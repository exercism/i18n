# Instrucciones

Tu amiga Leticia trabaja en la oficina de objetos perdidos de una estación de metro.

Cada artículo que se encuentra se añade como una nueva entrada en un array de artículos del día.
Al final del mes, todo artículo que no se haya recuperado se traslada a un depósito, en una caja etiquetada con la fecha en que se encontró.
Todo esto se hace en papel, así que a veces la cosa se vuelve inmanejable.

Leticia te ha pedido ayuda para automatizar algunas de estas tareas.

~~~~exercism/note
Estas son las instrucciones mencionadas en este concepto:

| Instrucción   | Descripción                                               |
|---------------|-----------------------------------------------------------|
| push a        | introduce `a` en la pila, reduciendo `rsp` en el tamaño de `a`  |
| pop a         | extrae `a` de la pila, aumentando `rsp` en el tamaño de `a`  |
~~~~

## 1. Crea una entrada para cada artículo

Lo primero que tienes que hacer es organizar todos los artículos, para que sea más fácil buscarlos.
Cada artículo se identifica en el almacenamiento por su ID, una descripción, la fecha en que se encontró y un número variable de categorías.

Define una función `create_item_entry` que no tiene valor devuelto e inserta una nueva entrada para un artículo en una posición de memoria.
Esta función puede recibir cualquier número de parámetros, de los cuales los seis primeros son siempre:

1. La dirección de una posición de memoria donde debe almacenarse la entrada.
2. El ID del artículo, como un entero sin signo de 64 bits.
3. La dirección de un string con la descripción del artículo.
4. El día en que se encontró el artículo, como un entero sin signo de 64 bits.
5. El mes en que se encontró el artículo, como un entero sin signo de 64 bits.
6. El número de categorías del artículo, como un entero sin signo de 64 bits.

Cada parámetro posterior es la dirección de un string con una de las categorías.

Los valores deben almacenarse en la posición de memoria proporcionada en el mismo orden que los argumentos: ID, descripción, día, mes, número de categorías y cada categoría en orden.

## 2. Reserva espacio para un array mensual de artículos

Es engorroso buscar artículos en tantos arrays distintos.
Así que decides organizarlo todo en un único array por mes.
Este array se implementa como una zona de memoria.

Define la función `create_monthly_list` que reserva espacio en memoria para un array y devuelve la dirección de esa posición de memoria.
Recibe como parámetros:

1. La capacidad del array en bytes, como un entero sin signo de 64 bits.
2. Una función de reserva de memoria.

La función de reserva recibe como parámetro un entero sin signo de 64 bits correspondiente al tamaño en memoria que hay que reservar, en bytes, y devuelve la dirección del espacio reservado.

Ten en cuenta que el espacio reservado tiene un valor _indefinido_, así que hay que limpiar todos los bytes de ese espacio, es decir, hay que asignarles el valor `0`.

## 3. Inserta un artículo en el array mensual

Cada día, todo artículo encontrado debe insertarse en el array mensual.

Define la función `insert_found_item` que no tiene valor devuelto y recibe como parámetros:

1. La dirección de una posición de memoria donde se encuentra el array mensual.
2. El número actual de entradas ya almacenadas en el array, como un entero sin signo de 64 bits.
3. Una nueva entrada que se va a añadir al array.

Puedes suponer que la nueva entrada siempre cabe en el array y que cada entrada del array ocupa 120 bytes de espacio.

## 4. Imprime un artículo

Buscar una entrada concreta sería mucho más fácil si Leticia pudiera verla impresa en la pantalla.

Define la función `print_item` que recibe como parámetros:

1. La dirección de un búfer donde puede almacenarse un string introductorio terminado en NUL ASCII.
2. La dirección de una posición de memoria donde se encuentra el array mensual.
3. El índice de la entrada en el array correspondiente al artículo que hay que imprimir, como un entero sin signo de 64 bits.
4. Una función de impresión.

Esta función no tiene valor devuelto y debe llamar a la función de impresión con los siguientes argumentos:

1. La dirección de una posición de memoria donde se almacena el string introductorio; o `0` (como un entero de 64 bits) si no se pasa ningún string.
2. El índice de la entrada en el array correspondiente al artículo que hay que imprimir, como un entero sin signo de 64 bits.
3. El ID del artículo, como un entero sin signo de 64 bits.
4. La dirección de un string con la descripción del artículo.
5. El día en que se encontró el artículo, como un entero sin signo de 64 bits.
6. El mes en que se encontró el artículo, como un entero sin signo de 64 bits.
7. El número de categorías del artículo, como un entero sin signo de 64 bits.
8. La dirección del primer string de categoría.

El string introductorio es opcional.
Si se usa en la función de impresión, este string debe terminar en NUL (acabar en `0`) y tener como máximo 50 caracteres, teniendo ya en cuenta el terminador NUL.
En caso contrario, debe pasarse el valor `0` a la función de impresión.

Puedes suponer que cada artículo del array ocupa 120 bytes de espacio.
