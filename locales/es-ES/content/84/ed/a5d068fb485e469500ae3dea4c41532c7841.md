# Anexo a las instrucciones

## Formato de entrada

Cada ficha de dominó se almacena en un único byte, con la mitad izquierda en el [nibble] alto y la mitad derecha en el [nibble] bajo. Por ejemplo, las fichas `[2|1]`, `[2|3]` y `[1|3]` se representan como los bytes `0x21 0x23 0x13`.

## Registros

| Registro | Uso       | Tipo    | Descripción                                              |
| -------- | --------- | ------- | -------------------------------------------------------- |
| `$a0`    | entrada   | dirección | array de bytes de las fichas                           |
| `$a1`    | entrada   | entero  | número de fichas                                         |
| `$v0`    | salida    | Boolean | las fichas de dominó se pueden encadenar (`0` = `false`, `1` = `true`) |
| `$t0-9`  | temporal  | cualquiera | se usa para almacenamiento temporal                   |


[nibble]: https://en.wikipedia.org/wiki/Nibble
