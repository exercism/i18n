# Pistas

## 1. Hazlo magnífico

- Mapear es el proceso correcto para aplicar una función a cada elemento de una secuencia.
- `mapcar` es una buena función para aplicar una función a un array.

## 2. Solo lo mejor

- El filtrado es el proceso correcto para eliminar uno o más elementos de una secuencia, dando como resultado una nueva secuencia.
- `remove` puede eliminar valores de una secuencia que sean iguales a un elemento específico.
- `remove-if` puede eliminar valores para los cuales una función de predicado se evalúa como un valor verdadero.
