# Acerca de

Las estructuras de datos que pueden contener cero o más elementos se conocen como _colecciones_.
Un **array** en Ruby es una colección que mantiene el orden en el que se añaden sus objetos.
Los arrays pueden contener cualquier objeto.
Los objetos se pueden añadir a un array o recuperar de él usando un índice.
La indexación de los arrays en Ruby empieza en cero, lo que significa que el índice del primer elemento siempre es cero:

```ruby
# Declare an array containing two values
two_ints = [1,2]

# Assign first and second element by index
two_ints[0] = 7
two_ints[1] = 8

# Retrieve the second element by index
two_ints[1] # => 8

# Check the length of the array
two_ints.size # => 2
```

En Ruby hay varias formas de crear un array:

- Usando el constructor literal `[]` _(la más común)_
- Llamando explícitamente a `Array.new`
- Llamando al método `Array()` de Kernel

El método `Array.new` admite dos argumentos opcionales: el tamaño inicial del array y un objeto predeterminado.

Cuando se proporcionan un tamaño y un valor predeterminado, el array se rellena con `size` copias del objeto predeterminado.

```ruby
a = Array.new(2, Hash.new)
# => [{}, {}]
```

Como todos los elementos del array almacenan el mismo hash, los cambios en uno de ellos afectarán a todos.

```ruby
a[0]['cat'] = 'feline'
a # => [{"cat"=>"feline"}, {"cat"=>"feline"}]

a[1]['cat'] = 'Felix'
a # => [{"cat"=>"Felix"}, {"cat"=>"Felix"}]
```

Si lo que quieres son varias copias, deberías usar la versión con bloque, que utiliza el resultado de ese bloque cada vez que hay que inicializar un elemento del array:

```ruby
a = Array.new(2) {Hash.new}
a[0]['cat'] = 'feline'
a # => [{"cat"=>"feline"}, {}]
```

Otra característica de los arrays de Ruby es que incluyen el módulo [Enumerable][enumerable-module], que añade un montón de métodos útiles para iterar, buscar, ordenar, filtrar, etc., elementos de un array.
