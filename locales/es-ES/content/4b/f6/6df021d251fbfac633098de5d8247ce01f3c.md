# Parámetros variádicos

Los [_parámetros variádicos_][variadic-parameters] en Swift permiten pasar cero o más valores del mismo tipo a un único parámetro de una función.
Esto se indica añadiendo `...` a la anotación de tipo del parámetro.

Estos valores se agruparán automáticamente en un array cuyos elementos serán del mismo tipo que el del parámetro variádico.

```swift
func geometricMean(_ numbers: Double...) -> Double {
  var total = 1.0
  for number in numbers {
      total *= number
  }
  return pow(total, 1.0 / Double(numbers.count))
}

geometricMean(1, 2, 3, 4, 5)
// Returns 2.605171084697352
```

Al usar parámetros variádicos, Swift tiene dos limitaciones:

1. Swift solo permite que las funciones tengan un parámetro variádico. Se ha decidido que esta restricción se eliminará en una futura versión de Swift, pero de momento sigue vigente.
2. Si una función tiene parámetros que siguen al parámetro variádico en la definición, el primer parámetro que sigue al parámetro variádico _debe_ tener una etiqueta de argumento.

[variadic-parameters]: https://docs.swift.org/swift-book/documentation/the-swift-programming-language/functions/#Variadic-Parameters
