# Introducción

## Boolean en Julia

Los valores verdadero o falso se representan con el tipo `Bool`.
Contiene solo dos valores: `true` y `false`.

```julia-repl
julia> true
true

julia> false
false
```

## Operadores Boolean

Hay tres operadores Boolean en Julia.

`&&` es el «y» Boolean.
Se evalúa como `true` si las expresiones en *ambos* lados de `&&` son `true`.

```julia-repl
julia> true && true
true

julia> true && false
false
```

`||` es el «o» Boolean.
Se evalúa como `true` si una expresión en *cualquiera* de los lados de `||` es `true`.

```julia-repl
julia> true || true
true

julia> false || true
true
```

`!` es el «no» Boolean.
Intercambia los valores `true` y `false`.

```julia-repl
julia> !true
false

julia> !false
true
```

Para expresiones más largas y complicadas, lo mejor es usar paréntesis para dejar clara tu intención.

```julia-repl
julia> (true || false) && (false && true)
false
```
