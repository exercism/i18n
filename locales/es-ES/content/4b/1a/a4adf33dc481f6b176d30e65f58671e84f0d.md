## Añadir un método al struct `Int`

Este ejercicio se centra en añadir métodos al struct `Int` de Crystal.
Para ello tendrás que definir un struct con el nombre `Int`.
Y colocar el método dentro de este struct.

```crystal
struct Int
  # your solution here
end
```
