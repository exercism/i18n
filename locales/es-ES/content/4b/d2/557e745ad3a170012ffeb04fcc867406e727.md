# Instalación

## Usuarios de Windows

Instala [Windows Subsystem for Linux][wsl-link] y consulta la sección siguiente.

## Usuarios de Linux/Mac

### Instalar con brew

Esta es la forma más sencilla de instalar Chapel.
Te proporcionará una instalación básica y funcional, adecuada para trabajar en el track de Exercism.
Los usuarios más avanzados quizá prefieran compilar Chapel a partir del código fuente (la sección siguiente).

0. Si aún no lo has hecho, instala el gestor de paquetes [brew][brew-link].
1. En primer lugar, asegúrate de que brew está actualizado ejecutando `brew update`
2. Instala Chapel ejecutando `brew install chapel`
3. Comprueba que la instalación se ha realizado correctamente ejecutando `chpl --version`

Esto instalará el compilador de Chapel (`chpl`), el gestor de paquetes `mason`, que usaremos para ejecutar las pruebas, y la herramienta de generación de documentación `chpldoc`. Esta última no es necesaria para Exercism, pero es bueno tenerla si (cuando :) ) quieres desarrollar tus propias bibliotecas en Chapel.

### Compilar Chapel a partir del código fuente

Los usuarios más avanzados quizá quieran compilar Chapel ellos mismos a partir del código fuente. Para ello:

1. Instala los [requisitos previos][prereqs-link].
2. [Descarga][download-link] el archivo de la última versión de Chapel y descomprímelo.
3. En primer lugar, debes preparar la instalación y configurar dónde quieres instalar Chapel.
Esto se puede hacer ejecutando el script `configure` proporcionado.
Basta con ejecutar

```
./configure
```

para instalar los binarios, las bibliotecas y los archivos compartidos en `/usr/local/`; puedes cambiar esto con la opción `--prefix`.
Por ejemplo, si quieres instalar Chapel en `~/.chapel`, puedes hacer

```
./configure --prefix=~/.chapel
```

4. Para instalar el compilador y las herramientas, ejecuta

```
make
make mason
make chpldoc
make install
```

5. Asegúrate de que la carpeta `/dir/for/install/bin` está en tu variable `PATH`.

Para obtener más información sobre las distintas formas de instalar Chapel y trabajar a partir del código fuente, consulta la página [Building Chapel][building-link] de la documentación.
