# Instrucciones

Vas a inicializar búferes vacíos y a listar los cinco primeros números, o elementos, de la sucesión de Fibonacci.

La sucesión de Fibonacci es un conjunto de números en el que cada elemento es la suma de los dos anteriores. Empezamos la sucesión en uno, así que los dos primeros elementos son 1 y 1.

## 1. Crea un búfer de `count` ceros

Crea una función que cree un búfer de `count` ceros.

```rust
let my_buffer = create_buffer(5);
// [0, 0, 0, 0, 0]
```

## 2. Lista los cinco primeros elementos de la sucesión de Fibonacci

Crea una función que devuelva los cinco primeros números de la sucesión de Fibonacci.
Sus cinco primeros elementos son `1, 1, 2, 3, 5`

```rust
let first_five = fibonacci();
// [1, 1, 2, 3, 5]
```
