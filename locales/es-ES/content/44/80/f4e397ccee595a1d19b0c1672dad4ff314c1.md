# Instalación

Consulta [System/Installation][install-link] para saber cómo configurar todo en tu sistema.

~~~exercism/caution
Si tienes instalado el Java Development Kit (JDK), el ejecutable `jconsole` podría entrar en conflicto con la Java Console, que usa el mismo nombre.

Entre las posibles soluciones se incluyen:

- Cambiar el nombre del ejecutable `jconsole` del lenguaje de programación J por uno único (por ejemplo, `jconsole-jlang`).

- Ajustar las variables de entorno o el PATH de tu sistema para dar prioridad al `jconsole` del lenguaje de programación J.

- **Si usas Linux**, hay un script de bash en `bin/install.sh` que creará un **enlace simbólico** llamado `ijconsole` en el directorio `/usr/`. Puedes usar este enlace escribiendo `ijconsole` en tu terminal.
~~~

Una vez instalado J, abre una consola de J en tu terminal e introduce los siguientes comandos para instalar el framework de pruebas unitarias:

```j
  load 'pacman'
  'update' jpkg ''
  'install' jpkg 'general/unittest'
  exit 0
```
