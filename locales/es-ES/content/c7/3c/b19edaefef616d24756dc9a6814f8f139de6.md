## Tupla

[Las tuplas][tuple] se usan habitualmente para agrupar información; se diferencian de las listas en que tienen un tamaño fijo y pueden contener distintos tipos de datos.
Las tuplas se crean con paréntesis, `()`, y a menudo se usan para devolver varios valores desde una función.

```haskell
tuple = (1, "abc", False)
```

Esto puede resultar útil cuando, por ejemplo, quieres almacenar una coordenada en un espacio 2D, ya que sabes que la tupla siempre tendrá dos elementos: la coordenada x y la coordenada y.

```haskell
coordinate = (3, 4)
```

### Acceder a los elementos

Con bastante frecuencia trabajarás con tuplas cortas, y puedes acceder a sus elementos con las funciones `fst` y `snd`.

```haskell
x = fst coordinate
-- x = 3
y = snd coordinate
-- y = 4
```

## Coincidencia de patrones

Al escribir funciones en Haskell, podemos hacer uso de un [estilo asertivo][assertive-style] con la [coincidencia de patrones][pattern-match-doc]:
La coincidencia de patrones es una característica muy potente de Haskell que te permite buscar coincidencias en constructores de datos y vincular variables a los valores que contienen.
Como su nombre indica, lo que hacemos es comparar valores con patrones y, si el valor coincide con el patrón, podemos vincular variables a los valores que hay dentro de él.
La coincidencia de patrones se compone principalmente de estos conceptos: reconocer valores, vincular variables y descomponer valores.

Fíjate, por ejemplo, en esta función:

```haskell
lucky :: Int -> String
lucky 7 = "Lucky number seven!"
lucky x = "Sorry, you're out of luck, pal!"
```

Aquí tenemos una función `lucky` que recibe un `Int` y devuelve un `String`.
Hemos definido dos patrones para la función: uno que coincide con el número `7` y otro que coincide con cualquier otro número; el nombre puede ser cualquiera (siempre que siga la convención de nombres de Haskell), pero aquí usamos `x`.
Si el número es `7`, la función devolverá `"Lucky number seven!"`; en caso contrario, devolverá `"Sorry, you're out of luck, pal!"`.
Lo importante que hay que señalar aquí es que los patrones se comprueban de arriba abajo, así que si hubiéramos intercambiado el orden de los patrones, la función siempre devolvería `"Lucky number seven!"`.

### Patrones de listas

Un patrón muy habitual es el que coincide con listas, y consiste en tomar la cabeza y la cola de la lista.
Esto se debe a la naturaleza de las listas como listas enlazadas.
Aquí tienes un ejemplo de una función que devuelve la cabeza y la cola de una lista:

```haskell
headAndTail :: [Int] -> (Int, [Int])
headAndTail [] = error "Can't call head on an empty list"
headAndTail (x:xs) = (x, xs)
```

Aquí tenemos dos patrones: uno que coincide con una lista vacía y otro que coincide con una lista con al menos un elemento.
Esto se debe a que, si la lista está vacía, necesitamos un caso para eso; de lo contrario, obtendríamos un error en tiempo de ejecución.
Si la lista no está vacía, podemos hacer coincidir la cabeza de la lista con `x` y la cola con `xs`.
Esto se hace con el operador `:` (cons), que se usa para anteponer un elemento a una lista.
Pero en la coincidencia de patrones nos permite descomponer una lista en su cabeza y su cola, es decir, en cierto modo hacer lo contrario.

`xs` es un nombre habitual para la cola de una lista, y resalta que se trata de una lista; pero si trabajaras con una lista anidada, podrías usar `xss` para resaltar que es una lista de listas.

### Patrones de tuplas

Al igual que con las listas, también podemos hacer coincidir tuplas.
Aquí tienes un ejemplo de una función que recibe una tupla y devuelve el primer y el segundo elemento:

```haskell
sumTuple :: (Int, Int) -> Int
sumTuple (x, y) = x + y
```

Aquí tenemos un patrón que coincide con una tupla de dos elementos: el primer elemento se vincula a `x` y el segundo se vincula a `y`.

### Patrones comodín

A veces no nos importa el valor de una variable, solo queremos hacer coincidir el patrón.
Aquí es donde entra el patrón comodín, que se representa con un guion bajo, `_`.

Aquí tienes un ejemplo de una función que devuelve el primer elemento de una lista:

```haskell
head' :: [Int] -> Int
head' [] = error "Can't call head on an empty list"
head' (x:_) = x
```

Aquí decimos que no necesitamos la cola de la lista, así que usamos el patrón comodín para ignorarla.

### Patrones de tipos

También podemos hacer coincidir tipos, y esto se hace usando el constructor de dicho tipo.
También podemos extraer valores del tipo, como hicimos con las tuplas.

```haskell
data AccountType = Guest | User String 

greet :: AccountType -> String
greet Guest = "Welcome, guest!"
greet (User name) = "Welcome, " ++ name ++ "!"
```

En el primer patrón coincidimos con el constructor `Guest`, y en el segundo patrón coincidimos con el constructor `User` y vinculamos el valor que contiene a `name`.
