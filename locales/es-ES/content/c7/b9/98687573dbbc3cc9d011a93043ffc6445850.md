# Pistas

## General

- Puedes usar la [clase Random][random-class] para generar números aleatorios.
- Puedes leer más en el artículo: [Generadores de números aleatorios en Java 17][random-number-generators].

## Generación del laberinto

Puedes usar cualquier algoritmo para generar un laberinto perfecto. El [algoritmo de backtracking recursivo][recursive-backtracker] es una buena opción.
