## Editores

### Gratuitos y de código abierto

- [VS Code](https://code.visualstudio.com)

  VS Code es un editor de código de código abierto. Puedes encontrar información sobre cómo configurar TypeScript [aquí](https://code.visualstudio.com/docs/languages/typescript). VS Code es un editor muy popular para TypeScript porque Microsoft mantiene tanto VS Code como TypeScript, así que se lleva bien con el lenguaje; VS Code admite TypeScript sin ninguna configuración adicional. De hecho, ¡VS Code se escribió con TypeScript!

  Un problema frecuente con VS Code y TypeScript se da cuando la versión de tu editor y la de tu proyecto son distintas, lo que puede hacer que VS Code muestre un mensaje de error que resulte confuso. Tienes instrucciones sobre cómo solucionar este error [aquí](https://code.visualstudio.com/docs/typescript/typescript-compiling#_using-newer-typescript-versions)

### De pago

- [Sublime Text](https://www.sublimetext.com)

  Sublime Text es un editor de código muy popular que admite la mayoría de los lenguajes mediante complementos instalables. Puedes probarlo gratis, pero se te pedirá periódicamente que compres una licencia, que actualmente cuesta \$70 USD.

- [WebStorm](https://www.jetbrains.com/webstorm/)

  WebStorm es un IDE (entorno de desarrollo integrado) de JavaScript/TypeScript con todas las funciones. Admite TypeScript sin configuración adicional y cuenta con pruebas, depuración y análisis de código integrados. Puedes probarlo gratis durante 30 días; después, una licencia anual cuesta \$129 USD el primer año.
