# Pistas

## General

- Los conceptos previos [estructuras][structs], [mapas][maps] y [métodos][methods] son útiles aquí.


## 1. Seguimiento de los asistentes

- El concepto [definición de tipos][type definition] explica cómo definir un tipo nuevo.
- Usa `make()` para crear una nueva instancia de `map`.
- Para añadir un valor al mapa, usa `struct{}{}` para crear una instancia del `struct{}` vacío.

## 2. Comprobación de los asistentes

- Si un elemento está en el mapa, el conjunto contiene ese valor.
- La [asignación de dos valores][two value assignment] se puede usar para comprobar si un mapa contiene un elemento.

## 3. Comparación de los asistentes

- Dos conjuntos son iguales si todos los valores de cada uno están contenidos en el otro conjunto.
- `range` se puede usar para comprobar todos los elementos del conjunto.
