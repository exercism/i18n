En Raku se hace un uso generoso de los bloques de código.
Son fundamentales para las funciones, pero también aparecen en herramientas como `grep` y `map`, en forma de bloques de `if`, `for`, `while` y `given`, e incluso en los subíndices de un array.

## Rutinas

[`Subs`][type/Sub] y [`Methods`][type/Method] son tipos de [`Routines`][type/Routine] en Raku.

Una rutina puede salir en cualquier momento con un valor devuelto usando la palabra clave [`return`][control-return], lo que resulta muy útil para crear funciones.
Si no se especifica `return`, la última instrucción de la rutina será su valor devuelto implícito.

Una rutina puede tener una [`Signature`][language/signatures] entre paréntesis antes del bloque de código.

[`Routine`][type/Routine] es una subclase de [`Block`][type/Block].

```raku
sub add ($x, $y --> Int) { return $x + $y }
say add(1, 2); # 3
```

Los métodos se tratarán en un concepto aparte sobre clases y objetos.

## Bloques de código

Un [`Block`][type/Block] es un objeto de código reutilizable, que se suele usar para crear lambdas.

La última instrucción de un bloque de código es su valor devuelto implícito.

Un bloque de código puede llevar una [`Signature`][language/signatures] precedida de `->` delante del bloque de código.

[`Block`][type/Block] es una subclase de [`Code`][type/Code], que es la clase base última de todos los objetos de código de Raku.

```raku
my $add = -> $x, $y { $x + $y };
say $add(1, 2); # 3
```

## Firmas

Una [`Signature`][language/signatures] se compone de cero o más [`Parameters`][type/Parameter], separados por comas.

Al final de una firma se puede especificar un tipo de retorno con una [flecha de tipo de retorno][signatures-return-type-arrow] `-->`.

Una firma puede utilizarse para especificar los argumentos que aceptará un `Block`.

En este concepto mantendremos las firmas sencillas, usando solo parámetros posicionales con variables de sigilo escalar y un tipo de retorno.
Se ampliarán en otros conceptos.

## Multi-Dispatch

Raku permite escribir varias rutinas con el mismo nombre pero con firmas distintas usando la palabra clave `multi`.
Esta funcionalidad se conoce como [multi-dispatch][multi-dispatch].
Cuando se llama a la rutina por su nombre, el entorno de ejecución determina el candidato adecuado y lo invoca.

Esto se tratará con más detalle en un concepto sobre tipos.

```raku
multi foo () { say 'No arguments given'}

multi foo ($bar) { say "One argument given: $bar" }
```

## WhateverCode

Cuando el asterisco `*` de [`Whatever`][type/Whatever] se usa junto con la mayoría de los operadores, se crea un objeto [`WhateverCode`][type/WhateverCode].
Esto te permite crear bloques de código con una sintaxis más sencilla.

```raku
# These will all give code blocks that increment a single argument by 1:
-> $x { $x  + 1 }; # Explicit signature
      { $^x + 1 }; # Signature via placeholder variable
      { $_  + 1 }; # Topic variable
          * + 1;   # WhateverCode
```
