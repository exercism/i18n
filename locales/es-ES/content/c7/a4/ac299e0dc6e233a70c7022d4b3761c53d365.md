# Ayuda

Si tienes problemas, puedes usar uno de los siguientes recursos para obtener ayuda:

- [Página principal de Reason](https://reasonml.github.io/)
- [API de la biblioteca estándar de Reason](https://reasonml.github.io/api/index.html)
- [/r/reasonml](https://www.reddit.com/r/reasonml) es el subreddit de ReasonML.
- [StackOverflow](http://stackoverflow.com/questions/tagged/reasonml) puedes usarlo para buscar tu problema y ver si ya se ha respondido. También puedes hacer y responder preguntas.
