# Introducción

Un `string` en Clojure es una cadena de caracteres de Java, es decir, un objeto que representa texto inmutable como una secuencia de caracteres Unicode (letras, dígitos, signos de puntuación, etc.).

La biblioteca `clojure.string` proporciona muchas funciones estándar de manipulación y procesamiento de strings. Además, todos los métodos habituales de Java para operar con strings están disponibles mediante la interoperabilidad.
