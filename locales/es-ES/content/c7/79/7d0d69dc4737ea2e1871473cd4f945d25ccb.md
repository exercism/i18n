# Anexo a las instrucciones

En [concept:python/unpacking-and-multiple-assignment](https://github.com/exercism/python/tree/main/concepts/unpacking-and-multiple-assignment), aprendiste varias técnicas para trabajar con `lists`/`tuples` de longitud arbitraria, así como con argumentos de función de longitud arbitraria.
Este ejercicio es un lugar estupendo para practicar esas técnicas.

## Cómo está implementado este ejercicio para Python

Los casos de prueba de este track añaden un argumento de palabra clave adicional llamado `qualifier`.
Debes usar el valor de ese argumento de palabra clave para modificar el verso final de tu Proverb.
