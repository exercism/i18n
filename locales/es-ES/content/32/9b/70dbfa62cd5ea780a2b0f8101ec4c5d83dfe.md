# Introducción

Además del condicional, JavaScript también tiene una instrucción `switch` para ejecutar lógica de forma condicional.
Se usa cuando una misma variable debe compararse con varias variantes.
La comparación se hace comprobando la igualdad estricta (`===`); consulta el [concepto de comparación][concept-comparison].
Para una variable `x` cualquiera, la instrucción `switch` de JavaScript tiene la siguiente sintaxis.

<!-- prettier-ignore-start -->
```javascript
switch (x) {
  case option1:
    // code that is executed when "x === option1" is true
    break;
  case option2:
    // code that is executed when "x === option2" is true
    break;
  default:
    // code that is executed when x does not equal any of the options
}
```
<!-- prettier-ignore-end -->

El caso `default` es opcional y se usa cuando quieres ejecutar algo de código si ninguna de las otras opciones coincide con la variable.

Las instrucciones `break` anteriores son necesarias porque, de forma predeterminada, en JavaScript todos los casos son «fallthrough».
Esto significa que, sin ninguna instrucción `break`, se ejecutaría todo el código de los casos situados por debajo de la primera opción que coincide, aunque `x` no coincida con esas opciones.
Este comportamiento de «fallthrough» predeterminado es una trampa habitual al usar `switch` en JavaScript.
Dentro de una función, también se puede usar `return` en lugar de `break` para evitar este problema.
