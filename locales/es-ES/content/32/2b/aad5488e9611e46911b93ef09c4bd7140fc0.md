# Anexo de instrucciones

La potenciación de números racionales con un número real requiere calcular un número elevado a una potencia no entera, una funcionalidad que no está disponible de forma nativa en WebAssembly.

Sin embargo, también puedes expresar `x ^ y` como `x ^ y = exp(y * ln(x))`.

Y, afortunadamente, se pueden usar distintas series para calcular la exponencial y el logaritmo natural.

## La función exponencial

La mejor solución para la exponencial es una [serie de Taylor](https://en.wikipedia.org/wiki/Taylor_series):

```
exp(x) ≃ 1 + x + x ^ 2 / 2! + x ^ 3 / 3! + x ^ 4 / 4! + ... + x ^ n / n!
```

## La función logaritmo (para x positiva)

Hay varias formas de calcular de manera eficiente un logaritmo natural. Una de ellas es una serie basada en una [tangente hiperbólica inversa](https://en.wikipedia.org/wiki/Logarithm#Inverse_hyperbolic_tangent):

```
ln(x) / 2 ≃ y + y ^ 3 / 3 + y ^ 5 / 5 + ... + y ^ n / n where y = (x - 1) / (x + 1)
```

También existe otra serie de Taylor para calcular el logaritmo natural:

```
ln(x) = (x - 1) - (x - 1) ^ 2 / 2 + (x  - 1) ^ 3 / 3 - (x - 1) ^ 4 / 4 ... + (x - 1) ^ n / n
```

Solo es precisa para valores de `x` entre 0 y 2. Sin embargo, también podemos usar `ln(x) = - ln(1 / x)`

## Potenciación con exponentes enteros

Para la potenciación con exponentes enteros, es mejor usar la multiplicación y un bucle o la recursión, tanto por rendimiento como por precisión. Para mejorar aún más el rendimiento, se puede usar el [método de Horner](https://en.wikipedia.org/wiki/Horner%27s_method) para reducir el número de multiplicaciones.
