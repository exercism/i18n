# Acerca de

Al escribir funciones en Haskell, podemos hacer uso de la [coincidencia de patrones][pattern-matching].
La coincidencia de patrones es una característica muy potente de Haskell que te permite coincidir con constructores de datos y vincular variables a los valores que contienen.
Como su nombre indica, lo que hacemos es hacer coincidir valores con patrones y, si el valor coincide con el patrón, podemos vincular variables a los valores que hay dentro del patrón.
La coincidencia de patrones se basa principalmente en estos conceptos: reconocer valores, vincular variables y descomponer valores.

~~~~exercism/note
La coincidencia de patrones en lenguajes como Elixir es un poco diferente de la coincidencia de patrones en Haskell.
Elixir, por ejemplo, permite varios nombres de vinculación iguales en un patrón, mientras que Haskell no.
~~~~


Fíjate en esta función:

```haskell
lucky :: Int -> String
lucky 7 = "Lucky number seven!"
lucky x = "Sorry, you're out of luck, pal!"
```

Aquí tenemos una función `lucky` que recibe un `Int` y devuelve un `String`.
Hemos definido dos patrones para la función: uno que coincide con el número `7` y otro que coincide con cualquier otro número. El nombre puede ser cualquiera (siempre que siga la convención de nombres de Haskell), pero aquí usamos `x`.
Si el número es `7`, la función devolverá `"Lucky number seven!"`; de lo contrario, devolverá `"Sorry, you're out of luck, pal!"`.
Lo importante aquí es que los patrones se comprueban de arriba abajo, así que si hubiéramos intercambiado el orden de los patrones, la función siempre devolvería `"Lucky number seven!"`.

## Patrones de listas

Un patrón muy común es el que coincide con listas y consiste en tomar la cabeza y la cola de la lista.
Esto se debe a la naturaleza de las listas como listas enlazadas.
Aquí tienes un ejemplo de una función que devuelve la cabeza y la cola de una lista:

```haskell
headAndTail :: [Int] -> (Int, [Int])
headAndTail [] = error "Can't call head on an empty list"
headAndTail (x:xs) = (x, xs)
```

Aquí tenemos dos patrones: uno que coincide con una lista vacía y otro que coincide con una lista con al menos un elemento.
Esto se debe a que, si la lista está vacía, necesitamos tener un caso para ello; de lo contrario, obtendríamos un error en tiempo de ejecución.
Si la lista no está vacía, podemos hacer coincidir la cabeza de la lista con `x` y la cola de la lista con `xs`.
Esto se hace usando el operador `:` (cons), que se usa para anteponer un elemento a una lista.
Pero en la coincidencia de patrones nos permite descomponer una lista en su cabeza y su cola, de algún modo haciendo lo contrario.

El nombre `xs` es común para la cola de una lista; resalta que es una lista, pero si trabajaras con una lista anidada, podrías usar `xss` para resaltar que es una lista de listas.

## Patrones de tuplas

Al igual que con las listas, también podemos hacer coincidir tuplas.
Aquí tienes un ejemplo de una función que toma una tupla y devuelve el primer y el segundo elemento:

```haskell
sumTuple :: (Int, Int) -> Int
sumTuple (x, y) = x + y
```

Aquí tenemos un patrón que coincide con una tupla de dos elementos: el primer elemento se vincula a `x` y el segundo se vincula a `y`.

## Patrones comodín

A veces no nos importa el valor de una variable; solo queremos hacer coincidir el patrón.
Aquí es donde entra el patrón comodín, que se denota con un guion bajo `_`.

Aquí tienes un ejemplo de una función que devuelve el primer elemento de una lista:

```haskell
head' :: [Int] -> Int
head' [] = error "Can't call head on an empty list"
head' (x:_) = x
```

Aquí decimos que no necesitamos la cola de la lista, así que usamos el patrón comodín para ignorarla.

## Patrones de tipos

También podemos hacer coincidir tipos; esto se hace usando el constructor de dicho tipo.
También podemos extraer valores del tipo, como hicimos con las tuplas.

```haskell
data AccountType = Guest | User String 

greet :: AccountType -> String
greet Guest = "Welcome, guest!"
greet (User name) = "Welcome, " ++ name ++ "!"
```

En el primer patrón coincidimos con el constructor `Guest`, y en el segundo coincidimos con el constructor `User` y vinculamos el valor que contiene a `name`.
