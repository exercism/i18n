# Anexo de instrucciones

## Mensajes de excepción

A veces es necesario [lanzar una excepción](https://docs.python.org/3/tutorial/errors.html#raising-exceptions). Cuando lo hagas, siempre deberías incluir un **mensaje de error significativo** que indique cuál es el origen del error. Esto hace que tu código sea más legible y ayuda mucho a la hora de hacer debug. En situaciones en las que sepas que el origen del error va a ser de un tipo concreto, puedes optar por lanzar uno de los [tipos de error integrados](https://docs.python.org/3/library/exceptions.html#base-classes), pero aun así deberías incluir un mensaje significativo.

Este ejercicio en concreto requiere que uses la [instrucción raise](https://docs.python.org/3/reference/simple_stmts.html#the-raise-statement) para «lanzar» un `ValueError` cuando el argumento que se pasa no es un literal binario válido. Los tests solo pasarán si tanto haces `raise` de la `exception` como incluyes un mensaje con ella.

Para lanzar un `ValueError` con un mensaje, escribe el mensaje como argumento del tipo `exception`:

```python
# example when the argument passed is not a valid binary literal
raise ValueError("Invalid binary literal: " + digits)
```
