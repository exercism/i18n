# Instrucciones

Mientras planean una noche de juegos con amigos, el grupo decide rememorar sus favoritos de la infancia. Tu amigo alemán propone el _Mensch ärgere Dich nicht_ (_Hombre, no te enfades_), un clásico en muchos países europeos (similar al _Ludo_ inglés o al _Parcheesi_ norteamericano).

Para prepararte para la partida, decides implementar la función de lanzamiento de dados en Elixir.

En el _Mensch ärgere Dich nicht_, los jugadores lanzan un dado de 6 caras para determinar su siguiente movimiento. Si tienen suerte y sacan un 6, pueden volver a lanzar y mover.

## 1. Haz una tirada de un dado de 6 caras

Implementa la función `d6/0`, que elegirá aleatoriamente un número entero entre 1 y 6 en cada llamada.

```elixir
MenschAergereDichNicht.d6()
# => 1
MenschAergereDichNicht.d6()
# => 5
```

## 2. Sigue lanzando mientras saques seises

Implementa la función `roll/0`. Debería devolver un stream de tiradas de dados. Las tiradas deben seguir las reglas del juego. Si saco un seis, puedo volver a lanzar. En caso contrario, dejo de lanzar. Usa la función `d6/0` definida en el paso anterior.

```elixir
MenschAergereDichNicht.roll() |> Enum.to_list()
# => [5]
MenschAergereDichNicht.roll() |> Enum.to_list()
# => [6, 3]
```

## 3. Permite usar un dado trucado

Para que sea más fácil probar tu código, permite usar un dado trucado.

Amplía la función `roll/0`. Debería aceptar un argumento opcional: una función. Si se pasa el argumento, úsalo para hacer la tirada. En caso contrario, recurre a `MenschAergereDichNicht.d6/0`.

```elixir
MenschAergereDichNicht.roll(fn -> 3 end) |> Enum.to_list()
# => [3]
```
