# Declaración de tipos

PHP es un lenguaje de _tipado dinámico_, lo que significa que una variable puede contener cualquier tipo de información.
PHP sí permite la declaración fuerte de tipos _opcional_ para las propiedades de clase, los argumentos de función y los valores devueltos de función.
Las declaraciones fuertes de tipo en PHP proporcionan aserciones de tipo en tiempo de ejecución; sin embargo, PHP intentará convertir los tipos escalares para que coincidan con la declaración si es posible.
El comportamiento de conversión se puede desactivar con la declaración `strict_types` al principio del archivo.

```php
<?php
declare(strict_types=1);
```

Además, las funciones pueden devolver un tipo `void` para indicar que no se debe devolver ningún valor desde la función.

```php
<?php
declare(strict_types=1);

class Driver
{
    string $serial_number;

    function setSerialNumber(string $number): void
    {
        $this->serial_number = $number;
    }

    function getSerialNumber(): string
    {
        return $this->serial_number; 
    }
}

$driver = new Driver(); 
$driver->setSerialNumber(1234);
// => This will throw a TypeError with strict_types=1
```

## Uniones de tipos

Si un argumento de función, un valor devuelto o una propiedad de clase puede ser de más de un tipo, se puede declarar una unión de tipos.

```php
<?php

class IdentityCard
{
    private int|float $id = 0;

    public function assign(int|float $id): void
    {
        $this->id = intval($id);
    }
}

$card = new IdentityCard();
$card->assign(5.0);
```

## Tipos mixtos

Cuando trabajamos con código, es posible que no podamos especificar un tipo.
A partir de PHP 8.0, se proporciona un tipo de escape llamado `mixed`.
Mixed equivale a una unión de tipos de `object|resource|array|string|float|int|bool|null`.
