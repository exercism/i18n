# Anexo a las instrucciones

## Instrucciones específicas del track

Implementa una función llamada `slices` que devuelva un array de strings como se describe arriba. Tu función debe lanzar un `IllegalArgumentError` con un mensaje de error apropiado, como se indica a continuación.
- Si el string dado está vacío, lanza un error con el mensaje `series cannot be empty`.
- Si la longitud del fragmento es negativa, lanza un error con el mensaje `slice length cannot be negative`.
- Si la longitud del fragmento es cero, lanza un error con el mensaje `slice length cannot be zero`.
- Si la longitud del fragmento supera la longitud del string, lanza un error con el mensaje `slice length can not be greater than series length`.
