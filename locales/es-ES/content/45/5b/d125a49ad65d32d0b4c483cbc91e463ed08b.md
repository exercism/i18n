# Pistas

## General

- La alineación de un struct es la alineación _máxima_ de cualquiera de sus campos.
- El tamaño de un struct es un múltiplo de su alineación.

## 1. Crear un coche teledirigido

- La alineación de un struct es la alineación _máxima_ de cualquiera de sus campos.
- El tamaño de un struct es un múltiplo de su alineación.
- La alineación de un array es igual a la alineación de sus elementos.
- Cada bloque de 8 bytes de un struct debe clasificarse por separado.
- Si un número entero y un valor de coma flotante comparten los mismos 8 bytes, los 8 bytes completos se pasan en un Registro de Propósito General (GPR).
- Un valor de coma flotante no puede ser una constante definida en tiempo de ensamblado con `equ`, pero sí puede ser una constante de la sección .rodata.
- Para mover bytes en bruto de un registro `xmm` a un GPR, sin cambiar su representación en bits, se pueden usar las instrucciones [movd][mov] o [movq][mov].

## 2. Crear una nueva pista

- La alineación de un struct es la alineación _máxima_ de cualquiera de sus campos.
- El tamaño de un struct es un múltiplo de su alineación.
- Si los campos adyacentes de un struct no se pueden agrupar para que quepan en su alineación, se insertan bytes de relleno.

## 3. Crear un evento de carreras

- La alineación de un struct es la alineación _máxima_ de cualquiera de sus campos.
- El tamaño de un struct es un múltiplo de su alineación.
- Un struct de hasta 16 bytes se pasa en registros a una función.
- Un struct de más de 16 bytes normalmente se coloca en memoria.
- Cuando una función devuelve un struct en memoria, la dirección de una posición de memoria para guardar este struct se pasa como primer argumento implícito, en `rdi`.
- En este caso, la función debe devolver esta dirección en `rax`.

## 4. Confirmar un coche para la carrera

- La alineación de un struct es la alineación _máxima_ de cualquiera de sus campos.
- El tamaño de un struct es un múltiplo de su alineación.
- Un puntero ocupa 8 bytes y se pasa en un Registro de Propósito General (GPR), independientemente del tamaño del tipo al que apunta.
- Tanto el array `cars` como el número de coches en carrera deben actualizarse en `race`.

## 5. Crear un torneo

- La alineación de un struct es la alineación _máxima_ de cualquiera de sus campos.
- El tamaño de un struct es un múltiplo de su alineación.
- Un struct de más de 16 bytes normalmente se coloca en memoria.
- Cuando una función recibe como argumento un struct en memoria, este struct se pasa en la pila.
- Tanto el array `races` como el número de carreras deben actualizarse en `tournament`.
