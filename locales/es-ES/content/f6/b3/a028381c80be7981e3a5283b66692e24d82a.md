# Consejos

## General

- Los índices de `Vector` empiezan en `1`.
- Las barajas no contienen cartas duplicadas.

## 1. Determina si una carta está presente

- Hay un método [`in`/`∈`](https://docs.julialang.org/en/v1/base/collections/#Base.in) en Base para determinar si una colección contiene un valor.

## 2. Encuentra la posición de una carta

- Hay un método [`findfirst`](https://docs.julialang.org/en/v1/base/arrays/#Base.findfirst-Tuple{Function,%20Any}) en Base para encontrar la posición del primer elemento de una colección que coincide con un predicado dado.
- Se puede usar `==(x)` como predicado para encontrar elementos iguales a `x` en los métodos que aceptan funciones de predicado.

## 3. Determina si cada carta es par

- Hay un método [`all`](https://docs.julialang.org/en/v1/base/collections/#Base.all-Tuple{AbstractArray,%20Any}) en Base que devuelve `true` si todos los elementos de una colección cumplen un predicado dado.
- [`iseven`](https://docs.julialang.org/en/v1/base/numbers/#Base.iseven) es una función de predicado.

## 4. Comprueba si la baraja contiene una carta de valor impar

- Hay un método [`any`](https://docs.julialang.org/en/v1/base/collections/#Base.any-Tuple{AbstractArray,%20Any}) en Base que devuelve `true` si algún elemento de una colección cumple un predicado dado.
- [`isodd`](https://docs.julialang.org/en/v1/base/numbers/#Base.isodd) es una función de predicado.

## 5. Determina la posición de la primera carta que es par

- Hay un método [`findfirst`](https://docs.julialang.org/en/v1/base/arrays/#Base.findfirst-Tuple{Function,%20Any}) en Base para encontrar la posición del primer elemento de una colección que coincide con un predicado dado.
- [`iseven`](https://docs.julialang.org/en/v1/base/numbers/#Base.iseven) es una función de predicado.

## 6. Obtén la primera carta impar de la baraja

- Puedes obtener el valor en la posición `n` de un vector `v` con `v[n]`.
- Hay un método [`findfirst`](https://docs.julialang.org/en/v1/base/arrays/#Base.findfirst-Tuple{Function,%20Any}) en Base para encontrar la posición del primer elemento de una colección que coincide con un predicado dado.
- Si ningún elemento de la colección dada coincide con el predicado que se pasa a `findfirst`, `findfirst` devuelve `nothing`.
- Repasa cómo funciona `nothing` en Julia: [concept:julia/nothingness](../../../../concepts/nothingness/about.md)
- Repasa cómo funcionan los condicionales en Julia: [concept:julia/conditionals](../../../../concepts/conditionals/about.md)
