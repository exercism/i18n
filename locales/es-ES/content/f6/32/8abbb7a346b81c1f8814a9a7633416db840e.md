# Anexo de instrucciones

## Añadir métodos a la clase Array

Este ejercicio se centra en añadir métodos a la clase `Array` en Crystal.
Para ello, tendrás que definir una clase con el nombre `Array(T)`.
Y poner los métodos dentro de esta clase.

```crystal
class Array(T)
  # your solution here
end
```

La clase array es una clase [genérica][generic]; también es [indexable][] y [enumerable][].
El código fuente de la clase `Array` se puede encontrar [aquí][array].

[array]: https://github.com/crystal-lang/crystal/blob/7aa5cdd86/src/array.cr#L48
[generic]: https://crystal-lang.org/docs/syntax_and_semantics/generics.html
[indexable]: https://crystal-lang.org/api/Indexable.html
[enumerable]: https://crystal-lang.org/api/Enumerable.html
