# Pistas

## General

- Recuerda que la asignación de una variable es una expresión dentro de un pipeline y que produce como salida el mismo valor que recibió como entrada.
- Usa [el operador alternativo `//`][alternative] para proporcionar valores por defecto.

## 1. Define el tiempo esperado en el horno, en minutos

- Define una variable que contenga el valor del tiempo esperado.
- Incluye el valor en el objeto de salida bajo la clave `"expected_minutes_in_oven"`.
- El atajo de construcción de objetos `{$foo}` es lo mismo que `{foo: $foo}`

## 2. Calcula el tiempo restante en el horno, en minutos

- Incluye el valor calculado en el objeto de salida bajo la clave `"remaining_minutes_in_oven"`.
- [El operador `-`][subtraction] se usa para la resta aritmética con números.

## 3. Calcula el tiempo de preparación, en minutos

- Incluye el valor calculado en el objeto de salida bajo la clave `"preparation_time"`.
- [El operador `*`][multiplication] se usa para la multiplicación aritmética con números.
- Un buen estilo sugiere usar una variable para ponerle nombre al «valor mágico» del tiempo que se dedica a cada capa.

## 4. Calcula el tiempo total de trabajo, en minutos

- Incluye el valor calculado en el objeto de salida bajo la clave `"total_time"`.
- [El operador `+`][addition] se usa para la suma aritmética con números.
