# Instrucciones

Todo papel en la obra del colegio tiene un suplente: alguien que puede entrar en escena y hacer lo que el papel necesita, sin que el director de escena sepa quién es.

Las cinco tareas van en la clase `UNDERSTUDY`. Las dos primeras son rutinas normales que las tareas posteriores vincularán.

## 1. Dos formas de decir una línea

Escribe `shout`, que devuelve la línea en mayúsculas, y `whisper`, que la devuelve en minúsculas con `"..."` a cada lado.

```sather
UNDERSTUDY::shout("who's there")
-- => "WHO'S THERE"
UNDERSTUDY::whisper("Who's There")
-- => "...who's there..."
```

## 2. Ensayar una línea

`rehearse` toma una línea y una forma de decirla, y devuelve el resultado. Su segundo argumento tiene el tipo `ROUT{STR}:STR`.

```sather
UNDERSTUDY::rehearse("who's there", bind(UNDERSTUDY::shout(_)))
-- => "WHO'S THERE"
```

## 3. La escena completa

`run_scene` toma un array de líneas y una forma de decirlas, y las devuelve todas dichas de esa forma, unidas con `" "`.

```sather
UNDERSTUDY::run_scene(|"Enter", "Exit"|, bind(UNDERSTUDY::shout(_)))
-- => "ENTER EXIT"
```

Una escena vacía es el string vacío.

## 4. Devolver una forma de decir cosas

`understudy_for` toma el nombre de un estilo, `"shout"` o cualquier otra cosa, y devuelve un `ROUT{STR}:STR`. `"shout"` da el de gritar; cualquier otra cosa da el de susurrar.

```sather
part ::= UNDERSTUDY::understudy_for("shout");
part.call("who's there")
-- => "WHO'S THERE"
```

## 5. Fijar un argumento

Escribe `repeat`, que toma un número de veces y una línea y devuelve la línea esas veces seguidas sin nada en medio:

```sather
UNDERSTUDY::repeat(3, "Ha")
-- => "HaHaHa"
```

Luego escribe `doubler`, que no toma argumentos y devuelve un `ROUT{STR}:STR` que repite dos veces lo que se le dé, vinculando `repeat` con el número ya rellenado.

```sather
UNDERSTUDY::doubler.call("Ha")
-- => "HaHa"
```
