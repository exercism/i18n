# Anexo a las instrucciones

## Sobre la habilidad Stream

Un `Stream` es una habilidad de Unison que se usa para emitir valores.

Podrías usar la habilidad `Stream` si tienes una función que debe producir valores como efecto secundario mientras se ejecuta. Por ejemplo, esta función devuelve el último valor del array, pero emite un total acumulado a medida que se ve cada elemento:

```
emitRunningTotal : '{Stream Nat} Nat
emitRunningTotal = 'let
  use Nat +
  List.foldLeft (
    acc a -> let
      runningTotal = acc + a
      Stream.emit runningTotal
      a
    ) 0 [1,2,3,4,5]
```

Podemos materializar el Stream como un array junto con el valor devuelto de la función que lo produce mediante un manejador de habilidad:

```
> Stream.toListWithResult! emitRunningTotal
  ⧩
  ([1, 3, 5, 7, 9], 5)
```
