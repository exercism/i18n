# Introducción

El tipo `Result` es la solución que ofrece el lenguaje Elm para informar de errores y también permite recuperarse de ellos. Se parece en cierto modo al tipo `Maybe`, pero, aunque `Maybe` lo pueden devolver funciones que pueden fallar, no te dice nada sobre por qué ha fallado. `Result` incluye ese contexto sobre por qué falló algo.

El tipo `Result` se define del siguiente modo:

```elm
type Result error value
  = Ok value
  | Err error
```

Esto se conoce como una definición de «tipo personalizado» en la terminología de Elm.
El `error` y el `value` de `OK value` y `Error error` representan una variable de tipo, lo que significa que puede ser cualquier tipo, como `Int`, `Bool` o `String`.
Así pues, un `Result String Int` es una variable que se espera que contenga un `Int`, y si hay un error, este se representará como un `String`.
Existe un [módulo Result](https://package.elm-lang.org/packages/elm/core/latest/Result) con un montón de funciones auxiliares muy útiles para trabajar con `Result`.
