# Instrucciones

El contramaestre dirige una charla diaria de la guardia en cubierta: un saludo fijo, un pase de lista de la tripulación de guardia y una despedida final. Vas a dividir la charla en pequeñas líneas con nombre y a componerlas.

Vas a editar **dos archivos** para este ejercicio:

- `bosuns-briefing/helpers/helpers.factor`: piezas pequeñas reutilizables. Vocabulario: `bosuns-briefing.helpers`.
- `bosuns-briefing/bosuns-briefing.factor`: el archivo principal que compone las funciones auxiliares. Vocabulario: `bosuns-briefing`.

## 1. Saludo

En `helpers.factor`, define `greeting` para que devuelva el string fijo de apertura `"All hands, attention!"`.

```factor
greeting .
! => "All hands, attention!"
```

## 2. Línea de tripulación

En `helpers.factor`, define `crew-line` para que tome un string con un nombre y devuelva ese nombre precedido por `"  - "` (dos espacios, un guion y un espacio).

```factor
"Lopez" crew-line .
! => "  - Lopez"
```

## 3. Despedida

En `helpers.factor`, define `closing` para que devuelva el string fijo de despedida `"Carry on."`.

```factor
closing .
! => "Carry on."
```

## 4. Lista de tripulación

En `bosuns-briefing.factor`, define `roster` para que tome un array de nombres de tripulantes y devuelva un único string multilínea con cada nombre formateado por `crew-line`, unidos por saltos de línea.

```factor
{ "Lopez" "Mwangi" } roster .
! => "  - Lopez\n  - Mwangi"

{ } roster .
! => ""
```

## 5. Charla

En `bosuns-briefing.factor`, define `briefing` para que tome un array de nombres de tripulantes y devuelva la charla completa como un único string: el saludo en la primera línea, la lista de tripulación en las siguientes y la despedida en la última. Usa las funciones auxiliares y `roster`.

```factor
{ "Lopez" "Mwangi" } briefing .
! => "All hands, attention!\n  - Lopez\n  - Mwangi\nCarry on."

{ } briefing .
! => "All hands, attention!\n\nCarry on."
```
