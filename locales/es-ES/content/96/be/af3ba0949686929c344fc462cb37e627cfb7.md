# Añadir un nuevo track

El primer paso de todos para añadir un nuevo track de lenguaje a Exercism es:

- [Solicitar un nuevo track de lenguaje](/docs/building/tracks/new/request-new)

Una vez que hayas completado ese paso, los siguientes pasos son:

- [Unirte a nuestra comunidad](/docs/building/tracks/new/join-our-community)
- [Seleccionar la variante del lenguaje de programación](/docs/building/tracks/new/select-programming-language-variant) (si procede)
- [Seleccionar el framework de pruebas](/docs/building/tracks/new/select-testing-framework)
- [Añadir el primer ejercicio](/docs/building/tracks/new/add-first-exercise)
- [Configurar la integración continua](/docs/building/tracks/new/setup-continuous-integration)
- [Añadir los ejercicios iniciales](/docs/building/tracks/new/add-initial-exercises)
- [Construir el ejecutor de pruebas](/docs/building/tracks/new/build-test-runner)
- [Configurar las herramientas](/docs/building/tracks/new/configure-tooling)
- [Prepararte para el lanzamiento](/docs/building/tracks/new/prepare-for-launch)
- [Probar el track](/docs/building/tracks/new/test-track)
- [Buscar mantenedores](/docs/building/tracks/new/find-maintainers)
- [¡Lanzamiento!](/docs/building/tracks/new/launch)
- [Activar el resaltado de sintaxis](/docs/building/tracks/new/syntax-highlighting)
- [Implementar herramientas adicionales](/docs/building/tracks/new/implement-tooling)
- [Prepararte para recibir contribuciones de código abierto de desconocidos](/docs/building/tracks/new/prepare-for-contributions)
