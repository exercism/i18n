# Aprender

Exercism ofrece ejercicios y comentarios, pero puede resultar difícil de abordar para quienes están aprendiendo Erlang por primera vez. Estos recursos pueden ayudarte a empezar:

* [Erlang Documentation](http://www.erlang.org/doc.html)
* [Learn You Some Erlang for Great Good](http://learnyousomeerlang.com)
* [StackOverflow](http://stackoverflow.com/)
