# Acerca de

Cuando modelamos datos que solo pueden tomar un conjunto específico de estados posibles (como los días de la semana, las direcciones de una brújula o los botones de un mando), tipos básicos como `Int` o `String` tienen grandes inconvenientes.
Con enteros o strings, tu código debe comprobar constantemente si hay valores no válidos (como un código de estado de `999` o una errata como `"leftt"`), y los lectores humanos no pueden saber fácilmente qué representan los números.

Swift resuelve este problema con [_enumeraciones_][enumerations] (a menudo abreviadas como *enums*).
Una enumeración define un tipo común para un grupo de valores relacionados con nombre. Como el compilador conoce todos los casos posibles de antemano, puede comprobar la exactitud y exhaustividad de tu código en tiempo de compilación.
Las enumeraciones también pueden tener métodos, inicializadores y propiedades calculadas.

## Definir enumeraciones

Define una enumeración con la palabra clave `enum` seguida del nombre del tipo, con sus casos listados entre llaves.
Por convención de Swift, el nombre del tipo usa `UpperCamelCase`, mientras que cada caso usa `lowerCamelCase`:

```swift
enum NESButton {
    case up
    case down
    case left
    case right
    case a
    case b
    case select
    case start
}
```

También puedes definir varios casos en una sola línea separados por comas:

```swift
enum NESButton {
    case up, down, left, right, a, b, select, start
}
```

Para referirte a un caso de una enumeración, escribe el nombre del tipo de la enumeración, un punto (`.`) y el nombre del caso. Una vez que el tipo se conoce o el compilador puede inferirlo, puedes omitir el nombre del tipo y usar la sintaxis de punto más corta:

```swift
var lastPressed = NESButton.up

// Swift infers the type, so you can omit the type name:
lastPressed = .down

let konamiCode: [NESButton] = [.up, .up, .down, .down, .left, .right, .left, .right, .b, .a]
```

## Enumeraciones e instrucciones switch

Las enumeraciones funcionan a la perfección con las [instrucciones `switch`][enums-and-switches].
Como un `switch` en Swift debe ser exhaustivo, el compilador se asegura de que contemples todos los casos posibles:

```swift
lastPressed = .left
switch lastPressed {
case .up: print("You pressed the UP button")
case .down: print("You pressed the DOWN button")
case .left: print("You pressed the LEFT button")
case .right: print("You pressed the RIGHT button")
case .a: print("You pressed the A button")
case .b: print("You pressed the B button")
case .select: print("You pressed the SELECT button")
case .start: print("You pressed the START button")
}
// Prints "You pressed the LEFT button"
```

Si omites algún caso sin proporcionar una cláusula `default`, el compilador informa de un error:

```swift
switch lastPressed {
case .up, .down, .left, .right:
    print("You pressed a direction button.")
}
// Error: Switch must be exhaustive
```

A menudo es preferible listar todos los casos explícitamente que usar `default`. Así, si añades un nuevo caso en el futuro, el compilador te avisará de inmediato para que actualices cada instrucción `switch` que gestione esa enumeración.

## Métodos e inicializadores

Las enumeraciones pueden definir métodos e inicializadores personalizados igual que las clases y las estructuras. Dentro de un método de una enumeración, `self` se refiere al valor del caso actual:

```swift
enum Coin {
    case heads
    case tails

    init(_ value: Int) {
        if value.isMultiple(of: 2) {
            self = .heads
        } else {
            self = .tails
        }
    }

    func flip() -> Coin {
        switch self {
        case .heads: return .tails
        case .tails: return .heads
        }
    }
}

let tails = Coin(13)     // .tails
let heads = Coin(0)      // .heads
let flipped = heads.flip() // .tails
```

## Valores brutos

Los casos de una enumeración pueden estar precargados con valores predeterminados llamados [_valores brutos_][raw-values].
Todos los valores brutos de una enumeración deben compartir el mismo tipo (como `Int`, `String` o `Character`):

```swift
enum NESButton: Character {
    case up = "⬆️"
    case down = "⬇️"
    case left = "⬅️"
    case right = "➡️"
    case a = "🅰️"
    case b = "🅱️"
    case select = "✅"
    case start = "🚦"
}

print(NESButton.left.rawValue) // Prints "⬅️"
```

Puedes inicializar una enumeración a partir de un valor bruto usando `init(rawValue:)`. Como es posible que se proporcione un valor bruto no válido, este inicializador devuelve un opcional:

```swift
let upButton = NESButton(rawValue: "⬆️") // Optional(NESButton.up)
let invalid = NESButton(rawValue: "🙄")  // nil
```

Swift puede asignar valores brutos automáticamente para enumeraciones de tipo `String` e `Int`:

- En las enumeraciones de tipo `String`, el valor bruto de cada caso es su nombre de caso de forma predeterminada.
- En las enumeraciones de tipo `Int`, los valores brutos empiezan en `0` y se incrementan en 1 a menos que se especifique lo contrario.

```swift
enum Planet: Int {
    case mercury = 1, venus, earth, mars
}

print(Planet.earth.rawValue) // Prints 3
```

## Valores asociados

Los casos de una enumeración también pueden almacenar valores personalizados de distintos tipos junto a cada caso, conocidos como [_valores asociados_][associated-values]:

```swift
enum Suit: Character {
    case diamonds = "♦️", clubs = "♣️", hearts = "♥️", spades = "♠️"
}

enum Card {
    case ace(Suit)
    case king(Suit)
    case queen(Suit)
    case jack(Suit)
    case number(Suit, Int)

    func description() -> String {
        switch self {
        case .ace(let suit): return "A\(suit.rawValue)"
        case .king(let suit): return "K\(suit.rawValue)"
        case .queen(let suit): return "Q\(suit.rawValue)"
        case .jack(let suit): return "J\(suit.rawValue)"
        case let .number(suit, value): return "\(value)\(suit.rawValue)"
        }
    }
}

let aceOfSpades = Card.ace(.spades)
let twoOfHearts = Card.number(.hearts, 2)

print(aceOfSpades.description()) // Prints "A♠️"
print(twoOfHearts.description()) // Prints "2♥️"
```

Una enumeración puede usar valores brutos o valores asociados, pero no ambos.

## Enumeraciones recursivas

Una [enumeración recursiva][recursive-enumerations] es una enumeración que tiene otra instancia de la enumeración como valor asociado de uno o más casos.
Para habilitar la recursión, marca el caso (o la enumeración completa) con la palabra clave `indirect`:

```swift
enum BinaryTree {
    case leaf(value: Int)
    indirect case node(left: BinaryTree, value: Int, right: BinaryTree)
}

let tree: BinaryTree = .node(
    left: .leaf(value: 1),
    value: 3,
    right: .node(left: .leaf(value: 5), value: 6, right: .leaf(value: 9))
)
```
