# Introducción

## Variables

Elixir es un lenguaje de tipado dinámico, lo que significa que el tipo de una variable solo se comprueba en tiempo de ejecución. Con el operador de coincidencia `=`, podemos vincular un valor de cualquier tipo a un nombre de variable:

```elixir
# Bound an integer value of 1
count = 1
# You may re-bind variables
count = 2

# You may re-bind any type to a variable
count = false

# Strings can be created by enclosing characters within double quotes
message = "Success!"
```

## Módulos

Elixir es un [lenguaje de programación funcional][functional-programming] y exige que todas las funciones con nombre se definan dentro de un _módulo_. La palabra clave `defmodule` se usa para definir un módulo. Todos los módulos están disponibles para los demás módulos en tiempo de ejecución y no necesitan un _modificador de acceso_ para ser visibles desde otras partes del programa. Un _módulo_ es análogo a una _clase_ en otros lenguajes de programación.

```elixir
defmodule Calculator do
  # ...
end
```

## Funciones con nombre

Las _funciones con nombre_ deben definirse dentro de un módulo. La palabra clave `def` se usa para definir una función con nombre _pública_.

Cada función puede tener cero o más argumentos. El valor de la última expresión de una función siempre se _devuelve de forma implícita_.

```elixir
defmodule Calculator do
  def add(x, y) do
    x + y
  end
end
```

Para invocar una función, se indica el nombre de su módulo y de la función y se pasa un argumento para cada uno de los argumentos de la función.

```elixir
sum = Calculator.add(1, 2)
# => 3
```

La palabra clave `defp` puede usarse en lugar de `def` para definir una función _privada_. Las funciones privadas solo pueden usarse desde el mismo módulo que las define.

Cuando invocas una función dentro del mismo módulo en el que está definida, puedes omitir el nombre del módulo.

También puedes escribir funciones cortas con una sintaxis de una sola línea (fíjate en la coma `,` y los dos puntos `:` alrededor de la palabra clave `do`).

```elixir
defmodule Calculator do
  def subtract(x, y) do
    private_subtract(x, y)
  end

  defp private_subtract(x, y), do: x - y
end

difference = Calculator.subtract(7, 2)
# => 5

difference = Calculator.private_subtract(7, 2)
# => ** (UndefinedFunctionError) function Calculator.private_subtract/2 is undefined or private
#       Calculator.private_subtract(7, 2)
```

## Aridad de las funciones

Es habitual referirse a las funciones por su _aridad_. La _aridad_ de una función es el número de argumentos que acepta.

```elixir
# add/3 because this function has three arguments, thus an arity of 3
def add(x, y, z) do
  x + y + z
end
```

## Convenciones de nombres

Los nombres de los módulos deben usar `PascalCase`. El nombre de un módulo debe empezar por una letra mayúscula `A-Z` y puede contener letras `a-zA-Z`, números `0-9` y guiones bajos `_`.

Los nombres de variables y funciones deben usar `snake_case`. El nombre de una variable o de una función debe empezar por una letra minúscula `a-z` o un guion bajo `_`, puede contener letras `a-zA-Z`, números `0-9` y guiones bajos `_`, y puede terminar con un signo de interrogación `?` o un signo de exclamación `!`.

## Biblioteca estándar

Elixir tiene una biblioteca estándar muy completa y bien documentada. La documentación está disponible en línea en [hexdocs.pm/elixir][docs]. Guarda este enlace en algún sitio, ¡lo usarás mucho!

La mayoría de los tipos de datos integrados tienen un módulo correspondiente que ofrece funciones para trabajar con ese tipo de datos; por ejemplo, existe el módulo `Integer` para los enteros, el módulo `String` para los strings, el módulo `List` para los arrays, etc.

Un módulo destacable es el módulo `Kernel`. Proporciona las capacidades básicas sobre las que se construye el resto de la biblioteca estándar, como los operadores aritméticos, las macros de control de flujo y mucho más. Las funciones del módulo `Kernel` se importan automáticamente, así que puedes usarlas sin el prefijo `Kernel.`.

## Comentarios en el código

Los comentarios pueden usarse para dejar notas a otros desarrolladores que lean el código fuente. Los comentarios de una sola línea en Elixir van precedidos de `#`.
