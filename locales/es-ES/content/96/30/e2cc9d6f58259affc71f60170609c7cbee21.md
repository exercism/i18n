# Instrucciones

Como aficionado al ajedrez, te gustaría escribir tu propia versión del juego. Sí, puede que ya haya muchas implementaciones de ajedrez disponibles en internet, pero la tuya será única.

Pero antes de dejar volar tu imaginación, tienes que ocuparte de lo básico. Empecemos por generar el tablero.

Cada casilla del tablero de ajedrez se identifica por un par letra-número. Las columnas verticales de casillas están etiquetadas de la A a la H. Las filas horizontales de casillas están numeradas del 1 al 8.

## 1. Define el rango de filas

Implementa la función `rank_range/0`. Debería devolver un rango de números enteros, del 1 al 8.

```elixir
Chessboard.rank_range()
```

## 2. Define el rango de columnas

Implementa la función `file_range/0`. Debería devolver un rango de números enteros, desde el punto de código de la letra mayúscula A hasta el punto de código de la letra mayúscula H.

```elixir
Chessboard.file_range()
```

## 3. Transforma el rango de filas en un array de filas

Implementa la función `ranks/0`. Debería devolver un array de números enteros, del 1 al 8. No escribas el array a mano; genéralo a partir del rango que devuelve la función `rank_range/0`.

```elixir
Chessboard.ranks()
# => [1, 2, 3, 4, 5, 6, 7, 8]
```

## 4. Transforma el rango de columnas en un array de columnas

Implementa la función `files/0`. Debería devolver un array de letras (strings), de la «A» a la «H». No escribas el array a mano; genéralo a partir del rango que devuelve la función `file_range/0`.

```elixir
Chessboard.files()
# => ["A", "B", "C", "D", "E", "F", "G", "H"]
```
