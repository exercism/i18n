# Introducción

PowerShell es un lenguaje de scripting de Microsoft con tipado dinámico e implícito (también admite variables de tipado fuerte), centrado principalmente en la automatización de tareas y la gestión de la configuración.

PowerShell admite programación imperativa, funcional y orientada a objetos, e incluso el estilo de canalización.

PowerShell se creó sobre la plataforma .NET y se publicó por primera vez en 2006.
Se incluye de forma predeterminada en todos los sistemas Windows modernos y se puede instalar en Mac y Linux.


## Variables

Hay dos formas habituales de definir una variable en PowerShell.

El nombre de una variable en PowerShell debe empezar por `$` y se usa el operador de asignación `=` para vincular el nombre de la variable a un valor.

```powershell
> $intVar = 1
> $doubleVar = 2.0
> $stringVar = "Hello"

# Checking a variable type using the GetType() method
> Write-Host $doubleVar.GetType()
System.Double
```

También puedes especificar explícitamente el tipo de una variable si quieres forzar un [tipo][strong typed] concreto.
PowerShell intentará convertir el valor de un tipo a otro siempre que sea posible.

```powershell
# String represents a floating number can be converted to integer
> [int]$staticOne = "1.234"
> $staticOne
1

# String of letters can not be converted to double type
> [double]$staticTwo = "hello"
MetadataError: Cannot convert value "hello" to type "System.Double"
```


### Constantes

Las constantes en PowerShell son variables de solo lectura que no se pueden **eliminar** una vez definidas.
Esto nos lleva a la segunda forma de definir variables, usando el cmdlet `New-Variable`.

```powershell
> New-Variable -Name "MyConstant" -Value 100 -Option Constant
> $MyConstant
```

Para ver una forma más detallada y avanzada de crear una variable nueva con distintas opciones, consulta el cmdlet [New-Variable][New-Variable].


## Funciones

Las [funciones][functions] en PowerShell se definen con la palabra clave `function`.
Cada función puede tener cero o más [parámetros][parameters] formales entre paréntesis `()`, seguidos de su propio [scope][scope], que empieza con `{` y termina con `}`.

```powershell
function Greeting {
    return "Hello!"
}
```

Las funciones en PowerShell pueden devolver valores explícitamente mediante la palabra clave `return`, después de llamarlas con la sintaxis `FuncName $Arg`.

```powershell
function AddTwoNumbers($NumOne, $NumTwo):
    $result = $NumOne + $NumTwo
    return $result

> AddTwoNumbers 10 20
30
```

En el módulo de concepto `Functions` veremos con más detalle cómo escribir una definición de función detallada y cómo las funciones pueden devolver valores de forma implícita.


## Comentarios

Un comentario de una sola línea en PowerShell empieza con `#` y termina al final de la línea.
Un bloque de comentario en PowerShell empieza con `<#` y termina con `#>`.
En el módulo de concepto `Functions` veremos con más detalle cómo usar bloques de comentario para crear la Ayuda basada en comentarios.

```powershell
function Main() {
    #This is a comment
}
```
