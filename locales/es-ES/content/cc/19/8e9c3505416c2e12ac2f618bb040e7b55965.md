# Instrucciones

En este ejercicio vas a trabajar con algunas funciones para gestionar citas.
El sistema lo almacena todo en strings con formato ISO 8601, pero así no es como la gente usa el calendario.
Se necesitan varias funciones para convertir entre los distintos formatos.

## 1. Crea una cita

Crea una cita dentro de `n` días, a la hora actual.
La función recibe `n` días y devuelve la hora de la cita dentro de `n` días.

```javascript
createAppointment(4, now);
// Given now is Sun Oct 05 2022 23:28:43 GMT+0600 (Bangladesh Standard Time)
// => Sun Oct 09 2022 23:28:43 GMT+0600 (Bangladesh Standard Time)
```

Si no se usa el segundo parámetro `now`, se debe usar la hora actual en su lugar.

## 2. Convierte una fecha en una marca de tiempo

Varias herramientas solo funcionan con el formato ISO 8601, estandarizado internacionalmente.
Escribe la función `getAppointmentTimestamp` para que reciba una fecha y devuelva un string en ese formato.

```javascript
const appointment = new Date(Date.UTC(2010, 6, 16, 12, 42, 0, 0));

getAppointmentTimestamp(appointment);
// => '2010-07-16T12:42:00.000Z'
```

## 3. Obtén los detalles de una cita

Las marcas de tiempo son difíciles de leer; una función para obtener los detalles de la cita debería ayudar con eso.
La función `getAppointmentDetails` recibe una marca de tiempo en formato ISO 8601 y devuelve el año, el mes, el día, la hora y el minuto.

```javascript
getAppointmentDetails('2022-04-24T08:15:00.000');
// => { year: 2022, month: 3, date: 24, hour: 8, minute: 15 }
```

## 4. Actualiza una cita con las opciones dadas

La función recibirá como primer argumento la hora de la cita y como segundo argumento un objeto con algunas opciones.
Tienes que actualizar la cita según las opciones del objeto y devolver la nueva fecha de la cita.
El objeto de opciones puede tener varias opciones.

```javascript
updateAppointment('2022-02-09T09:20:00.000', { month: 6 });
// => { year: 2022, month: 6, date: 9, hour: 10, minute: 20 }
```

## 5. Obtén el tiempo disponible entre dos citas

La función recibirá dos citas (marcas de tiempo) como argumentos.
Tienes que devolver la diferencia entre esos dos tiempos en segundos.

Como medio segundo casi no significa nada, redondea el número antes de devolverlo.

```javascript
timeBetween('2022-12-12T09:20:00.000', '2022-12-18T08:30:00.000');
// => 515400
```

## 6. Comprueba si una cita es válida o no

Por último, cuando se crea la cita, el sistema necesita comprobar si es válida.
En otras palabras, la cita debe estar en el futuro, y no en el pasado.

Escribe la función `isValid`, que recibe dos argumentos: una marca de tiempo de la cita (string) y la hora actual como marca de tiempo (string), y devuelve `true` si la cita está en el futuro, dada la hora actual.

```javascript
isValid('2022-02-11T23:00:00.000', '2022-02-08T23:00:00.000');
// => true
```
