# Introducción

Trabajar con datos binarios puede ser complicado, así que Gleam proporciona un tipo `BitArray` y una sintaxis asociada para construir datos binarios y para aplicar coincidencia de patrones sobre ellos.

Los literales de bit array se definen con la sintaxis `<<>>`. Un literal de bit array se define en segmentos. Cada segmento tiene un valor y una anotación, separados por `:`. La anotación especifica cuántos bits se usarán para codificar el valor y se puede omitir por completo, en cuyo caso el valor predeterminado será un entero de 8 bits.

```gleam
// This defines a bit array with three segments of a single bit each
<<0:1, 1:1, 0:1>>

// This defines a bit array with three segments of 8 bits each
<<0, 1, 0>>
```

Especificar el tipo como `:1` es una forma abreviada de escribir `:size(1)`. Tienes que usar la sintaxis más larga si el tamaño en bits proviene de una variable.

```gleam
let segment_size = 1
<<0:size(segment_size), 1:size(segment_size), 0:size(segment_size)>>
```

## Binario

Al escribir literales de enteros binarios, podemos escribirlos directamente en notación de base 2 anteponiendo `0b` al literal. Ten en cuenta que se mostrarán como números decimales cuando se impriman en las pruebas o en tu programa.

```gleam
<<0b1011:4>> == <<11:4>>
// -> True
```

## Truncamiento

Si el valor del segmento desborda la capacidad del tipo del segmento, se truncará por la izquierda.

```gleam
<<0b1011:3>> == <<0b0011:3>>
// -> True
```

## Anteponer y añadir

Puedes tanto anteponer como añadir a un bit array existente usando la sintaxis de bit array. La anotación `:bits` debe usarse para el bit array existente.

```gleam
let value = <<0b110:3, 0b001:3>>
let new_value = <<0b011:3, value:bits, 0b000:3>>
// -> <<120, 8:size(4)>>
```

## Concatenación

Podemos concatenar bit arrays guardados en variables usando la sintaxis. La anotación `:bits` debe usarse al concatenar dos bit arrays de tamaños variables.

```gleam
let first = <<0b110:3>>
let second = <<0b001:3>>
let concatenated = <<first:bits, second:bits>>
// -> <<49:size(6)>>
```

## Coincidencia de patrones

También se puede hacer coincidencia de patrones para obtener valores del bit array. Tienes que saber el número de bits de cada fragmento que quieras capturar, con una excepción: la anotación `:bits` se puede usar para hacer coincidencia de patrones en un bit array de tamaño desconocido, pero solo se puede usar para el último fragmento.

```gleam
let assert <<value:4, rest:bits>> = <<0b01101001:8>>
value == 0b0110
// -> true
```

## Inspeccionar bit arrays

~~~~exercism/note
Es posible que los bit arrays se impriman en un formato distinto del que se usó para crearlos. Esto suele causar confusión al aprender bit arrays.
~~~~

De forma predeterminada, los bit arrays se muestran en fragmentos de 8 bits (un byte), aunque los hayas creado con fragmentos de otro tamaño.

```gleam
<<2011:11>>
// -> <<251, 3:size(3)>>
```

Si creas un bit array que representa un string imprimible codificado en UTF-8, es posible que funciones como `io.debug` lo muestren como un string. Esto se debe a un detalle de implementación de cómo Gleam representa los strings internamente.

```gleam
<<>>
// -> ""

<<65, 66, 67>>
// -> "ABC"
```
