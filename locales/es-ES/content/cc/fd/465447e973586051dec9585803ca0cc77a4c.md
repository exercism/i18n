# Apéndice de instrucciones

## Palabras

Define una tupla `game` y un constructor `<game> ( -- game )` que devuelve una partida nueva sin tiradas.

Proporciona estas palabras que operan sobre una partida:

- `roll ( pins game -- )`: registra que se han derribado `pins` bolos. Lanza un error cuando la tirada no es válida:
  - `"Negative roll is invalid"` para un número negativo de bolos.
  - `"Cannot roll after game is over"` una vez que se hayan jugado las diez entradas (y las posibles bolas de relleno).
  - `"Pin count exceeds pins on the lane"` cuando se derriban más bolos de los que hay en pie en la pista.
- `score ( game -- n )`: la puntuación total de la partida. Lanza `"Score cannot be taken until the end of the game"` cuando la partida aún no ha terminado.

Ten en cuenta que `roll` oculta la palabra de barajado `roll` del vocabulario `kernel`. El conjunto de pruebas lo desambigua con `FROM: bowling => roll ;`.
