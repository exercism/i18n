# Instrucciones

Ese coche teledirigido que compraste hace poco se ha convertido en toda una afición. Has estado organizando carreras de coches teledirigidos.

Estabas a punto de terminar de escribir un programa que permitiera ejecutar simulaciones de carreras cuando tu gato saltó sobre el teclado y borró unas cuantas líneas de código. Ahora tu programa ya no compila...

## 1. Corrige el error de compilación `Race.__struct__/0 is undefined`

Añade un alias para que se pueda hacer referencia al módulo `NeedForSpeed.Race` con el nombre más corto `Race`.

## 2. Corrige el error de compilación `Car.__struct__/0 is undefined`

Añade un alias para que se pueda hacer referencia al módulo `NeedForSpeed.RemoteControlCar` con el nombre más corto `Car`.

## 3. Corrige el error de compilación `undefined function puts/1`

La función `puts/1` proviene del módulo `IO`. Impórtala para poder usarla sin hacer referencia al módulo.

## 4. Corrige el error de compilación `undefined function default_color/0`

Las funciones `default_color/0`, `red/0`, `cyan/0` y `green/0` provienen todas del módulo `IO.ANSI`. Tienes pensado añadir compatibilidad con otros colores de coche, así que quieres importar el módulo entero. Por desgracia, la función `color/1` del módulo `IO.ANSI` entra en conflicto con una de tus funciones locales. Importa todo el módulo `IO.ANSI` excepto esa función.
