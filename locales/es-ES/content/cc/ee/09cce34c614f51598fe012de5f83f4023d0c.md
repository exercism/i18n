# Instrucciones

Elena es la nueva responsable de calidad de una fábrica de periódicos. Como acaba de llegar a la empresa, ha decidido revisar algunos de los procesos de la fábrica para ver qué se puede mejorar.
Ha descubierto que los técnicos hacen un montón de controles de calidad a mano.
Ve una buena oportunidad para la automatización y te pide a ti, desarrollador freelance, que desarrolles un programa para monitorizar algunas de las máquinas.

## 1. Monitoriza el nivel de humedad de la sala

Tu primera misión es escribir un programa para monitorizar el nivel de humedad de la sala de producción. Ya hay un sensor conectado al software de la empresa que devuelve periódicamente el porcentaje de humedad de la sala.

Debes implementar una función en el software que lance un error si el porcentaje de humedad es demasiado alto.
La función debe llamarse `checkHumidityLevel` y recibir el porcentaje de humedad como parámetro.

Debes lanzar un error (el mensaje no es importante) si el porcentaje supera el 70 %.

```javascript
checkHumidityLevel(60);
// => undefined
```

```javascript
checkHumidityLevel(100);
// Throws an error
```

## 2. Detecta el sobrecalentamiento

Elena está muy contenta con tu primera tarea y te pide que te encargues de monitorizar la temperatura de las máquinas.
Mientras charlas con un técnico, Greg, este te cuenta que, si la temperatura de una máquina supera los 500 °C, los técnicos empiezan a preocuparse por el sobrecalentamiento.

La máquina está equipada con un sensor que mide su temperatura interna.
Debes saber que el sensor es muy sensible y a menudo se rompe.
En ese caso, los técnicos tendrán que cambiarlo.

Tu trabajo consiste en implementar una función `reportOverheating` que reciba la temperatura como parámetro y lance un error si el sensor está roto o si la máquina empieza a sobrecalentarse.
Como más adelante tendrás que reaccionar de forma distinta según el error, necesitas un mecanismo para diferenciar los dos tipos de errores.
Podrías basarte en los mensajes de error, pero eso haría tu código frágil, ya que se rompería si se actualiza el mensaje.
Así que, para poder hacerlo correctamente, lanzarás instancias de distintas clases de error.

- Si el sensor está roto, la temperatura será `null`.
  En ese caso, debes lanzar un `ArgumentError`.
- Cuando todo funciona, si la temperatura supera los 500 °C, debes lanzar un `OverheatingError`.
  Esta clase de error se instanciará con un argumento de temperatura.
  Asegúrate de que el `OverheatingError` que lances tenga una propiedad temperature adjunta.

```javascript
reportOverheating(null);
// Throws an ArgumentError
```

```javascript
reportOverheating(800);
// Throws an OverheatingError
```

## 3. Monitoriza la máquina

Ahora que tu máquina puede detectar errores, implementarás una función que reaccione a esos errores de distintas formas:

- Si el sensor está roto, tienes que avisar a un técnico
- Si la temperatura es demasiado alta, apagarás la máquina si la temperatura supera los 600 °C o encenderás una luz de advertencia si es inferior a esa cifra.
- Si ocurre otro error, lo volverás a lanzar.

Implementa una función `monitorTheMachine` que reciba un argumento `actions`.

`actions` es un objeto que tiene 4 propiedades:

| propiedad           | descripción                                                                         |
| ------------------ | ----------------------------------------------------------------------------------- |
| `check`            | una _*función*_. Comprueba la temperatura de la máquina. Puede lanzar varios errores. |
| `alertDeadSensor`  | una _*función*_. Avisa a un técnico de que el sensor de temperatura está averiado.          |
| `alertOverheating` | una _*función*_. Encenderá una luz de advertencia en la máquina.                        |
| `shutdown`         | una _*función*_. Apagará la máquina.                                          |

La función `monitorTheMachine(actions)` debe llamar internamente a `check()`.
Si eso no lanza ningún error, la función no debe devolver nada.
Si eso, al hacer `throw`, lanza un error, se espera un comportamiento distinto:

| excepción          | comportamiento esperado                   |
| ------------------ | ------------------------------------ |
| `ArgumentError`    | llama a la función `alertDeadSensor`. |
| `OverheatingError` | ejecuta el protocolo de sobrecalentamiento.    |
| _(cualquier otra cosa)_  | vuelve a lanzar el error                    |

**Protocolo de sobrecalentamiento**
Si la temperatura es inferior a 600 °C, enciende la luz de advertencia llamando a la función `alertOverheating`.
Si la temperatura supera los 600 °C, la situación es crítica, así que llama a la función `shutdown`.

```javascript
monitorTheMachine({
  check,
  alertDeadSensor,
  alertOverheating,
  shutdown,
});
```
