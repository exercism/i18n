# Instrucciones

En este ejercicio vas a trabajar con cuentas de ahorros.
Cada año, el saldo de tu cuenta de ahorros se actualiza según su tipo de interés.
El tipo de interés que te da tu banco depende de la cantidad de dinero que haya en tu cuenta (su saldo):

- 3,213 % para un saldo negativo (el saldo se vuelve más negativo).
- 0,5 % para un saldo positivo inferior a `1000` dólares.
- 1,621 % para un saldo positivo mayor o igual que `1000` dólares e inferior a `5000` dólares.
- 2,475 % para un saldo positivo mayor o igual que `5000` dólares.

Tienes cuatro tareas, y cada una de ellas trabajará con tu saldo y su tipo de interés.

## 1. Calcula el tipo de interés

Implementa el método `SavingsAccount.interest_rate()`, que recibe un saldo como argumento.
El método debe devolver el tipo de interés para el saldo dado.

```Crystal
SavingsAccount.interest_rate(200.75)
# => 0.5
```

## 2. Calcula los intereses

Implementa el método `SavingsAccount.interest()`, que recibe un saldo como argumento.
El método debe devolver los intereses para el saldo dado.

```Crystal
SavingsAccount.interest(200.75)
# => 1.00375
```

## 3. Calcula la actualización anual del saldo

Implementa el método `SavingsAccount.annual_balance_update()`, que recibe un saldo como argumento.
El método debe devolver el saldo después de un año.

```Crystal
SavingsAccount.annual_balance_update(200.75)
# => 201.75375
```

## 4. Calcula los años que faltan para alcanzar el saldo deseado

Implementa el método `SavingsAccount.years_before_desired_balance()`, que recibe un saldo y un saldo objetivo como argumentos.
El método debe devolver el número de años que se tardaría en alcanzar el saldo objetivo.

```Crystal
balance = 200.75
target_balance = 214.88
SavingsAccount.years_before_desired_balance(balance, target_balance)
# => 14
```

~~~~exercism/note
Cuando se aplica interés simple a un saldo principal, el saldo se multiplica por el tipo de interés y el producto de ambos es el importe de los intereses.

El interés compuesto, por otro lado, se calcula aplicando los intereses de forma recurrente.
En cada aplicación se calcula el importe de los intereses y se suma al saldo principal, de modo que los cálculos de intereses posteriores se hacen sobre un saldo principal mayor.
~~~~
