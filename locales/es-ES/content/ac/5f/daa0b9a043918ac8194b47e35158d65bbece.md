# Pistas

## General

- `H{ } clone` es la forma correcta de empezar una tabla hash nueva y mutable: los literales `H{ }` se pueden compartir entre llamadas.
- `inc-at` de [`assocs`][assocs] suma 1 al valor de una clave (o la inserta con valor 1 si no existe).

## 1. Construye un inventario a partir de una lista

- Empieza con `H{ } clone` y `inc-at` para cada elemento. Una quotation de fry como `'[ _ inc-at ]` captura la tabla hash para que puedas pasarla a través de `each`.
- Envuelve la iteración en `[ … ] keep` para que la tabla hash sea el valor que queda en la pila.

## 2. Añade más elementos

- La forma es la misma que en la tarea 1, salvo que partes de un `clone` del inventario de entrada en lugar de uno vacío.

## 3. Decrementa los recuentos

- Usa `key?` primero; solo se tocan los elementos que ya están en el inventario.
- `change-at` acepta una quotation `( old -- new )`; combínala con `[ 1 - 0 max ]` (con `max` de [`math.order`][math.order]) para que el recuento nunca sea negativo.

## 4. Elimina un elemento por completo

- `delete-at` modifica la tabla hash y no devuelve nada: haz primero `clone`, luego `delete-at` y deja el clon en la pila.

## 5. Enumera los elementos disponibles

- `>alist` convierte la tabla hash en una secuencia de pares.
- `[ second 0 > ] filter` conserva solo los elementos con existencias.
- `sort-keys` (de [`sorting`][sorting]) ordena un alist por clave.

[math.order]: https://docs.factorcode.org/content/vocab-math.order.html
