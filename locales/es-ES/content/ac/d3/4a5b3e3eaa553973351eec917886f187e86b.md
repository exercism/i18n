# Instrucciones

En este ejercicio vas a procesar líneas de registro.

Cada línea de registro es un string con el siguiente formato: `"[<LVL>]: <MESSAGE>"`.

Estos son los distintos niveles de registro:

- `TRC` (trace)
- `DBG` (debug)
- `INF` (info)
- `WRN` (warning)
- `ERR` (error)
- `FTL` (fatal)

Tienes tres tareas, y debes completar cada una de ellas para proporcionar la funcionalidad necesaria.

## 1. Crea la enumeración LogLevel

Define una enumeración `LogLevel` que tenga seis casos correspondientes a los niveles de registro anteriores, más un caso desconocido para niveles ausentes o no estándar.

- `trace`
- `debug`
- `info`
- `warning`
- `error`
- `fatal`
- `unknown`

## 2. Analiza el nivel de registro

A continuación, implementa el inicializador de `LogLevel` para analizar el nivel de registro de una línea de registro:

```swift
LogLevel("[INF]: File deleted")
// Returns LogLevel.info
LogLevel("Something went wrong!")
// Returns LogLevel.unknown
```

## 3. Convierte la línea de registro al formato corto

El nivel de registro de una línea de registro es bastante verboso.
Para reducir el espacio en disco necesario para almacenar las líneas de registro, se ha desarrollado un formato corto: `"<ENCODED_LEVEL>:<MESSAGE>"`.

El nivel de registro codificado es una simple asignación de un nivel de registro a un número:

- `trace` - `0`
- `debug` - `1`
- `info` - `4`
- `warning` - `5`
- `error` - `6`
- `fatal` - `7`
- `unknown` - `42`

Implementa el método `shortFormat(message: String) -> String` que devuelve la línea de registro en formato corto como un `String`:

```swift
let overflow = LogLevel.error
overflow.shortFormat(message: "Stack overflow")
// Returns "6:Stack overflow"
```
