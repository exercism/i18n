# Pistas

## General

- Lee sobre los [structs][getting-started-structs] en la guía de introducción.
- Lee sobre [`defstruct`][docs-defstruct] en la documentación.
- Mira [Elixir Casts - #106: Intro to Structs][elixir-casts].

## 1. Crea un coche teledirigido nuevo

- El atributo de módulo `@enforce_keys` puede usarse para especificar los valores obligatorios. Tiene que definirse antes de llamar a `defstruct`.
- El campo `nickname` no debe tener un valor por defecto especificado.
- La función `new/0` debe inicializar el `nickname` con el valor `"none"`.

## 2. Crea un coche teledirigido nuevo con un apodo

- Usa [`multiple-function-clauses`][multiple-fn-clauses] para reutilizar el nombre de la función pero aceptar argumentos distintos.
- Considera usar un [`default-argument`][default-arg] para la función.

## 3. Muestra la distancia

- En las funciones que solo aceptan un tipo concreto de struct, asegúrate de hacer una coincidencia de patrones para comprobar el argumento.
- Usa el _operador de acceso estático_ para obtener los valores de los campos.

## 4. Muestra el porcentaje de batería

- En las funciones que solo aceptan un tipo concreto de struct, asegúrate de hacer una coincidencia de patrones para comprobar el argumento.
- Usa el _operador de acceso estático_ para obtener los valores de los campos.

## 5. Conducir cambia la batería y la distancia recorrida

- En las funciones que solo aceptan un tipo concreto de struct, asegúrate de hacer una coincidencia de patrones para comprobar el argumento.
- Usa el _operador de acceso estático_ para obtener los valores de los campos.
- Repasa la introducción sobre cómo actualizar los structs.

## 6. Ten en cuenta conducir con la batería agotada

- Si la batería está agotada, debe devolver el struct sin cambios.
