# Resolver ejercicios

La forma principal en que Exercism te ayuda a aprender es resolviendo ejercicios.

Hay dos maneras de resolver ejercicios en Exercism:

1. [En línea, con el editor del navegador de la web](/docs/using/solving-exercises/using-the-online-editor)
2. [En tu máquina local, con la CLI](/docs/using/solving-exercises/working-locally)

## ¿Qué opción debería elegir?

Usar el editor en línea o la CLI tiene sus ventajas e inconvenientes:

|            | Editor en línea                        | CLI                                          |
| ---------- | -------------------------------------- | -------------------------------------------- |
| Instalación | No                                     | Sí (p. ej., SDK)                             |
| Edición    | Navegador                              | Tu editor preferido                          |
| Tests      | Ejecutar los tests en la web           | Ejecutar los tests en local                  |
| Depuración | Soporte limitado (solo en algunos tracks) | Soporte completo (según tu entorno)       |

En general, el editor en línea es ideal para empezar tracks nuevos, mientras que el enfoque basado en la CLI es perfecto si quieres usar tu propio entorno de programación personalizado.
