# Pistas

## General

- Vuelve al [concepto de objetos][concept-objects] si lo necesitas para refrescar lo básico.

## 1. Define Size para almacenar las dimensiones de la ventana

- Recuerda usar la [sintaxis de prototipos][mdn-prototype] para esta tarea.
- Empieza definiendo una función con el nombre `Size` y asegúrate de [exportarla][mdn-export].
- Los argumentos que se pasan a la función constructora deben añadirse al objeto `this`.
- Puedes aplicar valores predeterminados haciendo uso de los [parámetros predeterminados][mdn-default-params].
- Puedes añadir un método a través de la propiedad `prototype` de la función constructora.

## 2. Define Position para almacenar la posición de una ventana

- Recuerda usar la [sintaxis de prototipos][mdn-prototype] para esta tarea.
- Empieza definiendo una función con el nombre `Position` y asegúrate de [exportarla][mdn-export].
- Los argumentos que se pasan a la función constructora deben añadirse al objeto `this`.
- Puedes aplicar valores predeterminados haciendo uso de los [parámetros predeterminados][mdn-default-params].
- Puedes añadir un método a través de la propiedad `prototype` de la función constructora.

## 3. Define una clase ProgramWindow

- Recuerda usar la [sintaxis de clases][mdn-class] para esta tarea.
- Asegúrate de [exportar][mdn-export] la clase.
- Define campos añadiéndolos al objeto `this`.
- Haz uso de las clases que definiste en las tareas anteriores.
- Comprueba que tu función constructora no acepte ningún argumento.

## 4. Añade un método para redimensionar la ventana

- Recuerda usar la [sintaxis de clases][mdn-class] para esta tarea.
  Eso significa que añades la definición del método directamente en el cuerpo de la clase.
- Para encontrar los valores correctos para el redimensionado, piensa primero en la anchura que quieres alcanzar, teniendo en cuenta el límite inferior (`1`).
- Después, calcula la anchura máxima permitida considerando el tamaño de la pantalla y la posición `x` actual de la ventana.
- Con esos dos valores, puedes decidir qué aplicar y usar una lógica análoga para la altura.
- Haz uso del método `resize` del objeto `Size` para aplicar el cambio.

## 5. Añade un método para mover la ventana

- Recuerda usar la [sintaxis de clases][mdn-class] para esta tarea.
  Eso significa que añades la definición del método directamente en el cuerpo de la clase.
- Para encontrar los valores correctos para el movimiento, piensa primero en la posición `x` a la que quieres llegar, teniendo en cuenta el límite inferior (`0`).
- Después, calcula el valor máximo permitido de `x`.
  Ten en cuenta el tamaño de la pantalla y la anchura actual de la ventana.
- Con esos dos valores, puedes decidir qué aplicar y usar una lógica análoga para la altura.
- Haz uso del método `move` del objeto `Position` para aplicar el cambio.

## 6. Modifica la ventana de un programa

- Primero, define una función `changeWindow` y asegúrate de [exportarla][mdn-export].
- Crea una instancia de la clase `Size` usando la palabra clave `new` y proporciona las dimensiones que quieras como argumentos. (Lo mismo para el objeto de posición que necesites).
- Usa los métodos definidos en las tareas 4 y 5. Por ejemplo, llamas a un método `a` de un objeto `obj` con `obj.a()`.
- Asegúrate de devolver la instancia de `Window` que recibes como entrada.
