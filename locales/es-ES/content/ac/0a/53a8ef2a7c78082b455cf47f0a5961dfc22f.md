# Generadores

Un `generator` es una función o expresión que devuelve un tipo especial de [iterador][iterator] llamado [`generator iterator`][generator-iterator].
Los `Generator-iterator` son [perezosos][lazy iterator]: no almacenan sus `values` en memoria, sino que _generan_ sus valores cuando se necesitan.

Una función generadora es como cualquier otra función, pero contiene una o más [expresiones yield][yield expression].
Cada `yield` suspende la ejecución del código y guarda el estado de ejecución actual (_incluidas todas las variables locales y las instrucciones try_).
Cuando el generador se reanuda, retoma el estado desde la suspensión, a diferencia de las funciones normales, que se reinician en cada llamada.


## Cómo construir un generador

Los generadores se construyen de forma muy similar a otras funciones con bucles o recursivas, pero requieren una [expresión `yield`](#the-yield-expression), que exploraremos en profundidad un poco más adelante.

Un ejemplo es una función que devuelve los _cuadrados_ de un array de números dado.
Tal como está escrita, hay que procesar toda la entrada antes de poder devolver algún valor:

```python
>>> def squares(list_of_numbers):
...     squares = []
...     for number in list_of_numbers:
...         squares.append(number ** 2)
...     return squares
```

Puedes convertir esa función en un generador así:

```python
>>> def squares_generator(list_of_numbers):
...     for number in list_of_numbers:
...         yield number ** 2
```

La razón es que usas un generador cuando no necesitas producir todos los valores _a la vez_.
Esto ahorra memoria y potencia de procesamiento, ya que solo se calcula el valor en el que estás _trabajando en ese momento_.


## Cómo usar un generador

Los generadores pueden usarse en lugar de la mayoría de los `iterables` de Python.
Esto incluye _funciones_ u _objetos_ que requieren un `iterable`/`iterator` como argumento.

Para usar el generador `squares_generator()`:

```python
>>> squared_numbers = squares_generator([1, 2, 3, 4])

>>> for square in squared_numbers:
...     print(square)
...
1
4
9
16
```

Los valores dentro de un `generator` también pueden producirse o consultarse mediante la función `next()`.
`next()` llama al método `__next__()` de un objeto generador-iterador, «avanzando» o evaluando el código hasta su expresión `yield`, que entonces «cede» o devuelve un valor:

```python
>>> squared_numbers = squares_generator([1, 2])

>>> next(squared_numbers)
1
>>> next(squared_numbers)
4
```

Cuando un `generator-iterator` se consume por completo y no le quedan valores que devolver, lanza un error `StopIteration`.

```python
>>> next(squared_numbers)
Traceback (most recent call last):
  File "<stdin>", line 1, in <module>
StopIteration
```


~~~~exercism/note

Los generadores-iteradores son un subconjunto especial de los [iteradores][iterator].
Los `Iterators` son el mecanismo o protocolo que permite iterar sobre _iterables_.
Los generadores-iteradores y los iteradores que devuelven los [`iterables`][iterables] habituales de Python funcionan de forma muy similar, pero hay algunas diferencias importantes que conviene tener en cuenta:

- Se _[evalúan de forma perezosa][lazy evaluation]_; la iteración es _unidireccional_ y no se puede «retroceder» a un valor anterior.
- Se _consumen_ al iterar sobre los valores devueltos; no se reinician ni se guardan en memoria.
- No se pueden ordenar ni invertir.
- No son tipos de secuencia y _no_ tienen `indexes`. 
  No puedes referenciar un valor anterior o futuro mediante sumas o restas, ni usar la notación de corchetes (`[]`) ni el slicing.
- No se pueden usar con la función `len()`, ya que no tienen longitud.
- Pueden ser _finitos_ o _infinitos_: ¡ten cuidado al recopilar todos los valores de un `generator-iterator` _infinito_!

## La expresión yield

La [expresión yield][yield expression] es muy similar a la expresión `return`.
_A diferencia_ de la expresión `return`, `yield` cede valores a quien lo llama en un _punto concreto_, suspendiendo la evaluación o la devolución de cualquier valor adicional hasta que se soliciten.
Cuando se evalúa `yield`, se pausa la ejecución de la función que lo contiene y se devuelven los valores de la función _en ese momento_.
La función entonces _permanece en el scope_, y cuando se llama a `__next__()`, la ejecución se reanuda hasta que se encuentra `yield` de nuevo.


~~~~exercism/note
El uso de expresiones `yield` está prohibido fuera de las funciones.
~~~~

```python
>>> def infinite_sequence():
...     current_number = 0
...     while True:
...         yield current_number
...         current_number += 1

>>> lets_try = infinite_sequence()
>>> lets_try.__next__()
0
>>> lets_try.__next__()
1
```


## ¿Por qué crear un generador?

Los generadores son útiles en muchas aplicaciones.

Cuando trabajas con una colección de valores potencialmente grande, puede que no quieras cargarlos todos en memoria.
Puedes usar un generador para trabajar con datos más grandes pieza a pieza, ahorrando memoria y mejorando el rendimiento.

Los generadores también resultan muy útiles cuando un proceso o cálculo es _complejo_, _costoso_ o _infinito_:

```python
>>> def infinite_sequence():
...     current_number = 0
...     while True:
...         yield current_number
...         current_number += 1
```

Ahora, siempre que se llame a `__next__()` en el objeto `infinite_sequence`, devolverá el _número anterior_ + 1.
