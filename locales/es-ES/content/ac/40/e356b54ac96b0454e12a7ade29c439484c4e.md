# Instrucciones

Tu amigo acaba de enviarte un mensaje con un secreto importante.
Como no quería que a otros les resultara fácil leerlo, el mensaje se ha cifrado mediante una serie de manipulaciones de bits.
Tendrás que escribir un programa que te ayude a descifrar el mensaje.

## 1. Desplaza los bits de vuelta

El primer paso para descifrar el mensaje consiste en deshacer el desplazamiento del proceso de cifrado desplazando los bits de nuevo hacia la izquierda.
El número de posiciones que hay que desplazar puede variar de un mensaje a otro.

Implementa el método `Secrets.shift_back`, que recibe un valor y el número de posiciones que hay que desplazar a la izquierda.

```crystal
Secrets.shift_back(0b0001, 2)
# => 0b0100
```

## 2. Aplica una máscara de bits

El siguiente paso es aplicar una máscara de bits para extraer el valor de determinados bits.
La máscara se aplica realizando una operación AND bit a bit entre el valor y la máscara.

Implementa el método `Secrets.apply_mask`, que recibe un valor y le aplica una máscara.

```crystal
Secrets.apply_mask(0b0110, 0b0101)
# => 0b0100
```

## 3. Establece algunos bits

Al desplazar bits a la izquierda se han añadido nuevos bits con valor 0.
Algunos de estos nuevos bits deben establecerse a 1.
El OR bit a bit resulta útil para establecer ciertos bits a 1 y conservar el resto.

Implementa el método `Secrets.set_bits`, que recibe dos valores y realiza una operación OR bit a bit.

```crystal
Secrets.set_bits(0b0110, 0b0101)
# => 0b111
```

## 4. Deshacer el XOR

Parte del proceso de cifrado aplica un XOR con un valor acordado.
Para recuperar el valor original, basta con volver a aplicar el XOR al valor cifrado junto con el valor acordado.
Sin embargo, debido a un malentendido, tu amigo invirtió los bits del valor acordado (es decir, aplicó un NOT bit a bit al valor acordado) antes de aplicar el XOR.

Implementa el método `Secrets.reverse_xor`, que recibe los valores cifrado y acordado y calcula el valor original.

```crystal
Secrets.reverse_xor(0b1100, 0b0101)
# => 0b(0110)
```
