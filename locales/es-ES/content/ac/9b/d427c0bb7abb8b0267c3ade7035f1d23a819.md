Elixir tiene convenciones de nomenclatura específicas, que incluyen cómo nombrar las [funciones que devuelven Boolean](https://hexdocs.pm/elixir/naming-conventions.html#trailing-question-mark-foo) y las [comprobaciones que devuelven Boolean y son válidas en cláusulas de guarda](https://hexdocs.pm/elixir/naming-conventions.html#is_-prefix-is_foo):

> Las funciones que devuelven un Boolean se nombran con un signo de interrogación al final.

> Las comprobaciones de tipos y otras comprobaciones Boolean que se permiten en las cláusulas de guarda se nombran con el prefijo `is_`.

Las macros pueden usarse en ambos contextos, así que la notación depende del caso, pero las dos convenciones de nomenclatura no deben mezclarse.

```elixir
# this is the expected name of macros that return booleans

%{option1}

# this is the expected name of macros that return booleans and are valid in guard clauses

%{option2}

# this is the current name

%{actual}
```
