# Pistas

## General

- [Ruby para principiantes: la nada y la verdad][rfb-nothingness-and-truth]

## 1. Comprobar si un visitante tiene un pase para las atracciones

- Convierte pass_id en un objeto booleano.
- Fíjate en la clase [`BasicObject`][basicobject-class]; contiene métodos que heredan la mayoría de las clases.

## 2. Comprobar si un visitante tiene la altura suficiente para una atracción

- Compara la altura mínima de la atracción con la altura del visitante.
- Fíjate en el módulo [`Comparable`][comparable-module]; contiene métodos para comparar objetos que se pueden usar cuando se incluyen.
  - La clase [Integer][integer-class] incluye el módulo [`Comparable`][comparable-module].

## 3. Comprobar si un visitante puede subir a una atracción

- Combina los métodos de instancia que has creado usando un [operador booleano][pr-boolean-operator] para devolver el resultado.
