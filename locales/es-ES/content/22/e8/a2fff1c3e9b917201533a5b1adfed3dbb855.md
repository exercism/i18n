# ficticio

## Instrucciones específicas de MoonScript

Este es un ejercicio de orientación a objetos: vas a implementar ComplexNumbers como una clase.

Los tests compararán dos instancias de números complejos para ver si son iguales.
Esto significa que tu clase tendrá que implementar el [metamétodo][metamethods] `__eq`.

Los tests también realizan operaciones aritméticas con números complejos, así que hay metamétodos aritméticos que implementar.

~~~~exercism/caution
Algunas de las funciones de números complejos harán cálculos con números de coma flotante.
Tu «igualdad» tendrá que lidiar con que los números sean _aproximadamente iguales_.
~~~~

[metamethods]: https://www.lua.org/manual/5.4/manual.html#2.4
