# Introducción

En Python, un `str` es una [secuencia inmutable][text sequence] de [puntos de código Unicode][unicode code points].
Entre ellos puede haber letras, signos diacríticos, caracteres de posicionamiento, números, símbolos de moneda, emojis, signos de puntuación, espacios y caracteres de salto de línea, y mucho más.

Los strings implementan todas las [operaciones comunes de secuencia][common sequence operations] y se pueden recorrer con la sintaxis `for item in <string>` o `for index, item in enumerate(<string>)`.

Los strings se pueden concatenar con `<str> + <other str>` o `<str>.join(<iterable>)` y dividir con `<str>.split(<separator>)`.
También ofrecen muchas otras opciones de formato, de ensamblado y de plantillas.

Como es inmutable, el valor de un objeto `str` en memoria no cambia; los métodos que parecen modificar un string devuelven una copia nueva o una instancia nueva de `str`.

Para profundizar en qué información codifica un string (o, _«¿cómo sabe un ordenador traducir ceros y unos a letras?»_), [esta entrada de blog sigue siendo de gran ayuda][joel-on-text].
La documentación de Python también ofrece una [unicode HOWTO][unicode how-to] muy detallada, que trata el soporte de Python para la especificación Unicode en los módulos `str`, `bytes` y `re`, las consideraciones sobre las configuraciones regionales y algunos problemas comunes de codificación y traducción.
