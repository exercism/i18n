# Pistas

## General

- Todas las direcciones de memoria de este ejercicio están alineadas a 16 bytes, así que las variantes de movimiento alineadas (`movaps` para números de coma flotante, `movdqa` para enteros) son las adecuadas.
  La memoria alineada también se puede usar directamente como operando fuente (pero no como destino).
- Las máscaras se pueden definir en memoria.

## 1. Rectificar la traza

- El signo de un número de coma flotante de 32 bits es su bit más alto.
  Poner a cero el bit más alto hace que el número no sea negativo.
- Es posible poner a cero el bit más alto aplicando un AND con un número de 32 bits en el que todos los bits están establecidos excepto el más alto.
- Una máscara se puede definir en memoria con 4 números de 32 bits empaquetados.
- La instrucción `andps` aplica AND a valores de coma flotante.

## 2. Leer la escala de un temblor

- El campo del exponente de un número de coma flotante IEEE-754 de 32 bits está en los bits de las posiciones 23 a 30, ambas incluidas.
- Los bits del exponente se pueden aislar aplicando un AND (`andps` o `pand`) a los números de coma flotante con una máscara en la que solo estén establecidos los bits 23 a 30.
- Una vez aislados los bits del exponente, se pueden desplazar a la parte baja de cada carril con un desplazamiento lógico a la derecha (`psrld`).
- El sesgo de un número de coma flotante IEEE-754 de 32 bits es 127.
  Se puede eliminar restando 127 a cada carril (`psubd`).

## 3. Reducir la resolución

- Un desplazamiento aritmético a la derecha (`psrad`) de `n` unidades divide entre `2^n` a la vez que conserva el signo y redondea hacia menos infinito.
- Las instrucciones de desplazamiento empaquetado toman su cuenta de un valor inmediato o de un registro `xmm`, no de un registro de propósito general (GPR).
- Se puede usar la instrucción `movq` para mover 64 bits en crudo de un GPR a un registro `xmm`.

## 4. Condicionar los canales

- Se puede usar `por` para combinar todos los bits establecidos en cualquiera de los dos operandos.
- `pandn` calcula ((NOT destino) AND fuente) en una sola instrucción.
  Se puede usar para poner a cero todos los bits de la fuente que están establecidos en el destino.

## 5. Alternar los bits de calibración

- Para invertir solo los bits desbloqueados, primero hay que poner a cero todos los bits bloqueados en el toggle.
- `pandn` calcula ((NOT destino) AND fuente) en una sola instrucción.
  Se puede usar para poner a cero todos los bits de la fuente que están establecidos en el destino.
- Se puede usar `pxor` para invertir los bits seleccionados por el toggle restante en cada palabra de estado.

## 6. Amplificar la traza

- El campo del exponente de un número de coma flotante IEEE-754 de 32 bits está en los bits de las posiciones 23 a 30, ambas incluidas.
  Para llevar la ganancia `k` a la posición correcta, hay que desplazarla a la izquierda.
- Sumar las ganancias desplazadas a los bits en crudo de las lecturas (`paddd`) tiene el efecto de multiplicar la lectura por `2^k`.
  El patrón de bits sigue siendo válido porque se garantiza que las entradas y los resultados son normales.
