# Acerca de

Un fichero es un flujo con un nombre en el disco. El vocabulario [`io.files`][io.files] ofrece dos maneras de trabajar con uno: palabras de conveniencia para ficheros completos, que leen o escriben todo en una sola llamada, y abridores de flujo (los combinadores `with-…`) para leer o escribir de forma incremental. Ambos se apoyan en el mismo [protocolo de flujo][stream-protocol] que los flujos en memoria del concepto `io-streams`: un `<file-reader>` y un `<string-reader>` responden a las mismas palabras.

Todas las palabras de fichero reciben una **codificación**, el esquema que asigna bytes a caracteres y viceversa. Para texto, casi siempre es [`utf8`][utf8] de `io.encodings.utf8`; el trabajo binario usa `latin1` o una codificación `<byte-array>`.

## Lectura de ficheros completos

```
file-contents   ( path encoding -- str )
file-lines      ( path encoding -- seq )
```

`file-contents` devuelve el fichero entero como un solo string. `file-lines` devuelve sus líneas como un array, con los terminadores de línea eliminados. Resulta práctico cuando cada línea es un registro.

```factor
USING: io.encodings.utf8 io.files ;

"forecast.txt" utf8 file-contents   ! => "sunny\ncloudy\n"
"forecast.txt" utf8 file-lines      ! => { "sunny" "cloudy" }
```

## Escritura de ficheros completos

```
set-file-contents   ( str path encoding -- )
set-file-lines      ( seq path encoding -- )
```

Ambas **reemplazan** el fichero, creándolo si no existe. `set-file-contents` escribe un string tal cual; `set-file-lines` escribe cada elemento de una secuencia en su propia línea, añadiendo los saltos de línea.

```factor
{ "sunny" "cloudy" } "forecast.txt" utf8 set-file-lines
! forecast.txt now holds "sunny\ncloudy\n"
```

## Flujos con scope

Cuando quieras añadir contenido a un fichero, o leer y escribir pieza a pieza, ábrelo con un combinador `with-…` y usa dentro de la cita las palabras de flujo ambientales:

```
with-file-reader     ( path encoding quot -- )
with-file-writer     ( path encoding quot -- )
with-file-appender   ( path encoding quot -- )
```

```factor
USING: io io.encodings.utf8 io.files ;

"log.txt" utf8 [ "another line" print ] with-file-appender
```

`with-file-writer` trunca el fichero primero; `with-file-appender` conserva el contenido existente y escribe a continuación. Cada uno es un scope de destructor: el manejador de fichero se cierra cuando termina la cita, incluso si lanza una excepción. Es la misma garantía que ofrecen los combinadores de `boatswains-bilge`, aquí especializada para ficheros.

## ¿Fichero completo o con scope?

Recurre a `file-contents` / `file-lines` / `set-file-contents` / `set-file-lines` cuando el fichero sea lo bastante pequeño para caber en memoria y quieras todo de una vez. Recurre a los abridores `with-…` cuando necesites añadir contenido, recorrer por flujo un fichero grande línea a línea con `readln` o intercalar lecturas y escrituras; en definitiva, siempre que mantener el fichero entero en memoria resulte derrochador o incorrecto.
