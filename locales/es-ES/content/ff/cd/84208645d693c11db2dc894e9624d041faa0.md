# Acerca de

Un `Map` se usa para almacenar pares de **clave** y **valor**. Los `Maps` se inicializan igual que un array, pero usan el operador de literal de mapa `=>`. También pueden tener sus tipos de clave-valor definidos explícitamente, o los tipos se pueden inferir. Las claves deben ser únicas; de lo contrario, se lanza un error.

```haxe
var map1:Map<Int, String> = [1 => "one", 2 => "two", 3 => "three"];

var map2 = ["one" => 1, "two" => 2, "three" => 3];

var map3 = [1 => "cat", 1 => "dog"]; // Error: Duplicate Key

var map4 = ["h" => "Hello", "b" => "Bye"];
trace(map4["h"]); // Hello
```

Se puede iterar un `Map` con un bucle `for`. Puedes iterar sobre los valores o sobre las claves:

```haxe
for (value in map) {
  // ...
}

for (key in map.keys()) {
  // ...
}
```

Internamente, un `Map` es un tipo abstracto. En tiempo de compilación, se convierte en uno de varios tipos especializados según el tipo de clave:

- `String`: `haxe.ds.StringMap`
- `Int`: `haxe.ds.IntMap`
- `EnumValue`: `haxe.ds.EnumValueMap`
- `{}`: `haxe.ds.ObjectMap`

El tipo `Map` no existe en tiempo de ejecución y se ha sustituido por uno de los objetos anteriores.
