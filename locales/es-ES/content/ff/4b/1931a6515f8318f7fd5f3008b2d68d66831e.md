# Instrucciones

Como aficionado al ajedrez, te gustaría escribir tu propia versión del juego.
Sí, puede que ya haya muchas implementaciones de ajedrez disponibles en línea, ¡pero la tuya será única!

Empiezas implementando un sistema básico de movimiento para las piezas.

La partida de ajedrez se jugará en un tablero de 8 casillas de ancho y 8 de largo.
Las casillas se identifican con una letra y un número.

## 1. Define el rango de filas y columnas

El juego tendrá que almacenar las filas del tablero.
Las filas son las líneas horizontales del tablero, y se numeran del 1 al 8.

El juego también tendrá que almacenar las columnas del tablero.
Las columnas son las líneas verticales del tablero y se identifican con las letras de la A a la H.

Define las constantes `Chess::RANKS` y `Chess::FILES` que almacenan el rango de filas y columnas respectivamente.

```ruby
Chess::RANKS
# => 1..8

Chess::FILES
# => 'A'..'H'
```

## 2. Comprueba si la casilla es válida

El juego tendrá que comprobar si una casilla es válida.
Una casilla es válida si la fila y la columna están dentro de los rangos de las filas y las columnas.

Define el método `Chess.valid_square?` que recibe los argumentos `rank`, que contiene un número entero de la fila, y `file`, que contiene un carácter de la columna.
El método debe devolver `true` si la fila y la columna están dentro de los rangos de las filas y las columnas, y devolver `false` en caso contrario.

```ruby
Chess.valid_square?(1, 'A')
# => true
```

## 3. Obtén el apodo del jugador

El juego tendrá que obtener el apodo del jugador.
El apodo son los 2 primeros caracteres del nombre del jugador y los 2 últimos caracteres del apellido del jugador.
El apodo debe ir en mayúsculas.

Define el método `Chess.nickname` que recibe los argumentos `first_name`, que contiene un string con el nombre del jugador, y `last_name`, que contiene un string con el apellido del jugador.
El método debe devolver el apodo del jugador como un string en mayúsculas.

```ruby
Chess.nickname("John", "Doe")
# => "JOOE"
```

## 4. Crea el mensaje de movimiento

El juego tendrá que crear un mensaje para un movimiento que indique qué jugador se movió a qué casilla.
El mensaje debe usar el apodo del jugador y la casilla a la que se movió.
El juego también tiene que determinar si el movimiento es válido comprobando si la columna y la fila de la casilla están dentro de los rangos de las columnas y las filas.

Si el movimiento es válido, el mensaje debe ser: `"{nickname} moved to {square}"`
Si el movimiento no es válido, el mensaje debe ser: `"{nickname} attempted to move to {square}, but that is not a valid square"`

Define el método `Chess.move_message` que recibe los argumentos `first_name`, que contiene un string con el nombre del jugador, `last_name`, que contiene un string con el apellido del jugador, y `square`, que contiene un string con la casilla a la que se movió el jugador.
El método debe devolver el mensaje del movimiento como un string.

```ruby
Chess.move_message("John", "Doe", "A1")
# => "JOOE moved to A1"
```
