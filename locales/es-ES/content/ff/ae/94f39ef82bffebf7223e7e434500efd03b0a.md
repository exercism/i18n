# Acerca de

Los [bucles repeat-while][repeat-loops] son similares a los bucles `while`, pero con una diferencia clave: la comprobación de la condición ocurre *después* de que se ejecute el cuerpo del bucle, no antes.
Como resultado, un bucle `repeat-while` garantiza que su bloque de código se ejecute al menos una vez.

```swift
repeat {
    print("This runs at least once")
} while false

print("Loop done")

// Prints:
// This runs at least once
// Loop done
```

[repeat-loops]: https://docs.swift.org/swift-book/LanguageGuide/ControlFlow.html#ID126
