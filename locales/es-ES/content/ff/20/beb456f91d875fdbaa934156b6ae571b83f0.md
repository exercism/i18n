# Introducción

## Instrucciones switch

Al igual que una instrucción condicional _if/else_, una instrucción `switch` te permite cambiar el flujo del programa ejecutando código de forma condicional.
La diferencia es que una instrucción `switch` solo puede comparar el valor de una expresión primitiva o de tipo string con valores constantes predefinidos.

Algunas palabras clave resultan útiles cuando usas una instrucción switch.

- `switch`: esta palabra clave te permite declarar la estructura del switch.
  Va seguida de la expresión o la variable que cambiará el resultado.
- `case`: usarás esta palabra clave para declarar las distintas posibilidades del resultado.
- `break`: la palabra clave `break` es muy útil para detener la ejecución del switch al final del flujo deseado.
  Si la olvidas, el programa continuará y puede dar lugar a resultados inesperados.
- `default`: como su nombre indica, úsala como resultado predeterminado cuando ningún otro caso coincida con el resultado de tu expresión.

En su forma más simple, comprueban el valor de una expresión primitiva o de tipo string y toman una decisión basada en él.
Por ejemplo:

```java
String direction = getDirection();
switch (direction) {
    case "left":
        goLeft();
        break;
    case "right":
        goRight();
        break;
    default:
        // otherwise
        markTime();
        break;
}
```
