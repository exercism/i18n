# Pistas

## 1. Crear una nueva tabla de puntuaciones máximas

- Se pueden usar las funciones [`dict.new`][new] y [`dict.from_list`][from_list] para crear un dict nuevo.

## 2. Añadir jugadores a una tabla de puntuaciones

- Se puede usar la función [`dict.insert`][insert] para añadir un nuevo par clave-valor a un dict.

## 3. Eliminar jugadores de una tabla de puntuaciones

- Se puede usar la función [`dict.delete`][delete] para eliminar un par clave-valor de un dict.

## 4. Aumentar la puntuación de un jugador

- Se puede usar la función [`dict.get`][get] para obtener el valor de una clave en un dict.
- Se puede usar la función [`dict.insert`][insert] para sobrescribir un par clave-valor existente en un dict.

## 5. Aplicar los puntos de bonificación del lunes

- Se puede usar la función [`dict.map_values`][map_values] para modificar todos los valores de un dict.
