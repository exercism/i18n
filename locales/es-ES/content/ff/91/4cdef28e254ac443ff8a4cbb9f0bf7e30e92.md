# Aprendizaje

* [The Rust Programming Language](https://doc.rust-lang.org/book/) es un recurso excelente para empezar con Rust y también para profundizar en funcionalidades concretas del lenguaje.
* [Rust by Example](https://doc.rust-lang.org/stable/rust-by-example/) te muestra ejemplos de las cosas más habituales que escribirás en Rust.
* [Into_rust()](http://intorust.com/) «Screencasts para aprender Rust.»
* [Rustlings](https://github.com/carols10cents/rustlings) «Pequeños ejercicios para que te acostumbres a leer y escribir código Rust.»
* El [Rust User Forum](http://users.rust-lang.org) responde a preguntas de todos los niveles.
