# Fundamentos

Un programa de Sather se compone de **clases** que contienen **rutinas**.

```sather
class GREETER is

   hello : STR is
      return "Hello!";
   end;

end; -- class GREETER
```

## Clases

El nombre de una clase se escribe en mayúsculas, con guiones bajos entre las palabras:
`GREETER`, `STAGE_DIRECTIONS`. Normalmente, el nombre del fichero coincide, en
minúsculas: `stage_directions.sa`.

Todas las rutinas viven dentro de una clase. No hay código fuera de una.

## Rutinas

Una rutina que produce una respuesta declara el tipo de respuesta después de dos puntos:

```sather
   hello : STR is
      return "Hello!";
   end;
```

`STR` es el tipo para el texto. Una rutina que no recibe argumentos se escribe y se
llama sin paréntesis.

Una rutina puede recibir argumentos, escritos entre paréntesis después del nombre:

```sather
   louder(word : STR) : STR is
      return word;
   end;
```

`return` devuelve una respuesta y detiene la rutina de inmediato, así que las líneas
que van debajo se omiten.

## Llamadas

Desde fuera de la clase, escribe el nombre de la clase, luego `::` y, a continuación,
la rutina:

```sather
GREETER::hello
```

Desde dentro de la misma clase, se puede omitir el nombre de la clase. Esta es la
forma habitual de que una rutina use otra:

```sather
   greeting_again : STR is
      return hello;
   end;
```

## Comentarios

Dos guiones inician un comentario que llega hasta el final de la línea.

```sather
   -- Explain why, not what: the code already says what.
   hello : STR is
      return "Hello!";   -- a trailing comment is fine too
   end;
```

Por convención, una clase termina con un comentario que la nombra. Las rutinas, los
bucles y las clases se cierran todas con `end;`, así que el comentario indica a cuál
pertenece este `end;`:

```sather
end; -- class GREETER
```

## Puntos y coma

Las instrucciones terminan con un punto y coma. El punto y coma después de la última
instrucción de una rutina es opcional, pero escribirlo siempre es una cosa menos en la
que pensar.
