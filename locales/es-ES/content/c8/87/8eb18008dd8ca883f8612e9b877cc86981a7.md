# Desempaquetado y asignación múltiple

El desempaquetado se refiere al acto de extraer los elementos de una colección, como un `list`, `tuple` o `dict`, mediante iteración.
Los valores desempaquetados se pueden asignar después a variables dentro de la misma instrucción.
Un ejemplo muy común de este comportamiento es `for item in list`, donde `item` adopta el valor de cada elemento de `list` a lo largo de la iteración.

La [asignación múltiple][multiple assignment] es la capacidad de asignar varias variables a valores desempaquetados dentro de una misma instrucción.
Esto permite que el código sea más conciso y legible, y se consigue separando con una coma las variables que se van a asignar, como en `first, second, third = (1,2,3)` o `for index, item in enumerate(iterable)`.

Los operadores especiales `*` y `**` se usan a menudo en contextos de desempaquetado.
`*` se puede usar para combinar varios `list`s/`tuple`s en un único `list`/`tuple` _desempaquetando_ cada uno en un nuevo `list`/`tuple` común.
`**` se puede usar para combinar varios diccionarios en un único diccionario _desempaquetando_ cada uno en un nuevo `dict` común.

Cuando el operador `*` se usa sin una colección, _empaqueta_ una serie de valores en un `list`.
Esto se usa a menudo en la asignación múltiple para agrupar en una sola variable todos los elementos «sobrantes» que no tienen una asignación individual.

En Python también es habitual aprovechar este comportamiento de desempaquetado y empaquetado al usar o definir funciones que aceptan un número arbitrario de argumentos posicionales o de palabra clave.
A menudo verás estos parámetros «especiales» definidos como `def some_function(*args, **kwargs)` y estos argumentos «especiales» usados como `some_function(*some_tuple, **some_dict)`.

`*<variable_name>` y `**<variable_name>` no deben confundirse con `*` y `**`. Mientras que `*` y `**` se usan para la multiplicación y la exponenciación respectivamente, `*<variable_name>` y `**<variable_name>` se usan como operadores de empaquetado y desempaquetado.
