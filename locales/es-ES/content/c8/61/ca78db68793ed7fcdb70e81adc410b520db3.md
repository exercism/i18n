# Acerca de

Uno de los aspectos clave de trabajar con números en F# es la distinción entre los números enteros (números sin dígitos después del separador decimal) y los números de coma flotante (números con cero o más dígitos después del separador decimal).

Los dos tipos numéricos más usados en F# son `int` (un entero de 32 bits) y `float` (un número de coma flotante de 64 bits).

```fsharp
let i = 123   // Type is `int`
let d = 54.29 // Type is `float`
```

Tanto los números enteros como los de coma flotante pueden usar el carácter `_` como _separador de dígitos_, lo cual puede ayudar a la hora de definir números grandes:

```fsharp
let largeInt = 1_000_000
// => 1000000

let largeFloat = 9_876_543.21
// => 9876543.21
```

La aritmética se realiza con los [operadores aritméticos][arithmetic-operators] estándar (`+`, `-`, `*`, etc.). Los números se pueden comparar con los [operadores de comparación][comparison-operators] estándar (`<`, `>=`, etc.) y con los operadores de igualdad (`=`) y desigualdad (`<>`).

```fsharp
5 * 6
// => 30

1.2 > 0.8
// => true

2 <> 4
// => true
```

Para convertir entre tipos numéricos, hay que usar el [operador de conversión][conversion-operators] integrado. Estos operadores reciben el nombre del tipo al que van a convertir.

```fsharp
let floatFromInt = float 2
let intFromFloat = int 3.39
```

Al convertir entre tipos, ten siempre cuidado. Si el tipo de destino no puede representar un valor, se producirá un _desbordamiento_.
