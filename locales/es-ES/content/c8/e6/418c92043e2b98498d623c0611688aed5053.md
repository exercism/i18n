# Pistas

## 1. Extraer errores

- Se pueden hacer coincidir los errores con patrones usando la sintaxis de patrón `Error(value)`.

## 2. Eliminar el prefijo del equipo

- Los prefijos de string se pueden hacer coincidir con patrones usando la sintaxis de patrón `"prefix" <> rest`.

## 3. Dividir región y equipo

- Los strings se pueden dividir por un carácter usando la [función `string.split`][split].
- Los arrays se pueden hacer coincidir con patrones usando la sintaxis de patrón `[a, b, c]`.

[split]: https://hexdocs.pm/gleam_stdlib/gleam/string.html#split
