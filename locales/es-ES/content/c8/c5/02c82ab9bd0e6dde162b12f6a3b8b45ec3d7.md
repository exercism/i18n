# If, elseif y else

Las instrucciones condicionales con `if`, `elseif` y `else` son una parte fundamental del flujo de control de un programa.
La instrucción `if` evalúa una expresión y, si es `true`, ejecuta la rama de código.

```php
<?php

if ($expression) {
    // .. executed if $expression is true
}
```

Si la expresión no es un valor booleano, la evaluación determina la «veracidad» o la «no falsedad» del valor.
En PHP, los siguientes valores se consideran iguales a false:

- el valor booleano `false`
- el número entero `0`
- el número decimal `0.0` y `-0.0`
- un array vacío `[]`
- un string vacío `""` o un string numérico `"0"`
- `null`

Todos los demás valores se consideran true.

## Responder a varias condiciones

Después de una instrucción `if`, puedes encadenar varias condiciones con `elseif` y `else`.

```php
<?php

if ($value === 0) {
    // .. do something
} elseif ($value === 1) {
    // .. do something else
} else {
    // ,, do this if nothing else
}
```

Solo se ejecutará una instrucción condicional que se evalúe como true.
Así que, si varias condiciones pueden evaluarse como true, el orden en que están escritas es importante.

```php
<?php

if (true) {
    // .. always do something
} elseif (true)
    // .. will never be executed
} else {
    // .. will never be executed
}
```
