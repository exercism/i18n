# Instrucciones

Tu amiga Li Mei tiene un bar de zumos donde vende deliciosos zumos de frutas. Eres un cliente habitual de su tienda y te has dado cuenta de que podrías hacerle la vida un poco más fácil con algo de código Factor.

## 1. Averigua cuánto se tarda en preparar un zumo

A Li Mei le gusta decir a sus clientes de antemano cuánto tienen que esperar por un zumo del menú. Le cuesta recordar las cifras exactas porque el tiempo que se tarda en preparar los zumos varía:

- `"Pure Strawberry Joy"` tarda `0.5` minutos.
- `"Energizer"` y `"Green Garden"` tardan `1.5` minutos cada uno.
- `"Tropical Island"` tarda `3` minutos.
- `"All or Nothing"` tarda `5` minutos.
- Todas las demás bebidas (p. ej., ofertas especiales) tardan `2.5` minutos.

Define `time-to-mix-juice` para que tome de la pila el nombre de un zumo y devuelva el número de minutos que se tarda en preparar esa bebida.

```factor
"Tropical Island" time-to-mix-juice .
! => 3

"Berries & Lime" time-to-mix-juice .
! => 2.5
```

## 2. Repón las reservas de gajos de lima

Muchas de las creaciones de Li Mei incluyen gajos de lima, ya sea como ingrediente o como parte de la decoración. Así que cuando empieza su turno por la mañana tiene que asegurarse de que el recipiente de gajos de lima esté lleno para el resto del día.

Define `wedges-from-lime` para que tome el tamaño de una lima y devuelva el número de gajos que produce: `6` de una lima `"small"`, `8` de una `"medium"` y `10` de una `"large"`.

Luego define `limes-to-cut` para que tome el número de gajos `needed` y un array de `limes` (tamaños de lima en el orden de corte). Corta las limas una a una, en orden, y se detiene en cuanto tiene suficientes gajos o se queda sin limas. Devuelve el número de limas que ha tenido que cortar.

```factor
25 { "small" "small" "large" "medium" "small" } limes-to-cut .
! => 4
```

## 3. Enumera los tiempos para preparar cada pedido de la cola

A Li Mei le gusta llevar un registro del tiempo que se tardará en preparar los pedidos por los que esperan los clientes.

Define `order-times` para que tome un array de pedidos y devuelva un array con el tiempo para preparar cada pedido, en el mismo orden.

```factor
{ "Energizer" "Tropical Island" } order-times .
! => { 1.5 3 }
```

## 4. Termina el turno

Li Mei siempre trabaja hasta las 3 de la tarde. Luego, su empleado Dmitry toma el relevo. A menudo hay bebidas que se han pedido pero aún no se han preparado cuando termina el turno de Li Mei; entonces Dmitry prepara los zumos restantes.

Para facilitar el relevo, define `remaining-orders` para que tome el número de minutos `time-left` del turno de Li Mei y un array de `orders` (zumos que se han pedido pero aún no se han preparado). Devuelve los pedidos de los que Dmitry tendrá que hacerse cargo, es decir, aquellos que Li Mei no tiene tiempo de empezar antes de que termine su turno.

`time-left` siempre es mayor que `0`. Los pedidos se preparan en el orden en que aparecen en el array. Una vez que Li Mei empieza un zumo, siempre lo termina, aunque tenga que trabajar un poco más. Si tiene tiempo de empezar todos los pedidos, devuelve un array vacío.

```factor
5 { "Energizer" "All or Nothing" "Green Garden" } remaining-orders .
! => { "Green Garden" }
```
