# Acerca de

El operador condicional ternario se usa para escribir una expresión compacta que devuelve uno de dos valores alternativos en función de una condición.
A menudo se le llama el «operador ternario».
El nombre proviene de que el operador tiene tres operandos: `predicate ? consequent-expression : alternative-expression`
Se puede usar como sustituto de condicionales if-else cortos.

Al igual que con los condicionales `if`, JavaScript realiza una conversión de tipo implícita para evaluar la condición.
Si la condición se evalúa como verdadera, se devolverá el operando que está a la izquierda de los dos puntos.
En caso contrario, el resultado de la expresión ternaria es el operando que está a la derecha de los dos puntos.

```javascript
const year = 2020;

year > 2000 ? 'in the past years' : 'a long time ago';
// => 'in the past years'
```
