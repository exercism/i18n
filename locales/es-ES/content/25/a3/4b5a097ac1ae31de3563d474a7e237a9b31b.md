## Ejecutar los tests

1. Ve a la raíz del directorio de tu ejercicio de PHP, que es `<EXERCISM_WORKSPACE>/php`.
   Para encontrar el espacio de trabajo de Exercism, ejecuta

   ```shell
   exercism workspace
   ```

2. Instala [PHPUnit] si aún no lo tienes.
3. Ejecuta los tests con:

   ```shell
   phpunit test_file.php
   ```

   Por ejemplo, para ejecutar los tests del ejercicio Hello World, ejecutarías:

   ```shell
   phpunit HelloWorldTest.php
   ```

[PHPUnit]: https://exercism.org/docs/tracks/php/installation#h-via-php-archive-phar
