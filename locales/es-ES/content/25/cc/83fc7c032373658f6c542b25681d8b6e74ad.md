# Anexo a las instrucciones

## Literales de fecha de nacimiento con `from_quote`

La función `DateOfBirth.from_quote` analiza un string con el formato `"YYYY-MM-DD"` y lo convierte en un `DateOfBirth`. Esto permite escribir código como el siguiente:

```roc
birthdate : DateOfBirth
birthdate = "2019-01-20"
```

Este código llama implícitamente a `DateOfBirth.from_quote("2019-01-20")` en tiempo de compilación. Ejecutar código en tiempo de compilación con este enfoque (u otros métodos que se describen a continuación) puede acelerar el programa, ya que no necesita gestionar el análisis ni la validación de datos en tiempo de ejecución. Además, garantiza que los datos no válidos (como un formato de fecha incorrecto) se rechacen en tiempo de compilación en lugar de en tiempo de ejecución, lo que hace que tu aplicación sea más robusta. Por último, hace que el código sea agradable y legible. Por ejemplo, aquí tienes una de las pruebas de este ejercicio:

```roc
# multiple birthdates with one shared birthday
expect {
	shared_birthday(["1966-07-29", "1977-02-12", "2001-07-29", "1980-11-10"])
}
```

Sin embargo, quien lea este código podría suponer que la función `shared_birthday` recibe una `List(Str)`, cuando en realidad recibe una `List(DateOfBirth)`. Esto puede dar lugar a confusión y errores. Por este motivo, puede que prefieras el formato algo más largo pero más explícito: `"2019-01-20".DateOfBirth`, que también llama a `from_quote` en tiempo de compilación.

En tus propios programas, puede que prefieras proporcionar un constructor cómodo, como este:

```roc
DateOfBirth := { year : I64, month : U8, day : U8 }.{
    from_ymd : I64, U8, U8 -> Try(DateOfBirth, [InvalidMonth, InvalidDay])
    from_ymd = |year, month, day| ...
}
```

También puedes llamar a este constructor en tiempo de compilación, así:

```roc
Ok(birthdate) = DateOfBirth.from_ymd(2019, 1, 20)
```

Nota: colocar esta definición en el nivel superior hace que se ejecute en tiempo de compilación (dado que la función es pura y las entradas se conocen en tiempo de compilación). Dentro de una función, puedes usar el mismo constructor en tiempo de ejecución.
