# Instrucciones

Cuando los alienígenas de Lisp llegaron por primera vez a la Tierra, se encontraron con incontables cosas raras y maravillosas, pero uno de sus descubrimientos favoritos fue el de las «mascotas». Seamos sinceros, ¿a qué clase de alienígena no se le derretiría el corazón con un cachorro o un gatito?

Tras sus recientes vacaciones en la Tierra, ¡Ludwig ha decidido que quiere una mascota propia! ¿El único problema? ¡Demasiadas opciones! ¿Quizá podrías escribir un programa que ayude a Ludwig a encontrar y cuidar a su próximo amigo peludo?

## 1. Elegir a un amigo

Aunque Ludwig tiene claro que quiere una mascota, hasta ahí llega su planificación. El primer paso, entonces, es decidir qué tipo de mascota quiere.

Ludwig quiere encontrar a un amigo con una personalidad que complemente la suya. ¿Podrías escribirle a Ludwig una función llamada `pal-picker` que reciba un rasgo de personalidad (una palabra clave) y devuelva el tipo de mascota (un string) con ese rasgo?

En este caso concreto:

- `:lazy` -> `"Cat"`
- `:energetic` -> `"Dog"`
- `:quiet` -> `"Fish"`
- `:hungry` -> `"Rabbit"`
- `:talkative` -> `"Bird"`

Para otras personalidades desconocidas, tu función debe dar como resultado: `"I don't know... A dragon?"`

```lisp
(pal-picker :quiet) ; => "Fish"
```

## 2. En su hábitat natural

Ahora que Ludwig tiene un nuevo amigo, ¡necesitará un sitio donde vivir! ¿Puedes ayudar a Ludwig a elegir la cama, el tanque o la jaula del tamaño adecuado para su mascota?

Aquí, Ludwig necesita una función llamada `habitat-fitter` que seleccione el tamaño de hábitat adecuado (una palabra clave) a partir del peso de su mascota en kilogramos (un número entero).

Los hábitats que necesita cada mascota según su tamaño son:

- 40 kg o más -> `:massive`
- De 20 kg a 39 kg, ambos incluidos -> `:large`
- De 10 kg a 19 kg, ambos incluidos -> `:medium`
- De 1 kg a 9 kg, ambos incluidos -> `:small`
- 0 kg o menos -> `:just-your-imagination`

```lisp
(habitat-fitter 42) ; => :MASSIVE
```

## 3. Y ahora, ¡a comer!

Todos los animales de compañía terrícolas tienen algo en común: ¡la necesidad de comer! Sin embargo, este concepto le resulta un tanto ajeno a Ludwig, ya que tiende a olvidarse de rellenar el cuenco de comida de su mascota.

A Ludwig le vendría bien una función sencilla llamada `feeding-time` que le avise cuando haya que rellenar el cuenco. La función recibiría un porcentaje de llenado (un número entero) y devolvería un mensaje en forma de string.

Si el nivel de comida es:

- Por encima del 20 % -> `"All is well."`
- Un 20 % o menos -> `"It's feeding time!"`

```lisp
(feeding-time 15) ; => "It's feeding time!"
```

## 4. Un código de conducta

Con lo básico resuelto, Ludwig tiene muchas ganas de probar varias cosas emocionantes, como «acariciar» y jugar a «traer la pelota». Dicho esto, no todas las mascotas sirven para estas actividades.

A Ludwig le gustaría tener un par de funciones, `pet` y `play-fetch`, que reciban el tipo de mascota (como string) y devuelvan o bien nada, o bien un mensaje como `"Maybe not with this pet..."` si la acción no es adecuada.

Supón que solo los `"Dog"` juegan a traer la pelota y que se puede acariciar a todas las mascotas excepto a los `"Fish"`.

```lisp
(pet "Dog")         ; => NIL
(play-fetch "Fish") ; => "Maybe not with this pet..."
```
