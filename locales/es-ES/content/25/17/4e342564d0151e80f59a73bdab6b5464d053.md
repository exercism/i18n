# Introducción a la manipulación de bits

Java tiene operadores para manipular los bits de un `byte`, `short`, `int`, `long` o `char`.

## Operadores de desplazamiento

Usa `<<` para desplazar bits a la izquierda y `>>` para desplazarlos a la derecha.

```java
// Shift two places to the left
0b0000_1011 << 2;
// # => 0b0010_1100

// Shift two places to the right
0b0000_1011 >> 2;
// # => 0b0000_0010
```

El operador `<<` siempre inserta 0s en el lado derecho.
Sin embargo, `>>` inserta el mismo bit que el bit más a la izquierda (1 si el número es negativo o 0 si es positivo).

```java
// Shift 2 places to the right preserves the sign
// This is a negative value, whose binary representation is
// 1000_0000_0000_0000_0000_0000_0010_0110
int value = -0x7FFFFFDA;

// Shift two places to the right, preserving the sign bit
value >> 2;
// # => 1110_0000_0000_0000_0000_0000_0000_1001
```

Usa `>>>` en su lugar cuando haya que insertar 0s al desplazar a la derecha.

```java
// Shift two places to the right, inserting 0s on the left
value >>> 2;
// # => 0010_0000_0000_0000_0000_0000_0000_1001
```

## Operaciones bit a bit

### AND bit a bit

El operador AND bit a bit (`&`) toma dos valores y realiza una operación AND sobre cada bit.
Compara cada bit del primer valor con el bit que ocupa la misma posición en el segundo valor.
Si ambos son 1, el bit del resultado es 1.
En caso contrario, el bit del resultado es 0.

```java
0b0110_0101 & 0b0011_1100;
// # => 0b0010_0100
```

### OR bit a bit

El operador OR bit a bit (`|`) toma dos valores y realiza una operación OR sobre cada bit.
Compara cada bit del primer valor con el bit que ocupa la misma posición en el segundo valor.
Si cualquiera de los dos bits es 1, el bit del resultado es 1.
En caso contrario, es 0.

```java
0b0110_0101 | 0b0011_1100;
// # => 0b0111_1101
```

### XOR bit a bit

El operador XOR bit a bit (`^`) realiza una operación XOR bit a bit sobre dos valores.
Al igual que los operadores AND y OR bit a bit, compara cada bit del primer valor con el bit que ocupa la misma posición en el segundo valor.
Si solo uno de ellos es 1, el bit resultante es 1.
En caso contrario, es 0.

```java
0b0110_0101 ^ 0b0011_1100;
// # => 0b0101_1001
```

### NOT bit a bit (`~`)

Por último, el operador NOT bit a bit (`~`) invierte cada bit.
A diferencia de los operadores anteriores, este es un operador unario y actúa sobre un solo valor.

```java
~0b0110_0101;
// # => 0b1001_1010
```
