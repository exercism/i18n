# Ejecutar las pruebas

Para compilar y ejecutar las pruebas, solo tienes que ejecutar lo siguiente en el directorio del ejercicio:
```bash
$ ponyc
$ ./exercise-name
```

(Sustituye `exercise-name` por el nombre del directorio del ejercicio)

El binario compilado ejecuta las pruebas en su actor `Main`, así que basta con ejecutar el binario y comprobar si tus pruebas pasan. Pony comprueba todo el código en tiempo de compilación, por lo que es posible que tus pruebas no compilen hasta que escribas el código necesario. Puedes comentar las pruebas que no compilen empezando cada línea con `//`. Después, cuando te pongas con esa prueba, puedes descomentarla.
