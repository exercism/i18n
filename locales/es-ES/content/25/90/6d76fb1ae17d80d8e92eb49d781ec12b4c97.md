# Pistas

## General

- La entrada de `delivery_date()` son dos argumentos de tipo `String`, y la salida es un `String`.
- Todas las fechas se expresan como string en formato [ISO 8601][iso], la representación de string predeterminada de Julia.
- La documentación útil sobre el módulo `Dates` incluye:
  - El [Learning Track][dates-times] de Exercism.
  - El [manual de Julia][Dates].
  - El [Wikilibro][Wikibook].
- Como mínimo, tendrás que familiarizarte con los constructores de [DateTime][datetime] y con sumar o restar [Periods][period].
- Entre las funciones útiles están [`dayofweek()`][dayofweek] y, de forma opcional, [`lastdayofmonth()`][lastdayofmonth] o [`lastdayofquarter()`][lastdayofquarter].
- Para extraer números enteros de un string, la función [`parse()`][parse] será importante.
- Las funciones [`tonext()`][tonext] y [`toprev()`][toprev] podrían ser útiles en un enfoque que incluya funciones de orden superior.
