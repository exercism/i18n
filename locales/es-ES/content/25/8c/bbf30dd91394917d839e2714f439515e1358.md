# Pruebas

## Ejecutar las pruebas

Desde el directorio del ejercicio, ejecuta `exercism test` o `eutest`.
Euphoria ejecutará entonces `t_<exercise>.e` para probar tu solución.

## Leer la salida

Al empezar un ejercicio, tu archivo de solución no tiene ningún valor devuelto y fallará al ejecutarlo.

```shell
C:\path\to\leap.ex:3
<0120>:: no value returned from function
end function
           ^

FAILURE: t_leap.e EUPHORIA error with status 1

Test results summary:
    FAIL: t_leap.e
Files (run: 1) (failed: 1) (0% success)
```

Esto es lo esperado.
Implementa la función y vuelve a ejecutar para ver qué pruebas pasan y cuáles fallan.

```shell
interpreting t_leap.e:
  passed: year not divisible by 4 in common year
  failed: year divisible by 2, not divisible by 4 in common year, expected: FALSE but got: TRUE
  failed: year divisible by 4, not divisible by 100 in leap year, expected: TRUE but got: FALSE
  ...

FAILURE: t_leap.e program died with status 1

Test results summary:
    FAIL: t_leap.e
Files (run: 1) (failed: 1) (0% success)
```

## Trabajar las pruebas de forma incremental

Una buena forma de empezar es comentar todas las pruebas excepto la primera en `t_<exercise>.e`.

```euphoria
test_false("year not divisible by 4 in common year", leap(1800))
-- test_false("year divisible by 100 but not by 3 is still not a leap year", leap(1900))
-- test_false("year divisible by 2, not divisible by 4 in common year", leap(1970))
```

Trabájalas de una en una, descomentando la siguiente prueba cuando pase la actual.
Cuando todas las pruebas pasen, habrás completado el ejercicio.
