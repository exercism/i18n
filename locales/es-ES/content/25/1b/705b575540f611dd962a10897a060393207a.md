# Acerca de

Una [tupla](https://docs.microsoft.com/en-us/dotnet/fsharp/language-reference/tuples) es una agrupación _inmutable_ de valores sin nombre pero ordenados.
Las tuplas pueden contener cualquier tipo de dato (o varios), incluidas otras tuplas.

Las tuplas se definen como valores separados por comas entre los caracteres `(` y `)`: `(<element_1>, ... , <element_n>)`.

```fsharp
("one", 2) // Tuple pair (2 values)
("one", 2, true) // Tuple triplet (3 values)
```

Solo se pueden comparar las tuplas que tienen la misma longitud y los mismos tipos (en el mismo orden).
Las tuplas tienen igualdad estructural, lo que significa que son iguales _solo_ si todos sus valores son iguales.

```fsharp
(1, 2) = (1, 2) // Same length, same types, same values, same order
// => true

(1, 2) = (2, 1) // Same length, same types, same values, different order
// => false

(1, 2) = (1, "2") // Same length, different types
// compiler error

(1, 2) = (1, 2, 3) // Different length
// compiler error
```

Hay [tres formas de extraer valores de una tupla](https://docs.microsoft.com/en-us/dotnet/fsharp/language-reference/tuples#obtaining-individual-values):

- Las funciones `fst` y `snd`
- La deconstrucción de tuplas
- La coincidencia de patrones

```fsharp
let person = ("Jordan", 170)

// Option 1: fst/snd
let name1 = fst person
let length1 = snd person

// Option 2: deconstruction
let (name2, length2) = person

// Option 3: pattern matching
match person with
| name3, length3 -> printf "%s: %d" name3 length3
```

~~~~exercism/note
Técnicamente, puedes acceder al valor de una tupla usando sus propiedades `.Item1`, `.Item2`, ..., pero no se recomienda y da lugar a una advertencia del compilador.
~~~~

## Aspectos clave de las tuplas

Estas son algunas cosas clave que conviene saber sobre las tuplas:

- Una instancia concreta de un tipo de tupla es un único objeto, similar, por ejemplo, a un array de dos elementos en C#. Cuando se usan con funciones, cuentan como un único parámetro. La única excepción es cuando se llama a código que no es F# con varios parámetros, en cuyo caso se pasa una tupla y sus valores se extraen automáticamente al valor del parámetro correspondiente.
- Los tipos de tupla no pueden recibir nombres explícitos. El «nombre» del tipo de tupla viene determinado por la combinación de tipos que se multiplican entre sí.
- La coma es el símbolo fundamental que define las tuplas, no los paréntesis. Puedes definir tuplas sin los paréntesis, aunque a veces puede resultar confuso. En F#, si ves una coma, probablemente forme parte de una tupla.
- Las tuplas pueden usarse como argumentos de una función y como valor devuelto de una función.
