# Instrucciones

Llevas un recuento diario de cuántos pájaros visitan tu jardín. Los datos se guardan en un array de números enteros, con **el recuento de hoy en primer lugar**.

## 1. El recuento de hoy

Define `today` para que tome un array de recuentos diarios de la pila y devuelva el recuento de hoy, o `f` si el array está vacío.

```factor
{ 2 5 1 } today .
! => 2

{ } today .
! => f
```

## 2. Incrementa el recuento de hoy

Define `increment-day-count` para que devuelva un nuevo array con el recuento de hoy incrementado en uno. Si la entrada está vacía, devuelve `{ 1 }`.

```factor
{ 4 0 2 } increment-day-count .
! => { 5 0 2 }

{ } increment-day-count .
! => { 1 }
```

## 3. ¿Hubo algún día sin pájaros?

Define `has-day-without-birds?` para que devuelva `t` si al menos un día registró cero pájaros, y `f` en caso contrario.

**Usa recursión** en lugar de `any?` u otras palabras de orden superior para secuencias.

```factor
{ 2 0 4 } has-day-without-birds? .   ! => t
{ 3 8 1 5 } has-day-without-birds? . ! => f
```

## 4. Total de pájaros desde que empezaste

Define `total` para que devuelva la suma de todos los recuentos.

**Usa recursión** en lugar de `sum`.

```factor
{ 4 0 9 0 5 } total .
! => 18
```

## 5. Días ajetreados

Un día ajetreado es aquel con cinco pájaros o más. Define `busy-days` para que devuelva el número de días ajetreados.

**Usa recursión** en lugar de `count`.

```factor
{ 4 5 0 0 6 } busy-days .
! => 2
```
