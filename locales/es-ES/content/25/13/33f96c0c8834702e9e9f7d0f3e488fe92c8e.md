# Instrucciones

En este ejercicio vas a generar informes meteorológicos para una emisora de noticias local.

## Genera informes meteorológicos

Empezarás con algunas funciones sin implementar y el siguiente enum:

```rust
#[derive(Drop, Clone, PartialEq, Debug)]
pub enum WeatherCondition {
    Sunny,
    Rainy,
    Cloudy,
    Stormy
}
```

Tendrás que dar formato a un informe meteorológico como `"Today is <CONDITION> with a temperature of <TEMPERATURE> degrees Celsius."`.
Tendrás que implementar la función que genera las condiciones meteorológicas correctas.

Por ejemplo, el siguiente fragmento muestra una salida esperada para la función `get_weather_report` en un día «lluvioso».

```rust
get_weather_report(WeatherCondition::Rainy, "25")
// Returns: "Today is RAINY with a temperature of 25 degrees Celsius."
```

Y en un día «soleado»:

```rust
get_weather_report(WeatherCondition::Sunny, "30")
// Returns: "Today is SUNNY with a temperature of 30 degrees Celsius."
```
