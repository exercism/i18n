# Tests

## Clojure CLI

Los ejercicios de Clojure en Exercism vienen con un fichero `deps.edn` que incluye un alias `:test` para invocar el [cognitect-labs test-runner](https://github.com/cognitect-labs/test-runner):

``` bash
$ clj -X:test
```

## Leiningen

También puedes ejecutar el test del ejercicio con Leiningen usando el siguiente comando desde el directorio del ejercicio:

```bash
lein test
```

## REPL

Para usar el REPL y ejecutar el test del ejercicio, ejecuta el siguiente comando desde el directorio del ejercicio:

```bash
$ clj
```

-o-

```bash
$ lein repl
```

Después, usa `require` para cargar el espacio de nombres de test del ejercicio y el de test de Clojure):

```clojure
;; replace <exercise> with the exercise's name
=> (require '<exercise>-test)
```

Después, llama a `run-tests` sobre `<exercise>-test`:

```clojure
;; replace <exercise> with the exercise's name
=> (clojure.test/run-tests '<exercise>-test)
```
