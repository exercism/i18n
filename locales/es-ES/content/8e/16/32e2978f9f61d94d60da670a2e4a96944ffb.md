# Paquetes

El track de F# es compatible con los siguientes paquetes:

| Paquete         | Versión |
| --------------- | ------- |
| Aether          | 8.3.1   |
| BenchmarkDotNet | 0.12.1  |
| FParsec         | 1.1.1   |

```exercism/caution
Si tu código usa una combinación de paquetes o versiones no compatibles, las ejecuciones de tests en el sitio web fallarán.
```
