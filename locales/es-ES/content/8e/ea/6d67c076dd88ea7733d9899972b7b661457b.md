# Pistas

## General

- No olvides el `;` después de cada instrucción.
- Puedes definir un número entero con `int myInteger = 44;`.

## 1. Obtén el tiempo de horneado.

- Las instrucciones contienen información sobre el tiempo de la receta.
- Una función puede devolver un valor con la forma `return 2;`

## 2. Obtén el tiempo de preparación.

- Puedes acceder al número de capas usando el parámetro correspondiente.
- Puedes hacer cálculos al definir un número entero: `int myInteger = 3 + myOtherInteger;`

## 3. Calcula el tiempo que queda en el horno

- Puedes llamar a otras funciones y usar el valor devuelto igual que una variable: `return 22 * myOtherCalculation();`

## 4. Calcula el tiempo total dedicado a la lasaña

- El resultado debe combinar el tiempo de preparación con el tiempo que la lasaña lleva ya en el horno.
