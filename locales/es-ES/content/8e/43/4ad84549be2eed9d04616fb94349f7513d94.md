# Pruebas

Para ejecutar las pruebas, ejecuta el comando `bal test --offline` desde el directorio del ejercicio.

## Pruebas omitidas

Al principio, solo estará habilitada la primera prueba.
Esto es para animarte a resolver el ejercicio paso a paso.
Una vez que consigas que la primera prueba pase, elimina la propiedad `enable: false` de la siguiente prueba y trabaja en conseguir que esa prueba pase.
