# Introducción

Haxe es un lenguaje fuertemente tipado, pero su sistema de tipos puede eludirse cuando es necesario. Asignar un valor a un nombre se conoce como definir una variable. Una variable se puede definir especificando explícitamente su tipo o dejando que el compilador de Haxe infiera el tipo. Por lo tanto, las dos definiciones de variable siguientes son equivalentes:

```haxe
var explicitVariable:Int = 10; // Explicitly typed
var implicitVariable = 10; // Implicit typed
```

Una variable se puede actualizar con el operador `=`:

```haxe
var number = 0; // Initial value
number = 1; // Updated value
```

El compilador lanzará un error al intentar asignar un valor cuyo tipo sea distinto del de la variable:

```haxe
var number = 1; // Variable number is of integer type
number = "Hello" // Error trying to assign a string to an integer variable
```

Una función que está dentro de una clase se llama _método_. Los métodos pueden tener cero o más parámetros. Todos los parámetros deben tener un tipo explícito. Al igual que los parámetros, el tipo de retorno de un método no se puede inferir y hay que especificarlo. Los valores se devuelven desde los métodos con la palabra clave `return`:

```haxe
function add(x:Int, y:Int):Int {
  return x + y;
}
```

Un método se invoca especificando su clase y el nombre del método y pasando los argumentos:

```haxe
var sum = add(1, 2) // sum = 3
```

En Haxe, el scope se define entre los caracteres `{` y `}`.

Haxe admite dos tipos de comentarios. Los de una sola línea van precedidos de `//` y los comentarios de varias líneas se insertan entre `/*` y `*/`.
