# Anexo a las instrucciones

## Implementación

Es posible quedarse sin nombres de robots: una vez asignados todos los nombres de robot posibles, se debe devolver un error.

## Prueba adicional

Cuando consigas que `go test` pase, verás que hay una prueba en la suite de pruebas llamada `TestCollisions` que se omite de forma predeterminada, ya que puede tardar mucho tiempo.
Esta prueba crea robots nuevos hasta que ya no se puedan asignar más nombres nuevos al robot.

Para que la prueba se ejecute, elimina esta línea:

```go
t.Skip("skipping test as it can take a long time to run if solution is sub-optimal.")
```

Para que esta prueba pase, tendrás que asegurarte de que el nombre de un robot no se haya usado antes y de que los nombres se puedan asignar de forma eficiente.
