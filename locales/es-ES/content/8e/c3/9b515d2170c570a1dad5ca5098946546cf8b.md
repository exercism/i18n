# Instrucciones adicionales

## Notas de implementación

`Range` debe devolver un array con todas las ternas pitagóricas cuyos lados estén en el rango de `min` a `max`, ambos inclusive.

`Sum` debe devolver un array con todas las ternas pitagóricas en las que la suma `a+b+c` (el perímetro) sea igual a `p`.
Los tres elementos de cada terna devuelta deben estar en orden, `t[0] <= t[1] <= t[2]`, y el array de ternas debe estar en orden lexicográfico.
