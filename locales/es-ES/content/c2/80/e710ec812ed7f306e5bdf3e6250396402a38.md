# Pistas

## 1. Genera un planeta aleatorio

- Esto se parece a un [muestreo][ref-sample] de un vector de entrada.
- Puede haber duplicados, así que muestrea con reemplazamiento.

## 2. Genera un número de registro de nave estelar aleatorio

- La parte numérica es un muestreo de un rango.
- Hay varias formas de construir el string, entre ellas [`sprintf()`][ref-sprintf] y [`str_glue()`][ref-str_glue].

## 3. Genera una flota de naves estelares de forma aleatoria

- La introducción trata el barajado.

## 4. Genera una fecha estelar aleatoria

- Queremos un valor de coma flotante con [distribución uniforme][ref-runif] entre un límite inferior y un límite superior.
- Puedes ignorar los matices sobre si los límites son inclusivos o exclusivos para esta tarea.

[ref-runif]: https://www.rdocumentation.org/packages/stats/versions/3.5.2/topics/Uniform
