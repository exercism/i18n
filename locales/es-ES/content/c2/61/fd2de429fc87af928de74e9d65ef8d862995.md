# Pruebas

Haz que la primera prueba compile, enlace y pase siguiendo las [tres reglas del desarrollo guiado por pruebas][3-tdd-rules].

El makefile incluido se puede usar para crear y ejecutar las pruebas con la tarea `test`.

```console
$ make test
```

Crea solo las funciones que necesites para resolver los errores del compilador y haz que la prueba falle.
Después, escribe solo el código suficiente para que la prueba pase.
Cuando lo hayas hecho, pasa a la siguiente prueba.

A medida que avances por las pruebas, tómate el tiempo de refactorizar tu implementación para que sea más legible y expresiva, y luego pasa a la siguiente prueba.

Intenta usar las utilidades estándar de C99 en lugar de escribir tus propios algoritmos o utilidades de bajo nivel a mano.

## Comprobar si hay fugas de memoria

El makefile incluye además una variante de compilación que comprueba algunos errores comunes relacionados con las fugas de memoria y el acceso fuera de los límites de un array.
Para ejecutar estas comprobaciones, usa lo siguiente en la línea de comandos:

```console
$ make memcheck
```
