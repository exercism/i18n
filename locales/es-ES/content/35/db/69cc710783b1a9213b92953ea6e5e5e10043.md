# No se usa gofmt

Ejecuta `gofmt` en la solución, lo que ayuda a dar formato al código en Go.

El formato del código en Go es muy importante para la comunidad.
La mayoría de los IDE se pueden configurar para que apliquen el formato automáticamente cada vez que guardes. Por ejemplo:

- Visual Studio Code tiene [un gran soporte para Go](https://code.visualstudio.com/docs/languages/go)
- Vim también tiene una [fantástica extensión para Go](https://github.com/fatih/vim-go)
- [Jetbrains Goland](https://www.jetbrains.com/go/) es todo un IDE para Go

Para ejecutar `gofmt` manualmente:

```bash
# will only show the differences
gofmt -d filename.go

# will apply the changes
gofmt -w filename.go
```

```git
%{gofmt}
```
