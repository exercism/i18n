# Instrucciones

En este ejercicio vas a ayudar a una pareja de enamorados del instituto a declarar su amor en las redes sociales.

## 1. Muestra el nombre de la pareja separado por un corazón

Implementa el método estático `HighSchoolSweethearts.DisplaySingleLine()` para recibir dos nombres y mostrarlos separados por un corazón.
El texto formateado debe tener 61 caracteres de ancho, con el corazón en el centro del string.

Todos los nombres caben de sobra dentro del ancho de la línea.

```csharp
HighSchoolSweethearts.DisplaySingleLine("Lance Green", "Pat Riley");
// => "                  Lance Green ♡ Pat Riley                    "
```

## 2. Muestra las iniciales de la pareja en un corazón de arte ascii

Implementa el método estático `HighSchoolSweethearts.DisplayBanner()`, que muestra los dos conjuntos de iniciales separados por un signo más.

```csharp
HighSchoolSweethearts.DisplayBanner("L. G.", "P. R.");
```

## 3. Haz que los estudiantes de intercambio alemanes se sientan como en casa con declaraciones adaptadas a la configuración regional.

Implementa el método estático `HighSchoolSweethearts.DisplayGermanExchangeStudents()` para mostrar la fecha de inicio de la relación y la duración de esta para nuestros estudiantes de intercambio alemanes.

```csharp
HighSchoolSweethearts.DisplayGermanExchangeStudents("Norbert", "Heidi", new DateTime(2019, 1, 22), 1535.22f);
// => "Norbert and Heidi have been dating since 22.01.2019 - that's 1.535,22 hours"
```
