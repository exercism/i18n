# Instrucciones

En este ejercicio vas a escribir algo de código que te ayude a prepararte para comprar un vehículo.

Tienes tres tareas: determinar si vas a necesitar un permiso de conducir, elegir entre dos vehículos y calcular el precio aceptable de un vehículo de segunda mano.

## 1. Determina si vas a necesitar un permiso de conducir

Algunos tipos de vehículos necesitan un permiso de conducir para poder manejarlos.
Supón que solo los tipos `"car"` y `"truck"` requieren permiso; todo lo demás se puede manejar sin permiso.

Implementa la función `needs_license`, que toma el tipo de vehículo y devuelve un valor booleano que indica si necesitas un permiso para ese tipo de vehículo.

```jq
"car" | needs_license
# => true

"bike" | needs_license
# => false
```

## 2. Elige entre dos posibles vehículos que comprar

Has evaluado tus opciones de vehículos disponibles.
Has conseguido reducirlas a dos opciones, pero necesitas ayuda para tomar la decisión final.
Implementa la función `choose_vehicle`, que toma como entrada un array de dos vehículos y devuelve una decisión: la opción que aparece primero en orden alfabético.

```jq
["Wuling Hongguang", "Toyota Corolla"] | choose_vehicle
# =>  "Toyota Corolla is clearly the better choice."

["Volkswagen Beetle", "Volkswagen Golf"] | choose_vehicle
# =>  "Volkswagen Beetle is clearly the better choice."
```

## 3. Calcula una estimación del precio de un vehículo de segunda mano

Ahora que has tomado tu decisión, quieres asegurarte de conseguir un precio justo en el concesionario.
Como te interesa comprar un vehículo de segunda mano, el precio depende de la antigüedad del vehículo.
Para una estimación aproximada, supón que si el vehículo tiene menos de 3 años, cuesta el 80 % del precio original que tenía cuando era nuevo.
Si tiene más de 10 años, cuesta el 50 %.
Si el vehículo tiene al menos 3 años, pero no más de 10, cuesta el 70 % del precio original.

Implementa la función `resell_price`, que aplica esta lógica usando `if`, `elif` y `else`.
Toma un objeto que contiene el precio original y la antigüedad del vehículo, y devuelve el precio estimado en el concesionario.

```jq
{"original_price": 1000, "age": 1} | resell_price
# => 800

{"original_price": 1000, "age": 5} | resell_price
# => 700

{"original_price": 1000, "age": 15} | resell_price
# => 500
```
