# Acerca de

Los caracteres de Factor son *enteros*, esto es, puntos de código Unicode, así que los operadores numéricos `<`, `>`, `=` ya te dan un orden que distingue entre mayúsculas y minúsculas. El vocabulario [`unicode`][unicode] añade además predicados que entienden Unicode y conversión de mayúsculas y minúsculas de un solo carácter.

## Predicados

```
LETTER?  ( c -- ? )    ! uppercase letter
letter?  ( c -- ? )    ! lowercase letter
Letter?  ( c -- ? )    ! letter, either case
digit?   ( c -- ? )    ! decimal digit
digit>   ( c -- n )    ! the integer value of a digit char
blank?   ( c -- ? )    ! whitespace
alpha?   ( c -- ? )    ! letter or decimal digit
```

```factor
USING: unicode ;

CHAR: A LETTER? .    ! => t
CHAR: a letter? .    ! => t
CHAR: 7 digit?  .    ! => t
CHAR: \n blank? .    ! => t
```

## Conversión de mayúsculas y minúsculas

```
ch>upper  ( c -- c' )
ch>lower  ( c -- c' )
ch>title  ( c -- c' )
```

Las versiones para strings `>upper`, `>lower` y `>title` aplican estas conversiones a cada carácter de un string.

```factor
CHAR: a ch>upper .   ! => 65   (which is CHAR: A)
"Hello" >upper .     ! => "HELLO"
```
