# Operador ternario

El operador ternario proporciona una sintaxis alternativa para realizar una comparación `if..else..` y devolver un valor.

## Sintaxis

PHP proporciona un condicional con el que se puede evaluar una acción en función de la veracidad de una condición.

```php
if ($condition) {
  $value = 1;
} else {
  $value = 2
}
```

Como alternativa, el operador ternario puede representar la misma operación:

```php
$value = $condition
  ? 1  // True branch
  : 2; // False branch
```

La sintaxis de comparación es breve y se representa con `(condition) ? (evaluate if true) : (evaluate if false);`.
