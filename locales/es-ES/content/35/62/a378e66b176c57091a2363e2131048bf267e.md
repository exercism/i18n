# Pistas

## Instrucciones específicas del track

Intenta evitar la repetición de código; usa funciones auxiliares privadas si puedes.

Y podrías plantearte usar una sola expresión `Boolean` en lugar de `if-else` para mejorar la legibilidad.
Consulta [aquí](http://cs.wellesley.edu/~cs111/spring00/lectures/boolean-simplification.html) cómo se podría hacer (el enlace es para Java, pero, por supuesto, la lógica también es válida para Scala).
