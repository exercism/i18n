# Instalación

El track del lenguaje C requiere que tengas instalado en tu sistema el siguiente software:

* Un compilador de C moderno
* La herramienta de compilación Make

El IDE Xcode de Apple combina el compilador y el sistema de compilación nativo en un único IDE (entorno de desarrollo integrado).
Los entornos Linux suelen ofrecer el compilador y el sistema de compilación nativo como herramientas de línea de comandos separadas.

## Linux

Los usuarios de Linux necesitarán gcc o clang como compilador, y `make` para la compilación nativa.
Make viene preinstalado en la mayoría de los sistemas unix, pero lo más probable es que esté disponible en el gestor de paquetes de tu distribución.
En las distribuciones basadas en Debian y Ubuntu, puedes instalar todo lo que necesitas con `sudo apt-get install build-essential` si no lo tienes ya.

## MacOS

Los usuarios de MacOS pueden instalar gcc o clang con [Homebrew][] mediante `brew install gcc` o `brew install llvm`.

## Windows

A los usuarios de Windows 10 se les recomienda usar el [Windows Subsystem for Linux][] y seguir las instrucciones para Linux de arriba.

Si usas una versión anterior de Windows o no tienes disponible WSL Bash, puedes usar [MSYS][] o [mingw-w64][].

[Homebrew]: https://brew.sh
[Windows Subsystem for Linux]: https://docs.microsoft.com/en-gb/windows/wsl/about
[MSYS]: https://www.msys2.org
[mingw-w64]: http://mingw-w64.org
