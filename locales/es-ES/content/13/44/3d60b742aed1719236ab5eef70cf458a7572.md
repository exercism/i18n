# Instrucciones

Siguiendo con la temática del juego de magos y guerreros, es hora de añadir un método para lanzar dados que sirva para todo. Será el tradicional dado de 18 caras con los números del 1 al 18. Los jugadores también generan una fuerza de hechizo.

## 1. Permite a un jugador de _magos y guerreros_ lanzar un dado.

Implementa un método `RollDie()` en la clase `Player`.

```csharp
var player = new Player();
player.RollDie();
// => >= 1 <= 18
```

## 2. Los jugadores necesitan su fuerza. Proporciona un medio para generar la fuerza de hechizo

Implementa un método `GenerateSpellStrength()` en la clase `Player`. La fuerza de hechizo está entre 0,0 y 100,0, sin incluir este último.

Ten en cuenta que la fuerza de hechizo debe ser un número real (no un número entero) para reducir la posibilidad de empate cuando se comparan las fuerzas de dos adversarios.

```csharp
var player = new Player();
player.GenerateSpellStrength();
// => >= 0.0 < 100.0
```
