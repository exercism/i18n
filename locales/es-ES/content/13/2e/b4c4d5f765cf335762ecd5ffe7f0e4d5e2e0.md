# Ayuda

## Ejecutar las pruebas

El track de Factor usa **Factor 0.101**. Después de
[instalarlo](https://exercism.org/docs/tracks/factor/installation),
ejecuta desde el directorio de este ejercicio:

```
factor -roots=. -run=exercism-tools <exercise>
```

Por ejemplo, para `hello-world`:

```
factor -roots=. -run=exercism-tools hello-world
```

Cada ejercicio viene con un pequeño vocabulario `exercism-tools` ya
incluido, que se encarga de ejecutar las pruebas. El ejecutor de
pruebas termina con estado 0 cuando todas las pruebas pasan, y con
un estado distinto de cero junto con la salida de diagnóstico si
alguna prueba falla.

### Pruebas omitidas

De forma predeterminada, solo se ejecuta la primera prueba. El
mecanismo es la línea `STOP-HERE` del fichero de pruebas: en el
momento de analizar el código, le indica al analizador léxico de
Factor que ignore todo lo que queda por debajo de ella, así que el
ejecutor solo ve las pruebas que están por encima. Cuando pase tu
primera prueba, puedes habilitar más pruebas de dos maneras:

- **Elimina la línea `STOP-HERE`** para habilitar de una vez todas
  las pruebas restantes.
- **Mueve la línea `STOP-HERE` más abajo** para habilitar las
  pruebas de una en una, o una tarea a la vez. Los ejercicios de
  concepto agrupan sus pruebas bajo marcadores `TASK:`, así que
  mover `STOP-HERE` justo antes del siguiente `TASK:` es un paso
  natural.

Cuando pasen todas las pruebas, habrás resuelto el ejercicio.

## Enviar tu solución

Desde el directorio del ejercicio:

```
exercism submit <exercise>/<exercise>.factor
```

Por ejemplo:

```
exercism submit hello-world/hello-world.factor
```

Si el fichero `.meta/config.json` del ejercicio incluye más de un
fichero de solución (algunos ejercicios de concepto reparten la
solución entre un subvocabulario auxiliar), pasa a `exercism submit`
todos los ficheros que hayas editado.

## Enviar soluciones incompletas

Puedes enviar una solución aunque las pruebas no pasen. Así puedes
ver cómo han abordado el ejercicio otras personas y pedir a un
mentor que te dé su opinión sobre lo que tengas hasta el momento.

## Cómo obtener más ayuda

- La [categoría de Factor en el foro de Exercism](https://forum.exercism.org/c/programming/factor/)
  es el mejor sitio para hacer preguntas y recibir comentarios
  específicos del track.
- El [Discord de Exercism](https://exercism.org/r/discord) tiene
  canales tanto para ayuda general como para tracks concretos.
- La documentación oficial de Factor es exhaustiva y se puede buscar. Dos buenos puntos de partida:
  - [El manual de Factor](https://docs.factorcode.org/content/article-handbook.html),
    a modo de referencia y organizado por vocabulario.
  - [El recetario de Factor](https://docs.factorcode.org/content/article-cookbook.html),
    con ejemplos breves e idiomáticos organizados por tema.
- El [tutorial de Factor](https://andreaferretti.github.io/factor-tutorial/)
  de Andrea Ferretti es una introducción rápida y amable al lenguaje
  y al entorno de desarrollo.
