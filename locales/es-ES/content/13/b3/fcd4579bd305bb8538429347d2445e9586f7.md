# Acerca de

En Factor, un string es una cadena de caracteres y comparte todo el protocolo [`sequences`][sequence-protocol] (`length`, `nth`, `head`, `tail`, `map`, `filter`, etc.), además de sus propios vocabularios.

```factor
"hello"  length .       ! => 5
"hello"  reverse .      ! => "olleh"
"abcdef" 3 head .       ! => "abc"
```

Las palabras específicas de los strings están sobre todo en [`splitting`][splitting], [`ascii`][ascii] y [`unicode`][unicode]:

| palabra      | vocabulario  | qué hace                              |
|--------------|---------------|---------------------------------------|
| `split1`     | [`splitting`][splitting]   | corta en la primera aparición         |
| `split`      | [`splitting`][splitting]   | corta por cualquier carácter de un conjunto |
| `harvest`    | [`sequences`][sequences]   | descarta los fragmentos vacíos de una división |
| `replace`    | [`splitting`][splitting]   | sustituye una subcadena               |
| `surround`   | [`sequences`][sequences]   | envuelve con un prefijo y un sufijo   |
| `glue`       | [`sequences`][sequences]   | une dos strings con un separador      |
| `join`       | [`sequences`][sequences]   | une un array de strings con un separador |
| `>lower`     | [`ascii`][ascii]       | convierte a minúsculas (ASCII)        |
| `>upper`     | [`ascii`][ascii]       | convierte a mayúsculas (ASCII)        |
| `[ blank? ] trim` | [`sequences`][sequences] | elimina los espacios en blanco del principio y del final |
| `first`, `second`, `third`, `fourth` | [`sequences`][sequences] | la posición inicial |
| `first2`, `first3`         | [`sequences`][sequences]   | desempaqueta dos o tres posiciones iniciales |
| `>string`    | [`strings`][strings]     | convierte una secuencia de caracteres en un string |
| `1string`    | [`strings`][strings]     | envuelve un solo carácter en un string de un carácter |
| `CHAR: x`    | parser        | un literal de un solo carácter (p. ej., `CHAR: A` → `65`) |

Para convertir en ambos sentidos entre números y strings, [`math.parser`][math.parser] ofrece `number>string` y `string>number`. Para generar strings con formato, [`formatting`][formatting] ofrece `sprintf` y compañía.

Para la conversión de mayúsculas y minúsculas o la clasificación de caracteres que tienen en cuenta Unicode, usa las palabras correspondientes de [`unicode`][unicode].
