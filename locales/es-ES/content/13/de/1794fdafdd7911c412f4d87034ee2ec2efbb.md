# Pistas

## General

- Intenta dividir un problema en un caso base y un caso recursivo
  Por ejemplo, digamos que quieres contar cuántas galletas hay en el bote de galletas con un enfoque recursivo
  Un caso base es un bote vacío: tiene cero galletas.
  Si el bote no está vacío, el número de galletas del bote es igual a una galleta más el número de galletas que quedan en el bote después de quitar una galleta.

## 1. Implementa una función que sume los números de un array

- La recursión consiste en iterar sobre los elementos del array, sumando cada uno a un acumulador.
- El caso base es un array vacío, cuya suma es igual a cero.
- El caso recursivo suma el primer elemento a la suma del resto del array.
- Recuerda la indexación y el corte de arrays del [concepto Arrays][arrays-concept] para separar el primer elemento del array del resto de los elementos.

## 2. Invierte un array

- La recursión consiste en iterar sobre los elementos del array, añadiendo cada uno a otro array en orden inverso.
- El caso base es un array vacío.
- Recuerda que el [operador `+`][manual-addition] concatena cuando se aplica a arrays.

## 3. Mapea un array

- La recursión consiste en iterar sobre los elementos del array, añadiendo a un array acumulador el resultado de aplicar el filtro al elemento.
- Para aplicar el parámetro filtro a un elemento, usa la sintaxis de tubería habitual: `.element | filter`.
- El caso base es un array vacío.
