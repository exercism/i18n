# Instrucciones

Tu club de netball necesita que se calcule su clasificación después de cada jornada.

Las cuatro tareas van en la clase `NETBALL_LADDER`.

## 1. Puntos de clasificación

Una victoria vale 4 puntos y un empate 2. Las derrotas no otorgan puntos.

```sather
NETBALL_LADDER::ladder_points(3, 1)
-- => 14
```

## 2. Diferencia de goles

Goles a favor menos goles en contra. Puede ser negativa.

```sather
NETBALL_LADDER::goal_difference(180, 205)
-- => -25
```

## 3. Cuartos completos jugados

Un cuarto son 15 minutos. Dado un número de minutos, ¿cuántos cuartos completos son?

```sather
NETBALL_LADDER::whole_quarters(38)
-- => 2
```

## 4. Minutos transcurridos del cuarto

Dado el mismo número de minutos, ¿en qué minuto del cuarto actual estamos?

```sather
NETBALL_LADDER::minutes_into_quarter(38)
-- => 8
```
