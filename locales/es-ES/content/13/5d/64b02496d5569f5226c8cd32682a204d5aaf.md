# Anexo de instrucciones

## Registros

| Registro | Uso       | Tipo    | Descripción                             |
| -------- | --------- | ------- | --------------------------------------- |
| `$a0`    | entrada   | dirección | array de palabras con los factores    |
| `$a1`    | entrada   | entero  | número de factores                      |
| `$a2`    | entrada   | entero  | límite                                  |
| `$v0`    | salida    | entero  | suma de los múltiplos dentro del límite |
| `$t0-9`  | temporal  | cualquiera | se usa para almacenamiento temporal  |
