# Extractor de fragmentos de código

El [extractor de fragmentos][snippet-extractor] toma la solución enviada por un estudiante y extrae de ella las diez primeras líneas de código «interesantes». El fragmento extraído se muestra en varias páginas del sitio web.

Por defecto, se muestran las diez primeras líneas, ignorando las líneas vacías iniciales. Esas diez primeras líneas _podrían_ incluir cosas como comentarios, que normalmente no son lo más adecuado para presentar en un fragmento.

## Personalizar la extracción de fragmentos

Recomendamos que cada track [personalice la extracción de fragmentos][snippet-extractor-customize] para, como mínimo, eliminar los comentarios del código fuente. Para personalizar la extracción de fragmentos, tendrás que:

1. Añadir un fichero `lib/languages/<track_slug>.txt` que configure la extracción de fragmentos.
   Este fichero puede usar el [modo básico][basic-mode] o el [modo extendido][extended-mode].
   La mayoría de los tracks usan el modo extendido, ya que ofrece más flexibilidad.
2. Añadir uno o más casos de prueba a un directorio `tests/<track_slug>/<test_slug>`.
   Cada directorio de pruebas necesitará dos ficheros:

   1. `tests/<track_slug>/<test_slug>/code.<track_extension>`: el código sobre el que ejecutar el extractor de fragmentos
   2. `tests/<track_slug>/<test_slug>/expected_snippet.<track_extension>`: el fragmento esperado

Consulta [este pull request de ejemplo][example-pr] que personaliza la extracción de fragmentos para el lenguaje Arturo.
