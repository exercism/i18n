# Introducción

## Tablas hash

Las tablas hash de Common Lisp son estructuras de datos para almacenar datos asociativos.
Asocian claves (que pueden ser cualquier objeto) con valores (que también pueden ser cualquier objeto).
Otros lenguajes se refieren a este concepto como mapas, diccionarios o hashes.

### Creación de tablas hash

Las tablas hash se pueden crear con la función `make-hash-table`.

`(make-hash-table) ; => #<HASH-TABLE :TEST EQL :COUNT 0 {10024AD2B3}>`

(Ten en cuenta que la representación impresa de una tabla hash depende de la implementación, por lo que puede aparecer de forma distinta en tu REPL).

### Recuperar valores por clave

Para obtener un valor a partir de una clave de la tabla hash, usa la función `gethash`:

```lisp
*h* ; => #<HASH-TABLE :TEST EQL :COUNT 3 {10024AD2B3}>`
(gethash :foo *h*) ; => :bar
                   ;    T
```

`gethash` devuelve [varios valores][concept-multiple-values], que se explican en otro concepto.

### Insertar valores

Para insertar un valor en una tabla hash, usa `setf` junto con `gethash` así:

`(setf (gethash :foo *hash-table*) :bar) : => :bar`

Esto modifica el valor de la clave `:foo` en la tabla hash `*hash-table*` para que sea `:bar`.
Devuelve ese valor.

El uso de `setf` se explicará en otro concepto.
