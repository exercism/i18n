# Booleanos

Haskell tiene un tipo conocido como [`Bool`][bools].
Es una enumeración de `True` y `False`.

## Operadores lógicos

Haskell tiene tres operadores lógicos (`not`, `||`, `&&`), que combinan valores `Bool` y crean expresiones que producen valores diferentes.

### Y(`&&`)

El [operador _y_][and] en Haskell se representa con `&&` y devuelve `True` si ambos valores son `True`; en caso contrario, devuelve `False`.
Al usar el operador _y_, se coloca un valor `Bool` a la derecha del `&&` y otro a la izquierda.

```haskell
True && True
-- -> True

True && False
-- -> False
```

### O(`||`)

El [operador _o_][or] en Haskell se representa con `||` y devuelve `True` si **al menos uno** de los valores dados es `True`. 
Si ambos valores son `False`, devuelve `False`.
Al usar el operador _o_, se debe colocar un valor `Bool` a la derecha del `||` y otro a la izquierda.

```haskell
True || True
-- -> True

True || False
-- -> True

False || False
-- -> False
```

### Negación(`not`)

El operador de _negación_ en Haskell se representa con `not` y devuelve `True` si el valor `Bool` dado es `False`, y devuelve `False` si se proporciona `True`.
Al usar el operador de _negación_, se debe colocar un valor `Bool` después del operador (`not`).

```haskell
not True
-- -> False

not False
-- -> True
```

## Uso de paréntesis(`()`)

Cuando trabajas con valores `Bool`, puedes usar paréntesis para decidir qué valores `Bool` evaluar primero.
El resultado puede variar según cómo se usen los paréntesis.
En Haskell, lo que está entre paréntesis se evalúa primero.

```haskell
True && False && False || True
-- -> True

True && False && (False || True)
-- -> False
```

Como lo que está entre paréntesis se evalúa primero, el operador de _negación_ se aplicará a la expresión dentro de los paréntesis en el siguiente ejemplo.

```haskell
not True && False
-- -> False

not (True && False)
-- -> True
```
