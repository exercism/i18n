# Instrucciones

Refactoriza un analizador de Markdown.

El ejercicio de Markdown es un ejercicio de refactorización. Hay código que analiza un string dado con [sintaxis de Markdown](https://guides.github.com/features/mastering-markdown/) y devuelve el HTML asociado a ese string. Aunque este código está escrito de forma confusa y es difícil de seguir, de algún modo funciona y todas las pruebas pasan. Tu reto es reescribir este código para que sea más fácil de leer y de mantener, sin dejar de asegurarte de que todas las pruebas sigan pasando.

Sería útil que anotaras en comentarios lo que has hecho durante la refactorización, para que quienes revisen puedan verlo, pero no es estrictamente necesario. ¡Lo más importante es mejorar el código!
