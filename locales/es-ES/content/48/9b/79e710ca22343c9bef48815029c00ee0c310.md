# Introducción

## Funciones flecha

Además de las declaraciones de funciones y las expresiones de funciones, JavaScript también tiene otra sintaxis muy concisa para definir una función.
Estas funciones se llaman _funciones flecha_.

Aquí tienes una comparación entre una declaración de función y una función flecha.

```javascript
function addUpTwoNumbers(num1, num2) {
  return num1 + num2;
}
// function keyword removed and => added
const addUpTwoNumbers = (num1, num2) => {
  return num1 + num2;
};
```

Si el cuerpo de la función contiene solo una instrucción return, como en el ejemplo anterior, se pueden omitir las `{}` y la palabra clave `return`.
Si solo hay un parámetro, también se pueden omitir los paréntesis `()`.

<!-- prettier-ignore-start -->
```javascript
const addUpTwoNumbers = (num1, num2) => num1 + num2;
const square = num => num * num;
```
<!-- prettier-ignore-end -->

Las funciones flecha se usan a menudo para definir funciones de callback cortas directamente en la llamada a la función.

<!-- prettier-ignore-start -->
```javascript
applyToSquare(number => number * number);
```
<!-- prettier-ignore-end -->

## Análisis de arrays

[Arrays][arrays-concept] tienen métodos integrados para analizar el contenido del array.
La mayoría de estos métodos toman una función que devuelve true o false como argumento.
Esa función se llama [`predicate`][predicate_in_programming].

Los métodos integrados están pensados para usarse _en lugar de un bucle `for`_ o del método integrado `forEach`:

Ejemplo de análisis usando un bucle `for`:

```javascript
const numbers = [1, 'two', 3, 'four'];
for (var i = 0; i < numbers.length; i++) {
  if (numbers[i] === 'two') {
    return i;
  }
}
// => 1
```

Ejemplo de análisis usando un método integrado:

```javascript
const numbers = [1, 'two', 3, 'four'];
numbers.indexOf('two');
// => 1
```

A continuación se muestran otros métodos integrados útiles disponibles para analizar un array.
Consulta [MDN][mdn-array-methods] para obtener una lista completa de los métodos de array.

### `includes`

El método `includes(value)` determina si un array incluye un valor determinado.
Devuelve `true` cuando el valor está incluido, `false` en caso contrario.

```javascript
const numbers = [1, 'two', 3, 'four'];
numbers.includes(1);
// => true
numbers.includes('one');
// => false
```

### `every`

El método `every(predicate)` toma una función que es _un predicado_.
Comprueba si todos los elementos del array devuelven `true` cuando se pasan al predicado.
En otras palabras: el método comprueba que todos sus elementos pasan la prueba que se le pasa a la función.
Devuelve `true` cuando cada elemento pasa la prueba del predicado, `false` en caso contrario.

```javascript
const numbers = [1, 3, 5, 7, 9];
numbers.every((num) => num % 2 !== 0);
// => true
```

### `some`

El método `some(predicate)` es igual que el método `every`, pero devuelve `true` si al menos un elemento del array pasa la prueba del _predicado_.

```javascript
const numbers = [1, 3, 5, 7, 9];
numbers.some((num) => num % 2 !== 0);
// => true
```

### `find`

El método `find(predicate)` devuelve el valor del primer elemento del array que pasa la prueba del `predicate`.
Mientras que `some()` devuelve `true` cuando pasa, `find()` devuelve el valor real en el array.
El método devuelve `undefined` cuando ninguno de los elementos del array pasa la prueba del _predicado_.

```javascript
const numbers = [1, 3, 5, 7, 9];
numbers.find((num) => num < 5);
// => 1
```

### `findIndex`

El `findIndex(predicate)` es igual que el método `find()`, pero devuelve el (primer) _índice_ del elemento que pasa la prueba del _predicado_ en lugar del `value`.
El método devuelve `-1` cuando ninguno de los elementos del array pasa la prueba del _predicado_.

```javascript
const numbers = [1, 3, 5, 7, 9];
numbers.findIndex((num) => num > 7);
// => 4
numbers.findIndex((num) => num > 9);
// => -1
```
