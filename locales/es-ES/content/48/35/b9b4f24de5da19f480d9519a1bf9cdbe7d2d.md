# Analizador de líneas de log

## Historia

En este ejercicio vas a procesar líneas de log.

Cada línea de log es un string con el siguiente formato: `"[<LVL>]: <MESSAGE>"`.

Estos son los distintos niveles de log:

- `TRC` (trace)
- `DBG` (debug)
- `INF` (info)
- `WRN` (warning)
- `ERR` (error)
- `FTL` (fatal)

## Tareas

Estas son tareas de ejemplo que encajan con el analizador de líneas de log:

- Convertir el nivel de log a un enum
- Admitir niveles de log desconocidos
- Convertir una línea de log a otro formato con el nivel de log convertido a un valor numérico
