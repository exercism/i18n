# Pruebas

Instala las dependencias.

```sh
dart pub get
```

Ejecuta las pruebas.

```sh
dart test
```

Para obtener una salida más detallada de cada prueba, usa el informe expandido.

```sh
dart test -r expanded
```

La mayoría de los ejercicios tienen varias pruebas, y todas menos la primera están omitidas por defecto.
Para ir resolviendo las pruebas de una en una, cambia `skip: true` por `skip: false` en cada prueba a medida que avances.

Como alternativa, ejecuta todas las pruebas a la vez sin editar el fichero.

```sh
dart test --run-skipped
```

Todas las pruebas se ejecutan con el ejecutor de pruebas en línea al enviar la solución, incluidas las omitidas.
