# Introducción

Elixir facilita las prácticas del **Principio de abierto-cerrado** al permitir que las funciones tengan múltiples cláusulas, de modo que, en lugar de una lógica de control extensa y codificada a mano, se pueden escribir funciones concretas para añadir o quitar comportamiento fácilmente.

Elixir ofrece _múltiples cláusulas de función_ y _guardas_ para escribir:

```elixir
def number(n) when n == 7 do
  "Awesome, that's my favorite"
end

def number(_n) do
  "That's not my favorite"
end
```

En tiempo de ejecución, Elixir comprobará, de arriba abajo del archivo de código fuente, qué cláusula de función invocar.

Las variables que no se usen deben ir precedidas de un guion bajo.
