# Hints

## 1. Establece la puntuación de un jugador en el hash %Scores

- Quieres modificar el hash `%Scores` para añadir las puntuaciones de nuevos jugadores y reemplazar las puntuaciones de jugadores existentes.
- Los hashes no pueden contener claves duplicadas; un valor más reciente en una lista reemplazará a un valor anterior.

## 2. Obtén la puntuación de un jugador del hash %Scores

- Quieres usar el nombre del jugador dado para `return` la puntuación del jugador desde el hash `%Scores`.

## 3. Aumenta la puntuación de un jugador en el hash %Scores

- Quieres modificar el hash `%Scores` para añadir las puntuaciones de los jugadores ya existentes a las nuevas puntuaciones dadas.

## 4. Ordena los jugadores del hash %Scores por su nombre

- Quieres `return` los nombres de los jugadores del hash `%Scores` como una lista ordenada alfabéticamente.


## 5. Ordena los jugadores del hash %Scores por su puntuación

- Quieres `return` los nombres de los jugadores del hash `%Scores` como una lista ordenada por puntuación de mayor a menor.

## 6. Elimina a un jugador del hash %Scores

- Quieres modificar el hash `%Scores` para eliminar el nombre y la puntuación del jugador dado.
