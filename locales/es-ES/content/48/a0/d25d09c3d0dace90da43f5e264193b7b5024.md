# Apéndice de las instrucciones

## Instrucciones específicas del track

Tu tarea consiste en implementar un record `circularBuffer` que tenga los siguientes métodos:

- `clear()`: vacía el buffer.
- `write(item)`: añade el elemento indicado al buffer. Si el buffer está lleno, debe lanzar `Error("Cannot write to full buffer.")`.
- `read()`: elimina el elemento más antiguo del buffer y lo devuelve. Si el buffer está vacío, debe lanzar `Error("Cannot read from an empty buffer.")`.
- `overwrite(item)`: si el buffer está lleno, sobrescribe el elemento más antiguo con `item`. Si el buffer no está lleno, se comporta como `write`.
