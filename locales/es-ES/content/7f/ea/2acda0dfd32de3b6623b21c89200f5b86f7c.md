# Instrucciones

En este ejercicio vas a implementar una forma de llevar un registro de las puntuaciones más altas del juego más popular de tu salón recreativo local.

Tienes 5 funciones que implementar, relacionadas en su mayoría con la manipulación de un objeto que contiene puntuaciones altas.

## 1. Crear un nuevo marcador de puntuaciones

Crea una función `createScoreBoard` que cree un objeto que sirva como marcador de puntuaciones.
Las claves de este objeto serán los nombres de los jugadores y los valores, sus puntuaciones.
Para poder hacer pruebas, quieres incluir directamente una entrada en el objeto.
Esta entrada inicial debe constar de `The Best Ever` como nombre del jugador y `1000000` como puntuación.

```javascript
createScoreBoard();
// returns an object with one initial entry
```

## 2. Añadir jugadores a un marcador de puntuaciones

Para añadir un jugador al marcador de puntuaciones, define la función `addPlayer`.
Acepta 3 parámetros:

- El primer parámetro es un objeto marcador de puntuaciones existente.
- El segundo parámetro es el nombre de un jugador como string.
- El tercer parámetro es la puntuación como número.

La función devuelve el mismo objeto marcador de puntuaciones que se le pasó, después de añadir al nuevo jugador.

```javascript
addPlayer({ 'Dave Thomas': 0 }, 'José Valim', 486373);
// => {'Dave Thomas': 0, 'José Valim': 486373}
```

## 3. Eliminar jugadores de un marcador de puntuaciones

Si los jugadores infringen las normas del salón recreativo, se les elimina manualmente del marcador de puntuaciones.
Define `removePlayer`, que acepta 2 parámetros:

- El primer parámetro es un objeto marcador de puntuaciones existente.
- El segundo parámetro es el nombre del jugador como string.

Esta función debe eliminar del marcador la entrada del jugador indicado y devolver el marcador a continuación.
Si el jugador no estaba en el marcador, no debe pasarle nada al marcador.
Se debe devolver tal cual.

```javascript
removePlayer({ 'Dave Thomas': 0 }, 'Dave Thomas');
// => {}

removePlayer({ 'Dave Thomas': 0 }, 'Rose Fanaras');
// => { 'Dave Thomas': 0 }
```

## 4. Aumentar la puntuación de un jugador

Si un jugador termina otra partida en el salón recreativo, se añadirá cierta cantidad de puntos a la puntuación anterior del marcador.
Implementa `updateScore`, que acepta 3 parámetros:

- El primer parámetro es un objeto marcador de puntuaciones existente.
- El segundo parámetro es el nombre del jugador cuya puntuación se debe aumentar.
- El tercer parámetro es la puntuación que quieres **añadir** a la puntuación alta almacenada.

La función debe devolver el marcador una vez hecha la actualización.

```javascript
updateScore({ 'Freyja Ćirić': 12771008 }, 'Freyja Ćirić', 73);
// => {"Freyja Ćirić", 12771081}
```

## 5. Aplicar los puntos de bonificación de los lunes

Los lunes, el salón recreativo lleva un marcador aparte.
Al final del día, cada jugador de ese marcador recibe 100 puntos adicionales.

Implementa la función `applyMondayBonus`, que acepta un marcador de puntuaciones.
La función añade los puntos de bonificación a cada jugador que aparece en ese marcador.
Después, se devuelve el marcador.

```javascript
const scoreBoard = {
  'Dave Thomas': 44,
  'Freyja Ćirić': 539,
  'José Valim': 265,
};

applyMondayBonus(scoreBoard);
// => { 'Dave Thomas': 144, 'Freyja Ćirić': 639, 'José Valim': 365 }
```
