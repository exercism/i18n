# Anexo a las instrucciones

## Implementación

Este ejercicio presenta los [genéricos](https://docs.oracle.com/javase/tutorial/java/generics/index.html).
Para que las pruebas pasen, tienes que construir tu clase de forma que acepte cualquier tipo de entrada, por ejemplo `Integer` o `String`.

Los genéricos son útiles porque te permiten escribir código más general y reutilizable.
Las implementaciones de [List](https://docs.oracle.com/javase/8/docs/api/java/util/List.html) y [Map](https://docs.oracle.com/javase/8/docs/api/java/util/Map.html) de Java son ambas ejemplos de clases que usan genéricos.
Si los usas, puedes construir un `List` que contenga `Integers` o una lista que contenga `Strings` o cualquier otro tipo.

Hay algunas restricciones en los tipos que se usan con los genéricos.
Una de ellas es que, una vez que has construido un `List` que contiene `Integers`, no puedes meter `Strings` en él.
Tienes que especificar qué tipo quieres introducir en la clase cuando la construyes, y esa instancia solo se puede usar después con ese tipo.

Por ejemplo, podrías construir una lista de `Integers`:

`List<Integer> someList = new LinkedList<>();`

Ahora `someList` solo puede contener `Integers`. También podrías hacer:

`List<String> someOtherList = new LinkedList<>()`

Ahora `someOtherList` solo puede contener `Strings`.

Otra restricción es que ningún tipo que se use con genéricos puede ser un [tipo primitivo](https://docs.oracle.com/javase/tutorial/java/nutsandbolts/datatypes.html), como `int` o `long`.
Sin embargo, todos los tipos primitivos tienen un tipo de referencia correspondiente, así que en lugar de `int` puedes usar [`Integer`](https://docs.oracle.com/javase/8/docs/api/java/lang/Integer.html) y en lugar de `long` puedes usar [`Long`](https://docs.oracle.com/javase/8/docs/api/java/lang/Long.html).

Puede ayudarte echar un vistazo a un [ejemplo de caso de uso de los genéricos](https://docs.oracle.com/javase/tutorial/java/generics/types.html) para empezar.
