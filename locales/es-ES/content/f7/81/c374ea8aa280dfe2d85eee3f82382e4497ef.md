# Pistas

## General

- Lee sobre enumerables y streams en la [guía oficial de introducción][getting-started-streams].
- Lee la documentación oficial de los [streams][stream].

## 1. Haz una tirada de un dado de 6 caras

- Los rangos implementan el _protocolo Enumerable_.
- Hay una [función incorporada][enum-random] para elegir un valor aleatorio de un enumerable.

## 2. Sigue tirando mientras saques seises

- Hay una [función incorporada][stream-repeatedly] que crea un stream generado llamando a una función repetidamente.
- Hay una [función incorporada para streams][stream-transform] que funciona de forma similar a `Enum.reduce/3`.

## 3. Permite usar un dado trucado

- Usa el [operador de captura][special-forms-capture] para capturar la función `roll/0`.
