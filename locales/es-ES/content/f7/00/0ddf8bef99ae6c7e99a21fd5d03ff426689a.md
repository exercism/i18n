# Instrucciones

Implementa la operación `accumulate`, que, dada una colección y una operación que hay que aplicar a cada elemento de la colección, devuelve una nueva colección con el resultado de aplicar esa operación a cada elemento de la colección de entrada.

Dada la colección de strings:

- "cat", "Dog", "b4t", "gO"

Y la operación:

- convertir un string a mayúsculas

Tu código debería ser capaz de producir la colección de strings:

- "CAT", "DOG", "B4T, "GO"

Echa un vistazo a la suite de tests para ver la firma de función esperada.

## Restricciones

¡No toques esa funcionalidad de collect/map/fmap/loquesea que te ofrece tu biblioteca estándar!
Resuelve este ejercicio por tu cuenta usando otras herramientas básicas.
