# Pistas

## 1. Define si Pac-Man puede comerse un fantasma

* La función debe devolver un valor booleano.
* Puedes usar el operador lógico `and` para combinar los argumentos y obtener un resultado.

## 2. Define si Pac-Man puntúa

* La función debe devolver un valor booleano.
* Puedes usar el operador booleano `or` para combinar los argumentos y obtener un resultado.

## 3. Define si Pac-Man pierde

* La función debe devolver un valor booleano.
* Puedes usar los operadores booleanos `and` y `not` para combinar los argumentos y obtener un resultado.

## 4. Define si Pac-Man gana

* La función debe devolver un valor booleano.
* Puedes usar los operadores booleanos `and` y `not` para combinar los argumentos y los resultados de una de las funciones implementadas previamente.
