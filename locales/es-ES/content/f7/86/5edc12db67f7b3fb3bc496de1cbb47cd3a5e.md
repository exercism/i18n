# Pistas

## General

- No te preocupes por los tipos de número concretos; por ahora, usa `Int32` y `Float64`.
- Int32 y Float64 son los tipos de número predeterminados en Crystal, así que no necesitas especificarlos.

## 1. Convierte la temperatura de Celsius a Kelvin

- Puedes usar el operador aritmético(`+`) para sumar números.

## 2. Redondea la temperatura

- Puedes usar el método `round` para redondear un número a un número concreto de decimales.
- El método `round` recibe un argumento `places` que especifica el número de decimales a los que redondear.

## 3. Convierte la temperatura de Celsius a Fahrenheit

- Puedes usar el operador aritmético(`*`) para multiplicar números.
- Puedes usar paréntesis(`()`) para agrupar operaciones.

## 4. Obtén el número de sensores que faltan

- Puedes usar el operador aritmético(`-`) para restar números.
- Puedes usar el operador aritmético(`%`) para obtener el residuo de una división.
