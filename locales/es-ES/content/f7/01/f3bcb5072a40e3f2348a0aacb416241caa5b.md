# Acerca de

El [paquete `strings`](https://pkg.go.dev/strings) proporciona funciones para trabajar con strings.
A continuación se muestran algunas de las funciones del paquete; consulta la documentación para ver el resto.

| Categoría             | Función                                             | Propósito                                                           |
| --------------------- | --------------------------------------------------- | ------------------------------------------------------------------- |
| Conversión de mayúsculas y minúsculas | [ToLower](https://pkg.go.dev/strings#ToLower) | Convertir un string a minúsculas                                |
| Conversión de mayúsculas y minúsculas | [ToUpper](https://pkg.go.dev/strings#ToUpper) | Convertir un string a mayúsculas                                |
| Búsqueda              | [Contains](https://pkg.go.dev/strings#Contains)     | Comprobar si un string contiene una subcadena concreta              |
| Búsqueda              | [Count](https://pkg.go.dev/strings#Count)           | Contar las apariciones no solapadas de una subcadena                |
| Búsqueda              | [HasPrefix](https://pkg.go.dev/strings#HasPrefix)   | Comprobar si un string empieza por una subcadena concreta           |
| Búsqueda              | [HasSuffix](https://pkg.go.dev/strings#HasSuffix)   | Comprobar si un string termina en una subcadena concreta            |
| Búsqueda              | [Index](https://pkg.go.dev/strings#Index)           | Devolver el índice de la primera aparición de una subcadena, o -1   |
| Modificación          | [Replace](https://pkg.go.dev/strings#Replace)       | Reemplazar hasta n apariciones de una subcadena                     |
| Modificación          | [ReplaceAll](https://pkg.go.dev/strings#ReplaceAll) | Reemplazar todas las apariciones de una subcadena                   |
| Modificación          | [TrimSpace](https://pkg.go.dev/strings#TrimSpace)   | Eliminar los espacios en blanco al principio y al final             |
| División y unión      | [Fields](https://pkg.go.dev/strings#Fields)         | Dividir un string en palabras por los espacios en blanco            |
| División y unión      | [FieldsSeq](https://pkg.go.dev/strings#FieldsSeq)   | Obtener cada palabra de una en una                                  |
| División y unión      | [Join](https://pkg.go.dev/strings#Join)             | Unir un slice de strings con un separador                           |
| División y unión      | [Split](https://pkg.go.dev/strings#Split)           | Dividir un string en partes por un separador                        |
| División y unión      | [SplitSeq](https://pkg.go.dev/strings#SplitSeq)     | Obtener cada parte de una en una                                    |

```go
import (
    "fmt"
    "strings"
)

// Case conversion
strings.ToLower("Gopher")              // "gopher"
strings.ToUpper("Gopher")              // "GOPHER"

// Searching
strings.Contains("Apple", "le")        // true
strings.Index("Apple", "le")           // 3
strings.Index("Apple", "xyz")          // -1
strings.Count("test", "t")             // 2
strings.HasPrefix("Gopher", "Go")      // true
strings.HasSuffix("Gopher", "er")      // true

// Modifying
strings.TrimSpace("  hello  ")         // "hello"
strings.Replace("aabbcc", "b", "x", 1) // "aaxbcc"
strings.ReplaceAll("aabbcc", "b", "x") // "aaxxcc"

// Splitting or Joining
strings.Fields("  a b\tc  ")               // []string{"a", "b", "c"}
strings.Split("a,b,c", ",")                // []string{"a", "b", "c"}
strings.Join([]string{"a", "b", "c"}, ",") // "a,b,c"

// You do not need to worry about this range syntax yet.
// It is covered later in the range iteration concept.
for word := range strings.FieldsSeq("  a b\tc  ") {
    fmt.Println(word)
}
// Output:
// a
// b
// c

for part := range strings.SplitSeq("a,b,c", ",") {
    fmt.Println(part)
}
// Output:
// a
// b
// c
```
