# Introducción

A veces, una parte del estado tiene que compartirse entre varias palabras sin pasarla por sus efectos de pila cada vez.
Las *variables dinámicas* de Factor, declaradas con `SYMBOL:`, dan a cada palabra acceso a un valor almacenado en un espacio de nombres.

```factor
USING: namespaces ;

SYMBOL: counter

0 counter set-global
counter [ 1 + ] change-global
counter get-global .       ! => 1
```

`set-global` y `get-global` operan sobre el espacio de nombres global.
`set` y `get` operan sobre el scope dinámico *actual* y normalmente se usan dentro de un bloque `with-variable` cuando quieres un enlace con scope en lugar de uno para todo el proceso.

`SYMBOLS: a b c ;` declara varios símbolos a la vez.
