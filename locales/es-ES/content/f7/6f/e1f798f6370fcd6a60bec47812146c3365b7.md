# Tests

Para ejecutar los tests, sigue estos pasos:

- Dirígete al directorio del problema (por ejemplo, `~/Exercism/hello-world`).
- Inicia una sesión de `jconsole` (por ejemplo, escribiendo `jconsole` o `ijconsole`) en un terminal.
- Carga tu archivo de solución (por ejemplo, `load 'hello-world.ijs'`)
- Carga el framework de tests unitarios escribiendo `load  'general/unittest'`
- Prueba tu solución escribiendo `unittest 'test.ijs'`.
<br></br>
- Como alternativa, es posible ejecutar los tests en una sola línea así: `jconsole -js "load 'hello-world.ijs'" "echo unittest 'test.ijs'" "exit 0"`.

## Tests omitidos

Al principio, solo se activará el test inicial.
El planteamiento te anima a resolver el ejercicio paso a paso.
Cada test incluye un sustantivo encima de su definición, con un nombre que termina en _'\_ignore'_.
Para ejecutar el test, cambia su valor a 0.

### Ejemplo:

```
    leap_test_02_ignore=: 1 NB. Change this value to 0 to run this test
    test_leap_test_02  =: monad define
    ...                     NB. test definitions
    )
```
