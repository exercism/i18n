# Instrucciones

Trabajas como asistente de enseñanza corrigiendo los exámenes de los estudiantes.
Llevar la cuenta de los resultados a mano se está volviendo tedioso y propenso a errores.
Así que decides hacer las cosas un poco más interesantes creando algunas funciones que cuenten y calculen los resultados de la clase.

## 1. Redondear las puntuaciones

Aunque puedes dar «crédito parcial» en las preguntas del examen, las puntuaciones globales del examen tienen que ser `int`s.
Así que, antes de poder hacer cualquier otra cosa con las puntuaciones de la clase, tienes que repasar las notas y convertir en `int`s todas las puntuaciones que sean `float`.
Por suerte para ti, Python tiene la función integrada [`round()`][round] que puedes usar.

Crea la función `round_scores(student_scores)` que recibe un `list` de `student_scores`.
Esta función debe _consumir_ el `list` de entrada y `return` un nuevo array con todas las puntuaciones convertidas a `int`s.
El orden de las puntuaciones en el `list` resultante no es importante.

```python
>>> student_scores = [90.33, 40.5, 55.44, 70.05, 30.55, 25.45, 80.45, 95.3, 38.7, 40.3]
>>> round_scores(student_scores)
...
[40, 39, 95, 80, 25, 31, 70, 55, 40, 90]
```

## 2. Estudiantes que no aprueban

Mientras corregías el examen, te diste cuenta de que algunos estudiantes no rendían tan bien como esperabas.
Pero te distrajiste y olvidaste anotar exactamente _cuántos_ estudiantes eran.

Crea la función `count_failed_students(student_scores)` que recibe un `list` de `student_scores`.
Esta función debe contar el número de estudiantes que no tienen una puntuación suficiente y devolver ese recuento como un número entero.
Un estudiante necesita una puntuación mayor que **40** para aprobar el examen.

```python
>>> count_failed_students(student_scores=[90,40,55,70,30,25,80,95,38,40])
5
```

## 3. Los «mejores»

El profesor al que ayudas quiere encontrar al grupo de estudiantes que ha rendido «mejor» en este examen.
Lo que se considera «el mejor» varía, así que tienes que encontrar las puntuaciones de los estudiantes que sean **mayores o iguales que** el umbral actual.

Crea la función `above_threshold(student_scores, threshold)` que recibe `student_scores` (un `list` de notas) y `threshold` (el umbral de la «puntuación más alta») como parámetros.
Esta función debe devolver un `list` con todas las puntuaciones que sean `>=` que `threshold`.

```python
>>> above_threshold(student_scores=[90,40,55,70,30,68,70,75,83,96], threshold=75)
[90,75,83,96]
```

## 4. Calcular las calificaciones con letras

Al profesor al que ayudas le gusta asignar calificaciones con letras además de puntuaciones numéricas.
Como los estudiantes rara vez sacan 100 en un examen, los umbrales inferiores de la «calificación con letra» se calculan a partir de la puntuación más alta obtenida y aumentan de forma uniforme entre esa puntuación máxima y el umbral de suspenso de **<= 40**.

Crea la función `letter_grades(highest)` que recibe la puntuación «más alta» del examen como argumento y devuelve un `list` de umbrales inferiores de puntuación para cada intervalo de calificación «al estilo estadounidense»: `["D", "C", "B", "A"]`.


```python
"""Where the highest score is 100, and failing is <= 40.
       "F" <= 40
 41 <= "D" <= 55
 56 <= "C" <= 70
 71 <= "B" <= 85
 86 <= "A" <= 100
"""

>>> letter_grades(highest=100)
[41, 56, 71, 86]


"""Where the highest score is 88, and failing is <= 40.
       "F" <= 40
 41 <= "D" <= 52
 53 <= "C" <= 64
 65 <= "B" <= 76
 77 <= "A" <= 88
"""

>>> letter_grades(highest=88)
[41, 53, 65, 77]
```

## 5. Emparejar nombres con puntuaciones

Tienes un array de puntuaciones de examen en orden descendente y otro array de nombres de estudiantes, también ordenados de forma descendente según sus puntuaciones en el examen.
Te gustaría emparejar el nombre de cada estudiante con su puntuación y mostrar una clasificación general de la clase.

Crea la función `student_ranking(student_scores, student_names)` con los parámetros `student_scores` y `student_names`.
Empareja cada nombre de estudiante del `list` student_names con su puntuación del `list` student_scores.
Puedes asumir que cada `list` de argumentos estará ordenado de la puntuación más alta a la más baja.
La función debe devolver un `list` de strings con el formato `<rank>. <student name>: <student score>`.

```python
>>> student_scores = [100, 99, 90, 84, 66, 53, 47]
>>> student_names =  ['Joci', 'Sara','Kora','Jan','John','Bern', 'Fred']
>>> student_ranking(student_scores, student_names)
...
['1. Joci: 100', '2. Sara: 99', '3. Kora: 90', '4. Jan: 84', '5. John: 66', '6. Bern: 53', '7. Fred: 47']
```

## 6. Una puntuación «perfecta»

Aunque una puntuación «perfecta» de 100 es poco frecuente en un examen, es interesante saber si al menos un estudiante la ha conseguido.

Crea la función `perfect_score(student_info)` con el parámetro `student_info`.
`student_info` es un `list` de arrays que contienen el nombre y la puntuación de cada estudiante: `[["Charles", 90], ["Tony", 80]]`.
La función debe `return` _el primer_ par `[<name>, <score>]` del estudiante que sacó 100 en el examen.

Si no se encuentra ninguna puntuación de 100 en `student_info`, debe devolverse un array vacío `[]`.

```python
>>> perfect_score(student_info=[["Charles", 90], ["Tony", 80], ["Alex", 100]])
["Alex", 100]

>>> perfect_score(student_info=[["Charles", 90], ["Tony", 80]])
[]
```
