# Introducción

El [tipo `enum`](https://docs.microsoft.com/en-us/dotnet/csharp/language-reference/builtin-types/enum) de C# representa un conjunto fijo de constantes con nombre (una enumeración).

Normalmente, un miembro de `enum` solo puede referirse a exactamente una de esas constantes con nombre. Sin embargo, a veces es útil referirse a más de una constante. Para ello, se puede anotar el `enum` con el [atributo `Flags`](https://docs.microsoft.com/en-us/dotnet/api/system.flagsattribute).

Una enumeración de banderas se puede definir de la siguiente manera (usando la notación de enteros binarios `0b`):

```csharp
[Flags]
enum PhoneFeatures
{
    Call = 0b00000001,
    Text = 0b00000010
}
```

Una instancia de `PhoneFeatures` cuyo valor es `0b00000011` tiene establecidas tanto la bandera `Call` _como_ la `Text`.

De forma predeterminada, se usa el tipo `int` para los valores de los miembros de la enumeración. Se puede usar un tipo entero diferente especificando el tipo en la declaración de la enumeración:

```csharp
[Flags]
enum PhoneFeatures : byte
{
    Call = 0b00000001,
    Text = 0b00000010
}
```
