# Pistas

## General

- Un [mapa][maps] es una estructura de datos asociativa de pares clave-valor.
- Elixir ofrece [muchas funciones útiles del módulo Map en la biblioteca estándar][map-module].

## 1. Define un nuevo mapa de puntuación máxima

- Debería devolver un [mapa][maps] vacío.
- Las funciones del [módulo Map][map-module] o las formas literales pueden ser útiles.

## 2. Añade jugadores al mapa de puntuación máxima

- Se debería devolver el mapa resultante.
- El [módulo Map][map-module] contiene funciones útiles para manipular mapas. [Una de ellas][map-put] coloca un valor en un mapa bajo una clave dada.

## 3. Elimina jugadores del mapa de puntuaciones

- Se debería devolver el mapa resultante.
- El [módulo Map][map-module] contiene funciones útiles para manipular mapas. [Una de ellas][map-delete] elimina una clave de un mapa.

## 4. Restablece la puntuación de un jugador

- Se debería devolver el mapa resultante con la puntuación del jugador restablecida a un valor inicial.
- El [módulo Map][map-module] contiene funciones útiles para manipular mapas. [Una de ellas][map-put] coloca un valor en un mapa bajo una clave dada.

## 5. Actualiza la puntuación de un jugador

- Se debería devolver el mapa resultante con la puntuación del jugador actualizada.
- El [módulo Map][map-module] contiene funciones útiles para manipular mapas. [Una de ellas][map-update] actualiza un valor en un mapa bajo una clave dada.

## 6. Obtén una lista de jugadores

- El [módulo Map][map-module] contiene funciones útiles para manipular mapas. [Una de ellas][map-keys] devuelve una lista con todas las claves de un mapa.
