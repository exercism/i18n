# Edición estándar

La Edición estándar de Exercism está diseñada para que las personas la usen para su aprendizaje personal, mientras se ayudan mutuamente a través de los sistemas de nuestra comunidad.

No está diseñada ni pensada para que las organizaciones la usen para formar a su personal ni para impulsar bootcamps.
Consulta la [Edición para equipos](/docs/editions/teams) para saber cómo puedes alcanzar esos objetivos.
