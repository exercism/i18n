# Instrucciones

En este ejercicio vas a procesar líneas de log.

Cada línea de log es un string con el siguiente formato: `"[<LEVEL>]: <MESSAGE>"`.

Hay tres niveles de log distintos:

- `INFO`
- `WARNING`
- `ERROR`

Tienes varias tareas, y cada una recibirá una línea de log y te pedirá que hagas algo con ella.

## 1. Permitir obtener el string que hay después de una subcadena concreta

Si observas los logs del último mes, verás que el mensaje de test siempre se encuentra después de una subcadena concreta. Como prevés que tendrás que extraer el mensaje de test en algún momento próximo, decides crear un método auxiliar que te ayude con eso.

Implementa el método de extensión (_static_) `LogAnalysis.SubstringAfter()`, que recibe un delimitador de tipo string y devuelve la subcadena que hay después del delimitador.

```csharp
var log = "[INFO]: File Deleted.";
log.SubstringAfter(": "); // => returns "File Deleted."
```

## 2. Permitir obtener el string que hay entre dos subcadenas

Si te fijas mejor, verás que el nivel de log siempre se encuentra entre corchetes (`[` y `]`). Como también prevés que tendrás que extraer el nivel de log en algún momento próximo, decides crear otro método auxiliar que te ayude con eso.

Implementa el método de extensión (_static_) `LogAnalysis.SubstringBetween()`, que recibe dos delimitadores de tipo string y devuelve la subcadena que hay entre ambos delimitadores.

```csharp
var log = "[INFO]: File Deleted.";
log.SubstringBetween("[", "]"); // => returns "INFO"
```

## 3. Analizar el mensaje de un log

Implementa el método de extensión (_static_) `LogAnalysis.Message()` para devolver el mensaje que contiene un log.

```csharp
var log = "[ERROR]: Missing ; on line 20.";
log.Message(); // => returns "Missing ; on line 20."
```

## 4. Analizar el nivel de log de un log

Implementa el método de extensión (_static_) `LogAnalysis.LogLevel()` para devolver el nivel de log de un log.

```csharp
var log = "[ERROR]: Missing ; on line 20.";
log.LogLevel(); // => returns "ERROR"
```
