# Apéndice de instrucciones

## Pistas

Para resolver este ejercicio tienes que implementar estas dos funciones:

- `largestPalindrome`
- `smallestPalindrome`

Ambas funciones reciben un límite inferior y otro superior para los factores y devuelven un par `(value, [(factor1, factor2)])` que contiene el palíndromo y sus posibles pares de factores.

Puedes usar las firmas proporcionadas si no estás seguro de los tipos, pero no dejes que restrinjan tu creatividad.

No pasa nada por devolver duplicados en el array de factores, y el orden de los factores es irrelevante.

Deberías plantearte usar un algoritmo ligeramente distinto para encontrar palíndromos pequeños o grandes.
