# Acerca de

La instrucción `guard` de Swift se usa para realizar salidas anticipadas de las funciones de Swift cuando no se cumple una condición necesaria que deba cumplirse para que continúe el procesamiento, por ejemplo:

```swift
guard myValue = 0 else { return 0 }
let root = myValue.squareRoot()
```

En este caso, el `guard` comprueba si la expresión booleana que sigue a la palabra clave `guard` se evalúa como verdadera. Si es así, el procesamiento continúa con el código que sigue a la instrucción `guard` (en este caso, `let root = myValue.squareRoot()`. En caso contrario, se ejecutará el código de la cláusula `else`. A diferencia de una instrucción `if`, una instrucción `guard` _debe_ tener una cláusula `else` y, a diferencia de la cláusula `else` de un `if`-`else`, la cláusula `else` de un `guard` _debe_ salir del ámbito de la instrucción `guard`. Es decir, debe usar una instrucción de transferencia de control como `return`, `continue` o `break`, o bien lanzar un error o salir del programa.

Un ejemplo de su uso es la función sinc, que es igual a sin(x)/x con sinc(0) definido como 1, lo que evita problemas con la división entre 0. Esta función se puede escribir en Swift usando un `guard` de la siguiente manera:

```swift
func sinc(_ x: Double) -> Double {
    guard x != 0 else { return 1 }
    return sin(x) / x
}

sinc(0)              // returns 1
sinc(Double.pi / 2)  // returns 0.6366197723675814
```
