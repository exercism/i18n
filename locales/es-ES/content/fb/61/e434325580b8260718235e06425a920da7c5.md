# Condicionales innecesarios

En esta solución se usan [condicionales][conditionals] innecesariamente.
Usar un [argumento predeterminado][default argument] junto con [str.format][str.format] o [f-strings][f-strings] (_también conocidos como «literales de string formateados» o «strings interpolados»_) puede hacer que el código sea más claro y menos verboso.

Consulta esta publicación sobre [argumentos predeterminados en Python][python default arguments] para obtener más detalles.
La entrada de blog [formato de strings en Python][string formatting in python] también puede ser un buen punto de partida para aprender sobre las opciones de formato de strings de Python.
