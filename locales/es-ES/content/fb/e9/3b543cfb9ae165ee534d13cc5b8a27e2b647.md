# Instrucciones

De repente te ha entrado un antojo de tortitas.
Como persona moderna con inclinaciones técnicas, escribes una lista de la compra con los ingredientes de las tortitas en formato JSON.
La estructura de la lista es:

```json
{
  "name": "name of shopping list",
  "ingredients": [ ...list of ingredients... ],
  "optional ingredients": [ ...list of ingredients... ]
}
```

Un ingrediente se representa como un objeto JSON, así:

```json
{
  "item": "flour",
  "amount": {
    "quantity": 2,
    "unit": "cup"
  }
}
```

Un ingrediente tiene una propiedad opcional llamada `"substitute"` que contiene un string con otro ingrediente que se puede usar en su lugar.

Vamos a ver cómo podemos examinar la lista de la compra con `jq`.

## 1. Extrae el nombre de la lista de la compra

Escribe una expresión que devuelva el elemento "name" de la lista de la compra.

## 2. Cuenta cuántos ingredientes se necesitan

Cuenta solo los ingredientes «obligatorios». No incluyas los ingredientes opcionales.

## 3. ¿Cuánta azúcar?

Escribe una expresión que devuelva la cantidad de azúcar.
Solo se quiere la parte numérica.

## 4. Mapea los ingredientes que se pueden sustituir

Algunos ingredientes se pueden sustituir (si no tienes el ingrediente X puedes usar Y).
Genera un objeto JSON que asocie el ingrediente recomendado con su sustituto.
Incluye los ingredientes opcionales en esa correspondencia.
