# Acerca de

El filtrado es el proceso de crear una secuencia a partir de otra secuencia copiando todos los elementos de la secuencia original excepto algunos.
La elección de qué elementos incluir en la nueva secuencia puede hacerse mediante una función de predicado (una función que se evalúa como un valor booleano) o mediante la igualdad con un objeto concreto.

## Eliminar mediante un predicado

`remove-if` es una función que toma una función de predicado y una secuencia como argumentos, y devuelve una secuencia con solo aquellos elementos para los que el predicado se evaluó como un valor falso.
En otras palabras, «elimina» todos los elementos de la secuencia para los que el predicado se evalúa como verdadero. No obstante, ¡ten en cuenta que esta función no modifica la secuencia original!
En su lugar, devuelve una nueva secuencia sin los elementos correspondientes. Si el predicado era verdadero para todos los valores, se devuelve una secuencia vacía.

```lisp
(remove-if #'evenp '(1 2 3 4 5)) ; => (1 3 5)
(remove-if #'oddp '(1 3 5))      ; => ()
```

## Conservar elementos mediante un predicado

Existe una función `remove-if-not` que es igual que `remove-if`, salvo que *conserva* el elemento para el que el predicado se evalúa como verdadero.

Como alternativa, se puede usar `complement` para convertir un predicado en su «opuesto».

```lisp
(remove-if #'evenp '(1 2 3 4 5 6))             ; => (1 3 5)
(remove-if-not #'oddp '(1 2 3 4 5 6))          ; => (1 3 5)
(remove-if (complement #'oddp) '(1 2 3 4 5 6)) ; => (1 3 5)
```

## Eliminar un elemento concreto

Si se quiere eliminar un elemento concreto de una secuencia, se puede usar `remove`, que toma el elemento que hay que eliminar y una secuencia.
Se devuelven todos los valores de la secuencia que no son iguales al elemento que se quiere eliminar.

```lisp
(remove 1 '(1 2 1 3 1 4)) ; => (2 3 4)
(remove #\l "hello")      ; => "heo"
```

La función que se usa para la igualdad puede especificarse con el [parámetro de palabra clave][concept-keyword-parameters] `:test`.

Ten en cuenta que `remove` podría implementarse con `remove-if` escribiendo un predicado que compruebe la igualdad de un objeto con un elemento concreto.

## Muchas opciones

Cada una de estas funciones también acepta muchos otros [parámetros de palabra clave][concept-keyword-parameters] que les permiten actuar solo sobre subsecuencias, aplicarse solo un número determinado de veces y otras cosas. Consulta la [documentación de Hyperspec][hyperspec-remove] para ver todos los detalles.


## Opciones destructivas

Además de `remove`, `remove-if` y `remove-if-not`, existen `delete`, `delete-if` y `delete-if-not`, que tienen el mismo efecto, salvo que pueden modificar la secuencia que se les pasa.
