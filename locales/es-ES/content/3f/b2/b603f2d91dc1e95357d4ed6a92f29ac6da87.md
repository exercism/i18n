# Anexo a las instrucciones

## Pistas

Para completar este ejercicio tienes que implementar la función `slices`,
que recibe un *texto* y devuelve las subsecuencias de dígitos con un
tamaño especificado:

Si es la primera vez que resuelves este ejercicio, se recomienda que te
ciñas a la firma proporcionada:

```haskell
slices :: Int -> String -> [[Int]]
```

Más adelante, puede ser buena idea volver sobre este problema y jugar con otros
tipos de datos y bibliotecas:

- `ByteString`, del paquete *bytestring*.
- `Sequence`, del paquete *containers*.
- `Text`, del paquete *text*.
- `Vector`, del paquete *vector*.

El conjunto de pruebas se diseñó intencionadamente para aceptar casi cualquier
firma de tipo que tenga sentido, así que te animamos a que encuentres la que
creas que es la mejor.
