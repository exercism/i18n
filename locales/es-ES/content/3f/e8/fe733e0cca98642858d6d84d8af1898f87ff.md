# Pistas

## 1. Describe números sencillos

- usa `fmt.Sprintf` para formatear

## 2. Describe una caja de números

- obtén el resultado del método `Number()`
- usa `fmt.Sprintf` para formatear

## 3. Implementa un método que extraiga el número de una caja de números sofisticada

- usa una aserción de tipo para comprobar si es un `FancyNumber`
- obtén el `string` del método `Value()`
- usa `strconv.Atoi` para convertir el `string` en un `int` (podemos descartar el error, ya que queremos 0 si no se puede convertir en un `int`)

## 4. Describe una caja de números sofisticada

- usa `ExtractFancyNumber` para obtener el valor `int`
- convierte el `int` en un `float64`
- usa `fmt.Sprintf` para formatear

## 5. Implementa `DescribeAnything`, que los usa todos

- usa aserciones de tipo (p. ej., `i.(someType)`) o un type switch (`switch v := i.(type)`)
- recuerda convertir `int` en un `float64`
