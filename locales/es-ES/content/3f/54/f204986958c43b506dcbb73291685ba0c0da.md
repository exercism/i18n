# Introducción

## Parámetros

Este ejercicio analiza algunos detalles de los parámetros de los métodos y su uso en C#.

Los parámetros transmiten información desde un método que llama hasta un método llamado.

- El comportamiento de los parámetros se puede modificar mediante el uso de modificadores como `ref` y `out`.

- Un parámetro con el modificador `out` transmite un valor de vuelta desde el método llamado al método que llama. El parámetro se puede pasar al método llamado sin que se haya inicializado y, en cualquier caso, dentro del método llamado se trata como si, al entrar, no se hubiera inicializado. La forma más sencilla de comprender el comportamiento y las reglas relativas a los modificadores de parámetros es mediante ejemplos (ver más abajo) y los mensajes del compilador.

```csharp
void Foo(out int val)
{
    val = 42;
}
void Bar(int val)
{
    val = 42;
}

int importantValue = 1729;
Foo(out importantValue);
var result = importantValue == 42;
// => true

importantValue = 1729;
Bar(importantValue);
result = importantValue == 1729;
// => true
```

- Los parámetros `out` deben asignarse dentro de un método llamado.

- Un parámetro con el modificador `ref` pasa un valor a un método llamado. Cuando el método finaliza, el método que llama encontrará en ese parámetro cualquier actualización que haya hecho el método llamado.

```csharp
void Foo(ref int val)
{
    val *= 7;
}

int importantValue = 6;
Foo(ref importantValue);
return importantValue;
// => 42
```

- Los parámetros `ref` deben ser variables, ya que el método llamado operará directamente sobre el parámetro tal como lo ve el método que llama.
- Los modificadores `out` y `ref` son obligatorios tanto en la firma del método llamado como en el lugar de la llamada.
