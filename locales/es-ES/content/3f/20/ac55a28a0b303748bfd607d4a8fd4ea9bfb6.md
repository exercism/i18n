# Introducción

## Funciones anónimas

En Elixir, las funciones se tratan como ciudadanos de primera clase. Esto significa que:

- Las funciones con nombre y las funciones anónimas se pueden asignar a variables.
- Las funciones con nombre y las funciones anónimas se pueden pasar de un sitio a otro como si fueran datos, como argumentos y como valores devueltos.
- Las funciones anónimas se pueden crear de forma dinámica.

Las funciones anónimas, a diferencia de las funciones con nombre, no tienen una referencia estática disponible; solo están disponibles si se asignan a una variable o se invocan inmediatamente.

Podemos usar funciones anónimas para:

- Ocultar datos usando el scope léxico (también conocido como _closure_).
- Crear funciones de forma dinámica en tiempo de ejecución.

Las funciones anónimas empiezan con la palabra reservada `fn`, los argumentos se separan del cuerpo de la función con el token `->` y terminan con un `end`. Al igual que ocurre con las funciones con nombre, la última expresión de la función se _devuelve implícitamente_ a la función que la ha llamado.

Para invocar una referencia a una función, debes usar un `.` entre la variable de referencia y la lista de argumentos:

```elixir
function_variable = fn param ->
  param + 1
end

function_variable.(1)
# => 2
```

Incluso puedes usar la notación abreviada de captura para que esto sea más conciso:

```elixir
variable = &(&1 + 1)

variable.(1)
# => 2
```

## Manipulación de bits

Elixir incluye muchas funciones para trabajar con bits en el _módulo Bitwise_.

- `band/2`: AND a nivel de bits
- `bsl/2`: DESPLAZAMIENTO A LA IZQUIERDA a nivel de bits
- `bsr/2`: DESPLAZAMIENTO A LA DERECHA a nivel de bits
- `bxor/2`: XOR a nivel de bits
- `bor/2`: OR a nivel de bits
- `bnot/1`: NOT a nivel de bits

Aquí tienes un ejemplo de cómo usar una función a nivel de bits:

```elixir
Bitwise.bsl(1, 3)
# => 8
```

Todas las funciones a nivel de bits solo funcionan con números enteros.

Si usas la versión 1.9 de Elixir o una anterior, tendrás que llamar a `require Bitwise` al principio de la definición del módulo para poder usar el _módulo Bitwise_.
