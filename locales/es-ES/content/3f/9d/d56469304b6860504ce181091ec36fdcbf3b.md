# Instrucciones

La dueña de tu pizzería local te ha pedido que la ayudes a calcular los tiempos de cocción de distintas pizzas. En este ejercicio vas a escribir unas cuantas funciones para calcularlo.

Tienes tres tareas.

## 1. Calcular el tiempo de horneado restante en minutos

Define e implementa la función `remainingMinutesInOven()`, que calculará cuántos minutos más tienes que mantener la pizza en el horno.

La función debe aceptar un parámetro **opcional** (con valor predeterminado) para la cantidad de minutos transcurridos desde que empezaste a hornear la pizza. Si no se indica el parámetro, da por hecho que acabas de meter la pizza en el horno y que ya han pasado **0 (cero)** minutos.

Para simplificar, supongamos que todos los tipos de pizza necesitan exactamente 40 minutos en el horno para estar listas.

```kotlin
remainingMinutesInOven()   // => 40

remainingMinutesInOven(10)   // => 30
```

## 2. Calcular el tiempo de preparación en minutos

Antes de hornear la pizza, tienes que preparar la masa, extenderla y ponerle los ingredientes.

Define e implementa la función `preparationTimeInMinutes()`, que calculará cuántos minutos se tardan en preparar la pizza antes de meterla en el horno.

La función debe aceptar un parámetro **obligatorio** (`numberOfIngredientTypes`) para el número de tipos de ingredientes que se van a usar.

Da por hecho que necesitas 5 minutos para hacer y extender la masa y 2 minutos por **cada** tipo de ingrediente.

```kotlin
preparationTimeInMinutes(0) // => 5

preparationTimeInMinutes(1) // => 7
```

## 3. Calcular el tiempo transcurrido en minutos

Define e implementa la función `elapsedCookingTimeInMinutes()`, que calculará cuántos minutos se tardan en preparar, hornear y servir la pizza. Usa las funciones de los pasos anteriores para hacer los cálculos.

La función debe aceptar dos parámetros. El primero es **obligatorio** y es el número de tipos de ingredientes. El segundo es **opcional** y es el tiempo, en minutos, que se tarda en servir la pizza (da por hecho que es 0 si no se indica).

```kotlin
elapsedCookingTimeInMinutes(1)  // => 47

elapsedCookingTimeInMinutes(2, 3)  // => 52
```
