# Introducción

## Clases

La principal construcción orientada a objetos en Java es la _clase_, que es una combinación de datos (_campos_) y comportamiento (_métodos_).
Los campos y los métodos de una clase se conocen como sus _miembros_.

Se puede controlar el acceso a los miembros mediante modificadores de acceso, y los dos más habituales son:

- `public`: cualquier código puede acceder al miembro (sin restricciones).
- `private`: solo puede acceder al miembro el código de la misma clase.

Puedes pensar en una clase como una plantilla para crear instancias de esa clase.
Para crear una instancia de una clase (también conocida como _objeto_), se utiliza la palabra clave `new`:

```java
class Car {
}

// Create two car instances
Car myCar = new Car();
Car yourCar = new Car();
```

Los campos tienen un tipo y un nombre (definido en camelCase) y se pueden definir en cualquier parte de una clase (por convención, en PascalCase):

```java
class Car {
    // Accessible by anyone
    public int weight;

    // Only accessible by code in this class
    private String color;
}
```

Opcionalmente, se puede asignar un valor inicial a un campo.
Si un campo _no_ especifica un valor inicial, se le asignará el valor por defecto de su tipo.
Se puede acceder a los valores de los campos de una instancia y actualizarlos con la notación de punto.

```java
class Car {
    // Will be set to specified value
    public int weight = 2500;

    // Will be set to default value (0)
    public int year;
}

Car newCar = new Car();
newCar.weight; // => 2500
newCar.year;   // => 0

// Update value of the field
newCar.year = 2018;
```

Los campos privados suelen actualizarse como efecto secundario de llamar a un método.
Normalmente, estos métodos no devuelven ningún valor, en cuyo caso el tipo devuelto debe ser `void`:

```java
class CarImporter {
    private int carsImported;

    public void importCars(int numberOfCars)
    {
        // Update private field from public method
        carsImported = carsImported + numberOfCars;
    }
}
```
