# Anexo a las instrucciones

## Instrucciones específicas del track

Si quieres algo un poco diferente, también puedes probar una solución con una función `unfold`.
Seguramente ya conozcas `foldLeft/Right`: «mapean» toda una colección a otra cosa (normalmente a algo que no es una colección).
`unfold` es la operación «inversa»: «mapea» algo (normalmente algo que no es una colección) a una colección.
Así que el `unfold` es una adición lógica al repertorio estándar de la programación funcional, y forma parte de él.

Este ejercicio puede verse como un caso para el `unfold`: «mapear» un `Int` a un `String` (que, por supuesto, es implícitamente un `Seq[Char]`).

Las colecciones de Scala lo incluyen desde la versión 2.13, por ejemplo [`List.unfold`][list] e `Iterator.unfold`.
Recibe un estado inicial y una función que devuelve el siguiente elemento y el siguiente estado, o `None` para detenerse:

```scala
List.unfold(1234)(n => Option.when(n > 0)((n % 10, n / 10)))
// List(4, 3, 2, 1)
```

[list]: https://www.scala-lang.org/api/current/scala/collection/immutable/List$.html
