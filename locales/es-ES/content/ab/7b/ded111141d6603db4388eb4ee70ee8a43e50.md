# Instrucciones

Turno de noche en el muelle de Hull. El carguero *Olwen* está atracado al lado, y una cuadrilla de estibadores trabaja el manifiesto en paralelo. Cada caja debe pesarse antes de subir a bordo, y el capitán de puerto lleva un único **registro de tonelaje** acumulado que cada izado actualiza. El problema: solo hay una grúa en el muelle, así que el registro no puede quedar corrompido porque dos estibadores lo actualicen al mismo tiempo.

Cada caja es un array de pesos de artículos. El peso de una caja es la suma de esos artículos.

## 1. Pesa una caja

Define `weigh-crate` para que reciba una caja y devuelva su peso total. Esto es trabajo secuencial sin más: entra una caja, sale un número.

```factor
{ 12 8 15 } weigh-crate .
! => 35
```

## 2. Pesa todo el manifiesto en paralelo

Define `weigh-all` para que reciba un array de cajas y devuelva el array de sus pesos, en el mismo orden. Usa `parallel-map` para que el trabajo de cada caja se realice de forma concurrente.

```factor
{ { 5 5 } { 10 } { 3 4 5 } } weigh-all .
! => { 10 10 12 }
```

## 3. Construye una grúa nueva

Define `<crane>` para construir una grúa nueva: una tupla con un `<lock>` nuevo y un tonelaje de `0`. La grúa es el recurso compartido que las tareas siguientes protegerán.

```factor
<crane> tonnage>> .
! => 0
```

## 4. Iza una caja al registro acumulado

Define `hoist-crate` para que reciba un `weight` y una `crane` y sume el peso al tonelaje de la grúa **bajo el bloqueo de la grúa**, de modo que la lectura, la suma y la escritura sean atómicas frente a otros estibadores que izan al mismo tiempo.

```factor
<crane>
35 over hoist-crate
17 over hoist-crate
tonnage>> .
! => 52
```

## 5. Lee el tonelaje acumulado

Define `crane-tonnage` para que devuelva el tonelaje actual de la grúa, también bajo el bloqueo, de modo que la lectura no pueda ver un valor corrompido a mitad de un izado.

```factor
<crane>
35 over hoist-crate
crane-tonnage .
! => 35
```

## 6. Carga el cargamento

Define `load-cargo` para que reciba un array de cajas y una grúa y **para cada caja, lance un hilo de estibador** que pese la caja e ice el peso a la grúa. La palabra solo devuelve el control cuando todos los estibadores han terminado. Usa `<promise>` y `?promise` para coordinar la unión.

```factor
<crane> :> crane
{ { 5 5 } { 10 } { 3 4 5 } } crane load-cargo
crane crane-tonnage .
! => 32
```
