# unnötige Bedingungen

In dieser Lösung werden [Bedingungen][conditionals] unnötig verwendet.
Wenn du einen [Standardargument][default argument] zusammen mit [str.format][str.format] oder [f-Strings][f-strings] verwendest (_auch bekannt als „formatted string literals“ oder „interpolated strings“_), kann der Code klarer und weniger ausführlich werden.

Weitere Details findest du in diesem Beitrag über [Standardargumente in Python][python default arguments].
Der Blogbeitrag [String-Formatierung in Python][string formatting in python] kann ebenfalls ein guter Ausgangspunkt sein, um die Formatierungsmöglichkeiten von Python-Strings kennenzulernen.
