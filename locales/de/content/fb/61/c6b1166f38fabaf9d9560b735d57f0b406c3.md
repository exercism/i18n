# Grundlagen der Elm-Syntax 1

## Konstanten und Funktionen

Elm-Programme bestehen aus Definitionen und Ausdrücken.
Alles in Elm ist entweder eine Definition oder ein Ausdruck.

Ein konstanter Wert wird mit `name = expression` definiert.

```elm
five = 5

six = 3 + 3
```

Funktionen werden mit `name parameters... = expression` definiert,
wobei die Parameter nur durch Leerzeichen getrennt werden.

```elm
add number1 number2 = number1 + number2
```

Der Aufruf einer Funktion ist ebenfalls ein Ausdruck. Dabei gibst du den Namen der Funktion an
und übergibst für jeden Parameter der Funktion ein Argument,
durch Leerzeichen getrennt, genau wie bei der Definition einer Funktion.

```elm
five = add 2 3
```

Mit runden Klammern kannst du die Reihenfolge der Auswertung eines Ausdrucks festlegen.

```elm
six = add 2 (1 * 4)

twelve = add 2 1 * 4
```

## Einrückung / signifikante Leerzeichen

Elm verwendet keine syntaktischen Marker wie geschweifte Klammern, runde Klammern oder Semikolons, um Codegrenzen festzulegen. Stattdessen nutzt es Leerzeichen und Einrückungen.

- Definitionen von Modulen, Imports und Funktionen auf oberster Ebene müssen in der am weitesten links stehenden Spalte beginnen.
- Wenn ein Ausdruck auf mehrere Zeilen aufgeteilt wird, muss der Code, der zu diesem Ausdruck gehört, mit mindestens einem Leerzeichen unter diesem Ausdruck eingerückt werden.
- Teile des Ausdrucks, die zusammengehören, sollten mit der gleichen Anzahl an Leerzeichen eingerückt werden.

```elm
-- A function split over multiple lines, so subsequent lines must be indented
add number1 number2 =
    number1 + number2
```

https://elmprogramming.com/indentation.html

## Module

Jede Datei in Elm ist ein Modul und muss vor dem restlichen Code eine `module`-Anweisung enthalten.
Modulnamen müssen zu ihrem Dateinamen passen, das Modul `Calculator` muss also in der Datei Calculator.elm liegen.
Alles, was innerhalb eines Moduls definiert wird, ist privat auf dieses Modul beschränkt
und kann von außerhalb dieses Moduls nicht erreicht werden, es sei denn, es ist in `exposing` aufgeführt.

```elm
-- Define the Calculator module, and expose the `add` function
module Calculator exposing (add)

six = 3 + 3

add number1 number2 = number1 + number2
```

```elm
-- Define the Calculator module, and expose everything within: `six` and `add`
module Calculator exposing (..)

six = 3 + 3

add number1 number2 = number1 + number2
```

https://elm-lang.org/docs/syntax#modules

## Kommentare

Ein Kommentar ist ein Text innerhalb der Elm-Datei, der nicht als Code interpretiert wird.
Er ist hauptsächlich dafür gedacht, von dir und anderen Programmierern gelesen zu werden.
Für einzeilige Kommentare gibt es eine einfache Syntax, die auf doppelten Bindestrichen basiert.
Mehrzeilige Kommentare sind ebenfalls möglich, mit dem Paar `{-` und `-}`
aus öffnendem und schließendem Begrenzer.

```elm
-- a single line comment
-- another single line comment

{- a multiline comment
   spawning multiple lines
-}
```
