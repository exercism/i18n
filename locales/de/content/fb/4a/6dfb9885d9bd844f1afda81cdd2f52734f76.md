# Anleitung

Schreibe für eine Zahl von 0 bis 999.999.999.999 die englische Schreibweise aus.

## Schritt 1

Behandle den einfachen Fall von 0 bis 99.

Wenn die Eingabe des Programms `22` ist, dann sollte die Ausgabe `'twenty-two'` sein.

Dein Programm sollte sich lautstark beschweren, wenn es eine Zahl außerhalb des zulässigen Bereichs bekommt.

Einige gute Testfälle für dieses Programm sind:

- 0
- 14
- 50
- 98
- -1
- 100

### Erweiterung

Wenn du einen Mac benutzt, rufe über die Kommandozeile das `say`-Programm von Mac OS X auf, um laut zu sprechen.
Wenn du Linux oder Windows benutzt, ist eSpeakNG vielleicht mit dem Befehl `espeak` verfügbar.

## Schritt 2

Implementiere das Zerlegen einer Zahl in Tausenderblöcke.

So sollte `1234567890` eine Liste wie 1, 234, 567 und 890 ergeben, während das viel einfachere `1000` nur 1 und 0 ergeben sollte.

Das Programm muss außerdem alle Werte melden, die außerhalb des Bereichs liegen.

## Schritt 3

Jetzt fügst du das passende Wort für die Größenordnung zwischen diesen Blöcken ein.

So sollte `1234567890` `'1 billion 234 million 567 thousand 890'` ergeben.

Das Programm muss außerdem alle Werte melden, die außerhalb des Bereichs liegen.
Es ist in Ordnung, bei „trillion“ aufzuhören.

## Schritt 4

Setze alles zusammen, sodass am Ende nur einfaches Englisch steht.

`12345` sollte `twelve thousand three hundred forty-five` ergeben.

Das Programm muss außerdem alle Werte melden, die außerhalb des Bereichs liegen.
