# Ergänzende Anweisungen

## Hinweise

Diese Übung arbeitet mit Textdaten. Aus historischen Gründen ist der Typ `String` in Haskell gleichbedeutend mit `[Char]`, einer Liste von Zeichen. Für einen effizienteren Umgang mit Textdaten kannst du den Typ `Text` verwenden.

Als optionale Erweiterung dieser Übung kannst du

- etwas über [String-Typen](https://haskell-lang.org/tutorial/string-types) in Haskell lesen.
- `- text` zu deiner Liste der Abhängigkeiten in package.yaml hinzufügen.
- `Data.Text` auf [die folgende Weise](https://hackernoon.com/4-steps-to-a-better-imports-list-in-haskell-43a3d868273c) importieren:

        import qualified Data.Text as T
        import           Data.Text (Text)

- jetzt zum Beispiel `transform :: Map Int Text -> Map Char Int` schreiben und `Data.Text`-Kombinatoren zum Beispiel als `T.toLower` verwenden.
- die Dokumentation für [`Data.Text`](https://hackage.haskell.org/package/text/docs/Data-Text.html) nachschlagen.

Dieser Teil ist völlig optional.
