# Anweisungen

In dieser Übung verarbeitest du Log-Zeilen.

Jede Log-Zeile ist ein String mit folgendem Format: `"[<LEVEL>]: <MESSAGE>"`.

Es gibt drei verschiedene Log-Level:

- `INFO`
- `WARNING`
- `ERROR`

Du hast mehrere Aufgaben. Bei jeder bekommst du eine Log-Zeile und sollst etwas mit ihr machen.

## 1. Den String nach einem bestimmten Teilstring abrufen

Wenn du dir die Logs des letzten Monats anschaust, siehst du, dass die Testnachricht immer nach einem bestimmten Teilstring steht. Da du damit rechnest, die Testnachricht in naher Zukunft extrahieren zu müssen, entscheidest du dich, eine Hilfsmethode zu erstellen, die dir dabei hilft.

Implementiere die (_static_) Erweiterungsmethode `LogAnalysis.SubstringAfter()`, die ein String-Trennzeichen entgegennimmt und den Teilstring nach dem Trennzeichen zurückgibt.

```csharp
var log = "[INFO]: File Deleted.";
log.SubstringAfter(": "); // => returns "File Deleted."
```

## 2. Den String zwischen zwei Teilstrings abrufen

Bei genauerem Hinsehen siehst du, dass der Log-Level immer zwischen eckigen Klammern (`[` und `]`) steht. Da du auch damit rechnest, den Log-Level in naher Zukunft extrahieren zu müssen, entscheidest du dich, eine weitere Hilfsmethode zu erstellen, die dir dabei hilft.

Implementiere die (_static_) Erweiterungsmethode `LogAnalysis.SubstringBetween()`, die zwei String-Trennzeichen entgegennimmt und den Teilstring zurückgibt, der zwischen den beiden Trennzeichen liegt.

```csharp
var log = "[INFO]: File Deleted.";
log.SubstringBetween("[", "]"); // => returns "INFO"
```

## 3. Die Nachricht in einem Log parsen

Implementiere die (_static_) Erweiterungsmethode `LogAnalysis.Message()`, die die in einem Log enthaltene Nachricht zurückgibt.

```csharp
var log = "[ERROR]: Missing ; on line 20.";
log.Message(); // => returns "Missing ; on line 20."
```

## 4. Den Log-Level in einem Log parsen

Implementiere die (_static_) Erweiterungsmethode `LogAnalysis.LogLevel()`, die den Log-Level eines Logs zurückgibt.

```csharp
var log = "[ERROR]: Missing ; on line 20.";
log.LogLevel(); // => returns "ERROR"
```
