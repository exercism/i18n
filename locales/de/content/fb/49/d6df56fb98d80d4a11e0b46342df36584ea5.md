# Über

Die `guard`-Anweisung in Swift wird für frühe Rückgaben aus Swift-Funktionen verwendet, wenn eine notwendige Bedingung nicht erfüllt ist, die für die weitere Verarbeitung erfüllt sein muss, z. B.:

```swift
guard myValue = 0 else { return 0 }
let root = myValue.squareRoot()
```

Hier prüft die `guard`-Anweisung, ob der boolesche Ausdruck nach dem Schlüsselwort `guard` zu wahr ausgewertet wird. Ist das der Fall, läuft die Verarbeitung mit dem Code nach der `guard`-Anweisung weiter (hier `let root = myValue.squareRoot()`). Andernfalls wird der Code im else-Zweig ausgeführt. Anders als eine `if`-Anweisung _muss_ eine `guard`-Anweisung einen else-Zweig haben, und anders als der else-Zweig eines if-else _muss_ der else-Zweig eines guard den Gültigkeitsbereich der `guard`-Anweisung verlassen. Das heißt, er muss eine Kontrollflussanweisung wie `return`, `continue` oder `break` verwenden, oder er muss einen Fehler auslösen oder das Programm beenden.

Ein Beispiel für ihre Verwendung ist die sinc-Funktion, die gleich sin(x)/x ist, wobei sinc(0) als 1 definiert ist, um Probleme mit der Division durch 0 zu vermeiden. Diese Funktion lässt sich in Swift mit einer `guard`-Anweisung so schreiben:

```swift
func sinc(_ x: Double) -> Double {
    guard x != 0 else { return 1 }
    return sin(x) / x
}

sinc(0)              // returns 1
sinc(Double.pi / 2)  // returns 0.6366197723675814
```
