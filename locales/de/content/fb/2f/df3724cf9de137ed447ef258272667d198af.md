Die öffentliche Schnittstelle einer Codebasis sollte gut durchdacht sein, denn jede öffentliche Funktion erhöht die langfristigen Wartungskosten und macht das Refactoring schwieriger.

In jeder Übung auf Exercism wird die öffentliche Schnittstelle von der Testsuite festgelegt.
Wenn eine Funktion getestet wird, muss sie öffentlich sein.
Alle anderen Funktionen sollten privat sein, auch Funktionen mit demselben Namen, aber unterschiedlicher Stelligkeit.

```elixir
# you defined the following public function

%{actual}

# make it private like this

%{expected}
```
Beachte, dass Standardargumente die Stelligkeit einer Funktion verändern.

Wenn du eine Bibliothek schreibst, ist es oft nötig, Funktionen öffentlich zu machen, damit sie modulübergreifend verwendet werden können.
Um solche Funktionen aus der Dokumentation herauszuhalten, fügst du `@doc false` vor den Funktionsdefinitionen ein oder `@moduledoc false`, um das ganze Modul auszublenden.
