# Über

Kotlin wurde von JetBrains entworfen und entwickelt, dem Unternehmen hinter IntelliJ.
Es ist eine Sprache, die auf der JVM läuft und Versionen ab 6 ansprechen kann (einschließlich der [Android-Plattform](https://blog.jetbrains.com/kotlin/2017/05/kotlin-on-android-now-official/)).
JetBrains wollte eine statisch typisierte Sprache einsetzen, die Boilerplate-Code in Java beseitigt, moderne funktionale Paradigmen bietet und nahtlos in beide Richtungen mit Java und der bestehenden Codebasis zusammenarbeitet.
Die JVM hatte bereits Alternativsprachen wie Groovy und Scala, aber keine von beiden erfüllte die gewünschten Kriterien, also entwickelten sie Kotlin.

Die Syntax von Kotlin ähnelt der von Scala und Swift, übernimmt aber die besten Features aus anderen Sprachen wie
C# und Groovy.
Bei den Features, die in die Sprache aufgenommen wurden, ging Kotlin pragmatisch vor und bot nur Funktionalität, die
sich für Entwickler als nützlich erwiesen hat.
Mit dieser Entscheidung implementierten sie eine Teilmenge der Features von Scala, in der Absicht, dass sie besser wartbaren Code und eine flachere Lernkurve für Entwickler bietet, die ein „besseres Java“ suchen.

JetBrains hat ein eigenes Entwicklerteam, das an Kotlin arbeitet; die Codebasis ist auf [GitHub](https://github.com/JetBrains/kotlin) verfügbar.
