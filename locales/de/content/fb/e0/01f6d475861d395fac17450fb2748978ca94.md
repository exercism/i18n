# Einführung

In Swift kannst du einen String nicht mit einer Ganzzahl indexieren (etwa `string[3]`). Da Swift-Strings aus Unicode-Zeichen mit variabler Länge bestehen, musst du die vorhergehenden Zeichen durchlaufen, um ein Zeichen zu finden.

Um auf ein Zeichen an einer bestimmten Position zuzugreifen, musst du einen Index vom Typ `String.Index` berechnen. Solche Indizes heißen *opake Indizes*, weil ihre interne Struktur von Swift verwaltet wird, statt dass du sie direkt als rohe Ganzzahlen manipulierst:

```swift
let csv = "apple,pear,peach,orange,cherry,lime,gooseberry"
let index = csv.index(csv.startIndex, offsetBy: 21)
print(csv[index])
// Prints "g"

print(index)
// Prints internal representation: Index(_rawBits: ...)
```
