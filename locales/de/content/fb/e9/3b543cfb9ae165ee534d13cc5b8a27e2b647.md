# Anleitung

Du hast plötzlich Lust auf Pfannkuchen.
Als moderner, technisch interessierter Mensch schreibst du eine Einkaufsliste für Pfannkuchen-Zutaten im JSON-Format.
Die Struktur der Liste sieht so aus:

```json
{
  "name": "name of shopping list",
  "ingredients": [ ...list of ingredients... ],
  "optional ingredients": [ ...list of ingredients... ]
}
```

Eine Zutat wird als JSON-Objekt dargestellt, etwa so:

```json
{
  "item": "flour",
  "amount": {
    "quantity": 2,
    "unit": "cup"
  }
}
```

Eine Zutat hat eine optionale Eigenschaft namens `"substitute"`, die einen String mit einem anderen Element enthält, das stattdessen verwendet werden kann.

Schauen wir uns an, wie wir die Einkaufsliste mit `jq` untersuchen können.

## 1. Extrahiere den Namen der Einkaufsliste

Schreibe einen Ausdruck, der das Element "name" der Einkaufsliste ausgibt.

## 2. Zähle, wie viele Zutaten benötigt werden

Zähle nur die benötigten Zutaten. Die optionalen Zutaten zählst du nicht mit.

## 3. Wie viel Zucker?

Schreibe einen Ausdruck, der die Menge Zucker ausgibt.
Gewünscht ist nur der numerische Teil.

## 4. Bilde die Zutaten ab, die ersetzt werden können

Einige Zutaten können ersetzt werden (wenn du Zutat X nicht hast, kannst du Y verwenden).
Gib ein JSON-Objekt aus, das die empfohlene Zutat auf ihren Ersatz abbildet.
Nimm die optionalen Zutaten in die Abbildung mit auf.
