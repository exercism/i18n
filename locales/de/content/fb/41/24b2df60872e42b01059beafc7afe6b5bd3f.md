# Einleitung

So wie ein Zeiger auf ein `int` oder einen anderen grundlegenden Datentyp zeigen kann, kann ein Zeiger auf eine Funktion zeigen.
Ein Funktionszeiger kann verwendet werden, um eine Funktion an eine andere Funktion zu übergeben.
Eine Funktion, die als Parameterwert an eine andere Funktion übergeben wird, heißt First-Class-Funktion.
Eine Funktion, die eine oder mehrere Funktionen als Parameter nimmt oder eine Funktion zurückgibt, heißt Funktion höherer Ordnung.

Im folgenden Beispiel sind `is_even` und `is_odd` First-Class-Funktionen.
Die Funktion höherer Ordnung ist `test_number`.

```c
#include <stdio.h>
#include <stdbool.h>

bool is_even (int number) {
    return number & 1 != 1;
}

bool is_odd (int number) {
    return number & 1 == 1;
}

// this function takes any other function which takes a number and returns a bool
void test_number(bool (*func) (int), int number, char *text){
    printf(text, number, func(number)? "true": "false");
}

int main() {
    // prints Testing odd for 3 is true
    test_number(is_odd, 3,"Testing odd for %d is %s\n");
    // prints Testing even for 3 is false
    test_number(is_even, 3,"Testing even for %d is %s\n");
}
```
Die Funktionssignatur `bool (*func) (int)` für das erste Argument von `test_number` passt zur Signatur der übergebenen Funktionen.
Sowohl `is_even` als auch `is_odd` nehmen einen Parameter vom Typ `int` und geben einen Wert vom Typ `bool` zurück.
In `(*func)` steht `func` für den Namen der Funktion, die verwendet werden soll.
Wäre `(*fn)` verwendet worden, dann wäre es so aufgerufen worden: `printf(text, number, fn(number)? "true": "false");`.
Um den Parameter für den Funktionszeiger zu erfüllen, übergeben wir beim Aufruf von `test_number` den Namen einer Funktion mit der erwarteten Signatur.
Wir sehen also, dass ein Funktionsname auf die Adresse dieser benannten Funktion zeigt.
