# Über

Filtern ist der Prozess, aus einer Sequenz eine neue Sequenz zu erzeugen, indem man alle Elemente bis auf bestimmte aus der ursprünglichen Sequenz kopiert.
Die Auswahl, welche Elemente in die neue Sequenz aufgenommen werden, kann durch eine Prädikatfunktion erfolgen (eine Funktion, die zu einem booleschen Wert auswertet) oder durch Gleichheit mit einem bestimmten Objekt.

## Entfernen mit einem Prädikat

`remove-if` ist eine Funktion, die eine Prädikatfunktion und eine Sequenz als Argumente entgegennimmt und eine Sequenz zurückgibt, die nur die Elemente enthält, für die das Prädikat zu einem falschen Wert ausgewertet hat.
In anderen Worten: Sie „entfernt" alle Elemente der Sequenz, für die das Prädikat zu wahr auswertet. Beachte jedoch, dass diese Funktion die ursprüngliche Sequenz nicht verändert!
Stattdessen gibt sie eine neue Sequenz ohne die entsprechenden Elemente zurück. Wenn das Prädikat für alle Werte wahr war, wird eine leere Sequenz zurückgegeben.

```lisp
(remove-if #'evenp '(1 2 3 4 5)) ; => (1 3 5)
(remove-if #'oddp '(1 3 5))      ; => ()
```

## Elemente mit einem Prädikat behalten

Es gibt eine Funktion `remove-if-not`, die genau wie `remove-if` ist, außer dass sie das Element *behält*, für das das Prädikat zu wahr auswertet.

Alternativ kannst du `complement` verwenden, um ein Prädikat in sein ‚Gegenteil' zu verwandeln.

```lisp
(remove-if #'evenp '(1 2 3 4 5 6))             ; => (1 3 5)
(remove-if-not #'oddp '(1 2 3 4 5 6))          ; => (1 3 5)
(remove-if (complement #'oddp) '(1 2 3 4 5 6)) ; => (1 3 5)
```

## Ein bestimmtes Element entfernen

Wenn du ein bestimmtes Element aus einer Sequenz entfernen möchtest, kannst du `remove` verwenden, das das zu entfernende Element und eine Sequenz entgegennimmt.
Alle Werte in der Sequenz, die nicht gleich dem zu entfernenden Element sind, werden zurückgegeben.

```lisp
(remove 1 '(1 2 1 3 1 4)) ; => (2 3 4)
(remove #\l "hello")      ; => "heo"
```

Die Funktion, die für den Gleichheitsvergleich verwendet werden soll, kann mit dem [Keyword-Parameter][concept-keyword-parameters] `:test` angegeben werden.

Beachte, dass `remove` mit `remove-if` implementiert werden könnte, indem du ein Prädikat schreibst, das ein Objekt auf Gleichheit mit einem bestimmten Element prüft.

## Viele Optionen

Jede dieser Funktionen nimmt außerdem viele weitere [Keyword-Parameter][concept-keyword-parameters] entgegen, mit denen sie nur auf Teilsequenzen arbeiten, nur eine bestimmte Anzahl von Malen angewendet werden können und anderes mehr. Die vollständigen Details findest du in der [Hyperspec-Dokumentation][hyperspec-remove].


## Destruktive Optionen

Zusätzlich zu `remove`, `remove-if` und `remove-if-not` gibt es `delete`, `delete-if` und `delete-if-not`, die die gleiche Wirkung haben, außer dass sie die ihnen übergebene Sequenz verändern können.
