# Anweisungen

In dieser Übung schreibst du Code, mit dem ein Freelancer mit einem Projektmanager kommuniziert: ein paar Hilfsfunktionen, mit denen sich Tages- und Monatssätze schnell berechnen lassen, optional mit einem vorgegebenen Rabatt.

Zuerst legen wir ein paar Regeln zwischen dem Freelancer und dem Projektmanager fest:

- Der Tagessatz ist 8-mal der Stundensatz.
- Ein Monat hat 22 abrechenbare Tage.

Manchmal bietet der Freelancer an, einen Rabatt auf seinen Tagessatz zu gewähren (zum Beispiel für seine treuesten Kunden oder für gemeinnützige Kunden).

Rabatte werden als Zahlen mit Nachkommastellen angegeben, die einen Prozentsatz darstellen, zum Beispiel `25.0` (25 %).

## 1. Tagessatz aus einem Stundensatz berechnen

Implementiere eine Funktion, die den Tagessatz aus einem Stundensatz berechnet:

```haskell
dailyRate 60
-- -> 480.0
```

Der zurückgegebene Tagessatz sollte ein Double sein.

## 2. Preis nach Rabatt berechnen

Implementiere eine Funktion, die den Preis nach Abzug eines Rabatts berechnet:

```haskell
applyDiscount 150 10
-- -> 135.0
```

Der zurückgegebene Wert sollte immer ein Double sein und auf keinen Fall gerundet werden.

## 3. Monatssatz aus Stundensatz und Rabatt berechnen

Implementiere eine Funktion, die den Monatssatz berechnet und einen Rabatt anwendet:

```haskell
monthlyRate 77 10.5
-- -> 12130
```

Der zurückgegebene Monatssatz sollte auf die nächste Ganzzahl aufgerundet werden (Ceiling).

## 4. Anzahl der Arbeitstage aus Budget, Stundensatz und Rabatt berechnen

Implementiere eine Funktion, die ein Budget, einen Stundensatz und einen Rabatt entgegennimmt und berechnet, wie viele Arbeitstage damit abgedeckt sind.

```haskell
daysInBudget 20000 80 11.0
-- -> 35.1
```

Die zurückgegebene Anzahl an Tagen sollte auf eine Nachkommastelle abgerundet werden (Floor).
