# Über

Tcl, ausgesprochen „tickle“ und die Kurzform von Tool Command Language, ist eine dynamische Open-Source-Programmiersprache.

Sie wurde mit dem Ziel entworfen, sehr einfach und trotzdem mächtig zu sein.
Sie ist so einfach, dass die gesamte Syntax in [nur 12 Regeln][rules] vollständig beschrieben wird.
Trotzdem ist sie eine vollwertige Programmiersprache.

Tcl fasst alles in *Befehlen* zusammen, sogar Variablenzuweisungen, Prozedurdefinitionen und Kontrollfluss.
Dadurch ähnelt sie sowohl Shell-Skripting als auch Lisp.

Tcl unterstützt mehrere Programmierparadigmen, darunter objektorientierte, imperative und funktionale Stile.
Die häufigsten Einsatzgebiete von Tcl sind eingebettete Skript-Laufzeitumgebungen in C-Anwendungen und das Prototyping von GUIs mit dem Tk-GUI-Toolkit.
