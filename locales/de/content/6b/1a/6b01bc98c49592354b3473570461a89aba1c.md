# Überblick

## Module

Gleam-Code ist in Module organisiert, und jede Datei ist ein Gleam-Modul.

Bisher haben wir Funktionen mit der `pub fn`-Syntax geschrieben, die eine Funktion definiert, die für andere Module öffentlich verfügbar ist. Mit `fn` definierte Funktionen sind privat für das Modul, in dem sie definiert sind, und können nicht von anderen Modulen verwendet werden.

```gleam
// This function is public
pub fn add(x, y) {
  x + y
}

// This function is private
fn subtract(x, y) {
  x - y
}
```

Gleam-Module haben Namen, und der Name basiert auf ihrem Dateipfad innerhalb des `src`- oder `test`-Verzeichnisses.

Zum Beispiel würde ein Modul, das in `src\geometry\rectangle.gleam` (unter Windows) oder `src/geometry/rectangle.gleam` (auf UNIX-ähnlichen Betriebssystemen) definiert ist, `geometry/rectangle` heißen.

## Funktionen aus anderen Modulen importieren

Der Zugriff auf Funktionen, die in anderen Modulen definiert sind, erfolgt über Importe. Alle Funktionen innerhalb dieses Moduls, die von ihm bereitgestellt wurden, werden beim Importieren dieses Moduls zugänglich. Wie auf sie zugegriffen wird, hängt jedoch davon ab, wie das Modul importiert wird.

Qualifizierte Importe sind der Standard, und der Zugriff auf eine Funktion in einem solchen Modul (zum Beispiel die Funktion `map` im Modul `gleam/list`) erfolgt durch Voranstellen des Modulnamens (`list.map`).

```gleam
// Import the int module
import gleam/int

pub fn run(x: Int) -> String {
  // Use the to_string function from the int module
  int.to_string(x)
}
```

Standardmäßig ist der Name, der zum Verweisen auf das Modul verwendet wird, der letzte Teil des Modulnamens, in diesem Fall `int`, aber dies kann mit dem Schlüsselwort `as` geändert werden.

```gleam
// Import the int module and refer to it as i
import gleam/int as i

pub fn run(x: Int) -> String {
  i.to_string(x)
}
```

Unqualifizierte Importe ermöglichen den direkten Zugriff auf die bereitgestellten Funktionen in diesem Modul, ohne Voranstellen.

```gleam
// Import the to_string function from the int module
import gleam/int.{to_string}

pub fn run(x: Int) -> String {
  to_string(x)
}
```

Qualifizierte Importe werden bevorzugt, da sie dem Leser klarer zeigen, woher eine Funktion stammt, und Namenskonflikte vermeiden.
