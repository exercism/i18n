# Tests

Wenn du eine Übung mit dem Kommandozeilen-Tool heruntergeladen hast, solltest du eine Futhark-Datei sehen, die nach der Übung benannt ist, sowie eine Datei namens `test.fut`.
Diese Datei enthält alle Testfälle, und zwar dieselben, die der Test-Runner ausführt, wenn du deine Lösung hochlädst.
Du kannst gerne zusätzliche Testfälle zum Ausprobieren hinzufügen.
Das Ändern von Tests wirkt sich jedoch nicht auf den Online-Testlauf aus.

## Lokales Testen

Um die Tests einer Übung auszuführen, öffne ein Terminal im Verzeichnis der Übung und führe den Befehl `futhark test test.fut` (oder `exercism test`) aus.
