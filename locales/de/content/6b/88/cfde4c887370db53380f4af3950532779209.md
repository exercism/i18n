# Einführung

Unison stellt die Werte wahr und falsch mit dem Typ `Boolean` dar. Es gibt nur zwei Werte: `true` und `false`.

```unison
trueVariable = true
falseVariable = false
```

Boolesche Ausdrücke werten wir mit den Operatoren und (`&&`), oder (`||`) und nicht (`not`) aus.

```unison
trueVariable = true && true
falseVariable = true && false

trueVariable = false || true
falseVariable = false || false

trueVariable = not false
falseVariable = not true
```
