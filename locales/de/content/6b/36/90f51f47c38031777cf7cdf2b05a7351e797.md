# Über

Boolesche Werte werden in F# durch den Typ `bool` dargestellt, dessen Werte entweder `true` oder `false` sein können.

F# unterstützt drei [boolesche Operatoren][operators]: `not` (NOT), `&&` (AND) und `||` (OR). Die Operatoren `&&` und `||` verwenden _Kurzschlussauswertung_. Das heißt, die rechte Seite des Operators wird nur ausgewertet, wenn sie benötigt wird.

```fsharp
true || false // => true
true && false // => false
```

Die drei booleschen Operatoren haben jeweils eine unterschiedliche [_Operatorrangfolge_][precedence]. Deshalb werden sie in dieser Reihenfolge ausgewertet: zuerst `not`, dann `&&` und schließlich `||`. Wenn du diese Regeln „umgehen“ möchtest, kannst du einen booleschen Ausdruck in runde Klammern (`()`) setzen, denn die Klammern haben eine noch höhere Operatorrangfolge.

```fsharp
not true && false   // => false
not (true && false) // => true
```

[precedence]: https://docs.microsoft.com/en-us/dotnet/fsharp/language-reference/symbol-and-operator-reference/#operator-precedence
