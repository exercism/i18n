# Anleitung

In dieser Übung implementierst du eine Teilmenge von Hilfsroutinen, die einem Entwickler helfen, SqueakyClean-Namen zu bereinigen.

In den 4 Aufgaben baust du nach und nach die Methode `clean` auf.
Ein gültiger SqueakyClean-Name besteht aus null oder mehr Buchstaben und Unterstrichen.

In allen Fällen ist garantiert, dass der übergebene String nicht null ist. Beachte, dass die Methode `clean` einen leeren String als gültig behandeln sollte.

## 1. Ersetze alle vorkommenden Leerzeichen durch Unterstriche

Implementiere die (_statische_) Methode `SqueakyClean.clean()`, um alle Leerzeichen durch Unterstriche zu ersetzen. Das gilt auch für führende und nachfolgende Leerzeichen.

```java
SqueakyClean.clean("my   Id");
// => "my___Id"
```

## 2. Wandle Kebab-Case in camelCase um

Ändere die (_statische_) Methode `SqueakyClean.clean()`, um Kebab-Case in camelCase umzuwandeln.

```java
SqueakyClean.clean("a-bc");
// => "aBc"
```

## 3. Wandle Leetspeak in normalen Text um

Ändere die (_statische_) Methode `SqueakyClean.clean()`, um [Leetspeak][leet-speak] in normalen Text umzuwandeln.

Der Einfachheit halber ersetzen wir nur `4`, `3`, `0`, `1` und `7` durch `a`, `e`, `o`, `l` bzw. `t`.

```java
SqueakyClean.clean("H3ll0 W0rld");
// => "Hello_World"
SqueakyClean.clean("4 73s7");
// => "a_test"
```

## 4. Lasse Zeichen weg, die keine Buchstaben sind

Ändere die (_statische_) Methode `SqueakyClean.clean()`, um alle Zeichen wegzulassen, die keine Buchstaben sind.

```java
SqueakyClean.clean("a$#.b");
// => "ab"
```

[leet-speak]: https://en.wikipedia.org/wiki/Leet
