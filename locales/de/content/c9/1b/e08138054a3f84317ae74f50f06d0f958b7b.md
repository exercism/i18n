# Tests

## Tests ausführen

Um die Tests auszuführen, führe den folgenden Befehl aus:

```bash
dotnet test
```

Um die Tests automatisch auszuführen, sobald eine Quelldatei geändert wird, führe den folgenden Befehl aus:

```bash
dotnet watch test
```

## Die Übung lösen

Eine Übung zu lösen bedeutet, alle ihre Tests zu bestehen. Standardmäßig wird nur ein Test (der erste) ausgeführt, wenn du die Tests startest. Das ist Absicht, denn so kannst du dich ganz darauf konzentrieren, diesen einen Test zu bestehen. Sobald er bestanden ist, kannst du den nächsten Test aktivieren, indem du `Skip = "Remove this Skip property to run this test"` aus dem `[Fact]`- oder `[Theory]`-Attribut des Tests entfernst. Wenn alle Tests aktiviert sind und deine Implementierung sie alle besteht, hast du die Übung gelöst!

Damit du leichter loslegen kannst, bringt jede Übung eine Stub-Implementierungsdatei mit. Du kannst diese Datei als Ausgangspunkt verwenden, um deine Lösung aufzubauen. Du kannst diese Datei gerne löschen oder ändern, wenn du das für richtig hältst.

## Pakete verwenden

Die meisten Übungen solltest du lösen können, ohne externe Pakete zu verwenden. Wenn du bei einzelnen Übungen aber doch ein externes Paket verwenden möchtest, kannst du es mit dem folgenden Befehl zu deinem Projekt hinzufügen:

```bash
dotnet add package [package-name]
```
