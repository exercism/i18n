## Importieren

Ein Modul wird üblicherweise mit dem Schlüsselwort `use` geladen.
Dabei wird es geladen und seine `import`-Methode aufgerufen, wodurch alle exportierten Symbole importiert werden.

Symbole im `@EXPORT`-Array des Pakets werden standardmäßig importiert.
Symbole im `@EXPORT_OK`-Array des Pakets müssen explizit importiert werden.

Vor Perl `v5.37` musste ein Modul mit einem wahren Wert enden (üblicherweise `1`), um anzuzeigen, dass es erfolgreich geladen wurde.
Bei Verwendung des Features [`module_true`][module_true] ist das nicht nötig.

## Exportieren

Damit ein Symbol importiert werden kann, muss es zuerst exportiert werden.
Das Modul [Exporter][Exporter] ist Teil von Perl und eine der bequemsten Möglichkeiten zum Exportieren.

Das Modul definieren:
```perl
package Foo;

use Exporter ('import');
our @EXPORT_OK = ('bar');

sub bar { ... }
```

Das Modul verwenden:
```perl
use Foo ('bar');

bar();
```

## Pragma

Ein Pragma ist ein Modul, das einen bestimmten Aspekt des Verhaltens von Perl beeinflusst.

Die Pragmas [`strict`][strict] und [`warnings`][warnings] werden häufig empfohlen, um unsichere Konstrukte einzuschränken bzw. auf mögliche Probleme hinzuweisen.
Das Pragma `strict` wird zusammen mit `use v5.12` oder höher aktiviert.
Das Pragma `warnings` wird zusammen mit `use v5.35` oder höher aktiviert.

Mit dem Pragma [`feature`][feature] kannst du neuere und experimentelle Perl-Features aktivieren.
Wenn dem Schlüsselwort `use` eine bestimmte Perl-Version angegeben wird, aktiviert es das Feature-Bundle für diese Version.

## Kernmodule

Neben [Exporter][Exporter] bietet Perl eine große Auswahl an [Kernmodulen][perl-core-modules], die du verwenden kannst.
Einige Beispiele, die für Übungen hier nützlich sein können, sind [List::Util][List::Util], [Time::Piece][Time::Piece] und [Math::BigRat][Math::BigRat].

## CPAN

Zusätzlich zu den Kernmodulen bietet [CPAN][metacpan] Tausende weiterer Module, die von der Perl-Community erstellt wurden und sich installieren lassen.
Der Perl-Track verwendet eine [cpanfile][test-runner-cpanfile], um eine Auswahl von Modulen zu installieren, die mit dem Perl-Test-Runner von Exercism genutzt werden können.
