# Implizites Includes verwenden

Entferne die explizite Existenzprüfung mit `.includes`. Wenn die Farbe (der String als Eingabe) in einen Code umgewandelt wird (die Zahl `colorCode`), gibt es bereits einen speziellen Wert, der zurückgegeben wird, wenn die Farbe nicht vorhanden ist. Suche diesen Wert und verwende ihn stattdessen.
