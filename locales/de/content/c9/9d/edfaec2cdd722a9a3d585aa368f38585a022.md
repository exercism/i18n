# Über

Common Lisp verwendet für die meisten Operationen die üblichen arithmetischen Operatoren, ist aber insofern etwas Besonderes, als es die „Präfixnotation“ statt der geläufigeren „Infixnotation“ verwendet.

Anschaulicher:

```lisp
;; Infix-notation (non-lisp languages)
1 + 2 + 3 + 4 + 5 ; => 15
;; Prefix-notation (lisp languages)
(+ 1 2 3 4 5)     ; => 15
```

Die Präfixnotation macht zwar aus manchen Operationen wie `2 + 2` die etwas ungewohnte Form `(+ 2 2)`, dafür ist es aber viel einfacher, mit mehr als einer Zahl gleichzeitig zu arbeiten.

## Arithmetische Operatoren mit einem einzigen Argument

Als kleine Eigenheit haben die Operatoren `-` und `/` eine besondere Bedeutung, wenn sie auf nur eine Zahl angewendet werden:

```lisp
;; A single number passed to `-` is simply negated
(- 4)   ; => -4
(- -32) ; => 32
;; A single number passed to `/` returns the reciprocal
(/ 8)   ; => 1/8
(/ 0.1) ; => 10.0
```

## Zahlen vergleichen

Schließlich kann es nützlich sein, verschiedene Zahlen mit Funktionen wie `=` (gleich), `/=` (ungleich) und `>=` (größer oder gleich) zu vergleichen.
Wenn diese Vergleiche wahr sind (wie in `(= 1 1)`), geben sie `T` zurück, und wenn sie es nicht sind (wie in `(> 0 1)`), geben sie `NIL` zurück.

## Numerische Prädikate

Die Sprache enthält außerdem einige nützliche Prädikate wie `zerop`, `evenp` und `oddp`, die die offensichtlichen Bedingungen prüfen.

## Referenz

```lisp
;; Addition
(+ 1 2 3 4 5) ; => 15

;; Subtraction
(- 15 3 2)    ; => 10
(- 42)        ; => -42

;; Multiplication
(* 4 3 2 1)   ; => 24

;; Division
(/ 64 16 2)   ; => 2
(/ 5)         ; => 1/5

;; Exponentiation
(expt 2 8)    ; => 256

;; Square Root
(sqrt 25)     ; => 25

;; Modulo (Similar to remainder)
(mod 10 3)    ; => 1

;; Equality
(= 2 2)       ; => T
(= 3 5)       ; => NIL
```
