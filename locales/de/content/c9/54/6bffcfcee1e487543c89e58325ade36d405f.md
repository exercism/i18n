# Installation

Folge den Anweisungen für dein System auf der Installationsseite unter [golang.org](http://golang.org/doc/install).

## Go-Version

Dieser Track verwendet Go 1.26.

Eine ältere Version von Go kannst du verwenden, indem du die `go.mod`-Datei der jeweiligen Übung änderst und die Zeile `go 1.26` anpasst.
Die Tests verwenden jedoch Funktionen, die in Go 1.22 eingeführt wurden, und funktionieren mit einer älteren Version nicht ohne Änderungen.
