# Empfohlene Lernressourcen

Willkommen beim Lernen von ColdFusion (CFML)! CFML ist eine dynamische und schwach typisierte JVM-Skriptsprache. Es gibt zwei verschiedene Dateitypen. `.cfm`-Dateien (ColdFusion-Markup)_ sind rein prozedural und nutzen die tagbasierte Syntax, um HTML mit Templates zu erzeugen. Diese würdest du für Views verwenden, wenn du eine Website baust:

**index.cfm**

```xml
<cfoutput>
	<html>
		<h1>Welcome to my site, #FirstName# #LastName#!
	</html>
</cfoutput>
```

Der andere Dateityp ist die `.cfc`-Datei (ColdFusion-Komponente), und mit ihr deklarierst du eine Klasse. Komponenten werden für Geschäftslogik, Modelle und Controller verwendet. Diese verwenden normalerweise die Skriptsyntax, die ähnlich aussieht wie JavaScript.

**Car.cfc**

```js
component accessors=true {
	property name='make' type='string';
	property name='model' type='string';
	property name='year' type='number';

	function init() {
		return this;
	}
 
}
```
