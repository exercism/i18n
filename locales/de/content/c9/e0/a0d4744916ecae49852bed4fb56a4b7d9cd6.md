# Gleitkommazahlen

Gleitkommazahlen werden in PHP verwendet, um einen Teilbereich der reellen Zahlen darzustellen.
Sie beginnen mit einer oder mehreren Ziffern, die durch ein Dezimaltrennzeichen getrennt sind.

```php
<?php

$a = 1.234; 
$b = 1.2e3; 
$c = 7E-10;
$d = 1_234.567; // as of PHP 7.4.0
```

## Häufige Stolperfallen

Nicht alle Zahlen und Rechenoperationen lassen sich mit Gleitkommazahlen ausführen.
Wenn du Gleitkommazahlen verwendest, um Euro und Cent darzustellen, kann das zu Rundungsfehlern führen.

```php
<?php

$result = 0.1 + 0.2; // => 0.30000000000000004
```
