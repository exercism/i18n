# Einführung

## Let

Der `let`-Ausdruck erzeugt einen lokalen Gültigkeitsbereich und ist in einigen Situationen nützlich:

- Zum Vereinfachen von Ausdrücken
- Zum Benennen der Ergebnisse von Zwischenausdrücken
- Zum Aufteilen eines Ausdrucks in kleinere Teile, wenn er zu groß wird

In einem `let`-Ausdruck kannst du fast alles tun, auch Destrukturierung (mehr dazu in späteren Übungen). Es ist aber nicht möglich, einen neuen Custom Type oder Type Alias zu definieren.

```elm
let
  cube x = x * x * x
in
  cube a + cube b + cube c
```

```elm
beginWithPattern : Size -> Padding -> Pattern -> GameOfLife
beginWithPattern minimumSize padding pattern =
    let
        size = calculateSize minimumSize padding pattern

        center = Size.center size

        centeredPattern = Pattern.centerAt center pattern

        dimensions = { width = size, height = size }

        deadCells = Matrix.create dimensions Dead
    in
    GameOfLife (bringPatternToLife deadCells centeredPattern)
```
