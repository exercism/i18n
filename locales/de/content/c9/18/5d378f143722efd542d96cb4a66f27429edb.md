# Einzelheiten

Reguläre Ausdrücke in Gleam folgen der **PCRE**-Spezifikation (**P**erl **C**ompatible **R**egular **E**xpressions), ähnlich wie in anderen populären Sprachen wie Java, JavaScript oder Ruby.

Das Modul `gleam/regex` bietet Funktionen, mit denen du reguläre Ausdrücke verarbeiten kannst.

~~~~exercism/note
Diese Übung setzt voraus, dass du die Syntax regulärer Ausdrücke bereits kennst, einschließlich Zeichenklassen, Quantoren, Gruppen und Captures.

Wenn du dein Wissen über reguläre Ausdrücke auffrischen möchtest, schau dir eine dieser Quellen an: [Regular-Expressions.info](https://www.regular-expressions.info), [Rex Egg](https://www.rexegg.com/), [RegexOne](https://regexone.com/), [Regular Expressions 101](https://regex101.com/), [RegExr](https://regexr.com/).
~~~~

Am häufigsten erstellst du reguläre Ausdrücke mit der Funktion `regex.from_string`.

```gleam
let assert Ok(re) = regex.from_string("test")
```

Die Funktion `regex.from_string` gibt einen `Error` zurück, wenn die Syntax des regulären Ausdrucks ungültig ist. Deshalb wird hier eine Let-Assertion verwendet, um sicherzustellen, dass der reguläre Ausdruck gültig ist.

Mit der Funktion `regex.check` kannst du prüfen, ob ein regulärer Ausdruck auf einen String passt.

```gleam
let assert Ok(re) = regex.from_string("test")

regex.check(re, "this is a test")
// -> True

regex.check(re, "this is too")
// -> False
```


## Captures

Wenn du mit einem regulären Ausdruck Teilstrings erfassen möchtest, kannst du dir mit der Funktion `regex.scan` eine Liste von Übereinstimmungen zurückgeben lassen.

```gleam
let assert Ok(re) = regex.from_string("[oi]n a (\\w+)")
regex.scan(with: re, content: "I am on a boat in a lake.")
// -> [
//   Match(
//     content: "on a boat",
//     submatches: [Some("boat")]
//   ),
//   Match(
//     content: "in a lake",
//     submatches: [Some("lake")]
//   )
// ]
```

## Modifikatoren

Du kannst das Verhalten eines regulären Ausdrucks ändern, indem du ihn mit der Funktion `regex.compile` erstellst und Optionen übergibst.

```gleam
let options = regex.Options(case_insensitive: True, multi_line: False)
let assert Ok(re) = regex.compile("[A-Z]", with: options)
regex.check(re, "abc123")
// -> True
```
