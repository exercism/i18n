# Einführung

Swift kennt viele verschiedene Typen, doch jeder dieser Typen fällt in eine von zwei Kategorien: _Werttypen_ und _Referenztypen_. In Swift sind Strukturen Werttypen, während Klassen Referenztypen sind.

Der wichtigste Unterschied zwischen Werttypen und Referenztypen: Weist man einen Werttyp einer Variable oder Konstante zu oder übergibt man ihn an eine Funktion, wird tatsächlich eine Kopie des Werts zugewiesen oder übergeben und nicht der Wert selbst. Ändert man eine Kopie einer Struktur, hat das keine Auswirkungen auf die anderen Kopien. Bei Referenztypen dagegen wird eine Referenz auf den Wert zugewiesen oder übergeben, sodass zwei verschiedene Namen auf dieselbe Instanz einer Klasse verweisen können. So kann es passieren, dass die ursprüngliche Instanz verändert wird, wenn man über einen anderen Namen auf sie zugreift.
