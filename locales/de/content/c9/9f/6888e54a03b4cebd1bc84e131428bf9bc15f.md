# Kraftstofftransformation JSON

## Problemstellung

Jeder Mitarbeiter von ABC Corp erhält eine unbegrenzte Kraftstoffpauschale. Die Mitarbeiter müssen jedes Mal, wenn sie ihr Fahrzeug tanken, einen Datensatz einsenden. Diese Datensätze werden an dieselbe JSON-Datei angehängt und am Monatsende verarbeitet.

Als Mitglied des Teams für den digitalen Betrieb ist es deine Aufgabe, diese JSON-Datei zu lesen und die Ergebnisse in eine andere JSON-Datei zu schreiben. Die Ausgabedatei sollte für jeden Mitarbeiter einen Eintrag mit den folgenden Details enthalten:

- Mitarbeiternummer
- Anzahl der Tankvorgänge
- Gesamtkosten für Kraftstoff
- Gallonen insgesamt
- Insgesamt gefahrene Meilen

Du erhältst zwei Argumente des Typs `string`.

1. Pfad zur JSON-Eingabedatei.
1. Pfad zur JSON-Ausgabedatei.

Die JSON-Eingabedatei enthält ein Array von JSON-Objekten. Jedes JSON-Objekt hat die folgende Form.


```json
{
    "type": "array",
    "items": {
        "type": "object",
        "properties": {
            "employeeId": {
                "type": "integer"
            },
            "odometerReading": {
                "type": "integer"
            },
            "gallons": {
                "type": "number"
            },
            "gasPrice": {
                "type": "number"
            }
        },
        "required": [
            "employeeId",
            "odometerReading",
            "gallons",
            "gasPrice"
        ]
    }
}
```

```ballerina
// Ballerina record type definition
type FillUpEntry record {|
    int employeeId;
    int odometerReading;
    decimal gallons;
    decimal gasPrice;
|};
```

Deine Aufgabe ist es, die JSON-Eingabe in das folgende JSON-Format umzuwandeln und den Inhalt in den angegebenen Pfad zu schreiben. Die Ausgabedatei sollte für jeden Mitarbeiter einen Eintrag enthalten, aufsteigend sortiert nach `employeeId`.

```json
{
    "type": "array",
    "items": {
        "type": "object",
        "properties": {
            "employeeId": {
                "type": "integer"
            },
            "gasFillUpCount": {
                "type": "integer"
            },
            "totalFuelCost": {
                "type": "number"
            },
            "totalGallons": {
                "type": "number"
            },
            "totalMilesAccrued": {
                "type": "integer"
            }
        },
        "required": [
            "employeeId",
            "gasFillUpCount",
            "totalFuelCost",
            "totalGallons",
            "totalMilesAccrued"
        ]
    }
 }
```

```ballerina
// Ballerina record type definition
type EmployeeFillUpSummary record {|
    int employeeId;
    int gasFillUpCount;
    decimal totalFuelCost;
    decimal totalGallons;
    int totalMilesAccrued;
|};
```

## Einschränkungen

- Anzahl der Tankdatensätze `n` in der JSON-Eingabedatei: 0 <= n <= 1000
- Anzahl der Mitarbeiter im Unternehmen: 97
- Der Kraftstoffpreis gilt pro Gallone
- Keine fehlenden Tankdatensätze

## Hinweise

- Verwende das [`ballerina/io`-Modul](https://lib.ballerina.io/ballerina/io/latest), um JSON-Dateien zu lesen und zu schreiben.
- Konvertiere die JSON-Werte in anwendungsspezifische Typen, um typsicher mit den Daten zu arbeiten. Weitere Informationen findest du im [Beispiel für das Konvertieren in einen benutzerdefinierten Typ](https://ballerina.io/learn/by-example/convert-from-json-to-user-defined-type) in den Ballerina By Examples (BBE).

```ballerina
   json jsonPayload = {id: "2", title: "Jeru", artist: "Gerry Mulligan", price: 17.99};

   // Using cloneWithType  
   Album album1 = check jsonPayload.cloneWithType();
   io:println(album1);
 
   // Using fromJsonWithType
   Album album2 = check jsonPayload.fromJsonWithType();
   io:println(album2);
```

- Das [Destrukturieren von Datensätzen](https://ballerina.io/learn/by-example/destructure-records-using-query) kann nützlich sein, um den Code weniger ausführlich zu machen.

```ballerina
   Album {id, title, artist, price} = album1;
   io:println(id);
   io:println(title);
```

- Verwende Funktionen mit Ausdruckskörper für Funktionen mit einem einzigen Ausdruck. Zum Beispiel Funktionen, die nur die `return`-Anweisung enthalten.

```ballerina
   function cfr(int deaths, int cases) returns decimal => <decimal>deaths / <decimal>cases * 100;
```
