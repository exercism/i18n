# Einführung

Die for-Schleife ist eine der am häufigsten verwendeten Anweisungen, um eine Logik wiederholt auszuführen.
In JavaScript besteht sie aus dem Schlüsselwort `for`, einem _Header_ in runden Klammern und einem Block in geschweiften Klammern, der den _Schleifenblock_ der Schleife enthält.

```javascript
for (initialization; condition; step) {
  // code that is executed repeatedly as long as the condition is true
}
```

Die Initialisierung legt üblicherweise eine Zählvariable an, die Bedingung prüft, ob die Schleife fortgesetzt oder beendet werden soll, und der Schritt erhöht den Zähler am Ende jeder Wiederholung.
Die einzelnen Teile des Headers werden durch Semikolons getrennt.

```javascript
const list = ['a', 'b', 'c'];
for (let i = 0; i < list.length; i++) {
  // code that should be executed for each item list[i]
}
```
