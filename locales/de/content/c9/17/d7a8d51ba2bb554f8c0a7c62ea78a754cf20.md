# Listen

Eine `LIST{T}` ist eine wachsende, geordnete Sammlung. Im Hintergrund steht ein Array, das durch ein größeres ersetzt wird, sobald es voll ist.

```sather
   notes ::= #LIST{STR};
   notes.append("muddy boots");
   notes[0]                     -- "muddy boots"
   notes[0] := "clean boots";
   notes.size
   notes.is_empty
   notes.has("clean boots")
   notes.remove_index(0);
```

## Array oder Liste?

| | `ARRAY{T}` | `LIST{T}` |
| --- | --- | --- |
| Größe | bei der Erzeugung festgelegt | ändert sich |
| Anhängen | nein | ja |
| Entfernen | nein | ja |
| Zugriff über Index | `a[i]` | `l[i]` |
| Zusatzaufwand | keiner | eine Größe und Reserve |

Verwende ein `ARRAY`, wenn die Größe bekannt ist und feststeht: eine Reihe Tänzerinnen und Tänzer, die Zählwerte einer Woche. Verwende eine `LIST`, wenn Dinge hinzukommen oder wegfallen.

## Direkt verändert, nicht funktional

`append`, `remove_index` und `[i] :=` verändern alle die Liste selbst. Du musst nichts wieder zuweisen, und eine Liste, die du an eine Routine übergibst, ist davor nicht sicher.

Das ist das Gegenteil von `FMAP` und `FSET`, und es lohnt sich, genau zu wissen, was du gerade in der Hand hältst. Die Faustregel: Ein `F` am Anfang des Namens bedeutet funktional, und alles andere verändert direkt.

Wenn du eine Liste herausgeben willst, die niemand verderben kann, gib eine Kopie heraus:

```sather
   return notes.copy;
```

## Die Kosten des Anhängens

Anhängen ist im Durchschnitt günstig. Wenn das zugrundeliegende Array voll wird, wird ein neues genommen, das doppelt so groß ist, und alles wird kopiert. Die meisten Anhänge kosten also kaum etwas, und gelegentlich kostet einer eine Kopie. Über viele Anhänge hinweg ergibt das im Schnitt einen konstanten Aufwand pro Anhang. Deshalb wird verdoppelt, statt jedes Mal um eins zu wachsen.

`remove_index` ist nicht günstig: Alles nach der entfernten Position rückt um eins nach. Wenn du wiederholt am Anfang einer langen Liste entfernst, ist das auf eine Weise langsam, die man leicht übersieht.

## Nützliche Routinen

| Aufruf | Wirkung |
| --- | --- |
| `l.append(x)` | hängt am Ende an |
| `l.insert_before(i, x)` | fügt an einer Position ein |
| `l.remove_index(i)` | entfernt eine Position |
| `l.has(x)` | ist es enthalten? |
| `l.copy` | eine unabhängige Kopie |
| `l.str` | der Inhalt, in geschweiften Klammern |
| `l.elt!`, `l.ind!` | durchlaufen die Werte oder die Positionen |
