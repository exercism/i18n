# Ergänzung zur Anleitung

## Register

| Register | Verwendung | Typ    | Beschreibung                                      |
| -------- | ---------- | ------ | ------------------------------------------------- |
| `$a0`    | Eingabe    | Ganzzahl | zu prüfendes Jahr                               |
| `$v0`    | Ausgabe    | boolescher Wert | die Eingabe ist ein Schaltjahr (`0` = `false`, `1` = `true`) |
| `$t0-9`  | temporär   | beliebig | wird als Zwischenspeicher verwendet              |
