# Installation

Der einfachste Weg, PureScript zu installieren, führt über Node.js und NPM.

Falls du Node.js noch nicht auf deinem Computer installiert hast, kannst du es von der [Node.js-Website](https://nodejs.org/) herunterladen. Sobald Node.js bei dir läuft, gib diesen Befehl ins Terminal ein, um den PureScript-Compiler und das Build-Tool Spago zu installieren:

    npm install --global purescript spago

Weitere Informationen findest du im [PureScript-Repository](https://github.com/purescript/purescript/blob/master/INSTALL.md).
