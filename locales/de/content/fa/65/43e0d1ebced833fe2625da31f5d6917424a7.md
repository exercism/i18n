# Für Maintainer

## Hilfsskript zum Erstellen von Fortran-Tests: create_fortran_test.py

Eine einfache Möglichkeit, einen Übungstest zu erstellen, ist die Verwendung des Skripts
`bin/create\_fortran\_test.py`.

Verwende dieses Skript, um eine erste <exercise>\_test.f90-Datei zu erstellen, die als Vorlage für deinen Test verwendet werden kann.
Normalerweise musst du die „response“-Funktion in der generierten Datei durch den korrekten Funktionsaufruf ersetzen.

Beachte außerdem, dass Fortran Probleme mit Sonderzeichen wie `\n` und `\t` hat, gehe also besonders sorgfältig damit um.

### Voraussetzungen

- Funktionierendes CMake und einen funktionierenden Fortran-Compiler
- Python3.x (Es mag mit Python2 funktionieren, aber ich habe mir nicht die Mühe gemacht,
  es abwärtskompatibel zu machen)
- neueste Version von https://github.com/exercism/problem-specifications.git
- git

### Workflow zum Erstellen eines neuen Tests

- Hole die neuesten Änderungen aus `exercism/problem-specifications`, z. B. git clone git@github.com:exercism/problem-specifications.git
- Erstelle einen neuen Branch für eine neue Übung, z. B. git checkout -b exercise-bob
- Führe dieses Skript für das Beispiel aus, das du erstellen möchtest
- Kopiere `config/CMakeLists.txt` in das Übungsverzeichnis (dafür kannst du `bin/update-cmake-files` verwenden)
- Implementiere die Übung, sodass sie funktioniert
- Behebe mögliche problematische Tests (siehe z. B. exercise/bob „Test 20“ und „Test 24“)
- Stelle sicher, dass der Befehl `ctest` fehlerfrei durchläuft
- Kopiere deine Lösung nach .meta/example.f90 und entferne die eigentliche Implementierung aus der Übungsdatei, z. B. bob.f90
- Aktualisiere die Verzeichnisse .docs und .meta
  - cp ../problem-specifications/exercises/bob/description.md exercises/practice/bob/.docs/instructions.md
    - Ersetze „# Description“ durch „# Instructions“
  - Fülle .meta/tests.toml manuell aus (bis es einen automatisierten Weg gibt)
  - Fülle .meta/config.json manuell aus (bis es einen automatisierten Weg gibt)
    - Verwende ../problem-specifications/exercises/bob/metadata.yml
- Öffne einen Pull Request mit deinen Änderungen

Für das Bob-Beispiel:

```bash
$ python bin/create_fortran_test.py -j ../problem-specifications/main/exercises/bob/canonical-data.json -t exercises/practice/bob/bob_test.f90
Namespace(json='../problem-specifications/main/exercises/bob/canonical-data.json', target='exercises/practice/bob/bob_test.f90')
Wrote : exercises/practice/bob/bob_test.f90
$ cp config/CMakeLists.txt exercises/practice/bob/.
$ cd exercises/practice/bob
$ touch bob.f90
$ mkdir build
$ cd build
$ cmake ..
$ make
$ ctest -V
```

### `CMakeLists.txt` ändern

Wenn du die CMake-Datei änderst, aktualisiere die Master-Kopie in `config/` und kopiere sie mit `bin/update-cmake-files` in alle Übungsverzeichnisse.

## Lösung

Wenn du eine Lösung hast, kopiere sie als „example.f90“ in das Verzeichnis „.meta“.

Vielleicht möchtest du eine Skelett-Implementierung der Funktion oder Subroutine hinterlassen, die dem Lernenden hilft, und die Datei mit dem Übungsnamen im Übungsverzeichnis lassen.
