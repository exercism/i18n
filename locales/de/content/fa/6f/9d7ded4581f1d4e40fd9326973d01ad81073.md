# Einführung

## Strings

In Common Lisp sind Strings [Vektoren][concept-vectors] aus [Zeichen][concept-characters].
Sie werden als Zeichen in doppelten Anführungszeichen geschrieben (_z. B._ "Hello World!").

Das Prädikat `stringp` gibt nur dann wahr zurück, wenn der übergebene Wert ein String ist.

Strings lassen sich mit der Funktion `subseq` in Teilstrings zerlegen. Diese nimmt den String, einen Startindex und optional einen Endindex entgegen.
Die Indizierung ist nullbasiert.

```lisp
(subseq "Hello World" 1 5)   ; => "ello"
(subseq "skip to the end" 5) ; => "to the end"
```

Strings lassen sich mit `string=` auf Gleichheit vergleichen.
Wenn die Groß- und Kleinschreibung der Zeichen ignoriert werden soll, kannst du `string-equal` verwenden.

```lisp
(string= "macaroni" "macaroni")      ; => T
(string= "macaroni" "MACARONI")      ; => NIL
(string-equal "macaroni" "MACARONI") ; => T
```

Mit `string-upcase`, `string-downcase` und `string-capitalize` kannst du Strings in Großbuchstaben, in Kleinbuchstaben oder in großgeschriebene Wörter umwandeln.

```lisp
(string-upcase "not too loud")                ; => "NOT TOO LOUD"
(string-downcase "YELL IT FROM THE ROOFTOPS") ; => "yell it from the rooftops"
(string-capitalize "practical COMMON LiSP")   ; => "Practical Common Lisp"
```
