# Einführung

Eine Gleitkommazahl ist eine Zahl mit null oder mehr Ziffern hinter dem Dezimaltrennzeichen.
Beispiele sind `-2.4`, `0.1`, `3.14`, `5.`, `16.984025` und `1024.0`.

Verschiedene Gleitkommatypen können unterschiedlich viele Ziffern hinter dem Trennzeichen speichern. Das nennt man ihre Genauigkeit.

Go hat zwei Gleitkommatypen:

- `float32`: 32 Bit (Genauigkeit von ~6-9 Ziffern).
- `float64`: 64 Bit (Genauigkeit von ~15-17 Ziffern).
   Das ist der Standard-Gleitkommatyp.

Wie man sieht, können beide Typen unterschiedlich viele Ziffern speichern.
Das bedeutet, dass beim Speichern von PI in einem `float32` nur die ersten 6 bis 9 Ziffern gespeichert werden (wobei die letzte Ziffer gerundet wird).

Standardmäßig verwendet Go für Gleitkommazahlen `float64`. Etwas anderes gilt nur, wenn die Gleitkommazahl:

1. einer Variablen mit dem Typ `float32` zugewiesen wird, oder
2. aus einer Funktion mit dem Rückgabetyp `float32` zurückgegeben wird, oder
3. als Argument an die Funktion `float32()` übergeben wird.

Das [`math` package] enthält viele hilfreiche mathematische Funktionen.

[`math` package]: https://pkg.go.dev/math
