# Hinweise

## Allgemein

- Jede Aufgabe baut in einer Schleife Text auf, also beginnt jede mit `#FSTR` und
  endet mit `.str`.
- Weise das Ergebnis jeder `+`-Operation wieder dem Builder zu:
  `script := script + ...`.

## 1. Einen Einsatz wiederholen

- `1.upto!(times)` lässt die Schleife genau so oft laufen, wie es nötig ist. Der Wert,
  den sie liefert, wird nicht gebraucht, also kann er direkt in eine Variable wandern,
  die nie verwendet wird. Oder du nimmst `times.times!`, das überhaupt nichts liefert.
- Wenn es gar keine Wiederholungen gibt, braucht das keine besondere Behandlung: Die
  Schleife läuft dann einfach nicht.

## 2. Die Initialen der Besetzung

- `names.elt!` liefert jeden Namen; `[0]` nimmt dessen erstes Zeichen.
- Ein `FSTR` akzeptiert ein `CHAR` direkt, du musst es also nicht erst in einen String
  umwandeln.

## 3. Die Zeilen nummerieren

- Zwei Iteratoren in einer Schleife, wie in der letzten Übung: `1.up!` für die Nummer
  und `lines.elt!` für den Text.
- Der Zeilenumbruch kommt *vor* jede Zeile außer der ersten. Am einfachsten prüfst du
  die Nummer: `if number > 1 then ... end`.
- Ein `FSTR` akzeptiert die Nummer direkt, also funktioniert
  `script + number + ". "` ohne Umwandlung.

## 4. Eine Zeile brüllen

- `line.elt!` durchläuft einen String Zeichen für Zeichen.
- `.upper` lässt alles, was kein Buchstabe ist, unverändert, das Leerzeichen braucht
  also keine besondere Behandlung.
