# Ergänzung zu den Anweisungen

Das ist eine gute Übung, um mit nicht standardmäßigen String-Literalen und Metaprogrammierung zu experimentieren.

Eine kurze Einführung in nicht standardmäßige String-Literale findest du in diesem [Blogbeitrag](https://web.archive.org/web/20170625222109/https://iaindunning.com/blog/julia-unicode.html). Eine ausführliche Anleitung zur Metaprogrammierung findest du im [Handbuch](https://docs.julialang.org/en/v1/manual/metaprogramming/).

Du kannst deine Lösung erweitern, indem du die unten beschriebene Funktionalität hinzufügst.

Für Bonus A reichen die Grundlagen, wie sie im Blogbeitrag beschrieben sind. Bonus B erfordert deutlich mehr Wissen über Metaprogrammierung in Julia.

## Bonus A
Implementiere ein String-Literal, das wie `ROT13` auf den String wirkt:
```julia
R13"abcdefghijklmnopqrstuvwxyz" == "nopqrstuvwxyzabcdefghijklm"
```

## Bonus B
Implementiere die String-Literale `R<i>`, `i = 0, ..., 26`, die den String um `i` Stellen verschieben:
```julia
R0"Hello, World!" == "Hello, World!"
R4"Testing 1 2 3 testing" == "Xiwxmrk 1 2 3 xiwxmrk"
R13"abcdefghijklmnopqrstuvwxyz" == "nopqrstuvwxyzabcdefghijklm"
```
