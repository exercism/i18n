# Anleitung

In dieser Übung erstellst du die Regeln für die Website eines Kinos.

## 1. Prüfe, ob ein Kinobesucher Anspruch auf den Seniorenrabatt hat

Das Kino bietet einen Rabatt für „Altersrentner“.
Wer 60 oder älter ist, zahlt 10,00 für eine Eintrittskarte.
Wer jünger ist, zahlt die vollen 15,00.

Schreibe die Methode `Moviegoer#ticket_price` mit einem ternären Operator.

```ruby
Moviegoer.new(21).ticket_price
#=> 15

Moviegoer.new(65).ticket_price
#=> 10
```

## 2. Prüfe, ob ein Kinobesucher einen Horrorfilm sehen darf

Das Kino hat ein vereinfachtes System zur Altersprüfung.
Wenn du 18 oder älter bist, darfst du Horrorfilme sehen.
Wenn du jünger bist, darfst du es nicht.

Implementiere die Methode `Moviegoer#watch_scary_movie?`.
Sie soll zurückgeben, ob jemand den Film sehen darf oder nicht.

```ruby
Moviegoer.new(21).watch_scary_movie?
#=> true

Moviegoer.new(17).watch_scary_movie?
#=> false
```

## 3. Prüfe, ob ein Kinobesucher Anspruch auf kostenloses Popcorn hat

Das Kino hat ein Movie-Club-Programm.
Mitglieder bekommen kostenloses Popcorn, wenn sie sich einen Film ansehen.

Implementiere die Methode `Moviegoer.claim_free_popcorn!`.
Wenn ein Zuschauer Mitglied im Movie Club ist, soll er mit seinem kostenlosen Popcorn belohnt werden.
Wenn nicht, soll die Methode die Ausnahme `UnsupportedOperation` auslösen, die oben im Code definiert ist.

```ruby
Moviegoer.new(21, member: true).claim_free_popcorn!
#=> 🍿

Moviegoer.new(17, member: false).claim_free_popcorn!
#=> Exception was raised! (NotMovieClubMemberError)
```

~~~~exercism/note
In dieser Übung wird von dir erwartet, dass du die Ausnahme `UnsupportedOperation` für einen bestimmten Gültigkeitsbereich definierst.
~~~~
