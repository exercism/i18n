# Anweisungen

Das Acht-Damen-Problem ist eine klassische Frage in Bewerbungsgesprächen für Programmierer. Zum Glück macht Z3 das Lösen einfach.
Das Problem ist folgendes: Platziere 8 Damen auf einem Schachbrett, sodass keine zwei Damen einander schlagen können. Im Schach
können Damen beliebig viele Felder in eine einzige Richtung ziehen (vorwärts, rückwärts, links, rechts, diagonal). Schreibe eine
Funktion, die eine Liste von Python-Tupeln mit den Positionen der 8 Damen zurückgibt.
