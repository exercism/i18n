# Anleitung

Einige „andere“ Entwickler haben am Projekt des ferngesteuerten Autos [exercise:csharp/remote-control-competition]() gearbeitet. Du wurdest gerufen, um den Code aufzuräumen.

## 1. Trenne die Zuständigkeiten zwischen dem Auto selbst und dem Telemetriesystem

Refaktoriere die Klasse `RemoteControlCar` so, dass die Telemetriemethoden und -eigenschaften ausgelagert und über eine `Telemetry`-Eigenschaft aufgerufen werden.

```csharp
var car = new RemoteControlCar();
car.Telemetry.Calibrate();
car.Telemetry.SelfTest();
car.Telemetry.ShowSponsor("Walker Industries Inc.");
car.CurrentSponsor
// => "Walker Industries Inc."
car.Telemetry.SetSpeed(100, "cps");
car.GetSpeed()
// => "100 centimeters per second"
```

## 2. Verhindere, dass anderer Code zu viele Abhängigkeiten vom Typ Telemetry eingeht

Stelle sicher, dass die `Telemetry`-Instanz nicht außerhalb des Gültigkeitsbereichs des Autos erstellt werden kann.

## 3. Verhindere, dass anderer Code Abhängigkeiten vom Speed-Struct eingeht

Stelle sicher, dass das `Speed`-Struct nicht außerhalb des Gültigkeitsbereichs der Klasse `RemoteControlCar` verwendet werden kann.

## 4. Verhindere, dass anderer Code Abhängigkeiten vom SpeedUnits-Enum eingeht

Stelle sicher, dass das `SpeedUnits`-Enum nicht außerhalb des Gültigkeitsbereichs der Klasse `RemoteControlCar` verwendet werden kann.
