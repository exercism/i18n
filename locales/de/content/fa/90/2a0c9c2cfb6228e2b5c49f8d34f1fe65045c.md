# Einführung

Ein Record ist eine Sammlung von Feldern (die von unterschiedlichen Typen sein können), die zusammengehören. Um einen Record zu definieren, verwendest du das Schlüsselwort `type`. Die Felder eines Records werden zwischen den Zeichen `{` und `}` definiert, und jedes Feld hat einen Namen _und_ einen Typ. Um einen Record zu erstellen, gibst du die Namen der Felder an und weist ihnen zwischen den Zeichen `{` und `}` einen Wert zu. Beim Erstellen eines Records müssen alle Felder einen Wert erhalten. Auf die Feldwerte einer Record-Instanz kannst du mit der Punktnotation zugreifen.

Beim Definieren oder Erstellen eines Records muss jedes Feld entweder in einer eigenen Zeile stehen oder, wenn alles in einer Zeile steht, durch Semikolons (`;`) getrennt werden.

```fsharp
// Define a record
type Address =
    { Street: string
      HouseNumber: int }

// Create a record
let oldAddress: Address =
    { Street = "Main Street"
      HouseNumber = 17 }

// Single-line alternative
type ConciseAddress = { Street: string; HouseNumber: int }
let conciseAddress: ConciseAddress = { Street = "Main Street"; HouseNumber = 17 }
```

Da Records unveränderlich sind, können sich die Feldwerte eines Records nach seiner Erstellung nie ändern. Wenn du die Werte eines Records ändern möchtest, kannst du mit dem Schlüsselwort `with` eine Kopie eines bestehenden Records erstellen, allerdings mit neuen Werten für ein oder mehrere Felder.

```fsharp
// Copy the old address but change the house number
let newAddress: Address = { oldAddress with HouseNumber = 86 }
newAddress.Street      // => "Main Street"
newAddress.HouseNumber // => 86
```

Records haben _strukturelle Gleichheit_, was bedeutet, dass zwei Instanzen desselben Records mit identischen Werten gleich sind.

Neben der Punktnotation für den Zugriff auf die Felder eines Records können Records auch in Bindungen und im Musterabgleich zerlegt werden:

```fsharp
let myAddress: Address = { Street = "Broadway"; HouseNumber = 123 }
let { Street = myStreet; HouseNumber = myHouseNumber } = myAddress

match myAddress with
| { HouseNumber = 1 } -> printfn "First house"
| { HouseNumber = houseNumber; Street = street } -> printfn "House number %d on %s" houseNumber street
// => "House number 123 on Broadway
```
