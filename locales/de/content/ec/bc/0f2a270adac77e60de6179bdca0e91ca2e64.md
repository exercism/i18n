# Einführung

Ein Wörterbuch ist eine Sammlung von Elementen, bei der jedes Element aus einem Schlüssel und einem Wert besteht, sodass, wenn ein Schlüssel an eine Methode des Wörterbuchs übergeben wird, der zugehörige Wert zurückgegeben wird. Es hat dieselbe Rolle wie Maps oder assoziative Arrays in anderen Sprachen.

Ein Wörterbuch kann wie folgt erstellt werden:

```csharp
new Dictionary<int, string>();
// Empty dictionary
```

Oder

```csharp
new Dictionary<int, string>
{
    [1] = "One",
    [2] = "Two"
};

// Or

new Dictionary<int, string>
{
    {1, "One"},
    {2, "Two"}
};
// 1 => "One", 2 => "Two"
```

Beachte, dass die Typen von Schlüssel und Wert Teil der Definition des Wörterbuchs sind.

Nachdem es erstellt wurde, können Einträge mit den integrierten Methoden `Add` und `Remove` zu einem Wörterbuch hinzugefügt oder daraus entfernt werden.

Das Abrufen oder Aktualisieren von Werten in einem Wörterbuch erfolgt durch Indizierung des Wörterbuchs mit einem Schlüssel:

```csharp
var numbers = new Dictionary<int, string>
{
   {1, "One"},
   {2, "Two"}
};

// Set the value of the element with key 2 to "Deux"
numbers[2] = "Deux";

// Get the value of the element with key 2
numbers[2];
// => "Deux"
```

Du kannst testen, ob ein Wert im Wörterbuch vorhanden ist, mit:

```csharp
var dict = new Dictionary<string, string>{/*...*/};
dict.ContainsKey("some key that exists");
// => true
```

Das Aufzählen über ein Wörterbuch zählt seine Schlüssel/Wert-Paare auf. Wörterbücher haben auch Eigenschaften, die das Aufzählen über seine Schlüssel oder Werte ermöglichen.
