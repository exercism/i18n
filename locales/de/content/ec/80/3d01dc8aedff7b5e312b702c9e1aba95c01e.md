# Repräsentationen

Der [Python representer][representer] verarbeitet Lösungen von Lernenden und normalisiert sie in eine eher „generische“ Form:

- Der Code wird mit dem [Python-AST-Modul][python-ast] in einen AST umgewandelt.
- Der fertige AST-Baum wird in einen String ohne Leerzeichen oder Einrückung umgewandelt und als `representation.txt` ausgegeben.
- Zur Fehlersuche enthält `representation.out` den Ausgangs-AST, den bearbeiteten AST und eine Code-Repräsentation mit angewendeten Normalisierungen.

- Was entfernt wird:
    - Typannotationen (_einschließlich Typannotationen in Dataclasses, siehe unten im Abschnitt „Was normalisiert wird“_)
    - `print()`-Anweisungen
    - `if __name__ == __main__`-Blöcke
    - Kommentare
    - Docstrings

- Was ersetzt wird:
    - benutzerdefinierte Namen werden durch Platzhalter ersetzt (_einschließlich Funktionsnamen, Parameter und Variablen in Lambdas_)

- Was normalisiert wird:
  - String-Anführungszeichen `'` werden in `"` geändert (_doppelte Anführungszeichen_), außer wenn Escapes nötig sind, dann bleiben sie unverändert.
  - Bei Zahlenliteralen werden alle Unterstriche entfernt und die wissenschaftliche Notation wird nach Stellenwerten berechnet:
    - **66_777_888_433** --> 66777888433
    - **1_999_878_473.66** --> 1999878473.66
    - **77_555_998_125.445_779** --> 77555998125.44579
    - **44_573_123.445_312+123_674.889_12j** --> 44573123.445312 + 123674.88912j
    - **1e6** --> 1000000.0 #1000000
    - **1e2+.23** --> 100.0 + 0.23 #100.23
    - **1e2+1_23e0+4.4e-1** --> 100.0 + 123.0 + 0.44 #223.44
    - **7e6+7e5+5e4+9.98e2+4.45_779e-1** -->7000000.0 + 700000.0 + 50000.0 + 998.0 + 0.445779 #7750998.445779
    - **(7e6+7e5+5e4+9.98e1+4.457_79e-1)+(1e2+1.23e1+4.444_23e-1)*1*j** --> (7000000.0 + 700000.0 + 50000.0 + 99.8 + 0.445779 + (100.0 + 12.3 + 0.444423) * 1j)  #7750100.245779+112.744423j
  - Bei Funktionen und Klassen, deren Rumpf nach dem Entfernen der Docstrings leer ist, wird dem Rumpf `pass` zugewiesen.
  - Bei Dataclasses mit typannotierten, aber nicht zugewiesenen Datenattributen bekommen diese Datenattribute `None` als Wert zugewiesen. Siehe den Docstring ab Zeile 153 in normalizer.py für weitere Details.
