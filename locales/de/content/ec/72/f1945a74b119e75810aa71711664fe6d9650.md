# Über

**Delphi** ist eine auf Object Pascal basierende Programmiersprache für die Entwicklung von Desktop-, Mobil-, Web- und Konsolensoftware.
Delphi war der [Codename](https://edn.embarcadero.com/article/20396) für ein noch unbenanntes Produkt während seiner ersten Entwicklungsphase vor seinem Debüt im Jahr 1995.

Delphi wurde ursprünglich von [Borland](https://en.wikipedia.org/wiki/Borland) entwickelt, unter der Leitung von Anders Heilsberg, als [RAD](https://en.wikipedia.org/wiki/Rapid_application_development)-Tool für Windows und als Nachfolger von [Turbo Pascal](https://en.wikipedia.org/wiki/Turbo_Pascal).
Delphi verlieh der bestehenden Sprache eine vollständige Objektorientierung, und seitdem ist die Sprache gewachsen und unterstützt viele weitere moderne Sprachmerkmale, darunter:
  
- **Generics**  
- **Anonyme Methoden (Closures)**  
- **Dynamische Konstrukte (Attribute)**  
- **Abstrakte Methoden**  
- **Eingebaute String-Typen**  
- **Native COM-Unterstützung**  
- **RTTI**  

Wie sein Vorgänger Turbo Pascal hat Delphi im Kern einen Native-Code-Compiler.
Turbo Pascal bot eine ideale Balance zwischen der Geschwindigkeit des Programmierens und der Geschwindigkeit der resultierenden Programme, der Klarheit der Syntax und der Ausdruckskraft. Diese Grundsätze gelten heute auch für Delphi.
Neuere Versionen von Delphi können nativen Code für viele verschiedene Plattformen kompilieren:

- **Windows (x86 und x64)**  
- **OS X (nur 32 Bit)**  
- **iOS (32 und 64 Bit)**  
- **Android**  
- **Linux (nur 64 Bit)**  

Im Jahr 2006 wurde der Bereich für Entwicklerwerkzeuge von Borland auf eine hundertprozentige Tochtergesellschaft namens [CodeGear](https://en.wikipedia.org/wiki/CodeGear) übertragen, die 2008 an [Embarcadero Technologies](https://en.wikipedia.org/wiki/Embarcadero_Technologies) verkauft wurde.
2015 wurde Embarcadero von Idera übernommen, die Marke Embarcadero blieb jedoch für die Entwicklerwerkzeug-Sparte erhalten.
