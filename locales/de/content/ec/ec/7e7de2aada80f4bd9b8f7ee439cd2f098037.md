# Gleitkommazahlen

`INT` kann nur ganze Zahlen speichern, und bei der Division zweier solcher Zahlen fällt der Rest weg:

```sather
7 / 2        -- 3, not 3.5
```

Wenn der Bruchteil zählt, ist der Typ `FLTD` gefragt: eine **Gleitkommazahl**, die auch Werte zwischen den ganzen Zahlen annehmen kann.

## So schreibst du eine

Ein Gleitkomma-Literal hat einen Dezimalpunkt und ein `d` am Ende.

```sather
   concert_a : FLTD is
      return 440.0d;
   end;
```

Das `d` ist nicht optional. `440.0` allein ist ein anderer Typ mit geringerer Genauigkeit; das `d` verlangt den Typ, den dieser Track überall verwendet.

Schreib `2.0d`, nicht `2d`: Es muss auch einen Dezimalpunkt geben.

## Rechnen

`+`, `-`, `*` und `/` funktionieren alle, und `/` behält jetzt den Bruchteil:

```sather
7.0d / 2.0d      -- 3.5
```

Beide Seiten müssen `FLTD` sein. Sather mischt die beiden Typen nicht stillschweigend, deshalb ist `7 / 2.0d` ein Fehler und keine Überraschung.

## Aus einer ganzen Zahl

`.fltd` wandelt `INT` in `FLTD` um:

```sather
   halve(n : INT) : FLTD is
      return n.fltd / 2.0d;
   end;
```

`halve(7)` ergibt `3.5`. Achte darauf, wo die Umwandlung steht: `(7 / 2).fltd` wäre `3.0`, weil die Division die Hälfte bereits verworfen hätte. Wandle **vor** der Division um, nicht danach.

## Wie weit auseinander?

`.abs` entfernt ein Minuszeichen. So kannst du fragen, wie weit zwei Werte auseinanderliegen, ohne dich darum zu kümmern, welcher größer ist:

```sather
(440.0d - 442.0d).abs      -- 2.0
```
