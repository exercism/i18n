# Überblick

## Struct-Typen

Wir haben Struct-Typen bereits kennengelernt. Zur Wiederholung: Ein `struct` ist eine Folge benannter Elemente, die _Felder_ heißen, wobei jedes Feld einen Namen und einen Typ hat.
Der Name eines Feldes muss innerhalb des Structs eindeutig sein.
`Structs` lassen sich mit der _Klasse_ im Paradigma der objektorientierten Programmierung vergleichen.

Du erstellst ein neues Struct mit den Schlüsselwörtern `type` und `struct` und legst dann den Namen und den Typ der Felder explizit fest, wie im folgenden Beispiel gezeigt.

```go
type StructName struct{
    field1 fieldType1
    field2 fieldType2
}
```

## Nicht-Struct-Typen

Du kannst auch Nicht-Struct-Typen definieren, die du als Alias für Deklarationen eingebauter Typen verwenden kannst.

```go
type Name string
func SayHello(n Name) {
  fmt.Printf("Hello %s\n", n)
}
n := Name("Fred")
SayHello(n)
// Output: Hello Fred
```

Du kannst auch Nicht-Struct-Typen definieren, die aus Arrays und Maps bestehen.

```go
type Names []string
func SayHello(n Names) {
  for _, name := range n {
    fmt.Printf("Hello %s\n", name)
  }
}
n := Names([]string{"Fred", "Bill"})
SayHello(n)
// Output:
// Hello Fred
// Hello Bill
```
