# Einführung

## Vergleichsoperatoren

[Vergleichsoperatoren][comparison-operators] vergleichen zwei Werte des gleichen Typs und geben einen `Bool`-Wert zurück (`true` oder `false`).
Wenn du versuchst, Werte unterschiedlicher Typen zu vergleichen, meldet der Compiler einen Fehler.

Die standardmäßigen Vergleichsoperatoren in Swift sind:

| Operator | Beschreibung             | Beispiel        |
| -------- | ------------------------ | --------------- |
| `==`     | Gleich                   | `1 == 1` (true) |
| `!=`     | Ungleich                 | `1 != 2` (true) |
| `<`      | Kleiner als              | `4 < 5`  (true) |
| `<=`     | Kleiner oder gleich      | `4 <= 4` (true) |
| `>`      | Größer als               | `3 > 1`  (true) |
| `>=`     | Größer oder gleich       | `2 >= 2` (true) |

## if- und else-Anweisungen

Eine [bedingte Anweisung][conditional-statement] führt Code aus, je nachdem, ob eine Bedingung `true` oder `false` ergibt.
Die häufigste bedingte Anweisung ist die [if-Anweisung][if], die einen Block Code nur ausführt, wenn ihre Bedingung `true` ist.
Schreibe eine `if`-Anweisung mit dem Schlüsselwort `if`, gefolgt von der Bedingung und dem Block in geschweiften Klammern:

```swift
let wheelCount = 4
if wheelCount == 4 {
    print("Your vehicle is a car")
}
// Prints "Your vehicle is a car"
```

Du kannst `if` mit einer `else`-Klausel kombinieren, um alternativen Code auszuführen, wenn die Bedingung `false` ist:

```swift
let precipitationInMM = 0.5
if precipitationInMM > 0.5 {
    print("You will need an umbrella")
} else {
    print("You will not need an umbrella")
}
// Prints "You will not need an umbrella"
```

Um mehrere Bedingungen nacheinander zu prüfen, verkettest du die Anweisungen mit `else if`.
Eine `if`-Anweisung benötigt keinen `else`-Zweig, aber du kannst einen angeben, um Fälle abzudecken, in denen keine der Bedingungen zutrifft:

```swift
let favoriteFruit = "Apple"

if favoriteFruit == "Banana" {
    print("Your favorite fruit is a banana")
} else if favoriteFruit == "Orange" {
    print("Your favorite fruit is an orange")
} else if favoriteFruit == "Apple" {
    print("Your favorite fruit is an apple")
} else {
    print("Your favorite fruit is not a banana, orange, or apple")
}
// Prints "Your favorite fruit is an apple"
```

## if-Ausdrücke

In modernem Swift kannst du `if`-Anweisungen auch als Ausdrücke verwenden, die einen Wert liefern.
Jeder Zweig ergibt einen Wert, sodass du Ergebnisse ganz einfach bedingt zuweisen kannst:

```swift
let cpuBits = 32
let architecture = if cpuBits == 64 {
    "x86_64"
} else {
    "x86_32"
}

print(architecture)
// Prints "x86_32"
```
