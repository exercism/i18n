# Einführung

Zur Erinnerung: `jq` unterstützt dieselben Datentypen wie JSON.
JSON beschreibt **Strings** so:

> Ein String ist eine Folge von null oder mehr Unicode-Zeichen, die in doppelte Anführungszeichen eingeschlossen ist und Backslash-Escapes verwendet.

## Escape-Sequenzen

Innerhalb eines Strings verwendest du den Backslash, um „spezielle“ Zeichen einzubetten:

- `\"` ein wörtliches Anführungszeichen,
- `\\` ein wörtlicher Backslash,
- Whitespace-Zeichen `\n`, `\t`, `\r`, `\f`, `\b`
- Unicode-Zeichen `\uAAAA`, wobei `A` eine Hexadezimalziffer ist

## String-Länge

Um die Anzahl der Zeichen herauszufinden, verwendest du die Funktion `length`.

```sh
$ jq -cn --args  '$ARGS.positional[] | length' "Hello world!" "❄🌡🤧🤒🏥🕰😀"
12
7
```

## Teilstrings

Mit der **Slice**-Notation kannst du Teilstrings extrahieren.
Die Syntax ist `.[i:j]`.
Der zurückgegebene Teilstring hat die Länge `j - i` und enthält die Zeichen von Index `i` (einschließlich) bis Index `j` (ausschließlich).
Jeder der beiden Indizes kann negativ sein; dann zählt er vom Ende des Strings rückwärts.
Jeder der beiden Indizes kann weggelassen werden; dann steht er für den Anfang bzw. das Ende des Strings.
Die Indizes beginnen bei null.

```jq
"abcdefghij"[3:6]   # => "def"
"abcdefghij"[3:]    # => "defghij"
"abcdefghij"[:-2]   # => "abcdefgh"
```

## Verkettung

Mit `+` verkettest du Strings:

```jq
"Hello" + " " + "world!"
# => "Hello world!"
```

Verwende `add`, wenn du ein Array von Strings hast:

```jq
["Hello", " ", "world!"] | add
# => "Hello world!"
```

## Aufteilen und Zusammenfügen

Zum Aufteilen verwendest du die Funktion `split/1` oder den Operator `/`:

```jq
"Hello beautiful world!" | split(" ")   # => ["Hello", "beautiful", "world!"]
```

```jq
"Hello beautiful world!" / " "          # => ["Hello", "beautiful", "world!"]
```

Die Umkehrung von `split/1` ist `join/1`.

Häufig musst du einen String in ein Array von Zeichen umwandeln.
Dafür gibt es zwei Möglichkeiten:

1. an einem leeren String aufteilen

   ```jq
   "Hi friend 😀" / ""   # => ["H","i"," ","f","r","i","e","n","d"," ","😀"]
   ```

1. mit `explode` in ein Array von _Codepoints_ zerlegen

   ```jq
   "Hi friend 😀" | explode   # => [72,105,32,102,114,105,101,110,100,32,128512]
   ```

   `implode` ist die Umkehrung von `explode`.

## Den Index eines Teilstrings finden

Verwende die Funktion `index/1`; der Index beginnt bei null.

```jq
"hello" | index("el")'   # => 1
```

Wenn der Teilstring nicht im String vorkommt, ist das Ergebnis `null`

```jq
"hello" | index("elk")   # => null
```

## String-Interpolation

Innerhalb eines Strings bettet die Sequenz `\(expression)` das _Ergebnis_ dieses Ausdrucks [in den String][interpolate] ein:

```jq
"The current datetime is \(now | strflocaltime("%c"))"   # => "The current datetime is Wed Nov 16 17:06:33 2022"
```

## Groß- und Kleinschreibung

Verwende die Funktionen `ascii_downcase` und `ascii_upcase`.

## Reguläre Ausdrücke

`jq` unterstützt reguläre Ausdrücke umfassend: das wird Thema einer späteren Lektion sein.
