# Einführung

## Maps

Maps sind in Elixir die Datenstruktur, um Informationen in Schlüssel-Wert-Paaren zu speichern. In anderen Programmiersprachen sind sie auch als assoziative Arrays (PHP), Hashes (Perl 5, Raku) oder Wörterbücher (Python) bekannt.

Schlüssel und Werte können einen beliebigen Datentyp haben. Ist der Schlüssel jedoch ein Atom, können wir eine Kurzsyntax verwenden. Beim Zugriff auf eine Map oder wenn sie zurückgegeben wird, ist die Reihenfolge ihrer Einträge nicht garantiert.

### Literale Schreibweise

Eine leere Map erzeugst du einfach mit `%{}`. Wenn wir Einträge zu einer Map hinzufügen wollen, können wir zwei Formen verwenden:

```elixir
# If the key is an atom:
%{atom_key: 1}

# If the key is a different type:
%{1 => :atom_value}

# You can even mix these if the atom form comes second:
%{"first_form" => :a, atom_form: :b}
```

Es gibt kein kanonisches Format. Wähle trotzdem eine einheitliche Art, die Schlüssel-Wert-Paar-Literale darzustellen.

### Funktionen des Map-Moduls

Elixir bietet viele Funktionen für die Arbeit mit Maps im _Map-Modul_. Einige Funktionen des _Map-Moduls_ erwarten, dass eine _anonyme_ Funktion übergeben wird, die bei der Transformation der Map hilft.

## Modulattribute als Konstanten

In Elixir können wir Modulattribute definieren, die wir als Konstanten in unseren Funktionen verwenden können.

```elixir
defmodule Example do
  # Defines the attribute as the value 1
  @constant_number 1

  def example_value() do
    # Returns the value 1
    @constant_number
  end
end
```

Wenn sie zum Definieren von Modulkonstanten verwendet werden, können Attribute ein beliebiger Ausdruck sein, der zur Kompilierzeit ausgewertet werden kann. Nach der Kompilierung sind Modulattribute nicht mehr zugänglich, da sie während der Kompilierung expandiert werden, ähnlich wie definierte Makros in Sprachen wie C.
