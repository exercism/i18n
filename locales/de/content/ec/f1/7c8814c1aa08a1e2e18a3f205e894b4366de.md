# break und continue

Wenn du eine Schleife oder eine andere iterierende Kontrollstruktur verwendest, kannst du mit den Schlüsselwörtern `break` und `continue` den Ablauf eines Programms steuern.
Das Schlüsselwort `break` verlässt den Schleifenkontext in den äußeren Gültigkeitsbereich und beendet damit die Schleife.
Das Schlüsselwort `continue` überspringt den Rest der aktuellen Iteration und startet den Schleifenkontext am Anfang der nächsten Iteration neu.
Auch wenn es selten vorkommt, kannst du dem Schlüsselwort eine Zahl mitgeben, um zu steuern, aus wie vielen Kontexten du ausbrichst oder wie viele Iterationen du überspringst.

```php
<?php
$i = 1;
while ($i <= 10) {

    if ($i <= 5) {
        i += 1;
        continue;
    }
    break;
}
```

Im vorherigen Beispiel wird `continue` fünf (5) Mal ausgeführt, aber in der sechsten (6) Iteration wird `break` ausgeführt, wodurch der Code die Schleife verlässt.
