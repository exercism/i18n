# Hinweise

## 1. Eine Karte aus einem Deck entnehmen

- Die Indizes von `Vector` beginnen bei `1`.
- Du kannst den `n`-ten Wert in einem `Vector` `v` mit `v[n]` abrufen.

## 2. Eine Karte im Deck austauschen

- `Vector`s sind veränderbar, du kannst ihren Inhalt jederzeit ändern.
- Die Methode nimmt ein [Pair](https://docs.julialang.org/en/v1/base/collections/#Base.Pair) als Argument.
- Du kannst mit `p.first` und `p.second` auf die Felder eines `Pair` `p` zugreifen.

## 3. Eine Karte oben auf das Deck legen

- In Base gibt es eine Methode [`push!`](https://docs.julialang.org/en/v1/base/collections/#Base.push!), um einen neuen Wert am Ende einer Collection hinzuzufügen.

## 4. Eine Karte aus dem Deck entfernen

- In Base gibt es eine Methode [`deleteat!`](https://docs.julialang.org/en/v1/base/collections/#Base.deleteat!), um ein Element an einem bestimmten Index aus einem `Vector` zu löschen.

## 5. Die oberste Karte vom Deck nehmen

- In Base gibt es eine Methode [`pop!`](https://docs.julialang.org/en/v1/base/collections/#Base.pop!), um ein Element am Ende einer Collection zu entfernen.

## 6. Eine Karte am unteren Ende des Decks einfügen

- In Base gibt es eine Methode [`pushfirst!`](https://docs.julialang.org/en/v1/base/collections/#Base.pushfirst!), um einen neuen Wert am Anfang einer Collection einzufügen.

## 7. Eine Karte am unteren Ende des Decks entfernen

- In Base gibt es eine Methode [`popfirst!`](https://docs.julialang.org/en/v1/base/collections/#Base.popfirst!), um ein Element am Anfang einer Collection zu entfernen.

## 8. Die Größe des Decks prüfen

- In Base gibt es eine Methode [`length`](https://docs.julialang.org/en/v1/base/collections/#Base.length), um die Länge einer Collection abzurufen.
