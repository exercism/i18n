# Anleitung

Du arbeitest am Sicherheitsschalter einer Forschungsstation. Mitarbeitende tragen *Ausweise*, deren Codes einem strengen Format folgen, das Zugriffsprotokoll ist voll von diesen Codes, die in gewöhnlichen Text eingestreut sind, und das Protokoll muss bereinigt werden, bevor es geteilt werden kann. Reguläre Ausdrücke sind für jede dieser Aufgaben das richtige Werkzeug.

Ein gültiger Ausweiscode besteht aus **zwei Großbuchstaben, einem Bindestrich und dann vier Ziffern**, zum Beispiel `NS-1024`.

## 1. Prüfe einen Ausweiscode

Definiere `valid-badge?`, das einen Ausweis-String entgegennimmt und `t` zurückgibt, wenn der *gesamte* String ein gültiger Ausweiscode ist, andernfalls `f`.

```factor
"NS-1024" valid-badge? .   ! => t
"NS-10"   valid-badge? .   ! => f
```

## 2. Hole jeden Code aus einer Protokollzeile

Definiere `badge-codes`, das eine Zeile des Zugriffsprotokolls entgegennimmt und eine Sequenz aller Ausweiscodes zurückgibt, die darin vorkommen, in der Reihenfolge ihres Auftretens.

```factor
"seen NS-1024 then AB-0007 today" badge-codes .
! => { "NS-1024" "AB-0007" }
```

## 3. Zähle die Ziffern in einem Code

Definiere `digit-count`, das einen String entgegennimmt und zurückgibt, wie viele Ziffern er enthält.

```factor
"NS-1024" digit-count .   ! => 4
```

## 4. Passwörter schwärzen

Protokollzeilen zeichnen manchmal ein Passwort in der Form `pass=`, gefolgt von dem Geheimnis (eine beliebige Folge von Zeichen, die keine Leerzeichen sind), auf. Definiere `redact`, das eine Zeile entgegennimmt und sie zurückgibt, wobei jedes solche Passwort durch `pass=****` ersetzt wird.

```factor
"user=alice pass=hunter2 ok" redact .
! => "user=alice pass=**** ok"
```
