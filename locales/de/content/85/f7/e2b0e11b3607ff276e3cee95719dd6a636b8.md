# Tests

## Tests ausführen

Um die Tests auszuführen, führe den folgenden Befehl aus:

```bash
dotnet test
```

## Die Übung lösen

Eine Übung zu lösen heißt, alle ihre Tests zu bestehen. Standardmäßig wird nur ein Test (der erste) ausgeführt, wenn du die Tests laufen lässt. Das ist Absicht, denn so kannst du dich darauf konzentrieren, genau diesen einen Test zu bestehen. Sobald er läuft, kannst du den nächsten Test aktivieren, indem du `Skip = "Remove this Skip property to run this test"` aus dem `[<Fact>]`- oder `[<Theory>]`-Attribut des Tests entfernst. Wenn alle Tests aktiviert sind und deine Implementierung sie alle besteht, hast du die Übung gelöst!

Damit du leichter loslegen kannst, enthält jede Übung eine Stub-Implementierungsdatei. Du kannst diese Datei als Ausgangspunkt für deine Lösung verwenden. Diese Datei darfst du gerne löschen oder ändern, wenn du meinst, dass es richtig ist.

## Pakete verwenden

Die meisten Übungen solltest du lösen können, ohne externe Pakete zu verwenden. Wenn du für eine Übung aber doch ein externes Paket verwenden möchtest, kannst du es mit dem folgenden Befehl zu deinem Projekt hinzufügen:

```bash
dotnet add package [package-name]
```
