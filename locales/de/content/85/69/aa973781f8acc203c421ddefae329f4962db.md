# Einführung

## Zahlen

In Java gibt es zwei verschiedene Arten von Zahlen:

- Ganzzahlen: Zahlen ohne Ziffern hinter dem Dezimaltrennzeichen (ganze Zahlen).
  Beispiele sind `-6`, `0`, `1`, `25`, `976` und `-500000`.
- Gleitkommazahlen: Zahlen mit null oder mehr Ziffern hinter dem Dezimaltrennzeichen.
  Beispiele sind `-20.4`, `0.1`, `2.72`, `16.984025` und `1024.0`.

Die beiden häufigsten numerischen Typen in Java sind `int` und `double`.
Ein `int` ist eine 32-Bit-Ganzzahl und ein `double` ist eine 64-Bit-Gleitkommazahl.

Für Rechenoperationen verwendest du die üblichen Rechenoperatoren.
Zahlen kannst du mit den üblichen numerischen Vergleichsoperatoren vergleichen (z. B. `5 > 4` und `4 <= 5`) sowie mit den Operatoren für Gleichheit (`==`) und Ungleichheit (`!=`).

In Java gibt es zwei Arten von numerischen Konvertierungen:

1. Implizite Konvertierungen: Es gehen keine Daten verloren und es ist keine zusätzliche Syntax nötig.
2. Explizite Konvertierungen: Es könnten Daten verloren gehen und es ist zusätzliche Syntax in Form eines _Casts_ erforderlich.

Da ein `int` weniger präzise ist als ein `double`, ist die Umwandlung von einem `int` in ein `double` sicher und damit eine implizite Konvertierung.
Die Umwandlung von einem `double` in ein `int` kann jedoch bedeuten, dass Daten verloren gehen, deshalb ist dafür eine explizite Konvertierung nötig.

## if-else-Anweisungen

### Die _if-then_-Anweisung

Die grundlegendste Kontrollfluss-Anweisung in Java ist die _if-then_-Anweisung.
Mit dieser Anweisung führst du einen Codeabschnitt nur dann aus, wenn eine bestimmte Bedingung `true` ist.
Eine _if-then_-Anweisung wird mit der `if`-Klausel definiert:

```java
class Car {
    void drive() {
        // the "if" clause: the car needs to have fuel left to drive
        if (fuel > 0) {
            // the "then" clause: the car drives, consuming fuel
            fuel--;
        }
    }
}
```

Im obigen Beispiel passiert nichts, wenn du die Methode `Car.drive` aufrufst und das Auto keinen Kraftstoff mehr hat.

### Die _if-then-else_-Anweisung

Die _if-then-else_-Anweisung bietet einen alternativen Ausführungspfad für den Fall, dass die Bedingung in der `if`-Klausel `false` ergibt.
Dieser alternative Ausführungspfad folgt auf eine `if`-Klausel und wird mit der `else`-Klausel definiert:

```java
class Car {
    void drive() {
        if (fuel > 0) {
            fuel--;
        } else {
            stop();
        }
    }
}
```

Im obigen Beispiel ruft der Aufruf der Methode `Car.drive` eine andere Methode auf, um das Auto anzuhalten, wenn das Auto keinen Kraftstoff mehr hat.

Die _if-then-else_-Anweisung unterstützt auch mehrere Bedingungen, indem du die `else if`-Klausel verwendest:

```java
class Car {
    void drive() {
        if (fuel > 5) {
            fuel--;
        } else if (fuel > 0) {
            turnOnFuelLight();
            fuel--;
        } else {
            stop();
        }
    }
}
```

Im obigen Beispiel fährt das Auto, wenn der Kraftstoffstand kleiner oder gleich `5` ist, aber dabei geht die Tankwarnleuchte an.
Wenn der Kraftstoff `0` erreicht, hält das Auto an.
