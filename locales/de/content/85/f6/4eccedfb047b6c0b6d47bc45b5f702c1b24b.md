# Ergänzung zu den Anweisungen

## Implementierung

Definiere eine einzelne Go-Funktion, Solve, die einen Puzzle-String entgegennimmt, der null oder mehr + Operatoren und einen == Operator enthalten kann. Solve sollte versuchen, das Alphametik-Rätsel zu lösen und eine Map mit allen Buchstabensubstitutionen sowohl für das Rätsel als auch für die Lösung der Addition zurückgeben.

Verwende für die Funktion Solve die folgende Signatur:

```go
func Solve(puzzle string) (map[string]int, error) {
```

Solve sollte einen Fehler zurückgeben, wenn es keine Lösung für das gegebene Rätsel gibt.

Ein Beispiel für ein Rätsel und die zurückgegebene Lösung ist:

```go
Solve("SEND + MORE == MONEY")
```

würde zurückgeben

```go
map[string]int{"M":1, "O":0, "N":6, "E":5, "Y":2, "S":9, "D":7, "R":8}, nil
```

```text
  S E N D
  M O R E +
-----------
M O N E Y
```

Ersetzt man diese durch gültige Zahlen, ergibt das:

```text
  9 5 6 7
  1 0 8 5 +
-----------
1 0 6 5 2
```
