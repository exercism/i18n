# Tests ausführen

Um die Testsuite auszuführen, führe den folgenden Befehl aus:

```bash
stack test
```

#### Wenn du eine Fehlermeldung wie diese bekommst ...

```
No .cabal file found in directory
```

oder

```
RedownloadInvalidResponse Request {
...
}
 "/home/username/.stack/build-plan/lts-xx.yy.yaml" (Response {responseStatus = Status {statusCode = 404, statusMessage = "Not Found"},
```

Dann verwendest du wahrscheinlich eine alte Version von Stack und musst sie aktualisieren. Versuch es mit:

```bash
stack upgrade
```

Oder schau dir weitere Möglichkeiten zum Aktualisieren in der [Stack-Dokumentation](https://docs.haskellstack.org/en/stable/install_and_upgrade/#upgrade) an.

#### Andernfalls, wenn du eine Fehlermeldung wie diese bekommst ...

```
No compiler found, expected minor version match with...
Try running "stack setup" to install the correct GHC...
```

Dann mach einfach, was dort steht, und die richtige Compiler-Version wird heruntergeladen und installiert:

```bash
stack setup
```

# *GHCi* ausführen

Wenn du mit deiner Lösung in GHCi herumprobieren möchtest, führe einfach diesen Befehl aus:

```bash
stack ghci
```
