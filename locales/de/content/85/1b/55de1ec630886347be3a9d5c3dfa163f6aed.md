# Einführung

## Funktionstypen

Wenn man alle Namen und Bezeichnungen aus einer Swift-Funktionssignatur entfernt, bleibt der Typ der Funktion übrig.

```swift
func shoppingList(item: String, quantity: Int) -> String {
  "You need to buy \(quantity) \(item)."
}
// shoppingList: (String, Int) -> String

func repeater(_ phrase: String, times: Int) -> String {
  var result = ""
  for _ in 1...times {
    result += phrase
  }
  return result
}
// repeater: (String, Int) -> String

func printString(line: String) {
  print(line)
}
// printString: (String) -> ()
```

Beachte, dass die Typen der ersten beiden Funktionen gleich sind, `(String, Int) -> String`, obwohl die beiden Signaturen unterschiedlich sind und die beiden Funktionen sehr unterschiedlich arbeiten. Beide nehmen einen `String` und einen `Int` als Eingabewerte und geben einen `String` zurück. Und wie man am Typ der dritten Funktion sieht, gibt diese, obwohl der Funktionskörper nichts zurückzugeben scheint, tatsächlich implizit `()` zurück, den einzigen Wert des Typs `Void`.

Diese Funktionstypen können genauso verwendet werden wie jeder andere Typ in Swift. Zum Beispiel können sie in der Deklaration von Variablen oder Konstanten verwendet werden. Und da Funktionen in Swift Werte sind, können bereits vorhandene Funktionen diesen Konstanten/Variablen zugewiesen werden:

```swift
var stringAndIntToString: (String, Int) -> String

stringAndIntToString = shoppingList
stringAndIntToString("carrots", 3)
// => "You need to buy 3 carrots."
```

Wie bei anderen Variablen/Konstanten muss der Wert, den du zuweist, den richtigen Typ haben:

```swift
stringAndIntToString = printShoppingList
// Error: Cannot assign value of type '(String) -> ()' to type '(String, Int) -> String'
```

## Funktionstypen als Parametertypen

Da Funktionstypen überall dort verwendet werden können, wo auch andere Typen verwendet werden können, können sie auch als Parametertypen verwendet, in andere Funktionen übergeben und innerhalb dieser Funktionen aufgerufen werden.

```swift
func apply3(to str: String, function f: (String, Int) -> String) -> String {
  f(str,3)
}
// apply3: ([String], (String, Int) -> String) -> [String]

apply3(to: "eggs", function: shoppingList)
// => "You need to buy 3 eggs."

apply3(to: "eggs", function: repeater)
// => "eggseggseggs"
```

## Funktionstypen als Rückgabetypen

Ebenso können Funktionstypen als Rückgabetypen für Funktionen verwendet werden. Mit anderen Worten: Man kann Funktionen schreiben, die andere Funktionen erzeugen und zurückgeben. Beim Erzeugen dieser Funktionen kann die zurückgegebene Funktion die anderen Parameter verwenden, die in die Funktion übergeben wurden, oder die lokalen Variablen, die innerhalb der übergeordneten Funktion erstellt wurden.

```swift
func makeAdder(base: Int) -> (Int) -> Int {
  func adder(_ i: Int) -> Int {
    base + i
  }
  return adder
}
// makeAdder: (Int) -> (Int) -> Int

let add10 = makeAdder(base: 10)
// add10: (Int) -> Int

let subtract20 = makeAdder(base: -20)
// subtract20: (Int) -> Int

add10(5)
// => 15

subtract20(5)
// => -15
```
