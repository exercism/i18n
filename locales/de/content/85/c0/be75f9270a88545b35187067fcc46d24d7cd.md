Doch die Sache ist ein wenig unordentlich: Azaras Koordinaten scheinen anders formatiert und sortiert zu sein als die von Rui, und die beiden müssen ständig von der einen Liste zur anderen schauen, um herauszufinden, welche Schätze zu welchen Orten gehören.
Da sie angehende Julia-Programmierer sind, kommen sie zu dir und bitten um Hilfe beim Schreiben eines kleinen Programms (genauer gesagt einer Reihe von Funktionen), mit dem sie ihre Informationen zur Schatzsuche besser ordnen können.

## 1. Koordinaten extrahieren

Implementiere die Funktion `get_cooordinate()`, die ein Paar `(treasure, coordinate)` aus Azaras Liste entgegennimmt und nur die extrahierte Kartenkoordinate zurückgibt.

```julia-repl
julia> get_cooordinate( ("Scrimshaw Whale's Tooth", "2A") )
"2A"
```

## 2. Koordinaten formatieren

Implementiere die Funktion `convert_coordinate()`, die eine Koordinate im Format „2A“ entgegennimmt und ein Tupel im Format `('2', 'A')` zurückgibt.

```julia-repl
julia> convert_coordinate("2A")
('2', 'A')
```

## 3. Koordinaten abgleichen

Implementiere die Funktion `compare_records()`, die ein Paar `(treasure, coordinate)` und einen Datensatz `(location, coordinate, quadrant)` entgegennimmt und die Koordinaten aus beiden vergleicht.
Gib **`true`** zurück, wenn die Koordinaten „übereinstimmen“, und **`false`**, wenn nicht.
Formatiere die Koordinaten bei Bedarf neu, damit der Vergleich genau ist.

```julia-repl
julia> compare_records(("Brass Spyglass", "4B"), ("Seaside Cottages", ('1', 'C'), "blue"))
false

julia> compare_records(("Model Ship in Large Bottle", "8A"), ("Harbor Managers Office", ('8', 'A'), "purple"))
true
```

## 4. Übereinstimmende Datensätze zusammenführen

Implementiere die Funktion `create_record()`, die ein Paar `(treasure, coordinate)` aus Azaras Liste und einen Datensatz `(location, coordinate, quadrant)` aus Ruis Liste entgegennimmt und `(coordinate, location, quadrant, treasure)` zurückgibt, **wenn die Koordinaten übereinstimmen**.

Wenn die Koordinaten _nicht_ übereinstimmen, gib ein leeres Tupel zurück.
Formatiere die Koordinaten bei Bedarf neu, damit der Vergleich genau ist.

```julia-repl
julia> create_record(("Brass Spyglass", "4B"), ("Abandoned Lighthouse", ('4', 'B'), "Blue"))
("4B", "Abandoned Lighthouse", "Blue", "Brass Spyglass")

julia> create_record(("Brass Spyglass", "4B"), ("Seaside Cottages", ('1', 'C'), "Blue"))
()
```
