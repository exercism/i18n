# Anweisungen

In dieser Übung schreibst du etwas Code, der dir hilft, eine großartige Lasagne aus deinem Lieblingskochbuch zu kochen.
Du hast vier Aufgaben, die alle mit der Zeit zu tun haben, die du mit dem Kochen der Lasagne verbringst.

## 1. Definiere die erwartete Backofenzeit in Minuten

Definiere die Konstante `expectedMinutesInOven`, die speichert, wie viele Minuten die Lasagne im Backofen bleiben soll.
Laut Kochbuch beträgt die erwartete Backofenzeit 40 Minuten:

```swift
expectedMinutesInOven
// Returns 40
```

## 2. Berechne die verbleibende Backofenzeit in Minuten

Definiere die Funktion `remainingMinutesInOven(elapsedMinutes:)`, die das Argument `elapsedMinutes` entgegennimmt, das die Anzahl der Minuten enthält, die die Lasagne bereits im Backofen war.
Die Funktion soll zurückgeben, wie viele Minuten die Lasagne noch im Backofen bleiben muss, basierend auf der erwarteten Backofenzeit in Minuten aus der vorherigen Aufgabe.

```swift
remainingMinutesInOven(elapsedMinutes: 30)
// Returns 10
```

## 3. Berechne die Vorbereitungszeit in Minuten

Definiere die Funktion `preparationTimeInMinutes(layers:)`, die das Argument `layers` entgegennimmt, das die Anzahl der Schichten enthält, die du der Lasagne hinzugefügt hast.
Die Funktion soll zurückgeben, wie viele Minuten du für die Vorbereitung der Lasagne gebraucht hast, wobei jede Schicht 2 Minuten Vorbereitung benötigt.

```swift
preparationTimeInMinutes(layers: 2)
// Returns 4
```

## 4. Berechne die gesamte Arbeitszeit in Minuten

Definiere die Funktion `totalTimeInMinutes(layers:elapsedMinutes:)`, die zwei Argumente entgegennimmt: Der Parameter `layers` ist die Anzahl der Schichten, die du der Lasagne hinzugefügt hast, und der Parameter `elapsedMinutes` ist die Anzahl der Minuten, die die Lasagne bereits im Backofen war.
Die Funktion soll zurückgeben, wie viele Minuten du insgesamt mit dem Kochen der Lasagne verbracht hast. Das ist die Summe aus der Vorbereitungszeit in Minuten und der Zeit in Minuten, die die Lasagne bis jetzt im Backofen verbracht hat.

```swift
totalTimeInMinutes(layers: 3, elapsedMinutes: 20)
// Returns 26
```
