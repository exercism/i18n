# Anhang zur Anleitung

## Register

| Register | Verwendung   | Typ      | Beschreibung                              |
| -------- | ------------ | -------- | ----------------------------------------- |
| `$a0`    | Eingabe      | Adresse  | erste Farbe als nullterminierter String   |
| `$a1`    | Eingabe      | Adresse  | zweite Farbe als nullterminierter String  |
| `$a2`    | Eingabe      | Adresse  | dritte Farbe als nullterminierter String  |
| `$a3`    | Ein-/Ausgabe | Adresse  | nullterminierter String für die Ausgabe   |
| `$t0-9`  | temporär     | beliebig | dient zur temporären Speicherung          |
