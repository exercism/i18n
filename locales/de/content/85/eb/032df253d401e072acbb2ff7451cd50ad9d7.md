# Einführung

Python stellt wahre und falsche Werte mit dem Typ [`bool`][bools] dar, der eine Unterklasse von `int` ist.
Unter diesem Typ gibt es nur zwei Werte: `True` und `False`.
Diese Werte kannst du an eine Variable binden:

```python
>>> true_variable = True
>>> false_variable = False
```

Boolesche Ausdrücke werten wir mit den Operatoren `and`, `or` und `not` aus.

```python
>>> true_variable = True and True
>>> false_variable = True and False

>>> true_variable = False or True
>>> false_variable = False or False

>>> true_variable = not False
>>> false_variable = not True
```

[bools]: https://docs.python.org/3/library/stdtypes.html#typebool
