# Einführung

Ein *disposable* ist alles, was eine Betriebssystem-Ressource hält (eine geöffnete Datei, ein Socket, ein Lock, das auf einer Hashtabelle basiert) und freigegeben werden muss, wenn du damit fertig bist. Das Vocab [`destructors`][destructors] von Factor verpackt diese in ein kleines Framework, sodass das Aufräumen auch dann stattfindet, wenn eine Exception den Stack abwickelt.

```factor
USING: destructors io.files io.encodings.utf8 ;

"log.txt" utf8 <file-writer> [
    "hello, world" write
] with-disposal
! file is closed even if write throws
```

`with-disposal ( disposable quot -- )` führt die Quotation mit der Ressource aus und gibt sie beim Verlassen frei. Bei mehr als einer Ressource öffnest du mit `with-destructors` einen Bereich und registrierst jede Ressource mit `&dispose` (Freigabe beim normalen Verlassen *und* bei einem Fehler) oder `|dispose` (Freigabe nur bei einem Fehler).

Eine Klasse wird Teil des Frameworks, indem sie `disposable` erweitert und das generische Wort `dispose*` implementiert. Das Framework ruft es genau einmal pro Objekt auf. Das öffentliche Wort, das Aufrufer verwenden, ist `dispose`.

[destructors]: https://docs.factorcode.org/content/vocab-destructors.html
