# Einführung

## Listen

Listen sind in Elixir eingebaut. Sie gelten als grundlegender Typ und werden durch eckige Klammern gekennzeichnet. Listen können leer sein oder beliebig viele Elemente beliebigen Typs enthalten. Zum Beispiel:

```elixir
empty_list = []
one_item_list = [1]
two_item_list = [1, 2]
multiple_type_list = [1, :pi, 3.14, "four"]
```

Elixir implementiert Listen als verkettete Liste, bei der jeder Knoten zwei Werte speichert: das erste Element und eine weitere Liste mit allen restlichen Elementen. Das erste Element der Liste wird als _Kopf_ bezeichnet, die restliche Liste als _Rest_. Diese Notation können wir im Code verwenden:

```elixir
# [1] represented in [head | tail] notation
[1 | []]

# [1, 2, 3] represented in [head | tail] notation
[1 | [2 | [3 | []]]]
```

Mit der Notation _`[head | tail]`_ können wir einer Liste Elemente voranstellen:

```elixir
# Suppose
list = [2, 1]

[3, 2, 1] == [3 | list]
# => true
```

Im Modul `Kernel` gibt es mehrere Funktionen für die Arbeit mit Listen, ebenso wie das gesamte Modul `List`.

```elixir
# Check if 1 is a member of the list
1 in [1, 2, 3, 4]
# => true
```
