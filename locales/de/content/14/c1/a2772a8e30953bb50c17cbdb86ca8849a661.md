# Anweisungen

Izzy ist eine begeisterte Vogelbeobachterin und hält fest, wie viele Vögel an einem beliebigen Tag ihren Garten besucht haben.

Sie hat dich gebeten, ihr Vogelbeobachten auf ein neues Niveau zu bringen und ein paar Tools zu implementieren, die ihr helfen, die Daten zu verfolgen und auszuwerten.

Du hast dich dafür entschieden, die Daten als Liste von Ganzzahlen zu speichern. Die erste Zahl in der Liste ist die Anzahl der Vögel, die heute deinen Garten besucht haben, die zweite die von gestern und so weiter.

## 1. Prüfe, wie viele Vögel heute zu Besuch waren

Implementiere die Funktion `today`. Sie soll eine Liste der täglichen Vogelzahlen entgegennehmen und die heutige Anzahl zurückgeben. Wenn die Liste leer ist, soll sie `0` zurückgeben.

```gleam
today([2, 5, 1])
// -> 2
```

## 2. Erhöhe die heutige Anzahl

Implementiere die Funktion `increment_day_count`. Sie soll eine Liste der täglichen Vogelzahlen entgegennehmen und die heutige Anzahl um 1 erhöhen. Wenn die Liste leer ist, gib `[1]` zurück.

```gleam
increment_day_count([4, 0, 2])
// -> [5, 0, 2]
```

## 3. Prüfe, ob es einen Tag ohne Vögel gab

Implementiere die Funktion `has_day_without_birds`. Sie soll eine Liste der täglichen Vogelzahlen entgegennehmen. Sie soll `True` zurückgeben, wenn es mindestens einen Tag gab, an dem keine Vögel den Garten besucht haben, und sonst `False`. Wenn die Liste leer ist, bedeutet das, dass _noch_ keine Vögel erfasst wurden; gib `False` zurück.

```gleam
has_day_without_birds([2, 0, 4])
// -> True

has_day_without_birds([3, 8, 1, 5])
// -> False
```

## 4. Berechne die Gesamtzahl der Vögel, die zu Besuch kamen

Implementiere die Funktion `total`. Sie soll eine Liste der täglichen Vogelzahlen entgegennehmen und die Gesamtzahl der Vögel zurückgeben, die deinen Garten besucht haben, seitdem du begonnen hast, die Daten zu sammeln.

```gleam
total([4, 0, 9, 0, 5])
// -> 18
```

## 5. Berechne die Anzahl der Tage mit viel Betrieb

An manchen Tagen ist mehr los als an anderen. Ein Tag mit viel Betrieb ist ein Tag, an dem fünf oder mehr Vögel deinen Garten besucht haben.

Implementiere die Funktion `busy_days`. Sie soll eine Liste der täglichen Vogelzahlen entgegennehmen und die Anzahl der Tage mit viel Betrieb zurückgeben.

```gleam
busy_days([4, 5, 0, 0, 6])
// -> 2
```
