# Ergänzung zur Anleitung

## Register

| Register | Verwendung   | Typ      | Beschreibung                     |
| -------- | ------------ | -------- | -------------------------------- |
| `$a0`    | Eingabe      | Adresse  | nullterminierter Eingabe-String  |
| `$a1`    | Ein-/Ausgabe | Adresse  | nullterminierter Ergebnis-String |
| `$t0-9`  | temporär     | beliebig | für die temporäre Speicherung    |
