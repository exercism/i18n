# Anweisungen

Ein Chiffrierrad besteht aus zwei Scheiben, eine in der anderen, die das Alphabet verdrehen: Stell es auf 3, und jeder Buchstabe wird zu dem Buchstaben drei Stellen weiter, wobei `z` wieder bei `a` ankommt. Detektive benutzen sie seit Jahrhunderten. Du baust gerade eines.

Alle fünf Aufgaben kommen in die Klasse `CIPHER_WHEEL`.

## 1. Ist es ein Buchstabe?

```sather
CIPHER_WHEEL::is_letter('m')
-- => true
CIPHER_WHEEL::is_letter('7')
-- => false
```

## 2. Schrei es

Gib den Großbuchstaben eines Zeichens zurück. Alles, was kein Buchstabe ist, kommt unverändert zurück.

```sather
CIPHER_WHEEL::shout('m')
-- => 'M'
```

## 3. Welche Zahl ist es?

Gib die Zahl zurück, die für ein Zeichen steht.

```sather
CIPHER_WHEEL::code('a')
-- => 97
```

## 4. Das erste Zeichen

Gib das erste Zeichen eines Strings zurück.

```sather
CIPHER_WHEEL::first_character("Marlowe")
-- => 'M'
```

## 5. Dreh das Chiffrierrad

Gegeben sei ein Kleinbuchstabe und eine Anzahl von Stellen. Gib den Buchstaben zurück, der entsprechend viele Stellen weiter im Alphabet liegt. Über `z` hinaus geht es wieder bei `a` los.

```sather
CIPHER_WHEEL::turn('a', 3)
-- => 'd'
CIPHER_WHEEL::turn('z', 1)
-- => 'a'
```

Das Drehen rückwärts funktioniert ebenfalls, mit einer negativen Anzahl von Stellen.

```sather
CIPHER_WHEEL::turn('a', -1)
-- => 'z'
```

Du kannst davon ausgehen, dass das übergebene Zeichen ein Kleinbuchstabe ist.
