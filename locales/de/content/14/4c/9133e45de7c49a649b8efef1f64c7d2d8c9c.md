# Anleitung

Finde heraus, ob eine Zahl perfect, abundant oder deficient ist. Das basiert auf dem Klassifikationsschema von Nikomachos (60–120 n. Chr.) für positive Ganzzahlen.

Der griechische Mathematiker [Nikomachos](https://en.wikipedia.org/wiki/Nicomachus) entwickelte ein Klassifikationsschema für positive Ganzzahlen, das jede von ihnen eindeutig einer der Kategorien **perfect**, **abundant** oder **deficient** zuordnet, und zwar anhand ihrer [aliquoten Summe](https://en.wikipedia.org/wiki/Aliquot_sum). Die aliquote Summe ist die Summe der Teiler einer Zahl, ohne die Zahl selbst. Zum Beispiel ist die aliquote Summe von 15 gleich (1 + 3 + 5) = 9

- **Perfect**: aliquote Summe = Zahl
  - 6 ist eine perfect-Zahl, weil (1 + 2 + 3) = 6
  - 28 ist eine perfect-Zahl, weil (1 + 2 + 4 + 7 + 14) = 28
- **Abundant**: aliquote Summe > Zahl
  - 12 ist eine abundant-Zahl, weil (1 + 2 + 3 + 4 + 6) = 16
  - 24 ist eine abundant-Zahl, weil (1 + 2 + 3 + 4 + 6 + 8 + 12) = 36
- **Deficient**: aliquote Summe < Zahl
  - 8 ist eine deficient-Zahl, weil (1 + 2 + 4) = 7
  - Primzahlen sind deficient

Implementiere eine Möglichkeit festzustellen, ob eine gegebene Zahl **perfect** ist. Je nach deinem Sprach-Track musst du vielleicht auch feststellen können, ob eine gegebene Zahl **abundant** oder **deficient** ist.
