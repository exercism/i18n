# Einführung

Ein String-Puffer ist eine effiziente Möglichkeit, einen großen String aufzubauen, indem du kleine Elemente nacheinander anhängst. Anders als ein String ist eine Instanz von `StringBuf` nicht unveränderlich, und zwar in dem Sinne, dass sie als Argument an Funktionen übergeben werden kann, die sie durch das Anhängen weiterer Werte verändern.

```haxe
var a = new StringBuf();
a.add("Hello");
trace(a.toString()); // Hello
a.add("Haxe!");
trace(a.toString()); // HelloHaxe
```
