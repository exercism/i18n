# Einführung

In Haxe ist eine `class` die grundlegende Datenstruktur, die Daten (Felder) und Verhalten (Methoden) kapselt. Felder und Methoden werden auch Mitglieder einer Klasse genannt.

Der Zugriff auf die Mitglieder lässt sich mit Zugriffsmodifikatoren einschränken. Es gibt:

- `public`: Auf das Mitglied kann von überall zugegriffen werden.
- `private`: Auf das Mitglied kann nur dieselbe Klasse zugreifen.

Klassen kann man sich als Vorlagen für das Erstellen von Instanzen vorstellen. Um eine Instanz zu erstellen, verwendest du einfach das Schlüsselwort `new`:

```haxe
class Car {
  public function new() {}
}

var myCar = new Car();
var yourCar = new Car();
```

Um ein Feld zu definieren, schreibst du einen Zugriffsmodifikator, gefolgt vom Namen und Typ der Variable:

```haxe
class Car {
  public var weight:Int; // Accessable by anyone

  private var color:String; // Accessable only within this class
}
```

Du kannst beim Definieren eines Feldes auch einen Anfangswert festlegen. Wenn ein Feld keinen Anfangswert angibt, bekommt es den Wert `null`. Auf ein Feld greifst du mit der Punktnotation zu:

```haxe
class Car {
  public var weight:Int = 2500; // Weight will be set to 2500
  public var year:Int; // year will be null

  public function new() {}
}

var newCar = new Car();
newCar.weight; // 2500
newCar.year; // null

// Update value of field
newCar.year = 2020;
```
