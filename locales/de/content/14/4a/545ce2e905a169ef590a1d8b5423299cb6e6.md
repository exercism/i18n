# Über

Ein String repräsentiert Textdaten.
In Swift ist ein [`String`][strings-and-characters] eine geordnete Sammlung von `Character`-Werten, wobei jedes Zeichen ein Unicode-Zeichen darstellt.

Du erstellst einen String mit einem String-Literal, also einer Folge von Zeichen, die von doppelten Anführungszeichen (`"`) umschlossen ist.
Für mehrzeilige Strings verwendest du drei doppelte Anführungszeichen (`"""`):

```swift
let hello: String = "Hello, World!"

let poem: String = """
Roses are red,
Violets are blue.
Sugar is sweet,
And so are you.
"""
```

Swift-Strings sind nahtlos mit der Klasse [`NSString`][nsstring-docs] des Foundation-Frameworks verzahnt und bieten damit Zugriff auf umfangreiche Möglichkeiten der Textverarbeitung.

## Zeichen

Ein `Character` repräsentiert einen einzelnen erweiterten Graphemcluster, also ein für Menschen lesbares Zeichen, das aus einem oder mehreren [Unicode-Skalarwerten][unicode-scalar-values] besteht.
Ein Unicode-Skalarwert ist ein 21-Bit-Codepunkt im Bereich `U+0000` bis `U+D7FF` (einschließlich) oder `U+E000` bis `U+10FFFF` (einschließlich).

```swift
let aChar: Character = "A"
```

## Typinferenz

Wenn du ein String-Literal schreibst, leitet Swift automatisch den Typ `String` ab.
Um ein einzelnes Zeichen als `Character` zu speichern, musst du eine explizite Typannotation angeben:

```swift
let aString = "A"        // Inferred as String
let aChar: Character = "A" // Explicitly typed as Character
print(type(of: aString)) // Prints String
print(type(of: aChar))   // Prints Character

// The following code will not compile:
let badChar: Character = "Too many characters"
// Error: Cannot convert value of type 'String' to specified type 'Character'
```

## Verkettung

Du kannst Strings mit dem Additionsoperator (`+`) aneinanderhängen:

```swift
print("honey" + "comb")
// Prints "honeycomb"
```

Mit `+` kannst du einen `Character` nicht direkt an einen `String` anhängen, ohne das Zeichen zuvor in einen String umzuwandeln.
Mit der Methode [`append(_:)`][append] kannst du jedoch sowohl einen String als auch ein Zeichen direkt an einen veränderbaren String anhängen:

```swift
var greeting = "Hello"
let world = ", world"
let period: Character = "."

greeting.append(world)
print(greeting) // Prints "Hello, world"

greeting.append(period)
print(greeting) // Prints "Hello, world."
```

## String-Interpolation

Mit der [String-Interpolation][string-interpolation] kannst du einen String aufbauen, indem du Konstanten, Variablen, Literale und Ausdrücke in String-Literale einbettest.
Setze jeden Ausdruck in runde Klammern, denen ein Backslash vorangeht (`\(` ... `)`):

```swift
let radius = 5.0
let circle = "The area of a circle with radius \(radius) is \(Double.pi * radius * radius)"
print(circle) // Prints "The area of a circle with radius 5.0 is 78.53981633974483"
```

## Eigenschaften von Strings und Characters

Strings und Characters bieten mehrere Eigenschaften, mit denen du ihren Inhalt untersuchen kannst.

### Eigenschaften von Strings

Häufige Eigenschaften von Strings sind:

| Eigenschaft | Beschreibung                                    | Beispiel                          |
| --------- | ---------------------------------------------- | -------------------------------- |
| `isEmpty` | Gibt `true` zurück, wenn der String keine Zeichen enthält | `"Hello".isEmpty` ergibt `false` |
| `count`   | Gibt die Anzahl der Zeichen im String zurück | `"Hello".count` ergibt `5`       |

Eine vollständige Liste der Eigenschaften findest du in der [Apple-Dokumentation zu String][string-docs].

### Eigenschaften von Characters

Häufige Eigenschaften von Characters sind:

| Eigenschaft       | Beschreibung                                   | Beispiel                              |
| -------------- | --------------------------------------------- | ------------------------------------ |
| `isLowercase`  | Gibt `true` zurück, wenn das Zeichen ein Kleinbuchstabe ist  | `"a".isLowercase` ergibt `true` |
| `isUppercase`  | Gibt `true` zurück, wenn das Zeichen ein Großbuchstabe ist  | `"A".isUppercase` ergibt `true` |
| `isNumber`     | Gibt `true` zurück, wenn das Zeichen eine Ziffer ist    | `"1".isNumber` ergibt `true`    |
| `isWhitespace` | Gibt `true` zurück, wenn es sich bei dem Zeichen um Whitespace handelt | `" ".isWhitespace` ergibt `true`|

Eine vollständige Liste der Eigenschaften findest du in der [Apple-Dokumentation zu Character][character-docs].

## Typumwandlung

Mit dem Initialisierer `String(_:)` kannst du andere Typen in Strings umwandeln. Er unterstützt Standardtypen wie `Int`, `Double` und `Character`:

```swift
let charX: Character = "x"
print(String(charX))     // Prints "x"
print(String(110))       // Prints "110"
print(String(Double.pi)) // Prints "3.141592653589793"
```

## Sonderzeichen

Swift-String-Literale unterstützen mehrere [Escape-Sequenzen][special-characters] für Sonderzeichen:

| Sequenz   | Beschreibung                   |
| ---------- | ----------------------------- |
| `\0`       | Nullzeichen                |
| `\\`       | Backslash                     |
| `\t`       | Horizontaler Tabulator                |
| `\n`       | Zeilenvorschub (Newline)           |
| `\r`       | Wagenrücklauf               |
| `\'`       | Einfaches Anführungszeichen         |
| `\"`       | Doppeltes Anführungszeichen         |
| `\u{n}`    | Beliebiger Unicode-Skalarwert (hexadezimal) |

```swift
let quote: String = "\"Hello\", he said."
print(quote) // Prints "Hello", he said.

let unicode: Character = "\u{1F496}"
print(unicode) // Prints 💖
```
