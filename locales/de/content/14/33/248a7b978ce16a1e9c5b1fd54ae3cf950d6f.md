# Installation

Dieser Track verwendet ReScript 12 und setzt [Node.js][nodejs] 22 oder höher voraus.
Auf vielen Systemen ist es bereits vorinstalliert, oder du hast es vielleicht schon für einen anderen Track installiert.

Öffne ein Terminal und führe Folgendes aus:

```sh
node -v
```

Wenn Node nicht installiert ist oder eine ältere Version angezeigt wird, folge bitte den [offiziellen Installationsanweisungen für Node.js][nodejs-install] für dein Betriebssystem.

## Abhängigkeiten installieren

Jede ReScript-Übung ist ein eigenständiges npm-Projekt.
Nachdem du eine Übung mit der [Exercism CLI][exercism-cli] heruntergeladen hast, installierst du die Projektabhängigkeiten einschließlich ReScript, und schon kann es losgehen:

```sh
cd /path/to/exercise
npm install
```
