# Einführung

Eine `MACRO:`-Deklaration ist wie `:`, nur dass der Rumpf zur *Kompilierzeit* ausgeführt wird und ein Quotation zurückgeben muss. Der Compiler setzt dieses zurückgegebene Quotation an die Stelle des Makroaufrufs. Da der Rumpf gewöhnlicher Factor-Code ist, ist das Erzeugen des Ergebnis-Quotations nichts weiter als das Manipulieren von Sequenzen von Words.

```factor
USING: kernel macros sequences ;

MACRO: twice ( quot -- compound )
    dup append ;

: shout-twice ( name -- ) [ " ahoy!" append print ] twice ;
! At compile time, the call site is replaced with
! [ " ahoy!" append print " ahoy!" append print ].
```

Die Eingabewerte eines Makros sind *Literale an der Aufrufstelle*. Übergibst du einen Nicht-Literal-Wert, weigert sich der Compiler zu spezialisieren, denn der Makro-Rumpf braucht den Wert zur Kompilierzeit, nicht zur Laufzeit.

Ein naher Verwandter ist der `<< … >>`-Block, der zur Parse-Zeit ausgewertet wird und beliebigen Factor-Code zur Kompilierzeit ausführt, ohne den Quotation-Rückgabe-Vertrag. Beide gehören zur `macros`-Maschinerie von Factor.
