# Einführung

Der Gültigkeitsbereich eines Werts bestimmt, wo im Programm auf diesen Wert zugegriffen werden kann.

## Die vier Arten von Gültigkeitsbereichen: Block, Funktion, Funktionsprototyp, Datei

### Blockgültigkeitsbereich

Auf einen Wert mit Blockgültigkeitsbereich kann nur innerhalb des Blocks zugegriffen werden, in dem er definiert ist.
Mehr über Blöcke erfährst du im [Block-Konzept](../blocks/introduction.md#Introduction).

### Funktionsgültigkeitsbereich

Der Funktionsgültigkeitsbereich ist eine besondere Art von Gültigkeitsbereich, die für Labels gilt, die mit `goto`-Anweisungen verwendet werden.
Zwei Labels mit demselben Namen können nicht in derselben Funktion verwendet werden, selbst wenn die Labels in verschiedenen Blöcken innerhalb der Funktion definiert sind.

### Gültigkeitsbereich von Funktionsprototypen

Der Gültigkeitsbereich von Funktionsprototypen ist eine weitere besondere Art von Gültigkeitsbereich, die nur für Parameter gilt, die innerhalb des Prototyps benannt werden (auch als Deklaration bezeichnet, wobei nicht alle Deklarationen Prototypen sind).
In einer Funktionsdeklaration ist ein Parametername normalerweise optional.
Der Gültigkeitsbereich eines Namens ist nur innerhalb der Deklaration relevant.
Eine Funktionsdefinition muss nicht denselben Namen für einen Parameter verwenden, der in der Funktionsdeklaration verwendet wurde.

### Dateigültigkeitsbereich

Auf einen Wert mit Dateigültigkeitsbereich kann von überall in der Datei zugegriffen werden.
Ein solcher Wert wird außerhalb einer Funktion definiert.
