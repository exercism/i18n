# Hinweise

## 1. Koordinaten extrahieren

- Wir versuchen, ein Element aus einem Tupel herauszuziehen.
- Indexierung ist eine Möglichkeit.
- Mehrfachzuweisung ist ein alternativer Ansatz.

## 2. Koordinaten formatieren

- Denk an den Konstruktor [`Tuple()`][Tuple].

## 3. Koordinaten abgleichen

- Du hast bereits eine Funktion, die Azaras Koordinate in Ruis Format umwandelt.
- Ein Test auf Gleichheit ist eine Möglichkeit.
- Alternativ kannst du prüfen, ob die Koordinate in Ruis Datensatz enthalten ist (∈).

## 4. Übereinstimmende Datensätze kombinieren

- Passen die Datensätze zusammen? Du weißt bereits, wie du das testest.
- Wenn sie übereinstimmen, müssen die gewünschten Elemente im Rückgabewert in einer anderen Reihenfolge kombiniert werden.
- Nicht jedes Element im Eingabetupel wird ausgegeben.
- Entpacken ist dein Freund. Elementen aussagekräftige Namen zu geben ist lesbarer und einfacher zu debuggen als Indexierung.

[Tuple]: https://docs.julialang.org/en/v1/base/base/#Core.Tuple
