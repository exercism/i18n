# Kraftstoffzuschuss

## Aufgabenstellung

Alle Beschäftigten von ABC Corp erhalten einen unbegrenzten Kraftstoffzuschuss. Die Beschäftigten müssen jedes Mal, wenn sie ihr Fahrzeug tanken, einen Datensatz einsenden. Diese Datensätze werden an dieselbe CSV-Datei angehängt und am Monatsende verarbeitet.

Du bist Mitglied des Teams für digitale Abläufe. Deine Aufgabe ist es, diese CSV-Datei zu lesen und die Ergebnisse in eine andere CSV-Datei zu schreiben. Die Ausgabedatei soll für jede Beschäftigte und jeden Beschäftigten einen Eintrag mit den folgenden Angaben enthalten:

- Personalnummer
- Anzahl der Tankvorgänge
- Kraftstoffkosten insgesamt
- Getankte Gallonen insgesamt
- Zurückgelegte Meilen insgesamt

Du bekommst zwei Argumente vom Typ `string`.

1. Pfad der Eingabe-CSV-Datei
1. Pfad der Ausgabe-CSV-Datei

Die Eingabe-CSV-Datei hat `n` Zeilen, und jede Zeile hat die folgende Form.

| Spaltenname      | Ballerina-Typ |
| ----------- | ----------- |
| employee_id      | `int`       |
| odometer_reading   | `int`       |
| gallons   | `decimal` |
| gas_price(USD)  |`decimal`|

Die Ausgabedatei soll für jede Beschäftigte und jeden Beschäftigten einen Eintrag enthalten, aufsteigend sortiert nach der `employee_id`. Jede Zeile hat die folgende Form:

| Spaltenname      | Ballerina-Typ |
| ----------- | ----------- |
| employee_id      | `int`       |
| gas_fill_up_count   | `int`        |
| total_fuel_cost(USD)   | `decimal` |
| total_gallons  |`decimal`|
| total_miles_accrued  |`int`|

## Einschränkungen

- Anzahl der Zeilen `n` in der Eingabe-CSV-Datei: 2 <= n <= 1000
- Anzahl der Beschäftigten im Unternehmen: 97
- Der Kraftstoffpreis gilt pro Gallone
- Es gibt keine fehlenden Tankvorgänge

## Beispiel 1

- Eingabe: `example01_input.csv`

```csv
2312,230,18.561,4.56
2312,500,19.345,4.89
```

- Ausgabe: `example01_output.csv`

```csv
2312,2,179.23521,37.906,270
```

## Hinweise

- Verwende das [`ballerina/io`-Modul](https://lib.ballerina.io/ballerina/io/latest), um CSV-Dateien zu lesen und zu schreiben
- Die Eingabe- und Ausgabedateien enthalten keine Kopfzeilen und sollen auch keine enthalten
- [Tabellensyntax in Ballerina](https://ballerina.io/learn/by-example/table)
