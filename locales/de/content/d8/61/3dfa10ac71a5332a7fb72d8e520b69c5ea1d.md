# Über

Rust ist eine Systemprogrammiersprache, die blitzschnell läuft, Segfaults verhindert und Thread-Sicherheit garantiert.
Ihr Ziel ist es, modernes Sprachdesign und ein fortschrittliches Typsystem in die Systemprogrammierung zu bringen.
Rust verwendet keinen Garbage Collector, sondern setzt auf erweiterte statische Analyse, um deterministische Drops zu ermöglichen.
Das erreicht Rust über das Konzept [Ownership](https://doc.rust-lang.org/book/ch04-00-understanding-ownership.html).

Der Kern von Rust und die Standardbibliothek sind bewusst minimal gehalten; Batterien sind nicht inklusive.
Rustaceans werden stattdessen ermutigt, Bibliotheken, sogenannte _Crates_, zur Sprache beizutragen, indem sie sie auf [crates.io](https://crates.io/) teilen.

Rust wird am häufigsten für Anwendungen verwendet, bei denen Geschwindigkeit, Performance und Stabilität entscheidend sind.
Die Liste [Awesome Rust](https://github.com/kud1ing/awesome-rust) sammelt Beispiele für Rust-Projekte, darunter Kommandozeilen-Tools, ORMs, Betriebssysteme und Spiele.
Egal, was du in Rust baust, es wird schnell und speichersicher sein!

Die Homepage von Rust ist [rust-lang.org](https://www.rust-lang.org/).
Rust hat eine hervorragende Dokumentation unter [rust-lang.org/documentation.html](https://www.rust-lang.org/documentation.html).
Einsteiger sollten mit „The Book“ beginnen, das unter [doc.rust-lang.org/book/](https://doc.rust-lang.org/book/) zu finden ist.
