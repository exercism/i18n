# Anleitung

Du wanderst in Neuseeland und nimmst mit einem Kompass Peilungen ab. Eine Peilung ist eine ganze Anzahl von Grad, und sie ist ein Wert: Wenn du um 20 Grad drehst, ändert das nicht die Peilung, die du genommen hast, sondern ergibt eine andere.

Schreibe eine `immutable class BEARING`. Die Vorgabe enthält bereits den Klassenkopf und sein Attribut.

## 1. Nimm eine Peilung

`create` nimmt eine Anzahl von Grad und gibt eine Peilung zurück. Grad läuft von 0 bis 359, also wird alles außerhalb wieder umgerechnet: 370 ergibt 10 und -10 ergibt 350.

```sather
#BEARING(370).degrees
-- => 10
#BEARING(-10).degrees
-- => 350
```

## 2. Drehen

`turned` nimmt eine Anzahl von Grad, um die gedreht wird, und gibt die neue Peilung zurück. Eine Drehung um eine negative Zahl dreht in die andere Richtung. Die Peilung, auf der die Methode aufgerufen wurde, bleibt unverändert.

```sather
#BEARING(350).turned(20).degrees
-- => 10
```

## 3. Vergleichen

`is_eq` nimmt eine andere Peilung und gibt zurück, ob sie gleich sind. Sobald `is_eq` existiert, funktioniert `=` für Peilungen.

```sather
#BEARING(10) = #BEARING(370)
-- => true
```

## 4. Benenne den Punkt

`point` gibt den Kompasspunkt zurück, der am nächsten an der Peilung liegt, als einen von `"N"`, `"NE"`, `"E"`, `"SE"`, `"S"`, `"SW"`, `"W"`, `"NW"`.

Jeder Punkt deckt 45 Grad ab, zentriert auf seine genaue Peilung: Norden reicht von 337,5 über 0 bis 22,5, Nordost von 22,5 bis 67,5, und so weiter. Da die Peilungen hier ganze Zahlen sind, ist eine Peilung von 22 `"N"` und 23 `"NE"`.

```sather
#BEARING(0).point
-- => "N"
#BEARING(90).point
-- => "E"
#BEARING(225).point
-- => "SW"
```

## 5. Schreibe es auf

`str` gibt die Gradzahl und den Punkt zurück, wie `"90 degrees (E)"`.

```sather
#BEARING(90).str
-- => "90 degrees (E)"
```
