# Anleitung

Du sollst noch etwas mehr am Netzwerk-Authentifizierungssystem arbeiten.

Neben der Admin-Identität, die während der Entwicklung fest im System einprogrammiert ist, möchten die Verantwortlichen, dass auch Senior-Entwickler genauso behandelt werden.

## 1. Speichere die Daten des System-Administrators fest im System und stelle sie den Aufrufern zur Verfügung

Die Daten des Administrators sind wie folgt:

| Email        | Augenfarbe | Philtrumbreite | Name     | Adresse 1 | Adresse 2 |
| ------------ | ---------- | -------------- | -------- | --------- | --------- |
| admin@ex.ism | green      | 0.9            | Chanakya | Mumbai    | India     |

Implementiere die Eigenschaft `Authenticator.Admin`, sodass sie die Identitätsdaten des System-Administrators zurückgibt. Der Name und jeder Teil der Adresse sollten in einem eigenen Element der `NameAndAddress`-Liste stehen.

```csharp
var authenticator = new Authenticator();
authenticator.Admin;
// => {"admin@ex.ism", {"green", 0.9m}, ["Chanakya", "Mumbai", "India"]}
```

## 2. Speichere die Daten der Entwickler fest im System und stelle sie in Form eines Wörterbuchs zur Verfügung

Die Daten der Entwickler sind wie folgt:

| Email         | Augenfarbe | Philtrumbreite | Name     | Adresse 1 | Adresse 2 |
| ------------- | ---------- | -------------- | -------- | --------- | --------- |
| bert@ex.ism   | blue       | 0.8            | Bertrand | Paris     | France    |
| anders@ex.ism | brown      | 0.85           | Anders   | Redmond   | USA       |

Implementiere die Eigenschaft `Authenticator.Developers`, sodass sie die Identitätsdaten der Entwickler zurückgibt. Der Schlüssel des Wörterbuchs ist der Name des Entwicklers.

```csharp
var authenticator = new Authenticator();
authenticator.Developers;
// => ["Bertrand"] = {"bert@ex.ism", {"blue", 0.8m}, ["Bertrand", "Paris", "France"]},
// ["Anders"] = {"anders@ex.ism", {"brown", 0.85m}, ["Anders", "Redmond", "USA"]},

```
