# Instructions

Du wirst etwas Code schreiben, um eine Punktetafel für ein Spiel zu verwalten.
Die Punktetafel ist ein Hash namens `%HighScoreBoard::Scores`.
Die Schlüssel des Hashes sind die Namen der Spieler, und die Werte sind ihre Punktzahlen.

## 1. Lege die Punktzahl eines Spielers im Hash %Scores fest

Passe die Subroutine `HighScoreBoard::set_player_scores`, die Spielernamen und Punktzahlen als Argumente entgegennimmt, so an, dass sie die Punktzahlen der Spieler im Hash `%HighScoreBoard::Scores` setzt.

## 2. Rufe die Punktzahl eines Spielers aus dem Hash %Scores ab

Passe die Subroutine `HighScoreBoard::get_player_score`, die einen Spielernamen als Argument entgegennimmt, so an, dass sie die Punktzahl des Spielers aus dem Hash `%HighScoreBoard::Scores` zurückgibt.

## 3. Erhöhe die Punktzahl eines Spielers im Hash %Scores

Passe die Subroutine `HighScoreBoard::increase_player_scores`, die Spielernamen und Punktzahlen als Argumente entgegennimmt, so an, dass sie die Punktzahlen der Spieler im Hash `%HighScoreBoard::Scores` um die angegebene Punktzahl erhöht.

## 4. Sortiere die Spieler im Hash %Scores nach ihrem Namen

Passe die Subroutine `HighScoreBoard::sort_players_by_name` so an, dass sie die Spielernamen im Hash `%HighScoreBoard::Scores` nach ihrem Namen sortiert zurückgibt.

## 5. Sortiere die Spieler im Hash %Scores nach ihrer Punktzahl

Passe die Subroutine `HighScoreBoard::sort_players_by_score` so an, dass sie die Spielernamen im Hash `%HighScoreBoard::Scores` nach ihrer Punktzahl sortiert zurückgibt.

## 6. Lösche einen Spieler aus dem Hash %Scores

Passe die Subroutine `HighScoreBoard::delete_player`, die einen Spielernamen als Argument entgegennimmt, so an, dass sie den Spieler aus dem Hash `%HighScoreBoard::Scores` löscht.
