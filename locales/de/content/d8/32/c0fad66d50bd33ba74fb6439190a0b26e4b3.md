# Anleitung

In dieser Übung spielst du ein Rollenspiel, in dem verschiedene Arten von Kämpfern gegeneinander antreten können.
Das Spiel hat für jede Art von Kämpfer andere Regeln.
Wir konzentrieren uns auf zwei bestimmte Arten: Zauberer und Krieger.

Für einen Krieger gelten diese Regeln:

- Ein Krieger ist niemals verwundbar.
- Ein Krieger verursacht `6` Schadenspunkte, wenn der Kämpfer, den er angreift, nicht verwundbar ist.
- Ein Krieger verursacht `10` Schadenspunkte, wenn der Kämpfer, den er angreift, verwundbar ist.

Für einen Zauberer gelten diese Regeln:

- Ein Zauberer kann einen Zauberspruch vorbereiten.
- Ein Zauberer ist verwundbar, es sei denn, er hat einen Zauberspruch vorbereitet.
- Ein Zauberer verursacht `12` Schadenspunkte, wenn er einen Zauberspruch vorbereitet hat.
- Ein Zauberer verursacht `3` Schadenspunkte, wenn er keinen Zauberspruch vorbereitet hat.

## 1. Erstelle die `Warrior`-Klasse

Erstelle eine neue Klasse namens `Warrior`.
Diese Klasse sollte von der vorhandenen `Fighter`-Klasse erben.

## 2. Beschreibe einen Krieger

Aktualisiere die `Warrior`-Klasse so, dass ihre `toString()`-Methode beschreibt, um welche Art von Kämpfer es sich handelt.
Die Methode sollte den String `"Fighter is a Warrior"` zurückgeben.

```java
Warrior warrior = new Warrior();
warrior.toString();
// => "Fighter is a Warrior"
```

## 3. Mach Krieger unverwundbar

Aktualisiere die `Warrior`-Klasse so, dass ihre `isVulnerable()`-Methode immer `false` zurückgibt.

```java
Warrior warrior = new Warrior();
warrior.isVulnerable();
// => false
```

## 4. Berechne die Schadenspunkte für einen Krieger

Aktualisiere die `Warrior`-Klasse so, dass ihre `getDamagePoints(Fighter)`-Methode den Schaden berechnet, den ein Krieger gemäß den obigen Regeln verursacht.

```java
Warrior warrior = new Warrior();
Wizard wizard = new Wizard();

warrior.getDamagePoints(wizard);
// => 10
```

## 5. Erstelle die `Wizard`-Klasse

Erstelle eine weitere neue Klasse namens `Wizard`.
Diese Klasse sollte ebenfalls von der vorhandenen `Fighter`-Klasse erben.

## 6. Beschreibe einen Zauberer

Aktualisiere die `Wizard`-Klasse so, dass ihre `toString()`-Methode beschreibt, um welche Art von Kämpfer es sich handelt.
Die Methode sollte den String `"Fighter is a Wizard"` zurückgeben.

```java
Wizard wizard = new Wizard();
wizard.toString();
// => "Fighter is a Wizard"
```

## 7. Erlaube Zauberern, einen Zauberspruch vorzubereiten, und mach sie verwundbar, wenn kein Zauberspruch vorbereitet wurde

Aktualisiere die `Wizard`-Klasse, um eine Methode namens `prepareSpell()` hinzuzufügen.
Die Klasse sollte sich merken, wann diese Methode aufgerufen wird, und dafür sorgen, dass ihre `isVulnerable()`-Methode nur dann `false` zurückgibt, wenn ein Zauberspruch vorbereitet wurde.

```java
Wizard wizard = new Wizard();
wizard.prepareSpell();
wizard.isVulnerable();
// => false
```

## 8. Berechne die Schadenspunkte für einen Zauberer

Aktualisiere die `Wizard`-Klasse so, dass ihre `getDamagePoints(Fighter)`-Methode den Schaden berechnet, den ein Zauberer gemäß den obigen Regeln verursacht.

```java
Wizard wizard = new Wizard();
Warrior warrior = new Warrior();

wizard.prepareSpell();
wizard.getDamagePoints(warrior);
// => 12
```
