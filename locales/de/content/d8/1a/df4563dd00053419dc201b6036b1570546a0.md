# Einführung

Common Lisp stellt mehrere verschiedene bedingte Ausdrücke bereit. Der wichtigste Unterschied ist die Anzahl der Zweige, die sie unterstützen.

- `when` und `unless` erlauben einen einzigen Zweig:

```lisp
(when (= 2 2) "All is well")      ; => "All is well"
(unless (= 2 2) "Time to panic!") ; => NIL
```

Auf den Testausdruck dürfen mehrere Ausdrücke folgen.

- `if` bietet das klassische Wenn-Dann-Sonst-Konstrukt:

```lisp
(if (= 2 2) 'how-honest 'you-liar) ; => HOW-HONEST
```

Beachte, dass sowohl der Dann- als auch der Sonst-Zweig nur ein einziger Ausdruck sein darf.

- `cond` ermöglicht mehrere Zweige, ohne `if`-Ausdrücke zu verschachteln:

```lisp
(cond ((= 0 2) 'nope)
      ((= 1 2) 'try-again)
      ((= 2 2) 'quite-true)
      ((= 3 2) 'too-far)
      (t 'something-else))
; => QUITE-TRUE
```

Beachte, dass es keine Grenze für die Anzahl der Ausdrücke nach dem Testausdruck gibt.

- `case` bietet ein klassisches Konstrukt im „switch“-Stil: Es prüft einen einzelnen Wert gegen eine Reihe von Zweigen:

```lisp
(case 'elder-beast
  (cat "Meow")
  (bird "Chirp")
  (dog "Bark")
  (otherwise "???"))
; => "???"
```

Beachte, dass es wie bei `cond` keine Grenze für die Anzahl der Ausdrücke nach dem Testausdruck gibt.
