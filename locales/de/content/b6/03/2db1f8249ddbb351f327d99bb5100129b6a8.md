# Ergänzung zu den Anweisungen

## Register

| Register | Verwendung  | Typ     | Beschreibung                     |
| -------- | ----------- | ------- | -------------------------------- |
| `$a0`    | Eingabe     | Adresse | nullterminierter String aus Ziffern |
| `$a1`    | Eingabe     | Ganzzahl | Spanne                          |
| `$v0`    | Rückgabewert | Ganzzahl | größtes Serienprodukt           |
| `$t0-9`  | temporär    | beliebig | zur Zwischenspeicherung         |
