# Sync-Labels-Workflow

Der Sync-Labels-Workflow synchronisiert die [GitHub-Labels](https://docs.github.com/en/issues/using-labels-and-milestones-to-track-work/managing-labels) eines Repositorys mit dem Inhalt der Datei `.github/labels.yml`.
Immer wenn sich die Datei `.github/labels.yml` ändert, aktualisiert der Sync-Labels-Workflow automatisch die Labels des Repositorys.

## Labels anpassen

Die in `.github/labels.yml` definierten Labels gibt es in zwei Formen:

- Geteilte Labels: Diese Labels werden von _allen_ Exercism-Repositorys verwendet und sind im [Repository für organisationsweite Dateien](https://github.com/exercism/org-wide-files/blob/main/global-files/.github/labels.yml) definiert.
- Track-spezifische Labels: Diese sind in einer Datei `.appends/.github/labels.yml` definiert.

Um Track-spezifische Labels hinzuzufügen, musst du sie der Datei `.appends/.github/labels.yml` hinzufügen (siehe [dieses Beispiel](https://github.com/exercism/python/blob/main/.appends/.github/labels.yml)).
Sobald du die Änderungen nach `main` gemergt hast, wird automatisch ein Pull Request geöffnet, der die Datei `.github/labels.yml` ändert.
Nach dem Mergen dieses PRs werden die Labels automatisch aktualisiert (siehe Beschreibung oben).

```exercism/caution
Bearbeite die Datei `.github/labels.yml` niemals manuell, denn diese Änderungen werden überschrieben, sobald die Labels das nächste Mal synchronisiert werden.
```

## Quelle

Der Workflow ist in der Datei `.github/workflows/sync-labels.yml` definiert.
