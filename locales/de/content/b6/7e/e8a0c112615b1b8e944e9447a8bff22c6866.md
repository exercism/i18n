# Einführung

## Grundlagen

C# ist eine statisch typisierte Sprache. Das bedeutet, dass alles zur Kompilierzeit einen Typ hat. Wenn du einem Namen einen Wert zuweist, wird das als Definieren einer Variable bezeichnet. Eine Variable kannst du auf zwei Arten definieren: entweder indem du ihren Typ explizit angibst oder indem du den C#-Compiler den Typ anhand des zugewiesenen Werts ableiten lässt (bekannt als _Typinferenz_). Die folgenden beiden Variablendefinitionen sind daher äquivalent:

```csharp
int explicitVar = 10; // Explicitly typed
var implicitVar = 10; // Implicitly typed
```

Den Wert einer Variable änderst du mit dem Operator `=`. Sobald eine Variable definiert ist, kann sich ihr Typ nie mehr ändern.

```csharp
var count = 1; // Assign initial value
count = 2;     // Update to new value

// Compiler error when assigning different type
// count = false;
```

C# ist eine [objektorientierte Sprache][object-oriented-programming] und verlangt, dass alle Funktionen in einer _Klasse_ definiert werden. Mit dem Schlüsselwort `class` definierst du eine Klasse. Objekte (oder _Instanzen_) erstellst du mit dem Schlüsselwort `new`.

```csharp
class Calculator
{
    // ...
}

var calculator = new Calculator();
```

Eine Funktion innerhalb einer Klasse wird als _Methode_ bezeichnet. Jede Methode kann null oder mehr Parameter haben. Alle Parameter müssen explizit typisiert sein, für Parameter gibt es keine Typinferenz. Genauso muss auch der Rückgabetyp explizit angegeben werden. Werte gibst du mit dem Schlüsselwort `return` aus Methoden zurück. Damit eine Methode von Code in anderen Dateien aufgerufen werden kann, musst du den Zugriffsmodifizierer `public` hinzufügen.

```csharp
class Calculator
{
    public int Add(int x, int y)
    {
        return x + y;
    }
}
```

Methoden rufst du mit der Punkt-Syntax (`.`) auf einer Instanz auf: Du gibst den Namen der aufzurufenden Methode an und übergibst Argumente für jeden Parameter der Methode. Argumente können optional den Namen des zugehörigen Parameters angeben.

```csharp
var calculator = new Calculator();
var sum_v1 = calculator.Add(1, 2);
var sum_v2 = calculator.Add(x: 1, y: 2);
```

Der Gültigkeitsbereich wird in C# zwischen den Zeichen `{` und `}` festgelegt.

C# unterstützt zwei Arten von Kommentaren. Einzeilige Kommentare werden mit `//` eingeleitet, mehrzeilige Kommentare stehen zwischen `/*` und `*/`.

[object-oriented-programming]: https://docs.microsoft.com/en-us/dotnet/csharp/programming-guide/concepts/object-oriented-programming
