# Einführung

`Complex numbers` sind nicht kompliziert.
Sie brauchen nur einen weniger abschreckenden Namen.


Sie sind so nützlich, besonders in Technik und Wissenschaft, dass Python [`complex`][complex] als standardmäßigen Zahlentyp enthält, zusammen mit Ganzzahlen ([`int`s][ints]) und Gleitkommazahlen ([`float`s][floats]).


Ein `complex`-Wert in Python ist im Wesentlichen ein Paar Gleitkommazahlen:

```python
>>> my_complex = 5.443+6.77j
(5.443+6.77j)
```

Diese heißen „Realteil“ und „Imaginärteil“.
Vielleicht hast du schon gehört, dass „`i` (oder `j`) die Quadratwurzel aus -1 ist“.
Für den Moment bedeutet das nur, dass der Imaginärteil _per Definition_ die Gleichung `1j * 1j == -1` erfüllt.
Das ist eine einfache Idee, die aber zu interessanten mathematischen Konsequenzen führt.

In Python wird der „imaginäre“ Teil mit `j` bezeichnet (_nicht `i`, wie du es in Mathematikbüchern sehen würdest_), und
das `j` muss direkt auf eine Zahl folgen, damit Python es nicht als Variablennamen ansieht:


```python
>>> j
Traceback (most recent call last):
  File "<stdin>", line 1, in <module>
NameError: name 'j' is not defined

>>> 1j
1j

>>> type(1j)
<class 'complex'>
```


Es gibt zwei gängige Möglichkeiten, komplexe Zahlen zu erstellen.

1) Der Konstruktor [`complex(real, imag)`][complex] nimmt zwei `float`-Parameter:

    ```python
    >>> z1 = complex(1.5, 2.0)
    >>> z1
    (1.5+2j)
    ```

    Der Konstruktor kann auch String-Eingaben verarbeiten.
    Das hat die seltsame Einschränkung, dass er fehlschlägt, wenn der String Leerzeichen enthält.

    ```python
    >>> complex('4+2j')
    (4+2j)
    
    >>> complex('4 + 2j')
    Traceback (most recent call last):
      File "<stdin>", line 1, in <module>
    ValueError: complex() arg is a malformed string
    ```


2) Die komplexe Zahl kann als Literal `<real part> + <complex part>j` angegeben werden, oder einfach als `<complex part>j`, wenn der Realteil null ist:


    ```python
    >>> z2 = 2.0 + 1.5j
    >>> z2
    (2+1.5j)
    ```
    Das Endergebnis ist identisch mit dem des `complex()`-Konstruktors.


## Arithmetik

Die meisten [`operators`][operators] für Gleitkommazahlen und Ganzzahlen funktionieren auch mit komplexen Zahlen.

Die ganzzahlige Division ist bei komplexen Zahlen _**nicht**_ möglich, deshalb schlagen die Operatoren `//` und `%` und die Funktion `divmod()` für den komplexen Zahlentyp fehl.

Die Regeln für die Multiplikation und Division komplexer Zahlen zu erklären, geht über den Rahmen dieses Konzepts hinaus (_und du wirst diese Operationen wahrscheinlich nicht oft „von Hand“ durchführen müssen_).

Jede [mathematische][math-complex] oder [elektrotechnische][engineering-complex] Einführung in komplexe Zahlen behandelt diese Szenarien, falls du tiefer in das Thema eintauchen möchtest.

Die Python-Standardbibliothek enthält das Modul [`math`][math-module] mit vielen nützlichen Funktionen für die Arbeit mit reellen Zahlen, und das Modul [`cmath`][cmath] ist das passende Gegenstück für die Arbeit mit komplexen Zahlen.
