# Installation

Stelle zuerst sicher, dass Erlang installiert ist, und folge dabei den Anweisungen auf der [Erlang][1]-Installationsseite.
[1]: /languages/erlang

## Homebrew für Mac OS X

Aktualisiere Homebrew auf die neueste Version:

```bash
$ brew update
```

Installiere LFE:

```bash
$ brew install lfe
```

## Installation aus dem Quellcode

Installiere die „developer tools" oder „essential build packages" deines Systems, `git` und Erlangs `erl`.

Zum Beispiel unter Ubuntu 18.04:

```bash
$ sudo apt-get install build-essential git erlang erlang-base-hipe
```

Danach kannst du LFE mit den folgenden Befehlen herunterladen und bauen:

```bash
$ git clone https://github.com/lfe/lfe.git
$ cd lfe
$ make
$ make install
```

Wenn du LFE kompiliert hast, kannst du die REPL (interaktive Sitzung) starten, indem du die Binärdatei ``lfe`` ausführst:

```bash
$ ./bin/lfe
```
