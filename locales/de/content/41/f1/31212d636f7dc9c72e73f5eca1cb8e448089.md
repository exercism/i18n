# Structs

Structs fassen eine feste, heterogene Menge von Daten zu einer Einheit zusammen. Structs in Rust haben folgende Eigenschaften:

- Jeder Struct-Typ hat einen bestimmten Namen.
- Jedes Mitglied eines Structs heißt **Feld**.
- Jedes Feld eines Structs hat einen bestimmten Namen.
- Die Sichtbarkeit wird auf Feldebene verwaltet: Jedes Feld kann unabhängig von den anderen `public`, `private` oder anders sein[^1].

# Überblick über Structs

Structs werden mit dem Schlüsselwort `struct` definiert, gefolgt vom Namen des Typs, den das Struct beschreibt.
Auf den Namen können dann geschweifte Klammern (für ein Standard-Struct), runde Klammern (für ein Tupel-Struct) oder ein Semikolon (für ein Unit-Struct) folgen.

```rust
struct Item {}
```

Weitere Typen werden dann als _Felder_ des Structs aufgenommen, jedes mit einem eigenen Typ:

```rust
struct Item {
    name: String,
    weight: f32,
    worth: u32,
}
```

Schließlich können Methoden für Structs in einem `impl`-Block definiert werden:

```rust
impl Item {
    // initializes and returns a new instance of our Item struct
    fn new() -> Self {
        todo!()
    }
}
```

# Arten von Structs

Es gibt drei Arten von Structs: Structs mit benannten Feldern (Standard-Structs), Tupel-Structs und Unit-Structs.

Structs ähneln **Tupeln** sehr. Der einzige Unterschied zwischen Structs und Tupeln betrifft eigentlich nur das, was anonym ist. Die allgemeine Form sieht so aus:

- Structs haben einen Namen und benannte Felder:

  ```rust
  struct Foo {
      bar: Bar,
      bat: Bat,
  }
  ```

  Auf die Felder wird über den Namen zugegriffen:

  ```rust
  let bar = foo.bar;
  ```

- Tupel-Structs haben einen Namen und anonyme Felder:

  ```rust
  Foo(Bar, Bat)
  ```

  Auf die Felder wird durch Entpacken oder über den numerischen Index zugegriffen:

  ```rust
  // unpacking
  let (bar, bat) = foo;
  ```

  ```rust
  // numeric index
  let bar = foo.0;
  let bat = foo.1;
  ```

- Tupel sind anonym und haben anonyme Felder:

  ```rust
  (Bar, Bat)
  ```

  Wie bei Tupel-Structs wird auf die Felder durch Entpacken oder über den numerischen Index zugegriffen.

- Anonyme Structs sind, wie der Name schon sagt, anonym, haben aber benannte Felder. Vielleicht kennst du sie aus anderen Sprachen wie Go oder Java. In Rust gibt es sie nicht; stattdessen gilt es als idiomatisch, ein Tupel zu verwenden.

# Zero Sized Types

Structs können so viele oder so wenige Felder haben, wie benötigt werden. Daraus folgt, dass ein Struct auch null Felder haben darf. Ein Struct ohne Felder heißt **Zero-Sized Type** und wird vom Compiler besonders behandelt: Zero-Sized Types (oft mit **ZSTs** abgekürzt) belegen niemals Stack- oder Heap-Speicher, auch wenn man das erwarten könnte. Zum Beispiel reserviert `Box<T>` keinen Heap-Speicher, wenn `T` ein ZST ist.

Beim Schreiben eines ZST kannst du die Syntax von Standard- oder Tupel-Structs verwenden:

```rust
// declaration
struct Foo {}
// instantiation
let foo = Foo {}
```

```rust
// declaration
struct Foo();
// instantiation
let foo = Foo();
```

Für ZSTs gibt es außerdem eine Kurzschreibweise:

```rust
// declaration
struct Foo;
// instantiation
let foo = Foo;
```

Wenn du ein ZST schreibst, ist normalerweise die Kurzschreibweise zu bevorzugen, denn du kannst die Stile nicht mischen: Der Stil, mit dem ein ZST deklariert wurde[^2], ist derselbe Stil, der zum Instanziieren benötigt wird.

Nach all dieser Diskussion über die Syntax von ZSTs stellt sich die Frage, warum man so etwas überhaupt brauchen sollte. Ein ZST kann keine Daten speichern, eignet sich aber hervorragend, um Traits darauf zu implementieren.
