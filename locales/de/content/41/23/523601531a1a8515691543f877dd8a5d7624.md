# Installation

Du brauchst [NodeJS LTS](https://nodejs.org/en).

> 💡 Dieser Track funktioniert wahrscheinlich auch mit älteren stabilen Versionen sowie mit der „current“-Version.
> Ungerade Versionen sind jedoch [bewusst](https://github.com/nodejs/release#release-schedule) nie stabil.
> Achte immer darauf, dass du eine gerade Version von NodeJS installierst.

Installiere [Yarn 4+](https://yarnpkg.com/getting-started/install) mit `corepack` aus Node.js:

```shell
corepack enable yarn
```

## Installation überprüfen

Normalerweise musst du ein neues Terminal öffnen, um die gerade installierten Programme zu verwenden.

```shell
$ node -v
v20.15.0

$ corepack -v
0.28.1

$ corepack yarn -v
v4.3.1
```

_Hinweis: deine Versionen werden wahrscheinlich von diesen abweichen._

## Installation für die Übungen

**Jede Übung** braucht ein paar Tools, um die Tests auszuführen:

Du kannst sie installieren, indem du diesen Befehl im Verzeichnis jeder Übung ausführst:

```bash
$ corepack yarn install
```

Je nach Editor muss das [Editor SDK](https://yarnpkg.com/getting-started/editor-sdks) in jeder Übung installiert werden, damit es mit Plug'n'Play-Installationen funktioniert.
Zum Zeitpunkt, an dem dies geschrieben wurde, werden die folgenden unterstützt:

- [CoC nvim](https://yarnpkg.com/getting-started/editor-sdks#coc-nvim)
- [Emacs](https://yarnpkg.com/getting-started/editor-sdks#emacs)
- [Neovim Native LSP](https://yarnpkg.com/getting-started/editor-sdks#neovim-native-lsp)
- [VSCode](https://yarnpkg.com/getting-started/editor-sdks#vscode)
