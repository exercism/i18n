# Über

Ruby wird mit einer Standardbibliothek ausgeliefert (oft kurz „stdlib“ genannt), einer Sammlung von Klassen für die Arbeit mit Dingen wie Datumsangaben, JSON und Netzwerken.
Außerdem bietet sie praktische Funktionen, die dir die Arbeit mit deinem Code erleichtern.

`OpenStruct` ist Teil der Standardbibliothek und ermöglicht es dir, ganz einfach ein Objekt aus einem `Hash` zu erstellen.
Statt auf `Hash`-Schlüssel zugreifen zu müssen, kannst du mit `OpenStruct` Werte über Methoden lesen und setzen.

Wenn du Klassen aus der Standardbibliothek oder einer anderen Bibliothek verwendest, musst du diese Klasse mit der Methode `require` einbinden.

```ruby
require 'ostruct'

attributes = { name: "Jeremy Walker", age: 21, location: "Nomadic" }
person = OpenStruct.new(attributes)

person.name
#=> Jeremy Walker

person.location
#=> Nomadic

# Update the age
person.age = 35

# It sets correctly
person.age
#=> 35
```

Ein weiterer Vorteil ist, dass du bei der Verwendung der Block-Syntax eine Abkürzung nutzen kannst.
Wenn ein Block nur eine einzige Methode aufruft, kannst du den Block durch `&:` gefolgt vom Methodennamen ersetzen.
Die folgenden beiden Zeilen sind zum Beispiel gleichbedeutend:

```ruby
people.sum { |person| person.age }
people.sum(&:age)
```
