# Überblick

Elixirs Standardbibliothek bietet 4 verschiedene Module für die Arbeit mit Datum und Uhrzeit, jedes mit einem eigenen Struct.

- Das [`Date`-Modul][date]. Ein `Date`-Struct erstellst du mit dem [`~D`-Sigil][sigil-d].
    ```elixir
    ~D[2021-01-01]
    ```

- Das [`Time`-Modul][time]. Ein `Time`-Struct erstellst du mit dem [`~T`-Sigil][sigil-t].
    ```elixir
    ~T[12:00:00]
    ```

- Das [`NaiveDateTime`-Modul][naivedatetime] für Datums- und Zeitangaben ohne Zeitzone. Ein `NaiveDateTime`-Struct erstellst du mit dem [`~N`-Sigil][sigil-n].
    ```elixir
    ~N[2021-01-01 12:00:00]
    ```

- Das [`DateTime`-Modul][datetime] für Datums- und Zeitangaben mit Zeitzone. Für andere Zeitzonen als UTC brauchst du bei diesem Modul eine externe Abhängigkeit, eine Zeitzonendatenbank. Ein `DateTime`-Struct kannst du mit dem [`~U`-Sigil][sigil-u] darstellen, du solltest es aber mit `DateTime`-Funktionen erstellen.
    ```elixir
    DateTime.new!(~D[2021-01-01], ~T[12:00:00], "Etc/UTC")
    # => ~U[2021-01-01 12:00:00Z]
    ```

## Vergleiche

Um Datums- und Zeitangaben miteinander zu vergleichen, suchst du im entsprechenden Modul nach einer `compare`- oder `diff`-Funktion. Vergleichsoperatoren wie `==`, `>` und `<` _scheinen_ zu funktionieren, aber sie führen für diese Structs keinen korrekten semantischen Vergleich durch.

```elixir
Date.compare(~D[2020-11-30], ~D[2020-12-01])
# => :lt

Time.diff(~T[13:45:00], ~T[13:46:30])
# => -90
```

## Verschieben

Datums- und Zeitangaben kannst du mit der `add/2`-Funktion aus dem entsprechenden Modul vorwärts und rückwärts in der Zeit verschieben.

```elixir
# add 4 days
Date.add(~D[2021-01-01], 4)
# => ~D[2021-01-05]

# subtract 1 second
Time.add(~T[12:00:00], -1)
# => ~T[11:59:59.000000]

# add 4 days and 30 seconds
NaiveDateTime.add(~N[2021-01-01 12:00:00], 4 * 24 * 60 * 60 + 30)
# => ~N[2021-01-05 12:00:30]
```

## Umwandlungen

Ein `NaiveDateTime`-Struct kannst du mit [`NaiveDateTime.to_date/1`][naivedatetime-to-date] und [`NaiveDateTime.to_time/1`][naivedatetime-to-time] in ein `Date`-Struct und ein `Time`-Struct zerlegen. Das Gegenteil erreichst du mit [`NaiveDateTime.new!/2`][naivedatetime-new].

```elixir
NaiveDateTime.to_date(~N[2021-01-01 12:00:00])
# => ~D[2021-01-01]

NaiveDateTime.to_time(~N[2021-01-01 12:00:00])
# => ~T[12:00:00]

NaiveDateTime.new!(~D[2021-01-01], ~T[12:00:00])
# => ~N[2021-01-01 12:00:00]
```
