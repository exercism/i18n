# Überblick

In Haxe ist ein abstrakter Typ ein Typ, der zur Laufzeit ein anderer Typ ist. Es ist ein Feature zur Compile-Zeit, das Typen „über“ konkreten Typen definiert, um deren Verhalten zu ändern oder zu erweitern:

```haxe
abstract AbstractInt(Int) {
    inline public function new(i:Int) {
        this = i;
    }
}
```

Hier deklarieren wir den Typ `AbstractInt` mit dem Schlüsselwort `abstract`. Seine Syntax ist der von `class` sehr ähnlich. Und genau wie Klassen können abstrakte Typen Methoden haben. Sie können auch instanziiert und genau wie Klassen verwendet werden:

```haxe
class Main {
    static public function main() {
        var a = new AbstractInt(12);
        trace(a); // 12
    }
}
```

Wie oben erwähnt, sind abstrakte Typen ein Feature zur Compile-Zeit. Kompiliert man das obige Beispiel nach JavaScript, ergibt sich Folgendes:

```javascript
var a = 12;
console.log(a)
```

Der abstrakte Typ `AbstractInt` verschwindet vollständig aus der Ausgabe. Das liegt daran, dass der Konstruktor von `Abstract` [inlined][inline] wird, was wir später sehen werden.

[inline]: https://haxe.org/manual/class-field-inline.html
