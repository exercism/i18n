# Überblick

## Trailing Closures

Swift bietet noch eine weitere Variante seiner Syntax für den Umgang mit Closures, bekannt als [Trailing Closures][trailing-closures]. Trailing Closures entstehen, wenn der letzte Parameter in der Parameterliste einer Funktion einen Funktionstyp hat. Wenn man in diesem Fall eine Closure übergibt, kann man sie _nach_ der schließenden Klammer schreiben, und das Argument-Label entfällt. Beachte: Hat die Funktion nur einen Parameter, kannst du die Klammern ganz weglassen.

```swift
func fetchURL(_ urlString: String,
              uponReceipt handleResult: (String) -> ()
             )  -> () {
  if let url = URL(string: urlString), let htmlString = fetch(url) {
    handleResult(htmlString)
  }
}

fetchURL("https://www.swift.org") { print($0) }
// prints the fetched html string

["apple", "ball", "carrot"].sorted { $0.count < $1.count }
```

## Mehrere Trailing Closures

Während frühere Versionen von Swift nur eine einzelne Trailing Closure unterstützten, unterstützt Swift ab Version 5.2.4 mehrere Trailing Closures.

Hat eine Funktion mehr als eine Closure am Ende ihrer Parameterliste, kann man mit der Trailing-Closure-Syntax alle aus den Klammern herausziehen. Allerdings entfällt nur das erste Argument-Label, die übrigen müssen mit ihrem Label angegeben werden:

```swift
func fetchURL(_ urlString: String,
              uponReceipt handleResult: (String) -> (),
              onFailure handleFailure: () -> ()
             )  -> () {
  if let url = URL(string: urlString), let htmlString = fetch(url) {
    handleResult(htmlString)
  } else {
    handleFailure()
  }
}

fetchURL("https://www.swift.org") {
  print($0)
} onFailure: {
  print("Error: https://www.swift.org could not be fetched")
}
// prints the fetched html string on successful fetch or prints error message on failure
```

[trailing-closures]: https://docs.swift.org/swift-book/LanguageGuide/Closures.html#ID102
