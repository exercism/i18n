# Ergänzung zu den Anweisungen

## Baum ausgeben

Diese Übung enthält einige vordefinierte Klassenmethoden, mit denen du den Baum in einem ansprechenden Format ausgeben kannst.
Ihr Hauptzweck ist es, beim Debuggen zu helfen und für mehr Klarheit zu sorgen.
Wenn du den Rest der Klasse korrekt implementierst, sollte sie den Baum für dich ausgeben.

```powershell
.Example
$tree = [BinarySearchTree]::new(@(50, 76, 1, 34, 89, 44, 25, 6, 26, 100, 13))
$tree.ToString()

Return:
@"
50
├──L:1
│   └──R:34
│       ├──L:25
│       │   ├──L:6
│       │   │   └──R:13    
│       │   └──R:26        
│       └──R:44
└──R:76
    └──R:89
        └──R:100
"@
```
