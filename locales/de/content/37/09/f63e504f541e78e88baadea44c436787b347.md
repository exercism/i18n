# Strings

Crystal hat einen Typ namens [`String`][strings], mit dem du Text darstellst.
Crystal-Strings sind Folgen von Unicode-Zeichen.
Strings sind unveränderlich, das heißt, sie können nach ihrer Erstellung nicht mehr geändert werden.
Bei jeder Änderung entsteht also ein neuer String. Der ursprüngliche String bleibt dabei unverändert.

Um einen String zu definieren, verwendest du doppelte Anführungszeichen `"`.

```crystal
"Hello World"
```

## Verkettung

Um zwei Strings zu verketten, verwendest du den Operator `+`.
Der Operator `+` gibt einen neuen String zurück, der beide Strings kombiniert.

```crystal
hello = "Hello"
hello + " World"
# => "Hello World"
```

## Umwandlung zwischen Strings und Zahlen

Die Methode `to_i` wandelt einen String in eine Ganzzahl um.
Alternativ kannst du mit der Methode `to_f` eine Gleitkommazahl erzeugen.
Lässt sich der String nicht in eine Zahl umwandeln, wird ein `ArgumentError` ausgelöst.

```crystal
"1".to_i
# => 1

"1.0".to_f
# => 1.0

"Hello".to_i
# => ArgumentError: Invalid integer: Hello
```

Eine Ganzzahl oder Gleitkommazahl kannst du mit der Methode `to_s` in einen String umwandeln.

```crystal
1.to_s
# => "1"

1.0.to_s
# => "1.0"
```

## Interpolation

Interpolation ist eine praktische Möglichkeit, Strings zu kombinieren und Ausdrücke in Strings einzubetten.
Zum Interpolieren schreibst du das Zeichen `#`, gefolgt von geschweiften Klammern `{}`, mit dem Ausdruck zwischen den Klammern.

```crystal
name = "World"
"Hello #{name}!"
# => "Hello World!"
```

Crystal wandelt das Ergebnis des Ausdrucks automatisch in einen String um.

```crystal
"Hello #{1 + 1}!"
# => "Hello 2!"
```

## Größe

Wenn du wissen willst, wie viele Zeichen ein String hat, verwendest du die Methode `size`. Sie gibt die Länge des Strings als Ganzzahl zurück.
Die Größe eines Strings ist eine gespeicherte Eigenschaft des Strings. Sie muss also nicht bei jedem Methodenaufruf neu berechnet werden, was die Methode sehr schnell macht.

```crystal
"Hello World".size
# => 11
```

## Indizierung

Beim Indizieren holst du ein bestimmtes Zeichen aus einem String.
Um ein Zeichen aus einem `String` zu holen, verwendest du die bekannte Notation mit eckigen Klammern.

~~~~exercism/note
`[]` ist als Instanzmethode von String implementiert, wobei der Index das Argument der Methode ist.
~~~~

In Crystal hat das erste Zeichen eines Strings den Index 0.

```crystal
"Hello World"[0]
# => 'H'

"Hello World"[6]
# => 'W'
```

Um ein Zeichen vom Ende eines Strings zu holen, kannst du die Länge des Strings minus eins rechnen und erhältst so den Index des letzten Zeichens. Für das vorletzte Zeichen rechnest du die Länge minus zwei, und so weiter.
Dafür gibt es eine Abkürzung: Du verwendest einfach einen negativen Index. Das letzte Zeichen hat dann den Index -1, das vorletzte den Index -2, und so weiter.

```crystal
name = "Hello World"
name[name.size - 1]
# => 'd'

name[-1]
# => 'd'
```

### Teilstring-Test

Crystal kann mit Indizierung prüfen, ob ein String einen Teilstring enthält.
Die gleiche Notation mit eckigen Klammern erledigt das, aber statt eines Index gibst du einen Teilstring an.
Wird der Teilstring im String gefunden, gibt Crystal ihn zurück. Andernfalls wird ein `NilAssertionError` ausgelöst.

```crystal
"Hello World"["Hello"]
# => "Hello"

"Hello World"["Goodbye"]
# => NilAssertionError
```

Wenn du einen `Bool`-Wert haben willst, der angibt, ob der Teilstring gefunden wurde, verwendest du die Methode `includes?`.

```crystal
"Hello World".includes?("Hello")
# => true

"Hello World".includes?("Goodbye")
# => false
```

## Escaping

Manche Zeichen kannst du nicht direkt in einen String schreiben. Stattdessen brauchst du eine Escape-Sequenz.
Wenn du zum Beispiel doppelte Anführungszeichen in einem String verwenden willst, musst du sie escapen.
Mit dem Zeichen `\` leitest du eine Escape-Sequenz ein, gefolgt von dem Zeichen, das du escapen willst.

Das sind die Sonderzeichen in Crystal:

| Value    | Description                   |
| -------- | ----------------------------- |
| `\a`     | Alarm                         |
| `\b`     | Rücktaste                     |
| `\e`     | Escape                        |
| `\f`     | Seitenvorschub                |
| `\n`     | Zeilenvorschub oder Zeilenumbruch |
| `\r`     | Wagenrücklauf                 |
| `\t`     | Horizontaler Tabulator        |
| `\v`     | Vertikaler Tabulator          |
| `\\`     | Backslash                     |
| `\'`     | Einfaches Anführungszeichen   |
| `\"`     | Doppeltes Anführungszeichen   |
| `\377`   | Oktales ASCII-Zeichen         |
| `\xFF`   | Hexadezimales ASCII-Zeichen   |
| `\uFFFF` | Hexadezimales Unicode-Zeichen |

```crystal
puts "Hello \"World\""
# => Hello "World"

puts "Hello \nWorld"
# => Hello
# => World
```

## Mehrzeilige Strings

Für einen mehrzeiligen String verwendest du die gleiche Syntax wie für einen einzeiligen, machst aber für jede gewünschte Zeile eine neue Zeile.

```crystal
"Hello
World"
# => "Hello\nWorld"
```

## Unicode

[Unicode][unicode] ist ein Standard zum Kodieren, Darstellen und Verarbeiten von Text in verschiedenen Schriftsystemen.
Unicode unterstützt über 100.000 Zeichen, darunter Buchstaben, Satzzeichen, Symbole und Emojis.

Da Crystal Unicode für Strings verwendet, kannst du zum Beispiel Emojis in Strings schreiben.

```crystal
"Hello 🌍"
# => "Hello 🌍"
```

Manchmal möchtest du ein Zeichen verwenden, das zum Beispiel in deinem Editor oder deinem System nicht verfügbar ist.
In diesem Fall kannst du die Unicode-Escape-Sequenz verwenden, um das Zeichen zu schreiben.

```crystal
"\u{1F310}"
# => "🌐"
```
