# Anhang zur Anweisung

Wenn die Eingabe ungültig ist, gib eine leere Länge zurück.

## Reservierte Adressen

Der Puffer für den ersten String belegt die Bytes 1024-2047 des linearen Speichers.
Der Puffer für den zweiten String belegt die Bytes 2048-3071 des linearen Speichers.
Der Puffer für den dritten String belegt die Bytes 3072-4095 des linearen Speichers.

Das erste Segment der Bytes 0-1023 des linearen Speichers kann frei verwendet werden.
