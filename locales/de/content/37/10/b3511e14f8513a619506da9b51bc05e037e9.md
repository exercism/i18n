# Einführung

Go kennt kein Konzept von leer, null oder undefiniert für Variablenwerte.
Variablen, die ohne einen expliziten Anfangswert deklariert werden, haben standardmäßig den Nullwert ihres jeweiligen Typs.

Der Nullwert für primitive Typen wie boolesche Werte, numerische Typen und Strings ist `false`, `0` bzw. `""`.

Der Bezeichner `nil`, der für Null steht, ist der Nullwert für komplexere Typen wie Zeiger, Funktionen, Interfaces, Slices, Channels und Maps.

Die folgende Tabelle zeigt den Nullwert für die Typen von Go.

| Typ       | Nullwert   |
| --------- | ---------- |
| boolescher Wert | `false`    |
| numerisch | `0`        |
| String    | `""`       |
| Zeiger    | `nil`      |
| Funktion  | `nil`      |
| Interface | `nil`      |
| Slice     | `nil`      |
| Channel   | `nil`      |
| Map       | `nil`      |

Vielleicht ist dir aufgefallen, dass Struct-Typen in der obigen Tabelle fehlen.
Das liegt daran, dass der Nullwert eines Struct-Typs von seinen Feldern abhängt.
Ein Struct hat dann seinen Nullwert, wenn alle seine Felder auf ihren jeweiligen Nullwert gesetzt sind.
