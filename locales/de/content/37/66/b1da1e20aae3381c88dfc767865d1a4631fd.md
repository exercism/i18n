# Ergänzung zu den Anweisungen

## Track-spezifische Anweisungen

Die Funktionen sollen das Produkt sowie den Offset und die Länge des Faktoren-Arrays zurückgeben. Die Faktoren werden einfach als Paare von i32 in den Speicher geschrieben:

```
Return value:
[u32 $product] [u32 $factorsOffset] [u32 $factorsLength]

Memory at $factorsOffset
[u32 firstFactor] [u32 firstCofactor] [u32 secondFactor] [u32 secondCofactor] ...
```

Für das größte einstellige Palindromprodukt sieht das so aus:

```
Return value
0009 0000 0004

Memory at offset 0
0001 0009 0003 0003
```
