# Boilerplate-Kommentar

Es sieht so aus, als hättest du die Kommentare „PLEASE REMOVE THESE COMMENTS..." in deinem Code gelassen.

Veraltete oder irrelevante Kommentare können die Klarheit deines Codes beeinträchtigen. Kommentare solltest du aktualisieren und/oder entfernen, sobald du den Code bearbeitest.
