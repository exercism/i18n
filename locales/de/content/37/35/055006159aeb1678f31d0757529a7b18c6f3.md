# Überblick

[Tupel][tuple] werden häufig verwendet, um Informationen zu gruppieren. Sie unterscheiden sich von Listen darin, dass sie eine feste Größe haben und verschiedene Datentypen enthalten können.
Tupel erstellst du mit runden Klammern, `()`, und sie werden oft verwendet, um mehrere Werte aus einer Funktion zurückzugeben.

```haskell
tuple = (1, "abc", False)
```

Das ist zum Beispiel nützlich, wenn du eine Koordinate in einem zweidimensionalen Raum speichern willst. Dann weißt du, dass das Tupel immer zwei Elemente hat: die x- und die y-Koordinate.

```haskell
coordinate = (3, 4)
```

## Zugriff auf Elemente

Häufig hast du es mit kurzen Tupeln zu tun, und auf die Elemente greifst du mit den Funktionen `fst` und `snd` zu.

```haskell
x = fst coordinate
-- x = 3
y = snd coordinate
-- y = 4
```

[tuple]: https://hackage.haskell.org/package/base/docs/Data-Tuple.html
