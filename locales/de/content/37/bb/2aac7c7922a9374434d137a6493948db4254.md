# Einführung

Jede Factor-Quelldatei deklariert mit `IN:` ein *Vokabular* und importiert alle weiteren, die sie verwendet, mit `USING:`.

```factor
USING: kernel sequences ;
IN: my-vocab

: shout ( str -- str ) "!" append ;
```

Die Verzeichnisstruktur folgt dem Vokabelnamen mit Punkten:

- das Vokabular `my-vocab` liegt unter `my-vocab/my-vocab.factor`
- das Vokabular `my-vocab.helpers` liegt unter `my-vocab/helpers/helpers.factor`

Der Vokabular-Lader von Factor folgt `USING:`-Deklarationen transitiv: Wenn eine Datei, die du einbindest, ein weiteres Vokabular importiert, wird dieses Vokabular automatisch geladen.

Häufig verteilst du eine große Routine über zwei Vokabulare hinweg: ein Hilfsvokabular mit kleinen wiederverwendbaren Wörtern und ein Hauptvokabular, das sie importiert und das Ergebnis zusammensetzt.
