# Syntax-Highlighting

Auf der Website gibt es zwei Arten von Syntax-Highlighting:

1. Das Hervorheben von _statischem_ Code (Code-Schnipsel, Iterationen und Ähnliches).
   Weitere Informationen findest du in der [Dokumentation zum statischen Syntax-Highlighting](/docs/building/tracks/new/syntax-highlighting/static).
2. Das Hervorheben von _dynamischem_ Code (der Online-Editor).
   Weitere Informationen findest du in der [Dokumentation zum dynamischen Syntax-Highlighting](/docs/building/tracks/new/syntax-highlighting/dynamic).

```exercism/note
Die Anforderungen an statisches und dynamisches Syntax-Highlighting sind _sehr_ unterschiedlich, deshalb nutzen sie unterschiedliche Bibliotheken.
```
