# Zusätzliche Anweisungen

## Track-spezifische Anweisungen

Das solltest du über das Eingabeformat wissen:

- **Linkes Argument**: Der Name des Planeten, angegeben als String.
- **Rechtes Argument**: Das Alter in Sekunden, angegeben als Ganzzahl.

Deine Funktion wird mit diesen Argumenten so aufgerufen:

```j
  planet  =. 'Earth'
  seconds =. 1000000000
  
  planet age seconds
```
