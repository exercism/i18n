## 1. Erkenne verstümmelte Logzeilen

- Verwende das Sigil [`r`][sigil-r], um einen regulären Ausdruck zu erstellen.
- Es gibt [einen Operator][match-operator], mit dem du einen String gegen einen regulären Ausdruck prüfen kannst. Es gibt auch eine [`Regex`-Funktion][regex-match] und eine [`String`-Funktion][string-match], die dasselbe leisten.
- Vergiss nicht, Zeichen zu escapen, die in regulären Ausdrücken eine besondere Bedeutung haben.

## 2. Teile die Logzeile auf

- Es gibt eine [`Regex`-Funktion][regex-split] sowie eine [`String`-Funktion][string-split], die einen String anhand eines regulären Ausdrucks in eine Liste von Strings aufteilen können.
- Vergiss nicht, Zeichen zu escapen, die in regulären Ausdrücken eine besondere Bedeutung haben.

## 3. Entferne Artefakte aus dem Log

- Es gibt eine [`Regex`-Funktion][regex-replace] sowie eine [`String`-Funktion][string-replace], die einen Teil eines Strings, der zu einem gegebenen regulären Ausdruck passt, durch einen anderen String ersetzen können.
- Es gibt einen [Modifier][regex-modifiers], mit dem du die Groß- und Kleinschreibung für den gesamten regulären Ausdruck ignorieren kannst.

## 4. Versehe Zeilen mit Benutzernamen

- Es gibt eine [`Regex`-Funktion][regex-run], die einen regulären Ausdruck auf einen String anwendet und alle Captures zurückgibt.
