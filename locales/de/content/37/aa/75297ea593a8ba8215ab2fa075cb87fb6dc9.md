# Anleitung

Deine Aufgabe ist es, zu bestimmen, was du sagst, wenn du den zusätzlichen Keks verschenkst.

Wenn dein Freund Kekse mag und Do-yun heißt, dann sagst du:

```text
One for Do-yun, one for me.
```

Wenn dein Freund keine Kekse mag, gibst du den Keks der nächsten Person in der Schlange in der Bäckerei. Da du ihren Namen nicht kennst, sagst du stattdessen _you_.

```text
One for you, one for me.
```

Hier sind einige Beispiele:

| Name   | Dialog                      |
| :----- | :-------------------------- |
| Alice  | One for Alice, one for me.  |
| Bohdan | One for Bohdan, one for me. |
|        | One for you, one for me.    |
| Zaphod | One for Zaphod, one for me. |
