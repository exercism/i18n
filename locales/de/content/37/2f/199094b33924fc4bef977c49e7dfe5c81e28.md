# Anweisungen

Hallo, Agent Doppel-Null0111.

Deine Mission, sofern du sie annehmen möchtest, ist es, ein Paar Tools zu schreiben, mit denen du in das Hauptquartier von UMBRA (United Minions Being Really Awful) eindringst und die Pläne für ihren neuesten wirklich furchtbaren Plan beschaffst.
Für diese Mission brauchst du drei Tools.

## 1. Generiere eine ID-Nummer

Jeder Minion hat eine eindeutige ID, die sich jeden Tag ändert. Sie hängt davon ab, wie viele Geheimnisse der Minion hütet und wie viele Stunden er schläft.
Du musst eine Funktion schreiben, die den Tag (als `Int`) entgegennimmt und eine Funktion zurückgibt, mit der sich die ID für diesen Tag erzeugen lässt.
Diese ID-erzeugende Funktion nimmt zwei Parameter entgegen:

1. die Anzahl der gehüteten Geheimnisse
2. die Anzahl der Stunden, die der Minion schläft

Die ID wird so berechnet:

1. Multipliziere die Anzahl der gehüteten Geheimnisse mit der Anzahl der Stunden, die der Minion schläft.
2. Addiere den Tag (als `Int` dargestellt) zum Ergebnis.

```kotlin
val idGenerator = makeIdGenerator(4)
idGenerator(3, 6)
// => 22

idGenerator(11, 5)
//  => 59
```

## 2. Schütze die geborgenen geheimen Pläne mit einem geheimen Passwort

Sobald du die geheimen Pläne hast, musst du sie schützen, damit nur diejenigen sie wiederherstellen können, die das Passwort kennen.
Dazu musst du die Funktion `protectSecret(secret: String, password: String) : (String) -> String` implementieren.
Diese Funktion gibt eine weitere Funktion zurück, die mögliche Passwörter als Eingabewerte entgegennimmt.
Wenn das eingegebene Passwort korrekt ist, gibt die neue Funktion das verborgene Geheimnis zurück. Ist das Passwort falsch, gibt die Funktion "Sorry. No hidden secrets here." zurück.

```kotlin
val secretFunction = protectSecret("Steal the world's supply of french fries!", "5up3r53cr37")

secretFunction("Open sesame")
// Returns "Sorry. No hidden secrets here."

secretFunction("5up3r53cr37")
// Returns "Steal the world's supply of french fries!"
```

## 3. Finde das geheime Passwort

Die UMBRA-Basis hat eine Reihe von Räumen, die von einem Wachmann bewacht werden, der dich nach dem geheimen Passwort fragt.
Das geheime Passwort hängt von der Nummer des Raums ab.
Leider kennen wir nur die Hälfte des Algorithmus, mit dem das Passwort berechnet wird.
Die andere Hälfte erfährst du, wenn du einen der Minions fragst.

Implementiere die Funktion `getPassword`, die Folgendes entgegennimmt und das Passwort zurückgibt:

1. die Raumnummer
2. die Funktion des Minions, und gibt das geheime Passwort zurück

Das geheime Passwort erhältst du, indem du die Funktion des Minions mit einer weiteren Funktion aufrufst, die den uns bekannten Algorithmus darstellt.
Unser Teil des Algorithmus:

1. nimmt zwei Zahlen und addiert sie
2. multipliziert das Ergebnis mit der Raum-ID

```kotlin
val minionFunction = { yourFunc : (Int, Int) -> Int ->
    "Password=${yourFunc(1, 3)}"
}

getPassword(5, minionFunction)
// Returns "Password=20"
```
