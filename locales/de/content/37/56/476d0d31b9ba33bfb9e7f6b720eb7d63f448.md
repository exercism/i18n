# Einführung

In der Programmierung ist es wichtig, Fehler sauber zu behandeln, damit unerwartete Situationen nicht dazu führen, dass ein Programm abstürzt oder sich unvorhersehbar verhält.
Cairo bietet zwei wichtige Mechanismen für die Fehlerbehandlung:

1. **Nicht behebbare Fehler** mit `panic`, die das Programm sofort stoppen.
2. **Behebbare Fehler** mit `Result`, mit denen das Programm auf Fehler reagieren und sie behandeln kann.

## Nicht behebbare Fehler mit `panic`

Manchmal stößt ein Programm auf einen Fehler, der so schwerwiegend ist, dass es nicht weiterarbeiten kann.
In solchen Fällen verwendet Cairo die Funktion `panic`, um die Ausführung sofort zu stoppen.
Das ist hilfreich, wenn ein Fehler, etwa der Zugriff auf einen Index außerhalb der Grenzen, es dem Programm unmöglich macht, sinnvoll weiterzumachen.
Die Funktion `panic` nimmt eine `ByteArray`-Nachricht entgegen, die den Grund für den Fehler beschreibt.

Zum Beispiel in Cairo:

```rust
fn main() {
    let data = array![1, 2];
    panic("An unrecoverable error has occurred!");
}
```

Dieses Beispiel zeigt einen erzwungenen Panic, der das Programm sofort mit einer Meldung stoppt.

### Das `assert!`-Makro

Das Makro `assert!` ist ein nützliches Werkzeug, um bestimmte Bedingungen in deinem Code durchzusetzen.
Wenn die Bedingung in `assert!` zu `false` ausgewertet wird, löst das Programm einen Panic mit einer `ByteArray`-Fehlermeldung aus.
Das wird oft genutzt, um Annahmen während der Entwicklung zu überprüfen und sicherzustellen, dass Werte bestimmte Kriterien erfüllen.

Zum Beispiel:

```rust
fn main() {
    let x = 5;
    assert!(x > 0, "x must be greater than zero");
}
```

Wenn `x` nicht größer als null ist, bricht das Programm mit der Meldung `"x must be greater than zero"` ab. `assert!` ist hilfreich, um Invarianten und Vorbedingungen zu prüfen, ohne manuell Fehlerbehandlungscode zu schreiben.

## Behebbare Fehler mit `Result`

Nicht jeder Fehler muss das Programm stoppen.
Manche lassen sich sauber behandeln, sodass das Programm weiterlaufen kann.
Das `Result`-Enum von Cairo steht für diese behebbaren Fehler und hat zwei Varianten:

- `Result::Ok` zeigt Erfolg an.
- `Result::Err` steht für einen Fehler.

Mit `Result` kann eine Funktion entweder einen Erfolgswert oder einen Fehler zurückgeben, sodass die aufrufende Funktion entscheiden kann, was als Nächstes zu tun ist.

```rust
fn divide(a: u32, b: u32) -> Result<u32, ByteArray> {
    if b == 0 {
        Result::Err("Error: Division by zero")
    } else {
        Result::Ok(a / b)
    }
}
```

In diesem Beispiel wird ein Fehler zurückgegeben, wenn `b` null ist; andernfalls wird das Ergebnis der Division zurückgegeben.
