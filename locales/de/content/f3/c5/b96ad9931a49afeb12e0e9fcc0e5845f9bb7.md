# Anleitung

In dieser Übung sollst du die Software für ein Verschlüsselungsgerät schreiben, das Daten durch Transformationen verändert. Du brauchst eine Möglichkeit, komplizierte Funktionen flexibel zu erstellen, indem du einfachere Funktionen kombinierst.

Gib für jede Aufgabe eine anonyme Funktion zurück, die aus dem aufrufenden Gültigkeitsbereich heraus aufgerufen werden kann.

## 1. Erstelle einen Addierer

Implementiere `secret_add`. Die Funktion sollte eine Funktion zurückgeben, die ein Argument entgegennimmt und zu diesem das Argument addiert, das an `secret_add` übergeben wurde.

```gleam
let adder = secret_add(2)
adder(2)
// -> 4
```

## 2. Erstelle einen Subtrahierer

Implementiere `secret_subtract`. Die Funktion sollte eine Funktion zurückgeben, die ein Argument entgegennimmt und den geheimen Wert, der an `secret_subtract` übergeben wurde, von diesem Argument subtrahiert.

```gleam
let subtractor = secret_subtract(2)
subtractor(3)
// -> 1
```

## 3. Erstelle einen Multiplizierer

Implementiere `secret_multiply`. Die Funktion sollte eine Funktion zurückgeben, die ein Argument entgegennimmt und dieses Argument mit dem geheimen Wert multipliziert, der an `secret_multiply` übergeben wurde.

```gleam
let multiplier = secret_multiply(7)
multiplier(3)
// -> 21
```

## 4. Erstelle einen Dividierer

Implementiere `secret_divide`. Die Funktion sollte eine Funktion zurückgeben, die ein Argument entgegennimmt und dieses Argument durch den geheimen Wert dividiert, der an `secret_divide` übergeben wurde.

```gleam
let divider = secret_divide(3)
divider(32)
// -> 10
```

## 5. Erstelle einen Funktionskombinierer

Implementiere `secret_combine`. Die Funktion sollte eine Funktion zurückgeben, die ein Argument entgegennimmt und auf dieses Argument der Reihe nach die beiden Funktionen anwendet, die an `secret_combine` übergeben wurden.

```gleam
let multiply = secret_multiply(7)
let divide = secret_divide(3)
let combined = secret_combine(multiply, divide)

combined(6)
// -> 14
```
