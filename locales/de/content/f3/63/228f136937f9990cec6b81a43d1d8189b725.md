# Anleitung

In dieser Übung baust du die Fehlerbehandlung für einen einfachen Ganzzahl-Taschenrechner.
Der Taschenrechner soll Addition, Multiplikation und Division unterstützen und das Ergebnis als formatierten String zurückgeben.
Außerdem implementierst du die Fehlerbehandlung für ungültige Operationen und die Division durch null.

Das Ziel ist ein funktionierender Taschenrechner, der einen String im folgenden Format zurückgibt:

```rust
SimpleCalculator::calculate(16, 51, "+"); // => returns "16 + 51 = 67"

SimpleCalculator::calculate(32, 6, "*"); // => returns "32 * 6 = 192"

SimpleCalculator::calculate(512, 4, "/"); // => returns "512 / 4 = 128"
```

## 1. Implementiere die Rechenoperationen

Die Hauptfunktion für diese Aufgabe ist `SimpleCalculator::calculate`. Sie nimmt drei Argumente entgegen: zwei Ganzzahlen und ein `ByteArray`, das die Operation darstellt.
Implementiere die folgenden Operationen:

- **Addition** mit dem Symbol `+`
- **Multiplikation** mit dem Symbol `*`
- **Division** mit dem Symbol `/`

## 2. Behandle ungültige Operationen

Wenn das Operationssymbol etwas anderes als `+`, `*` oder `/` ist, soll der Taschenrechner entweder panic auslösen oder einen Fehler zurückgeben:

- Wenn die Operation ein leerer String ist, löse einen panic mit der `ByteArray`-Fehlermeldung `"Operation cannot be an empty string"` aus.
- Bei jeder anderen ungültigen Operation gib `Result::Err("Operation is out of range")` zurück.

```rust
SimpleCalculator::calculate(100, 10, "-"); // => returns Result::Err("Operation is out of range")

SimpleCalculator::calculate(8, 2, ""); // => panics with "Operation cannot be an empty string"
```

## 3. Behandle Fehler bei der Division durch null

Wenn du versuchst, durch `0` zu teilen, soll der Taschenrechner mit einer Fehlermeldung panic auslösen, die angibt, dass die Division durch null nicht erlaubt ist.
Das zurückgegebene Ergebnis soll ein `felt252`-Wert mit dem Inhalt `'Division by zero is not allowed'` sein.

```rust
SimpleCalculator::calculate(512, 0, "/"); // => panics with 'Division by zero is not allowed'
```
