# Anweisungen

Karl möchte den Überblick über eine Liste von Sprachen behalten, die er auf der Website von Exercism lernen will.
Karl muss neue Sprachen hinzufügen, alte entfernen und prüfen können, ob bestimmte Sprachen in der Liste stehen.
Es wäre sehr spannend, wenn Karl Java oder Kotlin lernen möchte!

## 1. Definiere eine Funktion, die prüft, ob die Liste der Sprachen leer ist

Karl muss wissen, ob seine Liste der Sprachen irgendwann leer ist, damit er sich weitere zum Lernen suchen kann!
Definiere eine Methode namens `isEmpty`, die `true` zurückgibt, wenn keine Sprachen in der Liste sind.

```java
if (languageList.isEmpty()) {
    findMoreLanguagesToLearn();
}
```

## 2. Definiere eine Funktion, die eine Sprache zur Liste hinzufügt

Karl freut sich schon darauf, Kotlin und Python zu lernen!
Hilf Karl beim Einstieg, indem du eine Methode namens `addLanguage` definierst, die die Sprache entgegennimmt, die er lernen möchte, und sie der Liste hinzufügt.

```java
languageList.addLanguage("Kotlin");
languageList.addLanguage("Python");
```

## 3. Definiere eine Funktion, die eine Sprache aus der Liste entfernt

Karl hat entschieden, dass er Scala gerade nicht lernen möchte.
Hilf Karl, sie aus der Liste zu entfernen, indem du eine Methode namens `removeLanguage` definierst, die die Sprache entgegennimmt, die er entfernen möchte, und sie aus der Liste entfernt.

```java
languageList.removeLanguage("Scala");
```

## 4. Definiere eine Funktion, die den ersten Eintrag der Liste zurückgibt

Karl möchte sich an die erste Sprache erinnern, die er der Liste hinzugefügt hat (und die noch in der Liste ist).
Definiere eine Methode namens `firstLanguage`, die die erste Sprache in der Liste zurückgibt.

```java
String kotlin = languageList.firstLanguage(); // "Kotlin"
```

## 5. Definiere eine Funktion, die zurückgibt, wie viele Sprachen in der Liste sind

Karl muss wissen, wie viele Sprachen er lernen möchte.
Hilf Karl, die Antwort zu finden, indem du eine Methode namens `count` definierst, die die Anzahl der Sprachen in der Liste zurückgibt.

```java
int two = languageList.count(); // 2
```

## 6. Definiere eine Funktion, die feststellt, ob eine Sprache in der Liste ist

Karl versucht sich zu erinnern, ob er Python oder Ruby lernen wollte.
Definiere eine Methode namens `containsLanguage`, die die Sprache entgegennimmt, nach der er fragt, damit Karl es herausfinden kann!

```java
boolean learningPython = languageList.containsLanguage("Python"); // true
boolean learningRuby = languageList.containsLanguage("Ruby"); // false
```

## 7. Definiere eine Funktion, die feststellt, ob die Liste spannend ist

Wenn Karl Java oder Kotlin lernen möchte, ist das sehr spannend!
Definiere eine Methode namens `isExciting`, die true zurückgibt, wenn Karl Java oder Kotlin lernen möchte.

```java
javaLanguageList.isExciting() // true
neitherKotlinNorJavaLanguageList.isExciting() // false
```
