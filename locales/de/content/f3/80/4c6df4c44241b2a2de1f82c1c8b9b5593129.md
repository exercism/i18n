# Hinweise

## 1. Erstelle die Klasse `JuiceMaker`

- Der Konstruktor muss einen Parameter vom Typ `Int` und einen vom Typ `Jug` annehmen
- Die Klasse braucht außerdem die Eigenschaften `capacity` und `jug`

## 2. Erweitere den Krug, wenn die Kapazität mehr als 1.000 Milliliter beträgt

- Mit `init`-Blöcken kannst du alle nötigen Initialisierungen vornehmen, wenn du ein Objekt erstellst

## 3. Installiere den Starter

- Füge einen sekundären Konstruktor hinzu
- Sekundäre Konstruktoren müssen trotzdem den primären Konstruktor aufrufen

## 4. Füge eine `start`-Funktion hinzu

- Die Klasse muss sich die Geschwindigkeit „merken“

## 5. Füge eine `stop`-Funktion hinzu

- Beim Aufruf muss sich die Klasse „merken“, dass sie gestoppt wurde (zumindest so lange, bis sie wieder gestartet wurde)

## 6. Füge eine `lightColor`-Funktion hinzu

- Diese Funktion muss prüfen, mit welcher Geschwindigkeit der Juice Maker gestartet wurde
- Außerdem muss diese Funktion wissen, ob der Juice Maker gestoppt wurde

## 7. Mit einer üblichen Kapazität bauen

- Die Funktion `buildWithCommonCapacity` sollte _außerhalb_ der Klasse `JuiceMaker` definiert werden
