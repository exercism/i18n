# Hinweise

## 1. Erstelle eine leere Liste

Eine leere Liste erstellst du genauso wie eine Liste mit Elementen. Das geht entweder mit `list` oder indem du `quote` auf eine leere Liste anwendest.

## 2. Füge der Liste eine neue Sprache hinzu

Clojure hat eine Kernfunktion, die [ein Element an den Anfang einer Liste setzt](https://clojuredocs.org/clojure.core/cons).

## 3. Prüfe die zuletzt hinzugefügte Sprache

Wie andere Lisps hat Clojure eine Funktion, die [das erste Element einer Liste zurückgibt](https://clojuredocs.org/clojure.core/first).

## 4. Entferne die erste Sprache aus der Liste

Ebenso hat Clojure eine Funktion, die [eine Liste ohne das erste Element zurückgibt](https://clojuredocs.org/clojure.core/rest).

## 5. Zähle die Sprachen in der Liste

Die [Anzahl der Elemente](https://clojuredocs.org/clojure.core/count) in einer Liste lässt sich leicht mit einer Clojure-Kernfunktion ermitteln.

## 6. Setze alles zusammen

Denk daran, dass Funktionsaufrufe verschachtelt werden können.
