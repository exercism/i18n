# Über

Rust implementiert den Typ [char][char type], um ein einzelnes Zeichen darzustellen. Ein `char`-Literal steht in einfachen Anführungszeichen, wie `'a'`.
Jedes `char` ist vier Bytes groß und stellt einen einzelnen [Unicode-Skalarwert][unicode scalar] dar.

Ein [`char`][character type] ist jedoch nicht immer das, was wir uns unter einem Buchstaben vorstellen. In manchen Sprachen, zum Beispiel Hindi, gibt es [diakritische Zeichen][diacritics], also besondere Symbole, die das Zeichen verändern, an das sie angehängt sind. Obwohl das diakritische Zeichen in Rust ein eigenes `char` ist, verstehen wir unter einem Buchstaben üblicherweise das diakritische Zeichen zusammen mit dem Zeichen, das es verändert.

Der Begriff für ein Zeichen zusammen mit seinem diakritischen Zeichen ist [Graphemcluster][grapheme cluster]. Es gibt externe Crates, mit denen du Graphemcluster verarbeiten kannst, zum Beispiel [unicode-segmentation][unicode-segmentation].

Beispiel

```rust
pub fn main() {
    let text = "ü"; // a "u" with a diacritic
    let text_vec: Vec<char> = text.chars().collect(); // this gets the chars in "ü"
    println!("{:?}", text_vec.len()); // this prints the number of chars in "ü"
    println!("{:?}", text_vec[0]); // this prints the first char in "ü"
    println!("{:?}", text_vec[1]); // this prints the second char in "ü"
}
```

gibt aus

```rust
2
'u'
'\u{308}'
```

`'\u{308}'` ist eine andere Schreibweise für ein `char`-Literal. `\u` zeigt an, dass es sich um ein Unicode-`char` handelt, wobei `{308}` die eindeutige Unicode-Nummer für dieses Zeichen oder diakritische Zeichen ist.
