# Anleitung

Dein Freund hat dir gerade eine Nachricht mit einem wichtigen Geheimnis geschickt.
Damit es andere nicht so leicht lesen können, wurde die Nachricht durch eine Reihe von Bitmanipulationen verschlüsselt.
Du musst die Methoden schreiben, mit denen du die Nachricht entschlüsseln kannst.

## 1. Die Bits zurückschieben

Der erste Schritt beim Entschlüsseln der Nachricht ist, die Verschiebung aus dem Verschlüsselungsprozess rückgängig zu machen, indem du die Bits wieder nach rechts verschiebst.
In den weiteren Schritten des Entschlüsselungsprozesses wird davon ausgegangen, dass von links Nullen eingefügt werden.

Implementiere die Methode `Secrets.shiftBack`, die einen Wert und die Anzahl der Stellen zum Verschieben entgegennimmt und die Verschiebung durchführt.

```java
Secrets.shiftBack(0b1001, 2);
# => 0b0010
```

## 2. Einige Bits setzen

Als Nächstes gibt es einige Bits, die auf 1 gesetzt werden müssen.

Implementiere die Methode `Secrets.setBits`, die einen Wert und eine Maske entgegennimmt und das Ergebnis davon zurückgibt, die Bits im Wert auf 1 zu setzen.
Ein Bit aus dem Wert sollte auf 1 gesetzt werden, wenn das entsprechende Bit in der Maske ebenfalls 1 ist.
Alle anderen Bits bleiben unverändert.

```java
Secrets.setBits(0b0110, 0b0101);
# => 0b0111
```

## 3. Bestimmte Bits umdrehen

Beim Verschlüsseln werden einige Bits umgedreht.
Sie müssen wieder zurückgedreht werden, um die Nachricht zu entschlüsseln.

Implementiere die Methode `Secrets.flipBits`, die einen Wert und die Maske entgegennimmt.
Die Maske gibt an, welche Bits im Wert umgedreht werden sollen.
Wenn das Bit in der Maske 1 ist, wird das Bit im Wert umgedreht.
Alle anderen Bits bleiben unverändert.

```java
Secrets.flipBits(0b1100, 0b0101);
# => 0b1001
```

## 4. Bestimmte Bits löschen

Zuletzt gibt es außerdem bestimmte Bits, die immer zu 0 entschlüsselt werden.

Implementiere die Methode `Secrets.clearBits`, die einen Wert und eine Maske entgegennimmt.
Die Bits im `value` sollten auf 0 gesetzt werden, wenn das Bit in der Maske 1 ist.
Alle anderen Bits bleiben unverändert.

```java
Secrets.clearBits(0b0110, 0b0101);
# => 0b0010
```
