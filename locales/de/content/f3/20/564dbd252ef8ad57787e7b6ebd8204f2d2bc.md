# Anweisungen

In dieser Übung verarbeitest du Logzeilen.

Jede Logzeile ist ein String mit folgendem Format: `"[<LEVEL>]: <MESSAGE>*"`.

## 1. Hole die Nachricht aus einer Logzeile

Implementiere die Funktion `LogLevels.message()`, die die Nachricht aus einer Logzeile zurückgibt, ohne führende und abschließende Leerzeichen.

## 2. Ermittle das Log-Level aus einer Logzeile

Implementiere die Funktion `LogLevels.logLevel()`, die das Log-Level aus einer Logzeile in Kleinbuchstaben zurückgibt.

## 3. Formatiere eine Logzeile um

Implementiere die Methode `LogLevels.reformat()`, die eine Logzeile und einen String mit der Ortsangabe entgegennimmt und sie in eine Nachricht mit zwei Zeilen umformatiert.
Die erste Zeile hat das Format `<LEVEL>@<LOCATIOON>:`, wobei:

* `<LEVEL>` ist das Log-Level in Kleinbuchstaben (wie in 2. Ermittle das Log-Level aus einer Logzeile).
* `<LOCATION>` ist der Ort, der als zweiter Parameter übergeben wird.

Die zweite Zeile besteht aus genau zwei Leerzeichen, gefolgt von der Log-Nachricht (wie in 1. Hole die Nachricht aus einer Logzeile):

```kotlin
reformat("[TRACE]: Start of function", 2, 8)
// => "trace@208:
  Start of function"
```
