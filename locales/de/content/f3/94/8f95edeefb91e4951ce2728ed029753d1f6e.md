# Einführung

## Listen

Der Name der Sprache, die wir hier verwenden, Lisp, steht für _LIST Processing_. Da könnte man annehmen, dass die Sprache etwas für den Umgang mit Listen von Elementen mitbringt, und damit hättest du recht!

Common Lisp hat zwar auch andere Datenstrukturen als Listen, aber Listen werden trotzdem viel verwendet.

Eine Liste in Common Lisp ist eine Folge von Elementen. Sie wird (hauptsächlich aus historischen Gründen) auch **Cons** genannt.
Die Elemente selbst müssen nicht alle denselben Typ haben.
Du kannst zum Beispiel eine Liste aus `1`, `two` und `"III"` haben.

### Listen erstellen

Du kannst einfach eine quotierte Liste wie diese eintippen: `'(1 two "III")`. Dadurch wird eine Liste erstellt und ausgewertet (ausgewertet ergibt sie `(1 two "III")`).

Außerdem gibt es zwei wichtige Funktionen, mit denen du Listen erstellst: `list` und `cons`.

`list` nimmt null oder mehr Argumente und ergibt ausgewertet eine Liste, die mit diesen Werten erstellt wurde:

```lisp
(list 1 'two "III") ; => (1 two "III")
```

`cons` nimmt zwei Elemente und erstellt eine Liste, deren erstes Element das `car` (der Listenkopf) und deren zweites Element das `cdr` (der Rest der Liste) ist:

```lisp
(cons 1 2)            ; => (1 . 2) ;; (a list without `nil` as its `cdr` is printed in this way)
(cons 1 nil)          ; => (1)
(cons 1 (cons 2 nil)) ; => (1 2)
```

Mit den Funktionen `car` und `cdr` kannst du auf das `car` und das `cdr` einer Liste zugreifen.

(`first` und `rest` sind Synonyme für `car` und `cdr` und funktionieren genau gleich.)

### Länge und wahlfreier Zugriff

Die Länge einer Liste kannst du mit `length` bestimmen.
Eine leere Liste hat die Länge null.

Auf ein beliebiges Element kannst du mit `nth` zugreifen (beachte, dass Listen bei null anfangen zu zählen).

Es ist _kein_ Fehler, einen Index anzufordern, der größer ist als die Liste lang ist.
Stattdessen ergibt er ausgewertet `nil`:

```lisp
(nth 23 '(short list)) ; => nil
```

Außerdem gibt es mehrere Hilfsfunktionen, um auf die ersten Elemente einer Liste zuzugreifen: `first`, `second`, `third`, und so weiter bis `tenth`. Praktisch, oder?

### Listen kombinieren

Zwei oder mehr Listen kannst du mit `append` kombinieren: 

```lisp
(append '(a b c) '(1 2 3)) ; => (A B C 1 2 3)
(append '(a b c) '())     ; => (A B C)
```

Jedes Argument, das du `append` übergibst, muss eine Liste sein.
