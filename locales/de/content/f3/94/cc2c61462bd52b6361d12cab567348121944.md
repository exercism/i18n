# Signatur nicht optimal

Wenn du dir die Tests ansiehst, fällt dir auf, dass die Funktion `gigasecond(...)` nur einen Parameter erhält. Entferne die zusätzlichen Parameter aus der Definition von `gigasecond`, denn die Werte dieser zusätzlichen Parameter sind immer `undefined` oder entsprechen dem Standardwert, der derzeit in der Signatur definiert ist.
