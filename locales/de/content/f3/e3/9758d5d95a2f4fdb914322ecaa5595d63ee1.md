# Statische Schlüsselwörter in Klassen

Eine Klasse ist eine Einheit zur Organisation von Code in PHP und stellt oft eine Instanz einer Sache, eines Dienstes oder einer Prozedur dar.
Mit den Schlüsselwörtern `static` und `self` können Eigenschaften und Methoden in Bezug auf die Klasse für alle Instanzen (oder für keine Instanz) existieren.

```php
<?php

class Book
{
    static $genre = 'Adventure';

    static function getGenre()
    {
        return self::$genre;
    }
}

// Usage
$genre = Book::$genre;
$genre = Book::getGenre();
```

## Einschränkung

Statische Klassenmethoden können nur andere statische Klasseneigenschaften oder Klassenmethoden aus ihrer eigenen Klasse aufrufen.
