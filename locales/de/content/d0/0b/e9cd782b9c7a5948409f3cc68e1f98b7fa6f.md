# Installation

## Mac

Installiere es mit Homebrew über `brew install swi-prolog`.
Alternativ kannst du den Quellcode für dein System von der [SWI Prolog Website](http://www.swi-prolog.org/download/devel) herunterladen.

## Windows

Lade den Quellcode für dein System von der [SWI Prolog Website](http://www.swi-prolog.org/download/devel) herunter.

## Linux

Folge den Anweisungen für deine Distribution, die du [hier](http://www.swi-prolog.org/build/unix.html) findest.
