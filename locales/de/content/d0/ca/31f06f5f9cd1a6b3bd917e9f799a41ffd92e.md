# Ergänzung zu den Anweisungen

## Register

| Register | Verwendung | Typ      | Beschreibung                       |
| -------- | ---------- | -------- | ---------------------------------- |
| `$a0`    | Eingabe    | Ganzzahl | Nummer des Feldes im Bereich 1..64 |
| `$v0`    | Ausgabe    | Ganzzahl | untere 32 Bits der Ausgabe         |
| `$v1`    | Ausgabe    | Ganzzahl | obere 32 Bits der Ausgabe          |
| `$t0-9`  | temporär   | beliebig | zur temporären Speicherung         |
