# Anweisungen

In dieser Übung schreibst du Code, der einem Freelancer hilft, mit einer Projektleitung zu kommunizieren: Du stellst ein paar Hilfsfunktionen bereit, mit denen sich Tages- und Monatssätze schnell berechnen lassen, optional mit einem gegebenen Rabatt.

Zuerst legen wir ein paar Regeln zwischen dem Freelancer und der Projektleitung fest:

Der Tagessatz ist das 8-Fache des Stundensatzes.
Ein Monat hat 22 abrechenbare Tage.
Der Freelancer bietet an, einen Rabatt zu gewähren, wenn die Projektleitung sich dafür entscheidet, monatlich abrechnen zu lassen. Das ist praktisch, wenn die Projektleitung mit einem bestimmten Budget arbeiten muss.

Rabatte werden als Gleitkommazahlen modelliert, die einen Prozentsatz angeben, zum Beispiel 25.0 (25 %).

## 1. Berechne den Tagessatz bei gegebenem Stundensatz

Implementiere eine Funktion, die den Tagessatz bei gegebenem Stundensatz berechnet:

```gleam
freelancer_rates.daily_rate(60)
# => 480.0
```

Der zurückgegebene Tagessatz sollte eine Gleitkommazahl sein.

## 2. Berechne einen rabattierten Preis

Implementiere eine Funktion, die den Preis nach einem Rabatt berechnet.

```gleam
freelancer_rates.apply_discount(150, 10)
# => 135.0
```

Der Rückgabewert sollte immer eine Gleitkommazahl sein und in keiner Weise gerundet werden.

## 3. Berechne den Monatssatz bei gegebenem Stundensatz und Rabatt

Implementiere eine Funktion, die den Monatssatz berechnet und einen Rabatt anwendet:

```gleam
freelancer_rates.monthly_rate(77, 10.5)
# => 12130
```

Der zurückgegebene Monatssatz sollte auf die nächste Ganzzahl aufgerundet werden (das Ceiling).

## 4. Berechne die Anzahl der Arbeitstage bei gegebenem Budget, Stundensatz und Rabatt

Implementiere eine Funktion, die ein Budget, einen Stundensatz und einen Rabatt entgegennimmt und berechnet, wie viele Arbeitstage damit abgedeckt sind.

```gleam
freelancer_rates.days_in_budget(20000, 80, 11.0)
# => 35
```

Die zurückgegebene Anzahl an Tagen sollte auf eine Nachkommastelle abgerundet werden (das Floor).
