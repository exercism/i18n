# Einführung

Veränderbarkeit ist eine Eigenschaft einer bestimmten Bindung eines Werts an eine Variable.
Eine Variable ist entweder unveränderlich oder veränderlich.
Der Wert einer unveränderlichen Variable darf nicht geändert werden; der Wert einer veränderlichen Variable kann geändert werden.
Alle Variablen sind standardmäßig unveränderlich.
