# Anleitung

Deine Bekannte Erin muss für mehrere Veranstaltungen tausende Handzettel drucken und braucht deine Hilfe! Sie hat dich gebeten, das Layout für einen Flyer zu erstellen, der eine Kopfzeile, ein optionales Datum und eine Liste von Künstlern enthält, die jeweils mit einem _Unicode-Icon_ verknüpft sind. Das Ziel ist, dein cooles neues Flyerdesign mit `print` auszugeben und zu verteilen, und dafür brauchst du all deine Fähigkeiten zur Python-String-Formatierung.

## 1. Erstelle die Klasse mit einer großgeschriebenen Kopfzeile

Die Funktion `capitalize_header` soll einen Veranstaltungsnamen entgegennehmen und die Version des Veranstaltungsnamens mit großem Anfangsbuchstaben zurückgeben.

```python
>>> capitalize_header("fan meetup")
"Fan meetup"
```

## 2. Formatiere das Datum

Erstelle eine neue Methode `format_date`, die eine Liste entgegennimmt, die ein Datum, einen Monat und ein Jahr enthält. Sie zeigt das formatierte Datum im Format `<month_name> <date>, <year>` an.

```python
>>> convert_date([9, 4, 2020])
>>> leaflet.date
"April 9, 2020"
>>> leaflet.set_date([13, 5, 2030])
>>> leaflet.date
"May 13, 2030"
```

## 3. Stelle die Unicode-Codepunkte als Icons dar

Wenn die Methode `display_icons` aufgerufen wird, soll die übergebene Liste von Unicode-Codepunkten als `list` von _Icons_ dargestellt und zurückgegeben werden.

```python
>>> leaflet.display_icons(['\U00000040', '\U0001D70B'])
['@', '𝜋']
```

## 4. Zeige den fertigen Flyer an

Jetzt verwendest du alle Funktionen von oben und kombinierst sie in der Funktion `print_leaflet`.
Sie soll einen `event_name`, eine Liste von `icons`, eine Liste von `authors` und eine Liste `event_date` entgegennehmen.

Der Flyer soll sich an das folgende Layout halten.

Der Flyer folgt einem bestimmten Layout in Form eines Rechtecks:

- Die erste und die letzte Zeile enthalten 20 Sternchen. `"*"`
- Jeder Abschnitt wird durch eine leere Zeile darüber und darunter abgetrennt.
- Eine leere Zeile enthält nur ein Sternchen am Anfang und eines am Ende.
- Der erste Abschnitt ist die Kopfzeile des Flyers, dieser Titel wird großgeschrieben.
- Der zweite Abschnitt ist das optionale Datum. Wird kein Datum übergeben, soll dieser Abschnitt eine leere Zeile sein.
- Der dritte und letzte Abschnitt ist die Liste der Künstler, wobei jeder Künstler mit dem entsprechenden Icon verknüpft ist.

```python
********************
*                  *
*    'Concert'     *
*                  *
*  June 22, 2020   *
*                  *
* John         🎸  *
* Benjamin     🎤  *
* Max          🎹  *
*                  *
********************
```
