# Platzhalter

## So löst du diese Übung mit bash

`bash` hat von Haus aus keine Möglichkeit, Strings mit Datum und Uhrzeit zu **parsen**.
Für diese Übung musst du ein externes Programm aufrufen.

* Mit der Option `-d` des GNU-Befehls `date` kannst du [eine Vielzahl von Formaten][gnu-date] parsen.
* Wenn du einen Mac benutzt, schau dir den [BSD-Befehl `date`][bsd-date] und seine Option `-f` an.
* Perl ist weit verbreitet, und mit seinem [`Time::Piece`-Modul][time-piece] kannst du Zeitstempel parsen.

Datumswerte kann bash auch ganz ohne externe Tools **formatieren**.
Wenn dir ein Zeitwert als Ganzzahl vorliegt (Sekunden seit der Epoche), kannst du mit [dem Formatierungsspezifizierer `%()T` von `printf`][bash-printf] eine Formatierung im Stil von „strftime“ anwenden.

```bash
epoch=1234567890

printf '%(%Y-%m-%d %H:%M:%S)T\n' "$epoch"
# ==> 2009-02-13 18:31:30

# bash uses the `TZ` environment variable for the timezone.

TZ=Asia/Kolkata printf '%(%Y-%m-%d %H:%M:%S)T\n' "$epoch"
# ==> 2009-02-14 05:01:30
```

[bsd-date]: https://manpage.me/index.cgi?apropos=0&q=date&sektion=0&manpath=FreeBSD+12-CURRENT+and+Ports&arch=default&format=html
