# Überblick

## Mehrere Rückgabewerte

In Swift können Funktionen [mehrere Werte zurückgeben][multiple-return-values], indem sie ein Tupel zurückgeben:

```swift
func reverseAndLength(_ str: String) -> (reverse: String, length: Int) {
    return (reverse: String(str.reversed()), length: str.count)
}

let result = reverseAndLength("Hello")
print(result.reverse) // Prints "olleH"
print(result.length)  // Prints 5
```

## Das `return`-Schlüsselwort weglassen

Wenn der Körper einer Funktion aus einem einzigen Ausdruck besteht, kannst du [das `return`-Schlüsselwort weglassen][implicit-returns]:

```swift
func reverseAndLength(_ str: String) -> (reverse: String, length: Int) {
    (reverse: String(str.reversed()), length: str.count)
}
```

Diese Syntax der impliziten Rückgabe gilt für alle Funktionen, die einen Wert zurückgeben, nicht nur für solche, die Tupel zurückgeben.
