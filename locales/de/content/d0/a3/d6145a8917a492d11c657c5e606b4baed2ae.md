# SQLite-spezifische Anweisungen

In dieser Übung musst du die Spalte `result` der Tabelle `etl` auf den korrekten Wert setzen, und zwar auf Basis des JSON-Objekts, das in der Spalte `input` steht. Die Schlüssel im Ergebnisobjekt müssen alphabetisch sortiert sein.

## Tabellenschema

```sql
CREATE TABLE "etl" ("input" TEXT, "result" TEXT);
```
