# Match-Ausdrücke

Ein Match-Ausdruck wertet einen Wert und eine Bedingung aus, um einen auszuwertenden Ausdruck zurückzugeben. Ähnlich wie bei einem ternären Operator wird der Rückgabeausdruck nicht ausgewertet, wenn die Bedingung nicht übereinstimmt. Um eine Bedingung abzugleichen, wird eine Identitätsprüfung [strikte Gleichheit oder `===`] durchgeführt.

```php
<?php
$some_value = 42;

$return_value = match($some_value) {
    0 => 'number is 0',
    1 => 'number is 1',
    default => 'number is something else'
}
```

Um eine Gleichheitsprüfung [`==`] durchzuführen, kannst du die Bedingung umstellen:

```php
<?php
$some_value = 42;

$return_value = match(true) {
    $some_value < 100 => 'number is less than 100',
    $some_value > 100 => 'number is greater than 100',
    $some_value == 100 => 'number is 100',
}
```

Wenn in einem Match-Ausdruck keine Bedingung übereinstimmt, wird ein `UnhandledMatchError` geworfen.
