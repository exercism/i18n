# Einführung

## Vergleichsoperatoren

R hat eine Reihe von Operatoren, die es auch in vielen anderen Sprachen gibt:

```R
1 == 2 # FALSE
1 != 2 # TRUE
1 < 2 # TRUE
1 > 2 # FALSE
1 <= 2 # TRUE
1 >= 2 # FALSE
```

## Verzweigung

Die Grundform einer if-else-Anweisung sieht so aus:

```R
if (x > 10) {
    y <- "big"
} else if (x > 2) {
    y <- "medium"
} else {
    y <- "tiny"
}
```

In diesem Fall sind sowohl die runden Klammern `()` um den booleschen Wert als auch die geschweiften Klammern `{}` um die Anweisung erforderlich.
Eine einfache `if`-Anweisung lässt sich verkürzen:

```R
if (x == 0) return("success")
```
