# Ergänzung zur Anleitung

## Implementierung

Um diese Übung abzuschließen, musst du den Datentyp `Clock` definieren, eine `BEq`- und eine `ToString`-Instanz hinzufügen und die folgenden Funktionen implementieren:

* `create`: nimmt zwei Ganzzahlen entgegen, die auch negativ sein können und für Stunden bzw. Minuten stehen, und erzeugt eine gültige Clock.
* `add`: nimmt eine Clock und eine Anzahl Minuten entgegen, die zur Zeit der Clock addiert werden, und erzeugt eine neue Clock.
* `subtract`: nimmt eine Clock und eine Anzahl Minuten entgegen, die von der Zeit der Clock subtrahiert werden, und erzeugt eine neue Clock.

Beachte, dass der Typ Clock eine 24-Stunden-Uhr darstellt, die von „00:00“ bis „23:59“ läuft.

~~~~exercism/advanced
Beachte, dass sowohl die Stunden als auch die Minuten in einer `Clock` beschränkt sind:

- `0 <= hour < 24`
- `0 <= minute < 60`

In Lean ist es idiomatisch, solche Einschränkungen auf Typebene darzustellen, sodass ungültige Werte _nicht darstellbar_ sind.
Das erfordert allerdings auch den _Beweis_, dass ein gegebener Wert diese Einschränkungen erfüllt.
