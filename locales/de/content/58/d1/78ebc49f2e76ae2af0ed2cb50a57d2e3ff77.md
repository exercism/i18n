# Einleitung

Ein *Disjoint-Set* (eine Union-Find-Struktur) hält eine Sammlung von Werten, die in sich nicht überschneidende Gruppen aufgeteilt ist, und beantwortet schnell eine Frage: Sind diese beiden Werte in derselben Gruppe? Es gehört zum Vokabular [`disjoint-sets`][disjoint-sets].

## Ein Disjoint-Set aufbauen

`<disjoint-set>` erzeugt eine leere Struktur. Werte, also *Atome*, werden mit `add-atom` einzeln hinzugefügt oder mit `add-atoms` aus einer Sequenz. Jedes Atom startet in einer Gruppe für sich.

```
<disjoint-set> ( -- disjoint-set )
add-atom       ( atom disjoint-set -- )
add-atoms      ( seq disjoint-set -- )
```

```factor
USING: disjoint-sets ;

<disjoint-set>
{ 1 2 3 } over add-atoms   ! 1, 2 and 3 each in their own group
```

Das Disjoint-Set ist *veränderbar*: `add-atom`, `add-atoms` und `equate` ändern es an Ort und Stelle, statt ein neues zurückzugeben. `keep` ist praktisch, wenn du das Disjoint-Set wieder auf dem Stack haben willst, nachdem eines dieser Wörter es verbraucht hat.

## Gruppen zusammenführen

`equate` vereinigt die beiden Gruppen, die seine Atome enthalten. Das Vereinigen ist transitiv: Vereinige zwei Atome, dann eines davon mit einem dritten, und alle drei landen in einer Gruppe.

```
equate ( atom1 atom2 disjoint-set -- )
```

## Repräsentanten

Jede Gruppe hat ein kanonisches Mitglied, ihren *Repräsentanten*. `representative` gibt ihn zurück, und zwei Atome gehören genau dann zur selben Gruppe, wenn ihre Repräsentanten gleich sind.

```
representative ( atom disjoint-set -- representative )
```

```factor
USING: disjoint-sets ;

<disjoint-set>
{ 1 2 3 } over add-atoms
1 2 pick equate
1 over representative .   ! => 1
2 over representative .   ! => 1   (same representative as 1)
3 over representative .   ! => 3   (still on its own)
```

Welches Atom eine Gruppe als ihren Repräsentanten wählt, ist ein internes Detail. Verlass dich nie darauf, dass ein bestimmtes Atom gewählt wird, sondern nur darauf, dass sich zwei Atome in derselben Gruppe einig sind.
