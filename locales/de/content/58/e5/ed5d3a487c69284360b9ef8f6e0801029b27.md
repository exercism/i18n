**Hinweis:** Du kannst für Text im Fließtext auch normale Links verwenden, denen dann die Tooltips hinzugefügt werden. Weitere Details findest du in [der Dokumentation zum internen Verlinken](/docs/building/markdown/internal-linking).

## Verwendung

Widgets kannst du überall verwenden, wo Markdown erlaubt ist, zum Beispiel in der Dokumentation, in Approaches und in Diskussionen zwischen Lernenden und Mentor:innen.

Sie werden mit dem folgenden Format gerendert:

```md
[<type>:<id>]()
```

Die Teile `<type>` und `<id>` sind variabel und hängen vom jeweiligen Widget ab.

Die Link-Referenz, also der Inhalt von `()`, wird von der Website ignoriert. Du kannst dort zu Wartungszwecken angeben, was du möchtest.

## Übungs-Widget

Link-Format: `[exercise:<track-slug>/<exercise-slug>]()`

### Beispiel

```markdown
Great job on solving this exercise! Some other exercises that you might also like to try:

- [exercise:fsharp/anagram]()
- [exercise:fsharp/isogram]()
```

## Konzept-Widget

Link-Format: `[concept:<track-slug>/<concept-slug>]()`

### Beispiel

```markdown
There are three primary conditional statements that are used in Julia:

- [concept:julia/if-statements]()
- [concept:julia/ternary-operator]()
- [concept:julia/short-circuiting]()
```

## Approach-Widget

Link-Format: `[approach:<track-slug>/<exercise-slug>/<approach-slug>]()`

### Beispiel

```markdown
Here are some approaches you might want to checkout!

- [approach:csharp/two-fer/method-overloading]()
- [approach:csharp/two-fer/optional-parameter]()
```

## Artikel-Widget

Link-Format: `[article:<track-slug>/<exercise-slug>/<article-slug>]()`

### Beispiel

```markdown
We have an article you might be interested in:

- [article:csharp/reverse-string/performance]()
```
