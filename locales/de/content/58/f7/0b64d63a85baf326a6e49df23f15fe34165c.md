# Typumwandlung

Cairo unterstützt die Typumwandlung durch die Traits `Into` und `TryInto` aus der Core-Bibliothek, die häufig für eingebaute und benutzerdefinierte Typen verwendet werden.  

Diese Traits definieren Methoden, um Werte zwischen Typen umzuwandeln:  

- **`Into`**: Wird für garantierte, unfehlbare Umwandlungen verwendet.  
- **`TryInto`**: Wird für fehlbare Umwandlungen verwendet, die `Option<T>` zurückgeben.

## `Into` verwenden

`Into` behandelt Umwandlungen, bei denen der Zieltyp den Quellwert immer aufnehmen kann.

```rust
fn main() {
    let my_u8: u8 = 10;
    let my_felt252: felt252 = my_u8.into(); // Infallible conversion
    let my_u256: u256 = my_felt252.into(); // Conversion to larger types
}
```

## `TryInto` verwenden

`TryInto` ist für Fälle gedacht, in denen die Umwandlung fehlschlagen kann; es gibt `Option<T>` zurück.

```rust
fn main() {
    let my_u256: u256 = 10;
    let my_felt252: felt252 = my_u256.try_into().unwrap(); // Success
    let my_large_u16: u16 = 2048;
    let my_large_u8: u8 = my_large_u16.try_into().unwrap(); // Panics because value doesn't fit in `u8`
}
```

## Benutzerdefinierte Typumwandlung

Du kannst diese Traits für deine eigenen Typen implementieren.  

### Beispiel: `Into`

```rust
#[derive(Drop)]
struct Rectangle {
    width: u64,
    height: u64,
}

#[derive(Drop)]
struct Square {
    side_length: u64,
}

impl SquareIntoRectangle of Into<Square, Rectangle> {
    fn into(self: Square) -> Rectangle {
        Rectangle { width: self.side_length, height: self.side_length }
    }
}
```

### Beispiel: `TryInto`

```rust
impl RectangleIntoSquare of TryInto<Rectangle, Square> {
    fn try_into(self: Rectangle) -> Option<Square> {
        if self.height == self.width {
            Option::Some(Square { side_length: self.height })
        } else {
            Option::None
        }
    }
}
```

Dieses Setup ermöglicht flexible und typsichere Umwandlungen für eingebaute und benutzerdefinierte Typen in Cairo.
