# Unerwarteter erforderlicher Parameter

Der Parameter `${'parameter.name'}` wird in den Tests sowohl mit als auch ohne Wert aufgerufen, ist aber _nicht als optional gekennzeichnet_, was bedeutet, dass die Tests fehlschlagen werden. Ein TypeScript-Parameter kann explizit als optional gekennzeichnet werden, indem du ein `?` anhängst:

```typescript
function(${'parameter.name'}?: ${'parameter.type'}) {
  //
}
```

Oder alternativ, indem du einen Standardwert zuweist:

```typescript
function(${'parameter.name'}: ${'parameter.type'} = <default>) {
  //
}
```
