# Über

[Guards][guards] werden als Ergänzung zum [Pattern Matching][exercism-pattern-matching] eingesetzt. Das behandeln wir in einem späteren Konzept. Mit Guards können wir eine Funktion abhängig vom Eingabewert unterschiedlich umsetzen. Sie ermöglichen komplexere Prüfungen.

Eine Guard-Anweisung besteht aus einer Pipe `|`, gefolgt von einem booleschen Ausdruck, und schließt mit einem Gleichheitszeichen `=` und dem Funktionskörper ab. Für eine einzelne Funktion kann es mehrere Guard-Anweisungen geben. Die Guard-Anweisungen werden von oben nach unten ausgewertet, und die erste, die zu `True` ausgewertet wird, wird ausgeführt. Eine Guard-Anweisung kann eine `otherwise`-Anweisung enthalten, die alle Werte abfängt, die nicht zu den vorherigen Guard-Anweisungen passen.

```haskell
isEven :: Int -> String
isEven n
    | even n = "n is even"
    | otherwise = "n is odd"
```

Wir können unsere Funktion auch selbst definieren und sie dann innerhalb der Guard-Anweisung verwenden.

```haskell
isEven' :: Int -> Bool
isEven' n = even n

isEven :: Int -> String
isEven n
    | isEven' n = "n is even"
    | otherwise = "n is odd"
```
