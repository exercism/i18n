# String

Der Datentyp `String` ist eine lineare Folge von Zeichen, die als UTF-8 kodiert sind. Er eignet sich zum Speichern von Textdaten.

## Einen String erstellen

Ein String kann mit den assoziierten Funktionen `String::new()` oder `String::from()` erstellt werden. Viele Typen haben eine `to_string`-Methode, um einen String zu erzeugen, zum Beispiel aus einer Zahl.

```rust
let my_string = String::from("The answer is");
let answer = 42.to_string();
println!("{my_string} {answer}");
```

### Das `format!`-Makro

Weil es ein häufiger Vorgang ist, aus einer Auswahl kleinerer Datentypen einen großen String zu erzeugen, hat Rust eine Kurzschreibweise, die die Details des Aufrufs von `to_string` einspart: das Makro `format!`. Den Aufbau des zusammengesetzten Strings von oben könnten wir zum Beispiel so vereinfachen:

```rust
let the_answer = format!("{} {}.", "The answer is", 42);
assert_eq!("The answer is 42.", the_answer);
```

## String Slices

Strings haben eine enge Beziehung zu String Slices. String Slices sind unveränderliche Referenzen auf einen Speicherbereich bekannter Größe, der eine lineare Folge von als UTF-8 kodierten Zeichen enthält. Jeder String kann in ein String Slice umgewandelt werden, indem du ihn mit dem Dereferenzierungsoperator (`&`) ausleihst. Um ein String Slice in einen String umzuwandeln, eignen sich sowohl die Methode `to_string()` als auch `String::from`.

Im Rust-Code steht ein String-Literal in doppelten Anführungszeichen. Diese String-Literale sind immer String Slices, weil sie auf einen unveränderlichen Speicherbereich in der ausführbaren Programmdatei verweisen.

```rust
let string = String::from("string");
let slice = "string";
assert_eq!(slice, &string);
```

## Einen String verändern

Um ein einzelnes Zeichen an einen String anzuhängen, verwendest du die Methode `push`. Um ein String Slice an einen String anzuhängen, verwendest du die Methode `push_str` oder den Operator `+`.

```rust
fn main() {
    // For demonstration purposes, we're not using `format!`
    let s1 = String::from("tic");
    let s2 = String::from("tac");
    let s3 = String::from("toe");

    let s = s1 + "-" + &s2 + "-" + &s3;
    println!("{s}");
}
```

## Auf Zeichen in einem String zugreifen

Da Rust-Strings UTF-8-kodiert sind, haben die einzelnen Zeichen nicht alle die gleiche Größe. Deshalb bietet der Datentyp `String` keinen Indexoperator (`[]`). Um auf alle Zeichen oder ein bestimmtes Zeichen in einem String zuzugreifen, kannst du die Methode `chars()` verwenden. Sie durchläuft die Zeichen des Strings der Reihe nach.

```rust
let alphabet: String = ('a'..='z').collect();
for c in alphabet.chars() {
    println!("{c}");
}
let j = alphabet.chars().nth(9);
println!("{j:?}"); // prints Some('j')
```
