# Hinweise

## Allgemein

- Nutze den eingebauten [(verketteten) Listentyp][list].

## 1. Definiere eine Funktion, die eine leere Sprachliste zurückgibt

- Die Funktion muss `[]` zurückgeben.

## 2. Definiere eine Funktion, die eine Sprache zur Liste hinzufügt

- Ein Element kann mit `|` an den Anfang einer Liste gestellt werden.

## 3. Definiere eine Funktion, die eine Sprache aus der Liste entfernt

- Elixir [bietet eine Funktion][tl], die eine Liste ohne das erste Element zurückgibt.

## 4. Definiere eine Funktion, die das erste Element der Liste zurückgibt

- Elixir [bietet eine Funktion][hd], um das erste Element einer Liste zu erhalten.

## 5. Definiere eine Funktion, die zurückgibt, wie viele Sprachen in der Liste sind

- Elixir [bietet eine Funktion][length], um die Länge einer Liste zu zählen.

## 6. Definiere eine Funktion, die feststellt, ob die Liste eine funktionale Sprache enthält

- Deine Funktion sollte einen booleschen Wert zurückgeben, der angibt, ob `"Elixir"` ein Element der Liste ist. Elixir [bietet eine Funktion][in], um die Zugehörigkeit zu einer Liste zu prüfen.
