# Einführung

Externe Typen kannst du verwenden, um auf Datentypen zu verweisen, die in anderen Sprachen wie Erlang oder JavaScript definiert sind.

Um eine externe Funktion zu definieren, deklarierst du einen Typ, gibst aber keine Konstruktoren an. Dieser Typ lässt sich dann genauso verwenden wie jeder andere Typ.

```gleam
pub type OrderedDictionary(element)
```
