# Einführung

## Zufall

Mit einer Instanz der Klasse `java.util.Random` kannst du in Java Zufallszahlen erzeugen.

### Zufällige Ganzzahlen

Eine zufällige Ganzzahl kannst du mit der Methode `nextInt()` erzeugen.
Das erzeugt einen Wert im Bereich von `Integer.MIN_VALUE` bis `Integer.MAX_VALUE`.

```java
Random random = new Random();

random.nextInt();
// => -1169335537
```

Um den Bereich der erzeugten Werte einzuschränken, verwende `nextInt(int)`.
Das erzeugt einen Wert im Bereich von `0` (einschließlich) bis zur angegebenen Obergrenze (ausschließlich).

Zum Beispiel erzeugt dies eine Zufallszahl von `0` bis `9`.

```java
Random random = new Random();

random.nextInt(10);
// => 6
```

Und dies erzeugt eine Zufallszahl von `10` bis `19`.

```java
Random random = new Random();

10 + random.nextInt(10);
// => 11
```

### Zufällige Gleitkommazahlen

Eine zufällige Gleitkommazahl kannst du mit der Methode `nextDouble()` erzeugen.
Das erzeugt einen Wert im Bereich von `0.0` bis `1.0`.

```java
Random random = new Random();

random.nextDouble();
// => 0.19250004204021398
```

Und dies erzeugt eine Zufallszahl von `100.0` bis `200.0`.

```java
Random random = new Random();

100.0 + 100.0 * random.nextDouble();
// => 111.31849856260328
```
