# Anleitung

In dieser Übung implementierst du eine Teilmenge von Hilfsroutinen, mit denen ein Entwickler Bezeichnernamen bereinigen kann.
In den 5 Aufgaben baust du nach und nach die Routine `Clean` auf.
Ein gültiger Bezeichner besteht aus null oder mehr Buchstaben und Unterstrichen.
In allen Fällen ist garantiert, dass der eingegebene String nicht null ist.
Wenn ein leerer String an die Funktion `Clean` übergeben wird, sollte ein leerer String zurückgegeben werden.
Beachte, dass der Aufrufer die Routine `Clean` nicht mit einem leeren Bezeichner aufrufen sollte, da solche Bezeichner wirkungslos sind.

## 1. Ersetze alle vorkommenden Leerzeichen durch Unterstriche

Implementiere die (_statische_) Methode `Identifier.Clean()`, um alle Leerzeichen durch Unterstriche zu ersetzen.
Das gilt auch für führende und nachfolgende Leerzeichen.

```csharp
Identifier.Clean("my   Id");
// => "my___Id"
```

## 2. Ersetze Steuerzeichen durch den Großbuchstaben-String „CTRL“

Ändere die (_statische_) Methode `Identifier.Clean()` so, dass sie Steuerzeichen durch den Großbuchstaben-String `"CTRL"` ersetzt.

```csharp
Identifier.Clean("my\0Id");
// => "myCTRLId",
```

## 3. Wandle kebab-case in camelCase um

Ändere die (_statische_) Methode `Identifier.Clean()` so, dass sie kebab-case in camelCase umwandelt.

```csharp
Identifier.Clean("à-ḃç");
// => "àḂç"
```

## 4. Lass Zeichen weg, die keine Buchstaben sind

Ändere die (_statische_) Methode `Identifier.Clean()` so, dass sie alle Zeichen weglässt, die keine Buchstaben sind.

```csharp
Identifier.Clean("1😀2😀3😀");
// => ""
```

## 5. Lass griechische Kleinbuchstaben weg

Ändere die (_statische_) Methode `Identifier.Clean()` so, dass sie alle griechischen Buchstaben im Bereich 'α' bis 'ω' weglässt.

```csharp
Identifier.Clean("MyΟβιεγτFinder");
// => "MyΟFinder"
```
