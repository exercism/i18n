# Einführung

## With

Die [Spezialform with][with] bietet eine Möglichkeit, sich auf den „Happy Path“ einer Reihe von möglicherweise fehlschlagenden Schritten zu konzentrieren und die Fehler erst später zu behandeln.

```elixir
with {:ok, id} <- get_id(username),
     {:ok, avatar} <- fetch_avatar(id),
     {:ok, image_type} <- check_valid_image_type(avatar) do
  {:ok, image_type, avatar}
else
  :not_found ->
    {:error, "invalid username"}

  {:error, "not an image"} ->
    {:error, "avatar associated to #{username} is not an image"}

  err ->
    err
end
```

Bei jedem Schritt läuft die Kette weiter, wenn eine Klausel übereinstimmt, bis der `do`-Block ausgeführt wird. Stimmt eine Klausel nicht überein, stoppt die Kette und diese Klausel wird zurückgegeben. Du kannst außerdem einen `else`-Block verwenden, um fehlgeschlagene Übereinstimmungen abzufangen und den Rückgabewert zu ändern.

[with]: https://hexdocs.pm/elixir/Kernel.SpecialForms.html#with/1
