# Anweisungen

In dieser Übung spielst du mit einem Freund ein Zahlenratespiel. Die Regeln sind einfach: Du wählst heimlich eine Zahl zwischen `1` und `100`, und dein Freund versucht zu erraten, welche Zahl du gewählt hast. Um deinem Freund zu helfen, antwortest du unterschiedlich, je nachdem, wie nah der Tipp an der Zahl liegt, die du gewählt hast (`42`). Für die verschiedenen Antworten gelten diese Regeln:

- Wenn der Tipp `42` ist: "Correct"
- Wenn der Tipp `41` oder `43` ist: "So close"
- Wenn der Tipp kleiner als `41` ist: "Too low"
- Wenn der Tipp größer als `43` ist: "Too high"

Du hast vier Aufgaben, um die Antworten auf die Tipps zu programmieren.

## 1. Auf einen richtigen Tipp antworten

Implementiere die Funktion `reply`, um auf einen richtigen Tipp zu antworten:

```fsharp
reply 42
// => "Correct"
```

## 2. Auf einen fast richtigen Tipp antworten

Ändere die Funktion `reply`, um auf fast richtige Tipps zu antworten:

```fsharp
reply 41
// => "So close"
```

## 3. Auf zu niedrige Tipps antworten

Ändere die Funktion `reply`, um auf zu niedrige Tipps zu antworten:

```fsharp
reply 25
// => "Too low"
```

## 4. Auf zu hohe Tipps antworten

Ändere die Funktion `reply`, um auf zu hohe Tipps zu antworten:

```fsharp
reply 88
// => "Too high"
```
