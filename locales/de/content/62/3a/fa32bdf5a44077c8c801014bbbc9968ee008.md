# Hinweise

## 1. Die Bits nach rechts verschieben

- Es gibt zwei Operatoren für die Verschiebung nach rechts, aber nur einer fügt immer eine 0 ein.

## 2. Einige Bits setzen

- Einer der bitweisen Operatoren setzt ein Bit immer auf 1, wo die Bits in beiden Werten 1 sind.

## 3. Bestimmte Bits umdrehen

- Es gibt eine Bitoperation, die ein Bit umdreht, wo die Maske 1 ist.

## 4. Bestimmte Bits löschen

- Eine der Bitoperationen löscht Bits, wo das Bit in der Maske 0 ist.
- Aber du musst sie möglicherweise mit einem anderen Operator kombinieren, um Bits zu löschen, wo die Maske 1 ist.
