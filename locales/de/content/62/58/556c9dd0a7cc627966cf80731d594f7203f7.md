# Anleitung

In dieser Übung schreibst du Code, um Namensschilder zu erstellen, die Fabrikmitarbeiter tragen. Mitarbeiter haben eine ID, einen Namen und einen Abteilungsnamen. Die Beschriftung der Mitarbeiterschilder ist wie folgt formatiert: `"[id] - name - DEPARTMENT"`.

## 1. Erstelle ein Schild für einen Mitarbeiter

Implementiere die Funktion `print_name_badge`. Sie soll eine ID, einen Namen und eine Abteilung entgegennehmen. Sie soll die Beschriftung des Schilds zurückgeben, wobei der Abteilungsname in Großbuchstaben steht.

```julia-repl
julia> print_name_badge(67, "Katherine Williams", "Strategic Communication")
"[67] - Katherine Williams - STRATEGIC COMMUNICATION"
```

## 2. Erstelle ein Schild für einen neuen Mitarbeiter

Aufgrund einer Eigenheit im Computersystem haben neue Mitarbeiter manchmal noch keine ID, wenn sie anfangen, in der Fabrik zu arbeiten. Da Schilder Pflicht sind, erhalten sie ein vorläufiges Schild ohne das ID-Präfix.

Erweitere die Funktion `print_name_badge`. Wenn die ID fehlt, soll sie ein Schild ohne sie erstellen.

```julia-repl
julia> print_name_badge(missing, "Robert Johnson", "Procurement")
"Robert Johnson - PROCUREMENT"
```

## 3. Erstelle ein Schild für den Besitzer

Selbst der Besitzer der Fabrik muss jederzeit ein Schild tragen. Ein Besitzer hat jedoch keine Abteilung und wird auch nie eine haben: Er steht über allen Abteilungen. In diesem Fall soll die Beschriftung `"OWNER"` anstelle des Abteilungsnamens zurückgeben.

Erweitere die Funktion `print_name_badge`. Wenn die Abteilung `nothing` ist, gehe davon aus, dass das Schild dem Firmenbesitzer gehört.

```julia-repl
julia> print_name_badge(204, "Rachel Miller", nothing)
"[204] - Rachel Miller - OWNER"
```

Beachte, dass es möglich ist, dass der Besitzer auch ein neuer Mitarbeiter ist.

```julia-repl
julia> print_name_badge(missing, "Rachel Miller", nothing)
"Rachel Miller - OWNER"
```

## 4. Berechne das Gesamtgehalt der Mitarbeiter ohne ID

Als grobe Kennzahl dafür, wie gut die IDs ausgegeben werden, möchtest du das Gesamtgehalt der Mitarbeiter ohne ID sehen. Ein hoher Wert bedeutet, dass viele warten oder dass das Problem auch Mitarbeiter in höheren Positionen betrifft: beides schlecht.

Implementiere die Funktion `salaries_no_id`, die einen Vektor von IDs und einen entsprechenden Vektor von Gehältern entgegennimmt und die Summe der Gehälter für Personen zurückgibt, die noch keine ID haben. Beide Vektoren haben die gleiche Länge.

```julia-repl
julia> ids = [204, missing, 210, 352, missing, 263]
julia> salaries = [23, 21, 47, 35, 17, 101] * 1000
julia> salaries_no_id(ids, salaries)
38,000
```
