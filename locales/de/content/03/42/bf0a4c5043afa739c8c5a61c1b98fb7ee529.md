# Anleitung

Die klassische Einführungsübung. Sag einfach „Hello, World!“.

[„Hello, World!“](http://en.wikipedia.org/wiki/%22Hello,_world!%22_program) ist
das traditionelle erste Programm, wenn du in einer neuen Sprache
oder Umgebung mit dem Programmieren beginnst.

Die Ziele sind einfach:

- Ändere den vorgegebenen Code so, dass er den String „Hello, World!“ erzeugt.
- Führe die Testsuite aus und stell sicher, dass sie erfolgreich durchläuft.
- Reiche deine Lösung ein und überprüfe sie auf der Website.

Wenn alles gut läuft, bist du bereit, deine erste echte Übung abzurufen.
