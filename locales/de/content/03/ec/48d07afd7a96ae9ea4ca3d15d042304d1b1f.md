# Normalisierungen des Representers

Der [F#-Representer][representer] wendet die folgenden Normalisierungen an:

## Kommentare entfernen

Alle Kommentare werden entfernt.

### Vorher

```fsharp
module Fake

(* Block comment
   on multiple lines *)

let message = "Hi" (* Block comment after code *)

// Double-slash comment on single line
let reply = "Yo" // Double-slash comment after code

/// <summary>This function adds two numbers</summary>
/// <param name="x">The first number</param>
/// <param name="y">The second number</param>
/// <returns>The first number added to the second number</param>
let add x y = x + y
```

### Nachher

```fsharp
module Fake

let message = "Hi"

let reply = "Yo"

let add x y = x + y
```

## Import-Deklarationen entfernen

Alle Import-Deklarationen werden entfernt.

### Vorher

```fsharp
module Fake

open System
open System.IO

let message = "Hi"
```

### Nachher

```fsharp
module Fake

let message = "Hi"
```

## Code formatieren

Der Code wird mit der [Bibliothek fantomas][fantomas] formatiert.
Sie formatiert den Code nach dem F#-Style-Guide.
Die vollständige Liste der Transformationen, die fantomas anwendet, findest du [hier][fantomas-formatting].

### Vorher

```fsharp
module Fake

let  add ( birthDate  :  DateTime)  =
    birthDate.Add (    2.0)

type Volume =
| Liter of float
| USPint of float
| ImperialPint of float
```

### Nachher

```fsharp
module Fake

let add (birthDate: DateTime) =
    birthDate.Add(2.0)

type Volume =
    | Liter of float
    | USPint of float
    | ImperialPint of float
```

## Bezeichner normalisieren

Bezeichner werden zu einem Platzhalterwert normalisiert.

### Vorher

```fsharp
module Fake

let foo x = x + 1
```

### Nachher

```fsharp
module PLACEHOLDER_1

let PLACEHOLDER_3 PLACEHOLDER_2 = PLACEHOLDER_2 + 1
```
