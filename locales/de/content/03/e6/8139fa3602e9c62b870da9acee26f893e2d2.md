# Hinweise

Die ersten drei Aufgaben rufen alle dieselbe Funktion `print_name_badge()` auf. Du kannst die Implementierung schrittweise aufbauen und dabei nach und nach die Logik für die Aufgaben 2 und 3 ergänzen.

## 1. Erstelle ein Namensschild für einen Mitarbeiter

- Das ist der Standardfall: Setze einfach die 3 Argumente zu einem passenden String zusammen.
- [String-Interpolation][interpolation] ist wahrscheinlich der einfachste Weg.

## 2. Erstelle ein Namensschild für einen neuen Mitarbeiter

- Jetzt ist die ID `missing,`, das Format des Ziel-Strings ist also ein anderes.
- [`ismissing()][ismissing] ist hier nützlich.
- Julia hat einen [ternären Operator][ternary] mit knapper Syntax.

## 3. Erstelle ein Namensschild für den Inhaber

- Jetzt ist die Abteilung `nothing`.
- Es gibt eine [`isnothing()`][isnothing]-Funktion.

## 4. Berechne das Gesamtgehalt der Mitarbeiter ohne ID

- Fehlen [irgendwelche][any] IDs? Wenn nicht, ist der Rückgabewert null.
- Um Einträge mit fehlender ID herauszuziehen, kann es helfen, zuerst die Vektoren `ids` und `salaries` zu [zippen][zip].
- Es gibt mehrere Möglichkeiten, über den resultierenden Vektor von Tupeln zu iterieren, ohne eine explizite Schleife zu schreiben.
  - Auf Python-Art: mit einer Vektor-[Comprehension][comprehension].
  - Funktional: mit [`map()`][map] und einer [anonymen Funktion][anonymous].
  - Vektoriell: mit [Broadcasting][broadcasting] einer [anonymen Funktion][anonymous].
- Am Ende steht eine [`sum()`][sum] über einen geänderten salaries-Vektor.
   - Die Gehälter von Mitarbeitern mit ID können entweder weggelassen oder auf null gesetzt werden.
