# Einführung

Tupel sind eine leichtgewichtige Möglichkeit, eine feste Anzahl beliebiger Datentypen zusammenzufassen.
Ein Tupel kann eine beliebige Anzahl von Elementen haben.
Du kannst auf die Elemente zugreifen, indem du sie destrukturierst.

```rust
fn main() {
    let tup: (u32, u64, bool) = (10, 20, true);
}

fn main() {
    let (x, y, z) = (500, 6, true);

    if y == 6 {
        println!("y is 6!");
    }
}
