# Über

Lean ist eine universelle, abhängig typisierte, strikte, rein funktionale Programmiersprache mit integriertem Beweisassistenten.
Mit ihr schreibst du Programme zusammen mit maschinell geprüften Korrektheitsgarantien, und sie wird breit in der formalen Verifikation von Software und Mathematik eingesetzt.

**Abhängig typisiert** bedeutet, dass Typen von Werten abhängen können.
So lassen sich Spezifikationen und Einschränkungen direkt im Typsystem abbilden, wodurch ungültige Zustände praktisch _nicht darstellbar_ werden.

Lean beruht auf dem Prinzip der Propositionen als Typen, bei dem logische Propositionen als Typen dargestellt werden und Beweise Programme sind, die diese Typen bewohnen.
Jeder Wert eines Typs, der eine Spezifikation kodiert, muss auf eine Weise konstruiert werden, die _beweist_, dass er gültig ist.

**Strikte Auswertung** bedeutet, dass Funktionsargumente sofort ausgewertet werden, was eine deterministische Auswertungsreihenfolge ergibt.
Das vereinfacht das Nachdenken über das Verhalten und die Performance von Programmen.
Lean unterstützt Lazy Evaluation, aber nur explizit.

**Rein funktional** bedeutet, dass Funktionen keinen Zustand verändern und keine versteckten Seiteneffekte haben.
Eine reine Funktion gibt für dieselbe Eingabe immer denselben Wert zurück, Effekte müssen explizit gemacht und kontrolliert werden.

Lean wird im Voraus zu nativem Code kompiliert.
Ihr Laufzeitsystem bietet Garbage Collection ohne Tracing und effiziente In-Place-Aktualisierungen für nicht geteilte Daten.
