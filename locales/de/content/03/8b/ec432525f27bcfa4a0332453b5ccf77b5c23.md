# Einführung

In Go sind Funktionen erstklassige Werte.
Das bedeutet, dass du mit Funktionen dieselben Dinge tun kannst wie mit allen anderen Werten: Du kannst Funktionen Variablen zuweisen, sie als Argumente an andere Funktionen übergeben oder sogar Funktionen aus anderen Funktionen zurückgeben.

Im Folgenden erstellen wir zwei Funktionen, `engGreeting` und `espGreeting`, und weisen sie der Variable `greeting` zu:

```go
import "fmt"

func engGreeting(name string) string {
	return fmt.Sprintf("Hello %s, nice to meet you!", name)
}

func espGreeting(name string) string {
	return fmt.Sprintf("¡Hola %s, mucho gusto!", name)
}

greeting := engGreeting			// greeting is a variable of type func(string) string
fmt.Println(greeting("Alice"))	// Hello Alice, nice to meet you!

greeting = espGreeting
fmt.Println(greeting("Alice")) 	// ¡Hola Alice, mucho gusto!
```

Funktionswerte bieten die Möglichkeit, Funktionen nicht nur mit Daten, sondern auch mit Verhalten zu parametrisieren.
Im folgenden Beispiel übergeben wir Verhalten über den Parameter `greetingFunc` an die Funktion `dialog`:

```go
func dialog(name string, greetingFunc func(string) string) {
	fmt.Println(greetingFunc(name))
	fmt.Println("I'm a dialog bot.")
}

func espGreeting(name string) string {
	return fmt.Sprintf("¡Hola %s, mucho gusto!", name)
}

greeting := espGreeting
dialog("Alice", greeting)
// =>
// ¡Hola Alice, mucho gusto!
// I'm a dialog bot.
```

Der Wert einer nicht initialisierten Variable vom Funktionstyp ist `nil`.
Daher führt der Aufruf eines `nil`-Funktionswerts zu einer Panik.

```go
var dutchGreeting func(string) string
dutchGreeting("Alice") // panic: call of nil function
```

Funktionswerte können mit `nil` verglichen werden.
Das kann nützlich sein, um unnötige Paniken im Programm zu vermeiden.

```go
var dutchGreeting func(string) string
if dutchGreeting != nil {
	dutchGreeting("Alice") // safe to call dutchGreeting
}
```

## Funktionstypen

Die Verwendung von Funktionswerten ist dank der Funktionstypen in Go möglich.
Ein Funktionstyp bezeichnet die Menge aller Funktionen mit derselben Abfolge von Parametertypen und derselben Abfolge von Ergebnistypen.
Benutzerdefinierte Typen können auf Grundlage von Funktionstypen deklariert werden.
Zum Beispiel kann die Funktion `dialog` aus den vorherigen Beispielen wie folgt aktualisiert werden:

```go
type greetingFunc func(string) string

func dialog(name string, f greetingFunc) {
	fmt.Println(f(name))
	fmt.Println("I'm a dialog bot.")
}
```

## Anonyme Funktionen

Ein weiteres mächtiges Werkzeug, das dank der Unterstützung erstklassiger Funktionen zur Verfügung steht, sind anonyme Funktionen.
Anonyme Funktionen werden an ihrer Verwendungsstelle definiert, ohne dass ein Name auf das Schlüsselwort `func` folgt.
Solche Funktionen haben Zugriff auf die Variablen der umgebenden Funktion.

Zum Beispiel:

```go
func fib() func() int {
	var n1, n2 int

	return func() int {
		if n1 == 0 && n2 == 0 {
			n1 = 1
		} else {
			n1, n2 = n2, n1 + n2
		}
		return n2
	}
}

next := fib()
for i := range N {
  fmt.Printf("F%d\t= %4d\n", i, next())
}
```

Ein Aufruf von `fib` deklariert die Variablen `n1` und `n2` und gibt eine anonyme Funktion zurück, die wiederum bei jedem Aufruf der Funktion die Werte dieser Variablen ändert.
Der n-te Aufruf der anonymen Funktion gibt die n-te Zahl der Fibonacci-Folge zurück, beginnend bei 0. Die anonyme innere Funktion hat Zugriff auf die lokalen Variablen (`n1` und `n2`) der umgebenden Funktion `fib`.
Das ist eine großartige Möglichkeit, mit der Funktionswerte ihren Zustand zwischen Aufrufen behalten können.
Wir sagen, dass die anonyme Funktion eine Closure der Variablen `n1` und `n2` ist. [Closures][closure] werden in der Programmierung häufig verwendet, und du wirst vielleicht sehen, dass andere Sprachen sie unterstützen.

[closure]: https://en.wikipedia.org/wiki/Closure_(computer_programming)
