# Bereiche

[Bereiche][range] stehen für ein Intervall zwischen zwei Werten.
Die häufigsten Typen, die Bereiche unterstützen, sind `Int`, `Char` und `String`.
Man kann sie für viele Dinge nutzen, zum Beispiel um schnell eine Sammlung zu erstellen, Strings zu zerlegen, zu prüfen, ob ein Wert in einem Bereich liegt, oder zum Iterieren.
Erstellt werden sie mit dem Bereichsoperator `..` oder `...` (einschließlich bzw. ausschließend).

```crystal
1..5  # A range containing 1, 2, 3, 4, 5
1...5 # A range containing 1, 2, 3, 4
```

Der Grund für zwei Bereichsoperatoren ist, dass man Bereiche erstellen kann, die den Endwert einschließen oder ausschließen. Das ist zum Beispiel nützlich, wenn du mit nullbasierten Indizes arbeitest.

Bereiche lassen sich auch mit dem `Range`-Initialisierer erstellen.

```crystal
Range.new(1, 5) # A range containing 1, 2, 3, 4, 5
```

~~~~exercism/note
Wenn du in Crystal mit den Bereichsoperatoren `..` oder `...` einen Bereich erstellst und eine Methode darauf aufrufen willst, musst du den Bereich in runde Klammern setzen.
Sonst wird die Methode nämlich auf dem zweiten Argument des Bereichsoperators aufgerufen.

```crystal
(1..5).size # => 5
1..5.size # => Error: undefined method 'size' for Int32
```
~~~~

## Teilstrings extrahieren

Wenn du einen String zerlegen willst, kannst du mit dem Bereichsoperator einen Teilstring erhalten.
Dazu erstellst du einen Bereich mit dem Start- und Endindex des Teilstrings.

```crystal
"Hello World"[0..4] # => "Hello"
"Hello World"[6..10] # => "World"
```

Du kannst auch negative Indizes verwenden, um den Teilstring vom Ende des Strings zu erhalten.

```crystal
"Hello World"[-5..-1] # => "World"
"Hello World"[6..-4] # => "Wo"
```

## Methoden für Bereiche

Für Bereiche gibt es eine Reihe von Methoden, mit denen du arbeiten kannst.
Mit ihnen kannst du zum Beispiel die Summe aller Werte im Bereich berechnen oder prüfen, ob der Bereich einen Wert enthält.

| Method                  | Beschreibung                                                            | Beispiel                        |
|-------------------------|-------------------------------------------------------------------------|---------------------------------|
| [`sum`][sum]            | Gibt die Summe aller Werte im Bereich zurück                            | `(1..5).sum # => 15`            |
| [`size`][size]          | Gibt die Größe des Bereichs zurück                                      | `(1..5).size # => 5`            |
| [`includes?`][indludes] | Gibt `true` zurück, wenn der Bereich den angegebenen Wert enthält, sonst `false` | `(1..5).includes?(3) # => true` |

## Endlose und anfangslose Bereiche

Ein Bereich kann endlos und anfangslos sein.
Bei einem endlosen oder anfangslosen Bereich ist der Start- oder Endwert `nil`, aber `nil` kann beim Definieren des Bereichs weggelassen werden.

Anfangslose und endlose Bereiche sind nützlich, wenn du zum Beispiel einen String vom Anfang oder bis zum Ende zerlegen willst.

```crystal
"Hello World"[0..] # => "Hello World"
"Hello World"[4..] # => "o World"
"Hello World"[..5] # => "Hello"
```

~~~~exercism/caution
Wenn ein endloser Bereich nicht auf eine Sammlung angewendet wird, kann er eine endlose Sequenz verursachen, wenn man nicht vorsichtig ist.
~~~~

## Char-Bereiche

Chars können in Bereichen verwendet werden und ermöglichen es dir, ein Intervall von Chars zwischen zwei Chars zu erhalten.
Das ist zum Beispiel praktisch, wenn du das Alphabet erhalten willst.

```crystal
'a'..'z' # A range containing ['a', 'b', 'c', ..., 'z']
```

## String-Bereiche

Strings können ebenfalls in Bereichen verwendet werden, wodurch du ein Intervall von Strings zwischen zwei Strings erhältst.
Ihr Verhalten unterscheidet sich jedoch leicht von dem von `Char`, wenn mehrere Zeichen in einem String-Bereich verwendet werden.
Bei komplexeren String-Bereichen kann das Verhalten verwirrend werden, sei also vorsichtig.

```crystal
("aa".."az") # A range containing ["aa", "ab", "ac", ..., "az"]
```

## Eigene Objekte in Bereichen

~~~~exercism/advanced
Crystal erlaubt es dir, eigene Objekte in Bereichen zu verwenden.
Voraussetzung dafür ist, dass das Objekt Folgendes implementiert:

- das Modul `Comparable` einbinden
- die Methode `succ`
- die Methode `<=>`

Diese Methoden ermöglichen es dem Bereich, über das Objekt zu iterieren und die Objekte im Bereich zu vergleichen.

```crystal
class Foo
  include Comparable(Foo)

  getter value

  def initialize(@value : Int32)
  end

  def succ
    Foo.new(value + 1)
  end

  def <=>(other : Foo)
 value <=> other.value
  end
end

Foo.new(1)..Foo.new(5)
# => #<Foo:0x7f3552bebe70 @value=1>, #<Foo:0x7f3552bebe50 @value=2>, #<Foo:0x7f3552bebe40 @value=3>, #<Foo:0x7f3552bebe30 @value=4>, #<Foo:0x7f3552bebe20 @value=5>
```
~~~~
