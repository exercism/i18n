# Anleitung

Ellen entwickelt ein Spiel, in dem man gegen Aliens kämpfen muss.
Sie hat gerade etwas über objektorientierte Programmierung (OOP) gelernt und möchte unbedingt nutzen, was ihr der Einsatz von `classes` für ihr Programm bieten kann.

Zu Ellens Freude hast du angeboten zu helfen, und sie hat dir die Aufgabe übertragen, die Aliens zu programmieren, gegen die man kämpfen muss.


## 1. Erstelle die `Alien`-Klasse

Definiere die `Alien`-Klasse mit einem Konstruktor, der zwei `int`-Parameter `x` und `y` entgegennimmt und sie in den Membervariablen `x_coordinate` und `y_coordinate` ablegt.
Jeder Alien startet außerdem mit einem Gesundheitswert von `3`, also sollte auch die Membervariable `health` initialisiert werden.

`health` sollte eine private Membervariable sein.
Damit andere Teile des Programms die Gesundheitsinformationen lesen können, möchte Ellen eine `public`-Methode `get_health()` haben, die einen `int` zurückgibt.

```cpp
Alien alien{2, 0};
alien.x_coordinate;
// => 2
alien.y_coordinate;
// => 0
alien.get_health();
// => 3
```

Jetzt soll jeder Alien seine eigene Position und Gesundheit intern verwalten können.

## 2. Die `hit`-Funktion

Ellen möchte, dass die `class`-Klasse eine `hit`-Methode hat, die beim Aufruf die Gesundheit eines Alien-Objekts um `1` verringert.
So kann sie einfach `some_alien_instance.hit()` aufrufen, statt die Gesundheit eines Aliens manuell ändern zu müssen.
Stell sicher, dass die Gesundheitspunkte nicht unter null fallen.
Die Funktion sollte `true` zurückgeben.
Ellen möchte später Schilde einführen, die dann `false` melden würden, wenn der Schild aktiv ist.

```cpp
Alien alien {0, 0};
alien.get_health();
// => 3 (Initial health value)

alien.hit(); // Decrements health by 1 point.
alien.get_health();
// => 2
```

## 3. Die `is_alive`-Funktion

Du merkst, dass die Gesundheit irgendwann wahrscheinlich `0` erreichen wird, wenn sie weiter sinkt.
Es wäre eine gute Idee, eine `is_alive`-Methode hinzuzufügen, die Ellen schnell aufrufen kann, um zu prüfen, ob der Alien ... nun ja ... noch lebt. 😉
`some_alien_instance.is_alive()` sollte einen booleschen Wert zurückgeben.

```cpp
alien.get_health();
// => 1
alien.is_alive();
// => true
alien.hit();
alien.get_health();
// => 0
alien.is_alive();
// => false
```

## 4. Die `teleport`-Funktion

In Ellens Spiel können sich die Aliens teleportieren!
Du musst eine `teleport`-Methode schreiben, die die Werte `x_new` und `y_new` entgegennimmt und die Koordinaten des Aliens entsprechend ändert.
Vorerst sollte die Funktion `true` zurückgeben.
Ellen möchte in späteren Leveln Bomben hinzufügen, die das Teleportieren blockieren und dann `false` für fehlgeschlagene Teleportversuche melden würden.

```cpp
alien.teleport(5, -4);
alien.x_coordinate;
// => 5
alien.y_coordinate;
// => -4
```

## 5. Die `collision_detection`-Funktion

Wenn die Aliens von etwas getroffen werden können, müssen sie erkennen können, wann eine solche Kollision auftreten könnte.
Ellen muss wissen, ob zwei Aliens dieselben Koordinaten belegen.
Die `collision_detection()`-Funktion nimmt ein weiteres Alien-Objekt als Argument entgegen und gibt einen `bool` zurück.

```cpp
Alien lrrr {3, 6};
Alien ndnd {-2, 12};
lrrr.collision_detection(ndnd);
// => false
ndnd.teleport(3, 6);
ndnd.collision_detection(lrrr);
// => true
```
