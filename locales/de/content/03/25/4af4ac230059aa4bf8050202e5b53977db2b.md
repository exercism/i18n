# Einführung

## Grundlagen

[Lua](https://lua.org) ist eine einfache und doch mächtige, effiziente, leichtgewichtige, einbettbare Skriptsprache. Das Team um Roberto Ierusalimschy, Waldemar Celes und Luiz Henrique de Figueiredo entwirft, implementiert und pflegt sie seit 1993 bei [PUC-RIO](https://www.puc-rio.br/) in Brasilien.

### Kommentare

Einzeilige Kommentare in Lua beginnen mit `--`, mehrzeilige Kommentare beginnen mit `--[[` und enden mit `]]`.
```lua
-- This is a single line comment.

--[[This is
a multiline
comment
]]
```

### Variablen

In Lua gibt es drei Arten von Variablen: globale Variablen, lokale Variablen und Tabellenfelder. Um es einfach zu halten, werden hier nur lokale Variablen erklärt. Standardmäßig sind alle Variablen global, deshalb müssen wir lokale Variablen mit dem Schlüsselwort `local` als solche deklarieren.
```lua
local x
```

Ein Wert kann einer Variablen mit dem Operator `=` zugewiesen werden.
```lua
local x = 1
```

Der Gültigkeitsbereich einer `local`-Variable ist auf den Block beschränkt, in dem sie deklariert wird. Ein Block kann der Körper einer Kontrollstruktur, der Körper einer Funktion oder eine Datei oder ein String sein, in der oder dem die Variable deklariert wird.
```lua
local x = 1

if x == 1 then
  local x = 2
  print(x) -- prints 2
end

print(x) -- prints 1
```

### Funktionen

Eine Funktion wird mit dem Schlüsselwort `function` deklariert und ist, wie Variablen, standardmäßig global. Eine Funktionsdefinition hat einen Namen, eine Liste von Parametern und einen Körper. Die Funktion wird verlassen, wenn das Schlüsselwort `return` erreicht wird, und gibt alle danach aufgeführten Werte zurück. Ohne ein angegebenes `return` gibt die Funktion `nil` zurück.

```lua
-- Defining a local function which returns "Hello " followed by 
-- the name which was given as parameter
local function say_hello(name)
  return 'Hello ' .. name
end
```

### Tabellen

Tabellen sind der einzige Mechanismus zur Datenstrukturierung in Lua und sehr mächtig. Sie werden verwendet, um Arrays, Mengen, Objekte, Module und vieles mehr darzustellen. Im Wesentlichen ist eine Tabelle in Lua ein assoziatives Array.
```lua
-- create a table and assign its reference to tbl
local tbl = {}

-- new entry with key 'x' and value 1
tbl['x'] = 1

-- printing the value
print(tbl['x'])  --> 1

-- uninitialized table fields evaluate to nil
print(tbl['y'])  --> nil

-- there is also syntactic sugar - the following is the same as above
tbl.y = 1
print(tbl.y)    --> 1
```

Das ist nur ein kleiner Einblick, der für den nächsten Abschnitt benötigt wird. Wir kommen später ausführlich auf dieses Thema zurück.

### Module

Ein Modul ist eine Sammlung von Code, die in einer `.lua`-Quelldatei gespeichert ist. Alles, was das Modul exportiert, wird in einer Tabelle gespeichert, und diese Tabelle wird am Ende der Datei zurückgegeben. Die Tabelle fungiert also im Grunde als eine Art Namensraum.
```lua
-- say-hello.lua

-- defining the table 'say' which is exported at the end
local say = {}

-- defining the function 'hello' as a table field
-- this is syntax sugar for: say.hello = function() print('Hello!') end
function say.hello()
  print('Hello!')
end

-- returning (exporting) the table 'say'
return say
```

Dieses Modul kann dann durch die Funktion `require`, die die Tabelle zurückgibt, in eine andere Datei geladen werden.
```lua
-- lets_say_hello.lua
local say = require('say-hello')
say.hello() -- prints "Hello!"
```

Wenn wir `say.hello` sehen, denken wir an „die Funktion `hello` aus dem Modul `say`“. Aber wenn wir wissen, dass unsere `say-hello.lua` eine Tabelle zurückgibt, und auf den Tabellenabschnitt zurückblicken, fällt uns auf, dass der Ausdruck in Lua bedeutet, „die Tabelle `say` mit dem String `hello` als Schlüssel zu indizieren“.

Obwohl es gute Praxis ist, dass ein Modul eine Tabelle zurückgibt, ist es genauso möglich, einen anderen Typ zurückzugeben, zum Beispiel eine Funktion.

```lua
--- say-bye.lua
local function bye()
  print('Bye!')
end

return bye
```
