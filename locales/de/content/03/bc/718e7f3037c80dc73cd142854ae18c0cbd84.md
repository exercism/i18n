# Einführung

Im Konzept `Vectors` haben wir gesehen, dass ein Vektor in einem bedingten Ausdruck verwendet werden kann, wodurch ein logischer Vektor entsteht.
Dieser wiederum kann in Funktionen wie `all()` und `any()` verwendet werden.

```R
v <- c(4, 7, 10)
v >= 6
#> [1] FALSE  TRUE  TRUE
all(v > 6)
#> [1] FALSE    # not all elements match this condition
any(v > 6)
#> [1] TRUE     # at least one element matches
```

Diese Technik ist noch viel mächtiger.

## Teilmengen eines Vektors

Ausgewählte Elemente eines Vektors kannst du mit einer Indexzahl oder einem Vektor von Indizes herausziehen:

```R
v <- 5:10
v
#> [1]  5  6  7  8  9 10
v[3] 
#> [1] 7
v[c(2, 4)]
#> [1] 6 8
```

Alternativ kannst du mit einem logischen Vektor den ursprünglichen Vektor filtern und erhältst so eine Teilmenge der Einträge, die zu einem `TRUE`-Wert passen:

```R
v <- 1:3
bools <- c(FALSE, TRUE, TRUE)
v[bools]
#> [1] 2 3
```

Von dort ist es nur ein kleiner Schritt, den booleschen Vektor mit einem bedingten Ausdruck zu erzeugen:

```R
bools <- v >= 2
bools
#> [1] FALSE  TRUE  TRUE

v[bools]
#> [1] 2 3

# simpler form
v[v >= 2]
#> [1] 2 3
```

## Indizes finden

Die Funktion `which()` nimmt ein boolesches Argument und gibt einen Vektor von Indizes zurück, die `TRUE` liefern.

```R
v
#> [1] 2 7 9

v[v > 5]  # returns values
#> [1]  7  9

which(v > 5) # returns indices
#> [1] 2 3
```

## Prüfen, ob ein Eintrag existiert

In den vorherigen Abschnitten ging es darum, Einträge zu finden, die ein bestimmtes Kriterium erfüllen.

Wenn du nur wissen musst, ob der Vektor ein bestimmtes Element enthält, verwendest du den Operator `%in%`.

```R
3 %in% 1:5
#> [1] TRUE
7 %in% 1:5
#> [1] FALSE
```

Das ist funktional äquivalent zum folgenden Code, aber viel bequemer:

```R
v <- 1:5
length(v[v == 3]) > 0
#> [1] TRUE
```
