# Anleitung

Während du für deine Freunde Kekse backen willst, stellst du fest, dass du einige der im Rezept verwendeten Maßeinheiten umrechnen musst. Da du nur das metrische System kennst, brauchst du einen Weg, um gängige US-Backmaße für dich bequem in Milliliter (mL) umzurechnen.

Verwende diese Umrechnungstabelle für deine Lösung:

| Umzurechnende Einheit | Volumen | in Milliliter (mL) |
| --------------- | ------ | ------------------- |
| mL              | 1      | 1                   |
| US-Cup          | 1      | 240                 |
| US-Flüssigunze  | 1      | 30                  |
| US-Teelöffel    | 1      | 5                   |
| US-Esslöffel    | 1      | 15                  |

Als talentierte Programmierer:in in Ausbildung entscheidest du dich dafür, Milliliter als Zwischeneinheit zu verwenden, damit du jede aufgeführte Einheit in jede andere (sogar in sich selbst) umrechnen kannst.

## 1. Hole den numerischen Anteil aus einem Volumenpaar

Implementiere die Funktion `KitchenCalculator.get_volume/1`. Wenn man ihr ein Volumenpaar-Tupel übergibt, soll sie nur den numerischen Anteil zurückgeben.

```elixir
KitchenCalculator.get_volume({:cup, 2.0})
# => 2.0
```

## 2. Rechne das Volumenpaar in Milliliter um

Implementiere die Funktion `KitchenCalculator.to_milliliter/1`. Wenn man ihr ein Volumenpaar-Tupel übergibt, soll sie das Volumen mithilfe der Umrechnungstabelle in Milliliter umrechnen.

Nutze mehrere Funktionsklauseln und Pattern Matching, um die Funktionen für die einzelnen Einheiten zu erstellen. Die Atome, mit denen die einzelnen Einheiten bezeichnet werden, sind: `:cup`, `:fluid_ounce`, `:teaspoon`, `:tablespoon`, `:milliliter`. Gib das Ergebnis der Umrechnung in ein Tupel verpackt zurück.

```elixir
KitchenCalculator.to_milliliter({:cup, 2.5})
# => {:milliliter, 600.0}
```

## 3. Rechne das Milliliter-Volumenpaar in eine andere Einheit um

Implementiere die Funktion `KitchenCalculator.from_milliliter/2`. Wenn man ihr ein Volumenpaar-Tupel und die gewünschte Einheit übergibt, soll sie das Volumen mithilfe der Umrechnungstabelle in die gewünschte Einheit umrechnen.

Nutze mehrere Funktionsklauseln und Pattern Matching, um die Funktionen für die einzelnen Einheiten zu erstellen. Die Atome, mit denen die einzelnen Einheiten bezeichnet werden, sind: `:cup`, `:fluid_ounce`, `:teaspoon`, `:tablespoon`, `:milliliter`

```elixir
KitchenCalculator.from_milliliter({:milliliter, 1320.0}, :cup)
# => {:cup, 5.5}
```

## 4. Rechne von einer beliebigen Einheit in eine beliebige andere um

Implementiere die Funktion `KitchenCalculator.convert/2`. Wenn man ihr ein Volumenpaar-Tupel und die gewünschte Einheit übergibt, soll sie das angegebene Volumen in die gewünschte Einheit umrechnen.

```elixir
KitchenCalculator.convert({:teaspoon, 9.0}, :tablespoon)
# => {:tablespoon, 3.0}
```
