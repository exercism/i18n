# Über

ColdFusion (CFML) ist eine Skriptsprache für die JVM, deren Syntax der von C oder JavaScript ähnelt.
Sie wird per JIT zu Bytecode kompiliert, der auf der JVM läuft, ist aber dynamisch und locker typisiert, was die Entwicklung schnell und einfach macht.
CF ist eine multiparadigmatische Sprache, die klassische objektorientierte und funktionale Programmierung unterstützt.

CFML hat außerdem eine eingebaute, tagbasierte Template-Sprache, die es ideal für Web-Apps macht.
Sie läuft in einem J2EE-Container mit vielen mitgelieferten Bibliotheken, die sie sehr produktiv machen, ohne dass du viele Pakete installieren musst.
CFML bietet native Unterstützung für ZIP-Dateien, PDF- und Excel-Generierung, E-Mails, FTP, HTTP, S3-Dateisysteme, ESAPI-Sicherheitsbibliotheken, JDBC-Treiber, JSON- und REST-APIs.

CFML kann außerdem jedes Java-Projekt nutzen, indem du die JARs in das Projekt legst und Java-Objekte direkt in deinem Code instanziierst.
Mehr über grundlegende Syntax und First-Class-Datentypen erfährst du in diesem Leitfaden: [Modern ColdFusion (CFML) in 100 Minutes](https://modern-cfml.ortusbooks.com/)
