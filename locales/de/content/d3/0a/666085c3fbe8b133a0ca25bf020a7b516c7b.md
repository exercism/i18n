# Überblick

Der boolesche Typ in Lua hat die beiden traditionellen booleschen Werte: `true` und `false`. Diese Werte können einer Variablen zugewiesen, mit logischen Operatoren (`and`, `or`, `not`) kombiniert und in Bedingungsprüfungen verwendet werden (z. B. in Kontrollstrukturen).

```lua
local is_true = true
local is_false = false

true and true  --> true
true and false --> false
false or true  --> true
false or false --> false
not false      --> true
not true       --> false

-- prints 0
if is_true == true then
  print(0)
else
  print(1)
end
```

Bedingungsprüfungen und die logischen Operatoren betrachten sowohl den booleschen Wert `false` als auch `nil` als falsch und alles andere als wahr.
```lua
1 and 2          --> 2
nil and 2        --> nil
false and 2      --> false
1 or 2           --> 1
false or 'hello' --> "hello"
nil or false     --> false
```

Sowohl `and` als auch `or` verwenden *Kurzschlussauswertung*, was bedeutet, dass sie ihren zweiten Operanden nur auswerten, wenn es nötig ist. Alle Operationen werden gemäß der [Operatorrangfolge](https://www.lua.org/manual/5.4/manual.html#3.4.8) ausgewertet, wobei `not` vor `and` und `or` ausgewertet wird.

Da nur `false` und `nil` als falsch gelten und alles andere als wahr gilt, ist ein gängiges Idiom in Lua:
```lua
x = x or y
```

Das ist gleichbedeutend mit:
```lua
if not x then
  x = y
end
```

Es ist ziemlich üblich, dies in Funktionen zu verwenden, um einen Standardwert zuzuweisen, wenn ein Parameter keinen Wert hat (also `nil` ist):
```lua
local function hello(name)
  name = name or "World"
  print("Hello " .. name)
end

hello()       --> "Hello World"
hello('Mars') --> "Hello Mars"
```
