# Nutze String-Interpolation statt String-Verkettung

Verwende die [String-Interpolation](https://csharp.net-tutorials.com/operators/the-string-interpolation-operator/), um einen String dynamisch aufzubauen, statt Strings zu verketten. Der größte Vorteil ist weniger „Rauschen“: Die String-Verkettung verlangt zwischen jedem String ein `+`, die String-Interpolation kennt diese Einschränkung nicht. Dadurch ist Code mit String-Interpolation meist etwas leichter zu lesen.
