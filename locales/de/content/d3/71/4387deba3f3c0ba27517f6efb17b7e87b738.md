# Einführung

Pyret kennt zwei verschiedene boolesche Grundwerte, `true` und `false`.
Diese beiden Werte geben an, ob eine Aussage oder Bedingung zutrifft oder nicht.

```pyret
"a" == "a" # true
"a" == "b" # false
```

Pyret stellt die Operatoren `and` und `or` bereit, mit denen sich boolesche Werte verknüpfen lassen.

Der `and`-Operator gibt wahr zurück, wenn beide Seiten wahr sind, und falsch bei allen anderen Kombinationen.

```pyret
true and true # true
true and false # true
false and true # false
false and false # false
```

Der `or`-Operator gibt wahr zurück, wenn mindestens eine Seite wahr ist, und falsch, wenn beide Seiten falsch sind.

```pyret
true or true # true
true or false # true
false or true # true
false or false # false
```

`not()` ist eine eingebaute Funktion, die wahr zu falsch und falsch zu wahr umkehrt.

```pyret
not(true) # false
not(false) # true
```
