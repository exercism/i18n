# Installation

## Windows (empfohlen)

Verwendest du ein Windows-Betriebssystem?

Drücke `Windows Key`, tippe `cmd` und drücke `enter`.

> Wenn dein Betriebssystem Windows ist, ist Batch bereits auf deinem System installiert.

Wenn du ein anderes Betriebssystem verwendest, kannst du Batch installieren, indem du die folgenden Anweisungen befolgst.

## Mac OS

1. Der Gatekeeper darf nicht so eingestellt sein, dass er unsignierte Pakete blockiert.
2. Öffne die Anwendung Terminal.
3. Führe den folgenden Befehl aus, um Batch zu installieren:

```bash
brew install --cask --no-quarantine wine-stable
```

## Ubuntu

1. Wenn dein System 64 Bit ist, aktiviere die 32-Bit-Architektur (falls noch nicht geschehen):

```bash
sudo dpkg --add-architecture i386
```

2. Füge das WineHQ-Repository hinzu:

```bash
sudo mkdir -pm755 /etc/apt/keyrings
sudo wget -O /etc/apt/keyrings/winehq-archive.key https://dl.winehq.org/wine-builds/winehq.key
sudo apt update
```

3. Installiere WineHQ:

```bash
sudo apt install --install-recommends winehq-stable
```

## Fedora

1. Aktiviere das Wine-Repository:

```bash
# Fedore 39
dnf config-manager --add-repo https://dl.winehq.org/wine-builds/fedora/39/winehq.repo

# Fedora 40
dnf config-manager --add-repo https://dl.winehq.org/wine-builds/fedora/40/winehq.repo
```

2. Installiere WineHQ:

```bash
dnf install winehq-stable
```
