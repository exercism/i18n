# Einführung

## Maybe

Der `Maybe`-Typ ist die Lösung in der Sprache Elm für optionale Werte.
Er taucht daher in den Typsignaturen vieler Elm-Kernfunktionen auf, und ihn zu verstehen ist entscheidend.
Der `Maybe`-Typ ist wie folgt definiert:

```elm
type Maybe a = Nothing | Just a
```

In der Elm-Terminologie nennt man das eine „Custom Type“-Definition.
Er zeigt an, dass ein Wert dieses Typs entweder `Nothing` oder `Just` etwas vom Typ `a` sein kann.
Einen `Maybe`-Wert erstellst du mit einem seiner beiden Konstruktoren `Nothing` und `Just`.
Den Inhalt eines `Maybe`-Werts liest du mit Pattern Matching aus.

```elm
matthieu : Maybe String
matthieu = Just "Matthieu"

anon : Maybe String
anon = Nothing

sayHello : Maybe String -> String
sayHello maybeName =
    case maybeName of
        Nothing -> "Hello, World!"
        Just someName -> "Hello, " ++ someName ++ "!"

sayHello matthieu
    --> "Hello, Matthieu!"

sayHello anon
    --> "Hello, World!"
```

Außerdem gibt es im `Maybe`-Modul eine Reihe nützlicher Funktionen, mit denen du `Maybe`-Typen bearbeiten kannst.

```elm
sayHelloAgain : Maybe String -> String
sayHelloAgain name = "Hello, " ++ Maybe.withDefault "World" name ++ "!"

capitalizeName : Maybe String -> Maybe String
capitalizeName name = Maybe.map String.toUpper name

capitalizeName matthieu
    --> Just "MATTHIEU"

capitalizeName anon
    --> Nothing
```
