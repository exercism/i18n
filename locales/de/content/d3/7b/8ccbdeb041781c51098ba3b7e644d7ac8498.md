# Hinweise

## 1. Pokerrunden verfolgen

- Die Funktion [`list`][list] gibt eine Liste zurück, die aus den Argumenten besteht, die ihr übergeben werden.

## 2. Alle Runden an derselben Stelle halten

- Mit der Funktion [`concat`][concat] kannst du zwei Listen miteinander verketten.

## 3. Frühere Runden finden

- Die Funktion [`some`][some] gibt den ersten logisch wahren Wert in einer Collection zurück.
- Die Funktion [`boolean`][boolean] ist nützlich, wenn eine Funktion einen Wert zurückgibt, die Tests aber einen booleschen Wert erwarten.

## 4. Kartenwerte mitteln

- Erinnere dich an die grundlegenden Rechenoperatoren wie [`/`][division] und [`+`][addition].
- Eine Collection von Zahlen lässt sich mit [`apply`][apply] oder [`reduce`][reduce] summieren.
- Die Funktion [`count`][count] gibt die Anzahl der Elemente in einer Collection zurück.
- Die Funktion [`/`][division] gibt bei Ganzzahlen einen Ratio-Typ zurück. Mit [`double`][double] kannst du ein Ratio in eine Gleitkommazahl umwandeln.

## 5. Alternative Mittelwerte

- Es gibt Sequenzfunktionen, um das [`first`][first]- oder [`last`][last]-Element einer sequenziellen Collection zurückzugeben.
- Um die mittlere Karte zu finden, kannst du die Anzahl der Karten durch 2 teilen, mit [`int`][int] auf die niedrigste Ganzzahl abrunden und die Karte an diesem Index mit [`nth`][nth] abrufen.
- Verwende [`or`][or], um festzustellen, ob eine der beiden Bedingungen wahr ist.

## 6. Weitere Mittelwerttechniken

- Eine Möglichkeit, die Karten an geraden/ungeraden Indizes abzurufen, wäre, eine Funktion, die [`nth`][nth] verwendet, mit [`map`][map] über eine [`range`][range] laufen zu lassen, die ein optionales `step`-Argument akzeptiert.

## 7. Bonusrunden-Regeln

- Erinnere dich daran, wie du [`if`][if] aus der Übung zu Bedingungen verwendest.
- Mit [`butlast`][butlast] kannst du alle Elemente einer Collection außer dem letzten zurückgeben.
