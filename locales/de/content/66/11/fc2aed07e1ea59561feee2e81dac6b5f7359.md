## 1. Starte eine Zuverlässigkeitsprüfung für einen einzelnen Eingabewert

- Für diesen Schritt brauchst du keinen Task, ein normaler verknüpfter Prozess reicht aus.
- Es gibt eine [eingebaute Funktion][spawn-link], die eine gegebene anonyme Funktion in einem neuen Prozess ausführt und ihn mit dem aktuellen Prozess verknüpft.

## 2. Interpretiere die Ergebnisse einer Zuverlässigkeitsprüfung

- Um eine einzelne Nachricht zu empfangen, rufe [`receive`][receive] einmal auf. Es liest die erste Nachricht, die auf eines der angegebenen Muster passt, und lässt die übrigen Nachrichten im Posteingang des Prozesses.
- Du kannst entweder einen Guard oder [den Pin-Operator][pin-operator] verwenden, um sicherzustellen, dass nur Nachrichten von einem Prozess empfangen werden, dessen PID mit der PID übereinstimmt, die `await_reliability_check_result/2` als Argument übergeben wird.
- [`receive`][receive] akzeptiert eine `after`-Klausel, um Timeouts zu behandeln.

## 3. Führe eine nebenläufige Zuverlässigkeitsprüfung für viele Eingabewerte durch

- Der aktuelle Prozess muss beginnen, Exits abzufangen, bevor neue verknüpfte Prozesse erzeugt werden.
- Um Exits in einem Prozess abzufangen, setzt man ein Flag für diesen Prozess.
- Es gibt eine [eingebaute Funktion][process-flag], die ein Flag für einen Prozess setzt und den alten Wert dieses Flags zurückgibt.
- Das Flag zum Abfangen von Exits heißt `:trap_exit` und akzeptiert einen booleschen Wert.
- Nutze `Enum`-Funktionen, um zuerst für jeden Eingabewert einen Prozess zu starten und dann auf Nachrichten von jedem Prozess zu warten. Verwende die Funktionen, die du in den beiden vorherigen Schritten implementiert hast. Beachte, dass die von `start_reliability_check/2` zurückgegebene Map mit der Map übereinstimmt, die `await_reliability_check_result/2` als erstes Argument erwartet.

## 4. Führe eine nebenläufige Korrektheitsprüfung für viele Eingabewerte durch

- Verwende für diesen Schritt einen asynchronen Task.
- Es gibt eine [eingebaute Funktion][task-async], die einen asynchronen Task startet.
- Es gibt eine [eingebaute Funktion][task-await], die darauf wartet, dass ein asynchroner Task mit der Ausführung fertig wird, und sein Ergebnis zurückgibt. Sie akzeptiert einen Timeout als zweites Argument.
- Nutze `Enum`-Funktionen, um zuerst für jeden Eingabewert einen Task zu starten und dann auf jeden Task zu warten.
