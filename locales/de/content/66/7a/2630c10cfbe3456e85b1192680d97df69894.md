# Einführung

## Grundlagen

Ausführlichere Informationen zu diesen Themen findest du auf der [Konzeptseite][exercism-concept].

### Allgemeine Syntax

Das öffnende PHP-Tag `<?php` markiert den Beginn von PHP-Code.
Alle Anweisungen müssen mit einem `;` enden, um Anweisungen voneinander zu trennen.

```php
<?php

$message = "Success!"; // Statement correctly ends with `;`
$message = "I fail." // PHP Parse error: syntax error, [...]
```

Zur besseren Lesbarkeit lassen alle Codebeispiele das öffnende PHP-Tag `<?php` weg.

### Kommentare

Einzeilige Kommentare beginnen mit `//`.

```php
// Single line comment
```

### Werte und Variablen

Mit dem Zuweisungsoperator `=` kannst du einer Variablen einen Wert zuweisen.
Variablennamen müssen mit einem Dollarzeichen `$` beginnen und den [Namenskonventionen][exercism-concept-naming-conventions] folgen.

```php
$count = 1; // Assign value of 1

// Strings can be created by enclosing the characters
// within single `'` quotes or double `"` quotes.
$message = "Success!";
```

### Funktionen und Methoden

Werte und Variablen können an Funktionen übergeben werden.
Die Argumente einer Funktion werden zu neuen Variablen, die die übergebenen Werte aufnehmen.
Funktionen können mit dem Schlüsselwort `return` einen beliebigen Wert zurückgeben.

```php
function window_height($height)
{
    return $height + 10;
}

window_height(100);
// => 110
```

Funktionen innerhalb von Klassen und ihren Instanzen heißen Methoden.
Beim Aufruf einer Methode stehen vor dem Namen die Instanz und `->`.
Methoden haben Zugriff auf die spezielle Variable `$this`, die auf die aktuelle Instanz verweist.

```php
<?php

class Calculator {
    public function sub($x, $y)
    {
        return $this->add($x, -$y); // Calls the method add() of the current instance
    }

    public function add($x, $y)
    {
        return $x + $y;
    }
}

$calculator = new Calculator(); // Creates a new instance of Calculator class
$calculator->sub(3, 1); // Calls the method sub() of the instance stored in $calculator
// => 2
```
