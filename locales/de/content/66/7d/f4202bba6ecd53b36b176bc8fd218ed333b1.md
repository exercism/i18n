# Anleitung

Du führst die Anzeigetafel bei einem Netballspiel. Anders als alles bisher muss sich eine Anzeigetafel merken, was passiert ist.

Die Klasse `SCOREBOARD` braucht Folgendes. Das Stub liefert dir die Klasse und ihre beiden Attributdeklarationen; ergänze den Rest.

## 1. Richte die Anzeigetafel ein

`create` nimmt den Namen der Heimmannschaft und den Namen der Auswärtsmannschaft entgegen und gibt eine Anzeigetafel zurück, bei der beide Punktestände null sind.

```sather
board ::= #SCOREBOARD("Vixens", "Magpies");
board.home_score
-- => 0
```

## 2. Erziele ein Tor

`home_goal` erhöht den Heimstand um eins und `away_goal` erhöht den Auswärtsstand um eins. Keine der beiden gibt etwas zurück.

```sather
board.home_goal;
board.home_score
-- => 1
```

## 3. Lies die Anzeigetafel

`summary` gibt die Anzeigetafel so zurück, wie sie aufgeschrieben würde: die Heimmannschaft, ihr Punktestand, ein Bindestrich, der Auswärtsstand und dann die Auswärtsmannschaft.

```sather
board.summary
-- => "Vixens 1 - 0 Magpies"
```

Die Leerzeichen sind genau wie gezeigt, und der Bindestrich ist ein einzelnes `-`.

## 4. Wer führt?

`leader` gibt den Namen der führenden Mannschaft zurück oder `"Draw"`, wenn die Punktestände gleich sind.

```sather
board.leader
-- => "Vixens"
```

## 5. Wie groß ist der Vorsprung?

`margin` gibt zurück, wie viele Tore zwischen den Mannschaften liegen. Der Wert ist nie negativ, egal wer führt.

```sather
board.margin
-- => 1
```
