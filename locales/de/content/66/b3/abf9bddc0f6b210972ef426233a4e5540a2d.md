# Anleitung

Als angehende Magierin muss Elyse einige Grundlagen üben. Sie hat ein Kartendeck, das sie bearbeiten möchte.

Um es etwas einfacher zu machen, verwendet sie nur die Karten 1 bis 10.

## 1. Eine Karte aus einem Kartendeck holen

Implementiere die Funktion `getCard`, die die Karte an der Position `index` aus dem gegebenen Kartendeck zurückgibt. Wenn der Index nicht im Kartendeck vorkommt, gib Nothing zurück.

```elm
getCard 2 ( Array.fromList [ 1, 2, 4, 1 ] )
    --> Just 4
getCard 6 ( Array.fromList [ 1, 2, 4, 1 ] )
    --> Nothing
```

## 2. Eine Karte im Kartendeck ändern

Implementiere die Funktion `setCard`, die ein Kartendeck zurückgibt, in dem die Karte an der Position `index` durch die angegebene neue Karte ersetzt wurde.
Wenn der `index` nicht im Kartendeck vorkommt, gib das ursprüngliche Kartendeck zurück.

```elm
setCard 2 6 ( Array.fromList [ 1, 2, 4, 1 ] )
    --> Array.fromList [ 1, 2, 6, 1 ]
setCard 6 6 ( Array.fromList [ 1, 2, 4, 1 ] )
    --> Array.fromList [ 1, 2, 4, 1 ]
```

## 3. Eine Karte zum Kartendeck hinzufügen

Implementiere die Funktion `addCard`, die ein Kartendeck mit der neu hinzugefügten Karte zurückgibt.

```elm
addCard 8 ( Array.fromList [ 5, 9, 7, 1 ] )
    --> Array.fromList [ 5, 9, 7, 1, 8 ]
```

## 4. Eine Karte aus dem Kartendeck entfernen

Implementiere die Funktion `removeCard`, die ein Kartendeck zurückgibt, aus dem die Karte an der Position `index` entfernt wurde.
Wenn der angegebene `index` kein gültiger Index im Kartendeck ist, gib das ursprüngliche Kartendeck zurück.

```elm
removeCard 2 ( Array.fromList [ 3, 2, 6, 4, 8 ] )
    --> Array.fromList [ 3, 2, 4, 8 ]
removeCard 2 ( Array.fromList [ 3, 2 ] )
    --> Array.fromList [ 3, 2 ]
```

## 5. Die Anzahl der geraden Karten im Kartendeck zählen

Implementiere die Funktion `evenCardCount`, die die Anzahl der geraden Karten im Kartendeck zählt.

```elm
evenCardCount (Array.fromList [ 3, 8, 4, 5, 1, 6, 10 ] )
    --> 4
```
