# Überblick

Die zentralen Klassen in `java.time` wie `LocalDate` und `LocalDateTime` bieten einfache Methoden, um Zeiteinheiten zu addieren oder zu subtrahieren. Komplexere Datumsanpassungen brauchen aber oft deutlich mehr Logik (zum Beispiel, um den „zweiten Dienstag im Monat“ oder den „letzten Tag des Jahres“ zu finden).

Das Paket `java.time.temporal` stellt dafür das funktionale Interface [`TemporalAdjuster`][temporaladjuster-docs] bereit. Es beschreibt eine Strategie, um ein temporales Objekt (etwa ein `LocalDate`) anzupassen. Die Utility-Klasse [`TemporalAdjusters`][temporaladjusters-docs] (beachte das Plural-s) enthält statische Factory-Methoden mit vielen gängigen, vordefinierten Adjuster-Implementierungen.

## TemporalAdjusters verwenden

Temporale Objekte wie `LocalDate` und `LocalDateTime` haben eine `with()`-Methode, die einen `TemporalAdjuster` entgegennimmt. Diese Methode gibt ein *neues* temporales Objekt mit der angewendeten Anpassung zurück.

```exercism/note
`with(TemporalAdjuster)` gibt eine _neue_ Instanz zurück und aktualisiert die vorhandene Instanz nicht, denn alle temporalen Klassen in `java.time` sind unveränderlich.
```

```java
import java.time.LocalDate;
import java.time.Month;
import java.time.DayOfWeek;
import java.time.temporal.TemporalAdjusters;

LocalDate date = LocalDate.of(2024, Month.AUGUST, 15); // 2024-08-15 (a Thursday)

// Use a predefined adjuster from TemporalAdjusters
LocalDate firstDayOfNextMonth = date.with(TemporalAdjusters.firstDayOfNextMonth());
// => 2024-09-01

LocalDate nextSunday = date.with(TemporalAdjusters.next(DayOfWeek.SUNDAY));
// => 2024-08-18
```

## Häufige vordefinierte Adjuster

Die Klasse `TemporalAdjusters` bietet viele nützliche statische Methoden. Hier sind einige gängige Beispiele:

### Den n-ten Wochentag im Monat finden

Der Adjuster `dayOfWeekInMonth(int ordinal, DayOfWeek dayOfWeek)` findet das n-te Vorkommen eines bestimmten Wochentags im Monat.

```java
LocalDate date = LocalDate.of(2024, Month.AUGUST, 15); // 2024-08-15

// Find the second Tuesday of August 2024
LocalDate secondTuesday = date.with(TemporalAdjusters.dayOfWeekInMonth(2, DayOfWeek.TUESDAY));
// => 2024-08-13

// Find the fourth Friday of August 2024
LocalDate fourthFriday = date.with(TemporalAdjusters.dayOfWeekInMonth(4, DayOfWeek.FRIDAY));
// => 2024-08-23
```

### Den ersten bzw. letzten Wochentag im Monat finden

Die Adjuster `firstInMonth(DayOfWeek dayOfWeek)` und `lastInMonth(DayOfWeek dayOfWeek)` finden das erste oder letzte Vorkommen eines Wochentags im Monat.

```java
LocalDate date = LocalDate.of(2024, Month.AUGUST, 15); // 2024-08-15

// Find the first Sunday of August 2024
LocalDate firstSunday = date.with(TemporalAdjusters.firstInMonth(DayOfWeek.SUNDAY));
// => 2024-08-04

// Find the last Monday of August 2024
LocalDate lastMonday = date.with(TemporalAdjusters.lastInMonth(DayOfWeek.MONDAY));
// => 2024-08-26
```

### Den ersten bzw. letzten Tag des Monats oder Jahres finden

Einfachere Adjuster finden den ersten oder letzten Tag des aktuellen Monats oder Jahres.

```java
LocalDate date = LocalDate.of(2024, Month.AUGUST, 15); // 2024-08-15

LocalDate firstDay = date.with(TemporalAdjusters.firstDayOfMonth());
// => 2024-08-01

LocalDate lastDay = date.with(TemporalAdjusters.lastDayOfMonth());
// => 2024-08-31

LocalDate lastDayOfYear = date.with(TemporalAdjusters.lastDayOfYear());
// => 2024-12-31
```

### Relative Anpassungen (nächster/vorheriger)

Adjuster wie `next()`, `previous()`, `nextOrSame()` und `previousOrSame()` finden das nächste oder vorherige Vorkommen eines Wochentags relativ zum aktuellen Datum.

- `next()`/`previous()`: schließt das aktuelle Datum aus, wenn es passt.
- `nextOrSame()`/`previousOrSame()`: schließt das aktuelle Datum ein, wenn es passt.

```java
LocalDate thursday = LocalDate.of(2024, Month.AUGUST, 15); // A Thursday

// Find the next Sunday (exclusive)
LocalDate nextSunday = thursday.with(TemporalAdjusters.next(DayOfWeek.SUNDAY));
// => 2024-08-18

// Find the next Thursday (exclusive)
LocalDate nextThursday = thursday.with(TemporalAdjusters.next(DayOfWeek.THURSDAY));
// => 2024-08-22

// Find the next Thursday (inclusive) - returns the same date
LocalDate nextOrSameThursday = thursday.with(TemporalAdjusters.nextOrSame(DayOfWeek.THURSDAY));
// => 2024-08-15

// Find the previous Monday (exclusive)
LocalDate previousMonday = thursday.with(TemporalAdjusters.previous(DayOfWeek.MONDAY));
// => 2024-08-12
```

## Eigene Adjuster

Da `TemporalAdjuster` ein [`@FunctionalInterface`][functionalinterface-docs] ist, kannst du mit Lambda-Ausdrücken eigene Adjuster für Logik schreiben, die die vordefinierten Methoden nicht abdecken. Das Interface verlangt, dass du eine einzige Methode implementierst: `Temporal adjustInto(Temporal temporal)`.

```java
// Example: An adjuster that finds the next workday (Mon-Fri), skipping weekends.
TemporalAdjuster nextWorkday = temporal -> {
    LocalDate result = (LocalDate) temporal; // Assuming input is LocalDate
    do {
        result = result.plusDays(1);
    } while (result.getDayOfWeek() == DayOfWeek.SATURDAY || result.getDayOfWeek() == DayOfWeek.SUNDAY);
    return result;
};

LocalDate friday = LocalDate.of(2024, Month.AUGUST, 16);
LocalDate nextWorkdayDate = friday.with(nextWorkday);
// => 2024-08-19 (Monday)

LocalDate sunday = LocalDate.of(2024, Month.AUGUST, 18);
LocalDate nextWorkdayFromSunday = sunday.with(nextWorkday);
// => 2024-08-19 (Monday)
```

Eigene Adjuster sind zwar mächtig, doch die vordefinierten Adjuster in der Klasse `TemporalAdjusters` decken schon eine breite Palette gängiger Anwendungsfälle ab.
