# Tests

Führe die Tests so aus:

```bash
$ gradlew test
```

> Verwende `gradlew.bat`, wenn du Windows verwendest.

## Übersprungene Tests

In den Testsuiten wurden alle Tests außer dem ersten übersprungen.

Sobald ein Test erfolgreich ist, kannst du den nächsten aktivieren, indem du die
`@Ignore`-Annotation entfernst.
