# Anweisungen

Dein Freund hat es satt, für Fotobearbeitungssoftware zu bezahlen, und beschlossen, seine eigene zu schreiben.
Dein Freund hat entschieden, die neue Software Foto Fusionist zu nennen.

Foto Fusionist ist eine Fotobearbeitungssoftware, die eine Menge Dinge kann, aber du hast bisher nur wenige davon implementiert.
Trotzdem ist dein Freund mit den Fortschritten sehr zufrieden und hat dich gebeten, noch ein paar weitere Funktionen zu implementieren.

## 1. Binärdarstellung in eine Ganzzahl umwandeln

Für die erste Funktion möchte dein Freund in der Lage sein, eine Binärdarstellung einer Zahl in eine Ganzzahl umzuwandeln.
Das ist nötig, weil die Software die Binärdarstellung eines Farbkanals lesen und in eine Ganzzahl umwandeln können soll.

Implementiere die Methode `FotoFusionist.binary_to_int`, die ein Argument `binary` vom Typ `String` entgegennimmt.
Die Methode sollte die Ganzzahldarstellung der Binärzahl zurückgeben.

```crystal
FotoFusionist.binary_to_int("10011")
# => 19
```

## 2. Niedrigstwertiges Bit aus einer Ganzzahl ermitteln

Die zweite Funktion, die dein Freund möchte, ist, das [niedrigstwertige Bit][least-significant-bit] aus einer Ganzzahl ermitteln zu können.
Das niedrigstwertige Bit ist das Bit, das am weitesten rechts steht.
Es heißt niedrigstwertiges Bit, weil es den geringsten Wert hat.

Das niedrigstwertige Bit wird benötigt, um zu beurteilen, ob ein Bild optimiert werden kann, indem die Anzahl der Bits reduziert wird, die zur Darstellung des Farbkanals verwendet werden.

Implementiere die Methode `FotoFusionist.least_significant_bit`, die ein Argument `number` vom Typ `Int32` entgegennimmt.
Die Methode sollte das niedrigstwertige Bit der Zahl zurückgeben.

```crystal
FotoFusionist.least_significant_bit(0b10011)
# => 1

FotoFusionist.least_significant_bit(0b10010)
# => 0
```

## 3. Hex-Wert aus einem Farbkanal ermitteln

Die dritte Funktion, die dein Freund möchte, ist, den Hex-Wert aus einem Farbkanal ermitteln zu können.
Der Hex-Wert wird benötigt, um den Farbkanal in eine Hex-Darstellung umzuwandeln, und die gegebene Hex-Darstellung muss aus zwei Ziffern bestehen.

Implementiere die Methode `FotoFusionist.hex_value`, die ein Argument `number` vom Typ `Int32` entgegennimmt.
Die Methode sollte den Hex-Wert der Zahl als `String` zurückgeben.

```crystal
FotoFusionist.hex_value(19)
# => "13"
```

## 4. Hex-Wert aus RGB ermitteln

Die vierte Funktion, die dein Freund möchte, ist, den Hex-Wert aus einer RGB-Farbe ermitteln zu können.
Das ist nötig, damit ein Benutzer eine einzelne String-Darstellung einer Farbe erhalten kann.
Eine RGB-Farbe ist eine Farbe, die durch drei Farbkanäle dargestellt wird: Rot, Grün und Blau.
Jeder Farbkanal wird durch eine Zahl zwischen 0 und 255 dargestellt.

Der Hex-Wert einer RGB-Farbe ist eine String-Darstellung der Farbe im Hexadezimalsystem, wobei der rote Farbkanal zuerst kommt, dann der grüne Farbkanal und zuletzt der blaue Farbkanal.

Implementiere die Methode `FotoFusionist.hex_value_from_rgb`, die drei Argumente entgegennimmt: `red`, `green` und `blue` vom Typ `Int32`.
Die Methode sollte den Hex-Wert der RGB-Farbe als `String` zurückgeben.

```crystal
FotoFusionist.hex_value_from_rgb(255, 0, 0)
# => "ff0000"
```
