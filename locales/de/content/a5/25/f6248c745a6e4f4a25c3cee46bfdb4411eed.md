# Überblick

Ein Dictionary (`dict`) in Python ist eine Datenstruktur, die [hashbare][term-hashable] _Schlüssel_ mit _Werten_ verknüpft und in anderen Programmiersprachen auch als größenveränderliche [Hashtabelle][hashtable-wikipedia], Hashmap oder [assoziatives Array][associative-array] bekannt ist.
Dictionaries sind der einzige in Python eingebaute [Mapping-Typ][mapping-types-dict].

`keys` müssen hashbar und innerhalb des Dictionaries eindeutig sein.
Als Schlüsseltypen kommen `number`s, `str`s oder `tuple`s (aus _unveränderlichen_ Werten) infrage.
Sie dürfen keine _veränderlichen_ Datenstrukturen wie `list`s, `dict`s oder `set`s enthalten.
Seit Python 3.7 ist garantiert, dass die Reihenfolge der `dict`-Schlüssel der Reihenfolge entspricht, in der die Einträge eingefügt wurden.

`values` können von jedem Datentyp oder jeder Struktur sein.
 Werte können außerdem _beliebig_ verschachtelt sein, sodass sie Listen von Listen, Unter-Dictionaries und andere benutzerdefinierte oder zusammengesetzte Datenstrukturen enthalten können.

Mit einem `key` kann ein Dictionary einen `value` in (durchschnittlich) konstanter Zeit abrufen (_unabhängig von der Anzahl der Einträge_).
Verglichen mit der Suche nach einem Wert in einer `list` oder einem `array` (_ohne die `index`-Position zu kennen_), benötigt ein `dict` deutlich mehr Speicher, ermöglicht aber einen sehr schnellen Zugriff.

Dictionaries sind besonders nützlich, wenn die Sammlung von Elementen groß ist und häufig darauf zugegriffen und aktualisiert werden muss.


## Dictionaries erstellen

Dictionaries lassen sich auf viele verschiedene Arten erstellen, zum Beispiel:
 - Mit der Klassenmethode [`fromkeys()`][fromkeys].
 - Mit [Dictionary-Comprehensions][dict-comprehensions].
 - Zusammenführen zweier Dictionaries durch Entpacken (`**`).
 - Zusammenführen von Dictionaries mit dem `|`-Operator (_Aktualisierung_).
 - Mit einer Schleife, um einem zuvor erstellten leeren `dict` schrittweise Einträge hinzuzufügen.

Die beiden direktesten Methoden sind der Dictionary-_Konstruktor_ und das Dictionary-_Literal_.

### Der Dictionary-Konstruktor

`dict()` (_der Konstruktor der `dict`-Klasse_) kann mit jedem Iterable von `key`-`value`-Paaren verwendet werden.
 Es kann auch mit einer Reihe von `<name>=<value>`-_Argumenten_ aufgerufen werden:

```python
# Passing a list of key,value tuples.
>>> wombat = dict([('name', 'Wombat'),
...              ('speed', 23),
...              ('land_animal', True)])
{'name': 'Wombat', 'speed': 23, 'land_animal': True}


# Using key=value arguments.
>>> bear = dict(name="Black Bear",
...             speed=40,
...             land_animal=True)
{'name': 'Black Bear', 'speed': 40, 'land_animal': True}
```

Die [Dokumentation zu `dict`s][dicts-docs] beschreibt weitere Varianten und Optionen bei der Verwendung des Konstruktors.


### Dictionary-Literale

Ein Dictionary kann auch direkt als _Dictionary-Literal_ geschrieben werden, wobei geschweifte Klammern (`{}`) die `key : value`-Paare umschließen.
Die Einträge innerhalb der `{}` können auch in separaten Zeilen stehen:

```python
>>> whale = {"name": "Blue Whale", 
             "speed": 35, 
             "land_animal": False}
{'name': 'Blue Whale', 'speed': 35, 'land_animal': False}

>>> wombat = {'name': 'Wombat',
              'speed': 23,
              'land_animal': True,
              'color': 'Brindle'}

>>> wombat
{'name': 'Wombat', 'speed': 23, 'land_animal': True, 'color': 'Brindle'}
```

Dictionaries können beliebig verschachtelt werden:

```python

        "Winged" : {

            "Wombat" : {'name': 'Wombat', 'speed': 23, 'land_animal': True},
            "Black Bear": {'name': 'Black Bear', 'speed': 40, 'land_animal': True},
            "Polecat" : {'name': 'Polecat', 'speed': 15, 'land_animal': True}
           },
        "Other" :  {
            "Whale" : {'name': 'Blue Whale', 'speed': 35, 'land_animal': False},
            "Orca" : {'name': 'Orca', 'speed': 45, 'land_animal': False},
            "Snake" : {'name': 'Python', 'speed': 25, 'land_animal': True}
            }
        },
        
    "Imaginary": {
        "Winged" : {
            "Dragon" : {'name': 'Fire Dragon','speed': 100, 'land_animal': True},

```

## Auf Werte in einem `dict` zugreifen

Du kannst in einem Dictionary mit einem _Schlüssel_ in eckigen Klammern auf einen `value` zugreifen.
Wenn ein Schlüssel nicht im Dictionary vorhanden ist, wird ein `KeyError` ausgelöst:

```python
>>> bear["speed"]
40

>>> bear["color"]
Traceback (most recent call last):
  File "<stdin>", line 1, in <module>
KeyError: 'color'
```

Der Zugriff auf einen Eintrag über die Methode `get(<key>, <default value>)` kann den `KeyError` vermeiden:

```python
>>> bear.get("color", 'not found')
'not found'
```

### Auf verschachtelte Dictionary-Einträge zugreifen

Um auf Einträge in verschachtelten Dictionaries zuzugreifen, verwendest du aufeinanderfolgende Klammern.
Wenn ein bestimmter Schlüssel fehlt, wird der übliche KeyError ausgelöst:

```python
# Using the animals nested dictionary.
>>> animals["Real"]["winged"]["Kestrel"]["speed"]
15

>>> animals["Imaginary"]["winged"]["Kestrel"]["speed"]
Traceback (most recent call last):
  File "<stdin>", line 1, in <module>
KeyError: 'Kestrel'
```

Um den `KeyError` zu vermeiden, kann `.get()` verwendet werden, aber die Aufrufe von `.get()` müssen _verkettet_ werden:

```python
# Using the animals nested dictionary.
# Note the use of parenthesis to enable placing the 
# .get() calls on separate lines.
>>> (animals.get("Imaginary", {})
            .get("Legged", {})
            .get("Sphinx", {})
            .get("Color", "I have no idea!"))
'I have no idea!'
```

## Dictionary-Werte ändern oder hinzufügen

Du kannst den `value` eines Eintrags ändern, indem du seinem _Schlüssel_ einen neuen Wert zuweist:

```python
# Assigning the value "Grizzly Bear" to the name key.
>>> bear["name"] = "Grizzly Bear"
{'name': 'Grizzly Bear', 'speed': 40, 'land_animal': True}

>>> whale["speed"] = 25
{'name': 'Blue Whale', 'speed': 25, 'land_animal': False}
```

Neue `key`:`value`-Paare können auf dieselbe Weise _hinzugefügt_ werden:

```python
# Adding a new "color" key with a new "tawney" value.
>>> bear["color"] = 'tawney'
{'name': 'Grizzly Bear', 'speed': 40, 'land_animal': True, 'color': 'tawney'}

>>> whale["blowholes"] = 1
{'name': 'Blue Whale', 'speed': 25, 'land_animal': False, 'blowholes': 1}
```


## Dictionary-Einträge entfernen (mit pop und del)

Mit der Methode `<dict>.pop(<key>)` kannst du einen Dictionary-Eintrag löschen.
`<dict>.pop()` entfernt das Paar (`key`, `value`) und gibt den `value` zurück, damit du ihn weiterverwenden kannst.
Wie `<dict>.get()` akzeptiert `<dict>.pop(<key>)` ein zweites Argument (_`<dict>.pop(<key>, <default value>)`_), das zurückgegeben wird, wenn der `key` nicht gefunden wird.
Dadurch wird verhindert, dass ein `KeyError` ausgelöst wird:

```python
# Using .pop() removes both the key and value, returning the value.
>>> bear.pop("name")
'Grizzly Bear'


# The "name" key is now removed from the dictionary.
# Attempting .pop() a second time will throw a KeyError.
>>> bear.pop("name")
Traceback (most recent call last):
  File "<stdin>", line 1, in <module>
KeyError: 'name'


# Using a default argument with .pop() will 
# prevent a KeyError from a missing key.
>>> bear.pop("name", "Unknown")
'Unknown'
```

Du kannst auch die `del`-Anweisung verwenden, um einen oder mehrere Einträge zu entfernen.
Ein `KeyError` wird ausgelöst, wenn der zu entfernende Eintrag nicht im Dictionary gefunden wird:

```python
>>> wombat = {'name': 'Wombat',
              'speed': 23,
              'land_animal': True,
              'color': 'Brindle',
              'talent': 'Singing',
              'size': 'small'}

# Remove a single entry from the dictionary.
>>> del wombat["color"]
>>> wombat
{'name': 'Wombat', 'speed': 23, 'land_animal': True, 'talent': 'Singing', 'size': 'small'}


# Remove multiple entries from the dictionary.
>>> del wombat["talent"], wombat["size"]
>>> wombat
{'name': 'Wombat', 'speed': 23, 'land_animal': True}


# Attempting a deletion of a non-existent key raises a KeyError
>>> del wombat["number_of_legs"]
Traceback (most recent call last):
  File "<stdin>", line 1, in <module>
KeyError: 'number_of_legs'
```

## Ein Dictionary durchlaufen/iterieren

Wenn du ein Dictionary mit `for item in dict` oder `while item` durchläufst, wird standardmäßig über die _Schlüssel_ iteriert.
Du kannst innerhalb derselben Schleife mit _eckigen Klammern_ auf die _Werte_ zugreifen:

```python
>>> for key in bear:
...     print((key, bear[key])) # <--This prints a tuple of (key, value).
('name', 'Black Bear')
('speed', 40)
('land_animal', True)
```

Du kannst auch die Methode `.items()` verwenden, die Tupel aus (`key`, `value`) zurückgibt:

```python
# dict.items() forms (key, value tuples) that can be 
# unpacked and iterated over.
>>> for key, value in whale.items():
...     print(key, ":", value)
name : Blue Whale
speed : 25
land_animal : False
blowholes : 1
```

Ebenso gibt `.keys()` die `keys` und `.values()` die `values` zurück.

## Dictionary-Funktionalität erweitern: das collections-Modul

Das Modul [`collections`][collections-docs] fügt den standardmäßigen sammlungsbasierten Datentypen von Python (`dict`, `set`, `list`, `tuple`) spezialisierte Funktionalität hinzu.
Drei der nützlichsten Dictionary-basierten Klassen sind:

- [`Counter`][counter-dicts] zählt Elemente automatisch und gibt sie in einem `dict` zurück, wobei die Elemente die Schlüssel und ihre Anzahlen die Werte sind.
- [`OrderedDict`][ordered-dicts-docs] hat spezialisierte Methoden, um die Reihenfolge von Dictionary-Einträgen festzulegen.
- [`defaultdict`][default-dicts] verwendet eine Factory-Methode, um einen Standardwert festzulegen, wenn ein `key` beim Abrufen oder Zuweisen eines Dictionary-Eintrags nicht gefunden wird.
