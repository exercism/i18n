# Tests

## Den Test-Runner für den GDScript-Track von Exercism installieren

Um den Test-Runner zu verwenden, musst du [Godot korrekt installiert][installation] haben.

Um GDScript-Skripte für Exercism zu bauen und zu testen, startest du Godot über die Kommandozeile im „headless“-Modus.
Diese Anleitung setzt derzeit Linux und bash voraus.

### Schritt 1: Die gesamte Test-Runner-Infrastruktur installieren

Um alles fürs Testen einzurichten, klone [https://github.com/exercism/gdscript-test-runner][gdscript-test-runner] und verschiebe den Inhalt nach `/opt/test-runner/`:

```sh
git clone https://github.com/exercism/gdscript-test-runner.git
sudo mkdir -p /opt/
sudo mv gdscript-test-runner/ /opt/test-runner/
```

### Schritt 2: Das Test-Runner-Skript für eine einzelne Übung herunterladen

Wenn du das `exercism`-Tool eingerichtet und mindestens eine GDScript-Übung heruntergeladen hast, sollte ein Ordner `exercism/gdscript` angelegt worden sein, in dem die Übungen liegen.
Speichere [den Test-Runner][test-local-gdscript-solution] in diesem Ordner und markiere die Datei als ausführbar, oder erstelle einfach einen Link darauf:

```sh
cd ~/exercism/gdscript # replace with your exercism/gdscript directory
ln /opt/test-runner/bin/test-local-gdscript-solution.sh
```

## Tests ausführen

Wenn du die Installationsschritte abgeschlossen hast, kannst du aus jedem Übungsverzeichnis (z. B. `~/exercism/gdscript/two-fer`) starten und das Skript (eine Ebene höher, in `../`) ausführen, um deine lokale Lösung für diese Übung zu testen:

```sh
../test-local-gdscript-solution.sh
```
