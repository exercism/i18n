# Anleitung

Refaktoriere einen Hauptbuchdrucker.

Die Übung zum Hauptbuch ist eine Refactoring-Übung.
Es gibt Code, der ein schön formatiertes Hauptbuch ausgibt, und zwar für ein Locale (amerikanisch oder niederländisch) und eine Währung (US-Dollar oder Euro).
Der Code ist allerdings ziemlich schlecht geschrieben, besteht aber (etwas überraschend) durchgängig die Testsuite.

Schreib diesen Code neu.
Denk daran: Beim Refactoring kommt es darauf an, kleine Schritte zu machen, damit die Tests weiterhin bestehen.
So kannst du jederzeit schnell zu einer funktionierenden Version zurückkehren.
Versionskontrollwerkzeuge wie git können dir dabei ebenfalls helfen.

Führe bitte ein Protokoll darüber, welche Änderungen du vorgenommen hast, und schreib einen Kommentar zur Übung, der dieses Protokoll enthält. Das hilft den Reviewern.
