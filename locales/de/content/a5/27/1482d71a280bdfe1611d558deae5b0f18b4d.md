# Ergänzung zu den Anweisungen

## Reservierter Speicher

Der Puffer für den Eingabe-String verwendet die Bytes 64 bis 191 des linearen Speichers.

## Eingabeformat

Die Eingabe ist als einzelner String aus drei Zeilen formatiert, wobei am Ende jeder Zeile ein Zeilenumbruch steht. Kreuze und Kreise sind immer die Großbuchstaben `X` und `O`.

Das Spielfeld

```
X··
OXO
XOX
```
wird also so kodiert:

```
"X  \nOXO\nXOX\n"
```
