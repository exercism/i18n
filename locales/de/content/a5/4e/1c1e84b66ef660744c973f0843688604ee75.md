# Einführung

JavaScript ist eine dynamische Sprache und unterstützt objektorientierte, imperative und deklarative Stile (z. B. funktionale Programmierung).

## (Neu-)Zuweisung

Es gibt einige grundlegende Möglichkeiten, in JavaScript Werten Namen zuzuweisen: über Variablen oder Konstanten. Bei Exercism werden Variablen immer in [camelCase][wiki-camel-case] geschrieben, Konstanten in [SCREAMING_SNAKE_CASE][wiki-snake-case]. Es gibt keinen offiziellen Leitfaden, an den man sich halten muss, und verschiedene Unternehmen und Organisationen haben unterschiedliche Styleguides. _Du kannst Variablen so schreiben, wie du möchtest_. Der Vorteil, sie so zu schreiben, wie es die Übungen vorgeben, ist, dass sie in der Weboberfläche und in den meisten IDEs anders hervorgehoben werden.

Variablen lassen sich in JavaScript mit den Schlüsselwörtern [`const`][mdn-const], [`let`][mdn-let] oder [`var`][mdn-var] definieren.

Bei Verwendung von `let` oder `var` kann eine Variable im Laufe ihres Lebens auf verschiedene Werte verweisen. Zum Beispiel lässt sich `myFirstVariable` mit dem Zuweisungsoperator `=` beliebig oft definieren und neu zuweisen:

```javascript
let myFirstVariable = 1;
myFirstVariable = 'Some string';
myFirstVariable = new SomeComplexClass();
```

Im Gegensatz zu `let` und `var` lassen sich Variablen, die mit `const` definiert werden, nur einmal zuweisen. So werden in JavaScript Konstanten definiert.

```javascript
const MY_FIRST_CONSTANT = 10;

// Cannot be re-assigned.
MY_FIRST_CONSTANT = 20;
// => TypeError: Assignment to constant variable.
```

> 💡 In einer späteren Lernübung wird der Unterschied zwischen der Zuweisung bzw. Bindung an eine _Konstante_ und einem _konstanten_ Wert untersucht und erklärt.

## Funktionsdeklarationen

In JavaScript werden Funktionseinheiten in _Funktionen_ gekapselt. Funktionen, die zusammengehören, werden meist in derselben Datei gebündelt. Diese Funktionen können Parameter (Argumente) entgegennehmen und mit dem Schlüsselwort `return` einen Wert _zurückgeben_. Funktionen werden mit der `()`-Syntax aufgerufen.

```javascript
function add(num1, num2) {
  return num1 + num2;
}

add(1, 3);
// => 4
```

> 💡 In JavaScript gibt es _viele_ verschiedene Wege, eine Funktion zu deklarieren. Diese anderen Wege sehen anders aus als die Verwendung des Schlüsselworts `function`. Der Track versucht, sie nach und nach einzuführen. Wenn du sie aber schon kennst, kannst du jeden davon verwenden. In den meisten Fällen ist die eine oder andere Variante nicht besser oder schlechter.

## Für andere Dateien bereitstellen

Damit eine `function`, eine Konstante oder eine Variable in _anderen Dateien_ verfügbar ist, muss sie mit dem Schlüsselwort `export` [exportiert][mdn-export] werden. Eine andere Datei kann sie dann mit dem Schlüsselwort `import` [importieren][mdn-import]. Man nennt das auch das Modulsystem. Ein gutes Beispiel dafür ist, wie alle Tests funktionieren. Jede Übung hat mindestens eine Datei, zum Beispiel `lasagna.js`, die die _Implementierung_ enthält. Darüber hinaus gibt es mindestens eine weitere Datei, zum Beispiel `lasagna.spec.js`, die die _Tests_ enthält. Diese Datei _importiert_ die öffentlichen (also exportierten) Einheiten, um die Implementierung zu testen:

```javascript
// file.js
export const MY_VALUE = 10;

export function add(num1, num2) {
  return num1 + num2;
}

// file.spec.js
import { MY_VALUE, add } from './file';

add(MY_VALUE, 5);
// => 15
```
