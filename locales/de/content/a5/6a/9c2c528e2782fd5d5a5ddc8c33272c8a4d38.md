# Einführung

Zeichen sind in Factor Ganzzahlen, genauer Unicode-Codepunkte. Deshalb liefern dir die numerischen Vergleiche `<`, `>`, `=` direkt eine Sortierung, die Groß- und Kleinschreibung beachtet. Das Vokabular [`unicode`][unicode] fügt Unicode-fähige Prädikate und die Umwandlung der Schreibweise einzelner Zeichen hinzu.

## Zeichenprädikate

```
LETTER?  ( c -- ? )    ! uppercase letter
letter?  ( c -- ? )    ! lowercase letter
Letter?  ( c -- ? )    ! letter, either case
digit?   ( c -- ? )    ! decimal digit
digit>   ( c -- n )    ! the integer value of a digit char
blank?   ( c -- ? )    ! whitespace
```

```factor
USING: unicode ;

CHAR: A LETTER? .    ! => t
CHAR: a letter? .    ! => t
CHAR: 7 digit?  .    ! => t
CHAR: 7 digit>  .    ! => 7
```

## Umwandlung der Schreibweise

`ch>upper` und `ch>lower` ändern die Schreibweise eines einzelnen Zeichens. Die String-Operatoren `>upper` und `>lower` wenden sie auf jedes Zeichen eines Strings an.

```factor
CHAR: a ch>upper .   ! => 65   (which is CHAR: A)
"Hello" >upper .     ! => "HELLO"
```

`capitalize` wandelt einen ganzen String in Kleinbuchstaben um und setzt anschließend das erste Zeichen in Großbuchstaben. Das ergibt die Titelschreibweise eines einzelnen Wortes:

```factor
"hELLO" capitalize .   ! => "Hello"
```

## Zeichenliterale

`CHAR: A` wird zum ganzzahligen Codepunkt von `A` ausgewertet. Für benannte Zeichen verwendest du die Namen `space`, `tab`, `\n` usw.:

```factor
CHAR: A .        ! => 65
CHAR: space .    ! => 32
CHAR: \n .       ! => 10
```

## Symbole

Wenn ein Wort statt eines Werts ein Tag zurückgeben soll, zum Beispiel `yes`/`no`/`maybe` statt eines booleschen Werts, dann deklariere jedes Tag als *Symbol*. Ein Symbol ist ein Wort, das sich selbst auf den Stack legt, wenn es aufgerufen wird. Zwei Symbole sind nur dann gleich, wenn sie denselben Namen haben.

```factor
USING: kernel ;

SYMBOLS: yes no maybe ;

yes .    ! => yes
yes yes = .    ! => t
yes no = .     ! => f
```

`SYMBOL: name` deklariert eines, `SYMBOLS: a b c ;` deklariert mehrere.
