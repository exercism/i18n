# Referenzen und Snapshots

Wenn du eine Variable an eine Funktion übergibst, wird ihr Ownership normalerweise übertragen, wodurch die ursprüngliche Variable unbrauchbar wird. Das kann etwas mühsam werden, wenn du mehr als einmal auf einen Zustand zugreifst.
Cairo hat zwei Sprachmittel, um einen Wert zu übergeben, ohne ihn zu zerstören oder zu verschieben: `references` und `snapshots`.

## Snapshots

Snapshots bieten eine unveränderliche Sicht auf einen Wert zu einem bestimmten Zeitpunkt. So behältst du das Ownership einer Variable, während du auf ihren Zustand zugreifst.
Jede Änderung an der Variable erzeugt eine neue Speicherzelle, und die Sicht des Snapshots bleibt unverändert.

```rust
fn get_len(arr: @Array<u128>) -> u32 { // this parameter takes in a snapshot using `@` with the data-type
    arr.len()
}

fn foo(arr: Array<u128>) {
    arr.pop_front();
}

fn main() {
    let mut new_arr: Array<u128> = array![1, 2, 3, 4, 5, 6, 7, 8];
    let snapshot = @new_arr; // using `@` to create a snapshot of a variable
    let len = get_len(snapshot); // pass the snapshot as argument, retaining ownership
    foo(new_arr); // `new_arr` is still valid up until here and no further

    // let new_len = new_arr.len(); // this would throw an error if you uncommented the code because `new_arr` has been moved when it was passed into `foo()` above
}
```

## Der Desnap-Operator

Um einen Snapshot wieder in eine reguläre Variable umzuwandeln, kannst du den Desnap-Operator `*` verwenden. Er ist das Gegenstück zum `@`-Operator.
Nur Typen, die das `Copy`-Trait implementieren, lassen sich desnapen.

```rust
#[derive(Drop)]
struct Rectangle {
    height: u64,
    width: u64,
}

fn main() {
    let rec = Rectangle { height: 3, width: 10 };
    let area = calculate_area(@rec);
    println!("Area: {}", area);
}

fn calculate_area(rec: @Rectangle) -> u64 {
    // We need to transform the snapshots back into values using the desnap operator `*`.
    // Here we use `*` to both multiply the height and width and to desnap the snapshots.
    *rec.height * *rec.width
}
```

## Veränderbare Referenzen

Veränderbare Referenzen ermöglichen es dir, veränderbare Werte an eine Funktion zu übergeben, die dann implizit zurückgegeben werden, wobei das Ownership im aufrufenden Kontext erhalten bleibt.
Das erreichst du mit dem `ref`-Modifizierer, sofern die Variable mit dem Schlüsselwort `mut` als veränderbar deklariert ist.

```rust
fn foo(ref arr: Array<u128>) { // using `ref` marks the argument as a mutable reference
    arr.pop_front(); // modifies the state of arr
}

fn main() {
    let mut new_arr: Array<u128> = array![1, 2, 3, 4, 5, 6, 7, 8];

    foo(ref new_arr);  // use `ref` to pass a mutable reference to the function

    let new_len = new_arr.len();  // the current context retains ownership of `new_arr`, so we can still use it
}
```
