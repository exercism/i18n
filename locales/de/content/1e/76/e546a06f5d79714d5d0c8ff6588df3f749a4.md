# Ergänzung zu den Anweisungen

## Ausnahmemeldungen

Manchmal ist es nötig, [eine Ausnahme auszulösen](https://docs.python.org/3/tutorial/errors.html#raising-exceptions). Dabei solltest du immer eine **aussagekräftige Fehlermeldung** angeben, die zeigt, woher der Fehler stammt. Das macht deinen Code lesbarer und hilft beim Debugging erheblich weiter. Wenn du weißt, dass die Fehlerquelle von einem bestimmten Typ ist, kannst du eine der [eingebauten Fehlertypen](https://docs.python.org/3/library/exceptions.html#base-classes) auslösen, solltest aber trotzdem eine aussagekräftige Meldung angeben.

In dieser Übung musst du die [raise-Anweisung](https://docs.python.org/3/reference/simple_stmts.html#the-raise-statement) verwenden, um einen `ValueError` zu „werfen“, wenn die Parameter series und/oder length, die in die Funktion `slice()` eingegeben werden, leer sind oder außerhalb des gültigen Bereichs liegen. Die Tests bestehen nur, wenn du beides tust: die `exception` mit `raise` auslösen und eine Meldung dazu angeben.

Um einen `ValueError` mit einer Meldung auszulösen, übergib die Meldung als Argument an den Typ `exception`:

```python
# if the slice length is zero.
raise ValueError("slice length cannot be zero")

# if the slice length is negative.
raise ValueError("slice length cannot be negative")

# if the series provided is empty.
raise ValueError("series cannot be empty")

# if the slice length is longer than the series.
raise ValueError("slice length cannot be greater than series length")
```
