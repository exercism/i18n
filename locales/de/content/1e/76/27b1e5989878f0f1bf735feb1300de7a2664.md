# Anleitung

Erstelle eine Implementierung der Atbash-Chiffre, eines alten Verschlüsselungssystems aus dem Nahen Osten.

Die Atbash-Chiffre ist eine einfache Substitutionschiffre, bei der alle Buchstaben des Alphabets so vertauscht werden, dass das entstehende Alphabet rückwärts läuft.
Der erste Buchstabe wird durch den letzten ersetzt, der zweite durch den vorletzten und so weiter.

Eine Atbash-Chiffre für das lateinische Alphabet sieht so aus:

```text
Plain:  abcdefghijklmnopqrstuvwxyz
Cipher: zyxwvutsrqponmlkjihgfedcba
```

Sie ist eine sehr schwache Chiffre, denn sie hat nur einen möglichen Schlüssel und ist eine einfache monoalphabetische Substitutionschiffre.
Zu ihrer Zeit war das allerdings möglicherweise kein Problem.

Der Geheimtext wird in Gruppen fester Länge geschrieben, wobei die traditionelle Gruppengröße 5 Buchstaben beträgt. Zahlen bleiben unverändert und Satzzeichen werden weggelassen.
Das macht es schwerer, anhand von Wortgrenzen zu raten.
Der gesamte Text wird als Kleinbuchstaben kodiert.

## Beispiele

- Die Kodierung von `test` ergibt `gvhg`
- Die Kodierung von `x123 yes` ergibt `c123b vh`
- Die Dekodierung von `gvhg` ergibt `test`
- Die Dekodierung von `gsvjf rxpyi ldmul cqfnk hlevi gsvoz abwlt` ergibt `thequickbrownfoxjumpsoverthelazydog`
