# Anweisungen

Die Abteilung für Landansprüche von Isaac's Asteroid Exploration Co. hat dich damit beauftragt, die Leistung ihres Systems für Landansprüche zu verbessern.

Jedes Mal, wenn ein Asteroid zur Ausbeutung bereitsteht, werden Spekulanten eingeladen, ihren Anspruch auf eine Parzelle abzustecken.
Das Land des Asteroiden ist in nicht überlappende rechteckige Parzellen unterteilt.
Die Abmessungen sind unterschiedlich, aber alle haben Seiten, die parallel zu den Koordinatenachsen verlaufen.
Spekulanten beanspruchen eine der Parzellen, indem sie ihre Koordinaten angeben.

Dein Ziel ist es, ein leistungsfähiges System zu entwickeln, das den Ansturm auf das Land bewältigt, der in der Vergangenheit die Website zum Absturz gebracht hat.

Die Maßeinheit ist 100 Meter, kann in diesen Aufgaben aber ignoriert werden.

## 1. Definiere einen Punkt

Definiere ein `struct`, das die Koordinaten `x` und `y` enthält.
Das sind recht kleine, nicht-negative Ganzzahlen, also verwende den Typ `UInt16`.

```julia-repl
julia> Coord(7, 3)
Coord(0x0007, 0x0003)  # unsigned integers display in hex format by default
```

## 2. Definiere Plot

Da alle Parzellen rechteckig sein müssen und waagerechte sowie senkrechte Seiten haben, werden nur zwei gegenüberliegende Ecken benötigt, um sie zu definieren.

Implementiere die `Plot`-Struktur, die zwei Coord-Strukturen in ihrem Konstruktor entgegennimmt.

`Plot` sollte ein Keyword-Struct sein, mit den Feldern `bottom_left` und `top_right`.

```julia-repl
julia> plot = Plot(bottom_left=Coord(10, 1), top_right=Coord(20, 2))
Plot(Coord(0x000a, 0x0001), Coord(0x0014, 0x0002))

julia> plot.top_right
Coord(0x0014, 0x0002)
```

## 3. Prüfe, ob dein Anspruch bereits abgesteckt wurde

Um diese Ansprüche gibt es Konkurrenz. Bevor dein Anspruch zugelassen wird, wird er mit den bestehenden Ansprüchen im Register abgeglichen.

Implementiere die Funktion `is_claim_staked()`, um festzustellen, ob ein Anspruch bereits abgesteckt wurde.

```julia-repl
julia> claim = Plot(bottom_left=Coord(10, 1), top_right=Coord(20, 2));
julia> register = Set{Plot}();
julia> is_claim_staked(claim, register)
false
```

## 4. Spekulanten können ihren Anspruch abstecken, indem sie eine Parzelle anhand ihrer Eckkoordinaten angeben

Implementiere die mutierende Funktion `stake_claim!()`, damit ein Anspruch registriert werden kann.

Wenn derselbe Anspruch bereits abgesteckt wurde, gib `false` zurück.

Wenn ein neuer Anspruch möglich ist, füge ihn dem Register hinzu und gib `true` zurück.

```julia_repl
julia> claim = Plot(bottom_left=Coord(10, 1), top_right=Coord(20, 2));
julia> register = Set{Plot}();
julia> stake_claim!(claim, register)
true
```

## 5. Finde die Länge der längeren Seite einer Parzelle

Implementiere die Funktion `get_longest_side()`, um die längere Seite (waagerecht oder senkrecht) eines Anspruchs zu ermitteln.

```julia-repl
claim = Plot(bottom_left=Coord(10, 1), top_right=Coord(20, 2));

julia> get_longest_side(claim)
0x000a
```

## 6. Finde zu Forschungszwecken die beanspruchte Parzelle mit der längsten Seite

Implementiere die Funktion `get_claim_with_longest_side()`, um alle registrierten Ansprüche zu untersuchen und den bzw. die Ansprüche mit der längsten Seite zurückzugeben.

```julia-repl
julia> plot1 = Plot(bottom_left=Coord(5, 3), top_right=Coord(10, 5));
julia> plot2 = Plot(bottom_left=Coord(0, 0), top_right=Coord(3, 3));
julia> register = Set{Plot}([plot1, plot2]);

julia> get_claim_with_longest_side(register)
Plot(Coord(0x0005, 0x0003), Coord(0x000a, 0x0005))
```

Gib die Plots als `Set` zurück, mit einem Element, wenn es nur eine längste Parzelle gibt, und mehreren bei einem Gleichstand.
