# Einführung

In R gibt es keinen eigenen Typ für [Mengen][wiki-set]. Stattdessen verwendet R verschiedene Funktionen, um ähnliche Operationen auf Vektoren auszuführen.

Der Operator [`%in%`][ref-match] prüft die Zugehörigkeit zu einer Menge.
Dieser Infix-Operator ist ein Synonym für die Funktion `is.element()`.

```R
2 %in% 1:10 # TRUE
12 %in% 1:10 # FALSE
```

Zu den relevanten Funktionen gehören:

- [`unique()`][ref-unique] zum Entfernen von Duplikaten.
- [`union()`][ref-sets] zum Kombinieren von Mengen (mathematisch: `A ∪ B`).
- [`intersect()`][ref-sets] um Elemente zu finden, die in beiden Mengen vorkommen (`A ∩ B`).
- [`setdiff()`][ref-sets] um eine Menge von einer anderen abzuziehen (`A - B`).
- [`setequal`][ref-sets] um Mengengleichheit zu prüfen, ohne Duplikate und Reihenfolge zu berücksichtigen.

```R
> set_1 <- c("a", "b", "c", "b", "a")
> unique(set_1) # deduplicate
[1] "a" "b" "c"

> set_2 <- c('a', "c", "d")
> union(set_1, set_2) # values in either set
[1] "a" "b" "c" "d"

> intersect(set_1, set_2) # values in both sets
[1] "a" "c"

> setdiff(set_1, set_2) # values in set_1 but not set_2
[1] "b"

> setdiff(set_2, set_1) # values in set_2 but not set_1
[1] "d"

setequal(set_1, c("c", "b", "a", "b")) # are elements the same after deduplication?
[1] TRUE
```

In jedem Fall gibt die Funktion eine Kopie zurück und lässt die Argumente unverändert.

## Hash-Tabellen

Die oben beschriebenen Vektoroperationen gehören zu base R.
Für kleine Probleme sind sie nützlich, bei großen Mengen werden sie jedoch langsam.

Verschiedene Pakete von Drittanbietern implementieren [Hash-Tabellen][wiki-hash], um die Leistung in manchen Fällen zu verbessern.

Zum Beispiel bietet das Paket [`hashtable`][ref-hashtable] Implementierungen von `hashmap` und `hashset` an, die besser skalieren.
Wie die meisten externen Pakete ist das in Exercism nicht verfügbar, aber für reale Probleme lohnt es sich, einen Blick darauf zu werfen.
