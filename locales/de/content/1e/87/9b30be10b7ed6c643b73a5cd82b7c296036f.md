# Anleitung

In dieser Übung organisierst du Rennen zwischen verschiedenen Arten von ferngesteuerten Autos. Jedes Auto hat seine eigene Geschwindigkeit und seinen eigenen Batterieverbrauch.

Autos starten mit einer vollen Batterie (100 %). Jedes Mal, wenn du das Auto mit der Fernbedienung fährst, legt es die Geschwindigkeit des Autos in Metern zurück und verringert den verbleibenden Batteriestand in Prozent um seinen Batterieverbrauch.

Wenn der Batteriestand eines Autos unter dem Prozentsatz seines Batterieverbrauchs liegt, kannst du das Auto nicht mehr fahren.

Jede Rennstrecke hat ihre eigene Länge. Autos werden getestet, indem geprüft wird, ob sie die Strecke beenden können, ohne dass die Batterie leer wird.

Du hast sechs Aufgaben, die jeweils mit Instanzen von ferngesteuerten Autos arbeiten.

## 1. Ein ferngesteuertes Auto erstellen

Ermögliche das Erstellen eines ferngesteuerten Autos, indem du einen Konstruktor für die Klasse `RemoteControlCar` definierst, der die Geschwindigkeit des Autos in Metern und den Batterieverbrauch in Prozent als seine beiden Parameter (beide vom Typ `int`) entgegennimmt:

```csharp
int speed = 5;
int batteryDrain = 2;
var car = new RemoteControlCar(speed, batteryDrain);
```

## 2. Eine Rennstrecke erstellen

Ermögliche das Erstellen einer Rennstrecke, indem du einen Konstruktor für die Klasse `RaceTrack` definierst, der die Länge der Strecke in Metern als einzigen Parameter (vom Typ `int`) entgegennimmt:

```csharp
int distance = 800;
var raceTrack = new RaceTrack(distance);
```

## 3. Das Auto fahren

Implementiere die Methode `RemoteControlCar.Drive()`, die die Anzahl der gefahrenen Meter basierend auf der Geschwindigkeit des Autos aktualisiert. Implementiere außerdem die Methode `RemoteControlCar.DistanceDriven()`, die die Anzahl der vom Auto gefahrenen Meter zurückgibt:

```csharp
int speed = 5;
int batteryDrain = 2;
var car = new RemoteControlCar(speed, batteryDrain);
car.Drive();

car.DistanceDriven();
// => 5
```

## 4. Eine leere Batterie erkennen

Passe die Methode `RemoteControlCar.Drive()` an, sodass sie die Batterie entsprechend dem Batterieverbrauch des Autos entlädt. Implementiere außerdem die Methode `RemoteControlCar.BatteryDrained()`, die angibt, ob die Batterie leer ist:

```csharp
int speed = 5;
int batteryDrain = 2;
var car = new RemoteControlCar(speed, batteryDrain);
car.Drive();

car.BatteryDrained();
// => false
```

## 5. Das ferngesteuerte Nitro-Auto erstellen

Das meistverkaufte ferngesteuerte Auto ist das Nitro. Es hat eine beeindruckende Höchstgeschwindigkeit von 50 Metern bei einem Batterieverbrauch von 4 %. Implementiere die (statische) Methode `RemoteControlCar.Nitro()`, die diesen Autotyp zurückgibt:

```csharp
var car = RemoteControlCar.Nitro();
car.Drive();
car.DistanceDriven();
// => 50
```
## 6. Prüfen, ob ein ferngesteuertes Auto ein Rennen beenden kann

Um eine Rennstrecke zu beenden, muss ein Auto die Länge der Strecke fahren können. Das bedeutet, dass seine Batterie nicht leer sein darf, bevor es die Ziellinie überquert hat. Implementiere die Methode `RaceTrack.TryFinishTrack()`, die eine Instanz von `RemoteControlCar` als Parameter entgegennimmt und `true` zurückgibt, wenn das Auto die Rennstrecke beenden kann; andernfalls gib `false` zurück:

```csharp
int speed = 5;
int batteryDrain = 2;
var car = new RemoteControlCar(speed, batteryDrain);

int distance = 100;
var raceTrack = new RaceTrack(distance);

raceTrack.TryFinishTrack(car);
// => true
```
