# Überblick

Swift bietet drei grundlegende Schleifenkonstrukte:

- **`while`-Schleifen**: Wiederholen einen Codeblock, solange eine angegebene Bedingung `true` bleibt. Die Bedingung wird ausgewertet, bevor der Schleifenblock ausgeführt wird.
- **`repeat-while`-Schleifen**: Ähnlich wie `while`-Schleifen, aber die Bedingung wird ausgewertet, nachdem der Schleifenblock ausgeführt wurde. So wird garantiert, dass der Codeblock mindestens einmal ausgeführt wird.
- **`for-in`-Schleifen**: Führen einen Codeblock einmal für jedes Element in einer Sequenz oder Sammlung aus (etwa einem Bereich, einem Array oder einem String).
