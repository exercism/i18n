# Über

## Bitweise Operationen

### 32-Bit-Ganzzahlen in Elm verstehen

In Elm werden Ganzzahlen als vorzeichenbehaftete 32-Bit-Ganzzahlen in [Zweierkomplement](https://en.wikipedia.org/wiki/Two%27s_complement)-Darstellung gespeichert, was bedeutet, dass sie 32 Binärziffern (_Bits_) verwenden, um jeden Ganzzahlwert zu speichern.
Diese Bit-Begrenzung wirkt sich auf den Bereich der Ganzzahlen aus, die Elm direkt darstellen kann:

Positiver Bereich: 0 bis 2<sup>31</sup> - 1 (oder 0 bis 2.147.483.647)
Negativer Bereich: -2<sup>31</sup> bis -1 (oder -2.147.483.648 bis -1).

Zum Beispiel wird die Ganzzahl `5` binär als `00000000000000000000000000000101` dargestellt, obwohl wir normalerweise die führenden Nullen ignorieren und einfach `101` sagen.

### Bitweise Operatoren

Elm bietet mehrere bitweise Operatoren in seinem [Bitwise-Modul](https://package.elm-lang.org/packages/elm/core/latest/Bitwise)

## Grundlegende Operationen

Das Ändern einzelner Bits einer Zahl nennt man _Maskierung_.
Eine _Maske_ ist eine Zahl, bei der spezifische Bits auf eine bestimmte Weise gesetzt wurden, um eine andere Zahl mit bitweisen Operatoren wie `and`, `or` und `xor` zu manipulieren.

### and

`and` kombiniert zwei Zahlen, indem nur die Bits beibehalten werden, die in beiden `1` sind.
Das ist nützlich, um zu prüfen, ob ein einzelnes Bit gesetzt ist.
Um beispielsweise zu prüfen, ob das 4. Bit einer Zahl auf `1` gesetzt ist, verknüpfe sie mit `and` und einer Maske von `01000` (`8` im Dezimalsystem) und prüfe, ob das Ergebnis ungleich Null ist:

```elm
Bitwise.and 13 8 --> 8
--  13 = 01101
--   8 = 01000
-- and = 01000 = 8
```

### or

`or` kombiniert zwei Zahlen, indem jedes Bit auf `1` gesetzt wird, wenn es in einer oder beiden Zahlen `1` ist.
Das ist nützlich, um ein bestimmtes Bit auf `1` zu setzen.
Um beispielsweise das 2. Bit in `10101` zu setzen, verknüpfe es mit `or` und der Maske `00010`:

```elm
Bitwise.or 21 2 --> 23
-- 21 = 10101
--  2 = 00010
-- or = 10111 = 23
```

### Exklusiv-Oder (xor)

`xor` kombiniert zwei Zahlen, indem jedes Bit auf `1` gesetzt wird, wenn es in einer Zahl `1` ist, aber in der anderen `0`.
Das ist nützlich, um ein Bit in seinen entgegengesetzten Wert umzukehren:

```elm
Bitwise.xor 20 5 --> 17
--  20 = 10100
--   5 = 00101
-- xor = 10001 = 17
```

### Komplement

`complement` invertiert jedes Bit einer Zahl (`0` wird zu `1`, `1` wird zu `0`).

Beachte, dass dadurch positive Zahlen negativ und negative Zahlen positiv werden.
Das liegt daran, dass negative Zahlen im Binärsystem mit `1` an der am weitesten links stehenden Position dargestellt werden.

```elm
Bitwise.complement 21 --> -22
--         21 = 00000000000000000000000000010101
-- complement = 11111111111111111111111111101010 = -22
```

### Bitverschiebung

Die folgenden Operatoren verschieben Bits um eine bestimmte Anzahl von Positionen nach links oder rechts, was effektiv einer Multiplikation oder Division mit Zweierpotenzen entspricht.

`shiftLeftBy` verschiebt Bits nach links und füllt von der rechten Seite mit `0` auf.
Um beispielsweise `21` um 3 Stellen nach links zu verschieben:

```elm
Bitwise.shiftLeftBy 3 21 --> 168
--  21 = 10101
-- shiftLeftBy 3 = 10101000 = 168
```

Das ist dasselbe wie `21 * 2^3 = 21 * 2 * 2 * 2 = 168`

`shiftRightBy`: Verschiebt Bits nach rechts:

```elm
Bitwise.shiftRightBy 2 21 --> 5
--  21 = 10101
-- shiftRightBy 2 = 00101 = 5
```

Eine Verschiebung um 2 Stellen nach rechts entspricht einer ganzzahligen Division durch 4.

Beachte, dass diese Funktion den Wert des am weitesten links stehenden Bits dupliziert.
Negative Zahlen bleiben also negativ:

```elm
Bitwise.shiftRightBy 3 -21 --> -3
--  -21 = 111...101011
-- shiftRightBy 3 = 111...11101 = -3
```

Wenn du nach rechts verschieben und mit Nullen auffüllen möchtest, verwende `shiftRightZfBy`:

```elm
Bitwise.shiftRightZfBy 3 -21 --> 536870909
--  -21 = 111...101011
-- shiftRightZfBy 3 = 00111...11101 = 536870909
```
