# Installation

Mit der [Godot Engine][godot-engine] wird GDScript-Code ausgeführt.
Die Godot Engine läuft unter Windows, Linux, macOS und Android.

## Godot Engine installieren

Die Godot Engine kannst du direkt von [der Godot-Engine-Website][godot-engine] herunterladen.
Der Download enthält eine einzelne ausführbare Datei, die nach der Version der Godot Engine benannt ist.
Diese Datei muss in `godot` umbenannt und in einem der `$PATH`-Verzeichnisse abgelegt werden.
Nach der Installation kannst du prüfen, ob die Kommandozeile erfolgreich installiert wurde, indem du diesen Befehl in einem Terminal ausführst:

```bash
godot --version
```

Dieser Track verwendet Godot in Version 4.7.2.
