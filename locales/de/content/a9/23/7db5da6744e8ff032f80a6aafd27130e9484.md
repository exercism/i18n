# Einführung

## Arrays

In Ruby sind **Arrays** geordnete, ganzzahlig indizierte Sammlungen beliebiger Objekte.
Die Indizierung von Arrays beginnt bei `0`.
Ein negativer Index wird relativ zum Ende des Arrays interpretiert. Ein Index von `-1` gibt zum Beispiel das letzte Element des Arrays an, `-2` das vorletzte Element und so weiter.

### Arrays erstellen

Arrays werden normalerweise mit der `[]`-Notation erstellt.
Sie können Objekte ganz unterschiedlicher Typen enthalten.

```ruby
array = [1, "two", 3.0]
```

### Zugriff auf Elemente

Mit der Methode `#[]` kannst du Elemente eines Arrays über ihre Indizes abrufen.
Sie gibt das Element am angegebenen Index zurück oder ein Teilarray, das beim Startindex beginnt und über eine bestimmte Länge weitergeht.
Negative Indizes zählen vom Ende des Arrays rückwärts.

```ruby
a = [ "a", "b", "c", "d", "e" ]

a[2]       #=> "c"
a[6]       #=> nil
a[1, 3]    #=> [ "b", "c", "d" ]

a[-1]      #=> "e"
a[-2]      #=> "d"
a[-3, 2]   #=> ["c", "d"]
```

### Hilfsmethoden

Arrays haben viele nützliche Hilfsmethoden.
Hier sind einige der gebräuchlichsten:

```ruby
fibonacci = [0, 1, 1, 2, 3, 5, 8, 13]

fibonacci.size      #=> 8
fibonacci.sum       #=> 33
fibonacci.reverse   #=> [13, 8, 5, 3, 2, 1, 1, 0]
```

## Aufzählung

Anstatt mit Schleifen durch Sammlungen zu iterieren, verwenden wir in Ruby die Aufzählung.

Beim Aufzählen gehst du eine Sammlung (in diesem Fall ein Array) durch und führst für jedes Objekt eine Aktion aus. Die Aufzählung ist ein zentrales Konzept in Ruby und wird unter anderem zum Sortieren, Gruppieren, Abbilden und Reduzieren verwendet.

Eine Aufzählung, die jedes Wort in einem Array ausgibt, sieht so aus:

```ruby
words = ["the", "cat", "sat"]
words.each do |word|
  puts word
end

# Output:
# the
# cat
# sat
```

In diesem Beispiel haben wir die Methode `.each` auf unserem Array aufgerufen und einen _Block_ übergeben, der einen Parameter (`word`) entgegennimmt und ihn ausgibt.

Wir schauen uns _Blöcke_ später im Track noch viel genauer an, aber für den Moment kannst du sie dir als anonyme Funktionen vorstellen, die null oder mehr Argumente entgegennehmen können.
Sie können mit der `do...end`-Syntax (oben) oder der `{}`-Syntax (unten) definiert werden.

Hier sind einige weitere Beispiele für Array-Methoden, die Blöcke verwenden:

```ruby
fibonacci = [0, 1, 1, 2, 3, 5, 8, 13]

fibonacci.count  { |number| number == 1 }   #=> 2
fibonacci.any?   { |number| number == 6 }   #=> false
fibonacci.select { |number| number.odd? }   #=> [1, 1, 3, 5, 13]
fibonacci.all?   { |number| number < 20 }   #=> true
fibonacci.map    { |number| number * 2  }   #=> [0, 2, 2, 4, 6, 10, 16, 26]
```
