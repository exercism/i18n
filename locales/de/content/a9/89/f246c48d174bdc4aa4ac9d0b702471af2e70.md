# Einführung

## Tupel

Ein Tupel ist eine _unveränderliche_ Gruppierung unbenannter, aber geordneter Werte.
Ein Tupel kann beliebige (oder auch mehrere) Datentypen enthalten, einschließlich anderer Tupel.

Ein Tupel wird als kommagetrennte Folge von Werten zwischen den Zeichen `(` und `)` definiert: `(<element_1>, ... , <element_n>)`.

```fsharp
("one", 2) // Tuple pair (2 values)
("one", 2, true) // Tuple triplet (3 values)
```

Nur Tupel mit derselben Länge und denselben Typen (in derselben Reihenfolge) lassen sich vergleichen.
Tupel besitzen strukturelle Gleichheit. Das bedeutet, sie sind _nur_ dann gleich, wenn alle ihre Werte gleich sind.

```fsharp
(1, 2) = (1, 2) // Same length, same types, same values, same order
// => true

(1, 2) = (2, 1) // Same length, same types, same values, different order
// => false

(1, 2) = (1, "2") // Same length, different types
// compiler error

(1, 2) = (1, 2, 3) // Different length
// compiler error
```

Es gibt drei Möglichkeiten, Werte aus einem Tupel zu extrahieren:

- Die Funktionen `fst` und `snd`
- Die Dekonstruktion von Tupeln
- Pattern Matching

```fsharp
let person = ("Jordan", 170)

// Option 1: fst/snd
let name1 = fst person
let length2 = snd person

// Option 2: deconstruction
let (name2, length2) = person
// => name2 = "Jordan"
// => length2 = 170

// Option 3: pattern matching
match person with
| name3, length3 -> printf "%s: %d" name3 length3
```
