# Über

[Strukturen][structs-and-classes] (meist *Structs* genannt) sind einer der wichtigsten Bausteine von Swift-Programmen.
Mit Structs kannst du eigene Typen erstellen, die zusammengehörige Eigenschaften (Daten) und Methoden (Verhalten) bündeln.
Tatsächlich sind alle Standardtypen von Swift, darunter `Int`, `Double`, `Bool`, `String`, `Array` und `Dictionary`, als Structs implementiert.

## Structs definieren

Definiere ein Struct mit dem Schlüsselwort `struct`, gefolgt vom Typnamen und geschweiften Klammern, die seine Definition enthalten.
Nach Swift-Konvention schreibst du Struct-Namen in `UpperCamelCase`:

```swift
struct CharacterStats {
    var health = 0.0
    var speed = 0
    var strength = 0
}
```

## Instanzen erstellen

Eine Struct-Definition ist ein Bauplan.
Um eine *Instanz* eines Structs zu erstellen, rufst du seinen Initialisierer auf, indem du den Typnamen gefolgt von runden Klammern schreibst:

```swift
var someStats = CharacterStats()
```

So erstellst du eine Instanz, die mit den Standardwerten der Eigenschaften aus der Definition gefüllt ist.

Swift erzeugt außerdem automatisch einen **Memberwise-Initialisierer** für Structs, mit dem du Eigenschaften über ihren Namen initialisieren kannst:

```swift
let customStats = CharacterStats(health: 100.0, speed: 6, strength: 18)
```

## Auf Eigenschaften zugreifen und sie ändern

Du greifst mit der *Punktnotation* auf die Eigenschaften einer Instanz zu und änderst sie damit:

```swift
var stats = CharacterStats()

print(stats.health) // Prints 0.0

stats.health = 87.3
print(stats.health) // Prints 87.3
```

Weil Structs Werttypen sind, muss die Instanz selbst mit `var` deklariert sein, damit du ihre Eigenschaften ändern kannst.
Ist die Instanz mit `let` deklariert, werden alle ihre Eigenschaften unveränderlich.
