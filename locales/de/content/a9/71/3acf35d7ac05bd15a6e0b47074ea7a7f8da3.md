# Einführung

Ein String in Factor ist eine Folge von Zeichen. Die meisten Wörter aus dem Vokabular [`sequences`][sequences] funktionieren auch mit Strings, zusätzlich zu den speziellen Wörtern zur String-Verarbeitung in [`splitting`][splitting], [`ascii`][ascii] und Verwandten.

## String-Literale

Strings werden in doppelte Anführungszeichen gesetzt. Die üblichen Escape-Sequenzen werden unterstützt: `\n`, `\t`, `\r`, `\\`, `\"`:

```factor
"hello, world" .                 ! => "hello, world"
"first\nsecond" print            ! prints two lines
```

## Länge und Indexierung

Da ein String eine Sequenz ist, funktionieren die Wörter `length` und `nth` aus [`sequences`][sequences] direkt damit.

`length` gibt die Anzahl der Zeichen zurück:

```factor
"hello" length .    ! => 5
```

`nth` nimmt einen nullbasierten Index und die Sequenz und gibt das Element an dieser Position zurück. Bei einem String ist das Element ein *Zeichen*: ein Codepunkt (eine Ganzzahl), kein Teilstring aus einem Zeichen:

```factor
0 "hello" nth .     ! => 104   (CHAR: h)
4 "hello" nth .     ! => 111   (CHAR: o)
```

## Von einem Zeichen zurück zu einem String

Um einen einzelnen Codepunkt in einen String aus einem Zeichen umzuwandeln, verwende `1string ( char -- str )` aus dem Vokabular [`strings`][strings]. `CHAR:` ist die Form eines literalen Codepunkts zur Parse-Zeit:

```factor
CHAR: A 1string .                ! => "A"
0 "hello" nth 1string .          ! => "h"
```

## Aufteilen

Das Vokabular [`splitting`][splitting] zerlegt einen String in Teile.

`split1` zerlegt beim *ersten* Vorkommen eines Trennzeichens und gibt beide Hälften zurück:

```
split1 ( seq subseq -- before after )
```

```factor
"foo: bar" ": " split1 .s
! => "foo"
! => "bar"
```

`split` zerlegt bei *jedem* der Zeichen in einer Trennzeichenmenge und kann dabei leere Teile erzeugen:

```factor
"[ERROR]: Stack overflow" "[]" split .
! => { "" "ERROR" ": Stack overflow" }
```

`harvest` (in [`sequences`][sequences]) verwirft die leeren Teile:

```factor
"[ERROR]: Stack overflow" "[]" split harvest .
! => { "ERROR" ": Stack overflow" }
```

## Einen Teil herausgreifen

Sobald ein String in ein Array von Teilen zerlegt ist, geben `first`, `second`, `third` und `fourth` (in [`sequences`][sequences]) den Teil an dieser Position zurück:

```factor
"apple,bee,carrot,duck" "," split first .    ! => "apple"
"apple,bee,carrot,duck" "," split second .   ! => "bee"
"apple,bee,carrot,duck" "," split third .    ! => "carrot"
"apple,bee,carrot,duck" "," split fourth .   ! => "duck"
```

Wenn du alle führenden Teile auf einmal auf dem Stack haben möchtest, packen `first2` und `first3` zwei oder drei davon in einem Schritt aus:

```factor
"apple,bee,carrot,duck" "," split first2 .s
! => "apple"
! => "bee"

"apple,bee,carrot,duck" "," split first3 .s
! => "apple"
! => "bee"
! => "carrot"
```

Auf einem String selbst gibt `first` das erste **Zeichen** zurück, einen Codepunkt, und keinen Teilstring:

```factor
"hello" first .                         ! => 104   (CHAR: h)
```

## Trimmen

`[ blank? ] trim` (aus [`sequences`][sequences], mit `blank?` aus dem Vokabular [`ascii`][ascii]) entfernt führenden und abschließenden Leerraum:

```factor
"  Disk full \r\n" [ blank? ] trim .
! => "Disk full"
```

## Groß- und Kleinschreibung ändern

`>lower` und `>upper` (aus [`ascii`][ascii]) geben einen neuen String mit geänderter Groß- und Kleinschreibung zurück:

```factor
"WARNING" >lower .    ! => "warning"
"hello" >upper .      ! => "HELLO"
```

## Verbinden

Zwei Wörter aus [`sequences`][sequences] setzen Strings zusammen:

`surround` umschließt einen String mit einem Präfix und einem Suffix:

```
surround ( seq pre post -- new-seq )
```

```factor
"warning" "(" ")" surround .    ! => "(warning)"
```

`glue` verbindet zwei Strings mit einem Trennzeichen dazwischen:

```
glue ( s1 s2 sep -- s )
```

```factor
"Disk full" "(error)" " " glue .    ! => "Disk full (error)"
```
