# Einführung

Die Funktion `switch()` kann ein knapper Ersatz für eine lange Reihe von `if` ... `else if`-Tests sein.
Die Variable, auf die umgeschaltet wird, ist meistens ein String, und in diesem Fall können die Anführungszeichen im Selektor weggelassen werden.

```R
star <- function(type) {
  switch(type,
    M = , # will "fall through" if no value given
    K = "red dwarf",
    G = "Earth-like",
    "bigger star" # only correct for O,B,A,F
  )
}

> star("M")
[1] "red dwarf"
```

Beachte, dass Optionen nur dann durchfallen, wenn der Wert leer gelassen wird, wie bei `M` im Beispiel oben.
Anders als in manchen anderen Sprachen sind keine `break`-Anweisungen nötig.

Beim Umschalten auf `character`-Typen ist der letzte Wert ein Standardwert, wie hier.
Bei Ganzzahl-Typen kann kein Standardwert angegeben werden.

## Funktionen in `dplyr`

Das `switch` in Base R ist recht eingeschränkt: Es führt nur einen exakten Abgleich mit einer einzelnen Eingabe durch.
Das schien sinnvoll, als R 1993 zum ersten Mal veröffentlicht wurde, aber für moderne Anwendungen ist eine Verbesserung nötig.

~~~~exercism/note
Wie im [`Conditionals`][concept-conditionals]-Konzept erwähnt, ist die `tidyverse`-Sammlung von Paketen darauf ausgelegt, die Funktionalität von Base R zu ergänzen (und manchmal zu ersetzen), ohne die Abwärtskompatibilität zu beeinträchtigen.

Das `dplyr`-Paket kannst du einbinden, indem du entweder `library(dplyr)` (für das einzelne Paket) oder `library(tidyverse)` (für die ganze Sammlung) oben in deinen Code einfügst.

Die `dplyr`-Bibliothek bietet zwei zusätzliche Funktionen rund um `switch`.

### Die Funktionen `recode_values` und `replace_values`

Diese beiden verwandten Funktionen ermöglichen eine vektorisierte, switch-ähnliche Zuordnung alter Werte zu neuen Werten.

Der Hauptunterschied besteht darin, dass `recode_values()` einen völlig neuen Vektor erzeugt, während `replace_values()` partielle Aktualisierungen eines vorhandenen Vektors erlaubt.

Der Abgleich ist weiterhin exakt, aber:

- Die Optionen auf der linken Seite können Vektoren sein, und die Eingabe passt, wenn irgendein Element passt.
- Optionen links und Ergebnisse rechts werden mit einer Tilde `~` statt mit `=` verknüpft.
- Ein Standardwert kann in allen Fällen angegeben werden.

```R
library(dplyr)

x <- c("a", "b", "a", "d", "b", NA, "c", "e", "z")
recode_values(
  x,
  "a" ~ 1,
  "b" ~ 2,
  "c" ~ 3,
  c("d", "e") ~ 4, # either "d' or "e" will match
  NA ~ 0,          # matches missing values
  default = 100   # note the different syntax for the default
)
#> [1]   1   2   1   4   2   0   3   4 100
```

### Die Funktion `case_when`

`case_when` führt die `case_match`-Syntax noch einen Schritt weiter, indem es jeden beliebigen logischen Ausdruck links vom `~` erlaubt.

Der Eingabevektor (`x` im Beispiel unten) wird nicht als Argument übergeben, er muss nur bereits definiert sein.

```R
x <- 1:10
case_when(
  x < 3 ~ "low",
  between(x, 3, 5) ~ "mid",
  between(x, 6, 8) ~ "high",
  .default = "what?"
)
#>  [1] "low"   "low"   "mid"   "mid"   "mid"   "high"  "high"  "high"  "what?" "what?"
```

Die Funktion `between()` ist ebenfalls Teil von `dplyr`.
