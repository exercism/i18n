# TODO-Kommentare entfernen

Anscheinend hast du einige `// TODO: ...`-Kommentare in deinem Code gelassen, die Teil des Lösungs-Stubs waren.

Dein Code besteht die Tests, was bedeutet, dass diese Kommentare nicht mehr zutreffen: Du hast bereits alles implementiert, was nötig ist.

Achte darauf, veraltete Kommentare immer aus deinem Code zu entfernen.
