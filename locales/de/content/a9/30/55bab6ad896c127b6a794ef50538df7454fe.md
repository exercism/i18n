# Überblick

In Haxe verwendest du Iteratoren, um mit einer `for`-Schleife über einen Wert zu iterieren. Es gibt zwei Arten von Iteratoren:

- `Iterator`, der über einen Wert iteriert.
- `Iterable`-Daten, mit denen du über einen Datentyp iterieren kannst.

Beide Konzepte werden durch `Iterator<T>` und `Iterable<T>` dargestellt:

```haxe
typedef Iterator<T> = {
  function hasNext():Bool;
  function next():T;
}

typedef Iterable<T> = {
  function iterator():Iterator<T>;
}
```

Jede Klasse, die mit einem dieser Typen unifiziert, kannst du mit einer `for`-Schleife durchlaufen. Definiert eine Klasse die Methoden `hasNext` und `next`, gilt sie als Iterator. Definiert sie stattdessen eine Methode `iterator`, gilt sie als iterierbarer Typ:

```haxe
class MyStringIterator {
  var str:String;
  var i:Int;

  public function new(str:String) {
    this.str = str;
    i = 0;
  }

  public function hasNext():Bool {
    return i < str.length;
  }

  public function next():String {
    return str.charAt(i++);
  }
}
```

Im obigen Beispiel gilt die Klasse `MyStringIterator` als Iterator, weil sie sowohl die Methode `hasNext` als auch die Methode `next` implementiert und damit mit `Iterator<String>` kompatibel ist.

```haxe
class MyArrayWrap<T> {
  var arr:Array<T>;

  public function new(a:Array<T>) {
    this.a = a;
  }

  public function iterator() {
    return a.iterator();
  }
}
```

Hier gilt die Klasse `MyArrayWrap` als iterierbarer Datentyp, weil sie mit `Iterable<Array<T>>` kompatibel ist.
