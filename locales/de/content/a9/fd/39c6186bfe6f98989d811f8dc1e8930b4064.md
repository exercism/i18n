# Hinweise

## Allgemein

- [Structs und Klassen][structs-and-classes] haben eine ähnliche Definitionssyntax.

## 1. Definiere ein Size-Struct

- Eigenschaften müssen mit `var` definiert werden, wenn sie verändert werden können.
- Den Eigenschaften height und width sollten die Standardwerte 80 bzw. 60 zugewiesen werden.
- Methoden in einem Struct müssen mit `mutating` gekennzeichnet werden, wenn sie Eigenschaften des Structs verändern.

## 2. Definiere ein Position-Struct

- Eigenschaften müssen mit `var` definiert werden, wenn sie verändert werden können.
- Den Eigenschaften x und y sollte der Standardwert 0 zugewiesen werden.
- Methoden in einem Struct müssen mit `mutating` gekennzeichnet werden, wenn sie Eigenschaften des Structs verändern.

## 3. Definiere eine Window-Klasse

- Structs können mit unterschiedlichen Eigenschaftswerten initialisiert werden, indem du [Memberwise-Initialisierer][memberwise-initializers] verwendest.
- Konstante Eigenschaften sollten mit `let` definiert werden.
- Die Eigenschaft `contents` sollte optional sein, da sie möglicherweise keinen Wert hat.
- Du musst einen leeren Initialisierer für die Klasse definieren (`init() {}`).

## 4. Füge eine Methode zum Ändern der Fenstergröße hinzu

- Die Methode sollte einen Parameter `to` vom Typ `Size` entgegennehmen.
- Mit der Punktnotation kannst du width und height aus dem Parameter `to` auslesen.

## 5. Füge eine Methode zum Verschieben von Fenstern hinzu

- Die Methode sollte einen Parameter `to` vom Typ `Position` entgegennehmen.
- Mit der Punktnotation kannst du x und y aus dem Parameter `to` auslesen.

## 6. Füge eine Methode zum Setzen des Inhalts eines Fensters hinzu

- In Swift kannst du zwei Methoden mit demselben Namen, aber unterschiedlichen Parametern haben.
- Definiere eine Methode mit dem Parameter `title`, die die Eigenschaft `title` setzt.
- Definiere eine Methode mit dem Parameter `text`, die die Eigenschaft `contents` setzt.
- Definiere eine Anzeigemethode, die den Titel und den Inhalt des Fensters ausgibt.

## 7. Erstelle einen Initialisierer für die Window-Klasse

- Die Klasse sollte zwei Initialisierer haben: einen, der keine Parameter entgegennimmt, und einen, der Parameter entgegennimmt.
- Der neue Initialisierer sollte die Parameter `title` und `contents` haben; außerdem sollte er die optionalen Parameter `size` und `position` erlauben.
    Wenn keine Parameter angegeben werden, sollten die Standardwerte verwendet werden.
- Optionale Parameter kannst du mit [Standardparameterwerten][default-parameters-vales] umsetzen.
