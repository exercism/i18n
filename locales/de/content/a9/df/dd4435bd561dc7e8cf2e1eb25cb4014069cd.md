# Einführung

Dicts sind in Gleam die Datenstruktur, um Informationen in Schlüssel-Wert-Paaren zu speichern. In anderen Sprachen sind sie auch als assoziative Arrays, Hashes oder Wörterbücher bekannt.

Für die Schlüssel und Werte in einem Dict kannst du jeden Typ verwenden. Die Reihenfolge der Einträge ist nicht garantiert, wenn du auf sie zugreifst oder sie zurückgibst.

## Mit Dicts arbeiten

Dicts erstellst und bearbeitest du mit Funktionen aus dem Modul `gleam/dict`.

```gleam
// Create an empty dict
let dict1 = dict.new()

// Create a dict with some values
let dict2 = dict.from_list([
  #("name", "Gleam"),
  #("colour", "Pink"),
])

// Add a value to a dict
let dict3 = dict.insert(dict2, "website", "https://gleam.run")

// Get a value from a dict
let name = dict.get(dict3, "name")
// -> Ok("Gleam")
```
