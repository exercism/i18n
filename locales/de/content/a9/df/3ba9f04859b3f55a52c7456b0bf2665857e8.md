# Anleitung

Während du deine Arbeit bei _Instruments of Texas_ fortsetzt, macht die Elixir-Implementierung des UPN-Rechners Fortschritte. Dein Team möchte Fehler auslösen können, die spezifischer sind als die generischen Fehler aus der Standardbibliothek. Du recherchierst noch, hast dich aber entschieden, zwei neue Fehler zu implementieren, die das _Exception Behaviour_ umsetzen.

## 1. Fehler bei Division durch null

Wenn du eine Zahl durch null teilst, ist das Ergebnis undefiniert. Das Team entscheidet, dass ein Fehler das am besten darstellt.

Implementiere das Modul `DivisionByZeroError` mit der Fehlermeldung: `"division by zero occurred"`

```elixir
raise DivisionByZeroError
# => ** (DivisionByZeroError) division by zero occurred
```

## 2. Fehler bei einem Stack-Underflow

UPN-Rechner verwenden einen _Stack_, um Zahlen zu verwalten, bevor sie addiert werden. Das Team stellt diesen _Stack_ als eine Liste von Zahlen dar (Ganzzahlen und Gleitkommazahlen), z. B.: `[3, 4.0]`. Jede Operation benötigt eine bestimmte Anzahl an Zahlen auf dem Stack, um ihre Berechnung durchzuführen. Wenn nicht genug Zahlen auf dem Stack liegen, nennt man das einen Stack-Underflow-Fehler. Implementiere die Exception `StackUnderflowError`, die eine Standardmeldung und einen optionalen zusätzlichen Kontext bereitstellt

```elixir
raise StackUnderflowError
# => ** (StackUnderflowError) stack underflow occurred

raise StackUnderflowError, "when dividing"
# => ** (StackUnderflowError) stack underflow occurred, context: when dividing
```

## 3. Schreibe eine Funktion zum Dividieren

Implementiere die Funktion `divide/1`, die einen Stack _(eine Liste mit zwei Zahlen)_ entgegennimmt und:

- _Stack-Underflow_ auslöst, wenn der Stack nicht genug Zahlen enthält
- _Division durch null_ auslöst, wenn der Divisor 0 ist (beachte, der Stack mit den Zahlen ist in umgekehrter Reihenfolge gespeichert)
- die Division ausführt, wenn keine Fehler ausgelöst werden

```elixir
RPNCalculator.Exception.divide([])
# => ** (StackUnderflowError) stack underflow occurred, context: when dividing

RPNCalculator.Exception.divide([0, 100])
# => ** (DivisionByZeroError) division by zero occurred

RPNCalculator.Exception.divide([4, 16])
# => 4
```

> Beachte: Die Reihenfolge der Liste ist umgekehrt!
