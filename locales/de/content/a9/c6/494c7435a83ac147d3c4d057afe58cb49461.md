# Instructions

Mary ist ein großer Fan der TV-Serie _Star Trek: The Next Generation_.
Sie spielt oft Pen-&-Paper-Rollenspiele, in denen sie und ihre Freunde die Besatzung der _Starship Enterprise_ verkörpern.

Marys Figur ist Captain Picard, was bedeutet, dass sie das Logbuch des Captains führen muss.
Sie liebt den kreativen Teil des Spiels, mag es aber nicht, spontan zufällige Daten zu erzeugen.

Hilf Mary, indem du Zufallsgeneratoren für Daten erstellst, die häufig im Logbuch des Captains vorkommen.

## 1. Zufällige Planeten generieren

Die _Starship Enterprise_ trifft auf ihren Reisen auf viele Planeten.
Planeten im Star-Trek-Universum werden anhand ihrer Eigenschaften in Kategorien eingeteilt.
Zum Beispiel ist die Erde ein Planet der Klasse M. Alle möglichen Planetenklassen sind: D, H, J, K, L, M, N, R, T und Y.

Implementiere die Funktion `random_planet_class`.
Sie soll die erforderliche Anzahl an Planetenklassen zufällig als Vektor zurückgeben.
Doppelte Klassen sind erlaubt und bei langen Vektoren möglicherweise sogar nötig.

```R
random_planet_class(number_needed)
#> "K"
```

### 2. Eine zufällige Registrierungsnummer für ein Raumschiff generieren

Die Enterprise (Registrierungsnummer NCC-1701) ist nicht das einzige Raumschiff, das durchs All fliegt!
Wenn sie sich mit einem anderen Raumschiff trifft, muss Mary dessen Registrierungsnummer ins Logbuch eintragen.

Registrierungsnummern beginnen mit dem Präfix „NCC-" und verwenden dann eine Zahl von 1000 bis 9999 (einschließlich).

Implementiere die Funktion `random_ship_registry_number`, die eine zufällige Registrierungsnummer für ein Raumschiff zurückgibt.

```R
random_ship_registry_number()
#> "NCC-1947"
```

## 3. Eine Flotte von Raumschiffen zufällig mischen

Eine Version des Spiels beinhaltet die Interaktion mit anderen Raumschiffen, und Mary braucht eine Auswahl.

Es gibt eine vollständige Liste möglicher Raumschiffe, aber in jedem Spiel werden nur wenige davon gebraucht, und sie sollten zufällig ausgewählt werden.

Implementiere die Funktion `shuffle_starships(starships)`, die einen Vektor eindeutiger Registrierungsnummern entgegennimmt und einen Vektor derselben Länge mit den Raumschiffen in zufälliger Reihenfolge zurückgibt.
Dann ist es für Mary einfach, eine zufällige Auswahl beliebiger Größe vom Anfang des Vektors zu nehmen.

Die Ergebniswerte sollten aus `starships` stammen, ohne Duplikate.

```R
shuffle_starships(c("NCC-5011", "NCC-1228", "NCC-7039", "NCC-3978", "NCC-1476"))
#> [1] "NCC-1476" "NCC-7039" "NCC-3978" "NCC-5011" "NCC-1228"
```

## 4. Eine zufällige Sternzeit generieren

Was nützt ein Logbuch, wenn darin keine Daten stehen?

Eine Sternzeit ist eine Gleitkommazahl.
Die Abenteuer der _Starship Enterprise_ aus der ersten Staffel von _The Next Generation_ spielen zwischen den Sternzeiten 41000.0 und 42000.0.
Die „4" steht für das 24. Jahrhundert, die „1" für die erste Staffel.

Implementiere die Funktion `random_stardate`, die eine Gleitkommazahl zwischen 41000.0 und 42000.0 zurückgibt.

```R
random_stardate()
#> 41037.6
```
