# Ergänzung zur Anleitung

## Projektstruktur

Clojure-Übungen bei Exercism verwenden [leiningen](http://leiningen.org/), um deinen Code zu konfigurieren und auszuführen, und folgen der [Standard-Verzeichnisstruktur von leiningen](https://github.com/technomancy/leiningen/blob/master/doc/TUTORIAL.md#directory-layout).

Im Verzeichnis `test` findest du eine Testdatei namens `hello_world_test.clj`.
Schreib deinen Code in `src/hello_world.clj`. Er sollte den Namensraum `hello-world` verwenden, damit die Tests ihn aufgreifen können.

## Tests ausführen

Führe die Tests mit dem Befehl `lein test` aus und sorge dafür, dass sie bestehen:

```
$ lein test

lein test hello-world-test

Ran 3 tests containing 3 assertions.
0 failures, 0 errors.
```

Dann reichst du die Übung ein mit:

```
$ exercism submit src/hello_world.clj
```

Ausführlichere Anleitungen und Lernressourcen findest du auf [der Clojure-Sprachseite von Exercism](http://exercism.io/languages/clojure).
