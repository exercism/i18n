# Einführung

Der Operator `|>` heißt Pipe-Operator. Mit ihm kannst du Funktionsaufrufe so aneinanderreihen, dass der Rückgabewert des vorherigen Funktionsaufrufs an den nächsten Funktionsaufruf übergeben wird.

```gleam
"hello"
|> string.uppercase
|> string.append("?!")
// -> "HELLO?!"
```

Der Code oben entspricht dem folgenden:

```gleam
string.append(string.uppercase("hello"), "?!")
```

Der Pipe-Operator übergibt den Wert entweder als erstes Argument an den Funktionsaufruf oder als einziges Argument an einen neuen Aufruf. Dabei wählt er die Variante, bei der der Typ passt.

```gleam
100
|> function_that_takes_two_arguments(1)

// Is equivalent to
function_that_takes_two_arguments(100, 1)
```

```gleam
100
|> function_that_returns_a_function(1)

// Is equivalent to
function_that_returns_a_function(1)(100)
```

Manchmal möchtest du den Wert an einer anderen Position übergeben. In diesem Fall kannst du den Platzhalter `_` verwenden, um anzugeben, wo der Wert eingefügt werden soll.

```gleam
100
|> some_function(1, _, 2)
```
