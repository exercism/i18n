# Überblick

Die wichtigsten arithmetischen und Vergleichsoperatoren kannst du für deine eigenen Klassen und Structs anpassen. Man nennt das _Operatorüberladung_.

Dieser [Artikel][operator-overloading] behandelt ausführlich die Syntax und geht darauf ein, welche Operatoren überladen werden können und welche nicht.

Die meisten Operatoren haben die Form:

```csharp
static <return type> operaator <operator symbols>(<parameters>);
```

[Cast-Operatoren][ud-conversion-operators] haben die Form:

```csharp
static (explicit|implicit) operator <cast-to-type>(<cast-from-type> <parameter name>);
```

Operatoren verhalten sich wie statische Methoden.

- Ein Operatorsymbol tritt an die Stelle eines Methodennamens, und Operatoren haben Parameter und einen Rückgabetyp. Die Typregeln für Parameter und Rückgabetyp folgen deiner Intuition, und du kannst dich darauf verlassen, dass der Compiler dir detaillierte Hinweise gibt.
- Bei binären Operationen nimmt der erste Parameter das linke Argument der Operation auf.
- Operatoren haben eine Signatur, die bei binären Operatoren aus zwei Parametern und einem Rückgabetyp besteht, bei unären Operatoren aus einem einzelnen Parameter und einem Rückgabetyp.
- Bei binären Operatoren muss einer der Parametertypen der Typ der deklarierenden Klasse sein.
- Bei Typkonvertierungen muss entweder der Parameter oder der Rückgabetyp der Typ der deklarierenden Klasse sein.
- Bei Inkrement- und Dekrementoperatoren müssen Parameter und Rückgabetyp der Typ der deklarierenden Klasse sein.

Syntaxbeispiele:

```csharp
struct Point
{
    decimal x;
    decimal y;

    public static bool operator ==(Point pt, Point ptOther)
    {
        return pt.x == ptOther.x && pt.y == ptOther.y;
    }

    public static bool operator !=(Point pt, Point ptOther)
    {
        return !(pt == ptOther);
    }

    public static Point operator *(Point pt, decimal scale)
    {
        var ptNew = new Point();
        ptNew.x = pt.x * scale;
        ptNew.y = pt.y * scale;
        return ptNew;
    }

    public static implicit operator Point((decimal x, decimal y) xy)
    {
        var pt = new Point();
        pt.x = xy.x;
        pt.y = xy.y;
        return pt;
    }

    public static explicit operator (decimal x, decimal y)(Point pt)
    {
        return (pt.x, pt.y);
    }
}
```

Oft ist es sinnvoll, eine [`Equals()`][equals]-Methode zu implementieren und sie aus dem `==`-Operator heraus aufzurufen. Für Vergleiche kannst du außerdem das Interface [`IComparable`][icomparable] implementieren. In beiden Fällen schlägst du zwei Fliegen mit einer Klappe.

Du solltest beachten, dass du keine Operatoren aus Symbolen erstellen kannst, die nicht zum Standardsatz der Operatoren gehören. Du kannst nur vorhandene Symbole für die Operationen verwenden, für die die Dokumentation angibt, dass sie überladen werden können. Welche Operatoren überladen werden können, ist [hier][overloadable-operators] aufgelistet.

Beachte, dass die Reihenfolge der Parameter wichtig ist, wenn sie sich im Typ unterscheiden. Im obigen Beispielcode ist `pt * 10m` ein gültiger Ausdruck, während `10m * pt` nicht kompiliert wird.
