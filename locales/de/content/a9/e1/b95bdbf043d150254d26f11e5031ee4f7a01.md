# Über

Das Makro `use` ermöglicht es uns, unser Modul schnell um Funktionalität zu erweitern, die ein anderes Modul bereitstellt. Wenn wir `use` mit einem Modul aufrufen, kann dieses Modul Code in unser Modul einfügen. Es kann zum Beispiel Funktionen definieren, andere Module `import`ieren oder `alias`en, oder Modulattribute setzen.

Wenn du dir schon einmal die Testdateien einiger Elixir-Übungen hier auf Exercism angesehen hast, ist dir sicher aufgefallen, dass sie alle mit `use ExUnit.Case` beginnen. Diese eine Codezeile ist es, die die Makros `test` und `assert` im Testmodul verfügbar macht.

```elixir
defmodule LasagnaTest do
  use ExUnit.Case

  test "expected minutes in oven" do
    assert Lasagna.expected_minutes_in_oven() === 40
  end
end
```

## Das Makro `__using__/1`

Was genau passiert, wenn du `use` mit einem Modul aufrufst, bestimmt das Makro `__using__/1` dieses Moduls. Es nimmt ein Argument entgegen, eine Keyword-Liste mit Optionen, und gibt einen [quotierten Ausdruck][concept-ast] zurück. Der Code in diesem quotierten Ausdruck wird beim Aufruf von `use` in unser Modul eingefügt.

```elixir
defmodule ExUnit.Case do
  defmacro __using__(opts) do
    # some real-life ExUnit code omitted here
    quote do
      import ExUnit.Assertions
      import ExUnit.Case, only: [describe: 2, test: 1, test: 2, test: 3]
    end
  end
end
```

Die Optionen kannst du beim Aufruf von `use` als zweites Argument angeben, z. B. `use ExUnit.Case, async: true`. Wenn du sie nicht ausdrücklich angibst, wird standardmäßig eine leere Liste verwendet.

[concept-ast]: https://exercism.org/tracks/elixir/concepts/ast
