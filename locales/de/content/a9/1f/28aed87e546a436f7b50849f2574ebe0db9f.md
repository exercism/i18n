# Debug

Wenn ein Test fehlschlägt oder dein Code nicht kompiliert, wird in der Konsole ein Fehler angezeigt. Wenn er dir nicht weiterhilft, kannst du den [`stack ghci`-Befehl][docs-stack-ghci] ausführen und die [interaktive REPL][docs-ghci] starten. Dort kannst du deine Funktionen ausprobieren und experimentieren, bis du verstehst, wie du deinen Code korrigierst.

[docs-stack-ghci]: https://docs.haskellstack.org/en/stable/ghci/
[docs-ghci]: https://downloads.haskell.org/~ghc/latest/docs/html/users_guide/ghci.html
