# Überblick

Mit dem Typ `Option` stellst du Werte dar, die entweder fehlen oder vorhanden sind.

Er ist im Modul `gleam/option` wie folgt definiert:

```gleam
type Option(a) {
  Some(a)
  None
}
```

Der Konstruktor `Some` verpackt einen Wert, wenn dieser vorhanden ist, und der Konstruktor `None` steht für das Fehlen eines Werts.

Auf den Inhalt eines `Option`-Typs greifst du oft über Musterabgleich zu.

```gleam
import gleam/option.{type Option, None, Some}

pub fn say_hello(person: Option(String)) -> String {
  case person {
    Some(name) -> "Hello, " <> name <> "!"
    None -> "Hello, Friend!"
  }
}
```

```gleam
say_hello(Some("Matthieu"))
// -> "Hello, Matthieu!"

say_hello(None)
// -> "Hello, Friend!"
```

Das Modul `gleam/option` definiert außerdem eine Reihe nützlicher Funktionen für die Arbeit mit `Option`-Typen, zum Beispiel `unwrap`. Diese Funktion gibt den Inhalt eines `Option`-Typs oder einen Standardwert zurück, wenn dieser `None` ist.

```gleam
import gleam/option.{type Option}

pub fn say_hello_again(person: Option(String)) -> String {
  let name = option.unwrap(person, "Friend")
  "Hello, " <> name <> "!"
}
```
