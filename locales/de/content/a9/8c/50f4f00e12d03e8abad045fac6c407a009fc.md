# Über

Eine Schleife ist eine Möglichkeit, eine oder mehrere Anweisungen wiederholt auszuführen. Jeder Durchlauf durch einen Block von Anweisungen heißt Iteration.

## while-Schleife

Eine `while`-Schleife führt einen Block von Anweisungen aus, solange ein boolescher Ausdruck am Anfang der Schleife wahr ist. Wenn der boolesche Ausdruck falsch ist, hört die Schleife auf zu laufen und die Ausführung fährt mit der nächsten Codezeile nach der Schleife fort.

Wenn der boolesche Ausdruck von Anfang an falsch ergibt, läuft die `while`-Schleife überhaupt nicht und die Ausführung fährt mit der nächsten Codezeile nach der Schleife fort.

```c
int main() {
    int i = 0;
    while (i < 5) {
        printf("Number is %i\n", i++);
    }    
    return 0;
}
```

Wichtig ist, dass es eine Bedingung gibt, die die Schleife beendet; sonst entsteht eine Endlosschleife, die den gesamten Fortschritt des Codes blockiert. Wenn man im obigen Code das `++` bei `i` entfernen würde, wäre es eine Endlosschleife.

## do-Schleife

Bei einer `do`-Schleife wird der boolesche Ausdruck am Ende der Schleife geprüft. Eine `do`-Schleife läuft immer mindestens einmal, wie im folgenden Beispiel:

```c
do {
    printf("Enter the Answer to the Ultimate Question of Life: ");
    scanf("%d", &answer);
} while (answer != 42); 
// Note that a semicolon is needed after the Boolean expression.
```

Mit einer `while`-Schleife wäre das umständlicher:

```c
printf(""Enter the Answer to the Ultimate Question of Life: ");
scanf("%d", &answer);
while (answer != 42) {
    printf(""Enter the Answer to the Ultimate Question of Life: ");
    scanf("%d", &answer);
}
```

## for-Schleife

Oft aktualisiert eine Schleife eine Variable und endet, wenn die Variable einen bestimmten Wert erreicht. Eine `for`-Schleife ist eine Möglichkeit, eine oder mehrere Variablen in einer Zeile innerhalb runder Klammern zu initialisieren, zu aktualisieren und zu prüfen. Der erste Abschnitt dient zum Initialisieren der Variablen, der zweite zum Prüfen der Variablen und der dritte zum Aktualisieren des Werts der Variablen.

```c
for (int i = 0; i < 5; i++) {
    printf("Number is %i\n", i);
}
```

Das ist weniger umständlich als die entsprechende `while`-Schleife und trotzdem noch gut lesbar.

Die Abschnitte zum Initialisieren und Aktualisieren der `for`-Schleife können mehr als eine Variable verwalten, indem man den Kommaoperator verwendet, um die Ausdrücke innerhalb der Bedingungen zu trennen.

```c
    int i, j;
    for (i = 0, j = 5; i < 5 && j > 2; i++, j--) {
        printf("i is %i\n", i);
        printf("j is %i\n", j);
    }
    printf("After the loop");
```

Das gibt Folgendes aus:

```
i is 0
j is 5
i is 1
j is 4
i is 2
j is 3
After the loop
```

Kein Abschnitt der `for`-Schleife muss angegeben werden. Ein leerer Prüfausdruck ergibt wahr, daher könnte man mit einer `for`-Schleife so eine Endlosschleife definieren:

```c
int i = 0;
for (;;) {
    printf("Number is %i\n", i++);
    if (i == 5) break;
}
```

Das ähnelt der `while`-Schleife insofern, als `i` vor der Schleife initialisiert und innerhalb der Schleife erhöht wird. Außerdem wird `i` innerhalb der Schleife geprüft und die Schleife endet mit der `break`-Anweisung.

## break-Anweisung

Manchmal muss eine Schleife aufgrund einer besonderen Bedingung enden, die nicht in ihrem booleschen Ausdruck geprüft wird. Die `break`-Anweisung beendet die Schleife und die Ausführung fährt mit der nächsten Codezeile nach der Schleife fort.

```c
int i, j, k;
for (int i = 0, j = 5, k = 3; i < 5 && j > 2; i++, j--) {
    printf("i is %i\n", i);
    printf("j is %i\n", j);
    if (k == 3) break;
}
printf("After the loop");
```

Das gibt Folgendes aus:

```
i is 0
j is 5
After the loop
```

## continue-Anweisung

Manchmal muss eine Schleife mit der nächsten Iteration beginnen, ohne die aktuelle Iteration abzuschließen. Die `continue`-Anweisung beendet die Ausführung der aktuellen Iteration und setzt die Ausführung am Anfang der nächsten Iteration fort.

```c
int i, j;
for (int i = 0, j = 4; i < 4 && j > 0; i++, j--) {
    if (i == j) continue;
    printf("i is %i\n", i);
    printf("j is %i\n", j);
}
printf("After the loop");
```

Das gibt Folgendes aus:

```
i is 0
j is 4
i is 1
j is 3
i is 3
j is 1
After the loop
```

Die Werte für `i` und `j` werden nicht ausgegeben, wenn beide `2` sind.
