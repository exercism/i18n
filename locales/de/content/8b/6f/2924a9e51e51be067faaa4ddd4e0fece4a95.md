# Einführung

## Rekursion

Rekursive Funktionen sind Funktionen, die sich selbst aufrufen.

Eine rekursive Funktion braucht mindestens einen _Basisfall_ und mindestens einen _rekursiven Fall_.

Ein _Basisfall_ gibt einen Wert zurück, ohne die Funktion erneut aufzurufen.
Ein _rekursiver Fall_ ruft die Funktion erneut auf und ändert dabei die Eingabe so ab, dass sie irgendwann zum Basisfall passt.

In Elm werden rekursive Funktionen üblicherweise mit Pattern Matching über `case`-Ausdrücke oder mehrere Funktionsklauseln definiert.

```elm
count : List a -> Int
count list =
    case list of
        [] ->
            0  -- base case

        _ :: tail ->
            1 + count tail  -- recursive case
```

### Schleifen durch Rekursion

Wegen der Unveränderlichkeit werden Schleifen in Elm anders geschrieben als in imperativen Sprachen.
Zum Beispiel sehen Schleifen üblicherweise so aus:

```c
for(i = 0; i < array.length; i++) {
  // do something with array[i]
}
```

In einer funktionalen Sprache wie Elm lassen sich Variablen nicht verändern.
Deshalb müssen Schleifen mit Rekursion umgesetzt werden.

Das Äquivalent einer `for`-Schleife in Elm sieht so aus:

```elm
loop : List a -> (a -> b) -> List b
loop list f =
    case list of
        [] ->
            []

        head :: tail ->
            f head :: loop tail f
```

In der Praxis iteriert man in Elm über Listen und andere Datenstrukturen am häufigsten mit Funktionen aus dem `List`-Modul, wie `List.map`, `List.filter` und `List.foldl`.
Unter der Haube sind diese Funktionen mit Rekursion umgesetzt.
