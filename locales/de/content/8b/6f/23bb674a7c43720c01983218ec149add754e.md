# Einführung

## Externe Funktionen

Gleam kann auf der Erlang-VM (BEAM) laufen oder auf JavaScript-Laufzeitumgebungen. Es gibt viele andere Sprachen, die diese Laufzeitumgebungen nutzen, und oft ist es nützlich, Code, der in diesen Sprachen geschrieben wurde, aus Gleam heraus aufrufen zu können.

Gleams Feature der _externen Funktionen_ ermöglicht es, Funktionen aus anderen Sprachen in Gleam zu importieren und ohne Laufzeit-Overhead aufzurufen.

Wenn dein Gleam-Projekt auf der Erlang-VM läuft und du die Funktion `reverse` aus dem Erlang-Modul `lists` aufrufen möchtest, kannst du das tun, indem du das Attribut `@external` zu einem Gleam-Funktionskopf hinzufügst, so wie hier:

```gleam
@external(erlang, "lists", "reverse")
pub fn reverse_list(x: List(a)) -> List(a)
```

Diese lässt sich dann wie eine normale Gleam-Funktion aufrufen:

```gleam
let reversed = reverse_list([1, 2, 3])
// -> [3, 2, 1]
```

Wenn du versuchst, diesen Code für JavaScript-Laufzeitumgebungen zu kompilieren, schlägt das mit einer Fehlermeldung fehl, denn es gibt keine Implementierung für JavaScript. Eine andere Implementierung kannst du für JavaScript-Laufzeitumgebungen so angeben:

```gleam
@external(erlang, "lists", "reverse")
@external(javascript, "./my_module.mjs", "reverse")
pub fn reverse_list(x: List(a)) -> List(a)
```

Du kannst auch eine Gleam-Implementierung schreiben, die verwendet wird, wenn es keine externe Implementierung für das aktuelle Kompilierungsziel gibt:

```gleam
@external(erlang, "lists", "reverse")
pub fn reverse_list(x: List(a)) -> List(a) {
  tail_recursive_reverse(x, [])
}

fn tail_recursive_reverse(list, reversed) {
  case list {
    [] -> reversed
    [x, ..xs] -> tail_recursive_reverse(xs, [x, ..reversed])
  }
}
```

## Externe Typen

Externe Typen kannst du verwenden, um auf Datentypen zu verweisen, die in anderen Sprachen definiert sind, zum Beispiel in Erlang oder JavaScript.

Um einen externen Typ zu definieren, deklarierst du einen Typ, gibst aber keine Konstruktoren an. Dieser lässt sich dann genauso verwenden wie jeder andere Typ.

```gleam
pub type OrderedDictionary(element)
```
