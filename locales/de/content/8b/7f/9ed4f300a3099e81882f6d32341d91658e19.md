# Einführung

ABAP unterstützt ein objektorientiertes Programmiermodell, das auf Klassen und Interfaces von ABAP Objects basiert.

## (Neu-)Zuweisung

In ABAP gibt es einige grundlegende Möglichkeiten, Namen Werte zuzuweisen: mit Variablen oder Konstanten. Bei Exercism werden Variablen immer in [Snake Case][wiki-snake-case] geschrieben. Es gibt keine offizielle Richtlinie, an die du dich halten musst, und verschiedene Firmen und Organisationen haben unterschiedliche Style Guides. _Du kannst Variablen so schreiben, wie es dir gefällt_. Der Vorteil, wenn du sie so schreibst, wie es die Übungen vorgeben, ist, dass sie in der Weboberfläche und in den meisten IDEs anders hervorgehoben werden.

Variablen lassen sich in ABAP mit den Schlüsselwörtern [`constant`][constant] oder [`data`][data] definieren.

Eine Variable, die mit `data` definiert wird, kann im Laufe ihres Lebens verschiedene Werte annehmen. Zum Beispiel kann `my_first_variable` mit dem [Zuweisungsoperator `=`][assignment] viele Male definiert und neu zugewiesen werden:

```abap
DATA my_first_variable TYPE i. " integer

my_first_variable = 1.
my_first_variable = 4711 * 3.
my_first_variable = some_complex_calculation( ).
```

Im Gegensatz zu `data` können Variablen, die mit `constant` definiert werden, nur einmal zugewiesen werden. Damit werden in ABAP Konstanten definiert.

```abap
CONSTANT my_first_constant TYPE i VALUE 10.

" Can not be re-assigned
my_first_constant = 20.
// => SyntaxError: Assignment to constant variable.
```

## Klassen- und Methodendeklarationen

In ABAP werden Funktionseinheiten in _Methoden_ gekapselt; Methoden, die zusammengehören, werden meist in derselben [Klasse][classes] zusammengefasst. Diese Methoden können Parameter (Argumente) entgegennehmen und mit dem Schlüsselwort `returning` in der Methodendefinition einen Wert _zurückgeben_. Methoden werden mit der Syntax `( )` aufgerufen.

```abap
CLASS my_class DEFINITION.

  PUBLIC SECTION.

    METHODS add
      IMPORTING
        num1          TYPE i
        num2          TYPE i
      RETURNING
        VALUE(result) TYPE i.

ENDCLASS.

CLASS my_class IMPLEMENTATION.

  METHOD add.
    result = num1 + num2.
  ENDMETHOD.

ENDCLASS.

add( num1 = 1 num2 = 3 ).
// => 4
```

> 💡 In ABAP gibt es _viele_ verschiedene Arten, Klassen und Methoden zu deklarieren. Der Track versucht, sie nach und nach einzuführen, aber wenn du sie schon kennst, kannst du jede davon verwenden. In den meisten Fällen ist die eine nicht besser oder schlechter als die andere.
