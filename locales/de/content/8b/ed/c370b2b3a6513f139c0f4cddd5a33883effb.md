# Hinweise

## Allgemeines

- Die [`Map`-API-Dokumentation][map-docs] enthält eine Liste der Methoden, die auf der `Map`-Schnittstelle verfügbar sind.

## 1. Gib die Codes in einer Map zurück

- Du musst eine `Map` auf [diese Weise][declaring-members] definieren, damit du sie in den Klassenmethoden verwenden kannst.

## 2. Füge Einträge zum Wörterbuch hinzu

- Maps haben eine [Methode][map-put-docs], um den Wert für einen Schlüssel hinzuzufügen und zu aktualisieren.

## 3. Schlage das Land zu einer Vorwahl nach

- Maps haben eine [Methode][map-get-docs], um den Wert eines Schlüssels abzurufen.

## 4. Erlaube keine Duplikate

- Es gibt eine Möglichkeit zu prüfen, ob die Map einen [Schlüssel][map-contains-key-docs] oder einen [Wert][map-contains-value-docs] enthält.

## 5. Finde die Vorwahl eines Landes

- Es gibt einen [Weg][map-entry-set-docs], um eine iterierbare Sammlung von Einträgen einer Map zu erhalten, mit der du die Schlüssel-Wert-Paare durchgehen kannst.

## 6. Aktualisiere die Vorwahl des Landes

- Vergiss nicht, dass die vorherige Vorwahl des Landes noch in der Map steht.
- Es gibt eine [Methode][map-remove-docs], um einen Eintrag aus der Map zu entfernen.
