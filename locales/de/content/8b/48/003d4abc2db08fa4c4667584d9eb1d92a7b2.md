# Einführung

Binärziffern entsprechen letztlich direkt den Transistoren in deiner CPU oder deinem Arbeitsspeicher und der Frage, ob jeder von ihnen „an“ oder „aus“ ist.

Die Manipulation auf niedriger Ebene, informell „Bit-Twiddling“ genannt, ist besonders wichtig in Systemsprachen.

Hochsprachen wie Julia blenden die meisten dieser Details normalerweise aus.
Allerdings bietet die Sprache selbst einen vollen Satz an Bitoperationen.

***Hinweis:*** Um in der REPL eine menschenlesbare Binärausgabe zu sehen, müssen fast alle Beispiele unten mit der Funktion `bitstring()` umschlossen werden.
Das lenkt visuell ab, deshalb wurden die meisten Vorkommen dieser Funktion entfernt.

## Bitverschiebungen

Ganzzahltypen, ob mit oder ohne Vorzeichen, lassen sich als eine Zeichenkette aus Einsen und Nullen darstellen.

```julia-repl
julia> bitstring(UInt8(5))
"00000101"
```

Bitverschiebungen verschieben einfach alles um eine angegebene Anzahl von Stellen nach links oder rechts.
Bei `UInt`-Typen fallen an einem Ende Bits weg, und das andere Ende wird mit Nullen aufgefüllt:

```julia-repl
julia> ux::UInt8 = 5
5

julia> bitstring(ux)
"00000101"

julia> ux << 2 # left by 2
"00010100"

julia> ux >> 1 # right by 1
"00000010"
```

Jede Verschiebung nach links verdoppelt den Wert, jede nach rechts halbiert ihn (mit eventuellem Abschneiden).
In der Dezimaldarstellung ist das offensichtlicher:

```julia-repl
julia> 3 << 2
12

julia> 24 >> 3
3
```

Solche Bitverschiebungen sind viel schneller als „richtige“ Arithmetik, weshalb die Technik in der Programmierung auf niedriger Ebene sehr beliebt ist.

Bei Ganzzahlen mit Vorzeichen müssen wir etwas vorsichtiger sein.

Verschiebungen nach links sind relativ einfach:

```julia-repl
julia> sx = Int8(5)
5

julia> sx # positive integer
"00000101"

julia> sx << 2
"00010100"

julia> -sx # negative integer
"11111011"

julia> -sx << 2
"11101100"
```

Das Verschieben positiver Ganzzahlen mit Vorzeichen nach links ist also dasselbe wie bei Ganzzahlen ohne Vorzeichen.

Negative Werte werden im [Zweierkomplement][2complement] gespeichert, das heißt, das linkeste Bit ist 1.
Für eine Verschiebung nach links kein Problem, aber wie füllen wir beim Verschieben nach rechts die linkesten Bits auf?

```julia-repl
julia> sx >> 2 # simple for positive values!
"00000001"

julia> -sx # negative integer
"11111011"

julia> -sx >> 2 # pad with repeated sign bit
"11111110"

julia> -sx >>> 2 # pad with 0
"00111110"
```

Der Operator `>>` führt eine arithmetische Verschiebung aus und erhält dabei das Vorzeichenbit.

Der Operator `>>>` führt eine logische Verschiebung aus und füllt mit Nullen auf, als wäre die Zahl ohne Vorzeichen.

## Bitweise Logik

In einem früheren Konzept haben wir gesehen, dass die Operatoren `&&` (und), `||` (oder) und `!` (nicht) mit booleschen Werten verwendet werden.

Es gibt die entsprechenden Operatoren `&` (bitweises Und), `|` (bitweises Oder) und `~` (eine Tilde, bitweises Nicht), um die Bits zweier Ganzzahlen zu vergleichen.

```julia-repl
julia> 0b1011 & 0b0010 # bit is 1 in both numbers
"00000010"

julia> 0b1011 | 0b0010 # bit is 1 in at least one number
"00001011"

julia> ~0b1011 # flip all bits
"11110100"

julia> xor(0b1011, 0b0010) # bit is 1 in exactly one number, not both
"00001001"
```

Hier ist `xor()` das exklusive Oder, verwendet als Funktion.

[2complement]: https://en.wikipedia.org/wiki/Two%27s_complement
