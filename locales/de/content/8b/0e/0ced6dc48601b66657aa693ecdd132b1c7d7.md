# Anweisungen

Du entwickelst gerade das neue, hoch angesehene Spiel **Crystal Hunter**.
In dem Spiel bist du eine Spielfigur, die sich umherbewegt und Kristalle sammelt.
Der Spieler gewinnt, wenn er alle Kristalle einsammelt.
Wenn der Spieler mit einem Banditen in Berührung kommt, verliert er alle seine Kristalle und das Spiel.
Es gibt eine Ausnahme von dieser Regel: Der Spieler kann ein aktives Power-up haben, das ihn für die Banditen unsichtbar macht.

Dein Ziel ist es, einige Regeln zu schreiben, die im Spiel verwendet werden.

## 1. Bestimme, ob die Spielfigur Bonuspunkte bekommt

In dem Spiel bekommt die Spielfigur Bonuspunkte, wenn sie einen Banditen berührt, während sie ein Power-up hat.

Definiere die Methode `Rules#bonus_points?`, die zwei Argumente entgegennimmt (_ob die Spielfigur ein aktives Power-up hat_ und _ob die Spielfigur einen Banditen berührt_) und einen booleschen Wert zurückgibt, der angibt, ob die Spielfigur Bonuspunkte bekommt.
Die Methode soll nur dann `true` zurückgeben, wenn die Spielfigur ein aktives Power-up hat und einen Banditen berührt, andernfalls `false`.

```Crystal
Rules.new.bonus_points?(false, true)
# => false
```

## 2. Bestimme, ob die Spielfigur punktet

Der Spieler bekommt in dem Spiel Punkte, wenn er einen Kristall oder ein Power-up einsammelt.

Definiere die Methode `Rules#score?`, die zwei Argumente entgegennimmt (_ob die Spielfigur ein Power-up berührt_ und _ob die Spielfigur einen Kristall berührt_) und einen booleschen Wert zurückgibt, der angibt, ob die Spielfigur gepunktet hat.
Die Methode soll `true` zurückgeben, wenn die Spielfigur ein Power-up oder einen Kristall berührt, andernfalls `false`.

```crystal
Rules.new.score?(true, true)
# => true
```

## 3. Bestimme, ob die Spielfigur verliert

Definiere die Methode `Rules#lose?`, die zwei Argumente entgegennimmt (_ob die Spielfigur ein aktives Power-up hat_ und _ob die Spielfigur einen Banditen berührt_) und einen booleschen Wert zurückgibt, der angibt, ob die Spielfigur verliert.
Die Methode soll `true` zurückgeben, wenn die Spielfigur einen Banditen berührt und kein aktives Power-up hat, andernfalls `false`.

```crystal
Rules.new.lose?(false, true)
# => true
```

## 4. Bestimme, ob die Spielfigur gewinnt

Definiere die Methode `Rules#win?`, die drei Argumente entgegennimmt (_ob die Spielfigur alle Kristalle eingesammelt hat_, _ob die Spielfigur ein aktives Power-up hat_ und _ob die Spielfigur einen Banditen berührt_) und einen booleschen Wert zurückgibt, der angibt, ob die Spielfigur gewinnt.
Die Methode soll `true` zurückgeben, wenn die Spielfigur alle Kristalle gesammelt hat und gemäß den in Teil 3 definierten Argumenten nicht verloren hat, andernfalls `false`.

```crystal
Rules.new.win?(false, true, false)
# => false
```
