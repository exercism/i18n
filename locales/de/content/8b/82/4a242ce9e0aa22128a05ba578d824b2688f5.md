# Hinweise

## Allgemeines

- Julia stellt standardmäßig viele mathematische Funktionen bereit, darunter [`gcd()`][ref-gcd] und [`invmod()`][ref-invmod].
- In Julia ist der Operator `%` die Infixform von [`rem()`][ref-rem].
  - Das unterscheidet sich von einigen anderen Sprachen, darunter Python und R, in denen sich `%` eher wie Julias [`mod()`][ref-mod] verhält.
  - Die Funktionen unterscheiden sich im Umgang mit negativen Ganzzahlen.

  [ref-gcd]: https://docs.julialang.org/en/v1/base/math/#Base.gcd
  [ref-invmod]: https://docs.julialang.org/en/v1/base/math/#Base.invmod
  [ref-rem]: https://docs.julialang.org/en/v1/base/math/#Base.rem
  [ref-mod]: https://docs.julialang.org/en/v1/base/math/#Base.mod
