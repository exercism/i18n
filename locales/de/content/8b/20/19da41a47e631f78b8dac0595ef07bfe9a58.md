# SQLite-spezifische Anweisungen

Die Spalte **result** sollte ein JSON-kodiertes Objekt aus Objekten enthalten, wobei jedes Wort als Schlüssel und seine Anzahl als Ganzzahl dient.

Betrachte zum Beispiel den obigen Satz: `"That's the password: 'PASSWORD 123'!", cried the Special Agent.\nSo I fled.`
Für diese Eingabe sollte **result** so aussehen:

```json
{"123":1,"agent":1,"cried":1,"fled":1,"i":1,"password":2,"so":1,"special":1,"that's":1,"the":2}
```

## Tabellenschema

```sql
CREATE TABLE "word-count" (
    sentence TEXT NOT NULL,
    result   TEXT               -- json object
);
```
