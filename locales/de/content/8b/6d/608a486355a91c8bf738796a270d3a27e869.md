# Tests


Wir verwenden [pytest][pytest: Getting Started Guide] als Test-Runner für unsere Website.
Wenn du die Tests für den Python-Track lokal ausführen möchtest, musst du `pytest` auf deinem Entwicklungsrechner installieren.
Außerdem solltest du die folgenden `pytest`-Plugins installieren:

- [pytest-cache][pytest-cache]
- [pytest-subtests][pytest-subtests]

Weiterführende Informationen findest du in unserem [Python-Testleitfaden][Python track tests page].


### Tests ausführen

Um die enthaltenen Tests auszuführen, wechsle in deinem Terminal mit `cd` in den Ordner, in dem die Übung gespeichert ist (_ersetze `<exercise-folder-location>` unten durch deinen Pfad_).
Testdateien enden normalerweise auf `_test.py` und sind dieselben Tests, die auf der Website laufen, wenn eine Lösung hochgeladen wird.

Linux/MacOS
```bash
$ cd <path/to/exercise-folder-location>
```

Windows
```powershell
PS C:\Users\foobar> cd <path\to\exercise-folder-location>
```

<br>

Führe als Nächstes den Befehl `pytest` in deinem Terminal aus und ersetze `<exercise_test.py>` durch den Namen der Testdatei:

Linux/MacOS
```bash
$ python3 -m pytest -o markers=task <exercise_test.py>
==================== 7 passed in 0.08s ====================
```

Windows
```powershell
PS C:\Users\foobar> py -m pytest -o markers=task <exercise_test.py>
==================== 7 passed in 0.08s ====================
```


### Häufige Optionen
- `-o` : überschreibt die voreingestellte `pytest.ini` (_damit kannst du Marker-Warnungen vermeiden_)
- `-v` : aktiviert ausführliche Ausgaben.
- `-x` : bricht den Testlauf beim ersten Fehler ab.
- `--ff` : führt zuerst die Fehlschläge aus dem vorherigen Testlauf aus, bevor andere Testfälle an die Reihe kommen.

Weitere Optionen findest du mit `python3 -m pytest -h` oder `py -m pytest -h`.


### Warnungen beheben

Wenn du beim Aufruf von `pytest` nicht `pytest -o markers=task` verwendest, erhältst du möglicherweise eine `PytestUnknownMarkWarning` für Tests, die unsere neue Syntax verwenden:

```bash
PytestUnknownMarkWarning: Unknown pytest.mark.task - is this a typo?  You can register custom marks to avoid this warning - for details, see https://docs.pytest.org/en/stable/mark.html
```

Um nicht bei jedem Test `pytest -o markers=task` eingeben zu müssen, kannst du eine Konfigurationsdatei `pytest.ini` verwenden.
Wir haben eine erstellt, die du im obersten Verzeichnis des Python-Tracks herunterladen kannst: [pytest.ini][pytest.ini].

Du kannst auch deine eigene `pytest.ini`-Datei mit folgendem Inhalt anlegen:

```ini
[pytest]
markers =
    task: A concept exercise task.
```

Wenn du die `pytest.ini`-Datei im _root_- oder _working_-Verzeichnis deiner Python-Track-Übungen ablegst, werden die Marker registriert und die Warnungen verschwinden.
Mehr Informationen zu pytest-Markern findest du in der `pytest`-Dokumentation zum [Markieren von Testfunktionen][pytest: marking test functions with attributes] und in der `pytest`-Dokumentation zum [Arbeiten mit benutzerdefinierten Markern][pytest: working with custom markers].

Informationen zum Anpassen von pytest-Konfigurationen findest du in der `pytest`-Dokumentation zu den [Formaten von Konfigurationsdateien][pytest: configuration file formats].
