# Debug

Wenn ein Test fehlschlägt, wird eine Meldung angezeigt, die beschreibt, was schiefgelaufen ist und bei welchem Eingabewert. Außerdem wird auch jede [Konsolenausgabe][programiz.com-basic-input-output] angezeigt, was du dir zunutze machen kannst. So schreibst du in die Konsole:

```csharp
Console.WriteLine("Debug message");
```
