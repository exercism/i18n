# Einführung

## Enums

Ein _Enum-Typ_ ist ein spezieller Datentyp, mit dem eine Variable einen Wert aus einer Menge vordefinierter Konstanten annehmen kann.
Der Wert der Variablen muss einem der Werte entsprechen, die für sie vordefiniert wurden.
Häufige Beispiele sind Himmelsrichtungen (Werte wie `NORTH`, `SOUTH`, `EAST` und `WEST`) und die Wochentage.

Da es sich um Konstanten handelt, werden die Namen der Felder eines Enum-Typs in Großbuchstaben geschrieben.

### Einen Enum-Typ definieren

In der Programmiersprache Java definierst du einen Enum-Typ mit dem Schlüsselwort `enum`.
Ein Enum-Typ für die Wochentage sieht zum Beispiel so aus:

```java
public enum DayOfWeek {
    SUNDAY,
    MONDAY,
    TUESDAY,
    WEDNESDAY,
    THURSDAY,
    FRIDAY,
    SATURDAY
}
```

Du solltest Enum-Typen immer dann verwenden, wenn du eine feste Menge von Konstanten darstellen musst.
Das umfasst natürliche Enum-Typen wie die Planeten unseres Sonnensystems und Datensätze, bei denen du zur Kompilierzeit alle möglichen Werte kennst, zum Beispiel Menüoptionen, Kommandozeilen-Flags und so weiter.

### Einen Enum-Typ verwenden

Hier ist etwas Code, der dir zeigt, wie du den oben definierten Enum-Typ `DayOfWeek` verwendest:

```java
public class Shop {
    public String getOpeningHours(DayOfWeek dayOfWeek) {
        switch (dayOfWeek) {
            case MONDAY:
            case TUESDAY:
            case WEDNESDAY:
            case THURSDAY:
            case FRIDAY:
                return "9am - 5pm";
            case SATURDAY:
                return "10am - 4pm"
            case SUNDAY:
                return "Closed.";
        }
    }
}
```

```java
var shop = new Shop();
shop.getOpeningHours(DayOfWeek.WEDNESDAY);
// => "9am - 5pm"
```

### Methoden und Felder hinzufügen

Enum-Typen in Java sind viel mächtiger als ihre Gegenstücke in anderen Sprachen.
Die `enum`-Deklaration definiert eine _Klasse_ (auch _Enum-Typ_ genannt).
Der Körper der Enum-Klasse kann Methoden und andere Felder enthalten:

```java
public enum Rating {
    GREAT(5),
    GOOD(4),
    OK(3),
    BAD(2),
    TERRIBLE(1);

    private final int numberOfStars;

    Rating(int numberOfStars) {
        this.numberOfStars = numberOfStars;
    }

    public int getNumberOfStars() {
        return this.numberOfStars;
    }
}
```

So rufst du die Methode `getNumberOfStars` für ein Mitglied des Enum-Typs `Rating` auf:

```java
Rating.GOOD.getNumberOfStars();
// => 4
```
