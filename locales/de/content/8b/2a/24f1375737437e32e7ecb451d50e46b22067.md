# Einführung

Filtern ist der Vorgang, aus einer Sequenz eine andere Sequenz zu erzeugen, indem alle bis auf bestimmte Elemente der ursprünglichen Sequenz übernommen werden.
Die Auswahl, welche Elemente in die neue Sequenz aufgenommen werden, kann über eine Prädikatsfunktion erfolgen (eine Funktion, die einen booleschen Wert ergibt) oder über Gleichheit mit einem bestimmten Objekt.

## Entfernen anhand eines Prädikats

`remove-if` ist eine Funktion, die eine Prädikatsfunktion und eine Sequenz als Argumente nimmt und eine Sequenz zurückgibt, die nur die Elemente enthält, für die das Prädikat falsch ergab.
Mit anderen Worten: Sie „entfernt“ alle Elemente der Sequenz, für die das Prädikat wahr ergibt. Beachte aber, dass diese Funktion die ursprüngliche Sequenz nicht verändert!
Stattdessen gibt sie eine neue Sequenz ohne die entsprechenden Elemente zurück. Wenn das Prädikat für alle Werte wahr war, wird eine leere Sequenz zurückgegeben.

```lisp
(remove-if #'evenp '(1 2 3 4 5)) ; => (1 3 5)
(remove-if #'oddp '(1 3 5))      ; => ()
```

## Ein bestimmtes Element entfernen

Wenn du ein bestimmtes Element aus einer Sequenz entfernen möchtest, kannst du `remove` verwenden. Diese Funktion nimmt das zu entfernende Element und eine Sequenz.
Alle Werte in der Sequenz, die nicht gleich dem zu entfernenden Element sind, werden zurückgegeben.
HINWEIS: Standardmäßig wird die Gleichheit mit dem [generischen Gleichheitsprädikat][concept-equality] `eql` geprüft.

```lisp
(remove 1 '(1 2 1 3 1 4)) ; => (2 3 4)
(remove #\l "hello")      ; => "heo"
```
