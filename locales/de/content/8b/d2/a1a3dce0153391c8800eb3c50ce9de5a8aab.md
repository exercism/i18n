# Einführung

In Elixir verwenden wir `Enum.random`, um ein zufälliges Element aus einer aufzählbaren Datenstruktur (z. B. Liste, Bereich) auszuwählen. Diese Funktion wählt ein einzelnes Element aus, wobei jedes Element mit der gleichen Wahrscheinlichkeit ausgewählt wird.

Elixir hat keine eigenen Funktionen, um eine zufällige Gleitkommazahl auszuwählen. Dafür müssen wir Erlang direkt verwenden.
