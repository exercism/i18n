# Anleitung

Deine Aufgabe ist es, einen Passwort-Checker zu erstellen.
Ein Passwort-Checker überprüft das vorgeschlagene Passwort eines Benutzers. Er stellt sicher, dass es die Anforderungen erfüllt. Diese werden von der Organisation festgelegt, die den Zugriff auf die jeweilige Ressource kontrolliert.

Für diese Übung sind die Passwortanforderungen:
* Muss mindestens 12 Zeichen haben
* Muss mindestens einen Großbuchstaben enthalten
* Muss mindestens einen Kleinbuchstaben enthalten
* Muss mindestens eine Ziffer enthalten
* Muss mindestens ein Symbol aus der Menge !@#$%^&* enthalten

Deine Lösung muss ein `Result` verwenden, um den Erfolgs- oder Fehlerstatus zu kapseln.
Im Erfolgsfall muss das `Result` das validierte Passwort als String enthalten.
Im Fehlerfall muss das `Result` die Regel enthalten, die verletzt wurde.

~~~~exercism/note
Für diese Übung ist der Passwort-Checker einfach gehalten: Er zeigt nur an, wenn eine einzelne Regel verletzt wurde.
Eine spätere Übung behandelt einen realistischeren Passwort-Checker, der anzeigen kann, wenn mehrere Regeln gleichzeitig verletzt wurden.
~~~~

## 1. Implementiere die Funktion `checkPassword`

Die Funktion `checkPassword` prüft das angegebene Passwort gegen die oben genannten Regeln. Bei einem Fehler gibt sie die verletzte Regel an, indem sie einen der Werte von `PasswordRule` in den Ergebniswert einbettet.

```fsharp
checkPassword "abcdefghij5#"
// => Error MissingUppercaseLetter
```

## 2. Implementiere die Funktion ``getStatusMessage`

Die Funktion `getStatusMessage` gibt einen String zurück. Dieser enthält eine menschenlesbare Nachricht, die die Bedeutung des von `checkPassword` zurückgegebenen Ergebnisses angibt.

```fsharp
getStatusMessage (Error MissingDigit)
// => "Error: does not have at least one digit"
```
