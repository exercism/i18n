# Instructions

Du schreibst ein eingebettetes System für einen Wartenummern-Automaten. Es ist ein sehr einfaches Modell. Er kann fortlaufende Nummern ausgeben und melden, welche Nummer zuletzt ausgegeben wurde.

## 1. Starte den Automaten

Implementiere die Funktion `start/0`. Sie soll einen neuen Prozess erzeugen und die PID des Prozesses zurückgeben. Der neue Prozess muss noch nichts tun.

```elixir
TakeANumber.start()
# => #PID<0.138.0>
```

Beachte, dass die PID bei jedem Ausführen dieses Codes anders sein kann.

## 2. Melde den Zustand des Automaten

Passe den Automaten so an, dass der neu erzeugte Prozess bereit ist, Nachrichten zu empfangen (starte eine _Empfangsschleife_), mit einem Anfangszustand von `0`. Er soll Nachrichten `{:report_state, sender_pid}` empfangen können. Als Antwort auf solche Nachrichten soll er seinen aktuellen Zustand (die zuletzt ausgegebene Nummer) an `sender_pid` senden und dann auf weitere Nachrichten warten.

```elixir
machine_pid = TakeANumber.start()

# a client sending a message to the machine
send(machine_pid, {:report_state, self()})

# a client receiving a message from the machine
receive do
  msg -> msg
end

# => 0
```

## 3. Gib Nummern aus

Passe den Automaten so an, dass er Nachrichten `{:take_a_number, sender_pid}` empfangen kann. Er soll seinen Zustand um 1 erhöhen, den neuen Zustand an `sender_pid` senden und dann auf weitere Nachrichten warten.

```elixir
machine_pid = TakeANumber.start()

# a client sending a message to the machine
send(machine_pid, {:take_a_number, self()})

# a client receiving a message from the machine
receive do
  msg -> msg
end

# => 1
```

## 4. Stoppe den Automaten

Passe den Automaten so an, dass er eine `:stop`-Nachricht empfangen kann. Er soll aufhören, auf weitere Nachrichten zu warten.

## 5. Ignoriere unerwartete Nachrichten

Passe den Automaten so an, dass er eine unerwartete Nachricht ignoriert und weiter auf weitere Nachrichten wartet.
