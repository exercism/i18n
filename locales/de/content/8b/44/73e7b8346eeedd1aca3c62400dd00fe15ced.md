# Ergänzende Anweisungen

## Bonusaufgaben

Wenn du dich an diesen Aufgaben versuchst, schreib bitte eigene Tests dafür in deine Lösungsdatei!

* Definiere ein String-Makro, sodass `isbn"3-598-21507-X" == ISBN("3-598-21507-X")`.

* Lass den Konstruktor auch ISBN-13-Nummern akzeptieren. Dieselbe ISBN soll unabhängig vom Format gleich sein: `ISBN("1-234-56789-X") == ISBN("978-1-234-56789-7")`.

* Definiere eine Funktion oder einen Iterator, um eine gültige ISBN zu erzeugen, vielleicht sogar ausgehend von einer gegebenen Start-ISBN.

 Kannst du die ISBN als Ganzzahl statt als String speichern, und wäre das jemals eine gute Idee?
 Wenn du es tätest, könntest du die ISBN dann noch (inklusive Prüfziffer) als String ausgeben?
