# Einführung

Im Gegensatz zu vielen anderen Sprachen gibt es in JavaScript zwei verschiedene Dinge, die das Fehlen eines (sinnvollen) Werts darstellen.
Es gibt `null` und `undefined`.

## Null

Der primitive Wert `null` wird als absichtlicher „leerer Wert“ für Variablen jedes Typs verwendet.

```javascript
let name = null;
// name is intentionally set to "empty" because it is not
// available
```

Du kannst mit dem [Operator für strikte Gleichheit][mdn-strict-equality] `===` prüfen, ob eine Variable null ist.

```javascript
let name = null;

name === null;
// => true
```

## Undefined

> Eine Variable, der kein Wert zugewiesen wurde, hat den Typ `undefined`.<sup>1</sup>

Das heißt, während `null` einen leeren Wert (aber immer noch einen Wert) darstellt, steht `undefined` für die völlige Abwesenheit eines Werts. 🤯

`undefined` tritt in verschiedenen Zusammenhängen auf.

- Wenn eine Variable ohne einen Wert (Initialisierung) deklariert wird, ist sie `undefined`.
- Wenn du auf den Wert eines nicht existierenden Schlüssels in einem Objekt zugreifen willst, bekommst du `undefined`.
- Wenn eine Funktion keinen Wert zurückgibt, ist das Ergebnis `undefined`.
- Wenn ein Argument nicht an eine Funktion übergeben wird, ist es `undefined`, es sei denn, dieses Argument hat einen Standardwert.

```javascript
let name;
console.log(name);
// => undefined
```

Du kannst mit dem Operator für strikte Gleichheit `===` prüfen, ob eine Variable undefined ist.

```javascript
let name;

name === undefined;
// => true
```

## Optional Chaining

Wenn du versuchst, einen verschachtelten Wert in einem Objekt abzurufen, der übergeordnete Schlüssel aber nicht existiert, wirft JavaScript einen Fehler.
Um das auf einfache Weise zu vermeiden, wurde Optional Chaining im Jahr 2020 zur Sprachspezifikation hinzugefügt.
Mit dem Optional-Chaining-Operator `?.` kannst du sicherstellen, dass JavaScript nur dann auf den verschachtelten Schlüssel zuzugreifen versucht, wenn der übergeordnete Schlüssel nicht `null` oder `undefined` war.
Andernfalls wird `undefined` zurückgegeben.

```javascript
const obj = {
  address: {
    street: 'Trincomalee Highway',
    city: 'Batticaloa',
  },
};

obj.address.zipCode;
// => undefined

obj.residence.street;
// => TypeError: Cannot read property 'street' of undefined

obj.residence?.street;
// => undefined
```

## Nullish Coalescing

Es gibt Situationen, in denen du einen Standardwert anwenden möchtest, falls eine Variable null oder undefined ist (aber nur dann).
Um das zu ermöglichen, wurde der Nullish-Coalescing-Operator `??` im Jahr 2020 eingeführt.
Er gibt nur dann den rechten Operanden zurück, wenn der linke Operand `null` oder `undefined` ist.
Andernfalls wird der linke Operand zurückgegeben.

```javascript
let amount = null;
amount = amount ?? 1;
// => 1

amount = 0;
amount = amount ?? 1;
// => 0
```
