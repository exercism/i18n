# Anweisungen

Dein Freund Kojo ist ein großer Zahlenfan.
Er hat eine kleine Website namens „fun-with-numbers“.
Kojo ist nicht besonders gut im Programmieren, deshalb hat er dich um Hilfe gebeten.

Du wirst zwei Hilfsfunktionen für neue Zahlenspiele auf Kojos Website bauen und eine dritte, um eine Eingabe des Nutzers zu prüfen.

## 1. Berechne die Summe der Zahlen auf dem Spielautomaten

Eines der Spiele auf Kojos Website sieht aus wie ein Spielautomat, der zwei Gruppen von Walzen mit Ziffern darauf zeigt.
Jede Zifferngruppe stellt eine Zahl dar.
Für die Spielmechanik muss Kojo die Summe dieser beiden Zahlen kennen.

Schreibe eine Funktion `twoSum`, die zwei Arrays als Parameter entgegennimmt.
Jedes Array besteht aus einer oder mehreren Zahlen zwischen 0 und 9.
Die Funktion soll jedes Array als eine Zahl interpretieren und die Summe dieser beiden Zahlen zurückgeben.

```javascript
twoSum([1, 2, 3], [0, 7]);
//=> 130

// [1, 2, 3] represents 123 and [0, 7] represents 7.
// 123 + 7 = 130
```

## 2. Prüfe, ob eine Zahl ein Palindrom ist

Ein weiteres Spiel auf der Website ist ein kleines Quiz namens „Lucky Numbers“.
Ein Nutzer kann eine Zahl eingeben und sieht dann, ob die Zahl zu einer geheimen Folge oder einem Muster gehört.
Die Folge oder das Muster der „lucky numbers“ ändert sich jeden Monat, und jeder Nutzer hat nur eine begrenzte Anzahl von Versuchen, um sie zu erraten.

Die Glückszahlen dieses Monats sollen Zahlen sein, die Palindrome sind.
Palindromzahlen bleiben gleich, wenn man ihre Ziffern umdreht.

Implementiere die neue Funktion `luckyNumber`, die eine Zahl als Parameter entgegennimmt.
Die Funktion soll `true` zurückgeben, wenn die Zahl ein Palindrom ist, andernfalls `false`.
Die eingegebene Zahl ist immer eine positive Ganzzahl.

```javascript
luckyNumber(1441);
//=>  true

luckyNumber(123);
//=> false
```

## 3. Erzeuge eine Fehlermeldung für ungültige Nutzereingaben

An verschiedenen Stellen auf der Website gibt es Eingabefelder, in die Nutzer Zahlen eingeben und dann auf einen Button klicken können, um eine Aktion auszulösen.
Kojo möchte die Nutzererfahrung seiner Website verbessern.
Er möchte eine Fehlermeldung anzeigen, wenn der Nutzer auf den Button klickt, das Feld aber einen ungültigen Eingabewert enthält.

Hier sind noch ein paar Informationen dazu, wie der Wert eines Eingabefelds bereitgestellt wird.

- Wenn der Nutzer etwas in ein Feld tippt, ist der zugehörige Wert immer ein String, auch wenn er nur Zahlen eingegeben hat.
- Wenn der Nutzer etwas eingibt und es dann wieder löscht, ist die Variable ein leerer String.
- Bevor der Nutzer überhaupt mit dem Tippen begonnen hat, kann die Variable `undefined` oder `null` sein.

Schreibe eine Funktion `errorMessage`, die die Nutzereingabe als Parameter entgegennimmt.
Wenn der Nutzer keine Eingabe gemacht hat, soll `errorMessage` `'Required field'` zurückgeben.
Wenn die Eingabe keine Zahl ungleich 0 darstellt (gemäß den Umwandlungsregeln von JavaScript), soll `'Must be a number besides 0'` zurückgegeben werden.
In allen anderen Fällen kannst du davon ausgehen, dass die Eingabe gültig ist; der Rückgabewert sollte ein leerer String sein.

```javascript
errorMessage('123');
// => ''

errorMessage('');
// => 'Required field'

errorMessage('abc');
// => 'Must be a number besides 0'
```
