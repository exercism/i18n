# Einführung

Ein JSON-**Objekt** ist, um die Terminologie anderer Sprachen zu verwenden, ein „Hash“, „Map“ oder „Wörterbuch“.

JSON definiert ein _Objekt_ wie folgt:

> Ein Objekt ist eine ungeordnete Menge von **Name**/**Wert**-Paaren.
> Ein Objekt beginnt mit `{` (linke geschweifte Klammer) und endet mit `}` (rechte geschweifte Klammer).
> Auf jeden _Namen_ folgt `:` (Doppelpunkt) und die _Name/Wert_-Paare werden durch `,` (Komma) getrennt.

Der _Name_ **muss ein String sein**.
Ein anderes Wort für _Name_ ist _Schlüssel_.

Der _Wert_ kann von jedem JSON-Typ sein.
Verschiedene _Werte_ im selben Objekt können von unterschiedlichen Typen sein, wie dieses Beispiel zeigt.

<!-- prettier-ignore -->
```json
{
  "name": "Jane",
  "age": 42,
  "pets": ["cat", "fish"],
  "address": {"street": "123 Main St", "city": "Springfield"}
}
```

<!-- prettier-ignore-end -->

Beachte, dass nach dem _letzten_ Schlüssel-Wert-Paar **kein** Komma stehen darf.

## Objekte erstellen

Verwende geschweifte Klammern, um die Name/Wert-Paare zu sammeln.
Auch wenn die Namen Strings sein müssen, müssen sie nicht in Anführungszeichen gesetzt werden, wenn die Namen **bezeichnerähnlich** sind (aus alphanumerischen Zeichen und Unterstrich bestehend und nicht mit einer Ziffer beginnend).

```jq
{name: "Jane", age: 42}
```

Es ist erlaubt, Schlüssel zu verwenden, die nicht _bezeichnerähnlich_ sind.
Setze sie einfach in Anführungszeichen.

```jq
{"first name": "Jane", "last name": "Lopez", age: 42}
```

Wenn der Name das Ergebnis eines Ausdrucks ist, **muss** der Ausdruck in runden Klammern stehen.

```sh
$ echo "Jane" | jq -Rc '{.: 42}'
# verbose error message ...

$ echo "Jane" | jq -Rc '{(.): 42}'
{"Jane":42}
```

## Indexierung

Werte werden aus einem Objekt mit der **Punktnotation** abgerufen.

```jq
{name: "Jane", age: 42} | .age    # => 42
```

Wenn du den Schlüssel nicht als Bezeichner angeben kannst, verwende die **Klammernotation**.

```jq
"name" as $key | {name: "Jane", age: 42} | .$key    # => error
"name" as $key | {name: "Jane", age: 42} | .[$key]  # => "Jane"
```

## Schlüssel-Wert-Paare hinzufügen oder ändern

Um ein neues Schlüssel-Wert-Paar zu einem Array hinzuzufügen oder den Wert eines vorhandenen Schlüssels zu aktualisieren, verwende den Zuweisungsoperator `=`, mit einem Indexausdruck auf der linken Seite.

```jq
{name: "Jane", age: 42} | .sport = "tennis" | .age = 21
# => {
#      "name": "Jane",
#      "age": 21,
#      "sport": "tennis"
#    }
```

Der Operator `+` wird Objekte _zusammenführen_.

```jq
{Richard: 54} + {Jane: 42}
# => {
#      "Richard": 54,
#      "Jane": 42
#    }
```

## Einen Schlüssel entfernen

Verwende die Funktion `del`, um einen Schlüssel zu entfernen.
Sie gibt das aktualisierte Objekt zurück.

```jq
{name: "Jane", age: 42} | del(.age)   # => {"name": "Jane"}
```

Der Parameter von `del` ist ein **Indexausdruck** (mit Punkt- oder Klammernotation), der sich zu einem Schlüssel im Objekt auflöst.
`jq` nennt ihn einen **Pfadausdruck**.
Es reicht nicht aus, einfach einen String anzugeben.

```jq
{name: "Jane", age: 42} | del(name)        # error: name/0 is not defined
{name: "Jane", age: 42} | del("name")      # error: Invalid path expression with result "name"
{name: "Jane", age: 42} | del(.name)       # OK
{name: "Jane", age: 42} | del(.["name"])   # OK
```

## Zugehörigkeit

- Um zu testen, ob das Objekt einen Schlüssel hat, verwende die Funktion `has`.

  ```jq
  {name: "Jane", age: 42} as $example
  |
    ($example | has("name")),    # => true
    ($example | has("sport"))    # => false
  ```

- Teste mit `in`, ob ein Schlüssel in einem Objekt ist.

  ```jq
  {name: "Jane", age: 42} as $example
  |
    ("name"  | in($example)),    # => true
    ("sport" | in($example))     # => false
  ```

## Alle Schlüssel auflisten

Verwende die Funktion `keys`, um eine Liste aller Schlüssel auszugeben.

```jq
{name: "Jane", age: 42} | keys   # => ["age", "name"]
```

Beachte, dass `keys` die Schlüssel _sortiert_.
Um die Schlüssel in der ursprünglichen Reihenfolge abzurufen, verwende `keys_unsorted`.

Es gibt keine entsprechende Funktion, um alle _Werte_ aufzulisten.
Der Filter `.[]` gibt jedoch die Objektwerte als _Stream_ aus, und dieser Stream kann mit dem Array-Konstruktor `[...]` erfasst werden.

```jq
[{first: "Jane", last: "Lopez", status: "awesome!"} | .[]]
# => ["Jane", "Lopez", "awesome!"]
```

## Iterieren

- Die Funktion `map_values(filter)` wendet den Filter auf jeden _Wert_ im Objekt an.

  ```jq
  {first: "Jane", last: "Lopez", status: "awesome!"}
  | map_values(ascii_upcase)
  # => {"first": "JANE", "last": "LOPEZ", "status": "AWESOME!"}
  ```

- Um über ein Objekt zu iterieren, müssen wir es zuerst in ein Array von Schlüssel-Wert-Objekten umwandeln.
  Die Funktion `to_entries` macht das.

  ```jq
  {name: "Jane", age: 42} | to_entries'
  # => [
  #      {
  #        "key": "name",
  #        "value": "Jane"
  #      },
  #      {
  #        "key": "age",
  #        "value": 42
  #      }
  #    ]
  ```

  An diesem Punkt können wir Array-Iterationsfunktionen wie `map` verwenden.

- Die Funktion `from_entries` ist die Umkehrung: Sie wandelt ein Array von Schlüssel-Wert-Objekten in ein Objekt um.

  ```jq
  [
    {"key":"name", "value":"Jane"},
    {"key":"age", "value":42}
  ] | from_entries                  # =>{"name": "Jane", "age": 42}
  ```

- Um einen Filter auf _jedes_ Schlüssel-Wert-Paar in einem Objekt anzuwenden, verwende die Funktion `with_entries(filter)`.

  Zum Beispiel können bei einem Objekt, das einen Namen auf ein Alter abbildet, die Schlüssel und Werte wie folgt vertauscht werden.

  ```jq
  {"Jane": 42, "Richard": 54}
  | with_entries({key: (.value | tostring), value: .key})
  ```

  ergibt

  ```json
  {
    "42": "Jane",
    "54": "Richard"
  }
  ```

  `with_entries(filter)` ist dasselbe wie

  ```jq
  to_entries | map(filter) | from_entries
  ```
