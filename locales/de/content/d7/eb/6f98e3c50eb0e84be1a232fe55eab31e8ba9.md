# Hinweise

## Allgemein

- Ein [Ganzzahlwert][integers] kann als eine oder mehrere aufeinanderfolgende Ziffern definiert werden.

## 1. Definiere die erwartete Backzeit in Minuten

- Du musst eine [Methode][methods] ohne Argumente definieren.
- Du musst eine [Ganzzahl][integers] zurückgeben.

## 2. Berechne die verbleibende Backzeit in Minuten

- Du musst eine [Methode][methods] mit einem einzelnen Parameter definieren.
- Du musst aus einer Methode [explizit eine Ganzzahl zurückgeben][return].
- Der Parameter der Methode ist eine [Ganzzahl][integers].
- Du kannst den [mathematischen Operator für die Subtraktion][operators] verwenden, um Werte zu subtrahieren.

## 3. Berechne die Vorbereitungszeit in Minuten

- Du musst eine [Methode][methods] mit einem einzelnen Parameter definieren.
- Du musst aus einer Methode [explizit eine Ganzzahl zurückgeben][return].
- Der Parameter der Methode ist eine [Ganzzahl][integers].
- Du kannst den [mathematischen Operator für die Multiplikation][operators] verwenden, um Werte zu multiplizieren.

## 4. Berechne die verstrichene Zeit in Minuten

- Du musst eine [Methode][methods] mit zwei Parametern definieren.
- Du musst aus einer Methode [explizit eine Ganzzahl zurückgeben][return].
- Der Parameter der Methode ist eine [Ganzzahl][integers].
- Du kannst eine der anderen Methoden, die du zuvor definiert hast, [aufrufen][invocation].
- Du kannst den [mathematischen Operator für die Addition][operators] verwenden, um Werte zu addieren.
