# Überblick

Elixir stellt die Werte wahr und falsch mit dem booleschen Typ dar. Es gibt nur zwei Werte: `true` und `false`. Diese Werte lassen sich mit booleschen Operatoren kombinieren ([`and/2`][strict-and], [`or/2`][strict-or], [`not/1`][strict-not]):

```elixir
true_variable = true and true
false_variable = true and false

true_variable = false or true
false_variable = false or false

true_variable = not false
false_variable = not true
```

Die Operatoren [`and/2`][strict-and], [`or/2`][strict-or] und [`not/1`][strict-not] sind strikt boolesch. Das bedeutet, dass ihr _erstes_ Argument ein boolescher Wert sein muss. Es gibt auch äquivalente boolesche Operatoren, die mit beliebigen Argumenttypen arbeiten: [`&&/2`][and], [`||/2`][or] und [`!/1`][not].

Boolesche Operatoren nutzen die _Kurzschlussauswertung_. Das heißt, der Ausdruck auf der rechten Seite des Operators wird nur ausgewertet, wenn es nötig ist.

Jeder der Operatoren hat eine andere Priorität, wobei `not/1` vor `and/2` und `or/2` ausgewertet wird. Mit Klammern kannst du einen Teil des Ausdrucks vor den anderen auswerten:

```elixir
not true and false
# => false

not (true and false)
# => true
```

Wenn du eine Funktion schreibst, die einen booleschen Wert zurückgibt, ist es [üblich, den Funktionsnamen][naming] mit einem `?` zu beenden. Dieselbe Konvention kannst du für Variablen verwenden, die boolesche Werte speichern.

```elixir
def either_true?(a?, b?) do
  a? or b?
end
```
