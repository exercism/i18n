# Anleitung

Sarah arbeitet an einem neuen Rollenspiel und braucht deine Hilfe bei der Mechanik des Spielers.

## 1. Definiere das `player`-Tupel

Definiere eine Tupelklasse `player` mit vier Slots und Standardwerten:

| Slot     | Standardwert |
| -------- | ------------ |
| `name`   | `f`          |
| `level`  | `0`          |
| `health` | `100`        |
| `mana`   | `f`          |

Nach der Definition kannst du einen Spieler als Literal erzeugen:

```factor
T{ player { name "Merlin" } { level 5 } } .
! => T{ player { name "Merlin" } { level 5 } }
```

## 2. Stelle den Spieler vor

Definiere `introduce` so, dass der Name des Spielers zurückgegeben wird. Heimliche Spieler verbergen ihren Namen (`name` ist `f`) und sollten als `"Mighty Magician"` vorgestellt werden.

```factor
T{ player { name "Merlin" } } introduce .
! => "Merlin"

T{ player { health 8 } } introduce .
! => "Mighty Magician"
```

## 3. Belebe einen gefallenen Spieler wieder

Definiere `revive` so, dass ein *neuer* Spieler zurückgegeben wird, bei dem `health` auf 100 und `mana` auf 100 gesetzt ist, aber nur, wenn `health` des Spielers `0` ist. Ist der Spieler noch am Leben, gib `f` zurück.

```factor
T{ player { name "Merlin" } { health 0 } } revive .
! => T{ player { name "Merlin" } { health 100 } { mana 100 } }

T{ player { health 50 } } revive .
! => f
```

## 4. Nimm Schaden

Definiere `take-damage` so, dass ein *neuer* Spieler zurückgegeben wird, dessen `health` um den angegebenen Betrag verringert wurde und dabei nie unter `0` fällt.

```factor
T{ player { health 100 } } 30 take-damage .
! => T{ player { health 70 } }

T{ player { health 5 } } 30 take-damage .
! => T{ player { health 0 } }
```
