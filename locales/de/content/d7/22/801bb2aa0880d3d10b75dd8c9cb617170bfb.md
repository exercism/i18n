# Ergänzung zur Anleitung

## Reservierter Speicher

Die Bytes 1024 bis 1279 des linearen Speichers sind für den Eingabe-String reserviert.

Der Eingabe-String kann bei Bedarf an Ort und Stelle geändert werden.

## Eingabeformat

Die Codons werden als String aneinandergehängt und ohne Padding übergeben.

## Ausgabeformat

Gib die Proteinsequenz als nullterminierten String aus, mit einem Zeilenumbruch nach jedem Protein.

Eine Beispielausgabe wäre `"Methionine\nPhenylalanine\nSerine\n"`

Wenn die Eingabe ungültig ist, gib einen leeren String aus.
