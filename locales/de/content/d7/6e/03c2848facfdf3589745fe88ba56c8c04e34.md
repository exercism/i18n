# Ergänzung zu den Anweisungen

## Hinweise

Das ist die erste Übung, deren Tests verlangen, dass du eine [`Exception`][exception-docs] wirfst. `Exception`s werden normalerweise geworfen, um anzuzeigen, dass ein Programm auf eine unerwartete Eingabe oder einen unerwarteten Zustand gestoßen ist.

Die Tests im gesamten Track prüfen, dass die Exceptions, die du wirfst:

1. Instanzen eines bestimmten Java-Typs sind;
2. (optional) mit einer bestimmten Nachricht initialisiert sind.

[exception-docs]: https://docs.oracle.com/javase/8/docs/api/java/lang/Exception.html
