# Einführung

Typumwandlungen in Cairo ermöglichen es dir, Daten von einem Typ in einen anderen umzuwandeln. Das erlaubt eine flexible und sichere Datenmanipulation.

## Grundlagen

Cairo bietet mehrere Mechanismen für die Typumwandlung:

### Direktes Casting

Bei kompatiblen numerischen Typen kannst du direktes Casting verwenden:

```rust
let small_number: u8 = 42;
let big_number: u32 = small_number.into();
```

### Das Into-Trait

Das `Into`-Trait ermöglicht die Umwandlung von einem Typ in einen anderen:

```rust
let value: u16 = 100;
let converted: u32 = value.into();
```

### Das TryInto-Trait

Für Umwandlungen, die fehlschlagen können, verwende `TryInto`, das eine `Option` zurückgibt:

```rust
let large_value: u32 = 70000;
let small_value: Option<u16> = large_value.try_into();

match small_value {
    Option::Some(v) => println!("Converted: {}", v),
    Option::None => println!("Conversion failed"),
}
```

## Eigene Typumwandlungen

Du kannst `Into` für deine eigenen Typen implementieren:

```rust
#[derive(Drop)]
struct Celsius {
    value: i32,
}

#[derive(Drop)]
struct Fahrenheit {
    value: i32,
}

impl CelsiusIntoFahrenheit of Into<Celsius, Fahrenheit> {
    fn into(self: Celsius) -> Fahrenheit {
        Fahrenheit { value: (self.value * 9) / 5 + 32 }
    }
}
```

## Sicherheitsaspekte

- Verwende `TryInto`, wenn die Umwandlung fehlschlagen kann (z. B. von großen zu kleinen Typen)
- Verwende `Into`, wenn die Umwandlung immer gelingt
- Behandle immer die `Option::None`-Fälle von `TryInto`
- Achte auf Überlauf und Unterlauf, wenn du zwischen vorzeichenbehafteten und vorzeichenlosen Typen umwandelst
