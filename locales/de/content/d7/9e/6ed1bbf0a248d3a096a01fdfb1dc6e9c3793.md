# Instructions

In dieser Übung implementierst du einige Regeln aus [Pac-Man][Pac-Man], dem klassischen Arcade-Spiel aus den 1980er-Jahren.

Es gibt vier Regeln zu implementieren, die alle mit den Spielzuständen zusammenhängen.

> _Mach dir keine Gedanken darüber, wie die Argumente zustande kommen. Konzentriere dich darauf, sie so zu kombinieren, dass das gewünschte Ergebnis zurückgegeben wird._

## 1. Definiere, ob Pac-Man einen Geist frisst

Definiere die Funktion `eat_ghost()`, die zwei Parameter entgegennimmt (_ob Pac-Man eine Kraftpille aktiv hat_ und _ob Pac-Man einen Geist berührt_) und einen booleschen Wert zurückgibt, ob Pac-Man einen Geist fressen kann. Die Funktion sollte nur dann `True` zurückgeben, wenn Pac-Man eine Kraftpille aktiv hat und einen Geist berührt.

```python
>>> eat_ghost(False, True)
...
False
```

## 2. Definiere, ob Pac-Man punktet

Definiere die Funktion `score()`, die zwei Parameter entgegennimmt (_ob Pac-Man eine Kraftpille berührt_ und _ob Pac-Man einen Punkt berührt_) und einen booleschen Wert zurückgibt, ob Pac-Man gepunktet hat. Die Funktion sollte `True` zurückgeben, wenn Pac-Man eine Kraftpille oder einen Punkt berührt.

```python
>>> score(True, True)
...
True
```

## 3. Definiere, ob Pac-Man verliert

Definiere die Funktion `lose()`, die zwei Parameter entgegennimmt (_ob Pac-Man eine Kraftpille aktiv hat_ und _ob Pac-Man einen Geist berührt_) und einen booleschen Wert zurückgibt, ob Pac-Man verliert. Die Funktion sollte `True` zurückgeben, wenn Pac-Man einen Geist berührt und keine Kraftpille aktiv hat.

```python
>>> lose(False, True)
...
True
```

## 4. Definiere, ob Pac-Man gewinnt

Definiere die Funktion `win()`, die drei Parameter entgegennimmt (_ob Pac-Man alle Punkte gefressen hat_, _ob Pac-Man eine Kraftpille aktiv hat_ und _ob Pac-Man einen Geist berührt_) und einen booleschen Wert zurückgibt, ob Pac-Man gewinnt. Die Funktion sollte `True` zurückgeben, wenn Pac-Man alle Punkte gefressen hat und gemäß den in Teil 3 definierten Regeln nicht verloren hat.

```python
>>> win(False, True, False)
...
False
```
