# Tests

Um die Tests auszuführen, installiere zuerst das Paket `z3-solver`:

```
pip install z3-solver
```

Danach kannst du die Tests ausführen, indem du den folgenden Befehl im Verzeichnis der Übung eingibst:

```
python <snake_case_exercise>_test.py
```

Dabei ersetzt du `<snake_case_exercise>` durch den Namen der Übung.
