# Anleitung

Lilly, das Lisp-Alien, liebt es zu kochen. Sie möchte mit ihren Freunden eine Pizza-Party schmeißen, aber um das Beste aus ihren Zutaten herauszuholen, möchte sie vorher genau wissen, wie viel sie von jeder Zutat braucht.

Um das zu lösen, hat Lilly ein Programm entworfen, das einen Teil der Planung automatisieren soll, aber sie braucht deine Hilfe, um es fertigzustellen.
Hilfst du Lilly dabei, die perfekt proportionierte Pizza-Party zu schmeißen?

## 1. Ein Teigverhältnis

Eins nach dem anderen: Jede großartige Pizza beginnt mit einem leckeren Teig!

Lilly mag dünne, knusprige Pizzas mit einem dickeren Rand.
Der Teig für die Mitte beträgt konstant 200 g, aber jeder 20 cm Rand benötigt 45 g Teig.

Zum Glück hat Lilly die Gleichung für die Gramm Teig (g) aus der Anzahl der Pizzas (n) und ihrem Durchmesser (d) berechnet:

`g = n * (((45 * pi * d) / 20) + 200)`

Lilly braucht eine Funktion, die:
* Die Anzahl der Pizzas (n) und ihren Durchmesser (d) entgegennimmt
* und den benötigten Teig auf das nächste Gramm gerundet (g) zurückgibt.

Zum Beispiel, um 4 Pizzas mit 30 cm Durchmesser zu backen:

```lisp
(dough-calculator 4 30) ; => 1648
```

## 2. Ein Schuss Soße

Lilly ist sehr genau, wenn sie ihre Soße aufträgt, aber die Größe ihrer Pizzas kann schwanken.

Um den Durchmesser (d) zu ermitteln, verwendet sie die folgende Gleichung mit der aufgetragenen Soße (s) als Variable:

`d = square-root of ((40 * s) / (3 * pi))`

Lilly braucht eine Funktion, die den Pizza-Durchmesser (d) aus jedem Milliliter aufgetragener Soße (s) berechnet.

Zum Beispiel, wenn Lilly 250 ml Soße verwendet hat:

```lisp
(size-from-sauce 250) ; => 32.57
```

## 3. Etwas Käse, bitte

Auf Lillys Planeten kommt jeder Käse in perfekten Würfeln und wird nach Größe verkauft.
(Was hast du erwartet? Das ist schließlich ein fremder Planet ...)

Wieder einmal hat Lilly eine Gleichung für die Anzahl der Pizzas (n) mit einem bestimmten Durchmesser (d) berechnet, die aus einem Käsewürfel mit der Seitenlänge (l) entstehen:

`n = (2 * (l^3)) / (3* pi * (d^2))`

Erstelle eine Funktion, die:
* die Seitenlänge eines Käsewürfels (l) und den Durchmesser der Pizzas (d) entgegennimmt,
* und die Anzahl der daraus entstehenden Pizzas (n) abgerundet zurückgibt.

Zum Beispiel bei einem 25x25x25 cm Käsewürfel und Pizzas mit 30 cm Durchmesser:

```lisp
(pizzas-per-cube 25 30) ; => 3
```

## 4. Eine faire Aufteilung

Zum Schluss möchte Lilly, dass ihre Pizzas jeweils in 8 Stücke geschnitten und gleichmäßig unter ihren Freunden verteilt werden.

Erstelle eine Funktion, die:
* die Anzahl der Pizzas und die Anzahl der Freunde entgegennimmt
* und `T` zurückgibt, wenn sich die Pizzas gleichmäßig unter den Freunden verteilen lassen, andernfalls `NIL`.

Zum Beispiel:

```lisp
;; For splitting 3 pizzas between 4 friends
(fair-share-p 3 4) ; => T
;; For splitting 2 pizzas between 3 friends
(fair-share-p 2 3) ; => NIL
```
