# Einführung

`Rational numbers` sind Brüche mit einer Ganzzahl als Zähler, geteilt durch eine Ganzzahl als Nenner.

Zum Beispiel können wir `2//3` als exakten Bruch speichern, anstatt als den ungefähren `Float64`-Wert `0.6666...`

Der Vorteil ist, dass (außer im Extremfall des *Ganzzahlüberlaufs*) eine rationale Zahl exakt bleibt. So vermeidest du die Rundungsfehler, die bei Gleitkommazahlen oft unvermeidlich sind.

Rationale Zahlen sind ein recht einfacher numerischer Typ und funktionieren weitgehend so, wie du es erwartest.
Da sie in Julia seit den frühen Versionen ein Standardtyp sind, akzeptieren die meisten Funktionen sie als Eingabewert, genauso wie Ganzzahlen und Gleitkommazahlen.

## Rationale Zahlen erstellen

Das Erstellen ist so einfach wie die Verwendung von `//` zwischen zwei Ganzzahlen.

```julia-repl
julia> 3//4
3//4

julia> a = 3; b = 4;

julia> a//b
3//4
```

Gemeinsame Faktoren werden automatisch entfernt, wodurch der Bruch auf seine „gekürzte Form" reduziert wird: die kleinsten Ganzzahlen, die den Bruch genau darstellen, und mit einem nicht-negativen Nenner.

```julia-repl
julia> 5//15
1//3

julia> 5//-15
-1//3
```

## Rechnen mit rationalen Zahlen

Die üblichen `arithmetic operators` `+ - * / ^ %` funktionieren mit rationalen Zahlen, im Wesentlichen genauso wie mit anderen numerischen Typen.

Ganzzahlen und andere `Rational`s kannst du einbeziehen, und du erhältst ein `Rational`-Ergebnis.
Beziehst du einen `float` in den Ausdruck ein, ist die Ausgabe ein `float`, was einen (möglichen) Verlust an Genauigkeit zur Folge hat.

Wenn du einen `float` möchtest, verwende einfach die Funktion `float()`, um eine rationale Zahl umzuwandeln.
Es ist ganz normal, rationale Zahlen zu verwenden, um die Genauigkeit über eine lange Berechnung hinweg zu bewahren, und am Ende in eine Gleitkommazahl umzuwandeln.

```julia-repl
julia> 3//4 + 1//3  # addition
13//12

julia> 3//4 * 1//3  # multiplication
1//4

julia> 3//4 / 1//3  # division
9//4

julia> 3//4 ^ 2  # exponentiation
3//16

julia> 3//4 + 5  # rational and int => rational
23//4

julia> 3//4 + 5.3  # rational and float => float
6.05

julia> float(3//4)  # casting
0.75
```

## Weitere Operationen

In Julia sind rationale Zahlen einfach Zahlen.
Der Compiler wandelt Typen in der Regel nach Bedarf um.

Sei jedoch vorsichtig: Vergleiche funktionieren für Brüche mit einer endlichen Dezimaldarstellung:

```julia-repl
julia> 3//4 == 0.75
true

julia> 3//4 < 0.74
false
```

Andernfalls sollte ein `Rational` für Vergleiche in einen `Float` umgewandelt werden:

```julia-repl
julia> 1//3 == 1/3
false

julia> float(1//3) == 1/3
true
```

Mathematische Funktionen nehmen rationale Zahlen als Eingabewert, liefern aber möglicherweise ein Gleitkommaergebnis:

```julia-repl
julia> sqrt(9//16)
0.75
```
