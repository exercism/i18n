# Einführung

## Boolesche Werte in R

Werte, die wahr oder falsch sind, werden in R durch den Typ `logical` dargestellt.
Er enthält nur zwei Werte: `TRUE` und `FALSE`.

```R
TRUE
#> [1] TRUE
FALSE
#> [1] FALSE
typeof(TRUE)
#> [1] "logical"
```

## Boolesche Operatoren

In R gibt es fünf boolesche Operatoren, aber in dieser Phase des Lehrplans sind nur drei relevant.
Die anderen beiden werden wichtig, wenn du mit Vektoren arbeitest, was in mehreren späteren Konzepten behandelt wird.

`&&` ist das boolesche „und“.
Er wird zu `TRUE` ausgewertet, wenn die Ausdrücke auf *beiden* Seiten von `&&` `TRUE` sind.

```R
TRUE && TRUE
#> [1] TRUE
TRUE && FALSE
#> [1] FALSE
```

`||` ist das boolesche „oder“.
Er wird zu `TRUE` ausgewertet, wenn ein Ausdruck auf *einer* der beiden Seiten von `||` `TRUE` ist.

```R
TRUE || TRUE
#> [1] TRUE
FALSE || TRUE
#> [1] TRUE
```

`!` ist das boolesche „nicht“.
Er vertauscht die Werte `TRUE` und `FALSE`.

```R
!TRUE
#> [1] FALSE
!FALSE
#> [1] TRUE
```

Bei längeren und komplizierteren Ausdrücken ist es am besten, Klammern zu verwenden, um deine Absicht deutlich zu machen.

```R
(TRUE || FALSE) && (FALSE && TRUE)
#> [1] FALSE
```
