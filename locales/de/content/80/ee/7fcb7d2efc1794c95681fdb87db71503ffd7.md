# Hinweise zur Bash-Übung Blumenfeld

Diese Übung scheint ein zweidimensionales Array zu erfordern.
Bash bietet nur eindimensionale indizierte oder assoziative [Arrays][array].

Mehrdimensionale Arrays lassen sich mit einem assoziativen Array simulieren: Kodiere die Indizes in einen durch Kommas getrennten String und verwende ihn als Schlüssel des Arrays.

```bash
# store this matrix:
#   a b
#   c d
declare -A array2d
array2d["0,0"]="a"
array2d["0,1"]="b"
array2d["1,0"]="c"
array2d["1,1"]="d"
```

[array]: https://www.gnu.org/software/bash/manual/bash.html#Arrays
