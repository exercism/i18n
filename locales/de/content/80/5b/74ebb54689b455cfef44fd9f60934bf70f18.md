# Zeichen

`CHAR` ist ein einzelnes Zeichen, das du zwischen einfache Anführungszeichen schreibst.

```sather
   c : CHAR := 'M';
```

## Sonderzeichen

Einige Zeichen lassen sich nicht direkt eingeben, sie werden mit einem Backslash geschrieben:

| Schreibweise | Bedeutung |
| --- | --- |
| `'\n'` | eine neue Zeile |
| `'\t'` | ein Tabulatorzeichen |
| `'\''` | ein einfaches Anführungszeichen |
| `'\\'` | ein Backslash |

## Fragen

```sather
'M'.is_alpha      -- true
'7'.is_digit      -- true
'M'.is_upper      -- true
' '.is_space      -- true
'M'.is_alphanum   -- true, a letter or a digit
```

## Groß- und Kleinschreibung

`.upper` und `.lower` ändern die Groß- und Kleinschreibung eines Buchstabens und lassen alles andere unangetastet. Du kannst sie also bedenkenlos auf ein Zeichen anwenden, das du nicht geprüft hast.

## Zahlen

```sather
'a'.int           -- 97
97.char           -- 'a'
```

`.int` und `.char` sind exakte Umkehrungen voneinander. Die nützlichen Tatsachen über die Nummerierung: `'a'` bis `'z'` folgen aufeinander, `'A'` bis `'Z'` folgen aufeinander und `'0'` bis `'9'` folgen aufeinander. Also:

```sather
   c.int - 'a'.int          -- how far c is along the alphabet
   ('a'.int + n).char       -- the letter n places along
   d.int - '0'.int          -- the value of a digit character
```

## Wieder von vorn

Ein Chiffrierrad dreht über `z` hinaus und wieder zurück zu `a`. `%` macht genau das:

```sather
   ('a'.int + (c.int - 'a'.int + places) % 26).char
```

Sathers `%` liefert nie ein negatives Ergebnis, wenn die rechte Seite positiv ist. Deshalb funktioniert das auch, wenn du das Rad rückwärts statt vorwärts drehst.

## Zeichen und Strings

Ein `STR` ist eine Folge von Bytes und ein `CHAR` ist ein Byte. In englischem Text entspricht ein Byte einem Buchstaben, also ist `"Marlowe".size` gleich 7 und `"Marlowe"[0]` gleich `'M'`. Bei Text mit Akzenten oder einem anderen Alphabet kann ein Buchstabe mehrere Bytes belegen, und beides gilt dann nicht.
