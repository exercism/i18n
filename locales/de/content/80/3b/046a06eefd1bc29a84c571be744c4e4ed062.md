# Ergänzung zu den Anweisungen

## Hinweise zur Implementierung

Die Definition des Cipher-Interface steht in `cipher.go`.

Deine Implementierungen sollten dem Cipher-Interface entsprechen.

```go
type Cipher interface {
    Encode(string) string
    Decode(string) string
}
```

`Encode` ignoriert alle Zeichen im String, die nicht A-Za-z sind; sie tauchen in der Ausgabe nicht auf.
Die Ausgabe wird außerdem auf Kleinbuchstaben normalisiert.

Die Funktionen zum Erzeugen der Chiffren sind:

```go
func NewCaesar() Cipher { }

func NewShift(distance int) Cipher { }

func NewVigenere(key string) Cipher { }
```

Das Argument für `NewShift` muss im Bereich 1 bis 25 oder -1 bis -25 liegen.
Null ist nicht erlaubt.
Bei ungültigen Argumenten gibt `NewShift` nil zurück.

Das Argument für `NewVigenere` darf nur aus Kleinbuchstaben a-z bestehen.
Werte, die nur aus dem Buchstaben 'a' bestehen, sind nicht erlaubt.
Bei ungültigen Argumenten gibt `NewVigenere` `nil` zurück.
