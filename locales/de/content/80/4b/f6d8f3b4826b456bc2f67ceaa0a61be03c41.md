# Hinweise

## 1. Ersetze alle vorkommenden Leerzeichen durch Unterstriche

- [Dieses Tutorial][chars-tutorial] ist hilfreich.
- Mit der Methode [charAt][char-at] kannst du `char`s aus einem String auslesen.
- Um den Ausgabe-String aufzubauen, solltest du einen [`StringBuilder`][string-builder] verwenden.
- In der Dokumentation zu [Character][chars-docs] findest du eine Methode, die Leerzeichen erkennt. Denk daran, dass es eine statische Methode ist.
- `char`-Literale werden in einfache Anführungszeichen gesetzt.

## 2. Wandle Kebab-Case in CamelCase um

- In der Dokumentation zu [Character][chars-docs] findest du eine Methode, die ein Zeichen in einen Großbuchstaben umwandelt. Denk daran, dass es eine statische Methode ist.

## 3. Wandle Leetspeak in normalen Text um

- In der Dokumentation zu [Character][chars-docs] findest du eine Methode, mit der du erkennst, ob ein Zeichen eine Ziffer ist. Denk daran, dass es eine statische Methode ist.

## 4. Lass Zeichen weg, die keine Buchstaben sind

- In der Dokumentation zu [Character][chars-docs] findest du eine Methode, mit der du erkennst, ob ein Zeichen ein Buchstabe ist. Denk daran, dass es eine statische Methode ist.
