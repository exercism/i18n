# Einführung

In Common Lisp kann eine Funktion nicht nur einen Wert zurückgeben, sondern mehrere Werte.
Zum Beispiel gibt `floor`, das zur Null hin abrundet, zwei Werte zurück: der erste ist der gerundete Wert und der zweite der Rest.

```lisp
(floor 3.5) ; => 3
            ;    0.5
```
(Mehrere zurückgegebene Werte zeigen wir auf getrennten Zeilen der Ausgabe.)

## Mehrere Werte zurückgeben

Wenn du möchtest, dass eine Funktion mehrere Werte zurückgibt, verwendest du den Accessor `values`:

```lisp
(defun three-numbers () (values 1 2 3))
(three-numbers) ; => 1
                ;    2
                ;    3
```

## Umgang mit mehreren Werten

Wenn dich nur der erste Wert interessiert, musst du nichts Besonderes tun: Die Sprache kümmert sich darum:

```lisp
(+ (values 1 2 3) (values 10 20 30)) ; => 11
```

Wenn du aber auf die anderen Werte zugreifen möchtest, gibt es mehrere Funktionen, die du verwenden musst.
Die zwei wichtigsten Makros sind `multiple-value-list` und `multiple-value-bind`.
Mit ihnen umschließt man etwas, das mehrere Werte zurückgibt, und fängt alle Werte ein.
Das erste erstellt eine Liste mit allen Werten.
Mit dem zweiten kannst du Variablen an die einzelnen Werte binden.

```lisp
(multiple-value-list (values 1 2 3))                   ; => (1 2 3)
(multiple-value-bind (a b c) (values 1 2 3) 
   (+ a b c)) ; => 6
```

Eine weitere nützliche Funktion ist `nth-value`.
