# Code schreiben

Schreibe deinen Code in `<exercise_name>.zig`.
Manche Übungen enthalten bereits vorgegebene Signaturen für bestimmte Zig-Konstrukte, wie zum Beispiel [Konstanten][constants], [Funktionen][functions], [Imports][imports], [Structs][structs] und [potenziell viele mehr][et-cetera]!

Diese vorgegebenen Signaturen sollen dir helfen, Übungen zu lösen, indem sie dir einen klaren Ausgangspunkt geben.
Es ist aber nicht nötig, von diesen Signaturen auszugehen.
Zumal jeder Code, der die Tests besteht, eine vollkommen akzeptable Lösung ist.

## Tests ausführen

Um die Tests auszuführen, musst du nur den folgenden Befehl ausführen:

```bash
zig test test_exercise_name.zig
```

Dabei ersetzt du `exercise_name` durch den Namen der Übung.
Der obige Befehl muss im Stammverzeichnis der Übung ausgeführt werden, da sich die Testdatei am selben Ort befinden sollte.
Außerdem sind alle Tests einer Übung standardmäßig aktiviert, und keiner der Tests lässt sich überspringen.

Da das für alle Tests gilt, musst du Tests, die nicht bestehen, [auskommentieren][comments], wenn du die Tests einzeln durchgehen möchtest.
Einen Test auszukommentieren ist so einfach, wie jede Zeile mit `//` zu beginnen.
Wenn du dir dagegen sicher bist, dass deine Lösung die Tests besteht, kannst du diese Tests wieder einkommentieren, um zu sehen, ob sie besteht.
