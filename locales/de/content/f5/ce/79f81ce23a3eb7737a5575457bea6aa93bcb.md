# Einführung

Der `char`-Typ in C# ist ein 16-Bit-Wert, der die kleinsten adressierbaren Bestandteile von Text darstellt.
Mehrere `char`s können einen String wie `"word"` bilden, oder `char`s können
unabhängig voneinander verarbeitet werden. Ihre Literale stehen in einfachen Anführungszeichen, z. B. `'A'`.

Die `char`s von C# unterstützen die Unicode-Kodierung UTF-16, sodass zusätzlich zum
lateinischen Zeichensatz so gut wie alle weltweit verwendeten Schriftsysteme
dargestellt werden können, z. B. der griechische Buchstabe `'β'`.

Es gibt viele eingebaute Bibliotheksmethoden, um `char`s zu untersuchen und zu
bearbeiten. Du findest sie als statische Methoden der Klasse `System.Char`.
