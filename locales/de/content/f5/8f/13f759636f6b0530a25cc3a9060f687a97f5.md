# Überblick

`for`-Schleifen sind die komplexeste Schleifenart in PHP. Sie verhalten sich wie `for`-Schleifen in `C`, `Java` und `JavaScript`. Die Grundform ist:

```php
for (expr1; expr2; expr3) {
  // statements
}
```

Der erste Ausdruck (_expr1_) wird ausgewertet, bevor die Schleife beginnt. Der zweite Ausdruck (_expr2_) wird vor jeder Iteration ausgewertet. Ergibt er einen _truthy_-Wert, werden die Anweisungen ausgeführt. Nach den ausgeführten Anweisungen wird der dritte Ausdruck (_expr3_) ausgewertet.
