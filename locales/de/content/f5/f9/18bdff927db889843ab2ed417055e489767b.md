# Anleitung

Trage die Minenanzahl in ein fertiges Minesweeper-Spielfeld ein.

Minesweeper ist ein beliebtes Spiel, bei dem du die Minen mithilfe von Zahlenhinweisen finden musst. Diese Hinweise geben an, wie viele Minen direkt an ein Feld angrenzen (horizontal, vertikal, diagonal).

In dieser Übung schreibst du Code, der die Anzahl der Minen zählt, die an ein bestimmtes leeres Feld angrenzen, und dieses Feld durch die Anzahl ersetzt.

Das Spielfeld ist ein Rechteck, das aus Leerzeichen (' ') besteht.
Eine Mine wird durch ein Sternchen (`*`) dargestellt.

Wenn an ein Feld überhaupt keine Mine angrenzt, lass dieses Feld leer.

## Beispiele

Zum Beispiel bekommst du vielleicht ein 5 x 4 großes Spielfeld wie dieses (leere Felder werden hier zur Anzeige auf dem Bildschirm mit dem Zeichen '·' dargestellt):

```text
·*·*·
··*··
··*··
·····
```

Und dein Code verwandelt es in Folgendes:

```text
1*3*1
13*31
·2*2·
·111·
```
