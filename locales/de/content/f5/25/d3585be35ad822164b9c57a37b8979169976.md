# Anleitung

In dieser Übung implementierst du ein Programm, das den Zustand eines [tic-tac-toe][]-Spiels bestimmt.
(Du kennst das Spiel vielleicht auch unter den Namen „noughts and crosses" oder „Xs and Os".)

Das Spiel wird auf einem 3×3-Raster gespielt.
Die Spieler setzen abwechselnd `X`s und `O`s in das Raster.
Das Spiel endet, wenn ein Spieler gewinnt, indem er drei Markierungen in einer Reihe, einer Spalte oder auf einer Diagonale des Rasters platziert, oder wenn das gesamte Raster gefüllt ist.

In dieser Übung gehen wir davon aus, dass `X` beginnt.

Deine Aufgabe ist es, zu bestimmen, in welchem Zustand sich ein gegebenes Spiel befindet.

Es gibt 3 mögliche Spielzustände:

- Das Spiel ist **ongoing**.
- Das Spiel endete mit einem **draw**.
- Das Spiel endete mit einem **win**.

Ist das gegebene Spielfeld ungültig, wirf einen passenden Fehler.

Ein Spielfeld ist ungültig, wenn es die folgenden Bedingungen erfüllt:

- Das gegebene Spielfeld kann nicht erreicht werden, wenn die Züge in der richtigen Reihenfolge gemacht werden (denk daran, dass `X` beginnt).
- Es wurde weitergespielt, nachdem das Spiel bereits beendet war.

## Beispiele

### Laufendes Spiel

```text
   |   |
 X |   |
___|___|___
   |   |
   | X | O
___|___|___
   |   |
 O | X |
   |   |
```

### Unentschieden

```text
   |   |
 X | O | X
___|___|___
   |   |
 X | X | O
___|___|___
   |   |
 O | X | O
   |   |
```

### Sieg

```text
   |   |
 X | X | X
___|___|___
   |   |
   | O | O
___|___|___
   |   |
   |   |
   |   |
```

### Ungültig

#### Falsche Zugreihenfolge

```text
   |   |
 O | O | X
___|___|___
   |   |
   |   |
___|___|___
   |   |
   |   |
   |   |
```

#### Weitergespielt nach dem Sieg

```text
   |   |
 X | X | X
___|___|___
   |   |
 O | O | O
___|___|___
   |   |
   |   |
   |   |
```

[tic-tac-toe]: https://en.wikipedia.org/wiki/Tic-tac-toe
