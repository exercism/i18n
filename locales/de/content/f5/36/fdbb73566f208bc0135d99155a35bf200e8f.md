# Anleitung

Simuliere ein Bankkonto, das das Eröffnen und Schließen, Abhebungen und Einzahlungen von Geld unterstützt.
Achte auf gleichzeitige Transaktionen!

Auf ein Bankkonto kann man auf verschiedene Weise zugreifen.
Kundinnen und Kunden können Einzahlungen und Abhebungen über das Internet, das Handy und so weiter vornehmen.
Geschäfte können das Konto belasten.

Erstelle ein Konto, auf das aus mehreren Threads/Prozessen zugegriffen werden kann (die genaue Bezeichnung hängt von deiner Programmiersprache ab).

Ein Konto muss sich schließen lassen; Operationen gegen ein geschlossenes Konto müssen fehlschlagen.
