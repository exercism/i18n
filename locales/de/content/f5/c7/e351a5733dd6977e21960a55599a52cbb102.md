# Empfohlene Lektüre

Smalltalk wird viel genutzt, deshalb gibt es eine reiche Auswahl an Lesestoff.

## Für den Einstieg

* [Pharo Main Site](https://pharo.org/documentation):
bietet eine Fülle von Artikeln und Hilfe
* [Pharo Syntax Cheatsheet](https://files.pharo.org/media/pharoCheatSheet.pdf):
es passt auf eine Postkarte
* [I Can Read C but not Smalltalk](https://www.eli.sdsu.edu/courses/spring01/cs635/readingSmalltalk.pdf): mehrere einfache Schritte zum Verständnis von Smalltalk
* [Pharo By Example (9.0)](https://books.pharo.org/pharo-by-example9/):
ein vollständiges PDF-Buch mit Schritt-für-Schritt-Beispielen
* [Learning OOP and TDD in Pharo](https://books.pharo.org/learning-oop/):
führt in weitere Programmiertechniken und Konzepte ein
* [Discord](https://discord.gg/QewZMZa) hat ein
aktives Online-Diskussionsforum zu Pharo (nutze den Einladungslink oben auf der [Community Page](https://pharo.org/community))
* [Pharo Mooc](https://mooc.pharo.org/):
bietet eine Reihe vollständiger Programmierkurse und Videos

## Für Fortgeschrittene

* [Deep Into Pharo](https://books.pharo.org/deep-into-pharo/):
führt dich durch fortgeschrittenere Themen wie Grafik und Parsing
* [Pharo with style](https://github.com/SquareBracketAssociates/Booklet-PharoWithStyle):
ist der Leitfaden für Formatierung und Design nach Pharo-Art
* [Smalltalk with style](http://sdmeta.gforge.inria.fr/FreeBooks/WithStyle/SmalltalkWithStyle.pdf):
ist ein breiterer Leitfaden für Formatierung und Design in Smalltalk
* [Enterprise Pharo - Web Perspective](http://books.pharo.org/enterprise-pharo/):
behandelt Webanwendungen, HTTP und Daten
