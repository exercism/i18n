# Über

Ein *Heap* ist eine Sammlung, die immer ihr kleinstes (oder größtes) Element kennt und die du schnell entfernen kannst. Er ist die natürliche Implementierung einer *Prioritätswarteschlange*. Heaps findest du im Vokabular [`heaps`][heaps].

`<min-heap>` erzeugt einen leeren Heap, bei dem der kleinste Schlüssel zuerst herauskommt; `<max-heap>` liefert den größten zuerst. Jedes Element ist ein *Wert*, der unter einem *Schlüssel* gespeichert ist, und der Schlüssel ist die Priorität, nach der Factor ordnet:

```
<min-heap> ( -- min-heap )
<max-heap> ( -- max-heap )
heap-push  ( value key heap -- )
heap-push-all ( assoc heap -- )
```

```factor
USING: heaps ;

<min-heap>
"alice" 5 pick heap-push
"bob"   2 pick heap-push
```

Ein Heap ist *veränderlich*: `heap-push` und `heap-pop` ändern ihn direkt.

```
heap-peek    ( heap -- value key )
heap-pop     ( heap -- value key )
heap-pop-all ( heap -- alist )
heap-empty?  ( heap -- ? )
heap-size    ( heap -- n )
```

`heap-peek` liest das vorderste Element, ohne es zu entfernen; `heap-pop` entfernt es und gibt es zurück; `heap-pop-all` leert den Heap in eine Assoziationsliste aus `{ key value }`-Paaren in der Reihenfolge ihrer Priorität.

```factor
USING: assocs heaps kernel prettyprint ;

<min-heap>
"alice" 5 pick heap-push
"bob"   2 pick heap-push
"carol" 9 pick heap-push
dup heap-pop .           ! => 2 "bob"   (removed; value then key)
heap-pop-all values .    ! => { "alice" "carol" }
```

Das Einfügen kostet `O(log n)` und das Lesen des vordersten Elements `O(1)`. Selbst wenn du wiederholt „das dringendste Element nehmen und dann weitere hinzufügen“ machst, bleibt das auch bei einer großen Warteschlange schnell. Die Implementierung ist ein Binärheap in einem erweiterbaren Array; der Schlüssel kann ein beliebiger sortierbarer Wert sein (Zahlen, Strings, …).
