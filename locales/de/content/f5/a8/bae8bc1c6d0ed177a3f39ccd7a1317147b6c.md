# Anleitung

In dieser Übung implementierst du eine Teilmenge von Hilfsfunktionen, mit denen ein Entwickler Bezeichnernamen bereinigen kann.

In den 5 Aufgaben baust du nach und nach die Funktion `clean` auf.
Ein gültiger Bezeichner besteht aus null oder mehr Buchstaben und Unterstrichen.

Wenn ein leerer String an die Funktion `clean` übergeben wird, sollte ein leerer String zurückgegeben werden.

## 1. Leerzeichen durch Unterstriche ersetzen

Implementiere eine Funktion `clean1`, die alle Leerzeichen durch Unterstriche ersetzt. Das gilt auch für führende und nachfolgende Leerzeichen.

```elm
clean1 "my   Id"
    --> "my___Id"
```

## 2. Steuerzeichen durch den großgeschriebenen String `"[CTRL]"` ersetzen

Implementiere `clean2` so, dass es alles tut, was die vorherige Funktion tut, und gängige Steuerzeichen (\n, \t und \r) durch den String `"[CTRL]"` ersetzt.

```elm
clean2 "my\nId"
    --> "my[CTRL]Id",
```

## 3. Kebab-Case in camelCase umwandeln

Implementiere `clean3` so, dass es alles tut, was die vorherige Funktion tut, und Kebab-Case in camelCase umwandelt.

```elm
clean3 "à-ḃç"
    --> "àḂç"
```

## 4. Ziffern weglassen

Implementiere `clean4` so, dass es alles tut, was die vorherige Funktion tut, und alle Ziffern weglässt.

```elm
clean4 "123"
    --> ""
```

## 5. Griechische Kleinbuchstaben weglassen

Implementiere schließlich `clean` so, dass es alles tut, was die vorherige Funktion tut, und alle griechischen Buchstaben im Bereich 'α' bis 'ω' weglässt.

```elm
clean "My Οβιεγτ Finder"
    --> "My_Ο_Finder"
```
