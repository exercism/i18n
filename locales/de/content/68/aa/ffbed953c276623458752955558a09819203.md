# Einleitung

Du wurdest gerade als Professor für Mathematik eingestellt.
Deine erste Woche lief gut, aber in deiner zweiten Woche stimmt etwas nicht.
Das Problem ist, dass jede Antwort deiner Studierenden falsch ist!
Zum Glück hast du mit deinen Mathekenntnissen das Problem schnell gefunden: Die Antworten der Studierenden _sind_ richtig, aber sie stehen alle im Zweiersystem (Binärsystem)!
Erstaunlicherweise verwendet jede Woche eine andere Basis.
Damit du die Antworten deiner Studierenden schnell überprüfen kannst, baust du ein Tool, das Zahlen zwischen verschiedenen Basen umrechnet.
