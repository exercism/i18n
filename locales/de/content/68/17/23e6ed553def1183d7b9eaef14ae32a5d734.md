# Hilfe

Prüfe deinen Code auf Syntaxfehler: Füge deinen Code in
[https://shellcheck.net](https://shellcheck.net) ein (oder [installiere es](https://github.com/koalaman/shellcheck#user-content-installing) auf deinem Rechner).

Bei Fragen zu bash ist Stack Overflow deine erste Anlaufstelle.

* beginne mit dem [`bash`-Tag](https://stackoverflow.com/questions/tagged/bash), um nach deiner konkreten Frage zu suchen: Wahrscheinlich wurde sie schon einmal gestellt.
* unter dem bash-Tag auf Stack Overflow findest du über den Link [Mehr erfahren...](https://stackoverflow.com/tags/bash/info) _jede Menge_ gute Informationen.
    * der Abschnitt „Books and Resources“ ist besonders nützlich.
* auch der [`bash`-Tag](https://unix.stackexchange.com/questions/tagged/bash) auf Unix & Linux ist aktiv.

## Externe Tools

`bash` ist eine Sprache, um „Skripte“ zu schreiben, also Programme, die
externe Tools aufrufen können, zum Beispiel
[`sed`](https://www.gnu.org/software/sed/),
[`awk`](https://www.gnu.org/software/gawk/),
[`date`](https://www.gnu.org/software/coreutils/manual/html_node/date-invocation.html)
und sogar Programme, die in anderen Programmiersprachen geschrieben sind,
wie [`Python`](https://www.python.org/).
Dieser Track schränkt die Verwendung dieser Tools nicht ein, und solange
deine Lösung auf verschiedenen Systemen läuft und keine Installation von
Anwendungen Dritter erfordert, kannst du sie gern verwenden, um die Übung zu lösen.

Wenn du die Sprache besser verstehen möchtest, versuche als zusätzliche
Herausforderung, die Lösung in reinem bash neu zu implementieren, ohne
externe Tools zu verwenden. Es gibt einige Arten von Problemen, die bash nicht
lösen kann, zum Beispiel Arithmetik mit Gleitkommazahlen und das Bearbeiten
von Datumsangaben: Für diese musst du ein externes Tool aufrufen.
