# Anweisungen

Deine Designfirma hat bisher vor allem mit CSS-Transformationen gearbeitet, um Webseiten zu bauen. Nach einiger Diskussion habt ihr beschlossen, Clojure zu verwenden, um einige Berechnungen dynamisch durchzuführen. Einige deiner Teamkollegen haben weniger Erfahrung mit Clojure, deshalb entscheidest du dich, eine Closure zu verwenden, um wiederverwendbare Transformationen für `{x, y}` Koordinatenpaare zu erstellen.

## 1. Die Koordinaten verschieben

Implementiere die Funktion `translate2d`, die eine Funktion zurückgibt, die mithilfe einer Closure eine wiederholbare 2D-Verschiebung eines Koordinatenpaares durchführt.

```clojure
(def move-coordinates-right-2px (translate2d 2 0))
(def result (move-coordinates-right-2px 4 8))
;; result => [6 8]
```

## 2. Die Koordinaten skalieren

Implementiere die Funktion `scale2d`, die eine Funktion zurückgibt, die mithilfe einer Closure eine wiederholbare 2D-Skalierung eines Koordinatenpaares durchführt.

> Gehe bei dieser Übung davon aus, dass Skalierungswerte nur positiv sind.

```clojure
(def double-scale (scale2d 2 2))
(def result (double-scale 6 -3))
;; result => [12 -6]
```

## 3. Transformationsfunktionen kombinieren

Kombiniere zwei Transformationsfunktionen zu einer wiederholbaren Transformation. Das nennt man oft _Funktionskomposition_: Das Ergebnis der ersten Funktion _'f(x)'_ wird als Eingabewert für die zweite Funktion _'g(x)'_ verwendet.

```clojure
(def move-coordinates-right-2px (translate2d 2 0))
(def double-coordinates (scale2d 2 2))
(def composed-transformations 
  (compose-transform move-coordinates-right-2px 
                     double-coordinates))
(def result (composed-transformations 0 1))
;; result => [4 2]
```

## 4. Die Ergebnisse von Funktionen speichern

Implementiere die Funktion `memoize-transform`. Sie nimmt eine Funktion entgegen, die _memoisiert_ werden soll, und gibt eine neue Funktion zurück, die sich die Eingabewerte der übergebenen Funktion merkt, sodass der letzte Rückgabewert „erinnert“ werden kann und nur einmal berechnet wird, wenn sie erneut mit denselben Argumenten aufgerufen wird.

> Memoisierung wird manchmal auch _dynamische Programmierung_ genannt: Sie erlaubt es, aufwendige Operationen nur einmal auszuführen, da ihr Ergebnis gespeichert wird.

```clojure
(def triple-scale (scale2d 3 3))
(def memoized-scale (memoize-transform triple-scale))

(memoized-scale 4 3)
;; => [12, 9], this is computed since it hasn't been computed before for the arguments

(memoized-scale 4 3)
;; => [12, 9], this is remembered, since it was computed already
```
