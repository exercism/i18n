# Tests

Führe unter MacOS/Linux bitte Folgendes aus:

```sh
$ chmod +x gradlew
```

Führe die Tests mit folgendem Befehl aus:

```sh
$ ./gradlew test
```

> Verwende `gradlew.bat`, wenn du Windows benutzt

## Übersprungene Tests

Nachdem die ersten Tests bestanden sind, fahre fort, indem du die `@Ignore`-Annotationen, die den anderen Tests vorangestellt sind, auskommentierst oder entfernst.
