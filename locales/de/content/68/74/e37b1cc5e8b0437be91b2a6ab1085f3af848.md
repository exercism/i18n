# Über

[concept:csharp/resource-cleanup]() verwendet das Interface `IDispose`, um den Aufrufern einer Klasse zu signalisieren, dass es Ressourcen oder Programmzustand gibt, die rechtzeitig freigegeben oder zurückgesetzt werden müssen, wenn das betreffende Objekt nicht mehr benötigt wird. In dieser Übung haben wir mit dem Schlüsselwort `using` etwas syntaktischen Zucker eingeführt, der den Code weniger ausführlich macht und dafür sorgt, dass wichtige Aufrufe seltener ausgelassen werden.

`using` kann in manchen Fällen als Ersatz für [`try/finally`][try-finally] gesehen werden.

```csharp
File file = null;
try
{
    file = new File("myStuff.txt");
    file.Write("more stuff");
}
finally
{
    file.Dispose();
}
```

Diese Syntax wird durch die kompaktere und idiotensichere Variante ersetzt:

```csharp
using (var file = new File("myStuff.txt")
{
    file.Write("more stuff");
}
```

Beachte, dass mehrere Ressourcen ganz einfach kombiniert werden können, wenn du die üblichen Regeln für einzeilige Blöcke befolgst:

```csharp
using (var file = new File("mystuff.txt")
using (var fileWriter = new StreamWriter(file)
{
     ...
}
```

In C# 8 wurde die folgende Variante eingeführt, bei der die `using`-Anweisung am Anfang eines Blocks steht:

```csharp
using var file = new File("myStuff.txt");
file.Write("more stuff");
```

So kannst du mehrere Objekte, die freigegeben werden müssen, im selben Block haben und [`try/catch`][try-catch] natürlicher behandeln:

```csharp
using var fileIn = new File("myStuff.txt");
using var fileOut = new File("yourStuff.txt");
try
{
    var stuff = fileIn.Read();
    fileOut.Write(stuff);
}
catch (Exception)
{
    LogStuff();
}
```

Wie das Schlüsselwort `using` verwendet werden kann und auf Instanzen welcher Typen es angewendet werden darf, ist [hier][using-statement] im Detail beschrieben.

## Hinweis für Java-Entwickler

Java-Entwickler erkennen das vielleicht als Analogie zum Mechanismus der [_automatischen Ressourcenverwaltung_][automatic-resource-management] wieder, der in Java 7 eingeführt wurde. Beide sind sich sehr ähnlich. Javas Syntax, die `try` für einen anderen Zweck nutzt, hat den Vorteil, dass sie `catch`-Blöcke natürlicher einbindet als das `using` von C#.

## Versionen

Beachte, dass die flexiblere Variante von `using`, bei der es keinen eigenen syntaktischen Block hat, in C# 8 eingeführt wurde. Du musst also eventuell prüfen, ob die Codebasis, an der du arbeitest, C# 8 oder neuer verwendet.
