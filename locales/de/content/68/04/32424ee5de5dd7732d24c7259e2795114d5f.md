# Ergänzung zu den Anweisungen

## Spezielle Hinweise zu x86-64 Assembly

Die Funktionen in dieser Übung erhalten ein Array mit einer oder mehreren Zahlen, die jeweils für einen „Spielstand“ stehen.

In x86-64 Assembly sprichst du Elemente eines Arrays über einen Versatz in Bytes von einem Basiszeiger aus an.

Dieser Basiszeiger wird in einem Register übergeben, gemäß der [System V AMD64 ABI Calling Convention](https://www.uclibc.org/docs/psABI-x86_64.pdf).

Die ersten 3 Argumente werden in dieser Reihenfolge in rdi, rsi, rdx übergeben.

Da die Spielstände des Spielers als 32-Bit-Ganzzahlen dargestellt werden, die 4 Bytes belegen, kannst du sie so auslesen:

| `rsi`   |
|---|
| `dword [rsi]` |
| `dword [rsi + 4]` |
| ... |
| `dword [rsi + 4*scores_count - 4]` |

`personal_top_three()` sollte die besten Spielstände des Spielers in einen Puffer schreiben, der ebenfalls in einem Register übergeben und auf dieselbe Weise angesprochen wird.

| `rdi`   |
|---|
| `dword [rdi]` |
| `dword [rdi + 4]` |
| ... |

Ganzzahlige Werte werden per Konvention im Register rax zurückgegeben.
