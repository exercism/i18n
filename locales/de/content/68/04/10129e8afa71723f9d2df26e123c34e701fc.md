# Einführung

Mit Enums kannst du in Cairo einen Typ definieren, der einen von mehreren benannten Varianten annehmen kann.

## Grundlagen

Enums, kurz für Enumerationen, beschränken alle möglichen Werte von Daten auf eine vordefinierte Menge. Die möglichen Werte eines `enum` heißen Varianten:

```rust
#[derive(Drop)]
enum Direction {
    North,
    South,
    East,
    West,
}
```

Du erstellst Enum-Werte, indem du die Variante angibst:

```rust
let my_direction = Direction::North;
let another_direction = Direction::West;
```

## Pattern Matching

Verwende match, um verschiedene Enum-Varianten zu behandeln:

```rust
match my_direction {
    Direction::North => println!("Going north!"),
    Direction::South => println!("Going south!"),
    Direction::East => println!("Going east!"),
    Direction::West => println!("Going west!"),
}
```

Jeder Zweig des match behandelt eine Variante des Enums.

## Enums mit Daten

Enum-Varianten können zusätzliche Daten enthalten:

```rust
struct Location {
    x: u32,
    y: u32,
}

enum Message {
    Text: ByteArray,
    Number: u32,
    Location: Location,
}
```

Mit Pattern Matching extrahierst du die Daten:

```rust
match msg {
    Message::Text(content) => println!("Text: {}", content),
    Message::Number(val) => println!("Number: {}", val),
    Message::Location(Location { x, y }) => println!("Position: ({}, {})", x, y),
}
```
