# Über

`call` ist das universelle Primitiv für „führe diese Quotation jetzt aus“.
Wenn der Compiler die Quotation wörtlich vor sich hat, kann er den Effekt
ableiten; kommt die Quotation aus einer Variable, einem Array oder einem
Parameter, musst du den Effekt angeben:

```factor
: apply-binary ( a b op -- c )
    call( a b -- c ) ;

5 3 [ - ] apply-binary .   ! => 2
5 3 [ + ] apply-binary .   ! => 8
```

Die Deklaration `call( a b -- c )` wird zu einer Laufzeitprüfung kompiliert,
die sicherstellt, dass die Quotation tatsächlich den angegebenen Effekt hat.
Eine Abweichung führt dann zu einem klaren Fehler statt zu einem beschädigten
Stack-Zustand.

Eine Quotation als Daten zu behandeln – sie auf den Stack zu legen, sie in
einem Array abzulegen, sie aus einem Wort zurückzugeben – macht concatenative
Code besonders kompakt. Ein „Programm“ kann eine einfache Sequenz sein, und
`each` zusammen mit `call` reicht aus, um sie zu interpretieren.
