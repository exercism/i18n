# Über

Die Entwickler von Julia wollen den Kuchen haben und ihn gleichzeitig essen. Wie sie in ihrem Blogbeitrag [„Why We Created Julia“](http://julialang.org/blog/2012/02/why-we-created-julia) beschreiben, wollen sie die Geschwindigkeit von C, die Dynamik von Ruby und die vertraute mathematische Notation von Matlab. Sie wollen, dass Julia ihre liebsten Dinge aus ihren Lieblingssprachen vereint. Stringverarbeitung wie in Perl. Klebstoff wie in der Shell. Mächtig, aber nicht undurchdringlich komplex.

Julia hat ein mächtiges, zugleich klares und intuitives dynamisches [Typsystem](http://docs.julialang.org/en/v1/manual/types/). Damit kannst du dynamischen Code schreiben und trotzdem Typen angeben, wenn du mehr Ausdrucksstärke brauchst, um etwas zu vereinfachen oder die Performance zu erhöhen. Die Sprache unterstützt [Multiple Dispatch](https://youtu.be/kc9HwsxE1OY?t=66), das heißt, sie entscheidet anhand der Typen der einzelnen Argumente, welche Methode aufgerufen wird. So kannst du spezifische Methoden für bestimmte Typen schreiben und trotzdem generische Fallbacks anbieten. Das ist besonders nützlich für mathematischen Code, bei dem nicht klar ist, warum eine Operation zu einem bestimmten Argument gehören sollte.

[Metaprogrammierung](http://docs.julialang.org/en/v1/manual/metaprogramming/) ist in Julia einfach. Code lässt sich in Julia selbst als Datenstruktur darstellen, sodass ein Programm seinen eigenen Code umwandeln und erzeugen kann, ähnlich wie in Lisp. Große Teile von [Julias Basis- und Standardbibliothek](https://github.com/julialang/julia) sind ebenfalls in Julia geschrieben. Um sie zu verstehen und zu ändern, brauchst du keine Kenntnisse in einer anderen Sprache. Wenn eine Bibliothek, die du nutzen möchtest, in einer anderen Sprache geschrieben ist, etwa [C, Fortran](http://docs.julialang.org/en/v1/manual/calling-c-and-fortran-code/) oder [Python](https://github.com/JuliaPy/PyCall.jl), kannst du sie über einfache Schnittstellen direkt aus deinem Code aufrufen.

Obwohl Julia noch jung ist, wird sie in der Praxis bereits in den verschiedensten Bereichen eingesetzt, zum Beispiel im Finanzwesen, in der Datenwissenschaft und im wissenschaftlichen Rechnen, aber nicht nur dort. Viele Beispielanwendungen findest du im [Julia Blog Aggregator](https://www.juliabloggers.com/), Fallstudien aus der kommerziellen Nutzung auf [juliacomputing.com](https://juliacomputing.com/case-studies/) und eine Liste von Veröffentlichungen über die Sprache und ihre Anwendungen in der Forschung [hier](https://julialang.org/research/).
