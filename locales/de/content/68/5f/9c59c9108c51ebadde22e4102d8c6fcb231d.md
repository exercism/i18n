# Anleitung

Dein Freund Linus ist Lokführer und fährt Güterzüge zwischen Städten.
Er ist zwar großartig im Umgang mit Zügen, aber alles andere als großartig in Sachen Logistik oder Computer.
Er würde gerne deine Programmierhilfe in Anspruch nehmen, um Zugdaten zu organisieren und Fehler in den Routendaten zu korrigieren.

~~~~exercism/note
Diese Übung ließe sich leicht mit Slicing, Indexing und verschiedenen `hash`-Methoden lösen.
Wir möchten aber, dass du beim Lösen der folgenden Aufgaben das Packen, das Entpacken und die Mehrfachzuweisung übst.
~~~~

## 1. Eine Liste aller Waggons erstellen

Dein Freund hat bisher jede Waggon-Kennung (ID) mitgeschrieben, aber er weiß nie genau, wie viele Waggons das System jeweils verarbeiten muss.
Für den Rest des Logistikprogramms wäre es viel einfacher, diese Daten in einem einheitlichen **Array** zusammengefasst zu haben.

Implementiere eine Methode `generate_list_of_wagons()`, die eine beliebige Anzahl von Waggon-IDs entgegennimmt.
Jede ID ist eine positive Ganzzahl.
Die Methode soll die übergebenen IDs dann per `return` als einzelnes **Array** zurückgeben.

```ruby
LocomotiveEngineer.generate_list_of_wagons(1, 7, 12, 3, 14, 8, 5)
# => [1, 7, 12, 3, 14, 8, 5]
```

## 2. Die Waggonliste korrigieren

So langsam bekommst du ein Gefühl für die Daten und dafür, wie sie im Logistikprogramm verwendet werden.
Das ID-System weist der Lokomotive immer die ID **1** zu, während die übrigen Waggons des Zugs eine zufällig gewählte ID größer als **1** erhalten.

Dein Freund musste zwei neue Waggons an den Zug anhängen und hat vergessen, das System zu aktualisieren!
Jetzt müssen die ersten beiden Waggons im **Array** des Zugs ans Ende verschoben werden, sonst gerät alles durcheinander.

Um die Sache noch komplizierter zu machen, hat dein Freund gerade ein zweites **Array** entdeckt, das offenbar fehlende Waggon-IDs enthält.
Er erinnert sich nur noch daran, dass die IDs aus diesem zweiten **Array** direkt hinter der dafür vorgesehenen Lokomotive eingefügt werden sollen, sobald die neuen Waggons verschoben sind.

Linus wäre dir sehr dankbar, wenn du seine Fehler korrigierst und die Daten zusammenführst.

Implementiere eine Methode `fix_list_of_wagons()`, die zwei **Arrays** mit Waggon-IDs entgegennimmt.
Sie soll die ersten beiden Elemente des ersten **Arrays** ans Ende verschieben und die Werte aus dem zweiten **Array** hinter (_rechts von_) der Lokomotiv-ID (**1**) einfügen.
Die Methode soll dann per `return` ein **Array** mit den Änderungen zurückgeben.

```ruby
LocomotiveEngineer.fix_list_of_wagons([2, 5, 1, 7, 4, 12, 6, 3, 13], [3, 17, 6, 15])
# => [1, 3, 17, 6, 15, 7, 4, 12, 6, 3, 13, 2, 5]
```

## 3. Fehlende Zwischenstopps hinzufügen

Jetzt, wo alle Waggondaten korrekt sind, möchte Linus, dass du die Routing-Informationen des Systems aktualisierst.
Auf einer Transportstrecke hält ein Zug vielleicht an ein paar verschiedenen Bahnhöfen, um Fracht aufzunehmen und/oder abzugeben.
Jede Fahrt kann eine unterschiedliche Anzahl dieser Zwischenstopps haben.
Dein Freund möchte, dass du den Routing-**Hash** des Systems um alle fehlenden/zusätzlichen Lieferinformationen ergänzt.

Implementiere eine Methode `add_missing_stops()`, die einen Routing-**Hash** gefolgt von einer variablen Anzahl von Schlüsselwortargumenten entgegennimmt.
Diese Argumente können entweder in Form eines **Hashs** vorliegen, der einen oder mehrere Zwischenstopps enthält, oder als beliebig viele `stop_<number>: "city"`-Schlüsselwortpaare.
Deine Methode soll dann den Routing-**Hash** zurückgeben, erweitert um einen zusätzlichen **Schlüssel**, der ein **Array** mit allen hinzugefügten Zwischenstopps in der richtigen Reihenfolge enthält.

```ruby
LocomotiveEngineer.add_missing_stops({from: "New York", to: "Miami"},
                    stop_1: "Washington, DC", stop_2: "Charlotte", stop_3: "Atlanta",
                    stop_4: "Jacksonville", stop_5: "Orlando")
# => {from: "New York", to: "Miami", stops: ["Washington, DC", "Charlotte", "Atlanta", "Jacksonville", "Orlando"]}
```

~~~~exercism/note
Die Zwischenstopps werden immer in der richtigen Reihenfolge übergeben, du musst dir also keine Gedanken übers Sortieren machen.
~~~~

## 4. Routing-Informationen erweitern

Linus hat am Routing-Programm gearbeitet und bemerkt, dass bei bestimmten Routen einige wichtige Details fehlen.
Die anfänglichen Routeninformationen wurden als **Hash** aufgebaut, und dein Freund möchte, dass du diesen **Hash** um alles ergänzt, was noch fehlen könnte.
Jede Route im System braucht etwas andere Details, deshalb wäre Linus eine allgemeine Lösung wirklich lieber.

Implementiere eine Methode namens `extend_route_information()`, die zwei **Hashes** entgegennimmt.
Der erste **Hash** enthält die Start- und Zielstädte, zwischen denen die Zugroute verläuft.

Der zweite **Hash** enthält weitere Routing-Details wie Geschwindigkeit, Länge oder Temperatur des Zugs.
Die Methode soll einen zusammengeführten **Hash** mit allen Routing-Informationen zurückgeben.

~~~~exercism/note
Der zweite **Hash** kann andere/weitere Eigenschaften enthalten als die im Beispiel gezeigten.
~~~~

```ruby
LocomotiveEngineer.extend_route_information({"from": "Berlin", "to": "Hamburg"}, {"length": "100", "speed": "50"})
# => {"from": "Berlin", "to": "Hamburg", "length": "100", "speed": "50"}
```
