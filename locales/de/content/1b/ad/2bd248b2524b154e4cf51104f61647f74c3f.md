# Platzhalter

## Zeitfunktionen

Für diese Übung musst du die [Zeitfunktionen][time-func] von GNU awk verwenden.

Bei den Funktionen zum Parsen und Formatieren von Datum und Uhrzeit solltest du unbedingt **das UTC-Flag setzen**.
Ein Beispiel:

```sh
export TZ=Asia/Kolkata
gawk 'BEGIN {
    time = 1234567890
    print strftime("%Y-%m-%d %T", time)     # format for local timezone
    print strftime("%Y-%m-%d %T", time, 1)  # format for UTC
}'
```

gibt Folgendes aus:

```none
2009-02-14 05:01:30
2009-02-13 23:31:30
```

[time-func]: https://www.gnu.org/software/gawk/manual/html_node/Time-Functions.html
