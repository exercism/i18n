# Anleitung

Implementiere ein einfaches reaktives System.

Reaktive Programmierung ist ein Programmierparadigma, bei dem der Schwerpunkt darauf liegt, wie Werte auf Basis anderer Werte berechnet werden. So kann sich eine Änderung an einem Wert automatisch auf andere Werte ausbreiten, ähnlich wie in einer Tabellenkalkulation.

Implementiere ein einfaches reaktives System mit Zellen, deren Werte sich setzen lassen („Eingabezellen“), und Zellen, deren Werte aus anderen Zellen berechnet werden („Berechnungszellen“).
Implementiere die Aktualisierungen so, dass sich bei einer Änderung eines Eingabewerts die Werte ausbreiten, bis das System einen neuen stabilen Zustand erreicht.

Außerdem sollen Berechnungszellen das Registrieren von Callbacks zur Benachrichtigung über Änderungen ermöglichen.
Rufe die Callbacks einer Zelle auf, wenn sich der Wert der Zelle im neuen stabilen Zustand vom vorherigen stabilen Zustand unterscheidet.
