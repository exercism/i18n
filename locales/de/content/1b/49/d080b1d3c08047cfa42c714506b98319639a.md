# Tests

Wähle dein aktuelles Betriebssystem:

* [Windows](##windows)
* [macOS](##macos)
* [Linux](##linux)

# Tests ausführen

## Windows

1. Öffne ein Command Prompt.

2. Hol dir die erste Übung:

    ```batchfile
     C:\Users\USERNAME> exercism download --exercise hello-world --track cobol
    ```

3. Wechsle in den Übungsordner:

    ```batchfile
     C:\Users\USERNAME> cd C:\Users\USERNAME\exercism\cobol\hello-world
    ```
   
4. Führe die Tests aus:

    ```batchfile
     C:\Users\USERNAME\exercism\cobol\hello-world> test.ps1
    ```
    *(Mach dir keine Sorgen, wenn die Tests beim ersten Ausführen fehlschlagen, so beginnt jede Übung.)*

5. Löse die Übung. 
    Lies die `instructions.md` durch und schau, wie du die Übung löst ([auf GitHub ansehen](https://github.com/exercism/cobol/blob/main/exercises/practice/hello-world/.docs/instructions.md)).


Viel Glück, viel Spaß und willkommen im COBOL-Track!

## macOS

1. Öffne ein Terminalfenster.

2. Hol dir die erste Übung:

    ```
     $ exercism download --exercise hello-world --track cobol
    ```

3. Wechsle in den Übungsordner:

    ```
     $ cd /Users/USERNAME/exercism/cobol/hello-world
    ```

4. Führe die Tests aus:

    ```
     $ bash test.sh
    ```
    *(Mach dir keine Sorgen, wenn die Tests beim ersten Ausführen fehlschlagen, so beginnt jede Übung.)*

    Hinweis: Wenn du eine Meldung bekommst, dass `basename` fehlt, kannst du [brew](https://brew.sh/) verwenden, um coreutils zu installieren. (`brew install coreutils`)

5. Löse die Übung. 

    Lies die `instructions.md` durch und schau, wie du die Übung löst ([auf GitHub ansehen](https://github.com/exercism/cobol/blob/main/exercises/practice/hello-world/.docs/instructions.md)).


Viel Glück, viel Spaß und willkommen im COBOL-Track!
