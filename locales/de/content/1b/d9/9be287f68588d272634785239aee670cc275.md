# Hinweise

## 1. Erstelle eine neue Liste

- Eine leere Liste kannst du mit der Syntax `[]` erstellen.

## 2. Definiere eine bestehende Liste

- Listen mit mehreren Elementen kannst du mit der Syntax `["a", "b", "c"]` erstellen.

## 3. Füge eine neue Sprache zu einer Liste hinzu

- Mit der Spread-Syntax (`[x, ..list]`) kannst du ein Element am Anfang einer Liste hinzufügen.

## 4. Zähle die Sprachen in der Liste

- Im Modul `gleam/list` gibt es eine Funktion, um [die Elemente einer Liste zu zählen][length].

## 5. Kehre die Liste um

- Im Modul `gleam/list` gibt es eine Funktion, um [eine Liste umzukehren][reverse].

## 6. Prüfe, ob die Liste spannend ist

- Du kannst Pattern Matching mit dem Listenmuster und dem Spread-Muster verwenden, um bestimmte Listenstrukturen abzugleichen.

[reverse]: https://hexdocs.pm/gleam_stdlib/gleam/list.html#reverse
[length]: https://hexdocs.pm/gleam_stdlib/gleam/list.html#length
