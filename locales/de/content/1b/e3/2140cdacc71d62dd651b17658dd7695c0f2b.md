# Bedingungen

Crystal kennt sogenannte Kontrollausdrücke. Mit ihnen steuerst du den Ablauf des Programms, und sie haben einen truthy- oder falsey-Wert.
Es gibt Operatoren, mit denen du truthy- oder falsey-Werte erzeugen kannst. Man nennt sie [Gleichheits- und Vergleichsoperatoren][equality-and-comparison].

Es gibt zwei wichtige Kontrollausdrücke, mit denen du steuerst, welcher Code ausgeführt wird und welcher nicht.
Sie bestimmen also, welcher Zweig ausgeführt wird.

Diese beiden sind: `if` und der `unless`-Ausdruck.

## Vergleichsoperatoren

Mit Vergleichsoperatoren vergleichst du Werte und bekommst einen `true`- oder `false`-Wert zurück.
Diese Operatoren erwarten zwei Werte des gleichen Typs, die sie vergleichen.
Wenn die Werte nicht vom gleichen Typ sind, gibt der Compiler einen Fehler aus.
Hier ist eine Liste der Vergleichsoperatoren mit einem Beispiel, bei dem sie einen `true`-Wert liefern:

| Methode | Beschreibung          | Beispiel |
| ------ | --------------------- | ------- |
| <      | kleiner als           | 4 < 5   |
| <=     | kleiner als oder gleich | 4 <= 4  |
| >      | größer als            | 3 > 1   |
| >=     | größer als oder gleich | 2 >= 2  |

## Gleichheitsoperatoren

Gleichheitsoperatoren ähneln den Vergleichsoperatoren, aber mit ihnen prüfst du, ob zwei Werte gleich sind oder nicht.

Der Operator `==` prüft, ob zwei Werte gleich sind, und bezieht dabei den Typ des Werts mit ein.
Sind die Werte gleich, liefert er `true` zurück, andernfalls `false`.
Der Operator `==` kann jeden Typ von Wert mit jedem anderen Typ von Wert vergleichen.
Der Operator `!=` funktioniert genauso, liefert aber `true`, wenn die Werte nicht gleich sind, und `false`, wenn sie gleich sind.

## Der Spaceship-Operator

Der Spaceship-Operator ist ein besonderer Vergleichsoperator, und sein Name leitet sich von seinem Aussehen ab.
Er ist insofern besonders, als er keinen truthy- oder falsey-Wert zurückgibt, sondern eine Zahl.
Er wird als `<=>` geschrieben und vergleicht zwei Werte.
Er liefert `1`, wenn der linke Wert größer als der rechte ist, `-1`, wenn der linke Wert kleiner als der rechte ist, und `0`, wenn die Werte gleich sind.

```crystal
1 <=> 2 # => -1
2 <=> 2 # => 0
3 <=> 2 # => 1
```

## if-Anweisung

Mit der [`if`][if]-Anweisung prüfst du, ob eine Bedingung truthy oder falsey ist.
Ist die Bedingung truthy, wird der Code innerhalb der if-Anweisung ausgeführt.
Eine `if`-Anweisung endet mit dem Schlüsselwort `end`.

```crystal
if 1 == 1
  puts "1 is equal to 1"
end
# => 1 is equal to 1

if 1 > 2
  puts "1 is greater than 2"
end
# => no output
```

## unless-Anweisung

Die [`unless`][unless]-Anweisung funktioniert sehr ähnlich wie die `if`-Anweisung, führt den Code innerhalb der `unless`-Anweisung aber aus, wenn die Bedingung falsey ist.

```crystal
unless 1 == 1
  puts "1 is not equal to 1"
end
# => no output

unless 1 > 2
  puts "1 is not greater than 2"
end
# => 1 is not greater than 2
```

## else-Anweisung

Die `else`-Anweisung kannst du zusammen mit der `if`- und der `unless`-Anweisung verwenden.
Die `else`-Anweisung wird ausgeführt, wenn der `if`-Zweig oder der `unless`-Zweig nicht ausgeführt wird.

~~~~exercism/warning
Auch wenn du einen `else`-Zweig zusammen mit `unless,` verwenden kannst, wird davon abgeraten, weil es die Lesbarkeit beeinträchtigt.
Stattdessen empfiehlt es sich, `if !condition` mit einem else-Zweig zu verwenden.
~~~~

```crystal
if 1 == 1
  puts "1 is equal to 1"
else
  puts "1 is not equal to 1"
end
# => 1 is equal to 1

unless 1 < 2
  puts "1 is not greater than 2"
else
  puts "1 is greater than 2"
end
# => 1 is greater than 2
```

## Kaskadierende if-Anweisungen

Die `elsif`-Anweisung kannst du zusammen mit der `if`-Anweisung verwenden.
Die `elsif`-Anweisung wird ausgeführt, wenn der `if`-Zweig nicht ausgeführt wird und die Bedingung der `elsif`-Anweisung truthy ist.
`elsif`-Anweisungen lassen sich aneinanderreihen, und die erste truthy Bedingung wird ausgeführt.
Am Ende der `if`-Anweisung kann außerdem eine else-Anweisung stehen, die ausgeführt wird, wenn keine der vorherigen Anweisungen zutraf.

```crystal
if 1 != 1
  puts "1 is not equal to 1"
elsif 1 > 2
  puts "1 is greater than 2"
else
  puts "1 is not equal to 1 and 1 is not greater than 2"
end
# => 1 is not equal to 1 and 1 is not greater than 2
```

## Ternärer Operator

Crystal hat einen ternären Operator, eine einzeilige if-else-Anweisung: `condition ? expression_if_truthy : expression_if_falsey`

```crystal
1 == 1 ? puts("1 is equal to 1") : puts("1 is not equal to 1")
# => 1 is equal to 1
```

## if und unless als Suffix

Die if- und die unless-Anweisung kannst du auch als [Suffix][if-as-suffix] verwenden. Das ist praktisch, wenn du eine einzelne Codezeile nur ausführen möchtest, wenn eine Bedingung wahr ist.
Dazu setzt du die if- oder unless-Anweisung hinter den Code, den du ausführen möchtest.

```crystal
puts "1 is equal to 1" if 1 == 1
# => 1 is equal to 1

puts "1 is not equal to 1" unless 1 == 1
# => no output
```

## Typen mit Bedingungen

Wenn du unterschiedliche Typen zuweist, trägt die Variable beide Typen.
Das liegt daran, dass der Compiler nicht weiß, welcher Zweig ausgeführt wird.
Diese Mehrfachzuweisung, auch Union genannt, wird in späteren Konzepten erklärt.
Das siehst du im folgenden Beispiel:

```crystal
if 1 == 1
  a = 1
else
  a = "1"
end

typeof(a) # => Int32 | String
```
