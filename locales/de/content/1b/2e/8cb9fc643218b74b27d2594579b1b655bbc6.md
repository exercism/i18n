# Klassen

Klassen sind ein zentrales Konzept in der [objektorientierten Programmierung][object-oriented-programming].
[In Crystal ist alles ein Objekt][everything-is-an-object], jedes Objekt hat einen Typ und kann auf bestimmte Methoden reagieren.
Klassen sind Baupläne zum Erstellen von Objekten. Sie liefern Anfangswerte für den Zustand, etwa Variablen, und Implementierungen des Verhaltens, etwa Methoden.
Objekte sind Instanzen einer Klasse, die alle Instanzvariablen und Zustände enthalten.

## Klassendefinition

Eine Klasse definierst du mit dem Schlüsselwort `class`, gefolgt vom Namen der Klasse in `UpperCamelCase`.

```crystal
class Account
end
```

## Eine Instanz erstellen

Um [eine Instanz einer Klasse zu erstellen][new-initialize], rufst du den Klassennamen mit der Methode `new` auf.

```crystal
class Account
end

account = Account.new
```

Im obigen Beispiel ist die Variable `account` eine Instanz der Klasse `Account`.

Beim Erstellen einer Instanz wirkt eine spezielle Methode namens `initialize` als Konstruktor.
Sie wird aufgerufen, wenn eine Instanz erstellt wird.
Der Konstruktor ermöglicht es dir, den Anfangszustand der Instanz festzulegen.
Die Methode `initialize` kann Argumente entgegennehmen, die beim Erstellen einer Instanz übergeben werden.

```crystal
class Account
  def initialize(number)
    5 + number # => 9
  end
end

Account.new(4)
```

~~~~exercism/note
Die Methode `initialize` kann keinen Wert manuell zurückgeben; stattdessen gibt `new` die neu erstellte Instanz zurück.

```crystal
class Account
  def initialize(number)
    5 + number
  end
end

Account.new(4)
# => #<Account:0x7f5dc33dcea0>
```
~~~~

## Instanzmethoden

Eine Instanzmethode ist eine Methode, die einer Instanz einer Klasse zur Verfügung steht und auf dieser Instanz aufgerufen werden kann.
Instanzmethoden definierst du mit dem Schlüsselwort `def`, gefolgt vom Namen der Methode.
Sie werden innerhalb der Klassendefinition definiert.

```crystal
class Account
  def balance
    100
  end
end

account = Account.new
account.balance # => 100
```

## Instanzvariablen

[Instanzvariablen][instance-variable] sind Variablen, die in allen Methoden der Instanz verfügbar sind.
Um auf eine Instanzvariable zuzugreifen, musst du eine Instanzmethode definieren.
Sie können in der Methode `initialize` initialisiert werden.
Sie werden mit dem Präfix `@` definiert.

```crystal
class Account
  def initialize
    @balance = 100
  end

  def balance
    @balance
  end
end

account = Account.new
account.balance
# => 100
```

Instanzvariablen können auch innerhalb der Klassendefinition definiert werden.

```crystal
class Account
  @age = 0
end
```

### Instanzvariablen mit Initialisierung

Instanzvariablen können mit einem Argument initialisiert werden, das an die Methode `initialize` übergeben wird.
Da Crystal den Typ des bei der Initialisierung verwendeten Arguments nicht ableiten kann, musst du ihn angeben.
Wenn du mehr darüber lesen möchtest, kannst du das hier nachlesen: [type-inference][type-inference].
Um den Typ der Variable anzugeben, verwendest du das Symbol `:`, gefolgt vom Typ.
Wenn du zum Beispiel eine Instanzvariable namens `balance` vom Typ `Int32` erstellen möchtest, kannst du das so machen: `@balance : Int32`.
Oder wenn du eine Instanzvariable namens `raining` vom Typ `Bool` erstellen möchtest, kannst du das so machen: `@raining : Bool`.

Es gibt mehrere Wege, das umzusetzen. Entweder deklarierst du in der Methode `initialize` das Argument mit dem Typ und weist dann die Instanzvariable dem Argument zu, wie im folgenden Beispiel:

```crystal
class Account
  def initialize(balance : Int32)
    @balance = balance
  end

  def balance
    @balance
  end
end

account = Account.new(1)
account_2 = Account.new(5)

account.balance
# => 1

account_2.balance
# => 5
```

Ein anderer Weg ist, den Typ der Instanzvariable in der Klassendefinition in der Form `@<variable> : <Type>` zu deklarieren, wie im folgenden Beispiel:

```crystal
class Weather

  @raining : Bool

  def initialize(raining)
    @raining = raining
  end

  def raining
    @raining
  end
end

weather = Weather.new(true)
weather.raining
# => true
```

### Kurzschreibweise zum Initialisieren von Instanzvariablen

Es gibt eine Kurzschreibweise, um Instanzvariablen in den Argumenten der Methode `initialize` zu initialisieren, mit derselben Syntax `@<variable> : <Type>`.
Diese kombiniert die Zuweisung der Instanzvariable an das Argument und die Deklaration des Typs der Instanzvariable.

```crystal
class Account
  def initialize(@balance : Int32)
  end
end
```

## Instanzvariablen ändern

Methoden können Instanzvariablen ändern.
Diese Methoden können auf der Instanz der Klasse aufgerufen werden.
Wenn eine Methode eine Instanzvariable ändert, ist diese Änderung nur in der Instanz der Klasse sichtbar, auf der du sie aufgerufen hast.

```crystal
class Account
  def initialize(balance : Int32)
    @balance = balance
  end

  def withdraw(amount)
    @balance -= amount
  end

  def balance
    @balance
  end
end

account = Account.new(10)
account_2 = Account.new(10)
account.balance
# => 10

account_2.balance
# => 10

account.withdraw(5)
account.balance
# => 5

account_2.balance
# => 10
```

## Klassenmethoden

[Klassenmethoden][class-methods] sind Methoden, die für eine Klasse definiert sind, aber nicht für ihre Instanzen.
Sie bieten eine Möglichkeit, Methoden zu erstellen, die nicht vom Zustand der Instanz abhängig sind.
Sie werden mit dem Schlüsselwort `def` definiert, gefolgt von `self.<method name>`.
`self` ist eine Referenz auf den Namensraum, aus dem self aufgerufen wird.
In diesem Fall bezieht es sich auf die Klasse `Account`.
Es wäre dasselbe, als hättest du `Account.` geschrieben, aber `self.` ist der bevorzugte Weg.

```crystal
class Account
  def self.balance
    100
  end
end

Account.balance
# => 100
```
