# Einführung

Reguläre Ausdrücke in Elixir folgen der **PCRE**-Spezifikation (**P**erl **C**ompatible **R**egular **E**xpressions), ähnlich wie in anderen populären Sprachen wie Java, JavaScript oder Ruby.

Das Modul `Regex` bietet Funktionen für die Arbeit mit regulären Ausdrücken. Einige Funktionen des Moduls `String` akzeptieren ebenfalls reguläre Ausdrücke als Argumente.

~~~~exercism/note
Bei dieser Übung wird davon ausgegangen, dass du die Syntax regulärer Ausdrücke bereits kennst, einschließlich Zeichenklassen, Quantoren, Gruppen und Captures.

Wenn du deine Kenntnisse über reguläre Ausdrücke auffrischen möchtest, schau dir eine dieser Quellen an: [Regular-Expressions.info](https://www.regular-expressions.info), [Rex Egg](https://www.rexegg.com/), [RegexOne](https://regexone.com/), [Regular Expressions 101](https://regex101.com/), [RegExr](https://regexr.com/).
~~~~

## Sigils

Der gebräuchlichste Weg, reguläre Ausdrücke zu erstellen, ist das Sigil `~r`.

```elixir
~r/test/
```

Beachte, dass alle Elixir-Sigils [verschiedene Arten von Trennzeichen][sigils] unterstützen, nicht nur `/`.

## Abgleichen

Mit dem Operator `=~/2` kannst du einen Regex-Abgleich durchführen, der ein `boolean`-Ergebnis zurückgibt. Alternativ gibt es auch die Funktion `match?/2` im Modul `Regex` sowie im Modul `String`.

```elixir
"this is a test" =~ ~r/test/
# => true

String.match?("Alice has 7 apples", ~r/\d{2}/)
# => false
```

## Erfassen

Wenn eine einfache boolesche Prüfung nicht ausreicht, verwende die Funktion `Regex.run/3`, um eine Liste aller Captures zu erhalten (oder `nil`, wenn es keine Übereinstimmung gab). Das erste Element in der zurückgegebenen Liste ist immer eine Übereinstimmung für den gesamten regulären Ausdruck, und die folgenden Elemente sind übereinstimmende Gruppen.

```elixir
Regex.run(~r/(\d) apples/, "Alice has 7 apples")
# => ["7 apples", "7"]
```

## Modifikatoren

Das Verhalten eines regulären Ausdrucks kann durch das Anhängen spezieller Flags geändert werden. Wenn du ein Sigil verwendest, um einen regulären Ausdruck zu erstellen, fügst du die Modifikatoren nach dem zweiten Trennzeichen hinzu.

Gängige Modifikatoren sind:
- `i` - macht den Abgleich unabhängig von Groß- und Kleinschreibung.
- `u` - aktiviert Unicode-spezifische Muster wie `\p` und bewirkt, dass Zeichenklassen wie `\w`, `\s` usw. auch auf Unicode-Zeichen passen.

```elixir
"this is a TEST" =~ ~r/test/i
# => true
```
