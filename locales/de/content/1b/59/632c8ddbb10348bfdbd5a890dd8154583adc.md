# Tools für Mitwirkende

Zum Lösen der Übungen brauchst du nur die Tools aus [INSTALLATION.md](INSTALLATION.md).
Wer zum Track beiträgt, braucht ein paar mehr, denn die Skripte des Tracks verwenden sie:

- `git`, um das Repository zu klonen und Pull Requests zu öffnen.
- `jq`, wird von `bin/verify-exercises` und `bin/add-practice-exercise` genutzt.
- `curl`, wird von `bin/fetch-configlet` genutzt.
- Python 3.11 oder neuer, für den Testgenerator.
- `clang-format`, das der Testgenerator auf die Dateien anwendet, die er schreibt.
- `pre-commit`, das vor jedem Commit die Prüfungen des Repositorys ausführt.

Installiere sie mit dem Befehl für deine Distribution und folge dann den Schritten unter „Repository einrichten“.

## Debian / Ubuntu

```shell
sudo apt install git jq curl clang-format pre-commit
```

## Fedora

```shell
sudo dnf install git jq curl pre-commit clang-tools-extra diffutils
```

## Arch Linux

```shell
sudo pacman -S git jq curl pre-commit clang diffutils
```

## openSUSE Tumbleweed

```shell
sudo zypper install git jq curl python3-pre-commit clang-tools diffutils
```

## Repository einrichten

Vom Wurzelverzeichnis des Repositorys aus:

```shell
bin/fetch-configlet
bin/configlet info
pre-commit install
pre-commit run --all-files
```
