# Anweisungen

In dieser Übung schreibst du ein Programm, das dir bei der Vorbereitung auf den Kauf eines Fahrzeugs hilft.

Du hast zwei Aufgaben: Stelle fest, ob du einen Führerschein brauchst, und schätze den akzeptablen Preis für ein gebrauchtes Fahrzeug.

## 1. Stelle fest, ob du einen Führerschein brauchst

Für manche Arten von Fahrzeugen brauchst du einen Führerschein.
Geh davon aus, dass nur Fahrzeuge, die `car` oder `truck` enthalten, einen Führerschein brauchen; alles andere kannst du ohne Führerschein fahren.

Implementiere ein `pattern {action}`-Paar, das greift, wenn das erste Feld `needs_license` lautet.
Es soll die Art des Fahrzeugs aus dem zweiten Feld lesen und "true" ausgeben, wenn du für diese Art von Fahrzeug einen Führerschein brauchst.
Wenn du keinen Führerschein brauchst, musst du nichts ausgeben.

```sh
echo "needs_license,dumptruck" | gawk -f vehicle-purchase.awk
# => true

echo "needs_license,bike" | gawk -f vehicle-purchase.awk
# => (empty output)
```

## 2. Schätze den Preis für ein gebrauchtes Fahrzeug

Jetzt, wo du deine Entscheidung getroffen hast, willst du sichergehen, dass du beim Händler einen fairen Preis bekommst.
Da du ein gebrauchtes Fahrzeug kaufen möchtest, hängt der Preis davon ab, wie alt das Fahrzeug ist.
Für eine grobe Schätzung nimm an, dass ein Fahrzeug, das weniger als 3 Jahre alt ist, 80 % des ursprünglichen Preises kostet, den es neu hatte.
Ist es mehr als 10 Jahre alt, kostet es 50 %.
Ist das Fahrzeug mindestens 3 Jahre alt, aber nicht älter als 10 Jahre, kostet es 70 % des ursprünglichen Preises.

Implementiere ein `pattern {action}`-Paar, das greift, wenn das erste Feld `resell_price` lautet.
Es soll den ursprünglichen Preis des Fahrzeugs aus dem zweiten Feld und das Alter aus dem dritten Feld lesen.
Die Aktion soll den geschätzten Preis ausgeben.

```sh
echo "resell_price,1000,1" | gawk -f vehicle-purchase.awk
# => 800

echo "resell_price,1000,5" | gawk -f vehicle-purchase.awk
# => 700

echo "resell_price,1000,15" | gawk -f vehicle-purchase.awk
# => 500
```
