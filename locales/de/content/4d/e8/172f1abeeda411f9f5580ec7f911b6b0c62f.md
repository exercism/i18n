# Einführung

Die meisten Sequenzwörter höherer Ordnung übergeben der Quotation jeweils ein Element. Die `*-index`-Familie übergibt der Quotation das Element *und* seine Position. `times` führt eine Zählschleife aus, bei der der Schleifenblock gar keine Sequenz hat. Das ist nützlich, wenn du nur eine Zählung brauchst.
