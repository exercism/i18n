# Hinweise

## 1. Finde die Position einer Karte

- Die Indizes eines Arrays beginnen bei `0`.
- Es gibt eine [eingebaute][indexof_method_docs] Methode, um den Index eines bestimmten Werts zu bekommen.

## 2. Stelle fest, ob eine Karte vorhanden ist

- Es gibt eine [eingebaute][includes_method_docs] Methode, mit der du prüfen kannst, ob der Wert im Array vorhanden ist.

## 3. Stelle fest, ob jede Karte gerade ist

- Es gibt eine [eingebaute][every_method_docs] Methode, mit der du prüfen kannst, ob jeder Wert ein Prädikat erfüllt.

## 4. Prüfe, ob der Stapel eine Karte mit ungeradem Wert enthält

- Es gibt eine [eingebaute][some_method_docs] Methode, mit der du prüfen kannst, ob mindestens ein Wert ein Prädikat erfüllt.

## 5. Hole die erste ungerade Karte aus dem Stapel

- Es gibt eine [eingebaute][find_method_docs] Methode, um das erste Element zu bekommen, das ein Prädikat erfüllt.

## 6. Bestimme die Position der ersten geraden Karte

- Es gibt eine [eingebaute][findindex_method_docs] Methode, um den ersten Index im Array zu bekommen, bei dem der Wert die Bedingung erfüllt.
