# Installation

## Ubuntu (und die meisten anderen Debian-basierten Distributionen)

Um Code lokal zu kompilieren, brauchst du gcc und make. Installieren kannst du sie mit

```shell
sudo apt install gcc make
```

Wenn du nicht auf ARM64-Hardware läufst, installiere den [QEMU][]-Emulator und die GCC-ARM64-Cross-Toolchain mit

```shell
sudo apt install qemu-user libc6-dev-arm64-cross gcc-aarch64-linux-gnu
```

## Windows

Verwende das [Windows Subsystem for Linux][] mit einer Debian-basierten Distribution und folge der Ubuntu-Anleitung oben.
Alternativ kannst du eine Linux-VM einrichten.

## macOS

Eine Linux-VM lässt sich mit jeder geeigneten Virtualisierungslösung starten (z. B. [Lima][]).

[QEMU]: https://www.qemu.org/
[Windows Subsystem for Linux]: https://docs.microsoft.com/en-gb/windows/wsl/about
[Lima]: https://lima-vm.io/
