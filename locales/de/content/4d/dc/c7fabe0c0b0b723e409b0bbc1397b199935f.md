## 1. Fehler bei Division durch Null

- Implementiere das Modul und gib die Nachricht mit einem speziellen [eingebauten Makro zum Definieren von Ausnahmen][defexception] an.
- Module können in andere Module verschachtelt werden.

## 2. Fehler bei einem Stack-Underflow

- Implementiere das Modul und gib die Nachricht mit einem speziellen [eingebauten Makro zum Definieren von Ausnahmen][defexception] an.
- Du kannst einen der Callbacks des Exception-Verhaltens verwenden, um eine Ausnahme zu definieren, deren Nachricht sich je nach den an `raise/2` übergebenen Argumenten ändert.
- Module können in andere Module verschachtelt werden.

## 3. Schreibe eine Divisionsfunktion

- Schreibe eine Funktion mit mehreren Klauseln und verwende Guards für den Kontrollfluss.
- Du kannst in der Argumentliste der Funktion mithilfe von Pattern Matching die Werte des Stacks an Variablen binden.
