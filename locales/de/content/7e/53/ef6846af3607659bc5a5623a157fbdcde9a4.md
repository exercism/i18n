# Der ternäre Operator

Ein ternärer Operator ist eine kürzere Schreibweise für einfache `if/else`-Anweisungen.
Wenn eine `if/else`-Anweisung nur zwei Zweige enthält, einen für den Fall, dass die Bedingung wahr ist, und einen für den Fall, dass sie falsch ist, kannst du sie als ternären Operator schreiben.

Ternäre Operatoren verwenden die Symbole `?` und `:` zusammen, um eine Bedingung aufzuteilen:
```ruby
condition ? true_branch : false_branch
```

Der Code links vom `?` ist die Bedingung, und der Code rechts enthält die beiden möglichen Zweige, getrennt durch das `:`.
Wenn die Bedingung _wahr_ ist, wird der Code auf der _linken_ Seite des `:` ausgeführt.
Wenn die Bedingung _falsch_ ist, wird der Code _rechts_ vom `:` ausgeführt.

Zum Beispiel:

```ruby
if traffic_light == 'green'
  cross_the_road
else
  wait
end
```

kannst du so umschreiben:

```ruby
traffic_light == 'green' ? cross_the_road : wait
```
