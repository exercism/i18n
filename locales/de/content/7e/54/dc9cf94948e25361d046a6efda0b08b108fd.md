# Einführung

In JavaScript ermöglichen _Template-Strings_ das Einbetten von Ausdrücken in Strings, was auch als Stringinterpolation bezeichnet wird.
Diese Funktionalität erweitert die Möglichkeiten des eingebauten globalen Objekts [`String`][string-reference].

Du kannst Template-Strings in JavaScript erstellen, indem du den Text in Backticks einschließt.
Sie erlauben nicht nur, dass der Text Zeilenumbrüche und andere Sonderzeichen enthält, sondern du kannst auch Variablen und andere Ausdrücke einbetten.

```javascript
const num1 = 1;
const num2 = 2;

`Adding ${num1} and ${num2} gives ${num1 + num2}.`;
// => Adding 1 and 2 gives 3.
```

Im obigen Beispiel werden Backticks - (<code>\`\`</code>) - verwendet, um einen Template-String darzustellen. Das `${...}` ist der Platzhalter, der für die Substitution verwendet wird.
Alle Nicht-String-Typen werden _implizit_ in Strings umgewandelt.
Dieses Thema wird im Konzept [Typkonvertierung][type-conversion-concept] behandelt.
Alle Arten von Ausdrücken können mit Template-Strings verwendet werden.

```javascript
const track = 'JavaScript';

`This track on exercism.org is ${track.toUpperCase()}.`;
// => This track on exercism.org is JAVASCRIPT.
```

Wenn du Strings über mehrere Zeilen formatieren möchtest:

```javascript
`This is an example of using template
strings to accomplish multiple
lines`;
```

Mit den verfügbaren Substitutionsmöglichkeiten kannst du auch Logik in den Prozess einbringen, um festzulegen, wie der Ausgabe-String aussehen soll.
Eine Möglichkeit, diese Logik umzusetzen, ist die Verwendung des [ternären Operators][ternary-operator].
Das bietet die gleiche bedingte `if/else`-Funktionalität in einem etwas anderen Format.

Um Logik in die Syntax von Template-Strings einzubringen:

```javascript
const grade = 95;

`You have ${grade > 90 ? 'passed' : 'failed'} the exam.`;
// => You have passed the exam.
```
