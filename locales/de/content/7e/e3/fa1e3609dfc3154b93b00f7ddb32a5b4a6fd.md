# Anleitung

Elyse, die angehende Magierin, setzt ihr Training fort. Sie bekommt mehrere Kartenstapel, mit denen sie ihre Tricks vorführen muss.
Um es etwas einfacher zu machen, verwendet sie nur die Karten 1 bis 10.

In dieser Übung verwendest du eingebaute Methoden, um den Inhalt eines Vektors zu analysieren.

## 1. Prüfe, ob eine Karte vorhanden ist

Elyse möchte herausfinden, ob eine Karte im Stapel vorhanden ist, also ob der Stapel eine bestimmte Zahl enthält.

```R
card = 3;
does_stack_include_card(c(2, 3, 4, 5), card);
# => TRUE
```

## 2. Finde die Position einer Karte

Elyse möchte die Position (den Index) einer Karte im Stapel wissen.
Wenn die Karte nicht im Stapel ist, gib `-1` zurück.

```R
card = 2;
get_card_position(c(9, 7, 3, 2), card);
# => 4
```

## 3. Bestimme, ob jede Karte gerade ist

Elyse möchte wissen, ob jede Karte gerade ist, also ob jede Zahl im Stapel eine gerade Zahl ist.

```R
is_each_card_even(c(2, 4, 6, 7));
# => FALSE
```

## 4. Prüfe, ob der Stapel eine Karte mit ungeradem Wert enthält

Elyse möchte wissen, ob es eine ungerade Zahl im Stapel gibt.

```R
does_stack_include_odd_card(c(3, 2, 6, 4, 8));
# => TRUE
```

## 5. Hole die erste ungerade Karte aus dem Stapel

Elyse möchte den Wert der ersten Karte wissen, die ungerade ist.  
Wenn es keine ungerade Karte im Stapel gibt, gib `-1` zurück.

```R
get_first_odd_card(c(4, 2, 8, 7, 9));
# => 7
```

## 6. Bestimme die Position der ersten geraden Karte

Elyse möchte die Position der ersten Karte wissen, die gerade ist.
Wenn es keine gerade Karte im Stapel gibt, gib `-1` zurück.

```R
get_first_even_card_position(c(5, 2, 3, 1));
# => 2
```
