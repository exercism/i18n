# Anweisungen

In dieser Übung verarbeitest du Logzeilen.

Jede Logzeile ist ein String im Format `"[<LEVEL>]: <MESSAGE>"`.

Es gibt drei Log-Level: `INFO`, `WARNING` und `ERROR`.

Du hast drei Aufgaben. Jede nimmt eine einzelne Logzeile vom Stapel.

## 1. Die Nachricht aus einer Logzeile ermitteln

Definiere `message`, um die Nachricht der Logzeile zurückzugeben. Führende und
nachfolgende Leerzeichen sollen entfernt werden.

```factor
"[ERROR]: Invalid operation" message .
! => "Invalid operation"

"[WARNING]:  Disk almost full\r\n" message .
! => "Disk almost full"
```

## 2. Das Log-Level aus einer Logzeile ermitteln

Definiere `log-level`, um das Log-Level der Logzeile in Kleinbuchstaben
zurückzugeben.

```factor
"[ERROR]: Invalid operation" log-level .
! => "error"
```

## 3. Eine Logzeile umformatieren

Definiere `reformat`, um die Nachricht an den Anfang zu stellen und das
Log-Level in Kleinbuchstaben in Klammern dahinter zu setzen.

```factor
"[INFO]: Operation completed" reformat .
! => "Operation completed (info)"
```

----

***Hinweis:*** Alle Strings in dieser Übung sind ASCII. Spätere Übungen
beschäftigen sich mit der Verarbeitung von Strings, die Unicode berücksichtigen.
