# Einführung

Ruby wird mit einer Standardbibliothek ausgeliefert (oft kurz „stdlib“ genannt), einer Sammlung von Klassen für die Arbeit mit Dingen wie Datum, JSON und Netzwerk.
Sie bietet außerdem nützliche Funktionen, mit denen sich dein Code leichter handhaben lässt.

`OpenStruct` ist Teil der Standardbibliothek und erlaubt es dir, auf einfache Weise ein Objekt aus einem `Hash` zu erzeugen.
Statt über `Hash`-Schlüssel auf die Werte zuzugreifen, kannst du mit `OpenStruct` Methoden verwenden, um Werte zu lesen und zu setzen.

Wenn du Klassen aus der Standardbibliothek oder einer anderen Bibliothek verwendest, musst du diese Klasse mit der `require`-Methode einbinden.

```ruby
require 'ostruct'

attributes = { name: "Jeremy Walker", age: 21, location: "Nomadic" }
person = OpenStruct.new(attributes)

person.name
#=> Jeremy Walker

person.location
#=> Nomadic

# Update the age
person.age = 35

# It sets correctly
person.age
#=> 35
```

Ein zusätzlicher Vorteil ist, dass du bei der Blocksyntax eine Abkürzung nutzen kannst.
Wenn ein Block nur eine einzige Methode aufruft, kannst du den Block durch `&:` gefolgt vom Methodennamen ersetzen.
Diese beiden Zeilen sind zum Beispiel gleichbedeutend:

```ruby
people.sum { |person| person.age }
people.sum(&:age)
```
