# Einführung in For-Each-Schleifen

Die [for-each-Schleife](https://docs.oracle.com/javase/tutorial/java/nutsandbolts/for.html) bietet einen Mechanismus, um einen Block Code für jedes Element in einer Sammlung auszuführen.
Einige Dokumentationen (z. B. Oracles Dokumentation) bezeichnen diese als erweiterte for-Schleifen.

Hier ist die allgemeine Syntax:

```java
for(declaration: collection) {
    body;
}
```

Die `declaration` deklariert die Variable, die die aus der Sammlung zugewiesenen Werte aufnimmt.

Die `collection` ist ein Array oder eine Sammlung, die die Werte enthält, die der Schleifenvariable zugewiesen werden.

Der `body` enthält die Anweisungen, die einmal für jeden Wert in der Sammlung ausgeführt werden.

Zum Beispiel:

```java
char[] vowels = {'a', 'e', 'i', 'o', 'u'};

for(char vowel: vowels) {
    System.out.println(vowel);
}
```

was Folgendes ausgibt:

```text
a
e
i
o
u
```

Im Allgemeinen ist eine `for-each`-Schleife einer `for`-Schleife aus folgenden Gründen vorzuziehen:

- Eine `for-each`-Schleife iteriert garantiert über _alle_ Werte.
- Eine `for-each`-Schleife ist _deklarativer_, das heißt, der Code teilt mit, _was_ er tut, statt _wie_ er es tut.
- Eine `for-each`-Schleife ist narrensicher, während bei `for`-Schleifen leicht ein Off-by-one-Fehler passieren kann (denk an die Verwendung von `<` versus `<=`).
- Eine `for-each`-Schleife funktioniert mit allen Sammlungstypen, einschließlich solcher, die keinen Indexzugriff auf Elemente unterstützen (z. B. ein `Set`).
