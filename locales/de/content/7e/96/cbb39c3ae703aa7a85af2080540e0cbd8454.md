# Einführung

## Arrays und Vektoren

C++ bietet verschiedene Container, um Elemente desselben Typs geordnet zu speichern. Es gibt `std::array` für Container mit fester Größe und `std::vector`, der seine Größe dynamisch anpassen kann.

### Konstruktion

Wenn du ein Array oder einen Vektor deklarierst, musst du den Typ der Elemente angeben, die der Container aufnehmen soll.
Arrays brauchen außerdem eine Größe.
Schau dir diese Beispiele an, um zu sehen, wie die beiden Containertypen initialisiert werden:

```cpp
#include <array>
#include <string>

// std::array<element_type, size> variable_name {list of elements}
std::array<std::string, 3> indie_rock {"yeah", "yeah", "yeah"};
// indie_rock contains the elements "yeah" three times
```

Vektoren brauchen meist mehr Speicher, weil sie zusätzlichen Platz für weiteres Wachstum reservieren.
Eine Größe musst du nicht angeben:

```cpp
#include <vector>

// std::vector<element_type> variable_name {list of elements}
std::vector<int> countdown {3, 2, 1};
// countdown contains the elements 3, 2 and 1
```

> Hinweis: Die genauen Hintergründe des Template-Konzepts musst du jetzt noch nicht kennen. Es wird weiter unten im Lehrplan in einem eigenen Konzept behandelt.

### Zugriff auf Elemente

Vektoren und Arrays teilen sich dieselben Funktionen, um auf ihre Elemente zuzugreifen.
Mit den Memberfunktionen `front` und `back` bekommst du das erste und das letzte Element des Containers.
Außerdem gibt es `at` und den Operator `[]`, um auf bestimmte Elemente zuzugreifen.

```cpp
countdown[0];
// => 3
countdown.at(2);
// => 1
countdown[1] = 4;
// countdown now contains 3, 4 and 1
indie_rock.back() = "yeahs";
// indie_rock is now "yeah", "yeah", "yeahs"
```

> Hinweis: Wenn du eine Position wählst, die außerhalb des Bereichs deines Containers liegt, kann `[]` zu undefiniertem Verhalten führen.
> Die Funktion `at` würde eine Ausnahme auslösen, was dir langfristig das Leben erleichtern kann.

### Vektormodifizierer

Da ein `vector` nicht in seiner Größe festgelegt ist, kannst du Elemente hinzufügen oder entfernen.
Zwei häufige Funktionen dafür sind `emplace_back` und `pop_back`.

```cpp
std::vector<std::string> witches {"Holly", "Alyssa", "Shannen"};
witches.pop_back();
// Shannen is no longer with the witches
witches.emplace_back("Rose");
// Rose has joined the team
```

### Kapazität

Mit der Memberfunktion `empty` kannst du prüfen, ob ein Container leer ist.
Wenn du die Anzahl der Elemente wissen willst, kannst du `size` verwenden.
