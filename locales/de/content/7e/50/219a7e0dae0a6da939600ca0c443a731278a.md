# Anweisungen

Du beobachtest leidenschaftlich gern Vögel und hältst fest, wie viele Vögel in den letzten sieben Tagen deinen Garten besucht haben.

Du hast sechs Aufgaben, die sich alle mit der Anzahl der Vögel befassen, die deinen Garten besucht haben.

## 1. Prüfe, wie viele Vögel heute zu Besuch waren

Implementiere die Funktion `today()`, die zurückgibt, wie viele Vögel deinen Garten heute besucht haben. Die Vogelzahlen sind nach Tagen geordnet: Das erste Element ist die Zahl des ältesten Tages, das letzte Element die Zahl von heute.

```R
birds_per_day <- c(2, 5, 0, 7, 4, 1)
today(birds_per_day)
# => 1
```

## 2. Erhöhe die heutige Anzahl

Implementiere die Funktion `increment_todays_count()`, um die Anzahl für heute zu erhöhen:

```R
birds_per_day <- c(2, 5, 0, 7, 4, 1)
increment_todays_count(birds_per_day)
# => c(2, 5, 0, 7, 4, 2)
```

## 3. Prüfe, ob es einen Tag ohne Vogelbesuch gab

Implementiere die Funktion `has_day_without_birds()`, die `TRUE` zurückgibt, wenn es einen Tag gab, an dem kein Vogel den Garten besucht hat; andernfalls gibst du `FALSE` zurück:

```R
birds_per_day <- c(2, 5, 0, 7, 4, 1)
has_day_without_birds(birds_per_day)
# => true
```

## 4. Berechne die Anzahl der Vögel für die ersten Tage

Implementiere die Funktion `count_for_first_days()`, die die Anzahl der Vögel zurückgibt, die seit Beginn der Woche deinen Garten besucht haben. Beschränke die Zählung dabei auf die angegebene Anzahl von Tagen ab Beginn der Woche.

```R
birds_per_day <- c(2, 5, 0, 7, 4, 1)
count_for_first_days(birds_per_day, 4)
# => 14
```

## 5. Berechne die Anzahl der geschäftigen Tage

Manche Tage sind geschäftiger als andere. Ein geschäftiger Tag ist einer, an dem fünf oder mehr Vögel deinen Garten besucht haben.
Implementiere die Funktion `busy_days()`, die die Anzahl der geschäftigen Tage zurückgibt:

```R
birds_per_day <- c(2, 5, 0, 7, 4, 1)
busy_days(birds_per_day)
# => 2
```

## 6. Berechne die laufende Gesamtzahl der Vogelbesuche der letzten Woche

Du bist neugierig, wie viele Vögel diese Woche insgesamt schon zu Besuch waren.
Berechne die kumulierten Summen für jeden Tag.

```R
running_total(c(7, 6, 5, 4, 3, 2, 1))
#> [1]  7 13 18 22 25 27 28
```

## 7. Sortiere die Tagesnamen danach, wie geschäftig sie waren

Du vermutest, dass die Vogelbesuche vom Verkehrsaufkommen der umliegenden Straßen beeinflusst werden und deshalb am Wochenende anders ausfallen als an Wochentagen.

Sortiere die Tagesabkürzungen in _absteigender_ Reihenfolge nach der Anzahl der Vögel, die zu Besuch waren.

```R
day_names <- c("Mon", "Tue", "Wed", "Thu", "Fri", "Sat", "Sun")
birds_per_day <- c(5, 2, 4, 6, 0, 9, 8)
busy_days_of_week(birds_per_day, day_names)
#> [1] "Sat" "Sun" "Thu" "Mon" "Wed" "Tue" "Fri"
```
