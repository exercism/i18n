# Einführung

## Reduzieren

Beim Reduzieren wendest du wiederholt eine Funktion auf jedes Element einer Sequenz an und sammelst die Ergebnisse auf irgendeine Weise. Die angewendete Funktion nimmt zwei Parameter: den aktuellen gesammelten Wert und das zu verarbeitende Element. Sie muss den neuen gesammelten Wert ergeben.

In Common Lisp erledigst du das mit der Funktion `reduce`. In ihrer einfachsten Form sieht sie so aus:

`(reduce #'function-to-apply sequence :initial-value value)`

Beachte, dass ein Anfangswert angegeben wird. Dieser ist der „aktuelle gesammelte Wert“, der an die Funktion übergeben wird, wenn das erste Element verarbeitet wird.

Hier ist ein Beispiel, das die Zahlen der Liste addiert und dabei mit einem Anfangswert von 10 beginnt:

`(reduce #'+ '(1 2 3 4) :initial-value 10) ; => 20`

Beachte: Wenn die Sequenz leer ist, wird die Funktion nie aufgerufen und der Ausdruck ergibt den Anfangswert.
