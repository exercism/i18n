# Über

In Clojure bezeichnet man das Binden eines Werts an einen Namen als [_var_][vars]. Vars auf oberster Ebene (globale Vars) ähneln Konstanten in anderen Sprachen, werden aber häufig neu definiert, um eine dynamische Entwicklung zu ermöglichen.

Vars auf oberster Ebene werden mit [`def`][def] definiert:

```clojure
(def fingers 10)
```

Du kannst die Kernfunktionen für [Operationen mit Zahlen][operators] verwenden, um Werte zu berechnen.

Mit dem `defn`-Makro kannst du eine [Funktion][functions] definieren, die null oder mehr Argumente entgegennimmt. Eine Funktion gibt immer das Ergebnis des letzten Ausdrucks in ihrem Rumpf zurück.

```clojure
(defn add [x y]
  (+ x y))
```

Eine Funktion rufst du auf, indem du ihren Namen nennst und für jeden Parameter der Funktion ein Argument übergibst.

```clojure
(def five (add 2 3))
```

Funktionen und Werte in Clojure kannst du erst verwenden, _nachdem_ sie definiert wurden. Verwendest du sie, bevor sie definiert wurden, führt das zu einem Compilerfehler.

```clojure
;; Compile error as `add` has not yet been defined
(def seven (add 3 4))

(defn add [x y]
  (+ x y))
```

In Clojure hat Whitespace außer für die Formatierung keine Bedeutung.

Clojure-Funktionen und Vars sind in Namensräumen organisiert. Ein Namensraum gruppiert zusammengehörige Funktionalität und wird mit dem `ns`-Makro definiert:

```clojure
(ns calculator)

(def pi 3.14)

(defn add [x y]
  (+ x y))
```

Clojure unterstützt zwei Arten von Kommentaren. Einzeilige Kommentare beginnen mit `;`, und mit der `comment`-Form verhinderst du die Auswertung von allem zwischen `(comment` und `)`.
