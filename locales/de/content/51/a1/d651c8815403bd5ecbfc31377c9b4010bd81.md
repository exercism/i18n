# Überblick

Die wichtigsten arithmetischen und Vergleichsoperatoren kannst du für deinen eigenen **Abstract** anpassen. Das nennt man Operatorüberladung.

Verwende die `@:op()`-Metadaten an einem Klassenfeld, um einen Operator zu überladen:

```haxe
abstract MyAbstract(String) {
  public inline function new(s:String) {
    this = s;
  }

  @:op(A * B)
  public function repeat(rhs:Int):MyAbstract {
    var s:StringBuf = new StringBuf();
    for (i in 0...rhs)
      s.add(this);
    return new MyAbstract(s.toString());
  }
}

class Main {
  static public function main() {
    var a = new MyAbstract("foo");
    trace(a * 3); // foofoofoo
  }
}
```
