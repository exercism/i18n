# Anweisungen

In dieser Übung schreibst du Code, um Namensschilder für Fabrikmitarbeiter auszugeben.

## 1. Gib ein Namensschild für einen Mitarbeiter aus

Mitarbeiter haben eine ID, einen Namen und einen Abteilungsnamen.
Die Beschriftung der Namensschilder von Mitarbeitern ist wie folgt formatiert: `"[id] - name - DEPARTMENT"`.
Implementiere die Methode `printBadge()`, sodass sie die Beschriftung des Namensschilds eines Mitarbeiters zurückgibt:

```kotlin
printBadge(734, "Ernest Johnny Payne", "Strategic Communication")
// => "[734] - Ernest Johnny Payne - STRATEGIC COMMUNICATION"
```

~~~~exercism/note
Beachte, dass die Abteilung auf dem Schild in Großbuchstaben stehen muss.
~~~~

## 2. Gib ein Namensschild für einen neuen Mitarbeiter aus

Aufgrund einer Eigenheit im Computersystem haben neue Mitarbeiter zu Beginn ihrer Arbeit in der Fabrik manchmal noch keine ID.
Da Namensschilder Pflicht sind, bekommen sie ein vorläufiges Schild ohne ID-Präfix.
Passe die Methode `printBadge()` so an, dass sie auch neue Mitarbeiter unterstützt, die noch keine ID haben:

```kotlin
printBadge(null, "Jane Johnson", "Procurement")
// => "Jane Johnson - PROCUREMENT"
```

## 3. Gib ein Namensschild für den Besitzer aus

Selbst der Besitzer der Fabrik muss jederzeit ein Namensschild tragen.
Ein Besitzer hat jedoch keine Abteilung.
In diesem Fall sollte auf dem Schild `"OWNER"` statt des Abteilungsnamens stehen.
Passe die Methode `printBadge()` so an, dass sie eine Beschriftung für den Besitzer ausgibt:

```kotlin
printBadge(254, "Charlotte Hale", null)
// => "[254] - Charlotte Hale - OWNER"
```

~~~~exercism/note
Beachte, dass der Besitzer auch ein neuer Mitarbeiter sein kann:

```kotlin
printBadge(null, "Charlotte Hale", null)
// => "Charlotte Hale - OWNER"
```
~~~~
