# Einführung

Das Modul `Agent` bietet eine Abstraktion zum Erzeugen von [Prozessen und der _receive-send_-Schleife][exercism-processes]. Ab hier nennen wir Prozesse, die mit dem Modul `Agent` gestartet werden, _„Agent-Prozesse“_. Man kann einen _Agent-Prozess_ wählen, um einen zentralen, gemeinsam genutzten Zustand darzustellen.

Um einen _Agent-Prozess_ zu starten, bietet `Agent` die Funktion `start/2`. Die Funktion, die du beim _Starten_ des _Agent-Prozesses_ mit `start` übergibst, gibt den Anfangszustand des Prozesses zurück:

```elixir
# Start an agent process with an initial value of an empty list
{:ok, agent_pid} = Agent.start(fn -> [] end)
```

Genau wie `Map` oder `List` bietet `Agent` viele Funktionen für die Arbeit mit _Agent-Prozessen_.

Es ist üblich, die gesamte `Agent`-bezogene Funktionalität in einem Modul für die Domäne, die du modellierst, zu organisieren und zu kapseln.

[exercism-processes]: https://exercism.org/tracks/elixir/concepts/processes
