# Einführung

Eine Schleife ist eine Möglichkeit, einen Block aus einer oder mehreren Anweisungen wiederholt auszuführen.
Jeden einzelnen Durchlauf eines solchen Blocks von Anweisungen nennt man eine Iteration.

## while-Schleife

Eine `while`-Schleife führt einen Block von Anweisungen aus, solange ein boolescher Ausdruck am Anfang der Schleife wahr ist.
Wenn der boolesche Ausdruck falsch ist, hört die Schleife auf zu laufen und die Ausführung fährt mit der nächsten Codezeile nach der Schleife fort.

Wenn der boolesche Ausdruck von Anfang an falsch ist, wird die `while`-Schleife überhaupt nicht ausgeführt, und die Ausführung fährt mit der nächsten Codezeile nach der Schleife fort.

```c
int main() {
    int i = 0;
    while (i < 5) {
        printf("Number is %i\n", i++);
    }    
    return 0;
}
```

Wichtig ist, dass es eine Bedingung gibt, die die Schleife beendet; sonst ist es eine Endlosschleife, die jeglichen Fortschritt des Codes blockiert.
Wenn im obigen Code das `++` bei `i` entfernt würde, wäre es eine Endlosschleife.

## do-Schleife

Bei einer `do`-Schleife wird der boolesche Ausdruck am Ende der Schleife getestet.
Eine `do`-Schleife wird immer mindestens einmal ausgeführt, wie im folgenden Beispiel:

```c
do {
    printf("Enter the Answer to the Ultimate Question of Life: ");
    scanf("%d", &answer);
} while (answer != 42); 
// Note that a semicolon is needed after the Boolean expression.
```

Mit einer `while`-Schleife wäre das ausführlicher:

```c
printf(""Enter the Answer to the Ultimate Question of Life: ");
scanf("%d", &answer);
while (answer != 42) {
    printf(""Enter the Answer to the Ultimate Question of Life: ");
    scanf("%d", &answer);
}
```

## for-Schleife

Oft aktualisiert eine Schleife eine Variable und endet, wenn die Variable einen bestimmten Wert erreicht.
Eine `for`-Schleife ist eine Möglichkeit, eine oder mehrere Variablen in einer Zeile innerhalb runder Klammern zu initialisieren, zu aktualisieren und zu testen.
Der erste Abschnitt dient der Initialisierung der Variable, der zweite dem Testen der Variable und der dritte dem Aktualisieren des Werts der Variable.

```c
for (int i = 0; i < 5; i++) {
    printf("Number is %i\n", i);
}
```

Das ist weniger ausführlich als das entsprechende Konstrukt mit einer `while`-Schleife und trotzdem noch gut lesbar.
