# Über

Factor-Sequenzen gibt es in zwei Varianten, wenn du sie *verändern* musst:

- **Arrays** (`{ … }`) haben eine feste Länge. Mit `set-nth` / `change-nth` kannst du ändern, *was* an jeder Position steht, aber du kannst sie nicht vergrößern oder verkleinern.
- **Vektoren** (`V{ … }`) haben eine variable Länge. `push` hängt etwas ans Ende an, `pop` entfernt das letzte Element und gibt es zurück.

```factor
USING: arrays kernel sequences ;

! Fixed-length: build a counter array of zeros, then bump one slot.
3 0 <array>            ! { 0 0 0 }
dup [ 1 + ] 1 rot change-nth
.                      ! { 0 1 0 }

! Variable-length: build a vector of names by pushing.
V{ } clone
"alice" over push
"bob" over push
dup pop drop           ! removes "bob"
.                      ! V{ "alice" }
```

| Wort            | Wirkung                                        |
|-----------------|------------------------------------------------|
| `<array>`       | `( n elt -- array )`: Array aus `n` Kopien von `elt` |
| `<vector>`      | `( n -- vector )`: leerer Vektor mit Kapazität `n` |
| `V{ }`          | leeres Vektor-Literal                          |
| `set-nth`       | `( elt n seq -- )`: weist das Element an Index `n` zu |
| `change-nth`    | `( i seq quot -- )`: wendet `quot` auf das Element an `i` an |
| `push`          | `( elt seq -- )`: hängt an einen Vektor an     |
| `suffix!`       | `( seq elt -- seq )`: hängt an Ort und Stelle an, gibt den Vektor zurück |
| `pop`           | `( seq -- elt )`: entfernt das letzte Element und gibt es zurück |
| `pop*`          | `( seq -- )`: entfernt das letzte Element und verwirft es |
| `clone`         | `( obj -- copy )`: neue, unabhängige Kopie     |
| `new-sequence`  | `( n exemplar -- newseq )`: neue Sequenz derselben Klasse wie `exemplar` |
| `new-resizable` | `( n exemplar -- newseq )`: neue, in der Größe veränderbare Variante |

Wenn du eine Sequenz veränderst, die der Aufrufer übergeben hat, sieht der Aufrufer die Änderung, denn er hält dasselbe Objekt. Wenn du das nicht willst, rufe zuerst `clone` auf, um eine unabhängige Kopie zu bekommen.
