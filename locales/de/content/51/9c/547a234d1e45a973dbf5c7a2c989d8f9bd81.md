# Anleitung

In dieser Übung spielst du mit einem ferngesteuerten Auto herum, für das du endlich genug Geld zusammengespart hast.

Die Autos starten mit vollen (100 %) Batterien. Jedes Mal, wenn du das Auto mit der Fernbedienung fährst, legt es 20 Meter zurück und verbraucht ein Prozent der Batterie.

Das ferngesteuerte Auto hat ein schickes LED-Display, das zwei Informationen anzeigt:

- Die insgesamt gefahrene Strecke, angezeigt als: `"Driven <METERS> meters"`.
- Die verbleibende Batterieladung, angezeigt als: `"Battery at <PERCENTAGE>%"`.

Wenn die Batterie bei 0 % ist, kannst du das Auto nicht mehr fahren und die Batterieanzeige zeigt `"Battery empty"`.

Du hast sechs Aufgaben, die jeweils mit Instanzen des ferngesteuerten Autos arbeiten.

## 1. Kauf ein brandneues ferngesteuertes Auto

Implementiere die (_statische_) Methode `RemoteControlCar.Buy()`, die eine brandneue Instanz des ferngesteuerten Autos zurückgibt:

```csharp
RemoteControlCar car = RemoteControlCar.Buy();
```

## 2. Zeige die gefahrene Strecke an

Implementiere die Methode `RemoteControlCar.DistanceDisplay()`, die die Strecke so zurückgibt, wie sie auf dem LED-Display angezeigt wird:

```csharp
var car = RemoteControlCar.Buy();
car.DistanceDisplay();
// => "Driven 0 meters"
```

## 3. Zeige den Batteriestand in Prozent an

Implementiere die Methode `RemoteControlCar.BatteryDisplay()`, die den Batteriestand so zurückgibt, wie er auf dem LED-Display angezeigt wird:

```csharp
var car = RemoteControlCar.Buy();
car.BatteryDisplay();
// => "Battery at 100%"
```

## 4. Aktualisiere die gefahrene Strecke beim Fahren

Implementiere die Methode `RemoteControlCar.Drive()`, die die Anzahl der gefahrenen Meter aktualisiert:

```csharp
var car = RemoteControlCar.Buy();
car.Drive();
car.Drive();
car.DistanceDisplay();
// => "Driven 40 meters"
```

## 5. Aktualisiere den Batteriestand beim Fahren

Erweitere die Methode `RemoteControlCar.Drive()` so, dass sie den Batteriestand aktualisiert:

```csharp
var car = RemoteControlCar.Buy();
car.Drive();
car.Drive();
car.BatteryDisplay();
// => "Battery at 98%"
```

## 6. Verhindere das Fahren, wenn die Batterie leer ist

Erweitere die Methode `RemoteControlCar.Drive()` so, dass sie weder die gefahrene Strecke erhöht noch den Batteriestand verringert, wenn die Batterie leer ist (bei 0 %):

```csharp
var car = RemoteControlCar.Buy();

// Drain the battery
// ...

car.DistanceDisplay();
// => "Driven 2000 meters"

car.BatteryDisplay();
// => "Battery empty"
```
