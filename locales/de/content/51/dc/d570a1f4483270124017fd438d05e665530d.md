# Einführung

Charlists werden mit dem Sigil `~c` erstellt.

```elixir
~c"hello"
```

~~~~exercism/note
Beachte, dass Charlists in älteren Versionen von Elixir mit einfachen Anführungszeichen als `'hello'` dargestellt werden.
~~~~

Auch wenn sie Strings sehr ähnlich sehen, sind die beiden Datentypen ganz verschieden. Ein Charlist ist eine Liste von Ganzzahlen. Die Ganzzahlen stehen für die Unicode-Werte eines Zeichens, auch Codepunkte genannt.

```elixir
[65, 66, 67]
# => ~c"ABC"
```

Du kannst vor ein Zeichen ein `?` setzen, um seinen Codepunkt zu bekommen.

```elixir
?A
# => 65

[?:, ?)]
# => ~c":)"
```

Da Charlists Listen sind, kannst du mit ihnen genauso arbeiten wie mit jeder anderen Liste, mit Rekursion und Pattern Matching.

```elixir
[first_letter | _] = ~c"cat"
first_letter
# => 99
```

Du kannst zwei Listen mit `++` verketten.

```elixir
~c"hi" ++ ~c"!"
# => ~c"hi!"
```

Je länger die erste Liste ist, desto langsamer läuft das Verketten. Deshalb solltest du es vermeiden, wiederholt an Listen beliebiger Länge anzuhängen.
