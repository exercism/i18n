# Anleitung

Berechne aus einem Alter in Sekunden, wie alt jemand auf einem Planeten in unserem Sonnensystem wäre.

Ein Erdjahr entspricht 365,25 Erdentagen oder 31.557.600 Sekunden.
Wenn dir jemand sagt, jemand sei 1.000.000.000 Sekunden alt, dann wäre diese Person 31,69 Erdjahre alt.

Bei den anderen Planeten musst du ihre Umlaufzeit in Erdjahren berücksichtigen:

| Planet  | Umlaufzeit in Erdjahren |
| ------- | ----------------------------- |
| Merkur | 0,2408467                     |
| Venus   | 0,61519726                    |
| Erde   | 1,0                           |
| Mars    | 1,8808158                     |
| Jupiter | 11,862615                     |
| Saturn  | 29,447498                     |
| Uranus  | 84,016846                     |
| Neptun | 164,79132                     |

~~~~exercism/note
Die tatsächliche Länge eines vollständigen Umlaufs der Erde um die Sonne liegt näher bei 365,256 Tagen (1 siderisches Jahr).
Der gregorianische Kalender hat im Durchschnitt 365,2425 Tage.
Auch wenn das nicht ganz genau ist, wird in dieser Übung der Wert 365,25 verwendet.
Unter [Year auf Wikipedia][year] findest du weitere Möglichkeiten, ein Jahr zu messen.

[year]: https://en.wikipedia.org/wiki/Year#Summary
~~~~
