# Einführung

Kotlins `when` ist ein bedingter Ausdruck, mit dem du zwischen mehreren Möglichkeiten wählst. Er ähnelt `switch` in Java und ist flexibler als eine Kette aus `if` ... `else if` ... `else`.

Wie `if` kannst du `when` auch als Ausdruck verwenden, der einen Wert liefert.

## Einen Wert abgleichen

Gib `when` in runden Klammern den Wert, den du abgleichen willst. Jeder Zweig vergleicht diesen Wert, bis einer passt:

```kotlin
val animal = "chicken"
val type = when (animal) {
    "chicken" -> "bird"
    "poodle" -> "dog"
    else -> "unknown"
}
// type => "bird"
```

- Jeder Zweig wird als `pattern -> result` geschrieben.
- Die Zweige werden von oben nach unten durchprobiert, bis ein Treffer gefunden ist.
  Nur der erste Zweig wird ausgeführt.
- Verwende `else` für jeden Wert, der oben nicht aufgeführt ist (ähnlich dem abschließenden `else` in einer `if`-Kette).

Das ähnelt dem [Pattern Matching][pattern-matching].
Das `pattern` kann ein Wert sein, mit dem du abgleichst, oder du verwendest `is`, um nach Typ abzugleichen:

```kotlin
fun typeText(subject: Any): String {
    return when(subject) {
        is Animal -> "Animal"
        is Fruit -> "Fruit"
        is String -> "Text"
        else -> "Unknown"
    }
}
```

oder du verwendest `in`, um zu prüfen, ob der Wert in einem Bereich, einer Collection, einem String oder irgendetwas anderem mit einer `contains`-Methode enthalten ist:

```kotlin
fun describe(number: Int, position: String) {
    // Range
    when(number) {
        in 1..10 -> println("From 1 to 10")
        in 11..20 -> println("From 11 to 20")
    }

    // Collection
    when(number) {
        in listOf(2, 4, 6) -> println("small even")
        in listOf(3, 5, 7) -> println("small odd")
    }

    // String
    when(position) {
        in "center middle" -> println("inner")
        in "left right boundary" -> println("outer")
    }
}
```

~~~exercism/note
Du kannst `in` auch mit anderen Objekten verwenden, indem du die [Operator-Erweiterungsfunktion][kotlin-operator-overloading] `contains` definierst.
Zum Beispiel mit [Regex][kotlin-regex]:

```kotlin
operator fun Regex.contains(text: CharSequence): Boolean = this.matches(text)

fun replace(input: String) {
    return when(input) {
        in Regex("""ani*""") -> println("animal")
        in Regex("""fru.*""") -> println("fruit")
        in Regex("""num.*""") -> println("number")
        else -> println("unknown")
    }
}
```

## Guard-Bedingungen

Wenn du einen Wert abgleichst, kannst du zusätzliche Bedingungen in einem `if` hinter dem Muster angeben.
Diese Bedingungen heißen Guard-Bedingungen.

```kotlin
val x = 5
val y = 10
val description = when (x) {
    5 if y % 2 == 0 -> "x is 5, y is even"
    else -> "other"
}
// description => "x is 5, y is even"
```

Sogar `else if` lässt sich verwenden.

```kotlin
val x = 7
val y = 10
val description = when (x) {
    5 if y % 2 == 0 -> "x is 5, y is even"
    else if y % 2 == 0 -> "y is an even number"
    else -> "other"
}
// description => "y is an even number"
```


## Bedingungen abgleichen

Alternativ kannst du den Wert weglassen und auf jedem Zweig boolesche Bedingungen angeben:

```kotlin
val x = 5
val y = 8
val description = when {
    x % 2 != 0 -> "x is odd"
    y % 2 == 0 -> "y is even"
    else -> "neither condition matched first"
}
// description => "x is odd"
```

Auch hier werden die Zweige von oben nach unten geprüft, und nur der erste Zweig, dessen Bedingung `true` ist, wird ausgeführt.

## `when` als Ausdruck verwenden

Wenn du `when` wegen seines Ergebnisses verwendest (du weist es einer Variablen zu, gibst es aus einer Funktion zurück und so weiter), musst du jeden möglichen Fall abdecken.

- Wenn du einen Wert abgleichst, füge `else` hinzu, es sei denn, jeder mögliche Wert ist bereits abgedeckt (zum Beispiel alle Werte eines `Boolean` oder eines `enum`).
- Wenn du Bedingungen abgleichst, ist ein `else`-Zweig erforderlich, weil der Compiler nicht wissen kann, dass deine Bedingungen jeden Fall abdecken.

```kotlin
fun label(n: Int): String = when (n) {
    0 -> "zero"
    1 -> "one"
    else -> "other"
}
```
