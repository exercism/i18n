# Anleitung

In dieser Übung implementierst du einige Regeln von [Blackjack][blackjack], zum Beispiel wie das Spiel gespielt und gewertet wird.

**Hinweis**: In dieser Übung steht _`A`_ für Ass, _`J`_ für Bube, _`Q`_ für Dame und _`K`_ für König.
Joker werden aussortiert.
Es wird ein [französisches Standardkartenspiel mit 52 Karten][standard_deck] angenommen, aber in den meisten Varianten werden mehrere Decks zusammen für das Spiel gemischt.

## 1. Berechne den Wert einer Karte

Bei Blackjack entscheidet jeder Spieler selbst, ob ein Ass 1 oder 11 Punkte wert ist (_mehr dazu später_).
Bildkarten (`J`, `Q`, `K`) werden mit 10 Punkten gewertet, und jede andere Karte ist ihren „Pip“-Wert (_ihren Zahlenwert_) wert.

Definiere die Funktion `value_of_card(<card>)` mit dem Parameter `card`.
Die Funktion soll den _numerischen Wert_ des übergebenen Karten-Strings zurückgeben.
Da ein Ass mehrere Werte annehmen kann (1 **oder** 11), soll diese Funktion den Wert einer Ass-Karte vorerst auf 1 festlegen.
Später implementierst du eine Funktion, die den Wert einer Ass-Karte anhand einer bestehenden Hand bestimmt.

```python
>>> value_of_card('K')
10

>>> value_of_card('4')
4

>>> value_of_card('A')
1
```

## 2. Bestimme, welche Karte einen höheren Wert hat

Definiere die Funktion `higher_card(<card_one>, <card_two>)` mit den Parametern `card_one` und `card_two`.
Für die Wertung haben `J`, `Q` und `K` den Wert 10.
Die Funktion soll zurückgeben, welche Karte für die Wertung den höheren Wert hat.
Wenn beide Karten denselben Wert haben, gib beide zurück.
Beide Karten kannst du zurückgeben, indem du ein Komma in der `return`-Anweisung verwendest:

```python
# Using a comma in a return creates a Tuple.  Tuples will be covered in a later exercise.
>>> def returning_two_values(value_one, value_two):
        return value_one, value_two

>>> returning_two_values('K', '3')
('K', '3')
```

Ein Ass kann mehrere Werte annehmen, deshalb legen wir `A`-Karten für diese Aufgabe auf den Wert 1 fest.

```python
>>> higher_card('K', '10')
('K', '10')

>>> higher_card('4', '6')
'6'

>>> higher_card('K', 'A')
'K'
```

## 3. Berechne den Wert eines Asses

Wie bereits erwähnt, kann ein Ass _entweder_ 1 **oder** 11 Punkte wert sein.
Die Spieler versuchen, so nah wie möglich an 21 Punkte heranzukommen, ohne _über_ 21 zu gehen (_sich also zu überkaufen_).

Definiere die Funktion `value_of_ace(<card_one>, <card_two>)` mit den Parametern `card_one` und `card_two`. Das sind zwei Karten, die bereits auf der Hand liegen, _bevor_ eine Ass-Karte dazukommt.
Deine Funktion muss entscheiden, ob das kommende Ass den Wert 1 oder den Wert 11 bekommt, und diesen Wert zurückgeben.
Denk daran: Der Wert der Hand mit dem Ass muss so hoch wie möglich sein, _ohne_ über 21 zu gehen.

**Hinweis**: Wenn bereits ein Ass auf der Hand liegt, dann wäre der Wert für das kommende Ass 1.

```python
>>> value_of_ace('6', 'K')
1

>>> value_of_ace('7', '3')
11
```

## 4. Bestimme eine „Natural“- oder „Blackjack“-Hand

Wenn ein Spieler als erste zwei Karten ein Ass (`A`) und eine Zehnerkarte (10, `K`, `Q` oder `J`) bekommt, dann hat er 21 Punkte.
Das nennt man eine **Blackjack**-Hand.


Definiere die Funktion `is_blackjack(<card_one>, <card_two>)` mit den Parametern `card_one` und `card_two`. Das sind zwei Karten.
Stelle fest, ob die Zwei-Karten-Hand ein **Blackjack** ist, und gib den booleschen Wert `True` zurück, wenn ja, sonst `False`.

**Hinweis**: Die _Berechnung_ des Punktestands kann auf viele Arten erfolgen.
Wenn möglich, möchten wir aber, dass du prüfst, ob ein Ass und eine Zehnerkarte **_auf_** der Hand liegen (_oder an einer bestimmten Position_), statt die Handwerte zu _summieren_.

```python
>>> is_blackjack('A', 'K')
True

>>> is_blackjack('10', '9')
False
```

## 5. Paare aufteilen

Wenn die ersten beiden Karten einer Hand denselben Wert haben (_zum Beispiel zwei Sechsen oder eine `Q` und ein `K`_), kann ein Spieler sie als zwei getrennte Hände behandeln.
Das nennt man „Paare aufteilen“.

Definiere die Funktion `can_split_pairs(<card_one>, <card_two>)` mit den Parametern `card_one` und `card_two`. Das sind zwei Karten.
Stelle fest, ob diese Zwei-Karten-Hand in zwei Paare aufgeteilt werden kann.
Wenn die Hand aufgeteilt werden kann, gib den booleschen Wert `True` zurück, sonst `False`

```python
>>> can_split_pairs('Q', 'K')
True

>>> can_split_pairs('10', 'A')
False
```

## 6. Verdoppeln

Wenn die ursprünglichen zwei ausgeteilten Karten zusammen 9, 10 oder 11 Punkte ergeben, kann ein Spieler einen zusätzlichen Einsatz in Höhe seines ursprünglichen Einsatzes platzieren.
Das nennt man „Verdoppeln“.

Definiere die Funktion `can_double_down(<card_one>, <card_two>)` mit den Parametern `card_one` und `card_two`. Das sind zwei Karten.
Stelle fest, ob die Zwei-Karten-Hand „verdoppelt“ werden kann, und gib den booleschen Wert `True` zurück, wenn ja, sonst `False`.

```python
>>> can_double_down('A', '9')
True

>>> can_double_down('10', '2')
False
```
