# Einführung

Ein `vector` in Clojure ist eine sequenzielle, indizierte, unveränderliche Sammlung von null oder mehr Werten. Das heißt: Sobald ein Vektor erstellt wurde, kann er nicht mehr geändert werden. Funktionen, die auf Vektoren arbeiten, geben einen neuen Vektor zurück, während der ursprüngliche Vektor unverändert bleibt. Die Werte in einem Vektor können unterschiedliche Typen haben. Vektoren kannst du so definieren:

```clojure
(def empty [])
(def single-value 5)
(def single-value-alternative (vector 5))
(def three-values [a b c]
```

Elemente kannst du über einen Index aus einem Vektor abrufen. Clojure-Vektoren sind nullbasiert, das heißt, der Index des ersten Elements ist immer null:

```clojure
(def numbers [2 3 5])
;; Read value from vector
(get numbers 2)
;;=> 5
;; Update value in vector
(assoc numbers 2 9)
;;=> [2 3 9]
```

Der ursprüngliche Vektor bleibt unverändert:

```clojure
numbers
;;=> [2 3 5]
```

Um den aktualisierten Wert zu behalten, musst du ihn weitergeben oder in einer Var festhalten:

```clojure
(def updated-numbers
  (assoc numbers 2 9))
(get updated-numbers 2)
;;=> 9
```
