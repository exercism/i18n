# Ergänzung der Anweisungen

## Implementierung

Definiere eine einzelne Go-Funktion, MakeChain, die ein Slice von Dominosteinen entgegennimmt und versucht, daraus eine gültige Kette von Dominosteinen zu bilden.

MakeChain sollte die folgende Signatur haben:

```go
type Domino [2]int

func MakeChain(input []Domino) (chain []Domino, ok bool)
```

Das boolesche Ergebnis `ok` zeigt an, ob sich die gegebene Eingabeliste von Dominosteinen zu einer gültigen Kette anordnen lässt.
Eine leere Eingabeliste gilt als gültig, und ein einzelner Dominostein, dessen beide Seiten gleich sind, gilt ebenfalls als gültig.

Das Ergebnis 'chain' ist ein Slice aus null oder mehr Dominosteinen, die in einer Reihenfolge angeordnet sind, die die gültige Kette zeigt.
Es ist in Ordnung (und wird erwartet), dass Dominosteine in 'input' gedreht werden müssen, damit jede Seite zu ihrem benachbarten Dominostein in der Kette passt.
Auch die Dominosteine am Anfang und am Ende der Kette müssen mit ihrer Außenseite übereinstimmen.

Lässt sich das gegebene Eingabe-Slice von Dominosteinen nicht zu einer gültigen Kette anordnen,
darf MakeChain für das Ergebnis 'chain' nil zurückgeben, muss aber für das Ergebnis `ok` falsch zurückgeben.

Da es für eine gegebene Eingabeliste mehr als eine gültige Kettenanordnung geben kann, prüft das Testprogramm die Kette nur dann auf Gültigkeit, wenn `ok` wahr ist.
