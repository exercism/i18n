# Ignorieren

## Zusätzliche jq-Kommandozeilenoptionen

Dir werden in den Tests zusätzliche Optionen für `jq` auffallen.

```sh
run jq -s -R -c -f minesweeper.jq << 'END_INPUT'
```

Was bedeuten sie?

- `-s`

  Das ist der „Slurp“-Modus.
  Statt die Eingabe als Strom von JSON-Objekten zu behandeln,
  wird die gesamte Eingabe in ein Array eingelesen.

  ```sh
  $ seq 5 | jq -c '.'
  1
  2
  3
  4
  5
  $ seq 5 | jq -s -c '.'
  [1,2,3,4,5]
  ```

- `-R`

  Vielleicht kennst du `-r` schon, um „rohe“ Strings auszugeben (ohne Anführungszeichen).
  Dies ist das Gegenteil.
  Jede Eingabezeile wird als String behandelt.

  Zwei Beispiele:

  ```sh
  $ seq 5 | jq -R -c .
  "1"
  "2"
  "3"
  "4"
  "5"

  $ echo 42 | jq '. * 2'      # input is a JSON number
  84
  $ echo 42 | jq -R '. * 2'   # input is a JSON string
  "4242"
  ```

Wenn du diese beiden Optionen kombinierst, erhältst du _nicht_ ein Array von Strings:
Du erhältst die gesamte Eingabe als einen einzigen String, einschließlich der Zeilenumbrüche am Zeilenende.

```sh
$ seq 5 | jq -s -R -c .
"1\n2\n3\n4\n5\n"
```

Der Umgang damit ist Teil der Herausforderung dieser Übung.
