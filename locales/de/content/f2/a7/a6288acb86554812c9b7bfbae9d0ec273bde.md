# Einführung

Wenn die Anzahl der Iterationen einer Schleife nicht im Voraus bekannt ist, also „immer weiterlaufen, bis ein Prädikat nicht mehr wahr ist", verwendet Factor den `while`-Kombinator aus [`kernel`][kernel]:

```
while ( pred body -- )
```

Sowohl `pred` als auch `body` sind Quotations, die mit dem Datenstack arbeiten. `while` ruft `pred` auf. Hinterlässt sie oben einen Wert, der als wahr gilt, führt `while` `body` aus und wiederholt das. Andernfalls stoppt sie. Der Zustand, der von einer Iteration zur nächsten fließt, liegt zwischen den Aufrufen auf dem Stack (oder in benannten lokalen Variablen, wenn es mehr als einen Zustandswert gibt).

```factor
USING: kernel math ;

5 [ dup 0 > ] [ dup . 1 - ] while drop
! prints 5 4 3 2 1
```

`until` ist die symmetrische Form: Sie läuft weiter, *bis* das Prädikat wahr wird.

[kernel]: https://docs.factorcode.org/content/vocab-kernel.html
