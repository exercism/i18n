# Einführung

Ein algebraischer Datentyp (ADT) stellt eine feste Anzahl benannter Fälle dar.
Jeder Wert eines ADT entspricht genau einem der benannten Fälle.

Ein ADT wird mit dem Schlüsselwort `data` definiert, wobei die Fälle durch Pipe-Zeichen (`|`) getrennt werden.
Wenn keinem der Fälle Daten zugeordnet sind, ähnelt der ADT dem, was andere Sprachen üblicherweise als _Enumeration_ (oder _Enum_) bezeichnen.

```haskell
data Season
  = Spring
  | Summer
  | Autumn
  | Winter
```

Jedem Fall eines ADT können optional Daten zugeordnet werden, und verschiedene Fälle können unterschiedliche Datentypen haben.
Wenn dem Fall Daten zugeordnet sind, ist ein Konstruktor erforderlich.

```haskell
data Number
  = NInt Int      --'NInt' is the constructor for an Int Number.
  | NFloat Float  --'NFloat' is the constructor for an Float Number.
  | Invalid       --'Invalid' does not have data associated to it.
```

Einen Wert für einen bestimmten Fall erzeugst du, indem du seinen Namen angibst (z. B. `NInt 22`).
Da Fallnamen einfach Konstruktorfunktionen sind, kannst du die zugehörigen Daten wie ein normales Funktionsargument übergeben.

ADTs haben _strukturelle Gleichheit_. Das bedeutet, dass zwei Werte für denselben Fall mit denselben (optionalen) Daten gleichwertig sind.

Du kannst zwar `if/else`-Ausdrücke verwenden, um mit ADTs zu arbeiten, der empfohlene Weg ist jedoch der Musterabgleich mit einer _case_-Anweisung:

```haskell
add1 :: Number -> String
add1 number =
    case number of
      NInt    i -> show (i + 1)
      NFloat  f -> show (f + 1.0)
      Invalid   -> error "Invalid input"
```
