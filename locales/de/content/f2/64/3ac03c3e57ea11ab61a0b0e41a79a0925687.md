# Einführung

Casting und Typkonvertierung sind zwei verschiedene Arten, einen Ausdruck von einem Datentyp in einen anderen umzuwandeln.

Ein Ausdruck kann mit dem Cast-Operator `(<type>)` in einen anderen Typ umgewandelt werden.

```csharp
long l = 1000L;
int i = (int)l;

object o = new Random();
Random r = (Random)o;
```

Sind die Typen nicht kompatibel, wird eine Instanz von `InvalidCastException` ausgelöst. Bei Zahlen bedeutet das, dass der Zieltyp den umgewandelten Wert nicht darstellen kann. Bei Klassen muss einer der Typen vom anderen abgeleitet sein (für Structs gilt das trivialerweise ebenfalls).

Eine Alternative zum _Casting_ ist die _Typkonvertierung_ mit dem `is`-Operator. Sie wird typischerweise auf Referenz- und Nullable-Typen angewendet.

```csharp
object o = new Random();
if (o is Random rand)
{
    int ii = rand.Next();
    // now, do something random
}
```

Wenn du den genauen Typ eines Objekts ermitteln musst, ist `is` vielleicht etwas zu großzügig, denn es gibt wahr zurück für eine Klasse und für alle Klassen und Interfaces, von denen sie direkt oder indirekt abgeleitet ist. `typeof` und `Object.GetType()` sind in diesem Fall die Lösung.

```csharp
object o = new List<int>();

o is ICollection<int> // true
o.GetType() == typeof(ICollection<int>) // false
o is List<int> // true
o.GetType() == typeof(List<int>) // true
```
