# Über

Bedingte Anweisungen funktionieren in C++ ähnlich wie in anderen Sprachen.
Der zugrunde liegende Typ jeder bedingten Operation ist der Typ `bool`, der den Wert `true` oder `false` haben kann.
Bedingte Anweisungen werden oft zur Ablaufsteuerung verwendet, um verschiedene Bedingungen zu prüfen.

Eine `if`-Anweisung führt ihren Code aus, wenn die zugrunde liegende Bedingung `true` ist, und zwar so:

```cpp
std::string value{"val"};

if (value == "val") {
    return "was val";
}
```

Wenn mehr als ein Fall abgedeckt werden muss, kannst du mehrere `if`-Anweisungen mit `else if`- und `else`-Anweisungen verketten.

```cpp
int number{33};

if (number > 0) {
   return "positive";
} else if (number < 0) {
    return "negative";
} else {
   return "zero";
}
```

Seit C++17 können `if`-Anweisungen auch eine kurze Initialisierungsanweisung enthalten, mit der du eine oder mehrere Variablen für die `if`-Anweisung initialisieren kannst.
Zum Beispiel:

```cpp
int num{7};
if (int v{2 * num}; v > 10) {
    return v;
} else {
    return num;
}
// => 14
```

> Hinweis: Auf Variablen, die in der Initialisierung angelegt werden, kannst du nach dem Ende der `if`-Anweisung nicht mehr zugreifen.
