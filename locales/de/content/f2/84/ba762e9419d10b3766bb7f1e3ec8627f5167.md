# Number statt parse bevorzugen

Die `parseXXX`-Familie ist _großartig_ dafür geeignet, eine Eingabe in eine Zahl umzuwandeln, wenn du nicht weißt, ob die Eingabe eine Zahl ist. Wenn du es aber weißt, ist es besser, die strengere Funktion [`Number(...)`](https://developer.mozilla.org/en-US/docs/Web/JavaScript/Reference/Global_Objects/Number#Convert_numeric_strings_and_null_to_numbers ) zu verwenden.
