# Einführung

In dieser Übung geht es darum, Logik abhängig von Bedingungen auszuführen. Am häufigsten machst du das in C# mit einer `if/else`-Anweisung:

```csharp
int x = 6;

if (x == 5)
{
    // Execute logic if x equals 5
}
else if (x > 7)
{
    // Execute logic if x greater than 7
}
else
{
    // Execute logic in all other cases
}
```

Die Bedingung einer `if`-Anweisung muss vom Typ `bool` sein. C# kennt kein Konzept von _truthy_-Werten.
