# Einführung

Mit einer Funktion kannst du Code zu einer wiederverwendbaren Einheit zusammenfassen.
Sie besteht aus dem Schlüsselwort `func`, dem Namen der Funktion und einer durch Kommas getrennten Liste von null oder mehr Parametern und Typen in runden Klammern.

## Funktionsparameter

Alle Parameter müssen explizit typisiert sein; für Parameter gibt es keine Typinferenz.
Für Parameter gibt es keine Standardwerte, daher sind alle Funktionsparameter erforderlich.

```go
import "fmt"

// No parameters
func PrintHello() {
    fmt.Println("Hello")
}

// One parameter
func PrintHelloName(name string) {
  fmt.Println("Hello " + name)
}
```

Parameter desselben Typs können gemeinsam deklariert werden, gefolgt von einer einzigen Typdeklaration.

```go
import "fmt"

func PrintGreetingName(greeting, name string) {
  fmt.Println(greeting + " " + name)
}
```

## Parameter und Argumente

Schauen wir uns kurz zwei Begriffe an, die oft verwechselt werden: `parameters` und `arguments`.
Funktionsparameter sind die Namen, die in der Signatur der Funktion definiert werden, wie `greeting` und `name` in der Funktion `PrintGreetingName` oben.
Funktionsargumente sind die konkreten Werte, die beim Aufruf der Funktion an die Funktionsparameter übergeben werden.
Im folgenden Beispiel sind `"Hello"` und `"Katrina"` die Argumente, die an die Parameter `greeting` und `name` übergeben werden:

```go
PrintGreetingName("Hello", "Katrina")
```

## Rückgabewerte

Auf die Funktionsparameter folgen null oder mehr Rückgabewerte, die ebenfalls explizit typisiert sein müssen.
Einzelne Rückgabewerte stehen ohne Klammern, mehrere Rückgabewerte werden in runde Klammern gesetzt.
Werte werden mit dem Schlüsselwort `return` von Funktionen an den aufrufenden Code zurückgegeben.
Eine Funktion kann mehrere `return`-Anweisungen enthalten.
Die Ausführung der Funktion endet, sobald sie auf eine dieser `return`-Anweisungen trifft.
Wenn mehrere Werte von einer Funktion zurückgegeben werden sollen, werden sie durch Kommas getrennt.

```go
func Hello(name string) string {
  return "Hello " + name
}

func HelloAndGoodbye(name string) (string, string) {
  return "Hello " + name, "Goodbye " + name
}
```

## Funktionen aufrufen

Du rufst eine Funktion auf, indem du den Funktionsnamen angibst und für jeden Parameter der Funktion ein Argument in runden Klammern übergibst.

```go
import "fmt"

// No parameters, no return value
func PrintHello() {
    fmt.Println("Hello")
}
// Called like this:
PrintHello()

// One parameter, one return value
func Hello(name string) string {
  return "Hello " + name
}
// Called like this:
greeting := Hello("Dave")

// Multiple parameters, multiple return values
func SumAndMultiply(a, b int) (int, int) {
    return a+b, a*b
}
// Called like this:
aplusb, atimesb := SumAndMultiply(a, b)
```

## Benannte Rückgabewerte und nackte Rückgabe

Neben Parametern können auch Rückgabewerte optional benannt werden.
Wenn benannte Rückgabewerte verwendet werden, gibt eine `return`-Anweisung ohne Argumente diese Werte zurück.
Das nennt man eine „nackte“ Rückgabe.

```go
func SumAndMultiplyThenMinus(a, b, c int) (sum, mult int) {
    sum, mult = a+b, a*b
    sum -= c
    mult -= c
    return
}
```
