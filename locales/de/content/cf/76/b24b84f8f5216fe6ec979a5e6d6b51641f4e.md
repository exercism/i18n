# Installation

## Anforderungen des PowerShell-Tracks

Der PowerShell-Track von Exercism setzt voraus, dass auf deinem System Folgendes installiert ist:

- PowerShell oder Windows PowerShell Core
- das Modul für das Pester-Test- und Mock-Framework ist installiert

(PS: Der Support für PowerShell beschränkt sich auf kritische Fehlerbehebungen. PowerShell Core wird kontinuierlich gepflegt und bietet eine bessere plattformübergreifende Unterstützung.)

### PowerShell installieren

Ab Windows 7 SP1 ist PowerShell auf allen Windows-Betriebssystemen vorinstalliert.

Die neueste Version von PowerShell und Installationsanleitungen für alle Plattformen (Linux, macOS und Windows) findest du [hier][installation].

Der Quellcode und eine manuelle Installation für [PowerShell][source-code] sind ebenfalls verfügbar.

### Das Pester-Framework installieren und aktualisieren

[Pester][pester] ist das Test-Framework für PowerShell.
Seit Version 4.0.9 ist es mit PowerShell Core unter Windows, Linux und macOS kompatibel (mit einigen Einschränkungen).

Unter Windows 10 ist es vorinstalliert. Es wird jedoch empfohlen, es mit dem folgenden PowerShell-Befehl zu aktualisieren:

```PowerShell
Install-Module -Name Pester -Force -SkipPublisherCheck
```

Für spätere Aktualisierungen führst du Folgendes aus:

```PowerShell
Update-Module -Name Pester
```

Falls nötig, findest du weitere Installationsanleitungen unter: [https://github.com/pester/Pester/wiki/Installation-and-Update]()

## Eine IDE verwenden

Wenn du eine komfortablere Bearbeitungsumgebung möchtest, ist eine IDE wahrscheinlich genau das Richtige für dich.
Das sind die beliebtesten IDEs, die das Erstellen von PowerShell-Projekten unterstützen:

### Alle Plattformen

- [PowerShell ISE (Integrated Scripting Environment)][ise], die integrierte grafische IDE, die mit PowerShell geliefert wird (nur Windows).
  Um PowerShell ISE zu starten, gib `powershell_ise.exe` in einer PowerShell-Konsole ein.
- [Visual Studio Code][vsc] mit der [PowerShell-Erweiterung][vsc-extension].
  Mit Visual Studio Code kannst du außerdem die Tests ausführen und deinen Code debuggen.
- [Sublime Text 3][sublime] mit dem [PowerShell-Paket][sublime-package].
