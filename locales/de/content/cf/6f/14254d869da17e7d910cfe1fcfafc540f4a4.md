# Einführung

Ein zentrales Ziel von Julia ist es, Berechnungen mit numerischen Daten schnell und effizient durchführen zu können.
_Sehr viele_ numerische Daten.

Typischerweise werden die Daten in Arrays (oder einem verwandten Typ) gespeichert, man kann also mit Fug und Recht sagen, dass Arrays das Herz der Sprache Julia bilden.

Arrays können beliebig groß sein (nur begrenzt durch den Speicher deiner Hardware) und beliebig viele Dimensionen haben.

Dieses einführende Konzept konzentriert sich auf die Grundlagen eindimensionaler Arrays, die Vektoren genannt werden.

## Vektoren erstellen

In Julia ist ein Vektor eine geordnete Folge von Werten, auf die man über eine Indexnummer zugreifen kann.

Der einfachste Weg, einen Vektor zu erstellen, ist, die Werte in eckige Klammern zu schreiben:

```julia-repl
julia> num_vec = [1, 4, 9]
3-element Vector{Int64}:
 1
 4
 9

julia> str_vec = ["arrays", "are", "important"]
3-element Vector{String}:
 "arrays"
 "are"
 "important"
```

Der Vektor-Typ entspricht dem Typ jedes einzelnen Elements.

_Brauchen Vektoren also homogen zu sein (alle Elemente vom selben Typ)?_

Auf einer gewissen Ebene ja – und es ist empfehlenswert, das anzustreben, wenn du die beste Performance willst.
Julia kann diese Einschränkung jedoch (wenn nötig) umgehen, indem es den Typ `Any` verwendet:

```julia-repl
julia> mixed_vector = [1, "str", 'c']
3-element Vector{Any}:
 1
  "str"
  'c': ASCII/Unicode U+0063 (category Ll: Letter, lowercase)
```

Wenn du einen leeren Vektor erstellst, verwendet Julia standardmäßig den Elementtyp `Any`, aber du kannst ihn genauer festlegen, indem du das leere Array mit dem gewünschten Elementtyp annotierst.

```julia-repl
julia> empty_vec = []
Any[]

julia> empty_int_vec = Int64[]
Int64[]
```

# Indizierung

Bitte lies und merke dir diese Regel:

- ***Standardmäßig beginnt die Indizierung in Julia bei 1, nicht bei 0***.

Das ist für alle vertraut, die andere Data-Science-Sprachen verwendet haben (R, Matlab, Fortran ...), mag aber für Informatiker mit einem Hintergrund in C-ähnlichen Sprachen schockierend erscheinen.

Ansonsten funktionieren Indizes so, wie du vermutest: Du schreibst sie einfach in eckige Klammern:

```julia
squares = [0, 1, 4, 9, 16]
squares[1]  # 0
squares[3]  # 4
squares[begin]  # 0 ("begin" is synonym for 1)
squares[end]  # 16 ("end" is synonym for length(squares))
```

Beachte, wie praktisch die Indizierung mit `end` (sehr nützlich) und `begin` (wohl eher nicht) ist.

Python-Programmierer fragen sich vielleicht, was es mit negativen Indizes auf sich hat.
Vergiss es: Die gibt es in Julia nicht, und sie lösen einen `BoundsError` aus. Dasselbe gilt für jeden Index kleiner als 1 oder größer als `length(squares)`.

## Vektoroperationen

Vektoren in Julia sind _veränderbar_: Wir können den Inhalt einzelner Zellen ändern.

```julia-repl
julia> vals = [1, 3, 5, 7]
4-element Vector{Int64}:
 1
 3
 5
 7

julia> vals[2] = 4  # reassign the value of this element
4

# Only the value at position 2 changes:
julia> vals
4-element Vector{Int64}:
 1
 4
 5
 7
```

Es gibt viele Funktionen zum Bearbeiten von Vektoren, auch wenn die Julia-Dokumentation sie allgemeiner auf „Collections“ statt auf Vektoren bezieht.

Beachte, dass Funktionen, die ihre Eingabe verändern, per Konvention ein `!` im Namen haben.
Der Compiler erzwingt das nicht, aber es ist eine sehr _starke_ Konvention in der Julia-Welt.

Hier sind einige der nützlichen Funktionen:

- Um Werte ans Ende des Vektors anzuhängen, verwende `push!()`.
- Um den letzten Wert zu entfernen, verwende `pop!()`.
- Um am Anfang des Vektors zu arbeiten, sind die entsprechenden Funktionen `pushfirst!()` und `popfirst!()`.
- Um an einer beliebigen Position ein Element einzufügen oder zu entfernen, gibt es `insert!()` und `deleteat!()`.

```julia-repl
julia> vals = [1, 3]
2-element Vector{Int64}:
 1
 3

julia> push!(vals, 5, 6)  # can add multiple values
4-element Vector{Int64}:
 1
 3
 5
 6

julia> pop!(vals)  # mutates vals, return popped value
6

julia> vals
3-element Vector{Int64}:
 1
 3
 5
```
