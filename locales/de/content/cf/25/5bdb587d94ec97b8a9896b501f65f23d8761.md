# String-Methoden

`String` hat mehrere Methoden, mit denen du Strings bearbeiten kannst.
Diese Methoden rufst du auf dem String selbst auf und verkettest sie oft, um mehrere Operationen auf einem String auszuführen.

Das Folgende ist eine Liste einiger der häufigsten Methoden.
Eine vollständige Liste der Methoden findest du in der [`String`-API-Dokumentation][string-api].

## String#upcase & String#downcase

Die Methode [`upcase`][upcase] gibt einen neuen String zurück, bei dem alle Zeichen in Großbuchstaben umgewandelt wurden.

```crystal
"hello".upcase
# => "HELLO"
```

Die Methode [`downcase`][downcase] gibt einen neuen String zurück, in dem alle Zeichen in Kleinbuchstaben umgewandelt wurden.

```crystal
"HELLO".downcase
# => "hello"
```

## String#capitalize & String#camelcase & String#underscore & String#titleize

Mehrere Methoden können speziellere Umwandlungen der Groß- und Kleinschreibung vornehmen.
Das kann nützlich sein, wenn du einen String in ein bestimmtes Format umwandeln willst.
Hier ist eine Liste einiger der häufigsten Methoden:

| Methode                           | Beschreibung                                                                                                       | Beispiel                                             |
| --------------------------------- | ------------------------------------------------------------------------------------------------------------------ | ---------------------------------------------------- |
| [`String#capitalize`][capitalize] | Wandelt den ersten Buchstaben in einen Großbuchstaben um und den Rest in Kleinbuchstaben                           | `"hEllO" # => "Hello"`                               |
| [`String#camelcase`][camel-case]  | Wandelt Unterstriche in CamelCase um                                                                               | `"eiffel_tower" # => "EiffelTower"`                  |
| `String#camelcase(lower: true)`   | Wie String#camelcase, lässt aber das erste Zeichen kleingeschrieben                                                | `"empire_state_building" # => "empireStateBuilding"` |
| [`String#underscore`][underscore] | Wandelt alle Zeichen in Kleinbuchstaben um und setzt einen Unterstrich zwischen einen Kleinbuchstaben und einen Großbuchstaben | `"PartyInTheUSA" # => "party_in_the_usa"`            |
| [`String#titleize`][titleize]     | Schreibt den ersten Buchstaben jedes Wortes groß und den Rest klein                                                | `"the great gatsBY" # => "The Great Gatsby"`         |

## String#sub & String#gsub

Crystal hat Methoden zum Ersetzen von Teilen eines Strings.
Sie heißen [`sub`][sub] (_Substitution_) und [`gsub`][gsub] (_globale Substitution_).

Diese Methoden können einen String, ein Char oder einen Regex als erstes Argument und einen String oder ein Char als zweites Argument annehmen.
Das erste Argument ist der Teil des Strings, der ersetzt wird, und das zweite Argument ist der Ersatz.
`Char` und Regex werden in späteren Konzepten erklärt.

Die Methode `sub` ersetzt das erste Vorkommen des ersten Arguments durch das zweite Argument.

```crystal
"hello".sub("l", "r")
# => "herlo"
```

Die Methode `gsub` funktioniert wie `sub`, ersetzt aber alle Vorkommen des ersten Arguments durch das zweite Argument.

```crystal
"hello".gsub("l", "r")
# => "herro"
```

## String#chomp & String#strip

Mit Chomp und Strip kannst du unerwünschte Zeichen aus einem String entfernen.

Die Methode [`chomp`][chomp] entfernt standardmäßig die letzten Zeichen `\r`, `\n` oder `\r\n` aus einem String.
Wenn du die Methode mit einem Argument aufrufst, entfernt sie den angegebenen Wert vom Ende des Strings, sofern er dort vorkommt.

```crystal
"hello\n".chomp
# => "hello"

"hello".chomp("llo")
# => "he"
```

Standardmäßig entfernt die Methode [`strip`][strip] alle Leerzeichen am Anfang und Ende eines Strings.
Wenn du die Methode mit einem Argument aufrufst, entfernt sie dieses Argument vom Anfang und Ende des Strings, sofern es dort vorkommt.

```crystal
" hello ".strip
# => "hello"
```

## String#reverse

Mit der Methode [`reverse`][reverse] kannst du einen String umkehren.
Diese Methode gibt einen neuen String mit den Zeichen in umgekehrter Reihenfolge zurück.

```crystal
"hello".reverse
# => "olleh"
```

## String#index

Mit der Methode [`index`][index] kannst du den Index eines Zeichens in einem String finden.
Die Methode `index` nimmt einen `String`, ein `Char` oder einen Regex als Argument.
Sie kann ein optionales zweites Argument annehmen, das angibt, ab welchem Index gesucht wird.
Die Methode `index` gibt den Index des ersten Vorkommens des Arguments zurück.

```crystal
"hello".index("l")
# => 2

"hello".index("l", 3)
# => 3
```

## String#delete_at

Mit der Methode [`delete_at`][delete_at] kannst du ein Zeichen aus einem String entfernen.
Die Methode `delete_at` nimmt einen Index als Argument und entfernt das Zeichen an diesem Index.

```crystal
"hello".delete_at(0)
# => "ello"

"hello".delete_at(3)
# => "helo"
```

## String#insert

Mit der Methode [`insert`][insert] kannst du einen String an einer bestimmten Position einfügen.
Die Methode `insert` nimmt einen Index als erstes Argument und einen String als zweites Argument.
Die Methode `insert` gibt einen neuen String zurück, in den das zweite Argument an diesem Index eingefügt wurde.

```crystal
"hello".insert(0, "h")
# => "hhello"

"hello".insert(3, "l")
# => "helllo"
```
