# Einführung

Viele Programme brauchen (pseudo-)zufällige Werte, um Ereignisse aus der realen Welt zu simulieren.

Häufige, bekannte Beispiele sind:

- Ein Münzwurf: ein zufälliger Wert aus ('H', 'T').
- Der Wurf eines Würfels: eine zufällige Ganzzahl von 1 bis 6.
- Das Mischen eines Kartendecks: eine zufällige Reihenfolge einer Kartenliste.
- Das Erzeugen von Bäumen und Sträuchern in einer 3D-Grafiksimulation.

Wirklich zufällige Werte mit einem Computer zu erzeugen, ist eine [erstaunlich schwierige technische Herausforderung][why-randomness-is-hard]. Deshalb gibt es auch „pseudozufällige“ Generatoren.

## Zufallszahlen erzeugen

In JavaScript kannst du pseudozufällige Zahlen mit der Funktion [`Math.random()`][Math.random] erzeugen.
Sie gibt eine pseudozufällige Gleitkommazahl zwischen 0 (einschließlich) und 1 (ausschließlich) zurück.

[why-randomness-is-hard]: https://www.malwarebytes.com/blog/news/2013/09/in-computers-are-random-numbers-really-random
