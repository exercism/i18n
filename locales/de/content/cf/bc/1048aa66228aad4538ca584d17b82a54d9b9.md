# Anweisungen

Du erstellst ein einfaches Online-Spiel, bei dem ein Freund eine geheime Zahl erraten kann. Du möchtest etwas Feedback geben, aber die Antwort nicht schon mit einer Vermutung verraten. Du brauchst eine Funktion, die je nachdem, wie die Vermutung zur geheimen Zahl steht, unterschiedliche Antworten liefert.

| Bedingung                                                      | Antwort        |
| -------------------------------------------------------------- | -------------- |
| Wenn die Vermutung mit der geheimen Zahl übereinstimmt         | "Correct"      |
| Wenn die Vermutung um eins größer oder eins kleiner als die geheime Zahl ist | "So close"     |
| Wenn die Vermutung größer als die geheime Zahl ist             | "Too high"     |
| Wenn die Vermutung kleiner als die geheime Zahl ist            | "Too low"      |
| Wenn keine Vermutung abgegeben wird                            | "Make a guess" |

Alle Vermutungen und geheimen Zahlen sind Ganzzahlen.

## 1. Erzeuge die Antwort, wenn die Vermutung mit der geheimen Zahl übereinstimmt

Implementiere die Funktion `compare/2`, die zwei Argumente entgegennimmt, `secret_number` und `guess`, die beide Ganzzahlen sind.

```elixir
GuessingGame.compare(5, 5)
# => "Correct"
```

## 2. Erzeuge die Antwort, wenn die Vermutung größer als die geheime Zahl ist

Passe die Funktion `compare` an, damit sie auf Vermutungen reagiert, die größer als die geheime Zahl sind.

```elixir
GuessingGame.compare(5, 8)
# => "Too high"
```

## 3. Erzeuge die Antwort, wenn die Vermutung kleiner als die geheime Zahl ist

Passe die Funktion `compare` an, damit sie auf Vermutungen reagiert, die kleiner als die geheime Zahl sind.

```elixir
GuessingGame.compare(5, 2)
# => "Too low"
```

## 4. Erzeuge die Antworten, wenn die Vermutung um eins größer oder eins kleiner als die geheime Zahl ist

Passe die Funktion `compare` an, damit sie auf Vermutungen reagiert, die nahe an der geheimen Zahl liegen.

```elixir
GuessingGame.compare(5, 6)
# => "So close"
GuessingGame.compare(5, 4)
# => "So close"
```

## 5. Erzeuge die Antwort, wenn es keine Vermutung gibt

Passe die Funktion `compare` an, damit sie reagiert, wenn keine Vermutung abgegeben wird.

```elixir
GuessingGame.compare(5)
# => "Make a guess"

GuessingGame.compare(5, :no_guess)
# => "Make a guess"
```
