# Einführung

## Funktionen mit mehreren Klauseln

Elixir unterstützt Praktiken des **Open-Closed Principle**, indem Funktionen mehrere Klauseln haben dürfen. Statt ausufernder, fest verdrahteter Steuerlogik kannst du so gezielte Funktionen schreiben, denen sich Verhalten leicht hinzufügen oder entfernen lässt.

Elixir bietet _mehrere Funktionsklauseln_ und _Guards_, um Folgendes zu schreiben:

```elixir
def number(n) when n == 7 do
  "Awesome, that's my favorite"
end

def number(_n) do
  "That's not my favorite"
end
```

Zur Laufzeit prüft Elixir von oben nach unten in der Quelldatei, welche Funktionsklausel aufgerufen wird.

Variablen, die nicht verwendet werden, sollten mit einem Unterstrich beginnen.

## Guards

Mit Guards verhinderst du, dass Elixir eine Funktion aufruft, wenn die Auswertung der Argumente durch die Guard-Funktionen fehlschlägt. Guards beginnen mit dem Schlüsselwort `when`, gefolgt von einem booleschen Ausdruck. Guard-Funktionen sind spezielle Funktionen, die:

- pur sein müssen und keine globalen Zustände verändern dürfen.
- ausschließlich `true` oder `false` zurückgeben müssen.

Eine Liste der gängigen Guards findest du in der [Elixir-Dokumentation][kernel-guards]. Sie umfasst Typprüfungen, einfache Arithmetik, Vergleiche und strikt boolesche Operatoren.

## Standardargumente

Funktionen können für ein oder mehrere Argumente Standardwerte angeben. Schauen wir uns diese Funktion an:

```elixir
def number(n \\ 13), do: "That's not my favorite"
```

Beim Kompilieren erzeugt Elixir eine Funktionsdefinition für `number/0` (keine Argumente) und `number/1` (ein Argument).

Haben mehr als ein Argument einen Standardwert, werden die Standardwerte von links nach rechts angewendet, um fehlende Argumente zu füllen.

Hat die Funktion mehr als eine Klausel, sollten die Standardargumente in einem Funktionskopf (einer Funktion ohne Rumpf) vor den Funktionsklauseln definiert werden:

```elixir
def number(n \\ 13)
def number(n) when n < 10, do: "Dream bigger!"
def number(n) when n > 100, do: "Not that big..."
```
