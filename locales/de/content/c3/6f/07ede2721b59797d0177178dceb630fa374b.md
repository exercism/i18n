# Installation

## Die Clojure-Kommandozeile installieren

Clojure bietet Kommandozeilen-Tools, mit denen du eine Clojure-REPL starten, Clojure- und Java-Bibliotheken nutzen und Clojure-Programme starten kannst.

Wenn du Java installieren musst, empfehlen wir [Adoptium Temurin 17](https://adoptium.net/).

### Linux

Stelle sicher, dass die folgenden Abhängigkeiten installiert sind: `bash`, `curl`, `rlwrap` und `Java`. 
Du kannst Clojure auf eine dieser 2 Arten installieren:

1. LinuxBrew: erfordert [Homebrew](https://brew.sh/)

```bash
brew install clojure/tools/clojure
```

2. Installationsskript

```bash
curl -O https://download.clojure.org/install/linux-install-1.11.1.1347.sh
chmod +x linux-install-1.11.1.1347.sh
sudo ./linux-install-1.11.1.1347.sh
```

### Homebrew für Mac OS X

Installiere die Kommandozeilen-Tools mit brew aus dem Tap [clojure/tools](https://github.com/clojure/homebrew-tools):

```bash
brew install clojure/tools/clojure
```

#### Java

Jede Java-Distribution funktioniert. Bei Bedarf kannst du Temurin mit brew installieren:

```bash
brew tap homebrew/cask-versions
brew install --cask temurin17
```

### Windows

Clojure unter Windows hat sich in letzter Zeit deutlich verbessert. Früher haben wir WSL2 empfohlen, was hervorragend funktioniert, aber inzwischen gibt es einen PowerShell-Installer. Clojure unter Windows ist derzeit noch im Alpha-Stadium, bekannte Probleme findest du unter [clj-on-windows](https://github.com/clojure/tools.deps.alpha/wiki/clj-on-Windows#known-issues).

Stelle sicher, dass Java installiert und die Umgebungsvariable `JAVA_HOME` gesetzt ist, und führe Folgendes aus:

```powershell
iwr -useb download.clojure.org/install/win-install-1.11.1.1165.ps1 | iex
```

Eine weitere Möglichkeit, Clojure unter Windows zu installieren, ist der Paketmanager [Scoop](https://scoop.sh/). Um Scoop zu installieren, öffne PowerShell und führe diese 2 Befehle nacheinander aus:

 ```sh
 iwr -useb get.scoop.sh | iex
Set-ExecutionPolicy RemoteSigned -Scope CurrentUser -Force
```

Um Clojure mit Scoop zu installieren, musst du zuerst zwei wichtige Buckets hinzufügen:

```sh
# if you don't have git version control system installed
# it is required for adding new external buckets to your scoop installer
# you can skip this step otherwise
scoop install git

# add scoop bucket for Java 
scoop bucket add java

# add scoop bucket for clojure build
scoop bucket add scoop-clojure https://github.com/littleli/scoop-clojure
```

Jetzt können wir Java und Clojure installieren, indem wir die folgenden Befehle ausführen:

```sh
# install Java runtime and compiler
scoop install adoptopenjdk-lts-hotspot

# install official clojure tools
scoop install clojure

# update to the newest version
scoop update clojure
```

Nachdem du die obigen Schritte erfolgreich ausgeführt hast, solltest du Clojure so starten können:

```sh
clj
```

## Leiningen installieren (optional)

Auch wenn es nicht mehr nötig ist, unterstützen wir weiterhin das voll ausgestattete Projektmanagement-Tool [Leiningen](https://leiningen.org/). Es bietet eine Vielzahl hilfreicher Aufgaben wie bequemes Testen, Builds und eine verbesserte REPL.

1. Lade das [lein-Skript](https://raw.githubusercontent.com/technomancy/leiningen/stable/bin/lein) oder [lein.bat](https://raw.githubusercontent.com/technomancy/leiningen/stable/bin/lein.bat) herunter (Windows)
2. Lege es in deinem `$PATH` ab, wo deine Shell es findet (z. B. `/usr/local/bin/`)
3. Mache es ausführbar (`sudo chmod a+x /usr/local/bin/lein`)
4. Führe `lein` aus.
