# Tests

## Die Tests ausführen

1. Lade eine Übung herunter:

    ```bash
    $ exercism download -track=kotlin --exercise=hello-world
    ```

2. Wechsle in das Verzeichnis der Übung:

    ```bash
    $ cd <path_to_exercise_directory>
    ```

3. Führe die Tests aus:

    ```bash
    $ ./gradlew test
    ```

Bei den meisten Übungen wird standardmäßig nur der erste Test ausgeführt.  
Die anderen Tests sind mit `@Ignore` annotiert, damit sie übersprungen werden.  
Wenn du einen Test gelöst hast, entferne das `@Ignore` beim nächsten, um weiterzukommen.

Das ist übliche Praxis in der testgetriebenen Entwicklung (kurz TDD).  
Damit stellst du sicher, dass du immer nur an einem Problem gleichzeitig arbeitest.
