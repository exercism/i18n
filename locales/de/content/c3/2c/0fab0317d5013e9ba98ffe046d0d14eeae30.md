# Einführung

Der `char`-Typ in F# ist ein 16-Bit-Wert, der die kleinsten adressierbaren Bestandteile eines Textes darstellt und standardmäßig unveränderlich ist.

`char`s können als Literale mit einfachen Anführungszeichen definiert werden:

```fsharp
let ch = 'A'
// => val ch: char = 'A'
```

Strings sind eine Folge von `char`s.

Ein einzelnes `char` kann mit (nullbasierter) Indexierung aus einem String abgerufen werden:

```fsharp
"Exercism"[4] //  =>  'c'
```

Beim Iterieren über einen String wird bei jedem Schritt ein `char` zurückgegeben.

Das nächste Beispiel verwendet der Einfachheit halber eine Funktion höherer Ordnung und eine anonyme Funktion.
Diese werden später im Lehrplan richtig behandelt, aber für den Moment sind sie im Wesentlichen eine kompakte Möglichkeit, eine Schleife über die Zeichen in einem String zu schreiben.

```fsharp
Seq.map (fun c -> c, int c) "F#"  //  =>  [('F', 70); ('#', 35)]
```

Wie oben gezeigt, kann ein `char` in seinen `int`-Wert umgewandelt werden.
Das funktioniert (*zumindest manchmal*) auch für andere Schriftsysteme:

```fsharp
Seq.map (fun c -> c, int c) "東京"  //  =>  [('東', 26481); ('京', 20140)]
```

Beim Vergleichen von Zeichen wird der zugrunde liegende Int16-Wert verwendet:

```fsharp
'A' < 'D'  // =>  true
```

Außerdem kann ein `int` in ein `char` umgewandelt werden:

```fsharp
char 77  // => 'M'
```

Die `System.Char`-Bibliothek enthält den vollständigen Satz von Methoden, die man von einer .NET-Sprache erwartet, wie etwa Umwandlungen in Groß- und Kleinbuchstaben:

```fsharp
'a' |> System.Char.ToUpper  // =>  'A'

'Q' |> System.Char.ToLower  // =>  'q'
```
