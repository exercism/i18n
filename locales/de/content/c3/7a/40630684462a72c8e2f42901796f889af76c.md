# Anweisungen

Du wirst etwas Code schreiben, um eine Liste von Programmiersprachen zu verwalten, die du lernen möchtest. Die Liste ist in einem Array namens `@LanguageList::Languages` enthalten.

## 1. Eine Sprache zum @Languages-Array hinzufügen

Ändere die Subroutine `LanguageList::add_language`, die einen Sprachnamen als Argument entgegennimmt, so, dass sie die Sprache an das Ende des Arrays `@LanguageList::Languages` anhängt.

## 2. Eine Sprache aus dem @Languages-Array entfernen

Ändere die Subroutine `LanguageList::remove_language` so, dass sie die letzte Sprache aus dem Array `@LanguageList::Languages` entfernt.

## 3. Die erste Sprache aus dem @Languages-Array holen

Ändere die Subroutine `LanguageList::first_language` so, dass sie die erste Sprache im Array `@LanguageList::Languages` zurückgibt.

## 4. Die letzte Sprache aus dem @Languages-Array holen

Ändere die Subroutine `LanguageList::last_language` so, dass sie die letzte Sprache im Array `@LanguageList::Languages` zurückgibt.

## 5. Einen Ausschnitt von Sprachen aus dem @Languages-Array holen

Ändere die Subroutine `LanguageList::get_languages`, die eine Liste von Zahlen für die gewünschten Elemente entgegennimmt, so, dass sie einen Ausschnitt des Arrays `@LanguageList::Languages` zurückgibt.

## 6. Prüfen, ob eine Sprache im @Languages-Array existiert

Ändere die Subroutine `LanguageList::has_language`, die einen Sprachnamen als Argument entgegennimmt, so, dass sie entweder den Wert wahr oder falsch zurückgibt, je nachdem, ob die Sprache im Array `@LanguageList::Languages` vorhanden ist.
