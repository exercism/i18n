# Platzhalter

## `jq`-Tipps

In dieser Übung geht es darum, ein Eingabeobjekt zu nehmen und daraus ein neues Objekt zu machen.
Ein paar eingebaute Funktionen, die dabei helfen können:

- [`to_entries`][x_entries]
  - diese Funktion nimmt ein Objekt als Eingabewert
  - sie gibt ein _Array_ aus: jedes Array-Element ist ein Objekt `{"key": "K", "value": V}`
    - jedes `K` ist ein Schlüssel aus dem Eingabeobjekt
    - jedes `V` ist der zu `K` gehörende Wert.
- [`from_entries`][x_entries]
  - die umgekehrte Operation
  - nimmt ein Array von `{"key": K, "value": V}`-Objekten und konstruiert daraus ein Objekt

Ein Beispiel:

```sh
jq -n '
    {
        "username": "glennj",
        "tracks": ["bash", "awk", "jq"],
        "reputation": 123
    }
    | to_entries
'
```

gibt Folgendes aus:

```json
[
  {
    "key": "username",
    "value": "glennj"
  },
  {
    "key": "tracks",
    "value": ["bash", "awk", "jq"]
  },
  {
    "key": "reputation",
    "value": 123
  }
]
```

[x_entries]: https://jqlang.org/manual/#to_entries-from_entries-with_entries
