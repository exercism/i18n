# Einführung

Das Flags-Attribut ermöglicht es, die in einer Discriminated Union definierten Werte als Bitpositionen darzustellen (d. h. als Flags).
Als Flags lassen sich solche Werte kombinieren, sodass sich mehrere boolesche Bedingungen in einem einzigen Wert darstellen lassen.

```fsharp
[<Flags>]
type PhoneFeatures =
| Call = 1
| Text = 2
```

```fsharp
[<Flags>]
type PhoneFeaturesBinary =
| Call = 0b00000001
| Text = 0b00000010
```

Ein Flag setzt du mit dem bitweisen OR-Operator (`|||`); ein Flag entfernst du mit einer Kombination aus dem bitweisen AND-Operator (`&&&`) und dem bitweisen Negationsoperator (`~~~`).
Den Zustand eines Flags kannst du mit dem bitweisen AND-Operator prüfen, du kannst aber auch die `HasFlag()`-Methode verwenden.

```fsharp
let features = PhoneFeatures.Call

// Set the Text flag
let moreFeatures = features ||| PhoneFeatures.Text

moreFeatures.HasFlag(PhoneFeatures.Call) // => true
moreFeatures.HasFlag(PhoneFeatures.Text) // => true
```

Eine vollständige Liste der bitweisen Operatoren, die in der Sprache F# verfügbar sind, findest du unter [Zusammenfassung der bitweisen Operatoren][bitwise-operators].
