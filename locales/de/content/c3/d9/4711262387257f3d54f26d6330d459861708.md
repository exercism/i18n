# Arrays

Ein **Array** speichert eine Reihe von Werten, alle vom selben Typ, in einer festen Reihenfolge.

Der Typ wird als `ARRAY{T}` geschrieben, wobei `T` angibt, was das Array enthält. Ein Array aus Strings ist `ARRAY{STR}`; ein Array aus Ganzzahlen ist `ARRAY{INT}`.

```sather
   row : ARRAY{STR} := |"Mia", "Ana", "Ben"|;
```

Die Werte zwischen den beiden `|`-Zeichen sind das **Array-Literal**. Sather ermittelt die Größe daraus, wie viele es sind.

## Einen Wert herausholen

In eckigen Klammern steht die Position:

```sather
row[0]      -- "Mia"
row[1]      -- "Ana"
row[2]      -- "Ben"
```

Das Zählen beginnt bei **null**, nicht bei eins. Der erste Wert steht also bei `0`, und der letzte in einer Reihe von drei steht bei `2`.

## Wie viele?

`.size` gibt an, wie viele Werte das Array enthält.

```sather
row.size    -- 3
```

Weil das Zählen bei null beginnt, ist die letzte Position immer `.size - 1`:

```sather
row[row.size - 1]     -- "Ben"
```

Wenn du eine Position abfragst, die es nicht gibt (`row[3]` oder `row[-1]`), ist das ein Fehler, den Sather nicht für dich findet. Deshalb solltest du lieber `.size - 1` schreiben, statt die Werte mit dem Auge abzuzählen.

## Ein Array durchlaufen

Array und Schleife gehören zusammen. Zähle eine Variable durch die Positionen hoch und benutze sie, um jeden Wert zu erreichen:

```sather
   total ::= 0;
   i ::= 0;
   loop
      until!(i >= scores.size);
      total := total + scores[i];
      i := i + 1;
   end;
```
