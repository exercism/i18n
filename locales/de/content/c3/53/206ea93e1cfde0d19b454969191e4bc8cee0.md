# Ganzzahlen

Ganzzahlen sind ganze Zahlen aus der Menge `{..., -2, -1, 0, 1, 2, ...}`.
Die maximalen und minimalen Werte einer Ganzzahl hängen von dem System ab, auf dem PHP läuft.
Auf den meisten modernen Systemen ist eine Ganzzahl ein 64-Bit-Wert. Das bedeutet, sie kann Werte von `-9_223_372_036_854_775_808` bis einschließlich `9_223_372_036_854_775_807` darstellen.

```php
<?php

$a = 1234;
$a = 1_234_567;
```

Du kannst Ganzzahl-Literale auch in anderen Basen als 10 schreiben, indem du ein Basispräfix verwendest:

```php
<?php

$a = 0123; // octal number (equivalent to 83 decimal)
$a = 0o123; // octal number (as of PHP 8.1.0)
$a = 0x1A; // hexadecimal number (equivalent to 26 decimal)
$a = 0b11111111; // binary number (equivalent to 255 decimal)
```
