# Anleitung

Deine Freundin Leticia arbeitet im Fundbüro einer U-Bahn-Station.

Jeder gefundene Gegenstand wird als neuer Eintrag in eine Liste der Gegenstände des Tages aufgenommen.
Am Ende des Monats wird jeder Gegenstand, der nicht abgeholt wurde, in ein Depot in einer Kiste verlegt, auf der das Datum steht, an dem er gefunden wurde.
Das alles läuft auf Papier ab, deshalb wird es manchmal ganz schön unübersichtlich!

Leticia hat dich um Hilfe dabei gebeten, einige dieser Aufgaben zu automatisieren.

|---------------|-----------------------------------------------------------|

## 1. Für jeden Gegenstand einen Eintrag anlegen

Als Erstes musst du alle Gegenstände ordnen, damit sie sich leichter nachschlagen lassen.
Jeder Gegenstand wird im Speicher durch seine ID, eine Beschreibung, das Datum, an dem er gefunden wurde, und eine variable Anzahl von Kategorien identifiziert.

Definiere eine Funktion `create_item_entry`, die keinen Rückgabewert hat und einen neuen Eintrag für einen Gegenstand an eine Speicherstelle schreibt.
Diese Funktion kann beliebig viele Parameter annehmen, von denen die ersten sechs immer diese sind:

1. Die Adresse einer Speicherstelle, an der der Eintrag gespeichert werden soll.
2. Die ID des Gegenstands als 64-Bit-Ganzzahl ohne Vorzeichen.
3. Die Adresse eines Strings mit der Beschreibung des Gegenstands.
4. Der Tag, an dem der Gegenstand gefunden wurde, als 64-Bit-Ganzzahl ohne Vorzeichen.
5. Der Monat, in dem der Gegenstand gefunden wurde, als 64-Bit-Ganzzahl ohne Vorzeichen.
6. Die Anzahl der Kategorien des Gegenstands als 64-Bit-Ganzzahl ohne Vorzeichen.

Jeder weitere Parameter ist die Adresse eines Strings mit einer der Kategorien.

Die Werte sollten in der angegebenen Speicherstelle in derselben Reihenfolge wie die Argumente gespeichert werden: ID, Beschreibung, Tag, Monat, Anzahl der Kategorien und dann jede Kategorie der Reihe nach.

## 2. Speicher für eine monatliche Liste von Gegenständen reservieren

Es ist mühsam, Gegenstände in so vielen verschiedenen Listen zu suchen.
Deshalb beschließt du, alles in einer einzigen Liste pro Monat zu organisieren.
Diese Liste ist als Array umgesetzt.

Definiere die Funktion `create_monthly_list`, die Speicher für ein Array reserviert und die Adresse dieser Speicherstelle zurückgibt.
Sie nimmt folgende Parameter an:

1. Die Kapazität des Arrays in Bytes als 64-Bit-Ganzzahl ohne Vorzeichen.
2. Eine Allocator-Funktion.

Die Allocator-Funktion nimmt als Parameter eine 64-Bit-Ganzzahl ohne Vorzeichen an, die der zu reservierenden Speichergröße in Bytes entspricht, und gibt die Adresse des reservierten Speichers zurück.

Beachte, dass der reservierte Speicher einen _undefinierten_ Wert hat, also sollten alle Bytes in diesem Speicher gelöscht werden, d. h. ihr Wert sollte auf `0` gesetzt werden.

## 3. Einen Gegenstand in die monatliche Liste einfügen

An jedem Tag sollte jeder gefundene Gegenstand in die monatliche Liste eingefügt werden.

Definiere die Funktion `insert_found_item`, die keinen Rückgabewert hat und folgende Parameter annimmt:

1. Die Adresse einer Speicherstelle, an der die monatliche Liste liegt.
2. Die aktuelle Anzahl der bereits in der Liste gespeicherten Einträge als 64-Bit-Ganzzahl ohne Vorzeichen.
3. Einen neuen Eintrag, der zur Liste hinzugefügt werden soll.

Du kannst davon ausgehen, dass der neue Eintrag immer in die Liste passt und dass jeder Eintrag in der Liste 120 Bytes belegt.

## 4. Einen Gegenstand ausgeben

Die Suche nach einem bestimmten Eintrag wäre viel einfacher, wenn Leticia ihn auf dem Bildschirm sehen könnte.

Definiere die Funktion `print_item`, die folgende Parameter annimmt:

1. Die Adresse eines Puffers, in dem ein einführender ASCII-String mit NUL-Terminierung gespeichert werden kann.
2. Die Adresse einer Speicherstelle, an der die monatliche Liste liegt.
3. Den Index des Eintrags im Array für den Gegenstand, der ausgegeben werden soll, als 64-Bit-Ganzzahl ohne Vorzeichen.
4. Eine Ausgabefunktion.

Diese Funktion hat keinen Rückgabewert und sollte die Ausgabefunktion mit folgenden Argumenten aufrufen:

1. Die Adresse einer Speicherstelle, an der der einführende String gespeichert ist; oder `0` (als 64-Bit-Ganzzahl), wenn kein String übergeben wird.
2. Den Index des Eintrags im Array für den Gegenstand, der ausgegeben werden soll, als 64-Bit-Ganzzahl ohne Vorzeichen.
3. Die ID des Gegenstands als 64-Bit-Ganzzahl ohne Vorzeichen.
4. Die Adresse eines Strings mit der Beschreibung des Gegenstands.
5. Der Tag, an dem der Gegenstand gefunden wurde, als 64-Bit-Ganzzahl ohne Vorzeichen.
6. Der Monat, in dem der Gegenstand gefunden wurde, als 64-Bit-Ganzzahl ohne Vorzeichen.
7. Die Anzahl der Kategorien des Gegenstands als 64-Bit-Ganzzahl ohne Vorzeichen.
8. Die Adresse des ersten Kategorie-Strings.

Der einführende String ist optional.
Wenn er in der Ausgabefunktion verwendet wird, muss dieser String NUL-terminiert sein (endet mit `0`) und darf höchstens 50 Zeichen lang sein, wobei das NUL-Terminator-Zeichen bereits mitgezählt wird.
Andernfalls sollte stattdessen der Wert `0` an die Ausgabefunktion übergeben werden.

Du kannst davon ausgehen, dass jeder Gegenstand in der Liste 120 Bytes belegt.
