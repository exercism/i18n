# Einführung

Die Klasse Lambda ist eine Sammlung funktionaler Methoden, um mit Haxe im funktionalen Stil zu programmieren. Sie ermöglicht es uns, ein ganzes Iterable auf einmal zu bearbeiten. Das ist oft besser, als die Arbeit in Schleifen zu erledigen, weil es weniger fehleranfällig und leichter zu lesen ist. Der Einfachheit halber enthalten die Klassen Array und List einige der häufig verwendeten Methoden aus der Klasse Lambda.

Einige Funktionen der Klasse `Lambda` sind:

- `Lambda.array`, `Lambda.list` Wandelt ein Iterable in ein Array oder eine List um. Gibt immer eine neue Instanz zurück.
- `Lambda.count` Zählt die Anzahl der Elemente. Wenn das Iterable ein Array oder eine List ist, ist es schneller, die Eigenschaft length zu verwenden.
- `Lambda.has` Bestimmt, ob das angegebene Element im Iterable enthalten ist.
- `Lambda.indexOf` Findet den Index des angegebenen Elements heraus.
- `Lambda.find` Findet das erste Element mit der angegebenen Suchfunktion.
- `Lambda.concat` Führt zwei Iterables zusammen und gibt eine neue List zurück.
- `Lambda.filter` Findet die Elemente, die ein Kriterium erfüllen, und gibt eine neue List zurück.

Ein Beispiel, das einige Funktionen zeigt:

```haxe
using Lambda;

class Main {
  static function main() {
    var words = ["boat", "dog", "phone", "cat", "food"];

    var isThreeLetters = function(word) return word.length == 3;

    trace(words.filter(isThreeLetters)); // [dog,cat]
  }
}
```
