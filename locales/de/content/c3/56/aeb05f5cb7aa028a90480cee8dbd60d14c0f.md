# Tests

## TLDR

- Wechsle in das Verzeichnis der Übung (z. B. `~/Exercism/hello-world`).
- Starte eine `jconsole`-Sitzung in einem Terminal.
- Lade deine Lösungsdatei (z. B. `load 'hello-world.ijs'`).
- Lade das Unit-Test-Framework, indem du `load  'general/unittest'` eingibst.
- Teste deine Lösung, indem du `unittest 'test.ijs'` eingibst.
<br></br>
- Alternativ kannst du die Tests in einer einzigen Zeile so ausführen: `jconsole -js "load 'hello-world.ijs'" "echo unittest 'test.ijs'" "exit 0"`.

## Jconsole Session

Die Tests dieses Tracks sollen so einfach wie möglich aufgebaut sein.
Wenn du an einer Übung arbeitest, sagen wir `hamming.ijs`, dann sollte die Arbeit so ablaufen.
Bearbeite `hamming.ijs` und schreibe deine Lösung hinein.
Baue sie interaktiv auf, indem du zuerst Folgendes eingibst:

```j
NB. your j terminal binary may be ijconsole (eg. on Debian)
jconsole 'hamming.ijs' NB. start a J console session with definitions loaded hamming.ijs
```

Lade dann aus der J-Konsole heraus neu, indem du Folgendes eingibst:

```j
load 'hamming.ijs'
```

Der nächste Schritt ist, das Unit-Test-Framework zu laden, indem du Folgendes eingibst:

```j
load 'general/unittest'
```

Um die Tests auszuführen &#x2013; nachdem du deine Lösung geladen hast &#x2013; gib Folgendes ein:

```j
unittest 'test.ijs'
```

Und beobachte dann die Ergebnisse.

## Kommandozeile

Du kannst die Tests mit dem Flag -js in einem einzigen Befehl im Terminal ausführen:

```j
jconsole  -js "load 'hamming.ijs'" "echo unittest 'test.ijs'" "exit 0"
```
wobei jedes Argument einen Befehl darstellt, der nacheinander ausgeführt wird.
