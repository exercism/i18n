# Einführung

Die meisten Programme hängen von der einen oder anderen Bibliothek ab. Diese von Hand zu verwalten, kann ganz schön mühsam sein. Zum Glück bringt das Rust-Ökosystem `cargo` schon von Haus aus mit! Mit `cargo` kannst du die Abhängigkeiten eines Projekts verwalten.

In Rust werden externe Pakete oft als „Crates“ bezeichnet. Ein Crate ist eine Kompilierungseinheit in Rust. Ein Crate lässt sich in eine Binärdatei oder in eine Bibliothek kompilieren.

Meistens ist es so einfach, eine externe Abhängigkeit hinzuzufügen, wie eine Zeile in deine `Cargo.toml`-Datei zu schreiben.
