# Einführung

AWK ist eine sehr kleine Sprache und hat nur wenige grundlegende Datentypen.
In dieser Lektion schauen wir uns Zahlen und Strings an.

## Zahlen

Zahlen werden in AWK als Gleitkommazahlen mit doppelter Genauigkeit dargestellt.
Es gibt keinen Unterschied zwischen Ganzzahlen, Gleitkommazahlen und Doubles.

AWK versteht Oktalzahlkonstanten (beginnend mit `0`) und Hexadezimalzahlkonstanten (beginnend mit `0x` oder `0X`).

### Numerische Operationen

Du kannst die [Standard-Arithmetikoperatoren][ops-arith] `+`, `-`, `*`, `/`, `%` verwenden.
Der Potenzoperator ist `^` (so legt es POSIX fest), obwohl auch `**` verwendet werden kann.
Es gibt einige [integrierte numerische Funktionen][funcs-numeric], darunter trigonometrische Funktionen, die Erzeugung von Zufallszahlen und `int(x)`, um eine Zahl auf die nächste Ganzzahl zwischen _x_ und null abzuschneiden.

Es gibt keine bitweisen _Operatoren_.
gawk implementiert sie als Funktionen.
Die Argumente müssen nicht-negative Zahlen sein.

| Funktion            | Operation                                      |
| ------------------- | ---------------------------------------------- |
| `and(a, b [, ...])` | bitweises AND der Argumente                    |
| `or(a, b [, ...])`  | bitweises OR der Argumente                     |
| `xor(a, b [, ...])` | bitweises XOR der Argumente                    |
| `lshift(v, count)`  | der Wert von _v_, um _count_ Bits nach links verschoben  |
| `rshift(v, count)`  | der Wert von _v_, um _count_ Bits nach rechts verschoben |
| `compl(v, count)`   | bitweises Komplement von _v_                   |

## Strings

AWK-Strings sind Sequenzen von Zeichen.
Eine Stringkonstante gibst du mit doppelten Anführungszeichen an.

~~~~exercism/caution
GNU awk erlaubt Unicode-Zeichen in Strings: andere awk-Implementierungen möglicherweise nicht.
Ein Vergleich von `gawk` und `mawk`, einem anderen beliebten AWK:

```sh
$ echo "Hi friend 😀!" | gawk '{print length($3)}'
2
$ echo "Hi friend 😀!" | mawk '{print length($3)}'
5
```
~~~~

### String-Operationen

Es gibt nur eine String-Operation: die Verkettung.
Die Verkettung hat keinen eigenen Operator;
du setzt einfach zwei Strings nebeneinander, um sie zu verketten:

```awk
BEGIN {
    hw = "Hello" "World"
    print hw
}
# => HelloWorld
```

~~~~exercism/note
`print` ist eine **Anweisung** und keine Funktion.
`print` benötigt keine runden Klammern.
~~~~

AWK hat eine Fülle von [Funktionen zur Stringbearbeitung][funcs-string].
Wir werden sie nach und nach im Verlauf des Tracks im Detail kennenlernen.

## Umwandlung zwischen Zahlen und Strings

Es gibt keine expliziten Operatoren, um zwischen Zahlen und Strings umzuwandeln.
AWK erledigt das implizit, abhängig vom Kontext des Programms.
Dadurch ist die Arbeit mit den Werten der Eingabefelder sehr einfach: AWK macht im Allgemeinen einfach das, was du willst.

* `print x + y` wandelt die Werte der Variablen `x` und `y` dank der numerischen Operation `+` in Zahlen um.
* `print x y` wandelt die Werte der Variablen `x` und `y` dank der Verkettung in Strings um.

Wenn du es explizit haben willst, liefert `0 + x` die Zahlendarstellung von _x_ und `"" x` die Stringdarstellung von _x_.

### Von Strings zu Zahlen

Die Art und Weise, wie AWK einen String in eine Zahl umwandelt, kann verwirrend sein.
Eine einfache Denkhilfe: AWK liest vom Anfang eines Strings so lange „Zahlzeichen“, bis es auf ein „Nicht-Zahlzeichen“ trifft.
Ein paar Beispiele:

* `"2.5"` wird zur Zahl `2.5`;
* `"1e3"` wird zur Zahl `1000` (wissenschaftliche Notation);
* `"456abc"` wird zur Zahl `456` (weil `a` keine „Ziffer“ ist, stoppt die Umwandlung dort).
* `"abc789"` wird zur Zahl `0` (am **Anfang** des Strings stehen keine Ziffern).

Alle Details stehen [im Handbuch][str-to-num].

## Den Typ einer Variable bestimmen

Die [`typeof(var)`-Funktion][func-typeof] gibt den Typ als String zurück.

```awk
BEGIN {
    x = "42"
    print x, typeof(x)
    x = x + 1           # type conversion
    print x, typeof(x)
}
```
gibt aus:
```none
42 string
43 number
```
