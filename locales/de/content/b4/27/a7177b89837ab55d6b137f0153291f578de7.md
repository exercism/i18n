## Variablen

Variablen sind symbolische Namen, die entweder auf Werte oder auf Container verweisen.
Ein Variablenname kann mit einem Sonderzeichen beginnen, dem sogenannten [Sigil][sigils], auf das ein Bezeichner folgt, oder direkt mit dem Bezeichner.
Auf ein Sigil kann außerdem ein [Twigil][twigils] folgen.

Variablen mit unterschiedlichem Sigil enthalten unterschiedliche Arten von Datenstrukturen.

```raku
my $scalar; # Assigned value will be stored as-is
my @array;  # Assigned value will be coerced into an array
my %hash;   # Assigned value will be coerced into a hash
my &code;   # Assigned value must be a code object
```

Twigils, die dir häufig begegnen, sind `^` und `:`. Sie sind Kurzformen für die Signatur eines Blocks.
Das `^` steht für positionale Parameter.
Das `:` steht für benannte Parameter.

```raku
{ $^a + $^b }; #`[same as] ->  $a,  $b { $a + $b }; # Called with (1, 2)
{ $:a + $:b }; #`[same as] -> :$a, :$b { $a + $b }; # Called with (a => 1, b => 2)
```

## Container

Container sind das, was eine Variable veränderbar macht.

Variablen, die mit `constant` deklariert werden, sowie Variablen ohne Sigil (deklariert mit einem `\` vor dem Bezeichner) haben keinen Container und verweisen stattdessen direkt auf Werte.

```raku
my $foo = 1;
$foo = 2;

constant $bar = 3;
my \baz = 4;

# The following will fail
$bar = 5;
baz  = 6;
```

## Typen

Variablen können mit einer Typbeschränkung deklariert werden.
Typbeschränkungen können auch eine Koerzierung haben: Dazu gibst du einen akzeptierten Typ als Argument für den gewünschten Typ an.

```raku
my Bool   $foo = True; # Booleans only.
my Bool() $bar = 0;    # Accepts type `Any`. Coerced to False.

my Str(Bool(Int)) $baz;
$baz = 1;   # "True"
$baz = "1"; # "1"
```

Typbeschränkungen sind eine Möglichkeit, Multi-Dispatch-Routinen zu nutzen.

```raku
multi foo (Int $bar) { say 'Type of arg to $bar is Int!' }
multi foo (Str $bar) { say 'Type of arg to $bar is Str!' }
```

Typen sind in Raku einfach eine weitere Art von Objekt.
Mit der Deklaration von `class`, `role` oder `enum` erstellst du deine eigenen Typobjekte.
Der eingebaute Typ `Bool` zum Beispiel ist mit einem `enum` gebaut: `enum Bool <False True>`.

Mit dem Schlüsselwort `subset` kannst du außerdem einfache Typbeschränkungen auf Basis anderer Typen erstellen.
Mit einer `where`-Klausel kannst du diesen neuen Typ weiter einschränken.
Eine `where`-Klausel kannst du auch in einer Signatur verwenden.

```raku
subset PositiveInt of Int where * > 0;

sub is-even (PositiveInt $n where  %% 2) { say "$n is even!" }
```
