# Einführung

## Eigenschaften

Eine Eigenschaft in C# ist ein Member einer Klasse, das den Zugriff auf Daten innerhalb dieser Klasse ermöglicht.
Aufrufer können die Daten setzen oder abrufen (get). Eigenschaften können entweder automatisch implementiert sein oder ein Backing-Field haben. Sie bestehen aus einem set-Accessor und/oder einem get-Accessor.
In manchen anderen Sprachen entspricht ein „Mutator“ ungefähr einem set-Accessor und ein „Accessor“ ungefähr einem get-Accessor, obwohl der Aufbau der Syntax völlig anders ist.

Beim Setzen einer Eigenschaft kann der Eingabewert validiert, formatiert oder anderweitig bearbeitet werden. Tatsächlich kann jede programmatische Operation ausgeführt werden, auf die der Code in der Klasse zugreifen kann.

Ebenso können beim Abrufen einer Eigenschaft Daten berechnet oder formatiert werden, und auch hier kann jede programmatische Operation ausgeführt werden, die der Klasse zur Verfügung steht.

Eigenschaften haben Zugriffsmodifikatoren (`public`, `private` usw.) genauso wie andere Klassenmember. Der set-Accessor kann jedoch eine Zugriffsebene haben, die unabhängig vom get-Accessor ist, und umgekehrt. Eine Eigenschaft muss nicht beide Accessoren haben, sie kann auch nur einen besitzen (entweder get oder set).

Die grundlegende Syntax für Eigenschaften kann zwei Formen annehmen:

### Feld-/ausdrucksbasierte Eigenschaften:

```csharp
private int myField;
public int MyProperty
{
    get { return myField; }
    set { myField = value; }
}
```

### Automatisch implementierte Eigenschaften

```
public int MyProperty { get; private set; } = 42;
```

Die Initialisierung ist optional.
