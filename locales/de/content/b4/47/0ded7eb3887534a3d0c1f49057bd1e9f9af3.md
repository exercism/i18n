# Hinweise

## Allgemeines

- Mach dir keine Gedanken darüber, in welchem Betriebszustand die Maschine gerade ist; wenn du sie zum Beispiel einsteckst, läuft sie noch nicht.

## 1. Debug-Leuchte

- Du musst eine Klasse mit dem Namen `JuiceMaker` definieren.
- Du musst eine [Klassenmethode][class-methods] definieren, die `true` zurückgibt.

## 2. Die Maschine initialisieren

- Erstelle einen [Konstruktor][new-initialize] für die Klasse `JuiceMaker`.
- Erstelle eine [Instanzvariable][instance-variable] `@running`, die auf `false` gesetzt wird.
- Erstelle eine [Instanzvariable][instance-variable] `@fluid`, die auf die Menge gesetzt wird, die dem Konstruktor als Argument übergeben wird.

## 3. Die Maschine einschalten

- Definiere eine Instanzmethode namens `start`.
- Setze die [Instanzvariable][instance-variable] `@running` auf `true`.

## 4. Status der Maschine

- Definiere eine Instanzmethode namens `running?`.
- Gib die [Instanzvariable][instance-variable] `@running` zurück.

## 5. Saft hinzufügen

- Definiere eine Instanzmethode namens `add_juice`, die eine Ganzzahl als Argument entgegennimmt.
- Setze die [Instanzvariable][instance-variable] `@fluid` auf die Summe aus dem aktuellen Wert von `@fluid` und dem Argument, das der Methode übergeben wird.

## 6. Die Maschine ausschalten

- Definiere eine Instanzmethode namens `stop`, die eine Ganzzahl als Argument entgegennimmt.
- Setze die [Instanzvariable][instance-variable] `@running` auf `false`.
- Setze die [Instanzvariable][instance-variable] `@fluid` auf den aktuellen Wert von `@fluid` minus das Argument, das der Methode übergeben wird, mal 5.
