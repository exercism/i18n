# Ergänzung zu den Anweisungen

## Register

| Register | Verwendung | Typ     | Beschreibung                                                                                                   |
| -------- | ---------- | ------- | -------------------------------------------------------------------------------------------------------------- |
| `$a0`    | Eingabe    | Ganzzahl | Zahl                                                                                                          |
| `$v0`    | Ausgabe    | Ganzzahl | Klassifizierung (`1` = `perfect`, `2` = `abundant`, `3` = `deficient`, `-1` = `error`)                         |
| `$t0-9`  | temporär   | beliebig | wird als temporärer Speicher verwendet                                                                        |
