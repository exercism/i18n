# Anleitung

Du bist der Zahlmeister des Schiffs und verwaltest den Bestand der Speisekammer. Das Inventar ist eine Hashtabelle, in der jeder Schlüssel ein Artikelname und der Wert die Menge auf Lager ist.

## 1. Ein Inventar aus einer Liste erstellen

Definiere `create-inventory`, sodass es eine Folge von Artikelnamen entgegennimmt und eine Hashtabelle zurückgibt, die jeden eindeutigen Namen mit seiner Anzahl paart.

```factor
{ "coal" "wood" "wood" "diamond" "diamond" "diamond" } create-inventory .
! => H{ { "coal" 1 } { "wood" 2 } { "diamond" 3 } }
```

## 2. Weitere Artikel hinzufügen

Definiere `add-items`, sodass es ein Inventar und eine Folge von Artikeln entgegennimmt und ein neues Inventar zurückgibt, dessen Anzahlen für jeden aufgeführten Artikel erhöht wurden. Das ursprüngliche Inventar darf nicht verändert werden.

```factor
H{ { "coal" 1 } } { "wood" "iron" "coal" "wood" } add-items .
! => H{ { "coal" 2 } { "wood" 2 } { "iron" 1 } }
```

## 3. Mengen verringern

Definiere `decrement-items`, sodass es ein Inventar und eine Folge von Artikeln entgegennimmt und ein neues Inventar zurückgibt, dessen Anzahlen für jeden aufgeführten Artikel um eins verringert wurden. Die Anzahlen dürfen nie unter null fallen, und Artikel, die noch nicht im Inventar sind, sollen weggelassen werden (es werden keine negativen Einträge eingefügt).

```factor
H{ { "coal" 3 } { "diamond" 1 } { "iron" 5 } }
{ "diamond" "coal" "iron" "iron" } decrement-items .
! => H{ { "coal" 2 } { "diamond" 0 } { "iron" 3 } }
```

## 4. Einen Artikel komplett entfernen

Definiere `remove-item`, sodass es ein Inventar und einen Artikel entgegennimmt und ein neues Inventar zurückgibt, in dem dieser Artikel entfernt wurde. Wenn der Artikel nicht vorhanden ist, gib eine unveränderte Kopie zurück.

```factor
H{ { "coal" 2 } { "wood" 1 } { "diamond" 2 } } "coal" remove-item .
! => H{ { "wood" 1 } { "diamond" 2 } }
```

## 5. Die verfügbaren Artikel auflisten

Definiere `list-inventory`, sodass es ein Inventar entgegennimmt und ein Array von `{ name quantity }`-Paaren zurückgibt, das nur die Artikel enthält, deren Menge größer als null ist, alphabetisch nach Namen sortiert.

```factor
H{ { "coal" 7 } { "wood" 11 } { "diamond" 2 } { "iron" 7 } { "silver" 0 } }
list-inventory .
! => { { "coal" 7 } { "diamond" 2 } { "iron" 7 } { "wood" 11 } }
```
