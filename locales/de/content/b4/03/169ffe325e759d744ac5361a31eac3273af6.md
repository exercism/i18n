# Über

Konstanten in Gleam sind eine Möglichkeit, Werten Namen zu geben. Du definierst sie mit dem `const`-Schlüsselwort.

```gleam
pub const pi: Float = 3.14159

pub fn circle_area(radius: Float) -> Float {
  radius *. radius *. pi
}
```

Wenn du eine Modulkonstante mit dem `pub`-Schlüsselwort definierst, kannst du von anderen Modulen aus auf sie zugreifen. Sonst ist sie nur innerhalb des Moduls verfügbar, in dem sie definiert ist.
