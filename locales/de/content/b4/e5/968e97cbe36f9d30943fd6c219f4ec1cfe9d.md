# Über arithmetische Operatoren

## Operatoren

Go unterstützt die folgenden arithmetischen Operatoren:

| Operator | Beispiel       |
| -------- | -------------- |
| `+`      | `4 + 6 == 10`  |
| `-`      | `15 - 10 == 5` |
| `*`      | `2 * 3 == 6`   |
| `/`      | `13 / 3 == 4`  |
| `%`      | `13 % 3 == 1`  |

Bei der Division von Ganzzahlen wird der Rest verworfen (z. B. `5 / 2 == 2`).

Der `+`-Operator verkettet auch Strings: `"foo" + "bar" == "foobar"`.

## Arithmetik mit gemischten Typen

Go erlaubt keine arithmetischen Operationen zwischen verschiedenen numerischen Typen:

```go
x := 42
n := 2.0
value := n * x // invalid operation: n * x (mismatched types float64 and int)
```

Die Operanden müssen denselben Typ haben, manchmal ist dafür eine explizite Konvertierung nötig:

```go
x := float64(42)
n := 2.0
value := n * x 
```

## Kurzschreibweisen für Zuweisungen

Jeder Operator hat eine Kurzform für die Zuweisung, die die Variable direkt aktualisiert:

```go
a := 1
a += 2 // same as a = a + 2 == 3

b := 2
b -= 2 // same as b = b - 2 == 0

c := 4
c *= 2 // same as c = c * 2 == 8

d := 8
d /= 2 // same as d = d / 2 == 4

e := 16
e %= 2 // same as e = e % 2 == 0
```

## Inkrement und Dekrement

Wenn sie hinter einer Variablen stehen, erhöhen oder verringern die Anweisungen zum Inkrementieren (`++`) und Dekrementieren (`--`) ihren gespeicherten numerischen Wert um 1.
Wenn du sie vor eine Variable stellst, ist das ein Syntaxfehler.

```go
a := 10
a++ // same as a += 1, a == 11

b := 10
b-- // same as b -= 1, b == 9
```

Da es Anweisungen sind, geben sie keinen Wert zurück.
