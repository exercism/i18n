# Anleitung

Das ferngesteuerte Auto, das du dir vor Kurzem gekauft hast, ist zu einem ganz neuen Hobby geworden. Du hast angefangen, Rennen mit ferngesteuerten Autos zu organisieren.

Du warst fast fertig mit einem Programm, mit dem sich Rennsimulationen durchführen lassen, als deine Katze auf deine Tastatur sprang und ein paar Zeilen Code löschte. Jetzt lässt sich dein Programm nicht mehr kompilieren...

## 1. Behebe den Kompilierungsfehler `Race.__struct__/0 is undefined`

Füge einen Alias hinzu, damit du auf das Modul `NeedForSpeed.Race` mit dem kürzeren Namen `Race` verweisen kannst.

## 2. Behebe den Kompilierungsfehler `Car.__struct__/0 is undefined`

Füge einen Alias hinzu, damit du auf das Modul `NeedForSpeed.RemoteControlCar` mit dem kürzeren Namen `Car` verweisen kannst.

## 3. Behebe den Kompilierungsfehler `undefined function puts/1`

Die Funktion `puts/1` stammt aus dem Modul `IO`. Importiere es, damit du sie verwenden kannst, ohne das Modul anzugeben.

## 4. Behebe den Kompilierungsfehler `undefined function default_color/0`

Die Funktionen `default_color/0`, `red/0`, `cyan/0` und `green/0` stammen alle aus dem Modul `IO.ANSI`. Du hast vor, Unterstützung für weitere Autofarben hinzuzufügen, deshalb möchtest du das ganze Modul importieren. Leider kollidiert die Funktion `color/1` aus dem Modul `IO.ANSI` mit einer deiner lokalen Funktionen. Importiere das gesamte Modul `IO.ANSI`, außer dieser einen Funktion.
