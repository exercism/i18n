# Anleitung

In dieser Übung arbeitest du an einigen Funktionen, um Termine zu verwalten.
Das System speichert alles in Strings im ISO-8601-Format, aber so benutzen Menschen den Kalender nicht.
Um zwischen den verschiedenen Formaten umzurechnen, brauchst du verschiedene Funktionen.

## 1. Einen Termin erstellen

Erstelle einen Termin `n` Tage ab jetzt zur aktuellen Uhrzeit.
Die Funktion nimmt `n` Tage entgegen und gibt die Terminzeit in `n` Tagen zurück.

```javascript
createAppointment(4, now);
// Given now is Sun Oct 05 2022 23:28:43 GMT+0600 (Bangladesh Standard Time)
// => Sun Oct 09 2022 23:28:43 GMT+0600 (Bangladesh Standard Time)
```

Wenn der zweite Parameter `now` nicht verwendet wird, soll stattdessen die aktuelle Zeit verwendet werden.

## 2. Ein Datum in einen Zeitstempel umwandeln

Verschiedene Tools arbeiten nur mit dem international standardisierten ISO-8601-Format.
Schreibe die Funktion `getAppointmentTimestamp`, die ein Datum entgegennimmt und einen String in diesem Format zurückgibt.

```javascript
const appointment = new Date(Date.UTC(2010, 6, 16, 12, 42, 0, 0));

getAppointmentTimestamp(appointment);
// => '2010-07-16T12:42:00.000Z'
```

## 3. Die Details eines Termins abrufen

Zeitstempel sind schwer zu lesen; eine Funktion, die die Details eines Termins liefert, soll dabei helfen.
Die Funktion `getAppointmentDetails` nimmt einen Zeitstempel im ISO-8601-Format entgegen und gibt das Jahr, den Monat, den Tag, die Stunde und die Minute zurück.

```javascript
getAppointmentDetails('2022-04-24T08:15:00.000');
// => { year: 2022, month: 3, date: 24, hour: 8, minute: 15 }
```

## 4. Einen Termin mit den angegebenen Optionen aktualisieren

Die Funktion erhält als erstes Argument die Terminzeit und als zweites Argument ein Objekt mit einigen Optionen.
Du musst den Termin entsprechend den Optionen im Objekt aktualisieren und das neue Datum des Termins zurückgeben.
Das Optionsobjekt kann mehrere Optionen enthalten.

```javascript
updateAppointment('2022-02-09T09:20:00.000', { month: 6 });
// => { year: 2022, month: 6, date: 9, hour: 10, minute: 20 }
```

## 5. Die verfügbare Zeit zwischen zwei Terminen ermitteln

Die Funktion erhält zwei Termine (Zeitstempel) als Argumente.
Du musst die Differenz zwischen diesen beiden Zeiten in Sekunden zurückgeben.

Da eine halbe Sekunde fast bedeutungslos ist, runde die Zahl, bevor du sie zurückgibst.

```javascript
timeBetween('2022-12-12T09:20:00.000', '2022-12-18T08:30:00.000');
// => 515400
```

## 6. Prüfen, ob ein Termin jetzt gültig ist oder nicht

Schließlich muss das System beim Erstellen eines Termins prüfen, ob er gültig ist.
Mit anderen Worten: Der Termin muss in der Zukunft liegen und nicht in der Vergangenheit.

Schreibe die Funktion `isValid`, die zwei Argumente entgegennimmt, einen Termin-Zeitstempel (String) und die aktuelle Zeit als Zeitstempel (String), und `true` zurückgibt, wenn der Termin angesichts der aktuellen Zeit in der Zukunft liegt.

```javascript
isValid('2022-02-11T23:00:00.000', '2022-02-08T23:00:00.000');
// => true
```
