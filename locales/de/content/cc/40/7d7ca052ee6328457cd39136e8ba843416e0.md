# Einführung

Die Arbeit mit Binärdaten kann knifflig sein, deshalb bietet Gleam den Typ `BitArray` und eine passende Syntax, um Binärdaten zu konstruieren und mit ihnen Pattern Matching zu betreiben.

Bit-Array-Literale werden mit der Syntax `<<>>` definiert. Ein Bit-Array-Literal besteht aus Segmenten. Jedes Segment hat einen Wert und eine Annotation, die durch einen `:` getrennt werden. Die Annotation gibt an, wie viele Bits zur Kodierung des Werts verwendet werden, und kann ganz weggelassen werden. Dann wird standardmäßig ein 8-Bit-Ganzzahlwert angenommen.

```gleam
// This defines a bit array with three segments of a single bit each
<<0:1, 1:1, 0:1>>

// This defines a bit array with three segments of 8 bits each
<<0, 1, 0>>
```

Die Angabe `:1` ist eine Kurzform für `:size(1)`. Du musst die längere Syntax verwenden, wenn die Bitgröße aus einer Variable stammt.

```gleam
let segment_size = 1
<<0:size(segment_size), 1:size(segment_size), 0:size(segment_size)>>
```

## Binär

Binäre Ganzzahl-Literale können wir direkt in der Basis-2-Notation schreiben, indem wir dem Literal ein `0b` voranstellen. Beachte, dass sie als Dezimalzahlen dargestellt werden, wenn sie in Tests oder in deinem Programm ausgegeben werden.

```gleam
<<0b1011:4>> == <<11:4>>
// -> True
```

## Abschneiden

Wenn der Wert des Segments die Kapazität des Segmenttyps übersteigt, wird er von links abgeschnitten.

```gleam
<<0b1011:3>> == <<0b0011:3>>
// -> True
```

## Vorne und hinten anhängen

Mit der Bit-Array-Syntax kannst du sowohl vorne als auch hinten an ein bestehendes Bit-Array anhängen. Für das bestehende Bit-Array muss die Annotation `:bits` verwendet werden.

```gleam
let value = <<0b110:3, 0b001:3>>
let new_value = <<0b011:3, value:bits, 0b000:3>>
// -> <<120, 8:size(4)>>
```

## Verketten

Bit-Arrays, die in Variablen gespeichert sind, können wir mit der Syntax verketten. Die Annotation `:bits` muss verwendet werden, wenn zwei Bit-Arrays variabler Größe verkettet werden.

```gleam
let first = <<0b110:3>>
let second = <<0b001:3>>
let concatenated = <<first:bits, second:bits>>
// -> <<49:size(6)>>
```

## Pattern Matching

Mit Pattern Matching kannst du auch Werte aus dem Bit-Array herausziehen. Für jedes Fragment, das du erfassen willst, musst du die Anzahl der Bits kennen. Eine Ausnahme gibt es: Mit der Annotation `:bits` kannst du Pattern Matching auf einem Bit-Array unbekannter Größe durchführen, aber das geht nur für das letzte Fragment.

```gleam
let assert <<value:4, rest:bits>> = <<0b01101001:8>>
value == 0b0110
// -> true
```

## Bit-Arrays untersuchen

~~~~exercism/note
Bit-Arrays werden manchmal in einem anderen Format ausgegeben als dem, in dem sie erstellt wurden. Das führt beim Lernen von Bit-Arrays oft zu Verwirrung.
~~~~

Standardmäßig werden Bit-Arrays in Fragmenten von 8 Bits (einem Byte) dargestellt, auch wenn du sie mit Fragmenten einer anderen Größe erstellt hast.

```gleam
<<2011:11>>
// -> <<251, 3:size(3)>>
```

Wenn du ein Bit-Array erstellst, das einen druckbaren, UTF-8-kodierten String darstellt, kann es von Funktionen wie `io.debug` als String ausgegeben werden. Das liegt an einem Implementierungsdetail, wie Gleam Strings intern darstellt.

```gleam
<<>>
// -> ""

<<65, 66, 67>>
// -> "ABC"
```
