# Ergänzung zu den Anweisungen

## Wörter

Definiere ein Tupel `game` und einen Konstruktor `<game> ( -- game )`, der ein neues Spiel ohne Würfe zurückgibt.

Stelle die folgenden Wörter bereit, die auf einem Spiel arbeiten:

- `roll ( pins game -- )` – notiert, dass `pins` Pins umgeworfen wurden. Löse einen Fehler aus, wenn der Wurf ungültig ist:
  - `"Negative roll is invalid"` bei einer negativen Anzahl Pins.
  - `"Cannot roll after game is over"`, sobald alle zehn Frames (und eventuelle Fill-Balls) geworfen wurden.
  - `"Pin count exceeds pins on the lane"`, wenn mehr Pins umgeworfen werden, als noch stehen.
- `score ( game -- n )` – die Gesamtpunktzahl für das Spiel. Löse `"Score cannot be taken until the end of the game"` aus, wenn das Spiel noch nicht abgeschlossen ist.

Beachte, dass `roll` das Shuffle-Wort `roll` aus dem Vokabular `kernel` verdeckt. Die Testsuite löst die Mehrdeutigkeit mit `FROM: bowling => roll ;` auf.
