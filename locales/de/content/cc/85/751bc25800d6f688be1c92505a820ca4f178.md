# Funktionen wiederverwenden

Wenn du wartbaren Code schreiben willst, hilft es, eine bereits geschriebene Funktion wiederzuverwenden.

Verwende vorhandene Funktionen wieder:
- `initial/1` kann `first_letter/1` wiederverwenden
- `initials/1` kann `initial/1` wiederverwenden
- `pair/2` kann `initials/1` wiederverwenden
