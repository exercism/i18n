# Über

Boolesche Werte werden in C++ durch den Typ `bool` dargestellt.
Ein `bool` ist entweder `true` oder `false`.

## Logische Operatoren

C++ unterstützt drei boolesche Operatoren: `!` (NICHT), `&&` (UND) und `||` (ODER).
Du kannst auch die alternativen Varianten `not`, `and` und `or` verwenden.

```cpp
true || false // => true
true && false // => false
!true // => false
not false // => true
```

## Rangfolge

Die drei booleschen Operatoren haben jeweils eine unterschiedliche _Operatorrangfolge_.
Daher werden sie in dieser Reihenfolge ausgewertet: zuerst `!`, dann `&&` und schließlich `||`.
Wenn du eine andere Reihenfolge erzwingen willst, kannst du einen booleschen Ausdruck in runde Klammern setzen (d. h. `()`), denn die Klammern haben eine noch höhere Operatorrangfolge.

```cpp
!true && false   // => false
!(true and false) // => true
```

## Umwandlung

Wenn du `true` oder `false` an einer Stelle verwendest, an der eine Zahl erwartet wird, werden sie in `1` bzw. `0` umgewandelt.
Wenn du eine Zahl in einer booleschen Operation verwendest, wird alles außer `0` als `true` behandelt, sogar negative Werte.

```cpp
!true && 0.0   // => false
true + true + false // => 2
```
