# Anweisungen

In dieser Übung arbeitest du mit Sparkonten.
Jedes Jahr wird der Kontostand deines Sparkontos auf Basis seines Zinssatzes aktualisiert.
Der Zinssatz, den deine Bank dir gibt, hängt vom Betrag auf deinem Konto ab (dem Kontostand):

- 3,213 % für einen negativen Kontostand (der Kontostand wird negativer).
- 0,5 % für einen positiven Kontostand von weniger als `1000` Dollar.
- 1,621 % für einen positiven Kontostand von mindestens `1000` Dollar und weniger als `5000` Dollar.
- 2,475 % für einen positiven Kontostand von mindestens `5000` Dollar.

Du hast vier Aufgaben, von denen sich jede mit deinem Kontostand und seinem Zinssatz befasst.

## 1. Berechne den Zinssatz

Implementiere die Methode `SavingsAccount.interest_rate()`, die einen Kontostand als Argument entgegennimmt.
Die Methode soll den Zinssatz für den gegebenen Kontostand zurückgeben.

```Crystal
SavingsAccount.interest_rate(200.75)
# => 0.5
```

## 2. Berechne die Zinsen

Implementiere die Methode `SavingsAccount.interest()`, die einen Kontostand als Argument entgegennimmt.
Die Methode soll die Zinsen für den gegebenen Kontostand zurückgeben.

```Crystal
SavingsAccount.interest(200.75)
# => 1.00375
```

## 3. Berechne die jährliche Aktualisierung des Kontostands

Implementiere die Methode `SavingsAccount.annual_balance_update()`, die einen Kontostand als Argument entgegennimmt.
Die Methode soll den Kontostand nach einem Jahr zurückgeben.

```Crystal
SavingsAccount.annual_balance_update(200.75)
# => 201.75375
```

## 4. Berechne die Jahre bis zum Erreichen des gewünschten Kontostands

Implementiere die Methode `SavingsAccount.years_before_desired_balance()`, die einen Kontostand und einen Zielkontostand als Argumente entgegennimmt.
Die Methode soll die Anzahl der Jahre zurückgeben, die es dauern würde, den Zielkontostand zu erreichen.

```Crystal
balance = 200.75
target_balance = 214.88
SavingsAccount.years_before_desired_balance(balance, target_balance)
# => 14
```

~~~~exercism/note
Wenn du einfache Zinsen auf ein Kapital anwendest, wird das Kapital mit dem Zinssatz multipliziert, und das Produkt der beiden ist der Zinsbetrag.

Zinseszinsen hingegen entstehen dadurch, dass du Zinsen wiederholt anwendest.
Bei jeder Anwendung berechnest du den Zinsbetrag und addierst ihn zum Kapital, sodass nachfolgende Zinsberechnungen auf ein größeres Kapital angewendet werden.
~~~~
