# Einführung

PowerShell ist eine dynamisch implizit typisierte Skriptsprache von Microsoft (sie unterstützt auch stark typisierte Variablen), die sich vor allem auf die Automatisierung von Aufgaben und die Konfigurationsverwaltung konzentriert.

PowerShell unterstützt imperative, funktionale und objektorientierte Programmierung und sogar den Pipeline-Stil.

PowerShell wurde auf der .NET-Plattform aufgebaut und 2006 erstmals veröffentlicht.
Es ist standardmäßig in allen modernen Windows-Versionen enthalten und lässt sich auf Mac und Linux installieren.


## Variablen

Es gibt zwei übliche Wege, eine Variable in PowerShell zu definieren.

Ein Variablenname in PowerShell muss mit `$` beginnen, und mit dem Zuweisungsoperator `=` bindest du den Variablennamen an einen Wert.

```powershell
> $intVar = 1
> $doubleVar = 2.0
> $stringVar = "Hello"

# Checking a variable type using the GetType() method
> Write-Host $doubleVar.GetType()
System.Double
```

Du kannst den Typ einer Variablen auch explizit angeben, wenn du einen bestimmten [Typ][strong typed] erzwingen willst.
PowerShell versucht nach besten Kräften, den Wert von einem Typ in einen anderen umzuwandeln, wenn das möglich ist.

```powershell
# String represents a floating number can be converted to integer
> [int]$staticOne = "1.234"
> $staticOne
1

# String of letters can not be converted to double type
> [double]$staticTwo = "hello"
MetadataError: Cannot convert value "hello" to type "System.Double"
```


### Konstanten

Konstanten sind in PowerShell schreibgeschützte Variablen, die nach ihrer Definition nicht **entfernt** werden können.
Das führt uns zum zweiten Weg, Variablen zu definieren: mit dem Cmdlet `New-Variable`.

```powershell
> New-Variable -Name "MyConstant" -Value 100 -Option Constant
> $MyConstant
```

Einen ausführlicheren und fortgeschritteneren Weg, eine neue Variable mit verschiedenen Optionen zu erstellen, findest du im Cmdlet [New-Variable][New-Variable].


## Funktionen

[Funktionen][functions] werden in PowerShell mit dem Schlüsselwort `function` definiert.
Jede Funktion kann null oder mehr formale [Parameter][parameters] in runden Klammern `()` haben, gefolgt von ihrem eigenen [Gültigkeitsbereich][scope], der mit `{` beginnt und mit `}` endet.

```powershell
function Greeting {
    return "Hello!"
}
```

Funktionen in PowerShell können Werte explizit über das Schlüsselwort `return` zurückgeben, nachdem sie mit der Syntax `FuncName $Arg` aufgerufen wurden.

```powershell
function AddTwoNumbers($NumOne, $NumTwo):
    $result = $NumOne + $NumTwo
    return $result

> AddTwoNumbers 10 20
30
```

Wie du eine ausführliche Funktionsdefinition schreibst und wie Funktionen Werte implizit zurückgeben können, behandeln wir im Konzeptmodul `Functions`.


## Kommentare

Ein einzeiliger Kommentar beginnt in PowerShell mit einem `#` und endet am Zeilenende.
Ein Kommentarblock beginnt in PowerShell mit `<#` und endet mit `#>`.
Eine fortgeschrittene Verwendung von Kommentarblöcken zur Erstellung von Comment-Based Help behandeln wir im Konzeptmodul `Functions`.

```powershell
function Main() {
    #This is a comment
}
```
