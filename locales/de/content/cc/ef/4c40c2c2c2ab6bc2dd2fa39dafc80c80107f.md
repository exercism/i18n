# Konzepte von Armstrong-Zahlen

> Eine [Armstrong-Zahl](https://en.wikipedia.org/wiki/Narcissistic_number) ist eine Zahl, die gleich der Summe ihrer eigenen Ziffern ist, wenn man jede Ziffer mit der Anzahl der Ziffern potenziert.

## Beispiellösung

```rust
pub fn is_armstrong_number(num: u32) -> bool {
    let digits = format!("{}", num);
    digits
        .chars()
        .map(|c| c.to_digit(10).unwrap().pow(digits.len() as u32))
        .sum::<u32>()
    == num
}
```

## Konzepte

- Funktionen: unverzichtbar, um die Lösung zu überprüfen und die Logik zu definieren
- Testsuites: werden benötigt, um die Lösung zu überprüfen
- Ganzzahlen: u32 für Argument und Identitätsprüfungen
- `&str`: wird benötigt, um die Länge der Zahl zu zählen, da Rust streng typisiert ist
- `Option<T>`: wird benötigt, um auf den tatsächlichen Wert von `char::to_digit` zuzugreifen
- Typumwandlung: erforderlich, um arithmetische Operationen anzuwenden
- Iterator-Features:
  - Turbofish, um eine Lösung mit einem einzigen Ausdruck zu ermöglichen
  - `map` und `sum`, um den Ausdruck bequem auf das zu reduzieren, was wir überprüfen müssen
