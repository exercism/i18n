# Einführung

## Arrays

Ein `array` in F# ist eine veränderliche Sammlung von null oder mehr Werten mit fester Länge. Das bedeutet, dass sich die Größe eines Arrays nach seiner Erstellung nicht mehr ändern kann, seine Werte aber schon. Alle Werte in einem Array müssen denselben Typ haben. Arrays lassen sich wie folgt definieren:

```fsharp
let empty = [| |]
let emptyAlternative = Array.empty

let singleValue = [| 5 |]
let singleValueAlternative = Array.singleton 5

let threeValues = [| "a"; "b"; "c" |]
```

Über einen Index kannst du Elemente einem Array zuweisen oder aus ihm abrufen. F#-Arrays sind nullbasiert, das heißt, der Index des ersten Elements ist immer null:

```fsharp
let numbers = [| 2; 3; 5 |]

// Update value in array
numbers[2] <- 9

// Read value from array
numbers[2]
// => 9
```

Arrays werden entweder mit Funktionen und Operatoren aus dem `Array`-Modul bearbeitet oder manuell per Musterabgleich mit dem _array_-Muster:

```fsharp
let describe array =
    match array with
    | [| |] -> "Empty"
    | [| 1; 2; three |] -> sprintf "1, 2, %d" three
    | _ -> "Other"

describe [| |]         // => "Empty"
describe [| 1; 2; 4 |] // => "1, 2, 4"
describe [| 5; 7; 9 |] // => "Other"
```

Beim Musterabgleich kannst du einen Wert auch _verwerfen_; wenn dir ein Wert in einem bestimmten Fall _nicht_ wichtig ist (das heißt, du wirst den Wert _nicht verwenden_), kannst du dies mit einem Unterstrich (`'_'`) kennzeichnen:

```fsharp
let describe array =
    match array with
    | [| |] -> "Empty array"
    | [| x |] -> "Array with one item"
    | [| _; y |] -> "Array with two items (first item ignored)"
    | _ -> "Array with many items (all items ignored)"

describe [| |]          // => "Empty array"
describe [| 1 |]        // => "Array with one item"
describe [| 5; 7 |]     // => "Array with two items (first item ignored)"
describe [| 5; 7; 9 |]  // => "Array with many items (all items ignored)"
```

Der einzelne `'_'` sollte beim Musterabgleich immer _zuletzt_ stehen; jeder Wert, der auf keinen der anderen Fälle passt, wird von diesem Fall behandelt.
