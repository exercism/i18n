# Anweisungen

Elena ist die neue Qualitätsmanagerin einer Zeitungsfabrik. Da sie gerade erst im Unternehmen angekommen ist, hat sie beschlossen, einige Prozesse in der Fabrik zu überprüfen, um zu sehen, was verbessert werden könnte.
Sie hat herausgefunden, dass Techniker viele Qualitätsprüfungen von Hand durchführen.
Sie sieht eine gute Gelegenheit für Automatisierung und bittet dich als freiberuflichen Entwickler, eine Software zu entwickeln, um einige der Maschinen zu überwachen.

## 1. Überwache die Luftfeuchtigkeit im Raum

Deine erste Mission ist es, eine Software zu schreiben, die die Luftfeuchtigkeit im Produktionsraum überwacht. Es gibt bereits einen Sensor, der an die Software des Unternehmens angeschlossen ist und regelmäßig die Luftfeuchtigkeit des Raums in Prozent zurückgibt.

Du musst eine Funktion in der Software implementieren, die einen Fehler auslöst, wenn die Luftfeuchtigkeit zu hoch ist.
Die Funktion soll `checkHumidityLevel` heißen und die Luftfeuchtigkeit in Prozent als Parameter entgegennehmen.

Du solltest einen Fehler auslösen (die Meldung ist nicht wichtig), wenn der Prozentsatz 70 % überschreitet.

```javascript
checkHumidityLevel(60);
// => undefined
```

```javascript
checkHumidityLevel(100);
// Throws an error
```

## 2. Überhitzung erkennen

Elena ist sehr zufrieden mit deiner ersten Aufgabe und bittet dich, dich um die Überwachung der Temperatur der Maschinen zu kümmern.
Während du mit einem Techniker namens Greg sprichst, erfährst du, dass die Techniker sich wegen Überhitzung Sorgen machen, wenn die Temperatur einer Maschine 500 °C überschreitet.

Die Maschine ist mit einem Sensor ausgestattet, der ihre Innentemperatur misst.
Du solltest wissen, dass der Sensor sehr empfindlich ist und oft kaputtgeht.
In diesem Fall müssen die Techniker ihn austauschen.

Deine Aufgabe ist es, eine Funktion `reportOverheating` zu implementieren, die die Temperatur als Parameter entgegennimmt und einen Fehler auslöst, wenn der Sensor defekt ist oder die Maschine zu überhitzen beginnt.
Da du später je nach Fehler unterschiedlich reagieren musst, brauchst du einen Mechanismus, um die beiden Fehlerarten zu unterscheiden.
Du könntest dich auf die Fehlermeldungen verlassen, aber das würde deinen Code anfällig machen, denn er würde kaputtgehen, wenn die Meldung aktualisiert wird.
Um das sauber hinzubekommen, löst du Instanzen verschiedener Fehlerklassen aus.

- Wenn der Sensor defekt ist, ist die Temperatur `null`.
  In diesem Fall solltest du einen `ArgumentError` auslösen.
- Wenn alles funktioniert und die Temperatur 500 °C überschreitet, solltest du einen `OverheatingError` auslösen.
  Diese Fehlerklasse wird mit einem Temperatur-Argument instanziiert.
  Stelle sicher, dass der `OverheatingError`, den du auslöst, eine temperature-Eigenschaft hat.

```javascript
reportOverheating(null);
// Throws an ArgumentError
```

```javascript
reportOverheating(800);
// Throws an OverheatingError
```

## 3. Überwache die Maschine

Jetzt, wo deine Maschine Fehler erkennen kann, implementierst du eine Funktion, die auf diese Fehler unterschiedlich reagiert:

- Wenn der Sensor defekt ist, musst du einen Techniker warnen
- Wenn die Temperatur zu hoch ist, schaltest du entweder die Maschine ab, falls die Temperatur 600 °C überschreitet, oder du schaltest eine Warnleuchte ein, wenn sie darunter liegt.
- Wenn ein anderer Fehler auftritt, löst du ihn erneut aus.

Implementiere eine Funktion `monitorTheMachine`, die ein Argument `actions` entgegennimmt.

`actions` ist ein Objekt mit vier Eigenschaften:

| Eigenschaft | Beschreibung |
| --- | --- |
| `check` | eine _*Funktion*_. Überprüft die Temperatur der Maschine. Sie kann verschiedene Fehler auslösen. |
| `alertDeadSensor` | eine _*Funktion*_. Benachrichtigt einen Techniker, dass der Temperatursensor defekt ist. |
| `alertOverheating` | eine _*Funktion*_. Schaltet eine Warnleuchte an der Maschine ein. |
| `shutdown` | eine _*Funktion*_. Schaltet die Maschine aus. |

Die Funktion `monitorTheMachine(actions)` sollte intern `check()` aufrufen.
Wenn das erfolgreich ist, sollte die Funktion nichts zurückgeben.
Wenn dabei `throw` aufgerufen wird, wird ein anderes Verhalten erwartet:

| Ausnahme | erwartetes Verhalten |
| --- | --- |
| `ArgumentError` | die Funktion `alertDeadSensor` aufrufen. |
| `OverheatingError` | das Überhitzungsprotokoll ausführen. |
| _(alles andere)_ | den Fehler erneut auslösen |

**Überhitzungsprotokoll**
Wenn die Temperatur unter 600 °C liegt, schalte die Warnleuchte ein, indem du die Funktion `alertOverheating` aufrufst.
Wenn die Temperatur 600 °C überschreitet, ist die Situation kritisch, also rufe die Funktion `shutdown` auf.

```javascript
monitorTheMachine({
  check,
  alertDeadSensor,
  alertOverheating,
  shutdown,
});
```
