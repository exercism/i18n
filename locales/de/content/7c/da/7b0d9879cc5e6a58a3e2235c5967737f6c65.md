# Einführung

Du kannst einen Methodenparameter optional machen, indem du ihm einen Standardwert zuweist. Wenn du eine Methode mit optionalen Parametern aufrufst, musst du für sie keinen Wert übergeben. Wird für einen optionalen Parameter kein Wert übergeben, wird sein Standardwert verwendet.

Optionale Parameter müssen am Ende der Parameterliste stehen; nach ihnen dürfen keine nicht-optionalen Parameter folgen.

```haxe
class Card {
  static function newYear(year = 2021):String {
    return "Happy " + year;
  }
}

Card.newYear(); // Happy 2020
Card.newYear(1990); // Happy 1990
```

Du kannst den optionalen Parameter auf `null` setzen, indem du den `?`-Operator vor den Variablennamen schreibst:

```haxe
function newYear(?year:Int) {
  if (year != null)
    return "It's " + year;
  return "Year is null";
}

newYear(); // Year is null
```
