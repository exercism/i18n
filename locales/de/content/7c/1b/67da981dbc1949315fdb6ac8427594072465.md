# Hinweise

Bei allen diesen Aufgaben muss die Logzeile in einzelne Teile zerlegt werden.

- Schau dir die Funktion [`split()`][split] an, um die Möglichkeiten zu sehen.

## 1. Nachricht aus einer Logzeile auslesen

- Die Funktion `split()` gibt einen Vektor aus Strings zurück.
- Du musst das passende Element in diesem Vektor holen.
- Führende und nachfolgende Leerzeichen kannst du mit [`strip()`][strip] entfernen.

## 2. Log-Level aus einer Logzeile auslesen

- Die Funktion [`lowercase()`][lowercase] ist hier nützlich.
- Ein ASCII-String kann mit einem Bereich indexiert werden.
- Der Index `end` verweist auf das letzte Element in einem Vektor.
- Alternativ kannst du die Aufgabe lösen, indem du mit [`replace()`][replace] unerwünschte Zeichen entfernst.

## 3. Eine Logzeile neu formatieren

- String-[Interpolation][interpolation] ist hier vielleicht der einfachste Ansatz.
- Alternativ bevorzugen manche (mit Erfahrung in anderen Sprachen) vielleicht [`@sprintf()`][sprintf].
