# Über

[Symbole][symbols] sind benannte Bezeichner, mit denen auf einen Wert verwiesen werden kann.
Symbole werden über ein Symbol-Literal erzeugt, indem man einem Namen ein `:`-Zeichen voranstellt, z. B. `:foo`.
Sie können auch mit Anführungszeichen geschrieben werden, z. B. `:"foo"`, wodurch zum Beispiel Leerzeichen im Namen möglich sind.

```crystal
:foo           # => :foo
:"foo boo"     # => :"foo boo"
:foo == :"foo" # => true
```

Symbole werden in der Sprache an vielen Stellen verwendet, unter anderem als Schlüssel in NamedTuples und um Methoden- und Variablennamen darzustellen.

## Symbole in Crystal

Symbole in Crystal unterscheiden sich stark von Ruby.
In Crystal ist ein Symbol eine Art Konstante und wird daher zur Kompilierzeit zugewiesen.
Das bedeutet, dass Symbole nicht dynamisch erzeugt werden können, was in Ruby möglich ist.

Symbole in Crystal werden als `Int32`-Werte dargestellt, was sie sehr effizient macht.

## Umwandlung

Symbole können in Strings umgewandelt werden, aber nicht umgekehrt.
Der Grund dafür ist, dass Symbole zur Kompilierzeit und Strings zur Laufzeit erzeugt werden.

```crystal
:foo.to_s # => "foo"
```
