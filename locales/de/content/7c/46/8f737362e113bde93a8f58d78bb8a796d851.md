# Einführung

Variablen, die mit dem Schlüsselwort `final` statt mit `var` deklariert werden, kann man nur einmal einen Wert zuweisen.

```haxe
final a = "hello";
var b = "world";
trace(a, b); // hello, world
b = "haxe";
trace(a, b); // hello, haxe

// The following line would cause a compilation error:
// a = "bye";
```
