# Hinweise

## Allgemeines

- In der Standardbibliothek gibt es eine Reihe von Funktionen für boolesche Ausdrücke. Schau sie dir im Namensraum `Boolean` auf [Unison Share](https://share.unison-lang.org/@unison/code/latest/namespaces/public/base/latest/;/types/Boolean) an.
- Die Each-Fähigkeit ermöglicht es dir, mit einer Liste von Elementen so zu arbeiten, als wäre sie ein einziges Element, und die gewünschte Funktion auf jedem Element auszuführen. Du kannst sie auch verwenden, um Kombinationen von Elementen zu erstellen, indem du Each auf zwei verschiedene Listen anwendest.
- Schau dir die [`guard`-Funktion auf `Each`](https://share.unison-lang.org/@unison/code/latest/namespaces/public/base/latest/;/types/abilities/Each) an. Sie kann nützlich sein, wenn du bedingt etwas aus der `Each`-Fähigkeit zurückgeben möchtest.
- Angesichts der Anzahl einzigartiger Kombinationen, die für dieses Problem möglich sind, könntest du auf Probleme mit Speicher- oder Zeitkomplexität stoßen. Es gibt ziemlich viele Mechanismen, um die Suche zu optimieren. Schau dir [Backtracking](https://www.geeksforgeeks.org/backtracking-algorithms/) oder [Branch-and-Bound](https://www.geeksforgeeks.org/branch-and-bound-algorithm/?ref=lbp)-Algorithmen an.
