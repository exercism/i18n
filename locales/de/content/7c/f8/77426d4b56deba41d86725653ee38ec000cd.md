# Website für ein Basketballteam

## Story

Du arbeitest an einer Website für ein Basketballteam. Die Website zeigt viele Daten an, aber leider ändert sich ständig, was angezeigt wird. Da die Daten in einem einzigen Objekt gespeichert sind, ist das nicht schwer, aber zeitaufwendig und langweilig. Deshalb hast du beschlossen, die Sache zu automatisieren.

## Aufgaben

Hier sind Beispiele für Aufgaben, die zur Story der Automatisierung der Website passen:

- Dein Ziel ist es, dem Content-Team zu ermöglichen, selbst auszuwählen, welche Daten angezeigt werden. Das machen sie, indem sie im Content-Editor der Website einen Pfad zu den Daten angeben, die angezeigt werden sollen. Deine Aufgabe ist es, eine Funktion extract zu erstellen, die ein Objekt und einen Pfad entgegennimmt, getrennt durch einen Punkt. Gib den Wert an diesem Pfad zurück oder einen Standardwert.

## Zusätzliche Aufgaben

Die Story lässt sich fortsetzen, zum Beispiel:

- Das Content-Team ist von dieser neuen Funktionalität sehr begeistert und hat schon ein neues Feature angefragt. Es möchte die Daten bestimmter Elemente in einem Array anzeigen können.
