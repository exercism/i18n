# Einführung

Zwar können `if/else`-Ausdrücke verwendet werden, um bedingte Logik auszuführen, aber Haskell bietet auch einen mächtigeren Weg dafür: [Musterabgleich][pattern-matching].
Beim Musterabgleich kann ein Wert gegen ein oder mehrere _Muster_ geprüft werden.
Ein Beispiel für ein solches Muster ist das _Konstantenmuster_, das einen Wert mit einer Konstante abgleicht (z. B. `1` oder `"hello"`).

Beim Definieren von Funktionen kannst du für verschiedene Muster separate Funktionskörper definieren.
Das führt zu sauberem Code, der einfach und lesbar ist.
Du kannst Musterabgleich auf jeden Datentyp anwenden: Zahlen, Zeichen, Listen, Tupel usw.

Eine triviale Funktion, die eine Ganzzahl (`Int`) entgegennimmt und sie um _1_ näher an _0_ bringt, könnte beispielsweise so aussehen:

```haskell
closerToZero :: Int -> Int
closerToZero 0 = 0
closerToZero 1 = 0
```

Musterabgleich zeigt seine Stärke, wenn er zusammen mit anderen Mustern verwendet wird, zum Beispiel dem _Variablenmuster_:

```haskell
closerToZero :: Int -> Int
closerToZero 0 = 0
closerToZero n = n - 1
```

Das obige Beispiel behandelt alle Eingabewerte außer _0_ gleich und würde für negative Zahlen falsche Ergebnisse liefern.
Das lässt sich mit bedingten Mustern lösen, den sogenannten _Guards_, die mit dem Symbol `|` notiert werden:

```haskell
closerToZero :: Int -> Int
closerToZero n
    | n < 0 = n + 1
    | n > 0 = n - 1
```

In den obigen Beispielen haben nicht alle möglichen Eingabewerte ein passendes Muster.
Der Compiler erkennt das und gibt eine Warnung aus.
Das ist eine sehr nützliche Eigenschaft von Haskell, die dabei hilft, alle möglichen Pfade abzudecken, um Laufzeitfehler zu vermeiden.
Sie ist als _Vollständigkeitsprüfung_ bekannt.
Um die Warnung zu beheben, musst du alle Fälle behandeln.
Innerhalb von _Guards_ kannst du den Ausdruck `otherwise` als syntaktischen Zucker für `True` verwenden, um alle verbleibenden Muster abzufangen.

```haskell
closerToZero :: Int -> Int
closerToZero n
    | n < 0 = n + 1
    | n > 0 = n - 1
    | otherwise = 0
```

Der Musterabgleich prüft einen Wert von oben nach unten gegen jedes Muster, bis er ein passendes Muster findet und die zugehörige Logik ausführt.
**Die Reihenfolge der Muster ist wichtig!**
