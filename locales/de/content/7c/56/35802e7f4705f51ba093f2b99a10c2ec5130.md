# Einführung

Alle Common-Lisp-Objekte sind entweder „Atome“ (einzelne, unteilbare Werte) oder „Conses“ (die durch die Konstruktionsfunktion „cons“ erzeugt werden).
Ein Cons besteht aus zwei Teilen: dem ersten Element und dem Rest der Elemente.
Aus historischen Gründen heißen diese beiden Teile `car` und `cdr`.
Wenn diese Conses als Code ausgewertet werden, repräsentiert das erste Element (`car`) die aufgerufene Funktion, während der Rest der Elemente
(`cdr`) die Argumente dieser Funktion repräsentiert:

```lisp
(<function> <arg1> <arg2> ... <argN>)
; ^ car ^  |        ^ cdr ^
```
