# Über

## Optionals

Swift verwendet [_Optionals_][optionals], damit Programmierer die mögliche Abwesenheit eines Werts ausdrücken können. Ein Optional ist ein Typ, der entweder einen Wert enthält oder [`nil`][nil] ist, was die Abwesenheit eines Werts darstellt. Um ein Optional zu verwenden, muss ein Programm prüfen, ob tatsächlich ein Wert vorhanden ist, bevor es ihn nach dem Auspacken benutzt.

Jeder Typ kann zu einem Optional gemacht werden, indem du ein `?` ans Ende des Typnamens anhängst. Eine optionale Ganzzahl hätte also den Typ `Int?` und ein optionaler String den Typ `String?`. Konstanten oder Variablen eines optionalen Typs zu definieren und ihnen Werte zuzuweisen, funktioniert genauso wie bei Werten nicht-optionaler Typen.

```swift
let x: Int? = 42
var y: String? = "Hello"
y = "Goodbye"
```

Du kannst einer Variable eines optionalen Typs die Abwesenheit eines Werts zuweisen, indem du ihr den speziellen Wert `nil` zuweist. `nil` kann mit allen optionalen Typen verwendet werden, aber `nil`, das zwei verschiedenen optionalen Typen zugewiesen wird, hat nicht denselben Typ und kann weder ausgetauscht noch verglichen werden.

```swift
let intOpt: Int? = nil
let stringOpt: String? = nil

intOpt = stringOpt
// Compiler error: Cannot assign value of type 'String?' to type 'Int?'

intOpt == stringOpt
// Compiler error: Binary operator '==' cannot be applied to operands of type 'Int?' and 'String?'
```

Beachte außerdem, dass `nil` zwar jedem optionalen Typ zugewiesen werden kann, aber nicht einem nicht-optionalen Typ (auch wenn dieser nicht wirklich `nil` enthält). Und Methoden, die einen nicht-optionalen Typ erwarten, kann kein optionaler Typ übergeben werden, ohne ihn vorher auszupacken.

```swift
var x: Int = 42
var y: Int? = 42

y = x
// Works fine
x = y
// error: value of optional type 'Int?' must be unwrapped to a value of type 'Int'
x + y
// error: value of optional type 'Int?' must be unwrapped to a value of type 'Int'
```

## Optionals verwenden

Da optionale Typen nicht dieselben Typen wie ihre Basistypen sind, können die beiden Typen nicht auf dieselbe Weise verwendet werden. Zum Beispiel führt `Int("123") + 1` zu einem Compilerfehler: „Value of optional type 'Int?' must be unwrapped to a value of type 'Int'". Das liegt daran, dass `Int("123")` einen optionalen Typ `Int?` zurückgibt und nicht den Typ `Int`, denn wenn der String nicht in eine Ganzzahl umgewandelt werden kann, ist das Ergebnis `nil`. Um aus der Umwandlung an die `Int` zu gelangen, musst du sie zuerst „auspacken".

In Swift machst du das am häufigsten mit den Konstrukten `if-let` und `guard-let` für [_optionales Binden_][optional-binding]. Sie prüfen auf `nil` und nehmen einen Codepfad, bei dem der ausgepackte Wert an einen angegebenen Namen gebunden wird, wenn ein Wert vorhanden ist, und einen anderen Codepfad, wenn `nil` gefunden wurde.

```swift
if let safeNum = Int("123") {
	let sum = safeNum + 1
	…
} else {
  // code for the case where nil was found -- may be left out
}
```

Es ist erwähnenswert, dass die Variable `safeNum` den Typ `Int` und nicht `Int?` hat. Im folgenden Beispiel hat `num` den Typ `Int?` und `safeNum` den Typ `Int`.

```swift
let num = Int("123")
if let safeNum = num {
  // num is of type Int
}
```

Dieses _optionale Binden_ ist wichtig, weil es den optionalen Typ aus dem Wert auspackt (oder „entfernt"), sodass er als nicht-optionaler Wert verwendet werden kann. Wenn du nur bedingt prüfst, ob der Wert `nil` ist, bleibt der Wert weiterhin vom optionalen Typ:

```swift
let num = Int("123")
if num != nil {
  // num is of type Int?
}
```

Die `guard-let`-Option kannst du auch in Fällen verwenden, in denen du früh zurückkehren möchtest:

```swift
guard let num = Int("123") else { return nil }
let sum = num + 1
…
```

## Optionals vergleichen

Beachte, dass die Optionals selbst nicht verglichen werden können, auch wenn der Basistyp eines Paars von Optionals mit den Standard-Vergleichsoperatoren verglichen werden kann. Sie können nur auf Gleichheit geprüft werden. Zwei Optionals sind gleich, wenn beide `nil` sind oder wenn die Werte, die sie umschließen, innerhalb ihrer Basistypen gleich sind.

Du kannst jedoch Code schreiben, der einen benutzerdefinierten Vergleich zweier optionaler Werte durchführt. Unten ist ein Beispiel für eine `switch`-Anweisung, die nur dann `true` zurückgibt, wenn beide optionalen Werte nicht-nil sind und der erste Wert kleiner als der zweite ist. Dazu verwendet sie das _optionale Muster_ `varName?`, das nur nicht-nil Optionals abgleicht und den Wert innerhalb des Optionals an den Namen `varName` bindet.

```swift
switch (optionalA, optionalB) {
case let (valA?, valB?): return valA < valB
default: return false
}
```
