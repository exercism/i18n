# Anleitung

Deine Aufgabe ist es, in einem fertigen Minesweeper-Spielfeld die Minenzahlen in die leeren Felder einzutragen. Das Spielfeld selbst ist ein Rechteck aus Feldern, die entweder leer (`' '`) oder eine Mine (`'*'`) sind.

Für jedes leere Feld zählst du die Anzahl der Minen, die daran angrenzen (horizontal, vertikal und diagonal). Wenn das leere Feld keine angrenzenden Minen hat, lass es leer. Andernfalls ersetzt du es durch die Anzahl der angrenzenden Minen.

Zum Beispiel bekommst du vielleicht ein 5 x 4 großes Spielfeld wie dieses (die leeren Felder werden hier zur Anzeige auf dem Bildschirm mit dem Zeichen '·' dargestellt):

```text
·*·*·
··*··
··*··
·····
```

Dein Code soll daraus dieses machen:

```text
1*3*1
13*31
·2*2·
·111·
```
