# Überblick

C# ist eine statisch typisierte Sprache, das heißt, alles hat zur Kompilierzeit einen Typ. Wenn du einen Namen für eine [Variable][variable] wählst, nennt man das Definieren einer Variable. Sobald eine Variable definiert ist, nennt man das Setzen oder Aktualisieren eines Werts eine Zuweisung. Du kannst eine Variable definieren, indem du ihren Typ explizit angibst, oder indem du das [`var`-Schlüsselwort][var] verwendest, damit der C#-Compiler ihren Typ anhand des zugewiesenen Werts ableitet. Die Verwendung von `var` nennt man _Typinferenz_.

```csharp
int explicitVar = 10; // Explicitly typed
var implicitVar = 10; // Implicitly typed
```

Den Wert einer Variable kannst du mit dem [`=`-Operator][assignment] zuweisen und aktualisieren. Sobald sie definiert ist, kann sich der Typ einer Variable nie mehr ändern.

```csharp
var count = 1; // Assign initial value
count = 2;     // Update to new value

// Compiler error when assigning different type
// count = false;
```

C# ist eine objektorientierte Sprache und verlangt, dass alle [Funktionen][function] in einer _Klasse_ definiert werden. Klassen definierst du mit dem [`class`-Schlüsselwort][classes]. Objekte (oder _Instanzen_) erstellst du mit dem `new`-Schlüsselwort.

```csharp
class Calculator
{
    // ...
}

var calculator = new Calculator();
```

Eine Funktion innerhalb einer Klasse nennt man _Methode_. Jede [Methode][methods] kann null oder mehr Parameter haben. Alle Parameter müssen explizit typisiert sein, für Parameter gibt es keine Typinferenz. Ebenso muss auch der Rückgabetyp explizit angegeben werden. Werte gibst du mit dem [`return`-Schlüsselwort][return] aus Methoden zurück. Damit Code in anderen Dateien eine Methode aufrufen kann, musst du den Zugriffsmodifizierer `public` hinzufügen.

```csharp
class Calculator
{
    public int Add(int x, int y)
    {
        return x + y;
    }
}
```

Methoden rufst du mit der Punkt-Syntax (`.`) auf einer Instanz auf. Dabei gibst du den Namen der Methode an und übergibst Argumente für jeden Parameter der Methode. Argumente können optional den Namen des zugehörigen Parameters angeben.

```csharp
var calculator = new Calculator();
var sum_v1 = calculator.Add(1, 2);
var sum_v2 = calculator.Add(x: 1, y: 2);
```

Ist die aufzurufende Methode in derselben Klasse definiert wie die aufrufende Methode, kannst du den Klassennamen weglassen.

Wenn eine Methode keinen Objekt-_Zustand_ verwendet, kannst du sie mit dem `static`-Modifizierer _statisch_ machen. Statische Methoden rufst du ebenfalls mit der Punkt-Syntax (`.`) auf, aber auf der Klasse selbst statt auf einer Instanz der Klasse.

Wenn eine Klasse nur statische Methoden hat, kannst du auch sie mit dem `static`-Modifizierer statisch machen. Das drückt die Absicht der Klasse aus.

```csharp
static class Calculator
{
    public static int Multiply(int x, int y)
    {
        return x * y;
    }
}

Calculator.Multiply(2, 4); // => 8
```

Der Gültigkeitsbereich in C# wird zwischen den Zeichen `{` und `}` definiert.

C# unterstützt zwei Arten von [Kommentaren][comments]. Einzeilige Kommentare beginnen mit `//`, mehrzeilige Kommentare stehen zwischen `/*` und `*/`.

Ganzzahlwerte werden als eine oder mehrere (aufeinanderfolgende) Ziffern definiert und unterstützen die [üblichen mathematischen Operatoren][operators].

Ein Variablenname [muss bestimmten Regeln folgen][identifier-names], etwa mit einem Buchstaben oder einem Unterstrich beginnen, und [sollte den C#-Namenskonventionen folgen][naming-guidelines]. Wenn ein Variablenname mit einem reservierten [C#-Schlüsselwort][csharp-keywords] kollidiert, musst du ihn mit `@` escapen. Diese Schreibweise ist nicht empfehlenswert, aber in Ausnahmefällen kann sie dir begegnen, zum Beispiel: `var @this`, `var @class` oder `var @var`.

Ein paar Konzepte sind für eine Sprache aus der C-Familie wie C# so grundlegend, dass sie in fast jedem nichttrivialen Codestück ganz natürlich vorkommen. Das sind [Mutation][mutation] und [Gültigkeitsbereich][scope]. Mutation bedeutet, dass sich der Wert einer Variable im Laufe der Laufzeit eines Programms ändern kann. Gültigkeitsbereich bedeutet, dass ein Wert, der mit einem Namen (eines Programmelements) verknüpft ist, nur in dem Code-„Bereich“ zugänglich ist, in dem er definiert wird. Die wichtigsten Codebereiche in C# sind _Klassen/Structs_ und _Funktionen_ (typischerweise Methoden), sie können aber auch Schleifenblöcke und andere Konstrukte umfassen.
