# Über

Eine statische Erweiterung ermöglicht es, bestehende Typen pseudo zu erweitern, ohne deren Quellcode zu ändern. Das gelingt mit der `using`-Anweisung. Statische Erweiterungen können ein mächtiges Werkzeug sein, mit dem du Typen erweitern kannst, ohne sie tatsächlich zu verändern.

```haxe
using Main.IntExtender;

class Main {
  public static function main() {
    trace(2.triple()); // 6
  }
}

class IntExtender {
  public static function triple(i:Int):Int {
    return i * 3;
  }
}
```
