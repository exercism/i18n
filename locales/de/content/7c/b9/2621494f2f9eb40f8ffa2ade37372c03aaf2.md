# Anweisungen

Leslie, das Lisp-Alien, muss einkaufen gehen. Eine Einkaufsliste ist dabei sehr wichtig. Man muss Dinge hinzufügen und wieder entfernen.

Natürlich reichen Stift und Papier für ein Lisp-Alien nicht aus. „List“ ist sogar fast das ganze Wort „Lisp“! Also braucht es ein paar Funktionen, die die Einkäufe im Blick behalten.

Kannst du Leslie helfen, die Einkaufsliste im Blick zu behalten?

## 1. Eine neue Liste erstellen

Zuerst braucht Leslie eine leere Liste. Eine Funktion namens `new-list` wäre dafür perfekt.

```lisp
(new-list) ; => ()
```

Oh nein... Leslie hat schon ein paar Dinge im Kopf, also braucht Leslie eine Funktion, die drei Dinge entgegennimmt (zum Glück erstellt Leslie nur Listen mit drei Dingen. Nicht mehr und nicht weniger!) und daraus eine neue Einkaufsliste macht. Schreib eine Funktion `list-of-things`, die drei Dinge entgegennimmt und eine Liste daraus zurückgibt.

```lisp
(list-of-things 'bread 'milk 'butter) ; => '(bread milk butter)
```

## 2. Dinge zur Liste hinzufügen.

Bevor Leslie in den Laden geht, schaut Leslie in die Speisekammer, um zu sehen, was gebraucht wird. Hilf Leslie, indem du die Funktion `add-to-list` schreibst, die ein Element am Anfang einer Liste hinzufügt.

```lisp
(add-to-list 'butter '(bread)) ; => '(butter bread)
```

## 3. Was steht als Nächstes auf der Liste?

Beim Einkaufen möchte Leslie wissen, wonach als Nächstes zu suchen ist. Außerdem schaut Leslie gern in der Liste voraus, um das zweite, dritte oder sogar das 23. Ding zu sehen (die Glückszahl von Leslie).

- `first-thing` ergibt das erste Ding auf der Liste
- `second-thing` ergibt das zweite Ding
- `third-thing` ergibt das dritte Ding
- `twenty-third-thing` ergibt das dreiundzwanzigste Ding

```lisp
(first-thing '(bread butter milk)) ; => 'bread
(second-thing '(bread butter milk)) ; => 'butter
(third-thing '(bread butter milk)) ; => 'milk
```

## 4. Ein Ding von der Liste entfernen

Leslie möchte das erste Element der Liste finden und es aus dem Regal nehmen. Hilf Leslie, indem du eine Funktion `remove-first-item` schreibst, die eine Liste ergibt, die alles außer dem ersten Element der Eingabeliste enthält.

```lisp
(remove-first-item '(bread butter milk)) ; => '(butter milk)
```

## 5. Größere Listen aus kleineren Listen

Leslie hat bemerkt, dass aus Versehen zwei Einkaufslisten statt einer entstanden sind! Schreib eine Funktion `list-append`, die eine Liste zurückgibt, die zuerst die Elemente der ersten Liste und danach die der zweiten Liste enthält.

```lisp
(list-append '(bread salt) '(butter milk)) ; => '(bread salt butter milk)
```

## 6. Wie lange noch?

Leslie macht sich langsam Sorgen, dass dieser Einkaufsbummel eine Weile dauern wird. Wie viele Dinge stehen überhaupt auf dieser Liste? Schreib eine Funktion `just-how-long`, die Leslie verrät, wie lang die Liste ist.

```lisp
(just-how-long '(bread milk butter salt)) ; => 4
```
