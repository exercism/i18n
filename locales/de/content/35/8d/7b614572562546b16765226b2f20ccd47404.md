# Spezifikation verwenden

[comment]: # (Diese Warnung wird ausgegeben, wenn die Lösung keine Typspezifikation enthält)

Gib [Typspezifikationen](https://elixir-lang.org/getting-started/typespecs-and-behaviours.html#types-and-specs) (`@spec`) an, um den Vertrag zwischen den Eingabewerten und dem Rückgabewert einer Funktion zu verdeutlichen.

- Elixir ist eine dynamisch typisierte Sprache. Das bedeutet, dass Typprüfungen erst zur Laufzeit stattfinden. Mit Typspezifikationen können Linter und statische Analysewerkzeuge wie [`Dialyxir`](https://hexdocs.pm/dialyxir/readme.html) (basiert auf Erlangs [`Dialyzer`](http://erlang.org/doc/man/dialyzer.html)) den Code auf unbeabsichtigtes Verhalten hin untersuchen.
- Eine [vollständige Liste](https://hexdocs.pm/elixir/typespecs.html#basic-types) aller eingebauten Typen findest du in der [Sprachdokumentation](https://hexdocs.pm/elixir/typespecs.html#content).
- Typen kannst du mit oder ohne runde Klammern angeben, also `atom()` oder `atom`
  - Im Elixir-Stil von Exercism werden sie ohne Klammern angegeben.

```elixir
# Example 1
@spec add_one(int) :: int
def add_one(n) when is_integer(n) do
  n + 1
end

# Example 2
@spec hello(String.t) :: String.t
def hello(what \\ "world") when is_binary(what) do
  "Hello, #{what}"
end
```
