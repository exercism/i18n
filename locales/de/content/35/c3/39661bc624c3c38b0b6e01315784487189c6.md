# Anleitung

In dieser Übung schreibst du etwas Code, um dich auf den Kauf eines Fahrzeugs vorzubereiten.

Du hast drei Aufgaben: Finde heraus, ob du einen Führerschein brauchst; wähle zwischen zwei Fahrzeugen; und schätze den angemessenen Preis für ein gebrauchtes Fahrzeug.

## 1. Finde heraus, ob du einen Führerschein brauchst

Manche Fahrzeugarten erfordern einen Führerschein, um sie zu fahren.
Gehe davon aus, dass nur die Arten `"car"` und `"truck"` einen Führerschein erfordern; alles andere kann ohne Führerschein gefahren werden.

Implementiere die Funktion `needs_license`, die die Fahrzeugart entgegennimmt und einen booleschen Wert zurückgibt, der angibt, ob du für diese Fahrzeugart einen Führerschein brauchst.

```jq
"car" | needs_license
# => true

"bike" | needs_license
# => false
```

## 2. Wähle zwischen zwei möglichen Fahrzeugen, die du kaufen könntest

Du hast deine Optionen an verfügbaren Fahrzeugen geprüft.
Du hast sie auf zwei Optionen eingegrenzt, aber du brauchst Hilfe bei der endgültigen Entscheidung.
Implementiere die Funktion `choose_vehicle`, die ein Array mit zwei Fahrzeugen als Eingabe entgegennimmt und eine Entscheidung zurückgibt: die Option, die in lexikografischer Reihenfolge zuerst kommt.

```jq
["Wuling Hongguang", "Toyota Corolla"] | choose_vehicle
# =>  "Toyota Corolla is clearly the better choice."

["Volkswagen Beetle", "Volkswagen Golf"] | choose_vehicle
# =>  "Volkswagen Beetle is clearly the better choice."
```

## 3. Berechne eine Schätzung für den Preis eines gebrauchten Fahrzeugs

Jetzt, wo du deine Entscheidung getroffen hast, willst du sichergehen, dass du beim Händler einen fairen Preis bekommst.
Da du ein gebrauchtes Fahrzeug kaufen möchtest, hängt der Preis davon ab, wie alt das Fahrzeug ist.
Für eine grobe Schätzung gehst du davon aus, dass ein Fahrzeug, das weniger als 3 Jahre alt ist, 80 % des ursprünglichen Preises kostet, den es neu hatte.
Ist es älter als 10 Jahre, kostet es 50 %.
Ist das Fahrzeug mindestens 3 Jahre alt, aber nicht älter als 10 Jahre, kostet es 70 % des ursprünglichen Preises.

Implementiere die Funktion `resell_price`, die diese Logik mit `if`, `elif` und `else` anwendet.
Sie nimmt ein Objekt entgegen, das den ursprünglichen Preis und das Alter des Fahrzeugs enthält, und gibt den geschätzten Preis beim Händler zurück.

```jq
{"original_price": 1000, "age": 1} | resell_price
# => 800

{"original_price": 1000, "age": 5} | resell_price
# => 700

{"original_price": 1000, "age": 15} | resell_price
# => 500
```
