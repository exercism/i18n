# Anleitung

Deine Aufgabe ist es, RNA-Sequenzen in Proteine zu übersetzen.

RNA-Stränge bestehen aus Sequenzen von drei Nukleotiden, den sogenannten **Codons**.
Jedes Codon steht für eine **Aminosäure**.
Aneinandergereiht bilden diese Aminosäuren ein Protein.

In der Realität gibt es 64 Codons, die wiederum 20 Aminosäuren entsprechen.
Für diese Übung verwendest du jedoch nur einige der 64 Möglichkeiten.
Sie sind unten aufgeführt:

| Codon              | Aminosäure    |
| ------------------ | ------------- |
| AUG                | Methionine    |
| UUU, UUC           | Phenylalanine |
| UUA, UUG           | Leucine       |
| UCU, UCC, UCA, UCG | Serine        |
| UAU, UAC           | Tyrosine      |
| UGU, UGC           | Cysteine      |
| UGG                | Tryptophan    |
| UAA, UAG, UGA      | STOP          |

Zum Beispiel hat der RNA-String „AUGUUUUCU“ drei Codons: „AUG“, „UUU“ und „UCU“.
Diese stehen für Methionine, Phenylalanine und Serine.

## „STOP“-Codons

In der Tabelle oben siehst du, dass es drei **„STOP“-Codons** gibt.
Wenn du auf eines dieser Codons stößt, ignoriere den Rest der Sequenz: Das Protein ist vollständig.

Zum Beispiel enthält „AUGUUUUCUUAAAUG“ ein STOP-Codon („UAA“).
Sobald wir an diese Stelle gelangen, hören wir mit der Verarbeitung auf.
Wir betrachten also nur den Teil davor (d. h. „AUGUUUUCU“) und keine weiteren Codons danach (d. h. „AUG“).
