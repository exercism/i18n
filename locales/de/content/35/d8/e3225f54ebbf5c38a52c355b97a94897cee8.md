# Einführung

In dieser Übung geht es um einige Details von Methodenparametern und ihre Verwendung in C#.

Parameter übermitteln Informationen von einer aufrufenden Methode an eine aufgerufene Methode.

- Das Verhalten von Parametern lässt sich durch Modifizierer wie `ref` und `out` ändern.

- Ein Parameter mit dem Modifizierer `out` übermittelt einen Wert von der aufgerufenen Methode zurück an den Aufrufer. Der Parameter kann an die aufgerufene Methode übergeben werden, ohne initialisiert zu sein, und wird in der aufgerufenen Methode auf jeden Fall so behandelt, als wäre er beim Eintritt nicht initialisiert worden. Das Verhalten und die Regeln zu Parameter-Modifizierern versteht man am leichtesten anhand von Beispielen (siehe unten) und Compiler-Meldungen.

```csharp
void Foo(out int val)
{
    val = 42;
}
void Bar(int val)
{
    val = 42;
}

int importantValue = 1729;
Foo(out importantValue);
var result = importantValue == 42;
// => true

importantValue = 1729;
Bar(importantValue);
result = importantValue == 1729;
// => true
```

- `out`-Parameter müssen innerhalb einer aufgerufenen Methode zugewiesen werden.

- Ein Parameter mit dem Modifizierer `ref` übergibt einen Wert an eine aufgerufene Methode. Wenn die Methode zurückkehrt, findet der Aufrufer alle Aktualisierungen wieder, die die aufgerufene Methode an diesem Parameter vorgenommen hat.

```csharp
void Foo(ref int val)
{
    val *= 7;
}

int importantValue = 6;
Foo(ref importantValue);
return importantValue;
// => 42
```

- `ref`-Parameter müssen Variablen sein, da die aufgerufene Methode direkt auf dem Parameter arbeitet, so wie der Aufrufer ihn sieht.
- Die Modifizierer `out` und `ref` sind sowohl in der Signatur der aufgerufenen Methode als auch an der Aufrufstelle erforderlich.
