# Ternärer Operator

Der ternäre Operator bietet eine alternative Syntax, um einen `if..else..`-Vergleich durchzuführen und einen Wert zurückzugeben.

## Syntax

PHP bietet eine if-Anweisung, bei der eine Aktion anhand der „Wahrheitswertigkeit" einer Bedingung ausgewertet werden kann.

```php
if ($condition) {
  $value = 1;
} else {
  $value = 2
}
```

Alternativ kann der ternäre Operator dieselbe Operation darstellen:

```php
$value = $condition
  ? 1  // True branch
  : 2; // False branch
```

Die Vergleichssyntax ist kurz und sieht so aus: `(condition) ? (evaluate if true) : (evaluate if false);`.
