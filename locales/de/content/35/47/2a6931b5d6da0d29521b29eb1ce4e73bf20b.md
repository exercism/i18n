# Einführung

Im [`Basics`][basics]-Konzept hast du zwei Arten kennengelernt, eine Funktion zu definieren.

Am allgemeinsten ist die mehrzeilige Form:

```julia
function muladd(x, y, z)
    x * y + z
end
```

Die „Zuweisungs“- oder „einzeilige“ Form für kurze Definitionen:
```julia
muladd(x, y, z) = x * y + z
```

In einer dritten, noch kürzeren Form kannst du eine kurze Funktion, die nur einmal verwendet wird, ohne Namen erstellen:

```julia-repl
julia> map(x -> 2x, 1:3)
4-element Vector{Int64}:
 2
 4
 6

julia> map((x, y) -> x * y, 1:3, 4:6)
3-element Vector{Int64}:
  4
 10
 18
```

In diesem Fall ist `x -> 2x` eine „anonyme Funktion“.
Das entspricht dem, was andere Sprachen eine „Lambda-Funktion“ nennen.

Beachte, dass mehrere Argumente runde Klammern brauchen, wie in `(x, y) -> x * y`.

Anonyme Funktionen sind in Julia-Code weit verbreitet, besonders in Kombination mit Funktionen höherer Ordnung wie `map()` und `filter()` (die wir in einem späteren Konzept ausführlicher behandeln).

```julia-repl
julia> map(x -> x^4, [1, 2, 3])
3-element Vector{Int64}:
  1
 16
 81
```

## Funktionsargumente

Bisher haben wir im Lehrplan nur Funktionen betrachtet, die eine feste Anzahl von Argumenten haben und bei deren Aufruf du alle Argumente in der richtigen Reihenfolge angeben musst.
Das wäre einschränkend und unpraktisch, deshalb gibt es mehrere weitere Möglichkeiten.

### Optionale Argumente

Wie viele andere Sprachen erlaubt es Julia, in Funktionsdefinitionen für einzelne Argumente Standardwerte anzugeben.

Ein Funktionsaufruf kann dann entweder einen Wert für dieses Argument angeben oder es weglassen und den Standardwert verwenden.

```julia-repl
julia> f(x, y=10) = x * y
f (generic function with 2 methods)

julia> f(2, 3)
6

julia> f(2)
20
```

Alle Argumente _ohne_ Standardwert müssen vor allen Argumenten _mit_ Standardwert stehen, das heißt, `f(x=2, y)` wäre ungültig.

### Schlüsselwortargumente

Alle bisherigen Beispiele verwenden `positional arguments`, bei denen die in einem Funktionsaufruf übergebenen Werte in der Reihenfolge der entsprechenden Argumente in der Funktionsdefinition stehen müssen.

Wie viele andere Sprachen erlaubt Julia auch `keyword arguments`.
In einem Funktionsaufruf musst du den Namen des Arguments angeben, dafür kannst du mehrere Schlüsselwortargumente in beliebiger Reihenfolge angeben.

Eine Besonderheit von Julia ist, dass den Schlüsselwortargumenten (falls vorhanden) in der Funktionsdefinition ein Semikolon `;` vorangehen muss, um sie von eventuellen Positionsargumenten zu trennen.
In einem Funktionsaufruf kannst du zwischen dem letzten Positionsargument und dem ersten Schlüsselwortargument entweder `;` oder `,` verwenden.

```julia-repl
julia> b(x; y) = x + y
b (generic function with 1 method)

julia> b(2, y=3)
5

# keyword is required when calling
julia> b(2, 3)
ERROR: MethodError: no method matching b(::Int64, ::Int64)
The function `b` exists, but no method is defined for this combination of argument types.
```

Standardwerte kannst du optional angeben, genau wie bei Positionsargumenten.

Häufig entsteht in einem Funktionsaufruf Syntax wie `myarg=myarg`, wenn eine Variable mit demselben Namen wie der Parameter vorher berechnet wurde.
In diesem Fall ist eine Kurzschreibweise erlaubt:

```julia-repl
julia> width = 4.0
4.0

julia> height = √ width
2.0

julia> area(; width, height) = width * height
area (generic function with 1 method)

# repetition
julia> area(; width=width, height=height)
8.0

# shorthand form
julia> area(; width, height)
8.0
```

### Splat und Slurp

Falls du dich gefragt hast: Das sind die üblichen Namen für einen nützlichen Teil der Julia-Syntax.
Beide beziehen sich auf den `...`-Operator.

#### Splat

Bei _Funktionsaufrufen_ wird Splatting verwendet, um Sammlungen in die einzelnen Werte zu entpacken, die die Funktion benötigt.

Das lässt sich leichter zeigen als erklären:

```julia-repl
julia> fxyz(x, y, z) = x * y * z
fxyz (generic function with 1 method)

julia> xyz = [2, 3, 4]
3-element Vector{Int64}:
 2
 3
 4

# Using the vector directly in a function call is invalid
julia> fxyz(xyz)
ERROR: MethodError: no method matching fxyz(::Vector{Int64})
The function `fxyz` exists, but no method is defined for this combination of argument types.

# splatting converts the vector to 3 numbers, used as positional arguments
julia> fxyz(xyz...)
24
```

Manche „Funktionsaufrufe“ sind hinter syntaktischem Zucker versteckt, deshalb lässt sich Splatting auch an weniger offensichtlichen Stellen verwenden.

Zum Beispiel nutzt die Mehrfachzuweisung intern eine Tupel-Konstruktorfunktion:

```julia-repl
julia> first, rest... = [1, 2, 3, 4]
4-element Vector{Int64}:
 1
 2
 3
 4

julia> first
1

julia> rest
3-element Vector{Int64}:
 2
 3
 4
```

Schlüsselwortargumente kannst du ebenfalls per Splatting übergeben, üblicherweise mit einem `named tuple`. 
Ein `Dict` funktioniert auch, aber die Schlüssel müssen Symbole sein (Strings funktionieren nicht).

```julia-repl
# function with 3 keyword arguments
julia> fabc(; a, b, c) = a + b + c
fabc (generic function with 1 method)

# named tuple
julia> abc_nt = (a=2, b=3, c=4)
(a = 2, b = 3, c = 4)

# there are no positional arguments, so need to use ; before kw argument
julia> fabc(;abc_nt...)
9

# Dict
julia> abc_dict = Dict(:a=>2, :b=>3, :c=>4)
Dict{Symbol, Int64} with 3 entries:
  :a => 2
  :b => 3
  :c => 4

julia> fabc(;abc_dict...)
9
```

#### Slurp

Bei der _Definition_ einer Funktion wird Slurping verwendet, um eine beliebige Anzahl einzelner Werte in einer Sammlung zu bündeln.

```julia-repl
julia> f_more(i, j, more...) = i + j + sum(more)
f_more (generic function with 1 method)

julia> f_more(1, 3, 5, 7, 9, 11)
36
```

Der Name des Arguments, das per Slurping gesammelt wird (hier `more`), spielt keine Rolle.
Den Typ dieser Variable wählt der Compiler, bei Positionsargumenten ist es aber wahrscheinlich `tuple` oder etwas Ähnliches.

Schlüsselwortargumente kannst du ebenfalls per Slurping sammeln, dabei erhältst du ein `Dict` (oder etwas Ähnliches).

```julia-repl
julia> f_kwslurp(x, y; switches...) = :mult in keys(switches) ? x * y : x + y
f_kwslurp (generic function with 1 method)

julia> f_kwslurp(5, 6; mult=true)
30

julia> f_kwslurp(5, 6)
11
```

Im Aufruf kannst du beliebige Schlüsselwortargumente verwenden.
Die Funktionsdefinition entscheidet, auf welche Schlüsselwörter sie reagiert und welche sie ignoriert.
