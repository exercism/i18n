# gofmt nicht verwendet

Führe `gofmt` für deine Lösung aus. Das hilft, Go-Code zu formatieren.

Code-Formatierung ist in der Go-Community sehr wichtig.
Die meisten IDEs lassen sich so einrichten, dass sie den Code bei jedem Speichern automatisch formatieren. Zum Beispiel:

- Visual Studio Code hat eine [großartige Go-Unterstützung](https://code.visualstudio.com/docs/languages/go)
- Vim hat außerdem eine [fantastische Go-Erweiterung](https://github.com/fatih/vim-go)
- [Jetbrains Goland](https://www.jetbrains.com/go/) ist eine komplette IDE für Go

Um `gofmt` manuell auszuführen:

```bash
# will only show the differences
gofmt -d filename.go

# will apply the changes
gofmt -w filename.go
```

```git
%{gofmt}
```
