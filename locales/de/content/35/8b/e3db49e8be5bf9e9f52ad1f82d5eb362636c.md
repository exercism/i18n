# Über

Zeichen in Factor sind *Ganzzahlen*, genauer gesagt Unicode-Codepoints. Die numerischen Operatoren `<`, `>`, `=` liefern dir daher schon eine Sortierung, die Groß- und Kleinschreibung unterscheidet. Das Vokabular [`unicode`][unicode] fügt Unicode-fähige Prädikate und die Umwandlung der Groß- und Kleinschreibung einzelner Zeichen hinzu.

## Prädikate

```
LETTER?  ( c -- ? )    ! uppercase letter
letter?  ( c -- ? )    ! lowercase letter
Letter?  ( c -- ? )    ! letter, either case
digit?   ( c -- ? )    ! decimal digit
digit>   ( c -- n )    ! the integer value of a digit char
blank?   ( c -- ? )    ! whitespace
alpha?   ( c -- ? )    ! letter or decimal digit
```

```factor
USING: unicode ;

CHAR: A LETTER? .    ! => t
CHAR: a letter? .    ! => t
CHAR: 7 digit?  .    ! => t
CHAR: \n blank? .    ! => t
```

## Umwandlung der Groß- und Kleinschreibung

```
ch>upper  ( c -- c' )
ch>lower  ( c -- c' )
ch>title  ( c -- c' )
```

Die String-Funktionen `>upper`, `>lower` und `>title` wenden sie auf jedes Zeichen eines Strings an.

```factor
CHAR: a ch>upper .   ! => 65   (which is CHAR: A)
"Hello" >upper .     ! => "HELLO"
```
