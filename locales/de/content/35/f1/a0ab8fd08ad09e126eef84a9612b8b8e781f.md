# Einführung

## List Comprehensions

Comprehensions bieten eine einfache und deklarative Möglichkeit, _Enumerables_ umzuwandeln.

Um eine sehr einfache Comprehension zu deklarieren, verwendest du das Schlüsselwort `for`, gefolgt von einem _Generator_ und einem _do-Block_, der aus den aufgezählten Werten die neuen Werte erzeugt.

```elixir
for n <- [0, 1, 2, 3], do: n + 1
# => [1, 2, 3, 4]
```

Comprehensions können auch _Filter_ haben. Werte, die den Filter nicht bestehen, werden aus der endgültigen Liste entfernt:

```elixir
for n <- [0, 1, 2, 3], n > 1, do: n + 1
# => [3, 4]
```

Du kannst komplexere Comprehensions auch über mehrere Zeilen deklarieren:

```elixir
for {atom, number} <- [a: 1, b: 2, c: 3, d: 4],
    rem(number, 2) == 0 do
  atom
end

# => [:b, :d]
```

Ein _kartesisches Produkt_ lässt sich mit mehreren Generatoren erzeugen. Das bedeutet, dass jeder Wert, den der erste Generator erzeugt, einmal mit jedem Wert des zweiten Generators kombiniert wird:

```elixir
for x <- [0, 1],
    y <- [0, 1] do
  {x, y}
end

# => [{0, 0}, {0, 1}, {1, 0}, {1, 1}]
```
