# Einführung

Wenn eine Quotation Werte aus ihrer Umgebung *behalten* muss (was andere Sprachen eine *Closure* nennen), greift Factor zu zwei Werkzeugen: dem `curry`-Wort und der *Fry*-Syntax `'[ ]`.

## `curry`: einen Wert erfassen

`curry` (aus [`kernel`][kernel]) nimmt einen Wert und eine Quotation und gibt eine neue Quotation zurück, in die dieser Wert fest eingebaut ist:

```
curry ( value quot -- newquot )
```

```factor
3 [ + ] curry .
! => [ 3 + ]

10 3 [ + ] curry call .
! => 13
```

Wende `curry` zweimal an, um zwei Werte zu erfassen:

```factor
2 3 [ + + ] curry curry .
! => [ 2 3 + + ]
```

## `compose`: zwei Quotationen verbinden

`compose` (aus [`kernel`][kernel]) klebt zwei Quotationen zusammen:

```
compose ( quot1 quot2 -- quot )
```

```factor
[ 1 + ] [ 2 * ] compose .
! => [ 1 + 2 * ]

5 [ 1 + ] [ 2 * ] compose call .
! => 12
```

## Fry-Quotationen: mehrere Werte erfassen

Ab mehr als ein oder zwei Erfassungen werden verkettete `curry`-Aufrufe schnell unübersichtlich. *Fry* verwendet `'[ … ]` mit einem oder mehreren `_`-Platzhaltern; jeder `_` wird der Reihe nach durch einen Wert ersetzt, der vom Datenstack genommen wird:

```factor
2 3 '[ _ _ + + ] .
! => [ 2 3 + + ]
```

Sowohl `curry` als auch Fry *verbrauchen* ihre Werte vom Stack, sobald die Closure erstellt wird. Die Zeile oben lässt nichts auf dem Stack zurück und ist ein direkter Ersatz für `[ + + ] curry curry`.

Platzhalter werden von links nach rechts mit den Stackwerten von unten nach oben gefüllt: `2 3 '[ _ _ ]` ergibt `[ 2 3 ]`, nicht `[ 3 2 ]`.

Fry greift auch *in* verschachtelte Quotationen hinein, sodass du die erfassten Werte genau dort platzieren kannst, wo du sie haben willst:

```factor
2 '[ [ _ > ] filter ] { 1 2 3 4 5 } swap call( s -- s ) .
! => { 3 4 5 }
```

Der `_` steht innerhalb der inneren `[ … ]`, aber Fry füllt ihn trotzdem.

## `call` mit deklariertem Effekt

Wenn du eine gespeicherte Quotation schließlich ausführst, deklariere ihren Stack-Effekt bei `call`, damit der Compiler sie typprüfen kann:

```factor
{ 3 4 5 } [ first2 + ] call( p -- n ) .
! => 7

{ 3 4 5 } [ first ] call( p -- n ) .
! => 3
```

## Vektorarithmetik

Das Vokabular [`math.vectors`][math.vectors] kombiniert zwei gleich lange Sequenzen elementweise. `v+` und `v*` addieren oder multiplizieren sie; `vmax` und `vmin` behalten die größere bzw. kleinere Komponente. Jede dieser Operationen liefert ein 2-Array zurück:

```factor
{ 1 1 } { 3 4 } v+ .    ! => { 4 5 }
{ 2 5 } { 3 -1 } v* .   ! => { 6 -5 }
{ 1 9 } { 4 4 } vmax .  ! => { 4 9 }
{ 1 9 } { 4 4 } vmin .  ! => { 1 4 }
```
