# Babashka-Integrationen für Texteditoren

## nREPL

### Emacs: [CIDER](https://cider.mx/)

Damit hat alles angefangen, und das [Orchard](https://metaredux.com/posts/2018/11/09/ciders-orchard-the-heart.html)-Ökosystem dahinter treibt viele der anderen Plug-ins an.

1. Installiere [Emacs](https://www.gnu.org/software/emacs/download.html) für dein Betriebssystem.

2. Wähle eine bestehende Emacs-Distribution ([Prelude](https://prelude.emacsredux.com/), [Spacemacs](https://www.spacemacs.org/) und [Doom Emacs](https://github.com/hlissner/doom-emacs) sind alle großartig) oder füge Folgendes in deine `init.el` ein:

```elisp
(unless (package-installed-p 'cider)
  (package-install 'cider))
  
(add-hook 'clojure-mode-hook #'cider-mode)
```

Zusammengefasst aus der [CIDER-Dokumentation](https://docs.cider.mx/cider/platforms/babashka.html):

Starte den nREPL-Server aus dem Projektverzeichnis:

```bash
$ bb --nrepl-server
```

Erstelle oder öffne eine beliebige Clojure-Datei (`.clj`) mit `C-x C-f` und verbinde dich mit `C-c C-x c j` (cider-connect-clj) damit.

Die [grundlegenden CIDER-Tastenkürzel](https://docs.cider.mx/cider/usage/cider_mode.html#key-reference):

* `cider-load-buffer` - `C-c C-k`
* `cider-eval-last-sexp` - `C-x C-e` oder `C-c C-e`
* `cider-eval-defun-at-point` - `C-M-x` oder `C-c C-c`

### VSCode: [Calva](https://github.com/BetterThanTomorrow/calva)

1. Installiere [VSCode](https://code.visualstudio.com/).

2. Installiere [Calva](https://marketplace.visualstudio.com/items?itemName=betterthantomorrow.calva).

Derzeit geht Calva davon aus, dass dein Quellcode im Kontext eines Ordners steht, also eines Clojure-Projekts. Ein schöner Weg, eines zu erstellen, ist [clj-new](https://github.com/seancorfield/clj-new):

```bash
$ clj -A:new lib myorg/bbtest
Generating a project called bbtest based on the 'lib' template.
The lib template is intended for library projects, not applications.
```
3. Starte den nREPL-Server aus dem Verzeichnis des Projekts:

```bash
$ cd bbtest
bbtest$ bb --nrepl-server 1667
Started nREPL server at localhost:1667
For more info visit https://github.com/borkdude/babashka/blob/master/doc/repl.md#nrepl.
```

Öffne den Projektordner in VSCode (Ctrl+K Ctrl+O) oder aus einem anderen Terminal:

```bash
$ cd bbtest
bbtest$ code .
```

4. Führe in VSCode den Calva-Befehl `Connect to a running REPL` aus (ctrl+alt+c ctrl+alt+c). Wähle auf Nachfrage das Projekt `Generic` und gib `localhost:1667` ein.

REPL-Befehle:

* `Load Current File and Dependencies` ctrl+alt+c enter
* `Evaluate Current Form Inline` ctrl+alt+c e
* `Evaluate Current Top Level Form (defun)` ctrl+alt+c space

### IntelliJ: [Cursive](https://cursive-ide.com/)

1. Lade IntelliJ [hier](https://www.jetbrains.com/idea/download/index.html) herunter.
2. Installiere Cursive mithilfe des [Benutzerhandbuchs](https://cursive-ide.com/userguide/) und [konfiguriere die Abhängigkeiten](https://cursive-ide.com/userguide/deps.html).
3. Weitere Informationen findest du unter [Cursive: Working with Babashka](https://cursive-ide.com/userguide/babashka.html).

## Socket REPL

### Atom: [chlorine](https://github.com/mauricioszabo/atom-chlorine)

1. Installiere [atom](https://flight-manual.atom.io/getting-started/sections/installing-atom/)

2. Installiere das Paket `chlorine`

3. Starte den Socket-REPL:

 ```
$ bb --socket-repl 1666
Babashka socket REPL started at localhost:1666
 ```

4. Öffne die Befehlspalette von Atom (ctrl+shift+p) und führe den Befehl `Connect Clojure Socket REPL` mit `localhost` `1666` aus

5. Bearbeite die Tastenbelegungen in keymap.cson über das Menü `Edit` -> `Keymap...`:

```
'atom-text-editor[data-grammar="source clojure"]':
  'ctrl-; y':       'chlorine:connect-clojure-socket-repl'
  'ctrl-; e':       'chlorine:disconnect'
  'ctrl-; k':       'chlorine:clear-console'
  'ctrl-shift-enter':       'chlorine:load-file'
  'ctrl-enter':       'chlorine:evaluate-block'
  'shift-enter':       'chlorine:evaluate-top-block'
  'ctrl-; i':       'chlorine:inspect-block'
  'ctrl-; I':       'chlorine:inspect-top-block'
  'ctrl-; s':       'chlorine:evaluate-selection'
  'ctrl-; c':       'chlorine:break-evaluation'
  'ctrl-; S':       'chlorine:source-for-var'
  'ctrl-; d':       'chlorine:doc-for-var'
  'ctrl-; x':       'chlorine:run-tests-in-ns'
  'ctrl-; t':       'chlorine:run-test-for-var'
```

### Emacs: [inf-clojure](https://github.com/clojure-emacs/inf-clojure)

Installiere für Emacs [inf-clojure](https://github.com/clojure-emacs/inf-clojure), indem du Folgendes in deine `init.el` einfügst:

```
(unless (package-installed-p 'inf-clojure)
  (package-refresh-contents)
  (package-install 'inf-clojure))

(add-hook 'clojure-mode-hook #'inf-clojure-minor-mode)
```

Starte den Socket-REPL wie oben und führe in Emacs `M-x inf-clojure-connect` aus (C-c M-c).

Werte Formulare mit C-c C-e aus. Eine Liste aller verfügbaren Befehle in inf-clojure-mode (auch bekannt als REPL) und inf-clojure-minor-mode erhältst du, indem du C-h f RET inf-clojure-mode und C-h f RET inf-clojure-minor-mode aufrufst, oder du siehst einfach in deren Menüs nach.

### Vim: [vim-iced](https://github.com/liquidz/vim-iced)

Lade das [Neovim-AppImage](https://github.com/neovim/neovim/releases/download/v0.4.3/nvim.appimage) herunter und lege einen Alias auf `vim` an.

* Installiere [vim-plug](https://github.com/junegunn/vim-plug):

```
$ curl -fLo ~/.local/share/nvim/site/autoload/plug.vim --create-dirs \
    https://raw.githubusercontent.com/junegunn/vim-plug/master/plug.vim
```

Erstelle `~/.config/nvim/init.vim`:

```
call plug#begin('~/.vim/plugged')

Plug 'liuchengxu/vim-clap'
Plug 'guns/vim-sexp',    {'for': 'clojure'}
Plug 'liquidz/vim-iced', {'for': 'clojure'}

call plug#end()

" Enable vim-iced's default key mapping
" This is recommended for newbies
let g:iced_enable_default_key_mappings = v:true
```

Öffne Neovim und führe den Befehl `:PlugInstall` aus.

Füge den Befehl `iced` zum $PATH hinzu:

`$ export PATH=$PATH:~/.vim/plugged/vim-iced/bin`

* Starte den Socket-REPL-Server, öffne die Quelldatei und führe `:IcedConnectSocketRepl 1666` aus.

Standard-REPL-Befehle (Standard für `<Leader>` ist `\`):

- `<Leader>ei` : Inneres Element auswerten
- `<Leader>ee` : Äußere Liste auswerten
- `<Leader>et` : Äußere oberste Liste auswerten
