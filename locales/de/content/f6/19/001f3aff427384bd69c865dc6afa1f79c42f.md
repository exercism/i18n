# Anleitung

Zu jeder Rolle im Schultheaterstück gibt es einen Einspringer: jemanden, der einspringen und tun kann, was die Rolle verlangt, ohne dass der Inspizient weiß, wer das ist.

Alle fünf Aufgaben gehören in die Klasse `UNDERSTUDY`. Die ersten beiden sind gewöhnliche Routinen, die spätere Aufgaben binden werden.

## 1. Zwei Arten, eine Zeile zu sagen

Schreibe `shout`, das die Zeile in Großbuchstaben zurückgibt, und `whisper`, das sie in Kleinbuchstaben mit `"..."` an beiden Enden zurückgibt.

```sather
UNDERSTUDY::shout("who's there")
-- => "WHO'S THERE"
UNDERSTUDY::whisper("Who's There")
-- => "...who's there..."
```

## 2. Eine Zeile proben

`rehearse` bekommt eine Zeile und eine Art, sie zu sagen, und gibt das Ergebnis zurück. Das zweite Argument hat den Typ `ROUT{STR}:STR`.

```sather
UNDERSTUDY::rehearse("who's there", bind(UNDERSTUDY::shout(_)))
-- => "WHO'S THERE"
```

## 3. Die ganze Szene

`run_scene` bekommt ein Array von Zeilen und eine Art, sie zu sagen, und gibt sie alle so gesagt zurück, verbunden mit `" "`.

```sather
UNDERSTUDY::run_scene(|"Enter", "Exit"|, bind(UNDERSTUDY::shout(_)))
-- => "ENTER EXIT"
```

Eine leere Szene ist der leere String.

## 4. Eine Sprechweise zurückgeben

`understudy_for` bekommt den Namen eines Stils (`"shout"` oder irgendetwas anderes) und gibt einen `ROUT{STR}:STR` zurück. `"shout"` ergibt die schreiende Variante, alles andere die flüsternde.

```sather
part ::= UNDERSTUDY::understudy_for("shout");
part.call("who's there")
-- => "WHO'S THERE"
```

## 5. Ein Argument festlegen

Schreibe `repeat`, das eine Anzahl von Wiederholungen und eine Zeile bekommt und die Zeile so oft hintereinander zurückgibt, ohne etwas dazwischen:

```sather
UNDERSTUDY::repeat(3, "Ha")
-- => "HaHaHa"
```

Dann schreibe `doubler`, das keine Argumente bekommt und einen `ROUT{STR}:STR` zurückgibt, der alles zweimal wiederholt, was er bekommt, indem du `repeat` mit der schon eingesetzten Zahl bindest.

```sather
UNDERSTUDY::doubler.call("Ha")
-- => "HaHa"
```
