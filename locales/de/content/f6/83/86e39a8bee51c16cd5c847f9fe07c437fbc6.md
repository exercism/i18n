# Einführung

## Zahlen

Viele Programmiersprachen haben eigene numerische Typen, um verschiedene Arten von Zahlen darzustellen, aber JavaScript kennt nur zwei:

- `number`: ein numerischer Datentyp im 64-Bit-Gleitkommaformat mit doppelter Genauigkeit (IEEE 754).
  Beispiele sind `-6`, `-2.4`, `0`, `0.1`, `1`, `3.14`, `16.984025`, `25`, `976`, `1024.0` und `500000`.
- `bigint`: ein numerischer Datentyp, der _Ganzzahlen_ im Format mit beliebiger Genauigkeit darstellen kann.
  Beispiele sind `-12n`, `0n`, `4n` und `9007199254740991n`.

Wenn du beliebige Genauigkeit benötigst oder mit extrem großen Zahlen arbeitest, verwende den Typ `bigint`.
Andernfalls ist der Typ `number` wahrscheinlich die bessere Wahl.

### Runden

Es gibt ein eingebautes globales Objekt namens `Math`, das verschiedene [Rundungsfunktionen][ref-math-object-rounding] bereitstellt.
Zum Beispiel kannst du Kommazahlen mit `floor` abrunden oder mit `ceil` aufrunden, und zwar auf die nächste ganze Zahl.

```javascript
Math.floor(234.34); // => 234
Math.ceil(234.34); // => 235
```

## Arithmetische Operatoren

JavaScript bietet 6 verschiedene Operatoren für grundlegende Rechenoperationen mit Zahlen.

- `+`: Der Additionsoperator wird verwendet, um die Summe von Zahlen zu ermitteln.
- `-`: Der Subtraktionsoperator wird verwendet, um die Differenz zwischen zwei Zahlen zu ermitteln.
- `*`: Der Multiplikationsoperator wird verwendet, um das Produkt zweier Zahlen zu ermitteln.
- `/`: Der Divisionsoperator wird verwendet, um zwei Zahlen zu dividieren.

```javascript
2 - 1.5; //=> 0.5
19 / 2; //=> 9.5
```

- `%`: Der Restoperator wird verwendet, um den Rest einer durchgeführten Division zu ermitteln.

  ```javascript
  40 % 4; // => 0
  -11 % 4; // => -3
  ```

- `**`: Der Potenzoperator wird verwendet, um eine Zahl in eine Potenz zu erheben.

  ```javascript
  4 ** 3; // => 64
  4 ** 1 / 2; // => 2
  ```

### Reihenfolge der Operationen

Wenn du mehrere Operatoren in einer Zeile verwendest, folgt JavaScript einer Rangfolge, wie sie in [dieser Rangfolgetabelle][mdn-operator-precedence] dargestellt ist.
Vereinfacht gesagt verwendet JavaScript die PEDMAS-Regel (Klammern, Exponenten, Division/Multiplikation, Addition/Subtraktion), die wir aus dem Mathematikunterricht der Grundschule kennen.

<!-- prettier-ignore-start -->
```javascript
const result = 3 ** 3 + 9 * 4 / (3 - 1);
// => 3 ** 3 + 9 * 4/2
// => 27 + 9 * 4/2
// => 27 + 18
// => 45
```
<!-- prettier-ignore-end -->

### Kurzschreibweise für Zuweisungsoperatoren

Kurzschreibweisen für Zuweisungsoperatoren sind eine kürzere Art, Code zu schreiben, der Rechenoperationen auf eine Variable ausführt und der Variablen den neuen Wert zuweist.
Betrachte zum Beispiel zwei Variablen `x` und `y`.
Dann ist `x += y` dasselbe wie `x = x + y`.
Häufig wird dies mit einer Zahl statt mit einer Variablen `y` verwendet.
Die 5 anderen Operationen lassen sich auf ähnliche Weise durchführen.

```javascript
let x = 5;
x += 25; // x is now 30

let y = 31;
y %= 3; // y is now 1
```
