# Grundlagen

Die Standardbibliothek von Swift bietet bereits viel Funktionalität, doch zusätzliche Möglichkeiten bekommst du, wenn du externe Bibliotheken und Frameworks importierst.
Diese Module können direkt aus dem Swift-Projekt stammen (etwa der [Swift Argument Parser][argument-parser]), aus Apples Plattform-Frameworks (etwa [Foundation][apple-foundation] und das [Network Framework][network-framework]) oder aus Open-Source-Bibliotheken von Drittanbietern (etwa [SwiftyBeaver][swifty-beaver]).

Kernmodule wie Foundation, eine der am weitesten verbreiteten Bibliotheken in Swift, sind in der Swift-Toolchain enthalten.
Bibliotheken von Drittanbietern musst du erst zur Konfiguration deines Projekts hinzufügen (zum Beispiel mit dem Swift Package Manager), bevor du sie importieren kannst.

Um ein Modul zu importieren, schreibst du das Schlüsselwort `import`, gefolgt vom Namen des Moduls:

```swift
import Foundation
```

Wenn du ein Modul importierst, stehen seine Typen, Methoden und Funktionen deinem Code zur Verfügung.
Der Import von Foundation erweitert zum Beispiel `String` um nützliche Hilfsmethoden wie `components(separatedBy:)`.

Nach Konvention stehen `import`-Anweisungen am Anfang einer Swift-Datei, damit Abhängigkeiten für alle, die den Code lesen, sofort sichtbar sind.

[network-framework]: https://developer.apple.com/documentation/network
[swifty-beaver]: https://github.com/SwiftyBeaver/SwiftyBeaver
[apple-foundation]: https://developer.apple.com/documentation/foundation
