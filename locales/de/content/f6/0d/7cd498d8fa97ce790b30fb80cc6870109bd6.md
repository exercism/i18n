# Beschreibung

Implementiere die Operation `accumulate`. Sie erhält eine Sammlung und eine Operation, die auf jedes Element der Sammlung angewendet werden soll, und gibt eine neue Sammlung zurück, die das Ergebnis der Anwendung dieser Operation auf jedes Element der Eingabesammlung enthält.

Gegeben ist die Sammlung von Zahlen:

- 1, 2, 3, 4, 5

Und eine Quotation, die Folgendes tut:

- eine Zahl quadrieren (`[ sq ]`)

Dein Code sollte die Sammlung der Quadrate erzeugen können:

- 1, 4, 9, 16, 25

## Einschränkungen

Lass die Finger von der collect/map/fmap-wasauchimmer-Funktionalität, die deine Standardbibliothek bietet!

Löse diese Aufgabe stattdessen selbst mit anderen grundlegenden Werkzeugen.
