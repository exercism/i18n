# Hinweise

## Allgemein

- Die Indizes von `Vector` beginnen bei `1`.
- Die Kartendecks enthalten keine doppelten Karten.

## 1. Prüfe, ob eine Karte vorhanden ist

- In Base gibt es eine Methode [`in`/`∈`](https://docs.julialang.org/en/v1/base/collections/#Base.in), mit der du feststellen kannst, ob eine Collection einen Wert enthält.

## 2. Finde die Position einer Karte

- In Base gibt es eine Methode [`findfirst`](https://docs.julialang.org/en/v1/base/arrays/#Base.findfirst-Tuple{Function,%20Any}), mit der du die Position des ersten Elements einer Collection findest, das ein gegebenes Prädikat erfüllt.
- `==(x)` kannst du als Prädikat verwenden, um in Methoden, die Prädikatfunktionen entgegennehmen, Elemente zu finden, die gleich `x` sind.

## 3. Prüfe, ob jede Karte gerade ist

- In Base gibt es eine Methode [`all`](https://docs.julialang.org/en/v1/base/collections/#Base.all-Tuple{AbstractArray,%20Any}), die `true` zurückgibt, wenn alle Elemente einer Collection ein gegebenes Prädikat erfüllen.
- [`iseven`](https://docs.julialang.org/en/v1/base/numbers/#Base.iseven) ist eine Prädikatfunktion.

## 4. Prüfe, ob das Deck eine Karte mit ungeradem Wert enthält

- In Base gibt es eine Methode [`any`](https://docs.julialang.org/en/v1/base/collections/#Base.any-Tuple{AbstractArray,%20Any}), die `true` zurückgibt, wenn mindestens ein Element einer Collection ein gegebenes Prädikat erfüllt.
- [`isodd`](https://docs.julialang.org/en/v1/base/numbers/#Base.isodd) ist eine Prädikatfunktion.

## 5. Bestimme die Position der ersten geraden Karte

- In Base gibt es eine Methode [`findfirst`](https://docs.julialang.org/en/v1/base/arrays/#Base.findfirst-Tuple{Function,%20Any}), mit der du die Position des ersten Elements einer Collection findest, das ein gegebenes Prädikat erfüllt.
- [`iseven`](https://docs.julialang.org/en/v1/base/numbers/#Base.iseven) ist eine Prädikatfunktion.

## 6. Hole die erste ungerade Karte aus dem Deck

- Mit `v[n]` kannst du den `n`-ten Wert aus einem Vektor `v` abrufen.
- In Base gibt es eine Methode [`findfirst`](https://docs.julialang.org/en/v1/base/arrays/#Base.findfirst-Tuple{Function,%20Any}), mit der du die Position des ersten Elements einer Collection findest, das ein gegebenes Prädikat erfüllt.
- Wenn kein Element der übergebenen Collection zu dem Prädikat passt, das `findfirst` bekommt, gibt `findfirst` `nothing` zurück.
- Schau dir noch einmal an, wie `nothing` in Julia funktioniert: [concept:julia/nothingness](../../../../concepts/nothingness/about.md)
- Schau dir noch einmal an, wie bedingte Anweisungen in Julia funktionieren: [concept:julia/conditionals](../../../../concepts/conditionals/about.md)
