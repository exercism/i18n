# Anweisungen

In dieser Übung bist du ein großer Sportfan und hast gerade deine Leidenschaft für NBA-Basketball entdeckt. Da du neu im NBA-Basketball bist, tauchst du tief in die NBA-Geschichte ein, behältst Teams, Trainer und ihre Sieg-/Niederlagen-Statistiken im Blick und vergleichst sie miteinander.

Da du noch kein Lieblingsteam hast, entwickelst du außerdem einen Algorithmus, der herausfindet, ob du für ein bestimmtes Team die Daumen drücken solltest.

Sieben Aufgaben helfen dir dabei, deinen ganz eigenen _Root-for-a-Team_-Algorithmus zu entwickeln.

## 1. Definiere das Modell

Definiere den Record `Coach` mit den folgenden zwei Feldern:

- `Name`: der Name des Trainers, vom Typ `string`.
- `FormerPlayer`: gibt an, ob der Trainer früher selbst Spieler war, vom Typ `bool`.

Definiere den Record `Stats` mit den folgenden zwei Feldern:

- `Wins`: die Anzahl der Siege, vom Typ `int`.
- `Losses`: die Anzahl der Niederlagen, vom Typ `int`.

Definiere den Record `Team` mit den folgenden drei Feldern:

- `Name`: der Name des Teams, vom Typ `string`.
- `Coach`: der Trainer des Teams, vom Typ `Coach`.
- `Stats`: die Statistiken des Teams, vom Typ `Stats`.

## 2. Erstelle den Trainer eines Teams

Implementiere die Funktion `createCoach`, die den Namen des Trainers und seinen Status als ehemaliger Spieler als Parameter entgegennimmt und den Record `Coach` zurückgibt:

```fsharp
createCoach "Larry Bird" true
// => { Name = "Larry Bird"; FormerPlayer = true }
```

## 3. Erstelle die Statistiken eines Teams

Implementiere die Funktion `createStats`, die die Anzahl der Siege und die Anzahl der Niederlagen als Parameter entgegennimmt und den Record `Stats` zurückgibt:

```fsharp
createStats 58 24
// => { Wins = 58; Losses = 24 }
```

## 4. Erstelle ein Team

Implementiere die Funktion `createTeam`, die den Teamnamen, den Trainer und den Record als Parameter entgegennimmt und den Record `Team` zurückgibt:

```fsharp
let coach = createCoach "Larry Bird" true
let record = createStats 58 24
createTeam "Indiana Pacers" coach record
// => { Name = "Indiana Pacers"
//      Coach = { Name = "Larry Bird"; FormerPlayer = true }
//      Stats = { Wins = 58; Losses = 24 } }
```

## 5. Ersetze den Trainer

NBA-Besitzer sind ungeduldig, und du hast festgestellt, dass schlechte Ergebnisse eines Teams oft dazu führen, dass der Trainer ersetzt wird. Implementiere die Funktion `replaceCoach`, die das Team und seinen neuen Trainer als Parameter entgegennimmt und das Team mit dem neuen Trainer zurückgibt:

```fsharp
let coach = createCoach "Larry Bird" true
let record = createStats 58 24
let team = createTeam "Indiana Pacers" coach record

let newCoach = createCoach "Isiah Thomas" true
replaceCoach team newCoach
// => { Name = "Indiana Pacers"
//      Coach = { Name = "Isiah Thomas"; FormerPlayer = true }
//      Stats = { Wins = 58; Losses = 24 } }
```

## 6. Prüfe, ob es dasselbe Team ist

Während du dich mit Statistiken beschäftigst, führst du Listen von Teams und ihren Records. Manchmal machst du dabei Fehler, und dann stehen doppelte Einträge auf deiner Liste. Implementiere die Funktion `isSameTeam`, die zwei Teams entgegennimmt und `true` zurückgibt, wenn es dasselbe Team ist; andernfalls gibst du `false` zurück:

```fsharp
let pacersCoach = createCoach "Larry Bird" true
let pacersStats = createStats 58 24
let pacersTeam = createTeam "Indiana Pacers" pacersCoach pacersStats

let lakersCoach = createCoach "Del Harris" false
let lakersStats = createStats 61 21
let lakersTeam = createTeam "LA Lakers" lakersCoach lakersStats

isSameTeam pacersTeam lakersTeam
// => false
```

## 7. Prüfe, ob du für ein Team die Daumen drücken solltest

Nachdem du viele Teams und Spiele analysiert hast, hast du einen Algorithmus entwickelt. Wenn eine der folgenden Bedingungen zutrifft, drückst du diesem Team die Daumen:

- Der Name des Trainers ist "Gregg Popovich"
- Der Trainer war früher selbst Spieler
- Das Team heißt "Chicago Bulls"
- Das Team hat 60 oder mehr Spiele gewonnen
- Das Team hat mehr Niederlagen als Siege

Implementiere die Funktion `rootForTeam`, die ein Team entgegennimmt und `true` zurückgibt, wenn du für dieses Team die Daumen drücken solltest; andernfalls gibst du `return` zurück:

```fsharp
let spursCoach = createCoach "Gregg Popovich" false
let spursStats = createStats 56 26
let spursTeam = createTeam "San Antonio Spurs" spursCoach spursStats
rootForTeam spursTeam
// => true
```
