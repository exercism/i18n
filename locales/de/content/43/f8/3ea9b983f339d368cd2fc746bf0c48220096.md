### Dynamischer Funktionsaufruf

awk-Funktionen sind keine First-Class-Objekte: Sie lassen sich nicht so herumreichen, wie es andere Sprachen erlauben.
Eine Variable kann aber den _Namen_ einer Funktion (einen String) enthalten, und die Funktion wird mit der speziellen Schreibweise `@varname(args)` aufgerufen.
Ein Beispiel:

```awk
function greet(name) {
    print "Hello, " name
}
BEGIN {
    greet("John")       # => "Hello, John"

    f = "greet"
    f("Bill")           # => error
    @f("Bill")          # => "Hello, Bill"
}
```
Das wird in [Indirect Function Calls][indirect] beschrieben.
Das ist eine `gawk`-Erweiterung.
