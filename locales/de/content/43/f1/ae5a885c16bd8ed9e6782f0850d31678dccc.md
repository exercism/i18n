# Anleitung

In dieser Übung implementierst du eine Möglichkeit, die Highscores für das beliebteste Spiel in deiner Spielhalle im Blick zu behalten.

Du musst 7 Funktionen implementieren, die alle ein Wörterbuch mit Highscore-Daten zurückgeben oder verändern.

## 1. Ein neues Highscore-Wörterbuch definieren

Erstelle eine Funktion `newScoreBoard()`, die keine Parameter entgegennimmt und ein neues Highscore-Wörterbuch zurückgibt, das Werte vom Typ `String` für die Schlüssel und Werte vom Typ `Int` als Werte verwendet.

## 2. Spieler zum Highscore-Wörterbuch hinzufügen

Um einen Spieler zum Highscore-Wörterbuch hinzuzufügen, definiere `addPlayer(_:_:_:)`, eine Funktion, die 3 Parameter entgegennimmt:

- Der erste Parameter ist das Wörterbuch mit den Punktzahlen. 
    Er sollte ein In-out-Parameter sein.
- Der zweite Parameter ist der Name eines Spielers als String.
- Der dritte Parameter ist die Punktzahl als Ganzzahl. 
    Der Parameter ist optional; implementiere den dritten Parameter mit dem Standardwert 0.

```swift
var highScores = newScoreBoard()
addPlayer(&highScores, "Dave Thomas")
// Returns ["Dave Thomas": 0]
addPlayer(&highScores, "José Valim", 486_373)
// Returns ["Dave Thomas": 0, "José Valim": 486_373]
```

## 3. Spieler aus dem Punktzahlen-Wörterbuch entfernen

Um einen Spieler aus dem Highscore-Wörterbuch zu entfernen, definiere `removePlayer(_:_:)`, die 2 Parameter entgegennimmt:

- Der erste Parameter ist das Wörterbuch mit den Punktzahlen. 
    Er sollte ein In-out-Parameter sein.
- Der zweite Parameter ist der Name des Spielers als String.

Diese Funktion sollte den Spieler aus dem Wörterbuch entfernen, wenn er darin enthalten ist, und ansonsten nichts tun.

```swift
var highScores = ["Dave Thomas": 0, "José Valim": 486_373]
removePlayer(&highScores, "Dave Thomas")
// Returns ["José Valim": 486_373]
removePlayer(&highScores, "Rose Fanaras")
// Returns ["José Valim": 486_373]
```

## 4. Die Punktzahl eines Spielers zurücksetzen

Um die Punktzahl eines Spielers zurückzusetzen, definiere `resetPlayer(_:_:)`, die 2 Parameter entgegennimmt:

- Der erste Parameter ist das Wörterbuch mit den Punktzahlen.
    Er sollte ein In-out-Parameter sein.
- Der zweite Parameter ist der Name des Spielers als String, dessen Punktzahl du zurücksetzen möchtest.

Die Funktion setzt die Punktzahl des Spielers auf 0. 
Wenn der Spieler nicht im Wörterbuch steht, soll nichts passieren.

```swift
var highScores = ["Dave Thomas": 486_373, "José Valim": 10]
resetScore(&highScores, "Dave Thomas")
// Returns ["Dave Thomas": 0, "José Valim": 10]
```

## 5. Die Punktzahl eines Spielers aktualisieren

Um die Punktzahl eines Spielers zu aktualisieren, indem du etwas zur bisherigen Punktzahl addierst, definiere `updateScore`, die 3 Parameter entgegennimmt:

- Der erste Parameter ist das Wörterbuch mit den Punktzahlen. Er sollte ein In-out-Parameter sein.
- Der zweite Parameter ist der Name des Spielers als String, dessen Punktzahl du aktualisieren möchtest.
- Der dritte Parameter ist die Punktzahl, die du zum gespeicherten Highscore **hinzufügen** möchtest.

```swift
var highScores = ["Dave Thomas": 0, "José Valim": 486_373]
addPlayer(&highScores, "Freyja Ćirić", 12_771_008)
updateScore(&highScores, "Freyja Ćirić", 73)
// Returns ["Dave Thomas": 0, "José Valim": 486_373, "Freyja Ćirić": 12_771_081]
```

## 6. Eine Liste von Spielern mit Punktzahlen abrufen, nach Spielername sortiert

Definiere die Funktion `orderByPlayers`, die 1 Parameter entgegennimmt:

- Der erste Parameter ist das Wörterbuch mit den Punktzahlen.

Die Funktion gibt ein Array aus `(String, Int)`-Tupeln zurück, also die Spieler und ihre Highscores, aufsteigend nach dem Namen des Spielers sortiert.

```swift
var highScores = ["Dave Thomas": 0, "José Valim": 486_373, "Freyja Ćirić": 12_771_091]
orderByPlayers(highScores)
// Returns [("Dave Thomas", 0), ("Freyja Ćirić", 12_771_091), ("José Valim", 486_373)]
```

## 7. Eine Liste von Spielern abrufen, nach Punktzahl absteigend sortiert

Um eine Liste von Spielern zu erhalten, die nach ihren Punktzahlen absteigend sortiert ist, definiere `orderByScores`, die 1 Parameter entgegennimmt:

- Der erste Parameter ist das Wörterbuch mit den Punktzahlen.

Die Funktion gibt ein Array aus `(String, Int)`-Tupeln zurück, also die Spieler und ihre Highscores, absteigend nach der Punktzahl des Spielers sortiert.

```swift
var highScores = ["Dave Thomas": 0, "José Valim": 486_373, "Freyja Ćirić": 12_771_091]
orderByScores(highScores)
// Returns [("Freyja Ćirić", 12_771_091), ("José Valim", 486_373), ("Dave Thomas", 0)]
```
