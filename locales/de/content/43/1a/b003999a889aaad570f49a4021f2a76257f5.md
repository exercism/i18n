# Tests

Wenn du das 8th-Binary im PATH hast, gib folgenden Befehl ein:

```bash
8th -f test.8th
```

Wenn das 8th-Binary nicht im PATH liegt, gib unter Windows Folgendes ein:

```cmd
\path\to\8th -f test.8th
```

Linux oder macOS:

```bash
/path/to/8th -f test.8th
```

## Testen in der REPL

Starte 8th und lade dabei test-words.8th:

```sh
8th -f test-words.8th
```

Damit startest du eine Sitzung in der Kommandozeile, in der du deinen Code aus der Lösungsdatei in die REPL laden kannst, sobald du ihn geschrieben hast.
Für die Übung „word-count“ gibst du zum Beispiel Folgendes ein:

```8th
"word-count.8th" f:include
```

Und du kannst die Tests so ausführen:
```sh
"word-count-tests.8th" f:include
```

Oder du kopierst einen einzelnen Test aus dieser Datei und fügst ihn ein, oder du schreibst deinen eigenen.

## Übersprungene Tests

Eine Übung zu lösen bedeutet, alle ihre Tests zum Bestehen zu bringen.
Standardmäßig wird beim Ausführen der Tests nur ein einziger Test ausgeführt (der erste).
Das ist Absicht. So kannst du dich ganz darauf konzentrieren, genau diesen einen Test zum Bestehen zu bringen.
Sobald er besteht, kannst du den nächsten Test aktivieren, indem du das Wort `SKIP-REST-OF-TESTS` hinter ihn verschiebst.

## Überspringen aufheben

Um alle Tests auszuführen, auch die nach dem Wort `SKIP-REST-OF-TESTS`, kannst du die Umgebungsvariable `RUN_ALL_TESTS` auf den Wert `true` setzen.
Eine Möglichkeit, das nur für die Dauer des Testlaufs zu setzen, ist (macOS und Linux):

```bash
RUN_ALL_TESTS=true 8th -f test.8th
```
