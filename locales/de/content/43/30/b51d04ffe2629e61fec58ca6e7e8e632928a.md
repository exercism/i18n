# Anleitung

Eine Schule in deiner Nähe hat eine sehr aktive Schülervertretung.
Die Schülervertretung wird von einem Präsidenten geleitet, und alle 2 Jahre finden Wahlen statt, um einen neuen Präsidenten zu wählen.
Bei der diesjährigen Wahl wurde entschieden, dass ein neues digitales System zum Auszählen der Stimmen gebraucht wird.

Die Schule braucht deine Hilfe beim Aufbau dieses neuen Systems.

## 1. Erstelle einen Stimmenzähler

Eines der ersten Dinge, die das neue Wahlsystem braucht, ist ein Stimmenzähler.
Mit diesem Zähler behältst du den Überblick über die Stimmen, die ein bestimmter Kandidat hat.

Erstelle eine Funktion `new_vote_counter`, die die Anzahl der anfänglichen Stimmen für einen Kandidaten entgegennimmt und eine Momentaufnahme einer `VoteCounter`-Struktur zurückgibt, die mit der angegebenen Anzahl an Anfangsstimmen initialisiert wurde.

```rust
let initial_votes: u32 = 2;
let counter: @VoteCounter = new_vote_counter(initial_votes);
// @VoteCounter {
//     value: 2,
// }
```

## 2. Ermittle die Anzahl der Stimmen aus einem Zähler

Jetzt hast du eine Möglichkeit, neue Zähler zu erstellen!
Aber jetzt fällt dir auf, dass das neue System auch eine Möglichkeit braucht, um die Anzahl der Stimmen aus einem Zähler zu ermitteln.

Erstelle eine Funktion `vote_count`, die einen Zähler (`@VoteCounter`) als Argument entgegennimmt und die Anzahl der Stimmen im Zähler zurückgibt.

```rust
let initial_votes: u32 = 3;
let vote_counter: @VoteCounter = new_vote_counter(initial_votes);

let count = vote_count(vote_counter);
// => 3
```

## 3. Erhöhe die Stimmen eines Zählers

Endlich ist es Zeit, die Stimmen auszuzählen!
Jetzt brauchst du eine Möglichkeit, die Stimmen in einem Zähler zu erhöhen.

Erstelle eine Funktion `increment_vote_count`, die einen Zähler (`@VoteCounter`) als Argument und eine Anzahl von Stimmen entgegennimmt und den Zähler um diese Anzahl von Stimmen erhöht.

```rust
let votes: u32 = 3;
let vote_counter: @VoteCounter = new_vote_counter(initial_votes);
let vote_counter: VoteCounter = increment_vote_count(vote_counter, 2);

let count = vote_count(@vote_counter);
// => 5
```

## 4. Erstelle das Wahlergebnis

Da nun alle Stimmen ausgezählt sind, ist es Zeit, die Bekanntgabe des Ergebnisses für die ganze Schule vorzubereiten.
Dabei fällt dir auf, dass Zähler für die Stimmen allein nicht ausreichen.
Es muss eine Möglichkeit geben, die Anzahl der Stimmen einem bestimmten Kandidaten zuzuordnen.

Erstelle eine Funktion `new_election_result`, die den Namen eines Kandidaten und seine Anzahl an Stimmen entgegennimmt und ein neues Wahlergebnis zurückgibt.

```rust
let result: ElectionResult = new_election_result("Peter", 3);
// ElectionResult {
//     name: "Peter",
//     votes: @VoteCounter {
//         value: 3,
//     },
// }
```

Die Struktur für das Wahlergebnis ist bereits für dich erstellt und ist so definiert:

```rust
struct ElectionResult {
    name: ByteArray,
    counter: @VoteCounter,
}
```

## 5. Verkünde die Ergebnisse

Es ist Zeit, der Schule den neuen Präsidenten bekanntzugeben!
Der Präsident wird auf den kleinen digitalen Anzeigetafeln bekanntgegeben, die die Schule hat.

Die Nachricht sollte den Namen des neuen Präsidenten und die Anzahl der Stimmen im folgenden Format anzeigen: `<candidate_name> (<votes>)`.
Ein Beispiel für eine solche Nachricht ist: `"Peter (51)"`.

Erstelle eine Funktion `display_result`, die ein `@ElectionResult` als Argument entgegennimmt und ein `ByteArray` mit der anzuzeigenden Nachricht zurückgibt.

```rust
let result = ElectionResult {
    name: "John",
    votes: @VoteCounter {
        value: 32,
    },
};

let msg = display_result(@result);
// => "John (32)"
```

## 6. Stimmen neu auszählen

Um sicherzustellen, dass die endgültigen Ergebnisse korrekt waren, wurden die Stimmen neu ausgezählt.
Bei der Nachzählung stellte sich heraus, dass die Anzahl der Stimmen einiger Kandidaten um eins daneben lag.

Erstelle eine Funktion `decrement_votes_of_candidate`, die die endgültigen Ergebnisse und den Namen eines Kandidaten entgegennimmt, für den du die Stimmenanzahl verringern sollst.
Die endgültigen Ergebnisse werden in Form eines `Felt252Dict<u32>` angegeben, wobei die Schlüssel die Namen der Kandidaten und die Werte ihre Gesamtstimmen sind.

```rust
let mut final_results: Felt252Dict<u32> = Default::default();
final_results.insert('Mary', 10);
final_results.insert('John', 51);

decrement_votes_of_candidate(ref final_results, 'Mary');

let decremented_votes = final_results.get('Mary');
// => 9
```
