# Einführung

Erweiterungsmethoden ermöglichen es, vorhandenen Typen Methoden hinzuzufügen, ohne einen neuen abgeleiteten Typ zu erstellen, neu zu kompilieren oder den ursprünglichen Typ anderweitig zu verändern. Sie werden als statische Methoden definiert, aber mit der Syntax von Instanzmethoden aufgerufen. Ihr erster Parameter wird durch den `this`-Modifier eingeleitet und legt fest, auf welchen Typ die Methode angewendet wird; in den Gültigkeitsbereich kommen Erweiterungsmethoden auf Namespace-Ebene.

```csharp
public static int WordCount(this string str)
{
    return str.Split().Length;
}

"Hello World".WordCount();
// => 2
```
