# Ergänzung zu den Anweisungen

## Register

| Register | Verwendung      | Typ      | Beschreibung                             |
| -------- | --------------- | -------- | ---------------------------------------- |
| `$a0`    | Eingabe         | Adresse  | nullterminierter String für den Namen    |
| `$a1`    | Eingabe         | Ganzzahl | Zahl                                     |
| `$a2`    | Eingabe/Ausgabe | Adresse  | nullterminierter String für das Ergebnis |
| `$t0-9`  | temporär        | beliebig | für die temporäre Speicherung            |
