# Installation

## Godot Engine installieren

Der GDScript-Track baut auf der [Godot Engine][godot-engine] auf, die unter Windows, Linux, macOS und Android läuft.
Der Testrunner für das [lokale Arbeiten][working-locally] erfordert momentan Linux.
Dieser Track erfordert Godot in Version 4.0 oder höher.

Nach der Installation kannst du prüfen, ob die Kommandozeile erfolgreich installiert wurde, indem du diesen Befehl in einem Terminal ausführst:

```bash
godot --version
```

## Den Testrunner für den GDScript-Track von Exercism installieren

Um den Testrunner zu verwenden, musst du [Godot korrekt installiert][installation] haben.

Um GDScript-Skripte für Exercism zu bauen und zu testen, startet man Godot über die Kommandozeile im „Headless“-Modus.
Diese Anweisungen erfordern derzeit Linux und bash.

### Schritt 1: Die gesamte Testrunner-Infrastruktur installieren

Um alles für das Testen einzurichten, klone [https://github.com/exercism/gdscript-test-runner][gdscript-test-runner] und verschiebe den Inhalt nach `/opt/test-runner/`:

```sh
git clone https://github.com/exercism/gdscript-test-runner.git
sudo mv gdscript-test-runner/ /opt/test-runner/
```

### Schritt 2: Das Testrunner-Skript für einzelne Übungen herunterladen

Wenn du das `exercism`-Tool eingerichtet und mindestens eine GDScript-Übung heruntergeladen hast, sollte es in deinem Arbeitsbereich einen Ordner `gdscript` angelegt haben (zu sehen, wenn du `exercism configure` ausführst), in dem die Übungen liegen.
Speichere [den Testrunner][test-local-gdscript-solution] in diesem Ordner und markiere die Datei als ausführbar.

## Tests ausführen

Wenn du die Installationsschritte abgeschlossen hast, kannst du aus jedem Übungsverzeichnis (z. B. `~/exercism/gdscript/two-fer`) heraus das Skript (es liegt eine Ebene höher, in `../`) ausführen, um deine lokale Lösung für diese Übung zu testen:

```sh
../test-local-gdscript-solution.sh
```

## Eine IDE verwenden

Um in einem Editor wie [Visual Studio Code][vscode] eine GDScript-Syntaxhervorhebung zu bekommen, brauchst du eine Erweiterung wie [godot-tools][godot-tools] und einen laufenden Debug-Server.
Godot startet diesen Debug-Server automatisch, sobald ein Projekt im eigenen Editor geöffnet ist, und lässt ihn laufen, bis das Projekt oder Godot selbst geschlossen wird.
