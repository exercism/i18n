# Intelligente Zeiger

Intelligente Zeiger sind in Cairo ein mächtiges Werkzeug, das eine sichere und effiziente Speicherverwaltung ermöglicht.

Ein intelligenter Zeiger ist eine Datenstruktur, die sich wie ein normaler Zeiger verhält, aber zusätzliche Sicherheitsfunktionen bietet, um häufige Probleme bei der Speicherverwaltung zu vermeiden, etwa das Dereferenzieren von Nullzeigern oder den Zugriff auf nicht initialisierten Speicher.

## Was ist ein intelligenter Zeiger?

Im Allgemeinen ist ein Zeiger eine Variable, die eine Speicheradresse speichert und typischerweise auf einen Wert zeigt, der an dieser Adresse abgelegt ist.

Allerdings können rohe Zeiger gefährlich sein: Wenn der Zeiger nicht auf gültigen Speicher zeigt oder falsch dereferenziert wird, kann das zu Abstürzen oder unvorhersehbarem Verhalten führen.

Intelligente Zeiger lösen dieses Problem, indem sie strikte Regeln für die Speicherverwaltung durchsetzen und so sicherstellen, dass auf den Speicher sicher und kontrolliert zugegriffen wird.

Cairo verwendet wie viele moderne Sprachen, etwa Rust, intelligente Zeiger, um unsicheren Speicherzugriff zu verhindern.

Ein intelligenter Zeiger in Cairo speichert nicht nur eine Speicheradresse, sondern verfolgt auch die Eigentümerschaft und gewährleistet Speichersicherheit.

## Typen von intelligenten Zeigern in Cairo

Cairo bietet mehrere Typen intelligenter Zeiger, darunter `Box<T>` und `Nullable<T>`, die jeweils einem anderen Zweck dienen.

Schauen wir uns genauer an, wie diese Typen funktionieren und wann du sie verwenden könntest.

### `Box<T>`

Der Typ `Box<T>` ist der wichtigste intelligente Zeiger in Cairo.

Er ermöglicht es dir, Daten in einem speziellen Speichersegment zu speichern, dem sogenannten „boxed segment“. Eine `Box<T>` ist ein Zeiger, der auf dieses Segment zeigt, und wenn du eine Box erstellst, weist du Speicher für die Daten in diesem Segment zu.

Boxen sind ideal in Situationen, in denen:

- Du musst einen Wert eines Typs speichern, dessen Größe zur Kompilierzeit nicht bestimmt werden kann.
- Du hast eine große Datenmenge und möchtest die Eigentümerschaft übertragen, ohne sie zu kopieren.

Durch die Verwendung einer Box kannst du große Datenstrukturen effizienter speichern.

Wenn du eine `Box<T>` an eine Funktion übergibst, wird nur der Zeiger übergeben. Dadurch muss nicht der gesamte Inhalt kopiert werden, was die Leistung verbessert, besonders bei großen Strukturen.

### `Nullable<T>`

Der Typ `Nullable<T>` ist ein weiterer wichtiger intelligenter Zeiger in Cairo.

Er kann entweder auf einen gültigen Wert vom Typ `T` zeigen oder `null` sein, wenn kein Wert vorhanden ist.

Dieser Typ ist nützlich, wenn du Werte speichern musst, die nicht immer vorhanden sind, etwa in einem Wörterbuch, das optionale Elemente enthalten kann.

In Cairo wird `Nullable<T>` typischerweise in Wörterbüchern verwendet, um Fälle zu behandeln, in denen kein Standardwert angewendet werden kann.

Er ermöglicht es dir, Werte bedingt zu speichern, wodurch du das Fehlen von Daten sicherer handhaben kannst.

## Speichersicherheit mit intelligenten Zeigern

Einer der Hauptvorteile intelligenter Zeiger ist, dass sie helfen, die Speichersicherheit zu gewährleisten.

Durch die Verwaltung von Eigentümerschaft und Zugriffsregeln verhindert Cairo häufige Probleme wie das Dereferenzieren von Null- oder hängenden Zeigern.

Intelligente Zeiger verfolgen, wann Daten nicht mehr benötigt werden, und können Speicher automatisch freigeben, wenn er den Gültigkeitsbereich verlässt, wodurch das Risiko von Speicherlecks verringert wird.

### Beispiel: `Box<T>` für rekursive Typen verwenden

Eine häufige Herausforderung in vielen Programmiersprachen ist der Umgang mit rekursiven Typen.

Rekursive Typen sind Typen, die Verweise auf sich selbst enthalten.

Ohne ordnungsgemäße Speicherverwaltung kann das Definieren eines rekursiven Typs zu Problemen wie Endlosrekursion führen.

In Cairo ermöglicht `Box<T>` das sichere Definieren rekursiver Typen.

Zum Beispiel kannst du `Box<T>` verwenden, um einen Binärbaum zu implementieren, bei dem jeder Knoten einen Verweis auf einen anderen Knoten enthält.

Indem Verweise in Boxen gespeichert werden, stellt Cairo sicher, dass die Speichernutzung endlich ist, und der Compiler kann die benötigte Speichergröße für die Struktur bestimmen.

```rust
use core::box::{BoxTrait};

#[derive(Copy, Drop)]
enum BinaryTree {
    Leaf: u32,
    Node: (u32, Box<BinaryTree>, Box<BinaryTree>),
}

fn main() {
    let leaf1 = BinaryTree::Leaf(1);
    let leaf2 = BinaryTree::Leaf(2);
    let node = BinaryTree::Node((3, BoxTrait::new(leaf1), BoxTrait::new(leaf2)));
    println!("{:?}", node);
}
```

### Leistungsvorteile intelligenter Zeiger

Intelligente Zeiger verbessern auch die Leistung deiner Programme.

Wenn du `Box<T>` verwendest, wird nur der Zeiger auf die Daten weitergegeben, anstatt die gesamte Datenstruktur zu kopieren.

Das ist besonders nützlich beim Umgang mit großen Datenmengen, da es den Overhead von Speicheroperationen erheblich reduziert.

Im folgenden Beispiel werden die Daten per Referenz mit einer `Box<T>` übergeben, um die Kosten für das Kopieren der gesamten Struktur zu vermeiden:

```rust
#[derive(Drop)]
struct Cart {
    paid: bool,
    items: u256,
    buyer: ByteArray,
}

fn pass_data(cart: Cart) {
    println!("{} is shopping today and bought {} items", cart.buyer, cart.items);
}

fn pass_pointer(cart: Box<Cart>) {
    let cart = cart.unbox();
    println!("{} is shopping today and bought {} items", cart.buyer, cart.items);
}

fn main() {
    let new_cart = Cart { paid: true, items: 1, buyer: "John" };
    pass_data(new_cart);

    let new_box = BoxTrait::new(Cart { paid: false, items: 3, buyer: "Jane" });
    pass_pointer(new_box);
}
```

In diesem Beispiel nimmt `pass_pointer` eine `Box<Cart>` anstelle einer `Cart` entgegen, wodurch die Menge des während des Funktionsaufrufs kopierten Speichers reduziert wird.
