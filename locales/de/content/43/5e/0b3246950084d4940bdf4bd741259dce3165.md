# Anleitung

Implementiere die Operation `accumulate`. Sie bekommt eine Sammlung und eine Operation, die auf jedes Element der Sammlung angewendet wird, und gibt eine neue Sammlung zurück, die das Ergebnis der Anwendung dieser Operation auf jedes Element der Eingabesammlung enthält.

Gegeben ist die Sammlung von Zahlen:

- 1, 2, 3, 4, 5

Und die Operation:

- eine Zahl quadrieren (`x => x * x`)

Dein Code sollte die Sammlung der Quadrate erzeugen können:

- 1, 4, 9, 16, 25

Schau dir die Testsuite an, um die erwartete Funktionssignatur zu sehen.
