# Anleitung

Gib die Zahlen von 1 bis n nach folgenden Regeln aus:

1. Wenn die Zahl ein Vielfaches von 3 ist, gib „Fizz“ aus.
2. Wenn die Zahl ein Vielfaches von 5 ist, gib „Buzz“ aus.
3. Wenn die Zahl sowohl ein Vielfaches von 3 als auch von 5 ist, gib „Fizz Buzz“ aus.
4. Wenn die Zahl kein Vielfaches von 3 oder 5 ist, gib die Zahl aus.

Die Ausgabe sollte ein Vektor von Strings sein, zum Beispiel „1“ „2“ „Fizz“ „4“ „Buzz“ ...
