# Einführung

Ein `str` in Python ist eine [unveränderliche Sequenz][text sequence] von [Unicode-Codepunkten][unicode code points].
Dazu gehören Buchstaben, diakritische Zeichen, Positionierungszeichen, Zahlen, Währungssymbole, Emojis, Satzzeichen, verschiedene Leerzeichen, Zeilenumbrüche und mehr.

Strings implementieren alle [allgemeinen Sequenzoperationen][common sequence operations] und können mit der Syntax `for item in <str>` oder `for index, item in enumerate(<str>)` durchlaufen werden.
Sie können mit `<str> + <other str>` oder `<str>.join(<iterable>)` verkettet und mit `<str>.split(<separator>)` aufgeteilt werden und bieten vielfältige Formatierungs- und Zusammenbauoptionen.

Für die weitergehende Arbeit mit Strings bietet Python eine umfangreiche Sammlung von [String-Methoden][str-methods], die beim Suchen, Bereinigen, Umwandeln, Übersetzen und bei vielen anderen Operationen helfen.

Da ein `str`-Objekt _unveränderlich_ ist, ändert sich sein Wert im Speicher nicht; Methoden, die einen String zu verändern scheinen, geben eine neue Kopie oder Instanz dieses `str`-Objekts zurück.

[str-methods]: https://docs.python.org/3/library/stdtypes.html#string-methods
