# Datenbank: Hohe Ausgaben

## Problemstellung

ABC Corp möchte, dass du den Namen und die Abteilung von Mitarbeitern findest, deren Zahlungseinträge einen bestimmten Betrag überschreiten (z. B. `3000.00`).

Erstelle einen Record namens `HighPayment`, um die benötigten Daten zurückzugeben. Die Definition des Records sieht wie folgt aus.

```ballerina
type HighPayment record {
    string name;
    string department;
    decimal amount;
    string reason;
};
```

Verwende die `query`-Operation des JDBC-Clients, um die benötigten Daten aus der Datenbank zu holen.

> HINWEIS: Sortiere das Ergebnis aufsteigend nach `payment_id`.

## Datenbankdetails

Verwende für diese Aufgabe die bereitgestellte H2-Datenbank.

> Die Beispieldatenbankdatei ist `gofigure.mv.db` und der Datenbankname ist `gofigure`. Sie liegt im Ordner `db`.

Die folgenden Tabellen sind mit einigen Beispieldaten bereits in der H2-Beispieldatenbank enthalten. Die Spaltennamen und Datentypen findest du unten.

**Tabellenname**: `Employee`

| **Spalten:**      | Typ |
| -----------       | ----------- |
| `employee_id`     | Ganzzahl, automatisch hochgezählter Primärschlüssel       |
| `name`            | String        |
| `city`            | String        |
| `department`      | String        |
| `age`             | Ganzzahl        |

**Tabellenname**: `Payment`

| **Spalten:**      | Typ |
| -----------       | ----------- |
| `payment_id`      | Ganzzahl, automatisch hochgezählter Primärschlüssel       |
| `date`            | Datum        |
| `amount`          | Gleitkommazahl        |
| `employee_id`     | Ganzzahl        |
| `reason`          | String        |

* Die Datenbankdatei ist `gofigure.mv.db`. Verwende die JDBC-URL `jdbc:h2:file:/path/to/db/file`
* Benutzername: `root`
* Passwort: `root`

## Einschränkungen

* Verwende die im Ordner `db` bereitgestellte H2-Datenbankdatei, um Abfragen und das Ballerina-Beispiel zu überprüfen
* Verwende den Ansatz über die Maven-Dependency-Parameter, um den H2-Datenbanktreiber in deiner Ballerina.toml als Plattform-Abhängigkeit hinzuzufügen

## Testumgebung

## Beispiele

### Beispiel 1

**Eingabe:** dbFilePath : `“/Path/to/file/gofigure”`, amount : `3000`

**Ausgabe:** `[{"name":"Anita Bath","department":"Marketing", "amount":3400, "reason": "Stationary"}, {"name":"Amanda Hug","department":"Engineering", "amount":4400, "reason": "Travel expenses"}]`

## Hinweise

* Verwende das Modul [ballerinax/java.jdbc](https://central.ballerina.io/ballerinax/java.jdbc), um mit der Datenbank zu arbeiten
* Sieh dir den Abschnitt [Voraussetzungen](https://lib.ballerina.io/ballerinax/java.jdbc/latest) an, um die Schritte zum Hinzufügen des JDBC-Treibers als Abhängigkeit zu finden
* Verwende die Remote-Methode [query](https://lib.ballerina.io/ballerinax/java.jdbc/latest#Client-query), um Daten aus der Datenbank abzufragen
* Sieh dir das Beispiel [Einfache Abfrage](https://ballerina.io/learn/by-example/mysql-query-operation) an
* Verwende den [stream](https://ballerina.io/learn/by-example/stream-type)-Typ von Ballerina, um auf die Daten zuzugreifen
* Verwende SQL-Joins, um den benötigten Datensatz aus der Datenbank zu finden
