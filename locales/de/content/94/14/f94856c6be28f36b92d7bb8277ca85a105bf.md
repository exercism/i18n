# Einführung

## For-Schleifen

Eine `for`-Anweisung wiederholt einen Block.
Ihre erste Zeile legt fest, wie oft der Block wiederholt wird:

```go
for init; condition; post {
    // loop body
}
```

- Die **init**-Anweisung läuft einmal vor der ersten Iteration. Üblicherweise deklariert und initialisiert man dort eine Zählvariable, die die Schleife verwendet.
- Die **condition** ist ein boolescher Ausdruck, der vor jeder Iteration ausgewertet wird. Die Schleife endet, wenn er zu `false` ausgewertet wird.
- Die **post**-Anweisung läuft nach jeder abgeschlossenen Iteration. Mit ihr lässt sich ein Zähler aktualisieren.

Setze `init; condition; post` nicht in runde Klammern.
Die geschweiften Klammern um den Schleifenblock sind jedoch immer erforderlich.

Diese Schleife startet `i` bei `1`, gibt den aktuellen Wert von `i` aus, erhöht ihn für die nächste Iteration und stoppt, wenn `i` den Wert `10` erreicht:

```go
for i := 1; i < 10; i++ {
    fmt.Println(i)
}
```
