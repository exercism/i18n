# Anleitung

In dieser Übung implementierst du die Quest-Logik für ein neues RPG, das ein Freund gerade entwickelt.

Die Hauptfigur des Spiels ist Annalyn, ein tapferes Mädchen mit einem wilden und treuen Hund. Doch dann schlägt das Unglück zu: Ihre beste Freundin wurde entführt, während sie im Wald nach Beeren suchte.

Annalyn wird versuchen, ihre beste Freundin zu finden und zu befreien, und dabei wahlweise ihren Hund mit auf diese Quest nehmen.

Nachdem sie eine Zeit lang der Spur ihrer besten Freundin gefolgt ist, findet sie das Lager, in dem ihre beste Freundin gefangen gehalten wird. Es stellt sich heraus, dass es zwei Entführer gibt: einen mächtigen Ritter und einen gerissenen Bogenschützen.

Nachdem sie die Entführer gefunden hat, überlegt Annalyn, welche der folgenden Aktionen sie ausführen kann:

- _Schnellangriff_: Ein Schnellangriff ist möglich, wenn der Ritter schläft, denn er braucht Zeit, um seine Rüstung anzulegen, und ist dann verwundbar.
- _Spionieren_: Die Gruppe kann ausspioniert werden, wenn mindestens einer von ihnen wach ist. Ansonsten ist Spionieren Zeitverschwendung.
- _Gefangene signalisieren_: Der Gefangene kann mit Vogelstimmen signalisiert werden, wenn der Gefangene wach ist und der Bogenschütze schläft, denn Bogenschützen sind im Signalisieren mit Vogelstimmen ausgebildet und könnten die Nachricht abfangen.
- _Gefangene befreien_: Annalyn kann versuchen, sich ins Lager zu schleichen, um den Gefangenen zu befreien.
  Das ist riskant und kann nur auf eine von zwei Arten gelingen:
  - Wenn Annalyn ihren Hund dabei hat, kann sie den Gefangenen befreien, wenn der Bogenschütze schläft.
    Der Ritter hat Angst vor dem Hund, und der Bogenschütze hat keine Zeit, sich bereit zu machen, bevor Annalyn und der Gefangene entkommen können.
  - Wenn Annalyn ihren Hund nicht dabei hat, müssen sie und der Gefangene sehr leise sein!
    Annalyn kann den Gefangenen befreien, wenn der Gefangene wach ist und sowohl der Ritter als auch der Bogenschütze schlafen. Wenn der Gefangene jedoch schläft, kann er nicht befreit werden: Annalyns plötzliches Auftauchen würde ihn erschrecken und den Ritter und den Bogenschützen aufwecken.

Du hast vier Aufgaben: Implementiere die Logik, mit der du anhand des Zustands der drei im Wald gefundenen Charaktere und der Anwesenheit von Annalyns Hund entscheidest, ob die oben genannten Aktionen möglich sind.

## 1. Prüfe, ob ein Schnellangriff möglich ist

Implementiere die Methode `canFastAttack()`, die einen booleschen Wert entgegennimmt, der angibt, ob der Ritter wach ist. Die Methode gibt `true` zurück, wenn ein Schnellangriff basierend auf dem Zustand des Ritters möglich ist. Andernfalls gibt sie `false` zurück:

```haxe
var knightIsAwake = true;
canFastAttack(knightIsAwake);
// => false
```

## 2. Prüfe, ob die Gruppe ausspioniert werden kann

Implementiere die Methode `canSpy()`, die drei boolesche Werte entgegennimmt, die angeben, ob der Ritter, der Bogenschütze bzw. der Gefangene wach sind. Die Methode gibt `true` zurück, wenn die Gruppe basierend auf dem Zustand der drei Charaktere ausspioniert werden kann. Andernfalls gibt sie `false` zurück:

```haxe
var knightIsAwake = false;
var archerIsAwake = true;
var prisonerIsAwake = false;
canSpy(knightIsAwake, archerIsAwake, prisonerIsAwake);
// => true
```

## 3. Prüfe, ob der Gefangene signalisiert werden kann

Implementiere die Methode `canSignalPrisoner()`, die zwei boolesche Werte entgegennimmt, die angeben, ob der Bogenschütze bzw. der Gefangene wach sind. Die Methode gibt `true` zurück, wenn der Gefangene basierend auf dem Zustand der zwei Charaktere signalisiert werden kann. Andernfalls gibt sie `false` zurück:

```haxe
var archerIsAwake = false;
var prisonerIsAwake = true;
canSignalPrisoner(archerIsAwake, prisonerIsAwake);
// => true
```

## 4. Prüfe, ob der Gefangene befreit werden kann

Implementiere die Methode `canFreePrisoner()`, die vier boolesche Werte entgegennimmt. Die ersten drei Parameter geben an, ob der Ritter, der Bogenschütze bzw. der Gefangene wach sind. Der letzte Parameter gibt an, ob Annalyns Hund dabei ist. Die Methode gibt `true` zurück, wenn der Gefangene basierend auf dem Zustand der drei Charaktere und der Anwesenheit von Annalyns Hund befreit werden kann. Andernfalls gibt sie `false` zurück:

```haxe
var knightIsAwake = false;
var archerIsAwake = true;
var prisonerIsAwake = false;
var petDogIsPresent = false;
canFreePrisoner(knightIsAwake, archerIsAwake, prisonerIsAwake, petDogIsPresent);
// => false
```
