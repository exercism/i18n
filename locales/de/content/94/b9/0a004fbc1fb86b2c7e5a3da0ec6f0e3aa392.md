# Einführung

Boolesche Werte in Cairo werden durch den vordeklarierten booleschen Typ `bool` dargestellt, dessen Werte entweder `true` oder `false` sein können.

```rust
let speeding = true;   // Boolean variable 'speeding' set to 'true'
let has_error = false; // Boolean variable 'has_error' set to 'false' 
```

Cairo unterstützt drei logische Operatoren, die Ausdrücke zu booleschen Werten auswerten und entweder `true` oder `false` zurückgeben.

| Operator    | Bedeutung                                                       |
| ----------- | --------------------------------------------------------------- |
| `&&` (und)  | Ist wahr, wenn beide Aussagen wahr sind.                        |
| `\|\|` (oder) | Ist wahr, wenn mindestens eine Aussage wahr ist.              |
| `!` (nicht) | Ist nur wahr, wenn die Aussage falsch ist.                      |
