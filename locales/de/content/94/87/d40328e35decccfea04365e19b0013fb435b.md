# Exakte Zahlen

Zwei der Zahlentypen, die du kennengelernt hast, verzichten auf etwas.

`INT` ist genau 32 Bit groß, also passen Zahlen von etwa minus zwei Milliarden bis zwei Milliarden hinein und nicht weiter. Gehst du darüber hinaus, gibt es einen stillen Überlauf: kein Fehler, nur eine falsche Antwort.

`FLTD` speichert Brüche, aber nur näherungsweise. `0.1d + 0.2d` ist sehr nahe an `0.3` und nicht exakt.

Für Arbeiten, bei denen es darauf ankommt, hat die Bibliothek jeweils einen Typ.

## INTI: Ganzzahlen beliebiger Größe

`INTI` speichert eine Ganzzahl ohne andere Begrenzung als den Speicher.

```sather
   #INTI(2).pow(100)
   -- 1267650600228229401496703205376
```

Ein `INT` kann das nicht speichern. Eine `FLTD` könnte etwas Ähnliches speichern und würde die letzten zwanzig Ziffern verlieren.

Erzeuge eine aus einem `INT` oder aus einem String, wenn die Zahl zu groß ist, um sie überhaupt als `INT` zu schreiben:

```sather
   #INTI(42)
   #INTI("123456789012345678901234567890")
```

Dann funktionieren `+`, `-`, `*`, `/` und Vergleiche wie gewohnt, und `.str` liefert jede Ziffer.

Das Zählen der Möglichkeiten, wie eine Tanzgruppe sich aufstellen kann, ist der übliche Grund, das zu wollen. Zwölf Tänzer haben 479001600 Möglichkeiten, was eine `INT` speichern kann; dreizehn haben 6227020800, was sie nicht kann.

```sather
   #INTI(20).factorial
   -- 2432902008176640000
```

## RAT: exakte Brüche

`RAT` speichert eine Ganzzahl über einer anderen und behält sie so.

```sather
   #RAT(1, 3)          -- 1/3, exactly
   #RAT(1, 2) + #RAT(1, 3)
   -- 5/6
```

Es findet keine Rundung statt, weil nichts jemals in eine Dezimalzahl umgewandelt wird.

```sather
   #RAT(1, 10) + #RAT(2, 10) = #RAT(3, 10)      -- true
   0.1d + 0.2d = 0.3d                            -- not to be relied on
```

Eine `RAT` kürzt sich selbst: `#RAT(2, 4)` ist `1/2` und wird als `1/2` ausgegeben. Eine, die ganzzahlig aufgeht, wird als ganze Zahl ausgegeben: `#RAT(6, 3)` gibt `2` aus.

## Die Kosten

Beide sind langsamer als die eingebauten Typen und beide belegen Speicher. `INT` und `FLTD` sind einzelne Maschinenbefehle; `INTI` und `RAT` sind Objekte, die Arithmetik in Software ausführen.

Verwende sie, wo Exaktheit das Ziel ist, und die gewöhnlichen Typen überall sonst.
