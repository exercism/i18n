# Anleitung

Du bist ein Elf, der in der Logistikabteilung des Weihnachtsmanns arbeitet, und hast von deinem Chef zwei Aufgaben bekommen, um die Software des Systems zu verbessern.

## 1. Ermittle den Namen des Spielzeugs

Das System muss den Namen eines Spielzeugs aus der Datenbank auslesen können.
Die Datenbank besteht aus Tupeln vom Typ `(name: String, quantity: Int)`.

Implementiere die Funktion `getName(_:)`, die ein Argument entgegennimmt, das ein Tupel vom Typ `(name: String, quantity: Int)` enthält.

```swift
let toy = (name: "Doll", quantity: 10)
getName(toy)
// Returns "Doll"
```

## 2. Füge ein neues Spielzeug zur Datenbank hinzu

Der Spielzeugmarkt ist schnelllebig, und was beliebt ist, ändert sich sehr schnell.
Deshalb wird eine Funktion benötigt, die ein neues Spielzeug erstellt.

Implementiere die Funktion `createToy(name:amount:)`, die das Argument `name`, das den Namen des Spielzeugs enthält, und `amount`, das die Anzahl des Spielzeugs enthält, entgegennimmt.

```swift
createToy(name: "Doll", amount: 10)
// Returns (name: "Doll", amount: 10)
```

## 3. Aktualisiere die Anzahl eines Spielzeugs

Die Elfen in der Werkstatt des Weihnachtsmanns stellen ständig neue Spielzeuge her, und der Weihnachtsmann muss die Anzahl jedes Spielzeugs im Blick behalten.
Dazu muss das System die Anzahl eines Spielzeugs in der Datenbank aktualisieren können.

Implementiere die Funktion `updateQuantity(_:toy:Amount:)`, die folgende Argumente entgegennimmt:
- `toys`, das ein Array von Tupeln vom Typ `(name: String, quantity: Int)` enthält.
- `toy`, das den Namen des zu aktualisierenden Spielzeugs enthält.
- `amount`, das die neue Anzahl des Spielzeugs enthält.

Du kannst davon ausgehen, dass das Spielzeug bereits in der Datenbank ist, und musst das nicht prüfen.

```swift
let toys = [(name: "Doll", quantity: 10), (name: "Car", quantity: 5), (name: "Train", quantity: 3)]
updateQuantity(toys, toy: "Doll", amount: 15)
// Returns [(name: "Doll", quantity: 15), (name: "Car", quantity: 5), (name: "Train", quantity: 3)]
```

## 4. Füge einem Spielzeug einen Kategorieschlüssel hinzu

Der Weihnachtsmann möchte die Spielzeuge in der Datenbank kategorisieren können.
So kann er die Spielzeuge leicht finden, wenn er eine Lieferung machen muss, und die Spielzeuge in der Datenbank sortieren.

Allerdings wurde der Kategorieschlüssel vergessen, als das System zum ersten Mal implementiert wurde.
Jetzt muss das System einem Spielzeug in der Datenbank einen Kategorieschlüssel hinzufügen können.

Implementiere die Funktion `addCategory(_:category:)`, die folgende Argumente entgegennimmt:
- `toys`, das ein Array von Tupeln vom Typ `(name: String, quantity: Int)` enthält.
- `category`, das den Kategorieschlüssel enthält, der zu den Spielzeugen hinzugefügt wird.

Du kannst davon ausgehen, dass das Spielzeug bereits in der Datenbank ist, und musst das nicht prüfen.
Du kannst außerdem davon ausgehen, dass das Spielzeug noch keinen Kategorieschlüssel hat.

```swift
let toys = [(name: "Car", quantity: 5), (name: "Train", quantity: 3)]
addCategory(toys, category: "Vehicle")
// Returns [(name: "Car", quantity: 5, category: "Vehicle"), (name: "Train", quantity: 3, category: "Vehicle")]
```
