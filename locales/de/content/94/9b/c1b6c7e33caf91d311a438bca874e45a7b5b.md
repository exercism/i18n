# Anweisungen

Elena ist die neue Qualitätsmanagerin einer Zeitungsfabrik.
Da sie gerade erst im Unternehmen angekommen ist, hat sie beschlossen, einige Abläufe in der Fabrik zu überprüfen, um zu sehen, was verbessert werden könnte.

Sie hat herausgefunden, dass die Techniker viele Qualitätsprüfungen von Hand durchführen.

Sie sieht eine gute Gelegenheit zur Automatisierung und bittet dich, einen freiberuflichen Entwickler, eine Software zu entwickeln, die einige der Maschinen überwacht.

## 1. Überwache die Luftfeuchtigkeit im Raum

Deine erste Aufgabe ist es, eine Software zu schreiben, die die Luftfeuchtigkeit im Produktionsraum überwacht.
Es gibt bereits einen Sensor, der mit der Software des Unternehmens verbunden ist und regelmäßig den Prozentsatz der Luftfeuchtigkeit im Raum zurückgibt.

Du musst eine Funktion in der Software implementieren, die einen Fehler auslöst, wenn der Prozentsatz der Luftfeuchtigkeit zu hoch ist.
Die Funktion soll `check_humidity_level` heißen und den Prozentsatz der Luftfeuchtigkeit als Parameter entgegennehmen.

Du sollst mit einem Fehler abbrechen (die Meldung ist nicht wichtig), wenn der Prozentsatz 70 % überschreitet.
Andernfalls gib eine Meldung aus, die „humidity test passed“ enthält, und gib `TRUE` zurück, um zu bestätigen, dass die Messung in Ordnung ist.

```R
check_humidity_level(60)
#> humidity test passed
#> [1] TRUE

check_humidity_level(100)
#> Error in check_humidity_level(100) : pct_humidity <= 70 is not TRUE
```

## 2. Überhitzung erkennen

Elena ist mit deiner ersten Aufgabe sehr zufrieden und bittet dich, dich um die Überwachung der Temperatur der Maschinen zu kümmern.
Beim Plaudern mit einem Techniker, Greg, erfährst du, dass die Techniker sich Sorgen um eine Überhitzung machen, wenn die Temperatur einer Maschine 500 °C überschreitet.

Die Maschine ist mit einem Sensor ausgestattet, der ihre Innentemperatur misst.
Du solltest wissen, dass der Sensor sehr empfindlich ist und oft kaputtgeht.
In diesem Fall müssen die Techniker ihn austauschen.

Deine Aufgabe ist es, eine Funktion `report_overheating` zu implementieren, die die Temperatur als Parameter entgegennimmt und einen Fehler auslöst, wenn der Sensor defekt ist oder die Maschine zu überhitzen beginnt.

Da du später je nach Fehler unterschiedlich reagieren musst, brauchst du einen Mechanismus, um die beiden Fehlerarten zu unterscheiden.

- Wenn der Sensor defekt ist, ist die Temperatur `NULL`.
  In diesem Fall sollst du mit einer Fehlermeldung abbrechen, die „Sensor Broken“ als Teil des Strings enthält.
- Wenn der Sensor funktioniert und die Temperatur 600 °C überschreitet, sollst du mit einer Meldung abbrechen, die die Temperatur enthält.
- Wenn die Temperatur 500 °C überschreitet, aber nicht 600 °C, sollst du eine Warnung ausgeben, die die Temperatur enthält, und `FALSE` zurückgeben.
- Andernfalls ist alles in Ordnung, also gib die Meldung `"temperature check passed: t °C"` aus, wobei `t` die Temperatur ist, und gib `TRUE` zurück.

```R
report_overheating(NULL)
#> Error in report_overheating(NULL) : Sensor Broken

report_overheating(800)
#> Error in report_overheating(800) : Overheating: 800 C

report_overheating(550)
#> [1] FALSE
#> Warning message:
#> In report_overheating(550) : Risk of overheating: 550 C

report_overheating(450)
#> temperature check passed: 450 °C
#> [1] TRUE
```


## 3. Überwache die Maschine

Jetzt, da deine Maschine Fehler erkennen kann und du einen eigenen Maschinenfehler hast, fügst du eine Wrapper-Funktion hinzu, die melden kann, wie alles läuft.
Neben dem Zurückgeben der Protokolle aus den vorherigen Funktionen muss dieser Wrapper auch Protokolle hinzufügen, je nachdem, welche Art(en) von Fehler(n) auftreten.

- Überprüfe die Luftfeuchtigkeit und die Temperatur.
- Wenn es Probleme gibt, lass `check_humidity_level()` und `report_overheating()` einfach ihre Protokolle ausgeben.
- Wenn alles in Ordnung ist, füge eine Meldung hinzu, die „All OK“ enthält.

Implementiere eine Funktion `monitor_the_machine()`, die die Luftfeuchtigkeit und die Temperatur als Argumente entgegennimmt.

```R
# Working well
monitor_the_machine(53, 200)
#> humidity test passed
#> temperature check passed: 200 °C
#> All OK!

# High humidity
monitor_the_machine(90, 200)
#> Error in check_humidity_level(pct_humidity) : 
#>   pct_humidity <= 70 is not TRUE

# Faulty sensor
monitor_the_machine(53, NULL)
#> humidity test passed
#> Error in report_overheating(temperature) : Sensor Broken

# Mild overheating
monitor_the_machine(53, 550)
#> humidity test passed
#> Warning message:
#> In report_overheating(temperature) : Risk of overheating: 550 C

# Dangerous overheating: shutdown
monitor_the_machine(53, 650)
#> humidity test passed
#> Error in report_overheating(temperature) : Overheating: 650 C
```
