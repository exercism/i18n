# Anweisungen

Du wurdest als Spezialist für reguläre Ausdrücke in einem Unternehmen eingestellt, das einen Chatbot entwickelt.

Er befindet sich in einer sehr frühen Entwicklungsphase.
Deine Aufgabe ist es, reguläre Ausdrücke zu verwenden, um die Fähigkeit des Chatbots zu verbessern, natürliche Sprache zu verstehen und zu erzeugen.

## 1. Gültigen Befehl prüfen

Der Chatbot ist nicht nur schlau, sondern auch ein loyaler Assistent.
Um den Chatbot etwas zu fragen, muss der Benutzer das Wort „**Chatbot**“ an der ersten Position des Befehls sagen.
Es spielt keine Rolle, ob das Schlüsselwort in Groß- oder Kleinbuchstaben steht.
Wichtig ist die Position des Wortes.

Implementiere die Funktion `is_valid_command`, die dem Chatbot hilft zu erkennen, wann der Benutzer einen Befehl gibt.

```jq
"Chatbot, play a song from the 80's." | is_valid_command
# => true
"Hey Chatbot, where is the closest pharmacy?" | is_valid_command
# => false
"CHATBOT, do you have a solution for this challenge?" | is_valid_command
# => true
```

## 2. Verschlüsselte Emojis entfernen

Der Chatbot hat Schwierigkeiten zu verstehen, wie Menschen Emojis verwenden, um ihre Gefühle auszudrücken.
Wenn der Chatbot Nachrichten von Benutzern empfängt, wird jedes Emoji als der String „emoji“ dargestellt, gefolgt von einer _ID-Nummer_.

Implementiere die Methode `remove_emoji`, die einen String entgegennimmt und alle Emojis aus der Nachricht entfernt.

Zeilen, die keine Emojis enthalten, sollen unverändert zurückgegeben werden.
Entferne einfach den String „emoji“.
Verändere die Leerzeichen nicht.

```jq
"I love playing videogames emoji3465 it's one of my hobbies" | remove_emoji
# => "I love playing videogames  it's one of my hobbies"
```

## 3. Gültige Telefonnummer prüfen

Irgendwann während der Interaktion mit dem Chatbot gibt der Benutzer eine Telefonnummer an.
Der Chatbot kann nur Nummern in einem bestimmten Format anrufen.

Implementiere die Funktion `check_phone_number`.

Wenn die Nummer gültig ist, antwortet der Chatbot mit einer Nachricht, in der er sich beim Benutzer bedankt und die Nummer bestätigt.
Wenn die Nummer ungültig ist, teilt der Chatbot dem Benutzer mit, dass die Telefonnummer nicht gültig ist.

Das erwartete Format ist `(+NN) NNN-NNN-NNN`, wobei N eine Ziffer ist.

```jq
"chatbot my phone number is (+34) 659-771-594" | check_phone_number
# => "Thanks! Your phone number is OK."
"chatbot, call me at 659-771-594" | check_phone_number
# => "Oops, it seems like I can't reach out to 659-771-594."
```

## 4. Website-Link ermitteln

Der Chatbot ist eine wirklich neugierige Software.
Obwohl er das Internet nach einem bestimmten Thema durchsuchen kann, fragt er Benutzer gern nach coolen Websites, die sie besuchen können, um relevante Informationen zu finden.

Beispielgespräch:

> **Chatbot**: Hey Benutzer, ich würde gern lernen, wie man in JavaScript programmiert. Kennst du eine coole Website, auf der ich das lernen kann?

> **Benutzer**: Ich habe viel auf exercism.org gelernt, dort gibt es jede Menge großartige Sachen.

Implementiere die Funktion `get_domains`, die ein Array von Website-Domains zurückgibt.

```jq
"I learned a lot from exercism.org and google.com" | get_domains
# => ["exercism.org", "google.com"]
```

## 5. Den Benutzer begrüßen

Ein höflicher Chatbot spricht Benutzer mit ihrem Namen an.
Wenn ein Benutzer sich vorstellt, erkennt unser Chatbot seinen Namen und antwortet mit einer freundlichen Begrüßung.

Schreibe die Funktion `nice_to_meet_you`.

Wenn der Eingabe-String „My name is Someone.“ enthält, erfasse den Namen und gib den String „Nice to meet you, Someone.“ zurück.

```jq
"My name is Jean-Luc" | nice_to_meet_you
# => "Nice to meet you, Jean-Luc"
```

## 6. Sehr einfaches CSV-Parsen

Weil wir uns der „schleichenden Funktionswut“ beugen, fügen wir dem Chatbot eine Funktion zum Parsen von CSV hinzu.

Implementiere die Funktion `parse_csv`, die einen String entgegennimmt und ein Array der resultierenden Felder zurückgibt.
Der Feldtrenner soll „Komma plus optionaler Leerraum“ sein.

Wir kümmern uns nicht um die Randfälle des CSV-Formats (etwa Felder, die Kommas enthalten).

```jq
"first, second,third,   fourth" | parse_csv
# => ["first", "second", "third", "fourth"]
```
