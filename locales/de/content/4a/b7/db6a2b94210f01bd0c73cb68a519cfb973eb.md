# Einführung

## Diskriminierte Unions

Eine diskriminierte Union stellt eine feste Anzahl benannter Fälle dar. Jeder Wert einer diskriminierten Union entspricht genau einem dieser benannten Fälle.

Du definierst eine diskriminierte Union mit dem Schlüsselwort `type`. Die einzelnen Fälle trennst du durch das Pipe-Zeichen (`|`):

```fsharp
type Season =
    | Spring
    | Summer
    | Autumn
    | Winter
```

Jeder Fall einer diskriminierten Union kann optional zugeordnete Daten haben, und verschiedene Fälle können unterschiedliche Datentypen haben. Wenn kein Fall zugeordnete Daten hat, ähnelt die diskriminierte Union dem, was andere Sprachen üblicherweise als _Enumeration_ (oder _Enum_) bezeichnen.

```fsharp
type Number =
    | Integer of int
    | Float of float
    | Invalid
```

Um einen Wert für einen bestimmten Fall zu erzeugen, gibst du seinen Namen an (z. B. `Success`). Da Fallnamen einfach Konstruktorfunktionen sind, kannst du die zugeordneten Daten wie ein normales Argument übergeben. Wenn eine andere diskriminierte Union bereits einen Fall mit demselben Namen definiert hat, musst du den vollständigen Namen verwenden (z. B. `Result.Success`).

```fsharp
let byName = Integer 2
let byFullName = Number.Invalid
```

Diskriminierte Unions besitzen _strukturelle Gleichheit_. Das heißt, zwei Werte für denselben Fall mit denselben (optionalen) Daten sind gleichwertig.

Du kannst zwar Ausdrücke mit `if/elif/else` verwenden, um mit diskriminierten Unions zu arbeiten, der empfohlene Weg ist aber der Musterabgleich mit dem _Bezeichnermuster_:

```fsharp
let describe number =
    match number with
    | Integer i -> sprintf "Integer: %d" i
    | Float d  -> sprintf "Float: %f" d
    | Invalid   -> "Invalid"
```
