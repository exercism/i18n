# Ignorieren

## Methodensignaturen in Wren

In Wren kannst du Methoden _nach ihrer Arität_ überladen.
Das heißt, deine Klasse kann zwei (oder mehr) Methoden mit dem **gleichen Namen** haben, solange sie eine unterschiedliche Anzahl von Argumenten akzeptieren.

Weitere Details findest du unter [Signaturen][signatures].

[signatures]: https://wren.io/method-calls.html#signature
