# Überblick

Viele Operatoren können auch als [zusammengesetzte Zuweisung][compound-assignment] verwendet werden. Das ist eine Kurzschreibweise, bei der `x = op y` als `x op= y` geschrieben werden kann:

```csharp
var features = PhoneFeatures.Call;
features |= PhoneFeatures.Text;
features &= ~PhoneFeatures.Call;
```
