# Einführung

Funktionen sind in Kotlin Bürger erster Klasse.
Das bedeutet, du kannst sie in Variablen speichern, als Argumente übergeben und sogar von anderen Funktionen zurückgeben lassen.
Zum Beispiel, wenn du eine Funktion der Variablen `addOne` zuweist:

```kotlin
val addOne = fun (num : Int) : Int {
    return num + 1
}
```

Eine Funktion kann auch eine andere Funktion zurückgeben:

```kotlin
fun makeAddOne() : (Int) -> Int {
    return fun(num : Int) : Int {
        return num + 1
    }
}

val addOne = makeAddOne()
```

Nach der Zuweisung kannst du die Funktion über die Variable aufrufen, als wäre sie eine ganz normale Funktion:
```kotlin
addOne(3)
// => 4
```

## Funktionstypen deklarieren

Du kannst den Typ einer Variablen oder eines Parameters mit der Syntax `(parameter types) -> return type` deklarieren.
Zum Beispiel beim Deklarieren einer Variablen:

```kotlin
val addOne : (Int) -> Int = fun (num : Int) : Int {
    return num + 1
}
```

Und für einen Parameter einer Funktion:

```kotlin
fun perform(operation : (Int) -> Int) {
    operation(3)
}
```

## Lambda-Ausdrücke

Ein Lambda-Ausdruck ist eine kürzere Art, eine Funktion zu definieren.
Sie werden in der Form `{ parameters -> body }` geschrieben.
Der Ausdruck gibt den letzten Wert der letzten Anweisung im Rumpf zurück.
Zum Beispiel:

```kotlin
// Assigning to a variable
val addOne = { num : Int -> num +  1}

// In a function call
perform({ num : Int -> num + 1 })
```

Kotlin kann Typen ableiten, wenn genügend Informationen vorhanden sind.
Zum Beispiel lassen sich die obigen Beispiele auch so schreiben:

```kotlin
// Assigning to a variable
val addOne : (Int) -> Int = { num -> num + 1 }

// Or ...
val addOne  = { num : Int -> num + 1 }

// Using in a function
perform({ num -> num + 1 })
```

## `it` für Lambdas mit einem einzigen Parameter

Wenn der Ausdruck nur einen Parameter hat, kannst du den Parameter weglassen.
Kotlin stellt dann im Rumpf einen Parameter namens `it` zur Verfügung.
Zum Beispiel:

```kotlin
val addOne : (Int) -> Int = { it +  1 }
```

## Trailing Lambdas übergeben

Wenn das letzte Argument einer Funktion ein Lambda ist, wird der Lambda-Ausdruck direkt _nach_ den runden Klammern geschrieben.
Zum Beispiel:

```kotlin
// Function that takes a function as last argument
fun calculateFrom(from : Int, operation : (Int) -> Int) : Int {
    return operation(from)
}

// Call the calculateFrom function
calculateFrom(2) { it * 3 }
// => 6
```
