# Einführung

Es ist oft nützlich, eine Sammlung von Elementen zusammenzufassen und diese Gruppen als Einheiten zu behandeln. In Rust nennen wir eine solche Gruppe ein Struct und jedes Element eines der Felder des Structs. Ein Struct legt die allgemeine Menge der verfügbaren Felder fest, aber ein konkretes Exemplar eines Structs nennt man Instanz.

Außerdem können für Structs Methoden definiert werden, die Zugriff auf die Felder haben. Das Struct selbst wird in diesem Fall als `self` bezeichnet. Wenn eine Methode `&mut self` verwendet, können die Felder geändert oder mutiert werden. Wenn eine Methode `&self` verwendet, können die Felder nicht geändert werden: sie sind unveränderlich. Die Kontrolle der Veränderbarkeit hilft dem Borrow-Checker dabei, sicherzustellen, dass ganze Klassen von Nebenläufigkeits-Bugs in Rust gar nicht erst auftreten.

In dieser Übung implementierst du zwei Arten von Methoden für ein Struct. Die Methoden der ersten Art heißen allgemein Getter: sie legen die Felder des Structs nach außen offen, ohne dass irgendjemand sonst diesen Wert verändern kann. In Rust tragen diese Methoden idiomatischerweise denselben Namen wie das Feld, das sie offenlegen. Wenn wir also eine Getter-Methode haben, die ein Struct-Feld namens `name` abruft, dann heißt die Methode einfach `name()`.

Du wirst außerdem Methoden einer anderen Art implementieren, die allgemein als Setter bekannt sind. Diese ändern den Wert des Feldes. Setter sind in Rust nicht sehr verbreitet. Wenn ein Feld frei geändert werden kann, ist es üblicher, es einfach öffentlich zu machen. Sie sind aber nützlich, wenn das Aktualisieren des Feldes Nebenwirkungen haben soll, oder für die Zugriffskontrolle: Ein als `pub(crate)` markierter Setter erlaubt anderen Modulen innerhalb desselben Crates, ein privates Feld zu aktualisieren, das von außen nicht beeinflusst werden kann.

Structs gibt es in drei Ausführungen: Structs mit benannten Feldern, Tupel-Structs und Unit-Structs. In dieser Konzeptübung schauen wir uns die erste Variante an: Structs mit benannten Feldern.

Structs werden mit dem Schlüsselwort `struct` definiert, gefolgt vom großgeschriebenen Namen des Typs, den das Struct beschreibt:

```rust
struct Item {}
```

Anschließend werden weitere Typen als _Felder_ des Structs in den Body des Structs eingebracht, jeweils mit ihrem eigenen Typ:

```rust
struct Item {
    name: String,
    weight: f32,
    worth: u32,
}
```

Schließlich können Methoden für Structs innerhalb eines `impl`-Blocks definiert werden:

```rust
impl Item {
    // initializes and returns a new instance of our Item struct
    fn new() -> Self {
        todo!()
    }
}
```
