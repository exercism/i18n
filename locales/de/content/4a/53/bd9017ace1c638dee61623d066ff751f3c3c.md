# Ergänzende Anweisungen

## Hinweise

Die Tests in dieser Übung unterscheiden sich von den Tests, die du sonst kennst. Normalerweise prüft ein Test, ob die Ausgabe für eine gegebene Eingabe dem erwarteten Wert entspricht. Das nennt man _wertbasiertes Testen_. Diese Übung verwendet jedoch _eigenschaftsbasiertes Testen_, bei dem die Tests prüfen, ob die Ausgabe für eine Reihe von Eingaben eine bestimmte Eigenschaft hat. Die zwei wichtigsten Unterschiede zwischen eigenschaftsbasiertem und wertbasiertem Testen sind:

1. Ein eigenschaftsbasierter Test arbeitet nicht mit einem einzelnen Eingabewert, sondern mit vielen.
1. Ein eigenschaftsbasierter Test überprüft Eigenschaften, nicht konkrete Werte.

In dieser Übung überprüfen alle Tests eine Eigenschaft der Rautenform, die dein Code erzeugen soll. Außerdem prüfen alle Tests, ob die Eigenschaft, die sie testen, für alle gültigen Eingabebuchstaben ('A' bis 'Z') gilt.

Um eigenschaftsbasiertes Testen zu ermöglichen, verwenden die Tests in dieser Übung die Pakete [FsCheck](https://www.nuget.org/packages/FsCheck) und [FsCheck.Xunit](https://packages.nuget.org/packages/FsCheck.Xunit/2.2.0). Mehr über FsCheck erfährst du in der [Dokumentation zum Framework](https://fscheck.github.io/FsCheck/).

Wenn du mehr über eigenschaftsbasiertes Testen erfahren möchtest, schau dir [diesen Artikel](http://www.erikschierboom.com/2016/02/22/property-based-testing/) an.
