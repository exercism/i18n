# Ergänzung zur Anleitung

## Register

| Register | Verwendung | Typ             | Beschreibung                             |
| -------- | ---------- | --------------- | ---------------------------------------- |
| `$a0`    | Eingabe    | Adresse         | nullterminierter Eingabe-String          |
| `$v0`    | Ausgabe    | boolescher Wert | gültige ISBN (`0` = `false`, `1` = `true`) |
| `$t0-9`  | temporär   | beliebig        | für temporäre Speicherung                |
