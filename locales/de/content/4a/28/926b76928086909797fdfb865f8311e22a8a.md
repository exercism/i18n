# Hinweise

## Allgemein

- Lies im [offiziellen Getting-Started-Leitfaden][getting-started-enum] oder auf [elixirschool.com][elixir-school-enum] etwas über das Modul `Enum`.
- Wirf einen Blick in die Dokumentation, um die vollständige [Liste der Funktionen im Modul `Enum`][enum-functions] zu sehen.

## 1. Artikel nach Preis sortieren

- Es gibt eine [eingebaute Funktion][enum-sort-by], um Enumerables mit einer Sortierfunktion zu sortieren.

## 2. Alle Artikel mit fehlenden Preisen finden

- Es gibt eine [eingebaute Funktion][enum-filter], um Enumerables zu filtern.

## 3. Artikelnamen aktualisieren

- Es gibt eine [eingebaute Funktion][enum-map], um jedes Element in einem Enumerable umzuwandeln.
- Es gibt eine [eingebaute Funktion][string-replace], die alle Vorkommen eines Strings durch einen anderen ersetzen kann.

## 4. Die Menge des Artikels erhöhen

- Maps implementieren das Enumerable-Protokoll.
- `Enum`-Funktionen wandeln Maps in eine Liste von `{key, value}`-Tupeln um.
- Es gibt zwei verschiedene Funktionen, die eine Liste von `{key, value}`-Tupeln mit einer Transformationsfunktion wieder in eine Map umwandeln können. [Eine davon gibt immer eine neue Map zurück][map-new], während [du bei der anderen ein Collectable auswählen kannst][enum-into].

## 5. Die Gesamtmenge des Artikels berechnen

- Maps implementieren das Enumerable-Protokoll.
- `Enum`-Funktionen wandeln Maps in eine Liste von `{key, value}`-Tupeln um.
- Es gibt eine [eingebaute Funktion][enum-reduce], um ein Enumerable auf einen einzelnen Wert zu reduzieren.
