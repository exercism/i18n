# Hinweise

## Allgemein

- Schau dir die [Array-Sprachreferenz][ref-arrays] an
- Schau dir die [Referenz der Array-Funktionen][ref-array-functions] an

## 1. Definiere eine Funktion, die eine leere Sprachenliste zurückgibt

- Schau dir die [Sprachreferenz][ref-arrays] an
- Du kannst ein leeres Array zurückgeben

## 2. Ändere die Funktion, sodass sie aus beliebig vielen Sprachen eine Liste erstellt

- Sieh in der Funktionsreferenz unter [Argumenten variabler Länge][variable-arguments] nach

## 3. Definiere eine Funktion, die eine Sprache zur Liste hinzufügt

- Erstelle eine neue Funktion, um die Operation auszuführen
- Verwende eine [bestehende Funktion][ref-array-functions] wieder oder nutze die [Einfügesyntax][square-bracket-syntax]

## 4. Definiere eine Funktion, die ein Element aus der Sprachenliste entfernt

- Erstelle eine neue Funktion, um die Operation auszuführen
- Verwende eine [bestehende Funktion][ref-array-functions] wieder, um die Operation auszuführen

## 5. Definiere eine Funktion, die das erste Element der Liste zurückgibt

- Erstelle eine neue Funktion, um die Operation auszuführen
- Nutze die [Indexsyntax][index-syntax], um das erste Element zu erhalten

## 6. Definiere eine Funktion, die zurückgibt, wie viele Sprachen in der Liste sind

- Erstelle eine neue Funktion, um die Operation auszuführen
- Verwende eine [bestehende Funktion][ref-array-functions] wieder, um die Operation auszuführen
