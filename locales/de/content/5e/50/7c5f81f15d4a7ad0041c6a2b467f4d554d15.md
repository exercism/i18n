# Über

[`fold`][fold] ist ein [konsumierender Iterator-Adaptor][consuming iterator adaptor], der eine Funktion auf jedes Element der Iteration anwendet und das Ergebnis in einem neuen Wert ansammelt.

Jeder Durchlauf von `fold` nimmt zwei Argumente entgegen. Das erste ist ein Startwert für den Akkumulator. Das zweite ist eine Closure, die selbst zwei Argumente entgegennimmt: den Akkumulator und ein Element. Der Rückgabewert der Closure ist der anschließende Wert des Akkumulators. Sobald der Iterator erschöpft ist, wird der endgültige Wert des Akkumulators zurückgegeben.

`fold` kannst du verwenden, wenn eine Sammlung in einen einzelnen Wert umgewandelt werden soll. Wenn du zum Beispiel die Summe aller geraden Zahlen haben möchtest

```rust
pub fn main() {
    let even_sum = (1..=10).fold(0, |acc, num| if num % 2 == 0 { acc + num } else { acc });
    println!("{even_sum:?}");
}
```

gibt das Programm `30` aus.

Was mit `fold` gemacht werden kann, lässt sich oft auch mit einer anderen Funktion oder mit mehreren Funktionen erledigen. Für das obige Beispiel wäre es weniger ausführlich, auf `(1..=10)` [`filter`][filter] und dann [`sum`][sum] anzuwenden; das Ergebnis wäre dasselbe, und zwar so

```rust
(0..=10).filter(|n| *n % 2 == 0).sum()
```

Weitere Funktionen, die häufiger als `fold` verwendet werden, sind [`product`][product] und [`collect`][collect].

Ein Akkumulator lässt sich auch für andere Werte als Zahlen verwenden. Zum Beispiel

```rust
pub fn giant_grunts(initial: char) -> String {
    ["Bee", "Fee", "Gee", "Fi", "Hi", "Fo", "Mo", "Fum", "Tum"].iter().fold(
        String::new(),
        |acc, grunt| if grunt.starts_with(initial) { acc + grunt } else { acc },
    )
}

pub fn main() {
    let song = giant_grunts('F');
    println!("{song:?}");
}
```

gibt das Programm `FeeFiFoFum` aus.
