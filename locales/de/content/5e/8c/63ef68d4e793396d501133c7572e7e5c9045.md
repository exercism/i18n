# Einführung

In Kotlin kannst du Klassen verwenden, um Daten und Verhalten zu kapseln.
Eine Klasse wird mit dem Schlüsselwort `class` deklariert.
Zum Beispiel:

```kotlin
class Car
```

Erstelle eine Instanz der Klasse, indem du sie aufrufst.

```kotlin
val instance = Car()
```

## Eigenschaften

In den obigen Beispielen wurde die Klasse `Car` ohne Eigenschaften deklariert.
Klasseneigenschaften lassen sich im Klassenkörper zwischen `{}` deklarieren, wobei du `var` für veränderbare Eigenschaften und `val` für unveränderbare verwendest.
Zum Beispiel:

```kotlin
class Car {
    // color is mutable
    var color = "red"

    // year is immutable
    val year = 2025
}
```

Alternativ lassen sich die Eigenschaften in einem Konstruktor definieren, der sie entgegennimmt.

## Konstruktoren

Kotlin kennt zwei Arten von Konstruktoren: primäre und sekundäre Konstruktoren.
Der primäre Konstruktor wird in derselben Zeile wie die Klassendeklaration deklariert.
Zum Beispiel:

```kotlin
class Car constructor(var color : String = "red", val year : Int = 2025) {
    // ...
}
```

Das Schlüsselwort `constructor` kannst du weglassen, wenn es keine Annotationen und keine Sichtbarkeitsmodifizierer gibt:

```kotlin
class Car(var color : String = "red", val year : Int = 2025) {
    // ...
}
```

~~~~exercism/note
Kotlin erlaubt es, die Klasse ohne Klassenkörper zu definieren, wenn sie nur Eigenschaften enthält. Dann brauchst du keine geschweiften Klammern `{}`:

```kotlin
class Car (var color : String = "red", val year : Int = 2025)
```
~~~~

Eine Klasse kann nur einen primären Konstruktor haben.
Sekundäre Konstruktoren sind weitere Konstruktoren, die du hinzufügen kannst, indem du sie im Klassenkörper mit dem Schlüsselwort `constructor` deklarierst.
Zum Beispiel:

```kotlin
class Car constructor(var color : String = "red", val year : Int = 2025) {

    // This constructor allows the year to be provided as a String
    constructor(color : String = "red", yearText : String) : this(color, yearText.toIntOrNull() ?: 0)
}
```

Sekundäre Konstruktoren müssen den primären Konstruktor aufrufen, indem sie `this` aufrufen.

## Initialisierungsblöcke

Der primäre Konstruktor setzt die Eigenschaften der Klasse.
Wenn während der Objekterstellung mehr erledigt werden muss, kannst du `init`-Blöcke verwenden, um zusätzliche Aktionen auszuführen.

```kotlin
class Car constructor(var color: String = "red", val year : Int = 2025) {
    init {
        println("Car is ${color}, made in ${year}")
    }
}
```

## Funktionen

Funktionen lassen sich im Klassenkörper definieren.
Zum Beispiel:

```kotlin
class Car (var color : String = "red", val year : Int = 2025) {
    fun repaint(newColor : String) {
        color = newColor
    }
}
```

## Sichtbarkeit

Eigenschaften und Funktionen können entweder `private`, `public`, `internal` oder `protected` sein.

- `private` ist nur innerhalb der Klasse zugänglich
- `protected` ist innerhalb der Klasse und in allen Unterklassen zugänglich
- `internal` ist innerhalb desselben Moduls zugänglich
- `public` ist für andere Komponenten zugänglich, die die Klasse verwenden

Zum Beispiel:

```kotlin
class Car {
    private val color: String
    public val year: Int
    internal val model: String
    protected val brand: String

    private fun drive() {
        // ...
    }

    internal fun start() {
        // ...
    }

    protected fun stop() {
        // ...
    }

    public fun make() {
        // ...
    }
}
```
