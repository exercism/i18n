# Testen im MoonScript-Track

Das Testen im MoonScript-Track funktioniert genau wie [das Testen im Lua-Track][lua-tests].
Gib aus einem Übungsverzeichnis heraus Folgendes ein:

```console
$ busted
```

## Ausstehende Tests

Dieser Track folgt der [testgetriebenen Entwicklung][tdd] von Exercism.
Du bekommst eine vollständige Testsuite, aber nur der erste Test ist „aktiv“.

Um die Tests zu aktivieren, ändere den Befehl eines Tests von `pending` zu `it`.

Wenn du gerne immer alle Tests ausführst, kannst du ein Kommandozeilen-Tool verwenden, um sie alle auf einmal zu ändern.
Hier ein Beispiel mit perl (das so gut wie überall installiert ist):

```console
$ perl -i -pe 's/^\s+\Kpending\b/it/' two_fer_spec.moon
```

Wenn du im Online-Editor arbeitest, führt der Test-Runner automatisch alle Tests aus.

## LuaRocks verwenden

Lua selbst ist eine sehr kleine Sprache.
[LuaRocks][luarocks] ist der Paketmanager für Lua-Module.

Du kannst in deinen Lösungen jedes Modul verwenden, aber nicht alle von ihnen sind im Online-Test-Runner verfügbar.
Der Test-Runner stellt diese bereit:

**Bereits als `busted`-Abhängigkeiten verfügbar**

* [penlight][penlight-home]
* [dkjson][dkjson-home]

**Bereits als MoonScript-Abhängigkeiten verfügbar**

* [LPeg][lpeg-home]
* [LuaFileSystem][lfs-home]

**Datum und Uhrzeit**

* [date][date-home]
* [lua-tz][lua-tz-home]
* [luatz][luatz-home]
