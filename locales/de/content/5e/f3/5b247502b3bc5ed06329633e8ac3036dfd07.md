# Überblick

Eine [switch-Anweisung][switch] vergleicht einen Wert mit mehreren möglichen passenden Mustern.
Sie ist eine sauberere und besser lesbare Alternative, als mehrere `if-else`-Anweisungen aneinanderzureihen.

Eine `switch`-Anweisung beginnt mit dem Schlüsselwort `switch`, gefolgt von dem Wert, der geprüft werden soll.
Jeder mögliche Treffer wird mit dem Schlüsselwort `case` eingeleitet.
Das Schlüsselwort `default` definiert einen Ausweichfall, der ausgeführt wird, wenn keiner der ausdrücklichen Fälle passt.
Wie `if-else`-Ketten führt eine `switch`-Anweisung nur den Codeblock aus, der zum ersten passenden Fall gehört.

```swift
switch value {
case 1:
    print("One")
case 2:
    print("Two")
default:
    print("Other")
}
```

Schau dir die folgende `if-else`-Kette an:

```swift
if str == "apple" {
    print("Let's bake an apple crumble")
} else if str == "lemon" {
    print("Let's bake a lemon meringue pie!")
} else if str == "peach" {
    print("Let's bake a peach pie!")
} else {
    print("Let's buy ice cream.")
}
```

Mit einer `switch`-Anweisung lässt sich das klarer schreiben:

```swift
switch str {
case "apple":
    print("Let's bake an apple crumble")
case "lemon":
    print("Let's bake a lemon meringue pie!")
case "peach":
    print("Let's bake a peach pie!")
default:
    print("Let's buy ice cream.")
}
```

## Werte binden und where-Klauseln

Ein `switch`-Fall kann passende Werte an temporäre Konstanten oder Variablen binden, die du im Block des Falls verwendest.
Fälle können außerdem eine `where`-Klausel enthalten, um vor dem Vergleich zusätzliche boolesche Bedingungen zu prüfen:

```swift
let x = 1337
switch sumOfDivisors(of: x) {
case let total where total == x:
    print(total, "is a perfect number")
default:
    print(x, "is not a perfect number")
}
```
