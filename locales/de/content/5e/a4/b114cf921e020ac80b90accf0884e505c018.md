# Rust-Referenz

## Konzepte

Die Rust-Konzeptübungen vermitteln Konzepte von den Grundlagen bis zur Beherrschung der Sprache. Sie sind unten klassifiziert und aufgelistet.

Die Konzepte von Exercism sollen Lernenden auf praktische Weise dienen, deshalb unterscheiden sie sich von abstrakten Ideen. Dieses Dokument definiert, was diese Konzepte in Rust bedeuten. Wir haben unten eine visuelle Gruppierung hinzugefügt, um Track-Maintainern zu helfen, ein effektives Referenzdokument zu erstellen. Solche Gruppierungen stellen _keine_ pädagogischen Einteilungen dar. Bitte beziehe dich beim Unterrichten also nicht darauf.

Kontrollkästchen zeigen an, ob die Konzepte in der Übungszuordnungsliste bereits vermittelt werden.

## Zuordnung der Konzeptübungen

Idealerweise gibt es für jedes der oben aufgeführten Konzepte eine einzige Konzeptübung, die genau ein Konzept vermittelt und nur dessen Voraussetzungen erfordert, doch ist das nicht ganz praktikabel. Zum Beispiel wäre es schwierig, eine Übung zu entwerfen, die vermittelt, was Funktionen sind, ohne jegliche Kenntnis von Primitiven vorauszusetzen. Ebenso wäre es schwierig, Primitive mit einer Testsuite zu vermitteln, ohne jegliche Kenntnis von Funktionen.

Die Übungen in dieser Tabelle sollten einen DAG (einen gerichteten azyklischen Graphen) bilden, der irgendwann alle oben aufgeführten Konzepte abdeckt.

| Übung                    | Voraussetzungen                              | vermittelt                                               | Erzählung                                                                        |
| ------------------------ | -------------------------------------------- | -------------------------------------------------------- | -------------------------------------------------------------------------------- |
| `hello-world`            | -                                            | Funktionen, Testsuites                                   | gibt das `&str`-Literal `"hello world"` zurück                                   |
| `compiled-calculator`    | `hello-world`                                | Ganzzahlen, Variablenzuweisung                           | eine Reihe von Rechenoperationen ausführen und das Ergebnis implizit zurückgeben |
| `conditionals`           | `hello-world`                                | Bedingte Anweisungen                                     | sollte als 3-zweigiges `if` / `else if` / `else` strukturiert sein; implizite Rückgabe |
| `slices`                 | `hello-world`, `compiled-calculator`         | Slices                                                   | einen Slice aus einem Parameter extrahieren, der ein Slice von Ganzzahlen ist    |
| `loops`                  | `slices`                                     | grundlegendes Durchlaufen eines Slices                   | idealerweise mit vorzeitiger Rückgabe, sodass es umständlich ist, das als Iterator auszudrücken |
| `iterator-use`           | `slices`                                     | Verwendung von Iteratoren, `collect`                     |
| `integer-sizes`          | `compiled-calculator`                        | Ganzzahlen außer `i32`, Casting                          | weiterhin alle mit Vorzeichen                                                    |
| `unsigned-ints`          | `integer-sizes`                              | vorzeichenlose Ganzzahlen                                |
| `indexing`               | `integer-sizes`, `slices`                    | Indexierung, `usize`                                     |
| `floats`                 | `compiled-calculator`                        | Gleitkommazahlen                                         | wahrscheinlich dieselbe compiled-calculator-Übung, aber mit Ergebnissen, die keine Ganzzahlen sind |
| `bools`                  | `compiled-calculator`                        | boolesche Werte, boolesche Operatoren                    |
| `char`                   | `compiled-calculator`                        | Datentyp `char`                                          | sollte einige Beispiele mit breiten Zeichen enthalten                            |
| `str-use`                | `char`, `slices`                             | `&str`                                                   | Hinweis: unveränderlich!                                                         |
| `string-use`             | `str-use`                                    | `String`                                                 | Hinweis: im Besitz, veränderlich                                                 |
| `format-macro`           | `string-use`                                 | `format!`-Makro                                          |
| `str-vs-string`          | `str-use`, `string-use`                      | Kombinieren, Konvertieren, Kosten usw.                   |
| `generics-basics`        | `integer-sizes`, `floats`                    | externe Traits als Bounds verwenden, grundlegende Generics | wahrscheinlich immer noch compiled-calculator, nur generisch                     |
| `structs`                | `string-use`, `unsigned-ints`, `floats`      | ein Struct erstellen und verwenden, um Daten zu verwalten | `Person` hat Name, Größe und Anzahl der Schuhe im Besitz                         |
| `implicit-return`        | `compiled-calculator`                        | Gültigkeitsbereiche, Ausdrücke, implizite Rückgabe       |
| `explicit-return`        | `implicit-return`, `conditionals`            | explizite `return`-Anweisung                             |
| `methods`                | `structs`, `explicit-return`                 | `impl`-Blöcke, Methoden                                  |
| `tuples`                 | `structs`                                    | Tupel                                                    | als anonyme Structs vermitteln; `.0`-Syntax vermitteln                           |
| `tuple-structs`          | `tuples`, `structs`                          | Tupel-Structs (benannte Tupel)                           |
| `basic-enums`            | `unsigned-ints`                              | einfache Enums (keine Felder), `match`                   |
| `enums`                  | `basic-enums`, `tuple-structs`               | Tupel-Syntax für Enum-Varianten                          |
| `option`                 | `enums`                                      | `Option<T>`                                              |
| `result`                 | `enums`                                      | `Result<T, E>`                                           |
| `mutability`             | `compiled-calculator`                        | standardmäßige Unveränderlichkeit; explizite Veränderlichkeit |                                                                               |
| `let-expressions`        | `loops`, `option`, `result`                  | `if let`, `while let`                                    | hängt je nach Implementierung wahrscheinlich nur von `option` oder `result` ab   |
| `vectors`                | `slices`                                     | `Vec<T>`                                                 |
| `hashmaps`               | `vectors`                                    | `Hashmap<K, V>`                                          |
| `entry-api`              | `hashmaps`                                   | Entry-API                                                |
| `hashsets`               | `hashmaps`                                   | `HashSet<K>`                                             |
| `btreemaps`              | `hashmaps`                                   | `BTreeMap<K, V>`                                         |
| `deriving-traits`        | `structs`                                    | `PartialEq`, `PartialOrd`, `Debug`, `Display`, `Default` |
| `implementing-traits`    | `deriving-traits`                            | manuelles Implementieren eines Traits                    | wahrscheinlich `Iterator` implementieren                                         |
| `collection-conversions` | `vectors`, `hashsets`, `implementing-traits` | `FromIterator`, `IntoIterator`                           |
