# Anleitung

Du bist ein begeisterter Vogelbeobachter und zählst jeden Tag die Vögel, die deinen Garten besuchen. Die Zählungen werden in einem Array gespeichert, der älteste Tag zuerst.

## 1. Die heutige Zählung

Definiere `today`, sodass es das Array der täglichen Zählungen vom Stack nimmt und die Zählung für heute zurückgibt.

```factor
{ 2 5 0 7 4 1 } today .
! => 1
```

## 2. Die heutige Zählung erhöhen

Definiere `increment-todays-count`, sodass es ein neues Array zurückgibt, in dem die heutige Zählung um eins erhöht ist. Das ursprüngliche Array darf nicht verändert werden.

```factor
{ 2 5 0 7 4 1 } increment-todays-count .
! => { 2 5 0 7 4 2 }
```

## 3. Gab es einen Tag ohne Vögel?

Definiere `has-day-without-birds?`, sodass es `t` zurückgibt, wenn an mindestens einem Tag null Vögel gezählt wurden, andernfalls `f`.

```factor
{ 2 5 0 7 4 1 } has-day-without-birds? .
! => t

{ 2 5 1 } has-day-without-birds? .
! => f
```

## 4. Die ersten Tage summieren

Definiere `count-for-first-days`, sodass es ein Array von Zählungen und eine Zahl `n` entgegennimmt und die Summe der ersten `n` Zählungen zurückgibt.

```factor
{ 2 5 0 7 4 1 } 4 count-for-first-days .
! => 14
```

## 5. Die betriebsamen Tage zählen

Ein betriebsamer Tag ist ein Tag mit fünf oder mehr Vögeln. Definiere `busy-days`, sodass es die Anzahl der betriebsamen Tage im Array zurückgibt.

```factor
{ 2 5 0 7 4 1 } busy-days .
! => 2
```

## 6. Fehlende Tage auffüllen

Wenn du nicht an jedem Tag eines Zeitraums von `n` Tagen beobachtet hast, fülle die fehlenden Tage am Ende mit `0` auf. Definiere `pad-missing-days`, sodass es ein Array von Zählungen und eine Ziel-Länge `n` entgegennimmt und ein Array der Länge mindestens `n` zurückgibt, dessen zusätzliche Plätze `0` sind. Vorhandene Zählungen müssen unverändert erhalten bleiben; ist die Eingabe bereits mindestens `n` lang, gib sie unverändert zurück.

```factor
{ 2 5 0 } 7 pad-missing-days .
! => { 2 5 0 0 0 0 0 }

{ 4 1 6 8 } 3 pad-missing-days .
! => { 4 1 6 8 }
```
