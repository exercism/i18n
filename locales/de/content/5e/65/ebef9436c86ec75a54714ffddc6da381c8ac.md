# Anweisungen

Eine [domänenspezifische Sprache (DSL)][dsl] ist eine kleine Sprache, die auf einen bestimmten Bereich zugeschnitten ist.
Da eine DSL auf einen bestimmten Zweck ausgerichtet ist, kann sie Produktivität und Verständnis stark verbessern: Du beschreibst _was_ du willst, statt _wie_.

Ein Problembereich, in dem sie eingesetzt werden, sind komplexe Anpassungen und Konfigurationen.

Zum Beispiel erlaubt dir die [DOT-Sprache][dot-language], eine Textbeschreibung eines Graphen zu schreiben, die dann von einem der [Graphviz][graphviz]-Tools (wie `dot`) in ein Bild umgewandelt wird.
Ein einfacher Graph sieht so aus:

    graph {
        graph [bgcolor="yellow"]
        a [color="red"]
        b [color="blue"]
        a -- b [color="green"]
    }

Wenn du das in eine Datei `example.dot` schreibst und `dot example.dot -T png -o example.png` ausführst, entsteht ein Bild `example.png`: ein roter und ein blauer Kreis, die durch eine grüne Linie auf gelbem Hintergrund verbunden sind.

Schreibe eine domänenspezifische Sprache, die der Graphviz-DOT-Sprache ähnelt.

Unsere DSL ähnelt der Graphviz-DOT-Sprache insofern, als sie zur Erstellung von Graph-Datenstrukturen verwendet wird.
Anders als die DOT-Sprache ist unsere DSL jedoch eine interne DSL, die nur in unserer Programmiersprache verwendet wird.

[Erfahre mehr über den Unterschied zwischen internen und externen DSLs][fowler-dsl].
