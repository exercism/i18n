# Einführung

`when` ist das Schlüsselwort beim Filtern von Ausnahmen. Es steht nach der `catch`-Anweisung und kann einen booleschen Ausdruck annehmen, der alle Werte enthält, die zu diesem Zeitpunkt im Gültigkeitsbereich liegen. Ergibt der Ausdruck wahr, wird der Block ausgeführt, der zu dieser `catch`-Anweisung gehört. Andernfalls wird die nächste `catch`-Anweisung geprüft, falls es eine gibt.

```csharp
try
{
    // do stuff
}
catch (Exception ex) when (ex.Message != "")
{
    // output the message when it is not empty
}
catch (Exception ex)
{
    // show stack trace or something.
}
```
