# Ergänzung zu den Anweisungen

## Wörter

- `tick ( matrix cols -- matrix' )`: Berechne die nächste Generation des Gitters und gib das neue Gitter zurück.

Jede Zeile des Gitters wird als 64-Bit-Ganzzahl dargestellt; `cols` ist die Anzahl der Spalten (höchstens 64). Zum Beispiel:

```
    0 1 0
    1 0 0
    1 1 0
```

wird dargestellt als

```
0b010
0b100
0b110
```
