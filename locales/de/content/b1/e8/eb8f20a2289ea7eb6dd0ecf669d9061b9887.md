# Dictionary-Methoden in Python

Die Klasse `dict` in Python bietet viele nützliche [Methoden][dict-methods], von denen einige in der Konzeptübung für Dictionaries eingeführt werden.

Dieses Konzept behandelt noch ein paar weitere:

- `<dict>.setdefault()` fügt automatisch Schlüssel hinzu, ohne einen KeyError auszulösen.
- `<dict>.fromkeys(<iterable>, <default value>)` erstellt ein neues `dict` aus beliebig vielen Iterables.
- `<dict>.keys()`, `<dict>.values()` und `<dict>.items()` bieten praktische Iteratoren.
- `sorted(<dict>.items())` kann Einträge in einem `dict` leicht neu anordnen.
- `<dict_one>.update(<dict_two>)` aktualisiert ein `dict` mit sich überschneidenden Werten aus einem anderen `dict`.
- `<dict> | <other_dict>` und `<dict> |= <other_dict>` führen zwei `dict`s mithilfe von Operatoren zusammen oder aktualisieren sie.
- `reversed(<dict>.keys())`, `reversed(<dict>.values())` oder `reversed(<dict>.items())` erzeugen _umgekehrte_ Ansichten.
- `<dict>.popitem()` entfernt ein Paar aus `key` und `value` und gibt es zurück.

[dict-methods]: https://docs.python.org/3/library/stdtypes.html#dict
