# Einführung

Diese Übung baut auf dem auf, was du in [Gartenvogelbeobachter][backyard-birdwatcher] gesehen hast, und führt die Wörter höherer Ordnung ein, die eine *Quotation* entgegennehmen, also ein Stück Code in `[ ]`-Klammern, um die Operation zu steuern.

## Quotations als Werte

Eine Quotation ist einfach ein wörtliches Stück Code. Du kannst sie als Daten an ein anderes Wort übergeben:

```factor
{ 1 2 3 4 5 } [ 2 > ] count .   ! => 3
```

Hier ist `[ 2 > ]` eine Quotation, die eine Zahl entgegennimmt und einen booleschen Wert hinterlässt. `count` führt sie für jedes Element aus und zählt die Ergebnisse, die wahr sind.

## Filtern und Verwerfen

```
find      ( seq quot    -- i/f elt/f ) ! first match: index and element, or f f
find-last ( seq quot    -- i/f elt/f ) ! same, but searches from the end
filter    ( seq quot    -- newseq )    ! keep elements where quot is truthy
reject    ( seq quot    -- newseq )    ! drop them instead
without   ( seq exclude -- newseq )    ! drop every element that's in `exclude`
sift      ( seq         -- newseq )    ! drop every `f`, keep the rest
```

```factor
{ 1 2 3 4 5 } [ 3 > ] find .s
! => 3            (index)
! => 4            (element)
{ 1 2 3 4 5 } [ 3 > ] find-last .s
! => 4            (index)
! => 5            (element)
{ 1 2 3 4 5 } [ even? ] filter .    ! => { 2 4 }
{ 1 2 3 4 5 } [ even? ] reject .    ! => { 1 3 5 }
"hello world" " ld" without .       ! => "heowor"
{ 1 f 2 f 3 } sift .                ! => { 1 2 3 }
```

`without` behandelt sein zweites Argument als Menge: Jedes Element von `seq`, das `=` zu *irgendeinem* Element von `exclude` ist, wird verworfen. `sift` ist der Sonderfall von `reject` ohne Quotation: Es behält jedes Element außer `f`. Das ist praktisch, um die Lücken zu schließen, die ein vorheriges `map` hinterlassen hat.

### Das Ergebnis des Tests behalten

`find` gibt das passende *Element* zurück. Wenn der Test den Wert, den du eigentlich willst, bereits *berechnet*, sparst du mit `map-find` einen zweiten Durchlauf: Es führt die Quotation für jedes Element aus und gibt das erste Ergebnis zurück, das nicht `f` ist, **und** dazu das Element, das es erzeugt hat.

```
map-find ( seq quot: ( elt -- result/f ) -- result elt )
```

```factor
USING: kernel math sequences ;

! First multiple of 3, paired with that multiple divided by 3.
{ 11 13 15 17 } [ dup 3 mod 0 = [ 3 /i ] [ drop f ] if ] map-find .s
! => 5            (result: 15/3)
! => 15           (element)
```

Die Quotation gibt `f` für Elemente zurück, die nicht passen, und das Ergebnis, das du behalten willst, für das eine, das passt. Wenn nichts passt, hinterlässt `map-find` `f f`, genau wie `find`.

### Datensätze nach einem Slot filtern

Wenn die Elemente *Tupel* sind, projiziert das Prädikat normalerweise über seinen automatisch erzeugten Reader `slot>>` auf einen Slot und prüft darauf:

```factor
USING: accessors sequences ;

TUPLE: customer name vip? ;

{
    T{ customer { name "Alice" } { vip? t } }
    T{ customer { name "Bob"   } { vip? f } }
    T{ customer { name "Carol" } { vip? t } }
}
[ vip?>> ] filter [ name>> ] map .
! => { "Alice" "Carol" }
```

## Einen festen Wert mit `with` durchreichen

Manchmal braucht das Prädikat einen Wert, der bei jedem Aufruf gleich ist: einen Schwellenwert, einen Divisor, einen Ziel-String. `with` (in [`kernel`][kernel]) backt diesen festen Wert in die Quotation ein und macht aus einer Quotation mit zwei Argumenten `( value elt -- ? )` die Quotation mit einem Argument, die `filter`, `count`, `map` und `each` erwarten:

```
with ( value seq quot -- seq curry )
```

Jeder Aufruf pro Element sieht `( value elt )` auf dem Stack: fester Wert zuerst, aktuelles Element danach:

```factor
USING: kernel sequences ;

! Count elements greater than 5 — value=5 is threaded in
5 { 2 7 4 9 1 8 } [ < ] with count .   ! => 3
```

## Mapping und Iterieren

`map` (in [`sequences`][sequences]) wendet eine Quotation auf jedes Element an und gibt das Array der Ergebnisse zurück. `each` macht denselben Durchlauf, verwirft aber die Ergebnisse. Das ist nützlich, wenn die Quotation nur wegen ihrer Seiteneffekte läuft. `2map` durchläuft *zwei* Sequenzen im Gleichschritt und kombiniert die einander entsprechenden Elemente; `2each` und `2reduce` sind die Verwandten für reine Seiteneffekte bzw. das Falten; `zip` ist die Kurzform für „stelle sie paarweise zusammen, ohne sie zu kombinieren“:

```
map     ( seq       quot           -- newseq )
map-as  ( seq       quot exemplar  -- newseq )
each    ( seq       quot           -- )
2map    ( seq1 seq2 quot           -- newseq )
2each   ( seq1 seq2 quot           -- )
2reduce ( seq1 seq2 identity quot  -- result )
zip     ( seq1 seq2                -- pairs )
```

`2reduce` reicht einen Akkumulator gleichzeitig durch beide Sequenzen; seine Quotation nimmt `( accumulator elt1 elt2 -- accumulator' )`. Hier sammelt es ein Skalarprodukt an: Jedes Paar wird multipliziert und die Produkte werden summiert (`1*10 + 2*20 + 3*30`):

```factor
{ 1 2 3 } { 10 20 30 } 0 [ * + ] 2reduce .   ! => 140
```

`map-as` ist der Verwandte von `map`, der den Typ der Ausgabesequenz erzwingt. Übergib ein leeres `{ }` oder `V{ }` als Exemplar, um den Standardtyp der Eingabe zu überschreiben (sonst schlägt das Abbilden eines Strings auf Nicht-Zeichen fehl, wenn Factor die Ergebnisse wieder in einen String packen will).

```factor
USING: formatting math sequences ;

{ 1 2 3 } [ sq ] map .                         ! => { 1 4 9 }
{ 1 2 3 } [ . ] each                           ! prints 1, then 2, then 3
{ 1 2 3 } { 10 20 30 } [ + ] 2map .            ! => { 11 22 33 }
{ "x" "y" } { 1 2 } [ "%s%d" sprintf ] 2map .  ! => { "x1" "y2" }
{ 1 2 3 } { 10 20 30 } [ + . ] 2each           ! prints 11, then 22, then 33
{ "a" "b" "c" } { 1 2 3 } zip .                ! => { { "a" 1 } { "b" 2 } { "c" 3 } }
```

Beide Formen mit zwei Sequenzen enden bei der Länge der kürzeren Eingabe. `zip` ist dasselbe wie `[ 2array ] 2map`: Es behält die Paare, statt sie zusammenzufassen.

## Sortieren

`sort` gibt eine sortierte Kopie in natürlicher Reihenfolge zurück; `sort-by` (in [`sorting`][sorting]) sortiert nach einem Schlüssel, der aus jedem Element extrahiert wird:

```
sort    ( seq      -- sortedseq )
sort-by ( seq quot -- sortedseq )
```

```factor
{ 3 1 4 1 5 9 2 6 } sort .
! => { 1 1 2 3 4 5 6 9 }

{ -3 5 -1 4 } [ abs ] sort-by .
! => { -1 -3 4 5 }
```

## Zusammenfassen

`map-sum` (in [`sequences`][sequences]) bildet eine Quotation über die Sequenz ab und summiert die Ergebnisse in einem Durchlauf:

```
map-sum ( seq quot -- n )
```

```factor
{ 1 2 3 4 } [ sq ] map-sum .   ! => 30
```

## Minimum und Maximum

`minimum` und `maximum` geben direkt das kleinste bzw. größte Element einer Sequenz zurück. `minimum-by` und `maximum-by` (beide in [`sequences`][sequences]) geben das Element zurück, dessen extrahierter Schlüssel am kleinsten bzw. am größten ist:

```
minimum     ( seq      -- elt )
maximum     ( seq      -- elt )
minimum-by  ( seq quot -- elt )
maximum-by  ( seq quot -- elt )
```

```factor
{ 3 1 4 1 5 9 2 6 } minimum .       ! => 1
{ 3 1 4 1 5 9 2 6 } maximum .       ! => 9

{ -3 5 -1 4 } [ abs ] minimum-by .
! => -1
```

## Ein eigenes Wort höherer Ordnung schreiben

Wenn *dein* Wort eine Quotation als Laufzeitargument entgegennimmt und sie an `map`, `filter`, `each` usw. weiterreicht, deklariere dein Wort mit `; inline`. Das weist den Compiler an, dein Wort an jeder Aufrufstelle zu inlinen, wo die Quotation ein bekanntes Literal ist. Ohne das hat der Compiler keine Möglichkeit, den Stack-Effekt der Quotation zu kennen.

```factor
USING: math sequences ;

: tax-on ( inventory quot -- total )
    map-sum ; inline

{ { "shirt" 20 } { "hat" 15 } } [ second 1/10 * ] tax-on .
! => 3+1/2
```

Wörter, die nur aus literalen Quotations aufgebaut sind, brauchen kein `inline`, nur die, die eine *hereinkommende* Quotation weiterreichen.

Wenn ein solches `inline`-Wort sich jemals *selbst* aufruft, also ein rekursiver Kombinator ist, deklariere es stattdessen mit `; inline recursive`. Ohne das zusätzliche Wort bricht der Compiler mit *„The inline recursive word ... must be declared recursive“* ab, was dir genau sagt, was du hinzufügen musst.

## Das zweite Element holen

Bei einem Array mit 2 Elementen gibt `second` sein zweites Element zurück. `first` gibt das erste zurück. Beide sind in [`sequences`][sequences].

## Zahlen in Strings umwandeln

`number>string ( n -- str )` (in [`math.parser`][math.parser]) wandelt eine Zahl in die Form eines Dezimal-Strings um:

```factor
42 number>string .     ! => "42"
3.5 number>string .    ! => "3.5"
```
