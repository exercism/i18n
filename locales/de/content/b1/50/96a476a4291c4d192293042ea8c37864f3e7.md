# Anleitung

In dieser Übung schreibst du Code, um ein Fließband in einer Autofabrik zu analysieren.

## 1. Berechne, wie viele funktionierende Autos pro Stunde produziert werden

Implementiere eine Funktion, die die Anzahl der pro Stunde produzierten Autos und die Erfolgsquote entgegennimmt und berechnet, wie viele Autos pro Stunde erfolgreich hergestellt werden. Die Erfolgsquote wird als Prozentsatz von `0` bis `100` angegeben:

```lua
cars.calculate_working_cars_per_hour(1547, 90)
--> => 1392.3
```

**Hinweis:** Der Rückgabewert sollte eine Gleitkommazahl sein.

## 2. Berechne, wie viele funktionierende Autos pro Minute produziert werden

Implementiere eine Funktion, die die Anzahl der pro Stunde produzierten Autos und die Erfolgsquote entgegennimmt und berechnet, wie viele Autos pro Minute erfolgreich produziert werden:

```lua
cars.calculate_working_cars_per_minute(1105, 90)
-- => 16
```

**Hinweis:** Der Rückgabewert sollte eine Ganzzahl sein.

## 3. Berechne die Produktionskosten

Normalerweise kostet es 10.000 $, ein Auto einzeln zu produzieren, unabhängig davon, ob es erfolgreich ist oder nicht. Mit etwas Planung lassen sich aber 10 Autos zusammen für 95.000 $ produzieren. Zum Beispiel lassen sich 37 Autos so produzieren:
37 = 3 x Zehnergruppen + 7 einzelne Autos

Die Kosten für 37 Autos betragen also:
3 \* 95.000 + 7 \* 10.000 = 355.000

Implementiere eine Funktion, die die Kosten für die Produktion einer beliebigen Anzahl von Autos berechnet, egal ob sie erfolgreich sind oder nicht:

```lua
cars.calculate_cost(37)
-- => 355000

cars.calculate_cost(21)
-- => 200000
```

**Hinweis:** Der Rückgabewert sollte eine Ganzzahl sein.
