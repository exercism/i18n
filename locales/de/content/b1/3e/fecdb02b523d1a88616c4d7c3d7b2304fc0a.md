# Einführung

Die Arbeit mit Binärdaten ist in jeder Programmiersprache ein wichtiges Konzept, und Elixir bietet eine elegante Syntax, um Binärdaten zu schreiben, abzugleichen und zu konstruieren.

In Elixir spricht man bei Binärdaten vom Bitstring-Typ. Der _Typ_ für Binärdaten (nicht zu verwechseln mit Binärdaten im Allgemeinen) ist eine bestimmte Form eines Bitstrings, die wir in einer späteren Übung besprechen werden.

Bitstring-Literale werden mit der speziellen Bitstring-Form `<<>>` definiert. Wenn du ein Bitstring-Literal definierst, definierst du es in Segmenten. Jedes Segment hat einen Wert und einen Typ, die durch den Operator `::` getrennt werden. Der Typ gibt an, wie viele Bits zum Kodieren des Werts verwendet werden. Der Typ kann ganz weggelassen werden; dann wird standardmäßig ein 8-Bit-Ganzzahlwert verwendet.

```elixir
# This defines a bitstring with three segments of a single bit each
<<0::1, 1::1, 0::1>>
```

Die Angabe des Typs als `::1` ist eine Kurzform für `::size(1)`. Du musst die längere Syntax verwenden, wenn die Bitgröße aus einer Variablen stammt.

## Binärzahlen

Binäre Ganzzahl-Literale kannst du direkt in der Basis-2-Notation schreiben, indem du dem Literal `0b` voranstellst. Beachte, dass sie ohnehin als Dezimalzahlen angezeigt werden, wenn sie in Testergebnissen ausgegeben werden oder wenn du iex verwendest.

```elixir
<<0b1011::4>> == <<11::4>>
# => true
```

## Abschneiden

Wenn der Wert des Segments die Kapazität des Segmenttyps überschreitet, wird er von links abgeschnitten.

```elixir
<<0b1011::3>> == <<0b0011::3>>
# => true
```

## Voranstellen und Anhängen

Mit der speziellen Form kannst du einem vorhandenen Bitstring sowohl etwas voranstellen als auch etwas an ihn anhängen. Der Typ `::bitstring` muss für den vorhandenen Bitstring verwendet werden, wenn seine Größe unbekannt ist.

```elixir
value = <<0b110::3, 0b001::3>>
new_value = <<0b011::3, value::bitstring, 0b000::3>>
# => <<120, 8::size(4)>>
```

## Verketten

Wir können Bitstrings, die in Variablen gespeichert sind, mit der speziellen Form verketten. Der Typ `::bitstring` muss verwendet werden, wenn du zwei Bitstrings unbekannter Größe verkettest.

```elixir
first = <<0b110::3>>
second = <<0b001::3>>
concatenated = <<first::bitstring, second::bitstring>>
# => <<49::size(6)>>
```

## Pattern Matching

Mit Pattern Matching kannst du auch Werte aus der speziellen Form erhalten. Du musst die Anzahl der Bits für jedes Fragment kennen, das du erfassen willst, mit einer Ausnahme: Mit dem Typ `::bitstring` kannst du Pattern Matching auf einem Bitstring unbekannter Größe durchführen, aber das geht nur für das letzte Fragment.

```elixir
<<value::4, rest::bitstring>> = <<0b01101001::8>>
value == 0b0110
# => true
```

## Bitstrings untersuchen

~~~~exercism/note
Bitstrings werden möglicherweise (vom Test-Runner oder in iex) in einem
anderen Format ausgegeben als dem, mit dem sie erstellt wurden. Das führt
beim Lernen von Bitstrings oft zu Verwirrung.
~~~~

Standardmäßig werden Bitstrings in Fragmenten von 8 Bits (einem Byte) angezeigt, auch wenn du sie mit Fragmenten einer anderen Größe erstellt hast.

```elixir
<<2011::11>>
# => <<251, 3::size(3)>>
```

Wenn du einen Bitstring erstellst, der einen druckbaren UTF-8-kodierten String darstellt, wird er als String angezeigt.

```elixir
<<>>
# => ""

<<65, 66, 67>>
# => "ABC"
```
