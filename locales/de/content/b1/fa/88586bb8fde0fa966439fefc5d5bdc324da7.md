# String-Verkettung

String-Verkettung ist in Crystal völlig in Ordnung, aber üblicher ist es, einen String mit [String-Interpolation][interpolation] zusammenzusetzen.
Zum Beispiel:

```crystal
# Rather than:
"One for " + name_variable + ", one for me"

# Consider:
"One for #{name_variable}, one for me."
```

[interpolation]: https://crystal-lang.org/reference/latest/syntax_and_semantics/literals/string.html#interpolation
