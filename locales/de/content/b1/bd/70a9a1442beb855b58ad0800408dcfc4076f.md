# Überblick

Die Gleam-Standardbibliothek implementiert im Modul `gleam/queue` einen Typ `Queue`. Er ähnelt dem Typ `List`, hat aber ein paar wichtige Unterschiede:

- Der Typ `Queue` hat keine Literalschreibweise, mit der du Queues erzeugen oder Musterabgleich darauf machen kannst.
- Bei einer `Queue` lassen sich Elemente sowohl vorne als auch hinten effizient hinzufügen und entfernen, während der Typ `List` Elemente nur vorne effizient hinzufügen und entfernen kann.

Meistens willst du den Typ `List` verwenden, aber wenn du am Ende einer Sammlung hinzufügen und entfernen können musst, ist der Typ `Queue` eine gute Wahl.

Queues erzeugst du mit den Funktionen `queue.new` und `queue.from_list`:

```gleam
let empty = queue.new()
let one_to_four = queue.from_list([1, 2, 3, 4])
```

Elemente fügst du mit den Funktionen `queue.push_front` und `queue.push_back` zur Queue hinzu:

```gleam
let one_to_four = queue.from_list([1, 2, 3, 4])
let one_to_five = queue.push_back(one_to_four, 5)
let zero_to_five = queue.push_front(one_to_five, 0)
```

Elemente entfernst du mit den Funktionen `queue.pop_front` und `queue.pop_back` aus der Queue:

```gleam
let one_to_four = queue.from_list([1, 2, 3, 4])

queue.pop_back(one_to_four)
// -> Ok(#(4, queue.from_list([1, 2, 3])))

queue.pop_front(one_to_four)
// -> Ok(#(1, queue.from_list([2, 3, 4])))

queue.pop_front(queue.new())
// -> Error(Nil)
```

Eine Queue kannst du mit der Funktion `queue.to_list` in eine Liste umwandeln:

```gleam
let one_to_four = queue.from_list([1, 2, 3, 4])
queue.to_list(one_to_four)
// -> [1, 2, 3, 4]
```

## Gleichheit von Queues

Weil Queues so implementiert sind, wie sie sind, sind zwei Queues mit denselben Elementen in derselben Reihenfolge für den Operator `==`, der Werte strukturell vergleicht, möglicherweise nicht gleich. Zum Beispiel:

```gleam
let empty = queue.new()
let a = queue.push_front(empty, 1)
let b = queue.push_back(empty, 1)
a == b
// -> False
```

Wenn du zwei Queues auf Gleichheit vergleichen willst, kannst du die Funktion `queue.is_logically_equal` verwenden.

```gleam
queue.is_logically_equal(a, b, fn(x, y) { x == y })))
// -> True
```
