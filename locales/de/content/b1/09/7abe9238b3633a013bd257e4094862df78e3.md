# Anleitung

Alizé betreibt eine Online-Boutique für Mode. Der große jährliche Ausverkauf steht bevor, deshalb möchte sie eine Funktion erstellen, die ihr bei der Bestandsaufnahme des Lagers hilft.

Ein einzelner Artikel im Lager wird mit einem eigenen Typ dargestellt.

```gleam
Item(
  name: "White Shirt",
  price: 40,
  quantity: 6,
)
```

## 1. Gib eine Liste der Namen der Artikel zurück

Implementiere die Funktion `item_names`, die einen Iterator von Artikeln entgegennimmt und einen Iterator ihrer Namen in derselben Reihenfolge zurückgibt.

```gleam
[
  Item(price: 65, name: "Maxi Brown Dress", quantity: 8),
  Item(price: 50, name: "Red Short Skirt", quantity: 0),
  Item(price: 29, name: "Black Short Skirt", quantity: 4),
  Item(price: 20, name: "Bamboo Socks Cats", quantity: 7),
]
|> iterator.from_list
|> item_names
|> iterator.to_list

// -> ["Maxi Brown Dress", "Red Short Skirt", "Black Short Skirt", "Bamboo Socks Cats"]
```

## 2. Gib alle Artikel zurück, die günstig sind

Implementiere die Funktion `cheap`, die einen Iterator von Artikeln entgegennimmt und einen Iterator der Artikel zurückgibt, die weniger als 30 kosten.

```gleam
[
  Item(price: 65, name: "Maxi Brown Dress", quantity: 8),
  Item(price: 50, name: "Red Short Skirt", quantity: 0),
  Item(price: 29, name: "Black Short Skirt", quantity: 4),
  Item(price: 20, name: "Bamboo Socks Cats", quantity: 7),
]
|> iterator.from_list
|> cheap
|> iterator.to_list

// -> [
//   Item(price: 29, name: "Black Short Skirt", quantity: 4),
//   Item(price: 20, name: "Bamboo Socks Cats", quantity: 7),
// ]
```

## 3. Gib alle Artikel zurück, die nicht auf Lager sind

Implementiere die Funktion `out_of_stock`, die alle Artikel zurückgibt, die nicht auf Lager sind.

```gleam
[
  Item(price: 65, name: "Maxi Brown Dress", quantity: 8),
  Item(price: 50, name: "Red Short Skirt", quantity: 0),
  Item(price: 29, name: "Black Short Skirt", quantity: 4),
  Item(price: 20, name: "Bamboo Socks Cats", quantity: 7),
]
|> iterator.from_list
|> out_of_stock
|> iterator.to_list

// -> [
//   Item(price: 50, name: "Red Short Skirt", quantity: 0),
// ]
```

## 4. Gib den Gesamtbestand zurück

Implementiere die Funktion `total_stock`, die die Gesamtzahl der Artikel in deinem Lager berechnet:

```gleam
[
  Item(price: 65, name: "Maxi Brown Dress", quantity: 8),
  Item(price: 50, name: "Red Short Skirt", quantity: 0),
  Item(price: 29, name: "Black Short Skirt", quantity: 4),
  Item(price: 20, name: "Bamboo Socks Cats", quantity: 7),
]
|> iterator.from_list
|> total_stock

// -> 19
```
