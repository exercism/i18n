# Hinweise

## Allgemein

- Alle Begriffe zum Lesen und Schreiben von Dateien stecken in [`io.files`][io.files]; die
  `utf8`-Kodierung, die sie alle erwarten, stammt aus
  [`io.encodings.utf8`][utf8].

## 1. Jeden Messwert lesen

- `file-lines` gibt ein Array von Zeilen zurück, bei dem die Zeilenumbrüche entfernt
  wurden.

## 2. Den neuesten Messwert finden

- Lies die Zeilen mit `file-lines` und nimm dann die `last`-Zeile (aus
  `sequences`).

## 3. Das rohe Log lesen

- `file-contents` gibt die Datei als einen einzigen String zurück, samt Zeilenumbrüchen.

## 4. Einen Messwert aufzeichnen

- Öffne die Datei zum Anhängen und gib den Messwert mit `print` innerhalb der Quotation
  aus: `with-file-appender ( path encoding quot -- )`. Der Messwert wird innerhalb der
  Quotation verwendet, während der Pfad davor verbraucht wird, deshalb halten `::`-Locals
  den Rumpf lesbar:
  `:: record-reading ( reading path -- ) path utf8 [ reading print ]
  with-file-appender ;`.

## 5. Das Log neu schreiben

- `set-file-lines` schreibt jedes Element einer Sequenz in eine eigene Zeile und fügt
  die Zeilenumbrüche für dich ein.
