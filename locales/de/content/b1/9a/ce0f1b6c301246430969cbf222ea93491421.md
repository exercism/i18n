# Über

[Strings][strings] in Haxe sind unveränderliche Objekte, die Text als Folge von Unicode-Zeichen (Buchstaben, Ziffern, Satzzeichen usw.) darstellen. Mit doppelten Anführungszeichen definierst du eine `string`-Instanz:

```haxe
var fruit:String = "Apple";
```

Einen String bearbeitest du, indem du eine seiner [Methoden oder Eigenschaften][string-api] aufrufst. Da sich String-Werte nach ihrer Definition nie mehr ändern, liefern alle Methoden zur String-Bearbeitung einen neuen String zurück.

Ein String wird von doppelten Anführungszeichen (`"`) begrenzt. Einige Sonderzeichen müssen mit dem Backslash-Zeichen (`\`) [escaped][escaping] werden. Außerdem sind Haxe-Strings mehrzeilig, sodass du ganz einfach lange String-Literale erstellen kannst:

```haxe
var escaped:String = "c:\\test.txt";
var multiline:String = "
- apple
- pear
- banana";
```

Strings verkettest du am einfachsten mit dem [`+`-Operator][plus-operator].

```haxe
var name:String = "Jane";
trace("Hello " + name + "!");
// => "Hello Jane!"
```

Für komplexere String-Formatierungen ist die [String-Interpolation][interpolation] die bessere Wahl. Dazu schließt du den String in einfache Anführungszeichen (`'`) ein und verwendest das Dollarzeichen (`$`), um die Variablen-Interpolation auszulösen. Du kannst auch ganze Ausdrücke mit `${expr}` auswerten, wobei `expr` ein beliebiger gültiger Haxe-Ausdruck ist:

```haxe
var name:String = "Jane";
trace('Hello $name!');
// => "Hello Jane!"
trace('HELLO ${name.toUpperCase()}!');
// => "HELLO JANE!"
```
