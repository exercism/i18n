# Hinweise

## Allgemein

- Mach dir keine Sorgen darüber, wie die Argumente zustande kommen. Konzentriere dich einfach darauf, die Argumente zu kombinieren, um das beabsichtigte Ergebnis zurückzugeben.
- Unison hat [bestimmte Regeln für die Operatorrangfolge][operator-precedence]. Denk daran, runde Klammern zu verwenden, wenn du die Funktionsanwendung anders anordnen musst.

## 1. Definiere, ob Pac-Man einen Geist fressen kann

- Du musst eine Funktion mit 2 Argumenten definieren. Das erste Argument ist ein [boolescher Wert][boolean], der angibt, ob Pac-Man eine Kraftpille aktiv hat. Das zweite Argument ist ein [boolescher Wert][boolean], der angibt, ob Pac-Man einen Geist berührt.
- Die Funktion muss einen [booleschen Wert][boolean] zurückgeben.
- Du kannst den [booleschen Operator][boolean] `&&` verwenden, um die Argumente zu einem Ergebnis zu kombinieren.

## 2. Definiere, ob Pac-Man punktet

- Du musst eine Funktion mit 2 Argumenten definieren. Das erste Argument ist ein [boolescher Wert][boolean], der angibt, ob Pac-Man eine Kraftpille berührt. Das zweite Argument ist ein [boolescher Wert][boolean], der angibt, ob Pac-Man einen Punkt berührt.
- Die Funktion muss einen [booleschen Wert][boolean] zurückgeben.
- Du kannst den [booleschen Operator][boolean] `||` verwenden, um die Argumente zu einem Ergebnis zu kombinieren.

## 3. Definiere, ob Pac-Man verliert

- Du musst eine Funktion mit 2 Argumenten definieren. Das erste Argument ist ein [boolescher Wert][boolean], der angibt, ob Pac-Man eine Kraftpille aktiv hat. Das zweite Argument ist ein [boolescher Wert][boolean], der angibt, ob Pac-Man einen Geist berührt.
- Die Funktion muss einen [booleschen Wert][boolean] zurückgeben.
- Du kannst die [booleschen Operatoren][boolean] `&&` und `not` verwenden, um die Argumente zu einem Ergebnis zu kombinieren.

## 4. Definiere, ob Pac-Man gewinnt

- Du musst eine Funktion mit 3 Argumenten definieren. Das zweite Argument ist ein [boolescher Wert][boolean], der angibt, ob Pac-Man alle Punkte gefressen hat. Das erste Argument ist ein [boolescher Wert][boolean], der angibt, ob Pac-Man eine Kraftpille aktiv hat. Das zweite Argument ist ein [boolescher Wert][boolean], der angibt, ob Pac-Man einen Geist berührt.
- Die Funktion muss einen [booleschen Wert][boolean] zurückgeben.
- Du kannst die [booleschen Operatoren][boolean] `&&` und `not` verwenden, um die Argumente und Ergebnisse aufgerufener Funktionen zu kombinieren.
