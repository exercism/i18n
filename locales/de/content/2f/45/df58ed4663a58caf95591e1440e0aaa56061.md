# Code von „Beschreibe zwei Parameter“ wiederverwenden

Die Methode `describe(Character, Destination)` sollte die Logik wiederverwenden, die in `describe(Character, Destination, TravelMethod)` oder in den einzelnen Methoden `describe(Character)`, `describe(Destination)` und `describe(TravelMethod)` umgesetzt ist.
Wenn du vorhandene Methoden wiederverwendest, lässt sich der Code leichter pflegen.
