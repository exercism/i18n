# Test Runner

Ein Test Runner ist ein Stück Software, das die Tests einer Übung mit dem Code eines Lernenden ausführt.

Test Runner bieten uns zwei Vorteile:

1. Sie ermöglichen das Programmieren im Browser, wo Lernende an einer Lösung arbeiten und dabei sehen, ob die Tests bestehen oder fehlschlagen.
2. Sie erlauben uns, Mentorinnen und Mentoren darüber zu informieren, ob der Code eines Lernenden „funktioniert“ oder nicht.

## Zu Test Runnern beitragen

Jede Sprache hat ihren eigenen Test Runner, der in dieser Sprache geschrieben ist.
Die Website fungiert als Vermittler zwischen den Test Runnern und den Einsendungen der Lernenden.

Jeder Test Runner liegt in der Exercism-GitHub-Organisation in einem Repository namens `<track_slug>-test-runner` (z. B. [`exercism/ruby-test-runner`](https://github.com/exercism/ruby-test-runner)).
Die vorhandenen Test Runner findest du [hier](https://github.com/search?q=topic%3Aexercism-test-runner&type=repositories).

Wenn du bei einem vorhandenen Test Runner mithelfen möchtest, eröffne ein Issue in seinem Repository und frage, ob es irgendwo etwas gibt, wobei du helfen kannst.
Wenn du einen Test Runner für eine Sprache erstellen möchtest, die bisher keinen hat, folge der Anleitung [Test Runner erstellen](/docs/building/tooling/test-runners/creating-from-scratch).
