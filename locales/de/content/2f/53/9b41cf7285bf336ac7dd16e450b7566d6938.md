# Anhang zu den Anweisungen

## Register

| Register | Verwendung | Typ             | Beschreibung                                                  |
| -------- | ---------- | --------------- | ------------------------------------------------------------- |
| `$a0`    | Eingabe    | Adresse         | nullterminierter Eingabe-String                               |
| `$v0`    | Ausgabe    | boolescher Wert | Gültigkeit des Eingabe-Strings (`0` = `false`, `1` = `true`)  |
| `$t0-9`  | temporär   | beliebig        | wird für die temporäre Speicherung verwendet                  |
