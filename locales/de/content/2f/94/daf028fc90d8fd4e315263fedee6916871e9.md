# Ergänzung zu den Anweisungen

## Format des Spielfelds

Das Spielfeld wird als nullterminierter String dargestellt, mit einem Zeilenumbruch am Ende jeder Zeile.

Ein Beispiel wäre `"X  \n XO\nOX \n"`

## Register

| Register | Verwendung   | Typ     | Beschreibung                                                            |
| -------- | ------------ | ------- | ----------------------------------------------------------------------- |
| `$a0`    | Eingabe      | Adresse | nullterminierter String für die Eingabe                                 |
| `$v0`    | Ausgabe      | Ganzzahl | Spielzustand (`1` = `ongoing`, `2` = `draw`, `3` = `win`, `-1` = `error`) |
| `$t0-9`  | temporär     | beliebig | für temporäre Speicherung                                               |
