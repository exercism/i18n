# Einführung

## Strings

Ein `string` in C# ist ein Objekt, das unveränderlichen Text als Folge von Unicode-Zeichen (Buchstaben, Ziffern, Satzzeichen usw.) darstellt. Mit doppelten Anführungszeichen definierst du eine `string`-Instanz:

```csharp
string fruit = "Apple";
```

### Methoden

Strings bearbeitest du, indem du die [eingebauten Methoden][docs-string-methods] des Strings aufrufst.
Um beispielsweise die Leerzeichen aus einem String zu entfernen, kannst du die [Trim-Methode][tutorial-docs.microsoft.com-trim-white-space] so verwenden:

```csharp
string name = " Jane "
name.Trim()
// => "Jane"
```

Sobald ein String erstellt wurde, kann sich sein Wert nie mehr ändern.
Methoden, die einen String zu verändern scheinen, geben in Wirklichkeit einen neuen String zurück.

### Verkettung

Mehrere Strings kannst du miteinander verketten (addieren). Am einfachsten geht das mit dem Operator `+`.

```csharp
string name = "Jane";
"Hello " + name + "!";
// => "Hello Jane!"
```

### Formatierung

Für jede String-Formatierung, die komplexer ist als eine einfache Verkettung, ist die String-Interpolation vorzuziehen. Um Interpolation in einem String zu verwenden, stellst du ihm das Dollarzeichen (`$`) voran. Dann kannst du geschweifte Klammern (`{}`) verwenden, um auf Variablen innerhalb deines Strings zuzugreifen.

```csharp
string name = "Jane";
$"Hello {name}!";
// => "Hello Jane!"
```
