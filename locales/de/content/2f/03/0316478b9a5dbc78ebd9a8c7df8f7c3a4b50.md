# Überblick

- Pony ist statisch typisiert. Das heißt, du *musst* die Datentypen in deinen Programmen vorher festlegen. Wenn du Pony sagst, dass die Variable `x` eine Ganzzahl ist, kannst du ihr keinen String zuweisen.
- Das Typsystem von Pony ist die Grundlage für Ponys Garantien.
  - Wenn dein Programm kompiliert, stürzt es nicht ab.
  - Es gibt nie eine unbehandelte Ausnahme.
  - `null` gibt es nicht, dein Programm wird also nie versuchen, `null` zu dereferenzieren.
  - Es wird nie ein Data Race geben.
  - Es wird nie einen Deadlock geben.
  - Dein Code ist immer Capability-sicher (Schutz vor Supply-Chain-Angriffen).
- In Pony kannst du Typen nicht casten. Alle Typänderungen müssen über eine Funktion erfolgen, die eine neue Instanz des neuen Typs erzeugt.
- Das Typsystem von Pony unterscheidet sich von fast allen anderen Sprachen, deshalb schauen wir es uns in kleinen Häppchen an.

## Primitive

- Primitive sind die einfachste Form der Codeorganisation in Pony.
  - Du kannst sie dir als Container oder Namensraum für Funktionen vorstellen.
  - Ein Primitive hat keine Felder (dafür gibt es Klassen).
  - Definiert wird es mit dem Schlüsselwort `primitive`.

## Funktionen

- Funktionen werden mit dem Schlüsselwort `fun` definiert.
  - Funktionen müssen in einem `primitive` (oder einer `class` oder einem `actor`) leben, aber die kommen später).
  - Funktionen können Argumente entgegennehmen und einen Rückgabewert haben. Beides muss typisiert sein.
  - Wenn du einen Rückgabetyp definierst, *muss* deine Funktion einen Wert dieses Typs zurückgeben. Pony kennt das Konzept Null nicht.

```pony
primitive Greeter
  // A Function that takes a String, and returns a different String
  fun hello(name: String): String =>
    "Hello " + name + "!"
```

## Kommentare

Kommentare kannst du nutzen, um Notizen oder Erinnerungen zu hinterlassen oder um Code vorübergehend aus dem Quellcode zu entfernen. Wie du oben schon gesehen hast, verwendet man für einzeilige Kommentare `//`. Mehrzeilige Kommentare verwenden den C-Stil `/*` und `*/`.

## Variablen

- Variablen beginnen immer mit einem Kleinbuchstaben.
  - Wir deklarieren sie mit `var`. (`let` und `embed` kommen später).
  - Wenn Pony den Typ der Variablen bestimmen kann, macht es das für dich.
  - Der Typ der Variablen wird zur Kompilierzeit geprüft und kann sich nie ändern.
  - Wenn du mit Pony anfängst, empfehlen wir, den Typ explizit anzugeben.

```pony
var name: "Bob"
var bettername: String = "Bobby"
```
