## Optionale Argumente

```julia-repl
julia> f(a, b=1) = a + b
f (generic function with 2 methods)
```

ist äquivalent zu

```julia-repl
julia> f(a, b) = a + b
f (generic function with 1 method)

julia> f(a) = f(a, 1)
f (generic function with 2 methods)
```

In der Antwort in der REPL siehst du, dass die erste Definition zwei Methoden auf einmal definiert.
