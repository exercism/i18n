# Anweisungen

Erstelle eine Implementierung der Atbash-Chiffre, eines alten Verschlüsselungssystems aus dem Nahen Osten.

Die Atbash-Chiffre ist eine einfache Substitutionschiffre. Sie beruht darauf,
alle Buchstaben des Alphabets so zu vertauschen, dass das entstehende
Alphabet rückwärts läuft. Der erste Buchstabe wird durch den letzten ersetzt,
der zweite durch den vorletzten und so weiter.

Eine Atbash-Chiffre für das lateinische Alphabet sieht so aus:

```text
Plain:  abcdefghijklmnopqrstuvwxyz
Cipher: zyxwvutsrqponmlkjihgfedcba
```

Sie ist eine sehr schwache Chiffre, denn sie hat nur einen möglichen Schlüssel und ist eine
einfache monoalphabetische Substitutionschiffre. Zu ihrer Zeit war das
allerdings möglicherweise kein Problem.

Der Geheimtext wird in Gruppen fester Länge geschrieben, wobei die traditionelle
Gruppengröße 5 Buchstaben beträgt; Satzzeichen werden weggelassen. So ist es
schwieriger, anhand von Wortgrenzen etwas zu erraten.

## Beispiele

- Das Kodieren von `test` ergibt `gvhg`
- Das Dekodieren von `gvhg` ergibt `test`
- Das Dekodieren von `gsvjf rxpyi ldmul cqfnk hlevi gsvoz abwlt` ergibt `thequickbrownfoxjumpsoverthelazydog`
