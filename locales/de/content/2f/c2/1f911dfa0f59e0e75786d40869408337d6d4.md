# Einführung

Clojure verwendet den zugrunde liegenden Typ `java.lang.Character`, eine 16-Bit-Größe, mit der sich die kleinsten adressierbaren Bestandteile von Text darstellen lassen.
Mehrere `char`s können einen String wie `"word"` bilden, oder `char`s lassen sich einzeln verarbeiten. Ihre Literale schreibt man wie `\a \b \c`.

Die `char`s von Clojure unterstützen die UTF-16-Unicode-Kodierung. Deshalb lassen sich neben dem lateinischen Zeichensatz so ziemlich alle Schriftsysteme darstellen, die auf der Welt verwendet werden, zum Beispiel der griechische Buchstabe `'β'`.

Es gibt viele Bibliotheksmethoden, um `char`s zu untersuchen und zu manipulieren. Auf sie kannst du über Interop als Methoden der Klasse `Character` zugreifen. Clojure enthält außerdem eine eingebaute Hilfsbibliothek für Strings, `clojure.string`, die viele mächtige Funktionen für die Arbeit mit Zeichen bietet.
