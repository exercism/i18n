# Einführung

C ist eine statisch typisierte Sprache. Das bedeutet, dass alles zur Kompilierzeit einen Typ hat.
Einer Variablen einen Namen zu geben und ihren Typ festzulegen, nennt man das Deklarieren einer Variablen.

Eine Variable wird deklariert, indem du ihren Typ ausdrücklich angibst.
Ein Variablenname muss mit einem Buchstaben oder einem Unterstrich beginnen.
Manche Namen kannst du nicht verwenden, weil sie [für Schlüsselwörter][reserved-keywords] oder [andere Bezeichner][reserved-identifiers] reserviert sind.

Das Setzen oder Aktualisieren einer Variablen geschieht durch eine Zuweisung.
Wenn du den Wert setzt, definierst du die Variable.
Das Definieren einer Variablen nennt man auch Initialisierung.

```c
int foo;      // Declare an integer named var
foo = 10;     // Define the variable

int bar = 15; // Both can also be done in a single statement
```

Der Wert einer Variablen lässt sich mit dem einfachen Zuweisungsoperator `=` zuweisen und aktualisieren.
Sobald eine Variable definiert ist, kann sich ihr Typ nie mehr ändern.

```c
int foo = 10; // Assign initial value
foo = 25;     // Update to new value

foo = false;  // Compiler error when assigning value of a different type
```

C ist eine imperative prozedurale Sprache.
Jede Berechnung erfolgt als Teil einer Reihe von Anweisungen, die zu einer Funktion oder zu mehreren Funktionen gehören.

Jede Funktion kann null oder mehr Parameter haben.
Wenn du eine Funktion definierst, musst du alle Parameter und den Rückgabewert ausdrücklich mit einem Typ versehen.
Werte werden mit dem Schlüsselwort `return` aus Funktionen zurückgegeben.
Funktionen haben standardmäßig die externe Speicherklasse. Das bedeutet, dass sie für die gesamte Laufzeit des Programms existieren und außerhalb der Datei sichtbar sein können.
Um das zu verhindern, kannst du das Schlüsselwort `static` hinzufügen, um interne Sichtbarkeit festzulegen.

```c
static int add(int x, int y) {
  return x + y;
}
```

Im obigen Beispiel lassen sich die Variablen `x` und `y` nur innerhalb der Funktion verwenden, das heißt, sie haben Funktionsgültigkeitsbereich.
Der Gültigkeitsbereich bedeutet, dass der Wert, der mit einem Namen (eines Programmelements) verbunden ist, nur innerhalb des Code-„Bereichs“ zugänglich ist, in dem er definiert wurde.
Die wichtigsten Codebereiche in C sind:

- Datei
- Funktion
- Block (etwa innerhalb von Schleifen und anderen Konstrukten)

Funktionen werden aufgerufen, indem du den Funktionsnamen angibst und für jeden Parameter der Funktion ein Argument übergibst.

```c
int sum = add(1, 2);
```

C unterstützt zwei Arten von Kommentaren.
Einzeilige Kommentare beginnen mit `//` (seit C99), mehrzeilige Kommentare stehen zwischen `/*` und `*/`.
