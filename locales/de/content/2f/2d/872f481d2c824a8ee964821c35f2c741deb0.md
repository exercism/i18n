# keine Schleifen

Der Schleifenoperator wird nicht gebraucht.
Baue den zurückzugebenden String mit [Standardwerten für Parameter](https://docs.scala-lang.org/tour/default-parameter-values.html) und [String-Interpolation](https://docs.scala-lang.org/overviews/core/string-interpolation.html) dynamisch auf.
