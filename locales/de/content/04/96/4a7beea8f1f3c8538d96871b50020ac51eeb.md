# Keine Standardargumente verwendet

In der Funktionsdefinition dieser Lösung wird kein [Standardargument][default argument] verwendet.
[Standardargumente in Python][default arguments in python] können dabei helfen, Situationen abzufangen, in denen eine Funktion ohne ein erwartetes Argument aufgerufen wird oder kein Argument zum Übergeben verfügbar ist.
`Default arguments` können außerdem dabei helfen, unnötigen bedingten Code oder unnötige Prüfungen innerhalb einer Funktion zu vermeiden.

Diese Lösung lässt sich verbessern, indem du ein `default argument` zusammen mit entweder [str.format][str.format] oder [f-strings][f-strings] verwendest (_auch bekannt als „formatted string literals“ oder „interpolated strings“_).

[String Formatting in Python][string formatting in python] von Real Python kann ein guter Ausgangspunkt sein, um die Formatierungsmöglichkeiten von Python-Strings kennenzulernen.
