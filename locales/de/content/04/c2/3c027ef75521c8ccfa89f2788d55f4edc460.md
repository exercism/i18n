# Einführung

## Vergleichsoperatoren

R hat eine Reihe von Operatoren, die mit denen vieler anderer Sprachen übereinstimmen:

```R
1 == 2 # FALSE
1 != 2 # TRUE
1 < 2 # TRUE
1 > 2 # FALSE
1 <= 2 # TRUE
1 >= 2 # FALSE
```

## Verzweigung

Die Grundform einer if-else-Anweisung sieht so aus:

```R
if (x > 10) {
    y <- "big"
} else if (x > 2) {
    y <- "medium"
} else {
    y <- "tiny"
}
```

In diesem Fall sind sowohl die runden Klammern `()` um den booleschen Wert als auch die geschweiften Klammern `{}` um den Block erforderlich.

Eine einfache `if`-Anweisung kannst du verkürzen:

```R
if (x == 0) return("success")
```
