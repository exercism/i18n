# Zahlen

`INT` speichert eine Ganzzahl. In diesem Sather ist er genau 32 Bit groß, er zählt also von -2147483648 bis 2147483647.

```sather
   goals : INT is
      return 42;
   end;
```

## Argumente

Eine Routine nimmt Argumente in runden Klammern entgegen, jedes mit einem Typ:

```sather
   total(first : INT, second : INT) : INT is
      return first + second;
   end;
```

Argumente mit demselben Typ können sich eine Deklaration teilen; das ist der übliche Stil:

```sather
   total(first, second : INT) : INT is
```

## Arithmetik

| Operator | Bedeutung |
| --- | --- |
| `+` | addieren |
| `-` | subtrahieren und negieren |
| `*` | multiplizieren |
| `/` | dividieren, wobei der Rest verworfen wird |
| `%` | der Rest dieser Division |

`/` zwischen zwei `INT`s ergibt nie einen Bruch:

```sather
7 / 2      -- 3
7 % 2      -- 1
```

Wenn du einen Bruch willst, brauchst du `FLTD`, das später drankommt.

Multiplikation und Division binden stärker als Addition und Subtraktion, wie in der gewöhnlichen Arithmetik. Klammern gruppieren, wenn du etwas anderes brauchst:

```sather
2 + 3 * 4        -- 14
(2 + 3) * 4      -- 20
```

## Nützliche Routinen für INT

```sather
7.max(3)     -- 7
7.min(3)     -- 3
(-7).abs     -- 7
7.str        -- "7", the number written as text
```

Mit `.str` wird eine Zahl Teil eines Satzes, sobald du Strings kennengelernt hast.
