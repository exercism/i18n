# Ignoriere mich

## Eingabe

Dein Skript erhält das alphametische Rätsel als einzelnen String über die
Standardeingabe (stdin). Der Rätsel-String hat das Format
`WORD1 + WORD2 + ... == RESULT`.

Zum Beispiel:

```text
SEND + MORE == MONEY
```

## Ausgabe

Wenn das Rätsel eine Lösung hat, gib eine einzelne Zeile aus, die aus
durch Leerzeichen getrennten `LETTER=DIGIT`-Paaren besteht, alphabetisch nach
Buchstabe sortiert.

Für das Beispiel oben sollte die Ausgabe so aussehen:

```text
D=7 E=5 M=1 N=6 O=0 R=8 S=9 Y=2
```

Wenn das Rätsel mehrere gültige Lösungen hat, ist es in Ordnung, eine beliebige
davon auszugeben.

Wenn das Rätsel keine Lösung hat, gib nichts aus (eine leere Zeile).
