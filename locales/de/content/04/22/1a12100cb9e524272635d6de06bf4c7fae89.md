# Anleitung

Du bist der Bootsmann auf einem Küstenfrachter. Die Bilge, der unterste Raum des Rumpfes, sammelt Abwasser, und jede Schicht muss die Bilgenausrüstung geöffnet, betrieben und wieder verstaut werden. Was auch immer mitten im Pumpen passiert, die Ausrüstung *muss* am Ende wieder in ihrem verstauten Zustand sein.

Die Tests geben dir `<test-pump>`, um frische Pumpen zu bekommen. Jede Pumpe hat einen `opened>>`-Slot, der `t` liefert, solange sie geöffnet ist, und `f`, sobald sie entsorgt wurde.

## 1. Die Bilge lenzen

Definiere `drain-bilge`, um eine einzelne Pumpe freizugeben. `drain-bilge` zweimal für dieselbe Pumpe aufzurufen, sollte harmlos sein, denn das Framework erledigt das für dich.

```factor
<test-pump> dup drain-bilge opened>> .   ! => f
```

## 2. Die Abpumproutine

Definiere `pump-out` so, dass es eine Pumpe und eine Quotation entgegennimmt, die Pumpe auf den Stack legt, damit die Quotation sie verwenden kann, und die Pumpe danach freigibt, *selbst wenn die Quotation eine Exception wirft*.

```factor
<test-pump> [ drop ] pump-out   ! pump released
```

## 3. Die Routine für die ganze Schicht

Definiere `shift-routine` so, dass es zwei Pumpen und eine Quotation entgegennimmt. Öffne einen Destruktor-Gültigkeitsbereich, registriere *beide* Pumpen für die bedingungslose Freigabe und rufe dann die Quotation auf. Beide Pumpen werden am Ende freigegeben, egal ob die Quotation normal endet oder eine Exception wirft.

Die Quotation erhält beide Pumpen als Eingabewerte auf dem Stack.

```factor
<test-pump> <test-pump> [ 2drop ] shift-routine
! both pumps released
```

## 4. Riskantes Abpumpen

Manchmal ist eine Pumpe nur ausgeliehen: Du willst sie nur dann entsorgen, wenn etwas schiefgeht, denn sonst braucht die nächste Wache sie noch im geöffneten Zustand. Definiere `risky-pump-out` so, dass es eine Pumpe und eine Quotation entgegennimmt, die Pumpe für eine Freigabe **nur im Fehlerfall** registriert und die Quotation mit der Pumpe auf dem Stack aufruft.

Gelingt die Quotation, bleibt die Pumpe geöffnet. Wirft die Quotation eine Exception, wird die Pumpe freigegeben und die Exception wird weitergereicht.

```factor
<test-pump> [ drop ] risky-pump-out                ! stays open
<test-pump> [ drop "boom" throw ] risky-pump-out   ! pump released, throws
```

## 5. Ein eigenes Disposable: das Ventil

Runde den Werkzeugkasten mit einem brandneuen Disposable ab: einem `valve`. Das Tupel ist bereits für dich deklariert:

```factor
TUPLE: valve < disposable is-open ;
```

- Definiere `<valve> ( -- valve )`, um über `new-disposable` ein frisches Ventil zu erzeugen, wobei `is-open` auf `t` gesetzt ist.
- Implementiere `M: valve dispose*`, um `is-open` auf `f` umzuschalten.

```factor
<valve> is-open>> .                ! => t
<valve> dup dispose is-open>> .    ! => f
```
