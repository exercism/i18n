# Ergänzung zur Anleitung

## Eigene Exceptions anpassen und auslösen

Manchmal ist es notwendig, Exceptions in deinem Code sowohl [anzupassen](https://docs.python.org/3/tutorial/errors.html#user-defined-exceptions) als auch mit [`raise`](https://docs.python.org/3/tutorial/errors.html#raising-exceptions) auszulösen. Dabei solltest du immer eine **aussagekräftige Fehlermeldung** angeben, die verrät, woher der Fehler kommt. Das macht deinen Code lesbarer und hilft beim Debuggen erheblich.

Eigene Exceptions kannst du über neue Exception-Klassen erstellen (siehe [`classes`](https://docs.python.org/3/tutorial/classes.html#tut-classes) für weitere Details), die normalerweise Unterklassen von [`Exception`](https://docs.python.org/3/library/exceptions.html#Exception) sind.

Wenn du weißt, dass die Fehlerquelle von einem bestimmten Exception-Typ abgeleitet ist, kannst du von einem der [`built in error types`](https://docs.python.org/3/library/exceptions.html#base-classes) unter der _Exception_-Klasse erben. Auch beim Auslösen des Fehlers solltest du trotzdem eine aussagekräftige Meldung angeben.

In dieser Übung musst du zwei _eigene Exceptions_ erstellen. Eine Exception, die [ausgelöst](https://docs.python.org/3/reference/simple_stmts.html#the-raise-statement)/„geworfen" wird, wenn dein Ringpuffer **voll** ist, und eine für den Fall, dass er **leer** ist. Die Tests bestehen nur, wenn du passende Exceptions anpasst, sie mit `raise` auslöst und passende Fehlermeldungen angibst.

Um eine `built-in exception` anzupassen, erstelle eine `class`, die von dieser Exception erbt. Wenn du die eigene Exception mit einer Meldung auslöst, schreibst du die Meldung als Argument an den Typ `exception`:

```python
# subclassing the built-in BufferError to create BufferFullException
class BufferFullException(BufferError):
    """Exception raised when CircularBuffer is full.

    message: explanation of the error.

    """
    def __init__(self, message):
        self.message = message

        
# raising a BufferFullException
raise BufferFullException("Circular buffer is full")
```
