# Einführung

## Opaque-Typen

Opaque-Typen in Gleam sind benutzerdefinierte Typen. Nur das Modul, das den Typ definiert, kann Werte dieses Typs konstruieren oder per Mustervergleich abgleichen. Das ist nützlich, um Typen zu erstellen, die nur auf eine bestimmte Weise verwendet werden sollten.

Opaque-Typen werden mit dem Schlüsselwort `opaque` definiert.

```gleam
pub opaque type PositiveInt {
  PositiveInt(inner: Int)
}
```

Dieser `PositiveInt`-Typ soll in Situationen verwendet werden, in denen eine Ganzzahl gewünscht ist, aber sie muss null oder größer sein. Ein normales Gleam-`Int` könnte nicht verwendet werden, da sie auch negativ sein können.

Das Modul, das diesen Typ definiert, kann eine Funktion definieren, um den inneren Ganzzahlwert zu erhalten, und eine Funktion zum Erstellen des `PositiveInt`-Typs, die einen Fehler zurückgibt, wenn der Wert nicht positiv ist.

```gleam
pub fn from_int(i: Int) -> Result(PositiveInt, String) {
  case i {
    _ if i < 0 -> Error("Value must be positive")
    _ -> Ok(PositiveInt(i))
  }
}

pub fn to_int(i: PositiveInt) -> Int {
  i.inner
}
```

Mit dieser API können andere Module keinen `PositiveInt` mit einem negativen Wert konstruieren, sodass jede Funktion, die einen `PositiveInt` entgegennimmt, sicher sein kann, dass der Wert positiv ist.
