# Anleitung

In dieser Übung implementierst du eine Möglichkeit, die Highscores für das beliebteste Spiel in deiner örtlichen Spielhalle im Blick zu behalten.

## 1. Definiere eine neue Highscore-Map

Um eine neue Highscore-Map zu erstellen, definiere die Funktion `HighScore.new/0`, die keine Argumente entgegennimmt und eine neue, leere Map mit Highscores zurückgibt.

```elixir
HighScore.new()
# => %{}
```

## 2. Füge Spieler zur Highscore-Map hinzu

Um einen Spieler zur Highscore-Map hinzuzufügen, definiere `HighScore.add_player/3`, eine Funktion, die 3 Argumente entgegennimmt:

- Das erste Argument ist die Map mit den Punktzahlen.
- Das zweite Argument ist der Name eines Spielers als String.
- Das dritte Argument ist die Punktzahl als Ganzzahl. Das Argument ist optional, implementiere das dritte Argument mit dem Standardwert 0.

Speichere die Standardpunktzahl für den Anfang in einem Modulattribut. Du wirst sie später noch brauchen.

```elixir
score_map = HighScore.new()
# => %{}
score_map = HighScore.add_player(score_map, "Dave Thomas")
# => %{"Dave Thomas" => 0}
score_map = HighScore.add_player(score_map, "José Valim", 486_373)
# => %{"Dave Thomas" => 0, "José Valim"=> 486_373}
```

## 3. Entferne Spieler aus der Highscore-Map

Um einen Spieler aus der Highscore-Map zu entfernen, definiere `HighScore.remove_player/2`, eine Funktion, die 2 Argumente entgegennimmt:

- Das erste Argument ist die Map mit den Punktzahlen.
- Das zweite Argument ist der Name des Spielers als String.

```elixir
score_map = HighScore.new()
# => %{}
score_map = HighScore.add_player(score_map, "Dave Thomas")
# => %{"Dave Thomas" => 0}
score_map = HighScore.remove_player(score_map, "Dave Thomas")
# => %{}
```

## 4. Setze die Punktzahl eines Spielers zurück

Um die Punktzahl eines Spielers zurückzusetzen, definiere `HighScore.reset_score/2`, eine Funktion, die 2 Argumente entgegennimmt:

- Das erste Argument ist die Map mit den Punktzahlen.
- Das zweite Argument ist der Name des Spielers als String, dessen Punktzahl du zurücksetzen möchtest.

Die Funktion sollte auch funktionieren, wenn der Spieler noch keine Punktzahl hat.

```elixir
score_map = HighScore.new()
# => %{}
score_map = HighScore.add_player(score_map, "José Valim", 486_373)
# => %{"José Valim"=> 486_373}
score_map = HighScore.reset_score(score_map, "José Valim")
# => %{"José Valim"=> 0}
```

## 5. Aktualisiere die Punktzahl eines Spielers

Um die Punktzahl eines Spielers zu aktualisieren, indem du etwas zur vorherigen Punktzahl hinzufügst, definiere `HighScore.update_score/3`, eine Funktion, die 3 Argumente entgegennimmt:

- Das erste Argument ist die Map mit den Punktzahlen.
- Das zweite Argument ist der Name des Spielers als String, dessen Punktzahl du aktualisieren möchtest.
- Das dritte Argument ist die Punktzahl, die du zur gespeicherten Punktzahl **addieren** möchtest.

Die Funktion sollte auch funktionieren, wenn der Spieler noch keine vorherige Punktzahl hat. Geh davon aus, dass die vorherige Punktzahl 0 ist.

```elixir
score_map = HighScore.new()
# => %{}
score_map = HighScore.add_player(score_map, "José Valim", 486_373)
# => %{"José Valim"=> 486_373}
score_map = HighScore.update_score(score_map, "José Valim", 5)
# => %{"José Valim"=> 486_378}
```

## 6. Hole eine Liste der Spieler

Um eine Liste der Spieler zu erhalten, definiere `HighScore.get_players/1`, eine Funktion, die 1 Argument entgegennimmt:

- Das erste Argument ist die Map mit den Punktzahlen.

```elixir
score_map = HighScore.new()
# => %{}
score_map = HighScore.add_player(score_map, "Dave Thomas", 2_374)
# => %{"Dave Thomas" => 2_374}
score_map = HighScore.add_player(score_map, "José Valim", 486_373)
# => %{"Dave Thomas" => 2_374, "José Valim"=> 486_373}
HighScore.get_players(score_map)
# => ["Dave Thomas", "José Valim"]
```
