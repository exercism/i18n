# Tests

Für die Tests muss das Paket `{testthat}` in R installiert sein.
Um die Tests für eine Übung auszuführen, führst du einfach das Skript `test_<exercise_name>.R` im Verzeichnis der Übung aus.

Praktischer geht das mit [der Funktion `auto_test` von testthat](https://testthat.r-lib.org/reference/auto_test.html). Da der Code und die Tests bei Exercism im selben Ordner liegen, verwendest du denselben Pfad für die Parameter `code_path` und `test_path`. Auf der Kommandozeile kannst du außerdem `Rscript test_<exercise_name>.R` ausführen.

Weitere Informationen findest du auf der [Tests-Seite](https://exercism.org/docs/tracks/r/tests).
