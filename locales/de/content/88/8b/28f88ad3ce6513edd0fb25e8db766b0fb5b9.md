# Einführung

Wenn eine Variante eines Custom Types Daten enthält, nennt man sie einen Record, und jeder enthaltene Wert liegt in einem _Feld_.

```gleam
pub type Rectangle {
  Rectangle(
    Float, // The first field
    Float, // The second field
  )
}
```

Um die Lesbarkeit zu erleichtern, erlaubt es Gleam, Felder mit einem Namen zu beschriften.

```gleam
pub type Rectangle {
  Rectangle(
    width: Float,
    height: Float,
  )
}
```

Mit Labels können die Argumente dem Konstruktor eines Records in beliebiger Reihenfolge übergeben werden.

```gleam
let a = Rectangle(height: 10.0, width: 20.0)
let b = Rectangle(width: 20.0, height: 10.0)

a == b
// -> True
```

Wenn ein Custom Type nur eine Variante hat, kann die Zugriffssyntax `.label` verwendet werden, um an die Felder eines Records zu gelangen.

```gleam
let rect = Rectangle(height: 10.0, width: 20.0)

rect.height // -> 10.0
rect.width  // -> 20.0
```

Die Syntax zum Aktualisieren von Records kann verwendet werden, wenn ein Custom Type eine einzige Variante hat, um aus einem bestehenden Record einen neuen zu erzeugen, bei dem einige Felder durch neue Werte ersetzt sind.

```gleam
let rect = Rectangle(height: 10.0, width: 20.0)
let tall_rect = Rectangle(..rect, height: 50.0)

tall_rect.height // -> 50.0
tall_rect.width  // -> 20.0
```

Labels können auch beim Pattern Matching verwendet werden, um Werte aus Records zu extrahieren.

```gleam
pub fn is_tall(rect: Rectangle) {
  case rect {
    Rectangle(height: h, width: _) if h > 20.0 -> True
    _ -> False
  }
}
```

Wenn wir nur auf einige der Felder matchen wollen, können wir den Spread-Operator `..` verwenden, um alle übrigen Felder zu ignorieren.

```gleam
pub fn is_tall(rect: Rectangle) {
  case rect {
    Rectangle(height: h, ..) if h >. 20.0 -> True
    _ -> False
  }
}
```
