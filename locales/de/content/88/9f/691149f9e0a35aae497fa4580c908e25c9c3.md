# Anweisungen

In dieser Übung schreibst du Code, der einem Freelancer dabei hilft, mit der Projektleitung zu kommunizieren. Deine Aufgabe ist es, ein paar Hilfsfunktionen bereitzustellen, mit denen sich Tages- und Monatssätze schnell berechnen lassen, optional mit einem gegebenen Rabatt.

Zuerst legen wir ein paar Regeln zwischen dem Freelancer und der Projektleitung fest:

- Der Tagessatz ist das 8-Fache des Stundensatzes.
- Ein Monat hat 22 abrechenbare Tage.

Manchmal bietet der Freelancer an, einen Rabatt auf seinen Tagessatz zu gewähren (zum Beispiel für seine treuesten Kunden oder für gemeinnützige Kunden).

Rabatte werden als Bruchzahlen modelliert, die Prozentwerte darstellen, zum Beispiel `25.0` (25 %).

## 1. Berechne den Tagessatz aus einem Stundensatz

Implementiere eine Funktion namens `daily_rate`, die den Tagessatz aus einem Stundensatz als Parameter berechnet.
Der Vertrag legt fest, dass ein Tag 8 abrechenbare Stunden hat.

```elixir
FreelancerRates.daily_rate(60)
# => 480.0
```

Der zurückgegebene Tagessatz sollte eine Gleitkommazahl sein.

## 2. Berechne einen rabattierten Preis

Implementiere eine Funktion `apply_discount`, die den Preis nach einem Rabatt berechnet.

```elixir
FreelancerRates.apply_discount(150, 10)
# => 135.0
```

Der Rückgabewert sollte immer eine Gleitkommazahl sein und in keiner Weise gerundet werden.

## 3. Berechne den Monatssatz aus einem Stundensatz und einem Rabatt

Implementiere eine Funktion `monthly_rate`, die den rabattierten Monatssatz berechnet.
Sie nimmt zwei Parameter entgegen: einen Stundensatz und den Rabatt in Prozent.

```elixir
FreelancerRates.monthly_rate(77, 10.5)
# => 12130
```

Der zurückgegebene Monatssatz sollte auf die nächste Ganzzahl aufgerundet werden.

## 4. Berechne die Anzahl der vollständigen Arbeitstage aus einem Budget, einem Stundensatz und einem Rabatt

Implementiere eine Funktion `days_in_budget`, die ein Budget, einen Stundensatz und einen Rabatt entgegennimmt und berechnet, wie viele vollständige Arbeitstage damit abgedeckt sind.

```elixir
FreelancerRates.days_in_budget(20000, 80, 11.0)
# => 35.1
```

Die zurückgegebene Anzahl an Tagen sollte auf eine Nachkommastelle abgerundet werden.
