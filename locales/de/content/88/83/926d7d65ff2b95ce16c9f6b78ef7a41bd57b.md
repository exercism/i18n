# Zahlen

Crystal hat einen Typ `Number`, der der Basistyp für alle numerischen Typen ist.
Innerhalb des Typs Number gibt es zwei wichtige Untertypen: [`Int`][int] und [`Float`][float].

`Int` ist die Kurzform von Ganzzahl und steht für ganze Zahlen.
`Int` kann sowohl negativ als auch positiv sein, ohne Dezimalpunkt.

```crystal
1.class
# => Int32

-1.class
# => Int32
```

`Float` stellt Zahlen mit einem Dezimalpunkt dar.
`Float`s können sowohl negativ als auch positiv sein.

```crystal
10.5.class
# => Float64
```

## Zwischen `Int` und `Float` umwandeln

Mit den Methoden „to_i“ und „to_f“ kannst du zwischen `Int` und `Float` umwandeln.
Beim Umwandeln von `Float` zu `Int` wird die Zahl abgerundet.

```crystal
1.to_f
# => 1.0

1.0.to_i
# => 1

1.9.to_i
# => 1
```

## Arithmetische Operatoren

Du kannst die [grundlegenden arithmetischen Operatoren][math] auf `Int` und `Float` anwenden.
Die Operatoren sind `+`, `-`, `*`, `/` und `%`.
Bei der Verwendung dieser Operatoren kannst du `Int` und `Float` beliebig mischen.

### Addition, Subtraktion und Multiplikation

Der Operator `+` steht für die Addition, der Operator `-` für die Subtraktion und der Operator `*` für die Multiplikation.

| Operator | Beispiel       |
| -------- | -------------- |
| `+`      | `4 + 6 => 10`  |
| `-`      | `15 - 10 => 5` |
| `*`      | `2 * 3 => 6`   |

### Division

Mit der Division werden Zahlen geteilt.
Der Operator `/` steht für die Division.
Das Ergebnis ist immer ein Float.

```crystal
4 / 2
# => 2.0

4.0 / 2
# => 2.0
```

~~~~exercism/caution
In manchen Programmiersprachen führt eine Division durch null zu einem Fehler.

In Crystal ist das Ergebnis einer Division durch null `Infinity` oder `-Infinity`.
Die einzige Ausnahme ist die Division von null durch null, die `NaN` (keine Zahl) ergibt.
`Infinity` und `NaN` sind spezielle Werte im Typ `Float`.

```crystal
1 / 0
# => Infinity

-1 / 0
# => -Infinity

0 / 0
# => NaN
```
~~~~

### Modulus

Mit dem Modulus bestimmst du den Rest einer Division.
Der Operator `%` steht für den Modulus.

```crystal
5 % 2
# => 1

5.0 % 2
# => 1.0

5 % 3
# => 2
```

~~~~exercism/caution
Eine Division durch null beim Modulo ergibt einen DivisionByZeroError.
Das unterscheidet sich von der normalen Division.

```crystal
1 % 0
# Error: Unhandled exception: Division by 0 (DivisionByZeroError)
```
~~~~

## Runden

Die Methode `round` nimmt ein optionales Argument entgegen: die Anzahl der Dezimalstellen, auf die gerundet werden soll.
Standardmäßig ist die Anzahl der Dezimalstellen 0.

```crystal
1.0.round
# => 1

1.5.round
# => 2

1.234.round(2)
# => 1.23
```

## Priorität und Klammern

Crystal erlaubt runde Klammern (`()`), mit denen du Ausdrücke gruppieren kannst.
Das ist nützlich, wenn du die Reihenfolge der Operationen ändern möchtest.

Wenn du mehrere arithmetische Operatoren verwendest, gilt die gleiche Reihenfolge der Operationen wie in der Mathematik, auch bekannt als [PEMDAS][pemdas].
Sie folgt der Reihenfolge: runde Klammern (`()`), Exponenten (`**`), Multiplikation (`*`) und Division (`/`) sowie Addition (`+`) und Subtraktion (`-`).

```crystal
2 + 3 - 4 * 4
# => -11

(2 + 3 - 4) * 4
# => 4
```
