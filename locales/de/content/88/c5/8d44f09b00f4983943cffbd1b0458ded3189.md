# Einführung

Zeichen in Factor sind Ganzzahlen (Unicode-Codepunkte). Daher liefern die numerischen Operatoren `<`, `>`, `=` direkt eine Sortierung, die zwischen Groß- und Kleinschreibung unterscheidet. Das Vokabular [`unicode`][unicode] fügt Unicode-fähige Prädikate und die Umwandlung der Groß-/Kleinschreibung einzelner Zeichen hinzu.

## Zeichenprädikate

```
LETTER?  ( c -- ? )    ! uppercase letter
letter?  ( c -- ? )    ! lowercase letter
Letter?  ( c -- ? )    ! letter, either case
digit?   ( c -- ? )    ! decimal digit
blank?   ( c -- ? )    ! whitespace
```

```factor
USING: unicode ;

CHAR: A LETTER? .    ! => t
CHAR: a letter? .    ! => t
CHAR: 7 digit?  .    ! => t
```

## Umwandlung der Groß-/Kleinschreibung

`ch>upper` und `ch>lower` wandeln ein einzelnes Zeichen um. Die String-Varianten `>upper` und `>lower` wenden sie auf jedes Zeichen eines Strings an.

```factor
CHAR: a ch>upper .   ! => 65   (which is CHAR: A)
"Hello" >upper .     ! => "HELLO"
```
