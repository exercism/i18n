# Einführung

## Reguläre Ausdrücke

Reguläre Ausdrücke in Gleam folgen der **PCRE**-Spezifikation (**P**erl **C**ompatible **R**egular **E**xpressions), ähnlich wie in anderen populären Sprachen wie Java, JavaScript oder Ruby.

Das Modul `gleam/regexp` aus dem Paket `gleam_regexp` bietet Funktionen für den Umgang mit regulären Ausdrücken.

~~~~exercism/note
Diese Übung geht davon aus, dass du die Syntax regulärer Ausdrücke bereits kennst, einschließlich Zeichenklassen, Quantoren, Gruppen und Captures.

Wenn du dein Wissen über reguläre Ausdrücke auffrischen möchtest, schau dir eine dieser Quellen an: [Regular-Expressions.info](https://www.regular-expressions.info), [Rex Egg](https://www.rexegg.com/), [RegexOne](https://regexone.com/), [Regular Expressions 101](https://regex101.com/), [RegExr](https://regexr.com/).
~~~~

Am häufigsten erstellst du reguläre Ausdrücke mit der Funktion `regexp.from_string`.

```gleam
let assert Ok(re) = regexp.from_string("test")
```

Die Funktionen zum Erstellen regulärer Ausdrücke geben einen Fehler zurück, wenn die Syntax des regulären Ausdrucks ungültig ist. Deshalb wird hier mit einer let-Assertion sichergestellt, dass der reguläre Ausdruck gültig ist.

Mit der Funktion `regexp.check` kannst du prüfen, ob ein regulärer Ausdruck zu einem String passt.

```gleam
let assert Ok(re) = regexp.from_string("test")

regexp.check(re, "this is a test")
// -> True

regexp.check(re, "this is too")
// -> False
```


### Captures

Wenn du mit einem regulären Ausdruck Teile eines Strings erfassen möchtest, liefert dir die Funktion `regexp.scan` eine Liste von Treffern.

```gleam
let assert Ok(re) = regexp.from_string("[oi]n a (\\w+)")
regexp.scan(with: re, content: "I am on a boat in a lake.")
// -> [
//   Match(
//     content: "on a boat",
//     submatches: [Some("boat")]
//   ),
//   Match(
//     content: "in a lake",
//     submatches: [Some("lake")]
//   )
// ]
```

### Modifikatoren

Das Verhalten eines regulären Ausdrucks kannst du ändern, indem du ihn mit der Funktion `regexp.compile` erstellst und Optionen übergibst.

```gleam
let options = regexp.Options(case_insensitive: True, multi_line: False)
let assert Ok(re) = regexp.compile("[A-Z]", with: options)
regexp.check(re, "abc123")
// -> True
```
