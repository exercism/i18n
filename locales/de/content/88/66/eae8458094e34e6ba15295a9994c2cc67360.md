# Über

[Ballerina](https://ballerina.io/) ist eine kompilierte, transaktionale, statisch und stark typisierte Programmiersprache mit textueller und grafischer Syntax. Ballerina integriert grundlegende Konzepte der Integration verteilter Systeme direkt in die Sprache und bietet eine typsichere, nebenläufige Umgebung, um Microservices mit verteilten Transaktionen, zuverlässigem Messaging, Stream-Verarbeitung und Workflows umzusetzen.

Ballerina ist so entworfen, dass Integration einfach wird. Die Sprache baut auf den Interaktionen von Sequenzdiagrammen auf und bringt Unterstützung für gängige Integrationsmuster und Konnektoren bereits mit, darunter verteilte Transaktionen, Kompensation und Circuit Breaker. Mit erstklassiger Unterstützung für JSON und XML macht Ballerina es einfach und effektiv, eine robuste Integration über Netzwerk-Endpunkte hinweg aufzubauen.
