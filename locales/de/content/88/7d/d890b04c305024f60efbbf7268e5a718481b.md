# Anleitung

Dein Freund, ein angehender Künstler, hat sich mit einer Projektidee bei dir gemeldet. Kombinieren wir seine visuelle Kreativität mit deiner technischen Expertise. Zeit, dich in [generativer Kunst][generative-art] zu versuchen!

Einschränkungen fördern die Kreativität und verkürzen Projektfristen, deshalb habt ihr beide vereinbart, euer Meisterwerk auf eine einzige Form zu beschränken: den Kreis. Aber es wird viele Kreise geben. Und sie können sich bewegen! Ihr nennt es ... Dancing Dots.

Dein Freund wird auf jeden Fall neue, ausgefallene Bewegungen für die Punkte entwickeln wollen, also beginnst du mit dem Programmieren, indem du eine Architektur erstellst, mit der du später leicht neue Animationen definieren kannst.

## 1. Definiere das Verhalten der Animation

Jedes Animationsmodul muss zwei Callbacks implementieren: `init/1` und `handle_frame/3`. Definiere sie im Modul `Animation`.

Definiere den Callback `init/1`. Er sollte ein Argument vom Typ `opts` entgegennehmen und entweder ein `{:ok, opts}`-Tupel oder ein `{:error, error}`-Tupel zurückgeben. Implementierungen dieses Callbacks prüfen, ob die übergebenen Optionen für diese spezielle Art von Animation gültig sind.

Definiere den Callback `handle_frame/3`. Er sollte drei Argumente entgegennehmen: den Punkt, eine Frame-Nummer und die Optionen. Er sollte immer einen Punkt zurückgeben. Implementierungen dieses Callbacks ändern die Attribute des Punktes basierend auf der aktuellen Frame-Nummer und den Optionen der Animation.

## 2. Stelle eine Standardimplementierung für den Callback `init/1` bereit

Das Verhalten `Animation` sollte sich leicht in andere Module einbinden lassen, indem du `use DancingDots.Animation` aufrufst.

Implementiere dazu das Makro `__using__` im Modul `Animation`, sodass es das Modul `Animation` als Verhalten des anderen Moduls festlegt. Es sollte außerdem eine Standardimplementierung des Callbacks `init/1` bereitstellen. Die Standardimplementierung von `init/1` sollte die übergebenen Optionen unverändert zurückgeben.

```elixir
defmodule MyCustomAnimation do
  use DancingDots.Animation
end

MyCustomAnimation.init(some_option: true)
# => {:ok, [some_option: true]}
```

## 3. Implementiere die Animation `Flicker`

Nutze das Verhalten `Animation`, um eine flackernde Animation zu implementieren.

Sie sollte den Standard-Callback `init/1` verwenden, weil sie keine Optionen entgegennimmt.

Implementiere den Callback `handle_frame/3`, der einen einzelnen Frame verarbeitet. Wenn die Frame-Nummer ein Vielfaches von vier ist, sollte die Funktion den Punkt mit der Hälfte seiner ursprünglichen Deckkraft zurückgeben. In allen anderen Frames sollte sie den Punkt unverändert zurückgeben.

Die Frames werden ab `1` gezählt. Der an `handle_frame/3` übergebene Punkt ist immer der Punkt in seinem ursprünglichen Zustand, nicht in dem Zustand aus dem vorherigen Frame.

```elixir
dot = %DancingDots.Dot{x: 100, y: 100, radius: 24, opacity: 1}

DancingDots.Flicker.handle_frame(dot, 1, [])
# => %DancingDots.Dot{opacity: 1, radius: 24, x: 100, y: 100}

DancingDots.Flicker.handle_frame(dot, 4, [])
# => %DancingDots.Dot{opacity: 0.5, radius: 24, x: 100, y: 100}
```

## 4. Implementiere die Animation `Zoom`

Nutze das Verhalten `Animation`, um eine zoomeinde Animation zu implementieren.

Diese Animation nimmt eine Option entgegen: die Geschwindigkeit. Die Geschwindigkeit kann eine beliebige Zahl sein. Ist sie negativ, wird der Punkt herausgezoomt statt hineingezoomt.

Implementiere den Callback `init/1`. Er sollte prüfen, dass die übergebenen Optionen eine Keyword-Liste mit dem Schlüssel `:velocity` sind. Der Wert der Geschwindigkeit muss eine Zahl sein. Wenn er keine Zahl ist, gib den Fehler `"The :velocity option is required, and its value must be a number. Got: #{inspect(velocity)}"` zurück.

Implementiere den Callback `handle_frame/3`. Er sollte den Punkt mit einem Radius zurückgeben, der um die aktuelle Frame-Nummer minus eins, multipliziert mit der Geschwindigkeit, vergrößert wurde.

Die Frames werden ab `1` gezählt. Der an `handle_frame/3` übergebene Punkt ist immer der Punkt in seinem ursprünglichen Zustand, nicht in dem Zustand aus dem vorherigen Frame.

```elixir
DancingDots.Zoom.init(velocity: nil)
# => {:error, "The :velocity option is required, and its value must be a number. Got: nil"}

dot = %DancingDots.Dot{x: 100, y: 100, radius: 24, opacity: 1}

DancingDots.Zoom.handle_frame(dot, 1, velocity: 10)
# => %DancingDots.Dot{radius: 24, opacity: 1, x: 100, y: 100}

DancingDots.Zoom.handle_frame(dot, 2, velocity: 10)
# => %DancingDots.Dot{radius: 34, opacity: 1, x: 100, y: 100}
```
