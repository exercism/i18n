# Hinweise

## Allgemein

- Alle Erweiterungsmethoden müssen mit `static` gekennzeichnet werden.
- Alle Erweiterungsmethoden müssen `this` vor dem ersten Argument haben

## 1. Implementiere die Erweiterungsmethode SubstringAfter

- Verschiedene Möglichkeiten, in einem String nach Text zu suchen, werden in [diesem Tutorial][tutorial-csharp.net-strings] vorgestellt.

## 2. Implementiere die Erweiterungsmethode SubstringBetween

- Verschiedene Möglichkeiten, in einem String nach Text zu suchen, werden in [diesem Tutorial][tutorial-csharp.net-strings] vorgestellt.

## 3. Zerlege eine Nachricht in einem Log

- Hier kannst du die Erweiterungsmethode `SubstringAfter()` wiederverwenden.

## 4. Zerlege das Log-Level in einem Log

- Hier kannst du die Erweiterungsmethode `SubstringBetween()` wiederverwenden.
