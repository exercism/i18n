# Anweisungen

Bestimme für zwei beliebige Listen `A` und `B`, ob:

- Liste `A` gleich Liste `B` ist; oder
- Liste `A` die Liste `B` enthält (`A` ist eine Oberliste von `B`); oder
- Liste `A` in Liste `B` enthalten ist (`A` ist eine Unterliste von `B`); oder
- nichts davon zutrifft, die Listen `A` und `B` also ungleich sind

Genauer gesagt: Liste `A` ist gleich Liste `B`, wenn beide Listen dieselben Werte in derselben Reihenfolge enthalten.
Liste `A` ist eine Oberliste von `B`, wenn `A` eine Teilfolge von Werten enthält, die gleich `B` ist.
Liste `A` ist eine Unterliste von `B`, wenn `B` eine Teilfolge von Werten enthält, die gleich `A` ist.

Beispiele:

- Wenn `A = []` und `B = []` (beide Listen sind leer), dann sind `A` und `B` gleich
- Wenn `A = [1, 2, 3]` und `B = []`, dann ist `A` eine Oberliste von `B`
- Wenn `A = []` und `B = [1, 2, 3]`, dann ist `A` eine Unterliste von `B`
- Wenn `A = [1, 2, 3]` und `B = [1, 2, 3, 4, 5]`, dann ist `A` eine Unterliste von `B`
- Wenn `A = [3, 4, 5]` und `B = [1, 2, 3, 4, 5]`, dann ist `A` eine Unterliste von `B`
- Wenn `A = [3, 4]` und `B = [1, 2, 3, 4, 5]`, dann ist `A` eine Unterliste von `B`
- Wenn `A = [1, 2, 3]` und `B = [1, 2, 3]`, dann sind `A` und `B` gleich
- Wenn `A = [1, 2, 3, 4, 5]` und `B = [2, 3, 4]`, dann ist `A` eine Oberliste von `B`
- Wenn `A = [1, 2, 4]` und `B = [1, 2, 3, 4, 5]`, dann sind `A` und `B` ungleich
- Wenn `A = [1, 2, 3]` und `B = [1, 3, 2]`, dann sind `A` und `B` ungleich
