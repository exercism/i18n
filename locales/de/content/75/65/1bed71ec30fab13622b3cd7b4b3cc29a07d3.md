# Entry-API

Die Entry-API ist oft die idiomatischste Art, den Inhalt einer Map-Struktur zu bearbeiten. Für Rust ist es jedoch ungewöhnlich, dass sie nicht in einem Trait formalisiert wurde; sie ist einfach eine Sammlung von Typen und Methoden, die auf den Map-Typen der Standardbibliothek implementiert sind.

Im Kern liefert die Methode `map.entry()` ein `enum`:

```rust
enum Entry {
    Occupied(_),
    Vacant(_),
}
```

Der Nutzen kommt aus weiteren Methoden, die auf diesem Enum implementiert sind. Wenn du zum Beispiel den Wert für einen bestimmten Schlüssel abrufen und möglicherweise ändern möchtest und der Standardwert des Werttyps passt, kannst du einfach Folgendes schreiben:

```rust
// `entry` has type `&mut Value` for the value type of the map
let entry = map.entry(key).or_default();
```

Für Anwendungen wie einen Zähler ist das sehr praktisch:

```rust
let counts: HashMap<_, usize> = HashMap::new();
for item in sequence {
    *counts.entry(item).or_default() += 1;
}
```

Falls der Standardwert des Typs für deine Anwendung nicht passt, kannst du mit `or_insert` einen eigenen konstanten Standardwert angeben oder mit `or_insert_with` einen berechnen.

In bestimmten Fällen möchtest du vielleicht eine Berechnung an einem vorhandenen Wert durchführen, bevor mögliche Einfügungen stattfinden. In diesen Fällen erlaubt `and_modify` das. Diese Anwendung ist jedoch etwas selten. Häufiger wird `and_modify` verwendet, um das Dereferenzieren zu vermeiden:

```rust
map.entry(key).and_modify(|v| *v += 1).or_default();
```

Gelegentlich ist es wünschenswert, den Entry direkt zu matchen. Das ist zulässig:

```rust
match map.entry(key) {
    Entry::Occupied(occupied) => println!("removed from the map: {:?}", occupied.remove_entry()),
    Entry::Vacant(vacant) => println!("key not present in map: {:?}", vacant.key()),
}
```

Weitere Informationen findest du unter [`std::collections::hash_map::Entry`](https://doc.rust-lang.org/std/collections/hash_map/enum.Entry.html) und [`std::collections::btree_map::Entry`](https://doc.rust-lang.org/std/collections/btree_map/enum.Entry.html).
