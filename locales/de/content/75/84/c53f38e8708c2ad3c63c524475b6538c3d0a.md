# Anweisungen

Conda Airlines ist die größte Fluggesellschaft der Programmierwelt und hat über 10.000 Flüge pro Tag!

Momentan verteilen sie alle Sitze noch von Hand an die Passagiere; das muss automatisiert werden.

Sie haben _dich_ gebeten, eine Software zu entwickeln, die die Sitzplatzvergabe automatisch übernimmt.
Deine Software soll speichereffizient und leistungsfähig sein.

## 1. Sitzbuchstaben erzeugen

Conda möchte Sitzbuchstaben für ihre Flugzeuge erzeugen.
Ein Flugzeug besteht aus Sitzreihen.
Jede Reihe hat _4 Sitze_.
Die Sitze in jeder Reihe heißen immer `A`, `B`, `C` und `D`.
Der erste Sitz in der Reihe ist `A`, der zweite Sitz in der Reihe ist `B` und so weiter.
Nach `D` beginnt es wieder mit `A`.

Implementiere eine Funktion `generate_seat_letters(<number>)`, die ein `int` entgegennimmt, das angibt, wie viele Sitzbuchstaben erzeugt werden sollen.
Die Funktion soll dann ein _Iterable_ von Sitzbuchstaben zurückgeben.

```python
>>> letters = generate_seat_letters(4)
>>> next(letters)
"A"
>>> next(letters)
"B"
```

## 2. Sitze erzeugen

Conda möchte ein System, das eine bestimmte Anzahl von Sitzen für ihre Flugzeuge erzeugen kann.
Jedes Flugzeug hat _4 Sitze_ pro Reihe.
Die Reihen werden mit Zahlen nummeriert, beginnend bei `1` und aufsteigend.
Die Sitze sollen in dieser Reihenfolge angeordnet sein: `1A`, `1B`, `1C`, `1D`, `2A`, `2B`, `2C`, `2D`, `3A`, `3B`, `3C`, `3D`, ...

Hier ein Beispiel:

|      x      |  1  |  2  |
| :---------: | :-: | :-: |
|    Reihe    |  5  | 21  |
| Sitzbuchstabe |  A  |  D  |
|  Ergebnis   | 5A  | 21D |

Viele Fluggesellschaften haben wegen des Aberglaubens ihrer Passagiere keine _Reihe_ 13 auf ihren Flügen.
Conda Airlines hält sich ebenfalls an diese Konvention, also stelle sicher, dass du für _Reihe_ 13 _keine_ Sitze erzeugst.

Implementiere eine Funktion `generate_seats(<number>)`, die ein `int` entgegennimmt, das angibt, wie viele Sitze erzeugt werden sollen.
Die Funktion soll dann ein _Iterable_ der angegebenen Sitze zurückgeben.

```python
>>> seats = generate_seats(10)
>>> next(seats)
"1A"
>>> next(seats)
"1B"
```

## 3. Sitze an Passagiere vergeben

Jetzt, wo du eine Funktion hast, die Sitze erzeugt, kannst du damit Sitze an Passagiere vergeben.

Implementiere eine Funktion `assign_seats(<passengers>)`, die eine `list` mit Passagiernamen entgegennimmt.
Die Funktion soll dann ein _Wörterbuch_ zurückgeben, in dem `passenger` der _Schlüssel_ und `seat_number` der _Wert_ ist.

```python
>>> passengers = ['Jerimiah', 'Eric', 'Bethany', 'Byte', 'SqueekyBoots', 'Bob']

>>> assign_seats(passengers)
{'Jerimiah': '1A', 'Eric': '1B', 'Bethany': '1C', 'Byte': '1D', 'SqueekyBoots': '2A', 'Bob': '2B'}
```

## 4. Ticketcodes

Conda Airlines möchte für jedes Ticket einen eindeutigen Code haben.
Da sie eine große Fluggesellschaft sind, haben sie viele Flüge.
Das bedeutet, dass es mehrere Flüge mit derselben Sitznummer gibt.
Sie möchten, dass du ein System entwickelst, das ein eindeutiges Ticket als _12_ Zeichen langen String erzeugt.

Dieser Code beginnt mit dem `assigned_seat`, gefolgt von der `flight_id`.
Der Rest des Codes wird mit `0s` aufgefüllt.

Implementiere eine Funktion `generate_codes(<seat_numbers>, <flight_id>)`, die eine `list` mit `seat_numbers` und einen `string` mit der Flugnummer entgegennimmt.
Die Funktion soll dann einen `generator` zurückgeben, der eine `ticket_number` liefert.

```python
>>> seat_numbers = ['1A', '17D']
>>> flight_id = 'CO1234'
>>> ticket_ids = generate_codes(seat_numbers, flight_id)

>>> next(ticket_ids)
'1ACO12340000'
>>> next(ticket_ids)
'17DCO1234000'
```
