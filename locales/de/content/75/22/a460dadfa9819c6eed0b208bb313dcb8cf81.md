# Zusätzliche Anweisungen

## Implementierung

In Racket verwendet diese Übung sortierte [Vektoren][vectors] statt Listen, weil Vektoren einen Zugriff auf ihre Elemente in konstanter Zeit ermöglichen.
Wie in mehreren anderen Lisp-Tracks gilt: Wenn ein Element nicht im Vektor enthalten ist, wird erwartet, dass das [boolesche Literal `#f`][booleans] zurückgegeben wird, statt eine Ausnahme auszulösen.

[vectors]: https://docs.racket-lang.org/guide/vectors.html
[booleans]: https://docs.racket-lang.org/reference/booleans.html
