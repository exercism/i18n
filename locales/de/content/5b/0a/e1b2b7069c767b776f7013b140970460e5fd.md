# Über

In Haxe ist eine `class` die primäre Datenstruktur, die Daten (Felder) und Verhalten (Methoden) kapselt. Felder und Methoden werden auch als Member einer Klasse bezeichnet.

Der Zugriff auf die Member lässt sich mit [Zugriffsmodifikatoren][visibility] einschränken, nämlich:

- `public`: Auf den Member kann von überall zugegriffen werden.
- `private`: Auf den Member kann nur innerhalb derselben Klasse zugegriffen werden.

Klassen kann man sich als Vorlagen für die Erstellung von Instanzen vorstellen. Um eine [Instanz][class-instance] zu erzeugen, verwendest du einfach das Schlüsselwort `new`:

```haxe
class Car {
  public function new() {}
}

var myCar = new Car();
var yourCar = new Car();
```

Um ein Feld zu definieren, verwendest du einen Zugriffsmodifikator, gefolgt vom Variablennamen und Typ:

```haxe
class Car {
  public var weight:Int; // Accessable by anyone

  private var color:String; // Accessable only within this class
}
```

Du kannst beim Definieren eines Feldes auch einen Anfangswert festlegen. Gibst du für ein Feld keinen Anfangswert an, bekommt es den Wert `null`. Auf ein Feld greifst du mit der Punktnotation zu:

```haxe
class Car {
  public var weight:Int = 2500; // Weight will be set to 2500
  public var year:Int; // year will be null

  public function new() {}
}

var newCar = new Car();
newCar.weight; // 2500
newCar.year; // null

// Update value of field
newCar.year = 2020;
```
