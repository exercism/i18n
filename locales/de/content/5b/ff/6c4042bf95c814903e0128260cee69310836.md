# Einführung

## Konstanten und Funktionen

Ein konstanter Wert wird mit `name = expression` definiert,
wobei in Elm alles außer Definitionen Ausdrücke sind.

```elm
five = 5

six = 3 + 3
```

Funktionen werden mit `name parameters... = expression` definiert,
wobei die Parameter nur durch Leerzeichen getrennt werden.

```elm
add number1 number2 = number1 + number2
```

Der Aufruf einer Funktion ist ebenfalls ein Ausdruck. Du gibst dabei ihren Namen an
und übergibst Argumente für jeden Parameter der Funktion,
durch Leerzeichen getrennt, genau wie bei der Definition einer Funktion.

```elm
five = add 2 3
```

Mit runden Klammern kannst du die Reihenfolge festlegen, in der ein Ausdruck ausgewertet wird.

```elm
six = add 2 (1 * 4)

twelve = add 2 1 * 4
```

## Einrückung / signifikante Leerzeichen

Elm verwendet keine syntaktischen Marker wie geschweifte Klammern, runde Klammern oder Semikolons, um Codegrenzen festzulegen. Stattdessen nutzt es Leerzeichen und Einrückungen.

- Modul-, Import- und Funktionsdefinitionen auf oberster Ebene müssen in der am weitesten links liegenden Spalte beginnen.
- Wenn ein Ausdruck auf mehrere Zeilen aufgeteilt wird, muss der Code, der zu diesem Ausdruck gehört, unter dem Ausdruck mit mindestens einem Leerzeichen eingerückt werden.
- Teile des Ausdrucks, die zusammengehören, sollten mit der gleichen Anzahl an Leerzeichen eingerückt werden.

```elm
-- A function split over multiple lines, so subsequent lines must be indented
add number1 number2 =
    number1 + number2
```

https://elmprogramming.com/indentation.html

## Module

Jede Datei in Elm ist ein Modul und muss eine `module`-Anweisung vor allem anderen Code enthalten.
Modulnamen müssen mit ihrem Dateinamen übereinstimmen, das Modul `Calculator` muss also in der Datei Calculator.elm liegen.
Alles, was innerhalb eines Moduls definiert wird, ist privat auf dieses Modul beschränkt
und von außerhalb nicht zugänglich, es sei denn, es ist in `exposing` aufgeführt.

```elm
-- Define the Calculator module, and expose the `add` function
module Calculator exposing (add)

six = 3 + 3

add number1 number2 = number1 + number2
```

```elm
-- Define the Calculator module, and expose everything within: `six` and `add`
module Calculator exposing (..)

six = 3 + 3

add number1 number2 = number1 + number2
```

https://elm-lang.org/docs/syntax#modules

## Kommentare

Ein Kommentar ist ein Text innerhalb einer Elm-Datei, der nicht als Code interpretiert wird.
Er ist in erster Linie dafür gedacht, dass du und andere Programmierer ihn lesen.
Für einzeilige Kommentare gibt es eine leichtgewichtige Syntax auf Basis von doppelten Bindestrichen.
Mehrzeilige Kommentare sind mit dem Paar `{-` und `-}` aus öffnendem und schließendem Begrenzer ebenfalls möglich.

```elm
-- a single line comment
-- another single line comment

{- a multiline comment
   spawning multiple lines
-}
```
