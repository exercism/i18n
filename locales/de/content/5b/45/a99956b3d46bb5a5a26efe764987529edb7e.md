# Einführung

Factor bildet Datums- und Zeitangaben mit dem Vokabular [`calendar`][calendar] ab. Ein Zeitpunkt ist ein `timestamp`, eine Zeitspanne eine `duration`.

## Ein Datum erstellen

`<date>` (in [`calendar`][calendar]) erzeugt einen `timestamp` für Mitternacht am angegebenen Tag:

```
<date> ( year month day -- timestamp )
```

```factor
USING: calendar ;

1904 11 16 <date> .
! a timestamp at midnight on 1904-11-16
```

`>date<` zerlegt einen Zeitstempel wieder in seine Bestandteile:

```
>date< ( timestamp -- year month day )
```

```factor
1904 11 16 <date> >date< .   ! => 16   (with 1904 and 11 below it)
```

## Ein Datum untersuchen

`day-of-week` gibt den Wochentag als Ganzzahl zurück: `0` für Sonntag bis `6` für Samstag. `day-names` (in [`calendar.english`][english]) ist die passende Liste der Namen, sodass `day-names nth` die Zahl in ein Wort umwandelt:

```factor
USING: calendar calendar.english sequences ;

2024 1 8 <date> day-of-week .          ! => 1
day-names .   ! { "Sunday" "Monday" ... "Saturday" } — Sunday first
```

`leap-year?` akzeptiert ein Jahr (oder einen Zeitstempel), und `days-in-month` gibt die Länge des Monats eines Zeitstempels zurück und berücksichtigt dabei bereits Schaltjahre:

```
leap-year?    ( obj -- ? )
days-in-month ( timestamp -- n )
```

```factor
2024 leap-year? .                ! => t
2024 2 1 <date> days-in-month .  ! => 29
```

## Rechnen mit Datumsangaben

Wörter wie `days`, `weeks` und `hours` erzeugen eine `duration`, und `time+` verschiebt einen Zeitstempel um eine solche:

```
days  ( x -- duration )
time+ ( timestamp duration -- timestamp )
```

```factor
2024 2 28 <date> 1 days time+ >date< .
! => 29   (2024-02-29, with 2024 and 2 below it)
```

Die Arithmetik rechnet korrekt über Monats- und Jahresgrenzen hinweg, und zwei Zeitstempel, die denselben Zeitpunkt bezeichnen, sind mit `=` gleich.

## Uhrzeiten

`<timestamp>` erzeugt einen vollständigen Zeitstempel, genau bis auf die Sekunde. Sein letztes Argument ist der Versatz von UTC; `instant` (eine `duration` von null) hält den Zeitstempel bei UTC:

```
<timestamp> ( year month day hour minute second gmt-offset -- timestamp )
```

```factor
USING: calendar ;

1969 7 21 2 56 15 instant <timestamp> .
! a timestamp at 02:56:15 on 1969-07-21
```

`>time<` ist das Gegenstück zu `>date<` und zerlegt einen Zeitstempel in Stunde, Minute und Sekunde:

```
>time< ( timestamp -- hour minute second )
```

```factor
1969 7 21 2 56 15 instant <timestamp> >time< .   ! => 15   (with 2 and 56 below it)
```

`seconds` und `minutes` erzeugen ebenso wie `days`, `weeks` und `hours` eine `duration`, die man an `time+` übergeben kann:

```
seconds ( x -- duration )
minutes ( x -- duration )
```

Die einzelnen Felder eines Zeitstempels liest man mit den Zugriffswörtern `year>>`, `month>>`, `day>>`, `hour>>`, `minute>>` und `second>>`:

```factor
1969 7 21 2 56 15 instant <timestamp> hour>> .   ! => 2
```
