# Anleitung

In dieser Übung simulierst du ein fensterbasiertes Computersystem.
Du erstellst einige Fenster, die verschoben und in ihrer Größe geändert werden können.
Das folgende Bild veranschaulicht die Werte, mit denen du unten arbeiten wirst.

```text

 ║                 ^      *──────────────────────┐            ║
 ║                 |      │        title         │            ║
 ║                 |      ├──────────────────────┤            ║
 ║                 |      │                      │            ║
```

## 1. Definiere die Eigenschaften des Programmfensters

Definiere mit dem vorgegebenen Klassengerüst die Eigenschaften für die Werte `y`, `x`, `height` und `width`.

```php
<?php

$window = new ProgramWindow();
$window->y; // => null
$window->x; // => null
$window->height; // => null
$window->width; // => null
```

## 2. Definiere die Anfangswerte für das Programmfenster

Definiere eine Konstruktorfunktion für `ProgramWindow`.
Sie sollte keine Argumente entgegennehmen, aber während der Ausführung des Konstruktors die Standardwerte für ihre Eigenschaften setzen.
Sie sollte die anfänglichen Werte für `y` und `x` auf `0` setzen.
Sie sollte die anfängliche `height` und `width` auf eine Bildschirmgröße von `600x800` setzen.

```php
<?php

$window = new ProgramWindow();
$window->y; // => 0 
$window->x; // => 0
$window->height; // => 600
$window->width; // => 800
```

## 3. Definiere eine Funktion zum Ändern der Fenstergröße

Definiere in `Size.php` eine neue Klasse für eine Size-Klasse.
Ihre Konstruktorargumente sollten die Eigenschaften `height` und `width` setzen.
Außerdem braucht `ProgramWindow` eine resize-Funktion, die die Instanz des `Size`-Objekts entgegennimmt und die eigenen Eigenschaften aktualisiert.

```php
<?php 

$window = new ProgramWindow();
$size = new Size(764, 1080);
$window->resize($size)

$window->height;
// => 764
$window->width;
// => 1080
```

## 4. Definiere eine Funktion zum Verschieben des Fensters

Definiere in `Position.php` eine neue Klasse für eine Position-Klasse.
Ihre Konstruktorargumente sollten die Eigenschaften `y` und `x` setzen.
Außerdem braucht `ProgramWindow` eine move-Funktion, die die Instanz des `Position`-Objekts entgegennimmt und die eigenen Eigenschaften aktualisiert.

```php
<?php 

$window = new ProgramWindow();
$position = new Position(80, 313);
$window->move($position)

$window->y;
// => 80
$window->x;
// => 313
```
