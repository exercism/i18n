# Einführung

PowerShell ist eine dynamische und implizit typisierte Skriptsprache von Microsoft (_unterstützt aber auch [stark typisierte][strong typed] Variablen_), die sich vor allem auf Aufgabenautomatisierung und Konfigurationsverwaltung konzentriert.

PowerShell unterstützt imperative, funktionale, objektorientierte und sogar Programmierung im Pipeline-Stil.

PowerShell basiert auf der .NET-Plattform und wurde erstmals 2006 veröffentlicht.
Es ist standardmäßig in allen modernen Windows-Betriebssystemen enthalten und kann auch auf Mac und Linux installiert werden.


## Variablen

Es gibt zwei gängige Arten, eine Variable in PowerShell zu definieren.

Variablennamen in PowerShell müssen mit einem `$` beginnen und verwenden den Zuweisungsoperator `=`, um den Variablennamen an einen Wert zu binden.

```powershell
> $intVar = 1
> $doubleVar = 2.0
> $stringVar = "Hello"

# Checking a variable type using the GetType() method
> Write-Host $doubleVar.GetType()
System.Double
```

Du kannst den Typ einer Variablen auch explizit angeben, wenn du erzwingen möchtest, dass der Wert einen bestimmten Typ hat.
PowerShell versucht nach Kräften, den Wert von einem Typ in einen anderen umzuwandeln, wenn das möglich ist.

```powershell
# String represents a floating number can be converted to integer
> [int]$staticOne = "1.234"
> $staticOne
1

# String of letters can not be converted to double type
> [double]$staticTwo = "hello"
MetadataError: Cannot convert value "hello" to type "System.Double"
```


### Konstanten

Konstanten in PowerShell sind Variablen, die nach der Definition weder **geändert** noch **entfernt** werden können.
Das bringt uns zur zweiten Art, Variablen zu definieren: mit dem Cmdlet `New-Variable`.

```powershell
> New-Variable -Name "MyConstant" -Value 100 -Option Constant
> $MyConstant
```

Für ausführlichere und fortgeschrittenere Möglichkeiten, eine neue Variable zu erstellen, lies bitte [New-Variable][New-Variable].


## Funktionen

[Funktionen][functions] in PowerShell werden mit dem Schlüsselwort `function` definiert.
Jede Funktion kann null oder mehr formale Parameter in den runden Klammern `()` haben, gefolgt vom Gültigkeitsbereich der Funktion, der mit `{` beginnt und mit `}` endet.

```powershell
function Greeting {
    return "Hello!"
}
```

Funktionen in PowerShell können Werte explizit über das Schlüsselwort `return` zurückgeben, nachdem sie mit der Syntax `FuncName $Arg` aufgerufen wurden.

```powershell
function AddTwoNumbers($NumOne, $NumTwo):
    $result = $NumOne + $NumTwo
    return $result

> AddTwoNumbers 10 20
30
```

Ein fortgeschrittener Blick darauf, wie du eine ausführliche Funktionsdefinition schreibst und wie Funktionen Werte implizit zurückgeben können, wird im Konzeptmodul `Functions` behandelt.


## Kommentare

Einzelkommentare in PowerShell beginnen mit einem `#` und enden am Zeilenende.
Kommentarblöcke in PowerShell beginnen mit `<#` und enden mit `#>`.
Ein fortgeschrittenes Beispiel für einen Kommentarblock zur Erstellung von Comment-Based Help wird im Konzeptmodul `Functions` behandelt.

```powershell
function Main() {
    #This is a comment
    <#
    And this is a comment block
    that can span multiple lines
    #>
}
```
