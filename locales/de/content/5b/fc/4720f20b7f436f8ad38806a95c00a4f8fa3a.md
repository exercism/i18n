# Einführung

Funktionen sind in Python First-Class-Objekte. Das bedeutet, dass sie auch als Argumente an andere Funktionen übergeben werden können.
Dekoratoren sind [Funktionen höherer Ordnung][hofunc], die eine andere Funktion als Argument entgegennehmen und sie zurückgeben, nachdem sie deren Verhalten erweitert oder geändert haben.
Dekoratoren werden genauso definiert wie jede andere Funktion, aber sie werden in der Zeile über den Funktionen, die sie dekorieren, mit dem `@`-Symbol vor ihren Namen angewendet (`@my_decorator`). Dekoratoren können zwar mehrere Argumente entgegennehmen, müssen aber _mindestens_ die Funktion, die sie dekorieren, als Argument entgegennehmen.

[hofunc]:https://en.wikipedia.org/wiki/Higher-order_function
