# Anleitung

Der neue Flughafen in Berlin hat Entwickler für sein Roboterlabor eingestellt, und du fängst dort deinen Job an.
Sie haben klobige, etwas humanoid aussehende Roboter, mit denen sie den Kundenservice verbessern wollen.

Die erste Aufgabe bei deiner Arbeit ist es, ein Programm zu schreiben, damit der Roboter Menschen in ihrer Muttersprache begrüßen kann, nachdem sie ihre Pässe am Self-Check-in-Schalter gescannt haben.

Der Roboter ist stolz auf seine Fähigkeiten, deshalb sagt er immer zuerst, welche Sprache er spricht, und begrüßt dann die Person.
Wenn zum Beispiel jemand einen deutschen Pass scannt, sagt der Roboter:

```txt
I can speak German: Hallo Dietrich!
```

## 1. Erstelle die abstrakte Begrüßungsfunktionalität

Den Code für die verschiedenen Sprachen wirst du nicht selbst schreiben, also musst du deinen Code für den Roboter so strukturieren, dass andere Entwickler später leicht weitere Sprachen hinzufügen können.

Definiere als ersten Schritt ein Interface `Greeter` mit zwei Methoden.

- `LanguageName`, die den Namen der Sprache (einen `string`) zurückgibt, in der der Roboter den Besucher begrüßen soll.
- `Greet`, die den Namen eines Besuchers (einen `string`) entgegennimmt und einen `string` mit der Begrüßungsnachricht in einer bestimmten Sprache zurückgibt.

Implementiere als Nächstes eine Funktion `SayHello`, die den Namen des Besuchers und alles, was das Interface `Greeter` implementiert, als Argumente entgegennimmt und den gewünschten Begrüßungsstring zurückgibt.
Stell dir zum Beispiel eine deutsche `Greeter`-Implementierung vor, bei der `LanguageName` `"German"` zurückgibt und `Greet` `"Hallo {name}!"` zurückgibt:

```go
SayHello("Dietrich", germanGreeter)
// => "I can speak German: Hallo Dietrich!"
```

## 2. Implementiere Italienisch

Jetzt ist es deine Aufgabe, den Roboter für Menschen zum Laufen zu bringen, die italienische Pässe scannen.

Erstelle dazu ein Struct `Italian` und implementiere die beiden Methoden, die nötig sind, damit das Struct das Interface `Greeter` erfüllt, das du in Aufgabe 1 angelegt hast.
Mit `"Ciao {name}!"` kannst du jemanden auf Italienisch begrüßen.

## 3. Implementiere Portugiesisch

Bevor du Feierabend machst, sollst du außerdem die Funktionalität fertigstellen, um Menschen auf Portugiesisch zu begrüßen.

Erstelle dazu ein Struct `Portuguese` und implementiere auch hier die beiden Methoden, die nötig sind, damit das Struct das Interface `Greeter` erfüllt.
Mit `"Olá {name}!"` kannst du jemanden auf Portugiesisch begrüßen.
