# Einführung

Factor ist eine *verkettende* Sprache: Jedes Wort liest seine Eingaben von einem gemeinsamen **Datenstapel** und legt seine Ausgaben wieder darauf ab. Es gibt keinen anderen Weg, Werte weiterzugeben.

Wenn du ein Literal schreibst, wird es oben auf den Stapel gelegt; Code wird von links nach rechts gelesen:

```factor
1 2 3    ! stack (bottom → top): 1 2 3
```

Eine Deklaration des *Stapeleffekts* dokumentiert den Vertrag eines Worts:

```factor
: restow ( a b -- b a ) swap ;
```

`( a b -- b a )` besagt, dass das Wort zwei Werte vom Stapel nimmt und zwei in der anderen Reihenfolge zurücklässt. Die Namen dienen nur der Dokumentation (der Compiler prüft lediglich die *Anzahl* der Eingaben und Ausgaben), und der Name ganz rechts bezeichnet das oberste Element des Stapels.

Die alltäglichen **Shuffle-Wörter** aus `kernel` ordnen den oberen Teil des Stapels um:

```
dup  ( x   -- x x   )
drop ( x   --       )
swap ( x y -- y x   )
over ( x y -- x y x )
nip  ( x y -- y     )
rot  ( x y z -- y z x )
```

Wörter werden mit `:` definiert und enden mit `;`; eine Definition, deren Code nicht zu dem deklarierten Effekt passt, lehnt der Compiler ab.
