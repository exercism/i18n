# Einführung

Dynamischer Speicher wird durch Bibliotheksfunktionen bereitgestellt, mit denen du zur Laufzeit Speicher reservieren und wieder freigeben kannst.
Da du die Reservierung und Freigabe des Speichers steuerst, ist dynamischer Speicher genau so sicher, wie du vor menschlichen Fehlern gefeit bist.
Aus diesem Grund ist dynamischer Speicher eine der größten Quellen für Programmierfehler und ein beliebtes Ziel für Hackerangriffe.

## malloc

`malloc` ist eine Funktion, die in `stdlib.h` deklariert ist und mit der du dynamischen Speicher reservierst.
Wenn die Reservierung erfolgreich ist, wird ein Zeiger zurückgegeben, der auf die Adresse des ersten Bytes des reservierten Speichers zeigt.
Wenn die Reservierung nicht erfolgreich ist, wird `NULL` zurückgegeben.
Es ist ratsam, das Ergebnis von `malloc` auf `NULL` zu prüfen und den Fehlerfall sauber zu behandeln.
Der zurückgegebene Zeiger hat den Typ `pointer-to-void`, den man grob als „generischen“ Zeiger betrachten kann, der sich in den konkreten Typ umwandeln lässt, den der Speicher verwendet.
`malloc` hat einen Parameter, nämlich die Größe des gewünschten Speichers in Bytes.
Die Gesamtgröße für die Reservierung eines Arrays ist die Größe des Datentyps jedes Elements multipliziert mit der Anzahl der Elemente.
Der Operator `sizeof` wird üblicherweise verwendet, um die Größe des Datentyps jedes Elements zu ermitteln.
Das folgende Beispiel zeigt das

```c
#include <stdio.h>
#include <stdlib.h>

int * my_function(int count) {
    // pointer-to-void from malloc is converted to a pointer-to-int
    int * numbers = malloc(sizeof(int) * count);
    return numbers;
}

int main() {
    int * numbers = my_function(3);
    if (!numbers) return -1;
    // printed The size of numbers is 8 bytes (can vary by system)
    printf("The size of numbers is %zu bytes\n", sizeof(numbers));
    numbers[0] = 1;
    numbers[1] = 2;
    numbers[2] = 3;
    // prints The first element of the array is 1
    printf("The first element of the array is %d\n", numbers[0]);
    // prints The second element of the array is 2
    printf("The second element of the array is %d\n", numbers[1]);
    // prints The third element of the array is 3
    printf("The third element of the array is %d\n", numbers[2]);
    free(numbers);
    numbers = NULL;
}
```

Wichtig zu wissen: Der von `malloc` neu reservierte Speicher ist nicht initialisiert, sondern kann Müllwerte enthalten.
Beachte, dass `sizeof` des Zeigers `numbers` weder die Anzahl der Elemente des Arrays noch die insgesamt reservierte Speichermenge ist.
Die Größe des von `malloc` zurückgegebenen Zeigers ist die Größe jedes beliebigen Zeigers auf diesem System.
Der Beispielcode wurde auf einem 64-Bit-System ausgeführt, daher betrug die Größe des Zeigers 8 Byte (multipliziert mit 8 Bits pro Byte = 64 Bits).
Der Zeigertyp wurde implizit von pointer-to-void in pointer-to-int umgewandelt.
Er hätte auch explizit umgewandelt werden können: `int * numbers = (int *) malloc(sizeof(int) * count);`.
Wenn die Werte definitiv geschrieben werden, bevor sie gelesen werden, kann `malloc` eine effiziente Möglichkeit sein, Speicher zu reservieren.
Wenn jedoch die Möglichkeit besteht, dass die Werte gelesen werden, bevor sie initialisiert wurden, ist `malloc` riskant.
Eine sicherere Möglichkeit, Speicher zu reservieren, ist `calloc`, das den neu reservierten Speicher mit Null initialisiert.

Beachte in den Beispielen oben, dass `free(numbers)` verwendet wurde.

## free

`free` ist eine Funktion, die in `stdlib.h` deklariert ist und mit der du Speicher freigibst, der dynamisch reserviert wurde.
Dynamisch reservierter Speicher bleibt belegt, bis er durch `free` freigegeben wird.
Manche Betriebssysteme geben dynamisch reservierten Speicher möglicherweise automatisch frei, wenn das Programm endet, aber es ist gute Praxis, sich nicht darauf zu verlassen.
`free` hat einen Parameter, nämlich einen Zeiger auf den Speicher, der dynamisch reserviert wurde.
Ein Zeiger, der nach seiner Freigabe nicht auf `NULL` gesetzt wird, wird als hängender Zeiger bezeichnet.
Ein hängender Zeiger kann auf anderen Speicher verweisen als den, für den er gedacht war.
Dadurch kann ein hängender Zeiger zu Datenbeschädigung sowie zum Einschleusen und Ausführen beliebigen Codes führen.
Ein Zeiger auf reservierten Speicher, der nicht durch Setzen auf `NULL` geleert wurde, kann dazu benutzt werden, das Programm zu hacken.
Es ist gute Praxis, einen Zeiger auf `NULL` zu setzen, nachdem er an `free` übergeben wurde.

## calloc

`calloc` ist eine Funktion, die in `stdlib.h` deklariert ist und mit der du dynamischen Speicher reservierst und den neu reservierten Speicher gleichzeitig mit Null initialisierst.
Wenn die Reservierung erfolgreich ist, wird ein Zeiger zurückgegeben, der auf die Adresse des ersten Bytes des reservierten Speichers zeigt.
Wenn die Reservierung nicht erfolgreich ist, wird `NULL` zurückgegeben.
Es ist ratsam, das Ergebnis von `calloc` auf `NULL` zu prüfen und den Fehlerfall sauber zu behandeln.
Der zurückgegebene Zeiger hat den Typ `pointer-to-void`, den man grob als „generischen“ Zeiger betrachten kann, der sich in den konkreten Typ umwandeln lässt, den der Speicher verwendet.
`calloc` hat zwei Parameter.
Der erste Parameter gibt an, wie viele Werte des angegebenen Datentyps reserviert werden sollen.
Der zweite Parameter gibt die Größe des angegebenen Datentyps an, der reserviert werden soll.

Im folgenden Beispiel sollten alle `printf`-Anweisungen immer `0` anzeigen, da `calloc` garantiert die neu reservierten Werte auf Null setzt.

```c
#include <stdio.h>
#include <stdlib.h>

int * my_function(int count) {
    // allocates the amount of bytes in an int, multiplied by count
    int * numbers = calloc(count, sizeof(int));
    return numbers;
}

int main() {
    int * numbers = my_function(3);
    if (!numbers) return -1;
    // prints The first element of the array is 0
    printf("The first element of the array is %d\n", numbers[0]);
    // prints The second element of the array is 0
    printf("The second element of the array is %d\n", numbers[1]);
    // prints The third element of the array is 0
    printf("The third element of the array is %d\n", numbers[2]);
    free(numbers);
    numbers = NULL;
}
```

## realloc

`realloc` ist eine Funktion, die in `stdlib.h` deklariert ist und mit der du bereits reservierten Speicher vergrößern oder verkleinern kannst.
Wenn der Speicher erfolgreich neu reserviert wurde, wird ein Zeiger zurückgegeben, der auf die Adresse des ersten Bytes des neu reservierten Speichers zeigt.
Wenn die Neureservierung fehlschlägt, wird `NULL` zurückgegeben.
Es ist ratsam, das Ergebnis von `realloc` auf `NULL` zu prüfen und den Fehlerfall sauber zu behandeln.
`realloc` hat zwei Parameter.
Der erste Parameter ist ein Zeiger auf den vorhandenen Speicher, der neu reserviert werden soll.
Der zweite Parameter ist die Größe des neu reservierten Speichers in Bytes.
Werte, die gesetzt wurden, bevor der Speicher vergrößert wird, bleiben erhalten.
Wichtig zu wissen: Der Speicher, der beim Vergrößern hinzugefügt wird, ist nicht auf Null initialisiert, und seine Werte können beliebig sein.
Auch der Speicher, der beim Verkleinern entfernt wird, ist nicht initialisiert und kann die Werte noch enthalten.
Das folgende Beispiel zeigt das Vergrößern und Verkleinern eines Arrays

```c
#include <stdio.h>
#include <stdlib.h>

int * my_function(int count) {
    // allocates the amount of bytes in an int, multiplied by count
    int * numbers = calloc(count, sizeof(int));
    return numbers;
}

int * my_function_2 (int * ptr , int count) {
    // reallocates the memory to the size of an int multiplied by count
    int * numbers = realloc(ptr, sizeof(int) * count);
    // if realloc fails, exit the program
    if (!numbers) exit(-1);
    return numbers;
}

int main() {
    int * numbers = my_function(3);
    if (!numbers) return -1;
    numbers[0] = 1;
    numbers[1] = 2;
    numbers[2] = 3;
    // expand the size of the array
    numbers = my_function_2(numbers, 6);
    // prints The first element of the array is 1
    printf("The first element of the array is %d\n", numbers[0]);
    // prints The sixth element of the array is [whatever is there]
    // the additional memory is not initialized, so it could be
    // 0 or it could be 18728 or anything else
    printf("The sixth element of the array is %d\n", numbers[5]);
    numbers[5] = 6;
    // shrink the size of the array
    numbers = my_function_2(numbers, 3);
    // prints The sixth element of the array is [whatever is there]
    // the removed memory is not initialized, so it could be
    // 6 or it could be 43164 or anything else
    printf("The sixth element of the array is %d\n", numbers[5]);
}
```
