# Einführung

Ganzzahlen lassen sich nicht nur als numerische Werte, sondern auch als Bitmuster betrachten. Factors Vokabular [`math`][math] enthält die üblichen Low-Level-Operationen auf diesen Bitmustern, und das Vokabular [`math.bitwise`][bitwise] ergänzt ein paar Helfer für die Arbeit mit Werten fester Breite.

## Bitverschiebungen

`shift ( m n -- m' )` verschiebt die Bits von `m`. Ein *positives* `n` verschiebt nach links (multipliziert bei jedem Schritt mit 2), ein *negatives* `n` verschiebt nach rechts (dividiert bei jedem Schritt durch 2):

```factor
3 2 shift .     ! => 12   (3 << 2)
24 -3 shift .   ! => 3    (24 >> 3)
```

Bei positiven Ganzzahlen verwirft die Verschiebung nach rechts die untersten Bits und füllt mit Nullen auf. Bei *negativen* Ganzzahlen ist Factors `shift` arithmetisch: Es behält das Vorzeichenbit bei und füllt gedanklich von links mit Kopien des Vorzeichenbits auf. (Factors Ganzzahlen haben beliebige Genauigkeit, „links“ reicht also so weit, wie nötig.)

## Bitweise Logik

Die vier grundlegenden logischen Operationen sind:

```
bitor  ( x y -- z )   ! 1 in either operand
bitand ( x y -- z )   ! 1 in both operands
bitxor ( x y -- z )   ! 1 in exactly one operand
bitnot ( x   -- z )   ! flip every bit
bit?   ( x n -- ? )   ! true when bit at position n is set
```

```factor
0b1011 0b0010 bitor .    ! => 11  (0b1011)
0b1011 0b0010 bitand .   ! => 2   (0b0010)
0b1011 0b0010 bitxor .   ! => 9   (0b1001)
0b1011 bitnot .          ! => -12
0b1011 0 bit? .          ! => t   (low bit is set)
0b1011 2 bit? .          ! => f   (bit 2 is clear)
```

`bitnot` von `0b1011` ergibt `-12`, weil Factors Ganzzahlen beliebige Genauigkeit haben: Die Bits von `0b1011` umzudrehen bedeutet gedanklich „lauter Einsen, bei denen die unteren vier zu `0100` umgedreht sind“, und das ergibt als vorzeichenbehaftetes Bignum gelesen `-12`.

## Einen Wert als N Bits behandeln

`bits ( x n -- y )` aus `math.bitwise` maskiert `x` auf seine unteren `n` Bits. Das ist der Factor-Weg, um „einen Wert als N-Bit-Ganzzahl ohne Vorzeichen neu zu interpretieren“:

```factor
-1 8 bits .              ! => 255   (lowest 8 bits of -1 are all 1)
-2144333657 32 bits .    ! => 2150633639
```

Das zweite Beispiel ist für diese Übung wichtig. Wenn du mit einem negativen Int32-Wert im Zweierkomplement beginnst und ihn um `amount` „logisch“ nach rechts verschieben willst (von links mit Nullen auffüllen), lautet das Factor-Idiom:

```
( value -- shifted )
32 bits  amount neg  shift
```

Maskiere zuerst auf 32 Bits, um zur Interpretation ohne Vorzeichen zu wechseln, und verschiebe dann. Da der maskierte Wert nicht negativ ist, verwirft `shift` einfach die unteren Bits und füllt mit Nullen auf.
