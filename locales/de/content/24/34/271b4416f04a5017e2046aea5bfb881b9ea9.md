# Anleitung

Larry ist ein Lisp-Alien, das gern Code schreibt, um Spiele zu spielen. Heute möchte Larry ein paar Funktionen schreiben, die ihm bei einem Spiel helfen, das sehr an Tic-Tac-Toe erinnert.

Wie Tic-Tac-Toe wird dieses Spiel auf einem Spielfeld gespielt, das ein 3x3-Raster ist.

## 1. Von Grund auf beginnen

Zuerst braucht Larry eine Funktion, um ein leeres Spielfeld zu erzeugen, `make-empty-board`. Alle Zellen des Spielfelds sollten `NIL` sein.

```lisp
(make-empty-board) ; => #2A((NIL NIL NIL) (NIL NIL NIL) (NIL NIL NIL))
```

## 2. Ausgehend von einem vorhandenen Spielfeld

Als Nächstes braucht Larry eine Funktion, um ein Spielfeld aus einer Liste von Zeilen zu erzeugen. Zum Beispiel:

```lisp
(make-board-from-list '((A B C) (D E F) (G H I))) ; => #2A((A B C) (D E F) (G H I))
```

## 3. Gewinnbedingung

Wenn drei gleiche Symbole in einer Reihe liegen, hat diese Person gewonnen. Larry braucht dafür eine Funktion, `all-the-same-p`, die bei einem Array aus 3 Elementen zu `T` auswertet, wenn alle Elemente dasselbe Symbol sind. (Mit `eq` kannst du feststellen, ob zwei Symbole gleich sind.)

```lisp
(all-the-same-p #(A A A)) ; => T
(all-the-same-p #(A B C)) ; => NIL
```

## 4. In einer Zeile

Jetzt braucht Larry eine Möglichkeit, die Elemente einer Zeile zu bekommen. Die Funktion `row` nimmt ein Spielfeld und eine Zeilennummer und soll ein Array der Elemente in dieser Zeile zurückgeben.

```lisp
(row #2A((1 2 3) (4 5 6) (7 8 9)) 1) ; => #(4 5 6)
```

## 5. In einer Spalte

Schließlich braucht Larry eine Möglichkeit, die Elemente einer Spalte zu bekommen. Die Funktion `column` nimmt ein Spielfeld und eine Spaltennummer und soll ein Array der Elemente in dieser Spalte zurückgeben.

```lisp
(column #2A((1 2 3) (4 5 6) (7 8 9)) 1) ; => #(2 5 8)
```
