# Zahlen

Crystal hat einen Typ `Number`, der der Basistyp für alle numerischen Typen ist.
Innerhalb des Typs Number gibt es zwei wichtige Untertypen: [`Int`][int] und [`Float`][float].

`Int` ist die Kurzform von integer und steht für ganze Zahlen.
`Int` kann sowohl negativ als auch positiv sein und hat keinen Dezimalpunkt.

```crystal
1.class
# => Int32

-1.class
# => Int32
```

`Float` steht für Zahlen mit einem Dezimalpunkt.
`Float`s können sowohl negativ als auch positiv sein.

```crystal
10.5.class
# => Float64
```

## Umwandlung zwischen `Int` und `Float`

Mit den Methoden `to_i` und `to_f` kannst du zwischen `Int` und `Float` umwandeln.
Bei der Umwandlung von `Float` zu `Int` wird die Zahl abgerundet.

```crystal
1.to_f
# => 1.0

1.0.to_i
# => 1

1.9.to_i
# => 1
```

## Arithmetische Operatoren

Du kannst die [grundlegenden arithmetischen Operatoren][math] auf `Int` und `Float` anwenden.
Die Operatoren sind `+`, `-`, `*`, `/` und `%`.
Bei der Verwendung dieser Operatoren kannst du `Int` und `Float` beliebig mischen.

### Addition, Subtraktion und Multiplikation

Der Operator `+` wird für die Addition verwendet, der Operator `-` für die Subtraktion und der Operator `*` für die Multiplikation.

| Operator | Beispiel       |
| -------- | -------------- |
| `+`      | `4 + 6 => 10`  |
| `-`      | `15 - 10 => 5` |
| `*`      | `2 * 3 => 6`   |

### Division

Mit der Division teilst du Zahlen.
Der Operator `/` wird für die Division verwendet.
Das Ergebnis ist immer ein Float.

```crystal
4 / 2
# => 2.0

4.0 / 2
# => 2.0
```

~~~~exercism/caution
In manchen Programmiersprachen führt eine Division durch null zu einem Fehler.

In Crystal ist das Ergebnis einer Division durch null `Infinity` oder `-Infinity`.
Die einzige Ausnahme ist die Division von null durch null, die `NaN` (Not a Number) ergibt.
`Infinity` und `NaN` sind besondere Werte des Typs `Float`.

```crystal
1 / 0
# => Infinity

-1 / 0
# => -Infinity

0 / 0
# => NaN
```
~~~~

## Ganzzahlige Division

Mit der ganzzahligen Division teilst du Zahlen und erhältst den ganzzahligen Teil des Ergebnisses.
Das Ergebnis wird immer auf einen Int abgerundet.

```crystal
4.0 // 2
# => 2

4.5 // 2
# => 2
```

~~~~exercism/caution
Eine Division durch null bei der ganzzahligen Division führt zu einem `DivisionByZeroError`.
Das unterscheidet sich von der normalen Division.
~~~~

### Modulo

Mit Modulo erhältst du den Rest einer Division.
Der Operator `%` wird für Modulo verwendet.

```crystal
5 % 2
# => 1

5.0 % 2
# => 1.0

5 % 3
# => 2
```

~~~~exercism/caution
Eine Division durch null beim Modulo führt zu einem DivisionByZeroError.
Das unterscheidet sich von der normalen Division.

```crystal
1 % 0
# Error: Unhandled exception: Division by 0 (DivisionByZeroError)
```
~~~~

## Potenzierung

Mit der Potenzierung erhebst du eine Zahl in eine Potenz.
Der Operator `**` wird für die Potenzierung verwendet.
Das Ergebnis einer Operation mit einem `Float` und einem `Int` ist ein `Float`.

```crystal
2 ** 2
# => 4

2.0 ** 2
# => 4.0
```

## Runden

Die Methode `round` nimmt ein optionales Argument: die Anzahl der Nachkommastellen, auf die gerundet werden soll.
Die Standardanzahl der Nachkommastellen ist 0.

```crystal
1.0.round
# => 1

1.5.round
# => 2

1.234.round(2)
# => 1.23
```

### Auf- und Abrunden

Mit den Methoden `ceil` und `floor` kannst du auch auf einen `Int` auf- oder abrunden.
Die Methode `ceil` rundet auf und die Methode `floor` rundet ab.

```crystal
1.0.ceil
# => 1

1.2.ceil
# => 2

1.7.floor
# => 1
```

## Priorität und runde Klammern

Crystal erlaubt runde Klammern (`()`), mit denen du Ausdrücke gruppieren kannst.
Das ist nützlich, wenn du die Reihenfolge der Operationen ändern möchtest.

Wenn du mehrere arithmetische Operatoren verwendest, ist die Reihenfolge der Operationen dieselbe wie in der Mathematik, auch bekannt als [PEMDAS][pemdas].
Sie folgt der Reihenfolge Klammern (`()`), Exponenten (`**`), Multiplikation (`*`) und Division (`/`) sowie Addition (`+`) und Subtraktion (`-`).

```crystal
2 + 3 - 4 * 4
# => -11

(2 + 3 - 4) * 4
# => 4
```
