# Einführung

## Importieren

Swift bietet in seiner Standardbibliothek viele Funktionen, aber du kannst auf viele weitere Möglichkeiten zugreifen, indem du externe Bibliotheken und Frameworks importierst.
Diese Module können direkt aus dem Swift-Projekt stammen (etwa [Swift Argument Parser][argument-parser]), aus Apples Plattform-Frameworks (etwa [Foundation][apple-foundation] und das [Network Framework][network-framework]) oder aus Open-Source-Bibliotheken von Drittanbietern (etwa [SwiftyBeaver][swifty-beaver]).

Kernmodule wie Foundation, eine der am weitesten verbreiteten Bibliotheken in Swift, sind Teil der Swift-Toolchain.
Bibliotheken von Drittanbietern müssen deiner Projektkonfiguration hinzugefügt werden (zum Beispiel mit dem Swift Package Manager), bevor du sie importieren kannst.

Um ein Modul zu importieren, schreibst du das Schlüsselwort `import` gefolgt vom Namen des Moduls.
Foundation importierst du zum Beispiel, indem du Folgendes in dein Programm einfügst:

```swift
import Foundation
```

Wenn du ein Modul importierst, stehen seine Typen, Methoden und Funktionen in deinem Code zur Verfügung.
Wenn du beispielsweise Foundation importierst, wird `String` um nützliche Hilfsmethoden wie `components(separatedBy:)` erweitert.

Nach Konvention stehen `import`-Anweisungen am Anfang einer Swift-Datei, damit jeder, der den Code liest, die Abhängigkeiten sofort sieht.

## String-Indizierung

Auf einzelne Zeichen in einem `String` kannst du mit der Indexschreibweise zugreifen, die du von Arrays kennst.
Die [Indizes][string-indices], die für Strings verwendet werden, sind jedoch _keine_ Ganzzahlen und du kannst nicht direkt mit ihnen arbeiten.
Stattdessen musst du sie ausgehend von einem anderen bekannten Index berechnen, etwa `startIndex`, der auf die Position des ersten Zeichens in einem nicht leeren String zeigt. Dafür nutzt du die Methoden aus den Bibliotheken [`String`][string-docs] und [`NSString`][nsstring-docs] (wenn das Modul `Foundation` importiert ist, haben Strings in Swift Zugriff auf alle Eigenschaften und Methoden von NSString).

Zum Beispiel bei folgendem String:

```swift
let csv = "apple,pear,peach,orange,cherry,lime,goosberry"
```

Du kannst nicht `csv[21]` schreiben, um das „g“ in „orange“ zu bekommen. Stattdessen musst du einen Wert vom Typ `String.Index` berechnen und diesen Index verwenden.
Beachte, dass diese Indizes nicht dafür gedacht sind, von Menschen direkt gelesen zu werden.
Sie werden als _opake Indizes_ bezeichnet, denn Menschen müssen nicht wissen, was in ihnen steckt.

```swift
let index = csv.index(csv.startIndex, offsetBy: 21)
csv[index]
// "g"
print(index)
// prints Index(_rawBits: 1376513)
```

Beachte aber: Wenn der Offset kein gültiger Index ist, also wenn er einen Index vor `startIndex` oder nach `endIndex` ergeben würde, löst die Operation einen Fehler aus und das Programm stürzt ab.
Um das zu verhindern, kannst du einen begrenzenden Index angeben.
Dieser gibt einen optionalen Index zurück und liefert nil für Indizes, die sonst ungültig wären.

```swift
let tooFar = csv.index(csv.startIndex, offsetBy: 200)
// error: Execution was interrupted, reason: EXC_BAD_INSTRUCTION (code=EXC_I386_INVOP, subcode=0x0).
let tooFarButSafe = csv.index(csv.startIndex, offsetBy: 200, limitedBy: csv.endIndex)
// nil
```

Außerdem lassen sich Indizes nicht zwischen Strings teilen.
Wenn du zum Beispiel mit dem oben berechneten `index` des „g“ in „orange“ in den String `fam = "This is my family: 👨‍👩‍👦‍👦, this is our dog: 🐶, this is our cat: 🐱!"` indexieren willst, also `fam[index]`, dann stürzt dein Programm ab.

Dafür gibt es viele Gründe, aber im Kern laufen sie alle darauf hinaus, dass „Unicode knifflig ist“.

Im Allgemeinen gilt: Wenn du wahlfreien Zugriff auf einzelne Zeichen brauchst, solltest du wahrscheinlich eine andere Datenstruktur verwenden, etwa `Array<Character>`.

### Einige nützliche Methoden

Swift bietet die Methoden `first` und `last`, um das erste und letzte Zeichen eines Strings zu erhalten.
Diese Methoden geben ein optionales Zeichen zurück. Ist der String leer, liefern sie nil.

```swift
let str = "Hello, world!"
print(str.first) // Prints Optional("H")
print(str.last)  // Prints Optional("!")
```

Du kannst auch die Methoden `prefix` und `suffix` verwenden, um einen Teilstring eines Strings zu erhalten.
Diese Methoden nehmen eine Ganzzahl als Argument und geben einen Teilstring zurück, der die ersten bzw. letzten n Zeichen des Strings enthält.

```swift
let str = "Hello, world!"
print(str.prefix(5)) // Prints "Hello"
print(str.suffix(6)) // Prints "world!"
```

## String-Methoden

Die Arbeit mit Text ist eine häufige Aufgabe beim Programmieren.
Swift bietet zusammen mit dem Foundation-Framework viele praktische Methoden und Eigenschaften, um Strings zu untersuchen, umzuwandeln und zu bearbeiten.

## Strings aufteilen mit `components(separatedBy:)`

Um einen String anhand eines Trennzeichens in ein Array aus Teilstrings aufzuteilen, verwendest du `components(separatedBy:)` (erfordert den Import von Foundation):

```swift
import Foundation

let sentence = "Hello, world!"
let words = sentence.components(separatedBy: " ")
print(words) // Prints ["Hello,", "world!"]
```

## Präfixe und Suffixe prüfen mit `hasPrefix(_:)` und `hasSuffix(_:)`

Um zu prüfen, ob ein String mit einer bestimmten Zeichenfolge beginnt oder endet, verwendest du `hasPrefix(_:)` und `hasSuffix(_:)`:

```swift
let greeting = "Hello, world!"
print(greeting.hasPrefix("Hello"))  // Prints true
print(greeting.hasSuffix("world!")) // Prints true
```

## Groß- und Kleinschreibung ändern

Die Groß- und Kleinschreibung eines Strings kannst du mit diesen Standardmethoden und -eigenschaften ändern:

- `lowercased()`: Gibt eine Kopie des Strings in Kleinbuchstaben zurück.
- `uppercased()`: Gibt eine Kopie des Strings in Großbuchstaben zurück.
- `capitalized`: Gibt eine Kopie zurück, in der der erste Buchstabe jedes Wortes großgeschrieben ist (aus Foundation).

```swift
let greeting = "hello, world!"
print(greeting.lowercased())  // Prints "hello, world!"
print(greeting.uppercased())  // Prints "HELLO, WORLD!"
print(greeting.capitalized)   // Prints "Hello, World!"
```

## Teilstrings ersetzen mit `replacingOccurrences(of:with:)`

Um alle Vorkommen eines Ziel-Teilstrings durch einen anderen String zu ersetzen, verwendest du `replacingOccurrences(of:with:)` (aus Foundation):

```swift
let greeting = "Hello, world!"
let updated = greeting.replacingOccurrences(of: "world", with: "Swift")
print(updated) // Prints "Hello, Swift!"
```

## Strings verbinden mit `joined(separator:)`

Die Methode `joined(separator:)` gehört zu Sammlungen von Strings, etwa `[String]`.
Sie fügt Elemente mit einem Trennzeichen zu einem einzigen String zusammen:

```swift
let words = ["Hello", "world"]
let sentence = words.joined(separator: ", ")
print(sentence) // Prints "Hello, world"
```
