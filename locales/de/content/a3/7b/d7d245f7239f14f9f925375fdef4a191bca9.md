# Einführung

Mit einer `for`-Schleife kannst du über ein Array iterieren und den Code für jedes Element wiederholen:

```haxe
var fruitList = ["apple", "banana", "pear"];

for (fruit in fruitList) {
  trace(fruit);
}

// apple
// banana
// pear
```

Im obigen Beispiel ist `fruit` die Variable, die den Wert eines einzelnen Elements des Arrays `fruitList` enthält. Der Compiler stellt sicher, dass über `fruitList` iteriert werden kann, andernfalls bricht er die Ausführung ab.

Du kannst auch über Zahlen iterieren, indem du den Range-Operator verwendest. Der Operator nimmt zwei `Int`-Operanden und wird als `min...max` geschrieben:

```haxe
for (i in 0...10) {
  trace(i); // from 0 to 9
}
```
