# Einführung

Die Klasse `TimeZoneInfo` bietet Routinen für den Umgang mit den Unterschieden zwischen Zeitzonen. Außerdem enthält sie Methoden, die den Umgang mit der Sommerzeit erleichtern.

Die Klasse `CultureInfo` unterstützt kulturspezifische Datums- und Zeitformate.

Um plattformübergreifendes Programmieren zu unterstützen, kannst du mit der Klasse `RuntimeInformation` herausfinden, auf welchem Betriebssystem dein Code ausgeführt wird: Linux, Windows oder OSX.
