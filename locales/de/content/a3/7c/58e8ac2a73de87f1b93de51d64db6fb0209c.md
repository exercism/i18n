# Einführung

## Strings

Strings in Elixir werden von doppelten Anführungszeichen eingeschlossen und sind in UTF-8 kodiert:

```elixir
"Hi!"
```

Strings lassen sich mit dem Operator `<>/2` verketten:

```elixir
"Welcome to" <> " " <> "New York"
# => "Welcome to New York"
```

Strings in Elixir unterstützen Interpolation mit der Syntax `#{}`:

```elixir
"6 * 7 = #{6 * 7}"
# => "6 * 7 = 42"
```

Um ein Zeilenumbruchzeichen in einen String einzufügen, verwendest du den Escape-Code `\n`:

```elixir
"1\n2\n3\n"
```

Um bequem mit Texten mit vielen Zeilenumbrüchen zu arbeiten, verwendest du stattdessen die Heredoc-Syntax mit dreifachen doppelten Anführungszeichen:

```elixir
"""
1
2
3
"""
```

Elixir bietet viele Funktionen für die Arbeit mit Strings im Modul `String`.

## Pipe-Operator

Der Operator `|>` heißt Pipe-Operator. Mit ihm kannst du Funktionsaufrufe so aneinanderreihen, dass der Rückgabewert des vorherigen Funktionsaufrufs als erstes Argument an den nächsten Funktionsaufruf übergeben wird.

```elixir
"hello"
|> String.upcase()
|> Kernel.<>("?!")

# => "HELLO?!"
```
