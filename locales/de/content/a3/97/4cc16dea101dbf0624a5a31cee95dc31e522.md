# Über

Wörterbücher speichern, wie ihre Entsprechungen in anderen Sprachen, etwa Maps oder assoziative Arrays, Schlüssel/Wert-Paare, sodass ein Wert direkt abgerufen oder geändert werden kann, indem man den Schlüssel an die Indexer-Eigenschaft des Wörterbuchs übergibt.

Außerdem lassen sich Schlüssel/Wert-Paare zum Wörterbuch hinzufügen und daraus entfernen. Schlüssel, Werte und Schlüssel/Wert-Paare können aufgezählt werden.

Werte können Objekte jedes beliebigen C#-Typs sein, einschließlich primitiver Typen, Strukturen _und_ Klassen.

Das Wörterbuch-Objekt erlaubt Schlüssel jedes beliebigen Typs. Damit das Verhalten zur Laufzeit korrekt ist, müssen die Schlüssel jedoch einen passenden Hashcode haben, wie ihn [GetHashCode][gethashcode] zurückgibt.

Auf eine Wörterbuch-Instanz kann nicht sicher von mehr als einem Thread zugegriffen werden (nicht threadsicher). Für Multithreading-Situationen steht [ConcurrentDictionary][concurrent-dictionary] zur Verfügung.

Siehe auch [HashSet][hashset], [ConcurrentDictionary][concurrent-dictionary], [SortedDictionary][sorted-dictionary].

Auch wenn es keine nicht-generische Version des Wörterbuchs gibt, bleiben einige Klassen in der Bibliothek, um eine nicht-generische Map zu unterstützen. Du solltest die nicht-generischen IDictionary und Hashtable vor allem kennen, damit du sie erkennst, wenn du sie siehst. Es ist unwahrscheinlich, dass du sie benutzen musst, außer wenn du eine alte Codebasis pflegst.

Oft möchtest du das Wörterbuch über seine [`IDictionary<TKey, TValue>`][idictionary]-Schnittstelle bereitstellen und darauf zugreifen.

Beachte, dass primitive Werte aufgrund der Natur von [Indexer-Eigenschaften][indexer-properties] direkt an Ort und Stelle geändert werden können, zum Beispiel:

```csharp
nums["some-number"] = 3;
nums["some-number"]++;
// nums["some-number"] == 4

```
