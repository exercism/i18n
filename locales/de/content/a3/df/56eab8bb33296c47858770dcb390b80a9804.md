# Über

[Strings][getting-started-strings] in Elixir werden von doppelten Anführungszeichen umschlossen und sind in UTF-8 kodiert:

```elixir
"Hi!"
```

Strings lassen sich mit dem Operator [`<>/2`][kernel-concat] verketten:

```elixir
"Welcome to" <> " " <> "New York"
# => "Welcome to New York"
```

Strings in Elixir unterstützen [Interpolation][string-interpolation] mit der Syntax `#{}`:

```elixir
"6 * 7 = #{6 * 7}"
# => "6 * 7 = 42"
```

Jeder Elixir-Ausdruck ist innerhalb der Interpolation gültig. Wird ein String übergeben, wird er unverändert interpoliert. Wird ein anderer Wert übergeben, versucht Elixir, ihn in einen String umzuwandeln.

```elixir
"Elixir can convert booleans to strings: #{true}"
# => "Elixir can convert booleans to strings: true"

"And #{["lists", ", ", "too!"]}"
# => "And lists, too!"

"But not functions: #{fn x -> x end}"

# => ** (Protocol.UndefinedError) protocol String.Chars not implemented for #Function<7.126501267/1 in :erl_eval.expr/5> of type Function
#        (elixir 1.10.1) lib/string/chars.ex:3: String.Chars.impl_for!/1
#        (elixir 1.10.1) lib/string/chars.ex:22: String.Chars.to_string/1
```

Elixir bietet im Modul `String` viele Funktionen für die Arbeit mit Strings. Wenn du nicht sicher bist, wie du einen String so verarbeitest, wie du es brauchst, schau dir am besten [die im Modul `String` verfügbaren Funktionen][string-module-functions] an, und du wirst höchstwahrscheinlich finden, was du brauchst.

```elixir
String.downcase("PLEASE NO SHOUTING")
# => "please no shouting"

String.split("hello", "", trim: true)
# => ["h", "e", "l", "l", "o"]

String.replace("Do I enjoy Elixir? Maybe...", "Maybe...", "Definitely!")
# => "Do I enjoy Elixir? Definitely!"

String.at("12345", 2)
# => "3"
```

Wenn du einige dieser Funktionen verwendest, denk daran, dass das erste Zeichen in einem String den Index `0` hat.

Einige Zeichen müssen [maskiert][escape-characters] werden, damit sie in einen String aufgenommen werden können, z. B. Zeilenumbrüche, doppelte Anführungszeichen oder das Zeichen `#`:

```elixir
"\"A\" is the \#1st letter of the alphabet.\n"
```

Wenn du bequem mit Texten arbeiten möchtest, die viele Zeilenumbrüche enthalten, verwende stattdessen die [Heredoc-Syntax mit dreifachen doppelten Anführungszeichen][heredoc-syntax]:

```elixir
"""
1
2
3
"""
```

Du wirst diese Syntax sehr oft beim Dokumentieren von Code finden:

```elixir
defmodule MyApp.Hello do
  @moduledoc """
  This is the Hello module.
  """

  @doc """
  Says hello to the given `name`.

  Returns `:ok`.

  ## Examples

      iex> MyApp.Hello.world(:john)
      :ok

  """
  def world(name) do
    IO.puts("hello #{name}")
  end
end
```
