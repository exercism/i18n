# Verwendung von naked returns

Die Go-Community empfiehlt, *naked returns* (oder *bare returns*) unter normalen Umständen zu vermeiden, weil sie den Code in der Regel schwerer lesbar machen.
Details findest du im [offiziellen Leitfaden zum Go-Code-Review](https://github.com/golang/go/wiki/CodeReviewComments#naked-returns).
Es gibt einen [Vorschlag](https://github.com/golang/go/issues/21291), bare returns in Go 2 ganz abzuschaffen.
