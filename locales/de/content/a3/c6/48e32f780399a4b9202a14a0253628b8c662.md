# Anleitung

Wandle eine hexadezimale Zahl, die als String vorliegt (z. B. „10af8c“), von Grund auf selbst in ihr dezimales Äquivalent um (d. h. nein, du darfst für die Umwandlung keine eingebauten oder externen Bibliotheken verwenden).

Im Web stellen wir Farben hexadezimal dar, z. B. grün: 008000, türkis: 008080, marineblau: 000080).

Das Programm soll mit ungültigen hexadezimalen Strings umgehen können.
