# Anleitung

In dieser Übung implementierst du die Mechaniken eines Rollenspiels.
Der Charakter eines Spielers wird durch den folgenden Typ dargestellt:

```fsharp
type Player = {
    Name: string option
    Level: int
    Health: int
    Mana: int option
}
```

Spieler in diesem Spiel müssen Level 10 erreichen, bevor sie einen Manapool freischalten, damit sie Zauber wirken können.
In diesem Spiel arbeitest du an zwei Funktionen: der Wiederbelebung und dem Zauberwirken.

## 1. Stell dich vor

Schreibe den Inhalt der Funktion `introduce`.
Beachte, dass das Feld `Name` des `Player`-Records ein `Option` ist.
Verschwiegene Spieler möchten ihren Namen vielleicht verbergen, indem sie ihn auf `None` lassen. Solche Spieler werden als `"Mighty Magician"` vorgestellt.
Ansonsten stellst du dich einfach mit deinem Namen vor.

```fsharp
introduce { Name = None; Level = 2; Health = 8; Mana = None }
    --> "Mighty Magician"

introduce { Name = Some "Merlin"; Level = 2; Health = 8; Mana = None }
    --> "Merlin"
```

## 2. Implementiere die Wiederbelebungsmechanik

Die Funktion `revive` sollte prüfen, ob der Charakter des Spielers tatsächlich tot ist (seine Gesundheit hat 0 erreicht).
Wenn ja, sollte sie eine neue `Player`-Instanz mit 100 Gesundheit zurückgeben.
Andernfalls, wenn der Charakter des Spielers nicht tot ist, gibt die Funktion `revive` `None` zurück.

Wenn das Level des Spielers 10 oder höher ist, sollte er außerdem mit 100 Mana wiederbelebt werden.
Wenn das Level des Spielers unter 10 liegt, sollte sein Mana `None` sein.
Die Funktion `revive` sollte das Level des Spielers beibehalten.

```fsharp
let deadPlayer = { Name = None; Level = 2; Health = 0; Mana = None }

revive deadPlayer
    --> Some { Name = None; Level = 2; Health = 100; Mana = None }
```

Wird die Methode `revive` für einen Spieler aufgerufen, dessen Gesundheit 1 oder höher ist, dann sollte die Funktion `None` zurückgeben.

```fsharp
let alivePlayer = { Name = None; Level = 2; Health = 42; Mana = None }

revive alivePlayer
    --> None
```

## 3. Implementiere die Zaubermechanik

Die Funktion `castSpell` nimmt als Argumente einen `int`, der angibt, wie viel Mana der Zauber kostet, sowie einen `Player` entgegen.
Sie gibt den aktualisierten Spieler sowie die Menge an Schaden zurück, den der gewirkte Zauber verursacht.
Ein erfolgreich gewirkter Zauber verursacht doppelt so viel Schaden, wie der Zauber an Mana kostet.
Wenn der Spieler jedoch nicht genug Mana hat, passiert nichts, der Spieler bleibt unverändert und es wird kein Schaden verursacht.
Wenn der Spieler nicht einmal einen Manapool hat, muss der Versuch, den Zauber zu wirken, seine Gesundheit um die Manakosten des Zaubers verringern und verursacht keinen Schaden.

```fsharp
let wizard = { Name = None; Level = 18; Health = 123; Mana = Some 30 }

let updatedWizard, damage = castSpell 14 wizard

updatedWizard.Mana --> Some 16
damage             --> 28
```
