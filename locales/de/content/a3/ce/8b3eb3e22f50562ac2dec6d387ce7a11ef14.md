# Anweisungen

Du bist ein begeisterter Vogelbeobachter und behältst im Blick, wie viele Vögel in den letzten sieben Tagen deinen Garten besucht haben.

Du hast sechs Aufgaben, die sich alle mit der Anzahl der Vögel befassen, die deinen Garten besucht haben.

## 1. Prüfe, wie die Zählungen letzte Woche waren

Zu Vergleichszwecken hast du immer eine Kopie der Zählungen der letzten Woche in der Nähe, und zwar: 0, 2, 5, 3, 7, 8 und 4. Erstelle einen Vektor, der die Zählungen der letzten Woche enthält:

```clojure
last-week
;;=> [0 2 5 3 7 8 4]
```

## 2. Prüfe, wie viele Vögel heute zu Besuch waren

Implementiere die Funktion `today`, die zurückgibt, wie viele Vögel heute deinen Garten besucht haben. Die Vogelzählungen sind nach Tagen geordnet, wobei das erste Element die Zählung des ältesten Tages und das letzte Element die heutige Zählung ist.

```clojure
(def birds-per-day [2 5 0 7 4 1])
(today birds-per-day)
;;=> 1
```

## 3. Erhöhe die heutige Zählung

Implementiere die Funktion `inc-bird`, um die heutige Zählung zu erhöhen:

```clojure
(inc-bird birds-per-day)
;;=> [2 5 0 7 4 2]
```

## 4. Prüfe, ob es einen Tag ohne Vögel gab

Implementiere die Prädikatfunktion `day-without-birds?`, die `true` zurückgibt, wenn es einen Tag gab, an dem null Vögel den Garten besucht haben; andernfalls gib `false` zurück:

```clojure
(day-without-birds? birds-per-day)
;;=> true
```

## 5. Berechne die Anzahl der Vögel, die an den ersten Tagen zu Besuch waren

Implementiere die Funktion `n-days-count`, die die Anzahl der Vögel zurückgibt, die deinen Garten seit Beginn der Woche besucht haben, aber begrenze die Zählung auf die angegebene Anzahl von Tagen ab Beginn der Woche.

```clojure
(n-days-count birds-per-day 4)
;;=> 14
```

## 6. Berechne die Anzahl der geschäftigen Tage

Manche Tage sind geschäftiger als andere. Ein geschäftiger Tag ist einer, an dem fünf oder mehr Vögel deinen Garten besucht haben.
Implementiere die Funktion `busy-days`, die die Anzahl der geschäftigen Tage zurückgibt:

```clojure
(busy-days birds-per-day)
;;=> 2
```

## 7. Prüfe auf eine seltsame Woche

Im letzten Jahr hast du festgestellt, dass einige Wochen demselben seltsamen Muster folgen, bei dem die Zählungen zwischen einem und null besuchenden Vögeln wechseln. Implementiere die Funktion `odd-week?`, die `true` zurückgibt, wenn das Vogelzählungsmuster dieser Woche dem seltsamen Muster entspricht:

```clojure
(odd-week? [1 0 1 0 1 0 1])
;;=> true
```
