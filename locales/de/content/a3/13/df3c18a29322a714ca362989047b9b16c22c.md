# Funktionen

In JavaScript sind Funktionen _First-Class-Objekte_. Das heißt, sie lassen sich Variablen und Eigenschaften zuweisen, an andere Funktionen übergeben und aus Funktionen zurückgeben. Sie können Eigenschaften und Methoden haben, genau wie jedes andere _Objekt_.

## Eingabe: Argumente übergeben

JavaScript-Funktionen erlauben dir, Argumente zu übergeben, wenn sie aufgerufen werden. Argumente werden immer [als Wert übergeben](https://dev.to/xpbytes/javascript-ruby-and-c-are-not-call-by-reference-23f7). Anders gesagt: Wenn eine Funktion einen Parameter innerhalb der Funktion neu zuweist, ändert sich der Wert außerhalb der Funktion nicht. Das bedeutet aber nicht, dass übergebene Objekte nicht verändert werden können.

> [!TIP]
> Wenn ein Objekt übergeben wird, wird die Referenz auf dieses Objekt als Wert übergeben. Dadurch _scheint_ es, als würden übergebene Objekte anders behandelt, aber das ist nicht der Fall.

Ein Beispiel für eine Funktion, die zwei Argumente entgegennimmt und sie multipliziert, ist:

```javascript
function multiply(a, b) {
  return a * b;
}

multiply(2, 3);
// => 6
```

## Ausgabe: Rückgabewert

JavaScript kann mit dem Schlüsselwort `return`, gefolgt von einem Ausdruck, einen einzelnen Wert aus einer Funktion zurückgeben. Wenn nichts aus einer Funktion zurückgegeben wird, ist der Rückgabewert `undefined`.

Ein Beispiel für eine Funktion, die einen Wert zurückgibt, ist:

```javascript
function multiply(a, b) {
  return a * b;
}

multiply(2, 3);
// => 6
```

## Funktionen definieren

In JavaScript gibt es vier Arten von Funktionen:

1. Reguläre Funktionen, die alles zurückgeben können und immer bis zum Ende durchlaufen;
2. Asynchrone Funktionen, die immer ein `Promise` zurückgeben und mit dem Operator `await` pausiert und fortgesetzt werden können;
3. Generator-Funktionen, die immer ein `Generator`-Objekt zurückgeben und mit dem Operator `yield` pausiert und fortgesetzt werden können;
4. Asynchrone Generator-Funktionen, die immer ein `AsyncGenerator`-Objekt zurückgeben und mit _sowohl_ dem `yield`- als auch dem `await`-Operator pausiert und fortgesetzt werden können.

Für jede dieser vier Arten gibt es drei Möglichkeiten, sie zu definieren:

1. mit einer Deklaration
2. mit einem Ausdruck
3. mit dem Konstruktor

Schließlich gibt es eine spezielle Syntax, um _Arrow Functions und Methoden_ zu definieren.
