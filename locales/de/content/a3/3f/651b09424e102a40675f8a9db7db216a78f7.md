# Anweisungen

In dieser Übung implementierst du Regeln zur Berechnung des Gesamtgehalts eines Mitarbeiters für einen Monat.
Die International Siderurgy Company (ISC) braucht Unterstützung bei der Berechnung von Mitarbeitergehältern und muss dabei verschiedene Faktoren berücksichtigen, die das endgültige Gehalt beeinflussen können.

Du hast drei Aufgaben, und für ihre Umsetzung solltest du den ternären Operator anstelle von if/else-Anweisungen verwenden.

## 1. Bestimme den Gehaltsmultiplikator

Implementiere die Methode `salaryMultiplier`, die den Gehaltsmultiplikator anhand der Anzahl der Tage zurückgibt, an denen ein Mitarbeiter der Arbeit ferngeblieben ist.
Wenn der Mitarbeiter mindestens fünf Tage gefehlt hat, ziehe 15 % ab.

```java
int daysSkipped = 3;
salaryMultiplier(daysSkipped);
// => 1.0

daysSkipped = 7;
salaryMultiplier(daysSkipped);
// => 0.85
```

## 2. Berechne den Bonus für verkaufte Produkte

Implementiere die Methoden `bonusMultiplier` und `bonusForProductsSold`.
Die ISC zahlt zehn Geldeinheiten für jedes verkaufte Produkt. Verkauft ein Mitarbeiter zwanzig Produkte oder mehr, steigt der Multiplikator auf dreizehn.
`bonusMultiplier` soll bestimmen, welcher Multiplikator anzuwenden ist, und `bonusForProductSold` soll den Gesamtbonus in Geldeinheiten zurückgeben.

```java
int productsSold = 21;
bonusMultiplier(productsSold);
// => 13
bonusForProductsSold(productsSold);
// => 273

productsSold = 5;
bonusMultiplier(productsSold);
// => 10
bonusForProductsSold(productsSold);
// => 50
```

## 3. Berechne das endgültige Gehalt des Mitarbeiters

Implementiere die Methode `finalSalary`.
Sie soll das Grundgehalt von `1000.00` mit dem Gehaltsmultiplikator multiplizieren, den Bonus addieren und das Ergebnis zurückgeben.
Das Gehalt darf jedoch `2000.00` nicht überschreiten.

```java
int daysSkipped = 2;
int productsSold = 3;
finalSalary(daysSkipped, productsSold);
// => 1030.00

productsSold = 90;
finalSalary(daysSkipped, productsSold);
// => 2000.00
```
