# Konzeptübungen

Konzeptübungen sollen Lernenden die wichtigsten Fähigkeiten vermitteln, die man braucht, um in einer bestimmten Sprache zu arbeiten. Sie decken sowohl ab, wie man übliche Dinge in dieser Sprache macht (z. B. wie man mit Strings umgeht), als auch, wie man sprachspezifischere Dinge macht (z. B. Monaden, OOP, Funktionen höherer Ordnung).

Konzeptübungen haben die folgenden Merkmale:

- Jede hat ein klares Lernziel.
- Sie sind sprachspezifisch, nicht allgemein.
- Stubs/Boilerplate werden verwendet, damit Lernende bei Übungen keinen unnötigen Code lernen oder schreiben müssen.

## Konzepte

Übungen werden auf Basis der vermittelten und gelernten Konzepte freigeschaltet.
Jede Konzeptübung muss ein oder mehrere Konzepte vermitteln.
Sie kann außerdem Voraussetzungen an Konzepte haben, was bedeutet, dass sie erst freigeschaltet wird, wenn die Konzeptübungen abgeschlossen sind, die diese vorausgesetzten Konzepte vermitteln.

## Schwierigkeit

Konzeptübungen sollten nicht von Natur aus schwieriger werden, je weiter der Track voranschreitet.
Wer in Sprache X erfahren ist, sollte alle Konzeptübungen dieses Tracks durcharbeiten können und dabei für jede höchstens 5-10 Minuten brauchen.
Da jede Übung darauf ausgerichtet ist, jemanden ein Konzept zum ersten Mal verwenden zu lassen, und da diese erfahrene Person das Konzept in Sprache X bereits versteht, sollte sich die Übung für sie relativ trivial anfühlen.
Spätere Übungen mögen sich für jemanden, der Sprache X nicht kennt, schwieriger anfühlen, aber nur, weil die spätere Übung ein Konzept vermittelt, das für sich genommen komplizierter ist (die meisten würden zum Beispiel zustimmen, dass Rekursion ein komplexeres Thema ist, wenn man es zum ersten Mal lernt, als eine Schleife von einer Sprache in eine andere zu übertragen).

## Feedback

Konzeptübungen werden nicht durch Mentoring begleitet.
Wenn Lernende eine Lösung einreichen, mit der die Tests einer Konzeptübung bestanden werden, prüfen wir, ob es einen Analyzer oder Representer gibt, der Feedback geben kann.
Wird keiner gefunden, wird die Lösung freigegeben.
Damit verlagert sich die Last des Vermittelns auf die Übung, die einen klaren Weg zum Erlernen des vermittelten Konzepts bieten muss.
