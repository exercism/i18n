# Hinweise

## Allgemeines

- Ein Vertrag steht nach dem Rückgabetyp und vor dem `is`:

  ```sather
     spare_capacity(load : INT) : INT
        pre load >= 0
     is
        ...
     end;
  ```

- In einem Vertrag kannst du die Argumente und die Attribute des Objekts verwenden, also ist `limit` verfügbar.
- Die Tests werden ohne `-chk` gebaut, ein falscher Vertrag lässt sie also nicht fehlschlagen. Schreib die Verträge für den Leser.

## 1. Ein Sicherheitsgeschirr anlegen

- `pre kg > 0`, bei `create`.
- Der Rumpf ist das übliche `new`, setze das Attribut und gib es zurück.

## 2. Wie viel ist übrig?

- Zwei Bedingungen, mit `and` verbunden: `pre load >= 0 and load <= limit`.
- `post result >= 0`. Das folgt aus dem `pre`, und genau das macht es lohnenswert, es anzugeben: Es hält fest, warum der Antwort vertraut werden kann.

## 3. Wie voll ist es?

- `pre load >= 0` und `post result >= 0`.
- `load * 100 / limit`, in dieser Reihenfolge. Zuerst zu dividieren würde alles verwerfen, wie es auch in `tuning-the-strings` der Fall wäre.

## 4. Ist es sicher?

- Gar kein `pre`: Der springende Punkt ist, dass nach jeder Last gefragt werden darf.
- Das `post` wiederholt die Frage: `post result = (load <= limit)`. Klammern, weil `=` zweimal für verschiedene Dinge verwendet wird.
