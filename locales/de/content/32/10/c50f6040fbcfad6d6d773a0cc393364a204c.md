# Überblick

Tupel werden häufig genutzt, um Informationen informell zu gruppieren. Ein gängiges Muster in Elixir ist es, die Rückgabewerte einer Funktion zusammen mit einem Status zu gruppieren.

```elixir
File.read("hello.txt")
# => {:ok, "World"}

File.read("invalid.txt")
# => {:error, :enoent}
```

- Tupel-Literale werden in geschweifte Klammern `{}` eingeschlossen.
- Tupel können beliebige Datentypen in zusammenhängendem Speicher halten, der beim Erstellen des Tupels reserviert wird.
- Tupel ermöglichen einen Lesezugriff in konstanter Zeit.
- Wenn du ein Tupel bearbeitest, wird nicht das bestehende Tupel verändert, sondern ein neues erstellt.
- Die Performance-Eigenschaften von Tupeln machen sie ideal dafür, zusammengehörige Informationen gemeinsam zu speichern, aber nicht dafür, Sammlungen von Elementen zu speichern, die iteriert werden müssen oder wachsen bzw. schrumpfen können. Im letzteren Fall [ist eine Liste besser geeignet][getting-started-lists-or-tuples].
- Die Module [`Kernel`][kernel-module] und [`Tuple`][tuple-module] haben nützliche Funktionen für die Arbeit mit Tupeln.
