# Anleitung

Bei der Planung eines Spieleabends mit Freunden beschließt die Gruppe, ihre Kindheitsfavoriten wieder aufleben zu lassen. Dein deutscher Freund schlägt _Mensch ärgere Dich nicht_ (_Man, Don't Get Angry_) vor, ein Klassiker in vielen europäischen Ländern (ähnlich dem englischen _Ludo_ oder dem nordamerikanischen _Parcheesi_).

Um dich auf das Spiel vorzubereiten, entscheidest du dich, die Funktion zum Würfeln in Elixir zu implementieren.

In _Mensch ärgere Dich nicht_ würfeln die Spielenden mit einem 6-seitigen Würfel, um ihren nächsten Zug zu bestimmen. Wenn sie Glück haben und eine 6 würfeln, dürfen sie noch einmal würfeln und ziehen.

## 1. Würfle einmal mit einem 6-seitigen Würfel

Implementiere die Funktion `d6/0`, die bei jedem Aufruf zufällig eine Ganzzahl zwischen 1 und 6 auswählt.

```elixir
MenschAergereDichNicht.d6()
# => 1
MenschAergereDichNicht.d6()
# => 5
```

## 2. Würfle so lange weiter, wie du Sechsen würfelst

Implementiere die Funktion `roll/0`. Sie sollte einen Stream von Würfelwürfen zurückgeben. Die Würfe sollten den Regeln des Spiels folgen. Wenn ich eine Sechs würfle, darf ich noch einmal würfeln. Andernfalls höre auf zu würfeln. Verwende die im vorherigen Schritt definierte Funktion `d6/0`.

```elixir
MenschAergereDichNicht.roll() |> Enum.to_list()
# => [5]
MenschAergereDichNicht.roll() |> Enum.to_list()
# => [6, 3]
```

## 3. Erlaube die Verwendung eines gezinkten Würfels

Um deinen Code leichter testen zu können, erlaube die Verwendung eines gezinkten Würfels.

Erweitere die Funktion `roll/0`. Sie sollte ein optionales Argument akzeptieren, und zwar eine Funktion. Wenn das Argument übergeben wird, verwende es für den Würfelwurf. Andernfalls greife auf `MenschAergereDichNicht.d6/0` zurück.

```elixir
MenschAergereDichNicht.roll(fn -> 3 end) |> Enum.to_list()
# => [3]
```
