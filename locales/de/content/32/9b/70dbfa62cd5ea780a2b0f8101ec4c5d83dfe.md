# Einführung

Neben der if-Anweisung gibt es in JavaScript auch die switch-Anweisung, um Logik bedingt auszuführen.
Du verwendest sie, wenn eine einzelne Variable mit mehreren Varianten verglichen werden muss.
Der Vergleich erfolgt über strikte Gleichheit (`===`), siehe [Konzept Vergleich][concept-comparison].
Für eine Variable `x` sieht die switch-Anweisung in JavaScript so aus:

<!-- prettier-ignore-start -->
```javascript
switch (x) {
  case option1:
    // code that is executed when "x === option1" is true
    break;
  case option2:
    // code that is executed when "x === option2" is true
    break;
  default:
    // code that is executed when x does not equal any of the options
}
```
<!-- prettier-ignore-end -->

Der `default`-Fall ist optional. Du verwendest ihn, wenn du Code ausführen möchtest, falls keine der anderen Optionen zur Variable passt.

Die `break`-Anweisungen oben sind nötig, weil in JavaScript standardmäßig alle Fälle ein „Fallthrough“ haben.
Das bedeutet, dass ohne `break`-Anweisung der gesamte Code in den Fällen unterhalb der ersten passenden Option ausgeführt würde, selbst wenn `x` nicht zu diesen Optionen passte.
Dieses standardmäßige „Fallthrough“-Verhalten ist eine häufige Fehlerquelle bei der Verwendung von `switch` in JavaScript.
Innerhalb einer Funktion kannst du statt `break` auch `return` verwenden, um dieses Problem zu vermeiden.
