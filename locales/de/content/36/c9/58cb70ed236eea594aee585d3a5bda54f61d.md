# Einführung

## Mapping

Mapping bezeichnet die Anwendung einer Funktion auf jedes Element einer Sequenz, um eine neue Sequenz zu erzeugen.

Das lässt sich bei einer Liste leicht mit der Funktion `mapcar` erledigen.
Nehmen wir an, wir haben eine Funktion `double`, die ihr Argument mit `2` multipliziert:

```lisp
(mapcar #'double '(1 2 3 4)) ; => (2 4 6 8)
```

Beachte, dass das erste Argument eine Funktion ist, die aufgerufen werden soll. Das `#'` ist eine spezielle Quoting-Syntax, um eine Funktion anzugeben.

`double` wurde zuerst mit dem ersten Element aufgerufen, dann mit dem zweiten usw.
Die Ergebnisse wurden in einer Liste gesammelt, die der Wert ist, zu dem der Ausdruck auswertet.

## Filtern

Filtern ist der Prozess, bei dem aus einer Sequenz eine andere Sequenz erstellt wird, indem alle bis auf bestimmte Elemente aus der ursprünglichen Sequenz kopiert werden.
Die Auswahl, welche Elemente in die neue Sequenz aufgenommen werden, kann durch eine Prädikatfunktion (eine Funktion, die zu einem booleschen Wert auswertet) oder durch Gleichheit mit einem bestimmten Objekt erfolgen.

### Entfernen anhand eines Prädikats

`remove-if` ist eine Funktion, die eine Prädikatfunktion und eine Sequenz als Argumente entgegennimmt und eine Sequenz zurückgibt, die nur die Elemente enthält, für die das Prädikat zu einem falschen Wert auswertete.
Mit anderen Worten: Sie „entfernt“ alle Elemente der Sequenz, für die das Prädikat zu einem wahren Wert auswertet. Beachte jedoch, dass diese Funktion die ursprüngliche Sequenz nicht verändert!
Stattdessen gibt sie eine neue Sequenz ohne die betreffenden Elemente zurück. Wenn das Prädikat für alle Werte wahr war, wird eine leere Sequenz zurückgegeben.

```lisp
(remove-if #'evenp '(1 2 3 4 5)) ; => (1 3 5)
(remove-if #'oddp '(1 3 5))      ; => ()
```

### Entfernen eines bestimmten Elements

Wenn du ein bestimmtes Element aus einer Sequenz entfernen möchtest, kannst du `remove` verwenden, das das zu entfernende Element und eine Sequenz entgegennimmt.
Alle Werte in der Sequenz, die nicht gleich dem zu entfernenden Element sind, werden zurückgegeben.
Hinweis: Die Gleichheit wird standardmäßig mit dem `eql` [generischen Gleichheitsprädikat][concept-equality] geprüft.

```lisp
(remove 1 '(1 2 1 3 1 4)) ; => (2 3 4)
(remove #\l "hello")      ; => "heo"
```
