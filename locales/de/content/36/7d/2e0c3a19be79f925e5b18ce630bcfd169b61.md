# Tests

## Tests ausführen

Um die Tests auszuführen, führe folgenden Befehl aus:

```bash
call {slug}Test.bat
```

## Die Übung lösen

Eine Übung zu lösen heißt, alle ihre Tests zu bestehen.
Wenn alle Tests bestanden sind, hast du die Übung gelöst!

Damit du gut starten kannst, enthält jede Übung eine Datei mit einer Stub-Implementierung.
Du kannst diese Datei als Ausgangspunkt für deine Lösung verwenden.
Du kannst sie auch gerne löschen oder ändern, wenn du findest, dass es das Richtige ist.
