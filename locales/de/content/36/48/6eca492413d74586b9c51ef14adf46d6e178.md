# Über

Der Typ `Maybe` ist die Lösung der Sprache Elm für optionale Werte.
Er kommt daher in den Typsignaturen vieler Kernfunktionen von Elm vor, und ihn zu verstehen ist entscheidend.

## Definition und Typvariable

Der Typ `Maybe` ist wie folgt definiert:

```elm
type Maybe a = Nothing | Just a
```

In der Elm-Terminologie nennt man das eine „Custom Type“-Definition.
Custom Types werden in einem anderen Konzept dieses Tracks ausführlich eingeführt, aber um `Maybe` gezielt zu verstehen, brauchen wir das nicht.
Das `a` in `Maybe a` und `Just a` steht für eine Typvariable, das heißt, es kann jeder Typ sein, etwa `Int`, `Bool` oder `String`.
So ist ein `Maybe String` eine Variable, die optional einen `String` enthält, während ein `Maybe Int` optional einen `Int` enthalten würde.

```elm
name : Maybe String
name = Just "Matthieu"

age : Maybe Int
age = Just 29
```

Der senkrechte Strich `|` in der Typdefinition von `Maybe` bedeutet „ODER“.
Er zeigt an, dass ein Wert dieses Typs entweder `Nothing` sein kann ODER `Just` mit etwas vom Typ `a`.
Angenommen, diese Person hätte Name und Alter nicht ausgefüllt, dann hätten wir Folgendes:

```elm
name : Maybe String
name = Nothing

age : Maybe Int
age = Nothing
```

## Den Inhalt eines Maybe-Werts lesen

Den Inhalt eines `Maybe`-Werts liest man per „Pattern Matching“.
Auch Pattern Matching wird in einem anderen Konzept ausführlicher behandelt, daher konzentrieren wir uns hier darauf, wie Pattern Matching mit einem `Maybe` funktioniert.

```elm
-- This function returns "Hello, <name>!" if the name was provided.
-- Otherwise, it just says "Hello, World!".
sayHello : Maybe String -> String
sayHello maybeName =
    case maybeName of
        Nothing -> "Hello, World!"
        Just someName -> "Hello, " ++ someName ++ "!"

sayHello (Just "Matthieu")
    --> "Hello, Matthieu!"

sayHello Nothing
    --> "Hello, World!"
```

Jedes Mal, wenn du einen `Maybe`-Wert verwendest, prüft der Elm-Compiler, dass dein Code alle Möglichkeiten abdeckt. Du kannst also nie ein `Maybe` per Pattern Matching auswerten und dabei nur den Fall behandeln, dass ein `Just someValue` vorliegt.
Das mag zunächst lästig erscheinen, aber es ist eine der größten Stärken von Elm.
Es verhindert hunderte Fehler und macht compilergesteuertes Refactoring zu einer furchtlosen und lohnenden Erfahrung.

## Weitere Funktionen für den Umgang mit `Maybe`

Im Modul `Maybe` gibt es außerdem eine Reihe nützlicher Funktionen für den Umgang mit `Maybe`-Typen.

```elm
sayHelloAgain : Maybe String -> String
sayHelloAgain name = "Hello, " ++ Maybe.withDefault "World" name ++ "!"

capitalizeName : Maybe String -> Maybe String
capitalizeName name = Maybe.map String.toUpper name

capitalizeName matthieu
    --> Just "MATTHIEU"

capitalizeName anon
    --> Nothing
```
