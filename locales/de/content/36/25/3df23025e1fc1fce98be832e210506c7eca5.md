# Anleitung

In dieser Übung spielst du mit deinen besten Freunden ein Rollenspiel namens „Wizard and Warriors“.
Du bist der Game Master, also die Person, die dafür sorgt, dass die Spielwelt für die Spieler lebendig wird.
Ein wichtiger Aspekt dabei ist, den Spielern das Spiel zu beschreiben: Wie ist der Status eines Charakters, wie sieht die Stadt aus, die sie gerade besuchen, usw.

Du hast fünf Aufgaben, in denen du den Spielern Teile des Spiels beschreibst.

## 1. Beschreibe einen Charakter

Jeder Charakter hat eine Klasse, eine Stufe und eine Anzahl an Trefferpunkten und wird so beschrieben: `"You're a level <LEVEL> <CLASS> with <HIT_POINTS> hit points."`.
Implementiere die Methode `GameMaster.describe`, die einen `Character` als einzigen Parameter entgegennimmt und seine Beschreibung zurückgibt.

```java
Character character = new Character();
character.setCharacterClass("Wizard");
character.setLevel(4);
character.setHitPoints(28);

new GameMaster().describe(character);
// => "You're a level 4 Wizard with 28 hit points."
```

## 2. Beschreibe ein Reiseziel

Jedes Reiseziel hat einen Namen und eine Anzahl an Einwohnern und wird so beschrieben: `"You've arrived at <NAME>, which has <INHABITANTS> inhabitants."`.
Implementiere die Methode `GameMaster.describe`, die ein `Destination` als einzigen Parameter entgegennimmt und seine Beschreibung zurückgibt.

```java
Destination destination = new Destination();
destination.setName("Muros");
destination.setInhabitants(732);

new GameMaster().describe(destination);
// => "You've arrived at Muros, which has 732 inhabitants."
```

## 3. Beschreibe die Reisemethode

Charaktere können auf eine von zwei Arten zu einem Reiseziel reisen:

- Zu Fuß, beschrieben als: `"You're traveling to your destination by walking."`
- Zu Pferd, beschrieben als: `"You're traveling to your destination on horseback."`

Implementiere die Methode `GameMaster.describe`, die eine `TravelMethod` als einzigen Parameter entgegennimmt und ihre Beschreibung zurückgibt.

```java
new GameMaster().describe(TravelMethod.HORSEBACK);
// => "You're traveling to your destination on horseback."
```

## 4. Beschreibe einen Charakter, der zu einem Reiseziel reist

Wenn ein Charakter zu einem Reiseziel reist, wird das als Kombination der einzelnen Beschreibungen beschrieben: `"<CHARACTER> <TRAVEL_METHOD> <DESTINATION>"`.
Implementiere die Methode `GameMaster.describe`, die einen `Character`, ein `Destination` und eine `TravelMethod` als Parameter entgegennimmt und die Beschreibung zurückgibt.

```java
Character character = new Character();
character.setCharacterClass("Wizard");
character.setLevel(4);
character.setHitPoints(28);

Destination destination = new Destination();
destination.setName("Muros");
destination.setInhabitants(732);

new GameMaster().describe(character, destination, TravelMethod.HORSEBACK);
// => "You're a level 4 Wizard with 28 hit points. You're traveling to your destination on horseback. You've arrived at Muros, which has 732 inhabitants."
```

## 5. Beschreibe einen Charakter, der zu einem Reiseziel reist, ohne die Reisemethode anzugeben

In den meisten Fällen reisen Charaktere zu Fuß zu ihrem Reiseziel.
Der Einfachheit halber dürfen Spieler ihre Reisemethode weglassen. In diesem Fall wird angenommen, dass sie zu Fuß unterwegs sind.
Implementiere die Methode `GameMaster.describe`, die einen `Character` und ein `Destination` als Parameter entgegennimmt und die Beschreibung zurückgibt.

```java
Character character = new Character();
character.setCharacterClass("Wizard");
character.setLevel(4);
character.setHitPoints(28);

Destination destination = new Destination();
destination.setName("Muros");
destination.setInhabitants(732);

new GameMaster().describe(character, destination);
// => "You're a level 4 Wizard with 28 hit points. You're traveling to your destination by walking. You've arrived at Muros, which has 732 inhabitants."
```
