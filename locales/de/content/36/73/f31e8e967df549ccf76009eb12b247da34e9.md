# Einführung

Julia bietet wie die meisten Programmiersprachen eine reiche Auswahl an Sammlungstypen.

Einige sind von Natur aus geordnet (darunter `Vectors` und höherdimensionale `Arrays`), sodass wir auf Elemente über ihre Position zugreifen können.
Andere Sammlungen sind ungeordnet (`Sets`, `Dicts`), und auf ihre Elemente muss man über einen Schlüssel oder einen Wert zugreifen.

Im einfachsten Fall nehmen wir an, wir haben einen `Vector` aus `Ints` und wollen ihn aufsteigend sortieren.

```julia-repl
julia> v = [3, 2, 4, 1]
4-element Vector{Int64}:
 3
 2
 4
 1

julia> sort(v)
4-element Vector{Int64}:
 1
 2
 3
 4

# sort descending
julia> sort(v, rev=true)
4-element Vector{Int64}:
 4
 3
 2
 1
```

Einfach!
Die Funktion `sort()` hat einen naheliegenden Namen und gibt scheinbar den sortierten `Vector` zurück.

_Nur Spaß!_
An diesem Punkt im Lehrplan ahnst du vielleicht (zu Recht), dass es Feinheiten gibt, die wir besprechen müssen.

## Mutierende und nicht-mutierende Funktionen

Was ist `v`, nachdem wir `sort(v)` ausgeführt haben?

```julia-repl
julia> v
4-element Vector{Int64}:
 3
 2
 4
 1

julia> issorted(v)
false
```

Der ursprüngliche Vektor bleibt unverändert.
`sort()` ist eine ***nicht-mutierende*** Funktion, die eine _Kopie_ ihrer Eingabe zurückgibt.

Das ist in vielen Zusammenhängen gutes Design: Wir haben eine [reine Funktion][wiki-pure-func], deren Verhalten leicht nachzuvollziehen ist, selbst in parallelem, verteiltem Code.

Andererseits: Angenommen, wir hätten ein Array mit einer Milliarde Strings und wollten es sortieren.

Das Sortieren ist wahrscheinlich langsam.
Außerdem müssen wir alles kopieren (_langsam!_) und genug Speicher reservieren (_mehrere Gigabyte!_), um die Kopie zu speichern.

Vergleiche diesen recht ähnlichen Code:

```julia-repl
# v is as previously

julia> issorted(v)
false

julia> sort!(v)
4-element Vector{Int64}:
 1
 2
 3
 4

julia> v
4-element Vector{Int64}:
 1
 2
 3
 4

julia> issorted(v)
true
```

Jetzt wird der eingegebene `Vector` direkt an Ort und Stelle sortiert, ohne zu kopieren, und die ursprüngliche Reihenfolge ist dauerhaft verloren.

Das kann effizient sein, es kann fehlerhaft sein und zu unerwarteten Seiteneffekten führen, und es kann andere verwirren, die deinen Code nutzen.
_Wähle mit Bedacht!_

`sort!()` ist eine „mutierende Funktion“, und nach einer (_sehr starken_) Konvention bekommt jede Funktion, die ihre Eingaben verändert, ein `!` an ihren Namen angehängt, als Warnung an Programmierer.

## Sortieren nach was?

Das Sortieren von `Int64`-Werten ist relativ einfach: Selbst kleine Kinder verstehen, dass 2 größer als 1 und kleiner als 3 ist.

Andere Typen können komplizierter sein, aber im Allgemeinen gilt `x < y`, wenn `isless(x, y) == true`.
Julia bietet Implementierungen von `isless()` für die meisten Standardtypen.

Zum Beispiel Unicode-Zeichen (bei europäischen Buchstaben werden Großbuchstaben vor Kleinbuchstaben sortiert):

```julia-repl
julia> j = collect("Julia")
5-element Vector{Char}:
 'J': ASCII/Unicode U+004A (category Lu: Letter, uppercase)
 'u': ASCII/Unicode U+0075 (category Ll: Letter, lowercase)
 'l': ASCII/Unicode U+006C (category Ll: Letter, lowercase)
 'i': ASCII/Unicode U+0069 (category Ll: Letter, lowercase)
 'a': ASCII/Unicode U+0061 (category Ll: Letter, lowercase)

julia> sort(j)
5-element Vector{Char}:
 'J': ASCII/Unicode U+004A (category Lu: Letter, uppercase)
 'a': ASCII/Unicode U+0061 (category Ll: Letter, lowercase)
 'i': ASCII/Unicode U+0false069 (category Ll: Letter, lowercase)
 'l': ASCII/Unicode U+006C (category Ll: Letter, lowercase)
 'u': ASCII/Unicode U+0075 (category Ll: Letter, lowercase)
```

Wir können vor dem Sortieren auch eine beliebige Funktion auf die Einträge anwenden, etwa `abs`, um das Vorzeichen zu ignorieren, oder `uppercase` für eine Sortierung, die Groß- und Kleinschreibung nicht unterscheidet:

```julia-repl
julia> nums = [3, -2, -4, 1]
4-element Vector{Int64}:
  3
 -2
 -4
  1

julia> sort(nums)
4-element Vector{Int64}:
 -4
 -2
  1
  3

julia> sort(nums, by=abs)
4-element Vector{Int64}:
  1
 -2
  3
 -4

# j is from "Julia", as previously

julia> sort(j, by=uppercase)
5-element Vector{Char}:
 'a': ASCII/Unicode U+0061 (category Ll: Letter, lowercase)
 'i': ASCII/Unicode U+0069 (category Ll: Letter, lowercase)
 'J': ASCII/Unicode U+004A (category Lu: Letter, uppercase)
 'l': ASCII/Unicode U+006C (category Ll: Letter, lowercase)
 'u': ASCII/Unicode U+0075 (category Ll: Letter, lowercase)

julia> vecs = [[1, 3], [4, 2], [3, 4], [2, 1]];

julia> sort(vecs)  # by default sorts by the first element of the (2-element) vectors
4-element Vector{Vector{Int64}}:
 [1, 3]
 [2, 1]
 [3, 4]
 [4, 2]

julia> sort(vecs, by=last)
4-element Vector{Vector{Int64}}:
 [2, 1]
 [4, 2]
 [1, 3]
 [3, 4]
```

## Sortieren über ein Index-Array

Wenn die zu sortierenden Elemente große Objekte sind, ist es vielleicht einfacher, mit ihrem Index zu arbeiten.

```julia-repl
julia> langs = ["Julia", "C++", "Python", "Elixir"]
4-element Vector{String}:
 "Julia"
 "C++"
 "Python"
 "Elixir"

julia> inxs = sortperm(langs)  # => Integers
4-element Vector{Int64}:
 2
 4
 1
 3

julia> langs[inxs]  # sort the entire vector
4-element Vector{String}:
 "C++"
 "Elixir"
 "Julia"
 "Python"

julia> langs[inxs[1:2]]  # slice the indices
2-element Vector{String}:
 "C++"
 "Elixir"
```

Da `langs` ein Vector ist, ist jeder Index eine Ganzzahl im [Bereich][concept-range] `1:length(langs)`.
Die Ausgabe von `sortperm()` ist eine [Permutation][wiki-permutation] dieser Ganzzahlen, die einer Sortierung des Eingabevektors entspricht.

## Teilweises Sortieren

Muss dein Programm die gesamte Eingabe sortieren?
Wenn nur die ersten oder letzten paar Einträge interessant sind, kann ein [teilweises Sortieren][wiki-partial-sort] deutlich schneller sein.

Julia bietet die Funktionen `partialsort()` und `partialsort!()`, die garantieren, dass der angegebene Eintrag oder Bereich von Einträgen korrekt ist, aber keine Garantien für den Rest der Eingabe geben.

Das zweite Argument kann entweder eine Ganzzahl oder ein Bereich sein und steht für den Index bzw. die Indizes der sortierten Eingabe:

```julia-repl
julia> vsq = [9, 4, 16, 1];  # would be [1, 4, 9, 16] after a full sort

julia> partialsort(vsq, 4)
16

julia> partialsort(vsq, 2:3)
2-element view(::Vector{Int64}, 2:3) with eltype Int64:
 4
 9
```
