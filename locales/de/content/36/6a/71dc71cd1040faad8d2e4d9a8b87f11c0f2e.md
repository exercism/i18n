# strings split verwendet

Verwende den eingebauten Typ `rune`, um in Go mit einzelnen Zeichen zu arbeiten.
Ein `string` lässt sich so in ein `[]rune` (ein Slice aus Runes) umwandeln:

```go
aRunes := []rune(a)
```

Einen String in viele kleine Strings aufzuteilen (für jedes Rune einen) funktioniert, ist aber ineffizient.
