# Einführung

Wenn sich die Typen der Parameter ableiten lassen, erlaubt Swift auch, die Parameternamen und das Schlüsselwort `in` in der Closure-Definition wegzulassen. Stattdessen kannst du auf die Parameter mit einer speziellen Kurzschreibweise verweisen, bei der `$0` für den ersten Parameter steht, `$1` für den zweiten und so weiter.

```swift
let mean: (Double, Double) -> Double = { $0 + $1 / 2.0 }

["apple", "ball", "carrot"].sorted(by: { $0.count < $1.count })
```
