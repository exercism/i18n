# Hinweise

## 1. Doppelte Tracks entfernen

- Ein Beispiel, wie du aus einem Array ein Set erstellst, findest du in den [MDN-Dokumenten][mdn-relation-to-arrays].
- Achte darauf, dein Set wieder in ein Array umzuwandeln, bevor du es zurückgibst.
- Schau dir erneut das [Konzept der Array-Destrukturierung][concept-array-destructuring] an, um dir ins Gedächtnis zu rufen, wie du den Spread-Operator einsetzt.

## 2. Prüfen, ob ein Track bereits hinzugefügt wurde

- Es gibt eine [eingebaute Methode][mdn-set-has], mit der du prüfen kannst, ob ein Element in einem Set enthalten ist.

## 3. Einen Track hinzufügen

- Es gibt eine [eingebaute Methode][mdn-set-add], mit der du ein Element zu einem Set hinzufügen kannst.
- Rufe nicht selbst `Set.has()` auf, um vor dem Hinzufügen zu prüfen, ob das Element vorhanden ist; `Set.add()` erledigt das für dich!

## 4. Einen Track löschen

- Es gibt eine [eingebaute Methode][mdn-set-delete], mit der du ein Element aus einem Set entfernst.
- Rufe nicht selbst `Set.has()` auf, um vor dem Löschen zu prüfen, ob das Element vorhanden ist; `Set.delete()` erledigt das für dich!

## 5. Eindeutige Künstler auflisten

- Es gibt [mehrere Möglichkeiten][mdn-set-iteration], über ein Set zu iterieren.
- Es gibt eine [eingebaute Methode][mdn-string-split], mit der du einen String in Teilstrings zerlegen kannst.
- Schau dir erneut das [Konzept der Array-Destrukturierung][concept-array-destructuring] an, um nachzuvollziehen, wie du beim Destrukturieren eines Arrays ein Element überspringst.
