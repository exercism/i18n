# Über

ABAP hat mehrere numerische Typen. Die gebräuchlichsten für kleine Einsteigerübungen sind `i` für Ganzzahlen und `p` für gepackte Dezimalzahlen.

Verwende `i`, wenn ein Wert eine ganze Zahl sein muss, etwa eine Anzahl von Tagen. Einen Dezimaltyp verwendest du, wenn ein Wert Nachkommastellen enthalten kann, etwa einen Stundensatz.

```abap
DATA hours_per_day TYPE i VALUE 8.
DATA rate_per_hour TYPE p LENGTH 8 DECIMALS 2 VALUE '89.89'.

DATA day_rate TYPE p LENGTH 8 DECIMALS 2.
day_rate = hours_per_day * rate_per_hour.
```

Gepackte Zahlen werden in betriebswirtschaftlichen Anwendungen oft verwendet, wenn eine feste Anzahl von Nachkommastellen erforderlich ist. ABAP kennt außerdem Dezimal-Gleitkommazahlen (`decfloat16` und `decfloat34`) und binäre Gleitkommazahlen (`f`). Binäre Gleitkommazahlen können für wissenschaftliche Berechnungen nützlich sein, sind aber für geldähnliche Beispiele keine gute Standardwahl, weil sich viele Dezimalbrüche nicht exakt darstellen lassen.
