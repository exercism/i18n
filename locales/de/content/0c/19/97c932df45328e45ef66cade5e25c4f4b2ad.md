Raku ist eine unglaublich reichhaltige, flexible und leistungsstarke Programmiersprache.
Seine Flexibilität erlaubt es Programmierern, ausdrucksstarken Code zu schreiben, der zu ihrem eigenen Stil passt.

Raku ist eine umfangreiche Sprache mit viel Tiefe zum Lernen, Erkunden und Experimentieren.
Dieser Lehrplan soll die Grundlagen abdecken, damit du loslegen kannst.

Objektorientierte Programmierung ist das Herzstück von Raku, jedoch zwingt sie keine objektorientierten Praktiken auf.
Aufgrund ihrer objektorientierten Natur wird dieser Lehrplan oft auf [Objekte, Klassen und Methoden][object-orientation] verweisen.

## Variablen

Wir verwenden in den Grundlagen nur skalare [Variablen][variables], um die Dinge einfach zu halten.

Skalare Variablen sind [Bezeichner][identifiers], denen das `$`-Sigil vorangestellt ist.

Skalare Variablen können praktisch alles enthalten und haben standardmäßig den Typ [`Any`][Any].

Die meisten Variablen, die du verwendest, benötigen eine [Deklaration][variable-declarator].
Bleib vorerst bei [`my`][my] und [`constant`][constant].

```raku
my $foo;
constant $BAR;
```

## Subroutinen

Eine Subroutine wird mit dem [`sub`][sub-declarator] Deklarator deklariert.

Auf eine `sub`-Deklaration folgt ein optionaler [Bezeichner][identifiers], gefolgt von einer optionalen [Signatur][signatures] und schließlich einem [Block][blocks].

Subroutinen (unter anderem) können exportiert werden, indem man das [`is export`][exporting] Trait hinzufügt.

Eine Subroutine kann mit einem [Postcircumfix-`( )`][postcircumfix-()] Operator auf dem Bezeichner aufgerufen werden.

```raku
sub foo ($bar) is export { ... } # Subroutine definition

foo($bar); # Subroutine call
```

## Operatoren

Raku hat eine große Vielfalt an [Operatoren][operators].
Wir werden einige grundlegende mathematische Operatoren in Raku verwenden, wie `+` und `-`, für die Übungen im Grundlagen-Konzept.

```raku
say 0.1 + 0.2 - 0.3;
# Raku is not like other languages -> https://0.30000000000000004.com/#raku
```

Du kannst in Raku leicht deine eigenen Operatoren definieren, wenn du möchtest.
Die meisten eingebauten Operatoren sind auch als Subroutinen verfügbar.

## Pakete und Module

Es gibt verschiedene Arten von [Paketen][package-declarator] in Raku. Wir werden in den Grundlagen nur `module` verwenden.

Um eine ganze Datei als `module` zu deklarieren, wird der Moduldeklaration `unit` vorangestellt.

```raku
unit module Foo;

sub bar () { ... }
```

## Kommentare

Raku hat [einzeilige][single-line-comments] und [mehrzeilige/eingebettete][multi-line-comments] Kommentare.

Einzeilige Kommentare beginnen mit `#` und reichen bis zum Ende der Zeile.

Mehrzeilige/eingebettete Kommentare beginnen mit einer Raute, gefolgt von einem Backtick und einem Unicode-Zeichen für öffnende Interpunktion.
Sie enden mit einem gepaarten passenden schließenden Zeichen.

```raku
# This is a single-line comment

#`(
    This is a
    multi-line/embedded comment
)
```

## Stilkonventionen

Bezeichner für Variablen und Subroutinen in Raku werden in `kebab-case` geschrieben.
Konstanten werden in `ALL-CAPS` geschrieben.
Paketnamen werden in `PascalCase` geschrieben.
