# Einführung

Eine Instanz einer Klasse erstellst du, indem du ihren _Konstruktor_ mit dem `new`-Operator aufrufst. Ein Konstruktor ist eine spezielle Methode innerhalb einer Klasse, deren Ziel es ist, die Klasse zu initialisieren. In Haxe hat die Konstruktormethode den Namen `new()`.

```haxe
class Library {
  private var books:Int;

  public function new() {
    this.books = 10; // Initialize the books field
  }
}

var library = new Library(); // This calls the constructor
```

Wie normale Methoden können auch Konstruktoren Parameter haben. Diese Parameter werden (üblicherweise) in privaten Feldern gespeichert und später wieder abgerufen.

```haxe
class Building {
  private var numberOfStories:Int;
  private var totalHeight: Float;

  public function new(numberOfStories:Int, storyHeight:Float) {
    this.numberOfStories = numberOfStories;
    this.totalHeight = storyHeight * numberOfStories;
  }
}

var largeBuilding = new Building(55, 6.2);
```
