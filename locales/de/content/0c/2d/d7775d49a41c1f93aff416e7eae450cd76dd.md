# Ergänzung zu den Anweisungen

## Umsetzung

In dieser Übung lernst du die [Nebenläufigkeit][oracle-docs-concurrency] kennen.
Um den letzten Test zu bestehen, könnten dir das [`synchronized`-Schlüsselwort oder Locks][oracle-docs-synchronized] nützlich sein.

Probleme, die beim gleichzeitigen Ausführen von Code auftreten, sind oft nur sporadisch, weil sie von der Reihenfolge abhängen, in der der Code ausgeführt wird.
Deshalb führt der letzte Test viele [Threads][threads-api] mehrmals aus, um die Chance zu erhöhen, einen Fehler zu finden.
Das bedeutet, dieser Test sollte fehlschlagen, wenn deine Implementierung nicht [threadsicher][wiki-thread-safety] ist. Es kann aber vorkommen, dass er nur deshalb besteht, weil es keinen Versuch einer gleichzeitigen Änderung gab.
Es ist unwahrscheinlich, dass das mehrmals hintereinander passiert, denn die Reihenfolge, in der der Code ausgeführt wird, sollte sich bei jedem Testlauf ändern.
Wenn du den letzten Test also ein paar Mal ausführst und er jedes Mal besteht, kannst du ziemlich sicher sein, dass deine Implementierung korrekt ist.
