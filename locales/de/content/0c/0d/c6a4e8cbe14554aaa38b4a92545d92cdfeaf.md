# Debug

Wenn ein Test fehlschlägt, wird eine Meldung angezeigt, die beschreibt, was schiefgelaufen ist und bei welcher Eingabe. Außerdem wird jede [Konsolenausgabe][dotnetperls.com-console-vbnet] angezeigt, was du dir zunutze machen kannst. Mit folgendem Code schreibst du in die Konsole:

```vbnet
Console.WriteLine("Debug message");
```

[dotnetperls.com-console-vbnet]: https://www.dotnetperls.com/console-vbnet
