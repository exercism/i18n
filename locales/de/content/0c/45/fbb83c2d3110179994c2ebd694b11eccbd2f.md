# Einführung

Swift bietet Kontrolltransfer-Anweisungen, mit denen du den Ausführungsablauf von Schleifen und switch-Anweisungen verändern kannst.
Neben `return` gibt es in Swift `continue`, `break`, Labels für Schleifen und `fallthrough`.

## Continue

Die Anweisung `continue` weist eine Schleife an, die aktuelle Iteration abzubrechen und sofort mit der nächsten zu beginnen.
In einer `while`- oder `repeat-while`-Schleife springt sie direkt zur Bedingungsprüfung.
In einer `for-in`-Schleife rückt sie zum nächsten Element der Sequenz vor.

```swift
var count = 1
while count < 6 {
    count += 1
    if count == 4 {
        continue
    }
    print(count)
}

// Prints:
// 2
// 3
// 5
// 6
```

## Break

Die Anweisung `break` verlässt eine gesamte Schleife oder switch-Anweisung sofort.
Die Ausführung geht dann mit der ersten Codezeile nach der Schleife oder dem switch weiter.

```swift
for fruit in ["banana", "grapes", "apple", "strawberry", "kiwi", "lemon"] {
    if !fruit.count.isMultiple(of: 2) {
        break
    }
    print(fruit)
}

// Prints:
// banana
// grapes
```

## Labels

In verschachtelten Schleifen möchtest du vielleicht, dass `break` oder `continue` eine äußere Schleife betrifft statt der innersten.
Du kannst eine Schleife mit einem Label versehen, indem du einen Namen und einen Doppelpunkt davorstellst (`labelName:`).
Dieses Label kannst du dann an `break` oder `continue` übergeben:

```swift
outerLoop: for fruit in ["banana", "grapes", "apple", "strawberry", "kiwi", "lemon"] {
    print("\n--- \(fruit) ---")
    for letter in fruit {
        guard letter != "n" else {
            break outerLoop
        }
        print(letter)
    }
}

// Prints:
// --- banana ---
// b
// a
```
