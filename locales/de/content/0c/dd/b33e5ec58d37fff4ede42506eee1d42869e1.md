# Ändere die vorgegebenen Signaturen nicht

Wie in den Anweisungen erwähnt, solltest du die Signaturen von `makeChest` und `makeTreasureChest` nicht ändern.
Sie sollten genau so bleiben:

```elm
makeChest : String -> treasure -> Chest treasure {}

makeTreasureChest : Chest treasure { conditions | securePassword : (), uniqueTreasure : () } -> TreasureChest treasure
```
