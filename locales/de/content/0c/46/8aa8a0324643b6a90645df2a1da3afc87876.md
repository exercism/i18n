# Anleitung

Du leitest ein exklusives Kino.
Um einen Film zu sehen, müssen die Leute eine Jahreskarte kaufen; danach können sie die Filme kostenlos anschauen.

Dein Kino führt ein Besucherverzeichnis.
Du willst anhand dieses Verzeichnisses nachverfolgen, welche Mitglieder in diesem Monat ihre Jahreskarte genutzt haben.
Außerdem möchtest du etwas über die Altersstruktur deiner Kundschaft erfahren.
Du merkst, dass du diese Ziele mit Sets lösen kannst.

## Sets

Ein Set ist der perfekte Datentyp, um diese Art von Daten zu speichern.

Ein Set ist ein Datentyp, mit dem du verschiedene, eindeutige Werte ohne feste Reihenfolge speicherst.
Verschieden und eindeutig bedeutet: Ein Element ist entweder im Set oder nicht. Anders als bei einem Array kann es nicht mehrmals im Set sein.
Sets sind normalerweise ungeordnet. Wenn du die Elemente eines Sets auflistest, kann die Reihenfolge, die du bekommst, von der Reihenfolge abweichen, in der sie hinzugefügt wurden. Oder sogar von der Reihenfolge der vorherigen Auflistung!

Eine Grundeigenschaft von Sets ist die Zugehörigkeitsprüfung: die Möglichkeit zu prüfen, ob ein Set ein Element enthält.
Zugehörigkeitsprüfungen sind der Kern fast jeder Verwendung eines Sets.

Go bietet keinen eingebauten Set-Datentyp.
Üblicherweise verwendest du `map[<type>]struct{}` oder `map[<type>]bool` anstelle eines Sets. Ähnlich wie ein Set erlaubt dir eine `map`, verschiedene, eindeutige Elemente hinzuzufügen, und unterstützt Zugehörigkeitsprüfungen.

## 1. Ein Ort für Besucherinformationen

Um die Besucherzahlen und die Altersstruktur zu verfolgen, willst du ein Set verwenden.

Du willst keine getrennten Sets für Namen und Alter schreiben. Stattdessen kannst du für beides ein generisches Set verwenden.
Definiere einen Typ `Set` als `map[T comparable]struct{}`, um Besucher zu speichern.
Schreibe eine Funktion `NewSet[T comparable]()`, die ein leeres `Set[T]` zurückgibt.

```go
names := NewSet[string]()
```

## 2. Besucher erfassen

Jetzt bist du bereit, Besucherinformationen zu erfassen.

Schreibe eine Methode `Add[T]()`, die ein Element zum Set hinzufügt.

```go
names := NewSet[string]()
names.Add("Alice")
```

## 3. Besucher prüfen

Jetzt, wo du ein Set von Besuchern hast, kannst du prüfen, ob bestimmte Mitglieder und Altersgruppen erschienen sind.
Schreibe eine Methode `Contains[T](element)`, die zurückgibt, ob ein Mitglied oder eine Altersgruppe im `Set` ist.

```
names := NewSet[string]()
names.Add("Alice")
names.Contains("Alice")
// => true
names.Contains("Bob")
// => false
```

## 4. Besucher vergleichen

Ein weiterer Monat ist vergangen und du hast ein neues `Set` von Altersgruppen.
Dein Marketingleiter möchte wissen, ob die neuen Filme in diesem Monat daran etwas geändert haben, welche Altersgruppen erscheinen.
Schreibe eine Methode `Equals[T](other)`, die feststellt, ob zwei Sets dieselben Elemente haben.

```go
agesOne := NewSet[int]()
names.Add(25)

agesTwo := NewSet[int]()
names.Add(25)

agesOne.Equals(agesTwo)
// => true

agesThree := NewSet[int]()
names.Add(35)

agesOne.Equals(agesThree)
// => false
```
