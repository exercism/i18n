# SQLite-spezifische Anweisungen

In dieser Übung musst du die Spalte `result` der Tabelle `kindergarten-garden` abhängig von den Spalten `diagram` und `student` auf den richtigen Wert setzen.

## Tabellenschema

```sql
CREATE TABLE "kindergarten-garden" ("diagram" TEXT, "student" TEXT, "result" TEXT);
```
