# Über

Rekursion ist eine Möglichkeit, Code in einer Funktion zu wiederholen, indem die Funktion sich selbst aufruft.
Sie ist eine weitere Möglichkeit, eine Schleife zu schreiben oder zu iterieren. Wie bei einer Schleife sollte die Funktion einen booleschen Ausdruck prüfen, um zu wissen, wann sie aufhören muss.
Anders als bei einer Schleife läuft eine Rekursion, die nie endet, nicht unendlich lange weiter.
Die Werte, die bei jedem Funktionsaufruf verwendet werden, können in einem eigenen Frame auf dem Stack liegen.
Wenn die vielen Funktionsaufrufe mehr Platz belegen, als der Stack hat, kommt es zu einem Stack-Overflow-Fehler.

```c
int printIncrement (int i, int maxValue){
    if (i > maxValue) return i;
    printf("The number is %i\n", i++);
    printIncrement(i, maxValue);
}

int main() {
    printIncrement(1, 2);
    printf("After recursion");
    return 0;
}
```

Die Ausgabe lautet

```
The number is 1
The number is 2
After recursion
```

Manche Situationen sind leichter zu lesen und/oder leichter nachzuvollziehen, wenn man sie mit Rekursion ausdrückt statt mit einer Schleife.


## Endaufruf

Von einem Endaufruf spricht man, wenn die letzte Anweisung einer Funktion nur die Funktion selbst aufruft und sonst nichts.

Ein Endaufruf ist eine besondere Form der Rekursion, die es dem Compiler erlauben kann, die Rekursion im kompilierten Code in eine Schleife zu optimieren.
Das vereint das Beste aus beiden Welten: die Lesbarkeit der Rekursion mit der Performance einer Schleife.
Das Übersetzen von Rekursion in eine Schleife nennt man `tail call elimination` oder `tail call optimization.`

Wenn ein Endaufruf in eine Schleife kompiliert wird, wird nicht für jeden Funktionsaufruf ein neuer Frame auf dem Stack angelegt.
Der Adresse der Funktion, wie sie ursprünglich aufgerufen wurde, werden die aktualisierten Werte übergeben. Das spart Stack-Speicher und verbessert die Performance.

Dieses Beispiel ist kein Endaufruf, denn die Funktion addiert 1 zum Ergebnis ihres eigenen Aufrufs

```c
int printIncrement (int i, int maxValue){
    if (i > maxValue) return 1;
    printf("The number is %i\n", i++);
    return 1 + printIncrement(i, maxValue);
}

int main() {
    int j = printIncrement(1, 2);
    printf("j is %i after recursion", j);
    return 0;
}
```

Die Ausgabe lautet

```
The number is 1
The number is 2
j is 3 after recursion
```

Damit daraus ein Endaufruf wird, machst du `j` zu einem Parameter von `printIncrement`

```c
int printIncrement (int i, int maxValue, int j){
    if (i > maxValue) return j;
    printf("The number is %i\n", i++);
    return printIncrement(i, maxValue, ++j);
}

int main() {
    int j = printIncrement(1, 2, 1);
    printf("j is %i after recursion", j);
    return 0;
}
```

Vielleicht findest du es einfacher, einen Endaufruf nachzuvollziehen, als einen rekursiven Aufruf, der kein Endaufruf ist.
Allerdings garantieren Compiler normalerweise nicht, dass alle Endaufrufe optimiert werden.
Bei Rekursion ist es immer wichtig, sicher zu sein, dass es nicht so viele Iterationen gibt, dass der Stack überläuft.
