# Über

Neben `cond` bietet Elixir auch das Makro [`if/2`][getting-started-if], das nützlich ist, wenn du nur eine Bedingung prüfen musst.

[`if/2`][kernel-if] akzeptiert eine Bedingung und zwei Optionen. Es gibt die erste Option zurück, wenn die Bedingung _truthy_ ist, und die zweite Option, wenn die Bedingung _falsy_ ist.

```elixir
age = 15

if age >= 16 do
  "You are allowed to drink beer in Germany."
else
  "No beer for you!"
end

# => "No beer for you!"
```

Ist die zweite Option nicht angegeben, wird `nil` zurückgegeben.

```elixir
age = 15

if age >= 16 do
  "You are allowed to drink beer in Germany."
end

# => nil
```

Du kannst einen `if`-Ausdruck auch in einer einzigen Zeile schreiben. Beachte das Komma nach der Bedingung.

```elixir
if age >= 16, do: "beer", else: "no beer"
```

Diese Syntax ist hilfreich für sehr kurze Ausdrücke, aber du solltest sie vermeiden, wenn der Ausdruck nicht in eine einzelne Zeile passt.

## _Truthy_ und _falsy_

In Elixir ergeben alle Datentypen einen _truthy_- oder _falsy_-Wert, wenn sie in einem booleschen Kontext auftreten (wie in einem `if`-Ausdruck). Alle Daten gelten als _truthy_, **außer** `false` und `nil`. Insbesondere leere Strings, die Ganzzahl `0` und leere Listen gelten in Elixir alle als _truthy_. Darin [ähnelt Elixir Ruby, unterscheidet sich aber von JavaScript, Python oder PHP][falsy-various-langs].

```elixir
truthy? = fn x -> if x, do: "truthy", else: "falsy" end

truthy?.(true)
# => "truthy"
truthy?.(0)
# => "truthy"
truthy?.([])
# => "truthy"

truthy?.(false)
# => "falsy"
truthy?.(nil)
# => "falsy"
```

[`&&/2`][kernel-and], [`||/2`][kernel-or] und [`!/1`][kernel-not] sind _truthy_-boolesche Operatoren, die mit jedem Wert arbeiten und die _strikten_ booleschen Operatoren [`and/2`][kernel-boolean-and], [`or/2`][kernel-boolean-or] und [`not/1`][kernel-boolean-not] ergänzen.

```elixir
0 and true
# => ** (BadBooleanError) expected a boolean on left-side of "and", got: 0

0 && true
# => true
```
