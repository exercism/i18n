# Einführung

In Go ist ein `struct` eine Folge von benannten Elementen, die _Felder_ genannt werden. Jedes Feld hat einen Namen und einen Typ.
Der Name eines Feldes muss innerhalb des Structs eindeutig sein.
Structs lassen sich mit _Klassen_ aus der objektorientierten Programmierung vergleichen.

## Ein Struct definieren

Du erstellst ein neues Struct mit den Schlüsselwörtern `type` und `struct` und legst dabei den Namen und den Typ der Felder explizit fest.
Zum Beispiel definieren wir hier das Struct `Shape`, das den Namen einer Form und ihre Größe enthält:

```go
type Shape struct {
    name string
    size int
}
```

Feldnamen in Structs folgen der Go-Konvention: Felder, deren Name mit einem Kleinbuchstaben beginnt, sind nur für Code im selben Paket sichtbar, während Felder, deren Name mit einem Großbuchstaben beginnt, auch in anderen Paketen sichtbar sind.

## Instanzen eines Structs erstellen

Nachdem du das `struct` definiert hast, kannst du eine neue Instanz erstellen, indem du die Felder über ihren Feldnamen in beliebiger Reihenfolge angibst:

```go
s := Shape {
    name: "Square",
    size: 25,
}
```

Um die Felder einer Instanz zu lesen oder zu ändern, verwendest du die `.`-Notation:

```go
// Update the name and the size
s.name = "Circle"
s.size = 35
fmt.Printf("name: %s size: %d\n", s.name, s.size)
// Output: name: Circle size: 35
```

Felder, denen kein Anfangswert zugewiesen wurde, haben ihren Nullwert.
Zum Beispiel:

```go
s := Shape{name: "Circle"}
fmt.Printf("name: %s size: %d\n", s.name, s.size)
// Output: name: Circle size: 0
```

Du kannst eine Instanz eines `struct` auch ohne Feldnamen erstellen, solange du die Felder _in der richtigen Reihenfolge_ angibst:

```go
s := Shape {
	"Oval",
	20,
}
```

Diese Syntax gilt jedoch als _brüchiger Code_, weil sie brechen kann, wenn ein Feld hinzugefügt wird, besonders wenn das neue Feld einen anderen Typ hat.
Im folgenden Beispiel fügen wir dem `Shape` ein zusätzliches Feld hinzu:

```go
type Shape struct {
	name        string
	description string // new field 'description' added
	size        int
}

s := Shape{
    "Circle",
    20,
}
// Since the second field of the struct is now a string and not an int,
// the compiler will throw an error when compiling the program:
// Output: cannot use 20 (type untyped int) as type string in field value
// Output: too few values in Shape{...}
```

## „New“-Funktionen

Manchmal ist es praktisch, Funktionen zu haben, die uns beim Erstellen von Struct-Instanzen helfen.
Konventionsgemäß heißen diese Funktionen meist `New` oder beginnen mit `New`. Da es aber ganz normale Funktionen sind, kannst du ihnen jeden beliebigen Namen geben.
Sie erinnern dich vielleicht an Konstruktoren aus anderen Sprachen, aber in Go sind es einfach ganz normale Funktionen.

Im folgenden Beispiel wird eine dieser `New`-Funktionen verwendet, um eine neue Instanz von `Shape` zu erstellen und automatisch einen Standardwert für die `size` der Form zu setzen:

```go
func NewShape(name string) Shape {
	return Shape{
		name: name,
		size: 100, //default-value for size is 100
	}
}

NewShape("Triangle")
// => Shape { name: "Triangle", size: 100 }

```

Die Verwendung von `New`-Funktionen kann die folgenden Vorteile haben:

* Validierung der übergebenen Werte
* Behandlung von Standardwerten
* Da `New`-Funktionen oft im selben Paket wie die Structs deklariert werden, die sie initialisieren, können sie sogar private Felder des Structs initialisieren

Wenn du tiefer in diesen Typ eintauchen möchtest, kannst du dir diese Ressourcen ansehen: [Go by Example: Structs][go-by-example-structs], [A Tour of Go: Structs][tour-of-go-structs] oder [Structures in Go (structs)][medium-structures-in-go]

## Die eingebaute Funktion `new`

Eine andere Möglichkeit, eine neue Instanz eines Structs zu erstellen, ist die eingebaute Funktion `new`:

```go
s := new(Shape) // s will be of type *Shape (pointer to shape)
fmt.Printf("name: %s size: %d\n", s.name, s.size)
// Output: name:  size: 0
```

In diesem Beispiel erstellt `new` eine Instanz des Structs `Shape`, in der alle Werte auf den Nullwert ihres Typs initialisiert sind, und gibt einen Zeiger darauf zurück.

~~~~exercism/note
Meistens wirst du keine neuen Struct-Instanzen sehen, die mit dem eingebauten `new` erstellt werden.
Bevorzuge immer ein Struct-Literal, eine eigene `New`-Funktion oder eine andere Funktion aus dem Paket, die dir beim Aufbau eines Structs hilft.
Greife nur als letztes Mittel auf das eingebaute `new` zurück, um neue Struct-Instanzen zu erstellen.
~~~~
