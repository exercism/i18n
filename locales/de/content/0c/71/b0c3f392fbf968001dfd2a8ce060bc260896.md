# Einführung

Wenn du eine Variable an eine Funktion übergibst, wird ihr Ownership übertragen, wodurch die ursprüngliche Variable unbrauchbar wird.
Das kann etwas mühsam sein, wenn du mehr als einmal auf einen Zustand zugreifst. Zum Glück hat Cairo aber zwei Features, mit denen du Werte übergeben kannst, ohne sie zu zerstören oder zu verschieben: `references` und `snapshots`.
