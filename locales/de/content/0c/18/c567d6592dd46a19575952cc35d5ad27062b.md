# Anweisungen

Tori ist Klimajournalistin und möchte einen Artikel über das Wetter in verschiedenen Städten schreiben. Sie hat Daten über das Wetter in verschiedenen Städten und möchte sie anhand ihrer Temperatur in eine Rangfolge bringen, aber einige der Temperaturen sind in Fahrenheit und einige in Celsius. Sie braucht deine Hilfe, um die Temperaturen in dieselbe Einheit umzurechnen und sie zu ordnen.

## 1. Fahrenheit in Celsius umrechnen

Definiere die Funktion `fahrenheit_to_celsius`, die eine Temperatur in Fahrenheit als Argument entgegennimmt und die Temperatur in Celsius zurückgibt.

Um Fahrenheit in Celsius umzurechnen, subtrahiere 32 vom Fahrenheit-Wert und teile das Ergebnis dann durch 1,8.

```gleam
fahrenheit_to_celsius(72.5)
// -> 22.5
```

## 2. Zwei Temperaturen vergleichen

Definiere die Funktion `compare_temperature`, die zwei Temperaturen entgegennimmt und einen `Order`-Wert zurückgibt, der angibt, ob die erste Temperatur kleiner als, gleich oder größer als die zweite Temperatur ist.

```gleam
compare_temperature(Celsius(30.5), Fahrenheit(82.1))
// -> Gt
```

## 3. Städte nach Temperatur sortieren

Definiere die Funktion `sort_cities_by_temperature`, die eine Liste von Städten entgegennimmt und sie von der kältesten zur wärmsten zurückgibt.

```gleam
sort_cities_by_temperature([
  City(name: "London", temperature: Celsius(30.5)),
  City(name: "Paris", temperature: Fahrenheit(82.1))
])
// -> [
//   City(name: "Paris", temperature: Fahrenheit(82.1)),
//   City(name: "London", temperature: Celsius(30.5)))
// ]
```
