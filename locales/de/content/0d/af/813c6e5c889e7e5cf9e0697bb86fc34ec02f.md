# Ausnahmen

Manche Routinen können keine Antwort geben. Wenn `count_of` nach einer Eigenschaft gefragt wird, die nicht vorhanden ist, hat es keine Zahl, die es zurückgeben könnte, und Null wäre eine Lüge, denn Null bedeutet „wir haben keine davon“, nicht „so etwas gibt es nicht“.

Eine **Ausnahme** ist, wie eine Routine sagt, dass sie keine Antwort geben kann.

## Auslösen

`raise` bricht die Routine ab und übergibt einen Wert an den Aufrufer.

```sather
   count_of(props : FMAP{STR,INT}, prop : STR) : INT is
      if ~props.has_ind(prop) then
         raise "Unknown prop: " + prop;
      end;
      return props.get(prop);
   end;
```

Nach einem `raise` wird nichts mehr ausgeführt. Die Routine kehrt nicht zurück, es gibt also keine Antwort zu prüfen und für den Aufrufer keine Möglichkeit, so weiterzumachen, als gäbe es eine.

Der ausgelöste Wert ist normalerweise ein String, der beschreibt, was schiefgelaufen ist.

## Abfangen

`protect` führt ein Stück Code aus und ist darauf vorbereitet, dass es eine Ausnahme auslöst.

```sather
   protect
      taken ::= count_of(props, prop);
      #OUT + "There are " + taken;
   when $STR then
      #OUT + "Cannot: " + exception.str;
   end;
```

Wenn nichts ausgelöst wird, wird der Teil nach `protect` ausgeführt und der `when`-Zweig übersprungen. Wenn etwas ausgelöst wird, wird der Rest des `protect`-Teils abgebrochen und stattdessen der passende `when`-Zweig ausgeführt.

`when $STR then` fängt einen ausgelösten String ab. `exception` ist der Wert, der ausgelöst wurde, und steht innerhalb des Zweigs zur Verfügung.

## Weiterreichen

Eine Routine, die eine Ausnahme nicht abfängt, muss sich nicht darum kümmern. Sie wandert nach außen, durch jeden Aufrufer hindurch, bis etwas sie abfängt:

```sather
   take_one(props : FMAP{STR,INT}, prop : STR) : INT is
      -- If this raises, take_one raises too. Nothing here says so.
      have ::= count_of(props, prop);
      ...
   end;
```

Das ist der Sinn von Ausnahmen. Die Routine, die das Problem bemerkt, und die Routine, die weiß, was dagegen zu tun ist, sind normalerweise nicht dieselbe, und alles dazwischen kann es ignorieren.
