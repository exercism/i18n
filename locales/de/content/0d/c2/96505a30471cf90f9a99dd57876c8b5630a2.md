# Anleitung

Während du Kekse für deine Freunde backen willst, stellst du fest, dass du einige der im Rezept verwendeten Maßeinheiten umrechnen musst.
Da du nur das metrische System kennst, musst du dir etwas überlegen, um gängige US-Backmaße für dich bequem in Milliliter (mL) umzurechnen.

Verwende diese Umrechnungstabelle für deine Lösung:

| Umzurechnende Einheit | Volumen | in Milliliter (mL) |
| --------------- | ------ | ------------------- |
| mL              | 1      | 1                   |
| US-Cup          | 1      | 240                 |
| US-Flüssigunze  | 1      | 30                  |
| US-Teelöffel    | 1      | 5                   |
| US-Esslöffel    | 1      | 15                  |

Als talentierter Programmierer in Ausbildung entscheidest du dich, Milliliter als Zwischeneinheit zu verwenden, um die Umrechnung von jeder aufgeführten Einheit in jede andere (sogar in sich selbst) zu erleichtern.

## 1. Ermittle die numerische Komponente aus einem Volumenpaar

Implementiere die Methode `KitchenCalculator.get_volume`.
Wenn du ein Volumenpaar-Tupel übergibst, soll sie nur die numerische Komponente zurückgeben.

```crystal
KitchenCalculator.get_volume({:cup, 2.0})
# => 2.0
```

## 2. Rechne das Volumenpaar in Milliliter um

Implementiere die Methode `KitchenCalculator.to_milliliter`.
Wenn du ein Volumenpaar-Tupel übergibst, soll sie das Volumen mithilfe der Umrechnungstabelle in Milliliter umrechnen.

```crystal
KitchenCalculator.to_milliliter({:cup, 2.5})
# => {:milliliter, 600.0}
```

## 3. Rechne das Milliliter-Volumenpaar in eine andere Einheit um

Implementiere die Methode `KitchenCalculator.from_milliliter`. 
Wenn du ein Volumenpaar-Tupel und die gewünschte Einheit übergibst, soll sie das Volumen mithilfe der Umrechnungstabelle in die gewünschte Einheit umrechnen.

```crystal
KitchenCalculator.from_milliliter({:milliliter, 1320.0}, :cup)
# => {:cup, 5.5}
```

## 4. Rechne von einer beliebigen Einheit in eine andere um

Implementiere die Methode `KitchenCalculator.convert`.
Wenn du ein Volumenpaar-Tupel und die gewünschte Einheit übergibst, soll sie das angegebene Volumen in die gewünschte Einheit umrechnen.

```crystal
KitchenCalculator.convert({:teaspoon, 9.0}, :tablespoon)
# => {:tablespoon, 3.0}
```
