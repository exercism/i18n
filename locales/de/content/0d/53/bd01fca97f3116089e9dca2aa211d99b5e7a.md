# Einführung

In Cairo helfen Module dabei, Code zu organisieren, indem sie zusammengehörige Funktionen, Structs und Traits in getrennte Namensräume gruppieren.
Das Schlüsselwort `use` vereinfacht den Zugriff auf diese Elemente, indem es sie in den Gültigkeitsbereich bringt, und reduziert Wiederholungen beim Aufrufen von Funktionen oder beim Verwenden von Typen.
Dieser Abschnitt behandelt bewährte Vorgehensweisen für den Aufbau von Modulen, das effiziente Importieren von Elementen und das Re-Exportieren für saubereren und besser wartbaren Code.
