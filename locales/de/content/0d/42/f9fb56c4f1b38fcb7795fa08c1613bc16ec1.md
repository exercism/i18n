# Über

Klassen sind ein grundlegender Baustein von Swift-Programmen.
Sie ermöglichen es dir, zusammengehörige Eigenschaften (Daten) und Methoden (Funktionen) zu eigenständigen Einheiten zusammenzufassen.

### Klassen definieren

Um eine Klasse zu definieren, verwendest du das Schlüsselwort `class`, gefolgt vom Klassennamen, wobei die Klassendefinition in geschweifte Klammern eingeschlossen wird:

```swift
class GameCharacter {
    var characterClass: String?
    var name: String?
    var active = false
    let id = makeRandomID()
}
```

Der Rumpf einer Klasse kann gespeicherte Eigenschaften enthalten, die wie reguläre Konstanten (`let`) oder Variablen (`var`) definiert werden und sich auch so verhalten.

### Instanzen

Eine Klassendefinition dient als Bauplan: Sie definiert einen neuen Typ und beschreibt, wie seine Werte aussehen, erzeugt aber selbst keine Instanzen.

Um eine *Instanz* einer Klasse zu erzeugen, rufst du ihren Initialisierer auf, indem du den Klassennamen mit runden Klammern dahinter schreibst:

```swift
let someCharacter = GameCharacter()
```

Dadurch entsteht eine neue Instanz, deren Eigenschaften mit den Standardwerten initialisiert werden, die in der Klassendefinition angegeben sind.
Optionale Eigenschaften ohne expliziten Standardwert (wie `name`) setzt Swift auf `nil`.

### Auf Eigenschaften zugreifen

Auf die Eigenschaften einer Instanz greifst du mit der *Punktnotation* zu: Du schreibst den Namen der Instanz, einen Punkt (`.`) und den Namen der Eigenschaft.
Die Punktnotation funktioniert auch für verschachtelte Eigenschaften.

Mit der Punktnotation kannst du Werte lesen und, wenn die Eigenschaft veränderbar (`var`) ist, neue Werte zuweisen:

```swift
someCharacter.name
// => nil

someCharacter.name = "Luther"
someCharacter.name
// => "Luther"

someCharacter.id = "new id"
// Error: Cannot assign to property: 'id' is a 'let' constant
```

### Methoden

Neben Eigenschaften können Klassen auch *Methoden* definieren, also Funktionen, die zur Klasse gehören.

Definiere Methoden im Rumpf der Klasse mit der üblichen `func`-Syntax.
Wenn eine Methode eine Eigenschaft ändert, muss diese mit `var` deklariert sein:

```swift
class GameCharacter {
    var characterClass: String?
    var name: String?
    var active = false
    let id: String = makeRandomID()

    func takesDamage(_ damage: Double) {
        if damage > 100 {
            active = false
        }
    }

    func sayName() -> String {
        return "My name is \(name ?? "no one"), my class is \(characterClass ?? "undetermined")"
    }
}
```

Rufe Methoden auf einer Instanz mit der Punktnotation auf, genau wie Eigenschaften:

```swift
var myChar = GameCharacter()
myChar.active = true
myChar.takesDamage(200)
myChar.active
// => false
```

### Self

Jede Instanz einer Klasse hat eine implizite Eigenschaft namens `self`, die auf die Instanz selbst verweist.
Wenn du auf Eigenschaften oder Methoden verweist, wird sie oft weggelassen, aber `self` wird häufig verwendet, um zwischen Eigenschaftsnamen und Parameternamen einer Methode zu unterscheiden, wenn beide denselben Namen haben.
