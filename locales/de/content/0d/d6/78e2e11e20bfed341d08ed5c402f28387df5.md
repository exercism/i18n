# Anleitung

Die Inspizienz möchte das Probenskript abgetippt haben, und mehrere Teile davon entstehen dadurch, dass Dinge wiederholt oder aneinandergereiht werden.

Alle vier Aufgaben gehören in die Klasse `REHEARSAL_SCRIPT`.

## 1. Wiederhole ein Stichwort

Wenn du ein Stichwort und eine Zahl bekommst, gib das Stichwort so oft hintereinander zurück, ohne etwas dazwischen.

```sather
REHEARSAL_SCRIPT::repeat_cue("Ha", 3)
-- => "HaHaHa"
```

Wiederholst du etwas null Mal, erhältst du den leeren String.

## 2. Die Initialen der Besetzung

Wenn du die Besetzungsliste bekommst, gib die ersten Buchstaben aller Namen aneinandergereiht zurück.

```sather
REHEARSAL_SCRIPT::initials(|"Mia", "Ana", "Ben"|)
-- => "MAB"
```

## 3. Nummeriere die Zeilen

Wenn du die Zeilen einer Szene bekommst, nummeriere sie ab eins, jede in einer eigenen Zeile.

```sather
REHEARSAL_SCRIPT::numbered_lines(|"Enter", "Exit"|)
-- => "1. Enter\n2. Exit"
```

Zwischen den Zeilen steht ein Zeilenumbruch, nach der letzten keiner. Eine Szene ohne Zeilen ergibt den leeren String.

## 4. Brülle eine Zeile

Gib eine Zeile zurück, in der jeder Buchstabe in einen Großbuchstaben umgewandelt wird.

```sather
REHEARSAL_SCRIPT::shout("quiet please")
-- => "QUIET PLEASE"
```
