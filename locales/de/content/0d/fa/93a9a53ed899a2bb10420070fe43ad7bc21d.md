# Einführung

## Arrays

In C# bezeichnet man Datenstrukturen, die null oder mehr Elemente aufnehmen können, als _Sammlungen_. Ein **Array** ist eine Sammlung mit fester Größe/Länge, deren Elemente alle denselben Typ haben müssen. Mit einem Index kannst du Elemente einem Array zuweisen oder daraus abrufen. C#-Arrays sind nullbasiert: Der Index des ersten Elements ist immer null:

```csharp
// Declare array with explicit size (size is 2)
int[] twoInts = new int[2];

// Assign second element by index
twoInts[1] = 8;

// Retrieve the second element by index
twoInts[1] == 8; // => true
```

Arrays lassen sich auch mit einer Kurzschreibweise definieren, mit der du das Array erstellst und gleichzeitig seine Werte festlegst. Da der Compiler nun erkennen kann, wie viele Elemente das Array haben wird, kannst du die Länge weglassen:

```csharp
// Three equivalent ways to declare and initialize an array (size is 3)
int[] threeIntsV1 = new int[] { 4, 9, 7 };
int[] threeIntsV2 = new[] { 4, 9, 7 };
int[] threeIntsV3 = { 4, 9, 7 };
```

Arrays kannst du bearbeiten, indem du entweder die Methoden oder Eigenschaften einer Array-Instanz aufrufst oder die statischen Methoden der Klasse `Array` verwendest.

## for-Schleifen

Mit einer `for`-Schleife kannst du Code so lange wiederholt ausführen, bis eine Bedingung erfüllt ist.

```csharp
for (int i = 0; i < 5; i++)
{
    System.Console.Write(i);
}

// => 01234
```

Eine `for`-Schleife besteht aus vier Teilen:

1. Der Initialisierer: wird einmal ausgeführt, bevor die Schleife beginnt. Damit definierst du meist die Variablen, die in der Schleife verwendet werden.
2. Die Bedingung: wird vor jeder Iteration der Schleife ausgeführt. Die Schleife läuft weiter, solange dies `true` ergibt.
3. Der Iterator: wird nach jeder Iteration der Schleife ausgeführt. Damit änderst du meist die Schleifenvariable (oft: erhöhen/verringern).
4. Der Schleifenblock: der Code, der bei jeder Iteration der Schleife ausgeführt wird.

## foreach-Schleifen

Dass ein Array auch eine _Sammlung_ ist, bedeutet, dass du zusätzlich zum Zugriff über den Index mit einer `foreach`-Schleife über _alle_ seine Werte iterieren kannst:

```csharp
char[] vowels = new [] { 'a', 'e', 'i', 'o', 'u' };

foreach (char vowel in vowels)
{
    // Output the vowel
    System.Console.Write(vowel);
}

// => aeiou
```
