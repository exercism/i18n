# Einführung

## Grundlagen

Wir gehen davon aus, dass du mit der JSON-Syntax und den Datentypen vertraut bist.

jq funktioniert, indem die eingehenden JSON-Daten durch einen _einzigen Ausdruck_ (geschrieben als _Pipeline aus Filtern_) geleitet werden, um die gewünschten transformierten Daten zu erhalten.

<!-- prettier-ignore -->
~~~~exercism/note
Die Sprache `jq` wird durch das `jq`-_Programm_ umgesetzt.
Dieses Programm bietet mehrere praktische Kommandozeilenoptionen, mit denen du steuern kannst, wie die Eingabe verarbeitet und die Ausgabe dargestellt wird.

In den folgenden Beispielen wirst du auf Folgendes stoßen:

- `-n` oder `--null-input`

    Normalerweise wird dem `jq`-Programm eine Datei zum Lesen übergeben, oder du sendest Daten an seine Eingabe.
    Die Option `--null-input` ermöglicht es dir, JSON-Daten ohne Eingaben zu erzeugen.

- `-c` oder `--compact-output`

    `jq` gibt seine Ausgabe standardmäßig formatiert aus.
    Für Menschen ist es äußerst nützlich, die Daten anzusehen, wenn sie schön formatiert sind.
    Für Maschinen ist das jedoch nicht nötig: Die Option `--compact-output` entfernt die Formatierungsleerzeichen, um die Größe des resultierenden JSON zu minimieren.

- `-f filename` oder `--from-file filename`

    Lies das `jq`-Programm aus `filename`, anstatt es in der Kommandozeile anzugeben.
    `sed` und `awk` verwenden die Option `-f` für denselben Zweck.
    Du wirst dies in den Testskripten für die Übungen sehen.

Der Rest dieser Lektion konzentriert sich auf die _Sprache_ `jq`.
~~~~

<!-- prettier-ignore-end -->

### Filter und Pipes

**Filter** werden auch als **Ausdrücke** bezeichnet.

Ein _Filter_ nimmt eine Eingabe entgegen und erzeugt eine Ausgabe.
Ähnlich wie in einer Unix-Shell kannst du _Filter_ mit einer Pipe `|` verbinden, um die Ausgabe eines _Filters_ mit der Eingabe eines anderen zu verbinden.

### Der Identitätsfilter: `.`

Dies ist der einfachste _Filter_.
Er gibt einfach seine Eingabe an seine Ausgabe weiter.

```sh
$ echo '[1, 2, 3]' | jq '.'
[
  1,
  2,
  3
]
```

### Arrays

Dies ist eine kurze Einführung in die Arbeit mit **Arrays**.
Wir werden dieses Thema später ausführlicher behandeln.

Auf _Array_-Elemente wird mit Klammern zugegriffen, und sie sind nullbasiert indiziert.

```sh
$ echo '[10, 20, 30]' | jq '.[1]'
20
```

Ein _Filter_ kann ein _Array_ erstellen, indem er einen Ausdruck in `[` und `]` einschließt

- mit einer bekannten Liste von Elementen:

  ```sh
  jq -n '[1, 2, 3]'
  ```

- um einen Strom von Elementen zu sammeln: Zum Beispiel ist `range` eine Funktion, die einen Strom von Zahlen ausgibt

  ```sh
  $ jq -n 'range(10; 70; 15)'
  10
  25
  40
  55
  ```

  Die Verwendung von `[]` sammelt die Ergebnisse des Ausdrucks in einem Array

  ```sh
  $ jq -c -n '[range(10; 70; 15)]'
  [10,25,40,55]
  ```

### Das Komma ist ein Operator

Das _Komma_ ist nicht nur Syntax, die _Array_-Elemente trennt.
**Komma** ist ein **Operator**, der Ströme verbindet.

Zum Beispiel ist `[1, 2, 3]` ein _Filter_, der den _Array_-Konstruktor `[]` verwendet, um das Ergebnis der Verknüpfung der drei Ausdrücke `1`, `2` und `3` zu sammeln.

Hast du die Semikolons in `range(10; 70; 15)` oben bemerkt?
Weil _Kommas_ in der Sprache `jq` einen bestimmten Zweck haben, verwenden Funktionen, die mehrere Argumente annehmen, Semikolons, um die Argumente zu trennen.

### Objekte

Eine kurze Einführung in **Objekte**.

Ähnlich wie in vielen Programmiersprachen verwendest du Punkte, um auf _Objekt_-Eigenschaften zuzugreifen

```sh
$ echo '{"foo": {"bar": "qux"}}' | jq '.foo.bar'
"qux"
```

<!-- prettier-ignore -->
~~~~exercism/note
Klammern können auch für _Objekte_ verwendet werden, aber dann werden Anführungszeichen für Zeichenkettenliterale benötigt.
Dies ist eine Methode, um mit Schlüsseln zu arbeiten, die Leerzeichen enthalten.

```sh
$ echo '{"foo bar": "qux"}' | jq '.["foo bar"]'
"qux"
```
~~~~

<!-- prettier-ignore-end -->

Du kannst ein _Objekt_ mit `{}` und `key: value`-Paaren erstellen.
Anführungszeichen sind bei _Schlüsseln_, die „einfache“ Strings sind, nicht erforderlich.

```sh
jq -n '{question: (6 * 9), answer: 42}'
```

gibt aus

```none
{
  "question": 54,
  "answer": 42
}
```

Um den _Schlüssel_ als _Ausdruck_ zu behandeln, musst du ihn in runde Klammern setzen (das Folgende gibt ebenfalls dasselbe wie oben aus).

```sh
echo '[{"key":"question", "value":54}, {"key":"answer", "value":42}]' \
| jq '{(.[0].key): .[0].value, (.[1].key): .[1].value}'
```

### Pipelines

Zum Beispiel, gegeben `file.json` mit

```json
{
  "key1": "value1",
  "key2": [5, 15, 25]
}
```

Berechnen wir die Länge des _Array_ key2:

```sh
$ jq '.key2 | length' file.json
3
```

Wir _leiten_ die Ausgabe des Ausdrucks `.key2` als Eingabe an `length` weiter, was wenig überraschend die Anzahl der Elemente im _Array_ ausgibt.

### Filter können ihre Eingabe ignorieren

In diesem Beispiel werden die eingehenden JSON-Daten ignoriert und haben keinen Einfluss auf die Ausgabe:

```sh
$ echo '{"answer": 42}' | jq '6 * 9'
54
```

### Filter können Datenströme ausgeben

Ein _Filter_ kann mehr als einen Wert ausgeben.
Zum Beispiel gibt der _Filter_ `.[]` jedes Element eines _Arrays_ als separaten Wert aus:

```sh
$ jq -n -c '[1, 2, 3]'
[1,2,3]

$ jq -n -c '[1, 2, 3] | .[]'
1
2
3
```

Wenn du einen solchen _Filter_ in einen anderen leitest, wird der zweite _Filter_ **_für jeden Wert_** ausgeführt:

```sh
$ jq -n -c '[1, 2, 3] | .[] | . * 2'
2
4
6
```

Dies ist wie eine implizite Iteration.
Sobald du diese Technik verstehst, wirst du erkennen, dass sehr mächtige `jq`-_Filter_ sehr prägnant sein können.

### Runde Klammern

**Runde Klammern** werden verwendet, um Teilausdrücke zusammenzufassen und die Reihenfolge der Operationen zu erzwingen, genau wie in anderen Sprachen.
In `jq` kann der Bedarf dafür etwas überraschend erscheinen.

Zum Beispiel wollen wir ein _Array_ mit 2 Elementen erstellen: die Quadratwurzel aus 9 und _e_ hoch 1.
Die beiden einzelnen Ausdrücke sind `9 | sqrt` und `1 | exp`.
Wir erwarten, dass die Ausgabe das _Array_ `[3, 2.7...]` ist

```jq
$ jq -n '[ 9|sqrt, 1|exp ]'
[
  20.085536923187668,
  2.718281828459045
]
```

Warum haben wir nicht bekommen, was wir erwartet haben? `jq` interpretiert das so:

```jq
[ ((9|sqrt), 1) | exp ]
```

`jq` erstellt einen Strom aus zwei Elementen (`3` und `1`), die jeweils an `exp` übergeben werden.

Wir müssen sicherstellen, dass `exp` nur eine Zahl als Eingabe erhält.
Mit anderen Worten: Wir müssen erzwingen, dass die Pipe vor dem Komma ausgewertet wird.

```jq
$ jq -n '[ 9|sqrt, (1|exp) ]'
[
  3,
  2.718281828459045
]
```

### Funktionen und Operatoren

Ohne zu sehr ins Detail zu gehen (Funktionen sind Thema einer anderen Übung), hier einige nützliche eingebaute Funktionen:

- `length`

  Wenn ein Array als Eingabe gegeben ist, gib die Anzahl der Elemente im Array aus.

  ```sh
  $ jq -n '[10, 20, 30, 40] | length'
  4
  ```

- `+`

  Dieser Operator tut je nach Typ seiner Operanden unterschiedliche Dinge:
  Er addiert Zahlen,
  verkettet Strings,
  hängt Arrays an,
  führt Objekte zusammen.

  ```sh
  $ jq -c -n '
      3 + 4,
      "foo" + "bar",
      ["a", "b"] + ["c"],
      {"m": 10} + {"n": 20}
  '
  7
  "foobar"
  ["a","b","c"]
  {"m":10,"n":20}
  ```

  `add` ist eine Funktion, die ein Array entgegennimmt und ein Element zurückgibt, bei dem alle Elemente nach den Regeln von `+` zusammengefügt wurden.
  `[1, 2, 3] | add` gibt `6` aus.

- `map`

  Wenn ein Array als Eingabe und ein Filter als Argument gegeben ist, gib ein Array aus, bei dem der Filter auf jedes Element angewendet wird

  ```sh
  $ jq -c -n '[10, 20, 30, 40] | map(. / 5)'
  [2,4,6,8]
  ```

- `select`

  Wenn _eine_ Eingabe und ein Filter als Argument gegeben sind:
  - wenn der auf das Argument angewendete Filter einen _wahren_ Wert ergibt, gib die Eingabe unverändert aus
  - andernfalls gib _nichts_ aus (nicht den Wert `null`, wirklich keine Ausgabe)

  Zum Beispiel: Wähle aus einigen Zahlen die durch 3 teilbaren aus

  ```sh
  $ jq -n 'range(10) | select(. % 3 == 0)'
  0
  3
  6
  9
  ```

  Erinnere dich, dass `range` einen _Strom_ von Zahlen ausgibt.
  `select` wird für jede Zahl einmal aufgerufen.
  Nur die Zahlen, die den Ausdruck „bestehen“, werden ausgegeben.

  Oft musst du Elemente eines Arrays auswählen.
  Es gibt ein paar Möglichkeiten, dies zu tun.

  Wähle bei der Eingabe `["Anne", "Bob", "Cathy", "Dave"]` die Namen mit der Länge 4 aus.
  - verwende `map` und `select` zusammen

    ```jq
    map(select(length == 4))
    ```

  - zerlege das Array in Elemente, wende `select` auf diesen Strom an und sammle die Ergebnisse

    ```jq
    [ .[] | select(length == 4) ]
    ```
