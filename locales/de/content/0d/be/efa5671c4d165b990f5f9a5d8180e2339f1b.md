# Über

[Custom Types][custom-types] in Elm stehen für eine feste Anzahl benannter Fälle. Jeder Wert entspricht genau einem dieser benannten Fälle. In anderen Sprachen und Kontexten kennt man sie als _Summentypen_, _Discriminated Unions_, _Tagged Unions_ und _algebraische Datentypen_.

Jeder Fall einer Discriminated Union kann optional zugehörige Daten haben, und verschiedene Fälle können verschiedene Arten von Daten haben. Hat kein Fall zugehörige Daten, ähnelt die Discriminated Union dem, was andere Sprachen üblicherweise als _Aufzählung_ (oder _Enum_) bezeichnen.

Ein Custom Type wird mit dem Schlüsselwort `type` definiert und braucht sehr wenig Syntax. Sie gehören zu den wichtigsten Techniken der Elm-Programmierung. Mit ihnen passen die möglichen Werte im Code genau zu den gültigen Werten in der realen Welt. Das lässt keinen Raum für ungültige Daten und sorgt dafür, dass sich [unmögliche Zustände im Code gar nicht erst darstellen lassen][impossible-states].

```elm
-- Custom Type without associated data
type Season
    = Spring
    | Summer
    | Autumn
    | Winter

-- Custom Type with associated data
type FlexibleNumber
    = Integer Int
    | Float Float
    | Invalid
```

Einen Wert für einen bestimmten Fall erzeugst du, indem du seinen Namen (`Spring`) verwendest. Das geht, wenn der Fall im selben Modul definiert oder mit der Syntax `import SeasonModule exposing (Season(..))` importiert wurde. Alternativ verwendest du seinen vollqualifizierten Namen (`Season.Spring`), wenn der Import mit der Syntax `import SeasonModule exposing (Season)` erfolgt ist.

```elm
integerTwo = Integer 2
invalid = FlexibleNumber.Invalid
```

Custom Types haben, wie alles in Elm, _strukturelle Gleichheit_. Das heißt: Zwei Werte für denselben Fall mit denselben (optionalen) Daten sind gleichwertig.

Custom Types bearbeitest du am besten mit [Pattern Matching][pattern-matching]:

```elm
let describe flexibleNumber =
    case flexibleNumber of
        Integer i ->
            "Integer: " ++ fromInt(i)

        Float f ->
            "Float: " ++ fromFloat(f)

        Invalid   ->
            "Invalid"
```
