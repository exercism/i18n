# Einführung

Funktionen können für ein oder mehrere Argumente Standardwerte festlegen. Schauen wir uns diese Funktion an:

```elixir
def number(n \\ 13), do: "That's not my favorite"
```

Beim Kompilieren erzeugt Elixir eine Funktionsdefinition für `number/0` (keine Argumente) und `number/1` (ein Argument).

Wenn mehr als ein Argument einen Standardwert hat, werden die Standardwerte von links nach rechts auf die Funktion angewendet, um fehlende Argumente zu ersetzen.

Wenn die Funktion mehr als eine Klausel hat, sollten die Standardargumente in einem Funktionskopf (einer Funktion ohne Rumpf) vor den Funktionsklauseln definiert werden:

```elixir
def number(n \\ 13)
def number(n) when n < 10, do: "Dream bigger!"
def number(n) when n > 100, do: "Not that big..."
```

[kernel-guards]: https://hexdocs.pm/elixir/Kernel.html#guards
