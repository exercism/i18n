# Anleitung

Du wurdest als Spezialist für reguläre Ausdrücke in einem Unternehmen eingestellt, das einen Chatbot entwickelt.

Er befindet sich in einer sehr frühen Entwicklungsphase, deshalb ist es deine Aufgabe, reguläre Ausdrücke zu verwenden, um die Fähigkeit des Chatbots zu verbessern, natürliche Sprache zu verstehen und zu erzeugen.

## Gültigen Befehl prüfen

Neben seiner Intelligenz ist der Chatbot auch ein treuer Assistent.

Um dem Chatbot etwas zu fragen, muss der Nutzer das Wort „**Chatbot**“ an der ersten Position des Befehls sagen.

Es spielt keine Rolle, ob das Schlüsselwort in Groß- oder Kleinbuchstaben geschrieben ist. Wichtig ist hier die Position des Wortes.

Implementiere die Funktion `isValidCommand()`, die dem Chatbot hilft zu erkennen, wann der Nutzer einen Befehl gibt.

```javascript
isValidCommand("Chatbot, play a song from the 80's.";
// => True
isValidCommand("Hey Chatbot, where is the closest pharmacy?";
// => False
isValidCommand("CHATBOT, do you have a solution for this challenge?";
// => True
```

## Verschlüsselte Emojis entfernen

Der Chatbot hat Schwierigkeiten zu verstehen, wie Menschen Emojis benutzen, um ihre Gefühle auszudrücken.

Wenn der Chatbot Nachrichten von Nutzern erhält, wird jedes Emoji als „_emoji_“ gefolgt von seiner _id_-Nummer dargestellt.

Implementiere die Methode `removeEmoji()`, die einen String entgegennimmt und die gesamte Emoji-Verschlüsselung aus der Nachricht entfernt.

Zeilen, die keinen Emoji-Text enthalten, sollten unverändert zurückgegeben werden.

Entferne einfach den Emoji-String. Versuche nicht, die Leerzeichen anzupassen.

Verwende für diese Aufgabe die Konstruktor-Syntax, um den regulären Ausdruck zu erstellen.

```javascript
removeEmoji("I love playing videogames emoji3465 it's one of my hobbies");
// => "I love playing videogames  it's one of my hobbies"
```

## Gültige Telefonnummer prüfen

Da die Chatbot-Funktionen in einer mobilen App heruntergeladen werden, wird vom Nutzer erwartet, dass er während des Gesprächs eine Telefonnummer angibt.

Das Problem ist, dass der Chatbot nur eine Nummer mit einem bestimmten Format lesen und validieren kann.

Wenn die Nummer gültig ist (mit der Zeichenfolge übereinstimmt, die durch den **regulären Ausdruck** festgelegt ist), antwortet der Chatbot mit einer Nachricht, in der er dem Nutzer dankt und die Nummer bestätigt. Wenn die Nummer ungültig ist, informiert die Funktion den Nutzer darüber, dass die Telefonnummer nicht gültig ist.

Das erwartete Format ist: (+##) ###-###-###

```javascript
checkPhoneNumber('(+34) 659-771-594');
// => "Thanks! You can now download me to your phone."
checkPhoneNumber('659-771-594');
// => "Oops, it seems like I can't reach out to 659-771-594"
```

## Website-Link ermitteln

Der Chatbot ist eine wirklich neugierige Software. Obwohl er im Internet zu einem bestimmten Thema suchen kann, fragt er Nutzer gerne nach coolen Websites oder URLs, um relevante Informationen zu finden.

Beispiel für ein Gespräch:

- **Chatbot**: Hey username, ich würde gerne lernen, in JavaScript zu programmieren. Kennst du eine coole Website, auf der ich das lernen könnte?
- **Nutzer**: Ich habe viel von [exercism.org](http://exercism.org) gelernt.

Implementiere die Funktion `getURL()`, die ein Array zurückgeben kann, das nur den Link jeder Website enthält. Einen regulären Ausdruck zu schreiben, der jede URL erkennt, wäre sehr kompliziert, aber der Chatbot muss nur einfache URLs lesen. Für diese Übung ist eine URL jede durch `"."` getrennte Folge von Wörtern.

```javascript
getURL(
  'I learned a lot from exercism.org and developer.mozilla.org, but I found ts39.es very boring!',
);
// => ["exercism.org", "developer.mozilla.org", "ts39.es"];
```

## Den Nutzer begrüßen

Um Daten von allen Personen zu speichern, mit denen eine Unterhaltung geführt wurde, kann der Chatbot den vollständigen Namen aus dem Profil des Nutzers in diesem Stil abrufen: **„smith, john“**.

Auf diese Weise möchten wir, dass unser Chatbot wirklich höflich ist und einen guten Eindruck macht.

Schreibe die Funktion `niceToMeetYou()`, die einen String mit dem vollständigen Namen des Nutzers entgegennimmt und den String **„Nice to meet you, John Smith“** zurückgibt.

Implementiere die Funktion zu Lernzwecken mit einer **Ersetzungsmethode** für reguläre Ausdrücke.

```javascript
let str = 'Smith, John';

niceToMeetYou(str);
// => "Nice to meet you, John Smith"
```
