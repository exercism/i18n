# Einführung

JavaScript ist eine dynamische Sprache, die objektorientierte, imperative und deklarative Stile (z. B. funktionale Programmierung) unterstützt.

## (Neu-)Zuweisung

In JavaScript gibt es einige grundlegende Möglichkeiten, Namen Werte zuzuweisen: mit Variablen oder Konstanten. Bei Exercism werden Variablen immer in [camelCase][wiki-camel-case] geschrieben, Konstanten in [SCREAMING_SNAKE_CASE][wiki-snake-case]. Es gibt keinen offiziellen Leitfaden, an den man sich halten muss, und verschiedene Firmen und Organisationen haben unterschiedliche Styleguides. _Du kannst Variablen so schreiben, wie du möchtest_. Der Vorteil, sie so zu schreiben, wie die Übungen vorbereitet sind, ist, dass sie in der Web-Oberfläche und in den meisten IDEs anders hervorgehoben werden.

Variablen lassen sich in JavaScript mit dem Schlüsselwort [`const`][mdn-const], [`let`][mdn-let] oder [`var`][mdn-var] definieren.

Bei `let` oder `var` kann eine Variable im Laufe ihres Lebens auf verschiedene Werte verweisen. Zum Beispiel kann `myFirstVariable` mit dem Zuweisungsoperator `=` viele Male definiert und neu definiert werden:

```javascript
let myFirstVariable = 1
myFirstVariable = 'Some string'
myFirstVariable = new SomeComplexClass()
```

Im Gegensatz zu `let` und `var` können Variablen, die mit `const` definiert werden, nur einmal zugewiesen werden. Damit werden in JavaScript Konstanten definiert.

```javascript
const MY_FIRST_CONSTANT = 10

// Can not be re-assigned.
MY_FIRST_CONSTANT = 20
// => TypeError: Assignment to constant variable.
```

> 💡 In einer späteren Konzeptübung wird der Unterschied zwischen der Zuweisung bzw. Bindung an eine _Konstante_ und dem _konstanten_ Wert untersucht und erklärt.

## Funktionsdeklarationen

In JavaScript werden Funktionseinheiten in _Funktionen_ gekapselt, wobei Funktionen, die zusammengehören, normalerweise in derselben Datei gruppiert werden. Diese Funktionen können Parameter (Argumente) annehmen und mit dem Schlüsselwort `return` einen Wert _zurückgeben_. Funktionen werden mit der Syntax `()` aufgerufen.

```javascript
function add(num1, num2) {
  return num1 + num2
}

add(1, 3)
// => 4
```

> 💡 In JavaScript gibt es _viele_ verschiedene Möglichkeiten, eine Funktion zu deklarieren. Diese anderen Möglichkeiten sehen anders aus als die Verwendung des Schlüsselworts `function`. Der Track versucht, sie nach und nach einzuführen, aber wenn du sie schon kennst, kannst du jede davon verwenden. In den meisten Fällen ist die eine nicht besser oder schlechter als die andere.

## Für andere Dateien bereitstellen

Um eine `function`, eine Konstante oder eine Variable in _anderen Dateien_ verfügbar zu machen, müssen sie mit dem Schlüsselwort `export` [exportiert][mdn-export] werden. Eine andere Datei kann sie dann mit dem Schlüsselwort `import` [importieren][mdn-import]. Das nennt man auch das Modulsystem. Ein gutes Beispiel dafür ist, wie all die Tests funktionieren. Jede Übung hat mindestens eine Datei, zum Beispiel `lasagna.js`, welche die _Implementierung_ enthält. Zusätzlich gibt es mindestens eine weitere Datei, zum Beispiel `lasagna.spec.js`, die die _Tests_ enthält. Diese Datei _importiert_ die öffentlichen (also exportierten) Entitäten, um die Implementierung zu testen:

```javascript
// file.js
export const MY_VALUE = 10

export function add(num1, num2) {
  return num1 + num2
}

// file.spec.js
import { MY_VALUE, add } from './file'

add(MY_VALUE, 5)
// => 15
```
