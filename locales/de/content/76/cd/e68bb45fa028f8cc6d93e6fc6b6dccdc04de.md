# Hinweise

## Allgemein

- Eine Ganzzahl kann als eine oder mehrere aufeinanderfolgende Ziffern definiert werden.

## 1. Definiere die erwartete Backzeit in Minuten

- Du musst eine [Methode][methods] ohne Argumente definieren.
- Du musst eine Ganzzahl zurückgeben (siehe [built-in types]).

## 2. Berechne die verbleibende Backzeit in Minuten

- Du musst eine [Methode][methods] mit einem einzigen Parameter definieren.
- Der Parameter der Methode ist eine Ganzzahl.
- Du musst eine Ganzzahl zurückgeben (siehe [built-in types]).
- Du kannst den Operator `-` verwenden, um Werte zu subtrahieren.

## 3. Berechne die Vorbereitungszeit in Minuten

- Du musst eine [Methode][methods] mit einem einzigen Parameter definieren.
- Der Parameter der Methode ist eine Ganzzahl.
- Du musst eine Ganzzahl zurückgeben (siehe [built-in types]).
- Du kannst den Operator `*` verwenden, um Werte zu multiplizieren.

## 4. Berechne die verstrichene Zeit in Minuten

- Du musst eine [Methode][methods] mit zwei Parametern definieren.
- Die Parameter der Methode sind vom Typ Ganzzahl.
- Du musst eine Ganzzahl zurückgeben (siehe [built-in types]).
- Du kannst eine der anderen Methoden [aufrufen][invocation], die du zuvor definiert hast.
- Du kannst den Operator `+` verwenden, um Werte zu addieren.

[methods]: https://docs.scala-lang.org/overviews/scala-book/methods-first-look.html
[built-in types]: https://docs.scala-lang.org/overviews/scala-book/built-in-types.html
