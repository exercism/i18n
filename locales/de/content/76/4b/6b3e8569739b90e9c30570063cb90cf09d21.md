# Über

Zum Auftakt der C++-Reise beginnen wir mit Variablen, Funktionsaufrufen und Kommentaren.

## Kommentare

Kommentare gibt es in zwei Varianten: einzeilig und mehrzeilig.
Alles, was in derselben Zeile nach `//` steht, wird vom Compiler ignoriert.
Mehrzeilige Kommentare werden auch als Kommentare im C-Stil bezeichnet.
Sie werden von `/*` und `*/` umschlossen.
Alles, was dazwischen steht, wird ebenfalls ignoriert.

## Variablen

C++ ist eine typisierte Sprache.
Alle Typen müssen zur Kompilierzeit bekannt sein, und meistens musst du sie explizit angeben.
Der Typ einer Variable kann sich nicht ändern.
Eine Ganzzahl-Variable mit dem Namen `years` kannst du so deklarieren:

```cpp
int years;
```

Es ist gute Praxis, Variablen schon bei der Deklaration zu initialisieren.
C++ bietet dafür verschiedene Mechanismen.
Die Version mit den geschweiften Klammern entspricht eher dem modernen C++, aber die Version mit dem Gleichheitszeichen ist ebenfalls sehr verbreitet.

```cpp
int tomatoes{80};
int potatoes = 40;
```

~~~~exercism/caution
C++ erlaubt es tatsächlich, nicht initialisierte Variablen zu verwenden.
Solange die Variable nicht bewusst gesetzt wurde, ist sie undefiniert und kann irgendetwas enthalten.
Um Fehler durch eine Verwendung vor der Zuweisung und undefiniertes Verhalten zu vermeiden, solltest du **immer initialisieren**.
Undefiniertes Verhalten kann dein Programm im ungünstigsten Moment zum Absturz bringen, obwohl es vorher einwandfrei lief.
Man kann es nicht oft genug betonen: Vermeide undefiniertes Verhalten unter allen Umständen.
~~~~

## Rechenoperationen

Rechenoperatoren wie `*`, `+` oder `-` können Teil eines Ausdrucks wie `3 * 2` oder `tomatoes + potatoes` sein.

## Variablen aktualisieren

Du kannst Variablen neu zuweisen, solange sie ihren Typ behalten:

```cpp
tomatoes = tomatoes - 5; // tomatoes is now 75
potatoes = (32 * 2) + 11; // potatoes is now 75 as well
```

## Funktionen

Funktionen haben einen Namen, einen Rückgabetyp und eine (möglicherweise leere) Parameterliste.
Ein Beispiel für eine Funktion mit dem Namen `always_fortyseven`, die immer 47 zurückgeben würde, sieht so aus:

```cpp
int always_fortyseven() {
    return 47;
}
```

Hier ist `vip_fee` mit einem Parameter:
```cpp
int vip_fee(int standard_fee) {
    /*
    vip_fee calculates the vip fee based on the standard_fee.
    */
    int vip_multi{3};
    return standard_fee * vip_multi;
}
```

Oder `total_fee`, eine Funktion mit drei Parametern und einem Aufruf einer anderen Funktion.

```cpp
int total_fee(int vips, int adults, int kids) {
    /*
    total_fee calculates the total price for a group of VIP and adult guests with kids.
    Kids get a flat discount on the standard fee.
    VIP guest fees are calculated by calling vip_fee.
    */
    int standard_fee{30};
    int kids_discount{15};

    int kids_total_fee = kids  * (standard_fee - kids_discount);
    int vips_total_fee = vips * vip_fee(standard_fee);
    int adult_total_fee = adults * standard_fee;

    return vips_total_fee + adult_total_fee + kids_total_fee;
}
```

Funktionen in C++ geben nicht den Wert der letzten Anweisung zurück, wie es in manchen anderen Sprachen der Fall ist.
Das Schlüsselwort `return` ist erforderlich, damit der Code kompiliert.

### Whitespace

Whitespace wird verwendet, um Quellcode zu formatieren, und umfasst Leerzeichen, Tabs oder Zeilenumbrüche.
Da der Compiler überflüssigen Whitespace ignoriert, kannst du ihn nutzen, um deinen Code zu strukturieren.
Ein geschickter Einsatz von Whitespace kann die Lesbarkeit deines Codes verbessern.
Es gibt verschiedene Formatierungsstandards, aber sie sind alle konventionell und werden nicht vom Compiler erzwungen.

```cpp
// Formatting makes it easier to find bugs

int eggs_yolks =  3;
int      yeast = 15;

int flour=500;int sugar=200;// compact, but difficult to read
```
