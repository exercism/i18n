# Einführung

In Common Lisp sind Strings [Vektoren][concept-vectors] aus [Zeichen][concept-characters]. Sie werden als Zeichen geschrieben, die von doppelten Anführungszeichen umgeben sind (_z. B._ "Hello World!").

Das Prädikat `stringp` gibt nur dann wahr zurück, wenn der gegebene Wert ein String ist.

Strings lassen sich mit der Funktion `subseq` in Teilstrings aufteilen. Sie nimmt den String, einen Startindex und optional einen Endindex entgegen. Die Indizierung beginnt bei null.

```lisp
(subseq "Hello World" 1 5)   ; => "ello"
(subseq "skip to the end" 5) ; => "to the end"
```

Strings lassen sich mit `string=` auf Gleichheit vergleichen.
Wenn die Groß- und Kleinschreibung der Zeichen ignoriert werden soll, kann `string-equal` verwendet werden.

```lisp
(string= "macaroni" "macaroni")      ; => T
(string= "macaroni" "MACARONI")      ; => NIL
(string-equal "macaroni" "MACARONI") ; => T
```

Operationen wie das Großschreiben, Kleinschreiben und Kapitalisieren von Strings lassen sich mit `string-upcase`, `string-downcase` und `string-capitalize` durchführen.

```lisp
(string-upcase "not too loud")                ; => "NOT TOO LOUD"
(string-downcase "YELL IT FROM THE ROOFTOPS") ; => "yell it from the rooftops"
(string-capitalize "practical COMMON LiSP")   ; => "Practical Common Lisp"
```
