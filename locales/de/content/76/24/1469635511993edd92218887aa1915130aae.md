# Über

Die [spezielle Form with][with] bietet eine Möglichkeit, sich auf den „Happy Path“ einer Reihe von potenziell fehlschlagenden Schritten zu konzentrieren und die Fehler später zu behandeln.

Angenommen, du möchtest einen Benutzernamen mit mehreren Überprüfungen validieren. Dann greifst du vielleicht zu `case`:

```elixir
case check_ascii(username) do
  {:ok, username} ->
    case check_starts_with_letter(username) do
      {:ok, username} ->
        {:ok, username}

      {:error, "usernames may only start with a letter"} = err ->
        err
    end

  {:error, "usernames may only contain ascii letters"} = err ->
    err
end
```

Das mag jetzt lesbar sein, aber wenn du mehr verschachtelte Überprüfungen hinzufügst, wird es unübersichtlicher. In dieser Situation verwendest du `with`:


```elixir
with {:ok, username} <- check_ascii(username),
     {:ok, username} <- check_starts_with_letter(username),
     {:ok, username} <- check_not_a_joke_name(username),
     {:ok, username} <- check_if_available(username) do
  {:ok, "#{username} is a fine username and you deserve it!"}
end
```

Bei jedem Schritt: Wenn eine Klausel passt, läuft die Kette weiter, bis der `do`-Block ausgeführt wird. Wenn eine Klausel nicht passt, stoppt die Kette und die nicht passende Klausel wird zurückgegeben.

Du kannst in der Kette Guards verwenden, ebenso den `=`-Operator für reguläre Übereinstimmungen.

```elixir
with {:ok, id} <- get_id(username),
     {:ok, avatar} when is_bitstring(avatar) <- fetch_avatar(id),
     avatar_size = bit_size(avatar),
     {:ok, image_type} <- check_valid_image_type(avatar) do
  {:ok, image_type, avatar_size, avatar}
end
```

Schließlich kannst du einen `else`-Block verwenden, um fehlgeschlagene Übereinstimmungen abzufangen und den Rückgabewert zu ändern.

```elixir
with {:ok, id} <- get_id(username),
     {:ok, avatar} when is_bitstring(avatar) <- fetch_avatar(id),
     avatar_size = bit_size(avatar),
     {:ok, image_type} <- check_valid_image_type(avatar) do
  {:ok, image_type, avatar_size, avatar}
else
  :not_found ->
    {:error, "invalid username"}

  {:error, "not an image"} ->
    {:error, "avatar associated to #{username} is not an image"}

  err ->
    err
end
```

Der `else`-Block ist wie eine `case`-Anweisung für jeden nicht passenden Wert der `with`-Klausel. Der erste passende Wert wird verwendet.
