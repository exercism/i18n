# Hinweise

## 1. Implementiere das `Stringer`-Interface für den Typ `TemperatureUnit`

- Der Typ `TemperatureUnit` ist bereits für dich angelegt und steht für eine Temperatureinheit
- Beachte, dass bereits 2 Konstanten dieses Typs für dich angelegt wurden: `Celsius` und `Fahrenheit`, die jeweils eine Temperatur in Celsius bzw. Fahrenheit darstellen
- Füge dem Typ `TemperatureUnit` eine `String()`-Methode hinzu, damit er das `Stringer`-Interface erfüllt.
  Diese Methode muss den String `"°C"` zurückgeben, wenn die Temperatureinheit Celsius ist, oder `"°F"`, wenn die Temperatureinheit Fahrenheit ist

## 2. Implementiere das `Stringer`-Interface für den Typ `Temperature`

- Füge dem Typ `Temperature` eine `String()`-Methode hinzu, damit er das `Stringer`-Interface erfüllt
- Die `String()`-Methode sollte einen String mit dem numerischen Wert für die Temperatur und der Temperatureinheit zurückgeben, getrennt durch ein Leerzeichen (`<temperature> <unit>`)
- Die Struktur `Temperature` enthält eine `TemperatureUnit` und ein `int`.
  Du kannst [fmt.Sprintf][sprintf] verwenden, um diesen String zu formatieren
- Da `TemperatureUnit` bereits das `Stringer`-Interface implementiert (aus Aufgabe 1), wissen die Funktionen des `fmt`-Pakets wie [fmt.Sprintf][sprintf], wie sie es formatieren müssen, wenn du die [Formatierungsverben][fmt] `%v` oder `%s` verwendest

## 3. Implementiere das `Stringer`-Interface für den Typ `SpeedUnit`

- Der Typ `SpeedUnit` ist bereits für dich angelegt und steht für eine Temperatureinheit
- Beachte, dass bereits 2 Konstanten dieses Typs für dich angelegt wurden: `KmPerHour` und `MilesPerHour`, die jeweils eine Geschwindigkeit in Kilometern pro Stunde bzw. Meilen pro Stunde darstellen
- Füge dem Typ `SpeedUnit` eine `String()`-Methode hinzu, damit er das `Stringer`-Interface erfüllt.
  Diese Methode muss den String `"km/h"` zurückgeben, wenn die Geschwindigkeitseinheit Kilometer pro Stunde ist, oder `"mph"`, wenn die Geschwindigkeitseinheit Meilen pro Stunde ist.

## 4. Implementiere das `Stringer`-Interface für `Speed`

- Füge dem Typ `Speed` eine `String()`-Methode hinzu, damit er das `Stringer`-Interface erfüllt
- Die `String()`-Methode sollte einen String mit dem numerischen Wert für die Geschwindigkeit und der Geschwindigkeitseinheit zurückgeben, getrennt durch ein Leerzeichen (`<speed> <unit>`)
- Die Struktur `Speed` enthält eine `SpeedUnit` und ein `int`.
  Du kannst [fmt.Sprintf][sprintf] verwenden, um diesen String zu formatieren
- Da die Struktur `TemperatureUnit` bereits das `Stringer`-Interface implementiert (aus Aufgabe 3), wissen die Funktionen des `fmt`-Pakets wie [fmt.Sprintf][sprintf], wie sie es formatieren müssen, wenn du die [Formatierungsverben][fmt] `%v` oder `%s` verwendest
- Um bei [fmt.Sprintf][sprintf] ein `%` in den fertigen String einzufügen, verwendest du `%%` im Formatierungs-String.

## 5. Implementiere das `Stringer`-Interface für den Typ `MeteorologyData`

- Die Struktur `Speed` enthält unter anderem die Felder `Temperature` und `Speed`.
  Du kannst [fmt.Sprintf][sprintf] verwenden, um diesen String zu formatieren
- Die `String`-Methode sollte die Meteorologiedaten im folgenden Format zurückgeben: `"<location>: <temperature>, Wind <wind_direction> at <wind_speed>, <humidity>% Humidity"`
- Da die Typen `Temperature` und `Speed` bereits das `Stringer`-Interface implementieren (aus Aufgabe 2 und 4), wissen die Funktionen des `fmt`-Pakets wie [fmt.Sprintf][sprintf], wie sie es formatieren müssen, wenn du die [Formatierungsverben][fmt] `%v` oder `%s` verwendest
