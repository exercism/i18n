# Anweisungen

Schreibe eine Funktion, die normale Zahlen in [Ordinalzahlen](https://en.wikipedia.org/wiki/Ordinal_numeral) umwandelt. Für die Null (0) gib einfach „0“ als String zurück.

Ordinalzahlen sind Zahlen, die die Position von etwas in einer Liste beschreiben.
Genau in diesem Zusammenhang werden Ordinalzahlen verwendet, nämlich als englisch geschriebener Name einer Ordinalzahl.

Die Ordinalzahlen sind (zumindest eine Form davon):

```
1st 2nd 3rd 4th 5th... 9th 10th 11th 12th... 20th 21st 22nd 23rd 24th... etc.
```

Wenn du also eine normale Zahl eingibst, erhältst du die passende Ordinalzahl:

```
1 -> 1st
2 -> 2nd
3 -> 3rd
(and so on...)
```
