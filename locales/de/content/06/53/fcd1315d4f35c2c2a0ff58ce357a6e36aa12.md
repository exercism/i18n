Doch die Sache ist etwas unübersichtlich: Azaras Koordinaten scheinen anders formatiert und sortiert zu sein als die von Rui, und sie müssen ständig von der einen Liste zur anderen schauen, um herauszufinden, welche Schätze zu welchen Orten gehören.
Da sie angehende F#-Fans sind, bitten sie dich um Hilfe: Du sollst ein kleines Programm schreiben (genauer gesagt ein paar Funktionen), mit dem sie ihre Jagdinformationen besser organisieren können.

## 1. Koordinaten extrahieren

Implementiere die Funktion `getCooordinate()`, die ein Paar `(treasure, coordinate)` aus Azaras Liste entgegennimmt und nur die extrahierte Kartenkoordinate zurückgibt.

```fsharp
getCoordinate ("Scrimshaw Whale's Tooth", "2A")
// "2A"
```

## 2. Koordinaten formatieren

Implementiere die Funktion `convertCoordinate()`, die eine Koordinate im Format „2A“ entgegennimmt und ein Tupel im Format `(2, 'A')` zurückgibt.

```fsharp
convertCoordinate "2A"
// (2, 'A')
```

## 3. Koordinaten abgleichen

Implementiere die Funktion `compareRecords()`, die ein Paar `(treasure, coordinate)` und einen Record `(location, coordinate, quadrant)` entgegennimmt und die Koordinaten aus beiden vergleicht.
Gib **`true`** zurück, wenn die Koordinaten „übereinstimmen“, und **`false`**, wenn nicht.
Formatiere die Koordinaten bei Bedarf neu, um sie korrekt vergleichen zu können.

```fsharp
compareRecords ("Brass Spyglass", "4B") ("Seaside Cottages", (1, 'C'), "blue")
// false

compareRecords ("Model Ship in Large Bottle", "8A") ("Harbor Managers Office", (8, 'A'), "purple")
// true
```

## 4. Übereinstimmende Records zusammenführen

Implementiere die Funktion `createrecord()`, die ein Paar `(treasure, coordinate)` aus Azaras Liste und einen Record `(location, coordinate, quadrant)` aus Ruis Liste entgegennimmt und `(coordinate, location, quadrant, treasure)` zurückgibt, **sofern die Koordinaten übereinstimmen**.
Wenn die Koordinaten _nicht_ übereinstimmen, gib ein Tupel derselben Form zurück, aber mit `""` gefüllt.
Formatiere die Koordinaten bei Bedarf neu, um sie korrekt vergleichen zu können.

```fsharp
createRecord ("Brass Spyglass", "4B") ("Abandoned Lighthouse", (4, 'B'), "Blue")
// ("4B", "Abandoned Lighthouse", "Blue", "Brass Spyglass")

createRecord ("Brass Spyglass", "4B") ("Seaside Cottages", (1, 'C'), "Blue")
// ("", "", "", "")
```
