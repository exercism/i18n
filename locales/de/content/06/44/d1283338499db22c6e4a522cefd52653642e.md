# Einführung

Spiele mit Zufall brauchen eine Quelle für Zufälligkeit. Factors Vokabular [`random`][random] bietet ein generisches Wort, `random`, das sich an das anpasst, was du ihm übergibst, dazu Hilfsmittel zum Mischen und Ziehen sowie eine Möglichkeit, Zufall für Tests *reproduzierbar* zu machen.

## Ein Wort als `inline` markieren

Einige Aufgaben dieser Übung definieren ein Wort, das eine *Quotation* (einen `[ … ]`-Block) als Argument nimmt und ausführt. Dazu hat Factor eine feste Regel: **ein Wort, das eine als Argument erhaltene Quotation `call`t, muss als `inline` deklariert werden**, geschrieben, indem du `inline` direkt nach dem abschließenden `;` setzt.

`inline` weist den Compiler an, den Rumpf des Wortes an jeder Aufrufstelle einzufügen, statt ihn einmal separat zu kompilieren.

- Die Quotation des Aufrufers wird direkt eingefügt, sodass **alles, was die Quotation auf dem Stack hinterlässt, zum Aufrufer zurückfließt**, obwohl der Stack-Effekt des Wortes selbst keine Ausgabewerte deklariert.

Hier ist ein kleines Wort, das `10` auf den Stack legt und dann die ihm übergebene Quotation ausführt:

```factor
USING: kernel math prettyprint ;

: with-ten ( quot -- ) 10 swap call ; inline
```

Sein Stack-Effekt, `( quot -- )`, nennt keine Ausgabewerte, und doch liefert ein Aufruf mit zwei Quotationen mit *unterschiedlichen* Effekten verschiedene Ergebnisse, die alle zum Aufrufer zurückfließen:

```factor
[ 1 + ] with-ten .        ! => 11   (quotation ( n -- n ): one value back)
[ dup 2 * ] with-ten . .  ! => 20
                          ! => 10   (quotation ( n -- n n ): two values back)
```

## `random` – ein Element

`random` (in [`random`][random]) ist generisch bezüglich seines Arguments:

```
random ( obj -- elt )
```

- Bei einer **Ganzzahl** `n` gibt es eine zufällige Ganzzahl in `[0, n)` zurück:

```factor
USING: random ;

6 random .    ! 4   (a value from 0 to 5)
```

- Bei einer **Sequenz** gibt es ein zufälliges Element zurück:

```factor
{ "rock" "paper" "scissors" } random .    ! "paper"
```

Um einen normalen Würfel zu werfen, verschiebst du den Bereich um eins nach oben: `random` von `6` ergibt 0 bis 5, also ergibt `6 random 1 +` 1 bis 6.

## Mehrere Werte ziehen

Um eine feste Anzahl zufälliger Ziehungen zu sammeln, wiederhole eine Quotation mit `replicate` (in [`sequences`][sequences]):

```
replicate ( n quot -- seq )
```

```factor
USING: random sequences ;

3 [ 6 random 1 + ] replicate .    ! { 4 1 6 }   (three dice)
```

## `randomize` – in-place mischen

`randomize` (in [`random`][random]) gibt die Sequenz mit ihren Elementen in zufälliger Reihenfolge zurück:

```
randomize ( seq -- randomized )
```

```factor
{ 1 2 3 4 5 } randomize .    ! { 3 1 5 2 4 }
```

Es mischt **in-place** und gibt dieselbe Sequenz zurück. Wenn du die ursprüngliche Reihenfolge behalten willst, rufe also zuerst `clone` auf.

## `sample` – mehrere verschiedene Elemente

`sample` (in [`random`][random]) zieht `n` *verschiedene* Elemente aus einer Sequenz, wie beim Austeilen einer Hand Karten, nie dieselbe Karte zweimal:

```
sample ( seq n -- seq' )
```

```factor
{ 10 20 30 40 50 } 3 sample .    ! { 40 10 30 }
```

Mehr Elemente zu verlangen, als die Sequenz enthält, ist ein Fehler.

## Reproduzierbare Zufälligkeit

Standardmäßig zieht `random` aus einem globalen Generator, der mit der Systemuhr initialisiert wird, sodass jeder Durchlauf anders ausfällt. Für Tests, oder wann immer du ein Spiel haben möchtest, das du *nachspielen* kannst, bindest du einen Generator mit einem festen **Seed**.

`<mersenne-twister>` (in [`random.mersenne-twister`][mt]) baut einen Generator aus einem ganzzahligen Seed, und `with-random` (in [`random`][random]) führt eine Quotation aus, während dieser Generator installiert ist:

```
<mersenne-twister> ( seed -- rnd )
with-random        ( rnd quot -- )
```

```factor
USING: random random.mersenne-twister ;

42 <mersenne-twister> [ 6 random 1 + ] with-random .
! always the same value for seed 42
```

Alles innerhalb der Quotation – `random`, `randomize`, `sample` – zieht aus dem mit Seed versehenen Generator, sodass derselbe Seed immer dasselbe Ergebnis reproduziert.

Ein Wort, das eine Quotation als Argument nimmt und sie durch `with-random` laufen lässt, fällt unter die Regel aus [Ein Wort als `inline` markieren](#marking-a-word-inline): `with-random` `call`t diese Quotation am Ende, also muss ein solcher Wrapper als `inline` markiert werden.
