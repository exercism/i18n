# Ergänzung zu den Anweisungen

## Wie diese Übung im Python-Track aufgebaut ist

Die Tests für diese Übung erwarten, dass dein Programm als [`class`][classes in python] namens `Garden` umgesetzt wird (_siehe auch [concept:python/classes]()_).
Wenn du mit Klassen in Python noch nicht vertraut bist, ist dieses [Real-Python-Tutorial][how-to-make-a-class] vielleicht ein guter zusätzlicher Einstieg.

Deine `class` sollte eine [`method`][methods] namens `plants` implementieren, die den Namen eines Schülers als Argument entgegennimmt und die `list` der Pflanzennamen zurückgibt, die zu diesem Schüler gehören.


## Konstruktoren

Das Anlegen des Beispielgartens:

```python
[window][window][window]
VRCGVVRVCGGCCGVRGCVCGCGV
VRCCCGCRRGVCGCRVVCVGCGCV
```

würde in den Tests als `Garden("VRCGVVRVCGGCCGVRGCVCGCGV\nVRCCCGCRRGVCGCRVVCVGCGCV")` dargestellt.

Damit diese Darstellung funktioniert, muss deine `class` eine [`__init__()`][init] [spezielle Methode][special-methods] implementieren.
Wenn du mit `__init__()` oder [_Konstruktoren_][what-is-a-constructor] nicht vertraut bist, gibt [Klassen- und Instanzobjekte][class vs instance objects in python] aus der Python-Dokumentation eine ausführlichere Erklärung.


## Standardparameter

In einigen Tests wird eine `list` von Schülern als Argument an `__init__()` übergeben.
Diese sollte die zwölf Schüler umfassende Liste aus der Aufgabenstellung überschreiben.
Beide folgenden Anweisungen müssen mit deiner `__init__()`-Methode funktionieren:


```Python
# Make a garden based on the default 12-student roster.
Garden("VRCGVVRVCGGCCGVRGCVCGCGV\nVRCCCGCRRGVCGCRVVCVGCGCV") 

# Make a garden based on a 2-student roster.
Garden("VRCC\nVCGG", students=["Valorie", "Raven"]) 
```

Eine Möglichkeit ist, die Schüler-`list` zu einem [Standardargument][default argument values] zu machen; die Python-Dokumentation beschreibt `default parameters` ausführlich bei der Erklärung von [Funktionsdefinitionen][function definitions].
