# Hinweise

## 1. Ein neues Highscore-Wörterbuch anlegen

- [Leere Wörterbücher][empty-dictionary] lassen sich initialisieren, indem man dem Typnamen ein Paar leerer runder Klammern folgen lässt oder, wenn sich der Typ aus dem Kontext ergibt, über das Literal für ein leeres Wörterbuch.

## 2. Spieler zum Highscore-Wörterbuch hinzufügen

- Ein Wörterbuch muss als Variable deklariert werden, um Elemente hinzuzufügen.
- Elemente können mit der [Subscript-Syntax für Wörterbücher][dictionary-subscripts] zu einem Wörterbuch hinzugefügt werden.

## 3. Spieler aus dem Punkte-Wörterbuch entfernen

- Ein Wörterbuch muss als Variable deklariert werden, um Elemente daraus zu entfernen.
- Elemente können mit der [passenden Methode][dictionary-docs] aus einem Wörterbuch entfernt werden.

## 4. Die Punkte eines Spielers zurücksetzen

- Ein Wörterbuch muss als Variable deklariert werden, um Werte darin zu ändern.
- Werte können mit der [Subscript-Syntax für Wörterbücher][dictionary-subscripts] in einem Wörterbuch aktualisiert werden.

## 5. Die Punkte eines Spielers aktualisieren

- Ein Wörterbuch muss als Variable deklariert werden, um Werte darin zu ändern.
- Werte können mit der [Subscript-Syntax für Wörterbücher][dictionary-subscripts] in einem Wörterbuch aktualisiert werden.

## 6. Eine Liste von Spielern abrufen, deren Punkte nach Spielernamen sortiert sind

- Wörterbuch-Elemente können mit der [passenden Methode][dictionary-docs] sortiert werden.
- Du musst eine Sortierfunktion vom Typ `((String, Int), (String, Int)) -> Bool` definieren, die du an die Methode `sorted(by:)` übergibst.
- Die Sortierfunktion sollte `true` zurückgeben, wenn das linke Schlüssel-Wert-Paar _vor_ dem rechten Schlüssel-Wert-Paar in der sortierten Ausgabe erscheinen soll.

## 7. Eine Liste von Spielern abrufen, sortiert nach Punkten in absteigender Reihenfolge

- Wörterbuch-Elemente können mit der [passenden Methode][dictionary-docs] sortiert werden.
- Du musst eine Sortierfunktion vom Typ `((String, Int), (String, Int)) -> Bool` definieren, die du an die Methode `sorted(by:)` übergibst.
- Die Sortierfunktion sollte `true` zurückgeben, wenn das linke Schlüssel-Wert-Paar _vor_ dem rechten Schlüssel-Wert-Paar in der sortierten Ausgabe erscheinen soll.
