# Einführung

**Reguläre Ausdrücke** (Regexe) sind Zeichenfolgen, die ein Suchmuster in einem Text beschreiben.

Die Syntax regulärer Ausdrücke zu erlernen, geht über dieses Thema hinaus.
Wir konzentrieren uns auf die Ausdrücke, die `jq` bereitstellt, um reguläre Ausdrücke zu nutzen.

## Regex-Variante

Verschiedene Tools implementieren verschiedene Versionen regulärer Ausdrücke.
`jq` verwendet die Regex-Bibliothek [Oniguruma][oniguruma], die weitgehend mit den regulären Ausdrücken von Perl v5.8 kompatibel ist.

Die konkrete Syntax, die `jq` verwendet, [findest du im Oniguruma-GitHub-Repo][onig-syntax].

<!-- prettier-ignore -->
~~~~exercism/caution
`jq` hat keine spezielle Syntax für reguläre Ausdrücke.
Sie werden einfach als Strings ausgedrückt.
Das bedeutet, dass alle Backslashes im regulären Ausdruck im String escaped werden müssen.

Zum Beispiel muss die Zeichenklasse für Ziffern (`\d`) als `"\\d"` geschrieben werden.
~~~~

<!-- prettier-ignore-end -->

## Regex-Funktionen

Reguläre Ausdrücke in `jq` beschränken sich auf [eine Reihe von Filtern][jq-regex-funcs].

### Einfaches Abgleichen

Wenn du wissen möchtest, ob ein String zu einem Muster passt, verwende den `test`-Filter.

```jq
STRING | test(REGEX)
STRING | test(REGEX; FLAGS)
STRING | test([REGEX, FLAGS])
```

Dieser Filter gibt ein _boolesches_ Ergebnis aus.

```jq
"Hello World!" | test("W")    # => true
"Goodbye Mars" | test("W")    # => false
```

### Informationen über den Treffer

Wenn du den Teilstring extrahieren möchtest, der tatsächlich zum Muster gepasst hat, verwende den `match`-Filter.

```jq
STRING | match(REGEX)
STRING | match(REGEX; FLAGS)
STRING | match([REGEX, FLAGS])
```

Dieser Filter liefert:

- nichts, wenn es keinen Treffer gab, oder
- ein Objekt mit verschiedenen Eigenschaften, wenn es einen Treffer gab.

Dieses Beispiel sucht mit der Backref-Syntax `\1` nach zwei identischen aufeinanderfolgenden Vokalen.

```jq
"Hello World!" | match("([aeiou])\\1")
# => empty

"Goodbye Mars" | match("([aeiou])\\1")
# => {
#      "offset": 1,
#      "length": 2,
#      "string": "oo",
#      "captures": [
#        {
#          "offset": 1,
#          "length": 1,
#          "string": "o",
#          "name": null
#        }
#      ]
#    }
```

Der `match`-Filter gibt für _jeden_ Treffer ein Objekt zurück.
Dieses Beispiel zeigt das Flag `"g"` in Aktion, um alle Vokale zu finden.

```jq
"Goodbye Mars" | match("[aeiou]"; "g")
# => { "offset": 1, "length": 1, "string": "o", "captures": [] }
#    { "offset": 2, "length": 1, "string": "o", "captures": [] }
#    { "offset": 6, "length": 1, "string": "e", "captures": [] }
#    { "offset": 9, "length": 1, "string": "a", "captures": [] }
```

### Erfasste Teilstrings

Ähnlich wie der `match`-Filter gibt der `capture`-Filter ein Objekt zurück, wenn es einen Treffer gab.

```jq
STRING | capture(REGEX)
STRING | capture(REGEX; FLAGS)
STRING | capture([REGEX, FLAGS])
```

Das zurückgegebene Objekt ist eine Zuordnung der **benannten Captures**.

```jq
"JIRAISSUE-1234" | capture("(?<project>\\w+)-(?<issue_num>\\d+)")
# => {
#      "project": "JIRAISSUE",
#      "issue_num": "1234"
#    }
```

### Nur die Teilstrings

Der `scan`-Filter ähnelt `match` mit dem Flag `"g"`.

```jq
STRING | scan(REGEX)
STRING | scan(REGEX; FLAGS)
```

`scan` gibt einen _Stream_ von Teilstrings aus.

```jq
"Goodbye Mars" | scan("[aeiou]")
# => "o"
#    "o"
#    "e"
#    "a"
```

Verwende den Array-Konstruktor `[...]`, um die Teilstrings zu erfassen.

```jq
"Goodbye Mars" | [ scan("[aeiou]") ]
# => ["o", "o", "e", "a"]
```

### Einen String aufteilen

Wenn du die Teile des Strings kennst, die du **behalten** möchtest, verwende `match` oder `scan`.
Wenn du die Teile kennst, die du **verwerfen** möchtest, verwende `split`.

```jq
STRING | split(REGEX; FLAGS)
```

<!-- prettier-ignore -->
~~~~exercism/caution
Der `split`-Filter in der **1-Arity**-Form behandelt sein Argument als **festen String**.

Um mit `split` einen regulären Ausdruck zu verwenden, **musst** du das zweite Argument angeben; ein leerer String ist in Ordnung.
~~~~

<!-- prettier-ignore-end -->

Ein Beispiel, das einen String an beliebigem Whitespace aufteilt.

```jq
"first   second           third fourth" | split("\\s+"; "")
# => ["first", "second", "third", "fourth"]
```

### Ersetzungen

Die Filter `sub` und `gsub` können den Eingabe-String umwandeln, indem sie die übereinstimmenden Teile der Eingabe durch einen Ersatz-String ersetzen.

Um nur den ersten Treffer zu ersetzen, verwende `sub`.
Um alle Treffer zu ersetzen, verwende `gsub`.

```jq
STRING | sub(REGEX; REPLACEMENT)
STRING | sub(REGEX; REPLACEMENT; FLAGS)
STRING | gsub(REGEX; REPLACEMENT)
STRING | gsub(REGEX; REPLACEMENT; FLAGS)
```

```jq
"Goodnight kittens. Goodnight mittens." | sub("night"; " morning")
# => "Good morning kittens. Goodnight mittens."

"Goodnight kittens. Goodnight mittens." | gsub("night"; " morning")
# => "Good morning kittens. Good morning mittens."
```

Der Ersatztext kann auf die gefundenen Teilstrings verweisen; verwende benannte Captures und [String-Interpolation][jq-interp].

```jq
"Some 3-letter acronyms: gnu, csv, png"
| gsub( "\\b(?<tla>[[:alpha:]]{3})\\b";     # find words 3 letters long
        "\(.tla | ascii_upcase)" )          # upper-case the match
# => "Some 3-letter acronyms: GNU, CSV, PNG"
```

## Flags

In allen oben genannten Filtern ist FLAGS ein String, der aus null oder mehr der unterstützten Flags besteht.

- `g` - Globale Suche (alle Treffer finden, nicht nur den ersten)
- `i` - Suche ohne Beachtung der Groß-/Kleinschreibung
- `m` - Mehrzeilenmodus ('.' passt auch auf Zeilenumbrüche)
- `n` - Leere Treffer ignorieren
- `p` - Sowohl der s- als auch der m-Modus sind aktiviert
- `s` - Einzeilenmodus ('^' -> '\A', '$' -> '\Z')
- `l` - Längstmögliche Treffer finden
- `x` - Erweitertes Regex-Format (Whitespace und Kommentare ignorieren)

Zum Beispiel

```jq
"JIRAISSUE-1234" | capture("(?<project>\\w+)-(?<issue_num>\\d+)")

# or with Extended formatting

"JIRAISSUE-1234" | capture("
                     (?<project>   \\w+ )  # the Jira project
                     -                     # followed by a hyphen
                     (?<issue_num> \\d+ )  # followed by digits
                   "; "x")
```
