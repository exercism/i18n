# Anweisungen

In dieser Übung schreibst du eine generische (/ magische!) TreasureChest, um einen Schatz aufzubewahren.

## 1. Definiere den Typ TreasureChest

Definiere einen parametrischen Typ `TreasureChest{T}` mit zwei Feldern.

- Ein Feld `password` vom Typ `String`, in dem das Passwort der Schatztruhe gespeichert wird.
- Ein Feld `treasure` vom Typ `T`, in dem der Schatz gespeichert wird.
Dieser Wert ist generisch, sodass der Schatz alles Mögliche sein kann.

```julia-repl
julia> chest = TreasureChest{String}("password", "gold")
TreasureChest{String}("password", "gold")
```



## 2. Definiere die Funktion get_treasure()

Diese Funktion sollte zwei Argumente entgegennehmen.

- Einen `String` (zum Ausprobieren eines Passworts)
- Einen Typ `TreasureChest`

Diese Funktion sollte das übergebene Passwort mit dem `password` in der `TreasureChest` abgleichen.

- Wenn die Passwörter übereinstimmen, gib den Schatz zurück.
- Wenn die Passwörter nicht übereinstimmen, gib `nothing` zurück.

```julia-repl
julia> get_treasure("password", chest)
"gold"

julia> get_treasure("wrong", chest)
# no output

julia> isnothing(get_treasure("wrong", chest))
true
```

## 3. Definiere die Funktion multiply_treasure()

Diese Funktion sollte zwei Argumente entgegennehmen.

- Einen ganzzahligen Multiplikator `n`.
- Einen Typ `TreasureChest{T}`.

Die Funktion sollte eine neue `TreasureChest{Vector{T}}` zurückgeben, mit
- demselben Passwort wie das Original
- dem vervielfachten Schatz als `Vector{T}` der Länge `n`, wobei der ursprüngliche Schatz `n` mal wiederholt wird.

```julia-repl
julia> multiply_treasure(3, chest)
TreasureChest{Vector{String}}("password", ["gold", "gold", "gold"])
```
