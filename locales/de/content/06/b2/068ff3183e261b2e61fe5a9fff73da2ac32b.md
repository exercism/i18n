# If, Elseif, Else

Bedingte Anweisungen mit `if`, `elseif` und `else` sind ein grundlegender Teil des Kontrollflusses eines Programms.
Die `if`-Anweisung wertet einen Ausdruck aus und führt den Codezweig aus, wenn er `true` ergibt.

```php
<?php

if ($expression) {
    // .. executed if $expression is true
}
```

Wenn der Ausdruck kein boolescher Wert ist, bestimmt die Auswertung, ob der Wert als „wahr“ oder als „nicht falsch“ gilt.
In PHP gelten die folgenden Werte als falsch:

- boolescher Wert `false`
- Ganzzahl `0`
- Gleitkommazahl `0.0` und `-0.0`
- ein leeres Array `[]`
- ein leerer String `""` oder ein numerischer String `"0"`
- `null`

Alle anderen Werte gelten als wahr.

## Auf mehrere Bedingungen reagieren

An eine `if`-Anweisung kannst du mit `elseif` und `else` mehrere Bedingungen anhängen.

```php
<?php

if ($value === 0) {
    // .. do something
} elseif ($value === 1) {
    // .. do something else
} else {
    // ,, do this if nothing else
}
```

Es wird nur eine einzige bedingte Anweisung ausgeführt, die als wahr ausgewertet wurde.
Wenn also mehrere Bedingungen wahr ergeben können, ist die Reihenfolge wichtig, in der sie geschrieben sind.

```php
<?php

if (true) {
    // .. always do something
} elseif (true)
    // .. will never be executed
} else {
    // .. will never be executed
}
```
