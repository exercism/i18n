# Einführung

Typen, die die Schnittstelle `IEnumerable<T>` implementieren, bezeichnet man als _aufzählbar_. Alle eingebauten Sammlungstypen implementieren diese Schnittstelle.

Einen aufzählbaren Typ kannst du mit einer `foreach`-Schleife durchlaufen:

```csharp
var primes = new[] { 2, 3, 5, 7 };
foreach (var prime in primes)
{
    Console.Write(prime);
}
// => 2357
```

Um `IEnumerable<T>` zu implementieren, muss ein Typ eine einzige Methode implementieren: `IEnumerator<T> GetEnumerator()`. Wie du siehst, überlässt ein aufzählbarer Typ das eigentliche Durchlaufen einer Sammlung einem `IEnumerator<T>`-Typ. Diese Schnittstelle hat eine Eigenschaft und drei Methoden, die implementiert werden müssen:

- `public T Current { get; }`: ruft das aktuelle Element ab.
- `public bool MoveNext ();`: wechselt zum nächsten Element und gibt `true` zurück, wenn der Wechsel zum nächsten Element erfolgreich war, und `false`, wenn nicht (es gibt keine weiteren Elemente).
- `public void Reset ();`: setzt den Enumerator auf seinen Ausgangszustand zurück (vor dem ersten Element).
