# Ergänzung zu den Anweisungen

## Implementierung

In dieser Übung siehst du eine Datei `cases_test.go`.
Sie enthält die Testfälle, die in `leap_test.go` verwendet werden.
Du kannst diese Datei größtenteils ignorieren.

Wenn es dich aber interessiert... manchmal erzeugen wir die Testdaten aus einem [sprachübergreifenden Repository][problem-specifications-leap].
In diesem Repo haben Übungen manchmal eine [.json-Datei][problem-specifications-leap-json], die gemeinsame Testdaten enthält.
Einige unserer lokalen Übungen haben ein [Zwischenprogramm][local-leap-gen], das die Problem-Spezifikation als JSON nimmt und daraus Go-Structs macht, die in die Datei `<exercise>_test.go` eingespeist werden.
Die Go-spezifische Transformation dieser Daten steckt in der Datei `cases_test.go`.

[problem-specifications-leap]: https://github.com/exercism/problem-specifications/tree/master/exercises/leap
[problem-specifications-leap-json]: https://github.com/exercism/problem-specifications/blob/master/exercises/leap/canonical-data.json
[local-leap-gen]: https://github.com/exercism/go/blob/main/exercises/practice/leap/.meta/gen.go
