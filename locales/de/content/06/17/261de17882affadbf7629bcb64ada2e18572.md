# Einführung

In Swift ist ein `String` eine geordnete Sammlung von `Character`-Werten, die menschenlesbaren Text darstellen. Swift-Strings unterstützen Unicode-Zeichen und Emojis vollständig.

Du erzeugst einen String mit einem String-Literal, indem du den Text in doppelte Anführungszeichen (`"`) einschließt.
Sonderzeichen gibst du über Escape-Sequenzen an, zum Beispiel steht `\n` für einen Zeilenumbruch und `\"` für ein maskiertes doppeltes Anführungszeichen innerhalb eines String-Literals.

Einen leeren String schreibst du als ein Paar doppelter Anführungszeichen ohne Inhalt dazwischen (`""`).

```swift
let hello = "Hello, World!"
let sausage = "Weißwurst is a tasty sausage."
var family = "This is my family: 👨‍👩‍👦‍👦, this is our dog: 🐶"
var empty = ""
```
