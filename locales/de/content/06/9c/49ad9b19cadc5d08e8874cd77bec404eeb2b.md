# Tests

Du kannst eine Übung in deinem eigenen SAP-System implementieren. Führe die folgenden Schritte aus:

1. Erstelle ein SAP-Paket für alle Exercism-Übungen in deinem System (empfohlener Name: `$EXERCISM`)
2. Erstelle für jede Übung ein SAP-Paket als Unterpaket (empfohlener Name: `$EXERCISM_<name-of-exercise>`, Beispiel: `$EXERCISM_HELLO-WORLD`)
3. Erstelle eine ABAP-Klasse, die der Übung entspricht (Beispiel: `ZCL_HELLO_WORLD`)
4. Kopiere den Vorlagencode von Exercism in die Klasse
5. Pflege die Testklassen und kopiere den Code von Exercism in die Testklasse

Jetzt kannst du die Implementierung der Klasse abschließen und den Unit-Test ausführen, um zu sehen, ob deine Lösung richtig funktioniert.

Hinweis: Mit diesem Paket-Setup kannst du deine gesamte Arbeit sichern, indem du mit [abapGit](https://abapgit.org) ein Repository für das Paket `$EXERCISM` erstellst.

Weitere Details findest du in der [Exercism ABAP-Dokumentation](https://exercism.org/docs/tracks/abap).
