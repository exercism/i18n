# Einführung

Tupel sind eine leichtgewichtige Möglichkeit, eine feste Menge beliebiger Datentypen zusammenzufassen.
Ein Tupel hat keinen eigenen Namen; sobald man eine Datenstruktur benennt, wird daraus ein `struct`.
Die Felder eines Tupels haben keine Namen; auf sie greift man über Destrukturierung oder über ihre Position zu.

## Erstellung

Tupel werden immer mit einem Tupel-Ausdruck erzeugt:

```rust
// pointless but legal
let unit = ();
// single element
let single_element = ("note the comma",);
// two element
let two_element = (123, "elements can be of differing types");
```

Tupel können eine beliebige Anzahl von Elementen haben.

## Zugriff durch Destrukturierung

Es ist möglich, auf die Elemente eines Tupels durch Destrukturierung zuzugreifen.
Das bedeutet einfach, dass du den einzelnen Elementen des Tupels Variablennamen zuweist und es dabei verbrauchst.

```rust
let (elem1, _elem2) = two_element;
assert_eq!(elem1, 123);
```
