# Überblick

PowerShell ist eine dynamische und implizit typisierte Skriptsprache von Microsoft (_unterstützt aber auch [stark typisierte][strong typed] Variablen_), die vor allem auf die Automatisierung von Aufgaben und die Verwaltung von Konfigurationen ausgerichtet ist.

PowerShell unterstützt imperative, funktionale, objektorientierte und sogar Pipeline-orientierte Programmierung.

PowerShell wurde auf der .NET-Plattform aufgebaut und erstmals 2006 veröffentlicht.
In allen modernen Windows-Versionen ist es standardmäßig enthalten und lässt sich auch auf Mac und Linux installieren.


## Variablen

Es gibt zwei übliche Wege, eine Variable in PowerShell zu definieren.

Variablennamen in PowerShell müssen mit einem `$` beginnen, und mit dem Zuweisungsoperator `=` bindest du den Variablennamen an einen Wert.

```powershell
> $intVar = 1
> $doubleVar = 2.0
> $stringVar = "Hello"

# Checking a variable type using the GetType() method
> Write-Host $doubleVar.GetType()
System.Double
```

Du kannst den Typ einer Variable auch explizit angeben, wenn du erzwingen oder verlangen möchtest, dass der Wert einen bestimmten Typ hat.
PowerShell versucht nach besten Kräften, den Wert von einem Typ in einen anderen umzuwandeln, wenn das möglich ist.

```powershell
# String represents a floating number can be converted to integer
> [int]$staticOne = "1.234"
> $staticOne
1

# String of letters can not be converted to double type
> [double]$staticTwo = "hello"
MetadataError: Cannot convert value "hello" to type "System.Double"
```

### Konstanten

Konstanten in PowerShell sind Variablen, die nach ihrer Definition weder **geändert** noch **entfernt** werden können.
Das bringt uns zum zweiten Weg, Variablen zu definieren: mit dem Cmdlet `New-Variable`.

```powershell
> New-Variable -Name "MyConstant" -Value 100 -Option Constant
> $MyConstant
100
```


## Funktionen

Funktionen werden in PowerShell mit dem Schlüsselwort `function` definiert.
Jede Funktion kann null oder mehr formale Parameter in den runden Klammern `()` haben, gefolgt vom Funktionsbereich, der mit `{` beginnt und mit `}` endet.

```powershell
function Greeting {
    return "Hello!"
}
```

Funktionen in PowerShell können Werte explizit mit dem Schlüsselwort `return` zurückgeben, nachdem sie mit der Syntax `FuncName $Arg` aufgerufen wurden.

```powershell
function AddTwoNumbers($NumOne, $NumTwo):
    $result = $NumOne + $NumTwo
    return $result

> AddTwoNumbers 10 20
30
```

## Kommentare

Einzelne Kommentare in PowerShell beginnen mit einem `#` und enden am Zeilenende.
Kommentarblöcke in PowerShell beginnen mit `<#` und enden mit `#>`.

```powershell
function Main() {
    #This is a comment
    <#
    And this is a comment block
    that can span multiple lines
    #>
}
```
