# Einführung

## Strings

Zeichen und Strings bilden die Grundlage für die Textdarstellung in Elm.
Man kann sich Strings als Listen von Zeichen vorstellen, und die meisten Funktionen aus `List` haben ihr Gegenstück im Modul `String`.

### Zeichen

Der Typ `Char` repräsentiert ein einzelnes Unicode-Zeichen und wird mit einfachen Anführungszeichen geschrieben, z. B. `'a'`.
Das Modul `Char` bietet Prädikatfunktionen (`Char -> Bool`), mit denen du Eigenschaften eines Zeichens prüfen kannst: `isUpper`, `isLower`, `isAlpha` und `isAlphaNum`.
Außerdem bietet das Modul Funktionen, um ein Zeichen umzuwandeln: `toUpper`, `toLower`, `toLocaleUpper` und `toLocaleLower`, sowie Funktionen, um es in seinen numerischen Unicode-Wert (`Int`) umzuwandeln und daraus zurück, nämlich `toCode` und `fromCode`.

### Strings

Der Typ `String` bietet eine eingebaute Darstellung für effiziente String-Manipulation und kann jede Folge von Unicode-Zeichen darstellen, z. B. "this is an Elm string."
Mehrzeilige Strings werden mit dreifachen doppelten Anführungszeichen dargestellt und dürfen nicht maskierte Anführungszeichen und Zeilenumbrüche enthalten.
```elm
"""
    This is a multiline string.
All line-breaks and whitespace,
are preserved. 
"""
```

### String-Funktionen

Das Modul `String` enthält alle Funktionen, die in der folgenden Tabelle zusammengefasst sind.
Zu den am häufigsten verwendeten Funktionen gehören:

`cons : Char -> String -> String` fügt ein Zeichen am Anfang eines Strings hinzu.
```elm
cons 'T' "he truth is out there" 
    --> "The truth is out there"
```

`(++): String -> String -> String` hängt zwei Strings aneinander.
```elm
"butter" ++ "fly" 
    --> "butterfly"
```

`split : String -> String -> List String` teilt einen String am angegebenen Trennzeichen in eine Liste von Strings auf.
```elm
split ";" "cat;dog;cow" 
    --> ["cat", "dog", "cow"]
```

`join : String -> List String -> String` fügt eine Liste von Strings mit einem angegebenen Trennzeichen zusammen.
```elm
join "a" ["H", "w", "ii", "n"] 
    --> "Hawaiian"
```
`replace : String -> String -> String -> String` ersetzt alle Vorkommen eines angegebenen Teilstrings.
```elm
replace "Hello" "Goodbye cruel" "Hello world." 
    --> "Goodbye cruel world."
```

`length : String -> Int` gibt die Anzahl der Zeichen in einem String zurück.
```elm 
length "Hello world." 
    --> 12
```

`toInt : String -> Maybe Int` versucht, einen String in `Just Int` umzuwandeln, und gibt für falsch formatierte Strings `Nothing` zurück.
```elm
toInt "-42" 
    --> Just -42
```    

`contains : String -> String -> Bool` prüft, ob der zweite String den ersten enthält.
```elm
contains "the" "theory" 
    --> True
```

`map : (Char -> Char) -> String -> String` wendet eine angegebene Funktion auf jedes `Char` im String an.
Beachte, dass die übergebene Funktion eine Abbildung von `Char` nach `Char` sein muss.
```elm
map (\c -> if c == '/' then '.' else c) "a/b/c" 
    --> "a.b.c"
```
