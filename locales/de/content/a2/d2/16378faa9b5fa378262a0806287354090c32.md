# Über

`Enum` ist ein sehr nützliches Modul, das eine Reihe von Algorithmen für die Arbeit mit Enumerables bereitstellt. Es bietet:

- Sortieren ([`sort/2`][enum-sort/2], [`sort_by/2`][enum-sort_by/2]),
- Filtern ([`filter/2`][enum-filter/2]),
- Gruppieren ([`group_by/3`][enum-group_by/3]),
- Zählen ([`count/2`][enum-count/2])
- Suchen ([`find/3`][enum-find/3]),
- Finden von Min-/Max-Werten ([`min/3`][enum-min/3], [`max/3`][enum-max/3]),
- Reduzieren ([`reduce/3`][enum-reduce/3], [`reduce_while/3`][enum-reduce_while/3]),

Und vieles mehr! Eine vollständige Liste findest du in der [Dokumentation des `Enum`-Moduls][enum-functions].

## Enumerable

Im Allgemeinen ist ein _Enumerable_ eine beliebige Datenstruktur, über die iteriert werden kann, also eine Sammlung. In Elixir ist ein Enumerable jeder Datentyp, der das [Protokoll][exercism-protocols] `Enumerable` implementiert. Das sind:

- [`List`][list]
- [`Map`][map]
- [`Range`][range]
- [`Stream`][stream]
- [`MapSet`][mapset]
- [`Function`][function]
- [`Date.Range`][date-range]
- [`IO.Stream`][io-stream]
- [`File.Stream`][file-stream]

Mach dir keine Sorgen, wenn du noch nicht alle kennst.

Jeder kann das `Enumerable`-Protokoll für seine eigene Datenstruktur implementieren.

## Reduce

Mit `Enum.reduce/2` kannst du das gesamte Enumerable zu einem einzelnen Wert _reduzieren_. Dazu wird eine spezielle Variable namens _Akkumulator_ verwendet. Der Akkumulator trägt den Zwischenzustand der Reduktion zwischen den Iterationen. Damit ist sie eine der mächtigsten Funktionen für Enumerables. Viele andere spezialisierte Funktionen lassen sich durch das allgemeinere `reduce` ersetzen. Zum Beispiel ...

Den größten Wert finden:

```elixir
Enum.max([4, 20, 31, 9, 2])
# => 31

Enum.reduce([4, 20, 31, 9, 2], nil, fn x, acc ->
  cond do
    acc == nil -> x
    x > acc -> x
    x <= acc -> acc
  end
end)

# => 31
```

Und sogar Mapping (allerdings muss das Ergebnis danach umgekehrt werden):

```elixir
Enum.map([1, 2, 3, 4, 5], fn x -> x + 10 end)
# => [11, 12, 13, 14, 15]

Enum.reduce([1, 2, 3, 4, 5], [], fn x, acc -> [x + 10 | acc] end)
# => [15, 14, 13, 12, 11]
```

## Maps abbilden

- Mit [`Map.new/2`][map-new]:
  ```elixir
  %{a: 1, b: 2}
  |> Map.new(fn {key, value} -> {key, value * 10} end)
  ```

- Mit [`Enum.into/3`][enum-into]:
  ```elixir
  %{a: 1, b: 2}
  |> Enum.into(%{}, fn {key, value} -> {key, value * 10} end)
  ```

- Mit [`Enum.map/2`][enum-map]:
  ```elixir
  %{a: 1, b: 2}
  |> Enum.map(fn {key, value} -> {key, value * 10} end)
  |> Enum.into(%{})
  ```
