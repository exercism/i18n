# Überblick

Da Clojure eine funktionale Sprache ist, sind Funktionen dort Bürger erster Klasse. Das bedeutet, dass sie wie Daten an andere Funktionen übergeben und von anderen Funktionen erzeugt werden können. Clojure bietet insbesondere einen reichen Satz von Funktionen höherer Ordnung, die aus bestehenden Funktionen neue Funktionen ableiten. Wir schauen uns hier vier wichtige Fälle an: `partial`, `comp`, `memoize` und `juxt`. Diese Funktionen, die neue Funktionen erzeugen, gehören zu einer breiteren Kategorie von Funktionen höherer Ordnung, etwa `map`, `reduce`, `apply`, `complement`, um nur einige zu nennen, die auf bestehenden Funktionen arbeiten.

## partial

Im Allgemeinen können wir bei einer bestehenden Funktion `my-function` mit den Parametern `p1, p2, ..., pN` einige ihrer Parameter `p1, p2, ..., pM` auf konstante Werte `v1, v2, ..., vM` festlegen. Das machen wir, indem wir `partial` so anwenden: `(partial my-function v1 v2 ... vM)`.

Das Ergebnis ist eine neue Funktion, die die ursprüngliche Funktion `my-function` anwendet und dabei `p1=v1, p2=v2, ..., pM=vM` festlegt. Unsere neue Funktion nimmt die übrigen Parameter `pM+1, pM+2, ..., pN` als Eingabewerte entgegen. Deren Werte wurden beim Anwenden von `partial` nicht angegeben:

```clojure
(def my-new-function 
  (partial my-function v1 v2 ... vM))
(my-new-function xM+1 xM+2 ... xN)
; => equivalent to (my-function v1 v2 ... vM xM+1 xM+2 ... xN)
```

Als einfaches Beispiel definieren wir eine Funktion `inc-by-9`, die um 9 erhöht, einen festen Betrag, egal was wir übergeben. Wir könnten eine solche Funktion so implementieren:

```clojure
(def inc-by-9 (partial + 9))
(inc-by-9 5)
; => 14
```

Als zweites Beispiel haben wir eine Funktion `generic-greetings`, die den Namen der Person, die wir begrüßen möchten, zusammen mit einer einleitenden und einer abschließenden Textnachricht verwendet:

```clojure
(defn generic-greetings
  [initial-text final-text name]
  (println (str initial-text name final-text)))
```

Und wir verwenden `partial`, um immer eine bestimmte Begrüßungsnachricht zu verwenden:

```clojure
(def say-hello-and-how-are-you-doing 
  (partial generic-greetings "Hello " ", how are you doing?"))
(say-hello-and-how-are-you-doing "Mary")
; => Hello Mary, how are you doing?
```

## comp

Mit `comp` lässt sich eine Komposition aus beliebig vielen Funktionen erstellen, die wir zusammensetzen möchten. Im Allgemeinen bedeutet das Zusammensetzen von `N` Funktionen `f1, f2, ..., fN`, diese Funktionen nacheinander anzuwenden und die Ausgabe der vorherigen Funktion an die nächste weiterzugeben. In mathematischer Schreibweise wird das so ausgedrückt:

```
f1 (f2 (... fN(x)))
```

In Clojure ist das äquivalent zu:

```clojure
(f1 (f2 (... (fN x))))
```

Indem wir `comp` verwenden, können wir eine neue Funktion erstellen, die diese Komposition für uns ausführt:

```clojure
(def my-function-composition 
  (comp f1 f2 ... fN))
(my-function-composition x)
; equivalent to
(f1 (f2 (... (fN x))))
```

Als Beispiel: Angenommen, wir möchten eine Reihe von Zahlen summieren und das Ergebnis dann mit 6 multiplizieren. Das geht so:

```clojure
(def six-times-result-sum 
  (comp (partial * 6) +))
(six-times-result-sum 3 2)
; = ((partial * 6) (+ 3 2))
; = (* 6 (+ 3 2))
; = 30
```

## memoize

`memoize` ermöglicht es, bereits berechnete Ergebnisse für eine gegebene Eingabe wiederzuverwenden. Bei derselben Eingabe liefert die *memoisierte* Funktion dasselbe Ergebnis, ohne es erneut berechnen zu müssen. Es nutzt die Tatsache aus, dass `clojure`-Funktionen standardmäßig *referenziell transparent* sind: Bei gleicher Eingabe liefern sie immer die gleiche Ausgabe, wodurch frühere Berechnungen leicht wiederverwendet werden können.

Um zu sehen, wie das funktioniert, verwenden wir einen künstlichen Fall, in dem die Funktion zwei Sekunden schläft, bevor sie die Ausgabe erzeugt, damit wir die *Berechnungszeit* vor und nach der Verwendung von `memoize` leicht vergleichen können.

```clojure
(defn my-time-consuming-fn
    "Original, time-consuming function"
    [x]
    (Thread/sleep 2000)
    (* x 2)
)

; We measure the time it takes for the original function
(time (my-time-consuming-fn 3))
; => "Elapsed time: 2007.785622 msecs"
; => 6

; We define a memoized function
(def my-memoized-fn 
  (memoize my-time-consuming-fn) )

; We call the memoized function and measure its execution time. 
; The first execution actually runs the function, taking
; similar time as the original.
(time (my-memoized-fn 3))
; => "Elapsed time: 2001.364052 msecs"
; => 6

; Subsequent calls reuse the previous computation, taking less
; time. Time is further reduced in additional calls.
(time (my-memoized-fn 3))
; => "Elapsed time: 1.190291 msecs"
; => 6

(time (my-memoized-fn 3))
; => "Elapsed time: 0.043701 msecs"
; => 6

; Changing the input makes the function be executed, so that
; we observe a similar computation time as the original 
(time (my-memoized-fn 4))
; => "Elapsed time: 2000.29306 msecs"
; => 8

; Again, repeating the same input will make the 
; execution be skipped, and the associated output returned
(time (my-memoized-fn 4))
; => "Elapsed time: 0.043701 msecs"
; => 8
```

## juxt

`juxt` erzeugt eine Funktion, die die an sie übergebenen Funktionen in der Reihenfolge von links nach rechts anwendet. Das Ergebnis ist ein Vektor, dessen Komponenten die einzelnen Ergebnisse jeder Funktion sind:

```clojure
((juxt f g h) x) ; => [(f x) (g x) (h x)]
```

Als einfaches Beispiel erzeugen wir eine Funktion, die das Produkt von x mit aufeinanderfolgenden Faktoren von 2 bis 5 berechnet:
```clojure
((juxt (partial * 2) (partial * 3) (partial * 4) (partial * 5)) 10) ; => [20 30 40 50]
```
