# Anhang zur Anleitung

## Implementierung

Definiere
`type Classification`
für die Klassifizierungswerte natürlicher Zahlen.
Für diesen Typ kannst du eine beliebige Darstellung wählen.

Definiere drei Konstanten des Typs Classification mit den Namen

```text
	ClassificationDeficient
	ClassificationPerfect
	ClassificationAbundant
```

Implementiere eine Funktion namens Classify, die einen int64-Eingabewert entgegennimmt und eine Classification sowie einen Fehlerwert zurückgibt.

Erstelle einen Fehler namens ErrOnlyPositive,
der zurückgegeben wird, wenn die Eingabe keine positive Ganzzahl ist.
