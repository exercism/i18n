# Überblick

Swift bietet Kontrollübertragungsanweisungen, mit denen du den Ausführungsfluss von Schleifen und switch-Anweisungen verändern kannst.
Neben `return` gibt es in Swift `continue`, `break`, Schleifenlabels und `fallthrough`.

## Continue

Die `continue`-Anweisung weist eine Schleife an, die aktuelle Iteration zu beenden und sofort mit der nächsten zu beginnen.
In einer `while`- oder `repeat-while`-Schleife springt sie direkt zur Bedingungsprüfung.
In einer `for-in`-Schleife rückt sie zum nächsten Element in der Sequenz vor.

```swift
var count = 1
while count < 6 {
    count += 1
    if count == 4 {
        continue
    }
    print(count)
}

// Prints:
// 2
// 3
// 5
// 6
```

## Break

Die `break`-Anweisung verlässt eine ganze Schleife oder switch-Anweisung sofort.
Die Ausführung wird in der ersten Codezeile nach der Schleife bzw. der switch-Anweisung fortgesetzt.

```swift
for fruit in ["banana", "grapes", "apple", "strawberry", "kiwi", "lemon"] {
    if !fruit.count.isMultiple(of: 2) {
        break
    }
    print(fruit)
}

// Prints:
// banana
// grapes
```

## Anweisungen mit Labels

In verschachtelten Schleifen kann es vorkommen, dass `break` oder `continue` eine äußere Schleife statt der innersten betreffen soll.
Du kannst eine Schleife mit einem Label versehen, indem du einen Namen und einen Doppelpunkt davorstellst (`labelName:`).
Dieses Label kannst du dann an `break` oder `continue` übergeben:

```swift
outerLoop: for fruit in ["banana", "grapes", "apple", "strawberry", "kiwi", "lemon"] {
    print("\n--- \(fruit) ---")
    for letter in fruit {
        guard letter != "n" else {
            break outerLoop
        }
        print(letter)
    }
}

// Prints:
// --- banana ---
// b
// a
```

## Fallthrough

In Swift fallen `switch`-Anweisungen standardmäßig nicht in den nächsten Fall durch; die Ausführung endet automatisch am Ende des passenden Falls.
Wenn die Ausführung ausdrücklich in den nächsten Fall übergehen soll, ohne dessen Muster auszuwerten, verwendest du das Schlüsselwort `fallthrough`:

```swift
let value = 1
switch value {
case 1:
    print("One")
    fallthrough
case 2:
    print("Two")
default:
    break
}

// Prints:
// One
// Two
```
