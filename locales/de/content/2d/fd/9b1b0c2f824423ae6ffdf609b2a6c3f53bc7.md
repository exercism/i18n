# Anleitung

Du arbeitest an einem Spiel für ein stromsparendes eingebettetes System und musst mehrere Hilfsfunktionen schreiben, die andere Teile des Spiels verwenden werden.

## 1. Berechne den Quotienten und den Rest einer Division

Der Quotient ist das Ergebnis einer Division.

```rust
fn divmod(dividend: i16, divisor: i16) -> (i16, i16)
```

Beispiel:

```rust
assert_eq!(divmod(10, 3), (3, 1));
```

## 2. Wähle Elemente an geraden Positionen aus einem Iterator aus

Damit lässt sich später eine Optimierung des Bildschirmpuffers umsetzen, verspricht zumindest dein Chef.

Iteratoren stellen die Methoden bereit, die im [`Iterator`-Trait](https://doc.rust-lang.org/std/iter/trait.Iterator.html) definiert sind. Diese Dokumentation ist recht umfangreich, weil sie viele Methoden anbieten. Hier sind die wichtigsten Eigenschaften:

- Ein Iterator ist ein Strom von Elementen beliebiger Länge
- Er hat eine [`enumerate`-Methode](https://doc.rust-lang.org/std/iter/trait.Iterator.html#method.enumerate), die für jeden Wert ein Tupel `(i, val)` zurückgibt
- Er hat eine [`filter`-Methode](https://doc.rust-lang.org/std/iter/trait.Iterator.html#method.filter), die eine Closure verwendet, um zu entscheiden, ob ein Element des Iterators ausgegeben wird
- Er hat eine [`map`-Methode](https://doc.rust-lang.org/std/iter/trait.Iterator.html#method.map), die eine Closure verwendet, um Elemente des Iterators zu verändern

Weil deine Funktion mit jeder Art von Iterator arbeiten kann, verwendet sie `impl`, um anzuzeigen, dass es sich um eine Trait-Instanz und nicht um ein einfaches Element handelt. Ebenso bedeutet die Syntax `<Item=T>` nur, dass es keine Rolle spielt, welche Art von Element der Iterator erzeugt; deine Funktion kann die geraden Elemente jedes Iterators liefern.

```rust
fn evens<T>(iter: impl Iterator<Item=T>) -> impl Iterator<Item=T>
```

Beispiele:

```rust
let mut even_ints = evens(0_u8..);
assert_eq!(even_ints.next(), Some(0));
assert_eq!(even_ints.next(), Some(2));
assert_eq!(even_ints.next(), Some(4));
assert_eq!(even_ints.next(), Some(6));
```

```rust
let mut evens_from_odds = evens(1_i16..);
assert_eq!(evens_from_odds.next(), Some(1));
assert_eq!(evens_from_odds.next(), Some(3));
assert_eq!(evens_from_odds.next(), Some(5));
assert_eq!(evens_from_odds.next(), Some(7));
```

## 3. Berechne die Manhattan-Distanz einer Position vom Ursprung

Damit du bequem mit Koordinaten arbeiten kannst, hast du ein Tupel-Struct `Position`:

```rust
struct Position(i16, i16);
```

Du musst eine Methode `manhattan` auf `Position` implementieren, die die [Manhattan-Distanz](https://en.wikipedia.org/wiki/Taxicab_geometry) dieser Position vom Ursprung (`Position(0, 0)`) zurückgibt.

```rust
impl Position {
    fn manhattan(&self) -> i16
}
```

Beispiel:

```rust
assert_eq!(Position(3, 4).manhattan(), 7);
```
