# Anleitung

Du hilfst bei einer Vogelzählung. Jeden Tag sitzt jemand in einer Hütte und
zählt, was vorbeifliegt, und die Zählungen des Tages kommen als Array zurück.

Alle fünf Aufgaben gehören in die Klasse `BIRD_SURVEY`.

## 1. Die Gesamtzahl

Addiere die Zählungen aller Tage.

```sather
BIRD_SURVEY::total_seen(|3, 0, 7|)
-- => 10
```

Eine Zählung ganz ohne Tage zählt null Vögel.

## 2. Der belebteste Tag

Gib die größte Zählung zurück. Wenn es keine Tage gab, ist die Antwort null.

```sather
BIRD_SURVEY::busiest_day(|3, 0, 7|)
-- => 7
```

## 3. Die belebten Tage

Bei wie vielen Tagen lag die Zählung über einer bestimmten Zahl?

```sather
BIRD_SURVEY::days_over(|3, 0, 7|, 2)
-- => 2
```

Über heißt wirklich über: eine Zählung von genau 2 zählt nicht.

## 4. Zu prüfende Hütten

Am ersten Tag der Zählung prüfst du eine Hütte, am zweiten Tag zwei und so
weiter. Wie viele Hüttenprüfungen sind das insgesamt?

```sather
BIRD_SURVEY::hides_to_check(4)
-- => 10
```

Das ist 1 + 2 + 3 + 4.

## 5. Der erste belebte Tag

Welcher Tag war der erste mit einer Zählung über einer bestimmten Zahl? Die
Tage werden ab null nummeriert, so wie die Positionen im Array. Wenn kein Tag
so belebt war, ist die Antwort `-1`.

```sather
BIRD_SURVEY::first_busy_day(|3, 0, 7|, 5)
-- => 2
BIRD_SURVEY::first_busy_day(|3, 0, 7|, 9)
-- => -1
```
