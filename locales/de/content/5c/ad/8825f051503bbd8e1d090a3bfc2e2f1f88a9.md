# Anweisungen

Implementiere ein grundlegendes reaktives System.

Reaktive Programmierung ist ein Programmierparadigma, bei dem es darum geht, wie Werte auf Basis anderer Werte berechnet werden. So kann sich eine Änderung eines Werts automatisch auf andere Werte ausbreiten, ähnlich wie in einer Tabellenkalkulation.

Implementiere ein grundlegendes reaktives System mit Zellen, deren Werte gesetzt werden können („Eingabe“-Zellen), und Zellen, deren Werte auf Basis anderer Zellen berechnet werden („Berechnungs“-Zellen). Implementiere die Aktualisierungen so, dass bei einer Änderung eines Eingabewerts die Werte sich ausbreiten, bis ein neuer stabiler Systemzustand erreicht ist.

Außerdem sollten Berechnungszellen das Registrieren von Callbacks für Änderungsbenachrichtigungen ermöglichen. Rufe die Callbacks einer Zelle auf, wenn sich der Wert der Zelle in einem neuen stabilen Zustand gegenüber dem vorherigen stabilen Zustand geändert hat.
