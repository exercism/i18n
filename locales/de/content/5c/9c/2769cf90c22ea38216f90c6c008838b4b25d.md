# Hilfe

Es gibt viele großartige kostenlose Online-Ressourcen für Lua, darunter:

1. [lua.org][8]
2. Eine sehr empfehlenswerte, ausführliche und maßgebliche Einführung in alle Aspekte der Programmierung mit Lua vom Chefarchitekten von Lua: [Programming in Lua, by Roberto Ierusalimschy][6]. Beachte, dass die erste Auflage (die Lua 5.0 behandelt) [online kostenlos verfügbar][9] ist.
3. Eine offizielle Definition der Sprache Lua findest du im [Lua 5.4 Reference Manual][7] von R. Ierusalimschy, L. H. de Figueiredo, W. Celes.
4. [Lua Style Guide][4]
5. [Learn Lua in 15 minutes][5]
6. Einige Optionen für Linting
    - [Lua Lint][10]
    - [Lua Inspect][11]
    - [luacheck][12]
    - [Detecting Undefined Variables][13]
