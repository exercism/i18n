# Anleitung

In dieser Übung baust du die Fehlerbehandlung für einen einfachen Rechner für Ganzzahlen.
Um es einfach zu halten, sind Methoden für die Addition, Multiplikation und Division bereits vorgegeben.

Das Ziel ist ein funktionierender Rechner, der einen String nach folgendem Muster zurückgibt: `16 + 51 = 67`, wenn er die Argumente `16`, `51` und `+` erhält.

```java
CalculatorConundrum calculator = new CalculatorConundrum();

calculator.calculate(16, 51, "+");
// => returns "16 + 51 = 67"

calculator.calculate(32, 6, "*");
// => returns "32 * 6 = 192"

calculator.calculate(512, 4, "/");
// => returns "512 / 4 = 128"
```

## 1. Implementiere die Methode calculate, um einige grundlegende Operationen zu unterstützen

Die zentrale Methode, die du in dieser Aufgabe implementierst, ist die Methode `CalculatorConundrum.calculate()`.
Sie nimmt drei Argumente entgegen.
Die ersten beiden Argumente `operand1` und `operand2` sind Ganzzahlen, auf die eine Operation angewendet wird.
Das dritte Argument `operation` ist vom Typ String, und für diese Übung musst du die folgenden Operationen implementieren:

- Addition mit dem String `+`
- Multiplikation mit dem String `*`
- Division mit dem String `/`

## 2. Behandle unzulässige Operationen

Passe die Methode `CalculatorConundrum.calculate()` an, um unzulässige Operationen zu behandeln:

- Wenn das Argument `operation` `null` ist, soll eine `IllegalArgumentException` mit der Meldung `Operation cannot be null` geworfen werden.
- Wenn das Argument `operation` `""` ist, soll eine `IllegalArgumentException` mit der Meldung `Operation cannot be empty` geworfen werden.
- Wenn das Argument `operation` eine andere Operation als `+`, `*` oder `/` ist, soll eine `IllegalOperationException` mit der Meldung `Operation '{operation}' does not exist` geworfen werden.

```java
calculator.calculate(10, 1, null);
// => throws IllegalArgumentException with message "Operation cannot be null"

calculator.calculate(10, 1, "");
// => throws IllegalArgumentException with message "Operation cannot be empty"

calculator.calculate(10, 1, "-");
// => throws IllegalOperationException with message "Operation '-' does not exist"
```

## 3. Behandle die Ausnahme, die beim Teilen durch null geworfen wird

In Java wird beim Versuch, durch null zu teilen, eine `ArithmeticException` geworfen.
Passe die Methode `CalculatorConundrum.calculate()` an, um diese Ausnahme abzufangen und dann eine `IllegalOperationException` mit der Meldung `Division by zero is not allowed` und der abgefangenen `ArithmeticException` als Ursache zu werfen.

```java
calculator.calculate(512, 0, "/");
// => throws IllegalOperationException with message "Division by zero is not allowed"
```
