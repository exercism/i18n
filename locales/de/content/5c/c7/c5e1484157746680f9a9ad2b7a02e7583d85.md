# Über

Das [`Stream`-Modul][stream] ist eine _faule_ Alternative zum _eifrigen_ [`Enum`-Modul][enum]. Streams:

- Implementieren das [_Enumerable-Protokoll_][enumerable].
- Sind komponierbar.
- Werden intern als Funktionen dargestellt.
- Können unendlich sein.

Streams eignen sich ideal für den Umgang mit langsamen Ressourcen und sehr großen, potenziell unendlichen Sammlungen. In allen anderen Fällen verwendest du stattdessen `Enum`.

[stream]: https://hexdocs.pm/elixir/Stream.html
[enum]: https://hexdocs.pm/elixir/Enum.html
[enumerable]: https://hexdocs.pm/elixir/Enumerable.html
