# Einführung

Ein Array ist auch eine _Sammlung_. Das bedeutet: Du kannst nicht nur über den Index auf seine Werte zugreifen, sondern mit einer `foreach`-Schleife auch über _alle_ seine Werte iterieren:

```csharp
char[] vowels = new [] { 'a', 'e', 'i', 'o', 'u' };

foreach (char vowel in vowels)
{
    // Output the vowel
    System.Console.Write(vowel);
}

// => aeiou
```
