# Anleitung

In dieser Übung beschäftigst du dich mit einem ferngesteuerten Auto, für das du endlich genug Geld gespart hast.

Die Autos starten mit vollen (100 %) Akkus.
Jedes Mal, wenn du das Auto mit der Fernbedienung fährst, legt es 20 Meter zurück und verbraucht ein Prozent des Akkus.
Der Spitzname des Autos ist erst bekannt, wenn es erstellt wurde.

Das ferngesteuerte Auto hat eine schicke LED-Anzeige, die zwei Informationen anzeigt:

- Die insgesamt gefahrene Strecke, angezeigt als: `"<METERS> meters"`.
- Die verbleibende Akkuladung, angezeigt als: `"Battery at <PERCENTAGE>%"`.

Wenn der Akku bei 0 % ist, kannst du das Auto nicht mehr fahren und die Akkuanzeige zeigt `"Battery empty"`.

## 1. Ein brandneues ferngesteuertes Auto erstellen

Implementiere die Funktion `new_remote_control_car/0`, die ein brandneues ferngesteuertes Auto-Objekt zurückgibt:

```jq
new_remote_control_car
# => {
#      "battery_percentage": 100,
#      "distance_driven_in_meters": 0,
#      "nickname": null
#    }
```

## 2. Ein brandneues ferngesteuertes Auto mit Spitznamen erstellen

Implementiere die Funktion `new_remote_control_car/1`, die ein brandneues ferngesteuertes Auto-Objekt mit einem angegebenen Spitznamen zurückgibt:

```jq
new_remote_control_car("Blue")
# => {
#      "battery_percentage": 100,
#      "distance_driven_in_meters": 0,
#      "nickname": "Blue"
#    }
```

## 3. Die Entfernung anzeigen

Implementiere die Funktion `display_distance/0`, die ein Auto-Objekt als Eingabe nimmt und den String für die Entfernung ausgibt, wie er auf der LED-Anzeige dargestellt wird:

```jq
new_remote_control_car | display_distance
# => "0 meters"
```

## 4. Den Akkustand anzeigen

Implementiere die Funktion `display_battery/0`, die ein Auto-Objekt als Eingabe nimmt und den String für den Akkustand ausgibt, wie er auf der LED-Anzeige dargestellt wird:

```jq
new_remote_control_car | display_battery
# => "Battery at 100%"
```

Wenn der Akku bei 0 % ist, zeigt die Akkuanzeige „Battery empty".

## 5. Das Fahren verändert den Akkustand und die gefahrene Strecke

Implementiere die Funktion `drive/0`, die:

- ein Auto-Objekt als Eingabe nimmt
- die Anzahl der gefahrenen Meter um 20 erhöht
- 1 % des Akkus verbraucht
- das veränderte Auto-Objekt ausgibt

```jq
new_remote_control_car("Red") | drive
# => {
#      "battery_percentage": 99,
#      "distance_driven_in_meters": 20,
#      "nickname": "Red"
#    }
```

## 6. Fahren mit leerem Akku berücksichtigen

Aktualisiere die Funktion `drive/0`, sodass sie die gefahrene Strecke nicht erhöht und den Akkustand nicht verringert, wenn der Akku leer ist (bei 0 %):

```jq
{
  battery_percentage: 0,
  distance_driven_in_meters: 2000,
  nickname: "Red"
} | drive
# => {
#      "battery_percentage": 0,
#      "distance_driven_in_meters": 2000,
#      "nickname": "Red"
#    }
```
