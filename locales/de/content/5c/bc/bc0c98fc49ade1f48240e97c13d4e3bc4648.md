# Einführung

## Result

Der Typ `Result` ist in der Sprache Elm die Lösung für das Melden von Fehlern und ermöglicht es, nach einem Fehler weiterzumachen. Er ähnelt dem Typ `Maybe` ein wenig, aber während `Maybe` von Funktionen zurückgegeben werden kann, die fehlschlagen können, verrät er dir nichts darüber, warum etwas fehlgeschlagen ist. `Result` enthält diesen Kontext darüber, warum etwas fehlgeschlagen ist.

Der Typ `Result` ist wie folgt definiert:

```elm
type Result error value
  = Ok value
  | Err error
```

In der Elm-Terminologie spricht man dabei von einer „custom type“-Definition.
Die `error` und `value` in `OK value` und `Error error` stehen für eine Typvariable, das heißt, sie kann jeder Typ sein, wie etwa `Int`, `Bool` oder `String`.
Ein `Result String Int` ist also eine Variable, die einen `Int` enthalten soll, und wenn ein Fehler auftritt, wird dieser als `String` dargestellt.
Es gibt ein [Result-Modul](https://package.elm-lang.org/packages/elm/core/latest/Result) mit vielen nützlichen Hilfsfunktionen für Result.
