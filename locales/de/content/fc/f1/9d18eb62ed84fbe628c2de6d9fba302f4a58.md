# Anleitung

Jede Routine, die die Tanzgruppe aufführt, baut auf demselben Warm-up auf und geht dann ihren eigenen Weg.

Der Stub gibt dir `WARM_UP` vor. Schreibe drei weitere Klassen darunter.

## 1. Die Jazz-Routine

`JAZZ_ROUTINE` übernimmt alles von `WARM_UP` unverändert und fügt nichts hinzu.

```sather
JAZZ_ROUTINE::counts
-- => 8
JAZZ_ROUTINE::describe
-- => "8 counts"
```

## 2. Die Stepptanz-Routine

`TAP_ROUTINE` übernimmt `counts` von `WARM_UP`, beschreibt sich aber auf seine eigene Art. Lass `describe` beim `include` weg und schreibe ein neues.

```sather
TAP_ROUTINE::counts
-- => 8
TAP_ROUTINE::describe
-- => "Tap: 8 counts"
```

## 3. Das Finale

`FINALE` übernimmt `counts` von `WARM_UP` unter dem Namen `warm_up_counts` und lässt `describe` weg. Dann hat es ein eigenes `counts`, das doppelt so groß ist wie das des Warm-ups, und ein eigenes `describe`.

```sather
FINALE::warm_up_counts
-- => 8
FINALE::counts
-- => 16
FINALE::describe
-- => "Finale: 16 counts"
```

Beachte, was das zeigt: `FINALE::counts` ist nicht `WARM_UP::counts`, und beide sind in derselben Klasse unter verschiedenen Namen verfügbar.
