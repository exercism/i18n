# Zeichen

Ein **Zeichen** ist ein einzelner Buchstabe, eine Ziffer, ein Leerzeichen oder ein Satzzeichen. Sathers Typ dafür ist `CHAR`, und ein Zeichen schreibst du zwischen einfache Anführungszeichen.

```sather
   initial : CHAR is
      return 'M';
   end;
```

Einfache Anführungszeichen für ein einzelnes Zeichen, doppelte für einen String. `'M'` und `"M"` sind verschiedene Typen und lassen sich nicht austauschen.

## Zeichen aus einem String

Ein String ist eine Reihe von Zeichen, und mit eckigen Klammern erreichst du ein einzelnes über seine Position, gezählt ab null. Das ist genau wie bei einem Array.

```sather
"Marlowe"[0]      -- 'M'
"Marlowe"[3]      -- 'l'
```

## Fragen zu einem Zeichen

| Aufruf | Antwort |
| --- | --- |
| `c.is_alpha` | Ist es ein Buchstabe? |
| `c.is_digit` | Ist es eine der Ziffern `0`–`9`? |
| `c.is_upper` | Ist es ein Großbuchstabe? |
| `c.is_lower` | Ist es ein Kleinbuchstabe? |

Jeder Aufruf gibt `true` oder `false` zurück.

```sather
'M'.is_alpha      -- true
'7'.is_alpha      -- false
'7'.is_digit      -- true
```

## Groß- und Kleinschreibung ändern

`.upper` liefert den Großbuchstaben eines Buchstabens, `.lower` den Kleinbuchstaben. Alles, was kein Buchstabe ist, wird unverändert zurückgegeben.

```sather
'm'.upper         -- 'M'
'M'.lower         -- 'm'
'7'.upper         -- '7'
```

## Zeichen als Zahlen

Jedes Zeichen hat eine Zahl. `.int` liefert sie, und `.char` verwandelt eine Zahl zurück in ein Zeichen.

```sather
'a'.int           -- 97
'b'.int           -- 98
98.char           -- 'b'
```

Die genauen Zahlen sind selten wichtig. Wichtig ist, dass die Buchstaben `a` bis `z` in Reihenfolge und nebeneinander liegen, sodass `'c'.int - 'a'.int` gleich 2 ist. Das zeigt, wie weit `c` im Alphabet steht. Genau das lässt ein Chiffrierrad funktionieren.
