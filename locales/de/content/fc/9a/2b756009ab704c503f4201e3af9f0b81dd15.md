# Einführung

## Zeichen

Der `char`-Typ in C# ist eine 16-Bit-Größe, die die kleinsten adressierbaren Bestandteile von Text darstellt.
Mehrere `char`s können einen String wie `"word"` bilden, oder `char`s lassen sich
einzeln verarbeiten. Ihre Literale stehen in einfachen Anführungszeichen, z. B. `'A'`.

`char`s in C# unterstützen die UTF-16-Unicode-Kodierung. Deshalb lässt sich neben dem
lateinischen Zeichensatz so ziemlich jedes auf der Welt verwendete Schriftsystem
darstellen, zum Beispiel der griechische Buchstabe `'β'`.

Es gibt viele eingebaute Bibliotheksmethoden, um `char`s zu untersuchen und zu
manipulieren. Du findest sie als statische Methoden der Klasse `System.Char`.

## StringBuilder

`char`s werden manchmal zusammen mit einem `StringBuilder`-Objekt verwendet.
Dieses Objekt hat Methoden, mit denen sich ein String
Zeichen für Zeichen aufbauen und bearbeiten lässt. Am Ende des Prozesses
kannst du `ToString` darauf aufrufen, um einen vollständigen String auszugeben.
