# Einführung

Die `guard`-Anweisung in Swift dient dazu, früh aus einer Swift-Funktion zurückzukehren, wenn eine notwendige Bedingung nicht erfüllt ist, die für die weitere Verarbeitung erfüllt sein muss, z. B.:

```swift
guard myValue >= 0 else { return 0 }
let root = myValue.squareRoot()
```

Hier prüft die `guard`-Anweisung, ob der boolesche Ausdruck nach dem Schlüsselwort `guard` wahr ergibt. Ist das der Fall, läuft die Verarbeitung mit dem Code nach der `guard`-Anweisung weiter (hier `let root = myValue.squareRoot()`. Andernfalls führt sie den Code im else-Zweig aus. Anders als eine `if`-Anweisung _muss_ eine `guard`-Anweisung einen else-Zweig haben, und anders als der else-Zweig eines if-else _muss_ der else-Zweig einer `guard`-Anweisung den Gültigkeitsbereich der `guard`-Anweisung verlassen. Das heißt, sie muss eine Kontrolltransferanweisung wie `return`, `continue` oder `break` verwenden, oder sie muss einen Fehler werfen bzw. das Programm beenden.
