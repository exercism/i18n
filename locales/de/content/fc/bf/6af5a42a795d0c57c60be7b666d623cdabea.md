# Char

`Char` ist ein Datentyp in Crystal, der einen 32-Bit-[Unicode][unicode]-Codepoint darstellt.
Seine Größe macht ihn speichereffizient und gibt ihm bestimmte Eigenschaften, die Strings nicht haben.
Er wird mit einfachen Anführungszeichen (`'`) erstellt und erlaubt nur, dass ein einziger Unicode-Codepoint darin steht.

```crystal
'a' # => 'a'
'a'.class # => Char
```

Es ist ganz üblich, mit Chars zu arbeiten, wenn du in Crystal mit Strings arbeitest, da einige Methoden der String-Klasse Chars zurückgeben oder Chars als Argumente nehmen.
Zum Beispiel gibt die Methode [`String#[]`][index] einen Char zurück, oder die Methode [`String#chars`][chars] gibt eine Sammlung von Chars zurück.

## Erhöhen / Verringern

Da ein Char ein 32-Bit-Unicode-Codepoint ist, unterstützt er das Erhöhen und Verringern. Wenn du also `'a'` hast, kannst du durch Addieren von eins `'b'` erhalten.

```crystal
'a' + 5
# => 'f'

'z' - 25
# => 'a'
```

Es gibt auch eine Methode namens [`Char#succ`][succ], die den nächsten Char in der Unicode-Tabelle zurückgibt, und [`Char#pred`][pred], die den vorherigen Char in der Unicode-Tabelle zurückgibt.

```crystal
'a'.succ
# => 'b'

'z'.pred
# => 'y'
```

## Verkettung

Da ein Char nur dazu gedacht ist, ein 32-Bit-Unicode-Codepoint darzustellen, können zwei Chars nicht verkettet werden.
Deshalb können Chars nur mit Strings verkettet werden.

```Crystal
'a' + "bc"
# => "abc"

'a' + 'b'
# => error: expected argument #1 to 'Char#+' to be Int or String, not Char
```

## Eigenschaftsmethoden

Crystal hat ein paar Methoden, um Informationen über ein Zeichen zu erhalten, etwa ob es eine Zahl oder ein Buchstabe ist oder ob es groß- oder kleingeschrieben ist.
Hier ist eine Liste einiger dieser Methoden; eine vollständige Liste findest du in der [Char API][char-api]:

| Methode                          | Beschreibung                                              |
| -------------------------------- | --------------------------------------------------------- |
| [`Char#number?`][number]         | Gibt `true` zurück, wenn der Char eine Zahl ist           |
| [`Char#letter?`][letter]         | Gibt `true` zurück, wenn der Char ein Buchstabe ist       |
| [`Char#lowercase?`][lowercase]   | Gibt `true` zurück, wenn der Char kleingeschrieben ist    |
| [`Char#uppercase?`][uppercase]   | Gibt `true` zurück, wenn der Char großgeschrieben ist     |
| [`Char#ascii?`][ascii]           | Gibt `true` zurück, wenn der Char ein ASCII-Zeichen ist   |
| [`Char#whitespace?`][whitespace] | Gibt `true` zurück, wenn der Char ein Leerraumzeichen ist |

## Umwandeln

### Umwandeln zwischen Codepoints und Chars

Da ein Char ein 32-Bit-Unicode-Codepoint ist, kannst du zwischen Chars und Codepoints (Int) umwandeln.
Das kannst du mit der Methode [`Char#ord`][ord] machen, die den Codepoint des Chars zurückgibt, oder mit der Methode [`Int#chr`][chr], die den Char des Codepoints zurückgibt.

```crystal
'a'.ord
# => 97

97.chr
# => 'a'
```

### Umwandeln zwischen Typen

Wie bei anderen Datentypen gibt es bei Chars ein paar Methoden zum Umwandeln zwischen Typen.
Die gebräuchlichste ist die Methode `Char#to_s`, die den Char in einen String umwandelt. Es gibt aber auch die Methode `Char#to_i`, die den Char in einen Int umwandelt, und die Methode `Char#to_f`, die den Char in einen Float umwandelt.

```crystal
'a'.to_s
# => "a"

'4'.to_i
# => 4

'a'.to_i
# => Error: Invalid integer: a (ArgumentError)
```
