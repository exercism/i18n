# Maps und Sets

| Typ | Enthält | Nachschlagen über |
| --- | --- | --- |
| `ARRAY{T}` | Werte in Reihenfolge | Position |
| `FMAP{K,T}` | Schlüssel-Ziel-Paare | Schlüssel |
| `FSET{T}` | Werte, keine Wiederholungen | Zugehörigkeit |

## FMAP

```sather
   m ::= #FMAP{STR,INT};
   m := m.insert("emu", 2);
   m.get("emu")          -- 2
   m.has_ind("emu")      -- true
   m.size                -- 1
   m := m.delete("emu");
```

`m["emu"]` ist **nicht**, wie du eine Map liest: `FMAP` hat keine solche Routine, und diese Zeile lässt sich nicht kompilieren. Du nimmst `get`.

### Fehlende Schlüssel

`get` auf einen Schlüssel, der nicht da ist, liefert den leeren Wert des Typs, statt sich zu beschweren: `0`, `false` oder void. Ein void `STR` scheitert nicht dort, wo er entsteht; er scheitert später, dort, wo er schließlich verwendet wird. Erst `has_ind` zu prüfen, ist die Gewohnheit, die sich lohnt.

## FSET

```sather
   s ::= #FSET{STR};
   s := s.insert("emu");
   s.has("emu")          -- true
   s.size                -- 1
   s := s.delete("emu");
```

Sets lassen sich kombinieren:

```sather
   a.union(b)            -- in either
   a.intersect(b)        -- in both
   a.difference(b)       -- in a but not b
   a.is_subset(b)
```

## Zurückschreiben und kopieren

`insert` und `delete` liefern den Container, den du von jetzt an verwenden sollst. Meist ist das dasselbe Objekt, das an Ort und Stelle geändert wurde; wenn es wachsen muss, ist es ein neues, größeres. Also:

```sather
   m := m.insert(k, v);     -- always
```

und der Name auf der linken Seite ist danach der einzige, dem du vertrauen kannst. Ein anderer Name für dieselbe Map, der vor dem `insert` angelegt wurde, kann veraltet sein.

Wenn du eine unabhängige Kopie behalten willst, lege zuerst eine an:

```sather
   n ::= m.copy.insert(k, v);      -- m is unchanged
```

mit einem Haken: Eine Map, in die noch nie etwas eingefügt wurde, ist **void**, und `copy` auf einer void Map schlägt fehl. `insert`, `get`, `has_ind` und `size` kommen alle mit einer void Map zurecht (`#FMAP{K,T}` ist void, und einzufügen ist genau das, wodurch eine Map erst entsteht), `copy` aber nicht.

`HMAP` und `HSET` sind die Varianten, die sich immer nur an Ort und Stelle ändern. Sie sind schneller, wenn du etwas Großes aufbaust, aber sie sind die falsche Standardwahl, während du lernst.

## Durchlaufen

| Iterator | Liefert |
| --- | --- |
| `m.ind!` | jeden Schlüssel |
| `m.target!` | jedes Ziel |
| `m.pair!` | jeden Schlüssel und jedes Ziel zusammen |
| `s.elt!` | jeden Wert eines Sets |

Weder eine Map noch ein Set hat eine Reihenfolge. Zwei Durchläufe können sie unterschiedlich durchlaufen, also schreibe nie etwas, das davon abhängt, was zuerst kommt.

```sather
   loop
      #OUT + guide.ind! + "\n";
   end;
```
