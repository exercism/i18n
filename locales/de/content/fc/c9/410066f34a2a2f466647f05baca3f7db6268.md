# Debug

Wenn ein Test fehlschlägt, wird eine Nachricht angezeigt, die beschreibt, was schiefgelaufen ist und bei welcher Eingabe.

Auch das Ausgeben von Werten und Inhalten von Variablen kann dir helfen zu verstehen, was passiert.
PHP kann Werte so ausgeben:

- `echo 'Debug message';`, um einen String deiner Wahl auszugeben
- `var_dump($variable);`, um mehr über einen Wert zu erfahren, z. B. über den Typ, den PHP sieht
