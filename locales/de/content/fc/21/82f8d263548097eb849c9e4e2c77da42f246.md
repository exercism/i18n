# Anleitung

Wir gründen einen Käseclub, der maschinelles Lernen (ML) einsetzt, um neue Käsesorten auszuwählen, die wir unseren käseliebenden Kunden auf Basis ihrer Historie und ihres Geschmacks anbieten können.

Neue Mitglieder müssen eine erste Umfrage ausfüllen, damit wir zu Beginn ein paar grundlegende Daten sammeln können.
Dabei hat sich herausgestellt, dass es eine Untergruppe von emphatischen Kunden gibt, denen es an Nuancen in ihren Kritiken fehlt.
Da dies einen differenzierteren Algorithmus unwiderruflich verzerren kann, gibt es einen separaten Algorithmus, der auf ihre Bedürfnisse zugeschnitten ist.
Du sollst einige Hilfsfunktionen bereitstellen, um ihre Daten aufzubereiten.

~~~~exercism/note
Auch wenn es verschiedene Wege geben mag, die folgenden Aufgaben zu lösen, lässt sich jede mit höchstens zwei Funktionen höherer Ordnung lösen.
~~~~

## 1. Kunden klassifizieren

Das Bewertungssystem beruht auf einer Fünf-Sterne-Basis und besteht einfach aus den Ganzzahlen `1:5`.
Die emphatischen Kunden vergeben nur Bewertungen von `1` oder `5`, und wir wollen wissen, ob ein Kunde dieses Verhalten zeigt.

Implementiere `all_15()`, die einen Vektor von Bewertungen entgegennimmt und `true` zurückgibt, wenn alle Bewertungen entweder `1` oder `5` sind, und andernfalls falsch.

```R
all_15(c(2, 3, 4, 4, 1))
#> [1] FALSE

all_15(c(1, 5, 5, 1, 5))
#> [1] TRUE
```

## 2. Kunden benennen

Wir müssen den Kundennamen (oder die ID) mit den jeweiligen Bewertungen verknüpfen.

Implementiere `name_customers()`, die einen Vektor von Namen und eine Liste von Bewertungen entgegennimmt und sie zu einer Liste von Listen „zippt“.

Die inneren Listenelemente sollten die Namen `name` und `rating` haben.

```R
names <- c("c1", "c2")
ratings <- list(c(2, 3, 5), c(1, 1, 5))
name_customers(names, ratings)
#> [[1]]
#> [[1]]$name
#> [1] "c1"

#> [[1]]$rating
#> [1] 2 3 5

#> [[2]]
#> [[2]]$name
#> [1] "c2"

#> [[2]]$rating
#> [1] 1 1 5
```

## 3. Emphatische Kunden herausfiltern

Wir müssen die emphatischeren Kunden von den anderen trennen.

Implementiere `emphatics()`, die Kunden und Bewertungen entgegennimmt.
Sie gibt eine Liste zurück, die auf diejenigen beschränkt ist, die nur Bewertungen mit `1` oder `5` Sternen abgeben.

```R
# names and ratings as in the task 2 example

emphatics(names, ratings)
#> [[1]]
#> [[1]]$name
#> [1] "c2"

#> [[1]]$rating
#> [1] 1 1 5
```

## 4. Bewertungen in Binärwerte umwandeln

Da die emphatischen Kunden nur die Bewertungen `1` und `5` verwenden, ist es recheneffizienter, diese in `0` und `1` umzuwandeln.

Implementiere `to_binary()`, die einen Vektor emphatischer Bewertungen entgegennimmt.
Sie gibt binäre Bewertungen zurück, wobei `1` in `0` und `5` in `1` umgewandelt wurde.

```R
to_binary(c(1, 1, 5, 5, 1))
#> [1] 0 0 1 1 0
```

## 5. Durchschnittliche Bewertungen über die Zeit berechnen

Du möchtest die Empfehlungen für alle einzelnen Kunden (nicht nur für die emphatischen) mit der Zeit immer weiter verbessern, während du ihren Geschmack besser verstehst.

Implementiere `satisfactions()`, die einen Vektor von Bewertungen entgegennimmt.
Sie gibt einen Vektor der kumulativen Durchschnittsbewertungen bis zu diesem Punkt zurück.
Runde die Ergebnisse auf 2 Nachkommastellen.

Hoffentlich steigen die Zahlen immer weiter, für zufriedene Kunden!

```R
satisfactions(c(1, 2, 2, 3))
#> [1] 1.00 1.50 1.67 2.00
```
