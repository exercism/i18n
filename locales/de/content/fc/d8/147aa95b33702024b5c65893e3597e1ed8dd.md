Eine Übung auf Exercism zu lösen ist nur der erste Schritt.
Das eigentliche Lernen kommt danach!

Diese Woche haben wir den neuen Tab „Dig Deeper“ bei den Übungen eingeführt. Er soll dir helfen, über das Lösen hinauszugehen und die Feinheiten und die Vor- und Nachteile einer Übung zu erkunden, ohne dafür einen Mentor fragen zu müssen.

## Einführung

Die Lösungen unserer Übungen sind erstaunlich vielfältig.
Die einfachste „richtige“ Übung in den meisten Tracks ist `TwoFer`.
Eine typische Lösung sieht so aus (das hier ist Ruby, aber in den meisten Sprachen ist es ähnlich):

```ruby
module TwoFer
  def self.two_fer(name='you')
    "One for #{name}, one for me."
  end
end
```

Von den letzten 500 Lösungen, die die Tests bestanden haben, waren allerdings über 350 einzigartig 😲
Und selbst wenn du Dinge wie Leerzeichen und Variablennamen normalisierst, sind immer noch mehr als die Hälfte davon wirklich einzigartige Lösungen.

Das macht es ungemein spannend zu sehen, wie unterschiedlich alle an die Aufgaben herangehen.
Aber es ist auch völlig unrealistisch. Auf Exercism gibt es Millionen von Lösungen, und sie alle zu lesen würde buchstäblich ein Leben lang dauern.

Aber! Da unser Team die Übungen entworfen und Hunderttausende von Menschen dabei begleitet hat, hat es einen ziemlich guten Überblick darüber, wie unterschiedlich die Leute vorgehen.
Deshalb haben wir den neuen Tab „Dig Deeper“ hinzugefügt, der die verschiedenen idiomatischen (oder nicht idiomatischen, aber interessanten) Wege hervorhebt, eine Übung zu lösen.

## Ein Beispiel

Schauen wir uns ein Beispiel an, um das in Aktion zu sehen.
In C# gibt es verschiedene Möglichkeiten, einen String umzukehren.

Du kannst die Methode `Array.Reverse()` verwenden:
```csharp
var chars = input.ToCharArray();
Array.Reverse(chars);
return new string(chars);
```

Oder du nimmst einen kürzeren Ansatz auf LINQ-Basis:
```csharp
return new string(input.Reverse().ToArray());
```

oder du verwendest einen `StringBuilder`:
```
var chars = new StringBuilder();
for (var i = input.Length - 1; i >= 0; i--)
{
    chars.Append(input[i]);
}
return chars.ToString();
```

oder du gehst sogar etwas weniger idiomatisch vor (aber performanter!) und verwendest `Span<T>`:

```csharp
Span<char> chars = stackalloc[input.Length];
for (var i = 0; i < input.Length; i++)
{
    chars[input.Length - 1 - i] = input[i];
}
return new string(chars);
```

Wir nennen jeden davon einen Ansatz, und jeder hat einen eigenen Artikel, der ihn erklärt.
Die Seite „Dig Deeper“ für diese Übung führt sie zusammen und enthält außerdem einen Artikel zur Performance, der die Vor- und Nachteile beleuchtet.
