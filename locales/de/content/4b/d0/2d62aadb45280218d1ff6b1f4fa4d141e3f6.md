# Tests

Die Testsuites der PureScript-Übungen kannst du mit dem Tool spago aus dem Übungsverzeichnis heraus ausführen:

    cd <exercism-workspace>/purescript/<exercise name>
    spago test

Dabei ist <exercism-workspace> das Arbeitsverzeichnis der Kommandozeile.

Zum Beispiel:

    cd ~/exercism/purescript/accumulate
    spago test
