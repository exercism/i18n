# Community-Beiträge pausieren

Manche Repositories haben nicht die Ressourcen, Issues oder Pull Requests von Nutzern, die keine Maintainer sind, zu triagieren und zu prüfen.
Das Pausieren von Community Solutions
Wenn ein Repository diesen Workflow aktiviert hat, kommentiert es automatisch ein neu eröffnetes Issue oder einen neu eröffneten Pull Request, wenn der Autor _kein_ Mitglied der GitHub-Organisation von Exercism ist.
Der Kommentar schlägt dem Nutzer vor, zuerst ein Topic im Exercism-Forum zu eröffnen.

## Workflow aktivieren

Füge die [Datei .github/workflows/pause-community-contributions.yml](https://github.com/exercism/github-actions/blob/b5424c17f661f5529493258a1ad480013351aa9e/.github/workflows/pause-community-contributions.yml) in dein Repository ein.

## Workflow deaktivieren

Entferne die Workflow-Datei aus deinem Repository.

## Quelle

Der Workflow ist in der Datei `.github/workflows/pause-community-contributions.yml` definiert.
