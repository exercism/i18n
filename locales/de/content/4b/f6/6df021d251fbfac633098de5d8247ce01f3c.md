# Variadische Parameter

[_Variadische Parameter_][variadic-parameters] in Swift erlauben es, null oder mehr Werte desselben Typs an einen einzelnen Parameter einer Funktion zu übergeben.
Dazu hängt man `...` an die Typannotation des Parameters an.

Diese Werte werden automatisch zu einem Array gruppiert, dessen Elemente den gleichen Typ wie der Typ des variadischen Parameters haben.

```swift
func geometricMean(_ numbers: Double...) -> Double {
  var total = 1.0
  for number in numbers {
      total *= number
  }
  return pow(total, 1.0 / Double(numbers.count))
}

geometricMean(1, 2, 3, 4, 5)
// Returns 2.605171084697352
```

Bei variadischen Parametern hat Swift zwei Einschränkungen:

1. Swift erlaubt es Funktionen nur, einen variadischen Parameter zu haben. Es wurde entschieden, dass diese Einschränkung in einer zukünftigen Version von Swift entfernt wird, aber derzeit besteht sie noch.
2. Wenn eine Funktion Parameter hat, die in der Definition auf den variadischen Parameter folgen, muss der erste Parameter nach dem variadischen Parameter _zwingend_ ein Argument-Label haben.

[variadic-parameters]: https://docs.swift.org/swift-book/documentation/the-swift-programming-language/functions/#Variadic-Parameters
