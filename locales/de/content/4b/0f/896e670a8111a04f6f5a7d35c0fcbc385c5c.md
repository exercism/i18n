## Fehlermeldungen (Exceptions)

Manchmal ist es notwendig, eine [Exception auszulösen](https://docs.python.org/3/tutorial/errors.html#raising-exceptions). Wenn du das tust, solltest du immer eine **aussagekräftige Fehlermeldung** angeben, die erkennen lässt, woher der Fehler stammt. Das macht deinen Code lesbarer und hilft beim Debugging erheblich. Wenn du weißt, dass die Fehlerquelle von einem bestimmten Typ sein wird, kannst du eine der [eingebauten Fehlertypen](https://docs.python.org/3/library/exceptions.html#base-classes) auslösen, solltest aber trotzdem eine aussagekräftige Meldung angeben.

Diese Übung verlangt, dass du die [raise-Anweisung](https://docs.python.org/3/reference/simple_stmts.html#the-raise-statement) verwendest, um einen `ValueError` zu „werfen“, wenn das Spiel beendet ist, der Spieler aber weiterspielen möchte. Die Tests bestehen nur, wenn du die `exception` sowohl `raise`st als auch eine Meldung dazu angibst.

Um einen `ValueError` mit einer Meldung auszulösen, schreibst du die Meldung als Argument an den Typ `exception`:

```python
# when player tries to play, but the game is already over.
raise ValueError("The game has already ended.")
```
