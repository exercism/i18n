# Einführung

## Boolesche Werte in Julia

Wahrheitswerte werden durch den Typ `Bool` dargestellt.
Er enthält nur zwei Werte: `true` und `false`.

```julia-repl
julia> true
true

julia> false
false
```

## Boolesche Operatoren

In Julia gibt es drei boolesche Operatoren.

`&&` steht für das boolesche „und“.
Er ergibt `true`, wenn die Ausdrücke auf *beiden* Seiten von `&&` `true` sind.

```julia-repl
julia> true && true
true

julia> true && false
false
```

`||` steht für das boolesche „oder“.
Er ergibt `true`, wenn ein Ausdruck auf *einer* der beiden Seiten von `||` `true` ist.

```julia-repl
julia> true || true
true

julia> false || true
true
```

`!` steht für das boolesche „nicht“.
Er vertauscht die Werte `true` und `false`.

```julia-repl
julia> !true
false

julia> !false
true
```

Bei längeren und komplizierteren Ausdrücken ist es am besten, runde Klammern zu verwenden, um deine Absicht klar zu machen.

```julia-repl
julia> (true || false) && (false && true)
false
```
