# Über

PHP bietet eine Reihe von Operatoren für arithmetische Operationen. Bei seinen arithmetischen Operatoren folgt PHP der üblichen mathematischen Reihenfolge der Operationen. Die Operatoren, die PHP bereitstellt, sind:

* Identität (+)
* Negation (-)
* Addition (+)
* Subtraktion (-)
* Multiplikation (*)
* Division (/)
* Modulo (%)
* Potenzierung (**)

Schauen wir uns jeden einzelnen an und wie er verwendet werden kann:

## Identität (+)

Der Identitätsoperator (+) arbeitet mit einem einzelnen Wert (unärer Operator). Er ergibt den `float`- oder `int`-Wert der Variable.

```php
$value = '42';
$answer = +$value; // 42 (int)
```

## Negation (-)

Der Negationsoperator arbeitet mit einem einzelnen Wert (unärer Operator) und gibt das Gegenteil des numerischen Werts zurück.

```php
$forward = 65;
$reverse = -$forward; // -65
```

## Addition (+) und Subtraktion (-)

Der Additionsoperator addiert die beiden Werte links und rechts von ihm, während der Subtraktionsoperator den rechten Wert vom linken Wert subtrahiert.

```php
$apples = 5;
$yourApples = 0;

$apples = $apples - 2; // 3
$yourApples = $yourApples + 2; 2
```

## Division (/)

Der Divisionsoperator liefert das Ergebnis der Division des linken Werts durch den rechten Wert. Ist der rechte Wert 0, wird ein Fehler `DivisionByZeroError` ausgelöst.

```php
$slicesOfPizza = 8;
$people = 4;
$slicesPerPerson = $slicesOfPizza / $people; // 2
```

## Multiplikation (*)

Der Multiplikationsoperator gibt das Ergebnis der Multiplikation des linken und des rechten Werts zurück.

```php
$tires = 4;
$priceOfTire = 250;
$totalCost = $tires * $priceOfTire; // 1000
```

## Modulo (%)

Der Modulo-Operator gibt den Rest zurück, wenn der linke Wert durch den rechten Wert geteilt wird. Dieser Operator ist sehr nützlich, um festzustellen, ob eine Zahl ohne Rest in einer anderen aufgeht, ob ein Wert gerade oder ungerade ist, und für vieles mehr.

```php
$value = 3;
$isOdd = $value % 2;
if ($isOdd === 1) {
    echo 'Yes, it is odd!';
} else {
    echo 'It is even.';
}
```

## Potenzierung (**)

Der Potenzierungsoperator wird verwendet, um den linken Wert mit dem rechten Wert zu potenzieren. Vor PHP 5.6 musstest du die Funktion `pow` verwenden, um dasselbe zu erreichen.

```php
$sideLength = 13;
$areaOfSquare = $sideLength ** 2; // 169
```

Der Potenzierungsoperator unterstützt Ganzzahlen und Gleitkommazahlen auf beiden Seiten, sodass du damit Quadratwurzeln (oder andere Wurzeln) oder komplexere exponentielle Werte berechnen kannst.

```php
$squareArea = 144;
$side = $squareArea ** .5; // 12
```

## Reihenfolge der Operationen

PHP folgt bei der Mathematik der üblichen Reihenfolge der Operationen. Das bedeutet, dass die Operationen nicht einfach von links nach rechts ausgeführt werden, sondern jeder Operator eine Priorität hat und die Operationen gemäß ihrer Priorität aufgelöst werden. Die Reihenfolge der Operationen ist:

* Klammern
* Potenzierung
* Multiplikation, Division
* Addition, Subtraktion

Multiplikation und Division haben dieselbe Priorität. Ebenso haben Addition und Subtraktion dieselbe Priorität.

Das bedeutet, dass der Wert unten 17 statt 10 wäre, da die Multiplikation eine höhere Priorität als die Addition hat:

```php
$value = 2 + 3 * 5;
```

PHP bietet außerdem eine Reihe hilfreicher Zuweisungsoperatoren, die arithmetische Operatoren mit der Zuweisung kombinieren, wenn du eine Operation auf eine Variable anwendest und das Ergebnis wieder derselben Variable zuweist. Diese werden im Konzept `Assignment Operators` behandelt.
