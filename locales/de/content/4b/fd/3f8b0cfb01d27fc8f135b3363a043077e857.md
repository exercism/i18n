# Einführung

## Wahr und falsch

Wahre und falsche logische Zustände werden in Ruby mit `true` und `false` dargestellt.

```ruby
happy = true
sad = false
```

## Gleichheit und Vergleich

In Ruby kannst du Objekte mit den üblichen Vergleichszeichen miteinander vergleichen:
- Mit `==` prüfst du, ob zwei Objekte gleich sind
- Mit `>` prüfst du, ob das Objekt links **größer als** das Objekt rechts ist
- Mit `<` prüfst du, ob das Objekt links **kleiner als** das Objekt rechts ist.
- Mit `>=` bzw. `<=` prüfst du auf „größer oder gleich“ und „kleiner oder gleich“.

Außerdem kannst du die üblichen Operatoren für boolesche Logik verwenden:
- Mit `&&` oder `and` prüfst du, ob `x and y` wahr sind
- Mit `||` oder `or` prüfst du, ob `x or y` wahr ist.
- Mit `!` oder `not` kehrst du die Gleichheit um, z. B. `x != y` (x ist nicht gleich y)

Hier sind einige Beispiele:
```ruby
# Is "true equal to false"? 
true == false # false

# Is "true not equal to false"
true != false # true

# Is 5 greater than 4?
5 > 4 # true

# Is 3 less than or equal to 2?
3 <= 2 # false
```
