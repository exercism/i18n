# Anleitung

Du wirst leere Puffer initialisieren und die ersten fünf Zahlen bzw. Elemente der Fibonacci-Folge auflisten.

Die Fibonacci-Folge ist eine Menge von Zahlen, bei der das nächste Element die Summe der beiden vorherigen ist. Wir starten die Folge bei eins. Die ersten beiden Elemente sind also 1 und 1.

## 1. Erstelle einen Puffer mit `count` Nullen.

Erstelle eine Funktion, die einen Puffer mit `count` Nullen erstellt.

```rust
let my_buffer = create_buffer(5);
// [0, 0, 0, 0, 0]
```

## 2. Liste die ersten fünf Elemente der Fibonacci-Folge auf

Erstelle eine Funktion, die die ersten fünf Zahlen der Fibonacci-Folge zurückgibt.
Ihre ersten fünf Elemente sind `1, 1, 2, 3, 5`

```rust
let first_five = fibonacci();
// [1, 1, 2, 3, 5]
```
