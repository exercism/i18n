# Über Typumwandlung

Go erfordert eine explizite Umwandlung zwischen verschiedenen Typen.
Das hier verursacht zum Beispiel einen Compilerfehler:

```go
var x int = 42
var f float64 = x // compiler error x is an int not a float64
```

Die Umwandlung zwischen Typen (auch **Type Casting** genannt) erfolgt über eine Funktion, die den Namen des Zieltyps trägt.
Ein Wert `v` wird mit `T(v)` in den Typ `T` umgewandelt.
Um zum Beispiel einen `int` in einen `float64` umzuwandeln, gehst du so vor:

```go
var x int = 42 // x has type int
f := float64(x) // f has type float64 (ie. 42.0)
```

Dasselbe gilt für eigene Typen:

```go
type Id int
var number int = 121 // number has type int
userId := Id(number) // userId now has type Id
```

## Umwandlung zwischen primitiven Typen und Strings

Für die Umwandlung zwischen primitiven Typen (wie `int`) und `string` gibt es das Paket `strconv`.

```go
import "strconv"

var intString string = "42"
var i, err = strconv.Atoi(intString)

var number int = 12
var s string = strconv.Itoa(number)
```

WARNUNG: Die übliche Casting-Methode verhält sich nicht so.
Zum Beispiel:

```go
var num int = 65
str := string(num) // str is now "A" not "65"
```

Hier sind einige der anderen gängigen Umwandlungsmethoden:

| Methode     | Zweck                       |
| ----------- | --------------------------- |
| ParseBool   | Wandelt `string` in `bool` um  |
| FormatBool  | Wandelt `bool` in `string` um  |
| ParseFloat  | Wandelt `string` in `float` um |
| FormatFloat | Wandelt `float` in `string` um |
| ParseInt    | Wandelt `string` in `int` um   |
| FormatInt   | Wandelt `int` in `string` um   |
