# Über

Datenstrukturen, die null oder mehr Elemente enthalten können, werden als _Sammlungen_ bezeichnet.
Ein **Array** in Ruby ist eine Sammlung, die die Reihenfolge beibehält, in der seine Objekte hinzugefügt werden.
Arrays können beliebige Objekte enthalten.
Du kannst einem Array Objekte hinzufügen oder sie über einen Index daraus abrufen.
Die Indizierung von Ruby-Arrays beginnt bei null, das heißt, der Index des ersten Elements ist immer null:

```ruby
# Declare an array containing two values
two_ints = [1,2]

# Assign first and second element by index
two_ints[0] = 7
two_ints[1] = 8

# Retrieve the second element by index
two_ints[1] # => 8

# Check the length of the array
two_ints.size # => 2
```

In Ruby gibt es mehrere Möglichkeiten, ein Array zu erstellen:

- Mit dem Literal-Konstruktor `[]` _(am häufigsten)_
- Indem du `Array.new` explizit aufrufst
- Indem du die Kernel-Methode `Array()` aufrufst

Die Methode `Array.new` unterstützt zwei optionale Argumente: die Anfangsgröße des Arrays und ein Standardobjekt.

Wenn eine Größe und ein Standardobjekt angegeben werden, wird das Array mit `size` Kopien des Standardobjekts gefüllt.

```ruby
a = Array.new(2, Hash.new)
# => [{}, {}]
```

Da alle Elemente des Arrays denselben Hash speichern, wirken sich Änderungen an einem von ihnen auf alle aus.

```ruby
a[0]['cat'] = 'feline'
a # => [{"cat"=>"feline"}, {"cat"=>"feline"}]

a[1]['cat'] = 'Felix'
a # => [{"cat"=>"Felix"}, {"cat"=>"Felix"}]
```

Wenn du mehrere Kopien möchtest, solltest du die Blockversion verwenden, die jedes Mal, wenn ein Element des Arrays initialisiert werden muss, das Ergebnis des Blocks verwendet:

```ruby
a = Array.new(2) {Hash.new}
a[0]['cat'] = 'feline'
a # => [{"cat"=>"feline"}, {}]
```

Ein weiteres Merkmal von Ruby-Arrays ist, dass sie das Modul [Enumerable][enumerable-module] einbinden, das viele praktische Methoden zum Iterieren, Suchen, Sortieren, Filtern usw. von Elementen eines Arrays hinzufügt.

[enumerable-module]: https://docs.ruby-lang.org/en/master/Enumerable.html
