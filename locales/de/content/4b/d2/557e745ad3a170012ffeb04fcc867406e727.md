# Installation

## Windows-Nutzer

Bitte installiere das [Windows Subsystem for Linux][wsl-link] und lies dann den nächsten Abschnitt.

## Linux-/Mac-Nutzer

### Mit brew installieren

Das ist der einfachste Weg, Chapel zu installieren.
Du bekommst damit eine grundlegende, funktionierende Installation, die sich gut eignet, um den Exercism-Track durchzuarbeiten.
Fortgeschrittene wollen Chapel vielleicht selbst aus dem Quellcode bauen (nächster Abschnitt).

0. Falls noch nicht geschehen, installiere den Paketmanager [brew][brew-link].
1. Stelle zuerst sicher, dass brew aktuell ist, indem du `brew update` ausführst.
2. Installiere Chapel mit `brew install chapel`.
3. Prüfe mit `chpl --version`, ob die Installation erfolgreich war.

Damit werden der Chapel-Compiler (`chpl`), der Paketmanager `mason`, den wir zum Ausführen der Tests verwenden, und das Werkzeug `chpldoc` zur Dokumentationserzeugung installiert. `chpldoc` brauchst du für Exercism nicht, aber es ist gut, es zu haben, wenn (und das wirst du :) ) du eigene Bibliotheken in Chapel entwickeln willst.

### Chapel aus dem Quellcode bauen

Fortgeschrittene wollen Chapel vielleicht selbst aus dem Quellcode bauen. Dazu gehst du so vor:

1. Installiere die [Voraussetzungen][prereqs-link].
2. [Lade][download-link] das Archiv der neuesten Chapel-Version herunter und entpacke es.
3. Zuerst bereitest du die Installation vor und legst fest, wohin Chapel installiert werden soll.
Das geht mit dem mitgelieferten `configure`-Skript.
Wenn du einfach

```
./configure
```

ausführst, werden Binärdateien, Bibliotheken und gemeinsam genutzte Dateien nach `/usr/local/` installiert. Mit der Option `--prefix` kannst du das ändern.
Wenn du Chapel zum Beispiel nach `~/.chapel` installieren willst, geht das so:

```
./configure --prefix=~/.chapel
```

4. Um den Compiler und die Werkzeuge zu installieren, führe Folgendes aus:

```
make
make mason
make chpldoc
make install
```

5. Stelle sicher, dass der Ordner `/dir/for/install/bin` in deiner `PATH`-Variable enthalten ist.

Weitere Informationen über die verschiedenen Möglichkeiten, Chapel zu installieren und aus dem Quellcode zu arbeiten, findest du auf der Seite [Building Chapel][building-link] in der Dokumentation.
