# Ergänzung zu den Anweisungen

## Wörter

Definiere ein Tupel `stopwatch` und einen Konstruktor `<stopwatch> ( -- stopwatch )`,
der eine neue Stoppuhr im Zustand `"ready"` zurückgibt, ohne verstrichene Zeit und
ohne vorherige Runden.

Stelle die folgenden Wörter bereit, die auf einer Stoppuhr arbeiten:

- `state ( stopwatch -- str )` — `"ready"`, `"running"` oder `"stopped"`.
- `current-lap ( stopwatch -- str )` — die verstrichene Zeit der aktuellen Runde als
  `"HH:MM:SS"`-String.
- `total ( stopwatch -- str )` — die gesamte verstrichene Zeit der aktuellen Runde
  und aller vorherigen Runden als `"HH:MM:SS"`-String.
- `previous-laps ( stopwatch -- seq )` — ein Array der zuvor aufgezeichneten
  Runden, jede als `"HH:MM:SS"`-String.
- `start ( stopwatch -- )`, `stop ( stopwatch -- )`, `reset ( stopwatch -- )`
  und `lap ( stopwatch -- )` — die vier Befehle aus der Tabelle oben. Wird einer
  davon aus einem Zustand aufgerufen, der ihn nicht erlaubt, sollte er einen
  Fehler `throw`en.

Die Zeit wird so erhöht:

- `advance-time ( str stopwatch -- )` — addiert die Dauer `"HH:MM:SS"` zur
  aktuellen Runde. Das wirkt sich nur aus, während die Stoppuhr läuft.
