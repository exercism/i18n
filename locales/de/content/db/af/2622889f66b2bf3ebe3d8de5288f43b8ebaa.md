# Anleitung

Du hast dich mit einem schwindelerregenden Tagessatz zurück nach Hyperia (mit der hohen Inflation) locken lassen.

Die Zentralbank erwägt, den US-Dollar als zweite Währung einzuführen, deshalb müssen alle Buchhaltungssysteme angepasst werden, damit sie mehrere Währungen verarbeiten können.

Du sollst das Objekt für Währungsbeträge implementieren.

## 1. Ermögliche es, Währungsbeträge auf Gleichheit zu testen

Bitte passe die `CurrencyAmount`-Struktur an, sodass sie Gleichheit behandelt. Wenn die beiden Währungsbeträge nicht dieselbe Währung haben („USD“ oder „HD“), dann sollte eine Instanz von `ArgumentException` ausgelöst werden.

```csharp
CurrencyAmount amountA = new CurrencyAmount(55, "HD");
CurrencyAmount amountB = new CurrencyAmount(55, "HD");
CurrencyAmount amountC = new CurrencyAmount(55, "USD");
amountA == amountB
// => true
amountA != amountB
// => false
amountA == amountC
// => ArgumentException
amountA != amountC
// => ArgumentException
```

## 2. Vergleiche Währungsbeträge

Bitte passe die `CurrencyAmount`-Struktur an, sodass sie Vergleiche behandelt (`>` und `<`, nur diese). Wenn die beiden Währungsbeträge nicht dieselbe Währung haben („USD“ oder „HD“), dann sollte eine Instanz von `ArgumentException` ausgelöst werden.

```csharp
CurrencyAmount amountA = new CurrencyAmount(55, "HD");
amountA > new CurrencyAmount(50, "HD")
// => true
amountA < new CurrencyAmount(50, "HD")
// => false
amountA > new CurrencyAmount(50, "USD")
// => ArgumentException
```

## 3. Addiere und subtrahiere Währungsbeträge

Bitte passe die `CurrencyAmount`-Struktur an, sodass sie arithmetische Addition und Subtraktion behandelt (`+` und `-`, nur diese). Wenn die beiden Währungsbeträge nicht dieselbe Währung haben („USD“ oder „HD“), dann sollte eine Instanz von `ArgumentException` ausgelöst werden.

```csharp
CurrencyAmount amountA = new CurrencyAmount(55, "HD");
CurrencyAmount amountB = new CurrencyAmount(100, "HD");
CurrencyAmount amountC = new CurrencyAmount(55, "USD");
amountA + amountB
// => {155, HD}
amountB - amountA
// => {45, HD}
amountA + amountC
// => ArgumentException
```

## 4. Multipliziere und dividiere Währungsbeträge

Bitte passe die `CurrencyAmount`-Struktur an, sodass sie arithmetische Multiplikation und Division behandelt (`*` und `/`, nur diese).

```csharp
CurrencyAmount amountA = new CurrencyAmount(10, "HD");
amountA * 2m
// => {20, HD}
amountA / 2m
// => {5, HD}
```

## 5. Konvertiere den Währungsbetrag in einen double

Bitte passe die `CurrencyAmount`-Struktur an, sodass eine Instanz explizit in einen `double` umgewandelt werden kann.

```csharp
CurrencyAmount amountA = new CurrencyAmount(55.5m, "HD");
(double)amountA
// => 55.5d
```

## 6. Konvertiere den Währungsbetrag in einen decimal

Bitte passe die `CurrencyAmount`-Struktur an, sodass eine Instanz implizit in einen `decimal` umgewandelt werden kann.

```csharp
CurrencyAmount amountA = new CurrencyAmount(55.5m, "HD");
decimal d = amountA;
// => d == 55.5m
```
