# Einführung

Boolesche Werte werden in Rust durch den Typ `bool` dargestellt. Ein Wert kann entweder `true` oder `false` sein.

Rust unterstützt sechs Vergleichsoperatoren: `==` (gleich), `!=` (ungleich), `>` (größer als), `<` (kleiner als), `>=`
(größer oder gleich), `<=` (kleiner oder gleich). Mit ihnen kannst du die Beziehung zwischen nicht-booleschen Werten
auswerten und in einen booleschen Wert umwandeln.

```rust
1 > 0 // true
1 < 0 // false
1 == 0 // false
1 != 0 // true
1 >= 0 // true
1 <= 0 // false
```

Anders als in manchen anderen Sprachen ist `0` nicht `false` und ein Wert ungleich null ist nicht `true`.

Rust unterstützt zwei boolesche Operatoren: `||` (Oder) und `&&` (Und). Sie werden nur ausgewertet, wenn der linke Operand
das Ergebnis des Ausdrucks nicht schon bestimmt. Das heißt, `||` wertet den rechten Operanden nur aus, wenn der linke
Operand `false` ergibt, und `&&` nur, wenn er `true` ergibt.
