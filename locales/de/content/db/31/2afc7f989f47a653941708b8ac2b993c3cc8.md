# Instructions

In dieser Übung sollst du die Software für ein Verschlüsselungsgerät schreiben, das Daten transformiert. Du brauchst eine Möglichkeit, komplizierte Funktionen flexibel zu erstellen, indem du einfachere Funktionen kombinierst.

Gib für jede Aufgabe eine anonyme Funktion zurück, die aus dem aufrufenden Gültigkeitsbereich heraus aufgerufen werden kann.

Alle Funktionen sollten Ganzzahlen als Argumente erwarten. Ganzzahlen eignen sich in Elixir auch für bitweise Operationen.

## 1. Erstelle einen Addierer

Implementiere `Secrets.secret_add/1`. Sie sollte eine Funktion zurückgeben, die ein Argument entgegennimmt und zu diesem das an `secret_add` übergebene Argument addiert.

```elixir
adder = Secrets.secret_add(3)
adder.(2)
# => 5
```

## 2. Erstelle einen Subtrahierer

Implementiere `Secrets.secret_subtract/1`. Sie sollte eine Funktion zurückgeben, die ein Argument entgegennimmt und von diesem das an `secret_subtract` übergebene Geheimnis subtrahiert.

```elixir
subtractor = Secrets.secret_subtract(2)
subtractor.(3)
# => 1
```

## 3. Erstelle einen Multiplizierer

Implementiere `Secrets.secret_multiply/1`. Sie sollte eine Funktion zurückgeben, die ein Argument entgegennimmt und es mit dem an `secret_multiply` übergebenen Geheimnis multipliziert.

```elixir
multiplier = Secrets.secret_multiply(7)
multiplier.(3)
# => 21
```

## 4. Erstelle einen Dividierer

Implementiere `Secrets.secret_divide/1`. Sie sollte eine Funktion zurückgeben, die ein Argument entgegennimmt und es durch das an `secret_divide` übergebene Geheimnis dividiert.

```elixir
divider = Secrets.secret_divide(3)
divider.(32)
# => 10
```

Nutze die Ganzzahldivision, damit die Ausgabe mit dem erwarteten Eingabewert der anderen Funktionen kompatibel ist.

## 5. Erstelle einen „and“-Verknüpfer

Implementiere `Secrets.secret_and/1`. Sie sollte eine Funktion zurückgeben, die ein Argument entgegennimmt und eine bitweise _und_-Operation damit und mit dem an `secret_and` übergebenen Geheimnis durchführt.

```elixir
ander = Secrets.secret_and(1)
ander.(2)
# => 0
```

## 6. Erstelle einen „xor“-Verknüpfer

Implementiere `Secrets.secret_xor/1`. Sie sollte eine Funktion zurückgeben, die ein Argument entgegennimmt und eine bitweise _xor_-Operation damit und mit dem an `secret_xor` übergebenen Geheimnis durchführt.

```elixir
xorer = Secrets.secret_xor(1)
xorer.(3)
# => 2
```

## 7. Erstelle einen Funktionskombinierer

Implementiere `Secrets.secret_combine/2`. Sie sollte eine Funktion zurückgeben, die ein Argument entgegennimmt und die beiden an `secret_combine` übergebenen Funktionen der Reihe nach darauf anwendet.

```elixir
add_one = Secrets.secret_add(1)
multiply_by_2 = Secrets.secret_multiply(2)
combined = Secrets.secret_combine(add_one, multiply_by_2)

combined.(3)
# => 8
```
