# Anleitung

In dieser Übung simulierst du ein Spiel, das dem klassischen Kartenspiel **Camicia** sehr ähnlich ist.
Dein Programm erhält die Anfangskonfiguration der Kartenstapel zweier Spieler und muss das Spiel simulieren, bis es endet (oder erkennen, dass es nie enden wird).

## Regeln

- Der Kartenstapel wird zwischen **zwei Spielern** aufgeteilt.
  Die Karten eines Spielers werden von links nach rechts gelesen, wobei die Karte ganz links die oberste Karte des Stapels ist.
- Eine Runde besteht darin, dass beide Spieler mindestens eine Karte ausspielen.
- Die Spieler legen abwechselnd die **oberste Karte** ihres Stapels auf den Mittelstapel.
- Ist die Karte eine **Zahlenkarte** (2-10), geht das Ausspielen einfach an den anderen Spieler über.
- Ist die Karte eine **Zahlkarte**, muss eine Strafe gezahlt werden:
  - **J** → der Gegner muss 1 Karte zahlen
  - **Q** → der Gegner muss 2 Karten zahlen
  - **K** → der Gegner muss 3 Karten zahlen
  - **A** → der Gegner muss 4 Karten zahlen
- Deckt der Spieler, der eine Strafe zahlt, eine weitere Zahlkarte auf, hört dieser Spieler auf, die Strafe zu zahlen.
  Der andere Spieler muss dann eine Strafe zahlen, die auf der neuen Zahlkarte beruht.
- Wird die Strafe ohne Unterbrechung vollständig gezahlt, nimmt der Spieler, der die **letzte Zahlkarte** gelegt hat, den Mittelstapel auf und legt ihn unter seinen Stapel.
  Dieser Spieler beginnt dann die nächste Runde.
- Gehen einem Spieler die Karten aus und kann er keine Karte spielen (entweder beim Zahlen einer Strafe oder wenn er an der Reihe ist), nimmt der andere Spieler den Mittelstapel auf.
- Der Moment, in dem ein Spieler die Karten aus dem Mittelstapel aufnimmt, wird als **Trick** bezeichnet.
- Hat ein Spieler nach einem Trick alle Karten in seinem Besitz, **endet** das Spiel.
- Das Spiel **gerät in eine Schleife**, sobald die Stapel genauso aussehen wie früher im Spiel, wobei Zahlenkarten **nicht** mitgezählt werden!

## Deine Aufgabe

- Simuliere das Spiel mit der Eingabe nach den obigen Regeln.
- Ermittle die folgenden Informationen zum Spiel:
  - **Status**: `"finished"` oder `"loop"`
  - **Cards**: Gesamtzahl der Karten, die während des Spiels gespielt wurden
  - **Tricks**: Anzahl der Male, in denen der Mittelstapel aufgenommen wurde
