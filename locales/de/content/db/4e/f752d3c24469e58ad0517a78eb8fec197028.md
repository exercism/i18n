# Einführung

## Typaliase

### Typaliase

Ein Typalias kann in Gleam verwendet werden, um einem bereits existierenden Typ einen praktischen Namen zu geben, der sonst umständlich zu schreiben wäre.

```gleam
pub type Headers =
  List(#(String, String))

pub fn html_headers() -> Headers {
  [
    #("content-type", "text/html"),
    #("x-frame-options", "DENY"),
  ]
}
```

Wenn man den Alias mit `pub type` schreibt, kann man ihn auch außerhalb des Moduls verwenden, in dem er definiert ist. Lässt man `pub` weg, ist der Alias privat und kann in anderen Modulen nicht verwendet werden.

## Dicts

Dicts sind in Gleam die Datenstruktur, um Informationen in Schlüssel-Wert-Paaren zu speichern. In anderen Sprachen kennt man sie vielleicht auch als assoziative Arrays, Hashes oder Wörterbücher.

Für die Schlüssel und Werte eines Dicts kann jeder beliebige Typ verwendet werden, und die Reihenfolge der Einträge ist nicht garantiert, wenn man auf sie zugreift oder sie zurückgibt.

### Mit Dicts arbeiten

Dicts werden mit Funktionen aus dem Modul `gleam/dict` erstellt und bearbeitet.

```gleam
// Create an empty dict
let dict1 = dict.new()

// Create a dict with some values
let dict2 = dict.from_list([
  #("name", "Gleam"),
  #("colour", "Pink"),
])

// Add a value to a dict
let dict3 = dict.insert(dict2, "website", "https://gleam.run")

// Get a value from a dict
let name = dict.get(dict3, "name")
// -> Ok("Gleam")
```
