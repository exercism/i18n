# Einführung

## Arrays

Die Cairo-Kernbibliothek implementiert einen `Array`-Typ.

Er ähnelt den üblichen Array-Typen anderer Programmiersprachen, weist aber ein paar wichtige Unterschiede auf:

- Elemente können effizient nur hinten an den `Array`-Typ angehängt werden, und effizient entfernen lassen sie sich nur vorne.
- Es ist nicht möglich, ein Element über den Array-Index manuell zu setzen.

Arrays lassen sich mit der Funktion `ArrayTrait::new` und auch mit dem `array!`-Makro erstellen:

```rust
let empty: Array<u32> = ArrayTrait::new();
let one_to_four = array![1, 2, 3, 4];
```

Elemente lassen sich mit der Funktion `ArrayTrait::append` zum Array hinzufügen:

```rust
let mut num_array = array![1, 2, 3, 4];
num_array.append(5);
// -> [1, 2, 3, 4, 5]
```

Elemente lassen sich mit der Funktion `ArrayTrait::pop_front` aus dem Array entfernen:

```rust
let mut one_to_four = array![1, 2, 3, 4];

one_to_four.pop_front();
// -> [2, 3, 4]
```

Cairo führt außerdem einen `Span`-Typ ein, der wie eine „Momentaufnahme“ des `Array` funktioniert.

Jeder `Array` kann mit der Funktion `ToSpanTrait::span` in einen `Span` umgewandelt werden:

```rust
let one_to_four = array![1, 2, 3, 4];
let one_to_four_span = one_to_four.span();
// -> [1, 2, 3, 4]
```

Ein Array in einen `Span` umzuwandeln ist sehr effizient, denn `Span` ist nur eine Datenstruktur, die es Cairo erlaubt, einen Abschnitt des Arrays zu „betrachten“, ohne ihn in irgendeiner Weise zu verändern.

Indem Cairo ein Array in einen `Span` umwandelt, erlaubt es mehr Operationen, als direkt auf `Array` möglich wären, zum Beispiel das Entfernen eines Elements vom Anfang des Span.

```rust
let one_to_four = array![1, 2, 3, 4];
let mut one_to_four_span = one_to_four.span();
one_to_four_span.pop_back();
// -> [2, 3, 4]
```

Beachte, dass wir `one_to_four_span` mit dem Schlüsselwort `mut` veränderlich machen mussten, um `pop_back` aufzurufen. Dieser Aufruf verändert den Span, indem er den Abschnitt des Arrays verkürzt, den der Span gerade „betrachtet“.
