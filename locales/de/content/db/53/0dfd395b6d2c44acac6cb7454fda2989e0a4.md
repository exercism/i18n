# Über

Mit [Bitstrings][bitstring] können Programmierer effektiv mit Binärdaten arbeiten.

- Du kannst Bitstrings elegant mit der [`<<>>`-Spezialform][bitstring-form] konstruieren.

  ```elixir
  <<0b101::3>> == <<5::3>> and <<5::3>> == <<5::size(3)>>
  # => true

  first = <<0b110::3>>
  second = <<0b001::3>>
  combined = <<first::bitstring, second::bitstring>>
  # => <<49::size(6)>>
  ```

- Du kannst die `<<>>`-Form für einen Mustervergleich nutzen und damit [Binärdaten weiter zerlegen][bitstring-matching].

  ```elixir
  <<data_size::32, count::size(data_size)>> = <<8::32, 3::8>>
  # => <<0, 0, 0, 8, 3>>
  data_size
  # => 8
  count
  # => 3
  ```

- Du kannst mit `::bitstring` den Rest des Bitstrings abgleichen.

  ```elixir
  <<_::32, remainder::bitstring>> = <<8::32, 3::8>>
  # => <<0, 0, 0, 8, 3>>
  remainder
  # => <<3>>
  ```

- Der *Typ* der Binärdaten ist eine bestimmte Art von Bitstring, bei dem die Anzahl der Bits durch 8 teilbar ist.
  - Alle Binärdaten sind Bitstrings, aber nicht alle Bitstrings sind Binärdaten.
- Elixir bietet syntaktischen Zucker für die Arbeit mit [Ganzzahl-Literalen][integer-literal] in verschiedenen Formen:
  - `0b1000001 = ?A = 65`
