# Anleitung

In dieser Übung modellierst du eine Waage mit Kilogramm als Einheit.

Du hast 6 Aufgaben, für die du jeweils eine oder mehrere Eigenschaften implementieren musst:

## 1. Gib der Waage eine Genauigkeit

Um unterschiedlichen Anforderungen gerecht zu werden, lässt sich jede Waage mit einer Genauigkeit konfigurieren (die Anzahl der Nachkommastellen).
Implementiere die Klasse `WeighingMachine` mit einer schreibgeschützten Eigenschaft `Precision`, die auf das Argument `precision` des Konstruktors gesetzt wird:

```csharp
var wm = new WeighingMachine(precision: 3);

//  => wm.Precision == 3
```

## 2. Erlaube, dass das Gewicht der Waage gesetzt werden kann

Implementiere die Eigenschaft `WeighingMachine.Weight` so, dass das Gewicht abgerufen _und_ gesetzt werden kann:

```csharp
var wm = new WeighingMachine(precision: 3);
wm.Weight = 60.5;

//  => wm.Weight == 60.5
```

## 3. Stelle sicher, dass ein negatives Gewicht als Eingabe abgelehnt wird

Natürlich kann niemand ein negatives Gewicht haben.
Füge der Eigenschaft `WeighingMachine.Weight` eine Validierung hinzu, die eine `ArgumentOutOfRangeException` auslöst, wenn versucht wird, sie auf ein negatives Gewicht zu setzen:

```csharp
var wm = new WeighingMachine(precision: 3);
wm.Weight = -10; // Throws an ArgumentOutOfRangeException
```

## 4. Erlaube, dass eine Tara-Anpassung auf die Waage angewendet wird

Die Tara-Anpassung kann jeder Wert sein (sogar negativ oder ein Wert, der das angezeigte Gewicht negativ macht).
Implementiere die Eigenschaft `WeighingMachine.TareAdjustment` so, dass die Tara-Anpassung gesetzt werden kann:

```csharp
var wm = new WeighingMachine(precision: 3);
wm.TareAdjustment = -10.6;

// => wm.TareAdjustment == -10.6
```

## 5. Stelle sicher, dass die Waage eine Standard-Tara-Anpassung hat

Nach einigen gründlichen Tests stellt sich heraus, dass alle Waagen aufgrund eines Herstellungsfehlers dazu neigen, das Gewicht um `5` zu überschätzen.
Ändere die Eigenschaft `WeighingMachine.TareAdjustment` so, dass ihr Standardwert `5` ist.

```csharp
var wm = new WeighingMachine(precision: 3);

// => wm.TareAdjustment == 5.0
```

## 6. Erlaube, dass das Gewicht abgerufen werden kann

Implementiere die Eigenschaft `WeighingMachine.DisplayWeight`, die einen String zurückgeben soll, der das Gewicht nach der Tara-Anpassung zeigt, mit der korrekten Genauigkeit und der angehängten Einheit.
Beachte:
``` display-weight = input-weight - tare-adjustment ```

```csharp
var wm = new WeighingMachine(precision: 3);
wm.Weight = 60.567;
wm.TareAdjustment = 10;

// => wm.DisplayWeight == "50.567 kg"
```
