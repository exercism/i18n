# Typdeklaration

Typdeklarationen in PHP bieten zur Laufzeit Typzusicherungen für Funktionsargumente, Rückgabewerte und Klasseneigenschaften.
Bei Funktionen kann ein `void`-Rückgabetyp angegeben werden, um auszudrücken, dass die Funktion keinen Wert zurückgibt.
Deklarierte Typen dienen außerdem als Laufzeitprüfungen dafür, dass Funktionen eine vernünftig typisierte Antwort zurückgeben.

```php
<?php

class Driver
{
    private int $serial_number;

    public function setSerialNumber(int $number): void
    {
        $this->serial_number = $number;
    }

    public function getSerialNumber(): int
    {
        return $this->serial_number; 
    }
}

$driver = new Driver();
$driver->setSerialNumber("Version 1b"); // This will throw a TypeError
```

## Typunionen

Wenn ein Funktionsargument, ein Rückgabewert oder eine Klasseneigenschaft mehr als einen Typ haben kann, kann eine Typunion deklariert werden.

```php
<?php

class IdentityCard
{
    private int|null $id = null;

    public function assign(int|float $id): void
    {
        $this->id = intval($id);
    }
}

$card = new IdentityCard();
$card->assign(5.0);
```

## Gemischte Typen

Bei der Arbeit mit Code können wir manchmal keinen Typ angeben.
Ab PHP 8.0 gibt es einen Notausgang-Typ namens `mixed`.
Mixed entspricht einer Typunion aus `object|resource|array|string|float|int|bool|null`.
