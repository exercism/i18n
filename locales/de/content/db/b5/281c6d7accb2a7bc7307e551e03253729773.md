# Tests

Tests lassen sich auf verschiedene Weise ausführen.

## Interaktiv aus Emacs heraus

1. Öffne die Testdatei, `M-x eval-buffer RET`
2. Interaktiv und einzeln, mit `M-x ert RET test-name RET`
3. Interaktiv und alle auf einmal, mit `M-x ert RET t RET`
   Beachte, dass damit alle Tests ausgeführt werden, die gerade in Emacs geladen sind!
4. Führe vor dem Testen erneut `M-x eval-buffer RET` aus, wenn du Änderungen vorgenommen hast

Wenn du nur die Tests im aktuellen Buffer ausführen möchtest, kannst du Folgendes in deine `.emacs` oder `init.el` einfügen:

```elisp
(defun my-eval-and-run-all-tests-in-buffer ()
  "Deletes all loaded tests from the runtime, evaluates the current buffer and runs all loaded tests with ert."
  (interactive)
  (ert-delete-all-tests)
  (eval-buffer)
  (ert 't))
```

Nach einem Neustart von Emacs:

1. Öffne die Testdatei
2. `M-x my-eval-and-run-all-tests-in-buffer RET`

## Im Terminal

Um alle Tests im Batch-Modus vom Terminal aus auszuführen, führe `emacs -batch -l ert -l *-test.el -f ert-run-tests-batch-and-exit` aus

Der obige Befehl ist etwas unhandlich. Wenn du magst:

1. Erstelle eine Datei in deinem `$PATH` (wahrscheinlich in `~/bin`) namens `ert-run`
2. Der Inhalt der Datei sollte wie folgt aussehen:
   ```sh
   #!/usr/bin/env sh
   emacs -batch -l ert -l $1 -f ert-run-tests-batch-and-exit
   ```
3. Mach die Datei mit `chmod +x ert-run` ausführbar

Du solltest einfach `ert-run *-test.el` aufrufen und die Tests im Batch-Modus ausführen können.

## Weitere Optionen

Weitere Optionen findest du in der Dokumentation, `C-h i m ert RET`.
