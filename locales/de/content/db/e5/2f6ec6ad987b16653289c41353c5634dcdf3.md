# Hinweise

## 1. Stell dich vor

Die Funktion `introduce` muss den Wert, der in `player.Name` steckt, „auspacken“.
Überleg dir, die Funktion [`Options.defaultValue`][defaultvalue] zu verwenden, um `player.Name` in seinen „eingepackten“ Wert umzuwandeln, wenn er `Some` ist, oder in den erforderlichen Standardwert, wenn er `None` ist.

## 2. Implementiere die revive-Mechanik

Die Funktion `revive` muss entweder `Some <player>` oder `None` zurückgeben, wobei `<player>` ein `Player`-Record ist, möglicherweise mit einigen geänderten Feldern.

## 3. Implementiere die Mechanik für das Zauberwirken

Überleg dir, einen match-Ausdruck zu verwenden, um sowohl den Fall `Some` als auch den Fall `None` abzudecken, wie im folgenden Beispiel:

```fsharp
let exists (x: int option) =
    match x with
    | Some n -> true
    | None -> false
```

[defaultvalue]: https://learn.microsoft.com/en-us/dotnet/fsharp/language-reference/options#converting-options-with-default-values
