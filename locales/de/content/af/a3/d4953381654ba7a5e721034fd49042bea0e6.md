# Platzhalter

## List-Operationen implementieren

Das Ziel dieser Übung ist es, einige Methoden von List selbst zu implementieren.
Es ist ganz natürlich, im Hintergrund ein List-Objekt zu verwenden, das die Daten hält.
Lass die Finger von den List-Methoden (wie `where`, `map` usw.).

Einige „primitive“ List-Operationen sind unvermeidlich, zum Beispiel:

* Slicing: `list[from..to]`
* Hinzufügen: `list.add(item)`

## Iterator-Protokoll

Bei den List-Operationen, die du implementieren sollst, geht es darum, auf verschiedene Arten zu iterieren.
Lies mehr über [das Iterator-Protokoll][iter].
Danach kannst du Folgendes tun:

```wren
var list = ListOps.new([1, 2, 3, 4])
for (item in list) {
    do_something_with(item)
}
```

[iter]: https://wren.io/control-flow.html#the-iterator-protocol
