# Hinweise

## Allgemeines

- Das [C#-Strings-Tutorial von csharp.net][tutorial-csharp.net-strings] bietet eine schöne Einführung in C#-`string`s.
- Die Klasse `string` hat viele nützliche [eingebaute Methoden][docs-string-methods].

## 1. Nachricht aus einer Logzeile holen

- Verschiedene Möglichkeiten, in einem String nach Text zu suchen, werden in [diesem Tutorial][tutorial-docs.microsoft.com-search-text-in-string] erklärt.
- Das Entfernen von Leerraum ist [eingebaut][tutorial-docs.microsoft.com-trim-white-space].

## 2. Log-Level aus einer Logzeile holen

- Wie du die Groß- und Kleinschreibung eines `string` änderst, wird in [diesem Tutorial][tutorial-docs.microsoft.com-changing-case] erklärt.

## 3. Logzeile umformatieren

- Es gibt mehrere Möglichkeiten, [Strings zu verketten][tutorial-docs.microsoft.com-concatenate-strings], aber die bevorzugte ist meistens die [String-Interpolation][tutorial-csharp.net-string-interpolation].
