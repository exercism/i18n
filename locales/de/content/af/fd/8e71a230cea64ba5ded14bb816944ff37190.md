# Über

Das Modul `Time` wird verwendet, um menschenlesbare Datums- und Zeitangaben anzuzeigen.
Zwar kannst du Zeiten mit `Time` technisch gesehen auch selbst bearbeiten, aber es gibt Elm-Pakete aus der Community, die dafür viel besser geeignet sind, zum Beispiel [`justinmimbs/date`][date] oder [`CoderDennis/elm-time-format`][elm-time-format].

## Posix

Zeiten werden durch den undurchsichtigen Typ `Posix` dargestellt, der die Unix-Epoch-Zeit umschließt, also die Anzahl der Millisekunden seit dem 1. Januar 1970 um Mitternacht UTC.
Eine `Posix` ist ein eindeutiger Wert, der sich nicht zwischen Zeitzonen ändert, und daher eine gute Wahl, um Zeiten zu speichern.
In einer Elm-Anwendung kommen `Posix`-Zeiten typischerweise aus externen Quellen, etwa dem Browser.

Mit den folgenden Funktionen kannst du eine `Posix` in eine Anzahl von Millisekunden umwandeln und umgekehrt:

```elm
posixToMillis : Posix -> Int
millisToPosix : Int -> Posix
```

## Zeitzonen

In unserem Alltag lesen wir Menschen üblicherweise keine `Posix`-Werte, sondern bevorzugen die lokale Zeit, die von unserem Standort auf der Erde und den lokalen Sommerzeitregeln abhängt.
In Elm stecken diese Informationen im undurchsichtigen Typ `Zone`, der normalerweise vom Browser kommt.

Es gibt eine besondere `Zone`, die immer verfügbar ist:

```elm
utc : Zone
```

## Zeitangaben für Menschen

Mit einer `Posix` und einer `Zone` haben wir genug Informationen, um die lokale Zeit in beliebigem Detailgrad anzuzeigen.
Hier ist eine Liste der Funktionen, die du dafür verwenden kannst:

```elm
toYear : Zone -> Posix -> Int
toMonth : Zone -> Posix -> Month
toDay : Zone -> Posix -> Int
toWeekday : Zone -> Posix -> Weekday
toHour : Zone -> Posix -> Int
toMinute : Zone -> Posix -> Int
toSecond : Zone -> Posix -> Int
toMillis : Zone -> Posix -> Int
```

Dir sind sicher schon zwei weitere eigene Typen von `Time` aufgefallen:

```elm
type Month = Jan | Feb | Mar | Apr | May | Jun | Jul | Aug | Sep | Oct | Nov | Dec
type Weekday = Mon | Tue | Wed | Thu | Fri | Sat | Sun
```

Diese eigenen Typen in menschenlesbare Werte umzuwandeln, bleibt den Nutzern überlassen.
