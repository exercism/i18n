# Hinweise

## Allgemein

- Jede Aufgabe ist ein dünner Wrapper um ein Wort aus dem Vokabular von
  [`math.combinatorics`][math.combinatorics].
- Die zählenden Wörter nehmen zwei Ganzzahlen; die auflistenden Wörter nehmen eine
  Sequenz.

## 1. Kombinationen zählen

- `nCk ( n k -- m )` gibt die Anzahl der Möglichkeiten zurück, `k` Elemente
  aus `n` auszuwählen. Der Stack ist bereits in der richtigen Reihenfolge. Ruf es
  einfach auf.

## 2. Permutationen zählen

- `nPk ( n k -- m )` gibt die Anzahl der geordneten Möglichkeiten zurück, `k`
  Elemente aus `n` auszuwählen.

## 3. Kombinationen auflisten

- `all-combinations ( seq k -- combinations )` gibt jede `k`-elementige
  Teilmenge von `seq` in lexikografischer Reihenfolge zurück.

## 4. Permutationen auflisten

- `all-permutations ( seq -- permutations )` gibt jede Anordnung von `seq`
  zurück.

## 5. Kombinationen mit einer Zielsumme

- Beginne mit jeder `k`-Kombination aus `all-combinations`.
- Behalte nur die, deren Elemente zusammen `target` ergeben. `filter` aus
  [`sequences`][sequences] nimmt eine Quotation, die einen booleschen Wert
  zurückgibt; darin summiert `sum` (aus [`math`][math]) eine Kombination, und
  `=` vergleicht sie mit `target`.
- Weil die Aufgabe `target` innerhalb der Quotation braucht, kannst du das Wort
  mit `::` (aus [`locals`][locals]) definieren und so `seq`, `k` und `target`
  über ihren Namen ansprechen.
