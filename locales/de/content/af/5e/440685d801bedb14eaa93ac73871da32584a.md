# Ergänzung zu den Anweisungen

## Fehlermeldungen bei Ausnahmen

Manchmal ist es notwendig, [eine Ausnahme auszulösen](https://docs.python.org/3/tutorial/errors.html#raising-exceptions). Dabei solltest du immer eine **aussagekräftige Fehlermeldung** angeben, die zeigt, woher der Fehler stammt. Das macht deinen Code lesbarer und hilft beim Debuggen deutlich. Wenn du weißt, dass die Fehlerquelle von einem bestimmten Typ ist, kannst du eine der [eingebauten Fehlertypen](https://docs.python.org/3/library/exceptions.html#base-classes) auslösen, solltest aber trotzdem eine aussagekräftige Meldung angeben.

Diese Übung verlangt, dass du die [raise-Anweisung](https://docs.python.org/3/reference/simple_stmts.html#the-raise-statement) verwendest, um für unterschiedliche Eingabe- und Ausgabebasen einen `ValueError` zu „werfen“. Die Tests bestehen nur, wenn du die `exception` mit `raise` auslöst und dazu eine aussagekräftige Meldung angibst.

Um einen `ValueError` mit einer Meldung auszulösen, übergibst du die Meldung als Argument an den `exception`-Typ:

```python
# for input.
raise ValueError("input base must be >= 2")

# another example for input.
raise ValueError("all digits must satisfy 0 <= d < input base")

# or, for output.
raise ValueError("output base must be >= 2")
```
