# Einführung

Opake Typen sind in Gleam benutzerdefinierte Typen, bei denen nur das Modul, das den Typ definiert, Werte dieses Typs erzeugen oder per Musterabgleich vergleichen kann. Das ist nützlich, um Typen zu erstellen, die nur auf eine bestimmte Art und Weise verwendet werden sollen.

Opake Typen werden mit dem Schlüsselwort `opaque` definiert.

```gleam
pub opaque type PositiveInt {
  PositiveInt(inner: Int)
}
```

Dieser Typ `PositiveInt` ist für Situationen gedacht, in denen eine Ganzzahl gewünscht ist, die aber null oder größer sein muss. Ein gewöhnliches `Int` in Gleam ließe sich dafür nicht verwenden, denn es kann auch negativ sein.

Das Modul, das diesen Typ definiert, kann eine Funktion definieren, um den inneren Wert als Ganzzahl zu erhalten, und eine Funktion zum Erzeugen des Typs `PositiveInt`, die einen Fehler zurückgibt, wenn der Wert nicht positiv ist.

```gleam
pub fn from_int(i: Int) -> Result(PositiveInt, String) {
  case i {
    _ if i < 0 -> Error("Value must be positive")
    _ -> Ok(PositiveInt(i))
  }
}

pub fn to_int(i: PositiveInt) -> Int {
  i.inner
}
```

Mit dieser API können andere Module keinen `PositiveInt` mit einem negativen Wert erzeugen. Jede Funktion, die einen `PositiveInt` entgegennimmt, kann also sicher sein, dass der Wert positiv ist.
