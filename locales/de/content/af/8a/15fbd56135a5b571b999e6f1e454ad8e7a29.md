# Einführung

In dieser Übung lernst du die grundlegenden Bausteine von Ruby kennen.
Sie deckt eine Menge Stoff ab, aber keine Sorge, wenn es dir zu viel erscheint: Wir gehen auf alles noch viel ausführlicher ein, wenn wir den Track weiter durchlaufen.

Eines der wichtigsten Dinge, die du über Ruby verstehen solltest, ist, dass es eine [objektorientierte Sprache][object-oriented-programming] ist und dass **in Ruby alles ein [Objekt][object] ist**. Zahlen, Strings, Arrays - sie alle sind Objekte.

## Variablen und Konstanten

Wir nutzen Objekte meist, indem wir ihnen Namen geben, entweder über Variablen oder Konstanten.

Variablen werden immer in [Snake Case][snake-case] geschrieben.
Eine Variable kann im Laufe ihres Lebens auf verschiedene Objekte verweisen.
Zum Beispiel kann `my_first_variable` mit dem Operator `=` viele Male definiert und neu definiert werden:

```ruby
my_first_variable = 1
my_first_variable = "Some string"
my_first_variable = SomeComplexObject.new
```

Konstanten hingegen sind dafür gedacht, nur einmal zugewiesen zu werden.
Sie müssen mit einem Großbuchstaben beginnen und werden normalerweise in Großbuchstaben geschrieben, wobei die Wörter durch Unterstriche getrennt sind.
Zum Beispiel:

```ruby
MY_FIRST_CONSTANT = 10

# Redefining not allowed
# MY_FIRST_CONSTANT = "Some String"
```

## Klassen

Ruby ist in Klassen organisiert.
Klassen werden mit dem Schlüsselwort `class` definiert, gefolgt vom Namen der Klasse.
Objekte werden in der Regel erstellt, indem man Klassen mit der Methode `.new` instanziiert.
Zum Beispiel:

```ruby
# Define the class
class Calculator
  #...
end

# Create an instance of it and assign it to a variable
my_first_calc = Calculator.new
```

## Methoden

Funktionseinheiten werden in Methoden gekapselt, ähnlich wie _Funktionen_ in anderen Sprachen.

Eine Methode kann mit Positionsargumenten, Schlüsselwortargumenten (die mit der Syntax `:` definiert und aufgerufen werden) oder ganz ohne Argumente definiert werden.

Methoden geben entweder implizit das Ergebnis der zuletzt ausgewerteten Anweisung zurück oder explizit ein Objekt über das Schlüsselwort `return`.

```ruby
class Calculator

  # Positional arguments
  def add(num1, num2)
    return num1 + num2 # Explicit return
  end

  # Keyword arguments
  def multiply(num1:, num2:)
    num1 * num2 # Implicit return
  end
end
```

Methoden werden mit der Syntax `.` aufgerufen:

```ruby
calc = Calculator.new
calc.add(1, 3)
calc.multiply(num1: 2, num2: 5)
```
