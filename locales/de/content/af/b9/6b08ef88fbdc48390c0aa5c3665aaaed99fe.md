# Einführung

Haxe hat eingebaute Unterstützung für reguläre Ausdrücke. Damit kannst du das Format eines Strings überprüfen, einen String umwandeln oder aus einem gegebenen Text Daten nach einem bestimmten Muster herausziehen.

Um einen regulären Ausdruck zu erstellen, schreibst du den Ausdruck zwischen `~/` und `/`:

```haxe
var r = ~/haxe/i;
```

Eine andere Möglichkeit ist die Verwendung einer `EReg()`-Instanz:

```haxe
var r = new EReg("haxe", "i");
```

Hier ist das `i` ein Flag, das das Muster unabhängig von Groß- und Kleinschreibung macht. Es gibt noch weitere Flags, zum Beispiel:

- `g`: globales Ersetzen.
- `m`: mehrzeilige Suche

Zwischen `~/` und `/` schreibst du die Muster des regulären Ausdrucks. Angenommen, du suchst einen String, der Buchstaben von A bis Z enthält. Dafür können wir das Bereichsmuster `[A-Z]` verwenden. Es gibt viele Ausdrucksmuster, zum Beispiel:

- `.`: ein beliebiges Zeichen
- `*`: null Mal oder öfter wiederholen
- `+`: ein Mal oder öfter wiederholen
- `[A-Z0-9]`: Zeichenbereiche
