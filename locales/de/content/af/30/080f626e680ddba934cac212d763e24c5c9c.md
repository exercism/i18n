# Details

Über Zeichenklassen und Quantoren hinaus können reguläre Ausdrücke die *Struktur* und den *Kontext* von Text beschreiben. Diese Möglichkeiten stecken im selben Vokabular [`regexp`][regexp], das mit dem Literal `R/ /` geschrieben wird.

## Gruppierung und Alternation

Runde Klammern `( )` fassen einen Teil eines Musters zusammen, sodass ein Quantor oder ein `|` („dies oder das“) auf die ganze Gruppe wirkt. Ein `?` nach einer Gruppe macht sie optional:

```factor
USING: regexp ;

"abab"    R/ (ab)+/ matches? .             ! => t
"cat"     R/ cat|dog/ matches? .           ! => t
"$100.50" R/ \$\d+(\.\d{2})?/ matches? .   ! => t
"$100"    R/ \$\d+(\.\d{2})?/ matches? .   ! => t   (group optional)
```

## Anker

```
^    ! start of the string
$    ! end of the string
\b   ! a word boundary
```

Eine *Wortgrenze* (`\b`) liegt dort, wo ein Wortzeichen (ein Buchstabe, eine Ziffer oder ein Unterstrich) auf ein Nicht-Wortzeichen trifft, auch an den Enden des Strings. `\bcat\b` findet `cat` also nur, wenn es für sich allein steht:

```factor
USING: regexp ;

"cat nap" R/ \bcat\b/ re-contains? .   ! => t
"scatter" R/ \bcat\b/ re-contains? .   ! => f
```

## Lookaround

Ein *Lookaround* prüft, was unmittelbar vor oder nach einer Stelle steht, ohne dass diese Zeichen Teil des Treffers werden. Er ist nullbreit:

```
(?=...)    ! lookahead
(?!...)    ! negative lookahead
(?<=...)   ! lookbehind
```

```factor
USING: regexp ;

"spent $100 and $25" R/ (?<=\$)\d+/ all-matching-subseqs .
! => { "100" "25" }

"up 5% then 12%" R/ \d+(?=%)/ all-matching-subseqs .
! => { "5" "12" }
```

## Optionen

Ein Optionsbuchstabe nach dem schließenden `/` verändert das gesamte Muster. Mit `i` wird die Groß- und Kleinschreibung ignoriert:

```factor
USING: regexp ;

"REFUND" R/ refund/i matches? .   ! => t
```

## Jeden Treffer umwandeln

`map-matches` führt für jeden Treffer ein Quotation aus und sammelt die Ergebnisse; `each-match` macht dasselbe, aber nur wegen der Seiteneffekte. Beide übergeben dem Quotation den `start`-Index und den `end`-Index des Treffers sowie den ganzen String, sodass `subseq` den gefundenen Text zurückliefert:

```
map-matches ( string regexp quot: ( start end string -- obj ) -- seq )
each-match  ( string regexp quot: ( start end string --     ) --     )
```

```factor
USING: math regexp sequences ;

"a1 b22 c333" R/ \d+/ [ subseq length ] map-matches .
! => { 1 2 3 }
```

## Was Factor nicht unterstützt

Die Regexp-Engine von Factor beherrscht keine **Extraktion von Capture-Gruppen** (eine Gruppe `( )` strukturiert zwar das Muster, aber du kannst den Text, auf den sie passt, nicht zurücklesen), keine **Rückverweise** (`\1`) und keine **faulen (non-greedy) Quantoren** (`*?`, `+?`). Lookaround ist der idiomatische Ersatz für Capture-Gruppen: Du suchst den Teil, den du brauchst, und erkennst ihn am umgebenden Kontext.
