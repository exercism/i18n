# Statische Schlüsselwörter in Klassen

Eine Klasse ist eine Einheit zur Organisation von Code in PHP und stellt oft eine Instanz eines Dings, eines Dienstes oder eines Vorgangs dar.
Mit den Schlüsselwörtern `static` und `self` können Eigenschaften und Methoden in Bezug auf die Klasse für alle Instanzen (oder auch ohne Instanz) existieren.

```php
<?php

class Book
{
    static $genre = 'Adventure';

    static function getGenre()
    {
        return self::$genre;
    }
}

// Usage
$genre = Book::$genre;
$genre = Book::getGenre();
```

## Einschränkung

Statische Klassenmethoden können nur andere statische Eigenschaften oder statische Methoden ihrer eigenen Klasse aufrufen.

```php
<?php

class Book
{
    $name = 'Treasure Island';

    static function getName()
    {
        // This static method cannot access the instance variable
        return $this->name;
    }
}
```
