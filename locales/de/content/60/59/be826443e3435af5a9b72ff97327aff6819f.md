# Tests

Wenn du die phix-Binary in deinem Pfad hast, gib folgenden Befehl ein:

```bash
p test 
```
Damit wird die Testdatei (test.exw) ausgeführt.

Wenn die phix-Binary nicht im PATH ist, gib unter Windows Folgendes ein:

```cmd
\path\to\p.exe test
```

Linux:

```bash
/path/to/p test
```

## Übersprungene Tests

Eine Übung zu lösen bedeutet, dass alle ihre Tests bestehen.
Standardmäßig werden alle Tests in der Datei test.exw ausgeführt.
Um einen Test zu überspringen, setze zwei Bindestriche (das übliche Kommentarzeichen von Phix) an den Anfang der Zeile.

Beachte, dass die Tests keine include=false-Flags in tests.toml berücksichtigen. Vielmehr liegt es in der Verantwortung der Person, die test.exw geschrieben hat, sie in dieser Datei manuell zu pflegen, damit sie die Realität widerspiegeln, zum Nutzen der Exercism-Website (z. B. für das Sammeln von Track-Statistiken). Aber nichts im Track selbst macht irgendeinen Gebrauch davon, insbesondere nicht der Testgenerator und der Test-Runner.
