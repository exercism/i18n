# Hinweise

## Allgemein

- `set-nth ( elt n seq -- )`, `change-nth ( i seq quot -- )`,
  `push ( elt seq -- )` und `pop ( seq -- elt )` *verändern* alle
  ihr Sequenzargument und geben nichts darüber auf dem Stack
  zurück. Die Veränderung ist der Effekt.

## 1. Frisches Mosaik

- `<array>` (aus [`arrays`][arrays]) nimmt eine Länge und einen
  Füllwert und gibt ein neues Array zurück.

## 2. Einen Mosaikstein setzen

- `set-nth` erledigt die Zuweisung, erwartet aber
  `( elt n seq -- )`, während die Eingaben als `( row position colour -- )`
  ankommen. `spin ( x y z -- z y x )` aus `kernel` ordnet drei Werte
  auf dem Stack in einem einzigen Wort um, sodass sie in der
  Reihenfolge von `set-nth` landen.

## 3. Einen Mosaikstein herausschlagen

- „Setze diese Position auf `f`“ – gleiche Form wie in Aufgabe 2,
  aber du musst `f` zuerst auf den Stack legen.

## 4. Einen Mosaikstein neu einfärben

- `change-nth` führt ein Quotation auf dem Element an der angegebenen
  Position aus und speichert das Ergebnis zurück.

## 5. Momentaufnahme

- `clone` (aus [`kernel`][kernel]) gibt eine unabhängige Kopie zurück.

## 6. Zwischenspeichern

- `push` hängt ein Element an Ort und Stelle an einen Vektor an.

## 7. Rückgabe

- `pop` entfernt das letzte Element eines Vektors und gibt es zurück.
