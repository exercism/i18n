# Hinweise

## Allgemein

- Lies die offizielle Dokumentation zu [Ranges][range].

## 1. Definiere den Bereich der Reihen

- Es gibt einen [speziellen Operator][range-creation-operator] zum Erstellen von Bereichen.

## 2. Definiere den Bereich der Linien

- Es gibt einen [speziellen Operator][range-creation-operator] zum Erstellen von Bereichen.
- Es gibt eine [spezielle Syntax][unicode-code-points], um einen Zeichencodepunkt zu schreiben, ohne seinen Wert explizit zu kennen.

## 3. Wandle den Bereich der Reihen in eine Liste von Reihen um

- Bereiche implementieren das `Enumerable`-Protokoll.
- Es gibt eine [eingebaute Funktion][enum-to-list], um eine aufzählbare Datenstruktur in eine Liste umzuwandeln.

## 4. Wandle den Bereich der Linien in eine Liste von Linien um

- Bereiche implementieren das `Enumerable`-Protokoll.
- Es gibt eine [eingebaute Funktion][enum-map], um eine aufzählbare Datenstruktur in eine Liste umzuwandeln und dabei ihre Elemente zu verändern.
- Die [spezielle Bitstring-Form][bitstring-special-form] kann verwendet werden, um einen Codepunkt in einen String umzuwandeln.
