# Einführung

## Vergleich

In Go kann man Zahlen mit den folgenden relationalen und Gleichheitsoperatoren vergleichen.

| Vergleich           | Operator  |
| ------------------- | --------- |
| gleich              | `==`      |
| ungleich            | `!=`      |
| kleiner             | `<`       |
| kleiner oder gleich | `<=`      |
| größer              | `>`       |
| größer oder gleich  | `>=`      |

Das Ergebnis des Vergleichs ist immer ein boolescher Wert, also entweder `true` oder `false`.

```go
a := 3

a != 4 // true
a > 5  // false
```

Die oben genannten Vergleichsoperatoren kann man auch verwenden, um Strings zu vergleichen.
In diesem Fall wird eine lexikografische (Wörterbuch-)Reihenfolge angewendet.
Zum Beispiel:

```Go
	"apple" < "banana"  // true
	"apple" > "banana"  // false
```

## if-Anweisungen

Bedingte Anweisungen in Go ähneln bedingten Anweisungen in anderen Sprachen.
Der zugrunde liegende Typ jeder bedingten Operation ist der Typ `bool`, der die Werte `true` oder `false` annehmen kann.
Bedingte Anweisungen werden oft zur Steuerung des Programmflusses verwendet, um verschiedene Bedingungen zu prüfen.

Um einen bestimmten Fall zu prüfen, kann man eine `if`-Anweisung verwenden, die ihren Code ausführt, wenn die zugrunde liegende Bedingung `true` ist, wie folgt:

```go
var value string

if value == "val" {
    return "was val"
}
```

In Szenarien mit mehr als einem Fall können viele `if`-Anweisungen mit `else if`- und `else`-Anweisungen verkettet werden.

```go
var number int
result := "This number is "

if number > 0 {
    result += "positive"
} else if number < 0 {
    result += "negative"
} else {
    result += "zero"
}
```

`if`-Anweisungen können auch eine kurze Initialisierungsanweisung enthalten, mit der man eine oder mehrere Variablen für die `if`-Anweisung initialisieren kann.
Zum Beispiel:

```go
num := 7
if v := 2 * num; v > 10 {
    fmt.Println(v)
} else {
    fmt.Println(num)
}
// Output: 14
```

> Hinweis: Alle Variablen, die in der Initialisierungsanweisung erstellt werden, sind nach dem Ende der `if`-Anweisung außerhalb des Gültigkeitsbereichs.
