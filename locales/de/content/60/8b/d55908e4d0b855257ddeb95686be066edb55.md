# Einführung

Ein [C# `Attribute`](https://docs.microsoft.com/en-us/dotnet/csharp/programming-guide/concepts/attributes/) bietet eine Möglichkeit, eine Deklaration zu versehen und ihr Metadaten zuzuordnen: einer Klasse, einer Methode, einem Enum, einem Feld, einer Eigenschaft oder jeder [anderen unterstützten](https://docs.microsoft.com/en-us/dotnet/csharp/programming-guide/concepts/attributes/#attribute-targets) Deklaration.

Du kannst ein Attribut anwenden, indem du es in der Zeile vor der Deklaration hinzufügst, und zwar mit einem `ClassAttribute` und einem `FieldAttribute`:

```csharp
[Class]
class MyClass
{
    [Field]
    int myField;
}
```

Diese deklarativen Metadaten verknüpfen nur zusätzliche strukturierte Informationen mit dem Code und verändern sein Verhalten nicht. Andere Teile des Codes verwenden diese Metadaten jedoch, um das Verhalten ihres Ziels zu ändern oder einige seiner Funktionalitäten hinzuzufügen, zu ändern, zu entfernen oder einzuschränken.

Es gibt viele [vordefinierte und reservierte Attribute](https://docs.microsoft.com/en-us/dotnet/csharp/language-reference/attributes/general#conditional-attribute), zum Beispiel `Flags`, `Obsolete` und `Conditional`. Jedes davon hat eine eigene Bedeutung, die du in der C#-Dokumentation nachschlagen kannst. Beachte, dass der vollständige Name eines Attributs wie [`Flags`](https://docs.microsoft.com/en-us/dotnet/api/system.flagsattribute) per Konvention `FlagsAttribute` lautet, aber das Suffix _Attribute_ kann weggelassen werden, wenn das Attribut auf eine Deklaration angewendet wird.
