# Hinweise

## Allgemeines

- Jede Schleife hier wird von einem Iterator gesteuert, also braucht keine davon eine
  Zählvariable oder ein `until!`.
- Die Antwort steckt immer in einer Variable, die vor der Schleife deklariert wird, denn
  alles, was innerhalb deklariert wird, verschwindet, wenn die Schleife endet.

## 1. Die Gesamtsumme

- `counts.elt!` liefert bei jedem Durchlauf einen Zählwert.
- Starte die Gesamtsumme bei `0`. Das ergibt auch für eine Zählung ohne Tage die richtige
  Antwort.

## 2. Der beste Tag

- Merke dir den bisher besten Wert in einer Variable, die bei `0` beginnt.
- Vergleiche bei jedem Durchlauf und ersetze, wenn dieser Tag ihn übertrifft. `.max`
  erledigt den Vergleich in einem Schritt: `best := best.max(counts.elt!)`.

## 3. Die ereignisreichen Tage

- Zähle, statt zu addieren: `if counts.elt! > n then found := found + 1; end;`
- Frage den Iterator einmal ab, und zwar innerhalb der `if`-Bedingung. Wenn du
  `counts.elt!` zweimal im selben Schleifenblock schreibst, durchläufst du das Array
  zweimal.

## 4. Zu prüfende Verstecke

- Hier wird nichts durchlaufen, also nützt `elt!` nichts. `1.upto!(days)` zählt für dich.
- `1.upto!(0)` liefert überhaupt nichts, und das ist die richtige Antwort für null Tage.

## 5. Der erste ereignisreiche Tag

- Die Antwort ist eine Position, kein Wert, also durchlaufe die Positionen:
  `i ::= 0.upto!(counts.size - 1)`.
- Starte die Antwort bei `-1`. Wenn nichts gefunden wird, ist das bereits der Wert, der
  zurückgegeben werden soll.
- Sobald ein Tag gefunden wird, verlasse die Schleife mit `break!`. Sonst würde ein
  späterer ereignisreicher Tag den ersten überschreiben.
