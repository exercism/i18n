# Hinweise

## Allgemeines

- Die Wörter zum Lesen findest du in [`io`][io]; die Konstruktoren für
  String-Streams und `with-string-writer` findest du in
  [`io.streams.string`][io.streams.string].
- Für die Aufgabe zum Leeren des Writers halten lokale Variablen (`::` und
  `:>`) den Rumpf lesbar, wenn du auf denselben Stream zweimal zugreifen
  musst.

## 1. Hör dir alles an

- Ein Wort: `stream-contents`.

## 2. Zähle die Nachrichten

- `stream-lines` teilt den Stream in ein Array von Zeilen auf;
  `length` gibt die Anzahl zurück.

## 3. Gib den letzten Aufruf zurück

- Dieselben `stream-lines` wie oben, dann `last`, dann `>upper` (aus
  `ascii`).

## 4. Sende eine Nachricht an alle

- `stream-write` schreibt die Nachricht, `stream-flush` schiebt sie
  hinaus. Der Writer wird zweimal verwendet, also greif zu `::`-lokalen
  Variablen:
  `:: broadcast ( message writer -- ) message writer stream-write
  writer stream-flush ;`.

## 5. Fange die Ausgabe einer Quotation auf

- Ein Wort: `with-string-writer`. Füge `inline` nach dem schließenden
  `;` hinzu, damit der Compiler durch das Quotation-Argument hindurchsehen
  kann: `: capture ( quot -- captured ) with-string-writer ; inline`.
