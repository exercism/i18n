# Überblick

Bei der Enumeration durchläufst du eine Sammlung (`Array`, `Hash` usw.) und führst mit jedem Objekt eine Aktion aus.

Enumeration ist ein zentrales Konzept in Ruby und wird zum Sortieren (`sort_by`), Gruppieren (`group_by`), Transformieren (`map`), Reduzieren (`reduce`) und für vieles mehr verwendet.
Am häufigsten begegnet dir Enumeration als idiomatische Art, Sammlungen zu durchlaufen, statt Schleifen zu verwenden.

Eine einfache Enumeration, die jedes Wort in einem Array ausgibt, sieht so aus:

```ruby
words = %w[the cat sat on the mat]
words.each do |word|
  puts word
end

# Output:
# the
# cat
# sat
# on
# the
# mat
```

In diesem Beispiel haben wir die Methode `Array#each` aufgerufen und einen _Block_ übergeben, der einen Parameter (`word`) entgegennimmt und ihn ausgibt.

Wir können Enumerable-Methoden auch verketten.
Zum Beispiel können wir `.with_index` an `each` anhängen, um sowohl den Index als auch den Wert eines Objekts auszugeben:

```ruby
words = %w[the cat sat on the mat]
list = words.map.with_index { |word, index| "#{index}. #{word}" }
puts list

# Output:
# 0. the
# 1. cat
# ...
# 5. mat
```

Das Enumerieren von `Hash`-Objekten funktioniert genauso wie das Enumerieren von `Array`-Objekten, nur dass der Block zwei Argumente erhält: den Schlüssel und den Wert:

```ruby
pet_names = {cat: "bob", horse: "caris", mouse: "arya"}
words.each { |animal, name| ... }

# The two arguments should be put in brackets when chaining
words.each.with_index { |(animal, name), index| ... }
```

Die oben beschriebenen Methoden sind Teil des [`Enumerable`-Moduls][enumerable-module], das in `Array`, `Hash` und andere Klassen eingebunden ist, die die Fähigkeit zum Enumerieren brauchen.

[enumerable-module]: https://docs.ruby-lang.org/en/master/Enumerable.html
