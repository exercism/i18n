# Anleitung

Das Netball-Training beginnt mit Runden. Der Trainer macht jede Runde ein wenig länger als die vorherige: Die erste ist 100 Meter lang, die zweite 110, die dritte 120 und so weiter, jedes Mal zehn Meter mehr.

Alle drei Aufgaben kommen in die Klasse `WARM_UP_LAPS`.

## 1. Wie weit insgesamt?

Gegeben ist eine Anzahl Runden. Berechne daraus die Gesamtdistanz.

```sather
WARM_UP_LAPS::distance_run(3)
-- => 330
```

Das ist 100 + 110 + 120. Null Runden sind null Meter.

## 2. Wie viele Runden für eine Strecke?

Gegeben ist eine Strecke in Metern. Wie viele Runden sind nötig, bis die Gesamtdistanz mindestens so weit ist?

```sather
WARM_UP_LAPS::laps_to_reach(330)
-- => 3
WARM_UP_LAPS::laps_to_reach(331)
-- => 4
```

Für null Meter braucht es gar keine Runden.

## 3. Ab welcher Runde wird es lang?

Gegeben ist eine Strecke in Metern. Welches ist die erste Runde, die *selbst* länger ist als diese? Runde 1 ist 100 Meter lang, Runde 2 ist 110, und so weiter.

```sather
WARM_UP_LAPS::first_long_lap(115)
-- => 3
```

Runde 3 ist 120 Meter lang und damit die erste über 115.
