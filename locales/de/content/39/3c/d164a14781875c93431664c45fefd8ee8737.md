# Tupel

Tupel in Elm können zwei oder drei Werte enthalten, und jeder Wert kann einen beliebigen Typ haben.
In Elm werden Tupel meist für einfache, kurzlebige Typen verwendet.
Aus diesem Grund haben Tupel höchstens 3 Werte, und als zusätzliche Ermutigung gibt es Komfortfunktionen nur für 2 Werte.
Bei komplexeren Daten wechselt man am besten zu Records.
Ein häufiger Anwendungsfall ist, wenn du mehr als einen Wert aus einer Funktion zurückgeben musst.
Die Felder eines Tupels haben keine Namen; auf sie greifst du per Destrukturierung oder über ihre Position zu.

Eine [kurze Einführung in Tupel][tuples-concise] findest du hier.
Außerdem gibt es eine [ausführlichere Einführung][tuples-in-depth], und die [API-Dokumentation des Tuple-Moduls][tuple-core] enthält Codebeispiele und eine ausführliche Dokumentation.

## Deklaration

Typen für Tupel werden mit runden Klammern erstellt, und ihre Elementtypen werden durch Kommas getrennt.

```elm
type alias IntStringTuple = (Int, String)
```

### Erstellung

Tupel werden mit runden Klammern erstellt, und ihre Elemente werden durch Kommas getrennt.

```elm
aTuple : IntStringTuple
aTuple = (123, "elements can be of differing types")
```

Du kannst auch `Tuple.pair` verwenden, um ein Tupel mit zwei Werten zu erstellen.

```elm
anotherTuple : (String, String)
anotherTuple = Tuple.pair "this time it's" "two strings"
    --> ("this time it's", "two strings")
```

### Zugriff

Es gibt auch Funktionen, um über die Position auf die Werte eines Tupels zuzugreifen: `Tuple.first` und `Tuple.second`.

```elm
Tuple.first aTuple
    --> 123

Tuple.second aTuple
    --> "elements can be of differing types"
```

Tupel können in Bindings mit Pattern Matching auf Tupel _destrukturiert_ werden.
Destrukturieren ist in let-Ausdrücken, Funktionsdeklarationen und case-Anweisungen möglich.

```elm
repeatString : (Int, String) -> Bool
repeatString aTuple =
let
    (aNumber, aString) = aTuple
in
    String.repeat aNumber aString

repeatStringAgain : (Int, String) -> Bool
repeatStringAgain (aNumber, aString) = String.repeat aNumber aString
```

Pattern Matching in einer case-Anweisung erlaubt es dir außerdem, den Inhalt der Werte abzugleichen:

```elm
has123 : (Int, String, Bool) -> Bool
has123 aTuple =
    case aTuple of
        (123, _, _) ->
            True
        (_, "123", _) ->
            True
        (_, _, True) ->
            True
        _ ->
            False
```
