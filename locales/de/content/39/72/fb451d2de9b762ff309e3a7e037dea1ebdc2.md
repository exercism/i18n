# Einführung

`Enum` ist ein sehr nützliches Modul, das eine Reihe von Algorithmen für die Arbeit mit Enumerables bereitstellt. Es bietet Sortieren, Filtern, Gruppieren, Zählen, Suchen, Finden von Min-/Max-Werten und vieles mehr.

Im Allgemeinen ist ein _Enumerable_ alles, worüber iteriert werden kann, also eine Sammlung. In Elixir ist ein Enumerable jeder Datentyp, der das [Protokoll][exercism-protocols] `Enumerable` implementiert. Die häufigsten davon sind [Listen][exercism-lists] und [Maps][exercism-maps].

Viele `Enum`-Funktionen akzeptieren eine Funktion als Argument.

```elixir
Enum.all?([1, 2, 3, 4, 5], fn x -> x > 3 end)
# => false
```

Die gebräuchlichsten `Enum`-Funktionen sind `map` und `reduce`.

## `map/2`

Mit `Enum.map/2` kannst du jedes Element in einem Enumerable durch ein anderes Element ersetzen. Das zweite Argument von `Enum.map/2` ist eine Funktion, die das ursprüngliche Element entgegennimmt und seinen Ersatz zurückgibt.

## `reduce/3`

Mit `Enum.reduce/3` kannst du das gesamte Enumerable auf einen einzelnen Wert _reduzieren_. Um das zu erreichen, wird eine spezielle Variable namens _Akkumulator_ verwendet. Der Akkumulator trägt den Zwischenzustand der Reduktion zwischen den Iterationen.

Das zweite Argument von `Enum.reduce/3` ist der Startwert des Akkumulators. Das dritte Argument ist eine Funktion, die ein Element und einen Akkumulator entgegennimmt und den neuen Wert für den Akkumulator zurückgibt.

## Arbeiten mit Maps

Wenn du Maps mit `Enum`-Funktionen verwendest, wird die Map automatisch in eine Liste aus 2 `{key, value}`-Tupeln umgewandelt.

Um sie wieder in eine Map umzuwandeln, verwende `Enum.into/2`. `Enum.into/2` ist eine Funktion, die ein Enumerable in ein Collectable umwandelt, also in jede Datenstruktur, die das Protokoll `Collectable` implementiert. Man kann sie sich als Gegenstück zu `Enum.reduce/3` vorstellen.

`Enum` hat auch `Enum.into/3`. `Enum.into/3` ist eine Variante von `Enum.into/2`, die eine Transformationsfunktion akzeptiert, die angewendet wird, während das Enumerable in ein Collectable umgewandelt wird.

### Maps abbilden

Statt `Enum.into/3` oder `Enum.map/2` plus `Enum.into/2` zu verwenden, um eine Transformation (ein Mapping) auf eine Map anzuwenden, können wir auch eine dedizierte Funktion `Map.new/2` verwenden. Sie funktioniert genau wie `Enum.into/3`, indem sie ein Enumerable und eine Transformationsfunktion akzeptiert, aber sie gibt immer eine neue Map zurück, statt uns die Wahl des Collectables zu überlassen.
