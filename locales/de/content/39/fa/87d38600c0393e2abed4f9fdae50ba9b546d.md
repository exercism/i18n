# Einführung

Hash-Tabellen sind in Common Lisp Datenstrukturen zum Speichern assoziativer Daten.
Sie bilden Schlüssel (die jedes Objekt sein können) auf Werte ab (die ebenfalls jedes Objekt sein können).
Andere Sprachen nennen dieses Konzept vielleicht Maps, Wörterbücher oder Hashes.

## Hash-Tabellen erstellen

Hash-Tabellen erstellst du mit der Funktion `make-hash-table`.

`(make-hash-table) ; => #<HASH-TABLE :TEST EQL :COUNT 0 {10024AD2B3}>`

(Beachte, dass die Darstellung einer Hash-Tabelle bei der Ausgabe implementationsabhängig ist, sie kann in deiner REPL also anders aussehen.)

## Werte über Schlüssel abrufen

Um einen Wert über einen Schlüssel aus der Hash-Tabelle zu holen, verwendest du die Funktion `gethash`:

```lisp
*h* ; => #<HASH-TABLE :TEST EQL :COUNT 3 {10024AD2B3}>`
(gethash :foo *h*) ; => :bar
                   ;    T
```

`gethash` gibt [mehrere Werte][concept-multiple-values] zurück, die in einem anderen Konzept erklärt werden.

## Werte einfügen

Um einen Wert in eine Hash-Tabelle einzufügen, verwendest du `setf` zusammen mit `gethash`, und zwar so:

`(setf (gethash :foo *hash-table*) :bar) : => :bar`

Damit änderst du den Wert für den Schlüssel `:foo` in der Hash-Tabelle `*hash-table*` zu `:bar`.
Der Wert wird zurückgegeben.

Die Verwendung von `setf` wird in einem anderen Konzept erklärt.
