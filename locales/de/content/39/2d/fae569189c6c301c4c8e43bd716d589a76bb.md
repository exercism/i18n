# Anweisungen

Ein Freund von dir hat einen alten Großhandel namens **Gross Store**.

Der Name kommt von der Menge, in der das Geschäft seine Artikel verkauft: Alles gibt es nur im [Gros][gross-unit].

Dein Freund hat dich gebeten, ein Kassensystem (POS) für seinen Laden zu programmieren.

**Zuerst möchtest du einen Prototyp dafür bauen.**

**In deinem Prototyp erfasst dein System nur die Menge.**

Dein Freund hat dir eine Liste mit Maßeinheiten gegeben, die dir helfen soll:

| Einheit            | Wert |
| ------------------ | ----- |
| quarter_of_a_dozen | 3     |
| half_of_a_dozen    | 6     |
| dozen              | 12    |
| small_gross        | 120   |
| gross              | 144   |
| great_gross        | 1728  |

## 1. Speichere die Maßeinheit in deinem Programm

Um die Maßeinheit zu verwenden, musst du sie in deinem Programm speichern.

```rust
let units = units();
// Felt252Dictionary with entries like { 'dozen': 12 }
```

## 2. Erstelle eine neue Kundenrechnung

Du musst eine Funktion implementieren, die eine neue (leere) Rechnung für den Kunden erstellt.

```rust
let bill = new_bill();
// Empty Felt252Dictionary
```

## 3. Füge einen Artikel zur Kundenrechnung hinzu

Um das umzusetzen, musst du:

- `false` zurückgeben, wenn die angegebene `unit` nicht in der `units`-Map enthalten ist.
- Andernfalls den Artikel der `bill` des Kunden hinzufügen, indiziert über den Artikelnamen, und anschließend `true` zurückgeben.
- Wenn der Artikel bereits in der Rechnung vorhanden ist, seine Menge um den Betrag erhöhen, der zur angegebenen `unit` gehört.

```rust
let bill = new_bill();
let units = units();
let ok = add_item(bill, units, 'carrot', 'dozen');
println!(ok);
// Output: true (since dozen is a valid unit)
```

> Beachte, dass der Rückgabewert den Typ `bool` hat.

## 4. Entferne einen Artikel aus der Kundenrechnung

Um das umzusetzen, musst du:

- `false` zurückgeben, wenn der angegebene Artikel **nicht** in der Rechnung ist.
Ein Artikel gilt als nicht in der Rechnung, wenn seine Menge 0 ist.
- `false` zurückgeben, wenn die angegebene `unit` nicht in der `units`-Map enthalten ist.
- `false` zurückgeben, wenn die neue Menge kleiner als 0 wäre.
- Wenn die neue Menge 0 ist, gilt der Artikel als aus der `bill` entfernt, du kannst also `true` zurückgeben.
- Andernfalls die Menge des Artikels verringern und `true` zurückgeben.

```rust
let bill = new_bill();
let units = units();
let ok = remove_item(bill, units, 'carrot', 'dozen');
println!(ok);
// Output: false (because there are no carrots in the bill)
```

> Beachte, dass der Rückgabewert den Typ `bool` hat.

## 5. Gib die Menge eines bestimmten Artikels in der Kundenrechnung zurück

```rust
let mut bill: Felt252Dict<u32> = Default::default();
bill.insert('carrot', 12);
bill.insert('grapes', 3);
let qty = get_item(bill, 'carrot');
println!(qty);
// Output: 12
```

> Beachte, dass der Rückgabewert den Typ `u32` hat.
