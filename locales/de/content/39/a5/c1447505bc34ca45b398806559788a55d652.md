# Einführung

Eine `list` in R ist eine geordnete Sammlung von Elementen, die sich in einigen Punkten von `vectors` unterscheidet:

- Die Elemente können von unterschiedlichem Typ sein (z. B. `numeric` mit `character` gemischt).
- Die Elemente können komplexe Strukturen sein (z. B. Vektoren, andere Listen usw.).
- Für den Zugriff auf die Elemente gibt es eine etwas andere Syntax.

Analogien zu anderen Sprachen sind ungenau.
Eine R-`list` ähnelt ein wenig einem Python-Dictionary, aber die `list` ist geordnet und kann über einen numerischen Index angesprochen werden.
Sie ähnelt ein wenig einem C-`struct`, mit dem Unterschied, dass die `list` zur Laufzeit leicht erweitert werden kann.

## Listen erstellen

Den Elementen Namen zu geben (oft „Tags“ genannt), ist bei Listen üblicher als bei Vektoren:

```R
list(x = 5.3, y = 4.2, color = "blue")
$x
#> [1] 5.3

$y
#> [1] 4.2

$color
#> [1] "blue"
```

Tags sind aber optional, und R verwendet dann einfach Indexnummern:

```R
list(5.3, 4.2, "blue")
#> [[1]]
#> [1] 5.3

#> [[2]]
#> [1] 4.2

#> [[3]]
#> [1] "blue"
```

## Zugriff auf Listenelemente

Dafür gibt es drei Möglichkeiten, jede in einem anderen Kontext nützlich.

### 1. Mit der `$tag`-Notation

Sehr verbreitet, wenn die Tag-Namen im Voraus bekannt sind.

```R
point <- list(x = 5.3, y = 4.2, color = "blue")
point$x
#> [1] 5.3
point$color
#> [1] "blue"
```

### 2. Mit der `[[tag]]`-Notation

Das hat den Vorteil, dass der Tag-Name zur Laufzeit gewählt werden kann.
Beachte die doppelten Klammern.

```R
want <- "y"
point[[want]] # same as point$y
#> [1] 4.2
```

### 3. Mit dem Positionsindex

Das funktioniert unabhängig davon, ob die Liste Tags hat.
Auch hier sind die Klammern doppelt.

```R
point[[3]] # same as point$color
#> [1] "blue"
```

## Elemente hinzufügen und löschen

Ganz einfach: Eine Zuweisung an ein Element ändert es, wenn es existiert, und fügt es ein, wenn es neu ist.

```R
point$color <- "red"
point[[trust]] <- TRUE
str(point)
#> List of 4
#>  $ x    : num 5.3
#>  $ y    : num 4.2
#>  $ color: chr "red"
#>  $ trust: logi TRUE
```

Um ein Element zu löschen, weise dem unerwünschten Element `NULL` zu.

```R
point$trust <- NULL
str(point)
#> List of 3
#>  $ x    : num 5.3
#>  $ y    : num 4.2
#>  $ color: chr "red"
```
