# Einführung

## Alias

Um Code zwischen verschiedenen Elixir-Modulen innerhalb desselben Projekts zu teilen, musst du auf das externe Modul mit seinem vollständigen Namen verweisen. Aber was, wenn dieser Name zu lang oder verwirrend ist?

Die spezielle Form `alias` ermöglicht es dir, den Namen zu verkürzen oder zu ändern, mit dem du auf ein externes Modul verweist. Wenn sie ohne Argumente verwendet wird, kürzt sie den Modulnamen auf sein letztes Segment, z. B. wird `MyApp.Logger.Settings` zu `Settings`. Ein benutzerdefinierter Name kann mit der Option `:as` angegeben werden.

Normalerweise werden Aliase am Anfang der Moduldefinition hinzugefügt.

```elixir
defmodule Square do
  alias Integer, as: I

  def area(a), do: I.pow(a, 2)
end
```

## Import

Die spezielle Form `import` ermöglicht es dir, Funktionen aus einem externen Modul zu verwenden, ohne den Namen des Moduls anzugeben.

Das Importieren eines ganzen externen Moduls kann zu Konflikten mit vorhandenen lokalen Funktionen führen. Um dies zu vermeiden, stehen zwei Optionen zur Verfügung: `:except` und `:only`. Beide erwarten eine Keyword-Liste, bei der der Schlüssel der Funktionsname und der Wert die Arity der Funktion ist.

Normalerweise werden Importe am Anfang der Moduldefinition hinzugefügt.

```elixir
defmodule Square do
  import Integer, only: [pow: 2]

  def area(a), do: pow(a, 2)
end
```
