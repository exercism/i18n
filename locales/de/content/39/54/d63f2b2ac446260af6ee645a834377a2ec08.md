# Über

PHP verfügt über eine Reihe eingebauter Kontrollstrukturen für Schleifen, wie zum Beispiel `while`. Die grundlegende Form einer `while`-Anweisung ist:

```php
while (expr) {
  // statements
}
```

Solange der Ausdruck (_expr_) einen _truthy_-Wert ergibt, durchläuft die Schleife die Anweisungen in ihrem Inneren. Wenn der Ausdruck (_expr_) vor der ersten Iteration als falsch ausgewertet wird, werden die Anweisungen nie ausgeführt.

Alternativ kannst du eine `do-while`-Schleife verwenden, die die Anweisungen in der Schleife einmal ausführt, bevor der Ausdruck (_expr_) ausgewertet wird.

```php
do {
  // statements
} while (expr);
```
