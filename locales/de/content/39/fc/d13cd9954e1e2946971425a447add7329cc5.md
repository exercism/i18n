# Einführung

Fehler sind nützlich, um zu melden, wenn in einem Programm oder einem Stück Code etwas falsch oder unerwartet ist.

Sie sind JavaScript-Objekte.

Die Haupteigenschaft dieses Objekts ist `message`:

```javascript
const error = new Error('Oops, something went wrong');

console.log(error.message);
// => "Oops, something went wrong"
```

Mit der `throw`-Syntax kannst du einen Error werfen.

```javascript
throw new Error('Oops');
```

Wenn ein `Error` geworfen wird, wird die aktuelle Ausführung gestoppt und im ersten catch-Block des Aufrufstapels fortgesetzt.

```javascript
try {
  throw new Error('Oops');
} catch (error) {
  console.log(error.message);
  // => "Oops"
}
```

Wie bei jeder Klasse in JavaScript können Unterklassen mithilfe des `extends`-Schlüsselworts von `Error` erben, um benutzerdefinierte Fehler zu erstellen.
Die `instanceof`-Syntax prüft, ob der gefangene Fehler eine Instanz einer bestimmten Unterklasse von `Error` ist.

```javascript
class CustomError extends Error {}

try {
  // ... Code that may throw an error
} catch (error) {
  if (error instanceof CustomError) {
    console.log('The error thrown is an instance of the CustomError');
  }
}
```
