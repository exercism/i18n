# Zahlen

`INT` ist Sathers Typ für ganze Zahlen: `0`, `7`, `-3`. Eine Routine, die mit einer Ganzzahl antwortet, sagt das nach dem Doppelpunkt, so wie eine Routine, die mit Text antwortet, `STR` sagt.

```sather
   goals : INT is
      return 42;
   end;
```

Routinen können **Argumente** entgegennehmen: Werte, die beim Aufruf der Routine übergeben werden. Jedes Argument bekommt einen Namen und einen Typ, in runden Klammern nach dem Namen der Routine:

```sather
   total(first : INT, second : INT) : INT is
      return first + second;
   end;
```

Wenn zwei Argumente denselben Typ haben, kannst du sie zusammen benennen:

```sather
   total(first, second : INT) : INT is
```

Du rufst die Routine auf, indem du die Werte in runde Klammern setzt:

```sather
SCORES::total(3, 4)     -- this is 7
```

Die fünf Rechenoperatoren sind `+`, `-`, `*`, `/` und `%`.

`/` auf zwei `INT`s ist die **Ganzzahldivision**: Sie verwirft jeden Rest, statt einen Bruch zu liefern.

```sather
7 / 2      -- 3, not 3.5
```

`%` liefert, was bei dieser Division übrig bleibt.

```sather
7 % 2      -- 1
```

Beides gehört zusammen: `7` sind `3` mal `2`, und `1` bleibt übrig.
