# Ternärer Operator

Der ternäre Operator bietet eine alternative Syntax, um einen `if..else..`-Vergleich durchzuführen und einen Wert zurückzugeben.

## Syntax

PHP bietet eine if-Anweisung, bei der eine Aktion auf Grundlage der „Truthiness“ einer Bedingung ausgewertet werden kann.

```php
if ($condition) {
  $value = 1;
} else {
  $value = 2
}
```

Alternativ kann der ternäre Operator dieselbe Operation darstellen:

```php
$value = $condition
  ? 1  // True branch
  : 2; // False branch
```

Die Vergleichssyntax ist kurz und wird durch `(condition) ? (evaluate if true) : (evaluate if false);` dargestellt.

## Vorteile

Der offensichtliche Vorteil eines ternären Operators ist seine Kürze: Der bedingte Ausdruck lässt sich kürzer schreiben als eine `if..else..`-Anweisung. Es gibt aber noch einige weitere:

- Er ist ein Ausdruck, der in einem anderen Ausdruck verwendet werden kann.
- Er ermöglicht die verzögerte Auswertung der einzelnen Zweige.

  ```php
  function expensiveCalculation(): int
  {
    // An expensive calculation is performed
    $answerToEverything = 42;
    return $answerToEverything;
  }

  $needExactAnswer = false;
  $estimatedAnswer = 40;
  $answer = $needExactAnswer ? expensiveCalculation() : $estimatedAnswer;
  ```

  In diesem Beispiel wird die aufwendige Berechnung nicht aufgerufen, wenn die exakte Antwort nicht benötigt wird.

## Nachteile

Ternäre Operatoren haben mehrere Nachteile, weshalb man ihren Einsatz gut abwägen sollte:

- Ein ternärer Operator kann schwerer zu lesen sein, weil er auf der Interpretation von Symbolen beruht und nicht auf der Verwendung von Schlüsselwörtern.
- Ein ternärer Operator kann unbeabsichtigt zu Bugs führen, weil der ternäre Operator in PHP im Gegensatz zu den meisten modernen Sprachen (z. B. C, Java, JavaScript) linksassoziativ ist.
- Der ausgewertete Ausdruck in den Wahr- oder Falsch-Zweigen muss einen Wert zurückgeben.

## Noch kürzer

Die Ternärsyntax lässt sich weiter verkürzen zu `(condition) ?: (evaluate if falsey)`.
Eine Anwendung davon ist, in einem Ausdruck einen Ersatzwert bereitzustellen:

```php
$fruit = null;
eat($fruit ?: 'apple');
```

Das wird manchmal auch als _Elvis-Operator_ (`?:`) bezeichnet.
