# Über

Gleam kennt Funktionen erster Klasse. Das heißt, Funktionen sind ganz normale Werte, die du Variablen zuweisen, als Argumente übergeben und aus anderen Funktionen zurückgeben kannst.

Eine benannte Funktion, die in einem Modul definiert ist, kannst du über ihren Namen referenzieren.

```gleam
pub fn main() {
  // Assign the function to a variable
  let f = add_one
  
  // Invoke the function
  f(1) // -> 2
  f(2) // -> 3
}

fn add_one(x) {
  x + 1
}
```

Gleam kennt außerdem anonyme Funktionen. Sie werden innerhalb anderer Funktionen definiert.

```gleam
// Define the function
let f = fn(x) { x + 1 }

// Invoke the function
f(1) // -> 2
f(2) // -> 3
```

Den Typ einer Funktion schreibst du in einer ähnlichen Syntax wie bei anonymen Funktionen. Der Typ einer Funktion, die einen `Int` und einen `Float` entgegennimmt und einen `Int` zurückgibt, sieht so aus:

```gleam
fn(Int, Float) -> Int
```

Anonyme Funktionen können auf Variablen verweisen, die beim Definieren in ihrem Gültigkeitsbereich lagen. Dadurch sind sie _Closures_.

```gleam
let secret_number = 42

// This function always returns 42
fn() { secret_number }
```

Die _Function-Capture_-Syntax bietet eine praktische Kurzform, um anonyme Funktionen zu erstellen, die ein einzelnes Argument an eine Funktion übergeben. Diese beiden Ausdrücke sind äquivalent:

```gleam
// Anonymous function syntax
let f = fn(x) { my_function(1, 2, x) }

// Function capture syntax
let f = my_function(1, 2, _)
```
