# Einführung

## Module

Gleam-Code ist in Module organisiert, und jede Datei ist ein Gleam-Modul.

Bisher haben wir Funktionen mit der Syntax `pub fn` geschrieben. Damit definierst du eine Funktion, die anderen Modulen öffentlich zur Verfügung steht. Funktionen, die mit `fn` definiert werden, sind dagegen privat für das Modul, in dem sie definiert sind, und können nicht von anderen Modulen verwendet werden.

```gleam
// This function is public
pub fn add(x, y) {
  x + y
}

// This function is private
fn subtract(x, y) {
  x - y
}
```

Gleam-Module haben Namen, und der Name richtet sich nach ihrem Dateipfad innerhalb des Verzeichnisses `src` oder `test`.

Ein Modul, das in `src\geometry\rectangle.gleam` (unter Windows) oder `src/geometry/rectangle.gleam` (unter UNIX-ähnlichen Betriebssystemen) definiert ist, heißt zum Beispiel `geometry/rectangle`.

## Funktionen aus anderen Modulen importieren

Auf Funktionen, die in anderen Modulen definiert sind, greifst du über Importe zu. Wenn du ein Modul importierst, werden alle Funktionen darin zugänglich, die es nach außen freigibt. Wie du auf sie zugreifst, hängt aber davon ab, wie das Modul importiert wird.

Qualifizierte Importe sind der Standard. Auf eine Funktion in einem solchen Modul (zum Beispiel die Funktion `map` im Modul `gleam/list`) greifst du zu, indem du den Modulnamen voranstellst (`list.map`).

```gleam
// Import the int module
import gleam/int

pub fn run(x: Int) -> String {
  // Use the to_string function from the int module
  int.to_string(x)
}
```

Standardmäßig ist der Name, mit dem du auf das Modul verweist, der letzte Teil des Modulnamens, in diesem Fall `int`. Mit dem Schlüsselwort `as` kannst du das ändern.

```gleam
// Import the int module and refer to it as i
import gleam/int as i

pub fn run(x: Int) -> String {
  i.to_string(x)
}
```

Unqualifizierte Importe ermöglichen den direkten Zugriff auf die freigegebenen Funktionen in diesem Modul, ohne Präfix.

```gleam
// Import the to_string function from the int module
import gleam/int.{to_string}

pub fn run(x: Int) -> String {
  to_string(x)
}
```

Qualifizierte Importe sind vorzuziehen, weil sie für den Leser klarer machen, woher eine Funktion stammt, und weil sie Namenskonflikte vermeiden.


## Standardbibliothek

Gleam hat eine umfangreiche und gut dokumentierte Standardbibliothek. Die Dokumentation findest du online unter [hexdocs.pm/gleam_stdlib][docs]. Speichere dir diesen Link gut, du wirst ihn oft brauchen!

Die meisten eingebauten Datentypen haben ein passendes Modul mit Funktionen für diesen Datentyp: Es gibt zum Beispiel das Modul `gleam/int` für Ganzzahlen, das Modul `gleam/string` für Strings, das Modul `gleam/list` für Listen und so weiter.

[docs]: https://hexdocs.pm/gleam_stdlib/
