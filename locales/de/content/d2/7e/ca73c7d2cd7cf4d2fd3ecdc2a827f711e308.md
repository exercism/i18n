# Küchenrechner

## Geschichte

Diese Geschichte hilft dabei, [Tupel][type-tuple] in einer Sprache zu erkunden.

Grundannahme ist, dass Küchenzutaten oft auf obskure Weise gemessen werden und je nach Menge oder vorhandenen Werkzeugen unterschiedlich umgerechnet werden müssen. Tupel werden verwendet, um der numerischen Komponente der Messung [Duck-Typing][concept-duck-typing] zu verleihen.

Hier wird also die grundlegende Umrechnung von Werten mit Gleitkommazahlen erkundet.

### Umrechnungen

| Von                | Nach    |
| ------------------ | ------- |
| 1 mL               | 1mL     |
| 1 Tasse            | 240mL   |
| 1 Flüssigunze (US) | 29,57mL |
| 1 Teelöffel        | 5 mL    |
| 1 Esslöffel        | 15 mL   |

## Aufgaben

Dies sollte den Lernenden zeigen, wie sie Folgendes verwenden:

- Tupel
- Tupel als gruppierte Informationen
- Werte aus einem Tupel über den Elementindex abrufen
- Werte aus einem Tupel mithilfe des Musterabgleichs abrufen
- Neue Tupel erstellen
