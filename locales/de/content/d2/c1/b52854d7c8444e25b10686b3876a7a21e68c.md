# Einführung

## Ganzzahlen

Ganzzahlen sind ganze Zahlen, die zur Menge `{..., -2, -1, 0, 1, 2, ...}` gehören.
Die maximalen und minimalen Werte einer Ganzzahl hängen von dem System ab, auf dem PHP läuft.
Auf den meisten modernen Systemen ist eine Ganzzahl ein 64-Bit-Wert. Das bedeutet, sie kann `-9_223_372_036_854_775_808` bis `9_223_372_036_854_775_807` einschließlich darstellen.

```php
<?php

$a = 1234;
$a = 1_234_567;
```

Du kannst ganzzahlige Literale auch in einer anderen Basis als 10 schreiben, indem du ein Basispräfix verwendest:

```php
<?php

$a = 0123; // octal number (equivalent to 83 decimal)
$a = 0o123; // octal number (as of PHP 8.1.0)
$a = 0x1A; // hexadecimal number (equivalent to 26 decimal)
$a = 0b11111111; // binary number (equivalent to 255 decimal)
```

> Übernommen aus der PHP-[Dokumentation][syntax]

## Gleitkommazahlen

Gleitkommazahlen werden in PHP verwendet, um einen Teilbereich der reellen Zahlen darzustellen.
Sie beginnen mit einer oder mehreren Ziffern, die durch ein Dezimaltrennzeichen getrennt werden.

```php
<?php

$a = 1.234; 
$b = 1.2e3; 
$c = 7E-10;
$d = 1_234.567; // as of PHP 7.4.0
```

### Häufige Fallstricke

Nicht alle Zahlen und arithmetischen Operationen lassen sich mit Gleitkommazahlen ausführen.
Wenn du Gleitkommazahlen verwendest, um Dollar und Cent darzustellen, kann das zu Rundungsfehlern führen.

```php
<?php

$result = 0.1 + 0.2; // => 0.30000000000000004
```

## Arithmetische Operatoren

PHP bietet eine Reihe von Operatoren für arithmetische Operationen. Für seine arithmetischen Operatoren folgt PHP der üblichen mathematischen Reihenfolge der Operationen. Die von PHP bereitgestellten Operatoren sind:

* Identität (+)
* Negation (-)
* Addition (+)
* Subtraktion (-)
* Multiplikation (*)
* Division (/)
* Modulo (%)
* Potenzierung (**)

```php
$moles = +'10';
$aLotOfMoles = 6.022 * 10**23 * $moles;
```

[syntax]: https://www.php.net/manual/en/language.types.integer.php#language.types.integer.syntax
