# Einführung

Jedes Bit einer Ganzzahl kann verwendet werden, um einen binären Wert zu speichern.
Da viele Situationen binäre Informationen betreffen, etwa wahr oder falsch, Einschluss oder Ausschluss, an oder aus, bietet die Binärdarstellung einer N-Bit-Ganzzahl eine kompakte Möglichkeit, den binären Zustand von N Elementen zu kodieren.
Dadurch ist die Fähigkeit, Bits und Bytes zu manipulieren, im Assembler unerlässlich.
Der x86-64-Befehlssatz bietet eine Vielzahl von Befehlen zur Bitmanipulation.

## Manipulation einzelner Bits

Diese Befehle arbeiten mit einzelnen Bits in einem Operanden.

Alle nehmen zwei Operanden; der zweite gibt den Index des Bits an, das im ersten Operanden bearbeitet wird.
Alle kopieren das ausgewählte Bit in das **Carry-Flag (CF)**.

| Name  | Beschreibung                                                                   |
|-------|-------------------------------------------------------------------------------|
| `bt`  | kopiert das Bit in `CF`, ohne einen Operanden zu verändern                         |
| `bts` | kopiert das Bit in `CF` und setzt es im Zieloperanden                |
| `btr` | kopiert das Bit in `CF` und löscht es im Zieloperanden              |
| `btc` | kopiert das Bit in `CF` und komplementiert (kippt) es im Zieloperanden |

## Bitweise Operationen

Bitweise Operationen werden auf alle Bits eines Operanden angewendet.

Alle haben einen Befehl mit demselben Namen wie die ausgeführte bitweise Operation:

| Name   | Beschreibung                                  |
|--------|----------------------------------------------|
| `and`  | 1, wenn beide Bits 1 sind                          |
| `or`   | 1, wenn mindestens eines der Bits 1 ist            |
| `xor`  | 1, wenn die Bits verschieden sind                          |
| `not`  | 1, wenn das Bit 0 war; 0, wenn das Bit 1 war                |

Die meisten von ihnen nehmen zwei Operanden, führen eine bitweise Operation mit beiden durch und speichern das Ergebnis im Zieloperanden.
Die Ausnahme ist `not`, das nur einen Zieloperanden nimmt.

## Masken

Wenn wir Eins und Null als Einschluss bzw. Ausschluss interpretieren, nennt man eine Ganzzahl eine _Bitmaske_ (oder einfach eine _Maske_).

Eine Bitmaske „maskiert“ Elemente aus, weil eine Null im `i`-ten Bit das `i`-te Element ausschließt, während eine Eins es einschließt.
Wir verwenden eine Bitmaske auch häufig, um bestimmte Bits einer Ganzzahl einzuschließen und andere auszuschließen.

Zum Beispiel sei `A` eine Ganzzahl, deren Binärdarstellung so aussieht:

| Index | 7 | 6 | 5 | 4 | 3 | 2 | 1 | 0 |
|-------|---|---|---|---|---|---|---|---|
| Bits  | 1 | 0 | 0 | 1 | 0 | 1 | 0 | 1 |

Außerdem sei `M` eine Ganzzahl, deren Binärdarstellung so aussieht:

| Index | 7 | 6 | 5 | 4 | 3 | 2 | 1 | 0 |
|-------|---|---|---|---|---|---|---|---|
| Bits  | 0 | 0 | 0 | 0 | 1 | 1 | 0 | 1 |

Beide sind `8`-Bit-Ganzzahlen.
In diesem Fall können wir sagen, dass `M` die Bits `0`, `2` und `3` von `A` auswählt und die übrigen ausschließt.

Die zuvor besprochenen bitweisen Befehle sind nützlich, um Ganzzahlen mit Masken zu manipulieren.
Zum Beispiel:

- Um die Bits von `A` zu *löschen*, die nicht von `M` ausgewählt werden, nimm das bitweise AND: `A AND M`.
- Um die von `M` ausgewählten Bits von `A` zu *setzen*, nimm das bitweise OR: `A OR M`.

## TEST-Befehl

Der `test`-Befehl führt ein bitweises AND zwischen beiden Operanden aus und setzt die Flags entsprechend dem Ergebnis.

Wenn A der erste Operand und B der zweite ist:

| Flag | gesetzt, wenn              |
|:----:|:---------------------------|
| `CF` | immer gelöscht             |
| `ZF` | A AND B == 0               |
| `SF` | Vorzeichenbit von A AND B ist gesetzt |
| `OF` | immer gelöscht             |

Dieser Befehl nimmt zwei Operanden und aktualisiert die Flags, verändert aber **seine Operanden nicht**.

## Verschiebeoperationen

Diese Befehle verschieben die Bits im Zieloperanden um eine Anzahl von Positionen, die durch den zweiten Operanden angegeben wird.
Der zweite Operand muss eine konstante Zahl (ein `immediate`) oder das Register `cl` sein (die niedrigsten `8` Bits von `rcx`).

| Name        | Beschreibung              |
|-------------|--------------------------|
| `shl`/`sal` | Verschiebt Bits nach links  |
| `shr`/`sar` | Verschiebt Bits nach rechts |

Beachte, dass der Zählwert im zweiten Operanden auf `5` Bits maskiert wird, oder auf `6` Bits bei einem `64`-Bit-Zieloperanden.
Jedes Bit danach wird praktisch ignoriert.
Das bedeutet, dass die maximale Verschiebung `31` beträgt, oder `63` bei einem `64`-Bit-Operanden.

### Shl / Sal

Sowohl `shl` als auch `sal` führen genau dieselbe Operation aus, eines ist ein Alias des anderen.

Immer wenn eine Verschiebung nach links durchgeführt wird, werden Bits, die näher am Ende der Sequenz liegen als die Länge der Verschiebung, zuerst nach `CF` verschoben und dann verworfen.
Andererseits wird eine Anzahl neuer gelöschter Bits, die der Länge der Verschiebung entspricht, am Anfang hinzugefügt.

Da jedes Bit in einer Ganzzahl eine Potenz von `2` darstellt, hat eine Verschiebung nach links um n Positionen den Effekt, die Ganzzahl mit `2ⁿ` zu multiplizieren.

### Shr / Sar

Es gibt zwei Befehle, um Bits nach rechts zu verschieben: `shr` und `sar`.

Immer wenn einer der beiden Befehle verwendet wird, werden Bits, die näher am Anfang der Sequenz liegen als die Länge der Verschiebung, zuerst nach `CF` verschoben und dann verworfen.
Andererseits wird eine Anzahl neuer Bits, die der Länge der Verschiebung entspricht, am Ende hinzugefügt.

Der Unterschied zwischen ihnen ist, dass `shr` `0`-Bits an das linke Ende verschiebt, während `sar` `1` verschiebt, wenn das höchstwertige Bit gesetzt war, und andernfalls `0`.
Das bedeutet, dass `sar` das Vorzeichen bei der Verschiebung einer vorzeichenbehafteten Ganzzahl erhält.

Da jedes Bit in einer Ganzzahl eine Potenz von `2` darstellt, hat eine Verschiebung nach rechts um n Positionen mit `shr` den Effekt, eine *vorzeichenlose* Division durch `2ⁿ` durchzuführen.

Ähnlich hat eine Verschiebung nach rechts um n Positionen mit `sar` den Effekt, eine *vorzeichenbehaftete* Division durch `2ⁿ` durchzuführen.

## Rotationsoperationen

Diese Befehle drehen die Bits im Zieloperanden um eine Anzahl von Positionen, die durch den zweiten Operanden angegeben wird.
Der zweite Operand muss eine konstante Zahl (ein `immediate`) oder das Register `cl` sein (die niedrigsten `8` Bits von `rcx`).

Der Unterschied zwischen einer Rotation und einer Verschiebung besteht darin, dass eine Rotation keine Bits verwirft oder hinzufügt.
Bits, die bei einer Verschiebung verworfen würden, werden stattdessen an das gegenüberliegende Ende verschoben.
Alle Bits bleiben also erhalten, sie wechseln alle die Plätze.

| Name    | Beschreibung                |
|---------|----------------------------|
| `rol`   | Dreht Bits nach links   |
| `ror`   | Dreht Bits nach rechts  |

Beachte, dass der Zählwert im zweiten Operanden auf `5` Bits maskiert wird, oder auf `6` Bits bei einem `64`-Bit-Zieloperanden.
Jedes Bit danach wird praktisch ignoriert.
Das bedeutet, dass die maximale Rotation `31` beträgt, oder `63` bei einem `64`-Bit-Operanden.

## Weitere Bitmanipulationsbefehle

Es gibt weitere nützliche Bitmanipulationsbefehle:

| Name       | Beschreibung                                                                                          |
|------------|------------------------------------------------------------------------------------------------------|
| `popcnt`   | Zählt die Anzahl der gesetzten Bits                                                                        |
| `bsr`      | Ermittelt den Index des höchstwertigen gesetzten Bits. Wenn kein Bit gesetzt ist, ist das Ergebnis undefiniert                |
| `bsf`      | Ermittelt den Index des niedrigstwertigen gesetzten Bits. Wenn kein Bit gesetzt ist, ist das Ergebnis undefiniert               |

Diese Befehle arbeiten alle mit zwei `16`-Bit-, `32`-Bit- oder `64`-Bit-Operanden.
Diese Befehle können nicht mit `8`-Bit-Operanden verwendet werden.
