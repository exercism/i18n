# Einführung

Manchmal schreiben wir Funktionen, die zu einem bestimmten Typ gehören, etwa einem `struct`, `enum` oder `trait`. Solche Funktionen nennt man üblicherweise Methoden oder assoziierte Funktionen. Methoden sind assoziierte Funktionen, die auf einer Instanz eines bestimmten Typs aufgerufen werden. Assoziierte Funktionen sind Funktionen, die auf einem Typ definiert sind und im Allgemeinen auf dem Typ selbst aufgerufen werden.

Methoden und assoziierte Funktionen werden in einem `impl`-Block für einen Typ definiert. Der erste Parameter einer Methode in ihrer `fn`-Signatur ist immer `self` (oder eine Variante davon), während das bei einer assoziierten Funktion nicht der Fall ist. Hier ein Beispiel:

```rust
#[derive(Debug)]
struct Rectangle {
    width: u32,
    height: u32,
}

impl Rectangle {
    // Without `self` keyword as its first parameter, this is an associated function that returns a new instance of `Rectangle`.
    // `Self` is an alias for the type `Rectangle`.
    fn new(width: u32, height: u32) -> Self {
        Self {
            width,
            height,
        }
    }

    // `&self` borrows an immutable instance of the Rectangle type and reads its fields
    fn area(&self) -> u32 {
        self.width * self.height
    }

    // `&mut self` borrows a mutable instance of the Rectangle type and can mutate its fields
    fn change_width(&mut self, new_width: u32) {
        self.width = new_width;
    }
}

fn main() {
    let mut rect = Rectangle::new(30, 50);

    rect.change_width(60);

    println!(
        "The area of the rectangle is {} square pixels.",
        rect.area()
    );
    // => The area of the rectangle is 3000 square pixels.
}
```
