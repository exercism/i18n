# Über

[F#](https://try.fsharp.org/) ist eine streng typisierte, funktionale Sprache, die Teil von Microsofts .NET-Sprachfamilie ist.

F# eignet sich hervorragend für Probleme aus dem Bereich Data Science, aber es kann fast jedes Problem, das du ihm vorwirfst, elegant lösen.

Da F# auf der .NET-Runtime läuft, hast du Zugriff auf das gesamte .NET-Ökosystem, einschließlich aller Pakete auf [nuget.org](https://www.nuget.org/).

Die Integration in bestehenden .NET-Code ist noch einfacher, weil du mit F# auch objektorientierten Code schreiben kannst.

Die Homepage von F# ist [fsharp.org](http://fsharp.org/), und eine großartige Einführung in F# findest du auf der Website [F# for fun and profit](http://fsharpforfunandprofit.com/).
