# Anleitung

Du hilfst einem Freund, einen Bericht aus Messwerten zu erstellen, die er in verschiedenen Ecken seines Gartens aufgenommen hat.
Leider hat dein Freund die Daten in einem seltsamen Format gespeichert.
Jeder Messwert besteht aus einer Reihe durch Kommas getrennter Felder.
Allerdings hat er zweistellige Zahlen auf zwei Spalten verteilt gespeichert.

| Feldnummer | Bedeutung |
| --- | --- |
| 1 | ID-Nummer |
| 2 | Ort |
| 3 | erster Messwert, Zehnerwert |
| 4 | erster Messwert, Einerwert |
| 5 | zweiter Messwert, Zehnerwert |
| 6 | zweiter Messwert, Einerwert |

Für eine Eingabezeile wie `101,house,4,2,5,4`
- ist der erste Messwert `42`,
- ist der zweite Messwert `54`.

## Aufgabe 1: Bericht erstellen

Deine Aufgabe ist es, den Durchschnitt der beiden Messwerte zu ermitteln und die Ergebnisse jeder Zeile im folgenden Format auszugeben

```none
#<id>, <label> = <average>
```

Da der Durchschnitt von 42 und 54 48 ist, sollte die Ausgabe für die Beispielzeile so aussehen:

```none
#101, house = 48
```
