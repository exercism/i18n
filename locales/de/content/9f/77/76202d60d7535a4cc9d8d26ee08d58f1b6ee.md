# Über

Die Lambda-Klasse ist eine Sammlung funktionaler Methoden, mit denen du funktionale Programmierung in Haxe nutzen kannst. Sie ermöglicht es dir, ein ganzes Iterable auf einmal zu bearbeiten. Das ist oft einer Schleife vorzuziehen, denn es ist weniger fehleranfällig und leichter zu lesen. Der Einfachheit halber enthalten die Klassen Array und List einige der häufig verwendeten Methoden der Lambda-Klasse.

Einige der Funktionen der Klasse `Lambda` sind:

- `Lambda.array`, `Lambda.list` Wandelt ein Iterable in ein Array oder eine List um. Gibt immer eine neue Instanz zurück.
- `Lambda.count` Zählt die Anzahl der Elemente. Wenn das Iterable ein Array oder eine List ist, ist es schneller, seine length-Eigenschaft zu verwenden.
- `Lambda.has` Bestimmt, ob das angegebene Element im Iterable enthalten ist.
- `Lambda.indexOf` Ermittelt den Index des angegebenen Elements.
- `Lambda.find` Findet das erste Element, das die angegebene Suchfunktion erfüllt.
- `Lambda.concat` Führt zwei Iterables zusammen und gibt eine neue List zurück.
- `Lambda.filter` Findet die Elemente, die ein Kriterium erfüllen, und gibt eine neue List zurück.

Ein Beispiel, das einige dieser Funktionen zeigt:

```haxe
using Lambda;

class Main {
  static function main() {
    var words = ["boat", "dog", "phone", "cat", "food"];

    var isThreeLetters = function(word) return word.length == 3;

    trace(words.filter(isThreeLetters)); // [dog,cat]
  }
}
```
