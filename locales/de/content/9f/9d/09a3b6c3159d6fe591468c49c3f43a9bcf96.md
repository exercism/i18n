# Structs

Structs sind eigene Datentypen, mit denen du mehrere zusammengehörige Werte benennen und bündeln kannst.
Sie ähneln Tupeln, sind aber flexibler und lassen dich jeden einzelnen Wert benennen, was deinen Code übersichtlicher macht.
Structs in Cairo haben diese Eigenschaften:

- Jeder Struct-Typ hat einen bestimmten Namen.
- Jedes Element eines Structs wird als **Feld** bezeichnet.
- Jedes Feld eines Structs hat einen bestimmten Namen.
- Die Sichtbarkeit wird auf Feldebene verwaltet: Jedes Feld kann unabhängig öffentlich oder privat sein.

## Structs definieren und instanziieren

Um einen Struct zu definieren, verwendest du das Schlüsselwort `struct`, gefolgt von einem Namen und geschweiften Klammern, die die Felder mit ihren Namen und Typen enthalten:

```rust
#[derive(Drop)]
struct User {
    active: bool,
    username: ByteArray,
    email: ByteArray,
    sign_in_count: u64,
}
```

Um eine Instanz eines `struct` zu erzeugen, gibst du den Namen des `struct` an und verwendest geschweifte Klammern mit Schlüssel-Wert-Paaren für die Felder.
Beachte, dass du die Felder beim Erzeugen einer Instanz in beliebiger Reihenfolge angeben kannst:

```rust
let user1 = User {
   active: true, username: "someusername123", email: "someone@example.com", sign_in_count: 1
};

let user2 = User {
    sign_in_count: 1, username: "someusername123", active: true, email: "someone@example.com"
};
```

## Mit einer Instanz eines Structs arbeiten

Verwende die Punktnotation, um auf die Felder einer `struct`-Instanz zuzugreifen oder sie zu ändern.
Beachte, dass die Instanz veränderlich sein muss, um ein Feld zu ändern:

```rust
let mut user1 = User {
    active: true, username: "someusername123", email: "someone@example.com", sign_in_count: 1
};
user1.email = "anotheremail@example.com";
```

Wie bei jedem Ausdruck können wir eine neue Instanz des `struct` als letzten Ausdruck im Funktionskörper erzeugen, um diese neue Instanz implizit zurückzugeben:

```rust
fn build_user(email: ByteArray, username: ByteArray) -> User {
    User {
        email: email,
        username: username,
        active: true,
        sign_in_count: 1,
    }
}
```

## Kurzschreibweise für die Feldinitialisierung

Im letzten Beispiel war es sinnvoll, die Funktionsparameter `email` und `username` genauso zu benennen wie die Felder im `struct`. Sie beim Zuweisen an die Struct-Felder aber wiederholen zu müssen, ist etwas mühsam.
Zum Glück gibt es eine praktische Kurzschreibweise, um Struct-Felder aus Variablen mit denselben Namen zu initialisieren:

```rust
fn build_user_short(email: ByteArray, username: ByteArray) -> User {
    User { email, username, active: true, sign_in_count: 1, }
}
```

## Instanzen aus anderen Instanzen mit der Struct-Update-Syntax erzeugen

Verwende die Struct-Update-Syntax, um aus einer vorhandenen Instanz eine neue zu erzeugen und dabei einige Felder zu ändern, während der Rest gleich bleibt.
Das erreichst du mit dem Operator `..`.

Ohne Update-Syntax:

```rust
let user2 = User {
    active: user1.active,
    username: user1.username,
    email: "another@example.com",
    sign_in_count: user1.sign_in_count,
};
```

Mit Update-Syntax:

```rust
let user2 = User { email: "another@example.com", ..user1 };
```

Die Syntax `..user1` kopiert die übrigen Felder von `user1` nach `user2`.
Beachte, dass dabei die Daten von `user1` nach `user2` verschoben werden. Enthält `user1` nicht kopierbare Typen, kannst du `user1` danach nicht mehr verwenden.
