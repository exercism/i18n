# Anweisungen

In dieser Übung verarbeitest du Logzeilen.

Jede Logzeile ist ein String mit folgendem Format: `"[<LEVEL>]: <MESSAGE>"`.

Es gibt drei verschiedene Log-Level:

- `INFO`
- `WARNING`
- `ERROR`

Du hast drei Aufgaben, bei denen du jeweils eine Logzeile bekommst und etwas damit machen sollst.

## 1. Nachricht aus einer Logzeile holen

Implementiere die (_statische_) `LogLevels.message()`-Methode, die die Nachricht einer Logzeile zurückgibt:

```java
LogLevels.message("[ERROR]: Invalid operation")
// => "Invalid operation"
```

Führender und abschließender Leerraum sollte entfernt werden:

```java
LogLevels.message("[WARNING]:  Disk almost full\r\n")
// => "Disk almost full"
```

## 2. Log-Level aus einer Logzeile holen

Implementiere die (_statische_) `LogLevels.logLevel()`-Methode, die das Log-Level einer Logzeile zurückgibt, und zwar in Kleinbuchstaben:

```java
LogLevels.logLevel("[ERROR]: Invalid operation")
// => "error"
```

## 3. Eine Logzeile umformatieren

Implementiere die (_statische_) `LogLevels.reformat()`-Methode, die die Logzeile umformatiert, wobei die Nachricht zuerst kommt und das Log-Level danach in Klammern steht:

```java
LogLevels.reformat("[INFO]: Operation completed")
// => "Operation completed (info)"
```
