# const statt let und var bevorzugen

Statt \`${'kind'} ${'name'}\` solltest du \`const\` verwenden.

Die `const`-Deklaration verhindert, dass eine Variable versehentlich neu zugewiesen wird. Das sorgt für Sicherheit und verringert die kognitive Belastung für alle, die den Code lesen.
[Dieser Artikel](https://medium.com/javascript-scene/javascript-es6-var-let-or-const-ba58b8dcde75)
erklärt den Unterschied zwischen den dreien.
