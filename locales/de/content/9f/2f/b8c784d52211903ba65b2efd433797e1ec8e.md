# Einführung

Die I/O von Factor basiert auf *Streams*: Objekte, aus denen du Bytes oder Zeichen liest oder in die du sie schreibst. Das Vokabular [`io`][io] gibt dir zwei Sichten auf dasselbe [Protokoll][stream-protocol].

## Die beiden Sichten

Wörter für **explizite Streams** nehmen den Stream als Argument. Sie beginnen alle mit `stream-`:

```
stream-read       ( n stream -- seq/f )
stream-readln     ( stream -- str/f )
stream-write      ( seq stream -- )
stream-flush      ( stream -- )
stream-contents   ( stream -- seq )
stream-lines      ( stream -- seq )
```

Wörter für **ambientale Streams** lesen aus dem Stream, der *gerade gebunden* ist, oder schreiben in ihn: die programmweite dynamische Variable `input-stream` oder `output-stream`. Ihre Namen sind kurz:

```
read1 read readln write write1 print flush
```

Die ambientale Form verwendet der meiste Alltagscode. Zur expliziten Form greifst du, wenn du einen bestimmten Stream in der Hand hast und den ambientalen nicht austauschen willst.

## Streams im Speicher

In der Übung arbeitest du mit Streams auf Stringbasis aus [`io.streams.string`][io.streams.string]:

```
<string-reader>   ( str -- reader )
<string-writer>   ( -- writer )
```

Ein `<string-reader>` liest aus einem Literal-String, als wäre er eine Datei; ein `<string-writer>` sammelt alles, was in ihn geschrieben wird, sodass du es später zurücklesen kannst. Beide implementieren dasselbe Protokoll wie Datei-Streams, sodass sich das Gelernte direkt auf `<file-reader>` / `<file-writer>` übertragen lässt.

## Gültigkeitsbereich mit `with-…`

Um einen expliziten Stream für eine Quotation als den ambientalen zu binden und ihn danach freizugeben, verwendest du einen `with-…`-Kombinator:

```
with-input-stream    ( stream quot -- )
with-output-stream   ( stream quot -- )
with-string-writer   ( quot -- str )
with-file-reader     ( path encoding quot -- )
with-file-writer     ( path encoding quot -- )
```

[`with-string-writer`][with-string-writer] ist die praktische Form für „sammle, was diese Quotation ausgibt“: Sie erzeugt den Writer, führt die Quotation mit diesem Writer als ambientaler Ausgabe aus und gibt den aufgefangenen String zurück:

```factor
USING: io io.streams.string ;

[ "captured" print ] with-string-writer .
! => "captured\n"
```

Alle `with-…`-Kombinatoren sind Destruktor-Kombinatoren (dieselbe Familie wie `with-disposal` und `with-destructors` aus [`boatswains-bilge`][boatswains-bilge]): Der Stream wird beim Verlassen freigegeben, selbst wenn die Quotation eine Ausnahme auslöst.
