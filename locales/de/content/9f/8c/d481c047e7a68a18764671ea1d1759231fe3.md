# Anleitung

Du arbeitest weiterhin im Freizeitpark. Jetzt sollst du einige Hilfsmethoden schreiben, mit denen du prüfen kannst, ob ein Besucher ein Fahrgeschäft nutzen darf.

## 1. Prüfe, ob ein Besucher einen Fahrpass hat

Implementiere die Methode `Attendee#has_pass?`, die anhand des Vorhandenseins eines Fahrpasses einen booleschen Wert (`true`/`false`) zurückgibt.

```ruby
Attendee.new(100).has_pass?
# => false
```

## 2. Prüfe, ob ein Besucher in ein Fahrgeschäft passt

Implementiere die Methode `Attendee#fits_ride?`, um zu prüfen, ob ein Besucher von seiner Körpergröße her in ein Fahrgeschäft passt.
Die erforderliche Mindestgröße des Fahrgeschäfts wird als Argument übergeben.
Die Körpergröße eines Besuchers muss größer oder gleich der erforderlichen Mindestgröße des Fahrgeschäfts sein.

```ruby
Attendee.new(140).fits_ride?(100)
# => true
```

## 3. Prüfe, ob ein Besucher fahren darf

Implementiere die Methode `Attendee#allowed_to_ride?`, um zu prüfen, ob ein Besucher ein Fahrgeschäft nutzen darf. Die erforderliche Mindestgröße des Fahrgeschäfts wird als Argument übergeben. Ein Besucher muss einen Fahrpass haben und in das Fahrgeschäft passen.

```ruby
attendee = Attendee.new(100)
attendee.issue_pass!(42)
attendee.allowed_to_ride?(120)
# => false
```
