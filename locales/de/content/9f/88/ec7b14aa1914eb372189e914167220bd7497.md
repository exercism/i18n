# Eigene Iteratoren

Iteratoren benutzt du schon seit `bird-survey`. Jetzt schreibst du selbst einen.

## yield

Ein Iterator sieht aus wie eine Routine, mit zwei Unterschieden: Sein Name endet auf `!`, und er übergibt Werte mit `yield` statt mit `return`.

```sather
   markers!(count : INT) : INT is
      loop
         yield 100 * 1.upto!(count);
      end;
   end;
```

`yield` gibt einen Wert an die Schleife, die den Iterator aufgerufen hat, und **wartet** dann. Wenn diese Schleife wieder an der Reihe ist, macht der Iterator direkt nach dem `yield` weiter, und alles ist genau so, wie er es verlassen hat: seine Variablen, seine eigene Schleife, seine Position.

Genau das ist ein Iterator: eine Routine, die mittendrin pausieren und dann fortgesetzt werden kann.

```sather
   loop
      #OUT + TRAIL::markers!(3) + " ";      -- 100 200 300
   end;
```

## Beenden

Ein Iterator endet auf eine von zwei Arten.

**Auslaufen.** Wenn die eigene Schleife des Iterators endet oder die Routine ihr Ende erreicht, ist er vorbei, und die Schleife, die ihn aufgerufen hat, endet sofort.

**quit.** `quit` beendet ihn auf der Stelle, ohne etwas zu übergeben.

```sather
   named!(names : ARRAY{STR}) : STR is
      loop
         name ::= names.elt!;
         if name = "" then quit; end;
         yield name;
      end;
   end;
```

Das übergibt Namen, bis es auf einen leeren trifft, und hört dann auf. `quit` ist für einen Iterator das, was `return` für eine Routine ist, nur dass es keinen Wert mitführt: Es bleibt nichts mehr zu übergeben.

## once

Ein Argument, das mit `once` markiert ist, wird nur ein einziges Mal berechnet, nämlich beim Start der Schleife, und nicht bei jedem Durchlauf:

```sather
   markers!(once count : INT) : INT is
```

Nutze es für alles, was sich zwischen den Durchläufen nicht ändert; das trifft auf die meisten Argumente zu. Die Iteratoren der Bibliothek tun es auch: `upto!(once i : SAME)`.

## Iteratoren ohne Wert

Ein Iterator muss nicht unbedingt etwas übergeben. `times!` ist so einer:

```sather
   steps!(once count : INT) is
      loop
         ignored ::= 1.upto!(count);
         yield;
      end;
   end;
```

Ein bloßes `yield` übergibt nichts und lässt die Schleife einfach weiterlaufen.

## Wo die Position sitzt

Jede *Stelle im Programm*, die einen Iterator aufruft, behält ihre eigene Position. Deshalb läuft derselbe Iterator zweimal durch, wenn du ihn im selben Schleifenblock zweimal aufrufst. Jetzt wird klar, warum: Die beiden Aufrufe sind zwei getrennte pausierte Routinen.
