# Anweisungen

In dieser Übung arbeitest du an einem Terminplaner für einen Schönheitssalon, der am 15. September 2012 eröffnet wurde.

Du hast fünf Aufgaben, bei denen es alles um Termindaten geht.

## 1. Termindatum parsen

Implementiere die `Schedule`-Funktion, um eine textuelle Darstellung eines Termindatums in das entsprechende `time.Time`-Format zu parsen:

```go
Schedule("7/25/2019 13:45:00")
// => 2019-07-25 13:45:00 +0000 UTC
```

## 2. Prüfen, ob ein Termin bereits vorbei ist

Implementiere die `HasPassed`-Funktion, die ein Termindatum entgegennimmt und prüft, ob der Termin irgendwann in der Vergangenheit lag:

```go
HasPassed("July 25, 2019 13:45:00")
// => true
```

## 3. Prüfen, ob der Termin am Nachmittag liegt

Implementiere die `IsAfternoonAppointment`-Funktion, die ein Termindatum entgegennimmt und prüft, ob der Termin am Nachmittag liegt (>= 12:00 und < 18:00):

```go
IsAfternoonAppointment("Thursday, July 25, 2019 13:45:00")
// => true
```

## 4. Zeit und Datum des Termins beschreiben

Implementiere die `Description`-Funktion, die ein Termindatum entgegennimmt und eine Beschreibung dieses Datums und dieser Uhrzeit zurückgibt:

```go
Description("7/25/2019 13:45:00")
// => "You have an appointment on Thursday, July 25, 2019, at 13:45."
```

## 5. Den Jahrestag der Salon-Eröffnung zurückgeben

Implementiere die `AnniversaryDate`-Funktion, die den Jahrestag der Salon-Eröffnung für das aktuelle Jahr in UTC zurückgibt.

Angenommen, das aktuelle Jahr ist 2020:

```go
AnniversaryDate()

// => 2020-09-15 00:00:00 +0000 UTC
```

**Hinweis:** Der Rückgabewert ist ein `time.Time`, und die Tageszeit spielt keine Rolle.
