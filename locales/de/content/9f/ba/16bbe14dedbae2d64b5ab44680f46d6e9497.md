# About

Die Sequenzbibliothek von Factor stützt sich stark auf *Quotationen*, also Code in `[ ]`-Klammern, um die Iteration zu parametrisieren. Die Form ist immer dieselbe: Du übergibst eine Sequenz und eine Quotation, und das Wort höherer Ordnung führt die Quotation für jedes Element aus.

```factor
{ 1 2 3 4 5 } [ even? ] filter .   ! => { 2 4 }
{ 1 2 3 4 5 } [ even? ] reject .   ! => { 1 3 5 }
{ 1 2 3 4 5 } [ 3 > ] find .s      ! => 3 / 4 (index, element)
{ 1 2 3 4 5 } [ sq ] map .         ! => { 1 4 9 16 25 }
{ 1 2 3 4 5 } [ . ] each           ! prints each element
0 { 1 2 3 4 5 } [ + ] reduce .     ! => 15
```

Die gängigen Wörter im Überblick:

| Wort         | Stackeffekt                                |
|--------------|--------------------------------------------|
| `each`       | `( seq quot -- )`                          |
| `map`        | `( seq quot -- newseq )`                   |
| `filter`     | `( seq quot -- newseq )`                   |
| `reject`     | `( seq quot -- newseq )`                   |
| `find`       | `( seq quot -- i/f elt/f )`                |
| `find-last`  | `( seq quot -- i/f elt/f )`                |
| `reduce`     | `( seq init quot -- result )`              |
| `map-sum`    | `( seq quot -- n )`                        |
| `count`      | `( seq quot -- n )`                        |
| `any?`       | `( seq quot -- ? )`                        |
| `all?`       | `( seq quot -- ? )`                        |
| `with`       | `( value seq quot -- seq curry )`          |
| `without`    | `( seq exclude -- newseq )`                |
| `sort`       | `( seq -- sortedseq )`                     |
| `sum`        | `( seq -- n )`                             |
| `minimum`    | `( seq -- elt )`                           |
| `maximum`    | `( seq -- elt )`                           |
| `minimum-by` | `( seq quot -- elt )`                      |
| `maximum-by` | `( seq quot -- elt )`                      |

Wenn *dein* Wort eine Quotation zur Laufzeit an einen dieser Kombinatoren weiterreicht, deklariere dein Wort mit `; inline`, damit die Effektinferenz des Kombinators die Form der Quotation an der Aufrufstelle sehen kann. Wörter, die nur aus literalen Quotationen bestehen, brauchen das nicht.

Über die Kernoperationen für Sequenzen hinaus:

| Vokabular              | bietet                                        |
|--------------------|-----------------------------------------------|
| [`sorting`][sorting]          | `sort`, `sort-by`                             |
| [`math.statistics`][math.statistics]  | `cum-sum`, `cum-product`, `cum-min`, `cum-max` |
| [`grouping`][grouping]         | `group`, `clump`, `monotonic-split`           |
| [`sets`][sets]             | `members`, `all-unique?`                      |

Paar-Kombinatoren (`bi`, `tri`) und „n-stellige“ Kombinatoren (`2map`, `2each`, `zip`) erweitern dasselbe Muster, wenn die Quotation mehr als eine Eingabe braucht.
