# Anweisungen

Du wirst etwas Code schreiben, um den Bestand an Artikeln in einem Geschäft zu verwalten.
Der Bestand ist eine Hash-Referenz, die die Artikel und ihre Anzahl enthält.

## 1. Erstelle einen neuen Bestand mit den Artikeln

Ändere die Subroutine `InventoryManagement::create_inventory`, die eine Artikel-Array-Referenz als Argument entgegennimmt, so, dass sie eine neu erstellte Bestands-Hash-Referenz zurückgibt, deren Schlüssel die Artikelnamen und deren Werte die Anzahl sind.

## 2. Füge die Artikel zum Bestand hinzu

Ändere die Subroutine `InventoryManagement::add_items`, die eine Bestands-Hash-Referenz und eine Artikel-Array-Referenz als Argumente entgegennimmt, so, dass sie eine Hash-Referenz zurückgibt, bei der die Artikel zum Bestand hinzugefügt wurden.

## 3. Entferne die Artikel aus dem Bestand

Ändere die Subroutine `InventoryManagement::remove_items`, die eine Bestands-Hash-Referenz und eine Artikel-Array-Referenz als Argumente entgegennimmt, so, dass sie eine Hash-Referenz zurückgibt, bei der die Artikel aus dem Bestand entfernt wurden.
Die Anzahl der Artikel darf nicht unter null fallen.

## 4. Lösche den Artikel vollständig aus dem Bestand

Ändere die Subroutine `InventoryManagement::delete_item`, die eine Bestands-Hash-Referenz und einen Artikelnamen als Argumente entgegennimmt, so, dass sie eine Hash-Referenz zurückgibt, bei der der Artikel vollständig aus dem Bestand gelöscht wurde.
