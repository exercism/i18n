# Tests ausführen

Um die Tests für eine Übung auszuführen, führe das Skript `<exercise>.test` im Verzeichnis der Übung aus:

```bash
tclsh <exercise>.test
```

Bei den meisten Übungen wird jeder Test außer dem ersten übersprungen.
So kannst du testgetriebene Entwicklung betreiben: Du schreibst nur so viel Code, wie nötig ist, um die Tests einen nach dem anderen zu bestehen.
Um die Skip-Befehle zu überschreiben, setze die Umgebungsvariable `RUN_ALL` vor dem Ausführen der Testsuite auf einen gültigen Tcl-Wert für wahr \[1\]:

```bash
RUN_ALL=yes tclsh <exercise>.test
```

\[1\]: Tcl-Werte für wahr und falsch sind in der Manpage der C-Bibliotheksfunktion [Tcl_GetBoolean][bool] dokumentiert.

[bool]: https://www.tcl-lang.org/man/tcl8.6/TclLib/GetInt.htm
