# Ergänzung

## Hinweise zur Implementierung

Du schreibst eine Implementierung einer doppelt verketteten Liste.

Implementiere einen Node, der einen Wert und Zeiger auf den nächsten und vorherigen Knoten enthält.

Implementiere dann eine LinkedList, die Referenzen auf den ersten und letzten Knoten hält und eine array-ähnliche Schnittstelle zum Hinzufügen und Entfernen von Elementen bietet:

- `push` (*Wert hinten einfügen*);
- `pop` (*Wert hinten entfernen*);
- `shift` (*Wert vorne entfernen*);
- `unshift` (*Wert vorne einfügen*);
- `delete` (*den ersten passenden Knoten entfernen*)

Um deine Implementierung einfach zu halten, decken die Tests keine Fehlerfälle ab. Konkret: `pop` oder `shift` werden nie auf einer leeren Liste aufgerufen.
