# Einführung

In Python wird `None` häufig verwendet, um das Fehlen eines Werts darzustellen – ein Platzhalter, um eine `null`-Variable (also eine leere Variable), ein Objekt oder ein Argument zu definieren.

Wenn du in einer anderen Programmiersprache schon von einem `NULL`- oder `nil`-Typ gehört oder ihn verwendet hast, wird dir diese Verwendung von `None` in Python bekannt vorkommen. `None` hilft dir, Variablen oder Funktionsargumente zu deklarieren, für die du noch keine Werte hast. Diese kannst du später nach Bedarf mit konkreten Werten neu belegen.

```python
a = None
print(a)
#=> None
type(a)
#=> <class 'NoneType'>

# Adding a Default Argument with `None`
def add_to_todos(new_task, todo_list=None):
  if todo_list is None:
    todo_list = []
    todo_list.append(new_task)
  return todo_list

```

`None` wird bei einer Bedingungsprüfung zu `False` ausgewertet, deshalb ist es nützlich, um das „Vorhandensein“ oder „Fehlen“ eines Werts zu prüfen – von _irgendeinem_ Wert. Dieses Muster wird häufig verwendet, wenn eine Funktion oder ein Prozess ein Fehlerobjekt oder eine Fehlermeldung zurückgeben könnte.

```python
a = None
if a: #=> a will be evaluated to False when its used in a conditional check.
    print("This will not be printed")
```
