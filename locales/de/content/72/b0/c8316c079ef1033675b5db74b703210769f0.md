# Anweisungen

In dieser Übung arbeitest du mit Sparkonten.
Jedes Jahr wird der Kontostand deines Sparkontos anhand seines Zinssatzes aktualisiert.
Der Zinssatz, den dir deine Bank gewährt, hängt davon ab, wie viel Geld auf deinem Konto liegt (der Kontostand):

- 3,213 % bei einem Kontostand von weniger als `0` Dollar (der Kontostand wird stärker negativ).
- 0,5 % bei einem Kontostand von mindestens `0` Dollar und weniger als `1000` Dollar.
- 1,621 % bei einem Kontostand von mindestens `1000` Dollar und weniger als `5000` Dollar.
- 2,475 % bei einem Kontostand von mindestens `5000` Dollar.

Du hast vier Aufgaben, die sich jeweils mit deinem Kontostand und seinem Zinssatz befassen.

## 1. Berechne den Zinssatz

Implementiere die Funktion `InterestRate()`, um den Zinssatz anhand des angegebenen Kontostands zu berechnen:

```go
InterestRate(200.75)
// => 0.5
```

Beachte, dass der Rückgabewert ein `float32` ist.

## 2. Berechne die Zinsen

Implementiere die Funktion `Interest()`, um die Zinsen anhand des angegebenen Kontostands zu berechnen:

```go
Interest(200.75)
// => 1.003750
```

Beachte, dass der Rückgabewert ein `float64` ist.

## 3. Berechne die jährliche Aktualisierung des Kontostands

Implementiere die Funktion `AnnualBalanceUpdate()`, um die jährliche Aktualisierung des Kontostands zu berechnen, wobei der Zinssatz berücksichtigt wird:

```go
AnnualBalanceUpdate(200.75)
// => 201.75375
```

Beachte, dass der Rückgabewert ein `float64` ist.

## 4. Berechne die Jahre bis zum Erreichen des gewünschten Kontostands

Implementiere die Funktion `YearsBeforeDesiredBalance()`, um die minimale Anzahl von Jahren zu berechnen, die nötig ist, um den gewünschten Kontostand zu erreichen, wobei berücksichtigt wird, dass jedes Jahr Zinsen zum Kontostand hinzugefügt werden.
Das bedeutet, dass der Kontostand nach einem Jahr folgender ist: Anfangskontostand + Zinsen für den Anfangskontostand.
Der Kontostand nach dem zweiten Jahr ist: Kontostand nach einem Jahr + Zinsen für den Kontostand nach einem Jahr.
Und so weiter, bis der Kontostand des aktuellen Jahres größer oder gleich dem Zielkontostand ist.

```go
balance := 200.75
targetBalance := 214.88
YearsBeforeDesiredBalance(balance, targetBalance)
// => 14
```

Beachte, dass der Rückgabewert ein `int` ist.
