# Tests

Um die Tests der Übung über die Kommandozeile auszuführen, führe den folgenden Befehl im Verzeichnis der Übung aus:

```bash
clojure -M:test
```

## REPL

Um die Tests der Übung mit der REPL auszuführen, führe den folgenden Befehl im Verzeichnis der Übung aus:

```bash
$ clojure -m cljs.main -re node
```

Dann `require` den Test-Namespace der Übung und den Clojure-Test-Namespace):

```clojure
;; replace <exercise> with the exercise's name
=> (require '<exercise>-test)
nil
;; and the test namespace
=> (require 'cljs.test)
```

Wechsle den ns zum Test-Namespace:

```clojure
;; replace <exercise> with the exercise's name
=> (ns <exercise>-test)
nil
```

Rufe dann `run-tests` auf:

```clojure
=> (cljs.test/run-tests)
```
