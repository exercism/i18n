# Swift installieren

Swift ist für macOS, Linux und Windows verfügbar.
Wie die Installation abläuft, hängt von deinem Betriebssystem ab.
Wichtig für die Linux-Unterstützung: Swift wird (offiziell) nur auf den folgenden Distributionen unterstützt:
- Ubuntu
- Debian
- RedHat
- Fedora
- Amazon Linux

Wenn du eine andere Linux-Distribution verwendest, musst du selbst einen Weg finden, Swift zu installieren.

## Xcode (macOS)

Swift ist in Xcode enthalten, Apples IDE für die Entwicklung für macOS und iOS.
Für den Exercism-Track brauchst du Xcode in Version 16.0 oder höher.
Xcode gibt es kostenlos im [Mac App Store][xcode].
Weitere Versionen von Xcode (einschließlich der neuesten Beta) findest du im [Apples Entwicklerzentrum][apple-developer-center].

## macOS und Linux

Für macOS und Linux gibt es einen Swift-Installationsmanager namens [swiftly][swiftly].
Es ist ein Kommandozeilen-Tool, mit dem du mehrere Swift-Versionen auf deinem System installieren und verwalten kannst.
Den Befehl zum Installieren von swiftly unter macOS findest du [hier][swiftly-macos] und [hier][swiftly-linux] für Linux.

Eine weitere Installationsmöglichkeit für macOS ist [Homebrew][homebrew].
Unter Linux kannst du Swift mit dem Tarball von der offiziellen [Swift-Website][tarball] installieren.

## Windows

Für Windows empfehlen wir den [WinGet-Installer][winget-windows].
Du kannst Swift auch mit dem Paketmanager Scoop oder manuell installieren.
Alle Optionen findest du auf der Seite [Swift für Windows installieren][swift-windows].
