# Anweisungen

Du betreibst die Glücksspiele in der Spielhalle auf dem Boardwalk am Meer. Die Spieler würfeln, der Greifautomat zieht einen Preis, und am Kartentisch muss das Deck gemischt und müssen die Hände ausgeteilt werden. Alles angetrieben vom Zufall. Am Ende des Abends möchtest du außerdem eine „Replay“-Funktion, damit ein umstrittenes Spiel mit demselben Seed noch einmal ablaufen kann.

## 1. Würfle einen Würfel

Definiere `roll-die`, sodass es die Anzahl der Seiten entgegennimmt und einen Wurf im Bereich `1` bis `sides` (einschließlich) zurückgibt.

```factor
6 roll-die .
! => 4   (some value from 1..6)
```

## 2. Schnapp dir einen Preis

Definiere `pick-prize`, sodass es eine Sequenz von Preisen entgegennimmt und zufällig einen davon zurückgibt.

```factor
{ "teddy" "goldfish" "keyring" } pick-prize .
! => "goldfish"
```

## 3. Mische das Deck

Definiere `shuffle-deck`, sodass es ein Deck (eine Sequenz) entgegennimmt und es mit den Karten in zufälliger Reihenfolge zurückgibt.

```factor
{ 1 2 3 4 5 } shuffle-deck .
! => { 3 1 5 2 4 }
```

## 4. Teile eine Hand aus

Definiere `deal-hand`, sodass es ein Deck und eine Anzahl `n` entgegennimmt und `n` *verschiedene* Karten aus dem Deck zurückgibt.

```factor
{ 10 20 30 40 50 } 3 deal-hand .
! => { 40 10 30 }
```

## 5. Mit einem Seed erneut abspielen

Definiere `play-seeded`, sodass es einen Seed und eine Quotation entgegennimmt und die Quotation mit einem Generator ausführt, der mit dieser Ganzzahl als Seed initialisiert wird. So liefert derselbe Seed immer dasselbe Ergebnis. Das Ergebnis der Quotation soll an den Aufrufer zurückgegeben werden.

```factor
42 [ 6 roll-die ] play-seeded .
! => the same value every time for seed 42

! Same seed, same game:
99 [ 5 deal-hand ] play-seeded   99 [ 5 deal-hand ] play-seeded   =  .
! => t
```
