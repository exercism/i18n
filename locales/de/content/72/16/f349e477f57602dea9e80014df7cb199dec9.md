# Installation

## Installationsoptionen

Die aktuelle Unison-Version ist für Mac OS X, 64-Bit-Linux und Windows verfügbar! Wenn du Unison ausprobierst, würden wir uns freuen, wenn du im Exercism-Forum oder im [Unison Discord](https://unison-lang.org/discord) vorbeischaust. Stell Fragen und melde Probleme, auf die du stößt! Wir möchten, dass dein Einstieg einladend und positiv ist! 😊

Unison kannst du mit [homebrew](https://brew.sh/), [Nix](https://github.com/ceedubs/unison-nix/#usage) oder direkt über fertige Binärpakete herunterladen. Alle diese Download-Optionen sind auf der [Seite mit den Installationsanweisungen unserer Website](https://www.unison-lang.org/learn/quickstart/#installation-options) beschrieben. Sobald du das UCM installiert hast, komm hierher zurück!

### Option 1: Homebrew verwenden

Installiere zuerst [homebrew](https://brew.sh/), falls du es noch nicht hast.

Gib dann in der Kommandozeile diese Befehle ein:

```
brew tap unisonweb/unison
brew install unison-language
```

Damit wird die ausführbare Datei des Unison Codebase Managers installiert, `ucm`. Wenn du von einer früheren Version aktualisierst, genügt

```
brew upgrade unison-language.
```

Hinweis: Wenn du an dieser Stelle nach einem GitHub-Benutzernamen und Passwort gefragt wirst, prüfe, ob du unisonweb/unison richtig geschrieben hast.

### Option 2: Manuelle Installation für Mac- und Linux-Nutzer

[Die Links für die manuelle Installation unter Linux und Mac findest du hier](https://www.unison-lang.org/learn/quickstart/#installation-options) im jeweiligen Abschnitt zum manuellen Download für Linux und Mac.

Du wirst in deiner Shell einen Befehl ausführen, der ungefähr so aussieht, aber der obige Link enthält die aktuellste Binärdatei:

```
mkdir unisonlanguage
curl -L https://github.com/unisonweb/unison/releases/download/release_VERSION_NAME/ucm-YOUR_PLATFORM.tar.gz --output unisonlanguage/ucm.tar.gz
tar -xzf unisonlanguage/ucm.tar.gz -C unisonlanguage
./unisonlanguage/ucm
```

### Option 3: Manuelle Installation für Windows-Nutzer

1. Lege deine Standard-Terminalanwendung auf „Windows Terminal“ fest, um die besten Ergebnisse zu erzielen. Suche in den Einstellungen nach „Terminal“ oder folge [dieser Anleitung.](https://bit.ly/3IXwdlY)
2. Wenn du nicht sicher bist, ob du es schon hast, installiere Git:
  * Über winget: `winget install --id Git.Git -e --source winget`
  * Falls du Windows 10 verwendest und kein winget hast, kannst du es aus dem [Microsoft Store](https://www.microsoft.com/en-us/p/app-installer/9nblggh4nns1) installieren und dann den obigen Befehl ausführen.
3. [Lade das UCM über den hier angegebenen Link herunter](https://www.unison-lang.org/learn/quickstart/#installation-options) und entpacke es an einen Ort deiner Wahl.
4. Führe `ucm.exe` aus

### Option 4: Installation mit Nix
Gehe zu [https://github.com/ceedubs/unison-nix/#usage](https://github.com/ceedubs/unison-nix/#usage) und folge den Anweisungen in der dortigen Readme.

## Erstelle deine Unison-Codebasis

Führe `ucm` aus, um eine Unison-Codebasis in `$HOME/.unison` zu initialisieren. Dort speichert Unison Funktionsdefinitionen, Typen, Namensräume und so weiter. Standardmäßig beginnt der Unison Codebase Manager (kurz „UCM“) damit, die Standardbibliothek herunterzuladen, die `base` heißt und die du zum Schreiben von Unison-Code verwendest. Das kann einen Moment dauern! 🕰

## Unison-Workflow

Wenn du Unison-Code schreiben möchtest, gibst du den Befehl `ucm` ein, um den Codebase Manager zu starten. Der UCM beobachtet dann Änderungen an jeder Datei mit der Endung `.u` in dem Verzeichnis, aus dem er aufgerufen wurde. Du könntest zum Beispiel Funktionen in einer Datei namens `scratch.u` in einem Verzeichnis namens `~/exercism/unison/my-exercise/` implementieren. Dann solltest du mit `cd` in `~/exercism/unison/my-exercise/` wechseln und `ucm` ausführen. So stellst du sicher, dass der UCM deine Datei `scratch.u` auf Änderungen überwacht.

Wenn du dir mal unsicher bist, welches Verzeichnis der `ucm` auf Dateiänderungen überwacht, wird es beim Start der Kommandozeile im Willkommensbildschirm angezeigt.

```
👀 I'm watching for changes to .u files under /Users/myUser/exercism/unison/my-exercise
```

[Hier findest du weitere Tipps zum Workflow!](https://exercism.org/docs/tracks/unison/workflow)

## Editor-Unterstützung

Zum Schreiben deiner `.u`-Dateien kannst du jeden beliebigen Texteditor verwenden. Unison bietet [LSP-Unterstützung](https://github.com/unisonweb/unison/blob/trunk/docs/language-server.markdown), sodass deine Lieblings-IDE dich mit Dingen wie Typen beim Hovern und Autovervollständigung unterstützen kann. Ein paar beliebte Editoren mit Unison-Unterstützung sind unten aufgeführt:

### Vim

Mit [vim-plug](https://github.com/junegunn/vim-plug):

1. Installiere [`vim-plug`](https://github.com/junegunn/vim-plug), falls du es noch nicht hast.
2. Füge Folgendes zu deiner .vimrc hinzu: `Plug 'unisonweb/unison', { 'branch': 'trunk', 'rtp': 'editor-support/vim' }`
3. Führe den Vim-Befehl `:PlugInstall` aus.

Weitere Informationen erhältst du, wenn du innerhalb von Vim `:help unison` ausführst oder dir die [Online-Hilfe](https://github.com/unisonweb/unison/blob/trunk/editor-support/vim/doc/unison.txt) ansiehst.

### Atom
Führe in der Konsole aus:

```
apm install unisonweb/atom-unison
```

### VS Code

1. Rufe die Extensions-Ansicht auf, indem du in der Aktivitätsleiste am Rand von VS Code auf das Extensions-Symbol klickst, oder mit ⇧⌘X.
2. Suche nach „unison“
3. Installiere die [Unison VS Code-Erweiterung](https://marketplace.visualstudio.com/items?itemName=unison-lang.unison)

### Emacs
Installiere [`unison-mode`](https://github.com/dariooddenino/unison-mode-emacs).
