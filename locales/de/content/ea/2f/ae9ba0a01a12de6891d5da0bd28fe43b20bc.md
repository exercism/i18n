# Anleitung

In dieser Übung schreibst du Code, um Namensschilder für Fabrikmitarbeiter zu drucken.

## 1. Ein Namensschild für einen Mitarbeiter drucken

Mitarbeiter haben eine ID, einen Namen und einen Abteilungsnamen. Die Beschriftung eines Mitarbeiter-Namensschilds ist folgendermaßen aufgebaut: `"[id] - name - DEPARTMENT"`.
Implementiere die Methode `Badge.print()`, um die Beschriftung des Namensschilds eines Mitarbeiters zurückzugeben:

```java
Badge badge = new Badge();
badge.print(734, "Ernest Johnny Payne", "Strategic Communication");
// => "[734] - Ernest Johnny Payne - STRATEGIC COMMUNICATION"
```

Beachte, dass die Abteilung auf dem Schild in Großbuchstaben geschrieben werden muss.

## 2. Ein Namensschild für einen neuen Mitarbeiter drucken

Aufgrund einer Eigenheit im Computersystem haben neue Mitarbeiter manchmal noch keine ID, wenn sie ihre Arbeit in der Fabrik beginnen.
Da Namensschilder Pflicht sind, erhalten sie ein vorläufiges Namensschild ohne das ID-Präfix. Ändere die Methode `Badge.print()`, damit sie auch neue Mitarbeiter unterstützt, die noch keine ID haben:

```java
Badge badge = new Badge();
Badge.print(null, "Jane Johnson", "Procurement");
// => "Jane Johnson - PROCUREMENT"
```

## 3. Ein Namensschild für den Besitzer drucken

Sogar der Besitzer der Fabrik muss jederzeit ein Namensschild tragen.
Ein Besitzer hat jedoch keine Abteilung. In diesem Fall soll auf dem Schild `"OWNER"` statt des Abteilungsnamens stehen.
Ändere die Methode `Badge.print()`, damit sie ein Schild für den Besitzer ausgibt:

```java
Badge badge = new Badge();
badge.print(254, "Charlotte Hale", null);
// => "[254] - Charlotte Hale - OWNER"
```

Beachte, dass der Besitzer gleichzeitig auch ein neuer Mitarbeiter sein kann:

```java
Badge badge = new Badge();
badge.print(null, "Charlotte Hale", null);
// => "Charlotte Hale - OWNER"
```
