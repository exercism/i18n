# Modeboutique

## Geschichte

Du betreibst eine Online-Modeboutique. Der Black Friday steht vor der Tür, also musst du dein Inventar überprüfen, um sicherzugehen, dass du bereit bist.

Ein einzelner Artikel im Inventar wird durch eine Map oder ein Wörterbuch dargestellt, und das ganze Inventar ist eine Liste oder ein Array solcher Maps oder Wörterbücher.

```elixir
%{
  name: "White Shirt",
  price: 40,
  quantity_by_size: %{s: 3, m: 7, l: 8, xl: 4}
}
```

## Aufgaben

- Artikel nach Preis sortieren
- Alle Artikel mit fehlendem Preis finden
- Die Menge eines Artikels erhöhen
- Die Gesamtmenge eines Artikels berechnen
