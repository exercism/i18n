# Ergänzung zur Anleitung

## Projektstruktur

Clojure-Übungen bei Exercism unterstützen die zwei gängigsten Werkzeuge für Abhängigkeitsverwaltung und Tests, [leiningen][leiningen] und die [Clojure CLI][clojure-cli].

Im Verzeichnis `test` findest du eine Testdatei namens `hello_world_test.clj`.
Schreib deinen Code in `src/hello_world.clj`. Er sollte den Namensraum `hello-world` verwenden, damit die Tests ihn aufgreifen können.

### Tests mit der Clojure CLI ausführen

```
$ clj -X:test
```

### Tests mit Leiningen ausführen

```
$ lein test

lein test hello-world-test

Ran 3 tests containing 3 assertions.
0 failures, 0 errors.
```

Dann reichst du die Übung ein mit:

```
$ exercism submit src/hello_world.clj
```

Ausführlichere Anleitungen und Lernressourcen findest du auf [der Clojure-Sprachseite von Exercism][exercism-clojure].

[leiningen]: https://leiningen.org
[clojure-cli]: https://clojure.org/guides/deps_and_cli
[exercism-clojure]: https://exercism.org/tracks/clojure
