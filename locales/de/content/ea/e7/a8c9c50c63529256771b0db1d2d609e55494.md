# Einführung

Comprehensions bieten eine Möglichkeit, _Enumerables_ einfach und deklarativ umzuwandeln.

Um eine sehr einfache Comprehension zu deklarieren, können wir das Schlüsselwort `for` verwenden, gefolgt von einem _Generator_ und einem _do-Block_, der die neuen Werte aus den aufgezählten Werten erzeugt.

```elixir
for n <- [0, 1, 2, 3], do: n + 1
# => [1, 2, 3, 4]
```

Comprehensions können auch _Filter_ haben. Werte, die den Filter nicht passieren, werden aus der endgültigen Liste entfernt:

```elixir
for n <- [0, 1, 2, 3], n > 1, do: n + 1
# => [3, 4]
```

Wir können kompliziertere Comprehensions über mehrere Zeilen deklarieren:

```elixir
for {atom, number} <- [a: 1, b: 2, c: 3, d: 4],
    rem(number, 2) == 0 do
  atom
end

# => [:b, :d]
```

Ein _kartesisches Produkt_ lässt sich mit mehreren Generatoren erstellen. Das bedeutet, dass jeder Wert, der vom ersten Generator erzeugt wird, einmal mit jedem Wert gepaart wird, der vom zweiten Generator erzeugt wird:

```elixir
for x <- [0, 1],
    y <- [0, 1] do
  {x, y}
end

# => [{0, 0}, {0, 1}, {1, 0}, {1, 1}]
```
