# Einführung

## Bedingte Anweisungen

Bedingte Anweisungen sind Entscheidungsanweisungen, die entweder Seiteneffekte ausführen oder den Ablauf der Ausführung durch ein Programm steuern können.
Zu den bedingten Anweisungen gehören `if`-, `if/else`-, `switch`- und `ternary`-Anweisungen.

Bedingte Anweisungen werden verwendet, um Fragen über einen Wert oder eine Beziehung zwischen Werten zu stellen.
Die Frage ergibt eine boolesche Antwort, aber die `if`-Anweisung selbst kann einen beliebigen Wert zurückgeben oder einfach einen Seiteneffekt ausführen.

## if-Anweisungen

Die einfachste `if`-Anweisung wertet einen Ausdruck aus und führt eine Zeile aus.
Der getestete Ausdruck steht immer in runden Klammern.

Sie kann einen Seiteneffekt ausführen

```c
if (count > 10)
    printf("count is greater than 10");
```

oder sie kann den Ablauf der Ausführung ändern


```c
if (count > 10)
    return sum;
```

Wenn eine `if`-Anweisung mehr als eine Zeile ausführt, muss sie die Zeilen in geschweifte Klammern setzen

```c
if (count > 10) {
    printf("count is greater than 10");
    return sum;
}
```

Manche Teams legen als Standard fest, dass `if`-Anweisungen immer geschweifte Klammern verwenden sollten, auch bei nur einer Zeile.


## if-else

Eine `if`-Anweisung kann mit einem `else` gekoppelt werden

```c
if (number % 2 == 0)
    return "even";
else
    return "odd";
```

## if-else-if


`else` kann mit einem weiteren `if` gekoppelt werden, um das zu erzeugen, was man eine `if-else-if ladder` nennt.

```c
if (number == 0)
    return "zero";
else if (number < 0)
    return "negative";
else if (number < 10)
    return "single digit";   
else if (number % 2 == 0)
    return "even";
else
    return "odd";
```

## switch


Manchmal lässt sich eine `if-else-if ladder` besser durch ein `switch` darstellen.
Wie bei `if` steht der getestete Ausdruck immer in runden Klammern.

```c
switch (number) {
    case -1:
        return "negative one";
    case 0:
        return "zero";
    case 1:
        return "positive one";
    case 10:
        return "positive ten";
    case -10:
        return "negative ten";
    default:
        return "don't care";
}
```

Der `default`-Fall wird ausgeführt, wenn der getestete Wert mit keinem der vorherigen Fälle übereinstimmt.

Wenn ein `switch`-Fall nicht zurückgibt, wird normalerweise ein `break` eingefügt, um jeden Fall zu beenden, sonst „fällt“ die Logik durch zum nächsten Fall.
Manchmal ist das Durchfallen beabsichtigt

```c
switch (number) {
    case 0:
        msg = "zero"; break;
    case 1:
        msg = "one"; break;
    case 2: case 3: case 4:
        msg = "more than one and less than five"; break;
    default:
        msg = "don't care";
}
```

Wenn das Durchfallen unbeabsichtigt passiert, ist es ein Bug.

```c
switch (number) {
    case 0:
        msg = "zero"; // bug! fallthrough of 0 will set msg to "one"
    case 1:
        msg = "one"; break; 
    case 2: case 3: case 4:
        msg = "more than one and less than five"; break;
    default:
        msg = "don't care";
}
```

Ein switch kann von Vorteil sein, wenn du gegen bestimmte Werte statt gegen einen Wertebereich testest.
Er kann schneller sein als eine `if-else-if ladder`, weil der Compiler die `switch`-Anweisung möglicherweise optimieren kann, was mit einer `if-else-if ladder` nicht geht.
Ein switch kann manchmal auch lesbarer aussehen.

## Ternärer Operator (auch Bedingungsoperator)

Der ternäre Operator ist eine dreiteilige bedingte Anweisung, die oft zum Setzen eines Werts verwendet wird.
Der zu testende Ausdruck steht vor dem Fragezeichen und muss nicht in Klammern stehen.
Der Wert, der bei wahr zurückgegeben wird, steht vor dem Doppelpunkt, der Wert bei falsch danach.
Zurückgegeben werden kann entweder ein Wertliteral oder eine Variable.

```c
int i = j > 5 ? 5: j;
```

Ternäre Operatoren können verschachtelt werden, um syntaktischen Ballast zu reduzieren.

```c
// the below could also be 
i = j > 5 ? j :k > 5 ? k: 10;
// but that may not be quite as readable

i = j > 5 ? j
    :k > 5 ? k
    :10;

// which is the same as
if (j > 5) i = j;
else if (k > 5) i = k;
else i = 10;
```
