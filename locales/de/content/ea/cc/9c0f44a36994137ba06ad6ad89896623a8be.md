# Anleitung

Mecha Munch™, ein Unternehmen für die Automatisierung des Lebensmitteleinkaufs, hat dich gerade eingestellt, um an seiner Bestell-App mitzuarbeiten.
Dein Team hat die Aufgabe, ein MVP (_[Minimum Viable Product][mvp]_) zu bauen, das alle grundlegenden Aktivitäten rund um den Warenkorb abdeckt und es Nutzern ermöglicht, ihre Einkäufe hinzuzufügen, zu entfernen und zu sortieren.
Zum Glück kümmert sich ein anderes Team um alle Geld- und Bezahlvorgänge!

## 1. Artikel zum Warenkorb des Nutzers hinzufügen

Der MVP sollte es dem Nutzer ermöglichen, Artikel zu seinem Warenkorb hinzuzufügen.
Das kann ein einzelner Artikel oder mehrere auf einmal sein.
Da es sich um einen MVP handelt, wird die Artikelmenge durch _Wiederholungen_ angegeben.
Wenn ein Nutzer 2 Oranges hinzufügen möchte, erscheint „Oranges" zweimal im übergebenen Iterable.
Wenn der Nutzer den Artikel bereits im Warenkorb hat, sollte die Menge im Warenkorb um 1 erhöht werden.
Wenn der Artikel _neu_ im Warenkorb ist, sollte er mit der Menge 1 hinzugefügt werden.

Erstelle die Funktion `add_items!(<cart>, <items>)`, die ein Warenkorb-Wörterbuch und ein Iterable von hinzuzufügenden Artikeln als Argumente entgegennimmt.
Sie sollte das aktualisierte Warenkorb-Wörterbuch für den Nutzer zurückgeben.

```julia-repl
julia> additems!(Dict("Banana" => 3, "Apple" => 2, "Orange" => 1),
                 ("Apple", "Apple", "Orange", "Apple", "Banana"))
Dict{String, Int64} with 3 entries:
  "Apple"  => 5
  "Orange" => 2
  "Banana" => 4

julia> additems!(Dict("Banana" => 3, "Apple" => 2, "Orange" => 1),
                 ["Banana", "Orange", "Blueberries", "Banana"])
Dict{String, Int64} with 4 entries:
  "Blueberries" => 1
  "Apple"       => 2
  "Orange"      => 2
  "Banana"      => 5
```

## 2. Den Rezeptbereich „Ideen" aktualisieren

Die App hat einen Bereich „Ideen", der mit fertigen Rezepten aus verschiedenen Küchen gefüllt ist.
Der Nutzer kann eines dieser Rezepte auswählen und alle Zutaten automatisch zu seinem Warenkorb hinzufügen lassen.
Die Projektleitung hat dich gebeten, eine Möglichkeit zum Bearbeiten dieser „Ideen"-Rezepte zu schaffen, weil das Content-Team ständig Zutaten und Mengen ändert.

Erstelle die Funktion `update_recipes!(<ideas>, <updates>)`, die ein „Ideen"-Wörterbuch und ein Wörterbuch mit Rezeptänderungen als Argumente entgegennimmt.
Die Funktion sollte das aktualisierte „Ideen"-Wörterbuch zurückgeben.

## 3. Den Warenkorb des Nutzers zur Abwicklung an den Laden senden

Die App muss den Warenkorb eines bestimmten Nutzers zur Abwicklung an den Laden senden.
Die Einkäufer im Laden müssen jedoch wissen, wo der Artikel mithilfe eines eindeutigen Gangcodes zu finden ist.
Der „Abwicklungs-Warenkorb" muss nach den Gangcodes der Artikel sortiert werden, damit die Einkäufer effizienter arbeiten können.

Erstelle die Funktion `send_to_store(<cart>, <aislecodes>)`, die einen Warenkorb und ein Wörterbuch mit den Gangnummern des Ladens entgegennimmt.
Die Funktion sollte einen kombinierten „Abwicklungs-Warenkorb" zurückgeben, der für jeden bestellten Artikel ein Paar `aislecode => quantity` enthält.
Die Artikel sollten in der Reihenfolge ihrer Gangcodes erscheinen.

```julia-repl
julia> cart = Dict("Orange" => 1, "Milk" => 2, "Banana" => 3, "Apple" => 2, "Chocolate" => 2);

julia> aislecodes = Dict("Orange" => 2.4, "Milk" => 3.3, "Banana" => 2.6, "Apple" => 2.2, "Chocolate" => 5.7);

julia> send_to_store(cart, aislecodes)
5-element Vector{Pair{Float64, Int64}}:
 2.2 => 2
 2.4 => 1
 2.6 => 3
 3.3 => 2
 5.7 => 2
```

## 4. Den Ladenbestand an die Bestellung eines Nutzers anpassen.

Die App kann nicht einfach endlos Kundenbestellungen aufgeben.
Irgendwann gehen dem Laden verschiedene Produkte aus.
Deshalb muss dein MVP den Ladenbestand jedes Mal aktualisieren, wenn ein Nutzer seine Bestellung an den Laden sendet.
Sonst bestellen Kunden Produkte, die gar nicht verfügbar sind.

Erstelle die Funktion `update_store_inventory!(<inventory>, <cart>)`, die einen `cart` und ein `inventory` entgegennimmt.
Die Funktion sollte die Bestandsmengen des Ladens um die im „cart" bestellten Mengen verringern und dann ein Wörterbuch mit allen Artikeln zurückgeben, die ausverkauft sind (also `0` erreicht haben).

```julia-repl
julia> inventory = Dict("Banana" => 15, "Apple" => 12, "Orange" => 1, "Milk" => 4);

julia> cart = Dict("Orange" => 1, "Milk" => 2, "Banana" => 3, "Apple" => 2);

julia> update_store_inventory!(inventory, cart)
Dict{String, Int64} with 1 entry:
  "Orange" => 0

julia> inventory
Dict{String, Int64} with 4 entries:
  "Milk"   => 2
  "Apple"  => 10
  "Orange" => 0
  "Banana" => 12
```

## 5. Ausverkaufte Artikel nachbestellen.

Über die Aktualisierung des Bestands hinaus kann deine App auch beim Auffüllen helfen.
Dein MVP sollte in der Lage sein, eine Mini-Bestellung für alle Artikel vorzubereiten, die nach der Bestellung eines Kunden ausverkauft sind.
Das macht es einfacher, eine große Bestellung auszulösen.
Außerdem gibt es manchmal zeitlich begrenzte Aktionsartikel, die nicht auf der Bestandsliste stehen.
Wenn diese vor Ende des Aktionszeitraums ausverkauft sind, haben sie sich als beliebt erwiesen und können zur Bestandsliste hinzugefügt werden.

Erstelle die Funktion `reorder!(<outofstock>, <stock>)`, die `outofstock` und `stock` entgegennimmt.
Das `stock`-Wörterbuch enthält die Standard-Bestandsartikel und ihre Nachbestellmengen.
Das `outofstock`-Wörterbuch ist das Ergebnis von `update_store_inventory!`, nämlich ein Wörterbuch mit Artikeln der Menge null.
Die Mengen in `outofstock` sollten an die in `stock` angepasst und zurückgegeben werden.
Außerdem sollten alle Artikel in `outofstock`, die nicht in `stock` vorhanden sind, mit der Standardmenge `100` zu `stock` hinzugefügt werden.

```julia-repl
julia> inventory = Dict("Banana" => 15, "Apple" => 12, "Orange" => 1, "Milk" => 4, "Chocolate" => 2);

julia> cart = Dict("Orange" => 1, "Milk" => 2, "Banana" => 3, "Apple" => 2, "Chocolate" => 2);

julia> stock = Dict("Banana" => 150, "Apple" => 120, "Orange" => 120, "Milk" => 45);

julia> outofstock = update_store_inventory!(inventory, cart)
Dict{String, Int64} with 1 entry:
  "Orange"    => 0
  "Chocolate" => 0

julia> reorder!(outofstock, stock)
Dict{String, Int64} with 1 entry:
  "Orange"    => 120
  "Chocolate" => 100

julia> stock 
Dict{String, Int64} with 5 entries:
  "Milk"      => 45
  "Apple"     => 120
  "Chocolate" => 100
  "Orange"    => 120
  "Banana"    => 150
```
