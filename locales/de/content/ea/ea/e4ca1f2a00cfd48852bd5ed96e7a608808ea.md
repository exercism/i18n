# Einführung

Eine `switch`-Anweisung wertet einen Ausdruck aus und führt den ersten `case` aus, der zu seinem Wert passt.
Sie ist oft eine sauberere Alternative zu langen `if ... else if`-Ketten.
Zum Beispiel

```go
operatingSystem := "windows"

if operatingSystem == "windows" {
    // do something if the operating system is windows
} else if operatingSystem == "linux" {
    // do something if the operating system is linux
} else if operatingSystem == "macos" {
    // do something if the operating system is macos
} else {
    // do something if the operating system is none of the above
}
```

lässt sich so umschreiben:

```go
operatingSystem := "windows"

switch operatingSystem {
case "windows":
    // do something if the operating system is windows
case "linux":
    // do something if the operating system is linux
case "macos":
    // do something if the operating system is macos
default:
    // do something if the operating system is none of the above
}
```

Mehrere Werte kannst du mit einem Komma zu einem einzigen `case` zusammenfassen.
Der `case` passt, wenn der Ausdruck einem der Werte entspricht:

```go
switch operatingSystem {
case "windows", "linux":
    // do something if the operating system is windows or linux
case "macos":
    // do something if the operating system is macos
default:
    // do something if the operating system is none of the above
}
```

Der Ausdruck nach `switch` kann auch ganz weggelassen werden.
Dann enthält jeder `case` einen booleschen Ausdruck, und der erste `case`, der wahr ist, wird ausgeführt.

```go
age := 21

switch {
case age > 20 && age < 30:
    // do something if age is between 20 and 30
case age == 10:
    // do something if age is equal to 10
default:
    // do something else for every other case
}
```
