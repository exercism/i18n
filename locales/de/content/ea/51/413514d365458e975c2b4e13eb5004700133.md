# Generische Datentypen

Generics in Cairo ermöglichen dir, wiederverwendbaren Code zu schreiben, der mit verschiedenen Typen funktioniert. Das vermeidet Duplikate und verbessert die Wartbarkeit.

Du kannst Generics mit Funktionen, Structs, Enums, Traits und Methoden verwenden.

## Generische Funktionen

Eine generische Funktion arbeitet mit verschiedenen Typen, ohne dass du für jeden Typ eine eigene Implementierung brauchst.

Zum Beispiel:

```rust
fn largest_list<T>(l1: Array<T>, l2: Array<T>) -> Array<T> {
    if l1.len() > l2.len() {
        l1
    } else {
        l2
    }
}
```

Hier ist `T` ein Platzhalter für einen beliebigen Typ.

Cairo verlangt allerdings Trait Bounds, damit der generische Typ bestimmte Anforderungen erfüllt.

Wenn `T` droppable sein muss, können wir die Signatur anpassen:

```rust
fn largest_list<T, impl TDrop: Drop<T>>(l1: Array<T>, l2: Array<T>) -> Array<T> {
    if l1.len() > l2.len() {
        l1
    } else {
        l2
    }
}
```

Trait Bounds wie `Drop` oder `PartialOrd` schränken Generics für bestimmte Operationen ein.

## Anonyme Einschränkungen

Wenn eine Trait-Implementierung nicht direkt in einer Funktion verwendet wird, kannst du anonyme Einschränkungen mit `+` schreiben:

```rust
fn smallest_element<T, +PartialOrd<T>, +Drop<T>, +Copy<T>>(list: @Array<T>) -> T {
    let mut smallest = *list[0];
    let mut index = 1;

    while index < list.len() {
        if *list[index] < smallest {
            smallest = *list[index];
        }
        index += 1;
    };

    smallest
}
```

So vermeidest du es, Traits wie `TPartialOrd` zu benennen, und sparst Schreibarbeit.

## Structs mit Generics

Generics in Structs machen Felder flexibel.

Zum Beispiel:

```rust
#[derive(Drop)]
struct Wallet<T> {
    balance: T,
}

let w = Wallet { balance: 42 };
```

Wenn ein Struct mehrere generische Typen braucht, fügst du einfach weitere Platzhalter hinzu:

```rust
#[derive(Drop)]
struct Wallet<T, U> {
    balance: T,
    address: U,
}

let w = Wallet { balance: 42, address: '0xabc' };
```

## Enums mit Generics

Enums können ebenfalls generische Datentypen enthalten.

Zum Beispiel:

```rust
enum Option<T> {
    Some: T,
    None,
}
```

Das Enum `Option<T>` kann einen optionalen Wert beliebigen Typs darstellen.

Genauso kannst du mit `Result<T, E>` Erfolgs- und Fehlertypen definieren:

```rust
enum Result<T, E> {
    Ok: T,
    Err: E,
}
```

## Generische Methoden

Auch Methoden können Generics verwenden.

Zum Beispiel:

```rust
#[derive(Copy, Drop)]
struct Wallet<T> {
    balance: T,
}

trait WalletTrait<T> {
    fn balance(self: @Wallet<T>) -> T;
}

impl WalletImpl<T, +Copy<T>> of WalletTrait<T> {
    fn balance(self: @Wallet<T>) -> T {
        *self.balance
    }
}

let w = Wallet { balance: 50 };
assert!(w.balance() == 50);
```

Du kannst Methoden auch für bestimmte generische Typen definieren, zum Beispiel für `Wallet<u128>`:

```rust
trait WalletReceiveTrait {
    fn receive(ref self: Wallet<u128>, value: u128);
}

impl WalletReceiveImpl of WalletReceiveTrait {
    fn receive(ref self: Wallet<u128>, value: u128) {
        self.balance += value;
    }
}

let mut w = Wallet { balance: 50 };
w.receive(100);
assert!(w.balance() == 150);
```

## Generische Typen mischen

Generics können komplexe Kombinationen verarbeiten.

Zum Beispiel, wenn du zwei `Wallet`-Instanzen unterschiedlichen Typs kombinierst:

```rust
trait WalletMixTrait<T1, U1> {
    fn mixup<T2, +Drop<T2>, U2, +Drop<U2>>(
        self: Wallet<T1, U1>, other: Wallet<T2, U2>,
    ) -> Wallet<T1, U2>;
}

impl WalletMixImpl<T1, +Drop<T1>, U1, +Drop<U1>> of WalletMixTrait<T1, U1> {
    fn mixup<T2, +Drop<T2>, U2, +Drop<U2>>(
        self: Wallet<T1, U1>, other: Wallet<T2, U2>,
    ) -> Wallet<T1, U2> {
        Wallet { balance: self.balance, address: other.address }
    }
}

let w1 = Wallet { balance: true, address: 10 };
let w2 = Wallet { balance: 32, address: 100 };
let w3 = w1.mixup(w2);

assert!(w3.balance);
assert!(w3.address == 100);
```

Durch Einschränkungen wie `+Drop` stellt der Compiler den korrekten Umgang mit Ressourcen sicher.

Generics sind mächtig, erfordern aber einen sorgfältigen Umgang mit Einschränkungen.

Nutze sie, um wiederverwendbaren, typunabhängigen und knappen Code zu schreiben.
