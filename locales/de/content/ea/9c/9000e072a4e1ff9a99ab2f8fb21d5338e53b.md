# Einführung

In Python ist [ein Enum](https://docs.python.org/3/library/enum.html) eine Menge von Namen, die an eindeutige `literal`- bzw. `constant`-Werte gebunden sind. Du definierst ein Enum, indem du von einer `Enum`-Klasse erbst. Eingebaute Enum-Typen findest du im Modul `enum`, und die Klasse `Enum` kannst du mit `from enum import Enum` importieren.

```python
class Color(Enum):
    RED = 1
    GREEN = 2
```

Beachte, dass die Werte der Enum-Mitglieder beliebige Datentypen sein können, etwa str, tuple, float und so weiter.

```python
class Color(Enum):
    RED = 'red'
    GREEN = 'green'
```

Wenn du zwei Mitgliedern in einem Enum denselben Wert zuweist, wird das zuletzt zugewiesene Mitglied zu einem Alias für das zuerst definierte. Es ist nicht erlaubt, denselben Namen für zwei Mitglieder eines Enums zu verwenden.

```python
class Color(Enum):
    RED = 1
    GREEN = 2
    ALIAS_OF_RED = 1

Color.ALIAS_OF_RED
#=> <Color.RED: 1>

Color.ALIAS_OF_RED.value
#=> 1
```

Über die Mitglieder des Enums kannst du mit der Standard-Syntax `for member in` iterieren:

```python
for member in Color:
    print((member.name, member.value))
#=> (RED, 1)
#=> (GREEN, 2)
```

Enum-Mitglieder lassen sich mit [`is` (_Identitätsoperator_)](https://www.w3schools.com/python/ref_keyword_is.asp) oder `is not` vergleichen. Die Operatoren `==` bzw. `!=` (_Gleichheitsoperatoren_) funktionieren genauso.

```python
a = Color.RED

a is Color.RED
#=> True

a == Color.RED
#=> True
```

Um für einen bestimmten Wert auf ein Enum-Mitglied zuzugreifen, kannst du `EnumName(value)` verwenden:

```python
g = Color(2)

g is Color.GREEN
#=> True

g
#=> <Color.GREEN: 2>
```
