# Einführung

Neben Funktionsdeklarationen und Funktionsausdrücken gibt es in JavaScript noch eine weitere, sehr kompakte Syntax, um eine Funktion zu definieren.
Diese Funktionen heißen _Arrow-Funktionen_.

In diesem Konzept geht es um die Syntax, mit der du eine Arrow-Funktion schreibst.
Es gibt Unterschiede in der Funktionsweise einer Arrow-Funktion, etwa beim Binden von _this_, auf die wir in anderen Konzepten eingehen.

Hier ist ein Vergleich zwischen einer Funktionsdeklaration und einer Arrow-Funktion.

```javascript
function addUpTwoNumbers(num1, num2) {
  return num1 + num2;
}

// function keyword removed and => added
const addUpTwoNumbers = (num1, num2) => {
  return num1 + num2;
};
```

Oben siehst du, dass die Syntax der Arrow-Funktion:

1. das Schlüsselwort `function` weglässt
2. den Bezeichner `addUpTwoNumbers` als `const` deklariert
3. ein Fat Arrow `=>` hinzufügt

Wenn der Funktionskörper nur eine return-Anweisung enthält, wie im Beispiel oben, kannst du die `{}` und das Schlüsselwort `return` weglassen.

<!-- prettier-ignore-start -->
```javascript
const addUpTwoNumbers = (num1, num2) => { return num1 + num2 };

// can be shortened to
const addUpTwoNumbers = (num1, num2) => num1 + num2;
// braces {} and return removed
```
<!-- prettier-ignore-end -->

Wenn eine Arrow-Funktion nur ein Objekt zurückgibt, brauchst du runde Klammern um das Objekt, damit du die return-Anweisung weglassen kannst.

```javascript
// explicit return of object
const addUpTwoNumbers = (num1, num2) => {
  return {
    num1,
    num2,
  };
};

// implicit return of object
const addUpTwoNumbers = (num1, num2) => ({ num1, num2 });
```

Ob Parameter in runde Klammern gesetzt werden, hängt von der Anzahl der Parameter ab.

<!-- prettier-ignore-start -->
```javascript
// one parameter does not need parenthesis
const square = num => num * num;

// two or more parameters need to be wrapped in parenthesis
const addUpTwoNumbers = (num1, num2) => num1 + num2;
```
<!-- prettier-ignore-end -->
