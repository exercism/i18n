# Ergänzung zu den Anweisungen

## Umsetzung

Dein Code sollte nicht nur eine Liste von Zeilen und Spalten liefern können, sondern außerdem:

- den Wert eines Elements in der Matrix anhand seiner Zeilen- und Spaltennummer setzen.

Geh bei allen Operationen auf der Matrix davon aus, dass Zeilen und Spalten bei null beginnen. Das heißt, die erste Zeile ist Zeile 0, die zweite Zeile ist Zeile 1, und so weiter.
