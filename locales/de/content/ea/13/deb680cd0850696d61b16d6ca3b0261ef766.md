# Einführung

[Go](https://golang.org) ist eine statisch typisierte, kompilierte Programmiersprache.
In dieser Übung lernst du drei wichtige Sprachmerkmale kennen: Pakete, Funktionen und Variablen.

## Pakete

Go-Anwendungen werden in Paketen organisiert.
Ein Paket ist eine Sammlung von Quelldateien, die im selben Verzeichnis liegen.
Alle Quelldateien in einem Verzeichnis müssen denselben Paketnamen haben.
Wenn ein Paket importiert wird, können nur Entitäten (Funktionen, Typen, Variablen, Konstanten) verwendet bzw. darauf zugegriffen werden, deren Namen mit einem Großbuchstaben beginnen.
Der empfohlene Stil für die Benennung in Go ist, dass Bezeichner in `camelCase` benannt werden, außer denen, die paketübergreifend zugänglich sein sollen, die `PascalCase` verwenden sollten.

```go
package lasagna
```

## Variablen

Go ist statisch typisiert, das heißt, alle Variablen [müssen zur Kompilierzeit einen definierten Typ haben](https://en.wikipedia.org/wiki/Type_system).

Variablen können definiert werden, indem du einen Typ explizit angibst:

```go
var explicit int // Explicitly typed
```

Du kannst auch einen Initialisierungswert verwenden, und der Compiler weist der Variablen einen Typ zu, der zum Typ des Initialisierungswerts passt.

```go
implicit := 10   // Implicitly typed as an int
```

Nach der Deklaration kannst du Variablen mit dem Operator `=` Werte zuweisen.
Nach der Deklaration kann sich der Typ einer Variablen nie ändern.

```go
count := 1 // Assign initial value
count = 2  // Update to new value

count = false // This throws a compiler error due to assigning a non `int` type
```

## Konstanten

Konstanten enthalten genau wie Variablen einen Datenwert, aber ihr Wert kann sich während der Ausführung des Programms nicht ändern.

Konstanten werden mit dem Schlüsselwort `const` definiert und können Zahlen, Zeichen, Strings oder boolesche Werte sein:

```go
const Age = 21 // Defines a numeric constant 'Age' with the value of 21
```

## Funktionen

Go-Funktionen akzeptieren null oder mehr Parameter.
Parameter müssen explizit typisiert sein, es gibt keine Typinferenz.

Werte werden mit dem Schlüsselwort `return` aus Funktionen zurückgegeben.

Eine Funktion wird aufgerufen, indem du den Funktionsnamen angibst und für jeden Parameter der Funktion ein Argument übergibst.

Beachte, dass Go zwei Arten von Kommentaren unterstützt.
Einzeilige Kommentare werden mit `//` eingeleitet, mehrzeilige Kommentare zwischen `/*` und `*/` eingefügt.

```go
package greeting

// Hello is a public function.
func Hello (name string) string {
    return hi(name)
}

// hi is a private function.
func hi (name string) string {
    return "hi " + name
}
```
