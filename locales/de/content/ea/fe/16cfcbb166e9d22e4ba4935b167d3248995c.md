# Anleitung

Du! Ja, du, mutiger Lisper! [Lenny, das Lisp-Alien][alien], braucht deine Hilfe! Lenny will mit all den anderen Lisp-Aliens abhängen, aber ihre Eltern haben Lenny gesagt, dass Lenny nirgendwo hingeht, bis das Zimmer aufgeräumt ist.

Das Problem ist: Lenny kann den Boden kaum sehen! Lenny kann ihre Atome nicht von ihren Conses unterscheiden, ihre Symbole nicht von ihren Keywords, ihre `car`s nicht von ihren `cdr`s!

Kannst du Lenny helfen, dieses Chaos zu beseitigen? Vergiss nicht [deine Klammern][xkcd], du wirst sie brauchen!

## 1. Frische Lennys Wissen über Symbole auf

Bevor Lenny loslegen kann, braucht Lenny eine Auffrischung, wie Symbole und Keywords aussehen. Es ist eine Weile her, seit Lenny das letzte Mal aufgeräumt hat... Hilf Lenny, indem du zwei Funktionen definierst: `lennys-favorite-food`, die zu einem Symbol ausgewertet wird, und `lennys-secret-keyword`, die zu einem Keyword ausgewertet wird. Zum Beispiel:

```lisp
(lennys-favorite-food) ; => LASAGNA
```

```lisp
(lennys-secret-keyword) ; => :ALIENS-ARE-REAL
```

Beachte, dass du jedes beliebige Symbol oder Keyword zurückgeben kannst (falls du kein Fan von Lasagne bist oder nicht an Aliens glaubst).

## 2. Hilf Lenny, zwischen Atomen und Conses zu unterscheiden

Sobald Lenny ihr Wissen über Symbole und Keywords aufgefrischt hat, geht es ans Aufräumen! Um all die S-Ausdrücke zu sortieren, die in ihrem Zimmer herumliegen, braucht Lenny Hilfe dabei, festzustellen, was ein Cons und was ein Atom ist. Du kannst helfen, indem du zwei Funktionen implementierst, `is-an-atom-p` und `is-a-cons-p`:

```lisp
(is-an-atom-p 'one-thing)    ; => T
(is-an-atom-p '(two things)) ; => NIL
```

```lisp
(is-a-cons-p 'one-thing)    ; => NIL
(is-a-cons-p '(two things)) ; => T
```

Für diesen Abschnitt gibt es eine Reihe eingebauter Lisp-Funktionen, die dir nützlich sein können. Außerdem kannst du vorerst `T` einfach als wahr und `NIL` als falsch betrachten.

## 3. Hilf Lenny, die Conses aufzuteilen

Zum Schluss sind Lennys Conses zu sperrig, um sie ordentlich wegzuräumen, also müssen sie in kleinere Teile zerlegt werden. Kannst du helfen, indem du zwei weitere Funktionen definierst, um die Conses aufzuteilen (`first-thing` und `rest-of-it`)?

```lisp
(first-thing '(first second third)) ; => FIRST
(rest-of-it  '(first second third)) ; => (SECOND THIRD)
```

Auch hier können einige der eingebauten Funktionen von Common Lisp nützlich sein.
