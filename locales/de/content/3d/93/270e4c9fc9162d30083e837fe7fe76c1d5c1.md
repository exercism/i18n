# Instructions

Du bist ein begeisterter Vogelbeobachter und notierst, wie viele Vögel in den letzten sieben Tagen deinen Garten besucht haben.

Du hast fünf Aufgaben, die sich alle mit der Anzahl der Vögel beschäftigen, die deinen Garten besucht haben.

## 1. Prüfe, wie die Zählungen letzte Woche waren

Zum Vergleich bewahrst du immer eine Kopie der Zählungen der letzten Woche in der Nähe auf, und zwar: 0, 2, 5, 3, 7, 8 und 4. Implementiere die Methode `BirdCount.last_week`, die die Zählungen der letzten Woche zurückgibt:

```ruby
BirdCount.last_week
# => [0, 2, 5, 3, 7, 8, 4]
```

## 2. Prüfe, wie viele Vögel gestern zu Besuch waren

Implementiere die Methode `BirdCount#yesterday`, die zurückgibt, wie viele Vögel gestern deinen Garten besucht haben. Die Vogelzählungen sind nach Tagen geordnet, wobei das erste Element die Zählung des ältesten Tages ist und das letzte Element die Zählung von heute.

```ruby
birds_per_day = [2, 5, 0, 7, 4, 1]
bird_count = BirdCount.new(birds_per_day)
bird_count.yesterday
# => 4
```

## 3. Berechne die Gesamtzahl der zu Besuch gekommenen Vögel

Implementiere die Methode `BirdCount#total`, die die Gesamtzahl der Vögel zurückgibt, die deinen Garten besucht haben:

```ruby
birds_per_day = [2, 5, 0, 7, 4, 1]
bird_count = BirdCount.new(birds_per_day)
bird_count.total
# => 19
```

## 4. Berechne die Anzahl der geschäftigen Tage

Manche Tage sind geschäftiger als andere. Ein geschäftiger Tag ist ein Tag, an dem fünf oder mehr Vögel deinen Garten besucht haben.
Implementiere die Methode `BirdCount#busy_days`, die die Anzahl der geschäftigen Tage zurückgibt:

```ruby
birds_per_day = [2, 5, 0, 7, 4, 1]
bird_count = BirdCount.new(birds_per_day)
bird_count.busy_days
# => 2
```

## 5. Prüfe, ob es einen Tag ohne besuchende Vögel gab

Implementiere die Methode `BirdCount#day_without_birds?`, die `true` zurückgibt, wenn es einen Tag gab, an dem null Vögel den Garten besucht haben; andernfalls gibt sie `false` zurück:

```ruby
birds_per_day = [2, 5, 0, 7, 4, 1]
bird_count = BirdCount.new(birds_per_day)
bird_count.day_without_birds?
# => true
```
