# Anleitung

Die klassische Einstiegsübung.
Sag einfach „Hello, World!“.

[„Hello, World!“][hello-world] ist das traditionelle erste Programm, wenn man mit dem Programmieren in einer neuen Sprache oder Umgebung beginnt.

Die Ziele sind einfach:

- Ändere den vorgegebenen Code so, dass er den String „Hello, World!“ ausgibt.
- Führe die Test-Suite aus und stelle sicher, dass sie erfolgreich ist.
- Reiche deine Lösung ein und überprüfe sie auf der Website.

Wenn alles gut geht, bist du bereit, deine erste echte Übung herunterzuladen.

[hello-world]: https://en.wikipedia.org/wiki/%22Hello,_world!%22_program
