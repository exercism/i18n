# Einführung

Haxe unterstützt die Reflexion von Typen und Feldern zur Laufzeit. Um Reflexion korrekt einzusetzen, musst du verstehen, welche Arten von Operationen unterstützt werden und welche nicht. Da Reflexion dynamisch ist, lässt sich das nicht immer zur Compilezeit feststellen.

Die Reflexions-API besteht aus zwei Klassen:

- `Reflect`: Eine schlanke API, die am besten mit anonymen Strukturen funktioniert und Klassen nur eingeschränkt unterstützt.
- `Type`: Eine robustere API für die Arbeit mit Klassen und Enums.

Für das folgende Beispiel verwenden wir das JavaScript-Ziel:

```haxe
class Main {
  public static function main() {
    trace(Type.resolveClass("Main"));
  }
}

// This outputs
// class Test { static main() { console.log("Test.hx:3:",$hxClasses["Test"]); } }
```
