# Einführung


## Boolesche Werte

PowerShell hat den Typ [`bool`][booleans], um wahre und falsche Werte darzustellen.
In diesem Typ gibt es nur zwei Werte: `True` und `False`.
Du kannst diese Werte mit dem Präfix `$` an Variablen binden:

```powershell
> $TrueVar  = $true
> $FalseVar = $FALSE
#Case senstitivity doesn't matter here
```

Wir können [logische Operatoren][logical-operators] wie `-and`, `-or` und `-not` verwenden, um boolesche Ausdrücke zu kombinieren und auszuwerten.

```powershell
> $TrueVar  = $true -and $true
> $FalseVar = $true -and $false

> $TrueVar  = $true -or $false
> $FalseVar = $false -or $false

> $TrueVar  = -not $false
> $FalseVar = -not $true
```


## Comment-based help

[`Comment-based help`][comment-based help] in PowerShell hilft dabei, detaillierte Informationen für Funktionen und Skripte bereitzustellen, die in Kommentaren geschrieben sind.
Es verwendet spezielle Hilfe-Kommentar-Schlüsselwörter, um die Themen anzugeben, die im Fokus stehen, z. B. `.SYNOPSIS`, `.EXAMPLE` oder `.NOTES`.

```powershell
function ExampleFunction($Arg) {
    <#
    .DESCRIPTION
    A detailed description of the function or script. This keyword can be used only once in each topic.

    .PARAMETER Arg
    The description of a parameter, it must be follow with the parameter name.
    #>
}
```

Du kannst die Informationen zu Comment-based help mit dem Cmdlet `Get-Help` anzeigen.

```powershell
> Get-Help -Name "ExampleFunction"
```
