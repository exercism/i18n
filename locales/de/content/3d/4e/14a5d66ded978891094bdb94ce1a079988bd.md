# Tests

## clojure.test

Babashka bringt clojure.test bereits mit. Sobald du bereit bist, an einer Übung zu arbeiten, und eine Datei für deine Lösung angelegt hast (zum Beispiel `bob.clj`), kannst du die Tests mit `clojure.test/run-tests` ausführen, [wie hier beschrieben](http://clojure.github.io/clojure/clojure.test-api.html#clojure.test/run-tests).


Mit der REPL kannst du Code einfach ausführen und bekommst sofort Feedback; du kannst sie auch zum Ausführen von Tests verwenden. Empfohlen ist `rlwrap`, damit Zeilenbearbeitung und Befehlshistorie mit den Pfeiltasten nach oben und unten funktionieren. Um eine Übung zu testen, wechsle in ihr Verzeichnis und öffne eine Socket-REPL, wobei du die Verzeichnisse `src` und `test` zum Classpath hinzufügst:
``` bash
/bob $ rlwrap bb --classpath src:test socket-repl 1666
```

Zuerst rufst du `require` für den Test-Namespace auf:
``` clojure
=> (require 'bob-test)
nil
```

Dann rufst du `run-tests` für `bob-test` auf:
``` clojure
=> (clojure.test/run-tests 'bob-test)

Testing bob-test

Ran 25 tests containing 25 assertions.
0 failures, 0 errors.
{:test 25, :pass 25, :fail 0, :error 0, :type :summary}
```

So erstellst du ein Skript zum Ausführen der Tests:

``` clojure
#!/usr/bin/env bb

(require '[clojure.test :as t]
         '[babashka.classpath :as cp])

(cp/add-classpath "src:test")                        

(require 'bob-test)                  

(def test-results
  (t/run-tests 'bob-test))           

(def failures-and-errors
  (let [{:keys [:fail :error]} test-results]
    (+ fail error)))                                 

(System/exit failures-and-errors)
```
