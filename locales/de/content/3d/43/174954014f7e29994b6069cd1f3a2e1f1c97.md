# Lernen

Vim bringt bereits eine großartige Dokumentation mit. Der Zugriff auf die Dokumentation läuft über den Befehl `:help`.

Eine Einführung findest du unter `:h user-manual`.

Fast alle Vim-Installationen enthalten außerdem ein interaktives Tutorial:

```
$ vimtutor
```

Vim ist Jahrzehnte alt und trotzdem noch beliebt. Im Web findest du viele Ressourcen dazu, manche besser als andere. Die guten sind [hier](https://exercism.org/docs/tracks/vimscript/resources) aufgelistet.
