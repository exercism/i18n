# Anleitung

Das Notizbuch eines Detektivs füllt sich, während ein Fall voranschreitet, und leert sich wieder, wenn Ermittlungsansätze ausgeschlossen werden.

Alle fünf Aufgaben gehören in die `CASE_NOTES`-Klasse.

## 1. Eröffne einen Fall

Gib ein neues, leeres Notizbuch zurück.

```sather
notes ::= CASE_NOTES::new_case;
notes.size
-- => 0
```

## 2. Schreib eine Spur auf

Hänge eine Spur am Ende des Notizbuchs an. Das liefert keinen Rückgabewert, sondern verändert das Notizbuch, das ihm übergeben wird.

```sather
CASE_NOTES::add_clue(notes, "muddy boots");
notes.size
-- => 1
```

## 3. Wie viele Spuren?

```sather
CASE_NOTES::clue_count(notes)
-- => 1
```

## 4. Schließ eine aus

Nimm die Spur an einer Position aus dem Notizbuch heraus. Alles danach rückt nach. Das liefert ebenfalls keinen Rückgabewert.

```sather
CASE_NOTES::rule_out(notes, 0);
```

## 5. Lies den Fall noch einmal durch

Gib jede Spur im Notizbuch zurück, verbunden mit `"; "`. Ein leeres Notizbuch ergibt den leeren String.

```sather
CASE_NOTES::summary(notes)
-- => "muddy boots; broken window"
```
