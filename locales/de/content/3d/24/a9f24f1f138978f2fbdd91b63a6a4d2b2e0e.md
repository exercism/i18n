# Einführung

## Grundlagen

Wenn du in F# einem Namen einen Wert zuweist, nennt man das eine _Bindung_. Bindungen sind unveränderlich, was sie Konstanten in anderen Sprachen ähnlich macht. Da F# eine statisch typisierte Sprache ist, hat jede Bindung zur Kompilierzeit einen Typ.

Bindungen definierst du mit dem Schlüsselwort `let`. Bei den meisten Bindungen ist die Angabe des Typs optional, da die _Typinferenz_ von F# den Typ meist anhand des Werts ableiten kann. Eine Bindung sieht so aus:

```fsharp
// Automatically inferred type
let fingers = 10
```

Funktionen sind ebenfalls reguläre Bindungen, allerdings mit einem oder mehreren Parametern. Eine Funktion gibt automatisch ihren letzten Ausdruck zurück. Die Typinferenz funktioniert auch bei den meisten Funktionen: Sie analysiert, mit welchen Werten die Funktion aufgerufen wird und welchen Wert sie zurückgibt.

```fsharp
// Automatically inferred types for parameters and return type
let add x y = x + y
```

Um eine Funktion aufzurufen, gibst du ihren Namen an und übergibst für jeden Parameter der Funktion ein Argument.

```fsharp
let five = add 2 3
```

Kann der Typ einer Bindung nicht abgeleitet werden, meldet der Compiler einen Fehler. Um das zu beheben, fügst du der Bindung eine explizite Typanmerkung hinzu.

```fsharp
// Explicit type annotation
let fingers: int = 10

// Explicit type annotation (also for parameters)
let add (x: int) (y: int): int = x + y
```

Bindungen in F# kannst du erst verwenden, _nachdem_ sie definiert wurden. Wenn du eine Bindung verwendest, bevor sie definiert wurde, führt das zu einem Kompilierfehler.

```fsharp
// Compile error as the add binding has not yet been defined
// let seven = add 3 4

let add x y = x + y
```

F# verwendet signifikanten Leerraum, um Gültigkeitsbereiche festzulegen. Das bedeutet, dass du einen Gültigkeitsbereich festlegst, indem du den Code relativ zur Zeile, die die Bindung deklariert, mit Leerzeichen einrückst. Standardmäßig wird mit vier Leerzeichen eingerückt:

```fsharp
let toes =
    let left = 5
    let right = 5
    left + right

let multiplyPlusTwo x y =
    let product = x * y
    product + 2

// Trying to access the left, right or product bindings
// here would result in a compile error
```

F#-Bindungen (zu denen auch Funktionen gehören) werden normalerweise in Modulen organisiert. Ein Modul gruppiert zusammengehörige Funktionalität und wird mit dem Schlüsselwort `module` definiert. Die Moduldefinition muss vor ihren Bindungen stehen:

```fsharp
module Calculator

let pi = 3.14

let add x y = x + y
```

F# unterstützt zwei Arten von Kommentaren. Einzeilige Kommentare werden mit `//` eingeleitet, mehrzeilige Kommentare stehen zwischen `(*` und `*)`.
