# Einführung

In Haxe kannst du eine Klassenhierarchie mit _Vererbung_ definieren. Dabei erbt eine abgeleitete Klasse (`Car`) das Verhalten und die Daten ihrer Elternklasse (`Vehicle`).

In der Elternklasse kannst du:

- Methoden definieren, die überschrieben werden können
- abstrakte Methoden definieren, die von den abgeleiteten Klassen implementiert werden müssen

```haxe
abstract class Vehicle {
  public function new() {}

  // Can be overridden
  public function drive() {
    // ...
  }

  // Must be implemented
  public abstract function getSpeed():Int;
}

class Car extends Vehicle {
  public function new() {
    super(); // Runs the parent class' constructor
  }

  public override function drive() {
    // ...
  }

  public function getSpeed():Int {
    // ...
  }
}
```

Wenn die Elternklasse einen Konstruktor hat, rufen wir ihn mit `super()` auf:

```haxe
abstract class Vehicle {
  var wheels:Int;

  public function new(wheels:Int) {
    this.wheels = wheels
  }
}

class Car extends Vehicle {
  var color:String;

  public function new(wheels:Int, color:String) {
    super(wheels);
    this.color = color;
  }
}

```
