# Grundlagen

## Erste Schritte

### Variablen

Um eine [Variable][variables] zu deklarieren, verwendest du den Zuweisungsoperator `=`.
In Crystal sollten Variablen das Format [snake_case][snake-case] verwenden.

```crystal
number = 1
puts number # => 1

number = 2
puts number # => 2
```

### Konstanten

[Konstanten][constants] werden mit demselben Zuweisungsoperator `=` deklariert, verwenden aber ausschließlich Großbuchstaben, bekannt als SCREAMING_SNAKE_CASE.

```crystal
NUMBER = 1
puts NUMBER # => 1
```

Wenn du einer bereits definierten Konstante einen Wert zuweist, führt das zu einem Fehler zur Kompilierzeit.

```crystal
NUMBER = 1

NUMBER = 2
# Error: already initialized constant NUMBER
```

### Typen

Crystal ist eine kompilierte Sprache. Das bedeutet, dass jeder Variablen oder jedem Methodenargument zur Kompilierzeit ein Typ zugewiesen wird.
Der Compiler kann den Typ einer Variablen oder eines Methodenarguments ableiten.
In manchen Fällen ist es jedoch notwendig, den Typ anzugeben.
Die Fälle, in denen ein Typ festgelegt werden muss, werden in späteren Konzepten erklärt.

### Methoden

[Methoden][methods] sind eine Möglichkeit, eine Reihe von Anweisungen zu gruppieren, die wiederverwendet werden können.
In Crystal werden Methoden oft in einer Klasse, einem Modul oder einem Struct definiert.
Allerdings können Methoden auch außerhalb einer Klasse, eines Moduls oder eines Structs definiert werden.
Methoden werden mit dem Schlüsselwort `def` deklariert, gefolgt vom Namen der Methode.
In Crystal sollten Methoden in snake_case geschrieben werden.
Du kannst die runden Klammern weglassen, wenn eine Methode keine Argumente hat.
Um das Ende einer Methode festzulegen, musst du das Schlüsselwort `end` verwenden.

```crystal
def hello
  puts "Hello World!"
end
```

Wenn du eine Methode verwendest, die für den Typ der Variablen oder des Methodenarguments nicht existiert, führt das zu einem Fehler zur Kompilierzeit.

```crystal
number = 1
number + "1"
# Error: no overload matches 'Int32#+' with type String
```

### Argumente

Methoden können [Argumente][arguments] haben.
Argumente sind Daten, die an eine Methode übergeben werden.
Um einer Methode Argumente übergeben zu können, musst du den Namen des Arguments angeben.
In Crystal sollten Argumente in snake_case geschrieben werden.
Eine Methode kann mehrere Argumente haben, aber die Argumente müssen durch ein Komma getrennt werden.

```crystal
def hello(name)
  puts "Hello #{name}!"
end
```

Methoden können auch mehrere Argumente haben.
In diesem Fall müssen die Argumente durch ein Komma getrennt werden.

```crystal
def hello(name, language)
  puts "Hello #{name}! You are learning #{language}."
end
```

### Methoden aufrufen

Wenn du eine Methode aufrufst, die zu einer Klasse, einem Modul oder einem Struct gehört, musst du den Punktoperator (`.`) verwenden.
Das Format sollte so aussehen: `<ClassName>.<method_name>`.
Wenn eine Methode nicht zu einer Klasse, einem Modul oder einem Struct gehört, kannst du sie einfach aufrufen, indem du ihren Namen schreibst.
Methoden geben immer implizit den Wert des letzten Ausdrucks zurück.

Wenn eine Methode Argumente hat, kannst du runde Klammern verwenden, um die Argumente beim Aufruf und bei der Definition der Methode anzugeben, wie folgt: `<method_name>(<argument_1>, <argument_2>, ...)`.
Wenn eine Methode keine Argumente hat, sollten die runden Klammern weggelassen werden.

```crystal
def hello(name)
  "Hello #{name}!"
end

hello("Crystal")
# => Hello Crystal!
```

Wenn du eine Methode mit mehreren Argumenten aufrufst, sollten die Argumente durch ein Komma getrennt werden.
Die Argumente müssen in derselben Reihenfolge angegeben werden wie die Methodenargumente.

```crystal
def hello_language(name, language)
  "Hello #{name}! You are learning #{language}."
end

hello_language("World", "Crystal")
# => Hello World! You are learning Crystal.
```

Wenn du eine Methode mit der falschen Anzahl von Argumenten aufrufst, führt das zu einem Fehler zur Kompilierzeit.

```crystal
hello_language("Crystal")
# wrong number of arguments for 'hello_language' (given 1, expected 2)
```

### Addition, Subtraktion und Multiplikation

In Crystal kannst du den Operator `+` verwenden, um zwei Zahlen zu addieren.
Du kannst auch den Operator `-` verwenden, um zwei Zahlen zu subtrahieren.
Und du kannst den Operator `*` verwenden, um zwei Zahlen zu multiplizieren.

```crystal
1 + 1
# => 2

2 - 1
# => 1

2 * 2
# => 4
```

### Kommentare

In Crystal werden [Kommentare][comments] mit dem Zeichen `#` geschrieben, gefolgt von einem Leerzeichen und dann dem Kommentar.
Kommentare werden verwendet, um Code zu dokumentieren.
Der Compiler führt Kommentare nicht aus.

```crystal
# This is a comment
```
