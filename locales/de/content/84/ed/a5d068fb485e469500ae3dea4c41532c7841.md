# Ergänzung zu den Anweisungen

## Eingabeformat

Jeder Dominostein wird als einzelnes Byte gespeichert, wobei die linke Hälfte im
hohen [Nibble][nibble] und die rechte Hälfte im niedrigen [nibble] steht. Zum Beispiel
werden die Steine `[2|1]`, `[2|3]` und `[1|3]` als die Bytes
`0x21 0x23 0x13` dargestellt.

## Register

| Register | Verwendung | Typ             | Beschreibung                                          |
| -------- | ---------- | --------------- | ----------------------------------------------------- |
| `$a0`    | Eingabe    | Adresse         | Array von Stein-Bytes                                 |
| `$a1`    | Eingabe    | Ganzzahl        | Anzahl der Steine                                     |
| `$v0`    | Ausgabe    | boolescher Wert | Dominosteine lassen sich aneinanderreihen (`0` = `false`, `1` = `true`) |
| `$t0-9`  | temporär   | beliebig        | wird für temporäre Speicherung verwendet              |


[nibble]: https://en.wikipedia.org/wiki/Nibble
