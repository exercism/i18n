# Tests

Du kannst den Online-Editor auf der Exercism-Website verwenden, um die Übungen zu lösen. Oder du lädst die Übungen auf deinen Computer herunter, löst sie lokal und reichst sie dann bei Exercism ein.

Wenn du lokal arbeiten möchtest, brauchst du das Programm [`bats`][bats]. Die Installationsanleitung findest du auf der Seite [Testing on the Bash track][test-bash].

Dein Code wird auf dem jq-Test-Runner von Exercism mit [`jq` Version **1.8**][jq] getestet.

[bats]: https://github.com/bats-core/bats-core
[test-bash]: https://exercism.org/docs/tracks/bash/tests
[jq]: https://jqlang.org/manual/
