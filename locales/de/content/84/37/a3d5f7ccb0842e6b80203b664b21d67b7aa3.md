# Hinweise

## 1. Mach es großartig

- Mapping ist das richtige Verfahren, um eine Funktion auf jedes Element einer Sequenz anzuwenden.
- `mapcar` ist eine gute Funktion, um eine Funktion auf eine Liste anzuwenden.

## 2. Nur das Beste

- Filtern ist das richtige Verfahren, um ein oder mehrere Elemente aus einer Sequenz zu entfernen. Das Ergebnis ist eine neue Sequenz.
- `remove` kann Werte aus einer Sequenz entfernen, die gleich einem bestimmten Element sind.
- `remove-if` kann Werte entfernen, für die eine Prädikatfunktion wahr ergibt.
