# Anleitung

In dieser Übung hilfst du Highschool-Liebespaaren, ihre Liebe in den sozialen Medien zu verkünden, indem du ein ASCII-Herz mit ihren Initialen erzeugst:

```
❤ J.  +  M. ❤
```

## 1. Den Namen bereinigen

Implementiere die Methode `HighSchoolSweetheart.clean_up_name`.
Sie soll einen Namen entgegennehmen, alle `-`-Zeichen daraus entfernen und sie durch ein Leerzeichen ersetzen.
Außerdem soll sie alle Leerzeichen am Anfang und am Ende des Namens entfernen.

```crystal
HighSchoolSweetheart.clean_up_name("Jane-Ann")
# => "Jane Ann"
```

## 2. Den ersten Buchstaben des Namens ermitteln

Implementiere die Methode `HighSchoolSweetheart.first_letter`.
Sie soll einen Namen entgegennehmen und seinen ersten Buchstaben zurückgeben.
Achte darauf, `HighSchoolSweetheart.clean_up_name` wiederzuverwenden, die du im vorherigen Schritt definiert hast.

```crystal
HighSchoolSweetheart.first_letter("Jane")
# => "J"
```

## 3. Den ersten Buchstaben als Initiale formatieren

Implementiere die Methode `HighSchoolSweetheart.initial`.
Sie soll einen Namen entgegennehmen und seinen ersten Buchstaben in Großschreibung zurückgeben, gefolgt von einem Punkt.
Achte darauf, `HighSchoolSweetheart.first_letter` wiederzuverwenden, die du im vorherigen Schritt definiert hast.

```crystal
HighSchoolSweetheart.initial("Robert")
# => "R."
```

## 4. Die Initialen in das Herz setzen

Implementiere die Methode `HighSchoolSweetheart.pair`.
Sie soll zwei Namen entgegennehmen und die Initialen mit Emoji-Herzen drumherum zurückgeben.
Achte darauf, `HighSchoolSweetheart.initial` wiederzuverwenden, die du im vorherigen Schritt definiert hast.

```crystal
HighSchoolSweetheart.pair("Blake Miller", "Riley Lewis")
# => "❤ B.  +  R. ❤"
```
