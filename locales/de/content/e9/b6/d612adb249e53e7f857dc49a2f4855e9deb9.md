# Threads

Diese Übung führt Threads ein, um zu testen, wie robust dein Bankkonto bei gleichzeitigen Operationen ist.
Ein wenig Lesestoff zu Tcl-Threads:

* [Tcl Threading Model](https://www.tcl.tk/doc/howto/thread_model.html)
* [Threads Done Right… with Tcl](https://www.activestate.com/blog/threads-done-right-tcl/)
* [Multi-Threaded Tcl Scripts](http://www.beedub.com/book/4th/Threads.pdf),
  ein Kapitel aus _Practical Programming in Tcl and Tk, 4th Ed._,
copyright 2003 © Brent Welch, Ken Jones
[http://www.beedub.com/book/](http://www.beedub.com/book/)
    * Beachte: In diesem Kapitel steht „Most binary distributions of Tcl are not thread-enabled“. Das stimmt heute nicht mehr: Tcl-Distributionen werden inzwischen mit Thread-Unterstützung gebaut (siehe [TIP 364](https://core.tcl-lang.org/tips/doc/trunk/tip/364.md))
* [Thread Package Commands](https://tcl.tk/man/tcl8.6/ThreadCmd/contents.htm) aus der Tcl-Dokumentation.

## Installation

Manche Tcl-Distributionen enthalten das Thread-Paket von Tcl nicht standardmäßig: Es muss möglicherweise separat installiert werden.
Prüfe das mit
```bash
$ echo 'package require Thread' | tclsh
```
Wenn dabei _keine Ausgabe_ entsteht, ist das Thread-Paket bereits installiert.

Führe bei Bedarf `apt install tcl-thread` (oder `dnf install tcl-thread`) aus.
