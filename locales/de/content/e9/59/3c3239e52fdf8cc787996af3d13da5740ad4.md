# Ergänzende Anweisungen

## Register

| Register | Verwendung | Typ | Beschreibung |
| -------- | --------- | ------- | -------------------------- |
| `$a0`    | Eingabe     | Ganzzahl | Index der Primzahl                |
| `$v0`    | Ausgabe    | Ganzzahl | Wert der n-ten Primzahl            |
| `$t0-9`  | temporär | beliebig     | wird für die Zwischenspeicherung verwendet |
