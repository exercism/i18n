# Vertiefung

- Der Typ [Binary][binary] ist eine Spezialisierung des Typs [Bitstring][bitstring].
- Binaries bestehen aus [Bytes][wiki-byte].
  - Ein Byte besteht aus 8 [Bits][wiki-bit].
  - Bytes können Zahlen von `0` bis `255` darstellen
  - [Hexadezimale][wiki-hexadecimal] Ganzzahlwerte sind beim Arbeiten mit Bytes üblich: `0x00` bis `0xFF`.
- Binäre Literale werden mit der [speziellen Form `<<>>`][special-form] definiert.
  - Wenn du für ein Byte eine Ganzzahl größer als `255` verwendest, werden nur die letzten 8 Bits verwendet, es sei denn, du gibst mit dem [`::`][type-operator]-Operator die [zu verwendende Einheit und/oder Größe][bin-size] an.
- Mit [`<>/2`][bin-concat] kannst du Bitstrings/Binaries/Strings verketten.

```elixir
<<255>> == <<0xFF>>
# Overflowing bits are truncated
<<256>> == <<0>>
<<256::size(16)>> == <<1, 0>>

<<"Hello">> == <<72, 101, 108, 108, 111>>
```

Ein _Nullbyte_ ist ein anderer Name für `<<0>>`.

## Strings sind kodierte Binärdaten

- Strings sind kodierte Binärdaten im [UTF-8][wiki-utf8]-Format.
  - Sie werden in Blöcken von 8 Bit (einem Byte) kodiert und nutzen bis zu 4 Bytes, um mehr als 255 Zeichen darzustellen.
  - Die [Länge eines Strings][string-length] ist möglicherweise nicht mit seiner [Bytegröße][byte-size] identisch.

```elixir
# This string has a string length of 5, but is made up of 7 bytes
string = "cześć"
String.length(string) != byte_size(string)

# Even emoji strings are encoded binaries
"👍" == <<240, 159, 145, 141>>
```

## Pattern Matching auf Binärdaten

- Du kannst Binaries [als Ganzes oder mit der speziellen Form matchen][special-form], um nur einen Teil zu treffen.
  - Nur der letzte Teil eines Pattern Matchings darf eine variable Größe haben.

```elixir
# Ignore the first 8 bytes, bind the remaining variable sized binary to `body`
<<_::binary-size(8), body::binary>>
```

Das funktioniert auch mit Strings:

```elixir
# bind the first 5 bytes to `name`,
# match the string literal " the ",
# bind remaining bytes to `species`
<<name::binary-size(5), " the ", species::binary>> = <<"Frank the Walrus">>
{name, species}
# => {"Frank", "Walrus"}
```
