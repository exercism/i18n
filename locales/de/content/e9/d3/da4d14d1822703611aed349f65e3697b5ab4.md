# Einführung

Die Grundlagen zu Funktionsargumenten findest du im [Funktionskonzept][function concept].

## Parameternamen

[Parameternamen][parameters] müssen wie Variablennamen mit einem Buchstaben oder einem Unterstrich beginnen und dürfen Buchstaben, Unterstriche oder Zahlen enthalten.
Parameternamen sollten keine Leerzeichen oder Satzzeichen enthalten.


## Positionsargumente

Positionsargumente sind Werte, die in derselben Reihenfolge an eine Funktion übergeben werden, in der die Parameter gebunden werden.
Du kannst sie optional über ihren Parameternamen übergeben:


```python
def concat(greeting, name):
    return f"{greeting}{name}"
 
# Passing data to the function by position.
print(concat("Hello, ", "Judy"))
#->  Hello, Judy

# Passing data to the function using the parameter name.
print(concat(name="Sally", greeting="Hello, "))
#-> Hello, Sally
```

Der erste Aufruf von concat übergibt die Argumente nach Position.
Der zweite Aufruf von concat übergibt die Argumente über den _Namen_, sodass sich ihre Reihenfolge ändern lässt.

Beachte, dass Positionsargumente nicht nach Argumenten stehen können, die über den Namen übergeben werden (_auch [Schlüsselwortargumente][keyword-arguments] genannt. **Nicht** zu verwechseln mit var-positionalen Parametern oder [**kwargs][kwargs]_).

Diese Argumentliste:

```python
>>> print(concat(greeting="Hello, ", "Zed"))
```

führt zu diesem Fehler:

```
SyntaxError: positional argument follows keyword argument
```

## Standardwerte für Argumente

[Standardwerte][default arguments] für ein oder mehrere Argumente kannst du in der Parameterliste angeben.
Dadurch lässt sich die Funktion bei Bedarf mit _weniger_ Argumenten aufrufen.
Du kannst die Standardwerte überschreiben, indem du die Funktion mit neuen Argumenten anstelle der Standardwerte aufrufst:


```python
# Note the default arguments for both greeting and name.
def concat(greeting="Hello, ", name="you"):
    return f"{greeting}{name}"
 
# Function call overriding the defaults
print(concat(name="Jerry", greeting="Hello, "))
#-> Hello, Jerry

# Function call without arguments resulting in the defaults being used.
print(concat())
#-> Hello, you
```

## Schlüsselwortargumente

Schlüsselwortargumente nutzen den Parameternamen, wenn du Argumente an eine Funktion übergibst.
Du kannst sie optional auch über ihre Position übergeben:


```python
# Note the default arguments for both greeting and name.
def concat(greeting="Hello, ", name="you"):
    return f"{greeting}{name}"

# Function call using parameter names as argument keywords.
print(concat(name="Jerry", greeting="Hello, "))
#-> Hello, Jerry

# Function call with positional data as arguments.
print(concat("Hello, ", "Isaac"))
#-> Hello, Isaac
```
