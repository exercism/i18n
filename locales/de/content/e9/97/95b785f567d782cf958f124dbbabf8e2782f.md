# Tests

Um die bereitgestellten Tests auszuführen, brauchst du das Minitest-Gem. Öffne ein Terminalfenster und führe den folgenden Befehl aus, um Minitest zu installieren:

```
gem install minitest
```


Führe die Tests aus dem Übungsverzeichnis mit dem folgenden Befehl aus:

```
ruby <snake-case-exercise>_test.rb
```

Bitte ersetze `<snake-case-exercise>` durch den Namen deiner Übung in snake_case.

## Farbige Ausgabe

Du kannst `require 'minitest/pride'` verwenden oder den folgenden Befehl ausführen, um eine farbige Ausgabe zu erhalten:

```
ruby -r minitest/pride <snake-case-exercise>_test.rb
```
