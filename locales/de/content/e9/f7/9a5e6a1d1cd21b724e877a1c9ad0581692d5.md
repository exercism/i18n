# Anleitung

Du bist der Funktelegrafist auf einem Frachter. Das Signal kommt über eine verrauschte Leitung herein: Schiffsmaschinen, Wetterrauschen, gelegentlich fremdes Geplauder, alles durchsetzt mit dem echten Morsecode, auf den du horchst. Um die Nachricht aufzufangen, schickst du den Draht durch ein *Band*gerät, das alles außer gültigen Morsesymbolen (`.`, `-` und dem Leerzeichen, das die Buchstaben trennt) herausfiltert.

Deine Aufgabe ist es, das Band als eigenen Factor-Eingabestream zu bauen.

## 1. Definiere das Band

Definiere ein `tape`-Tupel, das `disposable` erweitert und einen Slot `wire` für den darunterliegenden Eingabestream enthält.

```factor
TUPLE: tape < disposable wire ;
```

Dann schreib den Konstruktor `<tape> ( wire -- tape )`. Verwende `new-disposable` (nicht `new`), damit das Destruktor-Framework das Band registriert, und speichere den darunterliegenden Stream im Slot `wire`.

## 2. Tritt dem input-stream-Mixin bei

Deklariere `tape` als `input-stream`:

```factor
INSTANCE: tape input-stream
```

Dadurch leiten die Standard-Kombinatoren des Protokolls an deine Klasse weiter.

## 3. Lies ein Morsesymbol ein

Implementiere `M: tape stream-read1 ( tape -- elt/f )`. Lies Bytes vom darunterliegenden Draht, bis du auf `CHAR: .`, `CHAR: -` oder `CHAR: \s` (Leerzeichen) stößt. Gib dieses Byte zurück. Wenn der Draht `f` zurückgibt (Ende des Streams), gib ebenfalls `f` zurück, dann ist das Band fertig.

```factor
"x.y -ab cz" <string-reader> <tape>
[ stream-read1 ] [ stream-read1 ] [ stream-read1 ] tri
! => CHAR: . CHAR: - CHAR: \s
```

## 4. Delegiere den Elementtyp

Implementiere `M: tape stream-element-type ( tape -- type )`, indem du an den Draht delegierst. Das Band ändert die Art der gelesenen Elemente nicht.

## 5. Räum auf

Implementiere `M: tape dispose* ( tape -- )`. Das Framework ruft deine Methode genau einmal pro `dispose` auf. Du musst nur den darunterliegenden Draht freigeben.

Wenn diese fünf Teile stehen, funktioniert das Band wie ein normaler Eingabestream: `with-input-stream`, `stream-read` und die übrigen Wörter des Protokolls leiten automatisch an deine Methoden weiter.
