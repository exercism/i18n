# Ergänzung der Anweisungen

## Assert

Für diese Übung gehen wir davon aus, dass der Aufrufer dafür verantwortlich ist, `classify` nur mit einer von null verschiedenen Eingabe aufzurufen.
Also lass die Funktion `classify` bitte mit einer Assertion prüfen, dass ihre Eingabe von null verschieden ist.
Weitere Details findest du in der [Zig Language Reference][zig-reference] und in der Implementierung von [`std.debug.assert`][assert].

Beachte jedoch, dass diese Übung derzeit keine Eingabe von 0 testet (weil `std.testing` [noch nicht das Erwarten einer Panik unterstützt][proposal]).

[zig-reference]: https://ziglang.org/documentation/0.16.0/#unreachable
[assert]: https://ziglang.org/documentation/0.16.0/std/#std.debug.assert
[proposal]: https://github.com/ziglang/zig/issues/1356
