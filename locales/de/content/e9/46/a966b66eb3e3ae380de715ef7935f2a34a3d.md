# Über

Das grundlegende `try .. rescue`-Konstrukt lässt sich um `else`- und `after`-Klauseln erweitern:

- Der `else`-Block:
  - Hier findet ein Musterabgleich auf das erfolgreiche Ergebnis aus dem try-Block statt.
- Der `after`-Block:
  - Hier werden Funktionen aufgerufen, egal ob der try-Block erfolgreich ist oder ob eine Ausnahme abgefangen wird, solange das Programm läuft.
  - Das Ergebnis des `after`-Blocks wird nicht an den aufrufenden Gültigkeitsbereich zurückgegeben.

```elixir
try do
  :a
rescue
  _ -> :error
else
  :a -> :success
after
  :some_action
end

# => :success
```
