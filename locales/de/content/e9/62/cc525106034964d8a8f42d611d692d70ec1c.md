# Ceylon-Tests ausführen

Bevor du die Tests ausführen kannst, musst du deinen Code mit [`ceylon compile`](https://ceylon-lang.org/documentation/current/reference/tool/ceylon/subcommands/ceylon-compile.html) kompilieren.

Die Tests führen wir mit dem Befehl [`ceylon test`](https://ceylon-lang.org/documentation/reference/tool/ceylon/subcommands/ceylon-test.html) aus.

`ceylon test` erwartet den Namen eines Moduls, für das die Tests ausgeführt werden sollen.
Im Ceylon-Track hat jede Übung nur ein einziges Modul.

Deshalb kannst du die Tests so ausführen:

```bash
ceylon compile && ceylon test $(basename source/*)
```
