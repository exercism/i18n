# Ergänzende Anweisungen

## Register

| Register | Verwendung  | Typ     | Beschreibung                       |
| -------- | ----------- | ------- | ---------------------------------- |
| `$a0`    | Eingabe     | Ganzzahl | gegebene Zahl                     |
| `$a1`    | Eingabe/Ausgabe | Adresse | nullterminierter Ergebnis-String |
| `$t0-9`  | temporär    | beliebig | für temporäre Speicherung         |
