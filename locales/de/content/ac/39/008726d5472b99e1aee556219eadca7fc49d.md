# Anleitung

Bestimme, ob ein Dreieck _equilateral_, _isosceles_ oder _scalene_ ist.

Ein Dreieck ist _equilateral_, wenn alle drei Seiten gleich lang sind.

Ein Dreieck ist _isosceles_, wenn mindestens zwei Seiten gleich lang sind.
(Manchmal wird festgelegt, dass genau zwei Seiten gleich lang sein müssen, aber für diese Übung sagen wir: mindestens zwei.)

Ein Dreieck ist _scalene_, wenn alle Seiten unterschiedlich lang sind.

## Hinweis

Damit eine Form überhaupt ein Dreieck ist, müssen alle Seiten eine Länge > 0 haben, und die Summe der Längen zweier beliebiger Seiten muss größer oder gleich der Länge der dritten Seite sein.

In Gleichungen:

Seien `a`, `b` und `c` die Seiten des Dreiecks.
Dann müssen alle drei der folgenden Ausdrücke wahr sein:

```text
a + b ≥ c
b + c ≥ a
a + c ≥ b
```
