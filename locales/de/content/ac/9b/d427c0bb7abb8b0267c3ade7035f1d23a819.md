Elixir hat spezielle Namenskonventionen. Dazu gehört, wie [Funktionen, die boolesche Werte zurückgeben](https://hexdocs.pm/elixir/naming-conventions.html#trailing-question-mark-foo) und [Überprüfungen, die boolesche Werte zurückgeben und in Guard-Klauseln gültig sind](https://hexdocs.pm/elixir/naming-conventions.html#is_-prefix-is_foo) benannt werden:

> Funktionen, die einen booleschen Wert zurückgeben, werden mit einem abschließenden Fragezeichen benannt.

> Typüberprüfungen und andere boolesche Überprüfungen, die in Guard-Klauseln erlaubt sind, werden mit einem `is_`-Präfix benannt.

Makros können in beiden Kontexten verwendet werden, daher ist die Schreibweise kontextabhängig, aber die beiden Namenskonventionen dürfen nicht vermischt werden.

```elixir
# this is the expected name of macros that return booleans

%{option1}

# this is the expected name of macros that return booleans and are valid in guard clauses

%{option2}

# this is the current name

%{actual}
```
