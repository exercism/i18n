# date-wert nicht verwenden

Verwende [`Date#getTime`](https://developer.mozilla.org/en-US/docs/Web/JavaScript/Reference/Global_Objects/Date/getTime)
anstelle von [`Date#valueOf`](https://developer.mozilla.org/en-US/docs/Web/JavaScript/Reference/Global_Objects/Date/valueOf).
Sie sind funktional gleichwertig, aber `valueOf` ist wie folgt markiert:

> Diese Methode wird normalerweise intern von JavaScript aufgerufen und nicht
> explizit im Code.
