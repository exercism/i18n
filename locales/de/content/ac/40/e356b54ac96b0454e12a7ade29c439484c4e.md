# Anleitung

Dein Freund hat dir gerade eine Nachricht mit einem wichtigen Geheimnis geschickt.
Damit es andere nicht leicht haben, sie zu lesen, wurde die Nachricht mit einer Reihe von Bitmanipulationen verschlüsselt.
Du musst ein Programm schreiben, das dir hilft, die Nachricht zu entschlüsseln.

## 1. Die Bits zurückverschieben

Der erste Schritt beim Entschlüsseln der Nachricht besteht darin, die Verschiebung aus dem Verschlüsselungsprozess rückgängig zu machen, indem die Bits wieder nach links verschoben werden.
Die Anzahl der Stellen, um die verschoben wird, kann von Nachricht zu Nachricht variieren.

Implementiere die Methode `Secrets.shift_back`, die einen Wert und die Anzahl der Stellen für die Verschiebung nach links entgegennimmt.

```crystal
Secrets.shift_back(0b0001, 2)
# => 0b0100
```

## 2. Eine Bitmaske anwenden

Der nächste Schritt ist, eine Bitmaske anzuwenden, um den Wert bestimmter Bits herauszulesen.
Die Maske wird angewendet, indem ein bitweises UND zwischen dem Wert und der Maske durchgeführt wird.

Implementiere die Methode `Secrets.apply_mask`, die einen Wert entgegennimmt und eine Maske anwendet.

```crystal
Secrets.apply_mask(0b0110, 0b0101)
# => 0b0100
```

## 3. Einige Bits setzen

Das Verschieben der Bits nach links hat einige neue 0-Bits hinzugefügt.
Einige dieser neuen Bits müssen auf 1 gesetzt werden.
Das bitweise ODER ist nützlich, um bestimmte Bits auf 1 zu setzen und die übrigen beizubehalten.

Implementiere die Methode `Secrets.set_bits`, die zwei Werte entgegennimmt und ein bitweises ODER durchführt.

```crystal
Secrets.set_bits(0b0110, 0b0101)
# => 0b111
```

## 4. XOR umkehren

Ein Teil des Verschlüsselungsprozesses wendet ein XOR mit einem vereinbarten Wert an.
Um zum ursprünglichen Wert zurückzukommen, kann der verschlüsselte Wert einfach erneut mit dem vereinbarten Wert XOR-verknüpft werden.
Aufgrund eines Missverständnisses hat dein Freund jedoch die Bits des vereinbarten Werts umgedreht (d. h. ein bitweises NICHT auf den vereinbarten Wert angewendet), bevor er das XOR angewendet hat. 

Implementiere die Methode `Secrets.reverse_xor`, die den verschlüsselten und den vereinbarten Wert entgegennimmt und den ursprünglichen Wert berechnet.

```crystal
Secrets.reverse_xor(0b1100, 0b0101)
# => 0b(0110)
```
