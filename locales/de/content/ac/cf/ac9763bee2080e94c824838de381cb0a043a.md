# Einführung

Referenzen zu verstehen ist ein grundlegender Baustein, um Perl effektiv einzusetzen.
Da Referenzen Skalare sind und Arrays und Hashes nur Skalare enthalten können, sind Referenzen der Schlüssel, um diese Datenstrukturen zu verschachteln.

Mit dem Backslash-Operator `\` kannst du Referenzen auf vorhandene Variablen und Subroutinen erzeugen:

* `\$scalar`, um eine Skalarreferenz zu erzeugen (das kann jeder Skalar sein, z. B. `\1`, nicht nur eine Variable).
* `\@array`, um eine Array-Referenz zu erzeugen.
* `\%hash`, um eine Hash-Referenz zu erzeugen.
* `\&sub`, um eine Code-Referenz zu erzeugen.

Du kannst auch eine sogenannte anonyme Referenz auf Arrays, Hashes und Subroutinen erzeugen:

* `['Alice', 'Bob', 'Charlie']`, um eine anonyme Array-Referenz zu erzeugen.
* `{foo => 'a', bar => 'b', baz => 'c'}`, um eine anonyme Hash-Referenz zu erzeugen.
* `sub { return 1 }`, um eine anonyme Code-Referenz zu erzeugen.

WARNUNG: Geschweifte Klammern können in Perl in bestimmten Kontexten mehrdeutig sein. Wenn du nicht die erwartete Hash-Referenz bekommst, stelle ein Pluszeichen voran, um die Mehrdeutigkeit aufzulösen, z. B. `+{}`. Mehr dazu unter [Geschweifte Klammern][perlrefcurlybrackets].

Auf den Inhalt einer Referenz greifst du mit dem Pfeiloperator `->` zu:

* `$ref->[0]`, um auf ein Element innerhalb einer Array-Referenz zuzugreifen.
* `$ref->{foo}`, um auf einen Wert innerhalb einer Hash-Referenz zuzugreifen.
* `$ref->($arg)`, um eine Subroutine über eine Code-Referenz aufzurufen.

Auf Daten in komplexen Datenstrukturen wie mehrdimensionalen Arrays und verschachtelten Hashes kannst du zugreifen, indem du Indizes aneinanderreihst, z. B. `$ref->{foo}[0]{bar}` (dasselbe wie `$ref->{foo}->[0]->{bar}`).

Wenn du ein ganzes Array oder einen ganzen Hash dereferenzieren möchtest, kannst du den Pfeiloperator gefolgt von `@*` bzw. `%*` verwenden, z. B. `$ref->@*` oder `$ref->%*`.
Du kannst auch Slices einer Array- oder Hash-Referenz erhalten, indem du das `*` durch einen Index ersetzt, z. B. `$ref->@[0..2]` oder `$ref->@{'Foo', 'Bar'}`.
Bei Slices gilt hier die Sigil-Varianz genauso wie bei Array- und Hash-Variablen.

[perlrefcurlybrackets]: https://perldoc.perl.org/perlref#Curly-Brackets
