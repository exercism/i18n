# Einführung

Die Fähigkeit, etwas durch sich selbst zu definieren, nennt man Rekursion. In Gleam begegnet dir Rekursion am häufigsten in rekursiven Funktionen, also Funktionen, die sich selbst aufrufen.

Eine rekursive Funktion braucht mindestens einen _Basisfall_ und mindestens einen _rekursiven Fall_. Ein _Basisfall_ gibt einen Wert zurück, ohne die Funktion erneut aufzurufen. Ein _rekursiver Fall_ ruft die Funktion erneut auf und ändert dabei den Eingabewert so, dass er irgendwann zum Basisfall passt.

```gleam
pub fn factorial(x: Int) -> Int {
  case x {
    // Base case
    1 -> 1

    // Recursive case
    _ -> x * factorial(x - 1)
  }
}
```

Gleam hat keine spezielle Syntax für Schleifen, deshalb wird jede Schleife mit Rekursion umgesetzt.

```gleam
pub fn list_length(list: List(String)) -> Int {
  case list {
    [] -> 0
    [_, ..rest] -> 1 + list_length(rest)
  }
}
```

Gleam unterstützt außerdem rekursive benutzerdefinierte Typen. Bei einem rekursiven benutzerdefinierten Typ bezieht sich mindestens eine seiner Varianten in ihren enthaltenen Daten auf den Typ selbst.

```gleam
pub type RussianDoll {
  Child               // Base case
  Mother(RussianDoll) // Recursive case
}
```
```gleam
let very_big_doll = Mother(Mother(Mother(Child)))
let small_doll = Mother(Child)
```
