# Einführung

Mit einer Funktion kannst du Code zu einer wiederverwendbaren Einheit zusammenfassen.
Sie besteht aus dem Schlüsselwort `func`, dem Namen der Funktion und einer durch Kommas getrennten Liste von null oder mehr Parametern und Typen in runden Klammern.

## Funktionsparameter

Alle Parameter müssen explizit typisiert werden; für Parameter gibt es keine Typinferenz.
Es gibt keine Standardwerte für Parameter, deshalb sind alle Funktionsparameter erforderlich.

```go
import "fmt"

// No parameters
func PrintHello() {
    fmt.Println("Hello")
}

// Two parameters
func PrintGreetingName(greeting string, name string) {
  fmt.Println(greeting + " " + name)
}
```

Parameter desselben Typs kannst du gemeinsam angeben, gefolgt von einer einzigen Typangabe.

```go
import "fmt"

func PrintGreetingName(greeting, name string) {
  fmt.Println(greeting + " " + name)
}
```

## Parameter vs. Argumente

Schauen wir uns kurz zwei Begriffe an, die oft verwechselt werden: `parameters` und `arguments`.
Funktionsparameter sind die Namen, die in der Signatur der Funktion definiert sind, wie `greeting` und `name` in der Funktion `PrintGreetingName` oben.
Funktionsargumente sind die konkreten Werte, die an die Funktionsparameter übergeben werden, wenn wir die Funktion aufrufen.
Im folgenden Beispiel sind `"Hello"` und `"Katrina"` zum Beispiel die Argumente, die an die Parameter `greeting` und `name` übergeben werden:

```go
PrintGreetingName("Hello", "Katrina")
```

## Rückgabewerte

Auf die Funktionsparameter folgen null oder mehr Rückgabewerte, die ebenfalls explizit typisiert werden müssen.
Einzelne Rückgabewerte stehen ohne Klammern, mehrere Rückgabewerte werden in runde Klammern gesetzt.
Werte werden mit dem Schlüsselwort `return` an den aufrufenden Code zurückgegeben.
Eine Funktion kann mehrere `return`-Anweisungen enthalten.
Die Ausführung der Funktion endet, sobald sie auf eine dieser `return`-Anweisungen trifft.
Wenn eine Funktion mehrere Werte zurückgeben soll, werden sie durch Kommas getrennt.

```go
func Hello(name string) string {
  return "Hello " + name
}

func HelloAndGoodbye(name string) (string, string) {
  return "Hello " + name, "Goodbye " + name
}
```

## Funktionen aufrufen

Um eine Funktion aufzurufen, gibst du den Funktionsnamen an und übergibst in runden Klammern Argumente für jeden Parameter der Funktion.

```go
import "fmt"

// No parameters, no return value
func PrintHello() {
    fmt.Println("Hello")
}
// Called like this:
PrintHello()

// One parameter, one return value
func Hello(name string) string {
  return "Hello " + name
}
// Called like this:
greeting := Hello("Dave")

// Multiple parameters, multiple return values
func SumAndMultiply(a, b int) (int, int) {
    return a+b, a*b
}
// Called like this:
aplusb, atimesb := SumAndMultiply(a, b)
```

## Benannte Rückgabewerte und nacktes `return`

Rückgabewerte kannst du, genau wie Parameter, optional benennen.
Wenn benannte Rückgabewerte verwendet werden, gibt eine `return`-Anweisung ohne Argumente diese Werte zurück.
Man nennt das ein „nacktes“ `return`.

```go
func SumAndMultiplyThenMinus(a, b, c int) (sum, mult int) {
    sum, mult = a+b, a*b
    sum -= c
    mult -= c
    return
}
```

## Wertübergabe vs. Referenzübergabe

Es ist auch wichtig, das Konzept der Wertübergabe und der Referenzübergabe zu klären.

Klären wir zuerst die Wertübergabe.
Wenn wir im folgenden Beispiel die Variable `val` an die Funktion `MultiplyByTwo` übergeben, übergeben wir eine Kopie von `val`.
Deshalb hat `newVal` den aktualisierten Wert `4`, aber die ursprüngliche Variable `val` ist immer noch `2`.
Im Hintergrund erstellt Go im Wesentlichen eine Kopie des ursprünglichen Werts, sodass die Funktion nur diese Kopie, also `v`, verändert.

```go
val := 2
func MultiplyByTwo(v int) int {
    v = v * 2
    return v
}
newVal := MultiplyByTwo(val)
// newval is 4, val is still 2 because only a copy of its value was passed into the function
```

Streng genommen werden in Go alle Argumente als Wert übergeben, das heißt, es wird eine Kopie des Werts oder der Daten erstellt, die an die Funktion übergeben werden.
Wenn du aber keine Kopie der Daten erstellen möchtest, die an eine Funktion übergeben werden, und die Daten in der Funktion ändern willst, dann solltest du `pointers` als Argumente verwenden, also die Referenzübergabe.

## Pointer

Wir verwenden einen `pointer`, um die Referenzübergabe zu erreichen.
Indem wir `pointer`-Argumente an eine Funktion übergeben, können wir die zugrunde liegenden Daten verändern, die an die Funktion übergeben wurden, statt nur mit einer Kopie der Daten zu arbeiten.

Für den Moment reicht es zu wissen, dass Pointer-Typen am `*` vor dem Typ in der Funktionssignatur zu erkennen sind.

```go
func HandlePointers(x, y *int) {
    // Some logic to handle integer values referenced by pointers x and y
}
```

Wenn dir das Konzept `pointer` schwerfällt, keine Sorge.
Später im Lehrplan gibt es einen eigenen Abschnitt, der dir hilft, Pointer zu meistern.

## Ausnahmen

Beachte, dass `slices` und `maps` Ausnahmen von der oben genannten Regel sind.
Wenn wir einen `slice` oder eine `map` als Argumente an eine Funktion übergeben, werden sie wie Pointer-Typen behandelt, obwohl im Typ kein explizites `*` steht.
Das bedeutet: Wenn wir einen Slice oder eine Map an eine Funktion übergeben und ihre zugrunde liegenden Daten ändern, wirken sich die Änderungen auf den ursprünglichen Slice bzw. die ursprüngliche Map aus.
