# Übungen lösen

Exercism hilft dir vor allem dadurch beim Lernen, dass du Übungen löst.

Es gibt zwei Wege, auf Exercism Übungen zu lösen:

1. [Online über den Editor im Browser der Website](/docs/using/solving-exercises/using-the-online-editor)
2. [Lokal auf deinem Rechner über die Kommandozeile](/docs/using/solving-exercises/working-locally)

## Welche Option soll ich wählen?

Der Online-Editor und die Kommandozeile haben unterschiedliche Vor- und Nachteile:

|            | Online-Editor                          | Kommandozeile                                |
| ---------- | -------------------------------------- | -------------------------------------------- |
| Installation | Nein                                 | Ja (z. B. SDK)                               |
| Bearbeiten | Browser                                | Dein bevorzugter Editor                      |
| Testen     | Tests auf der Website ausführen        | Tests lokal ausführen                        |
| Debuggen   | Eingeschränkt (nur für manche Tracks) | Vollständig (abhängig von deiner Umgebung)   |

Generell ist der Online-Editor ideal für den Einstieg in neue Tracks. Der Ansatz über die Kommandozeile ist dagegen großartig, wenn du deine eigene, persönliche Programmierumgebung nutzen möchtest.
