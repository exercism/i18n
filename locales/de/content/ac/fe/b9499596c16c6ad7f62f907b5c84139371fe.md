# Anleitung

Du arbeitest daran, ein System zur Gesundheitsüberwachung zu implementieren.
Dabei musst du die Gesundheitsstatistiken der Nutzer verfolgen.

Du startest mit einigen Stub-Funktionen in einem `impl`-Block sowie der folgenden `struct`-Definition:

```rust
pub struct User {
    name: String,
    age: u32,
    weight: u32,
}
```

Dein Ziel ist es, die Stub-Methoden des `User`-Structs zu implementieren, das im `impl`-Block definiert ist.

Zum Beispiel sollte die `new`-Methode eine Instanz des `User`-Structs mit den angegebenen Werten für Name, Alter und Gewicht zurückgeben.

```rust
let mut bob = User::new("Bob", 32, 72);
// Returns: a User with name "Bob", age 32, and weight 72
```

Die `weight`-Methode sollte das Gewicht des `User` zurückgeben.

```rust
bob.weight();
// Returns: 72
```

Die `set_age`-Methode sollte das Alter des `User` setzen.

```rust
bob.set_age(33);
// Updates Bob's age to 33; happy birthday Bob!
```
