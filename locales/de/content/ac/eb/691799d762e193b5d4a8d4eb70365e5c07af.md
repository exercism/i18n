# Anweisungen

Bob ist Finanzberater und hilft Menschen, ihre Ausgaben zu verwalten.
Bobs Kunden schicken ihm Ausgabenaufzeichnungen, die er analysieren soll.
Bob hat Aufzeichnungen aus früheren Zeiträumen, damit er Veränderungen bei den Ausgaben erkennen kann.
Bob mag keine Kalender und verwendet statt Datumsangaben die *Bob-Epoche*.
Die Bob-Epoche ist die Anzahl der Tage, die vergangen sind, seit Bobs Kunde seine Aktivität begonnen hat.

In dieser Übung baust du ein Programm, das Bob dabei hilft, die Ausgaben seiner Kunden zu verwalten und zu analysieren.

Bob arbeitet mit `Record`s und `DaysPeriod`s.

Ein `Record` steht für eine Ausgabenaufzeichnung, die den Tag, an dem die Ausgabe gemacht wurde, den ausgegebenen Betrag und die Kategorie der Ausgabe enthält.

```go
// Record represents an expense record.
type Record struct {
	Day         int
	Amount      float64
	Category    string
}
```

Ein `DaysPeriod` steht für einen Zeitraum von Tagen und umfasst alle Tage vom Tag `From` bis zum Tag `To`.
Beide Enden sind im Zeitraum enthalten.

```go
// DaysPeriod represents a period of days.
type DaysPeriod struct {
	From int
	To   int
}

p := DaysPeriod{From: 1, To: 31}
// p represents all days from the day 1 to the day 31:
//  - days 1, 20, 16 and 31 are examples of days that are included
//    in the range of time specified by p
//  - days 50 and 40 are examples of days that are not included
//    in the range of time specified by p
```

## 1. Implementiere einen allgemeinen Filter für Aufzeichnungen

Bob hat jeden Tag mit vielen Aufzeichnungen zu tun, aber je nach Analyse sind nicht alle davon interessant.
Helfen wir Bob dabei, eine einfache Filterung der Aufzeichnungen durchzuführen.

Implementiere die generische Funktion `Filter`, um Aufzeichnungen nach einem Kriterium zu filtern, das durch eine Funktion vorgegeben wird.
Diese Filterfunktion nimmt eine Sammlung von Aufzeichnungen und eine Prädikatfunktion entgegen und gibt nur die Aufzeichnungen aus der Sammlung zurück, die das Prädikat erfüllen.

```go
records := []Record{
  {Day: 1, Amount: 15, Category: "groceries"},
  {Day: 11, Amount: 300, Category: "utility-bills"},
  {Day: 12, Amount: 28, Category: "groceries"},
}

// Day1Records only returns true for records that are from day 1
func Day1Records(r Record) bool {
  return r.Day == 1
}

Filter(records, Day1Records)
// =>
// [
//   {Day: 1, Amount: 15, Category: "groceries"}
// ]
```

## 2. Filtere Aufzeichnungen innerhalb eines Zeitraums

Bob muss häufig Aufzeichnungen filtern, die in einem bestimmten Zeitraum liegen.

Implementiere die Funktion `ByDaysPeriod`, die Bob dabei hilft, solche Filter zu erstellen.
Diese Funktion nimmt ein `DaysPeriod` entgegen und gibt eine Funktion zurück, die eine Aufzeichnung entgegennimmt und angibt, ob die Aufzeichnung in dem Zeitraum liegt, der durch das als Argument übergebene `DaysPeriod` festgelegt ist.

```go
records := []Record{
  {Day: 1, Amount: 15, Category: "groceries"},
  {Day: 11, Amount: 300, Category: "utility-bills"},
  {Day: 12, Amount: 28, Category: "groceries"},
  {Day: 26, Amount: 300, Category: "university"},
  {Day: 28, Amount: 1300, Category: "rent"},
}

period := DaysPeriod{From: 1, To: 15}

Filter(records, ByDaysPeriod(period))
// =>
// [
//   {Day: 1, Amount: 15, Category: "groceries"},
//   {Day: 11, Amount: 300, Category: "utility-bills"},
//   {Day: 12, Amount: 28, Category: "groceries"},
// ]
```

## 3. Filtere Aufzeichnungen nach Kategorie

Neben dem Filtern von Aufzeichnungen nach einem Zeitraum muss Bob Aufzeichnungen auch nach ihrer Kategorie filtern.

Implementiere die Funktion `ByCategory`, die Bob dabei hilft, solche Filter zu erstellen.
Diese Funktion nimmt eine Kategorie entgegen und gibt eine Funktion zurück, die eine Aufzeichnung entgegennimmt und angibt, ob die Kategorie dieser Aufzeichnung mit der als Argument übergebenen Kategorie übereinstimmt.

```go
records := []Record{
  {Day: 1, Amount: 15, Category: "groceries"},
  {Day: 11, Amount: 300, Category: "utility-bills"},
  {Day: 12, Amount: 28, Category: "groceries"},
  {Day: 28, Amount: 1300, Category: "rent"},
}

Filter(records, ByCategory("groceries"))
// =>
// [
//   {Day: 1, Amount: 15, Category: "groceries"},
//   {Day: 12, Amount: 28, Category: "groceries"},
// ]
```

## 4. Berechne die Gesamtausgaben in einem Zeitraum

Bob möchte außerdem die Gesamtausgaben in einem Zeitraum wissen.

Implementiere die Funktion `TotalByPeriod`, die die Summe der Ausgaben im Tageszeitraum zurückgibt.

```go
records := []Record{
  {Day: 15, Amount: 16, Category: "entertainment"},
  {Day: 32, Amount: 20, Category: "groceries"},
  {Day: 40, Amount: 30, Category: "entertainment"}
}

p1 := DaysPeriod{From: 1, To: 30}
p2 := DaysPeriod{From: 31, To: 60}

TotalByPeriod(records, p1)
// => 16

TotalByPeriod(records, p2)
// => 50
```

## 5. Berechne die Gesamtausgaben für Aufzeichnungen einer Kategorie in einem Zeitraum

Für die komplexesten Berichte, die Bob für seine Kunden erstellt, muss Bob Aufzeichnungen gleichzeitig nach Kategorie und Zeitraum filtern.
Das heißt, Bob möchte die Gesamtausgaben für Aufzeichnungen einer Kategorie in einem bestimmten Zeitraum wissen.

Implementiere die Funktion `CategoryExpenses`, die die Gesamtausgaben in einer Kategorie in einem bestimmten Zeitraum von Tagen zurückgibt.
Die Funktion soll außerdem den Fall unterscheiden, dass die angegebene Kategorie in den Ausgabenaufzeichnungen nicht vorkommt, und den Fall, dass es im angegebenen Zeitraum keine Ausgaben dieser Kategorie gibt.
Wenn die Kategorie in keiner der Aufzeichnungen vorkommt (unabhängig vom Zeitraum), soll die Funktion einen Fehler zurückgeben.

```go
p1 := DaysPeriod{From: 1, To: 30}
p2 := DaysPeriod{From: 31, To: 60}

records := []Record{
  {Day: 1, Amount: 15, Category: "groceries"},
  {Day: 11, Amount: 300, Category: "utility-bills"},
  {Day: 12, Amount: 28, Category: "groceries"},
  {Day: 26, Amount: 300, Category: "university"},
  {Day: 28, Amount: 1300, Category: "rent"},
}

CategoryExpenses(records, p1, "entertainment")
// => 0, error(unknown category entertainment)

CategoryExpenses(records, p1, "rent")
// => 1300, nil

CategoryExpenses(records, p2, "rent")
// => 0, nil
```
