# Anweisungen

In dieser Übung verarbeitest du Logzeilen.

Jede Logzeile ist ein String, der wie folgt formatiert ist: `"[<LVL>]: <MESSAGE>"`.

Das sind die verschiedenen Log-Level:

- `TRC` (trace)
- `DBG` (debug)
- `INF` (info)
- `WRN` (warning)
- `ERR` (error)
- `FTL` (fatal)

Du hast drei Aufgaben, die du alle erledigen musst, um die nötige Funktionalität bereitzustellen.

## 1. Erstelle das LogLevel-Enum

Definiere ein `LogLevel`-Enum mit sechs Fällen, die den obigen Log-Leveln entsprechen, plus einem unbekannten Fall für Log-Level, die fehlen oder nicht dem Standard entsprechen.

- `trace`
- `debug`
- `info`
- `warning`
- `error`
- `fatal`
- `unknown`

## 2. Log-Level parsen

Implementiere als Nächstes den Initialisierer von `LogLevel`, um den Log-Level einer Logzeile zu parsen:

```swift
LogLevel("[INF]: File deleted")
// Returns LogLevel.info
LogLevel("Something went wrong!")
// Returns LogLevel.unknown
```

## 3. Logzeile ins Kurzformat umwandeln

Der Log-Level einer Logzeile nimmt ziemlich viel Platz ein.
Um den Speicherplatz zu reduzieren, den die Logzeilen belegen, wurde ein Kurzformat entwickelt: `"<ENCODED_LEVEL>:<MESSAGE>"`.

Der kodierte Log-Level ist eine einfache Zuordnung eines Log-Levels zu einer Zahl:

- `trace` - `0`
- `debug` - `1`
- `info` - `4`
- `warning` - `5`
- `error` - `6`
- `fatal` - `7`
- `unknown` - `42`

Implementiere die Methode `shortFormat(message: String) -> String`, die das verkürzte Logzeilenformat als `String` ausgeben kann:

```swift
let overflow = LogLevel.error
overflow.shortFormat(message: "Stack overflow")
// Returns "6:Stack overflow"
```
