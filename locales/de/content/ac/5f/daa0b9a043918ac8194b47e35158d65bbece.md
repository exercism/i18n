# Hinweise

## Allgemein

- `H{ } clone` ist der richtige Weg, um eine neue, veränderliche Hashtabelle anzulegen: `H{ }`-Literale können zwischen Aufrufen geteilt werden.
- `inc-at` aus [`assocs`][assocs] addiert 1 auf den Wert eines Schlüssels (oder fügt ihn als 1 ein, wenn er fehlt).

## 1. Ein Inventar aus einer Liste aufbauen

- Beginne mit `H{ } clone` und `inc-at` für jedes Element. Eine Fry-Quotation `'[ _ inc-at ]` erfasst die Hashtabelle, sodass du sie durch `each` weitergeben kannst.
- Umhülle die Iteration mit `[ … ] keep`, damit die Hashtabelle der Wert ist, der auf dem Stack liegen bleibt.

## 2. Weitere Elemente hinzufügen

- Die Form ist dieselbe wie bei Aufgabe 1, nur startest du mit einem `clone` des übergebenen Inventars statt mit einem leeren.

## 3. Zählwerte verringern

- Verwende zuerst `key?`; nur Elemente, die bereits im Inventar sind, werden angefasst.
- `change-at` akzeptiert eine Quotation `( old -- new )`; kombiniere sie mit `[ 1 - 0 max ]` (`max` aus [`math.order`][math.order]), damit der Zählerstand nie negativ wird.

## 4. Ein Element ganz entfernen

- `delete-at` verändert die Hashtabelle und gibt nichts zurück: Erst klonen, dann `delete-at`, und anschließend den Klon auf dem Stack liegen lassen.

## 5. Die verfügbaren Elemente auflisten

- `>alist` wandelt die Hashtabelle in eine Sequenz von Paaren um.
- `[ second 0 > ] filter` behält nur die Elemente auf Lager.
- `sort-keys` (in [`sorting`][sorting]) sortiert eine Alist nach Schlüssel.
