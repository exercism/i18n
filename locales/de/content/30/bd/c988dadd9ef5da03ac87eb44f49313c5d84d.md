# Anweisungen

Deine Aufgabe ist es, eine Stoppuhr zu bauen, mit der du Rundenzeiten präzise erfassen kannst.

Die Stoppuhr verwendet vier Befehle (start, stop, lap und reset), um Folgendes zu erfassen:

1. Die erfasste Zeit der aktuellen Runde
2. Zuvor aufgezeichnete Rundenzeiten

Welche Befehle verwendet werden können, hängt davon ab, in welchem Zustand sich die Stoppuhr befindet:

1. Ready: Anfangszustand
2. Running: Zeitmessung läuft
3. Stopped: Zeitmessung angehalten

| Befehl | Startzustand | Endzustand | Wirkung                                                             |
| ------ | ------------ | ---------- | ------------------------------------------------------------------- |
| Start  | Ready        | Running    | Beginnt die Zeitmessung                                             |
| Start  | Stopped      | Running    | Setzt die Zeitmessung fort                                          |
| Stop   | Running      | Stopped    | Stoppt die Zeitmessung                                              |
| Lap    | Running      | Running    | Fügt die aktuelle Runde den vorherigen Runden hinzu, setzt dann die aktuelle Runde zurück |
| Reset  | Stopped      | Ready      | Setzt die aktuelle Runde zurück und löscht die vorherigen Runden    |
