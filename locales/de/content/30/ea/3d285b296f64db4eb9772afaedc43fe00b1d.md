# Einführung

In Clojure bezeichnet man das Binden eines Werts an einen Namen als _Var_. Vars auf oberster Ebene (globale Vars) ähneln Konstanten in anderen Sprachen, werden aber häufig neu definiert, um dynamische Entwicklung zu ermöglichen.

Vars auf oberster Ebene definierst du mit `def`:

```clojure
(def fingers 10)
```

Mit dem Makro `defn` kannst du eine Funktion definieren, die null oder mehr Argumente entgegennimmt. Eine Funktion gibt immer das Ergebnis des letzten Ausdrucks in ihrem Körper zurück.

```clojure
(defn add [x y]
  (+ x y))
```

Du rufst eine Funktion auf, indem du ihren Namen nennst und für jeden Parameter der Funktion ein Argument übergibst.

```clojure
(def five (add 2 3))
```

Funktionen und Werte in Clojure kannst du erst verwenden, _nachdem_ du sie definiert hast. Verwendest du sie, bevor sie definiert wurden, führt das zu einem Kompilierfehler.

```clojure
;; Compile error as `add` has not yet been defined
(def seven (add 3 4))

(defn add [x y]
  (+ x y))
```

In Clojure hat Leerraum keine andere Bedeutung als die Formatierung.

Clojure organisiert Funktionen und Vars in Namespaces. Ein Namespace fasst zusammengehörige Funktionalität zusammen und wird mit dem Makro `ns` definiert:

```clojure
(ns calculator)

(def pi 3.14)

(defn add [x y]
  (+ x y))
```

Clojure unterstützt zwei Arten von Kommentaren. Einzeilige Kommentare beginnen mit `;`, und die `comment`-Form verhindert die Auswertung von allem zwischen `(comment` und `)`.
