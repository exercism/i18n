# Ergänzung zu den Anweisungen

## Hinweise

Um diese Übung zu lösen, musst du die Funktion `score` implementieren, die eine Folge von Bowling-*Würfen* entgegennimmt und die Endpunktzahl oder den passenden Fehler zurückgibt:

```haskell
score :: [Int] -> Either BowlingError Int

data BowlingError = IncompleteGame
                  | InvalidRoll { rollIndex :: Int, rollValue :: Int }
                  deriving (Eq, Show)
```

Diese Definitionen findest du bereits vor, aber die Funktion musst du selbst definieren.

Denk daran, dass die Testsuite erwartet, dass die Würfe bei null beginnend nummeriert werden.
