# Anleitung

In dieser Übung arbeitest du an einem Terminplaner für einen Schönheitssalon in New York, der am 15. September 2012 eröffnet wurde.

Du hast fünf Aufgaben, bei denen es jedes Mal um Termindaten geht.
Die Uhrzeiten sind im 24-Stunden-Format (kein AM/PM).

## 1. Termindatum im Zahlenformat parsen

Implementiere die Funktion `schedule_appointment()`, um eine textliche Darstellung eines Termindatums in das entsprechende `DateTime`-Format zu parsen.

Beachte, dass die Eingabe im US-amerikanischen Format Monat/Tag/Jahr vorliegt.

```julia-repl
julia> schedule_appointment("07/25/2023 13:45:00")
2023-07-25T13:45:00
```

## 2. Prüfen, ob ein Termin bereits vorbei ist

Implementiere die Funktion `has_passed()`, die ein Termindatum entgegennimmt und prüft, ob der Termin irgendwann in der Vergangenheit lag:

```julia-repl
julia> has_passed(DateTime(1999, 12, 31, 9, 0, 0))
true
```

## 3. Prüfen, ob ein Termin am Nachmittag liegt

Implementiere die Funktion `is_afternoon_appointment()`, die ein Termindatum entgegennimmt und prüft, ob der Termin am Nachmittag liegt (>= 12:00 und < 18:00):

```julia-repl
julia> is_afternoon_appointment(DateTime(2023, 3, 29, 15, 0, 0))
true
```

## 4. Uhrzeit und Datum des Termins beschreiben

Implementiere die Funktion `description()`, die ein Termindatum entgegennimmt und eine Beschreibung dieses Datums und dieser Uhrzeit zurückgibt:

```julia-repl
julia> describe(DateTime(2023, 3, 29, 15, 0, 0))
"You have an appointment on Wednesday, March 29, 2023 at 15:00"
```

## 5. Das Jubiläumsdatum zurückgeben

Implementiere die Funktion `anniversary_date()`, die das Jubiläumsdatum dieses Jahres zurückgibt, also den 15. September:

```julia-repl
julia> anniversary_date()  # run during 2025
2025-09-15
```
