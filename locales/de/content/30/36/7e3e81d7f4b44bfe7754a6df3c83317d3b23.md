# Ergänzung zu den Anweisungen

## Format des Minenfelds

Das Minenfeld wird als null-terminierter String dargestellt, mit einem Zeilenumbruch am Ende jeder Zeile.

Ein Beispiel wäre `"   \n * \n   \n"`

## Register

| Register | Verwendung    | Typ     | Beschreibung                     |
| -------- | ------------- | ------- | -------------------------------- |
| `$a0`    | Eingabe       | Adresse | null-terminierter Eingabe-String |
| `$a1`    | Ein-/Ausgabe  | Adresse | null-terminierter Ausgabe-String |
| `$t0-9`  | temporär      | beliebig | für die temporäre Speicherung   |
