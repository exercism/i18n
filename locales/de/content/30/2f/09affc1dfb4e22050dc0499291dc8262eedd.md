# Über

`assocs` ist ein [Protokoll][assoc-protocol], kein einzelner Datentyp. Hashtabellen (`H{ }`), Assoziationslisten (Folgen von `{ key value }`-Paaren) und Baum-Maps implementieren es alle, und die meisten Wörter, die auf Assocs arbeiten, lassen sich zwischen ihnen austauschen.

```factor
USING: assocs ;

H{ } clone "coal" over inc-at
"coal" over inc-at
"wood" over inc-at      ! => H{ { "coal" 2 } { "wood" 1 } }
```

Die volle Bandbreite ist groß: sortierte Iteration, Mapping, Filtern. Doch bei den meisten Arbeiten auf Übungsniveau geht es nur um eine kleine Auswahl:

| Wort        | Stackeffekt                                   |
|-------------|-----------------------------------------------|
| `at`        | `( key assoc -- value/f )`                    |
| `at*`       | `( key assoc -- value ? )` unterscheidet f als Wert von einem fehlenden Schlüssel |
| `key?`      | `( key assoc -- ? )`                          |
| `set-at`    | `( value key assoc -- )` mutiert              |
| `change-at` | `( key assoc quot -- )`, `quot` ist `( old -- new )` |
| `inc-at`    | `( key assoc -- )`, `+1`, fügt `1` ein, falls der Schlüssel fehlt |
| `delete-at` | `( key assoc -- )` mutiert                    |
| `>alist`    | `( assoc -- pairs )`                          |

`sort-keys` und `sort-values` (aus `sorting`) sortieren eine Alist nach dem gewählten Feld.

[assoc-protocol]: https://docs.factorcode.org/content/article-assocs-protocol.html
