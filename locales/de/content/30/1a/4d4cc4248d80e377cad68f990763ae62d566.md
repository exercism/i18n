# Überblick

Objektinitialisierer sind eine Alternative zu Konstruktoren. Die Syntax ist eine durch Kommas getrennte Liste von Paaren der Form Feldname=Wert, wie im folgenden Beispiel:

```csharp
public class Person
{
    public string Name;
    public string Address;
}

var person = new Person{Name="The President", Address = "Élysée Palace"};
```

Auflistungen lassen sich ebenfalls auf diese Weise initialisieren. Typischerweise geschieht das mit durch Kommas getrennten Listen, wie hier gezeigt:

```csharp
IList<Person> people = new List<Person>{ new Person(), new Person{Name="Joe Shmo"}};
```

Dieser Ansatz (und diese Syntax) kann bei jeder Klasse verwendet werden, die `IEnumerable` implementiert und eine `Add()`-Methode besitzt.

Die Felder können in beliebiger Reihenfolge aufgeführt oder ganz weggelassen werden.

Wörterbücher verwenden die folgende Syntax:

```csharp
IDictionary<int, string> numbers = new Dictionary<int, string>{ [0] = "zero", [1] = "one"...};

// or

IDictionary<int, string> numbers = new Dictionary<int, string>{ {0, "zero" }, {1,  "one"}...};
```

Die initialisierten Felder müssen für den Aufrufer zugänglich sein. Typischerweise heißt das, sie müssen `public` oder `internal` sein.

Unter den Sprachentwicklern und führenden Praktikern gibt es einen starken Trend zur Unveränderlichkeit, weshalb die Veränderbarkeit von Objekten, die auf diese Weise initialisiert werden, als Nachteil gilt. Es gibt Vorschläge, eine `init`-Klausel in der kommenden Version der Sprache, C# 9, einzuführen, die dies lösen könnte.

- Die Dokumentation zu [Auflistungsinitialisierern][collection-initializers] gibt einen Vorgeschmack darauf, wie Initialisierer mit Auflistungen wie Wörterbüchern und Listen verwendet werden können.
