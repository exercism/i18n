# Tests

Du kannst die bereitgestellten Tests über DrRacket oder über die Kommandozeile ausführen.

Um die Tests über DrRacket auszuführen, öffne einfach die Testdatei und klicke oben rechts auf die Schaltfläche „Run".

Um die Tests über die Kommandozeile auszuführen, führe sie einfach aus dem Verzeichnis der Übung heraus aus. Wenn die Testsuite zum Beispiel `hello-world-test.rkt` heißt, kannst du den folgenden Befehl ausführen:

```
raco test hello-world-test.rkt
```

Dieser zeigt dann Folgendes an:

```
raco test: (submod "hello-world-test.rkt" test)
2 success(es) 0 failure(s) 0 error(s) 2 test(s) run
0
2 tests passed
```
