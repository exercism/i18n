# Über

Haxe ist stark typisiert, aber das Typsystem kann bei Bedarf umgangen werden. Wenn du einem Namen einen Wert zuweist, nennt man das Definieren einer Variablen. Du kannst eine Variable definieren, indem du ihren Typ explizit angibst, oder indem du den Haxe-Compiler den Typ mit dem [`var`-Schlüsselwort](var) ableiten lässt. Die folgenden beiden Variablendefinitionen sind daher gleichwertig:

```haxe
var explicitVariable:Int = 10; // Explicitly typed
var implicitVariable = 10; // Implicit typed
```

Eine Variable kannst du mit dem Operator `=` aktualisieren:

```haxe
var number = 0; // Initial value
number = 1; // Updated value
```

Der Compiler wirft einen Fehler, wenn du einen Wert zuweist, dessen Typ sich vom Typ der Variablen unterscheidet:

```haxe
var number = 1; // Variable number is of integer type
number = "Hello" // Error trying to assign a string to an integer variable
```

In Haxe wird Code normalerweise in einer _Funktion_ geschrieben, die auch [_Methode_](method) genannt wird. Diese Funktionen können Parameter (Argumente) annehmen und mit dem Schlüsselwort `return` Werte zurückgeben. Funktionen werden mit der Syntax `()` aufgerufen. Alle Funktionen müssen einen Rückgabetyp haben.

```haxe
function add(x:Int, y:Int):Int {
  return x + y;
}
```

Der Gültigkeitsbereich wird in Haxe zwischen den Zeichen `{` und `}` festgelegt.

Haxe unterstützt zwei Arten von Kommentaren. Einzeilige Kommentare werden mit `//` eingeleitet, mehrzeilige Kommentare stehen zwischen `/*` und `*/`.
