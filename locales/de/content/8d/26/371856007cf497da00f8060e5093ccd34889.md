# Anweisungen

Du und deine Freunde spielt gerne Pen-and-Paper-Rollenspiele, aber dir ist aufgefallen, dass es schwierig ist, neue Leute für eure Gruppe zu gewinnen. Sie haben oft Mühe mit der Charaktererstellung. Sie wissen nicht, wo sie anfangen sollen. Um neuen Spielerinnen und Spielern zu helfen, hast du beschlossen, ein kleines Programm zu schreiben, das sie durch den Prozess führt.

## 1. Heiße den neuen Spieler willkommen

Implementiere die Funktion `RPG.CharacterSheet.welcome/0`. Sie sollte eine Willkommensnachricht ausgeben und `:ok` zurückgeben.

```elixir
RPG.CharacterSheet.welcome()
# > Welcome! Let's fill out your character sheet together.
# => :ok
```

## 2. Frage nach dem Namen des Charakters

Implementiere die Funktion `RPG.CharacterSheet.ask_name/0`. Sie sollte eine Frage ausgeben, auf eine Antwort warten und die Antwort ohne führende und nachfolgende Leerzeichen zurückgeben.

```elixir
RPG.CharacterSheet.ask_name()
# > What is your character's name?
# < Mathilde
# => "Mathilde"
```

## 3. Frage nach der Klasse des Charakters

Implementiere die Funktion `RPG.CharacterSheet.ask_class/0`. Sie sollte eine Frage ausgeben, auf eine Antwort warten und die Antwort ohne führende und nachfolgende Leerzeichen zurückgeben.

```elixir
RPG.CharacterSheet.ask_class()
# > What is your character's class?
# < healer
# => "healer"
```

## 4. Frage nach dem Level des Charakters

Implementiere die Funktion `RPG.CharacterSheet.ask_level/0`. Sie sollte eine Frage ausgeben, auf eine Antwort warten und die Antwort als Ganzzahl zurückgeben.

```elixir
RPG.CharacterSheet.ask_level()
# > What is your character's level?
# < 2
# => 2
```

## 5. Fasse die vorherigen Schritte zu einem zusammen

Implementiere die Funktion `RPG.CharacterSheet.run/0`. Sie sollte den neuen Spieler willkommen heißen, nach dem Namen, der Klasse und dem Level des Charakters fragen und den Charakterbogen als Map zurückgeben. Sie sollte außerdem die Map mit der Beschriftung „Your character“ ausgeben.

```elixir
RPG.CharacterSheet.run()
# > Welcome! Let's fill out your character sheet together.
# > What is your character's name?
# < Mathilde
# > What is your character's class?
# < healer
# > What is your character's level?
# < 2
# > Your character: %{class: "healer", level: 2, name: "Mathilde"}
# => %{class: "healer", level: 2, name: "Mathilde"}
```
