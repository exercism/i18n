# Anweisungen

Gegeben ist ein String aus Ziffern. Berechne das größte Produkt für einen
zusammenhängenden Teilstring aus Ziffern der Länge n.

Zum Beispiel ist für die Eingabe `'1027839564'` das größte Produkt für eine
Folge von 3 Ziffern 270 (9 * 5 * 6), und das größte Produkt für eine
Folge von 5 Ziffern ist 7560 (7 * 8 * 3 * 9 * 5).

Beachte, dass diese Folgen nur *benachbarte Positionen* in der Eingabe
belegen müssen; die Ziffern müssen nicht *numerisch aufeinanderfolgend* sein.

Für die Eingabe `'73167176531330624919225119674426574742355349194934'`
ist das größte Produkt für eine Folge von 6 Ziffern 23520.
