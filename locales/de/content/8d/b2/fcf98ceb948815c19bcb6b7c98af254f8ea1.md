# Anweisungen

Dein Freund Linus ist Lokomotivführer und fährt Güterzüge zwischen Städten. Züge zu steuern, das macht ihm so schnell keiner nach, aber mit Logistik oder Computern kennt er sich nicht so gut aus. Er würde deine Programmierhilfe gerne in Anspruch nehmen, um Zugdaten zu ordnen und Fehler in den Routendaten zu korrigieren.

~~~~exercism/note
Diese Übung ließe sich leicht mit Slicing, Indexierung und verschiedenen `Dict`-Methoden lösen. Wir möchten jedoch, dass du beim Lösen der folgenden Aufgaben das Packen (also Slurping), das Entpacken (also Splatting) und die Mehrfachzuweisung übst.
~~~~

## 1. Erstelle einen Vektor mit allen Waggons

Dein Freund hat bisher jede Waggon-Kennung (ID) mitgeschrieben, aber er weiß nie genau, wie viele Waggons das System zu einem bestimmten Zeitpunkt verarbeiten muss. Für den Rest des Logistikprogramms wäre es viel einfacher, wenn diese Daten in einem einheitlichen `Vector` verpackt wären.

Implementiere eine Funktion `get_vector_of_wagons(args...)`, die eine beliebige Anzahl von Waggon-IDs entgegennimmt. Jede ID ist eine positive Ganzzahl. Die Funktion soll die übergebenen IDs dann per `return` als einzelnen `Vector` zurückgeben.

```julia-repl
julia> get_vector_of_wagons(1, 7, 12, 3, 14, 8, 5)
7-element Vector{Int64}:
  1
  7
 12
  3
 14
  8
  5
```

## 2. Korrigiere den Vektor der Waggons

Mittlerweile bekommst du ein Gefühl für die Daten und dafür, wie sie im Logistikprogramm verwendet werden. Das ID-System vergibt an die Lokomotive immer die ID **1**, während die übrigen Waggons im Zug eine zufällig gewählte ID größer als **1** erhalten.

Dein Freund musste zwei neue Waggons an den Zug anhängen und hat vergessen, das System zu aktualisieren! Jetzt müssen die ersten beiden Waggons im `Vector` des Zuges ans Ende verschoben werden, sonst gerät alles durcheinander.

Um die Sache noch komplizierter zu machen, hat dein Freund gerade einen zweiten `Vector` entdeckt, der offenbar fehlende Waggon-IDs enthält. Er kann sich nur noch daran erinnern, dass die IDs aus diesem zweiten `Vector` direkt hinter der dafür bestimmten Lokomotive stehen sollen, sobald die neuen Waggons verschoben sind.

Linus wäre dir sehr dankbar, wenn du seine Fehler korrigierst und die Daten zusammenführst.

Implementiere eine Funktion `fix_vector_of_wagons(each_wagons_id, missing_wagons)`, die zwei `Vectors` mit Waggon-IDs entgegennimmt. Sie soll die ersten beiden Elemente des ersten `Vector`s ans Ende verschieben und die Werte aus dem zweiten `Vector` hinter (_also rechts von_) der Lokomotiv-ID (**1**) einfügen. Die Funktion gibt dann per `return` einen `Vector` mit den Änderungen zurück.

```julia-repl
julia> fix_vector_of_wagons([2, 5, 1, 7, 4, 12, 6, 3, 13], [3, 17, 6, 15])
13-element Vector{Int64}:
  1
  3
 17
  6
 15
  7
  4
 12
  6
  3
 13
  2
  5
```

## 3. Ergänze fehlende Stopps

Jetzt, wo alle Waggondaten korrekt sind, möchte Linus, dass du die Routing-Informationen des Systems aktualisierst. Auf einer Transportstrecke hält ein Zug möglicherweise an ein paar verschiedenen Bahnhöfen, um Fracht aufzunehmen und/oder abzuladen. Jede Fahrt kann eine unterschiedliche Anzahl solcher Zwischenstationen haben. Dein Freund möchte, dass du das Routing-`Dict` des Systems um fehlende bzw. zusätzliche Lieferinformationen ergänzt.

Implementiere eine Funktion `add_missing_stops(route, stops...)`, die ein Routing-`Dict` gefolgt von einer variablen Anzahl von `stop_number => city`-Paaren entgegennimmt. Deine Funktion soll dann das Routing-`Dict` zurückgeben, ergänzt um einen zusätzlichen `key`, der einen `Vector` mit allen hinzugefügten Stopps in der richtigen Reihenfolge enthält.

```julia-repl
julia> add_missing_stops(Dict("from" => "New York", "to" => "Miami"), :stop_1 => "Washington, DC", :stop_2 => "Charlotte", :stop_3 => "Atlanta", :stop_4 => "Jacksonville")
Dict{String, Any} with 3 entries:
  "stops" => ["Washington, DC", "Charlotte", "Atlanta", "Jacksonville"]
  "to"    => "Miami"
  "from"  => "New York"
```

## 4. Erweitere die Routing-Informationen

Linus hat am Routing-Programm gearbeitet und dabei bemerkt, dass bei bestimmten Routen einige wichtige Details fehlen. Die anfänglichen Routeninformationen wurden als `Dict` aufgebaut, und dein Freund möchte, dass du dieses `Dict` um alles ergänzt, was fehlen könnte. Jede Route im System braucht etwas andere Details, deshalb wäre Linus eine generische Lösung am liebsten.

Implementiere eine Funktion namens `extend_route_information(route; more_route_information...)`, die ein `Dict` entgegennimmt, das die Start- und Zielstadt der Zugstrecke enthält, dazu eine variable Anzahl von Schlüsselwortargumenten mit Routing-Details wie Geschwindigkeit, Länge oder Temperatur des Zuges. Die Funktion soll ein zusammengeführtes `Dict` mit allen Routing-Informationen zurückgeben.

```julia-repl
julia> extend_route_information(Dict("from" => "Berlin", "to" => "Hamburg"); length = "100", speed = "50")
Dict{Any, String} with 4 entries:
  :speed  => "50"
  "to"    => "Hamburg"
  "from"  => "Berlin"
  :length => "100"


julia> extend_route_information(Dict("from" => "Paris", "to" => "London"), length = "15", temperature = "20", timeOfArrival = "10:30")
Dict{Any, String} with 5 entries:
  :temperature   => "20"
  :timeOfArrival => "10:30"
  "to"           => "London"
  "from"         => "Paris"
  :length        => "15"
```
