# Überblick

So wie ein Zeiger auf ein `int` oder einen anderen grundlegenden Datentyp verweisen kann, kann ein Zeiger auch auf eine Funktion verweisen.
Ein Funktionszeiger kann verwendet werden, um eine Funktion an eine andere Funktion zu übergeben.
Eine Funktion, die als Parameterwert an eine andere Funktion übergeben wird, wird als First-Class-Funktion bezeichnet.
Eine Funktion, die eine oder mehrere Funktionen als Parameter entgegennimmt oder eine Funktion zurückgibt, wird als Funktion höherer Ordnung bezeichnet.

Im folgenden Beispiel sind `is_even` und `is_odd` First-Class-Funktionen.
Die Funktion höherer Ordnung ist `test_number`.

```c
#include <stdio.h>
#include <stdbool.h>

bool is_even (int number) {
    return number & 1 != 1;
}

bool is_odd (int number) {
    return number & 1 == 1;
}

// this function takes any other function which takes a number and returns a bool
void test_number(bool (*func) (int), int number, char *text){
    printf(text, number, func(number)? "true": "false");
}

int main() {
    // prints Testing odd for 3 is true
    test_number(is_odd, 3,"Testing odd for %d is %s\n");
    // prints Testing even for 3 is false
    test_number(is_even, 3,"Testing even for %d is %s\n");
}
```
Die Funktionssignatur `bool (*func) (int)` für das erste Argument von `test_number` stimmt mit der Signatur der übergebenen Funktionen überein.
Sowohl `is_even` als auch `is_odd` nehmen einen Parameter vom Typ `int` entgegen und geben einen `bool` zurück.
In `(*func)` steht `func` für den Namen der zu verwendenden Funktion.
Würde `(*fn)` verwendet, wäre der Aufruf so erfolgt: `printf(text, number, fn(number)? "true": "false");`.
Um den Parameter für den Funktionszeiger zu erfüllen, übergeben wir beim Aufruf von `test_number` den Namen einer Funktion mit der erwarteten Signatur.
Wir sehen also, dass ein Funktionsname auf die Adresse dieser benannten Funktion zeigt.

Der Aufruf eines Funktionszeigers mit der falschen Signatur führt zu undefiniertem Verhalten (UB).
Je nach Compiler lässt es sich möglicherweise nicht kompilieren, oder es kompiliert mit oder ohne Warnungen, stürzt dann aber zur Laufzeit ab.
