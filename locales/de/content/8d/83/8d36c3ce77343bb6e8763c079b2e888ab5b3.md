# Anleitung

Du bist ein begeisterter Vogelbeobachter und behältst den Überblick darüber, wie viele Vögel an einem beliebigen Tag deinen Garten besucht haben.

Du hast beschlossen, deine Vogelbeobachtung auf ein neues Niveau zu heben, und möchtest ein paar Tools implementieren, die dir dabei helfen, die Daten zu verfolgen und zu verarbeiten.

Du hast dich entschieden, die Daten als Liste von Ganzzahlen zu speichern.
Die erste Zahl in der Liste ist die Anzahl der Vögel, die heute deinen Garten besucht haben, die zweite die von gestern, und so weiter.

```exercism/note
In echten Anwendungen solltest du immer Kernmodule verwenden, wann immer es möglich ist. Damit du aber etwas über Rekursion lernst, darfst du in dieser Übung keine der `List`-Funktionen verwenden.
```

## 1. Prüfe, wie viele Vögel heute zu Besuch waren

Implementiere die Funktion `today`.
Sie soll eine Liste mit den täglichen Vogelzahlen entgegennehmen und die heutige Anzahl zurückgeben.
Wenn die Liste leer ist, soll sie `Nothing` zurückgeben, andernfalls wird die Anzahl in ein `Just` verpackt.

```elm
BirdCount.today [2, 5, 1]
    -- Just 2
```

## 2. Erhöhe die heutige Anzahl

Implementiere die Funktion `incrementDayCount`.
Sie soll eine Liste mit den täglichen Vogelzahlen entgegennehmen und die heutige Anzahl um 1 erhöhen.
Wenn die Liste leer ist, gib `[1]` zurück.

```elm
BirdCount.incrementDayCount [4, 0, 2]
    -- [5, 0, 2]
```

## 3. Prüfe, ob es einen Tag ohne Vogelbesuch gab

Implementiere die Funktion `hasDayWithoutBirds`.
Sie soll eine Liste mit den täglichen Vogelzahlen entgegennehmen.
Sie soll `True` zurückgeben, wenn es mindestens einen Tag gab, an dem keine Vögel den Garten besucht haben, und andernfalls `False`.

```elm
BirdCount.hasDayWithoutBirds [2, 0, 4]
    -- True

BirdCount.hasDayWithoutBirds [3, 8, 1, 5]
    -- False
```

## 4. Berechne die Gesamtzahl der Vögel, die zu Besuch kamen

Implementiere die Funktion `total`.
Sie soll eine Liste mit den täglichen Vogelzahlen entgegennehmen und die Gesamtzahl der Vögel zurückgeben, die deinen Garten besucht haben, seit du begonnen hast, die Daten zu sammeln.

```elm
BirdCount.total [4, 0, 9, 0, 5]
    -- 18
```

## 5. Berechne die Anzahl der geschäftigen Tage

Manche Tage sind geschäftiger als andere.
Ein geschäftiger Tag ist einer, an dem fünf oder mehr Vögel deinen Garten besucht haben.

Implementiere die Funktion `busyDays`.
Sie soll eine Liste mit den täglichen Vogelzahlen entgegennehmen und die Anzahl der geschäftigen Tage zurückgeben.

```elm
BirdCount.busyDays [4, 5, 0, 0, 6]
    -- 2
```
