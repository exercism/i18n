# Anleitung

Deine Aufgabe ist es, eine Liste der Torschützen eines Spiels zu nehmen und zu zählen, wie viele Tore jeder Spieler erzielt hat.

`PlayerName` ist ein Typalias für `String`, damit der Code leichter zu lesen ist und damit diese Verwendung von `String` von anderen Verwendungen von `String` unterschieden werden kann.

## 1. Torschützen zusammenfassen

Implementiere zuerst `updateGoalCountForPlayer`, um die Toranzahl für einen Spieler zu initialisieren oder zu erhöhen.
Implementiere dann die Funktion `aggregateScorers`, um zu zählen, wie viele Tore jeder Spieler erzielt hat, indem du `updateGoalCountForPlayer` verwendest.
Diese Funktion nimmt eine `List PlayerName` (die Namen der Spieler, die die Tore erzielt haben; sie kann doppelte Spielernamen enthalten) und gibt ein `Dict PlayerName Int` zurück, das alle Spieler aus der Liste zusammen mit der Anzahl der erzielten Tore enthält.

```elm
aggregateScorers [ "Betty", "Cedd", "Betty" ]
--> Dict.fromList [ ( "Betty", 2 ), ( "Cedd", 1 ) ]
```

## 2. Unbedeutende Spieler entfernen

Implementiere die Funktion `removeInsignificantPlayers`, um alle Spieler herauszufiltern, die weniger Tore als der Schwellenwert erzielt haben.

```elm
removeInsignificantPlayers 2 (Dict.fromList [ ( "Betty", 2 ), ( "Cedd", 1 ) ] )
--> Dict.fromList [ ( "Betty", 2 ) ]
```

## 3. Toranzahl eines Spielers zurücksetzen

Implementiere die Funktion `resetPlayerGoalCount`, um die erzielten Tore eines Spielers auf null zurückzusetzen.

```elm
resetPlayerGoalCount "Cedd" (Dict.fromList [ ( "Betty", 2 ), ( "Cedd", 1 ) ] )
--> Dict.fromList [ ( "Betty", 2 ), ( "Cedd", 0 ) ]
```

## 4. Die Toranzahl für einen einzelnen Spieler formatieren

Implementiere die Funktion `formatPlayer`, um die Toranzahl für einen einzelnen Spieler als String zu formatieren. Wenn der Spieler nicht im Dict vorhanden ist, gehe davon aus, dass seine Toranzahl null ist.

```elm
formatPlayer "Betty" (Dict.fromList [ ( "Betty", 2 ), ( "Cedd", 1 ) ] )
--> "Betty: 2"
```

## 5. Die Toranzahl für alle Spieler formatieren

Implementiere die Funktion `formatPlayers`, um die Toranzahl für alle Spieler als String zu formatieren. Die Spieler sollten nach Spielernamen sortiert sein.

```elm
formatPlayers (Dict.fromList [ ( "Betty", 2 ), ( "Cedd", 1 ) ] )
--> "Betty: 2, Cedd: 1"
```

## 6. Spiele kombinieren

Implementiere die Funktion `combineGames`, die die Gesamtzahl der Tore zählt, die jeder Spieler in beiden Spielen erzielt hat.

```elm
combine Games
  (Dict.fromList [ ( "Betty", 2 ), ( "Cedd", 1 ) ] )
  (Dict.fromList [ ( "Betty", 2 ), ( "Mario", 3 ) ] )
--> Dict.fromList [ ( "Betty", 4 ), ( "Cedd", 1 ), ( "Mario", 3 ) ]
```
