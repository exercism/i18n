# Einführung

In Common Lisp wird die Argumentliste einer Funktion als ['lambda list'][lambda-list] bezeichnet.
Eine lambda list kann Argumente unterschiedlicher Typen enthalten.
Diese verschiedenen Typen werden mit ['lambda list keywords'][lambda-list-keyword] gekennzeichnet, die alle mit `&` beginnen.
Die am häufigsten verwendeten Typen sind optionale Argumente, Keyword-Argumente und Rest-Argumente.
Jeder Parameter in der lambda list nach einem bestimmten lambda list keyword hat diesen Typ.
Ein lambda list keyword kann nur einmal in einer lambda list verwendet werden.

Lambda lists werden auch in anderen Konstrukten verwendet, die später besprochen werden, etwa beim Destructuring und bei Makros.
