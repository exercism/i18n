# Anleitung

Nimm ein verschachteltes Array beliebiger Tiefe und gib ein vollständig abgeflachtes Array zurück.

Beachte, dass manche Sprach-Tracks null-ähnliche Werte im Eingabe-Array enthalten können und dass diese Werte je nach Track unterschiedlich dargestellt werden.
Solche Werte solltest du aus dem abgeflachten Array ausschließen.

Außerdem kann die Eingabe je nach Track einen anderen Datentyp haben und unterschiedliche Typen enthalten.

Schau in die Testsuite, um Details zu erfahren.

## Beispiel

Eingabe: `[1, [2, 6, null], [[null, [4]], 5]]`

Ausgabe: `[1, 2, 6, 4, 5]`
