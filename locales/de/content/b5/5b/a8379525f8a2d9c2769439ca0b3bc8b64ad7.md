# Über

Haxe unterstützt Reflection zur Laufzeit für Typen und Felder. Um Reflection korrekt zu verwenden, musst du verstehen, welche Arten von Operationen unterstützt werden und welche nicht. Da Reflection dynamisch ist, lässt sich das nicht immer zur Compile-Zeit feststellen.

Die Reflection-API besteht aus zwei Klassen:

- `Reflect`: Eine schlanke API, die am besten mit anonymen Strukturen funktioniert, mit begrenzter Unterstützung für Klassen.
- `Type`: Eine robustere API für die Arbeit mit Klassen und Enums.

Die verfügbaren Methoden sind in der API für [Reflect][reflect] und [Type][type] ausführlich beschrieben.

Für das folgende Beispiel verwenden wir das JavaScript-Ziel:

```haxe
class Main {
  public static function main() {
    trace(Type.resolveClass("Main"));
  }
}

// This outputs
// class Test { static main() { console.log("Test.hx:3:",$hxClasses["Test"]); } }
```

[reflect]: https://api.haxe.org/Reflect.html
[type]: https://api.haxe.org/Type.html
