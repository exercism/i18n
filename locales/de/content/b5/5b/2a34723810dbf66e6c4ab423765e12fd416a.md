# Über

Strings in Gleam sind unveränderlicher Text, der von doppelten Anführungszeichen umschlossen wird. Sie unterstützen Unicode-Zeichen und können mehrzeilig sein.

```gleam
let greeting = "Hello, Joe! 📞"

let multi_line_string = "one
two
three"
```

Strings lassen sich mit dem Operator `<>` verknüpfen:

```gleam
let name = "Mike"
"Hello, " <> name <> "!"
// -> "Hello, Mike!"
```

Das Modul [`gleam/string`][stdlib] in der Standardbibliothek bietet Funktionen für den Umgang mit Strings.

In Case-Ausdrücken kannst du Strings abgleichen:

```gleam
pub fn on_an_excellent_adventure(name: String) -> Bool {
  case name {
    "Bill" -> True
    "Ted" -> True
    _ -> False
  }
}
```

Wenn du den Anfang eines Strings abgleichen und den Rest einer Variablen zuweisen möchtest, kannst du das Muster mit dem Operator `<>` verwenden:

```gleam
pub fn profession(name: String) -> String {
  case name {
    "Dr " <> rest -> rest <> " is a doctor"
    _ -> "I'm not sure what " <> name <> " does"
  }
}
```

[stdlib]: https://hexdocs.pm/gleam_stdlib/gleam/string.html
