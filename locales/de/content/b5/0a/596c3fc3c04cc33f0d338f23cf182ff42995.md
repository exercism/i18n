# Tests

Um die Tests auszuführen, führe den folgenden Befehl im Verzeichnis der Übung aus:

```shell
make
```

## Übersprungene Tests

Eine Übung zu lösen bedeutet, alle ihre Tests zu bestehen.
Standardmäßig wird nur ein Test (der erste) ausgeführt, wenn du die Tests ausführst.
Das ist Absicht, denn so kannst du dich ganz darauf konzentrieren, nur diesen einen Test zu bestehen.
Sobald er besteht, kannst du den nächsten Test aktivieren, indem du die Zeile `TEST_IGNORE();` entfernst.
Wenn alle Tests aktiviert sind und deine Implementierung sie alle besteht, hast du die Übung gelöst!
