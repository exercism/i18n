# Hinweise

## Allgemein

- `accessors` stellt die automatisch generierten Getter `slot>>`, Setter
  `>>slot` und Updater `change-slot` bereit.
- Setter und `change-slot` *verändern* das Tupel. Rufe zuerst `clone` auf, wenn
  du eine nicht-destruktive Aktualisierung willst.

## 1. Definiere das `player`-Tupel

- Die Slot-Syntax lautet `{ name initial: value }` innerhalb von `TUPLE: …  ;`.
- Slots ohne eine `initial:`-Klausel sind standardmäßig `f`.

## 2. Führe den Spieler ein

- `name>>` liest den `name`-Slot.
- `unless*` aus [`kernel`][kernel] ist das Idiom „Standardwert, wenn `f`“.

## 3. Belebe einen gefallenen Spieler wieder

- `health>>` liest den Slot; `zero?` aus [`math`][math] prüft auf null.
- Erzeuge den neuen Spieler mit `clone`, gefolgt von `100 >>health` und
  `100 >>mana`.
- Für den Fall „noch am Leben“ gib `f` zurück.

## 4. Nimm Schaden

- `change-health` akzeptiert eine Quotation `( old-health -- new-health )`.
- Eine Fry-Quotation `'[ _ - 0 max ]` (mit `max` aus
  [`math.order`][math.order]) liefert dir „subtrahiere den erfassten Schaden
  und begrenze bei null“.
- Denk daran, vor dem Verändern `clone` aufzurufen.
