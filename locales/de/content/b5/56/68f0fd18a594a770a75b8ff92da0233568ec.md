# Einführung

Objektinitialisierer sind eine Alternative zu Konstruktoren. Die Syntax ist unten dargestellt. Du gibst in geschweiften Klammern eine durch Kommas getrennte Liste von Name-Wert-Paaren an, die durch `=` getrennt sind:

```csharp
public class Person
{
    public string Name;
    public string Address;
}

var person = new Person{Name="The President", Address = "Élysée Palace"};
```

Auch Sammlungen lassen sich auf diese Weise initialisieren. Typischerweise geschieht das mit durch Kommas getrennten Listen, wie hier gezeigt:

```csharp
IList<Person> people = new List<Person>{ new Person(), new Person{Name="Joe Shmo"}};
```

Wörterbücher verwenden die folgende Syntax:

```csharp
IDictionary<int, string> numbers = new Dictionary<int, string>{ [0] = "zero", [1] = "one"...};

// or

IDictionary<int, string> numbers = new Dictionary<int, string>{ {0, "zero" }, {1,  "one"}...};
```
