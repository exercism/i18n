# Anweisungen

Du führst den Requisitentisch für das Schultheaterstück. Die Requisiten sind eine Zuordnung vom Namen einer Requisite zu der Anzahl, in der es sie gibt.

Alle drei Aufgaben kommen in die Klasse `MISSING_PROPS`.

## 1. Wie viele haben wir?

Gib zurück, wie viele Exemplare einer Requisite es gibt. Wenn die Requisite überhaupt nicht auf dem Tisch steht, löse den String `"Unknown prop: "` gefolgt von ihrem Namen aus.

```sather
MISSING_PROPS::count_of(props, "crown")
-- => 2

MISSING_PROPS::count_of(props, "sword")
-- raises "Unknown prop: sword"
```

Beachte den Unterschied zwischen null Exemplaren einer Sache und einer Sache, die es gar nicht gibt. Eine Requisite, die mit null aufgeführt ist, ist bekannt; sie ist einfach ausgegangen.

## 2. Nimm eine weg

Gib zurück, wie viele übrig bleiben, wenn du eine wegnimmst. Wenn die Requisite aufgeführt ist, aber keine mehr übrig sind, löse `"Out of "` gefolgt von ihrem Namen aus.

```sather
MISSING_PROPS::take_one(props, "crown")
-- => 1

MISSING_PROPS::take_one(props, "lantern")
-- raises "Out of lantern"
```

Eine Requisite, die überhaupt nicht auf dem Tisch steht, sollte trotzdem `"Unknown prop: ..."` auslösen, und du solltest diese Meldung nicht zweimal schreiben müssen.

## 3. Melde zurück

Gib eine Meldung zurück, anstatt etwas auszulösen, egal was passiert.

```sather
MISSING_PROPS::report(props, "crown")
-- => "Took crown, 1 left"

MISSING_PROPS::report(props, "lantern")
-- => "Out of lantern"

MISSING_PROPS::report(props, "sword")
-- => "Unknown prop: sword"
```

Wenn es klappt, besteht die Meldung aus `"Took "`, dem Namen, `", "`, der Anzahl der übrigen Exemplare und `" left"`. Wenn nicht, ist die Meldung genau das, was ausgelöst wurde.
