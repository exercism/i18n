# Einführung

## Arrays

JSON definiert ein **Array** wie folgt:

> Ein Array ist eine geordnete Sammlung von Werten.
> Ein Array beginnt mit der linken eckigen Klammer `[` und endet mit der rechten eckigen Klammer `]`.
> Die Werte werden durch ein Komma `,` getrennt.

Arrays können null oder mehr JSON-Werte _jeder Art_ enthalten.
Die Elemente eines Arrays müssen nicht alle denselben Typ haben.

### Arrays erstellen

Verwende eckige Klammern, um Elemente in einem Array zu sammeln.

```jq
[1, 2, 3]
```

Die Elemente eines _Streams_ kannst du in einem Array sammeln, indem du ihn in eckige Klammern setzt.

```jq
range(5)     # => a stream of 5 numbers
[range(5)]   # => the array [0, 1, 2, 3, 4]
```

### Größe

Die Funktion `length` gibt die Anzahl der Elemente in einem Array zurück.

### Indizierung und Slicing

Die Indizierung von Arrays beginnt bei null.

Ein Element holst du mit einem Klammerausdruck aus einem Array:
`.[2]` liefert das dritte Element.

Negative Indizes zählen vom Ende des Arrays rückwärts:
`.[-1]` liefert das letzte Element; `.[-2]` das vorletzte.

Ein **Slice** ist eine Teilsequenz des Arrays.
`.[10:15]` gibt 5 Elemente ab Index 10 zurück; der Endindex ist _nicht enthalten_.

Es gibt ein paar praktische Funktionen:

- `first` liefert das erste Element.
- `last` liefert das letzte Element.
- `nth(n)` liefert das Element an Index `n`.

### Iterieren

`jq` bietet viele Funktionen, die die üblichen Iterationsaufgaben abdecken:

- `map(expr)` gibt ein neues Array zurück, in dem `expr` nacheinander auf jedes Element angewendet wird.

  ```jq
  [1, 2, 3] | map(. * 10)    # => [10, 20, 30]

  ```

- `select(expr)` ist eine Funktion, die `expr` auf einen _einzelnen Wert_ anwendet;
  ist das Ergebnis des Ausdrucks wahr, wird der Wert zurückgegeben;
  ist das Ergebnis falsch, wird _nichts_ zurückgegeben, nicht `null`, sondern wirklich nichts.

  Um das auf ein Array anzuwenden, kombinierst du es mit `map`.

  ```jq
  [range(10)] | map(select(. % 2 == 0))    # => [0, 2, 4, 6, 8]
  ```

  Alternativ wendest du `select` auf einen _Stream_ an und sammelst die Ergebnisse.

  ```jq
  [range(10) | select(. % 2 == 0)]    # => [0, 2, 4, 6, 8]
  ```

- `any(condition)` und `all(condition)` geben einen booleschen Wert zurück, je nachdem, ob beliebige oder alle Elemente im Array die Bedingung erfüllen.

  ```jq
  [1, 2, 3, 4] | any(. > 4)    # false
  [1, 2, 3, 4] | any(. >= 4)   # true

  [1, 2, 3, 4] | all(. >= 4)   # false
  [1, 2, 3, 4] | all(. <= 4)   # true
  ```
