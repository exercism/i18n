# Einführung

Damit ein Objekt mit einem anderen Objekt verglichen werden kann, muss es die `IComparable<T>`-Schnittstelle implementieren.
Diese Schnittstelle hat eine einzige Methode, die implementiert werden muss: `int CompareTo(T other)`.

Die `CompareTo`-Methode kann drei verschiedene Werte zurückgeben:

- Wert kleiner als null: Das aktuelle Objekt ist kleiner als das andere Objekt.
- Wert größer als null: Das aktuelle Objekt ist größer als das andere Objekt.
- Wert gleich null: Das aktuelle Objekt ist gleich dem anderen Objekt.
