# Anweisungen

Das Projekt mit dem ferngesteuerten Auto, das du in der Übung `classes` gestartet hast, ist gut gelaufen (Herzlichen Glückwunsch!), und aufgrund einer Reihe neuer Sponsorenverträge ist Geld für Verbesserungen im Budget.

Ein Teil des Budgets wird für Telemetrie verwendet.

Um die Sponsoren bei Laune zu halten, wurde eine Anzeigetafel am Auto installiert, die die Namen der Sponsoren anzeigt, während es über die Strecke fährt.

Du wirst feststellen, dass die Einführung dieser schicken neuen Technologien die Akkulaufzeit des Autos drastisch verkürzt hat.

## 1. Ermögliche dem ferngesteuerten Auto, Sponsorennamen anzuzeigen

Implementiere `SetSponsors()`, um einen oder mehrere Sponsorennamen entgegenzunehmen und sie im Auto zu speichern.

Beachte, dass das Argument der Methode `SetSponsors()` garantiert nicht null ist.

Implementiere `DisplaySponsor()`, um den ausgewählten Sponsor anzuzeigen. Der erste übergebene Sponsor hat eine `sponsorNum` von 0, der zweite 1 usw.

```csharp
var car = RemoteControlCar.Buy();
car.SetSponsors("Exercism", "Walker Industries", "Acme Co.");
var sp2 = car.DisplaySponsor(sponsorNum: 1);
// => "Walker Industries"
```

## 2. Rufe die Telemetriedaten des Autos ab

Implementiere die Methode `RemoteControlCar.GetTelemetryData()`.

`GetTelemetryData()` soll den Akkustand in Prozent und die gefahrene Strecke in Metern über `out`-Parameter verfügbar machen.

`GetTelemetryData()` soll `false` zurückgeben, wenn das Argument serialNum kleiner ist als der zuvor empfangene Wert. (Es gibt da ein Problem mit mehreren beteiligten Telemetrieknoten.) In diesem Fall wird `serialNum` auf den höchsten vorherigen `serialNum` gesetzt und sowohl der Akkustand als auch die gefahrenen Meter werden auf `-1` gesetzt. Wenn der Aufruf erfolgreich ist, bleibt `serialNum` unverändert.

```csharp
var car = RemoteControlCar.Buy();
car.Drive();
car.Drive();
int serialNum = 4;
car.GetTelemetryData(ref serialNum, out int batteryPercentage, out int distanceDrivenInMeters);
// => true, 4L, 80, 4

serialNum = 1;
car.GetTelemetryData(ref serialNum, out batteryPercentage, out distanceDrivenInMeters);
// => false, 4L, -1, -1
```

## 3. Füge Funktionalität hinzu, damit das Telemetriesystem den Akkuverbrauch pro Meter ermitteln kann

Implementiere die Methode `TelemetryClient.GetBatteryUsagePerMeter()`.

Dies ruft `RemoteControlCar.GetTelemetryData()` auf. Wenn `GetTelemetryData()` `false` zurückgibt oder das Auto nicht gefahren wurde, dann sollte diese Routine „no data“ zurückgeben. Wenn `GetTelemetryData()` `true` zurückgibt, dann sollte eine Nachricht in der folgenden Form zurückgegeben werden: „usage-per-meter=BATTERY-USAGE-PER-METER“. Die Berechnung ist dabei (100 - aktueller Akkustand in Prozent) geteilt durch die bisher gefahrene Strecke in Metern.

```csharp
var car = RemoteControlCar.Buy();
car.Drive();
car.Drive();
var tc = new TelemetryClient(car);
int serialNum = 4;
tc.GetBatteryUsagePerMeter(serialNum);
// => "usage-per-meter=5"

serialNum = 1;
tc.GetBatteryUsagePerMeter(serialNum);
// => "no data"
```
