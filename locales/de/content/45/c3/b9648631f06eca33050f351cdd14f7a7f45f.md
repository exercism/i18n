# Anleitung

Gegeben sind zwei Listen. Finde heraus, ob die erste Liste in der zweiten Liste enthalten ist, ob die zweite Liste in der ersten Liste enthalten ist, ob beide Listen ineinander enthalten sind oder ob nichts davon zutrifft.

Eine Liste A ist genauer gesagt eine Unterliste der Liste B, wenn du 0 oder mehr Elemente vom Anfang von B und 0 oder mehr Elemente vom Ende von B weglässt und dadurch eine Liste erhältst, die vollständig gleich A ist.

Beispiele:

 * A = [1, 2, 3], B = [1, 2, 3, 4, 5], A ist eine Unterliste von B
 * A = [3, 4, 5], B = [1, 2, 3, 4, 5], A ist eine Unterliste von B
 * A = [3, 4], B = [1, 2, 3, 4, 5], A ist eine Unterliste von B
 * A = [1, 2, 3], B = [1, 2, 3], A ist gleich B
 * A = [1, 2, 3, 4, 5], B = [2, 3, 4], A ist eine Überliste von B
 * A = [1, 2, 4], B = [1, 2, 3, 4, 5], A ist keine Überliste von B, keine Unterliste von B und auch nicht gleich B
