# Anweisungen

In dieser Übung verarbeitest du Logzeilen.

Jede Logzeile ist ein String, der wie folgt formatiert ist: `"[<LEVEL>]: <MESSAGE>"`.

Es gibt drei verschiedene Log-Level:

- `INFO`
- `WARNING`
- `ERROR`

Du hast drei Aufgaben. Jede bekommt eine Logzeile, mit der du etwas machen sollst.

## 1. Die Nachricht aus einer Logzeile holen

Implementiere die Funktion `message`, die die Nachricht einer Logzeile zurückgibt:

```clojure
(message "[ERROR]: Invalid operation")
;;=> "Invalid operation"
```

Führende und nachfolgende Leerzeichen sollen entfernt werden:

```clojure
(message "[WARNING]:  Disk almost full\r\n")
;;=> "Disk almost full"
```

## 2. Das Log-Level aus einer Logzeile holen

Implementiere die Funktion `log-level`, die das Log-Level einer Logzeile zurückgibt. Es soll in Kleinbuchstaben zurückgegeben werden:

```clojure
(log-level "[ERROR]: Invalid operation")
;;=> "error"
```

## 3. Eine Logzeile neu formatieren

Implementiere die Funktion `reformat`, die die Logzeile neu formatiert. Zuerst kommt die Nachricht, danach das Log-Level in runden Klammern:

```clojure
(reformat "[INFO]: Operation completed")
;;=> "Operation completed (info)"
```
