# Hinweise

## Allgemein

- Die Ausrichtung einer Struktur ist die _maximale_ Ausrichtung ihrer Felder.
- Die Größe einer Struktur ist ein Vielfaches ihrer Ausrichtung.

## 1. Ein ferngesteuertes Auto erstellen

- Die Ausrichtung einer Struktur ist die _maximale_ Ausrichtung ihrer Felder.
- Die Größe einer Struktur ist ein Vielfaches ihrer Ausrichtung.
- Die Ausrichtung eines Arrays entspricht der Ausrichtung seiner Elemente.
- Jeder 8-Byte-Block einer Struktur sollte getrennt klassifiziert werden.
- Wenn sich eine Ganzzahl und ein Gleitkommawert dieselben 8 Bytes teilen, wird der gesamte 8-Byte-Block in einem General-Purpose-Register (GPR) übergeben.
- Ein Gleitkommawert kann keine mit `equ` definierte Konstante zur Assembler-Zeit sein, aber er kann eine Konstante im Abschnitt .rodata sein.
- Um Rohbytes von einem `xmm`-Register in ein GPR zu verschieben, ohne die Bitdarstellung zu ändern, können die Instruktionen [movd][mov] oder [movq][mov] verwendet werden.

## 2. Eine neue Strecke erstellen

- Die Ausrichtung einer Struktur ist die _maximale_ Ausrichtung ihrer Felder.
- Die Größe einer Struktur ist ein Vielfaches ihrer Ausrichtung.
- Wenn benachbarte Felder einer Struktur nicht so gruppiert werden können, dass sie in ihre Ausrichtung passen, werden Füllbytes eingefügt.

## 3. Ein Renn-Event erstellen

- Die Ausrichtung einer Struktur ist die _maximale_ Ausrichtung ihrer Felder.
- Die Größe einer Struktur ist ein Vielfaches ihrer Ausrichtung.
- Eine Struktur mit bis zu 16 Bytes wird in Registern an eine Funktion übergeben.
- Eine Struktur mit mehr als 16 Bytes wird üblicherweise im Speicher abgelegt.
- Wenn eine Funktion eine Struktur im Speicher zurückgibt, wird die Adresse eines Speicherplatzes, an dem diese Struktur abgelegt werden soll, als implizites erstes Argument in `rdi` übergeben.
- In diesem Fall sollte die Funktion diese Adresse in `rax` zurückgeben.

## 4. Ein Auto für das Rennen bestätigen

- Die Ausrichtung einer Struktur ist die _maximale_ Ausrichtung ihrer Felder.
- Die Größe einer Struktur ist ein Vielfaches ihrer Ausrichtung.
- Ein Zeiger belegt 8 Bytes und wird in einem General-Purpose-Register (GPR) übergeben, unabhängig von der Größe des Typs, auf den er zeigt.
- Sowohl das `cars`-Array als auch die Anzahl der fahrenden Autos müssen in `race` aktualisiert werden.

## 5. Ein Turnier erstellen

- Die Ausrichtung einer Struktur ist die _maximale_ Ausrichtung ihrer Felder.
- Die Größe einer Struktur ist ein Vielfaches ihrer Ausrichtung.
- Eine Struktur mit mehr als 16 Bytes wird üblicherweise im Speicher abgelegt.
- Wenn eine Funktion eine Struktur im Speicher als Argument entgegennimmt, wird diese Struktur auf dem Stack übergeben.
- Sowohl das `races`-Array als auch die Anzahl der Rennen müssen in `tournament` aktualisiert werden.
