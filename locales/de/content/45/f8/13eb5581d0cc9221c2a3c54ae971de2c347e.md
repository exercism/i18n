# Tests

## Einrichtung

Arbeite die [Einrichtungsanleitung für JavaScript][docs-exercism-javascript] durch, um die notwendigen Abhängigkeiten zu installieren.

## Voraussetzungen

Installiere die Abhängigkeiten der Übung:

```shell
corepack pnpm install
```

Wenn sich `corepack` darüber beschwert, dass es nicht aktiviert ist, kannst du es so aktivieren:

```bash
corepack enable pnpm
```

## Die Testsuite zum Laufen bringen

Jede Übung enthält eine Testsuite, mit der du deine Lösung überprüfen kannst, bevor du sie einreichst.
Du kannst diese Tests ausführen, indem du eine Kommandozeile im Verzeichnis der Übung öffnest und dann Folgendes ausführst:

```bash
corepack pnpm test
```

In manchen Testsuiten sind alle Tests außer dem ersten übersprungen.

Sobald ein Test bestanden ist, kannst du den nächsten aktivieren, indem du `xtest` in `test` änderst.

## Eigene Tests schreiben

Wenn du zusätzliche, eigene Tests schreiben möchtest, erstelle eine neue Datei `custom.spec.js` und reiche sie zusammen mit deiner Lösung und der neuen Datei ein:

```shell
exercism submit numbers.js custom.spec.js
```
