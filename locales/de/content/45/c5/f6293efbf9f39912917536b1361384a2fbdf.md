# Anhang zu den Anweisungen

## Trackspezifische Anweisungen

Implementiere eine Funktion namens `slices`, die ein Array von Strings zurückgibt, wie oben beschrieben.
Deine Funktion sollte einen `IllegalArgumentError` mit einer passenden Fehlermeldung werfen, und zwar wie folgt:
- Wenn der gegebene String leer ist, wirf einen Fehler mit der Meldung `series cannot be empty`.
- Wenn die Slice-Länge negativ ist, wirf einen Fehler mit der Meldung `slice length cannot be negative`.
- Wenn die Slice-Länge null ist, wirf einen Fehler mit der Meldung `slice length cannot be zero`.
- Wenn die Slice-Länge die String-Länge überschreitet, wirf einen Fehler mit der Meldung `slice length can not be greater than series length`.
