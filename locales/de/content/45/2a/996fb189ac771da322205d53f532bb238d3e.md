# Anweisungen

Eine [Armstrong-Zahl](https://en.wikipedia.org/wiki/Narcissistic_number) ist eine Zahl, die gleich der Summe ihrer eigenen Ziffern ist, wobei jede Ziffer mit der Anzahl der Ziffern potenziert wird.

Zum Beispiel:

- 9 ist eine Armstrong-Zahl, denn `9 = 9^1 = 9`
- 10 ist *keine* Armstrong-Zahl, denn `10 != 1^2 + 0^2 = 1`
- 153 ist eine Armstrong-Zahl, denn: `153 = 1^3 + 5^3 + 3^3 = 1 + 125 + 27 = 153`
- 154 ist *keine* Armstrong-Zahl, denn: `154 != 1^3 + 5^3 + 4^3 = 1 + 125 + 64 = 190`

Schreib etwas Code, um festzustellen, ob eine Zahl eine Armstrong-Zahl ist.
