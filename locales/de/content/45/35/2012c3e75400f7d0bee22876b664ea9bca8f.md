# Typdeklaration

PHP ist eine _dynamisch typisierte_ Sprache. Das heißt, eine Variable kann jede Art von Information enthalten.
PHP erlaubt jedoch _optional_ starke Typdeklarationen für Klasseneigenschaften, Funktionsargumente und Rückgabewerte von Funktionen.
Starke Typdeklarationen in PHP bieten zur Laufzeit Typüberprüfungen. PHP versucht allerdings, skalare Typen an die Deklaration anzupassen, wenn das möglich ist.
Dieses Umwandlungsverhalten lässt sich mit der `strict_types`-Deklaration am Anfang der Datei deaktivieren.

```php
<?php
declare(strict_types=1);
```

Außerdem können Funktionen den Rückgabetyp `void` haben, um anzuzeigen, dass die Funktion keinen Wert zurückgibt.

```php
<?php
declare(strict_types=1);

class Driver
{
    string $serial_number;

    function setSerialNumber(string $number): void
    {
        $this->serial_number = $number;
    }

    function getSerialNumber(): string
    {
        return $this->serial_number; 
    }
}

$driver = new Driver(); 
$driver->setSerialNumber(1234);
// => This will throw a TypeError with strict_types=1
```

## Union-Typen

Wenn ein Funktionsargument, ein Rückgabewert oder eine Klasseneigenschaft mehr als einen Typ haben kann, lässt sich ein Union-Typ deklarieren.

```php
<?php

class IdentityCard
{
    private int|float $id = 0;

    public function assign(int|float $id): void
    {
        $this->id = intval($id);
    }
}

$card = new IdentityCard();
$card->assign(5.0);
```

## Gemischte Typen

Wenn wir mit Code arbeiten, können wir den Typ manchmal nicht genauer angeben.
Seit PHP 8.0 gibt es einen Typ namens `mixed`, der als Notausgang dient.
`mixed` entspricht einem Union-Typ aus `object|resource|array|string|float|int|bool|null`.
