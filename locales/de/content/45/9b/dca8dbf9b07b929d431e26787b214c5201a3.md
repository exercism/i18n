# Tests

Der Factor-Track verwendet **Factor 0.101**. Jede Übung bringt ein mitgeliefertes `exercism-tools`-Vokabular mit, das die Wörter `STOP-HERE` und `TASK:` für das Parsen sowie einen Test-Runner definiert. Führe im Verzeichnis der Übung Folgendes aus:

```
factor -roots=. -run=exercism-tools <exercise>
```

Zum Beispiel für die Übung `hello-world`:

```
factor -roots=. -run=exercism-tools hello-world
```

Der Runner beendet sich mit Status 0, wenn alle Tests bestehen, und mit einem Wert ungleich 0 samt Diagnoseausgabe, wenn ein Test fehlschlägt.

## Übersprungene Tests

Eine Übung zu lösen heißt, dafür zu sorgen, dass alle ihre Tests bestehen.
Standardmäßig wird nur ein Test (der erste) ausgeführt, wenn du die Tests laufen lässt.
Das ist Absicht, damit du dich darauf konzentrieren kannst, nur diesen einen Test bestehen zu lassen.

Der Mechanismus ist die Zeile `STOP-HERE` in der Testdatei: Beim Parsen weist sie Factor an, alles darunter zu ignorieren, sodass der Runner nur die Tests darüber sieht. Sobald dein erster Test besteht, kannst du auf zwei Wegen weitere Tests aktivieren:

- **Lösche die Zeile `STOP-HERE`**, um alle übrigen Tests auf einmal zu aktivieren.
- **Verschiebe die Zeile `STOP-HERE` weiter nach unten**, um Tests einen nach dem anderen zu aktivieren, oder eine Aufgabe nach der anderen. Konzeptübungen gruppieren Tests unter `TASK:`-Markern. Die Zeile `STOP-HERE` einfach direkt vor das nächste `TASK:` zu setzen, ist ein natürlicher Schritt.

Wenn alle Tests aktiviert sind und deine Implementierung sie alle besteht, hast du die Übung gelöst!
