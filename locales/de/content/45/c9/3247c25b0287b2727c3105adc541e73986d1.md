# Einführung

## Pakete

In Go ist eine Anwendung in Pakete organisiert.
Ein Paket ist eine Sammlung von Quelldateien, die sich im gleichen Ordner befinden.
Alle Quelldateien in einem Ordner müssen am Anfang der Datei denselben Paketnamen haben.
Üblicherweise werden Pakete genauso benannt wie der Ordner, in dem sie liegen.

```go
package greeting
```

Go bietet eine umfangreiche Standardbibliothek aus Paketen, die du in deinem Programm mit dem Schlüsselwort `import` verwenden kannst.
Pakete der Standardbibliothek werden über ihren Namen importiert.

```go
package greeting

import "fmt"
```

Ein importiertes Paket wird dann über den Paketnamen angesprochen:

```go
world := "World"
fmt.Sprintf("Hello %s", world)
```

Go entscheidet anhand der Deklaration, ob ein Element von Code in anderen Paketen aufgerufen werden kann.
Damit eine Funktion, ein Typ, eine Variable, eine Konstante oder ein Strukturfeld von außen sichtbar ist (man nennt das _exportiert_), muss der Name mit einem Großbuchstaben beginnen.

```go
package greeting

// Hello is a public function (callable from other packages).
func Hello(name string) string {
    return "Hello " + name
}

// hello is a private function (not callable from other packages).
func hello(name string) string {
    return "Hello " + name
}
```

## String-Formatierung

Go bietet ein eingebautes Paket namens `fmt` (Formatpaket), das verschiedene Funktionen anbietet, um das Format von Ein- und Ausgabe zu bearbeiten.
Die am häufigsten verwendete Funktion ist `Sprintf`, die Verben wie `%s` verwendet, um Werte in einen String einzusetzen, und diesen String zurückgibt.

```go
import "fmt"

food := "taco"
fmt.Sprintf("Bring me a %s", food)
// Returns: Bring me a taco
```

In Go lassen sich Gleitkommazahlen bequem mit den Verben von Sprintf formatieren: `%g` (kompakte Darstellung), `%e` (Exponent) oder `%f` (ohne Exponent).
Alle drei Verben erlauben es, die Breite des Felds und die numerische Position zu steuern.

```go
import "fmt"

number := 4.3242
fmt.Sprintf("%.2f", number)
// Returns: 4.32
```

Eine vollständige Liste der verfügbaren Verben findest du in der [Dokumentation des Formatpakets][fmt-docs].

`fmt` enthält weitere Funktionen für die Arbeit mit Strings, zum Beispiel `Println`, das die übergebenen Argumente einfach auf der Konsole ausgibt, und `Printf`, das die Eingabe auf dieselbe Weise wie `Sprintf` formatiert, bevor es sie ausgibt.

[fmt-docs]: https://pkg.go.dev/fmt
