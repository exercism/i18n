# Überblick

Um ein zufälliges Element aus einer aufzählbaren Datenstruktur (z. B. einer Liste, einem Range) auszuwählen, verwenden wir [`Enum.random/1`][enum-random]. Diese Funktion wählt ein einzelnes Element aus, wobei jedes Element mit gleicher Wahrscheinlichkeit gewählt wird. Einen einzelnen zufälligen Wert aus einem Range auszuwählen, läuft in konstanter Zeit ab, ohne den gesamten Range zu durchlaufen.

## Zufällige Ganzzahlen und Buchstaben

- Eine zufällige Ganzzahl wählen
  ```elixir
  Enum.random(1..10)
  # => 7
  ```
- Einen zufälligen Buchstaben als String wählen
  ```elixir
  <<Enum.random(?A..?Z)>>
  # => "K"
  ```
- Einen zufälligen Buchstaben als Charlist wählen
  ```elixir
  [Enum.random(?A..?Z)]
  # => ~c"J"
  ```

Um mehr als ein Element aus einer aufzählbaren Datenstruktur auszuwählen, verwende [`Enum.take_random/2`][enum-take-random]. Um eine aufzählbare Datenstruktur in eine zufällige Reihenfolge zu bringen, verwende [`Enum.shuffle/1`][enum-shuffle].

## Zufällige Gleitkommazahlen

Elixir hat keine eigenen Funktionen, um eine zufällige Gleitkommazahl zu wählen. Dafür müssen wir das Modul [`rand`][erl-rand] von Erlang verwenden, das übrigens auch unter der Haube von `Enum.random` zum Einsatz kommt.

- Eine zufällige Gleitkommazahl wählen (größer oder gleich 0.0 und kleiner als 1.0):

  ```elixir
  :rand.uniform()
  # => 0.275329955448815
  ```

- Eine zufällige Gleitkommazahl wählen (größer oder gleich `a` und kleiner als `b`):
  ```elixir
  a = 13
  b = 20
  :rand.uniform() * (b - a) + a
  # => 18.96815556890448
  ```

## Normalverteilung

Alle oben genannten Funktionen wählen einen zufälligen Wert, wobei jeder mögliche Wert mit gleicher Wahrscheinlichkeit gewählt wird. Das nennt man eine _Gleichverteilung_. Das Modul `rand` bietet außerdem die Funktionen [`normal/0`][erl-rand-normal-0] und [`normal/2`][erl-rand-normal-2], die eine zufällige Gleitkommazahl mit einer [Normalverteilung][normal-distribution] wählen.

## Seed

Es ist wichtig zu verstehen, dass die „zufälligen“ Werte von einem _Pseudo_-Zufallszahlengenerator erzeugt werden. Ein PRNG ist ein Algorithmus, der ausgehend von einem Anfangswert namens _Seed_ eine Folge von Zahlen erzeugt, die zufällig erscheint, aber überhaupt nicht zufällig ist.

Diese Tatsache kann beim Debuggen nützlich sein. Du kannst den Pseudo-Zufallszahlengenerator von Erlang (und damit von Elixir) dazu zwingen, dieselbe Zahlenfolge zu erzeugen, indem du seinen Seed mit [`:rand.seed/2`][rand-seed-2] zurücksetzt. Das erste Argument ist ein bestimmter PRNG-Algorithmus und das zweite ein Tupel aus drei Ganzzahlen, also der Seed.

```elixir
:rand.seed(:exsss, {1, 2, 3})
Enum.take_random(100..999, 3)
# => [680, 127, 622]

:rand.seed(:exsss, {1, 2, 3})
Enum.take_random(100..999, 3)
# => [680, 127, 622]
```

## Kryptografie

Die zufälligen Werte, die `Enum.random` und das Modul `rand` von Erlang zurückgeben, sind nicht [kryptografisch sicher][cryptographically-secure-rng]. Verwende sie nicht, um kryptografische Schlüssel, Passwörter oder Nonces zu erzeugen. Für diesen Anwendungsfall gibt es [`:crypto.strong_rand_bytes/1`][erl-crypto-strong-rand-bytes] von Erlang.
