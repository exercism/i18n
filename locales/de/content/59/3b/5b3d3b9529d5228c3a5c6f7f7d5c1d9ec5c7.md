# Hinweise

## 1. Verdopple jede einzelne Karte

- Es gibt eine eingebaute Methode, die sich hervorragend für [einfache Transformationen][map_method_docs] wie diese eignet.

## 2. Erstelle mehrere Kopien von jeder 3, die im Kartenstapel vorkommt

- Es gibt eine eingebaute Methode, die perfekt für eigene Transformationen oder [Akkumulationen][reduce_method_docs] geeignet ist (etwa zum Summieren eines Arrays usw.).

## 3. Finde zwei Karten aus der exakten Mitte des Kartenstapels

- Es gibt eine eingebaute Methode, um Arrays in kleinere Segmente zu [zerlegen und aufzuteilen][slice_method_docs].

## 4. Die beiden äußeren Karten tauchen in der Mitte des Kartenstapels wieder auf

- Es gibt eine eingebaute Methode, um Elemente aus der Mitte eines Arrays [einzufügen oder zu entfernen][splice_method_docs].
- Arrays haben außerdem eingebaute Methoden, um das erste und das letzte Element zu entfernen, siehe die [MDN-Dokumentation zu Arrays][array_docs].

## 5. Jede Karte, die keine 2 ist, verschwindet

- Es gibt eine eingebaute Methode zum [Filtern][filter_method_docs] oder Ausschließen von Elementen in einem Array.

## 6. Verwandle einen gemischten Kartenstapel in einen perfekt geordneten Kartenstapel

- Es gibt eine eingebaute Methode zum [Sortieren][sort_method_docs].

## 7. Ordne den Kartenstapel neu

- Es gibt eine eingebaute Methode zum [Umkehren][reverse_method_docs] eines Arrays.
