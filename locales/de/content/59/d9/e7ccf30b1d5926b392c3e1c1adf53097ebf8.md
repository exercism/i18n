# Anleitung

In dieser Übung spielst du ein Rollenspiel namens „Wizard and Warriors“, in dem du entweder als Wizard oder als Warrior spielst.

Für Warriors und Wizards gelten unterschiedliche Regeln, die bestimmen, wie viele Schadenspunkte sie verursachen.

Für einen Warrior gelten diese Regeln:

- Verursache 6 Schadenspunkte, wenn die angegriffene Figur nicht verwundbar ist
- Verursache 10 Schadenspunkte, wenn die angegriffene Figur verwundbar ist

Für einen Wizard gelten diese Regeln:

- Verursache 12 Schadenspunkte, wenn der Wizard im Voraus einen Zauberspruch vorbereitet hat
- Verursache 3 Schadenspunkte, wenn der Wizard keinen Zauberspruch vorbereitet hat

Normalerweise sind Figuren nie verwundbar. Allerdings _sind_ Wizards verwundbar, wenn sie keinen Zauberspruch vorbereitet haben.

Du hast sechs Aufgaben, die mit Warrior- und Wizard-Figuren arbeiten.

## 1. Beschreibe eine Figur

Überschreibe die Methode `ToString()` der Klasse `Character`, sodass sie eine Beschreibung der Figur zurückgibt, formatiert als `"Character is a <CHARACTER_TYPE>"`.

```csharp
var warrior = new Warrior();
warrior.ToString();
// => "Character is a Warrior"
```

## 2. Sorge dafür, dass Figuren standardmäßig nicht verwundbar sind

Stelle sicher, dass die Methode `Character.Vulnerable()` immer `false` zurückgibt.

```csharp
var warrior = new Warrior();
warrior.Vulnerable();
// => false
```

## 3. Erlaube Wizards, einen Zauberspruch vorzubereiten

Implementiere die Methode `Wizard.PrepareSpell()`, damit ein Wizard im Voraus einen Zauberspruch vorbereiten kann.

```csharp
var wizard = new Wizard();
wizard.PrepareSpell();
```

## 4. Mache Wizards verwundbar, wenn sie keinen Zauberspruch vorbereitet haben

Stelle sicher, dass die Methode `Vulnerable()` `true` zurückgibt, wenn der Wizard keinen Zauberspruch vorbereitet hat, und andernfalls `false`.

```csharp
var wizard = new Wizard();
wizard.Vulnerable();
// => true
```

## 5. Berechne die Schadenspunkte für einen Wizard

Implementiere die Methode `Wizard.DamagePoints()`, sodass sie die verursachten Schadenspunkte zurückgibt: 12 Schadenspunkte, wenn ein Zauberspruch vorbereitet wurde, 3 Schadenspunkte, wenn nicht.

```csharp
var wizard = new Wizard();
var warrior = new Warrior();

wizard.PrepareSpell();
wizard.DamagePoints(warrior);
// => 12
```

## 6. Berechne die Schadenspunkte für einen Warrior

Implementiere die Methode `Warrior.DamagePoints()`, sodass sie die verursachten Schadenspunkte zurückgibt: 10 Schadenspunkte, wenn das Ziel verwundbar ist, 6 Schadenspunkte, wenn nicht.

```csharp
var warrior = new Warrior();
var wizard = new Wizard();

warrior.DamagePoints(wizard);
// => 10
```
