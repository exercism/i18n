# Schleifen

```sather
   loop
      ...
   end;
```

Sather hat genau eine Schleifenanweisung. Es gibt kein `while` und kein `for`;
beide werden aus `loop` und etwas, das es beendet, aufgebaut.

## Variablen

```sather
   total ::= 0;          -- declare, with a starting value
   total := total + 5;   -- assign
```

`::=` deklariert und übernimmt den Typ vom angegebenen Wert. Wenn eine Variable
existieren muss, bevor es einen Wert für sie gibt, deklariere sie stattdessen
mit einem Typ:

```sather
   total : INT;
   total := 0;
```

Eine Variable, die ohne Wert deklariert wird, startet als Null für `INT`,
`false` für `BOOL` und void für einen String oder ein Objekt.

## Eine Schleife beenden

| Geschrieben | Beendet die Schleife |
| --- | --- |
| `until!(q)` | wenn `q` wahr ist |
| `while!(q)` | wenn `q` falsch ist |
| `break!` | sofort |

Alle drei können überall im Schleifenblock auftauchen, und eine Schleife kann
mehr als eine davon verwenden.

```sather
   loop
      until!(n > last);      -- may run no times at all
      ...
   end;

   loop
      ...
      until!(done);          -- always runs at least once
   end;
```

## Das Ausrufezeichen

`until!`, `while!` und `break!` enden mit `!`, weil sie **Iteratoren** sind,
also Dinge, die nur innerhalb einer Schleife vorkommen dürfen und die sie
beenden können. Eine davon außerhalb einer Schleife zu schreiben, ist ein
Fehler und keine Warnung. In späteren Übungen verwendest du die anderen
Iteratoren der Bibliothek und schreibst schließlich neue.

## Endlosschleifen

Eine Schleife ohne Abbruchbedingung läuft endlos. Das ist gelegentlich
gewünscht, aber viel häufiger bedeutet es, dass der Wert, nach dem die
Bedingung fragt, nie geändert wird. Wenn ein Programm hängt, ist das Erste,
was du prüfen solltest, ob etwas innerhalb der Schleife es in Richtung
Beendigung bewegt.
