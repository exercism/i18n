# Über

[Nil][nil-dictionary] ist ein englisches Wort und bedeutet „nichts“ oder „null“.
In Ruby ist `nil` ein Objekt, das die _Abwesenheit_ eines Werts ausdrückt.
In anderen Programmiersprachen können `null` oder `none` eine ähnliche Rolle spielen.

```ruby
# I do not have a favorite color
favorite_color = nil
```

Ruby weist jeder Instanzvariable den Standardwert `nil` zu, sobald sie zum ersten Mal auftritt, bis sie anders gesetzt wird.

[nil-dictionary]: https://www.merriam-webster.com/dictionary/nil
