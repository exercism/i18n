# Hinweise

## Allgemein

- Struct-Instanzen erstellst du, indem du den Struct-Namen angibst, gefolgt von den Feldwerten in geschweiften Klammern.
- Mit `@T` kannst du Snapshots eines Typs `T` deklarieren, z. B. deklariert `let i: @u32 = @1;` eine Variable `i`, die ein Snapshot des `u32`-Werts `1` ist.
- Mit dem `*`-Operator (Desnap) kannst du einen Wert aus einem Snapshot extrahieren, z. B. `let int = *an_int_snapshot;`.
- Mit dem Schlüsselwort `mut` kannst du einen Wert als veränderlich deklarieren, z. B. `let mut i = 1;`.

## 1. Erstelle einen Stimmenzähler

- Du musst einen Pointer auf ein `VoteCounter`-Struct erstellen, also ein `@VoteCounter`.
- Den Parameter `value` kannst du direkt zuweisen, wenn du eine Struct-Instanz erstellst.

## 2. Ermittle die Anzahl der Stimmen aus einem Zähler

- Mit dem `*`-Operator kannst du einen Snapshot desnappen und so seinen Wert erhalten, z. B. `*my_snapshot`

## 3. Erhöhe die Stimmen eines Zählers

- Statt den Snapshot `@VoteCounter` zu verändern, musst du eine neue Instanz von `VoteCounter` mit erhöhten Stimmen zurückgeben.
- Du kannst den zugrunde liegenden Wert des Stimmenzählers mit dem `*`-Operator desnappen oder die Funktion aufrufen, die du in der vorherigen Aufgabe erstellt hast.

## 4. Erstelle die Wahlergebnisse

- Erstelle ein neues `ElectionResult`-Struct oder eine Variable mit den Feldern `name` und `vote_counter`, gefüllt mit den Werten aus den Argumenten der Funktion.
- Du kannst einen `VoteCounter`-Snapshot erstellen, indem du den `@`-Operator vor den Variablennamen bzw. die Struct-Deklaration setzt, oder die Funktion `new_vote_counter` aufrufen, die du in einer der vorherigen Aufgaben erstellt hast.

## 5. Gib die Ergebnisse bekannt

- Obwohl du einen Snapshot eines `ElectionResult` erhältst, kannst du auf seine Felder mit der Punktnotation `.` zugreifen, als wäre es kein Snapshot!
- Baue die Nachricht, indem du auf die Felder `name` und `vote_counter` des Structs zugreifst.
- Wenn du einen verschachtelten Snapshot desnappst, musst du so viele `*`-Operatoren anwenden, wie es Snapshots zum Desnappen gibt:

```rust
let result = @ElectionResult {
    name: "John",
    vote_counter: @VoteCounter { value: 32 },
};

println!("{}", **result.vote_counter.value); 
// => 32
```

## 6. Zähle die Stimmen neu aus

- Weil [Wörterbücher auf eine bestimmte Weise implementiert sind][dictionaries underneath], müssen sie veränderlich sein, um sie sowohl zu ändern als auch aus ihnen zu lesen. Das bedeutet, dass Änderungen, die du am Wörterbuch innerhalb der Funktion vornimmst, auch außerhalb der Funktion sichtbar sind.
- Um den Wert eines Schlüssels in einem `let mut m: Felt252Dict<u32>` zu erhöhen, solltest du seine Funktionen `get` und `insert` kombinieren: `m.insert('mykey', m.get('mykey') + 1);`

[dictionaries underneath]: https://book.cairo-lang.org/ch03-02-dictionaries.html#dictionaries-underneath
