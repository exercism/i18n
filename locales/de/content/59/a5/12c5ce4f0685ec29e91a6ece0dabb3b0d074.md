# Einführung

Eine [switch-Anweisung][switch] vergleicht einen Wert mit mehreren möglichen passenden Mustern.
Sie ist eine sauberere und besser lesbare Alternative dazu, mehrere `if-else`-Anweisungen aneinanderzureihen.

Eine `switch`-Anweisung beginnt mit dem Schlüsselwort `switch`, auf das der zu prüfende Wert folgt.
Jeder mögliche Treffer wird mit dem Schlüsselwort `case` eingeleitet.
Mit dem Schlüsselwort `default` definierst du einen Standardfall, der ausgeführt wird, wenn keiner der expliziten Fälle passt.
Wie `if-else`-Ketten führt auch eine `switch`-Anweisung nur den Block aus, der zum ersten passenden Fall gehört.

```swift
switch value {
case 1:
    print("One")
case 2:
    print("Two")
default:
    print("Other")
}
```

Schauen wir uns die folgende `if-else`-Kette an:

```swift
if str == "apple" {
    print("Let's bake an apple crumble")
} else if str == "lemon" {
    print("Let's bake a lemon meringue pie!")
} else if str == "peach" {
    print("Let's bake a peach pie!")
} else {
    print("Let's buy ice cream.")
}
```

Mit einer `switch`-Anweisung lässt sich das übersichtlicher schreiben:

```swift
switch str {
case "apple":
    print("Let's bake an apple crumble")
case "lemon":
    print("Let's bake a lemon meringue pie!")
case "peach":
    print("Let's bake a peach pie!")
default:
    print("Let's buy ice cream.")
}
```
