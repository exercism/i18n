# Tests

Bevor du versuchst, die Tests auszuführen, stelle sicher, dass der Übungsordner korrekt eingerichtet ist, indem du die Installationsschritte befolgst, nämlich `corepack yarn install` und die Einrichtung des Editor SDK.

Führe die Tests so aus:

```bash
$ corepack yarn test
```

Achte darauf, dass dein Code bewährten Praktiken folgt, wie es bei anderen Nutzern der Fall ist, und nutze eslint, ein Tool, das eine statische Analyse deines Codes durchführt.
Solche Tools sparen dir Zeit beim Aufspüren von Tippfehlern oder Flüchtigkeitsfehlern in deinem Code:

```bash
$ corepack yarn lint
```

Oder mach beides gleichzeitig:

```bash
$ corepack yarn test && corepack yarn lint
```

Der TypeScript-Track auf Exercism schreibt keinen Code-*Stil* vor, du kannst also frei zwischen Semikolons, Tabs oder Leerzeichen und allem dazwischen wählen.

## Dein erstes Modul erstellen

Normalerweise laden die Tests in diesem Track deine Implementierung, indem sie sie als Modul importieren: `import Bob from './bob';`.
Damit das funktioniert, musst du deine Implementierung aus der Datei exportieren, in der die Tests dein Modul erwarten, `bob.ts`:

```typescript
export class Bob {
  public hey(message: string) {
    // Your solution here
  }
}
```

Wir haben in jeder Übung Stubs bereitgestellt und diesen `export` für dich dort eingebaut.
