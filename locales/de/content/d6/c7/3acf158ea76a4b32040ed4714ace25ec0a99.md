# Ergänzende Anweisungen

## Words

Definiere ein `linked-list-node`-Tupel.

Definiere ein `linked-list`-Tupel und stelle eine Methode
`M: linked-list length` bereit (aus `sequences`), damit die Tests
`length` direkt auf deiner Liste aufrufen können.

- `<linked-list> ( -- linked-list )` – erzeugt eine leere Liste.
- `>linked-list ( seq -- linked-list )` – legt jedes Element von
  `seq` der Reihe nach auf eine neue Liste.
- `linked-list>array ( linked-list -- array )` – gibt die Werte
  zurück, das oberste Element der Liste zuerst.
- `list-push ( linked-list value -- linked-list )` – legt einen
  Wert oben auf die Liste.
- `list-pop ( linked-list -- linked-list value )` – entfernt den
  obersten Wert und gibt ihn zurück.
- `list-peek ( linked-list -- value )` – gibt den obersten Wert
  zurück, ohne ihn zu entfernen.
- `list-reverse ( linked-list -- linked-list )` – gibt eine Liste
  mit den Elementen in umgekehrter Reihenfolge zurück.

Wirf aus `list-pop` und `list-peek` eine Fehlerklasse `list-empty`,
wenn die Liste leer ist.
