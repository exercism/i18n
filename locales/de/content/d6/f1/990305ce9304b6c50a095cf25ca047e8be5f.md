# Ergänzung zu den Anweisungen

## Zusätzliche Anweisungen

Du bekommst eine Tabelle namens „isogram“.
Die erste Spalte „phrase“ enthält einen Text.
Du musst herausfinden, ob die Phrase ein Isogramm ist.
Aktualisiere die zweite Spalte „is_isogram“ mit einem Ganzzahlwert:

* 1, wenn die Phrase ein Isogramm ist,
* 0, wenn nicht.

~~~~exercism/note
Vergleichsoperationen in SQLite geben boolesche Werte als 0/1-Zahlen zurück

```sh
$ sqlite3
sqlite> .mode table
sqlite> SELECT 1 < 2 AS "true", 1 > 2 AS "false";
+------+-------+
| true | false |
+------+-------+
| 1    | 0     |
+------+-------+
```
