# Über anonyme Funktionen und Closures

In PHP kannst du Funktionen innerhalb anderer Funktionen deklarieren. Diese Funktionen müssen keinen Namen haben, du kannst sie aber Variablen zuweisen oder sogar direkt an eine andere Funktion übergeben, die einen Funktionsparameter erwartet.

```php
function onlyOdds(array $numbers): array
{
    return array_filter($numbers, function($num) {
        return $num % 2 === 1;
    });
}
```

Die oben definierte und an array_filter übergebene Funktion ist eine anonyme Funktion. Die Funktion `array_filter` nutzt sie, um zu entscheiden, ob ein gegebener Wert in einem Array im Ergebnis von `array_filter` enthalten ist. Wenn die Funktion für einen Wert `true` zurückgibt, wird dieser in das Ergebnis-Array aufgenommen.

Anonyme Funktionen kannst du außerdem nutzen, um von innerhalb der Funktion auf Variablen zuzugreifen, die außerhalb der Funktion im Gültigkeitsbereich liegen. Man sagt, der Gültigkeitsbereich der Funktion „schließt“ die Variable ein, die in der Funktion verwendet wird, daher der Name „Closure“. In manchen Sprachen dürfen alle Variablen im Gültigkeitsbereich automatisch innerhalb des Closures verwendet werden. In PHP ist `$this`, also das aktuelle Objekt, automatisch innerhalb des Closures erlaubt. Alle anderen Variablen musst du explizit mit dem Schlüsselwort `use` einbinden.

```php
function makeAdderFunction(int $number) {
    return function(int $x) use($number) {
        return $x + $number;
    }
}

$add5 = makeAdderFunction(5);
echo $add5(4); // echos 9
```

In der Funktion `makeAdderFunction` oben wird der übergebene Wert `$number` von der intern definierten anonymen Funktion, die dann zurückgegeben wird, „eingeschlossen“. Wann immer diese Funktion dann ausgeführt wird, kennt sie den Wert von `$number`, der übergeben wurde. Wenn du diese Funktion erneut mit einer anderen Zahl aufrufst, bekommst du eine völlig andere Funktion. Die Werte oder die Funktionalität, die der erste Funktionsaufruf zurückgibt, ändern sich dadurch nicht.
Wenn du mehr als eine Variable einschließen musst, kannst du sie durch Kommas getrennt in das Schlüsselwort `use` schreiben.

PHP kennt außerdem eine kürzere Funktionssyntax namens `arrow functions`. Sie müssen recht einfach sein. Die Grundform sieht so aus:

```php
fn(arguments) => expression
```

Bei diesem Funktionsstil brauchst du `use` nicht zu verwenden. Er schließt automatisch alle Werte im umgebenden Gültigkeitsbereich ein und erfasst sie. Der Ausdruck in diesen Arrow-Funktionen wird automatisch zurückgegeben, ohne dass du das Schlüsselwort `return` brauchst. Damit können wir die Funktion `onlyOdds` von oben so umschreiben:

```php
function onlyOdds(array $numbers): array
{
    return array_filter($numbers, fn($n) => $n % 2 == 1);
}
```

Die Funktion `makeAdderFunction` von oben könnte so umgeschrieben werden:

```php
function makeAdderFunction(int $number) {
    return fn(int $x) => $x + $number;
}
```

**Hinweis:** Wenn die Funktion nicht als Ausdruck geschrieben werden kann, kannst du die kürzere Syntax der Arrow-Funktionen nicht verwenden.

Variablen werden bei anonymen Funktionen und Closures nach Wert übergeben und verwendet. Das bedeutet: Wenn du den Wert der Variable innerhalb der Funktion änderst, wirkt sich das nicht auf den Wert der Variable außerhalb der Funktion aus. Wenn der Wert geändert werden soll, kannst du ihn als Referenz übergeben.

```php
function positiveAverage(array $numbers): float
{
    $total = 0;
    $count = 0;
    return array_walk(
      $numbers,
      function($num) use (&$count, &$total) {
          $total += abs($num);
          $count++;
      }
    );
    return $total / $count;
}
```

Im Beispiel oben iteriert `array_walk` über jedes Element im Array und übergibt jeden Wert an die im Aufruf deklarierte Funktion. Es führt eine laufende Summe in `$total`, wobei jeder addierte Wert der Betrag der Zahl ist. Außerdem zählt es mit, wie viele Zahlen es waren. Beide Werte werden im Closure als Referenz verwendet, was durch das `&` vor jeder Variable im `use`-Abschnitt angezeigt wird. Das bedeutet, dass die Änderungen an den Variablen auch nach Abschluss von `array_walk` bestehen bleiben, sodass die Funktion den Durchschnitt der Beträge der Zahlen im Array zurückgeben kann.

Anonyme Funktionen und Closures sind eine praktische Möglichkeit, eine Funktion zu definieren, die vielleicht nur in einem einzigen Kontext gebraucht wird, oder eine Funktion zu definieren, die abhängig von einer Reihe von Parametern eine dynamische Funktion zurückgibt, wobei diese Parameter zu einem anderen Zeitpunkt bekannt sind als dem, zu dem die Funktion tatsächlich verwendet wird.
