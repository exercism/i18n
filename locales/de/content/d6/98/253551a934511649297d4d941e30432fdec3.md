# Einführung

Eine [`function`][function] ist eine Möglichkeit, Code so zu unterteilen, dass er von einer oder mehreren Stellen im Programm über seinen Namen aufgerufen werden kann.
Funktionen werden verwendet, um bestimmte und wiederkehrende Aufgaben auszuführen.

Genauer gesagt: Eine Funktion ist jedes Python-Objekt, auf das man die Operation [`function call`][calls] anwenden kann.
Eine Funktion kann dazu dienen, einen oder mehrere Werte als Ergebnis bestimmter Operationen zurückzugeben ([`return`][return]), oder sie kann einen oder mehrere Seiteneffekte haben ([`side effects`][side effects]).
Wenn eine Funktion keinen Rückgabewert angibt, gibt sie trotzdem `None` zurück.

Hier ist ein Beispiel für eine Funktion mit einem Seiteneffekt:

```python
>>> def hello():
...     print("Hello")
...
>>> hello()
Hello

```

Im obigen Beispiel kennzeichnet das Schlüsselwort [`def`][def] den Beginn der Funktionsdefinition.
`hello` ist der Name der Funktion.
Die leeren runden Klammern bedeuten, dass keine Werte an die Funktion übergeben werden.
Der Körper der Funktion ist die einzelne Anweisung `print("Hello")`.
`print` ist ebenfalls eine Funktion.
Das `"Hello"` in den runden Klammern der Funktion `print` wird als [`argument`][arguments] bezeichnet.
Die Funktion `print` verwendet das Argument, um zu wissen, was sie ausgeben soll.
Beachte, dass der Körper der Funktion eingerückt ist.
Die Einrückung ist wichtig, denn Python verlässt sich darauf, um zu wissen, wo dieser Block endet.
Der Körper der Funktion endet entweder am Ende des Programms oder direkt vor der nächsten Codezeile, die _nicht_ eingerückt ist.
Da `hello()` keinen `return`-Wert angibt, führt es seinen Seiteneffekt aus (den Aufruf von `print()`) und gibt anschließend `None` zurück.
Schließlich rufen wir die Funktion über ihren Namen und die runden Klammern auf, was dem Python-Interpreter signalisiert, dass dies ein _aufrufbarer_ Name ist.

Hier ist ein Beispiel für eine Funktion mit einem Rückgabewert:

```python
>>> def hello():
...     return "Hello"
... 
print(hello())
Hello

```

Der Körper dieser Funktion wurde geändert: Statt `print` _aufzurufen_, wird jetzt der `string` „Hello“ _zurückgegeben_.
Am Ende gibt der Code immer noch `"Hello"` aus, aber der Seiteneffekt findet im _aufrufenden Code_ statt und nicht in der Funktion `hello`.
Wenn man die runden Klammern beim Aufruf der Funktion `hello` weglässt (z. B. `print(hello)`), dann gibt `print` etwa Folgendes aus

```
<function hello at 0x0000026E18E93E20>
```

Wichtig ist: Auch wenn eine Funktion keine Argumente akzeptiert (_d. h. keine Parameter hat_), müssen die leeren runden Klammern verwendet werden, um sie korrekt _aufzurufen_.
Das unterscheidet sich von einer Sprache wie Ruby, die keine leeren runden Klammern benötigt, um eine Funktion ohne Argumente aufzurufen.

Eine Funktion kann null oder mehr [`parameters`][parameters] definieren. Ein Parameter legt fest, welche Argumente die Funktion akzeptiert.

Hier ist ein Beispiel für eine Funktion, die ein Argument akzeptiert:

```python
>>> def hello(name):
...     return f"Hello, {name}"
... 
>>> print(hello("Bob"))
Hello, Bob

```

Der Parameter heißt `name`.
`"Bob"` ist das Argument, das das Programm an die Funktion `hello` übergibt.
Die Funktion _gibt_ den `string` „Hello, Bob“ _zurück_.

Was passiert, wenn jemand `hello` aufruft, ohne ein Argument zu übergeben?
Das Programm wirft einen Fehler:

```python
print(hello())
Traceback (most recent call last):

  Input In in <line: 1>
    print(hello())

TypeError: hello() missing 1 required positional argument: 'name'
```

Wenn wir nicht wollen, dass das Programm ohne Argument einen Fehler wirft (_aber dem aufrufenden Code erlauben wollen, keines anzugeben_), können wir ein [Standardargument][default arguments] definieren.
Ein Standardargument legt fest, welcher Wert verwendet wird, wenn das Argument beim Aufruf der Funktion fehlt.

Hier ist ein Beispiel für eine Funktion mit einem Standardargument:

```python
>>> def hello(name="you"):
...     return f"Hello, {name}"
... 
>>> print(hello())
Hello, you

```

Dem Parameter `name` wird das Standardargument `"you"` zugewiesen, sodass das Programm `Hello, you` ausgibt, wenn kein `name`-Argument übergeben wird.

Mehr über Funktionsargumente findest du im Konzept [Funktionsargumente][function arguments].
