# Anweisungen

In dieser Übung schreibst du Code, der einem Freelancer bei der Kommunikation mit einem Projektmanager hilft.
Deine Aufgabe ist es, ein paar Hilfsfunktionen bereitzustellen, mit denen sich Tages- und Monatssätze schnell berechnen lassen, optional mit einem gegebenen Rabatt.

Zuerst legen wir ein paar Regeln zwischen dem Freelancer und dem Projektmanager fest:

- Der Tagessatz beträgt das Achtfache des Stundensatzes.
- Ein Monat hat 22 abrechenbare Tage.

Manchmal bietet der Freelancer an, einen Rabatt auf seinen Tagessatz zu gewähren (zum Beispiel für seine treuesten Kunden oder für gemeinnützige Kunden).

Rabatte werden als Bruchzahlen modelliert, die Prozentsätze darstellen, zum Beispiel `25.0` (25 %).

## 1. Berechne den Tagessatz bei gegebenem Stundensatz

Implementiere eine Funktion namens `daily_rate`, um den Tagessatz bei gegebenem Stundensatz als Parameter zu berechnen.
Der Vertrag legt fest, dass ein Tag 8 abrechenbare Stunden hat.

```cpp
daily_rate(60)
// => 480.0
```

Der zurückgegebene Tagessatz sollte vom Typ `double` sein.

## 2. Berechne einen rabattierten Preis

Implementiere eine Funktion `apply_discount`, um den Preis nach einem Rabatt zu berechnen.
Sie sollte zwei Parameter akzeptieren: den ursprünglichen Preis und den Rabattsatz in Prozent.

```cpp
apply_discount(150, 10)
// => 135.0
```

Der zurückgegebene Wert sollte immer vom Typ `double` sein und in keiner Weise gerundet werden.

## 3. Berechne den Monatssatz bei gegebenem Stundensatz und Rabatt

Implementiere eine Funktion `monthly_rate`, um den rabattierten Monatssatz zu berechnen.
Sie sollte zwei Parameter haben: einen Stundensatz und den Rabatt in Prozent.

```cpp
monthly_rate(77, 10.5)
// => 12130
```

Der zurückgegebene Monatssatz sollte aufgerundet werden (Aufrunden auf die nächste ganze Zahl).

## 4. Berechne die Anzahl der vollständigen Arbeitstage bei gegebenem Budget, Stundensatz und Rabatt

Implementiere eine Funktion `days_in_budget`, die ein Budget, einen Stundensatz und einen Rabatt entgegennimmt und berechnet, wie viele vollständige Arbeitstage damit abgedeckt sind.

```cpp
days_in_budget(20'000, 80, 11.0)
// => 35
```

Die zurückgegebene Anzahl an Tagen sollte abgerundet werden (Abrunden auf die nächste ganze Zahl).
