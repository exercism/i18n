# Einführung

Das Modul `Time` dient dazu, menschenlesbare Datums- und Zeitangaben auszugeben.
Auch wenn du Zeiten technisch gesehen mit `Time` bearbeiten kannst, gibt es Pakete aus der Elm-Community, die für diese Aufgabe deutlich besser geeignet sind, zum Beispiel [`justinmimbs/date`][date] oder [`CoderDennis/elm-time-format`][elm-time-format].

## Posix

Zeiten werden durch den opaken Typ `Posix` dargestellt, der die Unix-Epochenzeit umschließt: die Anzahl der Millisekunden, die seit dem 1. Januar 1970 um Mitternacht UTC vergangen sind.
Ein `Posix` ist ein eindeutiger Wert, der sich nicht zwischen Zeitzonen ändert, und daher gut geeignet, um Zeit festzuhalten.
In einer Elm-Anwendung kommen `Posix`-Zeiten typischerweise aus externen Quellen, etwa vom Browser.

Du kannst ein `Posix` mit den folgenden Funktionen in eine Anzahl Millisekunden umwandeln und umgekehrt:

```elm
posixToMillis : Posix -> Int
millisToPosix : Int -> Posix
```

## Zeitzonen

Im Alltag lesen wir Menschen normalerweise keine `Posix`-Werte, sondern bevorzugen die lokale Zeit, die von unserem Standort auf der Erde und den lokalen Sommerzeitregeln abhängt.
In Elm steckt diese Information im opaken Typ `Zone`, der üblicherweise vom Browser kommt.

Es gibt eine spezielle `Zone`, die immer verfügbar ist:

```elm
utc : Zone
```

## Menschenlesbare Zeiten

Mit einem `Posix` und einer `Zone` haben wir genug Information, um die lokale Zeit in beliebigem Detailgrad anzuzeigen.
Hier ist eine Liste der Funktionen, die du dafür verwenden kannst:

```elm
toYear : Zone -> Posix -> Int
toMonth : Zone -> Posix -> Month
toDay : Zone -> Posix -> Int
toWeekday : Zone -> Posix -> Weekday
toHour : Zone -> Posix -> Int
toMinute : Zone -> Posix -> Int
toSecond : Zone -> Posix -> Int
toMillis : Zone -> Posix -> Int
```

Du hast sicher schon zwei weitere eigene Typen aus `Time` entdeckt:

```elm
type Month = Jan | Feb | Mar | Apr | May | Jun | Jul | Aug | Sep | Oct | Nov | Dec
type Weekday = Mon | Tue | Wed | Thu | Fri | Sat | Sun
```

Diese eigenen Typen in menschenlesbare Werte umzuwandeln, bleibt den Nutzern überlassen.
