# Anweisungen

Du schreibst den digitalen Kern eines kleinen Mischpults in einem Tonstudio.

Ton kommt als Strom von Samples an.
Jedes Sample ist eine Zahl, die die Position der Lautsprechermembran zu einem Zeitpunkt beschreibt.
Ein Mischpult verarbeitet einen ganzen Block von Samples auf einmal und wendet auf jedes dieselbe Operation an.

Du hast fünf Aufgaben, die jeweils auf einem im Speicher liegenden Block von Samples arbeiten.
Du erhältst die Operanden über Speicheradressen und schreibst dein Ergebnis über eine Ergebnisadresse.

~~~~exercism/note
Die Berechnungen in dieser Übung sollten mit SIMD-Befehlen durchgeführt werden, nicht mit skalaren Operationen.
~~~~

## 1. Zwei Spuren mischen

Das Studio nimmt Instrumente manchmal auf verschiedenen Spuren auf.
Um sie über dieselben Lautsprecher abzuspielen, summierst du die beiden Spuren zu einer.

Implementiere die Funktion `mix_tracks`, die zwei Spuren Sample für Sample addiert.
Jede Spur ist ein Block aus 8 vorzeichenbehafteten 16-Bit-Samples.
Eine Summe, die den vorzeichenbehafteten 16-Bit-Bereich überläuft, muss begrenzt werden statt umzuschlagen.

Diese Funktion nimmt folgende Argumente in dieser Reihenfolge entgegen:

- `result`: 16-Byte-ausgerichtete Speicheradresse für einen Puffer, in den die 8 gemischten Samples geschrieben werden.
- `track_a`: 16-Byte-ausgerichtete Speicheradresse der ersten Spur mit 8 vorzeichenbehafteten 16-Bit-Samples.
- `track_b`: 16-Byte-ausgerichtete Speicheradresse der zweiten Spur mit 8 vorzeichenbehafteten 16-Bit-Samples.

```c
track_a = {10000, 30000, 20000, -30000, -20000, -100,  100, 0}
track_b = { 5000,  5000, 20000,  -5000, -20000,  100, -100, 0}
result  = {15000, 32767, 32767, -32768, -32768,    0,    0, 0}
```

Diese Funktion hat keinen Rückgabewert.

## 2. Übersprechen entfernen

Wenn zwei Mikrofone gleichzeitig aufnehmen, fängt jedes eine schwache Kopie der Quelle des anderen auf.
Diese unerwünschte Kopie heißt _Übersprechen_.
Sobald dieses Übersprechen gemessen wurde, muss es wieder abgezogen werden, um die Spur zu bereinigen.

Implementiere die Funktion `remove_bleed`, die den Übersprechblock Sample für Sample vom Spurblock subtrahiert.
Jeder Block besteht aus 8 vorzeichenbehafteten 16-Bit-Samples, und die Subtraktion muss sättigen.

Diese Funktion nimmt folgende Argumente in dieser Reihenfolge entgegen:

- `result`: Speicheradresse, an die die 8 bereinigten Samples geschrieben werden (Ausrichtung nicht garantiert).
- `track`: 16-Byte-ausgerichtete Speicheradresse der aufgenommenen Spur, 8 vorzeichenbehaftete 16-Bit-Samples.
- `bleed`: Speicheradresse des zu entfernenden Übersprechens, 8 vorzeichenbehaftete 16-Bit-Samples (Ausrichtung nicht garantiert).

```c
track  = {10000, -30000, 5000, 32767, 0,  200, -200, 15000}
bleed  = { 2000,   5000, 5000,    -5, 0,  300,  300,  5000}
result = { 8000, -32768,    0, 32767, 0, -100, -500, 10000}
```

Diese Funktion hat keinen Rückgabewert.

## 3. Pegel kombinieren

Über jedem Kanal sitzt eine Pegelanzeige, ein kleiner Balken, dessen Helligkeit zeigt, wie laut dieser Kanal ist.
Die Frontplatte hat eine Hauptpegelanzeige, die so hell leuchten soll wie die beiden Kanäle zusammen.
Du addierst die beiden Pegelblöcke, um die Hauptpegelanzeige anzusteuern.

Beachte, dass eine helle Pegelanzeige auf voller Helligkeit bleibt, statt wieder dunkel zu werden, daher ist die Summe sättigend.

Implementiere die Funktion `combine_meters`, die zwei Pegelblöcke Sample für Sample addiert.
Diese Funktion nimmt folgende Argumente in dieser Reihenfolge entgegen:

- `result`: 16-Byte-ausgerichtete Speicheradresse, an die die 16 kombinierten Werte geschrieben werden.
- `meter_a`: 16-Byte-ausgerichtete Speicheradresse des Pegelblocks des ersten Kanals mit 16 gepackten vorzeichenlosen 8-Bit-Werten.
- `meter_b`: 16-Byte-ausgerichtete Speicheradresse des Pegelblocks des zweiten Kanals mit 16 gepackten vorzeichenlosen 8-Bit-Werten.

Jeder Block besteht aus 16 vorzeichenlosen 8-Bit-Werten.
Sie sollten addiert werden, wobei auf den vorzeichenlosen Bereich gesättigt wird.

```c
meter_a = {200, 100,  50, 255, 0, 128, 10, 240, 1, 2, 3, 4, 5, 6, 7, 8}
meter_b = {100, 100, 200,   1, 0, 128, 10,  20, 1, 2, 3, 4, 5, 6, 7, 8}
result  = {255, 200, 250, 255, 0, 255, 20, 255, 2, 4, 6, 8, 10, 12, 14, 16}
```

Diese Funktion hat keinen Rückgabewert.

## 4. Eine Ausblendung anwenden

Der Song soll nicht abrupt enden, sondern am Ende ausblenden.
Du hast einen Block von _Verstärkungskoeffizienten_, einen pro Sample, die von leiser zu noch leiser abnehmen.

Jeder Koeffizient ist ein Bruch, der über `65536` ausgedrückt wird.
Wenn ein Sample zum Beispiel den Wert `16384` hat, drückt es tatsächlich `16384 / 65536` aus, also `1 / 4`.
Der größte nutzbare Wert, `32767`, liegt knapp unter der Hälfte.

Da `65536` gleich `2^16` ist, ergibt die Multiplikation eines Samples mit seinem Koeffizienten und das Behalten der _oberen Hälfte_ des Produkts `sample * gain / 65536`.

Implementiere die Funktion `apply_fade`, die jedes Sample mit seinem Koeffizienten skaliert.
Diese Funktion nimmt folgende Argumente in dieser Reihenfolge entgegen:

- `result`: 16-Byte-ausgerichtete Speicheradresse, an die alle skalierten Samples geschrieben werden.
- `track`: 16-Byte-ausgerichtete Speicheradresse der Spur mit `n` vorzeichenbehafteten 16-Bit-Samples.
- `gains`: 16-Byte-ausgerichtete Speicheradresse der Verstärkungskoeffizienten mit `n` vorzeichenbehafteten 16-Bit-Werten, jeweils im Bereich `0` bis `32767`.
- `n`: die Anzahl der Samples, die immer ungleich null und ein Vielfaches von `8` ist, als vorzeichenlose 64-Bit-Ganzzahl.

Beachte, dass die Spur ein Array ist, das `n` vorzeichenbehaftete 16-Bit-Samples enthält, wobei `n` nie null und immer ein Vielfaches von `8` ist.
Für jedes Sample ist das skalierte Ergebnis die _hohen_ 16 Bits des vorzeichenbehafteten Produkts: `sample * gain`.

```c
track  = {20000, 20000, 20000, 20000, -20000, -20000, -20000, -20000}
gains  = {32767, 24576, 16384,  8192,  32767,  24576,  16384,   8192}
result = { 9999,  7500,  5000,  2500, -10000,  -7500,  -5000,  -2500}
```

~~~~exercism/note
Die obere Hälfte zu behalten rundet in Richtung negative Unendlichkeit.
Deshalb skaliert `20000 * 32767` zu `9999`, während `-20000 * 32767` zu `-10000` statt zu `-9999` skaliert.
~~~~

Diese Funktion hat keinen Rückgabewert.

## 5. Eine Spur abschwächen

Der Schlagzeuger wurde viel zu laut aufgenommen.
Um die ganze Spur herunterzuziehen, teilst du jedes Sample durch eine Konstante.

Implementiere die Funktion `attenuate_track`.
Diese Funktion nimmt folgende Argumente in dieser Reihenfolge entgegen:

- `result`: 16-Byte-ausgerichtete Speicheradresse, an die die Ergebnisse als vorzeichenbehaftete 32-Bit-Ganzzahlen geschrieben werden.
- `samples`: 16-Byte-ausgerichtete Speicheradresse der Samples, `n` vorzeichenbehaftete 16-Bit-Werte.
- `divisor`: 16-Byte-ausgerichtete Speicheradresse von 4 identischen Kopien des Divisors als 32-Bit-Ganzzahlen.
- `n` ist die Anzahl der Samples, die immer ungleich null und ein Vielfaches von `4` ist, als vorzeichenlose 64-Bit-Ganzzahl.

Beachte, dass `samples` ein Array ist, das `n` vorzeichenbehaftete 16-Bit-Samples enthält, wobei `n` nie null und immer ein Vielfaches von `4` ist.

Der Divisor wird als `4` Kopien derselben 32-Bit-Ganzzahl bereitgestellt, bereits repliziert, damit er alle vier Lanes auf einmal füllen kann.

Ganzzahl-SIMD hat keine gepackte Division, daher wird die Arbeit in gepackten Gleitkommazahlen erledigt und dann zurück in gepackte 32-Bit-Ganzzahlen umgewandelt, um in `result` gespeichert zu werden.
Wandle zurück, indem du gegen Null abschneidest, sodass ein Quotient von `2.3` zu `2` wird und `-2.3` zu `-2`.

```c
samples = {300, 150, 90, -120, 100, 50, -50, 7}
divisor = {3, 3, 3, 3}
result  = {100,  50, 30,  -40,  33, 16, -16, 2}
```

Diese Funktion hat keinen Rückgabewert.
