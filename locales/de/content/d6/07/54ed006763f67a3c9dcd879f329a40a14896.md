# Bools

Crystal hat einen Typ namens [`Bool`][bools].
Er repräsentiert die Werte `true` und `false`.

## Logische Operatoren

Crystal hat drei logische Operatoren (`!`, `||`, `&&`), die Bools kombinieren und Ausdrücke bilden, die unterschiedliche Werte erzeugen.

### Und(`&&`)

Der [_und_-Operator][and] in Crystal wird durch `&&` dargestellt und gibt `true` zurück, wenn beide Werte `true` sind; andernfalls gibt er `false` zurück.
Beim _und_-Operator steht ein Bool rechts vom `&&` und ein weiteres links davon.

```crystal
true && true
# => true

true && false
# => false
```

### Oder(`||`)

Der [_oder_-Operator][or] in Crystal wird durch `||` dargestellt und gibt `true` zurück, wenn **mindestens einer** der angegebenen Werte `true` ist.
Wenn beide Werte `false` sind, gibt er `false` zurück.
Beim _oder_-Operator steht ein Bool rechts vom `||` und ein weiteres links davon.

```crystal
true || true
# => true

true || false
# => true

false || false
# => false
```

### Nicht(`!`)

Der _nicht_-Operator in Crystal wird durch `!` dargestellt und gibt `true` zurück, wenn der angegebene Bool `false` ist, und `false`, wenn `true` übergeben wird.
Beim _nicht_-Operator steht ein Bool nach dem Operator (`!`).

```crystal
!true
# => false

!false
# => true
```

## Klammern verwenden(`()`)

Wenn du mit booleschen Werten arbeitest, kannst du Klammern verwenden, um festzulegen, welche Bools zuerst ausgewertet werden.
Das Ergebnis kann sich je nach Verwendung der Klammern unterscheiden.
In Crystal wird zuerst ausgewertet, was in Klammern steht.

```crystal
true && false && false || true
# => true

true && false && (false || true)
# => false
```

Da zuerst ausgewertet wird, was in Klammern steht, wirkt der _nicht_-Operator im folgenden Beispiel auf den Ausdruck innerhalb der Klammern.

```crystal
!true && false
# => false

!(true && false)
# => true
```

~~~~exercism/note
Verwende Klammern nur, wenn sie das Ergebnis beeinflussen; ansonsten lässt du sie weg.
~~~~
