# Einführung

Eine *Quotation*, also Code in eckigen Klammern (`[ ]`), ist in Factor selbst ein Wert, genau wie eine Zahl oder ein String. Du kannst eine in einer Variablen speichern, in ein Array legen, an ein anderes Wort übergeben und später *aufrufen*.

## `call`

`call` (im [`kernel`][kernel]) führt eine Quotation aus:

```factor
3 4 [ + ] call .
! => 7
```

Wenn du `call` für eine Quotation in einem Kontext verwendest, in dem Factor ihren Stack-Effekt nicht ableiten kann, musst du den Effekt ausdrücklich angeben:

```
call( stack-effect ) ! e.g. call( a b -- c )
```

```factor
: apply-binary ( a b op -- c )
    call( a b -- c ) ;

5 3 [ - ] apply-binary .
! => 2
```

Das kompiliert eine Laufzeitprüfung, die sicherstellt, dass die Quotation tatsächlich den angegebenen Effekt hat.

## Quotations in Sequenzen

Weil Quotations Werte sind, kann ein Array eine Mischung aus Zahlen und Quotations enthalten:

```factor
{ 3 4 [ + ] }
```

Damit ist „ein Programm" eine ganz normale Sequenz, und `each` wird zu einer natürlichen Art, eines auszuführen:

```
each ( seq quot -- )
```

```factor
{ [ 1 + ] [ 2 * ] } 5 swap [ call( x -- y ) ] each .
! 5 -> 6 -> 12
```

## Das Ende einer Sequenz abschneiden

`head*` gibt alles außer den letzten `n` Elementen zurück; `last2` gibt die letzten beiden zurück:

```
head* ( seq n -- headseq )
last2 ( seq -- penultimate last )
```

```factor
{ 1 2 3 4 5 } 2 head* .    ! => { 1 2 3 }
{ 1 2 3 4 5 } last2 .s
! => 4
! => 5
```

Zusammen mit `suffix` ist das alles, was du brauchst, um eine Stack-Operation zu schreiben, die „die obersten zwei verbraucht und ein Ergebnis auf den Stack legt".
