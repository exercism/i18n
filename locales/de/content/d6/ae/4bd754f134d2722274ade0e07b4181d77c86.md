# Über

Der primitive Typ `char` in Java ist eine 16-Bit-Darstellung eines einzelnen Unicode-Zeichens.

~~~~exercism/note
Der Typ `char` basiert auf der [ursprünglichen Unicode-Spezifikation][unicode-specification], die 16 Bit zur Darstellung von Zeichen verwendete.
Das reicht aus, um die meisten gängigen Buchstaben abzudecken, und deckt Zeichen im Bereich 0x0000 bis 0xFFFF ab.
Seitdem hat die Spezifikation den Bereich der möglichen Zeichen bis auf 0x01FFFF erweitert.

[unicode-specification]: https://www.unicode.org/versions/Unicode1.0.0/
~~~~

Mehrere `char`s können zusammen einen String bilden, wie zum Beispiel `"word"`, oder `char`s können unabhängig voneinander verarbeitet werden.
Ein `char`-Literal wird von einfachen Anführungszeichen umschlossen (z. B. `'A'`).

```java
char lowerA = 'a';
char upperB = 'B';
```

## Die `char`s eines `String`s auslesen

Die Methode `String.toCharArray` gibt die `char`s eines String als Array zurück.
Wie in [Arrays][concept-arrays] erwähnt, kannst du eine `for`-Schleife verwenden, um über das Array zu iterieren.

```java
String text = "Hello";
char[] asArray = text.toCharArray();

for (char ch: asArray) {
    System.out.println(ch);
}

// Outputs:
// H
// e
// l
// l
// o
```

## Die Klasse [Character][docs-character]

Es gibt viele eingebaute Bibliotheksmethoden, um `char`s zu untersuchen und zu manipulieren.
Du findest sie als statische Methoden der Klasse [`java.lang.Character`][docs-character].
Hier sind einige Beispiele:

```java
Character.isWhitespace(' ');    // true
Character.isWhitespace('#');    // false

Character.isLetter('a');        // true
Character.isLetter('3');        // false

Character.isDigit('6');         // true
Character.isDigit('?');         // false
```

~~~~exercism/note
Einige Methoden der Klasse Character haben eine Überladung, sodass sie entweder ein `char` oder ein `int` annehmen können.
Zum Beispiel hat `isDigit` eine, die ein [`char`][is-digit-char] annimmt, und eine andere, die ein [`int`][is-digit-int] annimmt.
Wie bereits erwähnt, kann der Typ `char` nur die Zeichen im Bereich von 0x0000 bis 0xFFFF darstellen.
Das `int` hingegen kann alle Zeichen darstellen, daher die `int`-Überladungen.

[is-digit-char]: https://docs.oracle.com/en/java/javase/21/docs/api/java.base/java/lang/Character.html#isDigit(char)
[is-digit-int]: https://docs.oracle.com/en/java/javase/21/docs/api/java.base/java/lang/Character.html#isDigit(int)
~~~~

## Ein `char` zu einem `String` hinzufügen

Mit dem Operator `+` kannst du ein `char` zu einem `String` hinzufügen.

```java
'a' + " banana"     // => "a banana"
"banana " + 'a'     // => "banana a"
```

~~~~exercism/caution
Pass auf, dass du `+` _nicht_ verwendest, um zwei `char`s zu einem `String` zusammenzufügen!
Wenn du zwei `char`s auf diese Weise addierst, erhältst du ein `int`, _kein_ `String`!
Zum Beispiel:

```java
'b' + 'c';
// => 197 (not the String "bc")
```

Das liegt daran, dass Java das `char` zu einem `int` hochstuft (siehe [4.2 Primitive Typen und Werte ][jls-primitives] der [Java Language Specification][jls-main]).

[jls-main]: https://docs.oracle.com/javase/specs/jls/se21/html/
[jls-primitives]: https://docs.oracle.com/javase/specs/jls/se21/html/jls-4.html#jls-4.2
~~~~

Wenn jedoch viele Zeichen hinzugefügt werden sollen, kann es effizienter sein, stattdessen einen [`StringBuilder`][docs-stringBuilder] zu verwenden:

```java
StringBuilder builder = new StringBuilder();
builder.append('a');
builder.append('b');
builder.append('c');

String builtString = builder.toString();
// => abc
```
