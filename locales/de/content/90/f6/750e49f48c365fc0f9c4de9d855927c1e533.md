# Anleitung

Implementiere einen Evaluator für eine sehr einfache Teilmenge von Forth.

[Forth][forth] ist eine stapelbasierte Programmiersprache.
Implementiere einen sehr einfachen Evaluator für eine kleine Teilmenge von Forth.

Dein Evaluator muss die folgenden Wörter unterstützen:

- `+`, `-`, `*`, `/` (Ganzzahl-Arithmetik)
- `DUP`, `DROP`, `SWAP`, `OVER` (Stapelmanipulation)

Du kannst ein Tupel als Stapel verwenden, um fift- und asm-bezogene Stack-Opcodes zu vermeiden.

Um es einfach zu halten, ist der einzige Datentyp, den du unterstützen musst, vorzeichenbehaftete Ganzzahlen mit einer Größe von mindestens 16 Bit.

Du solltest die folgenden Regeln für die Syntax verwenden: Eine Zahl ist eine Folge von einer oder mehreren (ASCII-)Ziffern, ein Wort ist eine Folge von einem oder mehreren Buchstaben, Ziffern, Symbolen oder Satzzeichen, die keine Zahl ist.
(Forth verwendet wahrscheinlich etwas andere Regeln, aber das ist nah genug.)
