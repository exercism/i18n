# Überblick

Ein [Record][records] ist eine Sammlung von Feldern (die unterschiedliche Typen haben können), die zusammengehören. Um [einen Record zu definieren][define], wird das Schlüsselwort `type` verwendet. Die Felder eines Records werden zwischen den Zeichen `{` und `}` definiert, und jedes Feld hat einen Namen _und_ einen Typ.

```fsharp
type Address =
    { Street: string
      HouseNumber: int }
```

Um [einen Record zu erstellen][create], gibst du die Namen der Felder an und weist ihnen zwischen den Zeichen `{` und `}` einen Wert zu. Allen Feldern eines Records muss beim Erstellen ein Wert zugewiesen werden. Die Felder können in beliebiger Reihenfolge angegeben werden, sie müssen nicht mit der Reihenfolge der Definition des Record-Typs übereinstimmen. Auf die Feldwerte einer Record-Instanz greifst du mit der Punktnotation zu.

```fsharp
let oldAddress: Address =
    { Street = "Main Street"
      HouseNumber = 17 }

oldAddress.Street      // => "Main Street"
oldAddress.HouseNumber // 17
```

Wenn du einen Record definierst oder erstellst, muss jedes Feld entweder in einer eigenen Zeile stehen oder, wenn alles in einer Zeile steht, durch Semikolons (`;`) getrennt sein:

```fsharp
type Address = { Street: string; HouseNumber: int }

let oldAddress: Address = { Street = "Main Street"; HouseNumber = 17 }
```

Wenn die Feldnamen eines Records eindeutig sind, sind Typannotationen optional, da der Compiler den Typ automatisch ableiten kann. Wenn die Kombination der Feldnamen _nicht_ eindeutig ist, kannst du dem Compiler bei der Auswahl des richtigen Records helfen, indem du entweder einen expliziten Typ für die Record-Bindung angibst oder ein oder mehrere Felder mit dem Record-Typ präfixierst:

```fsharp
type Boat = { Weight: int; Length: int }
type Car = { Weight: int; Length: int }

// Let compiler infer type. As there are multiple matching record types,
// the last matching type is used (Car)
let typeEqualsLastMatch = { Weight = 5000; Length = 15 }

// Use type annotation on binding to force type to Boat
let typeAnnotation: Boat = { Weight = 5000; Length = 15 }

// Use fully qualified name for field to force type to Boat
let fullyQualifiedField = { Boat.Weight = 5000; Length = 15}
```

Records sind unveränderlich: Sobald ein Record konstruiert wurde, können sich seine Feldwerte nie mehr ändern. Wenn du die Werte eines Records ändern möchtest, kannst du mit dem Schlüsselwort `with` [eine Kopie eines bestehenden Records erstellen, aber mit neuen Werten für ein oder mehrere Felder][create].

```fsharp
// Copy the old address but change the house number
let newAddress = { oldAddress with HouseNumber = 86 }
newAddress.Street      // => "Main Street"
newAddress.HouseNumber // => 86
```

Records haben [_strukturelle Gleichheit_][equality], das heißt, zwei Instanzen desselben Records mit identischen Werten sind gleichwertig:

```fsharp
let address1 = { Street = "Main Street"; HouseNumber = 17 }
let address2 = { Street = "Main Street"; HouseNumber = 17 }
let address3 = { Street = "Broadway"; HouseNumber = 17 }

address1 = address2 // => true
address1 = address3 // => false
```

Neben dem Zugriff auf die Felder eines Records mit der Punktnotation lassen sich Records auch in Bindungen und im Pattern Matching mit dem [Record-Muster][record-patterns] _dekonstruieren_:

```fsharp
let myAddress = { Street = "Broadway"; HouseNumber = 123 }
let { Street = myStreet; HouseNumber = myHouseNumber } = myAddress

match myAddress with
| { HouseNumber = 1 } -> printfn "First house"
| { HouseNumber = houseNumber; Street = street } -> printfn "House number %d on %s" houseNumber street
// => "House number 123 on Broadway
```
