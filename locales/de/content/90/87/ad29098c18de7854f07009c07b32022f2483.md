# Einführung

## Ternäre Operatoren

Der _ternäre Operator_ ist eine leichtgewichtige, kompakte Alternative für einfache _if/else_-Anweisungen. Er wird meistens in (aber nicht nur in) return-Anweisungen verwendet und braucht nur eine einzige Zeile für die Entscheidung: Er gibt den linken Wert zurück, wenn der Ausdruck `true` ist, und den rechten Wert, wenn er `false` ist. Das sieht so aus:

```java
boolean expr = 0 != 200;

// Ternary statement
int value = expr ? 22 : 33;
// => 22
```

Viele einfache _if/else_-Ausdrücke lassen sich mit _ternären Operatoren_ vereinfachen.
