# Einführung

Ein `array` in F# ist eine veränderbare Sammlung von null oder mehr Werten mit fester Länge. Das bedeutet, dass sich die Größe eines Arrays nach seiner Erstellung nicht mehr ändern lässt, seine Werte aber schon. Alle Werte in einem Array müssen denselben Typ haben. Du kannst Arrays so definieren:

```fsharp
let empty = [| |]
let emptyAlternative = Array.empty

let singleValue = [| 5 |]
let singleValueAlternative = Array.singleton 5

let threeValues = [| "a"; "b"; "c" |]
```

Elemente kannst du einem Array über einen Index zuweisen oder aus ihm auslesen. F#-Arrays sind nullbasiert, das heißt, der Index des ersten Elements ist immer null:

```fsharp
let numbers = [| 2; 3; 5 |]

// Update value in array
numbers[2] <- 9

// Read value from array
numbers[2]
// => 9
```

Arrays bearbeitest du entweder mit Funktionen und Operatoren aus dem `Array`-Modul oder manuell per Musterabgleich mit dem _Array_-Muster:

```fsharp
let describe array =
    match array with
    | [| |] -> "Empty"
    | [| 1; 2; three |] -> sprintf "1, 2, %d" three
    | _ -> "Other"

describe [| |]         // => "Empty"
describe [| 1; 2; 4 |] // => "1, 2, 4"
describe [| 5; 7; 9 |] // => "Other"
```

Du kannst beim Musterabgleich auch einen Wert _verwerfen_; wenn dir ein Wert in einem bestimmten Fall _nicht_ wichtig ist (d. h., du wirst ihn nicht _verwenden_), kannst du einen Unterstrich (`'_'`) verwenden, um das anzuzeigen:

```fsharp
let describe array =
    match array with
    | [| |] -> "Empty array"
    | [| x |] -> "Array with one item"
    | [| _; y |] -> "Array with two items (first item ignored)"
    | _ -> "Array with many items (all items ignored)"

describe [| |]          // => "Empty array"
describe [| 1 |]        // => "Array with one item"
describe [| 5; 7 |]     // => "Array with two items (first item ignored)"
describe [| 5; 7; 9 |]  // => "Array with many items (all items ignored)"
```

Der einzelne `'_'` sollte beim Musterabgleich immer _zuletzt_ kommen; jeder Wert, der auf keinen der anderen Fälle _passt_, wird von diesem Fall behandelt.
