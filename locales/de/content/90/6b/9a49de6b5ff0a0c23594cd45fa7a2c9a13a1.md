# Anleitung

Die ESA (Exercism Space Agency) plant mit voller Geschwindigkeit eine neue Mission zum [Phobos][phobos], einem Mond des Mars.
Das Ziel der Mission ist, eine Sonde auf der Oberfläche von Phobos zu landen und Daten über die Oberfläche zurückzusenden.
Die ESA hat dich um Hilfe beim Bau des Navigationscomputers für die Sonde gebeten.
Der Navigationscomputer hat nur wenig Speicher, deshalb müssen wir den Speicherverbrauch so gering wie möglich halten.
Deshalb müssen wir die passenden Datentypen verwenden.

## 1. Navigationskonstanten

Der Navigationscomputer muss die Entfernung zwischen einigen Objekten im Weltraum kennen, um die richtigen Berechnungen durchzuführen; die Entfernung wird in km gemessen.

Definiere die folgenden Konstanten:

- `NEPTUNE_DISTANCE` mit dem Wert `4_400_000_000`, der als `Int64` gespeichert werden soll
- `MARS_DISTANCE` mit dem Wert `227_940_000`, der als `Int32` gespeichert werden soll
- `ATMOSPHERE_DISTANCE` mit dem Wert `10_000`, der als `Int16` gespeichert werden soll

## 2. Korrekte Flächenanalyse

Der Navigationscomputer muss die Fläche einiger Objekte im Weltraum kennen, um die richtigen Berechnungen durchzuführen.
Eine Fläche kann **NICHT** negativ sein.
Die Ingenieure hatten geplant, dass das Programm einen Überlauffehler erzeugt, wenn die Fläche negativ ist.
Allerdings haben die Ingenieure vergessen, die vorzeichenbehaftete Ganzzahl in eine vorzeichenlose Ganzzahl zu ändern.

Deshalb hätten die Ingenieure gerne ein Programm, das eine vorzeichenbehaftete Ganzzahl in eine vorzeichenlose Ganzzahl umwandelt.

Implementiere die Methode `Navigation#correct_area_analysis`, die ein `measurement` als Argument entgegennimmt und die Fläche als vorzeichenlose Ganzzahl mit 32 Bit zurückgibt.

~~~~exercism/note
Die angegebene Fläche passt immer in eine vorzeichenlose Ganzzahl mit 32 Bit.
~~~~

```crystal
measurement = 52554
measurement.class
# => Int32

Navigation.new.correct_area_analysis(measurement)
# => 52554

Navigation.new.correct_area_analysis(measurement).class
# => UInt32
```

## 3. Berechne die Geschwindigkeit

Der Navigationscomputer muss die Geschwindigkeit der Sonde kennen.
Die Geschwindigkeit wird in m/s gemessen.

Um die Geschwindigkeit zu berechnen, müssen wir die zurückgelegte Strecke und die dafür benötigte Zeit kennen.
Dann nimmst du die Strecke und teilst sie durch die Zeit.

Die Geschwindigkeit muss nicht exakt sein und wird nie eine besonders große Zahl sein.
Deshalb können wir ein `Float32` verwenden.

Implementiere die Methode `Navigation#calculate_velocity`, die `distance` und `time` als Argumente entgegennimmt und die Geschwindigkeit als `Float` mit 32 Bit zurückgibt.

```crystal
distance = 52554
time = 2.5

Navigation.new.calculate_velocity(distance, time)
# => 21021.6

Navigation.new.calculate_velocity(distance, time).class
# => Float32
```
