# Einführung

## Module

Bisher haben alle Übungen, die du gesehen hast, Klassen verwendet.
Manchmal brauchen wir den Mehraufwand nicht, ein Objekt mit Zustand zu erzeugen, also verwenden wir stattdessen `module`.

Ein Modul ist einer Klasse sehr ähnlich (tatsächlich ist `Module` in der Objekthierarchie das Elternteil von `Class`). Der Hauptunterschied besteht darin, dass wir statt Instanzmethoden Klassenmethoden verwenden.
Klassenmethoden beginnen mit `self.` und werden direkt auf einem Modul aufgerufen.

Zum Beispiel:

```ruby
module Speaker
  def self.echo(something)
    "#{something} ... #{something}"
  end
end

Speaker.echo("Hello")   #=> "Hello ... Hello"
```

## Schleifen

Es gibt mehrere Möglichkeiten, in Ruby Schleifen zu schreiben. Da wir aber im Allgemeinen eher Enumeration als Schleifen verwenden, ist die wohl am häufigsten gesehene Schleife die `while`-Schleife:

```ruby
counter = 0

while counter < 5
  counter += 1
end
```

Du kannst auch ihr Gegenstück `until` verwenden:

```ruby
counter = 0

until counter == 5
  counter += 1
end
```
