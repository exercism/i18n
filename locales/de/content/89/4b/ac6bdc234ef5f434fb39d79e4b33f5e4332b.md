# Überblick

Eine *disjunkte Menge* (eine Union-Find-Struktur) hält eine Sammlung von Werten, die in überschneidungsfreie Gruppen aufgeteilt ist, und beantwortet schnell eine Frage: Sind diese beiden Werte in derselben Gruppe? Sie ist im Vokabular [`disjoint-sets`][disjoint-sets] zu finden.

`<disjoint-set>` erzeugt eine leere Struktur. Werte, die *Atome*, fügst du mit `add-atom` hinzu, oder gleich mehrere auf einmal mit `add-atoms`; jedes Atom startet in seiner eigenen Gruppe:

```
<disjoint-set> ( -- disjoint-set )
add-atom       ( atom disjoint-set -- )
add-atoms      ( seq disjoint-set -- )
```

```factor
USING: disjoint-sets ;

<disjoint-set>
{ "a" "b" "c" "d" } over add-atoms   ! four singleton groups
```

`equate` vereinigt die Gruppen, die zwei Atome enthalten. Das Vereinigen ist transitiv: Sobald `a` mit `b` und `b` mit `c` gleichgesetzt wurde, teilen alle drei dieselbe Gruppe.

```
equate ( atom1 atom2 disjoint-set -- )
```

Jede Gruppe wird durch ein einziges kanonisches Element identifiziert, ihren *Repräsentanten*. `representative` gibt ihn zurück, und zwei Atome gehören genau dann zur selben Gruppe, wenn ihre Repräsentanten gleich sind. `equiv?` führt diesen Test direkt aus:

```
representative ( atom disjoint-set -- representative )
equiv?         ( atom1 atom2 disjoint-set -- ? )
```

```factor
USING: disjoint-sets ;

<disjoint-set>
{ "a" "b" "c" "d" } over add-atoms
"a" "b" pick equate
"b" "c" pick equate
"a" "c" pick equiv? .          ! => t   (transitively connected)
"a" "d" pick equiv? .          ! => f
"a" over representative
"c" pick representative = .     ! => t   (same representative)
```

Welches Atom als Repräsentant einer Gruppe gewählt wird, ist ein internes Detail: Es kann jedes Element der Gruppe sein und kann sich ändern, während Gruppen verschmelzen. Verlass dich nie darauf, dass ein bestimmtes Atom der Repräsentant ist, sondern nur darauf, dass zwei Atome in derselben Gruppe übereinstimmen.

`disjoint-set-members` gibt jedes Atom zurück, das hinzugefügt wurde.

Die Struktur ist *veränderbar*: `equate` und `add-atom` ändern die disjunkte Menge an Ort und Stelle, statt eine neue zurückzugeben. Die Implementierung nutzt Union by Rank mit Pfadkompression, sodass eine lange Folge von `equate`- und `representative`-Aufrufen effektiv konstante Zeit pro Aufruf kostet.
