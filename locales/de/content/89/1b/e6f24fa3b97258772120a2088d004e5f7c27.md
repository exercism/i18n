# Tests

Da OCaml eine kompilierte Sprache ist, musst du deine Lösung und den Testcode kompilieren, bevor du die Tests ausführen kannst.
Wir nutzen [`dune`](https://dune.build/) zum Bauen.
Jeder Ordner enthält eine dune-Datei, die angibt, wie gebaut wird, und dazu ein Makefile, das die Arbeit an dune weitergibt.

Um die Tests zu kompilieren und auszuführen, gib im Übungsordner einfach Folgendes ein:

```bash
make
```

## Dein erstes OCaml-Modul erstellen

Um ein Modul zu erstellen, das du mit dem Test in der Übung `bob` verwenden kannst, schreibe Folgendes in eine Datei namens `bob.ml`:

```ocaml
open Base 

let response_for input = failwith "TODO"
```
