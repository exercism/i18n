# Einführung

In JavaScript ist ein Array eine listenähnliche Struktur ohne feste Länge, die jeden Typ von Primitiven oder Objekten aufnehmen kann, sogar gemischte Typen.

Um ein Array zu erstellen, schreibst du Elemente zwischen eckige Klammern `[]`.
Um aus einem Array zu lesen, setzt du den Index nach dem Bezeichner in eckige Klammern `[]`.
Die Indizes eines Arrays beginnen bei null.

Zum Beispiel:

```javascript
const numbers = [1, 'two', 3, 'four'];
numbers[2];
// => 3
```

Um die Anzahl der Elemente in einem Array zu ermitteln, verwendest du die Eigenschaft `length`:

```javascript
const numbers = [1, 'two', 3, 'four'];
numbers.length;
// => 4
```

Um ein Element im Array zu ändern, weist du dem Index einen Wert zu:

```javascript
const numbers = [1, 'two', 3, 'four'];
numbers[0] = 'one';
numbers;
// => ['one', 'two', 3, 'four']
```

## Methoden

Einige der [Methoden][array_methods], die auf jedem Array-Objekt verfügbar sind, kannst du verwenden, um Elemente zum Array hinzuzufügen oder daraus zu entfernen.

### push

> Die Methode `push()` fügt ein oder mehrere Elemente am Ende eines Arrays hinzu und gibt die neue Länge des Arrays zurück.[^1]

```javascript
const numbers = [1, 'two', 3, 'four'];
numbers.push(5); // => 5
numbers;
// => [1, 'two', 3, 'four', 5]
```

### pop

> Die Methode `pop()` entfernt das letzte Element aus einem Array und gibt dieses Element zurück.
> Diese Methode ändert die Länge des Arrays.[^2]

```javascript
const numbers = [1, 'two', 3, 'four'];
numbers.pop(); // => four
numbers;
// => [1, 'two', 3]
```

### shift

> Die Methode `shift()` entfernt das erste Element aus einem Array und gibt dieses entfernte Element zurück.
> Diese Methode ändert die Länge des Arrays.[^3]

```javascript
const numbers = [1, 'two', 3, 'four'];
numbers.shift(); // => 1
numbers;
// => ['two', 3, 'four']
```

### unshift

> Die Methode unshift() fügt ein oder mehrere Elemente am Anfang eines Arrays hinzu und gibt die neue Länge des Arrays zurück.[^4]

```javascript
const numbers = [1, 'two', 3, 'four'];
numbers.unshift('one'); // => 5
numbers;
// => ['one', 1, 'two', 3, 'four']
```

### splice

> Die Methode splice() ändert den Inhalt eines Arrays, indem sie vorhandene Elemente entfernt oder ersetzt und/oder neue Elemente an Ort und Stelle hinzufügt. Diese Methode gibt ein Array zurück, das die gelöschten Elemente enthält.[^5]

```javascript
const numbers = [1, 'two', 3, 'four'];
numbers.splice(2, 1, 'one'); // => [3]
numbers;
// => [1, 'two', 'one', 'four']
```
