# Anhang zu den Anweisungen

## Der Tcl-Befehl `apply`

Die Testfälle können verwirrend aussehen.
Du sollst Folgendes implementieren:

```tcl
set myList {alpha beta gamma delta}
listOps::filter $myList {{word} {expr {[string length $word] == 4}}
```

Warum hat dieses letzte Argument so viele geschweifte Klammern?

Zur Erinnerung: Der Befehl `proc` ist so definiert:

```tcl
proc procName argList body
```

Tcl hat einen Befehl `apply`:

```tcl
apply func ?arg1 arg2 ...?
```

Dieses „func“ ist eine Liste mit zwei Elementen, `{argList body}`, die im Wesentlichen ein anonymer Proc (oder „Lambda“) ist.
Der Befehl `apply` ruft diesen anonymen Proc auf und übergibt ihm die Argumente, die er braucht.

Zum Beispiel sind die folgenden Varianten äquivalent:

```tcl
# using proc
proc myReverse {str} {return [string reverse $str]}
puts [myReverse "Hello, World!"]

# using apply
puts [apply {{str} {string reverse $str}} "Hello, World!"]

# or, store the func in a variable
set func {{str} {string reverse $str}}
puts [apply $func "Hello, World!"]
```

Mit `apply` ist es einfacher, Codeblöcke weiterzureichen.

Siehe auch: [`apply`](https://tcl.tk/man/tcl8.6/TclCmd/apply.htm), [`proc`](https://tcl.tk/man/tcl8.6/TclCmd/proc.htm).
