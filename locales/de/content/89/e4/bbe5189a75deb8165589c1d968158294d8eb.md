# Anleitung

Das Land Hyperia hat seine Probleme. Besonders die Inflation gerät außer Kontrolle. Du wurdest eingeflogen, um einen Vertrag bei der Zentralbank anzutreten.

## 1. Nennwerte der Banknoten drucken

Um die Verwaltung intern zu vereinfachen, hat die Zentralbank jeden Nennwert in Teile aufgeteilt: eine _Basis_, die relativ unverändert bleibt, und einen _Multiplikator_ (derselbe für alle Nennwerte), der jährlich, wöchentlich oder sogar täglich geändert werden kann.

Beim Drucken sind die Nennwerte auf den Banknoten das Produkt aus _Basis_ und _Multiplikator_.

Als dieses System eingeführt wurde, hatte die kleinste Banknote bereits einen Nennwert von 10.000.000. Die folgende Tabelle zeigt den Stand (für die ersten 3 Nennwerte), als das System eingeführt wurde. Seitdem ist es viel schlimmer geworden: Nicht nur der Multiplikator ändert sich, sondern auch die Basis.

| Basis   | Multiplikator | Nennwert     |
| ------- | ------------- | ------------ |
| 10.000  | 1.000         | 10.000.000   |
| 50.000  | 1.000         | 50.000.000   |
| 100.000 | 1.000         | 100.000.000  |
| ...     | 1.000         | ...          |

Zusammengefasst bedeutet das: _Nennwert_ = _Basis_ \* _Multiplikator_.

Bitte implementiere die Methode `CentralBank.DisplayDenomination()`, die die Basis und den Multiplikator entgegennimmt und einen String ihres Produkts (Basis \* Multiplikator) zurückgibt. Der zurückgegebene numerische String sollte nicht formatiert sein.

Wenn die Multiplikation einen Überlauf verursacht, sollte der String `"*** Too Big ***"` zurückgegeben werden.

```csharp
CentralBank.DisplayDenomination(10000L, 1000L);
// => "10000000"
CentralBank.DisplayDenomination(long.MaxValue / 2, 10000L);
// => "*** Too Big ***"
```

## 2. BIP für Hyperia anzeigen

Die Zentralbank verwendet intern denselben Multiplikator-Ansatz, um das BIP zu erfassen. Statistiken werden in einem Basis-Nennwert erfasst und dann mit dem Multiplikator hochskaliert.

Bitte implementiere die Methode `CentralBank.DisplayGDP()`, die das Basis-BIP und den aktuellen Multiplikator entgegennimmt und das BIP als String zurückgibt.

Wenn das BIP nicht berechnet werden kann, wird `"*** Too Big ***"` zurückgegeben.

```csharp
CentralBank.DisplayGDP(555f, 10000f);
// => "5550000"
CentralBank.DisplayGDP(float.MaxValue / 2, 10000f);
// => "*** Too Big ***"
```

## 3. Das Gehalt des Chefvolkswirts anzeigen

Dein Chef bei der Bank möchte sicherstellen, dass es zum Zeitpunkt der Lohnauszahlung keine Probleme gibt.

Implementiere die Methode `CentralBank.DisplayChiefEconomistSalary()`, die ein in Basiseinheiten ausgedrücktes Gehalt (wie oben) und einen Multiplikator entgegennimmt und einen String mit dem Produkt zurückgibt.

Wenn das Gehalt nicht berechnet werden kann, wird `"*** Much Too Big ***"` zurückgegeben.

```csharp
CentralBank.DisplayChiefEconomistSalary(555000m, 10000m);
// => "5550000000"
CentralBank.DisplayChiefEconomistSalary(555000m, decimal.MaxValue / 2L);
// => "*** Much Too Big ***"
```
