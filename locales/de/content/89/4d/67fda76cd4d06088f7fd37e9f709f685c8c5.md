# Hinweise

## Allgemein

- Linsen werden in Roc nicht oft verwendet, weil die Syntax zum Aktualisieren von Records die meisten Anwendungsfälle gut abdeckt.
  Betrachte zum Beispiel diesen verschachtelten Record:

  ```roc
  bob = { hair: { color: Brown, length: Long }, mouth: Smiling, height: 6.0 }
  ```

  Jetzt verpassen wir Bob einen Haarschnitt:

  ```roc
  new_bob = { ..bob, hair: { ..bob.hair, length: Short } }
  ```

  Ganz ohne Linsen!

- Allerdings sind Linsen in Roc zwar selten, in anderen Sprachen wie Haskell und Scala aber üblich. Vielleicht interessiert dich deshalb, wie man sie in Roc umsetzen könnte.
  Außerdem ist das eine gute Gelegenheit, einige fortgeschrittene Roc-Features zu üben, etwa parametrisierte Typen und Records, die Funktionen enthalten.
  Hier ist eine Möglichkeit, eine Linse in Roc darzustellen:

  ```roc
  Lens(whole, part) := {
      get : whole -> part,
      set : whole, part -> whole,
  }
  ```

  Das ist ein parametrisierter Typ: `whole` und `part` können beliebige Typen sein.
  `whole` ist typischerweise ein Record, `part` kann ein beliebiger Feldtyp sein.
  Das Feld `get` enthält eine Funktion, die einen bestimmten `part` des übergebenen `whole` zurückgibt, während das Feld `set` eine Funktion enthält, die eine Kopie des übergebenen `whole` zurückgibt, nur dass darin ein bestimmter `part` durch den übergebenen `part` ersetzt ist.

  Hier ist zum Beispiel eine Linse, mit der du die Haare einer Person auslesen oder setzen kannst:

  ```roc
  hair_lens = {
      get: |person| person.hair,
      set: |person, hair| { ..person, hair },
  }
  ```

  Mit dieser Linse können wir auf Bobs Haare fokussieren, so wie hier:

  ```roc
  bob_hair = bob |> hair_lens.get
  ```

  Und wir können seine Haare so ändern:

  ```roc
  new_hair = { ..bob.hair, length: Short }
  new_bob = bob |> (hair_lens.set)(new_hair)
  ```

- Hinweis: Die runden Klammern um `hair_lens.set` sind nötig. Ohne sie würde Roc im Typ von `hair_lens` nach einer Funktion namens `set` suchen.

- Besonders nützlich werden Linsen, wenn du anfängst, sie zu kombinieren, denn so kommst du an tief verschachtelte Teile und kannst sie setzen.
  Das geht, indem du eine Funktion wie diese implementierst:

  ```roc
  compose : Lens(outer, inner), Lens(inner, part) -> Lens(outer, part)
  ```

  Sobald diese Funktion umgesetzt ist, kannst du damit eine Linse für die Haarlänge bauen:

  ```roc
  length_lens = {
      get: |hair| hair.length,
      set: |hair, length| { ..hair, length },
  }
  hair_length_lens = compose(hair_lens, length_lens)

  ```

  Jetzt kannst du Bob noch einen Haarschnitt verpassen:

  ```roc
  set_hair_length = hair_length_lens.set
  new_bob = bob |> set_hair_length(Short)
  ```

- Vielleicht möchtest du auch eine Funktion implementieren, mit der du eine beliebige Transformation auf einen verschachtelten Teil anwenden kannst:

  ```roc
  over : Lens(whole, part), whole, (part -> part) -> whole
  ```

  Sobald sie umgesetzt ist, kannst du `over` so verwenden:

  ```roc
  cut_hair = |current_length| match current_length {
      Long => Short
      Short => Bald
      Bald => Bald
  }
  new_bob = hair_length_lens |> over(bob, cut_hair)
  ```

- Wir empfehlen dir, die Tests zuerst mit der Syntax zum Aktualisieren von Records zu bestehen und es dann mit Linsen zu versuchen.
