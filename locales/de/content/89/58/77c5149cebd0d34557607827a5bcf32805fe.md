# Einführung

Angenommen, wir wollen ein Array von Zahlen summieren.
Es gibt viele Wege, dieses Ziel zu erreichen.

- In vielen Sprachen wird dieses Problem als Schleife mit einer Akkumulator-Variablen ausgedrückt.
- Dieses Problem lässt sich als rekursive Funktion schreiben.
  In Pseudocode könnte das so aussehen.

  ```none
  function Add(X, Sum=0):
    if X is empty then
      return Sum
    else
      return Add(rest(X), Sum + first(X))
    end
  end
  ```

  Diese Methode, das Problem in kleinere Teile zu zerlegen, kann man auch als „Reduzieren hin zum Basisfall“ beschreiben.

**Reduce** ist eine Möglichkeit, alle Elemente einer Datenstruktur zu einem einzigen Wert zusammenzufassen.
Der Vorgang durchläuft die Datenstruktur und wendet auf jedes Element eine Funktion an, um das angesammelte Ergebnis zu aktualisieren.

In `jq` ist dieser Vorgang im [`reduce`-Filter][jq-man-reduce] umgesetzt.
In anderen Sprachen heißt es vielleicht „fold“, „fold-left“, „inject“ oder „aggregate“.

Der `reduce`-Ausdruck in `jq` sieht so aus.

```jq
reduce STREAM_EXPRESSION as $var (INITIAL_VALUE; UPDATE_EXPRESSION)
```

- `STREAM_EXPRESSION` ist ein _Stream_ von Elementen, die nacheinander in der Variablen `$var` gespeichert werden.
  - Zur Erinnerung: Um ein Array zu streamen, verwendest du den [Iterator-Filter `.[]`][jq-man-iterator]: `$myArray | .[]`.
- `INITIAL_VALUE` ist der Startwert des angesammelten Ergebnisses (bekannt als der „Akkumulator“).
- Die `UPDATE_EXPRESSION` kombiniert („faltet“) den aktuellen Wert ($var) in den Akkumulator.
  - Im Kontext dieses Ausdrucks ist `.` der Wert des Akkumulators.
  - Die Ausgabe des Ausdrucks wird im Akkumulator gespeichert und in der nächsten Iteration verwendet.
  - Nach der letzten Iteration ist das angesammelte Ergebnis die Ausgabe von `reduce`.

Schauen wir uns ein Beispiel an: die Zahlen eines Arrays aufsummieren.
Der `add`-Filter macht genau das, aber wir schauen uns an, wie man ihn implementiert.

Wenn wir `[10, 20, 30, 40]` als Eingabe verwenden und null als Ausgangszustand nehmen, sieht jeder Schritt so aus.

| \#  | Zustand | Element | Reducer | Ergebnis |
| :-: | :---: | :-----: | :-----: | :----: |
|  1  |   0   |   10    | 0 + 10  |   10   |
|  2  |  10   |   20    | 10 + 20 |   30   |
|  3  |  30   |   30    | 30 + 30 |   60   |
|  4  |  60   |   40    | 60 + 40 |  100   |

In der `jq`-Syntax sieht dieser Code so aus.

```jq
0 + 10 | . + 20 | . + 30 | . + 40
```

Wir können das mit dem `reduce`-Filter ausdrücken.

```jq
[10, 20, 30, 40] | reduce .[] as $n (0; . + $n)     # => 100
```

## Ein paar Dinge, die du beachten solltest

- Im reduzierenden Ausdruck ist `.` der Akkumulator.
  Wenn die Eingabe ein Objekt ist, auf das du innerhalb der reduzierenden Funktion verweisen musst, musst du es in einer Variablen speichern.

  ```jq
  {"apple": 10, "banana": 16, "carrot": 4}
  | . as $obj
  | reduce (keys | .[]) as $key (0; . + $obj[$key])     # => 30
  ```

- Der Akkumulator kann von jedem Datentyp sein.
  Zum Beispiel möchtest du vielleicht ein Array umkehren.

  ```jq
  ["A", "B", "C", "D"]
  | reduce .[] as $elem ([]; [$elem] + .)       # => ["D", "C", "B", "A"]
  ```
