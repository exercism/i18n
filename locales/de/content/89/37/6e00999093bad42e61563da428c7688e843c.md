# Überblick

[Closures][closures] sind in Swift in sich geschlossene Blöcke aus Code, denen du Parameter übergeben kannst, um ihre Berechnung auszulösen und Werte zurückzugeben.
Closures erfassen außerdem Werte aus ihrer Umgebung und verwenden sie in ihren Berechnungen.
Da sie in sich geschlossen sind, kannst du sie in einem Programm wie andere Werte weiterreichen oder Konstanten und Variablen zuweisen.

Closures klingen vielleicht sehr nach Swift-Funktionen; das tun sie auch, und das aus gutem Grund.
Funktionen in Swift sind Spezialfälle von Closures, die einen Namen haben müssen und mit einer etwas anderen Syntax definiert werden.

Funktionen in Swift sind zwar technisch gesehen Closures, aber wenn in Swift von „Closures“ die Rede ist, sind damit die [Closure-Ausdrücke][closure-expressions] gemeint.
Closure-Ausdrücke bestehen aus einer Parameterliste, gefolgt von einem Rückgabetyp und dem Schlüsselwort `in`, gefolgt vom Rumpf des Closure, und das Ganze steht in einem Paar geschweifter Klammern:

```swift
{ (a: Double, b: Double) -> Double in
  return (a + b) / 2.0
}
```

Das definiert einen Closure-Ausdruck vom Typ `(Double, Double) -> Double`, und du kannst ihn ähnlich ausführen wie eine Funktion dieses Typs, indem du ihn auf Parameter des passenden Typs anwendest:

```swift
{ (a: Double, b: Double) -> Double in
  return (a + b) / 2.0
}(10.0, 15.0)
// returns 12.5
```

Es ist nicht sehr praktisch, jedes Mal den vollständigen Closure-Ausdruck auszuschreiben, wenn du ihn ausführen willst. Deshalb kannst du Closures wie jeden anderen Wert in Swift einem Namen zuweisen.
Danach rufst du sie auf, indem du den Namen auf die Parameter anwendest:

```swift
let mean = { (a: Double, b: Double) -> Double in
  (a + b) / 2.0
}

mean(13.0, 100.0)
// returns 56.5
```

Wie oben zu sehen ist, können Closures wie reguläre Funktionen das Schlüsselwort `return` weglassen, wenn der Rumpf des Closure ein einzelner Ausdruck ist.

Meistens werden Closures mit Funktionen höherer Ordnung verwendet, entweder als Parameter übergeben oder als Ergebnis zurückgegeben:

```swift
[11, 75, 3, 99, 53].contains(where: { (x: Int) -> Bool in x > 100 })
// returns false

["apple", "ball", "carrot"].sorted(by: { (s1: String, s2: String) -> Bool in s1.count < s2.count })
// returns ["ball", "apple", "carrot"]

func makeAdder(base: Int) -> (Int) -> Int {
  { (x: Int) -> Int in base + x }
}
```
