# Emacs installieren

Da Emacs Lisp (elisp) die Erweiterungssprache von Emacs ist, musst du zuerst
[GNU Emacs](http://www.gnu.org/software/emacs/) installieren.

Am besten nimmst du die neueste Emacs-Version, aber 28.1 oder höher solltest du als
Ziel-Implementierung für die Übungen ansehen.
Wenn du Emacs bereits installiert hast, kannst du die Emacs-Version mit `M-x emacs-version RET` prüfen.

## Unter OS X
Am einfachsten besuchst du [Emacs For Mac OS X](http://emacsformacosx.com/) und lädst die dmg-Datei herunter,
die GNU Emacs als fertig gepackte OS-X-App installiert.

Es gibt auch Alternativen, etwa Aquamacs (nicht empfohlen) oder die Installation über
[Homebrew](https://formulae.brew.sh/formula/emacs), falls dir das lieber ist.

## Unter Linux
Bei manchen Distributionen ist Emacs schon installiert, weil es Teil von GNU ist.

### Ubuntu
Der derzeit empfohlene Weg, das neueste Emacs zu installieren, führt über [snap](https://snapcraft.io/emacs):

```
sudo snap install emacs --classic
```

Wenn du snap nicht verwenden möchtest, kannst du Emacs auch über apt installieren, aber die Version aus den Ubuntu-Repositories ist oft veraltet.
Wenn du eine neuere Emacs-Version über apt installieren möchtest, brauchst du ein [PPA](https://launchpad.net/ubuntu/+ppas?name_filter=emacs) oder musst [aus dem Quellcode bauen](https://www.emacswiki.org/emacs/BuildingEmacs).

Wenn dir die neueste Version egal ist, geht es ganz einfach mit

```
sudo apt-get install emacs
```

### Arch
Arch liefert normalerweise die neueste Emacs-Version aus, also führe einfach

```
sudo pacman -S emacs
```

aus, und schon ist alles eingerichtet.

### Andere Distributionen
Schau bei deiner Distribution nach, welche Version aktuell ist, und nutze deinen
Paketmanager oder baue je nach Bedarf aus dem Quellcode.

### Windows
Um Emacs unter Windows zu installieren, geh zum nächstgelegenen
[FTP-Archiv-Spiegelserver](https://ftpmirror.gnu.org/emacs/windows), hol dir das Installationsprogramm (=emacs-XX.X-installer.exe=) und starte es.
Wenn du Emacs nutzen möchtest, ohne ihn zu installieren, kannst du die Datei nach dem Muster =emacs-XX.x.zip= herunterladen, sie entpacken und `bin\runemacs.exe` starten.

Wenn du [MSYS2](https://www.msys2.org/) verwendest, kannst du die 64-Bit-Version von Emacs installieren mit

```
pacman -S mingw-w64-x86_64-emacs
```

oder die 32-Bit-Version mit

```
pacman -S mingw-w64-i686-emacs
```
