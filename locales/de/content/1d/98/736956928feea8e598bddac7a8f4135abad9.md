# Hinweise

## 1. Standardberechtigungen für einen Kontotyp abrufen

- Definiere das `Permission`-Enum mit Werten für die folgenden Berechtigungstypen: `None`, `Read`, `Write` und `Delete`.
- Wenn du die Enum-Flags verwendest, kannst du die Bitoperationen für das `Permission`-Enum direkt nutzen, [siehe `enum` `Flags`][docs-enum-flags].
- Das Enum-Mitglied `All` kann als Kombination der Enum-Mitglieder `Read`, `Write` und `Delete` definiert werden.
- Definiere das `AccountType`-Enum mit Werten für die folgenden Kontotypen: `Guest`, `User` und `Moderator`.
- Um jeden Kontotyp zu behandeln, könntest du eine `if`-Anweisung verwenden, aber die [`switch`-Anweisung][docs.microsoft.com-switch-keyword] ist eine großartige Alternative.
- Flags zu kombinieren bedeutet, ein bestimmtes Bit mit einem der [Bitoperatoren][docs.microsoft.com-bitwise-and-shift-operators] auf `1` zu setzen.

## 2. Eine Berechtigung erteilen

- Flags zu kombinieren bedeutet, ein bestimmtes Bit mit einem der [Bitoperatoren][docs.microsoft.com-bitwise-and-shift-operators] auf `1` zu setzen.

## 3. Eine Berechtigung entziehen

- Ein Flag zu entfernen bedeutet, ein bestimmtes Bit mit einer Kombination aus zwei [Bitoperatoren][docs.microsoft.com-bitwise-and-shift-operators] auf `0` zu setzen.

## 4. Eine Berechtigung prüfen

- Eine Berechtigung kannst du prüfen, indem du das Ergebnis der Anwendung eines der [Bitoperatoren][docs.microsoft.com-bitwise-and-shift-operators] prüfst.
