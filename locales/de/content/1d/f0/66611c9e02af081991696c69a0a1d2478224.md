# Ergänzung zur Anleitung

## Ausgabe

In dieser Übung implementierst du ein Verb, das das Pascalsche Dreieck bis zu einer bestimmten Anzahl von Zeilen erzeugt. Die Ausgabe deines Verbs kann auf eine von zwei Arten formatiert werden:

  1. Als Array von boxed Lists, wobei jede Liste eine Zeile im Pascalschen Dreieck darstellt.
  1. Als Tabelle, in der die Zahlen rechtsbündig ausgerichtet sind und Nullen die leeren Stellen auf der linken Seite auffüllen.

### Beispielausgabe

Hier sind zwei gültige Ausgaben für `pascal 3`:

  - Als Array von boxed Lists:
```j
  (1 ; 1 1 ; 1 2 1) -: pascal 3          NB. This test will pass
```
  - Als Tabelle mit Auffüllung:
```j
  (3 3$1 0 0 1 1 0 1 2 1) -: pascal 3   NB. This test also passes
```
