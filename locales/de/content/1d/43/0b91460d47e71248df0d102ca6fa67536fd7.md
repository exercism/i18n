# Hinweise

## Allgemein

- Lies im [Handbuch][function-composition-manual] etwas über Funktionskomposition.
- Sieh dir die [für _Strings_ verfügbaren Methoden][string-methods] an.

## 1. Bereinige den Namen

- Es gibt eine [eingebaute Methode][string-replace], mit der du alle Vorkommen eines Teilstrings in einem String ersetzen kannst.
- Es gibt eine [eingebaute Methode][string-strip], mit der du führende und nachfolgende Leerzeichen aus einem String entfernst.

## 2. Hole den ersten Buchstaben des Namens

- Um ein bestimmtes Zeichen aus einem String zu bekommen, kannst du [Indexierung][string-indexing] verwenden.
- Am saubersten schreibst du das mit dem Kompositionsoperator `∘`.

## 3. Formatiere den ersten Buchstaben als Initiale

- Es gibt eine [eingebaute Methode][string-uppercase], mit der du alle Zeichen in einem String in ihre Großbuchstaben-Variante umwandelst.

## 4. Setze die Initialen in das Herz

- Du kannst Unicode-Zeichen in Strings verwenden, indem du `'\u<id>'` schreibst, wobei die id beim Herz-Emoji `2764` ist.
- Das kannst du mit [Verkettung][string-concatenation] oder [Interpolation][string-interpolation] machen.
