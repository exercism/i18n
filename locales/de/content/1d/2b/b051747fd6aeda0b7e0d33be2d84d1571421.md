# Ergänzung der Anweisungen

## Ausgabeformat

Gib den Liedtext als nullterminierten String aus.

## Register

| Register | Verwendung   | Typ      | Beschreibung                            |
| -------- | ------------ | -------- | --------------------------------------- |
| `$a0`    | Eingabe      | Ganzzahl | Anzahl der Flaschen zu Beginn           |
| `$a1`    | Eingabe      | Ganzzahl | Anzahl der Flaschen, die wegfallen      |
| `$a2`    | Ein-/Ausgabe | Adresse  | nullterminierter Ausgabe-String         |
| `$t0-9`  | temporär     | beliebig | zur temporären Speicherung              |
