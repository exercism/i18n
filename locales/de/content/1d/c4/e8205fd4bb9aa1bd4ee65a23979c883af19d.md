# Über

Das Wichtigste über Zeichenketten in Java: Sie sind unveränderliche Objekte, die Text als Folge von Unicode-Zeichen darstellen (Buchstaben, Ziffern, Satzzeichen usw.).
Mit doppelten Anführungszeichen definierst du eine `String`-Instanz:

```java
String fruit = "Apple";
```

Eine Zeichenkette kannst du mit den Methoden der Klasse [`String`][string-class] bearbeiten.
Da sich der Wert einer Zeichenkette nach seiner Definition nie mehr ändert, geben alle Methoden zur Bearbeitung von Zeichenketten eine neue Zeichenkette zurück.

Eine Zeichenkette wird von doppelten Anführungszeichen (`"`) begrenzt.
Einige Sonderzeichen müssen mit dem Backslash (`\`) maskiert werden.
Zeichen, die in Java maskiert werden müssen:

- `"`
- `\`

```java
String escaped = "c:\\test.txt";
// => c:\test.txt
```

Schließlich gibt es viele Möglichkeiten, Zeichenketten zu verknüpfen.
Die einfachste ist der `+`-Operator:

```java
String name = "Jane";
"Hello " + name + "!";
// => "Hello Jane!"
```

Für jede Zeichenkettenformatierung, die komplexer ist als eine einfache Verkettung, ist die Methode `String.format` vorzuziehen.

```java
String name = "Jane";
String.format("Hello %s!",name);
// => "Hello Jane!"
```

Weitere Möglichkeiten sind:

- die Klasse [`StringBuilder`][string-builder] verwenden
- die Methode [`String.concat`][string-concat] verwenden
