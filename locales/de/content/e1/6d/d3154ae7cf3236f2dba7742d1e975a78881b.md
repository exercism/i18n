# Tests

Wechsle in das Verzeichnis, das die passende Datei `${slug}_test.sql` enthält. `${slug}` ist der Name der Übung, mit Bindestrichen statt Leerzeichen und durchgehend kleingeschrieben (z. B. `hello-world_test.sql` für die Übung `Hello World`).

```bash
sqlite3 -bail < ${slug}_test.sql
```

Zum Debuggen kannst du `SELECT`-Anweisungen verwenden.
Die Ausgabe wird an `user_output.md` weitergeleitet und im Web-Editor angezeigt, wenn die Tests fehlschlagen.

Weitere Informationen findest du in der [sqlite-Track-Dokumentation zum Testen](https://exercism.org/docs/tracks/sqlite/tests).
