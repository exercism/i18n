# Hinweise

## Allgemein

- Ein [Ganzzahlwert][integers] kann als eine oder mehrere aufeinanderfolgende Ziffern definiert werden.
- [String][string]-Literale sind eine Folge von Zeichen, die von doppelten Anführungszeichen umschlossen sind.

## 1. Definiere die erwartete Backzeit in Minuten

- Du musst eine [Funktion][functions] ohne Argumente definieren.
- Du musst eine [Ganzzahl][integers] zurückgeben.

## 2. Berechne die verbleibende Backzeit in Minuten

- Du musst eine [Funktion][functions] mit einem Argument definieren.
- Du musst aus einer Funktion [implizit eine Ganzzahl zurückgeben][return].
- Das Argument der Funktion ist eine [Ganzzahl][integers].
- Du kannst den [mathematischen Operator für Subtraktion][operators] verwenden, um Werte zu subtrahieren.

## 3. Berechne die Vorbereitungszeit in Minuten

- Du musst eine [Funktion][functions] mit einem Argument definieren.
- Du musst aus einer Funktion [implizit eine Ganzzahl zurückgeben][return].
- Das Argument der Funktion ist eine [Ganzzahl][integers].
- Du kannst den [mathematischen Operator für Multiplikation][operators] verwenden, um Werte zu multiplizieren.

## 4. Berechne die gesamte Arbeitszeit in Minuten

- Du musst eine [Funktion][functions] mit zwei Argumenten definieren.
- Du musst aus einer Funktion [implizit eine Ganzzahl zurückgeben][return].
- Das Argument der Funktion ist eine [Ganzzahl][integers].
- Du kannst eine der anderen Funktionen aufrufen, die du zuvor definiert hast.
- Du kannst den [mathematischen Operator für Addition][operators] verwenden, um Werte zu addieren.

## 5. Erstelle eine Benachrichtigung, dass die Lasagne fertig ist

- Du musst eine [Funktion][functions] ohne Argumente definieren.
- Du musst einen [String][string] zurückgeben.
