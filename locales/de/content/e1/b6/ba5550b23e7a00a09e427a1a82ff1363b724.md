# Einführung

## Zahlen

Go enthält grundlegende numerische Typen, die Mengen von Ganzzahl- oder Gleitkommawerten darstellen können.
Es gibt verschiedene Typen, je nachdem, welche Größe von Wert du brauchst und auf welcher Architektur der Computer läuft, auf dem die Anwendung ausgeführt wird (z. B. 32-Bit und 64-Bit).

Für diese Übung hast du es nur mit den folgenden zu tun:

- `int`: z. B. `0`, `255`, `2147483647`.
  Eine vorzeichenbehaftete Ganzzahl, die mindestens 32 Bit groß ist (Wertebereich: -2147483648 bis 2147483647).
  Das hängt aber von der Architektur des Systems ab.
  Die meisten modernen Computer sind 64 Bit, deshalb ist `int` 64 Bit groß (Wertebereich: -9223372036854775808 bis 9223372036854775807).

- `float64`: z. B. `0.0`, `3.14`.
  Enthält die Menge aller 64-Bit-Gleitkommazahlen.

- `uint`: z. B. `0`, `255`.
  Eine vorzeichenlose Ganzzahl, die genauso groß ist wie `int` (Wertebereich: 0 bis 4294967295 bei 32 Bit und 0 bis 18446744073709551615 bei 64 Bit)

Zahlen können durch Typkonvertierung in andere numerische Typen umgewandelt werden.

## Arithmetische Operatoren

Go unterstützt viele der üblichen arithmetischen Operatoren:

| Operator | Beispiel       |
| -------- | -------------- |
| `+`      | `4 + 6 == 10`  |
| `-`      | `15 - 10 == 5` |
| `*`      | `2 * 3 == 6`   |
| `/`      | `13 / 3 == 4`  |
| `%`      | `13 % 3 == 1`  |

Bei der Ganzzahldivision wird der Rest verworfen (z. B. `5 / 2 == 2`).

Go hat für die obigen Operatoren eine Kurzform für die Zuweisung (z. B. ist `a += 5` die Kurzform von `a = a + 5`).
Go unterstützt außerdem die Inkrement- und Dekrement-Anweisungen `++` und `--` (z. B. `a++`).

## Konvertieren zwischen Typen

Das Konvertieren zwischen Typen erfolgt über eine Funktion mit dem Namen des Zieltyps.
Zum Beispiel:

```go
var x int = 42 // x has type int
f := float64(x) // f has type float64 (ie. 42.0)
var y float64 = 11.9 // y has type float64
i := int(y) // i has type int (ie. 11)
```

## Arithmetische Operationen mit verschiedenen Typen

In vielen Sprachen kannst du arithmetische Operationen mit Variablen unterschiedlicher Typen durchführen, in Go führt das jedoch zu einem Fehler.
Zum Beispiel:

```go
var x int = 42

// this line produces an error
value := float32(2.0) * x // invalid operation: mismatched types float32 and int

// you must convert int type to float32 before performing arithmetic operation
value := float32(2.0) * float32(x)
```
