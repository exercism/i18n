# Instructions

In dieser Übung schreibst du Code, um einem Schilderunternehmen zu helfen, individuelle Botschaften für seine Schilder zu erstellen.

## 1. Erstelle ein Anlassschild

Implementiere die Methode `build_sign( )`, die einen String als Parameter `occasion` und einen String mit dem Namen einer Person als Parameter `name` entgegennimmt. Die beiden Parameter werden in ein String-Template eingebettet, um die Botschaft auf dem Schild auszugeben.

```abap
build_sign( occasion = 'Birthday' 
            name     = 'Rob').
" => "Happy Birthday Rob!"
```

## 2. Erstelle ein Geburtstagsschild

Implementiere die Methode `build_birthday_sign( )`, die ein Alter entgegennimmt und anhand des Alters einen Teil der Botschaft auf dem Schild bestimmt. Wenn das Alter 50 oder älter ist, enthält das Schild das Wort _mature_, andernfalls enthält das Schild das Wort _young_.

```abap
build_birthday_sign( 45 ).
" => "Happy Birthday! What a young fellow you are."
```

## 3. Erstelle ein Abschlussschild

Implementiere die Methode `graduation_for( )`, die einen Namen als String-Parameter und ein Jahr als numerischen Parameter entgegennimmt und String-Templates verwendet, um einen Text für ein Schild zu erstellen, der einen Zeilenumbruch nutzt, um die beiden Zeilen der Botschaft zu trennen.

```abap
graduation_for( name = 'Hannah' 
                year = 2022 ).
" => "Congratulations Hannah!\nClass of 2022"
```

## 4. Berechne die Kosten für ein Schild

Implementiere die Funktion `cost_of( sign currency )`, die einen String mit dem Inhalt des Schilds und einen String für die Währung entgegennimmt.
Das Schild hat einen Grundpreis von 20 in der angegebenen Währung. Zusätzlich kostet jeder Buchstabe 2. (Leerzeichen werden bei der Berechnung mitgezählt.)
Der zurückgegebene Text enthält die Kosten für die Erstellung des Schilds, geschrieben mit zwei Nachkommastellen, gefolgt von dem Währungs-String.

```abap
costOf( sign     = 'Happy Birthday Rob!'
        currency = 'euros');
// => "Your sign costs 58.00 euros."
```
