# Einführung

Ein wichtiges Mittel zur Organisation von Code sind Namensräume.
Zwei Funktionen können einen Namenskonflikt haben, den du auflösen kannst, indem du sie in verschiedene Namensräume packst.
Namensräume lassen sich verschachteln, was helfen kann, große Codebasen zu strukturieren.
Auf die Namensräume greifst du mit dem Bereichsauflösungsoperator `::` zu.

Das folgende Beispiel zeigt die Verwendung von zwei verschiedenen `foo`-Funktionen.
Sie werden gemeinsam verwendet, indem du ihnen ihren jeweiligen Namensraum voranstellst.

```cpp
namespace my_ns {
    int foo() {
        return 44;
    }
    namespace my_inner_ns {
        int baz() {
            return 90;
        }
    }
}
namespace my_other_ns {
    int foo() {
        return -2;
    }
}

int myresult{my_ns::foo() + my_other_ns::foo() * my_ns::my_inner_ns::baz()};
```
