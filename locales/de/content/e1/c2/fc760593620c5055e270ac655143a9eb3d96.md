# Hinweise

## Allgemein

- Die Anzahl der Vögel pro Tag wird in einer [Instanzvariablen][instance-variables] namens `birds_per_day` gespeichert.
- Die Anzahl der Vögel pro Tag ist ein Array mit genau 7 Ganzzahlen.

## 1. Prüfe, was die Zählungen letzte Woche waren

- Da diese Methode _nicht_ von der Zählung der aktuellen Woche abhängt, ist sie als [`class`-Methode][class-method] definiert.
- Es gibt [mehrere Möglichkeiten, ein Array zu definieren][array-definition].

## 2. Prüfe, wie viele Vögel gestern zu Besuch waren

- Denk daran, dass die Zählungen nach Tagen vom ältesten zum neuesten geordnet sind, wobei das letzte Element den heutigen Tag darstellt.
- Auf das vorletzte Element kannst du entweder über seinen (festen) Index zugreifen (denk daran, bei null mit dem Zählen zu beginnen) oder seinen Index mithilfe der [Größe des Arrays][array-length] berechnen.

## 3. Berechne die Gesamtzahl der Vögel, die zu Besuch waren

- Du kannst die Summe einer Sammlung mit der Methode [Array#sum][array-sum] berechnen.

## 4. Berechne die Anzahl der geschäftigen Tage

- Ruby bietet außerdem eine Methode zum [Zählen von Elementen in einer Sammlung][array-count]

## 5. Prüfe, ob es einen Tag ohne Vögel gab

- Es gibt einige Methoden, mit denen du prüfen kannst, ob ein Element in einer Sammlung enthalten ist. Zum Beispiel [Enumerable#any?][enumerable-any] und [Enumerable#all?][enumerable-all]
