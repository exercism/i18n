# Ressourcen

## Module

Perl wird mit einer Reihe von Kernmodulen ausgeliefert, die du auf [perldoc](https://perldoc.perl.org/modules) aufgelistet findest. Normalerweise kannst du jedes dieser Module sofort verwenden. (Bei manchen Distributionen musst du Kernmodule möglicherweise separat installieren.)

[Awesome Perl](https://github.com/hachiojipm/awesome-perl) ist eine kuratierte Liste nützlicher Module und verweist außerdem auf eine Auswahl weiterer Empfehlungslisten.

Für Perl gibt es mehrere Modul-Installer, mit denen du eine große Auswahl der auf [CPAN](https://metacpan.org/) verfügbaren Module installieren kannst.

### App::cpm
Ein sehr schneller und unkomplizierter Modul-Installer.
Ein Tutorial findest du auf [CPAN](https://metacpan.org/pod/App::cpm::Tutorial).

Du hast es bereits installiert, wenn du die Anweisungen zu `local::lib` aus der [Installationsdokumentation](https://exercism.org/tracks/perl5/installation) befolgt hast.

Führe einfach `cpm install` aus, um die benötigten Module aus einer `cpanfile` zu installieren, und verwende `--with-recommends` bzw. `--with-suggested`, um empfohlene bzw. vorgeschlagene Module zu installieren.

Führe `cpm install Module::Name` aus, um ein bestimmtes Modul lokal zu installieren, oder führe `cpm install -g Module::Name` aus, um es global zu installieren.

### App::cpanminus
Der bekannteste und am häufigsten verwendete Modul-Installer.
Installationsanweisungen findest du auf [CPAN](https://metacpan.org/pod/App::cpanminus).

Führe `cpanm -L local --installdeps .` aus, um die benötigten Module aus einer `cpanfile` zu installieren.
Führe `cpanm -L local Module::Name` aus, um ein bestimmtes Modul lokal zu installieren, oder führe `cpanm Module::Name` aus, um es global zu installieren.

## Codestil und Linting

Wenn du gute allgemeine Ratschläge zum Programmieren in Perl suchst, ist Damian Conways [Perl Best Practices][PBP] eine gute Referenz.

Um deinen Code zu verschönern, kannst du das Modul [Perl::Tidy][PerlTidy] verwenden.

Anschließend kannst du das mitgelieferte Dienstprogramm `perltidy` verwenden, um deinen Code neu zu formatieren.

    # modify file in-place and save old version as some_script.pl.bak
    $ perltidy -b some_script.pl

`perltidy` hat *sehr viele* Konfigurationsoptionen für jeden Geschmack. Sie sind [hier][perltidyDocs] dokumentiert.

Es gibt außerdem [tidyview], eine grafische Oberfläche, mit der du die verschiedenen Optionen anpassen und das Ergebnis sofort sehen kannst.

Wenn du Programmierrichtlinien durchsetzen möchtest, gibt es außerdem [Perl::Critic][perlcritic]. Es enthält die Regeln aus dem bereits erwähnten Buch *Perl Best Practices*, aber es gibt zahlreiche Plugins, und es lässt sich an jede interne Programmierrichtlinie anpassen.

So verwendest du es:

    $ perlcritic some_script.pl

Das Tool bietet sehr, sehr viele Konfigurationsmöglichkeiten; sieh dir die [Dokumentation][perlcriticdocs] an, um alles darüber zu erfahren.
