# Einführung

Wenn du eine Reihe von `n` Werten brauchst, bei der jeder Wert von seiner Position abhängt, arbeiten Factors `<iota>` und `map` zusammen, um die Aufgabe zu erledigen, ohne dass du einen Schleifenzähler schreiben musst.

## `<iota>` und `map`

`<iota>` (in [`sequences`][sequences]) nimmt eine nicht-negative Ganzzahl `n` und gibt eine *virtuelle* Sequenz der Ganzzahlen `0, 1, …, n-1` zurück. `map` läuft sie dann durch und wendet deine Quotation auf jedes Element an:

```factor
USING: math sequences ;

5 <iota> [ 2 * ] map .   ! => { 0 2 4 6 8 }
```

Die Quotation erhält eine Ganzzahl, den Index, und legt den Wert für diese Position auf dem Stack ab.

## Iterieren und Wiederholen nach Anzahl

Wenn du nur die *Seiteneffekte* des Besuchs jedes Index brauchst, nicht eine neue Sequenz, dann lässt `each-integer` (in [`math`][math]) eine Quotation über `0, 1, …, n-1` laufen:

```
each-integer ( n quot: ( i -- ) -- )
```

`replicate` (in [`sequences`][sequences]) ruft eine Quotation `n`-mal auf und sammelt die Ergebnisse. Der Index wird dabei ignoriert. Das ist praktisch, um `n` unabhängige Werte zu erzeugen:

```
replicate ( n quot: ( -- elt ) -- seq )
```

```factor
USING: sequences ;

3 [ { 0 0 } ] replicate .   ! => { { 0 0 } { 0 0 } { 0 0 } }
```

## Begrenzte Bereiche

Wenn der Indexbereich nicht bei `0` beginnt oder du ihn an beiden Enden inklusive haben willst, bietet das Vokabular [`ranges`][ranges] Literale in Klammernotation. Eckige Klammern schließen den Endpunkt ein, runde Klammern schließen ihn aus.

```
[a..b]    ! a, a+1, …, b      (inclusive)
[a..b)    ! a, a+1, …, b-1    (half-open at the top)
```

```factor
USING: math ranges sequences ;

3 7 [a..b] [ 2 * ] map .   ! => { 6 8 10 12 14 }
3 7 [a..b) [ 2 * ] map .   ! => { 6 8 10 12 }
```

Ein paar gängige Abkürzungen mit einem Argument:

```
[1..b]    ! 1, 2, …, b        (same as 1 b [a..b])
[1..b)    ! 1, 2, …, b-1      (same as 1 b [a..b))
[0..b)    ! 0, 1, …, b-1      (same as 0 b [a..b), and same as `b <iota>`)
```

```factor
6 [1..b] [ sq ] map .      ! => { 1 4 9 16 25 36 }
6 [1..b) [ sq ] map .      ! => { 1 4 9 16 25 }
4 [0..b) [ 1 + ] map .     ! => { 1 2 3 4 }
```

`<iota>` ist die gebräuchlichste Form. `[a..b]` und Verwandte sind das richtige Werkzeug, wenn der Bereich woanders als bei `0` beginnt oder eine inklusive Obergrenze braucht.

## Offene Untergrenzen und möglicherweise leere Bereiche

Eckige Klammern *schließen* einen Endpunkt *ein*, runde Klammern *schließen* ihn *aus*. Derselbe Trick auf der linken Seite ergibt `(a..b]` und `(a..b)`:

```
(a..b]    ! a+1, …, b              (lower open, upper inclusive)
(a..b)    ! a+1, …, b-1            (both open)
```

`0 n (a..b]` ergibt `{ 1 … n }` für `n > 0` und `{ }` für `n = 0`. Das ist die natürliche Form, wenn du „jede positive Ganzzahl bis einschließlich `n`“ durchläufst.

## Absteigende Bereiche

Alle vier Klammerformen, `[a..b]`, `[a..b)`, `(a..b]` und `(a..b)`, zählen *abwärts*, wenn `a > b`, und nicht auf ein leeres Ergebnis zu:

```factor
USING: ranges sequences ;

5 1 [a..b] >array .   ! => { 5 4 3 2 1 }
1 0 [a..b] >array .   ! => { 1 0 }   (not empty!)
```

## Einen String nach Position aufbauen

`map` liefert die Gestalt, die seine Quotation zurückgibt. Wenn die Quotation einen Zeichencode auf dem Stack hinterlässt, macht `>string` (in [`strings`][strings]) aus dem Ergebnis einen String:

```factor
USING: math sequences strings ;

4 <iota> [ 2 * CHAR: A + ] map >string .   ! => "ACEG"
```

`CHAR: A` wird zur Ganzzahl `65` geparst. Die Quotation hier verdoppelt den Index und addiert diese Basis, was bei jedem zweiten Großbuchstaben landet. Jede Arithmetik, die du zusätzlich auf den Index anwendest, entscheidet, welches Zeichen an dieser Position landet.

## Auswahl pro Position

Wenn das Zeichen von einer *Bedingung* über den Index abhängt, triff die Auswahl innerhalb der Quotation:

```factor
USING: kernel math sequences strings ;

5 <iota> [ 3 < [ CHAR: a ] [ CHAR: b ] if ] map >string .
! => "aaabb"
```

Die ersten drei Positionen testen `i 3 <` als `t`, also bekommen sie `a`; der Rest bekommt `b`. Dieselbe Form, `[ <test> [ <yes> ] [ <no> ] if ]`, deckt Paritätstests mit `even?` / `odd?` (in [`math`][math]) und Tests für „jede k-te Position“ mit `mod` und `zero?` ab.
