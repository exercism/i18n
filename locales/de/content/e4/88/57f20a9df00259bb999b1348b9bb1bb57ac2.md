# Einführung

In Python ist ein [Tupel][tuple] eine _unveränderliche_ Sammlung von Elementen in _einer Sequenz_.
Wie die meisten Sammlungen können `tuples` jeden (oder mehrere) Datentyp(en) enthalten, auch andere `tuples`.
Tupel unterstützen alle [gemeinsamen Sequenzoperationen][common sequence operations], aber **nicht** die [Operationen für veränderbare Sequenzen][mutable sequence operations].

Die Elemente eines Tupels lassen sich mit dem Konstrukt `for item in <tuple>` durchlaufen.
Wenn du sowohl den Index als auch den Wert eines Elements brauchst, kannst du `for index, item in enumerate(<tuple>)` verwenden.
Wie bei jeder Sequenz kannst du auf Elemente in `tuples` über die _Klammernotation_ zugreifen, und zwar mit einem `0-based index`, der von links zählt, oder einem `-1-based index`, der von rechts zählt.
Tupel kannst du außerdem ganz oder teilweise mit der Slice-Notation kopieren (_`<tuple>[<start>:<stop>:<step>]`_).


## Tupel erstellen

Tupel lassen sich auf verschiedene Arten bilden: entweder mit dem Klassenkonstruktor `tuple(<iterable>)` oder mit der Literalschreibweise `tuple`.

### Den Konstruktor `tuple()` leer oder mit einem _iterierbaren Objekt_ verwenden:

```python
>>> no_elements = tuple()
()

# The constructor *requires* an iterable, so single elements must be passed in a list or another tuple.
>>> one_element = tuple([16])
(16,)
```

Strings sind iterierbar. Wenn du also einen einzelnen `str` als Argument an den Konstruktor `tuple()` übergibst, kann das überraschende Ergebnisse liefern:

```python
# String elements (characters) are iterated through and added to the tuple
>>> multiple_elements_string = tuple("Timbuktu")
('T', 'i', 'm', 'b', 'u', 'k', 't', 'u')
```

Bei einzelnen Iterables werden die Elemente eins nach dem anderen hinzugefügt:

```python
>>> multiple_elements_list = tuple(["Parrot", "Bird", 334782])
("Parrot", "Bird", 334782)

>>> multiple_elements_set = tuple({2, 3, 5, 7, 11})
(2,3,5,7,11)
```

#### Ein Tupel als _Literal_ deklarieren:

Da der Konstruktor `tuple(<iterable>)` nur _Iterables_ (oder gar nichts) als Argumente akzeptiert, ist es viel einfacher, ein Ein-Element-Tupel mit der Literalschreibweise zu erstellen.

```python
>>> no_elements = ()
()

>>> one_element = ("Guava",)
("Guava",)
```

Verschachtelte Datenstrukturen können als `tuple`-Elemente vorkommen, auch andere `tuples`:

```python
>>> nested_data_structures = ({"fish": "gold", "monkey": "brown", "parrot" : "grey"}, ("fish", "mammal", "bird"))
({"fish": "gold", "monkey": "brown", "parrot" : "grey"}, ("fish", "mammal", "bird"))

>>> nested_data_structures_1 = (["fish", "gold", "monkey", "brown", "parrot", "grey"], ("fish", "mammal", "bird"))
(["fish", "gold", "monkey", "brown", "parrot", "grey"], ("fish", "mammal", "bird"))
```

## Tupel verketten

Tupel lassen sich mit dem Plus-Operator `+` verketten. Dabei wird jedes `tuple` entpackt und ein neues, kombiniertes `tuple` erzeugt.

```python
>>> new_via_concatenate = ("George", 5) + ("cat", "Tabby")
("George", 5, "cat", "Tabby")

#likewise, using the multiplication operator * is the equivalent of using + n times
>>> first_group = ("cat", "dog", "elephant")

>>> multiplied_group = first_group * 3
('cat', 'dog', 'elephant', 'cat', 'dog', 'elephant', 'cat', 'dog', 'elephant')
```

## Zugriff auf Elemente eines Tupels

Auf Elemente in einem `tuple` kannst du über die _Klammernotation_ zugreifen, mit einem `0-based index`, der von links zählt, oder einem `-1-based index`, der von rechts zählt.

```python
student_info = ("Alyssa", "grade 3", "female", 8 )

#gender is at index 2 or index -2
>>> student_gender = student_info[2]
'female'

>>> student_gender = student_info[-2]
'female'

#name is at index 0 or index -4
>>> student_name = student_info[0]
Alyssa

>>> student_name = student_info[-4]
Alyssa
```

## Über die Elemente eines Tupels iterieren

Elemente in einem `tuple` lassen sich in einer Schleife mit der Syntax `for item in <tuple>` _durchlaufen_.
Wenn du sowohl die Indizes als auch die Werte brauchst, kannst du `for index, item in enumerate(<tuple>)` verwenden.

```python
>>> student_info = ("Alyssa", "grade 3", "female", 8 )
>>> for item in student_info:
...   print(item)

...
Alyssa
grade 3
female
8

>>> for index, item in enumerate(student_info):
...  print("Index is: " + str(index) + ", value is: " + str(item) +".")

...
Index is: 0, value is: Alyssa.
Index is: 1, value is: grade 3.
Index is: 2, value is: female.
Index is: 3, value is: 8.
```

## Prüfen, ob ein Element in einem Tupel enthalten ist

Mit dem Operator `in` kannst du prüfen, ob ein Element in einem `tuple` enthalten ist.

```python
>>> multiple_elements_list = tuple(["Parrot", "Bird", 334782])
("Parrot", "Bird", 334782)

>>> "Parrot" in multiple_elements_list
True
```
