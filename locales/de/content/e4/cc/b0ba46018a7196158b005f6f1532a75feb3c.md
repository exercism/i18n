# Anleitung

In dieser Übung schreibst du Code, der einem Schilderunternehmen hilft, individuelle Botschaften für seine Schilder zu erstellen.

## 1. Erstelle ein Schild für einen Anlass

Implementiere die Funktion `buildSign(occasion, name)`, die einen String als Parameter `occasion` und einen String mit dem Namen einer Person als Parameter `name` entgegennimmt.
Die beiden Parameter werden in einen Template-String eingebettet, um die Botschaft auf dem Schild auszugeben.

```javascript
buildSign('Birthday', 'Rob');
// => "Happy Birthday Rob!"
```

## 2. Erstelle ein Geburtstagsschild

Implementiere die Funktion `buildBirthdaySign(age)`, die ein Alter entgegennimmt und anhand des Alters einen Teil der Botschaft auf dem Schild bestimmt.
Ist das Alter 50 oder älter, bezeichnet das Schild die Person als _mature_, andernfalls als _young_.
Die genaue erwartete Ausgabe ist unten zu sehen:

```javascript
buildBirthdaySign(50);
// => "Happy Birthday! What a mature fellow you are."

buildBirthdaySign(45);
// => "Happy Birthday! What a young fellow you are."
```

## 3. Erstelle ein Schild für den Schulabschluss

Implementiere die Funktion `graduationFor(name, year)`, die einen Namen als String-Parameter und ein Jahr als Zahlen-Parameter entgegennimmt und mithilfe von String-Interpolation einen Text für ein Schild erstellt, der einen Zeilenumbruch nutzt, um die beiden Zeilen der Botschaft zu trennen.

```javascript
graduationFor('Hannah', 2022);
/* => "Congratulations Hannah!
       Class of 2022"
*/
```

## 4. Berechne die Kosten eines Schilds

Implementiere die Funktion `costOf(sign, currency)`, die einen String mit dem Inhalt des Schilds und einen String für die Währung entgegennimmt.
Das Schild hat einen Grundpreis von 20 in der angegebenen Währung. Außerdem kostet jeder Buchstabe 2. (Leerzeichen werden in die Berechnung einbezogen.)
Der zurückgegebene Text enthält die Kosten für die Erstellung des Schilds, geschrieben mit zwei Nachkommastellen, gefolgt vom Währungs-String.

```javascript
costOf('Happy Birthday Rob!', 'dollars');
// => "Your sign costs 58.00 dollars."
```
