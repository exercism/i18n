# Einführung

## Vergleich

In JavaScript können Zahlen mit den folgenden Vergleichs- und Gleichheitsoperatoren verglichen werden.

| Vergleich             | Operator  |
| ---------------------- | --------- |
| Größer als             | `a > b`   |
| Größer als oder gleich | `a >= b`  |
| Kleiner als            | `a < b`   |
| Kleiner als oder gleich | `a <= b`  |
| (Strikt) gleich        | `a === b` |
| Nicht (strikt) gleich  | `a !== b` |

Das Ergebnis eines Vergleichs ist immer ein boolescher Wert: `true` oder `false`.

```javascript
1 < 3;
// => true

2 !== 2;
// => false

1 === 1.0;
// => true
// All numbers are floating-points, so this is different syntax for
// the exact same value.
```

In JavaScript können die obigen Vergleichsoperatoren auch verwendet werden, um Strings zu vergleichen.
In diesem Fall wird eine lexikografische (Wörterbuch-)Reihenfolge angewendet.
Eine Liste mit der genauen Reihenfolge aller Zeichen findest du [hier][utf-16-list].

```javascript
'Apple' > 'Pear';
// => false

'a' < 'above';
// => true

'a' === 'A';
// => false
```

## Bedingungen

Eine übliche Möglichkeit, Logik in JavaScript bedingt auszuführen, ist die if-Anweisung.
Sie besteht aus dem Schlüsselwort `if`, einer Bedingung in runden Klammern und einem Block in geschweiften Klammern.
Der Block wird nur ausgeführt, wenn die Bedingung `true` ergibt.

```javascript
if (condition) {
  // code that is executed if "condition" is true
}
```

Sie kann allein oder in Kombination mit dem Schlüsselwort `else` verwendet werden.

```javascript
if (condition) {
  // code that is executed if "condition" is true
} else {
  // code that is executed otherwise
}
```

Um eine weitere Bedingung in die `else`-Anweisung zu verschachteln, kannst du `else if` verwenden.

```javascript
if (condition1) {
  // code that is executed if "condition1" is true
} else if (condition2) {
  // code that is executed if "condition2" is true
  // but "condition1" was false
} else {
  // code that is executed otherwise
}
```
