# Einführung

Kotlin ist eine **statisch typisierte** Programmiersprache, die von JetBrains entwickelt wurde. Das bedeutet, dass der Typ von Variablen zur Kompilierzeit festgelegt wird.

## Variablen

Wie in anderen statisch typisierten Programmiersprachen solltest du den Typ jeder Variablen zur Kompilierzeit angeben. Explizite Typangaben kannst du weglassen, wenn der Compiler sie aus dem Kontext ableiten kann.

Kotlin kennt unveränderliche (`val`) und veränderliche (`var`) Variablen. Der Wert einer unveränderlichen Variablen lässt sich nicht mehr ändern, nachdem ihr Anfangswert zugewiesen wurde. Meistens wirst du diese Art von Variable verwenden.

```kotlin
val robotName = "HAL-9000"
userId = "T-1000"  // This will not compile
```

Der Wert einer veränderlichen Variablen kann ein- oder mehrmals geändert werden:

```kotlin
var index = 12
print(index)  // 12

index = 100
print(index)  // 100
```

Semikolons sind in Kotlin optional, abgesehen von ein paar Sonderfällen, die wir später behandeln.

## Funktionen

Funktionen werden in Kotlin mit dem Schlüsselwort `fun` definiert und sind _Bürger erster Klasse_ (das hat nichts mit OOP zu tun). Das bedeutet, dass du sie direkt in Dateien deklarieren kannst (sogenannte `top-level functions`), zum Beispiel kannst du in Java Methoden nur in Klassen definieren, nicht in Dateien:

```kotlin
// This is content of the Hello.kt file

fun hello() {}
```

Funktionen können Argumente entgegennehmen. Jedes Argument hat einen Namen und einen Typ. Anders als bei Variablen lässt sich der Typ von Argumenten nicht ableiten. Funktionen können null oder mehr Argumente haben:

```kotlin
fun hello() {}

fun hello(name: String) {}

fun hello(name: String, age: Int) {}
```

Kotlin-Funktionen können einen Wert zurückgeben, müssen aber nicht:

```kotlin
fun min(a: Int, b: Int): Int

fun countBonuses(user: User): Bonuses

fun run() {}
```

Um einen Wert aus einer Funktion zurückzugeben, verwendest du das Schlüsselwort `return`:

```kotlin
fun getName(): String {
    return "Alice"
}
```

Funktionen können Parameter mit Standardwerten haben. Diese Werte werden verwendet, wenn sie beim Aufruf der Funktion weggelassen werden:

```kotlin
fun ping(host: String = "localhost") {
    println("PING --> $host")
}

ping("exercism.io")  // PING --> exercism.io
ping()               // PING --> localhost
```

## Kommentare

Mit `//` definierst du einen einzeiligen Kommentar:

```kotlin
foo() // Everything after `//` will be ignored by compiler

// I will be ignored too
```

Mit `/*` und `*/` definierst du mehrzeilige Kommentare:

```kotlin
/*
   This this an example
   for a multiline comment
*/
```
