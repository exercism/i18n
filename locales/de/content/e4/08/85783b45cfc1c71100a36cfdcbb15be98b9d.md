# Überblick

Mit benutzerdefinierten Typen definierst du in Gleam neue Datentypen. Ein solcher Typ kann mehrere _Varianten_ haben, jede mit einem eigenen Namen.

```gleam
pub type Season {
  Spring
  Summer
  Autumn
  Winter
}
```

Jede Variante eines benutzerdefinierten Typs kann optional Daten enthalten, und verschiedene Varianten können Daten unterschiedlicher Typen enthalten. Enthält eine Variante Daten, nennt man sie ein _Record_.

```gleam
pub type Number {
  SomeInt(Int)
  SomeFloat(Float)
  Invalid
}
```

Um einen Wert für eine bestimmte Variante zu erzeugen, gibst du ihren Namen an, wenn sie keine zusätzlichen Daten enthält (`Spring`), oder du rufst sie wie eine Funktion auf, wenn sie Daten enthält (`SomeInt(2)`).

```gleam
let spring = Spring
let integer_two = SomeInt(2)
```

Benutzerdefinierte Typen haben, wie alles in Gleam, _strukturelle Gleichheit_. Das bedeutet, dass zwei Werte derselben Variante mit denselben Daten äquivalent sind.

```gleam
Spring == Spring // -> True
Spring == Autumn // -> False
SomeInt(2) == SomeInt(2) // -> True
SomeInt(2) == SomeFloat(2.0) // -> False
```

Auf Varianten benutzerdefinierter Typen kannst du mit case-Ausdrücken Pattern Matching anwenden.

```gleam
import gleam/int
import gleam/float

pub fn describe(flexible_number: Number) -> String {
  case flexible_number {
    SomeFloat(f) -> "Float: " <> float.to_string(f)
    SomeInt(i) -> "Int: " <> int.to_string(i)
    Invalid -> "Neither a float nor an int"
  }
}
```
