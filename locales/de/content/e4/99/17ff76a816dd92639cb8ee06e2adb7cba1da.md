# Einführung

Arrays sind Factors Sequenzen mit fester Länge: Du kannst die
Elemente ändern, aber nicht die Länge. Du weißt bereits, wie du ein
Array-Literal schreibst, nämlich `{ … }`, und wie du einen Ausschnitt
daraus nimmst oder Werte daraus zusammenfasst. Diese Übung behandelt
den kleinen Werkzeugkasten, der zum Einsatz kommt, wenn du Arrays aus
Werten auf dem Stack aufbaust und anschließend ihre Inhalte
nachschlägst oder umsortierst.

## Aus dem Stack aufbauen

`1array`, `2array`, `3array` und `4array` (in [`arrays`][arrays])
nehmen 1, 2, 3 oder 4 Werte vom oberen Ende des Stacks und bündeln
sie:

```
1array ( a       -- { a }       )
2array ( a b     -- { a b }     )
3array ( a b c   -- { a b c }   )
4array ( a b c d -- { a b c d } )
```

```factor
42 1array .                ! => { 42 }
3 4 2array .               ! => { 3 4 }
"x" "y" "z" 3array .       ! => { "x" "y" "z" }
1 2 3 4 4array .           ! => { 1 2 3 4 }
```

## Verbinden

`concat` (in [`sequences`][sequences]) nimmt eine Sequenz, deren
Elemente selbst Sequenzen sind, und flacht sie um eine Ebene ab.
`join` macht dasselbe, fügt aber zwischen jedem Paar ein Trennzeichen
ein:

```
concat ( seqs     -- seq )
join   ( seqs sep -- seq )
```

```factor
{ { 1 2 } { 3 4 } { 5 } } concat .
! => { 1 2 3 4 5 }

{ "alpha" "beta" "gamma" } ", " join .
! => "alpha, beta, gamma"
```

## Umkehren

`reverse` gibt eine neue Sequenz zurück, in der die Elemente in
umgekehrter Reihenfolge stehen:

```
reverse ( seq -- newseq )
```

```factor
{ 1 2 3 4 } reverse .   ! => { 4 3 2 1 }
```

## Ist es ein Array?

`array?` (in [`arrays`][arrays]) ist das Typ-Prädikat. Es ist
wahr für jeden Wert, der von `<array>`, `1array`/`2array`/... oder
einem Array-Literal `{ … }` erzeugt wurde, und falsch für alles
andere (einschließlich Vektoren, Strings und anderen Sequenzen):

```
array? ( obj -- ? )
```

```factor
{ 1 2 3 } array? .         ! => t
"hello" array? .           ! => f
V{ 1 2 3 } array? .        ! => f
```

## Nachschlagen

`index` gibt die Position des ersten Elements zurück, das gleich dem
Eingabewert ist, oder `f`, wenn es nicht vorkommt. `member?` gibt nur
einen booleschen Wert zurück. Beide erwarten das **Element zuerst**
und die **Sequenz danach**. `members` (in [`sets`][sets]) gibt die
*eindeutigen* Elemente einer Sequenz zurück, also die Operation, die
Duplikate entfernt, und `all-unique?` (ebenfalls in `sets`) prüft, ob
die Sequenz bereits keine Duplikate enthält:

```
index       ( elt seq -- i/f )
member?     ( elt seq -- ? )
members     ( seq     -- uniques )
all-unique? ( seq     -- ? )
```

```factor
"b" { "a" "b" "c" } index .       ! => 1
"z" { "a" "b" "c" } index .       ! => f
"b" { "a" "b" "c" } member? .     ! => t
"z" { "a" "b" "c" } member? .     ! => f
{ 1 2 3 2 1 } members .           ! => { 1 2 3 }
{ 1 2 3 } all-unique? .           ! => t
{ 1 2 1 } all-unique? .           ! => f
```
