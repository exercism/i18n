# For-Schleifen

Schleifen sind ein grundlegendes Konzept in der Programmierung. Sie ermöglichen es dir, einen Block Code mehrfach auszuführen.
In Swift gibt es zwei Arten von Schleifen: [`for-in`-Schleifen][for-loops] und `while`-Schleifen.
In diesem Kapitel lernst du `for-in`-Schleifen kennen.

For-Schleifen ermöglichen es dir, über eine Sequenz von Werten zu iterieren: Du nimmst jedes Element der Reihe nach und bindest es an eine Variable deiner Wahl.
Swift erlaubt es dir, über die verschiedensten Sequenzen zu iterieren, zum Beispiel über Bereiche, Arrays und Strings (und weitere Typen, die später behandelt werden).
Wenn jedes Element der Sequenz durchlaufen wurde, endet die Schleife.

For-Schleifen deklarierst du mit dem Schlüsselwort `for`, gefolgt von einem Variablennamen, dem Schlüsselwort `in` und einer Sequenz von Werten, über die iteriert wird.
Die Variable, die du in der `for-in`-Schleife angibst, ist unveränderlich. Du kannst ihren Wert innerhalb der Schleife also nicht ändern.
Hier ist ein Beispiel für eine `for-in`-Schleife, die über ein Array von Zahlen iteriert:

```swift
let numbers = [3, 10, 7, 11]

for number in numbers {
  print(number)
}
print("Done with numbers")

// prints:
// 3
// 10
// 7
// 11
// Done with numbers
```

~~~~exercism/note
Die Variable `number` wird in der `for-in`-Schleife deklariert und ist nur innerhalb des Gültigkeitsbereichs der Schleife verfügbar.

```swift
let numbers = [3, 10, 7, 11]

for number in numbers {
    number + 1
}
number + 1
// Error: Use of unresolved identifier 'number'
```
~~~~

## Über einen Bereich iterieren

Du kannst mit einer `for-in`-Schleife auch über einen Bereich von Zahlen iterieren.
So kannst du einen Block Code eine bestimmte Anzahl von Malen ausführen. Der Bereich `1...5` zum Beispiel durchläuft die Zahlen 1, 2, 3, 4 und 5, die Schleife wird also 5 Mal ausgeführt.
Manchmal möchtest du über Indizes in einer Datenstruktur wie einem Array iterieren. Dann kannst du einen Bereich `0..<array.count` verwenden.

```swift
let numbers = [3, 10, 7, 11]

for i in 0..<numbers.count {
  print(numbers[i])
}

// prints:
// 3
// 10
// 7
// 11
```

## Über einen String iterieren

Du kannst mit einer `for-in`-Schleife auch über einen String iterieren.
So kannst du über jedes Zeichen im String iterieren. Beachte insbesondere, dass der in der Schleife angegebene Typ ein `Character` ist.

```swift
let message = "Hello!"

for character in message {
  print(character)
}

// prints:
// H
// e
// l
// l
// o
// !
```

## stride

Swift bietet außerdem eine `stride`-Funktion, mit der du eine Sequenz über einen Bereich mit einer bestimmten Schrittweite erstellen kannst.
Diese kannst du dann mit einer `for-in`-Schleife durchlaufen.
`stride` ist als [`stride(from:to:by:)`][stride-to] oder [`stride(from:through:by:)`][stride-through] definiert. Die erste Variante schließt den Endwert aus, die zweite schließt ihn ein.

```swift
for i in stride(from: 0, to: 10, by: 2) {
  print(i)
}

// prints:
// 0
// 2
// 4
// 6
// 8
```

Beachte, dass der Parameter `to` exklusiv ist, die Schleife läuft also bis zu der Zahl vor dem Parameter `to`. Der Parameter `through` dagegen ist inklusiv und schließt in diesem Fall auch die `10` mit ein.

[stride-to]: https://developer.apple.com/documentation/swift/stride(from:to:by:)
[stride-through]: https://developer.apple.com/documentation/swift/stride(from:through:by:)
[for-loops]: https://docs.swift.org/swift-book/documentation/the-swift-programming-language/controlflow/#For-In-Loops
