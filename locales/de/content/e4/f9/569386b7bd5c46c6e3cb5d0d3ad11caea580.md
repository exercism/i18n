# Überblick

`case` ist Factors Mehrfachverzweigung auf Basis von Gleichheit. Es ist das richtige Werkzeug, wenn die Auswahl davon abhängt, dass ein *einzelner* Wert gleich einer von mehreren Alternativen ist, und nicht, wenn jeder Zweig einen anderen Test braucht (dafür nimmst du `cond`).

```factor
USING: combinators ;

SYMBOLS: yes no maybe ;

: invert ( ?/maybe -- ?'/maybe )
    {
        { yes [ no ] }
        { no  [ yes ] }
        [ ]            ! default: leave value alone
    } case ;
```

Ein paar Dinge, die du auseinanderhalten solltest:

- Gleichheit ist `=`. Alles, wofür `=` funktioniert, taugt als Schlüssel: Zahlen, Strings, Zeichen, Symbole, sogar Tupel.
- *Passende* Zweige sehen den Stack *ohne* den Eingabewert. *Standard*-Zweige sehen ihn noch oben auf dem Stack.
- Ein `case` ohne Standard-Zweig und ohne passende Klausel wirft einen Fehler.

`case` wird, wo möglich, zu einer Sprungtabelle kompiliert. Es ist also nicht nur syntaktischer Zucker für eine `if`-Kette, sondern auch schnell.
