# Einführung

Angenommen, du willst alle nicht-negativen Ganzzahlen bis 1000 haben.
Es wäre absurd, wenn du sie alle in ein Array eintippen müsstest.

Dafür gibt es den Typ `range`:

```julia-repl
julia> 0:1000
0:1000

julia> typeof(0:1000)
UnitRange{Int64}
```

Ranges sind sehr verbreitet: nicht nur, um dir Tipparbeit zu sparen, sondern auch als Rückgabetypen von Funktionen.

Beachte, dass Ranges _keine_ Vektoren sind.
Sie sind nur eine Reihe von Anweisungen, um eine Sequenz zu erzeugen (eine „lazy“ Auswertung, also ein „Iterator“).

Wenn du eine Range als Vektor brauchst, wandelst du sie mit der Funktion `collect()` um:

```julia-repl
julia> collect(0:5)
6-element Vector{Int64}:
 0
 1
 2
 3
 4
 5
```

Die Schrittweite lässt sich angeben, in diesem Fall 0.3:

```julia-repl
julia>  collect(1.0:0.3:2.0)
4-element Vector{Float64}:
 1.0
 1.3
 1.6
 1.9
```

Die Syntax ist also `start:stepsize:stop`.
Beide Endpunkte sind _inklusiv_, wie im Ganzzahl-Beispiel zu sehen.
Wenn die Schrittweite `stop - start` nicht genau teilt, überschreitet das letzte Element `stop` nicht.

## Ranges aus Buchstaben

In Ranges lassen sich auch nicht-numerische Sequenzen verwenden.
Das einfachste Beispiel sind ASCII-Buchstaben:

```julia-repl
julia> 'a':'d'
'a':1:'d'

julia> typeof('a':'d')
StepRange{Char, Int64}

julia> collect('a':'d')
4-element Vector{Char}:
 'a': ASCII/Unicode U+0061 (category Ll: Letter, lowercase)
 'b': ASCII/Unicode U+0062 (category Ll: Letter, lowercase)
 'c': ASCII/Unicode U+0063 (category Ll: Letter, lowercase)
 'd': ASCII/Unicode U+0064 (category Ll: Letter, lowercase)
```

Der Typ `Char` wird in einem anderen Konzept ausführlicher behandelt.
Betrachte diese vorerst einfach als einzelne Zeichen in einfachen Anführungszeichen.

## Funktionen und Operatoren für Ranges

Mit `first()` und `last()` kannst du die Grenzen einer Range prüfen.

```julia
 r = 1:10  # => 1:10
 first(r)  # => 1
 last(r)   # => 10
```

## Mehr zur Vektorindizierung

Ganzzahl-Ranges und Vektoren kannst du zum Indexieren von Vektoren verwenden:

```julia
nums = collect(10.0:50.0)
nums[3:2:7]  # gives [12.0, 14.0, 16.0]
nums[ [3, 5, 7] ] # also gives [12.0, 14.0, 16.0]
```
