# Über

Haxe hat zwei Zahlentypen: Ganzzahlen und Gleitkommazahlen:

- `Int`: Stellt eine Ganzzahl dar.
- `Float`: Stellt eine 64-Bit-Gleitkommazahl mit doppelter Genauigkeit dar.

```haxe
var integer:Int = 10;
var floating:Float = 5.4;
```

Während jeder `Int` überall dort verwendet werden kann, wo ein `Float` erwartet wird (das heißt, `Int` **ist zuweisbar an** oder **vereinigt sich mit** `Float`), gilt das Umgekehrte nicht: Das Zuweisen eines `Float` an einen `Int` kann zu Präzisionsverlust führen und ist daher implizit nicht erlaubt.

## Vergleich

Zahlen sind gleich, wenn sie denselben Wert haben.

```haxe
1 == 1; // true

1.2 == 1.2; // true

1 == 1.0; // true

0.2 + 0.1 == 0.3 // false
```

Für den letzten Fall siehe [0.30000000000000004.com][0.30000000000000004.com] für eine kurze Erklärung.
