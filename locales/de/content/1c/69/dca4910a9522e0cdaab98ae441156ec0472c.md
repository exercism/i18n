# Einführung

Der F#-Typ `char` ist ein 16-Bit-Wert, der die kleinsten adressierbaren Bestandteile von Text darstellt, und ist standardmäßig unveränderlich.

Ein `char`-Literal kannst du mit einfachen Anführungszeichen schreiben:

```fsharp
let ch = 'A'
// => val ch: char = 'A'
```

Ein String ist eine Folge von `char`-Werten.

Ein einzelnes `char` holst du über die (nullbasierte) Indexierung aus einem String:

```fsharp
"Exercism"[4] //  =>  'c'
```

Wenn du über einen String iterierst, bekommst du bei jedem Schritt einen `char`.

Das nächste Beispiel verwendet der Einfachheit halber eine Funktion höherer Ordnung und eine anonyme Funktion.
Diese werden später im Lehrplan ausführlich behandelt, aber für den Moment sind sie eine knappe Möglichkeit, eine Schleife über die Zeichen eines Strings zu schreiben.

```fsharp
Seq.map (fun c -> c, int c) "F#"  //  =>  [('F', 70); ('#', 35)]
```

Wie oben zu sehen, kannst du einen `char` in seinen `int`-Wert umwandeln.
Das funktioniert (*zumindest manchmal*) auch für andere Schriftsysteme:

```fsharp
Seq.map (fun c -> c, int c) "東京"  //  =>  [('東', 26481); ('京', 20140)]
```

Beim Vergleichen von Zeichen wird der zugrunde liegende Int16-Wert verwendet:

```fsharp
'A' < 'D'  // =>  true
```

Umgekehrt kannst du einen `int` in einen `char` umwandeln:

```fsharp
char 77  // => 'M'
```

Die Bibliothek `System.Char` enthält den vollständigen Satz an Methoden, den man von einer .NET-Sprache erwartet, etwa die Umwandlung in Groß- und Kleinschreibung:

```fsharp
'a' |> System.Char.ToUpper  // =>  'A'

'Q' |> System.Char.ToLower  // =>  'q'
```
