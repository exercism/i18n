# Über

[Nil][nil-dictionary] ist ein englisches Wort und bedeutet „nichts“ oder „null“. In Elixir ist `nil` ein besonderer Wert, der die _Abwesenheit_ eines Werts bedeutet.

```elixir
# I do not have a favorite color
favorite_color = nil
```

`nil` ist ein Atom, wird aber üblicherweise als `nil` und nicht als `:nil` geschrieben. Die booleschen Werte `true` und `false` sind ebenfalls Atome.

[//]: # (elixir-formatter-disable-next-block)

```elixir
nil === :nil
# => true

true === :true
# => true
```

Du kannst mit [`==`][kernel-equal], mit Pattern Matching oder mit dem [`is_nil`-Guard][kernel-is-nil] prüfen, ob der Wert einer Variablen `nil` ist.

```elixir
def call(phone_number) do
  if phone_number == nil do
    :error
  end
end
```

```elixir
def call(phone_number) when is_nil(phone_number) do
  :error
end
```

```elixir
def call(nil) do
  :error
end
```
