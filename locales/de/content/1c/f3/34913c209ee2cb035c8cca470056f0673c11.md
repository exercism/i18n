# Anweisungen

In dieser Übung schreibst du Code, um internationale Vorwahlen mithilfe einer Hashmap für Vorwahlen im Blick zu behalten.

Die Map verwendet für ihre Schlüssel eine Ganzzahl (die Vorwahl) und für ihre Werte einen String (den Ländernamen).

Du hast 11 Aufgaben, in denen es um Vorwahlen geht.

## 1. Erstelle eine vorab befüllte Hashmap

Es gibt eine vorab befüllte Hashmap mit den folgenden 3 Vorwahlen: „United States of America“ mit der Vorwahl 1, „Brazil“ mit der Vorwahl 55 und „India“ mit der Vorwahl 91. Definiere die Variable `countries`, um die vorab befüllte Hashmap zu speichern:

```clojure
countries
;;=> {1 "United States of America", 55 "Brazil", 91 "India"}
```

## 2. Füge ein Land zu einer Map hinzu

Füge „United Kingdom“ mit der Vorwahl 44 zur Map aus Aufgabe 1 hinzu:

```clojure
(add-country countries 44 "United Kingdom")
;;=> {1 "United States of America", 44 "United Kingdom", 55 "Brazil", 91 "India"}
```

## 3. Ermittle den Ländernamen zu einer Vorwahl

Rufe den Namen des Landes mit der Vorwahl 55 ab:

```clojure
(country-name countries 55)
;;=> "Brazil"
```

## 4. Aktualisiere einen Ländernamen

Ändere den Namen von „United States of America“ in „Les États-Unis“:

```clojure
(update-map countries 1 "Les États-Unis")
;;=> {1 "Les États-Unis", 55 "Brazil", 91 "India"}
```

## 5. Prüfe, ob ein Land in der Map existiert

Prüfe, ob ein Eintrag für Brazil in der Map aus Aufgabe 1 existiert:

```clojure
(code-exists? countries 55)
;;=> true
```

## 6. Versuche, den Namen eines Landes zu aktualisieren, das nicht in der Map ist

Versuche, den Namen eines Landes mit einer Vorwahl zu ändern, die nicht in der Map ist, z. B. 999. Die Map sollte sich dadurch nicht ändern:

```clojure
(update-map countries 999, "Newlands")
;;=> {1 "United States of America", 44 "United Kingdom", 55 "Brazil", 91 "India"}
```

## 7. Entferne ein Land aus der Map

Entferne India aus der Map:

```clojure
(remove-country countries 91)
;;=> {1 "United States of America", 55 "Brazil"}
```

## 8. Finde das Land mit dem längsten Namen

Verarbeite die Werte in der Map, um den mit dem längsten Namen zu finden:

```clojure
(longest-name countries)
;;=> "United States of America"
```
