# Anleitung

Ein pythagoreisches Tripel ist eine Menge aus drei natürlichen Zahlen {a, b, c}, für die gilt:

```text
a² + b² = c²
```

und für die außerdem gilt:

```text
a < b < c
```

Zum Beispiel:

```text
3² + 4² = 5².
```

Gegeben sei eine Ganzzahl N. Finde alle pythagoreischen Tripel, für die `a + b + c = N` gilt.

Zum Beispiel gibt es für N = 1000 genau ein pythagoreisches Tripel, für das `a + b + c = 1000` gilt: `{200, 375, 425}`.
