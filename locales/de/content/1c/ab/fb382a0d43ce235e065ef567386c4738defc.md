# Ergänzung der Anweisungen

## Moment, das ist unmöglich!

Diese Listenoperationen zu implementieren, ohne _irgendeine_ eingebaute Funktion zu verwenden, ist in Roc praktisch unmöglich, denn du brauchst eine Möglichkeit, Elemente an eine Liste anzuhängen oder ihr welche voranzustellen.
In anderen Sprachen könntest du Operatoren wie `:` in Haskell oder `+=` in Python verwenden, aber in Roc musst du die [`List`-Funktionen](https://www.roc-lang.org/builtins/main/#Builtin.List) benutzen.

Für diese Übung darfst du also `List.append` verwenden (aber vermeide jede andere eingebaute Funktion).

Viele funktionale Programmiersprachen verwenden verkettete Listen als primären Sammlungstyp.
Bei einer verketteten Liste ist es effizient, ein Element voranzustellen oder das erste Element zu entfernen, deshalb würdest du Listenoperationen in diesen Sprachen mit `List.prepend` implementieren.
In Roc ist eine `List` jedoch ein Array (ein zusammenhängender Block von Bytes).
Arrays haben andere Eigenschaften als verkettete Listen, zum Beispiel die Möglichkeit, effizient über einen Index auf Elemente zuzugreifen und neue Elemente anzuhängen.
Deshalb verwenden wir in Roc häufig `List.append` und nur selten `List.prepend`.

## Benennung

Roc verwendet etwas andere Namen als die in den allgemeinen Anweisungen aufgeführten:

- `concat` statt `append`
- `join` statt `concatenate`
- `len` statt `length`
- `fold` statt `foldl`
- `fold_rev` statt `foldr`

Die folgenden Funktionsnamen sind in Roc jedoch Standard:
- `filter`
- `map`
- `reverse`

## Hinweis

Versuche Folgendes:

```roc
match list {
    [] => ...
    [first, .. as rest] => ...
}
```

oder

```roc
match list {
    [] => ...
    [.. as rest, last] => ...
}
```
