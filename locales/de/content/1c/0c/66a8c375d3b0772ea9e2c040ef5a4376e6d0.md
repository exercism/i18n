# Einführung

In Factor kombinierst du Wörter einfach, indem du sie hintereinander schreibst: Die Reihenfolge, in der du sie schreibst, *ist* die Art und Weise, wie sie sich verbinden. (Programmierer nennen das *Funktionskomposition*.) Der Rumpf eines Wortes ist selbst eine Folge von Wörtern: Jedes entnimmt dem Stack einige Werte und legt sein Ergebnis auf den Stack, und das nächste Wort knüpft dort an, wo das vorherige aufgehört hat. Wenn du also

```factor
! DOCTEST: SKIP   (cleanupname is hypothetical here — the exercise's job)
: firstletter ( name -- letter ) cleanupname first 1string ;
```

definierst, ist das bereits *die* Komposition von `cleanupname`, `first` und `1string`.

In dieser Übung lernst du außerdem **Quotationen** kennen: Code, den du als Wert speichern und später ausführen kannst, statt ihn sofort auszuführen.

## Quotationen

Eine Quotation ist Code, der in eckige Klammern eingeschlossen ist. Sie läuft nicht, wenn sie geschrieben wird, sondern liegt als Wert auf dem Stack:

```factor
[ 2 * ] .       ! => [ 2 * ]
```

`call` führt eine Quotation aus:

```factor
3 [ 2 * ] call .    ! => 6
```

Du schreibst eine Quotation, wenn du Code als Daten übergeben musst: damit er später ausgeführt oder an einen *Kombinator* weitergereicht wird, also an ein Wort, das eine Quotation als Eingabe nimmt.

## `compose`

`compose ( quot1 quot2 -- combined )` klebt zwei Quotationen zu einer zusammen und führt sie in der Reihenfolge aus, in der du sie geschrieben hast:

```factor
[ 2 * ] [ 1 + ] compose .    ! => [ 2 * 1 + ]
```

Meist wirst du merken, dass es besser lesbar ist, ein kleines Wort mit `:` ... `;` zu definieren, als `compose` zu verwenden. Aber `compose` ist praktisch, wenn du Quotationen spontan zusammenbauen musst. Wenn die Bausteine noch keine Quotationen sind, verwandelt `>quotation ( seq -- quot )` (aus [`quotations`][quotations]) eine Folge von Werten und Wortverweisen in eine aufrufbare Quotation:

```factor
USING: quotations sequences ;

{ [ 1 ] [ 2 + ] [ 3 * ] } concat >quotation call .   ! => 9
```

## Eine Quotation auf zwei Eingaben anwenden

`bi@ ( x y quot -- ... )` führt die Quotation zuerst auf `x` aus und dann noch einmal auf `y`; beide Ergebnisse bleiben auf dem Stack:

```factor
3 4 [ 2 * ] bi@ .s
! => 6
! => 8
```

Die `couple`-Aufgabe dieser Übung nimmt zwei Namen entgegen; `bi@` ist der natürliche Weg, `initial` auf beide anzuwenden.

## Ein paar Wörter für Strings

Die Übung braucht ein paar kleine Wörter für Strings, die aus drei Vokabularen stammen: [`sequences`][sequences], [`ascii`][ascii] und [`strings`][strings]:

- `replace ( seq old new -- new-seq )` (in `splitting`) – ersetzt einen Teilstring.
- `[ blank? ] trim` (`trim` in `sequences`, `blank?` in `ascii`) – entfernt führende und nachfolgende Leerzeichen.
- `1string ( char -- str )` (in `strings`) – verpackt ein einzelnes Zeichen in einen String.
- `>upper ( str -- upper )` (in `ascii`) – wandelt einen String in Großbuchstaben um.
- `append ( s1 s2 -- s )` (in `sequences`) – hängt zwei Strings aneinander.
- `prepend ( s1 s2 -- s )` (in `sequences`) – hängt `s2` und dann `s1` aneinander (`append` mit den Eingaben in umgekehrter Reihenfolge).
- `glue ( s1 s2 sep -- s )` (in `sequences`) – fügt zwei Strings mit einem Trennzeichen dazwischen zusammen.
- `surround ( seq pre post -- new )` (in `sequences`) – umschließt einen String mit einem Präfix und einem Suffix.

Unicode-Zeichen kannst du in einem String als `\u{XXXX}` schreiben, wobei `XXXX` der Codepoint in Hexadezimalform ist. Das Herz `\u{2764}` (❤) kommt in dieser Übung vor.

## Formatierte Ausgabe

Wenn `append`/`glue`/`surround` nicht ausdrucksstark genug sind, bietet [`formatting`][formatting] das printf-artige `sprintf`:

```
sprintf ( inputs... format-string -- str )
```

`%s` setzt einen String ein, `%d` eine Ganzzahl, `%f` eine Gleitkommazahl; optionale Angaben zu Breite, Präzision und Auffüllung stehen zwischen `%` und dem Typbuchstaben:

```factor
USING: formatting ;

"Alice" "Bob" "%s & %s" sprintf .   ! => "Alice & Bob"
3.14159 "%.2f" sprintf .             ! => "3.14"
42 "%05d" sprintf .                  ! => "00042"
```

Für die Hin-und-zurück-Umwandlung zwischen Zahlen und Strings bietet [`math.parser`][math.parser] `number>string` und `string>number`:

```factor
USING: math.parser ;

42 number>string .       ! => "42"
"3.14" string>number .   ! => 3.14
```
