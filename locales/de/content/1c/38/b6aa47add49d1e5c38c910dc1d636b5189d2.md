# Hinweise

- Die Dokumentation für das `Bitwise`-Paket findest du [hier][bitwise-docs].

## 1. Die Bits zurückschieben

- Es gibt zwei Funktionen, um Bits nach rechts zu verschieben, aber [nur eine][bitwise-shiftRightZfBy] fügt immer eine 0 ein.

## 2. Einige Bits setzen

- [Eine der bitweisen Funktionen][bitwise-or] setzt ein Bit immer auf 1, wenn die Bits in beiden Werten 1 sind.

## 3. Bestimmte Bits umdrehen

- Es gibt [eine bitweise Funktion][bitwise-xor], die ein Bit umdreht, wenn die Maske 1 ist.

## 4. Bestimmte Bits löschen

- [Eine der bitweisen Funktionen][bitwise-and] löscht Bits, bei denen das Bit in der Maske 0 ist.
- Aber du musst sie möglicherweise mit [einer anderen Funktion][bitwise-complement] kombinieren, um Bits zu löschen, bei denen die Maske 1 ist.

## 5. Eine Nachricht entschlüsseln

- Wende die anderen Funktionen, die du geschrieben hast, in der folgenden Reihenfolge auf die Eingabe an: Nimm die Ausgabe der einen und verwende sie als Eingabe für die nächste:

1. `setBits`
2. `flipBits`
3. `shiftBack`
4. `clearBits`

Für Schritt 4 musst du die Binärzahl mit dem 1. und 5. Bit gesetzt (10001) in eine Dezimalzahl umwandeln.
