# Anleitung

Du bist ein begeisterter Vogelbeobachter und hältst fest, wie viele Vögel in den letzten sieben Tagen deinen Garten besucht haben.

Du hast fünf Aufgaben, die sich alle mit der Anzahl der Vögel befassen, die deinen Garten besucht haben.

## 1. Prüfe, wie die Zählungen letzte Woche waren

Du speicherst deine Vogelzählungen im JSON-Format.
Ein „Haupt“-Array speichert Arrays mit den wöchentlichen Zählungen.
Jede wöchentliche Zählung ist ein Array aus sieben Ganzzahlen, eine Zahl für jeden Tag der Woche.
Neue Wochen hängst du immer am Ende des Haupt-Arrays an.
Implementiere den Filter, der die Zählungen der letzten Woche zurückgibt.

```sh
$ cat bird-counting-data.json
[
  ...,
  [0, 2, 5, 3, 7, 8, 4],
  [4, 5, 9, 10, 9, 4, 3]
]

$ jq -f bird-count.jq < bird-counting-data.json
{
  "last_week": [0, 2, 5, 3, 7, 8, 4],
  ...
```

## 2. Prüfe, wie viele Vögel gestern zu Besuch waren

Implementiere den Filter, der zurückgibt, wie viele Vögel gestern deinen Garten besucht haben.
Die Vogelzählungen sind nach Tagen geordnet: Das erste Element ist die Zählung des ältesten Tages, das letzte Element die Zählung von heute.

```jq
$ jq -f bird-count.jq < bird-counting-data.json
{
  ...
  "yesterday": 4,
  ...
```

## 3. Berechne die Gesamtzahl der zu Besuch gekommenen Vögel

Implementiere den Filter, der die Gesamtzahl der Vögel zurückgibt, die diese Woche deinen Garten besucht haben.

```jq
$ jq -f bird-count.jq < bird-counting-data.json
{
  ...
  "total": 44,
  ...
```

## 4. Berechne die Anzahl der geschäftigen Tage

Manche Tage sind geschäftiger als andere.
Ein geschäftiger Tag ist ein Tag, an dem fünf oder mehr Vögel deinen Garten besucht haben.
Implementiere den Filter, der die Anzahl der geschäftigen Tage dieser Woche zurückgibt.

```jq
$ jq -f bird-count.jq < bird-counting-data.json
{
  ...
  "busy_days": 4,
  ...
```

## 5. Prüfe, ob es einen Tag ohne Vögel gab

Implementiere den Filter, der `true` zurückgibt, wenn es diese Woche einen Tag gab, an dem null Vögel den Garten besucht haben; andernfalls gibt er `false` zurück.

```jq
$ jq -f bird-count.jq < bird-counting-data.json
{
  ...
  "has_day_without_birds": false
}
```
