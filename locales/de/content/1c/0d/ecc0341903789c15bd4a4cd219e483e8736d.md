# Destrukturierung im Parameter

Die [Destrukturierungszuweisung](https://developer.mozilla.org/en-US/docs/Web/JavaScript/Reference/Operators/Destructuring_assignment) funktioniert auch direkt in Parametern, etwa bei
`%{parameter}`. So kannst du den Elementen im Parameter einen Namen geben, begrenzen,
wie viele Elemente übergeben werden, und die kryptischen numerischen Indizes durch
die benannten Elemente ersetzen.
