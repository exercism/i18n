# Zusatz zu den Anweisungen

## Bonus

Teste deine Funktion mit diesem String: `uüu` und schau, was passiert.
Versuch, eine Funktion zu schreiben, die diesen String wirklich umdreht.
Hinweis: Graphemcluster

Damit der Bonus-Test ausgeführt wird, entferne das Ignore-Flag (`#[ignore]`) aus dem letzten Test und führe die Tests so aus:

```bash
cargo test --features grapheme
```

Für die Bonus-Aufgabe brauchst du externe Bibliotheken (im Rust-Jargon ein `crate`).
Eine gute Anlaufstelle dafür ist [crates.io](https://crates.io/), das offizielle Repository für Crates.
Denk daran, dass unser Test-Runner nur eine begrenzte Anzahl von Crates unterstützt.
Die vollständige Liste findest du in [dieser Datei](https://github.com/exercism/rust-test-runner/blob/main/local-registry/Cargo.toml) im Abschnitt `[dependencies]`.

[Schau in die Dokumentation](https://doc.rust-lang.org/cargo/guide/dependencies.html), wenn du wissen willst, wie du externe Crates in deinen Projekten verwendest.
