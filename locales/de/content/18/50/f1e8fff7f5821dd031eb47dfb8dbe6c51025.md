# Einführung

Eine Schnittstelle ist ein Typ, der Member enthält, die eine Gruppe zusammengehöriger Funktionalität definieren. Sie trennt die Verwendung einer Klasse von der Implementierung und ermöglicht so mehrere verschiedene Implementierungen oder die Unterstützung eines generischen Verhaltens wie Formatierung, Vergleich oder Konvertierung.

Die Syntax einer Schnittstelle ähnelt der einer Klasse oder Struktur. Der Unterschied ist, dass Methoden und Eigenschaften nur als Signatur erscheinen und kein Rumpf angegeben wird.

```csharp
public interface ILanguage
{
    string LanguageName { get; set; }
    string Speak();
}

public class ItalianTaveller : ILanguage, ICloneable
{
    public string LanguageName { get; set; } =  "Italiano";

    public string Speak()
    {
        return "Ciao mondo";
    }

    public object Clone()
    {
        ItalianTaveller it = new ItalianTaveller();
        it.LanguageName = this.LanguageName;
        return it;
    }
}
```

Alle Operationen, die von der Schnittstelle definiert werden, müssen implementiert werden.

Schnittstellen können neben anderen Membern auch Instanzmethoden und Eigenschaften enthalten.
