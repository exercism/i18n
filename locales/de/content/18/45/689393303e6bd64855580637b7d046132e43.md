# Lokales Debugging

Wenn du die Tests des Bash-Tracks mit [Bats](https://github.com/bats-core/bats-core) ausführst, zeichnet Bats sowohl STDOUT als auch STDERR für Ausgabe-Assertions auf.

```exercism/caution
Dies funktioniert lokal mit `bats`, aber **nicht** im Online-Editor von Exercism.
```

Wenn du Debug-Ausgaben ausgeben möchtest, ohne das Testergebnis zu beeinflussen, schreibe sie in Dateideskriptor (fd) 3.

```bash
echo 'debug message' >&3
```

Bats zeigt während des Testlaufs Ausgaben an, die in fd 3 geschrieben wurden, aber es bezieht diese Ausgaben nicht in Assertions wie `assert_output` ein.

Beispiellauf:

```none
$ bats hello_world.bats
hello_world.bats
 ✓ Say Hi!
debug message
1 test, 0 failures
```

Das ist nützlich, wenn du die Tests lokal ausführst.
