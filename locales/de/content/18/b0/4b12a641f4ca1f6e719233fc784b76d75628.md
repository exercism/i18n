# Anleitung

Du arbeitest in einer Online-Modeboutique.
Du hast die Idee für eine Website-Funktion, bei der dem Nutzer Outfits vorgeschlagen werden.
Von Interesse sind die möglichen Outfits, ihre Preise und das Ausschließen nicht zusammenpassender Kombinationen.

~~~~exercism/note
Auch wenn es verschiedene Wege gibt, die folgenden Probleme zu lösen, lassen sich alle mit einer Comprehension lösen.
~~~~

## 1. Ein Kleidungsstück erstellen


Implementiere `clothingitem()`, das zwei `Tuple`s entgegennimmt, eines mit `categories` und das andere mit den zugehörigen `qualities`.
Die Funktion soll ein `Dict` zurückgeben, dessen Schlüssel die `categories` und dessen Werte die `qualities` sind.

```julia-repl
julia> categories = ("item_name", "price", "color", "base_color");

julia> qualities = ("Descriptive Name", 99.00, "Ochre Red", "red");

julia> clothingitem(categories, qualities)
Dict{String, Any} with 4 entries:
  "price"      => 99.0
  "item_name"  => "Descriptive Name"
  "base_color" => "red"
  "color"      => "Ochre Red"
```

Deine Funktion soll mit beliebig vielen `categories` umgehen können.

## 2. Kombinationen vorschlagen

Implementiere `get_combinations()`, das ein `Tuple` mit Oberteilen und ein `Tuple` mit Unterteilen entgegennimmt.
Die Funktion soll das `cartesian product` der Tuples als 2-D-Array (d. h. `Matrix`) zurückgeben.
Jeder Eintrag ist eine `(top, bottom)`-Kombination als `Tuple`.
Oberteile ändern sich von Zeile zu Zeile, Unterteile von Spalte zu Spalte.

```julia-repl
julia> tops = (
        Dict("item_name" => "Dress shirt"),
        Dict("item_name" => "Casual shirt")
        );

julia> bottoms = (
        Dict("item_name" => "Jeans"),
        Dict("item_name" => "Dress trousers")
       );

julia> get_combinations(tops, bottoms)
2×2 Matrix{Tuple{Dict{String, String}, Dict{String, String}}}:
 (Dict("item_name"=>"Dress shirt"), Dict("item_name"=>"Jeans"))   (Dict("item_name"=>"Dress shirt"), Dict("item_name"=>"Dress trousers"))
 (Dict("item_name"=>"Casual shirt"), Dict("item_name"=>"Jeans"))  (Dict("item_name"=>"Casual shirt"), Dict("item_name"=>"Dress trousers"))
```

## 3. Die Preise von Outfits zusammenzählen

Jedes Kleidungsstück hat ein zugehöriges `price`-Feld, daher kann es hilfreich sein, den Gesamtpreis von Outfits vergleichen zu können.
Implementiere `get_prices()`, das ein Array mit Kleidungskombinationen entgegennimmt.
Die Funktion soll ein Array mit derselben Form zurückgeben, in dem die Preise der Outfits an ihren jeweiligen Positionen stehen.

```julia-repl
julia> tops = (
        Dict("item_name" => "Dress shirt", "base_color" => "blue", "price" => 35),
        Dict("item_name" => "Casual shirt", "base_color" => "black", "price" => 20)
       );

julia> bottoms = (
        Dict("item_name" => "Jeans", "base_color" => "blue", "price" => 30),
        Dict("item_name" => "Dress trousers", "base_color" => "black", "price" => 75)
       );

julia> combomatrix = get_combinations(tops, bottoms);

julia> get_prices(combomatrix)
2×2 Matrix{Int}::
 65  110
 50   95

julia> filteredmatrix = filter_clashing(combomatrix)
1-element Vector{Tuple{Dict{String, Any}, Dict{String, Any}}}:
 (Dict("price" => 20, "item_name" => "Casual shirt", "base_color" => "black"), Dict("price" => 30, "item_name" => "Jeans", "base_color" => "blue"))

julia> get_prices(filteredmatrix)
1-element Vector{Int}:
 50
```

## 4. Nicht zusammenpassende Outfits herausfiltern

Jedes Kleidungsstück hat ein `base_color`-Feld.
Nutze dieses Feld, um alle Kombinationen zu entfernen, bei denen Oberteil und Unterteil dieselbe Grundfarbe haben.
Implementiere `filter_clashing()`, das ein Array mit Kleidungskombinationen entgegennimmt.
Gib ein 1-D-Array (d. h. `Vector`) mit den passenden Kombinationen zurück.

```julia-repl
julia> tops = (
        Dict("item_name" => "Dress shirt", "base_color" => "blue", "price" => 35),
        Dict("item_name" => "Casual shirt", "base_color" => "black", "price" => 20)
       );

julia> bottoms = (
        Dict("item_name" => "Jeans", "base_color" => "blue", "price" => 30),
        Dict("item_name" => "Dress trousers", "base_color" => "black", "price" => 75)
       );

julia> combos = get_combinations(tops, bottoms);

julia> filter_clashing(combos)
1-element Vector{Tuple{Dict{String, Any}, Dict{String, Any}}}:
 (Dict("price" => 20, "item_name" => "Casual shirt", "base_color" => "black"), Dict("price" => 30, "item_name" => "Jeans", "base_color" => "blue"))
```
