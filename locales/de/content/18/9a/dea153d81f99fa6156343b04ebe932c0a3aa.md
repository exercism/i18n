# Tests auf dem MoonScript-Track

Das Testen auf dem MoonScript-Track läuft genau so ab wie [das Testen auf dem Lua-Track][lua-tests].
Gib in einem Übungsverzeichnis Folgendes ein:

```console
$ busted
```

## Ausstehende Tests

Dieser Track folgt der [Test-Driven Development][tdd]-Methodik von Exercism.
Du bekommst eine vollständige Testsuite, aber nur der erste Test ist „aktiv“.

Um die Tests zu aktivieren, änderst du den Befehl eines Tests von `pending` zu `it`.

Wenn du gerne immer alle Tests ausführen möchtest, kannst du sie mit einem Kommandozeilen-Tool auf einmal umstellen.
Hier ist ein Beispiel mit perl (das so gut wie überall installiert ist):

```console
$ perl -i -pe 's/^\s+\Kpending\b/it/' two_fer_spec.moon
```

Wenn du im Online-Editor arbeitest, führt der Test Runner automatisch alle Tests aus.

## LuaRocks verwenden

Lua allein ist eine sehr kleine Programmiersprache.
[LuaRocks][luarocks] ist der Paketmanager für Lua-Module.

Du kannst in deinen Lösungen jedes Modul verwenden, aber nicht alle davon sind im Online-Test-Runner verfügbar.
Der Test Runner stellt diese bereit:

**Bereits als `busted`-Abhängigkeiten verfügbar**

* [penlight][penlight] ([Homepage][penlight-home])

  > Penlight ist eine Sammlung reiner Lua-Bibliotheken, die die Arbeit mit alltäglichen Aufgaben erleichtert, etwa das Durchlaufen von Verzeichnissen oder das Lesen von Konfigurationsdateien. Es bietet funktionale Operationen für Tabellen und Sequenzen.

* [dkjson][dkjson] ([Homepage][dkjson-home])

  > dkjson ist ein Modul zum Kodieren und Dekodieren von JSON-Daten. 

**Bereits als MoonScript-Abhängigkeiten verfügbar**

* [LPeg][lpeg] ([Homepage][lpeg-home])

  > LPeg ist eine neue Bibliothek für den Musterabgleich in Lua, die auf Parsing Expression Grammars (PEGs) basiert. 

* [LuaFileSystem][lfs] ([Homepage][lfs-home])

  > LuaFileSystem bietet eine portable Möglichkeit, auf die zugrunde liegende Verzeichnisstruktur und Dateiattribute zuzugreifen.

**Datum und Uhrzeit**

* [date][date] ([github][date-home])

  > Parsen von Datums- und Zeit-Strings; Addieren und Subtrahieren von Zeiten; Berechnen von Zeitspannen; Unterstützt ISO-8601-Datumsangaben. 

* [lua-tz][lua-tz] ([github][lua-tz-home])

  > Lua TZ bietet Datums- und Zeitfunktionen mit Unterstützung für Zeitzonen. Die Kernfunktionen haben eine Schnittstelle, die den Standardfunktionen os.date und os.time ähnelt, akzeptieren aber zusätzlich ein Argument für die Zeitzone.

* [luatz][luatz] ([github][luatz-home])

  > Eine Lua-Bibliothek zur Manipulation von Zeit und Datum.
