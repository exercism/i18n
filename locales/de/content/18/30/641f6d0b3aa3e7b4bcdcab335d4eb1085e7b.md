# Über

[Variadische Parameter][variadic-parameters] erlauben es einer Funktion, null oder mehr Werte eines bestimmten Typs für einen einzelnen Parameter zu akzeptieren.
Du definierst einen variadischen Parameter, indem du drei Punkte (`...`) an die Typannotation des Parameters anhängst.

Innerhalb des Funktionskörpers stellt Swift diese Werte als Array des angegebenen Typs bereit:

```swift
import Foundation

func geometricMean(_ numbers: Double...) -> Double {
    var total = 1.0
    for number in numbers {
        total *= number
    }
    return pow(total, 1.0 / Double(numbers.count))
}

let result = geometricMean(1, 2, 3, 4, 5)
// result is 2.605171084697352
```

~~~~exercism/note
Wenn eine Funktion zusätzliche Parameter nach einem variadischen Parameter enthält, **muss** der erste Parameter nach dem variadischen Parameter ein explizites Argument-Label haben, damit Swift weiß, wo die Liste der variadischen Argumente endet.
~~~~
