# Einleitung

Eine Methode ist eine Funktion mit einem speziellen _Receiver_-Argument.
Der Receiver erscheint in seiner eigenen Argumentliste zwischen dem `func`-Schlüsselwort und dem Namen der Methode.

```go
func (receiver type) MethodName(parameters) (returnTypes) {
}
```

du kannst eine Methode nur mit einem Receiver definieren, dessen Typ im selben Paket wie die Methode definiert ist.

```go
package person 

type Person struct {
	Name string
}

func (p Person) Greetings() string {
	return fmt.Sprintf("Welcome %s!", p.Name)
}
```

Die Methode auf dem Struct kann über die Punktnotation aufgerufen werden.

```go
p := Person{Name: "Bronson"}
fmt.Println(p.Greetings())
// Output: Welcome Bronson!
```

Schau dir an, wie wir die Methode `Greetings()` auf der `Person`-Instanz `p` aufgerufen haben.
Es ist genau so, wie du Methoden in einer objektorientierten Programmiersprache aufrufst.

Denk daran: Eine Methode ist nur eine Funktion mit einem Receiver-Argument.
Methoden helfen, Namenskonflikte zu vermeiden: Da eine Methode an einen bestimmten Receiver-Typ gebunden ist, kannst du denselben Methodennamen auf verschiedenen Typen haben.

```go
import "math"

type rect struct {
	width, height int
}
func (r rect) area() int {
	return r.width * r.height
}

type circle struct {
	radius int
}
func (c circle) area() float64 {
	return math.Pow(float64(c.radius), 2) * math.Pi
}
```

Es gibt zwei Arten von Receivern: Wert-Receiver und Zeiger-Receiver.

Alle Methoden, die wir bisher gesehen haben, haben einen Wert-Receiver. Das heißt, sie erhalten eine Kopie des Werts, der an die Methode übergeben wird. Änderungen am Receiver innerhalb der Methode sind daher für den Aufrufer nicht sichtbar.

du kannst Methoden mit Zeiger-Receivern deklarieren, um den Wert zu ändern, auf den der Receiver zeigt. Dazu setzt du ein `*` vor den Typnamen. Für den Typ `rect` würde ein Zeiger-Receiver beispielsweise als `*rect` deklariert. Solche Änderungen sind auch für den Aufrufer der Methode sichtbar.

```go
type rect struct {
	width, height int
}
func (r *rect) squareIt() {
	r.height = r.width
}

r := rect{width: 10, height: 20}
fmt.Printf("Width: %d, Height: %d\n", r.width, r.height)
// Output: Width: 10, Height: 20

r.squareIt()
fmt.Printf("Width: %d, Height: %d\n", r.width, r.height)
// Output: Width: 10, Height: 10
```
