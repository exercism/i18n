# Einführung

Objekte können ihren eigenen Zustand speichern, indem sie _Instanzvariablen_ setzen. Diese erstellst du, indem du einem Variablennamen ein `@` voranstellst.

```ruby
@name = 2
```

Objekte legen ihren Anfangszustand normalerweise in einer `initialize`-Methode fest. Diese wird automatisch aufgerufen, wenn du `new` auf eine Klasse aufrufst.

```ruby
class Airplane
  def initialize
    @wings = 2
  end
end
```

Die `initialize`-Methode kann auch Argumente entgegennehmen, sodass jede Instanz mit einem individuellen Zustand starten kann:

```ruby
class Suitcase
  def initialize(locked)
    @locked = locked
  end
end
```

Betrachte _Instanzvariablen_ als privat, was das Lesen und Schreiben von außen angeht. Um Instanzvariablen zu lesen und zu setzen, solltest du _Instanz_-Methoden verwenden:

```ruby
class Suitcase
  #...

  def locked? # Query methods should be named with a trailing `?`
    @locked
  end

  def unlock! # Methods which mutate state should have trailing `!`
    @locked = false
  end
end
```
