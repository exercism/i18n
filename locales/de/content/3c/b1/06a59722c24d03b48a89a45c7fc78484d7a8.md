# Einführung

Der `let`-Ausdruck wird verwendet, um einen lokalen Gültigkeitsbereich zu erstellen, und ist in einigen Situationen nützlich:

- Um Ausdrücke zu vereinfachen
- Um die Ergebnisse von Zwischenausdrücken zu benennen
- Um einen Ausdruck in kleinere Teile aufzuteilen, wenn er zu groß wird

Du kannst fast alles in einem `let`-Ausdruck machen, einschließlich Destrukturierung (mehr dazu in späteren Übungen), aber es ist nicht möglich, einen neuen Custom Type oder Type Alias zu definieren.

```elm
let
  cube x = x * x * x
in
  cube a + cube b + cube c
```

```elm
beginWithPattern : Size -> Padding -> Pattern -> GameOfLife
beginWithPattern minimumSize padding pattern =
    let
        size = calculateSize minimumSize padding pattern

        center = Size.center size

        centeredPattern = Pattern.centerAt center pattern

        dimensions = { width = size, height = size }

        deadCells = Matrix.create dimensions Dead
    in
    GameOfLife (bringPatternToLife deadCells centeredPattern)
```
