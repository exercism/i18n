# Einführung

## Vergleichsoperatoren

Vergleichsoperatoren in Julia ähneln denen vieler anderer Sprachen, bieten aber ein paar Extras für Mathe-Fans.

Für Gleichheit gibt es die Operatoren `==` (gleich) und `!=` oder `≠` (ungleich).

```julia
txt = "abc"
txt == "abc"  # true
txt != "abc"  # false
txt ≠ "abc"  # false (synonym for !=)
```

Außerdem gibt es noch die verschiedenen Größer-als- und Kleiner-als-Operatoren.

```julia
1 < 3  # true
3 > 3  # false
3 <= 3  # true
3 ≤ 3  # true (synonym for <=)
4 >= 3  # true
4 ≥ 3  # true (synonym for >=)
```

Wie so oft bei Julia macht ein passender Editor die Verwendung des mathematischen Symbols einfach. Tippe `\ne`, `\le` oder `\ge` und dann `TAB`, um `≠`, `≤` oder `≥` zu erhalten.

Das vorige Beispiel verwendet nur Zahlen, aber wir werden in anderen Teilen des Lehrplans sehen, dass diverse weitere Typen eine Ordnung kennen und auf Größer-als/Kleiner-als geprüft werden können.

Vergleichsoperatoren lassen sich verketten, was eine klare und knappe Syntax ermöglicht:

```julia
n = 3
1 ≤ n ≤ 5  # true (n "between" two limits)
```

Das vorige Beispiel ist ein Synonym für `1 ≤ n && n ≤ 5`.

## Verzweigen mit `if`

Das ist die vollständige Form einer `if`-Anweisung:

```julia
if conditional1
    statements...
elseif conditional2
    statements...
else
    statements...
end
```

Klammern `()` oder geschweifte Klammern `{}` sind nicht nötig, und die Einrückung dient „nur“ der besseren Lesbarkeit _(aber Lesbarkeit ist sehr wichtig!)_.

Sowohl `elseif` als auch `else` sind optional, und es kann mehrere `elseif`-Blöcke geben. Das `end` ist jedoch erforderlich.

Es ist möglich, `if`-Anweisungen zu verschachteln, doch für die Lesbarkeit kann ein durchdachter Einsatz von Klammern, Einrückungen und Kommentaren helfen.

Die kürzeste Form einer `if`-Anweisung sieht etwa so aus:

```julia
if n < 0
    n = 0
end
```

Zur Erinnerung: Nur Ausdrücke, die zu `true` oder `false` ausgewertet werden, können als Bedingungen verwendet werden. Julia vermeidet bewusst jedes Konzept von „truthiness“, deshalb sind Nullwerte, leere Strings und leere Arrays _nicht_ gleichbedeutend mit `false`.

## Ternärer Operator

Eine einfache und häufige Situation ist, abhängig von einer Bedingung einen von zwei Werten auszuwählen.

Julia hat wie viele Sprachen einen ternären Operator, um das knapper zu machen.

Die Syntax ist `conditional ? value_if_true : value_if_false`.

Das vorige Beispiel kann man also auch so schreiben:

```julia
n = n < 0 ? 0 : n
```

Der Compiler verlangt keine Klammern, aber sie können die Lesbarkeit verbessern.
