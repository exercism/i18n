# Über

Ein String-Puffer ist eine effiziente Möglichkeit, einen großen String aufzubauen, indem du kleine Elemente aneinanderhängst. Anders als String ist eine Instanz von StringBuf nicht unveränderlich: Man kann sie als Argument an Funktionen übergeben, die sie verändern, indem sie weitere Werte anhängen.

```haxe
var a = new StringBuf();
a.add("Hello");
trace(a.toString()); // Hello
a.add("Haxe!");
trace(a.toString()); // HelloHaxe
```
