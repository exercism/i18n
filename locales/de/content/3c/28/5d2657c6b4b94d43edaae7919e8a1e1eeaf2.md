# Einführung

## Rekursion

Rekursive Funktionen sind Funktionen, die sich selbst aufrufen.

Eine rekursive Funktion braucht mindestens einen _Basisfall_ und mindestens einen _rekursiven Fall_.

Ein _Basisfall_ gibt einen Wert zurück, ohne die Funktion erneut aufzurufen. Ein _rekursiver Fall_ ruft die Funktion erneut auf und verändert dabei den Eingabewert so, dass er irgendwann dem Basisfall entspricht.

Sehr oft wird jeder Fall in eine eigene Funktionsklausel geschrieben.

```elixir
# base case
def count([]), do: 0

# recursive case
def count([_head | tail]), do: 1 + count(tail)
```
