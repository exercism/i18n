# Streng geheim

## Geschichte

Du kämpfst gegen Wirtschaftsspionage, mit Hilfe einer geheimen Informantin, die geheime Nachrichten durch ihren Code verschlüsselt.

## Aufgaben

In den folgenden Schritten implementiert der Lernende eine Funktion, um Nachrichten aus Quellcode zu entschlüsseln:

- Wandle Quellcode in einen AST um
- Parse einen einzelnen Knoten: Wenn der Knoten eine Funktionsdefinition ist, gib den Funktionsnamen zurück
- Erweitere das Parsen: Gib nur so viele Zeichen zurück, wie die Funktion Argumente erhält
- Entschlüssele die Nachricht: Durchlaufe alle Knoten und verkette die zurückgegebenen Strings
