## Typ-Aliase

In Gleam kannst du mit einem Typ-Alias einem vorhandenen Typ, der sonst umständlich zu schreiben wäre, einen praktischen Namen geben.

```gleam
pub type Headers =
  List(#(String, String))

pub fn html_headers() -> Headers {
  [
    #("content-type", "text/html"),
    #("x-frame-options", "DENY"),
  ]
}
```

Wenn es mit `pub type` geschrieben wird, kann das Alias außerhalb des Moduls verwendet werden, in dem es definiert ist. Wenn `pub` weggelassen wird, ist das Alias privat und kann nicht in anderen Modulen referenziert werden.
