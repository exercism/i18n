# Überblick

Die [Methodenüberladung][method-overloading] ist ein zentrales Konzept in Java: Sie erlaubt es einer Klasse, mehr als eine Methode mit demselben Namen zu haben, solange jede Methode eine andere Parameterliste hat.
Dieses Feature ist ein grundlegender Bestandteil der objektorientierten Programmierung in Java und bietet eine Möglichkeit, ähnliche Operationen mit unterschiedlichen Typen oder Anzahlen von Eingabewerten auszuführen.
Die Methodenüberladung verbessert die Lesbarkeit und die Struktur des Codes, weil Methoden mit ähnlicher Funktion denselben Namen tragen dürfen.
Wichtig ist, dass die Überladung durch die Signatur der Methode bestimmt wird. Zur Signatur gehören der Methodenname und die Parameterliste.

## Die wichtigsten Punkte

- **Die Signatur entscheidet**: Der Rückgabetyp ist nicht Teil der Methodensignatur. Nur den Rückgabetyp einer Methode zu ändern, ist also keine Überladung.
- **Unterschiedliche Parameter**: Überladene Methoden müssen sich in der Anzahl oder im Typ der Parameter unterscheiden.
- **Verwendung**: Die Überladung wird oft genutzt, um eine Methode mit unterschiedlichen Typen von Eingabewerten intuitiver verwenden zu können.

## Beispiele für Methodenüberladung

Schauen wir uns eine Klasse `Calculator` an, die Zahlen addieren kann.
Durch die Überladung sind verschiedene Arten der Addition möglich:

```java
public class Calculator {

    public int add(int a, int b) {
        return a + b;
    }

    public double add(double a, double b) {
        return a + b;
    }

    public int add(int a, int b, int c) {
        return a + b + c;
    }
}
```

## Bewährte Vorgehensweisen

- **Klarheit**: Überladene Methoden sollten so verwendet werden, dass der Code intuitiver wird.
  - Das Verhalten überladener Methoden sollte zusammenhängen und einheitlich sein.
- **Vermeide Mehrdeutigkeit**: Achte darauf, dass jede überladene Methode einen klaren Zweck hat und dass sich die Parameterlisten deutlich genug unterscheiden, um Verwechslungen zu vermeiden.
- **Dokumentation**: Dokumentiere jede Version der überladenen Methoden ordentlich.
  - Eine klare Dokumentation hilft anderen Entwicklern zu verstehen, wozu jede Variante der Methode dient und wie sie verwendet wird.
- **Einheitliche Rückgabetypen**: Rückgabetypen dürfen bei überladenen Methoden zwar unterschiedlich sein, aber es ist generell gute Praxis, sie nach Möglichkeit einheitlich zu halten, um Verwirrung zu vermeiden.
- **Begrenze die Überladung**: Vermeide es, die Methodenüberladung zu übertreiben.
  - Zu viel Überladung macht den Code schwerer lesbar und schwerer zu pflegen.

## Fazit

Die Methodenüberladung ist ein mächtiges Feature in Java. Richtig eingesetzt, verbessert sie die Lesbarkeit und die Flexibilität deines Codes deutlich.
Sie macht Methoden vielseitiger und anpassungsfähiger an unterschiedliche Kontexte, wodurch deine Java-Programme modularer und besser wartbar werden.
