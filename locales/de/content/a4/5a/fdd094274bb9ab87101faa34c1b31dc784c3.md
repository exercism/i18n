# Null

Null ist ein primitiver Werttyp mit nur einem Wert: `null`.
Null wird oft verwendet, um Nichts darzustellen.
Es gilt als „falsey“, unterscheidet sich aber von `false` und anderen falsey-Werten.

```php
<?php

is_null(null); // => true
isset(null); // => false

null == true; // => false
null === true; // => false

null == false; // => true
null === false; // => false
```

## Arbeiten mit Null-Werten

In PHP können Null-Werte häufig zu Fehlern führen, da sie oft anstelle eines Fehlerzustands zurückgegeben werden oder um Nichts darzustellen.
Um Fehler zu vermeiden, ist oft ein „Null-Check“ erforderlich, um sicherzustellen, dass der Wert nicht null ist, bevor man damit arbeitet.

```php
<?php

$value = null;

$value->doSomething(); // throws an error as a null value is not an object instance.

if (!is_null($value)) {
    $value->doSomething(); // succeeds
}
```

Wiederholte Null-Checks können fehleranfällig sein, deshalb bietet PHP zwei Operatoren für die Arbeit mit Null-Werten: den null-sicheren Zugriffsoperator `?->` und den Null-Koaleszenz-Operator `??`.

```php
<?php

$value = null;
$result = $value?->doSomething(); // => return null rather than error
$result = $result ?? "default"; // => "default" is assigned to $result
```
