# Enums

Enums sind ein Cairo-Datentyp, mit dem du eine Menge vordefinierter Varianten definierst, um die Lesbarkeit und Sicherheit des Codes zu verbessern.
In Cairo können `enum`-Varianten deklariert werden, die verschiedene Datentypen enthalten (Ganzzahlen, Structs, Tupel, andere Enums usw.).

Der folgende Codeausschnitt zeigt, wie Enums definiert werden können:

```rust
#[derive(Drop)]
enum Direction {
    North,
    East,
    South,
    West,
}
```

Das oben deklarierte `Direction`-Enum ist ein einfaches Enum mit vier Varianten: `North`, `East`, `South` und `West`.
Die Namenskonvention ist PascalCase für Enum-Varianten.
Jede Variante repräsentiert einen eigenen Wert des `Direction`-Enum-Typs.
Jede Variante in diesem konkreten Enum-Beispiel hat keinen zugehörigen Wert und kann mit dieser Syntax instanziiert werden:

```rust
let direction = Direction::North;
```

Unten siehst du dasselbe `Direction`-Enum, aber mit Varianten, die zugehörige Werte haben, die den genauen Grad der Richtung speichern:

```rust
#[derive(Drop)]
enum Direction {
    North: u128,
    East: u128,
    South: u128,
    West: u128,
}
```

In diesem Beispiel ist klar, dass jede Variante im `Direction`-Enum einen zugehörigen Wert vom Typ `u128` hat.
Diese Art von Enum kann wie folgt instanziiert werden:

```rust
let direction = Direction::North(10);
```

## Komplexes Enum-Beispiel mit benutzerdefinierten Typen

Ein Enum kann mit einer Kombination verschiedener Datentypen als Varianten deklariert werden.
Im folgenden Beispiel ist `Action` ein komplexes Enum, das eine Sammlung von `Quit`, `Direction`, `SendMessage`, `ChangeAvatar` und `ProfileState` als Varianten enthält.

```rust
#[derive(Drop)]
struct Move {
    up: u32,
    down: u32,
    right: u32,
    left: u32,
}

#[derive(Drop)]
enum UserCommand {
    Login,
    UpdateProfile,
    Logout,
}

#[derive(Drop)]
enum Action {
    Quit, //  variant with no associated value
    Direction: Move, // variant with the `Move` struct associated value
    SendMessage: felt252, // a single felt252 variant
    ChangeAvatarColor: (u8, u8, u8), // variant with the tuple of three associated values
    ProfileState: UserCommand // variant with an enum associated value
}
```

## Trait-Implementierungen für Enums

In Cairo können Traits für benutzerdefinierte Enums definiert und implementiert werden.
So kannst du Methoden und Attribute definieren, die mit einem Enum verknüpft sind.
Unten siehst du ein Beispiel, in dem wir ein `Message`-Enum definieren und einen `Processing`-Trait dafür implementieren:

```rust
#[derive(Drop)]
enum Message {
    Quit,
    Echo: felt252,
    Move: (u128, u128),
}

trait Processing {
    fn process(self: Message);
}

impl ProcessingImpl of Processing {
    fn process(self: Message) {
        match self {
            Message::Quit => { println!("quitting") },
            Message::Echo(value) => { println!("echoing {}", value) },
            Message::Move((x, y)) => { println!("moving from {} to {}", x, y) },
        }
    }
}
```

So könnte der Trait verwendet werden, um eine `Quit`-Nachricht zu verarbeiten:

```rust
let msg: Message = Message::Quit;
msg.process(); // prints "quitting"
```

In vielen Situationen sind Enums nützlich, besonders in Kombination mit dem `match`-Ablauf, wie oben in der Trait-Implementierung verwendet.
Mehr über den `match`-Ablauf erfährst du in [The Cairo Book][match].
