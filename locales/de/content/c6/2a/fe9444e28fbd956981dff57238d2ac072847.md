# Einführung

## Erweiterungsmethoden

Mit Erweiterungsmethoden kannst du vorhandenen Typen Methoden hinzufügen, ohne einen neuen abgeleiteten Typ zu erstellen, neu zu kompilieren oder den ursprünglichen Typ anderweitig zu verändern. Sie werden als statische Methoden definiert, aber mit der Syntax von Instanzmethoden aufgerufen. Ihr erster Parameter wird vom `this`-Modifizierer eingeleitet und gibt an, auf welchem Typ die Methode arbeitet; in den Gültigkeitsbereich kommen sie auf Namespace-Ebene.

```csharp
public static int WordCount(this string str)
{
    return str.Split().Length;
}

"Hello World".WordCount();
// => 2
```
