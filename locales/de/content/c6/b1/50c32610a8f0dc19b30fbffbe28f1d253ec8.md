# Einführung

In JavaScript ermöglichen _Template-Strings_ das Einbetten von Ausdrücken in Strings, was man auch als String-Interpolation bezeichnet.
Diese Funktionalität erweitert die des eingebauten globalen Objekts [`String`][string-reference].

Du kannst Template-Strings in JavaScript erstellen, indem du Text in Backticks einschließt.
Sie erlauben nicht nur, dass der Text Zeilenumbrüche und andere Sonderzeichen enthält, sondern du kannst auch Variablen und andere Ausdrücke einbetten.

```javascript
const num1 = 1;
const num2 = 2;

`Adding ${num1} and ${num2} gives ${num1 + num2}.`;
// => Adding 1 and 2 gives 3.
```

Im obigen Beispiel werden Backticks - (<code>\`\`</code>) - verwendet, um einen Template-String darzustellen. Der `${...}` ist der Platzhalter, der für die Ersetzung verwendet wird.
Alle Nicht-String-Typen werden _implizit_ in Strings umgewandelt.
Dieses Thema wird im Konzept [Typkonvertierung][type-conversion-concept] behandelt.
Alle Arten von Ausdrücken können mit Template-Strings verwendet werden.

```javascript
const track = 'JavaScript';

`This track on exercism.org is ${track.toUpperCase()}.`;
// => This track on exercism.org is JAVASCRIPT.
```

Wenn du Strings über mehrere Zeilen formatieren möchtest:

```javascript
`This is an example of using template
strings to accomplish multiple
lines`;
```

Mit den verfügbaren Ersetzungsmöglichkeiten kannst du auch Logik in den Prozess einbringen, um zu bestimmen, wie der ausgegebene String aussehen soll.

Ein Beispiel dafür ist das Einbetten eines [ternären Operators][ternary-operator].
Dieser Operator ist eine Kurzform für das Schreiben einer `if/else`-Anweisung.
Die Syntax lautet `condition ? consequent-expression : alternative-expression`.
Wenn die Bedingung truthy ist, wird der Operand auf der linken Seite des Doppelpunkts zurückgegeben.
Andernfalls ist das Ergebnis des ternären Ausdrucks der Operand auf der rechten Seite des Doppelpunkts.

```javascript
const grade = 95;

`You have ${grade > 90 ? 'passed' : 'failed'} the exam.`;
// => You have passed the exam.
```
