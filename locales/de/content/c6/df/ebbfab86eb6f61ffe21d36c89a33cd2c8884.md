# Einführung

Swift bietet in seiner Standardbibliothek eine Menge Funktionalität. Du kannst aber noch viele weitere Features nutzen, indem du externe Bibliotheken und Frameworks importierst.
Diese Module können direkt aus dem Swift-Projekt stammen (wie der [Swift Argument Parser][argument-parser]), aus Apples Plattform-Frameworks (wie [Foundation][apple-foundation] und das [Network Framework][network-framework]) oder aus Open-Source-Bibliotheken von Drittanbietern (wie [SwiftyBeaver][swifty-beaver]).

Kernmodule wie Foundation, eine der am häufigsten verwendeten Bibliotheken in Swift, sind Teil der Swift-Toolchain.
Bibliotheken von Drittanbietern musst du erst deiner Projektkonfiguration hinzufügen (zum Beispiel mit dem Swift Package Manager), bevor du sie importieren kannst.

Um ein Modul zu importieren, schreibst du das Schlüsselwort `import`, gefolgt vom Namen des Moduls:

```swift
import Foundation
```

Wenn du ein Modul importierst, stehen seine Typen, Methoden und Funktionen in deinem Code zur Verfügung.
Wenn du zum Beispiel Foundation importierst, wird `String` um nützliche Hilfsmethoden wie `components(separatedBy:)` erweitert.

Üblicherweise stehen `import`-Anweisungen am Anfang einer Swift-Datei, damit jeder, der den Code liest, die Abhängigkeiten sofort sieht.
