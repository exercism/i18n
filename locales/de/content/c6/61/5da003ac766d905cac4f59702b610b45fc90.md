# Hinweise

## 1. Erzeuge eine ID-Nummer

- Die Funktion soll eine weitere Funktion zurückgeben.
- Die zurückgegebene Funktion muss auf den Parameter `day` zugreifen.

## 2. Schütze die geborgenen geheimen Pläne mit einem geheimen Passwort

- Die zurückgegebene Funktion hat nur einen Parameter.
- Strings kannst du mit [Gleichheit][equality] vergleichen.

## 3. Finde das geheime Passwort

- Rufe die Funktion des Minions mit einer anderen Funktion auf, die unseren Teil des Algorithmus ausführt.
