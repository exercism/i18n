# Anleitung

Das Unternehmen, für das du arbeitest, steht kurz vor der Markteinführung seines brandneuen Smartphones **Smarty 5**. Es bietet ein brandneues Kamerasystem, ein neues Design und einen revolutionären neuen Prozessor, auf dem ein neues Betriebssystem namens **smartyOS** läuft.

Der neue Prozessor ist leistungsstark genug, um sicherere Passwörter zu verarbeiten als je zuvor, und das Unternehmen hat beschlossen, das zu seinem Vorteil zu nutzen.
Es hat dich gebeten, ein Passwort-Sperrsystem für das Telefon zu implementieren, mit dem der Benutzer ein Passwort festlegen und dann prüfen kann, ob ein eingegebenes Passwort korrekt ist.

~~~~exercism/caution
Das in dieser Übung verwendete Passwortsystem ist nicht sicher und dient nur zu Lernzwecken.
Es sollte **NICHT** in echten Anwendungen verwendet werden.
~~~~

## 1. Passwort festlegen

Das Telefon erlaubt es Benutzern, verschiedene Arten von Passwörtern zu verwenden, von einem einfachen Ziffernpasswort über ein sichereres alphanumerisches Passwort bis hin zu einem Passwort, das ihren Fingerabdruck speichert.

Diese verschiedenen Passwortarten verwenden unterschiedliche Typen: Das Ziffernpasswort verwendet einen `Int32`, das alphanumerische Passwort einen `String` und das Fingerabdruck-Passwort einen `Float64`.

Implementiere die Klasse `PasswordLock` mit einem Initialisierer, der einen der drei Passworttypen als Argument entgegennimmt und ihn in einer Instanzvariable namens `@password` speichert.

```crystal
password_lock = PasswordLock.new(1234)
# => #<PasswordLock:0x7f8e1b8c0b80 @password=1234>
```

## 2. Passwort verschlüsseln

Das Unternehmen hat beschlossen, das Passwort zu verschlüsseln, damit es nicht im Klartext gespeichert wird, und hat dich gebeten, eine Methode zum Verschlüsseln zu implementieren.

Jeder Passworttyp hat seine eigene Art der Verschlüsselung:

- `Int32`-Passwort: Das Passwort wird durch zwei geteilt und auf die nächste Ganzzahl gerundet.
- `String`-Passwort: Das Passwort wird umgekehrt.
- `Float64`-Passwort: Das Passwort wird mit vier multipliziert.

Implementiere eine Instanzmethode namens `encrypt`, die keine Argumente entgegennimmt und die Instanzvariable `@password` so verändert, dass sie verschlüsselt ist.

```crystal
password_lock = PasswordLock.new(1234)
# => #<PasswordLock:0x7f8e1b8c0b80 @password=1234>

password_lock.encrypt
# => #<PasswordLock:0x7f8e1b8c0b80 @password=617>
```

## 3. Prüfen, ob ein Passwort korrekt ist

Das Unternehmen hat dich außerdem gebeten, eine Methode zu implementieren, die prüft, ob ein eingegebenes Passwort korrekt ist.

Die Methode soll `nil` zurückgeben, wenn das Passwort falsch ist, und `"Unlocked"`, wenn das Passwort korrekt ist.

Implementiere eine Instanzmethode namens `unlock?`, die das zu prüfende Passwort als Argument entgegennimmt.
Die Methode sollte `nil` zurückgeben, wenn das Passwort falsch ist, und `"Unlocked"`, wenn das Passwort korrekt ist.

```crystal
password_lock = PasswordLock.new(1234)
password_lock.encrypt
password_lock.unlock?(1234)
# => "Unlocked"
```
