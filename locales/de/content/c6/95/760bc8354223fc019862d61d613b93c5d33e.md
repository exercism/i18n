# Über

Eine Keyword-Liste ist eine Liste von [Tupeln][exercism-tuples] der Form `{key, value}`. Es gibt zwei Möglichkeiten, eine Keyword-Liste zu schreiben:

```elixir
# concise
[month: "April", year: 2018]

# explicit
[{:month, "April"}, {:year, 2018}]
```

## Schlüssel müssen Atome sein

Nicht jede Liste aus 2-Tupeln ist eine Keyword-Liste. Die Schlüssel müssen Atome sein:

```elixir
Keyword.keyword?([{"month", "April"}])
# => false
```

Wenn du im Schlüssel andere Zeichen als Buchstaben, Zahlen und `_` verwenden möchtest, musst du ihn in Anführungszeichen setzen. Dadurch wird er aber nicht zu einem String. Er ist weiterhin ein Atom.

[//]: # (elixir-formatter-disable-next-block)

```elixir
Keyword.keyword?(["day of week": "Monday"])
# => true
```

## Schlüssel können sich wiederholen

Schlüssel in einer Keyword-Liste können sich wiederholen, und die [Schlüssel-Wert-Paare sind geordnet][keyword-duplicate-keys-and-ordering]. Wenn du versuchst, einen einzelnen Wert unter einem bestimmten Schlüssel abzurufen, bekommst du den ersten Wert. Alle weiteren Werte unter demselben Schlüssel werden stillschweigend ignoriert.

```elixir
list = [month: "April", month: "May"]

Keyword.get_values(list, :month)
# => ["April", "May"]

Keyword.get(list, :month)
# => "April"
```

Auch Keyword-Listen unterstützen das [_Access-Verhalten_][access-behaviour].

```elixir
list[:month]
# => "April"
```

## Keyword-Listen als Optionen

Die Eigenschaften von Keyword-Listen machten sie zum Standardmechanismus, um Optionen an Funktionen in Elixir zu übergeben.

Als du etwas über `if` gelernt hast, bist du auf eine besondere, kürzere Syntax gestoßen:

```elixir
if age >= 16, do: "beer", else: "no beer"
```

Das sieht vielleicht so aus, als würde `if` zwei Argumente akzeptieren, aber das Paar `do:` und `else:` ist tatsächlich ein einziges Argument, nämlich eine Keyword-Liste. Derselbe Code ließe sich auch so schreiben:

[//]: # (elixir-formatter-disable-next-block)

```elixir
if age >= 16, [do: "beer", else: "no beer"]
# or
if age >= 16, [{:do, "beer"}, {:else, "no beer"}]
```

Die Verwendung von Keyword-Listen als Funktionsoptionen ist so üblich, dass Elixir es dir erlaubt, [die eckigen Klammern wegzulassen, wenn die Keyword-Liste das letzte Argument ist][keyword-call-syntax], das an eine Funktion übergeben wird.

Da Tupel, Listen, Maps und andere in der Elixir-Syntax genauso behandelt werden wie Funktionsaufrufe, gilt diese Eigenschaft auch für sie.

```elixir
[1, 2, three: 3]
# => [1, 2, {:three, 3}]
```

## Musterabgleich

Um mit der knappen Syntax einen Musterabgleich auf einer Keyword-Liste durchzuführen, müsstest du alle Schlüssel in der richtigen Reihenfolge angeben. Damit ist der Musterabgleich keine naheliegende Wahl für die Arbeit mit Keyword-Listen. Verwende stattdessen das Modul [`Keyword`][keyword] oder das [_Access-Verhalten_][access-behaviour].

```elixir
[month: month] = [month: "April", year: 2018]
# => ** (MatchError) no match of right hand side value: [month: "April", year: 2018]

[year: year, month: month] = [month: "April", year: 2018]
# => ** (MatchError) no match of right hand side value: [month: "April", year: 2018]
```

## Keyword-Listen vs. Maps

|                    | Keyword-Liste                 | Map                                    |
| ------------------ | ----------------------------- | -------------------------------------- |
| Schlüsseltyp       | Atome                         | Beliebig, Mischen in einer Map möglich |
| Doppelte Schlüssel | Ja                            | Nein                                   |
| Schlüssel geordnet | Ja                            | Nein                                   |
| Zugriff            | `list[:key]`, `Keyword.get/2` | `map.key`, `map[:key]`, `Map.get/2`    |
| Zugriffszeit       | Linear                        | Logarithmisch                          |
| Musterabgleich     | Nicht sehr nützlich           | Nützlich                               |

Schnellere Zugriffszeit, flexibler Schlüsseltyp und ein nützlicher Musterabgleich machen Maps in den meisten Fällen zur Standardwahl.

Verwende Keyword-Listen, wenn du nicht viele Daten hast, aber doppelte Schlüssel oder Schlüssel in einer bestimmten Reihenfolge brauchst.
