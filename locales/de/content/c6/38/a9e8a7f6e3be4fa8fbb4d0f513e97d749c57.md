## 1. Verwandle Code in Daten

- Es gibt eine [eingebaute Funktion][doc-code-string-to-quoted], die einen String mit Code in einen AST umwandelt.

## 2. Einen einzelnen AST-Knoten parsen

- Untersuche die Ausgabe von [`quote`][doc-quote], um dich damit vertraut zu machen, wie ASTs für bestimmte Code-Schnipsel aussehen.
- Die Operationen, die eine Funktion definieren, sind `:def` und `:defp`.
- Die Operation ist das erste Element eines dreielementigen AST-Knoten-Tupels.
- Das zweite Element im Tupel kannst du in dieser Übung komplett ignorieren.
- Das dritte Element im Tupel ist die Argumentliste der Operation, die die Funktion definiert.
- Das erste Element dieser Liste ist ein Tupel mit dem Namen und den Argumenten der Funktion, und das zweite Element ist der Funktionskörper.

## 3. Den Teil der geheimen Nachricht aus der Funktionsdefinition dekodieren

- Untersuche die Ausgabe von [`quote`][doc-quote], um dich damit vertraut zu machen, wie ASTs für bestimmte Code-Schnipsel aussehen.
- Der AST-Knoten, der den Namen der Funktion enthält, enthält als drittes Element auch die Argumentliste der Funktion.
- Die Stelligkeit einer Funktion ist die Länge ihrer Argumentliste.
- Es gibt eine [eingebaute Funktion im `String`-Modul][string-slice], die die ersten `n` Zeichen aus einem String holen kann.
- Eine Funktion ohne Argumente, die ohne Klammern geschrieben wird, hat als Argument keine Liste, sondern ein Atom.

## 4. Die Dekodierung für Funktionen mit Guards korrigieren

- Untersuche die Ausgabe von [`quote`][doc-quote], um dich damit vertraut zu machen, wie ASTs für bestimmte Code-Schnipsel aussehen.
- Wenn eine Funktion einen Guard hat, ist das dritte Element im Tupel für die Operation `:def/:defp` etwas anders.
- Dieses dritte Element ist eine Liste mit zwei Elementen: Das erste ist das Tupel für die Operation `:when`, und das zweite ist der Funktionskörper.
- Die Argumente der Operation `:when` sind eine zweielementige Liste, bei der das erste Argument der Name der Funktion und das zweite der Guard-Ausdruck ist.

## 5. Die vollständige geheime Nachricht dekodieren

- Verwende die Funktion `to_ast/1`, die du in der ersten Aufgabe implementiert hast, um den AST zu erzeugen.
- Es gibt eine [eingebaute Funktion][macro-prewalk], die jeden Knoten in einem AST mit einem Akkumulator besuchen kann.
- Verwende die Funktion `decode_secret_message_part/2`, die du in den vorherigen Aufgaben implementiert hast, um die Prewalk-Funktion auf den AST anzuwenden.
- Um den Akkumulator am Ende umzudrehen und in einen String umzuwandeln, frische dein Wissen über das [`Enum`-Modul][enum] auf.
