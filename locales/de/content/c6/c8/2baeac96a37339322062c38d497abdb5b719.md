# Hinweise

## 1. Die erste Karte holen

- [Dieser Artikel][mdn-destructuring] bietet einen guten Überblick über die Destrukturierung von Arrays. Ein Beispiel für eine einfache Variablenzuweisung findest du im Abschnitt „Basic Array Destructuring“.

## 2. Die zweite Karte holen

- Du kannst Platzhalter verwenden, um einen oder mehrere Werte im Array zu ignorieren.
- Ein Beispiel findest du [auf MDN][mdn-destructuring-ignore-value].

## 3. Die beiden Karten tauschen

- Es ist möglich, zwei Werte in einem einzigen Destrukturierungsausdruck zu tauschen.
- Ein Beispiel findest du [auf MDN][mdn-destructuring-swapping].

## 4. Drei Karten verschieben

- Es ist möglich, die Position von drei Werten in einem einzigen Destrukturierungsausdruck zu ändern.
- Das ist dasselbe wie das Tauschen von zwei Werten, nur mit drei (oder mehr).

## 5. Den benannten Stapel auswählen

- Objekte lassen sich genauso destrukturieren wie Arrays.
- Ein Beispiel findest du [auf MDN][mdn-object-destructuring-basic-assignment].

## 6. Die benannten Stapel tauschen

- Wenn eine Eigenschaft aus einem Objekt extrahiert wird, kann sie mit einer bestimmten Syntax umbenannt werden.
- Ein Beispiel findest du [auf MDN][mdn-object-destructuring-object-rename].
