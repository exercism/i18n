# Einführung

Das Fehlersystem von Factor besteht aus drei Teilen: `throw`, um einen Fehler zu melden, `recover`, um einen zu behandeln, und `ERROR:`, um deine eigene Fehlerart zu definieren.

## `throw`

`throw` (in [`kernel`][kernel]) löst einen Fehler aus. Das Argument kann *jeder* beliebige Wert sein, egal ob String, Zahl oder Tupel, und es wird zu dem Fehler, den du später untersuchen kannst:

```factor
! DOCTEST: SKIP
"file not found" throw
```

`throw` kehrt nicht zurück; der Rest des aktuellen Words wird übersprungen.

## `recover`

`recover` (in [`continuations`][continuations]) ist das try/catch von Factor. Es nimmt eine *try*-Quotation und eine *recovery*-Quotation:

```
recover ( try recovery -- )
```

Wenn `try` ohne Fehler durchläuft, wird `recovery` ignoriert. Wenn `try` einen Fehler auslöst, wird der Fehler auf den Stack gelegt und `recovery` ausgeführt:

```factor
[ "boom" throw ] [ drop "caught" ] recover .
! => "caught"

[ "ok" ] [ drop "never runs" ] recover .
! => "ok"
```

`when` aus [`kernel`][kernel] ist der natürliche Begleiter: Es führt eine Quotation nur dann aus, wenn der oberste Wert auf dem Stack wahr ist:

```factor
: check-positive ( n -- )
    0 < [ "negative!" throw ] when ;
```

## `ERROR:`

`ERROR:` definiert eine Tupelklasse *und* ein Word, das eine neue Instanz erzeugt und sie auslöst:

```factor
! DOCTEST: SKIP
ERROR: not-found path ;

"/missing" not-found
! throws T{ not-found { path "/missing" } }
```

Ein Fehler ohne Slots ist einfach `ERROR: name ;`. Der Aufruf von `name` löst eine leere Instanz aus. Tupel, die mit `ERROR:` definiert werden, bringen ein Klassenprädikat `name?` mit, mit dem du prüfen kannst, ob ein gefangener Fehler von diesem Typ war.

## Slots wieder auslesen

Ein gefangener Fehler ist einfach ein Tupel, deshalb bringt jeder Slot von `ERROR:` denselben automatisch generierten `slot>>`-Reader mit wie jedes andere Tupel.

```factor
! DOCTEST: SKIP
{
    T{ not-found { path "/a" } }
    T{ not-found { path "/b" } }
}
[ path>> ] map .   ! => { "/a" "/b" }
```
