# Einführung

In Swift kannst du [Funktionen innerhalb anderer Funktionen definieren][nested-functions]. Diese werden als **verschachtelte Funktionen** bezeichnet.

Verschachtelte Funktionen werden häufig als private Hilfsfunktionen eingesetzt, die bestimmte Aufgaben für die umgebende Funktion übernehmen, ohne den äußeren Gültigkeitsbereich zu überladen:

```swift
func makeNumber(_ number: Int) -> Int {
    func double(_ x: Int) -> Int {
        x * 2
    }

    func increment(_ x: Int) -> Int {
        x + 1
    }

    return number.isMultiple(of: 2) ? increment(double(number)) : double(number)
}

print(makeNumber(3)) // Prints 6
print(makeNumber(4)) // Prints 9
```

Verschachtelte Funktionen verhalten sich wie normale Funktionen, aber ihre Sichtbarkeit ist auf den Körper der umgebenden Funktion beschränkt.
