# Einführung

## Datum und Uhrzeit

Das in Java 8 eingeführte Paket `java.time` enthält mehrere Klassen, um mit Datum und Uhrzeit zu arbeiten.

### `LocalDate`

Die Klasse `java.time.LocalDate` repräsentiert ein Datum ohne Zeitzone im [ISO-8601-Kalendersystem][iso-8601], zum Beispiel `2007-12-03`:

```java
LocalDate date = LocalDate.of(2007, 12, 3);
```

Datumsangaben lassen sich mit anderen Datumsangaben vergleichen:

```java
LocalDate date1 = LocalDate.of(2007, 12, 3);
LocalDate date2 = LocalDate.of(2007, 12, 4);

date1.isBefore(date2);
// => true

date1.isAfter(date2);
// => false
```

Eine `LocalDate`-Instanz hat Getter, mit denen du einzelne Zeitanteile daraus abrufen kannst:

```java
LocalDate date = LocalDate.of(2007, 12, 3);

date.getDayOfMonth();
// => 3
```

Eine `LocalDate`-Instanz hat Methoden, mit denen du Zeiteinheiten hinzufügen kannst:

```exercism/note
Diese Methoden geben eine _neue_ `LocalDate`-Instanz zurück und aktualisieren die bestehende Instanz nicht, da die Klasse `LocalDate` unveränderlich ist.
```

```java
LocalDate date = LocalDate.of(2007, 12, 3);

date.plusDays(3);
// => 2007-12-06
```

### `LocalDateTime`

Die Klasse `java.time.LocalDateTime` repräsentiert einen Zeitpunkt aus Datum und Uhrzeit ohne Zeitzone im [ISO-8601-Kalendersystem][iso-8601], zum Beispiel `2007-12-03T10:15:30`:

```java
LocalDateTime datetime = LocalDateTime.of(2007, 12, 3, 10, 15, 30);
```

Du kannst eine `LocalDate`-Instanz in einen `LocalDateTime` umwandeln:

```java
LocalDate date = LocalDate.of(2007, 12, 3);
LocalDateTime datetime = date.atTime(10, 15, 30);
datetime.toString();
// => "2007-12-03T10:15:30"
```

### Datums- und Uhrzeitangaben formatieren

Sowohl `LocalDate` als auch `LocalDateTime` verwenden die Standardnotation nach [ISO-8601][iso-8601], wenn sie in einen `String` umgewandelt oder daraus gelesen werden.

```java
LocalDateTime datetime = LocalDateTime.of(2007, 12, 3, 10, 15, 30);
LocalDateTime parsed = LocalDateTime.parse("2007-12-03T10:15:30");

datetime.isEqual(parsed);
// => true
```

Es ist nicht möglich, ein `LocalDate` oder `LocalDateTime` auf diese Weise mit einem anderen Format aus einem `String` zu parsen.
Um Datumsangaben stattdessen mit einem eigenen Format zu formatieren, solltest du den `java.time.format.DateTimeFormatter` verwenden:

```java
DateTimeFormatter parser = DateTimeFormatter.ofPattern("dd/MM/yyyy");
LocalDate date = LocalDate.parse("03/12/2007", parser);

DateTimeFormatter printer = DateTimeFormatter.ofPattern("MMMM d, yyyy");
printer.format(date);
// => "December 3, 2007"
```

Beim Erstellen des eigenen Formats kann auch ein Locale angegeben werden, um für verschiedene Regionen zu formatieren und zu parsen:

```java
DateTimeFormatter.ofPattern("MMMM d, yyyy", Locale.FRENCH).format(date);
// => décembre 3, 2007

DateTimeFormatter.ofPattern("MMMM d, yyyy", Locale.of("pt")).format(date);
// => dezembro 3, 2007
```

[iso-8601]: https://en.wikipedia.org/wiki/ISO_8601
