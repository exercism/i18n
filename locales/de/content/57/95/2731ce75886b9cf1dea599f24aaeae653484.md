# Ergänzung zu den Anweisungen

## Register

| Register | Verwendung | Typ      | Beschreibung                    |
| -------- | ---------- | -------- | ------------------------------- |
| `$a0`    | Eingabe    | Adresse  | Array mit Buchwörtern           |
| `$a1`    | Eingabe    | Ganzzahl | Anzahl der Bücher               |
| `$v0`    | Ausgabe    | Ganzzahl | Preis in Cent                   |
| `$t0-9`  | temporär   | beliebig | für temporäre Speicherung       |
