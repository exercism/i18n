# Ergänzung zu den Anweisungen

## Ausgabeformat

Gib den Diamanten als nullterminierten String aus, mit einem Zeilenumbruch am Ende jeder Zeile.

Eine Beispielausgabe wäre `"  A  \n B B \nC   C\n B B \n  A  \n"`

## Register

| Register | Verwendung   | Typ     | Beschreibung                  |
| -------- | ------------ | ------- | ----------------------------- |
| `$a0`    | Eingabe      | Byte    | Buchstabe                     |
| `$a1`    | Ein-/Ausgabe | Adresse | nullterminierter Ergebnis-String |
| `$t0-9`  | temporär     | beliebig | für temporäre Speicherung     |
