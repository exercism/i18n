# Einführung

In Rust kann jeder Typ, der das Trait [`Iterator`](https://doc.rust-lang.org/stable/std/iter/trait.Iterator.html) implementiert, als Iterator behandelt werden.
Die eingebauten [`collections`](https://doc.rust-lang.org/std/collections/index.html) von Rust lassen sich mit den Methoden `iter`, `iter_mut` und `into_iter` in Iteratoren umwandeln.
Iteratoren bieten eine breite Palette an [mächtigen Methoden](https://doc.rust-lang.org/stable/std/iter/trait.Iterator.html#provided-methods) wie `collect`, `map`, `filter` und `fold`, mit denen du Operationen auf deinen Daten ausführen kannst.

```rust
use std::collections::HashMap;

let v = vec![0, 1, 2];

let mut iter = v.iter();

// Call next() to return the next value
assert_eq!(Some(&0), iter.next());
assert_eq!(Some(&1), iter.next());
assert_eq!(Some(&2), iter.next());
// Ahen None once it's over
assert_eq!(None, iter.next());

// Loop over iterators with built-in methods, such as `map` and `collect`
let w: HashMap<_, _> = v.into_iter().map(|x| (x, x + 1)).collect();
println!("{w:?}");
// => {1: 2, 0: 1, 2: 3}
```
