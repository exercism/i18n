# Anleitung

In dieser Übung arbeitest du mit Sparkonten.
Jedes Jahr wird der Kontostand deines Sparkontos anhand seines Zinssatzes aktualisiert.
Der Zinssatz, den deine Bank dir gewährt, hängt davon ab, wie viel Geld auf deinem Konto ist (dem Kontostand):

- 3,213 % für einen Kontostand von weniger als `0` Dollar (der Kontostand wird negativer).
- 0,5 % für einen Kontostand von mindestens `0` Dollar und weniger als `1000` Dollar.
- 1,621 % für einen Kontostand von mindestens `1000` Dollar und weniger als `5000` Dollar.
- 2,475 % für einen Kontostand von mindestens `5000` Dollar.

Du hast vier Aufgaben, die sich jeweils mit dem Kontostand und seinem Zinssatz befassen.

## 1. Berechne den Zinssatz

Implementiere die Funktion `interest_rate`, um den Zinssatz anhand des angegebenen Kontostands zu berechnen:

```cpp
interest_rate(200.75);
// => 0.5
```

## 2. Berechne die Zinsen

Implementiere die Funktion `yearly_interest`, um die Zinsen anhand des angegebenen Kontostands zu berechnen:

```cpp
yearly_interest(200.75):
// => 1.003750
```

## 3. Berechne die jährliche Aktualisierung des Kontostands

Implementiere die Funktion `annual_balance_update`, um die jährliche Aktualisierung des Kontostands zu berechnen und dabei den Zinssatz zu berücksichtigen:

```cpp
annual_balance_update(200.75);
// => 201.75375
```

## 4. Berechne die Jahre bis zum Erreichen des gewünschten Kontostands

Implementiere die Funktion `years_until_desired_balance`, um die Mindestanzahl an Jahren zu berechnen, die nötig ist, um den gewünschten Kontostand zu erreichen.
Dabei kommen jedes Jahr Zinsen zum Kontostand hinzu.
Das bedeutet, dass der Kontostand nach einem Jahr so aussieht: Anfangskontostand + Zinsen auf den Anfangskontostand.
Der Kontostand nach dem zweiten Jahr ist der Kontostand nach einem Jahr + Zinsen auf den Kontostand nach einem Jahr.
Und so weiter, bis der Kontostand des aktuellen Jahres größer oder gleich dem Zielkontostand ist.

```cpp
double balance {200.75};
double targetBalance {214.88};
years_until_desired_balance(balance, targetBalance)
// => 14
```

Beachte, dass der zurückgegebene Wert ein `int` ist.
