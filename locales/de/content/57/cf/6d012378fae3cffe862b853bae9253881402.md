# Java installieren

Zusätzlich zur Exercism CLI und deinem Lieblingstexteditor brauchst du für die Übungen des Java-Tracks von Exercism das **Java Development Kit** (JDK). Das JDK enthält sowohl eine Java Runtime _als auch_ Entwicklungswerkzeuge (allen voran den Java-Compiler).

Mittlerweile gibt es viele Varianten des JDK, von denen einige quelloffen sind. Bei Exercism empfehlen wir [Eclipse Temurin von Adoptium][adoptium].

## Unterstützte Java-Versionen

Der Java-Track von Exercism unterstützt Java 25 LTS und ältere Versionen.

## Eclipse Temurin installieren

Um Eclipse Temurin auf deinem System zu installieren, schau dir die hervorragende [Installationsanleitung][adoptium-installation-guide] an. Dort findest du Anleitungen, wie du das JDK mit deinem Lieblings-Paketmanager installierst, und außerdem Links zu herunterladbaren Installern für alle wichtigen Betriebssysteme.

## Java-IDEs

Für Java gibt es viele kostenlose IDEs. Hier sind ein paar beliebte Optionen:

- [IntelliJ IDEA Community Edition][intellij-idea]
- [Eclipse][eclipse]
- [Visual Studio Code mit der Java-Erweiterung][vscode-java]

## Nächste Schritte

Jetzt kann es mit dem Java-Track von Exercism losgehen!

Wie du startest, erfährst du unter „[Tests ausführen][exercism-java-tests-docs]“.
