# Anleitung

Lamont ist ein Lisp-Alien, das sein eigenes Videospiel schreiben möchte. Eine Aufgabe, bei der es deine Hilfe braucht, ist das Führen einer Highscore-Liste.

## 1. Die Highscore-Tabelle erstellen

Definiere eine Funktion `make-high-score-table`, die keine Argumente entgegennimmt und sich zu einer neuen, leeren Hash-Tabelle auswertet:

```lisp
(make-high-score-table) ; => #<HASH-TABLE :TEST EQL :COUNT 0 {1005A90103}>
```

## 2. Einen Spieler zur Tabelle hinzufügen

Um einen Spieler zur Tabelle hinzuzufügen, definiere eine Funktion `add-player`, die zwei Argumente entgegennimmt:
- die Highscore-Tabelle
- den Namen des Spielers als Keyword

Setze die Anfangspunktzahl des Spielers auf null.

```lisp
(add-player hash-table :louis) ; => 0
(add-player hash-table :lilly) ; => 0
```

## 3. Die Punktzahl eines Spielers festlegen

Um die Punktzahl für einen Spieler festzulegen, definiere eine Funktion `set-score`, die drei Argumente entgegennimmt:
- die Highscore-Tabelle
- den Namen des Spielers als Keyword
- die Punktzahl des Spielers als Ganzzahl

```lisp
(set-score hash-table :louis 1234) ; => 1234
```

## 4. Eine Punktzahl aus der Tabelle abrufen

Um die Punktzahl eines Spielers aus der Tabelle abzurufen, definiere eine Funktion `get-score`, die zwei Argumente entgegennimmt:
- die Highscore-Tabelle
- den Namen des Spielers als Keyword

Diese Funktion sollte sich zu der für den Spieler gespeicherten Punktzahl auswerten.
Wenn für diesen Spieler keine Punktzahl gespeichert ist oder der Spieler noch nicht in der Tabelle steht, sollte sie sich zu `0` auswerten.

```lisp
(get-score hash-table :louis)                         ; => 1234
(get-score hash-table :lilly)                         ; => 0
(get-score hash-table :not-a-character-in-this-story) ; => 0
```

## 5. Einen Spieler aus der Tabelle entfernen

Um einen Spieler aus der Highscore-Tabelle zu entfernen, definiere eine Funktion `remove-player`, die zwei Argumente entgegennimmt:
- die Highscore-Tabelle
- den Namen des Spielers als Keyword

Diese Funktion sollte Fälle problemlos behandeln, in denen der Spieler noch nicht zur Tabelle hinzugefügt wurde.
Wenn ein Spieler entfernt wurde, ist die Punktzahl, die man aus der Tabelle für ihn abruft, natürlich null.

```lisp
(set-score hash-table :louis 1234)           ; => 1234
(remove-player hash-table :louis)            ; => T
(get-score hash-table :louis)                ; => 0

(remove-player hash-table :not-in-the-table) ; => NIL
```
