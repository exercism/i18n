# Maps und Sets

Ein Array enthält Werte an nummerierten Positionen. Manchmal ist die hilfreiche Bezeichnung keine Zahl.

## Maps

Eine **Map** ordnet jedem **Schlüssel** ein **Ziel** zu. Schlägst du etwas über seinen Schlüssel nach, gibt dir die Map das zurück, was darunter abgelegt wurde.

`FMAP{K,T}` ist eine Map von Schlüsseln des Typs `K` zu Zielen des Typs `T`. Ein Verzeichnis, das den Namen eines Tieres mit seinem Lebensraum verknüpft, ist vom Typ `FMAP{STR,STR}`.

```sather
   guide ::= #FMAP{STR,STR};
   guide := guide.insert("emu", "grassland");
   guide.get("emu")               -- "grassland"
```

## Das Ergebnis immer wieder zuweisen

Schau dir noch einmal die mittlere Zeile an. `insert` gibt die Map mit dem zusätzlichen Paar darin zurück, und dieses Ergebnis musst du behalten:

```sather
   guide := guide.insert("emu", "grassland");     -- yes
   guide.insert("emu", "grassland");              -- no: the answer is lost
```

Das ist dieselbe Regel wie bei `FSTR`, und aus demselben Grund. Das Ergebnis ist meist genau die Map, die hineinging, an Ort und Stelle verändert; gelegentlich, wenn die Map keinen Platz mehr hat, ist es eine größere. Da du das nicht erkennen kannst, **verwende das Ergebnis und benutze den alten Namen nicht mehr.** Ein Name, der von vor einem `insert` übrig geblieben ist, kann veraltet sein oder gar keine verwendbare Map mehr bezeichnen.

Das bedeutet auch: Eine Map, die an eine Routine übergeben wird, ist vor ihr nicht sicher. Wenn das Original erhalten bleiben muss, schau dir `copy` auf der Konzeptseite an.

## Ist es da?

`has_ind` fragt, ob ein Schlüssel in der Map ist. Der Name ist die Kurzform von „has index“, wobei ein Index das ist, was diese Maps einen Schlüssel nennen.

```sather
   guide.has_ind("emu")           -- true
   guide.has_ind("moa")           -- false
```

Wenn du nach einem Schlüssel fragst, der nicht da ist, beschwert sich **nichts**. `get` gibt den leeren Wert für den Typ zurück – Null für ein `INT` und void für einen `STR` –, was später und an anderer Stelle schiefgehen wird. Also schau erst nach, bevor du den Wert holst:

```sather
   if guide.has_ind(animal) then
      return guide.get(animal);
   else
      return "Unknown";
   end;
```

## Sets

Ein **Set** enthält Werte ohne Wiederholungen und ohne Reihenfolge. `FSET{T}` ist ein Set von Werten des Typs `T`.

```sather
   seen ::= #FSET{STR};
   seen := seen.insert("emu");
   seen := seen.insert("emu");    -- already there; nothing changes
   seen.size                      -- 1
   seen.has("emu")                -- true
```

Wenn du etwas zweimal einfügst, bleibt eine einzige Kopie übrig. Dafür ist ein Set da: Dinge zu sammeln und dabei zu vergessen, wie oft jedes aufgetaucht ist.

`insert` auf einem Set gibt das Set zurück, das du von da an verwendest, genau wie bei einer Map, also weise es jedes Mal wieder zu.

## Wie viele

`.size` funktioniert bei beiden: wie viele Paare eine Map enthält und wie viele Werte in einem Set sind.
