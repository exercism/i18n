# Einführung

Mit `OpenStruct` kannst du auf einfache Weise ein Objekt aus einem `Hash` erstellen. 
Statt über `Hash`-Schlüssel darauf zugreifen zu müssen, erlaubt uns `OpenStruct`, Methoden zu verwenden, um Werte abzurufen und zu setzen.


```ruby
attributes = { name: "Jeremy Walker", age: 21, location: "Nomadic" }
person = OpenStruct.new(attributes)

person.name
#=> Jeremy Walker

person.location
#=> Nomadic

# Update the age
person.age = 35

# It sets correctly
person.age
#=> 35
```

Ein Vorteil dieses Ansatzes ist, dass wir eine Abkürzung nutzen können, wenn wir die Block-Syntax verwenden. 
In Situationen, in denen ein Block eine einzelne Methode aufruft, kannst du den Block durch `&:` gefolgt vom Methodennamen ersetzen. 
Zum Beispiel sind diese beiden Zeilen gleichbedeutend:

```ruby
people.sum { |person| person.age }
people.sum(&:age)
```

## Standardbibliothek

Alle Klassen, die du in vorherigen Übungen gesehen hast, waren Teil der Ruby-Kernbibliothek.

OpenStruct ist Teil der Ruby-Standardbibliothek (oft kurz „stdlib“ genannt): eine Sammlung von Klassen für die Arbeit mit Dingen wie Datumsangaben, JSON und Netzwerk.
Sie bietet außerdem einige nützliche Funktionen, mit denen du leichter mit deinem Code arbeiten kannst.

Wenn du Klassen verwendest, die nicht aus der Kernbibliothek stammen (dein eigener Code in anderen Dateien, Klassen aus der Standardbibliothek oder externe Abhängigkeiten), musst du sie mit der `require`-Methode importieren, bevor du sie verwenden kannst.
Zum Beispiel:

```ruby
require 'ostruct'

person = OpenStruct.new(name: "Jeremy Walker")
# ...
```
