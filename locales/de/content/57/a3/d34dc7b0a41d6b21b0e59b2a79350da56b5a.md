# Einführung

## Enum

`Enum` ist ein sehr nützliches Modul, das eine Reihe von Algorithmen für die Arbeit mit Enumerables bereitstellt. Es bietet Sortieren, Filtern, Gruppieren, Zählen, Suchen, das Finden von Minimal- und Maximalwerten und vieles mehr.

Im Allgemeinen ist ein _Enumerable_ jede Art von Daten, über die iteriert werden kann, also eine Sammlung. In Elixir ist ein Enumerable jeder Datentyp, der das [Protokoll][exercism-protocols] `Enumerable` implementiert. Die häufigsten davon sind [Listen][exercism-lists] und [Maps][exercism-maps].

Viele Funktionen von `Enum` akzeptieren eine Funktion als Argument.

```elixir
Enum.all?([1, 2, 3, 4, 5], fn x -> x > 3 end)
# => false
```

Die häufigsten Funktionen von `Enum` sind `map` und `reduce`.

### `map/2`

Mit `Enum.map/2` kannst du jedes Element in einem Enumerable durch ein anderes Element ersetzen. Das zweite Argument von `Enum.map/2` ist eine Funktion, die das ursprüngliche Element entgegennimmt und dessen Ersatz zurückgibt.

### `reduce/3`

Mit `Enum.reduce/3` kannst du das gesamte Enumerable zu einem einzigen Wert _reduzieren_. Dazu wird eine spezielle Variable namens _Akkumulator_ verwendet. Der Akkumulator trägt den Zwischenzustand der Reduktion zwischen den Iterationen.

Das zweite Argument von `Enum.reduce/3` ist der Anfangswert des Akkumulators. Das dritte Argument ist eine Funktion, die ein Element und einen Akkumulator entgegennimmt und den neuen Wert für den Akkumulator zurückgibt.

### Mit Maps arbeiten

Wenn du Maps mit `Enum`-Funktionen verwendest, wird die Map automatisch in eine Liste aus 2 `{key, value}`-Tupeln umgewandelt.

Um sie wieder in eine Map umzuwandeln, verwendest du `Enum.into/2`. `Enum.into/2` ist eine Funktion, die ein Enumerable in ein Collectable umwandelt, also eine beliebige Datenstruktur, die das Protokoll `Collectable` implementiert. Man kann sie sich als das Gegenteil von `Enum.reduce/3` vorstellen.

`Enum` hat auch `Enum.into/3`. `Enum.into/3` ist eine Variante von `Enum.into/2`, die eine Transformationsfunktion entgegennimmt, die angewendet wird, während das Enumerable in ein Collectable umgewandelt wird.

#### Maps mappen

Anstatt `Enum.into/3` oder `Enum.map/2` plus `Enum.into/2` zu verwenden, um eine Transformation (ein Mapping) auf eine Map anzuwenden, können wir auch die spezielle Funktion `Map.new/2` verwenden. Sie funktioniert genau wie `Enum.into/3`, indem sie ein Enumerable und eine Transformationsfunktion entgegennimmt, aber sie gibt immer eine neue Map zurück, statt uns die Wahl des Collectables zu überlassen.
