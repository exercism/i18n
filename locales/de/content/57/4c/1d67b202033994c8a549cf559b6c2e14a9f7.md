# Ergänzung zur Anweisung

## Register

| Register | Verwendung | Typ             | Beschreibung                                            |
| -------- | ---------- | --------------- | ------------------------------------------------------- |
| `$a0`    | Eingabe    | Adresse         | nullterminierter Eingabe-String                         |
| `$v0`    | Ausgabe    | boolescher Wert | Eingabe ist ein Isogramm (`0` = `false`, `1` = `true`)  |
| `$t0-9`  | temporär   | beliebig        | wird für temporäre Speicherung verwendet                |
