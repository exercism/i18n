### Einleitung

Willkommen zur ersten Übung im Java-Track!

Dieses Dokument ist eine Schritt-für-Schritt-Anleitung zum Lösen dieser Übung.
Diese Anleitung funktioniert unter Windows, macOS und Linux gleichermaßen gut.

Auch wenn du die Java-Grundlagen schon kennst, kann es hilfreich sein, dieser Anleitung zu folgen. Denn so lernst du die Ausgabe des Tools Gradle kennen, das wir zum Kompilieren und Testen unseres Codes verwenden, und bekommst außerdem einen Einblick in die Muster, die in allen Übungen in diesem Track vorkommen.

### Aufbau der Übung

Wenn du eine neue Java-Übung abrufst, erhältst du:

- __eine oder mehrere Testdateien__ (immer).
Sie liegen im Verzeichnis `src/test/java` und definieren eine Reihe von Tests, die deine Lösung erfüllen muss, bevor sie als funktionierend gelten kann.
- __eine oder mehrere Starterdateien__ (am Anfang).
Falls vorhanden, liegen sie im Verzeichnis `src/main/java` und enthalten Grundgerüste der Klassen, die du brauchst, um das aktuelle Problem zu lösen.

### „Hello, World!“ lösen

Du kannst unseren Online-Editor verwenden, um deine Lösung zu schreiben und die Tests auszuführen. Wenn du das Problem aber lokal lösen und die Tests lokal ausführen möchtest, schau dir die folgenden Links an:

- [Java installieren][Installing Java]
- [Lokal arbeiten][Working Locally]
- [Lokal testen im Java-Track][Testing locally on the java track]

### Schritt 1: Die Lösung korrigieren

Egal ob du lokal arbeitest oder den Online-Editor verwendest, du solltest den folgenden Code finden:

```java
String getGreeting() {
    return "Goodbye, Mars!";
}
```

Das Ziel ist, den vorgegebenen Code so zu ändern, dass er den Text `"Hello, World!"` statt `"Goodbye, Mars!"` ausgibt.

### Schritt 2: Die Tests ausführen

Nachdem du die Korrekturen vorgenommen und deine Lösung implementiert hast, führe die Tests erneut aus.
Du kannst die Tests im Online-Editor oder lokal auf deinem Rechner ausführen:

- Um die Tests im Online-Editor auszuführen, klicke auf die Schaltfläche „Run Tests“.
- Um die Tests lokal auszuführen, schau dir [Lokal testen im Java-Track][Testing locally on the java track] an. Wenn die Tests fehlschlagen, ist das in Ordnung! Schau, was die Fehlermeldung dir sagt, ändere deinen Code und teste erneut. Wenn deine Tests bestehen, geh zum nächsten Schritt über.

### Schritt 3: Deine erste Iteration einreichen

Mit einer funktionierenden Lösung, die wir überprüft haben, können wir sie jetzt bei exercism.org einreichen.
Du kannst die Lösung im Online-Editor oder lokal mit der [Exercism CLI][Working Locally] einreichen:

- Um die Übung lokal einzureichen, [installiere zuerst die Exercism CLI][Working Locally], falls noch nicht geschehen, und reiche dann die Dateien deiner Lösung ein, z. B.:

  ```sh
  exercism submit <file location>
  ```

- Ersetze `<file location>` durch den relativen Pfad zu deiner Datei `Greeter.java`. Wenn du also in `C:\exercism\java\hello-world` arbeitest, lautet der Befehl

  ```sh
  exercism submit .\src\main\java\Greeter.java
  ```

- Wenn du deine Lösung mit dem Online-Editor einreichen möchtest, klicke einfach auf die Schaltfläche „Submit“!

Wenn du genauer sehen möchtest, wie du eine Lösung lokal einreichst:

- [Lokal einreichen][Working Locally]

### Werde Mentor

Das Herz von Exercism sind die Gespräche über Programmierpraktiken.
Üben macht definitiv Spaß, aber der Austausch mit anderen, über deren Versuche und über deine eigenen, bringt dir Feedback.
Dieses Feedback kann dir zeigen, was du gut machst und wo du dich noch verbessern kannst.

Manche Einreichungen ähneln deiner fast, andere sind völlig anders.
Beide Arten zu sehen, kann lehrreich und interessant sein.

Mentoren begutachten eingereichte Lösungen für den Track, in dem sie mentorieren möchten, damit Lernende so viel wie möglich lernen.

Mehr über das Mentoring findest du in den [Exercism-Dokumenten][Mentoring].
