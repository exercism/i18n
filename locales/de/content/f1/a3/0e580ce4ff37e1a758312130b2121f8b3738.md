# Hinweise

## Allgemein

- Ein Array von Namen hat den Typ `ARRAY{STR}`, ein Array von Zahlen den
  Typ `ARRAY{INT}`. Sowohl das Argument als auch, in Aufgabe 4, die Antwort
  müssen angeben, um welchen der beiden es sich handelt.

## 1. Wie viele sind in der Reihe?

- `.size`, ohne runde Klammern dahinter.

## 2. Wer führt?

- Die erste Position ist `0`.

## 3. Wer ist hinten?

- Die letzte Position ist eins weniger als die Größe, weil das Zählen bei
  null beginnt.
- Berechne sie aus `.size`, statt `2` zu schreiben. Die Tests verwenden
  Reihen mit mehreren unterschiedlichen Längen.

## 4. Die Anfangsformation

- Die Antwort ist ein Array von Strings, also wird die Routine als
  `: ARRAY{STR}` deklariert.
- Gib ein Array-Literal zurück: die drei Namen zwischen `|`-Zeichen.

## 5. Zähle die Schritte

- Eine laufende Summe und eine Schleife, wie in der vorigen Übung.
- Zähle eine Positionsvariable von `0` aufwärts und beende die Schleife mit
  `until!(i >= steps.size)`.
- Weil die Summe bei `0` beginnt, ergibt die leere Reihe ohne besondere
  Behandlung null.
