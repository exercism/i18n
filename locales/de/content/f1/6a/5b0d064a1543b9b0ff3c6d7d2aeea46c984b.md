# Einführung

In C++ kannst du Werte mit den Vergleichsoperatoren vergleichen.

| Vergleich         | Operator  |
| ------------------| --------- |
| gleich            | `==`      |
| ungleich          | `!=`      |
| kleiner           | `<`       |
| kleiner oder gleich | `<=`    |
| größer            | `>`       |
| größer oder gleich | `>=`     |

Das Ergebnis dieser Vergleiche ist immer ein boolescher Wert:

```cpp
int a{3};

bool eq1 = a != 4; // true

bool eq2 = a > 5;  // false
```

Die Operatoren `==` und `!=` prüfen, ob ein Wert gleich einem anderen ist oder nicht.
Hier sind einige gängige Beispiele:

```cpp
bool eq3 = 2 == 3; // false, integer comparison

bool eq4 = 2.1 != 2.2; // true, float comparison

bool eq5 = "hello" == "hello"; // true, string comparison
```

Die anderen Operatoren prüfen, ob ein Wert größer als (`>`), größer oder gleich (`>=`), kleiner als (`<`) oder kleiner oder gleich (`<=`) einem anderen Wert ist.
Diese Art des Vergleichs gibt es für Zahlen und Strings.
Beim Vergleichen von Strings wird die Wörterbuchreihenfolge (auch als lexikografische Ordnung bekannt) verwendet.

```cpp
bool eq6 = 2 > 3; // false, integer comparison

bool eq7 = 1.2 < 1.3; // true, float comparison

bool eq8 = "Hello" < "World"; // true, string comparison
```
