# Einführung

Im Gegensatz zu vielen anderen Sprachen gibt es in JavaScript zwei verschiedene Dinge, die das Fehlen eines (sinnvollen) Werts darstellen: `null` und `undefined`.

## Null

Der primitive Wert `null` wird als absichtlich „leerer Wert“ für Variablen jedes Typs verwendet.

```javascript
let name = null;
// name is intentionally set to "empty" because it is not
// available
```

Du kannst prüfen, ob eine Variable null ist, indem du den [Operator für strikte Gleichheit][mdn-strict-equality] `===` verwendest.

```javascript
let name = null;

name === null;
// => true
```

## Undefined

> Eine Variable, der kein Wert zugewiesen wurde, hat den Typ `undefined`.[^1]

Das heißt: Während `null` einen leeren Wert darstellt (aber immer noch einen Wert), steht `undefined` für das völlige Fehlen eines Werts. 🤯

`undefined` tritt in verschiedenen Situationen auf.

- Wird eine Variable ohne Wert (Initialisierung) deklariert, ist sie `undefined`.

  ```js
  let name;
  console.log(name); // => undefined
  ```

- Wenn du auf den Wert eines nicht existierenden Schlüssels in einem Objekt zugreifen willst, bekommst du `undefined`.

  ```js
  let obj = {
    name: 'John',
  };
  console.log(obj.age); // => undefined
  ```

- Wenn eine Funktion keinen Wert zurückgibt, ist das Ergebnis `undefined`.

  ```js
  function printName(name) {
    'My name is ' + name;
  }
  console.log(printName('John')); // => undefined
  ```

- Wenn ein Argument nicht an eine Funktion übergeben wird, ist es `undefined`, es sei denn, dieses Argument hat einen Standardwert.

  ```js
  function printName(name) {
    return name;
  }
  console.log(printName()); // => undefined
  ```

Du kannst mit dem Operator für strikte Gleichheit `===` prüfen, ob eine Variable undefined ist.

```javascript
let name;

name === undefined;
// => true
```

## Optional Chaining

Wenn du einen verschachtelten Wert in einem Objekt abrufen willst, aber der übergeordnete Schlüssel nicht existiert, wirft JavaScript einen Fehler.
Um das einfach zu vermeiden, wurde Optional Chaining 2020 in die Sprachspezifikation aufgenommen.
Mit dem Optional-Chaining-Operator `?.` kannst du sicherstellen, dass JavaScript nur dann versucht, auf den verschachtelten Schlüssel zuzugreifen, wenn der übergeordnete Wert nicht `null` oder `undefined` war.
Andernfalls wird `undefined` zurückgegeben.

```javascript
const obj = {
  address: {
    street: 'Trincomalee Highway',
    city: 'Batticaloa',
  },
};

obj.address.zipCode;
// => undefined

obj.residence.street;
// => TypeError: Cannot read property 'street' of undefined

obj.residence?.street;
// => undefined
```

## Nullish Coalescing

Es gibt Situationen, in denen du einen Standardwert anwenden willst, falls eine Variable null oder undefined ist (aber nur dann).
Um das abzudecken, wurde 2020 der Nullish-Coalescing-Operator `??` eingeführt.
Er gibt den rechten Operanden nur dann zurück, wenn der linke Operand `null` oder `undefined` ist.
Andernfalls wird der linke Operand zurückgegeben.

```javascript
let amount = null;
amount = amount ?? 1;
// => 1

amount = 0;
amount = amount ?? 1;
// => 0
```
