# Konstante auf die oberste Ebene auslagern

Lagere die Konstante am besten in den Gültigkeitsbereich der obersten Ebene aus:

```javascript
const %{name} = %{value}

// the rest of your code below it
export %{method.signature}
```

Nur Funktionen, Klassen und Konstanten, die mit `export` exportiert werden, sind von außen sichtbar und zugänglich.
Diese Konstanten können in derselben Datei liegen, ohne für anderen Code sichtbar zu sein.
Außerdem spart das Auslagern von Konstanten Speicher: Wiederholte Allokationen in Funktionen entfallen, wenn dieselben Konstanten wiederverwendet werden.
