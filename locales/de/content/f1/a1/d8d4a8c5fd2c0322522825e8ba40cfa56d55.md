# Einführung

In Cairo ist ein Trait eine Reihe von Methoden, die von einem Datentyp implementiert werden können.
Wenn ein Trait für einen Typ implementiert wird, können die in diesem Trait definierten Methoden auf Instanzen dieses Typs aufgerufen werden.
Ein Trait kann mit generischen Typen definiert werden und definiert Verhalten, das mehrere Datentypen gemeinsam haben.
