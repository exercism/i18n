# Über

[Java](https://go.java/index.html) gehört dank seiner Vielseitigkeit und Kompatibilität zu den beliebtesten Programmiersprachen.
Es wird häufig für die Softwareentwicklung, für mobile Anwendungen und für den Aufbau größerer Systeme eingesetzt.

Java entstand 1995 und wird von [Oracle](https://www.oracle.com/index.html) gepflegt.
Auch wenn Java nicht mehr so jung ist wie manche der frischen Sprachen da draußen, ist es immer noch sehr beliebt.
Es wurde entwickelt, um schnell, sicher, zuverlässig, anfängerfreundlich und besonders portabel zu sein.
Dieser Vorteil der Portabilität ist möglich, weil Java auf einer plattformübergreifend kompatiblen [Java Virtual Machine – JVM](https://en.wikipedia.org/wiki/Java_virtual_machine) ausgeführt wird.
Auch Android-Apps werden mit Java entwickelt, da das [Android-Betriebssystem](<https://en.wikipedia.org/wiki/Android_(operating_system)>) auf einer Java-Sprachumgebung läuft.

Die Java-Community ist riesig!
GitHub zum Beispiel beherbergt über 1,5 Millionen Java-Projekte.
Außerdem hat Java die zweitgrößte Community auf [StackOverflow](https://stackoverflow.com/questions/tagged/java)!
Das ist wichtig, denn je größer die Community einer Programmiersprache ist, desto mehr Unterstützung kannst du erwarten.

Java hat außerdem eine leistungsstarke und gut durchdachte Sammlung eingebauter [APIs – Programmierschnittstellen](https://docs.oracle.com/en/java/javase/11/docs/api/index.html), die für verschiedenste Aufgaben genutzt werden können, etwa Datenbankverbindungen, Netzwerke, I/O, XML-Parsing, Hilfsfunktionen und vieles mehr.

Von Laptops bis zu Rechenzentren, von Spielkonsolen bis zu wissenschaftlichen Supercomputern, von Mobiltelefonen bis zum Internet: [Java ist überall](https://en.wikipedia.org/wiki/Write_once,_run_anywhere)!
