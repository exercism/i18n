# Hinweise

## Allgemein

- Deklariere die vier Symbole für die Himmelsrichtungen und die vier Symbole für relative Peilungen in einer einzigen `SYMBOLS:`-Zeile: `SYMBOLS: north east south west ahead starboard behind port ;`
- Jedes Tupel wird mit `TUPLE: <class> <slot1> <slot2> ;` deklariert.
- Eine `GENERIC:`-Zeile deklariert das Wort; jede `M:`-Zeile fügt eine Methode für eine Klasse hinzu. Verwende `M::`, wenn du benannte lokale Variablen im Methodenrumpf haben möchtest.

## 1. `>cartesian` für Himmelsrichtungen

- Ein kleines `case` über die vier Richtungssymbole reicht aus.
- `{ north [ 0 1 ] }`: Der Rumpf schiebt nur die beiden Werte; der Test erwartet `x` unter `y` auf dem Stack.

## 2. `>cartesian` für Polarkoordinaten

- Wandle Grad in Bogenmaß um: `bearing pi * 180 /`.
- `sin` und `cos` sind in `math.functions` enthalten.
- Schiebe zuerst `magnitude * sin(rad)` und dann `magnitude * cos(rad)`.

## 3. `>cartesian` für relative Peilungen

- Deklariere eine dynamische Variable: `SYMBOL: heading`.
- Lies sie in deiner Methode mit `heading get` aus.
- Ordne `ahead/starboard/behind/port` mit einem `case` einem Versatz von `0/90/180/270` zu und addiere dann die Peilung. Von dort aus ist es dieselbe Umrechnung in Polarkoordinaten wie in Aufgabe 2. Zieh am besten ein Hilfswort heraus: `: deg>cartesian ( magnitude bearing -- x y ) ... ;`.

## 4. `flip`

- `change-direction` auf einem `cardinal` und `change-bearing` auf einem `polar` oder `relative` erzeugen ein neues Tupel, bei dem ein Slot geändert wird und die übrigen unberührt bleiben: `[ <transformation-quotation> ] change-bearing`.
- Für die Drehung von `polar`: `[ 180 + 360 mod ] change-bearing`.

## 5. `add-bearings`

- Rufe `>cartesian` für jeden Eingabewert auf und addiere dann die x-Komponenten und die y-Komponenten. Lokale Variablen machen das lesbar:
  ```factor
  :: add-bearings ( a b -- x y )
      a >cartesian :> ay :> ax
      b >cartesian :> by :> bx
      ax bx +
      ay by + ;
  ```
