# Anweisungen

Eine stark frequentierte Bank bedient wartende Kunden nach *Priorität* und nicht in der Reihenfolge, in der sie angekommen sind. Jeder Kunde zieht eine Wartenummer und bekommt dabei eine Prioritätsnummer. Der Schaltermitarbeiter bedient als Nächstes immer die niedrigste Nummer (`1` ist am dringendsten). Ein Min-Heap ist die perfekte Warteschlange.

## 1. Die Warteschlange öffnen

Definiere `new-queue`, das keine Argumente entgegennimmt und eine neue, leere Prioritätswarteschlange zurückgibt.

```factor
new-queue
! => an empty priority queue
```

## 2. Einen Kunden hinzufügen

Definiere `join-queue`, das einen Kundennamen, eine Prioritätsnummer und eine Warteschlange entgegennimmt. Es fügt den Kunden zur Warteschlange hinzu und gibt die Warteschlange zurück, sodass du Kunden nacheinander hinzufügen kannst.

```factor
new-queue "alice" 5 rot join-queue "bob" 2 rot join-queue
! => the queue, now holding alice (5) and bob (2)
```

## 3. Wer ist als Nächstes dran?

Definiere `next-name`, das eine Warteschlange entgegennimmt und den Namen des Kunden zurückgibt, der als Nächstes bedient werden soll, also den Namen des Kunden mit der niedrigsten Prioritätsnummer, *ohne* ihn aus der Warteschlange zu entfernen.

```factor
new-queue "alice" 5 rot join-queue "bob" 2 rot join-queue next-name .
! => "bob"
```

## 4. Alle bedienen

Definiere `serve-all`, das eine Warteschlange entgegennimmt und die Namen aller wartenden Kunden in der Reihenfolge zurückgibt, in der sie bedient würden.

```factor
new-queue "alice" 5 rot join-queue "bob" 2 rot join-queue
"carol" 9 rot join-queue serve-all .
! => { "bob" "alice" "carol" }
```
