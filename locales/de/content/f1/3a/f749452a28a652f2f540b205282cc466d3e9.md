# Einführung

## Vergleichen

### Zahlen vergleichen

In `jq` kannst du Zahlen mit den folgenden Vergleichs- und Gleichheitsoperatoren vergleichen.

| Vergleich              | Operator |
| ---------------------- | -------- |
| Größer als             | `a > b`  |
| Größer oder gleich     | `a >= b` |
| Kleiner als            | `a < b`  |
| Kleiner oder gleich    | `a <= b` |
| Gleich                 | `a == b` |
| Ungleich               | `a != b` |

Das Ergebnis des Vergleichs ist immer ein boolescher Wert, also entweder `true` oder `false`.

```jq
1 < 3,      # => true
2 != 2,     # => false
1 == 1.0    # => true
            # All numbers are floating-points, so this is different syntax
            # for the exact same value.
```

### Strings vergleichen

Die obigen Vergleichsoperatoren kannst du auch verwenden, um Strings zu vergleichen.
In diesem Fall wird eine Wörterbuchreihenfolge (lexikografische Reihenfolge) angewendet.
Die Reihenfolge richtet sich _nach dem Unicode-Codepoint-Wert_.

```jq
"Apple" > "Pear",   # => false
"a" < "above",      # => true
"a" == "A"          # => false
```

Du musst vorsichtig sein, wenn du zwei Variablen vergleichst, die numerische Werte zu enthalten scheinen, aber vom Typ String sind.
Wegen der Wörterbuchreihenfolge ist das Ergebnis nicht dasselbe wie beim Vergleich von Werten des Typs Zahl.

```jq
10 < 2,     # => false
"10" < "2"  # => true (because "1" comes before "2")
```

### „Strikte" Gleichheit

Der `==`-Operator von `jq` ist wie JavaScripts `===` in dem Sinne, dass Dinge, die gleich „aussehen", aber von unterschiedlichem Typ sind, nicht gleich sind.

```jq
"3" == 3    # => false
            # the value on the left has type string,
            # the value on the right has type number.
```

### Arrays vergleichen

Zwei Arrays sind gleich, wenn alle entsprechenden Elemente gleich sind.

```jq
[1, 2, 3] == [1, 2, 3]      # => true
[1, 2, 3] == [1, 3, 2]      # => false, different order
[1, 2, 3] == [1, 2, "3"]    # => false, different types
```

### Objekte vergleichen

Zwei Objekte sind gleich, wenn sie dieselben Schlüssel-Wert-Paare haben.

```jq
{name: "Joe", age: 42} == {age: 42, name: "Joe"}                # => true
{name: "Joe", age: 42} == {age: 42, name: "Jane"}               # => false
{name: "Joe", age: 42} == {age: "42", name: "Joe"}              # => false
{name: "Joe", age: 42} == {age: 42, name: "Joe", height: 175}   # => false

# comparisons will drill down as deeply as required
{a: {b: {c: [1, 2]}}} == {a: {b: {c: [1, 2]}}}                  # => true
{a: {b: {c: [1, 2]}}} == {a: {b: {c: [1, 2, 3]}}}               # => false
```

## Bedingungen

### if-Ausdruck

Der **bedingte Ausdruck** von `jq` lautet `if A then B else C end`.

`if-then-else` ist ein Filter wie alle eingebauten Funktionen von `jq`: Er nimmt eine Eingabe und erzeugt eine Ausgabe.

Wenn der Ausdruck `A` einen „truthy"-Wert erzeugt, wertet der `if`-Filter `B` aus.
Andernfalls wertet er `C` aus.
Die Eingabe des `if`-Filters wird an `B` oder `C` weitergegeben.

```jq
42 | if . < 50 then "small" else "big" end      # => "small"
```

```jq
5 | if . % 2 == 0 then . / 2 else . * 4 end     # => 20
```

~~~~exercism/note
Die `else`-Klausel ist **optional**; die folgenden beiden Anweisungen sind gleichwertig.

```jq
if A then B else . end
if A then B end
```
~~~~

### Verschachtelte if-Anweisungen

Weitere Bedingungen kannst du mit `elif` hinzufügen.

```jq
42 | if . < 33 then "small"
     elif . < 66 then "medium"
     else "big"
     end
# => "medium"
```

Verwende so viele `elif`-Klauseln, wie du brauchst.

### Truthiness

Die einzigen „falschen" Werte in `jq` sind `false` und `null`.
Alles andere ist „wahr", sogar die Zahl null und der leere String, das leere Array und das leere Objekt.

### Boolesche Operatoren

Mit den **booleschen Operatoren** `and` und `or` kannst du komplexe Abfragen aufbauen.

```jq
42 | if . < 33 or . > 66 then "big or small"
     else "medium"
     end
```

Zum Negieren verwendest du `not`. Das ist ein **Filter**, kein Operator.

```jq
42 | if (. < 33 or . > 66 | not) then "medium"
     else "big or small"
     end
```

### Alternativer Operator

Mit dem **alternativen Operator** kannst du einen „Standardwert" angeben, falls ein Ausdruck falsch oder null ist.

```jq
A // B

# This is identical to
if A then A else B end
```

Zur Veranschaulichung

```jq
[3, 5, 18] | add / 2       # => 13
[]         | add / 2       # => error: null (null) and number (2) cannot be divided
[]         | add // 0 / 2  # => 0
```
