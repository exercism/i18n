# Ressourcen

Es gibt viele großartige kostenlose Online-Ressourcen für Lua, darunter:

1.  [lua.org][8]
2.  Eine sehr empfehlenswerte, ausführliche und maßgebliche Einführung in alle Aspekte der Lua-Programmierung vom Chefarchitekten von Lua: [Programming in Lua, von Roberto Ierusalimschy][6]
3.  Eine offizielle Definition der Sprache Lua findest du im [Lua 5.4 Reference Manual][7] von R. Ierusalimschy, L. H. de Figueiredo und W. Celes.
4.  [Lua Style Guide][4]
5.  [Learn Lua in 15 minutes][5]
6.  Auch wenn es nicht schön aussieht: Das Wiki von [lua-users.org][14] enthält viele nützliche Informationen und Kenntnisse.
7.  Einige Optionen für Linting
    -   [luacheck][12]
    -   [Detecting Undefined Variables][13]
8.  Implementierungen des Language Server Protocol für Lua
    -   [Lua Language Server][9]
    -   [EmmyLua-LanguageServer][10]
