# Ergänzung zu den Anweisungen

## Mit Datumsangaben in Prolog arbeiten

Die eingebaute Unterstützung für Datumsangaben in Prolog ist [ziemlich rudimentär][built-in-dates-support].
Ein viel schönerer Weg, mit Datumsangaben zu arbeiten, führt über das [date_time-Paket][date_time-package].

### Das date_time-Paket installieren

Wenn deine installierte Swipl-Version einigermaßen aktuell ist, kannst du das Paket so installieren:

```bash
swipl pack install date_time
```

Wenn das nicht funktioniert, kannst du Folgendes ausführen:

```shell
swipl -g 'pack_install(date_time)'
```

~~~~exercism/note
Wenn du den Online-Editor verwendest, musst du nichts manuell installieren.
~~~~

### Das date_time-Paket verwenden

Füge den folgenden Code oben in deine Lösungsdatei ein, um das `date_time`-Paket zu verwenden:

```prolog
:- use_module(library(date_time)).
```

~~~~exercism/note
Tipp: Der [Quellcode des date_time-Pakets][https://www.swi-prolog.org/pack/file_details/date_time/prolog/date_time.pl?show=src] ist gut dokumentiert und kann eine große Hilfe sein!
~~~~
