# Einführung

In C# gibt es zwei verschiedene Arten von Zahlen:

- Ganzzahlen: Zahlen ohne Nachkommastellen (ganze Zahlen). Beispiele sind `-6`, `0`, `1`, `25`, `976` und `500000`.
- Gleitkommazahlen: Zahlen mit null oder mehr Nachkommastellen. Beispiele sind `-2.4`, `0.1`, `3.14`, `16.984025` und `1024.0`.

Die beiden häufigsten numerischen Typen in C# sind `int` und `double`. Ein `int` ist eine 32-Bit-Ganzzahl und ein `double` ist eine 64-Bit-Gleitkommazahl.

Rechenoperationen führst du mit den üblichen arithmetischen Operatoren durch. Zahlen kannst du mit den üblichen numerischen Vergleichsoperatoren sowie den Operatoren für Gleichheit (`==`) und Ungleichheit (`!=`) vergleichen.

In C# gibt es zwei Arten der numerischen Konvertierung:

1. Implizite Konvertierungen: Es gehen keine Daten verloren und es ist keine zusätzliche Syntax erforderlich.
2. Explizite Konvertierungen: Es könnten Daten verloren gehen und es ist zusätzliche Syntax in Form eines _Casts_ erforderlich.

Da ein `int` eine geringere Genauigkeit als ein `double` hat, ist die Konvertierung von einem `int` zu einem `double` sicher und damit eine implizite Konvertierung. Die Konvertierung von einem `double` zu einem `int` kann jedoch den Verlust von Daten bedeuten, weshalb dafür eine explizite Konvertierung nötig ist.

```csharp
int softCool = 1358938113;
double notLost = 4.8151623;

// implicit cast: no loss of information
double macDebug = softCool;         // 1358938113.0

// explicit cast: possible loss of information 
int somethingLost = (int)notLost;   // 4
```
