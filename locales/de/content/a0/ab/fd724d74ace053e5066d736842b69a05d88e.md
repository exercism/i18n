# Debug

Wenn ein Test fehlschlägt, bekommst du eine Meldung, die beschreibt, was schiefgelaufen ist und bei welcher Eingabe. Du kannst dir außerdem zunutze machen, dass auch die Konsolenausgabe angezeigt wird. Mit folgendem Code schreibst du in die Konsolenausgabe:

```crystal
puts "Debug message"
```

oder

```crystal
p "Debug message"
```

`puts` wandelt den Wert in einen String um und gibt ihn in der Konsolenausgabe aus.
`p` gibt den Wert in der Konsolenausgabe aus, ohne ihn in einen String umzuwandeln.
