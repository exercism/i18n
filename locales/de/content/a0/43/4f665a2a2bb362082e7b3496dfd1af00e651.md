# Einführung

In Haxe ist ein **Array** eine Sammlung von Elementen, die (meistens) vom selben Typ sind. In Haxe gibt es drei Möglichkeiten, ein Array zu erstellen: entweder über einen Konstruktor oder über eine Deklarationssyntax. In Haxe hat das erste Element eines Arrays den Index null:

```haxe
var a = [1, 2, 3];
trace(a); // [1,2,3]

// Here the second element is called by index
trace(a[1]); // 2

// The actual first element's index is 0
trace(a[0]); // 1
```

Um ein Array mit einem Konstruktor zu erstellen, musst du den Typ der Elemente übergeben, die das Array enthalten soll:

```haxe
var a:Array<Int> = [0, 1, 2, 3];
a[1] = "Hello"; // Error: the array a takes integers only
```

Wenn ein Array mehrere Typen von Elementen enthalten soll, fügen wir den Typ `Dynamic` zur Typangabe hinzu:

```haxe
var a:Array<Dynamic> = [10, "Bob", true]
```
