# Anweisungen

In dieser Übung schreibst du etwas Code, mit dem du eine großartige Lasagne aus deinem Lieblingskochbuch kochst.

Du hast vier Aufgaben, die alle mit der Zeit zu tun haben, die du für das Kochen der Lasagne brauchst.

## 1. Bestimme die erwartete Ofenzeit in Minuten

Definiere die Methode `expectedMinutesInOven()`, die keine Parameter entgegennimmt und zurückgibt, wie viele Minuten die Lasagne im Ofen bleiben sollte. Laut Kochbuch beträgt die erwartete Ofenzeit 40 Minuten:

```java
Lasagna lasagna = new Lasagna();
lasagna.expectedMinutesInOven();
// => 40
```

## 2. Berechne die verbleibende Ofenzeit in Minuten

Definiere die Methode `remainingMinutesInOven()`, die die tatsächlichen Minuten, die die Lasagne schon im Ofen war, als Parameter entgegennimmt und zurückgibt, wie viele Minuten die Lasagne noch im Ofen bleiben muss. Dabei gehst du von der erwarteten Ofenzeit aus der vorherigen Aufgabe aus.

```java
Lasagna lasagna = new Lasagna();
lasagna.remainingMinutesInOven(30);
// => 10
```

## 3. Berechne die Vorbereitungszeit in Minuten

Definiere die Methode `preparationTimeInMinutes()`, die die Anzahl der Schichten, die du zur Lasagne hinzugefügt hast, als Parameter entgegennimmt und zurückgibt, wie viele Minuten du für die Vorbereitung der Lasagne gebraucht hast. Dabei gehst du davon aus, dass du für jede Schicht 2 Minuten brauchst.

```java
Lasagna lasagna = new Lasagna();
lasagna.preparationTimeInMinutes(2);
// => 4
```

## 4. Berechne die gesamte Arbeitszeit in Minuten

Definiere die Methode `totalTimeInMinutes()`, die zwei Parameter entgegennimmt: Der erste Parameter ist die Anzahl der Schichten, die du zur Lasagne hinzugefügt hast, und der zweite Parameter ist die Anzahl der Minuten, die die Lasagne schon im Ofen war. Die Funktion soll zurückgeben, wie viele Minuten du insgesamt mit dem Kochen der Lasagne verbracht hast. Das ist die Summe aus der Vorbereitungszeit in Minuten und der Zeit in Minuten, die die Lasagne bisher im Ofen verbracht hat.

```java
Lasagna lasagna = new Lasagna();
lasagna.totalTimeInMinutes(3, 20);
// => 26
```
