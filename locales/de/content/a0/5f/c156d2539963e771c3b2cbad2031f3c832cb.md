# Einführung

## Module

Mit Modulen gruppierst du zusammengehörigen Code und vermeidest Namenskonflikte. In allen außer den denkbar einfachsten Codebasen sind sie normalerweise vorhanden.

Die Syntax sieht so aus:

```rust
mod my_module {
    pub struct MyStruct {}

    pub struct OtherClass {}
}
```

Außerhalb des Gültigkeitsbereichs eines Moduls sprichst du Typen, die in Modulen liegen, an, indem du dem Typnamen die Doppelpunkt-Doppelpunkt-Syntax `::` voranstellst.
Alternativ und üblicher kannst du eine `use`-Anweisung an den Anfang der Datei (oder in ein Modul) setzen. Danach lassen sich die Typen ohne das Präfix verwenden.
Innerhalb desselben Moduls musst du Typnamen nicht qualifizieren.

```rust
mod my_module {
    #[derive(Drop)]
    pub struct MyStruct {}

    pub struct Foo {}

    #[generate_trait]
    pub impl FooImpl of FooTrait {
        fn bar() {
            let baz = MyStruct {};
        }
    }
}

#[derive(Drop)]
pub struct Qux {}

#[generate_trait]
impl QuxImpl of QuxTrait {
    fn box() {
        let nux = my_module::MyStruct {};
    }
}

mod other_module {
    use super::my_module::*;

    #[derive(Drop)]
    pub struct Tix {}

    #[generate_trait]
    pub impl TixImpl of TixTrait {
        fn jeg() {
            let lor = MyStruct {};
        }
    }
}
```

Du kannst einem Modul oder einem Typ mit der Syntax `use core::array::ArrayTrait as Arr;` einen Alias geben. Diesen Alias verwendest du dann überall dort, wo das Modul oder der Typ verwendet werden kann.
