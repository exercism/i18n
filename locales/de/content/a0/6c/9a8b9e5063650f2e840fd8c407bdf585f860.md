# Überblick

**Closures** sind ein Programmiermuster [in Clojure][clojure-guide-closures], mit dem Variablen aus einem äußeren [lexikalischen Gültigkeitsbereich][wiki-lexical-scope] innerhalb einer Funktion verwendet werden können. Clojure unterstützt Closures transparent, und sie werden oft verwendet, ohne dass man weiß, was sie sind.

```clojure
;; Top-level definitions are global-scope
(def dozen 12)

;; Functions create a new scope.
;; Referencing the outer variable here is a closure.
(fn [n] (* dozen n))
```

## Closures: Zustand speichern und Werte weitergeben

Ein Atom ermöglicht es, einen gewissen Zustand zu erhalten:

```clojure
;; This function closure increments the counter's state
;; in the outer lexical context.
;; This way the counter can be shared between many calling contexts.

(def increment
  (let [counter (atom 0)]
    (fn [] (swap! counter inc))))
```

Jeder aufeinanderfolgende Aufruf von `increment` erhöht seinen Zähler:

``` clojure
(increment)
;;=> 1
(increment)
;;=> 2
```
