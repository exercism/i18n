Entferne alle expliziten Aufrufe von `Boolean(...)`.

In JavaScript muss das Ergebnis eines Ausdrucks nicht in einen bestimmten Typ _umgewandelt_ werden.
Zum Beispiel kannst du das Ergebnis eines binären Ausdrucks direkt zurückgeben, ohne einen weiteren Aufruf, der daraus einen `boolean` macht.

```javascript
// instead of
return Boolean(some_expression);

// ...In JavaScript, in general, values don't need to be explicitly changed
return some_expression;
```
