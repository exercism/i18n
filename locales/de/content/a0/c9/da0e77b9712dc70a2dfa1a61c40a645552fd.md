# Anleitung

In der Nähe gibt es einen Laden namens „Tech Palace“.
Der Inhaber des Ladens hat vor Kurzem ein großes Display installiert, um damit Werbebotschaften anzuzeigen und um Kunden, die am Eingang ihre Kundenkarte scannen, einen besonderen Gruß zu zeigen.
Das Display besteht aus vielen kleinen LED-Leuchten und kann mehrere Textzeilen anzeigen.

Der Inhaber braucht deine Hilfe bei dem Code, mit dem der Text für das neue Display erzeugt wird.

## 1. Erstelle die Willkommensnachricht

<!-- markdownlint-disable-next-line MD038 -->
Für die meisten Kunden, die ihre Kundenkarte scannen, möchte der Inhaber auf dem Display `Welcome to the Tech Palace, ` gefolgt vom Namen des Kunden in Großbuchstaben sehen.

Implementiere die Funktion `welcome_message`, die den Namen des Kunden als kurzen String (`felt252`) entgegennimmt und die gewünschte Nachricht als `ByteArray` zurückgibt.

```rust
welcome_message("Judy")
// => Welcome to the Tech Palace, JUDY
```

## 2. Füge einen schicken Rahmen hinzu

Für treue Kunden, die viel im Laden kaufen, möchte der Inhaber die Willkommensanzeige aufhübschen, indem er vor und nach der Willkommensnachricht eine Zeile mit Sternen hinzufügt.
Er ist sich noch nicht sicher, wie viele Sterne in den Zeilen stehen sollen, also möchte er das konfigurierbar machen.

Schreibe eine Funktion `add_border`, die eine Willkommensnachricht (ein `ByteArray`) und die Anzahl der Sterne pro Zeile (Typ `u32`) als Argumente entgegennimmt.
Sie soll ein `ByteArray` zurückgeben, das aus 3 Zeilen besteht: eine Zeile mit der gewünschten Anzahl Sterne, dann die Willkommensnachricht so, wie sie übergeben wurde, und dann noch eine Zeile mit Sternen.

```rust
add_border("Welcome!", 10)
```

Sollte Folgendes zurückgeben:

```bash
**********
Welcome!
**********
```

## 3. Räume alte Werbebotschaften auf

Bevor dieses neue Display installiert wurde, hatte der Laden ein ähnliches Display, das nur nicht konfigurierbare, statische Zeilen anzeigen konnte.
Der Inhaber möchte einige der alten Werbebotschaften auf dem neuen Display weiterverwenden.
Allerdings enthalten die Daten bereits einen Sternenrahmen und einige unglückliche Leerzeichen.
Deine Aufgabe ist es, die Nachrichten aufzuräumen, damit sie weiterverwendet werden können.

Implementiere eine Funktion `clean_up_message`, die die alte Werbebotschaft als `ByteArray` entgegennimmt.
Die Funktion soll zuerst alle Sterne aus dem Text entfernen und danach die führenden und abschließenden Leerzeichen aus dem verbleibenden Text entfernen.
Anschließend soll die Funktion die aufgeräumte Nachricht zurückgeben.

```rust
let message: ByteArray = "
**************************
*    BUY NOW, SAVE 10%   *
**************************
";

clean_up_message(message)
// => BUY NOW, SAVE 10%
```
