# Anleitung

Du bist ein begeisterter Vogelbeobachter und hältst fest, wie viele Vögel deinen Garten besucht haben.
Normalerweise benutzt du eine Strichliste in einem Notizbuch, um die Vögel zu zählen, aber du möchtest besser mit deinen Daten arbeiten.
Die Vogelzahlen pro Tag für die letzten Wochen, die du im Notizbuch festgehalten hast, hast du bereits digitalisiert.

Jetzt möchtest du die Gesamtzahl der Vögel bestimmen, die du gezählt hast, die Vogelanzahl für eine bestimmte Woche berechnen und einen Zählfehler korrigieren.

<!-- prettier-ignore -->
~~~~exercism/note
Verwende zum Üben eine `for`-Schleife, um die folgenden Aufgaben zu lösen.
~~~~

## 1. Bestimme die Gesamtzahl der Vögel, die du bisher gezählt hast

Beginnen wir mit der Analyse der Daten und verschaffen uns einen Überblick.
Finde heraus, wie viele Vögel du insgesamt gezählt hast, seit du mit deinen Aufzeichnungen begonnen hast.

Implementiere eine Funktion `totalBirdCount`, die ein array-ähnliches Objekt mit der Vogelanzahl pro Tag entgegennimmt.
Sie sollte die Gesamtzahl der Vögel zurückgeben, die du gezählt hast.

```javascript
birdsPerDay = [2, 5, 0, 7, 4, 1, 3, 0, 2, 5, 0, 1, 3, 1];
totalBirdCount(birdsPerDay);
// => 34
```

## 2. Berechne die Anzahl der Vögel, die in einer bestimmten Woche zu Besuch kamen

Jetzt, wo du ein allgemeines Gefühl für deine Vogelzahlen bekommen hast, möchtest du eine genauere Analyse machen.

Implementiere eine Funktion `birdsInWeek`, die ein array-ähnliches Objekt mit der Vogelanzahl pro Tag und eine Wochennummer entgegennimmt.
Sie gibt die Gesamtzahl der Vögel zurück, die du in dieser bestimmten Woche gezählt hast.
Du kannst davon ausgehen, dass Wochen immer vollständig erfasst werden.

```javascript
birdsPerDay = [2, 5, 0, 7, 4, 1, 3, 0, 2, 5, 0, 1, 3, 1];
birdsInWeek(birdsPerDay, 2);
// => 12
```

## 3. Korrigiere einen Zählfehler

Du hast festgestellt, dass sich die ganze Zeit, in der du versucht hast, die Vögel zu erfassen, einer in einer weit entfernten Ecke des Gartens versteckt hat.
Du hast herausgefunden, dass dieser Vogel jeden zweiten Tag in deinem Garten war.
Du weißt nicht genau, wo er an den Tagen dazwischen war, aber definitiv nicht in deinem Garten.
Deine Intuition als Vogelbeobachter sagt dir außerdem, dass der Vogel am ersten Tag, den du in deiner Liste erfasst hast, in deinem Garten war.

Schreibe mit diesen neuen Informationen eine Funktion `fixBirdCountLog`, die ein array-ähnliches Objekt mit den pro Tag gezählten Vögeln als Argument entgegennimmt. Sie sollte den Zählfehler korrigieren, indem sie das übergebene Array verändert.

```javascript
birdsPerDay = [2, 5, 0, 7, 4, 1];
fixBirdCountLog(birdsPerDay);
// => [3, 5, 1, 7, 5, 1]
```
