# Über

`when` ist das Schlüsselwort beim Filtern von Ausnahmen. Es wird nach der catch-Anweisung platziert und kann einen booleschen Ausdruck annehmen, der beliebige Werte enthält, die zu diesem Zeitpunkt im Gültigkeitsbereich liegen. Dabei muss es sich nicht nur um Member der Ausnahme selbst handeln. Wenn der Typ der Ausnahme übereinstimmt und der Ausdruck als wahr ausgewertet wird, wird der Block ausgeführt, der zu dieser `catch`-Anweisung gehört; andernfalls wird die nächste `catch`-Anweisung, falls vorhanden, überprüft.

```csharp
try
{
    // do stuff
}
catch (Exception ex) when (ex.Message != "")
{
    // output the message when it is not empty
}
catch (Exception ex)
{
    // show stack trace or something.
}
```

- Dieser [Ausnahmefilter][exception-filters]-Artikel zeigt, wie du Ausnahmen filterst.

[exception-filters]: https://docs.microsoft.com/en-us/dotnet/csharp/language-reference/keywords/when
