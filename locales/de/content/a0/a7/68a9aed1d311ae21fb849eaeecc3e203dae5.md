# Hinweise

## 1. Einen String in einzelne Zeilen aufteilen

- Swift hat eine [Methode][nsstring-components-docs], um einen String mithilfe eines angegebenen Trennzeichens in ein Array von Strings aufzuteilen.

## 2. Vordertür

- Die Wache wird ein Gedicht aufsagen, und du musst das Gedicht in einzelne Zeilen aufteilen. Dafür kannst du eine bereits vorhandene Funktion verwenden.
- Du kannst eine for-Schleife verwenden, um über die Zeilen des Gedichts zu iterieren.
- Du kannst die Eigenschaft `first` eines Strings verwenden, um das erste Zeichen eines Strings zu erhalten.
- Um das erste Zeichen jeder Zeile zu speichern, kannst du ein Array von Zeichen oder einen String verwenden.

## 3. Hintertür

- Die Wache wird ein Gedicht aufsagen, und du musst das Gedicht in einzelne Zeilen aufteilen. Dafür kannst du eine bereits vorhandene Funktion verwenden.
- Du kannst eine for-Schleife verwenden, um über die Zeilen des Gedichts zu iterieren.
- Du kannst die Eigenschaft `last` eines Strings verwenden, um das letzte Zeichen eines Strings zu erhalten.
- Um das letzte Zeichen jeder Zeile zu speichern, kannst du ein Array von Zeichen oder einen String verwenden.

## 4. Geheimraum

- Die Wache wird ein Gedicht aufsagen, und du musst das Gedicht in einzelne Zeilen aufteilen. Dafür kannst du eine bereits vorhandene Funktion verwenden.
- Du kannst eine for-Schleife verwenden, die über die Länge der Zeilen des Gedichts iteriert.
- Swift hat eine [Methode][indexing], um das Zeichen an einem bestimmten Index in einem String zu erhalten.
- Swift hat eine [Methode][uppercased], um einen String in Großbuchstaben umzuwandeln.
