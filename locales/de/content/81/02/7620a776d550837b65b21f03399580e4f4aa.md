# Anleitung

Du bist ein begeisterter Vogelbeobachter und hältst fest, wie viele Vögel in den letzten sieben Tagen deinen Garten besucht haben.

Du hast sechs Aufgaben, die sich alle mit der Anzahl der Vögel befassen, die deinen Garten besucht haben.

## 1. Prüfe, wie die Zählungen letzte Woche waren

Für Vergleiche bewahrst du immer eine Kopie der Zählungen der letzten Woche in der Nähe auf, und zwar: 0, 2, 5, 3, 7, 8 und 4. Implementiere die (_statische_) Methode `BirdCount.LastWeek()`, die die Zählungen der letzten Woche zurückgibt:

```csharp
BirdCount.LastWeek();
// => [0, 2, 5, 3, 7, 8, 4]
```

## 2. Prüfe, wie viele Vögel heute zu Besuch waren

Implementiere die Methode `BirdCount.Today()`, die zurückgibt, wie viele Vögel heute deinen Garten besucht haben. Die Vogelzählungen sind nach Tagen geordnet, wobei das erste Element die Zählung des ältesten Tages und das letzte Element die Zählung von heute ist.

```csharp
int[] birdsPerDay = { 2, 5, 0, 7, 4, 1 };
var birdCount = new BirdCount(birdsPerDay);
birdCount.Today();
// => 1
```

## 3. Erhöhe die Zählung von heute

Implementiere die Methode `BirdCount.IncrementTodaysCount()`, um die Zählung von heute zu erhöhen:

```csharp
int[] birdsPerDay = { 2, 5, 0, 7, 4, 1 };
var birdCount = new BirdCount(birdsPerDay);
birdCount.IncrementTodaysCount();
birdCount.Today();
// => 2
```

## 4. Prüfe, ob es einen Tag ohne Vögel gab

Implementiere die Methode `BirdCount.HasDayWithoutBirds()`, die `true` zurückgibt, wenn es einen Tag gab, an dem null Vögel den Garten besucht haben; andernfalls gib `false` zurück:

```csharp
int[] birdsPerDay = { 2, 5, 0, 7, 4, 1 };
var birdCount = new BirdCount(birdsPerDay);
birdCount.HasDayWithoutBirds();
// => true
```

## 5. Berechne die Anzahl der Vögel, die in den ersten Tagen zu Besuch waren

Implementiere die Methode `BirdCount.CountForFirstDays()`, die die Anzahl der Vögel zurückgibt, die deinen Garten seit Beginn der Woche besucht haben, aber begrenze die Zählung auf die angegebene Anzahl von Tagen ab Beginn der Woche.

```csharp
int[] birdsPerDay = { 2, 5, 0, 7, 4, 1 };
var birdCount = new BirdCount(birdsPerDay);
birdCount.CountForFirstDays(4);
// => 14
```

## 6. Berechne die Anzahl der geschäftigen Tage

Manche Tage sind geschäftiger als andere. Ein geschäftiger Tag ist ein Tag, an dem fünf oder mehr Vögel deinen Garten besucht haben.
Implementiere die Methode `BirdCount.BusyDays()`, die die Anzahl der geschäftigen Tage zurückgibt:

```csharp
int[] birdsPerDay = { 2, 5, 0, 7, 4, 1 };
var birdCount = new BirdCount(birdsPerDay);
birdCount.BusyDays();
// => 2
```
