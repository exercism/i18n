# Anleitung

In deiner Stadt hat ein neuer Poesieclub eröffnet, und du überlegst, hinzugehen.
Weil es in der Vergangenheit Zwischenfälle gab, hat der Club eine ganz besondere Türpolitik, die du beherrschen musst, bevor du einen Einlassversuch unternimmst.

Der Poesieclub hat zwei Türen, eine vordere und eine hintere, und beide werden bewacht.
Um Einlass zu bekommen, musst du das Passwort des Tages herausfinden.

Das Passwort basiert immer auf einem Gedicht und lässt sich in zwei Schritten herleiten.

1. Der Wächter trägt das Gedicht Zeile für Zeile vor, und du musst mit einem passenden Buchstaben dieser Zeile antworten.
2. Der Wächter nennt dir nun alle Buchstaben, mit denen du geantwortet hast, auf einmal, und du musst sie in einem bestimmten Format auf ein Blatt Papier schreiben.

Die Einzelheiten des Ablaufs hängen davon ab, durch welche Tür du hineinwillst.

~~~~exercism/note
Alle Strings in dieser Übung sind ASCII-kodiert und NUL-terminiert.
Das bedeutet, dass alle Zeichen ASCII-kodiert sind und jeder String dort endet, wo das '\0' (das NUL-Zeichen mit dem Wert `0`) steht.
~~~~

~~~~exercism/note
Das sind die String-Anweisungen, die in diesem Konzept erwähnt werden:

| Anweisung | was sie bewirkt                                                                                                                |
|-----------|--------------------------------------------------------------------------------------------------------------------------------|
| `lods`    | lädt einen Wert von einer Speicheradresse, auf die `rsi` zeigt, nach `rax`                                                     |
| `stos`    | speichert einen Wert aus `rax` an einer Speicheradresse, auf die `rdi` zeigt                                                   |
| `movs`    | kopiert einen Wert von einer Speicheradresse, auf die `rsi` zeigt, und speichert ihn an einer Speicheradresse, auf die `rdi` zeigt |

Alle von ihnen brauchen ein Suffix, das die Größe der Operation angibt:

| Suffix | Größe            |
|--------|------------------|
| `b`    | Byte             |
| `w`    | Wort (2 Bytes)   |
| `d`    | dword (4 Bytes)  |
| `q`    | qword (8 Bytes)  |

Alle String-Anweisungen verändern außerdem die Adressen in `rsi` und/oder `rdi` (nur in den Registern, die die Anweisung verwendet).
Standardmäßig erhöhen sie die Adressen um die Größe der Operation.

Das Präfix `rep` kann vor jede der obigen String-Anweisungen gesetzt werden, um sie so oft zu wiederholen, wie `rcx` angibt.
~~~~

## 1. Den ersten Buchstaben eines Satzes ermitteln

Um die Buchstaben für das Passwort der vorderen Tür zu bestimmen, musst du mit dem ersten Buchstaben der Zeile des Gedichts antworten, die dir der Wächter vorträgt.

Damit ein schönes Passwort dabei herauskommt, verwenden die Mitglieder des Poesieclubs gern _akrostische_ Gedichte.
Das heißt, die ersten Buchstaben aller Sätze bilden zusammen ein Wort.
Hier ist ein Beispiel von einem ihrer Lieblingsautoren, Michael Lockwood.

```text
Stands so high
Huge hooves too
Impatiently waits for
Reins and harness
Eager to leave
```

Wenn der Wächter also **Stands so high** vorträgt, antwortest du mit **S**, und wenn er **Huge hooves too** vorträgt, antwortest du mit **H**.

Implementiere die Funktion `front_door_response`, die die Speicheradresse einer Gedichtzeile als Argument nimmt und den ersten Buchstaben dieser Zeile zurückgibt.
Dieser Buchstabe muss als ASCII-kodiertes Zeichen zurückgegeben werden, das 1 Byte belegt.

```c
front_door_response("Stands so high");
// => 'S'
```

## 2. Ein Wort großschreiben

Jetzt, wo du alle richtigen Buchstaben hast, musst du nur noch das Wort richtig großschreiben, um das Passwort für die vordere Tür zu erhalten.

Implementiere die Funktion `front_door_password`, die als Argument die Speicheradresse eines Strings nimmt, der nur die zusammengesetzten Buchstaben aus Aufgabe 1 enthält.
Sie soll den Eingabe-String [in-place][in-place] verändern, sodass er korrekt großgeschrieben ist.
Das bedeutet, dass der korrekte String an derselben Speicherstelle wie die Eingabe stehen muss.

Die Funktion hat keinen Rückgabewert.

```c
front_door_password('SHIRE');
// => buffer == "Shire"

front_door_password('shire');
// => buffer == "Shire"
```

## 3. Den letzten Buchstaben eines Satzes ermitteln

Um die Buchstaben für das Passwort der hinteren Tür zu bestimmen, musst du mit dem letzten Buchstaben der Zeile des Gedichts antworten, die dir der Wächter vorträgt.

Die Mitglieder des Poesieclubs sind wirklich clever.
Das eben erwähnte Gedicht ist außerdem ein _Telestichon_, das heißt, auch die letzten Buchstaben aller Sätze bilden zusammen ein Wort:

```text
Stands so high
Huge hooves too
Impatiently waits for
Reins and harness
Eager to leave
```

Wenn der Wächter **Stands so high** vorträgt, antwortest du mit **h**, und wenn er **Huge hooves too** vorträgt, antwortest du mit **o**.

Beachte, dass der Wächter beim Vortragen des Gedichts manchmal stilistische Pausen macht (in Form von Satzzeichen oder Leerzeichen).
Diese Pausen musst du ignorieren, um den richtigen Buchstaben zu ermitteln.

Implementiere die Funktion `back_door_response`, die als Argument die Speicheradresse einer Gedichtzeile nimmt und den letzten Buchstaben dieser Zeile zurückgibt.
Dieser Buchstabe muss als ASCII-kodiertes Zeichen zurückgegeben werden, das 1 Byte belegt.

```c
back_door_response('Stands so high');
// => "h"

back_door_response('Stands ... so high   ');
// => "h"
```

## 4. Sei höflich

Um über die hintere Tür in den Poesieclub zu gelangen, musst du besonders höflich sein.
Um das Passwort zu ermitteln, musst du diesmal also das Wort richtig großschreiben und `", please."` am Ende anhängen.

Implementiere die Funktion `back_door_password`, die in dieser Reihenfolge folgende Argumente entgegennimmt:

1. Die Speicheradresse eines Buffers, in dem der resultierende String gespeichert wird.
2. Die Speicheradresse eines Strings, der die zusammengesetzten Buchstaben aus Aufgabe 3 enthält.

Die Funktion soll die höfliche Version des großgeschriebenen Passworts im [Puffer][buffer] ablegen.
Ein _Puffer_ ist ein Array, mit dem man Werte im Speicher ablegen kann, um sie zwischen verschiedenen Funktionen zu übergeben.

Diese Funktion hat keinen Rückgabewert.

```c
back_door_password("horse");
// => "Horse, please."
```
