# Über

Eine `do-while`-Schleife ist eine Alternative zur `while`-Schleife, mit dem einzigen Unterschied, dass eine `do-while`-Schleife mindestens einmal durchlaufen wird:

```haxe
var i = 0;

do {
  trace("Hello");
} while (i < 10);
```

Fälle, in denen du eine `do-while`-Schleife brauchst, sind sehr selten, also nimmst du stattdessen die normale `while`-Schleife.
