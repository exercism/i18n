# Über

Der Typ `Bool` ist einer der Grundbausteine der Sprache.
Er dient dazu, zu beschreiben, ob etwas wahr oder falsch ist, und zwar mit den jeweiligen Werten `True` und `False`.
Der Name `Bool` ist die Kurzform von Boolean, einem Teilgebiet der Mathematik, das mit logischem Denken zu tun hat und nach den Arbeiten von George Boole benannt ist.

## Boolesche Operatoren

Es gibt zwei Funktionen und zwei Operatoren, um Werte vom Typ `Bool` zu manipulieren.

- `not : Bool -> Bool`
  Diese Funktion verwandelt `True` in `False` und `False` in `True`.
- `(&&) : Bool -> Bool -> Bool`
  Dieser Operator namens „UND“ nimmt zwei boolesche Werte und gibt `True` zurück, wenn beide `True` sind.
  Zum Beispiel gibt `True && True` `True` zurück, aber `True && False` gibt `False` zurück.
- `(||) : Bool -> Bool -> Bool`
  Dieser Operator namens „ODER“ nimmt zwei boolesche Werte und gibt `True` zurück, wenn mindestens einer davon `True` ist.
  Zum Beispiel gibt `False || False` `False` zurück, aber `True || False` gibt `True` zurück.
- `xor : Bool -> Bool -> Bool`
  Diese Funktion (kein Operator) namens „XOR“ nimmt zwei boolesche Werte und gibt genau dann `True` zurück, wenn einer `True` und der andere `False` ist.

Die Operatoren `&&` und `||` haben nicht dieselbe Priorität.
Die Priorität von `&&` ist höher als die von `||`, genau wie bei der Multiplikation `*` und der Addition `+`.
Folglich ist der Ausdruck `True || False && False` äquivalent zu `True || (False && False)`, was sich von `(True || False) && False` unterscheidet.
Während der erste `True` zurückgibt, gibt der zweite `False` zurück.

## Bedingte Verzweigung

Boolesche Werte sind äußerst nützlich, um im Code Verzweigungen zu erstellen, die nur ausgeführt werden, wenn bestimmte Bedingungen erfüllt sind.
In Elm machst du das mit einem `if-then-else`-Ausdruck, der so aussieht.

```elm
if someCondition || (someOtherCondition && anotherCondition) then
    doSomething
else
    doSomethingElse
```

Der Wert `someCondition` kann jeder Ausdruck sein, der einen `Bool`-Wert zurückgibt.
Wenn dieser boolesche Wert `True` ist, führt der Code `doSomething` aus.
Andernfalls ist er `False`, und der Code führt `doSomethingElse` aus.
Der `else`-Zweig ist Pflicht, anders als in einigen anderen Programmiersprachen.

Wenn du Bedingungen verketten musst, kannst du einfach die `if-then-else`-Ausdrücke verketten.

```elm
if someCondition then
    doSomething
else if someOtherCondition then
    doAnotherThing
else
    doSomethingElse
```
