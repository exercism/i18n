# strings.TrimSpace wird verwendet

Es ist nicht nötig, den Code aufzuräumen, zum Beispiel mit `strings.TrimSpace`.

Bei allen Exercism-Übungen kannst du davon ausgehen, dass der Code Teil einer internen Bibliothek ist und dass es am Rand der Anwendung Code gibt, der das Aufräumen von Eingaben übernimmt, wenn sie ins System gelangen.
