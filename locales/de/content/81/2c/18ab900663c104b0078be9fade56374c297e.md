# Anhang zu den Anweisungen

## Register

| Register | Verwendung      | Typ      | Beschreibung                   |
| -------- | --------------- | -------- | ------------------------------ |
| `$a0`    | Eingabe         | Ganzzahl | Anzahl der Zeilen des Dreiecks |
| `$a1`    | Eingabe/Ausgabe | Adresse  | Array von Wörtern              |
| `$v0`    | Ausgabe         | Ganzzahl | Anzahl der ausgegebenen Wörter |
| `$t0-9`  | temporär        | beliebig | zur temporären Speicherung     |
