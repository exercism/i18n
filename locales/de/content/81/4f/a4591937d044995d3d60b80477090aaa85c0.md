# Einführung

## Ganzzahlen

In Elixir gibt es zwei verschiedene Arten von Zahlen: Ganzzahlen und Gleitkommazahlen.

Ganzzahlen sind Zahlen ohne Nachkommateil.

```elixir
integer = 3
# => 3
```

## Gleitkommazahlen

Gleitkommazahlen sind Zahlen mit einer oder mehreren Ziffern hinter dem Dezimaltrennzeichen. Sie verwenden das 64-Bit-Gleitkommaformat mit doppelter Genauigkeit.

```elixir
float = 3.45
# => 3.45
```

### Mit Zahlen arbeiten

In den Modulen [`Integer`][integer-functions] und [`Float`][float-functions] findest du nützliche Funktionen für die Arbeit mit diesen Typen. Die grundlegenden arithmetischen Operatoren sind im Modul [`Kernel`][kernel-arithmetic-operators] definiert.

### Umwandlung

Ganzzahlen und Gleitkommazahlen können in einem einzigen arithmetischen Ausdruck gemischt werden. Sobald eine Gleitkommazahl in einem Ausdruck vorkommt, ist auch das Ergebnis eine Gleitkommazahl.

```elixir
2 * 3
# => 6

2 * 3.0
# => 6.0
```

Bei einer Division ist das Ergebnis jedoch immer eine Gleitkommazahl, selbst wenn nur Ganzzahlen verwendet werden.

```elixir
6 / 2
# => 3.0
```

Um eine Gleitkommazahl in eine Ganzzahl umzuwandeln, kannst du den Dezimalteil mit [`trunc/1`][trunc-1] verwerfen.
