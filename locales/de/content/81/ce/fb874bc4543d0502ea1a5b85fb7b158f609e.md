# Hinweise

## Allgemein

- [Nicht behebbare Fehler][unrecoverable]: löse einen Panic mit Fehlermeldung aus.
- [`panic!`-Makro][panic-excl-macro]: löse einen Panic mit einer `ByteArray`-Fehlermeldung aus.
- [`assert!`-Makro][assert]: löse einen Panic aus, wenn eine Bedingung zu `false` ausgewertet wird.
- [Result-Enum][result]: wie du das `Result`-Enum verwendest.

## 2. Ungültige Operationen behandeln

- Hier musst du [einen Fehler zurückgeben][result].

## 3. Fehlende Operation behandeln

- Hier musst du [panic][panic-excl-macro] mit einer `ByteArray`-Nachricht auslösen, um leere Strings als Operationen zu behandeln.

## 4. Fehler bei Division durch Null behandeln

- Hier musst du einen Panic auslösen, um die Division durch Null zu behandeln.
