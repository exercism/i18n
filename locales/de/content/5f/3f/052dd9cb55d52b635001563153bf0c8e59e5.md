# Einführung

## Datensätze

Ein Datensatz ist eine Sammlung von Feldern (die unterschiedliche Typen haben können), die zusammengehören. Um einen Datensatz zu definieren, wird das Schlüsselwort `type` verwendet. Die Felder eines Datensatzes werden zwischen den Zeichen `{` und `}` definiert, und jedes Feld hat einen Namen _und_ einen Typ. Um einen Datensatz zu erstellen, gib die Namen der Felder an und weise ihnen zwischen den Zeichen `{` und `}` einen Wert zu. Bei der Erstellung eines Datensatzes müssen alle Felder einen Wert erhalten. Auf die Feldwerte einer Datensatzinstanz kann mit Punktnotation zugegriffen werden.

Beim Definieren oder Erstellen eines Datensatzes muss sich jedes Feld entweder in einer eigenen Zeile befinden oder, wenn es in einer einzigen Zeile steht, durch Semikolons (`;`) getrennt werden.

```fsharp
// Define a record
type Address =
    { Street: string
      HouseNumber: int }

// Create a record
let oldAddress: Address =
    { Street = "Main Street"
      HouseNumber = 17 }

// Single-line alternative
type ConciseAddress = { Street: string; HouseNumber: int }
let conciseAddress: ConciseAddress = { Street = "Main Street"; HouseNumber = 17 }
```

Da Datensätze unveränderlich sind, können sich die Feldwerte eines Datensatzes nach seiner Erstellung nie ändern. Wenn du die Werte eines Datensatzes ändern möchtest, kannst du mit dem Schlüsselwort `with` eine Kopie eines vorhandenen Datensatzes erstellen, allerdings mit neuen Werten für ein oder mehrere Felder.

```fsharp
// Copy the old address but change the house number
let newAddress: Address = { oldAddress with HouseNumber = 86 }
newAddress.Street      // => "Main Street"
newAddress.HouseNumber // => 86
```

Datensätze haben _strukturelle Gleichheit_, was bedeutet, dass zwei Instanzen desselben Datensatzes mit identischen Werten äquivalent sind.

Neben der Möglichkeit, mit Punktnotation auf die Felder eines Datensatzes zuzugreifen, können Datensätze auch in Bindungen und im Musterabgleich _dekonstruiert_ werden:

```fsharp
let myAddress: Address = { Street = "Broadway"; HouseNumber = 123 }
let { Street = myStreet; HouseNumber = myHouseNumber } = myAddress

match myAddress with
| { HouseNumber = 1 } -> printfn "First house"
| { HouseNumber = houseNumber; Street = street } -> printfn "House number %d on %s" houseNumber street
// => "House number 123 on Broadway
```
