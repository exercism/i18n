# Installation

## Linux

Bash, die GNU-Shell, findest du auf jedem GNU/Linux-System.
Bei BSD und anderen UNIX-Derivaten musst du sie wahrscheinlich selbst installieren.
Wenn du BSD, AIX oder ein Linux ohne bash verwendest, schau in den Ressourcen deines Betriebssystems nach, wie du Pakete außerhalb des Kerns installierst.

Such in deiner grafischen Oberfläche deiner Wahl nach einer Anwendung namens „Terminal": Du findest sie vielleicht unter einem Abschnitt „Administrative/System Tools".

Um die verfügbare Bash-Version zu prüfen, führe in der Kommandozeile oder im Terminal aus:

    echo $BASH_VERSION

Wenn deine Shell `bash` ist, sollte die Ausgabe ungefähr so aussehen:

    4.4.19(1)-release

Du musst sonst nichts weiter tun. Bash sollte zu diesem Zeitpunkt bereits installiert sein und in deinem Pfad liegen, denn sie ist deine aktuelle Shell.

Wenn deine Shell nicht bash ist, gibt es keinen Grund, das zu ändern.
Du kannst Bash-Skripte schreiben und ausführen, ohne dich in einer Bash-Shell zu befinden.

Um die installierte Bash-Version zu prüfen, führe aus:

```plain
bash --version
```

Die Ausgabe sieht ungefähr so aus:

```
GNU bash, version 4.4.19(1)-release (x86_64-pc-linux-gnu)
Copyright (C) 2016 Free Software Foundation, Inc.
License GPLv3+: GNU GPL version 3 or later <http://gnu.org/licenses/gpl.html>

This is free software; you are free to change and redistribute it.
There is NO WARRANTY, to the extent permitted by law.
```

Wenn nicht, ist bash bei dir vielleicht nicht installiert.
Installiere sie dann mit dem Paketmanager deiner Distribution.

## Windows

Unter Windows 10 kannst du [WSL](https://docs.microsoft.com/en-us/windows/wsl/about) installieren.
Damit installierst du eine vollständige (na ja, die Komponenten ohne grafische Oberfläche) Linux-Distribution, die nativ unter Windows läuft.

Alternativ kannst du installieren:

* [Cygwin](https://cygwin.com/)
* [git for windows](https://gitforwindows.org/)
* [MinGW](http://mingw.org/)
* eine vollständige Linux-Distribution in [einer virtuellen Maschine](https://docs.microsoft.com/en-us/virtualization/hyper-v-on-windows/about/)

## MacOS

Für Apple OSX:

* öffne den Finder,
* öffne deinen „Applications"-Ordner,
* öffne den „Utilities"-Ordner,
* und öffne schließlich die Anwendung `Terminal`.

Beachte, dass die unter MacOS installierte Bash-Version sehr alt ist, nämlich Version 3.2.
Das liegt daran, dass (i) neuere Bash-Versionen unter der GPLv3 lizenziert sind und (ii) Apple nicht gezwungen sein möchte, die Bedingungen dieser Lizenz einzuhalten.
Außerdem hat Apple angedeutet, dass bash aus MacOS verschwinden wird: Die Standard-Login-Shell wurde kürzlich [von bash zu zsh geändert](https://support.apple.com/en-us/HT208050).

So bekommst du ein aktuelles bash auf deinem Mac:

1. installiere [Homebrew](https://brew.sh)
1. gib in einem Terminal ein: `brew install bash`

Damit wird ein aktuelles bash (ich glaube) als `/usr/local/bin/bash` installiert (damit das Standard-bash des Systems nicht überschrieben wird, denn andere Tools könnten auf /bin/bash angewiesen sein).

Wenn du möchtest, dass beim Tippen von `bash` das Homebrew-bash gestartet wird, dann bearbeite deine Datei ~/.bash_profile (oder ~/.profile) und setze /usr/local/bin im PATH *vor* /bin:

    PATH=/usr/local/bin:$PATH
