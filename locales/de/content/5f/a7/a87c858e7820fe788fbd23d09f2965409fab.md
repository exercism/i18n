# Tests

## Den Code schreiben

Schreibe deinen Code in `src/lib.cairo`.
Zu den Übungen gehört eine Stub-Datei in `src/lib.cairo`, die dir die Signaturen des Codes zeigt, den du schreiben musst.

Bei den meisten Übungen ist es am besten, deinen gesamten Code in der Datei `src/lib.cairo` zu schreiben.
Wenn du deine Lösung auf mehrere Dateien aufteilen möchtest, schau dir das [Kapitel über Module][chapter-modules] im Cairo Book an.

[chapter-modules]: https://book.cairo-lang.org/ch07-02-defining-modules-to-control-scope.html

## Tests ausführen

Um die Tests auszuführen, musst du zuerst dein Arbeitsverzeichnis in das Verzeichnis der Übung wechseln, die du testen möchtest:

```bash
cd path/to/exercise
```

Und dann führst du den folgenden Befehl aus:

```bash
scarb cairo-test
```

Standardmäßig ist nur der erste Test aktiviert.
Wenn du bereit bist, den nächsten Test zu bestehen, entfernst du das ignore-Flag vom nächsten Test (`#[ignore]`).

Um alle Tests einschließlich der ignorierten auszuführen, kannst du das Flag `ignore` von allen Tests entfernen oder einfach Folgendes ausführen:

```bash
scarb cairo-test --include-ignored
```

Du kannst ruhig so wenig Code wie möglich schreiben, damit die Tests bestehen.
Die Fehlermeldungen der Tests zeigen dir, was du als Nächstes schreiben solltest.

Da Cairo den gesamten Code zur Kompilierzeit prüft, kann es sein, dass deine Tests erst kompilieren, wenn du den erforderlichen Code geschrieben hast.
Auch Tests, die mit `ignore` markiert sind, werden zur Kompilierzeit geprüft.
Du kannst Tests, die nicht kompilieren, [auskommentieren][comments], indem du jede Zeile mit `//` beginnst.
Wenn du dann bereit bist, an diesem Test zu arbeiten, kannst du die Kommentarzeichen wieder entfernen.
Cairo hat außerdem ein spezielles Makro namens `panic!()`, das du auf unfertigen Codepfaden verwenden kannst, damit dein Programm kompiliert.

[comments]: https://book.cairo-lang.org/ch02-04-comments.html
