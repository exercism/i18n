# Ergänzung zur Anleitung

## Implementierung

In dieser Übung musst du eine Funktion aufrufen, die als Argument übergeben wird.
In Uiua geht das über [Makros](https://www.uiua.org/tutorial/macros), und genau so erwartet diese Übung, dass du sie löst.

```exercism/note
Du erkennst sofort, dass ein Binding ein Makro ist, weil es das Suffix `!` hat.
```
