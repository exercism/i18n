# Überblick

Bedingte Anweisungen führen unterschiedlichen Code aus, je nachdem, ob eine Bedingung `true` oder `false` ist.

Eine [`if`-Anweisung][if_statement] führt ihren Block nur aus, wenn ihre Bedingung `true` ist.
Go kennt keine truthy- oder falsy-Werte, deshalb muss die Bedingung vom Typ `bool` sein.
Ausdrücke wie `if mySlice { ... }` oder `if 1 { ... }` sind Kompilierfehler.

```go
func describe(val string) string {
    if val == "val" {
        return "was val"
    }
    return "was not val"
}
```

Mit `else if` prüfst du weitere Bedingungen, und mit `else` fängst du den Fall ab, dass keine davon zutrifft.
Die Bedingungen werden von oben nach unten ausgewertet, und nur der erste Zweig, dessen Bedingung wahr ist, wird ausgeführt.

```go
number := 0
result := "This number is "

if number > 0 {
    result += "positive"
} else if number < 0 {
    result += "negative"
} else {
    result += "zero"
}
```

Im Allgemeinen kehrt Go lieber früh aus dem Ausnahmefall zurück und vermeidet `else`.

```go
func getVal(connected bool) int {
    if !connected {
        return readLocalVal()
    }

    return readVal()
}
```

Eine `if`-Anweisung kann außerdem eine kurze Initialisierungsanweisung enthalten.
Das wird häufig genutzt, um direkt nach einem Aufruf einen Fehler zu prüfen:

```go
num := 7
if v := 2 * num; v > 10 {
    fmt.Println(v)
} else {
    fmt.Println(num)
}
// Output: 14
```

Variablen, die in der Initialisierungsanweisung deklariert werden, sind nur innerhalb der gesamten `if`/`else`-Kette im Gültigkeitsbereich.
Bemerkenswert ist, dass Go keinen Ternär-Operator hat. Das ist eine bewusste Designentscheidung, damit der Code leicht zu überfliegen ist.
