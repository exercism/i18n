# Hinweise

## Allgemein

- Das Modul `gleam/string` enthält viele nützliche [String-Funktionen][stdlib].

## 1. Nachricht aus einer Log-Zeile auslesen

- Mit dem Operator `<>` kannst du im Pattern Matching den Anfang eines Strings abgleichen.
- Das Modul `gleam/string` hat eine [Funktion][trim], die umgebende Leerzeichen aus einem String entfernt.

## 2. Log-Level aus einer Log-Zeile auslesen

- Das Modul `gleam/string` hat eine [Funktion][lowercase], die einen String in Kleinbuchstaben umwandelt.

## 3. Eine Log-Zeile umformatieren

- Mit dem Operator `<>` kannst du Strings miteinander verbinden.

[trim]: https://hexdocs.pm/gleam_stdlib/gleam/string.html#trim
