# Über

Boolesche Werte werden in C# durch den Typ `bool` dargestellt, dessen Werte entweder `true` oder `false` sein können.

C# unterstützt vier [boolesche Operatoren][operators]: `!` (NOT), `&&` (AND), `||` (OR) und `^` (XOR). Die Operatoren `&&` und `||` verwenden die _Kurzschlussauswertung_. Das heißt, die rechte Seite des Operators wird nur ausgewertet, wenn sie gebraucht wird.

```csharp
true || false // => true
true && false // => false
true ^ false  // => true
true ^ true   // => false
```

Die drei booleschen Operatoren haben jeweils eine unterschiedliche [_Operatorrangfolge_][precedence]. Deshalb werden sie in dieser Reihenfolge ausgewertet: `not` zuerst, `&&` danach, `^` als Drittes und schließlich `||`. Wenn du diese Regeln „umgehen“ willst, kannst du einen booleschen Ausdruck in runde Klammern (`()`) setzen, denn die Klammern haben eine noch höhere Operatorrangfolge.

```csharp
!true && false   // => false
!(true && false) // => true
```
