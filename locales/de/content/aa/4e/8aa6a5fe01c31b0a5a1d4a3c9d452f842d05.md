# Einführung

In Elixir kannst du Modulattribute definieren und sie in deinen Funktionen als Konstanten verwenden.

```elixir
defmodule Example do
  # Defines the attribute as the value 1
  @constant_number 1

  def example_value() do
    # Returns the value 1
    @constant_number
  end
end
```

Verwendest du Attribute, um Modulkonstanten zu definieren, kann es sich um einen beliebigen Ausdruck handeln, der zur Kompilierungszeit ausgewertet werden kann. Nach der Kompilierung sind Modulattribute nicht mehr verfügbar, weil sie während der Kompilierung expandiert werden, ähnlich wie definierte Makros in Sprachen wie C.
