# Ergänzung zu den Anweisungen

## Register

| Register | Verwendung | Typ             | Beschreibung                                                      |
| -------- | ---------- | --------------- | ----------------------------------------------------------------- |
| `$a0`    | Eingabe    | Adresse         | nullterminierter Eingabestring                                    |
| `$v0`    | Ausgabe    | boolescher Wert | Die Eingabe hat passende Klammern (`0` = `false`, `1` = `true`)   |
| `$t0-9`  | temporär   | beliebig        | wird für temporäre Speicherung verwendet                          |
