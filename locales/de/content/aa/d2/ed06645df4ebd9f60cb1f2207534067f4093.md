# Über

[Anonyme Funktionen][anon-fns] werden in Elixir häufig verwendet, sowohl allein als auch als Rückgabewerte und als Argumente in Funktionen höherer Ordnung wie `Enum.map/2`:

```elixir
Enum.map([1, 2, 3], fn n -> n + 1 end)
# => [2, 3, 4]
```

Funktionen sind in Elixir Bürger erster Klasse:

- Benannte und anonyme Funktionen können Variablen zugewiesen werden.
- Benannte und anonyme Funktionen können wie Daten herumgereicht werden, als Argumente und als Rückgabewerte.
- Anonyme Funktionen können dynamisch erstellt werden.

Anonyme Funktionen werden mit dem Schlüsselwort [`fn`][kernel-fn] erstellt und mit einem Punkt (`.`) aufgerufen:

```elixir
function_variable = fn n -> n + 1 end

function_variable.(1)
# => 2
```

Anonyme Funktionen können auch mit der Capture-Kurzschreibweise [`&`][kernel-capture] erstellt werden.

- Das `&` am Anfang kennzeichnet den Beginn des Capture-Ausdrucks.
- `&1`, `&2` und so weiter verweisen auf die Positionsargumente der anonymen Funktion.

  ```elixir
  # Instead of:
  fn x, y -> abs(x) + abs(y) end

  # We can write:
  &(abs(&1) + abs(&2))
  ```

- Mit dem `&`-Capture-Operator kannst du auch eine [bestehende benannte Funktion _capturen_][capture]:

  ```elixir
  # Instead of:
  fn a, b -> a <= b end

  # We can capture the function using its name and arity:
  &<=/2
  ```

Anonyme Funktionen sind in Elixir [Closures][closure]. Sie können auf Variablen zugreifen, die sich im Gültigkeitsbereich befinden, wenn die Funktion definiert wird. Variablen, die innerhalb einer anonymen Funktion zugewiesen werden, sind außerhalb von ihr nicht zugänglich:

```elixir
y = 2

square = fn ->
  x = 3
  x * y
end

square.()
# => 6

x
# => ** (CompileError): undefined function x/0
```
