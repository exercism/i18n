# Ergänzung zur Anleitung

## Register

| Register | Verwendung | Typ     | Beschreibung                                          |
| -------- | ---------- | ------- | ----------------------------------------------------- |
| `$a0`    | Eingabe    | Ganzzahl | Startzahl                                             |
| `$v0`    | Ausgabe    | Ganzzahl | erwartete Anzahl an Schritten, -1 wenn die Zahl ungültig ist |
| `$t0-9`  | temporär   | beliebig | dient als temporärer Speicher                         |
