# Überblick

ABAP unterstützt die üblichen arithmetischen Operatoren für numerische Werte:

- `+` addiert Werte.
- `-` subtrahiert Werte.
- `*` multipliziert Werte.
- `/` dividiert Werte.
- `MOD` gibt den Rest einer Ganzzahldivision zurück.

```abap
DATA total TYPE i.
total = 6 + 4 * 2.

DATA remaining_days TYPE i.
remaining_days = 70 MOD 22.
```

Multiplikation und Division werden vor Addition und Subtraktion ausgewertet. Verwende runde Klammern, wenn eine Berechnung ausdrücklich gruppiert werden soll.

```abap
DATA result TYPE i.
result = ( 6 + 4 ) * 2.
```
