# Einführung

Beim Mapping wird eine Funktion auf jedes Element einer Sequenz angewendet, um eine neue Sequenz zu erzeugen.

Das lässt sich leicht mit der Funktion `mapcar` für eine Liste erledigen.
Nehmen wir an, wir haben eine Funktion `double`, die ihr Argument mit `2` multipliziert:

```lisp
(mapcar #'double '(1 2 3 4)) ; => (2 4 6 8)
```

Beachte, dass das erste Argument eine aufzurufende Funktion ist. Das `#'` ist eine spezielle Quoting-Syntax, um eine Funktion anzugeben.

`double` wurde zuerst mit dem ersten Element aufgerufen, dann mit dem zweiten usw.
Die Ergebnisse wurden in einer Liste gesammelt. Diese Liste ist der Wert, zu dem der Ausdruck ausgewertet wird.
