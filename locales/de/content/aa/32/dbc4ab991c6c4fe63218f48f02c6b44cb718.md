# Über

`awk` ist eine interpretierte Programmiersprache, die für die Textverarbeitung entwickelt wurde und typischerweise genutzt wird, um Daten zu extrahieren und Berichte zu erstellen.
Sie ist Standardbestandteil der meisten Unix-ähnlichen Betriebssysteme und hat eine [POSIX-Spezifikation][posix].

Man kann das Programmierparadigma von `awk` als „datengetrieben“ bezeichnen:
Ein `awk`-Programm liest Zeilen (oder andere Texteinheiten) und sucht nach Übereinstimmungen mit _Mustern_.
Wenn eine Übereinstimmung gefunden wird, wird die angegebene _Aktion_ ausgeführt.

Ein `awk`-Programm sieht ungefähr so aus:
```awk
pattern1 {action1}
pattern2 {action2}
...
```

Das _Muster_ kann ein regulärer Ausdruck sein oder ein anderer Ausdruck, der den Wert wahr oder falsch ergibt.
Das _Muster_ kann weggelassen werden; in diesem Fall wird die _Aktion_ für jeden Textdatensatz ausgeführt.
Die _Aktion_ kann weggelassen werden; in diesem Fall besteht die Standardaktion darin, den aktuellen Datensatz auszugeben.

`awk` ist eine hervorragende Ergänzung für den Werkzeugkasten eines jeden Nutzers.
Es eignet sich hervorragend für kurze „Einzeiler“, die auf der Kommandozeile eingegeben werden.
Ein einziges `awk`-Programm kann die meisten Pipelines aus `grep`, `sed`, `tr` und `cut` ersetzen.

## Implementierungen

`awk` wurde 1977 von den Autoren Alfred Aho, Peter Weinberger und Brian Kernighan erfunden (deren Nachnamen der Sprache ihren Namen geben).
Diese Implementierung ist als „old awk“ bekannt geworden.
1985 wurde eine verbesserte Version veröffentlicht, die als „BWK awk“, „new awk“ oder „the one-true-awk“ bekannt ist.
Sie ist die Version, die mit macOS und einigen der \*BSD-Distributionen ausgeliefert wird.

Eine weitere verbreitete Implementierung ist `mawk`, die auf einem Bytecode-Interpreter basiert.
`mawk` ist sehr schnell.
`mawk` ist das standardmäßige `/usr/bin/awk`, das mit vielen Linux-Distributionen ausgeliefert wird.

### GNU awk

In diesem Track wird `gawk` verwendet, GNUs Implementierung von awk.
`gawk` erreicht vielleicht nicht die rohe Geschwindigkeit von `mawk`, ist aber sehr funktionsreich, gut dokumentiert und bietet einige praktische Kommandozeilenoptionen.

### Shebang

Je nach Plattform können awk-Skripte ausgeführt werden, indem man eine [Shebang][shebang]-Zeile an den Anfang der Datei setzt.
Auf den meisten Systemen sollte einer der beiden folgenden Shebangs funktionieren.
Da es jedoch keinen einzigen Shebang gibt, der auf allen Systemen funktioniert, haben wir uns entschieden, Shebangs wegzulassen.

```bash
#!/usr/bin/env -S gawk -f
#!/usr/bin/gawk -f
```
