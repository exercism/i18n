# Tests auf der Kommandozeile

Führe die Tests so aus:

```bash
$ cargo test
```

Alle Tests außer dem ersten wurden ignoriert. Wenn du den ersten Test bestanden hast, öffne die Quelldatei der Tests im Verzeichnis `tests`, entferne das Flag `#[ignore]` beim nächsten Test und bring auch ihn zum Laufen. Jeder einzelne Test ist eine Funktion mit dem Flag `#[test]` darüber. Mach so weiter, bis du alle Tests bestanden hast.

Wenn du _nur ignorierte_ Tests ausführen möchtest, ohne die Quelldatei der Tests zu bearbeiten, verwende:

```bash
$ cargo test -- --ignored
```

Wenn du Rust 1.51 oder neuer verwendest, kannst du _alle_ Tests so ausführen:

```bash
$ cargo test -- --include-ignored
```

Um einen bestimmten Test auszuführen, zum Beispiel `some_test`, kannst du Folgendes verwenden:

```bash
$ cargo test some_test
```

Wenn der jeweilige Test ignoriert ist, verwende:

```bash
$ cargo test some_test -- --ignored
```

Mehr über Rust-Tests erfährst du in der [Testdokumentation][rust-tests].

[rust-tests]: https://doc.rust-lang.org/book/ch11-02-running-tests.html
