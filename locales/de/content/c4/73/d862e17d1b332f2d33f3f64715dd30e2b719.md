# Überblick

Wenn Typen nicht implizit umgewandelt werden können, musst du einen expliziten [Cast-Operator][cast-operator] verwenden.
Der Cast-Operator ist nichts weiter als der Zieltyp in Klammern vor dem Wert, den du umwandeln möchtest:

```csharp

int i = 7;
byte b = (byte)i; // Explicit cast from int to byte
```

Die Verwendung eines expliziten Casts ist potenziell gefährlich. Die zwei häufigsten Fehler sind:

- Ein Cast in einen inkompatiblen Typ. Zur Laufzeit wird dadurch eine Ausnahme ausgelöst.
- Ein Cast in einen numerischen Wert, der nicht „breit“ genug ist. Bei Ganzzahlen kann das zu einem Vorzeichenkonflikt oder zu einer Overflow-Ausnahme führen.

Hinweis: Ein Ausdruck vom Typ `int` kann explizit in `char` umgewandelt werden. Dabei kann ein ungültiges `char` entstehen.

[cast-operator]: https://docs.microsoft.com/en-us/dotnet/csharp/language-reference/operators/type-testing-and-cast#cast-expression
