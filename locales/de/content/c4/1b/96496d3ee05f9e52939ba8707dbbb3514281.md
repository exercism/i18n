# Ergänzende Anweisungen

## Register

| Register | Verwendung   | Typ     | Beschreibung                                       |
| -------- | ------------ | ------- | -------------------------------------------------- |
| `$a0`    | Eingabe      | Ganzzahl | Anzahl der Eingabeziffern                          |
| `$a1`    | Eingabe      | Ganzzahl | Basis für die Eingabeziffern                       |
| `$a2`    | Eingabe      | Ganzzahl | Basis für die Ausgabeziffern                       |
| `$a3`    | Eingabe/Ausgabe | Adresse | überschreibbares Array von Ziffernwörtern       |
| `$v0`    | Ausgabe      | Ganzzahl | Anzahl der Ausgabeziffern, -1 wenn die Eingabe ungültig ist |
| `$t0-9`  | temporär     | beliebig | wird für die temporäre Speicherung verwendet      |
