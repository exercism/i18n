# Über

Nim ist eine Allzweck-Programmiersprache, die von Andreas Rumpf entworfen und entwickelt wurde und erstmals 2008 erschien.
Sie ist darauf ausgelegt, effizient, ausdrucksstark und elegant zu sein.
Nim ist statisch typisiert und kompiliert, lässt dich aber eleganten Code schreiben, der effizient läuft.
Mit Nim kannst du viele Plattformen ansteuern, indem du den Code nach C, C++, JavaScript oder Objective-C kompilierst.
Die Syntax von Nim ähnelt Python und teilt viele von Pythons Eigenschaften, lässt sich aber von einer Reihe von Sprachen inspirieren, etwa C, C++, C#, Lisp, Ada, Go, Oberon und anderen.

Da Nim eine Allzweck-Programmiersprache ist, lässt sie sich überall einsetzen, doch vor allem füllt sie eine echte Nische in der Spieleentwicklung und der Systemprogrammierung, auch bei eingebetteten Systemen.

Nim bietet dir viel von dem Komfort, den du aus Python und anderen Sprachen kennst: eine gut lesbare Syntax, ein Paketverwaltungssystem für neue Bibliotheken in deinen Projekten und benutzerfreundliche Tracebacks beim Debuggen von Fehlern.

Nim bietet dir die Geschwindigkeit und Portabilität von C, aber mit einem leistungsstarken Garbage Collector und einer eleganten Syntax, die die Sprache für Neueinsteiger sehr zugänglich macht.
Nim gibt dir außerdem die Kontrolle: Du kannst den Garbage Collector wechseln oder ihn ganz abschalten und dich selbst um die Speicherverwaltung kümmern.
Mit Nim stehen dir vielfältige Programmierparadigmen und Abstraktionsebenen zur Verfügung.
