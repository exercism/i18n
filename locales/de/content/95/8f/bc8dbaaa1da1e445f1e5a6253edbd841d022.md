# Über

Eine Sammlung wird meist mit einem Platzhalter in spitzen Klammern definiert, üblicherweise `T`. Eine solche Sammlung nennt man einen generischen Typ. Dadurch kann, wer die Sammlung verwendet, festlegen, welchen Typ von Elementen die Sammlung speichert. Im obigen Beispielcode instanziieren wir eine Liste von Strings.

Eine Klasse oder eine Funktion wird **generisch**, indem du das Attribut `@:generic` verwendest. Dadurch erkennt der Compiler die Klasse oder die Funktion als generisch:

```haxe
@:generic
class MyValue<T> {
  public var value:T;

  public function new(value:T) {
    this.value = value;
  }
}

var a = MyValue<String>("Hello");
trace(a.value); // Hello
```
