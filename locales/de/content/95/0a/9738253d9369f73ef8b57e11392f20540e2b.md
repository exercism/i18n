# Einführung

Fehler passieren. In Elixir heißt es zwar oft „let it crash“, doch manchmal müssen wir den Funktionsaufruf abfangen und in einen bekannten guten Zustand überführen, um einen Softwarevertrag zu erfüllen. In manchen Sprachen dienen Fehler als Mittel zur Ablaufsteuerung, in Elixir ist dieses Muster jedoch verpönt. Oft erkennen wir Funktionen, die einen Fehler auslösen können, schon an ihrem Namen: Funktionen, die Fehler auslösen, haben ein `!` am Ende ihres Namens. Das unterscheidet sie von Funktionen, die `{:ok, value}` oder `:error` zurückgeben. Schau dir diese Beispiele aus der Bibliothek an:

```elixir
Map.fetch(%{a: 1}, :b)
# => :error
Map.fetch!(%{a: 1}, :b)
# => raises KeyError
```
