# Hinweise

## Allgemein

- Eine Zahl mit einem bestimmten Typ deklarierst du, indem du den Typ an die Zahl anhängst, z. B. `42_u8` für eine vorzeichenlose 8-Bit-Ganzzahl.
- Zwischen verschiedenen Typen konvertierst du, indem du die Methode `to_<type>` auf der Zahl aufrufst, z. B. `42u8.to_u16` für eine vorzeichenlose 16-Bit-Ganzzahl.

## 1. Navigationskonstanten

- Du musst [Konstanten][constants] definieren, die eine [Ganzzahl][integers] enthalten sollen.
- Die Konstante soll innerhalb der Klasse `Navigation` deklariert werden.
- Die Konstante muss außerhalb jeder Methode deklariert werden.

## 2. Korrekte Flächenanalyse

- Du musst den Eingabewert in eine vorzeichenlose Ganzzahl umwandeln.

## 3. Geschwindigkeit berechnen

- Um die Geschwindigkeit zu erhalten, teilst du die Strecke durch die Zeit.
- Das Ergebnis einer numerischen Operation hat den Typ mit der höchsten Genauigkeit, also musst du das Ergebnis in den richtigen Typ umwandeln.

[constants]: https://crystal-lang.org/reference/syntax_and_semantics/constants.html
[integers]: https://crystal-lang.org/reference/latest/syntax_and_semantics/literals/integers.html
