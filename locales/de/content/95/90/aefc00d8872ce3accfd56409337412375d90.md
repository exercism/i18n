# Über Maps

Eine **Map** ist eine Datenstruktur zum Speichern von Schlüssel-Wert-Paaren.
Sie ähnelt Wörterbüchern in anderen Programmiersprachen.
Die [Map][map-javadoc]-Schnittstelle definiert die Operationen, die du mit einer Map ausführen kannst.

## HashMap

Java hat eine Reihe verschiedener Map-Implementierungen.
[HashMap][hashmap-javadoc] ist eine häufig verwendete.

```java
// Make an instance
Map<String, Integer> fruitPrices = new HashMap<>();
```

~~~~exercism/note
Wenn du eine `Map`-Variable definierst, empfiehlt es sich, die Variable als Typ `Map` zu definieren statt als konkreten Typ, wie im obigen Beispiel.
Diese Vorgehensweise erleichtert es, die `Map`-Implementierung später zu ändern.
~~~~

`HashMap` hat auch einen Kopierkonstruktor.

```java
// Make a copy of a map
Map<String, Integer> copy = new HashMap<>(fruitPrices);
```

Füge Einträge mit [put][map-put-javadoc] zur Map hinzu.

```java
fruitPrices.put("apple", 100);
fruitPrices.put("pear", 80);
// => { "apple" => 100, "pear" => 80 }
```

Mit jedem Schlüssel kann nur ein Wert verknüpft werden.
Wenn du `put` mit demselben Schlüssel aufrufst, wird der Wert des Schlüssels aktualisiert.

```java
fruitPrices.put("pear", 40);
// => { "apple" => 100, "pear" => 40 }
```

Verwende [get][map-get-javadoc], um den Wert für einen Schlüssel abzurufen.

```java
fruitPrices.get("apple"); // => 100
```

Verwende [containsKey][map-containskey-javadoc], um zu prüfen, ob die Map einen bestimmten Schlüssel enthält.

```java
fruitPrices.containsKey("apple");   // => true
fruitPrices.containsKey("orange");  // => false
```

Entferne Einträge mit [remove][map-remove-javadoc].

```java
fruitPrices.put("plum", 90);  // Add plum to map
fruitPrices.remove("plum");   // Removes plum from map
```

Die Methode [size][map-size-javadoc] gibt die Anzahl der Einträge zurück.

```java
fruitPrices.size();  // Returns 2
```

Du kannst die Methoden [keySet][map-keyset-javadoc] oder [values][map-values-javadoc] verwenden, um die Schlüssel bzw. die Werte einer Map als Set oder Collection zu erhalten.

```java
fruitPrices.keySet();  // Returns "apple" and "pear" in a set
fruitPrices.values();  // Returns 100 and 80, in a Collection
```

## HashMap verwendet `hashCode` und `equals`

HashMaps verwenden die Methoden [hashCode][object-hashcode-javadoc] und [equals][object-equals-javadoc] des Objekts, um herauszufinden, wo die Werte für einen Schlüssel gespeichert und wie sie abgerufen werden.
Aus diesem Grund ist es wichtig, dass sich ihre Rückgabewerte zwischen dem Speichern und dem Abrufen nicht ändern, sonst kann die HashMap den Wert möglicherweise nicht finden.

Angenommen, wir haben die folgende Klasse, die als Schlüssel für eine Map verwendet wird:

```java
public class Stock {
    private String name;

    public void setName(String name) {
        this.name = name;
    }

    @Override
    public int hashCode() {
        return Objects.hash(name);
    }

    @Override
    public boolean equals(Object obj) {
        if (obj == this) {
            return true;
        }
        if (Objects.equals(Stock.class, obj.getClass()) && obj instanceof Stock other) {
            return Objects.equals(name, other.name);
        }
        return false;
    }
}
```

Die Methoden `hashCode` und `equals` hängen vom Feld `name` ab, das über `setName` geändert werden kann.
Eine Änderung des `hashCode` kann überraschende Ergebnisse liefern:

```java
Stock stock = new Stock();
stock.setName("Beanies");

Map<Stock, Integer> stockCount = new HashMap<>();
stockCount.put(stock, 80);

stockCount.get(stock); // Returns 80

Stock other = new Stock();
other.setName("Beanies");

stockCount.get(other); // Returns 80 because "other" and "stock" are equal

stock.setName("Choccies");
stockCount.get(stock); // Returns null because hashCode value has changed

stockCount.get(other);  // Also returns null because "other" and "stock" are not equal

stock.setName("Beanies");
stockCount.get(stock); // HashCode restored, so returns 80 again

stockCount.get(other); // Also returns 80 again because "other" and "stock" are back to equal
```

## Map.of und Map.copyOf

Eine weitere übliche Möglichkeit, Maps zu erstellen, ist die Verwendung von [Map.of][map-of-javadoc] oder [Map.ofEntries][map-ofentries-javadoc].

```java
// Using Map.of
Map<String, Integer> temperatures = Map.of("Mon", 30, "Tue", 28, "Wed", 32);

// or using Map.ofEntries
Map<String, Integer> temperatures2 = Map.ofEntries(
    Map.entry("Mon", 30),
    Map.entry("Tue", 28),
    Map.entry("Wed", 32)
);
```

Anders als `HashMap` befüllen sie die Map im Voraus und sind nach der Erstellung schreibgeschützt.
[Map.copyOf][map-copyof-javadoc] erstellt eine schreibgeschützte Kopie einer Map.

```java
Map<String, Integer> readOnlyFruitPrices = Map.copyOf(fruitPrices);
```

Der Aufruf von Methoden wie `put`, `remove` oder `clear` führt zu einer `UnsupportedOperationException`.
