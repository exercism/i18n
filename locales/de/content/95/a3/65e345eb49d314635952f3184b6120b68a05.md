# Einführung

## Ausnahmen

Ausnahmen in C# bieten eine strukturierte, einheitliche und typsichere Möglichkeit, Fehlerzustände zu behandeln, die zur Laufzeit auftreten. Eine saubere Behandlung von Ausnahmen und Fehlern ist wichtig, wenn du verhindern willst, dass deine Anwendung abstürzt.

In C# haben alle Ausnahmen die Klasse `System.Exception` als Basistyp. Sie enthält wichtige Eigenschaften wie `Message`, die eine für Menschen lesbare Beschreibung des Grundes enthält, aus dem die Ausnahme ausgelöst wurde.

Um zu signalisieren, dass an einer bestimmten Stelle im Code ein Fehler auftreten soll, musst du ein neues Ausnahmeobjekt erzeugen und es mit dem Schlüsselwort `throw` auslösen:

```csharp
using System;
static int Square(int number)
{
    if (number >= 46341)
    {
        throw new ArgumentException($"Argument {number} cannot be higher than 46340 as its' square doesn't fit into int type.");
    }
    return number * number;
}
```

Wenn eine Ausnahme ausgelöst wird, hat die Laufzeit die Aufgabe, ein Stück Code zu finden, das für die Behandlung dieser Ausnahme zuständig ist. Wird kein passender Handler gefunden, zeigt die Laufzeit die Meldung der unbehandelten Ausnahme an und beendet zusätzlich die Ausführung des Programms.

Um einen Handler für eine Ausnahme zu erstellen, verwendet C# die try-catch-Anweisung, die aus einem `try`-Block und einer oder mehreren `catch`-Klauseln besteht. Der `try`-Block sollte Code enthalten und absichern, der dazu führen kann, dass die Ausnahme ausgelöst wird. Die `catch`-Klauseln sollten Code enthalten, der das Verhalten des Programms nach dem Auftreten des Fehlers behandelt. Wichtig ist, dass die Reihenfolge der Ausnahmen nach dem `try`-Block eine Rolle spielt: Sind mehrere Ausnahmen aufgeführt, wird die erste passende `catch`-Klausel ausgeführt.

```csharp
try
{
   if (number == 42)
   {
       throw new ArgumentException("The number cannot be equal to 42.", "number");
   }

   if (number < 0)
   {
      throw new ArgumentOutOfRangeException("number", "The number cannot be negative.");
   }

    // Process number ...
}
catch (ArgumentOutOfRangeException e)
{
    Console.WriteLine($"Number is out of range: {e.Message}.");
}
catch (ArgumentException)
{
    Console.WriteLine("Invalid number.");
}
```
