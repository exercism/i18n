# Hinweise

## Allgemein

- Callback-Funktionen sind Funktionen, die als Argument an eine aufrufende Funktion übergeben werden.
- Callback-Funktionen müssen der Spezifikation der aufrufenden Funktion entsprechen.

## 1. Mit einer Erfolgsmeldung benachrichtigen

- Verwende die importierte API-Funktion `notify` in deiner Funktion.
- Übergib ein Objekt an `notify`. Es sollte die Eigenschaft `message` haben. Überlege dir, welchen Wert message haben sollte.
- Achte auf den JSDoc-Typ-Hinweis: Die Funktion sollte keinen Wert zurückgeben.

## 2. Mit einer Fehlermeldung benachrichtigen

- Verwende die importierte API-Funktion `notify` in deiner Funktion.
- Übergib ein weiteres Objekt an `notify`. Es sollte die Eigenschaft `message` haben. Der Wert von message sollte sich vom vorigen Teil unterscheiden.
- Achte auf die Kommentare [JSDoc] über der Funktionsdefinition:
  - Die Funktion sollte keinen Wert zurückgeben.

## 3. Eine Bestellung zum Kauf von Obst aufgeben

- Verwende die bereits importierte Funktion `order`.
- Achte auf die JSDoc-Typ-Hinweise: Die Funktion sollte 3 Argumente erhalten und keinen Wert zurückgeben.
- Verwende die zuvor erstellten Callbacks als Argumente für die Funktion `order`.

## 4. Refaktoriere deinen Code zu einer kompakteren Funktion

- Verwende die Funktionen aus den vorherigen Aufgaben erneut.
- Achte auf die JSDoc-Typ-Hinweise: Die Funktion sollte 2 Argumente erhalten und keinen Wert zurückgeben.
- Fasse die Argumente in einem Objekt zusammen, das die Anfrage an den Obsthändler zum Aufgeben einer Bestellung darstellt.
