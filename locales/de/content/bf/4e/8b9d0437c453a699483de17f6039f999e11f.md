# Einführung

In Python ist [ein `enum`][enum-docs] eine Menge von Namen, die an eindeutige `literal`- oder `constant`-Werte gebunden sind.
`Enums` definierst du, indem du von einer `Enum`-Klasse erbst oder sie als Unterklasse ableitest.
Eingebaute `enum`-Typen sind im Modul `enum` verfügbar, und die Klasse `Enum` kannst du mit `from enum import Enum` importieren.


```python
from enum import Enum

class Color(Enum):
    RED = 1
    GREEN = 2
```

Beachte, dass die Werte der `enum`-Member beliebige Datentypen wie `str`, `tuple`, `float` usw. sein können.

```python
class Color(Enum):
    RED = 'red'
    GREEN = 'green'
```

Wenn du zwei Membern in einem `enum` denselben Wert zuweist, wird der zuletzt zugewiesene Member zum Alias des ersten. Es ist nicht erlaubt, denselben Namen für zwei verschiedene Member eines `enum` zu verwenden.

```python
class Color(Enum):
    RED = 1
    GREEN = 2
    ALIAS_OF_RED = 1

Color.ALIAS_OF_RED
#=> <Color.RED: 1>

Color.ALIAS_OF_RED.value
#=> 1
```

Über die Member des `enum` kannst du mit der üblichen `for member in`-Syntax iterieren:

```python
for member in Color:
    print((member.name, member.value))
#=> (RED, 1)
#=> (GREEN, 2)
```

`Enum`-Member kannst du mit [`is` (_Identitätsoperator_)][identity-keyword] oder `is not` vergleichen. Die Operatoren `==` und `!=` (_Gleichheitsoperatoren_) funktionieren genauso:

```python
a = Color.RED

a is Color.RED
#=> True

a == Color.RED
#=> True
```

Um auf einen `enum`-Member für einen gegebenen Wert zuzugreifen, kannst du `<EnumName>(<value>)` verwenden:

```python
g = Color(2)

g is Color.GREEN
#=> True

g
#=> <Color.GREEN: 2>
```
