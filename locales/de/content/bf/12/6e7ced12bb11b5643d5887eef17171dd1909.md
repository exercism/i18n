# Anweisungen

Als angehende Zauberin muss Elyse ein paar Grundlagen üben. Sie hat einen Kartenstapel, den sie bearbeiten möchte.

Um es sich etwas einfacher zu machen, verwendet sie nur die Karten 1 bis 10.

Der Kartenstapel wird durch eine `queue` dargestellt, wobei sich das untere Ende des Stapels am Anfang der Warteschlange und das obere Ende am Ende der Warteschlange befindet.

## 1. Eine Karte oben auf den Stapel legen

Implementiere die Funktion `insert_top`, die eine Kopie des Stapels zurückgibt, bei der die angegebene neue Karte oben auf den Stapel gelegt wurde.

```gleam
insert_top(queue.from_list([5, 9, 7, 1]), 8)
// -> queue.from_list([5, 9, 7, 1, 8])
```

## 2. Die oberste Karte vom Stapel entfernen

Implementiere die Funktion `remove_top_card`, die eine Kopie des Stapels zurückgibt, bei der die oberste Karte entfernt wurde. Wenn der angegebene Stapel leer ist, soll der ursprüngliche Stapel unverändert zurückgegeben werden.

```gleam
remove_top_card(queue.from_list([3, 2, 6, 4, 8]))
// -> queue.from_list([3, 2, 6, 4])
```

## 3. Eine Karte am unteren Ende des Stapels einfügen

Implementiere die Funktion `insert_bottom`, die eine Kopie des Stapels zurückgibt, bei der die angegebene neue Karte am unteren Ende des Stapels eingefügt wurde.

```gleam
insert_bottom(queue.from_list([5, 9, 7, 1]), 8)
// -> queue.from_list([8, 5, 9, 7, 1])
```

## 4. Eine Karte vom unteren Ende des Stapels entfernen

Implementiere die Funktion `remove_bottom_card`, die eine Kopie des Stapels zurückgibt, bei der die unterste Karte entfernt wurde. Wenn der angegebene Stapel leer ist, soll der ursprüngliche Stapel unverändert zurückgegeben werden.

```gleam
remove_bottom_card(queue.from_list([8, 5, 9, 7, 1]))
// -> queue.from_list([5, 9, 7, 1])
```

## 5. Die Größe des Stapels überprüfen

Implementiere die Funktion `check_size_of_stack`, die überprüft, ob die Größe des Stapels gleich dem angegebenen `stack_size` ist oder nicht.

```gleam
check_size_of_stack(queue.from_list([3, 2, 6, 4, 8]), 4)
// -> False
```
