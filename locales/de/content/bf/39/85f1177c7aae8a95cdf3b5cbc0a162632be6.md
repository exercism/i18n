# Kommandozeile

## Einrichtung

Der einfachste Weg, Purescript zu installieren, führt über Node.js und NPM.

Wenn du Node.js noch nicht auf deinem Computer installiert hast, kannst du es von der [Node.js-Website][nodejs-website] herunterladen. Sobald Node.js läuft, gib diesen Befehl im Terminal ein, um den PureScript-Compiler sowie Spago, den Paketmanager und das Build-Tool, zu installieren.

```shell
npm install -g purescript spago
```

Mehr Informationen findest du im [PureScript-Repository][purescript-repository].

## Voraussetzungen

Installiere die Abhängigkeiten für die Übung:

```shell
spago install
spago build
```

## Die Testsuite bestehen lassen

Führe die Tests so aus:

```shell
spago test
```

In den Testsuiten sind alle Tests außer dem ersten übersprungen. Das soll dich dazu ermutigen, die Übung Schritt für Schritt zu lösen.

Sobald ein Test besteht, kannst du den nächsten aktivieren, indem du `xit` in `it` änderst.

## Die Lösung einreichen

Sobald kein Test mehr übersprungen wird und alle bestehen, kannst du deine Lösung so einreichen:

```shell
exercism submit src/<NAME>.purs
```

## Eigene Tests schreiben

Wenn du zusätzliche, eigene Tests schreiben möchtest, erstelle eine neue Datei `test/Custom.purs` und reiche sie zusammen mit deiner Lösung ein:

```shell
exercism submit src/<NAME>.purs test/Custom.purs
```
