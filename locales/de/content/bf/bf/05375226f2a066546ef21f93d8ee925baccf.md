# Einführung

Eine [`list`][list] ist eine veränderbare Sammlung von Elementen in _einer Sequenz_.
Wie die meisten Sammlungen (_siehe die eingebauten [`tuple`][tuple], [`dict`][dict] und [`set`][set]_) können Listen Verweise auf jeden (oder mehrere) Datentyp(en) enthalten, auch auf andere Listen.
Listen lassen sich vollständig oder teilweise über die [Slice-Notation][slice notation] oder mit `<list>.copy()` kopieren.
Wie bei jeder [Sequenz][sequence type] werden Elemente in `lists` über eine `0-based index`-Nummer von links oder eine `-1-based index`-Nummer von rechts referenziert.

Listen unterstützen sowohl [gemeinsame][common sequence operations] als auch [veränderbare][mutable sequence operations] Sequenzoperationen wie `min(<list>)`/`max(<list>)`, `<list>.index()`, `<list>.append()` und `<list>.reverse()`.
Über die Elemente in einer `list` kannst du mit dem Konstrukt `for item in <list>` iterieren.
`for index, item in enumerate(<list>)` kannst du verwenden, wenn du sowohl den Index als auch den Wert eines Elements brauchst.

Python bietet außerdem viele nützliche [Listen-Methoden][list-methods] für die Arbeit mit Listen.
Eine Auswahl dieser `list methods` wird unten behandelt.


Beachte: Wenn du eine `list` mit einer `list-method` bearbeitest, **veränderst du die Liste**, also das Objekt, das übergeben wurde.
Wenn du die ursprüngliche `list` nicht verändern willst, musst du zumindest eine `shallow copy` davon über einen Slice oder `<list>.copy()` anlegen.


## Elemente hinzufügen

Um ein Element am Ende oder auf der „rechten Seite“ einer bestehenden Liste hinzuzufügen, verwende `<list>.append(<item>)`:

```python
>>> numbers = [1, 2, 3]
>>> numbers.append(9)

>>> numbers
[1, 2, 3, 9]
```

Statt _anzuhängen_, gibt dir `<list>.insert()` die Möglichkeit, das Element an einem _bestimmten Index_ in die Liste einzufügen.
Sie erwartet 2 Parameter:

1. den `<index>`, an dem das Element eingefügt werden soll.
2. das `<item>`, das eingefügt werden soll.

**Hinweis**: Wenn der angegebene `index` 0 ist, wird das Element am Anfang (der „linken Seite“) der `list` eingefügt.
Wenn der angegebene `index` größer ist als der letzte `index` der `list`, wird das Element an der letzten Position eingefügt – das entspricht `<list>.append(<item>)`.


```python
>>> numbers = [1, 2, 3]
>>> numbers.insert(0, -2)

>>> numbers
[-2, 1, 2, 3]

>>> numbers.insert(1, 0)

>>> numbers
[-2, 0, 1, 2, 3]
```


Mit `<list>.extend(<item>)` kannst du eine bestehende Liste mit den Elementen aus einem anderen Iterable kombinieren (zum Beispiel einem `set`, `tuple`, `str` oder `list`).
  Das Iterable wird _entpackt_ und die Elemente werden der Reihenfolge nach angehängt (_Würdest du in diesem Fall `<list>.append(<item>)` verwenden, würde das gesamte Iterable als **ein einzelnes Element** hinzugefügt._).


```python
>>> numbers = [1, 2, 3]
>>> other_numbers = [5, 6, 7]

>>> numbers.extend(other_numbers)

>>> numbers
[1, 2, 3, 5, 6, 7]

>>> numbers.extend([8, 9])

>>> numbers
[1, 2, 3, 5, 6, 7, 8, 9]

>>> numbers.append([8,9])

>>> numbers
[1, 2, 3, 5, 6, 7, 8, 9, [8, 9]]
```


## Elemente entfernen

Um ein Element aus einer Liste zu löschen, verwende `<list>.remove(<item>)` und übergib das zu entfernende Element als Argument.
 `<list>.remove(<item>)` löst einen `ValueError` aus, wenn das Element nicht in der `list` vorhanden ist.


```python
>>> numbers = [1, 2, 3]
>>> numbers.remove(2)

>>> numbers
[1, 3]

# Trying to remove a value that is not in the list throws a ValueError
>>> numbers.remove(0)
ValueError: list.remove(x): x not in list
```


Alternativ entfernt die Methode `<list>.pop(<index>)` ein Element **und** gibt es per `return` zur weiteren Verwendung zurück.


`<list>.pop(<index>)` nimmt einen optionalen Parameter entgegen: den `index` des Elements, das entfernt und zurückgegeben werden soll.
 Wenn das (optionale) `index`-Argument nicht angegeben wird, wird das letzte Element der `list` entfernt und zurückgegeben.
 Wenn der angegebene `index` höher ist als der `index` des letzten Elements, wird ein `IndexError` ausgelöst.


```python
>>> numbers = [1, 2, 3]

>>> numbers.pop(0)
1

>>> numbers
[2, 3]

>>> numbers.pop()
3

>>> numbers
[2]

>>> numbers.pop(1)
Traceback (most recent call last):
  File "<stdin>", line 1, in <module>
IndexError: pop index out of range
```

Mit `list.clear()` kannst du alle Elemente aus einer `list` entfernen. Die Methode nimmt keine Parameter entgegen.

```python
>>> numbers = [1, 2, 3]
>>> numbers.clear()

>>> numbers
[]
```

## Umkehren und Neuordnen

Die Methode `<list>.reverse()` kehrt die Reihenfolge der Elemente **in-place** um.


```python
>>> numbers = [1, 2, 3]
>>> numbers.reverse()

>>> numbers
[3, 2, 1]
```


Eine Liste kann mit Hilfe von [`<list>.sort()`][sort] _**in place**_ neu geordnet werden.
Die Standard-Sortierreihenfolge ist _aufsteigend_ von links.
Die Python-Dokumentation bietet [weitere Tipps und Techniken zum Sortieren][sorting how to].

~~~~exercism/note
 Von 2002 bis 2022 verwendete Python intern einen Algorithmus namens [`Timsort`][timsort], um Listen zu sortieren, wechselte aber ab `Python 3.11` zu [`Powersort`][powersort].

[powersort]: https://www.wild-inter.net/publications/munro-wild-2018
[timsort]: https://en.wikipedia.org/wiki/Timsort
~~~~


```python
>>> names = ["Tony", "Natasha", "Thor", "Bruce"]

# The default sort order is *ascending*.
>>> names.sort()

>>> names
["Bruce", "Natasha", "Thor", "Tony"]
```

Wenn du eine _absteigende_ Reihenfolge möchtest, übergib das Argument `reverse=True`:

```python
>>> names = ["Tony", "Natasha", "Thor", "Bruce"]
>>> names.sort(reverse=True)

>>> names
["Tony", "Thor", "Natasha", "Bruce"]
```

Wenn du die ursprüngliche Liste nicht verändern möchtest, kannst du die eingebaute Funktion [`sorted(<iterable>)`][sorted] verwenden, um eine sortierte **Kopie** zurückzugeben.


```python
>>> names = ["Tony", "Natasha", "Thor", "Bruce"]

>>> sorted(names)
['Bruce', 'Natasha', 'Thor', 'Tony']
```


## Vorkommen eines Elements in einer Liste

Die Anzahl der Vorkommen eines Elements in einer Liste kannst du mit `list.count(<item>)` ermitteln.
 Sie nimmt das zu zählende `item` als Argument und gibt zurück, wie oft dieses Element in der `list` vorkommt.


```python
>>> items = [1, 4, 7, 8, 2, 9, 2, 1, 1, 0, 4, 3]

>>> items.count(1)
3
```

## Den Index von Elementen finden

`<list>.index(<item>)` gibt die `index`-Nummer des _ersten Vorkommens_ eines übergebenen Elements zurück.
 Wenn es kein Vorkommen gibt, wird ein `ValueError` ausgelöst.
 Wenn die genaue Position eines Elements nicht benötigt wird, ist der eingebaute `in`-Operator effizienter, um zu prüfen, ob eine Liste einen bestimmten Wert enthält.


Die Indizierung beginnt von links bei null, die Position des „ersten“ Elements ist also `0`.
Die Indizierung funktioniert auch von rechts, beginnend bei `-1`.


```python
>>> items = [7, 4, 1, 0, 2, 5]

>>> items.index(4)
1

>>> items.index(10)
ValueError: 10 is not in list
```

Du kannst auch die Indizes `start` und `end` angeben, um die Suche auf einen bestimmten Abschnitt der `list` einzugrenzen:

```python
>>> names = ["Tina", "Leo", "Thomas", "Tina", "Emily", "Justin"]

>>> names.index("Tina")
0

>>> names.index("Tina", 2, 5)
3
```
