# Exercism API

## Beschreibung

Die meisten Sprach-Tracks von Exercism nutzen das Kommandozeilen-Tool `exercism`, um Übungen abzurufen und einzureichen. Es kommuniziert über eine REST-API mit `exercism.io`. Der Pharo-Smalltalk-Track verwendet stattdessen dieselbe REST-API, um Übungen in das Pharo-Image hinein- und wieder herauszuholen, ohne dass ein zwischengeschaltetes Tool nötig wäre. Dieses Dokument beschreibt die Exercism-API im Detail, mit Blick darauf, wie der Pharo-Smalltalk-Track sie verwendet. Es richtet sich an die Maintainer der Pharo-Smalltalk-Tools.

## Header

Bei allen Endpunkten müssen die Header der Anfrage auf die folgenden Werte gesetzt sein:

```
Authorization: Bearer <token>
```

Der Wert `<token>` ist der CLI-Authentifizierungstoken des Nutzers. Du findest ihn unter `https://exercism.io/my/settings`.

## Übungen abrufen

```
Content-Type: application/json
```

`GET api.exercism.io/v1/solutions/latest?exercise_id=<slug>&track_id<language> HTTP/1.1`

In der URL oben ist `<slug>` der Name der Übung, z. B. `hello-world`, und `<language>` der Sprach-Track, z. B. `pharo-smalltalk`.

### Antwort

#### 200

Eine erfolgreiche Anfrage liefert eine Antwort mit einem JSON-Payload. Das JSON enthält Informationen zur Übung und eine URL, unter der du die Übungsdateien herunterladen kannst.

```json
"solution":{
	"id":"<id-string>",
	"url":"https://exercism.io/my/solutions/<id-string>",
	"team":null,
	"user":{
		"handle":"<exercism-user-name>",
		"is_requester":true
		},
		"exercise":{
			"id":"isogram",
			"instructions_url":"https://exercism.io/my/solutions/<id-string>",
			"auto_approve":false,
			"track":{
				"id":"pharo-smalltalk",
				"language":"Pharo"
				}
			},
			"file_download_base_url":"https://api.exercism.io/v1/solutions/<id-string>/files/",
			"files":[
				"IsogramTest.class.st",
				"README.md"
				],
			"iteration":null
		}
	}
```

#### 400

Der Name des Sprach-Tracks ist mehrdeutig, oder die eingereichten Übungsdateien haben sich nicht geändert.

#### 403

Die Lösung ist für den Nutzer nicht freigeschaltet, oder er ist dem Sprach-Track nicht beigetreten.

#### 404

Der Sprach-Track oder die Übung wurde nicht gefunden.

## Übungen einreichen

```
Content-Type: application/octet-stream
```

`PATCH api.exercism.io//v1/solutions/<some-kind-of-token-or-hash> HTTP/1.1`

### Antwort

#### 201

Eine erfolgreiche Einreichung.

#### 400

Eine eingereichte Datei ist zu groß (mehr als ein Megabyte), oder die Lösung ist ein Duplikat.

#### 403

Die Lösung ist für den Nutzer nicht zugänglich. Die Nutzer-ID der Lösung und die aktuelle Nutzer-ID stimmen nicht überein.

#### 404

Die Lösungs-ID wurde nicht gefunden.
