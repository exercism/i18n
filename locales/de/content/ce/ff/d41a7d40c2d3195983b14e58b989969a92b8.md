# Über

Futhark ist eine rein funktionale Programmiersprache für hochperformantes, datenparalleles Rechnen.
In Syntax und Struktur ähnelt sie funktionalen Sprachen wie Haskell und Standard ML, doch ihr Schwerpunkt liegt woanders.
Statt auf reiche Typsysteme oder maximale Ausdruckskraft zu setzen, will Futhark effizienten parallelen Code erzeugen.
Im Zentrum von Futhark stehen Operationen auf ganzen Arrays, die als Second-Order Array Combinators (SOACs) bezeichnet werden, etwa `map`, `reduce` und `filter`. Sie ähneln den Funktionen höherer Ordnung, die du aus anderen funktionalen Sprachen kennst.
Diese SOACs sind mit sequentieller Semantik definiert, aber darauf ausgelegt, zu paralleler Ausführung kompiliert zu werden. So bekommst du beides: klaren Code und hohe Leistung.
