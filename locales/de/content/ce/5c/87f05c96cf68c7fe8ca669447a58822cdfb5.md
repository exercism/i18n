# Einführung

Das Fehlersystem von Factor besteht aus drei Bausteinen: `throw` (in
[`kernel`][kernel]) löst einen Fehler aus, `recover` (in
[`continuations`][continuations]) fängt einen ab, und `ERROR:` definiert
eine Fehlerklasse mit Tupel-Typ.

```factor
! "file not found" throw          (raises a string as the error)

[ "boom" throw ] [ drop "caught" ] recover .
! => "caught"
```

`recover ( try recovery -- )` führt die *try*-Quotation aus; wenn sie
einen Fehler auslöst, wird der Fehler auf den Stack gelegt und die
*recovery*-Quotation wird ausgeführt.

`ERROR:` deklariert sowohl die Klasse *als auch* ein Konstruktorwort, das
eine frische Instanz auslöst:

```factor
! DOCTEST: SKIP
ERROR: not-found path ;

"/missing" not-found
! throws T{ not-found { path "/missing" } }
```

[kernel]: https://docs.factorcode.org/content/vocab-kernel.html
[continuations]: https://docs.factorcode.org/content/vocab-continuations.html
