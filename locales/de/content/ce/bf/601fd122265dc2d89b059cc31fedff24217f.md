# Einführung

Ein `String` (eine Zeichenkette) in Haxe ist ein Objekt, das unveränderlichen Text als Folge von Unicode-Zeichen (Buchstaben, Ziffern, Satzzeichen usw.) darstellt. Eine Instanz von `String` definierst du mit doppelten Anführungszeichen:

```haxe
var fruit:String = "Apple";
```

Zeichenketten bearbeitest du, indem du ihre Methoden aufrufst. Sobald eine Zeichenkette erzeugt wurde, kann ihr Wert sich nie mehr ändern. Methoden, die eine Zeichenkette zu verändern scheinen, geben in Wirklichkeit eine neue Zeichenkette zurück.

Du kannst mehrere Zeichenketten miteinander verketten (addieren). Am einfachsten geht das mit dem `+`-Operator.

```haxe
var name:String = "Jane";
trace("Hello " + name + "!");
// => "Hello Jane!"
```

Für jede Formatierung von Zeichenketten, die über eine einfache Verkettung hinausgeht, ist die Interpolation die bessere Wahl. Um die Interpolation in einer Zeichenkette zu verwenden, schließt du sie in einfache Anführungszeichen (`'`) ein. Dann kannst du das Dollarzeichen (`$`) verwenden, um die Interpolation auszulösen:

```haxe
var name:String = "Jane";
trace('Hello $name!');
// => "Hello Jane!"
```
