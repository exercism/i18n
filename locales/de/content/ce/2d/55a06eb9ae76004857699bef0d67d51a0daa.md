# Guards verwenden

[comment]: # (Dieser Fehler wird ausgelöst, wenn die Lösung überhaupt keine Guards verwendet)

Verwende [Guards](https://hexdocs.pm/elixir/master/guards.html), um zu verhindern, dass `two_fer/1` mit Eingaben ausgeführt wird, die keine Binärdaten sind.

> Denk daran, dass [Strings](https://elixir-lang.org/getting-started/binaries-strings-and-char-lists.html) in Elixir als [Binärdaten](https://elixir-lang.org/getting-started/binaries-strings-and-char-lists.html) gelten.

```elixir
# Consider this function with a guard:
def hello(what) when is_binary(what) do
  "Hello, #{what}!"
end
```

> Dieser Guard lässt sich in `iex` testen

```shell
iex> hello("world")
"Hello, world!"
iex> hello(123)
** (FunctionClauseError) no function clause matching in hello/1

    The following arguments were given to hello/1:

        # 1
        123
```
