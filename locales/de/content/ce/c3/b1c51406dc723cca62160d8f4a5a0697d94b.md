# Reihenfolge der Übungen im Rust-Track

Die maßgebliche Quelle für die Reihenfolge und die Themen der Übungen ist [config.json](config.json), diese Datei hält jedoch unsere Begründung für die Reihenfolge in dieser Datei fest.

## Unser Ansatz

Wir ordnen unsere Übungen für Lernende, die gerade Rust lernen. Mit dieser Zielgruppe vor Augen befolgen wir beim Hinzufügen neuer Übungen zwei Regeln.

- Eine Übung sollte ein neues Konzept einführen
- Die Übungen sollten von den Rust-Grundlagen zu fortgeschrittenen Rust-Konzepten fortschreiten

### Ein neues Konzept

Wenn für die Lösung einer Übung sowohl `Result` als auch `HashMap` nötig ist, dann sollte mindestens eines dieser Konzepte bereits in einer früheren Übung eingeführt worden sein.

Wenn mehrere Übungen im Track auf demselben Konzept aufbauen, fasse sie zusammen, damit sich das Gelernte festigt.

### Fortschritt durch Rust

#### Frühe Übungen

Frühe Übungen sollten sich auf Rust-Syntax und Konzepte konzentrieren, die es in vielen Programmiersprachen gibt: bedingte Anweisungen, Schleifen, Funktionen höherer Ordnung.

#### Mittlere Übungen

Übungen in der Mitte des Tracks sollten Konzepte einführen, die seltener vorkommen. Zum Beispiel `Result` und `Option` und Traits. Oder Syntax wie `while let`.

Im mittleren Abschnitt des Tracks sollten die Lernenden ein breites Spektrum an Rust-Konzepten kennenlernen.

#### Späte Übungen

Späte Übungen im Track sollten eines von zwei Dingen tun:

1. Fortgeschrittene Konzepte einführen: Lebensdauern, Nebenläufigkeit, unsicherer Code
2. Eine komplexe Lösung verlangen, die das gesamte Wissen zusammenführt, das die Lernenden bis dahin erworben haben
