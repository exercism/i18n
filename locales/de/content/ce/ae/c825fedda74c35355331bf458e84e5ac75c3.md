# Einführung

Für kurze Wörter ist Jonglieren mit dem Stack völlig in Ordnung. Wenn ein Wort aber mehrere Eingabewerte hat und du sie mit Namen ansprechen willst, bietet Factor *Locals*: benannte Bindungen, die mit `::` (für Wortdefinitionen) oder `[| | ]` (für Inline-Lambdas) eingeführt werden, beide aus [`locals`][locals].

```factor
USING: locals ;

:: hypotenuse ( a b -- c )
    a a *
    b b *
    + sqrt ;
```

Innerhalb einer Quotation ist `[| inputs | body ]` ein Lambda mit benannten Eingabewerten:

```factor
USING: assocs locals ;

H{ { "a" 1 } { "b" 2 } }
[| key value | key value 10 * ] assoc-map .
! => H{ { "a" 10 } { "b" 20 } }
```

[locals]: https://docs.factorcode.org/content/vocab-locals.html
