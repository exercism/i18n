# Einführung

Das Konzept [Paare und Wörterbücher][pairs-dicts] hat die Grundlagen von Julias Wörterbuch-Typ behandelt.

Da `Dict`s ein wichtiger und häufig verwendeter Sammlungstyp sind, gibt es auch viele Funktionen, um sie zu bearbeiten.

## Einträge abrufen

Der einfachste Weg, einen Eintrag abzurufen, ist über den Schlüssel (wie in vielen Sprachen).
Wenn du jedoch nach einem nicht existierenden Schlüssel fragst, bekommst du einen `KeyError`.

```julia-repl
julia> d = Dict(i => ('a':'c')[i] for i in 1:3)
Dict{Int64, Char} with 3 entries:
  2 => 'b'
  3 => 'c'
  1 => 'a'

julia> d[2]
'b': ASCII/Unicode U+0062 (category Ll: Letter, lowercase)

# missing key
julia> d[4]
ERROR: KeyError: key 4 not found
```

Wir könnten prüfen, ob der Schlüssel vorhanden ist, bevor wir versuchen, ihn abzurufen (etwa mit `haskey(d, 4)` oder `4 ∈ keys(d)`), aber es kann nützlich sein, einfach einen Standardwert für fehlende Schlüssel zu bekommen.

Dafür gibt es die Funktion `get()` und ihre mutierende Variante `get!()`.
Sie unterscheiden sich darin, ob der „fehlende“ Schlüssel dem `Dict` hinzugefügt wird.

```julia-repl
julia> get(d, 4, '!')
'!': ASCII/Unicode U+0021 (category Po: Punctuation, other)

# get() leaves Dict unchanged
julia> d
Dict{Int64, Char} with 3 entries:
  2 => 'b'
  3 => 'c'
  1 => 'a'

julia> get!(d, 4, '!')
'!': ASCII/Unicode U+0021 (category Po: Punctuation, other)

# get!() adds new key to Dict
julia> d
Dict{Int64, Char} with 4 entries:
  4 => '!'
  2 => 'b'
  3 => 'c'
  1 => 'a'
```

Wir haben im früheren Konzept gesehen, dass `delete!()` einen Eintrag anhand des Schlüssels entfernt.
Das lässt sich mit dem Abrufen des Werts kombinieren, indem du die Funktion `pop!()` verwendest.

```julia-repl
julia> d
Dict{Int64, Char} with 4 entries:
  4 => '!'
  2 => 'b'
  3 => 'c'
  1 => 'a'

# popped value is returned
julia> pop!(d, 3)
'c': ASCII/Unicode U+0063 (category Ll: Letter, lowercase)

# Dict is shrunk
julia> d
Dict{Int64, Char} with 3 entries:
  4 => '!'
  2 => 'b'
  1 => 'a'
```

## Iteration

Wenn du über ein `Dict` iterierst, werden standardmäßig `key => value`-Paare geliefert.
Auf die Bestandteile kannst du mit der üblichen Bezeichnung `.first` und `.second` zugreifen.

```julia-repl
# d is from the previous example
julia> [(kv.first, kv.second) for kv in d]
3-element Vector{Tuple{Int64, Char}}:
 (4, '!')
 (2, 'b')
 (1, 'a')
```

Oft wollen wir nur die Schlüssel oder nur die Werte verwenden, was ganz einfach ist.

```juliajulia> [k for k in keys(d)]
julia> [k for k in keys(d)]
3-element Vector{Int64}:
 4
 2
 1

julia> [v for v in values(d)]
3-element Vector{Char}:
 '!': ASCII/Unicode U+0021 (category Po: Punctuation, other)
 'b': ASCII/Unicode U+0062 (category Ll: Letter, lowercase)
 'a': ASCII/Unicode U+0061 (category Ll: Letter, lowercase)
```

## Zusammenführen

Zwei `Dict`s zu kombinieren kann nützlich sein, aber wir müssen uns darüber im Klaren sein, was wir mit Schlüsseln tun wollen, die in mehr als einem der übergebenen `Dict`s vorkommen.

Die Funktionen `merge()` und `merge!()` kombinieren eine beliebige Anzahl übergebener `Dict`s von links nach rechts.

Bei vorhandenen Schlüsseln werden die Werte einfach überschrieben, sodass das rechteste `Dict` „gewinnt“.

```julia-repl
julia> d3 = Dict("color" => "red", "shape" => "circle")
Dict{String, String} with 2 entries:
  "shape" => "circle"
  "color" => "red"

julia> d4 = Dict("color" => "blue", "coords" => (3, 2))
Dict{String, Any} with 2 entries:
  "color"  => "blue"
  "coords" => (3, 2)

# color from d3 is lost
julia> merge(d3, d4)
Dict{String, Any} with 3 entries:
  "shape"  => "circle"
  "color"  => "blue"
  "coords" => (3, 2)
```

Mit den Funktionen `mergewith()` und `mergewith!()` können wir eine Funktion als erstes Argument übergeben, um festzulegen, wie wiederholte Schlüssel zusammengeführt werden sollen.
Die Addition ist ein einfaches Beispiel.

```julia-repl
julia> d5 = Dict("color" => "red", "area" => 3)
Dict{String, Any} with 2 entries:
  "area"  => 3
  "color" => "red"

julia> d6 = Dict("shape" => "circle", "area" => 5)
Dict{String, Any} with 2 entries:
  "shape" => "circle"
  "area"  => 5

# area values are added, not overwritten
julia> mergewith(+, d5, d6)
Dict{String, Any} with 3 entries:
  "shape" => "circle"
  "area"  => 8
  "color" => "red"
```

Das Verketten zweier Vektoren ist eine weitere beliebte Operation beim Zusammenführen.
Dafür verwendet Julia die Funktion `vcat()`, aus Gründen, die im Konzept [`Multi Dimensional Arrays`][multidim] erklärt werden.

```julia-repl
julia> d7 = Dict("vals" => [1, 2, 3])
Dict{String, Vector{Int64}} with 1 entry:
  "vals" => [1, 2, 3]

julia> d8 = Dict("vals" => [4, 5])
Dict{String, Vector{Int64}} with 1 entry:
  "vals" => [4, 5]

julia> mergewith(vcat, d7, d8)
Dict{String, Vector{Int64}} with 1 entry:
  "vals" => [1, 2, 3, 4, 5]
```

Beachte, dass die `mergewith`-Funktionen ein gutes Beispiel für [Funktionen höherer Ordnung][hof] in Aktion sind.

Für mehrere [`Set`s][sets] ist die entsprechende Merge-Funktion `union`.
