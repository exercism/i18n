# Getter und Setter

Getter und Setter sind Methoden, mit denen du den Wert einer Eigenschaft eines Objekts lesen und schreiben kannst.
Crystal hat Makros, was das Definieren von Gettern und Settern für eine Eigenschaft einfach macht.
Makros sind eine Möglichkeit, Code zur Kompilierzeit zu erzeugen; das wird später im Makro-Konzept behandelt.

In Ruby werden diese Methoden mit den Methoden `attr_reader`, `attr_writer` und `attr_accessor` definiert und ähneln Crystals Implementierung oberflächlich betrachtet stark.
Crystal hat diese als die Makros `getter`, `setter` und `property` definiert.

## Getter

Getter ist ein Makro, das eine Methode definiert, die den Wert einer Instanzvariable zurückgibt.
Das bedeutet, dass du das `@` nicht mehr vor die Instanzvariable schreiben musst, wenn du auf sie zugreifen willst (in Methoden, außer in `initialize`); stattdessen kannst du die Methode aufrufen, die das Getter-Makro definiert hat.

Das Getter-Makro kann mehrere Instanzvariablen annehmen, wenn du sie mit Kommas trennst.

```crystal
# This:
class Person
  @name : String
  @age : Int32

  def name
    @name
  end

  def age
    @age
  end
end

# Is the same as this:
class Person
  @name : String
  @age : Int32

  getter name, :age
end
```

Wie du siehst, reduziert die Verwendung von Gettern die Menge an Code, die du schreibst, und macht sie leichter lesbar.
Außerdem unterscheiden sich Ruby und Crystal darin, dass Crystal sowohl den Variablennamen als auch das Symbol als Argumente für das Getter-Makro akzeptiert.
Symbole werden später im Symbol-Konzept behandelt.

## Setter

Setter ist ein Makro, das eine Methode definiert, die den Wert einer Instanzvariable setzt.
Dieses Makro trifft man nicht so oft an; stattdessen wird häufig das `property`-Makro verwendet.
Die erzeugten Methoden sehen wie `name_of_method=` aus; das `=` sorgt dafür, dass die Eigenschaft gesetzt werden kann.

Diese Methodendefinition ist etwas Besonderes, da das Argument, das die Methode erhält, nach dem `=`-Zeichen steht.
Mehrere andere spezielle Methoden in Crystal verwenden diese Syntax, zum Beispiel die `+`-Methode.

Wie beim Getter-Makro kannst du, wenn du den Wert einer Instanzvariable nach dem Definieren eines Setters aktualisieren willst, die Methode aufrufen, die das Setter-Makro definiert hat.

```crystal
# This:
class Person
  @name : String
  @age : Int32

  def name=(name : String)
    @name = name
  end

  def age=(age : Int32)
    @age = age
  end
end

# Is the same as this:
class Person
  @name : String
  @age : Int32

  setter name, :age
end
```

## Property

Property ist ein Makro, das sowohl einen Getter als auch einen Setter für eine Instanzvariable definiert.

```crystal
class Person
  @name : String
  @age : Int32

  property name, :age
end
```
