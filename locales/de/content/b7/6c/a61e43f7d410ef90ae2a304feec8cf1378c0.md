# Anhang
## Bonus

Behalte Graphemcluster bei, d. h.

```julia
myreverse("hi 👋🏾") == "👋🏾 ih"
myreverse("as⃝df̅") == "f̅ds⃝a"
```

Für diese Bonusaufgabe ist die `Unicode`-Standardbibliothek wahrscheinlich nützlich.

Um den Graphem-Test zu aktivieren, füge `const TEST_GRAPHEMES = true` zum globalen Gültigkeitsbereich deiner Datei hinzu.
