# Zahlentypen

Crystal hat eine Vielzahl verschiedener Zahlentypen für unterschiedliche Zwecke.
Einige Typen sind zum Beispiel schneller, haben aber einen kleineren Wertebereich als andere.
Andere haben einen größeren Wertebereich, sind aber langsamer.

In Crystal gibt es sowohl vorzeichenbehaftete als auch vorzeichenlose Ganzzahltypen.
Vorzeichenbehaftete Ganzzahltypen können positiv oder negativ sein.
Vorzeichenlose Ganzzahltypen können nur positiv sein.

## Vorzeichenbehaftete Ganzzahlen

Dies sind die [vorzeichenbehafteten Ganzzahltypen][int] in Crystal:

| Type     | Size (bits) | Range                                                                                                       |
| -------- | ----------- | ----------------------------------------------------------------------------------------------------------- |
| `Int8`   | 8           | -128 bis 127                                                                                                |
| `Int16`  | 16          | -32_768 bis 32_767                                                                                          |
| `Int32`  | 32          | -2_147_483_648 bis 2_147_483_647                                                                            |
| `Int64`  | 64          | -9_223_372_036_854_775_808 bis 9_223_372_036_854_775_807                                                    |
| `Int128` | 128         | -170_141_183_460_469_231_731_687_303_715_884_105_728 bis 170_141_183_460_469_231_731_687_303_715_884_105_727 |

Die kleineren Typen verwenden weniger Speicher und sind schneller als die größeren Typen, haben aber einen kleineren Wertebereich.

Wenn du weißt, dass Werte in einem bestimmten Bereich liegen, ist es am besten, den kleinstmöglichen Typ zu verwenden, um Speicher zu sparen und die Leistung zu verbessern.

Der Standardtyp für Ganzzahlen ist `Int32`.
Um eine Ganzzahl mit einem bestimmten Typ zu deklarieren, kannst du den Typnamen als Suffix verwenden, indem du `<number>_I <bit>` anhängst.

```crystal
1_i8.class
# => Int8
```

Mit der Methode `to_i<bit>` kannst du zwischen verschiedenen Ganzzahltypen konvertieren.
Die Methode `to_i` konvertiert in den Standardtyp für Ganzzahlen, `Int32`.

```crystal
1_i8.to_i16.class
# => Int16

2_i16.to_i.class
# => Int32
```

## Vorzeichenlose Ganzzahlen

Dies sind die [vorzeichenlosen Ganzzahltypen][uint] in Crystal:

`UInt8`, `UInt16`, `UInt32`, `UInt64`, `UInt128`

Der einzige Unterschied zwischen vorzeichenbehafteten und vorzeichenlosen Ganzzahlen ist, dass vorzeichenlose Ganzzahlen nur positiv sein können.
Um eine vorzeichenlose Ganzzahl mit einem bestimmten Typ zu deklarieren, kannst du den Typnamen als Suffix verwenden, indem du `<number>_u<bit>` anhängst.
Mit der Methode `to_u<bit>` kannst du zwischen verschiedenen vorzeichenlosen Ganzzahltypen konvertieren.
Die Methode `to_u` konvertiert in den Standardtyp für vorzeichenlose Ganzzahlen, `UInt32`.

```crystal
1_u8.to_u16.class
# => UInt16
```

## Gleitkommatypen

Dies sind die Gleitkommatypen in Crystal:

| Type      | Size (bits) | Range                |
| --------- | ----------- | -------------------- |
| `Float32` | 32          | 1.2E-38 bis 3.4E+38  |
| `Float64` | 64          | 2.3E-308 bis 1.7E+308 |

Es gibt zwei verschiedene [Gleitkommatypen][float], von denen einer präziser ist als der andere.

Der Standardtyp für Gleitkommazahlen ist `Float64`.

Mit der Methode `to_f<bit>` kannst du zwischen verschiedenen Gleitkommatypen konvertieren.
Die Methode `to_f` konvertiert in den Standardtyp für Gleitkommazahlen, `Float64`.

## Typ nach einer Operation

Wenn du eine Operation zwischen zwei Zahlen ausführst, hat das Ergebnis den Typ der Zahl mit der höchsten Genauigkeit.
Eine Gleitkommazahl ist präziser als eine Ganzzahl, und eine Ganzzahl ist genauer als eine vorzeichenlose Ganzzahl.
Außerdem ist `Float64` präziser als `Float32` und so weiter.

```crystal
(1_u8 + 2_u64).class
# => UInt64

(1_u8 + 2_i64).class
# => Int64

(1_u8 + 2.0_f64).class
# => Float64
```

## Dig Deeper: Vorzeichenlose vs. vorzeichenbehaftete Ganzzahlen

~~~~exercism/advanced
Im Hintergrund unterscheiden sich vorzeichenlose und vorzeichenbehaftete Ganzzahlen darin, dass vorzeichenbehaftete Ganzzahlen das erste Bit verwenden, um das Vorzeichen zu speichern.
Das Vorzeichen ist entweder positiv oder negativ.
Bei vorzeichenlosen Ganzzahlen wird das erste Bit verwendet, um den Wert zu speichern.
Bei einer vorzeichenbehafteten 32-Bit-Ganzzahl ist der Maximalwert also 2^31 - 1.
Bei einer vorzeichenlosen 32-Bit-Ganzzahl ist der Maximalwert 2^32 - 1.

Wenn du mehr über Signedness erfahren möchtest, kannst du mehr dazu auf [Wikipedia](https://en.wikipedia.org/wiki/Signedness) lesen.
~~~~
