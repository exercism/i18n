# Einführung

## For-Schleifen

Eine `for`-Anweisung wiederholt einen Block Code.
Die erste Zeile legt fest, wie oft der Block wiederholt wird:

```go
for init; condition; post {
    // loop body
}
```

- Die **init**-Anweisung wird einmal vor der ersten Iteration ausgeführt. Häufig deklarierst und initialisierst du damit eine Zählvariable, die die Schleife verwendet.
- Die **condition**-Komponente ist ein boolescher Ausdruck, der vor jeder Iteration ausgewertet wird. Die Schleife endet, wenn dieser zu `false` ausgewertet wird.
- Die **post**-Anweisung wird nach jeder abgeschlossenen Iteration ausgeführt. Damit lässt sich eine Zählvariable aktualisieren.

Setze `init; condition; post` nicht in runde Klammern.
Die geschweiften Klammern `{ }` um den Schleifenblock sind jedoch immer erforderlich.

Diese Schleife startet `i` bei `1`, gibt den aktuellen Wert von `i` aus, erhöht ihn für die nächste Iteration und endet, wenn `i` den Wert `10` erreicht:

```go
for i := 1; i < 10; i++ {
    fmt.Println(i)
}
```
