# Einführung

In Haxe sind Ausnahmen eine sichere Möglichkeit, Fehler zu behandeln, die beim Ausführen des Codes auftreten. Alle Ausnahmen sollten eine Nachricht enthalten, die den Fehler beschreibt. Wir können Ausnahmen mit dem Schlüsselwort `throw` _werfen_:

```haxe
public function main(num:Int) {
  if (num < 10) {
    throw "Argument num cannot be greater than 10";
  }
  // ...
}
```

Wenn eine Ausnahme geworfen wird, sucht der Code nach einem Abschnitt, der dafür vorgesehen ist, den Fehler zu behandeln. Wenn er keinen findet, zeigt er die Fehlermeldung an und beendet dabei die Ausführung des Programms.

Um Ausnahmen in Haxe zu behandeln, verwenden wir den `try-catch`-Block. Diese Blockanweisung besteht aus einem `try`-Block und einem oder mehreren `catch`-Blöcken. Der `try`-Block _versucht_, einen Codeabschnitt auszuführen, während der `catch`-Block darauf wartet, dass eine Ausnahme geworfen wird, um sie _abzufangen_, damit die Ausführung nicht gestoppt wird. Wenn der `catch`-Block eine Ausnahme abfängt, führt er außerdem alles innerhalb des Blocks aus:

```haxe
try {
  if (num < 10) {
    throw "Argument num cannot be greater than 10";
  }
} catch (e) {
  // All exceptions will be caught here
  trace(e.message); // Argument num cannot be greater than 10
}
```

Der Typ des Arguments des `catch`-Blocks sollte weggelassen werden.
