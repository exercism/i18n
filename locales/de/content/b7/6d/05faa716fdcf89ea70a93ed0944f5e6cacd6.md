# Einführung

## Standardwerte für Parameter

[Standardwerte für Parameter][default-parameter-values] kannst du für jeden beliebigen Parameter einer Funktion angeben, indem du in der Parameterliste nach der Typannotation des Parameters einen Wert zuweist. Wenn ein Standardwert für einen Parameter angegeben ist, kann der Aufrufer der Funktion diesen Parameter beim Aufruf weglassen; stattdessen wird dann der Standardwert verwendet.

```swift
func greeting(name: String = "guest", duration: Int = 2) -> String {
  "Welcome, \(name). Enjoy your \(duration) night stay."
}

greeting(name: "Bobo", duration: 7)
// Returns "Welcome, Bobo. Enjoy your 7 night stay."
greeting(duration: 3)
// Returns "Welcome, guest. Enjoy your 3 night stay."
greeting(name: "Wynona")
// Returns "Welcome, Wynona. Enjoy your 2 night stay."
greeting()
// Returns "Welcome, guest. Enjoy your 2 night stay."
```

## Variadische Parameter

[Variadische Parameter][variadic-parameters] ermöglichen es einer Funktion, für einen einzelnen Parameter null oder mehr Werte eines bestimmten Typs anzunehmen.
Du definierst einen variadischen Parameter, indem du drei Punkte (`...`) an die Typannotation des Parameters anhängst.

Innerhalb des Funktionskörpers stellt Swift diese Werte als Array des angegebenen Typs bereit:

```swift
import Foundation

func geometricMean(_ numbers: Double...) -> Double {
    var total = 1.0
    for number in numbers {
        total *= number
    }
    return pow(total, 1.0 / Double(numbers.count))
}

let result = geometricMean(1, 2, 3, 4, 5)
// result is 2.605171084697352
```

~~~~exercism/note
Wenn eine Funktion nach einem variadischen Parameter noch weitere Parameter enthält, **muss** der erste Parameter nach dem variadischen Parameter eine explizite Argumentbezeichnung haben, damit Swift weiß, wo die Liste der variadischen Argumente endet.
~~~~


## In-out-Parameter

Innerhalb des Funktionskörpers werden Parameter als Konstanten behandelt, nicht als Variablen. Wenn du versuchst, den Wert eines Parameters zu ändern, gibt es einen Fehler zur Kompilierzeit.
Wenn eine Funktion den Wert eines Parameters ändern möchte, muss sie einen [_In-out-Parameter_][in-out-parameters] verwenden, um diese Veränderbarkeit explizit zu machen.

Um In-out-Parameter zu verwenden, muss man auf drei Dinge achten:

1. In der Funktionsdefinition musst du In-out-Parameter explizit kennzeichnen, indem du das Schlüsselwort `inout` zwischen dem `:` und dem Typnamen in der Typannotation des Parameters schreibst.
2. Der Wert, der an den In-out-Parameter übergeben wird, muss als Variable deklariert sein, nicht als Konstante. Ebenso kann er kein Literal sein.
3. Dem Variablennamen muss beim Aufruf der Funktion ein `&` vorangestellt werden, wodurch er explizit als veränderbar gekennzeichnet wird.

Wenn du das tust, erstellt die Funktion eine interne Kopie des In-out-Parameters und ändert sie so, wie es im Funktionskörper vorgegeben ist. Wenn die Funktion zurückkehrt, kopiert sie den geänderten Wert zurück in die Variable, die übergeben wurde.

```swift
func updateVersion(_ record: inout (version: Int, title: String)) {
  record.version += 1
}

var dbRecord = (version: 2, title: "Exercism")
updateVersion(&dbRecord)

// dbRecord is now (3, "Exercism")
```

~~~~exercism/warning
Bei In-out-Parametern gibt es ein paar zusätzliche Regeln, die du kennen solltest.

1  Innerhalb einer Funktion mit In-out-Parametern darfst du nicht auf die Variable verweisen, die als In-out-Parameter übergeben wurde.
2. Dieselbe Variable kann in derselben Funktion nicht als mehrere In-out-Parameter übergeben werden.
   Zum Beispiel löst `inoutFunc(&mutVar, &mutVar)` einen Compilerfehler aus.
~~~~

## Verschachtelte Funktionen

Funktionen können [innerhalb anderer Funktionen][nested-functions] definiert werden.
Das wird häufig genutzt, um Hilfsfunktionen zu erstellen, die nur für die umgebende Funktion nützlich sind und daher nicht den äußeren Namensraum verschmutzen müssen.

Diese Funktionen werden genauso definiert und aufgerufen wie normale Funktionen, sind aber außerhalb der umgebenden Funktion nicht sichtbar.

```swift
func makeNumber(_ number: Int) -> Int {
  func double(_ x: Int) -> Int { 2 * x }
  func add(_ x: Int) -> Int { x + 1 }

  return number.isMultiple(of: 2) ? add(double(number)) : double(number)
}

makeNumber(3)
// Returns 6
makeNumber(4)
// Returns 9
```
