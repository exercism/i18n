# Einführung

Swift bietet eine Variante seiner Syntax im Umgang mit Closures, die man Trailing Closures nennt. Von einer Trailing Closure spricht man, wenn der letzte Parameter in der Parameterliste einer Funktion einen Funktionstyp hat. Wenn man in diesem Fall eine Closure übergibt, kann man die Closure _nach_ der schließenden runden Klammer schreiben, und das Argument-Label entfällt. Beachte, dass die Klammern ganz weggelassen werden können, wenn die Funktion nur einen Parameter hat.

```swift
func fetchURL(_ urlString: String,
              uponReceipt handleResult: (String) -> ()
             )  -> () {
  if let url = URL(string: urlString), let htmlString = fetch(url) {
    handleResult(htmlString)
  }
}

fetchURL("https://www.swift.org") { print($0) }
// prints the fetched html string

["apple", "ball", "carrot"].sorted { $0.count < $1.count }
```
