# Anleitung

Du betreibst eine Online-Boutique für Mode. Dein großer Ausverkauf steht kurz bevor, also musst du deinen Bestand überprüfen, um sicherzugehen, dass du bereit bist.

Ein einzelner Artikel im Bestand wird durch eine Map dargestellt, und der gesamte Bestand ist eine Liste solcher Maps.

```elixir
%{
  name: "White Shirt",
  price: 40,
  quantity_by_size: %{s: 3, m: 7, l: 8, xl: 4}
}
```

## 1. Sortiere die Artikel nach dem Preis

Implementiere die Funktion `sort_by_price/1`. Sie soll den Bestand entgegennehmen und ihn nach dem Artikelpreis aufsteigend sortiert zurückgeben.

```elixir
BoutiqueInventory.sort_by_price([
  %{price: 65, name: "Maxi Brown Dress", quantity_by_size: %{}},
  %{price: 50, name: "Red Short Skirt", quantity_by_size: %{}},
  %{price: 50, name: "Black Short Skirt", quantity_by_size: %{}},
  %{price: 20, name: "Bamboo Socks Cats", quantity_by_size: %{}}
])

# => [
#      %{price: 20, name: "Bamboo Socks Cats", quantity_by_size: %{}},
#      %{price: 50, name: "Red Short Skirt", quantity_by_size: %{}},
#      %{price: 50, name: "Black Short Skirt", quantity_by_size: %{}},
#      %{price: 65, name: "Maxi Brown Dress", price: 65, quantity_by_size: %{}}
#    ]
```

## 2. Finde alle Artikel mit fehlendem Preis

Nachdem du deinen Bestand nach dem Preis sortiert hast, ist dir aufgefallen, dass du beim Erfassen des Bestands einen Fehler gemacht haben musst und vergessen hast, für ein paar Artikel die Preise einzutragen.

Implementiere die Funktion `with_missing_price/1`. Sie soll den Bestand entgegennehmen und eine Liste der Artikel zurückgeben, die keinen Preis haben.

```elixir
BoutiqueInventory.with_missing_price([
  %{price: 40, name: "Black T-shirt", quantity_by_size: %{}},
  %{price: nil, name: "Denim Pants", quantity_by_size: %{}},
  %{price: nil, name: "Denim Skirt", quantity_by_size: %{}},
  %{price: 40, name: "Orange T-shirt", quantity_by_size: %{}}
])

# => [
#      %{price: nil, name: "Denim Pants", quantity_by_size: %{}},
#      %{price: nil, name: "Denim Skirt", quantity_by_size: %{}}
#    ]
```

## 3. Aktualisiere die Artikelnamen

Dir ist aufgefallen, dass in einigen Artikelnamen ein Wort vorkommt, das du nicht mehr verwenden möchtest. Jetzt musst du alle Artikelnamen mit diesem Wort aktualisieren.

Implementiere die Funktion `update_names/3`. Sie soll den Bestand, das alte Wort, das du entfernen möchtest, und ein neues Wort, das du stattdessen verwenden möchtest, entgegennehmen. Sie soll eine Liste der Artikel mit aktualisierten Namen zurückgeben.

```elixir
BoutiqueInventory.update_names(
  [
    %{price: 40, name: "Black T-shirt", quantity_by_size: %{}},
    %{price: 70, name: "Denim Pants", quantity_by_size: %{}},
    %{price: 65, name: "Denim Skirt", quantity_by_size: %{}},
    %{price: 40, name: "Orange T-shirt", quantity_by_size: %{}}
  ],
  "T-shirt",
  "Tee"
)

# => [
#      %{price: 40, name: "Black Tee", quantity_by_size: %{}},
#      %{price: 70, name: "Denim Pants", quantity_by_size: %{}},
#      %{price: 65, name: "Denim Skirt", quantity_by_size: %{}},
#      %{price: 40, name: "Orange Tee", quantity_by_size: %{}}
#    ]
```


## 4. Erhöhe die Menge des Artikels

Einige Artikel verkauften sich besonders gut, also hast du mehr nachbestellt, in allen Größen.

Implementiere die Funktion `increase_quantity/2`. Sie soll einen einzelnen Artikel und eine Zahl `n` entgegennehmen und diesen Artikel zurückgeben, wobei die Menge für jede Größe um `n` erhöht wurde.

```elixir
BoutiqueInventory.increase_quantity(
  %{
    name: "Polka Dot Skirt",
    price: 68,
    quantity_by_size: %{s: 3, m: 5, l: 3, xl: 4}
  },
  6
)

# => %{
#      name: "Polka Dot Skirt",
#      price: 68,
#      quantity_by_size: %{l: 9, m: 11, s: 9, xl: 10}
#    }
```

## 5. Berechne die Gesamtmenge des Artikels

Um zu wissen, wie viel Platz du in deinem Lager brauchst, musst du wissen, wie viele Stücke du von jedem Artikel insgesamt hast.

Implementiere die Funktion `total_quantity/1`. Sie soll einen einzelnen Artikel entgegennehmen und zurückgeben, wie viele Stücke du insgesamt hast, egal in welcher Größe.

```elixir
BoutiqueInventory.total_quantity(%{
  name: "Red Shirt",
  price: 62,
  quantity_by_size: %{s: 3, m: 6, l: 5, xl: 2}
})

# => 16
```
