# Ausgabe

Die Ausgabe in Cairo ermöglicht es dir, Nachrichten und Werte auf der Konsole anzuzeigen. Das erleichtert das Debuggen von Programmen oder die Kommunikation von Informationen während der Ausführung.

Das Ausgabesystem ist vielseitig und unkompliziert und bietet Werkzeuge zum Formatieren und Ausgeben von Daten verschiedener Typen.

## Grundlagen der Ausgabe

Cairo bietet zwei primäre Makros zum Ausgeben von Text auf der Konsole:

- **`println!`**: Gibt die Ausgabe in einer neuen Zeile aus.
- **`print!`**: Gibt die Ausgabe ohne Zeilenumbruch aus.

Beide Makros nehmen ein `ByteArray` als primäres Argument, das ein einfacher String oder ein formatierter String mit Platzhaltern für Werte sein kann.

```rust
// Printing a simple message
println!("Hello, Cairo!");

// Printing with values
let x = 10;
let y = 20;
println!("Values: x = {}, y = {}", x, y);
```

Im obigen Beispiel:

- `{}`-Platzhalter werden durch die Werte von `x` und `y` ersetzt.
- `println!` stellt sicher, dass die Ausgabe mit einer neuen Zeile endet.

## Strings formatieren

Manchmal musst du einen formatierten String erstellen, ohne ihn sofort auszugeben.

Das Makro `format!` ermöglicht dir das.

Es funktioniert ähnlich wie `println!`, gibt aber ein `ByteArray` zurück, anstatt eine Ausgabe auf der Konsole zu senden.

```rust
let s1: ByteArray = "tic";
let s2: ByteArray = "tac";
let s3: ByteArray = "toe";

// Create a formatted string
let result = format!("{s1}-{s2}-{s3}");

println!("{}", result); // Output: tic-tac-toe
```

In diesem Beispiel:

- `format!` kombiniert `s1`, `s2` und `s3` zu einem einzigen String und trennt sie durch Bindestriche (`-`).
- Der resultierende String kann später wiederverwendet oder ausgegeben werden.

## Benutzerdefinierte Datentypen ausgeben

Standardmäßig kann Cairo nur grundlegende Typen wie Ganzzahlen und Strings ausgeben.

Wenn du versuchst, einen benutzerdefinierten Typ wie ein Struct auszugeben, tritt ein Fehler auf, es sei denn, der Typ implementiert die Traits `Display` oder `Debug`.

### `Display` für benutzerdefinierte Formatierung verwenden

Das Trait `Display` ermöglicht es dir, zu definieren, wie ein benutzerdefinierter Typ ausgegeben werden soll.

Hier ist ein Beispiel:

```rust
use core::fmt::{Display, Formatter, Error};

struct Point {
    x: u8,
    y: u8,
}

impl PointDisplay of Display<Point> {
    fn fmt(self: @Point, ref f: Formatter) -> Result<(), Error> {
        write!(f, "Point({}, {})", *self.x, *self.y)
    }
}

let p = Point { x: 3, y: 4 };
println!("{}", p); // Output: Point(3, 4)
```

In diesem Beispiel:

- Die Funktion `fmt` definiert, wie das Struct `Point` in einen ausgabefähigen String umgewandelt wird.
- Das Makro `write!` hängt den formatierten String an den `Formatter` an.

### Debuggen mit `Debug`

Für Debugging-Zwecke bietet Cairo das Trait `Debug`.

Du kannst es für die meisten Typen automatisch ableiten, was das Ausgeben interner Details deiner Structs schnell und einfach macht.

```rust
#[derive(Debug)]
struct Point {
    x: u8,
    y: u8,
}

let p = Point { x: 3, y: 4 };
println!("{:?}", p); // Output: Point { x: 3, y: 4 }
```

In diesem Beispiel:

- `#[derive(Debug)]` generiert automatisch die Implementierung für das Trait `Debug`.
- Der Platzhalter `{:?}` weist `println!` an, das Trait `Debug` für die Formatierung zu verwenden.

## Ausgabe in Hexadezimal

Cairo ermöglicht es, Ganzzahlen im Hexadezimalformat mit dem Platzhalter `{:x}` auszugeben.

```rust
let value: u32 = 255;
println!("{:x}", value); // Output: ff
```

Dies ist besonders nützlich, wenn du mit Darstellungen auf niedriger Ebene arbeitest.
