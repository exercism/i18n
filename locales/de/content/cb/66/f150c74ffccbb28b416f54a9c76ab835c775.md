# Anleitung

In dieser Übung legst du einige Konstanten fest, die beim Betrieb einer Bank verwendet werden.

Du hast fünf Aufgaben:

## 1. Den festen Zinssatz für einen Kredit darstellen

Erstelle die untypisierte numerische Konstante `FixedInterestRate` mit dem Wert 5 % (5/100) und implementiere dann die Funktion `GetFixedInterestRate`, die ihn zurückgibt:

```go
GetFixedInterestRate()
// => 0.05
```

## 2. Die Anzahl der Tage eines Jahres darstellen

Erstelle die Konstante `DaysPerYear` vom Typ `int` mit dem Wert 365 und implementiere dann die Funktion `GetDaysPerYear`, die ihn zurückgibt:

```go
GetDaysPerYear()
// => 365
```

## 3. Die Monate des Jahres darstellen

Erstelle in einem Block mit dem Go-Enumerator zwölf untypisierte numerische Konstanten mit den Werten 1 bis 12 für die Monate des Jahres.
Benenne sie `Jan`, `Feb`, `Mar` usw. und implementiere dann die Funktion `GetMonth`, die den Wert für einen gegebenen Monat zurückgibt:

```go
GetMonth(Jan)
// => 1
```

## 4. Eine Kontonummer darstellen

Erstelle die untypisierte String-Konstante `AccountNo` mit dem Wert XF348IJ und implementiere dann die Funktion `GetAccountNumber`, die sie zurückgibt:

```go
GetAccountNumber()
// => "XF348IJ"
```
