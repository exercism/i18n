# Anweisungen

In dieser Übung spielst du mit einem ferngesteuerten Auto herum, für das du endlich genug Geld gespart hast.

Die Autos starten mit vollen (100 %) Akkus. Jedes Mal, wenn du das Auto mit der Fernbedienung fährst, legt es 20 Meter zurück und verbraucht ein Prozent des Akkus.

Das ferngesteuerte Auto hat ein schickes LED-Display, das zwei Informationen anzeigt:

- Die insgesamt gefahrene Strecke, angezeigt als: `"Driven <METERS> meters"`.
- Die verbleibende Akkuladung, angezeigt als: `"Battery at <PERCENTAGE>%"`.

Wenn der Akku bei 0 % ist, kannst du das Auto nicht mehr fahren, und die Akkuanzeige zeigt `"Battery empty"` an.

Du hast sechs Aufgaben, die jeweils mit Instanzen des ferngesteuerten Autos arbeiten.

## 1. Kaufe ein brandneues ferngesteuertes Auto

Implementiere die (_statische_) Methode `JedliksToyCar.buy()`, die eine brandneue Instanz des ferngesteuerten Autos zurückgibt:

```java
JedliksToyCar car = JedliksToyCar.buy();
```

## 2. Zeige die gefahrene Strecke an

Implementiere die Methode `JedliksToyCar.distanceDisplay()`, die die Strecke so zurückgibt, wie sie auf dem LED-Display angezeigt wird:

```java
JedliksToyCar car = JedliksToyCar.buy();
car.distanceDisplay();
// => "Driven 0 meters"
```

## 3. Zeige den Akkustand in Prozent an

Implementiere die Methode `JedliksToyCar.batteryDisplay()`, die den Akkustand so zurückgibt, wie er auf dem LED-Display angezeigt wird:

```java
JedliksToyCar car = JedliksToyCar.buy();
car.batteryDisplay();
// => "Battery at 100%"
```

## 4. Aktualisiere die gefahrenen Meter beim Fahren

Implementiere die Methode `JedliksToyCar.drive()`, die die Anzahl der gefahrenen Meter aktualisiert:

```java
JedliksToyCar car = JedliksToyCar.buy();
car.drive();
car.drive();
car.distanceDisplay();
// => "Driven 40 meters"
```

## 5. Aktualisiere den Akkustand beim Fahren

Aktualisiere die Methode `JedliksToyCar.drive()` so, dass sie auch den Akkustand aktualisiert:

```java
JedliksToyCar car = JedliksToyCar.buy();
car.drive();
car.drive();
car.batteryDisplay();
// => "Battery at 98%"
```

## 6. Verhindere das Fahren, wenn der Akku leer ist

Passe die Methode `JedliksToyCar.drive()` so an, dass sie die gefahrene Strecke nicht erhöht und den Akkustand nicht verringert, wenn der Akku leer ist (bei 0 %):

```java
JedliksToyCar car = JedliksToyCar.buy();

// Drain the battery
// ...

car.distanceDisplay();
// => "Driven 2000 meters"

car.batteryDisplay();
// => "Battery empty"
```
