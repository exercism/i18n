# Vermeide die Rückgabe boolescher Literale

Statt nach einer Bedingung boolesche Literale zurückzugeben, kannst du direkt die Bedingung zurückgeben.

Beispiel:

```java
// instead of
if (someExpression) {
  return true;
} else {
  return false;
}

// ... return the expression directly
return someExpression;
```
