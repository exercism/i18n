# Anweisungen

Als Schachfan möchtest du deine eigene Version des Spiels schreiben.
Ja, es gibt online vielleicht schon jede Menge Schach-Implementierungen, aber deine wird einzigartig sein!

Du fängst damit an, ein Schachbrett zu implementieren.

Das Schachspiel wird auf einem Brett gespielt, das acht Felder breit und acht Felder lang ist.
Die Felder werden durch einen Buchstaben und eine Zahl bezeichnet.

## 1. Definiere den Bereich der Reihen und Linien

Das Spiel muss die Reihen des Bretts speichern.
Die Reihen sind die Zeilen des Bretts und werden von 1 bis 8 nummeriert.

Das Spiel muss auch die Linien des Bretts speichern.
Die Linien sind die Spalten des Bretts und werden durch die Buchstaben A bis H bezeichnet.

Definiere die Konstanten `ranks` und `files`, die den Bereich der Reihen bzw. der Linien speichern.

```swift
ranks
// Returns 1..8

files
// Returns "A".."H"
```

## 2. Prüfe, ob ein Feld gültig ist

Das Spiel muss prüfen, ob ein Feld gültig ist.
Ein Feld ist gültig, wenn Reihe und Linie innerhalb der Bereiche der Reihen und Linien liegen.

Definiere die Methode `isValidSquare(rank:file:)` mit den Argumenten `rank`, das die Reihe als `Int` enthält, und `file`, das die Linie als `String` enthält.
Die Methode sollte `true` zurückgeben, wenn Reihe und Linie innerhalb des Bereichs der Reihen und Linien liegen, und andernfalls `false` zurückgeben.

```swift
isValidSquare(rank: 1, file: "A")
// Returns true
```

## 3. Ermittle die Zeile

Das Spiel speichert alle Felder des Bretts in einem eindimensionalen Array.
Die Felder werden als String aus Reihe und Linie gebildet, z. B. "1A", "8B", "4G" usw.
Um die Zeile eines Feldes zu ermitteln, muss das Spiel den Index des ersten Feldes der Zeile berechnen.

Definiere die Methode `getRow(rank:)` mit dem Argument `rank`, das die Reihe als `Int` enthält.
Die Methode sollte ein Array von Strings zurückgeben, die die Felder der Zeile darstellen.

```swift
let board = ["1A", "1B", "1C", "1D", "1E", "1F", "1G", "1H", "2A", ..., "8H"]
getRow(board, rank: 1)
// Returns ["1A", "1B", "1C", "1D", "1E", "1F", "1G", "1H"]
```
