# Anweisungen

Mary ist ein großer Fan der Fernsehserie Star Trek: The Next Generation.
Sie spielt oft Pen-and-Paper-Rollenspiele, in denen sie und ihre Freunde in die Rollen der Crew des Raumschiffs Enterprise schlüpfen.
Marys Charakter ist Captain Picard, was bedeutet, dass sie das Logbuch des Captains führen muss.
Sie liebt den kreativen Teil des Spiels, mag es aber nicht, spontan zufällige Daten zu erzeugen.

Hilf Mary, indem du Zufallsgeneratoren für Daten erstellst, die typischerweise im Logbuch des Captains auftauchen.

## 1. Erzeuge eine zufällige Registrierungsnummer eines Raumschiffs

Die Enterprise (Registrierungsnummer NCC-1701) ist nicht das einzige Raumschiff, das herumfliegt!
Wenn sie auf ein anderes Raumschiff trifft, muss Mary die Registrierungsnummer dieses Raumschiffs ins Logbuch eintragen.

Registrierungsnummern beginnen mit dem Präfix „NCC-“ und verwenden dann eine Zahl von 1000 bis 9999 (jeweils einschließlich).

Implementiere die Funktion `randomShipRegistryNumber()`, die eine zufällige Registrierungsnummer eines Raumschiffs zurückgibt.

```javascript
randomShipRegistryNumber();
// => "NCC-1947"
```

## 2. Erzeuge eine zufällige Sternzeit

Was nützt ein Logbuch, wenn darin keine Sternzeiten stehen?

Eine Sternzeit ist eine Gleitkommazahl.
Die Abenteuer des Raumschiffs Enterprise aus der ersten Staffel von The Next Generation finden zwischen den Sternzeiten 41000.0 und 42000.0 statt.
Die „4“ steht für das 24. Jahrhundert, die „1“ für die erste Staffel.

Implementiere die Funktion `randomStardate`, die eine Gleitkommazahl zwischen 41000.0 (einschließlich) und 42000.0 (ausschließlich) zurückgibt.

```javascript
randomStardate();
// => 41458.15721310934
```

## 3. Erzeuge einen zufälligen Planeten

Das Raumschiff Enterprise begegnet auf seinen Reisen vielen Planeten.
Planeten im Star-Trek-Universum werden anhand ihrer Eigenschaften in Kategorien eingeteilt.
Die Erde zum Beispiel ist ein Planet der Klasse M.
Alle möglichen Planetenklassen sind: D, H, J, K, L, M, N, R, T und Y.

Implementiere die Funktion `randomPlanetClass()`.
Sie soll zufällig eine der Planetenklassen zurückgeben.

```javascript
randomPlanetClass();
// => "K"
```
