# Hinweise

## 1. Eine Zahl kategorisieren

* Mit den Funktionen `evenp` oder `oddp` kannst du feststellen, ob eine Zahl gerade oder ungerade ist.
* Mit der Funktion `append` kannst du ein Element am Anfang einer Liste einfügen.
* Die Funktionen `car` und `cdr` helfen dir, das erste oder zweite Element eines Paares zu bekommen.

## 2. Viele Zahlen kategorisieren

* Der erste Parameter von `reduce` ist eine Funktion, die zwei Argumente entgegennimmt: den aktuellen akkumulierten Wert und das Element, das verarbeitet werden soll.
* `reduce` akzeptiert einen Parameter `:initial-value`, dessen Wert der erste akkumulierte Wert ist, der an die Funktion übergeben wird.
