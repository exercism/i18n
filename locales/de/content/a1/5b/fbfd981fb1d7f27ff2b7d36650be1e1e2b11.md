# Tests

## Tests ausführen

Wenn du die [Installationsschritte][test-installation-steps] erledigt hast, kannst du aus jedem Übungsverzeichnis (z. B. `~/exercism/gdscript/two-fer`) das Skript starten (es liegt eine Ebene höher, in `../`), um deine lokale Lösung für diese Übung zu testen:

```sh
../test-local-gdscript-solution.sh
```

## Eine Übung lösen

Eine Übung zu lösen bedeutet, alle ihre Tests zu bestehen.

Damit du leichter loslegen kannst, enthält jede Übung eine GDScript-Datei, die nach der Übung benannt ist (z. B. `exercism/gdscript/two-fer/two_fer.gd`).
Du kannst diese Datei als Ausgangspunkt für deine Lösung verwenden.
Du kannst sie nach Bedarf ändern, aber die Tests erwarten, dass die Funktionsnamen so bleiben, wie sie ursprünglich vorgegeben waren.

[test-installation-steps]: https://exercism.org/docs/tracks/gdscript/tests
