# Über

Die `guard`-Anweisung in Swift wird verwendet, um früh aus Funktionen, Schleifen oder Methoden auszusteigen, wenn eine erforderliche Bedingung nicht erfüllt ist:

```swift
guard myValue >= 0 else { return 0 }
let root = myValue.squareRoot()
```

Im obigen Beispiel wertet `guard` den booleschen Ausdruck aus, der darauf folgt.
Ist die Bedingung `true`, läuft die Ausführung mit dem Code nach der `guard`-Anweisung weiter.
Ist die Bedingung `false`, wird der Code im `else`-Block ausgeführt.

Anders als eine `if`-Anweisung:

- Eine `guard`-Anweisung **muss** einen `else`-Zweig enthalten.
- Der `else`-Zweig **muss** die Kontrolle übertragen, um den umgebenden Gültigkeitsbereich zu verlassen (zum Beispiel mit `return`, `continue`, `break` oder indem ein Fehler ausgelöst wird).

`guard` wird oft verwendet, um Vorbedingungen sauber zu prüfen.
Betrachte zum Beispiel die sinc-Funktion ($\text{sinc}(x) = \frac{\sin(x)}{x}$, mit $\text{sinc}(0) = 1$, um die Division durch null zu vermeiden):

```swift
func sinc(_ x: Double) -> Double {
    guard x != 0 else { return 1 }
    return sin(x) / x
}

sinc(0)             // returns 1
sinc(Double.pi / 2) // returns 0.6366197723675814
```
