# Anleitung

Du betreibst ein System, das aus ein paar Anwendungen besteht, die viele Logs erzeugen. Du möchtest ein kleines Programm schreiben, das diese Logs zusammenfasst und ihnen Labels entsprechend ihrem Schweregrad zuweist. Alle Anwendungen in deinem System verwenden dieselben Log-Codes, aber einige der Legacy-Anwendungen unterstützen nicht alle Codes.

| Log-Code              | Log-Label | In Legacy-Apps unterstützt? |
|-----------------------| --------- | ------------------------- |
| 0                     | trace     | nein                      |
| 1                     | debug     | ja                        |
| 2                     | info      | ja                        |
| 3                     | warning   | ja                        |
| 4                     | error     | ja                        |
| 5                     | fatal     | nein                      |
| andere / nicht unterstützt | unknown   | -                         |

## 1. Bestimme das Log-Label

Implementiere die Funktion `LogLevel.to_label/2`. Sie sollte eine Ganzzahl als Code und einen booleschen Wert entgegennehmen, der dir sagt, ob der Log von einer Legacy-App stammt, und das Label einer Logzeile als Atom zurückgeben.

Log-Codes, die nicht in der Tabelle angegeben sind, sollten ein _unknown_-Label zurückgeben. Log-Codes, die in der Tabelle als nicht in Legacy-Apps unterstützt angegeben sind, sollten ebenfalls ein _unknown_-Label zurückgeben, wenn der Log von einer Legacy-App stammt.

```elixir
LogLevel.to_label(0, false)
# => :trace

LogLevel.to_label(0, true)
# => :unknown
```

## 2. Sende einen Alarm

Jemand muss benachrichtigt werden, wenn unerwartete Dinge passieren.

Implementiere die Funktion `LogLevel.alert_recipient/2`, um zu bestimmen, an wen der Alarm gesendet werden muss. Die Funktion sollte eine Ganzzahl als Code und einen booleschen Wert entgegennehmen, der dir sagt, ob der Log von einer Legacy-App stammt, und den Namen des Empfängers als Atom zurückgeben.

Verwende die Funktion `LogLevel.to_label/2` aus der vorherigen Aufgabe. Wenn das Log-Label _error_ oder _fatal_ ist, sende den Alarm an das _ops_-Team. Wenn du einen Log mit einem _unknown_-Label von einem Legacy-System erhältst, sende den Alarm an das _dev1_-Team. Andere _unknown_-Labels sollten an das _dev2_-Team gesendet werden. Alle anderen Log-Labels kannst du getrost ignorieren, indem du _false_ zurückgibst.

```elixir
LogLevel.alert_recipient(-1, true)
# => :dev1

LogLevel.alert_recipient(0, false)
# => false
```
