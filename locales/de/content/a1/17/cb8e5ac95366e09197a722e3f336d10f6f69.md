# Anweisungen

Du hilfst Highschool-Liebespaaren dabei, ihre Liebe in den sozialen Medien
zu bekennen, indem du ein Unicode-Herz mit ihren Initialen erzeugst:

```
❤ J.  +  M. ❤
```

## 1. Bereinige den Namen

Definiere `cleanupname`, das einen Namen vom Stack nimmt. Ersetze jedes `-`
durch ein Leerzeichen und entferne dann führende und abschließende
Leerzeichen.

```factor
"Jane-Ann" cleanupname .
! => "Jane Ann"
```

## 2. Hole den ersten Buchstaben des Namens

Definiere `firstletter`, das einen Namen nimmt. Verwende `cleanupname` aus der
vorherigen Aufgabe erneut, nimm dann das erste Zeichen des Ergebnisses und gib
es als String mit einem Zeichen zurück.

```factor
"Jane" firstletter .
! => "J"
```

## 3. Formatiere den ersten Buchstaben als Initiale

Definiere `initial`, das einen Namen nimmt. Verwende `firstletter` aus der
vorherigen Aufgabe erneut, wandle es in einen Großbuchstaben um und hänge dann
einen `.` an.

```factor
"Robert" initial .
! => "R."
```

## 4. Setze die Initialen in das Herz

Definiere `couple`, das zwei Namen vom Stack nimmt. Wende `initial` aus der
vorherigen Aufgabe auf jeden Namen an und setze dann das Ergebnis zusammen:

```factor
"Blake Miller" "Riley Lewis" couple .
! => "❤ B.  +  R. ❤"
```
