# Tests

## Tests ausführen

Führe die Testspezifikation aus mit:

```bash
$ gradle test
```

## Weitere Tests aktivieren

Sobald dein Code alle aktiven Tests besteht, kannst du einen weiteren Test aktivieren, indem du das `@Ignore` vor dem nächsten Test entfernst, der dich interessiert. Lösche dazu die Zeile mit `@Ignore`, oder kommentiere sie aus, indem du zwei Schrägstriche an den Zeilenanfang setzt.

```Groovy
//@Ignore
def 'outputs "Hello, Alice!" when given the name "Alice"'() {
    expect: hello.hello('Alice') == 'Hello, Alice!'
}
```
