# Einführung

Die Gleam-Standardbibliothek implementiert im Modul `gleam/queue` einen Typ `Queue`. Er ähnelt dem Typ `List`, weist aber einige wichtige Unterschiede auf:

- Der Typ `Queue` hat keine Literalsyntax, mit der du Warteschlangen konstruieren oder per Musterabgleich verarbeiten kannst.
- Elemente können effizient sowohl am vorderen als auch am hinteren Ende des Typs `Queue` hinzugefügt und entfernt werden, während der Typ `List` Elemente nur am vorderen Ende effizient hinzufügen und entfernen kann.

Meistens wirst du den Typ `List` verwenden wollen, aber wenn du Elemente am Ende einer Sammlung hinzufügen und entfernen können musst, ist der Typ `Queue` eine gute Wahl.

Mit den Funktionen `queue.new` und `queue.from_list` kannst du Warteschlangen erstellen:

```gleam
let empty = queue.new()
let one_to_four = queue.from_list([1, 2, 3, 4])
```

Mit den Funktionen `queue.push_front` und `queue.push_back` kannst du Elemente zur Warteschlange hinzufügen:

```gleam
let one_to_four = queue.from_list([1, 2, 3, 4])
let one_to_five = queue.push_back(one_to_four, 5)
let zero_to_five = queue.push_front(one_to_five, 0)
```

Mit den Funktionen `queue.pop_front` und `queue.pop_back` kannst du Elemente aus der Warteschlange entfernen:

```gleam
let one_to_four = queue.from_list([1, 2, 3, 4])

queue.pop_back(one_to_four)
// -> Ok(#(4, queue.from_list([1, 2, 3])))

queue.pop_front(one_to_four)
// -> Ok(#(1, queue.from_list([2, 3, 4])))

queue.pop_front(queue.new())
// -> Error(Nil)
```

Mit der Funktion `queue.to_list` kannst du eine Warteschlange in eine Liste umwandeln:

```gleam
let one_to_four = queue.from_list([1, 2, 3, 4])
queue.to_list(one_to_four)
// -> [1, 2, 3, 4]
```

## Gleichheit von Warteschlangen

Dadurch, wie Warteschlangen implementiert sind, können zwei Warteschlangen mit denselben Elementen in derselben Reihenfolge im Sinne des Operators `==`, der Werte strukturell vergleicht, ungleich sein. Zum Beispiel:

```gleam
let empty = queue.new()
let a = queue.push_front(empty, 1)
let b = queue.push_back(empty, 1)
a == b
// -> False
```

Wenn du zwei Warteschlangen auf Gleichheit vergleichen musst, kannst du die Funktion `queue.is_logically_equal` verwenden.

```gleam
queue.is_logically_equal(a, b, fn(x, y) { x == y })))
// -> True
```
