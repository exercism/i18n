# Ergänzung zu den Anweisungen

## Beispieleingabe

```j
  INPUTS=: 2 ; 1 0 0 1 0 1 ; 10
```

Das heißt, deine Eingaben sind:
```
  0{INPUTS NB. is the input base.
  1{INPUTS NB. is the digits.
  2{INPUTS NB. is the output base.
```
## Umgang mit ungültigen Eingaben

Wenn einer der Eingabewerte ungültig ist, sollte dein Verb ein `empty` zurückgeben (z. B. `0$0` oder `''`).

### Beispiele

- Wenn die _Eingabebasis_ kleiner als 2 ist:
    ```j
      '' -: rebase 10 ; 0 0 0 0 ; 1
    ```

- Wenn die _Ausgabebasis_ kleiner als 2 ist:
    ```j
      '' -: rebase 1 ; 0 0 0 0 ; _7
    ```

- Wenn _Ziffern_ Werte enthalten, die größer oder gleich der Eingabebasis sind:
    ```j
      '' -: rebase 10 ; 1 0 2 0 ; 2
    ```
