# Einführung

## Variablen definieren

Eine Variable zu definieren bedeutet, einem Namen einen Wert zuzuweisen. In Scala gibt es zwei Arten von Variablen: vals und vars.

Ein `val` ist unveränderlich, sein Wert kann nach der ersten Zuweisung also nicht mehr geändert werden:

```scala
val numberTen = 10

numberTen = 11
// --> raises a compile error "reassignment to val"
```

Ein `var` kann dagegen mit einem neuen Wert desselben Typs neu belegt werden:

```scala
var someNumber = 10

someNumber = 11
// now someNumber has been reassigned
```

Scala ist eine statisch typisierte Sprache. Das bedeutet, dass alles zur Compile-Zeit einen Typ hat. Eine Variable lässt sich entweder definieren, indem du ihren Typ explizit angibst, oder indem der Scala-Compiler den Typ anhand des zugewiesenen Werts ableitet (das nennt man Typinferenz). Die folgenden beiden Variablendefinitionen sind daher gleichwertig:

```scala
val explicitNumber: Int = 10; // Explicitly typed
val implicitNumber = 10; // Implicitly typed
```

Einmal definiert, kann sich der Typ einer Variablen nie ändern.

```scala
var count = 1; // Assigning an initial value of type Int
count = 2;     // Updating to new value is possible, because it is defined as var

count = false;
// --> raises a compile error "type mismatch"
```

## Methoden innerhalb von Klassen definieren

Scala ist eine _objektorientierte Sprache_ und verlangt, dass alle Methoden in einer _Klasse_ definiert werden. Mit dem Schlüsselwort `class` definierst du eine Klasse.

```scala
class Calculator {
  // ...
}
```

Innerhalb einer Klasse kannst du Methoden definieren. Sie beginnen mit dem Schlüsselwort `def`, gefolgt von einem Namen. Jede Methode kann null oder mehr Parameter haben, die durch Kommas getrennt in runden Klammern aufgelistet werden. Alle Parameter müssen explizit typisiert sein, für Parameter gibt es keine Typinferenz. Nach der Parameterliste folgt, durch einen weiteren Doppelpunkt getrennt, der Rückgabetyp der Methode.

Auf die Methodendefinition folgt ein `=`-Zeichen, das den Methodenkörper einleitet. Im folgenden Beispiel besteht der Methodenkörper aus zwei Anweisungen, die von geschweiften Klammern umschlossen sind.

Die Methode gibt den Wert des letzten Ausdrucks zurück. In diesem Fall gibt die Methode `add` den Wert der Variablen `sum` zurück:

```scala
class Calculator {
  // long form
  def add(x: Int, y: Int): Int = {
    val sum = x + y
    sum
  }
}
```

Es gibt ein paar Verbesserungen, mit denen du diese Methode kürzen und so die Lesbarkeit verbessern kannst:

- da auf die Variable `sum` nur einmal zugegriffen wird, um den Wert zurückzugeben, kannst du sie weglassen
- Methoden, die nur aus einer Anweisung bestehen, brauchen keine geschweiften Klammern
- der Rückgabetyp der Methode lässt sich genauso ableiten wie der Typ von Variablen

So erhältst du die folgende einzeilige Methode mit derselben Funktionalität:

```scala
class Calculator {
  // shortened form
  def add(x: Int, y: Int) = x + y
}
```

## Klassen instanziieren und Methoden aufrufen

Um eine Methode aufzurufen, erstellst du zuerst eine Instanz einer Klasse und rufst dann die Methode mit Argumenten auf dieser Instanz auf:

```scala
val calculator = new Calculator()
val sum = calculator.add(5, 7)
// sum is of type Int with assigned value of 12
```

## Kommentare

Scala unterstützt zwei Arten von Kommentaren: einzeilige Kommentare und mehrzeilige Kommentare:

```scala
// this is a single line comment

/*
This comment spans across
multiple lines.
*/
```
