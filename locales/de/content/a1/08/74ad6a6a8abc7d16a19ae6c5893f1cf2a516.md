# Ergänzung zu den Anweisungen

Überschreibe den übergebenen String mit der Telefonnummer.
Wenn die Telefonnummer ungültig ist, ersetze sie durch einen leeren String.

## Register

| Register | Verwendung   | Typ     | Beschreibung                                      |
| -------- | ------------ | ------- | ------------------------------------------------- |
| `$a0`    | Eingabe/Ausgabe | Adresse | Telefonnummer als nullterminierter String       |
| `$t0-9`  | temporär     | beliebig | dient zur temporären Speicherung                 |
