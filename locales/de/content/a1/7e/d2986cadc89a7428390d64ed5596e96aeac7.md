# Tests

Wir verwenden [PonyTest](https://stdlib.ponylang.io/pony_test--index/) aus der Standardbibliothek, um die Tests zu schreiben, mit denen deine Lösung geprüft wird. Um deine Lösung zu testen, kompilierst und startest du deinen Code.

Zum Beispiel könnte deine Sitzung für „Hello World“ so aussehen:

```text
[red@apophenia:~/exercism/pony/hello-world]$ ponyc
Generating
 Reachability
 Selector painting
 Data prototypes
 Data types
 Function prototypes
 Functions
 Descriptors
Optimising
Writing ./hello-world.o
Linking ./hello-world

[red@apophenia:~/exercism/pony/hello-world]$ ./hello-world 
1 test started, 0 complete: hello-world/HelloWorld started
1 test started, 1 complete: hello-world/HelloWorld complete
---- Passed: hello-world/HelloWorld
----
---- 1 test ran.
---- Passed: 1
```
