# Anleitung

Mary ist ein großer Fan der TV-Serie _Star Trek: The Next Generation_.
Sie spielt oft Pen-&-Paper-Rollenspiele, bei denen sie und ihre Freunde in die Rollen der Crew der _Starship Enterprise_ schlüpfen.
Marys Figur ist Captain Picard, was bedeutet, dass sie das Logbuch des Captains führen muss.
Sie liebt den kreativen Teil des Spiels, mag es aber nicht, spontan Zufallsdaten zu erzeugen.

Hilf Mary, indem du Zufallsgeneratoren für Daten erstellst, die häufig im Logbuch des Captains vorkommen.

~~~~exercism/note
Die Startimplementierung dieser Übung nimmt eine Instanz von `java.util.Random` als Konstruktorargument entgegen.
Dadurch können die Tests der Übung eine Instanz mit einem vorgegebenen Seed übergeben, wodurch die Testergebnisse vorhersagbar werden.

Deshalb solltest du die bereitgestellte Instanz von `java.util.Random` in deiner Implementierung verwenden.
~~~~

## 1. Erzeuge einen zufälligen Planeten

Die _Starship Enterprise_ trifft auf ihren Reisen auf viele Planeten.
Planeten im Star-Trek-Universum werden anhand ihrer Eigenschaften in Kategorien eingeteilt.
Die Erde zum Beispiel ist ein Planet der Klasse `M`.
Alle möglichen Planetenklassen sind: `D`, `H`, `J`, `K`, `L`, `M`, `N`, `R`, `T` und `Y`.

Implementiere die Methode `randomPlanetClass()`.
Sie soll zufällig eine der Planetenklassen zurückgeben.

```java
captainsLog.randomPlanetClass();
// => "K"
```

## 2. Erzeuge eine zufällige Registriernummer eines Raumschiffs

Die Enterprise (Registriernummer `NCC-1701`) ist nicht das einzige Raumschiff, das durchs All fliegt!
Wenn sie sich mit einem anderen Raumschiff trifft, muss Mary dessen Registriernummer im Logbuch festhalten.

Registriernummern beginnen mit dem Präfix „NCC-" und enthalten danach eine Zahl von `1000` bis `9999` (einschließlich).

Implementiere die Methode `randomShipRegistryNumber()`, die eine zufällige Registriernummer eines Raumschiffs zurückgibt.

```java
captainsLog.randomShipRegistryNumber();
// => "NCC-1947"
```

## 3. Erzeuge eine zufällige Sternzeit

Was nützt ein Logbuch ohne Datumsangaben?

Eine Sternzeit ist eine Gleitkommazahl.
Die Abenteuer der _Starship Enterprise_ aus der ersten Staffel von _The Next Generation_ spielen zwischen den Sternzeiten `41000.0` und `42000.0`.
Die „4" steht für das 24. Jahrhundert, die „1" für die erste Staffel.

Implementiere die Methode `randomStardate()`, die eine Gleitkommazahl zwischen `41000.0` (einschließlich) und `42000.0` (ausschließlich) zurückgibt.

```java
captainsLog.randomStardate();
// => 41458.15721310934
```
