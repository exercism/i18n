# Überblick

Viele [Typen von Struct- und Klassenmembern][expression-bodied-members] (Felder sind die wichtigste Ausnahme) können die Syntax für expression-bodied Members verwenden. Wenn du ein Member mit einem Ausdruck definierst, entsteht oft kürzerer und besser lesbarer Code als mit traditionellen Blöcken bzw. Anweisungen.

```csharp
public int Times3(int input) => input * 3;

public int Interesting => 1729;
```

Expression-bodied Members können keine Blöcke mit mehreren Anweisungen enthalten, aber wer aus der funktionalen Programmierung kommt, sei gewarnt: Alles, was ein traditionelles Member kann, lässt sich auch mit einem dieser Members erreichen. Der „Ausdruck“ kann eine Zuweisung mit Seiteneffekten sein oder ein Methodenaufruf, was bedeutet, dass alles möglich ist.

[expression-bodied-members]: https://docs.microsoft.com/en-us/dotnet/csharp/programming-guide/statements-expressions-operators/expression-bodied-members
