# Hinweise

## Allgemeines

- Die Vogelanzahl pro Tag wird in einem Feld namens `birdsPerDay` gespeichert.
- Die Vogelanzahl pro Tag ist ein Array, das genau 7 Ganzzahlen enthält.

## 1. Prüfe, wie die Anzahlen letzte Woche waren

- Da wir die letzte Woche speichern, müssen wir nur die Werte der letzten Woche zurückgeben.

## 2. Prüfe, wie viele Vögel heute zu Besuch kamen

- Denk daran, dass die Anzahlen nach Tagen geordnet sind, vom ältesten bis zum neuesten, wobei das letzte Element für heute steht.
- Auf das letzte Element kannst du entweder über seinen (festen) Index zugreifen (denk daran, bei null mit dem Zählen zu beginnen) oder seinen Index über die Größe des Arrays berechnen.

## 3. Erhöhe die heutige Anzahl

- Setze das Element, das die heutige Anzahl darstellt, auf die heutige Anzahl plus 1.

## 4. Prüfe, ob es einen Tag ohne Vogelbesuch gab

- Das Array kann mit einer `for`-Schleife durchlaufen werden.
- Eine andere Lösung ist die Verwendung der Java Stream Api.

## 5. Berechne die Anzahl der Vögel, die in den ersten Tagen zu Besuch kamen

- Eine Variable kann verwendet werden, um die Anzahl der zu Besuch kommenden Vögel zu speichern.
- Das Array kann mit einer `for`-Schleife durchlaufen werden.
- Die Variable kann innerhalb der Schleife aktualisiert werden.
- Denk daran: Arrays werden ab `0` indiziert.

## 6. Berechne die Anzahl der geschäftigen Tage

- Eine Variable kann verwendet werden, um die Anzahl der geschäftigen Tage zu speichern.
- Das Array kann mit einer `foreach`-Schleife durchlaufen werden.
- Die Variable kann innerhalb der Schleife aktualisiert werden.
- Eine bedingte Anweisung kann innerhalb der Schleife verwendet werden.
