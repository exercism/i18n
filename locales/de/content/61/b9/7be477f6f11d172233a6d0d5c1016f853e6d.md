# Haskells eingebaute numerische Typen

## Zahlen

Haskells Standardbibliothek, bekannt als ***Prelude***, definiert die meisten grundlegenden numerischen Typen: Ganzzahlen fester Größe (`Int`), Ganzzahlen beliebiger Genauigkeit (`Integer`), Gleitkommazahlen einfacher Genauigkeit (`Float`) und Gleitkommazahlen doppelter Genauigkeit (`Double`).
Andere numerische Typen wie rationale und komplexe Zahlen werden in zusätzlichen Bibliotheken definiert.

`Integer`-Werte können jede beliebige Zahl halten, egal wie groß sie ist, bis zur Grenze des Arbeitsspeichers deines Rechners, während `Int` der Menge der positiven und negativen Ganzzahlen entspricht, die in 32 oder 64 Bit ausgedrückt werden können (garantiert mindestens -2^29 bis 2^29).

`Float` entspricht der Menge der reellen Zahlen, begrenzt durch die Genauigkeit des Computers.
Operationen, die auf Zahlen definiert sind, funktionieren meist mit dem einen oder dem anderen Typ, aber nicht mit beiden.

Funktionen zur Umwandlung zwischen `Float` und `Integer` sind unter anderem `toFloat`, das `Int`/`Integer` in `Float` umwandelt, und `ceiling`, das `Float` in `Int` umwandelt.

## Arithmetische Operatoren

Haskell hat drei Operatoren zum Potenzieren. Sie funktionieren unterschiedlich und erwarten unterschiedliche Argumenttypen.

- `**` Nimmt zwei **Gleitkommazahlen** und verwendet Logarithmen, um die Potenz zu berechnen.
- `^^` Nimmt eine **Gleitkommazahl** und erhebt sie mit einer positiven oder negativen **Ganzzahl** als Exponenten.
- `^` Nimmt **jeden numerischen Typ** und erhebt ihn mit einer **positiven Ganzzahl** als Exponenten.

Die Umwandlung von einem Ganzzahltyp (`Int` oder `Integer`) in einen anderen numerischen Typ erfolgt mit der Funktion `fromIntegral`.
Der Zieltyp wird automatisch hergeleitet.
Zum Beispiel:

```haskell
n :: Integer
n = 6
x :: Float
x = fromIntegral n      --> x = 6.0

m :: Int
m = 7
y :: Double
y = fromIntegral m      --> y = 7.0
```

Die Division von Ganzzahlen ist etwas kompliziert.
Wenn du den gewöhnlichen Operator `/` auf Ganzzahlen anwendest, erhältst du eine Fehlermeldung (obwohl der Ausdruck `4/3` funktioniert, weil Haskell hilfreicherweise Ganzzahlliterale in Gleitkommazahlen umwandelt, wo es nötig ist).
Stattdessen verwendet man für die Ganzzahldivision eine Reihe benannter Operatoren.

Haskell hat einen raffinierten Trick mit Operatoren: Du kannst jede Funktion, die zwei Argumente annimmt, wie einen Operator verwenden, indem du den Namen in Backticks einschließt.
Die folgenden beiden Zeilen bedeuten also genau dasselbe:

```haskell
 d = 7 `div` 3
 d = div 7 3
```

Vor diesem Hintergrund sind hier die Operatoren für die Ganzzahldivision:

- `quot`: Gibt den Quotienten der beiden Zahlen zurück.
  Das ist das Ergebnis der Division, das dann gegen null abgeschnitten wird.
- `rem`: Gibt den Rest aus dem Quotienten zurück.
- `div`: Ähnlich wie `quot`, wird aber gegen minus unendlich abgerundet.
- `mod`: Gibt den Modulus der beiden Zahlen zurück.
  Das ähnelt `rem`, hat aber andere Regeln, wenn `div` eine negative Zahl zurückgibt.

So wie du eine Funktion mit zwei Argumenten in einen Operator umwandeln kannst, kannst du einen Operator in eine Funktion mit zwei Argumenten umwandeln, indem du ihn in runde Klammern setzt.
Die folgenden beiden Zeilen bedeuten also dasselbe:

```haskell
(+) 3 4
3 + 4
```
