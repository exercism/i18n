# Boolesche Werte

`BOOL` enthält einen von zwei Werten, `true` und `false`.

```sather
   ready : BOOL is
      return true;
   end;
```

## Vergleich

| Operator | Fragt | Beispiel |
| --- | --- | --- |
| `=` | gleich? | `age = 13` |
| `/=` | anders? | `age /= 13` |
| `<` | kleiner als | `age < 13` |
| `<=` | kleiner oder gleich | `age <= 13` |
| `>` | größer als | `age > 13` |
| `>=` | größer oder gleich | `age >= 13` |

Diese funktionieren mit Zahlen, und `=` und `/=` funktionieren auch mit Strings.

## Die drei Operatoren

| Operator | Geschrieben | Wahr, wenn |
| --- | --- | --- |
| and | `a and b` | beide wahr sind |
| or | `a or b` | mindestens einer wahr ist |
| not | `~a` | `a` falsch ist |

`and` und `or` **werten kurzgeschlossen aus**: Bei `a and b` wird `b` gar
nicht mehr angeschaut, sobald `a` falsch ist, denn die Antwort steht schon
fest. Genauso hört `a or b` auf, wenn `a` wahr ist. Das ist wichtig, wenn
die rechte Seite teuer ist oder schiefgehen würde, falls sie ausgeführt
wird.

## Einen Vergleich direkt zurückgeben

Eine Routine, deren einzige Aufgabe es ist, eine Frage zu stellen, sollte
die Frage zurückgeben und nicht mit einer Bedingung eine Antwort auswählen:

```sather
   -- say this
   old_enough(age : INT) : BOOL is
      return age >= 13;
   end;
```

Wer `if age >= 13 then return true else return false end` schreibt, braucht
drei Zeilen für das, was der Vergleich schon gesagt hat, und jeder erfahrene
Leser merkt das.

## Rangfolge

`~` bindet am festesten, dann `and`, dann `or`. Also bedeutet

```sather
~a and b or c
```

`((~a) and b) or c`. Klammern kosten nichts und lohnen sich immer dann,
wenn ein Leser sonst diese Reihenfolge im Kopf haben müsste, um der Zeile
zu folgen.
