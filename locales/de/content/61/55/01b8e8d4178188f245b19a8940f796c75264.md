# Alias

Die [spezielle Form `alias`][alias] ermöglicht es dir, den Namen zu kürzen oder zu ändern, mit dem du auf ein externes Modul verweist. Ein eigener Name lässt sich mit der Option `:as` angeben.

```elixir
defmodule Square do
  alias Integer, as: I

  def area(a), do: I.pow(a, 2)
end
```

Verwendest du sie ohne Argumente, kürzt sie den Modulnamen auf seinen letzten Teil, z. B.

```elixir
alias MyApp.Account.User
# is the same as
alias MyApp.Account.User, as: User
```

Mehrere Aliase lassen sich mit `{}` gruppieren:

```elixir
alias MyApp.Account.{User, EmailValidation}
# is the same as
alias MyApp.Account.User
alias MyApp.Account.EmailValidation
```

Normalerweise legst du Aliase am Anfang der Moduldefinition an, aber sie können überall stehen. Sie haben einen lexikalischen Gültigkeitsbereich, das heißt: Ein Alias, den du innerhalb einer Funktionsdefinition anlegst, ist in einer anderen Funktion nicht verfügbar.

Nicht verwendete Aliase führen zu Warnungen des Compilers.

[alias]: https://hexdocs.pm/elixir/Kernel.SpecialForms.html#alias/2
