# Über

MIPS ist eine Befehlssatzarchitektur für Rechner mit reduziertem Befehlssatz (RISC), die heute überwiegend in Spielkonsolen und Routern eingesetzt wird. Sie ist außerdem eine beliebte Architektur in Einführungskursen und Lehrbüchern zur Rechnerarchitektur, weil sie im Vergleich zu x86 und ARM einfacher ist. Hier verwenden wir den 32-Bit-Befehlssatz; ein 64-Bit-Befehlssatz existiert ebenfalls.

In diesem Track programmierst du in der MIPS-Assemblersprache; assembliert und ausgeführt wird dein Code auf einem plattformübergreifenden Simulator.
