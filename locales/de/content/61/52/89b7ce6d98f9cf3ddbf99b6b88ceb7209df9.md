# Einführung

## Attribute

Ein [C#-`Attribute`](https://docs.microsoft.com/en-us/dotnet/csharp/programming-guide/concepts/attributes/) bietet eine Möglichkeit, eine Deklaration mit Metadaten zu versehen und sie so mit einer Klasse, einer Methode, einem Enum, einem Feld, einer Eigenschaft oder beliebigen [anderen unterstützten](https://docs.microsoft.com/en-us/dotnet/csharp/programming-guide/concepts/attributes/#attribute-targets) Deklarationen zu verknüpfen.

Du kannst ein Attribut anwenden, indem du es mit einem `ClassAttribute` und einem `FieldAttribute` in der Zeile vor der Deklaration hinzufügst:

```csharp
[Class]
class MyClass
{
    [Field]
    int myField;
}
```

Diese deklarativen Metadaten verknüpfen nur zusätzliche strukturierte Informationen mit dem Code und ändern sein Verhalten nicht. Andere Teile des Codes verwenden diese Metadaten jedoch, um das Verhalten ihres Ziels zu ändern oder bestimmte Funktionen hinzuzufügen, zu ändern, zu entfernen oder einzuschränken.

Es gibt viele [vordefinierte und reservierte Attribute](https://docs.microsoft.com/en-us/dotnet/csharp/language-reference/attributes/general#conditional-attribute), zum Beispiel: `Flags`, `Obsolete`, `Conditional` und `Experimental`. Jedes davon hat eine bestimmte semantische Bedeutung, die du in der C#-Dokumentation nachschlagen kannst. Beachte, dass der vollständige Name eines Attributs wie [`Flags`](https://docs.microsoft.com/en-us/dotnet/api/system.flagsattribute) die Form `<Name>Attribute` hat (z. B. `FlagsAttribute`).

## Flag-Enums

Der C#-[`enum`-Typ](https://docs.microsoft.com/en-us/dotnet/csharp/language-reference/builtin-types/enum) stellt eine feste Menge benannter Konstanten dar (eine Enumeration).

Normalerweise kann ein `enum`-Member nur auf genau eine dieser benannten Konstanten verweisen. Manchmal ist es jedoch nützlich, auf mehr als eine Konstante zu verweisen. Dazu kannst du das `enum` mit dem [`Flags`-Attribut](https://docs.microsoft.com/en-us/dotnet/api/system.flagsattribute) annotieren.

Ein Flag-Enum lässt sich wie folgt definieren (mit der binären Ganzzahlschreibweise `0b`):

```csharp
[Flags]
enum PhoneFeatures
{
    Call = 0b00000001,
    Text = 0b00000010
}
```

Bei einer `PhoneFeatures`-Instanz mit dem Wert `0b00000011` sind sowohl `Call` _als auch_ `Text` gesetzt.

Standardmäßig wird der Typ `int` für die Werte von Enum-Membern verwendet. Du kannst einen anderen Ganzzahltyp verwenden, indem du den Typ in der Enum-Deklaration angibst:

```csharp
[Flags]
enum PhoneFeatures : byte
{
    Call = 0b00000001,
    Text = 0b00000010
}
```
