# Einführung

[Nil][nil-dictionary] ist ein englisches Wort und bedeutet „nichts“ oder „null“.
In Ruby wird `nil` verwendet, um die _Abwesenheit_ eines Objekts auszudrücken.
In anderen Programmiersprachen können `null`- oder `none`-Werte eine ähnliche Rolle spielen.

```ruby
# I do not have a favorite color
favorite_color = nil
```

Jede Instanzvariable bekommt in Ruby den Standardwert `nil`, wenn sie zum ersten Mal auftritt, bis sie anders gesetzt wird.

[nil-dictionary]: https://www.merriam-webster.com/dictionary/nil
