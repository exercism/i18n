# Einführung

Ein _Enum-Typ_ ist ein spezieller Datentyp, mit dem eine Variable eine Menge vordefinierter Konstanten annehmen kann.
Die Variable muss einem der Werte entsprechen, die für sie vordefiniert wurden.
Häufige Beispiele sind Himmelsrichtungen (Werte von `NORTH`, `SOUTH`, `EAST` und `WEST`) und die Wochentage.

Da sie Konstanten sind, werden die Namen der Felder eines Enum-Typs in Großbuchstaben geschrieben.

## Einen Enum-Typ definieren

In der Programmiersprache Java definierst du einen Enum-Typ mit dem Schlüsselwort `enum`.
Zum Beispiel gibst du einen Enum-Typ für die Wochentage so an:

```java
public enum DayOfWeek {
    SUNDAY,
    MONDAY,
    TUESDAY,
    WEDNESDAY,
    THURSDAY,
    FRIDAY,
    SATURDAY
}
```

Du solltest Enum-Typen immer dann verwenden, wenn du eine feste Menge von Konstanten darstellen musst.
Das umfasst natürliche Enum-Typen wie die Planeten in unserem Sonnensystem und Datensätze, bei denen du zur Kompilierzeit alle möglichen Werte kennst, zum Beispiel die Auswahlmöglichkeiten in einem Menü, Kommandozeilen-Flags und so weiter.

## Einen Enum-Typ verwenden

Der folgende Code zeigt dir, wie du den oben definierten Enum-Typ `DayOfWeek` verwendest:

```java
public class Shop {
    public String getOpeningHours(DayOfWeek dayOfWeek) {
        switch (dayOfWeek) {
            case MONDAY:
            case TUESDAY:
            case WEDNESDAY:
            case THURSDAY:
            case FRIDAY:
                return "9am - 5pm";
            case SATURDAY:
                return "10am - 4pm"
            case SUNDAY:
                return "Closed.";
        }
    }
}
```

```java
var shop = new Shop();
shop.getOpeningHours(DayOfWeek.WEDNESDAY);
// => "9am - 5pm"
```

## Methoden und Felder hinzufügen

Enum-Typen in der Programmiersprache Java sind viel mächtiger als ihre Gegenstücke in anderen Sprachen.
Die `enum`-Deklaration definiert eine _Klasse_ (einen sogenannten _Enum-Typ_).
Der Rumpf der Enum-Klasse kann Methoden und andere Felder enthalten:

```java
public enum Rating {
    GREAT(5),
    GOOD(4),
    OK(3),
    BAD(2),
    TERRIBLE(1);

    private final int numberOfStars;

    Rating(int numberOfStars) {
        this.numberOfStars = numberOfStars;
    }

    public int getNumberOfStars() {
        return this.numberOfStars;
    }
}
```

So rufst du die Methode `getNumberOfStars` für ein Element des Enum-Typs `Rating` auf:

```java
Rating.GOOD.getNumberOfStars();
// => 4
```
