# Hinweise

## 1. Eine neue Liste erstellen

- Common Lisp hat eine [recht anschaulich benannte Funktion][hyper-list], um eine _LIST_ zu erstellen.

## 2. Dinge zur Liste hinzufügen

- Um etwas am Anfang einer Liste hinzuzufügen, ist es idiomatisch, eine neue Liste zu *CONS*truieren, mit dem Element als `car` und der Liste als `cdr`. Im Hyperspec findet sich eine [Seite][hyper-cons], die diese Funktion beschreibt.

## 3. Was steht als Nächstes auf der Liste?

- Common Lisp hat eine Allzweckfunktion, um ein Element [an einem beliebigen Index einer Liste][hyper-nth] zu holen.
- Außerdem gibt es [mehrere Hilfsfunktionen][hyper-first-tenth] für den Zugriff auf Indizes unter 11.
- Listenindizes beginnen bei null.

## 4. Ein Element aus der Liste entfernen

- Eine idiomatische Möglichkeit, das erste Element einer Liste zu entfernen, ist eine Funktion zu verwenden, die das `cdr` der Liste vom `car` der Liste trennen kann. Im Hyperspec findet man eine [Seite][hyper-rest], die eine dieser Funktionen beschreibt.

## 5. Größere Listen aus kleineren Listen

- Common Lisp hat eine Funktion, [die speziell eine Liste an den Anfang einer anderen anhängt][hyper-append].

## 6. Um wie viel länger?

- Common Lisp hat eine [offensichtlich benannte][hyper-length] Funktion, um die Länge einer Liste zu ermitteln.
