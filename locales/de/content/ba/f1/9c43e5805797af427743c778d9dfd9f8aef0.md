# Anleitung

Du gibst die Stichworte für die Vorstellung deiner Schule. Der Inspizient möchte, dass die Standardtexte aufgeschrieben werden, damit jeder die Ansagen machen kann.

Du hast vier Aufgaben, alle in der Klasse `STAGE_DIRECTIONS`.

## 1. Den Anfang ankündigen

Gib die Zeile zurück, die die Vorstellung eröffnet.

```sather
STAGE_DIRECTIONS::opening_line
-- => "The curtain rises."
```

## 2. Die Pause ankündigen

Gib die Zeile zurück, die in der Pause aufgerufen wird.

```sather
STAGE_DIRECTIONS::interval_line
-- => "Interval. Fifteen minutes."
```

## 3. Das Ende ankündigen

Gib die Zeile zurück, die die Vorstellung beendet.

```sather
STAGE_DIRECTIONS::closing_line
-- => "The curtain falls."
```

## 4. Das letzte Stichwort ansagen

Das letzte Stichwort ist dieselbe Zeile wie die, die die Vorstellung beendet. Statt den Text ein zweites Mal aufzuschreiben, ruf die Routine auf, die du schon geschrieben hast.

```sather
STAGE_DIRECTIONS::final_cue
-- => "The curtain falls."
```
