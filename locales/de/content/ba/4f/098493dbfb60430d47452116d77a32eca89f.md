# Einführung

In Python verwendest du [`if`][if statement]-, `elif`- (_eine Kurzform von „else and if“_) und `else`-Anweisungen, um den [Ablauf der Ausführung zu steuern][control flow tools] und in einem Programm Entscheidungen zu treffen.
Anders als viele andere Programmiersprachen bieten Python-Versionen 3.9 und älter keine formale case-switch-Anweisung. Stattdessen verwendest du mehrere `elif`-Anweisungen, um einen ähnlichen Zweck zu erfüllen.

Python 3.10 führt eine Variante der case-switch-Anweisung ein, die `pattern matching` heißt und in einem anderen Konzept gesondert behandelt wird.

Bedingte Anweisungen verwenden Ausdrücke, die sich zu `True` oder `False` auflösen müssen: entweder indem sie direkt einen `bool` zurückgeben oder indem sie [„truthy“ oder „falsy“][truth value testing] auswerten.


```python
x = 10
y = 5

# The comparison '>' returns the bool 'True',
# so the statement is printed.
if x > y:
    print("x is greater than y")
...
>>> x is greater than y
```

Zusammen mit `if` wird ein optionaler `else`-Block ausgeführt, wenn die ursprüngliche `if`-Bedingung zu `False` ausgewertet wird:

```python
x = 5
y = 10

# The comparison '>' here returns the bool False,
# so the 'else' block is executed instead of the 'if' block.
if x > y:
    print("x is greater than y")
else:
    print("y is greater than x")
...
>>> y is greater than x
```

`elif` ermöglicht mehrere Auswertungen bzw. Verzweigungen.

```python
x = 5
y = 10
z = 20

# The elif statement allows for the checking of more conditions.
if x > y > z:
    print("x is greater than y and z")
elif y > x > z:
    print("y is greater than x and z")
else:
    print("z is greater than x and y")
...
>>> z is greater than x and y
```

[Boolesche Operationen][boolean operations] und [Vergleiche][comparisons] lassen sich mit Bedingungen kombinieren, um komplexere Tests durchzuführen:

```python
>>> def classic_fizzbuzz(number):
...     if number % 3 == 0 and number % 5 == 0:
...         say = 'FizzBuzz!'
...     elif number % 5 == 0:
...         say = 'Buzz!'
...     elif number % 3 == 0:
...         say = 'Fizz!'
...     else:
...         say = str(number)
...     return say

>>> classic_fizzbuzz(15)
'FizzBuzz!'

>>> classic_fizzbuzz(13)
'13'
```
