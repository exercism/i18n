# Einführung

## Der Pipe-Operator

Der Operator `|>` heißt Pipe-Operator. Mit ihm kannst du Funktionsaufrufe so aneinanderreihen, dass der Rückgabewert des vorherigen Aufrufs an den nächsten Aufruf übergeben wird.

```gleam
"hello"
|> string.uppercase
|> string.append("?!")
// -> "HELLO?!"
```

Der Code oben ist äquivalent zu folgendem:

```gleam
string.append(string.uppercase("hello"), "?!")
```

Der Pipe-Operator übergibt den Wert entweder als erstes Argument an den Funktionsaufruf oder als einziges Argument an einen neuen Aufruf, je nachdem, welche Variante den passenden Typ ergibt.

```gleam
100
|> function_that_takes_two_arguments(1)

// Is equivalent to
function_that_takes_two_arguments(100, 1)
```

```gleam
100
|> function_that_returns_a_function(1)

// Is equivalent to
function_that_returns_a_function(1)(100)
```

Manchmal möchten wir den Wert an einer anderen Position einsetzen. In diesem Fall kannst du den Platzhalter `_` verwenden, um anzugeben, wo der Wert eingefügt werden soll.

```gleam
100
|> some_function(1, _, 2)
```
