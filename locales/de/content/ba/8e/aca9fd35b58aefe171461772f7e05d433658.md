# Tests ausführen

Um die Tests für eine bestimmte Übung auszuführen, wechsle mit `cd` in den Ordner und führe Folgendes aus:

```bash 
box task run TestRunner
# Or start up a test watcher that will rerun when files change
box task run TestRunner --:watcher
```

Die Tests verwenden eine Bibliothek namens TestBox, die sowohl xUnit- als auch BDD-Tests unterstützt. Alle Testsuiten sind im [BDD-Stil](https://testbox.ortusbooks.com/content/primers/bdd/specs.html) geschrieben, der Closures verwendet, um Testspezifikationen zu definieren. Du musst dir keine Gedanken über die Installation von TestBox machen. Der Test-Runner auf der Kommandozeile übernimmt das für dich. Du musst nur beim ersten Ausführen mit dem Internet verbunden sein. Mehr dazu erfährst du hier:

[https://testbox.ortusbooks.com](https://testbox.ortusbooks.com)
