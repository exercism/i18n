# Einführung

Viele Sprachen haben eine Möglichkeit wie `null` oder `none`, um einen nicht existierenden Wert anzugeben. Da R dafür ausgelegt ist, große Mengen (oft unordentlicher) Daten zu verarbeiten, gibt es mehrere Formen des Nichts.

Das übergeordnete Ziel ist, fehlende oder verdächtige Werte zu kennzeichnen, sobald sie auftreten, und dann fortzufahren, ohne eine Ausnahme auszulösen.

## NULL

Wenn ein Wert wirklich nicht existiert, wird er durch `NULL` dargestellt. Das kommt wahrscheinlich dem am nächsten, was C oder Python tun würden.

```R
v <- c() # zero-length vector
v
#> NULL
is.null(v)
#> [1] TRUE
```

In vielen Kontexten werden Werte von `NULL` einfach ignoriert:

```R
c(2, 3, NULL, 5)
#> [1] 2 3 5
```

## NA

Für Situationen, in denen ein Wert existiert, dessen Inhalt wir aber nicht kennen, wird `NA` verwendet. Wenn beispielsweise Fahrzeuge auf einer Straße gezählt werden, können menschliche Beobachter krank werden oder automatische Sensoren ausfallen, aber der Verkehr fließt weiter.

```R
v <- c(1, 2, NA, 4, 5)
v
#> [1]  1  2 NA 4  5
is.na(v) # test for data gaps
#> [1] FALSE FALSE  TRUE FALSE FALSE
```

Somit ist `NA` ein Platzhalter, der Menschen warnt, dass sie entscheiden müssen, wie sie damit umgehen.

## Leere Vektoren

Vielleicht überraschend: R hat keine Standardmethode, um zu prüfen, ob etwas leer ist, obwohl einige Pakete von Drittanbietern eigene Funktionen wie `is.empty()` implementieren.

Nicht einmal das Erzeugen eines leeren Vektors ist ganz offensichtlich.
Wir haben in einem früheren Abschnitt gesehen, dass `c()` ohne Argumente `NULL` zurückgibt, keinen Vektor.

```R
is.vector(c())
#> [1] FALSE
```

Funktionen wie `logical()` oder `integer()` nehmen ein Argument, das die gewünschte Länge angibt, die null sein kann.

```R
z <- logical(0)
is.vector(z)
#> [1] TRUE
length(z)
#> [1] 0
```

Wir können auch einen Vektor erzeugen und dann jedes Element entfernen, wie im [Vektoren-Konzept][concept-vectors] beschrieben. Das ergibt einen Vektor der Länge 0 mit einem passenden Typ.

```R
v <- 5
v[-1]  # delete the first element
#> numeric(0)
```
