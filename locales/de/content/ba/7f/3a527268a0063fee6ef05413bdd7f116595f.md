# Einführung

## Klassen

Das zentrale objektorientierte Konstrukt in C# ist die _Klasse_, eine Kombination aus Daten (_Feldern_) und Verhalten (_Methoden_). Die Felder und Methoden einer Klasse nennt man ihre _Member_.

Der Zugriff auf Member kann über Zugriffsmodifizierer eingeschränkt werden. Die beiden gebräuchlichsten sind:

- `public`: Auf das Member kann jeder Code zugreifen (keine Einschränkungen).
- `private`: Auf das Member kann nur Code in derselben Klasse zugreifen.

Du kannst dir eine Klasse als Vorlage für das Erstellen von Instanzen dieser Klasse vorstellen. Um eine Instanz einer Klasse zu erstellen (auch bekannt als _Objekt_), verwendet man das Schlüsselwort `new`:

```csharp
class Car
{
}

// Create two car instances
var myCar = new Car();
var yourCar = new Car();
```

Felder haben einen Typ und können an jeder Stelle in einer Klasse definiert werden.
Öffentliche Felder werden in PascalCase definiert, private Felder in camelCase und mit einem vorangestellten Unterstrich `_`:

```csharp
class Car
{
    // Accessible by anyone
    public int Weight;

    // Only accessible by code in this class
    private string _color;
}
```

Optional kannst du einem Feld einen Anfangswert zuweisen. Wenn ein Feld _keinen_ Anfangswert angibt, wird es auf den Standardwert seines Typs gesetzt. Auf die Feldwerte einer Instanz kannst du mit der Punktnotation zugreifen und sie ändern.

```csharp
class Car
{
    // Will be set to specified value
    public int Weight = 2500;

    // Will be set to default value (0)
    public int Year;
}

var newCar = new Car();
newCar.Weight; // => 2500
newCar.Year;   // => 0

// Update value of the field
newCar.Year = 2018;
```

Private Felder werden üblicherweise als Seiteneffekt eines Methodenaufrufs aktualisiert. Solche Methoden geben meistens keinen Wert zurück; in diesem Fall sollte der Rückgabetyp `void` sein:

```csharp
class CarImporter
{
    private int _carsImported;

    public void ImportCars(int numberOfCars)
    {
        // Update private field from public method
        _carsImported = _carsImported + numberOfCars;
    }
}
```
