# Debug

Wenn ein Test fehlschlägt, wird eine Meldung angezeigt, die beschreibt, was schiefgelaufen ist.
Wenn du zusätzliche Ausgaben möchtest, kannst du die Subroutine `::YYY()` um den Code herum verwenden, den du untersuchen willst.
(`::` ist eine Kurzform für `main::`.)
Diese Subroutine ist Teil des Moduls [XXX][XXX].

Du kannst auch einfach mit der Funktion `say` eine Meldung ausgeben, z. B. `say 'Hello, World!';`.

Der Online-Testrunner verwendet das [Test Anything Protocol][TAP].
Aufgrund der Natur von TAP wird von der Verwendung von `print` im Online-Testrunner dringend abgeraten.
