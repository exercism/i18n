# Einführung

In Python ist ein [Tupel][tuple] eine _unveränderliche_ Sammlung von Elementen in einer _festen Reihenfolge_.
Wie die meisten Sammlungen können `tuples` jeden Datentyp (oder auch mehrere) enthalten, einschließlich anderer `tuples`.
Tupel unterstützen alle [gemeinsamen Sequenzoperationen][common sequence operations], aber **keine** [Operationen auf veränderlichen Sequenzen][mutable sequence operations].
Die Elemente eines Tupels kannst du mit dem Konstrukt `for item in <tuple>` durchlaufen.
Wenn du sowohl den Index als auch den Wert eines Elements brauchst, kannst du `for index, item in enumerate(<tuple>)` verwenden.
Wie bei jeder Sequenz kannst du auf die Elemente eines Tupels über die _Notation mit eckigen Klammern_ zugreifen, mit einem `0-based index` von links oder einem `-1-based index` von rechts.

[common sequence operations]: https://docs.python.org/3/library/stdtypes.html#common-sequence-operations
[mutable sequence operations]: https://docs.python.org/3/library/stdtypes.html#mutable-sequence-types
[tuple]: https://docs.python.org/3/library/stdtypes.html#tuple
