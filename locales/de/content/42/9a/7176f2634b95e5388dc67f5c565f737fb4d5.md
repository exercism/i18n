# Überblick

Eine Gleitkommazahl ist eine Zahl mit null oder mehr Stellen hinter dem Dezimaltrennzeichen. Beispiele sind `-2.4`, `0.1`, `3.14`, `5.`, `16.984025` und `1024.0`.

Verschiedene Gleitkommatypen können unterschiedlich viele Stellen hinter dem Trennzeichen speichern. Das nennt man ihre Genauigkeit.

Go hat zwei Gleitkommatypen:

- `float32`: 32 Bit (~6-9 Stellen Genauigkeit).
- `float64`: 64 Bit (~15-17 Stellen Genauigkeit).
   Das ist der Standard-Gleitkommatyp.

Wie du siehst, können beide Typen unterschiedlich viele Stellen speichern.
Das bedeutet, wenn du PI in einem `float32` speicherst, werden nur die ersten 6 bis 9 Stellen gespeichert (wobei die letzte Stelle gerundet wird).

Standardmäßig verwendet Go `float64` für Gleitkommazahlen, es sei denn, die Gleitkommazahl wird:

1. einer Variablen mit dem Typ `float32` zugewiesen, oder
2. von einer Funktion mit dem Rückgabetyp `float32` zurückgegeben, oder
3. als Argument an die Funktion `float32()` übergeben.

Das [`math`-Paket] enthält viele hilfreiche mathematische Funktionen.

Sei immer vorsichtig, wenn du Gleitkommawerte auf Gleichheit prüfst, denn Werte, die gleich aussehen, können tatsächlich unterschiedlich sein.

Eine kurze Einführung in Gleitkommazahlen findest du auf [0.30000000000000004.com].
Die [Float Toy-Seite] bietet eine schöne, grafische Erklärung, wie die Bits einer Gleitkommazahl in einen tatsächlichen Gleitkommawert umgewandelt werden.
