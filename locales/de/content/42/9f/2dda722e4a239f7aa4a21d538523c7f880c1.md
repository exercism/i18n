# Ergänzung zu den Anweisungen

## Register

| Register | Verwendung | Typ             | Beschreibung                                              |
| -------- | ---------- | --------------- | --------------------------------------------------------- |
| `$a0`    | Eingabe    | Ganzzahl        | Zahl                                                      |
| `$v0`    | Ausgabe    | boolescher Wert | Gibt an, ob die Zahl eine Armstrong-Zahl ist (`0` = `false`, `1` = `true`) |
| `$t0-9`  | temporär   | beliebig        | wird für die temporäre Speicherung verwendet              |
