# Tests

Jede Übung stellt die Unit-Tests und ein Make-Build-Rezept bereit.
Du stellst die Implementierung bereit.

Jede Testdatei soll gegen deine Implementierung gelinkt werden, sodass ein ausführbares Konsolenprogramm entsteht, das die Tests ausführt.
Das Ausführen des Testprogramms gibt Meldungen für jeden fehlgeschlagenen Test aus und meldet einen Exit-Status ungleich null, wenn Tests fehlschlagen.

So arbeitest du eine Übung durch:
* Erstelle den ersten Build mit Make
* Für jeden Unit-Test:
  * Entferne die Zeile `TEST_IGNORE()`.
  * Beseitige alle Kompilierfehler, damit der Test fehlschlägt.
  * Implementiere gerade so viel, dass der Test bestanden wird.
  * Refaktoriere deine Implementierung, um die Lesbarkeit zu verbessern, Duplikate zu reduzieren usw.
