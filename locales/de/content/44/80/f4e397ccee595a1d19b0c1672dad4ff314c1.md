# Installation

Wie du alles auf deinem System einrichtest, erfährst du unter [System/Installation][install-link].

~~~exercism/caution
Wenn du das Java Development Kit (JDK) installiert hast, kann das ausführbare Programm `jconsole` möglicherweise mit der Java Console in Konflikt geraten, die denselben Namen verwendet.

Mögliche Lösungen sind:

- Benenne das ausführbare Programm `jconsole` der Programmiersprache J in etwas Eindeutiges um (z. B. `jconsole-jlang`).

- Passe die Umgebungsvariablen oder den PATH deines Systems an, damit `jconsole` der Programmiersprache J bevorzugt wird.

- **Für Linux-Nutzer**: Es gibt ein Bash-Skript unter `bin/install.sh`, das einen **symbolischen Link** namens `ijconsole` im Verzeichnis `/usr/` erstellt. Du kannst diesen Link verwenden, indem du `ijconsole` in deinem Terminal eingibst.
~~~

Sobald J installiert ist, öffnest du eine J-Konsole in deinem Terminal und gibst die folgenden Befehle ein, um das Unit-Test-Framework zu installieren:

```j
  load 'pacman'
  'update' jpkg ''
  'install' jpkg 'general/unittest'
  exit 0
```
