# Über

Elixir verwendet [_Behaviours_][behaviours], um gemeinsame generische Schnittstellen bereitzustellen und gleichzeitig spezifische Implementierungen für jedes Modul zu ermöglichen, das das Behaviour implementiert. Eines dieser Behaviours ist das _Access Behaviour_.

Das _Access Behaviour_ bietet eine gemeinsame Schnittstelle, um schlüsselbasierte Daten aus einer Datenstruktur abzurufen. Es ist für Maps und Keyword-Listen implementiert.

Das Modul [`Access`][access] definiert die für die Schnittstelle erforderlichen Callbacks. Die Module [`Map`][map] und [`Keyword`][keyword] implementieren dann die erforderlichen Callbacks [`fetch/2`][map-fetch], [`get_and_update/3`][map-get-and-update] und [`pop/2`][map-pop]

Um das Behaviour zu verwenden, hängst du an eine gebundene Variable _eckige Klammern_ an und rufst dann über den Schlüssel den Wert ab, der diesem Schlüssel zugeordnet ist. Maps unterstützen Schlüssel jeden Typs, Keyword-Listen hingegen nur Atom-Schlüssel.

```elixir
# Atom as key
my_map = %{key: "my value"}
my_map[:key]
# => "my value"

# String as key
another_map = %{"key" => "my value"}
another_map["key"]
# => "my value"
```

Wenn der Schlüssel nicht in der Datenstruktur existiert, wird `nil` zurückgegeben. Das kann zu unbeabsichtigtem Verhalten führen, weil kein Fehler ausgelöst wird.

```elixir
my_map = %{key: "my value"}
my_map[:wrong_key][:other_wrong_key]
# => nil
```

Beachte, dass `nil` selbst das Access Behaviour implementiert und für jeden Schlüssel immer `nil` zurückgibt.

```elixir
nil[:key]
# => nil
```

Structs implementieren das Access Behaviour nicht.
