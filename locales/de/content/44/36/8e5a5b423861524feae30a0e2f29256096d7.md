# Anleitung

In dieser Übung arbeitest du an einem Terminplaner für einen Schönheitssalon in New York, der am 15. September 2012 eröffnet hat.

Du hast fünf Aufgaben, bei denen es jeweils um Termindaten geht.
Die Uhrzeiten sind im 24-Stunden-Format angegeben (kein AM/PM).
Damit Zeitzonenprobleme so einfach wie möglich bleiben, geh davon aus, dass alles UTC verwendet.

## 1. Terminangabe im rein numerischen Format parsen

Implementiere die Funktion `schedule_appointment()`, um eine textuelle Darstellung eines Termins in das entsprechende `DateTime`-Format zu parsen.

Beachte, dass die Eingabe im US-Format Monat/Tag/Jahr vorliegt.

```julia-repl
julia> schedule_appointment("07/25/2023 13:45:00")
2023-07-25T13:45:00
```

## 2. Prüfen, ob ein Termin bereits vorbei ist

Implementiere die Funktion `has_passed()`, die einen Termin entgegennimmt und prüft, ob der Termin irgendwann in der Vergangenheit lag:

```julia-repl
julia> has_passed(DateTime(1999, 12, 31, 9, 0, 0))
true
```

## 3. Prüfen, ob ein Termin am Nachmittag liegt

Implementiere die Funktion `is_afternoon_appointment()`, die einen Termin entgegennimmt und prüft, ob er am Nachmittag liegt (>= 12:00 und < 18:00):

```julia-repl
julia> is_afternoon_appointment(DateTime(2023, 3, 29, 15, 0, 0))
true
```

## 4. Den Wochentag eines Termins prüfen

Implementiere die Funktion `day_of_week()`, die den _numerischen_ Wochentag zurückgibt.
Der Salon ist sonntags geschlossen, daher ist Montag Tag 1 und Samstag Tag 6.

```R
# a Friday
day_of_week(make_datetime(2026, 06, 05, 12, 30, 00))
#> [1] 5
```

## 5. Einen Termin verschieben

Wenn ein Kunde einen Termin verschieben muss, wird er automatisch auf den nächsten Freitag zur gleichen Uhrzeit gelegt (denn das ist der langsamste Tag der Woche).

Implementiere die Funktion `reschedule()`, die den ursprünglichen Termin (als String im Format Monat/Tag/Jahr) entgegennimmt und einen verschobenen Termin zurückgibt.

```R
# a Saturday
reschedule("06/13/2026 12:30:00")
#> [1] "2026-06-19 12:30:00 UTC"
```

Wenn der ursprüngliche Termin auf Montag bis Donnerstag fiel, verschiebe ihn auf Freitag _dieser_ Woche.
Bei Terminen am Freitag oder Samstag verschiebst du ihn auf Freitag der _nächsten_ Woche.
