# Einführung

Du erstellst eine Instanz einer Klasse, indem du ihren [_Konstruktor_][constructor] mit dem `new`-Operator aufrufst. Ein Konstruktor ist eine spezielle Methode innerhalb einer Klasse, deren Ziel es ist, die Klasse zu initialisieren. In Haxe heißt die Konstruktormethode `new()`.

```haxe
class Library {
  private var books:Int;

  public function new() {
    this.books = 10; // Initialize the books field
  }
}

var library = new Library(); // This calls the constructor
```

Genau wie normale Methoden können Konstruktoren Parameter haben. Diese Parameter werden (normalerweise) in privaten Feldern gespeichert, auf die später zugegriffen wird.

```haxe
class Building {
  private var numberOfStories:Int;
  private var totalHeight: Float;

  public function new(numberOfStories:Int, storyHeight:Float) {
    this.numberOfStories = numberOfStories;
    this.totalHeight = storyHeight * numberOfStories;
  }
}

var largeBuilding = new Building(55, 6.2);
```

Du **kannst** keine neue Instanz einer Klasse erstellen, wenn sie keinen Konstruktor hat. Ein leerer Konstruktor ist also die einzige Möglichkeit.

```haxe
class Car {
  public var weight:Int = 1000;

  public function new() {}
}

var myCar = new Car();
```
