# Einführung

Boolesche Werte werden in Go durch den vordeklarierten booleschen Typ `bool` dargestellt, dessen Werte entweder `true` oder `false` sein können.
Es ist ein definierter Typ.

```go
var closed bool    // boolean variable 'closed' implicitly initialized with 'false'
speeding := true   // boolean variable 'speeding' initialized with 'true'
hasError := false  // boolean variable 'hasError' initialized with 'false' 
```

Go unterstützt drei logische Operatoren, die Ausdrücke zu booleschen Werten auswerten können und entweder `true` oder `false` zurückgeben.

| Operator    | Was er bedeutet                                    |
| ----------- | -------------------------------------------------- |
| `&&` (und)  | Er ist wahr, wenn beide Aussagen wahr sind.        |
| `\|\|` (oder) | Er ist wahr, wenn mindestens eine Aussage wahr ist. |
| `!` (nicht) | Er ist nur wahr, wenn die Aussage falsch ist.      |
