# Anleitung

Übersetze RNA-Sequenzen in Proteine.

RNA kann in Sequenzen aus drei Nukleotiden, sogenannte Codons, zerlegt und dann wie folgt in ein Protein übersetzt werden:

RNA: `"AUGUUUUCU"` => wird übersetzt zu

Codons: `"AUG", "UUU", "UCU"`
=> die dann ein Protein mit der folgenden Sequenz ergeben =>

Protein: `"Methionine", "Phenylalanine", "Serine"`

Es gibt 64 Codons, die wiederum 20 Aminosäuren entsprechen; allerdings sind nicht alle Codonsequenzen und die daraus entstehenden Aminosäuren für diese Übung wichtig.
Wenn es für ein Codon funktioniert, sollte das Programm für alle funktionieren.
Du kannst die Liste in der Testsuite aber gerne erweitern, um alle aufzunehmen.

Es gibt außerdem drei terminierende Codons (auch als „STOP“-Codons bekannt); wenn eines dieser Codons (vom Ribosom) erreicht wird, endet die Translation und das Protein wird abgebrochen.

Alle darauffolgenden Codons werden ignoriert, wie hier:

RNA: `"AUGUUUUCUUAAAUG"` =>

Codons: `"AUG", "UUU", "UCU", "UAA", "AUG"` =>

Protein: `"Methionine", "Phenylalanine", "Serine"`

Beachte, dass das Stop-Codon `"UAA"` die Translation beendet und das letzte Methionin nicht in die Proteinsequenz übersetzt wird.

Nachfolgend sind die Codons und die daraus resultierenden Aminosäuren aufgeführt, die für die Übung benötigt werden.

| Codon              | Aminosäure    |
| :----------------- | :------------ |
| AUG                | Methionine    |
| UUU, UUC           | Phenylalanine |
| UUA, UUG           | Leucine       |
| UCU, UCC, UCA, UCG | Serine        |
| UAU, UAC           | Tyrosine      |
| UGU, UGC           | Cysteine      |
| UGG                | Tryptophan    |
| UAA, UAG, UGA      | STOP          |
