# Einführung

Ein Typ ist ein _generischer Typ_, wenn er mit einem _Typparameter_ Werte jedes beliebigen Typs enthalten kann.

Zum Beispiel hat dieser Typ `Box` den Typparameter `a` (mit Kleinbuchstaben geschrieben).

```gleam
pub type Box(a) {
  Box(a)
}
```

Der Typparameter `a` ist ein Platzhalter für jeden Typ, also kann `Box` mit Strings, Ganzzahlen oder jedem anderen Typ verwendet werden.

```gleam
Box("Hello, Joe!") // The type is Box(String)

Box(42) // The type is Box(Int)
```

Ein Typ kann mehrere Typparameter haben, indem du sie mit Kommas trennst.

```gleam
pub type Pair(a, b) {
  Pair(a, b)
}
```

## Generische Funktionen

Typparameter können auch in den Argumenten von Funktionen verwendet werden.

Diese Funktion nimmt einen Wert vom Typ `a` und ruft zweimal eine Funktion auf, die ein `a` nimmt und ein `b` zurückgibt.

```gleam
pub fn twice(value: a, f: fn(a) -> b) -> b {
  f(value)
  f(value)
}
```
```gleam
// The type is fn(String, fn(String) -> Nil) -> Nil
twice("Hello, Joe!", io.println)
```
