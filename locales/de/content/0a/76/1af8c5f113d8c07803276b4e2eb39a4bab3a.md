# Reihenfolge von Funktionsannotationen

Üblicherweise stehen `@doc`-Funktionsannotationen vor `@spec`-Funktionsannotationen, und `@spec`-Funktionsannotationen stehen direkt vor der Funktion. Wenn die Funktion mehrere Klauseln hat, stehen die Funktionsannotationen vor der ersten Klausel.

Beispiel:

```elixir
@doc """
This function counts the number elements in a list
"""
@spec count(list(any())) :: integer()
def count([]), do: 0
def count([h | t]), do: 1 + count(t)
```
