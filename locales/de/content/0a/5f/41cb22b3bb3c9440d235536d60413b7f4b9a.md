Das Ziel dieser Übung ist es, die Übung Passwortprüfer zu verbessern.
Da ein gegebenes Passwort wahrscheinlich gegen mehr als eine Regel gleichzeitig verstößt, sollte ein guter Passwortprüfer dem Nutzer alle verletzten Regeln mitteilen und nicht nur die erste, die ihm zufällig auffällt.
Der verbesserte Passwortprüfer sollte alle Regeln, gegen die ein gegebenes Passwort verstößt, auf einmal anzeigen.

Für diesen Passwortprüfer gelten dieselben Regeln wie in der vorherigen Übung Passwortprüfer:

- Muss mindestens 12 Zeichen haben
- Muss mindestens einen Großbuchstaben enthalten
- Muss mindestens einen Kleinbuchstaben enthalten
- Muss mindestens eine Ziffer enthalten
- Muss mindestens ein Symbol aus der Menge !@#$%^&\* enthalten

## 1. Ändere die diskriminierte Union `PasswordError`, sodass die einzelnen Werte als Flags behandelt werden können

Beachte, dass die Tests erst kompilieren, wenn dieser wichtige Schritt abgeschlossen ist.

## 2. Implementiere die Funktion `checkPassword`

Die Funktion `checkPassword` prüft das gegebene Passwort anhand der oben genannten Regeln.
Die Funktion sollte einen `Result`-Wert zurückgeben, wobei `Ok` zurückgegeben wird, wenn das Passwort alle Regeln erfüllt, und ein `Error`-Wert, wenn es gegen eine oder mehrere Regeln verstößt.
Wenn das gegebene Passwort gegen mehrere Regeln verstößt, sollte der `PasswordError`-Wert alle verletzten Regeln darstellen.

```fsharp
checkPassword "abcdefghijk5"
// => Error (PasswordError.MissingUppercaseLetter ||| PasswordError.MissingSymbol)
```

## 3. Implementiere die Funktion ``getStatusPhrases`

Die Funktion `getStatusPhrases` gibt eine Menge von Strings zurück, von denen jeder einen menschenlesbaren Ausdruck enthält, der einem der Fehler im Ergebnis von `checkPassword` entspricht.

```fsharp
getStatusPhrases (Error PasswordError.MissingDigit ||| PasswordError.LessThan12Characters)
// => List ["12 characters"; "digit"]
```
