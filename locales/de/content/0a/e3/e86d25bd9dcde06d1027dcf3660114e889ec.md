# Anleitung

In dieser Übung implementierst du die Quest-Logik für ein neues RPG, das ein Freund entwickelt. Die Hauptfigur des Spiels ist Annalyn, ein mutiges Mädchen mit einem wilden und treuen Hund. Doch dann kommt es zur Katastrophe: Ihre beste Freundin wurde entführt, während sie im Wald nach Beeren suchte. Annalyn wird versuchen, ihre beste Freundin zu finden und zu befreien, und dabei möglicherweise ihren Hund mit auf diese Quest zu nehmen.

Nachdem sie eine Zeit lang der Spur ihrer besten Freundin gefolgt ist, findet sie das Lager, in dem ihre beste Freundin gefangen gehalten wird. Es stellt sich heraus, dass es zwei Entführer gibt: einen mächtigen Ritter und einen listigen Bogenschützen.

Nachdem sie die Entführer gefunden hat, überlegt Annalyn, welche der folgenden Aktionen sie ausführen kann:

- Schneller Angriff: Ein schneller Angriff ist möglich, wenn der Ritter schläft, denn er braucht Zeit, um seine Rüstung anzulegen, und ist dann verwundbar.
- Spionieren: Die Gruppe kann ausspioniert werden, wenn mindestens einer von ihnen wach ist. Andernfalls ist Spionieren Zeitverschwendung.
- Gefangenen signalisieren: Dem Gefangenen kann mit Vogelstimmen ein Signal gegeben werden, wenn der Gefangene wach ist und der Bogenschütze schläft, denn Bogenschützen sind darin ausgebildet, mit Vogelstimmen zu signalisieren, und könnten die Nachricht abfangen.
- _Gefangenen befreien_: Annalyn kann versuchen, sich ins Lager zu schleichen, um den Gefangenen zu befreien.
  Das ist riskant und kann nur auf eine von zwei Arten gelingen:
  - Wenn Annalyn ihren Hund dabei hat, kann sie den Gefangenen befreien, wenn der Bogenschütze schläft.
    Der Ritter hat Angst vor dem Hund, und der Bogenschütze hat keine Zeit, sich vorzubereiten, bevor Annalyn und der Gefangene entkommen können.
  - Wenn Annalyn ihren Hund nicht dabei hat, müssen sie und der Gefangene sehr vorsichtig sein!
    Annalyn kann den Gefangenen befreien, wenn der Gefangene wach ist und der Ritter und der Bogenschütze beide schlafen. Wenn der Gefangene jedoch schläft, kann er nicht befreit werden: Der Gefangene würde durch Annalyns plötzliches Auftauchen erschrecken und den Ritter und den Bogenschützen aufwecken.

Du hast vier Aufgaben: die Logik zu implementieren, mit der du bestimmst, ob die oben genannten Aktionen verfügbar sind, basierend auf dem Zustand der drei Figuren im Wald und darauf, ob Annalyns Hund dabei ist oder nicht.

## 1. Prüfe, ob die Aktion „Schneller Angriff“ möglich ist

Implementiere eine Funktion namens `canExecuteFastAttack`, die einen booleschen Wert entgegennimmt, der angibt, ob der Ritter wach ist. Diese Funktion gibt `true` zurück, wenn die Aktion „Schneller Angriff“ basierend auf dem Zustand der Figur verfügbar ist. Andernfalls gibt sie `false` zurück:

```purescript
knightIsAwake :: Boolean
knightIsAwake = true

canExecuteFastAttack knightIsAwake
-- => false
```

## 2. Prüfe, ob die Aktion „Spionieren“ möglich ist

Implementiere eine Funktion namens `canSpy`, die drei boolesche Werte entgegennimmt, die angeben, ob der Ritter, der Bogenschütze bzw. der Gefangene wach sind. Die Funktion gibt `true` zurück, wenn die Aktion „Spionieren“ basierend auf dem Zustand der Figuren verfügbar ist. Andernfalls gibt sie `false` zurück:

```purescript
knightIsAwake :: Boolean
knightIsAwake = true

archerIsAwake :: Boolean
archerIsAwake = true

prisonerIsAwake :: Boolean
prisonerIsAwake = true

canSpy knightIsAwake archerIsAwake prisonerIsAwake
-- => true
```

## 3. Prüfe, ob die Aktion „Gefangenen signalisieren“ möglich ist

Implementiere eine Funktion namens `canSignalPrisoner`, die zwei boolesche Werte entgegennimmt, die angeben, ob der Bogenschütze bzw. der Gefangene wach sind. Die Funktion gibt `true` zurück, wenn die Aktion „Gefangenen signalisieren“ basierend auf dem Zustand der Figuren verfügbar ist. Andernfalls gibt sie `false` zurück:

```purescript
archerIsAwake :: Boolean
archerIsAwake = false

prisonerIsAwake :: Boolean
prisonerIsAwake = true

canSignalPrisoner archerIsAwake prisonerIsAwake -- => true
```

## 4. Prüfe, ob die Aktion „Gefangenen befreien“ möglich ist

Implementiere eine Funktion namens `canFreePrisoner`, die vier boolesche Werte entgegennimmt. Die ersten drei Parameter geben an, ob der Ritter, der Bogenschütze bzw. der Gefangene wach sind. Der letzte Parameter gibt an, ob Annalyns Hund anwesend ist. Die Funktion gibt `true` zurück, wenn die Aktion „Gefangenen befreien“ basierend auf dem Zustand der Figuren und der Anwesenheit von Annalyns Hund verfügbar ist. Andernfalls gibt sie `false` zurück:

```purescript
knightIsAwake :: Boolean
knightIsAwake = true

archerIsAwake :: Boolean
archerIsAwake = false

prisonerIsAwake :: Boolean
prisonerIsAwake = true

petDogIsPresent :: Boolean
petDogIsPresent = true

canFreePrisoner knightIsAwake archerIsAwake prisonerIsAwake petDogIsPresent
-- => false
```
