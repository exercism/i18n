# Anweisungen

Bestimme, ob ein Dreieck _equilateral_, _isosceles_ oder _scalene_ ist.

Ein Dreieck ist _equilateral_, wenn alle drei Seiten gleich lang sind.

Ein Dreieck ist _isosceles_, wenn mindestens zwei Seiten gleich lang sind. (Manchmal wird es als genau zwei gleich lange Seiten definiert, aber für diese Übung sagen wir mindestens zwei.)

Ein Dreieck ist _scalene_, wenn alle Seiten unterschiedlich lang sind.

## Hinweis

Damit eine Form überhaupt ein Dreieck sein kann, müssen alle Seiten eine Länge von mehr als 0 haben, und die Summe der Längen zweier beliebiger Seiten muss größer oder gleich der Länge der dritten Seite sein. Siehe [Dreiecksungleichung](https://en.wikipedia.org/wiki/Triangle_inequality).

## Dig Deeper

Der Fall, in dem die Summe der Längen zweier Seiten _gleich_ der Länge der dritten Seite ist, wird als _entartetes_ Dreieck bezeichnet. Es hat den Flächeninhalt null und sieht wie eine einzelne Linie aus. Du kannst gerne eigenen Code oder eigene Tests hinzufügen, um entartete Dreiecke zu überprüfen.
