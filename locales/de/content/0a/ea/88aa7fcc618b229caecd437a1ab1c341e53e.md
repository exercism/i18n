# Anleitung

Du machst deine Ausbildung in einer kleinen Möbelwerkstatt. Das Tablet des Tischlermeisters läuft mit Factor und führt die Zuschnittliste. Jedes Brett, das auf der Werkbank landet, wird vor dem ersten Schnitt mit ein paar abgeleiteten Werten durchgerechnet.

Der vorherige Auszubildende hat den bisherigen Code in einem Dschungel aus `dup`, `over`, `swap` und `rot` hinterlassen. Deine Aufgabe ist es, fünf kleine Wörter mithilfe von *Kombinatoren* neu zu schreiben.

Jedes Brett kommt nur mit seiner Rohlänge (cm) auf dem Stack in den Workflow.

## 1. Addiere die Schnittfugenzugabe

Sägeblätter entfernen bei jedem Schnitt einen dünnen Streifen Holz: die *Schnittfuge*. Die Werkstatt kalkuliert bei jedem Brett 2 % zusätzliche Länge ein, um das aufzufangen.

Definiere `with-kerf` so, dass es eine Länge entgegennimmt und die Länge zuzüglich einer Schnittfugenzugabe von 2 % zurückgibt.

```factor
100 with-kerf .
! => 102
```

## 2. Berechne die Schnittfugen- und Oberflächenzugaben

Nach dem Sägen folgt die Oberflächenbehandlung, also Schleifen und Hobeln, bei der weitere 5 % der ursprünglichen Länge abgetragen werden.

Definiere `kerf-and-finish` so, dass es *beide* Zugaben nebeneinander zurückgibt (Schnittfugenzugabe unten, Oberflächenzugabe oben).

```factor
100 kerf-and-finish .s
! => 2
! => 5
```

## 3. Erstelle die Zuschnittkarte

Auf jedes Brett, das der Meister zuschneidet, wird eine kleine Karte geklebt, auf der die Rohlänge, die Schnittfugenzugabe und die Oberflächenzugabe stehen: drei Zahlen, und zwar in dieser Reihenfolge.

Definiere `cut-card` so, dass es alle drei zurückgibt.

```factor
100 cut-card .s
! => 100
! => 2
! => 5
```

## 4. Länge pro Stück

Außerdem bekommt die Werkstatt große *Bunde* Holz, die in gleich große Stücke aufgeteilt werden müssen. Die Schnittfugenzugabe wird einmal zur Länge des Bundes addiert, dann wird das Ergebnis durch die Anzahl der Stücke geteilt.

Definiere `per-piece` so, dass es die Länge des Bundes und die Anzahl der Stücke entgegennimmt (die Stückzahl liegt oben auf dem Stack) und die Länge pro Stück zurückgibt.

```factor
100 2 per-piece .
! => 51

100 4 per-piece .
! => 25+1/2
```

## 5. Vergleiche zwei Bunde

Manchmal wählt der Meister beim Holzhändler zwischen zwei Bunden und möchte ihre Schnittfugenzugaben auf einen Blick vergleichen.

Definiere `compare-bolts` so, dass es zwei Längen vom Stack nimmt und die Schnittfugenzugabe für jede zurückgibt (in derselben Reihenfolge).

```factor
50 100 compare-bolts .s
! => 1
! => 2
```
