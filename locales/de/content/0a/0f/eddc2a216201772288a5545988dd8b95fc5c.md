# Verwende keine main-Methode

Versuche, die `main`-Methode aus deinem Code zu entfernen.
Die Tests der Übung setzen keine Lösung mit einer `main`-Methode voraus, und wenn eine vorhanden ist, wird der Code etwas schwerer zu lesen.

Normalerweise fügt man eine `main`-Methode hinzu, um den Code zu debuggen.
Besser ist es jedoch, den Code beim Ausführen von ein oder mehreren Unit-Tests zu debuggen.
Das hat den zusätzlichen Vorteil, dass man sich auf das Debuggen eines bestimmten Testfalls konzentrieren kann.

Hier sind einige Links, die erklären, wie du Java-Code beim Ausführen von Unit-Tests in verschiedenen IDEs debuggen kannst:

- [Java-Tests in Visual Studio Code ausführen und debuggen](https://code.visualstudio.com/docs/java/java-testing#_rundebug-test-cases)
- [Tests in IntelliJ IDEA debuggen](https://www.jetbrains.com/help/idea/performing-tests.html#RedebugFailedTests)
