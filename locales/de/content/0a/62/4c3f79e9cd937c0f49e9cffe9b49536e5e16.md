# Hinweise

## Allgemein

- Der Preis eines Artikels ist das zweite Element seines 2-Arrays. `second`
  aus [`sequences`][sequences] liest ihn.
- Wörter höherer Ordnung wie `filter`, `count`, `sort-by` und `map-sum`
  nehmen alle als zweites Argument eine *Quotation* entgegen, also Code in `[ ]`.

## 1. Sortiere das Inventar nach dem Preis

- `sort-by` (aus [`sorting`][sorting]) nimmt eine Sequenz und eine Quotation
  entgegen, die für jedes Element einen sortierbaren Schlüssel zurückgibt.

## 2. Finde Artikel ohne festgelegten Preis

- Ein fehlender Preis ist `f`. `f` ist außerdem der einzige Wert in Factor, der
  als falsch gilt, deshalb behält `[ second not ] filter` die Artikel, deren
  Preis `f` ist.
- `[ second ] reject` macht dasselbe andersherum.

## 3. Zähle die teuren Artikel

- `count` führt das Prädikat für jedes Element aus und zählt die Treffer.

## 4. Finde den günstigsten Artikel

- `minimum-by` (aus [`sequences`][sequences]) gibt das Element zurück, dessen
  extrahierter Schlüssel am kleinsten ist.

## 5. Summiere alle Preise

- `map-sum` (aus [`sequences`][sequences]) wendet eine Quotation auf die
  Sequenz an und summiert die Ergebnisse.

[sequences]: https://docs.factorcode.org/content/vocab-sequences.html
[sorting]: https://docs.factorcode.org/content/vocab-sorting.html
