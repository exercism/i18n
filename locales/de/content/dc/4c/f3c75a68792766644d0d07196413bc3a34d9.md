# Einführung

Wikipedia beschreibt eine `switch`-Anweisung als „eine Art von Auswahlkontrollmechanismus, mit dem der Wert einer Variable oder eines Ausdrucks den Kontrollfluss eines Programms ändern kann“.

Dieser Mechanismus verwendet die folgenden Schlüsselwörter: `switch`, `case`, `break` und `default`.

In ihrer einfachsten Form prüfen sie einen primitiven Ausdruck oder einen String und treffen anhand seines Werts eine Entscheidung. Zum Beispiel:

```csharp
string direction = GetDirection();
switch (direction)
{
    case "left":
        GoLeft();
        break;
    case "right":
        GoRight();
        break;
    default:
        MarkTime();
        break;
}
```

In ihrer ausgefeiltesten Form führen sie Downcasting mit `case <Type> <variable>:` und Guards (`when`) ein.

```csharp
Animal animal = GetAnimal();

switch (animal)
{
    case Dog canine:
    case Coyote canine:
        canine.Bark();
        break;
    case Cat cat when cat.HasOnly8Lives():
        cat.IsCareful();
        cat.Meow();
        break;
    case Cat cat:
        cat.Meow();
        break;
}
```
