# Einführung

## Generische Typen

Eine Definition einer Sammlung enthält üblicherweise einen Platzhalter in spitzen Klammern, oft `T` nach Konvention. Eine solche Sammlung wird als generischer Typ bezeichnet. Dadurch kann die Person, die die Sammlung verwendet, angeben, welchen Typ von Elementen sie in der Sammlung speichern möchte. Im folgenden Beispielcode instanziieren wir eine Liste von Strings.

## Listen

Listen in C# sind Sammlungen von primitiven Werten oder Instanzen von Strukturen oder Klassen. Sie sind in der Basisklassenbibliothek als `List<T>` implementiert, wobei `T` der Typ des Elements in der Liste ist. Die API stellt eine Vielzahl von Methoden zum Erstellen und Bearbeiten von Listen bereit.

Elemente können zu Listen hinzugefügt und aus ihnen entfernt werden. Listen wachsen und schrumpfen nach Bedarf.

```csharp
var listOfStrings = new List<string>();
```
