# Ergänzung zu den Anweisungen

## Testen

Die Tests führen einige Operationen nebenläufig aus.
Du solltest sicherstellen, dass Operationen auf dem Account diesen in einem konsistenten Zustand hinterlassen.
Zum Beispiel: Mehrere Goroutinen könnten gleichzeitig Geld einzahlen und abheben. Zwei gleichzeitige Abhebungen dürfen das Guthaben nicht ins Negative bringen.

Wenn du lokal arbeitest, kannst du prüfen, ob dein Code Nebenläufigkeit korrekt behandelt und keine Datenrennen erzeugt. Führe die Tests dazu mit aktiviertem `-race`-Flag aus.

```bash
cd exercism/project/directory/go/bank-account
go test -race
```
