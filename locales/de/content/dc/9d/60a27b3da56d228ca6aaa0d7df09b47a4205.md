# Überblick

Wenn eine Funktion viele Argumente entgegennimmt, kann es manchmal schwierig sein, sich die Reihenfolge zu merken, in der sie angegeben werden müssen. Um die Lesbarkeit zu verbessern, erlaubt Gleam, Argumente mit einem Label zu versehen.

Um ein Argument mit einem Label zu versehen, gibst du den Labelnamen vor dem Argumentnamen an, getrennt durch ein Leerzeichen.

```gleam
pub fn replace(
  in string: String,
  each target: String,
  with replacement: String
) -> String {
  // ...
}
```

Beim Aufruf einer Funktion mit gelabelten Argumenten können die Argumente in beliebiger Reihenfolge angegeben werden. Diese Aufrufe von `replace` sind alle gleichwertig:

```gleam
replace(in: "🍔🍔🍔" each: "🍔", with: "🍕")

replace(each: "🍔", in: "🍔🍔🍔", with: "🍕")

replace(with: "🍕", each: "🍔", in: "🍔🍔🍔")
```

Labels sind immer optional. Selbst wenn eine Funktion gelabelte Argumente hat, kann sie weiterhin ohne Labels aufgerufen werden.

```gleam
replace("🍔🍔🍔", "🍔", "🍕")
```

Wenn du eine Funktion mit gelabelten Argumenten definierst, müssen alle Argumente nach dem ersten gelabelten Argument ebenfalls gelabelt sein.

```gleam
// This function is valid
pub fn valid(
  x: Int,
  label1 y: Int,
  label2 z: Int
) -> Int {
  // ...
}

// This function is invalid
pub invalid(
  x: Int,
  label1 y: Int,
  z: Int
) -> Int {
  // ...
}
```
