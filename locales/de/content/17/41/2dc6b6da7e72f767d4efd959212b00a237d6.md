# Anleitung

Du arbeitest an der Umsetzung eines Systems zur Gesundheitsüberwachung. Dazu musst du die Gesundheitsstatistiken der Nutzer verfolgen.

Du startest mit einigen vorgegebenen, noch nicht implementierten Funktionen in einem `impl`-Block sowie der folgenden Struct-Definition:

```rust
pub struct User {
    name: String,
    age: u32,
    weight: f32,
}
```

Dein Ziel ist es, die vorgegebenen Methoden auf dem `User` `struct` zu implementieren, der im `impl`-Block definiert ist.

Zum Beispiel sollte die Methode `new` eine Instanz des `User` `struct` mit den angegebenen Werten für Name, Alter und Gewicht zurückgeben.

```rust
let mut bob = User::new(String::from("Bob"), 32, 155.2);
// Returns: a User with name "Bob", age 32, and weight 155.2
```

Die Methode `weight` sollte das Gewicht des `User` zurückgeben.

```rust
bob.weight();
// Returns: 155.2
```

Die Methode `set_age` sollte das Alter des `User` festlegen.

```rust
bob.set_age(33);
// Updates Bob's age to 33; happy birthday Bob!
```
