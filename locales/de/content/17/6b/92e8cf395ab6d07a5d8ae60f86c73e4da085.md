# Einleitung

Du gründest mit ein paar Freunden und Freunden von Freunden einen geheimen Programmierclub.
Nicht alle kennen sich untereinander, deshalb habt ihr beschlossen, einen geheimen Handschlag zu erfinden, mit dem ihr erkennt, dass jemand dazugehört.
Niemand, der nicht eingeweiht ist, soll den Code knacken können.

Ihr habt den Code so entworfen, dass eine Person eine Zahl zwischen 1 und 31 sagt und die andere daraus eine Reihe von Aktionen macht.
