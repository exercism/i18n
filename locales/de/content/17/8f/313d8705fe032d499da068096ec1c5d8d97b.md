# Einführung

Ein String ist eine Folge von Zeichen und stellt für gewöhnlich Text dar. Strings in Rust sind UTF-8-kodiert, das heißt, sie unterstützen eine Vielzahl von Sprachen und Zeichensätzen, einschließlich Emojis. Strings lassen sich auf verschiedene Weise verbinden, aufteilen und mischen; sie sind ein sehr häufig verwendeter Datentyp.
