# Ergänzungen zu den Anweisungen

## Implementierung

Du darfst Kernfunktionen der Sprache verwenden, um Arrays per Destrukturierung aufzubauen und zu zerlegen, und auch das Array-Literal `[]` ist erlaubt. Funktionen von `Array.prototype` darfst du jedoch nicht verwenden.

Damit deine Lösung getestet werden kann, stelle sicher, dass `forEach` implementiert ist.

```typescript
const list = List.create(1, 2)
list.forEach((item) => console.log(item))
// =>
//    1
//    2
```
