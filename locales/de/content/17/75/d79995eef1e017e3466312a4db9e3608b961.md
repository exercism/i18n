# Einführung

Rekursion ist eine Möglichkeit, Code in einer Funktion zu wiederholen, indem die Funktion sich selbst aufruft.
Man kann sie als eine weitere Art ansehen, eine Schleife zu schreiben bzw. zu iterieren.
Wie beim Schleifen wird ein boolescher Ausdruck oder ein `True`/`False`-Test verwendet, um festzulegen, wann die rekursive Ausführung beendet wird.
_Anders als_ beim Schleifen kann eine Rekursion ohne Abbruch in Python nicht unendlich laufen.
Die Werte, die bei jedem Funktionsaufruf verwendet werden, landen in einem eigenen [Frame][stack-frame] auf dem [Interpreter-Stack][what-is-the-call-stack] von Python.
Wenn die Gesamtzahl der Funktionsaufrufe mehr Platz beansprucht, als der Stack bietet, führt das zu einem Fehler.

```python
def print_increment(step, max_value):
    if step > max_value:
        return
    print(f'The step is {step}')
    print_increment(step + 1, max_value)


def main():
    print_increment(1, 2)
    print("After recursion")

if __name__ == "__main__":
    main()

```

Das gibt Folgendes aus:

```
The step is 1
The step is 2
After recursion
```

Es gibt Situationen, die sich mit Rekursion besser lesbar und/oder leichter nachvollziehbar ausdrücken lassen als mit Schleifen.
