# Anleitung

Du bist der Signalgeber auf einem Küstenpatrouillenboot. Für die heutige Tasche müssen fünf kleine Wörter bereitliegen, bevor die Morgenwache beginnt.

## 1. Einen Wert in seine Quelltextform bringen

Das Logbuch hält jede Beobachtung in der *Factor-Quelltextform* fest, also im selben Text, den der Parser wieder einliest. Definiere `quote-value`, um jeden Wert in seinen Quelltext-String zu verwandeln.

```factor
123 quote-value .   ! => "123"
"hi" quote-value .  ! => "\"hi\""
```

## 2. Den Flaggenrahmen entfernen

Eingehende Signalfahnen kommen mit einem Markierungszeichen an jedem Ende umrahmt an. Definiere `flag-body` so, dass alles *zwischen* den beiden Markierungszeichen zurückgegeben wird: das erste Zeichen weglassen, das letzte Zeichen weglassen.

Gib einen Ausschnitt (eine Sicht) zurück, anstatt zu kopieren.

```factor
"#NS-1024#" flag-body .   ! => "NS-1024"
```

## 3. Eine Flagge aufteilen

Jede Flagge trägt einen kurzen Präfixcode, gefolgt von der Nutzlast. Definiere `split-flag` so, dass sie eine Flagge und eine Header-Länge entgegennimmt und *sowohl* den Header-Ausschnitt als auch den Body-Ausschnitt zurückgibt.

```factor
"NS-1024" 2 split-flag .s
! => "NS"
! => "-1024"
```

## 4. Aus zwei Messwerten triangulieren

Zwei aufeinanderfolgende Signalmesswerte ergeben drei abgeleitete Messgrößen: ihre *Differenz* `a - b`, ihren *Mittelpunkt* `(a + b) / 2` und ihr *Verhältnis* `a / b`. Jede Messgröße verwendet beide Messwerte.

Definiere `triangulate` so, dass sie alle drei aus einem Paar Messwerte zurückgibt.

```factor
100 50 triangulate .s
! => 50
! => 75
! => 2
```

## 5. Drei Messwerte zusammenfassen

Drei aufeinanderfolgende Messwerte werden zu ihrer **Summe**, ihrem **Produkt** und ihrem **Maximum** zusammengefasst. Jede Statistik verwendet alle drei Messwerte.

Definiere `triangle-stats` so, dass sie alle drei zurückgibt.

```factor
5 3 8 triangle-stats .s
! => 16
! => 120
! => 8
```
