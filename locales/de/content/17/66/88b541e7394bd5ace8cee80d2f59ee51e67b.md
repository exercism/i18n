# Über

Methoden können einen Varargs-Parameter haben, mit dem der Aufrufer null oder mehr Argumente angeben kann, als wären es reguläre Parameter. Die Methode erhält diese Argumente in einem einzigen Array.

Um einen Parameter zu einem Varargs-Parameter zu machen, fügst du der Parameterdeklaration das [`params`-Schlüsselwort](https://docs.microsoft.com/en-us/dotnet/csharp/language-reference/keywords/params) hinzu:

```csharp
public static void PrintNumbers(params int[] numbers)
{
    foreach (var number in numbers)
    {
        Console.Write(number)
    }
}

// No values for a varags parameter is allowed
PrintNumbers();

PrintNumbers(1);
// => 1

PrintNumbers(1, 2, 3);
// => 123
```
