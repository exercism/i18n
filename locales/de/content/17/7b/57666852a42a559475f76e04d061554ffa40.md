# Anleitung

Deine Firma wurde beauftragt, CSV-Datensätze aus Benutzereingaben zu erzeugen.

Wir brauchen einen Builder für einen CSV-Datensatz nach dem Standard, der in [RFC 4180](https://tools.ietf.org/html/rfc4180) definiert ist.

Obwohl eine formale Spezifikation existiert, muss deine Firma nur die folgende Funktionalität implementieren:
- einen neuen Datensatz-Builder erstellen
- ein einzelnes Feld zum Datensatz hinzufügen
- den Datensatz mit einfachem Escaping serialisieren

Einfaches Escaping bedeutet:

- Felder, die Zeilenumbrüche, doppelte Anführungszeichen oder Kommas enthalten, sollten in doppelte Anführungszeichen gesetzt werden.

- Wenn doppelte Anführungszeichen verwendet werden, um Felder einzuschließen, dann muss ein doppeltes Anführungszeichen, das in einem Feld vorkommt, escaped werden, indem du ein weiteres doppeltes Anführungszeichen davor setzt.


## 1. Erstelle einen neuen Builder

Du musst die Methode `new` implementieren, um einen neuen Builder zu erstellen.

```rust
let mut builder = CsvRecordBuilder::new();
```

## 2. Füge einzelne Felder zum Datensatz hinzu

Du musst die Methode `add` implementieren, um Felder an deinen Datensatz-Builder anzuhängen.
`add` nimmt unveränderliche String-Slices, `&str`, als Argument.

```rust
builder.add("ant");
builder.add("ba\"t");
builder.add("cat");
```


## 3. Serialisiere den Datensatz mit einfachem Escaping

Du musst die Methode `build` implementieren.
`build` konsumiert den Builder und gibt einen CSV-Datensatz zurück.
```rust
let record = builder.build();
// Note that from now on we cannot use `builder`
assert_eq!(&record, r#"ant,"ba""t",cat"#);
```
