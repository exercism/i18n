# Einführung

Wie die meisten Programmiersprachen hat auch Gleam „Nebenwirkungen“: Funktionen können den Zustand der Welt lesen und verändern und außerdem einen Wert zurückgeben.

Das Modul `gleam/io` aus der Gleam-Standardbibliothek bietet Funktionen, mit denen du Strings auf der Konsole ausgeben kannst.

```gleam
io.println("Hello, Joe!")
// Hello, Joe!
// -> Nil
```

Andere Pakete bieten vielleicht weitere IO-Funktionen, zum Beispiel `simplifile`, ein Paket, das Funktionen zum Lesen und Schreiben von Dateien bereitstellt.

```gleam
simplifile.read("favourite-colour.txt")
// -> Ok("Pink\n")
```
