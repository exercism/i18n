# SQLite-spezifische Anleitung

Die Spalten **list_one** und **list_two** enthalten eine JSON-kodierte Liste von Ganzzahlen.

Beispiel:

```json
[1, 2, 3]
```

## Tabellenschema

```sql
CREATE TABLE sublist (
    list_one TEXT NOT NULL,     -- json array
    list_two TEXT NOT NULL,     -- json array
    result   TEXT
);
```
