# Einführung

In [Cargo Shuffle][cargo-shuffle] hast du den **Datenstapel** von Factor und die Umsortierwörter kennengelernt, die ihn umordnen. Diese Übung baut darauf auf: Du definierst Wörter, die mit ihren Eingabewerten *rechnen*, statt sie nur hin- und herzuschieben.

## Kommentare

Ein `!` beginnt einen Zeilenkommentar. Factor ignoriert alles vom `!` bis zum Zeilenende. Die folgenden Beispiele verwenden `!` sowohl, um zu kommentieren, was der Code tut, als auch, um zu zeigen, was er ausgeben würde.

## Wörter

Ein **Wort** ist Factors Name für eine Funktion. Wenn du ein Wort aufrufst, nimmt es einige Werte vom oberen Ende des Stapels und legt einige Werte wieder zurück.
`.` nimmt den obersten Wert vom Stapel und gibt ihn aus; die Rechenwörter für Ganzzahlen `+`, `-`, `*` nehmen zwei Zahlen und legen das Ergebnis ab:

```factor
2 3 + .    ! prints 5
8 3 - .    ! prints 5    (8 - 3, not 3 - 8)
2 3 * .    ! prints 6
```

Ein verwandtes Wort, `.s`, gibt den *gesamten* Datenstapel aus, ohne etwas zu verbrauchen. Das ist im Listener (Factors interaktive Eingabeaufforderung, in der du Code eintippst und Ergebnisse siehst) praktisch, um zu sehen, was ein Codeschnipsel hinterlässt. Deshalb enden spätere Beispiele manchmal mit `.s` statt mit `.`: Sie lassen mehr als einen Wert auf dem Stapel, und `.s` zeigt sie alle.

Die Rechenwörter leben im Vokabular `math`. Eine Datei, die sie verwendet, braucht daher `math` in ihrer `USING:`-Zeile.

## Stapeleffekte

Jedes Wort ist mit einem **Stapeleffekt** der Form `( inputs -- outputs )` dokumentiert. Er ist der Vertrag des Wortes: Das Wort nimmt die Eingabewerte vom oberen Ende des Stapels und hinterlässt die Ausgabewerte an ihrer Stelle. Die Namen darin sind nur dazu da, dir das Lesen zu erleichtern. Factor verwendet sie nicht. Er verfolgt nur die *Reihenfolge*, in der die Werte auf dem Stapel liegen.

```factor
! + is specified as ( x y -- sum )
! . is specified as ( x   --     )
```

Das obere Ende des Stapels ist der *rechte* Eingabewert. Bei `8 3 -` liegt also `3` oben, der Stapeleffekt ist `( x y -- difference )`, und das Ergebnis ist `8 - 3`.

Ein abschließendes `?` bei den Ausgabewerten ist die Konvention für „ein boolescher Wert“, aber die Lasagne-Übung verwendet nur Zahlen.

Ein Umsortierwort aus Cargo Shuffle kommt weiter unten vor: `swap` `( x y -- y x )`, das die obersten beiden Werte vertauscht, wenn sie für das nächste Wort in der falschen Reihenfolge liegen.

## Ein Wort definieren

`:` beginnt eine Wortdefinition, danach folgt der Stapeleffekt, dann der Rumpf, und `;` beendet sie.

```factor
: square ( x -- x^2 ) dup * ;

4 square .    ! => 16
```

Der Compiler von Factor prüft, ob der Rumpf tatsächlich zum angegebenen Stapeleffekt passt: Ein Wort, das `( x -- y )` angibt, aber null oder zwei Werte auf dem Stapel hinterlässt, lässt sich nicht kompilieren.

## Konstanten

`CONSTANT:` definiert einen Namen für einen festen Wert. Eine Konstante ist selbst ein Wort: Wenn du sie aufrufst, legt sie den Wert auf den Stapel:

```factor
CONSTANT: pi 3

pi pi * .    ! => 9
```

`CONSTANT:` ist Kernsyntax und braucht keine `USING:`-Zeile. Setze Konstanten an den Anfang der Datei, vor jedes Wort, das sie verwendet.

## Ein Wort aus einem anderen aufrufen

Der Rumpf eines Wortes kann jedes Wort aufrufen, das bereits im Gültigkeitsbereich liegt, auch solche, die du früher in derselben Datei definiert hast:

```factor
: double    ( x -- 2x ) 2 * ;
: quadruple ( x -- 4x ) double double ;

5 quadruple .    ! => 20
```

So greift die letzte Aufgabe der Übung auf eine frühere zurück.

## Namenskonventionen

Wörter und Konstanten verwenden beide `lowercase-kebab-case`: Kleinbuchstaben, die durch Bindestriche verbunden sind (zum Beispiel `expected-bake-time`, `preparation-time`).
