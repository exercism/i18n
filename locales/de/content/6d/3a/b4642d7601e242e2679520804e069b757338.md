# Ergänzung zur Anleitung

## Baue deine eigene DSL

In dieser Übung kannst du die Graph-DSL deiner Träume völlig frei entwerfen.

Vielleicht möchtest du eine DSL erstellen, die auf Listen von Tags und Records basiert, etwa so:

```roc
my_graph =
    Graph.new([
        Title("My Graph"),
        Node("a", { color: Green }),
        Node("b", { color: Blue }),
        Edge("a", "b", { style: Dotted }),
    ])
```

Oder vielleicht bevorzugst du eine DSL, die auf Ketten von Funktionsaufrufen basiert, etwa so:

```roc
my_graph =
    Graph.new
        .with_title("My Graph")
        .add_node("a", Attr.new.with_color(Green))
        ...
```

Oder hast du einen ganz anderen Plan? Nur zu! Die Tests verlangen nur, dass du ein paar bestimmte Graphen erstellst. Wie du sie aufbaust, bleibt völlig dir überlassen.

Trotzdem ist eine DSL meist besser, wenn sie klar, knapp und nicht allzu überraschend ist (z. B. ist die Funktion `minus` zum Subtrahieren gedacht und nicht dafür, eine Kante zwischen zwei Knoten zu bauen, wie in `node("a") - node("b")`).

Um den Spaß zu verdoppeln, kannst du optional versuchen, eine Funktion `to_dot` zu implementieren, die deinen Graphen ins DOT-Format umwandelt!
