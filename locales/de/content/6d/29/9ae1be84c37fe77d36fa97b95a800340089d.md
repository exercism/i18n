# Anleitung

Dein Unternehmen hat mit Mapping-Daten gearbeitet, um Webseiten zu erstellen.
Nach einiger Diskussion wird entschieden, R zu verwenden, um einige Berechnungen dynamisch durchzuführen.

Versuche, direkt mit den Vektorpunkten zu arbeiten: Es ist nicht nötig, sie in getrennte `x`- und `y`-Koordinaten aufzuteilen.

## 1. Skaliere die Koordinaten

Implementiere die Funktion `scale(point, s)`, die einen Punkt mit beliebiger Anzahl von Dimensionen entgegennimmt und ihn um das vordefinierte `s` skaliert.

```R
# A 2D example
s <- c(0.5, 0.8)
point <- c(10, 5)
scale(point, s)
#> [1] 5 4
```

## 2. Verschiebe die Koordinaten

Implementiere die Funktion `translate(point, ...)`, die einen neuen Punkt zurückgibt, bei dem jede Koordinate um die Werte in der Ellipse verschoben wird.

Diese Funktion muss Punkte beliebiger Dimension verarbeiten können, wobei die Anzahl der Ellipsen-Argumente zu dieser Dimension passt.

```R
point2d <- c(2, 3)

# supply dx, dy translations
translate(point2d, 0.5, 0.6)
#> [1] 2.5 3.6

point3d <- c(2, 3, 4)

# supply dx, dy, dz translations
translate(point3d, 0.5, 0.6, 0.7)
#> [1] 2.5 3.6 4.7
```

## 3. Transformiere einen 2D-Punkt

Einige deiner Teammitglieder haben weniger Erfahrung mit R, deshalb entscheidest du dich, eine Closure zu verwenden, um wiederverwendbare Transformationen für `{x, y}`-Koordinatenpaare zu erstellen.

Implementiere die Funktion `transform2d(dx, dy, s)`, die eine Funktion zurückgibt, die eine Closure nutzt, um eine wiederholbare 2D-Verschiebung und -Skalierung eines Punktes durchzuführen.

Das Skalierungsargument `s` sollte optional sein, mit einem Standardwert von `1`.

Die zurückgegebene Funktion sollte einen 2D-Punkt entgegennehmen und dann:

1. ihn um die vordefinierten `dx` und `dy` verschieben
2. ihn um `s` skalieren

```R
# scale all coordinates by the same amount (2) in this example
# your code needs to be able to handle a vector `s`

tf2d <- transform2d(0.5, 0.6, 2)
class(tf2d)
#> [1] "function"

tf2d(c(2, 3))
#> [1] 5.0 7.2

# Accept default for `s`
tf2d <- transform2d(0.5, 0.6)

tf2d(c(2, 3))
#> 2.5 3.6
```

Die Reihenfolge der Operationen ist wichtig: Erst verschieben, dann skalieren ergibt das korrekte Ergebnis, erst skalieren, dann verschieben nicht.
Fachlich ausgedrückt: Die Operationen _kommutieren nicht_.

## 4. Transformiere einen 3D-Punkt

Mapping-Daten können auch Höhen enthalten, die verwendet werden, um Schattierungen und Konturen auf dem Bildschirm hinzuzufügen.

Implementiere die Funktion `transform3d(dx, dy, dz, s)`, die eine Funktion zurückgibt.

Das Skalierungsargument `s` sollte optional sein, mit einem Standardwert von `1`.

Die zurückgegebene Funktion sollte einen 3D-Punkt entgegennehmen, ihn um die vordefinierten Werte verschieben und ihn dann um `s` skalieren.

```R
# using default `s`
tf3d <- transform3d(0.5, 0.6, 0.7)
point <- c(2, 3, 4)
tf3d(point)
#> [1] 2.5 3.6 4.7

# using vector `s`
tf3d <- transform3d(0.5, 0.6, 0.7, c(0.5, 0.6, 0.7))
tf3d(point)
#> [1] 1.25 2.16 3.29
```
