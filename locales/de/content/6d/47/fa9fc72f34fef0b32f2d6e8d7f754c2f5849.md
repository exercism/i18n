# Installation

Die Lösungen in diesem Track sind in 32-Bit-RISC-V-Assembler geschrieben und laufen unter Emulation, du brauchst also keine RISC-V-Hardware.
Jede Übung enthält ein Makefile, das die Tests baut und ausführt.
Um es zu nutzen, brauchst du drei Tools:

- [Zig][zig], das über `zig cc` den RISC-V-Assembler, C-Compiler und Linker bereitstellt.
- [Make][make], das den Build ausführt.
- `qemu-riscv32` aus [QEMU][qemu], das das erzeugte Programm ausführt.

## macOS

Starte mit einer geeigneten Virtualisierungslösung (z. B. [Lima][lima]) eine virtuelle Linux-Maschine und befolge dann einen der Abschnitte zu Linux-Distributionen weiter unten.

## Windows

Nutze das [Windows Subsystem for Linux][wsl] und befolge einen der Abschnitte zu Linux-Distributionen weiter unten.
Alternativ kannst du eine virtuelle Linux-Maschine einrichten.

## Debian / Ubuntu

Installiere Make und QEMUs Emulatoren im User-Mode:

```shell
sudo apt install make qemu-user
```

Installiere dann Zig 0.15.2 oder neuer wie unter [Direkter Download][zig-install] beschrieben.

## Fedora

Installiere alle drei Tools mit:

```shell
sudo dnf install zig make qemu-user
```

## Arch Linux

Installiere alle drei Tools mit:

```shell
sudo pacman -S zig make qemu-user
```

## openSUSE Tumbleweed

Installiere alle drei Tools mit:

```shell
sudo zypper install zig make qemu-linux-user
```

## Installation überprüfen

Prüfe, ob alle drei Tools gefunden werden:

```shell
zig version
make --version
qemu-riscv32 --version
```

Lade dann mit der Exercism-Kommandozeile eine Übung herunter und führe ihre Tests aus:

```shell
exercism download --track=risc-v --exercise=hello-world
cd ~/exercism/risc-v/hello-world/
make
```
