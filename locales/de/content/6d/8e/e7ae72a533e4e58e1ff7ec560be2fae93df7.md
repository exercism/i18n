# Ressourcen

* [The Rust Programming Language](https://doc.rust-lang.org/book/) ist eine großartige Ressource, um mit Rust anzufangen und tiefer in bestimmte Features von Rust einzusteigen.
* [Rust by Example](https://doc.rust-lang.org/stable/rust-by-example/) zeigt dir Beispiele für die häufigsten Dinge, die du in Rust schreiben wirst.
* Mit der [Rust API Documentation](http://doc.rust-lang.org/std/) kannst du neue Methoden entdecken und erfahren, wie sie funktionieren.
* [Stack Overflow](http://stackoverflow.com/questions/tagged/rust) kannst du nutzen, um nach deinem Problem zu suchen und zu sehen, ob es schon beantwortet wurde. Du kannst dort auch Fragen stellen und beantworten.
* Das [Rust User Forum](http://users.rust-lang.org) ist für allgemeine Diskussionen über Rust gedacht.
* [/r/rust](http://www.reddit.com/r/rust/) ist das offizielle Subreddit zu Rust.
* Der offizielle Server von [The Rust Programming Language](https://discord.gg/rust-lang) auf [Discord](https://discordapp.com/) eignet sich für schnelle Fragen und Diskussionen über die Sprache.
