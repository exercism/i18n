# Installation

## .NET installieren

Der C#-Track baut auf der Plattform [.NET](https://dotnet.microsoft.com/learn/dotnet/what-is-dotnet) auf, die unter Windows, Linux und macOS läuft.
Um .NET-Projekte zu erstellen, kannst du die .NET-Kommandozeile (CLI) verwenden.
Diese Kommandozeile ist Teil des .NET SDK, das du nach der [Installationsanleitung](https://dotnet.microsoft.com/download/dotnet/8.0) installieren kannst.
Hinweis: Der C#-Track benötigt SDK-Version 9.0 oder höher.

Wenn du die Installation abgeschlossen hast, kannst du prüfen, ob die Kommandozeile erfolgreich installiert wurde, indem du diesen Befehl in einem Terminal ausführst:

```bash
dotnet --version
```

Wenn die Ausgabe eine Version größer oder gleich `9.0.100` ist, wurde das .NET SDK erfolgreich installiert.

## Eine IDE verwenden

Wenn du eine komfortablere Umgebung zum Bearbeiten möchtest, ist eine [IDE oder integrierte Entwicklungsumgebung](https://en.wikipedia.org/wiki/Integrated_development_environment) wahrscheinlich genau das Richtige für dich.
Das sind die beliebtesten IDEs, die das Erstellen von .NET-Projekten unterstützen:

- [Visual Studio 2022](https://www.visualstudio.com/downloads/)
- [Visual Studio Code](https://code.visualstudio.com/download) mit der [C#-Erweiterung](https://marketplace.visualstudio.com/items?itemName=ms-dotnettools.csharp)
- [Visual Studio for Mac](https://www.visualstudio.com/vs/visual-studio-mac/)
- [Project Rider](https://www.jetbrains.com/rider/download/)

Hinweis: Da sich das .NET-Projektformat deutlich von früheren Versionen unterscheidet, werden ältere IDEs (wie Visual Studio 2015) nicht unterstützt.
