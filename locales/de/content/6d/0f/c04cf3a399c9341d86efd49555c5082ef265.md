# Einführung

## IO

Das Modul `IO` stellt Funktionen für die Ein- und Ausgabe bereit.

### Ausgabe

Um einen String auf die Standardausgabe zu schreiben, verwende `IO.puts`. `IO.puts` fügt immer eine neue Zeile am Ende des Strings hinzu. Wenn du dieses Verhalten nicht möchtest, verwende stattdessen `IO.write`. Beide Funktionen geben bei Erfolg das Atom `:ok` zurück.

```elixir
IO.puts("Hi!")
# > Hi!
# => :ok
```

`IO.puts` ist nützlich, um Strings zu schreiben, aber nicht viel mehr. Wenn du ein Werkzeug zum Debuggen brauchst, mit dem du jeden Wert auf die Standardausgabe schreiben kannst, verwende stattdessen `IO.inspect`. `IO.inspect` gibt den Wert, der ihm übergeben wurde, unverändert zurück, sodass du es an jeder Stelle in deinem Code einfügen kannst. Es akzeptiert außerdem viele Optionen, zum Beispiel `:label`, mit denen du es von anderen Aufrufen von `IO.inspect` unterscheiden kannst.

### Eingabe

Um eine Zeile aus der Standardeingabe zu lesen, verwende `IO.gets`. `IO.gets` akzeptiert ein Argument: einen String, den es als Eingabeaufforderung ausgibt. `IO.gets` fügt nach der Eingabeaufforderung keine neue Zeile hinzu; füge sie selbst hinzu, wenn du sie brauchst.

```elixir
IO.gets("What's your name?\n")
# > What's your name?
# < Mary
# => "Mary\n"
```
