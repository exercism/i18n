# Sichtbarkeit

Wenn du Klassen verwendest, um Code zu organisieren, kann die Sichtbarkeit von Eigenschaften, Methoden und Konstanten sinnvolle Abstraktionen und Verantwortlichkeiten fördern.
Die Sichtbarkeit von Eigenschaften, Methoden und Konstanten wird durch die Verwendung der Schlüsselwörter `public`, `private` oder `protected` zum Zeitpunkt ihrer Deklaration festgelegt.
Die Sichtbarkeit bezieht sich immer auf die externe Nutzung der Eigenschaft, Methode oder Konstante einer Klasse.
Das heißt: Wenn eine Eigenschaft als `public` deklariert ist, ist sie für externe Aufrufe beobachtbar und nutzbar.
Private Eigenschaften, Methoden und Konstanten sind für externe Aufrufe weder beobachtbar noch nutzbar.

```php
<?php

class SecretDocument
{
    private $encryption_key;

    public $title;

    public function __construct($encryption_key, $title)
    {
        $this->encryption_key = $encryption_key;
        $this->title = $title;
    }
}

$document = new SecretDocument('secret_password', 'Secret Plans');
$title = $document->title; // => succeeds
$key = $document->encryption_key; // => fails
```

Geschützte Eigenschaften, Methoden und Konstanten sind nur für sie selbst und für alle Kindklassen (durch Vererbung) beobachtbar.

```php
<?php

class Shape
{
    protected $color = "blue";
}

class Square extends Shape
{
    public function getColor()
    {
        return $this->color;
    }
}

$square = new Square();
$color = $square->getColor(); // => succeeds
```
