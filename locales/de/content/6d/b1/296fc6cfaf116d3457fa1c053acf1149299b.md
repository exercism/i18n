# Einführung

Wie viele andere Sprachen hat auch C++ _Zeiger_.
Du weißt schon, dass _Referenzen_ und _Zeiger_ ähnlich sind, aber stell sie dir eine Ebene näher an der Funktionsweise deines Computers vor.
_Zeiger_ sind Variablen, die die Adressen von Objekten speichern.
Mit ihnen arbeitest du direkt mit Objekten, was in C++ dynamische Speicherzuweisung und effiziente Datenbearbeitung ermöglicht.

Wenn _Zeiger_ für dich neu sind, wirken sie vielleicht etwas mysteriös, aber sobald du dich an sie gewöhnt hast, sind sie ziemlich unkompliziert.

Sie sind ein entscheidender Teil von C++, also nimm dir Zeit, sie wirklich zu verstehen.
Die einfache Variante, um die es in diesem Konzept geht, nennt man auch _dummer Zeiger_ oder _roher Zeiger_.
Im modernen C++ gibt es außerdem _schlaue Zeiger_; der einfache Typ ist überhaupt nicht schlau und du musst die ganze Arbeit selbst erledigen.

Bevor wir ins Detail gehen, lohnt es sich zu verstehen, wozu _Zeiger_ gut sind.
_Zeiger_ sind eine Möglichkeit, die Adresse eines Objekts mit anderen Teilen unseres Programms zu teilen, was aus zwei wichtigen Gründen nützlich ist:

1. Wie _Referenzen_ vermeiden Zeiger Kopien und helfen, den Ressourcenverbrauch deines Programms zu verringern.
1. Anders als _Referenzen_ können Zeiger neu zugewiesen werden, sodass sie auf andere Objekte zeigen.
1. Zeiger können außerdem auf einen Nullwert zeigen, um anzuzeigen, dass sie gerade auf kein Objekt zeigen.

## Allgemeine Syntax

Eine Zeigerdeklaration in C++ gibt den Datentyp an, auf den der Zeiger zeigt, gefolgt von einem Sternchen (`*`) und dem Namen des Zeigers.
Wenn Zeiger deklariert werden, werden sie nicht automatisch initialisiert.
Ohne ausdrückliche Zuweisung enthält ein Zeiger normalerweise einen unbestimmten Wert, oft als „Mülladresse“ bezeichnet.
Manche Compiler initialisieren Zeiger zwar mit `nullptr`, aber dieses Verhalten ist nicht bei allen Compilern garantiert, also solltest du dich nicht darauf verlassen.
Es ist bewährte Praxis, rohe Zeiger ausdrücklich zu initialisieren und vor der Verwendung zu prüfen, ob sie nicht null sind, um mögliche Probleme zu vermeiden.

```cpp
int* ptr{nullptr}; // Declares a pointer and makes sure it is not invalid
```

Um die Adresse einer Variable einem Zeiger zuzuweisen, verwendest du den Adressoperator (`&`).
Das Dereferenzieren eines Zeigers erfolgt mit dem _Dereferenzierungsoperator_ (`*`).

```cpp
std::string opponent{"Solomon Lane"};
// 'ethan' points to the address of the string opponent
std::string* ethan{&opponent};
// Instead of ethan's, the opponent's name address is given to the passPort
std::string passportName{*ethan};
```

Achtung: Das Dereferenzieren muss ausdrücklich erfolgen, während _Referenzen_ einfach wie ein Alias funktionieren.

## Zeigerarithmetik

Mit _Zeigerarithmetik_ kannst du Rechenoperationen auf Zeigern ausführen, was besonders beim Arbeiten mit Arrays nützlich ist.
Wenn du eine Ganzzahl zu einem Zeiger addierst, zeigt er auf ein anderes Element.

```cpp
// Stargate Coordinate Code
int gateCode[] = {462, 753, 218, 611, 977};
// 'ptr' points to the first element of 'gateCode'
int* ptr{&gateCode[0]};
// Accesses the third Stargate address through pointer arithmetic
int dialedAddress{*(ptr + 2)};
// Chevron encoded! Dialing Stargate address:
openStarGate(dialedAddress);
```

~~~~exercism/caution
Zeigerarithmetik in C++ kann leicht zu __undefiniertem Verhalten__ führen, wenn du nicht sorgfältig damit umgehst.
Undefiniertes Verhalten kann sich in unerwarteten Programmergebnissen, Abstürzen oder sogar Sicherheitslücken äußern.
Ein berüchtigtes Beispiel für die Folgen von undefiniertem Verhalten war die [Explosion der Ariane-5-Rakete][ariane-flight-v88] im Jahr 1996, bei der eine Softwareausnahme, ausgelöst durch die Umwandlung einer 64-Bit-Gleitkommazahl in eine 16-Bit-Ganzzahl mit Vorzeichen, zu einem katastrophalen Fehlschlag führte.

[ariane-flight-v88]: https://en.wikipedia.org/wiki/Ariane_flight_V88

## Zugriff auf Membervariablen

In C++ verwendest du den Operator `->`, um über einen Zeiger auf ein Objekt auf dessen Member zuzugreifen.
Er ist eine Kurzschreibweise, die den Zugriff auf Member von Objekten vereinfacht, auf die Zeiger zeigen.
Wenn `ptr` zum Beispiel ein Zeiger auf ein Objekt mit der Membervariable `x` ist, kannst du statt `(*ptr).x` direkt `ptr->x` schreiben.
Dieser Operator verbessert die Lesbarkeit des Codes und macht ihn weniger umständlich, wenn du mit Zeigern auf Objekte arbeitest.

Hier ein kurzes Beispiel mit einem _struct_ `Superhero`, das eine Membervariable `superpower` hat.
Die main-Funktion erstellt einen Zeiger `dianaPrince` auf ein `Superhero`-Objekt (das Wonder Woman darstellt).
Mit dem Operator `->` wird auf die Membervariable `superpower` zugegriffen, die Wonder Womans berühmten „Lasso der Wahrheit“ zeigt.

```cpp
struct Superhero {
    std::string superpower;
};
Superhero wonder_woman{};
Superhero* dianaPrince = &wonder_woman;
dianaPrince->superpower = "Lasso of Truth";
// Using the -> operator to access member variable superpower:
std::cout << "Wonder Woman, possesses the mighty " << dianaPrince->superpower;
// Memory cleanup:
delete dianaPrince;
```

## Zeiger vs. Referenzen

Zeiger und Referenzen ermöglichen beide den indirekten Zugriff auf Objekte, unterscheiden sich aber in ihren Möglichkeiten und in Fragen der Sicherheit.
Zeiger bieten die Flexibilität, ihr Zielobjekt zu ändern, und können auf null gesetzt werden.
Diese Flexibilität bringt jedoch Risiken mit sich, etwa das Dereferenzieren von Nullzeigern oder das Erzeugen verwaister Zeiger.
Referenzen hingegen können nicht null sein und werden bei ihrer Erstellung an gültige Objekte gebunden, wodurch diese Risiken entfallen.
Da sie sicherer sind, solltest du Referenzen gegenüber Zeigern bevorzugen, es sei denn, du brauchst die zusätzlichen Möglichkeiten, die Zeiger bieten.
