# Einführung

Eine *Quotation* ist ein Stück Code in `[ ]`. Sie ist ein Wert:
du kannst sie auf den Stack legen, sie an ein anderes Wort übergeben oder sie
in einem Array speichern.

```factor
[ 1 + ] .          ! => [ 1 + ]
5 [ 1 + ] call .   ! => 6
```

Die meisten Wörter höherer Ordnung erwarten eine Quotation als zweites Argument:

```factor
{ 1 2 3 } [ sq ] map .    ! => { 1 4 9 }
{ 1 2 3 } [ even? ] filter .  ! => { 2 }
```

Der Rumpf einer Quotation ist ganz normaler Factor-Code, mit denselben
Operatoren und Stack-Effekten, die du überall sonst verwendest.

Wenn du Code aus Daten baust, also Fragmente aneinanderfügst und
Tokens auf Operationen abbildest, ist das Ergebnis eine Sequenz. Schick sie
durch `>quotation`, um sie aufrufbar zu machen:

```factor
{ [ 1 ] [ 2 + ] [ 3 * ] } concat >quotation call .   ! => 9
```
