# Über

Ein boolescher Ausdruck ist eine Frage, die man an einen oder mehrere Werte stellt und die man mit `true` oder `false` beantworten kann.
Ein wahrer Ausdruck gibt `1` zurück; ein falscher Ausdruck gibt `0` zurück.
Auch Zahlen haben Wahrheitswerte. Null ist `false`; jede Zahl ungleich Null ist `true`.

Älterer C-Code verwendet entweder direkt den Typ `int` für boolesche Werte, oder der Programmierer hat eigene Konstanten wie `TRUE` und `FALSE` definiert, um `1` und `0` auf eine boolesche Darstellung abzubilden.

Mit der Version C99 wurde der Typ `_Bool` eingeführt.
Die Header-Datei `stdbool.h` definiert drei neue boolesche Symbole: `bool`, `true` und `false`.
`true` wird auf `1` abgebildet, `false` auf `0` und `bool` auf `_Bool`.
Statt also direkt `int` zu verwenden oder eigene boolesche Zuordnungen zu bauen, können Programmierer jetzt `stdbool.h` einbinden und erhalten damit automatisch boolesche Symbole in ihrem Code.

## Vergleichsoperatoren

C unterstützt sechs Vergleichsoperatoren: `==` (gleich), `!=` (ungleich), `>` (größer als), `<` (kleiner als), `>=` (größer oder gleich), `<=` (kleiner oder gleich).
Diese Operatoren vergleichen die Beziehung zwischen Werten und lösen sie zu booleschen Werten auf.

```c
0 == 0 // true. Although 0 is false, 0 equals 0 is true.
0 != 0 // false
1 > 0 // true
1 < 0 // false
1 >= 0 // true
1 <= 0 // false
```

## Boolesche Operatoren

C unterstützt drei boolesche Operatoren: `||` (Oder), `&&` (Und) und `!` (Nicht).

`!` wird mit einem Operanden verwendet.
Es kehrt den booleschen Wert des Operanden um.
Zum Beispiel ist `0` gleich `false`, aber `!0` ist `true`.

`||` und `&&` werden mit zwei Operanden verwendet.
Der rechte Operand wird nur ausgewertet, wenn der linke Operand das Ergebnis des Ausdrucks nicht bereits bestimmt.
Das heißt, `||` wertet seinen rechten Operanden nur aus, wenn der linke Operand `false` ergibt.
`&&` wertet seinen rechten Operanden nur aus, wenn der linke Operand `true` ergibt.


## Kurzschlussauswertung

Nicht alle Operanden auszuwerten, nennt man „Kurzschlussauswertung“.
Die Kurzschlussauswertung ist eine knappe und mächtige Möglichkeit, bestimmte Situationen zu behandeln.
Ein häufiges Idiom ist zum Beispiel zu prüfen, ob ein Zeiger nicht `NULL` ist, und (&&) ihn dann, wenn er nicht `NULL` ist, zu dereferenzieren. So vermeidest du, einen `NULL`-Zeiger zu dereferenzieren.
Doch die Kurzschlussauswertung kann auch zu Bugs führen.
Manchmal vergisst ein Programmierer, dass der rechte Operand von `||` oder `&&` nicht immer ausgewertet wird.
Wenn der rechte Operand ein Ausdruck mit einem Seiteneffekt ist, der immer passieren soll, dann entsteht ein Bug, der vom booleschen Wert des linken Operanden abhängt.


## Einen booleschen Ausdruck zurückgeben

Das Ergebnis eines booleschen Ausdrucks kann direkt zurückgegeben werden.
Zum Beispiel lässt sich diese `if`-Anweisung

```c
if (count > 0)
    return true;
else
    return false;
end
```

durch Folgendes ersetzen:

```c
return count > 0;
```
