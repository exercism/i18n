# Überblick

In Go sind Strings unveränderlich.
Verkettest du Strings in einer Schleife mit `+`, führt das zu häufigen Allokationen und kopiert die Daten mehrfach.
Das [`strings`-Paket](https://pkg.go.dev/strings) stellt [`Builder`](https://pkg.go.dev/strings#Builder) bereit, mit dem du den Speicheraufwand minimierst, indem du Strings effizient zusammensetzt.

## Strings aufbauen

Der Nullwert eines `strings.Builder` ist sofort einsatzbereit, ohne dass du ihn ausdrücklich initialisieren oder Speicher allozieren musst.
Du kannst neue Daten mit speziellen Schreibmethoden in den Builder schreiben.
Jede Schreibmethode gibt einen Fehlerwert zurück, um die Standard-Go-Interfaces zu erfüllen, aber er ist garantiert immer `nil` und wird im Alltagscode normalerweise ignoriert.

Die am häufigsten verwendeten Methoden sind:

- `WriteString(s string) (int, error)`: Hängt einen String an den Puffer an.
- `WriteRune(r rune) (int, error)`: Hängt die UTF-8-Kodierung eines Rune an.
- `WriteByte(c byte) error`: Hängt ein einzelnes Byte an.

```go
var sb strings.Builder

sb.WriteString("Hello")
var r rune = ' '
sb.WriteRune(r)
var b byte = '.'
sb.WriteByte(b)
```

## Abrufen und Zurücksetzen

Wenn du deinen Text fertig zusammengesetzt hast, kannst du den gesammelten Inhalt mit der Methode `String()` als normalen Go-String abrufen.
Der Aufruf von `String()` ist sehr günstig, weil er das zugrunde liegende Byte-Slice direkt als String zurückgibt, ohne die gesammelten Daten zu kopieren.

Wenn du dieselbe Builder-Instanz wiederverwenden willst, um einen neuen String zusammenzusetzen (zum Beispiel innerhalb einer Schleife), kannst du die Methode `Reset()` aufrufen.
Das leert den internen Puffer, sodass du von vorn beginnen und den nächsten String aufbauen kannst, während die bereits allokierte Speicherkapazität im Hintergrund erhalten bleibt.

```go
var sb strings.Builder

sb.WriteString("Task One")
fmt.Println(sb.String()) // Output: Task One

// Clear the buffer for resource reuse
sb.Reset()

sb.WriteString("Task Two")
fmt.Println(sb.String()) // Output: Task Two
```
