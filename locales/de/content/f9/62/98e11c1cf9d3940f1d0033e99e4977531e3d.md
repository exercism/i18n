# Überblick

Der `null`-Wert steht für die _Abwesenheit_ eines Werts. Ein **nullbarer** Typ ist ein Typ, bei dem eine Variable den `null`-Wert annehmen kann. Um jeden Typ nullbar zu machen, umschließen wir ihn mit `Null<T>`:

```haxe
var a:Int = null; // Error
var b:Null<Int> = null; // Allowed
```

Um zu prüfen, ob ein Wert aktuell `null` ist, verwende einfach einen `if`-Ausdruck:

```haxe
var a:Null<Int> = 10;

if (a != null) {
  trace("a is not null"); // a is not null
}
```
