# Anleitung

In dieser Übung schreibst du etwas Code, der dir hilft, eine großartige Lasagne aus deinem Lieblingskochbuch zu kochen.

Du hast fünf Aufgaben, die alle mit der Zeit zu tun haben, die du für das Kochen der Lasagne brauchst.

## 1. Definiere die erwartete Backzeit in Minuten

Implementiere die Funktion `expectedCookTime` in der Klasse `Lasagna`, die keine Argumente entgegennimmt und zurückgibt, wie viele Minuten die Lasagne im Ofen bleiben sollte.
Laut dem Kochbuch beträgt die erwartete Backzeit 40 Minuten:

```php
<?php
$timer = new Lasagna();
$timer->expectedCookTime()
// => 40
```

## 2. Berechne die verbleibende Backzeit in Minuten

Implementiere die Funktion `remainingCookTime` in der Klasse `Lasagna`, die die tatsächlichen Minuten, die die Lasagne schon im Ofen war, als Argument entgegennimmt und zurückgibt, wie viele Minuten die Lasagne noch im Ofen bleiben muss. Dabei orientierst du dich an der erwarteten Backzeit in Minuten aus der vorherigen Aufgabe.

```php
<?php
$timer = new Lasagna();
$timer->remainingCookTime(30)
// => 10
```

## 3. Berechne die Vorbereitungszeit in Minuten

Implementiere die Funktion `totalPreparationTime` in der Klasse `Lasagna`, die die Anzahl der Schichten, die du der Lasagne hinzugefügt hast, als Argument entgegennimmt und zurückgibt, wie viele Minuten du mit der Vorbereitung der Lasagne verbracht hast. Dabei gehst du davon aus, dass jede Schicht 2 Minuten Vorbereitung braucht.

```php
<?php
$timer = new Lasagna();
$timer->totalPreparationTime(3)
// => 6
```

## 4. Berechne die gesamte Arbeitszeit in Minuten

Implementiere die Funktion `totalElapsedTime` in der Klasse `Lasagna`, die zwei Argumente entgegennimmt: Das erste Argument ist die Anzahl der Schichten, die du der Lasagne hinzugefügt hast, und das zweite Argument ist die Anzahl der Minuten, die die Lasagne schon im Ofen war.
Die Funktion sollte zurückgeben, wie viele Minuten du insgesamt mit dem Kochen der Lasagne verbracht hast. Das ist die Summe aus der Vorbereitungszeit in Minuten und der Zeit in Minuten, die die Lasagne im Moment im Ofen verbracht hat.

```php
<?php
$timer = new Lasagna();
$timer->totalElapsedTime(3, 20)
// => 26
```

## 5. Erstelle eine Benachrichtigung, dass die Lasagne fertig ist

Implementiere die Funktion `alarm` in der Klasse `Lasagna`, die keine Argumente entgegennimmt und eine Nachricht zurückgibt, die anzeigt, dass die Lasagne fertig zum Essen ist.

```php
<?php
$timer = new Lasagna();
$timer->alarm()
// => "Ding!"
```
