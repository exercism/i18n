# Anweisungen

Der Tag, auf den du so lange gewartet hast, ist endlich gekommen, und du bist jetzt der stolze Besitzer eines wunderschönen Bauernhofs in den Alpen.

Du magst es immer noch nicht, früh am Morgen aufzuwachen, um deine Kühe zu füttern.
Weil du ein ausgezeichneter Ingenieur bist, baust du einen Futterspender, den `FEED-M-ALL`.

Das Letzte, was noch fehlt, um dein Projekt abzuschließen, ist ein Stück Code, das die Futtermenge berechnet, die jede Kuh bekommen soll.
Es ist wichtig, dass jede Kuh die gleiche Menge bekommt. Du musst Konflikte vermeiden.
Kühe sind sehr empfindlich.

Zum Glück musst du nicht alle Formeln zur Berechnung der Futtermenge selbst herausfinden.
Du verwendest eine geheimnisvolle externe Bibliothek, die du im Internet gefunden hast.
Sie soll zu den glücklichsten Kühen führen.
Die Bibliothek stellt einen Typ bereit, der das folgende Interface erfüllt.
Darauf wirst du dich in deinem eigenen Code verlassen.

```go
type FodderCalculator interface {
	FodderAmount(int) (float64, error)
	FatteningFactor() (float64, error)
}
```

Während du an deinem Code arbeitest, wirst du die Fehlerbehandlung verbessern, um sie robuster und später in deinem täglichen Leben auf dem Bauernhof einfacher zu debuggen zu machen.

## 1. Teile das Futter gleichmäßig auf

Zuerst konzentrierst du dich darauf, den Code zu schreiben, der benötigt wird, um die Futtermenge pro Kuh zu berechnen.

Implementiere eine Funktion `DivideFood`, die einen `FodderCalculator` und eine Anzahl Kühe als Ganzzahl als Argumente entgegennimmt.
*Für diese Aufgabe gehst du davon aus, dass die übergebene Anzahl der Kühe immer größer als null ist.*
Die Funktion soll die Futtermenge pro Kuh als `float64` oder einen Fehler zurückgeben, falls einer auftritt.

Um die Berechnung durchzuführen, musst du zuerst die Gesamtfuttermenge für alle Kühe abrufen.
Das machst du, indem du die Methode `FodderAmount` aufrufst und die Anzahl der Kühe übergibst.
Zusätzlich brauchst du einen Faktor, mit dem diese Menge multipliziert werden muss.
Diesen Faktor erhältst du, indem du die Methode `FatteningFactor` aufrufst.
Mit diesen beiden Werten und der Anzahl der Kühe kannst du nun die Futtermenge pro Kuh berechnen (als `float64`).
Das ist es, was die Funktion `DivideFood` zurückgeben soll.

Wenn eine der Methoden, die du aufrufst, einen Fehler zurückgibt, soll die Ausführung stoppen und dieser Fehler soll (unverändert) von der Funktion `DivideFood` zurückgegeben werden.

```go
// For this example, we assume FodderAmount returns 50
// and FatteningFactor returns 1.5.
DivideFood(fodderCalculator, 5)
// => 15 <nil>

// Now assuming FodderAmount returns an error with message "something went wrong".
DivideFood(fodderCalculator, 5)
// => 0 "something went wrong"
```

## 2. Überprüfe die Anzahl der Kühe

Während du an der ersten Aufgabe oben gearbeitet hast, hast du gemerkt, dass die externe Bibliothek, die du verwendest, nicht so hochwertig ist, wie du dachtest.
Zum Beispiel kann sie ungültige Eingaben nicht richtig verarbeiten.
Du möchtest diese Einschränkung umgehen, indem du in deinem eigenen Code eine Überprüfung des Eingabewerts hinzufügst.

Schreibe eine Funktion `ValidateInputAndDivideFood`, die dieselbe Signatur wie `DivideFood` oben hat.

- Wenn die übergebene Anzahl der Kühe größer als 0 ist, soll die Funktion `DivideFood` aufrufen und die Ergebnisse dieses Aufrufs zurückgeben.
- Wenn die Anzahl der Kühe 0 oder kleiner ist, soll die Funktion einen Fehler mit der Meldung `"invalid number of cows"` zurückgeben.

```go
ValidateInputAndDivideFood(fodderCalculator, 5)
// => 15 <nil>

ValidateInputAndDivideFood(fodderCalculator, -2)
// => 0 "invalid number of cows"
```

## 3. Verbessere die Fehlerbehandlung

Die Anzahl der Kühe zu überprüfen, bevor du sie weitergibst, war ein guter Zug, aber mit der unspezifischen Fehlermeldung bist du noch nicht ganz zufrieden.
Du beschließt, es besser zu machen, indem du einen benutzerdefinierten Fehlertyp namens `InvalidCowsError` erstellst.

Der benutzerdefinierte Fehler soll die Anzahl der Kühe (`int`) und eine benutzerdefinierte Nachricht (`string`) enthalten, und die Methode `Error` soll die Daten im folgenden Format serialisieren:

```txt
{number of cows} cows are invalid: {custom message}
```

Mit deinem benutzerdefinierten Fehler ausgestattet, implementiere eine Funktion `ValidateNumberOfCows`, die die Anzahl der Kühe als Ganzzahl akzeptiert und einen Fehler (oder nil) zurückgibt.

- Wenn die Anzahl der Kühe kleiner als 0 ist, gibt die Funktion einen `InvalidCowsError` mit der benutzerdefinierten Nachricht `"there are no negative cows"` zurück.
- Wenn die Anzahl der Kühe 0 ist, gibt die Funktion einen `InvalidCowsError` mit der benutzerdefinierten Nachricht `"no cows don't need food"` zurück.
- Andernfalls gibt die Funktion `nil` zurück, um anzuzeigen, dass die Validierung erfolgreich war.

```go
err := ValidateNumberOfCows(-5)
err.Error()
// => "-5 cows are invalid: there are no negative cows"
```

Nach der harten Arbeit, diese Validierungsfunktion einzurichten, merkst du, dass es bereits Abend ist, und verlässt deinen Schreibtisch, um den Sonnenuntergang über den Bergen zu genießen.
Die Aufgabe, die neue Validierungsfunktion tatsächlich in deinen Code einzubauen, verschiebst du auf einen anderen Tag.
