# Einführung

Wie eine _if/else_-Anweisung ermöglicht es dir eine `switch`-Anweisung, den Ablauf des Programms zu ändern, indem du Code bedingt ausführst.
Der Unterschied ist, dass eine `switch`-Anweisung den Wert eines primitiven Ausdrucks oder eines String-Ausdrucks nur mit vordefinierten konstanten Werten vergleichen kann.

Bei der Verwendung einer switch-Anweisung sind einige Schlüsselwörter nützlich.

- `switch`: Mit diesem Schlüsselwort deklarierst du die Struktur der `switch`-Anweisung.
  Danach folgt der Ausdruck oder die Variable, die das Ergebnis verändert.
- `case`: Mit diesem Schlüsselwort deklarierst du die verschiedenen Möglichkeiten für das Ergebnis.
- `break`: Das `break`-Schlüsselwort ist sehr nützlich, um die Ausführung der `switch`-Anweisung am Ende des gewünschten Ablaufs zu stoppen.
  Wenn du es vergisst, läuft das Programm weiter und das kann zu unerwarteten Ergebnissen führen.
- `default`: Wie der Name schon sagt, verwendest du es als Standardergebnis, wenn kein anderer Fall zum Ergebnis deines Ausdrucks passt.

In ihrer einfachsten Form prüfen sie einen primitiven Ausdruck oder einen String-Ausdruck und treffen anhand seines Werts eine Entscheidung.
Zum Beispiel:

```java
String direction = getDirection();
switch (direction) {
    case "left":
        goLeft();
        break;
    case "right":
        goRight();
        break;
    default:
        // otherwise
        markTime();
        break;
}
```
