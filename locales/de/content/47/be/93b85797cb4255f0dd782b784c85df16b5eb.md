# Verwendung eines Funktionskopfs

[comment]: # (Dieser Fehler wird ausgelöst, wenn die Lösung einen Funktionskopf verwendet)

Ein Funktionskopf (eine Funktionsdefinition ohne Rumpf) ist nur bei Funktionen mit Standardargumenten notwendig, die mehrere Klauseln haben.

```elixir
# necessary function header
def hello(what \\ "World")
def hello("Alice"), do: "Hello, darling!"
def hello(name), do: "Hello, #{name}!"
```

Bei Funktionen mit Standardargumenten, die nur eine einzelne Klausel haben, lassen sich die Standardargumente direkt in dieser Klausel angeben.

```elixir
# preferred
def bye(name \\ "World"), do: "See you, #{name}!"

# not preferred - unnecessary function header
def bye(what \\ "World")
def bye(name), do: "See you, #{name}!"
```

Die Funktion `two_fer/1` braucht nur eine einzelne Klausel und benötigt daher keinen Funktionskopf.
