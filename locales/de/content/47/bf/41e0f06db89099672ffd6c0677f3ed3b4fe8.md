# Installation

Die aktuelle Version von elm ist 0.19.1.
Die Installationsanweisungen ändern sich, während sich die Sprache weiterentwickelt.
Aktuelle Installationsanweisungen findest du in den
[Installationsanweisungen des elm-Leitfadens][elm-install].

[elm-install]: https://guide.elm-lang.org/install/elm.html

## Weitere Tools

**elm-test**

Das Tool, mit dem du die Tests von der Kommandozeile aus ausführst, heißt elm-test.
Zurzeit benötigt elm-test Node.js und npm. Falls du das noch nicht hast,
[installiere bitte zuerst Node.js und npm][npm-install].
Sobald du npm installiert hast, kannst du elm-test so installieren:

```shell
npm install --global elm-test@latest-0.19.1
```

Mehr Infos findest du auf der [npm-Homepage von elm-test][elm-test].

[npm-install]: https://www.npmjs.com/get-npm
[elm-test]: https://www.npmjs.com/package/elm-test

**elm-format**

Die meisten elm-Programmierer nutzen elm-format, um ihren elm-Code zu formatieren.
Es ist ein Code-Formatierungstool ganz ohne Konfiguration.
Am Anfang kann es etwas frustrierend sein, wenn du automatische
Formatierungstools nicht gewohnt bist. Aber sobald du dich daran gewöhnt hast,
fragst du dich, wie du vorher ohne es programmieren konntest.
Es lässt sich ebenfalls mit npm installieren:

```shell
npm install --global elm-format@latest-0.19.1
```

Mehr Infos findest du auf der [elm-format-Homepage auf GitHub][elm-format].

[elm-format]: https://github.com/avh4/elm-format

**Texteditor**

Die Elm-Unterstützung ist mindestens für [IntelliJ][intellij] gut,
sowie für Texteditoren, die mit dem [elm language server][els]
kompatibel sind, wie VS Code, Sublime Text oder Vim.

[els]: https://github.com/elm-tooling/elm-language-server
[intellij]: https://github.com/klazuka/intellij-elm

## Berechtigungsfehler mit npm

Beim Installieren von elm-test oder elm-format kann es vorkommen,
dass npm einen EACCESS-Berechtigungsfehler meldet.
Wenn das der Fall ist, folge bitte den Anweisungen auf der npm-Website.
[Resolving EACCES permissions errors when installing packages globally][eaccess].

[eaccess]: https://docs.npmjs.com/resolving-eacces-permissions-errors-when-installing-packages-globally
