# Tupel

Tupel sind eine einfache Möglichkeit, eine feste Menge beliebiger Datentypen zusammenzufassen. Ein Tupel hat
keinen eigenen Namen; gibst du einer Datenstruktur einen Namen, wird daraus ein `struct`. Die Felder eines
Tupels haben keine Namen; du greifst über Destrukturierung oder über die Position darauf zu.

## Syntax

Ein Tupel ist eine Liste von Feldern, die von runden Klammern umschlossen wird:

- `()` ist der `unit type`, ein [Sonderfall](https://doc.rust-lang.org/std/primitive.unit.html)
- **(** _Ausdruck_ **,)** ist ein Tupel-Ausdruck mit einem einzigen Element
- **(** _Typ_ **,)** ist ein Tupel-Typ mit einem einzigen Element
- **(** _Ausdruck_ **,** ... **)** ist ein allgemeiner Tupel-Ausdruck
- **(** _Typ_ **,** ... **)** ist ein allgemeiner Tupel-Typ

### Erstellung

Tupel werden immer mit einem Tupel-Ausdruck erstellt:

```rust
// pointless but legal
let unit = ();
// single element
let single_element = ("note the comma",);
// two element
let two_element = (123, "elements can be of differing types");
```

Ein Tupel kann eine beliebige Anzahl von Elementen haben.

### Zugriff durch Destrukturierung

Du kannst über Destrukturierung auf die Elemente eines Tupels zugreifen. Das bedeutet einfach, dass du den
einzelnen Elementen des Tupels Variablennamen zuweist und das Tupel dabei verbrauchst.

```rust
let (elem1, _elem2) = two_element;
assert_eq!(elem1, 123);
```

### Zugriff über die Position

Du kannst auch über einen numerischen Positionsindex auf die Elemente eines Tupels zugreifen. Die Indizierung
beginnt wie immer bei 0.

```rust
let notation = single_element.0;
assert_eq!(notation, "note the comma");
```

## Tupel-Structs

Du wirst ebenfalls mit Tupel-Structs arbeiten. Wie normale Structs sind sie benannte Typen; anders als
normale Structs haben sie anonyme Felder. Ihre Syntax ist der normalen Tupel-Syntax sehr ähnlich. Sowohl
Destrukturierung als auch Positionszugriff sind erlaubt.

```rust
struct TupleStruct(u8, i32);
let my_tuple_struct = TupleStruct(123, -321);
let borrowed_neg = &my_tuple_struct.1;
let TupleStruct(borrowed_byte, _) = &my_tuple_struct;
assert_eq!(borrowed_neg, &-321);
assert_eq!(borrowed_byte, &123);
```

### Sichtbarkeit von Feldern

Alle Felder anonymer Tupel sind immer öffentlich. Die Felder von Tupel-Structs haben jedoch jeweils eine
eigene Sichtbarkeit, die standardmäßig privat ist, genau wie bei den Feldern normaler Structs. Mit dem
`pub`-Modifizierer kannst du die Felder öffentlich machen, genau wie bei einem normalen Struct.

```rust
// fails due to private fields
mod tuple { pub struct TupleStruct(u8, i32); }
fn main() { let _my_tuple_struct = tuple::TupleStruct(123, -321); }
```

```rust
// succeeds: fields are public
mod tuple { pub struct TupleStruct(pub u8, pub i32); }
fn main() { let _my_tuple_struct = tuple::TupleStruct(123, -321); }
```
