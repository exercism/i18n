# Einführung

Der `|>`-Operator heißt Pipe-Operator. Er kann verwendet werden, um Funktionsaufrufe so zu verketten, dass der Rückgabewert des vorherigen Funktionsaufrufs als erstes Argument an den nächsten Funktionsaufruf übergeben wird.

```elixir
"hello"
|> String.upcase()
|> Kernel.<>("?!")

# => "HELLO?!"
```
