# Einführung

## Generics

### Einführung

Generics sind ein Sprachmerkmal, das die Wiederverwendung von Code ermöglicht.
Zum Beispiel sollte es keine Rolle spielen, welchen Typ eine Liste enthält, um ihre Länge zu berechnen.
Deshalb verwendet die Funktion `length` einen generischen Typparameter `a` in ihrer Typsignatur.

```elm
length : List a -> Int
```

### Parameter in Typen

Wenn ein Typ generisch über einen anderen Typ ist, verwenden wir einen kleingeschriebenen Namen für diesen anderen Typ und nennen ihn Typparameter.
Häufige Beispiele sind die benutzerdefinierten Typen `List`, `Maybe` und `Result`.

```elm
-- Maybe is generic over the type a
type Maybe a
    = Nothing
    | Just a

someString : Maybe String
someString = Just "hello"

someInt : Maybe Int
someInt = Just 42
```

Ein wichtiger Hinweis zu Namen von Typparametern: Sie können mehrere Zeichen lang sein.
Die einzige Einschränkung ist, dass sie kleingeschrieben sein müssen.
Wenn es nützlich ist, geben wir ihnen daher beschreibende Namen.

Ein Typ kann generisch über mehrere andere Typen sein und somit mehrere Typparameter haben.
In diesem Fall bekommt jeder unabhängige Typ einen anderen kleingeschriebenen Namen.
Unabhängig zu sein hindert sie nicht daran, derselbe Typ zu werden; es ermöglicht ihnen nur, verschieden zu sein.

```elm
-- Result is generic over the types error and value
type Result error value
    = Ok value
    | Err error
```

Record-Typaliase können ebenfalls Typparameter haben, obwohl das weniger verbreitet ist.

```elm
-- Event is generic over the type a
type alias Event a =
    { at : Time
    , data : a 
    }
```

### Typparameter in Funktionen

Da Typen generisch sein können, können es auch Funktionen sein.
Funktionen, die mit generischen Typen umgehen, können geschrieben werden, wie zum Beispiel `Maybe.withDefault`.

```elm
withDefault : a -> Maybe a -> a
withDefault default maybe =
    case maybe of
      Just value -> value
      Nothing -> default
```

Funktionen, die andere Funktionen als Parameter nehmen, heißen Funktionen höherer Ordnung, und diese können ebenfalls generisch sein.

```elm
map : (a -> b) -> Maybe a -> Maybe b
map function maybe =
  case maybe of
    Just value ->
      Just (function value)

    Nothing ->
      Nothing
```
