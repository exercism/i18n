# Anweisungen

In dieser Übung implementierst du einige Funktionen, um eine Liste von Programmiersprachen zu bearbeiten.

## 1. Definiere eine Funktion, die eine leere Sprachenliste zurückgibt

Definiere die Funktion `new/0`, die keine Argumente entgegennimmt und eine leere Liste zurückgibt.

```elixir
LanguageList.new()
# => []
```

## 2. Definiere eine Funktion, die eine Sprache zur Liste hinzufügt

Definiere die Funktion `add/2`, die 2 Argumente entgegennimmt (eine _Sprachenliste_ und ein String-Literal einer _Sprache_). Sie sollte die resultierende Liste zurückgeben, wobei die neue Sprache der übergebenen Liste vorangestellt wird.

```elixir
language_list = LanguageList.new()
# => []
language_list = LanguageList.add(language_list, "Clojure")
# => ["Clojure"]
language_list = LanguageList.add(language_list, "Haskell")
# => ["Haskell", "Clojure"]
```

## 3. Definiere eine Funktion, die eine Sprache aus der Liste entfernt

Definiere die Funktion `remove/1`, die 1 Argument entgegennimmt (eine _Sprachenliste_). Sie sollte die Liste ohne das erste Element zurückgeben. Gehe davon aus, dass die Liste immer mindestens ein Element enthält.

```elixir
language_list = LanguageList.new()
# => []
language_list = LanguageList.add(language_list, "Clojure")
# => ["Clojure"]
language_list = LanguageList.add(language_list, "Haskell")
# => ["Haskell", "Clojure"]
language_list = LanguageList.remove(language_list)
# => ["Clojure"]
```

## 4. Definiere eine Funktion, die das erste Element in der Liste zurückgibt

Definiere die Funktion `first/1`, die 1 Argument entgegennimmt (eine _Sprachenliste_). Sie sollte die erste Sprache in der Liste zurückgeben. Gehe davon aus, dass die Liste immer mindestens ein Element enthält.

```elixir
language_list = LanguageList.new()
# => []
language_list = LanguageList.add(language_list, "Elm")
# => ["Elm"]
language_list = LanguageList.add(language_list, "Prolog")
# => ["Prolog", "Elm"]
LanguageList.first(language_list)
# => "Prolog"
```

## 5. Definiere eine Funktion, die zurückgibt, wie viele Sprachen in der Liste sind

Definiere die Funktion `count/1`, die 1 Argument entgegennimmt (eine _Sprachenliste_). Sie sollte die Anzahl der Sprachen in der Liste zurückgeben.

```elixir
language_list = LanguageList.new()
# => []
language_list = LanguageList.add(language_list, "Elm")
# => ["Elm"]
language_list = LanguageList.add(language_list, "Prolog")
# => ["Prolog", "Elm"]
LanguageList.count(language_list)
# => 2
```

## 6. Definiere eine Funktion, die feststellt, ob die Liste eine funktionale Sprache enthält

Definiere die Funktion `functional_list?/1`, die 1 Argument entgegennimmt (eine _Sprachenliste_). Sie sollte einen booleschen Wert zurückgeben. Sie sollte wahr zurückgeben, wenn _"Elixir"_ eine der Sprachen in der Liste ist.

```elixir
language_list = LanguageList.new()
# => []
language_list = LanguageList.add(language_list, "Elixir")
# => ["Elixir"]
LanguageList.functional_list?(language_list)
# => true
```
