# Anleitung

Du sollst herausfinden, ob es in einer Tüte eine Bonbonfarbe gibt, die den Großteil der Tüte ausmacht. 🍬 Das Mehrheitselement ist eines, das mehr als die Hälfte der Sammlung einnimmt. Gegeben eine Liste von Elementen, die die Farben darstellen, gib die Farbe zurück, die die Mehrheit bildet, andernfalls zeige an, dass keine Mehrheit gefunden wurde.

Für eine einfache Liste `[Red, Red, Blue, Red, Green]` sollte der Rückgabewert Red sein, weil Red 3 von 5 Mal in der Liste vorkommt. Bei einer Liste `[Red, Red, Blue, Green]` gibt es jedoch keine Mehrheit, obwohl Red das häufigste Element ist, weil 2/4 nicht größer als die Hälfte der Elemente ist.
