# Hinweise

## Allgemein

- Ein [Ganzzahl-Wert (`Int`)][numbers] kann als eine oder mehrere aufeinanderfolgende Ziffern definiert werden.
- Verwende Variablen, um deinen Werten schöne und lesbare Namen zu geben. Denk daran, dass die Lesbarkeit des Codes viel wichtiger ist als die Anzahl der Codezeilen.

## 1. Verbleibende Backzeit in Minuten berechnen

- Du musst eine [Funktion][functions] mit einem einzelnen Parameter definieren.
- Du musst dem Parameter einen [Standardwert][function-defaults] zuweisen.
- Du musst explizit einen Ganzzahl-Wert aus einer Methode zurückgeben.
- Der Parameter der Methode ist eine [Ganzzahl][numbers].
- Du musst den mathematischen Operator für Subtraktion (`-`) verwenden, um Werte zu subtrahieren.

## 2. Zubereitungszeit in Minuten berechnen

- Du musst eine [Funktion][functions] mit einem einzelnen Parameter definieren.
- Du musst explizit einen Ganzzahl-Wert aus einer Methode zurückgeben.
- Der Parameter der Methode ist eine [Ganzzahl][numbers].
- Du musst den mathematischen Operator für Addition (`+`) verwenden, um Werte zu addieren.

## 3. Verstrichene Zeit in Minuten berechnen

- Du musst eine [Funktion][functions] mit zwei Parametern definieren.
- Du musst dem zweiten Parameter einen [Standardwert][function-defaults] zuweisen.
- Du musst explizit einen Ganzzahl-Wert aus einer Methode zurückgeben.
- Der Parameter der Methode ist eine [Ganzzahl][numbers].
- Du musst den mathematischen Operator für Addition (`+`) verwenden, um Werte zu addieren.
- Du musst bereits implementierte Funktionen aufrufen.

[numbers]: https://kotlinlang.org/docs/reference/basic-types.html#numbers
[functions]: https://kotlinlang.org/docs/reference/functions.html#function-declarations
