# Einführung

## Bedingte Anweisungen (if)

### Logische Operatoren

Java unterstützt die drei logischen Operatoren `&&` (UND), `||` (ODER) und `!` (NICHT).

### if-Anweisung

Der zugrunde liegende Typ jeder bedingten Operation ist der `boolean`-Typ, der den Wert `true` oder `false` haben kann. Bedingungen werden oft als Kontrollflussmechanismen eingesetzt, um verschiedene Fälle zu prüfen. Um einen bestimmten Fall zu prüfen, kannst du eine `if`-Anweisung verwenden. Sie führt ihren Code aus, wenn die zugrunde liegende Bedingung `true` ist:

```java
int val;

if(val == 9) {
    // conditional code
}
```

Wenn mehr als ein Fall zu prüfen ist, kannst du viele `if`-Anweisungen mit den Anweisungen `else if` und `else` aneinanderhängen.

```java
if(val == 10) {
    // conditional code
} else if(val == 17) {
    // conditional code
} else {
    // executes when val is different from 10 and 17
}
```

### switch-Anweisung

Java bietet außerdem eine `switch`-Anweisung für Situationen mit mehreren Möglichkeiten.

```java
int val;

// switch statement on variable content
switch(val) {
    case 1:
        // conditional code
        break;
    case 2: case 3: case 4:
        // conditional code
        break;
    default:
        // if all cases fail
        break;
}
```
