# Einführung

## Agent

Das Modul `Agent` bietet eine Abstraktion zum Erzeugen von [Prozessen und der _Receive-Send_-Schleife][exercism-processes]. Von hier an nennen wir Prozesse, die mit dem Modul `Agent` gestartet wurden, _„Agent-Prozesse“_. Ein _Agent-Prozess_ kann gewählt werden, um einen zentralen gemeinsamen Zustand darzustellen.

Zum Starten eines _Agent-Prozesses_ bietet `Agent` die Funktion `start/2`. Die übergebene Funktion gibt beim Aufruf von `start` den Anfangszustand des _Agent-Prozesses_ zurück:

```elixir
# Start an agent process with an initial value of an empty list
{:ok, agent_pid} = Agent.start(fn -> [] end)
```

So wie `Map` oder `List` bietet `Agent` viele Funktionen für die Arbeit mit _Agent-Prozessen_.

Es ist üblich, die gesamte `Agent`-bezogene Funktionalität in einem Modul für die zu modellierende Domäne zu organisieren und zu kapseln.

[exercism-processes]: https://exercism.org/tracks/elixir/concepts/processes
