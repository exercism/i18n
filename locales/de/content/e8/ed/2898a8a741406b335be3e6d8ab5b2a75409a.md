# Einführung

Verzweigungen in Factor wählen zwischen **Quotations**, also Codestücken in eckigen Klammern, `[ ... ]`. Wenn du `[ ... ]` schreibst, landet der Code als Wert auf dem Stack, statt ausgeführt zu werden; die Verzweigung entscheidet dann, welche Quotation ausgeführt wird. (Quotations werden in einer späteren Übung ausführlich behandelt.)

`if` (in [`kernel`][kernel]) ist die grundlegende Verzweigung in Factor. Sie nimmt einen booleschen Wert und zwei Quotations und führt die erste aus, wenn der boolesche Wert wahr ist, und sonst die zweite.

```
if ( ? then-quot else-quot -- )
```

```factor
: abs ( x -- y ) dup 0 < [ neg ] [ ] if ;
```

`when` führt seine Quotation nur aus, wenn der boolesche Wert wahr ist, `unless` nur, wenn er falsch ist. Für mehrfache Verzweigungen gibt es `cond` (in [`combinators`][combinators]):

```factor
USING: combinators ;

: classify ( n -- s )
    {
        { [ dup 0 <  ] [ drop "negative" ] }
        { [ dup 0 =  ] [ drop "zero"     ] }
        [ drop "positive" ]
    } cond ;
```

[combinators]: https://docs.factorcode.org/content/vocab-combinators.html
