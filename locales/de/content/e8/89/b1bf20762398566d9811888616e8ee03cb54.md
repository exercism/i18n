# Anleitung

Implementiere eine RESTful-API zum Verwalten von Schuldscheinen.

Vier Mitbewohner leihen sich gegenseitig häufig Geld und haben Mühe, sich zu merken, wer wem wie viel schuldet.

Deine Aufgabe ist es, eine einfache [RESTful-API][restful-wikipedia] zu implementieren, die [Schuldscheine][iou] über POST-Anfragen entgegennimmt und über GET-Anfragen bestimmte zusammenfassende Informationen liefern kann.

## API-Spezifikation

### Benutzerobjekt

```json
{
  "name": "Adam",
  "owes": {
    "Bob": 12.0,
    "Chuck": 4.0,
    "Dan": 9.5
  },
  "owed_by": {
    "Bob": 6.5,
    "Dan": 2.75
  },
  "balance": "<(total owed by other users) - (total owed to other users)>"
}
```

### Methoden

| Beschreibung                     | HTTP-Methode | URL    | Payload-Format                                                            | Antwort ohne Payload                   | Antwort mit Payload                                                             |
| -------------------------------- | ------------ | ------ | ------------------------------------------------------------------------- | -------------------------------------- | ------------------------------------------------------------------------------- |
| Liste der Benutzerinformationen  | GET          | /users | `{"users":["Adam","Bob"]}`                                                | `{"users":<List of all User objects>}` | `{"users":<List of User objects for <users> (sorted by name)}`                  |
| Benutzer erstellen               | POST         | /add   | `{"user":<name of new user (unique)>}`                                    | N/A                                    | `<User object for new user>`                                                    |
| Schuldschein erstellen           | POST         | /iou   | `{"lender":<name of lender>,"borrower":<name of borrower>,"amount":5.25}` | N/A                                    | `{"users":<updated User objects for <lender> and <borrower> (sorted by name)>}` |
