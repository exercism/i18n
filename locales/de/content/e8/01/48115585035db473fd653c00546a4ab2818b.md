# Über

Boolesche Werte werden in Rust durch den Typ `bool` dargestellt, dessen Werte entweder `true` oder `false` sein können.

Rust unterstützt einen [booleschen Negationsoperator][negation operators]: `!` (Nicht).

Rust unterstützt sechs [Vergleichsoperatoren][comparison operators]: `==` (Gleich), `!=` (Ungleich), `>` (Größer als), `<` (Kleiner als), `>=` (Größer oder gleich), `<=` (Kleiner oder gleich). Mit ihnen kannst du die Beziehung zwischen nicht-booleschen Werten auswerten und in einen booleschen Wert umwandeln.

```rust
1 > 0 // true
1 < 0 // false
1 == 0 // false
1 != 0 // true
1 >= 0 // true
1 <= 0 // false
```

Anders als in manchen anderen Sprachen ist `0` nicht `false` und ein Wert ungleich null nicht `true`.

Rust unterstützt drei [logische binäre Operatoren][logical binary operators]: `&` (Logisches Und), `|` (Logisches Oder), `^` (Logisches Xor).

Rust unterstützt zwei [boolesche Operatoren][lazy boolean operators]: `||` (Oder), `&&` (Und). Sie unterscheiden sich von `|` und `&` darin, dass der rechte Operand nur ausgewertet wird, wenn der linke Operand das Ergebnis des Ausdrucks nicht bereits bestimmt. Das heißt, `||` wertet seinen rechten Operanden nur aus, wenn der linke Operand `false` ergibt, und `&&` nur, wenn er `true` ergibt.

```rust
true || false // == true; the right-hand side was not evaluated
true && false // == false
```
