# Einführung

## Try/Rescue/Else/After

`try..rescue` ist ein mächtiges Konstrukt, um Fehler abzufangen, wenn sie auftreten. Wenn Du Fehler abfängst, können Funktionen definierte Werte zurückgeben, wenn es nötig ist. Das Konstrukt `try..rescue` bietet uns außerdem zwei zusätzliche Möglichkeiten, die wir nutzen können:

- der `else`-Block
  - Wenn der try-Block erfolgreich ist, wird das Ergebnis mit diesem Block abgeglichen.
- der `after`-Block
  - Ob der try-Block erfolgreich ist oder einen Fehler auslöst, der Code im `after`-Block wird immer ausgeführt, solange das Programm an diesem Punkt noch läuft.
  - Das Ergebnis des `after`-Blocks wird nicht an den aufrufenden Gültigkeitsbereich zurückgegeben.

```elixir
try do
  :a
rescue
  _ -> :error
else
  :a -> :success
after
  :some_action
end

# => :success
```

## Dynamischer Aufruf

Wenn Elixir die Funktion auflöst, die aufgerufen werden soll, verwendet es den Namen des Moduls, um eine Suche durchzuführen. Die Suche kann dynamisch erfolgen, wenn der Name des Moduls an eine Variable gebunden ist.

```elixir
defmodule MyModule do
  def message(), do: "My message"
end

atom = MyModule
atom.message()
# => "My message"
```

Intern ist der Name eines Moduls ein Atom. Allen Elixir-Modulatomen wird automatisch `Elixir.` vorangestellt.

```elixir
is_atom(Enum)
# => true
Enum == Elixir.Enum
# => true
```
