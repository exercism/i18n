# Kompilierfehler

Der Code enthält einen oder mehrere Kompilierfehler, wodurch die Testsuite nicht ausgeführt werden kann. Ein guter erster Schritt, um herauszufinden, wie du den oder die Fehler behebst, ist es, die Fehlermeldungen anzusehen, die beim Kompilieren des Codes angezeigt werden. Diese Fehlermeldungen enthalten eine Fehlernummer und eine Beschreibung, was dir hilft, das genaue Problem zu lokalisieren.
