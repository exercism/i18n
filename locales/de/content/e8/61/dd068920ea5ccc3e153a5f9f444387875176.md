# Über

Eine [while-Schleife][while-loops] ist eine Anweisung zur Ablaufsteuerung, mit der Code ausgeführt wird, solange eine bestimmte Bedingung wahr ist.
Swift bietet zwei Arten von while-Schleifen: while-Schleifen und repeat-while-Schleifen.
Die Bedingung einer while-Schleife wird ausgewertet, bevor der Schleifenblock ausgeführt wird. Ist die Bedingung falsch, wird der Schleifenblock gar nicht ausgeführt.
while-Schleifen haben in Swift den folgenden Aufbau:

```swift
while <#condition#> {
  <#code#>
}
```

Hier wird die Schleife so lange ausgeführt, wie count größer als 0 ist, und gibt dabei die Zahlen 2, 1 und „Liftoff!“ aus.

```swift
var count = 2
while count > 0 {
  print("\(count)…")
  count -= 1
}
print("Liftoff!")

// prints:
// 2…
// 1…
// Liftoff!
```

Eine [repeat-while-Schleife][while-loops] ähnelt einer while-Schleife, aber die Bedingung wird ausgewertet, nachdem der Schleifenblock ausgeführt wurde.
Das bedeutet, dass der Schleifenblock immer mindestens einmal ausgeführt wird, selbst wenn die Bedingung falsch ist.
repeat-while-Schleifen haben in Swift den folgenden Aufbau:

```swift
repeat {
  <#code#>
} while <#condition#>
```

Hier wird die Schleife nur einmal ausgeführt, da die Bedingung falsch ist.
Da es eine repeat-while-Schleife ist, wird der Schleifenblock einmal ausgeführt, bevor die Bedingung ausgewertet wird.

```swift
var count = 2
repeat {
  print("\(count)…")
} while count < 0
print("Liftoff!")
```

## Schleifen mit Optional Binding

Eine häufige Variante der while-Schleife in Swift ist die while-Schleife mit Optional Binding.
Diese Schleifen wiederholen sich, solange der Aufruf einer Funktion, die einen optionalen Wert liefert, einen anderen Wert als `nil` zurückgibt.
Dieser (nicht optionale) Wert wird dann an einen Namen deiner Wahl gebunden und kann im Schleifenblock verwendet werden.

```swift
var arr = [1,2]
while let count = arr.popLast() {
  print("\(count)…")
}
print("Liftoff!")

// prints:
// 2…
// 1…
// Liftoff!
```
