# Zusätzliche Anweisungen

## Register

| Register | Verwendung | Typ     | Beschreibung                              |
| -------- | ---------- | ------- | ----------------------------------------- |
| `$a0`    | Eingabe    | Adresse | nullterminierter String aus Oktalzeichen  |
| `$v0`    | Ausgabe    | Ganzzahl | Dezimalwert des Eingabe-Strings          |
| `$t0-9`  | temporär   | beliebig | wird als temporärer Speicher verwendet    |
