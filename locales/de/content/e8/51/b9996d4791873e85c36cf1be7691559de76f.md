# Rest

In der Mathematik ist der **Rest** (englisch *remainder*) der Betrag, der nach einer Berechnung „übrig bleibt“.
Zum Beispiel ist der Rest von `5 / 3` gleich `2`.

Viele Programmiersprachen verwenden das Prozentzeichen (`%`) als Operator, um den Rest zu berechnen.
Zum Beispiel:
```javascript
5 % 3 == 2
```

Reste lassen sich oft sowohl für Ganzzahlen als auch für Gleitkommazahlen berechnen.
Zum Beispiel:
```javascript
5.3 % 3 == 2.3
```

Bei negativen Zahlen hat das Ergebnis immer dasselbe Vorzeichen wie der Dividend (die Zahl auf der linken Seite, die geteilt wird).
Zum Beispiel:
```javascript
-5 % 3 == -2
5 % -3 == 2
-5 % -3 == -2
```

Manche Sprachen (zum Beispiel Python) verwenden den `%`-Operator, um den Modul zu berechnen, nicht den Rest.
Dabei werden negative Zahlen anders behandelt.
Mehr dazu erfährst du [auf Wikipedia](https://en.wikipedia.org/wiki/Modulo).
