# Ergänzung zu den Anweisungen

## Implementierung

Wenn das letzte Element in der Liste ein `object` statt eines `string` ist, enthält es einen Qualifier, der die letzte Zeile des Sprichworts verändert.

```javascript
proverb('nail', 'shoe', { qualifier: 'horseshoe' });
// => For want of a nail the shoe was lost.
//    And all for the want of a horseshoe nail.
```
