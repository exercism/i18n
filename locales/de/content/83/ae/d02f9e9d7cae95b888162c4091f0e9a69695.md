# Über

[Symbole][symbols] sind benannte Bezeichner, mit denen du auf einen Wert verweisen kannst.
Symbole werden über ein Symbol-Literal erstellt, indem du einem Namen ein `:`-Zeichen voranstellst, z. B. `:foo`.
Sie können auch mit Anführungszeichen geschrieben werden, z. B. `:"foo"`, was zum Beispiel Leerzeichen im Namen erlaubt.

```ruby
:foo # => :foo
:"foo boo" # => :"foo boo"
```

Symbole werden an vielen Stellen in der Sprache verwendet, unter anderem als Schlüssel in Hashes, um Methodennamen und Variablennamen zu repräsentieren.

## Bezeichner

Was Symbole von Strings unterscheidet, ist, dass sie Bezeichner sind und keine Daten oder Text darstellen.
Das bedeutet, dass zwei Symbole mit demselben Namen immer dasselbe Objekt sind.

```ruby
"foo".object_id # => 60
"foo".object_id # => 80
:foo.object_id # => 1086748
:foo.object_id # => 1086748
```

## Symbole verändern

Symbole sind unveränderlich, das heißt, sie können nicht verändert werden.
Wenn du ein Symbol also „veränderst“, erstellst du in Wirklichkeit ein neues Symbol.
Es gibt einige Methoden, mit denen du Symbole bearbeiten kannst, und sie geben alle neue Symbole zurück.
Alle Methoden findest du in der [Symbol-API][symbols-api].

```ruby
:foo.upcase # => :FOO

:foo.object_id # => 1086748
:foo.upcase.object_id # => 60
```

Der Vorteil der Unveränderlichkeit von Symbolen ist, dass sie speichereffizienter als Strings sind, aber als Bezeichner auch sicherer zu verwenden.

## Umwandlung

Symbole können in Strings umgewandelt werden und umgekehrt.
Das kann nützlich sein, wenn du ein Symbol verändern möchtest oder wenn du ein Symbol als String verwenden willst.
Um einen String als Symbol darzustellen, kannst du die Methode `String#to_sym` verwenden, und für das Gegenteil die Methode `Symbol#to_s`.
Da Symbole nur über eine begrenzte Auswahl an Methoden verfügen, kann es nützlich sein, ein Symbol in einen String umzuwandeln, um darauf String-Methoden anzuwenden, wenn ein neues Symbol benötigt wird.

```ruby
:foo.to_s # => "foo"
"foo".to_sym # => :foo
```
