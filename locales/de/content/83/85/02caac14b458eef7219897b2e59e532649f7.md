# Einführung

Eine Funktion ist ein Block aus organisiertem, wiederverwendbarem Code, der eine bestimmte Aktion ausführt.
Es gibt mehrere Möglichkeiten, Funktionen in JavaScript zu definieren.
Hier schauen wir uns _Funktionsdeklarationen_ und _Funktionsausdrücke_ an.
Andere Möglichkeiten wie [Pfeilfunktionen][concept-arrow-functions] behandeln wir in anderen Konzepten.

## Funktionsdeklaration

Der Standardweg, eine Funktion in JavaScript zu definieren, ist eine _Funktionsdeklaration_, auch _Funktionsdefinition_ oder _Funktionsanweisung_ genannt.

Sie besteht aus dem Schlüsselwort `function`, dem Namen der Funktion und einer durch Kommas getrennten Liste von Parametern in runden Klammern.
Danach folgt der Funktionskörper (die Sammlung von Anweisungen, die festlegt, was eine Funktion tut), eingefasst in geschweifte Klammern.

```javascript
function someName(param1, param2, param3) {
  // ...
}
```

In JavaScript rufst du eine Funktion auf, indem du den Funktionsnamen nennst, gefolgt von runden Klammern, die die Argumente enthalten.

```javascript
someName(arg1, arg2, arg3);
```

## Parameter

Wenn du im Funktionskörper mit Parametern arbeitest, achte auf mögliche Seiteneffekte.

- Werte von [primitiven Datentypen][mdn-primitives] sind _unveränderlich_.
  Der ursprüngliche Wert wird nie davon beeinflusst, was im Funktionskörper mit dem Argument passiert.
- Bei allen anderen Werten (Objekte, Arrays, Funktionen) wirkt sich eine Neuzuweisung nicht auf den ursprünglichen Wert aus.
  Wenn du ein solches Argument jedoch veränderst (z. B. einem Objekt einen Schlüssel hinzufügst), veränderst du auch den ursprünglichen Wert, der übergeben wurde.

Standardmäßig sind alle Parameter, die in der Funktionsdeklaration definiert sind, in JavaScript optional.
Wenn du weniger Argumente übergibst, als es Parameter gibt, sind die fehlenden Argumente innerhalb der Funktion `undefined`, siehe [Null und Undefined][concept-null-undefined].
In vielen Fällen ist es sinnvoll, einen passenderen Standardwert als `undefined` zuzuweisen.
Das kannst du tun, indem du Standardparameter direkt in der Funktionsdefinition angibst.

```javascript
function someName(param1 = defaultValue1, param2 = defaultValue2) {
  // ...
}
```

## return-Anweisung

Eine `return`-Anweisung beendet die Ausführung der Funktion und legt einen Wert fest, der an den Aufrufer der Funktion zurückgegeben wird. Eine Funktion kann mehrere `return`-Anweisungen haben.

```javascript
function checkNumber(num) {
  if (num === 0) {
    return 'You passed 0, please provide another number.';
  }

  return 'Thanks for passing such a nice number.';
}
```

Das Ergebnis einer Funktion, die keinen Wert `return`t oder keine `return`-Anweisung hat, ist `undefined`.
Implizite `return`s gibt es in JavaScript nicht.

```javascript
function nakedReturn(a) {
  a * 2;
  return;
}

nakedReturn(1);
// => undefined

function noReturn(a) {
  a * 2;
}

noReturn(1);
// => undefined
```

In JavaScript kannst du genau einen Wert zurückgeben.
Wenn du mehr Informationen übergeben möchtest, musst du sie zuerst in einer Einheit zusammenfassen, meist in einem [Objekt][concept-objects] oder einem [Array][concept-arrays].

```javascript
function divide(a, b) {
  return {
    quotient: Math.floor(a / b),
    remainder: a % b,
  };
}
```

## Funktionsausdruck

Eine Funktionsdeklaration ist eine eigenständige Anweisung.
Manchmal ist es jedoch hilfreich, eine Funktion als Teil eines anderen Ausdrucks zu definieren, z. B. in einer Zuweisung, als Funktionsparameter ([Callback][concept-callbacks]) oder als Wert in einem [Objekt][concept-objects].
Das geht mit einem Funktionsausdruck.
Er hat dieselbe Syntax wie eine Funktionsdeklaration, nur dass der Funktionsname weggelassen werden kann, um eine _anonyme Funktion_ zu erstellen.

```javascript
const someFunction = function (param) {
  // ...
};

someOtherFunction(function (param) {
  // ...
});

const obj = {
  someFunction: function (param) {
    // ...
  },
};
```
