# Einführung

Eine Zeichenkette stellt Textdaten dar.
In Swift ist ein [`String`][strings-and-characters] eine geordnete Sammlung von `Character`-Werten, wobei jedes Zeichen ein Unicode-Zeichen darstellt.

Du erstellst eine Zeichenkette mit einem String-Literal, also einer Folge von Zeichen, die von doppelten Anführungszeichen (`"`) umschlossen ist.
Für mehrzeilige Zeichenketten verwendest du drei doppelte Anführungszeichen (`"""`):

```swift
let hello: String = "Hello, World!"

let poem: String = """
Roses are red,
Violets are blue.
Sugar is sweet,
And so are you.
"""
```

Zeichenketten in Swift lassen sich nahtlos mit der Klasse [`NSString`][nsstring-docs] des Foundation-Frameworks verbinden und bieten so Zugriff auf umfangreiche Möglichkeiten der Textverarbeitung.

## Zeichen

Ein `Character` stellt einen einzelnen erweiterten Graphemcluster dar, also ein für Menschen lesbares Zeichen, das aus einem oder mehreren [Unicode-Skalarwerten][unicode-scalar-values] besteht.
Ein Unicode-Skalarwert ist ein 21-Bit-Codepunkt im Bereich von `U+0000` bis einschließlich `U+D7FF` oder von `U+E000` bis einschließlich `U+10FFFF`.

```swift
let aChar: Character = "A"
```

## Typinferenz

Wenn du ein String-Literal schreibst, leitet Swift automatisch den Typ `String` ab.
Um ein einzelnes Zeichen als `Character` zu speichern, musst du eine explizite Typannotation angeben:

```swift
let aString = "A"        // Inferred as String
let aChar: Character = "A" // Explicitly typed as Character
print(type(of: aString)) // Prints String
print(type(of: aChar))   // Prints Character

// The following code will not compile:
let badChar: Character = "Too many characters"
// Error: Cannot convert value of type 'String' to specified type 'Character'
```

## Verkettung

Du kannst Zeichenketten mit dem Additionsoperator (`+`) aneinanderfügen:

```swift
print("honey" + "comb")
// Prints "honeycomb"
```

Du kannst ein `Character` nicht direkt mit `+` an einen `String` verketten, ohne das Zeichen zuvor in eine Zeichenkette umzuwandeln.
Du kannst jedoch die Methode [`append(_:)`][append] verwenden, um entweder eine Zeichenkette oder ein Zeichen direkt an eine veränderbare Zeichenkette anzuhängen:

```swift
var greeting = "Hello"
let world = ", world"
let period: Character = "."

greeting.append(world)
print(greeting) // Prints "Hello, world"

greeting.append(period)
print(greeting) // Prints "Hello, world."
```

## String-Interpolation

Mit der [String-Interpolation][string-interpolation] kannst du eine Zeichenkette aufbauen, indem du Konstanten, Variablen, Literale und Ausdrücke in String-Literale einbettest.
Setze jeden Ausdruck in runde Klammern und stelle einen Backslash davor (`\(` ... `)`):

```swift
let radius = 5.0
let circle = "The area of a circle with radius \(radius) is \(Double.pi * radius * radius)"
print(circle) // Prints "The area of a circle with radius 5.0 is 78.53981633974483"
```

## Eigenschaften von Zeichenketten und Zeichen

Zeichenketten und Zeichen bieten mehrere Eigenschaften, mit denen du ihren Inhalt untersuchen kannst.

### Eigenschaften von Zeichenketten

Häufige Eigenschaften von Zeichenketten sind:

| Eigenschaft | Beschreibung                                    | Beispiel                          |
| --------- | ---------------------------------------------- | -------------------------------- |
| `isEmpty` | Gibt `true` zurück, wenn die Zeichenkette keine Zeichen enthält | `"Hello".isEmpty` ergibt `false` |
| `count`   | Gibt die Anzahl der Zeichen in der Zeichenkette zurück | `"Hello".count` ergibt `5`       |

Eine vollständige Liste der Eigenschaften findest du in der [Apple-Dokumentation zu String][string-docs].

### Eigenschaften von Zeichen

Häufige Eigenschaften von Zeichen sind:

| Eigenschaft       | Beschreibung                                   | Beispiel                              |
| -------------- | --------------------------------------------- | ------------------------------------ |
| `isLowercase`  | Gibt `true` zurück, wenn das Zeichen ein Kleinbuchstabe ist  | `"a".isLowercase` ergibt `true` |
| `isUppercase`  | Gibt `true` zurück, wenn das Zeichen ein Großbuchstabe ist  | `"A".isUppercase` ergibt `true` |
| `isNumber`     | Gibt `true` zurück, wenn das Zeichen eine Ziffer ist    | `"1".isNumber` ergibt `true`    |
| `isWhitespace` | Gibt `true` zurück, wenn das Zeichen Leerraum ist | `" ".isWhitespace` ergibt `true`|

Eine vollständige Liste der Eigenschaften findest du in der [Apple-Dokumentation zu Character][character-docs].

## Typkonvertierung

Du kannst andere Typen in Zeichenketten umwandeln, indem du den Initialisierer `String(_:)` verwendest. Er unterstützt Standardtypen wie `Int`, `Double` und `Character`:

```swift
let charX: Character = "x"
print(String(charX))     // Prints "x"
print(String(110))       // Prints "110"
print(String(Double.pi)) // Prints "3.141592653589793"
```

## Sonderzeichen

String-Literale in Swift unterstützen mehrere [Escape-Sequenzen][special-characters] für Sonderzeichen:

| Sequenz   | Beschreibung                   |
| ---------- | ----------------------------- |
| `\0`       | Nullzeichen                |
| `\\`       | Backslash                     |
| `\t`       | Horizontaler Tabulator                |
| `\n`       | Zeilenvorschub (Newline)           |
| `\r`       | Wagenrücklauf               |
| `\'`       | Einfaches Anführungszeichen         |
| `\"`       | Doppeltes Anführungszeichen         |
| `\u{n}`    | Beliebiger Unicode-Skalarwert (hexadezimal) |

```swift
let quote: String = "\"Hello\", he said."
print(quote) // Prints "Hello", he said.

let unicode: Character = "\u{1F496}"
print(unicode) // Prints 💖
```
