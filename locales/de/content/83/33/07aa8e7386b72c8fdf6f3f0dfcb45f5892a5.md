# Hinweise

## 1. `couple`

- Ein Wort aus `grouping` reicht dafür: nimm das für die disjunkten
  Blöcke.

## 2. `peek-couplings`

- Ein gleitendes Fenster der Größe 2, der überlappende Verwandte von `group`.

## 3. `split-at-junctions`

- `split-when` erwartet ein Prädikat `( elt -- ? )`. Darin musst du
  fragen: „Ist dieser Wagen eine der Kreuzungen?", das ist
  `member?` gegen das `junctions`-Array.
- Der Wert `junctions` wird innerhalb der Quotation für jedes einzelne
  Element gebraucht, das heißt, du musst ihn mit `with` einbinden (das
  kennst du schon aus `boutique-bookkeeping`).

## 4. `coalesce-cargo`

- `monotonic-split` erwartet ein Prädikat über *benachbarte Paare*
  `( a b -- ? )`. Du möchtest, dass eine Folge weiterläuft, solange zwei
  benachbarte Wagen die *gleiche* Fracht tragen.
