# String-Builder

Ein `STR` ändert sich nie. `+` kann also nichts zu einem hinzufügen: Es muss einen völlig neuen String erzeugen, der den Inhalt von beiden enthält.

Einmal ist das in Ordnung. In einer Schleife nicht:

```sather
   -- don't
   script ::= "";
   loop
      script := script + lines.elt!;
   end;
```

Jede Runde kopiert alles, was bisher aufgebaut wurde, in einen neuen String und wirft den alten weg. Zehn Zeilen bedeuten zehn Kopien, jede länger als die vorige. Hundert Zeilen bedeuten hundert. Der Aufwand wächst mit dem *Quadrat* der Anzahl der Zeilen, und eine Schleife, die harmlos aussieht, wird zum langsamen Teil des Programms.

## FSTR

`FSTR` ist ein String, der sich *ändern* lässt, ein **String-Builder**. Etwas hinzuzufügen schreibt meist einfach in den Platz, den er schon hat. Eine Schleife über hundert Zeilen erledigt also ungefähr die Arbeit von hundert Zeilen statt hundert Kopien.

```sather
   script ::= #FSTR;
   loop
      script := script + lines.elt!;
   end;
   return script.str;
```

Drei Dinge solltest du beachten.

**`#FSTR` erzeugt einen leeren.** `#FSTR(100)` erzeugt einen, bei dem schon Platz für hundert Zeichen reserviert ist. Das lohnt sich, wenn die Größe bekannt ist.

**Du musst das Ergebnis wieder zuweisen.** `script := script + ...`, niemals `script + ...` allein. Meist ist das Ergebnis derselbe Builder, der hineinging. Wenn ihm aber der Platz ausgeht, ist es ein größerer, neuer. Lässt du das Ergebnis fallen, schreibst du weiter in den alten.

**`.str` am Ende.** Eine Routine, die `: STR` verspricht, muss einen `STR` zurückgeben, und `.str` erzeugt einen aus dem Builder.

## Was sich hinzufügen lässt

`+` auf einem `FSTR` akzeptiert einen String, ein Zeichen, eine Ganzzahl oder einen booleschen Wert. Meist musst du also nichts vorher umwandeln:

```sather
   line ::= #FSTR;
   line := line + 1 + ". " + "Enter" + '!';   -- "1. Enter!"
```

## Neue Zeilen

`"\n"` innerhalb eines Strings ist eine neue Zeile: ein Zeichen, mit zwei geschrieben.

```sather
   script := script + "Enter" + "\n" + "Exit";
```
