# Hinweise

## Allgemeines

- Schau dir den [Elm-Leitfaden][elm-guide] an, der ein schönes, ähnliches durchgerechnetes Beispiel enthält.

## 1. Definiere die Typen Model und Msg für die Anwendung und schreibe die init-Funktion

- Das `Model` enthält den Zustand der Anwendung: alle Daten, die die Anwendung braucht.
- Es sollte ein [Record][record] sein.
- Diese Anwendung braucht nur einen `String`, um den Text im Textfeld zu speichern (die Tests verlangen, dass er `content` heißt).

- Der Typ `Msg` definiert die Nachrichten, die an die Funktion `update` übergeben werden, um bestimmte Änderungen am Modell auszulösen.
- Er sollte ein [benutzerdefinierter Typ][custom-type] sein.
- Diese Anwendung braucht nur eine einzige Änderung am Modell: das Modell aktualisieren, wenn sich der Text im Textfeld ändert.

- Die Funktion `init` sollte einfach ein `Model` mit einem sinnvollen Standardwert zurückgeben (die Tests verlangen einen leeren String).

## 2. Schreibe die update-Funktion

- In jeder nützlichen Anwendung nutzt die Funktion `update` eine `case`-Anweisung, um den Parameter `Msg` per Pattern Matching zu verarbeiten.
- In jedem Zweig der `case`-Anweisung extrahiert sie die Informationen, die sie braucht, aus dem Parameter `Msg` und gibt ein aktualisiertes `Model` zurück.
- Das `Model` sollte ein Record sein, und normalerweise wird die [Syntax zum Aktualisieren von Records][record-update-syntax] verwendet.

## 3. Schreibe die view-Funktion

- Die Funktion `view` sollte ein `div` für das Wurzelelement zurückgeben.
- Das erste Kind sollte ein `input` mit einem `value`-Attribut für den aktuellen Text und einem `onInput`-Attribut bzw. -Event mit der passenden Variante von `Msg` sein.
- Das zweite Kind sollte ein weiteres `div` mit einem `text`-Kind sein, das angibt, ob der Text ein Palindrom ist oder nicht.

## 4. Schreibe die main-Funktion

- Die Funktion `main` sollte einfach [`Browser.sandbox`][browser-sandbox] aufrufen.
- `Browser.sandbox` erwartet als Argument ein [Record][record] mit den Funktionen `init`, `update` und `view`.
