# while- und until-Schleifen

Eine Schleife ist eine Kontrollstruktur, mit der Code abhängig von einer Bedingung wiederholt ausgeführt werden kann.

## while-Schleifen

Eine while-Schleife ist eine Kontrollstruktur, mit der Code abhängig von einer Bedingung wiederholt ausgeführt werden kann.
Der Code innerhalb einer while-Schleife wird weiter ausgeführt, solange die Bedingung truthy ist.
while-Schleifen werden oft verwendet, wenn die Anzahl der Iterationen im Voraus unbekannt ist. Du kannst sie in jeder Situation einsetzen, in der eine Schleife gebraucht wird.

Die Bedingung wird ausgewertet, bevor der Code im Schleifenblock ausgeführt wird. Ist die Bedingung falsch, wird der Code im Schleifenblock nie ausgeführt.

```crystal
i = 0
while i < 3
  puts i
  i += 1
end

# Output:
# 0
# 1
# 2
```

Wenn du über einen String iterieren willst, kannst du über die Länge des Strings schleifen.

```crystal
str = "Hello"
i = 0
while i < str.size
  puts str[i]
  i += 1
end

# Output:
# H
# e
# l
# l
# o
```

## until-Schleifen

until-Schleifen funktionieren genauso wie while-Schleifen, nur dass der Code im Schleifenblock so lange ausgeführt wird, bis die Bedingung truthy ist.
Es ist derselbe Unterschied wie zwischen `if` und `unless`.

```crystal
i = 0
until i == 3
  puts i
  i += 1
end
```

### Endlosschleifen

Ein häufiger Fehler bei while-Schleifen ist eine Endlosschleife, die nie endet.
Eine Endlosschleife kann entstehen, wenn eine Bedingung _nie_ truthy oder falsey ergibt.
Das liegt oft an einem Programmierfehler, zum Beispiel daran, dass vergessen wird, die Schleifenvariable zu erhöhen.
Manchmal ist eine Endlosschleife aber der klarste Weg, die Logik des Programms umzusetzen.
Oder es ist unerlässlich, endlos zu schleifen. Ein HTTP-Server wartet zum Beispiel auf eine eingehende Verbindung, bearbeitet sie und wartet dann auf die nächste Verbindung.

## Break

Mit dem Schlüsselwort `break` kannst du eine Schleife vorzeitig verlassen.
Das ist praktisch, wenn du eine Schleife unter bestimmten Bedingungen vorzeitig verlassen willst.

```crystal
i = 0
while i <= 3
  puts i
  i += 1
  if i == 2
    break
  end
end

# Output:
# 0
# 1
```

## Next

Mit dem Schlüsselwort `next` kannst du zur nächsten Iteration einer Schleife springen.
Das ist praktisch, wenn du bestimmte Iterationen einer Schleife überspringen willst.

```crystal
i = 0
while i <= 3
  i += 1
  if i == 2
    next
  end
  puts i
end

# Output:
# 1
# 3
```

## Typen in Schleifen

Der Typ einer Variable kann sich innerhalb einer Schleife ändern.
Im folgenden Beispiel ist der Typ von `a` `Int32 | String`, weil `a` im ersten Teil der Schleife `Int32` oder `String` sein kann.
Die Variable `a` hat den Typ `Int32 | String` nur im ersten Teil der Schleife, denn beim Start der Schleife enthält sie `Int32` und in der zweiten Iteration einen `String`.
Dieses System mit mehreren Typen wird später ausführlich erklärt.
Da wir aber sicher wissen, dass im zweiten Teil der Schleife nur `String` vorkommt, ist der Typ von `a` im zweiten Teil der Schleife `String`.
Zur Laufzeit enthält sie nie gleichzeitig `Int32` und `String`.

```crystal
i = 0
a = 4
while i < 3
  p typeof(a)
  # => Int32 | String
  a = "4"
  p typeof(a)
  # => String
  i += 1
end
```
