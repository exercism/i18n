# Ergänzung zu den Anweisungen

## Except

Der Rückgabewert der Funktion `guess` ist vom Typ `Except String Result`.

Ein [`Except ε α`][except] stellt eine Berechnung dar, die entweder zu einem Fehler vom Typ `ε` führen oder einen erfolgreichen Wert vom Typ `α` liefern kann.
Es ist eine Monade, wodurch sich solche Berechnungen zusammensetzen lassen.
