# Anweisungen

In dieser Übung schreibst du etwas Code, der dir hilft, dich auf den Kauf eines Fahrzeugs vorzubereiten.

Du hast drei Aufgaben: eine, um zu bestimmen, ob du einen Führerschein brauchst, eine, um dir bei der Wahl zwischen zwei Fahrzeugen zu helfen, und eine, um den akzeptablen Preis für ein gebrauchtes Fahrzeug zu schätzen.

## 1. Finde heraus, ob du einen Führerschein brauchst

Manche Fahrzeugarten darf man nur mit einem Führerschein fahren.
Geh davon aus, dass nur die Arten `"car"` und `"truck"` einen Führerschein erfordern, alles andere kann ohne Führerschein gefahren werden.

Implementiere die Funktion `needsLicense(kind)`, die die Art des Fahrzeugs entgegennimmt und einen booleschen Wert zurückgibt, der angibt, ob du für diese Fahrzeugart einen Führerschein brauchst.

```kotlin
needsLicense("car")
// => true

needsLicense("bike")
// => false

needsLicense("truck")
// => true
```

## 2. Wähle zwischen zwei möglichen Fahrzeugen

Du schaust dir die verfügbaren Fahrzeuge an und bewertest deine Möglichkeiten.
Du schaffst es, die Auswahl auf zwei Optionen einzugrenzen, aber du brauchst Hilfe bei der endgültigen Entscheidung.
Dafür implementierst du die Funktion `chooseVehicle(option1, option2)`, die zwei Fahrzeuge als Argumente entgegennimmt und eine Entscheidung zurückgibt, die die Option enthält, die in der [lexikographischen Ordnung][lexicographical-order] zuerst kommt.

```kotlin
chooseVehicle("Wuling Hongguang", "Toyota Corolla")
// => "Toyota Corolla is clearly the better choice."

chooseVehicle("Volkswagen Beetle", "Volkswagen Golf")
// => "Volkswagen Beetle is clearly the better choice."
```

## 3. Berechne eine Schätzung für den Preis eines gebrauchten Fahrzeugs

Jetzt, wo du dich entschieden hast, willst du sicherstellen, dass du beim Händler einen fairen Preis bekommst.
Da du ein gebrauchtes Fahrzeug kaufen willst, hängt der Preis davon ab, wie alt das Fahrzeug ist.
Für eine grobe Schätzung geh davon aus, dass ein Fahrzeug, das weniger als 3 Jahre alt ist, 80 % des ursprünglichen Preises kostet, den es als Neuwagen hatte.
Ist es mindestens 10 Jahre alt, kostet es 50 %.
Ist das Fahrzeug mindestens 3 Jahre alt, aber weniger als 10 Jahre, kostet es 70 % des ursprünglichen Preises.

Implementiere die Funktion `calculateResellPrice(originalPrice, age)`, die diese Logik mit `if`, `else if` und `else` anwendet (es gibt auch andere Wege, wenn du üben möchtest).
Sie nimmt den ursprünglichen Preis und das Alter des Fahrzeugs als Argumente entgegen und gibt den geschätzten Preis beim Händler zurück.

```kotlin
calculateResellPrice(1000, 1)
// => 800

calculateResellPrice(1000, 5)
// => 700

calculateResellPrice(1000, 15)
// => 500
```

[lexicographical-order]: https://en.wikipedia.org/wiki/Lexicographic_order
