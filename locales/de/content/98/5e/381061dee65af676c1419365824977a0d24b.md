# Anleitung

In dieser Übung arbeitest du an einem Terminplaner für einen Schönheitssalon in New York, der am 15. September 2012 eröffnet wurde.

## 1. Termindatum parsen

Implementiere die Methode `AppointmentScheduler.schedule()`, um eine textuelle Darstellung eines Termindatums in den entsprechenden `LocalDateTime` zu parsen:

```java
AppointmentScheduler scheduler = new AppointmentScheduler();
scheduler.schedule("7/25/2019 13:45:00");
// => LocalDateTime.of(2019, 7, 25, 13, 45, 0)
```

## 2. Prüfen, ob ein Termin bereits vorbei ist

Implementiere die Methode `AppointmentScheduler.hasPassed()`, die ein Termindatum entgegennimmt und prüft, ob der Termin irgendwann in der Vergangenheit lag:

```java
AppointmentScheduler scheduler = new AppointmentScheduler();
scheduler.hasPassed(LocalDateTime.of(1999, 12, 31, 9, 0, 0));
// => true
```

## 3. Prüfen, ob der Termin am Nachmittag liegt

Implementiere die Methode `AppointmentScheduler.isAfternoonAppointment()`, die ein Termindatum entgegennimmt und prüft, ob der Termin am Nachmittag liegt (>= 12:00 und < 18:00):

```java
AppointmentScheduler scheduler = new AppointmentScheduler();
scheduler.isAfternoonAppointment(LocalDateTime.of(2019, 03, 29, 15, 0, 0))
// => true
```

## 4. Uhrzeit und Datum des Termins beschreiben

Implementiere die Methode `AppointmentScheduler.getDescription()`, die ein Termindatum entgegennimmt und eine Beschreibung dieses Datums und dieser Uhrzeit zurückgibt:

```java
AppointmentScheduler scheduler = new AppointmentScheduler();
scheduler.getDescription(LocalDateTime.of(2019, 03, 29, 15, 0, 0))
// => "You have an appointment on Friday, March 29, 2019, at 3:00 PM."
```

## 5. Das Jubiläumsdatum zurückgeben

Implementiere die Methode `AppointmentScheduler.getAnniversaryDate()`, die das Jubiläumsdatum dieses Jahres zurückgibt, also den 15. September:

```java
AppointmentScheduler scheduler = new AppointmentScheduler();
scheduler.getAnniversaryDate()
// => LocalDate.of(<current year>, 9, 15)
```
