# Ergänzung der Anweisungen

## Wörter

`classify ( n -- str )` gibt einen der Strings `"perfect"`,
`"abundant"` oder `"deficient"` zurück.

## Fehler

Wenn die Eingabe null oder negativ ist, wirf den String

```
"Classification is only possible for positive integers."
```

(wörtlich, einschließlich des abschließenden Punkts).
