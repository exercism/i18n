# Hinweise

## 1. Definiere die Genehmigung

- Benutzerdefinierte Typen kannst du mit der Syntax `pub type Name { Variant1 }` definieren.

## 4. Definiere die Aktivität

- Benutzerdefinierte Typen, die Daten enthalten, kannst du mit der Syntax `pub type Name { Variant1(SomeType) }` definieren.

## 5. Bewerte die Aktivität

- Auf Varianten eines benutzerdefinierten Typs kannst du mit `case`-Ausdrücken einen Musterabgleich durchführen.
- Wenn du einem Muster eine zusätzliche Bedingung hinzufügen möchtest, kannst du mit dem Schlüsselwort `if` einen Guard zum Muster hinzufügen.
