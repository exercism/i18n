# Einführung

Hashes sind in Perl ein Datentyp, der eine ungeordnete Sammlung von String-Schlüsseln enthält, die jeweils mit skalaren Werten gepaart sind.

Eine Hash-Variable wird üblicherweise befüllt, indem man ihr eine Liste zuweist, z. B. `my %scores = (Alice => 10, Bob => 15, Charlie => 20);`.

Listen werden üblicherweise durch Kommas getrennt, aber häufig siehst du das sogenannte „Fat Comma“ `=>`, um Schlüssel und Werte in einer Liste zu trennen.
Sein Verhalten ist fast identisch mit dem eines Kommas, aber es hat den zusätzlichen Vorteil, dass es das Element auf der linken Seite als String interpretiert.

Hashes können befüllt werden, indem man einzelnen Schlüsseln Werte zuweist, z. B. `$scores{Alice} = 10;`.

Auf die Werte eines Hashes kannst du zugreifen, indem du Schlüssel über einen Index angibst, z. B. `$scores{Bob} # 15`.

Schlüssel in einem Hash sind eindeutig.
Wenn ein Schlüssel mehrmals angegeben wird, bleibt nur der zuletzt angegebene Wert erhalten.

## Funktionen

Funktionen für die Arbeit mit Hashes sind unter anderem [keys][keys] und [values][values], mit denen du die jeweiligen Teile eines Hashes als Liste abrufen kannst.
Die von den Funktionen [keys][keys] und [values][values] zurückgegebenen Listen können für Listenfunktionen wie [grep][grep], [map][map] und [sort][sort] sowie für [for][for]-Schleifen nützlich sein.

Weitere Hash-Funktionen sind [exists][exists], mit der du prüfen kannst, ob ein Schlüssel in einem Hash existiert (selbst wenn sein Wert `undef` ist), und [delete][delete], mit der du einen Schlüssel aus einem Hash entfernst.

## Sigil-Varianz

Wenn du Werte eines Hashes abrufst, bestimmt das verwendete Sigil das Ergebnis.
Der Index `{}` am Ende des Variablennamens sagt Perl, dass du auf einen Hash mit diesem Namen zugreifst.

```perl
my %names = (Alice => 10, Bob => 15, Charlie => 20);

$names{Alice}; # 10            <- A scalar
@names{Alice}; # (10)          <- A slice (with only one key, this probably isn't what you want. There will be a warning.)
%names{Alice}; # ('Alice', 10) <- A key/index + value slice

$names{'Bob', 'Charlie'}; #                            <- An error (disabled syntax for an ancient feature.)
@names{'Bob', 'Charlie'}; # (15, 20)                   <- A slice
%names{'Bob', 'Charlie'}; # ('Bob', 15, 'Charlie', 20) <- A key/index + value slice
```

Es ist zwar erlaubt, aber aus Gründen der Lesbarkeit wird empfohlen, dass verschiedene Variablentypen nicht denselben Namen teilen.
