# Über

Ein `bit` ist der feinste Wert in der Datenverarbeitung.
Das Wort `bit` steht für „Binärziffer“.
Es ist eine Einheit zur Datenspeicherung in der Ausführungsumgebung, groß genug, um ein Objekt aufzunehmen, das einen von zwei Werten haben kann.
Als solches hat es einen binären Wert von entweder `1` oder `0`.
Alle anderen Datentypen bestehen aus mehreren `bits`.
Zum Beispiel besteht ein `byte` üblicherweise aus acht `bits`.

## Wie du Bitwerte schreibst

`Bits` bilden ein Zahlensystem zur Basis 2.
Jedes Vielfache von `2` wird an die Stelle gesetzt, die wir als Zehner-, Hunderter-, Tausenderstelle usw. betrachten, nur dass „Zehner“ „Zwei“ wäre, „Hunderter“ „Vier“ und „Tausender“ „Acht“, und so weiter.
Die Dezimalzahl `2` wäre also die Binärzahl `10`, `4` wäre `100` und `8` wäre `1000`.
Wie bei Dezimalzahlen werden die Werte von rechts nach links größer.
Wir können uns vorstellen, dass die Dezimalzahl `5` im Binärsystem durch `101` dargestellt wird, mit einer `1` an der Einerstelle und einer `1` an der Vierer-Stelle.
Binärliterale sind jedoch nicht Teil des C-Sprachstandards.
Die einzigen binären Werte, die der C-Sprachstandard unterstützt, sind eine einzelne `1` oder `0`.
Binärliterale _werden_ jedoch von einigen nicht standardmäßigen Compiler-Erweiterungen unterstützt, etwa dem GNU-Compiler, indem man dem Literal `0b` voranstellt.

```c
#include <stdio.h>

int main() {
    int binary_five = 0b101;
    printf("%d", binary_five);
    return 0;
}
```

Denk daran, dass eine solche Notation nicht von allen Compilern unterstützt wird und ein Hindernis für die Portabilität des Codes zwischen verschiedenen Compilern sein kann.

Eine übliche Methode, Binärwerte zu schreiben, ist die hexadezimale Notation, ein Zahlensystem zur Basis 16.
In der hexadezimalen Notation von C stellt man dem Literal `0x` oder `0X` voran.
Da die Dezimalzahl `16` an der Zehnerstelle als `1` dargestellt wird, wird die Dezimalzahl `10` in Hexadezimal als `0xA` dargestellt, `11` als `0xB`, `12` als `0xC`, `13` als `0xD`, `14` als `0xE` und `15` als `0xF`.
So würde zum Beispiel die Dezimalzahl `42` als `0x2A` geschrieben: `2` mal `16` (= `32`) plus `10` (= `42`).

Im Binärsystem können wir uns `42` als `00101010` vorstellen: `32` plus `8` plus `2`.
Wir würden sagen, dass das zweite, vierte und sechste Bit von rechts „gesetzt“ sind, das heißt, sie sind `1` statt `0`.
Das zweite Bit ist `2`, das vierte Bit ist `8` und das sechste Bit ist `32`.
Das Setzen dieser drei Bits ergibt den Wert `42`.

## Bitmasken

Eine Bitmaske kann jeder Wert sein, der zum Setzen einzelner Bits verwendet wird.
Zum Beispiel gibt es sechsundzwanzig Buchstaben im englischen Alphabet.
Ein Wert mit mindestens sechsundzwanzig Bits, etwa eine vorzeichenlose 32-Bit-Ganzzahl, könnte als Bitmaske verwendet werden, um für jeden englischen Buchstaben eine `true`- oder `false`-Bedingung zu setzen.
Jeder Wert mit genügend Bits, um eine erforderliche Menge von `true`- oder `false`-Bedingungen zu verarbeiten, kann als Bitmaske dienen.
Das Setzen und Lesen der einzelnen Bits erfolgt durch die Verwendung bitweiser Operatoren.

## Bitweise Operatoren

Angenommen, wir wollen verfolgen, welche Buchstaben in einem `string` vorkommen.
Für unser Beispiel verwenden wir nur die sechsundzwanzig Buchstaben des englischen Alphabets.
Unsere Bitmaske ist eine vorzeichenlose 32-Bit-Ganzzahl.
Eine `0` steht dafür, dass der Buchstabe nicht vorkommt.
Eine `1` steht dafür, dass der Buchstabe ein oder mehrere Male vorkommt.
Am Anfang ist die Bitdarstellung unserer Bitmaske 32 `0s` hintereinander: `00000000000000000000000000000000`.
Die rechteste Position ist für `A`.
Die zweite von rechts ist für `B`, und so weiter.
Angenommen, wir verarbeiten alle Buchstaben des Strings in einer Schleife. Dann wollen wir eine Codezeile, die zum Setzen jedes beliebigen Buchstabens funktioniert.

### Bitweiser Linksverschiebungsoperator: ein Bit positionieren

`<<` ist der bitweise Operator zum Verschieben nach links.

Wenn unser Buchstabe `A` ist, wollen wir nicht nach links verschieben. Wenn unser Buchstabe `B` ist, wollen wir um eine Position nach links verschieben, und wenn unser Buchstabe `C` ist, um zwei Positionen, und so weiter.
Obwohl wir `chars` als Buchstaben wie `A` oder `B` wahrnehmen können, ist ein `char` im Speicher als ganzzahliger Typ implementiert. Deshalb können wir mit einem `char` einfache Berechnungen durchführen.
Angenommen, es gibt eine Variable namens `letter`, die das `char` repräsentiert, das wir verarbeiten. Dann können wir um die erforderliche Anzahl von Positionen nach links verschieben, indem wir `1` um die Differenz zwischen `letter` und dem `char` `A` nach links verschieben, so: `1 << letter - 'A'`.
`A` - `A` ist `0`, also würde es um `0` Positionen nach links verschieben, wenn `letter` `A` ist.
`B` - `A` ist `1`, also würde es um `1` Position nach links verschieben, wenn `letter` `B` ist, und so weiter.

### Bitweiser inklusiver ODER-Operator: ein Bit setzen

Sobald wir wissen, _wo_ wir ein Bit setzen wollen, können wir es mit dem bitweisen inklusiven ODER-Operator `|` tatsächlich setzen.
Das Ergebnis des `|`-Operators ist `1` an jeder Position, an der entweder der linke oder der rechte Operand ein gesetztes Bit hat.
Das Ergebnis von `0010 | 0001` wäre also `0011`.
(Denk daran, dass der Wert binär `11` ist, dezimal aber `3`.)
Um das Ergebnis einem Wert zuzuweisen, kann der `|`-Operator mit dem Zuweisungsoperator kombiniert werden, um die Bits so zu setzen: `|=`.
Um es einfach zu halten, verwendet das folgende Beispiel keine Schleife. Es zeigt aber, wie wir die Buchstaben `ABA` in einer Bitmaske verarbeiten könnten.

```c
#include <stdio.h>
#include <stdint.h>

int main() {
    // it's important to initialize the mask to 0 so we don't get garbage values
    uint32_t mask = 0;
    char letter_A = 'A';
    char letter_B = 'B';
    char letter_A_again = 'A';
    mask |= 1 << letter_A - 'A';
    mask |= 1 << letter_B - 'A';
    mask |= 1 << letter_A_again - 'A';
    // prints 3
    printf("%d", mask);
}
```

Wir setzen den rechtesten Teil unserer Maske für `A` auf `0001` und setzen die Maske dann für `B` auf `0011`.
Das Setzen eines weiteren `A` ändert die vorhandene Maske nicht.
Wir hätten das erneute Setzen des Bits vermeiden können, indem wir geprüft hätten, ob `A` bereits gesetzt war.

### Bitweiser AND-Operator: ein Bit lesen

`&` ist der bitweise AND-Operator.
Das Ergebnis des `&`-Operators ist `1` an jeder Position, an der sowohl der linke als auch der rechte Operand ein gesetztes Bit haben.
Das Ergebnis von `0011 & 0001` wäre also `0001`.
Das sehen wir im folgenden Beispiel.

```c
#include <stdio.h>
#include <stdint.h>

int main() {
    uint32_t mask = 0;
    char letter_A = 'A';
    char letter_B = 'B';
    char letter_A_again = 'A';
    mask |= 1 << letter_A - 'A';
    mask |= 1 << letter_B - 'A';
    // prints A already set
    if (mask & 1 << letter_A_again - 'A')
        printf("A already set\n");
    else
        mask |= 1 << letter_A_again - 'A';
    printf("%d", mask);
}
```

### Bitweiser exklusiver ODER-Operator: ein Bit umschalten

`^` ist der bitweise exklusive ODER-Operator.
Ein _inklusiver_ ODER-Operator impliziert, dass es einen _exklusiven_ ODER-Operator mit anderem Verhalten gibt.
Das Ergebnis des `^`-Operators ist `1` an jeder Position, an der _nur einer_ der linken oder rechten Operanden ein gesetztes Bit hat.
Das Ergebnis von `0001 ^ 0011` wäre also `0010`.
Das rechteste Bit wird nicht gesetzt, weil _beide_ Operanden an der rechtesten Position `1` haben.
Die exklusive ODER-Operation wird manchmal als XOR notiert.
Wenn man das Ergebnis eines Werts, der XOR-verknüpft wurde, erneut XOR-verknüpft, erhält man den ursprünglichen Wert.
Das kann für eine sehr einfache Verschlüsselung verwendet werden, bei der derselbe Schlüssel zum Verschlüsseln und Entschlüsseln der Daten verwendet wird.
Zum Beispiel

```c
#include <stdio.h>

int main() {
    char a = 'a';
    char b = 'b';
    char c = 'c';
    // we will use "a" for the "key"
    char first = a ^ 'a';
    char second = b ^ 'a';
    char third = c ^ 'a';
    // prints three "dots" for unprintable characters
    printf("%c %c %c\n", first, second, third);
    // prints the ascii values 0 3 2
    printf("%d %d %d\n", first, second, third);
    first = first ^ 'a';
    second = second ^ 'a';
    third = third ^ 'a';
    // prints a b c
    printf("%c %c %c\n", first, second, third);
    // prints the ascii values 97 98 99
    printf("%d %d %d\n", first, second, third);
}
```

### Bitweiser Rechtsverschiebungsoperator: einen Wert halbieren

`>>` ist der bitweise Operator zum Verschieben nach rechts.
Normalerweise wird der Wert für jede Position, um die seine Bits nach rechts verschoben werden, durch zwei geteilt.
Zum Beispiel

```c
#include <stdio.h>

int main() {
    int number = 16;
    number >>= 2;
    // prints 4, or 16 / 2 = 8 / 2 = 4
    printf("%d\n", number);
}
```

Wenn der Wert des rechten Operanden negativ ist oder größer oder gleich der Breite des beförderten linken Operanden ist, ist das Verhalten undefiniert.
Das gilt auch für den Linksverschiebungsoperator.
Wenn eine vorzeichenbehaftete Ganzzahl statt einer vorzeichenlosen Ganzzahl verwendet wird, kann auch das Vorzeichen eine Rolle spielen.
Das folgende Beispiel zeigt das Verhalten auf einem System, wenn eine vorzeichenbehaftete Ganzzahl zu weit nach links oder rechts verschoben wird.

```c
#include <stdio.h>

int main() {
    int number = 16;
    number <<= 250;
    // prints 1073741824
    printf("%d\n", number);
    number <<= 1;
    // prints -2147483648
    printf("%d\n", number);
    number <<= 1;
    // prints 0
    printf("%d\n", number);
    // total shifts are now 256, done incrementally
    number <<= 4;
    // prints 0
    printf("%d\n", number);
    number = 16;
    // prints 16 when 256 total shifts done at once
    printf("%d\n", number << 256);
    // prints 0 when bits shifted right far enough
    printf("%d\n", number >> 5);    
    // still prints 0
    printf("%d\n", number >> 255);
    // prints 16 when shifted right far enough to "wrap around"
    printf("%d\n", number >> 256);
}
```

Da das Verhalten undefiniert ist, kann ein anderes System andere Ergebnisse liefern.
Beim Verschieben von Bits ist es wichtig, die Grenzen des verwendeten Datentyps zu kennen.

## Bitfelder

Wir haben gesehen, wie Bits, die in einen einfachen Datentyp gepackt sind, über ihre Position angesprochen werden können.
Bits, die in eine `struct` gepackt sind, können über ihren Namen angesprochen werden.
Ein solcher Datentyp wird `bit field` genannt.
Ein Anwendungsfall für `bit fields` kann gegeben sein, wenn eine Sammlung von AN/AUS-Flags benötigt wird und der Speicherverbrauch minimiert werden soll.

```c
#include <stdio.h>

int main() {

    struct lights {
        unsigned int number_of_lights;
        unsigned int red   : 1;
        unsigned int green : 1;
        unsigned int blue  : 1;
    };
    struct lights lightboard = {3, 0, 0, 0};
     
    //  prints 000
    printf("%d", lightboard.red);
    printf("%d", lightboard.green);
    printf("%d\n", lightboard.blue);
    
    lightboard.green = 1;

    //  prints 010
    printf("%d", lightboard.red);
    printf("%d", lightboard.green);
    printf("%d\n", lightboard.blue);
    
    // prints 3
    printf("%d\n", lightboard.number_of_lights);
}
```

Die Syntax `unsigned int variable_name : 1;` erzeugt ein Feld von `1` Bit innerhalb eines `unsigned int`, das in der Struktur liegt.
Statt eines `unsigned int` könnte ein `signed int` verwendet werden, oder, ab C99 oder später, ein `bool`-Typ.
Eine Struktur, die Bitfelder enthält, kann auch Felder anderer Datentypen enthalten, etwa `number_of_lights` im obigen Beispiel.
