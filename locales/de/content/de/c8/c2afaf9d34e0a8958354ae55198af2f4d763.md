# Vorlagenkommentar

Es sieht so aus, als hättest du einige „Please implement ...“-Kommentare im Code gelassen, die Teil der Vorlage für die Lösung waren.

Dein Code besteht die Tests. Das heißt, diese Kommentare stimmen nicht mehr, denn du hast alle nötigen Funktionen bereits implementiert.

Achte darauf, veraltete Kommentare immer aus deinem Code zu entfernen.
