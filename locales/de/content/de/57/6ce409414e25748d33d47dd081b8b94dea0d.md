# Einführung

Mit Generics kannst du Code schreiben, der mit mehreren Typen funktioniert, ohne ihn zu duplizieren. Definiere generische Typen mit spitzen Klammern `<T>`, wobei `T` ein Platzhalter für einen beliebigen Typ ist.

```rust
fn largest_list<T>(l1: Array<T>, l2: Array<T>) -> Array<T> {
    if l1.len() > l2.len() {
        l1
    } else {
        l2
    }
}
```

Cairo verlangt Trait-Bounds, um festzulegen, welche Operationen der generische Typ unterstützen muss. Du kannst Einschränkungen mit der `+`-Syntax hinzufügen:

```rust
fn process_data<T, +Drop<T>, +Copy<T>>(value: T) -> T {
    // Function body
}
```

Auch Structs können generisch sein:

```rust
#[derive(Drop)]
struct Container<T> {
    value: T,
}
```

Auch Traits können generisch sein, sodass sie mit verschiedenen Typen funktionieren:

```rust
trait Processor<T> {
    fn process(self: @T) -> ByteArray;
}

impl MyProcessor<T, +Drop<T>> of Processor<T> {
    fn process(self: @T) -> ByteArray {
        "processed"
    }
}
```

Funktionen können generische Parameter mit Trait-Bounds annehmen, sodass sie mit jedem Typ funktionieren, der den erforderlichen Trait implementiert:

```rust
fn use_processor<T, +Processor<T>, +Drop<T>>(item: T) -> ByteArray {
    item.process()
}
```
