# Einleitung

Bei der Global Verification Authority wurde dir gerade ein wichtiger Auftrag anvertraut.
In der ganzen Stadt, von Online-Käufen bis hin zu sicheren Logins, verlassen sich unzählige Vorgänge auf die Korrektheit numerischer Kennungen wie Kreditkartennummern, Bankkontonummern, Transaktionscodes und Tracking-IDs.
Der Luhn-Algorithmus ist eine einfache Prüfsummenformel, mit der sich falsch eingegebene Zahlen erkennen lassen.

Gerade ist ein Stapel Kennungen auf deinem Schreibtisch eingetroffen.
Alle müssen den Luhn-Test bestehen, damit sichergestellt ist, dass sie echt sind.
Wenn eine durchfällt, wird sie als ungültig markiert. So lassen sich Fehler wie falsche Transaktionen oder fehlgeschlagene Kontoverifizierungen vermeiden.

Kannst du dafür sorgen, dass das richtig gemacht wird? Die Integrität vieler Dienste hängt von dir ab.
