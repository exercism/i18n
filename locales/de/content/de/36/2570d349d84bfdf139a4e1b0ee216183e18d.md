# Hinweise

## 1. Eine Karte aus einem Stapel entnehmen

- Array-Indizes beginnen bei `0`.
- [Diese Seite][access_array_elements_resource] enthält mehr Informationen dazu, wie du auf Array-Elemente zugreifst.

## 2. Eine Karte im Stapel austauschen

- Das Array ist eine veränderbare Struktur, du kannst seinen Inhalt jederzeit ändern.
- Ein Beispiel findest du [hier][change_array_elements_resource], im Abschnitt „Changing an Array Element“.

## 3. Eine Karte oben in den Stapel einfügen

- Es gibt eine [eingebaute][push_method_docs] Methode, um einen neuen Wert am Ende des Arrays hinzuzufügen.

## 4. Eine Karte aus dem Stapel entfernen

- Es gibt eine [eingebaute][splice_method_docs] Methode, mit der du unter anderem Elemente ab einer bestimmten Position entfernen kannst.

## 5. Die oberste Karte aus dem Stapel entfernen

- Es gibt eine [eingebaute][pop_method_docs] Methode, um das letzte Element aus dem Array zu entfernen.

## 6. Eine Karte unten in den Stapel einfügen

- Es gibt eine [eingebaute][unshift_method_docs] Methode, um einen neuen Wert am Anfang des Arrays hinzuzufügen.

## 7. Eine Karte unten aus dem Stapel entfernen

- Es gibt eine [eingebaute][shift_method_docs] Methode, um das erste Element aus dem Array zu entfernen.

## 8. Die Größe des Stapels prüfen

- Arrays haben eine [Eigenschaft][length_property_docs], über die du ihre Länge abrufen kannst.
