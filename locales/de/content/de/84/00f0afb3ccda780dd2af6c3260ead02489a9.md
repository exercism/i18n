# Einführung

Das Modul `IO` stellt Funktionen für die Ein- und Ausgabe bereit.

## Ausgabe

Um einen String auf die Standardausgabe zu schreiben, verwendest du `IO.puts`. `IO.puts` hängt immer eine neue Zeile an das Ende des Strings an. Wenn du das nicht möchtest, nimm stattdessen `IO.write`. Beide Funktionen geben bei Erfolg das Atom `:ok` zurück.

```elixir
IO.puts("Hi!")
# > Hi!
# => :ok
```

`IO.puts` eignet sich gut zum Schreiben von Strings, aber für nicht viel mehr. Wenn du ein Werkzeug zum Debuggen brauchst, mit dem du jeden Wert auf die Standardausgabe schreiben kannst, verwendest du stattdessen `IO.inspect`. `IO.inspect` gibt den übergebenen Wert unverändert zurück, sodass du es an jeder Stelle in deinem Code einfügen kannst. Es akzeptiert außerdem viele Optionen, zum Beispiel `:label`, mit denen du es von anderen `IO.inspect`-Aufrufen unterscheiden kannst.

## Eingabe

Um eine Zeile von der Standardeingabe zu lesen, verwendest du `IO.gets`. `IO.gets` akzeptiert ein Argument: einen String, den es als Eingabeaufforderung ausgibt. `IO.gets` fügt nach der Eingabeaufforderung keine neue Zeile hinzu. Füge sie selbst hinzu, wenn du sie brauchst.

```elixir
IO.gets("What's your name?\n")
# > What's your name?
# < Mary
# => "Mary\n"
```
