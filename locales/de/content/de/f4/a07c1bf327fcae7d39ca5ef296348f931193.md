# Einführung

Haxe hat zwei Zahlentypen: Ganzzahlen und Gleitkommazahlen:

- `Int`: Repräsentiert eine Ganzzahl.
- `Float`: Repräsentiert eine 64-Bit-Gleitkommazahl mit doppelter Genauigkeit.

```haxe
var integer:Int = 10;
var floating:Float = 5.4;
```

Jeder `Int` kann zwar überall dort verwendet werden, wo ein `Float` erwartet wird (das heißt, `Int` **ist zuweisbar** oder **unifiziert mit** `Float`), aber das Umgekehrte gilt nicht: Einem `Int` einen `Float` zuzuweisen, kann zu Genauigkeitsverlust führen und ist daher nicht implizit erlaubt.
