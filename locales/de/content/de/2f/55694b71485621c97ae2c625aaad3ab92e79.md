# Über

Perl v5 ist eine universelle höhere Programmiersprache, die Larry Wall erfunden hat und die 1987 erstmals veröffentlicht wurde.
Sie ist eine eklektische, interpretierte, prozedurale Sprache mit loser Typisierung.
Ihre Beliebtheit erreichte mit dem Aufstieg des World Wide Web ihren Höhepunkt, doch sie wird weiterhin breit eingesetzt, etwa in der Qualitätssicherung, der Automatisierung von IT-Infrastruktur, der Textverarbeitung, der Bioinformatik und der Entwicklung von Webanwendungen, um nur einige Bereiche zu nennen.
Sie ist sehr flexibel, aber diese Flexibilität kann bei der Wartung Folgekosten verursachen.

Perl hat außerdem:

- minimale eingebaute Objektunterstützung, aber interessante Objektorientierung von Drittanbietern
- First-Class-Funktionen
- Closures
- eine leistungsstarke eingebaute Engine für reguläre Ausdrücke
- das [Comprehensive Perl Archive Network (CPAN)](http://www.cpan.org), eine riesige Bibliothek von Modulen, die von Nutzern beigetragen wurden

Jedes bekannte Unix- und Unix-artige Betriebssystem wird mit Perl ausgeliefert.
