# Hinweise

## Allgemein

- Nutze den eingebauten [(verketteten) Listentyp][list].

## 1. Definiere eine Funktion, die eine leere Liste von Sprachen zurückgibt

- Die Funktion muss `[]` zurückgeben.

## 2. Definiere eine Funktion, die der Liste eine Sprache hinzufügt

- Mit `:` kannst du ein Element an den Anfang einer Liste setzen.

## 3. Definiere eine Funktion, die eine Sprache aus der Liste entfernt

- Haskell [bietet eine Funktion][tail], die eine Liste ohne das erste Element zurückgibt.

## 4. Definiere eine Funktion, die das erste Element der Liste zurückgibt

- Haskell [bietet eine Funktion][head], mit der du das erste Element einer Liste bekommst.

## 5. Definiere eine Funktion, die zurückgibt, wie viele Sprachen in der Liste sind

- Haskell [bietet eine Funktion][length], die die Länge einer Liste zählt.

## 6. Definiere eine Funktion, die feststellt, ob die Liste eine funktionale Sprache enthält

- Deine Funktion sollte einen booleschen Wert zurückgeben, der angibt, ob `"Haskell"` ein Element der Liste ist. 
  Haskell [bietet eine Funktion][elem], mit der du prüfen kannst, ob ein Element in einer Liste enthalten ist.
