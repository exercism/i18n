# Tests

## Alle Tests ausführen

Es gibt ein Raku-Skript mit der Endung `.rakutest`, das verwendet wird, um deine Lösung zu testen.
Du kannst die Tests mit folgendem Befehl ausführen:

`prove6`

Bevor du mit der Übung beginnst, sieht die Ausgabe wahrscheinlich ungefähr so aus:

```
# Failed test 'Say Hi!'
# at t/hello-world.rakutest line 6
# expected: "Hello, World!"
#  matcher: 'infix:<eq>'
#      got: "Goodbye, Mars!"
# You failed 1 test of 1
t/hello-world.rakutest ... Dubious, test returned 1
Failed 1/1 subtests
```

Du musst das Modul mit der Endung `.rakumod` im Verzeichnis `lib/` bearbeiten und eine Lösung schreiben, damit die Tests bestehen.
Sobald die Tests bestehen, sieht die Ausgabe des obigen Befehls wahrscheinlich ungefähr so aus:

```
t/hello-world.rakutest ... ok
All tests successful.
```

## Nach dem ersten Fehler abbrechen

Wenn du die Umgebungsvariable `RAKU_TEST_DIE_ON_FAIL` gesetzt hast, bricht der Test-Runner nach dem ersten Fehler ab. Zum Beispiel:

Unter Linux / OS X:

```bash
export RAKU_TEST_DIE_ON_FAIL=1
# now all the follow up runs will stop at the first failure
prove6
# until we do
unset RAKU_TEST_DIE_ON_FAIL
# or you can use it for one run like this:
RAKU_TEST_DIE_ON_FAIL=1 prove6
```

Oder unter Windows:

```
SET RAKU_TEST_DIE_ON_FAIL=1
REM now all the follow up runs will stop at the first failure
prove6
REM until we do
set RAKU_TEST_DIE_ON_FAIL=
```

Weitere Informationen findest du im
[Kapitel zum Testen in der Raku-Dokumentation](https://docs.raku.org/language/testing.html).

## Fehlersuche

```
===SORRY!===
Could not find JSON::Fast
```

Alle Module, die im Raku-Track verwendet werden, sind in Rakudo Star enthalten.
Wenn du beim Ausführen eines Tests eine Fehlermeldung wie die oben erhältst, musst du entweder sicherstellen, dass du die neueste Distribution von Rakudo Star hast, oder das Modul selbst mit einem Paketmanager installieren.
Wie du Module installierst, erfährst du in der [Raku-Dokumentation zu Modulen](https://docs.raku.org/language/modules#Looking_for_and_installing_modules.).
