# Anleitung

Lerne die Grundlagen zu internen Tabellen in ABAP.

Deine Klasse hat eine interne Tabelle mit dem Namen `initial_data`. Sie hat drei Spalten: `GROUP`, `NUMBER` und `DESCRIPTION`.

```abap
TYPES group TYPE c LENGTH 1.
TYPES: BEGIN OF initial_type,
         group       TYPE group,
         number      TYPE i,
         description TYPE string,
       END OF initial_type,
       initial_data TYPE STANDARD TABLE OF initial_type WITH EMPTY KEY.
```

## Schritt 1

Deine erste Aufgabe ist es, die Methode `fill_itab` zu vervollständigen und 6 Datensätze mit den folgenden Werten in diese Tabelle einzufügen:

| GROUP | NUMBER | DESCRIPTION |
| --- | ----------- | ----------- |
| A | 10 | Group A-2 |
| B | 5 | Group B |
| A | 6 | Group A-1 |
| C | 22 | Group C-1 |
| A | 13 | Group A-3 |
| C | 500 | Group C-2 |

## Schritt 2

Als Nächstes implementierst du die Methode `add_to_itab`, um einen Datensatz mit dem folgenden Wert am Ende der internen Tabelle hinzuzufügen:

| GROUP | NUMBER | DESCRIPTION |
| --- | ----------- | ----------- |
| A | 19 | Group A-4 |

## Schritt 3

Jetzt sortiere die interne Tabelle in der Methode `sort_itab` nach der Spalte `GROUP` in alphabetischer Reihenfolge und nach der Spalte `NUMBER` in absteigender Reihenfolge.

## Schritt 4

Suche in der Methode `search_itab` in der sortierten Tabelle und gib den Index des Datensatzes zurück, dessen Spalte `NUMBER` den Wert 6 hat.
