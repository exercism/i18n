# Über

In Haxe kann eine Klassenhierarchie mithilfe von _Vererbung_ definiert werden, wodurch eine abgeleitete Klasse (`Car`) das Verhalten und die Daten ihrer Elternklasse (`Vehicle`) erben kann.

In der Elternklasse kannst du:

- Methoden, die überschrieben werden können
- Abstrakte Methoden, die von den abgeleiteten Klassen implementiert werden müssen

```haxe
abstract class Vehicle {
  public function new() {}

  // Can be overridden
  public function drive() {
    // ...
  }

  // Must be implemented
  public abstract function getSpeed():Int;
}

class Car extends Vehicle {
  public function new() {
    super(); // Runs the parent class' constructor
  }

  public override function drive() {
    // ...
  }

  public function getSpeed():Int {
    // ...
  }
}
```

Wenn die Elternklasse einen Konstruktor hat, verwenden wir `super()`, um ihn aufzurufen:

```haxe
abstract class Vehicle {
  var wheels:Int;

  public function new(wheels:Int) {
    this.wheels = wheels
  }
}

class Car extends Vehicle {
  var color:String;

  public function new(wheels:Int, color:String) {
    super(wheels);
    this.color = color;
  }
}

```
