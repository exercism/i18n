# Einführung

Viele Arten von struct- und class-Membern (Ausnahme sind in erster Linie Felder) lassen sich mit der Syntax für Member mit Ausdruckskörper definieren. Einen Member über einen Ausdruck zu definieren, führt oft zu kürzerem und besser lesbarem Code als die klassischen Blöcke bzw. Anweisungen.

Methoden und schreibgeschützte Eigenschaften gehören zu den Membern, die sich mit einem Ausdruckskörper definieren lassen.

```csharp
public int Times3(int input) => input * 3;

public int Interesting => 1729;
```
