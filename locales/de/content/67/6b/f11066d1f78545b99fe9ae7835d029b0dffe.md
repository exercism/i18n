# Einführung

Ein Dictionary (`dict`) in Python ist eine Datenstruktur, die [hashbare][term-hashable] _Schlüssel_ mit _Werten_ verknüpft und in anderen Programmiersprachen als vergrößerbare [Hashtabelle][hashtable-wikipedia], Hashmap oder [assoziatives Array][associative-array] bekannt ist.
Dictionaries sind der einzige eingebaute [Mapping-Typ][mapping-types-dict] von Python.


`keys` müssen hashbar und innerhalb des Dictionaries eindeutig sein.
Zu den Schlüsseltypen können `number`s, `str`s oder `tuple`s (aus _unveränderlichen_ Werten) gehören.
Sie können keine _veränderlichen_ Datenstrukturen wie `list`s, `dict`s oder `set`s enthalten.
Seit Python 3.7 ist garantiert, dass die Schlüsselreihenfolge in einem `dict` der Reihenfolge entspricht, in der Einträge eingefügt wurden.

`values` können jeden Datentyp oder jede Struktur haben.
 Werte können außerdem _beliebig_ verschachtelt sein, sodass sie Listen von Listen, Unter-Dictionaries und andere benutzerdefinierte oder zusammengesetzte Datenstrukturen enthalten können.

Mit einem `key` kann ein Dictionary einen `value` in (im Durchschnitt) konstanter Zeit abrufen (_unabhängig von der Anzahl der Einträge_).
Verglichen mit der Suche nach einem Wert in einer `list` oder einem `array` (_ohne die `index`-Position zu kennen_), benötigt ein `dict` deutlich mehr Speicher, ist aber sehr schnell beim Abrufen.

Dictionaries sind besonders nützlich, wenn die Sammlung von Elementen groß ist und häufig darauf zugegriffen und sie aktualisiert werden muss.
