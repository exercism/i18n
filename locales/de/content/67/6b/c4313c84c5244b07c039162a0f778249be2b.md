# Anleitung

Dein Freund Johannes baut für sein Leben gern eigene Hardware (DIY, do it yourself). Gerade hat er einen Entsafter gebaut, und Johannes ist richtig begeistert davon. Johannes möchte jeden Morgen frischen Saft machen können.

Der Entsafter von Johannes lässt sich mit verschiedenen Füllmengen konfigurieren. Johannes ist nicht der beste Programmierer, aber er will ein Programm schreiben, das die Maschine steuert. Deshalb hat er dich um Hilfe gebeten.

## 1. Erstelle die Klasse `JuiceMaker`

Erstelle die Klasse `JuiceMaker`.
Die Klasse hat zwei Eigenschaften, die ihr auch übergeben werden:
- die `capacity` in Millilitern (als `Int`)
- ein `jug` (als `Jug`-Objekt), das den Krug darstellt, der mit dem Saft aus dem Entsafter gefüllt wird

## 2. Erweitere den Krug, wenn die Kapazität mehr als 1.000 Milliliter beträgt

Wenn die Kapazität größer als 1.000 Milliliter ist, muss der Krug erweitert werden, damit er den Saft fassen kann.
Passe die Klasse `JuiceMaker` so an, dass sie den Krug erweitert (indem sie dessen Funktion `extend` aufruft), wenn sie mit einer Kapazität von mehr als 1.000 Millilitern erstellt wird.

## 3. Installiere den Starter

Manche Modelle haben ein sehr kompliziertes Anlaufverfahren, dessen Durchführung viele Jahre dauern würde.
Glücklicherweise wurden spezielle Starter entwickelt, die das beschleunigen.

Füge Unterstützung für Modelle mit kompliziertem Anlaufverfahren hinzu, indem du einen weiteren Konstruktor hinzufügst, der zusätzlich ein `Starter`-Objekt entgegennimmt.
Der Konstruktor sollte außerdem dessen Funktion `install` aufrufen, damit sich der Starter im Entsafter installiert.

## 4. Füge eine Funktion `start` hinzu

Füge eine Funktion `start` hinzu, die eine Geschwindigkeit entgegennimmt.
Der Entsafter läuft dann mit dieser Geschwindigkeit weiter.

## 5. Füge eine Funktion `stop` hinzu

Füge eine Funktion `stop` hinzu, die den Entsafter anhält.

## 6. Füge eine Funktion `lightColor` hinzu

Die Maschine hat ein Licht, das anzeigt, mit welcher Geschwindigkeit sie läuft.
Die Farbe des Lichts hängt davon ab, mit welcher Geschwindigkeit sie läuft:

| Geschwindigkeit        | Farbe  |
|------------------------|--------|
| Off                    | red    |
| kleiner oder gleich 3  | green  |
| größer als 3           | yellow |

Füge eine Funktion `lightColor` hinzu, die die Farbe zurückgibt.

# 7. Mit einer gängigen Kapazität bauen

Nachdem Johannes viele Entsafter gebaut hat, fällt ihm auf, dass 1.500 Milliliter eine gängige Kapazität sind.
Um diese Konfiguration zu vereinfachen, implementiere die Hilfsfunktion `buildWithCommonCapacity`.
Die Funktion sollte außerhalb der Klasse `JuiceMaker` definiert werden.
