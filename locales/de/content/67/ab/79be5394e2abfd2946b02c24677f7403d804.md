# Über

Elm ist eine vollständig funktionale Sprache. Es gibt also keine Anweisungen, sondern nur Ausdrücke, und Funktionen bestehen immer aus genau einem Ausdruck.

Das fördert kleine, einfache Funktionen und ist grundsätzlich eine gute Sache. Manchmal sind Funktionen aber unvermeidlich komplexer, und dann brauchen wir einen Weg, sie trotzdem elegant zu schreiben.

Hier kommen `let`-Ausdrücke ins Spiel. Sie bestehen aus zwei Teilen: einem `let`-Abschnitt, in dem du so viele Definitionen anlegen kannst, wie du brauchst, und einem `in`-Abschnitt, einem einzelnen Ausdruck, der diese Definitionen verwenden kann.

In der Informatik ausgedrückt erzeugt `let` einen Gültigkeitsbereich, der lokal für den Ausdruck in `in` ist.

Der `let`-Ausdruck ist in einigen Situationen nützlich:

- Zum Vereinfachen von Ausdrücken
- Zum Benennen der Ergebnisse von Zwischenausdrücken
- Zum Aufteilen eines Ausdrucks in kleinere Teile, wenn er zu groß wird

In einem `let`-Ausdruck kannst du die meisten Dinge tun, auch Destrukturierung. Folgendes ist jedoch nicht erlaubt:

- Custom Types
- Type Alias
- Name Shadowing (du kannst einen Namen, der bereits im Gültigkeitsbereich liegt, nicht neu definieren oder wiederverwenden)

## Ausdrücke vereinfachen

Dieser Ausdruck addiert die Kuben von 3 Zahlen, aber er ist schwer zu lesen, und es wäre leicht, dass die Berechnung für die einzelnen Zahlen unterschiedlich ausfällt.

```elm
(a * a * a) + (b * b * b) + (c * c * c)
```

Wir können in einem `let`-Ausdruck eine Funktion `cube` definieren, um die Berechnung einfacher, ausdrucksstärker und sicherer zu machen. Diese Funktion könnte eine Typannotation haben, aber in idiomatischem Elm-Code ist das eher selten.

```elm
let
  cube x = x * x * x
in
  cube a + cube b + cube c
```

## Ergebnisse von Zwischenausdrücken benennen

Dieser Code definiert sideArea und topArea, um die Berechnung einfacher und ausdrucksstärker zu machen.

```elm
cylinderArea : Float -> Float -> Float
cylinderArea radius height =
    let
        sideArea = 2 * pi * radius * height
        topArea = pi * radius ^2
    in
        sideArea + 2 * topArea
```

## Einen großen Ausdruck aufteilen

Dieser Code erzeugt ein Anfangsmuster für das [Game of Life](https://playgameoflife.com/) (ein häufiges Beispiel für eine Programmierübung).

Es ist nicht wichtig, genau zu verstehen, wie es funktioniert, aber hoffentlich ist klar, dass es sehr groß wäre, wenn man es ohne `let` als einzelnen Ausdruck schreiben würde.

```elm
beginWithPattern : Size -> Padding -> Pattern -> GameOfLife
beginWithPattern minimumSize padding pattern =
    let
        size = calculateSize minimumSize padding pattern

        center = Size.center size

        centeredPattern = Pattern.centerAt center pattern

        dimensions = { width = size, height = size }

        deadCells = Matrix.create dimensions Dead
    in
    GameOfLife (bringPatternToLife deadCells centeredPattern)
```
