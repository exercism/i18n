# Tests

## Tests ausführen

Führe im Verzeichnis der Übung `exercism test` oder `eutest` aus.
Euphoria führt dann `t_<exercise>.e` gegen deine Lösung aus.

## Die Ausgabe lesen

Zu Beginn einer Übung hat deine Lösungsdatei keinen Rückgabewert und stürzt beim Ausführen ab.

```shell
C:\path\to\leap.ex:3
<0120>:: no value returned from function
end function
           ^

FAILURE: t_leap.e EUPHORIA error with status 1

Test results summary:
    FAIL: t_leap.e
Files (run: 1) (failed: 1) (0% success)
```

Das ist zu erwarten.
Implementiere die Funktion und führe die Tests dann erneut aus, um zu sehen, welche bestehen und welche fehlschlagen.

```shell
interpreting t_leap.e:
  passed: year not divisible by 4 in common year
  failed: year divisible by 2, not divisible by 4 in common year, expected: FALSE but got: TRUE
  failed: year divisible by 4, not divisible by 100 in leap year, expected: TRUE but got: FALSE
  ...
  9 tests run, 6 passed, 3 failed, 67% success
FAILURE: t_leap.e program died with status 1

Test results summary:
    FAIL: t_leap.e
Files (run: 1) (failed: 1) (0% success)
```

## Tests schrittweise durcharbeiten

Ein guter Einstieg ist es, alle Tests außer dem ersten in `t_<exercise>.e` auszukommentieren.

```euphoria
test_false("year not divisible by 4 in common year", leap(1800))
-- test_false("year divisible by 100 but not by 3 is still not a leap year", leap(1900))
-- test_false("year divisible by 2, not divisible by 4 in common year", leap(1970))
```

Arbeite sie nacheinander durch und kommentiere den nächsten Test aus, sobald der aktuelle besteht.
Wenn alle Tests bestehen, hast du die Übung abgeschlossen.
