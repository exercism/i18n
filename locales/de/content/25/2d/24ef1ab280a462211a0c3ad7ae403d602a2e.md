# Introduction

## Instanzvariablen

Objekte können ihren eigenen Zustand speichern, indem sie _Instanzvariablen_ setzen.
Diese Variablen leben innerhalb eines Objekts und werden normalerweise verwendet, um einen internen Zustand zu speichern.

Instanzvariablen beginnen immer mit einem `@`.
Du kannst eine neue Instanzvariable erstellen, indem du eine Variable setzt, die mit einem `@` beginnt.
Zum Beispiel:

```ruby
class Repeater
  def hear(something)
    # Save what's been heard into a new instance variable called @heard
    @heard = something
  end

  def repeat
    # Return the value of the instance variable
    @heard
  end
end

repeater = Repeater.new
repeater.hear("Hello, friend!")
print repeater.repeat # Prints "Hello, friend!"
```

Objekte legen ihren Anfangszustand normalerweise in einer `initialize`-Methode fest, die automatisch aufgerufen wird, wenn du `new` für eine Klasse aufrufst.

```ruby
class Airplane
  def initialize
    @wings = 2
  end

  def wings
    @wings
  end
end

plane = Airplane.new
plane.wings # returns 2
```

Die `initialize`-Methode kann auch Argumente entgegennehmen, sodass jede Instanz mit einem eigenen Zustand starten kann:

```ruby
class Suitcase
  def initialize(locked)
    @locked = locked
  end
end
```

Es ist gute Praxis, _Instanzvariablen_ als privat gegenüber externem Lesen und Schreiben zu betrachten.
Stattdessen definieren wir Methoden, um ihre Werte zu lesen und zu setzen.
Zum Beispiel:

```ruby
class Suitcase
  def initialize
    @locked = false
  end

  def locked? # Query methods should be named with a trailing `?`
    @locked
  end

  def lock! # Methods which mutate state should have trailing `!`
    @locked = true
  end
end

suitcase = Suitcase.new
suitcase.locked? # false
suitcase.lock!
suitcase.locked? # true
```

## Nil

[Nil][nil-dictionary] ist ein englisches Wort und bedeutet „nichts“ oder „null“.
In Ruby wird `nil` verwendet, um die _Abwesenheit_ eines Objekts auszudrücken.
In anderen Programmiersprachen spielen Werte wie `null` oder `none` eine ähnliche Rolle.

```ruby
# I do not have a favorite color
favorite_color = nil
```

Ruby gibt jeder Instanzvariable den Standardwert `nil`, wenn sie zum ersten Mal auftritt, bis ihr anderweitig ein Wert zugewiesen wird.

```ruby
print @favourite_color # prints nil
@favourite_color = "blue"
print @favourite_color # prints "blue"
```
