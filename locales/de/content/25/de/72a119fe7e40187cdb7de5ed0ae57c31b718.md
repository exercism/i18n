# Ergänzung zu den Anweisungen

## Register

| Register | Verwendung | Typ      | Beschreibung                     |
| -------- | ---------- | -------- | -------------------------------- |
| `$a0`    | Eingabe    | Ganzzahl | x                                |
| `$a1`    | Eingabe    | Ganzzahl | y                                |
| `$v0`    | Ausgabe    | Ganzzahl | erreichte Punkte                 |
| `$t0-9`  | temporär   | beliebig | dient der temporären Speicherung |
