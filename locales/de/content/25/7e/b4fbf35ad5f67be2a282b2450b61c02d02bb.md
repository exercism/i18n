# Anleitung

Als die Lisp-Aliens zum ersten Mal auf die Erde kamen, begegneten sie unzähligen seltsamen und wunderbaren Dingen, aber eine ihrer liebsten Entdeckungen waren die „Haustiere“. Und mal ehrlich: Welcher Alien würde nicht bei einem Welpen oder Kätzchen ins Schwärmen geraten?

Ludwig hat nach dem letzten Urlaub auf der Erde beschlossen, sich ein eigenes Haustier anzuschaffen! Das einzige Problem? Es gibt viel zu viele Möglichkeiten! Vielleicht könntest du ein Programm schreiben, das Ludwig dabei hilft, den nächsten kuscheligen Freund zu finden und zu versorgen?

## 1. Einen Kumpel aussuchen

Ludwig ist zwar fest entschlossen, sich ein Haustier zuzulegen, aber weiter ist Ludwig beim Nachdenken noch nicht gekommen. Der erste Schritt ist also zu entscheiden, was für ein Haustier es werden soll!

Ludwig möchte einen Kumpel finden, dessen Persönlichkeit zu Ludwigs eigener passt. Könntest du für Ludwig eine Funktion namens `pal-picker` schreiben, die ein Persönlichkeitsmerkmal (ein Keyword) entgegennimmt und den Typ des Haustiers (einen String) mit diesem Merkmal zurückgibt?

In diesem konkreten Fall:

- `:lazy` -> `"Cat"`
- `:energetic` -> `"Dog"`
- `:quiet` -> `"Fish"`
- `:hungry` -> `"Rabbit"`
- `:talkative` -> `"Bird"`

Bei anderen, unbekannten Persönlichkeiten sollte deine Funktion zu folgendem Ergebnis kommen: `"I don't know... A dragon?"`

```lisp
(pal-picker :quiet) ; => "Fish"
```

## 2. In ihrem natürlichen Lebensraum

Jetzt, wo Ludwig einen neuen Freund hat, braucht Ludwig einen Platz zum Wohnen! Kannst du Ludwig helfen, die richtige Größe für Bett / Aquarium / Käfig für das Haustier auszuwählen?

Dafür braucht Ludwig eine Funktion namens `habitat-fitter`, die aus dem Gewicht des Haustiers in Kilogramm (einer Ganzzahl) die passende Größe des Lebensraums (ein Keyword) auswählt.

Die Lebensräume, die die einzelnen Größen brauchen, sind:

- Mehr als oder genau 40kg -> `:massive`
- 20kg bis 39kg inklusive -> `:large`
- 10kg bis 19kg inklusive -> `:medium`
- 1kg bis 9kg inklusive -> `:small`
- Weniger als oder genau 0kg -> `:just-your-imagination`

```lisp
(habitat-fitter 42) ; => :MASSIVE
```

## 3. Und jetzt wird geschlemmt

Eine Sache, die alle irdischen Haustiere gemeinsam haben, ist ihr Bedürfnis nach Futter! Dieses Konzept ist Ludwig allerdings etwas fremd, denn Ludwig vergisst leicht, den Futternapf des Haustiers nachzufüllen.

Ludwig könnte eine einfache Funktion namens `feeding-time` gebrauchen, die Ludwig warnt, wenn der Napf nachgefüllt werden muss. Die Funktion nimmt einen Füllstand in Prozent (eine Ganzzahl) entgegen und gibt eine Nachricht in Form eines Strings zurück.

Wenn der Futterstand:

- über 20% liegt -> `"All is well."`
- 20% oder darunter liegt -> `"It's feeding time!"`

```lisp
(feeding-time 15) ; => "It's feeding time!"
```

## 4. Ein Verhaltenskodex

Nachdem all die Grundlagen geklärt sind, freut sich Ludwig darauf, aufregende Dinge wie „Streicheln“ und „Apportieren“ auszuprobieren. Allerdings eignet sich nicht jedes Haustier für diese Aktivitäten.

Ludwig hätte gern zwei Funktionen, `pet` und `play-fetch`, die den Typ des Haustiers (als String) entgegennehmen und entweder nichts oder eine Nachricht wie `"Maybe not with this pet..."` zurückgeben, wenn die Aktion nicht passt.

Gehe davon aus, dass nur `"Dog"` Apportieren spielt und dass alle Haustiere außer `"Fish"` gestreichelt werden können.

```lisp
(pet "Dog")         ; => NIL
(play-fetch "Fish") ; => "Maybe not with this pet..."
```
