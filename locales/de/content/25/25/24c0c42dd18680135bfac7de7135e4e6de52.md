# Tests ausführen

Um die Tests zu kompilieren und auszuführen, führe einfach Folgendes in deinem Übungsverzeichnis aus:
```bash
$ ponyc
$ ./exercise-name
```

(Ersetze `exercise-name` durch den Namen des Übungsverzeichnisses)

Das kompilierte Programm führt die Tests in seinem Main-Actor aus. Führe also einfach das Programm aus und sieh nach, ob deine Tests erfolgreich sind. Pony prüft den gesamten Code beim Kompilieren. Deshalb kann es sein, dass deine Tests erst kompilieren, wenn du den nötigen Code geschrieben hast. Du kannst Tests, die nicht kompilieren, auskommentieren, indem du jede Zeile mit `//` beginnst. Wenn du dann bereit bist, an diesem Test zu arbeiten, kannst du die Kommentarzeichen wieder entfernen.
