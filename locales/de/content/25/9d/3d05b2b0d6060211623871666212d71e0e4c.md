# Anleitung

Du zählst täglich, wie viele Vögel deinen Garten besuchen. Die Daten liegen als Array von Ganzzahlen vor, wobei **die heutige Anzahl an erster Stelle steht**.

## 1. Die heutige Anzahl

Definiere `today`, sodass es ein Array mit täglichen Anzahlen vom Stack nimmt und die heutige Anzahl zurückgibt, oder `f`, wenn das Array leer ist.

```factor
{ 2 5 1 } today .
! => 2

{ } today .
! => f
```

## 2. Die heutige Anzahl erhöhen

Definiere `increment-day-count`, sodass es ein neues Array zurückgibt, in dem die heutige Anzahl um eins erhöht ist. Wenn der Eingabewert leer ist, gib `{ 1 }` zurück.

```factor
{ 4 0 2 } increment-day-count .
! => { 5 0 2 }

{ } increment-day-count .
! => { 1 }
```

## 3. Gab es einen Tag ohne Vögel?

Definiere `has-day-without-birds?`, sodass es `t` zurückgibt, wenn an mindestens einem Tag null Vögel gezählt wurden, andernfalls `f`.

**Verwende Rekursion** statt `any?` oder anderer Sequenzwörter höherer Ordnung.

```factor
{ 2 0 4 } has-day-without-birds? .   ! => t
{ 3 8 1 5 } has-day-without-birds? . ! => f
```

## 4. Vögel insgesamt seit dem Start

Definiere `total`, sodass es die Summe aller Anzahlen zurückgibt.

**Verwende Rekursion** statt `sum`.

```factor
{ 4 0 9 0 5 } total .
! => 18
```

## 5. Tage mit viel Betrieb

Ein Tag mit viel Betrieb ist einer mit fünf oder mehr Vögeln. Definiere `busy-days`, sodass es die Anzahl der Tage mit viel Betrieb zurückgibt.

**Verwende Rekursion** statt `count`.

```factor
{ 4 5 0 0 6 } busy-days .
! => 2
```
