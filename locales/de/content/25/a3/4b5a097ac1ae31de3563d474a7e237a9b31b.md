## Tests ausführen

1. Gehe in das Stammverzeichnis deines PHP-Übungsverzeichnisses, also in `<EXERCISM_WORKSPACE>/php`.
   Um den Workspace von Exercism zu finden, führe Folgendes aus:

   ```shell
   exercism workspace
   ```

2. Installiere [PHPUnit], falls du es noch nicht hast.
3. Führe die Tests so aus:

   ```shell
   phpunit test_file.php
   ```

   Wenn du zum Beispiel die Tests für die Übung Hello World ausführen möchtest, führst du Folgendes aus:

   ```shell
   phpunit HelloWorldTest.php
   ```

[PHPUnit]: https://exercism.org/docs/tracks/php/installation#h-via-php-archive-phar
