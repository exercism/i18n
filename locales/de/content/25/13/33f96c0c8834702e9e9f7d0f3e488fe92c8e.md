# Anweisungen

In dieser Übung erstellst du Wetterberichte für einen lokalen Nachrichtensender.

## Wetterberichte erstellen

Du startest mit ein paar vorgegebenen Stub-Funktionen und dem folgenden Enum:

```rust
#[derive(Drop, Clone, PartialEq, Debug)]
pub enum WeatherCondition {
    Sunny,
    Rainy,
    Cloudy,
    Stormy
}
```

Du musst einen Wetterbericht in der Form `"Today is <CONDITION> with a temperature of <TEMPERATURE> degrees Celsius."` formatieren.
Außerdem musst du die Funktion implementieren, die die passenden Wetterbedingungen ausgibt.

Der folgende Ausschnitt zeigt zum Beispiel eine erwartete Ausgabe der Funktion `get_weather_report` für einen „regnerischen“ Tag.

```rust
get_weather_report(WeatherCondition::Rainy, "25")
// Returns: "Today is RAINY with a temperature of 25 degrees Celsius."
```

Und für einen „sonnigen“ Tag:

```rust
get_weather_report(WeatherCondition::Sunny, "30")
// Returns: "Today is SUNNY with a temperature of 30 degrees Celsius."
```
