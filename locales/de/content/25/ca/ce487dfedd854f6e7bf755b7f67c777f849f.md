# Über

Ein Rest-Parameter wird in einer Lambda-Liste durch das Lambda-Listen-Schlüsselwort `&rest` gekennzeichnet.
Dieser Parameter wird an einen Wert gebunden, der eine Liste aller Argumente ist, die der Aufrufer übergibt und die nicht von anderen Parametern belegt werden.

Mehrere Parametertypen lassen sich zwar mit anderen Parametertypen kombinieren (optionale Parameter und Schlüsselwortparameter), doch das kann problematisch werden und sollte mit Bedacht geschehen.
Siehe dazu den Abschnitt [„Verschiedene Parametertypen mischen“][pcl-function] in Practical Common Lisp.

[pcl-function]: http://www.gigamonkeys.com/book/functions.html
