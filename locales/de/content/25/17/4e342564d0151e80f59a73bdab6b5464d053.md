# Einführung in die Bitmanipulation

Java bietet Operatoren, mit denen du die Bits eines `byte`, `short`, `int`, `long` oder `char` bearbeiten kannst.

## Schiebeoperatoren

Mit `<<` verschiebst du Bits nach links und mit `>>` nach rechts.

```java
// Shift two places to the left
0b0000_1011 << 2;
// # => 0b0010_1100

// Shift two places to the right
0b0000_1011 >> 2;
// # => 0b0000_0010
```

Der Operator `<<` fügt auf der rechten Seite immer 0en ein.
Der Operator `>>` dagegen fügt dasselbe Bit ein wie das am weitesten links stehende Bit (1, wenn die Zahl negativ ist, und 0, wenn sie positiv ist).

```java
// Shift 2 places to the right preserves the sign
// This is a negative value, whose binary representation is
// 1000_0000_0000_0000_0000_0000_0010_0110
int value = -0x7FFFFFDA;

// Shift two places to the right, preserving the sign bit
value >> 2;
// # => 1110_0000_0000_0000_0000_0000_0000_1001
```

Verwende stattdessen `>>>`, wenn beim Verschieben nach rechts 0en eingefügt werden sollen.

```java
// Shift two places to the right, inserting 0s on the left
value >>> 2;
// # => 0010_0000_0000_0000_0000_0000_0000_1001
```

## Bitweise Operationen

### Bitweises UND

Der bitweise UND-Operator (`&`) nimmt zwei Werte und führt für jedes Bit ein UND aus.
Er vergleicht jedes Bit des ersten Werts mit dem Bit an derselben Position des zweiten Werts.
Sind beide 1, dann ist das Bit des Ergebnisses 1.
Andernfalls ist das Bit des Ergebnisses 0.

```java
0b0110_0101 & 0b0011_1100;
// # => 0b0010_0100
```

### Bitweises ODER

Der bitweise ODER-Operator (`|`) nimmt zwei Werte und führt für jedes Bit ein ODER aus.
Er vergleicht jedes Bit des ersten Werts mit dem Bit an derselben Position des zweiten Werts.
Ist eines der beiden Bits 1, ist das Bit des Ergebnisses 1.
Andernfalls ist es 0.

```java
0b0110_0101 | 0b0011_1100;
// # => 0b0111_1101
```

### Bitweises XOR

Der bitweise XOR-Operator (`^`) führt für zwei Werte ein bitweises XOR aus.
Wie die bitweisen Operatoren UND und ODER vergleicht er jedes Bit des ersten Werts mit dem Bit an derselben Position des zweiten Werts.
Ist nur eines von beiden 1, ist das resultierende Bit 1.
Andernfalls ist es 0.

```java
0b0110_0101 ^ 0b0011_1100;
// # => 0b0101_1001
```

### Bitweises NICHT(`~`)

Zuletzt: Der bitweise NICHT-Operator (`~`) kehrt jedes Bit um.
Anders als die vorherigen Operatoren ist dies ein unärer Operator, der nur auf einen Wert wirkt.

```java
~0b0110_0101;
// # => 0b1001_1010
```
