# Über

Ein [Tupel](https://docs.microsoft.com/en-us/dotnet/fsharp/language-reference/tuples) ist eine _unveränderliche_ Gruppierung unbenannter, aber geordneter Werte.
Tupel können jeden (oder mehrere) Datentyp(en) enthalten, auch andere Tupel.

Tupel werden als kommagetrennte Werte zwischen den Zeichen `(` und `)` definiert: `(<element_1>, ... , <element_n>)`.

```fsharp
("one", 2) // Tuple pair (2 values)
("one", 2, true) // Tuple triplet (3 values)
```

Nur Tupel mit derselben Länge und denselben Typen (in derselben Reihenfolge) können verglichen werden.
Tupel haben strukturelle Gleichheit. Das heißt, sie sind _nur_ dann gleich, wenn alle ihre Werte gleich sind.

```fsharp
(1, 2) = (1, 2) // Same length, same types, same values, same order
// => true

(1, 2) = (2, 1) // Same length, same types, same values, different order
// => false

(1, 2) = (1, "2") // Same length, different types
// compiler error

(1, 2) = (1, 2, 3) // Different length
// compiler error
```

Es gibt [drei Möglichkeiten, Werte aus einem Tupel zu extrahieren](https://docs.microsoft.com/en-us/dotnet/fsharp/language-reference/tuples#obtaining-individual-values):

- Die Funktionen `fst` und `snd`
- Tupel-Dekonstruktion
- Pattern Matching

```fsharp
let person = ("Jordan", 170)

// Option 1: fst/snd
let name1 = fst person
let length1 = snd person

// Option 2: deconstruction
let (name2, length2) = person

// Option 3: pattern matching
match person with
| name3, length3 -> printf "%s: %d" name3 length3
```

~~~~exercism/note
Technisch gesehen kannst du auf den Wert eines Tupels über seine Eigenschaften `.Item1`, `.Item2`, ... zugreifen, aber das ist nicht empfehlenswert und führt zu einer Compiler-Warnung.
~~~~

## Wichtige Punkte zu Tupeln

Diese wichtigen Dinge solltest du über Tupel wissen:

- Eine konkrete Instanz eines Tupeltyps ist ein einzelnes Objekt, ähnlich wie etwa ein Array mit zwei Elementen in C#. Wenn du sie mit Funktionen verwendest, zählen sie als ein einzelner Parameter. Die einzige Ausnahme ist der Aufruf von Nicht-F#-Code mit mehreren Parametern. In diesem Fall übergibst du ein Tupel, und seine Werte werden automatisch in die entsprechenden Parameterwerte entpackt.
- Tupeltypen können keine expliziten Namen erhalten. Der „Name“ des Tupeltyps ergibt sich aus der Kombination der Typen, die miteinander multipliziert werden.
- Das Komma ist das entscheidende Symbol, das Tupel definiert, nicht die Klammern. Du kannst Tupel auch ohne die Klammern definieren, was allerdings manchmal verwirrend sein kann. Wenn du in F# ein Komma siehst, ist es wahrscheinlich Teil eines Tupels.
- Tupel können als Argumente von Funktionen und als Rückgabewerte von Funktionen verwendet werden.
