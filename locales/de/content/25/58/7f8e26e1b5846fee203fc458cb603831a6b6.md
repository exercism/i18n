# Anweisungen

Du arbeitest mit einem Webentwicklungsteam zusammen, um eine Website für ein lokales Basketballteam zu pflegen. Das Webentwicklungsteam ist mit Elixir weniger vertraut und bittet um eine Funktion, mit der sich Daten aus einer Reihe verschachtelter Maps extrahieren lassen, um die schnelle Entwicklung zu erleichtern.

## 1. Daten aus einer verschachtelten Map-Struktur extrahieren

Implementiere die Funktion `extract_from_path/2`, die zwei Argumente entgegennimmt:

- `data`: eine verschachtelte Map-Struktur mit Daten über das Basketballteam.
- `path`: ein String, der aus durch Punkte getrennten Schlüsseln besteht, um den Wert zu erhalten, der dem letzten Schlüssel zugeordnet ist.

Wenn der Wert oder der Schlüssel an irgendeiner Stelle im Pfad nicht existiert, gib `nil` zurück

```elixir
data = %{
  "team_mascot" => %{
    "animal" => "bear",
    "actor" => %{
      "first_name" => "Noel"
    }
  }
}

BasketballWebsite.extract_from_path(data, "team_mascot.animal")
# => "bear"
BasketballWebsite.extract_from_path(data, "team_mascot.colors")
# => nil
```

Verwende das _Access Behaviour_, wenn du diese Funktion implementierst.

Verwende keine Funktionen des `Map`- oder `Kernel`-Moduls, um mit der verschachtelten Map-Datenstruktur zu arbeiten.

## 2. Mit eingebauten Funktionen refaktorieren

Dein Kollege, der deinen Code überprüft, erzählt dir von einer Funktion des `Kernel`-Moduls, die etwas sehr Ähnliches macht wie deine Implementierung.

Implementiere `get_in_path/2` so, dass sie diese Funktion des `Kernel`-Moduls verwendet.

Die erwarteten Argumente sind dieselben wie in Teil 1.

```elixir
BasketballWebsite.get_in_path(data, "team_mascot.actor.first_name")
# => "Noel"
```
