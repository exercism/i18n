# Einführung

## Arrays

Arrays in PHP sind geordnete Maps.
Eine Map ist eine Datenstruktur, die einen Schlüssel einem Wert zuordnet.
Arrays sind vielseitig und können als lineares Array (wie in `C` oder `Java`), als Liste [Vektor], als Hashtabelle, als Wörterbuch, als Sammlung, als Stack oder als Warteschlange behandelt werden.

Ein Schlüssel ist optional, aber wenn er angegeben wird, muss er vom Typ `int` oder `string` sein.
Wenn kein Schlüssel angegeben wird, verwendet PHP standardmäßig ganzzahlige Schlüssel in aufsteigender Reihenfolge, beginnend bei `0`.

```php
$no_keys = ["my", "first", "array"];
$integer_keys = [0 => "my", 1 => "first", 2 => "array"];

$no_keys == $integer_keys // => equal returns true
$no_keys === $integer_keys // => strictly equal returns true
```

Ein Array kann Werte aller Typen speichern.
Jeder Wert kann einen anderen Typ haben.

### Arrays verwenden

Arrays können als Literal deklariert werden (im Code geschrieben, wie oben) oder mit Funktionen erstellt und bearbeitet werden.
Mit dem Index-Operator kannst du auf Werte zugreifen, sie zuweisen oder anhängen:

```php
$prime_numbers = [2, 3, 5, 6];

$prime_numbers[3] = 7; // replace 6 with 7

$prime_numbers[] = 11; // array now contains [2, 3, 5, 7, 11]
```

## Argumente mit variabler Länge

Du kannst Funktionsargumente so definieren, dass die Funktion beliebig viele Argumente entgegennimmt:

```php
<?php

function actOnItems(...$items) {
  // $items is an array containing 0 or more values
  // used to call the function.
}

actOnItems(1, 2, 3, 4); // $items => [1, 2, 3, 4]
```
