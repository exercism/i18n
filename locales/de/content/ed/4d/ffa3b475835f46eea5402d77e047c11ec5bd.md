# Anleitung

Deine Streichgruppe gibt ein Konzert, und jemand muss das Programm schreiben.

Alle fünf Aufgaben gehören in die Klasse `PROGRAMME_NOTES`.

## 1. Benenne das Stück und den Komponisten

Setze zuerst das Stück, dann ` by `, dann den Komponisten.

```sather
PROGRAMME_NOTES::full_title("Nocturne", "Chopin")
-- => "Nocturne by Chopin"
```

## 2. Miss eine Zeile

Der Drucker muss wissen, wie lang eine Zeile ist.

```sather
PROGRAMME_NOTES::title_length("Nocturne")
-- => 8
```

## 3. Die ersten Buchstaben

Gegeben sind ein Titel und eine Zahl. Gib so viele Buchstaben vom Anfang zurück.

```sather
PROGRAMME_NOTES::opening_letters("Nocturne", 3)
-- => "Noc"
```

## 4. Die letzten Buchstaben

Dasselbe, vom Ende gezählt.

```sather
PROGRAMME_NOTES::closing_letters("Nocturne", 4)
-- => "urne"
```

## 5. Kürze einen langen Titel

Titel, die nicht passen, werden auf ihre ersten sechs Buchstaben gekürzt, gefolgt von drei Punkten.

```sather
PROGRAMME_NOTES::short_title("Nocturne in E flat")
-- => "Noctur..."
```
