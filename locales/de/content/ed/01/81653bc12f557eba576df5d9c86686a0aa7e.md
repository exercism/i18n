# Anweisungen

Du steckst einen Wanderweg durch den Busch ab. Die Entfernungen und die
Sichtungen liegen beide als Sequenzen vor, sind also beide Iteratoren.

Alle vier kommen in die Klasse `BUSH_WALK`. Jede von ihnen ist ein Iterator,
deshalb endet jeder Name mit `!`.

## 1. Die Markierungen

`markers!` nimmt einen Abstand in Metern und eine Anzahl und gibt die
Entfernung jedes Markers vom Start zurück.

```sather
loop
   #OUT + BUSH_WALK::markers!(100, 3) + " ";
end;
-- 100 200 300
```

Eine Anzahl von null ergibt gar nichts.

## 2. Bis der Wanderweg endet

`until_end!` nimmt die Sichtungen entlang des Wanderwegs und gibt sie eine
nach der anderen zurück, wobei es stoppt, wenn es auf `"end"` trifft. Das
`"end"` selbst wird nicht zurückgegeben.

```sather
loop
   #OUT + BUSH_WALK::until_end!(|"gum", "wattle", "end", "banksia"|) + " ";
end;
-- gum wattle
```

Wenn es kein `"end"` gibt, gibt es alles zurück.

## 3. Nur die Vögel

`birds!` nimmt die Sichtungen und gibt nur die zurück, die mit einem
Großbuchstaben beginnen, denn so schreibt diese Zählung Vögel auf.

```sather
loop
   #OUT + BUSH_WALK::birds!(|"gum", "Emu", "wattle", "Galah"|) + " ";
end;
-- Emu Galah
```

## 4. Nummeriert

`numbered!` nimmt die Sichtungen und gibt jede mit ihrer Position davor
zurück, gezählt ab eins.

```sather
loop
   #OUT + BUSH_WALK::numbered!(|"gum", "Emu"|) + " ";
end;
-- 1. gum 2. Emu
```
