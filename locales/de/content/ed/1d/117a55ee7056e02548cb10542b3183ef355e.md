# Einführung

Funktionen sind in Elixir Bürger erster Klasse. Das bedeutet:

- Benannte und anonyme Funktionen können Variablen zugewiesen werden.
- Benannte und anonyme Funktionen können wie Daten weitergegeben werden, als Argumente und als Rückgabewerte.
- Anonyme Funktionen können dynamisch erzeugt werden.

Anonyme Funktionen haben, im Gegensatz zu benannten Funktionen, keine statische Referenz, über die man sie erreichen könnte. Sie sind nur verfügbar, wenn sie einer Variablen zugewiesen oder sofort aufgerufen werden.

Wir könnten anonyme Funktionen verwenden, um:

- Daten mit lexikalischem Gültigkeitsbereich zu verbergen (auch als Closure bekannt).
- Funktionen zur Laufzeit dynamisch zu erzeugen.

Anonyme Funktionen beginnen mit dem reservierten Wort `fn`, die Argumente werden mit dem Token `->` vom Funktionskörper getrennt, und sie enden mit einem `end`. Wie bei benannten Funktionen wird der letzte Ausdruck der Funktion _implizit_ an die aufrufende Funktion _zurückgegeben_.

Um eine Funktionsreferenz aufzurufen, musst du einen `.` zwischen die Referenzvariable und die Liste der Argumente setzen:

```elixir
function_variable = fn param ->
  param + 1
end

function_variable.(1)
# => 2
```

Du kannst sogar die Kurzform der Capture-Notation verwenden, um das knapper zu schreiben:

```elixir
variable = &(&1 + 1)

variable.(1)
# => 2
```
