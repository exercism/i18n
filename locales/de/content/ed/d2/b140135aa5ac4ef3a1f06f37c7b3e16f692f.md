# Überblick

Eine [switch-Anweisung][switch] ermöglicht es dir, einen Wert mit mehreren möglichen passenden Werten zu vergleichen.
Damit schreibst du übersichtlicheren Code als mit mehreren `else-if`-Anweisungen.
Eine switch-Anweisung beginnt mit dem Schlüsselwort `switch`, auf das der zu vergleichende Wert folgt.
Danach definierst du die Fälle mit dem Schlüsselwort `case`, auf das der Wert folgt, mit dem verglichen wird.
Mit dem Schlüsselwort `default` definierst du den Standardfall, wenn keiner der Fälle passt.
Wie `else-if`-Anweisungen führen auch `switch`-Anweisungen nur den Block aus, der zum ersten passenden Fall gehört.

```swift
switch value {
case 1:
    print("One")
case 2:
    print("Two")
default:
    print("Other")
}
```

Schauen wir uns das folgende Beispiel an:

```swift
if str == "apple" {
    print("Let's bake an apple crumble")
} else if str == "lemon" {
    print("Let's bake a lemon meringue pie!")
} else if str == "peach" {
    print("Let's bake a peach pie!")
} else {
    print("Let's buy ice cream.")
}
```

Das lässt sich auch so schreiben:

```swift
switch str {
case "apple":
    print("Let's bake an apple crumble")
case "lemon":
    print("Let's bake a lemon meringue pie!")
case "peach":
    print("Let's bake a peach pie!")
default:
    print("Let's buy ice cream.")
}
```

[switch]: https://docs.swift.org/swift-book/documentation/the-swift-programming-language/controlflow/#Switch
