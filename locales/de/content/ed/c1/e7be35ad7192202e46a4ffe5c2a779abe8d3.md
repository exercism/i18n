# Einführung

Der gesamte Common-Lisp-Code besteht aus S-Ausdrücken (symbolischen Ausdrücken). Kurz heißen sie Sexprs. Jeder Sexpr ist entweder ein Atom oder ein Cons. Wenn S-Ausdrücke ausgewertet werden, geben sie automatisch einen Wert zurück, der an die Stelle des Ausdrucks tritt. Wenn du deine eigenen Funktionen schreibst (mit `defun`), wird der letzte Wert im Rumpf des `defun` automatisch zurückgegeben:

```lisp
;; Defining a new function
(defun gimme-foo () 'foo)
;; Calling the function as an S-Expression
(gimme-foo) ; => FOO
```
