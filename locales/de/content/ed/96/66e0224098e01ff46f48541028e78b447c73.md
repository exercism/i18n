# Über

[Clojure](http://clojure.org) ist eine dynamische Programmiersprache für die Java Virtual Machine (JVM).
Clojure wurde als Allzwecksprache entworfen und verbindet die Zugänglichkeit einer Skriptsprache mit einer robusten Infrastruktur für Multithread-Programmierung.

Clojure ist in erster Linie eine funktionale Programmiersprache und bietet einen reichen Satz unveränderlicher, persistenter [Datenstrukturen](http://clojure.org/data_structures).

Clojure ist Open Source, und Informationen darüber, wie du zur Sprache beitragen kannst, [findest du hier](http://clojure.org/contributing).

Rich Hickey, der Schöpfer von Clojure, wollte ein modernes Lisp für die funktionale Programmierung, das symbiotisch mit der etablierten Java-Plattform zusammenarbeitet und auf Nebenläufigkeit ausgelegt ist. So entstand Clojure.

Hier sind ein paar Zitate, die die Ziele von Clojure veranschaulichen:

* _Gutes Design bedeutet nicht, große Pläne zu machen, sondern die Dinge auseinanderzunehmen._
* _Beim Programmieren geht es nicht ums Tippen ... sondern ums Denken._
