# Die Tests ausführen

## Eine Übung herunterladen

Mit der [Exercism CLI][cli] lädst du die Übung herunter, an der du arbeiten möchtest.

```sh
exercism download --track=dart --exercise=hello-world
```

Wechsle dann in das Verzeichnis der Übung.

```sh
cd /path/to/exercism/dart/hello-world
```

## Abhängigkeiten installieren

Bevor du die Tests ausführst, lädst du die Abhängigkeiten der Übung herunter.

```sh
dart pub get
```

## Die Tests ausführen

```sh
dart test
```

## Testergebnisse verstehen

`dart test` verwendet standardmäßig den kompakten Reporter und zeigt in einer einzigen Zeile fortlaufend an, wie viele Tests bestanden, übersprungen und fehlgeschlagen sind.

```sh
$ dart test
00:00 +1 -1: test/binary_search_test.dart: finds a value in the middle of an array [E]
  Expected: <3>
    Actual: <0>

  package:matcher                    expect
  test/binary_search_test.dart 13:5  main.<fn>


To run this test again: dart test test/binary_search_test.dart -p vm --plain-name 'finds a value in the middle of an array'
00:00 +1 ~9 -1: Some tests failed.
```

- `+1`: 1 Test bestanden
- `~9`: 9 Tests übersprungen
- `-1`: 1 Test fehlgeschlagen

## Die Tests durcharbeiten

Die meisten Übungen haben mehrere Tests, von denen standardmäßig alle bis auf den ersten übersprungen werden.

```dart
void main() {
  final twoFer = TwoFer();

  group('TwoFer', () {
    test('no name given', () {
      final result = twoFer.statement();
      expect(result, equals('One for you, one for me.'));
    }, skip: false);

    test('a name given', () {
      final result = twoFer.statement('Alice');
      expect(result, equals('One for Alice, one for me.'));
    }, skip: true);

    test('another name given', () {
      final result = twoFer.statement('Bob');
      expect(result, equals('One for Bob, one for me.'));
    }, skip: true);
  });
}
```

Um die Tests nacheinander durchzuarbeiten, änderst du bei jedem Test `skip: true` in `skip: false`, während du vorangehst. Alternativ kannst du alle Tests auf einmal ausführen, ohne die Datei zu bearbeiten.

```sh
dart test --run-skipped
```

Beim Einreichen werden alle Tests vom Online-Test-Runner ausgeführt, auch die übersprungenen.

## Den Fehler „Could not find a command named frontend_server.dart.snapshot“ behandeln

Angenommen, du hast eine Übung bereits gelöst und eingereicht und kehrst nach einer Weile zu ihr zurück. Beim Testen kann dir dann dieser Fehler begegnen:

```sh
$ dart test
...
Could not find a command named "/path/to/frontend_server.dart.snapshot".
```

Die [Lösung][solution] ist, die Datei `pubspec.lock` zu löschen. Führe danach den dart-Befehl erneut aus.
