# Einführung

Mit der Array-Destrukturierung in JavaScript kannst du Werte aus einem Array entnehmen und einzelnen Variablen zuweisen, und das auf sehr kompakte Weise.

Im folgenden Beispiel wird jeder Wert im Array `numberOfMoons` dem zugehörigen Planeten zugewiesen:

```javascript
const numberOfMoons = [0, 2, 14];
const [venus, mars, neptune] = numberOfMoons;

neptune;
// => 14
```
