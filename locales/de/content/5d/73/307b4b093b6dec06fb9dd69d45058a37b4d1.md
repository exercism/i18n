# Einführung

## Zeit

Das Modul `Time` wird verwendet, um menschenlesbare Datums- und Zeitangaben anzuzeigen.
Auch wenn es technisch möglich ist, Zeiten mit `Time` zu bearbeiten, gibt es Elm-Community-Pakete, die für diese Aufgabe viel besser geeignet sind, wie zum Beispiel [`justinmimbs/date`][date] oder [`CoderDennis/elm-time-format`][elm-time-format].

### Posix

Zeiten werden durch den opaken Typ `Posix` dargestellt, der die Unix-Epochenzeit kapselt, also die Anzahl der Millisekunden, die seit dem 1. Januar 1970 um Mitternacht UTC vergangen sind.
Ein `Posix` ist ein eindeutiger Wert, der sich nicht je nach Zeitzone ändert, und daher gut geeignet, um Zeitwerte zu speichern.
In einer Elm-Anwendung werden `Posix`-Zeiten normalerweise von externen Quellen bereitgestellt, etwa vom Browser.

Es ist möglich, ein `Posix` mit den folgenden Funktionen in eine Anzahl von Millisekunden umzuwandeln und umgekehrt:

```elm
posixToMillis : Posix -> Int
millisToPosix : Int -> Posix
```

### Zeitzonen

In unserem Alltag lesen wir Menschen normalerweise kein `Posix`. Stattdessen bevorzugen wir die lokale Zeit, die von unserem Standort auf der Erde und den lokalen Sommerzeitregeln abhängt.
In Elm wird diese Information im opaken Typ `Zone` kodiert, der normalerweise vom Browser bereitgestellt wird.

Es gibt eine spezielle `Zone`, die immer verfügbar ist:

```elm
utc : Zone
```

### Menschenlesbare Zeiten

Mit einem `Posix` und einer `Zone` haben wir genug Informationen, um die lokale Zeit in beliebigem Detailgrad anzuzeigen.
Hier ist eine Liste der Funktionen, die dafür verwendet werden können:

```elm
toYear : Zone -> Posix -> Int
toMonth : Zone -> Posix -> Month
toDay : Zone -> Posix -> Int
toWeekday : Zone -> Posix -> Weekday
toHour : Zone -> Posix -> Int
toMinute : Zone -> Posix -> Int
toSecond : Zone -> Posix -> Int
toMillis : Zone -> Posix -> Int
```

Du hast sicher schon zwei weitere benutzerdefinierte Typen von `Time` entdeckt:

```elm
type Month = Jan | Feb | Mar | Apr | May | Jun | Jul | Aug | Sep | Oct | Nov | Dec
type Weekday = Mon | Tue | Wed | Thu | Fri | Sat | Sun
```

Es bleibt den Nutzern überlassen, diese benutzerdefinierten Typen in menschenlesbare Werte umzuwandeln.
