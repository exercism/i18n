# Einführung

Die Konzepte Kovarianz und Kontravarianz in PHP sind wichtig, weil PHP darauf achtet, dass diese Regeln beim Erweitern von Klassen oder Interfaces eingehalten werden.

Kovarianz erhält die Beziehung zwischen zwei Typen, während Kontravarianz diese Beziehung umkehrt. Kurz gesagt bedeutet das: Wenn du Klassen erweiterst und Funktionen überschreibst, darfst du für die Parameter deiner Methode spezifischere oder weniger spezifische Typen erlauben, und aus der Methode darfst du weniger spezifische oder spezifischere Typen zurückgeben.

## Beispiele

Schau dir die folgende Klasse an:

```php
class Calculator 
{
    public function add(int $x, int $y): int 
    {
        return $x + $y;
    }
}
```

Wenn wir die Klasse erweitern, können wir mehr Parametertypen erlauben als ursprünglich deklariert, aber wir können nichts anderes als die ursprünglichen Rückgabetypen zurückgeben.

```php
class Floatulator extends Calculator
{
    // This is valid
    public function add(int|float $x, int|float $y): int 
    {
        return (int)($x + $y);
    }
}
```

Die folgende erweiterte Klasse ist nicht gültig, weil zusätzliche oder breitere Rückgabetypen nicht erlaubt sind:

```php
class BrokenCalculator extends Calculator 
{
    // This is invalid and will not compile
    public function add(int|float $x, int|float $y): int|float{
        return $x + $y;
    }
}
```
