# Einführung

Ein Methodenparameter kann optional gemacht werden, indem ihm ein Standardwert zugewiesen wird. Beim Aufruf einer Methode mit optionalen Parametern muss der Aufrufer keinen Wert dafür übergeben. Wird für einen optionalen Parameter kein Wert übergeben, wird sein Standardwert verwendet.

Optionale Parameter _müssen_ am Ende der Parameterliste stehen; nach ihnen dürfen keine nicht-optionalen Parameter folgen.

```csharp
class Card
{
    static string NewYear(int year = 2020)
    {
        return $"Happy {year}!";
    }
}

Card.NewYear();     // => "Happy 2020!"
Card.NewYear(1999); // => "Happy 1999!"
```
