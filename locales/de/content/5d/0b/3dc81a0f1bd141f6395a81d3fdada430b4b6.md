# Hinweise

## Allgemeines

- Die `string`-Klasse bietet viele nützliche [integrierte Methoden][methods].

## 1. Nachricht aus einer Logzeile ermitteln

- Es gibt [mehrere Methoden][index-of], um den Index zu finden, an dem ein Text in einem `string` vorkommt.
- Das Entfernen von Leerzeichen ist [integriert][trim].

## 2. Log-Level aus einer Logzeile ermitteln

- Ein `string` kann mit einer [integrierten Methode][to-lower] in Kleinbuchstaben umgewandelt werden.

## 3. Eine Logzeile neu formatieren

- Es gibt einen [integrierten Operator][plus-operator], um Strings zu verketten.
