# Ergänzung der Anweisungen

## Register

| Register | Verwendung   | Typ     | Beschreibung                    |
| -------- | ------------ | ------- | ------------------------------- |
| `$a0`    | Eingabe      | Adresse | nullterminierte Phrase          |
| `$a1`    | Eingabe/Ausgabe | Adresse | nullterminierter Ergebnis-String |
| `$t0-9`  | temporär     | beliebig | zur Zwischenspeicherung         |
