# Einführung

Ruby ist eine dynamische [objektorientierte Sprache][object-oriented-programming].
Alles in Ruby ist ein [Objekt][object].

In Ruby gibt es zwei Hauptwege, Objekten Namen zuzuweisen: über Variablen oder über Konstanten.
Variablen werden immer in [Snake Case][snake-case] geschrieben.
Eine Variable kann im Laufe ihres Lebens auf verschiedene Objekte verweisen.
Zum Beispiel kann `my_first_variable` mit dem `=`-Operator viele Male definiert und neu definiert werden:

```ruby
my_first_variable = 1
my_first_variable = "Some string"
my_first_variable = SomeComplexObject.new
```

Konstanten dagegen sind dafür gedacht, nur einmal zugewiesen zu werden.
Sie müssen mit Großbuchstaben beginnen und werden normalerweise komplett in Großbuchstaben geschrieben, wobei die Wörter durch Unterstriche getrennt sind.

Zum Beispiel:

```ruby
MY_FIRST_CONSTANT = 10

# Redefining not allowed
# MY_FIRST_CONSTANT = "Some String"
```

Ruby ist in Klassen organisiert.
Klassen werden mit dem Schlüsselwort `class` definiert, gefolgt vom Namen der Klasse.
Objekte werden im Allgemeinen erstellt, indem man Klassen mit der Methode `.new` instanziiert.

Zum Beispiel:

```ruby
# Define the class
class Calculator
  #...
end

# Create an instance of it and assign it to a variable
my_first_calc = Calculator.new
```

Funktionseinheiten werden in Methoden gekapselt, ähnlich wie _Funktionen_ in anderen Sprachen.
Eine Methode kann optional mit Positionsargumenten und/oder Schlüsselwortargumenten definiert werden, die mit der `:`-Syntax definiert und aufgerufen werden.
Methoden geben entweder implizit das Ergebnis der zuletzt ausgewerteten Anweisung zurück oder können über das Schlüsselwort `return` explizit ein Objekt zurückgeben.
Methoden werden mit der `.`-Syntax aufgerufen.

```ruby
class Calculator

  # Unnamed params
  def add(num1, num2)
    return num1 + num2 # Explicit return
  end

  # Named params
  def multiply(num1:, num2:)
    num1 * num2 # Implicit return
  end
end

calc = Calculator.new
calc.add(1, 3)
calc.multiply(num1: 2, num2: 5)
```
