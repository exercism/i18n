# Einführung

Manchmal nimmt eine Funktion so viele Argumente entgegen, dass es schwer sein kann, sich die Reihenfolge zu merken, in der sie übergeben werden müssen. Um die Lesbarkeit zu verbessern, erlaubt es Gleam, Argumente mit einem Label zu versehen.

Um ein Argument mit einem Label zu versehen, gibst du den Labelnamen vor dem Argumentnamen an, getrennt durch ein Leerzeichen.

```gleam
pub fn replace(
  in string: String,
  each target: String,
  with replacement: String
) -> String {
  // ...
}
```

Beim Aufruf einer Funktion mit gelabelten Argumenten kannst du die Argumente in beliebiger Reihenfolge angeben. Alle diese Aufrufe von `replace` sind gleichwertig:

```gleam
replace(in: "🍔🍔🍔" each: "🍔", with: "🍕")

replace(each: "🍔", in: "🍔🍔🍔", with: "🍕")

replace(with: "🍕", each: "🍔", in: "🍔🍔🍔")
```

Labels sind immer optional. Auch wenn eine Funktion gelabelte Argumente hat, kannst du sie weiterhin ohne Labels aufrufen.

```gleam
replace("🍔🍔🍔", "🍔", "🍕")
```
