# Ergänzung zu den Anweisungen

## Track-spezifische Anweisungen

Für diese Übung musst du ein **locale** namens `robot` definieren, das die **Substantive** `position` und `direction` und ein **Verb** `move` definiert.

- Das `create`-Verb von `robot` nimmt die Anfangsposition und die Anfangsrichtung als Array von Boxen entgegen.
    
    ```j
      r=. (0 0;'north') conew 'robot'
    ```
- `move` aktualisiert die Werte von `position` und `direction` in der erstellten **Instanz**.
    ```j
      r=. (0,0;'north') conew 'robot'
      
      NB. initial state
      NB. ====================================
      position__r
        0 0
      direction__r
        north
      
      NB. new states after `move` is executed 
      NB. ====================================
      move__r 'LA'
      position__r
        _1 0
      direction__r
        west      
    ```
