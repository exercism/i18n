# Über

Eine Funktion ist [endrekursiv][recursion-tc], wenn das _Letzte_, was die Funktion ausführt, ein Aufruf ihrer selbst ist.

Bei jedem Aufruf einer Funktion wird ein _Stackframe_ mit ihren lokalen Variablen, Argumenten usw. oben auf den [Funktionsaufruf-Stack][call-stack] gelegt. Wenn eine Funktion zurückkehrt, wird der Stackframe wieder vom Stack entfernt.

Endrekursive Funktionen ermöglichen die [Tail-Call-Optimierung][tail-call-optimization]. Das ist eine Optimierung, die es erlaubt, den letzten Stackframe für den nächsten Funktionsaufruf wiederzuverwenden, weil die vorherige Funktion ihn garantiert nicht mehr braucht. Das mindert die Gefahr, dass der Funktionsaufruf-Stack überläuft, also die Situation, in der so viele Frames auf dem Funktionsaufruf-Stack liegen, dass kein Speicher mehr bleibt, um einen weiteren anzulegen.

- Um in Elixir endrekursiv zu arbeiten, ist wegen der Unveränderlichkeit von Daten oft ein Akkumulator nötig.

  - Ein Akkumulator ist eine Variable, die entlang des rekursiven Aufrufs mitgeführt wird und den _bisherigen_ Zustand der rekursiven Funktion festhält, bis im Basisfall das Endergebnis zurückgegeben wird.

    ```elixir
    # Count the length of a list without an accumulator
    def count([]), do: 0
    def count([_head | tail]), do: 1 + count(tail)

    # Count the length of a list with an accumulator
    def count(list), do: do_count(list, 0)

    defp do_count([], count), do: count
    defp do_count([_head | tail], count), do: do_count(tail, count + 1)
    ```

- Wenn du mit Listen arbeitest, denk daran, dass sie als einfach verkettete Listen umgesetzt sind: Das Voranstellen von Elementen geht sehr schnell, das Anhängen dagegen ist sehr langsam.

  ```elixir
  # Reverse a list with an accumulator
  def reverse(list), do: do_reverse(list, [])

  defp do_reverse([], acc), do: acc

  defp do_reverse([head | tail], acc) do
    do_reverse(tail, [head | acc])
  end
  ```
