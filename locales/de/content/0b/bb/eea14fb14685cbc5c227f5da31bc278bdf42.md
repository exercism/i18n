# Main-Funktion vorhanden

Entferne die `Main`-Funktion, da die Tests sie nicht benötigen und sie den Code etwas schwerer lesbar machen.

Normalerweise wird die `Main`-Funktion hinzugefügt, um den Code zu debuggen. Besser ist es jedoch, den Code beim Ausführen von einem oder mehreren Unit-Tests zu debuggen. Das hat den zusätzlichen Vorteil, dass du dich auf das Debuggen eines bestimmten Testfalls konzentrieren kannst. Hier sind einige Links, die erklären, wie du Scala-Code beim Ausführen von Unit-Tests in verschiedenen IDEs debuggen kannst:

- [IntelliJ](https://www.jetbrains.com/help/idea/run-debug-and-test-scala.html)
- [Eclipse](http://scala-ide.org/docs/current-user-doc/features/scaladebugger/index.html)
