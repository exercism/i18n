# Ganzzahlen

Ganzzahlen sind ganze Zahlen, die zur Menge `{..., -2, -1, 0, 1, 2, ...}` gehören.
Der maximale und minimale Wert einer Ganzzahl wird vom System bestimmt, auf dem PHP läuft.
Typischerweise ist eine Ganzzahl auf den meisten modernen Systemen ein 64-Bit-Wert, das heißt, sie kann `-9_223_372_036_854_775_808` bis `9_223_372_036_854_775_807` einschließlich darstellen.

```php
<?php

$a = 1234;
$a = 1_234_567;
```

Du kannst ganzzahlige Literalwerte auch in einer anderen Basis als Basis 10 schreiben, indem du ein Basispräfix verwendest:

```php
<?php

$a = 0123; // octal number (equivalent to 83 decimal)
$a = 0o123; // octal number (as of PHP 8.1.0)
$a = 0x1A; // hexadecimal number (equivalent to 26 decimal)
$a = 0b11111111; // binary number (equivalent to 255 decimal)
```
