# Einführung in for-Schleifen

Die [for-Schleife](https://docs.oracle.com/javase/tutorial/java/nutsandbolts/for.html) bietet einen Mechanismus, um eine Gruppe von Anweisungen so lange wiederholt auszuführen, bis eine Bedingung erfüllt ist.
Die Schleife besteht aus vier Teilen:

```java
for (initialization; test; update) {
    body;
}
```

Die `initialization` legt einen Anfangszustand für die Schleife fest und wird genau einmal zu Beginn der Schleife ausgeführt.
Typischerweise deklariert und initialisiert sie eine Variable, die im Testausdruck und im Update-Ausdruck verwendet wird.
Zum Beispiel:

```java
int i = 1
```

Der `test`-Ausdruck prüft, ob die Schleife enden soll.
Ergibt er `true`, wird der Schleifenblock und danach der Update-Ausdruck ausgeführt.
Ergibt er `false`, werden weder der Schleifenblock noch der Update-Ausdruck ausgeführt, und die Ausführung geht nach der schließenden Klammer der Schleife weiter.
Typischerweise prüft er die Variable, die im Initialisierungsblock zugewiesen wurde.
Zum Beispiel:

```java
i <= 10
```

Nachdem der Schleifenblock ausgeführt wurde, wird der `update`-Ausdruck ausgeführt.
Typischerweise erhöht oder verringert er die Schleifenvariable um einen bestimmten Wert.
Zum Beispiel:

```java
i++
```

Eine `for`-Schleife, die die ersten vier Quadrate ausgibt, sieht so aus:

```java
for (int i = 1; i <= 4; i++) {
    System.out.println("square of " + i + " is " + i * i);
}
```

Die Ausgabe wäre:

```text
square of 1 is 1
square of 2 is 4
square of 3 is 9
square of 4 is 16
```

Wenn du jedes Element einer Sammlung durchlaufen möchtest, ist eine `for-each`-Schleife vorzuziehen, aber mit einer `for`-Schleife geht es so:

```java
for (int i = 0; i < array.length; i++) {
    System.out.print(array[i]);
}
```

Eine `for`-Schleife hat gegenüber einer `for-each`-Schleife einige Vorteile:

- Du kannst bei dem Index beginnen oder aufhören, den du möchtest.
- Du kannst jede beliebige (boolesche) Abbruchbedingung verwenden.
- Du kannst Elemente überspringen, indem du das Erhöhen der Schleifenvariable anpasst.
- Du kannst Sammlungen von hinten nach vorne verarbeiten, indem du herunterzählst.
- Du kannst `for`-Schleifen in Situationen verwenden, in denen es keine Sammlungen gibt.
