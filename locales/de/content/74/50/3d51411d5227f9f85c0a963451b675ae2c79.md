# Überblick

Datenstrukturen, die null oder mehr Elemente enthalten können, heißen _Sammlungen_. Ein **Array** ist eine Sammlung mit einer festen Größe/Länge, deren Elemente alle vom selben Typ sein müssen. Elemente können einem Array über einen Index zugewiesen oder daraus abgerufen werden. C#-Arrays sind nullbasiert, das heißt, der Index des ersten Elements ist immer null:

```csharp
// Declare array with explicit size (size is 2)
int[] twoInts = new int[2];

// Assign second element by index
twoInts[1] = 8;

// Retrieve the second element by index
twoInts[1] == 8; // => true

// Check the length of the array
twoInts.Length == 2; // => true
```

Arrays können auch mit einer Kurzschreibweise definiert werden, mit der du das Array sowohl erstellst als auch seine Werte festlegst. Da der Compiler nun erkennen kann, wie viele Elemente das Array haben wird, kann die Länge weggelassen werden:

```csharp
// Three equivalent ways to declare and initialize an array (size is 3)
int[] threeIntsV1 = new int[] { 4, 9, 7 };
int[] threeIntsV2 = new[] { 4, 9, 7 };
int[] threeIntsV3 = { 4, 9, 7 };
```

Arrays lassen sich bearbeiten, indem du entweder die [Methoden][array-methods] oder [Eigenschaften][array-properties] einer Array-Instanz aufrufst oder die statischen Methoden der [`Array`-Klasse][array-class] verwendest.

## Iteration

Ein Array ist auch eine _Sammlung_, das heißt, du kannst mit einer [`foreach`-Schleife][foreach-statement] über _alle_ seine Werte iterieren:

```csharp
char[] vowels = new [] { 'a', 'e', 'i', 'o', 'u' };

foreach (char vowel in vowels)
{
    // Output the vowel
    System.Console.Write(vowel);
}

// => aeiou
```

Man könnte auch eine [`for`-Schleife][for-statement] verwenden, um über ein Array zu iterieren:

```csharp
char[] vowels = new [] { 'a', 'e', 'i', 'o', 'u' };

for (int i = 0; i < vowels.Length; i++)
{
    // Output the vowel
    System.Console.Write(vowels[i]);
}

// => aeiou
```

Im Allgemeinen ist eine `foreach`-Schleife einer `for`-Schleife jedoch aus den folgenden Gründen vorzuziehen:

- Eine `foreach`-Schleife durchläuft garantiert _alle_ Werte. Bei einer `for`-Schleife übersieht man leicht Elemente, zum Beispiel wegen eines Off-by-one-Fehlers.
- Eine `foreach`-Schleife ist _deklarativer_: Dein Code teilt mit, _was_ er tun soll, statt wie bei einer `for`-Schleife, die mitteilt, _wie_ du es tun willst.
- Eine `foreach`-Schleife ist narrensicher, wohingegen bei `for`-Schleifen leicht ein Off-by-one-Fehler passiert.
- Eine `foreach`-Schleife funktioniert mit allen Sammlungstypen, auch mit denen, die keinen Indexer für den Zugriff auf Elemente unterstützen.

Um zu garantieren, dass eine `foreach`-Schleife über _alle_ Werte iteriert, erlaubt der Compiler nicht, dass eine Sammlung innerhalb einer `foreach`-Schleife geändert wird:

```csharp
char[] vowels = new [] { 'a', 'e', 'i', 'o', 'u' };

foreach (char vowel in vowels)
{
    // This would result in a compiler error
    // vowel = 'Y';
}
```

Eine `for`-Schleife hat gegenüber einer `foreach`-Schleife einige Vorteile:

- Du kannst bei dem Index beginnen oder aufhören, den du willst.
- Du kannst jede (boolesche) Abbruchbedingung verwenden, die du willst.
- Du kannst Elemente überspringen, indem du das Erhöhen der Schleifenvariable anpasst.
- Du kannst Sammlungen von hinten nach vorne verarbeiten, indem du herunterzählst.
- Du kannst `for`-Schleifen in Szenarien verwenden, in denen es keine Sammlungen gibt.

Verwandte Themen:

- Du solltest wissen, dass C# [mehrdimensionale Arrays][multi-dimensional-arrays] wie `int[,] arr = new int[10, 5]` unterstützt, was sehr nützlich sein kann.
- Du solltest außerdem wissen, dass du Objekte vom Typ [`System.Array`][system-array-object] mit `Array.CreateInstance` instanziieren kannst. Solche Objekte sind von geringem Nutzen, hauptsächlich für die Interoperabilität mit VB.NET-Code. Sie sind nicht mit Standard-Arrays (`T[]`) austauschbar. Sie können eine untere Grenze ungleich null haben.
