# PaySwitch - Gehaltsumrechner

## Problemstellung

Ein Unternehmen namens **Insure Everyone** bezahlt seine Angestellten in Fremdwährungen. Aufgrund gesetzlicher Vorgaben muss das Gehalt jedoch in die Landeswährung umgerechnet werden. Die Angestellten sind über die ganze Welt verteilt.
Die Personalabteilung von Insure Everyone sucht die Unterstützung einer talentierten Entwicklerin oder eines talentierten Entwicklers, um ein Programm zu bauen, das das Gehalt jeder angestellten Person in die entsprechende Landeswährung umrechnet. Insure Everyone verlässt sich dabei auf Wechselkurse, die eine externe API bereitstellt.

Angesichts der externen Wechselkurs-API musst du eine Funktion schreiben, die eine `source currency`, ein `salary` (in der Quellwährung) und die `local currency` der angestellten Person entgegennimmt und das Gehalt in der Landeswährung zurückgibt.

## Einschränkungen

* 500 <= `salary` <= 10000
* `sourceCurrency` und `targetCurrency` sind [ISO-Währungscodes (alphabetisch)](https://en.wikipedia.org/wiki/ISO_4217#Active_codes). Die Testeingabe kann ungültige Währungscodes enthalten.
* Die Genauigkeit des zurückgegebenen Kurses wird bis auf `5` Dezimalstellen genau gemessen.

## Beispiel

### Beispiel 1

#### Eingabe:
* Gehalt: 1000
* Quellwährung: USD
* Zielwährung: GBP

#### Ausgabe:

Angenommen, der externe Währungsumtausch hat die folgende Antwort mit Umrechnungskursen zurückgegeben (ausgelassen):

```json
{
    "base": "USD",
    "rates": {
        // omitted
        "GBP": 0.73584,
        // omitted
    }
}
```

Die Funktion muss `735.84000` zurückgeben

### Beispiel 2

#### Eingabe:

* Gehalt: 1000
* Quellwährung: GBP
* Zielwährung: USD

#### Ausgabe:

Angenommen, der externe Währungsumtausch hat die folgende Antwort mit Umrechnungskursen zurückgegeben (ausgelassen):

```json
{
    "base": "GBP",
    "rates": {
        // omitted
        "USD": 1.35898,
        // omitted
    }
```

Die Funktion muss `1358.9800` zurückgeben

## Hinweise

* Du kannst die empfangene JSON-Antwort in einen benutzerdefinierten Typ (genauer gesagt ein Open Record) umwandeln, um einfach darauf zugreifen zu können. Weitere Informationen findest du unter [Datenbindung im HTTP-Client](https://ballerina.io/learn/by-example/http-client-data-binding/)
