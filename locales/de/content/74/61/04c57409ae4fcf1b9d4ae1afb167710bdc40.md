# Einführung

Eine Funktion höherer Ordnung ist eine Funktion, die entweder:

- eine Funktion als Argument annimmt
- eine Funktion zurückgibt

Ein Funktionsargument ist einfach ein ganz normales Argument, nur dass du es aufrufen kannst.

```fsharp
let double = fun x -> x * 2

let apply f x = f x

apply double 3
// => 6
```
