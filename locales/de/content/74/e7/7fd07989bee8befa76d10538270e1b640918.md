# Die HTTP-Milliarden-Dollar-Frage

## Problemstellung

Deine Aufgabe ist es, in einer gegebenen Gruppe von Ländern die `x` Milliardäre mit dem höchsten Nettovermögen zu finden (Anzahl der Länder = `N`). Dafür hast du Zugriff auf eine API erhalten, die die Details der Milliardäre nach Land zurückgibt.

Um den Zugriff auf die API zu vereinfachen, kannst du den Connector [`ims/billionairehub`-Client](https://lib.ballerina.io/ims/billionairehub/1.0.0/clients/Client) verwenden, um dich mit der API zu verbinden, die die Details der Milliardäre nach Land zurückgibt.

## Einschränkungen

* 1 <= N <= 5
* 1 <= x <= 10

## Beispiel 1

Eingabe

```
Countries: ["United States"]
Limit: 3
```

Ausgabe

```
["Elon Musk", "Jeff Bezos", "Bill Gates"]
```

## Beispiel 2

Eingabe

```
Countries: ["China", "India"]
Limit: 5
```

Ausgabe

```
["Mukesh Ambani", "Gautam Adani & family", "Zhong Shanshan", "Zhang Yiming", "Ma Huateng"]
```

## Testumgebung

* Die Client-ID und das Client-Secret für die Verbindung zur Milliardärs-API findest du in `tests/Config.toml`. Du kannst sie verwenden, um den Client zu initialisieren.
* Verwende `bal test`, um deine Implementierung auszuführen und zu testen.

## Hinweise

* Der [Client](https://lib.ballerina.io/ims/billionairehub/1.0.0/clients/Client) des Pakets `ims/billionairehub` kann verwendet werden, um die API zum Abrufen der Milliardäre nach Land aufzurufen. Du kannst speziell die Remote-Methode `getBillionaires("<country>")` verwenden.
* Du kannst zuerst die reichsten Menschen pro Land finden und sie dann kombinieren, um die obersten `x` zu ermitteln.
* [Query-Ausdrücke](https://ballerina.io/learn/by-example/query-expressions/) sind praktisch zum Filtern und Sortieren.
