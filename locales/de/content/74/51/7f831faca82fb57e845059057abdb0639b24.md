# Ergänzende Anweisungen

## Register

| Register | Verwendung   | Typ      | Beschreibung                                    |
| -------- | ------------ | -------- | ---------------------------------------------- |
| `$a0`    | Eingabe      | Adresse  | Wort-Array mit den Eimerkapazitäten            |
| `$a1`    | Eingabe      | Ganzzahl | Starteimer (1 oder 2)                          |
| `$a2`    | Eingabe      | Ganzzahl | Zielvolumen                                    |
| `$a3`    | Ein-/Ausgabe | Adresse  | Wort-Array mit den endgültigen Eimerinhalten   |
| `$v0`    | Ausgabe      | Ganzzahl | Anzahl der erforderlichen Aktionen, -1 wenn nicht möglich |
| `$t0-9`  | temporär     | beliebig | wird für temporäre Speicherung verwendet       |
