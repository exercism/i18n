# Instructions

In dieser Übung übersetzt du einige Regeln aus dem klassischen Spiel Pac-Man in C++-Funktionen.

Du hast vier Regeln zu übersetzen, die alle mit den Spielzuständen zusammenhängen.

> Mach dir keine Gedanken darüber, wie die Argumente zustande kommen. Konzentriere dich darauf, die Argumente zu kombinieren und das gewünschte Ergebnis zurückzugeben.

## 1. Definiere, ob Pac-Man einen Geist frisst

Definiere die Funktion `can_eat_ghost`, die zwei Argumente entgegennimmt (_ob bei Pac-Man ein Kraftpillen-Effekt aktiv ist_ und _ob Pac-Man einen Geist berührt_) und einen booleschen Wert dafür zurückgibt, ob Pac-Man den Geist fressen kann. Die Funktion sollte nur dann wahr zurückgeben, wenn bei Pac-Man ein Kraftpillen-Effekt aktiv ist und er einen Geist berührt.

```cpp
can_eat_ghost(false, true);
// => false
```

## 2. Definiere, ob Pac-Man punktet

Definiere die Funktion `scored`, die zwei Argumente entgegennimmt (_ob Pac-Man einen Kraftpillen-Effekt berührt_ und _ob Pac-Man einen Punkt berührt_) und einen booleschen Wert dafür zurückgibt, ob Pac-Man gepunktet hat. Die Funktion sollte wahr zurückgeben, wenn Pac-Man einen Kraftpillen-Effekt oder einen Punkt berührt.

```cpp
scored(true, true);
// => true
```

## 3. Definiere, ob Pac-Man verliert

Definiere die Funktion `lost`, die zwei Argumente entgegennimmt (_ob bei Pac-Man ein Kraftpillen-Effekt aktiv ist_ und _ob Pac-Man einen Geist berührt_) und einen booleschen Wert dafür zurückgibt, ob Pac-Man verliert. Die Funktion sollte wahr zurückgeben, wenn Pac-Man einen Geist berührt und kein Kraftpillen-Effekt aktiv ist.

```cpp
lost(false, true);
// => true
```

## 4. Definiere, ob Pac-Man gewinnt

Definiere die Funktion `won`, die drei Argumente entgegennimmt (_ob Pac-Man alle Punkte gefressen hat_, _ob bei Pac-Man ein Kraftpillen-Effekt aktiv ist_ und _ob Pac-Man einen Geist berührt_) und einen booleschen Wert dafür zurückgibt, ob Pac-Man gewinnt. Die Funktion sollte wahr zurückgeben, wenn Pac-Man alle Punkte gefressen hat und anhand der in Teil 3 definierten Argumente nicht verloren hat.

```cpp
won(false, true, false);
// => false
```
