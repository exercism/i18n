# Anleitung

In dieser Übung wendest du die [Spielregeln von Go](https://matmoore.github.io/learngo/) an. Die Regeln selbst sind bereits geschrieben, du musst sie nur anwenden, um das Game zu aktualisieren und Fehler bzw. Regelverstöße zu behandeln.

Das Spiel wird wie folgt dargestellt:

```elm
type Player
    = Black
    | White


type alias Game =
    { whiteCapturedStones : Int
    , blackCapturedStones : Int
    , player : Player
    , error : String
    }
```

Im Spiel gibt es 4 Regeln:

- Jeder Punkt darf nur einen Stein enthalten (`oneStonePerPointRule`)
- Gegnerische Steine können gefangen werden! (`captureRule`)
- Du darfst keinen Stein dort setzen, wo er sich selbst fangen würde (`libertyRule`)
- Du darfst denselben Punkt nicht zweimal verwenden (`koRule`)

## 1. Wende die Regeln an

Schreibe den Inhalt der Funktion `applyRules`, die ein anfängliches `Game` und eine Menge von Regeln entgegennimmt und das neue `Game` zurückgibt, nachdem die Regeln angewendet wurden.

`oneStonePerPointRule`, `libertyRule` und `koRule` prüfen alle auf Regelverstöße und können einen Fehler zurückgeben, deshalb haben sie den Rückgabetyp `Result String Game`. Wenn eine dieser Regeln fehlschlägt, soll das ursprüngliche Spiel zurückgegeben werden, aber mit dem entsprechenden Fehler im Feld `error`.

`captureRule` prüft nicht auf Verstöße und kann daher nicht fehlschlagen (obwohl sie ein verändertes `Game` zurückgeben kann), deshalb hat sie den Rückgabetyp `Game`.

Wenn alle Regeln durchlaufen, sollen alle Änderungen am `Game` durch die Regeln beibehalten und der Spieler gewechselt werden. Die Funktion `changePlayer` ist dafür vorhanden.

```elm
applyRules : Game -> Rule -> NonValidatingRule -> Rule -> Rule -> Game
applyRules game oneStonePerPointRule captureRule libertyRule koRule =
--> If all rules pass, return a `Game` with all changes from the rules applied, and changePlayer
--> If any rule fails, return the original Game, but with the error field set
```
