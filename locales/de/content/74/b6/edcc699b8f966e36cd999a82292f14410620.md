# Anleitung

Du bist ein begeisterter Vogelbeobachter und hältst fest, wie viele Vögel deinen Garten besucht haben.
Normalerweise zählst du die Vögel mit einer Strichliste in einem Notizbuch, aber um besser mit deinen Daten arbeiten zu können, hast du die Vogelzahlen der letzten Wochen digitalisiert.

## 1. Ermittle die Gesamtzahl der Vögel, die du bisher gezählt hast

Fangen wir an, die Daten zu analysieren und uns einen Überblick zu verschaffen.
Finde heraus, wie viele Vögel du insgesamt gezählt hast, seit du mit deinen Aufzeichnungen begonnen hast.

Implementiere eine Funktion `TotalBirdCount`, die einen Slice von `int`s entgegennimmt, der die Vogelanzahl pro Tag enthält.
Sie soll die Gesamtzahl der Vögel zurückgeben, die du gezählt hast.

```go
birdsPerDay := []int{2, 5, 0, 7, 4, 1, 3, 0, 2, 5, 0, 1, 3, 1}
TotalBirdCount(birdsPerDay)
// => 34
```

## 2. Berechne die Anzahl der Vögel, die in einer bestimmten Woche zu Besuch waren

Jetzt, wo du ein allgemeines Gefühl für deine Vogelzahlen bekommen hast, möchtest du eine genauere Analyse machen.

Implementiere eine Funktion `BirdsInWeek`, die einen Slice mit der Vogelanzahl pro Tag und eine Wochennummer entgegennimmt.

Sie gibt die Gesamtzahl der Vögel zurück, die du in dieser bestimmten Woche gezählt hast.
Du kannst davon ausgehen, dass Wochen immer vollständig erfasst sind.

```go
birdsPerDay := []int{2, 5, 0, 7, 4, 1, 3, 0, 2, 5, 0, 1, 3, 1}
BirdsInWeek(birdsPerDay, 2)
// => 12
```

## 3. Korrigiere einen Zählfehler

Du hast gemerkt, dass sich die ganze Zeit, in der du versucht hast, die Vögel zu erfassen, ein Vogel in einer entfernten Ecke des Gartens versteckt hat.

Du hast herausgefunden, dass dieser Vogel jeden zweiten Tag in deinem Garten war.

Du weißt nicht genau, wo er an den Tagen dazwischen war, aber sicher nicht in deinem Garten.

Deine Vogelbeobachter-Intuition sagt dir außerdem, dass der Vogel am ersten Tag, den du in deiner Liste erfasst hast, in deinem Garten war.

Schreibe mit diesen neuen Informationen eine Funktion `FixBirdCountLog`, die einen Slice mit der pro Tag gezählten Vogelanzahl als Argument entgegennimmt und den Slice zurückgibt, nachdem der Zählfehler korrigiert wurde.

```go
birdsPerDay := []int{2, 5, 0, 7, 4, 1}
FixBirdCountLog(birdsPerDay)
// => [3 5 1 7 5 1]
```
