# Rekursion in JavaScript verstehen

Rekursion ist ein mächtiges Konzept in der Programmierung, bei dem eine Funktion sich selbst aufruft.
Es kann anfangs etwas knifflig sein, das zu verstehen, aber sobald du die Grundlagen kennst, wird es zu einem wertvollen Werkzeug beim Lösen komplexer Probleme.
Wir schauen uns die Rekursion in JavaScript mit leicht verständlichen Beispielen an.

## Was ist Rekursion?

Rekursion liegt vor, wenn eine Funktion sich selbst aufruft, direkt oder indirekt.
Es ist ähnlich wie eine Schleife, aber es zerlegt ein Problem in kleinere, überschaubarere Teilprobleme.

### Beispiel 1: Countdown

Fangen wir mit einem einfachen Beispiel an: einer Countdown-Funktion.

```javascript
function countdown(num) {
  // Base case
  if (num <= 0) {
    console.log('Blastoff!');
    return;
  }

  // Recursive case
  console.log(num);
  countdown(num - 1);
}

// Call the function
countdown(5);
```

In diesem Beispiel:

- **Basisfall**: Wenn `num` kleiner oder gleich 0 wird, gibt die Funktion „Blastoff!“ aus und hört auf, sich selbst aufzurufen.
- **Rekursiver Fall**: Die Funktion gibt das aktuelle `num` aus und ruft sich selbst mit `num - 1` auf.

### Beispiel 2: Fakultät

Jetzt schauen wir uns ein klassisches Beispiel für Rekursion an: die Berechnung der Fakultät einer Zahl.

```javascript
function factorial(n) {
  // Base case
  if (n === 0 || n === 1) {
    return 1;
  }

  // Recursive case
  return n * factorial(n - 1);
}

// Test the function
console.log(factorial(5)); // Output: 120
```

In diesem Beispiel:

- **Basisfall**: Wenn `n` 0 oder 1 ist, gibt die Funktion 1 zurück.
- **Rekursiver Fall**: Die Funktion multipliziert `n` mit der Fakultät von `n - 1`.

## Wichtige Konzepte

### Basisfall

Jede rekursive Funktion sollte mindestens einen Basisfall haben, eine Bedingung, bei der die Funktion aufhört, sich selbst aufzurufen.
Ohne einen Basisfall würde die Rekursion endlos weiterlaufen, was zu einem Stack Overflow führt.

### Rekursiver Fall

Der rekursive Fall definiert, wie die Funktion sich selbst mit einer kleineren oder einfacheren Version des Problems aufruft.

## Vor- und Nachteile der Rekursion

**Vorteile:**

- Elegante Lösung für bestimmte Probleme.
- Ahmt das Konzept der mathematischen Induktion nach.

**Nachteile:**

- Kann weniger effizient sein als iterative Lösungen.
- Kann bei tiefer Rekursion zu einem Stack Overflow führen.

## Fazit

Rekursion ist eine wertvolle Technik, die komplexe Probleme vereinfacht, indem sie sie in kleinere, überschaubarere Teilprobleme zerlegt.
Das Verständnis von Basisfällen und rekursiven Fällen ist entscheidend für die Umsetzung effektiver rekursiver Lösungen in JavaScript.
