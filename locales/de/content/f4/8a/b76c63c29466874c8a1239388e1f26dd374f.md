# Über

Blöcke sind kleine Gruppierungen von Anweisungen, die mehrmals ausgeführt werden können.
Man kann sie sich als Closures oder anonyme Funktionen vorstellen.
Blöcke werden mit der `do...end`-Syntax (oben) oder mit `{}` (unten) definiert.
Die Stile sind austauschbar, und es gibt unterschiedliche Meinungen dazu, wann man welchen verwenden sollte.

## Kurzsyntax
Wenn ein Block nur eine einzelne Methode aufruft, kannst du den Block durch `&:` gefolgt vom Methodennamen ersetzen. Diese beiden Zeilen sind zum Beispiel gleichbedeutend:

```ruby
people.sum { |person| person.age }
people.sum(&:age)
```
