# Anleitung

Im Zirkus steigt niemand auf das Trapez, bevor die Sicherheitschecks bestanden sind.
Du schreibst die Checks auf, damit für alle dieselben Regeln gelten.

Alle fünf Aufgaben kommen in die `SAFETY_CHECK`-Klasse.

## 1. Ist die Matte bereit?

Die Matte ist nur bereit, wenn sie sowohl ausgelegt als auch sauber ist.

```sather
SAFETY_CHECK::mat_ready(true, false)
-- => false
```

## 2. Gibt es etwas, worauf man landen kann?

Unter dir muss eine Matte oder ein Netz sein. Eins von beidem reicht, und
beides zu haben ist auch in Ordnung.

```sather
SAFETY_CHECK::something_below(false, true)
-- => true
```

## 3. Wer braucht noch die Einweisung?

Jeder, der noch nicht eingewiesen wurde, braucht die Einweisung.

```sather
SAFETY_CHECK::needs_briefing(false)
-- => true
```

## 4. Ist dieser Artist alt genug?

Trapez ist für Artisten ab 13 Jahren.

```sather
SAFETY_CHECK::old_enough(13)
-- => true
```

## 5. Setze alles zusammen

Ein Artist ist für das Trapez freigegeben, wenn er alt genug ist, eingewiesen
wurde und die Matte bereit ist.

```sather
SAFETY_CHECK::cleared(14, true, true, true)
-- => true
```

Die vier Argumente sind das Alter, ob der Artist eingewiesen wurde, ob die
Matte ausgelegt ist und ob die Matte sauber ist.
