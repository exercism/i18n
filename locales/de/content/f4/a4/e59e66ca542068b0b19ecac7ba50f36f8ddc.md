# Destrukturierung

Destrukturierung ist der Vorgang, bei dem man Elemente in ihre Bestandteile zerlegt und jeden davon an eine kleinere Variable bindet.

## Tupel destrukturieren

Tupel zu destrukturieren ist einfach: Du weist jedem Feld des Tupels einfach einen neuen Variablennamen zu:

```rust
let (first, second) = (1, 2);
```

## Tupelstrukturen destrukturieren

Das Destrukturieren von Tupelstrukturen läuft genauso ab wie das Destrukturieren von Tupeln, nur dass du zusätzlich den Namen der Struktur angibst:

```rust
struct TupleStruct(&'static str, i32);
let my_tuple_struct = TupleStruct("foo", 123);
let TupleStruct(foo, num) = my_tuple_struct;
```

## Strukturen destrukturieren

Das Destrukturieren von Strukturen ähnelt dem Destrukturieren von Tupelstrukturen. Du verwendest einfach die Feldnamen:

```rust
struct ArabianNights {
    name: String,
    stories: usize,
}
let teller = ArabianNights { name: "Scheherazade".into(), stories: 1001 };
{
    let ArabianNights { name, stories } = teller;
    println!("{name} told {stories} stories");
}
```

## Partielles Destrukturieren

Mit dem Operator `..` kannst du beim Destrukturieren einige Felder ignorieren:

```rust
let ArabianNights { name, .. } = teller;
println!("{name} survived by her wits");
```

## Bedingtes Destrukturieren

Das Destrukturieren von Strukturen und Tupeln kann nicht fehlschlagen. Enums lassen sich aber ebenfalls destrukturieren, und zwar mit den Sprachkonstrukten `if let`, `while let` und `match`.

```rust
if let Some(foo) = foo {
    println!("{foo:?}");
}
```
