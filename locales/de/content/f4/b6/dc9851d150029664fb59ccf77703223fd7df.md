# kernel format

Neben der Methode `format` gibt es in Ruby noch eine weitere übliche Art, Strings zu erzeugen: die [String-Interpolation](http://ruby-for-beginners.rubymonstas.org/bonus/string_interpolation.html). Zum Beispiel:

```ruby
# Rather than:
format("One for %%s, one for me.", %{name_variable})

# Consider:
"One for #{%{name_variable}}, one for me."
```
