# Einführung

Die assoziativen Arrays von Factor, also Hashtables und Verwandte, nutzen ein
gemeinsames [Protokoll][assoc-protocol] aus [`assocs`][assocs]. Das Hashtable-Literal ist
`H{ }`:

```factor
H{ { "coal" 1 } { "wood" 2 } } .

"coal" H{ { "coal" 1 } { "wood" 2 } } at .   ! => 1
"gold" H{ { "coal" 1 } { "wood" 2 } } at .   ! => f
```

Häufige Operationen:

```
at        ( key assoc -- value/f )
key?      ( key assoc -- ? )
set-at    ( value key assoc -- )
delete-at ( key assoc -- )
inc-at    ( key assoc -- )
change-at ( key assoc quot -- )
keys      ( assoc -- keys )
values    ( assoc -- values )
>alist    ( assoc -- alist )
```

Hashtables sind *veränderlich*. Rufe `clone` für ein `H{ }`-Literal auf, bevor du es
veränderst, damit das Literal nicht zwischen Aufrufen geteilt wird.

[assocs]: https://docs.factorcode.org/content/vocab-assocs.html
[assoc-protocol]: https://docs.factorcode.org/content/article-assocs-protocol.html
