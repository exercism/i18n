# Anleitung

In dieser Übung schreibst du ein hilfreiches Programm, damit du dir die Werte der Farbringe nicht merken musst.
Das Programm nimmt 1, 4 oder 5 Farben als Eingabe und gibt den korrekten Wert in Ohm aus.
Die Farbringe sind wie folgt kodiert:

| Farbe  | Wert |
| ------ | ----- |
| Black  | 0     |
| Brown  | 1     |
| Red    | 2     |
| Orange | 3     |
| Yellow | 4     |
| Green  | 5     |
| Blue   | 6     |
| Violet | 7     |
| Gray   | 8     |
| White  | 9     |

In [`Resistor Color Trio`][resistor-color-trio-exercise] hast du die ersten drei Farbringe entschlüsselt.
Zum Beispiel ergibt orange-orange-brown den Hauptwert `330`.
In dieser Übung kommt nun noch die _Toleranz_ dazu.
Die Toleranz gibt an, um wie viel ein Wert höchstens über oder unter dem Hauptwert liegen kann.
Wenn der letzte Farbring green ist, beträgt die maximale Toleranz zum Beispiel `±0.5%`.

Der Farbring für die Toleranz hat einen der folgenden Werte:

| Farbe  | Toleranz |
| ------ | --------: |
| Grey   |    ±0.05% |
| Violet |    ±0.10% |
| Blue   |    ±0.25% |
| Green  |    ±0.50% |
| Brown  |    ±1.00% |
| Red    |    ±2.00% |
| Gold   |    ±5.00% |
| Silver |   ±10.00% |

Ein Widerstand mit vier Farbringen ist so aufgebaut:

| Farbring_1  | Farbring_2  | Farbring_3     | Farbring_4    |
| ------- | ------- | ---------- | --------- |
| Wert_1 | Wert_2 | Multiplikator | Toleranz |

Beispiele:

- orange-orange-brown-green wäre `330` ohms mit einer Toleranz von `±0.5%`.
- orange-orange-red-grey wäre `3300` ohms mit einer Toleranz von `±0.05%`.

Der Unterschied zwischen einem Widerstand mit vier und einem mit fünf Farbringen ist, dass der Widerstand mit fünf Farbringen einen zusätzlichen Farbring hat, der einen genaueren Wert angibt.

| Farbring_1  | Farbring_2  | Farbring_3  | Farbring_4     | Farbring_5    |
| ------- | ------- | ------- | ---------- | --------- |
| Wert_1 | Wert_2 | Wert_3 | Multiplikator | Toleranz |

Beispiele:

- orange-orange-orange-black-green wäre `333` ohms mit einer Toleranz von `±0.5%`.
- orange-red-orange-blue-violet wäre `323 million` ohms mit einer Toleranz von `±0.1%`.

Es gibt außerdem Widerstände mit nur einem Farbring.
Bei Widerständen mit nur einem Farbring ist ausschließlich die Farbe black mit dem Wert 0 vorhanden.

Dein Programm soll eine `list` mit den Farbringen eines Widerstands als Eingabe nehmen und in ein Label umwandeln:

„... ohms ±...%“

Eine `list` wie `["orange", "orange", "black", "green"]` sollte also Folgendes zurückgeben:

„33 ohms ±0.5%“

Wenn der Wert im Tausenderbereich liegt, sagen wir „kiloohms“.
Das ist ähnlich wie „Kilometer“ für 1000 Meter und „Kilogramm“ für 1000 Gramm.

Eine `list` wie `["orange", "orange", "orange", "grey"]` sollte also Folgendes zurückgeben:

„33 kiloohms ±0.05%“

Wenn der Wert im Millionenbereich liegt, sagen wir „megaohms“.

Eine `list` wie `["orange", "orange", "blue", "red"]` sollte also Folgendes zurückgeben:

„33 megaohms ±2%“
