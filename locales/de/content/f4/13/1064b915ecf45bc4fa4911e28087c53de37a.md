# Einführung

Ein *Tupel* ist Factors Datensatz-, Struct- und Klassentyp. Jede Tupelklasse hat eine feste Sammlung benannter Slots, und Factor generiert automatisch Getter und Setter dafür.

```factor
TUPLE: point
    { x initial: 0 }
    { y initial: 0 } ;

T{ point { x 3 } { y 4 } } x>> .   ! => 3
3 4 point boa .                    ! => T{ point { x 3 } { y 4 } }
point new .                        ! => T{ point }
```

`boa` („in Reihenfolge der Argumente“) füllt Slots vom Stack, in Deklarationsreihenfolge. `new` erzeugt eine Instanz, bei der jeder Slot auf seinen deklarierten `initial:`-Wert gesetzt ist (oder `f`, wenn kein `initial:` angegeben ist).

Der Getter eines Slots ist `slot>>` und der Setter ist `>>slot`; der Setter *mutiert*, also rufe zuerst `clone` auf, wenn du ein nicht-destruktives Update brauchst:

```factor
T{ point { x 3 } { y 4 } } clone 10 >>x .
! => T{ point { x 10 } { y 4 } }
```

Slot-Standardwerte verwenden `{ name initial: value }`; ohne `initial:` ist der Standardwert `f`.
