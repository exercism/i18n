# Visual Basic lernen

## Websites

Visual Basic hat sich im Laufe der Jahre deutlich weiterentwickelt, und viele Tutorials von Drittanbietern beziehen sich auf veraltete Tools oder Funktionen.
Die [offizielle Visual-Basic-Dokumentation](https://learn.microsoft.com/en-us/dotnet/visual-basic/) ist die aktuellste und zuverlässigste Anlaufstelle, um deine Reise zu beginnen.

## Das .NET-Ökosystem

Visual Basic läuft auf der .NET-Runtime und teilt viele Kernfunktionen mit C# und F#.
Wenn du verstehst, wie .NET funktioniert, wirst du ein besserer VB-Entwickler.

- [Was ist .NET?](https://learn.microsoft.com/en-us/dotnet/core/introduction)
- [Das .NET-Glossar](https://learn.microsoft.com/en-us/dotnet/standard/glossary)
- [Das Common Type System (CTS)](https://learn.microsoft.com/en-us/dotnet/standard/base-types/common-type-system)
