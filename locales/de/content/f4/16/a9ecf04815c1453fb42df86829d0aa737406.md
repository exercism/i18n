# Zusätzliche Anweisungen

## Ausgabeformat

Gib einen null-terminierten String aus und verwende ein Komma und ein Leerzeichen als Trennzeichen.

Eine Beispielausgabe wäre `"491, 914, 142"`.

Wenn die Eingabe ungültig ist, gib einen leeren String aus.

## Register

| Register | Verwendung   | Typ     | Beschreibung                       |
| -------- | ------------ | ------- | ---------------------------------- |
| `$a0`    | Eingabe      | Adresse | null-terminierter String der Serie |
| `$a1`    | Eingabe      | Ganzzahl | Länge des Ausschnitts             |
| `$a2`    | Ein-/Ausgabe | Adresse | null-terminierter String für die Ausgabe |
| `$t0-9`  | temporär     | beliebig | für die temporäre Speicherung verwendet |
