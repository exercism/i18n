# Installation

## Voraussetzungen

Der C++-Track setzt voraus, dass du die folgende Software auf deinem System installiert hast:
* einen modernen C++14-Compiler
* das plattformübergreifende Buildsystem CMake

Zum Testen verwenden wir [Catch2](https://github.com/catchorg/Catch2), eine reine Header-Bibliothek, die zusammen mit den Übungen ausgeliefert wird.

Diese Abhängigkeiten sind für C++-Projekte sehr verbreitet. Falls du Probleme bei der Einrichtung hast, findest du online viele hilfreiche Ressourcen.

Viele IDEs, darunter Microsofts Visual Studio, Apples Xcode und JetBrains' CLion, bringen einen Compiler und CMake gleich mit. Du musst also nur die IDE installieren.

### Ein moderner C++14-Compiler

Dieser Track benötigt einen Compiler mit [C++14](http://en.wikipedia.org/wiki/C%2B%2B14)-Unterstützung, das 2014 veröffentlicht wurde. Alle großen Compiler der letzten Jahre sollten kompatibel sein. Solange du eine einigermaßen aktuelle Version verwendest, bist du auf der sicheren Seite. Konkret: GCC ab Version 7, Clang ab Version 6 oder Visual Studio 2017 oder neuer.

### CMake

CMake ist ein quelloffenes, plattformübergreifendes Buildsystem, das Build-Skripte für dein natives Buildsystem erzeugt (`make`, Visual Studio, Xcode usw.). Der C++-Track von Exercism verwendet CMake, damit du ein fertiges Build bekommst, das:

* die Tests kompiliert
* deine Lösung kompiliert
* das Testprogramm linkt
* die Tests bei jedem Build automatisch ausführt
* den Build fehlschlagen lässt, wenn Tests fehlschlagen

Mit CMake kann Exercism ein plattformübergreifendes Build-Skript bereitstellen, das Projektdateien für integrierte Entwicklungsumgebungen wie Visual Studio und Xcode erzeugen kann. So kannst du dich auf das Problem konzentrieren und musst dir keine Gedanken über die Einrichtung eines Builds für jede Übung machen.

Ein portables Build zu erhalten, ist nicht einfach und erfordert Zugriff auf viele verschiedene Systeme. Wenn du Probleme mit dem mitgelieferten CMake-Rezept hast, [melde das Problem](https://github.com/exercism/cpp/issues), damit wir die CMake-Unterstützung verbessern können.

Für das mitgelieferte Build-Rezept ist [CMake 3.5.1 oder neuer](http://www.cmake.org/) erforderlich.

## Windows

Wenn du Windows benutzt, kannst du dir [Visual Studio Community](https://www.visualstudio.com/vs/community/) herunterladen. Das ist ein kostenloser Download, der dir die Visual Studio IDE und die neueste Version des Microsoft Visual C++ Compilers liefert.

1. Folge [dieser Anleitung](https://docs.microsoft.com/en-us/cpp/build/cmake-projects-in-visual-studio), um CMake einzurichten.
1. Lade die Übung mit dem [exercism CLI](https://exercism.io/cli-walkthrough)-Tool herunter.
1. Öffne Visual Studio 2017 oder neuer (mit den Visual C++-Tools für CMake, wie im obigen Link beschrieben).
1. Öffne den Übungsordner in VS.
1. Führe „Build->Build the solution“ aus. Die Tests werden mit dem Build ausgeführt, die Ausgabe erscheint im Build-Fenster. Da die Tests während des Builds laufen, meldet VS einen Buildfehler, wenn einer der Tests fehlschlägt, und die Fehlermeldungen der Tests stehen im Build-Ausgabefenster.

Andere integrierte IDEs wie JetBrains' CLion solltest du auf ähnliche Weise verwenden können.

### Boost unter Windows installieren

Die Übungen `meetup` und `gigasecond` hängen von den [Boost][boost-website]-Bibliotheken ab. Die folgenden Schritte beschreiben, wie du das einrichtest.

1. Lade die [vorkompilierten Windows-Bibliotheken][sourceforge-boost-binaries] für Boost herunter.
   - Die Übungen setzen mindestens Boost 1.58 voraus.
   - Die Version von MSVC findest du, wenn du im Visual Studio Installer auf „Modify“ klickst.
1. Entpacke die Bibliotheken in einen lokalen Ordner.
1. Setze die Umgebungsvariable `BOOST_ROOT` auf den Ordner, in dem du die Boost-Bibliotheken installiert hast.
1. Wenn Visual Studio dabei geöffnet war, schließe es, damit der Wert von `BOOST_ROOT` übernommen wird.
1. Starte Visual Studio und öffne den Ordner mit der Übung `gigasecond` oder `meetup`.
1. Das „Startup Item“ sollte `gigasecond.exe` oder `meetup.exe` sein, und du solltest Buildfehler in `gigasecond_test.cpp` oder `meetup_test.cpp` bekommen, die dir sagen, dass du fehlende Elemente implementieren musst, ähnlich wie bei den anderen Übungen.

## Linux

Alle aktuellen Linux-Distributionen haben kompatible C++14-Compiler. Du solltest ihn mit deinem Paketmanager installieren können. Wir unterstützen die Versionen, die in Ubuntu LTS 18.04 standardmäßig installiert sind.

Unter Ubuntu installierst du gcc zum Beispiel mit dem folgenden Befehl.

```bash
$ sudo apt-get install gcc
$ gcc --version
```

Wenn du eine ältere Distribution verwendest, hast du vielleicht keinen Compiler, der C++14 unterstützt. In dem Fall musst du dich mit deiner Distribution beschäftigen, um herauszufinden, wie du die minimale Compilerversion installierst.

## MacOS

Unter MacOS kannst du GCC mit [Homebrew](http://brew.sh/) über `brew install gcc` installieren.
