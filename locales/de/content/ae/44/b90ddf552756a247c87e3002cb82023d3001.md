# Listen

Ein `ARRAY` ist fest. Es wird in einer bestimmten Größe erzeugt und behält sie: Du kannst nichts anhängen und nichts entfernen.

Das Notizbuch eines Detektivs funktioniert anders. Hinweise tauchen nach und nach auf und werden durchgestrichen, wenn sie sich als haltlos erweisen. Dafür brauchst du eine **Liste**.

```sather
   notes ::= #LIST{STR};
   notes.append("muddy boots");
   notes.append("broken window");
   notes.size                   -- 2
```

`LIST{T}` enthält Werte vom Typ `T` in einer Reihenfolge, wie ein Array, und wächst und schrumpft, wie du es verlangst.

## Sie ändert sich an Ort und Stelle

`append` verändert die Liste, auf der es aufgerufen wird, und gibt nichts zurück:

```sather
   notes.append("muddy boots");        -- yes
   notes := notes.append("muddy boots");   -- no: append answers nothing
```

Das ist anders als bei `FMAP` und `FSET`, wo du jede Änderung wieder zuweisen musstest. Eine `LIST` ist ein gewöhnliches Objekt, wie ein `SCOREBOARD`: Gib sie an eine Routine weiter, und die Routine kann deine verändern.

## Lesen und Schreiben

Eckige Klammern, gezählt ab null, genau wie bei einem Array:

```sather
   notes[0]                     -- "muddy boots"
   notes[1] := "smashed window";
   notes.size                   -- how many
   notes.is_empty               -- true when there are none
```

## Entfernen

`remove_index` entfernt eine Position, und alles danach rückt um eins nach:

```sather
   notes.remove_index(0);       -- the first clue is struck out
```

Positionen sind also nicht dauerhaft. Die Position eines Hinweises ändert sich, wenn ein früherer entfernt wird. Daran solltest du dich erinnern, bevor du eine speicherst.

## Sie durchlaufen

`elt!` funktioniert, genau wie bei einem Array:

```sather
   loop
      #OUT + notes.elt! + "\n";
   end;
```

## Die geschweiften Klammern

`LIST{STR}` ist eine Liste von Strings, `LIST{INT}` eine Liste von Ganzzahlen. Es ist eine generische Klasse, genau wie die, die du in `lost-property` geschrieben hast. Und jetzt kannst du die der Bibliothek genauso lesen.
