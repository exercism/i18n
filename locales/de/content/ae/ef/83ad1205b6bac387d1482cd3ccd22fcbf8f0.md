# Anleitung

In dieser Übung verwaltest du ein Inventarsystem.

Das Inventar sollte nach dem Elementnamen organisiert sein und die Anzahl der verfügbaren Elemente verfolgen.

Du musst das Hinzufügen von Elementen zu einem Inventar behandeln.
Jedes Mal, wenn ein Element in einem gegebenen Vektor auftaucht, sollte die Menge dieses Elements im Inventar um `1` erhöht werden.
Außerdem musst du das Löschen von Elementen aus einem Inventar behandeln, indem du die Mengen auf Anfrage um `1` verringerst.

Schließlich musst du eine Funktion implementieren, die alle Schlüssel-Wert-Paare eines gegebenen Inventars als `vector` von `pair`s zurückgibt.

~~~~exercism/note
Die Tests in dieser Übung prüfen nicht, ob mutiert wird, aber die Funktionsnamen deuten an, dass nicht mutiert werden sollte.
Wenn du Funktionen aus der Einführung verwenden möchtest, ohne die Eingabe zu mutieren, ist die Funktion `copy()` hilfreich.
~~~~

## 1. Erstelle ein Inventar auf Basis eines Vektors

Implementiere die Funktion `create_inventory(<input vector>)`, die aus einem Eingabevektor von Elementen ein „Inventar“ erstellt.
Sie sollte ein `dict` zurückgeben, das jeden Elementnamen mit der jeweiligen Menge paart.

```julia-repl
julia> create_inventory(["coal", "wood", "wood", "diamond", "diamond", "diamond"])
Dict("coal" => 1, "wood" => 2, "diamond" => 3)
```

## 2. Füge Elemente aus einem Vektor zu einem vorhandenen Wörterbuch hinzu

Implementiere die Funktion `add_items(<inventory dict>, <item vector>)`, die einen Vektor von Elementen zum übergebenen Inventar hinzufügt:

```julia-repl
julia> add_items(Dict("coal" => 1), ["wood", "iron", "coal", "wood"])
Dict("coal" => 2, "wood" => 2, "iron" => 1)
```

## 3. Verringere Elemente im Inventar

Implementiere die Funktion `decrement_items(<inventory dict>, <items vector>)`, die einen `vector` von Elementen entgegennimmt.
Deine Funktion sollte für jedes Mal, wenn ein Element im `vector` auftaucht, `1` von der Anzahl dieses Elements abziehen:

```julia-repl
julia> decrement_items(Dict("coal" => 3, "diamond" => 1, "iron" => 5), ["diamond", "coal", "iron", "iron"])
Dict("coal" => 2, "diamond" => 0, "iron" => 3)
```

Die Anzahl der Elemente im Inventar darf nicht unter 0 fallen.
Wenn die Anzahl der Vorkommen eines Elements im Eingabe-`vector` die verfügbare Menge übersteigt, sollte die für dieses Element angegebene Menge bei 0 bleiben.
Weitere Anfragen zum Verringern der Anzahl sollten ignoriert werden, sobald die Anzahl auf null fällt.

```julia-repl
julia> decrement_items(Dict("coal" => 2, "wood" => 1, "diamond" => 2), ["coal", "coal", "wood", "wood", "diamond"])
Dict("coal" => 0, "wood" => 0, "diamond" => 1)
```

## 4. Entferne einen Eintrag vollständig aus dem Inventar

Implementiere die Funktion `remove_item(<inventory dict>, <item>)`, die ein Element und seine Anzahl vollständig aus einem Inventar entfernt:

```julia-repl
julia> remove_item!(Dict("coal" => 2, "wood" => 1, "diamond" => 2), "coal")
Dict("wood" => 1, "diamond" => 2)
```

Wenn das Element nicht im Inventar gefunden wird, sollte die Funktion das ursprüngliche Inventar unverändert zurückgeben.

```julia-repl
julia> remove_item(Dict("coal" => 2, "wood" => 1, "diamond" => 2), "gold")
Dict("coal" => 2, "wood" => 1, "diamond" => 2)
```

## 5. Gib den gesamten Inhalt des Inventars zurück

Implementiere die Funktion `list_inventory(<inventory dict>)`, die ein Inventar entgegennimmt und einen Vektor von `(item, quantity)`-Paaren zurückgibt.

Der Vektor sollte nur die _verfügbaren_ Elemente enthalten (_mit einer Menge größer als null_) und nach Elementnamen alphabetisch sortiert sein:

```julia-repl
julia> list_inventory(Dict("coal" => 7, "wood" => 11, "diamond" => 2, "iron" => 7, "silver" => 0))
["coal" => 7, "diamond" => 2, "iron" => 7, "wood" => 11]
```
