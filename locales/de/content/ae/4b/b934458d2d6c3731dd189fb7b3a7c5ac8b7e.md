# Einführung

Bedingte Anweisungen in C++ ähneln denen in anderen Sprachen.
Der zugrunde liegende Typ einer bedingten Operation ist der Typ `bool`, der den Wert `true` oder `false` annehmen kann.
Bedingte Anweisungen werden oft als Kontrollflussmechanismen eingesetzt, um verschiedene Bedingungen zu prüfen.

Du kannst eine `if`-Anweisung verwenden, die ihren Code ausführt, wenn die zugrunde liegende Bedingung `true` ist:

```cpp
std::string value{"val"};

if (value == "val") {
    return "was val";
}
```

Wenn mehr als ein Fall abgedeckt werden soll, kannst du viele `if`-Anweisungen mit den `else if`- und `else`-Anweisungen verketten.

```cpp
int number{33};

if (number > 0) {
   return "positive";
} else if (number < 0) {
    return "negative";
} else {
   return "zero";
}
```

Seit C++17 können `if`-Anweisungen auch eine kurze Initialisierungsanweisung enthalten, mit der du eine oder mehrere Variablen für die `if`-Anweisung initialisieren kannst.
Zum Beispiel:

```cpp
int num{7};
if (int v{2 * num}; v > 10) {
    return v;
} else {
    return num;
}
// => 14
```

> Hinweis: Variablen, die in der Initialisierung angelegt werden, sind nach dem Ende der `if`-Anweisung nicht mehr zugänglich.
