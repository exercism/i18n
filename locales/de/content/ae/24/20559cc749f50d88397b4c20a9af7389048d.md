# Ergänzende Anweisungen

## Hinweis

Wenn du diese Datei in einem Texteditor und nicht in Pharo bearbeitest, schau dir bitte den Abschnitt [Erste Schritte](https://www.exercism.org/tracks/pharo/installation) an.

Du kannst zwar einen Texteditor verwenden, aber die Pharo-IDE ist zum Teil das, was die Sprache so besonders macht.

In Pharo kannst du Code (einschließlich Tests) mit defekten Methoden und fehlenden Klassen ausführen.
Wenn die VM auf fehlerhaften Code stößt, startet sie einen Debugger, mit dem du das Problem etwas genauer untersuchen kannst.

Dann hast du die Möglichkeit, auf die Schaltfläche „Create“ zu drücken, um eine fehlende Klasse oder Methode hinzuzufügen und jeden Code zu korrigieren, der einen Fehler verursacht.
Wenn du das tust, springt der Debugger zurück und lässt dich die Ausführung mit deinen neuen Änderungen fortsetzen.

Probier das mit deinem HelloWorld-Beispiel aus, indem du einfach eine der Unit-Test-Methoden ausführst.
