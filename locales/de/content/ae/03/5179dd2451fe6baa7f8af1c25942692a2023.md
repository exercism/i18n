# Einführung

In Haxe iterierst du mit einer `for`-Schleife über einen Wert. Es gibt zwei Arten von Iteratoren:

- `Iterator`, der über einen Wert iteriert.
- `Iterable`-Daten, die das Iterieren über einen Datentyp ermöglichen.

Beide Konzepte werden durch `Iterator<T>` und `Iterable<T>` dargestellt:

```haxe
typedef Iterator<T> = {
  function hasNext():Bool;
  function next():T;
}

typedef Iterable<T> = {
  function iterator():Iterator<T>;
}
```

Jede Klasse, die mit einem dieser Typen übereinstimmt, kannst du mit einer `for`-Schleife iterieren. Wenn eine Klasse die Methoden `hasNext` und `next` definiert, gilt sie als Iterator. Definiert sie dagegen eine Methode `iterator`, gilt sie als iterierbarer Typ.
