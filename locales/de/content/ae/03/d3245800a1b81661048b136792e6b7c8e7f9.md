[Boolesche Werte][booleans] werden in Haxe durch den Typ `Bool` dargestellt, dessen Werte entweder `true` oder `false` sein können.

Haxe unterstützt drei [boolesche Operatoren][operators]: `!` (unäres NICHT), `&&` (binäres UND) und `||` (binäres ODER).

Zusammengesetzte boolesche Ausdrücke (`&&` und `||`) verwenden eine _Kurzschlussauswertung_: Die Ausdrücke werden von links nach rechts ausgewertet, aber nur so weit wie nötig. Das ist in Fällen wie dem folgenden wichtig:

```haxe
object != null && object.field == x
```

Die erste boolesche Prüfung stellt sicher, dass nur dann auf `object.field` zugegriffen wird, wenn `object` nicht `null` ist. So schützt du dich vor einem Laufzeitfehler.

Die drei booleschen Operatoren haben eine unterschiedliche [Priorität][precedence] und werden in dieser Reihenfolge ausgewertet: `!` -> `&&` -> `||`.

Wenn du Ausdrücke in runde Klammern `()` setzt, kannst du diese Prioritätsregeln außer Kraft setzen, denn Klammern haben eine höhere Priorität.

```haxe
!true && false   // => false
!(true && false) // => true
```
