# Anleitung

In dieser Übung schreibst du Code, um Namensschilder für die Mitarbeiter einer Fabrik auszugeben. Mitarbeiter haben eine ID, einen Namen und einen Abteilungsnamen. Die Beschriftung der Namensschilder hat folgendes Format: `"[id] - name - DEPARTMENT"`.

## 1. Gib ein Namensschild für einen Mitarbeiter aus

Implementiere die Funktion `NameBadge.print/3`. Sie nimmt eine ID, einen Namen und eine Abteilung entgegen. Sie soll die Beschriftung des Schilds zurückgeben, wobei der Abteilungsname in Großbuchstaben steht.

```elixir
NameBadge.print(67, "Katherine Williams", "Strategic Communication")
# => "[67] - Katherine Williams - STRATEGIC COMMUNICATION"
```

## 2. Gib ein Namensschild für einen neuen Mitarbeiter aus

Wegen einer Eigenheit im Computersystem haben neue Mitarbeiter manchmal noch keine ID, wenn sie in der Fabrik anfangen zu arbeiten. Da Namensschilder Pflicht sind, bekommen sie ein vorläufiges Schild ohne das ID-Präfix.

Erweitere die Funktion `NameBadge.print/3`. Wenn die ID fehlt, soll sie ein Schild ohne ID ausgeben.

```elixir
NameBadge.print(nil, "Robert Johnson", "Procurement")
# => "Robert Johnson - PROCUREMENT"
```

## 3. Gib ein Namensschild für den Besitzer aus

Auch der Besitzer der Fabrik muss jederzeit ein Namensschild tragen. Ein Besitzer hat jedoch keine Abteilung. In diesem Fall soll die Beschriftung `"OWNER"` anstelle des Abteilungsnamens ausgeben.

Erweitere die Funktion `NameBadge.print/3`. Wenn die Abteilung fehlt, geh davon aus, dass das Schild dem Besitzer der Firma gehört.

```elixir
NameBadge.print(204, "Rachel Miller", nil)
# => "[204] - Rachel Miller - OWNER"
```

Beachte, dass der Besitzer gleichzeitig ein neuer Mitarbeiter sein kann.

```elixir
NameBadge.print(nil, "Rachel Miller", nil)
# => "Rachel Miller - OWNER"
```
