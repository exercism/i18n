# Einführung

## Strings

Strings sind eine Reihe von Zeichen, die von Anführungszeichen umschlossen werden.
Es werden sowohl einfache als auch doppelte Anführungszeichen unterstützt.

```php
<?php

$where = "Spain";
$what = 'rain';
```

### Variablenexpansion in Strings

Wenn du in Strings mit doppelten Anführungszeichen eine Variable referenzierst, die im Gültigkeitsbereich liegt, wird ihr Wert in den String eingesetzt.

```php
<?php

$answer = 42;
$expanded = "The answer to life, the universe, and everything is $answer"; 
```

### Unterstützung für Zeichenkodierungen

Historisch unterstützten String-Funktionen in PHP nur ASCII-Zeichen und keine modernen Unicode-Kodierungen.
ASCII-Zeichen sind jeweils 1 Byte lang, Unicode-Zeichen können dagegen 1 bis 4 Byte lang sein.
Wenn du Unicode-Strings sicher verarbeiten musst, schau dir die [Multibyte-Versionen][multi-byte-fns] der historischen Funktionen an.

```php
<?php

$byte_length = strlen('😃'); // => 4
$string_length = mb_strlen('😃'); // => 1
```

[multi-byte-fns]: https://www.php.net/manual/en/ref.mbstring.php
