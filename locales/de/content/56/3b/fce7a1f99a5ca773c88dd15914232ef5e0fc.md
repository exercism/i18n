# Über

[Listen][list] sind ein grundlegender Datentyp in Haskell, um eine Sammlung von Werten zu speichern.
Listen sind _unveränderlich_, das heißt, sie können nicht geändert werden.
Jede Operation, die eine Liste ändert, gibt eine neue Liste zurück.
In der Prelude gibt es mehrere Funktionen, mit denen du mit Listen arbeiten kannst.

Listen in Haskell sind als [verlinkte Listen][linked-list-wiki] implementiert und nicht als Arrays zusammenhängender Speicherbereiche.
Deshalb dauert der Zugriff auf ein Element in einer Liste linear zur Länge der Liste.

Listen kannst du in wörtlicher Form, in Kopf-Schwanz-Notation (die den `cons`-Operator `:` verwendet) oder in einer Kombination aus beidem schreiben:

```haskell
-- Literal Form
[]
[1]
[1, 2, 3]

-- Head-tail Notation
[]
-- same as [1]
1 : []
-- same as [1, 2, 3]
1 : (2 : (3 : []))

-- Mixed
-- same as [1, 2, 3]
1 : [2, 3]
```

Mit der Kopf-Schwanz-Notation kannst du Elemente an eine Liste anhängen.

```haskell
list = [2, 1]

[3, 2, 1] == 3 : list
-- -> True
```

Elemente während einer Iteration an eine Liste anzuhängen gilt als Anti-Pattern.
Das Anhängen eines Elements erfordert, die gesamte Liste zu durchlaufen und das Element am Ende hinzuzufügen. Ein neues Element in jeder Iteration anzuhängen würde also bedeuten, in jeder Iteration die gesamte Liste zu durchlaufen.

Du erreichst dasselbe Ergebnis, indem du ein Element an die umgekehrte Liste voranstellst und das Ergebnis anschließend umdrehst. Das Voranstellen ist eine schnelle Operation und benötigt konstante Zeit.

```haskell
-- Appending to the end of a list (potentially slow)
[1, 2, 3] ++ [4] ++ [5] ++ [6]

-- Prepend to the start of a list (faster, due to the nature of linked lists)
6 : (5 : (4 : [3, 2, 1]))
-- then reverse!
```

Es gibt mehrere gängige Prelude-Funktionen für Listen:

- [`head`][head] gibt den _Kopf_ einer Liste zurück, also das _erste_ Element einer Liste.
- [`tail`][tail] gibt den _Schwanz_ der Liste zurück, also die Liste _ohne_ das _erste_ Element.
- [`length`][length] gibt die Anzahl der Elemente in der Liste zurück.
- [`elem`][elem] gibt einen booleschen Wert zurück, der angibt, ob das Element in der Liste enthalten ist.

Außerdem gibt es das [`Data.List`-Modul][list].

## Listentypen

In Haskell sind Listen **homogen**.
Das bedeutet, dass alle Elemente einer Liste denselben Typ haben.
Wenn du versuchst, Elemente unterschiedlicher Typen in dieselbe Liste zu schreiben, bekommst du einen Typfehler.

```haskell
list = [1, "string"]
-- Error: No instance for (Num String) arising from the literal ‘1’
```

Die Typangabe einer Liste ist `[a]`, wobei a der Typ ist, den die Liste enthält, zum Beispiel `String` oder `Int`.

``` haskell
a :: [Int] 
a = [1, 2, 3]
```
