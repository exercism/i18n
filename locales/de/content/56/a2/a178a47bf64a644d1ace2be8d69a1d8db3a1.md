# Überblick

In Haxe sind Ausnahmen ein sicherer Weg, mit Fehlern umzugehen, die beim Ausführen des Codes auftreten. Jede Ausnahme sollte eine Nachricht enthalten, die den Fehler beschreibt. Wir können Ausnahmen mit dem Schlüsselwort `throw` _werfen_:

```haxe
public function main(num:Int) {
  if (num < 10) {
    throw "Argument num cannot be greater than 10";
  }
  // ...
}
```

Wenn eine Ausnahme geworfen wird, sucht der Code nach einem Codeabschnitt, der dafür zuständig ist, den Fehler zu behandeln. Findet er keinen, zeigt er die Fehlermeldung an und stoppt gleichzeitig die Ausführung des Programms.

Um Ausnahmen in Haxe zu behandeln, verwenden wir den `try-catch`-Block. Diese Blockanweisung besteht aus einem `try`-Block und einem oder mehreren `catch`-Blöcken. Der `try`-Block _versucht_, einen Codeabschnitt auszuführen, während der `catch`-Block darauf wartet, dass eine Ausnahme geworfen wird, um sie zu _fangen_, damit die Ausführung nicht gestoppt wird. Wenn ein `catch`-Block eine Ausnahme fängt, führt er außerdem alles innerhalb des Blocks aus:

```haxe
try {
  if (num < 10) {
    throw "Argument num cannot be greater than 10";
  }
} catch (e) {
  // All exceptions will be caught here
  trace(e.message); // Argument num cannot be greater than 10
}
```

Der Typ des Arguments im `catch`-Block sollte weggelassen werden.

Wichtig ist: Ausnahmen solltest du in Fällen einsetzen, in denen etwas Außergewöhnliches passiert, ein Fehler, der eine besondere Behandlung braucht. Sie sollten nicht für den Kontrollfluss eines Programms verwendet werden, denn das gilt als schlechtes Design, was oft zu schlechter Performance und schlechter Wartbarkeit führt.
