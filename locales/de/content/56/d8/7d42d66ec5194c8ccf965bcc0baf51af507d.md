# Hinweise

## Allgemein

- `matches?`, `all-matching-subseqs`, `count-matches` und
  `re-replace` stecken alle in [`regexp`][regexp]. Schreibe jedes Muster als
  Literal zwischen `R/ ` und `/`.
- Ein gültiger Badge-Code besteht aus zwei Großbuchstaben, einem Bindestrich und
  vier Ziffern: `R/ [A-Z]{2}-\d{4}/`.

## 1. Prüfe einen Badge-Code

- `matches?` prüft den *gesamten* String. Genau das brauchst du für die Frage
  „Ist das ein gültiger Badge-Code?“: `R/ [A-Z]{2}-\d{4}/ matches?`.

## 2. Hole jeden Code aus einer Logzeile

- `all-matching-subseqs` gibt jede Übereinstimmung als eine Sequenz von Strings
  zurück. Übergib ihm dasselbe Badge-Code-Muster.

## 3. Zähle die Ziffern in einem Code

- `\d` trifft auf eine Ziffer zu; `count-matches` zählt, wie oft das Muster
  zutrifft: `R/ \d/ count-matches`.

## 4. Schwärze Passwörter

- `\S` bedeutet „ein Zeichen, das kein Leerzeichen ist“, deshalb trifft
  `R/ pass=\S+/` auf `pass=` plus das Geheimnis dahinter zu.
- `re-replace` nimmt den String, das Muster und den Ersatztext
  `"pass=****"`.

[regexp]: https://docs.factorcode.org/content/vocab-regexp.html
