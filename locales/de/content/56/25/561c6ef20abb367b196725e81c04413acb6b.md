# Installation

Die empfohlenen Installationsanweisungen für deine Plattform findest du auf [der offiziellen Rust-Website].

Mit der installierten Toolchain allein ist es nicht getan!
IDE-Unterstützung ist ein enormer Produktivitätsschub, den die meisten Entwickler mittlerweile erwarten.
Wenn du Visual Studio Code verwendest, schau dir die [Dokumentation zur Rust-Unterstützung][vscode] an.
Wir empfehlen dir außerdem wärmstens, [Linting mit Clippy][vscode-linting] zu aktivieren!

[the official Rust website]: https://www.rust-lang.org/tools/install
[vscode]: https://code.visualstudio.com/docs/languages/rust
[vscode-linting]: https://code.visualstudio.com/docs/languages/rust#_linting
