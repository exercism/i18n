# Ergänzung zur Anleitung

## `Print` setzt String-Werte nicht in Anführungszeichen

In dieser Übung geht es um den Umgang mit numerischen Werten.
#[a: 1]` and `#[a: "1"]` sind nicht gleich:

```arturo
inspect #[a: 1]
; [ :dictionary
;        a  :        1 :integer
; ]

inspect #[a: "1"]
; [ :dictionary
;        a  :        1 :string
; ]
equal? #[a: "1"] #[a: 1]
; false
```

Beim Debuggen ist es üblich, Werte mit `print` auszugeben.
Die Ausgabe setzt jedoch keine Anführungszeichen um Strings.
Ein numerischer String wie `"1"` sieht beim Ausgeben deshalb genauso aus wie die Ganzzahl `1`.

```arturo
print #[a: 1]
; [a:1]
print #[a: "1"]
; [a:1]
```
In der Testausgabe dieser Übung kann dir ein Ergebnis wie `:x: equal? [a:1 e:1 i:1 o:1 u:1] [a:1 e:1 i:1 o:1 u:1]` begegnen.
Die beiden verglichenen Wörterbücher sehen beim Ausgeben gleich aus.
Das erste Wörterbuch enthält jedoch numerische String-Werte und das zweite Ganzzahlen, deshalb sind sie nicht gleich. 
Beim Debuggen kannst du mit `inspect` den Inhalt deines Wörterbuchs überprüfen.

## `Express` setzt String-Werte in Anführungszeichen

`express` wandelt einen Wert in Arturo-Code um und gibt einen String zurück, der diese Codedarstellung repräsentiert.
In diesem Ergebnis werden alle String-Werte in Anführungszeichen gesetzt.
Deshalb gibt `express "1"` den Wert `"1"` zurück, nicht `1`.

```arturo
express #[name: "Octavius" age: 22]
; #[name: "Octavius" age: 22 ]
```
```arturo
express #[name: "Octavius" age: "22"]
; #[name: "Octavius" age: "22" ]
```
