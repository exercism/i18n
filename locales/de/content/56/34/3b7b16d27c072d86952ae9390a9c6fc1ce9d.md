## 5. Alternative Mittelwerte

- Sequenztypen wie `list` unterstützen einige [gängige Operationen][common sequence operations].
- Um auf ein Element zuzugreifen, verwende die Schreibweise mit eckigen Klammern (`<list>[]`).
- Denk daran, dass das erste Element der `list` von der **linken** Seite aus den Index 0 hat.
- In Python beginnt die negative Indizierung bei -1 von der **rechten** Seite. Das heißt, du kannst das letzte Element einer `list` mit `<list>[-1]` finden.
- Überlege, wie du den Code aus den Funktionen wiederverwenden kannst, die du bereits implementiert hast.

## 6. Weitere Techniken zur Mittelwertbildung

- Sequenztypen wie `list` unterstützen bereits einige [gängige Operationen][common sequence operations].
- Überlege, ob du den Code aus den Funktionen wiederverwenden kannst, die du gerade implementiert hast.
- Die Slice-Syntax unterstützt eine _Schrittweite_ (`<list>[<start>:<stop>:<step>]`).

## 7. Regeln für die Bonusrunde

- Listen sind _veränderbar_. Sobald eine `list` erstellt wurde, kannst du jedes Element beliebiger Art ändern, löschen oder hinzufügen.
- Python bietet eine Vielzahl von [Möglichkeiten, `lists` zu ändern][ways to modify `lists`].
