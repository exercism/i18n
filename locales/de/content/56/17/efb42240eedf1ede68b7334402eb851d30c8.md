# Anleitung

In dieser Übung wendest du die [Regeln des Spiels Go](https://matmoore.github.io/learngo/) an. Die Regeln selbst sind bereits geschrieben, du musst sie nur anwenden, um das Game zu aktualisieren und Fehler bzw. Regelverstöße zu behandeln.

Das Spiel wird folgendermaßen dargestellt:

```gleam
pub type Player {
  Black
  White
}


pub type Game {
  Game(
    white_captured_stones: Int,
    black_captured_stones: Int,
    player: Player,
    error: String,
  )
}
```

Im Spiel gibt es 4 Regeln:

- Jeder Punkt kann nur einen Stein enthalten.
- Gegnerische Steine können geschlagen werden.
- Du kannst keinen Stein dort setzen, wo er sich selbst schlagen würde.
- Du kannst denselben Punkt nicht zweimal benutzen.

## 1. Wende die Regeln an

Schreibe den Inhalt der Funktion `apply_rules`, die ein initiales `Game` und eine Menge von Regeln entgegennimmt und das neue `Game` zurückgibt, nachdem die Regeln angewendet wurden.

Drei der Regeln prüfen auf Regelverstöße und können einen Fehler zurückgeben, haben also den Rückgabetyp `Result(Game, String)`. Wenn eine dieser Regeln fehlschlägt, soll das ursprüngliche Game zurückgegeben werden, allerdings mit dem `error`-Feld, das um den passenden Fehler aktualisiert wurde.

Die andere Regel prüft nicht auf Verstöße und kann daher nicht fehlschlagen (sie kann aber ein geändertes `Game` zurückgeben), hat also den Rückgabetyp `Game`.

Wenn alle Regeln erfolgreich sind, sollen alle Änderungen am `Game` aus den Regeln beibehalten und der Spieler gewechselt werden.

```gleam
pub fn apply_rules(
  game: Game,
  rule1: fn(Game) -> Result(Game, String),
  rule2: fn(Game) -> Game,
  rule3: fn(Game) -> Result(Game, String),
  rule4: fn(Game) -> Result(Game, String),
) -> Game {
  // -> If all rules pass, return a `Game` with all changes from the rules applied, and change player
  // -> If any rule fails, return the original Game, but with the error field set
}
```
