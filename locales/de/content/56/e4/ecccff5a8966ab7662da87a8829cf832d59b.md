# Einführung

Ein boolescher Ausdruck ist eine Frage, die an einen oder mehrere Werte gestellt wird und mit `true` oder `false` beantwortet werden kann.
Ein wahrer Ausdruck gibt `1` zurück; ein falscher Ausdruck gibt `0` zurück.
Außerdem haben Zahlen Wahrheitswerte. Null ist `false`; ungleich Null ist `true`.

Älterer C-Code verwendet entweder den Typ `int` direkt für boolesche Werte, oder der Programmierer hat möglicherweise Konstanten wie `TRUE` und `FALSE` definiert, um `1` und `0` auf eine boolesche Darstellung abzubilden.

Mit Version C99 wurde der Typ `_Bool` hinzugefügt.
Die Header-Datei `stdbool.h` definiert drei neue boolesche Symbole: `bool`, `true` und `false`.
`true` entspricht `1`, `false` entspricht `0` und `bool` entspricht `_Bool`.
Jetzt können Programmierer also `stdbool.h` einbinden, anstatt direkt `int`s zu verwenden oder eigene boolesche Zuordnungen zu erstellen, und erhalten automatisch boolesche Symbole in ihrem Code.

## Vergleichsoperatoren

C unterstützt sechs Vergleichsoperatoren: `==` (gleich), `!=` (ungleich), `>` (größer als), `<` (kleiner als), `>=`(größer oder gleich), `<=` (kleiner oder gleich).
Diese Operatoren vergleichen die Beziehungen zwischen Werten und werten sie zu booleschen Werten aus.

```c
0 == 0 // true. Although 0 is false, 0 equals 0 is true.
0 != 0 // false
1 > 0 // true
1 < 0 // false
1 >= 0 // true
1 <= 0 // false
```

## Boolesche Operatoren

C unterstützt drei boolesche Operatoren: `||` (oder), `&&` (und) und `!` (nicht).

`!` wird mit einem Operanden verwendet.
Es kehrt den booleschen Wert des Operanden um.
Zum Beispiel ist `0` `false`, aber `!0` ist `true`.

`||` und `&&` werden mit zwei Operanden verwendet.
Der rechte Operand wird nur ausgewertet, wenn der linke Operand das Ergebnis des Ausdrucks nicht bereits bestimmt.
Das heißt, `||` wertet seinen rechten Operanden nur aus, wenn sein linker Operand zu `false` ausgewertet wird.
`&&` wertet seinen rechten Operanden nur aus, wenn sein linker Operand zu `true` ausgewertet wird.
