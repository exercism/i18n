# Variadische Parameter

[_Variadische Parameter_][variadic-parameters] in Swift erlauben es, null oder mehr Werte desselben Typs in einen einzelnen Parameter einer Funktion zu übergeben. Das gibst du an, indem du `...` an die Typannotation des Parameters anhängst.

Diese Werte werden automatisch zu einem Array zusammengefasst, dessen Elemente denselben Typ haben wie der variadische Parameter.

```swift
func geometricMean(_ numbers: Double...) -> Double {
  var total = 1.0
  for number in numbers {
      total *= number
  }
  return pow(total, 1.0 / Double(numbers.count))
}

geometricMean(1, 2, 3, 4, 5)
// => 2.605171084697352
```

Beachte, dass Swift bei variadischen Parametern eine Einschränkung hat.
Wenn eine Funktion in ihrer Definition Parameter nach dem variadischen Parameter hat, muss der erste Parameter nach dem variadischen Parameter _zwingend_ ein Argument-Label haben.

[variadic-parameters]: https://docs.swift.org/swift-book/documentation/the-swift-programming-language/functions/#Variadic-Parameters
