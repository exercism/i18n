# Einführung

Common Lisp erlaubt es dir, „Kommentare" zu schreiben, die der Computer ignoriert.
Einzeilige Kommentare beginnen mit einem oder mehreren Semikolons (`;`) und gelegentlich siehst du auch Folgendes:

```lisp
(code...) ; => value
```

Dabei gibt der Kommentar an, welchen Wert Common Lisp zurückgibt, nachdem der Code in dieser Zeile ausgeführt wurde.

Es ist üblich, ein einzelnes Semikolon für einen kurzen Kommentar am Ende einer Zeile zu verwenden, zwei für einen längeren Kommentar über einem Codeabschnitt, drei für einen langen Kommentar, der etwas wie eine Funktion beschreibt, und vier für einen Kommentar wie eine Kopfzeile am Anfang einer Quelldatei.
