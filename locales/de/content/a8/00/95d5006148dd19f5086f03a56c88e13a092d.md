# Explizite Rückgabe

Entferne die explizite Rückgabe, um die Methode zu vereinfachen.

In Ruby gibt eine Methode das Ergebnis des zuletzt ausgewerteten Ausdrucks zurück. Das explizite Verwenden des Schlüsselworts `return` ist daher unnötig, außer wenn du früh aus einer Methode zurückkehrst.

Zum Beispiel gibt das hier `16` aus, denn die Methode `multiply` gibt das Ergebnis von `a * b` zurück, ihrem letzten Ausdruck.

```ruby
def multiple(a, b)
  a * b
end

print multiple(2, 8)
```
