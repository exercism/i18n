# Anleitung

Du bist gerade dabei, das neue, hoch geschätzte Spiel **Wings Quest** zu entwickeln.
Im Spiel bist du ein Vogel, der umherfliegt und Samen sammelt.
Der Spieler gewinnt, indem er alle Samen einsammelt.
Wenn der Spieler mit einem Adler in Berührung kommt, verliert er alle seine Samen und damit das Spiel.
Es gibt eine Ausnahme von dieser Regel: Der Spieler kann ein aktives Power-up haben, das ihn höher fliegen lässt als andere Vögel.

Dein Ziel ist es, einige Regeln zu schreiben, die im Spiel verwendet werden.

## 1. Lege fest, ob der Vogel Bonuspunkte bekommt

Im Spiel bekommt der Vogel Bonuspunkte, wenn er einen Adler berührt, während er ein Power-up hat.

Definiere die Funktion `bonusPoints(powerUpActive:touchingEagle:)`, die zwei Argumente entgegennimmt: `powerUpActive`, das angibt, ob der Vogel ein aktives Power-up hat, und das Argument `touchingEagle`, das angibt, ob der Vogel einen Adler berührt.
Die Funktion sollte nur dann `true` zurückgeben, wenn der Vogel ein aktives Power-up hat und einen Adler berührt, und ansonsten `false`.

```Swift
bonusPoints(powerUpActive: false, touchingEagle: true)
// Returns false
```

## 2. Lege fest, ob der Vogel punktet

Im Spiel bekommt der Spieler Punkte, wenn er einen Samen oder ein Power-up einsammelt.

Definiere die Funktion `score(touchingPowerUp:touchingSeed:)`, die zwei Argumente entgegennimmt: `touchingPowerUp`, das angibt, ob der Vogel ein Power-up berührt, und das Argument `touchingSeed`, das angibt, ob der Vogel einen Samen berührt.
Die Funktion sollte `true` zurückgeben, wenn der Vogel ein Power-up oder einen Samen berührt, und ansonsten `false`.

```Swift
score(touchingPowerUp: true, touchingSeed: true)
// Returns true
```

## 3. Lege fest, ob der Vogel verliert

Definiere die Funktion `lose(powerUpActive:touchingEagle:)`, die zwei Argumente entgegennimmt: `powerUpActive`, das angibt, ob der Vogel ein aktives Power-up hat, und das Argument `touchingEagle`, das angibt, ob der Vogel einen Adler berührt.
Die Funktion sollte `true` zurückgeben, wenn die Figur einen Adler berührt und kein aktives Power-up hat, und ansonsten `false`.

```Swift
lose(powerUpActive: false, touchingEagle: true)
// Returns true
```

## 4. Lege fest, ob der Vogel gewinnt

Definiere die Funktion `win(hasPickedUpAllSeeds:powerUpActive:touchingEagle:)`, die folgende Argumente entgegennimmt:

- `hasPickedUpAllSeeds`: ob der Vogel alle Samen eingesammelt hat.
- `powerUpActive`: ob der Vogel ein aktives Power-up hat.
- `touchingEagle`: ob der Vogel einen Adler berührt.

Die Funktion sollte `true` zurückgeben, wenn der Vogel alle Samen gesammelt hat und gemäß den in Teil 3 definierten Argumenten nicht verloren hat, und ansonsten `false`.

```Swift
win(hasPickedUpAllSeeds: false, powerUpActive: true, touchingEagle: false)
// Returns false
```
