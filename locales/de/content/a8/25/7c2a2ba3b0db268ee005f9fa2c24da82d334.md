# Anleitung

In dieser Übung schreibst du Code, der einem Freelancer bei der Kommunikation mit einem Projektmanager hilft.
Deine Aufgabe ist es, ein paar Hilfsfunktionen bereitzustellen, mit denen du schnell Tages- und Monatssätze berechnen kannst, optional mit einem gegebenen Rabatt.

Zuerst legen wir ein paar Regeln zwischen dem Freelancer und dem Projektmanager fest:

- Der Tagessatz ist das 8-Fache des Stundensatzes.
- Ein Monat hat 22 abrechenbare Tage.

Manchmal bietet der Freelancer an, einen Rabatt auf seinen Tagessatz zu gewähren (zum Beispiel für seine treuesten Kunden oder gemeinnützige Kunden).

Rabatte werden als Bruchzahlen modelliert, die Prozentwerte darstellen, zum Beispiel `25.0` (25 %).

~~~~exercism/note
Das sind die Suffixe für Gleitkomma-Befehle:

| Suffix | Operandengröße |
|--------|--------------|
| `ss`   | 32 Bit       |
| `sd`   | 64 Bit       |

Das sind einige der Befehle, die in diesem Konzept erwähnt werden:

| Befehl       | Beschreibung                                                  |
|-------------------------|--------------------------------------------------------|
| movss/movsd a, b        | kopiert b nach a                                       |
| addss/addsd a, b        | a = a + b                                              |
| subss/subsd a, b        | a = a - b                                              |
| mulss/mulsd a, b        | a = a * b                                              |
| divss/divsd a, b        | a = a / b                                              |
| cvtsi2ss/cvtsi2sd a, b  | wandelt die Ganzzahl b in die Gleitkommazahl a um      |
| roundss/roundsd a, b, c | rundet die Gleitkommazahl b gemäß c und speichert das Ergebnis in a |
| cvtss2si/cvtsd2si a, b  | wandelt die Gleitkommazahl b in die Ganzzahl a um      |
| comiss/comisd a, b      | vergleicht a und b, löst eine Ausnahme aus, wenn `NaN` |
| ucomiss/ucomisd a, b    | vergleicht a und b, setzt `PF`, wenn `NaN`             |

Das sind die Rundungssteuerzahlen in `roundss` und `roundsd`:

| Zahl   | Modus        |
|:-------|:-------------|
| 0      | Nächster Wert |
| 1      | Abrunden (nach unten) |
| 2      | Aufrunden (nach oben) |
| 3      | Abschneiden  |
~~~~

## 1. Tagessatz anhand eines Stundensatzes berechnen

Implementiere eine Funktion namens `daily_rate`, die den Tagessatz anhand eines als Parameter übergebenen Stundensatzes berechnet, einer 64-Bit-Gleitkommazahl.
Der Vertrag legt fest, dass ein Tag 8 abrechenbare Stunden hat.

```c
daily_rate(60)
// => 480.0
```

Der zurückgegebene Tagessatz sollte eine 64-Bit-Gleitkommazahl sein.

## 2. Einen rabattierten Preis berechnen

Implementiere eine Funktion `apply_discount`, die den Preis nach einem Rabatt berechnet.
Sie sollte zwei Parameter akzeptieren: den ursprünglichen Preis und den Rabattsatz in Prozent, beide als 64-Bit-Gleitkommazahl.

```c
apply_discount(150.0, 10.0)
// => 135.0
```

Der zurückgegebene Wert sollte immer eine 64-Bit-Gleitkommazahl sein.

## 3. Monatssatz anhand eines Stundensatzes und eines Rabatts berechnen

Implementiere eine Funktion `monthly_rate`, die den rabattierten Monatssatz berechnet.
Sie nimmt zwei Parameter, einen Stundensatz und den Rabatt in Prozent, beide als 64-Bit-Gleitkommazahl.

```c
monthly_rate(77.0, 10.5)
// => 12130
```

Der zurückgegebene Monatssatz sollte auf die nächste 64-Bit-Ganzzahl aufgerundet werden (nimm also die Obergrenze).

## 4. Die Anzahl der vollständigen Arbeitstage anhand eines Budgets, eines Stundensatzes und eines Rabatts berechnen

Implementiere eine Funktion `days_in_budget`, die folgende Parameter nimmt:

1. Ein Budget als 64-Bit-Ganzzahl ohne Vorzeichen.
2. Einen Stundensatz als 64-Bit-Gleitkommazahl.
3. Einen Rabatt in Prozent als 64-Bit-Gleitkommazahl.

Diese Funktion sollte die Anzahl der vollständigen Arbeitstage zurückgeben, die das Budget abdeckt.

```c
days_in_budget(20000, 80, 11.0)
// => 35
```

Die zurückgegebene Anzahl von Tagen sollte auf die nächste 32-Bit-Ganzzahl abgerundet werden (nimm also die Untergrenze).
