# kein rescue

Verwende keine Exceptions, um den Programmfluss zu steuern.
Versuche, diese Übung ohne `rescue` zu lösen.

Wenn du eine Funktion aus der Standardbibliothek benutzt, deren Name mit einem `!` endet (sie wirft Fehler), suche nach einer entsprechenden Funktion ohne `!` (diese geben oft `{:ok, result}` oder `{:error, message}` zurück).

Hinweis: Wenn du diesen automatischen Kommentar zu deiner Lösung siehst, sind andere automatische Kommentare möglicherweise nicht korrekt.
Behebe zuerst dieses Problem!

```elixir
# preferred: for example `case`

case Date.new(1999, 13, 1) do
  {:ok, date} -> date
  {:error, _} -> nil
end

# discouraged: rescuing exceptions

try do
  Date.new!(1999, 13, 1)
rescue
  ArgumentError ->
    nil
end
```
