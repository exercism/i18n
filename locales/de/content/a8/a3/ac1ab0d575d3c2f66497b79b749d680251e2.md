# Einführung

Die for-Schleife ist eine der am häufigsten verwendeten Anweisungen, um eine Logik wiederholt auszuführen.
In JavaScript besteht sie aus dem Schlüsselwort `for`, einem _Header_ in runden Klammern und einem Block in geschweiften Klammern, der den _Schleifenblock_ enthält.

```javascript
for (initialization; condition; step) {
  // code that is executed repeatedly as long as the condition is true
}
```

Die Initialisierung richtet normalerweise eine Zählvariable ein, die Bedingung prüft, ob die Schleife fortgesetzt oder beendet werden soll, und der Schritt erhöht am Ende jeder Wiederholung den Zähler.
Die einzelnen Teile des Headers werden durch Semikolons getrennt.

```javascript
const list = ['a', 'b', 'c'];
for (let i = 0; i < list.length; i++) {
  // code that should be executed for each item list[i]
}
```

Den Schritt legst du oft mit dem Inkrement- oder Dekrementoperator von JavaScript fest, wie im Beispiel oben gezeigt.
Diese Operatoren verändern eine Variable direkt an Ort und Stelle.
`++` addiert eins zu einer Zahl, `--` subtrahiert eins von einer Zahl.

```javascript
let i = 3;
i++;
// i is now 4

let j = 0;
j--;
// j is now -1
```
