# Bedingte Anweisungen

Eine **bedingte Anweisung** wählt zwischen zwei Vorgehensweisen aus, je nachdem,
ob etwas wahr ist.

```sather
   verdict(score : INT) : STR is
      if score >= 5 then
         return "Recalled";
      else
         return "Thank you";
      end;
   end;
```

Das liest sich so: `if`, dann eine Frage, die mit `true` oder `false`
beantwortet wird, dann `then`. Die Zeilen nach `then` werden ausgeführt, wenn
die Antwort wahr ist, und die Zeilen nach `else` werden ausgeführt, wenn sie
falsch ist. `end;` schließt das Ganze ab.

## Mehr als zwei Möglichkeiten

`elsif` fügt eine weitere Frage hinzu, die nur dann gestellt wird, wenn die
Fragen darüber falsch ausgegangen sind.

```sather
   verdict(score : INT) : STR is
      if score >= 8 then
         return "Cast";
      elsif score >= 5 then
         return "Recalled";
      else
         return "Thank you";
      end;
   end;
```

Auf die Reihenfolge kommt es an. Eine Punktzahl von `9` wird von der ersten
Frage abgefangen und erreicht die zweite nie, obwohl `9 >= 5` ebenfalls wahr
ist. Der übliche Fehler ist, die Abfragen in der falschen Reihenfolge zu
schreiben.

Es heißt `elsif`, nicht `elseif` und auch nicht `else if`.

## Das else weglassen

`else` darf weggelassen werden, wenn in diesem Fall nichts zu tun ist.

```sather
   if late then
      apologise;
   end;
```

Eine Routine, die etwas zurückgeben muss, braucht auf jedem Weg eine Rückgabe.
Deshalb behält in dieser Übung jedes `if` sein `else`.
