# Anweisungen

Simuliere ein Bankkonto, das das Eröffnen und Schließen sowie Abhebungen und Einzahlungen von Geld unterstützt. Achte auf gleichzeitige Transaktionen!

Auf ein Bankkonto kann auf verschiedene Arten zugegriffen werden. Kunden können über das Internet, mit dem Handy und so weiter Geld einzahlen und abheben. Geschäfte können das Konto belasten.

Erstelle ein Konto, auf das aus mehreren Threads/Prozessen zugegriffen werden kann (die Bezeichnung hängt von deiner Programmiersprache ab).

Es sollte möglich sein, ein Konto zu schließen; Operationen auf einem geschlossenen Konto müssen fehlschlagen.

## Anweisungen

Führe die Testdatei aus und behebe nacheinander jeden der Fehler. Wenn der erste Test bestanden ist, gehe zum ersten ausstehenden oder übersprungenen Test und lass auch diesen bestehen. Wenn alle Tests bestanden sind, kannst du die Lösung gerne einreichen.

Denk daran, dass bestandener Code nur der erste Schritt ist. Das Ziel ist eine Lösung, die so lesbar und ausdrucksstark ist, wie du sie hinbekommst.
