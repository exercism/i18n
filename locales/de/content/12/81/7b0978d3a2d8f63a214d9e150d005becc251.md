# Verwende `||` anstelle von if-else

Wenn du einen Wert ändern möchtest, falls er `nil` oder einen anderen falsy-Wert enthält, verwende den Operator `||` anstelle einer if-else-Anweisung.
Das ist idiomatischer und knapper und außerdem performanter.

Der Operator `||` gibt den Wert links vom Operator zurück, wenn dieser truthy ist. Andernfalls gibt er den Wert rechts vom Operator zurück.

Zum Beispiel:

```crystal
# Rather than:
value.nil? ? "default" : value

# Consider:
value || "default"
```
