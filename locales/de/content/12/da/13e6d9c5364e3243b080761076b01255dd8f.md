# Der Tupeltyp

Ein Tupel ist ein vielseitiger und effizienter zusammengesetzter Datentyp in Cairo. Damit kannst du mehrere Werte unterschiedlichen Typs zu einer Einheit zusammenfassen.
Tupel haben eine feste Länge: Ihre Größe lässt sich nach der Deklaration nicht mehr ändern.

## Tupel erstellen

Um ein Tupel zu erstellen, schreibst du eine kommagetrennte Liste von Werten in runde Klammern.
Jede Position im Tupel hat einen bestimmten Typ, und diese Typen dürfen sich voneinander unterscheiden.

```rust
fn main() {
    let tup: (u32, u64, bool) = (10, 20, true);
}
```

Ein Tupel kann mehrere Werte unterschiedlicher Datentypen enthalten, auch andere Tupel.
Zum Beispiel:

```rust
fn main() {
    let nested_tup: ((i32, u64), (u8, bool)) = ((10, 3), (5, false));
}
```

Hier ist die Variable `nested_tup` ein Tupel, das zwei Tupel enthält. Das zeigt, dass Tupel andere Tupel als Elemente aufnehmen können.

## Tupel destrukturieren

Um auf die einzelnen Werte in einem Tupel zuzugreifen, kannst du das Tupel mithilfe von Musterabgleich destrukturieren.
Dabei zerlegst du das Tupel in seine Bestandteile.

```rust
fn main() {
    let tup = (500, 6, true);

    let (x, y, z) = tup;

    println!("x is: {x}"); // prints "x is: 500"
    println!("y is: {y}"); // prints "x is: 6"
    println!("z is: {z}"); // prints "z is: true"
}
```

## Gleichzeitig deklarieren und destrukturieren

Du kannst ein Tupel auch gleichzeitig deklarieren und destrukturieren.

```rust
fn main() {
    let (x, y): (felt252, felt252) = (2, 3);
}
```

## Der Einheitstyp `()`

Der Einheitstyp ist ein besonderer Typ in Cairo, der nur einen einzigen Wert hat: `()`.
Er wird durch ein Tupel ohne Elemente dargestellt.
Die Größe des Einheitstyps ist immer null, und er existiert garantiert nicht im kompilierten Code.

In Cairo gibt jeder Ausdruck einen Wert zurück. Wenn ein Ausdruck nichts zurückgibt, gibt er implizit `()` zurück.
Das ist nützlich für Funktionen, die zwar einen Wert zurückgeben müssen, aber keinen sinnvollen Wert haben.

## Deklaration eines benannten Tupeltyps

Mit einem benannten Tupel kannst du einen aussagekräftigeren Typalias für ein Tupel anlegen und so die Lesbarkeit des Codes verbessern.

```rust
type Point = (u32, u32);

fn main() {
    let point: Point = (10, 8);
    println!("{point:?}"); // prints "(10, 8)"
}
```

In diesem Beispiel ist `Point` ein benannter Tupeltyp, der ein Paar vorzeichenloser 32-Bit-Ganzzahlen darstellt, was den Code ausdrucksstärker macht.
