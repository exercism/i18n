# Einführung

Perl ist eine Programmiersprache von Larry Wall, die erstmals 1987 veröffentlicht wurde.

## Pakete und Module

Ein Paket ist eine Sammlung von Code, die oft in einer Moduldatei mit demselben Namen und der Endung `.pm` liegt.
Das Modul kannst du dann in eine andere Datei importieren, normalerweise mit dem Schlüsselwort `use`.

```perl
# Foo.pm
package Foo;

# Accessible with `Foo::bar` when module is used
# or just `bar` if the subroutine is exported.
sub bar () {
    return 1;
}
```

## Variablen

Es gibt skalare Variablen (`$foo`), Array-Variablen (`@bar`) und Hash-Variablen (`%baz`).
Um es einfach zu halten, verwenden wir hier nur skalare Variablen.
Ein skalarer Wert kann Folgendes sein: ein String, eine Zahl, ein boolescher Wert oder eine [Referenz][perlreftut] auf etwas.
Wenn ein Wert fehlt, ist er `undef`.


Die Schlüsselwörter `my` und `our` deklarieren eine Variable im lexikalischen Gültigkeitsbereich, z. B. `my $foo;`.
Bei `our` wird die Variable zusätzlich als Alias auf eine Paketvariable mit demselben Namen angelegt.
Es gibt noch andere Möglichkeiten, Variablen zu deklarieren, die wir hier aber nicht behandeln.

Du kannst einer Variable mit dem Operator `=` einen Wert zuweisen, z. B. `$foo = 1;`, was auch gleichzeitig mit der Deklaration geschehen kann, z. B. `my $foo = 1;`.

```perl
package Foo;

sub baz () {
    our $bar = 1; # Sets both $bar and $Foo::bar as 1.
    return $bar;
}

$Foo::bar = 2; # $bar is not accessible here, but $Foo::bar is.

# Both of these will print 1.
say baz;
say $Foo::bar;
```

## Subroutinen

Das Schlüsselwort `sub` deklariert eine [Subroutine][perlsub].
Das Schlüsselwort `return` verlässt die Subroutine und gibt die angegebenen Werte zurück, oder eine leere Liste, wenn keine angegeben sind.
Ohne ein ausdrückliches `return` wird der Rückgabewert durch den Kontext (skalar, Liste oder void) der genutzten Subroutine und ihrer letzten Anweisung bestimmt.

```perl
sub hello () {
    return 'Hello, World!';
}
```

Neuere Perl-Versionen erlauben es dir, formale Parameter in einer [Signatur][perlsubsig] anzugeben.
Die Parameterliste kann skalare, Array- oder Hash-Variablen enthalten.
Eine leere Parameterliste bedeutet, dass die Subroutine keine Argumente akzeptiert.
In älteren Perl-Versionen musstest du die Argumente aus der speziellen Variable `@_` holen, was wir hier nicht behandeln.
