# Einführung

Wir gehen davon aus, dass du mit der JSON-Syntax und den Datentypen vertraut bist.

jq arbeitet, indem es die eingehenden JSON-Daten durch einen _einzigen Ausdruck_ (geschrieben als _Pipeline aus Filtern_) leitet, um die gewünschten transformierten Daten zu erhalten.

<!-- prettier-ignore -->
~~~~exercism/note
Die Programmiersprache `jq` wird durch das `jq`-_Programm_ implementiert.
Dieses Programm bietet mehrere praktische Kommandozeilenoptionen, mit denen du steuerst, wie die Eingabe verarbeitet und wie die Ausgabe dargestellt wird.

In den folgenden Beispielen wirst du auf Folgendes stoßen:

- `-n` oder `--null-input`

    Normalerweise bekommt das `jq`-Programm eine Datei zum Lesen, oder du schickst Daten an seine Eingabe.
    Die Option `--null-input` erlaubt es dir, JSON-Daten ohne jegliche Eingaben zu erzeugen.

- `-c` oder `--compact-output`

    Standardmäßig gibt `jq` seine Ausgabe formatiert aus.
    Für Menschen ist es äußerst nützlich, die Daten anzusehen, wenn sie schön formatiert sind.
    Für Maschinen ist das jedoch nicht notwendig: Die Option `--compact-output` entfernt die Formatierungs-Leerzeichen, um die Größe des resultierenden JSON zu minimieren.

- `-f filename` oder `--from-file filename`

    Lies das `jq`-Programm aus `filename`, anstatt es auf der Kommandozeile anzugeben.
    Sowohl `sed` als auch `awk` verwenden die Option `-f` zu demselben Zweck.
    Du wirst sehen, dass dies in den Testskripten für die Übungen verwendet wird.

Der Rest dieser Lektion konzentriert sich auf die _Programmiersprache_ `jq`.
~~~~

## Filter und Pipes

**Filter** werden auch **Ausdrücke** genannt.

Ein _Filter_ nimmt eine Eingabe und erzeugt eine Ausgabe.
So wie du in einer Unix-Shell arbeitest, kannst du _Filter_ mit einer Pipe `|` verbinden, um die Ausgabe eines _Filters_ mit der Eingabe eines anderen zu verbinden.

## Der Identitätsfilter: `.`

Dies ist der einfachste _Filter_.
Er reicht seine Eingabe einfach an seine Ausgabe weiter.

```sh
$ echo '[1, 2, 3]' | jq '.'
[
  1,
  2,
  3
]
```

## Arrays

Dies ist eine kurze Einführung in die Arbeit mit **Arrays**.
Wir werden dieses Thema später ausführlicher behandeln.

Auf die Elemente eines _Arrays_ greifst du mit eckigen Klammern zu; die Indizierung beginnt bei null.

```sh
$ echo '[10, 20, 30]' | jq '.[1]'
20
```

Ein _Filter_ kann ein _Array_ aufbauen, indem er einen Ausdruck in `[` und `]` einschließt

- mit einer bekannten Liste von Elementen:

  ```sh
  jq -n '[1, 2, 3]'
  ```

- um einen Datenstrom von Elementen zu sammeln: zum Beispiel
  ist `range` eine Funktion, die einen Datenstrom von Zahlen ausgibt

  ```sh
  $ jq -n 'range(10; 70; 15)'
  10
  25
  40
  55
  ```

  Mit `[]` sammelst du die Ergebnisse des Ausdrucks in einem Array

  ```sh
  $ jq -c -n '[range(10; 70; 15)]'
  [10,25,40,55]
  ```

## Das Komma ist ein Operator

Das _Komma_ ist nicht nur Syntax, die _Array_-Elemente trennt.
Das **Komma** ist ein **Operator**, der Datenströme verbindet.

Zum Beispiel ist `[1, 2, 3]` ein _Filter_, der den _Array_-Konstruktor `[]` verwendet, um das Ergebnis der Verknüpfung der drei Ausdrücke `1`, `2` und `3` zu sammeln.

Hast du die Semikolons in `range(10; 70; 15)` oben bemerkt?
Weil _Kommas_ in der Programmiersprache `jq` einen bestimmten Zweck haben, verwenden Funktionen mit mehreren Argumenten Semikolons, um die Argumente zu trennen.

## Objekte

Eine kurze Einführung in **Objekte**.

Ähnlich wie in vielen Programmiersprachen greifst du mit Punkten auf die Eigenschaften eines _Objekts_ zu

```sh
$ echo '{"foo": {"bar": "qux"}}' | jq '.foo.bar'
"qux"
```

<!-- prettier-ignore -->
~~~~exercism/note
Eckige Klammern kannst du auch für _Objekte_ verwenden, aber dann brauchst du Anführungszeichen für String-Literale.
Dies ist eine Methode, um mit Schlüsseln zu arbeiten, die Leerzeichen enthalten.

```sh
$ echo '{"foo bar": "qux"}' | jq '.["foo bar"]'
"qux"
```
~~~~

<!-- prettier-ignore-end -->

Du kannst ein _Objekt_ mit `{}` und `key: value`-Paaren konstruieren.
Anführungszeichen sind um _Schlüssel_ nicht erforderlich, die „einfache“ Strings sind.

```sh
jq -n '{question: (6 * 9), answer: 42}'
```

gibt aus

```none
{
  "question": 54,
  "answer": 42
}
```

Um den _Schlüssel_ als _Ausdruck_ zu behandeln, musst du ihn in runde Klammern setzen (das Folgende gibt ebenfalls dasselbe aus wie oben).

```sh
echo '[{"key":"question", "value":54}, {"key":"answer", "value":42}]' \
| jq '{(.[0].key): .[0].value, (.[1].key): .[1].value}'
```

## Pipelines

Zum Beispiel: `file.json` enthält

```json
{
  "key1": "value1",
  "key2": [5, 15, 25]
}
```

Berechnen wir die Länge des _Arrays_ key2:

```sh
$ jq '.key2 | length' file.json
3
```

Wir _leiten_ die Ausgabe des Ausdrucks `.key2` als Eingabe an `length` weiter, das wenig überraschend die Anzahl der Elemente im _Array_ ausgibt.

## Filter können ihre Eingabe ignorieren

In diesem Beispiel werden die eingehenden JSON-Daten ignoriert und haben keinen Einfluss auf die Ausgabe:

```sh
$ echo '{"answer": 42}' | jq '6 * 9'
54
```

## Filter können Datenströme ausgeben

Ein _Filter_ kann mehr als einen Wert ausgeben.
Zum Beispiel gibt der _Filter_ `.[]` jedes Element eines _Arrays_ als separaten Wert aus:

```sh
$ jq -n -c '[1, 2, 3]'
[1,2,3]

$ jq -n -c '[1, 2, 3] | .[]'
1
2
3
```

Wenn du einen solchen _Filter_ in einen anderen leitest, wird der zweite _Filter_ **_für jeden Wert_** ausgeführt:

```sh
$ jq -n -c '[1, 2, 3] | .[] | . * 2'
2
4
6
```

Das ist wie eine implizite Iteration.
Sobald du diese Technik verstehst, wirst du erkennen, dass sehr mächtige `jq`-_Filter_ sehr knapp sein können.

## Runde Klammern

**Runde Klammern** gruppieren Teilausdrücke, um die Reihenfolge der Operationen zu erzwingen, genau wie in anderen Sprachen.
In `jq` kann die Notwendigkeit dafür etwas überraschend erscheinen.

Angenommen, wir wollen ein _Array_ mit 2 Elementen konstruieren: die Quadratwurzel von 9; und _e_ hoch 1.
Die beiden einzelnen Ausdrücke sind `9 | sqrt` und `1 | exp`.
Wir erwarten, dass die Ausgabe das _Array_ `[3, 2.7...]` ist

```jq
$ jq -n '[ 9|sqrt, 1|exp ]'
[
  20.085536923187668,
  2.718281828459045
]
```

Warum haben wir nicht bekommen, was wir erwartet haben? `jq` interpretiert das so:

```jq
[ ((9|sqrt), 1) | exp ]
```

`jq` baut einen Datenstrom aus zwei Elementen (`3` und `1`) auf, die jeweils an `exp` übergeben werden.

Wir müssen sicherstellen, dass `exp` nur eine Zahl als Eingabe nimmt.
Mit anderen Worten, wir müssen erzwingen, dass die Pipe vor dem Komma ausgewertet wird.

```jq
$ jq -n '[ 9|sqrt, (1|exp) ]'
[
  3,
  2.718281828459045
]
```

## Funktionen und Operatoren

Ohne zu sehr ins Detail zu gehen (Funktionen sind ein Thema für eine andere Übung), hier einige nützliche eingebaute Funktionen:

- `length`

  Erhält ein Array als Eingabe und gibt die Anzahl der Elemente im Array aus.

  ```sh
  $ jq -n '[10, 20, 30, 40] | length'
  4
  ```

- `+`

  Dieser Operator tut je nach Typ seiner Operanden unterschiedliche Dinge:
  Er addiert Zahlen,
  er verkettet Strings,
  er hängt Arrays aneinander,
  er führt Objekte zusammen.

  ```sh
  $ jq -c -n '
      3 + 4,
      "foo" + "bar",
      ["a", "b"] + ["c"],
      {"m": 10} + {"n": 20}
  '
  7
  "foobar"
  ["a","b","c"]
  {"m":10,"n":20}
  ```

  `add` ist eine Funktion, die ein Array nimmt und ein Element zurückgibt, bei dem alle Elemente nach den Regeln von `+` zusammengezählt wurden.
  `[1, 2, 3] | add` gibt `6` aus.

- `map`

  Erhält ein Array als Eingabe und einen Filter als Argument und gibt ein Array aus, bei dem der Filter auf jedes Element angewendet wird

  ```sh
  $ jq -c -n '[10, 20, 30, 40] | map(. / 5)'
  [2,4,6,8]
  ```

- `select`

  Erhält _irgendeine_ Eingabe und einen Filter als Argument:
  - Wenn der auf das Argument angewendete Filter einen _wahren_ Wert ergibt, gib die Eingabe unverändert aus
  - Andernfalls gib _nichts_ aus (nicht den Wert `null`, wirklich keine Ausgabe)

  Zum Beispiel: Wähle aus einigen Zahlen die durch 3 teilbaren aus

  ```sh
  $ jq -n 'range(10) | select(. % 3 == 0)'
  0
  3
  6
  9
  ```

  Erinnere dich daran, dass `range` einen _Datenstrom_ von Zahlen ausgibt.
  `select` wird für jede Zahl einmal aufgerufen.
  Nur die Zahlen, die den Ausdruck „bestehen“, werden ausgegeben.

  Oft musst du Elemente eines Arrays auswählen.
  Dafür gibt es ein paar Möglichkeiten.

  Wähle aus der Eingabe `["Anne", "Bob", "Cathy", "Dave"]` die Namen mit der Länge 4 aus.
  - Verwende `map` und `select` zusammen

    ```jq
    map(select(length == 4))
    ```

  - Zerlege das Array in Elemente, wende `select` auf diesen Strom an und sammle die Ergebnisse

    ```jq
    [ .[] | select(length == 4) ]
    ```
