# Hinweise

## Allgemein

- Die Laufzeit dieser Übung hängt stark vom verwendeten Algorithmus ab, plane also von Anfang an auf Geschwindigkeit.
- Die Tests prüfen bewusst auf eine große Primzahl, und schlecht konzipierte Lösungen laufen in ein Timeout.
- Julia-Code läuft oft schneller, wenn du häufig verwendete Zeilen in eine separate Funktion auslagerst (die du optional in die Hauptfunktion einbetten kannst).
  - Anders als in manchen anderen Sprachen ist in Julia die Vorabkompilierung wichtiger als der Overhead durch Funktionsaufrufe.
- _Welche Werte musst du prüfen, um sicherzugehen, dass sie keine Teiler sind, bevor du eine Zahl zur Primzahl erklärst?_ Halte diese Gruppe so klein wie möglich!
