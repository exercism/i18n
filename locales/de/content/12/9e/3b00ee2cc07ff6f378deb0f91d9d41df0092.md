# Einführung

Ein `String` in Java ist ein Objekt, das unveränderlichen Text als eine Folge von Unicode-Zeichen (Buchstaben, Ziffern, Satzzeichen usw.) darstellt.
Mit doppelten Anführungszeichen definierst du eine `String`-Instanz:

```java
String fruit = "Apple";
```

Zeichenketten werden manipuliert, indem du die Methoden der Zeichenkette aufrufst.
Sobald eine Zeichenkette erstellt wurde, kann ihr Wert sich nie ändern.
Alle Methoden, die eine Zeichenkette zu verändern scheinen, geben tatsächlich eine neue Zeichenkette zurück.
Die Klasse `String` bietet einige _statische_ Methoden, um die Zeichenketten umzuwandeln.
