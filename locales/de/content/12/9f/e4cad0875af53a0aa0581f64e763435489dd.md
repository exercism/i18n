# Über

Über [concept:csharp/enumerables]() kannst du mit einer [`foreach`-Schleife][foreach-statement] iterieren:

```csharp
char[] vowels = new [] { 'a', 'e', 'i', 'o', 'u' };

foreach (char vowel in vowels)
{
    // Output the vowel
    System.Console.Write(vowel);
}

// => aeiou
```

Eine `foreach`-Schleife besteht aus drei Teilen:

1. Die Deklaration: Definiere die Variable, die den jeweils iterierten Wert aufnimmt. Diese Variable kann (nur) innerhalb der Schleife verwendet werden.
2. Das iterierbare Objekt: das Objekt, über das iteriert werden kann.
3. Der Schleifenblock.

## for-Schleifen vs. foreach-Schleifen

Im Allgemeinen ist eine `foreach`-Schleife einer `for`-Schleife jedoch aus folgenden Gründen vorzuziehen:

- Bei einer `foreach`-Schleife ist garantiert, dass sie über _alle_ Werte iteriert. Bei einer `for`-Schleife übersieht man leicht Elemente, zum Beispiel wegen eines Off-by-one-Fehlers.
- Eine `foreach`-Schleife ist _deklarativer_: Dein Code teilt mit, _was_ er tun soll, während eine `for`-Schleife mitteilt, _wie_ du es tun sollst.
- Eine `foreach`-Schleife ist idiotensicher, während bei `for`-Schleifen leicht ein Off-by-one-Fehler passiert.
- Eine `foreach`-Schleife funktioniert mit allen Sammlungstypen, auch mit denen, die keinen Indexer für den Zugriff auf Elemente unterstützen.

Damit garantiert ist, dass eine `foreach`-Schleife über _alle_ Werte iteriert, erlaubt der Compiler nicht, dass eine Sammlung innerhalb einer `foreach`-Schleife geändert wird:

```csharp
char[] vowels = new [] { 'a', 'e', 'i', 'o', 'u' };

foreach (char vowel in vowels)
{
    // This would result in a compiler error
    // vowel = 'Y';
}
```

Eine `for`-Schleife hat gegenüber einer `foreach`-Schleife aber auch einige Vorteile:

- Du kannst an dem Index beginnen oder enden, den du willst.
- Du kannst jede (boolesche) Abbruchbedingung verwenden, die du willst.
- Du kannst Elemente überspringen, indem du das Erhöhen der Schleifenvariable anpasst.
- Du kannst Sammlungen von hinten nach vorne verarbeiten, indem du rückwärts zählst.
- Du kannst `for`-Schleifen in Szenarien verwenden, in denen es keine Sammlungen gibt.

Verwandte Themen:

- Du solltest wissen, dass C# [mehrdimensionale Arrays][multi-dimensional-arrays] wie `int[,] arr = new int[10, 5]` unterstützt, was sehr nützlich sein kann.
- Du solltest außerdem wissen, dass du Objekte vom Typ [`System.Array`][system-array-object] mit `Array.CreateInstance` erzeugen kannst. Solche Objekte sind wenig nützlich, hauptsächlich für die Interoperabilität mit VB.NET-Code. Sie sind nicht austauschbar mit Standard-Arrays (`T[]`). Sie können eine untere Grenze ungleich null haben.
