# String-Verkettung

String-Verkettung ist in Ruby völlig in Ordnung, aber einen String setzt man meistens mit [String-Interpolation](http://ruby-for-beginners.rubymonstas.org/bonus/string_interpolation.html) zusammen. Zum Beispiel:

```ruby
# Rather than:
"One for " + %{name_variable} + ", one for me"

# Consider:
"One for #{%{name_variable}}, one for me."
```
