# Einführung

## Truthy und Falsy

In Common Lisp sind alle Werte „wahr“, außer `()`, das „falsch“ ist.
Es gibt zwei spezielle konstante Symbole `t` und `nil`, deren Werte wahr bzw. falsch sind.

## Bedingte Ausdrücke

Common Lisp bietet mehrere verschiedene bedingte Ausdrücke. Der wichtigste Unterschied ist die Anzahl der Zweige, die sie unterstützen.

- `when` und `unless` erlauben nur einen einzigen Zweig:

```lisp
(when (= 2 2) "All is well")      ; => "All is well"
(unless (= 2 2) "Time to panic!") ; => NIL
```

Der Abschnitt nach dem Testausdruck kann aus mehr als einem Ausdruck bestehen.

- `if` bietet das klassische Wenn-Dann-Sonst-Konstrukt:

```lisp
(if (= 2 2) 'how-honest 'you-liar) ; => HOW-HONEST
```

Beachte, dass sowohl der Dann- als auch der Sonst-Zweig nur ein einzelner Ausdruck sein kann.

- `cond` bietet eine Möglichkeit, mehrere Zweige zu haben, ohne `if`-Ausdrücke zu verschachteln:

```lisp
(cond ((= 0 2) 'nope)
      ((= 1 2) 'try-again)
      ((= 2 2) 'quite-true)
      ((= 3 2) 'too-far)
      (t 'something-else))
; => QUITE-TRUE
```

Beachte, dass die Anzahl der Ausdrücke nach dem Testausdruck unbegrenzt ist. 

- `case` bietet ein klassisches Konstrukt im Stil eines „switch“: Es prüft einen einzelnen Wert gegen eine Reihe von Zweigen:

```lisp
(case 'elder-beast
  (cat "Meow")
  (bird "Chirp")
  (dog "Bark")
  (otherwise "???"))
; => "???"
```

Beachte, dass wie bei `cond` die Anzahl der Ausdrücke nach dem Testausdruck unbegrenzt ist.
