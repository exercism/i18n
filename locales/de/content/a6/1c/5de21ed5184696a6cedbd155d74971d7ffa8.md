# Einführung

## Beschriftete Felder

Wenn eine Variante eines benutzerdefinierten Typs Daten enthält, nennt man sie einen Record, und jeder enthaltene Wert liegt in einem _Feld_.

```gleam
pub type Rectangle {
  Rectangle(
    Float, // The first field
    Float, // The second field
  )
}
```

Um die Lesbarkeit zu verbessern, erlaubt es Gleam, Felder mit einem Label zu versehen.

```gleam
pub type Rectangle {
  Rectangle(
    width: Float,
    height: Float,
  )
}
```

Labels können verwendet werden, um die Argumente in beliebiger Reihenfolge an den Konstruktor eines Records zu übergeben.

```gleam
let a = Rectangle(height: 10.0, width: 20.0)
let b = Rectangle(width: 20.0, height: 10.0)

a == b
// -> True
```

Wenn ein benutzerdefinierter Typ nur eine Variante hat, kann die `.label`-Zugriffssyntax verwendet werden, um die Felder eines Records zu erhalten.

```gleam
let rect = Rectangle(height: 10.0, width: 20.0)

rect.height // -> 10.0
rect.width  // -> 20.0
```

Die Syntax zum Aktualisieren von Records kann verwendet werden, wenn ein benutzerdefinierter Typ eine einzelne Variante hat, um aus einem vorhandenen Record einen neuen zu erzeugen, bei dem einige Felder durch neue Werte ersetzt werden.

```gleam
let rect = Rectangle(height: 10.0, width: 20.0)
let tall_rect = Rectangle(..rect, height: 50.0)

tall_rect.height // -> 50.0
tall_rect.width  // -> 20.0
```

Labels können auch beim Pattern Matching verwendet werden, um Werte aus Records zu extrahieren.

```gleam
pub fn is_tall(rect: Rectangle) {
  case rect {
    Rectangle(height: h, width: _) if h >. 20.0 -> True
    _ -> False
  }
}
```

Wenn wir nur auf einige der Felder matchen möchten, können wir den Spread-Operator `..` verwenden, um die restlichen Felder zu ignorieren.

```gleam
pub fn is_tall(rect: Rectangle) {
  case rect {
    Rectangle(height: h, ..) if h >. 20.0 -> True
    _ -> False
  }
}
```
