# Einführung

Symbole in Common Lisp sind spezielle Werte, die auf andere Werte zeigen können oder, im Fall von _Keywords_, auf sich selbst.
Wenn Lisp Symbole auswertet, ersetzt es sie durch die Werte, auf die sie zeigen:

```lisp
foo  ; => <whatever-foo-points-to>
:foo ; => :FOO
```

Beachte, dass Keywords durch einen vorangestellten Doppelpunkt (`:`) gekennzeichnet werden.

Quoting, also das Voranstellen eines `'` vor einen S-Ausdruck, weist Lisp an, diesen Ausdruck nicht auszuwerten.
Indem wir in unserem `defun`-Beispiel `'foo` quoteten, haben wir verhindert, dass Lisp versucht, nachzuschlagen (und nicht zu finden), worauf `FOO` zeigen sollte; stattdessen gab Lisp den Wert `FOO` selbst zurück.
Wenn `FOO` nirgendwo in unserem Programm definiert wurde:

```lisp
foo  ; => <ERROR! Lisp doesn't know what foo points to!>
'foo ; => FOO
```

Im Moment kannst du das einfach als eine Möglichkeit betrachten, Symbole aus einer Funktion zurückzugeben, aber wir werden das Quoting später wieder aufgreifen und seine Auswirkungen in künftigen Konzeptübungen genauer untersuchen.
