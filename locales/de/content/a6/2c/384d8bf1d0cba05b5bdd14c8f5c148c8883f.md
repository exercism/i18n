# Hinweise

Für alle diese Aufgaben brauchst du den `print`-Befehl:
```awk
{print "something", "something else"}
```

## 1. Die Benutzernamen auflisten

* Verwende [die Variable `FS`][var-fs], um das Feldtrennzeichen festzulegen.

## 2. Die Zeilennummern ausgeben

* Verwende die [eingebaute Variable `NR`][var-nr], um die Zeilennummer zu erhalten.

## 3. Datensätze mit ungültigen Home-Verzeichnissen ausgeben

* Das Home-Verzeichnis ist das 6. Feld.
* Verwende die vorgegebene Funktion `startsWith`.
* Verwende [boolesche Operatoren][boolean-ops]: `&&`, `||`, `!`.

## 4. Die Anzahl der gültigen Benutzer ausgeben, die bash verwenden

* Die Login-Shell ist das letzte Feld; du kannst [die Variable `NF`][var-nf] verwenden.
