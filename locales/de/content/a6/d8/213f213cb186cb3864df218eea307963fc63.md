# Einführung

Eine Eigenschaft in Haxe ist ein Member einer Klasse, das Zugriff auf Daten innerhalb dieser Klasse bietet. Aufrufer können die Daten setzen oder abrufen (get). Sie bestehen aus einer Set-Zugriffsmethode und/oder einer Get-Zugriffsmethode.

Eigenschaften haben Zugriffsmodifikatoren (public, private usw.) wie andere Klassenmember auch. Allerdings kann die Set-Zugriffsmethode eine Zugriffsebene haben, die unabhängig von der Get-Zugriffsmethode ist, und umgekehrt. Eine Eigenschaft muss nicht beide Zugriffsmethoden haben, eine einzige genügt (entweder get oder set).

Lesezugriff und Schreibzugriff spiegeln sich direkt in der Syntax wider, wie das folgende Beispiel zeigt:

```haxe
class Main {
  public var x(default, null):Int;
}
```

Sowohl `default` als auch `null` sind spezielle **Zugriffsbezeichner**. Die Zugriffsbezeichner legen das Verhalten fest, wenn das Feld gelesen wird (erster Bezeichner) und wenn das Feld geschrieben wird (zweiter Bezeichner). Zulässig sind:

- `default`: Erlaubt den normalen Zugriff auf das Feld, wenn das Feld public ist.
- `null`: Erlaubt Zugriff nur aus der definierenden Klasse heraus.
- `get/set`: Der Zugriff wird als Aufruf einer Zugriffsmethode (`get_x()`) generiert.
- `dynamic`: Wie `get/set`, aber die Existenz einer Zugriffsmethode lässt sich nicht überprüfen.
- `never`: Erlaubt überhaupt keinen Zugriff.

Hier ist ein vollständiges Beispiel:

```haxe
class Main {
  public var x(default, set):Int;

  public function set_x(x:Int):Int {
    return this.x = x + 2;
  }

  public function main() {
    trace(x); // null
    x = 2;
    trace(x); // 4
  }
}
```
