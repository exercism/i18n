# Überblick

Go ist statisch typisiert, daher hat jede Variable einen Typ, der zur Kompilierzeit bekannt ist. Nach der Deklaration kann sich der Typ einer Variablen nicht ändern.

## Eine Variable erstellen

Die `var`-Anweisung kann den Typ einer neuen Variable deklarieren, ihren Wert festlegen oder beides gleichzeitig tun:

```go
var total int     // Type explicitly declared, value implicitly set (see note on zero values below)
var count int = 1 // Type explicitly declared, value explicitly set
var sum = 100     // Type implictly declared, value explicitly set
```

Innerhalb einer Funktion kann auch die kurze Zuweisungsanweisung `:=` verwendet werden.

```go
count := 1 // Type implictly declared, value explicitly set
```

Eine Variable in Go hat immer einen Wert. Wenn bei der Deklaration keiner festgelegt wird, stellt Go einen [sogenannten Nullwert][zero-values] bereit, basierend auf dem Typ der Variablen.

```go
var total int     // 0
var name string   // ""
var ready bool    // false
```

## Eine Variable aktualisieren

Innerhalb einer Funktion kann der Zuweisungsoperator `=` einer vorhandenen Variable einen neuen Wert zuweisen:

```go
count := 1
count = 2
```

Der neue Wert muss denselben Typ wie die Variable haben:

```go
count := 1
count = false // compile error: a Boolean is not an int
```

[zero-values]: https://exercism.org/tracks/go/concepts/zero-values
