# Iteration

In der Programmierung bezeichnet [Iteration][iteration] das Wiederholen eines Blocks Code.
Das kannst du mit Konzepten wie while-Schleifen und until-Schleifen erreichen.
Es geht auch mit Rekursion, also einer Funktion, die sich selbst aufruft.

Meistens möchtest du jedoch über eine Sammlung von Elementen iterieren, zum Beispiel über ein `Array`, einen `Range` oder einen `String`.
Die Klassen `Array` und `Range` in Crystal binden das Modul [`Enumerable`][enumerable] ein, das eine Reihe von Methoden zum Iterieren über die Elemente bereitstellt.
Die Klasse `String` hat dagegen ihre eigenen Methoden zum Iterieren über die Zeichen.

Crystal hat auch keine for-Anweisung wie andere Sprachen.
Stattdessen gibt es mehrere Methoden, mit denen du iterieren kannst.

## Iterieren

Die gebräuchlichste Art, über eine Sammlung zu iterieren, ist die Methode [`each`][each], die jedes Element der Sammlung an einen Block übergibt.
Mit einem `Range` geht das ganz einfach.
Angenommen, du möchtest von 1 bis 3 durchlaufen, dann kannst du mit der Methode `each` über den Bereich iterieren.

```crystal
(1..3).each do |n|
  puts n
end

# Output:
# 1
# 2
# 3
```

Noch einfacher: Wenn du nur eine bestimmte Anzahl von Malen iterieren möchtest, kannst du die Methode [`times`][times] verwenden, die es in der Klasse `Int` gibt.

```crystal
3.times do |n|
  puts n
end

# Output:
# 0
# 1
# 2
```

## Über einen `String` iterieren

Ein `String` ist eine Folge von Zeichen und gehört nicht zum Modul `Enumerable`.
Deshalb hat er seine eigenen Methoden zum Iterieren über die Zeichen.
Am gebräuchlichsten ist die Methode [`each_char`][each_char], die jedes Zeichen im `String` an einen Block übergibt.

~~~~exercism/note
Die Methode `each_char` übergibt dem Block ein `Char`-Objekt und kein `String`-Objekt.
~~~~

```crystal
str = "hello"
str.each_char { |char| puts char }

# Output:
# h
# e
# l
# l
# o
```

Eine andere Möglichkeit, über einen `String` zu iterieren, ist die Methode [`each_line`][each_line].
Diese Methode wird meist verwendet, wenn du eine Datei Zeile für Zeile liest.

```crystal
str = "hello\nworld"
str.each_line do |line|
  puts line
end

# Output:
# hello
# world
```

## Über ein Objekt iterieren, das das `Enumerable`-Modul einbindet

Das Modul [`Enumerable`][enumerable] bietet eine Reihe von Methoden zum Iterieren über die Elemente einer Sammlung.
Sammlungen, die das Modul `Enumerable` einbinden, sind `Array`, `Range`, `Hash`, `Set` und weitere. Die letztgenannten werden in späteren Konzepten behandelt.

Am gebräuchlichsten ist es, über ein `Array` mit der Methode [`each`][each] zu iterieren, die jedes Element im `Array` an einen Block übergibt.

```crystal
arr = [5, 2, 3]
arr.each do |element|
  puts element
end

# Output:
# 5
# 2
# 3
```

### Map

Die Methode [`map`][map] ist eine weitere Möglichkeit, über ein `Array` zu iterieren. Sie gibt ein neues `Array` zurück, das die Ergebnisse enthält, die der Block für jedes Element liefert.
Sie ähnelt der Methode `each`, gibt aber ein neues `Array` mit den transformierten Elementen zurück.
Transformationen sind sehr nützlich, wenn du eine Funktion auf jedes Element der Sammlung anwenden möchtest, was eine häufige Operation ist.

```crystal
arr = [1, 2, 3]
new_arr = arr.map do |element|
  element * 2
end

new_arr
# => [2, 4, 6]
```

Mit einer Kontrollstruktur wie `if` kannst du filtern, welche Elemente transformiert werden.

```crystal
arr = [1, 2, 3]
new_arr = arr.map do |element|
  if element.odd?
    element * 2
  else
    element
  end
end

new_arr
# => [2, 2, 6]
```

## Kurzschreibweise

In Crystal gibt es eine Kurzschreibweise, um zu iterieren und eine Methode auf jedes Element einer Sammlung anzuwenden.
Das ist nützlich bei einfacher Logik, die nur mit einer einzigen Methode transformiert werden muss.
Dazu verwendest du die Syntax `&.` gefolgt vom Methodennamen.

```crystal
arr = [1, 2, 3]
arr.map(&.to_s)
# => ["1", "2", "3"]
```

### Mit Index

Manchmal musst du den Index des Elements kennen, über das du gerade iterierst. Dafür kannst du die Methoden [`each_with_index`][each_with_index] oder [`map_with_index`][map_with_index] verwenden.
Sie übergeben jedes Element und seinen Index an einen Block. Die Methode akzeptiert außerdem ein optionales Argument, mit dem du den Startindex festlegst.

```crystal
arr = [1, 2, 3]
arr.each_with_index(4) do |element, index|
  puts "Element: #{element}, Index: #{index}"
end

# Output:
# Element: 1, Index: 4
# Element: 2, Index: 5
# Element: 3, Index: 6
```

Beachte, dass die Methode [`each_char_with_index`][each_char_with_index] auch für `String`-Objekte verfügbar ist.

### sum

Die Methode [`sum`][sum] gibt die Summe aller Elemente der Sammlung zurück. Sie akzeptiert außerdem einen optionalen Block, um die Elemente vor dem Summieren zu transformieren.
Zudem akzeptiert sie ein optionales Argument, mit dem du den Startwert der Summe festlegst.

```crystal
arr = [1, 2, 3]
arr.sum
# => 6

arr.sum(2) { |n| n * 2 }
# => 14
```

### reduce

[`reduce`][reduce], in anderen Sprachen auch als fold bekannt, ist eine Methode, die zusammen mit einer Verknüpfungsmethode und einem Anfangswert alle Elemente der Sammlung verknüpft.
Die Methode `reduce` hat einen Akkumulator, der an den Block übergeben wird. Der Akkumulator ist das Ergebnis der vorherigen Iteration.
So entsteht ein rekursiver Prozess, der alle Elemente der Sammlung verknüpft.

```crystal
arr = [1, 2, 3]
arr.reduce(0) do |acc, n|
  acc + n
end
# => 6
```

`reduce` mag `sum` ähneln, aber `reduce` ist flexibler, weil du den Anfangswert des Akkumulators und die Verknüpfungsmethode angeben kannst.
Mit `reduce` lassen sich `sum`, `count` und andere Methoden umsetzen.
