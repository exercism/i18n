# Tests auf der Kommandozeile

Roc bringt eigene, integrierte Test-Tools mit. Du musst nichts weiter installieren.

Um deine Lösung für eine Übung zu testen, öffne ein Terminal, wechsle in das Verzeichnis der Übung und führe `roc test <exercise-name>-test.roc` aus, zum Beispiel `roc test hello-world-test.roc`. Stelle sicher, dass alle Tests bestehen. Bearbeite *nicht* `*-test.roc` selbst, sondern nur die andere(n) `*.roc`-Datei(en).
