# Einführung

Am gebräuchlichsten ist es, Code in F# mit einem `if/elif/else`-Ausdruck bedingt auszuführen:

```fsharp
if x = 5 then
    printfn "Expression to evaluate when x equals 5"
elif x > 7 then
    printfn "Expression to evaluate when x greater than 7"
else
    printfn "Expression to evaluate in all other cases"
```

Die Bedingung(en), die in einem `if/elif/else`-Ausdruck verwendet werden, müssen vom Typ `bool` sein. F# kennt keine _truthy_-Werte.
