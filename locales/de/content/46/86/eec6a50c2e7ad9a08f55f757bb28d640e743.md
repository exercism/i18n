# Über

Swift ist eine kompilierte, multiparadigmatische Programmiersprache, die mit drei Hauptzielen entworfen wurde:

- **Sicherheit**: Eingebaute Sprachfunktionen helfen dabei, Bugs zu erkennen und zu verhindern, bevor dein Code in Produktion läuft.
- **Geschwindigkeit**: Optimierte Leistung, vergleichbar mit C-basierten Sprachen.
- **Ausdrucksstärke**: Klare, moderne Syntax, die sich angenehm und einfach lesen und schreiben lässt.

Apple stellte Swift 2014 als modernen Ersatz für Objective-C vor, die frühere Sprache für die Entwicklung für iOS und macOS.
Heute ist Swift Open Source und läuft auf Apple-Plattformen, Linux und Windows.

## Erste Schritte

### Variablen

Du kannst Werte speichern und benennen, indem du eine [Variable][constants-variables] definierst.
Nachdem du eine Variable definiert hast, kannst du ihren Namen verwenden, um im gesamten Code auf diesen Wert zu verweisen.
Variablen sind _veränderbar_, das heißt, ihre Werte können sich ändern, nachdem sie definiert wurden.

Eine Variable definierst du mit dem Schlüsselwort `var`:

```swift
var variableName = 10
```

Swift ist eine statisch typisierte Sprache, das heißt, jeder Wert hat zur Kompilierungszeit einen bekannten Typ.
Du kannst einen Typ mit einer [Typannotation][type annotations] explizit angeben, oder du lässt den Swift-Compiler den Typ aus dem zugewiesenen Wert [ableiten][type-inferring]:

```swift
var explicitVar: Int = 10 // Explicitly typed
var implicitVar = 10      // Implicitly typed (inferred as Int)
```

Du kannst den Wert einer Variable mit dem Zuweisungsoperator (`=`) aktualisieren:

~~~~exercism/note
Der Typ einer Variable kann nach der Deklaration nicht geändert werden.

```swift
variableName = 13 // Allowed: same type (Int)

// Compiler error: cannot assign a different type
variableName = "Hello, world!" // Cannot assign value of type 'String' to type 'Int'
```
~~~~

Du kannst eine Variable ohne Anfangswert deklarieren, indem du ihren Typ angibst, aber du musst einen Wert zuweisen, bevor du sie verwendest:

```swift
var someInt: Int

// This triggers a compiler error:
// print(someInt) // Variable 'someInt' used before being initialized

// Assign a value first
someInt = 169
print(someInt) // Prints 169
```

### Konstanten

[Konstanten][constants-variables] verknüpfen ebenfalls einen Namen mit einem Wert, aber ihre Werte können nach der Zuweisung nicht geändert werden.
Sie sind _unveränderlich_.
Eine Konstante definierst du mit dem Schlüsselwort `let`:

```swift
let constantName = 10          // Inferred constant
let explicitConstant: Int = 10 // Explicitly typed constant
```

### Arithmetische Operatoren

Swift bietet standardmäßige [arithmetische Operatoren][arithmetical-operators] für einfache Mathematik:

- Addition: `+`
- Subtraktion: `-`
- Multiplikation: `*`

```swift
print(1 + 1) // Prints 2
print(2 - 1) // Prints 1
print(2 * 2) // Prints 4
```

### Funktionen

In Swift sind [Funktionen][functions] in sich geschlossene Codeblöcke, die eine bestimmte Aufgabe erfüllen.
Funktionen können Eingabewerte annehmen, einen Wert zurückgeben und als Werte an andere Funktionen weitergegeben werden.
Eine Funktion definierst du mit dem Schlüsselwort `func`, gefolgt vom Funktionsnamen, einer Parameterliste in runden Klammern und einem optionalen Rückgabetyp:

```swift
func functionName(argumentLabel parameterName: ParameterType) -> ReturnType {
    // Function body
}
```

Swift-Funktionen verwenden [Argument-Labels][argument-labels], die den Code wie natürliche Sätze lesen lassen:

- Das **Argument-Label** wird beim Aufruf der Funktion verwendet.
- Der **Parametername** wird im Funktionskörper verwendet, um auf den Wert zuzugreifen.

Wenn du nur einen Namen angibst, verwendet Swift ihn sowohl als Argument-Label als auch als Parametername:

```swift
func greet(name: String) {
    print("Hello, \(name)!")
}

greet(name: "Alice")
```

Wenn du beim Aufruf der Funktion kein Argument-Label möchtest, schreibst du einen Unterstrich (`_`) vor den Parameternamen:

```swift
func square(_ number: Int) -> Int {
    return number * number
}

square(5) // Called without an argument label
```

Alle Funktionsparameter sind standardmäßig Konstanten (`let`), das heißt, ihre Werte können im Funktionskörper nicht geändert werden.

Um einen Wert aus einer Funktion zurückzugeben, gibst du den Rückgabetyp nach `->` an und verwendest das Schlüsselwort `return`:

```swift
func addTen(to value: Int) -> Int {
    return value + 10
}

addTen(to: 10) // Returns 20
```

Wenn eine Funktion keinen Wert zurückgibt, ist ihr Rückgabetyp `Void` (äquivalent zu einem leeren Tupel, `()`).
In solchen Funktionen kannst du sowohl den Rückgabetyp `-> Void` als auch die `return`-Anweisung weglassen.

### Kommentare

Swift unterstützt zwei Formen von [Kommentaren][comments]:

- **Einzeilige Kommentare** beginnen mit `//` und reichen bis zum Ende der Zeile.
- **Mehrzeilige Kommentare** stehen zwischen `/*` und `*/`.

```swift
// This is a single-line comment

/* This is a comment
   that spans multiple lines */
```
