# Überblick

**Benutzerdefinierte** Funktionen erstellst du mit dem Schlüsselwort `function`. Danach müssen ein Funktionsname und eine Liste von Argumenten folgen.

```php
function alarm($hour, $minute, $second)
{
    return 'Alarm!';
}
```

Funktionen kannst du in einer Datei aufrufen, bevor sie definiert sind, weil sie an den Anfang ihres Gültigkeitsbereichs gezogen werden.

## Benennung

Funktionsnamen in PHP folgen den Regeln anderer Bezeichner: Ein Funktionsname muss mit einem Unterstrich oder einem Buchstaben beginnen und darf danach beliebig viele Buchstaben, Zahlen oder Unterstriche enthalten.
