# Anleitung

Du führst den Fahrplan für eine kleine Inselfähre. Abfahrten werden als
Datumswerte erfasst, und du brauchst ein paar Hilfsfunktionen, um mit ihnen zu
arbeiten.

## 1. Ein Fahrtdatum erfassen

Definiere `make-date` so, dass es ein Jahr, einen Monat und einen Tag
entgegennimmt und den entsprechenden Zeitstempel zurückgibt.

```factor
2024 7 14 make-date .
! => T{ timestamp { year 2024 } { month 7 } { day 14 } ... }
```

## 2. Den Wochentag benennen

Definiere `weekday-name` so, dass es den Zeitstempel einer Fahrt entgegennimmt
und den Namen des Wochentags zurückgibt, auf den sie fällt.

```factor
2024 1 8 make-date weekday-name .
! => "Monday"
```

## 3. Schaltjahre

Definiere `leap?` so, dass es ein Jahr entgegennimmt und zurückgibt, ob es ein
Schaltjahr ist.

```factor
2024 leap? .   ! => t
2023 leap? .   ! => f
```

## 4. Tage in einem Monat

Definiere `month-length` so, dass es ein Jahr und einen Monat entgegennimmt und
die Anzahl der Tage in diesem Monat zurückgibt (denk an den Februar).

```factor
2024 2 month-length .   ! => 29
2023 2 month-length .   ! => 28
```

## 5. Tage später

Definiere `add-days` so, dass es einen Zeitstempel und eine Anzahl von Tagen
entgegennimmt und den Zeitstempel zurückgibt, der entsprechend viele Tage
später liegt.

```factor
2024 2 28 make-date 1 add-days >date< .
! => 29   (2024-02-29)
```
