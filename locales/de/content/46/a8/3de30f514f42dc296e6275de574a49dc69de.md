# Module und Pfade in Cairo

Cairo verwendet **Module**, um Code zu organisieren.

Module helfen dabei, Projekte zu strukturieren und die Sichtbarkeit von Elementen wie Funktionen, Structs und Traits zu steuern.

## Module definieren

Module werden mit `mod` definiert und können verschachtelt werden:

```rust
mod front_of_house {
    pub mod hosting {
        pub fn add_to_waitlist() {}
    }
}
```

Funktionen, Structs und Traits sind **standardmäßig privat**.

Mit `pub` machst du sie außerhalb ihres Moduls zugänglich.

## Pfade: absolut oder relativ

Um auf ein Element in einem anderen Modul zu verweisen, kannst du Folgendes verwenden:

- **Absolute Pfade** (beginnend mit `crate::`):

  ```rust
  crate::front_of_house::hosting::add_to_waitlist();
  ```

- **Relative Pfade** (beginnend mit dem aktuellen Modul):

  ```rust
  front_of_house::hosting::add_to_waitlist();
  ```

  Das funktioniert, wenn `front_of_house` im selben Modul liegt.

## Module mit `use` in den Gültigkeitsbereich holen

Es ist umständlich, immer wieder vollständige Pfade zu schreiben.

Das Schlüsselwort `use` ermöglicht kürzere Verweise:

```rust
use crate::front_of_house::hosting;

pub fn eat_at_restaurant() {
    hosting::add_to_waitlist(); // Shorter path
}
```

`use` gilt **nur in dem Gültigkeitsbereich, in dem es steht**; wenn es anderswo gebraucht wird, muss es wiederholt werden.

### Idiomatische Verwendung von `use`

- Hole **Module** in den Gültigkeitsbereich, nicht Funktionen:

  ```rust
  use crate::front_of_house::hosting; // ✅
  hosting::add_to_waitlist();
  ```

  Statt:

  ```rust
  use crate::front_of_house::hosting::add_to_waitlist; // ❌
  add_to_waitlist();
  ```

- Verwende für **Traits, Structs und Enums** den vollständigen Pfad:

  ```rust
  use core::num::traits::BitSize;
  ```

### Aliase mit `as`

Benenne Importe um, wenn es nötig ist:

```rust
use core::array::ArrayTrait as Arr;

fn main() {
    let mut arr = Arr::new();
    arr.append(1);
}
```

### Mehrere Elemente importieren

Statt mehrerer `use`-Anweisungen kannst du Importe gruppieren:

```rust
use shapes::{Square, Circle, Triangle};
```

## Re-Export mit `pub use`

Um ein Modul in einer anderen Struktur verfügbar zu machen, verwende `pub use`:

```rust
pub use crate::front_of_house::hosting;
```

Jetzt kann externer Code `restaurant::hosting::add_to_waitlist()` verwenden statt `restaurant::front_of_house::hosting::add_to_waitlist()`.

## Externe Pakete mit Scarb verwenden

Um eine Abhängigkeit hinzuzufügen, aktualisiere `Scarb.toml`:

```toml
[dependencies]
alexandria_math = { git = "https://github.com/keep-starknet-strange/alexandria.git" }
```

Mit `scarb add <package>` fügst du Abhängigkeiten hinzu und mit `scarb rm <package>` entfernst du sie.

## Der Glob-Operator (`*`)

Um alles aus einem Modul zu importieren:

```rust
use core::num::traits::*;
```

Das solltest du mit Bedacht einsetzen, denn es kann den Code schwerer lesbar machen.
