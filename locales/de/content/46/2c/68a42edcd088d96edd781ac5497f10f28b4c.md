# Anweisungen

In dieser Übung hilfst du Highschool-Liebespaaren, ihre Liebe in sozialen Medien zu bekunden, indem du ein ASCII-Herz mit ihren Initialen erzeugst:

```
     ******       ******
   **      **   **      **
 **         ** **         **
**            *            **
**                         **
**     J. K.  +  M. B.     **
 **                       **
   **                   **
     **               **
       **           **
         **       **
           **   **
             ***
              *
```

## 1. Ermittle den ersten Buchstaben des Namens

Implementiere die Funktion `first_letter`. Sie soll einen Namen entgegennehmen und dessen ersten Buchstaben zurückgeben. Sie soll überflüssige Leerzeichen aus dem Namen entfernen.

```gleam
first_letter("Jane")
// -> "J"
```

## 2. Formatiere den ersten Buchstaben als Initiale

Implementiere die Funktion `initial`. Sie soll einen Namen entgegennehmen und dessen ersten Buchstaben in Großbuchstaben zurückgeben, gefolgt von einem Punkt. Stelle sicher, dass du `first_letter` aus dem vorherigen Schritt wiederverwendest.

```gleam
initial("Robert")
// -> "R."
```

## 3. Teile den vollständigen Namen in Vornamen und Nachnamen auf

Implementiere die Funktion `initials`. Sie soll einen vollständigen Namen entgegennehmen, der aus einem Vornamen und einem Nachnamen besteht, die durch ein Leerzeichen getrennt sind, und die Initialen zurückgeben. Stelle sicher, dass du `initial` aus dem vorherigen Schritt wiederverwendest.

```gleam
initials("Lance Green")
// -> "L. G."
```

## 4. Setze die Initialen in das Herz ein

Implementiere die Funktion `pair`. Sie soll zwei vollständige Namen entgegennehmen und die Initialen in einem ASCII-Herz zurückgeben. Stelle sicher, dass du `initials` aus dem vorherigen Schritt wiederverwendest.

```gleam
pair("Blake Miller", "Riley Lewis")
// -> "
//      ******       ******
//    **      **   **      **
//  **         ** **         **
// **            *            **
// **                         **
// **     B. M.  +  R. L.     **
//  **                       **
//    **                   **
//      **               **
//        **           **
//          **       **
//            **   **
//              ***
//               *
// "
```
