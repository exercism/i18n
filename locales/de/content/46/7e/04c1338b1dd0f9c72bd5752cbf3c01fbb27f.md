# Einführung

## Keyword-Listen

Keyword-Listen sind eine Schlüssel-Wert-Datenstruktur.

```elixir
[month: "April", year: 2018]
```

Keyword-Listen sind Listen von `{key, value}`-[Tupeln][exercism-tuples] und können auch so geschrieben werden, aber die kürzere Syntax wird häufiger verwendet.

```elixir
[month: "April"] == [{:month, "April"}]
# => true
```

Schlüssel in einer Keyword-Liste müssen [Atome][exercism-atoms] sein, aber die Werte können beliebig sein. Jeder Schlüssel kann mehr als einmal verwendet werden. Die Schlüssel-Wert-Paare in einer Keyword-Liste sind geordnet.

Du kannst mit Keyword-Listen genauso arbeiten wie mit Listen, oder du kannst das `Keyword`-Modul verwenden.

[exercism-tuples]: https://exercism.org/tracks/elixir/concepts/tuples
[exercism-atoms]: https://exercism.org/tracks/elixir/concepts/atoms
