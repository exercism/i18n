# Anleitung

Das Mosaik im Kunstzentrum der Gemeinde ist letzten Monat
fertiggestellt worden, und jetzt hat Magpie Marg es entdeckt. An
den meisten Tagen tauscht sie ein oder zwei Kacheln gegen
glänzendere aus ihrem **Hort** in der Nähe, oder sie zupft eine
Kachel heraus und verschwindet für eine Stunde.

Du bist die freiwillige Kraft, die jede Änderung protokolliert.
Das Mosaik selbst ist ein **Array mit fester Größe**: ein Platz
pro Kachelposition, der einen Farb-String enthält oder `f` für
„fehlt“. Magpie Margas Hort ist ein **Vektor** aus losen Kacheln,
die sie gestohlen hat.

## 1. Eine frische Reihe anlegen

Definiere `fresh-mosaic` so, dass es eine Länge `n` entgegennimmt
und ein Array mit `n` leeren Plätzen zurückgibt (jeweils `f`).

```factor
4 fresh-mosaic .
! => { f f f f }
```

## 2. Eine Kachel setzen

Definiere `place-tile` so, dass es eine Reihe, eine Position und
eine Farbe entgegennimmt und die Reihe an Ort und Stelle
aktualisiert, sodass die genannte Position diese Farbe enthält.
Das Wort gibt nichts zurück.

```factor
5 fresh-mosaic   ! { f f f f f }
dup 2 "ruby" place-tile
.
! => { f f "ruby" f f }
```

## 3. Eine Kachel herausbrechen

Definiere `chip-tile` so, dass es eine Reihe und eine Position
entgegennimmt und die Reihe an Ort und Stelle aktualisiert, sodass
die genannte Position wieder `f` wird.

```factor
{ "ruby" "lapis" "jade" } 1 chip-tile .
! => { "ruby" f "jade" }
```

## 4. Eine Kachel umfärben

Definiere `recolour-tile` so, dass es eine Reihe, eine Position und
ein Quotation mit einem Argument entgegennimmt und die Reihe an
Ort und Stelle aktualisiert, indem es das Quotation auf die Kachel
an dieser Position anwendet.

```factor
{ "RUBY" "LAPIS" "JADE" } 1 [ >lower ] recolour-tile .
! => { "RUBY" "lapis" "JADE" }
```

## 5. Ein Schnappschuss, bevor Marg kommt

Definiere `snapshot-mosaic` so, dass es eine Reihe entgegennimmt
und eine unabhängige Kopie zurückgibt, die von späteren Mutationen
des Originals nicht betroffen ist.

```factor
{ "ruby" "lapis" "jade" } dup snapshot-mosaic    ! two equal but independent copies
swap 0 "amber" place-tile                        ! mutate the first
.s
! => { "ruby" "lapis" "jade" }                   (the snapshot)
! => { "amber" "lapis" "jade" }                  (the mutated original)
```

## 6. Marg lässt eine Kachel mitgehen

Definiere `stash-tile` so, dass es Margas Hort (ein Vektor) und
eine Farbe entgegennimmt und die Farbe an den Hort anhängt. Gibt
nichts zurück.

```factor
V{ } clone   ! a fresh empty hoard
dup "ruby"  stash-tile
dup "lapis" stash-tile
.
! => V{ "ruby" "lapis" }
```

## 7. Marg gibt eine Kachel zurück

Definiere `return-tile` so, dass es Margas Hort entgegennimmt und
die zuletzt eingelagerte Kachel entfernt und zurückgibt (die
oberste).

```factor
V{ "ruby" "lapis" "jade" } clone
dup return-tile .
! => "jade"
.
! => V{ "ruby" "lapis" }
```
