# Ergänzung zu den Anweisungen

## Register

| Register | Verwendung | Typ      | Beschreibung                                               |
| -------- | ---------- | -------- | ---------------------------------------------------------- |
| `$a0`    | Eingabe    | Ganzzahl | Kategorie: `0` = choice, `1` = ones, `2` = twos, `3` = threes, `4` = fours, `5` = fives, `6` = sixes, `7` = little_straight, `8` = big_straight, `9` = full_house, `10` = four_of_a_kind, `11` = yacht |
| `$a2`    | Eingabe    | Adresse  | Würfel (Wort-Array)                                        |
| `$v0`    | Ausgabe    | Ganzzahl | resultierende Punktzahl                                    |
| `$t0-9`  | temporär   | beliebig | dient als temporärer Speicher                              |
