# Ternärer Operator

Die _ternären Operatoren_ kann man sich als eine kompakte Version von _if-else_ vorstellen. Meistens werden sie in return-Anweisungen verwendet (aber nicht nur dort), sie brauchen nur eine einzige Zeile, um die Entscheidung zu treffen, und geben den linken Wert zurück, wenn der Ausdruck `true` ist, und den rechten Wert, wenn er `false` ist.

Viele einfache _if/else_-Ausdrücke lassen sich mit _ternären Operatoren_ vereinfachen.

```java
// this ternary statement
return 5 > 4 ? true : false;

// is equivalent to this if/else
if ( 5 > 4 ) {
    return true;
} else {
    return false;
}
```

Wie entscheidest du also zwischen _if-else_ und _ternär_?
Nun, _ternäre Operatoren_ verwendet man in einfachen Szenarien, in denen du nur einen Wert zurückgeben musst, der auf einer Bedingung basiert, und keine zusätzliche Berechnung nötig ist.
Für alles andere nimmst du ein _if-else_, zum Beispiel bei verschachtelten Bedingungen, großen Ausdrücken und wenn mehr als eine Zeile nötig ist, um den Rückgabewert zu bestimmen.

Du kannst _ternäre Operatoren_ zwar verschachteln, aber der Code wird dadurch oft schwer lesbar.
In diesen Fällen sind verschachtelte if-Anweisungen die bessere Wahl.

```java
// hard to read
int value = expr1 ? expr2 && expr3 ? val1 : (val2 + val3) : expr4;

// easier to read
if (expr1){

    if (expr2 && expr3){

        return val1;
    }

    return val2 + val3;
}
return val4;


```

_Ternäre Operatoren_ und _if/else_-Anweisungen sind ein gutes Beispiel dafür, dass du beim Programmieren verschiedene Wege hast, dasselbe Ergebnis zu erreichen.
