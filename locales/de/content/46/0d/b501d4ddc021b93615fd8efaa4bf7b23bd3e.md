# Codezeilen-Zähler

Der Codezeilen-Zähler (Lines of Code, LoC) nimmt eine Lösung und zählt deren Codezeilen.

Standardmäßig werden nur die Codezeilen der von der lernenden Person eingereichten Dateien gezählt.
Wurde eine Testdatei eingereicht, wird sie ignoriert.

Das funktioniert für die meisten Einsendungen gut, manche Tracks müssen aber möglicherweise weitere Dateien ignorieren.
Dafür erlauben wir, den Codezeilen-Zähler [pro Track anzupassen][lines-of-code-counter-customize].

## Implementierung

Wir verwenden die [tokei][tokei]-Bibliothek, um das eigentliche Zählen durchzuführen.
Da Pull Requests oft nicht schnell zusammengeführt werden, haben wir unseren eigenen [Fork][tokei-fork] erstellt.
So können wir schneller iterieren und Unterstützung für jede Sprache hinzufügen, die wir wollen.

## Unterstützte Sprachen

Du kannst prüfen, ob deine Sprache direkt unterstützt wird, indem du sie in der Datei [languages.json][languages.json] nachschlägst.

### Eine neue Sprache hinzufügen

Wenn deine Sprache **nicht** unterstützt wird, kannst du sie folgendermaßen hinzufügen:

1. Füge einen Eintrag für deine Sprache in der Datei [languages.json] hinzu.
   Weitere Informationen findest du in der [Dokumentation zum Hinzufügen von Sprachen][adding-language].
2. Füge Tests hinzu, um zu überprüfen, dass das Zählen für deine Sprache korrekt funktioniert.
   Weitere Informationen findest du in der [Dokumentation zum Hinzufügen von Tests][adding-tests].

Sobald du diese Änderungen vorgenommen hast, öffne einen Pull Request im [exercism/tokei-Repository][tokei-fork].
Hier ist ein [Beispiel-Pull-Request][example-pr], der Unterstützung für die Sprache Arturo hinzufügt.
