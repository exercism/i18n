# Einführung

Ein Wörterbuch (`dict`) in Python ist eine Datenstruktur, die [hashbare][term-hashable] _Schlüssel_ mit _Werten_ verknüpft und in anderen Programmiersprachen als größenveränderbare [Hashtabelle][hashtable-wikipedia], Hashmap oder [assoziatives Array][associative-array] bekannt ist.
Wörterbücher sind der einzige eingebaute [Mapping-Typ][mapping-types-dict] in Python.


`Keys` müssen hashbar und innerhalb des Wörterbuchs eindeutig sein.
Schlüsseltypen können `numbers`, `str` oder `tuples` (aus _unveränderlichen_ Werten) sein.
Sie können keine _veränderbaren_ Datenstrukturen wie `lists`, `dict`s oder `set`s enthalten.
Seit Python 3.7 ist garantiert, dass die Schlüsselreihenfolge eines `dict` der Reihenfolge entspricht, in der die Einträge eingefügt werden.

`values` können jeden Datentyp oder jede Datenstruktur haben.
Werte können auch _beliebig_ verschachtelt sein, sie können also Listen von Listen, Unterwörterbücher und andere benutzerdefinierte oder zusammengesetzte Datenstrukturen enthalten.

Wenn ein `key` gegeben ist, können Wörterbücher einen `value` in (durchschnittlich) konstanter Zeit abrufen (_unabhängig von der Anzahl der Einträge_).
Im Vergleich zur Suche nach einem Wert in einer `list` oder einem `array` (_ohne die `index`-Position zu kennen_) verbraucht ein `dict` deutlich mehr Speicher, bietet aber einen sehr schnellen Zugriff.
Wörterbücher sind besonders nützlich in Szenarien, in denen die Sammlung von Elementen groß ist und häufig darauf zugegriffen und sie aktualisiert werden muss.


## Wörterbücher erstellen

Wörterbücher lassen sich auf viele Arten erstellen.
Die beiden einfachsten bestehen darin, den `dict()`-Konstruktor zu verwenden oder ein `dict`-_Literal_ zu deklarieren.

### Der Klassenkonstruktor `dict()`

`dict()` (_der Konstruktor für die Wörterbuchklasse_) kann mit jedem Iterable von `key`, `value`-Paaren oder mit einer Reihe von `<name>=<value>`-_Argumenten_ verwendet werden:

```python
#Passing a list of key,value tuples.
>>> wombat = dict([('name', 'Wombat'),('speed', 23),('land_animal', True)])
{'name': 'Wombat', 'speed': 23, 'land_animal': True}


#Using key=value arguments.
>>> bear = dict(name="Black Bear", speed=40, land_animal=True)
{'name': 'Black Bear', 'speed': 40, 'land_animal': True}
```

### Wörterbuch-Literale

Ein `dict` kannst du auch direkt als _Wörterbuch-Literal_ eingeben, indem du geschweifte Klammern (`{}`) verwendest, die `key : value`-Paare einschließen:

```python
>>> whale = {"name": "Blue Whale", "speed": 35, "land_animal": False}
{'name': 'Blue Whale', 'speed': 35, 'land_animal': False}
```

## Auf Werte in einem Wörterbuch zugreifen

Du kannst auf einen Eintrag in einem Wörterbuch über einen _Schlüssel_ in eckigen (`[]`) Klammern zugreifen.
Wenn ein `key` im `dict` nicht existiert, wird ein `KeyError` ausgelöst:

```python
>>> bear["speed"]
40

>>> bear["color"]
Traceback (most recent call last):
  File "<stdin>", line 1, in <module>
KeyError: 'color'
```

Wenn du über die Methode `.get(<key>, <default value>)` auf einen Eintrag zugreifst, kannst du den `KeyError` vermeiden:

```python
>>> bear.get("color", 'not found')
'not found'
```

## Werte in einem Wörterbuch ändern oder hinzufügen

Du kannst den `value` eines Eintrags ändern, indem du seinem _Schlüssel_ etwas zuweist:

```python
#Assigning the value "Grizzly Bear" to the name key.
>>> bear["name"] = "Grizzly Bear"
{'name': 'Grizzly Bear', 'speed': 40, 'land_animal': True}

>>> whale["speed"] = 25
{'name': 'Blue Whale', 'speed': 25, 'land_animal': False}
```

Neue `key`:`value`-Paare kannst du auf dieselbe Weise _hinzufügen_:

```python
# Adding a new "color" key with a new "tawney" value.
>>> bear["color"] = 'tawney'
{'name': 'Grizzly Bear', 'speed': 40, 'land_animal': True, 'color': 'tawney'}

>>> whale["blowholes"] = 1
{'name': 'Blue Whale', 'speed': 25, 'land_animal': False, 'blowholes': 1}
```

## Einträge aus einem Wörterbuch entfernen (pop)

Mit der Methode `.pop(<key>)` kannst du einen Eintrag aus einem Wörterbuch löschen.
`.pop()` entfernt das (`key`, `value`)-Paar und gibt den `value` zurück, damit du ihn weiterverwenden kannst.
Wie `.get()` akzeptiert `.pop(<key>)` ein zweites Argument (_`dict.pop(<key>, <default value>)`_), das zurückgegeben wird, wenn der `key` nicht gefunden wird.
So wird verhindert, dass ein `KeyError` ausgelöst wird:

```python
#Using .pop() removes both the key and value, returning the value.
>>> bear.pop("name")
'Grizzly Bear'


#The "name" key is now removed from the dictionary.
#Attempting .pop() a second time will throw a KeyError.
>>> bear.pop("name")
Traceback (most recent call last):
  File "<stdin>", line 1, in <module>
KeyError: 'name'


#Using a default argument with .pop() will prevent a KeyError from a missing key.
>>> bear.pop("name", "Unknown")
'Unknown'
```

## Ein Wörterbuch durchlaufen / iterieren

Wenn du mit `for item in dict` oder `while item` durch ein Wörterbuch schleifst, werden standardmäßig nur die _Schlüssel_ durchlaufen.
Auf die _Werte_ kannst du innerhalb derselben Schleife über _eckige Klammern_ zugreifen:

```python
>>> for key in bear:
>>>     print((key, bear[key])) #this forms a tuple of (key, value) and prints it.
('name', 'Black Bear')
('speed', 40)
('land_animal', True)
```

Du kannst auch die Methode `.items()` verwenden, die automatisch (`key`, `value`)-Tupel zurückgibt:

```python
#dict.items() forms (key, value tuples) that can be unpacked and iterated over.
>>> for key, value in whale.items():
>>>     print(key, ":", value)
name : Blue Whale
speed : 25
land_animal : False
blowholes : 1
```

Ebenso gibt die Methode `.keys()` die `keys` zurück und die Methode `.values()` die `values`.
