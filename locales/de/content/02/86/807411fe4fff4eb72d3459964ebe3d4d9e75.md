# Einführung

Mit einer while-Schleife kannst du Code wiederholt ausführen, solange eine bestimmte Bedingung erfüllt ist.
Sie wird mit dem Schlüsselwort `while` geschrieben, gefolgt von einer Bedingung in runden Klammern und einem Block in geschweiften Klammern, der den _Schleifenblock_ der Schleife enthält.

```javascript
while (condition) {
  // code that is executed repeatedly as long as the condition is true
}
```

JavaScript kennt außerdem die do-while-Schleife.
Dabei wird die Bedingung erst geprüft, nachdem der Schleifenblock ausgeführt wurde.
Das ist nützlich, wenn die Bedingung vom Ergebnis des Codes im Schleifenblock abhängt.

```javascript
do {
  // The code here will always be executed once and then
  // repeatedly while the condition is true.
} while (condition);
```

Innerhalb eines Schleifenblocks kannst du mit dem Schlüsselwort `break` die Ausführung der Schleife ganz beenden.
Im Gegensatz dazu beendet das Schlüsselwort `continue` nur die Ausführung der aktuellen Iteration und fährt mit der nächsten fort.
Mit `continue` kannst du oft vermeiden, große Teile des Schleifenblocks in eine if-Anweisung zu packen.

```javascript
let i = 0;

while (i < 100) {
  i = i + 2;

  if (i % 3 === 0) {
    continue;
  }

  // The code here will only be executed when i was not divisible
  // by 3 in the check above.
}
```
