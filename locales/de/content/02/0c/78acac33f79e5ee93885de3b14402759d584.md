# Bitmanipulation

Crystal hat Bitoperatoren, mit denen du [`Int`][ints] auf der binären Ebene bearbeiten kannst.

## Schiebeoperatoren 

Crystal hat [Schiebeoperatoren][shift], mit denen du Bits nach links (`<<`) oder nach rechts (`>>`) verschieben kannst.

### Nach links schieben (`<<`)

Der Linksschiebeoperator (`<<`) verschiebt die Bits nach links.
Der zu verschiebende Wert steht links und die Anzahl der Stellen, um die verschoben wird, steht rechts.

```crystal
0b0010 << 1
# => 0b0100

0b0010 << 2
# => 0b1000
```

Wenn die Zahl negativ ist, verschiebt er stattdessen nach rechts.

```crystal
0b0010 << -1
# => 0b0001
```

### Nach rechts schieben (`>>`)

Der Rechtsschiebeoperator (`>>`) verschiebt die Bits nach rechts.
Wie beim Linksschiebeoperator steht der zu verschiebende Wert links und die Anzahl der Stellen, um die verschoben wird, rechts.

```crystal
0b0100 >> 1
# => 0b0010

0b0100 >> 2
# => 0b0001
```

Und genauso verschiebt der Operator nach links, wenn die Zahl negativ ist.

```crystal
0b0100 >> -1
# => 0b1000
```

## Binäre Operatoren

Crystal hat 3 [binäre Operatoren][binary] (`&`, `|`, `^`) und einen `~`-Operator für bitweise Operationen.

### Bitweises UND (`&`)

Der binäre UND-Operator (`&`) führt ein bitweises UND mit zwei Werten aus.
Er vergleicht jedes Bit im ersten Wert mit dem Bit an derselben Position im zweiten Wert.
Das resultierende Bit wird auf 1 gesetzt, wenn beide Bits 1 sind.
Andernfalls wird es auf 0 gesetzt.

```crystal
0b0011 & 0b1010
# => 0b0010
```

### Bitweises ODER (`|`)

Der binäre ODER-Operator (`|`) führt ein bitweises ODER mit zwei Werten aus.
Auch er vergleicht jedes Bit im ersten Wert mit dem Bit an derselben Position im zweiten Wert.
Wenn eines der beiden Bits 1 ist, wird das resultierende Bit auf 1 gesetzt.
Andernfalls wird es auf 0 gesetzt.

```crystal
0b0011 | 0b1010
# => 0b1011
```

### Bitweises XOR (`^`)

Der binäre XOR-Operator (`^`) führt ein bitweises XOR aus.
Wie die Operatoren für bitweises UND und bitweises ODER vergleicht er jedes Bit des ersten Werts mit dem Bit an derselben Position im zweiten Wert.
Wenn _nur eines_ von ihnen 1 ist, ist das resultierende Bit 1.
Andernfalls ist es 0.

```crystal
0b0011 ^ 0b1010
# => 0b1001
```

### Bitweises NICHT (`~`)

Zuletzt kehrt der bitweise NICHT-Operator (`~`) jedes Bit des Werts um. 
Anders als die anderen binären Operatoren ist dies ein unärer Operator, der nur auf den Wert rechts von ihm wirkt.

```crystal
~0b1110_0010
# => 0b0001_1101
```
