# Über

[Python][python docs] ist eine [dynamisch und stark][dynamic typing in python] typisierte, [objektorientierte][object oriented programming] Programmiersprache.
Sie setzt sowohl [Duck Typing][duck typing] als auch [graduelle Typisierung][gradual typing] ein (über [Typ-Hinweise][type hints]).
Sie unterstützt mehrere Programmierparadigmen, darunter imperative (_objektorientierte, prozedurale_) und deklarative (_funktionale, nebenläufige_) Stile.
Aber lass dich nicht täuschen: Auch wenn das Programmieren über Paradigmen hinweg voll unterstützt wird, ist [in Python alles ein Objekt][everythings an object].

Python wurde von Guido van Rossum entwickelt und 1991 erstmals veröffentlicht.
Die [Python Software Foundation][psf] verwaltet und steuert die Ressourcen für die Entwicklung von Python und CPython und erhält über [Python Enhancement Proposals (PEPs)][peps] Vorschläge für Änderungen an der Sprache von [Mitgliedern][psf membership] der Community.
Sie gilt als starke Sprache für Programmierer, die [ihre Reise gerade beginnen][python for beginners], mit einer einladenden Community und vielen Ressourcen für Lernende auf allen Niveaus und mit allen Interessen.

Python legt großen Wert auf die Lesbarkeit von Code und nutzt (_ähnlich wie Haskell_) [signifikante Einrückung][significant indentation], um Funktions-, Methoden- und Klassendefinitionen zu kennzeichnen.
Code kann in der Kommandozeile, in einer interaktiven Interpreter-Sitzung, in [JupyterLab][jupyter] (Jupyter Notebooks) oder in einer Vielzahl von [Code-Editoren und IDEs][editors for python] geschrieben und ausgeführt werden.

[Python wird intensiv genutzt][python is used extensively] im wissenschaftlichen Rechnen, im Finanzwesen, in Spielen, in der Netzwerktechnik, in der Internetentwicklung und beim Zusammenbauen von Pipelines aus anderen Programmen.

Das [Zen of Python (PEP 20)][the zen of python] und [Was ist Pythonic?][what is pythonic] beschreiben zusätzliche Philosophien und Sichtweisen auf die Sprache.

Tests und Tooling für diesen Track unterstützen derzeit `Python 3.10 - 3.13.7` (_Tests_) und [`Python 3.13.7`][313-new-features] (_Tooling_).
Es wird dringend empfohlen, dass du mindestens auf `Python 3.10` aufrüstest, da einige Funktionen, die dieser Track verwendet, in früheren Versionen möglicherweise nicht unterstützt werden.
Trotzdem funktionieren die meisten Übungen mit `Python 3.6+` oder sogar noch früheren Versionen.
Für Versionen, die nicht unter [aktive Python-Versionen][active-python-releases] aufgeführt sind, garantieren wir jedoch keine Unterstützung.
Wir werden versuchen zu vermerken, wenn eine Funktion nur in einer bestimmten Version verfügbar ist.

Die vollständige Dokumentation für die von diesem Track verwendete Python-Version (`3.13.x`) findest du unter [docs.python.org][python docs].
