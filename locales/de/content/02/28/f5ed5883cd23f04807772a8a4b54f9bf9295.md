# Datenbank-Zahlungsstapel

## Problemstellung

Du musst einen Stapel Zahlungsdaten in die Tabelle `Payment` einfügen. Deine Aufgabe ist es, die Zahlungsdaten aus der angegebenen JSON-Eingabedatei zu lesen und die Operation `batchExecute` des JDBC-Clients zu verwenden, um die Zahlungsdaten in die Tabelle `Payment` einzufügen. Die Beispieldatei heißt `payments.json`.

Der Inhalt der JSON-Eingabedatei basiert auf dem folgenden JSON-Schema.

```json
{
  "type": "array",
  "items": [
    {
      "type": "object",
      "properties": {
        "employee_id": {
          "type": "integer"
        },
        "amount": {
          "type": "number"
        },
        "reason": {
          "type": "string"
        },
        "date": {
          "type": "string"
        }
      },
      "required": [
        "employee_id",
        "amount",
        "reason",
        "date"
      ]
    }
  ]
}

```

Du musst die automatisch generierten Zahlungs-IDs für die in den Stapel eingefügten Zahlungsdaten als Ausgabe zurückgeben, ohne eine weitere Abfrage an die Datenbank zu senden.

Du kannst davon ausgehen, dass die in der Datei `payments.json` angegebenen `employee_id` gültig sind und bereits in der Tabelle `Employee` enthalten sind.

## Datenbankdetails

Verwende für diese Aufgabe die bereitgestellte H2-Datenbank.

> Die Beispieldatenbankdatei ist `gofigure.mv.db`, und der Datenbankname ist `gofigure`. Sie befindet sich im Ordner `db`.

Die folgenden Tabellen sind bereits mit einigen Beispieldaten in der H2-Beispieldatenbank vorhanden. Die Spaltennamen und Datentypen findest du unten.

**Tabellenname** : `Employee`

| **Spalten:**      | Typ |
| -----------       | ----------- |
| `employee_id`     | Ganzzahl, automatisch erhöhter Primärschlüssel       |
| `name`            | String        |
| `city`            | String        |
| `department`      | String        |
| `age`             | Ganzzahl        |

**Tabellenname**: `Payment`

| **Spalten:**      | Typ |
| -----------       | ----------- |
| `payment_id`      | Ganzzahl, automatisch erhöhter Primärschlüssel       |
| `date`            | Datum        |
| `amount`          | Gleitkommazahl        |
| `employee_id`     | Ganzzahl        |
| `reason`          | String        |

* Die Datenbankdatei ist `gofigure.mv.db`. Verwende als JDBC-URL `jdbc:h2:file:/path/to/db/file`
* Benutzername: `root`
* Passwort: `root`

* Du musst die automatisch generierten Zahlungs-IDs finden, ohne eine weitere Abfrage an die Datenbank zu senden.

## Beispiele

### Beispiel 1

**Eingabe:** dbFilePath: `"/path/to/file/gofigure"`, paymentFilePath: `"/path/to/file/payments.json"`

Beispieldaten der Datei `payments.json`:

```json
[{
        "employee_id": 4,
        "amount": 12500.50,
        "reason": "Fuel for the month January",
        "date": "2022-02-03"
    },
    {
        "employee_id": 1,
        "amount": 10500.50,
        "reason": "Medical Expenses for the month January",
        "date": "2022-02-04"
    },
    {
        "employee_id": 4,
        "amount": 500.50,
        "reason": "Fuel for the month February",
        "date": "2022-03-03"
    }
]

```

**Ausgabe:** `[1,2,3]`

## Hinweise

* Verwende das Modul [ballerinax/java.jdbc](https://central.ballerina.io/ballerinax/java.jdbc), um mit der Datenbank zu arbeiten
* Sieh dir den Abschnitt [Voraussetzung](https://lib.ballerina.io/ballerinax/java.jdbc/latest) an, um den JDBC-Treiber als Abhängigkeit hinzuzufügen
* Verwende [io:fileReadJson](https://lib.ballerina.io/ballerina/io/latest/functions#fileReadJson), um die JSON-Eingabedatei zu lesen
* Konvertiere die JSON-Werte in anwendungsspezifische Typen, um typsicher mit den Daten zu arbeiten. Sieh dir das Beispiel [Konvertieren in einen benutzerdefinierten Typ](https://ballerina.io/learn/by-example/convert-from-json-to-user-defined-type/) an
* Verwende [sql:ParameterizedQuery](https://lib.ballerina.io/ballerina/sql/latest#ParameterizedQuery) und die Remote-Methode [batchExecute](https://lib.ballerina.io/ballerinax/java.jdbc/latest#Client-batchExecute), um mit der Datenbank zu arbeiten
* Sieh dir das Beispiel [Stapelausführung](https://ballerina.io/learn/by-example/mysql-batch-execute-operation/) an
