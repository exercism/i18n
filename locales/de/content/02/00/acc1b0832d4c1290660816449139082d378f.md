# Einführung

In Elixir ist ein Tupel eine Datenstruktur, die Daten organisiert und eine feste Anzahl von Elementen beliebigen Typs enthält, aber ohne explizite Namen für jedes Element. Tupel werden in Elixir oft für speicherleseintensive Operationen verwendet, da der lesende Zugriff auf ein Element eine Operation mit konstanter Laufzeit ist. Normalerweise werden sie nicht verwendet, wenn Elemente dynamisch hinzugefügt oder entfernt werden müssen, denn statt das vorhandene Tupel zu ändern, wird ein neues Tupel erstellt, wofür Speicher im Voraus reserviert werden muss.

In der Praxis erstellst du Tupel in Elixir mit geschweiften Klammern. Auf einzelne Elemente eines Tupels greifst du mit der Funktion `elem/2` zu, wobei die Indexierung bei 0 beginnt:

```elixir
empty_tuple = {}
one_element_tuple = {1}
multiple_element_tuple = {1, :a, "hello"}

elem(multiple_element_tuple, 2)
# => "hello"
```

## Tupel als gruppierte Informationen

In der Praxis werden Tupel oft verwendet, um gruppierte Informationen darzustellen.

```elixir
Float.ratio(0.25)
# => {1, 4} indicating the numerator and denominator of the fraction ¼
```
