# Einführung

Arrays und Listen enthalten eine geordnete Sammlung von Skalaren.
Abgesehen von Referenzen (die in einem eigenen Konzept behandelt werden) bedeutet das, dass Arrays und Listen immer flach sind, d. h. sie können keine anderen Arrays oder Listen enthalten.

In den meisten Fällen werden Listen von runden Klammern `()` umschlossen, wobei ihre Elemente durch Kommas `,` getrennt werden.

Eine Array-Variable wird normalerweise befüllt, indem man ihr eine Liste zuweist, z. B. `my @names = ('Alice', 'Bob', 'Charlie');`.

Auf die Elemente eines Arrays oder einer Liste greifst du zu, indem du einen Index in eckigen Klammern angibst, z. B. `('Alice', 'Bob', 'Charlie')[1] # 'Bob'`.

Indizes beginnen in Perl bei `0`.
Negative Indizes zählen vom Ende des Arrays oder der Liste, z. B. `('Alice', 'Bob', 'Charlie')[-1] # 'Charlie'`.

## Funktionen

Es gibt viele Funktionen für die Arbeit mit Arrays und Listen. Zu den nützlichsten gehören [grep][grep] für eine neue Liste gefilterter Elemente, die eine Bedingung erfüllen, [map][map] zum Umwandeln von Elementen in eine neue Liste von Werten und [sort][sort] für eine neue Liste neu geordneter Elemente.

Zu den Funktionen zum Bearbeiten von Arrays gehören [push][push], um Elemente am Ende anzuhängen, [pop][pop], um das letzte Element zu entfernen, [shift][shift], um das erste Element zu entfernen, [unshift][unshift], um Elemente am Anfang einzufügen, und [splice][splice] für komplexere Änderungen.

Auch das Iterieren über Arrays und Listen mit einer [for(each)][perlsynforeach]-Anweisung wirst du häufig antreffen.

## Die Wahl des Sigils

Beim Zugriff auf die Elemente eines Arrays bestimmt das verwendete Sigil das Ergebnis.
Der Index `[]` am Ende des Variablennamens sagt Perl, dass du auf ein Array mit diesem Namen zugreifst.

```perl
my @names = ('Alice', 'Bob', 'Charlie');

$names[0]; # 'Alice'      <- A scalar
@names[0]; # ('Alice')    <- A slice (with only one index, this probably isn't what you want. There will be a warning.)
%names[0]; # (0, 'Alice') <- A key/index + value slice

$names[1, 2]; # 'Charlie'                <- A scalar (via unsupported syntax for an ancient feature. Probably not what you want. There will be a warning.)
@names[1, 2]; # ('Bob', 'Charlie')       <- A slice
%names[1, 2]; # (1, 'Bob', 2, 'Charlie') <- A key/index + value slice
```

Es ist zwar erlaubt, aber aus Gründen der Lesbarkeit solltest du darauf verzichten, verschiedenen Variablentypen denselben Namen zu geben.

## Arrays vs. Listen

Arrays und Listen haben viele Gemeinsamkeiten und lassen sich an vielen Stellen austauschbar verwenden, aber sie sind nicht dasselbe.
Eine Liste ist eine feste und unveränderliche Sammlung von Skalaren.
Ein Array ist eine veränderliche Sammlung von Skalaren, deren Inhalt und Größe sich ändern lassen.

In manchen Kontexten verhalten sie sich unterschiedlich.
Ein Array im skalaren Kontext liefert dir die Größe des Arrays.
Eine Liste im skalaren Kontext liefert dir das letzte Element der Liste und möglicherweise einige Warnungen, weil der Rest ihres Inhalts im Void-Kontext verwendet wird.

```perl
my @names = ('Alice', 'Bob', 'Charlie');

scalar @names; # 3
scalar ('Alice', 'Bob', 'Charlie'); # 'Charlie' (and some warnings).
```
