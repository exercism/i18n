# Hinweise

## 1. Erstelle einen Vektor mit allen Wagen

- Eine klassische for/while-Schleife mit `push!` auf einen `Vector` funktioniert.
- Ansonsten kann die Funktion [`collect()`][collect] kompakter sein.
- Alternativ funktioniert Splatting in einem Vektor-Konstruktor:

```julia-repl
julia> input = (1, 5, 9)
(1, 5, 9)

julia> [input...]
3-element Vector{Int64}:
 1
 5
 9
```

## 2. Repariere den Vektor der Wagen

- Es ist hilfreich, die vorderen Wagen und die Lokomotive von allem anderen zu trennen, damit sie in der richtigen Reihenfolge wieder zusammengesetzt werden können.
- Mehrfachzuweisung mit Splatting kann dir helfen (siehe Einführung).

## 3. Füge fehlende Haltestellen hinzu

- Denk daran, diese Funktion verändert die Eingabe nicht! Erstelle ein neues `Dict`.
- Nur der Name der Haltestelle wird benötigt, nicht die Nummer der Haltestelle, also muss jedes Paar aufgeteilt werden.
- Es gibt mehrere Möglichkeiten, den Vektor der Namen zusammenzustellen:
  -  For/While-Schleife mit `push!()` auf einen `Vector`.
  -  Array-[Comprehension][comprehensions]
  -  [`map()`][map] einer Funktion über den Vektor.
  -  [Broadcasting][broadcasting] einer [anonymen][anonymous] Funktion ist möglich:

 ```julia-repl
julia> (x -> x^4).([1, 2, 3]) == [1, 16, 81]
true
 ```

## 4. Erweitere die Routing-Informationen

- Nach dem Slurping ist `more_route_information` eine `Pairs()`-Sammlung.
- Die Funktion [`merge()`][merge] kombiniert zwei oder mehr `Dict`s, akzeptiert aber auch eine `Pairs()`-Sammlung.
  Eine explizite Konvertierung der `Pairs()`-Sammlung in ein `Dict` ist möglich, aber unnötig.
