# Einführung

Gleam hat First-Class-Funktionen. Das bedeutet, Funktionen sind normale Werte, die Variablen zugewiesen, als Argumente übergeben und von anderen Funktionen zurückgegeben werden können.

Eine benannte Funktion, die in einem Modul definiert ist, kann über ihren Namen referenziert werden.

```gleam
pub fn main() {
  // Assign the function to a variable
  let f = add_one
  
  // Invoke the function
  f(1) // -> 2
  f(2) // -> 3
}

fn add_one(x) {
  x + 1
}
```

Gleam hat auch anonyme Funktionen, die innerhalb anderer Funktionen definiert werden.

```gleam
// Define the function
let f = fn(x) { x + 1 }

// Invoke the function
f(1) // -> 2
f(2) // -> 3
```

Der Typ einer Funktion wird in einer Syntax geschrieben, die der von anonymen Funktionen ähnelt. Der Typ einer Funktion, die einen `Int` und einen `Float` entgegennimmt und einen `Int` zurückgibt, wird so geschrieben:

```gleam
fn(Int, Float) -> Int
```

Anonyme Funktionen können auf Variablen verweisen, die sich im Gültigkeitsbereich befanden, als sie definiert wurden. Dadurch werden sie zu _Closures_.

```gleam
let secret_number = 42

// This function always returns 42
fn() { secret_number }
```

Die _Function-Capture_-Syntax bietet eine praktische Kurzform, um anonyme Funktionen zu erstellen, die ein einzelnes Argument an eine Funktion übergeben. Diese beiden Ausdrücke sind äquivalent:

```gleam
// Anonymous function syntax
let f = fn(x) { my_function(1, 2, x) }

// Function capture syntax
let f = my_function(1, 2, _)
```
