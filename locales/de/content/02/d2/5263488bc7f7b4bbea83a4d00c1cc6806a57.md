# Überblick

Eine [switch-Anweisung][switch] ermöglicht es dir, einen Wert mit mehreren möglichen übereinstimmenden Werten zu vergleichen.
Damit kannst du prägnanteren Code schreiben, als wenn du mehrere `else-if`-Anweisungen verwendest.
Eine switch-Anweisung beginnt mit dem Schlüsselwort `switch`, gefolgt von dem Wert, der verglichen werden soll.
Danach kannst du die Fälle mit dem Schlüsselwort `case` definieren, gefolgt von dem Wert, mit dem verglichen wird.
Das Schlüsselwort `default` definiert den Standardfall, wenn keiner der Fälle passt.
Wie `else-if`-Anweisungen führen `switch`-Anweisungen nur den Codeblock aus, der zum ersten passenden Fall gehört.

```swift
switch value {
case 1:
    print("One")
case 2:
    print("Two")
default:
    print("Other")
}
```

Schau dir das folgende Beispiel an:

```swift
if str == "apple" {
    print("Let's bake an apple crumble")
} else if str == "lemon" {
    print("Let's bake a lemon meringue pie!")
} else if str == "peach" {
    print("Let's bake a peach pie!")
} else {
    print("Let's buy ice cream.")
}
```

Das lässt sich stattdessen so schreiben:

```swift
switch str {
case "apple":
    print("Let's bake an apple crumble")
case "lemon":
    print("Let's bake a lemon meringue pie!")
case "peach":
    print("Let's bake a peach pie!")
default:
    print("Let's buy ice cream.")
}
```

## Binden und where-Anweisungen

Die Werte, die in `switch`-Anweisungen verglichen werden, können auch an Namen gebunden werden, die du im Block des Falls verwenden kannst.
Sie können außerdem in `where`-Klauseln verwendet werden. Das sind zusätzliche boolesche Ausdrücke, die `true` ergeben müssen, damit der Fall passt.

```swift
let x = 1337
switch sumOfDivisors(of: x) {
case let total where total == x:
  print(total, "is a perfect number")
default:
  print(x, "is not a perfect number")
}
```
