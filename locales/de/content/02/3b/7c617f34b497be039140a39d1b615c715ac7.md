# Über

[TypeScript](https://www.typescriptlang.org/) (TS) ist eine Obermenge von JavaScript (JS). Es wurde bei Microsoft entwickelt, weil die Entwicklung großer Anwendungen in JS zunehmend frustrierte. In einem großen JS-Projekt wird es schnell schwierig zu wissen, welche Eigenschaften die eigenen Objekte haben und welche Argumente deine Funktionen erwarten (und welchen Typ diese haben müssen). Ähnlich geht es dir, wenn du ein Paket einbindest (etwa über `npm`): Da sich JS-Code nicht intelligent untersuchen lässt, musst du die Dokumentation aktuell halten, um zu wissen, welche Methoden verfügbar sind und welche Argumente sie erwarten. TS löst diese Probleme. Es ist derzeit ein Open-Source-Projekt, das auf GitHub gehostet wird. Es unterstützt Tools für jeden Browser ebenso wie für Node, für jeden Host und jedes Betriebssystem. TS kompiliert zu lesbarem, standardkonformem JavaScript.

TS fügt JS ein flexibles Typsystem hinzu, ebenso wie Interfaces (benutzerdefinierte Typen) und Änderungen an der Syntax einiger ECMAScript-Features wie etwa Klassen. Typen sind optional und flexibel (du kannst zum Beispiel festlegen, dass ein Argument ein String ODER eine Zahl ist). Typen ermöglichen Tooling, das in den meisten Code-Editoren verfügbar ist und die Entwicklung angenehmer macht, etwa Code-Vervollständigung und Methodenerkennung, sowohl im eigenen Code als auch in den Paketen, die du verwendest. Es unterstützt viele kommende ECMAScript-Features (wie async/await). TS lässt sich objektorientiert oder funktional schreiben. Es ist mit allen bestehenden JS-Paketen kompatibel. TS transpiliert zu sauberem, lesbarem JS.

Probier es im [Playground](https://www.typescriptlang.org/play) aus und bleib über [den TypeScript-Blog](https://devblogs.microsoft.com/typescript/) und [den Twitter-Account](https://twitter.com/typescript) auf dem Laufenden.
