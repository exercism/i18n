# Einführung

Strings umzukehren (sie von rechts nach links statt von links nach rechts zu lesen) ist eine überraschend häufige Aufgabe beim Programmieren.

In der Bioinformatik zum Beispiel ist es oft wichtig, die Sequenz von DNA- oder RNA-Strings umzukehren, etwa für verschiedene Analysen wie das Finden komplementärer Stränge oder das Identifizieren palindromischer Sequenzen mit biologischer Bedeutung.
