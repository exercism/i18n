Ich bevorzuge die erste Beispiellösung, weil ihre Knappheit dem entspricht, was ich von idiomatischem Rust gesehen habe. Außerdem vermeidet sie die Ergänzung des Closure-Konzepts, die in der kanonischen Lösung steckt.

## Extrahierte Konzepte

### Allgemeines

- Boolesche Logik
  - boolescher Wert
- Ausdrücke
  - Rust-Funktionen geben implizit Ausdrücke zurück
- Arithmetik
  - Modulo

### Typen

- vorzeichenlose Ganzzahlen - `u64`
- boolesche Werte - `bool`

## Beispielübung 1

Lösung von [„desi-belokonska“](https://exercism.org/tracks/rust/exercises/leap/solutions/01d024321b6a491690321844aedf8b09)

```rust
pub fn is_leap_year(year: u64) -> bool {
  year % 400 == 0 || year % 4 == 0 && year % 100 != 0
}
```

## Beispielübung 2

[Kanonisch](https://github.com/exercism/rust/blob/master/exercises/leap/example.rs)

```rust
pub fn is_leap_year(year: u64) -> bool {
    let has_factor = |n| year % n == 0;
    has_factor(4) && (!has_factor(100) || has_factor(400))
}
```
