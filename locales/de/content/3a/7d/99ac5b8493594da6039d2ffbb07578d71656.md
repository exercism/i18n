# Ergänzung zu den Anweisungen

## Register

| Register | Verwendung | Typ      | Beschreibung                        |
| -------- | ---------- | -------- | ----------------------------------- |
| `$a0`    | Eingabe    | Adresse  | Farbe als nullterminierter String   |
| `$v0`    | Ausgabe    | Ganzzahl | Widerstandswert                     |
| `$t0-9`  | temporär   | beliebig | für temporäre Speicherung           |
