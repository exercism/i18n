# Überblick

[Structs][getting-started] sind besondere [Maps][maps] mit einer festgelegten Menge von Schlüsseln.

- Structs bieten Prüfungen zur Kompilierzeit und Standardwerte.
- Ein Struct wird nach dem Modul benannt, in dem es definiert ist.
- Um ein Struct zu definieren, verwendest du das Konstrukt [`defstruct`][docs-defstruct].
  - Das Konstrukt folgt in der Regel direkt auf die Moduldefinition.
- `defstruct` akzeptiert entweder eine Liste von [Atomen][atom] (für den Standardwert `nil`) oder Keyword-Listen (für festgelegte Standardwerte).
  - Die Felder ohne Standardwert müssen vor den Feldern mit Standardwerten stehen.

```elixir
defmodule Plane do
  defstruct [:engine, wings: 2]
end

plane = %Plane{}
# => %Plane{engine: nil, wings: 2}
```

## Zugriff auf Felder und Aktualisierung

- Die meisten Funktionen, die mit [Maps][maps] arbeiten, funktionieren auch mit Structs.
  - Das [_Access Behaviour_][access-behaviour] ist eine Ausnahme und ist für Structs **nicht** implementiert.
- Für den Zugriff auf die Felder eines Structs solltest du den _statischen Zugriffsoperator_ `.` verwenden.

- Feldwerte abrufen:

  ```elixir
  plane = %Plane{}
  plane.engine
  # => nil
  Map.fetch(plane, :wings)
  # => {:ok, 2}
  ```

- Feldwerte aktualisieren

  ```elixir
  plane = %Plane{}
  %{plane | wings: 4}
  # => %Plane{engine: nil, wings: 4}
  ```

## Initialisierung von Feldwerten erzwingen

- Das [`@enforce_keys`-Modulattribut][enforcing-keys] erzeugt eine Prüfung zur Laufzeit, dass angegebene Felder mit einem **nicht**-`nil`-Wert initialisiert werden müssen, wenn das Struct erstellt wird.
- Auf `@enforce_keys` folgt eine Liste der Feldschlüssel (die [Atome][atom] sind).
- Wenn ein erzwungener Schlüssel nicht initialisiert wird, wird ein Fehler ausgelöst.

```elixir
defmodule User do
  @enforce_keys [:username]
  defstruct [:username]
end

%User{}
# => (ArgumentError) the following keys must also be given when building struct User: [:username]
```
