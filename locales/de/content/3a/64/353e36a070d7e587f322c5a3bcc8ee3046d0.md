# Über

PureScript ist eine rein funktionale, statisch typisierte Programmiersprache mit globaler Typinferenz.

**Funktional** bedeutet, dass Funktionen Werte erster Klasse sind.
Funktionen sind ein wichtiges und mächtiges Werkzeug zur Abstraktion.
In PureScript wird eine Berechnung als Auswertung von Ausdrücken modelliert, die aus Funktionsanwendungen bestehen, und nicht als Ausführung einer Abfolge von Anweisungen.

**Rein funktional** bedeutet, dass man erkennen kann, ob eine Berechnung Seiteneffekte hat oder nicht. Wenn eine Berechnung also eine globale Variable ändert, Eingaben liest, in einen Socket schreibt und so weiter, dann spiegelt sich das im Typ der Berechnung wider.

**Statisch typisiert** bedeutet, dass alle Berechnungen einen Typ haben, der schon bekannt ist, bevor das Programm ausgeführt wird.

**Globale Typinferenz** bedeutet, dass der Compiler die Typen der Berechnungen im gesamten Programm ermitteln kann, ohne dass man den Typ angeben muss.
