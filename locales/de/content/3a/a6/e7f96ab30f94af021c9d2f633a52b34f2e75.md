# Einführung

[`Inheritance`][inheritance] ist eine der [„vier Säulen"][four-pillars] der objektorientierten Programmierung (`OOP`).
Wenn für eine neue `class` nur ein kleiner Teil der Funktionalität angepasst werden muss, ermöglicht `inheritance` die Wiederverwendung von Code aus einer oder mehreren übergeordneten `class`en und kann dazu beitragen, Programme sauberer und wartbarer zu machen.


`Inheritance` beschreibt eine [„ist eine Art von"-Beziehung][is-a] zwischen zwei oder mehr `class`en.
Gemeinsame oder eher „generische" Merkmale werden in einer `super class` zusammengefasst (auch _Basisklasse_ oder _Elternklasse_ genannt); spezifischere Details, Verhaltensweisen und Daten werden in einer oder mehreren `subclass`en ausgearbeitet und erweitert (auch _abgeleitete Klassen_ oder _Kindklassen_ genannt).
