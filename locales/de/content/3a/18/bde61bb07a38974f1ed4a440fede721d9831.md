# Einführung

In sicherheitssensiblen Situationen (oder auch einfach in einer großen Codebasis, in der Entwickler unterschiedliche Prioritäten und Ziele haben) solltest du vermeiden, dass die öffentliche API einer Klasse dadurch umgangen wird, dass du veränderliche Parameter einer Methode entgegennimmst und speicherst oder dass du ein veränderliches Mitglied einer Klasse über einen Rückgabewert oder als `out`-Parameter offenlegst.
