# Einführung

## Der ternäre Operator

Ein ternärer bedingter Ausdruck ist eine kürzere Schreibweise für einfache `if/else`-Anweisungen.
Enthält eine `if/else`-Anweisung nur zwei Zweige, einen für den Fall, dass die Bedingung wahr ist, und einen für den Fall, dass sie falsch ist, kannst du sie als ternären bedingten Ausdruck neu schreiben.

Ternäre Ausdrücke kombinieren die Symbole `?` und `:` und teilen damit eine Bedingung auf:

```ruby
condition ? true_branch : false_branch
```

Der Code links vom `?` ist die Bedingung, und der Code rechts enthält die beiden möglichen Zweige, getrennt durch das `:`.
Ist die Bedingung _wahr_, wird der Code auf der _linken_ Seite des `:` ausgeführt.
Ist die Bedingung _falsch_, wird der Code auf der _rechten_ Seite des `:` ausgeführt.

Zum Beispiel:

```ruby
if traffic_light == 'green'
  cross_the_road
else
  wait
end
```

lässt sich auch so schreiben:

```ruby
traffic_light == 'green' ? cross_the_road : wait
```
