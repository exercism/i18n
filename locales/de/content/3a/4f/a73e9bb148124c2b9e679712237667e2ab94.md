# Vermeide Drucken und Logging

Vermeide es, über `stdout` und `stderr` etwas auszugeben oder zu loggen.

Normalerweise ist es keine gute Idee, in Paketen auf einer niedrigeren Ebene etwas nach `stdout` oder `stderr` auszugeben.
Das erledigen Pakete auf einer höheren Ebene oder das `main`-Paket, die den nötigen Kontext haben, um zu wissen, was mit einem Fehler geschehen soll.
`log.Println` oder `fmt.Println` in einem Paket auf einer niedrigeren Ebene lassen sich von außen nicht überschreiben.
Drucken und Logging sind beim Debuggen nützlich, sollten aber entfernt werden, bevor du eine Übung einreichst oder ein Paket veröffentlichst.

Manchmal sieht es so aus, als müsste die Funktionssignatur geändert werden, um einen Fehler zurückzugeben.
Anders als in der echten Welt ist die Funktionssignatur in diesen Übungen vorgegeben.
Darüber lässt sich diskutieren: Vielleicht ist es gar nicht nötig, einen Fehler zurückzugeben, oder die Übung muss angepasst werden.
