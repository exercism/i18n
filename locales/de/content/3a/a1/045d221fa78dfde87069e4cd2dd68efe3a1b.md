# Einführung

## Zahlen vergleichen

In `jq` kannst du Zahlen mit den folgenden Vergleichs- und Gleichheitsoperatoren vergleichen.

| Vergleich              | Operator |
| ---------------------- | -------- |
| Größer als             | `a > b`  |
| Größer als oder gleich | `a >= b` |
| Kleiner als            | `a < b`  |
| Kleiner als oder gleich| `a <= b` |
| Gleich                 | `a == b` |
| Ungleich               | `a != b` |

Das Ergebnis des Vergleichs ist immer ein boolescher Wert, also entweder `true` oder `false`.

```jq
1 < 3,      # => true
2 != 2,     # => false
1 == 1.0    # => true
            # All numbers are floating-points, so this is different syntax
            # for the exact same value.
```

## Strings vergleichen

Die obigen Vergleichsoperatoren kannst du auch verwenden, um Strings zu vergleichen.
In diesem Fall wird eine Wörterbuch-Reihenfolge (lexikografisch) angewendet.
Die Reihenfolge richtet sich _nach dem Unicode-Codepunkt-Wert_.

```jq
"Apple" > "Pear",   # => false
"a" < "above",      # => true
"a" == "A"          # => false
```

Du musst vorsichtig sein, wenn du zwei Variablen vergleichst, die numerische Werte zu enthalten scheinen, aber vom Typ String sind.
Aufgrund der Wörterbuch-Reihenfolge ist das Ergebnis nicht dasselbe wie beim Vergleich von Werten des Typs Zahl.

```jq
10 < 2,     # => false
"10" < "2"  # => true (because "1" comes before "2")
```

## „Strict"-Gleichheit

Der `==`-Operator von `jq` ist wie Javascripts `===` in dem Sinne, dass Dinge, die gleich „aussehen", aber von unterschiedlichem Typ sind, nicht gleich sind.

```jq
"3" == 3    # => false
            # the value on the left has type string,
            # the value on the right has type number.
```

## Arrays vergleichen

Zwei Arrays sind gleich, wenn alle entsprechenden Elemente gleich sind.

```jq
[1, 2, 3] == [1, 2, 3]      # => true
[1, 2, 3] == [1, 3, 2]      # => false, different order
[1, 2, 3] == [1, 2, "3"]    # => false, different types
```

## Objekte vergleichen

Zwei Objekte sind gleich, wenn sie dieselben Schlüssel-Wert-Paare haben.

```jq
{name: "Joe", age: 42} == {age: 42, name: "Joe"}                # => true
{name: "Joe", age: 42} == {age: 42, name: "Jane"}               # => false
{name: "Joe", age: 42} == {age: "42", name: "Joe"}              # => false
{name: "Joe", age: 42} == {age: 42, name: "Joe", height: 175}   # => false

# comparisons will drill down as deeply as required
{a: {b: {c: [1, 2]}}} == {a: {b: {c: [1, 2]}}}                  # => true
{a: {b: {c: [1, 2]}}} == {a: {b: {c: [1, 2, 3]}}}               # => false
```
