# Anleitung

In dieser Übung schreibst du Code, um eine Liste von Programmiersprachen zu verarbeiten, die du auf der Exercism-Plattform üben möchtest.

Du hast sechs Aufgaben.

## 1. Erstelle eine neue Liste

Bevor du Sprachen hinzufügen kannst, musst du zuerst eine neue Liste erstellen. Definiere eine Funktion, die eine leere Liste zurückgibt.

```clojure
(new-list)
;; => ()
```

## 2. Füge eine neue Sprache zur Liste hinzu

Wenn du Exercism erkundest und Sprachen findest, die du lernen möchtest, musst du sie zu deiner Liste hinzufügen können. Definiere eine Funktion, die eine neue Sprache am Anfang deiner Liste hinzufügt.

```clojure
(add-language "JavaScript" '("Clojurescript"))
;; => '("JavaScript" "Clojurescript")
```

## 3. Prüfe die zuletzt hinzugefügte Sprache

Du möchtest schnell prüfen können, welche Sprache du gerade hinzugefügt hast. Definiere eine Funktion, die die erste Sprache aus deiner Liste zurückgibt.

```clojure
(first-language '("Haskell" "Python"))
;; => "Haskell"
```

## 4. Entferne die erste Sprache aus der Liste

Manchmal änderst du deine Meinung über eine Sprache, die du gerade hinzugefügt hast. Definiere eine Funktion, die die erste Sprache aus deiner Liste entfernt.

```clojure
(remove-language '("Common Lisp" "Racket" "Scheme"))
;; => '("Racket" "Scheme")
```

## 5. Zähle die Sprachen in der Liste

Die Sprachen einzeln zu zählen ist umständlich. Definiere eine Funktion, die die Anzahl der Sprachen in deiner Liste zählt.

```clojure
(count-languages '("C#" "Racket" "Rust" "Ruby"))
;; => 4
```

## 6. Füge alles zusammen

Definiere eine Funktion `learning-list`, in der du einige der oben definierten Funktionen verwendest.

- Erstelle eine leere Liste.
- Füge 2 neue Programmiersprachen zur Liste hinzu.

  - "Clojure"
  - "Lisp"

- Entferne "Lisp" aus der Liste, da du für dieses Jahr vielleicht nicht genug Zeit hast und es Clojure recht ähnlich ist.
- Füge 2 weitere Programmiersprachen zur Liste hinzu.

  - "Java"
  - "JavaScript"

- Gib die Gesamtzahl der Sprachen zurück. Hinweis: Es sollten 3 sein.

```clojure
(learning-list)
;; => 3
```
