# Überblick

Code kann bedingt ausgeführt werden, indem du [`if/elif/else`-Ausdrücke][conditional-expression] verwendest. Die Bedingung(en) in einem `if/elif/else`-Ausdruck müssen vom Typ `bool` sein. F# hat kein Konzept von _truthy_-Werten.

```fsharp
if x = 5 then
    printfn "x equals 5"
elif x > 7 then
    printfn "x is not 5 and greater than 7"
else
    printfn "x is not 5 and not greater than 7"
```

Da `if/elif/else` ein Ausdruck ist, kannst du ihn an einen Namen binden oder aus einer Funktion zurückgeben.

```fsharp
let message =
    if x = 5 then
        "x equals 5"
    elif x > 7 then
        "x is not 5 and greater than 7"
    else
        "x is not 5 and not greater than 7"
```

Alle Zweige müssen denselben Typ zurückgeben. Andernfalls gibt es einen Compilerfehler:

```fsharp
if x = 5 then
    true
elif x > 7 then
    5.6

// Results in compiler error
```

Die `else`- und `elif`-Zweige sind optional, aber nur, wenn der Typ des zurückgegebenen Ausdrucks [`unit`][unit-type] ist.

```fsharp
// Valid if expression
if x > 2 then
    printfn "x is greater than two"

// Invalid if expression, results in compiler warning
if x > 2 then
    true
```

Ein `if/else`-Ausdruck kann auch in einer einzigen Zeile stehen. Das solltest du nur für einfache `if`-Ausdrücke verwenden.

```fsharp
let y = if x > 5 then 10 else 20
```
