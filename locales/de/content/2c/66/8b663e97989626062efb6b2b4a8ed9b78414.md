# Anleitung

Du entwickelst ein System, das den Mitarbeitern der Website eines Fußballvereins hilft, über Spiele zu berichten. Die Daten kommen aus verschiedenen Quellen und werden nach der Bereinigung in einen einzigen Stream geleitet.

## 1. Gib die Beschreibungen der Spieler anhand ihrer Trikotnummer aus

Die Mannschaft spielt immer nur im 4-3-3-System und hat der Regeländerung von 1965, die Auswechslungen erlaubt, nie zugestimmt, von größeren Kadern ganz zu schweigen.

Die Spielerbeschreibungen sind wie folgt:

```text
1 -> "goalie"
2 -> "left back"
3 & 4 "center back"
5 -> "right back"
6, 7, & 8 -> "midfielder"
9 -> "left wing"
10 -> "striker"
11 -> "right wing"
```

Implementiere die statische Methode `FootballMatchReports.onField()`, die anhand der Trikotnummer eine Spielerbeschreibung ausgibt.

```java
FootballMatchReports.onField(10);
// => "striker"
```

## 2. Gib „invalid“ aus, wenn die Trikotnummer nicht Teil der offiziellen Liste ist

Ändere die Methode `FootballMatchReports.onField()` so, dass sie „invalid“ zurückgibt, wenn eine Trikotnummer außerhalb des Bereichs 1-11 verarbeitet wird.

```java
FootballMatchReports.onField(13);
// => "invalid"
```
