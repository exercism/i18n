# Zusätzliche Anweisungen

## Track-spezifische Anweisungen

Deine Aufgabe ist es, eine Funktion `nucleotideCounts` zu schreiben, die als Eingabe einen String entgegennimmt und als Ausgabe ein assoziatives Array zurückgibt, das zählt, wie oft jedes Nukleotid vorkommt.
Wenn der String eine ungültige Sequenz ist, soll die Funktion einen `IllegalArgumentError` mit der Meldung `Invalid nucleotide in strand` werfen.
