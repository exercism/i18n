# Anleitung

In dieser Übung implementierst du einige Regeln aus dem klassischen Spiel Pac-Man.

Du hast vier Regeln zu implementieren, die alle mit den Spielzuständen zu tun haben.

## 1. Bestimme, ob Pac-Man einen Geist frisst

Implementiere eine Funktion, die entgegennimmt, ob Pac-Man eine Kraftpille aktiv hat und ob Pac-Man einen Geist berührt, und die einen booleschen Wert zurückgibt, ob Pac-Man den Geist fressen kann. Die Funktion sollte nur dann `true` zurückgeben, wenn Pac-Man eine Kraftpille aktiv hat und einen Geist berührt.

```lua
rules.eat_ghost(false, true)
-- => false
```

## 2. Bestimme, ob Pac-Man punktet

Implementiere eine Funktion, die entgegennimmt, ob Pac-Man eine Kraftpille berührt und ob Pac-Man einen Punkt berührt, und die einen booleschen Wert zurückgibt, ob Pac-Man gepunktet hat. Die Funktion sollte `true` zurückgeben, wenn Pac-Man eine Kraftpille oder einen Punkt berührt.

```lua
rules.score(true, true)
-- => true
```

## 3. Bestimme, ob Pac-Man verliert

Implementiere eine Funktion, die entgegennimmt, ob Pac-Man eine Kraftpille aktiv hat und ob Pac-Man einen Geist berührt, und die einen booleschen Wert zurückgibt, ob Pac-Man verliert. Die Funktion sollte `true` zurückgeben, wenn Pac-Man einen Geist berührt und keine Kraftpille aktiv hat.

```lua
rules.lose(false, true)
-- => true
```

## 4. Bestimme, ob Pac-Man gewinnt

Implementiere eine Funktion, die entgegennimmt, ob Pac-Man alle Punkte gefressen hat, ob Pac-Man eine Kraftpille aktiv hat und ob Pac-Man einen Geist berührt, und die einen booleschen Wert zurückgibt, ob Pac-Man gewinnt. Die Funktion sollte `true` zurückgeben, wenn Pac-Man alle Punkte gefressen hat und nicht verloren hat, basierend auf den in Teil 3 definierten Argumenten.

```lua
rules.win(false, true, false)
-- => false
```
