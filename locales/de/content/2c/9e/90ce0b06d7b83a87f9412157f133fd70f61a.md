# Case-Anweisungen

Wenn ein Wert mit einer Liste von Möglichkeiten verglichen wird, sagt eine Kette von `elsif`s immer wieder dasselbe:

```sather
   if zone = 0 then
      return 0;
   elsif zone = 1 then
      return 550;
   elsif zone = 2 then
      return 370;
   else
      return 920;
   end;
```

`case` sagt es nur einmal:

```sather
   case zone
   when 0 then return 0;
   when 1 then return 550;
   when 2 then return 370;
   else return 920;
   end;
```

Der Wert steht nach `case`. Jedes `when` gibt einen Wert an, mit dem er verglichen wird, und das erste, das passt, wird ausgeführt.

## Mehrere Werte in einem when

Ein `when` kann Werte auflisten, getrennt durch Kommas:

```sather
   case day
   when "Sat", "Sun" then return "Weekend";
   when "Mon", "Tue", "Wed", "Thu", "Fri" then return "Weekday";
   else return "Unknown";
   end;
```

Das funktioniert mit Ganzzahlen, Zeichen und Strings, also allem, was mit `=` verglichen werden kann.

## Das else ist nicht optional

**Ein `case`, das auf nichts passt und kein `else` hat, ist ein Fehler, der das Programm beendet, sobald er auftritt.**

Das ist anders als bei `if`: Dort bedeutet ein fehlendes `else` einfach, dass nichts passiert. Es ist auch anders als in den meisten Sprachen, in denen ein `case`, auf das nichts passt, stillschweigend nichts tut.

Jedes `case` braucht also ein `else`, selbst wenn du sicher bist, dass die `when`-Teile bereits jeden Wert abdecken. Später wird eine vierte Zone hinzugefügt, das `case` wird nicht entsprechend aktualisiert, und das Programm bricht beim ersten Fahrgast ab, der sie benutzt.

## Nur ein when wird ausgeführt

Wenn ein `when` passt, werden die Anweisungen nach seinem `then` ausgeführt und das `case` ist beendet; das Programm läuft nach dem `end` weiter. Die `when`-Teile darunter werden nie betrachtet, du musst also nichts schreiben, um zu verhindern, dass der nächste `when`-Teil ebenfalls ausgeführt wird.
