# Einführung

Eine Static Extension ermöglicht es, bestehende Typen quasi zu erweitern, ohne ihren Quellcode zu verändern. Das gelingt mit der `using`-Anweisung. Static Extensions sind ein mächtiges Werkzeug: Sie erlauben es, Typen zu erweitern, ohne sie tatsächlich zu verändern.

```haxe
using Main.IntExtender;

class Main {
  public static function main() {
    trace(2.triple()); // 6
  }
}

class IntExtender {
  public static function triple(i:Int):Int {
    return i * 3;
  }
}
```
