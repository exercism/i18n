# Lernen

Exercism bietet dir Übungen und Feedback, aber der Einstieg kann schwerfallen, wenn du zum ersten Mal Common Lisp lernst.
Diese Ressourcen helfen dir beim Start:

* [A Road to Common Lisp][road-to-cl], ein Blogbeitrag, der beschreibt, wie eine Person zu Common Lisp gekommen ist und was sie über den Einstieg denkt
* [Practical Common Lisp][practical-cl], ein vollständiges Buch zum Erlernen von Common Lisp, kostenlos online verfügbar (und auch gedruckt)
* [Common Lisp Cookbook][cl-cookbook]
* [Cliki.net Getting Start Started Page][cliki-getting-started]
* [Wikibooks book of Common Lisp, First steps][wikibooks-cl-first-steps]
  von verschiedenen Mitwirkenden
* [Awesome Common Lisp Learning][awesome-cl]

Siehe auch in diesem Common Lisp-Track auf Exercism: [Important Resources][track-resources].
