# Hinweise

## Allgemein

- Lies in der [offiziellen Erste-Schritte-Anleitung][getting-started-erlang-libraries] über die Verwendung von Erlang-Bibliotheken und insbesondere über [das Formatieren von Strings][getting-started-formatted-text-output].

## 1. Einen zufälligen Planeten erzeugen

- Verwende das bereitgestellte Modulattribut mit einer Liste von Buchstaben, die Planetenklassen darstellen.
- Es gibt eine [eingebaute Funktion][enum-random], um ein Element zufällig aus einer Liste auszuwählen.

## 2. Eine zufällige Registriernummer für ein Raumschiff erzeugen

- Es gibt eine [eingebaute Funktion][enum-random], um ein Element zufällig aus einem Bereich auszuwählen.

## 3. Ein zufälliges Sternendatum erzeugen

- Es gibt keine Elixir-Funktion, die eine zufällige Gleitkommazahl zurückgeben würde.
- Es gibt eine [eingebaute Erlang-Funktion][erl-rand-uniform], die eine zufällige Gleitkommazahl x zurückgibt, wobei `0.0 <= x < 1.0` gilt.
- Wenn `x` zu einem Bereich `0.0 <= x < 1.0` gehört, du aber eine Zahl aus einem anderen Bereich `a <= x < b` brauchst, kannst du den Bereich von x verschieben, indem du ihn mit der Breite des Bereichs (`b - a`) multiplizierst und den Anfang des Bereichs (`a`) addierst. Das heißt: `x * (b - a) + a`.

## 4. Das Sternendatum formatieren

- Es gibt keine Elixir-Funktion, die eine Gleitkommazahl in einem einzigen Schritt als String mit einer bestimmten Genauigkeit formatieren könnte.
- Es gibt eine [eingebaute Erlang-Funktion][erl-io-lib-format], die einen Format-String und eine Liste von Daten entgegennimmt und eine Charlist zurückgibt.
- Es gibt eine [eingebaute Funktion][to-string], die eine Charlist in einen String umwandelt.
- Der Format-String dieser Funktion enthält Steuersequenzen.
- Eine Steuersequenz beginnt mit `~` und hat das Muster `~F.P.PadModC`, wobei `F` für die Breite der Ausgabe steht, `P` für die Genauigkeit, `Pad` für das Füllzeichen, `Mod` für den Modifikator der Steuersequenz und `C` für den Typ der Steuersequenz.
- Um eine Gleitkommazahl mit einer gewünschten Genauigkeit zu formatieren, genügt eine Steuersequenz mit dem Muster `~.PC`.
- Der Steuersequenztyp für Gleitkommazahlen ist `f`.
- Der genaue Format-String, den du brauchst, ist `~.1f`.
