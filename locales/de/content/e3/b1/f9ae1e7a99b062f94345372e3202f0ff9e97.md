# Anleitung

In der Nähe gibt es einen Elektrogeräteladen namens „Tech Palace“. Der Besitzer des Ladens hat vor Kurzem eine große Anzeige installieren lassen, um damit Werbebotschaften anzuzeigen und um einen besonderen Gruß zu zeigen, wenn Kunden ihre sogenannten Treuekarten am Eingang vorhalten. Die Anzeige besteht aus vielen kleinen LEDs und kann mehrere Textzeilen darstellen.

Der Ladenbesitzer braucht deine Hilfe bei dem Code, mit dem der Text für die neue Anzeige erzeugt wird.

## 1. Erstelle die Willkommensnachricht

Für die meisten Kunden, die ihre Treuekarten vorhalten, möchte der Ladenbesitzer auf der Anzeige `Welcome to the Tech Palace, ` gefolgt vom Namen des Kunden in Großbuchstaben sehen.

Implementiere die Funktion `welcome`, die den Namen des Kunden entgegennimmt und die gewünschte Nachricht als String zurückgibt.

```julia-repl
julia> welcome("Judy")
"Welcome to the Tech Palace, JUDY"
```

## 2. Füge einen schicken Rahmen hinzu

Für treue Kunden, die viel im Laden kaufen, möchte der Besitzer die Willkommensanzeige schicker machen, indem er vor und nach der Willkommensnachricht eine Zeile mit Sternen hinzufügt. Wie viele Sterne in den Zeilen stehen sollen, ist noch nicht sicher, deshalb soll sich das konfigurieren lassen.

Schreibe eine Funktion `add_border`, die eine Willkommensnachricht und die Anzahl der Sterne pro Zeile als Argumente entgegennimmt. Sie soll einen String zurückgeben, der aus 3 Zeilen besteht: einer Zeile mit der gewünschten Anzahl Sterne, dann der Willkommensnachricht so, wie sie übergeben wurde, und dann einer weiteren Sternenzeile.

```julia-repl
julia> add_border("Welcome!", 10)
"**********\nWelcome!\n**********"
```

## 3. Räume alte Werbebotschaften auf

Bevor diese neue Anzeige installiert wurde, hatte der Laden eine ähnliche Anzeige, die nur nicht konfigurierbare, statische Zeilen anzeigen konnte. Der Besitzer möchte einige der alten Werbebotschaften auf der neuen Anzeige wiederverwenden. Allerdings enthalten die Daten noch einige unglückliche Leerzeichen, die verwendet wurden, um Text über mehrere übereinander gestapelte Anzeigen hinweg auszurichten. Deine Aufgabe ist es, die Botschaften aufzuräumen, damit sie wiederverwendet werden können.

Implementiere eine Funktion `clean`, die die alte Werbebotschaft entgegennimmt. Die Funktion soll zuerst alle führenden und abschließenden Leerzeichen aus dem Text entfernen und ihn dann zurückgeben.

```julia-repl
julia> clean("    BUY NOW, SAVE 10%   ")
"BUY NOW, SAVE 10%"
```
