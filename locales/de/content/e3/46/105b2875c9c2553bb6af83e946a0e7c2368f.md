# Einführung

## Protokolle

Protokolle sind ein Mechanismus, um in Elixir Polymorphismus zu erreichen, wenn das Verhalten sich je nach Datentyp unterscheiden soll.

Protokolle werden mit `defprotocol` definiert und enthalten einen oder mehrere Funktionsköpfe.

```elixir
defprotocol Reversible do
  def reverse(term)
end
```

Protokolle können mit `defimpl` implementiert werden.

```elixir
defimpl Reversible, for: List do
  def reverse(term) do
    Enum.reverse(term)
  end
end
```

Ein Protokoll kann für jeden vorhandenen Elixir-Datentyp oder für ein Struct implementiert werden.

Wenn eine Protokollfunktion aufgerufen wird, wählt Elixir automatisch anhand des Typs des ersten Arguments die passende Implementierung aus.
