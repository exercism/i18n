# Hinweise

## Allgemein

- [Konstanten][const]

## 1. Den festen Zinssatz für ein Darlehen darstellen

- Die Konstante sollte untypisiert sein, muss aber überall akzeptiert werden, wo eine Gleitkommazahl verwendet werden kann.
  Die Funktion sollte die Konstante zurückgeben.

## 2. Die Anzahl der Tage in einem Jahr darstellen

- Die Funktion sollte die Konstante zurückgeben.

## 3. Die Monate des Jahres darstellen

- Es gibt einen [Bezeichner][iota] zum Erstellen aufgelisteter Konstanten.
  Ein Block sieht [so][block] aus.
  Die Funktion sollte ein Argument entgegennehmen und es zurückgeben.

## 4. Eine Kontonummer darstellen

- Die Konstante sollte untypisiert sein, muss aber überall akzeptiert werden, wo ein String verwendet werden kann.
  Die Funktion sollte die Konstante zurückgeben.

[const]: https://golang.org/doc/effective_go.html#constants
[iota]: https://golang.org/ref/spec#Iota
[block]: https://golang.org/pkg/debug/macho/#pkg-constants
