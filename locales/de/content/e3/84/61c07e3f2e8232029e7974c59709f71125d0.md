# Einführung

Java ist eine statisch typisierte Sprache. Das bedeutet, dass der Typ einer Variable zur Kompilierzeit bekannt ist.
Wenn du einem Namen einen Wert zuweist, nennt man das Definieren einer Variable.
Eine Variable wird definiert, indem du ihren Typ explizit angibst.

```java
int explicitVar = 10;
```

Den Wert einer Variable aktualisierst du mit dem `=`-Operator.
Hier steht `=` nicht für mathematische Gleichheit.
Er weist einer Variable einfach einen Wert zu.
Sobald sie definiert ist, kann sich der Typ einer Variable nie mehr ändern.

```java
int count = 1; // Assign initial value
count = 2;     // Update to new value

// Compiler error when assigning a different type
// count = false;
```

Java ist eine [objektorientierte Sprache][object-oriented-programming] und verlangt, dass alle Funktionen in einer _Klasse_ definiert werden.
Mit dem Schlüsselwort `class` definierst du eine Klasse.

```java
class Calculator {
    // ...
}
```

Eine Funktion innerhalb einer Klasse nennt man _Methode_.
Jede Methode kann null oder mehr Parameter haben.
Alle Parameter müssen explizit typisiert sein, es gibt keine Typinferenz für Parameter.
Ebenso muss der Rückgabetyp explizit angegeben werden.
Werte werden mit dem Schlüsselwort `return` aus Methoden zurückgegeben.
Damit eine Methode von anderen Klassen aufgerufen werden kann, musst du den Zugriffsmodifizierer `public` hinzufügen.

```java
class Calculator {
    public int add(int x, int y) {
        return x + y;
    }
}
```

Eine Methode rufst du auf, indem du ihre Klasse und ihren Methodennamen angibst und für jeden Parameter der Methode ein Argument übergibst.

```java
int sum = new Calculator().add(1, 2);  // here the  "add" method has been called to perform the task of addition
```

Der Gültigkeitsbereich wird in Java zwischen den Zeichen `{` und `}` definiert.

Java unterstützt zwei Arten von Kommentaren.
Einzeilige Kommentare beginnen mit `//` und mehrzeilige Kommentare stehen zwischen `/*` und `*/`.

[object-oriented-programming]: https://docs.oracle.com/javase/tutorial/java/javaOO/index.html
