# Einführung

*Kombinatorik* ist die Mathematik des Zählens und Auflistens: Sie beantwortet, auf wie viele Arten man eine Sammlung von Elementen auswählen oder anordnen kann. Factors Vokabular [`math.combinatorics`][math.combinatorics] deckt die beiden grundlegenden Fragen ab:

- **Kombinationen**: Auswahlen, bei denen die Reihenfolge *keine* Rolle spielt.
- **Permutationen**: Anordnungen, bei denen die Reihenfolge *doch* eine Rolle spielt.

Zu jeder Frage gehören zwei Wörter: ein *zählendes* Wort, das eine Zahl zurückgibt, und ein *auflistendes* Wort, das die tatsächlichen Auswahlen zurückgibt. Dazu kommt eine streamende `each-`-Variante, die für jede davon eine Quotation aufruft:

```
nCk              ( n k -- m )              ! count of k-combinations
nPk              ( n k -- m )              ! count of k-permutations
all-combinations ( seq k -- combinations )
all-permutations ( seq -- permutations )
each-combination ( seq k quot -- )
each-permutation ( seq quot -- )
```

```factor
USING: math.combinatorics prettyprint ;

5 2 nCk .                        ! => 10
{ 1 2 3 } 2 all-combinations .   ! => { { 1 2 } { 1 3 } { 2 3 } }
{ 1 2 } all-permutations .       ! => { { 1 2 } { 2 1 } }
```
