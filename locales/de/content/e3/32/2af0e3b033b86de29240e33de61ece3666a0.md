# Schleifen

Python kennt zwei Schleifenkonstrukte.
`while`-Schleifen für die _unbestimmte_ (ungezählte) Iteration und `for`-Schleifen für die _bestimmte_ (gezählte) Iteration.
Die Schlüsselwörter `break`, `continue` und `else` helfen dir, das Verhalten einer Schleife anzupassen.
`range()` und `enumerate()` helfen beim Zählen und Indexieren in Schleifen.

## While

[`while`][while statement]-Schleifen werden so lange ausgeführt, wie der `loop expression` oder „Test“ in einem [`boolean context`][truth value testing] zu `True` ausgewertet wird; sie enden, wenn er zu `False` ausgewertet wird:

```python
# Lists are considered "truthy" in a boolean context if they
# contain one or more values, and "falsy" if they are empty.

>>> placeholders = ["spam", "ham", "eggs", "green_spam", "green_ham", "green_eggs"]

>>> while placeholders:
...     print(placeholders.pop(0))
...
'spam'
'ham'
'eggs'
'green_spam'
'green_ham'
'green_eggs'
```

## For

Die grundlegende [`for`][for statement] `loop` in Python lässt sich besser als ein _`for each`_ beschreiben, das die Werte eines beliebigen [iterierbaren Objekts][iterable] durchläuft und endet, wenn der Aufruf von [`next()`][next built-in] keine Werte mehr zurückgibt (_wodurch eine [`StopIteration`][stopiteration] ausgelöst wird_).

```python
>>> word_list = ["bird", "chicken", "barrel", "bongo"]

>>> for word in word_list:
...    if word.startswith("b"):
...        print(f"{word.title()} starts with a B.")
...    else:
...        print(f"{word.title()} doesn't start with a B.")
...
'Bird starts with a B.'
'Chicken doesn\'t start with a B.'
'Barrel starts with a B.'
'Bongo starts with a B.'
```


## Sequenzobjekt `range()`

Wenn kein bestimmtes `iterable` angegeben ist, wird die spezielle Sequenz [`range()`][range] als Schleifenzähler verwendet.
`range()` benötigt ein `int`, vor dem die Sequenz `stop` macht, und kann optional die Parameter `start` und `step` annehmen.
Wenn keine `start`-Zahl angegeben wird, beginnt die Sequenz bei 0.
`range()`-Objekte sind **lazy** (_Werte werden bei Bedarf erzeugt_), unterstützen alle [üblichen Sequenzoperationen][common sequence operations] und belegen eine feste Menge an Speicher, egal wie lang die angegebene Sequenz ist.
Interessanterweise ist `range()` [_kein Iterator_][range is not an iterator] und kann in vielen Kontexten außerhalb von Schleifen verwendet werden, in denen eine Folge von Zahlen gebraucht wird.


```python
# Here we use range to produce some numbers, rather than creating a list of them in memory.
# The values will start with 1 and stop *before* 7.

>>> for number in range(1, 7):
...    if number % 2 == 0:
...       print(f"{number} is even.")
...    else:
...       print(f"{number} is odd.")
'1 is odd.'
'2 is even.'
'3 is odd.'
'4 is even.'
'5 is odd.'
'6 is even.'

# range() can also take a *step* parameter.
# Here we use range to produce only the "odd" numbers, starting with 3 and stopping *before* 15.

>>> for number in range(3, 15, 2):
...    if number % 2 == 0:
...       print(f"{number} is even.")
...    else:
...       print(f"{number} is odd.")
...
'3 is odd.'
'5 is odd.'
'7 is odd.'
'9 is odd.'
'11 is odd.'
'13 is odd.'
```


## Werte und Indizes mit `enumerate()`

Wenn sowohl Werte als auch Indizes gebraucht werden, liefert das eingebaute [`enumerate(<iterable>)`][enumerate] einen [`iterator`][iterator] über (`index`, `value`)-Paare:

```python
>>> word_list = ["bird", "chicken", "barrel", "apple"]

# *index* and *word* are the loop variables.
# Loop variables can be any valid python name.

>>> for index, word in enumerate(word_list):
...    if word.startswith("b"):
...        print(f"{word.title()} (at index {index}) starts with a B.")
...    else:
...        print(f"{word.title()} (at index {index}) doesn't start with a B.")
...
'Bird (at index 0) starts with a B.'
'Chicken (at index 1) doesn\'t start with a B.'
'Barrel (at index 2) starts with a B.'
'Apple (at index 3) doesn\'t start with a B.'


# The same method can be used as a "lookup" for pairing items between two lists.
# Of course, if the lengths or indexes don't line up, this doesn't work.

>>> word_list = ["cat", "chicken", "barrel", "apple", "spinach"]
>>> category_list = ["mammal", "bird", "thing", "fruit", "vegetable"]

>>> for index, word in enumerate(word_list):
...    print(f"{word.title()} is in category: {category_list[index]}.")
...
'Cat is in category: mammal.'
'Chicken is in category: bird.'
'Barrel is in category: thing.'
'Apple is in category: fruit.'
'Spinach is in category: vegetable.'
```

Bei der Funktion `enumerate(<iterable>)` kannst du den `start` für den Indexzähler auch auf eine andere Zahl setzen:


```python
# Here, the index count will start at 1.
>>> for position, word in enumerate(word_list, start=1):
...    if word.startswith("b"):
...        print(f"{word.title()} (at position {position}) starts with a B.")
...    else:
...        print(f"{word.title()} (at position {position}) doesn't start with a B.")
...
'Bird (at position 1) starts with a B.'
'Chicken (at position 2) doesn\'t start with a B.'
'Barrel (at position 3) starts with a B.'
'Apple (at position 4) doesn\'t start with a B.'
```


## Das Verhalten von Schleifen ändern

Mit dem Schlüsselwort [`continue`][continue statement] springst du vor zur nächsten Iteration:

```python
>>> word_list = ["bird", "chicken", "barrel", "bongo", "sliver", "apple", "bear"]
...
... # This will skip *bird*, at index 0
... for index, word in enumerate(word_list):
...     if index == 0:
...         continue
...     if word.startswith("b"):
...         print(f"{word.title()} (at index {index}) starts with a b.")
...
'Barrel (at index 2) starts with a b.'
'Bongo (at index 3) starts with a b.'
'Bear (at index 6) starts with a b.'
```


Mit dem Schlüsselwort [`break`][break statement] (_wie in vielen C-verwandten Sprachen_) kannst du die Iteration stoppen und aus der innersten umgebenden `loop` ausbrechen:

```python
>>>  word_list = ["bird", "chicken", "barrel", "bongo", "sliver", "apple"]

>>> for index, word in enumerate(word_list):
...    if word.startswith("b"):
...        print(f"{word.title()} (at index {index}) starts with a B.")
...    elif word == "sliver":
...        break
...    else:
...        print(f"{word.title()} doesn't start with a B.")
... print("loop broken.")
...
'Bird (at index 0) starts with a B.'
'Chicken doesn\'t start with a B.'
'Barrel (at index 2) starts with a B.'
'Bongo (at index 3) starts with a B.'
'loop broken.'
```


Die Schleifen-[`else`-Klausel][loop else] gibt es nur in Python, und du kannst sie für abschließende Aktionen nutzen, wenn die Iteration vollständig durchlaufen wurde.
 Anweisungen nach dem Schlüsselwort `else` werden nicht ausgeführt, wenn die Iteration durch `break` beendet wird:


```python
>>> word_list = ["bird", "chicken", "barrel", "bongo", "sliver", "apple"]

# Using enumerate to get both an index and a value.

>>> for index, word in enumerate(word_list):
...    word = word.title()
...    if word.startswith("B"):
...        print(f"{word} (at index {index}) starts with a B.")
...
... # This executes once *StopIteration* is raised and 
... # There are no more items to iterate through.
... # Note the indentation, which lines up with the for keyword.
... else:
...    print(f"Found the above b-words, out of {len(word_list)} words in the word list.")
...
'Bird (at index 0) starts with a B.'
'Barrel (at index 2) starts with a B.'
'Bongo (at index 3) starts with a B.'
'Found the above b-words, out of 6 words in the word list.'


# Terminating a loop via *break* will bypass the loop *else* clause

>>> for index, word in enumerate(word_list):
...    word = word.title()
...    if word.startswith("B"):
...       print(f"{word} (at index {index}) starts with a B.")
...    if word.startswith("S"):
...        print("Found an S, stopping iteration.")
...        break

... # This statement does not run, because a *break* was triggered.
... else:
...    print(f"Found the above b-words, out of {len(word_list)} words in the word list.")
...
'Bird (at index 0) starts with a B.'
'Barrel (at index 2) starts with a B.'
'Bongo (at index 3) starts with a B.'
'Found an S, stopping iteration.'
```
