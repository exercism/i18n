# Installation

## Zielversion

Für die Tests in diesem Track wird das Docker-Image `alpine:3.24.1` verwendet, das Stand September 2026 `sqlite3 version 3.53.4` nutzt.
Wir sind bemüht, dass die von diesem Track bereitgestellten Tools mit der neuesten Ubuntu-LTS-Version funktionieren.
Auch wenn du vielleicht neuere Versionen installiert hast, solltest du wissen, dass einige Funktionen mit unserem Test-Runner möglicherweise nicht funktionieren.
Einen Vergleich der Funktionen findest du in der [Versionshistorie von SQLite][version-history].

## Windows

So installierst du SQLite unter Windows:

1. Lade die vorkompilierten Windows-Binärdateien von der [offiziellen Downloadseite][sqlite-download] herunter.
2. Entpacke die heruntergeladene ZIP-Datei in ein Verzeichnis deiner Wahl.
   Zum Beispiel `C:\Program Files\sqlite3`.
3. Füge das Verzeichnis mit `sqlite3.exe` der PATH-Umgebungsvariable des Systems hinzu.
   Der Vorgang unterscheidet sich je nach Windows-Version ein wenig, aber die Informationen solltest du leicht finden können.
   Zum Beispiel [Anleitungen für Windows 11][windows-11-install] und [für Windows 10][windows-10-install].

## macOS

Unter macOS ist SQLite bereits vorinstalliert.
Wenn du jedoch eine neuere Version brauchst, kannst du [Homebrew][homebrew] verwenden:

```bash
brew install sqlite
```

## Ubuntu / Debian

Auf Ubuntu- und Debian-basierten Systemen kannst du SQLite mit apt installieren:

```bash
sudo apt install sqlite3
```

## CentOS / Fedora / RHEL

Auf CentOS-, Fedora- und Red-Hat-basierten Systemen kannst du SQLite mit yum oder dnf installieren:

```bash
sudo yum install sqlite3
# OR
sudo dnf install sqlite3
```

## Arch Linux

Auf Arch Linux kannst du SQLite mit pacman installieren:

```bash
sudo pacman -S sqlite
```

## Andere Installationswege und ältere Versionen

Weitere Informationen und alternative Installationsmethoden findest du auf der [SQLite-Downloadseite][sqlite-download].
Der Abschnitt `Build Product Names and Info` enthält die Namensvorlage für die verschiedenen SQLite-Versionen, sodass du mit deiner bevorzugten Suchmaschine nach der gewünschten Version suchen kannst.
