# Einführung

## Zahlen vergleichen

In JavaScript kannst du Zahlen mit den folgenden Vergleichs- und Gleichheitsoperatoren vergleichen.

| Vergleich              | Operator  |
| ---------------------- | --------- |
| Größer als             | `a > b`   |
| Größer als oder gleich | `a >= b`  |
| Kleiner als            | `a < b`   |
| Kleiner als oder gleich| `a <= b`  |
| (Strikt) gleich        | `a === b` |
| Nicht (strikt) gleich  | `a !== b` |

Das Ergebnis des Vergleichs ist immer ein boolescher Wert, also entweder `true` oder `false`.

```javascript
1 < 3;
// => true

2 !== 2;
// => false

1 === 1.0;
// => true
// All numbers are floating-points, so this is different syntax for
// the exact same value.
```

## Strings vergleichen

In JavaScript kannst du die obigen Vergleichsoperatoren auch verwenden, um Strings zu vergleichen.
In diesem Fall wird eine Wörterbuch-Reihenfolge (lexikografisch) angewendet.
Eine Liste mit der genauen Reihenfolge aller Zeichen findest du [hier][utf-16-list].

```javascript
'Apple' > 'Pear';
// => false

'a' < 'above';
// => true

'a' === 'A';
// => false
```

## Strikte Gleichheit

Vielleicht wunderst du dich über die drei Gleichheitszeichen, mit denen du in JavaScript Gleichheit prüfst.
`===` steht für die Prüfung auf _strikte Gleichheit_. Das bedeutet, dass keine Typumwandlung durchgeführt wird und Werte unterschiedlicher Typen immer ungleich sind.

```javascript
'3' === 3;
// => false
// The value on the left has type string, the value on the right has type number.

1 === 1n;
// => false
// The value on the left has type number, the value on the right has type bigint.
```

In JavaScript ist die Verwendung von `===` und `!==` die empfohlene Art, Gleichheit zu prüfen.

Es gibt auch `==` und `!=`, womit du auf _lose Gleichheit_ prüfst.
Das solltest du vermeiden, weil dabei vor dem Vergleich eine implizite Typumwandlung stattfindet.
Die Ergebnisse sind in diesen Fällen schwer vorherzusagen und manchmal nicht das, was du erwartest.

```javascript
0 == false;
// => true
```
