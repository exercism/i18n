# Anleitung

In dieser Übung organisierst du Rennen zwischen verschiedenen Arten von ferngesteuerten Autos.
Jedes Auto hat seine eigenen Eigenschaften und fährt während der Turniersaison auf vielen
verschiedenen Strecken Rennen.

~~~~exercism/note
Die Funktionen in dieser Übung werden in einer C-Quelldatei mit den vorgegebenen Signaturen
deklariert.
Dein x86-64-Assembly-Code muss diese Vorgaben einhalten.
~~~~

## 1. Erstelle ein ferngesteuertes Auto

Du hast eine Struktur `car_t` definiert, die ein ferngesteuertes Auto repräsentiert:

```c
struct car_t {
    char name[10];
    int16_t speed;
    float battery;
};
```

Definiere eine Funktion `new_car` in x86-64-Assembly, mit der du ein ferngesteuertes Auto
erzeugen kannst.
Das Feld `battery` hat immer den Startwert `100.0`.

```c
struct car_t new_car(short speed, const char name[]);
```

## 2. Erstelle eine neue Strecke

Strecken werden durch eine Struktur `track_t` dargestellt:

```c
struct track_t {
    enum surface_t surface;
    size_t distance;
};
```

Das `enum surface_t` hält die verschiedenen Oberflächen einer Strecke fest:

```c
enum surface_t {
    ASPHALT,
    SAND,
    ICE,
    CLAY
};
```

Definiere eine Funktion `new_track` in x86-64-Assembly, mit der du eine neue Strecke erzeugen
kannst.

```c
struct track_t new_track(enum surface_t surface, size_t distance);
```

## 3. Erstelle eine Rennveranstaltung

An jedem Rennen nehmen bis zu 6 Autos teil, die eine bestimmte Anzahl von Runden auf einer
Strecke fahren.
Rennen werden durch eine Struktur `race_t` dargestellt:

```c
struct race_t {
    struct track_t track;
    uint8_t num_of_laps;
    struct car_t cars[6];
    uint8_t num_of_running_cars;
};
```

Definiere eine Funktion `new_race` in x86-64-Assembly.
Zu Beginn gibt es noch keine bestätigten teilnehmenden Autos für das Rennen:

```c
struct race_t new_race(struct track_t track, uint8_t num_of_laps);
```

## 4. Bestätige ein Auto für das Rennen

Wenn der Besitzer eines Autos darum bittet, dass es an einem Rennen teilnimmt, wird seine
Teilnahme nur bestätigt, wenn die Liste noch nicht voll ist.

Definiere eine Funktion `add_participant` in x86-64-Assembly.
Wenn im Rennen noch Platz für einen weiteren Teilnehmer ist, wird das Auto zur Liste
hinzugefügt, der Zähler aktualisiert und seine Teilnahme bestätigt.
Andernfalls müssen die Rennveranstalter den Besitzer des Autos darüber informieren, dass es
diesmal nicht teilnehmen kann.

```c
bool add_participant(struct race_t *race, struct car_t car);
```

## 5. Erstelle ein Turnier

Die für die Saison geplanten Rennen hältst du in einer Struktur `tournament_t` fest:

```c
struct tournament_t {
    struct race_t races[20];
    size_t num_of_races;
};
```

Definiere eine Funktion `add_race` in x86-Assembly, um dem Array des Turniers ein Rennen
hinzuzufügen und auch seinen Zähler zu aktualisieren.
Du kannst davon ausgehen, dass im Array `races` immer genug Platz für das neue Rennen ist.

```c
void add_race(struct tournament_t *tournament, struct race_t race);
```
