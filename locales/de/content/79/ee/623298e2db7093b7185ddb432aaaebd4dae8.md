# Ergänzung zu den Anweisungen

## Ausgabeformate

Die Funktion `treeFromTraversals` soll ein Objekt mit 3 Eigenschaften zurückgeben:

- `value` Der Wert des aktuellen Knotens
- `left` Ein Objekt, das das linke Kind des Knotens enthält
- `right` Ein Objekt, das das rechte Kind des Knotens enthält

```javascript
{
    value: 'a',
    left: { value: 'i', left: {}, right: {} },
    right: { value: 'x', left: {}, right: {} },
}
```

Wenn der Baum leer ist, soll die Funktion ein leeres Objekt zurückgeben.
