# Einführung

In C# wird das Literal `null` verwendet, um das Fehlen eines Werts auszudrücken. Ein _nullable_-Typ ist ein Typ, der `null`-Werte zulässt.

Vor C# 8.0 waren Verweistypen immer nullable und Werttypen nicht. Ein Werttyp lässt sich jedoch nullable machen, indem man ein Fragezeichen (`?`) anhängt.

```csharp
string nullableReferenceType = "hello";
nullableReferenceType = null; // Valid as type is nullable

int nonNullableValueType = 5;
nonNullableValueType = null; // Compile error as type is not nullable

int? nullableValueType = 5; // Define nullable value type
nullableValueType = null;   // Valid as type is nullable
```

Der Zugriff auf einen Member einer Variablen, deren Wert `null` ist, lässt sich problemlos kompilieren, führt aber zur Laufzeit dazu, dass eine `NullReferenceException` ausgelöst wird:

```csharp
string sentence = null;

// Throws NullReferenceException at runtime
sentence.Length;
```

Um dieser häufigen Art von Fehler entgegenzuwirken, erlaubt es C# 8, sich für ein Feature zu entscheiden, das Verweistypen standardmäßig non-nullable macht:

```csharp
string nonNullableReferenceType = "book";
nonNullableReferenceType = null; // Compile warning (no error!)

string? nullableReferenceType = "movie";
nullableReferenceType = null; // Valid as type is nullable
```

Um sicher mit nullable-Werten zu arbeiten, sollte man prüfen, ob sie `null` sind, bevor man mit ihnen arbeitet:

```csharp
string NormalizedName(string? name)
{
    if (name == null)
    {
        return "UNKNOWN";
    }
    else
    {
        // Value is not null at this point, so no compile warning
        // and no runtime NullReferenceException being thrown
        return name.ToUpper();
    }
}

NormalizedName(null); // => "UNKNOWN"
NormalizedName("Elisabeth"); // => "ELISABETH"
```

Der Operator `??` erlaubt es, einen Standardwert zurückzugeben, wenn der Wert `null` ist:

```csharp
string? name1 = "John";
name1 ?? "Paul"; // => "John"

string? name2 = null;
name2 ?? "George"; // => "George"
```

Der Operator `?.` erlaubt es, Member sicher auf einem möglicherweise `null`-Wert aufzurufen:

```csharp
string? fruit = "apple";
fruit?.Length; // => 5

string? vegetable = null;
vegetable?.Length; // => null
```
