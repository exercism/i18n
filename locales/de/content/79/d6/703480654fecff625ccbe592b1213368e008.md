# Anleitung

Hallo, Agent Double-Null0111, da bist du ja wieder.

Die Kräfte von UMBRA machen wieder Ärger, und es liegt an dir, ihren neuesten Plan zu vereiteln.
Unser Geheimdienst teilt uns mit, dass diese Minions planen, auf dem Gouverneursball eine Stinkbombe zu zünden.

Da die Minions so tollpatschig sind, schärfen sie die Stinkbomben in ihren Laboren und Büros oft versehentlich.
Und weil sie immer wieder vergessen, wie man ihre Stinkbomben entschärft, haben sie ein System implementiert, das die Entschärfungsanweisungen generiert, in denen die Reihenfolge aufgelistet ist, in der die Drähte anhand der ID-Nummer der Bombe durchtrennt werden müssen.

Deine Aufgabe ist es, den Code zu schreiben, mit dem du die Stinkbombe auf dem Ball entschärfen kannst, bevor sie explodiert.

## 1. Schreibe eine Closure, die zwei Drähte vertauscht

Jede Stinkbombe hat drei verschiedenfarbige Drähte.
Schreibe eine Closure, die ein `(String, String, String)`-Tupel entgegennimmt und das Tupel zurückgibt, bei dem die Reihenfolge der ersten beiden Elemente vertauscht ist.
Weise diese Closure dem Namen `flip` zu.

Wichtig ist, dass der Typ `ChangeClosure` (oder ein Sendable-Typ) sein muss. Die Typdefinition ist in der Stub-Datei angegeben.
Andernfalls kompiliert der Code nicht.

```swift
flip(("red", "yellow", "blue"))
// Returns ("yellow", "red", "blue")
```

## 2. Schreibe eine Closure, die die Drähte rotiert

Schreibe eine Closure, die ein `(String, String, String)`-Tupel entgegennimmt und das Tupel zurückgibt, bei dem die Reihenfolge der Drähte nach links rotiert wurde.
Weise diese Closure dem Namen `rotate` zu.

Wichtig ist, dass der Typ `ChangeClosure` (oder ein Sendable-Typ) sein muss. Die Typdefinition ist in der Stub-Datei angegeben.

```swift
rotate(("red", "yellow", "blue"))
// Returns ("yellow", "blue", "red")
```

## 3. Implementiere einen Generator zum Mischen der Drähte

Um die Reihenfolge herauszufinden, in der die Drähte der Stinkbombe durchtrennt werden müssen, musst du eine Funktion implementieren, die anhand der ID-Nummer der Stinkbombe die passende Mischfunktion generiert.

Implementiere die Funktion:

```swift
makeShuffle(
  flipper: @escaping ((String, String, String)) -> (String, String, String),
  rotator: @escaping ((String, String, String)) -> (String, String, String)
) -> ([UInt8], (String, String, String)) -> (String, String, String)
```

die als Eingabe eine Closure, die zwei Drähte vertauscht, und eine Closure, die die drei Drähte rotiert, entgegennimmt und eine Closure zurückgibt.
Diese zurückgegebene Closure nimmt die ID-Nummer der Stinkbombe und die Reihenfolge der drei Drähte entgegen und berechnet dann die Reihenfolge, in der die Drähte durchtrennt werden müssen.
Die ID-Nummer besteht aus acht Bits, und jedes Bit bestimmt, ob die Drähte vertauscht oder rotiert werden.

Für jedes Bit in der ID-Nummer, beginnend mit dem rechtesten Bit, wendest du die `flipper`-Closure auf das Tupel der Drähte an, wenn das Bit 0 ist, und du wendest die `rotator`-Closure an, wenn es 1 ist, was den neuen Zustand der Drähte ergibt.
Nachdem die entsprechenden Closures für alle acht Bits der ID angewendet wurden, ist der endgültige Zustand der Drähte die Reihenfolge, in der sie durchtrennt werden müssen.

```swift
let shuffler = makeShuffle(flipper: flip, rotator: rotate)
// Returns ([UInt8], (String, String, String)) -> (String, String, String)
shuffler([1, 0, 0, 1, 1, 0, 1, 1], ("red", "yellow", "blue"))
// Returns ("red", "blue", "yellow")
```
