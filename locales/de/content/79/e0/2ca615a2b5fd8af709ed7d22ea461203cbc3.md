# Über

In Common Lisp werden falsche Werte durch die leere Liste `()` oder das Symbol `nil` dargestellt.
Diese Werte können mit oder ohne Quote geschrieben werden.

```lisp
;; Equivalent False Values
()   ; => NIL
nil  ; => NIL
'()  ; => NIL
'nil ; => NIL
```

Alle anderen Werte in Lisp gelten als wahr.
Es gibt außerdem das spezielle konstante Symbol `t`, das immer gleich `t` ist (und daher immer wahr ist).

```lisp
;; Some Different True Values
42                        ; => 42
"this statement is false" ; => "this statement is false"
t                         ; => T
't                        ; => T
```
