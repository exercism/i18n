# Hinweise

## Allgemeines

- Vielleicht möchtest du eine DSL auf Basis von Listen aus Tags und Records bauen, so wie hier:

  ```roc
  my_graph =
      Graph.create([
          Title("My Graph"),
          Node("a", { color: Green }),
          Node("b", { color: Blue }),
          Edge("a", "b", { style: Dotted }),
      ])
  ```

- Oder du bevorzugst vielleicht eine DSL auf Basis von Ketten von Funktionsaufrufen, so wie hier:

  ```roc
  my_graph =
      Graph.create()
          .with_title("My Graph")
          .add_node("a", Attr.create().with_color(Green))
          ...
  ```

  Oder hast du einen ganz anderen Plan?
  Nur zu!

- Allerdings ist eine DSL meist besser, wenn sie klar, knapp und nicht zu überraschend ist (z. B. ist die Funktion `minus` zum Subtrahieren gedacht und nicht dazu, eine Kante zwischen zwei Knoten zu bauen, wie in `node("a") - node("b")`).
