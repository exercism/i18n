# Über for-each-Schleifen

Die [for-each-Schleife](https://docs.oracle.com/javase/tutorial/java/nutsandbolts/for.html) bietet eine Möglichkeit, einen Block Code für jedes Element in einer Sammlung auszuführen.
Manche Dokumentationen (z. B. die Oracle-Dokumentation) nennen sie auch „enhanced for loops“.

Hier ist die allgemeine Syntax:

```java
for(declaration: collection) {
    body;
}
```

Die `declaration` deklariert die Variable, die die aus der Sammlung zugewiesenen Werte aufnimmt.

Die `collection` ist ein Array oder eine Sammlung, die die Werte enthält, die der Schleifenvariable zugewiesen werden.

Der `body` enthält die Anweisungen, die einmal für jeden Wert in der Sammlung ausgeführt werden.

Zum Beispiel:

```java
char[] vowels = {'a', 'e', 'i', 'o', 'u'};

for(char vowel: vowels) {
    System.out.println(vowel);
}
```

was Folgendes ausgibt:

```text
a
e
i
o
u
```

Im Allgemeinen ist eine `for-each`-Schleife einer `for`-Schleife aus den folgenden Gründen vorzuziehen:

- Eine `for-each`-Schleife durchläuft garantiert _alle_ Werte.
- Eine `for-each`-Schleife ist _deklarativer_, das heißt, der Code teilt mit, _was_ er tut, statt _wie_ er es tut.
- Eine `for-each`-Schleife ist narrensicher, während man bei `for`-Schleifen leicht einen Off-by-one-Fehler hat (denk an `<` gegenüber `<=`).
- Eine `for-each`-Schleife funktioniert mit allen Sammlungstypen, auch mit denen, die keinen Indexzugriff auf ihre Elemente unterstützen (z. B. ein `Set`).
