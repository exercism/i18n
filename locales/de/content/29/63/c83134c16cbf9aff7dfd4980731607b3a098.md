# Einführung

Wie andere Sprachen bietet auch C++ eine `switch`-Anweisung.
Mit `switch`-Anweisungen kannst du lange `if ... else if`-Anweisungen kürzer schreiben.
Um eine `switch`-Anweisung zu schreiben, beginnst du mit dem Schlüsselwort `switch`, gefolgt von einer Ganzzahl.
Danach deklarierst du jede der Bedingungen mit dem Schlüsselwort `case`.
Du kannst auch einen `default`-Fall deklarieren, der ausgeführt wird, wenn keine der vorherigen `case`-Bedingungen zutrifft.
Jeder Fall sollte mit einer `break`-Anweisung (oder einer `return`-Anweisung) enden.

```cpp
int price{0};
int adults{3};
int kids{2};

switch (int group_size{adults + kids}) {
    case 1:
        price = 50;
        break;
    case 2:
        price = 70;
        break;
    default:
        price = group_size * 30;
}
```

## Durchfallen

Wichtig bei einer `switch`-Anweisung ist, dass der Code so lange weiter ausgeführt wird, bis ihn eine `break`-Anweisung (oder eine `return`-Anweisung) stoppt.
Das kann zu unerwartetem Verhalten führen.

```cpp
int adults{1};
int kids{0};
switch (int group_size{adults + kids}) {
    case 1:
        price = 50;
    case 2:
        price = 70;
    default:
        price = group_size * 30;
}
// price will be 30!
```

Der wichtigste Anwendungsfall für dieses Weiterlaufen ist ein Fall mit mehreren Marken.
Mehrere `switch`-Ergebnisse können auf denselben auszuführenden Codeabschnitt verweisen.
So kann zum Beispiel in einer Buchungs-App die aufgerufene Funktion für die Gruppengrößen 2 und 3 dieselbe sein:
```cpp
switch (group_size) {
case 1:
    book_room();
    break;
case 2:
case 3:
    book_apartment(group_size);
    break;
default:
    book_house(group_size);
}
// book_apartment happens when group_size is 2 or 3
```
