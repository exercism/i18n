# Iteration

In der Programmierung bezeichnet [Iteration][iteration] den Vorgang, einen Block Code mehrmals zu wiederholen.
Das kannst du mit Konzepten wie while-Schleifen und until-Schleifen erreichen.
Ebenso geht es mit Rekursion, also einer Funktion, die sich selbst aufruft.

Meistens möchtest du aber über eine Sammlung von Elementen iterieren, etwa ein `Array`, ein `Range` oder ein `String`.
Die Klassen `Array` und `Range` in Crystal binden beide das Modul [`Enumerable`][enumerable] ein, das eine Reihe von Methoden zum Iterieren über die Elemente bereitstellt.
Die Klasse `String` hat dagegen ihre eigenen Methoden, um über die Zeichen zu iterieren.

Außerdem gibt es in Crystal keine for-Anweisung wie in anderen Sprachen.
Stattdessen gibt es mehrere Methoden, mit denen du iterieren kannst.

## Iterieren

Am häufigsten iterierst du über eine Sammlung mit der Methode [`each`][each], die jedes Element der Sammlung an einen Block übergibt.
Mit einem `Range` geht das ganz einfach.
Angenommen, du möchtest von 1 bis 3 schleifen, dann kannst du die Methode `each` verwenden, um über den Range zu iterieren.

```crystal
(1..3).each do |n|
  puts n
end

# Output:
# 1
# 2
# 3
```

Noch einfacher: Wenn du nur eine bestimmte Anzahl von Malen iterieren möchtest, kannst du die Methode [`times`][times] verwenden, die es in der Klasse `Int` gibt.

```crystal
3.times do |n|
  puts n
end

# Output:
# 0
# 1
# 2
```

## Über einen `String` iterieren

Ein `String` ist eine Folge von Zeichen und gehört nicht zum Modul `Enumerable`. Deshalb hat er seine eigenen Methoden, um über die Zeichen zu iterieren.
Am häufigsten iterierst du über einen `String` mit der Methode [`each_char`][each_char], die jedes Zeichen des `String` an einen Block übergibt.

~~~~exercism/note
Die Methode `each_char` übergibt dem Block ein `Char`-Objekt und kein `String`-Objekt.
~~~~

```crystal
str = "hello"
str.each_char { |char| puts char }

# Output:
# h
# e
# l
# l
# o
```

Eine andere Möglichkeit, über einen `String` zu iterieren, ist die Methode [`each_line`][each_line].
Diese Methode wird vor allem verwendet, wenn du eine Datei Zeile für Zeile liest.

```crystal
str = "hello\nworld"
str.each_line do |line|
  puts line
end

# Output:
# hello
# world
```

## Über ein Objekt iterieren, das das Modul `Enumerable` einbindet

Das Modul [`Enumerable`][enumerable] stellt eine Reihe von Methoden bereit, um über die Elemente einer Sammlung zu iterieren.
Sammlungen, die das Modul `Enumerable` einbinden, sind `Array`, `Range`, `Hash`, `Set` und andere. Die letzteren werden in späteren Konzepten behandelt.

Am häufigsten iterierst du über ein `Array` mit der Methode [`each`][each], die jedes Element des `Array` an einen Block übergibt.

```crystal
arr = [5, 2, 3]
arr.each do |element|
  puts element
end

# Output:
# 5
# 2
# 3
```

### Map

Die Methode [`map`][map] ist eine weitere Möglichkeit, über ein `Array` zu iterieren. Sie gibt ein neues `Array` zurück, das die Ergebnisse enthält, wenn du den Block auf jedes Element anwendest.
Sie ähnelt der Methode `each`, gibt aber ein neues `Array` mit den transformierten Elementen zurück.
Transformation ist sehr nützlich, wenn du eine Funktion auf jedes Element der Sammlung anwenden möchtest, was eine häufige Operation ist.

```crystal
arr = [1, 2, 3]
new_arr = arr.map do |element|
  element * 2
end

new_arr
# => [2, 4, 6]
```

Mit einer Kontrollstruktur wie `if` kannst du auch filtern, welche Elemente transformiert werden.

```crystal
arr = [1, 2, 3]
new_arr = arr.map do |element|
  if element.odd?
    element * 2
  else
    element
  end
end

new_arr
# => [2, 2, 6]
```

### Mit Index

Manchmal musst du den Index des Elements kennen, über das du gerade iterierst. Dafür kannst du die Methode [`each_with_index`][each_with_index] oder [`map_with_index`][map_with_index] verwenden.
Sie übergibt jedes Element und seinen Index an einen Block. Die Methode akzeptiert außerdem ein optionales Argument, um den Startindex anzugeben.

```crystal
arr = [1, 2, 3]
arr.each_with_index(4) do |element, index|
  puts "Element: #{element}, Index: #{index}"
end

# Output:
# Element: 1, Index: 4
# Element: 2, Index: 5
# Element: 3, Index: 6
```

Beachte, dass die Methode [`each_char_with_index`][each_char_with_index] auch für `String`-Objekte verfügbar ist.

### sum

Die Methode [`sum`][sum] gibt die Summe aller Elemente der Sammlung zurück. Sie akzeptiert außerdem einen optionalen Block, um die Elemente vor dem Summieren zu transformieren.
Sie akzeptiert auch ein optionales Argument, um den Startwert der Summe festzulegen.

```crystal
arr = [1, 2, 3]
arr.sum
# => 6

arr.sum(2) { |n| n * 2 }
# => 14
```

### reduce

[`reduce`][reduce], in anderen Sprachen auch als fold bekannt, ist eine Methode, die mit einer Kombinierungsmethode und einem Startwert alle Elemente der Sammlung zusammenführt.
Die Methode `reduce` hat einen Akkumulator, der an den Block übergeben wird. Der Akkumulator ist das Ergebnis der vorherigen Iteration.
So entsteht ein rekursiver Prozess, der alle Elemente der Sammlung zusammenführt.

```crystal
arr = [1, 2, 3]
arr.reduce(0) do |acc, n|
  acc + n
end
# => 6
```

`reduce` mag `sum` ähneln, aber `reduce` ist flexibler, weil du den Startwert des Akkumulators und die Kombinierungsmethode angeben kannst.
Mit `reduce` kannst du `sum`, `count` und andere Methoden implementieren.
