# Klassen

Klassen sind eine Einheit zur Organisation von Code in PHP.
Code, der das Verhalten eines Gegenstands beschreibt, oder Code, der das Verhalten eines Prozesses beschreibt, kann in einer Klasse zusammengefasst werden.
Funktionen, die einer Klasse zugeordnet sind, werden per Konvention `methods` genannt.

```php
<?php

class Door
{
    function lock()
    {
        // ...
    }

    function unlock()
    {
        // ...
    }
}
```

Klassen werden mit dem Schlüsselwort `new` instanziiert. Dabei wird Speicher für die Instanz der Klasse reserviert und die Konstruktormethode der Klasse aufgerufen.
Eine instanziierte Klasse kann einer Variablen zugewiesen werden.
Um die Methoden einer Klasseninstanz aufzurufen, verwenden wir den Zugriffsoperator `->`.

```php
<?php

$a_door = new Door();
$a_door->lock();
$a_door->unlock();
```

Eine instanziierte Klasse kann über die spezielle Variable `$this` auf ihre eigene Instanz verweisen.
Klassen können außerdem Eigenschaften haben. Diese verhalten sich wie Variablen, die an die Instanz des Klassenobjekts gebunden sind.
Auf diese Eigenschaften kann intern oder extern zugegriffen werden.

```php
<?php

class Car
{
    public $color;

    function __construct($color)
    {
        $this->color = $color;
    }

    function getColor()
    {
        return $this->color;
    }
}

$a_car = new Car("red");
$a_car->color; // => "red" by accessing the property
$a_car->getColor(); // => "red" by invoking the instance method
```
