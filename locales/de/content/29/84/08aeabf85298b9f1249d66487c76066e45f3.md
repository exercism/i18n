# Anweisungen

In dieser Übung organisierst du Rennen zwischen verschiedenen Arten von ferngesteuerten Autos. Jedes Auto hat seine eigene Geschwindigkeit und sein eigenes Entladeverhalten der Batterie.

Autos starten mit vollen Batterien (100 %). Jedes Mal, wenn du das Auto mit der Fernbedienung fährst, legt es die Geschwindigkeit des Autos in Metern zurück und verringert den verbleibenden Batteriestand um seine Batterieentladung.

Wenn der Batteriestand eines Autos unter seiner Batterieentladung liegt, kannst du das Auto nicht mehr fahren.

Jede Rennstrecke hat ihre eigene Distanz. Autos werden getestet, indem geprüft wird, ob sie die Strecke beenden können, ohne dass die Batterie leer wird.

Du hast sechs Aufgaben, die jeweils mit Instanzen von ferngesteuerten Autos arbeiten.

## 1. Ein ferngesteuertes Auto erstellen

Ermögliche das Erstellen eines ferngesteuerten Autos, indem du einen Konstruktor für die Klasse `NeedForSpeed` definierst, der die Geschwindigkeit des Autos in Metern und die Batterieentladung in Prozent als seine beiden Parameter entgegennimmt (beide vom Typ `int`):

```java
int speed = 5;
int batteryDrain = 2;
var car = new NeedForSpeed(speed, batteryDrain);
```

## 2. Eine Rennstrecke erstellen

Ermögliche das Erstellen einer Rennstrecke, indem du einen Konstruktor für die Klasse `RaceTrack` definierst, der die Distanz der Strecke in Metern als seinen einzigen Parameter entgegennimmt (vom Typ `int`):

```java
int distance = 800;
var raceTrack = new RaceTrack(distance);
```

## 3. Das Auto fahren

Implementiere die Methode `NeedForSpeed.drive()`, die die Anzahl der gefahrenen Meter basierend auf der Geschwindigkeit des Autos aktualisiert. Implementiere außerdem die Methode `NeedForSpeed.distanceDriven()`, die die Anzahl der vom Auto gefahrenen Meter zurückgibt:

```java
int speed = 5;
int batteryDrain = 2;
var car = new NeedForSpeed(speed, batteryDrain);
car.drive();

car.distanceDriven();
// => 5
```

## 4. Prüfen, ob die Batterie entladen ist

Aktualisiere die Methode `NeedForSpeed.drive()`, sodass sie die Batterie basierend auf der Batterieentladung des Autos entlädt. Implementiere außerdem die Methode `NeedForSpeed.batteryDrained()`, die angibt, ob die Batterie zu stark entladen ist, um noch zu fahren:

```java
int speed = 5;
int batteryDrain = 2;
var car = new NeedForSpeed(speed, batteryDrain);
car.drive();

car.batteryDrained();
// => false
```

## 5. Das ferngesteuerte Nitro-Auto erstellen

Das meistverkaufte ferngesteuerte Auto ist das Nitro. Es hat eine beeindruckende Spitzengeschwindigkeit von 50 Metern bei einer Batterieentladung von 4 %. Implementiere die (statische) Methode `NeedForSpeed.nitro()`, die diesen Autotyp zurückgibt:

```java
var car = NeedForSpeed.nitro();
car.drive();
car.distanceDriven();
// => 50
```

## 6. Prüfen, ob ein ferngesteuertes Auto ein Rennen beenden kann

Um ein Rennen zu beenden, muss ein Auto die Distanz des Rennens fahren können. Das bedeutet, dass seine Batterie nicht leer sein darf, bevor es die Ziellinie überquert hat. Implementiere die Methode `RaceTrack.canFinishRace()`, die eine Instanz von `NeedForSpeed` als Parameter entgegennimmt und `true` zurückgibt, wenn das Auto das Rennen beenden kann; andernfalls gibt sie `false` zurück:

```java
int speed = 5;
int batteryDrain = 2;
var car = new NeedForSpeed(speed, batteryDrain);

int distance1 = 100;
var race1 = new RaceTrack(distance1);

int distance2 = 300;
var race2 = new RaceTrack(distance2);

race1.canFinishRace(car);
// => true

race2.canFinishRace(car);
// => false
```
