# Tests

## Tests ausführen

Um die Tests auszuführen, führe den folgenden Befehl aus:

```bash
bats test-<exercise-slug>.bats
```

### bats ist in bash implementiert

Die bats-Datei ist ein bash-Skript mit einigen speziellen Funktionen, die der Befehl `bats` erkennt.
Du wirst einige Tests sehen, die so aussehen:

```bash
sed -E -f <exercise-slug>.sed <<< "$input"
```

Diese `<<<`-Syntax ist ein bash-*Here-String*.
Sie schickt den String auf der rechten Seite in die Standardeingabe des Programms auf der linken Seite.
Das ist ungefähr dasselbe wie

```bash
echo "$input" | sed -E -f <exercise-slug>.sed
```

## Übersprungene Tests

Eine Übung zu lösen bedeutet, dass alle ihre Tests bestehen.
Standardmäßig wird nur ein Test (der erste) ausgeführt, wenn du die Tests ausführst.
Das ist Absicht, denn so kannst du dich ganz darauf konzentrieren, nur diesen einen Test bestehen zu lassen.
Sobald er besteht, kannst du den nächsten Test aktivieren, indem du die

    [[ $BATS_RUN_SKIPPED == true ]] || skip

Annotationen, die anderen Tests vorangestellt sind, auskommentierst oder entfernst.

## Skips überschreiben

Um alle Tests auszuführen, auch die mit `skip`-Annotationen, kannst du Folgendes ausführen:

```bash
BATS_RUN_SKIPPED=true bats test-<exercise-slug>.bats
```

Oder du kannst die Zeile

```bash
[[ $BATS_RUN_SKIPPED == "true" ]] || skip
```

aus der Testdatei auskommentieren oder löschen.
