# Ergänzung zu den Anweisungen

## Hinweise

Du musst die Funktion `convert` implementieren, die eine Zahl in einen Regentropfenklang umgewandelt zurückgibt. Wenn du dir bei den Typen unsicher bist, kannst du die vorgegebene Signatur verwenden, aber lass dich davon nicht in deiner Kreativität einschränken:

```haskell
convert :: Int -> String
```

Diese Übung arbeitet mit Textdaten. Aus historischen Gründen ist der `String`-Typ von Haskell gleichbedeutend mit `[Char]`, einer Liste von Zeichen. Für einen effizienteren Umgang mit Textdaten kannst du den `Text`-Typ verwenden.

Als optionale Erweiterung dieser Übung kannst du

- dich über [String-Typen](https://haskell-lang.org/tutorial/string-types) in Haskell informieren.
- `- text` zu deiner Liste der Abhängigkeiten in package.yaml hinzufügen.
- `Data.Text` auf [die folgende Weise](https://hackernoon.com/4-steps-to-a-better-imports-list-in-haskell-43a3d868273c) importieren:

```haskell
import qualified Data.Text as T
import           Data.Text (Text)
```

- jetzt z. B. `convert :: Int -> Text` schreiben und dich auf `Data.Text`-Kombinatoren wie z. B. `T.pack` beziehen.
- die Dokumentation für [`Data.Text`](https://hackage.haskell.org/package/text/docs/Data-Text.html) nachschlagen,
- dann in Raindrops.hs alle Vorkommen von `String` durch `Text` ersetzen:

```haskell
convert :: Int -> Text
```

Dieser Teil ist völlig optional.
