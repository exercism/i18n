# Über

F#-Strings sind unveränderliche Objekte, die Text als eine Folge von Unicode-Zeichen (Buchstaben, Ziffern, Satzzeichen usw.) darstellen. Um eine Instanz von `string` zu definieren, verwendest du doppelte Anführungszeichen:

```fsharp
let fruit = "Apple"
```

Einen String kannst du bearbeiten, indem du eine seiner [Methoden][methods] oder [Eigenschaften][properties] aufrufst oder eine der Funktionen aus dem [`String`-Modul][string-module] verwendest. Da sich String-Werte nach ihrer Definition nicht mehr ändern lassen, geben alle Methoden und Funktionen zur String-Bearbeitung einen neuen String zurück.

Ein String wird durch doppelte Anführungszeichen (`"`) begrenzt. Einige Sonderzeichen müssen mit dem Backslash (`\`) [maskiert][escaping] werden. Strings können außerdem das At-Zeichen (`@`) vorangestellt bekommen, was sie zu einem [Verbatim-String][verbatim] macht, der alle maskierten Zeichen ignoriert.

```fsharp
let escaped = "c:\\test.txt"
let verbatim = @"c:\test.txt"
escaped = verbatim
// => true
```

Alternativ kannst du Strings mit [dreifachen Anführungszeichen][triple-quoted] (`"""`) definieren. Damit kannst du ein doppeltes Anführungszeichen im String verwenden, ohne es zu maskieren.

```fsharp
let tripledQuoted = """<movie title="Se7en" />"""
// => "<movie title="Se7en" />
```

Zu guter Letzt kannst du Strings mit dem [`+`-Operator][plus-operator] verketten:

```fsharp
let name = "Jane"
"Hello " + name + "!"
// => "Hello Jane!"
```
