# Über

Unison ist eine statisch typisierte, funktionale und unterhaltsame Programmiersprache, die ändern möchte, wie Programmierende mit ihrem Code umgehen.

Unison ist anders. 💖

Anders als bei vielen Programmiersprachen wird deine Unison-Codebasis nicht als veränderbare Sammlung von Textdateien gespeichert. Stattdessen wird *jede Unison-Definition über einen Hash ihres Syntaxbaums identifiziert.* Anders gesagt: Unison-Code ist inhaltsadressiert.

Diese Änderung hat weitreichende Folgen. Sie vereinfacht verteilte Programmierung, macht Builds und Abhängigkeitskonflikte überflüssig, unterstützt strukturiertes Refactoring und ermöglicht bessere Tools bei der Arbeit mit Code.

Du kannst mehr über die [große Idee hinter der Programmiersprache Unison](https://www.unison-lang.org/learn/the-big-idea/) lesen oder dir [eine kurze Tour durch die Sprache](https://www.unison-lang.org/learn/tour/) ansehen, um weitere Informationen zu bekommen.
