# Einführung

## Wörterbuch

Ein [`Dict`][dict] in Elm ist ein unveränderliches Wörterbuch aus null oder mehr Schlüssel-Wert-Paaren.

Wörterbücher werden mit Funktionen und Operatoren bearbeitet, die im [`Dict`-Modul][dict-module] definiert sind.

Typannotationen für Wörterbücher schreibt man wie folgt

```elm
Dict String (List Int) --> a dict with String keys and List Int values
Dict Int String --> a dict with Int keys and String values
```

Wörterbücher können wie folgt erstellt werden:

```elm
empty : Dict Int String
empty = Dict.empty

singleValue = Dict.singleton 5 "Value for key 5" --> Dict Int String

twoValues = Dict.fromList [ ( "Alice", 0 ), ( "Bob", 1 ) ] --> Dict String Int
```

Einträge können mit `get` abgerufen werden.
Da ein Schlüssel im Wörterbuch vorhanden sein kann oder nicht, wird das Ergebnis in ein `Maybe` verpackt.

```elm
alice = Dict.fromList [ ( 0, "Alice" ) ]
keyExists = Dict.get 0 alice --> Just "Alice"
keyNotPresent = Dict.get 1 alice --> Nothing
```

Einträge können mit `insert` hinzugefügt werden.
Einträge für Schlüssel, die bereits im Wörterbuch vorhanden sind, werden ersetzt.

```elm
alice = Dict.fromList [ ( "Alice", 0 ) ]
aliceAndBob = Dict.insert "Bob" 1 alice  --> Dict.fromList [ ( "Alice", 0 ), ( "Bob", 1 ) ]
aliceAndAlice = Dict.insert "Alice" 1 alice  --> Dict.fromList [ ( "Alice", 1 ) ]
```

Einträge können mit `update` aktualisiert werden.
Wenn der Schlüssel nicht existiert, wird die Update-Funktion mit `Nothing` aufgerufen.

```elm
alice = Dict.fromList [ ( 0, "Alice" ) ]
aliceUpperCase = Dict.update 0 (Maybe.map String.toUpper) alice --> Dict.fromList [ ( 0, "ALICE" ) ]
aliceNoCase = Dict.update 0 (\_ -> Nothing) alice --> Dict.empty
bobUpperCase = Dict.update 1 (\_ -> Just "BOB") alice --> Dict.fromList [ ( 0, "Alice" ), ( 1, "BOB" ) ]
bobNoCase = Dict.update 1 (\_ -> Nothing) alice --> Dict.fromList [ ( 0, "Alice" ) ]
```

Einträge können mit `remove` entfernt werden.
Wenn der Schlüssel nicht existiert, ändert sich nichts.

```elm
alice = Dict.fromList [ ( 0, "Alice" ) ]
stillAlice = Dict.remove 1 --> ( 0, "Alice" )
empty = Dict.remove 0 alice --> Dict.empty
```

Eine Liste von Schlüssel-Wert-Paaren kann mit `fromList` in ein Wörterbuch umgewandelt werden.

```elm
alice = Dict.fromList [ ( 0, "Bob" ), ( 0, "Alice" ) ]
--> True Dict.fromList [ ( 0, "Alice" ) ]
```

Einträge können mit `toList` in eine Liste umgewandelt werden.
Die Liste ist nach den Schlüsseln sortiert.

```elm
aliceAndBob = Dict.fromList [ ( 1, "Alice" ), ( 0, "Bob" ) ]
bobAndAlice = Dict.toList aliceAndBob
--> [ ( 0, "Bob" ), ( 1, "Alice" ) ]
```

Mehrere Einträge können mit `filter` entfernt werden.

```elm
aliceAndBob = Dict.fromList [ ( "Alice", 1 ), ( "Bob", 0 ) ]
bob = Dict.filter (\name count -> name == "Bob") aliceAndBob --> Dict.fromList [ ( "Bob", 0 ) ]
```

Einträge können mit `map` transformiert werden.

```elm
alice = Dict.fromList [ ( "Alice", 0 ) ]
empty = Dict.map (\player count -> count + 1) alice --> Dict.fromList [ ( "Alice", 1 ) ]
```

Wörterbücher können mit `merge` kombiniert bzw. transformiert werden.

```elm
aliceAndBob = Dict.fromList [ ( "Alice", 1 ), ( "Bob", 1 ) ]
bobAndCedd = Dict.fromList [ ( "Bob", 1 ), ( "Cedd", 1 ) ]
firstDictCountsDouble = Dict.merge
        -- when only in aliceAndBob
        (\name count mergedCounts -> Dict.insert name (2 * count) mergedCounts)
        -- when in aliceAndBob and bobAndCedd
        (\name aliceAndBobCount bobAndCeddCount mergedCounts -> Dict.insert name (2 * aliceAndBobCount + bobAndCeddCount) mergedCounts)
        -- when only in bobAndCedd
        (\name count mergedCounts -> Dict.insert name count mergedCounts)
        -- the two dicts to merge
        aliceAndBob
        bobAndCedd
        -- the initial state of the merge
        Dict.empty
--> Dict.fromList [ ( "Alice", 2 ), ( "Bob", 3 ), ( "Cedd", 1 ) ]
```

Jede Funktion oder jeder Operator, der ein Wörterbuch zu verändern scheint (etwa beim Hinzufügen eines Elements), gibt tatsächlich ein neues Wörterbuch zurück.
Die Performance ist meistens kein Problem, weil die Implementierung unnötige Allokationen und Kopien vermeidet.

In Elm ist es im Allgemeinen besser, Abstraktionen auf höherer Ebene wie `Dict.map`, `Dict.filter` und `Dict.merge` zu verwenden statt Abstraktionen auf niedrigerer Ebene wie `Dict.get` und `Dict.remove`. Natürlich hängt das vom Kontext ab.
