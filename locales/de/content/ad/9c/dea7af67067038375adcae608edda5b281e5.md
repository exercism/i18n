# Einführung

Wenn du eine Sequenz von `n` Werten brauchst, bei der jeder Wert von seinem Index abhängt, gibt Factor dir `<iota>`, eine virtuelle Sequenz der Ganzzahlen `0, 1, …, n-1`, und `map`:

```factor
USING: math sequences ;

5 <iota> [ 2 * ] map .   ! => { 0 2 4 6 8 }
```

`<iota>` belegt die Ganzzahlen nicht im Voraus; `map` durchläuft sie der Reihe nach und wendet die Quotation auf jede einzelne an.

Wenn das Ergebnis pro Position ein Zeichencode ist, macht `>string` daraus einen String. Das ist der natürliche Weg, eine Zeile aus Zeichen aus Entscheidungen zusammenzusetzen, die vom Index abhängen:

```factor
USING: strings ;

5 <iota> [ CHAR: a + ] map >string .   ! => "abcde"
```

[strings]: https://docs.factorcode.org/content/article-strings.html
