# Anleitung

Deine Aufgabe ist es, zu entscheiden, was du sagst, wenn du den zusätzlichen Keks verschenkst.

Wenn du den Namen der Person kennst (z. B. wenn sie Do-yun heißt), sagst du:

```text
One for Do-yun, one for me.
```

Wenn du den Namen der Person nicht kennst, sagst du stattdessen _you_.

```text
One for you, one for me.
```

Hier sind ein paar Beispiele:

| Name   | Dialog                      |
| :----- | :-------------------------- |
| Alice  | One for Alice, one for me.  |
| Bohdan | One for Bohdan, one for me. |
|        | One for you, one for me.    |
| Zaphod | One for Zaphod, one for me. |
