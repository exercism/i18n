# Anweisungen

Lilly kocht leidenschaftlich gern.
Sie möchte mit ihren Freunden eine Pizza-Party feiern.
Um möglichst viel aus ihren Zutaten herauszuholen, muss sie vorher wissen, wie viel sie von jeder Zutat braucht.

Um das zu lösen, hat Lilly ein Programm entworfen, das einen Teil der Planung automatisieren soll, aber sie braucht deine Hilfe, um es fertigzustellen.
Hilfst du Lilly dabei, die proportional perfekte Pizza-Party zu feiern?

## 1. Ein Teigverhältnis

Lilly mag dünne, knusprige Pizzen mit einem dünnen Rand.
Der Teig für die Mitte beträgt mindestens 200 g, aber jede Person, die versorgt wird, braucht weitere 20 g Teig.

`grams = pizzas * ((persons * 20) + 200)`

Lilly braucht eine Funktion, die:

- Die Anzahl der Pizzen entgegennimmt
- die Anzahl der Personen, die jede Pizza versorgt
- und den benötigten Teig auf das nächste Gramm gerundet zurückgibt.

Um zum Beispiel 4 Pizzen zu backen, die 8 Personen versorgen:

```php
<?php

$pizza_pi = new PizzaPi();
$pizza_pi->calculateDoughRequirement(4, 8);
// => 1440
```

## 2. Ein Schuss Soße

Lilly ist sehr genau, wenn sie ihre Soße aufträgt, aber die Größe ihrer Pizzen kann schwanken.
Aus ihrer Erfahrung weiß sie, dass sie 125 ml Soße pro Pizza braucht.
Lilly braucht eine Funktion, die berechnet, wie viele Dosen Soße sie kaufen muss.

`cans of sauce = pizzas * sauce per pizza / sauce can volume`

Zum Beispiel: Lilly muss 8 Pizzen backen und jede Dose enthält 250 ml:

```php
<?php

$pizza_pi = new PizzaPi();
$pizza_pi->calculateSauceRequirement(8, 250);
// => 4
```

## 3. Etwas Käse, bitte

Käse gibt es in perfekten Würfeln und wird nach Größe verkauft.

Die Formel, die Lilly verwendet, ist nicht die Formel für die Fläche der Pizza, denn sie möchte _nicht_, dass der Käse die gesamte Fläche bedeckt.
Sie hat sich entschieden, die folgende Formel zu verwenden, um zu bestimmen, wie viele Pizzen mit einem bestimmten Durchmesser (`diameter`) aus einem Käsewürfel mit einer bestimmten Seitenlänge (`cheese_dimension`) gemacht werden können:

`pizzas = (cheese_dimension³) / (thickness * PI * diameter)`

Erstelle eine Funktion, die:

- Die Seitenlänge eines Käsewürfels entgegennimmt
- die gewünschte Dicke der Käseschicht entgegennimmt
- den Durchmesser der Pizza entgegennimmt
- und mit Lillys Formel die Anzahl der möglichen Pizzen abgerundet zurückgibt.

Zum Beispiel: ein Käsewürfel von 25x25x25 cm, eine 0,5 cm dicke Käseschicht und Pizzen mit 30 cm Durchmesser:

```php
<?php

$pizza_pi = new PizzaPi();
$pizza_pi->calculateCheeseCubeCoverage(25, 0.5, 30);
// => 331
```

## 4. Eine gerechte Aufteilung

Zum Schluss möchte Lilly, dass ihre Pizzen in jeweils 8 Stücke geschnitten und gleichmäßig unter ihren Freunden verteilt werden.

Erstelle eine Funktion, die:

- eine Anzahl Pizzen und eine Anzahl Freunde entgegennimmt
- und die Anzahl der Stücke zurückgibt, die übrig bleiben, wenn jede Person gleich viele Stücke nimmt.

Zum Beispiel:

```php
<?php

$pizza_pi = new PizzaPi();
$pizza_pi->calculateLeftOverSlices(2, 4);
// => 0
$pizza_pi->calculateLeftOverSlices(4, 3);
// => 2
```
