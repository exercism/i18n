# Ergänzung zu den Anweisungen

## Maximaler Ganzzahlwert

Laut [der Vim-Dokumentation][number]:

> Wenn 64-Bit-Zahlen verwendet werden (siehe v:numbersize), wird eine vorzeichenlose Zahl auf 0x7fffffffffffffff oder 9223372036854775807 gekürzt.

Anders gesagt: Vim script kann keine Zahl ab `2^63` als Ganzzahl darstellen.

Einige Tests dieser Übung erfordern 64-Bit-Ganzzahlen, und das übersteigt die Größengrenze für Ganzzahlen in Vim script.
Wegen dieser Einschränkung werden die Ergebnisse der Berechnungen gegen einen String geprüft, der den Ganzzahlwert ausdrückt, statt die Antwort als Ganzzahl auszudrücken.
Kannst du das lösen, indem du Zahlen vermeidest, die größer sind, als die Sprache direkt zulässt?

[number]: https://vimhelp.org/eval.txt.html#expr-number
