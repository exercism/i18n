# Tests ausführen

Wähle dein Betriebssystem:

- [Windows](#windows)
- [macOS](#macos)
- [Linux](#linux)

## Windows

1. Öffne die Eingabeaufforderung.
2. Lade die erste Übung herunter:

   ```batchfile
   C:\Users\JohnDoe>exercism download --exercise hello-world --track java
   ```

3. Wechsle in das Verzeichnis der Übung:

   ```batchfile
   C:\Users\JohnDoe>cd C:\Users\JohnDoe\exercism\java\hello-world
   ```

4. Führe die Tests aus:

   ```batchfile
   C:\Users\JohnDoe>gradlew.bat test
   ```

   _(Mach dir keine Sorgen, wenn die Tests zunächst fehlschlagen, so beginnst du jede Übung.)_

5. Löse die Übung. Suche die Anleitung `instructions.append.md` und arbeite sie durch ([auf GitHub ansehen](https://github.com/exercism/java/blob/main/exercises/practice/hello-world/.docs/instructions.append.md#tutorial)).

Viel Glück! Viel Spaß!
