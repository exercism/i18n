# Einführung

## Mathematische Funktionen

Quadratwurzeln, Winkel und Wachstumskurven lassen sich mit `+`, `-`, `*` und `/` allein nur schwer berechnen. Das Vokabular [`math.functions`][math.functions] enthält Wörter, die das für dich erledigen, und [`math.constants`][math.constants] liefert π. Wie jedes andere Wort nehmen sie ihre Eingabewerte vom Stack und lassen ihre Antwort dort liegen.

## Quadratwurzeln

```
sqrt ( x -- y )
```

```factor
USING: kernel math math.constants math.functions math.libm prettyprint ;

9 sqrt .     ! => 3.0
2 sqrt .     ! => 1.4142135623730951
```

Eine 5 Meter lange Leiter, deren Fuß 3 Meter von einer Wand entfernt steht, reicht 4 Meter an der Wand hinauf:

```factor
5 sq 3 sq - sqrt .   ! => 4.0
```

## Pi

`pi` (aus `math.constants`) legt π auf den Stack, also die Anzahl, wie oft der Durchmesser eines Kreises in seinen Umfang passt:

```factor
: wheel-edge ( diameter -- edge ) pi * ;

2 wheel-edge .   ! => 6.283185307179586
```

## Winkel werden im Bogenmaß angegeben

```
sin ( x -- y )
cos ( x -- y )
tan ( x -- y )
```

`sin`, `cos` und `tan` nehmen einen Winkel, aber nicht in Grad. Sie verwenden **Bogenmaß**, bei dem eine halbe Drehung π statt 180 entspricht. Ihnen Grad zu geben ist kein Fehler: Es liefert stillschweigend das falsche Ergebnis.

`deg>rad` rechnet Grad in Bogenmaß um, und `rad>deg` rechnet zurück. Das ist dasselbe wie mit π zu multiplizieren und durch 180 zu teilen, oder umgekehrt:

```
deg>rad ( x -- y )
rad>deg ( x -- y )
```

```factor
30 deg>rad .       ! => 0.5235987755982988
30 pi * 180 / .    ! => 0.5235987755982988
pi rad>deg .       ! => 180.0
```

Rechne Grad in Bogenmaß um, bevor du `sin` aufrufst:

```factor
: ramp-rise ( length degrees -- rise ) deg>rad sin * ;

10 30 ramp-rise .   ! => 4.999999999999999
```

Eine 10 Meter lange Rampe mit 30 Grad Steigung steigt 5 Meter an. Die Ausgabe lautet `4.999999999999999`, weil mathematische Funktionen die nächstgelegene Gleitkommazahl liefern, nicht den exakten Wert. Ohne die Umrechnung behandelt `30 sin` die 30 als Bogenmaß (fast fünf volle Umdrehungen), und die Rampe würde `-9.88` Meter „ansteigen“.

## Einen Winkel bestimmen

`fatan2` geht den umgekehrten Weg: Wenn du ihm die Höhe und die Breite gibst, liefert es den Winkel im Bogenmaß. Es steckt in [`math.libm`][math.libm]. Der Abstand *nach oben* kommt zuerst auf den Stack, dann der Abstand *zur Seite*:

```
fatan2 ( y x -- radians )
```

```factor
1.0 1.0 fatan2 .              ! => 0.7853981633974483
1.0 1.0 fatan2 rad>deg .      ! => 45.0
-1.0 -1.0 fatan2 rad>deg .    ! => -135.0
0.0 -1.0 fatan2 rad>deg .     ! => 180.0
```

Der Winkel wird von der positiven *Seitenrichtung* aus gemessen. `fatan2` betrachtet die Vorzeichen beider Abstände und kann daher jeden Wert von −180 bis 180 Grad liefern.

## Zehnerpotenzen: 10^ und log10

`10^` erhebt 10 zu einer Potenz:

```factor
5 10^ .     ! => 100000
2 10^ .     ! => 100
0.5 10^ .   ! => 3.1622776601683795
```

`log10` geht den umgekehrten Weg. Es beantwortet die Frage „10 hoch was ergibt diese Zahl?“ Diese Antwort ist der **Logarithmus** der Zahl:

```factor
100000 log10 .   ! => 5.0
100 log10 .      ! => 2.0
1 log10 .        ! => 0.0
0.001 log10 .    ! => -3.0
```

## e^ und log

`e^` und `log` sind dasselbe Paar, nur mit *e* (etwa 2,718) anstelle von 10. `e^` erhebt *e* zu einer Potenz, und `log` beantwortet die Frage „*e* hoch was ergibt diese Zahl?“

```
e^  ( x -- y )
log ( x -- y )
```

Mathematikerinnen und Mathematiker verwenden *e* für alles, was bei jedem Schritt um denselben Anteil wächst oder schrumpft. Geld, das Zinsen bringt, ist ein Beispiel, und eine Tasse Tee, die abkühlt, ein weiteres:

```factor
! 80 degrees hotter than the room, the gap shrinking by 5% a minute
: tea-gap ( minutes -- gap ) -0.05 * e^ 80 * ;

0 tea-gap .    ! => 80.0
10 tea-gap .   ! => 48.52245277701067
```

`log` macht `e^` rückgängig. Damit beantwortest du die Frage andersherum: Wie viele Minuten dauert es, bis der Abstand auf 40 Grad gesunken ist?

```factor
80 40 / log 0.05 / .   ! => 13.862943611198904
```
