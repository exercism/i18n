# Installation

## Was du brauchst

Die grundlegenden Dinge, die du zum Entwickeln in Common Lisp brauchst, sind:

- Eine Lisp-„Implementierung“, mit der du Code kompilieren und ausführen kannst und die dir eine REPL bereitstellt.
- Ein Texteditor mit Unterstützung für Lisp-Code.
- (Schön zu haben:) Die viel genutzte Referenz für die Sprache Common Lisp, die [„Common Lisp Hyperspec“][hyperspec].

## Roswell

[Roswell][roswell] ist ein Befehl zum Installieren und Verwalten von Common-Lisp-Implementierungen und bietet viele Funktionen, mit denen du Lisp-Anwendungen einfach entwickeln und verteilen kannst.
Wir verwenden es, um die Installations- und Testschritte zu vereinfachen.

### Roswell installieren

Schau dir die [Installationsanleitung][ros-inst] an und folge den Anweisungen für deine Plattform.
Für die meisten Nutzer reicht Folgendes:

* Unter MacOS und Linux macht [Homebrew][brew] das ganz einfach:
  ```sh
  brew install roswell
  ```
* Unter Windows verwendest du [Scoop][scoop]:
  ```powershell
  scoop install roswell
  ```

Wenn du Roswell zum ersten Mal benutzt, lädt und installiert es SBCL und Quicklisp.
Führe einfach Folgendes aus:
```sh
ros help
```

Starte die REPL mit
```sh
ros run
```

## Richte deinen Texteditor ein

Wenn du neu in Common Lisp bist, besonders wenn du schon Erfahrung mit Emacs hast, kommst du mit [Portacle, die portable Common-Lisp-Umgebung][portacle] schnell und einfach los.
Es ist kostenlos, hat vollen Funktionsumfang, läuft auf allen gängigen Plattformen und ist schon ab Werk vorkonfiguriert. Damit bekommst du:

- Eine Lisp-Implementierung: SBCL, inklusive Quicklisp und ASDF.
- Einen Texteditor: Emacs

... mit vielen Zusatzpaketen für das Schreiben von Lisp-Code:
- SLIME, der „Superior Lisp Interaction Mode for Emacs“, macht aus Emacs eine Common-Lisp-IDE
- ParEdit, mit dem du ganz einfach mit Klammern arbeitest.

Alles ist bereits vorkonfiguriert und einsatzbereit. Installiere Portacle, indem du es von der [Startseite][portacle] herunterlädst.

Hinweis: Emacs (der Texteditor) kann am Anfang verwirrend sein, wenn du es nicht gewohnt bist. Zum Glück gibt es online viele Einführungen zu Emacs und SLIME.

## Klassischer Einstieg

Wenn du die benötigten Tools lieber einzeln installierst, musst du Folgendes installieren und einrichten:

- ein Lisp-fähiger Texteditor: [Emacs][emacs] mit dem Paket [Slime][slime] oder [Sly][sly] ist eine gängige Wahl, aber auch [VIM][vim] mit [SLIMV][slimv], [Atom][atom] mit [SLIMA][slima] oder [VSCode][vscode] mit einem [Common-Lisp-Plugin][vscode-plugin] sind gute Optionen.
- eine Common-Lisp-Implementierung: [SBCL][sbcl] ist eine „sichere“ Wahl, die unter Linux, MacOS und Windows läuft. Da die Sprache auf einem Standard basiert, funktionieren auch andere [konforme Implementierungen][awesome-cl-implementations].
- [Quicklisp][quicklisp] für die Bibliotheksverwaltung. Folge nach dem Herunterladen der [Anleitung][quicklisp-install], um sicherzustellen, dass es richtig in deine Common-Lisp-Implementierung eingebunden ist.
