# Einführung

## Typaliase

Mit einem Typalias kannst du in Gleam einem vorhandenen Typ einen praktischen Namen geben, der sonst umständlich zu schreiben wäre.

```gleam
pub type Headers =
  List(#(String, String))

pub fn html_headers() -> Headers {
  [
    #("content-type", "text/html"),
    #("x-frame-options", "DENY"),
  ]
}
```

Wenn du `pub type` verwendest, kann der Alias auch außerhalb des Moduls verwendet werden, in dem er definiert ist. Lässt du `pub` weg, ist der Alias privat und kann in anderen Modulen nicht verwendet werden.
