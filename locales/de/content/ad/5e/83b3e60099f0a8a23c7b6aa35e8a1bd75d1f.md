# Einführung

## Benutzerdefinierte Typen

Mit benutzerdefinierten Typen definierst du in Gleam neue Datentypen. Sie können mehrere _Varianten_ haben, jede mit einem eigenen Namen.

```gleam
pub type Season {
  Spring
  Summer
  Autumn
  Winter
}
```

Jede Variante eines benutzerdefinierten Typs kann optional Daten enthalten, und verschiedene Varianten können Daten unterschiedlicher Typen enthalten. Wenn eine Variante Daten enthält, nennt man sie ein _Record_.

```gleam
pub type Number {
  SomeInt(Int)
  SomeFloat(Float)
  Invalid
}
```

Einen Wert für eine bestimmte Variante erstellst du, indem du ihren Namen angibst, wenn sie keine zusätzlichen Daten enthält (`Spring`), oder indem du sie wie eine Funktion aufrufst, wenn sie welche enthält (`SomeInt(2)`).

```gleam
let spring = Spring
let integerTwo = SomeInt(2)
```

Benutzerdefinierte Typen haben, wie alles in Gleam, _strukturelle Gleichheit_. Das bedeutet, dass zwei Werte derselben Variante mit denselben Daten gleichwertig sind.

```gleam
Spring == Spring // -> True
Spring == Autumn // -> False
SomeInt(2) == SomeInt(2) // -> True
SomeInt(2) == SomeFloat(2.0) // -> False
```

Varianten benutzerdefinierter Typen lassen sich mit case-Ausdrücken per Pattern Matching abgleichen.

```gleam
import gleam/int
import gleam/float

pub fn describe(flexible_number: Number) -> String {
  case flexible_number {
    SomeFloat(f) -> "Float: " <> float.to_string(f)
    SomeInt(i) -> "Int: " <> int.to_string(i)
    Invalid -> "Neither a float nor an int"
  }
}
```
