# Einführung

Rekursive Funktionen sind Funktionen, die sich selbst aufrufen.

Eine rekursive Funktion braucht mindestens einen _Basisfall_ und mindestens einen _Rekursionsfall_.

Ein _Basisfall_ gibt einen Wert zurück, ohne die Funktion erneut aufzurufen.
Ein _Rekursionsfall_ ruft die Funktion erneut auf und verändert die Eingabe so, dass sie irgendwann zum Basisfall passt.

In Elm definierst du rekursive Funktionen normalerweise mit Pattern Matching über `case`-Ausdrücke oder mehrere Funktionsklauseln.

```elm
count : List a -> Int
count list =
    case list of
        [] ->
            0  -- base case

        _ :: tail ->
            1 + count tail  -- recursive case
```

## Schleifen durch Rekursion

Wegen der Unveränderlichkeit schreibst du Schleifen in Elm anders als in imperativen Sprachen.
Zum Beispiel sehen Schleifen oft so aus:

```c
for(i = 0; i < array.length; i++) {
  // do something with array[i]
}
```

In einer funktionalen Sprache wie Elm kannst du Variablen nicht verändern.
Deshalb musst du Schleifen mit Rekursion umsetzen.

Das Äquivalent einer `for`-Schleife in Elm sieht so aus:

```elm
loop : List a -> (a -> b) -> List b
loop list f =
    case list of
        [] ->
            []

        head :: tail ->
            f head :: loop tail f
```

In der Praxis iterierst du über Listen und andere Datenstrukturen in Elm meistens mit Funktionen aus dem `List`-Modul, wie `List.map`, `List.filter` und `List.foldl`.
Intern sind diese Funktionen mit Rekursion implementiert.
