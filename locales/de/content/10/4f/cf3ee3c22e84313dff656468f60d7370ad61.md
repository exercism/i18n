# Case

[Case][case] (in anderen Sprachen oft als switch bezeichnet) ist eine Form von Kontrollausdruck, ähnlich wie if-else.
Mit Case lassen sich mehrere if-else-if-Anweisungen verketten. Das kann lesbarer sein und übernimmt trotzdem die Ablaufsteuerung.

Ein Case wird durch das Schlüsselwort `case` definiert, auf das ein optionaler Ausdruck folgt.
Dann wird für jeden Fall das Schlüsselwort `when` verwendet, gefolgt von einem Ausdruck, der mit dem Case-Ausdruck verglichen wird.
Das Schlüsselwort `when` sollte nicht gegenüber dem Schlüsselwort `case` eingerückt werden.
Auf das Schlüsselwort `when` folgt der Code, der ausgeführt werden soll, wenn der Case-Ausdruck mit dem when-Ausdruck übereinstimmt.
Case erlaubt eine optionale `else`-Anweisung, die ausgeführt wird, wenn kein anderer Fall passt.

Der Case-Ausdruck wird ausgewertet und dann mit jedem `when`-Ausdruck verglichen.
Der Vergleich erfolgt mit dem Case-Gleichheitsoperator (`===`).

```ruby
value = 1
case value
when 1
  "One"
when 2
  "Two"
else
  "Other"
end

# This is the same as:
value = 1
if 1 === value
  "One"
elsif 2 === value
  "Two"
else
  "Other"
end
```

## Case-Gleichheitsoperator (`===`)

Der Case-Gleichheitsoperator (`===`) unterscheidet sich etwas vom Gleichheitsoperator (`==`).
Der Operator prüft, ob die rechte Seite ein Element der Menge ist, die von der linken Seite beschrieben wird.
Das bedeutet, dass es eine Rolle spielt, auf welcher Seite jeder Operand steht.
Wie das funktioniert, hängt vom Typ der linken Seite ab. Eine `Range` prüft zum Beispiel, ob die rechte Seite im Bereich liegt, und ein `Object` prüft, ob die rechte Seite eine Instanz des `Object` ist.

```ruby
(1..3) == 1  # => false
(1..3) === 1 # => true

String == "foo"  # => false
String === "foo" # => true
```

## Case mit mehreren Ausdrücken

Mit Case lassen sich mehrere Ausdrücke in einem einzigen Case abgleichen, wobei jeder mögliche Wert durch ein Komma getrennt wird.
Der Code wird ausgeführt, wenn einer der Ausdrücke passt.
Das ist nützlich, wenn ein einzelner Fall mehrere mögliche Werte haben soll.

```ruby
case var
when 1, 2
  "One or two"
else
  "Other"
end
```

## Cases mit Bereichen

Mit Case lässt sich auch prüfen, ob ein Wert in einem Bereich liegt.
Dazu verwendest du einen Bereich als when-Ausdruck.

```ruby
case var
when 1..3
  puts "One to three"
else
  puts "Other"
end
```

## Case ohne Case-Ausdruck

Wenn kein Case-Ausdruck benötigt wird, kannst du ihn weglassen.
In diesem Fall wird jeder when-Ausdruck darauf geprüft, ob er wahr ist.
Und sie verhalten sich dann wie if-else-if-Anweisungen.

```ruby
case
when 1 == 1
  "One is equal to one"
when 1 > 2
  "One is greater than two"
else
  "Other"
end
```

## Einzeiliges when

Ruby erlaubt einzeilige Case-Anweisungen.
Das kannst du verwenden, wenn du eine einfache einzeilige Anweisung hast.
Die einzeilige when-Anweisung wird als `when <expression> then <statement>` geschrieben.
Und in der else-Anweisung wird sie als `else <statement>` geschrieben.

```ruby
case var
when 1 then "One"
when 2 then "Two"
else "Other"
end
```

## Case mit Typen

Mit Case lässt sich auch nach Typen abgleichen.
Das ist nützlich, wenn du je nach Typ einer Variable ein unterschiedliches Verhalten möchtest.

```ruby
case var
when Integer
  "Integer"
when String
  "String"
else
  "Other"
end
```
