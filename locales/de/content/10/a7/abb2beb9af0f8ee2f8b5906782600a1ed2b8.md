# Einführung

C# ist eine statisch typisierte Sprache. Das bedeutet, dass alles zur Kompilierzeit einen Typ hat. Eine Variable zu definieren bedeutet, einem Namen einen Wert zuzuweisen. Eine Variable kannst du definieren, indem du entweder ihren Typ explizit angibst oder den C#-Compiler den Typ anhand des zugewiesenen Werts ableiten lässt (bekannt als *Typinferenz*). Daher sind die folgenden beiden Variablendefinitionen gleichwertig:

```csharp
int explicitVar = 10; // Explicitly typed
var implicitVar = 10; // Implicitly typed
```

Den Wert einer Variable aktualisierst du mit dem Operator `=`. Sobald eine Variable definiert ist, kann sich ihr Typ nie mehr ändern.

```csharp
var count = 1; // Assign initial value
count = 2;     // Update to new value

// Compiler error when assigning different type
// count = false;
```

C# ist eine [objektorientierte Sprache][object-oriented-programming] und erfordert, dass alle Funktionen in einer *Klasse* definiert werden. Mit dem Schlüsselwort `class` definierst du eine Klasse. Objekte (oder *Instanzen*) erstellst du mit dem Schlüsselwort `new`.

```csharp
class Calculator
{
    // ...
}

var calculator = new Calculator();
```

Eine Funktion innerhalb einer Klasse wird als *Methode* bezeichnet. Jede Methode kann null oder mehr Parameter haben. Alle Parameter müssen explizit typisiert sein, für Parameter gibt es keine Typinferenz. Ebenso muss der Rückgabetyp explizit angegeben werden. Mit dem Schlüsselwort `return` gibst du Werte aus Methoden zurück. Damit eine Methode von Code in anderen Dateien aufgerufen werden kann, musst du den Zugriffsmodifizierer `public` hinzufügen.

```csharp
class Calculator
{
    public int Add(int x, int y)
    {
        return x + y;
    }
}
```

Methoden rufst du mit der Punkt-Syntax (`.`) auf einer Instanz auf. Dabei gibst du den Namen der aufzurufenden Methode an und übergibst Argumente für jeden Parameter der Methode. Argumente können optional den Namen des entsprechenden Parameters angeben.

```csharp
var calculator = new Calculator();
var sum_v1 = calculator.Add(1, 2);
var sum_v2 = calculator.Add(x: 1, y: 2);
```

Der Gültigkeitsbereich in C# wird zwischen den Zeichen `{` und `}` definiert.

C# unterstützt zwei Arten von Kommentaren. Einzeilige Kommentare beginnen mit `//`, mehrzeilige Kommentare stehen zwischen `/*` und `*/`.

[object-oriented-programming]: https://docs.microsoft.com/en-us/dotnet/csharp/programming-guide/concepts/object-oriented-programming
