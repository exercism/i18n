# Anleitung

Ellen entwickelt ein Spiel, in dem der Spieler gegen Aliens kämpfen muss.
Sie hat gerade etwas über objektorientierte Programmierung (OOP) gelernt und möchte unbedingt nutzen, was ihr der Einsatz von `classes` für ihr Programm bieten könnte.

Zu Ellens Freude hast du angeboten zu helfen, und sie hat dir die Aufgabe übertragen, die Aliens zu programmieren, gegen die der Spieler kämpfen muss.


## 1. Erstelle die Alien-Klasse

Definiere die Klasse Alien mit einem Konstruktor, der zwei Parameter `<x_coordinate>` und `<y_coordinate>` entgegennimmt und sie in den Instanzvariablen `x_coordinate` und `y_coordinate` ablegt.
Jeder Alien startet außerdem mit 3 Gesundheitspunkten, also sollte auch die Variable `health` initialisiert werden.

```python
>>> alien = Alien(2, 0)
>>> alien.x_coordinate
2
>>> alien.y_coordinate
0
>>> alien.health
3
```

Jetzt soll jeder Alien seine eigene Position und seine Gesundheit selbst verwalten können.

## 2. Die Methode `hit`

Ellen möchte, dass die Alien-`class` eine Methode `hit` besitzt, die bei Aufruf die Gesundheit eines Alien-Objekts um 1 verringert.
So kann sie einfach `<alien>.hit()` aufrufen, statt die Gesundheit eines Aliens manuell ändern zu müssen.
Es bleibt dir überlassen, ob `hit()` die Gesundheitspunkte _auf_ oder _unter_ null bringt.

```python
>>> alien = Alien(0, 0)

# Initialized health value.
>>> alien.health
3

# Decrements health by 1 point.
>>> alien.hit()
>>> alien.health
2
```

## 3. Die Methode `is_alive`

Dir fällt auf, dass die Gesundheit irgendwann wahrscheinlich bei 0 landen wird, wenn sie immer weiter sinkt (_oder sogar darunter!_).
Es wäre eine gute Idee, eine Methode `is_alive` hinzuzufügen, die Ellen schnell aufrufen kann, um zu prüfen, ob der Alien ... nun ja ... noch lebt. 😉
`<alien>.is_alive()` sollte einen booleschen Wert zurückgeben.

```python
>>> alien.health
1
>>> alien.is_alive()
True
>>> alien.hit()
>>> alien.health
0
>>> alien.is_alive()
False
```

## 4. Die Methode `teleport`

In Ellens Spiel können sich die Aliens teleportieren!
Du musst eine Methode `teleport` schreiben, die neue Werte für `x_coordinate` und `y_coordinate` entgegennimmt und die Koordinaten des Aliens entsprechend ändert.

```python
>>> alien.teleport(5, -4)
>>> alien.x_coordinate
5
>>> alien.y_coordinate
-4
```

## 5. Die Methode `collision_detection`

Natürlich müssen die Aliens erkennen können, wenn eine solche Kollision stattgefunden hat, wenn sie von etwas getroffen werden können.
Allerdings können Algorithmen zur Kollisionserkennung knifflig sein, und du weißt noch nicht, wie man einen implementiert.
Ellen hat gesagt, dass sie das später erledigen wird, aber sie möchte trotzdem, dass die Methode `collision_detection` in der Klasse auftaucht, als Erinnerung daran, die Funktionalität noch auszubauen.
Sie muss irgendeine Variable entgegennehmen (wahrscheinlich ein anderes Objekt), aber mehr weißt du wirklich nicht.
Du musst sicherstellen, dass das Einfügen der Methodendefinition in die Klasse keine Fehler beim Aufruf verursacht:

```python
>>> alien.collision_detection(other_object)
>>>
```

## 6. Alien-Zähler

Ellen kommt mit einer neuen Bitte zu dir zurück.
Sie möchte den Überblick behalten, wie viele Aliens im Laufe des Spiels erstellt wurden.
Sie sagt, dass es etwas mit dem Punktesystem zu tun hat.

Zum Beispiel:

```python
>>> alien_one = Alien(5, 1)
>>> alien_one.total_aliens_created
1
>>> alien_two = Alien(3, 0)
>>> alien_two.total_aliens_created
2
>>> alien_one.total_aliens_created
2
# Accessing the variable from the class directly
>>> Alien.total_aliens_created
2
```

## 7. Eine Liste von Aliens erstellen

Ellen ist begeistert von dem, was du bisher gemacht hast, aber sie hat noch eine Bitte.
Sie hätte gern eine eigenständige Funktion (_außerhalb der `Alien()`-Klasse_), die aus einer Liste von Positionen (als `tuples`) eine `list` von `Alien()`-Objekten erstellt.

Zum Beispiel:

```python
>>> alien_start_positions = [(4, 7), (-1, 0)]
>>> aliens = new_aliens_collection(alien_start_positions)
...
>>> for alien in aliens:
...     print(alien.x_coordinate, alien.y_coordinate)
(4, 7)
(-1, 0)
```
