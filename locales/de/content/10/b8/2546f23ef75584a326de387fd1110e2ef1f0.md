# Anleitung

In dieser Übung schreibst du Code, um ein Wörterbuch internationaler Vorwahlen mit einer `Map` zu verwalten.

Das Wörterbuch ermöglicht es, den Namen eines Landes (den Wert der Map, als `String`) über die internationale Vorwahl (den Schlüssel der Map, als `Integer`) nachzuschlagen.

## 1. Gib die Codes in einer Map zurück

Implementiere die Methode `getCodes`, die keine Parameter entgegennimmt und eine Map zurückgibt, die die aktuell im Wörterbuch enthaltenen Vorwahlen auf Länder abbildet.

```java
DialingCodes dialingCodes = new DialingCodes();
dialingCodes.getCodes();
// => empty map 
```

## 2. Füge Einträge zum Wörterbuch hinzu

Das Wörterbuch muss befüllt werden.
Implementiere die Methode `setDialingCode`, die eine Vorwahl und das zugehörige Land entgegennimmt und die Vorwahl und das Land hinzufügt.
Wenn die Vorwahl bereits in der Map vorhanden ist, aktualisiere die Map mit der angegebenen Vorwahl und dem angegebenen Land.

```java
DialingCodes dialingCodes = new DialingCodes();
dialingCodes.setDialingCode(679, "Unknown");
// => { 679 => "Unknown" }

dialingCodes.setDialingCode(679, "Fiji");
// => { 679 => "Fiji" }
```

## 3. Schlage das Land zu einer Vorwahl nach

Implementiere die Methode `getCountry`, die eine Vorwahl entgegennimmt und den Ländernamen zu dieser Vorwahl zurückgibt.

```java
DialingCodes dialingCodes = new DialingCodes();
dialingCodes.setDialingCode(55, "Brazil");
dialingCodes.getCountry(55);
// => "Brazil"
```

## 4. Lass keine Duplikate zu

Beim Hinzufügen einer Vorwahl musst du darauf achten, dass weder eine Vorwahl noch ein Land zweimal hinzugefügt wird.
Wenn das doch passiert, kannst du davon ausgehen, dass der erste Eintrag der richtige ist.
Implementiere die Methode `addNewDialingCode`, die einen Eintrag für die angegebene Vorwahl und das angegebene Land hinzufügt.
Anders als `setDialingCode` tut sie jedoch nichts, wenn die Vorwahl oder das Land bereits in der Map vorhanden ist.

```java
DialingCodes dialingCodes = new DialingCodes();
dialingCodes.addNewDialingCode(32, "Belgium");
dialingCodes.addNewDialingCode(379, "Vatican City");
// => { 32 => "Belgium", 379 => "Vatican City" }


dialingCodes.addNewDialingCode(32, "Other");
dialingCodes.addNewDialingCode(39, "Vatican City");
// => { 32 => "Belgium", 379 => "Vatican City" }
```

## 5. Finde die Vorwahl eines Landes

Das kommt selten vor, aber Fehler passieren.
Um den Fehler zu korrigieren, müssen wir wissen, welche Vorwahl dem Land aktuell zugeordnet ist.
Um herauszufinden, welche Vorwahl korrigiert werden muss, implementiere die Methode `findDialingCode`, die ein Land entgegennimmt und die Vorwahl des Landes zurückgibt.
Gib `null` zurück, wenn das Land _nicht_ in der Map vorhanden ist.

```java
DialingCodes dialingCodes = new DialingCodes();
dialingCodes.addDialingCode(44, "UK");
dialingCodes.findDialingCode("UK");
// => 44

dialingCodes.findDialingCode("Unlisted");
// => null
```

## 6. Aktualisiere die Vorwahl des Landes

Jetzt, wo wir wissen, welche Vorwahl korrigiert werden muss, aktualisieren wir die Vorwahl.
Implementiere die Methode `updateCountryDialingCode`, die die neue Vorwahl des Landes und den Namen des Landes entgegennimmt und die Map entsprechend aktualisiert.
Tue nichts, wenn das Land _nicht_ in der Map vorhanden ist (diese Methode soll schließlich nur helfen, Fehler zu korrigieren).

```java
DialingCodes dialingCodes = new DialingCodes();
dialingCodes.addDialingCode(88, "Japan");
// => { 88 => "Japan" }

dialingCodes.updateCountryDialingCode(81, "Japan");
// => { 81 => "Japan" }

dialingCodes.updateCountryDialingCode(32, "Mars");
// => { 81 => "Japan"}
```
