# Hinweise

## Allgemeines

- Lies in der offiziellen [String-Anleitung][string-guide] über Strings.
- Sieh dir die [für _Strings_ verfügbaren Methoden][string-methods] an.

## 1. Bereinige den Namen

- Es gibt eine [eingebaute Methode][string-replace], mit der du alle Vorkommen eines Teilstrings in einem String ersetzen kannst.
- Es gibt eine [eingebaute Methode][string-strip], mit der du führende und abschließende Leerzeichen aus einem String entfernst.

## 2. Hole den ersten Buchstaben des Namens

- Um ein bestimmtes Zeichen aus einem String zu holen, kannst du den [Index-Operator][string-indexing] verwenden.

## 3. Formatiere den ersten Buchstaben als Initiale

- Es gibt eine [eingebaute Methode][string-upcase], mit der du alle Zeichen in einem String in ihre Großbuchstaben-Variante umwandelst.

## 4. Setze die Initialen in das Herz

- Es gibt eine spezielle Syntax, um einen Ausdruck in einen String zu [interpolieren][string-interpolation].
- Du kannst ein Herz-Emoji in einen String einfügen, indem du Escaping verwendest: `\u<id>`, die ID für das Herz-Emoji ist `2764`.
