# Einführung

In Go sind Strings unveränderlich.
Wenn du Strings in einer Schleife mit `+` verkettest, kommt es zu häufigen Allokationen, und die Daten werden mehrfach kopiert.
Das [`strings`-Paket](https://pkg.go.dev/strings) stellt [`Builder`](https://pkg.go.dev/strings#Builder) bereit, mit dem du den Speicheraufwand minimierst, indem du Strings effizient zusammensetzt.

## Strings aufbauen

Der Nullwert eines `strings.Builder` ist sofort einsatzbereit, ohne dass du ihn ausdrücklich initialisieren oder Speicher allokieren musst.
Du kannst neue Daten mit bestimmten Schreibmethoden in den Builder schreiben.
Jede Schreibmethode gibt einen Fehlerwert zurück, um die Standard-Interfaces von Go zu erfüllen. Dieser Wert ist aber garantiert immer `nil` und wird im Alltagscode normalerweise ignoriert.

Die am häufigsten verwendeten Methoden sind:

- `WriteString(s string) (int, error)`: Hängt einen String an den Puffer an.
- `WriteRune(r rune) (int, error)`: Hängt die UTF-8-Kodierung einer Rune an.
- `WriteByte(c byte) error`: Hängt ein einzelnes Byte an.

```go
var sb strings.Builder

sb.WriteString("Hello")
var r rune = ' '
sb.WriteRune(r)
var b byte = '.'
sb.WriteByte(b)
```

## Abrufen und Zurücksetzen

Wenn du deinen Text fertig zusammengesetzt hast, kannst du den angesammelten Inhalt als normalen Go-String abrufen, indem du die Methode `String()` aufrufst.
Der Aufruf von `String()` ist eine sehr günstige Operation, weil er das zugrunde liegende Byte-Slice direkt als String zurückgibt, ohne die angesammelten Daten zu kopieren.

Wenn du dieselbe Builder-Instanz wiederverwenden möchtest, um einen neuen String zusammenzusetzen (zum Beispiel in einer Schleife), kannst du die Methode `Reset()` aufrufen.
Das leert den internen Puffer. Dadurch kannst du von vorn anfangen und den nächsten String aufbauen; die bereits allokierte Speicherkapazität bleibt dabei unter der Haube erhalten.

```go
var sb strings.Builder

sb.WriteString("Task One")
fmt.Println(sb.String()) // Output: Task One

// Clear the buffer for resource reuse
sb.Reset()

sb.WriteString("Task Two")
fmt.Println(sb.String()) // Output: Task Two
```
