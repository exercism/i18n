## Bash-spezifische Anweisungen

Bei dieser Übung geht es darum, wie viele Argumente an dein Programm übergeben werden.

Beachte, dass du auch leere Strings als Argumente übergeben kannst.

`./program ""`

Das ist etwas anderes, als gar keine Argumente zu übergeben.

`./program`

Wenn dein Programm mit genau einem Argument aufgerufen wird (auch wenn es ein leerer String ist), behandle es als Namen einer Person und gib eine Begrüßungsnachricht aus.
Wenn es mit null Argumenten oder mit mehr als einem Argument aufgerufen wird, gib eine Fehlermeldung aus und beende das Programm mit einem Status ungleich null.
