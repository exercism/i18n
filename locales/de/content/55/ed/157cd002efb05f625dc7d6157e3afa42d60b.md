# Anleitung

Der Hafen von Palermo ist ein geschäftiger Hafen, in dem viele Schiffe kommen und gehen.
Seit Langem gibt es dort ein manuelles System, um die Schiffe zu erfassen, die sich gerade im Hafen befinden.
Dieses System ist sehr fehleranfällig, und der Hafenchef hat beschlossen, es durch ein computergestütztes System zu ersetzen.

Der Hafenchef hat dich damit beauftragt, das neue System umzusetzen.
Das System muss Kennungen für Schiffe verwalten, aber auch für Ziele.

## 1. Erstelle die Kennung für den Hafen

Als Erstes musst du die Kennung für den Hafen von Palermo erstellen.
Die Kennung besteht aus den ersten vier Buchstaben des Hafennamens in Großbuchstaben.

Definiere die Konstante `Port::IDENTIFIER` als Symbol mit dem Wert `:PALE`.
    
```ruby
Port::IDENTIFIER 
# => :PALE
```

## 2. Kennungen für andere Häfen ermitteln

Das Programm muss auch andere Häfen verwalten, also musst du auch für sie Kennungen erstellen.
Der Hafen möchte das System automatisieren, und da Häfen unterschiedliche Namenskonventionen verwenden, sollten die Kennungen aus dem Namen des Hafens erzeugt werden.
Die Kennung besteht aus den ersten vier Buchstaben des Hafennamens in Großbuchstaben.

Definiere die Methode `Port.get_identifier`, die einen String als Argument entgegennimmt und die Kennung für diesen Hafen als Symbol zurückgibt.

```ruby
Port.get_identifier("Hamburg") 
# => :HAMB
```

## 3. Bestimme, an welchem Terminal ein Schiff anlegen soll

Der Hafen hat zwei Terminals, und das System muss bestimmen, an welchem Terminal ein Schiff anlegen soll.
Das Terminal wird durch die Kennung des Schiffes bestimmt.

Die Kennung besteht aus 2 Teilen: Der erste Teil besteht aus 3 Großbuchstaben, die angeben, welche Fracht das Schiff transportiert, danach folgen 3 Zahlen, die eindeutige Kennung des Schiffes.

Wenn das Schiff **OIL** oder **GAS** geladen hat, soll es am Terminal **A** anlegen.
Andernfalls soll das Schiff am Terminal **B** anlegen.

Definiere die Methode `Port.get_terminal`, die ein Symbol als Argument entgegennimmt, nämlich die Kennung des Schiffes.
Die Methode sollte das Terminal als Symbol zurückgeben.

```ruby
Port.get_terminal(:OIL123)
# => :A
```
