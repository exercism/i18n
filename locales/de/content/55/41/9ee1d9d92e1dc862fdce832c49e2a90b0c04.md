# Einführung

## Verschachtelte Typen

C#-Typen kannst du innerhalb des Gültigkeitsbereichs einer Klasse oder eines Structs definieren. Der umschließende Typ fungiert dabei als eine Art Namespace. Auf den Typ greifst du über den umschließenden Typ und die Punktsyntax zu.

```csharp
class Outer
{
    public interface IInner {}
    public enum EInner {}
    public class CInner {}
    public struct SInner {}
}

var outer = new Outer();
var inner = new Outer.CInner();
```

Für innere Typen kannst du Zugriffsebenen festlegen.

Private Member des äußeren Typs sind für Member des inneren Typs im Gültigkeitsbereich, umgekehrt gilt das nicht.
