# Hinweise

## Allgemeines

- `disposable` ist in `destructors`; die Generics des Stream-Protokolls
  sind in `io`; `<string-reader>` (von den Tests verwendet) ist in
  `io.streams.string`.
- Eine Deklaration `TUPLE: x < y ...` lässt `x` die Slots von `y`
  erben. `disposable` fügt ein `disposed`-Flag hinzu und registriert das
  Tupel beim Destruktor-Framework, wenn es über `new-disposable` erzeugt
  wird.

## 1. Definiere das Band

- Der Konstruktor: `tape new-disposable swap >>wire ;`. Das `swap`
  sorgt dafür, dass der Wire unter dem frisch erzeugten Band landet,
  damit `>>wire` ihn verbrauchen kann.

## 2. Binde den input-stream-Mixin ein

- Eine Zeile auf der obersten Ebene, nach der `TUPLE:`-Deklaration.

## 3. Lies ein Morsezeichen

- Am einfachsten ist eine kleine Schleife: Lies ein Byte, prüfe es und
  gib es zurück, wenn es ein Morsezeichen oder `f` ist; andernfalls
  lies das nächste.
- Ein Zeichenliteral schreibt man `CHAR: .`. Das Leerzeichen ist
  `CHAR: \s`.
- `member?` auf einem kleinen Array funktioniert:
  `B{ CHAR: . CHAR: - CHAR: \s } member?`.
- Die einfachste Kontrollstruktur: eine `while`-Schleife, die liest,
  bis sie ein Morsezeichen oder `f` erhält, zusammen mit einem
  abschließenden `dup`, das das Ergebnis an den Aufrufer übergibt.

## 4. Delegiere den Elementtyp

- Eine einzeilige Methode: `wire>> stream-element-type`.

## 5. Aufräumen

- Gleiche Form: `wire>> dispose`.
- Ruf nicht selbst `dispose*` auf, sondern ruf `dispose` auf dem Wire
  auf. Die Aufgabe des Frameworks ist sicherzustellen, dass dein
  `dispose*` nur einmal ausgeführt wird.
