# Arrays

Arrays in PHP sind geordnete Maps.
Eine Map ist eine Datenstruktur, die einen Schlüssel einem Wert zuordnet.
Arrays sind vielseitig und können als lineares Array (wie in `C` oder `Java`), als Liste [Vektor], Hash-Tabelle, Wörterbuch, Sammlung, Stack oder Warteschlange behandelt werden.

Ein Schlüssel ist optional, muss aber, wenn er angegeben wird, entweder ein `int` oder ein `string` sein.
Wenn kein Schlüssel angegeben wird, verwendet PHP standardmäßig ganzzahlige Schlüssel in aufsteigender Reihenfolge, beginnend bei `0`.

```php
$no_keys = ["my", "first", "array"];
$integer_keys = [0 => "my", 1 => "first", 2 => "array"];

$no_keys == $integer_keys // => equal returns true
$no_keys === $integer_keys // => strictly equal returns true
```

Ein Array kann Werte aller Typen speichern.
Jeder Wert kann einen anderen Typ haben.

```php
$my_arr = [
  1,
  "second",
  new \DateTimeImmutable()
];
```

## Arrays verwenden

Arrays können als Literal deklariert werden (im Code geschrieben, wie oben) oder durch Funktionen erstellt und bearbeitet werden.

```php
$my_empty_arr = [];

// or
$my_empty_arr = array(); // => []

// or
$letters = mb_str_split("Hello"); // => ["H", "e", "l", "l", "o"] 
```

Mit dem Index-Operator kannst du auf Werte zugreifen, sie zuweisen oder anhängen:

```php
$prime_numbers = [2, 3, 5, 6];

$prime_numbers[3] = 7; // replace 6 with 7

$prime_numbers[] = 11; // array now contains [2, 3, 5, 7, 11]
```

So iterierst du mit foreach über ein Array:

```php
$names = ["Ani", "Jack", "Rami"]

// Iterate just the values
foreach ($names as $name) {
  echo $name;
}

// Iterate keys and values
foreach ($names as $index => $name) {
  echo "$index => $name";
}
```
