# Über

Mithilfe von GraalVM native-image und dem [Small Clojure Interpreter](https://github.com/borkdude/sci) ist [babashka](https://babashka.org/) eine eigenständige Skriptumgebung, die sofort startet und unter linux, macOS und Windows läuft.

Babashka implementiert eine beträchtliche Teilmenge von Clojure und bringt viele Bibliotheken für gängige Aufgaben mit. Neben den eingebauten Bibliotheken kann babashka Bibliotheken aus dem Quellcode laden und damit auf die Welt der bereits vorhandenen Clojure-Bibliotheken zugreifen.
