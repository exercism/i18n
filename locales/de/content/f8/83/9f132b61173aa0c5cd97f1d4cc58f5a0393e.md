# Einführung

## Beschriftete Argumente

Wenn eine Funktion viele Argumente entgegennimmt, kann es manchmal schwierig sein, sich die Reihenfolge zu merken, in der sie übergeben werden müssen. Um die Lesbarkeit zu verbessern, erlaubt es Gleam, Argumente mit einem Namen zu beschriften.

Um ein Argument zu beschriften, gibst du den Namen der Beschriftung vor dem Argumentnamen an, getrennt durch ein Leerzeichen.

```gleam
pub fn replace(
  in string: String,
  each target: String,
  with replacement: String
) -> String {
  // ...
}
```

Beim Aufruf einer Funktion mit beschrifteten Argumenten kannst du die Argumente in beliebiger Reihenfolge angeben. Die folgenden Aufrufe von `replace` sind alle gleichwertig:

```gleam
replace(in: "🍔🍔🍔", each: "🍔", with: "🍕")

replace(each: "🍔", in: "🍔🍔🍔", with: "🍕")

replace(with: "🍕", each: "🍔", in: "🍔🍔🍔")
```

Beschriftungen sind immer optional. Selbst wenn eine Funktion beschriftete Argumente hat, kannst du sie weiterhin ohne Beschriftungen aufrufen.

```gleam
replace("🍔🍔🍔", "🍔", "🍕")
```
