# SQLite-spezifische Hinweise

* Die Spalte **candidates** enthält eine JSON-kodierte Liste aus Strings.
  Beispiel:
  ```json
  ["stone","tones","banana","tons","notes","Seton"]
  ```
* Die Spalte **result** sollte ebenfalls eine JSON-kodierte Liste aus Strings enthalten.

## Tabellenschema

```sql
CREATE TABLE anagram (
  subject    TEXT NOT NULL,
  candidates TEXT NOT NULL,     -- json array of strings
  result     TEXT               -- json array of strings
);
```
