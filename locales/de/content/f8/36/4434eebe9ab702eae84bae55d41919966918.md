# Anleitung

Als angehende Magierin muss Elyse einige Grundlagen üben. Sie hat
einen Stapel Karten, den sie manipulieren möchte.

Um es etwas einfacher zu machen, verwendet sie nur die Karten 1 bis 10, sodass ihr Kartenstapel durch einen Vektor von Zahlen dargestellt werden kann.
Die Position einer bestimmten Karte entspricht dem Index im Vektor.

## 1. Eine Karte aus einem Stapel holen

Um eine Karte zu ziehen, gib die Karte am Index `position` aus dem gegebenen Stapel zurück.

```R
stack <- c(1, 2, 4, 1)
position <- 3
get_item(stack, position)
# => 4
```

## 2. Eine Karte im Stapel austauschen

Vollführe ein wenig Fingerfertigkeit und tausche die Karte am Index `position` gegen die angegebene Ersatzkarte aus.
Gib den angepassten Stapel zurück.

```R
stack <- c(1, 2, 4, 1)
position <- 3
replacement_card <- 6
set_item(stack, position, replacement_card)
# => c(1, 2, 6, 1)
```

## 3. Eine Karte oben auf den Stapel einfügen

Lass eine Karte erscheinen, indem du oben auf den Stapel eine neue Karte einfügst.
Gib den angepassten Stapel zurück.

```R
stack <- c(5, 9, 7, 1)
new_card <- 8
insert_item_at_top(stack, new_card)
# => c(5, 9, 7, 1, 8)
```

## 4. Eine Karte aus dem Stapel entfernen

Lass eine Karte verschwinden, indem du die Karte an der angegebenen `position` aus dem Stapel entfernst.
Gib den angepassten Stapel zurück.

```R
stack <- c(3, 2, 6, 4, 8)
position <- 3
remove_item(stack, position)
# => c(3, 2, 4, 8)
```

## 5. Die Größe des Stapels prüfen

Prüfe, ob die Größe des Stapels gleich `stack_size` ist oder nicht.

```R
stack <- c(3, 2, 6, 4, 8)
stack_size <- 4
check_size_of_stack(stack, stack_size)
# => FALSE
```

## 6. Die oberste Karte vom Stapel entfernen

Lass eine Karte verschwinden, indem du die oberste Karte vom Stapel entfernst.
Gib den angepassten Stapel zurück.

```R
stack <- c(3, 2, 6, 4, 8)
remove_item_from_top(stack)
# => c(3, 2, 6, 4)
```

## 7. Eine Karte unten an den Stapel anfügen

Lass eine Karte erscheinen, indem du unten am Stapel eine neue Karte einfügst.
Gib den angepassten Stapel zurück.

```R
stack <- c(5, 9, 7, 1)
new_card <- 8
insert_item_at_bottom(stack, new_card)
# => c(8, 5, 9, 7, 1)
```

## 8. Eine Karte unten vom Stapel entfernen

Lass eine Karte verschwinden, indem du die unterste Karte vom Stapel entfernst.
Gib den angepassten Stapel zurück.

```R
stack <- c(8, 5, 9, 7, 1)
remove_item_at_bottom(stack)
# => c(5, 9, 7, 1)
```
