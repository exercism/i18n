# Konzepte von Luhn

Luhn ist ein Validierungsalgorithmus, der textuelle und numerische Prüfungen kombiniert. Rust-Lösungen bevorzugen funktionale Ansätze.

## Allgemeines

### Primitive Datentypen

- `&str` und `char`
  - Du musst den Unterschied zwischen einzelnen `char` und `&str` verstehen, um Teile der gegebenen Eingabe richtig auszuschließen oder einzubeziehen.
- Ganzzahl
  - Ganzzahlen zu verstehen ist wichtig, um die nötige numerische Validierung durchzuführen.
- boolesche Werte
  - wesentlich für Identitätsprüfungen und den abschließenden Vergleich.

### Iterator-Eigenschaften

- Verkettung
  - Hier ist es wichtig, Iterator-Ketten zu verstehen, um das Problem in geordneter Reihenfolge zu lösen.
- `map`, `filter`, Turbofish und möglicherweise `fold`
  - Die Kombination von map und filter ergibt ein grundlegendes Entwurfsmuster für Validierungsprobleme wie dieses. Lösungen mit fold sind außerdem noch kürzer.
  - In manchen Lösungen brauchst du den Turbofish, um Rust zu sagen, welchen Typ du aus einem verketteten Ausdruck erzeugst.

## Beispiellösung 1

yorks [Lösung](https://exercism.org/tracks/rust/exercises/luhn/solutions/7038c269a4af4f5b95ca35a99c5c3b4d)

```rust
pub fn is_valid(code: &str) -> bool {
    code.chars()
        .filter(|c| !c.is_ascii_whitespace())
        .rev()
        .try_fold((0, 0), |(num_count, sum), c| {
            c.to_digit(10).map(|x| {
                let double = x * (num_count % 2 + 1);
                let double = if double > 9 { double - 9 } else { double };
                (num_count + 1, sum + double)
            })
        })
        .map_or(false, |(num_count, sum)| num_count >= 2 && sum % 10 == 0)
}
```

## Beispiellösung 2

Kanonisch

```rust
pub fn is_valid(candidate: &str) -> bool {
    if candidate.chars().filter(|c| c.is_ascii_digit()).take(2).count() <= 1
        || candidate.chars().any(|c| !c.is_ascii_digit() && c != ' ')
    {
        return false;
    }

    candidate
        .chars()
        .filter_map(|c| c.to_digit(10))
        .rev()
        .enumerate()
        .map(|(index, digit)| if index % 2 == 0 { digit } else { digit * 2 })
        .map(|digit| if digit > 9 { digit - 9 } else { digit })
        .sum::<u32>()
        % 10
        == 0
}
```
