# Einführung

JavaScript ist eine dynamische Sprache, die objektorientierte, imperative und deklarative Stile (z. B. funktionale Programmierung) unterstützt.

## Variablen

In JavaScript gibt es einige grundlegende Wege, Namen Werte zuzuweisen: mit Variablen oder Konstanten.
Bei Exercism werden Variablen immer in [camelCase][wiki-camel-case] geschrieben, Konstanten in [SCREAMING_SNAKE_CASE][wiki-snake-case].
Es gibt keinen offiziellen Leitfaden, an den du dich halten musst, und verschiedene Unternehmen und Organisationen haben unterschiedliche Styleguides.
_Schreib Variablen ruhig so, wie du möchtest_.
Der Vorteil, wenn du sie so schreibst, wie es die Übungen vorgeben, ist, dass sie in der Web-Oberfläche und in den meisten IDEs anders hervorgehoben werden.

Variablen in JavaScript können mit dem Schlüsselwort [`const`][mdn-const], [`let`][mdn-let] oder [`var`][mdn-var] definiert werden.

Wenn du `let` oder `var` verwendest, kann eine Variable im Laufe ihres Lebens auf verschiedene Werte verweisen.
Zum Beispiel kann `myFirstVariable` mit dem Zuweisungsoperator `=` viele Male definiert und neu definiert werden:

```javascript
let myFirstVariable = 1;
myFirstVariable = 'Some string';
myFirstVariable = new SomeComplexClass();
```

Im Gegensatz zu `let` und `var` können Variablen, die mit `const` definiert werden, nur einmal zugewiesen werden.
So werden in JavaScript Konstanten definiert.

```javascript
const MY_FIRST_CONSTANT = 10;

// Can not be re-assigned.
MY_FIRST_CONSTANT = 20;
// => TypeError: Assignment to constant variable.
```

## Funktionsdeklarationen

In JavaScript werden Einheiten von Funktionalität in _Funktionen_ gekapselt, wobei Funktionen, die zusammengehören, meist in derselben Datei zusammengefasst werden.
Diese Funktionen haben Parameter (und können daher Argumente entgegennehmen) und können mit dem Schlüsselwort `return` einen Wert _zurückgeben_.
Funktionen werden mit der Syntax `()` aufgerufen.

```javascript
function add(num1, num2) {
  return num1 + num2;
}

add(1, 3);
// => 4
```

In diesem Beispiel heißt die Funktion `add`.
Sie hat zwei Parameter, `num1` und `num2`.
Sie gibt einen Wert zurück: das Ergebnis des Ausdrucks `num1 + num2`.

Dann wird die Funktion `add` mit zwei Argumenten _aufgerufen_: `1` und `3`.
Das Ergebnis der Funktion, also der Rückgabewert, ist `4`.

Einige dieser anderen Möglichkeiten sehen anders aus als die Verwendung des Schlüsselworts `function`.
Der Track versucht, sie nach und nach einzuführen, aber wenn du sie schon kennst, kannst du jede davon verwenden.

## Für andere Dateien verfügbar machen

Um eine `function`, eine Konstante oder eine Variable in _anderen Dateien_ verfügbar zu machen, müssen sie mit dem Schlüsselwort `export` [exportiert][mdn-export] werden.
Eine andere Datei kann diese dann mit dem Schlüsselwort `import` [importieren][mdn-import].
Das nennt man auch das Modulsystem.

Ein gutes Beispiel dafür ist, wie alle Tests funktionieren.
Jede Übung hat mindestens eine Datei, zum Beispiel `lasagna.js`, die die _Implementierung_ enthält.
Die _Implementierung_ wird mit `export` aus der Datei exportiert und steht damit in einer anderen Datei zum Import zur Verfügung.
Außerdem gibt es mindestens eine weitere Datei, zum Beispiel `lasagna.spec.js`, die die _Tests_ enthält.
Diese Datei importiert die öffentlichen (also die mit `export` freigegebenen) Einheiten, um die Implementierung zu testen:

```javascript
// file.js
export const MY_VALUE = 10;

export function add(num1, num2) {
  return num1 + num2;
}

// file.spec.js
import { MY_VALUE, add } from './file';

add(MY_VALUE, 5);
// => 15
```
