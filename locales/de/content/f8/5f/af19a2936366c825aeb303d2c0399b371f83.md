# Anleitung

Deine Freundin Li Mei betreibt einen Saftladen, in dem sie köstliche gemischte Fruchtsäfte verkauft.
Du bist ein häufiger Gast in ihrem Laden und hast gemerkt, dass du deiner Freundin das Leben leichter machen könntest.
Du beschließt, deine Programmierkenntnisse einzusetzen, um Li Mei bei ihrer Arbeit zu helfen.

## 1. Ermittle, wie lange die Zubereitung eines Safts dauert

Li Mei sagt ihren Kunden gerne vorab, wie lange sie auf einen Saft von der Karte warten müssen, den sie bestellt haben.
Es fällt ihr schwer, sich die genauen Zeiten zu merken, weil die Zubereitung der Säfte unterschiedlich lange dauert:

| ID  | Getränk             | Zeit |
| --- | ------------------- | ---- |
| 1   | Reiner Erdbeergenuss| 1    |
| 2   | Energiespender      | 3    |
| 3   | Grüner Garten       | 3    |
| 4   | Tropeninsel         | 4    |
| 5   | Alles oder nichts   | 5    |
| 6   | Gutes Gefühl        | 4    |
| 7   | Tagesangebot        | 7    |
| 8   | Wahl des Kunden     | 10   |

Schreibe eine Funktion `time_to_make_juice`, die eine ID für einen Saft als 32-Bit-Zahl entgegennimmt und die Zeit zurückgibt, die die Zubereitung des Safts dauert, ebenfalls als 32-Bit-Zahl.

```c
time_to_make_juice(2);
// => 3
```

## 2. Ermittle, wie lange die Zubereitung aller bestellten Säfte dauert

Li Mei muss ihre Vorräte regelmäßig auffüllen und muss daher im Voraus wissen, wie viel Zeit sie braucht, um alle aktuell vorliegenden Bestellungen zuzubereiten.

Um deiner Freundin zu helfen, schreibe eine Funktion `time_to_prepare`, die ein Array mit den IDs der bestellten Säfte und die Anzahl der Säfte im Array entgegennimmt.
Diese Funktion soll die Gesamtzeit zurückgeben, die die Zubereitung aller Getränke im Array dauert.

Du kannst davon ausgehen, dass jede ID, die Anzahl der IDs im Array und der Rückgabewert 32-Bit-Zahlen sind.
Das Ergebnis passt immer in eine 32-Bit-Zahl.

```c
time_to_prepare({2, 3, 8}, 3);
// => 16
```

## 3. Fülle den Vorrat an Limettenstücken auf

Viele von Li Meis Kreationen enthalten Limettenstücke, sei es als Zutat oder als Teil der Dekoration.
Wenn sie morgens ihre Schicht beginnt, muss sie deshalb dafür sorgen, dass der Behälter mit Limettenstücken für den bevorstehenden Tag gut gefüllt ist.

Implementiere die Funktion `limes_to_cut`, die die Anzahl der Limettenstücke, die Li Mei schneiden muss, ein Array mit dem Vorrat an ganzen Limetten, die sie zur Hand hat, und die Anzahl der Limetten im Array entgegennimmt.

Jede Limette wird im Array durch ein Zeichen für ihre Größe dargestellt.
Verschiedene Limettengrößen liefern Li Mei unterschiedlich viele Stücke:

| Größe | Stücke |
| ----- | ------ |
| 'S'   | 6      |
| 'M'   | 8      |
| 'L'   | 10     |

~~~~exercism/note
Ein Zeichen ist eine 8-Bit-Zahl, die genauso verwendet werden kann wie jede andere 8-Bit-Zahl:

| Zeichen | Wert |
|---------|------|
| 'S'     | 83   |
| 'M'     | 77   |
| 'L'     | 76   |

Es kann auch direkt in Anweisungen verwendet werden, wo es seinem Wert entspricht:

```x86asm
mov dl, 'S'
cmp cl, 'M'
```
~~~~

Li Mei schneidet die Limetten immer in der Reihenfolge, in der sie im Array erscheinen, beginnend mit dem ersten Element.
Sie macht so lange weiter, bis sie die benötigte Anzahl an Stücken erreicht hat oder bis ihr die Limetten ausgehen.

Li Mei möchte im Voraus wissen, wie viele Limetten sie schneiden muss.

Du kannst davon ausgehen, dass die benötigte Anzahl an Stücken, die Anzahl der Limetten im Array und der Rückgabewert 32-Bit-Zahlen sind.
Das Ergebnis passt immer in eine 32-Bit-Zahl.

```c
limes_to_cut(25, {'S', 'S', 'L', 'M', 'S'}, 5);
// => 4
```

## 4. Beende die Schicht

Li Mei arbeitet immer bis 15 Uhr.
Dann übernimmt ihr Mitarbeiter Dmitry.
Oft sind Getränke bestellt, aber noch nicht zubereitet, wenn Li Meis Schicht endet.
Dmitry bereitet dann die restlichen Säfte zu.

Um die Übergabe zu erleichtern, implementiere eine Funktion `remaining_orders`, die Folgendes entgegennimmt:

- Die Anzahl der Minuten, die in Li Meis Schicht noch verbleiben.
- Ein Array mit den IDs aller Säfte, die bestellt, aber noch nicht zubereitet wurden.

Die Funktion soll die Anzahl der Bestellungen zurückgeben, die Li Mei vor dem Ende ihres Arbeitstags zubereitet hat.

Die verbleibende Zeit der Schicht ist immer größer als 0.
Das Array der zuzubereitenden Säfte ist nie leer, und die Schicht endet immer, bevor das Ende des Arrays erreicht ist.
Außerdem werden die Bestellungen in der Reihenfolge zubereitet, in der sie im Array erscheinen.
Wenn Li Mei anfängt, einen bestimmten Saft zu mixen, macht sie ihn immer fertig, auch wenn sie etwas länger arbeiten muss.

Du kannst davon ausgehen, dass die verbleibende Anzahl an Minuten, jede ID im Array und der Rückgabewert 32-Bit-Zahlen sind.
Das Ergebnis passt immer in eine 32-Bit-Zahl.

```c
remaining_orders(5, {5, 5, 3});
// => 1
```
