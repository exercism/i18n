# Einführung

## Variablen und Zuweisung

R ist eine dynamisch typisierte Sprache, daher musst du im Allgemeinen den Typ einer Variablen nicht angeben. Der bevorzugte Zuweisungsoperator ist `<-`

```R
x <- 42
avogadro <- 6.02e23
mystr <- "Hello, World!"
```

`=` statt `<-` zu verwenden, funktioniert oft, aber nicht immer, und gilt als schlechter Stil.
Wenn du in RStudio arbeitest, kannst du es mit dem Tastenkürzel `Alt-minus` eingeben.

Die Operatoren sind größtenteils konventionell, aber achte auf `%/%` und `%%`:

```R
2 + 3   # 5
2 - 3   # -1
2 * 3   # 6
2 / 3   # 0.6666667
8 %/% 3 # 2 (integer division)
8 %% 3  # 2 (remainder)
2 ^ 3   # 8 (exponential)
```

In R beginnt `#` einen einzeiligen Kommentar.
Für mehrzeilige Kommentare gibt es keine eigene Syntax.

## Funktionen

So definierst du eine Funktion:

```R
squareit <- function(x) {
    x * x
}
```

Funktionen können null oder mehr Argumente haben, die durch Kommas getrennt werden.
Die runden Klammern `()` sind bei `function()` nötig, auch wenn es keine Parameter gibt.

Für Funktionsargumente kannst du Standardwerte festlegen, allerdings müssen diese nach allen Argumenten ohne Standardwert stehen, und du weist den Standardwert mit `=` zu, nicht mit `<-`.
Ein ziemlich sinnloses Beispiel:

```R
squareit <- function(x = 42) {
    x * x
}

squareit()
#> [1] 1764
```

Die geschweiften Klammern `{ }` sind für einzeilige Funktionsblöcke nicht unbedingt nötig, aber sie mitzuschreiben gilt als guter Stil.

R gibt automatisch den letzten Wert einer Funktion zurück, wie in den Beispielen oben.

Mit `return()` kannst du überall im Funktionsblock einen Rückgabewert ausdrücklich angeben.

Eine Funktion aufzurufen funktioniert genauso wie in vielen anderen Sprachen:

```R
squareit(3)
#> [1] 9
```
