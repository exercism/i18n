# Installation

## Installiere .NET 10

Der Visual-Basic-Track verwendet .NET 10.
Um die Übungen lokal zu bauen und zu testen, installiere [das .NET 10 SDK für dein Betriebssystem][install-sdk]:
Installiere das SDK, nicht nur die Runtime.

## Überprüfe deine Installation

Öffne ein neues Terminal und führe Folgendes aus:

```bash
dotnet --version
```

Der Befehl sollte `10.0.0` oder höher ausgeben.

## Editor-Unterstützung

Das .NET SDK und ein schlichter Texteditor sind alles, was du brauchst, um die Übungen zu lösen.
Für weiterführende Funktionen wie Codevervollständigung und Debugging schau dir einen dieser Editoren an:

- [Visual Studio 2026][visual-studio] unter Windows
- [Visual Studio Code][visual-studio-code] unter Windows, Linux oder macOS
- [JetBrains Rider][rider] unter Windows, Linux oder macOS
