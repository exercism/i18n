# Überblick

Du kannst [Enumerationstypen][enumeration types] immer dann verwenden, wenn du eine feste Menge konstanter Werte hast. Ein `enum` bietet dir einen typsicheren Umgang mit konstanten Werten. Ein Enum definierst du mit dem Schlüsselwort `enum`. Auf ein Enum-Element verweist du, indem du den Enum-Namen und einen Punkt voranstellst (z. B. `Status.Active`).

Jedes Enum-Element verbindet einen Namen mit einem `int`-Wert. Wenn das erste Element keinen expliziten Wert hat, wird sein Wert auf `0` gesetzt. Wenn für ein Enum-Element kein Wert explizit angegeben wird, bekommt es automatisch den Wert des vorherigen Elements plus `1`.

```csharp
enum Season
{
    Spring,     // Auto set 0
    Summer = 2, // Set the value 2
    Autumn,     // Auto set 3
    Winter = 7  // Set the value 7
}
```

Enums sind sehr deklarativ. Vergleiche die folgenden beiden Methodenaufrufe:

```csharp
Users.WithStatus(1)
Users.WithStatus(Status.Active)
```

Für jemanden, der den Code liest, ist die zweite Version (mit Enum) leichter zu verstehen.

## Enums mit numerischem Typ

Der numerische Standardtyp der Werte ist `int`, aber du kannst ihn ändern, indem du einen anderen [integralen numerischen Typ][integral numeric] angibst.

Das folgende Enum verwendet den numerischen Typ `byte` für seine Werte:

```csharp
enum Priority : byte
{
    Low = 0,
    Medium = 127,
    High = 255
}
```

## In ein Enum-Element umwandeln

Du solltest immer ein Enum in Betracht ziehen, wenn du etwas wie einen booleschen Wert abbilden willst. Neben den genannten Vorteilen bei der Lesbarkeit haben Enums noch einen weiteren Vorteil gegenüber booleschen Werten: Einem Enum kannst du jederzeit neue Werte hinzufügen, ein boolescher Wert ist dagegen immer nur `true` oder `false`. Die Verwendung eines Enums ist also zukunftssicherer.

```csharp
enum Status
{
    Inactive = 0,
    Active = 1
}

Status active = (Status) 1;
active == Status.Active; // True
```

Beachte: Du _kannst_ Ganzzahlwerte zwar in ein Enum umwandeln, das kann aber zu unerwarteten Ergebnissen führen, wenn der Ganzzahlwert keinem Enum-Wert entspricht:

```csharp
Status status = (Status) 2;
status == Status.Inactive; // False
status == Status.Active;   // False
```

## Ein Enum parsen

Manchmal ist es nützlich, einen String anhand seines Namens mit [`Enum.Parse`][enum parse] in ein Enum-Element umzuwandeln:

```csharp
var input = "Inactive";
Status status = (Status)Enum.Parse(typeof(Status), input);
// Inactive
```

Um zu prüfen, ob ein Name oder ein Wert im Enum existiert, kannst du [`Enum.TryParse`][enum tryparse] oder [`Enum.IsDefined`][enum isdefined] verwenden. Beide geben einen booleschen Wert zurück, der angibt, ob das Enum-Element existiert:

```csharp
bool doesExist = Enum.IsDefined(typeof(Status), "Inexistent");
// False
```
