# Zusätzliche Anweisungen

## Register

| Register | Verwendung    | Typ     | Beschreibung                                  |
| -------- | ------------- | ------- | --------------------------------------------- |
| `$a0`    | Eingabe       | Ganzzahl | natürliche Zahl, die faktorisiert werden soll |
| `$a1`    | Eingabe/Ausgabe | Adresse | Ziel-Array für die Primfaktoren               |
| `$v0`    | Ausgabe       | Ganzzahl | Anzahl der Faktoren                           |
| `$t0-9`  | temporär      | beliebig | für die temporäre Speicherung verwendet       |
