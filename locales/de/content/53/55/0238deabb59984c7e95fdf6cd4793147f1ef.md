# Modulo

Modulo-Vergleiche sind in Crystal völlig in Ordnung, aber um den Rest einer Division zu vergleichen, ist die [`divisible_by?`][divisible_by]-Methode besser lesbar. Oder noch besser: Wenn du prüfen willst, ob eine Zahl ungerade oder gerade ist, verwendest du die Methoden [`odd?`][odd?] und [`even?`][even?].

Zum Beispiel:

```crystal
# Rather than:
number %% 2 == 0

# Consider:
number.even?
```
