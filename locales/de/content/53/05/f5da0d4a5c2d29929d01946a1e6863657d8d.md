# Tests

Um deine Lösung zu testen, führe einfach Folgendes aus:

```bash
make test
```

Damit wird die Testdatei `<exercise-name>-test.ys` ausgeführt, die alle Tests enthält, die deine Lösung bestehen muss, damit sie korrekt ist.
Du solltest die Testdatei studieren, um genau zu verstehen, was deine Lösung tun muss.

> Hinweis: Wenn du `make test` zum ersten Mal ausführst, wird dabei auch sichergestellt, dass die richtige Version des `ys`-YAMLScript-Interpreters am richtigen Ort installiert ist.

Wenn du `make test` ausführst, bevor du irgendeine Datei geändert hast, schlagen alle Tests fehl.
Das ist das richtige und erwartete Verhalten.
Beim normalen Entwickeln einer Übung verbesserst du deine Lösung Schritt für Schritt und führst nach jeder Änderung `make test` aus, bis alle Tests bestehen.

Wenn du nur einen bestimmten Test ausführen möchtest (weil du dich auf diesen Teil der Lösung konzentrierst), kannst du dieses Schlüssel-Wert-Paar zu diesem Test hinzufügen:

```yaml
  ONLY: true
```

Wenn du bestimmte Tests überspringen möchtest (weil du an anderen Teilen der Lösung arbeitest), kannst du dieses Schlüssel-Wert-Paar zu diesen Tests hinzufügen:

```yaml
  SKIP: true
```


## Voraussetzungen für die Tests

YAMLScript läuft derzeit auf MacOS und Linux.

Auf deinem Computer müssen die folgenden, sehr verbreiteten Befehle installiert sein:

* `bash` – Du kannst die Tests in jeder Shell ausführen, aber `bash` muss verfügbar sein.
* `make` – Du musst GNU `make` verwenden, um die Tests auszuführen.
  In manchen Umgebungen heißt es vielleicht anders als `make`.
  Möglicherweise `gmake`.
* `prove` – Dieses Programm ist Teil jeder normalen Perl-Installation.
* `curl` – Wird verwendet, um ys zu installieren, falls es noch nicht installiert ist.

Es ist sehr wahrscheinlich, dass du alle diese Programme bereits installiert hast.
