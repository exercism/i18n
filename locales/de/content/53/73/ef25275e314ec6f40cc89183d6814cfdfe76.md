# Über

Wenn du eine Sequenz durchgehst, reicht manchmal das Element allein nicht aus: Du brauchst auch die Position. Die *indexierten* Iterationswörter von Factor geben der Quotation pro Element beides, wobei der Index oben auf dem Stack liegt. `times` ist das verwandte Wort für gezählte Iterationen ohne eine zugrunde liegende Sequenz.

```factor
USING: io kernel math.parser sequences ;

! map-index: build a new sequence; quot sees ( elt index )
{ "alice" "bob" "carol" }
[ number>string ": " glue ] map-index .
! => { "alice: 0" "bob: 1" "carol: 2" }

! each-index: for side effect; quot sees ( elt index )
{ "alice" "bob" } [
    number>string ": " glue print
] each-index
! prints alice: 0
! prints bob: 1

! times: run a quotation N times
3 [ "tick " print ] times
```

| Wort         | Effekt                                                               |
|--------------|----------------------------------------------------------------------|
| `each-index` | `( seq quot: ( elt index -- ) -- )`                                  |
| `map-index`  | `( seq quot: ( elt index -- newelt ) -- newseq )`                    |
| `times`      | `( n quot: ( -- ) -- )`, aber siehe unten                            |

Eine Feinheit bei `times`: Obwohl seine Quotation als `( -- )` dokumentiert ist, ist das Wort `inline`, sodass eine effektbalancierte Quotation wie `( str -- str )` problemlos funktioniert und den Stack über die Iterationen hinweg weiterreicht. So bekommst du einen gezählten Akkumulator ganz ohne veränderlichen Zustand:

```factor
USING: kernel sequences ;

"" 3 [ "clop " append ] times .    ! => "clop clop clop "
```

Derselbe Trick funktioniert auch für `each-index` und `map-index`: Der angegebene Effekt pro Element ist ein *Minimum*, kein Maximum.
