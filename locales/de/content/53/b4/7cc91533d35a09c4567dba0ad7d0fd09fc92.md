# Ranges

[Ranges][range] repräsentieren ein Intervall zwischen zwei Werten.
Die häufigsten Typen, die Ranges unterstützen, sind `Integer` und `String`.
Du kannst sie für vieles nutzen: schnell eine Sammlung erzeugen, Strings zerteilen, prüfen, ob ein Wert in einem Range liegt, oder iterieren.
Erzeugt werden sie mit dem Range-Operator `..` oder `...` (einschließlich bzw. ausschließlich).

```ruby
1..5  # => 1..5
1...5 # => 1...5

(1..5).to_a # => [1, 2, 3, 4, 5]
(1...5).to_a # => [1, 2, 3, 4]
```

Der Grund für zwei Range-Operatoren ist, dass du damit Ranges erstellen kannst, die den Endwert einschließen oder ausschließen. Das ist zum Beispiel bei nullbasierten Indizes nützlich.

Ranges lassen sich auch mit dem `Range`-Initialisierer erzeugen.

```ruby
Range.new(1, 5) # A range containing 1, 2, 3, 4, 5
```

~~~~exercism/note
Wenn du in Ruby mit den Range-Operatoren `..` oder `...` einen Range erstellst und darauf eine Methode aufrufen willst, musst du den Range in runde Klammern setzen.
Sonst wird die Methode nämlich auf dem zweiten Argument des Range-Operators aufgerufen.

```ruby
(1..5).sum # => 15
1..5.sum # => Error: undefined method `sum' for 5:Integer (NoMethodError)
```
~~~~

## Teilstrings extrahieren

Wenn du einen String zerteilen willst, kannst du mit dem Range-Operator einen Teilstring holen.
Dazu erstellst du einen Range mit dem Start- und dem Endindex des Teilstrings.

```ruby
"Hello World"[0..4] # => "Hello"
"Hello World"[6..10] # => "World"
```

Du kannst auch negative Indizes verwenden, um den Teilstring vom Ende des Strings zu holen.

```ruby
"Hello World"[-5..-1] # => "World"
"Hello World"[6..-4] # => "Wo"
```

## Range-Methoden

Ranges haben eine Reihe von Methoden, mit denen du arbeiten kannst.
Diese Methoden kannst du zum Beispiel verwenden, um die Summe aller Werte im Range zu bilden oder um zu prüfen, ob der Range einen Wert enthält.

| Methode                 | Beschreibung                                                             | Beispiel                        |
| ----------------------- | ----------------------------------------------------------------------- | ------------------------------- |
| [`sum`][sum]            | Gibt die Summe aller Werte im Range zurück                               | `(1..5).sum # => 15`            |
| [`size`][size]          | Gibt die Größe des Ranges zurück                                         | `(1..5).size # => 5`            |
| [`include?`][indlude]   | Gibt `true` zurück, wenn der Range den angegebenen Wert enthält, sonst `false` | `(1..5).include?(3) # => true` |

## Endlose und anfangslose Ranges

Ein Range kann endlos und anfangslos sein.
Bei einem endlosen oder anfangslosen Range ist der Start- oder der Endwert `nil`, aber beim Definieren des Ranges kannst du das `nil` weglassen.

Anfangslose und endlose Ranges sind nützlich, wenn du zum Beispiel einen String vom Anfang oder bis zum Ende zerteilen willst.

```ruby
"Hello World"[0..] # => "Hello World"
"Hello World"[4..] # => "o World"
"Hello World"[..5] # => "Hello"
```

~~~~exercism/caution
Wenn du einen endlosen Range nicht auf einer Sammlung verwendest, kann er eine endlose Sequenz verursachen, sofern du nicht aufpasst.
~~~~

## String-Ranges

Strings kannst du ebenfalls in Ranges verwenden, und so bekommst du ein Intervall von Strings zwischen zwei Strings.
Das Verhalten kann bei bestimmten Strings etwas unerwartet sein, also sei vorsichtig.

```ruby
"aa".."az".to_a # => ["aa", "ab", "ac", ..., "az"]
```
