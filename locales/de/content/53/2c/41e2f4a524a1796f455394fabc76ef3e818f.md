# Strings

Strings sind eine Folge von Zeichen, die von Anführungszeichen umschlossen werden.
Sowohl einfache als auch doppelte Anführungszeichen werden unterstützt.

```php
<?php

$where = "Spain";
$what = 'rain';
```

## Variablen in Strings einsetzen

In Strings mit doppelten Anführungszeichen wird der Wert einer Variable, die im Gültigkeitsbereich liegt, in den String eingesetzt.

```php
<?php

$answer = 42;
$expanded = "The answer to life, the universe, and everything is $answer"; 
```

## Unterstützung für Zeichenkodierungen

Historisch gesehen unterstützten die String-Funktionen in PHP nur ASCII-Zeichen und keine modernen Unicode-Kodierungen.
Ein ASCII-Zeichen ist jeweils 1 Byte lang, ein Unicode-Zeichen kann dagegen 1 bis 4 Byte lang sein.
Wenn du Unicode-Strings sicher bearbeiten musst, schau dir die [Multibyte-Versionen][multi-byte-fns] der historischen Funktionen an.

```php
<?php

$byte_length = strlen('😃'); // => 4
$string_length = mb_strlen('😃'); // => 1
```

[multi-byte-fns]: https://www.php.net/manual/en/ref.mbstring.php
