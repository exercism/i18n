# Tests

Um die Tests auszuführen, führe den Befehl `sbt test` im Verzeichnis der Übung aus.
Weitere Informationen findest du auf der [Tests-Seite](https://exercism.org/docs/tracks/scala/tests).

## Übersprungene Tests

Anfangs ist nur der erste Test aktiviert.
Das soll dich ermutigen, die Übung Schritt für Schritt zu lösen.
Sobald der erste Test läuft, entferne das Schlüsselwort `pending` am Anfang des nächsten Tests und arbeite daran, auch diesen Test zum Laufen zu bringen.
