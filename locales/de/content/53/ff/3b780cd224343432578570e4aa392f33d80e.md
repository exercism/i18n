# Über

Wie die meisten Programmiersprachen hat Gleam „Seiteneffekte“: Funktionen können den Zustand der Welt lesen und verändern und außerdem einen Wert zurückgeben.

Das Modul `gleam/io` in der Gleam-Standardbibliothek bietet Funktionen zum Ausgeben von Strings auf der Konsole.

```gleam
io.println("Hello, Joe!")
// Hello, Joe!
// -> Nil
```

Andere Pakete können andere IO-Funktionen bereitstellen, etwa `simplifile`, ein Paket, das Funktionen zum Lesen und Schreiben von Dateien bietet.

```gleam
simplifile.read("favourite-colour.txt")
// -> Ok("Pink\n")
```
