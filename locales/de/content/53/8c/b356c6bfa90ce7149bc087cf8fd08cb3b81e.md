# Installation

## Clojure CLI installieren

Clojure bietet Kommandozeilen-Tools für: das Ausführen einer interaktiven REPL (Read-Eval-Print Loop), das Ausführen von Clojure-Programmen und das Auswerten von Clojure-Ausdrücken.
Wir empfehlen dir, für die Übungen die Clojure CLI zu verwenden. So installierst du die [Clojure CLI](https://clojure.org/guides/deps_and_cli):

### Windows
Die Installationsanleitung für Windows findest du hier: [Clojure CLI Installation](https://clojure.org/guides/getting_started#_installation_on_windows).

### Linux
Die Installationsanleitung für die meisten Plattformen findest du hier: [Clojure CLI Installation](https://clojure.org/guides/getting_started#_installation_on_linux).

### Homebrew für Mac OS X
Aktualisiere dein Homebrew:

``` bash
$ brew update
```

Installiere die Clojure CLI:
``` bash
$ brew install node clojure/tools/clojure
```

`Node` wird für die Node-Umgebung benötigt.

## Die Installation testen

Um zu prüfen, ob die Installation funktioniert hat, führe `clojure --help` aus. Wenn alles geklappt hat, wird dir die Version angezeigt.

```bash
$ clojure --help
Version: 1.10.1.547
...
```
