# Über

Ein Template ist ein String oder eine Datei, mit denen du abhängig von der Eingabe jede Art von String-Ausgabe erzeugen kannst.

```haxe
var sample = "My name is ::name::";
var template = new haxe.Template(sample);
var myName = {name: "Joe"};
var output = template.execute(myName);

trace(output); // My name is Joe
```

Unter anderem kannst du in Templates auch Bedingungen verwenden, um etwas zu prüfen:

```haxe
var sample = "::if isAwake:: I'm awake ::else:: Zzzzz ::end::";
var template = new haxe.Template(sample);
var awake = {isAwake: false};
var output = template.execute(awake);

trace(output); // Zzzzz
```
