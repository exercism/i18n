# Ergänzung der Anweisungen

## Trackspezifische Hinweise

In der Übung „Yacht" erstellst du ein Verb, das die Punktzahl für einen einzelnen Wurf mit fünf Würfeln im Spiel Yacht berechnet, basierend auf der gewählten Kategorie.

Für diese Übung erhält dein Verb zwei Argumente:

- **Linkes Argument**: Ein String, der die Wertungskategorie angibt, die auf den Würfelwurf angewendet wird.
- **Rechtes Argument**: Eine Liste von Ganzzahlen, die die fünf gewürfelten Würfel darstellen.

Dein Verb sollte so definiert werden, dass es diese Eingaben wie folgt verarbeitet:

```j
  category =. 'Full House'
  dice     =. 1 3 3 3 5
  
  category scoreYacht dice
```
