# Anleitung

In dieser Übung implementierst du einige Funktionen, um eine Liste von Programmiersprachen zu bearbeiten.

## 1. Definiere eine Funktion, die eine leere Liste von Programmiersprachen zurückgibt

Definiere die Funktion `new`, die keine Argumente entgegennimmt und eine leere Liste zurückgibt.

```haskell
new
-- -> []
```

## 2. Definiere eine Funktion, die eine Programmiersprache zur Liste hinzufügt

Definiere die Funktion `add/2`, die 2 Argumente entgegennimmt (eine _Liste von Programmiersprachen_ und ein String-Literal einer _Programmiersprache_).
Sie sollte die resultierende Liste zurückgeben, wobei die neue Programmiersprache an den Anfang der übergebenen Liste gesetzt wird.

```haskell
add new "Clojure"
-- -> ["Clojure"]
add ["Clojure"] "Haskell"
-- -> ["Haskell", "Clojure"]
```

## 3. Definiere eine Funktion, die eine Programmiersprache aus der Liste entfernt

Definiere die Funktion `remove`, die 1 Argument entgegennimmt (eine _Liste von Programmiersprachen_).
Sie sollte die Liste ohne das erste Element zurückgeben. Geh davon aus, dass die Liste immer mindestens ein Element enthält.

```haskell
remove ["Haskell", "Clojure", "Erlang"]
-- -> ["Clojure", "Erlang"]
```

## 4. Definiere eine Funktion, die das erste Element der Liste zurückgibt

Definiere die Funktion `first`, die 1 Argument entgegennimmt (eine _Liste von Programmiersprachen_).
Sie sollte die erste Programmiersprache in der Liste zurückgeben.
Geh davon aus, dass die Liste immer mindestens ein Element enthält.

```haskell
first ["Elixir", "Haskell", "Clojure", "Prolog"]
-- -> "Elixir"
```

## 5. Definiere eine Funktion, die zurückgibt, wie viele Programmiersprachen in der Liste sind

Definiere die Funktion `count`, die 1 Argument entgegennimmt (eine _Liste von Programmiersprachen_).
Sie sollte die Anzahl der Programmiersprachen in der Liste zurückgeben.

```haskell
count ["Prolog", "Elm"]
-- -> 2
```

## 6. Definiere eine Funktion, die feststellt, ob die Liste eine funktionale Programmiersprache enthält

Definiere die Funktion `isFunctionalList`, die 1 Argument entgegennimmt (eine _Liste von Programmiersprachen_).
Sie sollte einen booleschen Wert zurückgeben.
Sie sollte `True` zurückgeben, wenn _„Haskell“_ eine der Programmiersprachen in der Liste ist.

```haskell
isFunctionalList ["Haskell"]
-- -> True
```
