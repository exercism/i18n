# Einführung

## Objektorientierte Programmierung in Python

Wenn du bisher [funktional][functional], [deklarativ][declarative] oder [imperativ][imperative] programmiert hast, kann es dir etwas fremd vorkommen, den Fokus auf die [objektorientierte Programmierung][oop] (OOP) zu verlagern.
Ein OOP-Ansatz verlangt, dass du ein Problem als ein oder mehrere `objects` modellierst, die miteinander interagieren, einen Zustand speichern und auf Daten einwirken.
Objekte können Entitäten aus der realen Welt darstellen (_etwa Autos oder Katzen_) oder abstraktere Konzepte (_etwa Ganzzahlen, Fahrzeuge oder Säugetiere_).
Jedes Objekt wird zu einer eindeutigen Instanz im Arbeitsspeicher des Computers und repräsentiert einen Teil des Gesamtmodells.

## Klassen

`Classes` sind die Definitionen neuer Objekttypen, aus denen neue `instances` von Objekten erzeugt werden.
Sie bündeln oft Daten mit Code oder Funktionen, die auf diesen Daten arbeiten.
In diesem Sinne sind Klassen _Baupläne_ oder Sammlungen von Anweisungen, aus denen viele Objekte eines ähnlichen Typs gebaut und verwendet werden können.
Ein komplexes Programm kann viele Klassen haben, von denen jede viele verschiedene Varianten von Objekten erzeugt.
Der Prozess, ein Objekt aus einer Klasse zu bauen, heißt `instantiation` (_oder: eine Instanz der Klasse erzeugen_).

Eine Klassendefinition in Python ist unkompliziert:

```python
class MyClass:
    # Class body goes here
```

### Klassenattribute

Klassenfelder (_auch bekannt als `properties`, `attributes`, `data members` oder `variables`_) kannst du dem Klassenkörper hinzufügen:

```python
class MyClass:
    number = 5
    string = "Hello!"
```

Eine Instanz (_ein Objekt_) von `MyClass` kannst du erzeugen und an einen Namen binden, indem du die Klasse [_aufrufst_][calling] (_genauso, wie du eine Funktion aufrufst_):

```python
>>> new_object = MyClass()

# Class is instantiated and resulting object is bound to the "new_object" name.
# Note: the object address 'at 0x15adc55b0' will vary by computer.
>>> new_object
<__main__.MyClass at 0x15adc55b0>
```

`Class attributes` werden von allen Objekten (_oder Instanzen_) geteilt, die aus einer Klasse erzeugt werden. Du kannst über [`dot notation`][dot notation] auf sie zugreifen. Dabei steht ein `.` nach dem Objektnamen und vor dem Attributnamen:

```python
>>> new_object = MyClass()

# Accessing the class attribute "number" via dot-notation.
>>> new_object.number
5

# Accessing the class attribute "string" via dot-notation.
>>> new_object.string
'Hello!'

# Instantiating an additional object and binding it to the "second_new_object" name.
>>> second_new_object = MyClass()

>>> second_new_object
# Note: the object address "at 0x15ad99970" will vary by computer.
<__main__.MyClass at 0x15ad99970>

# Second_new_object shares the same class attributes as new_object.
>>> new_object.number == second_new_object.number
True
```

Klassenattribute werden im Klassenkörper selbst definiert, noch vor allen anderen Methoden.
Sie gehören der Klasse, wodurch sie von allen Instanzen der Klasse geteilt werden können.
Weil diese Attribute geteilt werden, kannst du ihren Wert _direkt_ über die Klasse abrufen und ändern.
Wenn du den Wert von Klassenattributen änderst, änderst du den Wert _**für alle Objekte, die aus der Klasse erzeugt wurden**_:

```python
>>> obj_one = MyClass()
>>> obj_two = MyClass()

# Accessing a class attribute from an object.
>>> obj_two.number
5

# Accessing the class attribute from the class itself.
>>> MyClass.number
5

# Modifying the value of the "number" class attribute.
>>> MyClass.number = 27

# Modifying the "number" class attribute changes the "number" attribute for all objects.
>>> obj_one.number
27

>>> obj_two.number
27
```

Eine Menge Objekte zu haben, deren Daten ständig synchron sind, ist nicht besonders nützlich.
Zum Glück kannst du Objekte, die aus einer Klasse erzeugt werden, mit eigenen `instance attributes` (_oder Instanzeigenschaften, -variablen oder -feldern_) anpassen.
Wie der Name schon sagt, sind Instanzattribute für jedes Objekt einzigartig und können unabhängig voneinander geändert werden.


## Objektinstanziierung mit `__init__()` anpassen

Die spezielle [„Dunder-Methode"][dunder] (_kurz für „double underscore method"_) `__init__()` dient dazu, Klasseninstanzen anzupassen, und du kannst damit Instanzattribute oder -eigenschaften für Objekte initialisieren.
Wegen ihrer Rolle beim Initialisieren von Instanzattributen wird `__init__()` auch als `class constructor` oder `initializer` bezeichnet.
`__init__()` nimmt einen erforderlichen Parameter namens `self`, der auf das gerade initialisierte oder erzeugte Objekt verweist.
Daten für Instanzattribute oder -eigenschaften kannst du dann als Argumente von `__init__()` übergeben, und zwar nach dem `self`-Parameter.

Unten hat `MyClass` nun Instanzattribute namens `location_x` und `location_y`.
Wie du siehst, wurden die beiden Attribute dem ersten und zweiten Index des `location`-Arguments (_eines Tupels_) zugewiesen, das an `__init__()` übergeben wurde.
Die Attribute `location_x` und `location_y` einer Klasseninstanz werden nun initialisiert, wenn du die Klasse instanziierst und so ein Objekt erzeugst:

```python
class MyClass:
    # These are class attributes, variables, or fields.
    number = 5
    string = "Hello!"

    # This is the class "constructor", with a "location" parameter that is a tuple.
    def __init__(self, location):

        # This is an instance or object property, attribute, or variable.
        # Note that we are unpacking the tuple argument into two separate instance variables.
        self.location_x = location[0]
        self.location_y = location[1]

# Create a new object "new_object_one", with object property (1, 2).
>>> new_object_one = MyClass((1, 2))

# Create a second new object "new_object_two" with object property (-8, -9).
>>> new_object_two = MyClass((-8, -9))

# Note that new_object_one.location_x and new_object_two.location_x two different values.
>>> new_object_one.location_x
1

>>> new_object_two.location_x
-8
```

Beachte, dass du beim Initialisieren von `MyClass` oben nur ein Argument übergeben musst. Python kümmert sich darum, `self` zu übergeben, wenn die Klasse aufgerufen wird.


## Methoden

Eine `method` ist eine `function`, die entweder an die Klasse selbst gebunden ist (_bekannt als [Klassenmethode][class method], dazu kommen wir in einer späteren Übung_) oder an eine _Instanz_ der Klasse (ein Objekt).
Methoden, die auf einem Objekt (einer Instanz) arbeiten, müssen mit `self` als erstem Parameter definiert werden.
Die übrigen Parameter kannst du dann genauso definieren wie bei einer „normalen" oder nicht gebundenen Funktion:

```python
class MyClass:
    number = 5
    string = "Hello!"

    # Class constructor.
    def __init__(self, location):
        # Instance properties
        self.location_x = location[0]
        self.location_y = location[1]

    # Instance method. Note "self" as first parameter.
    def change_location(self, amount):
        self.location_x += amount
        self.location_y += amount
        return self.location_x, self.location_y
```

Wie beim Zugriff auf Attribute musst du zum Aufrufen einer Methode einfach einen `.` nach dem Objektnamen und vor dem Methodennamen setzen.
Die aufgerufene Methode braucht keine Kopie des Objekts als ersten Parameter. Python setzt `self` automatisch ein:

```python
class MyClass:
    number = 5
    string = "Hello!"

    def __init__(self, location):
        self.location_x = location[0]
        self.location_y = location[1]

    def change_location(self, amount):
        self.location_x += amount
        self.location_y += amount
        return self.location_x, self.location_y

# Make a new test_object with location (3,7)
>>> test_object = MyClass((3,7))
>>> (test_object.location_x, test_object.location_y)
(3,7)

# Call change_location to increase location_x and location_y by 7.
>>> test_object.change_location(7)
(10, 14)
```

Auf Klassenattribute kannst du aus Instanzmethoden genauso zugreifen wie von außerhalb der Klasse:

```python
class MyClass:
    number = 5
    string = "Hello!"

    def __init__(self, location):
        self.location_x = location[0]
        self.location_y = location[1]

    # Alter instance variable location_x and location_y
    def change_location(self, amount):
        self.location_x += amount
        self.location_y += amount
        return self.location_x, self.location_y

    # Alter class variable number for all instances from within an instance.
    def increment_number(self):
        # Increment the 'number' class variable by 1.
        MyClass.number += 1


>>> test_object_one = MyClass((0,0))
>>> test_object_one.number
5

>>> test_object_two = MyClass((13, -3))
>>> test_object_two.increment_number()
>>> test_object_one.number
6
```

## Implementierung mit `pass` als Platzhalter oder Stub

In früheren Konzeptübungen und in den Stubs von Übungen hast du gesehen, dass das Schlüsselwort `pass` im Körper von Funktionen anstelle von echtem Code verwendet wird.
Das Schlüsselwort `pass` ist ein syntaktisch gültiger Platzhalter. Es verhindert, dass Python bei einer leeren Funktions- oder Klassendefinition einen Syntaxfehler auslöst.
Im Grunde ist es eine Art, dem Python-Interpreter zu sagen: „Keine Sorge! Ich _werde_ hier irgendwann Code einfügen, ich habe es nur noch nicht getan."

```python
class MyClass:
    number = 5
    string = "Hello!"

    def __init__(self, location):
        self.location_x = location[0]
        self.location_y = location[1]

    # Alter instance variable location_x and location_y
    def change_location(self, amount):
        self.location_x += amount
        self.location_y += amount
        return  self.location_x, self.location_y

    # Alter class variable number for all instances
    def increment_number(self):
        # Increment the 'number' class variable by 1.
        MyClass.number += 1

    # This will compile and run without error, but has no current functionality.
    def pending_functionality(self):
       # Stubbing or placholding the body of this method.
       pass
```
