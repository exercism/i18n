# Einführung

## Variablen

Zur Erinnerung: Ein `jq`-Programm ist eine _Pipeline aus Ausdrücken_.
**Variablenzuweisung** folgt dieser Regel: Eine _Variablenzuweisung_ ist ein Ausdruck, der so aussieht:

```jq
... | expr as $varname | ...
```

### Der Filter gibt die Eingabe aus

Wie beim _Identitätsausdruck_ `.` ist die Ausgabe der _Variablenzuweisung_ dieselbe wie ihre Eingabe.
Das Setzen des Variablenwerts ist ein Seiteneffekt.

Ein Beispiel, das zeigt, dass `.` nach der Zuweisung dieselbe Eingabe ist wie die ursprüngliche:

```sh
$ jq -c -n '42 | (. * 2) as $double | [., $double]'
[42,84]
```

### Gültigkeitsbereich von Variablen

Der Gültigkeitsbereich der Variable ist „lexikalisch“: Die Variable bleibt für den Rest der Pipeline im Gültigkeitsbereich.
Variablen, die in Funktionen definiert werden (zu Funktionen kommen wir später), sind „lokal“ für die Funktion.

### Variablennamen

Die Variable muss mit `$` beginnen.
Der Rest des Variablennamens ist ein **Bezeichner**: Er beginnt mit einem Buchstaben oder Unterstrich, gefolgt von Buchstaben, Zahlen oder Unterstrichen.

### Destrukturierende Zuweisung

Aus dem Handbuch:

> Mehrere Variablen lassen sich mit einem einzigen `as`-Ausdruck deklarieren, indem du ein Muster angibst, das _zur Struktur der Eingabe passt_ (das nennt man „Destrukturierung“).

Beispiele:

```jq
[1, 2, 3] as [$a, $b, $c]
| [$a, $b, $c]     # => [1, 2, 3]
```

```jq
{"foo": "bar", "len": [10, 20]} as {foo: $f, len: [$h, $w]}
| [$f, $h, $w]     # => ["bar", 10, 20]
```

Wenn der Variablenname zum _Objektschlüssel_ passt, bietet das eine Abkürzung:

```jq
{"x": 4, "y": 7} as {$x, $y}
| [$x, $y]         # => [4, 7]
```

```jq
{"foo": "bar", "len": [10, 20]} as {$foo, $len}
| [$foo, $len]     # => ["bar", [10, 20]]
```

### Konstanten

Wie das obige Beispiel zeigt, sind Variablen praktisch, um Konstanten zu speichern.
Es ist besser, Konstanten einen Namen zu geben, als „magische Zahlen“ im Code auftauchen zu lassen.

### Oft sind Variablen nicht nötig

Oft ist es lesbarer, auf Variablen zu verzichten.

Betrachte das Berechnen des Durchschnitts einer Liste von Zahlen

```jq
[2, 4, 8, 7]
| add as $sum
| length as $len
| $sum / $len
```

verglichen mit

```jq
[2, 4, 8, 7] | add / length
```

Das zeigt einen der stärksten Aspekte von `jq`: Die Eingabe eines Filters steht _jedem_ Teilausdruck zur Verfügung:

- das Eingabe-Array `[2,4,8,7]` wird an `add` übergeben (das die Zahlen summiert, indem es den `+`-Operator auf alle Elemente anwendet)
- _parallel dazu_ wird `[2,4,8,7]` auch an `length` übergeben
- wenn diese Teilausdrücke fertig sind, werden ihre Ergebnisse dividiert und ergeben den Durchschnitt der Zahlen im Eingabe-Array.

### `jq`-Operatoren, die du für die Lernübung brauchst

#### Alternativ-Operator: `//`

Der Ausdruck `a // b` gibt `b` aus, wenn `a` falsch oder null ist, andernfalls gibt er `a` aus.
Im Zusammenhang mit dem Setzen einer Variable ist das sehr praktisch, um einen Standardwert anzugeben:

```jq
(.input.theAnswer // 42) as $answer | ...
```

#### Arithmetische Operatoren

- `+`, `-`, `*` sind die üblichen Operatoren für numerische Addition, Subtraktion und Multiplikation.
