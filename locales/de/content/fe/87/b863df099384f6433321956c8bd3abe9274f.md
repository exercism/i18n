# Hinweise

## 1. Gib ein Badge für einen Mitarbeiter aus

- Um die Strings in Base R zu konstruieren, ist die Funktion [`sprintf`][ref-sprintf] nützlich.
- Für einen Tidyverse-Ansatz kannst du [`str_glue`][ref-str_glue] aus der `stringr`-Bibliothek verwenden.

## 2. Gib ein Badge für einen neuen Mitarbeiter aus

- Verzweige mit [`is.na`][ref-isna].

## 3. Gib ein Badge für den Besitzer aus

- Verzweige mit [`is.null`][ref-isnull].

## 4. Berechne das Gesamtgehalt der Mitarbeiter ohne ID

- Du kannst nach [`is.na`][ref-isna] [filtern][concept-vector-filtering] und dann [`sum`][ref-sum] verwenden.
- Was ergibt `salaries[is.na(ids)]`, wenn es keine Mitarbeiter ohne ID gibt? Es lohnt sich, das in einer R-Konsole zu überprüfen. Wenn R nicht auf deinem Computer installiert ist, können dir Online-Konsolen wie [rdrr.io][web-rdrr] helfen.
