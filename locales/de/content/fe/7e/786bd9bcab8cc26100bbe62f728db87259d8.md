# Anleitung

In dieser Übung implementierst du eine Möglichkeit, die Höchstpunktzahlen für das beliebteste Spiel in deiner örtlichen Spielhalle zu verwalten.

Du musst 6 Funktionen implementieren, die sich größtenteils mit der Manipulation eines Objekts befassen, das die Höchstpunktzahlen enthält.

## 1. Erstelle eine neue Bestenliste

Schreibe eine Funktion `create_score_board`, die ein Objekt erstellt, das als Bestenliste dient.
Die Schlüssel dieses Objekts sind die Namen der Spieler, die Werte ihre Punktzahlen.
Zu Testzwecken möchtest du direkt einen Eintrag in das Objekt aufnehmen.
Dieser anfängliche Eintrag sollte aus `"The Best Ever"` als Spielername und `1000000` als Punktzahl bestehen.

```jq
create_score_board
# returns an object with one initial entry
```

## 2. Füge Spieler zu einer Bestenliste hinzu

Um einen Spieler zur Bestenliste hinzuzufügen, implementiere die Funktion `add_player`.
Sie nimmt eine Bestenliste als Eingabe und benötigt zwei Parameter: den Spielernamen und die Punktzahl des Spielers.
Die Funktion gibt das Bestenlisten-Objekt mit dem neu hinzugefügten Spieler zurück.

```jq
{"José Valim", 486373}
| add_player("Dave Thomas"; 0)
# => {"Dave Thomas": 0, "José Valim": 486373} -- in some order
```

Wenn der Spieler bereits auf der Liste steht, gib die Liste unverändert zurück.

## 3. Entferne Spieler aus einer Bestenliste

Wenn Spieler gegen die Regeln der Spielhalle verstoßen, werden sie manuell aus der Bestenliste entfernt.
Implementiere `remove_player`, die eine Bestenliste als Eingabe und einen Parameter nimmt: den Namen des Spielers, der entfernt werden soll.
Diese Funktion soll den Eintrag für den angegebenen Spieler aus der Liste entfernen und die neue Liste zurückgeben.
Wenn der Spieler gar nicht auf der Liste stand, soll mit der Liste nichts passieren; sie soll unverändert zurückgegeben werden.

```q
{"Dave Thomas": 0} | remove_player("Dave Thomas")
# => {}

{"Dave Thomas": 0} | remove_player("Rose Fanaras")
# => {"Dave Thomas": 0}
```

## 4. Erhöhe die Punktzahl eines Spielers

Wenn ein Spieler ein weiteres Spiel in der Spielhalle beendet, wird eine bestimmte Anzahl von Punkten zur bisherigen Punktzahl auf der Liste addiert.
Implementiere `update_score`, die eine Bestenliste als Eingabe nimmt und zwei Parameter benötigt: den Spielernamen und die Anzahl der hinzuzufügenden Punkte.
Die Funktion soll die Bestenliste nach dem Update zurückgeben.

```jq
{"Freyja Ćirić": 12771000} | update_score("Freyja Ćirić"; 73)
# => {"Freyja Ćirić": 12771073}
```

Diese Funktion soll den Spieler zur Liste hinzufügen, wenn er noch nicht darauf stand.

## 5. Wende die Montags-Bonuspunkte an

Die Spielhalle führt montags eine separate Bestenliste.
Am Ende des Tages erhält jeder Spieler auf dieser Liste 100 zusätzliche Punkte.

Implementiere die Funktion `apply_monday_bonus`.
Die Funktion addiert die Bonuspunkte für jeden Spieler, der auf dieser Liste steht.

```jq
{
  "Dave Thomas": 44,
  "Freyja Ćirić": 539,
  "José Valim": 265
}
| apply_monday_bonus
# => {"Dave Thomas": 144, "Freyja Ćirić": 639, "José Valim": 365}
```

## 6. Ermittle die Gesamtpunktzahl

Verschiedene Spielhallen treten gegeneinander an, um zu ermitteln, wer die besten Spieler hat.
Die Spielhalle mit der höchsten Gesamtpunktzahl gewinnt die Ehre.

Schreibe eine Funktion `total_score`.
Sie nimmt eine Bestenliste als Eingabe und gibt die Summe aller Punktzahlen der Spieler zurück.

```jq
{
  "Dave Thomas": 44,
  "Freyja Ćirić": 539,
  "José Valim": 265
}
| total_score
# => 848
```
