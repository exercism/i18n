# Hinweise

## 1. Eine Übersetzung abrufen und dabei die Qualität ignorieren

- Promises lassen sich verketten, zum Beispiel mit `.then`.
- Promises reichen jeden Wert weiter.
  Das heißt: Wenn ein Promise aufgelöst wird, reicht es diesen Wert weiter, bis er das Ende der Kette oder ein `.then` erreicht, das den Wert als Argument erhält.
- Promises reichen jeden Fehler weiter.
  Das heißt: Wenn ein Promise abgelehnt wird, reicht es diese Ablehnung weiter, bis sie das Ende der Kette oder ein `.catch` erreicht, das den Wert als Argument erhält und ihn behandeln kann.

## 2. Einen Stapel Übersetzungen abrufen, alles oder nichts

- Um ein Promise mit einem Fehler zurückzugeben, erstelle ein `Promise`, das von Anfang an `rejected` ist.
- Auf `Promise` gibt es eine Hilfsmethode, die wartet, bis ein Array von Promises aufgelöst ist, und sich dann selbst auflöst.

## 3. Eine Übersetzung anfordern und höchstens 2-mal erneut versuchen

- Wandle den `callback` mit dem `new Promise`-Konstruktor in ein Promise um.

## 4. Eine Übersetzung abrufen, die Qualität prüfen oder sie anfordern

- Statt `.then` und/oder `.catch` zu verschachteln, nimmt `.then` ein zweites Argument entgegen, das alles _davor_ (früher in der Kette) abfängt und Fehler im ersten Argument von `.then` ignoriert.
