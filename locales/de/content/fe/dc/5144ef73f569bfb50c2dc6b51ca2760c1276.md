# Einführung

Lua verwendet zwei Darstellungen für Zahlen: 64-Bit-Ganzzahlen und Gleitkommazahlen mit doppelter Genauigkeit. Es unterstützt die üblichen arithmetischen Operatoren: Addition, Subtraktion, Multiplikation, Division und Negation. Außerdem gibt es die Ganzzahldivision, den Modulo und die Potenzierung.

| Operator | Beispiel            |
| -------- | ------------------- |
| `+`      | `1 + 2 --> 3`       |
| `-`      | `2 - 1 --> 1`       |
| `*`      | `2 * 2 --> 4`       |
| `/`      | `4 / 2 --> 2.0`     |
| `//`     | `11 // 3 --> 3`     |
| `%`      | `11 % 3 --> 2`      |
| `^`      | `10 ^ 2 --> 100.0`  |
| `-`      | `-(2 * 2) --> -4`   |
