# Hinweise

## Allgemein

- Das [Python-Tutorial][the python tutorial] kann ein großartiger Einstieg sein.
- [PEP 8][pep8] ist der Leitfaden für den Programmierstil in Python.
- [PEP 257][PEP257] beschreibt die Konventionen für Python-Docstrings.
- [Zahlen][numbers] in Python können Ganzzahlen, Gleitkommazahlen oder komplexe Zahlen sein.


## 1. Definiere die erwartete Backzeit in Minuten

- Zuerst musst du eine [Konstante][constants] [benennen][naming] und ihr einen Wert vom Typ [Ganzzahl][numbers] [zuweisen][assignment].
  Diese Konstante sollte das Erste nach dem Docstring sein, der am Anfang der Datei steht.
  Denk daran, den #TODO-Kommentar zu entfernen, nachdem du die Konstante definiert hast.

## 2. Berechne die verbleibende Backzeit in Minuten

- Definiere eine [Funktion][defining functions] mit einem einzelnen Parameter, der die bisher vergangene Zeit darstellt.
- Verwende den [mathematischen Operator für Subtraktion][numbers], um Werte zu subtrahieren.
- Diese Funktion sollte [einen Wert zurückgeben][return].

## 3. Berechne die Zubereitungszeit in Minuten

- Definiere eine [Funktion][defining functions] mit einem einzelnen Parameter, der die Anzahl der Schichten darstellt.
- Verwende den [mathematischen Operator für Multiplikation][numbers], um Werte zu multiplizieren.
- Du kannst eine _Konstante_ PREPARATION_TIME für die Zeit in Minuten pro Schicht definieren, statt eine [„magische
  Zahl“][magic-numbers] in deinem Code zu verwenden.
- Diese Funktion sollte [einen Wert zurückgeben][return].

## 4. Berechne die gesamte verstrichene Kochzeit (Zubereitung + Backen) in Minuten

- Definiere eine [Funktion][defining functions] mit zwei Parametern.
- Denk daran, dass du eine Funktion, die du zuvor definiert hast, jederzeit _aufrufen_ kannst.
- Mit dem [mathematischen Operator für Addition][python as a calculator] kannst du Werte summieren.
- Diese Funktion sollte [einen Wert zurückgeben][return].

## 5. Aktualisiere das Rezept mit Notizen

- Es ist immer empfehlenswert, deinen Code klar zu [kommentieren][comments] und gemäß [PEP257][pep257] zu [dokumentieren][docstrings].
- Einige Beispiele für Docstrings im Google-Stil findest du in der Sphinx-Dokumentation für das [Napoleon-Modul][napoleon].
