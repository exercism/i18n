# Über

Eine *regulärer Ausdruck* (Regex) ist ein kleines Muster, das die Form eines Textes beschreibt. Die Regex-Tools von Factor findest du im Vokabular [`regexp`][regexp], und ein Muster schreibst du als Literal zwischen `R/ ` und `/`.

Die meisten Zeichen in einem Muster stimmen mit sich selbst überein. Die Ausdrucksstärke kommt von Zeichenklassen und Quantifizierern:

```
\d        ! a digit 0–9            \s   ! whitespace
\D        ! any non-digit          \S   ! non-whitespace
[A-Z]     ! one capital letter     .    ! any one character
[^0-9]    ! any char except a digit

{4}       ! exactly 4              +    ! one or more
{2,5}     ! between 2 and 5        *    ! zero or more
?         ! optional               |    ! either side (alternation)
```

`R/ [A-Z]{2}-\d{4}/` passt also auf „zwei Großbuchstaben, einen Bindestrich, vier Ziffern“.

## Abgleich des ganzen Strings vs. Suche

`matches?` ist nur erfolgreich, wenn der *ganze* String auf das Muster passt. Die anderen Wörter suchen *innerhalb* eines Strings:

```
matches?             ( string regexp -- ? )
re-contains?         ( string regexp -- ? )
count-matches        ( string regexp -- n )
all-matching-subseqs ( string regexp -- seq )
first-match          ( string regexp -- slice/f )
re-split             ( string regexp -- seq )
re-replace           ( string regexp replacement -- result )
```

```factor
USING: regexp ;

"NS-1024" R/ [A-Z]{2}-\d{4}/ matches? .         ! => t
"id NS-1024 ok" R/ [A-Z]{2}-\d{4}/ matches? .   ! => f   (extra text)
"id NS-1024 ok" R/ [A-Z]{2}-\d{4}/ re-contains? .   ! => t

"a1b2c3" R/ \d/ count-matches .   ! => 3
"a1b2c3" R/ \d/ re-replace .      ! NOTE: see re-replace below
```

## Slices

`first-match` und `re-split` geben `slice`-Objekte zurück. Das sind leichtgewichtige Sichten auf den ursprünglichen String, keine neuen Strings. Wandle einen Slice mit `>string` um, wenn du einen eigenständigen String brauchst, zum Beispiel um ihn mit einem String-Literal zu vergleichen. `all-matching-subseqs` gibt bereits Strings zurück.

## Ersetzen

`re-replace` ersetzt jede Übereinstimmung durch einen Ersatz-String und gibt das Ergebnis zurück:

```factor
USING: regexp ;

"user=alice pass=hunter2" R/ pass=\S+/ "pass=****" re-replace .
! => "user=alice pass=****"
```

## Ein Muster zur Laufzeit erstellen

`R/ /` wird beim Laden der Datei geparst. Um ein Muster aus einem String zu bauen, der zur Laufzeit berechnet wird, nutze `<regexp>`:

```
<regexp> ( string -- regexp )
```

[regexp]: https://docs.factorcode.org/content/vocab-regexp.html
