# Installation

Cairo lässt sich ganz einfach installieren, indem du Scarb herunterlädst. Scarb bündelt den Cairo-Compiler und den Cairo-Sprachserver in einem leicht zu installierenden Paket, sodass du sofort mit dem Schreiben von Cairo-Code loslegen kannst. Scarb ist außerdem der Paketmanager von Cairo.

Um die empfohlenen Installationsanweisungen für dein Betriebssystem zu erhalten, geh auf [die offizielle Cairo-Website](https://www.cairo-lang.org/tutorials/getting-started-with-cairo/).

Nach Betriebssystem:

- Linux/MacOS
    1. Installiere [asdf](https://asdf-vm.com/guide/getting-started.html)
    2. Installiere [scarb](https://docs.swmansion.com/scarb/download#install-via-asdf)
    3. Überprüfe die Installation in einer neuen Terminal-Sitzung mit `scarb --version`
- Windows
    1. Installiere [scarb](https://docs.swmansion.com/scarb/download#windows)
    2. Überprüfe die Installation in einer neuen Terminal-Sitzung mit `scarb --version`

Die Toolchain installiert zu haben, ist nicht alles! IDE-Unterstützung ist ein enormer Produktivitätsschub, den die meisten Entwickler inzwischen erwarten.
Wenn du Visual Studio Code verwendest, empfehlen wir dir, die [Cairo-Erweiterung](https://marketplace.visualstudio.com/items?itemName=starkware.cairo1) zu installieren, die Syntaxhervorhebung, Codevervollständigung und andere nützliche Funktionen bietet!
