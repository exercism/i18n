# Über

Eine `List` ist einem [`Array`][array] sehr ähnlich. Es gibt jedoch wichtige Unterschiede, die du nicht überspringen solltest:

1. Eine Liste kann nicht mit eckigen Klammern indiziert werden, also `[0]`.
2. Eine Liste kann nicht initialisiert werden.
3. Es gibt keine List Comprehensions.
4. Eine Liste kann Elemente frei ändern, während du über sie iterierst.

`List` ist ein Mitglied des Pakets `haxe.ds`. Wenn du Listen verwenden möchtest, musst du also das Paket importieren:

```haxe
import haxe.ds.List;

class Main {
  static function main() {
    var myList = List<Int>();

    for (i in 0...5) {
      myList.add(i);
    }

    trace(myList); // {0, 1, 2, 3, 4}
  }
}
```

[array]: https://haxe.org/manual/std-Array.html
