# Einführung

In Haxe ist ein abstrakter Typ ein Typ, der zur Laufzeit ein anderer Typ ist. Er ist ein Feature zur Compile-Zeit, das Typen „über“ konkrete Typen definiert, um deren Verhalten zu ändern oder zu erweitern:

```haxe
abstract AbstractInt(Int) {
    inline public function new(i:Int) {
        this = i;
    }
}
```

Hier deklarieren wir den Typ `AbstractInt` mit dem Schlüsselwort `abstract`. Seine Syntax ist der von `class` sehr ähnlich. Und genau wie Klassen können abstrakte Typen Methoden haben. Man kann sie auch instanziieren und genau wie Klassen verwenden:

```haxe
class Main {
    static public function main() {
        var a = new AbstractInt(12);
        trace(a); // 12
    }
}
```
