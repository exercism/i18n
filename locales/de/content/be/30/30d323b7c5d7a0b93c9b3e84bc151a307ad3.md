# Überblick

**Union-Typ-Deklarationen** sind ab `PHP 8.0.0` verfügbar und akzeptieren Werte mehrerer verschiedener Typen anstelle eines einzelnen Typs. Union-Typ-Definitionen werden mit dem Pipe-Zeichen (`|`) erstellt, um Typen zu trennen.

```php
function add(int|float $a, int|float $b): int|float
{
    return $a + $b;
}
```

## Nuancen

- Du kannst `null`-Typen als _nullable_ deklarieren, indem du entweder `?Type` oder `Type1|Type2|null` verwendest.
- Wenn du doppelte oder redundante Typen deklarierst, führt das zu einem Compile-Time-Fehler.
- Du kannst `void` nicht als Teil einer Union-Typ-Deklaration verwenden.
