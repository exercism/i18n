# String-Interpolation verwenden

Verwende die [String-Interpolation](https://docs.scala-lang.org/overviews/core/string-interpolation.html), um einen String dynamisch aufzubauen, statt Strings zu verketten oder `StringBuilder` zu verwenden.

Der größte Vorteil ist, dass Code mit String-Interpolation in der Regel leichter zu lesen ist als String-Verkettung oder `StringBuilder`.
