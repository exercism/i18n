# https://www.php.net/manual/en/language.basic-syntax.phptags.php"Bereichsauflösungsoperator

Mit dem Bereichsauflösungsoperator (`::`) kannst du auf eine Klasse verweisen, um auf ihre Namenskonstanten, statischen Eigenschaften oder statischen Methoden zuzugreifen.

```php
class MyClass
{
  public const MY_VALUE = 1;
}

// MyClass::class => "MyClass"
// MyClass::MY_VALUE => 1
```

## `self` und `static` mit dem Bereichsauflösungsoperator verwenden

Manchmal muss ein Objekt auf seinen eigenen Gültigkeitsbereich verweisen. Damit das möglich ist, gibt es das Schlüsselwort `self`, mit dem eine Klasse auf ihren eigenen Gültigkeitsbereich verweisen kann. Wenn du `self` verwendest, löst du die Klasse von ihrem eigenen Namen, was den Code mit der Zeit leichter zu pflegen macht.

```php
class MyClass
{
  public const MY_VALUE = 1;

  public function getMyValue(): int
  {
    return self::MY_VALUE;
  }
}

// (new MyClass)->getMyValue() => 1
```

Allerdings ist `self` lexikografisch an die Klasse gebunden, in der es steht.

```php
class MyOtherClass extends MyClass
{
  public const MY_VALUE = 99;
}

// (new MyOtherClass)->getMyValue() => 1
```

Der Aufruf `MyOtherClass::getMyValue` ergibt trotzdem `1` und nicht `99`. Um das zu umgehen, kannst du das Schlüsselwort `static` zusammen mit dem Bereichsauflösungsoperator verwenden. Damit wird die Referenz erst spät gebunden, nämlich an die aktuelle abgeleitete Klasse.

```php
// Update MyClass:
class MyClass
{
  public const MY_VALUE = 1;

  public function getMyValue(): int
  {
    return static::MY_VALUE;
  }
}
```

## `parent` mit dem Bereichsauflösungsoperator verwenden

Manchmal musst du gezielt auf eine Konstante, eine Eigenschaft oder eine Methode aus dem Gültigkeitsbereich der Elternklasse verweisen:

```php
class MyClass
{
  public function getMaximum(): int
  {
    return 5;
  }
}

class AnotherClass extends MyClass
{
  public function getMaximum(): int
  {
    return parent::getMaximum() * 2;
  }
}

// (new AnotherClass())->getMaximum() => 10
```

In der objektorientierten Programmierung wird `parent` am häufigsten verwendet, um den Konstruktor der Elternklasse aufzurufen, wenn ein Objekt erzeugt wird:

```php
class ChildClass extends ParentClass
{
  public function __construct(): void
  {
    parent::__construct();
  }
}
```

## Zu beachten

### Sichtbarkeit von Konstanten, Eigenschaften und Methoden

Der Bereichsauflösungsoperator hält sich weiterhin an die Regeln, die die Sichtbarkeitsmodifizierer `public`, `private` und `protected` vorgeben.
