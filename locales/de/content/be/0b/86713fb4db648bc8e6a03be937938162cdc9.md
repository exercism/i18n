# Einführung

In Go wiederholt `for range` einen Block Code für Werte aus einem Range-Ausdruck.
Der Range-Ausdruck bestimmt, ob jede Iteration einen oder zwei Werte liefert.

## Range-Ausdrücke

### Range über ein Slice

`range` über ein Slice liefert den Index und den Wert jedes Elements in der Reihenfolge:

```go
vals := []int{10, 20, 30}
for i, v := range vals {
    fmt.Println(i, v)
}
// 0 10
// 1 20
// 2 30
```

### Range über eine Map

`range` über eine Map liefert jeden Schlüssel und jeden Wert, aber die Reihenfolge der Iteration ist nicht garantiert.
Go randomisiert die Iterationsreihenfolge von Maps absichtlich, sodass dasselbe Programm bei jedem Lauf eine andere Ausgabe erzeugen kann.

```go
hash := map[int]int{9: 10, 99: 20, 999: 30}
for k, v := range hash {
    fmt.Println(k, v)
}
// 99 20
// 999 30
// 9 10
```

### Range über einen String

`range` über einen String liefert den Byte-Index und jede Rune (Unicode-Codepunkt).
Im folgenden Beispiel belegt `子` drei Bytes, also beginnt `猫` beim Byte-Index `3`, nicht bei `1`.

```go
for i, r := range "子猫" {
    fmt.Println(i, r, string(r))
}
// 0 23376 子
// 3 29483 猫
```

Wenn du stattdessen Rune-Indizes brauchst, wandle den String in ein Slice von Runen um:

```go
for i, r := range []rune("子猫") {
    fmt.Println(i, r, string(r))
}
// 0 23376 子
// 1 29483 猫
```

### Range über eine Ganzzahl

`range` kann direkt über eine Ganzzahl iterieren und liefert Werte von `0` bis ausschließlich dieser Ganzzahl.
Null und negative Werte sind gültig, erzeugen aber keine Iterationen.

```go
for n := range 3 {
    fmt.Println(n)
}
// 0
// 1
// 2
```

### Range über einen Iterator

`range` akzeptiert einen Iterator vom Typ `iter.Seq[V]` oder `iter.Seq2[K, V]`.
Ein Iterator ist eine Funktion, die eine Folge von Werten nacheinander erzeugt.
`range` kann diese Werte dann durchlaufen.

```go
text := "The quick brown fox"
for word := range strings.FieldsSeq(text) {
    fmt.Println(word)
}
// The
// quick
// brown
// fox

names := []string{"Alice", "Bob", "Vera"}
for i, v := range slices.All(names) {
    fmt.Println(i, ":", v)
}
// 0 : Alice
// 1 : Bob
// 2 : Vera
```

### Range über einen Channel

Schließlich kann `range` Werte empfangen, die über einen Channel gesendet werden, bis dieser Channel an anderer Stelle geschlossen wird.
Channels werden später im Lehrplan des Tracks ausführlicher behandelt.

## Index oder Wert weglassen

Go lässt sich nicht kompilieren, wenn eine Variable deklariert, aber nie verwendet wird.

```go
vals := []int{10, 20, 30}
for i, v := range vals {
    fmt.Println(v)
}
// Go build failed: declared and not used: i
```

Wenn du nur den Wert brauchst, weise den Index oder den Schlüssel `_` zu, um ihn zu ignorieren.

```go
vals := []int{10, 20, 30}
for _, v := range vals {
    fmt.Println(v)
}
// 10
// 20
// 30
```

Wenn du nur den Index brauchst, lass ihn ganz weg:

```go
vals := []int{10, 20, 30}
for i := range vals {
    fmt.Println(i)
}
// 0
// 1
// 2
```

Wenn weder der Index noch der Wert gebraucht wird, kannst du beide weglassen:

```go
vals := []int{10, 20, 30}
count := 0
for range vals {
    count++
}
// count == 3
```
