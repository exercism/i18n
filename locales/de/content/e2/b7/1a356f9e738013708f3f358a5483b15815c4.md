# Hinweise

## Allgemeines

- Slices in Go sind nullbasiert.
  Der erste Index in einem Slice ist `0`.
- Die eingebaute Funktion [`append`][append-builtin] ist [`variadic`][variadic-gobyexample]
- Du kannst die Elemente eines Slices an ein anderes Slice anhängen, indem du die Drei-Punkte-Notation verwendest:

```go
a := []int{1, 3}
b := []int{4, 2, 6}
c := append(a, b...)
fmt.Println(c)
// Output: [1 3 4 2 6]
```

## 1. Ein Slice mit bestimmten Karten erstellen

- Um ein Slice mit vorbefüllten Daten zu erstellen, verwende die Slice-Literal-Notation: `s := []T{x1, x2, ..., xn}`.

## 2. Eine Karte aus einem Stapel entnehmen

- Um das `n`-te Element eines Slices zu erhalten, [verwende einen Index][go-slices].
- Um zu prüfen, ob ein Element in einem Slice existiert, verwende eine Bedingung und vergleiche den Index mit der [Länge des Slices][len-builtin].

## 3. Eine Karte im Stapel austauschen

- Um das `n`-te Element in einem Slice zu setzen, [verwende einen Index][go-slices] und weise ihm einen neuen Wert zu.
- Um ein neues Element am Ende eines Slices hinzuzufügen, verwende die Funktion `append`.

## 4. Karten oben auf den Stapel legen

- Du kannst Elemente am Anfang eines Slices hinzufügen, indem du die Elemente des ursprünglichen Slices an das Slice des Arguments `value` anhängst.

## 5. Eine Karte aus dem Stapel entfernen

- Du kannst ein Element aus einem Slice entfernen, indem du den Teil nach `index` an den Teil vor `index` anhängst.
