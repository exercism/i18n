# Überblick

Hashes sind ein Datentyp in Perl. Sie enthalten eine ungeordnete Sammlung von String-Schlüsseln, denen jeweils ein Skalarwert zugeordnet ist.

Eine Hash-Variable wird normalerweise gefüllt, indem du ihr eine Liste zuweist, z. B. `my %scores = (Alice => 10, Bob => 15, Charlie => 20);`.

Listenelemente werden meist durch Kommas getrennt, aber häufig siehst du das sogenannte „fette Komma“ `=>`, um Schlüssel und Werte in einer Liste zu trennen. Sein Verhalten ist fast identisch mit dem eines Kommas, aber es hat den zusätzlichen Vorteil, dass es das Element auf der linken Seite als String interpretiert.

Hashes können auch gefüllt werden, indem du einzelne Schlüssel zuweist, z. B. `$scores{Alice} = 10;`.

Auf die Werte eines Hashs kannst du zugreifen, indem du Schlüssel über einen Index angibst, z. B. `$scores{Bob} # 15`.

Schlüssel in einem Hash sind eindeutig. Wird ein Schlüssel mehrfach angegeben, bleibt nur der zuletzt angegebene Wert erhalten.

## Funktionen

Zu den Funktionen für die Arbeit mit Hashes gehören [keys][keys] und [values][values], mit denen du die jeweiligen Teile eines Hashs als Liste abrufen kannst. Die von den Funktionen [keys][keys] und [values][values] zurückgegebenen Listen sind nützlich für Listenfunktionen wie [grep][grep], [map][map] und [sort][sort] sowie für [for][for]-Schleifen.

Weitere Hash-Funktionen sind [exists][exists], mit der du prüfen kannst, ob ein Schlüssel in einem Hash existiert (auch wenn sein Wert `undef` ist), und [delete][delete], mit der du einen Schlüssel aus einem Hash entfernst.

## Sigil-Varianten

Wenn du Werte aus einem Hash holst, bestimmt das verwendete Sigil das Ergebnis. Der Index `{}` am Ende des Variablennamens sagt Perl, dass du mit diesem Namen auf einen Hash zugreifst.

```perl
my %names = (Alice => 10, Bob => 15, Charlie => 20);

$names{Alice}; # 10            <- A scalar
@names{Alice}; # (10)          <- A slice (with only one key, this probably isn't what you want. There will be a warning.)
%names{Alice}; # ('Alice', 10) <- A key/index + value slice

$names{'Bob', 'Charlie'}; #                            <- An error (disabled syntax for an ancient feature.)
@names{'Bob', 'Charlie'}; # (15, 20)                   <- A slice
%names{'Bob', 'Charlie'}; # ('Bob', 15, 'Charlie', 20) <- A key/index + value slice
```

Es ist zwar erlaubt, aber aus Gründen der Lesbarkeit wird empfohlen, dass unterschiedliche Variablentypen nicht denselben Namen tragen.
