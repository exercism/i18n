# Einführung

## Type Juggling

Type Juggling wird auch als Typumwandlung bezeichnet.
Type Juggling bedeutet, dass zwei Werte unterschiedlicher Typen in denselben Typ umgewandelt werden, um eine Operation auszuführen.

```php
$baskets = 5 // int
$apples_per_basket = "3" // string
$baskets * $apples_per_basket
# => 15
```

Das kann implizit geschehen (siehe obiges Beispiel) oder explizit mit einer Typumwandlung im `C`-Stil:

```php
$apples_per_basket = "3" // string
$my_number = (int) $apples_per_basket // cast string to int
# => 3 // int
```

Erlaubte Typen für eine manuelle Typumwandlung sind: `bool`, `int`, `float`, `string`, `array`, `object`.
Am häufigsten wird die Typumwandlung verwendet, um eine Ganzzahl (`int`) in eine Gleitkommazahl (`float`) umzuwandeln oder umgekehrt.
