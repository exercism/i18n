## Allgemein

- [String Templates][sap-string-templates] sind ein Typ der [String Expression](https://help.sap.com/doc/abapdocu_latest_index_htm/latest/en-US/index.htm?file=abapcompute_string.htm), mit dem du einen oder mehrere [eingebettete Ausdrücke][sap-embed-expr] in Strings einfügen kannst.

- Optional: Der [COND-Bedingungsoperator][sap-cond-operator] ist eine Kurzform, um eine Bedingung in einen Ausdruck einzubetten. Da wir Ausdrücke in String Templates einbetten können, können wir ganz auf ein `IF...ELSE...ENDIF`-Konstrukt verzichten.

- String Templates erlauben auch das Einfügen von [Steuerzeichen](https://help.sap.com/doc/abapdocu_latest_index_htm/latest/en-US/index.htm?file=abenstring_templates_separators.htm), einer kürzeren Form der Klassenkonstanten von [`cl_abap_char_utilities`](https://help.sap.com/doc/abapdocu_latest_index_htm/latest/en-US/index.htm?file=abencl_abap_char_utilities.htm), an die manche ABAPer gewöhnt sein mögen.

- Eingebaute Funktionen zur Beschreibung von Strings können dir helfen, die [Länge](https://help.sap.com/doc/abapdocu_latest_index_htm/latest/en-US/index.htm?file=abenlength_functions.htm) des Schilds zu ermitteln.

- Die in String Templates [eingebetteten Ausdrücke][sap-embed-expr] können auch [Formatierungsoptionen](https://help.sap.com/doc/abapdocu_latest_index_htm/latest/en-US/index.htm?file=abapcompute_string_format_options.htm) enthalten. Diese können hilfreich sein, um eine Ausgabe mit einer festen Anzahl von Nachkommastellen anzuzeigen.
