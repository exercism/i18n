# Debug

Die gesamte Ausgabe deines Red-Skripts ist in der Konsole sichtbar, wenn du jeden Test ausführst. Du kannst mit `print` ausgeben, was du willst, zum Beispiel die Werte von Wörtern:

```red
print ["x =" x]
```

Auch die Funktion `probe` ist sehr nützlich. Wenn sie ausgewertet wird, wertet sie ihre Eingabe aus, gibt das Ergebnis so aus, dass sein Typ erkennbar ist, und gibt es zurück. In den meisten Fällen ist sie also „transparent“, und du kannst sie in Ausdrücke einfügen:

```red
x: 10
y: probe x + 5
```

Manchmal kann die Funktion `type?` nützlich sein (ja, sie hat ein Fragezeichen im Namen!), um den Typ eines Werts zu prüfen:

```red
print ["x type:" type? x]
```

Es gibt außerdem einige fortgeschrittenere Debugging-Techniken, die [im Wiki von Red aufgelistet sind](https://github.com/red/red/wiki/%5BDOC%5D-Debugging).
