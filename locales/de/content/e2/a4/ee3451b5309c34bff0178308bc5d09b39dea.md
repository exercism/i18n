# Anweisungen

Du hast die Aufgabe, eine Log-Bibliothek zu erstellen, die beim Verwalten der Logs deiner Organisation hilft.
Mit dieser Bibliothek können Nutzer herausfinden, welche Anwendung ein bestimmtes Log ausgegeben hat, beschädigte Logs reparieren und feststellen, ob eine Logzeile ein bestimmtes Zeichenlimit einhält.

## 1. Ermittle, welche Anwendung ein Log ausgegeben hat

Logs stammen aus verschiedenen Anwendungen, die jeweils ihr eigenes proprietäres Logformat verwenden.
Bevor ein Log in einem Log-Aggregationssystem gespeichert werden kann, muss die Anwendung ermittelt werden, die es ausgegeben hat.

Implementiere die Funktion `Application`, die eine Logzeile entgegennimmt und die Anwendung zurückgibt, die diese Logzeile ausgegeben hat.

Um zu ermitteln, welche Anwendung eine bestimmte Logzeile ausgegeben hat, suche in der Logzeile nach einem bestimmten Zeichen, wie in der folgenden Tabelle angegeben:

| Anwendung        | Zeichen | Unicode-Codepoint  |
|------------------|---------|--------------------|
| `recommendation` | ❗       | `U+2757`           |
| `search`         | 🔍       | `U+1F50D`          |
| `weather`        | ☀       | `U+2600`           |

Wenn eine Logzeile keines der Zeichen aus der obigen Tabelle enthält, gib `default` an den Aufrufer zurück.
Wenn eine Logzeile mehr als eines der Zeichen aus der obigen Tabelle enthält, gib die Anwendung zurück, die zum ersten von links nach rechts gefundenen Zeichen in der Logzeile gehört.

```go
Application("❗ recommended search product 🔍")
// => recommendation
```

## 2. Beschädigte Logs reparieren

Aufgrund eines seltenen, aber hartnäckigen Bugs in der Log-Infrastruktur können bestimmte Zeichen in Logs beschädigt werden.
Nachdem du einige Zeit damit verbracht hast, die beschädigten Zeichen und ihren ursprünglichen Wert zu identifizieren, beschließt du, die Log-Bibliothek zu erweitern, damit sie beim Reparieren beschädigter Logs hilft.

Implementiere die Funktion `Replace`, die eine Logzeile, ein beschädigtes Zeichen und den ursprünglichen Wert entgegennimmt und eine geänderte Logzeile zurückgibt, in der alle Vorkommen des beschädigten Zeichens durch den ursprünglichen Wert ersetzt wurden.

```go
log := "please replace '👎' with '👍'"

Replace(log, '👎', '👍')
// => please replace '👍' with '👍'"
```

## 3. Feststellen, ob ein Log angezeigt werden kann

Systeme, die für die Anzeige von Logs zuständig sind, haben eine Obergrenze für die Anzahl der Zeichen, die pro Logzeile angezeigt werden können.
Deshalb bitten Nutzer darum, dass diese Bibliothek eine Hilfsfunktion enthält, mit der sich feststellen lässt, ob eine Logzeile ein bestimmtes Zeichenlimit einhält.

Implementiere die Funktion `WithinLimit`, die eine Logzeile und ein Zeichenlimit entgegennimmt und zurückgibt, ob die Logzeile das Zeichenlimit einhält.

```go
WithinLimit("hello❗", 6)
// => true
```
