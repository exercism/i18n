# Zusatz zur Anleitung

## Ausgabeformat

Jede Nationalität wird durch einen einzelnen Buchstaben angegeben. (`E` = `Englishman`, `J` = `Japanese`, `N` = `Norwegian`, `S` = `Spaniard`, `U` = `Ukrainian`)

## Register

| Register | Verwendung | Typ     | Beschreibung                     |
| -------- | ---------- | ------- | -------------------------------- |
| `$v0`    | Ausgabe    | Byte    | Nationalität des Wassertrinkers  |
| `$v1`    | Ausgabe    | Byte    | Nationalität des Zebrabesitzers  |
| `$t0-9`  | temporär   | beliebig| für die temporäre Speicherung    |
