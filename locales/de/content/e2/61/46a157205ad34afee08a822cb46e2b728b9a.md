# Anleitung

In dieser Übung bist du ein großer Sportfan und hast gerade deine Leidenschaft für NBA-Basketball entdeckt.
Da du neu im NBA-Basketball bist, tauchst du tief in die Geschichte der NBA ein, behältst Teams, Trainer, ihre Sieg- und Niederlagenstatistiken im Blick und vergleichst sie miteinander.

Da du noch kein Lieblingsteam hast, entwickelst du außerdem einen Algorithmus, der herausfindet, ob du für ein bestimmtes Team die Daumen drücken solltest.
Sieben Aufgaben helfen dir dabei, deinen eigenen _Daumen-drücken-für-ein-Team_-Algorithmus zu entwickeln.

## 1. Definiere das Modell

Definiere den Typalias `Coach` für einen Record mit den folgenden zwei Feldern, in dieser Reihenfolge:

- `name`: der Name des Trainers, vom Typ `String`.
- `formerPlayer`: gibt an, ob der Trainer früher Spieler war, vom Typ `Bool`.

Definiere den Typalias `Stats` für einen Record mit den folgenden zwei Feldern, in dieser Reihenfolge:

- `wins`: die Anzahl der Siege, vom Typ `Int`.
- `losses`: die Anzahl der Niederlagen, vom Typ `Int`.

Definiere den Typalias `Team` für einen Record mit den folgenden drei Feldern, in dieser Reihenfolge:

- `name`: der Name des Teams, vom Typ `String`.
- `coach`: der Trainer des Teams, vom Typ `Coach`.
- `stats`: die Statistiken des Teams, vom Typ `Stats`.

## 2. Erstelle ein Team

Du willst dich mit Code von Drittanbietern verbinden, der zwar ein Team-Konzept kennt, deinen Code aber mit den Parametern in einer anderen Reihenfolge aufruft. Füge eine Funktion `createTeam` mit der folgenden Signatur `String -> Stats -> Coach -> Team` hinzu.

## 3. Ersetze den Trainer

Weil die Besitzer der NBA ungeduldig sind, hast du festgestellt, dass schlechte Teamergebnisse oft dazu führen, dass der Trainer ersetzt wird.
Implementiere die Funktion `replaceCoach`, die den neuen Trainer und das Team als Parameter nimmt und das Team mit dem neuen Trainer zurückgibt:

```elm
let
    coach = { name = "Larry Bird", formerPlayer = True }
    stats = { wins = 58, losses =  24 }
    team = { name = "Indiana Pacers", coach = coach, stats =  stats }
    newCoach = { name = "Isiah Thomas", formerPlayer = True }
in
replaceCoach newCoach team
--> { name = "Indiana Pacers"
--  , coach = { name = "Isiah Thomas", formerPlayer = True }
--  , stats = { wins = 58, losses = 24 } }
```

## 4. Prüfe, ob du für ein Team die Daumen drücken solltest

In Zukunft willst du dir einen komplizierten Algorithmus ausdenken, der entscheidet, ob du für ein Team die Daumen drücken solltest oder nicht. Für den ersten Versuch hast du dich aber entschieden, dass du jedem Team die Daumen drückst, das mehr Siege als Niederlagen hat.

Du möchtest, dass diese Funktion auch in anderen Kontexten wiederverwendbar ist. Verwende deshalb einen erweiterbaren Record in der Typsignatur, der jeden Record annimmt, der die relevanten Felder hat.
Damit die Funktion so knapp wie möglich bleibt, willst du Pattern Matching verwenden, um die `stats` aus dem Funktionsparameter zu holen.
Implementiere die Funktion `rootForTeam`, die ein Team nimmt und `True` zurückgibt, wenn du für dieses Team die Daumen drücken solltest; andernfalls gib `False` zurück.

```elm
let
    spursCoach = { name = "Gregg Popovich", formerPlayer =  False }
    spursStats = { wins = 56, losses = 26 }
    spursTeam = { name = "San Antonio Spurs", coach = spursCoach, stats = spursStats }
in
rootForTeam spursTeam
--> True
```
