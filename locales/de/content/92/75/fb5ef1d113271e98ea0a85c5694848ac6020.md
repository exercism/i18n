# Tests

Um die Tests auszuführen, führe den Befehl `v test .` im Übungsverzeichnis aus.

Wenn du alle Tests sehen möchtest, die ausgeführt wurden, zusammen mit Statistiken zur Geschwindigkeit, verwende `v -stats test .`

Weitere Informationen zum Testen in V findest du in [der Dokumentation](https://github.com/vlang/v/blob/master/doc/docs.md#testing).
