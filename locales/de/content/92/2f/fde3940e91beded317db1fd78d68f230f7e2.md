# Anleitung

Du bist in der Funkstation an der Küste und hörst den Kanal ab: Nachrichten kommen über die Leitung herein, du protokollierst sie und schickst Antworten wieder hinaus. Fünf kleine Wörter erledigen die Arbeit einer ganzen Schicht.

Die Tests übergeben dir `<string-reader>`-Eingaben (hereinkommender Verkehr) und verwenden `<string-writer>` für den ausgehenden Verkehr. Doch jedes Wort hier funktioniert genauso mit einem echten `<file-reader>` oder einem Socket.

## 1. Hör alles ab

Definiere `hear-out`, sodass es einen Eingabestream in einen einzigen String leert.

```factor
"all quiet on the channel" <string-reader> hear-out .
! => "all quiet on the channel"
```

## 2. Zähl die Nachrichten

Definiere `count-messages`, sodass es jede Zeile aus einem Eingabestream liest und zurückgibt, wie viele es waren.

```factor
"alpha\nbravo\ncharlie\n" <string-reader> count-messages .
! => 3
```

## 3. Gib den letzten Ruf zurück

Definiere `echo-back`, sodass es jede Zeile liest und die **letzte in Großbuchstaben** zurückgibt, die übliche Funk-Antwort „du hast X gesagt“.

```factor
"alpha\nbravo\n" <string-reader> echo-back .
! => "BRAVO"
```

## 4. Sende eine Nachricht

Definiere `broadcast`, sodass es eine Nachricht an einen übergebenen Writer schreibt und den Stream leert, damit sie sofort hinausgeht. Gibt nichts zurück.

```factor
[ "mayday" output-stream get broadcast ] with-string-writer .
! => "mayday"
```

## 5. Fang die Ausgabe einer Quotation auf

Definiere `capture`, sodass es eine Quotation mit einem frischen string-writer als umgebenden Ausgabestream ausführt und alles zurückgibt, was die Quotation ausgegeben hat. Die Quotation nimmt keine Argumente entgegen, sie schreibt wie gewohnt in den umgebenden Stream.

```factor
[ "test broadcast" print ] capture .
! => "test broadcast\n"
```
