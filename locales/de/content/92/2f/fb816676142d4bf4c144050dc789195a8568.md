# Der boolesche Typ

In Cairo ist der boolesche Typ für logische Operationen und bedingte Anweisungen unerlässlich.
Boolesche Werte belegen in Cairo genau einen `felt252`, was eine effiziente Nutzung des Speicherplatzes ermöglicht und gleichzeitig die Einfachheit der wahr/falsch-Logik bewahrt.

Der boolesche Typ in Cairo wird mit dem Schlüsselwort `bool` angegeben.
Damit lassen sich boolesche Variablen in der Sprache deklarieren und bearbeiten.
Schauen wir uns zum Beispiel den folgenden Code an:

```rust
fn main() {
    let t = true;
    let f: bool = false; // with explicit type annotation
}
```

In diesem Beispiel werden zwei boolesche Variablen deklariert.
Der Variablen `t` wird der Wert `true` zugewiesen, und sie wird implizit als boolescher Typ deklariert. Die Variable `f` dagegen wird explizit mit dem Typ `bool` annotiert und bekommt den Wert `false` zugewiesen.

Ein wichtiger Punkt: Wenn du eine boolesche Variable in Cairo deklarierst, musst du als Wert unbedingt eines der Literale `true` oder `false` verwenden.
Das bedeutet, dass Ganzzahlliterale wie `0` oder `1` nicht als Ersatz für `false` oder `true` dienen können.
Die strikte Einhaltung dieser Regel gewährleistet Typsicherheit und verhindert mögliche Logikfehler bei der Entwicklung von Smart Contracts.

## Boolesche Operatoren in Cairo

- `||` (logisches ODER): Gibt `true` zurück, wenn mindestens einer der Operanden `true` ist.
- `&&` (logisches UND): Gibt `true` zurück, wenn beide Operanden `true` sind.
- `!` (logisches NICHT): Gibt den entgegengesetzten booleschen Wert des Operanden zurück.

## Beispielcode

Das folgende Codebeispiel zeigt, wie du boolesche Typen in Cairo verwendest.
Es zeigt die Deklaration boolescher Variablen, die Zuweisung boolescher Ausdrücke und die Verwendung von Assertions, um die Korrektheit der booleschen Logik zu überprüfen:

```rust
fn main() {
    // Declaration of Boolean variables
    let t: bool = true;
    let f: bool = false;

    // Boolean expression evaluation
    let true_expr = 5 == 5; // true
    let false_expr = 7 == 5; // false

    // Using Boolean operators
    let or_expr = t || f; // true || false => true
    let and_expr = t && f; // true && false => false
    let not_expr = !f; // !false => true

    // Assertions to verify the correctness
    assert(t == true_expr, 'this should be true'); // t == true
    assert(f == false_expr, 'this should be false'); // f == false
    assert(or_expr == true, 'this should be true for OR'); // true
    assert(and_expr == false, 'this should be false for AND'); // false
    assert(not_expr == true, 'this should be true for NOT'); // true
}
```
