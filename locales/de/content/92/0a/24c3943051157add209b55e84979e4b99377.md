# Anleitung

In dieser Übung hilfst du bei der täglichen Arbeit einer kleinen Bäckerei und nutzt dabei die Kontrollflusskonstrukte von Cairo.

## 1. Bestellsumme berechnen

Implementiere `calculate_total`, die die Kosten einer Bestellung anhand von Gebäckart und Menge berechnet:

- Croissant: 3 Münzen pro Stück
- Muffin: 2 Münzen pro Stück  
- Cookie: 1 Münze pro Stück

```rust
calculate_total(Pastry::Croissant, 4) // Returns: 12 (4 * 3)
calculate_total(Pastry::Cookie, 10)   // Returns: 10 (10 * 1)
```

## 2. Mengenrabatte anwenden

Implementiere `apply_discount`, die Rabatte auf Basis der Bestellsumme anwendet.
Wende den prozentualen Rabatt auf die Summe an und runde dann auf die nächste ganze Münze ab (Abrunden).

- Bestellungen ≥ 20 Münzen: 10 % Rabatt
- Bestellungen ≥ 10 Münzen: 5 % Rabatt
- Bestellungen < 10 Münzen: kein Rabatt

```rust
apply_discount(25) // Returns: 22
apply_discount(15) // Returns: 14
apply_discount(8)  // Returns: 8
```

## 3. Backplan erstellen

Implementiere `baking_schedule`, die einen täglichen Backplan erstellt.
Die Bäckerei backt in Chargen von 5 Bestellungen pro Stunde:

```rust
baking_schedule(18) // Returns: [5, 5, 5, 3] (3 full batches + 3 remaining)
baking_schedule(10) // Returns: [5, 5] (2 full batches)
baking_schedule(3)  // Returns: [3] (1 partial batch)
```

Nutze passende Kontrollflusskonstrukte (`if`/`else`, `loop`), um jedes Problem effizient zu lösen.
