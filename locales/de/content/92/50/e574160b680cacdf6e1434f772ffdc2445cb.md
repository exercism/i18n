# Anweisungen

In dieser Übung übersetzt du einige Regeln aus dem klassischen Spiel Pac-Man in Gleam-Funktionen.

Du hast vier Regeln zu übersetzen, die alle mit den Spielzuständen zusammenhängen.

> Mach dir keine Gedanken darüber, wie die Argumente zustande kommen. Konzentriere dich einfach darauf, die Argumente so zu kombinieren, dass das gewünschte Ergebnis zurückgegeben wird.

## 1. Definiere, ob Pac-Man einen Geist frisst

Definiere die Funktion `eat_ghost`, die zwei Argumente entgegennimmt (_ob Pac-Man eine aktive Kraftpille hat_ und _ob Pac-Man einen Geist berührt_) und einen booleschen Wert dafür zurückgibt, ob Pac-Man den Geist fressen kann. Die Funktion sollte nur dann `True` zurückgeben, wenn Pac-Man eine aktive Kraftpille hat und einen Geist berührt.

```gleam
eat_ghost(False, True)
// -> False
```

## 2. Definiere, ob Pac-Man punktet

Definiere die Funktion `score`, die zwei Argumente entgegennimmt (_ob Pac-Man eine Kraftpille berührt_ und _ob Pac-Man einen Punkt berührt_) und einen booleschen Wert dafür zurückgibt, ob Pac-Man punktet. Die Funktion sollte `True` zurückgeben, wenn Pac-Man eine Kraftpille oder einen Punkt berührt.

```gleam
score(True, True)
// -> True
```

## 3. Definiere, ob Pac-Man verliert

Definiere die Funktion `lose`, die zwei Argumente entgegennimmt (_ob Pac-Man eine aktive Kraftpille hat_ und _ob Pac-Man einen Geist berührt_) und einen booleschen Wert dafür zurückgibt, ob Pac-Man verliert. Die Funktion sollte `True` zurückgeben, wenn Pac-Man einen Geist berührt und keine aktive Kraftpille hat.

```gleam
lose(False, True)
// -> True
```

## 4. Definiere, ob Pac-Man gewinnt

Definiere die Funktion `win`, die drei Argumente entgegennimmt (_ob Pac-Man alle Punkte gefressen hat_, _ob Pac-Man eine aktive Kraftpille hat_ und _ob Pac-Man einen Geist berührt_) und einen booleschen Wert dafür zurückgibt, ob Pac-Man gewinnt. Die Funktion sollte `True` zurückgeben, wenn Pac-Man alle Punkte gefressen hat und aufgrund der in Teil 3 definierten Argumente nicht verloren hat.

```gleam
win(False, True, False)
// -> False
```
