# Anleitung

In der Stadt hat ein neuer Poesieclub eröffnet, und du überlegst, hinzugehen.
Weil es in der Vergangenheit Zwischenfälle gegeben hat, hat der Club eine ganz eigene Einlasspolitik, die du beherrschen musst, bevor du einen Eintritt versuchst.

Der Poesieclub hat zwei Türen, und beide sind bewacht.
Um hineinzukommen, musst du das Passwort des Tages herausfinden:

## 1. Einen String in einzelne Zeilen aufteilen

Als Erstes musst du das Gedicht in einzelne Zeilen aufteilen.
Der Wächter sagt ein Gedicht auf, und du musst es in Zeilen aufteilen.

Implementiere die Funktion `splitOnNewlines`, die einen String entgegennimmt und ihn anhand des Zeilenumbruchzeichens als Trennzeichen in ein Array aus Strings aufteilt.
Die Funktion sollte ein Array aus Strings zurückgeben, in dem jeder String eine Zeile des Gedichts ist.

```swift
splitOnNewlines("Hello.\nHow are you?\n\nI'm doing fine.")
// returns ["Hello." ,"How are you?", "", "I'm doing fine"].
```

## 2. Die Vordertür

1. Der Wächter sagt ein Gedicht auf.
2. Du musst das Gedicht in einzelne Zeilen aufteilen.
3. Du musst den ersten Buchstaben jeder Zeile nehmen.
   - Wenn die Zeile leer ist, solltest du stattdessen `_` verwenden.
4. Du musst die Buchstaben zusammensetzen, die dann ein Wort ergeben.

Zum Beispiel ist einer ihrer Lieblingsautoren Michael Lockwood, der das folgende _Akrostichon_ geschrieben hat. Das bedeutet, dass die ersten Buchstaben der einzelnen Sätze ein Wort ergeben:

```text
Stands so high
Huge hooves too
Impatiently waits for
Reins and harness
Eager to leave
```

Wenn der Wächter das Gedicht aufsagt, teilst du es in einzelne Zeilen auf und antwortest mit den ersten Buchstaben jeder Zeile, also `["S", "H", "I", "R", "E"]`.

Der Wächter gibt dir dann das Wort zurück, das die Buchstaben aus deiner Antwort bilden, damit du es großschreibst.
Das Passwort, das du am Ende zurückgibst, ist `"SHIRE"`, und du kommst hinein.

Implementiere die Funktion `frontDoorPassword`, die einen String entgegennimmt, der das Gedicht darstellt.
Die Funktion sollte das Passwort zurückgeben, das du dem Wächter geben würdest.

```swift
frontDoorPassword("Stands so high\nHuge hooves too\nImpatiently waits for\nReins and harness\nEager to leave")
// returns "SHIRE"
```

## 3. Die Hintertür

Im hinteren Teil des Clubs findest du die berühmtesten Dichter, so etwas wie der VIP-Bereich.
Weil das nicht für alle gedacht ist, ist der Ablauf an der Hintertür etwas komplizierter.

1. Der Wächter sagt ein Gedicht auf.
2. Du musst das Gedicht in Zeilen aufteilen.
3. Du musst den letzten Buchstaben jeder Zeile nehmen.
   - Die Zeile hat manchmal Leerzeichen am Ende, die du entfernen musst.
4. Du musst die Buchstaben zusammensetzen und dann `", please"` an das Ende des Wortes anhängen, das die Buchstaben ergeben.

Zum Beispiel ist das vorher erwähnte Gedicht auch ein _Telestichon_, was bedeutet, dass die letzten Buchstaben der einzelnen Sätze ein Wort ergeben:

```text
Stands so high
Huge hooves too
Impatiently waits for
Reins and harness
Eager to leave
```

Wenn der Wächter das Gedicht aufsagt, teilst du es in einzelne Zeilen auf, entfernst alle Leerzeichen am Ende und antwortest mit den ersten Buchstaben jeder Zeile, also `["h", "o", "r", "s", "e"]`.

Der Wächter gibt dir dann das Wort zurück, das die Buchstaben aus deiner Antwort bilden, damit du es großschreibst und `", please"` anhängst.
Das Passwort, das du am Ende zurückgibst, ist `"horse, please"`, und du kommst hinein.

Implementiere die Funktion `backDoorPassword`, die einen String entgegennimmt, der das Gedicht darstellt.
Die Funktion sollte das Passwort zurückgeben, das du dem Wächter geben würdest.

```swift
backDoorPassword("Stands so high\nHuge hooves too\nImpatiently waits for\nReins and harness\nEager to leave")
// returns "horse, please"
```

## 4. Der geheime Raum

Im hinteren Raum des Clubs gibt es noch eine Tür, die in den geheimen Raum führt, den nur die allerbesten Dichter betreten dürfen.

1. Der Wächter sagt ein Gedicht auf.
2. Du musst das Gedicht in Zeilen aufteilen.
3. Du musst den i<sup>ten</sup> Buchstaben der i<sup>ten</sup> Zeile nehmen.
4. Du musst die Buchstaben zusammensetzen und dann `"!"` an das Ende des Wortes anhängen, das die Buchstaben ergeben.
5. Du musst das Wort in Großbuchstaben umwandeln.

Zum Beispiel passt eine abgewandelte Version des vorher erwähnten Gedichts zu diesem Muster:

```text
Stands so high
Huge hooves too
Impatiently waits for
Rider with harness
Eager to leave
```

Wenn der Wächter das Gedicht aufsagt, teilst du es in einzelne Zeilen auf, entfernst alle Leerzeichen am Ende und antwortest mit den i<sup>ten</sup> Buchstaben jeder Zeile, also ["S", "u", "p", "e", "r"].

Der Wächter gibt dir dann das Wort zurück, das die Buchstaben aus deiner Antwort bilden, damit du es in Großbuchstaben umwandelst und `"!"` anhängst.
Das Passwort, das du am Ende zurückgibst, ist `SUPER!`, und du kommst hinein.

Implementiere die Funktion `secretRoomPassword`, die einen String entgegennimmt, der das Gedicht darstellt.
Die Funktion sollte das Passwort zurückgeben, das du dem Wächter geben würdest.

```swift
secretRoomPassword("Stands so high\nHuge hooves too\nImpatiently waits for\nRider with harness\nEager to leave")
// returns "SUPER!"
```
