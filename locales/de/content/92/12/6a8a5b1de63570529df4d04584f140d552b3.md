# Ergänzende Anweisungen

## Der vorgegebene Code

`src/TreeBuilding.hs` enthält bereits eine funktionierende Lösung, die alle Tests besteht.
Sie ist langsam und schwer zu lesen; deine Aufgabe ist es, sie zu verbessern, ohne die Tests zu brechen.

`buildTree` gibt `Nothing` zurück, wenn die Datensätze keinen gültigen Baum ergeben.

## Die Repräsentation ändern

Die Tests verwenden nie die Konstruktoren von `Tree` direkt.
Stattdessen bauen sie erwartete Bäume mit der Funktion

```haskell
node :: Int -> [Tree] -> Tree
```

Dabei ist `node i children` der Knoten mit der ID `i` und den angegebenen Kindern, aufsteigend nach ID sortiert.

Das heißt, du kannst frei entscheiden, wie `Tree` repräsentiert wird, zum Beispiel so:

```haskell
import qualified Data.Tree as T

type Tree = T.Tree Int

node :: Int -> [Tree] -> Tree
node = T.Node
```

solange `Tree` weiterhin `Eq`- und `Show`-Instanzen hat und `node` seine Bedeutung behält.
Wenn du eine Bibliothek wie `containers` verwendest, denk daran, sie in `package.yaml` unter `dependencies` hinzuzufügen.
