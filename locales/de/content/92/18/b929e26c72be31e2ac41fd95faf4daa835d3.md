# Anleitung

Du arbeitest wieder an dem ORM-System (objektrelationale Abbildung), das in [exercise:csharp/object-relational-mapping]() vorgestellt wurde.

Unsere Analyse der ORM-Nutzung zeigt, dass 95 % der Transaktionen innerhalb einer einzigen aufrufenden Methode ausgeführt werden. Deshalb wurde entschieden, dass es passender wäre, eine einzige ORM-Methode zu haben, die eine Transaktion beginnt, Daten schreibt und die Transaktion committet.

Die Datenbank hat die folgenden Instanzmethoden:

- `Database.BeginTransaction()` startet eine Transaktion auf der Datenbank.
- `Database.Write(string data)` schreibt Daten innerhalb der Transaktion in die Datenbank. Wenn sie ungültige Daten erhält, wird eine Exception ausgelöst. Ein Aufruf dieser Methode, ohne dass vorher `BeginTransaction()` aufgerufen wurde, führt ebenfalls zu einer Exception. Bei Erfolg wechselt der interne Zustand der Datenbank zu `DataWritten`.
- `Database.EndTransaction()` committet die Transaktion in die Datenbank. Sie kann eine Exception auslösen, wenn sie die Transaktion nicht abschließen kann oder wenn `Database.BeginTransaction()` nicht aufgerufen wurde.
- Ein Aufruf von `Database.Dispose()` räumt die Datenbank auf, wenn während einer Transaktion eine Exception ausgelöst wird. Dadurch wechselt der Zustand der Datenbank zu `Closed`.

## 1. In die Datenbank schreiben

Implementiere die Methode `Orm.Write()`, um eine Datenbanktransaktion zu beginnen, die übergebenen Daten zu schreiben und die Transaktion zu committen. Alle Exceptions, auch `InvalidOperationException`, sollen ohne Protokollierung oder andere Eingriffe an den Aufrufer weitergegeben werden.

```csharp
Database db = new Database();
Orm orm = new Orm(db);
orm.Write("good write");
// => database has an internal state of State.Closed
orm.Write("bad write");
// => an exception is thrown but database is left with an internal state of State.Closed
orm.Write("bad commit");
// => an exception is thrown but database is left with an internal state of State.Closed
```

## 2. In die Datenbank schreiben und dem Aufrufer zurückmelden, ob der Schreibvorgang erfolgreich war

Es ist einige Monate her, seit `Orm.Write()` eingeführt wurde, und im Team herrscht Uneinigkeit. Viele Entwickler hätten es gern, dass die _ORM_ Fehler behandelt, wenn Exceptions ausgelöst werden, und dem Aufrufer einfach eine Rückmeldung über den Erfolg gibt.

Bitte implementiere die Methode `Orm.WriteSafely()`, um eine Datenbanktransaktion zu beginnen, die übergebenen Daten zu schreiben und die Transaktion zu committen (wie oben). Sie soll `true` zurückgeben, wenn der _Schreibvorgang_ erfolgreich war, andernfalls `false`. Versuche nicht, die Exception zu protokollieren.

```csharp
Database db = new Database();
Orm orm = new Orm(db);
orm.WriteSafely("good write");
// => true
orm.WriteSafely("bad write");
// => false
orm.WriteSafely("bad commit");
// => false
```
