# Einführung

Rekursion ist eine Möglichkeit, Code in einer Funktion zu wiederholen, indem die Funktion sich selbst aufruft.
Sie ist eine weitere Art, eine Schleife zu schreiben bzw. zu iterieren. Wie bei einer Schleife sollte die Funktion einen booleschen Ausdruck prüfen, um zu wissen, wann sie enden soll.
Anders als bei einer Schleife läuft eine Rekursion, die nie endet, nicht unendlich weiter.
Die Werte, die bei jedem Funktionsaufruf verwendet werden, können in ihrem eigenen Stackframe abgelegt werden.
Wenn die Anzahl der Funktionsaufrufe mehr Platz belegt, als der Stack hat, führt das zu einem Stack-Overflow-Fehler.

```c
int printIncrement (int i, int maxValue){
    if (i > maxValue) return i;
    printf("The number is %i\n", i++);
    printIncrement(i, maxValue);
}

int main() {
    printIncrement(1, 2);
    printf("After recursion");
    return 0;
}
```

Das gibt Folgendes aus

```
The number is 1
The number is 2
After recursion
```

Es gibt Situationen, die sich mit Rekursion lesbarer und/oder leichter nachvollziehbar ausdrücken lassen als mit einer Schleife.
