# Konzepte der parallelen Buchstabenhäufigkeit

Diese Übung bietet eine große Vielfalt möglicher Lösungen, auch mithilfe externer Crates. Damit der Aufwand überschaubar bleibt, enthält dieses Dokument eine kleine Auswahl an Möglichkeiten. Lösungen mit Crossbeam decken einen ähnlichen Satz von Konzepten ab wie hier aufgeführt, und Rayon benötigt nur eine Teilmenge davon.

## Allgemeines

- Strings: Insbesondere `str` spielt hier immer eine Rolle
- Unicode: Kompromisse bei Leistung und Funktionsumfang von ASCII- vs. Unicode-Methoden. Ein Benchmark fällt verzerrt aus, wenn er Unicode-Methoden nutzt und die Lösung ASCII-Methoden verwendet.
- Iteratoren: über die Eingabe oder Teile davon iterieren.
- Kollektionen: über eine `HashMap` iterieren und `Entry` verwenden. Häufig werden Handles in einem `Vec` gesammelt.
- Referenzen
- Zahlen: speziell das Trait `Add`
- For-Schleife: In einem Iterator lassen sich Threads wegen move nicht verbinden.
- **Opt** Sichtbarkeit: Implementierungsdetails nicht öffentlich machen
- **Opt** Slices: `.chunks()` ist eine häufig verwendete Methode, um die Eingabe für Worker-Threads aufzuteilen. Alternativ werden Teilslices verwendet.
- **Opt** Funktionen höherer Ordnung: Die HashMaps lassen sich mit einem Iterator durch eine Funktion höherer Ordnung zusammenführen.
- **Opt** Typen: Zum Aufteilen der Eingabe können wir Ganzzahlen in Gleitkommazahlen umwandeln, um eine Rundung anzuwenden
- **Opt** Crates

## Std-Ansatz mit oder ohne Kanäle

- Parallelität - Unterthema Threads erzeugen/verbinden.
- Iteratoren - Unterthema verzögerte Auswertung: Threads mit demselben Iterator zu erzeugen und zu verbinden verhindert Parallelität.
- Lifetimes - Unterthemen `'static lifetime` und explizite `move`-Semantik
- Iteratoren/Lifetimes - Unterthema konsumierende Iteratoren: Mit einem Iterator lassen sich Threads nicht verbinden.
- Option-Typ: Thread- oder Kanalergebnisse entpacken
- Funktionen: Speziell für das Erzeugen von Threads werden Funktionen höherer Ordnung benötigt. Closures sind hier eine Möglichkeit.

## Std-Ansatz mit Kanälen

- Parallelität - Unterthema Kanäle.
- Tupel: `mpsc::channel()` gibt ein Tupel zurück
- Destrukturierung: Ein Tupel lässt sich bei der Zuweisung destrukturieren
- Lifetimes: `drop()`

## Alternativer Ansatz mit geteilten Variablen

- Referenzzählung: Aggregierte Daten zwischen Threads über eine referenzgezählte Kollektion teilen.
- **Lobende Erwähnung**: Parallelität - Unterthema Mutexe. Für diese Übung nicht nötig/nützlich, aber dennoch ein gängiges Konzept. Verwandt: `RwLock`.

### Beispiel für Std mit Kanälen

```rust
use std::collections::HashMap;
use std::thread;
use std::sync::mpsc;

pub fn frequency(input: &[&str], worker_count: usize) -> HashMap<char, usize> {
    let (tx, rx) = mpsc::channel();

    let _handles = input.chunks((input.len() as f64 / worker_count as f64).ceil() as usize)
        .map(|slice| slice.concat())
        .map(|slice| {
            let tx = tx.clone();
            thread::spawn(move || {
                let mut map: HashMap<char, usize> = HashMap::new();
                for chr in slice.chars().filter(|c| c.is_alphabetic()) {
                    if let Some(c) = chr.to_lowercase().next() {
                        (*map.entry(c).or_insert(0)) += 1;
                    };
                }
                tx.send(map).unwrap()
            })
        }).collect::<Vec<_>>();

    drop(tx);

    let mut result: HashMap<char, usize> = HashMap::new();
    for received in rx {
        for (c, count) in received {
            *result.entry(c).or_insert(0) += count;
        }
    }

    result
}
```

### Beispiel-Crate mit Arc

```rust
use std::collections::HashMap;
use std::iter::FromIterator;
use std::sync::Arc;
use dashmap::DashMap;

pub fn frequency(input: &[&str], worker_count: usize) -> HashMap<char, usize> {
    let map: Arc<DashMap<char, usize>> = Arc::new(DashMap::new());

    let handles = input
        .chunks((input.len() as f64 / worker_count as f64).ceil() as usize)
        .map(|slice| slice.concat())
        .map(|slice| {
            let map = map.clone();
            std::thread::spawn(move || {
                for c in slice.chars().filter(|c|c.is_alphabetic())
                  .flat_map(|c| c.to_lowercase().next()) {
                    *map.entry(c).or_insert(0) += 1;
                }
            })
        }).collect::<Vec<_>>();

    for h in handles {
        h.join().unwrap();
    }

    map.iter().map(|x| (*x.key(), *x.value())).collect()
}
```
