# Anleitung

In dieser Übung arbeitest du weiter an ferngesteuerten Autos.

Ein experimentelles Auto wurde entwickelt, und die Teststrecke muss angepasst werden, damit sie sowohl Serien- als auch Experimentalmodelle bewältigen kann. Die beiden Autotypen sind bereits gebaut, und du musst einen Weg finden, mit beiden auf der Teststrecke umzugehen.

Außerdem beginnen die Serienautos, Erfolge zu erzielen. Der Teamchef möchte den Wettbewerbsgeist erhalten, indem er eine Rangliste der Serienautos veröffentlicht.

## 1. Ermögliche, dass Autos auf derselben Teststrecke gefahren werden können

Bitte füge dem Interface `IRemoteControlCar` eine Methode hinzu, die die Implementierungen von `Drive()` für die beiden Autotypen verfügbar macht.

```csharp
TestTrack.Race(new ProductionRemoteControlCar());
TestTrack.Race(new ExperimentalRemoteControlCar());
// this should execute without an exception being thrown
```

## 2. Ermögliche, dass die von verschiedenen Modellen auf der Teststrecke zurückgelegte Strecke verglichen werden kann

Bitte füge dem Interface `IRemoteControlCar` eine Eigenschaft hinzu, die die Implementierungen der Eigenschaft `DistanceTravelled` für die beiden Autotypen verfügbar macht.

```csharp
var prod = new ProductionRemoteControlCar();
TestTrack.Race(prod);
var exp = new ExperimentalRemoteControlCar();
TestTrack.Race(exp);
prod.DistanceTravelled
// => 10
exp.DistanceTravelled
// => 20
```

## 3. Ermögliche eine Rangliste der Serienautos

Bitte implementiere das Interface `IComparable<T>` in der Klasse `ProductionRemoteControlCar`. Die standardmäßige Sortierreihenfolge der Autos soll aufsteigend nach Siegen sein.

Implementiere die statische Methode `TestTrack.GetRankedCars()`, die die übergebenen Autos aufsteigend nach der Anzahl der Siege sortiert zurückgibt.

```csharp
var prc1 = new ProductionRemoteControlCar();
var prc2 = new ProductionRemoteControlCar();
prc1.NumberOfVictories = 3;
prc2.NumberOfVictories = 2;
var rankings = TestTrack.GetRankedCars(prc1, prc2);
// => rankings[1] == prc1
```
