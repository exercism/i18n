Installation
============

Um Programme in YAMLScript zu schreiben, musst du den YAMLScript-Kommandozeilen-Interpreter installieren.
Dabei handelt es sich um eine ausführbare Binärdatei namens `ys`.
Der Interpreter läuft derzeit auf:

* Linux / Intel
* Linux / ARM
* MacOS / Intel
* MacOS / ARM

> Hinweis: Die Unterstützung für Windows ist geplant, aber noch nicht verfügbar.

Releases sind [auf GitHub verfügbar](
http://github.com/yaml/yamlscript/releases).


## Automatische Installation

Um die YAMLScript-Übungen bei Exercism zu lösen, änderst du dein Lösungsprogramm immer wieder und führst `make test` aus, bis alle Tests bestehen.

Das ist alles!

Wenn du `make test` zum ersten Mal ausführst, versucht es, die spezifische Version des `ys`-Interpreters zu installieren, die für die Übung benötigt wird, und zwar im Verzeichnis `/path/to/exercism/yamlscript/.local/`.

Wenn du diese Version von `ys` bereits irgendwo in deinem `PATH` installiert hast, kopiert es den `ys`-Interpreter still an die richtige Stelle.

Wenn nicht, wirst du aufgefordert, eine Installation aus einem binären Release durchzuführen, was normalerweise nur ein paar Sekunden dauert.

Wenn das fehlschlägt (selten, aber es kommt manchmal vor), wirst du aufgefordert, einen automatisierten Build aus dem Quellcode durchzuführen, was ein paar Minuten dauern kann (aber sehr zuverlässig ist und keine Interaktion erfordert).

Das passiert nur, wenn du `make test` zum ersten Mal ausführst.
Alle Übungen, die dieselbe Version von `ys` verwenden, nutzen dieselbe Installation.

> Hinweis: Du kannst den Befehl `make install-ys` auch getrennt von `make
> test` verwenden.
> Er führt genau denselben Installationsprozess aus wie `make test`, aber ohne anschließend die Tests auszuführen.


Weitere Informationen zur Installation von YAMLScript, insbesondere zur Verwendung außerhalb von Exercism, findest du in der [YAMLScript-Installationsdokumentation](
https://yamlscript.org/doc/install/).
