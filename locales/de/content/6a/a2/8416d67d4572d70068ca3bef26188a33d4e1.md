# Ergänzung zu den Anweisungen

## Implementierung

Implementiere im Paket twobucket eine Go-Funktion, Solve, mit der folgenden Signatur:

```go
func Solve(sizeBucketOne,
	sizeBucketTwo, goalAmount int, startBucket string,
) (goalBucket string, numSteps, otherBucketLevel int, e error)
```

Solve gibt vier Werte zurück: den Eimer, in dem das Ziel erreicht wurde ("one" oder "two"), die Anzahl der Züge bzw. Schritte, mit denen die Zielmenge erreicht wird, die Liter, die im anderen Eimer übrig bleiben, und einen Fehlerwert. Gib einen Fehler zurück, wenn ein Parameter ungültig ist oder keine Lösung möglich ist.
