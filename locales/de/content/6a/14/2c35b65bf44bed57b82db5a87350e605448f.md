# Grundlagen von match

Der `match`-Operator vergleicht einen Wert mit einer Reihe von Mustern und führt dann Code aus, je nachdem, welches Muster passt.

## Abgleich mit Literalen

Ganz grundlegend vergleicht `match` einen Wert mit mehreren möglichen Treffern und wählt den ersten Zweig, der passt. Es wird immer nur ein Zweig gewählt, und die Ausführung „fließt“ nie in einen anderen Zweig weiter. `match` ist ein Ausdruck, der einen Wert liefern kann.

```rust
enum TrollNumber {
    One,
    Two,
    Many,
    Lots,
}

fn estimated_value(troll_number: TrollNumber) -> u32 {
    match troll_number {
        TrollNumber::One => 1,
        TrollNumber::Two => 2,
        TrollNumber::Many => 10,
        TrollNumber::Lots => 100,
    }
}
```

## Vollständigkeit

Der Abgleich ist immer vollständig: Rust kompiliert ein Programm nicht, wenn ein Wert durchs Raster fallen könnte. Um das zu erleichtern, gibt es `_`, einen Platzhalter, der auf alles passt.

```rust
fn ordinal(n: u32) -> String {
    let ordinal = match n % 10 {
        1 => "st",
        2 => "nd",
        3 => "rd",
        _ => "th",
    };
    format!("{n}{ordinal}")
}
```

## Abgleich als Kontrollfluss

`match` kann als Ausdruck verwendet werden, um einen Wert zu liefern; es kann aber auch als Anweisung allein zur Steuerung des Kontrollflusses dienen.

```rust
// pretend that we've already filtered the key events relevant to the space bar (we don't want a keylogger)
fn space_timer(&mut self, event: Event) {
    match event {
        Event::KeyDown => self.timer = Some(Instant::now()),
        Event::KeyUp => {
            let duration = Instant::now() - self.timer.take().expect("can't have KeyUp without KeyDown");
            self.durations.push(duration);
        }
        // we don't care about any other events; the empty scope is a no-op
        _ => {}
    }
}
```

## Abgleich von Bereichen

Zweige müssen nicht als einzelne Werte angegeben werden; sie können auch Bereiche sein.

```rust
fn ascii_type(ch: u8) -> &'static str {
    match ch {
        0..=31 => "non-printable control code",
        32..=126 => "printable character",
        127 => "DEL",
        _ => "extended ASCII; region-specific",
    }
}
```

## Oder-Muster

Ein Zweig kann mithilfe des Zeichens `|` als Trennzeichen auf eine von mehreren möglichen Optionen passen.

```rust
fn should_retry(error: std::io::Error) -> bool {
    use std::io::ErrorKind;

    match error.kind() {
        ErrorKind::TimedOut | ErrorKind::Interrupted => true,
        _ => false,
    }
}
```

## Struktureller Abgleich und Bindungen

Ein Abgleich kann eine Bindung erzeugen, die nur innerhalb eines bestimmten Zweigs gültig ist. Das ist besonders nützlich, um Enums zu entpacken, die Daten in ihren Varianten tragen.

```rust
/// Consume a result and proceed, logging any errors.
trait OrLog {
    fn or_log(self);
}

impl<E: std::fmt::Display> OrLog for Result<(), E> {
    fn or_log(self) {
        match self {
            // discard Ok results
            Ok(()) => {},
            // log errors
            Err(err) => println!("ERROR: {err}"),
        }
    }
}
```
