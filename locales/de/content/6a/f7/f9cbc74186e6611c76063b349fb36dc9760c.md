# Einführung

In JavaScript kannst du mit _Template-Strings_ Ausdrücke in Strings einbetten. Man spricht dabei auch von String-Interpolation.
Diese Funktionalität erweitert das eingebaute globale Objekt [`String`][string-reference].

Du erstellst Template-Strings in JavaScript, indem du den Text in Backticks einschließt.
Sie erlauben nicht nur Zeilenumbrüche und andere Sonderzeichen im Text, sondern du kannst auch Variablen und andere Ausdrücke einbetten.

```javascript
const num1 = 1;
const num2 = 2;

`Adding ${num1} and ${num2} gives ${num1 + num2}.`;
// => Adding 1 and 2 gives 3.
```

Im obigen Beispiel werden Backticks (<code>\`\`</code>) verwendet, um einen Template-String darzustellen. Der `${...}` ist der Platzhalter, der für die Substitution verwendet wird.
Alle Typen, die keine Strings sind, werden _implizit_ in Strings umgewandelt.
Dieses Thema wird im Konzept [Typumwandlung][type-conversion-concept] behandelt.
Alle Arten von Ausdrücken können mit Template-Strings verwendet werden.

```javascript
const track = 'JavaScript';

`This track on exercism.org is ${track.toUpperCase()}.`;
// => This track on exercism.org is JAVASCRIPT.
```

Wenn du Strings über mehrere Zeilen formatieren möchtest:

```javascript
`This is an example of using template
strings to accomplish multiple
lines`;

/* => This is an example of using template
     strings to accomplish multiple
     lines
*/
```

Wenn du in einem regulären String einen Zeilenumbruch darstellen möchtest, statt einen Template-String zu verwenden (also keine Backticks benutzt), kannst du die Escape-Sequenz für Zeilenumbrüche `\n` verwenden:

```javascript
'This is an example of using the newline escape sequence!\nWithout backticks';

/* => This is an example of using the newline escape sequence!
      Without backticks
*/
```

Mit den verfügbaren Substitutionsmöglichkeiten kannst du auch Logik einbauen, um zu bestimmen, wie der Ausgabe-String aussehen soll.
Eine Möglichkeit, diese Logik umzusetzen, ist der [ternäre Operator][ternary-operator].
Er bietet die gleiche bedingte `if/else`-Funktionalität in einem etwas anderen Format.

So bringst du Logik in die Template-String-Syntax:

```javascript
const grade = 95;

`You have ${grade > 90 ? 'passed' : 'failed'} the exam.`;
// => You have passed the exam.
```
