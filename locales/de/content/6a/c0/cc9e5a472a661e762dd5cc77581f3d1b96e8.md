# Hinweise

## Allgemein

- Lies in der offiziellen [Getting-Started-Anleitung][getting-started-strings] über Strings.
- Sieh dir die [im _String-Modul verfügbaren Funktionen][string-module-functions] an, um herauszufinden, welche Operationen auf Strings die Standardbibliothek von Elixir bietet.

## 1. Den ersten Buchstaben des Namens ermitteln

- Es gibt eine [eingebaute Funktion][string-first], um das erste Zeichen aus einem String zu holen.
- Es gibt mehrere [eingebaute Funktionen][string-trim], um führende, abschließende oder führende und abschließende Leerzeichen aus einem String zu entfernen.

## 2. Den ersten Buchstaben als Initiale formatieren

- Es gibt eine [eingebaute Funktion][string-upcase], um alle Zeichen in einem String in Großbuchstaben umzuwandeln.
- Es gibt einen [Operator][kernel-concat], der zwei Strings aneinanderhängt.

## 3. Den vollständigen Namen in Vorname und Nachname aufteilen

- Es gibt eine [eingebaute Funktion][string-split], die einen String an Leerzeichen aufteilt.
- Ein paar erste Elemente einer Liste kannst du Variablen zuweisen, indem du Pattern Matching auf die Liste anwendest.

## 4. Die Initialen in das Herz setzen

- Es gibt eine spezielle Syntax, um einen [Ausdruck in einen String zu interpolieren][string-interpolation].
- Es gibt eine spezielle Syntax, um [mehrzeilige Strings][heredoc-syntax] zu schreiben, ohne Zeilenumbrüche escapen zu müssen.
