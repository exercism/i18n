# Schleifen

Mit Schleifen kannst du in Rust einen Block Code wiederholt ausführen, bis du ihn stoppst oder eine bestimmte Bedingung erfüllt ist.

Die einfachste Form einer Schleife verwendet das Schlüsselwort `loop`:

```rust
fn main() {
    loop {
        println!("again!");
    }
}
```

Das obige Codebeispiel erzeugt eine Endlosschleife. Um eine Schleife zu verlassen, verwendest du das Schlüsselwort break:

```rust
fn main() {
    let mut count = 0;
    loop {
        println!("again!");
        count += 1;
        if count > 10 { break; }
    }
}
```

## Schleifen mit `for` und `while`

Neben dem Schlüsselwort `loop` kannst du Schleifen auch mit `for` und `while` erstellen.

Eine `for`-Schleife durchläuft die Elemente einer Sammlung oder eines Iterators.

```rust
fn main() {
    let a = [10, 20, 30, 40, 50];

    for x in a {
        println!("the value is: {x}");
    }
}
```

Ranges sind ebenfalls Iteratoren. Deshalb ist es sehr bequem, sie mit der `for`-Schleife zu durchlaufen:

```rust
fn main() {
    for x in 0..10 {
        println!("the value is: {x}");
    }
}
```

Eine `while`-Schleife wiederholt Code so lange, bis eine Bedingung erfüllt ist. Wir können das frühere Beispiel mit einer `while`-Schleife so umschreiben:

```rust
fn main() {
    let a = [10, 20, 30, 40, 50];
    let mut index = 0;

    while index < 5 {
        println!("the value is: {}", a[index]);

        index += 1;
    }
}
```
