# Ergänzung zur Anleitung

## Ein-/Ausgabeformat

Die Funktion erhält einen einzelnen String aus Wörtern, wobei jedem ein Zeilenumbruch angehängt ist.

Das erste ist das Wort, dessen Anagramme die übrigen sein sollen.

Gib einen String mit allen gültigen Anagrammen zurück, wobei jedem ein Zeilenumbruch angehängt ist.


## Reservierte Adressen

Der Puffer für den Eingabe-String belegt die Bytes 64-319 des linearen Speichers.

Du kannst diesen Puffer direkt verändern, wenn du zusätzliche Speicherallokationen vermeiden möchtest.
