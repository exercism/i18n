# NuVoc

Die [NuVoc][nuvoc-link] ist die maßgebliche Referenz für J.
Sie ist eine sehr knappe und informationsdichte Übersicht über die Primitive und die Sprache von J.

# Rosetta Code

Viele Rosetta-Aufgaben haben `J`-Lösungen.
Es ist eine gute Quelle, um J-Programme zum Lernen zu finden.
[Hier](https://rosettacode.org/wiki/Sudoku#J) ist ein Sudoku-Löser von Roger Hui.
