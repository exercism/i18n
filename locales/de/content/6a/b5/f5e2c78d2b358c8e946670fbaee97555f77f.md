# Einführung

## Reguläre Ausdrücke

Reguläre Ausdrücke in Elixir folgen der **PCRE**-Spezifikation (**P**erl **C**ompatible **R**egular **E**xpressions), ähnlich wie in anderen populären Sprachen wie Java, JavaScript oder Ruby.

Das Modul `Regex` bietet Funktionen für die Arbeit mit regulären Ausdrücken. Einige Funktionen des Moduls `String` akzeptieren ebenfalls reguläre Ausdrücke als Argumente.

~~~~exercism/note
Diese Übung setzt voraus, dass du die Syntax regulärer Ausdrücke bereits kennst, einschließlich Zeichenklassen, Quantoren, Gruppen und Captures.

Wenn du dein Wissen über reguläre Ausdrücke auffrischen möchtest, schau dir eine dieser Quellen an: [Regular-Expressions.info](https://www.regular-expressions.info), [Rex Egg](https://www.rexegg.com/), [RegexOne](https://regexone.com/), [Regular Expressions 101](https://regex101.com/), [RegExr](https://regexr.com/).
~~~~

### Sigils

Der gebräuchlichste Weg, reguläre Ausdrücke zu erstellen, ist die Verwendung des Sigils `~r`.

```elixir
~r/test/
```

Beachte, dass alle Elixir-Sigils [verschiedene Arten von Trennzeichen][sigils] unterstützen, nicht nur `/`.

### Matching

Der Operator `=~/2` kann verwendet werden, um einen Regex-Abgleich durchzuführen, der ein `boolean`-Ergebnis zurückgibt. Alternativ gibt es auch die Funktionen `match?/2` im Modul `Regex` sowie im Modul `String`.

```elixir
"this is a test" =~ ~r/test/
# => true

String.match?("Alice has 7 apples", ~r/\d{2}/)
# => false
```

### Capturing

Wenn eine einfache boolesche Prüfung nicht ausreicht, verwende die Funktion `Regex.run/3`, um eine Liste aller Captures zu erhalten (oder `nil`, wenn es keinen Treffer gab). Das erste Element in der zurückgegebenen Liste ist immer ein Treffer für den gesamten regulären Ausdruck, und die folgenden Elemente sind die übereinstimmenden Gruppen.

```elixir
Regex.run(~r/(\d) apples/, "Alice has 7 apples")
# => ["7 apples", "7"]
```

### Modifikatoren

Das Verhalten eines regulären Ausdrucks kann durch Anhängen spezieller Flags geändert werden. Wenn du ein Sigil verwendest, um einen regulären Ausdruck zu erstellen, füge die Modifikatoren nach dem zweiten Trennzeichen hinzu.

Häufige Modifikatoren sind:
- `i` - macht den Abgleich unabhängig von Groß- und Kleinschreibung.
- `u` - aktiviert Unicode-spezifische Muster wie `\p` und sorgt dafür, dass Zeichenklassen wie `\w`, `\s` usw. auch Unicode-Zeichen abgleichen.

```elixir
"this is a TEST" =~ ~r/test/i
# => true
```
