# Einführung

## Funktionen

In Gleam definierst du Funktionen mit der Syntax `pub fn`.

```gleam
pub fn add(x: Int, y: Int) -> Int {
  x + y
}
```

Diese Funktion nimmt zwei Argumente entgegen, beide vom Typ `Int`, und gibt einen Wert vom Typ `Int` zurück. In Gleam gibt es kein Schlüsselwort `return`; der Wert des letzten Ausdrucks einer Funktion wird immer _implizit zurückgegeben_.

Die Typannotationen für die Argumente und der Rückgabetyp sind optional, und Gleam prüft deinen Code immer vollständig auf Typen. Normalerweise geben Gleam-Programmierer ihren Funktionen Typannotationen, um Klarheit zu schaffen, aber du kannst sie auch weglassen, wenn du möchtest.

```gleam
pub fn add(x, y) {
  x + y
}
```

Eine Funktion kannst du mit der Syntax `function_name(argument1, argument2)` aufrufen.

```gleam
pub fn double(x: Int) -> Int {
  // Call the add function defined above
  add(x, x)
}
```

## Variablen

In Gleam definierst du Variablen mit der Syntax `let name = expression`.

```gleam
pub fn main() {
  let count = 1
}
```

Variablen kannst du mit Typannotationen deklarieren. Wie bei Funktionsargumenten sind sie optional, doch die meisten Gleam-Programmierer lassen Typannotationen bei Variablen weg, um es kurz zu halten.

```gleam
pub fn main() {
  let count: Int = 1
}
```

## String-Literale

In Gleam schreibst du Strings mit doppelten Anführungszeichen.

```gleam
pub fn greeting() {
  "Hello, world!"
}
```

## Codekommentare

Mit Kommentaren kannst du Notizen für andere Entwickler hinterlassen, die den Quellcode lesen. Kommentare in Gleam sind einzelne Zeilen, denen `//` vorangestellt ist.

```gleam
pub fn main() {
  // This is a comment
  let x = 1
}
```
