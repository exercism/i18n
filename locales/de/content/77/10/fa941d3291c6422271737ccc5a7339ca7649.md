# Ergänzung zu den Anweisungen

## Umgang mit IO

Anders als bei anderen Übungen erfordert `grep` die Interaktion mit der „externen Welt“: Dateien lesen, Systemfehler behandeln und auf `stdout` schreiben.

In Lean interagierst du normalerweise über die [IO][io]-Monade mit dem System. Sie erlaubt Seiteneffekte in einer gekapselten Umgebung, ohne den reinen Zustand der meisten anderen Funktionen zu beeinflussen.

## Argumente lesen

In Lean kannst du eine Datei als Skript aufrufen, entweder direkt als eigenständiges Skript über `lean --run` oder mithilfe von `lake`.

Ein Lean-Projekt hat genau einen Einstiegspunkt, eine Funktion namens `main`, die eine `List String` mit allen übergebenen Argumenten entgegennimmt.
Um den Aufruf von `Grep.lean` als ausführbares Programm zu simulieren, werden die Argumente in dieser Übung genauso übergeben.

## Dateien lesen

Lean bietet [Funktionen][files], um Dateien in der `IO.FS`-Monade zu bearbeiten.
Zum Beispiel kannst du mit `IO.FS.readFile` den Inhalt einer Datei unter einem gegebenen Pfad als `String` lesen.

## Ausgaben schreiben

Statt einen Wert zurückzugeben, verlangt diese Übung, dass die Ergebnisse auf die Standardausgabe oder die Standardfehlerausgabe geschrieben werden.
In Lean gibt es dafür [Funktionen][console].

## Systemfehler behandeln

Anders als Fehler in `Except` sind `IO`-Ausnahmen tatsächlich Laufzeitausnahmen.
Du kannst `try`/`catch` verwenden, um sie zu behandeln:

```
try
    /- 
        code that may possibly raise an exception 
    -/
catch msg =>
    /-
        code that is executed only if an exception was thrown
    -/
```
