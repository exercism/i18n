# Anleitung

Du betreibst eine Online-Modeboutique. Dein großer jährlicher Ausverkauf steht kurz bevor, also möchtest du eine Funktion erstellen, die dir hilft, deinen Lagerbestand zu überprüfen, damit du sicher sein kannst, dass du vorbereitet bist.

Ein einzelner Artikel im Lager wird durch einen Hash dargestellt, und das gesamte Lager ist ein Array dieser Hashes.

```ruby
[
  {
    name: "White Shirt",
    price: 40,
    quantity_by_size: {s: 3, m: 7, l: 8, xl: 4}
  },
  { ... }
]
```

## 1. Gib eine Liste der Namen der Artikel zurück

Implementiere `BoutiqueInventory.item_names`, die eine Liste der Artikelnamen in alphabetischer Reihenfolge zurückgeben soll.

```ruby
BoutiqueInventory.new([
  {price: 65.00, name: "Maxi Brown Dress", quantity_by_size: {s: 3, m: 7, l: 8, xl: 4}},
  {price: 50.00, name: "Red Short Skirt", quantity_by_size: {}},
  {price: 29.99, name: "Black Short Skirt", quantity_by_size: {s: 1, xl: 4}},
  {price: 20.00, name: "Bamboo Socks Cats", quantity_by_size: {s: 7, m: 2}}
]).item_names

#=> ["Bamboo Socks Cats", "Black Short Skirt", "Maxi Brown Dress", "Red Short Skirt"]
```

## 2. Gib alle Artikel zurück, die günstig sind

Implementiere `BoutiqueInventory.cheap`, die alle Artikel zurückgeben soll, die weniger als 30 $ kosten.

```ruby
BoutiqueInventory.new([
  {price: 65.00, name: "Maxi Brown Dress", quantity_by_size: {s: 3, m: 7, l: 8, xl: 4}},
  {price: 50.00, name: "Red Short Skirt", quantity_by_size: {}},
  {price: 29.99, name: "Black Short Skirt", quantity_by_size: {s: 1, xl: 4}},
  {price: 20.00, name: "Bamboo Socks Cats", quantity_by_size: {s: 7, m: 2}}
]).cheap

# => [
#      {price: 29.99, name: "Black Short Skirt", quantity_by_size: {s: 1, xl: 4}},
#      {price: 20.00, name: "Bamboo Socks Cats", quantity_by_size: {s: 7, m: 2}}
#    ]
```

## 3. Gib alle Artikel zurück, die nicht auf Lager sind

Implementiere `BoutiqueInventory.out_of_stock`, die alle Artikel zurückgeben soll, die keinen Bestand haben (bei denen `quantity_by_size` leer ist).

```ruby
BoutiqueInventory.new([
  {price: 65.00, name: "Maxi Brown Dress", quantity_by_size: {s: 3, m: 7, l: 8, xl: 4}},
  {price: 50.00, name: "Red Short Skirt", quantity_by_size: {}},
  {price: 29.99, name: "Black Short Skirt", quantity_by_size: {s: 1, xl: 4}},
  {price: 20.00, name: "Bamboo Socks Cats", quantity_by_size: {s: 7, m: 2}}
]).out_of_stock

#=> [{price: 50.00, name: "Red Short Skirt", quantity_by_size: {}}]
```

## 4. Gib den Bestand eines einzelnen Artikels zurück

Implementiere `BoutiqueInventory.stock_for_item(name)`, um den Bestand eines Artikels anhand seines Namens zurückzugeben:

```ruby
BoutiqueInventory.new([
  {price: 65.00, name: "Maxi Brown Dress", quantity_by_size: {s: 3, m: 7, l: 8, xl: 4}},
  {price: 50.00, name: "Red Short Skirt", quantity_by_size: {}},
  {price: 29.99, name: "Black Short Skirt", quantity_by_size: {s: 1, xl: 4}},
  {price: 20.00, name: "Bamboo Socks Cats", quantity_by_size: {s: 7, m: 2}}
]).stock_for_item("Black Short Skirt")

#=> {s: 1, xl: 4}
```

## 5. Gib den Gesamtbestand zurück

Implementiere `BoutiqueInventory.total_stock`, um die Gesamtzahl der Artikel in deinem Lager zu berechnen:

```ruby
BoutiqueInventory.new([
  {price: 65.00, name: "Maxi Brown Dress", quantity_by_size: {s: 3, m: 7, l: 8, xl: 4}},
  {price: 50.00, name: "Red Short Skirt", quantity_by_size: {}},
  {price: 29.99, name: "Black Short Skirt", quantity_by_size: {s: 1, xl: 4}},
  {price: 20.00, name: "Bamboo Socks Cats", quantity_by_size: {s: 7, m: 2}}
]).total_stock

#=> 36
```
