# Ergänzende Anleitung

## Track-spezifische Anleitung

Du musst zwei Verben namens `allergic_to` und `list` definieren.

## Eingaben

1. Das Verb `allergic_to` ist ein **dyad**, wobei:

    - **Linkes Argument**: ist ein String, der den Namen des Allergens enthält.
    - **Rechtes Argument**: ist die erreichte Punktzahl.

1. Das Verb `list` ist ein **monad**, wobei:

    - Das einzige Argument ist die erreichte Punktzahl.

Deine Verben werden mit diesen Argumenten so aufgerufen:

```j
  'cats' allergic_to 255
  list 5
```

## Ausgaben

Die Ausgabe des Verbs `allergic_to` ist ein **boolescher Wert**

Die Ausgabe von `list` ist eine **Liste von Boxen**
