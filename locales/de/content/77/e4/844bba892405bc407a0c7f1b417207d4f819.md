# Einführung

Konstanten in Gleam sind eine Möglichkeit, Werten Namen zu geben. Sie werden mit dem Schlüsselwort `const` definiert.

```gleam
pub const pi: Float = 3.14159

pub fn circle_area(radius: Float) -> Float {
  radius *. radius *. pi
}
```

Wenn sie mit dem Schlüsselwort `pub` definiert werden, kann aus anderen Modulen auf die Modulkonstanten zugegriffen werden. Andernfalls kann nur aus dem Modul auf sie zugegriffen werden, in dem sie definiert sind.
