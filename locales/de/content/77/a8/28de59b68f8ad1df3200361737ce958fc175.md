# Ergänzung zu den Anweisungen

## Implementierung

Du kannst `collect(1:10)` als schnelle Möglichkeit nutzen, eine Collection zu erzeugen, aber denk daran, dass collect unter der Haube ein Array zurückgibt. Du kannst also auch einfach ein Array explizit anlegen, indem du `my_array = [1, 2, 3, 4, 5]` schreibst.
