# Einführung

Ausnahmen in C# bieten eine strukturierte, einheitliche und typsichere Möglichkeit, mit Fehlerbedingungen umzugehen, die zur Laufzeit auftreten. Der richtige Umgang mit Ausnahmen und Fehlern ist wichtig, wenn man Abstürze der Anwendung verhindern will.

In C# haben alle Ausnahmen die Klasse `System.Exception` als Basistyp. Sie enthält wichtige Eigenschaften wie `Message`, die eine für Menschen lesbare Beschreibung des Grundes enthält, aus dem die Ausnahme ausgelöst wurde.

Um zu signalisieren, dass an einer bestimmten Stelle im Code ein Fehler auftreten soll, muss ein neues Ausnahmeobjekt erstellt und dann mit dem Schlüsselwort `throw` ausgelöst werden:

```csharp
using System;
static int Square(int number)
{
    if (number >= 46341)
    {
        throw new ArgumentException($"Argument {number} cannot be higher than 46340 as its' square doesn't fit into int type.");
    }
    return number * number;
}
```

Wenn eine Ausnahme ausgelöst wird, hat die Laufzeit die Aufgabe, eine Stelle im Code zu finden, die für die Behandlung dieser Ausnahme zuständig ist. Wird kein passender Handler gefunden, zeigt die Laufzeit die Meldung über die unbehandelte Ausnahme an und stoppt zusätzlich die Ausführung des Programms.

Um einen Handler für eine Ausnahme zu erstellen, verwendet C# die try-catch-Anweisung, die aus einem `try`-Block und einer oder mehreren `catch`-Klauseln besteht. Der `try`-Block sollte den Code enthalten und absichern, der dazu führen kann, dass die Ausnahme ausgelöst wird. Die `catch`-Klauseln sollten den Code enthalten, der das Verhalten des Programms nach dem Auftreten des Fehlers regelt. Wichtig ist, dass die Reihenfolge der Ausnahmen nach dem `try`-Block eine Rolle spielt: Werden mehrere Ausnahmen aufgeführt, wird die erste passende `catch`-Klausel ausgeführt.

```csharp
try
{
   if (number == 42)
   {
       throw new ArgumentException("The number cannot be equal to 42.", "number");
   }

   if (number < 0)
   {
      throw new ArgumentOutOfRangeException("number", "The number cannot be negative.");
   }

    // Process number ...
}
catch (ArgumentOutOfRangeException e)
{
    Console.WriteLine($"Number is out of range: {e.Message}.");
}
catch (ArgumentException)
{
    Console.WriteLine("Invalid number.");
}
```
