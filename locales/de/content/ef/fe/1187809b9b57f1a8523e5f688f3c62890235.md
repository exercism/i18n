# Einführung

Swift bietet einen eingebauten Typ namens [`Bool`][bools], um Wahrheitswerte darzustellen: `true` und `false`.

## Logische Operatoren

Swift bietet drei [logische Operatoren][logical-operators] (`!`, `&&` und `||`), um boolesche Ausdrücke zu kombinieren und auszuwerten.

### Logisches UND (`&&`)

Der [_und_-Operator][and] (`&&`) gibt nur dann `true` zurück, wenn beide Operanden `true` sind.
Ist einer der Operanden `false`, gibt er `false` zurück.
Setze einen Ausdruck oder einen booleschen Wert auf jede Seite des `&&`-Symbols:

```swift
true && true  // true
true && false // false
```

### Logisches ODER (`||`)

Der [_oder_-Operator][or] (`||`) gibt `true` zurück, wenn **mindestens einer** der Operanden `true` ist.
Er gibt nur dann `false` zurück, wenn beide Operanden `false` sind.
Setze einen Ausdruck oder einen booleschen Wert auf jede Seite des `||`-Symbols:

```swift
true || true   // true
true || false  // true
false || false // false
```

### Logisches NICHT (`!`)

Der [_nicht_-Operator][not] (`!`) invertiert einen booleschen Wert.
Er gibt `true` zurück, wenn der Wert `false` ist, und `false`, wenn der Wert `true` ist.
Setze den `!`-Operator direkt vor den Wert oder Ausdruck:

```swift
!true  // false
!false // true
```

## Runde Klammern verwenden (`()`)

Du kannst [runde Klammern][explicit-parentheses] verwenden, um Ausdrücke zu gruppieren und die Reihenfolge der Auswertung zu steuern.
In Swift werden Ausdrücke in Klammern zuerst ausgewertet:

```swift
true && false && false || true   // true
true && false && (false || true) // false
```

Die Gruppierung mit Klammern bestimmt auch, wie der NICHT-Operator auf komplexe Ausdrücke angewendet wird:

```swift
!true && false   // false (evaluates (!true) first, then false && false)
!(true && false) // true  (evaluates (true && false) first to false, then !false)
```

~~~~exercism/note
Verwende Klammern, wenn du die Auswertungsreihenfolge klären oder komplexe Bedingungen lesbarer machen möchtest.
Vermeide unnötige Klammern, wenn die Standardrangfolge bereits klar ist.
~~~~
