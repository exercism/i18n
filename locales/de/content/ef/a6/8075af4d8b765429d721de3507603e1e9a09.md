# Übungen mit dem Online-Editor lösen

Wenn du Übungen online mit dem Online-Editor der Website löst, kannst du schnell mit einem Track loslegen.
Mit dem Online-Editor musst du nichts auf deinem Rechner installieren, alles läuft im Browser (auch das Ausführen der Tests).

## Die Übung lösen

Das Ziel jeder Übung ist eine Implementierung, die alle Tests besteht.
Eine solche Implementierung nennt man eine _Lösung_.

Um damit anzufangen, geh auf die Website, tritt einem Track bei und öffne die Seite der Übung.
Dort kannst du auf den Button „Open in editor“ klicken.
Damit öffnet sich der Online-Editor, der dir die folgenden Informationen zeigt:

- Auf der linken Seite befindet sich der Editor, in dem du deine Lösung schreibst
- Auf der rechten Seite stehen die Anweisungen, die erklären, was von dir erwartet wird

Dann kannst du mit dem Schreiben deiner Lösung beginnen.

Wenn du auf den Button „Run Tests“ klickst, wird geprüft, ob deine Lösung die Tests der Übung besteht.
Sobald die Tests gelaufen sind, werden die Testergebnisse rechts angezeigt.

### Debuggen

Der Online-Editor hat keinen integrierten Debugger.
Einige Tracks unterstützen Debugging über Ausgaben, bei dem dein Code Text ausgeben kann, der in den Ergebnissen angezeigt wird.
Wenn ein Track das unterstützt, werden rechts Anweisungen angezeigt, wie du diese Funktion verwendest.

## Deine Lösung einreichen

Sobald deine Lösung alle Tests besteht, kannst du sie mit dem Button „Submit“ einreichen.
