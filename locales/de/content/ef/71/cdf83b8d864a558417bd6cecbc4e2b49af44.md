# Debug

Der aktuelle Test-Runner nutzt [PonyTest](https://stdlib.ponylang.io/pony_test--index/), deshalb liegt der Main-Actor in test.pony und sollte nicht als Teil deiner Lösung geändert werden.

Wie es in Pony-Anwendungen bewährte Praxis ist, stellen wir keinen Zugang zu `Env` bereit, außer wenn er gebraucht wird. Das bedeutet, dass du in fast allen Fällen kein printf-Debugging mit `env.out.print()` verwenden kannst.

Allerdings hat Pony ein [debug](https://stdlib.ponylang.io/debug--index/)-Modul, das Programmen, die mit dem `-d`-Flag kompiliert wurden, einen besonderen Zugriff auf STDOUT und STDERR ermöglicht, ohne Zugriff auf `Env`.

Wenn du printf-Debugging brauchst, solltest du diese Funktionalität nutzen.

Debug-Beispiel:

```pony
use "debug"

actor Main
  new create(env: Env) =>
    MySolution.examplefn("First String", 42)

primitive MySolution
  fun examplefn(arg1: String, arg2: USize) =>
    Debug.out("arg1: " + arg1 + ", arg2: " + arg2.string() + " were provided to MySolution.examplefn()")
```
