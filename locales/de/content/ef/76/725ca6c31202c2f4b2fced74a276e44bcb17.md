# Anhang zu den Anweisungen

## Track-spezifische Anweisungen

Historisch gesehen verwendete Elm funktionale reaktive Programmierung, bis es sich auf die Elm-Architektur spezialisierte.

Löse diese Übung so, als würdest du eine Web-App mit der Elm-Architektur schreiben.
Das Programm soll HTML mit der folgenden Struktur ausgeben

```html
<div>
  <dl>
    <dt>State</dt>
    <dd>Ongoing</dd>
    <dt>Word</dt>
    <dd>______</dd>
    <dt>Remaining failures</dt>
    <dd>5</dd>
  </dl>
</div>
```

wobei `<dl>` das Element für die Beschreibungsliste ist, `<dt>` das Element für den Beschreibungsbegriff und `<dd>` das Element für die Beschreibungsdetails, alles Standard-HTML-Elemente.

Wenn ein Fehler auftritt, soll die Ausgabe die folgende Struktur haben

```html
<div>
  <p>error message</p>
</div>
```
