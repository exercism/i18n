# Einführung

## Vergleiche

In C++ kannst du Werte mit den Vergleichsoperatoren vergleichen.

| Vergleich         | Operator  |
| ------------------| --------- |
| gleich            | `==`      |
| ungleich          | `!=`      |
| kleiner           | `<`       |
| kleiner oder gleich | `<=`    |
| größer            | `>`       |
| größer oder gleich | `>=`     |

Das Ergebnis dieser Vergleiche ist immer ein boolescher Wert:

```cpp
int a{3};

bool eq1 = a != 4; // true

bool eq2 = a > 5;  // false
```

Die Operatoren `==` und `!=` prüfen, ob ein Wert gleich einem anderen ist oder nicht.
Hier sind einige gängige Beispiele:

```cpp
bool eq3 = 2 == 3; // false, integer comparison

bool eq4 = 2.1 != 2.2; // true, float comparison

bool eq5 = "hello" == "hello"; // true, string comparison
```

Die anderen Operatoren prüfen, ob ein Wert größer als (`>`), größer oder gleich (`>=`), kleiner als (`<`) oder kleiner oder gleich (`<=`) einem anderen Wert ist.
Diese Art des Vergleichs gibt es für Zahlen und Strings.
Beim Vergleichen von Strings wird die Wörterbuchordnung (auch lexikografische Ordnung genannt) verwendet.

```cpp
bool eq6 = 2 > 3; // false, integer comparison

bool eq7 = 1.2 < 1.3; // true, float comparison

bool eq8 = "Hello" < "World"; // true, string comparison
```

## if-Anweisungen

Bedingte Anweisungen in C++ ähneln denen in anderen Sprachen.
Der zugrunde liegende Typ jeder bedingten Operation ist der Typ `bool`, der den Wert `true` oder `false` annehmen kann.
Bedingte Anweisungen werden oft als Ablaufsteuerung verwendet, um verschiedene Bedingungen zu prüfen.

Du kannst eine `if`-Anweisung verwenden, die ihren Code ausführt, wenn die zugrunde liegende Bedingung `true` ist, etwa so:

```cpp
std::string value{"val"};

if (value == "val") {
    return "was val";
}
```

Wenn mehr als ein Fall abgedeckt werden muss, kannst du viele `if`-Anweisungen mit den `else if`- und `else`-Anweisungen verketten.

```cpp
int number{33};

if (number > 0) {
   return "positive";
} else if (number < 0) {
    return "negative";
} else {
   return "zero";
}
```

Seit C++17 können if-Anweisungen auch eine kurze Initialisierungsanweisung enthalten, mit der du eine oder mehrere Variablen für die if-Anweisung initialisieren kannst.
Zum Beispiel:

```cpp
int num{7};
if (int v{2 * num}; v > 10) {
    return v;
} else {
    return num;
}
// => 14
```

> Hinweis: Auf Variablen, die in der Initialisierung erstellt wurden, kannst du nach dem Ende der if-Anweisung nicht mehr zugreifen.
