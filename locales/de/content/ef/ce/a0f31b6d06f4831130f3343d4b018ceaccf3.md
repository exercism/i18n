# Bools

Crystal hat einen Typ, der [`Bool`][bools] heißt.
Er repräsentiert die Werte `true` und `false`.

## Logische Operatoren

Crystal hat drei logische Operatoren (`!`, `||`, `&&`), die Bools kombinieren und Ausdrücke erzeugen, die unterschiedliche Werte liefern.

### Und(`&&`)

Der [_Und_-Operator][and] in Crystal wird durch `&&` dargestellt und gibt `true` zurück, wenn beide Werte `true` sind; andernfalls gibt er `false` zurück.
Bei der Verwendung des _Und_-Operators wird ein Bool auf die rechte Seite des `&&` gesetzt und ein weiteres auf die linke Seite.

```crystal
true && true
# => true

true && false
# => false
```

### Oder(`||`)

Der [_Oder_-Operator][or] in Crystal wird durch `||` dargestellt und gibt `true` zurück, wenn **mindestens einer** der angegebenen Werte `true` ist. 
Wenn beide Werte `false` sind, gibt er `false` zurück.
Bei der Verwendung des _Oder_-Operators sollte ein Bool auf die rechte Seite des `||` gesetzt werden und ein weiteres auf die linke Seite.

```crystal
true || true
# => true

true || false
# => true

false || false
# => false
```

### Nicht(`!`)

Der _Nicht_-Operator in Crystal wird durch `!` dargestellt und gibt `true` zurück, wenn der gegebene Bool `false` ist, und gibt `false` zurück, wenn `true` angegeben wird.
Bei der Verwendung des _Nicht_-Operators sollte ein Bool nach dem Operator (`!`) platziert werden.

```crystal
!true
# => false

!false
# => true
```

## Verwendung von Klammern (`()`)

Wenn du mit booleschen Werten arbeitest, kannst du Klammern verwenden, um zu entscheiden, welche Bools zuerst ausgewertet werden.
Das Ergebnis kann sich je nach Verwendung der Klammern unterscheiden.
In Crystal wird zuerst ausgewertet, was in Klammern steht.

```crystal
true && false && false || true
# => true

true && false && (false || true)
# => false
```

Da zuerst ausgewertet wird, was in Klammern steht, wird der _Nicht_-Operator im folgenden Beispiel auf den Ausdruck innerhalb der Klammern angewendet.

```crystal
!true && false
# => false

!(true && false)
# => true
```

~~~~exercism/note
Du solltest Klammern nur verwenden, wenn sie das Ergebnis beeinflussen; andernfalls sollten sie weggelassen werden.
~~~~

## Truthy und Falsey

In Crystal sind die „falsey“-Werte: `false`, `nil` und Null-Zeiger; **alles andere** ist „truthy“.
Diese Werte können mit den oben genannten logischen Operatoren verwendet werden.

```crystal

true && nil
# => false

false && 4
# => false

true || nil
# => true
```

## Namenskonventionen für Methoden mit booleschen Werten

In Crystal ist es üblich, eine Methode, die einen truthy- oder falsey-Wert zurückgibt, mit einem Fragezeichen (`?`) zu benennen.
In den meisten Fällen gibt diese Methode einen Bool-Wert zurück, aber das muss nicht sein.
Das bedeutet, dass die Methode an Stellen verwendet werden kann, an denen ein truthy- oder falsey-Wert erwartet wird, zum Beispiel als Bedingung für eine `if`-Anweisung:

```crystal
def exchange(value)
    if value.nil?
        value = 5
    end
    value
end

exchange(10)
# => 10

exchange(nil)
# => 5
```

Methoden mit einem Fragezeichen am Ende ihres Namens, die keinen Bool-Wert zurückgeben, geben oft stattdessen `nil` zurück. `nil` ist _ähnlich wie `None` oder `null` aus anderen Sprachen_.
