# Überblick

In Common Lisp ist alles ein Ausdruck.
Ein Ausdruck ist entweder eine einzelne Sache (ein Atom) oder eine Liste von Dingen (eingeschlossen in runde Klammern: `()`).

## Quotierung

Alle S-Ausdrücke, etwa Symbole, lassen sich quotieren:

```lisp
;; This line is evaluated as code
(gimme-foo)  ; => FOO

;; This line is treated as data
'(gimme-foo) ; => (GIMME-FOO)
```

Diese Quotierung verhindert die Auswertung eines S-Ausdrucks und behandelt ihn stattdessen wie Daten.
Hier ist eine hervorragende [Antwort auf Stack Overflow][so-quoting], die das Quotieren etwas genauer erklärt.

[so-quoting]: https://stackoverflow.com/questions/134887/when-to-use-or-quote-in-lisp
