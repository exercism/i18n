## Paare

Ein `Pair` ist eine Datenstruktur, die genau zwei Elemente enthält, auf die man über die Felder `first` und `second` zugreifen kann.

Sie lassen sich mit `x => y` konstruieren:

```julia-repl
julia> p = 3 => true
3 => true

julia> p.first
3

julia> p.second
true
```

Die Elemente eines `Pair` können von unterschiedlichem Typ sein:

```julia-repl
julia> typeof(p)
Pair{Int64,Bool}
```

`Pair`s haben in Julia zwei häufige Verwendungen: Wörterbücher und Ersetzungen.

### Ersetzungen

Viele Ersetzungsmethoden nehmen ein `Pair` als Argument, um klarzumachen, welches Element ersetzt wird.
Das ermöglicht Syntax wie

```julia-repl
julia> replace!([1, 3, 4, 1], 4 => 0)
4-element Array{Int64,1}:
 1
 3
 0
 1
```

wobei jedes `4` in der Sammlung durch `0` ersetzt wird, statt der weniger klaren Syntax

```julia
replace!([1, 3, 4, 1], 4, 0) # this method doesn't exist
```
