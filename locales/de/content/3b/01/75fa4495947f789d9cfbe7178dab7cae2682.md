# Anleitung

Daphne hat an einem System gearbeitet, mit dem sie ihre Experimente ausführen und die Ergebnisse aufzeichnen kann. Ein Teil des Codes ist etwas umständlich und repetitiv geworden, deshalb hat sie dich gebeten, ein paar `use`-Ausdrücke zu schreiben, die beim Aufräumen helfen.

## 1. Definiere die `with_retry`-Funktion

Manchmal können Experimente wegen eines einmaligen Fehlers fehlschlagen. Wenn ein Experiment fehlschlägt, möchte Daphne es noch einmal versuchen, um zu sehen, ob es beim zweiten Mal klappt.

Definiere die `with_retry`-Funktion, die eine Funktion, die ein Ergebnis zurückgibt, als Argument entgegennimmt.

Wenn die Funktion einen `Ok`-Wert zurückgibt, soll `with_retry` diesen Wert zurückgeben.

Wenn die Funktion einen `Error`-Wert zurückgibt, soll `with_retry` die Funktion erneut aufrufen und das Ergebnis dieses Aufrufs zurückgeben.

So wird Daphne die Funktion verwenden:

```gleam
pub fn main() {
  use <- with_retry
  // Perform the experiment here
}
```

## 2. Definiere die `record_timing`-Funktion

Um festzuhalten, wie lange jedes Experiment läuft, ruft Daphne vor und nach jedem Experiment eine Zeitprotokollierungsfunktion auf.

Definiere die `record_timing`-Funktion, die zwei Argumente entgegennimmt:
- Eine Zeitprotokollierungsfunktion, die keine Argumente entgegennimmt und `Nil` zurückgibt.
- Eine Experimentfunktion, die keine Argumente entgegennimmt und ein Ergebnis zurückgibt.

`record_timing` soll die Zeitprotokollierungsfunktion aufrufen, dann die Experimentfunktion aufrufen, dann erneut die Zeitprotokollierungsfunktion aufrufen und schließlich das Ergebnis der Experimentfunktion zurückgeben.

So wird Daphne die Funktion verwenden:

```gleam
pub fn main() {
  use <- record_timing(time_logger)
  // Perform the experiment here
}
```

## 3. Definiere die `run_experiment`-Funktion

Experimente bestehen aus drei Phasen: dem Aufbau, der Aktion und der Aufzeichnung. Alle drei Phasen geben Ergebnisse zurück, und jede Phase braucht das erfolgreiche Ergebnis der vorherigen Phase, um zu laufen.

Definiere die `run_experiment`-Funktion, die vier Argumente entgegennimmt:
- Den Namen des Experiments als `String`.
- Eine Funktion für den Aufbau, die keine Argumente entgegennimmt und ein Ergebnis zurückgibt.
- Eine Funktion für die Aktion, die den `Ok`-Wert der Funktion für den Aufbau als Argument entgegennimmt und ein Ergebnis zurückgibt.
- Eine Funktion für die Aufzeichnung, die die `Ok`-Werte der Funktionen für den Aufbau und die Aktion als Argumente entgegennimmt und ein Ergebnis zurückgibt.

Wenn alle drei Funktionen erfolgreich sind, soll `run_experiment` `Ok(#(experiment_name, recording_data))` zurückgeben.

Wenn eine der Funktionen einen `Error`-Wert zurückgibt, soll `run_experiment` diesen Wert zurückgeben.

So wird Daphne die Funktion verwenden:

```gleam
pub fn main() {
  use setup_data, action_data <- run_experiment("Test 1", setup, action)
  // Record the results here
}
```
