# Hinweise

## Allgemein

- Der Code in den Familien-Namespaces sollte als „gegeben“ betrachtet und nicht verändert werden.
- Kopiere die Werte nicht in deinen Code, sondern rufe die Methoden auf.

## 1. Nimm deinen Platz vor den Familien ein und lege deine Papiere aus

- Der Namespace muss `EstateExecutor` heißen, damit deine Lösung die Tests besteht.

## 2. Finde die geheime Kontonummer

- Jedes `bank_number_part` muss mit dem `secret_modifier` aus der Parameterliste aufgerufen werden.

## 3. Letzter Schritt: Gib den geheimen Code ein

- Du kannst Methoden aus verschachtelten Namespaces so aufrufen: `OuterNamespace::InnerNamespace::my_method`.

- Achte darauf, die blauen und die roten Fragmente getrennt zu addieren, bevor du beide Teile multiplizierst.
