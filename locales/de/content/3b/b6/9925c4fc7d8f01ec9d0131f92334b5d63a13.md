# Empfohlene Lernressourcen

Exercism bietet Übungen und Feedback, aber der Einstieg kann schwierig sein, wenn du zum ersten Mal ABAP lernst. Diese kostenlosen Ressourcen helfen dir beim Start:

* SAP Learning Journey [Learning the Basics of ABAP Programming](https://learning.sap.com/courses/learn-the-basics-of-abap-programming-on-sap-btp)
* [ABAP for Newbies Community](https://pages.community.sap.com/topics/abap/abap-for-newbies)
* [ABAP Language Documentation](https://help.sap.com/doc/abapdocu_latest_index_htm/latest/en-US/index.htm)
* [ABAP Starter](https://github.com/Keller-Michael/ABAP_starter)
* [ABAP Cheat Sheets](https://github.com/SAP-samples/abap-cheat-sheets)

Wenn du neu bei ABAP bist, empfehlen wir dir, die folgenden Einheiten der SAP Learning Journey abzuschließen:

- Getting Started
- ABAP Language Basics
- Local Classes 

Danach bist du bereit, ABAP-Übungen auf Exercism zu lösen.

Wenn du zu komplexeren Übungen kommst, empfehlen wir dir zusätzlich, die folgenden Einheiten durchzugehen:

- Structures
- Complex Internal Tables

Diese Themen können dir helfen, schwierigere Übungen auf Exercism zu lösen.
