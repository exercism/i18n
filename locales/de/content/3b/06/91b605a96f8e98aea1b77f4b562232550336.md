# Case-Anweisungen

```sather
   case zone
   when 0 then return 0;
   when 1, 2 then return 550;
   else return 920;
   end;
```

## Wie der Abgleich funktioniert

Der Wert nach `case` wird von oben nach unten mit jedem `when`-Wert mithilfe von `=` verglichen. Der erste Treffer wird ausgeführt, und nur dieser. Die übrigen `when`-Teile werden übersprungen, und die Ausführung läuft nach dem `end` weiter.

Jeder Typ, der `=` unterstützt, kann verwendet werden: `INT`, `CHAR`, `STR`, `BOOL`.

## Das else

Ein `case` ohne Treffer und ohne `else` löst zur Laufzeit einen fatalen Fehler aus. Schreib immer eins. Wenn die übrigen Fälle wirklich nicht eintreten sollten, sag das dort, statt es wegzulassen:

```sather
   else
      raise "unknown zone: " + zone;
   end;
```

`raise` kommt später; bis dahin ist es völlig in Ordnung, einen sinnvollen Standardwert zurückzugeben.

## Wann if die bessere Wahl ist

`case` vergleicht einen Wert mit Konstanten. Alles andere will `if`:

```sather
   -- ranges
   if age < 13 then ... elsif age < 16 then ... end;

   -- more than one value at a time
   if score >= 8 and sings then ... end;
```

Wenn du versuchst, einen Bereich in ein `case` zu zwängen, kommt etwas Längeres und Schlechteres dabei heraus als das `if`, das es ersetzt hat.

## Case als Ausdruck

`case` ist eine Anweisung, kein Ausdruck, deshalb ist das kein Sather:

```sather
   -- wrong
   fare := case zone when 1 then 550 else 920 end;
```

Gib aus jedem Zweig heraus zurück, oder weise in jedem Zweig einer Variablen etwas zu.
