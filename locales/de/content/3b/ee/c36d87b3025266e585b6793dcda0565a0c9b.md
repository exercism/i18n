# Anweisungen

Als angehende Magierin muss Elyse einige Grundlagen üben.

Sie hat einen Stapel Karten, den sie bearbeiten möchte.

Um es etwas einfacher zu machen, verwendet sie nur die Karten 1 bis 10.

Der Kartenstapel wird durch ein `Array` dargestellt, wobei sich das untere Ende des Stapels vorne im Array und das obere Ende hinten befindet.

## 1. Füge eine Karte oben auf den Stapel ein

Implementiere die Funktion `insert_top`, die eine Kopie des Stapels zurückgibt, wobei die angegebene neue Karte oben auf den Stapel gelegt wird.

```rust
let stack = array![5, 9, 7, 1];
insert_top(stack, 8);
// -> [5, 9, 7, 1, 8]
```

## 2. Entferne die oberste Karte vom Stapel

Implementiere die Funktion `remove_top_card`, die eine Kopie des Stapels zurückgibt, bei der die oberste Karte entfernt wurde.

Wenn der angegebene Stapel leer ist, soll der ursprüngliche Stapel unverändert zurückgegeben werden.

```rust
let stack = array![3, 2, 6, 4, 8];
remove_top_card(stack);
// -> [3, 2, 6, 4]
```

## 3. Füge eine Karte unten in den Stapel ein

Implementiere die Funktion `insert_bottom`, die eine Kopie des Stapels zurückgibt, wobei die angegebene neue Karte unten in den Stapel gelegt wird.

```rust
let stack = array![5, 9, 7, 1];
insert_bottom(stack, 8);
// -> [8, 5, 9, 7, 1]
```

## 4. Entferne eine Karte vom unteren Ende des Stapels

Implementiere die Funktion `remove_bottom_card`, die eine Kopie des Stapels zurückgibt, bei der die unterste Karte entfernt wurde.

Wenn der angegebene Stapel leer ist, soll der ursprüngliche Stapel unverändert zurückgegeben werden.

```rust
let stack = array![8, 5, 9, 7, 1];
remove_bottom_card(stack);
// -> [5, 9, 7, 1]
```

## 5. Überprüfe die Größe des Stapels

Implementiere die Funktion `check_size_of_stack`, die überprüft, ob die Größe des Stapels gleich dem angegebenen `stack_size` ist oder nicht.

```rust
let stack = array![3, 2, 6, 4, 8];
check_size_of_stack(stack, 4);
// -> false
```
