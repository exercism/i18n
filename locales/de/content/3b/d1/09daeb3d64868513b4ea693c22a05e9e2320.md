# Überblick

Einer der wichtigsten Aspekte bei der Arbeit mit Zahlen in C# ist der Unterschied zwischen Ganzzahlen (Zahlen ohne Ziffern nach dem Dezimaltrennzeichen) und Gleitkommazahlen (Zahlen mit null oder mehr Ziffern nach dem Dezimaltrennzeichen).

Die beiden am häufigsten verwendeten numerischen Typen in C# sind `int` (eine 32-Bit-Ganzzahl) und `double` (eine 64-Bit-Gleitkommazahl).

```csharp
int i = 123;
double d = 54.29;
```

Sowohl Ganzzahlen als auch Gleitkommazahlen können das Zeichen `_` als _Zifferntrennzeichen_ verwenden. Das hilft dir beim Definieren großer Zahlen:

```csharp
int largeInt = 1_000_000;
// => 1000000

double largeDouble = 9_876_543.21;
// => 9876543.21
```

Für die Arithmetik verwendest du die üblichen [arithmetischen Operatoren][arithmetic-operators] (`+`, `-`, `*` usw.). Zahlen lassen sich mit den üblichen [Vergleichsoperatoren][comparison-operators] (`<`, `>=` usw.) sowie dem [Gleichheitsoperator][equality-operators] (`==`) und dem [Ungleichheitsoperator][equality-operators] (`!=`) vergleichen.

```csharp
5 * 6;
// => 30

1.2 > 0.8
// => true

2 != 4
// => true
```

Bei der Konvertierung zwischen numerischen Typen gibt es zwei Arten von Konvertierungen:

1. Implizite Konvertierungen: Es gehen keine Daten verloren und es ist keine zusätzliche Syntax nötig.
2. Explizite Konvertierungen: Es können Daten verloren gehen und es ist eine zusätzliche Syntax in Form eines _Casts_ nötig.

Da ein `int` weniger präzise ist als ein `double`, ist die Konvertierung von einem `int` in ein `double` sicher und damit implizit. Die Konvertierung von einem `double` in ein `int` kann jedoch Datenverlust bedeuten und erfordert daher eine explizite Konvertierung.

```csharp
int i = 9;
double d = 2.66;

// Safe conversion, thus implicit conversion
double fromInt = i;

// Potentially unsafe conversion, thus explicit conversion
int fromDouble = (int)d;
```
