# Veränderbarkeit

Cairo setzt mit seinem blockchain-orientierten Design standardmäßig auf ein unveränderliches Speichermodell. Das bedeutet: Sobald ein Wert in den Speicher geschrieben wurde, kann er nicht überschrieben, sondern nur gelesen werden. Cairo bietet jedoch einen Mechanismus, um mit dem Schlüsselwort `mut` veränderbare Variablen zu erstellen. Wenn eine Variable als veränderbar deklariert wird und ihr Wert geändert wird, wird der neue Wert in eine neue Speicherzelle geschrieben und die Variable zeigt anschließend auf die neue Zelle. Dieser Mechanismus sorgt für Flexibilität und behält gleichzeitig die Vorteile der Unveränderlichkeit bei.

Im folgenden Beispiel wird `x` als unveränderbare Variable deklariert. Wenn der Wert von `x` geändert wird, gibt der Compiler einen Fehler aus.

```rust
let x = 5;
x = 2; // Error: cannot assign twice to immutable variable
```

Wir können `x` mit dem Schlüsselwort `mut` als veränderbare Variable deklarieren. So lässt sich der Wert von `x` nach der Deklaration ändern.

```rust
let mut x = 5;
x = 10;
```

Letztendlich liegt es an dir, ob du Veränderbarkeit verwendest oder nicht. Es hängt davon ab, was du in der jeweiligen Situation für am klarsten hältst.

## Konstanten

Wie unveränderbare Variablen sind Konstanten Werte, die an einen Namen gebunden sind und sich nicht ändern dürfen. Es gibt jedoch ein paar Unterschiede zwischen Konstanten und Variablen:

- Konstanten werden mit dem Schlüsselwort `const` deklariert
- Du darfst `mut` nicht zusammen mit Konstanten verwenden
- Der Typ des Werts muss immer explizit angegeben werden
- Konstanten können nur im globalen Gültigkeitsbereich deklariert werden
- Konstanten dürfen nur auf konstante Ausdrücke gesetzt werden, nicht auf das Ergebnis eines Werts, der zur Laufzeit berechnet wird

```rust
struct AnyStruct {
    a: u256,
    b: u32
}

enum AnyEnum {
    A: felt252,
    B: (usize, u256)
}

const ONE_HOUR_IN_SECONDS: u32 = 3600;
const STRUCT_INSTANCE: AnyStruct = AnyStruct { a: 0, b: 1 };
const ENUM_INSTANCE: AnyEnum = AnyEnum::A('any enum');
const BOOL_FIXED_SIZE_ARRAY: [bool; 2] = [true, false];
```

Mit dem Makro `consteval_int!` kannst du eine `const`-Variable erstellen, die das Ergebnis einer Berechnung ist.

```rust
const ONE_HOUR_IN_SECONDS: u32 = consteval_int!(60 * 60);
```

## Shadowing

Es ist möglich und oft idiomatisch, einen Variablennamen wiederzuverwenden, während ein bestimmter Wert umgewandelt wird, indem du ihn mit mehreren `let`-Aufrufen neu deklarierst. Das nennt man _Shadowing_. Tatsächlich überschattet die zweite Variable die erste und übernimmt alle Verwendungen des Variablennamens für sich, bis sie selbst überschattet wird oder der Gültigkeitsbereich endet.

```rust
fn main() {
    let s: ByteArray = "my string";
    let s: ByteArray = s + " and a shadow";
    {
        let s: ByteArray = "a nested shadow";
        println!(s); // emits "a nested shadow"
    }
    println!(s); // emits "my string and a shadow"
}
```

Mit Shadowing können wir sogar den Typ der Variable ändern und dabei denselben Variablennamen wiederverwenden.

```rust
fn main() {
    let x: u64 = 2;
    println!("x is u64, value: {}", x);               // prints "x is u64, value: 2"
    let x: ByteArray = format!("fizz");               // converts x to a ByteArray, type annotation is required
    println!("x is now ByteArray, value: \"{}\"", x); // prints 'x is now ByteArray, value: "fizz"'
}
```
