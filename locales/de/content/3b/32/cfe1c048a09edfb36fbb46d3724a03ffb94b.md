# Einführung

## Zeichenketten

Erinnere dich daran, dass `jq` dieselben Datentypen wie JSON unterstützt.
JSON beschreibt **Zeichenketten** wie folgt:

> Eine Zeichenkette ist eine Folge von null oder mehr Unicode-Zeichen, die in doppelte Anführungszeichen eingeschlossen ist und Backslash-Escapes verwendet.

### Escape-Sequenzen

Innerhalb einer Zeichenkette verwendest du das Backslash-Zeichen, um „spezielle“ Zeichen einzubetten:

- `\"` ein wörtliches Anführungszeichen,
- `\\` ein wörtlicher Backslash,
- Whitespace-Zeichen `\n`, `\t`, `\r`, `\f`, `\b`
- Unicode-Zeichen `\uAAAA`, wobei `A` eine Hexadezimalziffer ist

### Zeichenkettenlänge

Um die Anzahl der Zeichen zu ermitteln, verwende die Funktion `length`.

```sh
$ jq -cn --args  '$ARGS.positional[] | length' "Hello world!" "❄🌡🤧🤒🏥🕰😀"
12
7
```

### Teilzeichenketten

Die **Slice**-Notation kann verwendet werden, um Teilzeichenketten zu extrahieren.
Die Syntax ist `.[i:j]`.
Die zurückgegebene Teilzeichenkette hat die Länge `j - i` und liefert Zeichen von Index `i` (inklusive) bis Index `j` (exklusiv).
Jeder Index kann negativ sein; in diesem Fall zählt er vom Ende der Zeichenkette rückwärts.
Jeder Index kann weggelassen werden; in diesem Fall bezieht er sich auf den Anfang oder das Ende der Zeichenkette.
Indizes sind nullbasiert.

```jq
"abcdefghij"[3:6]   # => "def"
"abcdefghij"[3:]    # => "defghij"
"abcdefghij"[:-2]   # => "abcdefgh"
```

### Verkettung

Verwende `+`, um Zeichenketten zu verketten:

```jq
"Hello" + " " + "world!"
# => "Hello world!"
```

Verwende `add`, wenn du ein Array von Zeichenketten hast:

```jq
["Hello", " ", "world!"] | add
# => "Hello world!"
```

### Split und Join

Zum Aufteilen verwendest du die Funktion `split/1` oder den Operator `/`:

```jq
"Hello beautiful world!" | split(" ")   # => ["Hello", "beautiful", "world!"]
```

```jq
"Hello beautiful world!" / " "          # => ["Hello", "beautiful", "world!"]
```

Die Umkehrung von `split/1` ist `join/1`.

Eine Zeichenkette in ein Array von Zeichen umzuwandeln, ist oft nötig.
Es gibt zwei Möglichkeiten, dies zu tun:

1. Aufteilen an einer leeren Zeichenkette

   ```jq
   "Hi friend 😀" / ""   # => ["H","i"," ","f","r","i","e","n","d"," ","😀"]
   ```

1. `explode` in ein Array von _Codepunkten_

   ```jq
   "Hi friend 😀" | explode   # => [72,105,32,102,114,105,101,110,100,32,128512]
   ```

   `implode` ist die Umkehrung von `explode`.

### Den Index eines Teilstrings finden

Verwende die Funktion `index/1`; der Index ist nullbasiert.

```jq
"hello" | index("el")'   # => 1
```

Wenn der Teilstring nicht in der Zeichenkette enthalten ist, ist das Ergebnis `null`

```jq
"hello" | index("elk")   # => null
```

### Zeichenketten-Interpolation

Innerhalb einer Zeichenkette bettet die Sequenz `\(expression)` das _Ergebnis_ dieses Ausdrucks [in die Zeichenkette][interpolate] ein:

```jq
"The current datetime is \(now | strflocaltime("%c"))"   # => "The current datetime is Wed Nov 16 17:06:33 2022"
```

### Groß-/Kleinschreibung

Verwende die Funktionen `ascii_downcase` und `ascii_upcase`.

### Reguläre Ausdrücke

`jq` bietet umfangreiche Unterstützung für reguläre Ausdrücke: Dies wird das Thema einer späteren Lektion sein.

[interpolate]: https://jqlang.org/manual/#string-interpolation
