# Über

Die Bindung beschreibt, von wo im Code aus auf einen Bezeichner zugegriffen werden kann.
Werte, deren Gültigkeitsbereich ein Block, eine Funktion oder ein Funktionsprototyp ist, haben keine Bindung.
Das heißt, von außerhalb ihres Gültigkeitsbereichs kann nicht auf sie zugegriffen werden.
Mehr zum Gültigkeitsbereich findest du im [Konzept zum Gültigkeitsbereich](../scope/introduction.md#Introduction).

## Externe Bindung

Bezeichner mit Dateigültigkeitsbereich haben standardmäßig eine externe Bindung.
Ein Bezeichner mit externer Bindung kann aus jeder Datei des Programms aufgerufen werden.

## Interne Bindung

Ein Bezeichner mit Dateigültigkeitsbereich kann mit dem Spezifizierer `static` mit interner Bindung versehen werden.
Ein Bezeichner mit interner Bindung kann nur innerhalb seiner Datei verwendet werden.

Zum Beispiel

```c
int public_count = 0; // file scope, external linkage by default
static int private_count = 0;  // file scope, internal linkage 

// file scope, internal linkage
static void some_function()
{
    // code snipped
}

// file scope, external linkage by default
int main()
{
    // code snipped
}
```

Statische Bindung sollte nicht mit der statischen Speicherdauer verwechselt werden.
Mehr zur statischen Speicherdauer findest du im [Konzept zur Speicherdauer](https://github.com/exercism/c/blob/main/concepts/storage-class-specifiers/about.md#static-the-storage-specifier-not-to-be-confused-with-the-static-linkage-type).

Wenn ein Wert (im Gegensatz zu einer Funktion) in einer Header-Datei deklariert, aber in der Quelldatei als `static`-Bezeichner mit Dateigültigkeitsbereich und initialisiertem Wert definiert wird, ist sein initialisierter Wert von außerhalb seiner Quelldatei nicht erreichbar.
Es kann fehlerfrei kompilieren, linken und laufen, aber der Wert des Bezeichners wird der Nullwert sein, selbst wenn der Wert mit `extern` deklariert ist.
(Mehr zu `extern` findest du im [extern-Konzept](https://github.com/exercism/c/blob/main/concepts/storage-class-specifiers/about.md#extern-how-to-access-a-variable-in-another-translation-unit).)
Ein Bezeichner mit Dateigültigkeitsbereich, der in einer Quelldatei als `static` gekennzeichnet ist, sollte nicht in der zugehörigen Header-Datei deklariert werden.
