# Anhang zur Anleitung

## Register

| Register | Verwendung | Typ      | Beschreibung                             |
| -------- | ---------- | -------- | ---------------------------------------- |
| `$a0`    | Eingabe    | Adresse  | null-terminierter String aus Binärzeichen |
| `$v0`    | Ausgabe    | Ganzzahl | Dezimalwert des Eingabe-Strings          |
| `$t0-9`  | temporär   | beliebig | dient zur temporären Speicherung         |
