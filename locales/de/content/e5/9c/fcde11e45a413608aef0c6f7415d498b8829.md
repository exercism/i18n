# Überblick

In Go sind Funktionen erstklassige Werte.
Das bedeutet, dass du mit Funktionen dasselbe machen kannst wie mit allen anderen Werten: Du kannst Funktionen Variablen zuweisen, sie als Argumente an andere Funktionen übergeben oder sogar Funktionen aus anderen Funktionen zurückgeben.

Im folgenden Beispiel erzeugen wir die zwei Funktionen `engGreeting` und `espGreeting` und weisen sie der Variablen `greeting` zu:

```go
import "fmt"

func engGreeting(name string) string {
	return fmt.Sprintf("Hello %s, nice to meet you!", name)
}

func espGreeting(name string) string {
	return fmt.Sprintf("¡Hola %s, mucho gusto!", name)
}

greeting := engGreeting			// greeting is a variable of type func(string) string
fmt.Println(greeting("Alice"))	// Hello Alice, nice to meet you!

greeting = espGreeting
fmt.Println(greeting("Alice")) 	// ¡Hola Alice, mucho gusto!
```

Funktionswerte bieten die Möglichkeit, Funktionen nicht nur mit Daten, sondern auch mit Verhalten zu parametrisieren.
Im folgenden Beispiel übergeben wir Verhalten über den Parameter `greetingFunc` an die Funktion `dialog`:

```go
func dialog(name string, greetingFunc func(string) string) {
	fmt.Println(greetingFunc(name))
	fmt.Println("I'm a dialog bot.")
}

func espGreeting(name string) string {
	return fmt.Sprintf("¡Hola %s, mucho gusto!", name)
}

greeting := espGreeting
dialog("Alice", greeting)
// Output:
// ¡Hola Alice, mucho gusto!
// I'm a dialog bot.
```

Der Wert einer nicht initialisierten Variablen vom Funktionstyp ist `nil`.
Ein Aufruf eines `nil`-Funktionswerts führt daher zu einer Panik.

```go
var dutchGreeting func(string) string
dutchGreeting("Alice") // panic: call of nil function
```

Funktionswerte kannst du mit `nil` vergleichen.
Das kann nützlich sein, um unnötige Paniken im Programm zu vermeiden.

```go
var dutchGreeting func(string) string
if dutchGreeting != nil {
	dutchGreeting("Alice") // safe to call dutchGreeting
}
```

## Funktionstypen

Funktionswerte sind dank der Funktionstypen in Go überhaupt erst möglich.
Ein Funktionstyp bezeichnet die Menge aller Funktionen mit derselben Abfolge von Parametertypen und derselben Abfolge von Ergebnistypen.
Benutzerdefinierte Typen kannst du auf Basis von Funktionstypen deklarieren.
Die Funktion `dialog` aus den vorherigen Beispielen kannst du zum Beispiel so anpassen:

```go
type greetingFunc func(string) string

func dialog(name string, f greetingFunc) {
	fmt.Println(f(name))
	fmt.Println("I'm a dialog bot.")
}
```

## Anonyme Funktionen

Ein weiteres mächtiges Werkzeug, das erstklassige Funktionen ermöglichen, sind anonyme Funktionen.
Anonyme Funktionen werden an der Stelle definiert, an der sie verwendet werden, ohne einen Namen nach dem Schlüsselwort `func`.
Solche Funktionen haben Zugriff auf die Variablen der umgebenden Funktion.

Zum Beispiel:

```go
func fib() func() int {
	var n1, n2 int

	return func() int {
		if n1 == 0 && n2 == 0 {
			n1 = 1
		} else {
			n1, n2 = n2, n1 + n2
		}
		return n2
	}
}

next := fib()
for i := 0; i < N; i++ {
  fmt.Printf("F%d\t= %4d\n", i, next())
}
```

Ein Aufruf von `fib` deklariert die Variablen `n1` und `n2` und gibt eine anonyme Funktion zurück, die wiederum bei jedem Aufruf die Werte dieser Variablen ändert.
Der n-te Aufruf der anonymen Funktion gibt die n-te Zahl der Fibonacci-Folge zurück, beginnend bei 0. Die anonyme innere Funktion hat Zugriff auf die lokalen Variablen (`n1` und `n2`) der umgebenden Funktion `fib`.
So können Funktionswerte auf elegante Weise Zustand zwischen Aufrufen behalten.
Man sagt, dass die anonyme Funktion ein Closure über die Variablen `n1` und `n2` ist.
[Closures][closure] werden in der Programmierung häufig verwendet, und du wirst sehen, dass andere Sprachen sie ebenfalls unterstützen.
