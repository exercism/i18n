# Ergänzung zur Anleitung

~~~~exercism/note

In der Beschreibung oben ist von [_mathematischen Mengen_][math-sets] die Rede, aber auch davon, dass ein pythagoreisches Tripel {a, b, c} so geordnet sein _**muss**_, dass a < b < c gilt (_aufsteigende Reihenfolge_).

Dadurch ist Pythons [`set`-Typ][python-sets] für diese Übung ungeeignet, denn er ist grundsätzlich _ungeordnet_.
Gib stattdessen eine [`list`][python-list] von `list`s zurück (_z. B. `[[a, b, c]]`_).
Die Tripel selbst kannst du in beliebiger Reihenfolge erzeugen, denn die Reihenfolge der umschließenden `list` wird in den Tests ignoriert.

[math-sets]: https://en.wikipedia.org/wiki/Set_(mathematics)
[python-sets]: https://docs.python.org/3/tutorial/datastructures.html#sets
[python-list]: https://docs.python.org/3/tutorial/datastructures.html#more-on-lists
