# Anweisungen

In dieser Übung implementierst du die Quest-Logik für ein neues RPG-Spiel, das ein Freund entwickelt. Die Hauptfigur des Spiels ist Annalyn, ein mutiges Mädchen mit einem wilden und treuen Hund. Doch dann schlägt das Unglück zu: Ihre beste Freundin wurde entführt, während sie im Wald Beeren suchte. Annalyn wird versuchen, ihre beste Freundin zu finden und zu befreien, und dabei optional ihren Hund mit auf diese Quest nehmen.

Nachdem sie eine Zeit lang der Spur ihrer besten Freundin gefolgt ist, findet sie das Lager, in dem ihre beste Freundin gefangen gehalten wird. Es stellt sich heraus, dass es zwei Entführer gibt: einen mächtigen Ritter und einen gerissenen Bogenschützen.

Nachdem sie die Entführer gefunden hat, überlegt Annalyn, welche der folgenden Aktionen sie ausführen kann:

- Schneller Angriff: Ein schneller Angriff ist möglich, wenn der Ritter schläft, denn er braucht Zeit, um seine Rüstung anzulegen, und ist dadurch verwundbar.
- Spionieren: Die Gruppe kann ausspioniert werden, wenn mindestens einer von ihnen wach ist. Andernfalls ist Spionieren Zeitverschwendung.
- Gefangenen signalisieren: Der Gefangene kann mit Vogelgeräuschen signalisiert werden, wenn der Gefangene wach ist und der Bogenschütze schläft, denn Bogenschützen sind darin ausgebildet, Vogelrufe zu imitieren, sodass sie die Nachricht abfangen könnten.
- _Gefangenen befreien_: Annalyn kann versuchen, sich ins Lager zu schleichen, um den Gefangenen zu befreien.
  Das ist riskant und kann nur auf eine von zwei Arten gelingen:
  - Wenn Annalyn ihren Hund dabei hat, kann sie den Gefangenen retten, wenn der Bogenschütze schläft.
    Der Ritter hat Angst vor dem Hund, und der Bogenschütze wird keine Zeit haben, sich vorzubereiten, bevor Annalyn und der Gefangene entkommen können.
  - Wenn Annalyn ihren Hund nicht dabei hat, müssen sie und der Gefangene sehr vorsichtig sein!
    Annalyn kann den Gefangenen befreien, wenn der Gefangene wach ist und sowohl der Ritter als auch der Bogenschütze schlafen. Aber wenn der Gefangene schläft, kann er nicht gerettet werden: Der Gefangene würde durch Annalyns plötzliches Auftauchen erschrecken und den Ritter und den Bogenschützen aufwecken.

Du hast vier Aufgaben: die Logik zu implementieren, mit der du bestimmst, ob die oben genannten Aktionen verfügbar sind, basierend auf dem Zustand der drei im Wald gefundenen Charaktere und darauf, ob Annalyns Hund anwesend ist oder nicht.

## 1. Prüfe, ob ein schneller Angriff möglich ist

Implementiere die Methode `canFastAttack()`, die einen booleschen Wert entgegennimmt, der angibt, ob der Ritter wach ist. Diese Methode gibt `true` zurück, wenn basierend auf dem Zustand des Ritters ein schneller Angriff möglich ist. Andernfalls gibt sie `false` zurück:

```kotlin
val knightIsAwake = true

canFastAttack(knightIsAwake)
// => false
```

## 2. Prüfe, ob die Gruppe ausspioniert werden kann

Implementiere die Methode `canSpy()`, die drei boolesche Werte entgegennimmt, die angeben, ob der Ritter, der Bogenschütze bzw. der Gefangene wach sind. Die Methode gibt `true` zurück, wenn die Gruppe basierend auf dem Zustand der drei Charaktere ausspioniert werden kann. Andernfalls gibt sie `false` zurück:

```kotlin
val knightIsAwake = false
val archerIsAwake = true
val prisonerIsAwake = false

canSpy(knightIsAwake, archerIsAwake, prisonerIsAwake)
// => true
```

## 3. Prüfe, ob der Gefangene signalisiert werden kann

Implementiere die Methode `canSignalPrisoner()`, die zwei boolesche Werte entgegennimmt, die angeben, ob der Bogenschütze bzw. der Gefangene wach sind. Die Methode gibt `true` zurück, wenn der Gefangene basierend auf dem Zustand der beiden Charaktere signalisiert werden kann. Andernfalls gibt sie `false` zurück:

```kotlin
val archerIsAwake = false
val prisonerIsAwake = true

canSignalPrisoner(archerIsAwake, prisonerIsAwake)
// => true
```

## 4. Prüfe, ob der Gefangene befreit werden kann

Implementiere die Methode `canFreePrisoner()`, die vier boolesche Werte entgegennimmt. Die ersten drei Parameter geben an, ob der Ritter, der Bogenschütze bzw. der Gefangene wach sind. Der letzte Parameter gibt an, ob Annalyns Hund anwesend ist. Die Methode gibt `true` zurück, wenn der Gefangene basierend auf dem Zustand der drei Charaktere und der Anwesenheit von Annalyns Hund befreit werden kann. Andernfalls gibt sie `false` zurück:

```kotlin
val knightIsAwake = false
val archerIsAwake = true
val prisonerIsAwake = false
val petDogIsPresent = false

canFreePrisoner(knightIsAwake, archerIsAwake, prisonerIsAwake, petDogIsPresent)
// => false
```
