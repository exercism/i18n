# Einführung

## Allgemeine Syntax

Die for-Schleife ist eine der am häufigsten verwendeten Anweisungen, um Logik wiederholt auszuführen.
In Go besteht sie aus dem Schlüsselwort `for`, einem Header und einem Block in geschweiften Klammern, der den Schleifenblock enthält.
Der Header besteht aus drei Komponenten, die durch Semikolons `;` getrennt sind: init, condition und post.

```go
for init; condition; post {
  // loop body - code that is executed repeatedly as long as the condition is true
}
```

- Die **init**-Komponente ist Code, der nur einmal ausgeführt wird, bevor die Schleife startet.
- Die **condition**-Komponente muss ein Ausdruck sein, der zu einem booleschen Wert ausgewertet wird und steuert, wann die Schleife beendet werden soll.
  Der Code innerhalb der Schleife wird ausgeführt, solange diese Bedingung zu wahr ausgewertet wird.
  Sobald dieser Ausdruck zu falsch ausgewertet wird, werden keine weiteren Iterationen der Schleife mehr ausgeführt.
- Die **post**-Komponente ist Code, der am Ende jeder Iteration ausgeführt wird.

**Hinweis:** Anders als in anderen Sprachen stehen um die drei Komponenten des Headers keine runden Klammern `()`.
Solche Klammern einzufügen führt sogar zu einem Compilerfehler.
Die geschweiften Klammern `{ }` um den Schleifenblock sind jedoch immer erforderlich.

## For-Schleifen: ein Beispiel

Die init-Komponente legt normalerweise eine Zählvariable an, die condition-Komponente prüft, ob die Schleife fortgesetzt oder beendet werden soll, und die post-Komponente erhöht normalerweise den Zähler am Ende jeder Wiederholung.

```go
for i := 1; i < 10; i++ {
  fmt.Println(i)
}
```

Diese Schleife gibt die Zahlen von `1` bis `9` aus (einschließlich `9`).
Den Schritt legt man oft mit einer Anweisung fest, die den Zähler erhöht oder verringert, wie im Beispiel oben.
