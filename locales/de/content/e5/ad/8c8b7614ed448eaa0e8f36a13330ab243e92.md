# Tests

Führe die Tests so aus:

```shell
npm run test
```

Du kannst Jest auch im „watch“-Modus ausführen. Dann werden deine Tests automatisch erneut ausgeführt, sobald du Änderungen am Code oder am Testmodul speicherst:

```shell
npm run watch
```

## Übersprungene Tests verstehen

Die skip-Methode weist die Testsuite an, einen Test nicht auszuführen. Diese Funktion kannst du auch unter den Aliasen `it.skip(name, fn)` oder `xit(name, fn)` oder `xtest(name, fn)` verwenden.

- Warum werden sie übersprungen?

Damit sich Nutzer auf jeweils einen Test auf einmal konzentrieren können und sie einen nach dem anderen aktivieren, während sie die Lösung weiterentwickeln.

- Wie aktivierst du sie?

Ändere `xtest` in `test`.

```javascript
test("title cased phrases", () => {
  expect(Acronyms.parse("Portable Network Graphics")).toEqual("PNG");
});
```
