# Einführung

Ein *regulärer Ausdruck* (Regex) ist ein kleines Muster, das beschreibt, wie ein Text aussehen soll. Statt einen String selbst Zeichen für Zeichen zu prüfen, schreibst du die gewünschte Form einmal auf und lässt Factor den Abgleich übernehmen. Factors Regex-Tools liegen im [`regexp`][regexp]-Vokabular.

## Ein Muster schreiben

In Factor schreibst du eine Regex zwischen `R/ ` und `/`:

```factor
R/ cat/      ! the pattern that matches the letters c, a, t
```

Die meisten Zeichen in einem Muster bedeuten einfach sich selbst: `R/ cat/` passt auf den Text `cat`. Die eigentliche Stärke kommt von ein paar speziellen Bausteinen, die für *Arten* von Zeichen stehen oder dafür, *wie viele* es sind.

### Zeichenklassen: „ein Zeichen aus einer Menge“

```
\d        ! any digit, 0–9
\D        ! any NON-digit (the opposite of \d)
\s        ! any space, tab, or newline
\S        ! any NON-space character (the opposite of \s)
\w        ! a "word" character: a letter, a digit, or an underscore
\W        ! any NON-word character (the opposite of \w)
[A-Z]     ! any one capital letter A to Z
[a-z]     ! any one lowercase letter
[0-9]     ! any one digit (same as \d)
.         ! any single character at all
```

Eine Klasse passt auf genau *ein* Zeichen. `[A-Z]` passt auf `Q`, aber nicht auf `QQ`.

### Quantifizierer: „wie oft“

Setze eines davon *hinter* einen Baustein, um anzugeben, wie oft er sich wiederholen darf:

```
{4}       ! exactly 4 times
{2,5}     ! between 2 and 5 times
+         ! one or more
*         ! zero or more
?         ! zero or one (optional)
```

Also bedeutet `\d{4}` vier Ziffern in Folge und `[A-Z]+` einen oder mehrere Großbuchstaben. Zusammengesetzt beschreibt `R/ [A-Z]+-\d+/` „ein oder mehrere Großbuchstaben, einen Bindestrich, dann eine oder mehrere Ziffern“, also Text wie `SALE-2024`. Der `-` ist hier ein ganz normales Zeichen: Außerhalb von `[ ]` passt ein Bindestrich einfach auf einen Bindestrich (innerhalb einer Klasse, wie in `[A-Z]`, kennzeichnet er einen Bereich).

## Einen ganzen String abgleichen

`matches?` beantwortet die Frage: „Passt dieser *komplette* String auf das Muster?“ Das Muster muss jedes Zeichen erfassen, vom Anfang bis zum Ende:

```
matches? ( string regexp -- ? )
```

```factor
USING: regexp ;

"SALE-2024"     R/ [A-Z]+-\d+/ matches? .   ! => t
"GET SALE-2024" R/ [A-Z]+-\d+/ matches? .   ! => f   (extra text before)
"SALE-2024 NOW" R/ [A-Z]+-\d+/ matches? .   ! => f   (extra text after)
"sale-2024"     R/ [A-Z]+-\d+/ matches? .   ! => f   (lowercase letters)
```

Obwohl `SALE-2024` in `"GET SALE-2024"` steckt, sagt `matches?` trotzdem `f`: Die zusätzlichen Zeichen gehören zum String und passen nicht auf das Muster. Wenn dich nur interessiert, ob das Muster *irgendwo* vorkommt, nimm `re-contains?`: Es gibt genau dort `t` zurück, wo `matches?` `f` zurückgegeben hat.

```
re-contains? ( string regexp -- ? )
```

```factor
USING: regexp ;

"GET SALE-2024" R/ [A-Z]+-\d+/ matches? .      ! => f
"GET SALE-2024" R/ [A-Z]+-\d+/ re-contains? .  ! => t
```

## Treffer in längerem Text finden

`re-contains?` verrät dir nur, *ob* das Muster darin vorkommt. Die folgenden Wörter schauen hinein und melden, *was* gepasst hat: `all-matching-subseqs` gibt jede Stelle zurück, an der das Muster passt, als Sequenz von Strings, und `count-matches` zählt sie nur.

```
all-matching-subseqs ( string regexp -- seq )
count-matches        ( string regexp -- n )
```

```factor
USING: regexp ;

"3 cats, 12 dogs, 1 fish" R/ \d+/ all-matching-subseqs .
! => { "3" "12" "1" }            (every run of digits)

"the quick fox" R/ \S+/ all-matching-subseqs .
! => { "the" "quick" "fox" }     (every run of non-space characters)

"id_7!" R/ \w/ count-matches .   ! => 4   (i, d, _ and 7 count; ! does not)
```

## Treffer ersetzen

`re-replace` ersetzt jeden Treffer durch einen Ersatztext und gibt den neuen String zurück:

```
re-replace ( string regexp replacement -- result )
```

```factor
USING: regexp ;

"page 7 of 12" R/ \d+/ "N" re-replace .
! => "page N of N"
```

Das `regexp`-Vokabular hat noch mehr Wörter, die sich lohnen. Folge den Links für Details: [`first-match`][first-match] (nur der erste Treffer) und [`re-split`][re-split] (teilt einen String überall dort, wo das Muster passt).
