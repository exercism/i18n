# Tests

Für jedes Beispiel sind die folgenden allgemeinen Schritte nötig.

Als Erstes wechselst du in das Verzeichnis der Übung, die du bearbeiten möchtest, in
diesem Fall `bob`.

```bash
$ cd </path/to/exercism>/lfe/bob
```

Als Nächstes führst du die Tests aus.  Das Make-Ziel `test` hängt von `compile`
ab, deshalb stellst du mit `make test` sicher, dass dein Quellcode kompiliert
 wird, und führst anschließend die Tests aus.


```bash
$ make test
```

Glückwunsch! Du hast fehlschlagende Tests!!!

Lies jetzt `README.md`, um herauszufinden, was du tun musst, damit alle
deine Tests durchlaufen.


Behebe den ersten Fehler, den der Test meldet, und führe die Tests erneut aus.

```bash
$ make test
```

Mach weiter, indem du den nächsten fehlschlagenden Test in deinem Quellcode
behebst und deine Tests so lange laufen lässt, bis alle Tests bestehen.

Sobald alle deine Tests bestehen, wirf einen letzten Blick auf deinen Code im
Verzeichnis `src`, um sicherzugehen, dass du mit deinem Code zufrieden bist, und
reiche ihn zur Überprüfung ein.

Hol dir Feedback, überarbeite deine Lösung, reiche sie ein, probiere die nächste
Übung aus und wiederhole das Ganze, bis du LFE-Erleuchtung erlangst.
