# Über

Gleam stellt die Werte wahr und falsch mit dem Typ `Bool` dar. Es gibt nur zwei Werte: `True` und `False`. Diese Werte kannst du an eine Variable binden:

```gleam
let true_variable = True
let false_variable = False
```

Mit den Operatoren `&&`, `||` und `!` kannst du boolesche Werte manipulieren:

```gleam
True && True  // -> True
True && False // -> False

False || True  // -> True
False || False // -> False

!False // -> True
!True  // -> False
```

Die Operatoren `&&` und `||` verwenden die Kurzschlussauswertung. Das heißt, der Ausdruck auf der rechten Seite des Operators wird nur ausgewertet, wenn er gebraucht wird.

Jeder dieser Operatoren hat einen anderen Vorrang, wobei `!` vor `&&` und `||` ausgewertet wird. Mit geschweiften Klammern kannst du einen Teil des Ausdrucks vor den anderen auswerten:

```gleam
!True && False   // -> False
!{True && False} // -> True
```
