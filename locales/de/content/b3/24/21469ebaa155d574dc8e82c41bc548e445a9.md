# Über

Ein **Wort** ist in Factor der Name für eine Funktion. Den Datenstack und die Shuffle-Wörter hast du in `basics` kennengelernt; hier definierst du deine eigenen Wörter, die mit ihren Eingabewerten arbeiten.

```factor
: square ( x -- x*x ) dup * ;
: hello  ( -- )       "Hello, world!" print ;
: max3   ( a b c -- max ) max max ;
```

Eine Definition besteht aus `:`, einem Stack-Effekt, dem Rumpf und zum Schluss `;`. Die Namen in `( … -- … )` sind für die Leserin oder den Leser gedacht; was der Compiler prüft, ist die *Anzahl* der Eingabewerte und Ausgaben. Stimmt sie nicht, gibt es einen Fehler zur Kompilierzeit. Damit fängst du eine ganze Klasse von Fehlern ab, die in einer dynamisch typisierten Sprache ohne solche Deklarationen erst zur Laufzeit auftreten würden.

Die Rechenwörter für Ganzzahlen `+`, `-` und `*` stammen aus dem Vokabular `math` und nehmen jeweils zwei Zahlen vom oberen Ende des Stacks. Das oberste Element des Stacks ist der rechte Operand, `8 3 -` berechnet also `8 - 3`.

`CONSTANT:` definiert einen Namen für einen festen Wert. Rufst du den Namen auf, wird der Wert auf den Stack gelegt, genau wie bei jedem anderen Wort. Setze Konstanten an den Anfang der Datei, vor jedes Wort, das sie verwendet.

Der Rumpf eines Wortes kann jedes Wort aufrufen, das bereits im Gültigkeitsbereich liegt: frühere Definitionen in derselben Datei, Wörter aus importierten Vokabularen und die Konstanten, die du deklariert hast. Kleine Wörter mit genau einem Zweck zu kombinieren ist der normale Weg, ein Programm aufzubauen.

Per Konvention gilt:

- Wörter und Konstanten verwenden `lowercase-kebab-case`.
- Prädikate enden auf `?` und liefern einen booleschen Wert (`even?`, `empty?`).
- Wörter, die ihre Eingabe verändern, teilen sich oft den Namen mit der nicht verändernden Variante und unterscheiden sich nur durch den Kontext.
