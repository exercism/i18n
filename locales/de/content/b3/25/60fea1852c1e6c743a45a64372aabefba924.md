# Anleitung

In dieser Übung schreibst du etwas Code, der dir hilft, eine großartige Lasagne aus deinem Lieblingskochbuch zu kochen.

Du hast fünf Aufgaben, die sich alle mit der Zeit befassen, die du für das Kochen der Lasagne brauchst.

## 1. Definiere die erwartete Backofenzeit in Minuten

Definiere die unveränderliche Variable `expectedMinutesInOven`, die zurückgibt, wie viele Minuten die Lasagne im Backofen bleiben soll.
Sie muss exportiert werden.
Laut Kochbuch beträgt die erwartete Backofenzeit 40 Minuten:

```nim
nim> expectedMinutesInOven
40 == type int
```

## 2. Berechne die verbleibende Backofenzeit in Minuten

Implementiere die Prozedur `remainingMinutesInOven`, die die tatsächlichen Minuten, die die Lasagne schon im Backofen war, als Parameter entgegennimmt und zurückgibt, wie viele Minuten die Lasagne noch im Backofen bleiben muss. Grundlage dafür ist die erwartete Backofenzeit aus der vorherigen Aufgabe.

```nim
nim> remainingMinutesInOven(30)
10 == type int
```

## 3. Berechne die Vorbereitungszeit in Minuten

Implementiere die Prozedur `preparationTimeInMinutes`, die die Anzahl der Schichten, die du der Lasagne hinzugefügt hast, als Parameter entgegennimmt und zurückgibt, wie viele Minuten du für die Vorbereitung der Lasagne gebraucht hast. Dabei gehst du davon aus, dass du für jede Schicht 2 Minuten Vorbereitung brauchst.

```nim
nim> preparationTimeInMinutes(2)
4 == type int
```

## 4. Berechne die gesamte Arbeitszeit in Minuten

Implementiere die Prozedur `totalTimeInMinutes`, die zwei Parameter entgegennimmt: Der Parameter `numberOfLayers` ist die Anzahl der Schichten, die du der Lasagne hinzugefügt hast, und der Parameter `actualMinutesInOven` ist die Anzahl der Minuten, die die Lasagne schon im Backofen war.
Die Prozedur soll zurückgeben, wie viele Minuten du insgesamt mit dem Kochen der Lasagne verbracht hast. Das ist die Summe aus der Vorbereitungszeit und der Zeit, die die Lasagne im Moment im Backofen war.

```nim
nim> totalTimeInMinutes(3, 20)
26 == type int
```
