# Hinweise

## Allgemeines

- Ändere den Code in den Namespaces der Familien nicht.
- Kopiere die Werte nicht in deinen Code, sondern rufe die Funktionen auf.

## 1. Nimm Platz vor den Familien und breite deine Unterlagen aus

- Der Namespace muss `estate_executor` heißen, damit die Tests funktionieren.

## 2. Finde die geheime Kontonummer

Jeder `bank_number_part` muss mit dem `secret_modifier` aus der Parameterliste aufgerufen werden.

## 3. Letzter Schritt: Gib den geheimen Code ein

- Du kannst Funktionen aus verschachtelten Namespaces so aufrufen: `outer_namespace::inner_namespac::my_function`.

- Achte darauf, die blauen und die roten Fragmente einzeln zu addieren, bevor du beide Teile multiplizierst.
