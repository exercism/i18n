# Überblick

Der Gültigkeitsbereich eines Werts bezieht sich darauf, wo im Programm auf diesen Wert zugegriffen werden kann.

## Die vier Arten von Gültigkeitsbereichen: Block; Funktion; Funktionsprototyp; Datei

### Blockgültigkeitsbereich

Auf einen Wert mit Blockgültigkeitsbereich kann nur innerhalb des Blocks zugegriffen werden, in dem er definiert ist.
Mehr über Blöcke erfährst du im [Blockkonzept](../blocks/introduction.md#Introduction).

### Funktionsgültigkeitsbereich

Der Funktionsgültigkeitsbereich ist eine besondere Art von Gültigkeitsbereich, die für Labels gilt, die mit `goto`-Anweisungen verwendet werden.
Zwei Labels mit demselben Namen können nicht in derselben Funktion verwendet werden, selbst wenn die Labels in getrennten Blöcken innerhalb der Funktion definiert sind.

### Gültigkeitsbereich von Funktionsprototypen

Der Gültigkeitsbereich von Funktionsprototypen ist eine weitere besondere Art von Gültigkeitsbereich, die nur für Parameter gilt, die innerhalb des Prototyps benannt werden (auch Deklaration genannt, wobei nicht alle Deklarationen Prototypen sind).
Ein Parametername ist in einer Funktionsdeklaration normalerweise optional.
Der Gültigkeitsbereich eines Namens ist nur innerhalb der Deklaration relevant.
Im folgenden Beispiel wird der Bezeichner `len` definiert und später in der Funktionsdeklaration referenziert.

```c
#include <stdio.h>

// len is defined and then referred to
void my_func(int len, int numbers[len]);

int main() {
    int numbers[2];
    numbers[0] = 1;
    numbers[1] = 2;
    my_func(2, numbers);
}

void my_func(int length, int numbers[length]) {
    // prints numbers should have 2 elements
    printf("numbers should have %d elements", length);
}
```

Beachte, dass innerhalb einer Deklaration die Namen übereinstimmen müssen, wenn auf dieselbe Variable verwiesen wird.
Wenn `my_func` als `void my_func(int len, int numbers[length]);` deklariert würde, würde ein Kompilierfehler erzeugt werden, der etwa so aussieht:

```
/tmp/scn62kKPEZ.c:4:35: error: 'length' undeclared here (not in a function)
    3 | void my_func(int len, int numbers[length]);
      |                                   ^~~~~~
/tmp/scn62kKPEZ.c: In function 'main':
/tmp/scn62kKPEZ.c:10:16: error: type of formal parameter 2 is incomplete
   10 |     my_func(2, numbers);
```

Eine Funktionsdefinition muss nicht denselben Namen für einen Parameter verwenden, der in der Funktionsdeklaration verwendet wurde.
Im obigen Beispiel wurde `len` in der Deklaration und `length` in der Definition verwendet. Das zeigt, dass der Gültigkeitsbereich des Bezeichners `len` nur innerhalb der Funktionsdeklaration lag.

### Dateigültigkeitsbereich

Auf einen Wert mit Dateigültigkeitsbereich kann von überall in der Datei zugegriffen werden.
Ein solcher Wert wird außerhalb einer Funktion definiert.
