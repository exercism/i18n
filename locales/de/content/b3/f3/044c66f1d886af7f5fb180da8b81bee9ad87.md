# Anleitung

Refaktoriere einen Markdown-Parser.

Die Markdown-Übung ist eine Refactoring-Übung.
Es gibt Code, der einen gegebenen String mit der [Markdown-Syntax][markdown] parst und das zugehörige HTML für diesen String zurückgibt.
Auch wenn dieser Code verwirrend geschrieben und schwer zu verfolgen ist, funktioniert er irgendwie, und alle Tests laufen durch!
Deine Aufgabe ist es, diesen Code neu zu schreiben, damit er leichter zu lesen und zu pflegen ist, und dabei sicherzustellen, dass alle Tests weiterhin bestehen.

Es wäre hilfreich, wenn du in Kommentaren notierst, was du beim Refactoring gemacht hast, damit Reviewer das sehen können, aber es ist nicht unbedingt nötig.
Das Wichtigste ist, den Code besser zu machen!

[markdown]: https://docs.github.com/en/get-started/writing-on-github/getting-started-with-writing-and-formatting-on-github/basic-writing-and-formatting-syntax
