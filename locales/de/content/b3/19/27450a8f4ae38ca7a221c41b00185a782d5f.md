# for-Schleifen

Schleifen sind ein grundlegendes Konzept in der Programmierung, mit dem du einen Block Code mehrmals ausführen kannst.
In Swift gibt es zwei Arten von Schleifen: [`for-in`-Schleifen][for-loops] und `while`-Schleifen.
In diesem Kapitel lernst du `for-in`-Schleifen kennen.

Mit for-Schleifen kannst du über eine Sequenz von Werten iterieren, nimmst dabei jedes Element der Reihe nach und bindest es an eine Variable deiner Wahl.
In Swift kannst du über verschiedene Arten von Sequenzen iterieren, etwa Ranges, Arrays und Strings (und weitere Typen, die später behandelt werden).
Wenn jedes Element der Sequenz durchlaufen wurde, endet die Schleife.

for-Schleifen deklarierst du mit dem Schlüsselwort `for`, gefolgt von einem Variablennamen, dem Schlüsselwort `in` und einer Sequenz von Werten, über die du iterierst.
Die Variable, die du in der `for-in`-Schleife angibst, ist unveränderlich, du kannst ihren Wert innerhalb der Schleife also nicht ändern.
Hier ist ein Beispiel für eine `for-in`-Schleife, die über ein Array von Zahlen iteriert:

```swift
let numbers = [3, 10, 7, 11]

for number in numbers {
  print(number)
}
print("Done with numbers")

// prints:
// 3
// 10
// 7
// 11
// Done with numbers
```

~~~~exercism/note
Die Variable `number` wird in der `for-in`-Schleife deklariert und ist nur innerhalb des Gültigkeitsbereichs der Schleife verfügbar.

```swift
let numbers = [3, 10, 7, 11]

for number in numbers {
    number + 1
}
number + 1
// Error: Use of unresolved identifier 'number'
```
~~~~

## Über einen Range iterieren

Du kannst auch mit einer `for-in`-Schleife über einen Range von Zahlen iterieren.
So kannst du einen Block Code eine bestimmte Anzahl von Malen ausführen. Der Range `1...5` durchläuft zum Beispiel die Zahlen 1, 2, 3, 4 und 5, die Schleife wird also 5-mal ausgeführt.
Manchmal möchtest du über Indizes in einer Datenstruktur wie einem Array iterieren, dann kannst du einen Range `0..<array.count` verwenden.

```swift
let numbers = [3, 10, 7, 11]

for i in 0..<numbers.count {
  print(numbers[i])
}

// prints:
// 3
// 10
// 7
// 11
```

## Über einen String iterieren

Du kannst auch mit einer `for-in`-Schleife über einen String iterieren.
So kannst du über jedes Zeichen im String iterieren. Beachte dabei, dass der Typ, der in der Schleife verwendet wird, ein `Character` ist.

```swift
let message = "Hello!"

for character in message {
  print(character)
}

// prints:
// H
// e
// l
// l
// o
// !
```

## stride

Swift bietet außerdem eine `stride`-Funktion, mit der du eine Sequenz über einen Range mit einer bestimmten Schrittweite erstellen kannst.
Über diese kannst du dann mit einer `for-in`-Schleife iterieren.
`stride` ist definiert als [`stride(from:to:by:)`][stride-to] oder [`stride(from:through:by:)`][stride-through]. Die erste Variante ist exklusiv und die zweite inklusiv.

```swift
for i in stride(from: 0, to: 10, by: 2) {
  print(i)
}

// prints:
// 0
// 2
// 4
// 6
// 8
```

Beachte, dass der Parameter `to` exklusiv ist, die Schleife läuft also bis zur Zahl vor dem Parameter `to`. Der Parameter `through` dagegen ist inklusiv, hier würde er also auch die `10` einschließen.

[stride-to]: https://developer.apple.com/documentation/swift/stride(from:to:by:)
[stride-through]: https://developer.apple.com/documentation/swift/stride(from:through:by:)
[for-loops]: https://docs.swift.org/swift-book/documentation/the-swift-programming-language/controlflow/#For-In-Loops
