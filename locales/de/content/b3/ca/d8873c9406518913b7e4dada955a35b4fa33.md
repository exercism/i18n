# Einführung

In Common Lisp ist ein Array, wie in anderen Sprachen auch, eine Menge von Elementen, auf die über ganzzahlige Indizes zugegriffen wird.
Die Typen der Elemente können unterschiedlich sein.
Das Array kann mehrdimensional sein (nicht nur 1-dimensional).

## Erstellen

Mit `make-array` kannst du Arrays erstellen.
Es hat viele Optionen, aber in seinen einfacheren Formen erlaubt es dir, N-dimensionale Arrays zu erstellen, bei denen alle Elemente mit einem einzigen Wert initialisiert werden, oder das Array mit den Werten einer anderen Sequenz (etwa einer Liste) zu initialisieren.
Sein erstes Argument ist eine Liste mit der Größe jeder Dimension.

```lisp
(make-array '(4) :initial-element 3)    ; => #(3 3 3 3)
(make-array '(2 2) :initial-element 'x) ; => #2A((X X) (X X))
```

(Beachte, dass die N-dimensionalen Arrays mit der Anzahl der Dimensionen ausgegeben werden.)

Arrays lassen sich auch über dasselbe Format erstellen, in dem sie ausgegeben werden:

```lisp
#(x y z)         ; => #(X Y Z)
#2A((1 2) (3 4)) ; => #2A((1 2) (3 4))
```

## Zugriff auf Elemente

Um auf Elemente eines Vektors zuzugreifen, verwendest du `aref`; die Indizes beginnen bei null.
Die Anzahl der angegebenen Indizes muss dem Rang des Arrays entsprechen.

```lisp
(aref #2A((1 2 3) (3 4 5)) 
       1 0)           ; => 3
(aref #3A(((a b) (c d)) 
           ((e f) (g h)) 
           ((t u) (v w))) 
       2 0 1)         ; => U
(aref #2A((1) (2)) 0) ; => ERROR (because not enough indexes provided)
```
