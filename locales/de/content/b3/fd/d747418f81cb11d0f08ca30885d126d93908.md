# Ergänzende Anweisungen

## Wie diese Übung in Python aufgebaut ist

Wir haben eine zusätzliche Wochenangabe (`fifth`) für den fünften Wochentag des Monats hinzugefügt, falls es einen gibt.  
Wenn es in einem Monat keinen fünften Wochentag gibt, solltest du eine Exception auslösen.

## Exceptions anpassen und auslösen

Manchmal ist es notwendig, Exceptions in deinem Code sowohl zu [anpassen](https://docs.python.org/3/tutorial/errors.html#user-defined-exceptions) als auch mit [`raise`](https://docs.python.org/3/tutorial/errors.html#raising-exceptions) auszulösen. Wenn du das tust, solltest du immer eine **aussagekräftige Fehlermeldung** angeben, um anzugeben, was die Fehlerquelle ist. Das macht deinen Code lesbarer und hilft beim Debugging erheblich.

Benutzerdefinierte Exceptions lassen sich durch neue Exception-Klassen erstellen (siehe [`classes`](https://docs.python.org/3/tutorial/classes.html#tut-classes) für weitere Details), die typischerweise Unterklassen von [`Exception`](https://docs.python.org/3/library/exceptions.html#Exception) sind.

In Situationen, in denen du weißt, dass die Fehlerquelle von einem bestimmten Exception-Typ abstammt, kannst du dich dafür entscheiden, von einem der [`built in error types`](https://docs.python.org/3/library/exceptions.html#base-classes) unter der _Exception_-Klasse zu erben. Wenn du den Fehler auslöst, solltest du trotzdem eine aussagekräftige Meldung angeben.

Diese Übung erfordert, dass du eine _benutzerdefinierte Exception_ erstellst, die [ausgelöst](https://docs.python.org/3/reference/simple_stmts.html#the-raise-statement)/„geworfen“ wird, wenn deiner `meetup()`-Funktion eine ungültige Kombination aus Wochentagsname und Zahl übergeben wird. Die Tests sind nur dann erfolgreich, wenn du passende Exceptions anpasst, diese Exceptions mit `raise` auslöst und passende Fehlermeldungen angibst.

Um eine `built-in exception` anzupassen, erstelle eine `class`, die von dieser Exception erbt. Wenn du die benutzerdefinierte Exception mit einer Meldung auslöst, schreibe die Meldung als Argument an den `exception`-Typ:

```python
# subclassing the built-in ValueError to create MeetupDayException
class MeetupDayException(ValueError):
    """Exception raised when the Meetup weekday and count do not result in a valid date.

    message: explanation of the error.

    """
    def __init__(self, message):
        self.message = message

        
# raising a MeetupDayException
raise MeetupDayException("That day does not exist.")
```
