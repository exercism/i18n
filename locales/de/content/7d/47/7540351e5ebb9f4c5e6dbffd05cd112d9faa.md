# Zusätzliche Anweisungen

## Gartenformat

Der Garten wird als nullterminierter String dargestellt, wobei am Ende jeder Zeile ein Zeilenumbruchzeichen steht.

Ein Beispiel wäre `"   \n * \n   \n"`

## Register

| Register | Verwendung   | Typ     | Beschreibung                   |
| -------- | ------------ | ------- | ------------------------------ |
| `$a0`    | Eingabe      | Adresse | nullterminierter Eingabe-String |
| `$a1`    | Eingabe/Ausgabe | Adresse | nullterminierter Ausgabe-String |
| `$t0-9`  | temporär     | beliebig | für die temporäre Speicherung   |
