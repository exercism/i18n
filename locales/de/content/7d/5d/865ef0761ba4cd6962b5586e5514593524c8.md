# Einführung in Listen

**Listen** sind in Java die Sammlung für geordnete Sequenzen.
Anders als Arrays kann eine [`List`](https://docs.oracle.com/en/java/javase/11/docs/api/java.base/java/util/List.html) wachsen und beliebig viele Elemente aufnehmen.
Eine Standardimplementierung ist die `ArrayList`, die auf einem Array mit veränderbarer Größe basiert.
Eine weitere Standardimplementierung ist die Klasse `LinkedList`, die auf einer doppelt verketteten Liste basiert.

`List`s können leer sein oder beliebig viele Elemente enthalten (auch Duplikate).
`List`s sind eine **generische Schnittstelle**, deren Typparameter angibt, welche Art von Objekten sie enthalten können.
Zum Beispiel:

```java
List<String> emptyListOfStrings = List.of();
List<Integer> singleInteger = List.of(1);
List<Boolean> threeBooleans = List.of(true, false, true);
List<Object> listWithMultipleTypes = List.of("hello", 1, true);
```

`List`s haben verschiedene hilfreiche Methoden, um Elemente hinzuzufügen, zu entfernen, abzurufen und zu prüfen, ob ein Element vorhanden ist:

```java
List<Character> vowels = new ArrayList<>(List.of('a', 'e', 'i', 'o', 'i', 'e', 'a'));
int startingSize = vowels.size(); // 7
vowels.add('u'); // vowels is now ['a', 'e', 'i', 'o', 'i', 'e', 'a', 'u']
char a = vowels.get(0); // 'a'
boolean hadI = vowels.remove('i'); // true and vowels is now ['a', 'e', 'o', 'i', 'e', 'a', 'u']
boolean hasI = vowels.contains('i'); // true (still have one more left)
```
