# Über

In Clojure gibt es einige grundlegende [Kontrollfluss](https://clojure.org/guides/learn/flow)-Konstrukte. `if` ist der wichtigste Bedingungsausdruck. Er besteht aus einer Bedingung, einem „Dann“ und einem optionalen „Sonst“. `if` wertet nur den Zweig aus, den die Bedingung auswählt.

```clojure
(if (even? 2) "even" "odd")
```

`cond` ist eine Reihe von Tests und Ausdrücken. Jeder Test wird der Reihe nach ausgewertet, und der Ausdruck wird für den ersten Test, der wahr ist, ausgewertet und zurückgegeben.

```clojure
(cond (= x 5) "Expression to evaluate when x equals 5"
      (> x 7) "Expression to evaluate when x is greater than 7"
      :else   "Expression to evaluate in all other cases")
```
