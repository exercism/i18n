# Einführung

## Operatorüberladung

Die wichtigsten arithmetischen und Vergleichsoperatoren kannst du für deine eigenen Klassen und Structs anpassen. Das nennt man _Operatorüberladung_.

Die meisten Operatoren haben die Form:

```csharp
static <return type> operator <operator symbols>(<parameters>);
```

Konvertierungsoperatoren haben die Form:

```csharp
static (explicit|implicit) operator <cast-to-type>(<cast-from-type> <parameter name>);
```

Operatoren verhalten sich genauso wie statische Methoden. Ein Operatorsymbol tritt an die Stelle eines Methodenbezeichners, und Operatoren haben Parameter und einen Rückgabetyp. Die Typregeln für Parameter und Rückgabetyp entsprechen deiner Intuition, und du kannst dich darauf verlassen, dass der Compiler dir ausführliche Hinweise gibt.
