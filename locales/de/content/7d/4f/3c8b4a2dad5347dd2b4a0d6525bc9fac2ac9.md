# Einführung

Exceptions sind eine Form der Fehlerbehandlung.
Sie heißen Exceptions, weil sie normalerweise bei einem unerwarteten Ereignis auftreten.

An jeder Stelle in unserem Code können wir eine Exception auslösen.
Dazu verwenden wir die Methode `raise`, der wir ein Objekt übergeben. Normalerweise ist das ein Exception-Objekt, es kann sich aber auch um einen einfachen String handeln.
Zum Beispiel siehst du in den Gerüsten der Übungen, dass wir den eingebauten `RuntimeError` verwenden, um Ruby mitzuteilen, dass eine Methode noch nicht implementiert wurde.
Du kannst auch die Kurzschreibweise `raise(ExceptionObject, params)` verwenden.
Wenn die Exception-Klasse weggelassen wird, wird standardmäßig `RuntimeError` verwendet.
Zum Beispiel:

```ruby
# These are equivalent
raise RuntimeError.new("Please implement this method")
raise RuntimeError, "Please implement this method"
raise "Please implement this method"
```

Wenn Ruby das sieht, reicht es den Fehler bis zur obersten Ebene des Programms weiter und beendet es dann.
Wenn du zum Beispiel versuchst, etwas durch null zu teilen, siehst du ungefähr Folgendes:
```ruby
5/0

#=> Traceback (most recent call last):
#=> ...
#=> ZeroDivisionError (divided by 0)
```
