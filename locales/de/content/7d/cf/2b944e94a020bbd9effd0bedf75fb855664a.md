# Über

Eine in `[ ]` geschriebene Quotation ist Factors Entsprechung einer anonymen Funktion oder eines Blocks. Sie ist ein Wert erster Klasse, den du auf den Stack legen, speichern oder weitergeben kannst, und der erst ausgeführt wird, wenn ihn etwas *aufruft*.

```factor
[ 1 + ]              ! a quotation, sitting on the stack
5 [ 1 + ] call .     ! => 6
```

Quotationen sind Folgen von Wörtern, und Factor setzt sie überall dort ein, wo ein Stück Verhalten aufgeschoben oder parametrisiert werden muss:

- die Zweige von `if` / `when` / `unless` / `cond`
- das Prädikat von `filter`, `count`, `any?`, `all?`
- die Umwandlung von `map`, `each`, `reduce`
- der Schleifenblock von `times`, `while`, `loop`

Der Stack-Effekt einer Quotation lässt sich meist ableiten. Wenn das nicht geht, etwa wenn sie gespeichert und später mit `call` aufgerufen wird, gib den Effekt explizit an: `call( a b -- c )`.

## Quotationen kombinieren

```
compose ( quot1 quot2 -- compound )
curry   ( value quot  -- curried )
```

`compose` verkettet zwei Quotationen hintereinander zu einer neuen Quotation, die zuerst die erste und dann die zweite ausführt. `curry` stellt einen festen Wert voran und gibt eine Quotation zurück, die diesen Wert auf den Stack legt, bevor sie die ursprüngliche aufruft. Beide erzeugen gewöhnliche Quotationen, die du mit `call` aufrufen, speichern oder an Kombinatoren übergeben kannst.

```factor
USING: kernel math ;

3 [ 2 * ] [ 1 + ] compose call .   ! 3 2 * 1 + => 7
5 [ 1 + ] curry call .             ! 5 1 +     => 6
```
