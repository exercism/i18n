# Anweisungen

In dieser Übung implementierst du einige Methoden, um ein Array von Programmiersprachen zu bearbeiten.

## 1. Definiere eine Methode, die ein leeres Array für Programmiersprachen zurückgibt

Definiere die Methode `LanguageList.list`, die keine Argumente entgegennimmt und ein leeres Array vom Typ `Array(String)` zurückgibt.

```crystal
LanguageList.list()
# => []
```

## 2. Definiere eine Methode, die eine Programmiersprache zum Array hinzufügt

Definiere die Methode `LanguageList.add`, die 2 Argumente entgegennimmt (ein _Programmiersprachen-Array_ und ein String-Literal einer _Programmiersprache_).
Die Methode sollte das Array mit der neuen Programmiersprache am Ende des Arrays zurückgeben.

```crystal
language_list = LanguageList.list()
# => []
language_list = LanguageList.add(language_list, "Crystal")
# => ["Crystal"]
language_list = LanguageList.add(language_list, "Ruby")
# => ["Crystal", "Ruby"]
```

## 3. Definiere eine Methode, die eine Programmiersprache aus dem Array entfernt

Definiere die Methode `LanguageList.remove`, die 1 Argument entgegennimmt (ein _Programmiersprachen-Array_).
Die Methode sollte das Array ohne das letzte Element zurückgeben.
Gehe davon aus, dass das Array immer mindestens ein Element enthält.

```crystal
language_list = LanguageList.list()
# => []
language_list = LanguageList.add(language_list, "Crystal")
# => ["Crystal"]
language_list = LanguageList.add(language_list, "Ruby")
# => ["Crystal", "Ruby"]
language_list = LanguageList.remove(language_list)
# => ["Crystal"]
```

## 4. Definiere eine Methode, die das n-te Element im Array zurückgibt

Definiere die Funktion `LanguageList.at`, die 2 Argumente entgegennimmt (ein _Programmiersprachen-Array_ und einen Index).
Die Methode sollte die Programmiersprache am n-ten Index im Array zurückgeben.
Gehe davon aus, dass an diesem Index immer eine Programmiersprache steht.

```crystal
language_list = LanguageList.new()
# => []
language_list = LanguageList.add(language_list, "Crystal")
# => ["Crystal"]
language_list = LanguageList.add(language_list, "Ruby")
# => ["Crystal", "Ruby"]
LanguageList.at(language_list, 1)
# => "Ruby"
```

## 5. Definiere eine Methode, die einen String aus Programmiersprachen parst

Definiere die Methode `LanguageList.parse`, die 1 Argument entgegennimmt (ein String-Literal aus Programmiersprachen, die durch ein Komma getrennt sind).
Die Methode sollte ein Array von Programmiersprachen zurückgeben.

```crystal
LanguageList.parse("Crystal, Ruby")
# => ["Crystal", "Ruby"]
```
