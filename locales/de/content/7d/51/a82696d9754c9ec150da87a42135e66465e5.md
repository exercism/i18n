# Einführung

Standardmäßig sind Variablen auf den Gültigkeitsbereich beschränkt, in dem sie definiert werden. Wenn sie in einer Datei außerhalb einer Funktion oder Klasse definiert werden, sind sie auf den Gültigkeitsbereich der Datei beschränkt. Werden sie in einer Funktion oder Klasse definiert, sind sie auf den Gültigkeitsbereich der Funktion oder Klasse beschränkt.

```php
<?php

$file_scoped = "I am file scoped";

function example(): void
{
  $function_scoped = "I am function scoped!";
}
```

Variablen können außerdem gezielt mit dem Gültigkeitsbereich `global` oder `static` deklariert werden.
