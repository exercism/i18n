# Über

In PHP kannst du eine Variable wie eine Funktion aufrufen, indem du runde Klammern [`()`] an sie anhängst. Wenn PHP versucht, die Funktion aufzurufen, sucht es nach einer Funktion, die denselben Namen hat wie der Wert der Variable.

```php
function foo(): string
{
    return "foo() invoked";
}

$func = 'foo';
$func(); // This calls foo()
```

## Statische Funktionen einer Klasse aufrufen

Statische Funktionen einer Klasse kannst du auf die gleiche Weise aufrufen:

```php
class Rocket
{
    public static function launch()
    {
        return '3, 2, 1, Liftoff!';
    }
}

$func = 'Rocket::launch';
$func(); // This calls Rocket::launch()
```

## Funktionen einer Klasseninstanz aufrufen

Du kannst auch die Funktion einer Klasseninstanz aufrufen:

```php
class Rocket
{
    public function openDoor()
    {
        return 'Door open.';
    }
}

$rocket = new Rocket();
$func = [$rocket, 'openDoor'];
$func(); // This calls Rocket::openDoor()
```
