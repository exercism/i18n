# Anleitung

Refaktoriere einen Markdown-Parser.

Die Markdown-Übung ist eine Refactoring-Übung.
Es gibt Code, der einen gegebenen String mit [Markdown-Syntax][markdown] parst und das zugehörige HTML für diesen String zurückgibt.
Auch wenn dieser Code verwirrend geschrieben und schwer zu verstehen ist, funktioniert er irgendwie und alle Tests bestehen!
Deine Herausforderung besteht darin, diesen Code so neu zu schreiben, dass er leichter zu lesen und zu warten ist und trotzdem alle Tests weiterhin bestehen.

Es wäre hilfreich, wenn du in Kommentaren notierst, was du bei deinem Refactoring gemacht hast, damit Reviewer es sehen können, aber es ist nicht unbedingt notwendig.
Das Wichtigste ist, den Code besser zu machen!

[markdown]: https://guides.github.com/features/mastering-markdown/
