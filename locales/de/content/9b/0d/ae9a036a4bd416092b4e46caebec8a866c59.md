# Anweisungen

Das Fundbüro der Schule bewahrt alles in Kisten auf, und was in eine Kiste kommt, kann alles Mögliche sein: ein Pullover, eine Anzahl von Dingen, ein Name.

Schreib eine Klasse `LOST_BOX{T}`. Der Stub gibt dir den Klassenkopf.

## 1. Nimm etwas an

`create` nimmt die Sache und den Namen der Person, die sie abgegeben hat, und gibt eine Kiste zurück. Eine Kiste ist zu Beginn nicht beansprucht.

```sather
box ::= #LOST_BOX{STR}("blue jumper", "Mia");
box.item
-- => "blue jumper"
box.handed_in_by
-- => "Mia"
box.claimed
-- => false
```

## 2. Beanspruche sie

`claim` markiert die Kiste als beansprucht. Sie gibt nichts zurück.

```sather
box.claim;
box.claimed
-- => true
```

## 3. Wartet sie noch?

`waiting` gibt zurück, ob die Kiste noch nicht beansprucht wurde.

```sather
box.waiting
-- => false
```

## 4. Tausche den Inhalt aus

`replace` nimmt eine neue Sache, legt sie in die Kiste und gibt zurück, was vorher darin war. Die Sache, die hineingeht, und die Sache, die herauskommt, sind beide `T`.

```sather
old ::= box.replace("red jumper");
old
-- => "blue jumper"
box.item
-- => "red jumper"
```

## 5. Schreib eine Beschreibung

`describe` gibt eine Zeile über die Kiste zurück, zum Beispiel `"blue jumper, handed in by Mia"`.

Um die Sache in einen String umzuwandeln, muss die Klasse wissen, dass ein `T` in einen umgewandelt werden kann. Schränke den Parameter ein: Schreib den Klassenkopf als `class LOST_BOX{T < $STR}`, und dann ist `item.str` erlaubt.

```sather
box.describe
-- => "blue jumper, handed in by Mia"
```
