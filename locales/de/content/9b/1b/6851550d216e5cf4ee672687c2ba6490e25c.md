# Einführung

C#-Typen können innerhalb des Gültigkeitsbereichs einer Klasse oder eines Structs definiert werden. Der umschließende Typ stellt eine Art Namespace bereit. Der Zugriff auf den Typ erfolgt über den umschließenden Typ mit Punktnotation.

```csharp
class Outer
{
    public interface IInner {}
    public enum EInner {}
    public class CInner {}
    public struct SInner {}
}

var outer = new Outer();
var inner = new Outer.CInner();
```

Du kannst Zugriffsebenen für innere Typen festlegen.

Private Member des äußeren Typs sind für Member des inneren Typs im Gültigkeitsbereich, aber nicht umgekehrt.
