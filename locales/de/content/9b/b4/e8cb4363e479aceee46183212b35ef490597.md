# Über

## Rechenoperatoren

JavaScript bietet 6 verschiedene Operatoren, um einfache Rechenoperationen mit Zahlen durchzuführen.

- `+`: Mit dem Additionsoperator berechnest du die Summe von Zahlen.

  ```javascript
  1 + 2; // => 3
  2.5 + 3.9; // => 6.5
  ```

- `-`: Mit dem Subtraktionsoperator berechnest du die Differenz zwischen zwei Zahlen

  ```javascript
  19 - 2; // => 17
  7.4 - 1.2; // => 6.2
  ```

- `*`: Mit dem Multiplikationsoperator berechnest du das Produkt zweier Zahlen

  ```javascript
  7 * 5; // => 35
  9.2 * 6.3; // => 57.959999999999994
  ```

- `/`: Mit dem Divisionsoperator teilst du zwei Zahlen.
  Da JavaScript-Zahlen immer Gleitkommazahlen sind, gibt es keine Ganzzahldivision.

  ```javascript
  8 / 2; // => 4
  25 / 3; // => 8.333333333333334
  ```

- `%`: Mit dem Restoperator ermittelst du den Rest einer Division.

  ```javascript
  40 % 4; // => 0
  11 % 4; // => 3
  -11 % 4; // => -3
  ```

- `**`: Mit dem Potenzoperator potenzierst du eine Zahl.
  Er entspricht der Verwendung von [`Math.pow()`][mdn-math-pow]

  ```javascript
  4 ** 3; // => 64
  4 ** 1 / 2; // => 2
  ```

## Rangfolge der Operatoren

Wenn du mehrere Operatoren in einer Zeile verwendest, folgt JavaScript einer Rangfolge, wie sie in [dieser Rangfolgetabelle][mdn-operator-precedence] dargestellt ist.
Vereinfacht gesagt verwendet JavaScript die PEDMAS-Regel (Klammern, Exponenten, Division/Multiplikation, Addition/Subtraktion), die wir im Matheunterricht gelernt haben.

<!-- prettier-ignore-start -->
```javascript
const result = 3 ** 3 + 9 * 4 / (3 - 1);
// => 3 ** 3 + 9 * 4/2
// => 27 + 9 * 4/2
// => 27 + 18
// => 45
```
<!-- prettier-ignore-end -->

## Kurzformen von Zuweisungsoperatoren

Kurzformen von Zuweisungsoperatoren sind eine kürzere Schreibweise, um Rechenoperationen mit einer Variable durchzuführen und den neuen Wert derselben Variable zuzuweisen.
Betrachte zum Beispiel zwei Variablen `x` und `y`.
Dann ist `x += y` dasselbe wie `x = x + y`.
Oft wird dies mit einer Zahl statt mit einer Variable `y` verwendet.
Die 5 anderen Operationen kannst du auf ähnliche Weise durchführen.

```javascript
let x = 5;
x += 25; // x is now 30

let y = 31;
y %= 3; // y is now 1
```
