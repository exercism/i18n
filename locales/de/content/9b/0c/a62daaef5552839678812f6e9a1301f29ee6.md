# Einführung

Go enthält grundlegende numerische Typen, die Mengen von Ganzzahl- oder Gleitkommawerten darstellen können.

Dieses Konzept konzentriert sich auf zwei Zahlentypen:

- `int`: z. B. `0`, `255`, `2147483647`.
   Eine vorzeichenbehaftete Ganzzahl, die mindestens 32 Bit groß ist (Wertebereich: -2147483648 bis 2147483647).
   Das hängt jedoch von der Architektur des Systems ab.
   Die meisten modernen Computer sind 64 Bit groß, daher ist `int` 64 Bit groß (Wertebereich: -9223372036854775808 bis 9223372036854775807).

- `float64`: z. B. `0.0`, `3.14`.
   Enthält die Menge aller 64-Bit-Gleitkommazahlen.

Go unterstützt die üblichen arithmetischen Operatoren `+`, `-`, `*`, `/` und `%` (Rest, nicht Modulo).

In Go erfordert die Zuweisung eines Werts zwischen verschiedenen Typen eine explizite Konvertierung.
Um zum Beispiel ein `int` in ein `float64` umzuwandeln, gehst du wie folgt vor:

```go
var x int = 42
f := float64(x)

fmt.Printf("x is of type: %s\n", reflect.TypeOf(x))
// Output: x is of type: int

fmt.Printf("f is of type: %s\n", reflect.TypeOf(f))
// Output: f is of type: float64
```
