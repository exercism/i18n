## MacOS

Installiere zuerst Lua und [Luarocks][2] mit [Homebrew][1]:

```shell
$ brew install lua luarocks
```

Installiere dann das Test-Framework [Busted][3] für Lua:

```shell
$ luarocks install --local busted
```

Füge `~/.luarocks/bin` zu deinem systemweiten `$PATH` hinzu

```shell
export PATH="$HOME/.luarocks/bin:$PATH"
```

Beachte, dass dies nur vorübergehend gilt.
Um es dauerhaft zu deinem `$PATH` hinzuzufügen, musst du es in deine `.bashrc`, `.zshrc` oder `config.fish` eintragen, je nachdem, welche Shell du verwendest.

Dann führe deine Tests aus:

```shell
$ busted
```

## Windows 10: WSL

Zuerst musst du [WSL (Windows Subsystem for Linux)][7] mit [PowerShell][8] (Administrator) aktivieren:

```shell
PS> Enable-WindowsOptionalFeature -Online -FeatureName Microsoft-Windows-Subsystem-Linux
```

Danach ist ein Neustart erforderlich.

Installiere als Nächstes Ubuntu aus dem [Microsoft Store][9] **oder** lade es herunter und installiere es mit PowerShell:

```shell
PS> curl.exe -L -o ubuntu1804.appx https://aka.ms/wsl-ubuntu-1804
PS> Add-AppxPackage .\ubuntu1804.appx; rm .\ubuntu1804.appx
PS> ubuntu1804
```

Aktualisiere dann deine Paketliste:

```shell
PS> wsl
$ sudo apt-get update
```

Jetzt kannst du [LuaRocks][2] und [Busted][3] installieren, indem du die [Ubuntu-Anleitung](#ubuntu) oben befolgst.

Danach kannst du deine Tests direkt von jeder Windows-Kommandozeile aus ausführen:

```cmd
C:\> wsl busted
```

## Windows 10: Docker

### Gitbash installieren

Dieser Schritt ist optional. Du musst die folgenden Schritte möglicherweise leicht anpassen, wenn du lieber die native Kommandozeile von Windows oder eine andere Kommandozeile verwendest.

Download [hier][10].
Installationsanleitung [hier][11].

### Docker installieren

Folge der Anleitung, um [Docker for Windows][12] zu installieren.
Wenn du mit der Installation fertig bist, kannst du den folgenden Befehl ausführen, um sicherzustellen, dass es korrekt installiert wurde.

```shell
$ docker --version
```

_Beim ersten Versuch, Docker auszuführen, kann ein Fehler auftreten._

`cannot enable hyper-v service`

_Wenn das passiert, kannst du dieser Anleitung folgen, um [Hyper V zu aktivieren][13]. Möglicherweise musst du die Einstellung deaktivieren, deinen Computer neu starten und sie nach dem Booten wieder aktivieren._

### busted installieren

Sobald du Gitbash und Docker installiert hast, kannst du einen busted-„Container“ installieren.

Führe in Gitbash Folgendes aus:

Lade diesen weit verbreiteten Docker-Container herunter, indem du Folgendes ausführst:

```shell
$ docker pull imega/busted
```

Erstelle eine Funktion, damit du nicht jedes Mal den ganzen Befehl eintippen musst.
Füge dies zu deiner `.bashrc` hinzu:

```shell
dbusted() { docker run --rm -t -v "/$@":/data imega/busted; }
```

Jetzt kannst du in deiner Kommandozeile in das Verzeichnis wechseln, in dem du deine Tests ausführen möchtest. Führe Folgendes aus:

```shell
$ dbusted $PWD
```

Du solltest die Ausgabe deiner busted-Tests sehen.
