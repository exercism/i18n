# Hinweise

## Allgemeines

- Nutze anonyme Funktionen.
- Anonyme Funktionen können auf Variablen verweisen, die beim Definieren der Funktion im Gültigkeitsbereich lagen.

## 1. Erstelle einen Addierer

- Gib eine anonyme Funktion zurück, die das Argument der anonymen Funktion zu dem Argument addiert, das an `secret_add` übergeben wurde.

## 2. Erstelle einen Subtrahierer

- Gib eine anonyme Funktion zurück, die das an `secret_subtract` übergebene Argument von dem Argument der anonymen Funktion subtrahiert.

## 3. Erstelle einen Multiplizierer

- Gib eine anonyme Funktion zurück, die das Argument der anonymen Funktion mit dem Argument multipliziert, das an `secret_multiply` übergeben wurde.

## 4. Erstelle einen Dividierer

- Gib eine anonyme Funktion zurück, die das Argument der anonymen Funktion durch das Argument dividiert, das an `secret_divide` übergeben wurde.

## 5. Erstelle einen Funktionskombinierer

- Gib eine anonyme Funktion zurück, die jede der Funktionen aufruft, die an `secret_combine` übergeben wurden.
