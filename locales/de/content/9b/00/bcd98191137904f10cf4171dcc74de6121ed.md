# Anweisungen

Der örtliche Lyrik-Club startet in eine neue Saison. Dichter treten dem Club bei,
und immer wenn zwei von ihnen gemeinsam ein Gedicht schreiben, gehören sie zum
selben *Schreibzirkel*. Der Club möchte den Überblick behalten, wer sich mit wem
einen Zirkel teilt, und du wurdest gebeten, die Wörter zu schreiben, die das
verwalten.

Ein Disjoint-Set passt hier perfekt: Jeder Dichter ist ein Atom und ein
Schreibzirkel ist eine Gruppe.

## 1. Eröffne den Club

Definiere `new-club`, das eine Sequenz von Dichtern entgegennimmt und ein neues
Disjoint-Set zurückgibt, in dem jeder Dichter registriert ist. Jeder Dichter
startet in einem eigenen Schreibzirkel.

```factor
{ "Keats" "Byron" "Dickinson" } new-club
! => a disjoint set holding the three poets
```

## 2. Halte eine Zusammenarbeit fest

Definiere `collaborate`, das zwei Dichter und einen Club entgegennimmt. Es vereint
die Schreibzirkel der beiden Dichter und gibt den Club zurück, sodass sich
Zusammenarbeiten nacheinander erfassen lassen.

```factor
{ "Keats" "Byron" "Dickinson" } new-club
"Keats" "Byron" rot collaborate
! => the club, with Keats and Byron now in one circle
```

## 3. Finde den Zirkel eines Dichters

Definiere `circle-of`, das einen Dichter und einen Club entgegennimmt und den
Repräsentanten des Schreibzirkels dieses Dichters zurückgibt. Zwei Dichter, die
sich einen Zirkel teilen, melden immer denselben Repräsentanten.

```factor
{ "Keats" "Byron" "Dickinson" } new-club
"Dickinson" swap circle-of
! => "Dickinson"   (still in a circle of their own)
```

## 4. Einen Zirkel teilen?

Definiere `same-circle?`, das zwei Dichter und einen Club entgegennimmt und `t`
zurückgibt, wenn beide Dichter zum selben Schreibzirkel gehören, und andernfalls
`f`. Vergleiche die Repräsentanten der Dichter, statt einen eingebauten
Äquivalenztest zu verwenden.

```factor
{ "Keats" "Byron" "Dickinson" } new-club
"Keats" "Byron" rot collaborate
dup [ "Keats" "Byron" ] dip same-circle? .      ! => t
    [ "Keats" "Dickinson" ] dip same-circle? .  ! => f
```
