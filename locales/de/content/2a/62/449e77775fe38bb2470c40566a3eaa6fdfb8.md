# Funktionsnamen in snake_case

[comment]: # (benötigt 2 Parameter:)
[comment]: # (- expected: der korrigierte Name)
[comment]: # (- actual: der falsche Name, den der Lernende verwendet hat)

Funktions-, Makro- und Guard-Namen werden in Elixir immer in snake_case geschrieben.

```elixir
# this is snake_case

%{expected}

# this is not snake_case

%{actual}
```
