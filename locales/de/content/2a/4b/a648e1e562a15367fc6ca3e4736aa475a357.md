# Tests

Es gibt zwei verschiedene Möglichkeiten, die Tests mit Objective-C auszuführen:

- Erstelle ein Xcode-Projekt mit einem Test-Target, das die Tests ausführt.
- Verwende das Ruby-Gem `objc` als Hilfsprogramm zum Ausführen der Tests.

Beides wird hier genauer beschrieben: https://exercism.org/tracks/objective-c/tests
