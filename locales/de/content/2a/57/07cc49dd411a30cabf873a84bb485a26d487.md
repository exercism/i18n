# Sichtbarkeit

Wenn du Klassen verwendest, um Code zu organisieren, hilft dir die Sichtbarkeit von Eigenschaften, Methoden und Konstanten dabei, saubere Abstraktionen und klare Verantwortlichkeiten zu erreichen.
Die Sichtbarkeit von Eigenschaften, Methoden und Konstanten wird dadurch festgelegt, wie die Schlüsselwörter `public`, `private` oder `protected` bei ihrer Deklaration verwendet werden.
Die Sichtbarkeit bezieht sich immer auf den externen Zugriff auf die Eigenschaft, Methode oder Konstante einer Klasse.
Das heißt: Ist eine Eigenschaft als `public` deklariert, dann ist sie für externe Aufrufe sichtbar und nutzbar.
Private Eigenschaften, Methoden und Konstanten sind für externe Aufrufe weder sichtbar noch nutzbar.

```php
<?php

class SecretDocument
{
    private $encryption_key;

    public $title;

    public function __construct($encryption_key, $title)
    {
        $this->encryption_key = $encryption_key;
        $this->title = $title;
    }
}

$document = new SecretDocument('secret_password', 'Secret Plans');
$title = $document->title; // => succeeds
$key = $document->encryption_key; // => fails
```

Eigenschaften, Methoden und Konstanten mit `protected` sind nur für die Klasse selbst und ihre Kindklassen (durch Vererbung) sichtbar.

```php
<?php

class Shape
{
    protected $color = "blue";
}

class Square extends Shape
{
    public function getColor()
    {
        return $this->color;
    }
}

$square = new Square();
$color = $square->getColor(); // => succeeds
```
