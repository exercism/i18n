# Einführung

Gleitkommazahlen sind Zahlen mit einer oder mehreren Nachkommastellen. Sie nutzen das 64-Bit-Gleitkommaformat mit doppelter Genauigkeit.

```elixir
float = 3.45
# => 3.45
```

## Mit Zahlen arbeiten

Im Modul [`Integer`][integer-functions] und im Modul [`Float`][float-functions] findest du nützliche Funktionen für den Umgang mit diesen Typen. Die grundlegenden Rechenoperatoren sind im Modul [`Kernel`][kernel-arithmetic-operators] definiert.

## Umwandlung

Ganzzahlen und Gleitkommazahlen können in einem einzigen arithmetischen Ausdruck gemischt werden. Wenn du eine Gleitkommazahl in einem Ausdruck verwendest, ist das Ergebnis ebenfalls eine Gleitkommazahl.

```elixir
2 * 3
# => 6

2 * 3.0
# => 6.0
```

Bei einer Division ist das Ergebnis jedoch immer eine Gleitkommazahl, selbst wenn nur Ganzzahlen verwendet werden.

```elixir
6 / 2
# => 3.0
```

Um eine Gleitkommazahl in eine Ganzzahl umzuwandeln, kannst du den Nachkommateil mit [`trunc/1`][trunc-1] verwerfen.
