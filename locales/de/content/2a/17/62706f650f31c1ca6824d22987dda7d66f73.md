# Einführung

## Charlists

Charlists erstellst du mit dem Sigil `~c`.

```elixir
~c"hello"
```

~~~~exercism/note
Beachte, dass Charlists in älteren Elixir-Versionen mit einfachen Anführungszeichen als `'hello'` dargestellt werden.
~~~~

Obwohl sie Strings sehr ähnlich sehen, sind diese beiden Datentypen ganz verschieden voneinander. Eine Charlist ist eine Liste von Ganzzahlen. Die Ganzzahlen stehen für die Unicode-Werte eines bestimmten Zeichens, auch Codepunkte genannt.

```elixir
[65, 66, 67]
# => ~c"ABC"
```

Du kannst einem Zeichen ein `?` voranstellen, um seinen Codepunkt zu erhalten.

```elixir
?A
# => 65

[?:, ?)]
# => ~c":)"
```

Weil Charlists Listen sind, kannst du mit ihnen genauso arbeiten wie mit jeder anderen Liste, nämlich mit Rekursion und Pattern Matching.

```elixir
[first_letter | _] = ~c"cat"
first_letter
# => 99
```

Du kannst zwei Listen mit `++` verketten.

```elixir
~c"hi" ++ ~c"!"
# => ~c"hi!"
```

Je länger die erste Liste ist, desto langsamer läuft das Verketten. Deshalb solltest du es vermeiden, wiederholt an Listen beliebiger Länge anzuhängen.

## Case

`case` ist eine Kontrollstruktur, mit der du einen gegebenen Wert mit vielen Mustern vergleichen kannst. Die Klauseln in einem `case`-Ausdruck werden von oben nach unten ausgewertet, bis eine Übereinstimmung gefunden wird.

```elixir
age = 15

case age do
  0 -> ~c"infant"
  age when age < 4 -> ~c"baby"
  age when age < 13 -> ~c"child"
  age when age < 18 -> ~c"teenager"
  _ -> ~c"adult"
end

# => ~c"teenager"
```
