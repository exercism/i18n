# Hinweise

## 1. Binärdarstellung in eine Ganzzahl umwandeln

- Es gibt eine [eingebaute Methode][string-to_i], um einen String mit einer Binärdarstellung unter Angabe der Basis in eine Ganzzahl umzuwandeln.

## 2. Niedrigstwertiges Bit aus einer Ganzzahl ermitteln

- Es gibt eine [eingebaute Methode][integer-bit], um unter Angabe eines Index ein Bit aus einer Ganzzahl zu ermitteln.
- Das niedrigstwertige Bit ist das Bit, das am weitesten rechts steht.
  Es steht an Index 0.

## 3. Hex-Wert aus einem Farbkanal ermitteln

- Es gibt eine [eingebaute Methode][integer-to_s], um eine Ganzzahl unter Angabe der Basis in einen String mit einer Hexadezimaldarstellung umzuwandeln.
- Die Methode kann ein optionales Argument annehmen, um die Genauigkeit der Anzahl erzeugter Ziffern festzulegen.

## 4. Hex-Wert aus RGB ermitteln

- Du kannst bereits definierte Methoden verwenden, um den Hex-Wert aus einem Farbkanal zu ermitteln.
