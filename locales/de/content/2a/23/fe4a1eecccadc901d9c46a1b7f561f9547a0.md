# Überblick

Ternäre Operatoren ermöglichen es, `if`-Bedingungen in Ausdrücken statt in Anweisungsblöcken zu definieren. Das erinnert an Ansätze der funktionalen Programmierung und kann den Code oft ausdrucksstärker und weniger fehleranfällig machen.

Der ternäre Operator kombiniert drei Ausdrücke: eine Bedingung, gefolgt von einem Ausdruck, der ausgewertet und zurückgegeben wird, wenn die Bedingung wahr ist (der `if`-Teil, eingeleitet durch `?`), und einem Ausdruck, der ausgewertet und zurückgegeben wird, wenn die Bedingung falsch ist (der `else`-Teil, eingeleitet durch `:`).

```haxe
trace(true ? "Haxe" : "Not Haxe"); // Haxe
trace(1 == 2 ? "Something is wrong" : "That's obvious"); // That's obvious
```
