# Anleitung

Eine Schule in deiner Nähe hat eine sehr aktive Schülervereinigung.
Die Schülervereinigung wird von einem Präsidenten geleitet, und alle zwei Jahre findet eine Wahl statt, um einen neuen Präsidenten zu wählen.

Bei der diesjährigen Wahl wurde entschieden, dass ein neues digitales System zum Auszählen der Stimmen gebraucht wird. Die Schule braucht deine Hilfe, um dieses neue System zu bauen.

## 1. Ermittle die Anzahl der Stimmen aus einem `ElectionResult`

Das neue System braucht eine Möglichkeit, die Anzahl der Stimmen aus einem Zähler zu ermitteln.

Das Struct für das Wahlergebnis ist bereits für dich erstellt und ist so definiert:

```cpp
struct ElectionResult {
    // Name of the candidate
    std::string name{};
    // Number of votes the candidate has
    int votes{};
};
```

Da alle Mitglieder im `struct` öffentlich sind, musst du keinen `constructor` schreiben, um ein `ElectionResult`-Objekt zu initialisieren.
Stattdessen kannst du eine `initializer list` verwenden:

```cpp
ElectionResult hamilton{"Alex", 1804};
// => the hamilton object was initialized with the name "Alex" and 1804 votes.
```

Erstelle eine Funktion `vote_count`, die eine Referenz auf ein `ElectionResult` als Argument entgegennimmt und die Anzahl der Stimmen im `ElectionResult` zurückgibt.

```cpp
vote_count(hamilton);
// => 1804
```

## 2. Erhöhe die Stimmen eines `ElectionResult`

Endlich ist es Zeit, die Stimmen auszuzählen!
Jetzt brauchst du eine Möglichkeit, die Stimmen in einem `ElectionResult` zu erhöhen.

Erstelle eine `void`-Funktion `increment_vote_count`, die eine Referenz auf ein `ElectionResult` und eine Anzahl von Stimmen als Argumente entgegennimmt und das `ElectionResult` um diese Anzahl von Stimmen erhöht.

```cpp
ElectionResult burr{"Aaron " 1801};

increment_vote_count(burr, 3);

vote_count(burr);
// => 1804
```

## 3. Stimmenauszählung und Präsidentschaft

Die Schule hat ihre Stimmen abgegeben, und jetzt ist es Zeit, die Ergebnisse zu prüfen, um den Gewinner zu ermitteln.

Erstelle eine Funktion `determine_result`, die eine Referenz auf ein Endergebnis entgegennimmt und eine Referenz auf das `ElectionResult` des neuen Präsidenten zurückgibt.
Sie soll außerdem den Namen des Gewinners ändern, indem sie ihm "President" voranstellt.
Das Endergebnis wird in Form einer `reference` auf `std::vector<ElectionResult>` übergeben, einem Vektor mit den `ElectionResults` aller teilnehmenden Kandidaten.

```cpp
ElectionResult sanchez{"Pedro", 471};
ElectionResult wheatley{"Summer", 340};
std::vector<ElectionResult> final_count{sanchez, wheatley};

ElectionResult& winner = determine_result(final_count);

winner.name;
// => "President Pedro"
```

Um es einfach zu halten, kannst du Folgendes annehmen:
- Der `vector` hat mindestens ein Element.
- Es gibt keinen Gleichstand um den ersten Platz.
