# Einführung

Der Typ `Option` ist der Mechanismus der Sprache F# für den Umgang mit Werten, die es geben kann oder auch nicht.
Er ist eine typsichere Alternative zur Verwendung von `null`, die in anderen Sprachen häufig für solche Werte genutzt wird.
Er kommt in vielen Funktionen der F#-Standardbibliothek vor, deshalb ist es wichtig, ihn zu verstehen, wenn du die F#-Standardbibliothek effektiv nutzen willst.

## Verwendung

Der Typ `Option` ist ein generischer Typ (er hat einen zugrunde liegenden Typ).
Ein `Option`-Wert ist entweder `Some value` und steht für einen konkreten Wert, oder `None` und steht für keinen Wert.

Die folgende Funktion zeigt, wie du einen `Option`-Wert erzeugst:

```fsharp
let keepIfPositive (a: int) : int option = if a > 0 then Some a else None
```

~~~~exercism/note
`T option` ist die Postfix-Syntax, die `Option<T>` entspricht; beide Schreibweisen kannst du austauschbar verwenden.
Laut F#-Style-Guide ist bei Option-Typen jedoch die Postfix-Notation zu bevorzugen (siehe [Abschnitt „Formatierung von Typen und Typannotationen“ im F#-Style-Guide](https://learn.microsoft.com/en-us/dotnet/fsharp/style-guide/formatting#for-types-prefer-prefix-syntax-for-generics-foot-with-some-specific-exceptions)).
~~~~

## Den Inhalt eines Option-Werts lesen

Der idiomatische Weg, einen `Option`-Wert auszulesen, ist der Musterabgleich, wie das folgende Beispiel zeigt:

```fsharp
// Returns "Hello, <name>!" if the name is provided; otherwise returns "Hello, you!"
let sayHello (optionalName: string option): string = 
    match optionalName with
    | Some name -> "Hello, " + name + "!"
    | None -> "Hello, you!"

sayHello (Some "Matthieu")
// --> "Hello, Matthieu!"

sayHello None
// --> "Hello, you!"
```

## Options mit Standardwerten entpacken

Du kannst `Option`-Werte „entpacken“ (in ihren enthaltenen Typ umwandeln), indem du mit der Funktion `Option.defaultValue` einen Standardwert angibst.
Das ist besonders nützlich, wenn du sicherstellen willst, dass der Wert nicht `None` ist.
Zum Beispiel:

```fsharp
Option.defaultValue "" (Some "F#")
// --> "F#"

Option.defaultValue 0 None
// --> 0
```
