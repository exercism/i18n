# TODO-Kommentar

Es sieht so aus, als hättest du ein paar „TODO“- oder „FIXME“-Kommentare in deinem Code hinterlassen.

Solche Kommentare sind super, um dich daran zu erinnern, was du später in deinem Code noch verbessern wolltest. Vergiss nicht, all diese Verbesserungen umzusetzen, bevor du die Übung abschließt, und entferne die Kommentare, wenn sie nicht mehr zutreffen.
