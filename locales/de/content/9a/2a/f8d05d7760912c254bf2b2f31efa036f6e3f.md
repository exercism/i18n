# Anleitung

Als Schachfan würdest du gerne deine eigene Version des Spiels schreiben. Ja, es gibt online vielleicht schon jede Menge Schach-Implementierungen, aber deine wird einzigartig sein!

Doch bevor du deiner Fantasie freien Lauf lassen kannst, musst du dich um die Grundlagen kümmern. Fangen wir damit an, das Brett zu erzeugen.

Jedes Feld des Schachbretts wird durch ein Buchstaben-Zahlen-Paar identifiziert. Die senkrechten Spalten der Felder heißen Linien und sind mit A bis H beschriftet. Die waagerechten Zeilen der Felder heißen Reihen und sind mit 1 bis 8 nummeriert.

## 1. Definiere den Bereich der Reihen

Implementiere die Funktion `rank_range()`. Sie sollte einen Bereich von Ganzzahlen von 1 bis 8 zurückgeben.

```julia-repl
julia> rank_range()
# output omitted
```

## 2. Definiere den Bereich der Linien

Implementiere die Funktion `file_range()`. 
Sie sollte einen Bereich von Zeichen zurückgeben, vom Großbuchstaben A bis zum Großbuchstaben H.

```julia-repl
julia> file_range()
# output omitted
```

## 3. Wandle den Bereich der Reihen in einen Vektor von Reihen um

Implementiere die Funktion `ranks()`. Sie sollte einen Vektor von Ganzzahlen von 1 bis 8 zurückgeben. 
Schreibe den Vektor nicht von Hand, sondern erzeuge ihn aus dem Bereich, den die Funktion `rank_range()` zurückgibt.

```julia-repl
julia> ranks()
[1, 2, 3, 4, 5, 6, 7, 8]
```

## 4. Wandle den Bereich der Linien in einen Vektor von Linien um

Implementiere die Funktion `files`. Sie sollte einen Vektor von Zeichen von 'A' bis 'H' zurückgeben. 
Schreibe den Vektor nicht von Hand, sondern erzeuge ihn aus dem Bereich, den die Funktion `file_range()` zurückgibt.

```julia-repl
julia> files()
['A', 'B', 'C', 'D', 'E', 'F', 'G', 'H']
```
