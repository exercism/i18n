# Über

Ein Methodenparameter kann optional gemacht werden, indem du ihm einen Standardwert zuweist. Wenn ein Parameter optional ist, muss der Aufrufer kein Argument für diesen Parameter angeben; in diesem Fall wird der Standardwert verwendet. [Optionale Parameter][optional-arguments] _müssen_ am Ende der Parameterliste stehen; nach ihnen dürfen keine nicht-optionalen Parameter folgen. Wenn eine Methode mehrere optionale Parameter hat, kannst du mit [benannten Argumenten][named-arguments] nur einige davon angeben.

```csharp
class Card
{
    static string NewYear(int year = 2020, string sender = "me")
    {
        return $"Happy {year} from {sender}!";
    }
}

Card.NewYear();     // => "Happy 2020 from me!"
Card.NewYear(1999); // => "Happy 1999 from me!"
Card.NewYear(sender: "mom"); // => "Happy 2020 from mom!"
```

Der Wert eines optionalen Parameters muss eines der Folgenden sein:

- Ein konstanter Ausdruck (z. B. `"hi"`, `2`, `DayOfWeek.Friday`, `null` usw.)
- Ein `new`-Ausdruck eines Werttyps
- Ein `default`-Ausdruck eines Werttyps
