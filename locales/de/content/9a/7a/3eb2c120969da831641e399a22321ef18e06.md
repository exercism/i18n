# Überblick

## For-Schleifen

Eine `for`-Anweisung wiederholt einen Block Code.
Ihre erste Zeile steuert, wie oft der Block wiederholt wird:

```go
for init; condition; post {
    // loop body
}
```

- Die **Initialisierung** ist eine Anweisung, die einmal vor der ersten Iteration ausgeführt wird. Häufig deklarierst und initialisierst du dort eine Zählervariable für die Schleife.
- Die **Bedingung** ist ein boolescher Ausdruck, der vor jeder Iteration ausgewertet wird. Die Schleife endet, sobald er zu `false` auswertet.
- Die **Post**-Anweisung wird nach jeder abgeschlossenen Iteration ausgeführt. Du kannst sie verwenden, um einen Zähler zu aktualisieren.

Setze `init; condition; post` nicht in runde Klammern.
Die geschweiften Klammern `{ }` um den Schleifenblock sind jedoch immer erforderlich.

Diese Schleife startet `i` bei `1`, gibt den aktuellen Wert von `i` aus, erhöht ihn für die nächste Iteration und endet, wenn `i` den Wert `10` erreicht:

```go
for i := 1; i < 10; i++ {
    fmt.Println(i)
}
```

## Weitere Schleifenformen

### Schleife nur mit Bedingung

Die Initialisierung und die Post-Anweisung kannst du weglassen.
Eine `for`-Anweisung nur mit Bedingung erfüllt denselben Zweck wie eine `while`-Schleife in anderen Sprachen.
In Go gibt es kein Schlüsselwort `while`.

```go
sum := 1
for sum < 1000 {
    sum += sum
}
fmt.Println(sum)
// Output: 1024
```

### Unendliche Schleife

Eine `for`-Anweisung kannst du auch ohne Bedingung schreiben:

```go
for {
    // loop body
}
```

Diese Schleife endet nicht von selbst.
Die Ausführung muss die Schleife explizit verlassen, zum Beispiel mit `break` oder `return`.

## Schleifen steuern

### Break und Continue

In dieser Schleife beendet `break` die Schleife:

```go
for n := 0; n <= 5; n++ {
    if n == 3 {
        break
    }
    fmt.Println(n)
}
// Output:
// 0
// 1
// 2
```

`continue` überspringt den Rest des aktuellen Schleifenblocks und beginnt die nächste Iteration:

```go
for n := 0; n <= 5; n++ {
    if n % 2 == 0 {
        continue
    }
    fmt.Println(n)
}
// Output:
// 1
// 3
// 5
```

### Break und Continue mit Labels

Bei verschachtelten Schleifen wirkt sich ein `break` oder `continue` ohne Label auf die innerste Schleife aus.
Um eine äußere Schleife zu labeln, setzt du einen Bezeichner gefolgt von einem Doppelpunkt in die Zeile direkt darüber.
Dann schreibst du das Label der Schleife hinter `break` oder `continue`, um die Aktion auf sie zu richten:

```go
OuterLoop:
for i := 0; i < 10; i++ {
    for j := 0; j < 10; j++ {
        if i + j == 10 {
            break OuterLoop
        }
    }
}
```
