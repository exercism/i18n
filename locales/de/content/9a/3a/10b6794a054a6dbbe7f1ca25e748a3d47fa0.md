# Über

Standardmäßig sind Variablen auf den Gültigkeitsbereich beschränkt, in dem sie definiert werden. Wenn sie in einer Datei außerhalb einer Funktion oder Klasse definiert werden, sind sie auf den Gültigkeitsbereich der Datei beschränkt. Wenn sie in einer Funktion oder Klasse definiert werden, sind sie auf den Gültigkeitsbereich der Funktion oder Klasse beschränkt.

```php
<?php

$file_scoped = "I am file scoped";

function example(): void
{
  $function_scoped = "I am function scoped!";
}
```

## Globaler Gültigkeitsbereich

Mit dem Schlüsselwort `global` vor einer Variablenzuweisung erstellst du eine Variable mit globalem Gültigkeitsbereich. Von diesem Muster wird oft abgeraten, da es zu [stark gekoppeltem Code](<https://en.wikipedia.org/wiki/Coupling_(computer_programming)#Disadvantages_of_tight_coupling>) führt.

```php
function example(): void
{
  global $hello = "World!";
}

echo $hello; // #=> "World!"
```

## Statischer Gültigkeitsbereich

Wenn du das Schlüsselwort `static` vor einer Variablenzuweisung oder -deklaration verwendest, bleibt der Gültigkeitsbereich der Variablen erhalten, ihr Wert bleibt jedoch zwischen den Ausführungsbereichen bestehen.

```php
function counter(): int
{
  static $count = 0;
  $count += 1;
  return $count;
}
```

In diesem Beispiel wird die Variable `$count` _nur beim ersten Funktionsaufruf_ auf 0 initialisiert. Bei jedem weiteren Aufruf wird der Wert in den nächsten Aufruf übernommen. Jeder Aufruf der Funktion gibt also eine immer größer werdende Ganzzahl zurück.
