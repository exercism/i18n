# Ergänzung zu den Anweisungen

## Reservierter Speicher

Der Puffer für den Eingabe-String verwendet die Bytes 64-191 des linearen Speichers.


## Ausgabeformat

Die Zahlenreihe wird als ein durchgehendes Array aus u8-Zahlen erwartet; bei der Deserialisierung wird es nach Länge aufgeteilt:

```js
slice("123456", 3) => UInt8Array[1, 2, 3,   2, 3, 4,   3, 4, 5,   4, 5, 6]
// will be split into          [[1, 2, 3], [2, 3, 4], [3, 4, 5], [4, 5, 6]]
```
