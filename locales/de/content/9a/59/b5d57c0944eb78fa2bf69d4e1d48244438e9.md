# Anleitung

Du bist ein begeisterter Vogelbeobachter und hältst fest, wie viele Vögel in den letzten sieben Tagen deinen Garten besucht haben.

Es gibt sechs Aufgaben, die sich alle mit der Anzahl der Vögel befassen, die deinen Garten besucht haben.

## 1. Prüfe, wie die Zählungen letzte Woche waren

Zu Vergleichszwecken hast du immer eine Kopie der Zählungen der letzten Woche in der Nähe, und zwar: 0, 2, 5, 3, 7, 8 und 4. Definiere die Bindung `lastWeek`, die die Zählungen der letzten Woche enthält:

```fsharp
lastWeek
// => [| 0; 2; 5; 3; 7; 8; 4 |]
```

## 2. Prüfe, wie viele Vögel gestern zu Besuch waren

Implementiere die Funktion `yesterday`, die zurückgibt, wie viele Vögel gestern deinen Garten besucht haben. Die Vogelzählungen sind nach Tagen geordnet, wobei das erste Element die Zählung des ältesten Tages und das letzte Element die heutige Zählung ist.

```fsharp
yesterday [| 3; 5; 0; 7; 4; 1 |]
// => 4
```

## 3. Berechne die Gesamtzahl der zu Besuch gekommenen Vögel

Implementiere die Funktion `total`, die die Gesamtzahl der Vögel zurückgibt, die deinen Garten besucht haben:

```fsharp
total [| 3; 5; 0; 7; 4; 1 |]
// => 20
```

## 4. Prüfe, ob es einen Tag ohne zu Besuch gekommene Vögel gab

Implementiere die Funktion `dayWithoutBirds`, die `true` zurückgibt, wenn es einen Tag gab, an dem null Vögel den Garten besucht haben; andernfalls gibt sie `false` zurück:

```fsharp
dayWithoutBirds [| 3; 5; 0; 7; 4; 1 |]
// => true
```

## 5. Erhöhe die heutige Zählung

Implementiere die Funktion `incrementTodaysCount`, um die heutige Zählung zu erhöhen und die aktualisierten Zählungen zurückzugeben:

```fsharp
let birdCount = [| 3; 5; 0; 7; 4; 1 |]
incrementTodaysCount birdCount
// => [| 3; 5; 0; 7; 4; 2 |]
```

## 6. Prüfe auf eine ungewöhnliche Woche

Im letzten Jahr hast du festgestellt, dass manche Wochen dieselben, ungewöhnlichen Muster haben:
- An jedem geraden Tag der Woche gab es keine Vögel
- An jedem geraden Tag der Woche wurden genau 10 Vögel gesichtet
- An jedem ungeraden Tag der Woche wurden genau 5 Vögel gesichtet

Implementiere die Funktion `unusualWeek`, die `true` zurückgibt, wenn das Vogelzählmuster dieser Woche einem der ungewöhnlichen Muster entspricht:

```fsharp
unusualWeek [| 1; 0; 5; 0; 12; 0; 2 |]
// => true

unusualWeek [| 5; 0; 5; 12; 5; 3; 5|]
// => true
```

(Beachte, dass die Tagesparität 1-basiert ist und nicht 0-basiert: Das erste Element im Array entspricht einem ungeraden Tag)
