# Einführung

Binärziffern entsprechen letztlich direkt den Transistoren in deiner CPU oder deinem RAM und deren Zustand „an" oder „aus".

Low-Level-Manipulation, umgangssprachlich „Bit-Twiddling" genannt, ist in Systemsprachen besonders wichtig.

Höhere Sprachen wie Kotlin abstrahieren die meisten dieser Details normalerweise weg. Ein grundlegender Satz von Bit-Operationen [ist aber verfügbar][ref-bitwise].

## Bit-Shift-Operationen

Die Typen `Int` oder `Long`, mit oder ohne Vorzeichen, lassen sich als Folge von Einsen und Nullen darstellen und als Bitsequenz manipulieren.

Vielleicht überraschend: Die Typen `Byte` oder `Short` sind in Kotlin mit den meisten bitweisen Operationen nicht kompatibel. Alle Beispiele unten verwenden 32-Bit-Ganzzahlen (`Int` oder `UInt`).

```kotlin
val ns = 0b111  // 7 decimal
Integer.toBinaryString(ns)  // => "111"
```

Bit-Shifts verschieben alles um eine bestimmte Anzahl von Positionen nach links oder rechts. An einem Ende fallen Bits heraus, und das andere Ende wird mit Nullen oder Einsen aufgefüllt.

- Linksverschiebung mit `shl`: Auffüllen mit Nullen.
- Rechtsverschiebung mit `shr` oder `ushr`: Auffüllen mit Nullen bei positiven Zahlen (zu negativen Zahlen später mehr).

```kotlin
val ns = 0b111  // 7 decimal
ns shl 1  // => 0b1110, decimal 14
ns shr 1  // => 0b11, decimal 3
ns ushr 1  // => 0b11

val nu: UInt = 0b111u  // 7 unsigned
nu shr 1  //  => 0b11
```

Jede Verschiebung nach links verdoppelt den Wert, jede nach rechts halbiert ihn (mit Abschneiden). In der Dezimaldarstellung ist das deutlicher:

```kotlin
3 shl 2  // => 12
24 shr 3 // => 3
```

Solche Bit-Shifts sind viel schneller als „richtige" Arithmetik, weshalb die Technik im Low-Level-Coding sehr beliebt ist.

Bei _negativen Ganzzahlen_ müssen wir etwas vorsichtiger sein.

Negative Werte werden im [Zweierkomplement][wiki-2complement] gespeichert, das heißt, das linkeste Bit ist 1. Für eine Linksverschiebung kein Problem, aber wie füllen wir beim Rechtsverschieben die linkesten Bits auf?

```kotlin
val ns = -0b111  // => 0b11111111111111111111111111111001

// shift left: simple
ns shl 1  // => 0b11111111111111111111111111110010, decimal -14

// shift right: preserves sign bit
ns shr 1  // => 0b11111111111111111111111111111100, decimal -4

// unsigned shift right: left-pads with zeros
ns ushr 1 // => 0b01111111111111111111111111111100, decimal 2147483644
```

Der Operator `shr` führt eine [arithmetische Verschiebung][wiki-arithmetic] aus und bewahrt das Vorzeichenbit.

Der Operator `ushr` führt eine [logische Verschiebung][wiki-logical] aus und füllt mit Nullen auf, als wäre die Zahl vorzeichenlos.

## Bitweise Logik

Im [Konzept Booleans][concept-booleans] haben wir gesehen, dass die Operatoren `&&` (und), `||` (oder) und `!` (nicht) mit booleschen Werten verwendet werden.

Es gibt entsprechende Operatoren `and`, `or`, `xor` ([exklusives Oder][wiki-xor]), um die Bits zweier Ganzzahlen zu vergleichen, sowie eine Funktion `inv` (Inversion), um alle Bits umzukehren.

```kotlin
0b1011 and 0b0010 //  bit is 1 in both numbers
// => 0b0010

0b1011 or 0b0010 // bit is 1 in at least one number
// => 0b1011

0b1011 xor 0b0010 // bit is 1 in exactly one number, not both
// => 0b1001

0b1011.inv() // flip all bits (in a 32-bit signed Int)
// => 0b11111111111111111111111111110100
```
