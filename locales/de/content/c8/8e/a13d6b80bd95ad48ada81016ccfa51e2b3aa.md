# Grundlagen

Ein Sather-Programm besteht aus **Klassen**, die **Routinen** enthalten.

```sather
class GREETER is

   hello : STR is
      return "Hello!";
   end;

end; -- class GREETER
```

## Klassen

Eine Klasse wird in Großbuchstaben benannt, mit Unterstrichen zwischen den Wörtern:
`GREETER`, `STAGE_DIRECTIONS`. Der Name der Datei passt meist dazu, in
Kleinschreibung: `stage_directions.sa`.

Jede Routine lebt in einer Klasse. Es gibt keinen Code außerhalb einer Klasse.

## Routinen

Eine Routine, die ein Ergebnis liefert, deklariert nach einem Doppelpunkt die Art
des Ergebnisses:

```sather
   hello : STR is
      return "Hello!";
   end;
```

`STR` ist der Typ für Text. Eine Routine, die keine Argumente entgegennimmt,
wird ohne runde Klammern geschrieben und aufgerufen.

Eine Routine kann Argumente entgegennehmen, die in runden Klammern nach dem Namen
stehen:

```sather
   louder(word : STR) : STR is
      return word;
   end;
```

`return` gibt ein Ergebnis zurück und beendet die Routine sofort, sodass alle
Zeilen darunter übersprungen werden.

## Aufrufen

Von außerhalb der Klasse nennst du die Klasse, dann `::`, dann die Routine:

```sather
GREETER::hello
```

Innerhalb derselben Klasse kannst du den Klassennamen weglassen. So lässt du
üblicherweise eine Routine eine andere verwenden:

```sather
   greeting_again : STR is
      return hello;
   end;
```

## Kommentare

Zwei Bindestriche beginnen einen Kommentar, der bis zum Ende der Zeile geht.

```sather
   -- Explain why, not what: the code already says what.
   hello : STR is
      return "Hello!";   -- a trailing comment is fine too
   end;
```

Konventionell endet eine Klasse mit einem Kommentar, der sie benennt. Routinen,
Schleifen und Klassen enden alle mit `end;`, daher sagt der Kommentar, zu welcher
dieses `end;` gehört:

```sather
end; -- class GREETER
```

## Semikolons

Anweisungen enden mit einem Semikolon. Das Semikolon nach der letzten Anweisung
in einer Routine ist optional, aber es jedes Mal zu schreiben, erspart dir einen
Gedanken.
