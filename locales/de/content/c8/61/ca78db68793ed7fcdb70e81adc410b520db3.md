# Überblick

Ein wichtiger Aspekt bei der Arbeit mit Zahlen in F# ist der Unterschied zwischen Ganzzahlen (Zahlen ohne Nachkommastellen) und Gleitkommazahlen (Zahlen mit null oder mehr Nachkommastellen).

Die beiden am häufigsten verwendeten numerischen Typen in F# sind `int` (eine 32-Bit-Ganzzahl) und `float` (eine 64-Bit-Gleitkommazahl).

```fsharp
let i = 123   // Type is `int`
let d = 54.29 // Type is `float`
```

Sowohl Ganzzahlen als auch Gleitkommazahlen können das Zeichen `_` als _Zifferntrennzeichen_ verwenden, was beim Definieren großer Zahlen helfen kann:

```fsharp
let largeInt = 1_000_000
// => 1000000

let largeFloat = 9_876_543.21
// => 9876543.21
```

Für Rechenoperationen verwendest du die üblichen [arithmetischen Operatoren][arithmetic-operators] (`+`, `-`, `*` usw.). Zahlen kannst du mit den [Standard-Vergleichsoperatoren][comparison-operators] (`<`, `>=` usw.) sowie den Operatoren für Gleichheit (`=`) und Ungleichheit (`<>`) vergleichen.

```fsharp
5 * 6
// => 30

1.2 > 0.8
// => true

2 <> 4
// => true
```

Um zwischen numerischen Typen umzuwandeln, musst du den eingebauten [Konvertierungsoperator][conversion-operators] verwenden. Diese Operatoren sind nach dem Typ benannt, in den sie umwandeln.

```fsharp
let floatFromInt = float 2
let intFromFloat = int 3.39
```

Sei beim Umwandeln zwischen Typen immer vorsichtig. Wenn ein Wert vom Zieltyp nicht dargestellt werden kann, kommt es zu einem _Überlauf_.
