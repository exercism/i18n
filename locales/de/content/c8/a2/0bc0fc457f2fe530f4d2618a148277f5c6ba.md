# Anweisungen

In dieser Übung implementierst du einige Funktionen, mit denen du eine Liste von Programmiersprachen bearbeitest.

## 1. Definiere eine Funktion, die eine leere Sprachenliste zurückgibt

Definiere die Funktion `language_list`, die keine Argumente entgegennimmt und eine leere Liste zurückgibt.

```php
<?php

language_list();
// => []
```

## 2. Ändere die Funktion, sodass sie aus beliebig vielen Sprachen eine Liste erstellt

Ändere die Funktion `language_list` so, dass sie ein variadisches Argument mit Sprachen (Strings) entgegennimmt. Sie soll die resultierende Liste mit den Sprachen in der Liste zurückgeben.

```php
<?php

$language_list = language_list();
// => []
$language_list = language_list("Clojure", "PHP");
// => ["Clojure", "PHP"]
$language_list = language_list("PHP", "Haskell", "Java", "C++", "Rust")
// => ["PHP", "Haskell", "Java", "C++", "Rust"]
```

## 3. Definiere eine Funktion, die eine Sprache zur Liste hinzufügt

Definiere die Funktion `add_to_language_list`, die zwei Argumente entgegennimmt: ein Array von Sprachen und die neue Sprache.

```php
<?php

$language_list = language_list();
// => []
$language_list = add_to_language_list($language_list, "Clojure");
// => ["Clojure"]
```

## 4. Definiere eine Funktion, die ein Element aus der Sprachenliste entfernt

Definiere die Funktion `prune_language_list`, um die erste Sprache aus dem Array von Sprachen zu entfernen.

```php
<?php

$language_list = language_list("PHP");
// => ["PHP"]
$language_list = prune_language_list($language_list);
// => []
```

## 5. Definiere eine Funktion, die das erste Element der Liste zurückgibt

Definiere die Funktion `current_language`, die ein Argument entgegennimmt (eine _Sprachenliste_). Sie soll die erste Sprache in der Liste zurückgeben. Geh davon aus, dass die Liste immer mindestens ein Element enthält.

```php
<?php

$language_list = language_list("PHP", "Prolog");
// => ["PHP", "Prolog"]
$first = current_language($language_list);
// => "PHP"
```

## 6. Definiere eine Funktion, die zurückgibt, wie viele Sprachen in der Liste sind

Definiere die Funktion `language_list_length`, die ein Argument entgegennimmt (eine _Sprachenliste_). Sie soll die Anzahl der Sprachen in der Liste zurückgeben.

```php
<?php

$language_list = language_list("PHP", "Prolog", "Wren");
// => ["PHP", "Prolog", "Wren"]
language_list_length($language_list);
// => 3
```
