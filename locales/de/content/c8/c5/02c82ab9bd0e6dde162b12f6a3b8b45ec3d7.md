# If, Elseif, Else

Bedingte Anweisungen mit `if`, `elseif` und `else` sind ein grundlegender Teil des Kontrollflusses eines Programms.
Die `if`-Anweisung wertet einen Ausdruck aus und führt den Codezweig aus, wenn dieser `true` ist.

```php
<?php

if ($expression) {
    // .. executed if $expression is true
}
```

Wenn der Ausdruck kein boolescher Wert ist, entscheidet die Auswertung, ob der Wert als wahr oder als falsch zählt.
In PHP gelten die folgenden Werte als falsch:

- der boolesche Wert `false`
- die Ganzzahl `0`
- die Gleitkommazahl `0.0` und `-0.0`
- ein leeres Array `[]`
- ein leerer String `""` oder ein numerischer String `"0"`
- `null`

Alle anderen Werte gelten als wahr.

## Auf mehrere Bedingungen reagieren

An eine `if`-Anweisung kannst du mehrere Bedingungen mit `elseif` und `else` anschließen.

```php
<?php

if ($value === 0) {
    // .. do something
} elseif ($value === 1) {
    // .. do something else
} else {
    // ,, do this if nothing else
}
```

Nur eine bedingte Anweisung, die als wahr ausgewertet wird, wird ausgeführt.
Wenn also mehrere Bedingungen als wahr ausgewertet werden können, ist die Reihenfolge, in der sie geschrieben sind, wichtig.

```php
<?php

if (true) {
    // .. always do something
} elseif (true)
    // .. will never be executed
} else {
    // .. will never be executed
}
```
