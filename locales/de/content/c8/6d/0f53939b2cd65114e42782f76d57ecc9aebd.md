# Anleitung

Josh arbeitet an einem neuen Rollenspiel und braucht deine Hilfe beim Umsetzen einiger Mechaniken.

## 1. Definiere Union-Typen

Definiere einen Union-Typ aus `String` und `Missing` mit dem Namen `StringOrMissing`, der später im Code verwendet werden kann.
Definiere einen Union-Typ aus `Int64` und `Nothing` mit dem Namen `IntOrNothing`, der später im Code verwendet werden kann.

## 2. Implementiere den zusammengesetzten Typ Player

Der zusammengesetzte Typ Player sollte vier Felder enthalten, jedes mit einer Typannotation und einem Standardwert:
- `name` ist ein `StringOrMissing` mit dem Standardwert `missing`
- `level` ist ein `Int64` mit dem Standardwert `0`
- `health` ist ein `Int64` mit dem Standardwert `100`
- `mana` ist ein `IntOrNothing` mit dem Standardwert `nothing`

```julia-repl
julia> defaultplayer = Player()
Player(missing, 0, 100, nothing)

julia> wealthyplayer = Player(mana=100)
Player(missing, 0, 100, 100)

julia> namedplayer = Player(name="Guilian", level=10)
Player("Guilian", 10, 100, nothing)
```

## 3. Stelle dich vor

Implementiere die Funktion `introduce`.

Heimliche Spieler verbergen möglicherweise ihren Namen und werden als `"Mighty Magician"` vorgestellt.
Ansonsten stelle sie einfach mit dem Namen des Spielers vor.

```julia-repl
julia> introduce(Player(level=2, health=8))
"Mighty Magician"

julia> introduce(Player(name="Merlin", level=2, health=8))
"Merlin"
```

## 4. Implementiere die increment-Methoden

Die Hilfsfunktion `increment` hat zwei Methoden mit jeweils einer anderen Funktionssignatur.
Das Argument jeder Methode braucht eine Typannotation, damit die Signatur eindeutig ist.

Die `increment`-Methode für Namen sollte den `name` eines Spielers entgegennehmen.
- Wenn der Name `missing` ist, gib den Titel "The Great" zurück.
- Andernfalls wird der Titel " the Great" an den Namen angehängt.

Diese `increment`-Methode gibt den neuen Namen zurück.

```julia-repl
julia> player1 = Player(name="Ogre", level=5, health=49, mana=26)
Player("Ogre", 5, 49, 26)

julia> increment(player1.name)
"Ogre the Great"

julia> player2 = Player(level=32, mana=57)
Player(missing, 32, 100, 57)

julia> increment(player2.name)
"The Great"
```

Die `increment`-Methode für Mana sollte den `mana` eines Spielers entgegennehmen.
- Wenn das Mana des Spielers `missing` ist, gib den Wert `50` zurück.
- Andernfalls wird das Mana um `100` erhöht.

Diese `increment`-Methode gibt das aktualisierte Mana zurück.

```julia-repl
julia> player3 = Player(level=3)
Player(missing, 3, 100, nothing)

julia> increment(player3.mana)
50

julia> player4 = Player("Goblin", level=15, health=49, mana=26)
Player("Goblin", 5, 49, 26)

julia> increment(player4.mana)
126
```

## 5. Implementiere die title-Funktion

Das höchste Level im Spiel ist `42`. Um die Leistung von Spielern zu würdigen, die dieses Level erreichen, wird ihrem Namen ein Titel angehängt. Die Funktion `title!` aktualisiert den Namen eines Spielers wie folgt.

- Wenn das Level des Spielers 42 ist, wird der Name mit der Funktion `increment` aktualisiert.
- Andernfalls bleibt der Name unverändert.

In beiden Fällen gibt die Funktion `title!` den Namen des Spielers zurück.

```julia-repl
julia> player1 = Player(level=42, health=12)
Player(missing, 42, 12, nothing)

julia> title!(player1)
"The Great"

julia> player1.name
"The Great"

julia> player2 = Player(name="Svengali", level=42, health=36, mana=54)
Player("Svengali", 42, 36, 54)

julia> title!(player2)
"Svengali the Great"

julia> player2.name
"Svengali the Great"

julia> player3 = Player(name="Rasputin", level=21, health=100, mana=54)
Player("Rasputin", 21, 100, 54)

julia> title!(player3)
"Rasputin"

julia> player3.name
"Rasputin"
```

## 6. Implementiere die revive-Funktion

Die Funktion `revive!` sollte prüfen, dass die Spielfigur tatsächlich tot ist (ihre Gesundheit hat `0` erreicht).

Wenn der Spieler tot ist:
- Der Spieler sollte mit `100` Gesundheit wiederbelebt werden.
- Das Mana des Spielers sollte mit der Funktion `increment` erhöht werden.

Wenn der Spieler lebt, geschieht nichts mit dem Spieler.

Die Funktion `revive!` sollte den Spieler zurückgeben.

```julia-repl
julia> deadplayer1 = Player(level=2, health=0)
Player(missing, 2, 0, nothing)

julia> revive!(deadplayer1)
Player(missing, 2, 100, 50)

julia> deadplayer2 = Player(level=12, health=0, mana=5)
Player(missing, 12, 0, 5)

julia> revive!(deadplayer2)
Player(missing, 12, 100, 105)

julia> aliveplayer = Player(level=23, health=1)
Player(missing, 23, 1, nothing)

julia> revive!(aliveplayer)
Player(missing, 23, 1, nothing)
```
