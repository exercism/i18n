# String-Methoden

`String` hat mehrere Methoden, mit denen du Strings bearbeiten kannst.
Diese Methoden werden auf dem String selbst aufgerufen und oft miteinander verkettet, um mehrere Operationen an einem String durchzuführen.

Das Folgende ist eine Liste einiger der häufigsten Methoden.
Eine vollständige Liste der Methoden findest du in der [`String`-API-Dokumentation][string-api].

## String#upcase & String#downcase

Die Methode [`upcase`][upcase] gibt einen neuen String zurück, bei dem alle Zeichen in Großbuchstaben umgewandelt werden.

```crystal
"hello".upcase
# => "HELLO"
```

Die Methode [`downcase`][downcase] gibt einen neuen String zurück, bei dem alle Zeichen in Kleinbuchstaben umgewandelt werden.

```crystal
"HELLO".downcase
# => "hello"
```

## String#sub & String#gsub

Crystal hat Methoden, um Teile eines Strings zu ersetzen.
Diese heißen [`sub`][sub] (_Substitution_) und [`gsub`][gsub] (_globale Substitution_).

Diese Methoden nehmen als erstes Argument einen String, ein Char oder ein Regex und als zweites Argument einen String oder ein Char.
Das erste Argument ist der Teil des Strings, der ersetzt wird, und das zweite Argument ist der Ersatz.
`Char` und Regex werden in späteren Konzepten erklärt.

Die `sub`-Methode ersetzt das erste Vorkommen des ersten Arguments durch das zweite Argument.

```crystal
"hello".sub("l", "r")
# => "herlo"
```

Die `gsub`-Methode funktioniert genauso wie `sub`, ersetzt aber alle Vorkommen des ersten Arguments durch das zweite Argument.

```crystal
"hello".gsub("l", "r")
# => "herro"
```

## String#chomp & String#strip

Mit Chomp und Strip kannst du unerwünschte Zeichen aus einem String entfernen.

Die Methode [`chomp`][chomp] entfernt standardmäßig die letzten Zeichen `\r`, `\n` oder `\r\n` aus einem String.
Wird die Methode mit einem Argument aufgerufen, entfernt sie den angegebenen Wert am Ende des Strings, sofern er dort vorkommt.

```crystal
"hello\n".chomp
# => "hello"

"hello".chomp("llo")
# => "he"
```

Standardmäßig entfernt die Methode [`strip`][strip] alle Leerzeichen am Anfang und Ende eines Strings.
Wird die Methode mit einem Argument aufgerufen, entfernt sie dieses Argument am Anfang und Ende des Strings, sofern es dort vorkommt.

```crystal
" hello ".strip
# => "hello"
```

## String#index

Mit der Methode [`index`][index] kannst du den Index eines Zeichens in einem String finden.
Die `index`-Methode nimmt einen `String`, ein `Char` oder ein Regex als Argument.
Optional kann sie ein zweites Argument annehmen, das den Index angibt, ab dem gesucht wird.
Die `index`-Methode gibt den Index des ersten Vorkommens des Arguments zurück.

```crystal
"hello".index("l")
# => 2

"hello".index("l", 3)
# => 3
```

## String#delete_at

Mit der Methode [`delete_at`][delete_at] kannst du ein Zeichen aus einem String entfernen.
Die `delete_at`-Methode nimmt einen Index als Argument und entfernt das Zeichen an diesem Index.

```crystal
"hello".delete_at(0)
# => "ello"

"hello".delete_at(3)
# => "helo"
```

## String#insert

Mit der Methode [`insert`][insert] kannst du einen String an einem bestimmten Index einfügen.
Die `insert`-Methode nimmt als erstes Argument einen Index und als zweites Argument einen String.
Die `insert`-Methode gibt einen neuen String zurück, bei dem das zweite Argument an dem Index eingefügt wurde.

```crystal
"hello".insert(0, "h")
# => "hhello"

"hello".insert(3, "l")
# => "helllo"
```
