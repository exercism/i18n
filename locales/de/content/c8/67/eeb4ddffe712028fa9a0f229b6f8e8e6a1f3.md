# Über

Der bedingte ternäre Operator ist dafür da, dass du einen kompakten Ausdruck schreiben kannst, der abhängig von einer Bedingung einen von zwei alternativen Werten zurückgibt.
Oft wird er als „ternärer Operator" bezeichnet.
Der Name rührt daher, dass der Operator drei Operanden hat: `predicate ? consequent-expression : alternative-expression`
Du kannst ihn als Ersatz für kurze if-else-Anweisungen verwenden.

Ähnlich wie bei `if`-Anweisungen führt JavaScript eine implizite Typumwandlung durch, um die Bedingung auszuwerten.
Wenn die Bedingung truthy ist, wird der Operand auf der linken Seite des Doppelpunkts zurückgegeben.
Andernfalls ist das Ergebnis des ternären Ausdrucks der Operand auf der rechten Seite des Doppelpunkts.

```javascript
const year = 2020;

year > 2000 ? 'in the past years' : 'a long time ago';
// => 'in the past years'
```
