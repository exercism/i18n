# Anleitung

Deine Freundin Li Mei betreibt eine Saftbar, in der sie köstliche
gemischte Fruchtsäfte verkauft. Du bist ein regelmäßiger Gast in
ihrem Laden und hast gemerkt, dass du ihr das Leben mit etwas
Factor-Code ein wenig erleichtern könntest.

## 1. Finde heraus, wie lange es dauert, einen Saft zu mixen

Li Mei sagt ihren Gästen gerne vorab, wie lange sie auf einen
Saft von der Karte warten müssen. Es fällt ihr schwer, sich die
genauen Zeiten zu merken, weil das Mixen der Säfte unterschiedlich
lange dauert:

- `"Pure Strawberry Joy"` dauert `0.5` Minuten.
- `"Energizer"` und `"Green Garden"` dauern jeweils `1.5` Minuten.
- `"Tropical Island"` dauert `3` Minuten.
- `"All or Nothing"` dauert `5` Minuten.
- Alle anderen Getränke (z. B. Sonderangebote) dauern `2.5` Minuten.

Definiere `time-to-mix-juice`, das einen Saftnamen vom Stapel nimmt
und die Anzahl der Minuten zurückgibt, die das Mixen dieses Getränks
dauert.

```factor
"Tropical Island" time-to-mix-juice .
! => 3

"Berries & Lime" time-to-mix-juice .
! => 2.5
```

## 2. Fülle den Vorrat an Limettenstücken auf

Viele von Li Meis Kreationen enthalten Limettenstücke, sei es als
Zutat oder als Teil der Dekoration. Wenn sie morgens ihre Schicht
beginnt, muss sie also dafür sorgen, dass der Behälter mit den
Limettenstücken für den kommenden Tag gut gefüllt ist.

Definiere `wedges-from-lime`, das eine Limettengröße entgegennimmt
und die Anzahl der Stücke zurückgibt, die daraus entstehen: `6` aus
einer Limette der Größe `"small"`, `8` aus einer der Größe
`"medium"` und `10` aus einer der Größe `"large"`.

Definiere dann `limes-to-cut`, das die Anzahl der benötigten Stücke
(`needed`) und ein Array von Limettengrößen (`limes`, in der
Reihenfolge, in der sie geschnitten werden) entgegennimmt. Es
schneidet die Limetten eine nach der anderen, in der
vorgegebenen Reihenfolge, und hört auf, sobald es entweder genug
Stücke hat oder keine Limetten mehr übrig sind. Gib die Anzahl der
Limetten zurück, die es schneiden musste.

```factor
25 { "small" "small" "large" "medium" "small" } limes-to-cut .
! => 4
```

## 3. Liste die Mixzeiten für jede Bestellung in der Warteschlange auf

Li Mei behält gerne den Überblick darüber, wie lange das Mixen der
Bestellungen dauert, auf die ihre Gäste warten.

Definiere `order-times`, das ein Array von Bestellungen entgegennimmt
und ein Array mit der Mixzeit für jede Bestellung zurückgibt, und
zwar in derselben Reihenfolge.

```factor
{ "Energizer" "Tropical Island" } order-times .
! => { 1.5 3 }
```

## 4. Beende die Schicht

Li Mei arbeitet immer bis 15 Uhr. Danach übernimmt ihr Angestellter
Dmitry. Wenn Li Meis Schicht endet, gibt es oft Getränke, die
bestellt, aber noch nicht zubereitet wurden; Dmitry bereitet dann
die restlichen Säfte zu.

Um die Übergabe einfacher zu machen, definiere `remaining-orders`,
das die verbleibenden Minuten `time-left` in Li Meis Schicht und ein
Array von Bestellungen (`orders`, also Säfte, die bestellt, aber
noch nicht zubereitet wurden) entgegennimmt. Gib die Bestellungen
zurück, die Dmitry übernehmen muss, also die, die Li Mei vor dem
Ende ihrer Schicht nicht mehr anfangen kann.

`time-left` ist immer größer als `0`. Die Bestellungen werden in der
Reihenfolge zubereitet, in der sie im Array stehen. Wenn Li Mei mit
einem Saft anfängt, macht sie ihn immer fertig, auch wenn sie dafür
etwas länger arbeiten muss. Wenn sie Zeit hat, mit jeder Bestellung
anzufangen, gib ein leeres Array zurück.

```factor
5 { "Energizer" "All or Nothing" "Green Garden" } remaining-orders .
! => { "Green Garden" }
```
