# Einführung

Es gibt im Grunde zwei Arten von Schleifen:

1. Wiederhole, bis eine Bedingung erfüllt ist.
2. Wiederhole die Elemente einer Sammlung.

Beides ist in Julia möglich, wobei die zweite Variante häufiger vorkommt.

## Die `while`-Schleife

Für Probleme ohne festes Ende, bei denen die Anzahl der Schleifendurchläufe im Voraus unbekannt ist, gibt es in Julia die `while`-Schleife.

Die Grundform ist recht einfach:

```julia
while condition
    do_something()
end
```

In diesem Fall läuft das Programm so lange durch die Schleife, bis `condition` nicht mehr `true` ist.

Es gibt zwei Möglichkeiten, die Schleife vorzeitig zu verlassen:

- Ein `break` bricht die Schleife ab, und die Ausführung geht in der nächsten Zeile nach dem `end` der Schleife weiter.
- Ein `return x` beendet die Ausführung der aktuellen Funktion und gibt den Rückgabewert `x` an den Aufrufer zurück.

Mit diesen Möglichkeiten kann es manchmal praktisch sein, eine „unendliche“ Schleife mit `while true ... end` zu erzeugen und dann im Schleifenblock auf eine Abbruchbedingung zu warten, die ein `break` oder `return` auslöst.

## Über eine Sammlung iterieren

Das einfachste Beispiel ist eine Schleife über einen Bereich.

Wenn wir etwas zehnmal machen wollen:

```julia
for n in 1:10
    do_something(n)
end
```

Wenn die aktuelle Iteration eine Bedingung nicht erfüllt, kannst du mit einem `continue` sofort zur nächsten Iteration springen:

```julia
for n in 1:10
    if is_useless(n)
        continue
    end
    
    # we decided this iteration could be useful
    do_something_slow(n)
end
```

In kürzerer Form lässt sich der `if`-Block durch `is_useless(n) && continue` ersetzen.

Über viele andere Arten von Sammlungen kann ebenfalls iteriert werden: Elemente in einem Array, Zeichen in einem String, Schlüssel in einem Wörterbuch …

Die bisherigen Beispiele durchlaufen den Bereich `1:10`, bei dem der Wert gleichzeitig der Schleifenindex ist.

Allgemeiner kann auch der Index benötigt werden und nicht nur der Wert.
Dafür wird die Funktion `eachindex()` verwendet, zum Beispiel `for i in eachindex(my_array) ... end`.
