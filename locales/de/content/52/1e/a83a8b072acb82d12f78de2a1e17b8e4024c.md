# Tests

Führe die Tests mit `exercism test` oder `eutest` aus. Standardmäßig werden alle Tests ausgeführt.

## Tests überspringen

Ein guter Einstieg ist es, alle Tests bis auf den ersten in `t_<exercise>.e` auszukommentieren.

```euphoria
test_equal("no name given", "One for you, one for me.", two_fer())
-- test_equal("a name given", "One for Alice, one for me.", two_fer("Alice"))
-- test_equal("another name given", "One for Bob, one for me.", two_fer("Bob"))
```

Arbeite sie nacheinander durch und kommentiere den nächsten Test ein, sobald der aktuelle besteht.
Wenn alle Tests bestehen, hast du die Übung abgeschlossen.
