# Anweisungen

Du arbeitest freiwillig im Gemeinschaftskunstzentrum mit, wo über dem Haupteingang ein langes Mosaik aus Keramikfliesen entsteht. Das Designteam hat die Arbeit **Reihe für Reihe** ausgelegt: Jede Reihe ist ein Array aus Kachelfarben, und das ganze Mosaik ist ein Array aus Reihen.

Während die Freiwilligen Kacheln zuschneiden, setzen und umsortieren, schreibst du kleine wiederverwendbare Wörter, um Teile des Designs aufzubauen, zu kombinieren und nachzuschlagen.

## 1. Ein Streifen aus einer einzigen Kachel

Definiere `tile-strip`, sodass es eine Farbe entgegennimmt und eine Reihe mit einem einzigen Element zurückgibt, die nur diese Farbe enthält.

```factor
"sky-blue" tile-strip .
! => { "sky-blue" }
```

## 2. Eine Reihe aus drei Kacheln

Definiere `row-of-three`, sodass es drei Farben vom Stack nimmt und eine Reihe mit drei Elementen zurückgibt.

```factor
"red" "white" "blue" row-of-three .
! => { "red" "white" "blue" }
```

## 3. Fasse die Reihen zu einer flachen Kachelliste zusammen

Das Designteam muss die Farbgesamtmengen über alle Reihen des Mosaiks hinweg auf Plausibilität prüfen. Definiere `combine-rows`, sodass es ein Array aus Reihen entgegennimmt und eine einzelne Sequenz aller Kacheln in der richtigen Reihenfolge zurückgibt.

```factor
{ { "red" "white" } { "blue" "red" } } combine-rows .
! => { "red" "white" "blue" "red" }
```

## 4. Spiegele eine Reihe

Für symmetrische Paneele spiegelt das Team eine Reihe, bevor es die Kopie auf der gegenüberliegenden Seite platziert. Definiere `mirror-row`, sodass es eine Reihe in umgekehrter Reihenfolge zurückgibt.

```factor
{ "red" "white" "blue" } mirror-row .
! => { "blue" "white" "red" }
```

## 5. Wo liegt diese Farbe in der Reihe?

Definiere `tile-position`, sodass es eine Reihe und eine Farbe entgegennimmt und den Index (0-basiert) der ersten Kachel mit dieser Farbe in der Reihe zurückgibt. Wenn die Farbe nicht vorkommt, gib `f` zurück.

```factor
{ "red" "white" "blue" } "white" tile-position .
! => 1

{ "red" "white" "blue" } "green" tile-position .
! => f
```

## 6. Enthält diese Reihe die Farbe?

Definiere `has-colour?`, sodass es eine Reihe und eine Farbe entgegennimmt und `t` zurückgibt, wenn die Farbe irgendwo in der Reihe vorkommt, andernfalls `f`.

```factor
{ "red" "white" "blue" } "white" has-colour? .
! => t

{ "red" "white" "blue" } "green" has-colour? .
! => f
```
