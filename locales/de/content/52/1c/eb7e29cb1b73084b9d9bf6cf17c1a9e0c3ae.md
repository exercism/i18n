# Anleitung

In dieser Übung schreibst du Code, um Namensschilder für Fabrikmitarbeiter auszugeben.
Mitarbeiter haben eine ID, einen Namen und einen Abteilungsnamen.
Die Beschriftungen der Mitarbeiterschilder sind wie folgt formatiert: `"[id] - name - DEPARTMENT"`.

## 1. Gib ein Namensschild für einen Mitarbeiter aus

Implementiere die Funktion `print_name_badge`. Sie soll eine ID, einen Namen und eine Abteilung entgegennehmen.
Sie soll die Beschriftung des Schilds zurückgeben, wobei der Abteilungsname in Großbuchstaben geschrieben wird.

```R
print_name_badge(67, "Katherine Williams", "Strategic Communication")
# => "[67] - Katherine Williams - STRATEGIC COMMUNICATION"
```

## 2. Gib ein Namensschild für einen neuen Mitarbeiter aus

Aufgrund einer Eigenheit im Computersystem haben neue Mitarbeiter manchmal noch keine ID, wenn sie anfangen, in der Fabrik zu arbeiten.
Da Schilder Pflicht sind, erhalten sie ein vorübergehendes Schild ohne das ID-Präfix.

Erweitere die Funktion `print_name_badge`. Wenn die ID fehlt, soll sie ein Schild ohne sie ausgeben.

```R
print_name_badge(NA, "Robert Johnson", "Procurement")
# => "Robert Johnson - PROCUREMENT"
```

## 3. Gib ein Namensschild für den Besitzer aus

Selbst der Besitzer der Fabrik muss jederzeit ein Schild tragen.
Ein Besitzer hat jedoch keine Abteilung und wird auch nie eine haben: Er steht über allen Abteilungen.
In diesem Fall soll auf der Beschriftung `"OWNER"` statt des Abteilungsnamens stehen.

Erweitere die Funktion `print_name_badge`. Wenn die Abteilung `NULL` ist, gehe davon aus, dass das Schild dem Firmenbesitzer gehört.

```R
print_name_badge(204, "Rachel Miller", NULL)
# => "[204] - Rachel Miller - OWNER"
```

Beachte, dass es möglich ist, dass der Besitzer auch ein neuer Mitarbeiter ist.

```R
print_name_badge(NA, "Rachel Miller", NULL)
# => "Rachel Miller - OWNER"
```

## 4. Berechne das Gesamtgehalt der Mitarbeiter ohne ID

Als grober Anhaltspunkt dafür, wie gut die IDs ausgegeben werden, möchtest du das Gesamtgehalt der Mitarbeiter ohne ID sehen.
Ein hoher Wert bedeutet, dass viele warten oder dass das Problem erfahrene Mitarbeiter betrifft: Beides ist schlecht.

Implementiere die Funktion `salaries_no_id`, die einen Vektor von IDs und einen entsprechenden Vektor von Gehältern entgegennimmt und die Summe der Gehälter der Personen ohne ID zurückgibt.
Beide Vektoren haben die gleiche Länge.

```R
ids <- c(204, NA, 210, 352, NA, 263)
salaries <- c(23, 21, 47, 35, 17, 101) * 1000
salaries_no_id(ids, salaries)
# => 38,000
```
