# Anleitung

In dieser Übung schreibst du Code, der einem Freelancer hilft, mit einem Projektmanager zu kommunizieren.
Deine Aufgabe ist es, ein paar Hilfsfunktionen bereitzustellen, um schnell Tages- und Monatssätze zu berechnen, optional mit einem gegebenen Rabatt.

Zuerst legen wir ein paar Regeln zwischen dem Freelancer und dem Projektmanager fest:

- Der Tagessatz ist das 8-Fache des Stundensatzes.
- Ein Monat hat 22 abrechenbare Tage.

Manchmal bietet der Freelancer an, einen Rabatt auf seinen Tagessatz zu gewähren (zum Beispiel für seine treuesten Kunden oder gemeinnützige Kunden).

Rabatte werden als Bruchzahlen modelliert, die Prozentsätze darstellen, zum Beispiel `25.0` (25 %).

## 1. Berechne den Tagessatz anhand eines Stundensatzes

Implementiere eine Funktion namens `dailyRateFrom`, um den Tagessatz anhand eines Stundensatzes als Parameter zu berechnen.
Der Vertrag legt fest, dass ein Tag 8 abrechenbare Stunden hat.

```swift
dailyRateFrom(hourlyRate: 60)
// Returns 480.0
```

Der zurückgegebene Tagessatz sollte ein `Double` sein.

## 2. Berechne den Monatssatz anhand eines Stundensatzes und eines Rabatts

Implementiere eine Funktion `monthlyRateFrom`, um den rabattierten Monatssatz zu berechnen.
Sie nimmt zwei Parameter entgegen, einen Stundensatz und den Rabatt in Prozent.


```swift
monthlyRateFrom(hourlyRate: 77, withDiscount: 10.5)
// Returns 12129
```

Der zurückgegebene Monatssatz sollte auf die nächste ganze Zahl aufgerundet werden.

## 3. Berechne die Anzahl der vollständigen Arbeitstage anhand von Budget, Stundensatz und Rabatt

Implementiere eine Funktion `workdaysIn`, die ein Budget, einen Stundensatz und einen Rabatt entgegennimmt und berechnet, wie viele vollständige Arbeitstage damit abgedeckt sind.

```swift
workdaysIn(budget: 20000, hourlyRate: 80, withDiscount: 11.0)
// Returns 35.0
```
Die zurückgegebene Anzahl an Tagen sollte auf die nächste ganze Zahl abgerundet werden.
