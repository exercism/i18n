## Verwendung

### Bauen

`npx blueprint build` oder `yarn blueprint build`

### Testen

`npx blueprint test` oder `yarn blueprint test`

### Ausrollen oder ein anderes Skript ausführen

`npx blueprint run` oder `yarn blueprint run`

### Einen neuen Vertrag hinzufügen

`npx blueprint create ContractName` oder `yarn blueprint create ContractName`
