# Bedingte Anweisungen

Ruby kennt sogenannte Kontrollfluss-Ausdrücke. Mit ihnen steuerst du, wie das Programm abläuft, und sie nehmen einen truthy- oder falsey-Wert an.
Es gibt Operatoren, mit denen du truthy- oder falsey-Werte erzeugen kannst. Man nennt sie [Vergleichsoperatoren][comparison-operators].

Es gibt zwei wichtige Kontrollausdrücke, mit denen du steuerst, welcher Code ausgeführt wird und welcher nicht.
Sie legen also fest, welcher Zweig ausgeführt wird.

Diese beiden sind: `if` und der `unless`-Ausdruck.

## Vergleichsoperatoren

Mit [Vergleichsoperatoren][comparison-operators] vergleichst du Werte und bekommst einen `true`- oder `false`-Wert zurück.
Die folgenden Operatoren erwarten zwei Werte desselben Typs, die sie vergleichen.
Haben die Werte nicht denselben Typ, wirft der Compiler einen Fehler.
Hier ist eine Liste der Operatoren mit einem Beispiel, bei dem sie einen `true`-Wert liefern:

| Methode | Beschreibung          | Beispiel |
| ------- | --------------------- | -------- |
| <       | kleiner als           | 4 < 5    |
| <=      | kleiner als oder gleich | 4 <= 4 |
| >       | größer als            | 3 > 1    |
| >=      | größer als oder gleich | 2 >= 2  |

Anders als die bisher genannten Operatoren kannst du die Gleichheits- und Ungleichheitsoperatoren auf jeden Wertetyp anwenden.
Mit dem Operator `==` prüfst du, ob zwei Werte gleich sind, wobei auch der Typ des Werts geprüft wird.
Der Operator `!=` funktioniert genauso, gibt aber `true` zurück, wenn die Werte nicht gleich sind, und `false`, wenn sie gleich sind.
Hier ist eine Liste der Gleichheits- und Ungleichheitsoperatoren mit einem Beispiel, bei dem sie einen `true`-Wert liefern:

| Methode | Beschreibung | Beispiel |
| ------- | ------------ | -------- |
| ==      | gleich       | 4 == 4   |
| !=      | nicht gleich | 5 != 4   |

## if-Anweisung

Mit der [`if`][if]-Anweisung prüfst du, ob eine Bedingung „truthy“ oder „falsey“ ist.
Ist die Bedingung truthy, wird der Code innerhalb der if-Anweisung ausgeführt.
Eine `if`-Anweisung endet mit dem Schlüsselwort `end`.

```ruby
value = 1
if value == 1
  "1 is equal to 1"
end
# => "1 is equal to 1"

if value > 2
  "1 is greater than 2"
end
# => nil
```

## unless-Anweisung

Die `unless`-Anweisung funktioniert ganz ähnlich wie die `if`-Anweisung, führt den Code innerhalb der `unless`-Anweisung aber aus, wenn die Bedingung falsey ist.

```ruby
value = 1
unless value == 1
  "1 is not equal to 1"
end
# => nil

unless value > 2
  "1 is not greater than 2"
end
# => "1 is not greater than 2"
```

## else-Anweisung

Die `else`-Anweisung kannst du zusammen mit der `if`-Anweisung verwenden.
Die `else`-Anweisung wird ausgeführt, wenn der `if`-Zweig nicht ausgeführt wird.

```ruby
value = 1
if value == 1
  "1 is equal to 1"
else
  "1 is not equal to 1"
end
# => "1 is equal to 1"

if value > 2
  "1 is greater than 2"
else
  "1 is not greater than 2"
end
# => "1 is not greater than 2"
```

## „Cascading-if“-Anweisungen

Die `elsif`-Anweisung kannst du zusammen mit der if-Anweisung verwenden.
Die `elsif`-Anweisung wird ausgeführt, wenn der if-Zweig nicht ausgeführt wird und die Bedingung der elsif-Anweisung truthy ist.
Elsif-Anweisungen lassen sich aneinanderreihen, und die erste truthy-Bedingung wird ausgeführt.
Am Ende der if-Anweisung kann außerdem eine else-Anweisung stehen, die ausgeführt wird, wenn keine der vorherigen Bedingungen zutraf.

```ruby
value = 1
if value == 0
  "1 is equal to 0"
elsif value > 2
  "1 is greater than 2"
else
  "1 is not equal to 0 and 1 is not greater than 2"
end
# => "1 is not equal to 0 and 1 is not greater than 2"
```
