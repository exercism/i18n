# Ergänzung zu den Anweisungen

# Eingabe

Die Eingaben für diese Übung sind:

- `target`: Ein String (z. B. `'stone'`) ist das _linke Argument_.
- `candidates`: Eine Liste geboxter Strings (z. B. `'stone' ; 'tones' ; 'banana' ; 'tons' ; 'notes' ; 'Seton'`) ist das _rechte Argument_.

Dein Verb wird so aufgerufen:

```j
  target     =. 'stone'
  candidates =. 'stone' ; 'tones' ; 'banana' ; 'tons' ; 'notes' ; 'Seton'
  
  subject findAnagrams candidates
```

## Ausgabe

Dein Verb soll eine _Liste_ von Boxen zurückgeben, die die Strings enthalten, die Anagramme des Ziels sind. Wenn es keine Anagramme gibt, sollte das Ergebnis `empty` sein.
