# Geheimagent

## Geschichte

Hallo, Agent Double-Null0111.

Deine Mission, sofern du sie annimmst, ist es, zwei Tools zu schreiben, mit denen du dich in das Hauptquartier von UMBRA (Vereinigte Handlanger, die wirklich furchtbar sind) einschleust und die Pläne für ihr neuestes, wirklich furchtbares Vorhaben beschaffst. Für diese Mission brauchst du zwei Tools.

## Aufgaben

Die Geschichte ermöglicht es, [Funktionen höherer Ordnung][concepts-higher_order_functions] zu definieren, darunter eine Funktion, die eine Funktion als Eingabewert entgegennimmt, und eine Funktion, die eine Funktion als Ausgabe zurückgibt:

- Erzeuge eine Kombination, um ihren Tresor zu öffnen
- Schütze die geborgenen geheimen Pläne mit einem Passwort
