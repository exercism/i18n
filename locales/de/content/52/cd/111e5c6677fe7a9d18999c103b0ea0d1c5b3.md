# Einführung

## Schleifen

Mit Schleifen kannst du eine Logik wiederholt ausführen.
Die beiden häufigsten Arten sind die `while loop`-Schleife (unbestimmtes Wiederholen) und die `for`-Schleife (bestimmtes oder gezähltes Wiederholen).
Außerdem gibt es die `for each`-Schleife, die in einem späteren Konzept behandelt wird.

### Allgemeine Syntax

Die `for loop`-Schleife besteht aus einem Kopf und einem Block, der den Schleifenblock in geschweifte Klammern eingeschlossen enthält.
Der Kopf besteht aus 3 Komponenten, die durch Semikolons `;` getrennt sind: init-statement, condition und ein weiterer Ausdruck.
Jede davon kann leer sein.

```cpp
for (init_statement; condition; expression) {
  some_statement;
}
```

- Die Komponente **init_statement** ist Code, der nur einmal vor dem Start der Schleife ausgeführt wird.
- Die Komponente **condition** muss ein Ausdruck sein, der zu einem `boolean` ausgewertet wird, und steuert, wann die Schleife beendet werden soll.
  Der Code innerhalb der Schleife läuft so lange, wie diese Bedingung zu `true` ausgewertet wird.
  Sobald dieser Ausdruck zu `false` ausgewertet wird, laufen keine weiteren Iterationen der Schleife mehr.
- Die Komponente **expression** ist Code, der am Ende jeder Iteration ausgeführt wird.

Die `for loop`-Schleife führt ihren Block so lange aus, wie die Prüfung ihrer **condition** `true` ergibt.
Das folgende Codebeispiel zeigt, wie du eine `while loop`-Schleife in eine `while loop`-Schleife umwandelst.

```cpp
init_statement;
while(condition) {
    some_statement;
    expression;
}
```

### Zwischenspiel: Erhöhen und Verringern

Bei der Arbeit mit Schleifen musst du oft 1 zu einer Zählervariable addieren oder 1 davon subtrahieren, die die Iterationen mitzählt.
Das ist so üblich, dass das Erhöhen und Verringern eigene Operatoren hat: `++` und `--`.

Sie treten in einer **Präfix**- und einer **Postfix**-Form auf.
Die Präfix-Version ändert die Variable vor ihrer Verwendung in der Anweisung, die Postfix-Version danach.
Die meiste Zeit willst du wahrscheinlich die Präfix-Version.

```cpp
int a{3};
int b{--a};
// b is 2, a is now 2
int c{a++};
// c is 2, a is now 3
```

### for-Schleifen: ein Beispiel

Die _Init-Komponente_ legt normalerweise eine Zählervariable fest, die _Bedingung_ prüft, ob die Schleife fortgesetzt oder beendet werden soll, und die _Post-Komponente_ erhöht normalerweise den Zähler am Ende jeder Wiederholung.

```cpp
int sum{0};
for (int i{1}; i < 10; ++i) {
  sum += i;
}
```

Diese Schleife summiert die Zahlen von `1` bis `9` (einschließlich `9`).

### break und continue

Innerhalb eines Schleifenblocks kannst du das Schlüsselwort `break` verwenden, um die Ausführung der Schleife vollständig zu stoppen:

```cpp
int sum{2};
while(true) {
    sum *= 2;
    if (sum > 1000)
        break;
}
// sum is now 1024
```

Im Gegensatz dazu stoppt das Schlüsselwort `continue` nur die Ausführung der aktuellen Iteration und fährt mit der nächsten fort:

```cpp
int equal_sum{0};
for (int i{1}; i < 7; ++i) {
  if  (i%2 == 1) {
    continue;
  }
  equal_sum += i;
}
// equal_sum is now 12
```

~~~~exercism/note
Es ist normalerweise einfacher, die Logik der Schleife zu verstehen, wenn die Verwendung von `break` und `continue` minimiert oder ganz vermieden wird.
Beide Schlüsselwörter überspringen bestimmte Abschnitte des Codes und machen es oft schwieriger, dem Ablauf zu folgen.
~~~~
