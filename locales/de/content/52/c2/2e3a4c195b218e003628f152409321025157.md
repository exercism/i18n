# Über

C# ist eine multiparadigmatische, statisch typisierte Programmiersprache. Sie bietet objektorientierte, deklarative, funktionale und generische Merkmale, Lazy Evaluation, integrierte Abfragen und Typinferenz.

**Statisch typisiert** bedeutet, dass Bezeichner einen [Typ](https://en.wikipedia.org/wiki/Type_system#Static_type_checking) haben, der zur Compile-Zeit festgelegt wird, wie in Java, C++ oder Haskell, statt Daten beliebigen Typs zu halten wie in Python, Ruby oder JavaScript.

**Objektorientiert** bedeutet, dass C# imperative [klassenbasierte Objekte](https://docs.microsoft.com/en-us/dotnet/csharp/programming-guide/concepts/object-oriented-programming) mit Merkmalen wie Einfachvererbung, Schnittstellen und Kapselung bietet.

**Deklarativ** bedeutet, zu programmieren, was getan werden soll, statt wie es getan wird (auch bekannt als imperative Programmierung), wobei dies ein Implementierungsdetail ist, das von der Domäne oder der Geschäftslogik ablenken kann.

**Funktional** bedeutet, dass [Funktionen erstklassige Datentypen sind](https://livebook.manning.com/#!/book/functional-programming-in-c-sharp/chapter-1), die als Argumente an andere Funktionen übergeben und von ihnen zurückgegeben werden können.

**Generisch** bedeutet, dass Algorithmen in Bezug auf Typen geschrieben werden, [die später festgelegt werden](https://docs.microsoft.com/en-us/dotnet/csharp/programming-guide/generics/generic-type-parameters) und dann bei Bedarf für die als Parameter angegebenen konkreten Typen instanziiert werden.

**Lazy** [(auch „verzögerte Ausführung“ genannt)](https://blogs.msdn.microsoft.com/pedram/2007/06/02/lazy-evaluation-in-c/) bedeutet, dass der Compiler die Auswertung eines Elements aufschiebt, bis sie gebraucht wird. So kannst du gefahrlos seltsame Dinge anstellen, zum Beispiel mit einer unendlichen Liste arbeiten: Die Sprache legt die Liste nur bis zum letzten benötigten Wert an.

**Integrierte Abfragen** bedeutet das Sprachmerkmal [LINQ „Language-Integrated Query“](https://docs.microsoft.com/en-us/dotnet/csharp/programming-guide/concepts/linq/), das verzögerte Abfragen direkt innerhalb der Sprache ermöglicht, nicht nur für die eigenen Objekte, sondern auch für externe Datenquellen über Formate wie XML, JSON, SQL, NoSQL-Datenbanken und Ereignisströme.

**Typinferenz** bedeutet, dass der Compiler den Typ eines Bezeichners oft selbst herausfindet, sodass du ihn nicht angeben musst. Scala und F# machen das genauso.

Die **Syntax** ähnelt der anderer Sprachen im C-Stil wie C, C++ und Java.

**.NET** ist die verwaltete Umgebung, in der C# läuft, sodass du Zugriff auf das gesamte .NET-Ökosystem hast, einschließlich aller Pakete auf [nuget.org](http://www.nuget.org). Früher lief .NET nur unter Windows, aber mit der Veröffentlichung von [.NET Core](https://www.microsoft.com/net/core) und auch von [Mono](http://www.mono-project.com/) kannst du C# jetzt ebenso auf Mac, Linux oder Unix-basierten Systemen und auf mobilen Plattformen einsetzen.

C# bietet außerdem unter anderem Merkmale, die das Programmieren mit mehreren Threads oder Prozessoren, Parallelisierung, Asynchronität, nicht verwaltetem Code in einer verwalteten Umgebung und Sprachinteroperabilität erleichtern. C# wird von Microsoft entwickelt und gepflegt, das auch die offizielle [Dokumentation](https://docs.microsoft.com/en-us/dotnet/csharp/) bereitstellt.
