# Einführung

Schleifen werden verwendet, um eine bestimmte Logik wiederholt auszuführen.
Die zwei häufigsten Arten sind die `while loop` (unbestimmtes Wiederholen) und die `for loop` (bestimmtes oder gezähltes Wiederholen).
Außerdem gibt es die `for each`-Schleife, die in einem späteren Konzept vorkommen wird.

## Allgemeine Syntax

Die `for loop` besteht aus einem Kopf und einem Block, der den Schleifenblock in geschweiften Klammern enthält.
Der Kopf besteht aus 3 Komponenten, die durch Semikolons `;` getrennt sind: Initialisierungsanweisung, Bedingung und ein weiterer Ausdruck.
Jede davon kann leer sein.

```cpp
for (init-statement; condition; expression) {
  some_statement;
}
```

- Die **init**-Komponente ist Code, der nur einmal ausgeführt wird, bevor die Schleife startet.
- Die **condition**-Komponente muss ein Ausdruck sein, der zu einem booleschen Wert ausgewertet wird und steuert, wann die Schleife aufhören soll.
Der Code innerhalb der Schleife wird so lange ausgeführt, wie diese Bedingung wahr ist.
Sobald dieser Ausdruck falsch ist, laufen keine weiteren Iterationen der Schleife mehr.
- Die **expression**-Komponente ist Code, der am Ende jeder Iteration ausgeführt wird.

Die `while loop` führt ihren Schleifenblock so lange aus, wie ihre Bedingung wahr ist.
Das folgende Codebeispiel zeigt, wie du eine for-Schleife in eine while-Schleife umwandelst.

```cpp
init-statement;
while(condition) {
    some_statement;
    expression;
}
```

## Zwischenspiel: Erhöhen und Verringern

Bei der Arbeit mit Schleifen ist es oft nötig, 1 zu einer Zählvariable zu addieren oder 1 davon zu subtrahieren.
Das ist so verbreitet, dass es für diese Operation spezielle Operatoren gibt: `++` und `--`.

Sie gibt es in einer Präfix- und einer Postfix-Form.
Die Präfix-Form ändert die Variable vor ihrer Verwendung in der Anweisung, die Postfix-Form danach.
Meistens willst du vermutlich die Präfix-Form.

```cpp
int a{3};
int b{--a};
// b is 2, a is now 2
int c{a++};
// c is 2, a is now 3
```

## for-Schleifen: ein Beispiel

Die init-Komponente richtet normalerweise eine Zählvariable ein, die Bedingung prüft, ob die Schleife fortgesetzt oder beendet werden soll, und die post-Komponente erhöht den Zähler in der Regel am Ende jeder Wiederholung.

```cpp
int sum{0};
for (int i{1}; i < 10; ++i) {
  sum += i;
}
```

Diese Schleife summiert die Zahlen von `1` bis `9` (einschließlich `9`).

## Break und Continue

Innerhalb eines Schleifenblocks kannst du das Schlüsselwort `break` verwenden, um die Ausführung der Schleife vollständig zu beenden:

```cpp
int sum{2};
while(true) {
    sum *= 2;
    if (sum > 1000)
        break;
}
// sum is now 1024
```

Im Gegensatz dazu stoppt das Schlüsselwort `continue` nur die Ausführung der aktuellen Iteration und fährt mit der nächsten fort:

```cpp
int equal_sum{0};
for (int i{1}; i < 7; ++i) {
  if  (i%2 == 1) {
    continue;
  }
  equal_sum += i;
}
// equal_sum is now 12
```
> Hinweis: Die Logik der Schleife ist normalerweise leichter zu verstehen, wenn `break` und `continue` möglichst wenig oder gar nicht verwendet werden.
