# Array-Methoden

Arrays sind eine häufig verwendete Datenstruktur.
Dafür gibt es eine ganze Reihe von Methoden, mit denen du Arrays bearbeiten kannst.
Dazu gehören Sortieren, Umkehren, Einfügen und vieles mehr.

Einige dieser Methoden sind destruktiv, das heißt, sie verändern das ursprüngliche Array.
Andere sind nicht destruktiv, geben also ein neues Array zurück und lassen das ursprüngliche Array unverändert.

Hier sind einige der gebräuchlichsten Methoden, die du beim Umgang mit Arrays verwenden kannst:

## insert

Wenn du ein Element in ein Array einfügen möchtest, kannst du die Methode [`insert`][insert] verwenden. Sie nimmt einen Index und ein Element als Argumente entgegen.
Das Element wird an der angegebenen Position eingefügt, und der Rest des Arrays wird nach rechts verschoben.
Wenn der Index außerhalb des gültigen Bereichs liegt, wird ein `IndexError` ausgelöst.

```crystal
numbers = [1, 2, 3]
numbers.insert(1, 4)
numbers # => [1, 4, 2, 3]

numbers.insert(5, 5) # => Error: Index out of bounds (IndexError)
```

## delete

Wenn du ein bestimmtes Element aus einem Array löschen möchtest, kannst du die Methode [`delete`][delete] verwenden, die ein Element als Argument entgegennimmt.
Die Methode gibt das Element zurück, das entfernt wurde.
Wenn das Element nicht im Array vorhanden ist, wird `nil` zurückgegeben.

```crystal
numbers = [1, 2, 3]
numbers.delete(2) # => 2
numbers           # => [1, 3]
```

## first & last

Wenn du das erste oder das letzte Element eines Arrays erhalten möchtest, kannst du die Methoden [`first`][first] und [`last`][last] verwenden.
Diese Methoden nehmen ein optionales Argument entgegen, das angibt, wie viele Elemente zurückgegeben werden sollen.
Das kann die Lesbarkeit verbessern, verglichen mit der Verwendung des Index `0` oder `-1` oder eines Bereichs.
Wenn das Array leer ist, wird ein `Enumerable::EmptyError` ausgelöst.

```crystal
numbers = [1, 2, 3]
numbers.first # => 1
numbers.last  # => 3

numbers.first(2) # => [1, 2]
numbers.last(2)  # => [2, 3]

empty_array = [] of Int32
empty_array.last # => Error: Empty enumerable (Enumerable::EmptyError)
```

## reverse

Wenn du ein Array umkehren möchtest, kannst du die Methode [`reverse`][reverse] verwenden, die ein neues Array mit den Elementen in umgekehrter Reihenfolge zurückgibt.
Wichtig zu wissen: `reverse` gibt ein neues Array zurück und verändert das ursprüngliche Array nicht.
Wenn du das ursprüngliche Array verändern möchtest, hänge ein `!` an das Ende des Methodennamens an.

```crystal
numbers = [1, 2, 3]
numbers.reverse # => [3, 2, 1]
numbers         # => [1, 2, 3]

numbers.reverse! # => [3, 2, 1]
numbers          # => [3, 2, 1]
```

## Concat(`+`)

Die Methode zum Anhängen (`<<`) ist nützlich, wenn du Objekte zu einem Array hinzufügen möchtest.
Wenn du jedoch zwei Arrays kombinieren willst, kannst du den Operator [`+`][concat] verwenden, der ein neues Array mit den Elementen beider Arrays zurückgibt.

```crystal
[1, 2] + [3, 4] # => [1, 2, 3, 4]
```

Wenn du ein Array an ein anderes Array anhängst, wird das Array als einzelnes Element hinzugefügt.

```crystal
[1, 2] << [3, 4] # => [1, 2, [3, 4]]
```

## empty?

Wenn du prüfen möchtest, ob ein Array leer ist, kannst du die Methode [`empty?`][empty?] verwenden, die `true` zurückgibt, wenn das Array leer ist, und andernfalls `false`.
Das verbessert die Lesbarkeit, verglichen damit, die Länge des Arrays mit `0` zu vergleichen.

```crystal
[].empty? # => true
[1, 2, 3].empty? # => false
```

## index

Wenn du den Index eines Elements in einem Array ermitteln möchtest, kannst du die Methode [`index`][index] verwenden, die ein Element als Argument entgegennimmt.
Wenn das Element nicht im Array vorhanden ist, wird `nil` zurückgegeben.

```crystal
numbers = [1, 2, 3]
numbers.index(2) # => 1
```

## size

Wenn du wissen möchtest, wie viele Elemente ein Array enthält, kannst du die Methode [`size`][size] verwenden.

```crystal
numbers = [1, 2, 3]
numbers.size # => 3
```

## count

Wenn du zählen möchtest, wie oft ein Element in einem Array vorkommt, kannst du die Methode [`count`][count] verwenden.

```crystal
fruits = ["apple", "banana", "apple"]
fruits.count("apple")      # => 2
fruits.count("banana")     # => 1
fruits.count("watermelon") # => 0
```

## sort

Wenn du ein Array sortieren möchtest, kannst du die Methode [`sort`][sort] verwenden, die ein neues Array mit den sortierten Elementen zurückgibt.
Wie bei `reverse` gibt diese Methode ein neues Array zurück und verändert das ursprüngliche Array nicht.

```crystal
numbers = [3, 2, 1]
numbers.sort # => [1, 2, 3]
numbers      # => [3, 2, 1]

numbers.sort! # => [1, 2, 3]
numbers       # => [1, 2, 3]
```
