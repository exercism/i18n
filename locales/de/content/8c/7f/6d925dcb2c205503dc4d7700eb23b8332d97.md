# Einführung

`call` (in [`kernel`][kernel]) führt eine Quotation aus. Wenn der Stack-Effekt der Quotation nicht abgeleitet werden kann, weil die Quotation typischerweise von woanders kommt, dann deklariere den Effekt bei `call` explizit:

```
call( stack-effect ) ! e.g. call( a b -- c )
```

```factor
3 4 [ + ] call .                 ! => 7
3 4 [ + ] call( a b -- c ) .     ! => 7

: apply-binary ( a b op -- c )
    call( a b -- c ) ;

5 3 [ - ] apply-binary .         ! => 2
```

Weil Quotationen Werte sind, kann ein Array eine Mischung aus Zahlen und Quotationen enthalten. Dadurch ist „ein Programm“ nur eine weitere Sequenz:

```factor
{ [ 1 + ] [ 2 * ] } 5 swap [ call( x -- y ) ] each .   ! 5 -> 6 -> 12
```
