# Zusätzliche Anweisungen

## `String.lowercase` ist veraltet

Je nachdem, welche Version von OCaml du installiert hast, wird von der Verwendung von `String.lowercase` abgeraten.
Seit Version 4.03.0 ist `String.lowercase` veraltet; verwende stattdessen `String.lowercase_ascii`.

Statt

```ocaml
String.lowercase "Hello, World!"
```

schreibst du also besser

```ocaml
String.lowercase_ascii "Hello, World!"
```

Weitere nützliche Funktionen findest du in der [String-Dokumentation][string].

[string]: http://caml.inria.fr/pub/docs/manual-ocaml/libref/String.html
