# Anleitung

Wenn du mit einem Raspberry Pi etwas bauen möchtest, wirst du wahrscheinlich _Widerstände_ verwenden.
Für diese Übung musst du zwei Dinge über sie wissen:

- Jeder Widerstand hat einen Widerstandswert.
- Widerstände sind klein, so klein, dass es schwer zu lesen wäre, wenn du den Widerstandswert darauf drucken würdest.

Um dieses Problem zu umgehen, drucken Hersteller farbcodierte Ringe auf die Widerstände, um ihre Widerstandswerte anzugeben.
Jeder Ring hat eine Position und einen Zahlenwert.

Die ersten 2 Ringe eines Widerstands folgen einem einfachen Kodierungsschema: Jede Farbe entspricht einer einzelnen Zahl.

Der dritte Ring ist ein Multiplikator.

In dieser Übung erstellst du ein hilfreiches Programm, damit du dir die Werte der Ringe nicht merken musst.

Mehr Informationen zur Farbkodierung von Widerständen findest du im [Wikipedia-Artikel zum elektronischen Farbcode][e-color-code].

## 1. Definiere einen benannten Vektor

Die Farben sind wie folgt kodiert:

- black: 0
- brown: 1
- red: 2
- orange: 3
- yellow: 4
- green: 5
- blue: 6
- violet: 7
- grey: 8
- white: 9

Erstelle den benannten Vektor `resistor_bands`, bei dem die Farben die Namen und die Zahlen die Werte sind.

## 2. Gib den Wert eines Rings zurück

Zuerst möchtest du den einzelnen Wert für einen beliebigen farbigen Ring finden können.

Definiere eine Funktion `band_value(band)`, die einen `string` mit einer Ringfarbe entgegennimmt.
Die Funktion gibt den zugehörigen Wert für diese Farbe zurück.

```R
band_value("green")
# => [1] 5

band_value("violet")
# => [1] 7
```

## 3. Gib den Wert zweier Ringe zurück

Die ersten beiden Ringe eines Widerstands bilden zusammen eine einzelne Zahl.
Wenn die ersten beiden Ringe die Zahlen `m` und `n` haben, ergeben sie zusammen die Zahl `mn`.

Definiere eine Funktion `two_band_value(bands)`, die einen `vector` aus `string`s mit zwei Ringfarben entgegennimmt.
Die Funktion gibt den zugehörigen Wert für die Kombination dieser beiden Farben zurück.

```R
two_band_value(c("yellow", "red"))
# => [1] 42

two_band_value(c("green", "violet"))
# => [1] 57
```

## 4. Gib den Ohm-Wert für alle drei Ringe zurück

Zum Schluss musst du den vollständigen Ohm-Wert mithilfe der ersten beiden Ringe zusammen mit dem dritten Ring ermitteln.
Dazu musst du den Zwei-Ringe-Wert und einen Multiplikator ermitteln.
Der Multiplikator gibt an, wie viele Nullen an den Zwei-Ringe-Wert angehängt werden.

Definiere eine Funktion `ohms(bands)`, die einen `vector` aus `string`s mit drei Ringfarben entgegennimmt.
Die Funktion gibt den zugehörigen Ohm-Wert für die Kombination der drei Farben zurück.

```R
ohms(c("yellow", "red", "orange"))
# => [1] 42000

ohms(c("green", "violet", "yellow"))
# => [1] 570000
```
