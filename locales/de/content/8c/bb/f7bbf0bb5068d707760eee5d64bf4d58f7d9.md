# Installation

## Die R-Laufzeitumgebung installieren
Besuche die [CRAN-Homepage](https://cran.r-project.org/). Dort findest du Downloadlinks für Linux, Mac OSX und Windows. Lade den Installer für dein Betriebssystem herunter und führe ihn aus.

## Die RStudio-IDE installieren (empfohlen)
RStudio ist eine beliebte plattformübergreifende integrierte Entwicklungsumgebung (IDE) für die Programmierung in R (und unterstützt auch andere Sprachen wie Python, JavaScript und Markdown). Mit RStudio fällt es dir leichter, deine Code-Lösungen zu schreiben und Tests auszuführen.

Lade die [aktuelle stabile Version von RStudio](https://www.rstudio.com/products/rstudio/download/) herunter und installiere sie. Oder hole dir alternativ die [Vorschauversion](https://www.rstudio.com/products/rstudio/download/preview/) einer kommenden Veröffentlichung.

## Die Visual Studio Code-Erweiterung für R installieren (Alternative)
Die R-Erweiterung für Visual Studio Code unterstützt erweitertes Syntax-Highlighting, Codevervollständigung, Linting, Formatierung, die Interaktion mit R-Terminals, das Anzeigen von Daten, Diagrammen, Workspace-Variablen, Hilfeseiten, das Verwalten von Paketen und die Arbeit mit R-Markdown-Dokumenten.

Lade die [aktuelle Version der R-Erweiterung](https://code.visualstudio.com/docs/languages/r) herunter und installiere sie.

## Die R-Pakete zum Ausführen von Tests installieren
Der Test-Runner für die Testspezifikationen ist die [`testthat`](https://github.com/hadley/testthat)-Bibliothek von Hadley Wickham, eine beliebte Wahl für Autorinnen und Autoren von R-Paketen.

Um diese Bibliothek zu installieren, gib Folgendes in deiner RStudio-Konsole ein (oder wo auch immer du R verwendest).

```{R}
install.packages("testthat")
```

Auch wenn es unwahrscheinlich ist, dass du Pakete installieren _musst_, um die Exercism-Übungen zu lösen, möchtest du vielleicht ein vielseitiges Hilfspaket wie [`tidyverse`](https://github.com/tidyverse/tidyverse) einbinden, das zu deinem Programmierstil passt. Um ein Paket wie `tidyverse` zu installieren und zu laden:

```{R}
install.packages("tidyverse")
library(tidyverse)
```
