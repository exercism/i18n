## 1. Eine Person zur Warteschlange hinzufügen

- Es gibt [eine Methode][append], um ein Element an ein Array anzuhängen.

## 2. Wo sind meine Freunde?

- Es gibt [eine Methode][index], um den Index eines Elements in einem Array zu ermitteln.

## 3. Darf ich mich dazugesellen?

- Du kannst bereits definierte Methoden verwenden, um den Index der Freundin oder des Freundes zu ermitteln und die Person an dieser Position einzufügen.
- Es gibt [eine Methode][insert], um ein Element an einem bestimmten Index in ein Array einzufügen.

## 4. Eine gemeine Person in der Warteschlange

- Es gibt [eine Methode][delete], um ein Element aus einem Array zu löschen.

## 5. Die Warteschlangenliste sortieren

- Es gibt [eine Methode][sort], um ein Array zu sortieren.
