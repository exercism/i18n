# Einführung

## Zahlen

Haskell hat einen Typ `Num`, den Basistyp für alle numerischen Typen.
Es gibt vier wichtige Untertypen des Zahlentyps: [`Int`][int], [`Integer`][integer], [`Double`][double] und [`Float`][float].

In Haskell gibt es zwei Ganzzahltypen, die ganze Zahlen darstellen.
`Int` ist eine Ganzzahl mit fester Größe, `Integer` eine Ganzzahl mit beliebiger Genauigkeit.
Ein `Integer` kann jede noch so große Zahl halten, bis zur Grenze des Arbeitsspeichers deiner Maschine, während `Int` der Menge der positiven und negativen Ganzzahlen entspricht, die sich in 32 oder 64 Bit darstellen lassen (garantiert mindestens -2^29 bis 2^29 - 1).

Beachte, dass du beim Schreiben negativer Zahlen runde Klammern verwenden solltest, um Mehrdeutigkeiten zu vermeiden.

```haskell
1

(-1)
```

`Float` entspricht der Menge der reellen Zahlen, begrenzt durch die Genauigkeit des Computers.
Operationen, die für Zahlen definiert sind, funktionieren meist nur für den einen oder den anderen Typ, aber nicht für beide.
`Double` ist eine Gleitkommazahl mit doppelter Genauigkeit.

```haskell
10.5
```

### Zwischen Ganzzahlen und Gleitkommazahlen umwandeln

Mit der Funktion `toFloat` kannst du einen Wert vom Typ `Int` oder `Integer` in einen Wert vom Typ `Float` umwandeln.

```haskell
toFloat 1
-- -> 1.0
```

Außerdem gibt es `fromIntegral`, das jeden Zahlentyp in den Typ umwandelt, der an dieser Stelle erwartet wird.

```haskell
fromIntegral 1
-- -> 1.0
```

Um einen Wert vom Typ `Float` in einen Wert vom Typ `Int` umzuwandeln, kannst du die Funktionen [`round`][round], [`floor`][floor] oder [`ceiling`][ceiling] verwenden.
Die Funktion `round` rundet auf die nächste Ganzzahl, `floor` rundet ab und `ceiling` rundet auf.

```haskell
round 1.5
-- -> 2

floor 1.5
-- -> 1

ceiling 1.5
-- -> 2
```

### Rechenoperatoren

Du kannst die [grundlegenden Rechenoperatoren][math] auf die numerischen Typen anwenden.
Die Operatoren sind `+`, `-`, `*`, `/` und `%`.
Wenn du diese Operatoren verwendest, müssen die Typen der Zahlen übereinstimmen.
Die Funktion `fromIntegral` wandelt um, damit die Typen übereinstimmen.

#### Addition, Subtraktion und Multiplikation

Der Operator `+` steht für Addition, der Operator `-` für Subtraktion und der Operator `*` für Multiplikation.

| Operator | Beispiel       |
| -------- | -------------- |
| `+`      | `4 + 6 => 10`  |
| `-`      | `15 - 10 => 5` |
| `*`      | `2 * 3 => 6`   |

#### Division

Mit der Division teilst du Zahlen.
Der Operator `/` steht für die Division.
Das Ergebnis ist immer eine Gleitkommazahl.

```haskell
4.0 / 2.5
-- -> 1.6

4 / 2
-- -> 2.0
```

~~~~exercism/caution
In manchen Programmiersprachen führt eine Division durch null zu einem Fehler.

In Haskell ist das Ergebnis bei einer Division durch null `Infinity` oder `-Infinity`.
Die einzige Ausnahme ist die Division von null durch null, die `NaN` (Not a Number) ergibt.

```haskell
1 / 0
-- -> Infinity

(-1) / 0
-- -> -Infinity

0 / 0
-- -> NaN
```
~~~~

### Ganzzahldivision

Bei der Ganzzahldivision teilst du ganze Zahlen und erhältst nur den ganzzahligen Teil des Ergebnisses.
Haskell hat zwei Funktionen für die Ganzzahldivision, die sich darin unterscheiden, wie sie runden, wenn das Ergebnis negativ ist:

- `div` rundet ab, in Richtung negativ unendlich.
- `quot` rundet in Richtung null.

```haskell
6 `div` 2
-- -> 3

5 `div` 2
-- -> 2

(-5) `div` 2
-- -> -3

5 `quot` 2
-- -> 2

(-5) `quot` 2
-- -> -2
```

~~~~exercism/caution
Eine Division durch null bei der Ganzzahldivision führt zu einer Exception.
Das unterscheidet sich von der normalen Division.
~~~~

#### Rest

Den Rest einer Ganzzahldivision ermittelst du mit `mod` oder `rem`.
Sie unterscheiden sich im Vorzeichen des Ergebnisses, wenn eine der Zahlen negativ ist:

- `mod` gehört zu `div`, und sein Ergebnis hat dasselbe Vorzeichen wie der Divisor.
- `rem` gehört zu `quot`, und sein Ergebnis hat dasselbe Vorzeichen wie der Dividend.

```haskell
5 `mod` 3
-- -> 2

(-5) `mod` 3
-- -> 1

5 `mod` (-3)
-- -> -1

5 `rem` 3
-- -> 2

(-5) `rem` 3
-- -> -2

5 `rem` (-3)
-- -> 2
```

Für alle `x` und `y` (wobei `y` nicht null ist) gelten diese Gesetze:

```haskell
(x `div` y) * y + (x `mod` y) == x
(x `quot` y) * y + (x `rem` y) == x
```

~~~~exercism/note
Wenn beide Zahlen positiv sind, liefern `div` und `quot` dasselbe Ergebnis, ebenso `mod` und `rem`.
In diesem Fall können `quot` und `rem` etwas effizienter sein, weil `div` und `mod` zusätzliche Schritte brauchen, um negative Zahlen zu behandeln.
~~~~

~~~~exercism/caution
Eine Division durch null mit `mod` oder `rem` führt zu einer Exception.
Das unterscheidet sich von der normalen Division.

```haskell
1 `mod` 0
-- Exception: divide by zero
```
~~~~

### Potenzieren

Haskell hat drei Operatoren zum Potenzieren, die unterschiedlich funktionieren und unterschiedliche Argumenttypen annehmen.

- `**` nimmt zwei **Gleitkommazahlen** und berechnet die Potenz mit Logarithmen.
- `^^` nimmt eine **Gleitkommazahl** und potenziert sie mit einer positiven oder negativen **Ganzzahl**.
- `^` nimmt **jeden numerischen Typ** und potenziert ihn mit einer **positiven Ganzzahl**.

```haskell
3.0 ** 2.1
-- -> 10.04510856630514

2.5 ^^ 2
-- -> 6.25

2 ^ 3
-- -> 8
```

### Rangfolge und Klammern

Haskell erlaubt runde Klammern (`()`), mit denen du Ausdrücke gruppieren kannst.
Das ist nützlich, wenn du die Reihenfolge der Operationen ändern willst.

Wenn du mehrere Rechenoperatoren verwendest, gilt dieselbe Reihenfolge wie in der Mathematik, auch bekannt als [PEMDAS][pemdas].
Sie folgt der Reihenfolge Klammern (`()`), Exponenten (`**`), Multiplikation (`*`) und Division (`/`) sowie Addition (`+`) und Subtraktion (`-`).

```haskell
2 + 3 - 4 * 4
-- -> -11

(2 + 3 - 4) * 4
-- -> 4
```
