# Über for-Schleifen

Die [for-Schleife](https://docs.oracle.com/javase/tutorial/java/nutsandbolts/for.html) bietet einen Mechanismus, um eine Gruppe von Anweisungen wiederholt auszuführen, bis eine bestimmte Bedingung erfüllt ist.
Die Schleife besteht aus vier Teilen:

```java
for (initialization; test; update) {
    body;
}
```

Der `initialization`-Teil legt einen Anfangszustand für die Schleife fest und wird genau einmal zu Beginn der Schleife ausgeführt.
Typischerweise deklariert und weist er eine Variable zu, die im `test`-Ausdruck und in der `update`-Anweisung verwendet wird.
Zum Beispiel:

```java
int i = 1
```

Der `test`-Ausdruck prüft, ob die Schleife enden soll.
Wenn er zu wahr ausgewertet wird, werden der Schleifenblock und danach der `update`-Ausdruck ausgeführt.
Wenn er zu falsch ausgewertet wird, werden weder der Schleifenblock noch die `update`-Anweisung ausgeführt, und die Ausführung wird nach der schließenden Klammer der Schleife fortgesetzt.
Typischerweise prüft er die Variable, die im `initialization`-Block zugewiesen wurde.
Zum Beispiel:

```java
i <= 10
```

Nachdem der Schleifenblock ausgeführt wurde, wird der `update`-Ausdruck ausgeführt.
Typischerweise erhöht oder verringert er die Schleifenvariable um einen bestimmten Wert.
Zum Beispiel:

```java
i++
```

Eine for-Schleife, die die ersten vier Quadrate ausgibt, sieht so aus:

```java
for (int i = 1; i <= 4; i++) {
    System.out.println(i * i);
}

/* =>
1
4
9
16
*/
```

Wenn du jedes Element in einer Sammlung durchläufst, ist eine `for-each`-Schleife vorzuziehen, aber du kannst es auch mit einer `for`-Schleife so machen:

```java
for (int i = 0; i < array.length; i++) {
    System.out.print(array[i]);
}
```

Eine `for`-Schleife hat einige Vorteile gegenüber einer `for-each`-Schleife:

- Du kannst an dem Index beginnen oder aufhören, den du möchtest.
- Du kannst jede (boolesche) Abbruchbedingung verwenden, die du möchtest.
- Du kannst Elemente überspringen, indem du das Erhöhen der Schleifenvariable anpasst.
- Du kannst Sammlungen von hinten nach vorne verarbeiten, indem du rückwärts zählst.
- Du kannst `for`-Schleifen in Szenarien verwenden, in denen es keine Sammlungen gibt.
