# Überblick

Auf einzelne Zeichen in einem `String` kannst du mit der Index-Schreibweise zugreifen, die du auch bei Arrays verwendest.
Allerdings sind die [Indizes][string-indices], die für Strings verwendet werden, _keine_ Ganzzahlen, und du kannst nicht direkt mit ihnen arbeiten.
Stattdessen müssen sie aus einem anderen bekannten Index berechnet werden, zum Beispiel `startIndex`, der auf die Position des ersten Zeichens in einem nicht leeren String zeigt. Dafür nutzt du die Methoden aus den Bibliotheken [`String`][string-docs] und [`NSString`][nsstring-docs] (wenn das Modul `Foundation` importiert ist, haben Strings in Swift Zugriff auf alle Eigenschaften und Methoden von NSString).

Zum Beispiel der folgende String:

```swift
let csv = "apple,pear,peach,orange,cherry,lime,goosberry"
```

Du kannst nicht `csv[21]` schreiben, um das „g“ in „orange“ zu erhalten. Stattdessen musst du einen Wert vom Typ `String.Index` berechnen und diesen Index übergeben.
Beachte, dass diese Indizes nicht dafür gedacht sind, von Menschen direkt gelesen zu werden.
Sie sind das, was man als _opake Indizes_ bezeichnet, denn Menschen müssen nicht wissen, was darin steckt.

```swift
let index = csv.index(csv.startIndex, offsetBy: 21)
csv[index]
// "g"
print(index)
// prints Index(_rawBits: 1376513)
```

Beachte jedoch: Wenn der Offset kein gültiger Index ist, also wenn er den Index vor `startIndex` oder nach `endIndex` zurückgeben würde, löst die Operation einen Fehler aus und das Programm stürzt ab.
Um dieses Problem zu vermeiden, kannst du einen begrenzenden Index angeben.
Dieser gibt einen optionalen Index zurück und liefert nil für Indizes, die sonst ungültig wären.

```swift
let tooFar = csv.index(csv.startIndex, offsetBy: 200)
// error: Execution was interrupted, reason: EXC_BAD_INSTRUCTION (code=EXC_I386_INVOP, subcode=0x0).
let tooFarButSafe = csv.index(csv.startIndex, offsetBy: 200, limitedBy: csv.endIndex)
// nil
```

Außerdem lassen sich Indizes nicht zwischen verschiedenen Strings verwenden.
Wenn du zum Beispiel den oben berechneten `index` des „g“ in „orange“ verwendest, um in den String `fam = "This is my family: 👨‍👩‍👦‍👦, this is our dog: 🐶, this is our cat: 🐱!"` zu indexieren, also `fam[index]`, stürzt dein Programm ab.

Es gibt viele Gründe dafür, aber im Grunde läuft alles immer darauf hinaus: „Unicode ist knifflig“.

Wenn du wahlfreien Zugriff auf einzelne Zeichen brauchst, solltest du im Allgemeinen eine andere Datenstruktur verwenden, zum Beispiel `Array<Character>`.

## Ein paar nützliche Methoden

Swift bietet die Methoden `first` und `last`, um das erste und letzte Zeichen eines Strings zu erhalten.
Diese Methoden geben ein optionales Zeichen zurück. Wenn der String leer ist, geben sie nil zurück.

```swift
let str = "Hello, world!"
print(str.first) // Prints Optional("H")
print(str.last)  // Prints Optional("!")
```

Du kannst auch die Methoden `prefix` und `suffix` verwenden, um einen Teilstring eines Strings zu erhalten.
Diese Methoden nehmen eine Ganzzahl als Argument und geben einen Teilstring mit den ersten bzw. letzten n Zeichen des Strings zurück.

```swift
let str = "Hello, world!"
print(str.prefix(5)) // Prints "Hello"
print(str.suffix(6)) // Prints "world!"
```

## Genauer hingeschaut: Unicode-Indizierung

~~~~exercism/advanced

[Unicode][unicode] ist ein Standard zur Kodierung von Text und umfasst eine große Anzahl von Zeichen aus vielen verschiedenen Sprachen und Schriftsystemen.
Er ist eine Obermenge von ASCII, das heißt, alle ASCII-Zeichen sind auch Unicode-Zeichen.
Unicode ist eine Kodierung mit variabler Länge, das heißt, einige Zeichen belegen mehr Bytes als andere.
Warum das wichtig ist, erklären wir im nächsten Abschnitt.

Um das Problem tatsächlich zu sehen, müssen wir zu anderen Sprachen als Englisch gehen. Nehmen wir das Zeichen „ü“ aus dem Deutschen (beachte, dass wir hier die 2-Byte-Variante verwenden, es gibt auch eine 1-Byte-Version).
Auf den ersten Blick sieht es wie ein einzelnes Zeichen aus, aber es sind tatsächlich zwei Zeichen: „u“ und „¨“. Wenn du also die Länge des Strings „ü“ ausgibst, wäre sie in Sprachen wie Python 2.
Als Nutzer oder Programmierer würden wir jedoch sagen, dass es ein einzelnes Zeichen ist, und Swift gibt uns tatsächlich recht.
Aber warum macht Swift das und Python nicht?
Die Antwort ist, dass Swift eine andere Darstellung von Strings verwendet als Python.
In Python werden Strings als eine Folge von Bytes dargestellt, das heißt, die Länge eines Strings ist die Anzahl der Bytes, die er im Speicher belegt.
In Swift werden Strings als eine Folge von Zeichen dargestellt, das heißt, die Länge eines Strings ist die Anzahl der Zeichen, die er enthält.
Das ist ein sehr wichtiger Unterschied, denn in Swift ist die Länge eines Strings nicht unbedingt gleich der Anzahl der Bytes, die er im Speicher belegt.
Das ist wiederum der Grund, warum wir Ganzzahlen nicht zum Indexieren von Strings verwenden können.
