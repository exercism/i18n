# Ergänzung zur Anleitung

## Wörter

- `<bst> ( data-seq -- tree )` – baue einen Baum auf, indem du jedes Element von `data-seq` der Reihe nach einfügst.
- `sorted-data ( tree -- seq )` – gib die Elemente des Baums in aufsteigender Reihenfolge zurück (In-Order-Durchlauf).

## Tupel-Hierarchie

Ein Knoten in einem binären Suchbaum ist entweder *leer* oder *hat Daten und zwei Teilbäume*. Modelliere das als kleine Vererbungshierarchie:

```factor
TUPLE: bst ;
TUPLE: leaf < bst ;
TUPLE: branch < bst data left right ;
```

`bst` ist die abstrakte Elternklasse; `leaf` ist der Fall des leeren Baums; `branch` trägt einen Wert und zwei Kinder vom Typ `bst` (jedes davon ist selbst entweder ein `leaf` oder ein `branch`).

## Reihenfolge

Vergleiche Daten mit `before=?` (aus `math.order`), das sowohl mit Strings als auch mit Zahlen funktioniert – die Tests verwenden String-Daten wie `"1"`, `"2"`, `"3"`.
