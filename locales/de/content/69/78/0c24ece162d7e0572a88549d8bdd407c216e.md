# Einführung

Julia ist eine Allzwecksprache, die für die meisten Programmieraufgaben verwendet werden kann.
In der Praxis liegen die wichtigsten Anwendungsfälle jedoch meist im Ingenieurwesen und in der Wissenschaft.
Schnelle, vielseitige und ausgefeilte numerische Berechnungen stehen im Zentrum des Designs.

## Ganzzahlen

Eine Ganzzahl ist eine „runde“ Zahl ohne Dezimalpunkt.

Im Konzept [Grundlagen][basics] haben wir gesehen, dass ein Ganzzahlwert einer Variablen zugewiesen werden kann, ohne einen Typ anzugeben.

Zur besseren Lesbarkeit können Unterstriche als Zifferntrennzeichen verwendet werden.
Sie werden vom Compiler ignoriert.

```julia-repl
julia> x = 3
3

julia> typeof(x)
Int64

julia> large_number = 1_234_567_890
1234567890
```


## Gleitkommazahlen

Es überrascht nicht, dass Gleitkommazahlen einen Dezimalpunkt und einen Nachkommateil haben.

```julia-repl
julia> f = 3.45
3.45

julia> typeof(f)
Float64
```

Natürlich wird auch die wissenschaftliche Notation unterstützt.

```julia-repl
julia> avogadro = 6.02e23
6.02e23
```

Die Maximal- und Minimalwerte könnten dich allerdings überraschen:

```julia-repl
julia> typemax(Float64)
Inf

julia> typemin(Float64)
-Inf
```

Unendlich ist ein gültiger Wert!

## Arithmetische Operatoren

Wie im Konzept Grundlagen besprochen, funktionieren arithmetische Operatoren meist genauso wie die normale Arithmetik, die man Kindern beibringt.
Beachte, dass die Potenzierung `^` verwendet, _nicht_ `**` (beides ist in anderen Sprachen üblich).

```julia
2 + 3  # 5 (addition)
2 - 3  # -1 (subtraction)
2 * 3  # 6 (multiplication)
8 / 2  # 4.0 (division)
8 % 3  # 2 (remainder)
2 ^ 3  # 8 (exponentiation)
```

Ein paar Julia-spezifische Details sind jedoch eine Diskussion wert.

### Multiplikation

```julia-repl
julia> x = 4.2
4.2

julia> 2 * x
8.4

julia> 2x
8.4

julia> 2.4x
10.08
```

Das mag überraschen.

Es ist immer möglich, `*` als Infix-Operator zu verwenden, wie in den meisten anderen Programmiersprachen.

Julia wurde jedoch von Menschen entworfen, die der Meinung sind, dass Code so weit wie möglich wie mathematische Gleichungen aussehen sollte.

Da Variablennamen mit einem Buchstaben beginnen müssen, wird eine Zahl (Ganzzahl oder Gleitkommazahl) vor dem Namen als implizite Multiplikation behandelt.

Wenn wir zum Beispiel die Oberfläche einer Kugel wollen, könnten wir statt `4 * pi * r * r` Folgendes tun:

```julia-repl
julia> surface(r) = 4π * r^2
surface (generic function with 1 method)

julia> surface(3)
113.09733552923255
```

Obwohl π eine eingebaute Konstante ist, ist es auch ein (griechischer) Buchstabe.
Der Parser braucht daher trotzdem ein explizites `*`, um `π` von `r` zu trennen.

### Division

Die Verwendung von `/` als Infix-Operator liefert immer ein Gleitkommaergebnis, selbst bei Ganzzahlen als Eingabe.

Für die Ganzzahldivision gibt es mehr Möglichkeiten.

```julia-repl
julia> 10 / 3  # floating-point division
3.3333333333333335

julia> div(10, 3)  # integer division
3

julia> 10 ÷ 3  # synonym for div()
3

julia> 10 // 3  # rational number (fraction)
10//3
```

Die Funktion `div()` ist für die Ganzzahldivision, wobei das Ergebnis gegen null abgeschnitten wird: bei positiven Zahlen abwärts, bei negativen Zahlen aufwärts.

Als Synonym können wir den Infix-Operator `÷` verwenden, wieder mit dem Ziel, es mathematischer aussehen zu lassen.
Wenn du einen Editor verwendest, der Julia versteht, gib dies als `\div` ein und drücke dann die `<Tab>`-Taste.

Der Operator `//` geht über den Rahmen dieses Konzepts hinaus.
Vorerst können wir einfach sagen, dass das Ergebnis von `//` eine „rationale“ Zahl ist, die die meisten Leute _Bruch_ nennen.

## Umwandlung numerischer Typen

Das kann oft automatisch geschehen:

```julia-repl
julia> x = 2 + 3.5
5.5

julia> typeof(x)
Float64
```

Wir haben eine `Int64` zu einer `Float64` addiert und ein `Float64`-Ergebnis erhalten.

Tatsächlich wurde die Ganzzahl stillschweigend in eine `Float64` umgewandelt, bevor die Addition durchgeführt wurde.

**Gleitkomma-zu-Ganzzahl**-Umwandlungen sind zwangsläufig komplizierter.
Was möchtest du mit allem nach dem Dezimalpunkt machen?

- Die Funktion `round()` wandelt in die nächstgelegene ganze Zahl um, wobei bei Gleichstand (wie bei 4.5) auf die nächstgelegene _gerade_ ganze Zahl gerundet wird.
- `floor()` rundet ab, `ceil()` rundet auf, `trunc()` rundet gegen null.
- Ein direkter Cast, zum Beispiel mit `Int32()`, schlägt mit einem `InexactError` fehl.

Standardmäßig geben diese Funktionen jedoch nicht den Ganzzahltyp zurück, den du vielleicht wolltest.
Der gewünschte Ausgabetyp kann angegeben werden.

```julia-repl
julia> round(4.5)
4.0

julia> ceil(Int, 4.3)
5
```

Das Runden auf eine bestimmte Anzahl von Nachkommastellen ist auch mit dem Schlüsselwort `digits` möglich.

```julia-repl
julia> round(π, digits=10)
3.1415926536
```

## Division durch null

Das wirft doch sicher einfach einen Fehler?
Tatsächlich ist die Situation nicht so einfach.

Die Ganzzahldivision mit `÷` oder `//` führt, wie du vielleicht erwartest, zu einem Fehler.

Die Gleitkommadivision mit `/` verfolgt einen eher ingenieurmäßigen Ansatz als den üblichen Ansatz der Informatik:

```julia-repl
julia> 2 / 0
Inf

julia> 0 / 0
NaN
```

Wie in einem vorherigen Abschnitt besprochen, ist Unendlich in Julia eine gültige Gleitkommazahl, dargestellt durch `Inf`.

Wenn der Zähler ebenfalls null ist, ist das Ergebnis mathematisch undefiniert.
Julia behandelt es dann als „keine Zahl“, dargestellt durch `NaN`.
