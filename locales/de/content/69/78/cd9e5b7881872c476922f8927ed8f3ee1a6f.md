## Z3 installieren

### Python herunterladen (falls noch nicht installiert)

Die neueste Version von Python findest du [hier.](https://python.org)

* Achte bei der Installation darauf, dass du das Kontrollkästchen aktivierst, das Python zum PATH hinzufügt

### Visual Studio herunterladen (falls noch nicht installiert)

Die neueste Version von Visual Studio findest du [hier.](https://visualstudio.microsoft.com/downloads/?utm_medium=microsoft&utm_source=docs.microsoft.com&utm_campaign=inline+link&utm_content=download+vs2019)

* Wähle bei der Installation die Workload **Python Development** aus
* Aktiviere rechts alle optionalen Kontrollkästchen für Python-Entwicklungspakete

Öffne nach der Installation Visual Studio und richte deine ersten Einstellungen ein.

### Git-Befehle installieren

Eine Anleitung zur Installation von Git findest du [hier.](https://git-scm.com/book/en/v2/Getting-Started-Installing-Git)

* Du musst [Git zu deinen Systemvariablen hinzufügen](https://stackoverflow.com/questions/4492979/git-is-not-recognized-as-an-internal-or-external-command)

### Z3 klonen

Gehe zum [Z3-GitHub-Repository](https://github.com/Z3Prover/z3), um das Projekt anzusehen.

Öffne ein Terminal auf deinem Computer und navigiere zu dem Ort, an den du das Z3-Repository klonen möchtest (z. B. C:\Z3).

Führe von dort aus Folgendes aus:

```bash
git clone https://github.com/z3Prover/z3.git
```

### Z3 unter Windows mit der Visual Studio Command Prompt bauen

Öffne die **Developer Command Prompt for VS 2019** über das Startmenü.

Navigiere zu dem Ordner, in den du das Z3-Repository geklont hast (z. B. C:\Z3).

Führe für 32-Bit-Builds Folgendes aus:

```bash
python scripts/mk_make.py
```

Führe für einen 64-Bit-Build Folgendes aus:

```bash
python scripts/mk_make.py -x
```

Führe danach Folgendes aus:

```bash
cd build
pip install z3-solver
```



Jetzt solltest du Visual Studio öffnen und Z3 mit seiner Python-Anbindung ausführen können.


Zum Testen kannst du Folgendes ausführen:
```python
from x3 import *
x = Real('x')
y = Real('y)
s = Solver()
s.add(x + y > 5, x > 1, y > 1)
print(s.check())
print(s.model())
```

Die letzten beiden Zeilen sollten `sat` und `[y = 4, x = 2]` ausgeben.
