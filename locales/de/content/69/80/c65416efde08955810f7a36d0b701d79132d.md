# Installation

Du brauchst den Node Package Manager (npm), um Reason zu installieren. Folge den Anweisungen [hier](https://www.npmjs.com/get-npm).

Sobald du npm hast, installierst du Reason so:
```
npm install -g bs-platform
```

Reason lässt sich in eine ganze Reihe von Editoren integrieren, siehe [hier](https://reasonml.github.io/docs/en/editor-plugins.html#officially-supported-editors).

Einige Kommandozeilen-Tools (darunter ein REPL, mit dem du Reason-Ausdrücke in einer Shell auswerten kannst) findest du [hier](https://github.com/reasonml/reason-cli).
