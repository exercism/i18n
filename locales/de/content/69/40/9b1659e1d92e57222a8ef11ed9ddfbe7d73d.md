# Einführung

So wie Eigenschaften, die Daten in deinen Strukturen und Klassen speichern, kannst du auch _Methoden_ definieren, die Funktionen in deiner Struktur oder deiner Klasse speichern.

Methoden werden genauso wie eine reguläre Funktion definiert, nur innerhalb der Struktur oder Klasse. Beachte, dass eine Funktion, die den Wert einer Eigenschaft in einer Struktur ändert, mit dem Schlüsselwort `mutating` versehen werden muss. Außerdem muss eine Eigenschaft, die von einer Methode geändert werden kann, mit `var` statt `let` definiert werden, genau wie bei regulären Variablen.

```swift
struct CharacterStats {
  var health = 0.0
  var speed = 0
  var strength = 0

  mutating func takeHit(_ damage: Double) {
    health = max(0.0, health - damage)
  }
  func canLift(_ weight: Int) -> Bool {
    weight < strength * 100
  }
}
```

Diese Methoden lassen sich genau wie Eigenschaften mit der Punktnotation aufrufen.

```swift
var stats = CharacterStats(health: 72.8, speed: 19, strength: 6)
stats.canLift(500)
// => true
```
