# Einführung

## Tupel

In Elixir ist ein Tupel eine Datenstruktur, die Daten organisiert und eine feste Anzahl von Elementen beliebigen Typs enthält, aber ohne explizite Namen für jedes Element. Tupel werden in Elixir oft für Operationen verwendet, die viele Lesezugriffe auf den Speicher erfordern, denn der Lesezugriff auf ein Element ist eine Operation mit konstanter Laufzeit. Sie werden normalerweise nicht verwendet, wenn Elemente dynamisch hinzugefügt oder entfernt werden müssen, denn statt das vorhandene Tupel zu ändern, wird ein neues Tupel erstellt, für das Speicher im Voraus reserviert werden muss.

In der Praxis werden Tupel in Elixir mit geschweiften Klammern erstellt. Auf die Elemente eines Tupels kann mit der Funktion `elem/2` und nullbasierter Indexierung einzeln zugegriffen werden:

```elixir
empty_tuple = {}
one_element_tuple = {1}
multiple_element_tuple = {1, :a, "hello"}

elem(multiple_element_tuple, 2)
# => "hello"
```

### Tupel als gruppierte Informationen

Tupel werden in der Praxis oft verwendet, um gruppierte Informationen darzustellen.

```elixir
Float.ratio(0.25)
# => {1, 4} indicating the numerator and denominator of the fraction ¼
```

## Musterabgleich

Die Verwendung von Musterabgleich ist in ausdrucksstarkem, idiomatischem Elixir-Code vorherrschend. Du erinnerst dich vielleicht, dass `=/2` als Match-Operator und nicht als Zuweisungsoperator beschrieben wird. Wenn du den Match-Operator verwendest und das Muster auf der linken Seite zur rechten Seite passt, werden alle Variablen auf der linken Seite gebunden. Der Wert der rechten Seite wird zurückgegeben. Wenn es keine Übereinstimmung gibt, wird ein `MatchError` ausgelöst.

```elixir
2 = 2
# => 2
# Literals can be matched if they are the same

2 = 3
# => ** (MatchError) no match of right hand side value: 3

{_, denominator} = Float.ratio(0.25)
# => {1, 4}
# the variable `denominator` is bound to the value 4
```

Denk daran: Übereinstimmungen erfolgen von der rechten zur linken Seite.

Wenn wir im letzten Beispiel eine Variable in einem Musterabgleich nicht brauchen, können wir sie mit `_` verwerfen.
Jede Variable, die mit einem `_` beginnt, wird von der Laufzeitumgebung nicht verfolgt.

### Musterabgleich in benannten Funktionen

Musterabgleich ist auch ein nützliches Werkzeug, wenn du mehrere Funktionsklauseln erstellst. Musterabgleich kann bei den Argumenten der Funktionen verwendet werden, was dann bestimmt, welche Funktionsklausel aufgerufen wird, beginnend oben in der Datei bis zur ersten Übereinstimmung. Variablen können in einem Funktionskopf gebunden und im Funktionskörper verwendet werden.

```elixir
defmodule Example do
  def named_function(:a = variable_a) do
    {variable_a, 1}
  end

  def named_function(:b = variable_b) do
    {variable_b, 2}
  end
end

Example.named_function(:a)
# => {:a, 1}

Example.named_function(:b)
# => {:b, 2}

Example.named_function(:c)
# => ** (FunctionClauseError) no function clause matching in Example.named_function/1
```
