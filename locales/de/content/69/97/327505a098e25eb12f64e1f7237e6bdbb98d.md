# Anweisungen

In dieser Übung verarbeitest du Zeilen aus einem protokollierten Bericht.
Jede Logzeile ist ein String mit folgendem Format: `"[<LEVEL>]: <MESSAGE>"`.

Es gibt drei verschiedene Log-Level:

- `INFO`
- `WARNING`
- `ERROR`

Du hast drei Aufgaben. Bei jeder bekommst du eine Logzeile und sollst etwas damit anstellen.

## 1. Die Nachricht aus einer Logzeile holen

Implementiere die Methode `log_line::message`, um die Nachricht einer Logzeile zurückzugeben:

```cpp
log_line::message("[ERROR]: Invalid operation")
// => "Invalid operation"
```

## 2. Den Log-Level aus einer Logzeile holen

Implementiere die Methode `log_line::log_level`, um den Log-Level einer Logzeile zurückzugeben, und zwar in Großbuchstaben:

```cpp
log_line::log_level("[ERROR]: Invalid operation")
// => "ERROR"
```

## 3. Eine Logzeile umformatieren

Implementiere die Methode `log_line::reformat`, die die Logzeile umformatiert: Sie stellt die Nachricht voran und hängt den Log-Level in Klammern dahinter:

```cpp
log_line::reformat("[INFO]: Operation completed")
// => "Operation completed (INFO)"
```
