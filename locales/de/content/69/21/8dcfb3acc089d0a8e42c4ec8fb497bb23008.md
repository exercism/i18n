# Einführung

## Namensräume

Eine wichtige Methode zur Organisation von Code ist die Verwendung von Namensräumen.
Zwei Funktionen könnten eine Namenskollision haben, die sich auflösen lässt, indem man sie in verschiedene Namensräume packt.
Namensräume lassen sich verschachteln, was helfen kann, große Codebasen zu strukturieren.
Der Zugriff auf die Namensräume erfolgt über den Gültigkeitsbereichsoperator `::`.

Das folgende Beispiel zeigt, wie zwei verschiedene Funktionen namens `foo` verwendet werden.
Sie werden zusammen verwendet, indem man ihre jeweiligen Namensräume voranstellt.

```cpp
namespace my_ns {
    int foo() {
        return 44;
    }
    namespace my_inner_ns {
        int baz() {
            return 90;
        }
    }
}
namespace my_other_ns {
    int foo() {
        return -2;
    }
}

int myresult{my_ns::foo() + my_other_ns::foo() * my_ns::my_inner_ns::baz()};
```
