# Kontrollfluss

`if`-Ausdrücke und Schleifen steuern den Ablauf der Ausführung in Cairo:
`

- **`if`-Ausdrücke** führen Code abhängig davon aus, ob eine Bedingung zu `true` ausgewertet wird.
- **Schleifen** (etwa `loop`, `while` und `for`) führen Code wiederholt aus, solange eine angegebene Bedingung wahr bleibt oder bis eine Abbruchbedingung erfüllt ist.

Diese Konstrukte sind grundlegend, um in Cairo Logik und Iteration umzusetzen.

## `if`-Ausdrücke

Mit `if`-Ausdrücken steuerst du in Cairo den Ablauf der Ausführung anhand einer Bedingung.
Ihr Aufbau ist so, dass Code abhängig davon ausgeführt wird, ob eine boolesche Bedingung zu `true` oder `false` ausgewertet wird.

```rust
fn main() {
    let temperature = 30;

    if temperature > 25 {
        println!("It's hot outside!");
    }
}
```

Dieses Beispiel zeigt einen einfachen `if`-Block in Cairo.
Die Meldung `"It's hot outside!"` wird nur ausgegeben, wenn die Bedingung `temperature > 25` zu `true` ausgewertet wird.
Ist die Bedingung `false`, wird kein Code ausgeführt und das Programm läuft weiter.

```rust
fn main() {
    let number: u32 = 5;

    if number < 10 {
        println!("The number is less than 10.");
    } else {
        println!("The number is 10 or greater.");
    }
}
```

Wenn du diesen Code ausführst, wird `"The number is less than 10."` in der Konsole ausgegeben.

### Mehrere Bedingungen mit `else if` behandeln

Du kannst mehrere Bedingungen verwenden, indem du `if` und `else` in einem `else if`-Ausdruck kombinierst.

```rust
fn main() {
    let score: u64 = 85;

    if score >= 90 {
        println!("Grade: A");
    } else if score >= 80 {
        println!("Grade: B");
    } else if score >= 70 {
        println!("Grade: C");
    } else {
        println!("Grade: F");
    }
}
```

Wenn du diesen Code ausführst, wird `"Grade: B"` in der Konsole ausgegeben.

### `if` in einer `let`-Anweisung verwenden

Der `if`-Ausdruck in Cairo kann auf der rechten Seite einer `let`-Anweisung stehen, um das Ergebnis einer Variablen zuzuweisen.

```rust
fn main() {
    let condition: bool = true;
    let number: felt252 = if condition {
        5
    } else {
        6
    };

    if number == 5 {
        println!("condition was true and number is {}", number);
    }
}
```

## Schleifen

Schleifen sind ein grundlegendes Konstrukt: Sie wiederholen Blöcke und lassen dich Aufgaben effizient und kontrolliert ausführen.
Schleifen können über eine Sequenz iterieren oder Code abhängig von einer Bedingung wiederholt ausführen.
Cairo bietet drei Arten von Schleifen:

- **`loop`**: Eine einfache Schleife, die unendlich läuft, bis sie mit einer `break`-Anweisung explizit gestoppt wird.
- **`while`**: Läuft so lange weiter, wie eine angegebene Bedingung `true` bleibt.
  Sie stoppt, wenn die Bedingung `false` wird.
- **`for`**: Iteriert über die Elemente einer Sammlung, etwa eines Arrays, und führt den Code für jedes Element aus.

### Code mit `loop` wiederholen

Das Schlüsselwort `loop` weist Cairo an, einen Block immer und immer wieder auszuführen, bis du ihm explizit sagst, dass es aufhören soll.

```rust
fn main() {
    loop {
        println!("again!");
    }
}
```

Wenn du diesen Code ausführst, wird `"again!"` so lange in der Konsole ausgegeben, bis dem Programm das Gas ausgeht oder wir es manuell stoppen.

> Hinweis: Cairo verhindert, dass wir ein Programm mit einer Endlosschleife ausführen, indem es einen Gaszähler mitbringt.
> Der Gaszähler ist ein Mechanismus, der begrenzt, wie viel Berechnung ein Programm durchführen kann.
> Gas ist eine Maßeinheit, die die Berechnungskosten einer Anweisung ausdrückt.
> Wenn der Gaszähler leer ist, stoppt das Programm.

Um eine Schleife zu verlassen, setzt du das Schlüsselwort `break` in die Schleife und sagst dem Programm damit, wann es die Ausführung beenden soll.

```rust
fn main() {
    let mut i: usize = 0;
    loop {
        if i > 10 {
            break;
        }
        println!("i = {}", i);
        i += 1;
    }
}
```

Das Schlüsselwort `continue` sagt dem Programm, dass es zur nächsten Iteration der Schleife springen und den restlichen Code in dieser Iteration überspringen soll.

```rust
fn main() {
    let mut i: usize = 0;
    loop {
        if i > 10 {
            break;
        }
        if i == 5 {
            i += 1;
            continue;
        }
        println!("i = {}", i);
        i += 1;
    }
}
```

Wenn du dieses Programm ausführst, wird der Wert von `i` nicht ausgegeben, wenn er gleich `5` ist.

#### Werte aus `loop` zurückgeben

Du kannst aus einer `loop` einen Wert zurückgeben, indem du auf das Schlüsselwort `break` den Wert folgen lässt, den du zurückgeben möchtest.
So verlässt du die `loop` und übergibst ein Ergebnis an den restlichen Code.

```rust
fn main() {
    let mut counter = 0;

    let result = loop {
        if counter == 10 {
            break counter * 2;
        }
        counter += 1;
    };

    println!("The result is {}", result); // prints "The result is 20"
}
```

### Bedingte Schleifen mit `while`

`while` führt Code aus, solange eine Bedingung `true` ist, und beendet die Schleife, wenn die Bedingung `false` wird.

```rust
fn main() {
    let mut number = 3;
    while number != 0 {
        println!("{}!", number);
        number -= 1;
    }
    println!("LIFTOFF!!!");
}
```

### Mit `for` über eine Sammlung iterieren

`for` iteriert über jedes Element einer Sammlung und führt den Code für jedes Element aus.

```rust
fn main() {
    let a = [10, 20, 30, 40, 50].span();
    for element in a {
        println!("the value is: {}", element);
    }
}
```
