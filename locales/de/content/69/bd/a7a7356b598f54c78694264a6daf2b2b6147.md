# Über

[Modulattribute][module-attr] können wie „Konstanten"[attr-as-const] verwendet werden, die zur Kompilierungszeit ausgewertet werden.

```elixir
defmodule Example do
  @number 2

  def number(), do: @number
end
```

Sie verhalten sich allerdings nicht wirklich wie Konstanten, weil sie überschrieben werden können, indem man sie im Modul neu definiert:

```elixir
defmodule Example do
  @standard_message "Hello, World!"
  @standard_message "Overwritten!"

  def message(), do: @standard_message
end
```

[module-attr]: https://hexdocs.pm/elixir/module-attributes.html
[attr-as-const]: https://hexdocs.pm/elixir/module-attributes.html#as-constants
