# Char

`Char` ist ein Datentyp in Crystal, der einen 32-Bit-[Unicode][unicode]-Codepoint darstellt.
Durch ihre Größe sind sie speichereffizient und haben besondere Eigenschaften, die Strings nicht haben.
Sie werden mit einfachen Anführungszeichen (`'`) erzeugt und lassen nur einen einzigen Unicode-Codepoint darin zu.

```crystal
'a' # => 'a'
'a'.class # => Char
```

In Crystal ist es recht üblich, mit Chars zu arbeiten, wenn du mit Strings arbeitest, denn einige Methoden der String-Klasse geben Chars zurück oder nehmen Chars als Argumente.
Zum Beispiel gibt die Methode [`String#[]`][index] einen Char zurück, oder die Methode [`String#chars`][chars] gibt eine Sammlung von Chars zurück.

## Erhöhen und Verringern

Da ein Char ein 32-Bit-Unicode-Codepoint ist, unterstützt er das Erhöhen und Verringern. So kannst du zu `'a'` eins addieren und erhältst `'b'`.

```crystal
'a' + 5
# => 'f'

'z' - 25
# => 'a'
```

Es gibt außerdem eine Methode namens [`Char#succ`][succ], die den nächsten Char in der Unicode-Tabelle zurückgibt, und [`Char#pred`][pred], die den vorherigen Char in der Unicode-Tabelle zurückgibt.

```crystal
'a'.succ
# => 'b'

'z'.pred
# => 'y'
```

## Verkettung

Da ein Char nur einen 32-Bit-Unicode-Codepoint darstellt, können zwei Chars nicht verkettet werden.
Deshalb lassen sich Chars nur mit Strings verketten.

```Crystal
'a' + "bc"
# => "abc"

'a' + 'b'
# => error: expected argument #1 to 'Char#+' to be Int or String, not Char
```

## Methoden für Eigenschaften

Crystal bietet einige Methoden, um Informationen über ein Zeichen zu erhalten, zum Beispiel ob es eine Zahl oder ein Buchstabe ist oder ob es groß- oder kleingeschrieben ist.
Hier ist eine Liste einiger dieser Methoden; die vollständige Liste findest du in der [Char-API][char-api]:

| Methode                          | Beschreibung                                             |
| -------------------------------- | -------------------------------------------------------- |
| [`Char#number?`][number]         | Gibt `true` zurück, wenn der Char eine Zahl ist          |
| [`Char#letter?`][letter]         | Gibt `true` zurück, wenn der Char ein Buchstabe ist      |
| [`Char#lowercase?`][lowercase]   | Gibt `true` zurück, wenn der Char kleingeschrieben ist   |
| [`Char#uppercase?`][uppercase]   | Gibt `true` zurück, wenn der Char großgeschrieben ist    |
| [`Char#ascii?`][ascii]           | Gibt `true` zurück, wenn der Char ein ASCII-Zeichen ist  |
| [`Char#whitespace?`][whitespace] | Gibt `true` zurück, wenn der Char ein Whitespace-Zeichen ist |

## Umwandeln

### Umwandeln zwischen Codepoints und Chars

Da ein Char ein 32-Bit-Unicode-Codepoint ist, kannst du zwischen Chars und Codepoints (Int) umwandeln.
Das geht mit der Methode [`Char#ord`][ord], die den Codepoint des Chars zurückgibt, oder mit der Methode [`Int#chr`][chr], die den Char zum Codepoint zurückgibt.

```crystal
'a'.ord
# => 97

97.chr
# => 'a'
```

### Umwandeln zwischen Typen

Wie bei anderen Datentypen gibt es auch für Chars einige Methoden, um zwischen Typen umzuwandeln.
Die gebräuchlichste ist die Methode `Char#to_s`, die den Char in einen String umwandelt. Es gibt aber auch die Methode `Char#to_i`, die den Char in ein Int umwandelt, und die Methode `Char#to_f`, die den Char in ein Float umwandelt.

```crystal
'a'.to_s
# => "a"

'4'.to_i
# => 4

'a'.to_i
# => Error: Invalid integer: a (ArgumentError)
```

## Escaping

Wie bei Strings gibt es bestimmte Zeichen, die sich nicht direkt schreiben lassen; um sie zu schreiben, musst du sie escapen.
Du kannst das Zeichen `\` verwenden, um eine Escape-Sequenz zu schreiben, gefolgt von dem Zeichen, das du escapen willst.

Das sind die Sonderzeichen in Crystal:

| Wert     | Beschreibung                   |
| -------- | ------------------------------ |
| `\a`     | Signalton                      |
| `\b`     | Rücktaste                      |
| `\e`     | Escape                         |
| `\f`     | Seitenvorschub                 |
| `\n`     | Zeilenvorschub oder neue Zeile |
| `\r`     | Wagenrücklauf                  |
| `\t`     | Horizontaler Tabulator         |
| `\v`     | Vertikaler Tabulator           |
| `\\`     | Backslash                      |
| `\'`     | Einfaches Anführungszeichen    |
| `\"`     | Doppeltes Anführungszeichen    |
| `\377`   | Oktales ASCII-Zeichen          |
| `\xFF`   | Hexadezimales ASCII-Zeichen    |
| `\uFFFF` | Hexadezimales Unicode-Zeichen  |
