# Einführung

## Boolesche Werte in R

Werte, die wahr oder falsch sind, werden durch den Typ `logical` dargestellt.
Er enthält nur zwei Werte: `TRUE` und `FALSE`.

```R
TRUE
#> [1] TRUE
FALSE
#> [1] FALSE
typeof(TRUE)
#> [1] "logical"
```

## Boolesche Operatoren

In R gibt es fünf boolesche Operatoren, aber an dieser Stelle im Lehrplan sind nur drei relevant.
Die anderen beiden werden wichtig, wenn du mit Vektoren arbeitest; das wird in mehreren späteren Konzepten behandelt.

`&&` ist das boolesche „und“.
Es wird zu `TRUE` ausgewertet, wenn die Ausdrücke auf *beiden* Seiten von `&&` `TRUE` sind.

```R
TRUE && TRUE
#> [1] TRUE
TRUE && FALSE
#> [1] FALSE
```

`||` ist das boolesche „oder“.
Es wird zu `TRUE` ausgewertet, wenn ein Ausdruck auf *einer* der beiden Seiten von `||` `TRUE` ist.

```R
TRUE || TRUE
#> [1] TRUE
FALSE || TRUE
#> [1] TRUE
```

`!` ist das boolesche „nicht“.
Es vertauscht `TRUE`- und `FALSE`-Werte.

```R
!TRUE
#> [1] FALSE
!FALSE
#> [1] TRUE
```

Bei längeren und komplizierteren Ausdrücken ist es am besten, runde Klammern zu verwenden, damit deine Absicht klar wird.

```R
(TRUE || FALSE) && (FALSE && TRUE)
#> [1] FALSE

TRUE || FALSE && (FALSE && TRUE)
#> [1] TRUE
```
