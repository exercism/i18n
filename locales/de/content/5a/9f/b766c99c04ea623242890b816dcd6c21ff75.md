# Hinweise

## Allgemein

## 1. Berechne die Produktionsrate pro Stunde

- Die Erfolgsrate kannst du mit einer [bedingten Anweisung](https://doc.rust-lang.org/stable/book/ch03-05-control-flow.html#if-expressions) bestimmen oder mit [Pattern Matching](https://doc.rust-lang.org/stable/book/ch18-01-all-the-places-for-patterns.html#match-arms).
- Da Rust eine Multiplikation nur zwischen Werten desselben Typs erlaubt, ist etwas [Type Casting](https://doc.rust-lang.org/rust-by-example/types/cast.html) nötig.

## 2. Berechne die Anzahl der pro Minute gefertigten funktionierenden Teile

- Genau wie bei der Multiplikation ist auch die Division nur zwischen Zahlen desselben Typs möglich. Indem wir eine Zahl mit einem Dezimaltrennzeichen schreiben (z. B. `1.0` statt `1`), können wir Konstanten direkt im Code vom Typ Gleitkommazahl schreiben.
