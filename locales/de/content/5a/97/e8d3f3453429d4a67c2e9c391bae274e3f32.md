# SQLite-spezifische Hinweise

* Die Spalte **digits** enthält eine JSON-kodierte Liste von Ganzzahlen.
  Beispiel:
  ```json
  [1,0,1,0,1,0]
  ```
* Die Spalte **result** sollte JSON-kodierte Daten enthalten: ein Objekt mit den Ziffern als Ganzzahlen oder eine Beschreibung etwaiger Fehler.
  Beispiele:
  ```json
  {"digits":[1,0,1,0,1,0]}
  ```
  oder
  ```json
  {"error":"some error description"}
  ```

## Tabellenschema

```sql
CREATE TABLE IF NOT EXISTS "all-your-base" (
  input_base  INTEGER NOT NULL,
  digits      TEXT    NOT NULL, -- json array
  output_base INTEGER NOT NULL,
  result      TEXT              -- json object
);
```
