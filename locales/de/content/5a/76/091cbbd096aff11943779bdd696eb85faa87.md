## General

- Um einen String zu definieren, kannst du doppelte Anführungszeichen `"` verwenden.
- Um Strings zu verketten, kannst du den `+`-Operator verwenden.
- Mit `#{}` kannst du einen String interpolieren.

## 1. Begrüße einen neuen Gast auf der Party

- Du kannst einen String mit einem anderen String mit dem `+`-Operator verketten.

## 2. Begrüße einen neuen Gast auf der Party, der heute Geburtstag hat

- Um eine Zahl in einen String umzuwandeln, kannst du die Methode `to_s` verwenden.

## 3. Gib eine Wegbeschreibung

- Um eine Zahl zu runden, kannst du die Methode `round` verwenden.
- Um ein Zeichen in einem String zu erhalten, kannst du die Methode `[]` verwenden, die eine Ganzzahl als Index entgegennimmt.
