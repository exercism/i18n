# Den ABAP-Track klonen

## Voraussetzungen

1. ABAP-System Release 7.4 oder höher
2. abapGit v1.115.0 oder höher
3. Berechtigungen zum Implementieren von ABAP-Paketen, -Programmen und -Klassen

## abapGit installieren

Der ABAP-Track mit allen Übungen ist als abapGit-Repository implementiert. Um den Track auf dein eigenes System zu klonen, musst du zuerst abapGit installieren.

1. Gehe zu [https://github.com/abapGit/abapGit](https://github.com/abapGit/abapGit)
2. Lade die Datei `zabapgit_standalone.prog.abap` herunter
3. Lege das Programm `zabapgit_standalone` in deinem eigenen System an
4. Lade den Quelltext aus `zabapgit_standalone.prog.abap` in das Programm `zabapgit_standalone` hoch
5. Aktiviere das Programm

## Exercism ABAP-Track installieren

### Online-Repository

Verwende diese Methode, wenn dein System mit dem Internet verbunden ist und Zugriff auf GitHub.com hat (empfohlener Ansatz).

1. Starte abapGit

![abapGit Online-Repository](https://github.com/exercism/abap/blob/main/docs/clone_01.png?raw=true)

2. Wähle in der „Repository Overview“ „New Online“ aus
3. Gib die folgenden Werte ein
- URL: `https://github.com/exercism/abap`
- Package: `$exer`
- Display Name: `Exercism - ABAP Track`

Hinweis: Wenn der Paketname zu lang ist, wie etwa `$exercism`, bekommst du beim Importieren des Repositorys einen Fehler. Halte den Namen deshalb so kurz wie oben angegeben.

![abapGit Online-Repository](https://github.com/exercism/abap/blob/main/docs/clone_02.png?raw=true)

4. Wähle „Create Online Repository“ aus. Du solltest eine Liste von Objekten mit dem Status „A“ sehen:

![abapGit Online-Repository](https://github.com/exercism/abap/blob/main/docs/clone_03.png?raw=true)

5. Wähle „Pull“ aus, um alle Objekte in dein System zu klonen. Nach Abschluss solltest du alle Objekte mit einem leeren Status sehen

![abapGit Online-Repository](https://github.com/exercism/abap/blob/main/docs/clone_04.png?raw=true)

### Offline-Repository

Verwende diese Methode, wenn dein System *nicht* mit dem Internet verbunden ist.

1. Gehe zu [https://github.com/exercism/abap](https://github.com/exercism/abap)
2. Lade die ZIP-Datei des Repositorys herunter

![abapGit Offline-Repository](https://github.com/exercism/abap/blob/main/docs/clone_10.png?raw=true)

3. Starte abapGit
4. Wähle in der „Repository Overview“ „New Offline“ aus
5. Gib die folgenden Werte ein
- Repository Name: `Exercism - ABAP Track`
- Package: `$exer`

![abapGit Offline-Repository](https://github.com/exercism/abap/blob/main/docs/clone_11.png?raw=true)

6. Wähle „Create Offline Repository“ aus

![abapGit Offline-Repository](https://github.com/exercism/abap/blob/main/docs/clone_12.png?raw=true)

7. Wähle „Import ZIP“ aus und such die heruntergeladene ZIP-Datei aus. Du solltest eine Liste von Objekten mit dem Status „A“ sehen:

![abapGit Offline-Repository](https://github.com/exercism/abap/blob/main/docs/clone_13.png?raw=true)

8. Wähle „Pull ZIP“ aus, um alle Objekte in dein System zu klonen. Nach Abschluss solltest du alle Objekte mit einem leeren Status sehen

![abapGit Offline-Repository](https://github.com/exercism/abap/blob/main/docs/clone_14.png?raw=true)

## Exercism ABAP-Track deinstallieren

Du kannst alle Objekte auf folgende Weise aus deinem System entfernen:

1. Starte abapGit
2. Gehe zum Repository `Execism - ABAP Track`
3. Wähle „Advanced > Uninstall“ aus
4. Bestätige das Löschen aller Objekte und des Repositorys

## Fehlerbehebung

- Bei Verbindungsproblemen schau dir [SSL Setup](https://docs.abapgit.org/user-guide/setup/ssl-setup.html) an
- Beim Fehler `Package $EXERCISM_DIFFERENCE-OF-SQUARES exceeds ABAP 30-characters name limit` verwende bitte einen kürzeren Paketnamen wie `$exer`.
- Bei einigen Dateien werden nach dem Pull in dein ABAP-System Diffs angezeigt. Unterschiede bei End-of-File-Zeichen oder Byte-Order-Marks kannst du ignorieren.
