# Anweisungen

Mary ist ein großer Fan der Fernsehserie _Star Trek: The Next Generation_. Sie spielt oft Pen-and-Paper-Rollenspiele, in denen sie und ihre Freunde sich als Crew der _Starship Enterprise_ ausgeben. Marys Figur ist Captain Picard, was bedeutet, dass sie das Logbuch des Captains führen muss. Sie liebt den kreativen Teil des Spiels, aber sie mag es nicht, spontan Zufallsdaten zu erzeugen.

Hilf Mary, indem du Zufallsgeneratoren für Daten erstellst, die häufig im Logbuch des Captains vorkommen.

## 1. Erzeuge einen zufälligen Planeten

Die _Starship Enterprise_ begegnet auf ihren Reisen vielen Planeten. Planeten im Star-Trek-Universum werden anhand ihrer Eigenschaften in Kategorien eingeteilt. Zum Beispiel ist die Erde ein Planet der Klasse M. Alle möglichen Planetenklassen sind: D, H, J, K, L, M, N, R, T und Y.

Implementiere die Funktion `random_planet_class/0`. Sie sollte eine der Planetenklassen zufällig zurückgeben.

```elixir
CaptainsLog.random_planet_class()
# => "K"
```

## 2. Erzeuge eine zufällige Registriernummer eines Raumschiffs

Die Enterprise (Registriernummer NCC-1701) ist nicht das einzige Raumschiff, das herumfliegt! Wenn sie sich mit einem anderen Raumschiff trifft, muss Mary die Registriernummer dieses Raumschiffs protokollieren.

Registriernummern beginnen mit dem Präfix „NCC-" und verwenden dann eine Zahl von 1000 bis 9999 (einschließlich).

Implementiere die Funktion `random_ship_registry_number/0`, die eine zufällige Registriernummer eines Raumschiffs zurückgibt.

```elixir
CaptainsLog.random_ship_registry_number()
# => "NCC-1947"
```

## 3. Erzeuge eine zufällige Sternzeit

Was nützt ein Logbuch, wenn es keine Daten enthält?

Eine Sternzeit ist eine Gleitkommazahl. Die Abenteuer der _Starship Enterprise_ aus der ersten Staffel von _The Next Generation_ spielen zwischen den Sternzeiten 41000.0 und 42000.0. Die „4" steht für das 24. Jahrhundert, die „1" für die erste Staffel.

Implementiere die Funktion `random_stardate/0`, die eine Gleitkommazahl zwischen 41000.0 (einschließlich) und 42000.0 (ausschließlich) zurückgibt.

Die Implementierung sollte eine Erlang-Funktion verwenden.

```elixir
CaptainsLog.random_stardate()
# => 41458.15721310934
```

## 4. Formatiere die Sternzeit

Im Logbuch des Captains werden Sternzeiten normalerweise auf eine Nachkommastelle gerundet.

Implementiere die Funktion `format_stardate/1`, die eine Gleitkommazahl entgegennimmt und einen String zurückgibt, in dem die Zahl auf eine Nachkommastelle gerundet ist.

Die Implementierung sollte eine Erlang-Funktion verwenden.

```elixir
CaptainsLog.format_stardate(41458.15721310934)
# => "41458.2"
```
