# Anleitung

Erstelle eine Implementierung der Atbash-Chiffre, eines alten Verschlüsselungssystems aus dem Nahen Osten.

Die Atbash-Chiffre ist eine einfache Substitutionschiffre, bei der alle Buchstaben des Alphabets so vertauscht werden, dass das resultierende Alphabet rückwärts läuft.
Der erste Buchstabe wird durch den letzten ersetzt, der zweite durch den vorletzten und so weiter.

Eine Atbash-Chiffre für das lateinische Alphabet sieht so aus:

```text
Plain:  abcdefghijklmnopqrstuvwxyz
Cipher: zyxwvutsrqponmlkjihgfedcba
```

Sie ist eine sehr schwache Chiffre, denn sie hat nur einen einzigen möglichen Schlüssel und ist eine einfache monoalphabetische Substitutionschiffre.
Zu ihrer Zeit war das allerdings möglicherweise kein Problem.

Der Geheimtext wird in Gruppen fester Länge geschrieben, wobei die traditionelle Gruppengröße bei 5 Buchstaben liegt. Zahlen bleiben unverändert stehen und Satzzeichen werden weggelassen.
Das soll es erschweren, anhand von Wortgrenzen auf den Inhalt zu schließen.
Der gesamte Text wird in Kleinbuchstaben kodiert.

## Beispiele

- Das Kodieren von `test` ergibt `gvhg`
- Das Kodieren von `x123 yes` ergibt `c123b vh`
- Das Dekodieren von `gvhg` ergibt `test`
- Das Dekodieren von `gsvjf rxpyi ldmul cqfnk hlevi gsvoz abwlt` ergibt `thequickbrownfoxjumpsoverthelazydog`
