# Anweisungen

Astrid, eine abenteuerlustige Alchemistin, versucht, die magischen Maßeinheiten zu standardisieren, die sie aus verschiedenen Reichen sammelt.
Einige Reiche verwenden vorzeichenbehaftete Maßeinheiten (die negativ sein können), während andere vorzeichenlose verwenden (die immer positiv sind).
Außerdem hat Astrid zwei eigene Typen für bestimmte seltene Zutaten, und sie braucht eine Möglichkeit, einfach zwischen diesen Typen umzuwandeln.

Deine Mission ist es, Astrid dabei zu helfen, zwischen vorzeichenbehafteten und vorzeichenlosen Ganzzahlen umzuwandeln und eigene Typumwandlungen für ihre speziellen Zutatentypen zu erstellen, und zwar mit den `Into`- und `TryInto`-Traits von Cairo.

## 1. Magische Einheiten zwischen vorzeichenbehaftet und vorzeichenlos umwandeln

Astrid hat Messwerte, die manchmal positive oder negative Werte haben (vorzeichenbehaftete Ganzzahlen), aber für bestimmte Aufgaben muss sie sicherstellen, dass die Werte immer positiv sind (vorzeichenlose Ganzzahlen).

Hilf Astrid, indem du eine Funktion schreibst, die Folgendes umwandelt:

1. Eine vorzeichenbehaftete Ganzzahl (`i32`) in eine vorzeichenlose Ganzzahl (`u16`).
2. Eine vorzeichenlose Ganzzahl (`u16`) in eine vorzeichenbehaftete Ganzzahl (`i32`).

```rust
let signed_value: i32 = -42;
match convert_signed_to_unsigned(signed_value) {
    Option::Some(v) => println!("Converted to unsigned: {}", v),
    Option::None => println!("Failed to convert: {}", signed_value),
} // prints "Failed to convert: -42"

let unsigned_value: u16 = 42;
let signed_value: i32 = convert_unsigned_to_signed(unsigned_value);
println!("Converted to signed: {}", signed_value); // prints "Converted to signed: 42"
```

## 2. Umwandlung eigener Zutatentypen

Astrid arbeitet mit zwei seltenen Zutaten, **Essence** und **Elixir**, die durch eigene Typen dargestellt werden.
Sie möchte **Essence** in **Elixir** umwandeln können, aber nicht umgekehrt.

Hilf Astrid, indem du zwei eigene Typen erstellst, `Essence` und `Elixir`, und den `Into`-Trait implementierst, um von `Essence` nach `Elixir` umzuwandeln.

Schreibe eine Funktion, die eine `Essence` entgegennimmt und sie mit `.into()` in ein `Elixir` umwandelt.

```rust
#[derive(Drop)]
struct Essence {
    potency: u16,
}

#[derive(Drop)]
struct Elixir {
    strength: u16,
}

fn convert_essence_to_elixir(essence: Essence) -> Elixir {
    // Convert the Essence to Elixir using the Into trait.
    essence.into()
}

fn main() {
    let essence = Essence { potency: 100 };
    let elixir: Elixir = convert_essence_to_elixir(essence);
    println!("Elixir strength: {}", elixir.strength); // Elixir strength: 100
}
```
