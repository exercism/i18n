Als angehende Magierin muss Elyse ein paar Grundlagen üben.
Sie hat ein Kartendeck, das sie gerne manipulieren möchte.

Damit es etwas einfacher wird, benutzt sie nur die Karten 1 bis 10.

## 1. Eine Karte aus dem Deck holen

Gib die Karte an Position `idx` aus dem gegebenen Deck zurück.

```julia-repl
julia> idx = 2;

julia> card([1, 3, 4, 1], idx)
3
```

## 2. Eine Karte im Deck austauschen

Tausche die Karte an Position `idx` gegen die angegebene neue Karte aus und gib das angepasste Deck zurück.
Beachte, dass dies den eingegebenen Vektor mutiert (verändert), und das ist in Ordnung.

```julia-repl
julia> idx = 2; new_card = 6;

julia> replace_card!([1, 3, 4, 1], idx => new_card)
[1, 6, 4, 1]
```

## 3. Eine Karte oben auf das Deck legen

Füge die neue Karte oben in das Deck ein und gib das Deck zurück.

```julia-repl
julia> new_card = 8;

julia> insert_card_at_top!([1, 3, 4, 1], new_card)
[1, 3, 4, 1, 8]
```

## 4. Eine Karte aus dem Deck entfernen

Entferne die Karte an Position `idx` aus dem Deck und gib das Deck zurück.

```julia-repl
julia> idx = 2;

julia> remove_card!([1, 3, 4, 1], idx)
[1, 4, 1]
```

## 5. Die oberste Karte vom Deck entfernen

Entferne die Karte oben im Deck und gib das Deck zurück.

```julia-repl
julia> remove_card_from_top!([1, 3, 4, 1])
[1, 3, 4]
```

## 6. Eine Karte unten an das Deck anfügen

Füge eine neue Karte unten in das Deck ein und gib das Deck zurück.

```julia-repl
julia> new_card = 8;

julia> insert_card_at_bottom!([1, 3, 4, 1], new_card)
[8, 1, 3, 4, 1]
```

## 7. Eine Karte von unten aus dem Deck entfernen

Entferne die Karte unten im Deck und gib das Deck zurück.

```julia-repl
julia> remove_card_at_bottom!([1, 3, 4, 1])
[3, 4, 1]
```

## 8. Die Größe des Decks prüfen

Prüfe, ob die Größe des Decks der angegebenen `deck_size` entspricht oder nicht.

```julia-repl
julia> deck_size = 4;

julia> check_deck_size([1, 3, 4, 1], deck_size)
true

julia> check_deck_size([1, 3, 4, 1, 5], deck_size)
false
```
