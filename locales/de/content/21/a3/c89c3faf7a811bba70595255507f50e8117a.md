# Wörterbücher

Wörterbücher sind in Cairo Schlüssel-Wert-Speicher, ähnlich wie Maps oder Hash-Tabellen in anderen Sprachen.

Allerdings haben sie aufgrund des unveränderlichen Speichermodells von Cairo einige Besonderheiten.

## Kernkonzept

Der Typ `Felt252Dict<T>` bietet Wörterbuchfunktionalität in Cairo, mit `felt252` als Schlüsseltyp und jedem unterstützten Typ `T` als Werttyp.

```rust
use core::dict::Felt252Dict;

fn main() {
    let mut balances: Felt252Dict<u64> = Default::default();
    balances.insert('Alice', 100);
    let balance = balances.get('Alice'); // Returns 100
}
```

## Wichtige Eigenschaften

Anders als Wörterbücher in anderen Sprachen haben Cairo-Wörterbücher einige besondere Eigenschaften:

1. Schlüssel müssen Werte vom Typ `felt252` sein.
2. Alle Schlüssel beginnen implizit mit dem Wert null.
3. Einträge kannst du nicht löschen, du kannst nur Werte aktualisieren.
4. Werte müssen das Trait `Felt252DictValue` implementieren.

## Hinweis zur Performance

Aufgrund des unveränderlichen Speichermodells von Cairo haben Wörterbuchoperationen eine Komplexität von $O(n)$, wobei $n$ die Anzahl der Operationen ist, die auf dem Wörterbuch ausgeführt werden.

Jede Operation erzeugt einen neuen Eintrag, der die Änderung festhält.

## Arbeiten mit komplexen Typen

Für Typen, die `Felt252DictValue` nicht implementieren (wie Arrays oder Structs), kannst du sie in `Nullable<T>` verpacken:

```rust
let mut dict: Felt252Dict<Nullable<Span<felt252>>> = Default::default();
dict.insert(0, NullableTrait::new(array![1, 2, 3].span()));
```

## Speicherverwaltung

Wörterbücher implementieren das Trait `Destruct`, das heißt, sie werden automatisch „zusammengequetscht“ (validiert und optimiert), wenn sie den Gültigkeitsbereich verlassen.

Das ist Teil des Beweissystems von Cairo und passiert im Hintergrund.

Denk daran: Wörterbücher wirken vielleicht weniger effizient als in anderen Sprachen, aber sie sind genau so entworfen, damit sie mit dem einzigartigen Speichermodell und den Anforderungen des Beweissystems von Cairo funktionieren.
