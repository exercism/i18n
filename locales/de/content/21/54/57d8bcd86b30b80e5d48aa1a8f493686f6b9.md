# Ergänzung zu den Anweisungen

## Wörter

`convert ( rows -- str )` nimmt das Gitter als Array von Strings entgegen, ein String pro Zeile, und gibt die erkannten Ziffern als einen einzelnen String zurück. Mehrere Zellenzeilen werden in der Ausgabe mit Kommas (`,`) verbunden.

## Fehler

Wirf bei fehlerhafter Eingabe einen dieser Strings (wörtlich) ab:

- `"Number of input lines is not a multiple of four"`
- `"Number of input columns is not a multiple of three"`
