# Einführung

## Webanwendungen

Elm ist eine wunderschöne Sprache, um zuverlässige Webanwendungen zu bauen.
Sie hat freundliche Fehlermeldungen, eine großartige Performance, kleine Assets und keine Laufzeitausnahmen.

Der wohl bekannteste und am häufigsten kopierte Teil von Elm ist The Elm Architecture, ein einfaches Muster, um Webanwendungen zu strukturieren, und die Art und Weise, wie alle Elm-Webanwendungen geschrieben werden.

Die Kernidee ist, dass dein Code um ein `Model` deines Anwendungszustands herum aufgebaut ist, außerdem um eine Möglichkeit, dein Model zu `update`n, und eine Möglichkeit, dein Model zu `view`en.

Das `Model` enthält den Zustand der Anwendung, also alle Daten, die die Anwendung braucht.
Wenn du dir eine einfache Anwendung mit einem Textfeld vorstellst und dazu Text, der diesen Text umgekehrt anzeigt, sähe das Model so aus wie unten.
Du kannst dieses Beispiel auch im [Elm Guide][elm-guide-text-fields] sehen.

```elm
type alias Model =
  { text : String
  }
```

`update` ist eine Funktion, die mit einer `Msg` aufgerufen wird, wenn sich etwas ändert (zum Beispiel, wenn der Benutzer auf eine Schaltfläche klickt).
Sie nimmt die `Msg` und das aktuelle `Model` und gibt ein neues `Model` zurück.

```elm
type Msg
  = TextChanged String

update : Msg -> Model -> Model
update msg model =
  case msg of
    TextChanged newText ->
      { model | text = newText }
```

`view` ist eine Funktion, die HTML zurückgibt, das dem Benutzer im Browser angezeigt wird.
Sie nimmt das aktuelle `Model` und gibt eine `Html Msg` zurück (der Typ, mit dem Elm HTML darstellt).

```elm
view : Model -> Html Msg
view model =
  Html.div []
    [ Html.input
      [ Html.Attributes.placeholder "Text to reverse"
      , Html.Attributes.value model.text
      , Html.Events.onInput TextChanged
      ]
      []
    , Html.div [] [ Html.text (String.reverse model.text) ]
    ]
```

[elm-guide-text-fields]: https://guide.elm-lang.org/architecture/text_fields
