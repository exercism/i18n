# Einführung

In Clojure bezeichnet man das Binden eines Werts an einen Namen als _Var_. Vars auf oberster Ebene (globale Vars) ähneln Konstanten in anderen Sprachen.

Vars auf oberster Ebene definierst du mit `def`:

```clojure
(def fingers 10)

fingers
;;=> 10
```

Mit `defn` kannst du eine Funktion definieren, die null oder mehr Argumente entgegennimmt. Diese Funktion würde zwei Zahlen addieren:

```clojure
(defn add [x y]
  (+ x y))
```

Diese Funktion nimmt zwei Argumente entgegen, die im Vektor `[x y]` stehen, gefolgt vom *Körper* der Funktion, der beliebig viele Ausdrücke enthalten kann. Der Rückgabewert ist immer das Ergebnis der Auswertung des letzten Ausdrucks im Körper, `(+ x y)`. Dieser Ausdruck ist eine Liste, die einen Funktionsaufruf darstellt. Das erste Element der Liste ist die Funktion `+`, die mit den folgenden Elementen `x` und `y` als Argumente ausgewertet wird.

Die oben definierte Funktion `add` rufst du genauso auf:

```clojure
(add 2 3)
;;=> 5
```

Funktionen und Werte in Clojure kannst du erst verwenden, _nachdem_ du sie definiert hast, d. h. Formen werden immer in der Reihenfolge ausgewertet, in der sie erscheinen.

In Clojure hat Leerraum keine andere Bedeutung als die Formatierung.

Clojure organisiert Funktionen und Vars in Namespaces. Ein Namespace fasst zusammengehörige Funktionalität zusammen und wird mit dem Makro `ns` definiert:

```clojure
(ns calculator)

(def pi 3.14)

(defn add [x y]
  (+ x y))
```

Clojure unterstützt zwei Arten von Kommentaren. Einzeilige Kommentare beginnen mit `;`, und die `comment`-Form verhindert die Auswertung von allem zwischen `(comment` und `)`.
