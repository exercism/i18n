# Anleitung

Du bist zurück in der Küche und feilst am Lasagne-Rezept aus
[Leahs köstliche Lasagne][lasagna]. Bei den Aufgaben hier jonglierst du
gleichzeitig mit mehreren Eingabewerten, und genau in solchen Fällen
zahlen sich *lokale Variablen* aus, also die benannten Bindungen von
Factor.

## 1. Bestimme den Garstatus

Definiere `cooking-status`, sodass es einen Timer-Wert vom Stack nimmt
und einen Status-String zurückgibt.

- `0` → `"Lasagna is done."`
- `f` (der Timer wurde nie gestellt) → `"You forgot to set the timer."`
- jede andere Zahl → `"Not done, please wait."`

```factor
12 cooking-status .   ! => "Not done, please wait."
0 cooking-status .    ! => "Lasagna is done."
f cooking-status .    ! => "You forgot to set the timer."
```

## 2. Schätze die Vorbereitungszeit

Definiere `preparation-time`, sodass es ein Array mit Schichtnamen und
eine durchschnittliche Minutenzahl pro Schicht nimmt und die gesamte
Vorbereitungszeit zurückgibt.

```factor
{ "sauce" "noodles" "sauce" "meat" "mozzarella" "noodles" } 3 preparation-time .
! => 18
```

## 3. Berechne die benötigten Mengen an Nudeln und Soße

Definiere `quantities`, sodass es ein Array mit Schichtnamen nimmt und
*zwei* Werte zurückgibt: die benötigte Menge Nudeln in Gramm (50 g pro
Nudelschicht) und die benötigte Menge Soße in Litern (`1/5` Liter pro
Soßenschicht).

```factor
{ "sauce" "noodles" "sauce" "meat" "mozzarella" "noodles" } quantities .s
! => 100
! => 2/5
```

## 4. Füge die geheime Zutat hinzu

Dein Freund schickt dir eine Liste mit Zutaten; der *letzte* Eintrag ist
sein Geheimnis. Definiere `add-secret-ingredient`, sodass es seine Liste
und deine nimmt und deine Liste mit der angehängten geheimen Zutat
zurückgibt.

```factor
{ "noodles" "sauce" "mozzarella" "kampot pepper" }
{ "noodles" "meat" "sauce" "mozzarella" }
add-secret-ingredient .
! => { "noodles" "meat" "sauce" "mozzarella" "kampot pepper" }
```

## 5. Skaliere das Rezept

Das Rezept im Kochbuch ergibt zwei Portionen. Definiere `scale-recipe`,
sodass es ein Rezept (eine Hashtable von Zutatenname zu Menge) und eine
Zielanzahl an Portionen nimmt und ein neues, passend skaliertes Rezept
zurückgibt.

```factor
H{ { "noodles" 200 } { "sauce" 1/2 } { "mozzarella" 1 } { "meat" 100 } }
4 scale-recipe .
! => H{ { "noodles" 400 } { "sauce" 1 } { "mozzarella" 2 } { "meat" 200 } }
```
