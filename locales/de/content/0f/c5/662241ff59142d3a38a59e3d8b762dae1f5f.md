# Hinweise

## Allgemein

- [Eigenschaften][docs.microsoft.com-properties]
- [Eigenschaften verwenden][docs.microsoft.com-using-properties]

## 1. Erlaube, dass die Waage eine Genauigkeit hat

- Du musst eine [Eigenschaft, die nur `get` hat][stackoverflow.com-get-only-properties] hinzufügen, um die Genauigkeit zu speichern.
- Du kannst die Eigenschaft, die nur `get` hat, im Konstruktor initialisieren (und nur dort).

## 2. Erlaube, dass das Gewicht an der Waage gesetzt werden kann

- Du solltest eine Eigenschaft mit einem privaten [Unterstützungsfeld][docs.microsoft.com-properties-with-backing-fields] hinzufügen.

## 3. Stelle sicher, dass ein negatives Eingabegewicht abgelehnt wird

- Das Schlüsselwort `value` wird verwendet, um auf den Wert zu verweisen, den der Aufrufer für die Eigenschaft haben möchte.
- Füge dem `set`-Accessor von `Weight` eine [Validierung][stackoverflow.com-validating-properties] hinzu, um eine Ausnahme auszulösen, wenn der Wert ungültig ist.

## 4. Erlaube, dass eine Tara-Anpassung auf die Waage angewendet wird

- Du solltest eine [automatisch implementierte Eigenschaft][docs.microsoft.com-auto-implemented-properties] für die Tara-Anpassung hinzufügen.

## 5. Stelle sicher, dass die Waage eine Standard-Tara-Anpassung hat

- Du kannst eine [automatisch implementierte Eigenschaft][docs.microsoft.com-auto-implemented-properties] genauso initialisieren wie ein Feld.

## 6. Erlaube, dass das Gewicht abgerufen werden kann

- Du solltest eine Eigenschaft hinzufügen, die nur `get` hat und in der das korrekte Anzeigegewicht berechnet wird.

## 7. Zeige den String für das Anzeigegewicht richtig an

- Du solltest den [Format-String][stackoverflow.com-format-string] passend wählen.
