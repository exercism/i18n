# Einführung

Mit einem `if/elif/else`-Ausdruck kannst du Logik bedingt ausführen. F# kennt aber noch einen anderen, mächtigeren Weg, Logik bedingt auszuführen: den Musterabgleich. Beim Musterabgleich wird ein Wert gegen ein oder mehrere _Muster_ geprüft. Ein Beispiel für ein solches Muster ist das _Konstantenmuster_, das einen Wert gegen eine Konstante prüft (z. B. `1` oder `"hello"`).

In F# erfolgt der Musterabgleich über das Schlüsselwort `match`:

```fsharp
let describe number =
    match number with
    | 0 -> "Zero"
    | 1 -> "One"
```

Das mag wie `switch`-Anweisungen in anderen Sprachen aussehen, doch der Musterabgleich spielt seine Stärke erst aus, wenn du auch andere Muster verwendest. Ein solches Muster ist das _Variablenmuster_, mit dem du einen Wert erfassen kannst:

```fsharp
match number with
| 0 -> "Zero"
| i -> sprintf "Non zero: %d" i
```

In manchen Fällen möchtest du einem Muster eine zusätzliche Bedingung hinzufügen. Das nennt man einen _Wächter_ oder eine _Wächterklausel_, den du mit dem Schlüsselwort `when` hinzufügst:

```fsharp
match number with
| 0 -> "Zero"
| i when i < 0 -> "Negative number"
```

Im obigen Beispiel hat nicht jede mögliche Eingabe ein passendes Muster. Der Compiler erkennt das und gibt eine Warnung aus. Man spricht hier von _Vollständigkeitsprüfung_. Um die Warnung zu beheben, musst du alle Fälle abdecken. Dafür kannst du das _Platzhaltermuster_ verwenden, ein Muster, das auf jeden Wert passt:

```fsharp
match number with
| i when i < 0 -> "Negative number"
| _ -> "Positive number"

// No compiler warning
```

Der Musterabgleich prüft einen Wert von oben nach unten gegen jedes Muster, bis er ein passendes Muster findet und die zugehörige Logik ausführt. Die Reihenfolge der Muster ist wichtig!
