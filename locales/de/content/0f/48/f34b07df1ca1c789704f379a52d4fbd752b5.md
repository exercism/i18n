# Installation

## Welches awk habe ich?

Der AWK-Track von Exercism verwendet `gawk`, das AWK von GNU.
Vielleicht hast du es bereits; führe zum Prüfen diesen Befehl aus:
```sh
awk --version
```

Wenn dabei Folgendes herauskommt:

* etwas wie `GNU Awk 5.1.0 ...`
    - Du hast bereits GNU awk und kannst mit den Übungen weitermachen.

* etwas wie `awk version 20200816`
    - Das ist `nawk`, auch bekannt als BWK awk (nach Brian Kernighan) oder „one true awk“.
    - Das ist die Version, die mit MacOS- und BSD-Systemen ausgeliefert wird.
    - Weiter unten findest du die Installationsanweisungen.

* der Fehler `awk: not an option: --version`
    - Wahrscheinlich hast du `mawk`.
    - Bestätigen kannst du das mit `awk -W version`, was `mawk 1.3.4 20200120` zurückgeben kann.
    - mawk ist eine sehr gute und schnelle awk-Implementierung, aber ihr fehlen einige der gawk-spezifischen Funktionen, die wir im Track verwenden werden.
    - Weiter unten findest du die Installationsanweisungen.

* der Fehler `awk: unrecognized option: version`, gefolgt von `BusyBox v1.35.0 ...`
    - Vielleicht verwendest du Alpine Linux.
    - Weiter unten findest du die Installationsanweisungen.

* ein Fehler „command not found“
    - Dann stimmt entweder mit deinem PATH etwas nicht, oder du hast awk einfach nicht installiert.
    - Weiter unten findest du die Installationsanweisungen.

### Linux

Hängt von der Paketverwaltung deiner Distribution ab. Typischerweise:
```sh
apt install gawk
yum install gawk
apk add gawk
# and so on
```
Möglicherweise brauchst du `sudo`, um den passenden Befehl auszuführen.

### MacOS

[Homebrew][brew] ist dein Freund. Folge dem Link, um es zu installieren, und führe dann aus:
```sh
brew install gawk
```

### Windows

Für [WSL][wsl] siehe die Anweisungen für Linux oben.
Für cygwin installiere das Paket `gawk`.

### Aus dem Quellcode kompilieren

Für die Mutigen gibt es Anweisungen [im `gawk`-Handbuch][build].
