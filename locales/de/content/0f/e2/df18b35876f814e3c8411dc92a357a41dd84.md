# Einführung

In Java gibt es zwei verschiedene Arten von Zahlen:

- Ganzzahlen: Zahlen ohne Ziffern hinter dem Dezimaltrennzeichen (ganze Zahlen).
  Beispiele sind `-6`, `0`, `1`, `25`, `976` und `-500000`.
- Gleitkommazahlen: Zahlen mit null oder mehr Ziffern hinter dem Dezimaltrennzeichen.
  Beispiele sind `-20.4`, `0.1`, `2.72`, `16.984025` und `1024.0`.

Die beiden häufigsten numerischen Typen in Java sind `int` und `double`.
Ein `int` ist eine 32-Bit-Ganzzahl und ein `double` ist eine 64-Bit-Gleitkommazahl.

Für die Arithmetik verwendest du die üblichen Rechenoperatoren.
Zahlen kannst du mit den üblichen Vergleichsoperatoren vergleichen (z. B. `5 > 4` und `4 <= 5`) sowie mit den Operatoren für Gleichheit (`==`) und Ungleichheit (`!=`).

In Java gibt es zwei Arten der Konvertierung von Zahlen:

1. Implizite Konvertierungen: Es gehen keine Daten verloren und es ist keine zusätzliche Syntax nötig.
2. Explizite Konvertierungen: Es könnten Daten verloren gehen und es ist zusätzliche Syntax in Form eines _Casts_ erforderlich.

Da ein `int` eine geringere Genauigkeit als ein `double` hat, ist die Umwandlung von einem `int` in ein `double` sicher und damit eine implizite Konvertierung.
Die Umwandlung von einem `double` in ein `int` kann jedoch Datenverlust bedeuten, deshalb ist dafür eine explizite Konvertierung nötig.
