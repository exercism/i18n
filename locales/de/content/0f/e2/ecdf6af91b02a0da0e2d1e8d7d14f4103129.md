# Einführung

Erinnere dich daran, dass ein `jq`-Programm eine _Pipeline von Ausdrücken_ ist.
**Eine Variablenzuweisung** folgt dieser Regel: Eine _Variablenzuweisung_ ist ein Ausdruck, der so aussieht:

```jq
... | expr as $varname | ...
```

## Der Filter gibt die Eingabe aus

Wie beim _Identitätsausdruck_ `.` ist die Ausgabe der _Variablenzuweisung_ dieselbe wie ihre Eingabe.
Das Setzen des Werts der Variable ist ein Seiteneffekt.

Ein Beispiel, das zeigt, dass `.` nach der Zuweisung gleich der ursprünglichen Eingabe ist:

```sh
$ jq -c -n '42 | (. * 2) as $double | [., $double]'
[42,84]
```

## Gültigkeitsbereich von Variablen

Der Gültigkeitsbereich der Variable ist „lexikalisch“: Die Variable bleibt für den Rest der Pipeline im Gültigkeitsbereich.
In Funktionen definierte Variablen (wir kommen später zu Funktionen) sind „lokal“ für die Funktion.

## Variablennamen

Die Variable muss mit `$` beginnen.
Der Rest des Variablennamens ist ein **Bezeichner**: Er beginnt mit einem Buchstaben oder Unterstrich, gefolgt von Buchstaben, Zahlen oder Unterstrichen.

## Destrukturierende Zuweisung

Aus dem Handbuch:

> Mit einem einzigen `as`-Ausdruck können mehrere Variablen deklariert werden, indem du ein Muster angibst, das _zur Struktur der Eingabe passt_ (das nennt man „Destrukturierung“).

Beispiele:

```jq
[1, 2, 3] as [$a, $b, $c]
| [$a, $b, $c]     # => [1, 2, 3]
```

```jq
{"foo": "bar", "len": [10, 20]} as {foo: $f, len: [$h, $w]}
| [$f, $h, $w]     # => ["bar", 10, 20]
```

Wenn der Variablenname mit dem _Objektschlüssel_ übereinstimmt, geht das kürzer:

```jq
{"x": 4, "y": 7} as {$x, $y}
| [$x, $y]         # => [4, 7]
```

```jq
{"foo": "bar", "len": [10, 20]} as {$foo, $len}
| [$foo, $len]     # => ["bar", [10, 20]]
```

## Konstanten

Wie das obige Beispiel zeigt, sind Variablen praktisch, um Konstanten zu speichern.
Es ist besser, einer Konstante einen Namen zu geben, als „magische Zahlen“ im Code auftauchen zu lassen.

## Oft brauchst du gar keine Variablen

Oft ist es lesbarer, auf Variablen zu verzichten.

Schauen wir uns an, wie man den Durchschnitt einer Liste von Zahlen berechnet

```jq
[2, 4, 8, 7]
| add as $sum
| length as $len
| $sum / $len
```

im Vergleich zu

```jq
[2, 4, 8, 7] | add / length
```

Das zeigt einen der mächtigsten Aspekte von `jq`: Die Eingabe für einen Filter steht _jedem_ Teilausdruck zur Verfügung:

- das Eingabe-Array `[2,4,8,7]` wird an `add` übergeben (das die Zahlen summiert, indem es den `+`-Operator auf alle Elemente anwendet)
- _parallel dazu_ wird `[2,4,8,7]` auch an `length` übergeben
- wenn diese Teilausdrücke abgeschlossen sind, werden ihre Ergebnisse dividiert und ergeben so den Durchschnittswert der Zahlen im Eingabe-Array.
