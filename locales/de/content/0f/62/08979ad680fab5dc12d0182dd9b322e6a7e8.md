# Zusätzliche Anweisungen

## Eingabeformat

Der Parameter `board`, der das Spielbrett darstellt, hat das Format eines Arrays aus Strings.

```javascript
['  B  ', ' B B ', 'B W B', ' W W ', '  W  '];
```

Jedes Zeichen eines Strings steht für eine Zelle.
Die gültigen Werte für eine Zelle sind:

- ` ` ein Leerzeichen für eine leere Zelle
- `B` eine Zelle, die dem schwarzen Spieler gehört
- `W` eine Zelle, die dem weißen Spieler gehört

## Ausgabeformate

Die Funktion `getTerritory` soll ein Objekt mit 2 Eigenschaften zurückgeben:

- `owner` Der Besitzer des Gebiets (`NONE`, `BLACK` oder `WHITE`)
- `territory` Ein Array von Koordinaten, die jede Zelle im Gebiet repräsentieren.

```javascript
{
    owner: 'BLACK',
    territory: [
        [0, 0],
        [0, 1],
        [1, 0],
    ],
}
```

Die Funktion `getTerritories` soll ein Objekt mit 3 Eigenschaften zurückgeben:

- `territoryBlack` Ein Array von Koordinaten, die die Gebiete repräsentieren, die dem Spieler `BLACK` gehören
- `territoryWhite` Ein Array von Koordinaten, die die Gebiete repräsentieren, die dem Spieler `WHITE` gehören
- `territoryNone` Ein Array von Koordinaten, die die Gebiete repräsentieren, die keinem der beiden Spieler gehören

```javascript
{
    territoryBlack: [
        [0, 0],
        [0, 1],
    ],
    territoryWhite: [
        [3, 0],
        [3, 1],
    ],
    territoryNone: [],
}
```
