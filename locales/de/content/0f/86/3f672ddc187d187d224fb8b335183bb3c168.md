# Einführung

In Cairo begegnet dir als eines der zentralen Konzepte der Typ `felt252`, auch bekannt als **Körperelement**.
Dieser Typ repräsentiert Ganzzahlen innerhalb eines bestimmten Bereichs, der durch eine große Primzahl $P$ festgelegt ist.
In dieser Übung arbeitest du ausschließlich mit dem Typ `felt252`, der ein wesentlicher Bestandteil der Programmierung mit Cairo ist.

Der Typ `felt252` in Cairo ist ein skalarer Typ, mit dem sich Ganzzahlen von 0 bis $P - 1$ darstellen lassen, wobei $P$ eine große Primzahl ist, die derzeit auf $( 2^{251} + 17 \cdot 2^{192} + 1 )$ gesetzt ist.
Dieser Typ sorgt dafür, dass alle Rechenoperationen modulo $P$ ausgeführt werden, was ihn von den Standard-Ganzzahltypen unterscheidet, die dir in anderen Programmiersprachen begegnen können.

Cairo unterstützt grundlegende Rechenoperationen mit `felt252`-Werten:

- **Addition (`+`)**: Addiert zwei `felt252`-Werte.
  Wenn das Ergebnis $P$ überschreitet, wird es modulo $P$ reduziert.
- **Subtraktion (`-`)**: Subtrahiert einen `felt252`-Wert von einem anderen.
  Wenn das Ergebnis negativ ist, wird es angepasst, um im Bereich zu bleiben, indem ein Vielfaches von $P$ addiert wird.
- **Multiplikation (`*`)**: Multipliziert zwei `felt252`-Werte, wobei das Ergebnis modulo $P$ berechnet wird.
- **Division (`/`)**: Dividiert einen `felt252`-Wert durch einen anderen und stellt dabei sicher, dass das Ergebnis die Gleichung $( \frac{x}{y} \cdot y = x \mod P)$ erfüllt.
