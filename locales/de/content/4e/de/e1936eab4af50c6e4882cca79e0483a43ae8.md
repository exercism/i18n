# Über

Boolesche Werte werden in Java durch den Typ `boolean` dargestellt. Ihre Werte sind entweder `true` oder `false`.

Java unterstützt drei [boolesche Operatoren][operators]:

- `!` (NOT): negiert den booleschen Wert
- `&&` (AND): nimmt zwei boolesche Werte und ergibt wahr, wenn beide wahr sind
- `||` (OR): ergibt wahr, wenn einer der beiden booleschen Werte wahr ist

Die Operatoren `&&` und `||` verwenden die _Kurzschlussauswertung_. Das heißt, die rechte Seite des Operators wird nur ausgewertet, wenn es nötig ist.

Man nennt sie auch Bedingungs- oder logische Operatoren.
In der Dokumentation wird `!` manchmal als bitweise Operation eingeordnet, aber es hat die übliche _NOT_-Semantik.

```java
true || false // => true
false || false // => false
false || true // => true
true && false // => false
true && true // => true
!true // => false
!false // => true
```

Die drei booleschen Operatoren haben jeweils eine andere [_Operatorrangfolge_][precedence].
Folglich werden sie in dieser Reihenfolge ausgewertet: zuerst `not`, dann `&&` und schließlich `||`.
Wenn du diese Regeln „umgehen“ willst, kannst du einen booleschen Ausdruck in runde Klammern (`()`) setzen, denn die Klammern haben eine noch höhere Operatorrangfolge.

```java
!true && false   // => false
!(true && false) // => true
```
