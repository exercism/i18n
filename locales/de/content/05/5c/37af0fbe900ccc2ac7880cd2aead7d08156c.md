# Überblick

Typischerweise akzeptieren Funktionen nur eine feste Anzahl an Argumenten.
Wenn du jedoch den Typ des letzten Parameters mit `...` präfixierst, kann die Funktion beliebig viele nachfolgende Argumente akzeptieren.
Dadurch wird der letzte Parameter zu einem _variadischen Parameter_.

```go
func sum(nums ...int) int {
    total := 0
    for _, n := range nums {
        total += n
    }
    return total
}
```

Innerhalb der Funktion ist der variadische Parameter ein Slice:

```go
sum(1, 2, 3)    // nums is []int{1, 2, 3}
sum(1, 2, 3, 4) // nums is []int{1, 2, 3, 4}
sum()           // nums is []int{}
```

Eine Funktion kann nicht-variadische Parameter vor dem variadischen Parameter haben.
Eine Funktion kann höchstens einen variadischen Parameter haben, und dieser muss der letzte Parameter sein.

```go
func greet(greeting string, names ...string) {
    for _, name := range names {
        fmt.Printf("%s, %s!\n", greeting, name)
    }
}
```

## Ein Slice entpacken

Um ein Slice an den variadischen Parameter zu übergeben, setze `...` dahinter:

```go
nums := []int{1, 2, 3}
sum(nums...) // equivalent to sum(1, 2, 3)
```

`...` ist nur dann gültig, wenn du ein Slice an einen variadischen Parameter übergibst.
