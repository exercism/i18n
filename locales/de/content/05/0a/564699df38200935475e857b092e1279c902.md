# Hinweise

## 1. Allgemeines

- Lies etwas über Dateien im offiziellen [Leitfaden „Erste Schritte“][getting-started-file].
- Lies etwas über Dateien auf [joyofelixir.com][joy-of-elixir-file].
- Wirf einen Blick in die [Dokumentation des Moduls `File`][file].

## 1. E-Mail-Adressen aus einer Datei lesen

- Es gibt eine [eingebaute Funktion][file-read], mit der du den Inhalt einer Datei auf einmal lesen kannst.

## 2. Eine Logdatei zum Schreiben öffnen

- Es gibt eine [eingebaute Funktion][file-open], mit der du eine Datei öffnest.
- Das zweite Argument dieser Funktion ist eine Liste von Modi. Damit kannst du festlegen, dass die Datei zum Schreiben geöffnet werden soll.

## 3. Eine gesendete E-Mail protokollieren

- Funktionen zum Lesen aus einer Datei und zum Schreiben in eine Datei, die mit [`File.open!/1`][file-open] geöffnet wurde, findest du im Modul [`IO`][io].
- Es gibt eine [eingebaute Funktion][io-puts], mit der du einen String in eine Datei schreibst, gefolgt von einem Zeilenumbruch.

## 4. Die Logdatei schließen

- Es gibt eine [eingebaute Funktion][file-close], mit der du eine Datei schließt.

## 5. Den Newsletter versenden

- Alle notwendigen Operationen an Dateien wurden in den vorherigen Schritten bereits implementiert.
- Bevor du in eine Datei schreibst, musst du die Datei öffnen.
- Nachdem alle Schreiboperationen an einer Datei abgeschlossen sind, solltest du die Datei schließen.
