# Einführung

Ein `bit` ist der kleinste Wert in der Informatik.
Das Wort `bit` steht für „Binärziffer“.
Es ist eine Einheit zur Datenspeicherung in der Ausführungsumgebung, die groß genug ist, um ein Objekt aufzunehmen, das einen von zwei Werten haben kann.
Als solches hat es einen binären Wert, entweder `1` oder `0`.
Alle anderen Datentypen bestehen aus mehreren `bits`.
Zum Beispiel besteht ein `byte` üblicherweise aus acht `bits`.

## Bitmasken

Eine Bitmaske kann jeder Wert sein, der zum Setzen einzelner Bits verwendet wird.
Das englische Alphabet hat zum Beispiel sechsundzwanzig Buchstaben.
Ein Wert mit mindestens sechsundzwanzig Bits, etwa eine vorzeichenlose 32-Bit-Ganzzahl, kann als Bitmaske dienen, um für jeden englischen Buchstaben eine `true`- oder `false`-Bedingung zu setzen.
Jeder Wert mit genügend Bits, um eine benötigte Menge von `true`- oder `false`-Bedingungen abzudecken, kann als Bitmaske dienen.
Das Setzen und Lesen der einzelnen Bits erfolgt mit bitweisen Operatoren.

## Bitweise Operatoren

Angenommen, wir wollen verfolgen, welche Buchstaben in einem `string` vorkommen.
Für unser Beispiel verwenden wir nur die sechsundzwanzig Buchstaben des englischen Alphabets.
Unsere Bitmaske ist eine vorzeichenlose 32-Bit-Ganzzahl.
Eine `0` steht dafür, dass der Buchstabe nicht vorkommt.
Eine `1` steht dafür, dass der Buchstabe ein- oder mehrmals vorkommt.
Am Anfang besteht die Bitdarstellung unserer Bitmaske aus 32 `0s` hintereinander: `00000000000000000000000000000000`.
Die rechteste Position ist für `A`.
Die zweite Position von links ist für `B`, und so weiter.
Sagen wir, wir verarbeiten alle Buchstaben des Strings in einer Schleife, also wollen wir eine einzige Codezeile, die zum Setzen jedes beliebigen Buchstabens funktioniert.

### Bitweise Linksverschiebung: ein Bit positionieren

`<<` ist der bitweise Operator zum Verschieben nach links.

Ist unser Buchstabe `A`, wollen wir nicht nach links verschieben; ist er `B`, verschieben wir um eine Position nach links, bei `C` um zwei Positionen und so weiter.
Wir nehmen `chars` zwar als Buchstaben wie `A` oder `B` wahr, doch ein `char` ist im Speicher als Ganzzahltyp umgesetzt, also können wir mit einem `char` einfache Rechenoperationen durchführen.
Mit einer Variablen namens `letter`, die das gerade verarbeitete `char` darstellt, verschieben wir die benötigte Anzahl von Positionen nach links, indem wir `1` um die Differenz zwischen `letter` und dem `char` `A` nach links verschieben, so: `1 << letter - 'A'`.
`A` - `A` ergibt `0`, also würde bei `letter` gleich `A` um `0` Positionen nach links verschoben.
`B` - `A` ergibt `1`, also würde bei `letter` gleich `B` um `1` Position nach links verschoben, und so weiter.

### Bitweises inklusives ODER: ein Bit setzen

Sobald wir wissen, _wo_ wir ein Bit setzen wollen, können wir es mit dem bitweisen inklusiven ODER-Operator setzen, also `|`.
Das Ergebnis des `|`-Operators ist `1` an jeder Position, an der entweder der linke oder der rechte Operand ein gesetztes Bit hat.
Das Ergebnis von `0010 | 0001` ist also `0011`.
(Wichtig: Der Wert ist `11` im Binärsystem, aber `3` im Dezimalsystem.)
Um das Ergebnis einem Wert zuzuweisen, lässt sich der `|`-Operator mit dem Zuweisungsoperator kombinieren, um die Bits so zu setzen: `|=`.
Der Einfachheit halber verwendet das folgende Beispiel keine Schleife, es zeigt aber, wie wir die Buchstaben `ABA` in einer Bitmaske verarbeiten könnten.

```c
#include <stdio.h>
#include <stdint.h>

int main() {
    // it's important to initialize the mask to 0 so we don't get garbage values
    uint32_t mask = 0;
    char letter_A = 'A';
    char letter_B = 'B';
    char letter_A_again = 'A';
    mask |= 1 << letter_A - 'A';
    mask |= 1 << letter_B - 'A';
    mask |= 1 << letter_A_again - 'A';
    // prints 3
    printf("%d", mask);
}
```

Wir setzen den rechtesten Teil unserer Maske für `A` auf `0001` und dann die Maske für `B` auf `0011`.
Ein weiteres `A` ändert die vorhandene Maske nicht.
Wir hätten das erneute Setzen des Bits vermeiden können, indem wir geprüft hätten, ob `A` schon gesetzt war.

### Bitweises UND: ein Bit auslesen

`&` ist der bitweise UND-Operator.
Das Ergebnis des `&`-Operators ist `1` an jeder Position, an der sowohl der linke als auch der rechte Operand ein gesetztes Bit hat.
Das Ergebnis von `0011 & 0001` ist also `0001`.
Das sehen wir im folgenden Beispiel in Aktion.

```c
#include <stdio.h>
#include <stdint.h>

int main() {
    uint32_t mask = 0;
    char letter_A = 'A';
    char letter_B = 'B';
    char letter_A_again = 'A';
    mask |= 1 << letter_A - 'A';
    mask |= 1 << letter_B - 'A';
    // prints A already set
    if (mask & 1 << letter_A_again - 'A')
        printf("A already set\n");
    else
        mask |= 1 << letter_A_again - 'A';
    printf("%d", mask);
}
```

### Bitweises exklusives ODER: ein Bit umschalten

`^` ist der bitweise exklusive ODER-Operator.
Ein _inklusives_ ODER legt nahe, dass es ein _exklusives_ ODER mit anderem Verhalten gibt.
Das Ergebnis des `^`-Operators ist `1` an jeder Position, an der _nur einer_ der beiden Operanden, links oder rechts, ein gesetztes Bit hat.
Das Ergebnis von `0001 ^ 0011` ist also `0010`.
Das rechteste Bit wird nicht gesetzt, weil _beide_ Operanden an der rechtesten Position eine `1` haben.
Die exklusive ODER-Verknüpfung wird manchmal als XOR geschrieben.
Wird das Ergebnis eines Werts, der XOR-verknüpft wurde, selbst noch einmal XOR-verknüpft, erhält man den ursprünglichen Wert zurück.
Das lässt sich für eine sehr einfache Verschlüsselung nutzen, bei der derselbe Schlüssel zum Ver- und Entschlüsseln der Daten dient.
Zum Beispiel

```c
#include <stdio.h>

int main() {
    char a = 'a';
    char b = 'b';
    char c = 'c';
    // we will use "a" for the "key"
    char first = a ^ 'a';
    char second = b ^ 'a';
    char third = c ^ 'a';
    // prints three "dots" for unprintable characters
    printf("%c %c %c\n", first, second, third);
    // prints the ascii values 0 3 2
    printf("%d %d %d\n", first, second, third);
    first = first ^ 'a';
    second = second ^ 'a';
    third = third ^ 'a';
    // prints a b c
    printf("%c %c %c\n", first, second, third);
    // prints the ascii values 97 98 99
    printf("%d %d %d\n", first, second, third);
}
```

## Bitfelder

Wir haben gesehen, wie sich Bits, die in einen einfachen Datentyp gepackt sind, über ihre Position ansprechen lassen.
In eine `struct` gepackte Bits lassen sich über ihren Namen ansprechen.
So einen Datentyp nennt man ein `bit field`.
Ein Anwendungsfall für `bit fields` ist eine Sammlung von AN/AUS-Flags, wenn zusätzlich der Speicherverbrauch möglichst klein sein soll.

```c
#include <stdio.h>

int main() {

    struct lights {
        unsigned int number_of_lights;
        unsigned int red   : 1;
        unsigned int green : 1;
        unsigned int blue  : 1;
    };
    struct lights lightboard = {3, 0, 0, 0};
     
    //  prints 000
    printf("%d", lightboard.red);
    printf("%d", lightboard.green);
    printf("%d\n", lightboard.blue);
    
    lightboard.green = 1;

    //  prints 010
    printf("%d", lightboard.red);
    printf("%d", lightboard.green);
    printf("%d\n", lightboard.blue);
    
    // prints 3
    printf("%d\n", lightboard.number_of_lights);
}
```

Die Syntax `unsigned int variable_name : 1;` erzeugt ein Feld von `1` Bit in einem `unsigned int`, das innerhalb der struct liegt.
Statt eines `unsigned int` kann auch ein `signed int` verwendet werden, oder seit C99 ein `bool`-Typ.
Eine struct mit Bitfeldern kann auch Felder anderer Datentypen enthalten, wie `number_of_lights` im obigen Beispiel.
