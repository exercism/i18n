# Installation

- macOS: Führe `brew install futhark` aus
- Linux: Führe `brew install futhark` aus
- Windows: Verwende entweder WSL oder folge [den Windows-spezifischen Anweisungen][windows-specific-instructions]

Alternative Installationsmethoden findest du in den [offiziellen Installationsanweisungen][instructions].

[instructions]: https://futhark.readthedocs.io/en/stable/installation.html
[windows-specific-instructions]: https://futhark.readthedocs.io/en/stable/installation.html#windows-installation
