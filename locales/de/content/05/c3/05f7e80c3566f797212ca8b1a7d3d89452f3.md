# Einführung

## Typdeklaration

Typdeklarationen in PHP bieten zur Laufzeit Typprüfungen für Funktionsargumente, Rückgabewerte und Klasseneigenschaften.
Bei Funktionen kannst du einen `void`-Rückgabetyp angeben, um anzuzeigen, dass die Funktion keinen Wert zurückgibt.
Deklarierte Typen dienen außerdem als Laufzeitprüfungen dafür, dass Funktionen einen einigermaßen passend typisierten Wert zurückgeben.

```php
<?php

class Driver
{
    private int $serial_number;

    public function setSerialNumber(int $number): void
    {
        $this->serial_number = $number;
    }

    public function getSerialNumber(): int
    {
        return $this->serial_number; 
    }
}

$driver = new Driver();
$driver->setSerialNumber("Version 1b"); // This will throw a TypeError
```

### Union-Typen

Wenn ein Funktionsargument, ein Rückgabewert oder eine Klasseneigenschaft mehr als einen Typ haben kann, kann ein Union-Typ deklariert werden.

```php
<?php

class IdentityCard
{
    private int|null $id = null;

    public function assign(int|float $id): void
    {
        $this->id = intval($id);
    }
}

$card = new IdentityCard();
$card->assign(5.0);
```

### Gemischte Typen

Beim Arbeiten mit Code können wir manchmal keinen Typ angeben.
Seit PHP 8.0 gibt es einen Notausgangstyp namens `mixed`.
Mixed entspricht einem Union-Typ aus `object|resource|array|string|float|int|bool|null`.
