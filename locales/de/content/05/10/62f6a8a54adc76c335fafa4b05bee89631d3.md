# Einführung in die Grundlagen

[Go](https://golang.org) ist eine statisch typisierte, kompilierte Programmiersprache.
Go ist syntaktisch ähnlich zu C.
Wegen seines früheren Domainnamens golang.org wird die Sprache oft Golang genannt, aber der richtige Name ist Go.

Das Konzept Grundlagen stellt dir drei wichtige Sprachmerkmale vor: Pakete, Funktionen und Variablen.

## Pakete

In Go sind Anwendungen in Pakete gegliedert.
Ein Paket ist eine Sammlung von Quelldateien, die sich im selben Verzeichnis befinden.
Alle Quelldateien in einem Verzeichnis müssen denselben Paketnamen haben.
Üblicherweise ist der Paketname das letzte Verzeichnis im Importpfad.
Zum Beispiel beginnen die Dateien im [Paket „math/rand“](https://golang.org/src/math/rand/) mit der Anweisung `package rand`.
Wenn du ein Paket importierst, kannst du nur auf Entitäten (Funktionen, Typen, Variablen, Konstanten) zugreifen, deren Namen mit einem Großbuchstaben beginnen.
Der empfohlene Namensstil in Go ist, dass Bezeichner in `camelCase` geschrieben werden, außer denen, die paketübergreifend zugänglich sein sollen; diese sollten `PascalCase` verwenden.

```go
package lasagna
```

## Variablen

Go ist statisch typisiert, was bedeutet, dass alle Variablen zur Kompilierzeit [einen definierten Typ haben müssen](https://en.wikipedia.org/wiki/Type_system).

Du kannst Variablen definieren, indem du einen Typ explizit angibst:

```go
var explicit int // Explicitly typed
```

Du kannst auch einen Initialisierungswert verwenden; der Compiler weist der Variablen dann den Typ zu, der zum Typ des Initialisierungswerts passt.

```go
implicit := 10   // Implicitly typed as an int
```

Nach der Deklaration kannst du Variablen mit dem Operator `=` Werte zuweisen.
Nach der Deklaration kann sich der Typ einer Variablen nie mehr ändern.

```go
count := 1 // Assign initial value
count = 2  // Update to new value

count = false // This throws a compiler error due to assigning a non `int` type
```

## Konstanten

Konstanten speichern einen Wert genau wie Variablen, aber ihr Wert kann sich während der Ausführung des Programms nicht ändern.

Konstanten werden mit dem Schlüsselwort `const` definiert und können Zahlen, Zeichen, Strings oder boolesche Werte sein:

```go
const Age = 21 // Defines a numeric constant 'Age' with the value of 21
```

## Funktionen

Go-Funktionen akzeptieren null oder mehr Parameter.
Parameter müssen explizit typisiert sein, es gibt keine Typinferenz.

Werte werden mit dem Schlüsselwort `return` aus Funktionen zurückgegeben.

Eine Funktion wird aufgerufen, indem du den Funktionsnamen angibst und für jeden Parameter der Funktion ein Argument übergibst.

Beachte, dass Go zwei Arten von Kommentaren unterstützt.
Einzeilige Kommentare beginnen mit `//`, mehrzeilige Kommentare stehen zwischen `/*` und `*/`.

```go
package greeting

// Hello is a public function.
func Hello (name string) string {
    return hi(name)
}

// hi is a private function.
func hi (name string) string {
    return "hi " + name
}
```
