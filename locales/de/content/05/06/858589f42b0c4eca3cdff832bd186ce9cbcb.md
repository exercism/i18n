# Einführung

Eine Definition einer Sammlung enthält typischerweise einen Platzhalter in spitzen Klammern, oft `T` nach Konvention. Eine solche Sammlung wird als generischer Typ bezeichnet. Dadurch kann die Person, die die Sammlung verwendet, festlegen, welchen Typ von Elementen sie in der Sammlung speichern möchte. Im obigen Beispielcode instanziieren wir eine Liste von Strings.
