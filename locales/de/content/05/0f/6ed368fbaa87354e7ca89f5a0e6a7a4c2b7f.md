# Einführung

Klassen sind ein grundlegender Baustein von Swift-Programmen.
Mit ihnen kannst du zusammengehörige Eigenschaften (Daten) und Methoden (Funktionen) zu in sich geschlossenen Einheiten bündeln.

### Klassen definieren

Um eine Klasse zu definieren, verwendest du das Schlüsselwort `class`, gefolgt vom Klassennamen. Die Klassendefinition schließt du in geschweifte Klammern ein:

```swift
class GameCharacter {
    var characterClass: String?
    var name: String?
    var active = false
    let id = makeRandomID()
}
```

In einer Klasse kannst du gespeicherte Eigenschaften definieren. Sie werden wie normale Konstanten (`let`) oder Variablen (`var`) definiert und verhalten sich auch so.

### Instanzen

Eine Klassendefinition ist ein Bauplan: Sie definiert einen neuen Typ und beschreibt, wie dessen Werte aussehen. Eine Instanz erzeugt sie dabei aber nicht.

Um eine *Instanz* einer Klasse zu erzeugen, rufst du ihren Initialisierer auf. Schreibe dazu den Klassennamen gefolgt von runden Klammern:

```swift
let someCharacter = GameCharacter()
```

So entsteht eine neue Instanz, deren Eigenschaften mit den Standardwerten aus der Klassendefinition initialisiert werden.
Optionale Eigenschaften ohne ausdrücklichen Standardwert (wie `name`) setzt Swift auf `nil`.

### Zugriff auf Eigenschaften

Auf die Eigenschaften einer Instanz greifst du mit der *Punktnotation* zu: Schreibe den Namen der Instanz, einen Punkt (`.`) und den Namen der Eigenschaft.
Die Punktnotation funktioniert auch für verschachtelte Eigenschaften.

Mit der Punktnotation kannst du Werte lesen und, wenn die Eigenschaft veränderbar ist (`var`), auch neue Werte zuweisen:

```swift
someCharacter.name
// => nil

someCharacter.name = "Luther"
someCharacter.name
// => "Luther"

someCharacter.id = "new id"
// Error: Cannot assign to property: 'id' is a 'let' constant
```

### Methoden

Neben Eigenschaften können Klassen auch *Methoden* definieren, also Funktionen, die zur Klasse gehören.

Methoden definierst du innerhalb der Klasse mit der üblichen `func`-Syntax.
Wenn eine Methode eine Eigenschaft verändert, muss diese mit `var` deklariert sein:

```swift
class GameCharacter {
    var characterClass: String?
    var name: String?
    var active = false
    let id: String = makeRandomID()

    func takesDamage(_ damage: Double) {
        if damage > 100 {
            active = false
        }
    }

    func sayName() -> String {
        return "My name is \(name ?? "no one"), my class is \(characterClass ?? "undetermined")"
    }
}
```

Methoden rufst du bei einer Instanz genauso wie Eigenschaften mit der Punktnotation auf:

```swift
var myChar = GameCharacter()
myChar.active = true
myChar.takesDamage(200)
myChar.active
// => false
```

### Self

Jede Instanz einer Klasse hat eine implizite Eigenschaft namens `self`, die auf die Instanz selbst verweist.
Beim Verweisen auf Eigenschaften oder Methoden wird sie oft weggelassen. Häufig verwendest du `self` aber, um zwischen einem Eigenschaftsnamen und einem Parameternamen einer Methode zu unterscheiden, wenn beide gleich heißen.
