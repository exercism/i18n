# Tests

## Interaktiv testen

Starte die REPL aus dem Verzeichnis, in das du die Übung heruntergeladen hast.

Du kannst die Tests ausführen, indem du die Testdatei mit `(load "exercise-test")` in die REPL lädst (ersetze dabei „exercise“ durch den passenden Namen). Rufe danach `(exercise-test:run-tests)` auf, um alle Tests auszuführen.

Wenn du deinen Code direkt in der REPL schreibst, rufe einfach `(exercise-test:run-tests)` auf.

Wenn du deinen Code in der Lisp-Datei der Übung schreibst, lade sie mit `(load "exercise")` und rufe danach `(exercise-test:run-tests)` auf.

## Testen auf der Kommandozeile

Du kannst die Tests mit diesem Kommandozeilenaufruf starten (ersetze „exercise“ wieder an zwei Stellen durch den passenden Namen)

```sh
ros run --load exercise-test.lisp --eval '(uiop:quit (if (exercise-test:run-tests) 0 1))'
```
