# Hinweise zur Übung

## Ein paar Anmerkungen zu Arturo-Strings

In den Tests siehst du eine Syntax, die dir vielleicht neu ist: mehrzeilige Strings, die in `{ braces }` eingeschlossen sind.

### Quellen

* Der [`:string`-Typ][string] in der Sprachreferenz.
* Die Dokumentation [zur grundlegenden Verwendung][usage] im Modul Strings.

[string]: https://arturo-lang.io/documentation/language/#string
[usage]: https://arturo-lang.io/documentation/library/strings/#basic-usage

### String-Literale in Arturo

In Arturo gibt es mehrere Möglichkeiten, String-Literale zu schreiben:

1. Einzeilige Strings in doppelten Anführungszeichen

    ```arturo
    greeting: "Hello, World!"

    print express greeting     ; => "Hello, World!"
    ```

1. Strings mit Zeilenende, eingeleitet durch ein „Smart Quote“ `«`

    ```arturo
    farewell: « Goodbye, Mars!

    print express farewell     ; => "Goodbye, Mars!"
    ```

   Die lassen sich schön lesbar gestalten, wenn du eine Liste mit kurzen Strings hast:

    ```arturo
    numberWords: [
        « one
        « two
        « three
        « four, and so on
    ]
 
    print express numberWords    ; => ["one" "two" "three" "four, and so on"]
    ```

1. Mehrzeilige Strings in geschweiften Klammern.
   Die „gemeinsame“ Einrückung wird entfernt.
   Führende und abschließende Zeilenumbrüche werden entfernt.

    ```arturo
    multiline: {
        First line
        Second line
            Third line keeps indentation
        Last line!


    }

    print express first multiline   ; => 'F'
    print express last multiline    ; => '!'
    lines: split.lines multiline
    print size lines                ; => 4
    print express lines\2           ; => "    Third line keeps indentation"
    ```

1. Verbatim-Strings bleiben exakt erhalten, einschließlich führendem und abschließendem Whitespace

    ```arturo
    code: {:
        greet: function [name][
            print ~"Hello, |name|~"

        greet "World""
    :}

    print ">" ++ code ++ "<"
    print express first code
        ; => prints a literal newline character between single quotes
    print express (split.lines code | get 1)
        ; => "    greet: function [name]["
    ```

1. Strings im Heredoc-Stil stehen unter einer Zeile aus 3 oder mehr Bindestrichen und reichen bis zum Ende der Datei.
   Das funktioniert genauso wie das Schlüsselwort `__DATA__` in Perl.
   Dieser Stil ist in einem Modul nützlich: Dort kannst du die Dokumentation oder den Lizenztext in einer Variablen am Ende der Datei ablegen.

    Wenn das in einer Datei namens „mymodule.art“ steht

    ```arturo
    myLicense:
    ---------
    This text has been placed in the public domain.
    Do with it what you will.
    ```

    Dann

    ```arturo
    import {mymodule}!
    print ~">|myLicense|<"  ; => >This text has been placed in the public domain.
                            ; => Do with it what you will.<
    ```
