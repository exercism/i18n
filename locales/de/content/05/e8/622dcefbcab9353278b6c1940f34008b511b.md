# Anleitung

In dieser Übung schreibst du etwas Code, um eine großartige Lasagne aus deinem Lieblingskochbuch zuzubereiten.

Du hast vier Aufgaben, die alle mit der Zeit zu tun haben, die du für das Kochen der Lasagne brauchst.

## 1. Definiere die erwartete Backzeit in Minuten

Definiere eine Konstante mit dem Namen `$expected_minutes_in_oven`.
Laut Kochbuch beträgt die erwartete Backzeit 40 Minuten:

```sh
$ jq -n -f lasagna.jq
{
  "expected_minutes_in_oven": 40,
  ...
```

## 2. Berechne die verbleibende Backzeit in Minuten

Dieser Wert nimmt die tatsächlichen Minuten, die die Lasagne bereits im Ofen war, als Eingabewert und gibt zurück, wie viele Minuten die Lasagne noch im Ofen bleiben muss. Grundlage dafür ist die erwartete Backzeit aus der vorherigen Aufgabe.

```sh
$ echo '{"actual_minutes_in_oven": 18}' | jq -f lasagna.jq
{
  "expected_minutes_in_oven": 40,
  "remaining_minutes_in_oven": 22,
  ...
```

## 3. Berechne die Vorbereitungszeit in Minuten

Die Vorbereitungszeit ist die Zeit, die du brauchst, um die Lasagne fertigzumachen, bevor sie in den Ofen kommt.
Für jede Schicht brauchst du 2 Minuten.

```sh
$ echo '{"number_of_layers": 3}' | jq -f lasagna.jq
{
  ...
  "preparation_time": 6,
  ...
```

## 4. Berechne die gesamte Arbeitszeit in Minuten

Berechne, wie viele Minuten du insgesamt mit dem Kochen der Lasagne verbracht hast.
Das ist die Summe aus der Vorbereitungszeit und der Zeit, die die Lasagne im Moment im Ofen verbracht hat.

```sh
$ echo '{"actual_minutes_in_oven": 10, "number_of_layers": 2}' | jq -f lasagna.jq
{
  ...
  "total_time": 14,
  ...
```
