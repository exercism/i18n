# Einführung

Der [ternäre Bedingungsoperator][ternary-operator] ist eine prägnante Kurzform für einen `if-else`-Ausdruck.
Er wertet eine Bedingung aus und gibt einen von zwei Werten zurück, je nachdem, ob diese Bedingung `true` oder `false` ist.

Der Operator besteht aus drei Teilen: `condition ? trueExpression : falseExpression`.
Wenn `condition` zu `true` ausgewertet wird, wird `trueExpression` ausgewertet und zurückgegeben, andernfalls wird `falseExpression` ausgewertet und zurückgegeben.

Der ternäre Operator eignet sich ideal für einfache Entscheidungen in einer Zeile:

```swift
let showFahrenheit = true
let temperatureInCelsius = 30

let temperature = showFahrenheit ? temperatureInCelsius * 9 / 5 + 32 : temperatureInCelsius
print(temperature)
// Prints 86
```

Das obige Beispiel ist eine kompakte Entsprechung zu:

```swift
let showFahrenheit = true
let temperatureInCelsius = 30

let temperature = if showFahrenheit {
    temperatureInCelsius * 9 / 5 + 32
} else {
    temperatureInCelsius
}
```

[ternary-operator]: https://docs.swift.org/swift-book/LanguageGuide/BasicOperators.html#ID71
