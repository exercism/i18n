# Über

Ein [`Array`][array] in Elm ist eine schnelle, unveränderliche Sammlung von null oder mehr Werten desselben Typs.
Da Arrays unveränderlich sind, kann sich der Wert eines Arrays nach seiner Erstellung nie mehr ändern.
Für Arrays gibt es keine Literalsyntax (anders als bei Listen), stattdessen wird die Syntax von Array.fromList verwendet.
Ein `Array` mit „a“, „b“ und „c“ darin wird zum Beispiel meist als `Array.fromList ["a", "b", "c"]` dargestellt.
Das siehst du in der Konsolenausgabe, im Debugger und an ähnlichen Stellen.

Anders als `List`, das ein [Standard-Import][default-imports] ist, muss das Modul `Array` ausdrücklich importiert werden, mit `import Array` oder ähnlich.

Typannotationen für Listen kannst du so definieren:

```elm
Array String --> an array of String
Array Int --> an array of Int
```

Arrays kannst du so definieren:

```elm
import Array exposing (Array)

empty : Array Char
empty = Array.empty

singleValue = Array.fromList [ 5 ] --> Array Int

repeatSingleValue = Array.repeat 2 5 --> Array.fromList [ 5, 5 ]

initialiseFromIndex = Array.initialise 3 (\index -> index * 2) --> Array.fromList [ 0, 2, 4 ]

initialisefromList = Array.fromList [ "a", "b", "c" ] --> Array.fromList [ "a", "b", "c" ]
```

Elemente fügst du einem Array mit `Array.push` hinzu:

```elm
twoToFour = Array.fromList [ 2, 3, 4 ]
oneToFour = Array.push 1 twoToFour --> Array.fromList [ 1, 2, 3, 4 ]
```

Mit `Array.append` hängst du Arrays aneinander:

```elm
sixSeven = Array.fromList [ 6, 7 ]
eightNine = Array.fromList [ 8, 9 ]
Array.append sixSeven eightNine --> Array.fromList [ 6, 7, 8, 9 ]
```

Ein Element in einem Array liest du mit `Array.get` aus:

```elm
sixSeven = Array.fromList [ 6, 7 ]
Array.get 0 sixSeven --> Just 6
```

Ein Element in einem Array setzt du mit `Array.set`:

```elm
sixSeven = Array.fromList [ 6, 7 ]
Array.set 1 8 sixSeven --> Array.fromList [ 6, 8 ]
```

Arrays werden mit Funktionen bearbeitet, die im [`Array`-Modul][array-module] definiert sind.

```elm
oneTwo = Array.fromList [ 1, 2 ]
Array.length oneTwo --> 2
```

Jede Funktion und jeder Operator, die ein `Array` zu verändern scheinen (etwa wenn ein Element hinzugefügt wird), gibt in Wahrheit ein neues `Array` zurück.
Die Performance ist aber meist kein Problem, weil die Implementierung von `Array` unnötige Allokationen und Kopien vermeidet.
