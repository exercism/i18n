# Hinweise

## Allgemein

- Um auf Instanzvariablen zuzugreifen und sie zu definieren, schreibst du `@` gefolgt vom Namen der Variable.

## 1. `TaskHandler` initialisieren

- Um einen `Proc` zu erstellen, verwendest du die Syntax `-> (args) { block }`.
- Wenn ein `Proc` für eine Instanzvariable definiert wird, muss er explizit typisiert werden.
  Das kannst du tun, indem du `: Proc(<arg_type>, <return_type>)` nach dem Variablennamen hinzufügst.
  Oder mit der Syntax `-> (arg_1 : <arg_type>) : <return_type> { block }`.
- Der `Proc` sollte vergleichen, ob das Argument größer oder gleich 0 ist.

## 2. Die Logik der Aufgabenbedingung aktualisieren

- Die Methode sollte einen Block als Argument entgegennehmen und ihn der Instanzvariable `@task_condition_logic` zuweisen.

## 3. Die nächste Aufgabe ausführen

- Um einen `Proc` auszuführen, kannst du die Methode `call` verwenden, die die Argumente für den Proc entgegennimmt.
