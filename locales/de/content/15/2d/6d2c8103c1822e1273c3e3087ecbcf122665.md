# Normalisierungen des Representers

Der [JavaScript-Representer][github-javascript-representer] wendet die folgenden Normalisierungen an:

## Kommentare entfernen

Alle Kommentare werden entfernt.
Die folgenden Beispiele sind äquivalent:

### Beispiel mit Kommentaren

```javascript
/**
 * Returns the string literal 'hi there' just to say hello
 * @return [String]
 */
function hello(/* nothing*/) {
  // just return it
  return 'hi there';
}
```

### Beispiel ohne Kommentare

```javascript
function hello() {
  return 'hi there';
}
```

## Leerraum normalisieren

Wenn der Code repräsentiert wird, ist seine _Reihenfolge_ von Bedeutung, seine physische Position aber nicht.
Das bedeutet, dass Leerraum normalisiert wird.
Die folgenden Beispiele sind äquivalent:

### Beispiel mit Einrückung um zwei Leerzeichen

```javascript
function hello() {
  return 'hello world';
}
```

### Beispiel mit Einrückung um vier Leerzeichen

```javascript
function hello() {
  return 'hello world';
}
```

### Beispiel mit interessanter Einrückung

```javascript
function hello() {
  return 'hello world';
}
```

## Bezeichner normalisieren

Bezeichner werden auf einen Platzhalterwert normalisiert.

### Davor

```javascript
const MY_CONSTANT = 42;

function answer(multiplier, addition = 1) {
  return MY_CONSTANT * multiplier + addition;
}
```

### Danach

```javascript
const PLACEHOLDER_1 = 42;

function PLACEHOLDER_2(PLACEHOLDER_3, PLACEHOLDER_4 = 1) {
  return PLACEHOLDER_1 * PLACEHOLDER_3 + PLACEHOLDER_4;
}
```
