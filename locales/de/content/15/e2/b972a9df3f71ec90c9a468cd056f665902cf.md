# Array-Methoden

Arrays sind eine häufige Datenstruktur, mit der man arbeitet.
Dabei gibt es eine Sammlung von Methoden, mit denen man Arrays bearbeiten kann.
Dazu gehören Sortieren, Umkehren, Einfügen und vieles mehr.

Einige dieser Methoden sind zerstörend, das heißt, sie verändern das ursprüngliche Array.
Andere sind nicht zerstörend, das heißt, sie geben ein neues Array zurück und verändern das ursprüngliche nicht.

Hier sind einige der häufigsten Methoden, die man im Umgang mit Arrays verwenden kann:

## insert

Beim Einfügen eines Elements in ein Array kannst du die Methode [`insert`][insert] verwenden, die einen Index und ein Element als Argumente entgegennimmt.
Das Element wird an der angegebenen Position eingefügt, und der Rest des Arrays wird nach rechts verschoben.
Liegt der Index außerhalb des gültigen Bereichs, wird ein `IndexError` ausgelöst.

```crystal
numbers = [1, 2, 3]
numbers.insert(1, 4)
numbers # => [1, 4, 2, 3]

numbers.insert(5, 5) # => Error: Index out of bounds (IndexError)
```

## delete

Wenn du ein bestimmtes Element aus einem Array löschen möchtest, kannst du die Methode [`delete`][delete] verwenden, die ein Element als Argument entgegennimmt.
Die Methode gibt das Element zurück, das entfernt wurde.
Existiert das Element nicht im Array, wird `nil` zurückgegeben.

```crystal
numbers = [1, 2, 3]
numbers.delete(2) # => 2
numbers           # => [1, 3]
```

## first & last

Wenn du das erste oder letzte Element eines Arrays erhalten möchtest, kannst du die Methoden [`first`][first] und [`last`][last] verwenden.
Diese Methoden nehmen ein optionales Argument entgegen, das angibt, wie viele Elemente zurückgegeben werden sollen.
Das kann die Lesbarkeit verbessern, verglichen mit dem Index `0` oder `-1` oder mit der Verwendung eines Bereichs.
Ist das Array leer, wird ein `Enumerable::EmptyError` ausgelöst.

```crystal
numbers = [1, 2, 3]
numbers.first # => 1
numbers.last  # => 3

numbers.first(2) # => [1, 2]
numbers.last(2)  # => [2, 3]

empty_array = [] of Int32
empty_array.last # => Error: Empty enumerable (Enumerable::EmptyError)
```

## reverse

Wenn du ein Array umkehren möchtest, kannst du die Methode [`reverse`][reverse] verwenden, die ein neues Array mit den Elementen in umgekehrter Reihenfolge zurückgibt.
Wichtig zu wissen ist, dass `reverse` ein neues Array zurückgibt und das ursprüngliche Array nicht verändert.
Wenn du das ursprüngliche Array verändern möchtest, hängst du ein `!` an das Ende des Methodennamens an.

```crystal
numbers = [1, 2, 3]
numbers.reverse # => [3, 2, 1]
numbers         # => [1, 2, 3]

numbers.reverse! # => [3, 2, 1]
numbers          # => [3, 2, 1]
```

## flatten & compact & transpose & uniq

Die folgenden Methoden sind nützlich, wenn du Operationen ausführst wie ein Array eindimensional zu machen, `nil`-Elemente zu entfernen, Duplikate zu entfernen oder ein Array aus Arrays zu transponieren.
Wie bei `reverse` geben diese Methoden ein neues Array zurück und verändern das ursprüngliche Array nicht.

| Methode | Beschreibung | Beispiel |
| ------ | ----------- | ------- |
| [`flatten`][flatten] | Gibt ein neues Array zurück, das eine eindimensionale Abflachung dieses Arrays ist (rekursiv). Das heißt, für jedes Array-Element werden seine Elemente in das neue Array extrahiert. | `[[1, 2], [3, 4]].flatten # => [1, 2, 3, 4]` |
| [`compact`][compact] | Gibt eine Kopie von self zurück, bei der alle nil-Elemente entfernt wurden. | `[1, nil, 2, nil, 3].compact # => [1, 2, 3]` |
| [`transpose`][transpose] | Nimmt an, dass self ein Array aus Arrays ist, und [transponiert][transpose] die Zeilen und Spalten. | `[[1, 2], [3, 4]].transpose # => [[1, 3], [2, 4]]` |
| [`uniq`][uniq] | Gibt ein neues Array zurück, indem doppelte Werte in self entfernt werden. | `[1, 2, 1, 3, 1].uniq # => [1, 2, 3]` |

## Concat(`+`)

Die Methode zum Anhängen (`<<`) ist nützlich, wenn du Objekte zu einem Array hinzufügen möchtest.
Wenn du jedoch zwei Arrays kombinierst, kannst du den Operator [`+`][concat] verwenden, der ein neues Array mit den Elementen beider Arrays zurückgibt.

```crystal
[1, 2] + [3, 4] # => [1, 2, 3, 4]
```

Wenn du ein Array an ein anderes Array anhängst, wird das Array als einzelnes Element hinzugefügt.

```crystal
[1, 2] << [3, 4] # => [1, 2, [3, 4]]
```

## empty?

Wenn du prüfen möchtest, ob ein Array leer ist, kannst du die Methode [`empty?`][empty?] verwenden, die `true` zurückgibt, wenn das Array leer ist, und andernfalls `false`.
Das verbessert die Lesbarkeit, verglichen damit, die Länge des Arrays mit `0` zu vergleichen.

```crystal
[].empty? # => true
[1, 2, 3].empty? # => false
```

## index

Wenn du den Index eines Elements in einem Array erhalten möchtest, kannst du die Methode [`index`][index] verwenden, die ein Element als Argument entgegennimmt.
Existiert das Element nicht im Array, wird `nil` zurückgegeben.

```crystal
numbers = [1, 2, 3]
numbers.index(2) # => 1
```

## size

Wenn du wissen möchtest, wie viele Elemente ein Array enthält, kannst du die Methode [`size`][size] verwenden.

```crystal
numbers = [1, 2, 3]
numbers.size # => 3
```

## count

Wenn du zählen möchtest, wie oft ein Element in einem Array vorkommt, kannst du die Methode [`count`][count] verwenden.

```crystal
fruits = ["apple", "banana", "apple"]
fruits.count("apple")      # => 2
fruits.count("banana")     # => 1
fruits.count("watermelon") # => 0
```

## sort

Wenn du ein Array sortieren möchtest, kannst du die Methode [`sort`][sort] verwenden, die ein neues Array mit den sortierten Elementen zurückgibt.
Wie bei `reverse` gibt diese Methode ein neues Array zurück und verändert das ursprüngliche Array nicht.

```crystal
numbers = [3, 2, 1]
numbers.sort # => [1, 2, 3]
numbers      # => [3, 2, 1]

numbers.sort! # => [1, 2, 3]
numbers       # => [1, 2, 3]
```
