# Einführung

Python hat drei verschiedene Typen eingebauter Zahlen: Ganzzahlen ([`int`][int]), Gleitkommazahlen ([`float`][float]) und komplexe Zahlen ([`complex`][complex]).
Fractions ([`fractions.Fraction`][fractions]) und Decimals ([`decimal.Decimal`][decimals]) sind ebenfalls über einen Import aus der Standardbibliothek verfügbar.

Ganze Zahlen, einschließlich hexadezimaler ([_`hex()`_][hex]), oktaler ([_`oct()`_][oct]) und binärer ([_`bin()`_][bin]) Zahlen **ohne** Nachkommastellen, werden ebenfalls als `ints` bezeichnet:

```python
# Ints are whole numbers.
>>> 1234
1234
>>> type(1234)
<class 'int'>

>>> -12
-12
```

Zahlen, die einen Dezimalpunkt enthalten (mit oder ohne Nachkommastellen), werden als `floats` bezeichnet:

```python
>>> 3.45
3.45
>>> type(3.45)
<class 'float'>
```

## Arithmetik

Python unterstützt Arithmetik zwischen diesen verschiedenen Zahlentypen vollständig und wandelt schmalere Zahlen um, damit sie zu ihren weniger schmalen Gegenstücken passen, wenn sie mit den binären arithmetischen Operatoren (`+`, `-`, `*`, `/`, `//` und `%`) verwendet werden.

### Addition und Subtraktion

Die Additions- und Subtraktionsoperatoren verhalten sich wie in der normalen Mathematik.
Wenn einer oder mehrere der Operanden ein `float` ist, werden die übrigen `int`s ebenfalls in `float`s umgewandelt:

```python
>>> 5 - 3
2
# The int is widened to a float here, and a float is returned.
>>> 3 + 4.0
7.0
```

### Multiplikation

Wie bei der Addition und Subtraktion wandelt die Multiplikation schmalere Zahlen um, damit sie zu ihren weniger schmalen Gegenstücken passen:

```python
>>> 3 * 2
6

>>> 3 * 2.0
6.0
```

### Division

Die Division gibt immer ein `float` zurück, selbst wenn das Ergebnis eine ganze Zahl ist:

```python
>>> 6/5
1.2

>>> 6/2
3.0
```

### Ganzzahlige Division

Wenn ein `int`-Ergebnis benötigt wird, kannst du die ganzzahlige Division verwenden, um das Ergebnis abzuschneiden.
Die ganzzahlige Division wird mit dem Operator `//` durchgeführt:

```python
>>> 6//5
1

>>> 6//2
3
```

### Modulo

Der Modulo-Operator (`%`) gibt den Rest der Division der beiden Operanden zurück:

```python
# The result of % is zero here, because dividing 8 by 2 leaves no remainder
>>> 8 % 2
0

# The result of % is 2 here, because 3 only goes into 5 once, with 2 leftover
>>> 5 % 3
2
```

Eine andere Betrachtungsweise von 5 % 3:

```python
>>> whole_part = int(5/3)
1

>>> decimal_part = 5/3 - whole_part
0.6666666666666667

>>> whole_remainder = decimal_part * 3
2.0
```

## Runden

Python stellt eine eingebaute Funktion [`round(number, <decimal_places>)`][round] bereit, um eine Gleitkommazahl auf eine bestimmte Anzahl von Nachkommastellen zu runden.
Wenn keine Anzahl von Nachkommastellen angegeben ist, wird die Zahl auf die nächste ganze Zahl gerundet und gibt ein `int` zurück:

```python
>>> round(3.1415926535, 2)
3.14

>>> round(3.1415926535)
3
```

## Priorität und Klammern

In Python kannst du Klammern verwenden, um Ausdrücke zu gruppieren.
Das ist nützlich, wenn du die Standardreihenfolge der Operationen überschreiben möchtest.

```python
>>> 2 + 3 * 4
14

>>> (2 + 3) * 4
20
```

Python folgt für die Operatorrangfolge der [PEMDAS][pemdas]-Regel.
Das bedeutet, dass Berechnungen innerhalb von `()` die höchste Priorität haben, gefolgt von `**`, dann `*`, `/`, `//`, `%`, `+` und `-`:

```python
>>> 2 + 3 - 4 * 4
-11

>>> (2 + 3 - 4) * 4
4

# In the following example, the `**` operator has the highest priority, then `*`, then `+`
# Meaning we first do 4 ** 4, then 3 * 64, then 2 + 192
>>> 2 + 3 * 4 ** 4
770
```

## Genauigkeit und Darstellung

Ganzzahlen in Python haben [beliebige Genauigkeit][arbitrary-precision]. Die Anzahl der Stellen ist nur durch den verfügbaren Speicher des Hostsystems begrenzt.

Gleitkommazahlen werden üblicherweise mit einem `double` in C implementiert (_15 Dezimalstellen Genauigkeit_), können aber je nach Hostsystem in ihrer Darstellung variieren.
Komplexe Zahlen haben einen `real`- und einen `imaginary`-Teil, die beide durch Gleitkommazahlen dargestellt werden.

Für ausführlichere Erörterungen der Probleme und Grenzen der Gleitkommaarithmetik über Programmiersprachen hinweg, schau dir [0.30000000000000004.com][0.30000000000000004.com] und das [Python-Tutorial][floating point math] an.
