# Einführung

Das Modul [`fractions`][fractions] ermöglicht es dir, [`rational numbers`][rational] zu erstellen und mit ihnen zu arbeiten: Brüche, bei denen eine Ganzzahl im Zähler durch eine Ganzzahl im Nenner geteilt wird.
Zum Beispiel können wir `2/3` als exakten Bruch speichern, statt als den genäherten `float`-Wert `0.6666...`.

Anders als `int`-, `float`- und `complex`-Zahlen haben Brüche keine Literalform.
Der Konstruktor für Brüche ist allerdings recht flexibel.

Am naheliegendsten nimmt er zwei Ganzzahlen als Argumente entgegen.
Gemeinsame Faktoren werden automatisch entfernt, wodurch der Bruch in seine „einfachste Form" (_die kleinsten Ganzzahlen, die den Bruch exakt darstellen_) gebracht wird:

```python
>>> from fractions import Fraction

>>> f1 = Fraction(2, 3) # 2/3
>>> f1
Fraction(2, 3)

>>> f2 = Fraction(6, 9)
>>> f2
Fraction(2, 3)  # automatically simplified

>>> f1 == f2
True
```

Der Konstruktor für Brüche kann auch eine String-Darstellung einlesen:

```python
>>> f3 = Fraction('2/3')
>>> f3
Fraction(2, 3)
```

Brüche können auch mit `float`-Parametern arbeiten, aber das kann wegen der genäherten internen Darstellung des Dezimalwerts als Binärzahl zu Problemen führen.
Mehr zu diesem Darstellungsproblem findest du auf der Website [0.30000000000000004][0.30000000000000004] und in [Floating Point Arithmetic: Issues and Limitations ][fp-issues] in der Python-Dokumentation.

Für ein zuverlässigeres Ergebnis bei der Verwendung von Gleitkommazahlen mit Brüchen gibt es die Methode `<fraction>.limit_denominator()`.


## Rechnen mit Brüchen

Die üblichen [`arithmetic operators`][operators] `+ - * / **` funktionieren mit Brüchen genauso wie mit anderen numerischen Typen.

Ganzzahlen und andere `Fraction`s können in den Ausdruck einbezogen werden und ergeben ein `Fraction`-Ergebnis.
Enthält der Ausdruck einen `float`, ist das Ergebnis ein `float`, was zu einem (möglichen) Präzisionsverlust führt:

```python
>>> Fraction(2, 3) + Fraction(1, 4) # addition
Fraction(11, 12)

>>> Fraction(2, 3) * Fraction(6, 5) # multiply fractions
Fraction(4, 5)

>>> Fraction(2, 3) * 6 / 5 # fraction with integers
Fraction(4, 5)

>>> Fraction(2, 3) * 1.2  # fraction with float -> float
0.7999999999999999

>>> Fraction(2, 3) ** 2  # exponentiation with integer
Fraction(4, 9)
```

Verschiedene numerische Standardfunktionen von Python liefern ebenfalls das Ergebnis, das du von der Arbeit mit `int`- und `float`-Typen erwarten würdest:

```python
>>> round(Fraction(11, 3))
4

>>> from math import floor, ceil
>>> floor(Fraction(11, 3))
3
>>> ceil(Fraction(11, 3))
4

>>> float(Fraction(11, 3))
3.6666666666666665
```
