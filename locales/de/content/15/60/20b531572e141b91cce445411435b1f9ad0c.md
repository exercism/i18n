# Einführung

Enumeration bedeutet, eine Sammlung (`Array`, `Hash`, usw.) schrittweise zu durchlaufen und für jedes Objekt eine Aktion auszuführen.

Enumeration ist ein zentrales Konzept in Ruby und wird zum Sortieren (`sort_by`), Gruppieren (`group_by`), Abbilden (`map`), Reduzieren (`reduce`) und für vieles mehr verwendet.
Meistens begegnet dir Enumeration als idiomatische Art, Sammlungen zu durchlaufen, statt Schleifen zu verwenden.

Eine einfache Enumeration mit `map` und `with_index` sieht so aus:

```ruby
words = %w[the cat sat on the mat]
list = words.map.with_index do |word, index|
  "#{index}. #{word}"
end

puts list

# Output:
# 0. the
# 1. cat
# 2. sat
# 3. on
# 4. the
# 5. mat
```
