# Anleitung

In deinem DNA-Forschungslabor hast du verschiedene Wege ausprobiert, deine Forschungsdaten zu komprimieren, um Speicherplatz zu sparen. Ein Teammitglied schlägt vor, die DNA-Daten in eine binäre Darstellung umzuwandeln:

| Nukleinsäure | Code   |
| ------------ | ------ |
| ein Leerzeichen | `0000` |
| A            | `0001` |
| C            | `0010` |
| G            | `0100` |
| T            | `1000` |

Du denkst darüber nach, denn das könnte die benötigten Speicherkosten halbieren, allerdings auf Kosten der menschlichen Lesbarkeit. Du beschließt, ein Modul zu schreiben, das deine Daten kodiert und dekodiert, um deine Einsparungen zu messen.

## 1. Nukleinsäure in einen Binärwert kodieren

Implementiere `encode_nucleotide/1`, sodass die Funktion den Codepunkt der Nukleinsäure entgegennimmt und den ganzzahligen Wert des kodierten Codes zurückgibt.

```elixir
DNA.encode_nucleotide(?A)
# => 1
# (which is equal to 0b0001)
```

## 2. Den Binärwert in die Nukleinsäure dekodieren

Implementiere `decode_nucleotide/1`, sodass die Funktion den ganzzahligen Wert des kodierten Codes entgegennimmt und den Codepunkt der Nukleinsäure zurückgibt.

```elixir
DNA.decode_nucleotide(0b0001)
# => 65
# (which is equal to ?A)
```

## 3. Eine DNA-Zeichenliste kodieren

Implementiere `encode/1`, sodass die Funktion eine Zeichenliste entgegennimmt, die Nukleinsäuren und Lücken repräsentiert, und einen Bitstring der kodierten Daten zurückgibt.

```elixir
DNA.encode(~c"AC GT")
# => <<18, 4, 8::size(4)>>
```

## 4. Einen DNA-Bitstring dekodieren

Implementiere `decode/1`, sodass die Funktion einen Bitstring entgegennimmt, der Nukleinsäuren und Lücken repräsentiert, und die dekodierten Daten als Zeichenliste zurückgibt.

```elixir
DNA.decode(<<132, 2, 1::size(4)>>)
# => ~c"TG CA"
```
