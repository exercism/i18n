# Anleitung

In dieser Übung schreibst du Code, um Namensschilder für Fabrikangestellte zu drucken.

## 1. Drucke ein Namensschild für einen Angestellten

Angestellte haben eine ID, einen Namen und einen Abteilungsnamen. Die Beschriftung eines Namensschilds hat folgendes Format: `"[id] - name - DEPARTMENT"`. Implementiere die (_statische_) Methode `Badge.Print()`, um die Beschriftung eines Namensschilds zurückzugeben:

```csharp
Badge.Print(734, "Ernest Johnny Payne", "Strategic Communication");
// => "[734] - Ernest Johnny Payne - STRATEGIC COMMUNICATION"
```

Beachte, dass die Abteilung auf dem Schild in Großbuchstaben geschrieben werden muss.

## 2. Drucke ein Namensschild für einen neuen Angestellten

Aufgrund einer Eigenheit im Computersystem haben neue Angestellte manchmal noch keine ID, wenn sie ihre Arbeit in der Fabrik beginnen. Da Namensschilder Pflicht sind, erhalten sie ein vorläufiges Namensschild ohne das ID-Präfix. Passe die (_statische_) Methode `Badge.Print()` an, damit sie neue Angestellte unterstützt, die noch keine ID haben:

```csharp
Badge.Print(id: null, "Jane Johnson", "Procurement");
// => "Jane Johnson - PROCUREMENT"
```

## 3. Drucke ein Namensschild für den Besitzer

Sogar der Besitzer der Fabrik muss jederzeit ein Namensschild tragen. Ein Besitzer hat jedoch keine Abteilung. In diesem Fall sollte das Schild `"OWNER"` anstelle des Abteilungsnamens anzeigen. Passe die (_statische_) Methode `Badge.Print()` an, um das Schild für den Besitzer auszugeben:

```csharp
Badge.Print(254, "Charlotte Hale", department: null);
// => "[254] - Charlotte Hale - OWNER"
```

Beachte, dass der Besitzer gleichzeitig auch ein neuer Angestellter sein kann:

```csharp
Badge.Print(id: null, "Charlotte Hale", department: null);
// => "Charlotte Hale - OWNER"
```
