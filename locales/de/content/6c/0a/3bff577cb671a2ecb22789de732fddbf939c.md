# Nachtrag zu den Anweisungen

## Umsetzung

Die Tests setzen einen Konstruktor voraus, der ein Array entgegennimmt. Im Inneren deiner eigenen Mengen-Implementierung kannst du auch andere Datenstrukturen verwenden, aber damit die Tests durchlaufen, musst du möglicherweise einen äußeren Konstruktor implementieren, der genau ein Array entgegennimmt.

Für einige Methoden gibt es einen entsprechenden Unicode-Operator. Zum Beispiel ist `intersect(CustomSet([1, 2, 3, 4]), CustomSet([]))` gleichbedeutend mit `CustomSet([1, 2, 3, 4]) ∩ CustomSet([])`.
