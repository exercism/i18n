# Bereiche

[Bereiche][range] repräsentieren ein Intervall zwischen zwei Werten.
Die häufigsten Typen, die Bereiche unterstützen, sind `Integer` und `String`.
Du kannst sie für vieles verwenden, zum Beispiel um schnell eine Sammlung zu erstellen, Strings zu zerlegen, zu prüfen, ob ein Wert in einem Bereich liegt, oder zum Iterieren.
Sie werden mit dem Range-Operator `..` oder `...` erstellt (inklusiv bzw. exklusiv).

```ruby
1..5  # => 1..5
1...5 # => 1...5

(1..5).to_a # => [1, 2, 3, 4, 5]
(1...5).to_a # => [1, 2, 3, 4]
```

Der Grund für zwei Range-Operatoren ist, dass du Bereiche erstellen kannst, die den Endwert einschließen oder ausschließen. Das ist zum Beispiel nützlich, wenn du mit nullbasierten Indizes arbeitest.

Bereiche können auch mit dem `Range`-Konstruktor `new` erstellt werden.

```ruby
Range.new(1, 5) # A range containing 1, 2, 3, 4, 5
```

~~~~exercism/note
Wenn du in Ruby einen Bereich mit den Range-Operatoren `..` oder `...` erstellst und eine Methode für den Bereich aufrufen möchtest, musst du den Bereich in runde Klammern setzen.
Sonst wird die Methode nämlich für das zweite Argument des Range-Operators aufgerufen.

```ruby
(1..5).sum # => 15
1..5.sum # => Error: undefined method `sum' for 5:Integer (NoMethodError)
```
~~~~

## Teilstrings extrahieren

Wenn du einen Teilstring aus einem String extrahieren möchtest, kannst du den Range-Operator verwenden.
Dazu erstellst du einen Bereich mit dem Start- und Endindex des Teilstrings.

```ruby
"Hello World"[0..4] # => "Hello"
"Hello World"[6..10] # => "World"
```

Du kannst auch negative Indizes verwenden, um den Teilstring vom Ende des Strings zu erhalten.

```ruby
"Hello World"[-5..-1] # => "World"
"Hello World"[6..-4] # => "Wo"
```

## Methoden für Bereiche

Bereiche haben eine Reihe von Methoden, mit denen du arbeiten kannst.
Zum Beispiel kannst du mit diesen Methoden die Summe aller Werte im Bereich berechnen oder prüfen, ob der Bereich einen Wert enthält.

| Methode                 | Beschreibung                                                            | Beispiel                        |
| ----------------------- | ----------------------------------------------------------------------- | ------------------------------- |
| [`sum`][sum]            | Gibt die Summe aller Werte im Bereich zurück                            | `(1..5).sum # => 15`            |
| [`size`][size]          | Gibt die Größe des Bereichs zurück                                      | `(1..5).size # => 5`            |
| [`include?`][indlude]   | Gibt `true` zurück, wenn der Bereich den angegebenen Wert enthält, sonst `false` | `(1..5).include?(3) # => true` |

## Endlose und anfangslose Bereiche

Ein Bereich kann endlos und anfangslos sein.
Bei einem endlosen oder anfangslosen Bereich ist der Start- oder Endwert `nil`, aber beim Definieren des Bereichs kannst du das `nil` weglassen.

Anfangslose und endlose Bereiche sind nützlich, wenn du zum Beispiel einen String vom Anfang oder bis zum Ende extrahieren möchtest.

```ruby
"Hello World"[0..] # => "Hello World"
"Hello World"[4..] # => "o World"
"Hello World"[..5] # => "Hello "
```

~~~~exercism/caution
Wenn du einen endlosen Bereich nicht auf eine Sammlung anwendest, kann er eine endlose Sequenz erzeugen. Verwende ihn also mit Vorsicht.
~~~~

## String-Bereiche

Strings können auch in Bereichen verwendet werden und ermöglichen ein Intervall von Strings zwischen zwei Strings.
Das Verhalten kann bei bestimmten Strings etwas unerwartet sein, also sei vorsichtig.

```ruby
("aa".."az").to_a # => ["aa", "ab", "ac", ..., "az"]
```
