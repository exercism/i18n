# Einführung

## Enums

Der `enum`-Typ in C# steht für eine feste Menge benannter Konstanten (eine Aufzählung). Sein Hauptzweck ist es, einen typsicheren Umgang mit numerischen Konstanten zu ermöglichen und die verfügbaren Werte auf eine vorab festgelegte Menge zu begrenzen. Ein einfaches Enum kannst du so definieren:

```csharp
enum Season
{
    Spring,
    Summer,
    Autumn,
    Winter
}
```

Wenn du die Werte nicht explizit angibst, bekommen die Enum-Member automatisch aufsteigende Ganzzahlen zugewiesen, wobei der erste Wert null ist. Es ist auch möglich, die Werte explizit zuzuweisen:

```csharp
enum Answer
{
    Maybe = 1,
    Yes = 3,
    No = 5
}
```
