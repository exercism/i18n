# Einführung

Viele Programmiersprachen haben eigene numerische Typen, um verschiedene Arten von Zahlen darzustellen, aber JavaScript kennt nur zwei:

- `number`: ein numerischer Datentyp im 64-Bit-Gleitkommaformat mit doppelter Genauigkeit (IEEE 754).
  Beispiele sind `-6`, `-2.4`, `0`, `0.1`, `1`, `3.14`, `16.984025`, `25`, `976`, `1024.0` und `500000`.
- `bigint`: ein numerischer Datentyp, der _Ganzzahlen_ im Format beliebiger Genauigkeit darstellen kann.
  Beispiele sind `-12n`, `0n`, `4n` und `9007199254740991n`.

Wenn du [beliebige Genauigkeit][ref-arbitrary-precision] brauchst oder mit extrem großen Zahlen arbeitest, nimm den Typ `bigint`.
Andernfalls ist der Typ `number` wahrscheinlich die bessere Wahl.

## Runden

Es gibt ein eingebautes globales Objekt namens `Math`, das verschiedene [Rundungsfunktionen][ref-math-object-rounding] bereitstellt. Du kannst Gleitkommazahlen zum Beispiel mit `floor` abrunden oder mit `ceil` aufrunden, jeweils auf die nächste ganze Zahl.

```javascript
Math.floor(234.34); // => 234
Math.ceil(234.34); // => 235
```
