# Ergänzung zu den Anweisungen

## Register

| Register | Verwendung | Typ      | Beschreibung                       |
| -------- | ---------- | -------- | ---------------------------------- |
| `$a0`    | Eingabe    | Adresse  | Array der Gewichte der Gegenstände |
| `$a1`    | Eingabe    | Adresse  | Array der Werte der Gegenstände    |
| `$a2`    | Eingabe    | Ganzzahl | Anzahl der Gegenstände             |
| `$a3`    | Eingabe    | Ganzzahl | maximales Gewicht                  |
| `$v0`    | Ausgabe    | Ganzzahl | maximaler Wert                     |
| `$t0-9`  | temporär   | beliebig | wird für temporäre Speicherung verwendet |
