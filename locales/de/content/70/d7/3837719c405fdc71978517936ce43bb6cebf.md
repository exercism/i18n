# Arrays

`ARRAY{T}` ist eine feste Reihe von Werten des Typs `T`.

```sather
   row : ARRAY{STR} := |"Mia", "Ana", "Ben"|;
   sizes : ARRAY{INT} := |3, 1, 2|;
```

## Die geschweiften Klammern

`ARRAY{STR}` liest man als „Array von `STR`“. Die geschweiften Klammern
enthalten einen **Typparameter**: `ARRAY` allein ist kein Typ, denn ein Array
muss immer ein Array von etwas sein. Ein großer Teil der Sather-Bibliothek ist
so aufgebaut, und eine solche Klasse selbst zu schreiben, kommt später.

## Positionen

```sather
row[0]                 -- the first
row[row.size - 1]      -- the last
row.size               -- how many
```

Die Positionen laufen von `0` bis `.size - 1`. Ein Array kennt seine Größe und
ändert sie nie: An ein `ARRAY` kann man nichts anhängen.

## Erzeugen ohne Literal

`#ARRAY{INT}(n)` erzeugt ein Array mit `n` Werten, alle null:

```sather
   counts ::= #ARRAY{INT}(5);      -- five noughts
   counts[0] := 7;
```

Eine Zuweisung an eine Position verwendet dieselben eckigen Klammern links von
`:=`.

## Außerhalb des Bereichs

Das Lesen oder Schreiben einer Position, die es nicht gibt, wird in einem
normalen Build nicht geprüft. Das Programm hält nicht mit einer hilfreichen
Meldung an; es liest oder schreibt einfach, was gerade als Nächstes im Speicher
steht. Zwei Gewohnheiten helfen dir, das zu vermeiden: benutze `.size - 1` statt
einer Zahl, die du per Augenmaß abgezählt hast, und beende Schleifen mit
`until!(i >= a.size)` statt mit einem Literal.

## Ausgeben

`.str` gibt den Inhalt in geschweiften Klammern aus, was praktisch ist, wenn du
etwas ausprobierst:

```sather
   #OUT + row.str;      -- {Mia,Ana,Ben}
```
