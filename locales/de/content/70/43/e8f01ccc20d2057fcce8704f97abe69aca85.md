# Tests

Die meisten Tests prüfen, dass du den erwarteten Wert zurückgibst, indem du [result] einen Wert zuweist oder einen Wert an [exit] übergibst.

Einige Tests prüfen, dass du die erwartete Ausnahme mit [raise] auslöst.

## Tests ausführen

Das Dienstprogramm `make` ist eine Voraussetzung, um die Tests auszuführen.

Gib im Verzeichnis der Übung in einer Konsole bzw. einem Terminal Folgendes ein:

```sh
make
```

Wenn du die Lösungsdatei der Übung noch nicht einmal angefasst hast, siehst du eine Meldung wie:

```
Please implement your solution.
```

Entferne diese Zeile also, bevor du mit dem Schreiben deiner Lösung beginnst.

Standardmäßig wird nur der erste Test ausgeführt.

```text
TAP version 14
1..10
ok 1 - ...
```

Um alle Tests auszuführen, gib Folgendes ein:

```sh
make test=all
```

```text
TAP version 14
1..10
ok 1 - empty_sentence
ok 2 - perfect_lower_case
ok 3 - only_lower_case
ok 4 - missing_the_letter_x
ok 5 - missing_the_letter_h
ok 6 - with_underscores
ok 7 - with_numbers
ok 8 - missing_letters_replaced_by_numbers
ok 9 - mixed_case_and_punctuation
ok 10 - am_and_AM_are_26_different_characters_but_not_a_pangram
```

Sobald alle Tests bestanden sind, bist du mit der Übung fertig und kannst die Lösung einreichen.

Du kannst einen einzelnen Test ausführen, indem du die entsprechende Nummer übergibst, zum Beispiel:

```sh
make test=2
```

würde nur den zweiten Test ausführen.
