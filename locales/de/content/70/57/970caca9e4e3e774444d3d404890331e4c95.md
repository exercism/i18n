# Lernen

Odin ist eine Systemprogrammiersprache.
Wie in C musst du den Speicher manuell verwalten.
Dennoch ist es eine recht einfache Sprache.

Die folgenden Ressourcen helfen dir, Odin zu lernen:

Einen ersten Eindruck von der Sprache bekommst du mit:

* Sieh dir die [Einführung in Odin][video] an, präsentiert von Odins Schöpfer.
* Lies den Artikel [Einführung in Odin][intro], geschrieben vom Autor von [„Understanding the Odin Programming Language“][book].
* Studiere die [Demo-Datei][demo], die Konzepte von Odin anhand von Code zeigt.

Tiefer einsteigen kannst du mit:

* [Überblick über die Sprache Odin][overview].
* Die Dokumentation für [offizielle Pakete][packages].
* Das Buch [„Understanding the Odin Programming Language“][book] (kostenpflichtig).
* Die offizielle Sammlung [„Odin-Beispiele“][examples].
