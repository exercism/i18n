# Hinweise

## Allgemein

## 1. Berechne die Produktionsrate pro Stunde

- Die Erfolgsquote kannst du mit einer [bedingten Anweisung][if-else-unless] bestimmen.
- Multiplizieren ist zwischen Instanzen von `Integer` und `Float` möglich. Das Ergebnis ist immer eine Instanz von `Float`.
- Zahlen lassen sich mit den eingebauten [Vergleichsoperatoren][comparison-operators] vergleichen.

## 2. Berechne die Anzahl der pro Minute produzierten funktionierenden Produkte

- Die Klasse `Float` implementiert eine [Methode][to_i], die eine Instanz von `Integer` zurückgibt.
- Die Klasse `Integer` implementiert eine [Methode][to_f], die eine Instanz von `Float` zurückgibt.

[if-else-unless]: https://www.w3resource.com/ruby/ruby-if-else-unless.php
[to_f]: https://docs.ruby-lang.org/en/master/Integer.html#method-i-to_f
[to_i]: https://docs.ruby-lang.org/en/master/Float.html#method-i-to_i
