# Anweisungen

Erstelle einen eigenen Set-Typ.

Manchmal ist es notwendig, eine eigene Datenstruktur eines bestimmten Typs zu definieren, zum Beispiel ein Set.
In dieser Übung definierst du dein eigenes Set.
Wie es intern funktioniert, ist egal, solange es sich wie ein Set aus eindeutigen Elementen verhält.
