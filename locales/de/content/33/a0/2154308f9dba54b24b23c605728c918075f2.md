# Einführung

## Listen

Eine Liste in Gleam ist eine unveränderliche Sammlung von null oder mehr Werten. Alle Werte in einer Liste müssen denselben Typ haben. Da Listen unveränderlich sind, kann sich ihr Wert, sobald eine Liste erstellt wurde, nie mehr ändern. Alle Funktionen oder Operatoren, die eine Liste zu verändern scheinen (etwa das Hinzufügen eines Elements), geben in Wirklichkeit eine neue Liste zurück.

Listen kannst du so definieren:

```gleam
let empty = []
let singleValue = [5]
let threeValues = ["a", "b", "c"]
```

Am häufigsten fügst du einer Liste ein Element mit der Spread-Syntax hinzu:

```gleam
let two_to_four = [2, 3, 4]
let one_to_four = [1, ..two_to_four]
// -> [1, 2, 3, 4]
```

Das Modul [`gleam/list`](https://hexdocs.pm/gleam_stdlib/gleam/list.html) in der Gleam-Standardbibliothek enthält viele nützliche Funktionen für die Arbeit mit Listen. Dieses Modul wird im Gleam-Code sehr häufig verwendet, deshalb ist es gut, es zu kennen.

Listenmuster kannst du in `case`-Ausdrücken verwenden, um Listen abzugleichen und die enthaltenen Werte Variablen zuzuweisen:

```gleam
pub fn describe(list: List(String)) -> String {
  case list {
    [] -> "Empty list"
    [x] -> "List with one item: " <> x
    [x, y] -> "List with two items: " <> x <> " and " <> y
    _ -> "List with three or more items"
  }
}
```

Neben dem Abgleich mit Listen exakter Länge kannst du die Spread-Syntax auch verwenden, um Listen abzugleichen, die mindestens eine bestimmte Länge haben:

```gleam
pub fn describe(list: List(String)) -> String {
  case list {
    [_, _, ..] -> "List with at least two items"
    [_] -> "List with one item"
    [] -> "Empty list"
  }
}
```

Mit der Spread-Syntax kannst du außerdem den Rest der Liste einer Variablen zuweisen:

```gleam
pub fn remove_first_item(list: List(String)) -> List(String) {
  case list {
    // Return the list without the first item
    [_, ..rest] -> rest

    // There's no first item to remove, return an empty list
    _ -> []
  }
}
```

`case`-Ausdrücke sollten ein Muster für jeden möglichen Wert des Typs haben, mit dem abgeglichen wird. Deshalb wird oft ein abschließendes Verwerfungsmuster (`_`) verwendet, um alle übrigen Werte abzudecken.
