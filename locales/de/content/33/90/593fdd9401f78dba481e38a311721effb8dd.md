# Ergänzung zur Übungsbeschreibung

## Implementierung

In dieser Übung implementierst du eine Prozedur, die den String, den sie zurückgibt, selbst allokieren soll. Den String wieder freizugeben, ist Aufgabe des Aufrufers der Prozedur.

```odin
// The procedure will be called like that:
formatted := format("Gianna", 4)
// ...
// and eventually the caller will delete the string
delete(formatted)
```
