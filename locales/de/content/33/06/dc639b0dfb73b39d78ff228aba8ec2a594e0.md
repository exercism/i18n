# Über

Eine [`list`][lists] in F# ist eine unveränderliche Sammlung von null oder mehr Werten. Alle Werte in einer Liste müssen denselben Typ haben. Da Listen unveränderlich sind, kann sich der Wert einer Liste nach ihrer Erstellung nie mehr ändern. Eine F#-Liste hat einen _Kopf_ (das erste Element) und einen _Rest_ (alles nach dem ersten Element). Der Rest einer Liste ist selbst eine Liste.

Listen lassen sich wie folgt definieren:

```fsharp
let empty = []
let emptyAlternative = List.empty

let singleValue = [5]
let singleValueAlternative = List.singleton 5

let threeValues = ["a"; "b"; "c"]
```

Ein Element fügt man am häufigsten mit dem `::`-Operator (cons) zu einer Liste hinzu:

```fsharp
let twoToFour = [2; 3; 4]
let oneToFour = 1 :: twoToFour
// => [1; 2; 3; 4]
```

Listen lassen sich mit dem `@`-Operator oder `List.append` aneinanderhängen:

```fsharp
[6; 7] @ [8; 9]           // => [6; 7; 8; 9]
List.append [6; 7] [8; 9] // => [6; 7; 8; 9]
```

Listen werden mit Funktionen und Operatoren aus dem [`List`-Modul][list-module] bearbeitet. Einige dieser Funktionen gibt es auch als [Eigenschaften][list-properties] einer `list`-Instanz:

```fsharp
List.length [7; 8] // => 2
[7; 8].Length      // => 2
```

Hier gibt es keine richtige oder falsche Wahl. Generell kommen die Funktionen im `List`-Modul besser mit der Typinferenz zurecht, während die Eigenschaften kompakteren Code erlauben.

Alle Funktionen und Operatoren, die eine Liste zu verändern scheinen (etwa wenn sie ein Element hinzufügen), geben in Wahrheit eine neue Liste zurück. Die Performance ist aber meist kein Problem, weil die Implementierung von Listen unnötige Allokationen und Kopien vermeidet.

Da Listen als einfach verkettete Listen umgesetzt sind, ist das Voranstellen eines Elements (mit dem `::`-Operator) sehr schnell, während der Zugriff auf ein Element über seinen Index potenziell relativ langsam ist.

Listen lassen sich außerdem mit Musterabgleich über die Muster [_list_][list-pattern] und [_cons_][cons-pattern] verarbeiten:

```fsharp
let describe list =
    match list with
    | [] -> "Empty list"
    | [ 1 ] -> "Singleton list with 1"
    | head::tail -> sprintf "Non-empty list with head: %d" head

describe []        // => "Empty list"
describe [1]       // => "Singleton list with 1"
describe [5; 7; 9] // => "Non-empty with head: 5"
```

Beim Musterabgleich kannst du außerdem einen Wert _verwerfen_. Wenn dir ein Wert in einem bestimmten Fall egal ist (das heißt, du wirst den Wert _nicht verwenden_), kannst du einen Unterstrich (`'_'`) verwenden, um das auszudrücken:

```fsharp
let describe list =
    match list with
    | [] -> "Empty list"
    | [x] -> "List with one item"
    | [_; y] -> "List with two items (first item ignored)"
    | _ -> "List with many items (all items ignored)"

describe []        // => "Empty list"
describe [1]       // => "List with one item"
describe [5; 7]     // => "List with two items (first item ignored)"
describe [5; 7; 9] // => "List with many items (all items ignored)"
```

Der einzelne `'_'` sollte beim Musterabgleich immer _zuletzt_ kommen. Jeder Wert, der zu keinem der anderen Fälle passt, wird von diesem Fall behandelt.
