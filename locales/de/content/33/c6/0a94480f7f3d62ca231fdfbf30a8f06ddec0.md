# Variable in const umwandeln

Ziehe in Betracht, die Variable `%{name}` in ein `const` umzuwandeln, da sich ihr Wert nie ändern soll. Normalerweise werden `const`-Werte auf Klassenebene definiert, weil sie häufig in mehreren Methoden verwendet werden. In diesem Fall kann der `const`-Wert innerhalb der Methode selbst definiert werden, was bedeutet, dass andere Methoden seinen Wert nicht verwenden können.
