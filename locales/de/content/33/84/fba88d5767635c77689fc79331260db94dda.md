# Anleitung

Es ist das Saisonfinale im örtlichen Verein. Du führst die Rangliste an der Ziellinie: Die Rennfahrer kommen in der Reihenfolge ins Ziel, die Bahnen brauchen Beschriftungen, und das offizielle Protokoll muss vor dem nächsten Lauf ergänzt werden.

Die Namen der Rennfahrer kommen als Array an, in der Reihenfolge des Zieleinlaufs: Der Name an Index 0 ist der Sieger, der an Index 1 der Zweitplatzierte und so weiter.

## 1. Startnummern zuweisen

Definiere `assign-bibs` so, dass es ein Array mit Rennfahrernamen entgegennimmt und ein Array aus Paaren der Form `{ position name }` zurückgibt, wobei die Position zuerst steht.

```factor
{ "Bolt" "Comet" "Spirit" } assign-bibs .
! => { { 0 "Bolt" } { 1 "Comet" } { 2 "Spirit" } }
```

## 2. Bahnbeschriftungen

Definiere `lane-labels` so, dass es ein Array mit Rennfahrernamen entgegennimmt und Strings wie `"Lane 0: Bolt"` zurückgibt.

```factor
{ "Bolt" "Comet" } lane-labels .
! => { "Lane 0: Bolt" "Lane 1: Comet" }
```

## 3. Die Rennfahrer taggen

Definiere `tag-racers` so, dass es ein Array mit Rennfahrernamen *und* einen Tag-String entgegennimmt und Beschriftungen der Form `"<tag>/<index>: <name>"` zurückgibt. Derselbe Tag steckt in jeder Beschriftung.

```factor
{ "Bolt" "Comet" } "Green" tag-racers .
! => { "Green/0: Bolt" "Green/1: Comet" }
```

## 4. Die Zieleinläufe erfassen

Definiere `record-finishes` so, dass es ein Array mit Rennfahrernamen und ein Protokoll (einen Vector) entgegennimmt. Hänge für jeden Rennfahrer einen String der Form `"<index>: <name>"` direkt an das Protokoll an. Gibt nichts zurück.

```factor
V{ } clone   ! a fresh empty ledger
{ "Bolt" "Comet" } over record-finishes
.
! => V{ "0: Bolt" "1: Comet" }
```

## 5. Rundenglocken

Definiere `lap-bells` so, dass es eine Zahl `laps` entgegennimmt und einen String zurückgibt, der `laps`-mal aus `"ding "` besteht.

```factor
0 lap-bells .   ! => ""
3 lap-bells .   ! => "ding ding ding "
```
