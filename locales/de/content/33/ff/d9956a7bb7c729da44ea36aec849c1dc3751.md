# Tests

Um eine Übung herunterzuladen, zum Beispiel `hello-world`, öffne ein Terminal und führe Folgendes aus:

```bash
exercism download --track roc --exercise hello-world
```

Wechsle dann in das Verzeichnis der Übung und bearbeite den Code, um die Übung zu lösen. Zum Beispiel:

```bash
cd {your Exercism folder}/roc/hello-world
edit HelloWorld.roc
```

Jede Übung enthält eine Testsuite. Du kannst die Tests mit dem Befehl `roc test` ausführen, zum Beispiel:

```
roc test hello-world-test.roc
```

Wenn du die Übung gelöst hast, solltest du 0 fehlgeschlagene Tests sehen, zum Beispiel:

```
All (5) tests passed in 123.4 ms.
```

Wenn dein Code jedoch Fehler enthält, sehen sie so aus:

```
── EXPECT FAILED in hello-world-test.roc ───────────────────────────────────────

This expectation failed:

6│  expect hello == "Hello, World!"
    ^^^^^^^^^^^^^^^^^^^^^^^^^^^^^^^


1 failed and 0 passed in 123.4 ms.
```

Das sollte dir helfen, deinen Code zu korrigieren. Sobald dein Code funktioniert, kannst du ihn mit dem Befehl `exercism submit` einreichen (weitere Details findest du in `HELP.md` im Verzeichnis der Übung).
