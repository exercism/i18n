# Anleitung

In dieser Übung schreibst du Code, um eine Liste der Programmiersprachen zu verwalten, die du auf Exercism lernen möchtest.

Du hast neun Aufgaben, bei denen es jeweils um Listen geht.

## 1. Erstelle eine neue Liste

Um den Überblick über die Sprachen zu behalten, die du lernen möchtest, musst du eine neue Liste erstellen.

Implementiere die statische Methode `Languages.NewList()`, die eine neue, leere Liste zurückgibt.

```csharp
Languages.NewList()
// => empty list
```

## 2. Definiere eine vorhandene Liste

Derzeit hast du einen Zettel, auf dem die Sprachen stehen, die du lernen möchtest: C#, Clojure und Elm.

Bitte implementiere die statische Methode `Languages.GetExistingLanguages()`, um die Liste zurückzugeben.

```csharp
Languages.GetExistingLanguages();
// => {"C#", "Clojure", "Elm"}
```

## 3. Füge eine neue Sprache zu einer Liste hinzu

Wenn du Exercism erkundest und weitere interessante Sprachen findest, möchtest du sie deiner Liste hinzufügen.

Implementiere die statische Funktion `Languages.AddLanguage()`, um eine neue Sprache am Ende deiner Liste hinzuzufügen.

```csharp
Languages.AddLanguage(Languages.GetExistingLanguages(), "VBA");
// => {"C#", "Clojure", "Elm", "VBA"}
```

## 4. Zähle die Sprachen in der Liste

Die Sprachen einzeln zu zählen, ist umständlich.

Implementiere die statische Methode `Languages.CountLanguages()`, um die Anzahl der Sprachen in deiner Liste zu zählen.

```csharp
Languages.CountLanguages(Languages.GetExistingLanguages())
// => 3
```

## 5. Prüfe, ob eine Sprache in der Liste ist

Implementiere die statische Methode `Languages.HasLanguage()`, um zu prüfen, ob eine Sprache vorhanden ist.

```csharp
Languages.HasLanguage(Languages.GetExistingLanguages(), "Elm")
// => true
```

## 6. Kehre die Liste um

Irgendwann stellst du fest, dass deine Liste tatsächlich rückwärts sortiert ist!

Implementiere die statische Methode `Languages.ReverseList()`, um deine Liste umzukehren.

```csharp
Languages.ReverseList(Languages.GetExistingLanguages())
// => {"Elm", "Clojure", "C#"}
```

## 7. Prüfe, ob eine Liste spannend ist

Obwohl du alle Sprachen liebst, hat C# einen besonderen Platz in deinem Herzen. Deshalb bist du von einer Liste von Sprachen wirklich begeistert, wenn eine der folgenden Bedingungen zutrifft:

- Das erste Element der Liste ist C#.
- Das zweite Element der Liste ist C# und die Liste enthält entweder zwei oder drei Sprachen.

Implementiere die statische Methode `Languages.IsExciting()`, um zu prüfen, ob eine Liste von Sprachen spannend ist:

```csharp
Languages.IsExciting(Languages.GetExistingLanguages())
// => true
```

## 8.Entferne eine Sprache

Bitte implementiere die statische Methode `Languages.RemoveLanguage()`, um eine bestimmte Sprache aus der Liste zu entfernen.

```csharp
Languages.RemoveLanguage(Languages.GetExistingLanguages(), "Clojure")
// => { "C#", "Elm" }
```

## 9. Prüfe, ob alle Sprachen in der Liste verschieden sind

Bitte implementiere die statische Methode `Languages.IsUnique()`, um zu prüfen, ob eine der Sprachen in der Liste mehrfach vorkommt.

Die Liste der Sprachen (d. h. der Parameter) ist garantiert nicht leer, wenn diese Methode aufgerufen wird und es spielt keine Rolle, ob die Liste verändert wird.

```csharp
Languages.IsUnique(Languages.GetExistingLanguages())
// => true
```
