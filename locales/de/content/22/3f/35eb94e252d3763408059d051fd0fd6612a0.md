# Überblick

Die eingebauten Zahlentypen in C++ lassen sich in Ganzzahlen und Gleitkommazahlen unterteilen.
Ganzzahlen sind ganze Zahlen wie `0`, `691` oder `-2`.
Gleitkommazahlen sind Zahlen mit einem Dezimalpunkt wie `6.02214076`, `0.1` oder `-1.616`.

## Ganzzahlen

Das folgende Beispiel zeigt die Deklaration und Initialisierung von vier verschiedenen Variablen

```cpp
int m_morales{9241};              // base 10: 0-9
int a_apaec{0x24CD};              // base 16: 0-9 and A-F
int m_gargan{0b10010000011001};   // base  2: 0-1
int b_reilly{022031};             // base  8: 0-7
                                  // Leading with a 0 not the letter o.
```

Wenn du einer `int`-Variable einen Wert zuweist, kannst du das direkt mit einem Literal tun.
Ein Literal ist eine fest im Code stehende Zahl wie `9241`.
Für die verschiedenen Basen der Darstellung gibt es unterschiedliche Ganzzahl-Literale.
Dezimale Ganzzahl-Literale sind die häufigsten und verwenden die Ziffern `0` bis `9`.
Mit einem speziellen Präfix wie `0x` kannst du auch andere Basen verwenden.
Das obige Beispiel zeigt die Zahl `9421` in ihren vier Darstellungen und Präfixen.
Alle Variablen werden mit demselben Wert initialisiert.

Für weitere Details zu den verschiedenen Darstellungssystemen wirf einen Blick auf [ein kleines Tutorial][cpp_numerical_bases].

Du kannst einen Apostroph verwenden, um Ziffern zur besseren Lesbarkeit zu trennen.
`9'241` ist dasselbe wie `0b0100'100'0001'1001` oder `92'4'1`.

## Gleitkommazahlen

Die Gleitkomma-Literale gibt es in zwei Varianten.
Zusätzlich zur intuitiven Schreibweise `0.0024` kannst du ihre wissenschaftliche Notation `2.4e-3` verwenden.
Der gebräuchlichste Gleitkommatyp ist `double`.

## Arithmetik

C++ unterstützt `+`, `-`, `*`, `/`, `(` und `)` sowie `%`, um Ausdrücke zu bilden.
Das Ergebnis der Operation zwischen zwei Ganzzahlen ist ebenfalls eine Ganzzahl.
`5 / 2` ergibt `2`.
Wenn einer der beteiligten Typen ein Gleitkommatyp ist, ist das Ergebnis ebenfalls eine Gleitkommazahl.
`5.0 / 2` und `5 / 2.0` ergeben `2.5`.
`%` ist der Restoperator und liefert den Rest einer Ganzzahldivision: `5%3` ist `2`.

## Zuweisungsoperator

Der Zuweisungsoperator weist einer Variablen ein Literal zu.
Er funktioniert immer von rechts nach links und niemals umgekehrt.

```cpp
int length = 5;
int width = 2;
length = width;
```

Hier wird der Ganzzahlwert `5` der Variablen `length` zugewiesen.
Dann wird der Ganzzahlwert `2` der Variablen `width` zugewiesen.
Schließlich wird der Wert von `width` in die Variable `length` kopiert und der frühere Wert `5` geht verloren.
Beachte außerdem, dass wir den Wert von `width` nur im Moment der Zuweisung an `length` übergeben.
Wenn sich der Wert von `width` später ändert, wirkt sich das daher nicht auf den Wert aus, den `length` annimmt.

Der Zuweisungsoperator lässt sich mit den anderen Operatoren (Arithmetik und Bitoperationen) kombinieren, bekannt als `compound assignment`-Operatoren `+=`, `-=`, `*=`, `/=`, `%=`.
Diese Operatoren ändern den aktuellen Wert einer Variablen, indem sie eine Operation darauf ausführen.

```cpp
// we start with 0 people
int people{};
// we need 0 eggs
int eggs{};
// two people joined:
people += 2;
// people is now 2
// let's add 3 eggs per person
eggs += 3 * people;
// eggs is now 6
```

Die Variablen `people` und `eggs` werden mit `0` initialisiert.
Dann addieren wir den Ganzzahlwert `2` zum vorhandenen Wert `0` der Variablen `people` und weisen das Ergebnis wieder `people` zu.
`people` ist jetzt `2`.
Später addieren wir `3` Eier für jede Person, was insgesamt `6` Eier ergibt.
Nun addieren wir diese `6` zum vorhandenen Wert `0` der Variablen `eggs` und weisen das Ergebnis wieder `eggs` zu.
`eggs` ist jetzt `6`.
Die äquivalenten Ausdrücke wären `people = people + 2` und `eggs = eggs + (3 * people)`.

## Casting

Casting ist die Umwandlung von einem Typ in einen anderen.
Wenn ein `double` benötigt wird, kann ein `int` an seiner Stelle verwendet werden.
Das Beispiel `5.0 / 2` von oben wird durch eine implizite Umwandlung von `2` zu `2.0` behandelt.
Ein `double`, der in einen `int` umgewandelt wird, kann Informationen verlieren.
Es ist gute Praxis, diese Umwandlungen in einen anderen Typ T explizit über `static_cast<T>` durchzuführen.
Der alte Cast im C-Stil über `(T)` wird im modernen C++ nicht empfohlen, sollte aber trotzdem bekannt sein.

```cpp
double pi{3.14};
int about_2_times_pi_cpp{static_cast<int>(pi) * 2};
// Old C-style cast:
int about_2_times_pi_c{(int)pi * 2};
```

## Präzision und Repräsentation

Zahlen in C++ können nicht beliebig groß werden.
`int` wird zum Beispiel durch 32 Bit dargestellt.
Das reicht für eine Menge von `2^32` Zahlen, also ungefähr 4 Milliarden.
Einschließlich `0` legt das die größten und kleinsten `int`-Zahlen als `-2^31` und `2^31 - 1` fest.

Gleitkommazahlen werden normalerweise mit einer Genauigkeit von 15 Dezimalstellen implementiert, ihre Darstellung variiert jedoch je nach Hostsystem.
