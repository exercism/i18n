# Tests

Um den Test-Runner zu verwenden, musst du [Godot korrekt installiert][installation] haben.

## Tests ausführen

Mit dem [Test-Runner][test runner] lädst du Lösungen und testest sie.
Wenn du eine Übung lokal herunterlädst, ist eine Kopie des Test-Runners enthalten, zusammen mit einem Shell-Skript, das ihn aufruft.

Um die Übung auszuführen, führst du einfach das Skript `run_tests` im Verzeichnis der Übung mit `bash` aus.

Zum Beispiel:

```bash
cd "$(exercism workspace)/gdscript/hello-world"
bash run_tests
```

[installation]: https://exercism.org/docs/tracks/gdscript/installation
[test runner]: https://raw.githubusercontent.com/exercism/gdscript-test-runner/refs/heads/main/bin/test_runner.gd
