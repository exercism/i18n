# Überblick

Eine Liste in Gleam ist eine unveränderliche Sammlung von null oder mehr Werten. Alle Werte in einer Liste müssen denselben Typ haben. Da Listen unveränderlich sind, kann sich ihr Wert nach der Erstellung nie mehr ändern. Alle Funktionen und Operatoren, die eine Liste scheinbar verändern (etwa ein Element hinzufügen), geben tatsächlich eine neue Liste zurück.

So definierst du eine Liste:

```gleam
let empty = []
let singleValue = [5]
let threeValues = ["a", "b", "c"]
```

Am gebräuchlichsten fügst du ein Element mit der Spread-Syntax am Anfang der Liste hinzu:

```gleam
let two_to_four = [2, 3, 4]
let one_to_four = [1, ..two_to_four]
// -> [1, 2, 3, 4]
```

Das Modul [`gleam/list`](https://hexdocs.pm/gleam_stdlib/gleam/list.html) in der Gleam-Standardbibliothek enthält viele nützliche Funktionen für die Arbeit mit Listen. Dieses Modul wird im Gleam-Code sehr häufig verwendet, daher lohnt es sich, es gut zu kennen.

Mit Listenmustern kannst du in case-Ausdrücken Listen abgleichen und die enthaltenen Werte an Variablen binden:

```gleam
pub fn describe(list: List(String)) -> String {
  case list {
    [] -> "Empty list"
    [x] -> "List with one item: " <> x
    [x, y] -> "List with two items: " <> x <> " and " <> y
    _ -> "List with three or more items"
  }
}
```

Neben Listen mit exakter Länge kannst du mit der Spread-Syntax auch Listen abgleichen, die mindestens eine bestimmte Länge haben:

```gleam
pub fn describe(list: List(String)) -> String {
  case list {
    [_, _, ..] -> "List with at least two items"
    [_] -> "List with one item"
    [] -> "Empty list"
  }
}
```

Mit der Spread-Syntax kannst du außerdem den Rest der Liste an eine Variable binden:

```gleam
pub fn remove_first_item(list: List(String)) -> List(String) {
  case list {
    // Return the list without the first item
    [_, ..rest] -> rest

    // There's no first item to remove, return an empty list
    _ -> []
  }
}
```

Case-Ausdrücke sollten für jeden möglichen Wert des abgeglichenen Typs ein Muster haben, daher wird oft ein abschließendes Verwerfungsmuster (`_`) verwendet, um alle übrigen Werte abzufangen.
