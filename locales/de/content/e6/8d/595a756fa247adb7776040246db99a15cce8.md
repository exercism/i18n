# Nummernausgabeautomat

## Geschichte

Du schreibst ein eingebettetes System für einen Nummernausgabeautomaten. Es ist ein sehr einfaches Modell. Er kann fortlaufende Nummern ausgeben und melden, welche Nummer zuletzt ausgegeben wurde.

## Aufgaben

- Starte den Automaten.
- Lass den Automaten seinen Zustand melden (die zuletzt ausgegebene Nummer).
- Lass den Automaten eine Nummer ausgeben.
- Lass den Automaten stoppen, wenn er dazu aufgefordert wird.
- Stelle sicher, dass der Automat unerwartete Nachrichten verarbeiten kann.
