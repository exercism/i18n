# Über

CoffeeScript ist eine Sprache, die nach JavaScript transpiliert und für dynamische Websites verwendet wird (sowohl im Webbrowser als auch auf dem Server).
Der Transpiler wird verwendet, um CoffeeScript-Code vor der Ausführung in JavaScript umzuwandeln, um die Kompatibilität und die gleiche Performance von JavaScript beizubehalten und gleichzeitig viele neue Funktionen zu bieten!

CoffeeScript wurde entwickelt, um eine vereinfachte Möglichkeit zum Schreiben von JavaScript zu bieten, basierend auf einer Mischung aus den Sprachen Ruby und Python.
Ein Unterschied ist die Verwendung von Einrückungen und Pfeilen, um den ausführlichen Funktionscode von JavaScript zu ersetzen, und es führt nützliche Funktionen aus funktionalen Sprachen ein, einschließlich Pattern Matching.

CoffeeScript ist eine von vielen neuen Sprachen, die nach JavaScript transpilieren, darunter TypeScript und Flow. Die Community wächst, und diese Art von Sprachen ist sehr beliebt.
