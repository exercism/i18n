# Arrays

In Cairo ist ein Array eine Datenstruktur, mit der du eine Sammlung von Elementen desselben Typs speichern kannst.
Arrays in Cairo lassen sich nur eingeschränkt verändern.
Du kannst Elemente nur am Ende eines Arrays anhängen und nur am Anfang entfernen.
Arrays sind tatsächlich Warteschlangen, deren Werte nicht verändert werden können.

## Arrays erstellen

Arrays werden in erster Linie über das Trait `ArrayTrait` erstellt. Es gibt die folgenden vier Möglichkeiten, ein Array mit den Elementen `[1, 2]` zu erstellen:

```rust
// 1. Passing the type to the `ArrayTrait`
let mut arr_type_in_trait = ArrayTrait::<felt252>::new();
arr_type_in_trait.append(1);
arr_type_in_trait.append(2);

// 2. Setting the type on the variable itself
let mut arr_explicit_type: Array<felt252> = ArrayTrait::new();
arr_explicit_type.append(1);
arr_explicit_type.append(2);

// 3. Using the `array!` macro
let mut arr_from_macro: Array<felt252> = array![1, 2]; // assign values in-line

// 4. Allowing the compiler to infer the type from the type of values being assigned to it
let mut arr_implicit_type = ArrayTrait::new(); // compiler "knows" this is a `felt252` array
arr_implicit_type.append(1);
arr_implicit_type.append(2);
```

> Jeder Aufruf von `append()` hängt eine neue Zahl an das Ende des Arrays an.

## Elemente aus einem Array entfernen

In Cairo kannst du Elemente nur am Anfang eines Arrays entfernen.
Diese Operation übernimmt die Methode `pop_front()`. Sie gibt eine `Option` zurück, die du entpacken kannst: entweder mit dem entfernten Element oder mit `Option::None`, wenn das Array leer ist.

```rust
fn main() {
    let mut a = array![10, 1, 2];
    let first_value = a.pop_front().unwrap(); // `unwrap()` is used to get the value from `Option`
    println!("The first value is {}", first_value); // prints "The first value is 10"
}
```

## Zugriff auf Werte in einem Array

Um auf Array-Elemente zuzugreifen, kannst du die Methoden `get()` oder `at()` verwenden. Beide geben unterschiedliche Typen zurück.
Eine Entsprechung zu `arr.at(index)` ist der Indexoperator `arr[index]`.

### Die Methode get() verwenden

Die Methode `get()` ist wie das Nachschlagen eines Eintrags in einer Liste über seine Nummer.
So funktioniert sie:

- Mit `arr.get(index)` holst du einen Eintrag an einer bestimmten Position (Index) im Array.
- Sie gibt `Option::Some(value)` zurück, wenn der Eintrag am angegebenen Index existiert, und `Option::None`, wenn der Index außerhalb des gültigen Bereichs liegt.

Diese Methode ist ideal, wenn du Fälle behandeln willst, in denen der Index ungültig sein könnte, ohne dass dein Programm abstürzt.

```rust
fn main() {
    let arr: Array<u32> = array![1, 2, 3];

    let index = 1;

    match arr.get(index) {
        Option::Some(value) => { println!("Element at index {}: {}", index, value.unbox()); },
        Option::None => { println!("Index {} is out of bounds!", index); }
    }
}
```

### Die Methode at() verwenden

Die Methode `at()` liefert dir direkt eine Momentaufnahme des Elements an einem bestimmten Index. Dabei entpackt die Operation `unbox()` den gespeicherten Wert aus der Box.
Eine Kurzform für diese Methode ist der Indexoperator `arr[index]`.
Wenn du auf einen Index zugreifst, der nicht existiert (außerhalb des gültigen Bereichs), stürzt das Programm mit einem Fehler ab.

```rust
fn main() {
    let a: Array<u32> = array![5, 8];

    println!("First: {}", *a.at(0)); // prints "First: 5"
    println!("Second: {}", a[1]); // prints "Second: 8"
    println!("Third: {}", a[2]); // panics with 'Index out of bounds'
}
```

## Methoden zur Größe

Um die Anzahl der Elemente in einem Array zu ermitteln, verwendest du die Methode `len()`.
Der Rückgabewert hat den Typ `usize`.

Wenn du prüfen willst, ob ein Array leer ist, kannst du die Methode `is_empty()` verwenden. Sie gibt `true` zurück, wenn das Array leer ist, andernfalls `false`.

## `Span`

`Span` ist ein Struct, das eine Momentaufnahme eines `Array` darstellt.
Es ist darauf ausgelegt, einen sicheren und kontrollierten Zugriff auf die Elemente eines Arrays zu ermöglichen, ohne das ursprüngliche Array zu verändern.
`Span` ist besonders nützlich, um die Datenintegrität zu wahren und Probleme beim Borrowing zu vermeiden, wenn du Arrays zwischen Funktionen übergibst oder nur lesende Operationen ausführst.

> Alle Methoden, die `Array` bereitstellt, kannst du auch mit `Span` verwenden, außer der Methode `append()`.

Um einen `Span` aus einem `Array` zu erstellen, rufst du die Methode `span()` auf:

```rust
let my_array: Array<u32> = array![1, 2, 3];
let my_span: Span<u32> = my_array.span();
```

## Der Typ `Array` mit fester Größe

Die Werte eines Arrays mit fester Größe schreibst du als kommagetrennte Liste in eckige Klammern.
Der Typ des Arrays wird ebenfalls in eckigen Klammern geschrieben: Typ jedes Elements, ein Semikolon und dann die Anzahl der Elemente im Array.

```rust
let arr: [u64; 5] = [1, 2, 3, 4, 5];
```

> Hinweis: Nur Arrays mit fester Größe können als Konstanten verwendet werden

Auf Elemente in einem Array mit fester Größe kannst du entweder durch Destrukturieren des Arrays oder durch Umwandeln in einen `Span` zugreifen, der Indexierung unterstützt.

```rust
fn main() {
    let arr = [1, 2, 3, 4, 5]; // implicit `felt252` array type

    // Accessing elements of a fixed-size array by deconstruction
    let [a, b, c, _, _] = arr;
    println!("c: {}", c); // c: 3
    
    // Accessing elements of a fixed-size array by index
    let my_span = arr.span();
    println!("my_span[2]: {}", my_span[2]); // my_span[2]: 3
}
```
