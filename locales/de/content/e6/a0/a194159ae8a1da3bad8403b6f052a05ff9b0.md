# Einführung

Listen in C# sind Sammlungen von primitiven Werten oder Instanzen von Structs oder Klassen. In der Basisklassenbibliothek sind sie als `List<T>` implementiert, wobei `T` der Typ des Elements in der Liste ist. Die API stellt eine Vielzahl von Methoden zum Erstellen und Bearbeiten von Listen bereit.

Elemente können zu Listen hinzugefügt und daraus entfernt werden. Sie wachsen und schrumpfen nach Bedarf.

```csharp
var listOfStrings = new List<string>();
```
