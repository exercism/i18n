# Über

Ein [Tupel][tuple] ist eine _unveränderliche_ Sammlung von Elementen in einer _Sequenz_.


Wie die meisten Sammlungen (_siehe die eingebauten [`list`][list], [`dict`][dict] und [`set`][set]_) können `tuples` jeden (oder mehrere) Datentyp(en) enthalten, einschließlich anderer `tuples`.
Die Elemente eines Tupels kannst du mit dem Konstrukt `for item in <tuple>` durchlaufen.
Wenn sowohl Index als auch Wert eines Elements benötigt werden, kannst du `for index, item in enumerate(<tuple>)` verwenden.


Wie bei jeder [Sequenz][sequence] kannst du auf Elemente in `tuples` über die _Klammernotation_ zugreifen, indem du von links eine Zahl mit `0-based index` oder von rechts eine Zahl mit `-1-based index` verwendest.
Tupel können vollständig oder teilweise über die _Slice-Notation_ oder `<tuple>.copy()` kopiert werden und unterstützen alle [allgemeinen Sequenzoperationen][common sequence operations].
Da sie _unveränderlich_ sind, unterstützen `tuples` **keine** [Operationen auf veränderlichen Sequenzen][mutable sequence operations].


Tupel belegen im Vergleich zu anderen Sammlungstypen sehr wenig Speicher und haben bei Zugriff über einen Index eine konstante Zugriffszeit (_O(1)_).
Sie können jedoch nicht in ihrer Größe geändert, sortiert oder nach der Erstellung verändert werden und sind daher weniger flexibel, wenn Daten häufig geändert oder aktualisiert werden müssen.
Wenn häufige Aktualisierungen oder Erweiterungen erforderlich sind, ist eine `list`, ein `collections.deque` oder ein `array.array` möglicherweise die bessere Datenstruktur.

<br>

## Tupel erstellen

Tupel können auf verschiedene Arten erstellt werden, entweder mit dem Konstruktor der Klasse `tuple` oder mit der Deklaration `(<element_1>, <element_2>)` (_`tuple`-Literal_).

### Den `tuple()`-Konstruktor leer oder mit einem _Iterable_ verwenden:

```python
>>> no_elements = tuple()
()

# The constructor *requires* an iterable, so single elements must be passed in a list or another tuple.
>>> one_element = tuple([16])
(16,)
```

Strings sind iterierbar. Wenn du also einen einzelnen `str` als Argument an den `tuple()`-Konstruktor übergibst, kann das überraschende Ergebnisse liefern:

```python
# String elements (characters) are iterated through and added to the tuple
>>> multiple_elements_string = tuple("Timbuktu")
('T', 'i', 'm', 'b', 'u', 'k', 't', 'u')
```

Bei anderen Iterables werden die Elemente ebenfalls einzeln hinzugefügt:

```python
>>> multiple_elements_list = tuple(["Parrot", "Bird", 334782])
("Parrot", "Bird", 334782)

>>> multiple_elements_set = tuple({2, 3, 5, 7, 11})
(2,3,5,7,11)
```

Ein `dict` wird standardmäßig über seine **Schlüssel** iteriert.
Um sowohl Schlüssel als auch Werte in ein Tupel aus einem Dictionary aufzunehmen, verwende `<dict>.items()`. Das gibt einen Iterator von (`key`, `value`)-`tuples` zurück.

```python
>>> source_data = {"fish": "gold", "monkey": "brown"}

>>> multiple_elements_dict_1 = tuple(source_data)
('fish', 'monkey')

>>> multiple_elements_dict_2 = tuple(source_data.items())
(('fish', 'gold'), ('monkey', 'brown'))
```

#### Ein Tupel als _Literal_ deklarieren:

Da der `tuple()`-Konstruktor nur _Iterables_ (oder nichts) als Argumente akzeptiert, ist es viel einfacher, ein Ein-Element-Tupel über die Literal-Schreibweise zu erstellen.

```python
>>> no_elements = ()
()

>>> one_element = ("Guava",)
("Guava",)
```

Beachte, dass Klammern im Allgemeinen **nicht** erforderlich sind, um ein `tuple`-Literal zu erstellen, sondern nur Kommas.
In den meisten Fällen gilt `(<element_1>, <element_2>)` jedoch als lesbarer.
Klammern sind auch in Fällen erforderlich, in denen es zu Mehrdeutigkeiten kommen kann, etwa bei einem leeren Tupel oder einem Tupel mit einem Element oder wenn eine Funktion ein Tupel als Argument erwartet.

```python
>>> elements_separated_with_commas = "Parrot", "Bird", 334782
("Parrot", "Bird", 334782)

>>> elements_with_commas_and_parentheses = ("Triangle", 60, 60, 60)
("Triangle", 60, 60, 60)
```

Andere Datenstrukturen können als Elemente eines `tuple` aufgenommen werden, auch andere `tuples`.

```python
>>> nested_data_structures = ({"fish": "gold", "monkey": "brown", "parrot" : "grey"}, ("fish", "mammal", "bird"))
({"fish": "gold", "monkey": "brown", "parrot" : "grey"}, ("fish", "mammal", "bird"))

>>> nested_data_structures_1 = (["fish", "gold", "monkey", "brown", "parrot", "grey"], ("fish", "mammal", "bird"))
(["fish", "gold", "monkey", "brown", "parrot", "grey"], ("fish", "mammal", "bird"))
```

Tupel können mit dem Plus-Operator `+` verkettet werden. Dabei wird jedes `tuple` entpackt und ein neues, kombiniertes `tuple` erstellt.

```python
>>> new_via_concatenate = ("George", 5) + ("cat", "Tabby")
("George", 5, "cat", "Tabby")

#likewise, using the multiplication operator * is the equivalent of using + n times
>>> first_group = ("cat", "dog", "elephant")

>>> multiplied_group = first_group * 3
('cat', 'dog', 'elephant', 'cat', 'dog', 'elephant', 'cat', 'dog', 'elephant')
```

## Auf Daten zugreifen

Auf Elemente in Tupeln (_wie bei den anderen Sequenztypen `str` und `list`_) kannst du über die _Klammernotation_ zugreifen.
Indizes können von **`left`** → **`right`** (_bei null beginnend_) oder von **`right`** → **`left`** (_bei -1 beginnend_) laufen.
Tupel können auch vollständig oder teilweise über die _Slice-Notation_ oder mit `<tuple>.copy()` kopiert werden.

```python
>>> student_info = ("Alyssa", "grade 3", "female", 8)

#name is at index 0 or index -4
>>> student_name = student_info[0]
Alyssa

>>> student_name = student_info[-4]
Alyssa

#age is at index 3 or index -1
>>> student_age_1 = student_info[3]
8

>>> student_age_2 = student_info[-1]
8
```

## Über Elemente iterieren

Elemente in Tupeln können in einer Schleife mit der Syntax `for item in <tuple>` _durchlaufen_ werden.
Wenn sowohl Index als auch Wert benötigt werden, kannst du `for index, item in enumerate(<tuple>)` verwenden.

```python
>>> student_info = ("Alyssa", "grade 3", "female", 8)
>>> for item in student_info:
...   print(item)
...
Alyssa
grade 3
female
8

>>> for index, item in enumerate(student_info):
...  print("Index is: " + str(index) + ", value is: " + str(item) + ".")
...
Index is: 0, value is: Alyssa.
Index is: 1, value is: grade 3.
Index is: 2, value is: female.
Index is: 3, value is: 8.
```


## Tupel als homogene Informationen

Tupel werden oft als _Datensätze_ verwendet, die Daten enthalten, die _organisatorisch_ oder _konzeptionell_ homogen sind und als eine einzelne Informationseinheit behandelt werden, auch wenn die einzelnen Elemente _heterogene_ Datentypen haben.

```python
>>> student_info = ("Alyssa", "grade 3", "female", 8)
```

Tupel werden auch verwendet, wenn homogene unveränderliche Datensequenzen für die [`hashability`][hashability], die Speicherung in einem `set` oder die Erstellung von Schlüsseln in einem Dictionary benötigt werden.

Beachte: Obwohl `tuples` in den meisten Fällen _unveränderlich_ sind, können sie _veränderbar werden_, wenn eines ihrer Elemente einen _veränderbaren Typ_ hat, da sie _jede_ Datenstruktur oder jedes Objekt enthalten können.
Wenn du einen veränderbaren Datentyp in einem `tuple` verwendest, wird das umgebende `tuple` **nicht hashbar**.

```python
>>> cmyk_color_map = {
        (.69, .3, .48, .1) : ("Teal 700", (59, 178, 146), 0x3BB292),
        (0, .5, 1, 0) : ("Pantone 151", (247, 127, 1), 0xF77F01),
        (.37, .89, 0, .44) : ("Pantone 267", (89, 16, 142), 0x59108E),
        (0, 1, .46, .45) : ("Pantone 228", (140, 0, 76), 0x8C004C)
    }

>>> unique_rgb_colors = {
        (59, 178, 146),
        (247, 127, 1),
        (89, 16, 142),
        (140, 0, 76),
        (76, 0, 140)
     }

>>> teal_700 = hash((59, 178, 146))

>>> teal_700 = hash(("Pantone 228", [(140, 0, 76), 0x8C004C]))
Traceback (most recent call last):
  File "<stdin>", line 1, in <module>
TypeError: unhashable type: 'list'
```

## Erweiterte Tupel und verwandte Datentypen

Tupel werden oft als _Datensätze_ verwendet, aber auf die darin enthaltenen Daten kann nur über _Position_/_Index_ zugegriffen werden.
Die Klasse [`namedtuple()`][namedtuple] im Modul [`collections`][collections] erweitert die grundlegende Tupel-Funktionalität, sodass du auf Elemente über ihren _Namen_ zugreifen kannst.
Darüber hinaus kannst du eine [`dataclass`][dataclass] anpassen, um eine ähnliche Funktionalität mit benannten Attributen zu erhalten, allerdings mit [Vor- und Nachteilen][dataclass pros and cons].
