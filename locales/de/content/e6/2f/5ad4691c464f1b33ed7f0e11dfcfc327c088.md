# Einführung

## Listen

Eine [`List`][lists] in Elm ist eine unveränderliche Sammlung von null oder mehr Werten desselben Typs.

Listen kannst du so definieren:

```elm
empty = []
singleValue = [ 5 ]
threeValues = [ "a", "b", "c" ]
```

Am häufigsten fügst du einer Liste ein Element mit dem `::`-Operator (cons) hinzu:

```elm
twoToFour = [ 2, 3, 4 ]
oneToFour = 1 :: twoToFour --> [ 1, 2, 3, 4 ]
```

Listen werden mit Funktionen und Operatoren aus dem [`List`-Modul][list-module] bearbeitet oder mit [Pattern Matching][list-destructuring].

```elm
describe : List String -> String
describe list =
    case list of
        [] ->
            "Empty list"

        [ "hello" ] ->
            "Singleton list with: hello"

        x :: xs ->
            "Non-empty list with head: " ++ x

describe []                   --> "Empty list"
describe [ "hello" ]          --> "Singleton list with: hello"
describe [ "hello", "world" ] --> "Non-empty list with head: hello"
```

[list-module]: https://package.elm-lang.org/packages/elm/core/latest/List
