# Anleitung

In dieser Übung implementierst du die Quest-Logik für ein neues RPG-Spiel, das ein Freund von dir entwickelt.

Die Hauptfigur des Spiels ist Annalyn, ein mutiges Mädchen mit einem wilden und treuen Hund. Leider kommt es zur Katastrophe: Ihre beste Freundin wurde entführt, während diese im Wald nach Beeren suchte.

Annalyn wird versuchen, ihre beste Freundin zu finden und zu befreien, wobei sie ihren Hund optional mit auf diese Quest nimmt.

Nachdem sie eine Zeit lang der Spur ihrer besten Freundin gefolgt ist, findet sie das Lager, in dem ihre beste Freundin gefangen gehalten wird. Es stellt sich heraus, dass es zwei Entführer gibt: einen mächtigen Ritter und einen listigen Bogenschützen.

Nachdem Annalyn die Entführer gefunden hat, überlegt sie, welche der folgenden Aktionen sie ausführen kann:

- _Schneller Angriff_: Ein schneller Angriff ist möglich, wenn der Ritter schläft, denn er braucht Zeit, um seine Rüstung anzulegen, sodass er verwundbar ist.
- _Ausspionieren_: Die Gruppe kann ausspioniert werden, wenn mindestens einer von ihnen wach ist. Andernfalls ist Spionieren Zeitverschwendung.
- _Dem Gefangenen ein Signal geben_: Dem Gefangenen kann mit Vogelrufen ein Signal gegeben werden, wenn der Gefangene wach ist und der Bogenschütze schläft, denn Bogenschützen sind darin ausgebildet, mit Vogelrufen zu signalisieren, sodass sie die Nachricht abfangen könnten.
- _Gefangenen befreien_: Annalyn kann versuchen, sich ins Lager zu schleichen, um den Gefangenen zu befreien.
  Das ist riskant und kann nur auf zwei Arten gelingen:
  - Wenn Annalyn ihren Hund dabei hat, kann sie den Gefangenen befreien, wenn der Bogenschütze schläft.
    Der Ritter hat Angst vor dem Hund, und der Bogenschütze wird keine Zeit haben, sich vorzubereiten, bevor Annalyn und der Gefangene entkommen können.
  - Wenn Annalyn ihren Hund nicht dabei hat, müssen sie und der Gefangene sehr leise sein!
    Annalyn kann den Gefangenen befreien, wenn der Gefangene wach ist und sowohl der Ritter als auch der Bogenschütze schlafen. Wenn der Gefangene jedoch schläft, kann er nicht gerettet werden: Der Gefangene würde durch Annalyns plötzliches Auftauchen erschrecken und den Ritter und den Bogenschützen aufwecken.

Du hast vier Aufgaben: die Logik zu implementieren, mit der bestimmt wird, ob die oben genannten Aktionen möglich sind, und zwar abhängig vom Zustand der drei im Wald gefundenen Charaktere und davon, ob Annalyns Hund dabei ist oder nicht.

## 1. Prüfe, ob ein schneller Angriff möglich ist

Implementiere die Methode `can_fast_attack()`, die einen booleschen Wert entgegennimmt, der angibt, ob der Ritter wach ist. Diese Methode gibt `TRUE` zurück, wenn ein schneller Angriff möglich ist, abhängig vom Zustand des Ritters. Andernfalls gibt sie `FALSE` zurück:

```R
knight_is_awake <- TRUE
can_fast_attack(knight_is_awake)
# => FALSE
```

## 2. Prüfe, ob die Gruppe ausspioniert werden kann

Implementiere die Methode `can_spy()`, die drei boolesche Werte entgegennimmt, die angeben, ob der Ritter, der Bogenschütze bzw. der Gefangene wach sind. Die Methode gibt `TRUE` zurück, wenn die Gruppe ausspioniert werden kann, abhängig vom Zustand der drei Charaktere. Andernfalls gibt sie `FALSE` zurück:

```R
knight_is_awake <- FALSE
archer_is_awake <- TRUE
prisoner_is_awake <- FALSE
can_spy(knight_is_awake, archer_is_awake, prisoner_is_awake)
# => TRUE
```

## 3. Prüfe, ob dem Gefangenen ein Signal gegeben werden kann

Implementiere die Methode `can_signal_prisoner()`, die zwei boolesche Werte entgegennimmt, die angeben, ob der Bogenschütze bzw. der Gefangene wach sind. Die Methode gibt `TRUE` zurück, wenn dem Gefangenen ein Signal gegeben werden kann, abhängig vom Zustand der beiden Charaktere. Andernfalls gibt sie `FALSE` zurück:

```R
archer_is_awake <- FALSE
prisoner_is_awake <- TRUE
can_signal_prisoner(archer_is_awake, prisoner_is_awake)
# => TRUE
```

## 4. Prüfe, ob der Gefangene befreit werden kann

Implementiere die Methode `can_free_prisoner()`, die vier boolesche Werte entgegennimmt. Die ersten drei Parameter geben an, ob der Ritter, der Bogenschütze bzw. der Gefangene wach sind. Der letzte Parameter gibt an, ob Annalyns Hund dabei ist. Die Methode gibt `TRUE` zurück, wenn der Gefangene befreit werden kann, abhängig vom Zustand der drei Charaktere und davon, ob Annalyns Hund anwesend ist. Andernfalls gibt sie `FALSE` zurück:

```R
knight_is_awake <- FALSE
archer_is_awake <- TRUE
prisoner_is_awake <- FALSE
pet_dog_is_present <- FALSE
can_free_prisoner(knight_is_awake, archer_is_awake, prisoner_is_awake, pet_dog_is_present)
# => FALSE
```
