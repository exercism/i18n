# Installation

## Quickstart

``` shellsession
$ bash <(curl -s https://raw.githubusercontent.com/borkdude/babashka/master/install)
```

Standardmäßig wird das nach `/usr/local/bin` installiert. Wenn du das ändern möchtest, gib den Namen des Verzeichnisses an:

``` shellsession
$ bash <(curl -s https://raw.githubusercontent.com/borkdude/babashka/master/install) /tmp
```

## Brew

Binärdateien für Linux und macOS gibt es über brew.

Installieren:

    brew install borkdude/brew/babashka

Aktualisieren:

    brew upgrade babashka

## Arch (Linux)

`babashka` ist [verfügbar](https://aur.archlinux.org/packages/babashka-bin/) im [Arch User Repository](https://aur.archlinux.org). Du kannst es mit deinem bevorzugten [AUR](https://aur.archlinux.org)-Helfer installieren, zum Beispiel
[yay](https://github.com/Jguer/yay), [yaourt](https://github.com/archlinuxfr/yaourt), [apacman](https://github.com/oshazard/apacman) und [pacaur](https://github.com/rmarquis/pacaur). Hier ist ein Beispiel mit `yay`:

    yay -S babashka-bin

## Windows

Unter Windows kannst du es mit [scoop](https://scoop.sh/) und dem
[scoop-clojure](https://github.com/littleli/scoop-clojure)-Bucket installieren.

## Download

Du kannst auch eine Binärdatei von
[Github](https://github.com/borkdude/babashka/releases) herunterladen. Für Linux gibt es eine
statische Binärdatei, die auf Alpine verwendet werden kann.

## Docker

Schau dir das Image auf [Docker hub](https://hub.docker.com/r/borkdude/babashka/) an.
