# Einführung

Wenn eine Quotation sich Werte aus ihrer Umgebung *merken* muss, bietet Factor zwei Werkzeuge: `curry`/`compose` aus [`kernel`][kernel] und die fry-Syntax `'[ … ]` aus [`fry`][fry].

`curry` fügt einen Wert an den Anfang einer Quotation ein:

```
curry ( value quot -- newquot )
```

```factor
3 [ + ] curry .          ! => [ 3 + ]
10 3 [ + ] curry call .  ! => 13
```

`compose` fügt zwei Quotationen zusammen:

```factor
[ 1 + ] [ 2 * ] compose .       ! => [ 1 + 2 * ]
5 [ 1 + ] [ 2 * ] compose call . ! => 12
```

Für mehr als ein oder zwei Captures ist fry sauberer. Jeder `_`-Platzhalter wird der Reihe nach mit einem Wert gefüllt, der vom Stack genommen wird:

```factor
2 3 '[ _ _ + + ] .    ! => [ 2 3 + + ]
```

Fry greift auch in verschachtelte Quotationen hinein.

[fry]: https://docs.factorcode.org/content/vocab-fry.html
