# Einführung

[Ranges][range] repräsentieren ein Intervall zwischen zwei Werten.
Häufig verwendest du Ranges mit Typen wie `Int`, `String` und `Character`, um über Sequenzen zu iterieren, Ausschnitte aus Sammlungen zu erstellen oder zu prüfen, ob ein Wert innerhalb der Grenzen liegt.

Swift bietet zwei grundlegende Range-Operatoren:

- **Geschlossener Range-Operator (`...`)**: Enthält sowohl den Start- als auch den Endwert (`1...5` enthält 1, 2, 3, 4 und 5).
- **Halboffener Range-Operator (`..<`)**: Enthält den Startwert, schließt aber den Endwert aus (`1..<5` enthält 1, 2, 3 und 4).

```swift
let closed = 1...5
let halfOpen = 1..<5
```

~~~~exercism/note
Wenn du eine Methode direkt auf einem Range-Literal aufrufst, setze den Range-Ausdruck in runde Klammern, damit der Compiler zuerst den Range auswertet:

```swift
(1...5).contains(3) // Returns true
// 1...5.contains(3) // Error: value of type 'Int' has no member 'contains'
```
~~~~

## Einen Range in ein Array umwandeln

Du kannst einen Range von Zahlen mit dem Initialisierer `Array(_:)` in ein `Array` umwandeln:

```swift
let range = 1...5
let numbers = Array(range)
// numbers is [1, 2, 3, 4, 5]
```

## Ausschnitte eines Arrays mit Ranges erstellen

Du kannst mit Ranges Ausschnitte aus einem Array erstellen:

```swift
let array = [10, 20, 30, 40, 50]
let slice = array[1...3]
// slice contains [20, 30, 40]
```

## Eigenschaften und Methoden von Ranges

Übliche Operationen mit Ranges sind:

| Member                  | Beschreibung                                                | Beispiel                              |
| ----------------------- | ---------------------------------------------------------- | ------------------------------------- |
| `count`                 | Gibt die Anzahl der Elemente im Range zurück                | `(1...5).count` gibt `5` zurück       |
| [`contains(_:)`][contains] | Gibt `true` zurück, wenn der Range den angegebenen Wert enthält | `(1...5).contains(3)` gibt `true` zurück |

## Einseitige Ranges

Swift unterstützt außerdem einseitige (partielle) Ranges, bei denen du entweder den Start- oder den Endwert weglässt:

- `array[2...]`: Vom Index 2 bis zum Ende der Sammlung.
- `array[...2]`: Vom Anfang der Sammlung bis einschließlich Index 2.
- `array[..<2]`: Vom Anfang der Sammlung bis ausschließlich Index 2.

## String- und Character-Ranges

Ranges können auch zwischen Zeichen oder Strings erstellt werden, die `Comparable` erfüllen:

```swift
let letters = "a"..."z"
print(letters.contains("m")) // Prints true
print(letters.contains("A")) // Prints false
```
