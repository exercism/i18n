# Anleitung

Die Vorsprechen für das Schultheaterstück sind vorbei und der Regisseur muss die Entscheidungen schriftlich festhalten.

Alle vier Aufgaben gehören in die Klasse `CASTING_CALL`.

## 1. Die Entscheidung

Jeder Darsteller wird mit bis zu zehn Punkten bewertet. Wer acht oder mehr erreicht, bekommt eine Rolle; wer fünf bis sieben erreicht, wird zurückgerufen; und wer weniger als fünf erreicht, bekommt ein Dankeschön.

```sather
CASTING_CALL::audition_outcome(8)
-- => "Cast"
CASTING_CALL::audition_outcome(6)
-- => "Recalled"
CASTING_CALL::audition_outcome(2)
-- => "Thank you"
```

## 2. Welche Gruppe?

Darsteller unter 13 sind Juniors. Von 13 bis 15 sind sie Middles. Ab 16 sind sie Seniors.

```sather
CASTING_CALL::age_group(13)
-- => "Middles"
```

## 3. Wann du wiederkommen sollst

Juniors werden um vier Uhr zurückgerufen, Middles um fünf und alle anderen um sechs.

```sather
CASTING_CALL::callback_time("Middles")
-- => "5pm"
```

Das Argument ist der Name einer Gruppe, genau so geschrieben, wie Aufgabe 2 ihn schreibt.

## 4. Was du auf das Blatt schreibst

Wer acht oder mehr Punkte erreicht und singen kann, ist ein `"Lead"`. Acht oder mehr ohne Gesang ist `"Speaking part"`. Alle anderen sind `"Chorus"`.

```sather
CASTING_CALL::casting_note(9, true)
-- => "Lead"
CASTING_CALL::casting_note(9, false)
-- => "Speaking part"
CASTING_CALL::casting_note(4, true)
-- => "Chorus"
```
