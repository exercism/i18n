# Hinweise

## 1. Die Verwendung von `preparation-time-in-minutes` erleichtern

- Ein „Rest-Parameter“ sammelt alle Argumente, die nicht von anderen Parametern verbraucht werden, in einer Liste.
- Ein „Rest-Parameter“ wird in der Lambda-Liste mit dem Lambda-Listen-Schlüsselwort `&rest` gekennzeichnet.
- Mit der Funktion `length` kannst du die Anzahl der Elemente in einer Liste ermitteln.

## 2. Die erwartete Backzeit ändern können

- Ein optionaler Parameter kann angegeben werden oder auch nicht.
- Ein optionaler Parameter kann einen Standardwert haben.
- Optionale Parameter werden durch das Lambda-Listen-Schlüsselwort `&optional` gekennzeichnet.

## 3. Lilly erinnert sich an einen weiteren bevorzugten Kochstil

- Ein „supplied-p-Parameter“ kann zusammen mit dem optionalen Parameter angegeben werden, um festzustellen, ob der Aufrufer den Parameter übergeben hat.

## 4. Die Reste aufteilen

- Schlüsselwortparameter haben Namen und sind optional.
- Schlüsselwortparameter werden mit dem Lambda-Listen-Schlüsselwort `&key` gekennzeichnet.

## 5. Annahmen treffen

- Schlüsselwortparameter können Standardwerte haben.

## 6. Standardmenge an Resten

- Schlüsselwortparameter können wie optionale Parameter einen „supplied-p-Parameter“ haben.
