# Ergänzende Anweisungen

## Operatoren für rationale Zahlen

Die arithmetischen Funktionen unterstützen reguläre Funktionsaufrufe, statischen Dispatch (d. h. die Syntax von Methodenaufrufen) und Operatoren:

| Funktionsaufruf | Methodenaufruf | Operator |
| --- | --- | --- |
| `plus(r1, r2)` | `r1.plus(r2)` | `r1 + r2` |
| `minus(r1, r2)` | `r1.minus(r2)` | `r1 - r2` |
| `times(r1, r2)` | `r1.times(r2)` | `r1 * r2` |
| `div_by(r1, r2)` | `r1.div_by(r2)` | `r1 / r2` |

Implementiere `reduce`, um eine rationale Zahl vollständig zu kürzen, zum Beispiel von `6 / 8` zu `3 / 4`.
