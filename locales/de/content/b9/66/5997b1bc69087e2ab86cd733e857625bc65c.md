# Tests

## Setup

Folge der [Anleitung zur Einrichtung von WebAssembly][docs-exercism-wasm], um die nötigen Abhängigkeiten zu installieren.

## Requirements

Installiere die Abhängigkeiten der Übung:

```shell
# Using npm
npm install

# Alternatively using yarn
yarn
```

## Making the test suite pass

Alle Übungen enthalten eine Testsuite, mit der du deine Lösung überprüfen kannst, bevor du sie einreichst.
Du kannst diese Tests ausführen, indem du eine Kommandozeile im Verzeichnis der Übung öffnest und dann Folgendes ausführst:

```bash
# Using npm
npm test

# Alternatively using yarn
yarn test
```

In manchen Testsuiten sind alle Tests außer dem ersten übersprungen.

Sobald du einen Test zum Laufen bringst, kannst du den nächsten aktivieren, indem du `xtest` durch `test` ersetzt.

## Writing custom tests

Wenn du zusätzliche, eigene Tests schreiben möchtest, erstelle eine neue Datei `custom.spec.js` und reiche sie zusammen mit deiner Lösung ein:

```shell
exercism submit numbers.wat custom.spec.js
```
