## Allgemein

Implementiere das Struct `SimpleLinkedList` nicht als Wrapper um einen `Vec`. Lege die Knoten stattdessen auf dem Heap an.

Das kannst du zum Beispiel so umsetzen:

```
pub struct SimpleLinkedList<T> {
    head: Option<Box<Node<T>>>,
}
```

Das Feld `head` zeigt auf das erste Element (Node) dieser verketteten Liste.

Diese Implementierung braucht außerdem ein Struct `Node` mit den folgenden Feldern:

```
struct Node<T> {
    data: T,
    next: Option<Box<Node<T>>>,
}
```

`data` enthält die gespeicherten Daten, und `next` zeigt auf den folgenden Knoten (falls vorhanden) oder auf None.

## Warum `Option<Box<Node<T>>>` und nicht nur `Option<Node<T>>`?

Probier es selbst aus. Du bekommst dann den folgenden Fehler.

```
| struct Node<T>
| ^^^^^^^^^^^^^^ recursive type has infinite size
...
|     next: Option<Node<T>>,
|     --------------------- recursive without indirection
```

Das Problem ist, dass die Größe von next zur Kompilierzeit bekannt sein muss.
Da `next` rekursiv ist („ein Knoten hat einen Knoten, der einen Knoten hat ...“), weiß der Compiler nicht, wie viel Speicher reserviert werden muss.
Im Gegensatz dazu ist [Box](https://doc.rust-lang.org/std/boxed/) ein Heap-Zeiger mit einer festgelegten Größe.
