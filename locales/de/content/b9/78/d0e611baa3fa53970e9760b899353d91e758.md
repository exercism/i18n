# Strings

`STR` speichert Text. Ein String wird zwischen doppelte Anführungszeichen geschrieben.

```sather
   composer : STR is
      return "Sibelius";
   end;
```

Einmal entstanden, ändert sich ein `STR` nie mehr. Alles Folgende liefert einen *neuen*
String, statt den String zu verändern, nach dem gefragt wurde.

## Verbinden

```sather
"Jean" + " " + "Sibelius"      -- "Jean Sibelius"
```

Mit `+` kannst du auch eine Zahl an einen String anhängen, und so kommt eine Zahl in
einen Satz:

```sather
"Opus " + 27           -- "Opus 27"
```

## Länge

```sather
"Sibelius".size        -- 8
"".size                -- 0
```

`.size` zählt die Zeichen, und die Antwort ist ein `INT`.

## Teile

| Aufruf | Antwort |
| --- | --- |
| `"Sibelius".head(3)` | `"Sib"` |
| `"Sibelius".tail(4)` | `"lius"` |

Wenn du nach mehr verlangst, als da ist, bekommst du einfach das zurück, was da ist,
statt einen Fehler zu bekommen.

## Vergleichen

`=` fragt, ob zwei Strings denselben Text enthalten, und `/=` ob sie sich unterscheiden.

```sather
"forte" = "forte"      -- true
"forte" = "Forte"      -- false
```

Die Groß- und Kleinschreibung ist wichtig. `.upper` und `.lower` geben eine Kopie in
einer Schreibweise zurück, was die übliche Art ist, zu vergleichen, ohne darauf zu
achten:

```sather
"Forte".lower                    -- "forte"
"Forte".lower = "forte".lower    -- true
```

## Ein Wort zur Größe

Ein `STR` ist eine Folge von Bytes, und `.size` zählt Bytes. Bei englischem Text ist
das dasselbe wie das Zählen von Buchstaben. Bei Text mit Akzenten oder anderen
Alphabeten ist das nicht so, weil diese Buchstaben jeweils mehr als ein Byte belegen.
