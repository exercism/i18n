# Ergänzung zur Anleitung

## Wie diese Übung für den Python-Track aufgebaut ist

Die Tests für diese Übung erwarten, dass deine Lösung als eine RelativeDistance-`class` in Python implementiert wird.
Wenn du mit `class`es in Python nicht vertraut bist, sind [concept:python/classes]() und [`classes` in der offiziellen Python-Dokumentation][classes in python] gute Ausgangspunkte.


`RelativeDistance` sollte mit `family_tree` initialisiert werden (_siehe [`__init__()`][init] für weitere Informationen_), einem Wörterbuch, dessen `keys` die Personen und dessen `values` `list`en der Kinder dieser Person sind.
Außerdem musst du eine [Methode][methods] `degree_of_separation` implementieren, die den Grad der Trennung zwischen `person_a` und `person_b` zurückgibt, die Personen im übergebenen Familienstammbaum sind.


Du bekommst eine Stub-Implementierung für die [spezielle Methode][special-methods] `__init__`, mit der eine Instanz der Klasse `RelativeDistance` erzeugt wird, sowie ein Stub der Methode `degree_of_separation`.
Zuerst musst du `__init__` mit einem passenden Attribut auf `self` (_der Instanz_) anpassen, das die `family_tree`-Daten repräsentiert.
Danach kannst du deine Logik in der Methode `degree_of_separation` ergänzen, um den Grad der Trennung zwischen `person_a` und `person_b` zu berechnen.


## Exception-Meldungen

Manchmal ist es notwendig, [eine Exception auszulösen][raising-exceptions].
Wenn du das tust, solltest du immer eine **aussagekräftige Fehlermeldung** angeben, die angibt, woher der Fehler stammt.
Das macht deinen Code lesbarer und hilft beim Debugging erheblich.
Wenn du weißt, dass die Fehlerquelle von einem bestimmten Typ ist, kannst du eine der [eingebauten Fehlertypen][base-error-classes] auslösen, solltest aber trotzdem eine aussagekräftige Meldung angeben.

Diese Übung verlangt, dass du die [raise-Anweisung][raise-statement] verwendest, um mehrere `ValueError`s zu „werfen“.
Im ersten Szenario musst du einen `ValueError` auslösen, wenn eine oder beide der Personen, die an die Methode `RelativeDistance.degree_of_separation` übergeben werden, nicht im Familienstammbaum vorhanden sind.

```python
# Example when Person A is not in the tree.
raise ValueError("Person A not in family tree.")
```

Wenn beide Personen im Familienstammbaum vorhanden sind, musst du einen `ValueError` auslösen, wenn es zwischen ihnen keine gültige Verbindung gibt, wie sie durch die Regeln definiert ist.

```python
# Example when there are no valid connections.
raise ValueError("No connection between person A and person B.")
```

Die Tests bestehen nur, wenn du sowohl den erwarteten `exception`-Typ mit `raise` auslöst als auch die erwartete Meldung dazu angibst.
Bitte schau dir die Tests und ihre erwarteten Ergebnisse sorgfältig an, denn diese Anleitung ist nicht vollständig.
