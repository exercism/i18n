# Über

Ein boolescher Wert gibt an, ob eine Bedingung `true` oder `false` ist.
In Go kann der Typ `bool` nur einen dieser beiden Werte annehmen.

```go
isDoorLocked := true
hasKey := true
knowsCode := false
```

## Logische Operatoren

Logische Operatoren arbeiten mit einem oder zwei booleschen Werten und ergeben einen booleschen Wert.

| Operator | Name  | Verhalten                                            |
| -------- | ----- | ---------------------------------------------------- |
| `!`      | NICHT | Gibt das Gegenteil eines einzelnen booleschen Werts zurück |
| `&&`     | UND   | Ergibt nur dann `true`, wenn beide Seiten `true` sind |
| `\|\|`   | ODER  | Ergibt `true`, wenn mindestens eine Seite `true` ist  |

Verwende `!` (NICHT), wenn du das Gegenteil eines booleschen Werts brauchst:

```go
!isDoorLocked // false
```

Verwende `&&` (UND), wenn beide Bedingungen `true` sein müssen:

```go
canUnlockDoor := isDoorLocked && hasKey // true
```

Verwende `||` (ODER), wenn mindestens eine Bedingung `true` sein muss:

```go
canOpenDoor := canUnlockDoor || knowsCode // true
```

Logische Operatoren werden in dieser Reihenfolge ausgewertet: zuerst `!`, dann `&&`, dann `||`.
Mit Klammern gruppierst du Code und steuerst, welche Operationen zuerst ausgeführt werden:

```go
!true && false   // false because !true is evaluated first
!(true && false) // true because true && false is evaluated first
```
