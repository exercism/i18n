# Einführung

Mit Kommentaren kannst du Notizen im Code hinterlassen, ohne dass sich das auf die Ausführung auswirkt.
Einzeilige Kommentare beginnen mit `//`, und mehrzeilige Kommentare werden in `/*` und `*/` eingeschlossen:

```go
// This is a single-line comment.

/*
This is a
multiline comment.
*/
```

Kommentare erfüllen unterschiedliche Zwecke, je nachdem, wo sie stehen.

## Code-Kommentare

Code-Kommentare erklären, warum etwas gemacht wird, nicht was.
Verwende sie, wenn der Grund für eine Entscheidung nicht aus dem Code hervorgeht:

```go
results = results[1:] // skipping the header row
```

## Doc-Kommentare

Doc-Kommentare stehen direkt vor einer Deklaration, ohne dass eine Leerzeile den Kommentar von der Deklaration trennt.
[`godoc`][godoc] liest sie ein, um die Paketdokumentation zu erzeugen.
Ein Doc-Kommentar sollte ein vollständiger Satz sein, der mit dem Namen des Bezeichners beginnt und mit einem Punkt endet.

Paketkommentare beginnen mit dem Paketnamen:

```go
// Package kelvin provides tools to convert temperatures to and from Kelvin.
package kelvin
```

Funktionskommentare beginnen mit dem Funktionsnamen:

```go
// CelsiusFreezingTemp returns an integer value equal to the temperature at which water freezes in degrees Celsius.
func CelsiusFreezingTemp() int {
	return 0
}
```

[godoc]: https://go.dev/blog/godoc
