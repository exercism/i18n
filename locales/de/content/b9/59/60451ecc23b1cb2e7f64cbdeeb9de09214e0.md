# Einführung

## Durations und Periods

Klassen wie `LocalDate` und `LocalDateTime` beschreiben einen _Zeitpunkt_.
Das Paket `java.time` enthält außerdem zwei Klassen, die eine _Zeitspanne_ beschreiben:

- `java.time.Period` ist eine Zeitspanne in Jahren, Monaten und Tagen, zum Beispiel „2 Monate und 5 Tage“.
- `java.time.Duration` ist eine Zeitspanne in Stunden, Minuten, Sekunden, Millisekunden und Nanosekunden, zum Beispiel „1 Stunde und 30 Minuten“.

Ein `Period`-Objekt folgt dem Kalender, deshalb verwendest du es mit Datumsangaben und Datum-Zeit-Werten.
Ein `Duration`-Objekt misst die exakte Zeit, deshalb verwendest du es mit Uhrzeiten und Datum-Zeit-Werten, aber nicht mit reinen Datumsangaben.

```exercism/note
Wie die anderen Klassen aus `java.time` sind `Period` und `Duration` unveränderlich.
Methoden, die so aussehen, als würden sie sie verändern, geben stattdessen eine _neue_ Instanz zurück.
```

### `Period`

Ein `Period`-Objekt erzeugst du mit einer seiner statischen Factory-Methoden:

```java
Period.ofDays(10);
// => P10D

Period.ofMonths(3);
// => P3M

Period.of(1, 2, 15);
// => P1Y2M15D
```

Das Ergebnis von `toString()` verwendet die [ISO-8601][iso-8601-durations]-Notation: `P` (für „period“), gefolgt von der Anzahl der Jahre (`Y`), Monate (`M`) und Tage (`D`).

Du kannst ein `Period`-Objekt zu einem Datum addieren oder davon subtrahieren:

```java
LocalDate date = LocalDate.of(2024, 3, 10);

date.plus(Period.ofMonths(2));
// => 2024-05-10

date.minus(Period.ofDays(10));
// => 2024-02-29
```

Weil Monate unterschiedlich lang sind, kann das Addieren von Monaten auf einen Tag fallen, den es nicht gibt.
In diesem Fall wird das Ergebnis auf den letzten gültigen Tag des Monats zurückgesetzt:

```java
LocalDate.of(2025, 1, 31).plus(Period.ofMonths(1));
// => 2025-02-28
```

`Period.between()` liefert den `Period` von einem Datum (einschließlich) bis zu einem anderen (ausschließlich):

```java
LocalDate start = LocalDate.of(2023, 3, 10);
LocalDate end = LocalDate.of(2024, 5, 25);

Period period = Period.between(start, end);
// => P1Y2M15D

period.getYears();
// => 1
period.getMonths();
// => 2
period.getDays();
// => 15
```

### Einheiten mit `ChronoUnit` zählen

Ein `Period`-Objekt hält Jahre, Monate und Tage getrennt.
Deshalb liefert `getDays()` nur den Tage-_Teil_ des Zeitraums, nicht die Gesamtzahl der Tage.
Um die Gesamtzahl einer einzelnen Einheit zwischen zwei Datumsangaben zu zählen, verwendest du die `between()`-Methode von [`java.time.temporal.ChronoUnit`][chronounit-docs]:

```java
LocalDate start = LocalDate.of(2024, 1, 15);
LocalDate end = LocalDate.of(2024, 3, 20);

Period.between(start, end);
// => P2M5D

Period.between(start, end).getDays();
// => 5

ChronoUnit.DAYS.between(start, end);
// => 65
```

Das Ergebnis ist negativ, wenn das zweite Datum vor dem ersten liegt:

```java
ChronoUnit.DAYS.between(end, start);
// => -65
```

### `Duration`

Ein `Duration`-Objekt erzeugst du ebenfalls mit statischen Factory-Methoden:

```java
Duration.ofMinutes(90);
// => PT1H30M

Duration.ofHours(2).plusMinutes(15);
// => PT2H15M
```

In der ISO-8601-Notation trennt das `T` den Datumsteil vom Zeitteil, deshalb werden Durations als `PT...` geschrieben.

Du kannst ein `Duration`-Objekt zu einem Datum-Zeit-Wert addieren oder davon subtrahieren:

```java
LocalDateTime start = LocalDateTime.of(2024, 3, 10, 22, 30);

start.plus(Duration.ofMinutes(90));
// => 2024-03-11T00:00
```

`Duration.between()` liefert die exakte Zeitspanne zwischen zwei Datum-Zeit-Werten:

```java
LocalDateTime checkIn = LocalDateTime.of(2024, 3, 10, 18, 5);
LocalDateTime checkOut = LocalDateTime.of(2024, 3, 10, 19, 40);

Duration.between(checkIn, checkOut);
// => PT1H35M
```

Mit Methoden wie `toHours()`, `toMinutes()` und `toSeconds()` kannst du ein `Duration`-Objekt in eine einzelne Einheit umrechnen.
Sie liefern die _Gesamtmenge_ in dieser Einheit, abgerundet:

```java
Duration duration = Duration.ofMinutes(95);

duration.toHours();
// => 1
duration.toMinutes();
// => 95
```

Um eine Duration in ihre Bestandteile zu zerlegen, wie auf einer Uhr, verwendest du stattdessen die `toXxxPart()`-Methoden:

```java
Duration duration = Duration.ofMinutes(95);

duration.toHoursPart();
// => 1
duration.toMinutesPart();
// => 35
```
