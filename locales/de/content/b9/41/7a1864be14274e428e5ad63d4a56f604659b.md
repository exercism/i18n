# Einführung

Common Lisp verwendet für die meisten Operationen die üblichen arithmetischen Operatoren, unterscheidet sich aber etwas dadurch, dass es eine „Präfixnotation“ statt der bekannteren „Infixnotation“ verwendet.

Anschaulicher:

```lisp
;; Infix-notation (non-lisp languages)
1 + 2 + 3 + 4 + 5 ; => 15
;; Prefix-notation (lisp languages)
(+ 1 2 3 4 5)     ; => 15
```

Auch wenn die Präfixnotation manche Operationen wie `2 + 2` in die etwas ungewohnte Form `(+ 2 2)` bringt, macht sie es viel einfacher, mit mehr als einer Zahl gleichzeitig zu arbeiten.

## Grundrechenarten

Common Lisp hat alle typischen Funktionen: `+`, `-`, `*`, `/` für Addition, Subtraktion, Multiplikation und Division.

Wenn du eine Division durchführst, möchtest du vielleicht den Rest der Division wissen. Das erledigt die Funktion `mod` (für Modulo), die eine Zahl und einen Divisor als Argumente entgegennimmt:

```lisp
(mod 4 2)  ; => 0
(mod 2 4)  ; => 2
(mod 10 3) ; => 1
```

## Zahlen vergleichen

Schließlich kann es nützlich sein, verschiedene Zahlen mit Funktionen wie `=` (gleich), `/=` (ungleich) und `>=` (größer oder gleich) zu vergleichen.
Wenn diese Vergleiche wahr sind (wie in `(= 1 1)`), geben sie `T` zurück, und wenn sie nicht wahr sind (wie in `(> 0 1)`), geben sie `NIL` zurück.
