# Tests

## Tests ausführen

Wenn du dich im Verzeichnis einer Übung befindest, siehst du zwei Unterverzeichnisse:

* `src` enthält deine Lösung für die Übung
* `spec` enthält die Tests, die für die Übung ausgeführt werden

Wenn du dich im richtigen Verzeichnis befindest (also in dem, das `src` und `spec` enthält), kannst du die Tests für diese Übung mit `crystal spec` ausführen:

```bash
$ pwd
/Users/johndoe/Code/exercism/crystal/hello-world

$ ls
GETTING_STARTED.md README.md          spec               src

$ crystal spec
```

Damit werden alle Testdateien im Verzeichnis `spec` ausgeführt.

In jeder Testdatei sind alle Tests bis auf den ersten übersprungen.

Sobald ein Test erfolgreich läuft, kannst du den nächsten wieder aktivieren, indem du `pending` in `it` änderst.

## Crystal-Formatierung

Bevor du einreichst, empfiehlt es sich, `crystal tool format` auf deine Lösung anzuwenden.

Du kannst alles in deinem aktuellen Verzeichnis so formatieren:

```bash
$ crystal tool format ./
```

Oder du formatierst gezielt einzelne Dateien:

```bash
$ crystal tool format ./<path>/<to>/<file>
```

## Deine Lösung einreichen

Achte darauf, beim Einreichen deiner Lösung die Quelldatei im Verzeichnis `src` einzureichen:

```bash
$ exercism submit src/<exercise>.cr
```
