## 1. Koordinaten extrahieren

Implementiere die Funktion `get_coordinate()`, die ein Paar `(treasure, coordinate)` aus Azaras Liste nimmt und nur die extrahierte Kartenkoordinate zurückgibt.


```python
>>> get_coordinate(('Scrimshawed Whale Tooth', '2A'))
2A
```

## 2. Koordinaten formatieren

Implementiere die Funktion `convert_coordinate()`, die eine Koordinate im Format "2A" nimmt und ein Tupel im Format `("2", "A")` zurückgibt.


```python
>>> convert_coordinate("2A")
("2", "A")
```

## 3. Koordinaten abgleichen

Implementiere die Funktion `compare_records()`, die ein Paar `(treasure, coordinate)` und einen Datensatz `(location, coordinate, quadrant)` nimmt und die Koordinaten aus beiden vergleicht.
Gib **`True`** zurück, wenn die Koordinaten „übereinstimmen", und gib **`False`** zurück, wenn nicht.
Formatiere die Koordinaten nach Bedarf neu, damit der Vergleich korrekt ist.


```python
>>> compare_records(('Brass Spyglass', '4B'), ('Seaside Cottages', ('1', 'C'), 'blue'))
False

>>> compare_records(('Model Ship in Large Bottle', '8A'), ('Harbor Managers Office', ('8', 'A'), 'purple'))
True
```

## 4. Übereinstimmende Datensätze kombinieren

Implementiere die Funktion `create_record()`, die ein Paar `(treasure, coordinate)` aus Azaras Liste und einen Datensatz `(location, coordinate, quadrant)` aus Ruis Liste nimmt und `(treasure, coordinate, location, coordinate, quadrant)` zurückgibt, **wenn die Koordinaten übereinstimmen**.
Wenn die Koordinaten _nicht_ übereinstimmen, gib den String **"not a match"** zurück.
Formatiere die Koordinate nach Bedarf neu, damit der Vergleich korrekt ist.


```python
>>> create_record(('Brass Spyglass', '4B'), ('Abandoned Lighthouse', ('4', 'B'), 'Blue'))

>>> create_record(('Brass Spyglass', '4B'), ('Seaside Cottages', ('1', 'C'), 'blue'))
"not a match"
```
