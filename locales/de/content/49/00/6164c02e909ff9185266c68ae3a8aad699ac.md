# Anleitung

Ozan stellt eine Playlist für einen bevorstehenden Roadtrip zusammen. Er möchte keinen Track mehr als einmal hören, doch die Playlist ist inzwischen so lang geworden, dass er Mühe hat, sich zu merken, welche Tracks schon hinzugefügt wurden.

Die API von Ozans Musikplayer kann nur mit Arrays umgehen. Also versucht er, Code zu schreiben, der `Array.indexOf()` verwendet, um zu prüfen, ob ein Track vorhanden ist, bevor er ihn zur Playlist hinzufügt. Leider braucht sein Programm viel zu lange, um ausgeführt zu werden. Er braucht deine Hilfe!

Du eilst Ozan zu Hilfe und stellst erstaunt fest, dass seine Playlist _eine halbe Million_ Tracks enthält. Vielleicht kennst du eine andere Datenstruktur, mit der du die Playlist effizienter bearbeiten kannst?

## 1. Doppelte Tracks entfernen

Implementiere die Funktion `removeDuplicates`, die eine Playlist als _Parameter_ entgegennimmt und eine neue Playlist _zurückgibt_, in der alle Tracks eindeutig sind.

```javascript
const playlist = [
  'Court and Spark - Joni Mitchell',
  'Big Yellow Taxi - Joni Mitchell',
  'Court and Spark - Joni Mitchell',
];

removeDuplicates(playlist);
//=> ['Court and Spark - Joni Mitchell', 'Big Yellow Taxi - Joni Mitchell']
```

## 2. Prüfen, ob ein Track bereits hinzugefügt wurde

Implementiere die Funktion `hasTrack`, die eine Playlist und einen Track als _Parameter_ entgegennimmt und einen booleschen Wert _zurückgibt_, der angibt, ob die Playlist den Track enthält.

```javascript
const playlist = [
  'The Fashion Show - Grace Jones',
  'Dr. Funkenstein - Parliament',
];

hasTrack(playlist, 'Dr. Funkenstein - Parliament');
//=> true

hasTrack(playlist, 'Walking in the Rain - Grace Jones');
//=> false
```

## 3. Einen Track hinzufügen

Implementiere die Funktion `addTrack`, die eine Playlist und einen Track als _Parameter_ entgegennimmt und eine neue Playlist _zurückgibt_, die den Track enthält.

```javascript
const playlist = ['Selma - Bijelo Dugme'];

addTrack(playlist, 'Atomic Dog - George Clinton');
//=> ['Selma - Bijelo Dugme', 'Atomic Dog - George Clinton']

addTrack(playlist, 'Selma - Bijelo Dugme');
//=> ['Selma - Bijelo Dugme', 'Atomic Dog - George Clinton']
```

## 4. Einen Track löschen

Implementiere die Funktion `deleteTrack`, die eine Playlist und einen Track als _Parameter_ entgegennimmt und eine neue Playlist _zurückgibt_, die den Track nicht enthält.

```javascript
const playlist = [
  'The Treasure - Fra Lippo Lippi',
  'After the Fall - Klaus Nomi',
];

deleteTrack(playlist, 'The Treasure - Fra Lippo Lippi');
//=> ['After the Fall - Klaus Nomi']

deleteTrack(playlist, 'I Feel the Magic - Belinda Carlisle');
//=> ['After the Fall - Klaus Nomi']
```

## 5. Eindeutige Künstler auflisten

Implementiere die Funktion `listArtists`, die eine Playlist als _Parameter_ entgegennimmt und die Liste der eindeutigen Künstler in der Playlist _zurückgibt_. Beachte, dass die Namen der Tracks das Format `<SONG> - <ARTIST>` haben.

```javascript
const playlist = [
  'All Mine - Portishead',
  'Sight to Behold - Devendra Banhart',
  'Sour Times - Portishead',
];

listArtists(playlist);
//=> ['Portishead', 'Devendra Banhart']
```
