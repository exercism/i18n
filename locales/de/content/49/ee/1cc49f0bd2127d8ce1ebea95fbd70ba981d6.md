# Einführung

AWK ist eine sehr kleine Sprache und hat nur wenige grundlegende Datentypen.
In dieser Lektion schauen wir uns Zahlen und Strings an.

## Zahlen

Zahlen werden in AWK als Gleitkommazahlen mit doppelter Genauigkeit umgesetzt.
Es gibt keinen Unterschied zwischen Ganzzahlen, Gleitkommazahlen und Doubles.

AWK versteht oktale Zahlenkonstanten (beginnend mit `0`) und hexadezimale Zahlenkonstanten (beginnend mit `0x` oder `0X`).

### Numerische Operationen

Du kannst die üblichen arithmetischen Operatoren `+`, `-`, `*`, `/`, `%` verwenden.
Der Operator für die Potenzierung ist `^`.
Es gibt einige eingebaute numerische Funktionen, darunter trigonometrische Funktionen, die Erzeugung von Zufallszahlen und `int(x)`, um eine Zahl auf die nächste Ganzzahl zwischen _x_ und null abzuschneiden.

## Strings

AWK-Strings sind Folgen von Zeichen.
Eine String-Konstante gibst du mit doppelten Anführungszeichen an.

### String-Operationen

Es gibt nur eine String-Operation: die Verkettung.
Die Verkettung hat keinen speziellen Operator;
du setzt einfach zwei Strings nebeneinander und schon werden sie verkettet:

```awk
BEGIN {
    hw = "Hello" "World"
    print hw
}
# => HelloWorld
```

~~~~exercism/note
`print` ist eine **Anweisung**, keine Funktion.
`print` braucht keine runden Klammern.
~~~~

AWK hat eine Fülle von Funktionen zur String-Bearbeitung.
Wir werden sie nach und nach im Laufe des Tracks kennenlernen.

## Umwandlung zwischen Zahlen und Strings

Es gibt keine expliziten Operatoren, um zwischen Zahlen und Strings umzuwandeln.
AWK erledigt das implizit, je nach Kontext des Programms.
Dadurch ist die Arbeit mit den Werten von Eingabefeldern sehr einfach: AWK macht im Allgemeinen genau das, was du willst.

* `print x + y` wandelt die Werte der Variablen `x` und `y` dank der numerischen Operation `+` in Zahlen um.
* `print x y` wandelt die Werte der Variablen `x` und `y` dank der Verkettung in Strings um.

Wenn du es explizit haben willst, liefert `0 + x` die Zahlendarstellung von _x_ und `"" x` die String-Darstellung von _x_.

### Von Strings zu Zahlen

Die Art und Weise, wie AWK einen String in eine Zahl umwandelt, kann verwirrend sein.
Eine einfache Vorstellung davon ist, dass AWK vom Anfang eines Strings „Zahlenzeichen“ liest, bis es auf ein „Nicht-Zahlenzeichen“ stößt.
Einige Beispiele:

* `"2.5"` wird zur Zahl `2.5`;
* `"1e3"` wird zur Zahl `1000` (wissenschaftliche Notation);
* `"456abc"` wird zur Zahl `456` (weil `a` kein „Zahlzeichen“ ist, endet die Umwandlung dort).
* `"abc789"` wird zur Zahl `0` (am **Anfang** des Strings stehen keine Zahlen).
