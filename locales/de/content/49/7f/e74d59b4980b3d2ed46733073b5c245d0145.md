# Anleitung

Wandle eine Binärzahl, die als String dargestellt wird (z. B. '101010'), von Grund auf in die entsprechende Dezimalzahl um.

Implementiere die Umwandlung von binär nach dezimal. Bei einem binären Eingabe-String soll dein Programm eine Dezimalzahl als Ausgabe liefern. Das Programm soll ungültige Eingaben behandeln.

## Hinweis

- Implementiere die Umwandlung selbst.
  Nutze nichts anderes, das die Umwandlung für dich erledigt.

## Über Binärzahlen (Basis 2)

Das Dezimalsystem ist ein System zur Basis 10.

Eine Zahl wie 23 in der Basis-10-Schreibweise lässt sich als Linearkombination von Zehnerpotenzen verstehen:

- Die rechteste Ziffer wird mit 10^0 = 1 multipliziert
- Die nächste Ziffer wird mit 10^1 = 10 multipliziert
- ...
- Die *n*-te Ziffer wird mit 10^_(n-1)_ multipliziert.
- Alle diese Werte werden summiert.

Also: `23 => 2*10^1 + 3*10^0 => 2*10 + 3*1 = 23 base 10`

Binär funktioniert ähnlich, verwendet aber Zweierpotenzen statt Zehnerpotenzen.

Also: `101 => 1*2^2 + 0*2^1 + 1*2^0 => 1*4 + 0*2 + 1*1 => 4 + 1 => 5 base 10`.
