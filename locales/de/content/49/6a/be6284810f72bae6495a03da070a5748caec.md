# Überschrift, die entfernt wird

## Ein neuer Ansatz für die Übung

Bitte ignoriere den Teil über eine FRP-Bibliothek: Für diese Übung ist
keine Bibliothek von Drittanbietern erforderlich. Diese Übung konzentriert
sich auf ereignisgesteuerte Programmierung mit Callbacks und der
Ereignisschleife von Tcl.

Du sollst einen TCP-Server und ein domänenspezifisches Protokoll
implementieren. Dieser Server wird mit dem zu erratenden Wort gestartet. Das
Testskript implementiert den Client, der die Befehle an den Server sendet.

### Domänenspezifisches Protokoll

Die Protokollbefehle, die du implementieren musst, sind:

- `STATUS`, um den aktuellen Zustand des Spiels zurückzugeben. Die Antwort ist
  eine dreielementige Liste:
    1) die Anzahl der verbleibenden Fehlversuche,
    2) das Wort, bei dem nicht geratene Buchstaben durch Unterstriche verdeckt
       sind, und
    3) ein Statusfeld (eines von „ongoing“, „win“
  oder „lose“)
- `GUESS x`, wobei `x` ein Buchstabe ist, der geraten werden soll. Der Server
  antwortet nach jedem Versuch mit der Statusliste.
- `SHUTDOWN`, um den Server aus der Ferne herunterzufahren. Andernfalls beendet
  sich der Server nach einem Sieg oder einer Niederlage.

Der Server sollte diese Befehle ohne Beachtung der Groß- und Kleinschreibung
verarbeiten können.

### Welchen Port verwendet der Server?

Starte deinen Server mit **Portnummer 0**: Tcl findet dann einen unbenutzten
Port, sodass wir keine Portnummer im Testskript fest verdrahten müssen. Alle
Interpreter, die in einem Prozess laufen (einschließlich Threads), teilen sich
dieselbe Umgebung, sodass der Server seinen Port über das globale `env`-Array
an das Testskript zurückmelden kann. Ein Beispiel findest du in der
ursprünglichen Datei hangman.tcl.

### Hinweise

Du brauchst diese Tcl-Befehle:
[`socket`](https://www.tcl-lang.org/man/tcl8.6/TclCmd/socket.htm),
[`fileevent`](https://www.tcl-lang.org/man/tcl8.6/TclCmd/fileevent.htm),
[`vwait`](https://www.tcl-lang.org/man/tcl8.6/TclCmd/vwait.htm).

Dieses [Beispiel-Socket-Programm](https://www.tcl-lang.org/about/netserver.html) kann dir den Einstieg erleichtern.
