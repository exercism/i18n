# Anleitung

In dieser Übung spielst du mit einer Freundin oder einem Freund ein Zahlenratespiel. Die Regeln sind einfach: du wählst heimlich eine Zahl zwischen `1` und `100` und deine Freundin oder dein Freund versucht zu erraten, welche Zahl du gewählt hast. Um deiner Freundin oder deinem Freund zu helfen, antwortest du unterschiedlich, je nachdem, wie nah der Tipp an der Zahl ist, die du gewählt hast (`42`). Das sind die Regeln für die verschiedenen Antworten:

- Wenn der Tipp `42` ist: „Correct“
- Wenn der Tipp `41` oder `43` ist: „So close“
- Wenn der Tipp kleiner als `41` ist: „Too low“
- Wenn der Tipp größer als `43` ist: „Too high“

Du hast vier Aufgaben, um die Antworten auf die Tipps umzusetzen.

## 1. Antworte auf einen richtigen Tipp

Implementiere die Funktion `reply`, um auf einen richtigen Tipp zu antworten:

```gleam
reply(42)
// -> "Correct"
```

## 2. Antworte auf einen fast richtigen Tipp

Ändere die Funktion `reply`, um auf fast richtige Tipps zu antworten:

```gleam
reply(41)
// -> "So close"
```

## 3. Antworte auf zu niedrige Tipps

Ändere die Funktion `reply`, um auf zu niedrige Tipps zu antworten:

```gleam
reply(25)
// -> "Too low"
```

## 4. Antworte auf zu hohe Tipps

Ändere die Funktion `reply`, um auf zu hohe Tipps zu antworten:

```gleam
reply(88)
// -> "Too high"
```
