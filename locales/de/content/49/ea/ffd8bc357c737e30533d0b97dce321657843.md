# Einleitung

Deine Freundin Eliud hat von ihrer Oma Tigist einen Bauernhof geerbt.
Ihre Oma war Erfinderin und hatte die Angewohnheit, Dinge übermäßig kompliziert zu bauen.
Im Hühnerstall gibt es eine digitale Anzeige. Sie zeigt eine kodierte Zahl, die die Positionen aller Eier angibt, die eingesammelt werden könnten.

Eliud bittet dich, ein Programm zu schreiben, das die tatsächliche Anzahl der Eier im Stall anzeigt.

Die Kodierung der Positionsinformationen wird so berechnet:

1. Untersuche die möglichen Legeplätze und notiere eine `1` für ein vorhandenes Ei oder eine `0` für einen leeren Platz.
2. Wandle die Zahl vom Binärsystem ins Dezimalsystem um.
3. Zeige das Ergebnis auf der Anzeige an.

Beispiel 1:

```text
Chicken Coop:
 _ _ _ _ _ _ _
|E| |E|E| | |E|

Resulting Binary:
 1 0 1 1 0 0 1

Decimal number on the display:
89

Actual eggs in the coop:
4
```

Beispiel 2:

```text
Chicken Coop:
 _ _ _ _ _ _ _ _
| | | |E| | | | |

Resulting Binary:
 0 0 0 1 0 0 0 0

Decimal number on the display:
16

Actual eggs in the coop:
1
```
