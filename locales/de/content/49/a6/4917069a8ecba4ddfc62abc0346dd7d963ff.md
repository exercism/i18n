# Ergänzende Anweisungen

## Register

| Register | Verwendung | Typ       | Beschreibung                                     |
| -------- | ---------- | --------- | ------------------------------------------------ |
| `$a0`    | Eingabe    | Ganzzahl  | Eingabezahl                                      |
| `$v0`    | Ausgabe    | Ganzzahl  | Anzahl der Eier                                  |
| `$t0-9`  | temporär   | beliebig  | wird zur temporären Speicherung verwendet        |
