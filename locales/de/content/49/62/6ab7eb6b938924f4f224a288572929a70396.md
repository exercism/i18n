# Anleitung

In dieser Übung modellierst du eine Waage.

## 1. Erstelle einen Anfangszustand für die Waage

Beim Initialisieren sollte sich die Waage an ihren Werkseinstellungen orientieren, die davon abhängen, wo die Waage verkauft wird.
Dabei soll die Waage mit einer Genauigkeit initialisiert werden können und damit, ob sie metrisch oder imperial ist.

Implementiere die Methode `WeighingMachine#initialize`, die zwei Argumente entgegennimmt: `precision`, eine `Int32`, und `metric`, ein `Bool`.
Das Argument `metric` bedeutet, wenn es `true` ist, dass die Waage das metrische System verwenden soll, andernfalls soll sie das imperiale System verwenden.
Die initialize-Methode soll außerdem die Instanzvariable `@weight` auf `0.0` setzen.

```crystal
precision = 3
metric = true
vm = WeighingMachine.new(precision, metric)
```

## 2. Gib der Waage eine Genauigkeit

Um unterschiedliche Anforderungen zu erfüllen, kann jede Waage mit einer Genauigkeit angepasst werden (die Anzahl der Stellen nach dem Dezimaltrennzeichen).

Implementiere die Getter-Methode `WeighingMachine#precision`, die die Genauigkeit der Waage zurückgibt.

```crystal
precision = 3
metric = true
vm = WeighingMachine.new(precision, metric)
vm.precision
# => 3
```

## 3. Erlaube, dass das Gewicht der Waage gesetzt werden kann

Implementiere die Eigenschaft `WeighingMachine#weight`, mit der das Gewicht gelesen _und_ gesetzt werden kann:

```crystal
precision = 3
metric = true
wm = WeighingMachine.new(precision, metric)
wm.weight = 60.5
wm.weight
# => 60.5

wm.weigh
# => 60.5
```

## 4. Erlaube das Umschalten zwischen metrischen und imperialen Einheiten

Implementiere die Eigenschaft `WeighingMachine#metric=`, mit der die Einheit gesetzt werden kann.
Sie soll einen booleschen Wert akzeptieren.

```crystal
precision = 3
metric = true
wm = WeighingMachine.new(precision, metric)
vm.weight = 60.5
wm.metric = false

vm.weigh
# => 133.377
```
