# In-out-Parameter

Innerhalb des Funktionskörpers werden Parameter als Konstanten behandelt, nicht als Variablen; der Versuch, den Wert eines Parameters zu ändern, führt zu einem Fehler zur Compile-Zeit.
Wenn eine Funktion den Wert eines Parameters ändern möchte, muss sie einen [_In-out-Parameter_][in-out-parameters] verwenden, um diese Veränderbarkeit explizit zu machen.

Um In-out-Parameter zu verwenden, muss man sich über drei Dinge im Klaren sein:

1. Die Funktionsdefinition muss In-out-Parameter explizit kennzeichnen, indem sie das Schlüsselwort `inout` zwischen dem `:` und dem Typnamen in der Typannotation des Parameters schreibt.
2. Der Wert, der an den In-out-Parameter übergeben wird, muss als Variable deklariert sein, nicht als Konstante. Ebenso kann er kein Literal sein.
3. Dem Variablennamen muss im Aufruf der Funktion ein `&` vorangestellt werden, um ihn explizit als veränderbar zu kennzeichnen.

Wenn dies geschieht, legt die Funktion eine interne Kopie des In-out-Parameters an, ändert sie wie im Funktionskörper angegeben und kopiert den geänderten Wert anschließend zurück in die Variable, die beim Aufruf übergeben wurde, sobald die Funktion zurückkehrt.

```swift
func updateVersion(_ record: inout (version: Int, title: String)) {
  record.version += 1
}

var dbRecord = (version: 2, title: "Exercism")
updateVersion(&dbRecord)

// dbRecord is now (3, "Exercism")
```

~~~~exercism/warning
Es gibt ein paar zusätzliche Regeln, die man im Zusammenhang mit In-out-Parametern kennen sollte.

1. Innerhalb einer Funktion mit In-out-Parametern darfst du nicht auf die Variable verweisen, die als In-out-Parameter übergeben wurde.
2. Dieselbe Variable kann in derselben Funktion nicht als mehrere In-out-Parameter übergeben werden.
   Zum Beispiel löst `inoutFunc(&mutVar, &mutVar)` einen Compilerfehler aus.
~~~~
