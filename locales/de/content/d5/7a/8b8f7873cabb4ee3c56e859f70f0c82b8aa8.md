# Hinweise

## Allgemein

- Nutze [anonyme Funktionen][anon-fns].
- Verwende eine [Closure][closure], um auf die Variable aus dem äußeren Gültigkeitsbereich zu verweisen.

## 1. Erstelle einen Addierer

- Gib eine anonyme Funktion zurück, die das Argument der anonymen Funktion zum Argument addiert, das an `Secret.secret_add/1` übergeben wird.

## 2. Erstelle einen Subtrahierer

- Gib eine anonyme Funktion zurück, die das an `Secret.secret_subtract/1` übergebene Argument vom Argument der anonymen Funktion subtrahiert.

## 3. Erstelle einen Multiplizierer

- Gib eine anonyme Funktion zurück, die das Argument der anonymen Funktion mit dem Argument multipliziert, das an `Secret.secret_multiply/1` übergeben wird.

## 4. Erstelle einen Dividierer

- Gib eine anonyme Funktion zurück, die das Argument der anonymen Funktion durch das Argument dividiert, das an `Secret.secret_divide/1` übergeben wird.
- Nutze die [Ganzzahldivision][div].

## 5. Erstelle einen „and“-Verknüpfer

- Gib eine anonyme Funktion zurück, die mit dem Argument, das an die anonyme Funktion übergeben wird, und dem Argument, das an `Secret.secret_and/1` übergeben wird, eine [bitweise _and_][bitwise-wiki]-Operation durchführt
- Funktionen im [Bitwise-Modul][bitwise-hexdocs] können hilfreich sein.
- Wenn du Elixir in Version 1.9 oder älter verwendest, musst du `require Bitwise` am Anfang der Moduldefinition aufrufen, um das _Bitwise_-Modul verwenden zu können.

## 6. Erstelle einen „xor“-Verknüpfer

- Gib eine anonyme Funktion zurück, die mit dem Argument, das an die anonyme Funktion übergeben wird, und dem Argument, das an `Secret.secret_xor/1` übergeben wird, eine [bitweise _xor_][bitwise-wiki]-Operation durchführt
- Funktionen im [Bitwise-Modul][bitwise-hexdocs] können hilfreich sein.
- Wenn du Elixir in Version 1.9 oder älter verwendest, musst du `require Bitwise` am Anfang der Moduldefinition aufrufen, um das _Bitwise_-Modul verwenden zu können.

## 7. Erstelle einen Funktionskombinierer

- Gib eine anonyme Funktion zurück, die [die an `Secret.secret_combine/2` übergebenen Funktionen zusammensetzt][fn-composition].
- Setze einen `.` vor `()`, wenn du eine anonyme Funktion aufrufst.
