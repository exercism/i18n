## 1. Begrüße den neuen Spieler

- Es gibt eine [eingebaute Funktion][io-puts], die einen String auf die Standardausgabe schreibt.

## 2. Frage nach dem Namen des Charakters

- Es gibt eine [eingebaute Funktion][io-gets], die einen String von der Standardausgabe liest. Sie kann auch eine Eingabeaufforderung schreiben, daher brauchst du keine separate Funktion, um die Frage zu schreiben.
- Im `String`-Modul gibt es eine [eingebaute Funktion][string-trim], die führende und abschließende Leerzeichen aus der Eingabe entfernen kann.

## 3. Frage nach der Klasse des Charakters

- Es gibt eine [eingebaute Funktion][io-gets], die einen String von der Standardausgabe liest. Sie kann auch eine Eingabeaufforderung schreiben, daher brauchst du keine separate Funktion, um die Frage zu schreiben.
- Im `String`-Modul gibt es eine [eingebaute Funktion][string-trim], die führende und abschließende Leerzeichen aus der Eingabe entfernen kann.

## 4. Frage nach der Stufe des Charakters

- Es gibt eine [eingebaute Funktion][io-gets], die einen String von der Standardausgabe liest. Sie kann auch eine Eingabeaufforderung schreiben, daher brauchst du keine separate Funktion, um die Frage zu schreiben.
- Im `String`-Modul gibt es eine [eingebaute Funktion][string-trim], die führende und abschließende Leerzeichen aus der Eingabe entfernen kann.
- Im `String`-Modul gibt es eine [eingebaute Funktion][string-to-integer], die einen String in eine Ganzzahl umwandeln kann.

## 5. Fasse die vorherigen Schritte zu einem zusammen

- Verwende die Funktionen aus den vorherigen Schritten wieder.
- Es gibt eine [eingebaute Funktion][io-inspect], die beim Debuggen nützlich ist und mehr als nur Strings auf die Standardausgabe schreiben kann. Diese Funktion akzeptiert Optionen, zum Beispiel einen String, der vor dem übergebenen Wert geschrieben wird.
- Die oben genannte Funktion und ihre Option hängen einen Doppelpunkt und ein Leerzeichen an diesen String für dich an.
