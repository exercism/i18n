# Instructions

In dieser Übung arbeitest du an einem Terminplaner für einen Schönheitssalon in New York, der am 15. September 2012 eröffnet hat.

Du hast vier Aufgaben, in denen es jedes Mal um Termindaten geht. Die Datums- und Zeitangaben verwenden eines der folgenden drei Formate:

- `"7/25/2019 13:45:00"`
- `"July 25, 2019 13:45:00"`
- `"Thursday, July 25, 2019 13:45:00:00"`

~~~~exercism/caution
Die Tests setzen die Kultur automatisch auf `en-US`. Du musst die Kultur nicht selbst festlegen oder angeben.
~~~~

## 1. Termindatum parsen

Implementiere die Funktion `schedule`, die eine textuelle Darstellung eines Termindatums in das entsprechende `DateTime`-Format parst:

```fsharp
schedule "7/25/2019 13:45:00"
// => DateTime(2019, 7, 25, 13, 45, 0)
```

## 2. Prüfen, ob ein Termin bereits vorbei ist

Implementiere die Funktion `hasPassed`, die ein Termindatum entgegennimmt und prüft, ob der Termin irgendwann in der Vergangenheit lag:

```fsharp
hasPassed (DateTime(1999, 12, 31, 9, 0, 0))
// => true
```

## 3. Prüfen, ob der Termin am Nachmittag liegt

Implementiere die Funktion `isAfternoonAppointment`, die ein Termindatum entgegennimmt und prüft, ob der Termin am Nachmittag liegt (>= 12:00 und < 18:00):

```fsharp
isAfternoonAppointment (DateTime(2019, 03, 29, 15, 0, 0))
// => true
```

## 4. Uhrzeit und Datum des Termins beschreiben

Implementiere die Funktion `description`, die ein Termindatum entgegennimmt und eine Beschreibung dieses Datums und dieser Uhrzeit zurückgibt:

```fsharp
description (DateTime(2019, 03, 29, 15, 0, 0))
// => "You have an appointment on 3/29/2019 3:00:00 PM."
```

## 5. Das Jubiläumsdatum zurückgeben

Implementiere die Funktion `anniversaryDate`, die das diesjährige Jubiläumsdatum zurückgibt, also den 15. September:

```fsharp
anniversaryDate()
// => DateTime(2019, 9, 15, 0, 0, 0)
```
