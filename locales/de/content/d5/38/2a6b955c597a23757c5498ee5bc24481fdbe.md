# Über

C ist eine statisch typisierte Sprache. Das heißt, dass alles zur Compile-Zeit einen Typ hat.
Einen Namen für eine [Variable][variable] zu wählen und ihren Typ festzulegen, nennt man das Deklarieren einer Variable.

Eine Variable wird deklariert, indem du ihren Typ explizit angibst.
Ein Variablenname [muss bestimmten Regeln folgen][name-rules], zum Beispiel mit einem Buchstaben oder einem Unterstrich beginnen.
Manche Namen kannst du nicht verwenden, weil sie [für Schlüsselwörter][reserved-keywords] oder [andere Bezeichner][reserved-identifiers] reserviert sind.

Eine Variable wird durch eine Zuweisung gesetzt oder aktualisiert.
Wenn du den Wert setzt, definierst du die Variable.
Das Definieren der Variable nennt man auch Initialisierung.

```c
int foo;      // Declare an integer named var
foo = 10;     // Define the variable

int bar = 15; // Both can also be done in a single statement
```

Der Wert einer Variable lässt sich mit dem [einfachen Zuweisungsoperator `=`][assignment-operator] zuweisen und aktualisieren.
Sobald eine Variable definiert ist, kann sich ihr Typ nie mehr ändern.

```c
int foo = 10; // Assign initial value
foo = 25;     // Update to new value

foo = false;  // Compiler error when assigning value of a different type
```

C ist eine [imperative][imperative], [prozedurale][procedural] Sprache.
Jede Berechnung findet als Teil einer Folge von [Anweisungen][statements] statt, die zu einer [Funktion][function] oder mehreren Funktionen gehören.

Jede Funktion kann null oder mehr [Parameter][parameters] haben.
Wenn du eine Funktion definierst, müssen alle Parameter und der Rückgabewert explizit typisiert werden.
Werte gibst du mit dem [Schlüsselwort `return`][return-keyword] aus einer Funktion zurück.
Funktionen haben standardmäßig die externe [Speicherklasse][storage_class]. Das bedeutet, dass sie über die Lebensdauer des Programms hinweg existiert und außerhalb der Datei sichtbar sein kann.
Um das zu verhindern, kannst du das Schlüsselwort `static` hinzufügen, um die interne Sichtbarkeit festzulegen.

```c
static int add(int x, int y) {
  return x + y;
}
```

Im obigen Beispiel kannst du die Variablen `x` und `y` nur innerhalb der Funktion verwenden, sie haben also Funktionsgültigkeitsbereich.
Der [Gültigkeitsbereich][scope] beschreibt die Idee, dass der Wert, der mit einem Namen (eines Programmelements) verknüpft ist, nur innerhalb des Code-„Bereichs“ zugänglich ist, in dem er definiert ist.
Die wichtigsten Code-Bereiche in C sind:

- Datei
- Funktion
- Block (zum Beispiel innerhalb von Schleifen und anderen Konstrukten)

Funktionen rufst du auf, indem du den Funktionsnamen angibst und für jeden Parameter der Funktion ein Argument übergibst.

```c
int sum = add(1, 2);
```

C unterstützt zwei Arten von [Kommentaren][comments].
Einzeilige Kommentare beginnen mit `//` (seit C99), mehrzeilige Kommentare stehen zwischen `/*` und `*/`.
