# Testen auf der Kommandozeile

Führe die Tests so aus:

```bash
scarb cairo-test
```

Alle Tests außer dem ersten sind ignoriert. Wenn du den ersten Test zum Laufen gebracht hast, öffne die Quelldatei der Tests im Verzeichnis `tests`, entferne das Flag `#[ignore]` beim nächsten Test und bring die Tests wieder zum Laufen. Jeder einzelne Test ist eine Funktion mit dem Flag `#[test]` darüber. Mach so weiter, bis du jeden Test bestehst.

Wenn du _alle_ Tests ausführen möchtest, ohne die Quelldatei der Tests zu bearbeiten, verwende:

```bash
scarb cairo-test --include-ignored
```

Um einen bestimmten Test auszuführen, egal ob er ignoriert wird oder nicht, zum Beispiel `some_test`, kannst du Folgendes verwenden:

```bash
scarb cairo-test -f some_test
```

Mehr über Cairo-Tests erfährst du in der [Testdokumentation][cairo-tests] im Netz.

[cairo-tests]: https://book.cairo-lang.org/ch10-01-how-to-write-tests.html
