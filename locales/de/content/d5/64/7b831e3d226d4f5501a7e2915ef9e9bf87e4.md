# Einführung

Eine Instanz einer _Klasse_ erstellst du, indem du ihren _Konstruktor_ mit dem `new`-Operator aufrufst. Ein Konstruktor ist eine besondere Art von Methode. Sein Ziel ist es, eine neu erstellte Instanz zu initialisieren. Konstruktoren sehen wie normale Methoden aus, haben aber keinen Rückgabetyp und tragen den Namen ihrer Klasse.

```csharp
class Library
{
    private int books;

    public Library()
    {
        // Initialize the books field
        this.books = 10;
    }
}

// This will call the constructor
var library = new Library();
```

Wie normale Methoden können auch Konstruktoren Parameter haben. Die Parameter eines Konstruktors werden meist in (privaten) Feldern gespeichert, um später darauf zuzugreifen, oder sie werden für eine einmalige Berechnung verwendet. Argumente kannst du an Konstruktoren genauso übergeben wie an normale Methoden.

```csharp
class Building
{
    private int numberOfStories;
    private int totalHeight;

    public Building(int numberOfStories, double storyHeight)
    {
        this.numberOfStories = numberOfStories;
        this.totalHeight = numberOfStories * storyHeight;
    }
}

// Call a constructor with two arguments
var largeBuilding = new Building(55, 6.2)
```
