# Anleitung

In dieser Übung sollst du die Software für ein Verschlüsselungsgerät schreiben, das Daten durch Transformationen verändert. Du brauchst eine Möglichkeit, auf flexible Weise komplizierte Funktionen zu erstellen, indem du einfachere Funktionen kombinierst.

Gib für jede Aufgabe einen Block zurück, der aus dem aufrufenden Gültigkeitsbereich heraus aufgerufen werden kann.

## 1. Erstelle einen Addierer

Implementiere `secret-add`.
`secret-add` sollte eine Funktion zurückgeben, die ein Argument entgegennimmt und ihm das Argument hinzufügt, das an `secret-add` übergeben wurde.

## 2. Erstelle einen Subtrahierer

Implementiere `secret-subtract`.
`secret-subtract` sollte eine Funktion zurückgeben, die ein Argument entgegennimmt und von diesem Argument das Geheimnis subtrahiert, das an `secret-subtract` übergeben wurde.

## 3. Erstelle einen Multiplizierer

Implementiere `secret-multiply`.
`secret-multiply` sollte eine Funktion zurückgeben, die ein Argument entgegennimmt und es mit dem Geheimnis multipliziert, das an `secret-multiply` übergeben wurde.

## 4. Erstelle einen Dividierer

Implementiere `secret-divide`.
`secret-divide` sollte eine Funktion zurückgeben, die ein Argument entgegennimmt und es durch das Geheimnis dividiert, das an `secret-divide` übergeben wurde.

## 5. Erstelle einen Funktionskombinierer

Implementiere `secret-combine`.
`secret-combine` sollte eine Funktion zurückgeben, die ein Argument entgegennimmt und darauf in der übergebenen Reihenfolge die beiden Funktionen anwendet, die an `secret-combine` übergeben wurden.
