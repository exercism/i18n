# Zusatz zu den Anweisungen

## Lean-Syntax

In dieser Übung definierst du eine Syntax für eine DSL, die der Sprache DOT ähnelt.

Für diese Aufgabe brauchst du wahrscheinlich Notationen oder Makros.
Ein Blick in eine [Referenz][macro-reference] kann sich lohnen.

~~~~exercism/note
In dieser Übung werden Kanten durch ein einzelnes `-` zwischen Knoten dargestellt, im Gegensatz zum `--` der echten DOT-Sprache.
So vermeidest du Konflikte mit der Syntax für einzeilige Kommentare in Lean.

Außerdem endet jede Anweisung mit `;`, sogar Kommentare auf Graph-Ebene.
~~~~

[macro-reference]: https://lean-lang.org/doc/reference/latest/Notations-and-Macros/#language-extension
