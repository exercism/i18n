# Onboarding neuer Mitarbeiter in der Datenbank

## Problemstellung

ABC Corp plant, alle Informationen zu Barzahlungen an Mitarbeiter in einer Datenbank zu pflegen. Du hilfst der Finanzabteilung von ABC Corp dabei, das umzusetzen. Da ABC Corp sein Geschäft ausbaut, müssen wegen Neueinstellungen häufig neue Mitarbeiter ins System aufgenommen werden.

Deine Aufgabe ist es, die angegebenen Daten des neuen Mitarbeiters in die Tabelle `Employee` der Datenbank einzufügen und den Wert der automatisch generierten Spalte `employee_id` zurückzugeben, ohne dazu eine weitere Abfrage an die Datenbank zu senden. Wenn bei der Ausführung ein Fehler auftritt, soll `-1` zurückgegeben werden.

## Details zur Datenbank

Verwende für diese Aufgabe die bereitgestellte H2-Datenbank.

> Die Beispieldatenbank-Datei ist `gofigure.mv.db`, und der Name der Datenbank ist `gofigure`. Sie liegt im Ordner `db`.

Die folgenden Tabellen sind bereits mit einigen Beispieldaten in der H2-Beispieldatenbank vorhanden. Die Spaltennamen und Datentypen findest du unten.

**Tabellenname** : `Employee`

| **Spalten:**      | Typ |
| -----------       | ----------- |
| `employee_id`     | Ganzzahl, automatisch erhöhter Primärschlüssel       |
| `name`            | String        |
| `city`            | String        |
| `department`      | String        |
| `age`             | Ganzzahl        |

**Tabellenname**: `Payment`

| **Spalten:**      | Typ |
| -----------       | ----------- |
| `payment_id`      | Ganzzahl, automatisch erhöhter Primärschlüssel       |
| `date`            | Datum        |
| `amount`          | Gleitkommazahl        |
| `employee_id`     | Ganzzahl        |
| `reason`          | String        |

* Die Datenbankdatei ist `gofigure.mv.db`. Verwende als JDBC-URL `jdbc:h2:file:/path/to/db/file`
* Benutzername: `root`
* Passwort: `root`

## Einschränkungen

* Verwende die im Ordner `db` bereitgestellte H2-Datenbankdatei, um Abfragen und das Ballerina-Beispiel zu prüfen
* Verwende den Ansatz mit den Maven-Dependency-Parametern, um den H2-Datenbanktreiber als Plattformabhängigkeit in deiner Ballerina.toml hinzuzufügen
* Stelle keine weitere Abfrage an die Datenbank, um die automatisch generierte ID zu ermitteln


## Testumgebung

* Du kannst die Tests mit `bal test` ausführen; sie laufen dann gegen die angegebene Beispieldatenbank.

## Beispiele

### Beispiel 1

**Eingabe** : dbFilePath: `"./db/gofigure"`, name : `“John Doe”`, city: `“Omaha”`, department : `“Sales”`, age: `24`

**Ausgabe** : `4`

### Beispiel 2

**Eingabe** : dbFilePath: `"./db/invalidDB"`, name : `“John"`, city: `"Colombo"`, department : `"HR"`, age: `25`

**Ausgabe** : `-1`

## Hinweise

* Verwende das Modul [ballerinax/java.jdbc](https://central.ballerina.io/ballerinax/java.jdbc), um mit der Datenbank zu arbeiten
* Sieh dir den Abschnitt [Voraussetzungen](https://lib.ballerina.io/ballerinax/java.jdbc/latest) an, um den JDBC-Treiber als Abhängigkeit hinzuzufügen
* Verwende die Remote-Methode [execute](https://lib.ballerina.io/ballerinax/java.jdbc/latest#Client-execute), um Daten einzufügen
* Schau dir die Beispiele zu [DML- und DDL-Operationen](https://ballerina.io/learn/by-example/mysql-execute-operation/) an
