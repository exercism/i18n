# Gültigkeitsbereichsauflösungsoperator

Mit dem Gültigkeitsbereichsauflösungsoperator (`::`) können wir auf eine Klasse verweisen und so auf ihre Namenskonstanten, statischen Eigenschaften oder statischen Methoden zugreifen.

```php
class MyClass
{
  public const MY_VALUE = 1;
}

// MyClass::class => "MyClass"
// MyClass::MY_VALUE => 1
```

## `self` und `static` mit dem Gültigkeitsbereichsauflösungsoperator verwenden

Manchmal muss ein Objekt auf seinen eigenen Gültigkeitsbereich verweisen. Dafür erlaubt das Schlüsselwort `self` einer Klasse, auf ihren eigenen Gültigkeitsbereich zu verweisen. Wenn du `self` verwendest, löst du die Klasse von ihrem eigenen Namen, was den Code mit der Zeit leichter zu pflegen macht.

```php
class MyClass
{
  public const MY_VALUE = 1;

  public function getMyValue(): int
  {
    return self::MY_VALUE;
  }
}

// (new MyClass)->getMyValue() => 1
```

Verwende das Schlüsselwort `static` zusammen mit dem Gültigkeitsbereichsauflösungsoperator, um die Referenz spät an die aktuelle Nachkommenklasse zu binden.

```php
// Update MyClass:
class MyClass
{
  public const MY_VALUE = 1;

  public function getMyValue(): int
  {
    return static::MY_VALUE;
  }
}
```

## `parent` mit dem Gültigkeitsbereichsauflösungsoperator verwenden

Mit dem Schlüsselwort `parent` verweist du auf Konstanten, Eigenschaften oder Methoden der Elternklasse. Häufig wird es verwendet, um den Konstruktor der Elternklasse aufzurufen, wenn ein Objekt instanziiert wird:

```php
class ChildClass extends ParentClass
{
  public function __construct(): void
  {
    parent::__construct();
  }
}
```

## Zu beachten

### Sichtbarkeit von Konstanten, Eigenschaften und Methoden

Der Gültigkeitsbereichsauflösungsoperator folgt weiterhin den Regeln, die die Sichtbarkeitsmodifizierer `public`, `private` und `protected` vorgeben.
