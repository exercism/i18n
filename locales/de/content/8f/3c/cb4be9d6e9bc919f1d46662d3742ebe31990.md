# Anweisungen

Es ist Valentinstag. Dein Partner hat ein paar Ideen für Aktivitäten und bittet dich, jede davon zu bewerten: `yes`, `no` oder `maybe`.

Aktivitäten werden als 2-elementige Arrays `{ tag value }` dargestellt, wobei `tag` eines von `board-game`, `chill`, `movie`, `restaurant` oder `walk` ist.

| Aktivität                 | Form                        |
| ------------------------- | --------------------------- |
| Ein Brettspiel spielen    | `{ board-game f }`          |
| Chillen                   | `{ chill f }`               |
| Einen Film des Genres `genre` ansehen | `{ movie genre }` |
| In einem `cuisine`-Lokal essen | `{ restaurant cuisine }` |
| `km` Kilometer laufen     | `{ walk km }`               |

Das Genre ist eines von `crime`, `horror`, `romance`, `thriller`. Die Küche ist `korean` oder `turkish`.

## 1. Bewerte die Küche

Definiere `rate-restaurant`, das eine Küche vom Stack nimmt und deine Bewertung zurückgibt:

- `korean` → `yes`
- `turkish` → `maybe`

```factor
korean rate-restaurant .   ! => yes
turkish rate-restaurant .  ! => maybe
```

## 2. Bewerte das Filmgenre

Definiere `rate-movie`, das ein Genre nimmt und zurückgibt:

- `romance` → `yes`
- alles andere → `no`

```factor
romance rate-movie .   ! => yes
horror rate-movie .    ! => no
```

## 3. Bewerte den Spaziergang

Definiere `rate-walk`, das eine Anzahl Kilometer nimmt und zurückgibt:

- mehr als `11` → `yes`
- mehr als `6`, bis zu `11` → `maybe`
- andernfalls → `no`

```factor
12 rate-walk .   ! => yes
8 rate-walk .    ! => maybe
3 rate-walk .    ! => no
```

## 4. Bewerte die Aktivität

Definiere `rate-activity`, das eine `{ tag value }`-Aktivität vom Stack nimmt und deine Bewertung zurückgibt. Verwende die obigen Hilfsfunktionen wieder:

- `board-game`, `chill` → immer `no`
- `movie` → an `rate-movie` delegieren
- `restaurant` → an `rate-restaurant` delegieren
- `walk` → an `rate-walk` delegieren

```factor
{ restaurant turkish } rate-activity .   ! => maybe
{ movie horror } rate-activity .         ! => no
{ walk 12 } rate-activity .              ! => yes
{ board-game f } rate-activity .         ! => no
```

## 5. Zähle die Zustimmungen

Definiere `approval-counts`, das eine Liste von Aktivitäten nimmt und ein 3-elementiges Array `{ yes-count maybe-count no-count }` zurückgibt, das angibt, wie viele jeweils so bewertet wurden.

```factor
{ { restaurant korean } { restaurant turkish } { walk 3 } { movie romance } }
approval-counts .
! => { 2 1 1 }
```
