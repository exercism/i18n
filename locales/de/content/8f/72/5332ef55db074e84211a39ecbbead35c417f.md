## Anleitung

Deine Aufgabe ist es, die perfekten Labyrinthe für Mickey und Minerva zu erzeugen, also solche mit nur einer Lösung und ohne isolierte Bereiche.
Folgendes solltest du wissen:

- Das Labyrinth hat eine rechteckige Form mit einer Öffnung am Anfang und am Ende.
- Das Labyrinth besteht aus Räumen und Gängen, die sich im rechten Winkel schneiden.
- Das Programm soll zwei Parameter akzeptieren: Zeilen und Spalten. Das Labyrinth soll zwischen 5 und 100 Zellen groß sein.
- Ein Labyrinth, das `x` Spalten breit und `y` Zeilen hoch ist, sollte `2x + 1` Zeichen breit und `2y + 1` Zeichen hoch sein.
- Wenn kein Seed angegeben wird, erzeuge ein zufälliges Labyrinth. Wenn derselbe Seed mehrmals angegeben wird, sollte das resultierende Labyrinth jedes Mal dasselbe sein.
- Verwende [Rahmenzeichen][Box-drawing], um Wände zu zeichnen, und ein Pfeilsymbol (⇨) für den Eingang links und den Ausgang rechts.

Zeit, ein paar perfekte Labyrinthe für diese abenteuerlustigen Mäuse zu erschaffen!

### Beispiele

1. Das kleine quadratische Labyrinth mit 5x5 Zellen (oder 11x11 Zeichen)
```text
	┌───────┬─┐
	│       │ │
	│ ┌─┬── │ │
	│ │ │   │ ⇨
	│ │ │ ──┤ │
	⇨ │ │   │ │
	┌─┤ └── │ │
	│ │     │ │
	│ │ ────┘ │
	│         │
	└─────────┘
```
2. Das rechteckige Labyrinth mit 6x18 Zellen
```text
	┌───────────┬─────────┬───────────┬─┐
	│           │         │           │ │
	│ ┌───────┐ │ ┌─┐ ──┐ └───┐ ┌───┐ │ │
	│ │       │ │ │ │   │     │ │   │   ⇨
	│ └─┐ ┌─┐ │ │ │ ├── ├───┐ │ │ ──┼── │
	│   │ │ │   │   │   │   │ │ │   │   │
	└── │ │ ├───┴───┤ ┌─┘ ┌─┘ │ ├── │ ──┤
	⇨   │   │       │ │   │   │ │   │   │
	┌─┬─┴─┐ └─┐ ┌─┐ │ └─┐ │ ┌─┘ │ ──┴─┐ │
	│ │   │   │ │ │ │   │   │   │     │ │
	│ │ │ └── │ │ │ └── │ ──┘ ┌─┘ ──┐ │ │
	│   │       │       │     │     │   │
	└───┴───────┴───────┴─────┴─────┴───┘
```
