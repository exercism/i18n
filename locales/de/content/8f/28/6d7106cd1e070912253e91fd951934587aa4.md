# Einführung

`try..rescue` zu verwenden, ist ein mächtiges Konstrukt, um Fehler abzufangen, wenn sie auftreten. Wenn du Fehler abfängst, können Funktionen bei Bedarf definierte Werte zurückgeben. Das `try..rescue`-Konstrukt bietet uns außerdem zwei zusätzliche Möglichkeiten, die wir nutzen können:

- der `else`-Block
  - Wenn der try-Block erfolgreich ist, wird das Ergebnis mit diesem Block abgeglichen.
- der `after`-Block
  - Egal, ob der try-Block erfolgreich ist oder eine Ausnahme auslöst, der Code im `after`-Block wird immer ausgeführt, solange das Programm an dieser Stelle läuft.
  - Das Ergebnis des `after`-Blocks wird nicht an den aufrufenden Gültigkeitsbereich zurückgegeben.

```elixir
try do
  :a
rescue
  _ -> :error
else
  :a -> :success
after
  :some_action
end

# => :success
```
