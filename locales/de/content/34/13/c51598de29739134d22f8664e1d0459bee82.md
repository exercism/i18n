# Anleitung

In dieser Übung schreibst du Code, um die Produktion an einem Fließband in einer Autofabrik zu analysieren.
Die Geschwindigkeit des Fließbands kann von `0` (aus) bis `10` (Maximum) reichen.

Bei der niedrigsten Geschwindigkeit (`1`) werden pro Stunde `221` Autos produziert.
Die Produktion steigt linear mit der Geschwindigkeit.
Bei einer Geschwindigkeit von `4` sollten also `4 * 221 = 884` Autos pro Stunde produziert werden.
Höhere Geschwindigkeiten erhöhen jedoch die Wahrscheinlichkeit, dass fehlerhafte Autos produziert werden, die dann aussortiert werden müssen.

Du hast drei Aufgaben.

## 1. Berechne die Erfolgsrate

Implementiere die (_statische_) Methode `AssemblyLine.SuccessRate()`, um für eine gegebene Geschwindigkeit den Anteil der fehlerfrei hergestellten Teile zu berechnen.
Die folgende Tabelle zeigt, wie die Geschwindigkeit die Erfolgsrate beeinflusst:

- `0`: 0 % Erfolgsrate.
- `1` bis `4`: 100 % Erfolgsrate.
- `5` bis `8`: 90 % Erfolgsrate.
- `9`: 80 % Erfolgsrate.
- `10`: 77 % Erfolgsrate.

```csharp
AssemblyLine.SuccessRate(10)
// => 0.77
```

## 2. Berechne die Produktionsrate pro Stunde

Implementiere die (_statische_) Methode `AssemblyLine.ProductionRatePerHour()`, um die Produktionsrate des Fließbands pro Stunde zu berechnen und dabei die Erfolgsrate zu berücksichtigen:

```csharp
AssemblyLine.ProductionRatePerHour(6)
// => 1193.4
```

Beachte, dass der zurückgegebene Wert ein `double` ist.

## 3. Berechne die Anzahl der pro Minute produzierten funktionierenden Teile

Implementiere die (_statische_) Methode `AssemblyLine.WorkingItemsPerMinute()`, um zu berechnen, wie viele funktionierende Autos pro Minute produziert werden:

```csharp
AssemblyLine.WorkingItemsPerMinute(6)
// => 19
```

Beachte, dass der zurückgegebene Wert ein `int` ist.
