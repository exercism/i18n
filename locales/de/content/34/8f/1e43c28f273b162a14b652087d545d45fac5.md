# Einführung

Boolesche Werte werden in Java durch den Typ `boolean` dargestellt. Ihre Werte können entweder `true` oder `false` sein.

Java kennt drei boolesche Operatoren:  

- `!` (NOT): negiert den booleschen Wert  
- `&&` (AND): nimmt zwei boolesche Werte und ergibt wahr, wenn beide wahr sind  
- `||` (OR): ergibt wahr, wenn einer der beiden booleschen Werte wahr ist  

## Beispiele

```java
!true // => false
!false // => true
true && false // => false
true && true // => true
false || false // => false
false || true // => true
```
