# Allgemein

Denk daran, dass du bereits fertige Funktionen immer wiederverwenden oder aufrufen kannst, wenn du neue schreibst.

## 1. Zusätzliche Stunden ermitteln

- Hier dreht sich alles darum, den _Rest_ zu berechnen, der nach einer ganzzahligen Division übrig bleibt.
- Schau dir [`divmod()`][divmod] an und suche nach einem Operator, der etwas Ähnliches macht.

## 2. kW-Wert ermitteln

- Denk daran, [`round()`][round] eine Anzahl von _Nachkommastellen_ zu übergeben, sonst bekommst du als Ergebnis eine ganze Zahl zurück.

## 3. kWh-Wert ermitteln

- Das Ergebnis einer Division von `int` durch `float` ist immer `float`.
- Um bei einer Division nur einen ganzzahligen Wert zu erhalten, verwendest du die [_Floor-Division_][floor], die die Nachkommastellen abschneidet.

## 4. Effizienz ermitteln

- Das Ergebnis einer Division von `int` durch `float` ist immer `float`.

## 5. Kosten ermitteln

- Vielleicht ist es sinnvoll, hier andere Funktionen, die du schon fertiggestellt hast, _wiederzuverwenden_ oder aufzurufen.
- Das Ergebnis einer Division von `int` durch `float` ist immer `float`.

[floor]: https://docs.python.org/3/glossary.html#term-floor-division
