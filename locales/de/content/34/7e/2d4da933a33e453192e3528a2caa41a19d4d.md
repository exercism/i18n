# Hinweise

## Allgemein

- Eine Schleife in x86-64 erreicht man, indem man zu einem vorherigen Label springt, und man kann sie verlassen, indem man zu einem Label außerhalb davon springt.
- Um auf Inhalte zuzugreifen, die unter einer Adresse im Speicher liegen, musst du sie mit `[]` dereferenzieren.
- Das Präfix für den Zugriff auf 4-Byte-Werte im Speicher ist `dword`.
- Ein Array wird durch seine Adresse dargestellt, die in x86-64 ein 8-Byte-Wert ist.
- Wenn eine aufgerufene Funktion ein Register verändert, musst du jeden Wert in diesem Register sichern, der später noch gebraucht wird.
