# Tests

## Tests ausführen

Der Haxe-Track setzt auf das Test-Framework [Buddy](https://github.com/ciscoheat/buddy).
Du installierst es so:

```bash
haxelib install buddy
```

Um die Tests auszuführen, führe den folgenden Befehl aus:

```bash
haxe test.hxml
```

In der Testdatei markiert jeder describe-Block einen Abschnitt der Übungstests, und jeder Test ist ein `it`- oder `xit`-Block.
`it`-Blöcke werden ausgeführt, wenn du die Tests laufen lässt, `xit`-Blöcke sind dagegen Tests, die noch ausstehen.
Wenn du eine Lösung einsendest, führt der Exercism-Test-Runner alle `it`- oder `xit`-Blöcke aus.
Wenn du lokal arbeitest, wird standardmäßig nur der erste Test ausgeführt.
Um andere Tests auszuführen, ändere die entsprechenden `xit`-Blöcke in `it`-Blöcke um und führe `haxe test.hxml` erneut aus.

Außerdem kann es sein, dass einige Übungen zusätzliche Bibliotheken erfordern, die mit haxelib installiert werden müssen.
Wenn das der Fall ist, findest du einen Hinweis in den Übungsanweisungen.

## Die Übung lösen

Eine Übung zu lösen heißt, alle ihre Tests zu bestehen.
Damit du leichter loslegen kannst, bringt jede Übung eine Datei mit einer Stub-Implementierung mit.
Du kannst diese Datei als Ausgangspunkt nutzen, um deine Lösung aufzubauen.
Du kannst diese Datei gerne löschen oder ändern, wenn du denkst, dass es das Richtige ist.
Versuche, dich jeweils auf einen einzelnen Test zu konzentrieren, während du auf die Lösung hinarbeitest.
