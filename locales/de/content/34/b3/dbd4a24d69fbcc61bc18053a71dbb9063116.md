# Ergänzung zur Anleitung

## Hinweise zur Implementierung

Ein Baum-Objekt hat zwei Attribute:

- `String` label
- `List<Tree>` children

Das Testprogramm erzeugt Bäume durch wiederholtes Anwenden der Builder-Funktion
`Tree.of`. Zum Beispiel konstruiert die Anweisung

```java
Tree tree = Tree.of("a", List.of(Tree.of("b"), Tree.of("c", List.of(Tree.of("d")))));
```

den folgenden Baum:

```text
      "a"
       |
    -------
    |     |
   "b"   "c"
          |
         "d"
```

Du kannst davon ausgehen, dass es in den Testbäumen keine doppelten Werte gibt.

---

Die Methoden `FromPov` und `PathTo` sind der interessante Teil der Übung.

Die Methode `FromPov` nimmt ein String-Argument `from` entgegen, das einen Knoten im
Baum über seinen Wert angibt. Sie soll einen Baum zurückgeben, in dessen Wurzel der
Wert `from` steht. Du kannst den ursprünglichen Baum verändern und ihn zurückgeben
oder einen neuen Baum erzeugen und diesen zurückgeben. Wenn du einen neuen Baum
zurückgibst, darfst du den ursprünglichen Baum verbrauchen oder zerstören. Natürlich
ist es schön, ihn unverändert zu lassen.

Die Methode `PathTo` nimmt zwei String-Argumente `from` und `to` entgegen, die zwei
Knoten im Baum über ihre Werte angeben. Sie soll den kürzesten Pfad im Baum vom
ersten zum zweiten Knoten zurückgeben.

## Exception-Meldungen

Manchmal ist es notwendig, [eine Exception zu werfen](https://docs.oracle.com/javase/tutorial/essential/exceptions/throwing.html).
Wenn du das tust, solltest du immer eine **aussagekräftige Fehlermeldung** angeben,
die zeigt, was die Fehlerursache ist. Das macht deinen Code lesbarer und hilft beim
Debuggen erheblich.

Diese Übung erfordert, dass du das [throw-Schlüsselwort](https://docs.oracle.com/javase/tutorial/essential/exceptions/throwing.html)
verwendest, um mehrere `UnsupportedOperationException` zu „werfen“, wenn der Klasse
`Tree()` ein Baum übergeben wird, der nicht neu ausgerichtet werden kann, oder wenn
zwischen einem `start node` und einem `end node` kein Pfad gefunden werden kann.
Die Tests bestehen nur, wenn du sowohl `throw` verwendest als auch eine Meldung für
die `exception` angibst.

Um eine `UnsupportedOperationException` mit einer Meldung zu werfen, gibst du die
Meldung als Argument für den `exception`-Typ an:

```java
// when a tree cannot be oriented to a new node POV
throw new UnsupportedOperationException("Tree could not be reoriented");

// when a path cannot be found between a start and end node on the tree.
throw new UnsupportedOperationException("No path found");
```
