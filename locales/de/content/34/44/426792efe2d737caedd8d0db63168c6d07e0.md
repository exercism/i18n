# Einführung

## Nil

`Nil` ist in Gleam ein Typ mit einem einzigen Wert, der ebenfalls `Nil` heißt. Er ähnelt `void` in anderen Sprachen insofern, als er verwendet wird, wenn eine Funktion keinen passenderen Wert zurückzugeben hat.

```gleam
io.println("Hello, Joe!")
// -> Nil
```

Werte in Gleam sind nicht „nil-able“ oder „nullable“ wie in manchen anderen Sprachen. Ein Wert kann nur dann `Nil` sein, wenn sein Typ `Nil` ist, und ein Wert jeden anderen Typs kann niemals `Nil` sein.

## IO

Wie die meisten Programmiersprachen hat Gleam „Seiteneffekte“, sodass Funktionen den Zustand der Welt lesen und ändern können und außerdem einen Wert zurückgeben.

Das Modul `gleam/io` in der Gleam-Standardbibliothek bietet Funktionen zum Ausgeben von Strings auf der Konsole.

```gleam
io.println("Hello, Joe!")
// Hello, Joe!
// -> Nil
```

Andere Pakete können weitere IO-Funktionen bereitstellen, etwa `simplifile`, ein Paket mit Funktionen zum Lesen und Schreiben von Dateien.

```gleam
simplifile.read("favourite-colour.txt")
// -> Ok("Pink\n")
```
