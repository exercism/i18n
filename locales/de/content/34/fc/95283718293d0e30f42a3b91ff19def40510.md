# Anleitung

Du arbeitest weiter an dem Lagerverwaltungssystem, das du zuvor gebaut hast. Seit du `OpenStruct` und Block-Kurzschreibweisen entdeckt hast, hast du beschlossen, den Code ein wenig zu refaktorieren. Statt die Artikel als Hashes zu speichern, wirst du deine neu entdeckten Fähigkeiten einsetzen.

## 1. Ermögliche das Abrufen von Artikeln

Du möchtest weiterhin die Liste der Artikel auf Lager abrufen, aber diesmal sollen es Objekte sein, auf denen Methoden aufgerufen werden können.

```ruby
inventory = BoutiqueInventory.new([
  {price: 65.00, name: "Maxi Brown Dress", quantity_by_size: {s: 3, m: 7, l: 8, xl: 4}},
  {price: 50.00, name: "Red Short Skirt", quantity_by_size: {}},
  {price: 29.99, name: "Black Short Skirt", quantity_by_size: {s: 1, xl: 4}},
  {price: 20.00, name: "Bamboo Socks Cats", quantity_by_size: {s: 7, m: 2}}
])

inventory.items.first.name
# => "Maxi Brown Dress"

inventory.items.first.price
# => 65

inventory.items.size
# => 4
```

## 2. Refaktoriere `item_names`

Refaktoriere `item_names`, sodass die Methode statt Hashes die neue Block-Kurzschreibweise verwendet, die du gelernt hast.
Zur Erinnerung: Die Methode sollte zurückgeben:

```ruby
BoutiqueInventory.new([
  {price: 65.00, name: "Maxi Brown Dress", quantity_by_size: {s: 3, m: 7, l: 8, xl: 4}},
  {price: 50.00, name: "Red Short Skirt", quantity_by_size: {}},
  {price: 29.99, name: "Black Short Skirt", quantity_by_size: {s: 1, xl: 4}},
  {price: 20.00, name: "Bamboo Socks Cats", quantity_by_size: {s: 7, m: 2}}
]).item_names

# => ["Bamboo Socks Cats", "Black Short Skirt", "Maxi Brown Dress", "Red Short Skirt"]
```

## 3. Refaktoriere `total_stock`

Refaktoriere `total_stock`, sodass die Methode die OpenStruct-Methode verwendet, anstatt auf einen Hash zu verweisen.
Zur Erinnerung: Die Methode sollte zurückgeben:

```ruby
BoutiqueInventory.new([
  {price: 65.00, name: "Maxi Brown Dress", quantity_by_size: {s: 3, m: 7, l: 8, xl: 4}},
  {price: 50.00, name: "Red Short Skirt", quantity_by_size: {}},
  {price: 29.99, name: "Black Short Skirt", quantity_by_size: {s: 1, xl: 4}},
  {price: 20.00, name: "Bamboo Socks Cats", quantity_by_size: {s: 7, m: 2}}
]).total_stock

# => 36
```
