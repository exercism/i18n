# Einführung in Variablen

## Variablen

_Variablen_ sind ein Ort, um Daten zu speichern.
Bash kennt zwei Arten von Daten: Strings und Arrays.
Über Arrays sprechen wir später.

Du weist einer Variablen so einen Wert zu:
```bash
name="value"
```

~~~~exercism/note
**Wichtig**: Rund um das Gleichheitszeichen dürfen _keine Leerzeichen_ stehen!

Stehen dort doch Leerzeichen, wie in diesem Beispiel,

```bash
x = 10
```

dann ruft bash den **Befehl** `x` mit den **zwei Argumenten** `=` und `10` auf!
~~~~

Variablen werden auch _Parameter_ genannt.
Die beiden Begriffe werden in diesem Dokument synonym verwendet.

Einige wichtige Parameter, die bash verwendet oder setzt, sind:

* `PATH` -- eine durch Doppelpunkte getrennte Liste von Verzeichnissen, in denen externe Befehle gesucht werden.
* `IFS` -- der „interne Feldtrenner“.
   Wie er verwendet wird, sehen wir weiter unten.
* `PWD` -- dein aktuelles Arbeitsverzeichnis.
   Es hat denselben Wert wie die Ausgabe des Befehls `pwd`.
* `RANDOM` -- eine pseudozufällige Ganzzahl zwischen 0 und 32767.
* `BASH_VERSION` -- der String mit der Version der laufenden bash-Instanz.

## Variablennamen

Ein Variablenname besteht aus _Großbuchstaben, Kleinbuchstaben, Zahlen und Unterstrich_.
Er darf nicht mit einer Zahl beginnen.

~~~~exercism/caution
Es ist bewährte Praxis, **Variablennamen komplett in Großbuchstaben zu vermeiden**.
Die Shell verwendet diese Konvention für ihre Parameter, und du willst nicht versehentlich Shell-Parameter überschreiben, die eine besondere Bedeutung haben.

## Parameterexpansion

Den Wert eines Parameters bekommst du mit der Syntax `$varname`.

```bash
x=10
echo "The value of x is $x"
```

Damit der Variablenname nicht mit dem umgebenden Text verwechselt wird, kannst du den Variablennamen in geschweifte Klammern setzen.
Um zum Beispiel den String `10x10` auszugeben:

```bash
echo "${x}x$x"
# or
echo "${x}x${x}"
```

Einige [Styleguides][google-style-guide] empfehlen, geschweifte Klammern in den meisten Fällen zu verwenden, weil das lesbarer und/oder konsistenter ist.

## Positionsparameter

Wie wir in der Lektion [Befehle und Argumente][cmds-args] besprochen haben, können Befehle Argumente entgegennehmen.
Bash-Skripte sind da keine Ausnahme.
Die Argumente der aktuellen bash-Instanz heißen _Positionsparameter_.
Du rufst sie mit diesen speziellen Parametern ab:

* `$1` -- der erste Positionsparameter
* `$2` ... `$9` -- die weiteren Parameter
* `${10}` ... -- bei zweistelligen Zahlen sind geschweifte Klammern nötig.
* `$0` -- der Name des aktuellen Skripts.

Argumente einer Shell-Funktion sind ebenfalls Positionsparameter und werden genauso behandelt.
Mehr über Funktionen sehen wir in einer späteren Lektion.

### Spezielle Positionsparameter

Es gibt einige _spezielle Parameter_, die dir im Umgang mit den Positionsparametern helfen.

* `$#` expandiert zur _Anzahl_ der Positionsparameter.
* `"$@"` expandiert zur Liste aller Positionsparameter, jeder als einzelnes Wort.
* `"$*"` expandiert zu einem einzelnen String, in dem alle Positionsparameter durch ein Zeichen verbunden sind.
  * Das Verbindungszeichen ist _das erste Zeichen_ der Variable `$IFS`, standardmäßig ein Leerzeichen.

`"$@"` ist der sicherste Weg, Positionsparameter an einen anderen Befehl zu übergeben und sie dabei korrekt zu quoten.
So durchläufst du auch die Positionsparameter:

```bash
for arg in "$@"; do
    do_something_with "$arg"
done
```

In der Praxis wird `"$@"` häufiger verwendet als `"$*"`.

## Befehlssubstitution

Eine sehr häufige Operation in Bash-Skripten ist es, die Ausgabe eines Befehls aufzufangen und in einer Variablen zu speichern.
Dafür verwendest du die _Befehlssubstitution_.

```bash
var=$(command)
```

Um zum Beispiel einen String in Großbuchstaben umzuwandeln, geht das so:

```bash
text="Hello world!"
uppercase=$(echo "$text" | tr '[:lower:]' '[:upper:]')
echo "$uppercase"
# => HELLO WORLD!
```

## Mehr zur Parameterexpansion

Bash hat viele eingebaute Möglichkeiten, um Variablen und Strings zu bearbeiten, sodass du keine externen Befehle aufrufen musst.

* Text in Großbuchstaben umwandeln.
  Im vorigen Abschnitt habe ich gezeigt, wie du mit `tr` Text in Großbuchstaben umwandelst.
  In bash geht das so:

  ```bash
  echo "${text^^}"
  ```

  Entsprechend wandelt `${text,,}` den Wert in Kleinbuchstaben um.

* Einen Standardwert angeben, falls die Variable leer ist.

  ```bash
  default="nothing here"
  result=""
  echo "${result:-$default}"
  # => nothing here
  ```

* Suchen und Ersetzen.

  ```bash
  text="Hello world!"
  echo "${text//[aeiou]/X}"
  # => HXllX wXrld!"
  ```

Es gibt noch viele weitere interessante Parameterexpansionen: einen Teilstring extrahieren, die Länge eines Strings ermitteln, einen Standardwert _zuweisen_, Text vom Anfang oder Ende des Werts entfernen und mehr.
Lies darüber [im Handbuch][param-exp].
