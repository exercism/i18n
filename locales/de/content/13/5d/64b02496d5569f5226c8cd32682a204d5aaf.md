# Ergänzung zu den Anweisungen

## Register

| Register | Verwendung | Typ      | Beschreibung                              |
| -------- | ---------- | -------- | ----------------------------------------- |
| `$a0`    | Eingabe    | Adresse  | Array von Faktorwörtern                   |
| `$a1`    | Eingabe    | Ganzzahl | Anzahl der Faktoren                       |
| `$a2`    | Eingabe    | Ganzzahl | Obergrenze                                |
| `$v0`    | Ausgabe    | Ganzzahl | Summe der Vielfachen innerhalb der Obergrenze |
| `$t0-9`  | temporär   | beliebig | dient als temporärer Speicher             |
