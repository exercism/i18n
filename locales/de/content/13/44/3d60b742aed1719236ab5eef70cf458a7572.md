# Anweisungen

Wir bleiben beim Thema des Spiels _Zauberer und Krieger_ und ergänzen jetzt eine universelle Methode zum Würfeln. Dabei handelt es sich um den traditionellen 18-seitigen Würfel mit den Zahlen von 1 bis 18. Außerdem erzeugen die Spieler eine Zauberstärke.

## 1. Ermögliche einem Spieler von _Zauberer und Krieger_, einen Würfel zu werfen

Implementiere eine Methode `RollDie()` in der Klasse `Player`.

```csharp
var player = new Player();
player.RollDie();
// => >= 1 <= 18
```

## 2. Spieler brauchen ihre Stärke. Schaffe eine Möglichkeit, die Zauberstärke zu erzeugen

Implementiere eine Methode `GenerateSpellStrength()` in der Spielerklasse. Die Zauberstärke liegt zwischen 0.0 und 100.0, wobei 100.0 nicht enthalten ist.

Beachte, dass die Zauberstärke eine reelle Zahl sein muss (keine Ganzzahl), um die Wahrscheinlichkeit eines Gleichstands zu verringern, wenn die Stärken zweier Gegner verglichen werden.

```csharp
var player = new Player();
player.GenerateSpellStrength();
// => >= 0.0 < 100.0
```
