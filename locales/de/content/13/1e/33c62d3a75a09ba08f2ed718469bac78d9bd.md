# Installation

Der Track für die Sprache C setzt voraus, dass du die folgende Software auf deinem System installiert hast:

* Einen modernen C-Compiler
* Das Build-Tool Make

Apples Xcode IDE vereint den Compiler und das native Build-System in einer einzigen IDE (integrierte Entwicklungsumgebung).
Linux-Umgebungen stellen den Compiler und das native Build-System normalerweise als getrennte Kommandozeilen-Tools bereit.

## Linux

Unter Linux brauchst du gcc oder clang als Compiler, und für den nativen Build wird `make` benötigt.
Make ist auf den meisten Unix-Systemen vorinstalliert, aber höchstwahrscheinlich über deinen Paketmanager verfügbar.
Auf Debian- und Ubuntu-basierten Distributionen kannst du alles, was du brauchst, mit `sudo apt-get install build-essential` installieren, falls es noch nicht vorhanden ist.

## MacOS

Unter MacOS kannst du gcc oder clang mit [Homebrew][] über `brew install gcc` oder `brew install llvm` installieren.

## Windows

Wenn du Windows 10 verwendest, empfehlen wir dir das [Windows Subsystem for Linux][] und dann die Anleitung für Linux weiter oben.

Wenn du eine ältere Windows-Version verwendest oder WSL Bash für dich nicht verfügbar ist, kannst du [MSYS][] oder [mingw-w64][] verwenden.

[Homebrew]: https://brew.sh
[Windows Subsystem for Linux]: https://docs.microsoft.com/en-gb/windows/wsl/about
[MSYS]: https://www.msys2.org
[mingw-w64]: http://mingw-w64.org
