# Boolesche Werte

Haskell hat einen Typ namens [`Bool`][bools].
Er ist eine Aufzählung von `True` und `False`.

## Logische Operatoren

Haskell hat drei logische Operatoren (`not`, `||`, `&&`), die boolesche Werte kombinieren und Ausdrücke bilden, die unterschiedliche Werte liefern.

### Und(`&&`)

Der [_und_-Operator][and] in Haskell wird durch `&&` dargestellt und gibt `True` zurück, wenn beide Werte `True` sind; andernfalls gibt er `False` zurück.
Wenn du den _und_-Operator verwendest, steht ein boolescher Wert rechts von `&&` und ein anderer links.

```haskell
True && True
-- -> True

True && False
-- -> False
```

### Oder(`||`)

Der [_oder_-Operator][or] in Haskell wird durch `||` dargestellt und gibt `True` zurück, wenn **mindestens einer** der angegebenen Werte `True` ist.
Wenn beide Werte `False` sind, gibt er `False` zurück.
Wenn du den _oder_-Operator verwendest, sollte ein boolescher Wert rechts von `||` stehen und ein anderer links.

```haskell
True || True
-- -> True

True || False
-- -> True

False || False
-- -> False
```

### Not(`not`)

Der _not_-Operator in Haskell wird durch `not` dargestellt und gibt `True` zurück, wenn der gegebene boolesche Wert `False` ist, und gibt `False` zurück, wenn `True` übergeben wird.
Wenn du den _not_-Operator verwendest, sollte ein boolescher Wert nach dem Operator (`not`) stehen.

```haskell
not True
-- -> False

not False
-- -> True
```

## Runde Klammern verwenden (`()`)

Wenn du mit booleschen Werten arbeitest, kannst du runde Klammern verwenden, um zu entscheiden, welche booleschen Werte zuerst ausgewertet werden.
Das Ergebnis kann sich je nach Verwendung der Klammern unterscheiden.
In Haskell wird zuerst ausgewertet, was in Klammern steht.

```haskell
True && False && False || True
-- -> True

True && False && (False || True)
-- -> False
```

Da zuerst ausgewertet wird, was in Klammern steht, wird der _not_-Operator im folgenden Beispiel auf den Ausdruck innerhalb der Klammern angewendet.

```haskell
not True && False
-- -> False

not (True && False)
-- -> True
```

~~~~exercism/note
Du solltest Klammern nur verwenden, wenn sie das Ergebnis beeinflussen; andernfalls solltest du sie weglassen.
~~~~
