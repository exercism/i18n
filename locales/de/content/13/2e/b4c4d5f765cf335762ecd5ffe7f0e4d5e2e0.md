# Hilfe

## Die Tests ausführen

Der Factor-Track verwendet **Factor 0.101**. Führe nach der
[Installation](https://exercism.org/docs/tracks/factor/installation)
im Verzeichnis dieser Übung Folgendes aus:

```
factor -roots=. -run=exercism-tools <exercise>
```

Zum Beispiel für `hello-world`:

```
factor -roots=. -run=exercism-tools hello-world
```

Jede Übung bringt ein kleines mitgeliefertes `exercism-tools`-Vokabular mit,
das den Testlauf steuert. Der Runner endet mit Status 0, wenn alle Tests
bestehen, und mit einem Status ungleich null plus diagnostischer Ausgabe,
wenn ein Test fehlschlägt.

### Übersprungene Tests

Standardmäßig wird nur der erste Test ausgeführt. Der Mechanismus ist die
Zeile `STOP-HERE` in der Testdatei: Beim Parsen weist sie den Lexer von
Factor an, alles darunter zu ignorieren, sodass der Runner nur die Tests
darüber sieht. Sobald dein erster Test besteht, kannst du weitere Tests auf
zwei Arten aktivieren:

- **Lösche die Zeile `STOP-HERE`**, um alle verbleibenden Tests auf einmal
  zu aktivieren.
- **Verschiebe die Zeile `STOP-HERE` weiter nach unten**, um Tests einzeln
  zu aktivieren, oder eine Aufgabe nach der anderen. Konzeptübungen
  gruppieren ihre Tests unter `TASK:`-Markern. `STOP-HERE` direkt vor das
  nächste `TASK:` zu setzen, ist ein natürlicher Schritt.

Wenn alle Tests bestehen, hast du die Übung gelöst.

## Deine Lösung einreichen

Im Verzeichnis der Übung:

```
exercism submit <exercise>/<exercise>.factor
```

Zum Beispiel:

```
exercism submit hello-world/hello-world.factor
```

Wenn die Datei `.meta/config.json` der Übung mehr als eine Lösungsdatei
auflistet (manche Konzeptübungen verteilen eine Lösung auf ein
Hilfs-Subvokabular), übergib jede Datei, die du geändert hast, an
`exercism submit`.

## Unvollständige Lösungen einreichen

Du kannst eine Lösung auch mit fehlschlagenden Tests einreichen. So siehst
du, wie andere die Übung angegangen sind, und kannst um Mentor-Feedback zu
dem bitten, was du bisher hast.

## Weitere Hilfe bekommen

- Die [Kategorie Factor im Exercism-Forum](https://forum.exercism.org/c/programming/factor/)
  ist der beste Ort für Fragen und Feedback zum Track.
- Der [Exercism-Discord](https://exercism.org/r/discord) hat
  Kanäle für allgemeine Hilfe und für einzelne Tracks.
- Die offizielle Dokumentation von Factor ist durchsuchbar und vollständig. Zwei gute Einstiegspunkte:
  - [Das Factor-Handbuch](https://docs.factorcode.org/content/article-handbook.html):
    Nachschlagewerk, nach Vokabularen geordnet.
  - [Das Factor-Cookbook](https://docs.factorcode.org/content/article-cookbook.html):
    kurze, idiomatische Beispiele nach Thema.
- Andrea Ferrettis
  [Factor-Tutorial](https://andreaferretti.github.io/factor-tutorial/)
  ist eine schnelle, freundliche Einführung in die Sprache und die
  Entwicklungsumgebung.
