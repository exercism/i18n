# Anleitung

Wandle eine Phrase in ihr Akronym um.

Techies lieben ihre TLA (Three Letter Acronyms)!

Hilf mit, etwas Jargon zu erzeugen: Schreibe ein Programm, das einen langen Namen wie Portable Network Graphics in sein Akronym (PNG) umwandelt.

Satzzeichen werden so behandelt: Bindestriche trennen Wörter (wie Leerraum); alle anderen Satzzeichen kannst du aus der Eingabe entfernen.

Zum Beispiel:

| Eingabe                   | Ausgabe |
| ------------------------- | ------- |
| As Soon As Possible       | ASAP    |
| Liquid-crystal display    | LCD     |
| Thank George It's Friday! | TGIF    |
