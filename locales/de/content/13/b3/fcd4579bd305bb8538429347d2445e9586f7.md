# Über

Ein String in Factor ist eine Zeichenfolge und teilt das vollständige
[`sequences`-Protokoll][sequence-protocol] (`length`, `nth`, `head`,
`tail`, `map`, `filter` und so weiter) zusammen mit seinen eigenen
Vokabularen.

```factor
"hello"  length .       ! => 5
"hello"  reverse .      ! => "olleh"
"abcdef" 3 head .       ! => "abc"
```

Die String-spezifischen Wörter stecken größtenteils in [`splitting`][splitting],
[`ascii`][ascii] und [`unicode`][unicode]:

| Wort         | Vokabular         | Was es macht                          |
|--------------|---------------|---------------------------------------|
| `split1`     | [`splitting`][splitting]   | beim ersten Vorkommen aufteilen       |
| `split`      | [`splitting`][splitting]   | an jedem Zeichen einer Menge aufteilen |
| `harvest`    | [`sequences`][sequences]   | leere Teile aus einem Aufteilungsergebnis verwerfen |
| `replace`    | [`splitting`][splitting]   | einen Teilstring ersetzen             |
| `surround`   | [`sequences`][sequences]   | mit einem Präfix und Suffix umschließen |
| `glue`       | [`sequences`][sequences]   | zwei Strings mit einem Trennzeichen verbinden |
| `join`       | [`sequences`][sequences]   | ein Array von Strings mit einem Trennzeichen verbinden |
| `>lower`     | [`ascii`][ascii]       | in Kleinbuchstaben umwandeln (ASCII)  |
| `>upper`     | [`ascii`][ascii]       | in Großbuchstaben umwandeln (ASCII)   |
| `[ blank? ] trim` | [`sequences`][sequences] | führende und nachfolgende Leerzeichen entfernen |
| `first`, `second`, `third`, `fourth` | [`sequences`][sequences] | die führende Position |
| `first2`, `first3`         | [`sequences`][sequences]   | zwei oder drei führende Positionen entpacken |
| `>string`    | [`strings`][strings]     | eine Folge von Zeichen in einen String umwandeln |
| `1string`    | [`strings`][strings]     | ein einzelnes Zeichen in einen String der Länge 1 umwandeln |
| `CHAR: x`    | parser        | ein Literal für ein einzelnes Zeichen (z. B. `CHAR: A` → `65`) |

Für die Hin- und Rückumwandlung zwischen Zahlen und Strings bietet
[`math.parser`][math.parser] `number>string` und `string>number`. Für die
Ausgabe mit Format-Strings bietet [`formatting`][formatting] `sprintf` und
verwandte Wörter.

Für die Unicode-fähige Umwandlung der Groß- und Kleinschreibung oder die
Klassifizierung von Zeichen verwende die entsprechenden Wörter in
[`unicode`][unicode].
