# Einführung

## Hash-Tabellen

Hash-Tabellen in Common Lisp sind Datenstrukturen zum Speichern assoziativer Daten.
Sie ordnen Schlüsseln (die beliebige Objekte sein können) Werte (die beliebige Objekte sein können) zu.
Andere Sprachen kennen dieses Konzept vielleicht unter Namen wie Map, Dictionary oder Hash.

### Hash-Tabellen erstellen

Hash-Tabellen lassen sich mit der Funktion `make-hash-table` erstellen.

`(make-hash-table) ; => #<HASH-TABLE :TEST EQL :COUNT 0 {10024AD2B3}>`

(Beachte: Die gedruckte Darstellung einer Hash-Tabelle hängt von der Implementierung ab, in deiner REPL kann sie also anders aussehen.)

### Werte über Schlüssel abrufen

Um mit einem Schlüssel einen Wert aus der Hash-Tabelle zu holen, verwendest du die Funktion `gethash`:

```lisp
*h* ; => #<HASH-TABLE :TEST EQL :COUNT 3 {10024AD2B3}>`
(gethash :foo *h*) ; => :bar
                   ;    T
```

`gethash` gibt [mehrere Werte][concept-multiple-values] zurück, die in einem anderen Konzept erklärt werden.

### Werte einfügen

Um einen Wert in eine Hash-Tabelle einzufügen, verwendest du `setf` zusammen mit `gethash`, und zwar so:

`(setf (gethash :foo *hash-table*) :bar) : => :bar`

Damit änderst du den Wert für den Schlüssel `:foo` in der Hash-Tabelle `*hash-table*` zu `:bar`.
Dabei wird der Wert zurückgegeben.

Die Verwendung von `setf` wird in einem anderen Konzept erklärt.
