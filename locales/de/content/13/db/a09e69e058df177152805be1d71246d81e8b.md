# Anweisungen

Dein Netballverein braucht nach jeder Runde eine aktualisierte Tabelle.

Alle vier Aufgaben kommen in die Klasse `NETBALL_LADDER`.

## 1. Tabellenpunkte

Ein Sieg bringt 4 Punkte, ein Unentschieden 2. Eine Niederlage bringt nichts.

```sather
NETBALL_LADDER::ladder_points(3, 1)
-- => 14
```

## 2. Tordifferenz

Erzielte Tore minus kassierte Tore. Sie kann negativ sein.

```sather
NETBALL_LADDER::goal_difference(180, 205)
-- => -25
```

## 3. Volle gespielte Viertel

Ein Viertel dauert 15 Minuten. Wie viele volle Viertel ergeben sich aus einer
gegebenen Anzahl von Minuten?

```sather
NETBALL_LADDER::whole_quarters(38)
-- => 2
```

## 4. Minuten im laufenden Viertel

Bei derselben Anzahl von Minuten: Wie weit sind wir im aktuellen Viertel?

```sather
NETBALL_LADDER::minutes_into_quarter(38)
-- => 8
```
