# Überblick

Eine Gleitkommazahl ist eine Zahl mit null oder mehr Nachkommastellen.
Beispiele sind `4.0`, `0.1`, `3.14`, `-6.4` `16.984025` und `1024.0`.
In Ruby werden Gleitkommazahlen durch die Klasse [Float][Float] umgesetzt.

Eine kurze Einführung in Gleitkommazahlen findest du auf [0.30000000000000004.com][0.30000000000000004.com].

Die [Float Toy Seite][evanw.github.io-float-toy] bietet eine schöne, grafische Erklärung, wie die Bits einer Gleitkommazahl in einen tatsächlichen Gleitkommawert umgewandelt werden.

Um Logik wiederholt auszuführen, kannst du Schleifen verwenden.
In diesem Beispiel ist die `while`-Schleife nützlich, weil sie so lange weiterläuft, _solange_ eine Bedingung einen truthy-Wert ergibt (also nicht `false` oder `nil`).
Ruby hat eine Schleife, die der `while`-Schleife ähnelt.
Sie heißt `until`-Schleife, und du hast sicher schon erraten, was sie macht.
Sie läuft so lange weiter, _bis_ eine boolesche Bedingung `true` ergibt.
In manchen Sprachen gibt es Konstrukte wie `while true`, um ein Stück Code unbegrenzt oft auszuführen.
In Ruby gibt es dafür die `loop`-Schleife.
Obwohl die `loop`-Schleife nicht von einer einzelnen Bedingung abhängt, kannst du sie mit dem Schlüsselwort `return` oder `break` beenden.

Die Methode `#years_before_desired_balance` aus der vorherigen Übung hätte mit jeder der drei genannten Schleifen geschrieben werden können:

## `while`

```ruby
def self.years_before_desired_balance(current_balance, desired_balance)
  years = 0
  while current_balance < desired_balance
    current_balance = annual_balance_update(current_balance)
    years += 1
  end
  years
end
```

## `until`

```ruby
def self.years_before_desired_balance(current_balance, desired_balance)
  years = 0
  until current_balance >= desired_balance
    current_balance = annual_balance_update(current_balance)
    years += 1
  end
  years
end
```

## `loop`

```ruby
def self.years_before_desired_balance(current_balance, desired_balance)
  years = 0
  loop do
    current_balance = annual_balance_update(current_balance)
    years += 1
    return years if current_balance >= desired_balance
  end
end
```

Wie du wahrscheinlich bemerkt hast, hat Ruby keinen Inkrement-Operator (`i++`) wie manche andere Sprachen.
Stattdessen kannst du Konstrukte wie `i += 1` verwenden (was gleichbedeutend mit `i = i + 1` ist).
