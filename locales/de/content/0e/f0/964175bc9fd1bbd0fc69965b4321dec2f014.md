# Einführung

Eine Eigenschaft (property) in C# ist ein Member einer Klasse, der Zugriff auf Daten innerhalb dieser Klasse bietet. Aufrufer können die Daten setzen oder abrufen (get). Eigenschaften können entweder automatisch implementiert sein oder ein Unterstützungsfeld haben. Sie bestehen aus einem set-Accessor und/oder einem get-Accessor. In manchen anderen Sprachen entspricht ein „Mutator“ ungefähr einem set-Accessor und ein „Accessor“ ungefähr einem get-Accessor, auch wenn der Aufbau der Syntax völlig anders ist.

Beim Setzen einer Eigenschaft kann der Eingabewert validiert, formatiert oder anderweitig bearbeitet werden, und tatsächlich lässt sich jede programmatische Operation ausführen, die dem Code in der Klasse zur Verfügung steht.

Ähnlich können beim Abrufen einer Eigenschaft die Daten berechnet oder formatiert werden, und auch hier lässt sich jede programmatische Operation ausführen, die der Klasse zur Verfügung steht.

Eigenschaften haben Zugriffsmodifizierer (`public`, `private` usw.) genau wie andere Member einer Klasse, aber der set-Accessor kann eine Zugriffsebene haben, die unabhängig von der des get-Accessors (Abrufen) ist, und umgekehrt. Eine Eigenschaft muss nicht beide Accessoren haben, sie kann auch nur einen besitzen (entweder get oder set).

Die grundlegende Syntax für Eigenschaften kann zwei Formen annehmen:

## Feld- oder ausdrucksgestützte Eigenschaften:

```csharp
private int myField;
public int MyProperty
{
    get { return myField; }
    set { myField = value; }
}
```

## Automatisch implementierte Eigenschaften

```
public int MyProperty { get; private set; } = 42;
```

Die Initialisierung ist optional.
