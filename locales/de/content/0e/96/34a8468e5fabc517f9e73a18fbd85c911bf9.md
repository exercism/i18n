# Über

Mit einer [`for`-Schleife][for-statement] kannst du Code wiederholt ausführen, bis eine Bedingung erfüllt ist.

```csharp
for (int i = 0; i < 5; i++)
{
    System.Console.Write(i);
}

// => 01234
```

Eine `for`-Schleife besteht aus vier Teilen:

1. Der Initialisierer: wird einmal vor dem Betreten der Schleife ausgeführt. Wird normalerweise verwendet, um Variablen zu definieren, die innerhalb der Schleife verwendet werden.
2. Die Bedingung: wird vor jeder Schleifeniteration ausgeführt. Die Schleife wird weiter ausgeführt, solange dies `true` ergibt.
3. Der Iterator: wird nach jeder Schleifeniteration ausgeführt. Wird normalerweise verwendet, um die Schleifenvariable(n) zu ändern (oft: zu erhöhen oder zu verringern).
4. Der Schleifenblock: der Code, der bei jeder Schleifeniteration ausgeführt wird.

## for- vs. foreach-Schleifen

Im Allgemeinen sind [concept:csharp/foreach-loops]() aus den folgenden Gründen gegenüber `for`-Schleifen vorzuziehen:

- Eine `foreach`-Schleife durchläuft garantiert _alle_ Werte. Bei einer `for`-Schleife kann man leicht Elemente übersehen, zum Beispiel aufgrund eines Off-by-one-Fehlers.
- Eine `foreach`-Schleife ist _deklarativer_: Dein Code teilt mit, _was_ du damit tun möchtest, statt einer `for`-Schleife, die mitteilt, _wie_ du es tun möchtest.
- Eine `foreach`-Schleife ist idiotensicher, während bei `for`-Schleifen schnell ein Off-by-one-Fehler passiert.
- Eine `foreach`-Schleife funktioniert mit allen Sammlungstypen, auch mit denen, die keinen Indexer für den Zugriff auf Elemente unterstützen.

Um zu garantieren, dass eine `foreach`-Schleife _alle_ Werte durchläuft, erlaubt der Compiler nicht, dass eine Sammlung innerhalb einer `foreach`-Schleife geändert wird:

```csharp
char[] vowels = new [] { 'a', 'e', 'i', 'o', 'u' };

foreach (char vowel in vowels)
{
    // This would result in a compiler error
    // vowel = 'Y';
}
```

Eine `for`-Schleife hat jedoch einige Vorteile gegenüber einer `foreach`-Schleife:

- Du kannst bei dem Index beginnen oder aufhören, den du möchtest.
- Du kannst jede (boolesche) Abbruchbedingung verwenden, die du möchtest.
- Du kannst Elemente überspringen, indem du das Erhöhen der Schleifenvariable anpasst.
- Du kannst Sammlungen von hinten nach vorne verarbeiten, indem du herunterzählst.
- Du kannst `for`-Schleifen in Szenarien verwenden, in denen es keine Sammlungen gibt.
