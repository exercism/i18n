# Tests

## Tests ausführen

Um die Tests auszuführen, führe im Übungsverzeichnis den folgenden Befehl aus:

```shell
make
```

Dieser assembliert deine Lösung, kompiliert die Tests, linkt sie zu einem RISC-V-Programm und führt es unter `qemu-riscv32` aus.
Das Programm gibt für jeden Test eine Zeile aus, die zeigt, ob er bestanden, fehlgeschlagen oder ignoriert wurde, und danach eine Zusammenfassung.

## Die Übung lösen

Eine Übung ist gelöst, wenn alle ihre Tests bestehen.
Standardmäßig wird nur ein Test (der erste) ausgeführt, wenn du die Tests laufen lässt.
Das ist beabsichtigt, damit du dich darauf konzentrieren kannst, genau diesen einen Test zu bestehen.
Sobald er besteht, kannst du den nächsten Test aktivieren, indem du die Zeile `TEST_IGNORE();` entfernst.
Wenn alle Tests aktiviert sind und deine Implementierung sie alle besteht, hast du die Übung gelöst!
