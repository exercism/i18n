# Anhang zur Anleitung

## Reservierte Adressen

Der Puffer für den ersten String verwendet die Bytes 1024-2047 des linearen Speichers.
Der Puffer für den zweiten String verwendet die Bytes 2048-3071 des linearen Speichers.

Diese Puffer solltest du weder ändern noch zusätzlichen Speicher reservieren müssen.
