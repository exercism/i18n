# Einführung

Ein `Map` wird verwendet, um Paare aus **Schlüssel** und **Wert** zu speichern. `Maps` werden genau wie ein Array initialisiert, verwenden aber den Operator `=>` für Map-Literale. Du kannst die Typen für Schlüssel und Werte auch explizit angeben, oder sie werden abgeleitet. Schlüssel müssen eindeutig sein, sonst wird ein Fehler geworfen.

```haxe
var map1:Map<Int, String> = [1 => "one", 2 => "two", 3 => "three"];

var map2 = ["one" => 1, "two" => 2, "three" => 3];

var map3 = [1 => "cat", 1 => "dog"]; // Error: Duplicate Key

var map4 = ["h" => "Hello", "b" => "Bye"];
trace(map4["h"]); // Hello
```

Ein `Map` kannst du mit einer `for`-Schleife durchlaufen. Du kannst entweder über die Werte oder über die Schlüssel iterieren:

```haxe
for (value in map) {
  // ...
}

for (key in map.keys()) {
  // ...
}
```
