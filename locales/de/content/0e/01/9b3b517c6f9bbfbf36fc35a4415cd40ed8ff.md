# Überblick

[_Methodenüberladung_][member-overloading] ermöglicht es, dass mehrere Methoden in derselben Klasse denselben Namen haben. Überladene Methoden müssen sich in einem der folgenden Punkte unterscheiden:

- Die Anzahl der Parameter
- Der Typ der Parameter

Es gibt keine Methodenüberladung basierend auf dem Rückgabetyp.

Der Compiler leitet automatisch ab, welche überladene Methode aufgerufen werden soll, [basierend auf der Anzahl der Parameter und ihrem Typ][overloading].
