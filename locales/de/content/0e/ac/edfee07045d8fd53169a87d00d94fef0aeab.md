# Einführung

Die Klasse `str` bietet [viele nützliche Methoden][str methods] für die Arbeit mit Strings und deren Zusammensetzung.
Dazu gehören Suchen, Bereinigen, Aufteilen, Umwandeln, Übersetzen und viele weitere Techniken.

Strings sind [Sequenzen][text sequence] von [Unicode-Codepunkten][unicode code points]. Einzelne „Zeichen“ oder Codepunkte (_Strings der Länge 1_) lassen sich über eine `0-based index`-Nummer von links oder eine `-1-based index`-Nummer von rechts ansprechen.
Strings unterstützen alle [üblichen Sequenzoperationen][common sequence operations].

Du kannst sie mit der Syntax `for item in <str>` oder `for index, item in enumerate(<str>)` durchlaufen.
Außerdem kannst du sie mit `<str> + <other str>` oder `<str>.join(<iterable>)` verketten.

Strings sind _unveränderlich_. Das bedeutet, der Wert eines `str`-Objekts im Speicher kann sich nicht ändern.
Funktionen oder Methoden, die auf einem `str` arbeiten (_wie die, die wir hier kennenlernen_), geben eine neue `instance` dieses `str`-Objekts zurück, statt das ursprüngliche `str` zu verändern.

Im Folgenden findest du eine kleine Auswahl von Python-String-Methoden.
Eine vollständige Liste findest du in der [Klasse str][str methods] in der Python-Dokumentation.


[`<str>.title()`][str-title] analysiert einen String und schreibt das erste „Zeichen“ jedes gefundenen „Worts“ groß.
In Python hängt das stark vom verwendeten [Sprach-Codec][codecs] ab und davon, wie die jeweilige Sprache Wörter und Zeichen darstellt.
Außerdem können für eine Sprache oder einen Zeichensatz [Locale][locale]-Regeln gelten.


```python
man_in_hat_th = 'ผู้ชายใส่หมวก'
man_in_hat_ru = 'мужчина в шляпе'
man_in_hat_ko = '모자를 쓴 남자'
man_in_hat_en = 'the man in the hat.'

>>> man_in_hat_th.title()
'ผู้ชายใส่หมวก'

>>> man_in_hat_ru.title()
'Мужчина В Шляпе'

>>> man_in_hat_ko.title()
'모자를 쓴 남자'

>> man_in_hat_en.title()
'The Man In The Hat.'
```

[`<str>.endswith(<suffix>)`][str-endswith] gibt `True` zurück, wenn der String mit `<suffix>` endet, andernfalls `False`.


```python
>>> 'My heart breaks. 💔'.endswith('💔')
True

>>> 'cheerfulness'.endswith('ness')
True

# Punctuation is part of the string, so needs to be included in any endswith match.
>>> 'Do you want to 💃?'.endswith('💃')
False

>> 'The quick brown fox jumped over the lazy dog.'.endswith('dog')
False
```

[`<str>.strip(<chars>)`][str-strip] gibt eine Kopie des `str` zurück, bei der führende und nachfolgende `<chars>` entfernt wurden.
Die in `<chars>` angegebenen Codepunkte sind kein Präfix oder Suffix: **alle Kombinationen** der Codepunkte werden von **beiden Enden** des Strings entfernt.
 Wenn für `<chars>` nichts angegeben wird, werden alle Kombinationen von Whitespace-Codepunkten entfernt.


 ```python
# This will remove "https://", because it can be formed from "/stph:". 
>>> 'https://unicode.org/emoji/'.strip('/stph:')
'unicode.org/emoji'

# Removal of all whitespace from both ends of the str.
>>> '   🐪🐪🐪🌟🐪🐪🐪   '.strip()
'🐪🐪🐪🌟🐪🐪🐪'

>>> justification = 'оправдание'
>>> justification.strip('еина')
'оправд'

# Prefix and suffix in one step.
>>> 'unaddressed'.strip('dnue')
'address'

>>> '  unaddressed  '.strip('dnue ')
'address'
```


[`<str>.replace(<substring>, <replacement substring>)`][str-replace] gibt eine Kopie des Strings zurück, in der alle Vorkommen von `<substring>` durch `<replacement substring>` ersetzt wurden.

Das unten verwendete Zitat stammt aus [The Hunting of the Snark][The Hunting of the Snark] von [Lewis Carroll][Lewis Carroll]

```python
# The Hunting of the Snark, by Lewis Carroll
>>> quote = '''
"Just the place for a Snark!" the Bellman cried,
   As he landed his crew with care;
Supporting each man on the top of the tide
   By a finger entwined in his hair.

"Just the place for a Snark! I have said it twice:
   That alone should encourage the crew.
Just the place for a Snark! I have said it thrice:
   What I tell you three times is true."
'''

>>> quote.replace('Snark', '🐲')
...
'\n"Just the place for a 🐲!" the Bellman cried,\n   As he landed his crew with care;\nSupporting each man on the top of the tide\n   By a finger entwined in his hair.\n\n"Just the place for a 🐲! I have said it twice:\n   That alone should encourage the crew.\nJust the place for a 🐲! I have said it thrice:\n   What I tell you three times is true."\n'

>>> 'bookkeeper'.replace('kk', 'k k')
'book keeper'
```
