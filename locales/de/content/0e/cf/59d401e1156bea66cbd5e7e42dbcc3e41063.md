# Einführung

Auf einzelne Zeichen in einem `String` greifst du mit der Subskript-Methode zu, die auch bei Arrays verwendet wird.
Die [Indizes][string-indices], die für Strings verwendet werden, sind jedoch _keine_ Ganzzahlen und du kannst nicht direkt mit ihnen arbeiten.
Stattdessen musst du sie auf Basis eines anderen bekannten Index berechnen, zum Beispiel `startIndex`, der auf die Position des ersten Zeichens in einem nicht leeren String zeigt. Dafür nutzt du die Methoden aus den Bibliotheken [`String`][string-docs] und [`NSString`][nsstring-docs] (wenn das Modul `Foundation` importiert ist, haben Strings in Swift Zugriff auf alle Eigenschaften und Methoden von NSString).

Zum Beispiel bei folgendem String:

```swift
let csv = "apple,pear,peach,orange,cherry,lime,goosberry"
```

Du kannst nicht `csv[21]` schreiben, um das „g“ in „orange“ zu erhalten. Stattdessen musst du einen Wert vom Typ `String.Index` berechnen und diesen Index übergeben.
Beachte, dass diese Indizes nicht dafür gedacht sind, dass Menschen sie für sich allein lesen können.
Sie werden als _opake Indizes_ bezeichnet, denn Menschen müssen nicht wissen, was in ihnen steckt.

```swift
let index = csv.index(csv.startIndex, offsetBy: 21)
csv[index]
// "g"
print(index)
// prints Index(_rawBits: 1376513)
```

Beachte jedoch: Wenn der Offset kein gültiger Index ist, also wenn er einen Index vor `startIndex` oder nach `endIndex` liefern würde, löst die Operation einen Fehler aus und das Programm stürzt ab.
Um dieses Problem zu vermeiden, kannst du einen begrenzenden Index angeben.
Dies gibt einen optionalen Index zurück, und für ansonsten ungültige Indizes wird nil zurückgegeben.

```swift
let tooFar = csv.index(csv.startIndex, offsetBy: 200)
// error: Execution was interrupted, reason: EXC_BAD_INSTRUCTION (code=EXC_I386_INVOP, subcode=0x0).
let tooFarButSafe = csv.index(csv.startIndex, offsetBy: 200, limitedBy: csv.endIndex)
// nil
```

Außerdem können Indizes nicht zwischen Strings geteilt werden.
Zum Beispiel: Wenn du den oben berechneten `index` des „g“ in „orange“ verwendest, um in den String `fam = "This is my family: 👨‍👩‍👦‍👦, this is our dog: 🐶, this is our cat: 🐱!"` zu indexieren, also `fam[index]`, stürzt dein Programm ab.

Es gibt viele Gründe dafür, aber im Grunde läuft alles auf „Unicode ist knifflig“ hinaus.

Allgemein gesprochen: Wenn du wahlfreien Zugriff auf einzelne Zeichen brauchst, solltest du wohl eine andere Datenstruktur verwenden, etwa `Array<Character>`.

## Einige nützliche Methoden

Swift bietet die Methoden `first` und `last`, um das erste und letzte Zeichen eines Strings zu erhalten.
Diese Methoden geben ein optionales Zeichen zurück. Wenn der String leer ist, geben sie nil zurück.

```swift
let str = "Hello, world!"
print(str.first) // Prints Optional("H")
print(str.last)  // Prints Optional("!")
```

Du kannst auch die Methoden `prefix` und `suffix` verwenden, um einen Teilstring eines Strings zu erhalten.
Diese Methoden nehmen eine Ganzzahl als Argument und geben einen Teilstring zurück, der die ersten oder letzten n Zeichen des Strings enthält.

```swift
let str = "Hello, world!"
print(str.prefix(5)) // Prints "Hello"
print(str.suffix(6)) // Prints "world!"
```
