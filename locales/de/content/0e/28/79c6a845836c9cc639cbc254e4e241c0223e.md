# Einführung

Namespaces sind eine Möglichkeit, zusammengehörigen Code zu gruppieren und Namenskonflikte zu vermeiden. In fast jeder Codebasis kommen sie vor, außer in den allertrivialsten.

Die Syntax sieht so aus:

```csharp
namespace MyNameSpace
{
    public class MyClass {}

    public class OtherClass {}
}
```

Auf Typen, die in einem Namespace eingeschlossen sind, greifst du außerhalb des Gültigkeitsbereichs dieses Namespace zu, indem du dem Typnamen die Punktnotation voranstellst. Alternativ, und meistens üblicher, setzt du eine `using`-Direktive an den Anfang der Datei (oder innerhalb eines Namespace); dann kannst du den Typ ohne Präfix verwenden. Innerhalb desselben Namespace musst du Typnamen nicht qualifizieren.

```csharp
namespace MySpace
{
    public class MyClass {}

    public class Foo
    {
        public void Bar()
        {
            var baz = new MyClass();
        }
    }
}

public class Qux
{
    public void Box()
    {
        var nux = new MySpace.MyClass();
    }
}

namespace OtherSpace
{
    using MySpace;

    public class Tix
    {
        public void Jeg()
        {
            var lor = new MyClass();
        }
    }
}
```

Du kannst einem Namespace mit der Syntax `using MyAlias = MySpace;` einen Alias geben und den Alias dann überall verwenden, wo du den Namespace verwenden könntest.
