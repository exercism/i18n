# Einführung

Ternäre Operatoren ermöglichen es, if-Bedingungen in Ausdrücken statt in Anweisungsblöcken zu definieren. Das erinnert an Ansätze der funktionalen Programmierung und macht den Code oft ausdrucksstärker und weniger fehleranfällig.

Der ternäre Operator kombiniert drei Ausdrücke: eine Bedingung, gefolgt von einem Ausdruck, der ausgewertet und zurückgegeben wird, wenn die Bedingung wahr ist (der `if`-Teil, eingeleitet durch `?`), und einem Ausdruck, der ausgewertet und zurückgegeben wird, wenn die Bedingung falsch ist (der `else`-Teil, eingeleitet durch `:`).

```csharp
int a = 3, b = 4;
int max = a > b ? a : b;
// => 4
```
