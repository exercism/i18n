# Anhang zur Anweisung

Jede Liste von Eingaben wird als String dargestellt, wobei am Ende jeder Eingabe ein Zeilenumbruchzeichen steht.

Ein Beispiel wäre `"nail\nshoe\nhorse\nrider\nmessage\nbattle\nkingdom\n"`

Jede Ausgabezeile sollte mit einem Zeilenumbruch `\n` enden.

## Reservierter Speicher

Die Bytes 128-383 des linearen Speichers sind für den Eingabe-String reserviert.
