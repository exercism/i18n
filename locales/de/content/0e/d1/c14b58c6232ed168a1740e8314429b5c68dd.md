# Type Juggling

Type Juggling ist auch unter dem Namen Type Coercion bekannt.
Von Type Juggling spricht man, wenn zwei Werte unterschiedlichen Typs auf denselben Typ umgewandelt werden, um eine Operation auszuführen.

```php
$baskets = 5 // int
$apples_per_basket = "3" // string
$baskets * $apples_per_basket
# => 15
```

Das kann implizit geschehen (siehe Beispiel oben) oder explizit durch Casting im `C`-Stil:

```php
$apples_per_basket = "3" // string
$my_number = (int) $apples_per_basket // cast string to int
# => 3 // int
```

Beim manuellen Casting sind folgende Typen erlaubt: `bool`, `int`, `float`, `string`, `array`, `object`.
Am häufigsten wird Casting verwendet, um eine Ganzzahl (`int`) in eine Gleitkommazahl (`float`) umzuwandeln oder umgekehrt.
