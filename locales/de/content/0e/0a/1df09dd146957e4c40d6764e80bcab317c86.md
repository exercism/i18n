# Introduction

Ein *Tupel* bündelt mehrere benannte Werte zu einem Objekt. Andere Sprachen nennen so etwas Record, Struct oder Klasse. Jede Tupel-Klasse hat eine feste Menge benannter Slots, und Factor erzeugt automatisch Getter und Setter dafür.

## Ein Tupel definieren

```factor
TUPLE: point
    { x initial: 0 }
    { y initial: 0 } ;
```

Jeder Slot wird mit `{ name initial: default-value }` deklariert. Ohne eine `initial:`-Klausel ist der Standardwert `f`.

## Ein Tupel erzeugen

Der einfachste Konstruktor ist `new`:

```factor
point new .
! => T{ point }
```

`boa` (kurz für „by order of arguments“) füllt Slots in der Reihenfolge ihrer Deklaration aus dem Datenstack:

```factor
3 4 point boa .
! => T{ point { x 3 } { y 4 } }
```

Mit der Literal-Syntax `T{ class { slot value } … }` erzeugst du ein Tupel, bei dem nur ein Teil der Slots gesetzt ist, und es wird genauso ausgegeben:

```factor
T{ point { x 3 } } .
! => T{ point { x 3 } }
```

Wenn der Wert eines Slots seinem Standardwert entspricht, lässt der Printer ihn weg.

## Ein Slot lesen

Factor erzeugt für jeden Slot einen Getter `slot>>`. Getter liegen in [`accessors`][accessors]:

```factor
T{ point { x 3 } { y 4 } } x>> .
! => 3
```

## Ein Slot aktualisieren

Setter werden als `>>slot` geschrieben und *verändern* das Tupel direkt:

```factor
T{ point { x 3 } { y 4 } } 10 >>x .
! => T{ point { x 10 } { y 4 } }
```

Um das Original unverändert zu lassen, rufst du zuerst `clone` auf:

```factor
: shifted ( pt -- pt' )
    clone 10 >>x ;
```

`change-slot` nimmt eine Quotation, die den aktuellen Wert auf den neuen abbildet:

```factor
: shift-x ( pt dx -- pt )
    [ + ] curry change-x ;
```

Auch `change-x` verändert das Tupel direkt. Ruf also `clone` auf, bevor du es aufrufst, wenn du das Original erhalten willst.
