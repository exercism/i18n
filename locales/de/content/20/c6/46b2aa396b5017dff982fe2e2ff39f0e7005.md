# Einführung

Elixir stellt die Werte wahr und falsch mit dem booleschen Typ dar. Es gibt nur zwei Werte: `true` und `false`. Diese Werte kannst du an eine Variable binden:

```elixir
true_variable = true
false_variable = false
```

Strikte boolesche Ausdrücke können wir mit den Operatoren `and/2`, `or/2` und `not/1` auswerten.

```elixir
true_variable = true and true
false_variable = true and false

true_variable = false or true
false_variable = false or false

true_variable = not false
false_variable = not true
```

Wenn du eine Funktion schreibst, die einen booleschen Wert zurückgibt, ist es idiomatisch, den Funktionsnamen mit einem `?` zu beenden. Dieselbe Konvention kannst du für Variablen verwenden, die boolesche Werte speichern.

```elixir
def either_true?(a?, b?) do
  a? or b?
end
```
