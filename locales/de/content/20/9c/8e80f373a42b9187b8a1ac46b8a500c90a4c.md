# Anleitung

In dieser Übung verarbeitest du Logeinträge.

Jede Logzeile ist ein String, der wie folgt formatiert ist: `"[<LEVEL>]: <MESSAGE>"`.

Es gibt drei verschiedene Log-Level:

- `INFO`
- `WARNING`
- `ERROR`

Du hast drei Aufgaben. Jede bekommt eine Logzeile und du sollst etwas damit machen. Es gibt viele Wege, diese Aufgaben zu lösen. Wähle deine Lieblingstechniken aus den Beispielen oben und schau, was dir einfällt.

## 1. Nachricht aus einer Logzeile ermitteln

Implementiere die Funktion `message`, die die Nachricht einer Logzeile zurückgibt:

```jq
"[ERROR]: Invalid operation" | message
# => "Invalid operation"
```

Führende und nachfolgende Leerzeichen sollen entfernt werden:

```jq
"[WARNING]:  Disk almost full\r\n" | message
# => "Disk almost full"
```

## 2. Log-Level aus einer Logzeile ermitteln

Implementiere die Funktion `log_level`, die das Log-Level einer Logzeile zurückgibt. Das Log-Level soll in Kleinbuchstaben zurückgegeben werden:

```ruby
"[ERROR]: Invalid operation" | log_level
# => "error"
```

## 3. Eine Logzeile umformatieren

Implementiere die Funktion `reformat`, die die Logzeile umformatiert: zuerst die Nachricht, danach das Log-Level in Klammern:

```ruby
"[INFO]: Operation completed" | reformat
# => "Operation completed (info)"
```
