# Anleitung

Die Tanzgruppe stellt sich in Reihen auf, und du behältst den Überblick, wer wo steht.

Alle fünf Aufgaben gehören in die `DANCE_FORMATION`-Klasse.

## 1. Wie viele sind in der Reihe?

```sather
DANCE_FORMATION::dancer_count(|"Mia", "Ana", "Ben"|)
-- => 3
```

## 2. Wer führt?

Der Anführer ist, wer an erster Stelle steht.

```sather
DANCE_FORMATION::leader(|"Mia", "Ana", "Ben"|)
-- => "Mia"
```

## 3. Wer ist am Ende?

Der Letzte in der Reihe ist, wer ganz am Ende steht, egal wie lang die Reihe ist.

```sather
DANCE_FORMATION::back_marker(|"Mia", "Ana", "Ben"|)
-- => "Ben"
```

## 4. Die Eröffnungsformation

Die Truppe eröffnet immer in derselben Reihenfolge: Mia, Ana, Ben. Gib diese Reihe zurück.

```sather
DANCE_FORMATION::opening_row
-- => an array holding "Mia", "Ana" and "Ben", in that order
```

Diese Routine nimmt keine Argumente.

## 5. Zähle die Schritte

Jeder Tänzer hat eine Anzahl von Schritten zu machen. Addiere sie.

```sather
DANCE_FORMATION::total_steps(|8, 16, 8|)
-- => 32
```

Eine leere Reihe ergibt null Schritte.
