# Überblick

Das [`sequences`][sequences]-Vokabular definiert ein einzelnes [Protokoll][sequence-protocol], das Arrays (`{ … }`), Vektoren (`V{ … }`), Strings, Bereiche und Slices alle implementieren. Alles, was du mit einem davon machen kannst, kannst du auch mit den anderen machen.

| Wort        | Wirkung                            |
|-------------|-----------------------------------|
| `length`    | `( seq -- n )`                    |
| `first`     | `( seq -- elt )`                  |
| `second`    | `( seq -- elt )`                  |
| `third`     | `( seq -- elt )`                  |
| `fourth`    | `( seq -- elt )`                  |
| `last`      | `( seq -- elt )`                  |
| `rest`      | `( seq -- tailseq )`              |
| `but-last`  | `( seq -- headseq )`              |
| `nth`       | `( n seq -- elt )` (0-basiert)    |
| `head`      | `( seq n -- headseq )`            |
| `head*`     | `( seq n -- headseq )` (alle außer den letzten n) |
| `tail`      | `( seq n -- tailseq )`            |
| `tail*`     | `( seq n -- tailseq )` (die letzten n) |
| `subseq`    | `( from to seq -- newseq )`       |
| `remove-nth`| `( n seq -- newseq )`             |
| `pad-head`  | `( seq n elt -- padded )`         |
| `pad-tail`  | `( seq n elt -- padded )`         |
| `prefix`    | `( seq elt -- newseq )`           |
| `suffix`    | `( seq elt -- newseq )`           |
| `unclip`    | `( seq -- rest first )`           |
| `unclip-last` | `( seq -- butlast last )`       |
| `empty?`    | `( seq -- ? )`                    |
| `if-empty`  | `( seq emptyquot nonemptyquot -- … )` |
| `member?`   | `( elt seq -- ? )`                |
| `reverse`   | `( seq -- newseq )`               |
| `index`     | `( elt seq -- i/f )`              |
| `index-or-length` | `( elt seq -- i )` (Länge, wenn nicht vorhanden) |
| `count`     | `( seq quot -- n )`               |
| `concat`    | `( seqs -- seq )`                 |
| `sum`       | `( seq -- n )`                    |
| `product`   | `( seq -- n )`                    |
| `find`      | `( seq quot -- i/f elt/f )`       |
| `find-last` | `( seq quot -- i/f elt/f )`       |
| `produce`   | `( pred quot -- seq )`            |

Arrays haben eine feste Länge. Die Operationen `prefix`/`suffix`/`append`/`prepend` geben daher alle neue Sequenzen zurück, anstatt das Original zu erweitern. Vektoren sind in der Größe veränderbar: `push` und `pop` arbeiten in-place, aber `clone` ist der richtige Ausgangspunkt, wenn du eine frische Kopie möchtest.

## Konvertierungen

`>array`, `>string` und `>vector` (in ihren jeweiligen Vokabularen) wandeln jede Sequenz in den genannten konkreten Typ um. Verwende sie, wenn ein Aufrufer eine bestimmte Darstellung möchte, oder um ein Slice oder eine andere lazy Sequenz zu materialisieren.

```factor
USING: arrays sequences strings vectors ;

V{ 1 2 3 } >array  .   ! => { 1 2 3 }
{ 65 66 67 } >string . ! => "ABC"
"abc" >vector .        ! => V{ CHAR: a CHAR: b CHAR: c }
```
