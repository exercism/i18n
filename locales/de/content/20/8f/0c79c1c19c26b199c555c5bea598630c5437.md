# Constructor Property Promotion

In Klassen, die viele Eigenschaften deklarieren, musst du die Klasse, ihre Eigenschaften und einen Konstruktor zum Setzen dieser Eigenschaften getrennt deklarieren. Das führt zu Wiederholungen. Mit Constructor Property Promotion kannst du die Wiederholungen reduzieren.

```php
<?php

class Book
{
    private string $isbn;
    private string $doi;
    private string $title;

    public function __construct(string $isbn, string, $doi, string $title)
    {
        $this->isbn = $isbn;
        $this->doi = $doi;
        $this->title = $title;
    }
}

// Using constructor property promotion
class Book
{
    public function __construct(
        private string $isbn,
        private string $doi,
        private string $title
    ) {
    }
}
