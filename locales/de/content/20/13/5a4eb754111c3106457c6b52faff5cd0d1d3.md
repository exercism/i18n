# Einführung

Wenn du anhand mehrerer diskreter möglicher Werte entscheiden musst, ist `case` (in [`combinators`][combinators]) die sauberere Wahl als eine Kette von `if`-Anweisungen.

## `case`

```
case ( obj assoc -- )
```

`case` nimmt den obersten Wert vom Stack und *assoc*, eine Sammlung von Klauseln. Jede Klausel ist `{ value [ body ] }`. Die erste Klausel, deren Wert `=` dem Eingabewert ist, gewinnt; ihr Rumpf wird ausgeführt, wobei der Eingabewert *bereits verbraucht* ist. Ein abschließender Eintrag, der nur `[ body ]` ist, ist der Standard: Der Eingabewert ist *noch auf dem Stack*, wenn dieser ausgeführt wird.

```factor
USING: combinators ;

: name-of ( n -- s )
    {
        { 1 [ "one" ] }
        { 2 [ "two" ] }
        [ drop "many" ]
    } case ;
```

Gleichheit wird über `=` bestimmt, also funktioniert alles, was gleich verglichen wird, als Schlüssel: Zahlen, Strings und Symbole funktionieren alle.

## `cond` für bedingte Verzweigungen

Wenn die Wahl von einem *Prädikat* statt von Gleichheit abhängt (z. B. `x > 11`), ist `cond` das passende Werkzeug. `cond` kennst du schon aus [Cars, Assemble!][cars-assemble].

## Symbole

Ein `SYMBOL:` deklariert ein Wort, das sich selbst auf den Stack legt: einen selbstauswertenden Tag-Wert. `SYMBOLS:` deklariert mehrere auf einmal:

```factor
SYMBOLS: yes no maybe ;
```

Jetzt ist `yes` ein Wert, vergleichbar mit `=`, den du als Schlüssel für `case` verwenden kannst:

```factor
: invert ( ? -- ?' )
    { { yes [ no ] } { no [ yes ] } [ ] } case ;
```
