# Tests

## Clojure CLI

Die Clojure-Übungen auf Exercism enthalten eine `deps.edn`-Datei mit einem `:test`-Alias, um den [cognitect-labs test-runner](https://github.com/cognitect-labs/test-runner) aufzurufen:

``` bash
clj -X:test
```

## Leiningen

Du kannst die Tests der Übung auch mit Leiningen ausführen. Führe dazu den folgenden Befehl im Verzeichnis der Übung aus:

```bash
lein test
```
