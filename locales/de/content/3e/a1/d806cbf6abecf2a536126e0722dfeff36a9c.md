# Einführung

Ein `string` in C# ist ein Objekt, das unveränderlichen Text als Folge von Unicode-Zeichen darstellt (Buchstaben, Ziffern, Satzzeichen usw.). Mit doppelten Anführungszeichen definierst du eine `string`-Instanz:

```csharp
string fruit = "Apple";
```

Strings manipulierst du, indem du ihre Methoden aufrufst. Sobald ein String erstellt wurde, kann sich sein Wert nie mehr ändern. Alle Methoden, die einen String zu verändern scheinen, geben in Wirklichkeit einen neuen String zurück.

Mehrere Strings lassen sich miteinander verketten (addieren). Am einfachsten geht das mit dem `+`-Operator.

```csharp
string name = "Jane";
"Hello " + name + "!";
// => "Hello Jane!"
```

Für eine String-Formatierung, die über eine einfache Verkettung hinausgeht, ist die String-Interpolation die bessere Wahl. Um die Interpolation in einem String zu verwenden, stellst du ihm das Dollarzeichen (`$`) voran. Dann kannst du mit geschweiften Klammern (`{}`) auf beliebige Variablen in deinem String zugreifen.

```csharp
string name = "Jane";
$"Hello {name}!";
// => "Hello Jane!"
```
