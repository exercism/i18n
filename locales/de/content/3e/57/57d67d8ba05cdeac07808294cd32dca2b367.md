# Einführung

Ein **Wort** ist in Factor der Name für eine Funktion. Aufbauend auf dem
Datenstack aus `basics` geht es in diesem Konzept darum, eigene Wörter zu
definieren: zu rechnen, festen Werten einen Namen zu geben und Wörter aus
anderen Wörtern zusammenzusetzen.

Eine Definition beginnt mit `:`, dann folgt der Stackeffekt, dann der
Rumpf, dann `;`. Der Compiler prüft, ob der Rumpf zum angegebenen
Stackeffekt passt:

```factor
: square ( x -- x*x ) dup * ;

4 square .    ! => 16
```

Die Rechenwörter `+`, `-` und `*` für Ganzzahlen nehmen jeweils zwei
Zahlen vom Stack und legen das Ergebnis auf den Stack. Sie gehören zum
`math`-Vokabular, deshalb braucht eine Datei, die sie verwendet, `math`
in ihrer `USING:`-Zeile. Die oberste Zahl auf dem Stack ist der rechte
Operand:

```factor
2 3 + .    ! => 5
8 3 - .    ! => 5    (8 - 3, not 3 - 8)
2 3 * .    ! => 6
```

`CONSTANT:` gibt einem festen Wert einen Namen. Eine Konstante ist selbst
ein Wort: Ruft man sie auf, legt sie den Wert auf den Stack:

```factor
CONSTANT: pi 3

pi pi * .    ! => 9
```

Der Rumpf eines Worts kann jedes Wort aufrufen, das bereits im
Gültigkeitsbereich liegt, auch Wörter, die du weiter oben in derselben
Datei definiert hast:

```factor
: double    ( x -- 2x ) 2 * ;
: quadruple ( x -- 4x ) double double ;

5 quadruple .    ! => 20
```

Ein abschließendes `?` in den Ausgabewerten ist die Konvention für
„ein boolescher Wert“, und sowohl Wörter als auch Konstanten verwenden
`lowercase-kebab-case`.
