# Ergänzung zur Anleitung

## Register

| Register | Verwendung | Typ      | Beschreibung                                                                                       |
| -------- | ---------- | -------- | -------------------------------------------------------------------------------------------------- |
| `$a0`    | Eingabe    | Ganzzahl | Seite a                                                                                            |
| `$a1`    | Eingabe    | Ganzzahl | Seite b                                                                                            |
| `$a2`    | Eingabe    | Ganzzahl | Seite c                                                                                            |
| `$v0`    | Ausgabe    | Ganzzahl | Art des Dreiecks (`0` = ungleichseitig, `1` = gleichschenklig, `2` = gleichseitig, `3` = ungültig) |
| `$t0-9`  | temporär   | beliebig | wird für die temporäre Speicherung verwendet                                                       |
