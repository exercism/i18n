## Einführung

Ein Zeiger ist eine Variable oder Konstante, deren Wert die Adresse einer anderen Variable oder Konstante ist.
Zeiger sind ein mächtiges und potenziell gefährliches Feature von C.
Es kann schwierig sein, Zeiger zu verstehen.

Variablen und Konstanten speichern ihren Wert an einer Speicherstelle.
Diese Stelle im Speicher nennt man die Adresse der Variable oder Konstante.

Um die Adresse einer Variable zu erhalten, verwenden wir den Adressoperator, also `&`.
```c
int i = 5;
int *i_address = &i;
```

Ein Typ, gefolgt von einem `*`, gefolgt von einem Bezeichner, ist die Art, einen Zeiger auf eine Variable dieses Typs zu deklarieren.
Der `*` heißt Dereferenzierungsoperator, weil er indirekt auf den Wert verweist, dessen Adresse der Zeiger enthält.

Wenn wir ein Array wie folgt erstellen

```c
int my_ints[] = {1, 2};
```

ist der Wert von `my_ints` tatsächlich seine Adresse, die zufällig auch dieselbe ist wie die Adresse seines ersten Elements.
Die Adresse seines zweiten Elements ist die Adresse des ersten Elements plus der Größe eines `int` auf dem System.

Deshalb werden Zeiger mit einem bestimmten Typ deklariert.
Wenn ein Zeiger nicht wüsste, auf welchen Typ er zeigt, wüsste er nicht, um wie viele Bytes er weiterrücken muss, wenn man `1` zu ihm addiert.
Wenn wir `1` zu einem Zeiger addieren, heißt das nicht unbedingt, dass wir ein Byte zur Adresse addieren.
Es bedeutet, dass wir `1` mal die Länge seines Typs in Bytes addieren.
