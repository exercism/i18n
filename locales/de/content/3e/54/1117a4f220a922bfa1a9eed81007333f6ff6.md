# Tests

Wenn du eine Übung mit dem CLI-Tool heruntergeladen hast, solltest du eine Uiua-Datei sehen, die nach der Übung benannt ist, sowie eine `tests.ua`-Datei.
Diese Datei enthält alle Testfälle. Sie stimmen mit denen überein, die der Testrunner ausführt, wenn du deine Lösung hochlädst.
Du kannst gerne zusätzliche Testfälle zum Experimentieren hinzufügen.
Das Ändern der Tests hat jedoch keinen Einfluss auf den Online-Testrunner.

## Lokales Testen

Um die Tests einer Übung auszuführen, öffne ein Terminal im Verzeichnis der Übung und führe den Befehl `uiua test tests.ua` aus.

Zum Beispiel könnte die Ausgabe einer unveränderten `hello-world`-Übung so aussehen:

```bash
$ uiua test tests.ua
Error: Goodbye, Mars!
  at tests.ua:3:1
3 | ⍤⤙≍ "Hello, World!" Hello
    ─
Test failed
```

Die Zeile `Error` zeigt die tatsächliche Ausgabe deines Codes an.
Die Zeilennummer gibt die Position des erwarteten Ergebnisses in `tests.ua` an.
Eine korrekte Lösung liefert:

```bash
$ uiua test tests.ua
Test passed
```
