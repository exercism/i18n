# Anleitung

In dieser Übung arbeitest du an einem Terminplaner für einen Schönheitssalon.

Du hast drei Aufgaben, bei denen es jeweils um Termindaten geht.

## 1. Prüfen, ob ein Termin bereits vorbei ist

Implementiere die Subroutine `appointment_has_passed`, die einen Datums-String entgegennimmt und prüft, ob der Termin irgendwann in der Vergangenheit lag:

```perl
appointment_has_passed("2019-07-25T13:45:00")
// => true
```

Datums-Strings werden im ISO-8601-Format für Datum und Uhrzeit übergeben: `YYYY-mm-ddTHH:MM:SS`

Du musst die private Subroutine `_parse_datetime` implementieren.
Ein paar Module werden dir empfohlen:

- [Time::Piece][time-piece] ist ein Perl-Kernmodul.
- [DateTime::Tiny][datetime-tiny] ist auf CPAN verfügbar.

## 2. Prüfen, ob der Termin am Nachmittag liegt

Implementiere die Funktion `is_afternoon_appointment`, die einen Datums-String entgegennimmt und prüft, ob der Termin am Nachmittag liegt (>= 12:00 und < 18:00):

```perl
is_afternoon_appointment("2019-07-25T13:45:00")
// => true
```

## 3. Zeit und Datum des Termins beschreiben

Implementiere die Funktion `describe_appointment`, die einen Datums-String entgegennimmt und eine Beschreibung dieses Datums und dieser Uhrzeit zurückgibt:

```perl
describe_appointment("2019-07-25T13:45:00")
// => "You have an appointment on 07/25/2019 1:45 PM"
```

Beachte, dass die Stunde im Bereich 0-12 liegt und weder eine führende Null noch ein Leerzeichen hat.

[time-piece]: https://perldoc.perl.org/Time::Piece
[datetime-tiny]: https://metacpan.org/pod/DateTime::Tiny
