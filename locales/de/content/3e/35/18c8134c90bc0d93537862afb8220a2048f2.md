# Einführung

Ein Interface kann man als die Signatur einer Klasse verstehen, weil es die öffentlichen Felder einer Klasse beschreibt. Eine Klasse _implementiert_ ein `interface` mit dem Schlüsselwort `implments`.

Die Syntax ist der einer Klasse sehr ähnlich, nur dass die Methoden als Signaturen ohne Rumpf erscheinen:

```haxe
interface Language {
  private var languageName:String;

  public function speak():String;
}

class FrenchSpeaker implements Language {
  var languageName = "French";

  public function speak():String {
    return "Bonjour!";
  }
}
```

Felder, die aus einem Interface implementiert werden, **müssen** immer denselben Sichtbarkeitsmodifizierer verwenden. Wenn zum Beispiel die Variable `a` in einem Interface `public` ist, muss ihre Implementierung ebenfalls `public` sein.
