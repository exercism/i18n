# Anleitung

Konvertiere eine hexadezimale Zahl, die als String dargestellt wird (z. B. „10af8c“), in ihren dezimalen Gegenwert, und zwar von Grund auf (das heißt: Nein, du darfst für die Umrechnung keine eingebauten oder externen Bibliotheken verwenden).

Im Web verwenden wir Hexadezimalzahlen, um Farben darzustellen, z. B. Grün: 008000,
Türkis: 008080, Marineblau: 000080).

Das Programm sollte mit ungültigen hexadezimalen Strings umgehen können.
