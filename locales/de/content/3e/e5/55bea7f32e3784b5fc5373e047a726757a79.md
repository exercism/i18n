# Anleitung

In deiner Stadt gibt es mehrere Läden, die Pizzastücke verkaufen, und du möchtest eine Web-App schreiben, mit der du zwei verschiedene Pizzakonfigurationen vergleichen kannst, um herauszufinden, wer dir das größere Stück gibt.

## 1. Schreibe eine Funktion, die die Größe von Pizzastücken berechnet und bei ungültiger Eingabe nil zurückgibt.

Implementiere die Funktion `sliceSize(diameter: Double?, slices: Int?) -> Double?`, die, wenn man ihr den Durchmesser einer Pizza und die Anzahl der Stücke pro Pizza übergibt, die Fläche eines Stücks zurückgibt.
Bei negativen Durchmessern und bei einer Anzahl von Stücken kleiner als 1 gib `nil` zurück, denn eine Pizza mit negativem Durchmesser gibt es nicht und man kann eine Pizza nicht in weniger als 1 Stück schneiden.
Wenn einer der beiden Parameter `nil` ist, gib ebenfalls `nil` zurück.

```swift
sliceSize(diameter: 16, slices: 12)
// Returns 16.75516081914556
sliceSize(diameter: nil, slices: 8)
// Returns nil
```

## 2. Verarbeite die Eingabe deiner Web-Anwendung, um das größere Stück zu bestimmen.

Deine Web-Anwendung übergibt vier Strings an deine Funktion, `biggestSlice(diameterA: String, slicesA: String, diameterB: String, slicesB: String) -> String`.
Der erste und der zweite String sind der Durchmesser bzw. die Anzahl der Stücke der ersten Pizza, der dritte und der vierte sind der Durchmesser bzw. die Anzahl der Stücke der zweiten Pizza.

Implementiere `biggestSlice` so, dass die Funktion versucht, den Durchmesser und die Anzahl der Stücke jeder Pizza in einen `Double` bzw. einen `Int` umzuwandeln.
Wenn sich beide Werte aus den Strings gewinnen lassen, versuche mit deiner ersten Funktion, die Fläche zu berechnen; andernfalls ist die Fläche für dieses Stück `nil`.
Sobald die Flächen beider Stücke vorliegen, vergleiche die beiden Flächen anhand der folgenden Regeln:

1. Wenn die Fläche von Stück A ein `Double` ist und die von Stück B `nil`, gib „Slice A is bigger“ zurück. Ist das Gegenteil der Fall, gib „Slice B is bigger“ zurück.
2. Wenn beide Flächen `Double`-Werte sind, gib je nachdem, welches Stück die größere Fläche hat, „Slice A is bigger“ oder „Slice B is bigger“ zurück.
3. Wenn beide Flächen `nil` sind oder wenn beide `Double`-Werte sind und gleich groß sind, gib „Neither slice is bigger“ zurück.

~~~~exercism/note
Auch wenn die Eingabe zu einer Fläche von 0 führt, gilt das Stück weiterhin als gültig und sollte als größer angesehen werden als ein Stück mit der Fläche `nil`.
~~~~

```swift
biggestSlice(diameterA: "10", slicesA: "6", diameterB: "14", slicesB: "12")
// Returns "Slice A is bigger"
biggestSlice(diameterA: "10", slicesA: "6", diameterB: "12", slicesB: "8")
// Returns "Slice B is bigger"
biggestSlice(diameterA: "Pepperoni", slicesA: "6", diameterB: "Sausage", slicesB: "12")
// Returns "Neither slice is bigger"
```
