# Hinweise

## Allgemein

- Alle Speicheradressen in dieser Übung sind auf 16 Byte ausgerichtet, deshalb sind die ausgerichteten Move-Befehle (`movdqa` für Ganzzahlen, `movaps` für Gleitkommazahlen) passend.
  Eine ausgerichtete Adresse kann auch direkt als Speicher-Quelloperand verwendet werden.

## 1. Ein Bild in die Anzeigereihenfolge umwandeln

- Innerhalb jedes 4-Byte-Pixels vertauscht die Umwandlung das Byte an Offset `0` (Rot) mit dem Byte an Offset `2` (Blau) und lässt die Offsets `1` (Grün) und `3` (Alpha) unverändert.
  Dasselbe Muster wiederholt sich über alle vier Pixel.
- Ein [Shuffle][pshufb] kann verwendet werden, um Bytes an Ort und Stelle gemäß den Indizes in einem Steuervektor umzuordnen.
- Der Steuervektor kann im Speicher definiert werden.
- Es kann mehr als einen Block geben, und jeder Block ist 16 Byte groß.

## 2. Einen Bereich mit einer Farbe füllen

- Die Farbe ist ein einzelnes 4-Byte-Pixel.
  Um sie 16 Byte auf einmal zu speichern, sollte sie zunächst über alle vier Lanes eines `xmm`-Registers [verteilt][pshufd] werden.
- Ein 4-Byte-Pixel muss zunächst in ein `xmm`-Register [verschoben][pinsrd] werden, bevor es verteilt wird.
- Jeder gefüllte Block ist identisch, daher kann das gefüllte Register einmal erstellt und dann wiederverwendet werden.
- Es kann mehr als einen Block geben, und jeder Block ist 16 Byte groß.

## 3. Zwei Scanlines verweben

- [Unpack][unpack]-Befehle können verwendet werden, um die Bytes zweier Operanden zu verschachteln.
- Beide Unpack-Befehle nehmen das erste Byte jedes Paares aus dem Zieloperanden und das zweite aus dem Quelloperanden.

## 4. Eine aufgehellte Zeile packen

- [Pack][pack]-Befehle können verwendet werden, um Lanes zu verkleinern und sie dabei zu begrenzen.
- Pack-Befehle nehmen die niedrigen Lanes aus dem Zieloperanden und die hohen Lanes aus dem Quelloperanden.

## 5. Koordinaten in x und y aufteilen

- [Gleitkommazahl-Shuffles][shufps] können verwendet werden, um Lanes aus zwei Operanden auszuwählen und umzuordnen.
- Die `x`-Koordinaten liegen in den geraden Lanes (`0` und `2`) jeder Eingabe und die `y`-Koordinaten in den ungeraden Lanes (`1` und `3`).
