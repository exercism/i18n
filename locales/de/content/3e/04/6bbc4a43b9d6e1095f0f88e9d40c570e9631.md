# Anleitung

Elyse, eine angehende Zauberin, setzt ihre Ausbildung fort. Sie bekommt mehrere Kartenstapel, mit denen sie ihre Tricks vorführen muss.
Damit alles etwas einfacher wird, verwendet sie nur die Karten 1 bis 10.

In dieser Übung verwendest du eingebaute Methoden, um den Inhalt eines Arrays zu analysieren.

## 1. Finde die Position einer Karte

Elyse möchte die Position (den Index) einer Karte im Stapel wissen.

```javascript
const card = 2;
getCardPosition([9, 7, 3, 2], card);
// => 3
```

## 2. Stelle fest, ob eine Karte vorhanden ist

Elyse möchte feststellen, ob eine Karte im Stapel vorhanden ist, mit anderen Worten, ob der Stapel eine bestimmte `number` enthält.

```javascript
const card = 3;
doesStackIncludeCard([2, 3, 4, 5], card);
// => true
```

## 3. Stelle fest, ob jede Karte gerade ist

Elyse möchte wissen, ob jede Karte gerade ist, mit anderen Worten, ob jede Zahl im Stapel eine gerade `number` ist.

```javascript
isEachCardEven([2, 4, 6, 7]);
// => false
```

## 4. Prüfe, ob der Stapel eine Karte mit ungeradem Wert enthält

Elyse möchte wissen, ob es eine ungerade Zahl im Stapel gibt.

```javascript
doesStackIncludeOddCard([3, 2, 6, 4, 8]);
// => true
```

## 5. Hole die erste ungerade Karte aus dem Stapel

Elyse möchte den Wert der ersten Karte wissen, die ungerade ist.

```javascript
getFirstOddCard([4, 2, 8, 7, 9]);
// => 7
```

## 6. Bestimme die Position der ersten Karte, die gerade ist

Elyse möchte die Position der ersten Karte wissen, die gerade ist.

```javascript
getFirstEvenCardPosition([5, 2, 3, 1]);
// => 1
```
