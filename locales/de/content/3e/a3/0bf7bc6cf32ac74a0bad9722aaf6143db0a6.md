# Einführung in Arrays

Bash kennt zwei Arten von Parametern: „skalare“ Werte und Arrays.
Ein skalarer Wert kann ein String oder eine Zahl sein; er repräsentiert eine einzelne „Sache“.

Meistens reichen skalare Werte aus, um deine Daten zu speichern.
Manchmal musst du aber eine Liste von skalaren Werten speichern.
In diesem Fall verwendest du ein _Array_.

Es gibt zwei Arten von Arrays:

* Numerisch indizierte Arrays ordnen einem Ganzzahl-Schlüssel einen String-Wert zu.
  (Andere Sprachen nennen das vielleicht eine „Liste“ oder eine „Sequenz“.)
* Assoziative Arrays ordnen einem String-Schlüssel einen String-Wert zu.
  (Andere Sprachen nennen das vielleicht eine „Map“ oder ein „Wörterbuch“.)

Die ersten Abschnitte dieses Dokuments behandeln numerisch indizierte Arrays (im Folgenden einfach „Arrays“ genannt).
Details zu assoziativen Arrays kommen am Ende.

~~~~exercism/caution
Bash-Arrays können _nur_ skalare Werte speichern.
Es gibt keine Möglichkeit, ein zweidimensionales Array (Array von Arrays) zu erstellen.
~~~~

## Eine Array-Variable deklarieren und initialisieren

Du kannst ein Array initialisieren, indem du einer Variablen eine in runden Klammern stehende Liste von Elementen (möglicherweise leer) zuweist.

```bash
myarray=("one" "two" "three")
```

Wie bei jeder Variablenzuweisung dürfen um das Gleichheitszeichen keine Leerzeichen stehen.

Beachte, dass es keine Kommas zwischen den Elementen gibt; es ist eine durch Leerzeichen getrennte Liste von Strings.

Tatsächlich ist die Menge an Leerraum innerhalb der runden Klammern völlig beliebig.
Zeilenumbrüche sind erlaubt; verwende so viele du möchtest, um die Lesbarkeit zu verbessern.

```bash
myarray=(
    "first element"
    "second element"
    "this is the last element"
)
```

Wenn du einer Array-Variable auf diese Weise eine Liste von Strings zuweist, wird der erste String unter Index null gespeichert, der nächste unter Index eins, der übernächste unter Index zwei und so weiter.

Es ist möglich, ein „dünn besetztes Array“ zu initialisieren, indem du die benötigten Indizes angibst.

```bash
raindrops=([3]="Pling" [5]="Plang [7]="Plong")
```

~~~~exercism/note
Um es zu wiederholen: Array-Indizes sind nullbasiert.
Dieses Schnipsel gibt „true“ aus:

```bash
myarray=("one" "two" "three")
[[ "${myarray[0]}" == "one" ]] && echo true || echo false
```
~~~~

Du kannst den Befehl `declare` (oder `local` innerhalb einer Funktion) verwenden, um anzugeben, dass eine Variable ein Array enthalten wird.

```bash
declare -a myarray
```

Es ist idiomatischer, einfach eine (vielleicht leere) Liste in runden Klammern zuzuweisen, um die Variable zu initialisieren.

## Auf Elemente eines Arrays zugreifen

Wie du in der obigen Notiz gesehen hast, lautet die Syntax für den Zugriff auf ein Array-Element `${myarray[$index]}`.
Der Index wird in eckigen Klammern angegeben.
Die geschweiften Klammern sind erforderlich.

~~~~exercism/note
Bei numerisch indizierten Arrays ist der Index ein arithmetischer Ausdruck.
Im Bash-Handbuch [steht][arithmetic]:

> Innerhalb eines arithmetischen Ausdrucks können Shell-Variablen auch über ihren Namen referenziert werden, ohne die Syntax der Parametererweiterung zu verwenden.

Das bedeutet, dass das `$` für die „einfache“ Variablenerweiterung nicht erforderlich ist.
Du kannst auf Elemente so zugreifen, was etwas leichter zu lesen ist:

```bash
i=5
echo "${myarray[i]}"
# ..............^
```

[arithmetic]: https://www.gnu.org/software/bash/manual/bash.html#Shell-Arithmetic
~~~~

Wenn der angegebene Index im Array nicht existiert, ist das Ergebnis der Erweiterung ein leerer String.

## Einem Array etwas zuweisen

Um einem bestimmten Array-Eintrag etwas zuzuweisen, verwende diese Syntax:

```bash
myarray[10]="hello"
```

Um etwas an ein Array _anzuhängen_, verwende den zusammensetzenden Zuweisungsoperator `+=` und runde Klammern:

```bash
myarray+=("new element 1" "new element 2")
```

## Über ein Array iterieren

Typischerweise musst du über die _Werte_ eines Arrays iterieren.
Verwende eine `for`-Schleife (die du im [Schleifen][looping]-Konzept gesehen hast):

```bash
myarray=("one" "two" "three")
for value in "${myarray[@]}"; do
    echo "$value"
done
```

Beachte die spezielle Syntax zum Erweitern des Arrays: `"${myarray[@]}"`
Diese Form der Parametererweiterung ersetzt die Array-Werte als separate Wörter.
Sie ist in etwa äquivalent zu:

```bash
for value in "${myarray[0]}" "${myarray[1]}" ... "${myarray[n]}"
```

Die Form `"${myarray[@]}"` funktioniert mit dünn besetzten Arrays und erweitert nur zu definierten Werten.

Diese spezielle Erweiterung, bei der der Index ein At-Zeichen (`@`) ist, ist nur innerhalb doppelter Anführungszeichen speziell.

#### Weitere spezielle Parametererweiterungen

Hier sind noch ein paar Bits spezieller Syntax, die wir für die Iteration über ein Array brauchen.
Diese werden im Handbuch unter [Shell-Parametererweiterung][man-expn] beschrieben.

Um die _Länge_ eines Arrays herauszufinden, verwende `${#myarray[@]}`, mit einem `#` vor dem Namen.
Die „Länge“ eines Arrays ist die Anzahl der Elemente darin.

Um die Liste der _Indizes_ eines Arrays zu extrahieren, verwende `"${!myarray[@]}"`, mit einem `!` vor dem Namen und der Erweiterung in doppelten Anführungszeichen.
Bei numerisch indizierten Arrays werden die Indizes in numerischer Reihenfolge erweitert.

### Über Array-Indizes iterieren

Manchmal brauchst du sowohl den Index als auch den Wert.
Dafür gibt es ein paar Möglichkeiten.

1. Wenn du weißt, dass die Indizes eine ununterbrochene Folge bilden, kannst du eine _arithmetische_ `for`-Schleife verwenden.

   ```bash
   for ((i = 0; i < ${#myarray[@]}; i++)); do
       echo "$i -> ${myarray[i]}"
   done
   ```

   Beachte die Syntax `${#myarray[@]}` mit dem Zeichen `#` vor dem Array-Namen.
   Da Arrays eine nullbasierte Indizierung verwenden, ist der letzte Index des Arrays um eins kleiner als die Array-Länge.

2. Wenn das Array dünn besetzt ist, kannst du diese Form verwenden:

   ```bash
   for index in "${!raindrops[@]}"; do
       echo "$index -> ${raindrops[index]}"
   done
   ```

   Beachte die Syntax `${!myarray[@]}` mit dem Zeichen `!` vor dem Array-Namen.

## Ein Array untersuchen

Wenn du dir den Inhalt eines Arrays ansehen möchtest, verwende den Befehl `declare` mit der Option `-p`:

```bash
a=("the 'first' element"
   second
   third
   'the "last" element')
declare -p a
```

Dies gibt den Inhalt mit kanonischem Shell-Quoting aus.

```bash
declare -a a=([0]="the 'first' element" [1]="second" [2]="third" [3]="the \"last\" element")
```

## Assoziative Arrays

Um es zu wiederholen: Assoziative Arrays verwenden Strings als Indizes, keine Zahlen.
Alles oben Geschriebene gilt auch für assoziative Arrays, allerdings mit kleinen Unterschieden.
Im Allgemeinen verwenden wir den Begriff „Schlüssel“ und nicht „Index“: Assoziative Arrays bilden Schlüssel auf Werte ab.

### Ein assoziatives Array deklarieren

Anders als Arrays **müssen** assoziative Arrays deklariert werden.
Verwende die Option `-A` für `declare` (oder `local` in einer Funktion):

```bash
declare -A mymap

myfunc() {
    local -A my_local_map
    # ...
}
```

### Ein assoziatives Array initialisieren

Die Schlüssel-Wert-Paare werden innerhalb der Liste in runden Klammern angegeben:

```bash
mymap=([first]=foo [second]=bar [third]=baz)
declare -p mymap
```

Dies gibt aus:

```
declare -A mymap=([second]="bar" [first]="foo" [third]="baz")
```

~~~~exercism/note
Beachte, dass assoziative Arrays **ungeordnet** sind.
~~~~

Deklaration und Initialisierung können in einer Zeile erfolgen.

```bash
declare -A mymap=([first]=foo [second]=bar [third]=baz)
```

In neueren Bash-Versionen kann die Initialisierung eine Liste `(key value key value ...)` verwenden.

```bash
declare -A mymap=(first foo second bar third baz)
```

### Auf Werte zugreifen

Für den Zugriff auf Elemente wird dieselbe Syntax wie zuvor verwendet: `${mymap[$key]}`.

Schlüssel assoziativer Arrays werden nicht in einem arithmetischen Kontext ausgewertet.
Die übliche Syntax der Parametererweiterung ist erforderlich.

### Einem assoziativen Array etwas zuweisen

Die Zuweisung verwendet dieselbe Syntax wie zuvor:

```bash
mymap[$key]="$value"
```

### Iterieren

Du kannst eine Schleife der Form `for value in "${mymap[@]}"` verwenden, um zu iterieren.
Normalerweise möchtest du aber auch den Schlüssel zusammen mit dem Wert haben.

Verwende die Syntax `"${!mymap[@]}"`, die wir oben gesehen haben.

```bash
for key in "${!mymap[@]}"; do
    echo "$key -> ${mymap[$key]}"
done
```

Dies gibt aus

```
second -> bar
first -> foo
third -> baz
```

Um es noch einmal zu betonen: Die Schlüssel haben keine Reihenfolge.
