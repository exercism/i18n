# Hinweise

## 1. Eine zufällige Registrierungsnummer für ein Raumschiff erzeugen

- Um eine zufällige Zahl im Bereich von _min_ (einschließlich) bis _max_ (ausschließlich) zu erzeugen, kannst du den Codeschnipsel `min + Math.random()*(max - min)` verwenden.
- Es gibt eine [integrierte Funktion][floor], mit der du eine Gleitkommazahl in eine Ganzzahl umwandeln kannst.

## 2.Eine zufällige Sternzeit erzeugen

- Um eine zufällige Zahl im Bereich von _min_ (einschließlich) bis _max_ (ausschließlich) zu erzeugen, kannst du den Codeschnipsel `min + Math.random()*(max - min)` verwenden.

## 3. Einen zufälligen Planeten erzeugen

- Du kannst eine zufällig erzeugte Ganzzahl als Index für ein Array verwenden.

[floor]: https://developer.mozilla.org/en-US/docs/Web/JavaScript/Reference/Global_Objects/Math/floor
