# for-Schleifen

Schleifen sind ein grundlegendes Konzept in der Programmierung, mit dem du einen Block Code mehrmals ausführen kannst.
In Swift gibt es zwei Arten von Schleifen: [`for-in`-Schleifen][for-loops] und `while`-Schleifen.
In diesem Kapitel lernst du `for-in`-Schleifen kennen.

Mit for-Schleifen kannst du über eine Sequenz von Werten iterieren und dabei jedes Element der Reihe nach an eine Variable deiner Wahl binden.
Swift erlaubt es dir, über eine Vielzahl von Sequenzen zu iterieren, etwa Bereiche, Arrays und Strings (und weitere Typen, die später behandelt werden).
Wenn über jedes Element der Sequenz iteriert wurde, endet die Schleife.

For-Schleifen deklarierst du mit dem Schlüsselwort `for`, gefolgt von einem Variablennamen, dem Schlüsselwort `in` und einer Sequenz von Werten, über die iteriert wird.
Die Variable, die in der `for-in`-Schleife angegeben wird, ist unveränderlich, das heißt, du kannst ihren Wert innerhalb der Schleife nicht ändern.
Hier ist ein Beispiel für eine `for-in`-Schleife, die über ein Array von Zahlen iteriert:

```swift
let numbers = [3, 10, 7, 11]

for number in numbers {
  print(number)
}
print("Done with numbers")

// prints:
// 3
// 10
// 7
// 11
// Done with numbers
```

~~~~exercism/note
Die Variable `number` wird in der `for-in`-Schleife deklariert und ist nur innerhalb des Gültigkeitsbereichs der Schleife verfügbar.

```swift
let numbers = [3, 10, 7, 11]

for number in numbers {
    number + 1
}
number + 1
// Error: Use of unresolved identifier 'number'
```
~~~~

## Über einen Bereich iterieren

Du kannst auch mit einer `for-in`-Schleife über einen Bereich von Zahlen iterieren.
So kannst du einen Block Code eine bestimmte Anzahl von Malen ausführen. Der Bereich `1...5` zum Beispiel durchläuft die Zahlen 1, 2, 3, 4 und 5, die Schleife wird also 5-mal ausgeführt.
Manchmal möchtest du über Indizes in einer Datenstruktur wie einem Array iterieren, dann kannst du einen Bereich `0..<array.count` verwenden.

```swift
let numbers = [3, 10, 7, 11]

for i in 0..<numbers.count {
  print(numbers[i])
}

// prints:
// 3
// 10
// 7
// 11
```

## Über einen String iterieren

Du kannst auch mit einer `for-in`-Schleife über einen String iterieren.
So kannst du über jedes Zeichen im String iterieren. Beachte, dass der Typ, der in der Schleife angegeben wird, ein `Character` ist.

```swift
let message = "Hello!"

for character in message {
  print(character)
}

// prints:
// H
// e
// l
// l
// o
// !
```

## Ungenutzte Variablen

Wenn du den Wert der Variable in der Schleife nicht brauchst, kannst du einen Unterstrich `_` verwenden, um ihn zu ignorieren.

```swift
let numbers = [3, 10, 7, 11]

for _ in numbers {
  print("Hello!")
}
```

## stride

Swift bietet außerdem eine `stride`-Funktion, mit der du eine Sequenz über einen Bereich mit einer bestimmten Schrittweite erzeugen kannst.
Über diese kannst du dann mit einer `for-in`-Schleife iterieren.
`stride` ist definiert als [`stride(from:to:by:)`][stride-to] oder [`stride(from:through:by:)`][stride-through]. Die erste Variante ist exklusiv und die zweite inklusiv.

```swift
for i in stride(from: 0, to: 10, by: 2) {
  print(i)
}

// prints:
// 0
// 2
// 4
// 6
// 8
```

Beachte, dass der Parameter `to` exklusiv ist, die Schleife also bis zu der Zahl vor dem Parameter `to` iteriert, während der Parameter `through` inklusiv ist, hier also auch die `10` einschließen würde.

[stride-to]: https://developer.apple.com/documentation/swift/stride(from:to:by:)
[stride-through]: https://developer.apple.com/documentation/swift/stride(from:through:by:)
[for-loops]: https://docs.swift.org/swift-book/documentation/the-swift-programming-language/controlflow/#For-In-Loops
