# Methode zu lang

Zerlege die folgende(n) Methode(n) am besten in Aufrufe anderer Methoden, die inhaltlich eine eigene Bedeutung haben: `%{methodNames}`

Die Methode hat mehr Codezeilen, als diese Übung normalerweise verlangt.
Das kann in Ordnung sein, aber es könnte ein Hinweis darauf sein, dass die Methode direkt zu viel Arbeit erledigt und einen Teil davon an andere Methoden delegieren sollte.
Versuche, alles innerhalb einer Methode auf einer Abstraktionsebene zu halten.
Zum Beispiel könnte das Durchlaufen der Elemente einer Schleife in einer Methode stehen, während die Bearbeitung jedes einzelnen Elements in einer anderen steht.
