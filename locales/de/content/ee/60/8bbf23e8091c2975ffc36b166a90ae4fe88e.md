# Einführung

Elixir verwendet _Behaviours_, um gemeinsame generische Schnittstellen bereitzustellen und gleichzeitig spezifische Implementierungen für jedes Modul zu ermöglichen, das sie umsetzt. Ein bekanntes Beispiel dafür ist das _Access Behaviour_.

Das _Access Behaviour_ bietet eine gemeinsame Schnittstelle, um Daten aus einer schlüsselbasierten Datenstruktur abzurufen. Es ist für Maps und Keyword-Listen implementiert. Schauen wir uns aber seine Verwendung mit Maps an, um ein Gefühl dafür zu bekommen. Das _Access Behaviour_ legt fest, dass du bei einer Map _eckige Klammern_ anhängen und darin den Schlüssel angeben kannst, um den zugehörigen Wert abzurufen.

```elixir
# Suppose we have these two maps defined (note the difference in the key type)
my_map = %{key: "my value"}
your_map = %{"key" => "your value"}

# Obtain the value using the Access Behaviour
my_map[:key] == "my value"
your_map[:key] == nil
your_map["key"] == "your value"
```

Wenn der Schlüssel in der Datenstruktur nicht existiert, wird `nil` zurückgegeben. Das kann zu unbeabsichtigtem Verhalten führen, denn es wird kein Fehler ausgelöst. Beachte, dass `nil` selbst das Access Behaviour implementiert und für jeden Schlüssel immer `nil` zurückgibt.
