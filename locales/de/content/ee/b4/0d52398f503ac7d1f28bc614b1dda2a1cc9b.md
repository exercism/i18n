# Hinweise

## 1. Eine Sprache zum @Languages-Array hinzufügen

- Du möchtest das `@Languages`-Array ändern, um eine neue Sprache am Ende hinzuzufügen.

## 2. Eine Sprache aus dem @Languages-Array entfernen

- Du möchtest das `@Languages`-Array ändern, um die letzte Sprache zu entfernen.

## 3. Die erste Sprache aus dem @Languages-Array abrufen

- Du möchtest das erste Element des `@Languages`-Arrays mit `return` zurückgeben.

## 4. Die letzte Sprache aus dem @Languages-Array abrufen

- Du möchtest das letzte Element des `@Languages`-Arrays mit `return` zurückgeben.

## 5. Einen Ausschnitt von Sprachen aus dem @Languages-Array abrufen

- Du möchtest einen Ausschnitt des `@Languages`-Arrays.
- Denk daran, dass Indizes bei 0 beginnen. Element `1` hat den Index `0`.

## 6. Prüfen, ob eine Sprache im @Languages-Array vorhanden ist

- Du möchtest entweder einen wahren Wert, z. B. `1`, oder einen falschen Wert, z. B. `0`, zurückgeben, wenn die angegebene Sprache im `@Languages`-Array gefunden werden kann.
