# Einführung

Im Konzept [`Vectors`][vectors] haben wir gesagt, dass „Arrays das Herz der Sprache Julia sind“, und dass ein Vektor ein eindimensionales Array ist.

Vor diesem Hintergrund können wir mit gutem Grund hoffen, dass die Sprache viele vielseitige und mächtige Möglichkeiten bietet, mit Vektoren _etwas anzufangen_, was auch immer das bedeuten mag.

## Funktionen, die einen Vektor als Eingabe erwarten

Einige sehr einfache Funktionen nehmen einen Vektor als Eingabewert und geben einen skalaren Wert zurück.

```julia
v = [2, 3, 4]
length(v)  # => 3
sum(v)  # => 9
```

## Arithmetik

Angenommen, du hast einen numerischen Vektor und möchtest von jedem Wert 0,5 subtrahieren.

```julia-repl
julia> v = [1.2, 1.5, 1.7]
3-element Vector{Float64}:
 1.2
 1.5
 1.7

julia> v - 0.5
ERROR: MethodError: no method matching -(::Vector{Float64}, ::Float64)
```

Das schlägt fehl. Wie wäre es dann, einen anderen Vektor zu subtrahieren?

```julia-repl
julia> v - [0.5, 0.5, 0.5]
3-element Vector{Float64}:
 0.7
 1.0
 1.2
```

Das funktioniert, ist aber ziemlich mühsam und speicherhungrig, je länger die Vektoren werden.

Zum Glück hat Julia einen „magischen“ Punkt, der dieses Problem ganz einfach löst: `v .- 0.5` ist alles, was du brauchst.

Der nächste Abschnitt erklärt, warum.

## Broadcasting

`v - 0.5` schlägt also fehl, `v .- 0.5` funktioniert. Wir müssen verstehen, was der Punkt bewirkt.

Zwei Dinge, die zusammen das gewünschte Ergebnis ergeben.

### 1. Elementweise Anwendung

Erstens bedeutet ein Punkt _vor_ einem Infix-Operator: „Wende diese Operation auf jedes Element einzeln an“.

Genauso „vektorisiert“ ein Punkt _nach_ einem Funktionsnamen die Funktion, auch wenn sie für skalare Eingaben geschrieben wurde.

```julia-repl
julia> sqrt.([1, 4, 9])
3-element Vector{Float64}:
 1.0
 2.0
 3.0
```

### 2. Singleton-Erweiterung

In einem vorherigen Beispiel haben wir gesehen, dass wir Vektoren gleicher Länge subtrahieren können. Beachte aber, dass `.-` ein _sicherer_ Operator als `-` ist, weil er die elementweise Absicht deutlich macht.

```julia-repl
julia> v .- [0.5, 0.5, 0.5]
3-element Vector{Float64}:
 0.7
 1.0
 1.2
```

Was ist mit Vektoren ungleicher Länge?

```julia-repl
julia> v .- [0.5, 0.5]
ERROR: DimensionMismatch: arrays could not be broadcast to a common size

julia> v .- [0.5,]
3-element Vector{Float64}:
 0.7
 1.0
 1.2
```

Im Allgemeinen sind ungleiche Längen ein Fehler, _außer_ wenn einer die Länge 1 hat (technisch gesehen eine „Singleton“-Dimension).

Singletons wie `[0.5,]` oder einfach nur `0.5` werden automatisch durch Wiederholung auf die nötige Länge erweitert.
Das ist der Kern des `broadcasting`.

### In-Place-Broadcasting

Wenn der Speicherverbrauch eine Rolle spielt, sind In-Place-Operationen ein üblicher Weg, um Allokationen zu reduzieren.

Die Broadcasting-Operationen in den Beispielen oben erzeugen jedoch einen neuen `Vector`, statt den ursprünglichen zu verändern.

Um den ursprünglichen `Vector` in-place zu verändern, muss die Änderung per Broadcasting erfolgen.

```julia-repl
julia> v .= v .+ 1
3-element Vector{Int64}:
 2
 3
 4

julia> v .+= 1  # equivalent operation to above
3-element Vector{Int64}:
 3
 4
 5

julia> v
3-element Vector{Int64}:
 3
 4
 5
```

## Indizierung

Wie du Elemente eines Vektors über die Indexnummer auswählst, haben wir in früheren Konzepten besprochen.

```julia
a = collect('A':'Z')  # => 26-element Vector{Char}

# index with an integer
a[2]  # => 'B'

# index with a range
 a[12:2:18]  # => ['L', 'N', 'P, 'R']
 
 # index with another vector
 a[ [1, 3, 5] ]  # => ['A', 'C', 'E']
```

### Logisches Indizieren

Du kannst auch Elemente auswählen, die einen logischen Ausdruck erfüllen (technisch gesehen ein „Prädikat“).
Das erfordert meist Broadcasting.

```julia-repl
julia> a[a .< 'D']
3-element Vector{Char}:
 'A': ASCII/Unicode U+0041 (category Lu: Letter, uppercase)
 'B': ASCII/Unicode U+0042 (category Lu: Letter, uppercase)
 'C': ASCII/Unicode U+0043 (category Lu: Letter, uppercase)
```

Bei komplexeren Ausdrücken vermehren sich die Punkte schnell (aber sie sind klein und leicht zu tippen).

```julia-repl
julia> a[a .< 'D' .|| a .> 'W']
6-element Vector{Char}:
 'A': ASCII/Unicode U+0041 (category Lu: Letter, uppercase)
 'B': ASCII/Unicode U+0042 (category Lu: Letter, uppercase)
 'C': ASCII/Unicode U+0043 (category Lu: Letter, uppercase)
 'X': ASCII/Unicode U+0058 (category Lu: Letter, uppercase)
 'Y': ASCII/Unicode U+0059 (category Lu: Letter, uppercase)
 'Z': ASCII/Unicode U+005A (category Lu: Letter, uppercase)
```

Zur Erinnerung: Der „Vektor“ kann in Wirklichkeit jedes passende geordnete Iterable sein, zum Beispiel ein Bereich:

```julia-repl
julia> n = 3:10
3:10

julia> n[isodd.(n)]
4-element Vector{Int64}:
 3
 5
 7
 9
```
