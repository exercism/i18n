# Zahlentypen

Crystal bietet eine Vielzahl verschiedener Zahlentypen für unterschiedliche Zwecke.
Manche Typen sind zum Beispiel schneller, haben aber einen kleineren Wertebereich als andere.
Andere haben einen größeren Wertebereich, sind dafür aber langsamer.

In Crystal gibt es sowohl vorzeichenbehaftete als auch vorzeichenlose Ganzzahltypen.
Die vorzeichenbehafteten Ganzzahltypen können positiv oder negativ sein.
Die vorzeichenlosen Ganzzahltypen können nur positiv sein.

## Vorzeichenbehaftete Ganzzahltypen

Das sind die [vorzeichenbehafteten Ganzzahltypen][int] in Crystal:

| Typ      | Größe (Bits) | Wertebereich                                                                                                |
| -------- | ------------ | ----------------------------------------------------------------------------------------------------------- |
| `Int8`   | 8            | -128 bis 127                                                                                                |
| `Int16`  | 16           | -32_768 bis 32_767                                                                                          |
| `Int32`  | 32           | -2_147_483_648 bis 2_147_483_647                                                                            |
| `Int64`  | 64           | -9_223_372_036_854_775_808 bis 9_223_372_036_854_775_807                                                    |
| `Int128` | 128          | -170_141_183_460_469_231_731_687_303_715_884_105_728 bis 170_141_183_460_469_231_731_687_303_715_884_105_727 |

Die kleineren Typen brauchen weniger Speicher und sind schneller als die größeren, haben aber einen kleineren Wertebereich.

Wenn du weißt, dass die Werte in einem bestimmten Bereich liegen, ist es am besten, den kleinstmöglichen Typ zu verwenden, um Speicher zu sparen und die Leistung zu verbessern.

Der Standardtyp für Ganzzahlen ist `Int32`.
Um eine Ganzzahl mit einem bestimmten Typ zu deklarieren, kannst du den Typnamen als Suffix verwenden, indem du `<number>_I <bit>` anhängst.

```crystal
1_i8.class
# => Int8
```

Mit der Methode `to_i<bit>` kannst du zwischen verschiedenen Ganzzahltypen umwandeln.
Die Methode `to_i` wandelt in den Standardtyp für Ganzzahlen um, `Int32`.

```crystal
1_i8.to_i16.class
# => Int16

2_i16.to_i.class
# => Int32
```

## Vorzeichenlose Ganzzahltypen

Das sind die [vorzeichenlosen Ganzzahltypen][uint] in Crystal:

`UInt8`, `UInt16`, `UInt32`, `UInt64`, `UInt128`

Der einzige Unterschied zwischen vorzeichenbehafteten und vorzeichenlosen Ganzzahlen ist, dass vorzeichenlose Ganzzahlen nur positiv sein können.
Um eine vorzeichenlose Ganzzahl mit einem bestimmten Typ zu deklarieren, kannst du den Typnamen als Suffix verwenden, indem du `<number>_u<bit>` anhängst.
Mit der Methode `to_u<bit>` kannst du zwischen verschiedenen vorzeichenlosen Ganzzahltypen umwandeln.
Die Methode `to_u` wandelt in den Standardtyp für vorzeichenlose Ganzzahlen um, `UInt32`.

```crystal
1_u8.to_u16.class
# => UInt16
```

## Gleitkommazahltypen

Das sind die Gleitkommazahltypen in Crystal:

| Typ       | Größe (Bits) | Wertebereich          |
| --------- | ------------ | --------------------- |
| `Float32` | 32           | 1.2E-38 bis 3.4E+38   |
| `Float64` | 64           | 2.3E-308 bis 1.7E+308 |

Es gibt zwei verschiedene [Gleitkommazahltypen][float], von denen einer präziser ist als der andere.

Der Standardtyp für Gleitkommazahlen ist `Float64`.

Mit der Methode `to_f<bit>` kannst du zwischen verschiedenen Gleitkommazahltypen umwandeln.
Die Methode `to_f` wandelt in den Standardtyp für Gleitkommazahlen um, `Float64`.

[float]: https://crystal-lang.org/api/latest/Float.html
[int]: https://crystal-lang.org/api/latest/Int.html
[uint]: https://crystal-lang.org/api/latest/UInt32.html
