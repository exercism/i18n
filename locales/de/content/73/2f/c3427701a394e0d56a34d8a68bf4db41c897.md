# Über

[Switch-Ausdrücke][switch-expressions] verhalten sich ähnlich wie die [switch-Anweisungen][switch-statements], die in [concept:csharp/switch-statements]() behandelt werden. Sie unterstützen eine Art Entscheidungstabelle, die Eingabebedingungen auf Aktionen oder Werte abbildet.

Im Kern des switch-Ausdrucks steht der _Musterabgleich_. In der Programmierübung haben wir Werte mit `const`-Mustern abgeglichen. In diesem Fall ist die Eingabe für das `switch` ein _Bereichsausdruck_, der mit const-Werten und den Werten der _case-Wächter_ abgeglichen wird.

Die Fälle (auch _switch-Arme_ genannt) werden in der Reihenfolge ausgewertet, in der sie im Text stehen. Sobald ein Treffer gefunden wurde, wird der Vorgang abgebrochen und der zugehörige Wert zurückgegeben.

Der `_`-Fall, der in der Liste am Ende steht, ist nützlich, um sicherzustellen, dass der Abgleich vollständig ist, und um mögliche Laufzeitfehler zu vermeiden.

```csharp
double xx = 42d;

string interesting = xx switch
{
    0 => "I suppose zero is interesting",
    3.14 when DateTime.Now.Day == 14 && DateTime.Now.Month == 3 => "Mmm pie!",
    3.14 => "π",
    42 => "a bit of a cliché",
    1729 => "only if you are a pure mathematician",
    _ => "not interesting"
};

// => interesting == "a bit of a cliché"
```

Ein „Arm" des `switch` wird ausgewählt, wenn das Muster auf die Bereichsvariable passt und etwaige case-Wächter wahr ergeben.

Switch-Ausdrücke unterstützen außerdem [Typmuster][pattern-matching] und rekursiven Abgleich.
