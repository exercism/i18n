# Einführung

Es gibt im Wesentlichen zwei Arten von Schleifen:

1. Wiederhole, bis eine Bedingung erfüllt ist.
2. Iteriere über die Elemente in einer Sammlung.

Beides ist in R möglich, wobei Ersteres häufiger vorkommt.

## `while` und `repeat`

Für Probleme ohne festes Ende, bei denen die Anzahl der Schleifendurchläufe nicht im Voraus bekannt ist, hat R die `while`-Schleife mit einer Bedingung und die `repeat`-Schleife ohne Bedingung (entspricht `while (TRUE)`).

Die Grundform ist recht einfach:

```R
while (condition) {
  do_something()
}
```

In diesem Fall läuft das Programm so lange durch die Schleife, bis `condition` nicht mehr `TRUE` ist.

Es gibt zwei Möglichkeiten, die Schleife vorzeitig zu verlassen:

- Ein `break` beendet die Schleife, und die Ausführung fährt mit der nächsten Zeile nach der schließenden Klammer `}` der Schleife fort.
- Ein `return(x)` beendet die Ausführung der aktuellen Funktion und gibt den Rückgabewert `x` an den Aufrufer zurück.

Mit diesen Möglichkeiten kann es manchmal praktisch sein, eine „unendliche“ Schleife mit `repeat { ... }` zu erstellen und sich dann darauf zu verlassen, im Schleifenblock eine Abbruchbedingung zu finden, die ein `break` oder `return` auslöst.

Diese drei Varianten sind äquivalent und enden alle mit `x == 0.4444...`

```R
x <- 12
while (x > 1) {
  x <- x / 3
}

x <- 12
while (TRUE) {
  x <- x/3
  if (x <= 1) break
}

x <- 12
# no boolean clause 
repeat { 
  x <- x/3
  if (x <= 1) break
}
```

## Über einen Vektor iterieren

Das ist in R oft nicht nötig.
Wie in anderen Konzepten besprochen, arbeiten viele Funktionen auf ganzen Vektoren.

Manchmal sind explizite Schleifen jedoch unvermeidlich.
Das gilt besonders, wenn:

- der Schleifenblock Seiteneffekte hat, etwa Ausgaben oder Datei-Ein-/Ausgabe.
- die Wiederholung so lange läuft, bis ein bestimmtes Kriterium erreicht ist, nach einer unvorhersehbaren Anzahl von Iterationen.

Die Schleifenbedingung muss in runden Klammern stehen.
Wie bei Funktionskörpern sind geschweifte Klammern bei einzeiligen Schleifenblöcken optional (aber oft üblich).

```R
words <- c("This", "is", "a", "loop")
for (w in words) { print(w) } # the braces are optional here
#> [1] "This"
#> [1] "is"
#> [1] "a"
#> [1] "loop"
```

Wenn die aktuelle Iteration eine Bedingung nicht erfüllt, kannst du mit einem `next` sofort zur nächsten Iteration springen:

```R
for (n in 1:10) {
    if (is_useless(n)) next
     
    # we decided this iteration could be useful
    do_something_slow(n)
}
```

Wenn der numerische Index benötigt wird, verwende `seq_along()`.

```R
v <- LETTERS[1:3]
v
#> [1] "A" "B" "C"

for (i in seq_along(v)) { print(sprintf("%s%i", v[i], i)) }
#> [1] "A1"
#> [1] "B2"
#> [1] "C3"
```

Die Verwendung von `i in 1:length(v)` ist _nicht_ zu empfehlen, da dies Probleme verursachen kann, wenn `length(v)` null ist.
Der Bereich `1:0` entspricht `c(1, 0)`, sodass der Schleifenblock ausgeführt wird und wahrscheinlich fehlschlägt.
Die Funktion `seq_along()` ist darauf ausgelegt, diesen Fall korrekt zu behandeln.
