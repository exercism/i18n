# Tests

Du kannst den Online-Editor auf der Exercism-Website verwenden, um die Übungen zu lösen.
Oder du lädst die Übungen auf deinen Computer herunter, löst sie lokal und reichst sie dann bei Exercism ein.
Im Rest dieses Dokuments geht es darum, lokal zu arbeiten.

## Exercism CLI

Du brauchst das `exercism`-Kommandozeilen-Tool, um Übungen herunterzuladen und einzureichen.
Wie du es herunterlädst und einrichtest, steht in [der Dokumentation zur Exercism CLI][exercism-cli].

Um eine Übung herunterzuladen, machst du Folgendes:

```bash
exercism download --track 8th --exercise hello-world
```

Und dann wechselst du in das Übungsverzeichnis:

```bash
cd /path/to/your/exercism_workspace/8th/hello-world
```

oder unter Windows:

```cmd
cd \path\to\your\exercism_workspace\8th\hello-world
```

Deinen Exercism-Workspace findest du übrigens mit dem Befehl `exercism configure` heraus.

## Lokal testen

Um die Tests für eine Übung auszuführen, musst du dich im richtigen Übungsverzeichnis befinden.
Dann startest du die Tests mit diesem Befehl:

```bash
8th -f test.8th
```

## Übersprungene Tests

Eine Übung zu lösen bedeutet, dass du alle ihre Tests bestehst.
Standardmäßig wird nur ein Test (der erste) ausgeführt, wenn du die Tests ausführst.
Das ist Absicht, denn so kannst du dich darauf konzentrieren, nur diesen einen Test zu bestehen.
Sobald er besteht, kannst du den nächsten Test aktivieren, indem du die Zeile `SKIP-REST-OF-TESTS` nach unten verschiebst.

### Überspringen umgehen

Um alle Tests auszuführen, auch die nach dem Wort `SKIP-REST-OF-TESTS`, kannst du die Umgebungsvariable `RUN_ALL_TESTS` auf den Wert `true` setzen.
Eine Möglichkeit, das nur für die Dauer des Testlaufs zu tun, ist (macOS und Linux):

```bash
RUN_ALL_TESTS=true 8th -f test.8th
```

## Lösung einreichen

Um deine Lösung mit dem Exercism-Tool auf die Exercism-Website hochzuladen:

```bash
exercism submit
```

Beachte, dass du deinen Code auch hochladen kannst, wenn er nicht alle Tests besteht.
Das ist gut, wenn du feststeckst und Hilfe von einem Mentor brauchst.
