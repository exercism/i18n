# Einführung

Wenn Typen nicht implizit gecastet werden können, musst du einen expliziten Cast-Operator verwenden.
Der Cast-Operator ist nichts anderes als der Zieltyp in runden Klammern vor dem Wert, den du casten möchtest:

```csharp

int i = 7;
byte b = (byte)i; // Explicit cast from int to byte
```
