# Anleitung

Du arbeitest als Systemadministrator für ein großes Unternehmen in München. Zu deinen Aufgaben gehört die Verwaltung von E-Mail-Konten.

Immer wieder beschweren sich Leute bei dir, sie könnten Herrn Müller keine E-Mails schreiben. Schnell wird dir klar, dass der Großteil des Unternehmens einen alten E-Mail-Client verwendet, der `müller@firma.de` wegen des Nicht-ASCII-Zeichens nicht als gültige E-Mail-Adresse erkennt.

Den Leuten zu sagen, sie sollen ihren liebsten alten E-Mail-Client aufgeben, ist ein aussichtsloses Unterfangen. Also beschließt du, für alle E-Mail-Konten bereinigte Aliase anzulegen.

## 1. Bereinige vorhandene Benutzernamen, indem du alles außer Kleinbuchstaben entfernst

Implementiere die Funktion `sanitize/1`. Sie soll einen Benutzernamen als Charlist entgegennehmen und den Benutzernamen zurückgeben, aus dem alle Zeichen außer Kleinbuchstaben entfernt wurden.

```elixir
Username.sanitize(~c"schmidt1985")
# => ~c"schmidt"
```

## 2. Erlaube Unterstriche

Erweitere die Funktion `sanitize/1`. Sie soll Unterstriche nicht aus dem Benutzernamen entfernen.

```elixir
Username.sanitize(~c"mark_fischer$$$")
# => ~c"mark_fischer"
```

## 3. Ersetze deutsche Zeichen

Im deutschen Alphabet gibt es 4 Nicht-ASCII-Zeichen, und für alle gibt es allgemein bekannte ASCII-Ersatzschreibweisen.

| Deutsches Zeichen | ASCII-Ersatz |
| ---------------- | ---------------- |
| ä                | ae               |
| ö                | oe               |
| ü                | ue               |
| ß                | ss               |

Erweitere die Funktion `sanitize/1`. Sie soll deutsche Zeichen gemäß der Tabelle ersetzen. Du kannst davon ausgehen, dass alle Benutzernamen bereits kleingeschrieben sind.

```elixir
Username.sanitize(~c"cäcilie_weiß")
# => ~c"caecilie_weiss"
```
