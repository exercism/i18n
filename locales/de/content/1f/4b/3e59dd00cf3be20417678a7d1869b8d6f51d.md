# Einführung

## Atome

Der Typ `atom` in Elixir steht für eine feste Konstante. Der Wert eines Atoms ist einfach sein eigener Name. Das gibt uns eine typsichere Möglichkeit, mit Daten zu arbeiten. Atome kannst du so definieren:

```elixir
# All atoms are preceded with a ':' then follow with alphanumeric snake-cased characters
variable = :an_atom
```

_Atome_ werden intern durch eine Ganzzahl in einer Nachschlagetabelle dargestellt, die automatisch festgelegt wird. Es ist nicht möglich, diesen internen Wert zu ändern.

## Cond

Oft wollen wir Code schreiben, der abhängig von einer Bedingung verzweigt. In Elixir gibt es dafür viele Möglichkeiten, aber eine der einfachsten ist `cond/1`.

In seiner einfachsten Form folgt `cond` dem ersten Pfad, der zu `true` ausgewertet wird, mit einem oder mehreren Zweigen:

```elixir
cond do
  x > 10 -> :this_might_be_the_way
  y < 7 -> :or_that_might_be_the_way
  true -> :this_is_the_default_way
end
```

Wenn kein Pfad zu `true` ausgewertet wird, wirft die Laufzeitumgebung einen Fehler.
