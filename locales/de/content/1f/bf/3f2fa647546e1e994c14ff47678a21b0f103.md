# Ergänzung zu den Anweisungen

## Ausnahmemeldungen

Manchmal ist es notwendig, eine [Ausnahme auszulösen](https://docs.python.org/3/tutorial/errors.html#raising-exceptions). Wenn du das tust, solltest du immer eine **aussagekräftige Fehlermeldung** angeben, die angibt, wo die Fehlerquelle liegt. Das macht deinen Code lesbarer und hilft beim Debuggen erheblich. Wenn du weißt, dass die Fehlerquelle von einem bestimmten Typ sein wird, kannst du eine der [eingebauten Fehlertypen](https://docs.python.org/3/library/exceptions.html#base-classes) auslösen, solltest aber trotzdem eine aussagekräftige Nachricht angeben.

Diese Übung setzt voraus, dass du die [raise-Anweisung](https://docs.python.org/3/reference/simple_stmts.html#the-raise-statement) verwendest, um einen `ValueError` zu „werfen“, wenn der gegebene Wert nicht im Array gefunden wird. Die Tests laufen nur durch, wenn du sowohl die `exception` mit `raise` auslöst als auch eine Nachricht mitgibst.

Um einen `ValueError` mit einer Nachricht auszulösen, schreibst du die Nachricht als Argument an den `exception`-Typ:

```python
# example when value is not found in the array.
raise ValueError("value not in array")
```
