# Ressourcen

## So erstellst du dein erstes CoffeeScript-Modul

Um ein Modul zu erstellen, das sich mit `Bob = require './bob'` laden lässt, schreib diesen Code in `bob.coffee`:

```coffeescript
class Bob

module.exports = Bob
```

Mehr über Module erfährst du in der [Node-Dokumentation](http://nodejs.org/api/modules.html#modules_module_exports).

## Visual Studio unter Windows

Wenn du eine kostenpflichtige Version von Visual Studio hast, kannst du eine Visual Studio-Solution herunterladen, die bereits für CoffeeScript und die anderen Sprachen eingerichtet ist, die Visual Studio unterstützt.

![Solution Explorer](https://raw.githubusercontent.com/exercism/coffeescript/main/docs/img/SolutionExplorer.png)

1. Lade das [Exercism.io Visual Studio Template](https://github.com/rprouse/Exercism.VisualStudio) von GitHub herunter, indem du auf der Seite auf die Schaltfläche „Download Zip“ klickst.
2. Entpacke das Template in dein Übungsverzeichnis, zum Beispiel `C:\src\exercises`
2. Installiere die [Exercism CLI](http://exercism.io/cli)
3. Öffne eine Eingabeaufforderung in deinem Übungsverzeichnis
4. Füge deinen API-Schlüssel zu exercism hinzu: `exercism configure --key=YOUR_API_KEY`
5. Konfiguriere dein Quellverzeichnis in exercism: `exercism configure --dir=C:\src\exercises`
6. [Hol dir deine erste Übung](http://exercism.io/languages/coffeescript): `exercism fetch coffeescript`
7. Öffne die Exercism-Solution in Visual Studio
8. Klappe das Projekt Exercism.coffeescript auf
9. Klicke im Solution Explorer auf **Show All Files** (siehe unten)
10. Die Übung, die du gerade geholt hast, erscheint ausgegraut. Klicke mit der rechten Maustaste auf den Ordner und wähle **Include In Project**
11. Jetzt kann das Programmieren losgehen...

![Dateien hinzufügen](https://raw.githubusercontent.com/exercism/coffeescript/main/docs/img/AddFiles.png)

Um in Visual Studio mit CoffeeScript zu arbeiten, solltest du die Erweiterung [Web Essentials](http://vswebessentials.com/) installieren. Sie macht auch die Arbeit mit JavaScript deutlich einfacher.

Die Unit-Tests kannst du über die Batchdatei im Projekt von einer Node.js-Kommandozeile aus ausführen.

```bash
C:\Src\exercises\coffeescript> test example\bob_test.spec.coffee
.................

Finished in 0.02 seconds
17 tests, 17 assertions, 0 failures, 0 skipped
```

Wenn du beim Ausführen der Tests keine Ausgabe siehst, bist du wahrscheinlich nicht in einer Node.js-Eingabeaufforderung.
