# Introduction

## Wörterbücher

Ein Wörterbuch ist eine Sammlung von Elementen, wobei jedes Element aus einem Schlüssel und einem Wert besteht. Wenn man den Schlüssel an eine Methode des Wörterbuchs übergibt, gibt diese den zugehörigen Wert zurück. Es hat dieselbe Rolle wie Maps oder assoziative Arrays in anderen Sprachen.

Ein Wörterbuch kannst du so erstellen:

```csharp
new Dictionary<int, string>();
// Empty dictionary
```

Oder

```csharp
new Dictionary<int, string>
{
    [1] = "One",
    [2] = "Two"
};

// Or

new Dictionary<int, string>
{
    {1, "One"},
    {2, "Two"}
};
// 1 => "One", 2 => "Two"
```

Beachte, dass die Typen von Schlüssel und Wert Teil der Definition des Wörterbuchs sind.

Nachdem es erstellt wurde, kannst du mit den eingebauten Methoden `Add` und `Remove` Einträge zu einem Wörterbuch hinzufügen oder daraus entfernen.

Um Werte in einem Wörterbuch abzurufen oder zu aktualisieren, greifst du über einen Schlüssel auf das Wörterbuch zu:

```csharp
var numbers = new Dictionary<int, string>
{
   {1, "One"},
   {2, "Two"}
};

// Set the value of the element with key 2 to "Deux"
numbers[2] = "Deux";

// Get the value of the element with key 2
numbers[2];
// => "Deux"
```

Du kannst mit folgendem Code prüfen, ob ein Wert im Wörterbuch existiert:

```csharp
var dict = new Dictionary<string, string>{/*...*/};
dict.ContainsKey("some key that exists");
// => true
```

Wenn du über ein Wörterbuch iterierst, iterierst du über seine Schlüssel-Wert-Paare. Wörterbücher haben außerdem Eigenschaften, mit denen du über seine Schlüssel oder Werte iterieren kannst.
