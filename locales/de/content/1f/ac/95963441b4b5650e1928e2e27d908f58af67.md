# Formatierung mit dem Prozentzeichen oder im „Old Style“

Diese Lösung verwendet für Strings `%%-formatting` oder die [Old-Style-Formatierung][old-style formatting].

Auch wenn `%%-formatting` völlig in Ordnung ist, kann es zu Problemen bei der Darstellung oder der Lesbarkeit kommen. Die Methode [str.format()][str.format()] oder [f-strings][f-strings] (_auch bekannt als „formatted string literals“ oder „interpolated strings“_) bietet dir Möglichkeiten, die die Lesbarkeit verbessern und den Austausch von Variablen innerhalb von Strings klarer machen.

Der Blogbeitrag [String Formatting in Python][string formatting in python] ist ein guter Ausgangspunkt, um alle Formatierungsoptionen von Python für Strings zu verstehen. [Newer Python String Format Techniques][newer python string format techniques] bietet außerdem ein paar gute Tipps und Tricks für die Verwendung von `str.format()` und `f-strings`.
