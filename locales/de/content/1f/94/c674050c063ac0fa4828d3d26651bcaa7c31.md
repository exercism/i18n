# Anleitung

Das Aufrufen von APIs ist ein wichtiger Teil davon, Code für das Internet zu schreiben. In dieser Übung musst du Daten von einem Endpunkt abrufen und sicherstellen, dass der Abruf erfolgreich war.

## Ziele

- Ändere den bereitgestellten Code.
- Rufe den HTTP-Client auf und versuche, ein Zitat abzurufen. Das Ergebnis sollte ein Union-Typ sein, der aus `string` und `error` besteht.
- Wenn das Zitat empfangen wird, gib es auf der Konsole aus (mit `io:println()`).
- Wenn ein `error` aufgetreten ist, gib die Fehlermeldung auf der Konsole aus.
