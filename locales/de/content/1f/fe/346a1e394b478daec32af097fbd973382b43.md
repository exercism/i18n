# Hinweise

## Allgemein

- Sieh dir die [im _String-Modul_ verfügbaren Funktionen][string-module-functions] an, um herauszufinden, welche Operationen auf Strings die Standardbibliothek von Gleam bietet.

## 1. Den ersten Buchstaben des Namens ermitteln

- Es gibt eine [Funktion][string-first], um das erste Zeichen aus einem String zu erhalten.
- Es gibt mehrere [Funktionen][string-trim], um führende, nachfolgende oder führende und nachfolgende Leerzeichen aus einem String zu entfernen.

## 2. Den ersten Buchstaben als Initial formatieren

- Es gibt eine [Funktion][string-upcase], um alle Zeichen eines Strings in Großbuchstaben umzuwandeln.
- Mit dem Operator `<>` kannst du Strings verketten.

## 3. Den vollständigen Namen in Vorname und Nachname aufteilen

- Es gibt eine [Funktion][string-split], die einen String an Leerzeichen aufteilt.
- Indem du Pattern Matching auf eine Liste anwendest, kannst du die ersten paar Elemente der Liste Variablen zuweisen.

## 4. Die Initialen in das Herz einfügen

- Mit dem Operator `<>` kannst du Strings verketten.
