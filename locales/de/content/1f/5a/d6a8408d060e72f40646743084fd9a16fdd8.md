# Null

Null ist ein primitiver Werttyp mit nur einem einzigen Wert: `null`.
Null wird oft verwendet, um das Nichts darzustellen.
Null gilt als „falsey“, unterscheidet sich aber von `false` und anderen falsey-Werten.

```php
<?php

is_null(null); // => true
isset(null); // => false

null == true; // => false
null === true; // => false

null == false; // => true
null === false; // => false
```

## Arbeiten mit Nullwerten

In PHP sind Nullwerte eine häufige Fehlerquelle, denn oft werden sie statt eines Fehlerzustands zurückgegeben oder um auszudrücken, dass kein Wert vorhanden ist.
Um Fehler zu vermeiden, brauchst du oft einen „Null-Check“: Du stellst sicher, dass der Wert nicht null ist, bevor du mit ihm arbeitest.

Wiederholte Null-Checks sind fehleranfällig, deshalb bietet PHP zwei Operatoren für den Umgang mit Nullwerten: den Nullsafe-Zugriffsoperator `?->` und den Null-Koaleszenz-Operator `??`.
