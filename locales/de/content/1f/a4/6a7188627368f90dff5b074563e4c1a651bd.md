# Grundlagen der Haskell-Syntax

## Konstanten und Funktionen

Haskell-Programme bestehen aus Definitionen und Ausdrücken.

Einen konstanten Wert definierst du mit `name = expression`.

```haskell
five = 5

six = 3 + 3
```

Funktionen definierst du mit `name parameters... = expression`, wobei die Parameter nur durch Leerzeichen getrennt werden.

```haskell
add number1 number2 = number1 + number2
```

Der Aufruf einer Funktion ist ebenfalls ein Ausdruck. Du gibst dabei den Namen der Funktion an und übergibst Argumente für jeden Parameter der Funktion, getrennt durch Leerzeichen, genau wie bei Funktionsdefinitionen.

```haskell
five = add 2 3
```

Mit runden Klammern kannst du die Reihenfolge der Auswertung eines Ausdrucks festlegen.

```haskell
six = add 2 (1 * 4)

twelve = add 2 1 * 4
```

## Einrückung / signifikante Leerzeichen

Haskell verwendet Leerzeichen und Einrückung, um Codegrenzen festzulegen.
***Code, der Teil eines Ausdrucks ist, muss weiter eingerückt sein als der Anfang dieses Ausdrucks.***

- Modul-, Import- und Funktionsdefinitionen auf oberster Ebene müssen in der äußersten linken Spalte beginnen.
- Wenn ein Ausdruck auf mehrere Zeilen aufgeteilt wird, muss der Code, der Teil dieses Ausdrucks ist, mit mindestens einem Leerzeichen unter diesem Ausdruck eingerückt werden.
- Teile des Ausdrucks, die zusammengehören, sollten mit der gleichen Anzahl an Leerzeichen eingerückt werden.

```haskell
-- A function split over multiple lines, so subsequent lines must be indented
add number1 number2 =
    number1 + number2
```

https://en.wikibooks.org/wiki/Haskell/Indentation

## Module

Module exportieren Funktionen.
Das bedeutet, du kannst die Funktionen verwenden, die das Modul über seine Export-Anweisung bereitstellt.
Ein Modul kann auch Funktionen nur für den internen Gebrauch definieren.
Standardmäßig können Funktionen, die nicht explizit exportiert werden, nicht von außerhalb des Moduls verwendet werden.

Am Anfang eines Moduls geben wir den Modulnamen an.
Wenn wir eine Datei namens Calculator.hs haben, sollten wir unser Modul Calculator nennen.
Dann geben wir die Funktionen an, die es exportiert, und danach können wir mit dem Schreiben der Funktionen beginnen.
Fangen wir also damit an.

```haskell
module Calculator ( add ) where
```

https://learnyouahaskell.github.io/modules#making-our-own-modules

## Kommentare

Ein Kommentar ist ein Text in der Haskell-Datei, der nicht als Code interpretiert wird.
Er ist hauptsächlich dafür gedacht, dass du und andere Programmierer ihn lesen.
Für einzeilige Kommentare gibt es eine einfache Syntax, die auf doppelten Bindestrichen basiert.
Mehrzeilige Kommentare sind auch möglich, mit dem Paar `{-` und `-}` als öffnende und schließende Begrenzer.

```haskell
-- a single line comment
-- another single line comment

{- a multiline comment
   spanning multiple lines
-}
```
