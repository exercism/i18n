# Anweisungen

Die Bibliothek von Luton ist eine große Bibliothek mit einer umfangreichen Sammlung von Literatur, von Büchern bis hin zu Kunst.
Die Bibliothek hat eine Abteilung, in der Literatur erforscht und Bücher in das Computersystem eingetragen werden.

Bestimmte Bereiche sollen automatisiert werden, und du wirst gebeten, dabei zu helfen.
Dazu gehört, Abläufe von der Automatisierung der Formulare für den Eintragungsprozess bis hin zum Entschlüsseln von Texten zu unterstützen.

## 1. Ermittle den ersten Buchstaben des Titels

Die Bücher einer Bibliothek sollen leicht zu finden sein, deshalb werden sie nach dem ersten Buchstaben des Titels sortiert.

Implementiere die Methode `Library.first_letter`, die ein Argument `title` entgegennimmt, das den Titel des Buchs enthält.
Die Methode soll den ersten Buchstaben des Titels zurückgeben.

```Crystal
Library.first_letter("Mystery of the Crystal Skull")
# => 'M'
```

## 2. Ermittle die Initialen der Autoren

Die Bibliothek hat viele Bücher, die von verschiedenen Autoren geschrieben wurden.
Autoren werden oft mit ihren Initialen bezeichnet, deshalb hat die Bibliothek ein System angefordert, das die Initialen eines Autors ausgibt, wenn man den Vornamen und den Nachnamen des Autors eingibt.
Die Initialen sollen folgendermaßen formatiert sein: `{first_letter_of_first_name}.{first_letter_of_last_name}`

Implementiere die Methode `Library.initials`, die zwei Argumente `first_name` und `last_name` entgegennimmt, die den Vornamen und den Nachnamen des Autors enthalten.
Die Methode soll die Initialen des Autors zurückgeben.

```Crystal
Library.initials("William", "Shakespeare")
# => "W.S"
```

## 3. Entschlüssele einen Buchstaben

Einige Literatur ist verschlüsselt, und die Bibliothek hat viele verschlüsselte Texte.
Die Bibliothek hätte gern ein neues Entschlüsselungssystem für eine spezielle Verschlüsselung.

Die Verschlüsselung funktioniert so, dass der Buchstabe durch den im Alphabet vorangehenden Buchstaben ersetzt wird.
Zum Beispiel wird aus `a` ein `z`, aus `b` ein `a`, aus `c` ein `b` und so weiter.

Die Bibliothek möchte, dass sowohl Groß- als auch Kleinbuchstaben entschlüsselt werden können und dabei die Groß- bzw. Kleinschreibung des ursprünglichen Buchstabens erhalten bleibt.

Implementiere die Methode `Library.decrypt_character`, die ein Argument `character` entgegennimmt, das den zu entschlüsselnden Buchstaben enthält.
Die Methode soll den entschlüsselten Buchstaben zurückgeben.

```Crystal
Library.decrypt_character('a')
# => 'z'
```

## 4. Entschlüssele einen Text

Die Bibliothek möchte außerdem einen ganzen Text mit dieser Verschlüsselung entschlüsseln, die jeweils den vorangehenden Buchstaben im Alphabet nimmt.

Die Entschlüsselung soll nur Buchstaben entschlüsseln und alle anderen Zeichen unverändert lassen.

Implementiere die Methode `Library.decrypt_text`, die ein Argument `text` entgegennimmt, das den zu entschlüsselnden Text enthält.
Die Methode soll den entschlüsselten Text zurückgeben.

```Crystal
Library.decrypt_text("Ifmmp Xpsme!")
# => "Hello World!"
```
