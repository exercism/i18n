# Über

`while` und `until` (in [`kernel`][kernel]) sind quotation-getriebene
Schleifenkombinatoren für den Fall, dass du die Anzahl der Iterationen
nicht im Voraus kennst:

```
while ( pred: ( -- ? ) body: ( -- ) -- )
until ( pred: ( -- ? ) body: ( -- ) -- )
```

`while` macht so lange weiter, wie `pred` einen als wahr geltenden Wert
hinterlässt; `until` macht so lange weiter, wie `pred` `f` hinterlässt.
Beide hören auf und kehren zurück, sobald ihr Prädikat umschlägt.

```factor
USING: kernel math ;

! Halve down to 1
16 [ dup 1 > ] [ 2 / ] while .   ! => 1

! Double up to 100
1 [ dup 100 >= ] [ 2 * ] until .   ! => 128
```

Wenn ein einzelner Wert, der über den Stack fließt, nicht genug Zustand
ist, etwa eine verbleibende Liste, eine laufende Summe und ein Zähler
gleichzeitig, dann ist es am saubersten, benannte *Locals* zu verwenden,
damit der Code übersichtlich bleibt. Locals werden später im Lehrplan
ausführlicher erklärt; hier reicht es zu wissen, dass `:: word ( a b -- c )`
die Eingabewerte als benannte Locals deklariert und `:> name!` ein
veränderbares Local hinzufügt, das der Rumpf mit `value name!`
aktualisieren kann.

```factor
USING: kernel locals math sequences ;

! Sum a sequence by hand
:: sum-by-hand ( seq -- total )
    seq :> rest!
    0 :> running!
    [ rest length 0 > ] [
        rest unclip [ rest! ] dip
        running + running!
    ] while
    running ;
```
