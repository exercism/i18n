# Anleitung

Du bist der Wärter am Leuchtturm von Cape Crozier. Von der Laternenkammer aus protokollierst du jedes Schiff, das vorbeikommt und durch ein eindeutiges Rufzeichen identifiziert wird. Außerdem koordinierst du die Signalweiterleitung mit den anderen Leuchttürmen entlang der Küste.

## 1. Ein frisches Logbuch

Definiere `empty-log` so, dass die Funktion ein frisches, leeres Hash-Set zurückgibt, bereit, Rufzeichen aufzunehmen.

```factor
empty-log .
! => HS{ }
```

## 2. Eine Sichtung festhalten

Definiere `sight`, um ein Logbuch und ein Rufzeichen zu übernehmen und die Sichtung direkt im Logbuch festzuhalten. Gibt nichts zurück.

```factor
empty-log dup "NS-1024" sight .
! => HS{ "NS-1024" }
```

## 3. Haben wir dieses schon gesehen?

Definiere `seen?`, um ein Logbuch und ein Rufzeichen zu übernehmen und `t` zurückzugeben, wenn das Rufzeichen aufgezeichnet wurde, andernfalls `f`.

```factor
HS{ "NS-1024" "WB-203" } "NS-1024" seen? .   ! => t
HS{ "NS-1024" "WB-203" } "X-99"    seen? .   ! => f
```

## 4. Eine Sichtung vergessen

Definiere `forget-sighting`, um ein Logbuch und ein Rufzeichen zu übernehmen und das Rufzeichen direkt aus dem Logbuch zu entfernen. Gibt nichts zurück. Wenn das Rufzeichen nicht vorhanden ist, unternimm nichts.

```factor
HS{ "NS-1024" "WB-203" } clone dup "WB-203" forget-sighting .
! => HS{ "NS-1024" }
```

## 5. Wie viele verschiedene Schiffe?

Definiere `unique-count`, um die Anzahl der verschiedenen Rufzeichen im Logbuch zurückzugeben.

```factor
HS{ "NS-1024" "WB-203" "AC-77" } unique-count .   ! => 3
empty-log unique-count .                          ! => 0
```

## 6. Erreichbare Leuchttürme

Die Küstenwache führt eine `relay-map`: eine Hashtabelle, deren Schlüssel Leuchtturmnamen sind und deren Werte jeweils ein Array der Leuchttürme enthalten, an die der betreffende Leuchtturm direkt weiterleiten kann.

Definiere `reachable`, um einen Leuchtturm `start` und eine `relay-map` zu übernehmen und ein Hash-Set aller Leuchttürme zurückzugeben, die von `start` aus durch wiederholte Weiterleitung erreichbar sind (`start` selbst eingeschlossen).

```factor
H{
    { "Crozier"  { "Beacon"  "Hadley"  } }
    { "Beacon"   { "Crozier" "Spiral"  } }
    { "Hadley"   { "Crozier"           } }
    { "Spiral"   { "Beacon"  "Outpost" } }
    { "Outpost"  { "Spiral"            } }
    { "Far-Isle" { "Lonely"            } }
    { "Lonely"   { "Far-Isle"          } }
}
"Crozier" swap reachable .
! => HS{ "Crozier" "Beacon" "Hadley" "Spiral" "Outpost" }
```

Das Paar `Far-Isle`/`Lonely` bildet eine eigene Zusammenhangskomponente, deshalb taucht keiner von beiden im Ergebnis auf.
