# Introduction

ABAP unterstützt arithmetische Operatoren für Berechnungen mit numerischen Werten.

```abap
DATA day_rate TYPE p LENGTH 8 DECIMALS 2.
day_rate = rate_per_hour * 8.
```

Die grundlegenden Operatoren sind:

- `+` für die Addition.
- `-` für die Subtraktion.
- `*` für die Multiplikation.
- `/` für die Division.
- `MOD` für den Rest einer ganzzahligen Division.

```abap
DATA full_months TYPE i.
full_months = floor( num_days / 22 ).

DATA remaining_days TYPE i.
remaining_days = num_days MOD 22.
```

ABAP wertet Multiplikation und Division vor Addition und Subtraktion aus. Mit runden Klammern kannst du die gewünschte Reihenfolge ausdrücklich festlegen.

```abap
DATA discounted_rate TYPE p LENGTH 8 DECIMALS 2.
discounted_rate = monthly_rate * ( 1 - discount ).
```
