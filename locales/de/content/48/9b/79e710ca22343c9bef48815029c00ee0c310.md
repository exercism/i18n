# Einführung

## Pfeilfunktionen

Neben Funktionsdeklarationen und Funktionsausdrücken hat JavaScript noch eine weitere, sehr kompakte Syntax, um eine Funktion zu definieren.
Diese Funktionen heißen _Pfeilfunktionen_.

Hier ist ein Vergleich zwischen einer Funktionsdeklaration und einer Pfeilfunktion.

```javascript
function addUpTwoNumbers(num1, num2) {
  return num1 + num2;
}
// function keyword removed and => added
const addUpTwoNumbers = (num1, num2) => {
  return num1 + num2;
};
```

Wenn der Funktionskörper nur eine return-Anweisung enthält, wie im Beispiel oben, kannst du die `{}` und das Schlüsselwort `return` weglassen.
Gibt es nur einen Parameter, kannst du auch die runden Klammern `()` weglassen.

<!-- prettier-ignore-start -->
```javascript
const addUpTwoNumbers = (num1, num2) => num1 + num2;
const square = num => num * num;
```
<!-- prettier-ignore-end -->

Pfeilfunktionen werden oft verwendet, um kurze Callback-Funktionen direkt im Funktionsaufruf zu definieren.

<!-- prettier-ignore-start -->
```javascript
applyToSquare(number => number * number);
```
<!-- prettier-ignore-end -->

## Array-Analyse

[Arrays][arrays-concept] haben eingebaute Methoden, um den Inhalt des Arrays zu analysieren.
Die meisten dieser Methoden nehmen eine Funktion als Argument, die wahr oder falsch zurückgibt.
Eine solche Funktion heißt [`predicate`][predicate_in_programming].

Die eingebauten Methoden sind dafür gedacht, _anstelle einer `for`-Schleife_ oder der eingebauten `forEach`-Methode verwendet zu werden:

Beispiel für eine Analyse mit einer for-Schleife:

```javascript
const numbers = [1, 'two', 3, 'four'];
for (var i = 0; i < numbers.length; i++) {
  if (numbers[i] === 'two') {
    return i;
  }
}
// => 1
```

Beispiel für eine Analyse mit einer eingebauten Methode:

```javascript
const numbers = [1, 'two', 3, 'four'];
numbers.indexOf('two');
// => 1
```

Einige weitere hilfreiche eingebaute Methoden, mit denen du ein Array analysieren kannst, sind unten aufgeführt.
Eine vollständige Liste der Array-Methoden findest du bei [MDN][mdn-array-methods].

### `includes`

Die Methode `includes(value)` bestimmt, ob ein Array einen bestimmten Wert enthält.
Wenn der Wert enthalten ist, gibt sie `true` zurück, sonst `false`.

```javascript
const numbers = [1, 'two', 3, 'four'];
numbers.includes(1);
// => true
numbers.includes('one');
// => false
```

### `every`

Die Methode `every(predicate)` nimmt eine Funktion, die _ein Prädikat_ ist.
Sie prüft, ob alle Elemente im Array `true` zurückgeben, wenn sie an das Prädikat übergeben werden.
Mit anderen Worten: Die Methode prüft, dass alle ihre Elemente den Test bestehen, der dem Funktionsaufruf übergeben wurde.
Sie gibt `true` zurück, wenn jedes Element den Test des Prädikats besteht, sonst `false`.

```javascript
const numbers = [1, 3, 5, 7, 9];
numbers.every((num) => num % 2 !== 0);
// => true
```

### `some`

Die Methode `some(predicate)` ist dieselbe wie die Methode `every`, gibt aber `true` zurück, wenn mindestens ein Element im Array den Test des _Prädikats_ besteht.

```javascript
const numbers = [1, 3, 5, 7, 9];
numbers.some((num) => num % 2 !== 0);
// => true
```

### `find`

Die Methode `find(predicate)` gibt den Wert des ersten Elements im Array zurück, das den `predicate`-Test besteht.
Während `some()` `true` zurückgibt, wenn ein Element besteht, gibt `find()` den tatsächlichen Wert im Array zurück.
Die Methode gibt `undefined` zurück, wenn keines der Elemente im Array den Test des _Prädikats_ besteht.

```javascript
const numbers = [1, 3, 5, 7, 9];
numbers.find((num) => num < 5);
// => 1
```

### `findIndex`

Die Methode `findIndex(predicate)` ist dieselbe wie die Methode `find()`, gibt aber den (ersten) _Index_ des Elements zurück, das den Test des _Prädikats_ besteht, anstatt des `value`.
Die Methode gibt `-1` zurück, wenn keines der Elemente im Array den Test des _Prädikats_ besteht.

```javascript
const numbers = [1, 3, 5, 7, 9];
numbers.findIndex((num) => num > 7);
// => 4
numbers.findIndex((num) => num > 9);
// => -1
```
