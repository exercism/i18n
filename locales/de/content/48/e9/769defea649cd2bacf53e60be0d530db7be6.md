# Über

Arturo ist eine unabhängig entwickelte, moderne Programmiersprache, die einigen sehr einfachen und geradlinigen Prinzipien folgt:

* Code ist einfach eine Liste von Wörtern, Symbolen und Literalwerten.
  
* Wörter und Symbole innerhalb eines Blocks werden, wenn nötig, je nach Kontext interpretiert.
  
* Keine reservierten Wörter, keine Schlüsselwörter: Such so gründlich du kannst, es gibt absolut keine.
