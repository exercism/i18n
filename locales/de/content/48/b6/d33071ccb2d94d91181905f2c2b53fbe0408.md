# Einführung

Elixir unterstützt das **Open-Closed-Prinzip**, indem es Funktionen erlaubt, mehrere Klauseln zu haben. Statt ausufernder, fest kodierter Steuerlogik kannst du so gezielte Funktionen schreiben, die Verhalten einfach hinzufügen oder entfernen.

Elixir bietet _mehrere Funktionsklauseln_ und _Guards_, mit denen du so etwas schreiben kannst:

```elixir
def number(n) when n == 7 do
  "Awesome, that's my favorite"
end

def number(_n) do
  "That's not my favorite"
end
```

Zur Laufzeit prüft Elixir von oben nach unten in der Quelldatei, welche Funktionsklausel aufgerufen wird.

Nicht verwendete Variablen sollten mit einem Unterstrich beginnen.
