# Anweisungen

Refaktoriere einen Markdown-Parser.

Bei der Übung Markdown geht es ums Refactoring. Es gibt Code, der einen gegebenen String mit [Markdown-Syntax](https://guides.github.com/features/mastering-markdown/) parst und das zugehörige HTML für diesen String zurückgibt. Auch wenn dieser Code verwirrend geschrieben und schwer zu verfolgen ist: Irgendwie funktioniert er, und alle Tests laufen durch! Deine Herausforderung ist es, diesen Code so umzuschreiben, dass er leichter zu lesen und zu pflegen ist, und dabei dafür zu sorgen, dass alle Tests weiterhin bestehen.

Es wäre hilfreich, wenn du in Kommentaren notierst, was du beim Refactoring gemacht hast, damit Reviewer das sehen können, aber unbedingt nötig ist es nicht. Am wichtigsten ist, dass der Code besser wird!
