# Ergänzende Anweisungen

## Track-spezifische Anweisungen

Deine Aufgabe ist es, ein Record `circularBuffer` zu implementieren, das die folgenden Methoden hat

- `clear()`: leert den Puffer.
- `write(item)`: fügt das angegebene Element dem Puffer hinzu. Wenn der Puffer voll ist, soll sie `Error("Cannot write to full buffer.")` werfen.
- `read()`: entfernt das älteste Element aus dem Puffer und gibt es zurück. Wenn der Puffer leer ist, soll sie `Error("Cannot read from an empty buffer.")` werfen.
- `overwrite(item)`: Wenn der Puffer voll ist, überschreibt sie das älteste Element mit `item`. Wenn der Puffer nicht voll ist, verhält sie sich wie `write`.
