# Einführung

[`Rational numbers`][rational] sind Brüche, bei denen ein ganzzahliger Zähler durch einen ganzzahligen Nenner geteilt wird.

Zum Beispiel können wir `2//3` als exakten Bruch speichern, statt als angenäherten `Float64`-Wert `0.6666...`

Der Vorteil ist, dass (außer im Extremfall eines [Überlaufs von Ganzzahlen][integer-overflow]) eine rationale Zahl exakt bleibt und so die Rundungsfehler vermieden werden, die bei Gleitkommazahlen oft unvermeidlich sind.

Weitere Details findest du auf der Julia-[Handbuchseite][julia-rational].

Rationale Zahlen sind ein recht einfacher numerischer Typ und sollen sich weitgehend so verhalten, wie du es erwartest.
Da sie in Julia seit den frühen Versionen ein Standardtyp sind, akzeptieren die meisten Funktionen sie als Eingabewert genauso wie Ganzzahlen und Gleitkommazahlen.

## Rationale Zahlen erstellen

Das Erstellen ist so einfach wie die Verwendung von `//` zwischen zwei Ganzzahlen.

```julia-repl
julia> 3//4
3//4

julia> a = 3; b = 4;

julia> a//b
3//4
```

Gemeinsame Faktoren werden automatisch gekürzt, wodurch der Bruch in seine [„vollständig gekürzte Form“][lowest-terms] gebracht wird: die kleinsten Ganzzahlen, die den Bruch genau darstellen, und mit einem nicht-negativen Nenner.

```julia-repl
julia> 5//15
1//3

julia> 5//-15
-1//3
```

Unendliche Ergebnisse werden akzeptiert, [`NaN`][NaN] jedoch nicht.

```julia-repl
julia> 1//0
1//0

julia> float(1//0)
Inf

julia> 0//0
ERROR: ArgumentError: invalid rational: zero(Int64)//zero(Int64)
```

## Rechnen mit rationalen Zahlen

Die üblichen [`arithmetic operators`][operators] `+ - * / ^ %` funktionieren mit rationalen Zahlen im Wesentlichen genauso wie mit anderen numerischen Typen.

Ganzzahlen und andere `Rational`s kannst du einbeziehen, und du erhältst ein `Rational`-Ergebnis.
Wenn du einen `float` in den Ausdruck einbeziehst, ist die Ausgabe `float`, mit einem daraus folgenden (möglichen) Genauigkeitsverlust.

Wenn du einen `float` möchtest, verwende einfach die Funktion `float()`, um eine rationale Zahl umzuwandeln.
Es ist ganz normal, rationale Zahlen zu nutzen, um die Genauigkeit durch eine lange Berechnung hindurch zu bewahren, und am Ende in eine Gleitkommazahl umzuwandeln.

```julia-repl
julia> 3//4 + 1//3  # addition
13//12

julia> 3//4 * 1//3  # multiplication
1//4

julia> 3//4 / 1//3  # division
9//4

julia> 3//4 ^ 2  # exponentiation
3//16

julia> 3//4 + 5  # rational and int => rational
23//4

julia> 3//4 + 5.3  # rational and float => float
6.05

julia> float(3//4)  # casting
0.75
```

Rationale Zahlen und [komplexe Zahlen][complex] lassen sich ebenfalls kombinieren.
Komplexe Zahlen werden in einem [eigenen Konzept][complex-concept] behandelt.

## Weitere Operationen

In Julia sind rationale Zahlen einfach Zahlen.
Der Compiler wandelt Typen normalerweise nach Bedarf um.

Beachte jedoch, dass Vergleiche für Brüche mit endlicher Dezimaldarstellung funktionieren:

```julia-repl
julia> 3//4 == 0.75
true

julia> 3//4 < 0.74
false
```

Andernfalls sollte eine `Rational` für Vergleiche in einen `Float` umgewandelt werden:

```julia-repl
julia> 1//3 == 1/3
false

julia> float(1//3) == 1/3
true
```

Mathematische Funktionen nehmen rationale Zahlen als Eingabewert, können aber ein Gleitkommaergebnis liefern:

```julia-repl
julia> sqrt(9//16)
0.75
```
