# Logzeilen-Parser

## Geschichte

In dieser Übung verarbeitest du Logzeilen.

Jede Logzeile ist ein String mit folgendem Format: `"[<LVL>]: <MESSAGE>"`.

Das sind die verschiedenen Log-Level:

- `TRC` (trace)
- `DBG` (debug)
- `INF` (info)
- `WRN` (warning)
- `ERR` (error)
- `FTL` (fatal)

## Aufgaben

Das sind beispielhafte Aufgaben, die zu einem Logzeilen-Parser passen:

- Log-Level zu einem Enum parsen
- Unbekannte Log-Level unterstützen
- Eine Logzeile in ein anderes Format umwandeln, wobei das Log-Level in einen numerischen Wert umgewandelt wird
