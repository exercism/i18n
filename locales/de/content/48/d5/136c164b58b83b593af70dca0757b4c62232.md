# Tests

Installiere die Abhängigkeiten.

```sh
dart pub get
```

Führe die Tests aus.

```sh
dart test
```

Für detailliertere Ausgaben pro Test verwende den Expanded-Reporter.

```sh
dart test -r expanded
```

Die meisten Übungen haben mehrere Tests, wobei standardmäßig alle außer dem ersten übersprungen werden.
Um die Tests einen nach dem anderen durchzugehen, ändere `skip: true` in `skip: false` bei jedem Test, während du fortschreitest.

Alternativ führe alle Tests auf einmal aus, ohne die Datei zu bearbeiten.

```sh
dart test --run-skipped
```

Alle Tests werden beim Einreichen vom Online-Test-Runner ausgeführt, einschließlich der übersprungenen.
