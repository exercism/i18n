# Tipps

## Allgemeines

- Diese Dokumentation zu [verschachtelten Typen][nested-types] erklärt die Syntax im Detail.

## 1. Trenne die Zuständigkeiten zwischen dem Auto selbst und dem Telemetriesystem

- Mitglieder von `RemoteControlCar` mit dem Suffix „\_Telemetry" könnten in eine eigene Klasse verschoben werden.

## 2. Verhindere, dass anderer Code zu viele Abhängigkeiten vom Telemetry-Typ eingeht

- [Interfaces][interfaces] sind hier das Geheimrezept.

## 3. Verhindere, dass anderer Code Abhängigkeiten von der Speed-Struktur eingeht

- Denk auch über die [Zugriffsebenen][access-levels] nach.
