# Anleitung

In dieser Übung hilfst du Highschool-Liebespaaren, ihre Liebe in den sozialen Medien zu bekunden, indem du eine ASCII-Box mit ihren Initialen erzeugst:

```
❤-------------------❤
|  J. K.  +  M. B.  |
❤-------------------❤
```

## 1. Ermittle den ersten Buchstaben des Namens

Implementiere die Funktion `HighSchoolSweetheart.first_letter/1`. Sie soll einen Namen entgegennehmen und dessen ersten Buchstaben zurückgeben. Überflüssige Leerzeichen soll sie aus dem Namen entfernen.

```elixir
HighSchoolSweetheart.first_letter("Jane")
# => "J"
```

## 2. Formatiere den ersten Buchstaben als Initiale

Implementiere die Funktion `HighSchoolSweetheart.initial/1`. Sie soll einen Namen entgegennehmen und dessen ersten Buchstaben in Großbuchstaben zurückgeben, gefolgt von einem Punkt. Achte darauf, die Funktion `HighSchoolSweetheart.first_letter/1` aus dem vorherigen Schritt wiederzuverwenden.

```elixir
HighSchoolSweetheart.initial("Robert")
# => "R."
```

## 3. Teile den vollständigen Namen in Vorname und Nachname auf

Implementiere die Funktion `HighSchoolSweetheart.initials/1`. Sie soll einen vollständigen Namen entgegennehmen, der aus einem Vornamen und einem Nachnamen besteht, die durch ein Leerzeichen getrennt sind, und die Initialen zurückgeben. Achte darauf, die Funktion `HighSchoolSweetheart.initial/1` aus dem vorherigen Schritt wiederzuverwenden.

```elixir
HighSchoolSweetheart.initials("Lance Green")
# => "L. G."
```

## 4. Setze die Initialen in die ASCII-Box ein

Implementiere die Funktion `HighSchoolSweetheart.pair/2`. Sie soll zwei vollständige Namen entgegennehmen und die Initialen in einer ASCII-Box zurückgeben. Du musst die Box nicht selbst zeichnen; nutze die Box, die im Codekommentar enthalten ist. Achte darauf, die Funktion `HighSchoolSweetheart.initials/1` aus dem vorherigen Schritt wiederzuverwenden.

```elixir
HighSchoolSweetheart.pair("Blake Miller", "Riley Lewis")
# => """
# ❤-------------------❤
# |  B. M.  +  R. L.  |
# ❤-------------------❤
# """
```
