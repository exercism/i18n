# Ameba-Konvention

**Zeile %{line_number}** :  %{message} wurde von Ameba gemeldet.

Das bedeutet, dass dieser Code die allgemeinen Konventionen für [Code-Stil][code style] nicht befolgt. Solche Verstöße haben in der Regel keinen Einfluss darauf, wie der Code _ausgeführt_ wird, können aber die Lesbarkeit oder die Leistung automatisierter Tools wie Dokumentationsgeneratoren oder Test-Runner beeinträchtigen.

[code style]: https://crystal-lang.org/reference/latest/conventions/coding_style.html
