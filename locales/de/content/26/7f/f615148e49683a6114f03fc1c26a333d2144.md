# Anleitung

Eine komplexe Zahl ist eine Zahl der Form `a + b * i`, wobei `a` und `b` reell sind und `i` die Gleichung `i^2 = -1` erfüllt.

Man nennt `a` den Realteil und `b` den Imaginärteil von `z`.
Die Konjugierte der Zahl `a + b * i` ist die Zahl `a - b * i`.
Der Betrag einer komplexen Zahl `z = a + b * i` ist eine reelle Zahl `|z| = sqrt(a^2 + b^2)`. Das Quadrat des Betrags `|z|^2` ist das Ergebnis der Multiplikation von `z` mit seiner komplexen Konjugierten.

Bei der Summe bzw. Differenz zweier komplexer Zahlen addiert bzw. subtrahiert man ihre Real- und Imaginärteile getrennt:
`(a + i * b) + (c + i * d) = (a + c) + (b + d) * i`,
`(a + i * b) - (c + i * d) = (a - c) + (b - d) * i`.

Für die Multiplikation gilt per Definition
`(a + i * b) * (c + i * d) = (a * c - b * d) + (b * c + a * d) * i`.

Der Kehrwert einer komplexen Zahl ungleich null ist
`1 / (a + i * b) = a/(a^2 + b^2) - b/(a^2 + b^2) * i`.

Dividiert man eine komplexe Zahl `a + i * b` durch eine andere `c + i * d`, ergibt sich:
`(a + i * b) / (c + i * d) = (a * c + b * d)/(c^2 + d^2) + (b * c - a * d)/(c^2 + d^2) * i`.

Das Potenzieren von e mit einem komplexen Exponenten lässt sich als `e^(a + i * b) = e^a * e^(i * b)` ausdrücken, wobei der letzte Term durch Eulers Formel `e^(i * b) = cos(b) + i * sin(b)` gegeben ist.

Implementiere die folgenden Operationen:
 - Addition, Subtraktion, Multiplikation und Division zweier komplexer Zahlen,
 - Konjugierte, Betrag und Exponentialfunktion einer gegebenen komplexen Zahl.


Geh davon aus, dass die Programmiersprache, die du verwendest, keine Implementierung komplexer Zahlen hat.
