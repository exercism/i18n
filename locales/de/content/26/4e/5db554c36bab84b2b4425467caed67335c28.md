# Überblick

[Closures][closures] in Swift sind in sich geschlossene Codeblöcke, denen man Parameter übergeben kann, um ihre Berechnung auszulösen, und die Werte zurückgeben.
Closures erfassen außerdem Werte aus ihrer Umgebung und verwenden sie in ihren Berechnungen.
Da sie in sich geschlossen sind, können sie in einem Programm wie andere Werte weitergegeben oder Konstanten und Variablen zugewiesen werden.

Closures klingen vielleicht sehr nach Swift-Funktionen; das tun sie auch, und das aus gutem Grund.
Funktionen in Swift sind Sonderfälle von Closures, die einen Namen haben müssen und mit einer etwas anderen Syntax definiert werden.

Funktionen in Swift sind zwar technisch gesehen Closures, aber wenn in Swift von „Closures“ die Rede ist, sind damit [Closure-Ausdrücke][closure-expressions] gemeint.
Closure-Ausdrücke werden als Parameterliste geschrieben, gefolgt von einem Rückgabetyp und dem Schlüsselwort `in`, gefolgt vom Body der Closure, alles eingeschlossen in ein Paar geschweifter Klammern:

```swift
{ (a: Double, b: Double) -> Double in
  return (a + b) / 2.0
}
```

Dies definiert einen Closure-Ausdruck vom Typ `(Double, Double) -> Double`, und er kann ähnlich wie eine Funktion dieses Typs ausgeführt werden, indem man ihn auf Parameter des passenden Typs anwendet:

```swift
{ (a: Double, b: Double) -> Double in
  return (a + b) / 2.0
}(10.0, 15.0)
// returns 12.5
```

Da es nicht sehr praktisch ist, jedes Mal den vollständigen Closure-Ausdruck auszuschreiben, wenn man ihn ausführen möchte, können Closures wie jeder andere Wert in Swift einem Namen zugewiesen werden.
Anschließend kann man sie aufrufen, indem man den Namen auf die Parameter anwendet:

```swift
let mean = { (a: Double, b: Double) -> Double in
  (a + b) / 2.0
}

mean(13.0, 100.0)
// returns 56.5
```

Wie oben zu sehen ist, können Closures wie reguläre Funktionen das Schlüsselwort `return` weglassen, wenn der Body der Closure aus einem einzigen Ausdruck besteht.

Meistens werden Closures mit Funktionen höherer Ordnung verwendet, entweder als Parameter übergeben oder als Ergebnis zurückgegeben:

```swift
[11, 75, 3, 99, 53].contains(where: { (x: Int) -> Bool in x > 100 })
// returns false

["apple", "ball", "carrot"].sorted(by: { (s1: String, s2: String) -> Bool in s1.count < s2.count })
// returns ["ball", "apple", "carrot"]

func makeAdder(base: Int) -> (Int) -> Int {
  { (x: Int) -> Int in base + x }
}
```

## Closure-Typen ableiten

Wenn der Rückgabetyp oder die Parametertypen [aus dem Kontext abgeleitet werden können][inferring-closure-types], können sie im Closure-Ausdruck weggelassen werden.
Wenn die Parametertypen weggelassen werden können, gilt das außerdem auch für die runden Klammern um die Parameternamen:

```swift
let mean: (Double, Double) -> Double = { a, b in a + b / 2.0 }

func makeAdder(base: Int) -> (Int) -> Int {
  { x in base + x }
}

["apple", "ball", "carrot"].sorted(by: { s1, s2 in s1.count < s2.count })
```

- Im ersten Beispiel lässt sich der Typ aus der Typannotation der Konstante `mean` ableiten.
- Im zweiten weiß der Compiler aus der Definition von `makeAdder`, dass `base` ein `Int` ist und dass die zurückgegebene Funktion vom Typ `(Int) -> Int` sein muss. Von dort aus kann er überprüfen, dass die Closure vom Typ `(Int) -> Int` ist, wenn `x` ein `Int` ist, und deshalb können wir die Typsignatur in der Closure weglassen, da `(Int) -> Int` die einzig mögliche gültige Signatur ist, die die Closure haben kann.
- Das dritte Beispiel ist ähnlich, aber der Compiler muss einen Teil der Typinformationen aus dem Array beziehen, mit dem die Methode verwendet wird. Er weiß, dass die Methode `sorted(by:)` als Parameter eine Closure mit zwei Parametern entgegennimmt, die denselben Typ wie die Elemente der sortierten Collection haben, und die ein `Bool` zurückgibt, also kann der Compiler ableiten, dass der Rückgabetyp der Closure `Bool` sein muss. Und da die Methode mit einem String-Array verwendet wird, kann er feststellen, dass die Typen der Parameter `s1` und `s2` beide `String` sein müssen.

## Einschränkungen von Closures

Wie oben erwähnt, sind Funktionen und Closures in Swift sehr ähnlich, aber es gibt einige wichtige Unterschiede:

- Closures dürfen keine externen Argumentlabels verwenden. Es gibt keine Möglichkeit, sie zu definieren, und der Versuch, beim Aufruf der Closure den Namen eines Parameters zu verwenden, führt zu einem Fehler:

```swift
let add5 = { x in x + 5 }
add5(x: 10)
// Error: Extraneous argument label 'x:' in call
```

- Parameter in Closures können keinen Standardwert haben.
- Parameter in Closures dürfen variadische Parameter sein, aber sie müssen einen Namen und eine Typannotation haben.
