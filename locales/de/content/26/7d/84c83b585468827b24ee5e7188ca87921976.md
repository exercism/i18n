# Anleitung

Eine Violine wird nach Gehör auf einen Referenzton gestimmt. Die Saiten liegen
klanglich weit auseinander, und die Zahlen, um die es dabei geht, sind keine
ganzen Zahlen.

Alle fünf Aufgaben kommen in die Klasse `TUNING_THE_STRINGS`.

## 1. Eine Oktave höher

Ein Ton eine Oktave höher hat die doppelte Frequenz.

```sather
TUNING_THE_STRINGS::octave_up(440.0d)
-- => 880.0d
```

## 2. Eine Oktave tiefer

Eine Oktave tiefer ist die Hälfte.

```sather
TUNING_THE_STRINGS::octave_down(440.0d)
-- => 220.0d
```

## 3. Genau dazwischen

Gegeben sind zwei Frequenzen. Gib die Frequenz zurück, die genau zwischen ihnen
liegt.

```sather
TUNING_THE_STRINGS::midpoint(440.0d, 442.0d)
-- => 441.0d
```

## 4. Wie weit daneben?

Wenn zwei Töne nah beieinander liegen, aber nicht gleich sind, hörst du für jede
Schwingung, um die sie sich unterscheiden, einmal pro Sekunde eine Schwebung.
Gib zurück, wie weit die Frequenzen auseinanderliegen. Die Antwort ist nie
negativ, egal welcher Ton höher ist.

```sather
TUNING_THE_STRINGS::beats_per_second(441.5d, 440.0d)
-- => 1.5d
```

## 5. Übungszeit aufteilen

Gegeben sind eine Anzahl Minuten und eine Anzahl Spieler: Wie viele Minuten
bekommt jeder? Die Minuten und die Spieler sind ganze Zahlen, aber die Antwort
muss es nicht sein.

```sather
TUNING_THE_STRINGS::minutes_each(45, 2)
-- => 22.5d
```
