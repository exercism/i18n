# Überblick

Ein Methodenparameter kann optional gemacht werden, indem man ihm einen Standardwert zuweist. Beim Aufruf einer Methode mit optionalen Parametern muss der Aufrufer keinen Wert dafür übergeben. Wird für einen optionalen Parameter kein Wert übergeben, wird sein Standardwert verwendet.

Optionale Parameter müssen am Ende der Parameterliste stehen; auf sie dürfen keine nicht-optionalen Parameter folgen.

```haxe
class Card {
  static function newYear(year = 2021):String {
    return "Happy " + year;
  }
}

Card.newYear(); // Happy 2020
Card.newYear(1990); // Happy 1990
```

Der optionale Parameter kann auf `null` gesetzt werden, indem man den `?`-Operator vor den Variablennamen setzt:

```haxe
function newYear(?year:Int) {
  if (year != null)
    return "It's " + year;
  return "Year is null";
}

newYear(); // Year is null
```
