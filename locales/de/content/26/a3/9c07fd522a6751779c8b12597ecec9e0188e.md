# Anleitung

Wie fast jeder mit einem Job muss auch Layla, das Lisp-Alien, manchmal Berichte schreiben, um andere zu informieren. Sie fragt dich, ob du ihr helfen kannst, die Daten für diese Berichte zu formatieren.

## 1. Quartalswerte formatieren

Als Erstes braucht Layla eine Funktion: `format-quarter-value`, die zwei Parameter entgegennimmt: das Kalenderquartal und den Wert, und sie für einen Bericht formatiert. Sie sollte einen String zurückgeben.

```lisp
(format-quarter-value "last" 3.14) ; => "The value last quarter: 3.14"
(format-quarter-value "this" 0) ; => "The value this quarter: 0"
```

## 2. Der Zwei-Quartale-Bericht

Layla bedankt sich für die Funktion `format-quarter-value` und sagt, dass sie in der *nächsten* Funktion, die gebraucht wird, sehr nützlich sein wird.

Der nächste Bericht soll das Quartal und den Wert aus 2 Quartalen anzeigen, gedruckt auf zwei Zeilen.

Außerdem muss die Ausgabe in den Stream geschrieben werden, der als erstes Argument übergeben wird.

Zum Beispiel erzeugt `(format-two-quarters t "last" 3.14 "this" 0)` die folgende Ausgabe auf der Standardausgabe:

```

The value last quarter: 3.14
The value this quarter: 0

```

Beachte die Leerzeilen davor und danach.

## 3. Für Menschen und Lisp-Aliens lesbar

Layla hat vergessen, dir zu sagen, dass Lisp-Aliens Werte gern so sehen, dass sie als Lisp-Daten lesbar sind. Also braucht sie eine neue Funktion, deren Ergebnis sich als Lisp-Daten lesen lässt (wieder in den angegebenen Stream):

```lisp
(format-two-quarters-for-reading nil "last" 3.14 "this" 0) ; =>

"(\"The value last quarter: 3.14\" \"The value this quarter: 0\")"
```
