# Installation

Dieser Track setzt durchgehend auf [Wren Console][wren-console], um eine lokale Laufzeitumgebung für Wren bereitzustellen. Das heißt, wir gehen davon aus, dass die gesamte Ausführung von Wren auf deinem Computer mit [Wren Console][wren-console] erfolgt. Bitte verwechsle das nicht mit der offiziellen Wren-<abbr title="Kommandozeilenschnittstelle">CLI</abbr>. In einer perfekten Welt könntest du diese Laufzeitumgebung verwenden, aber sie [hat](https://github.com/wren-lang/wren-cli/pull/74) derzeit [mehrere](https://github.com/wren-lang/wren/pull/1006) [verschiedene](https://github.com/wren-lang/wren-cli/issues/108) [Probleme](https://github.com/wren-lang/wren-cli/pull/105), was sie zu einer weniger optimalen Wahl macht, wenn du Wren mit Exercism lernen willst.

Wren Console ist ein Fork von Wren CLI, behebt diese Probleme und fügt Funktionen hinzu, die dein Lernerlebnis reibungsloser machen. Keine Sorge: Die Wren-Kenntnisse und -Konzepte, die du hier lernst, solltest du überall anwenden können, wo du Wren künftig einsetzen möchtest.

## Installationsübersicht

- Installiere Git für den Befehl `git`
- Installiere [Wren Console][wren-console] für den Befehl `wrenc`

### Git installieren

Du brauchst das `git`-Binary installiert und in deinem Pfad. So installiert Wren Package Pakete (etwa die Test-Suite, die du zum Testen deiner Übungen brauchst, usw.).

- **Windows** – Der offizielle [Git-Download](https://git-scm.com/download/win) ist ein guter Ausgangspunkt.
-  **Linux** – Dein bevorzugter Paketmanager sollte dir weiterhelfen.
- **Mac** – Alle neueren Versionen von Mac OS bringen `git` bereits mit.

Du kannst mit `git --version` prüfen, ob Git installiert ist:

```
$ git --version
git version 2.31.1
```

Mach dir keine Sorgen, wenn die genaue Version nicht übereinstimmt, das ist normalerweise nicht so kritisch.


### Wren Console installieren

#### Windows

Du möchtest wahrscheinlich die [neueste Version][releases] von GitHub herunterladen. Danach musst du sie entpacken und die ausführbare Datei `wrenc` in deinen Pfad kopieren.

Es ist auch möglich, [aus dem Quellcode][build-from-source] mit Visual Studio zu bauen.

#### Linux

Du kannst die [neueste Version][releases] von GitHub herunterladen oder [aus dem Quellcode bauen][build-from-source].

```sh
wget -c https://github.com/joshgoebel/wren-console/releases/download/v0.3.1/wren-console-v0.3.1-linux.tar.gz
tar xzf wren-console-v0.3.1-linux.tar.gz
```

Und stelle sicher, dass sie in deinem `PATH` verfügbar ist.

```sh
cp bin/wrenc /usr/local/bin/
```


#### Mac

Am einfachsten installierst du über den Homebrew-Tap und die Formel von Exercism:

```
brew tap exercism/wren
brew install wren-console
```

Alternativ kannst du die [neueste Version][releases] von GitHub herunterladen und sie manuell installieren, wie in der Linux-Anleitung beschrieben. Auch das Bauen aus dem Quellcode ist recht einfach, wenn du dich mit solchen Dingen auskennst.

### Die Installation testen

Wenn du glaubst, dass das Binary korrekt installiert ist, solltest du testen, ob alles funktioniert.

1. Öffne ein _Terminal_ (`Terminal`, `cmd`, `Powershell`, `bash`, ...)
2. Führe `wrenc -v` aus

Du solltest sowohl die Version von `wrenc` als auch die von Wren aufgelistet sehen:

```
wrenc v0.3.1 (wren v0.4.0)
```

**Hinweis**: Es ist wichtig, dass du ein _neues_ Terminalfenster öffnest. Bereits geöffnete Terminalfenster wurden nach Abschluss der Installation möglicherweise nicht aktualisiert. Das bedeutet, dass die offenen Terminals nicht wissen, dass ein neues Programm installiert wurde.

> _**Hilfe**_: `'wrenc' is not recognised`
>
> Wahrscheinlich hast du `wrenc` nicht in deinen PATH gelegt... Unter macOS und Linux kannst du deinen Pfad ändern, indem du Folgendes zu `~/.bash_profile` oder `~/.zshrc` hinzufügst:
>
> ```bash
> export PATH=/path/to/your/wrenc/:$PATH
> ```
> **Keine Ahnung, ob das alles stimmt.**
> Öffne unter Windows das Startmenü und suche nach „environment variables". Du
> musst dann den Eintrag `PATH` bearbeiten und hier den Pfad zu den `wrenc`-Binärdateien _hinzufügen_.
> Normalerweise findest du diese unter `C:\Program Files\nodejs`. Wenn du mit
> deinem `File Explorer` hierher navigierst, solltest du `node.exe`, `npm.bat` und `npx.bat` finden.
>
> Schließe alle geöffneten Terminals und öffne ein neues.

## Voraussetzungen für die Übungen

Folge [dieser Anleitung][cli-walkthrough], um die `exercism` CLI für dein Betriebssystem herunterzuladen.

Sobald die CLI eingerichtet und konfiguriert ist, lade die erste Übung herunter, `hello-world`:

```bash
$ exercism download --exercise=hello-world --track=wren
```

Jede Übung braucht dann einige Wren-Pakete, um die Tests auszuführen. Du kannst sie installieren, indem du diesen Befehl im Verzeichnis der Übung ausführst:

```bash
$ wrenc package.wren install
```
