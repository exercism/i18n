# Überblick

[`throw`-Ausdrücke][throw-expressions] sind eine Alternative zu `throw`-Anweisungen und können insbesondere die Möglichkeiten von ternären und anderen zusammengesetzten Ausdrücken erweitern.

```csharp
string trimmed = str == null ? throw new ArgumentException() : str.Trim();
```

Wenn `str` im obigen Code `null` ist, wird eine Ausnahme ausgelöst.

[throw-expressions]: https://docs.microsoft.com/en-us/dotnet/csharp/language-reference/keywords/throw#the-throw-expression
