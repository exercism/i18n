# Anweisungen

Ein Anagramm ist eine Neuanordnung von Buchstaben, die ein neues Wort ergibt.
Gegeben sind ein Wort und eine Liste von Kandidaten. Wähle daraus die Teilliste der Anagramme des gegebenen Wortes aus.

Wenn du `"listen"` und eine Liste von Kandidaten wie `"enlists" "google"
"inlets" "banana"` bekommst, soll das Programm eine Liste zurückgeben,
die `"inlets"` enthält.
