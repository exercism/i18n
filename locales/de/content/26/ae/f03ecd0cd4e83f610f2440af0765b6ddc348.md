# Zusatz zu den Anweisungen

## Wörter

Implementiere:

- `grep ( pattern flags files -- lines )`

`pattern` ist der String, nach dem gesucht wird, `flags` ist ein Array aus null oder mehr der Flag-Strings `"-n"`, `"-l"`, `"-i"`, `"-v"` und `"-x"`, und `files` ist ein Array aus einem oder mehreren Dateinamen. Gib die passenden Zeilen (mit den angeforderten Präfixen für Dateiname und Zeilennummer) als Array von Strings zurück.

Wenn das Flag `-l` angegeben wird, gib ein Array mit den Namen der Dateien zurück, die mindestens einen Treffer enthalten.

## Dateien lesen

Lies die Zeilen einer Datei mit `file-lines` und übergib eine Kodierung:

```factor
USING: io.encodings.utf8 io.files ;

"iliad.txt" utf8 file-lines
! => { "Achilles sing, O Goddess! Peleus' son;" ... }
```

Die drei Fixture-Dateien (`iliad.txt`, `midsummer-night.txt` und `paradise-lost.txt`) werden mit der Übung im Arbeitsverzeichnis ausgeliefert, daher funktioniert das Lesen über den Namen einfach.
