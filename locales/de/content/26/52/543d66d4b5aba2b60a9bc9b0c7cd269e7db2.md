# Einführung

Eine Methode ist eine Funktion mit einem besonderen Argument, dem _Empfänger_.
Der Empfänger steht in einer eigenen Parameterliste zwischen dem `func`-Schlüsselwort und dem Namen der Methode.

```go
func (receiver type) MethodName(parameters) (returnTypes) {

}
```

Eine Methode kannst du nur definieren, wenn der Typ des Empfängers im selben Paket definiert ist wie die Methode.

```go
type Person struct {
    Name string
}

func (p Person) Greetings() string {
	return fmt.Sprintf("Welcome %s!", p.Name)
}

s := Person{Name: "Bronson"}
fmt.Println(s.Greetings())
// Output: Welcome Bronson!
```

Es gibt zwei Arten von Empfängern: Wertempfänger und Zeigerempfänger.

Methoden mit einem Wertempfänger arbeiten mit einer Kopie des übergebenen Werts. Das bedeutet, dass Änderungen am Empfänger innerhalb der Methode für den Aufrufer nicht sichtbar sind.

Du kannst Methoden mit Zeigerempfängern deklarieren, um den Wert zu ändern, auf den der Empfänger zeigt.
Dazu stellst du dem Typnamen ein `*` voran. Für den Typ `rect` deklarierst du einen Zeigerempfänger zum Beispiel als `*rect`.
Solche Änderungen sind auch für den Aufrufer der Methode sichtbar.

```go
type rect struct {
	width, height int
}
func (r *rect) squareIt() {
	r.height = r.width
}

r := rect{width: 10, height: 20}
fmt.Printf("Width: %d, Height: %d\n", r.width, r.height)
// Output: Width: 10, Height: 20

r.squareIt()
fmt.Printf("Width: %d, Height: %d\n", r.width, r.height)
// Output: Width: 10, Height: 10

```
