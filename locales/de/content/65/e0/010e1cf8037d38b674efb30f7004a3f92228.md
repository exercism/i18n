# Über GitHub beitragen

Beiträge zur Codebasis von Exercism reichst du über [GitHub][github] ein.

Wie der Name schon sagt, nutzt GitHub [git][git] als Versionskontrollsystem.
Wenn du mit Git nicht vertraut bist, ist [Pro Git][pro-git] die beste Online-Ressource.

Falls du GitHub und den Workflow für Beiträge noch nicht kennst, helfen dir diese Ressourcen beim Einstieg:

- [Einführung in GitHub – interaktiver Kurs][github-course]
- [Wie du auf GitHub einen Pull Request erstellst – Tutorial][pr-tutorial]
- [Wie du einen einfachen GitHub-PR erstellst – Video von anthonywritescode][anthonywritescode]

## Leitfäden

Wie du dafür sorgst, dass dein Beitrag willkommen ist, liest du im Leitfaden [Wie du einen großartigen Pull Request erstellst][great-pr].

Außerdem gibt es mehrere Exercism-spezifische Leitfäden zu Pull Requests:
