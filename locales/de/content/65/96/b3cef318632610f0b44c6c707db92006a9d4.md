# Einführung

Eine Definition mit `:` kann sich direkt selbst aufrufen. Der Compiler von Factor leitet den Stack-Effekt rekursiver Wörter genauso ab wie bei jedem anderen. Für einfache Rekursion ist keine besondere Deklaration nötig.

```factor
: total ( seq -- sum )
    [ 0 ] [ unclip swap total + ] if-empty ;

{ 4 0 9 0 5 } total .    ! => 18
```

Die beiden Hälften sind der *Basisfall* der Rekursion (hier summiert sich die leere Sequenz zu `0`) und der *rekursive Schritt* (ein Element abziehen, auf dem Rest rekursiv aufrufen, die Ergebnisse zusammenführen).

`if-empty` und `unclip` sind die klassischen Begleiter für die Rekursion über Sequenzen. `if-empty ( seq emptyquot nonemptyquot -- )` führt abhängig von der Sequenz eine von zwei Quotations aus; `unclip` zieht das erste Element ab, damit der rekursive Schritt etwas Einfacheres hat.
