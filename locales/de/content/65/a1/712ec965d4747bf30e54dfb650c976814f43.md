# Readonly-Klassen und -Eigenschaften

Readonly-Klassen und -Eigenschaften ermöglichen es Klassen, öffentliche Eigenschaften für einen einfachen Zugriff bereitzustellen, verhindern aber deren Änderung.
Um eine Eigenschaft als readonly zu deklarieren, muss `readonly` vor der Typangabe stehen.
Die Eigenschaft darf einmal zugewiesen werden. Jeder Versuch, den Wert erneut zuzuweisen oder zu ändern, führt jedoch zu einem Error.

```php
<?php

class Block
{
    public function __construct(
        public readonly int $length,
        public readonly int $width,
    ) {
    }
}
```

Readonly-Klassen bauen auf diesem Verhalten auf: Wird eine Klasse als `readonly` deklariert, gilt die Readonly-Deklaration für jede Eigenschaft.
Außerdem verhindern sie das Hinzufügen dynamischer Eigenschaften.

```php
<?php

readonly class Block
{
    public function __construct(
        public int $length,
        public int $width,
    ) {
    }
}
```
