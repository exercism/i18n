# Überblick

Eine Typdefinition erstellt einen neuen benannten Typ, der sich von jedem anderen Typ unterscheidet, selbst von einem mit demselben zugrunde liegenden Typ.

## Typen definieren

Eine Typdefinition beginnt mit dem Schlüsselwort `type`, gefolgt vom Namen des neuen Typs und seinem zugrunde liegenden Typ:

```go
type File []bool
```

`File` bezeichnet hier eine einzelne vertikale Spalte auf einem Schachbrett, die üblicherweise mit A bis H beschriftet ist.
Jedes Feld in dieser Spalte wird durch einen booleschen Wert dargestellt, der angibt, ob es besetzt ist oder nicht.
Jetzt, wo `File` definiert ist, können wir es in anderen Definitionen verwenden:

```go
type Chessboard map[string]File

board := Chessboard{
    "A": File{true, false, true},
    "B": File{false, true, false},
}
```

`Chessboard` ordnet Spaltenbezeichner `File`-Werten zu.
Jedes `File` ist ein Slice aus booleschen Werten, der die Felder einer Schachspalte darstellt.
Ohne diese Typdefinitionen wäre `board` ein `map[string][]bool`, und es wäre schwerer zu verstehen, was wir damit darstellen.

## Definierte Typen sind eigenständig

Obwohl `Score` und `int` beide Ganzzahlwerte speichern, braucht man für die Umwandlung zwischen ihnen eine explizite Konvertierung:

```go
type Score int

var number int = 42

// var score Score = number is a compile error
var score Score = Score(number)
var converted int = int(score)
```

`42` ist eine untypisierte Konstante und kann daher direkt einer `Score`-Variable zugewiesen werden.

Definierte Typen können auch Methoden haben, die im Konzept „Methoden“ behandelt werden.

## Struct-Typen

Struct-Definitionen verwenden dasselbe Schlüsselwort `type`:

```go
type Player struct {
    Name  string
    Score Score
}
```

Struct-Typen werden im Konzept „Structs“ behandelt.

## Typ-Aliase

Ein Typ-Alias erstellt einen weiteren Namen für einen vorhandenen Typ, anstatt einen neuen Typ zu erstellen.
Da ein Alias und sein ursprünglicher Typ identisch sind, können ihre Werte austauschbar verwendet werden.
Aliase werden mit dem Schlüsselwort `type`, dem Alias-Namen, dem Gleichheitszeichen (`=`) und dem vorhandenen Typ deklariert.

```go
type Square = bool

var isOccupied bool = true
var square Square = isOccupied // no conversion needed
```
