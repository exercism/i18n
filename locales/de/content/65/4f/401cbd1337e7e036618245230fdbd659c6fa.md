# Über

Es dürfte schwerfallen, eine ausdrucksstärkere Programmiersprache zu finden. [Raku](https://raku.org/) ist eine moderne Sprache mit mehreren Paradigmen. Raku bietet [prozedurale](https://docs.raku.org/language/functions), [objektorientierte](https://docs.raku.org/language/objects) und [funktionale](https://docs.raku.org/language/functions#Functions_are_first-class_objects) Programmiermethoden.

[Neugierig?](https://raku.org/) Stöbere in der [Dokumentation](https://docs.raku.org/) oder im Modul-[Repository](https://raku.land/) (wie pypi oder CPAN).

Sie ist eine überaus [flexible](https://docs.raku.org/language/operators) Sprache, die sich an deinen Programmierstil [anpasst](https://docs.raku.org/language/glossary#gradual_typing), egal ob du schnelle [Einzeiler](https://docs.raku.org/language/create-cli) für Sysadmins schreibst, Skripte für einen Datenbankimport oder den ganzen Stack an Modulen, der für eine [komplette Website](https://cro.services/) nötig ist.

Raku lernt von anderen Sprachen:

* Es steigert die langfristige Attraktivität von Perl mit einem richtigen Objektsystem, inklusive [Rollen](https://docs.raku.org/language/typesystem#role), [Threading](https://docs.raku.org/language/concurrency) und [Multi-Methoden-]Dispatch(https://docs.raku.org/language/glossary#Multi-dispatch).
* Aus Java übernimmt es das Threading, [vereinfacht](https://docs.raku.org/language/concurrency) auf eine Handvoll Methoden.
* Mit [Foreign-Function-]Schnittstellen(https://docs.raku.org/language/nativecall) aus Lisp wird der Zugriff auf Bibliotheken so einfach wie eine Zeile Code.
* [Reguläre Ausdrücke](https://docs.raku.org/language/regexes) gehen jetzt bis 11, dank der Einführung von Parser Expression [Grammars](https://docs.raku.org/language/grammars), mit denen du riesige Parsing-Aufgaben bewältigst.
* Strictures und Warnungen sind jetzt automatisch und schneiden große Mengen möglicher Fehler weg.
* ... und es versteht etwas von [Mathematik](https://docs.raku.org/language/math): ```1/10 * 3 == 0.3 ```. Probier das mal in deiner Lieblingssprache!

Rakus Mottos:
* „Raku ist so entworfen, dass einfache Aufgaben einfach bleiben und schwierige nicht unmöglich werden.“
* „Es gibt mehr als einen Weg, das zu tun. Jetzt mit noch mehr -Ofun (auf Spaß optimiert).“
