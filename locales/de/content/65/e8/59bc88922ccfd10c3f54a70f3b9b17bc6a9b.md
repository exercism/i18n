# Einführung

Klassen sind das grundlegende Konstrukt für objektorientierte Programmierung in F#.

Eine Klasse in F# besteht aus ihren Feldern und Methoden. Die Felder und Methoden einer Klasse werden als ihre _Member_ bezeichnet.

Klassen in F# werden mit dem Schlüsselwort `type` definiert. Methoden werden mit dem Schlüsselwort `member` definiert und sind immer öffentlich. Um (private) Felder zu definieren, können `let`-Bindungen verwendet werden.

```fsharp
type Shoe() =
    let size = 8

    member this.Describe() = $"This is a size {size} shoe"
```

Klassen sind Vorlagen, mit denen man Objekte erstellt. Um eine Instanz einer Klasse zu erstellen, rufst du den Namen der Klasse wie eine Funktion auf. Eine Instanz einer Klasse wird auch als _Objekt_ bezeichnet.

Mit der Punktnotation kannst du auf die Member eines Objekts zugreifen.

```fsharp
let myShoe = Shoe()
myShoe.Describe()
// => "This is a size 8 shoe"
```
