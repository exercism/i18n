# Einführung

In Gleam kannst du einen `case`-Ausdruck verwenden, um Code bedingt auszuführen. Mit einem case-Ausdruck kann ein Wert gegen ein oder mehrere _Muster_ geprüft werden. Ein Beispiel für ein solches Muster ist das _literale Muster_, das einen Wert gegen einen Literalwert abgleicht (z. B. `1` oder `"hello"`).

Case-Ausdrücke werden mit dem Schlüsselwort `case` geschrieben:

```gleam
pub fn describe(number: Int) -> String {
  case number {
    0 -> "Zero"
    1 -> "One"
  }
}
```

Auch wenn das wie `switch`-Anweisungen in anderen Sprachen aussehen mag: Pattern Matching zeigt seine wahre Stärke erst, wenn du auch andere Muster verwendest. Ein solches Muster ist das _Variablenmuster_, mit dem du einer Variablen einen Wert zuweisen kannst. In diesem Beispiel bekommt die Variable `i` den Wert von `number`, wenn dieser nicht `0` ist:

```gleam
pub fn describe(number: Int) -> String {
  case number {
    0 -> "Zero"
    i -> "Non zero"
  }
}
```

Manchmal möchtest du einem Muster eine zusätzliche Bedingung hinzufügen. Das nennt man _Guard_ (Klausel), und du kannst ihn mit dem Schlüsselwort `if` hinzufügen:

```gleam
pub fn describe(number: Int) -> String {
  case number {
    0 -> "Zero"
    i if i < 0 -> "Negative number"
  }
}
```

Aus Performance-Gründen sind in Guards nur grundlegende mathematische und boolesche Operatoren erlaubt. Andere Funktionen kannst du in Guards nicht verwenden.

Im obigen Beispiel hat nicht jeder mögliche Eingabewert ein passendes Muster. Der Compiler erkennt das und gibt einen Fehler aus. Das nennt man _Vollständigkeitsprüfung_. Um die Warnung zu beheben, musst du alle Fälle abdecken. Dafür kannst du das _Verwerfungsmuster_ verwenden, ein Muster, das auf jeden Wert passt:

```gleam
pub fn describe(number: Int) -> String {
  case number {
    0 -> "Zero"
    i if i < 0 -> "Negative number"
    _ -> "Positive number"
  }
}

// No compiler error
```

Case-Ausdrücke prüfen einen Wert von oben nach unten gegen jedes Muster, bis sie ein passendes Muster finden und die zugehörige Logik ausführen. Die Reihenfolge der Muster ist wichtig!
