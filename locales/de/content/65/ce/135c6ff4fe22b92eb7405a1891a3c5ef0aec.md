# Anleitung

Wandle eine Oktalzahl, die als String dargestellt wird (z. B. '1735263'), selbst von Grund auf in die entsprechende Dezimalzahl um (d. h. nein, du darfst für die Umrechnung keine eingebauten oder externen Bibliotheken verwenden).

Implementiere die Umrechnung von Oktal nach Dezimal.
Bei einem Oktal-Eingabe-String soll dein Programm eine Dezimalzahl ausgeben.

## Hinweis

- Implementiere die Umrechnung selbst.
  Verwende nichts anderes, das die Umrechnung für dich erledigt.
- Behandle ungültige Eingaben als Oktal-0.

## Über Oktal (Basis 8)

Dezimal ist ein System zur Basis 10.

Eine Zahl wie 233 in Basis-10-Schreibweise lässt sich als Linearkombination von Zehnerpotenzen verstehen:

- Die rechteste Ziffer wird mit 10^0 = 1 multipliziert
- Die nächste Ziffer wird mit 10^1 = 10 multipliziert
- ...
- Die *n*-te Ziffer wird mit 10^*(n-1)* multipliziert.
- Alle diese Werte werden summiert.

Also:

```text
   233 # decimal
 = 2*10^2 + 3*10^1 + 3*10^0
 = 2*100  + 3*10   + 3*1
```

Oktal funktioniert ähnlich, verwendet aber Achterpotenzen statt Zehnerpotenzen.

Also:

```text
   233 # octal
 = 2*8^2 + 3*8^1 + 3*8^0
 = 2*64  + 3*8   + 3*1
 = 128   + 24    + 3
 = 155
```
