# Überblick

In Java wird das [`null`-Literal][null-keyword] verwendet, um das Fehlen eines Werts auszudrücken.

[Primitive Datentypen][primitive-data-types] haben in Java alle einen Standardwert und können daher niemals `null` sein.
Konventionsgemäß beginnen sie mit einem Kleinbuchstaben, z. B. `int`.

[Referenztypen][reference-data-types] enthalten die Speicheradresse eines Objekts und können den Wert `null` haben.
Sie beginnen in der Regel mit einem Großbuchstaben, z. B. `String`.

Wenn du versuchst, einer primitiven Variable den Wert `null` zuzuweisen, führt das zu einem Kompilierfehler, denn die Variable enthält immer einen Standardwert des zugewiesenen Typs.

```java
// Throws compile time error stating the required type is int, but null was provided
int number = null;
```

Wenn du einer Referenzvariable den Wert `null` zuweist, führt das nicht zu einem Kompilierfehler, denn Referenzvariablen dürfen `null` sein.

```java
//No error will occur as the String variable str is nullable
String str = null;
```

Der Zugriff auf eine Referenzvariable mit dem Wert `null` lässt sich zwar problemlos kompilieren, führt aber zur Laufzeit dazu, dass eine `NullPointerException` ausgelöst wird.

```java
int[] arr = null;

// Throws NullPointerException at runtime
arr.length;
```

Eine [`NullPointerException` wird ausgelöst][null-pointer-exception], wenn du versuchst, auf eine Referenzvariable zuzugreifen, die `null` ist, aber ein Objekt erfordert.

Um sicher mit nullbaren Werten zu arbeiten, solltest du prüfen, ob sie `null` sind, bevor du sie verwendest. Das geht mit [Gleichheitsoperatoren][equality-operators] wie `==` oder `!=`:

```java
int[] arr = null;

if(arr != null) {
    System.out.println(arr.length);
} else {
    //Perform an alternate action when arr is null
}
```
