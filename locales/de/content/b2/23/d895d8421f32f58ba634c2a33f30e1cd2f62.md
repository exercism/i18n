# Anhang zur Anleitung

Jede Zeile des Gitters wird als Wort dargestellt.

Zum Beispiel:

```
    0 1 0
    1 0 0
    1 1 0
```

wird dargestellt als

```
0x2
0x4
0x6
```

Das Gitter hat höchstens 32 Spalten.

## Register

| Register | Verwendung   | Typ      | Beschreibung                          |
| -------- | ------------ | -------- | ------------------------------------- |
| `$a0`    | Eingabe      | Ganzzahl | Anzahl der Zeilen                     |
| `$a1`    | Eingabe      | Ganzzahl | Anzahl der Spalten                    |
| `$a2`    | Eingabe      | Adresse  | Gitter für die aktuelle Generation    |
| `$a3`    | Ein-/Ausgabe | Adresse  | Gitter für die nächste Generation     |
| `$t0-9`  | temporär     | beliebig | dient der temporären Speicherung      |
