# Ergänzung der Anweisungen

## Trackspezifische Anweisungen

In dieser Übung geht es darum, der `Array`-Struktur in Swift Methoden hinzuzufügen.
Am einfachsten geht das mit [Extensions][extensions].

```swift
extension Array {
  // Write your code for the 'Strain' exercise in this file.
}
```

Die Dokumentation zu `Array` findest du [hier][array].
