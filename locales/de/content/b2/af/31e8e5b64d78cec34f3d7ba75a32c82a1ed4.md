# Aufgabenstellung

In dieser Übung analysierst du Telefonnummern.

Du sollst zwei Features implementieren.

Telefonnummern, die an die Routinen übergeben werden, haben garantiert die Form
`NNN-NNN-NNNN`, z. B. `212-515-9876`, und sind nie null.

## 1. Analysiere eine Telefonnummer

Deine Analyse sollte drei Angaben zurückgeben

1. Eine Angabe darüber, ob die Nummer eine New Yorker Vorwahl hat, also 212 als die ersten drei Ziffern
2. Eine Angabe darüber, ob die Nummer gefälscht ist, weil sie 555 als Präfix-Code an den Positionen 5 bis 7 hat (Zählung ab 1)
3. Die letzten vier Ziffern der Nummer.

Implementiere die (statische) Methode `PhoneNumber.Analyze()`, um die Informationen zur Telefonnummer zu erzeugen.

```csharp
PhoneNumber.Analyze("631-555-1234");
// => (false, true, "1234")
```

## 2. Erkenne, ob eine Telefonnummer einen gefälschten Präfix-Code (555) hat

Implementiere die (statische) Methode `PhoneNumber.IsFake()`, um mithilfe der Telefonnummer-Informationen aus Aufgabe 1 zu erkennen, ob die Telefonnummer gefälscht ist.

```csharp
PhoneNumber.IsFake(PhoneNumbers.Analyze("631-555-1234"));
// => true
```
