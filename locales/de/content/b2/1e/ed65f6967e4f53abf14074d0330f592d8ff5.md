# Hinweise

## Allgemein

- Du erhältst zwar eine `reference` auf ein `ElectionResult`, kannst aber mit der Punktnotation `.` auf dessen Member zugreifen, als wäre es keine `reference`!
- Eine `reference` auf eine Variable bekommst du mit dem `&`-Operator, z. B. `int&`.
- Wenn du dir unsicher bist, wie `references` funktionieren, lies [Learn C++: References][learncpp-references].

## 1. Die Anzahl der Stimmen aus einem `ElectionResult` ermitteln

- Du musst eine Funktion mit einer `reference` auf ein `ElectionResult` erstellen, mit anderen Worten ein `ElectionResult&`.
- - Du erhältst zwar eine `reference` auf ein `ElectionResult`, kannst aber mit der Punktnotation `.` auf dessen Member zugreifen, als wäre es keine `reference`!

## 2. Die Stimmen eines `ElectionResult` erhöhen

- Du musst eine Funktion mit einer `reference` auf ein `ElectionResult` erstellen, mit anderen Worten ein `ElectionResult&`.
- - Du erhältst zwar eine `reference` auf ein `ElectionResult`, kannst aber dessen Membervariablen mit der Punktnotation `.` ändern, als wäre es keine `reference`!

## 3. Stimmen auszählen und Präsidentschaft

- Du kannst eine `reference` auf einen `vector` wie einen normalen Vektor mit einer Schleife durchlaufen.
- Die Größe eines Vektors bekommst du mit `myvector.size()`.
