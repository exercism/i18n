# Über

In Swift kannst du einen String nicht mit einer Ganzzahl indizieren (etwa `string[3]`). Weil Swift-Strings aus Unicode-Zeichen mit variabler Länge bestehen, musst du beim Suchen eines Zeichens alle vorhergehenden Zeichen durchgehen.

Um auf ein Zeichen an einer bestimmten Position zuzugreifen, musst du einen Index vom Typ `String.Index` berechnen. Diese Indizes heißen *opaque Indizes*, weil Swift ihre interne Struktur verwaltet, anstatt dass du sie direkt als rohe Ganzzahlen manipulierst:

```swift
let csv = "apple,pear,peach,orange,cherry,lime,gooseberry"
let index = csv.index(csv.startIndex, offsetBy: 21)
print(csv[index])
// Prints "g"

print(index)
// Prints internal representation: Index(_rawBits: ...)
```
