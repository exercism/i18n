# Einführung

Der _ternäre Operator_ ist eine leichtgewichtige, kompakte Alternative für einfache _if/else_-Anweisungen.
Er wird üblicherweise in (aber nicht ausschließlich in) return-Anweisungen verwendet und braucht nur eine einzige Zeile, um die Entscheidung zu treffen: Er gibt den linken Wert zurück, wenn der Ausdruck `true` ist, und den rechten Wert, wenn er `false` ist, wie folgt:

```java
boolean expr = 0 != 200;

// Ternary statement
int value = expr ? 22 : 33;
// => 22
```

Viele einfache _if/else_-Ausdrücke lassen sich mit _ternären Operatoren_ vereinfachen.
