# Tests

Alle Übungen verwenden das [Pester][pester]-Framework zum Mocken und Testen.
Alle Tests stehen in einer Datei namens `[Exercise].tests.ps1`, wie es beim Pester-Framework Standard ist.
Wenn du dich im richtigen Verzeichnis befindest (also in dem, das `[Exercise].ps1` und `[Exercise].tests.ps1` enthält).
Du kannst die Tests in PowerShell ausführen, indem du Folgendes aufrufst:

``` PowerShell
Invoke-Pester
```

Damit werden alle `.tests.ps1`-Dateien ausgeführt, die im Verzeichnis gefunden werden.

Wenn du eine andere Shell als PowerShell verwendest, kannst du die Tests so ausführen:

``` PowerShell
pwsh -Command "Invoke-Pester"
```

## Tests in Visual Studio Code ausführen

Du musst sicherstellen, dass du [die PowerShell-Erweiterung][extension] in Visual Studio Code installiert hast.

Du kannst Tests in Visual Studio Code auf verschiedene Arten ausführen:

- Führe das Skript `.Tests.ps1` über das Debug-Menü aus. Die Tastenkürzel sind: `F5` oder `Shift + F5`
- Klicke im Editor auf den Link „Run Tests“ über dem Schlüsselwort `Describe` im Testcode selbst
- Konfiguriere einen Task, um das Pester-Framework auszuführen

[pester]: https://github.com/pester/Pester
[extension]: https://marketplace.visualstudio.com/items?itemName=ms-vscode.PowerShell
