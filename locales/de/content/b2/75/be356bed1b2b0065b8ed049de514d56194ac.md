# Anhang zur Anleitung

## Ausgabeformat

Gib die Pflanzen der Schülerin oder des Schülers als nullterminierten String aus und verwende ein Komma und ein Leerzeichen als Trennzeichen.

## Register

| Register | Verwendung      | Typ      | Beschreibung                          |
| -------- | --------------- | -------- | ------------------------------------- |
| `$a0`    | Eingabe         | Adresse  | Gartendiagramm                        |
| `$a1`    | Eingabe         | Adresse  | Name der Schülerin oder des Schülers  |
| `$a2`    | Eingabe/Ausgabe | Adresse  | nullterminierter Ausgabe-String       |
| `$t0-9`  | temporär        | beliebig | dient der Zwischenspeicherung         |
