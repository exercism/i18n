# Anleitung

Du bist der Maître D' in einem Hotelrestaurant.
Deine Aufgabe ist es, die Sitzordnung im Speisesaal zu verwalten, und zwar abhängig von der Anzahl der heute verfügbaren Plätze, der Anzahl der Reservierungen und den Gästen, die spontan hereinkommen und gerade darauf warten, einen Platz zu bekommen.
Für diese Übung wird jeweils der erste freie Platz vergeben.

In dieser Übung gibt es 6 verschiedene Aufgaben rund um die Organisation des Speisesaals.

## 1. Erstelle den Sitzplan für heute

Definiere die Funktion `new_seating_chart(<size=22>)`, die ein Argument `size` entgegennimmt, das die Anzahl der Plätze angibt, die heute im Speisesaal aufgestellt werden.
Wenn kein `size` angegeben wird, soll die Funktion einen Sitzplan mit 22 Plätzen zurückgeben.
Die Platzwerte sollen als Platzhalter `None` enthalten, um anzuzeigen, dass sie einem Gast zugewiesen werden können.

## 2. Reservierungen verteilen

Definiere die Funktion `arrange_reservations(<guest_names>)` mit einem Parameter für eine Liste mit den Namen der Gäste.
Das steht für die Anzahl der Personen, die heute einen Platz im Speisesaal reserviert haben.

Diese Funktion soll einen Sitzplan als `dict` in der Standardgröße (22 Plätze) zurückgeben, wobei die Gäste in der Reihenfolge auf die Plätze verteilt werden, in der sie auf der Reservierungsliste stehen.
Alle nicht zugewiesenen Plätze sollen auf `None` gesetzt werden.
Wenn es keine Gäste gibt, soll ein „leerer“ Sitzplan zurückgegeben werden, in dem alle Platzhalter `None` sind.

```python
>>> arrange_reservations(guests=["Walter", "Frank", "Jenny", "Carol", "Alice", "George"])
...
{1: 'Walter', 2: 'Frank', 3: 'Jenny', 4: 'Carol', 5: 'Alice', 6: 'George', 7: None, 8: None, 9: None, 10: None, 11: None, 12: None, 13: None, 14: None, 15: None, 16: None, 17: None, 18: None, 19: None, 20: None, 21: None, 22: None}
```

## 3. Finde alle „leeren“ Sitzplätze

Definiere die Funktion `find_all_available_seats(<seats>)`, die einen Parameter entgegennimmt (_ein Sitzplan-Wörterbuch_) und eine `list` mit Platznummern zurückgibt, die für Gäste verfügbar sind, die gerade warten.
Wenn ein Platz leer ist, hat er im Wörterbuch den Wert `None`. Besetzte Plätze enthalten den Namen des Gastes.

```python
>>> seats = {1: None, 2: 'Frank', 3: 'Jenny', 4: None, 5: 'Alice', 6: 'George', 7: None, 8: 'Carol', 9: None, 10: None, 11: None, 12: 'Walter'}

>>> find_all_available_seats(seats)
[1,4,7,9,10,11]
```

## 4. Aktuelle Zahl freier Plätze

Definiere die Funktion `current_empty_seat_capacity(<seats>)`, die einen Parameter entgegennimmt: das `dict` der bestehenden Platzreservierungen.
Die Funktion soll die Gesamtzahl der leeren Plätze zurückgeben.

```python
>>> curr_empty_seat_capacity({1: "Occupied", 2: None, 3: "Occupied"})
1

>>> curr_empty_seat_capacity({1: "Occupied", 2: None, 3: None})
2
```

## 5. Sollen wir warten?

Definiere die Funktion `accommodate_waiting_guests(<seats>, <guests>)`, die zwei Parameter entgegennimmt.
Der erste Parameter ist ein Sitzplan-`dict`.
Der zweite Parameter ist eine `list` mit Gästen, die unerwartet hereingekommen sind.
Zuerst musst du herausfinden, wie viele Plätze frei sind und ob du den unangekündigten Gästen überhaupt noch Plätze geben kannst.

Wenn du nicht genug Plätze hast, gib das Sitzplan-`dict` unverändert zurück.

Wenn Plätze _frei sind_, weise den Gästen Plätze im Sitzplan zu und gib den aktualisierten Sitzplan zurück.
**Tipp:** Du kannst die zuvor definierten Funktionen verwenden, um die Berechnungen für dich zu erledigen.

```python
# Guests cannot be accommodated.
>>> starting_reservations = {1: 'Carol', 2: 'Alice', 3: 'George', 4: None, 5: None, 6: None, 7: 'Frank', 8: 'Walter'}
>>> accommodate_guests(starting_reservations, ["Mort", "Suze", "Phillip", "Tony"])
...
{1: 'Carol', 2: 'Alice', 3: 'George', 4: None, 5: None, 6: None, 7: 'Frank', 8: 'Walter'}


# Guests can be accommodated.
>>> starting_reservations = {1: None, 2: None, 3: None, 4: 'Carol', 5: 'Alice', 6: 'George', 7: None, 8: None, 9: None, 10: None, 11: None, 12: None, 13: None, 14: None, 15: None, 16: None, 17: None, 18: 'Frank', 19:  'Jenny', 20: None, 21: None, 22: 'Walter'}
>>> accommodate_guests(starting_reservations, ["Mort", "Suze", "Phillip", "Tony"])
...
{1: 'Mort', 2: 'Suze', 3: 'Phillip', 4: 'Carol', 5: 'Alice', 6: 'George', 7: 'Tony', 8: None, 9: None, 10: None, 11: None, 12: None, 13: None, 14: None, 15: None, 16: None, 17: None, 18: 'Frank', 19: 'Jenny', 20: None, 21: None, 22: 'Walter'}
```

## 6. Sitzplätze leeren

Definiere die Funktion `empty_seats(<seats>, <seat_numbers>)`, die zwei Parameter entgegennimmt.
Der erste Parameter ist ein Sitzplan-Wörterbuch.
Der zweite Parameter ist eine Liste mit Platznummern, die du „freigeben“ oder leeren musst, das heißt, du musst den Wert der Platznummer auf `None` setzen.

Gib das `dict` der Plätze zurück, nachdem du die zu leerenden Platzwerte aktualisiert hast.

```python
>>> empty_seats(seats={1: "Alice", 2: None, 3: "Bob", 4: "George", 5: "Gloria"}, seat_numbers=[5,3,1])
{1: None, 2: None, 3: None, 4: "George", 5: None}
```
