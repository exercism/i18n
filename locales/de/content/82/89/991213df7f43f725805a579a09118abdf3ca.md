# Anhang zu den Anweisungen

## Register

| Register | Verwendung | Typ     | Beschreibung                                            |
| -------- | ---------- | ------- | ------------------------------------------------------- |
| `$a0`    | Eingabe    | Adresse | erste Farbe als nullterminierter String                 |
| `$a1`    | Eingabe    | Adresse | zweite Farbe als nullterminierter String                |
| `$a2`    | Eingabe    | Adresse | dritte Farbe als nullterminierter String (evtl. leer)   |
| `$v0`    | Ausgabe    | Ganzzahl | Widerstandswert                                        |
| `$t0-9`  | temporär   | beliebig | für die temporäre Speicherung                          |
