# Anweisungen

Als angehende Magierin muss Elyse ein paar Grundlagen üben. Sie hat
einen Stapel Karten, den sie manipulieren möchte.

Um es etwas einfacher zu machen, benutzt sie nur die Karten 1 bis 10, sodass ihr
Kartenstapel durch ein Array von Zahlen dargestellt werden kann. Die Position
einer bestimmten Karte entspricht dem Index im Array. Das heißt,
Position 0 verweist auf die erste Karte, Position 1 auf die zweite Karte
usw.

<!-- prettier-ignore-start -->
~~~~exercism/note
Bis auf zwei Funktionen sollten alle das Array der Karten aktualisieren und dann das geänderte Array zurückgeben. Das ist eine gängige Vorgehensweise, die als Builder-Muster bekannt ist und mit der du Funktionen schön verketten kannst.

Die beiden Ausnahmen sind `getItem`, das die Karte an der angegebenen Position zurückgeben sollte, und `checkSizeOfStack`, das `true` zurückgeben sollte, wenn die angegebene Größe übereinstimmt.
~~~~
<!-- prettier-ignore-end -->

## 1. Eine Karte aus einem Stapel holen

Um eine Karte zu ziehen, gib die Karte am Index `position` aus
dem angegebenen Stapel zurück.

```javascript
const position = 2;
getItem([1, 2, 4, 1], position);
// => 4
```

## 2. Eine Karte im Stapel austauschen

Führe ein paar Fingerfertigkeiten vor und tausche die Karte am Index `position`
gegen die angegebene Ersatzkarte aus.
Gib den angepassten Stapel zurück.

```javascript
const position = 2;
const replacementCard = 6;
setItem([1, 2, 4, 1], position, replacementCard);
// => [1, 2, 6, 1]
```

## 3. Eine Karte oben auf den Stapel legen

Lass eine Karte erscheinen, indem du eine neue Karte oben auf den Stapel legst.
Gib den angepassten Stapel zurück.

```javascript
const newCard = 8;
insertItemAtTop([5, 9, 7, 1], newCard);
// => [5, 9, 7, 1, 8]
```

## 4. Eine Karte aus dem Stapel entfernen

Lass eine Karte verschwinden, indem du die Karte an der angegebenen `position` aus dem Stapel entfernst.
Gib den angepassten Stapel zurück.

```javascript
const position = 2;
removeItem([3, 2, 6, 4, 8], position);
// => [3, 2, 4, 8]
```

## 5. Die oberste Karte vom Stapel entfernen

Lass eine Karte verschwinden, indem du die oberste Karte vom Stapel entfernst.
Gib den angepassten Stapel zurück.

```javascript
removeItemFromTop([3, 2, 6, 4, 8]);
// => [3, 2, 6, 4]
```

## 6. Eine Karte unten an den Stapel anfügen

Lass eine Karte erscheinen, indem du eine neue Karte unten an den Stapel anfügst.
Gib den angepassten Stapel zurück.

```javascript
const newCard = 8;
insertItemAtBottom([5, 9, 7, 1], newCard);
// => [8, 5, 9, 7, 1]
```

## 7. Eine Karte von unten vom Stapel entfernen

Lass eine Karte verschwinden, indem du die unterste Karte vom Stapel entfernst.
Gib den angepassten Stapel zurück.

```javascript
removeItemAtBottom([8, 5, 9, 7, 1]);
// => [5, 9, 7, 1]
```

## 8. Die Größe des Stapels prüfen

Prüfe, ob die Größe des Stapels gleich `stackSize` ist oder nicht.

```javascript
const stackSize = 4;
checkSizeOfStack([3, 2, 6, 4, 8], stackSize);
// => false
```
