# Einführung

Pattern Matching ist das Verzweigen abhängig davon, ob ein Wert auf vorgegebene, möglicherweise tief verschachtelte Patterns passt. In Haxe setzt du **Pattern Matching** mit `switch`-Ausdrücken und einzelnen `case`-Ausdrücken um.

Schau dir diese Datenstruktur an:

```haxe
enum Tree<T> {
  Leaf(v:T);
  Node(l:Tree<T>, r:Tree<T>);
}
```

- Patterns werden immer von oben nach unten abgeglichen.
- Beim obersten Pattern, das zum Eingabewert passt, wird der zugehörige Ausdruck ausgeführt.
- Ein `_`-Pattern passt auf alles, `case _:` entspricht also `default:`

## Matching von Enums

Enums kannst du ganz natürlich über ihre Konstruktoren abgleichen:

```haxe
var myTree = Node(Leaf("foo"), Node(Leaf("bar"), Leaf("foobar")));

var match = switch (myTree) {
  // Matches any Leaf
  case Leaf(_):
    "0";

  // Matches any Node that has r = Leaf
  case Node(_, Leaf(_)):
    "1";

  // Matches any Node that has
  // r = another Node which has
  // l = Leaf("bar")
  case Node(_, Node(Leaf("bar", _))):
    "2";

  // Matches anything
  case _:
    "3";
}

trace(match); // 2
```
