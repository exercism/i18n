# Vektoren als Stack

Ein Stack ist eine lineare Datenstruktur, die für den Zugriff von einem Ende her optimiert ist. Eine passende Metapher ist ein Stapel Papier auf einem Spieß: Neue Blätter werden immer am selben Ende hinzugefügt, und die Blätter werden in der umgekehrten Reihenfolge entfernt, in der sie hinzugefügt wurden. Die zuerst hinzugefügten Blätter werden zuletzt entfernt, die zuletzt hinzugefügten zuerst.

Die `Vec`-Datenstruktur von Rust eignet sich für die Verwendung als Stack. Die [`push`-Methode](https://doc.rust-lang.org/std/vec/struct.Vec.html#method.push) fügt Elemente am Ende des Vektors hinzu. Die [`pop`-Methode](https://doc.rust-lang.org/std/vec/struct.Vec.html#method.pop) entfernt das letzte Element aus dem Vektor. Sowohl `push` als auch `pop` brauchen nur eine amortisierte Laufzeit von `O(1)`.

## Beispiel

In diesem Beispiel verwenden wir einen Vektor als Stack für einen einfachen [RPN](https://en.wikipedia.org/wiki/Reverse_Polish_notation)-Rechner. Der vollständige Quellcode ist im [Playground](https://play.rust-lang.org/?version=stable&mode=debug&edition=2018&gist=b40514e282cb753d0c3272778f92d736) zu finden.

```rust
#[derive(Default)]
pub struct RpnCalculator {
    stack: Vec<Value>,
}

impl RpnCalculator {
    pub fn evaluate(&mut self, argument: Argument) -> Result<(), Error> {
        match argument {
            Argument::Value(value) => self.stack.push(value),
            Argument::Operator(operator) => {
                let b = self.stack.pop().ok_or(Error::StackUnderflow)?;
                let a = self.stack.pop().ok_or(Error::StackUnderflow)?;
                let output = operator.execute()(a, b);
                self.stack.push(output);
            }
        }
        Ok(())
    }

    pub fn conclude(self) -> Result<Value, Error> {
        if self.stack.len() == 1 {
            Ok(self.stack[0])
        } else {
            Err(Error::IncompleteCalculation)
        }
    }
}
```
