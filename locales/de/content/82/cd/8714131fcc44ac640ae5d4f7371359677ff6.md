# Über

[C++](https://en.wikipedia.org/wiki/C%2B%2B) (ausgesprochen „cee plus plus“) ist eine universell einsetzbare Programmiersprache, die [Bjarne Stroustrup](https://en.wikipedia.org/wiki/Bjarne_Stroustrup) ab 1979 in den Bell Labs entwickelte. Sie ist enorm beliebt, besonders für Anwendungen, die Geschwindigkeit und/oder den Zugriff auf bestimmte Low-Level-Funktionen erfordern. Sie gilt als Sprache auf mittlerem Niveau, da sie sowohl High-Level- als auch Low-Level-Sprachmerkmale in sich vereint.

C++ unterstützt [prozedurale](https://en.wikipedia.org/wiki/Procedural_programming), [objektorientierte](https://en.wikipedia.org/wiki/Object-oriented_programming), [funktionale](https://en.wikipedia.org/wiki/Functional_programming) und [generische](https://en.wikipedia.org/wiki/Generic_programming) Programmierung. Compiler für C++ gibt es für praktisch jede Plattform, darunter Windows, Mac OS und Linux.

Die wichtigsten Vorteile:
- **Typsicherheit:** Notwendige unsichere Operationen kapseln
- **Ressourcensicherheit:** Nicht jede Ressourcenverwaltung ist Speicherverwaltung
- **Performance:** Für manche Teile fast aller Systeme ist sie wichtig
- **Vorhersagbarkeit:** Für harte und weiche Echtzeitsysteme
- **Vermittelbarkeit:** Die Komplexität des Codes sollte proportional zur Komplexität der Aufgabe sein
- **Lesbarkeit:** Für Menschen und Maschinen („Analysierbarkeit“)
- **Direkte Abbildung auf die Hardware:** von Befehlen und grundlegenden Datentypen
- **Abstraktion ohne Overhead:** Klassen mit Konstruktoren und Destruktoren, Vererbung, generische Programmierung, Techniken der funktionalen Programmierung

Der Standard für C++ wird von der International Organization for Standardization (ISO) gepflegt. Die aktuelle Version von C++ ist Stand Juni 2018 C++17 (nicht als 17. Version von C++ benannt, sondern weil der Standard 2017 ratifiziert wurde).

Das Beste an C++ ist, dass es überall läuft: von eingebetteten Prozessoren mit sehr begrenzten Ressourcen bis hin zum größten Mainframe-Supercomputer und jedem PC dazwischen.
