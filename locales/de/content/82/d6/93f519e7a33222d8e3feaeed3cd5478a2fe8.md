# Anhang zu den Anweisungen

## Implementierung

Annahmen:

1. Null wird in Ausgaben immer als [0] dargestellt, nicht als [].
2. In keinem anderen Fall enthalten Ausgaben führende Nullen.
3. Eingaben dürfen führende Nullen enthalten.
4. Eine leere Sequenz von Eingabeziffern gilt als Null und nicht als Fehler.

Behandle Problemfälle, indem du einen Fehler zurückgibst, dessen Error()-Methode
eine der folgenden Meldungen zurückgibt:

- input base must be >= 2
- output base must be >= 2
- all digits must satisfy 0 <= d < input base
