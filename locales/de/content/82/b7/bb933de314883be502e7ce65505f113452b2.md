# Anleitung

In dieser Übung verarbeitest du Log-Nachrichten mit sechs Schweregraden.

Jede Log-Zeile ist ein String, der wie folgt formatiert ist: `"[<LVL>]: <MESSAGE>"`.

Das sind die verschiedenen Log-Level:

| STUFE     | LVL   |
| --------- | ----- |
| `Trace`   | `TRC` |
| `Debug`   | `DBG` |
| `Info`    | `INF` |
| `Warning` | `WRN` |
| `Error`   | `ERR` |
| `Fatal`   | `FTL` |

## 1. Log-Level parsen

Definiere ein Enum `LogLevel` mit sechs Elementen, die den oben definierten Log-Leveln entsprechen.
Definiere als Nächstes die Funktion `parse_log_level`, die die Log-Nachricht als Parameter entgegennimmt und das Enum-Element ihrer Stufe zurückgibt.

```python
parse_log_level("[INF]: File deleted")
#=> LogLevel.Info
```

## 2. Unbekannten Log-Level unterstützen

Leider tauchen gelegentlich Log-Nachrichten mit einem _unbekannten_ Schweregrad auf. Um diese „mysteriösen" Log-Nachrichten in der Funktion `parse_log_level` sauber zu behandeln, füge dem Enum `LogLevel` ein Member `Unknown` hinzu, das zurückgegeben wird, wenn ein unbekannter Log-Level geparst wird:

```python
parse_log_level("[XYZ]: Overly specific, out of context message")
#=> LogLevel.Unknown
```

## 3. Eine Log-Nachricht ins Kurzformat umwandeln

Der Log-Level einer Log-Zeile ist ziemlich ausführlich. Um den Speicherplatz zu reduzieren, der zum Speichern der Log-Nachrichten nötig ist, ist ein Kurzformat definiert: `"[<CODE_LEVEL>]:<MESSAGE>"`.

Die Codes der Log-Level folgen einer einfachen Zuordnung:

| STUFE     | CODE |
| --------- | ---- |
| `Trace`   | `0`  |
| `Debug`   | `1`  |
| `Info`    | `4`  |
| `Warning` | `5`  |
| `Error`   | `6`  |
| `Fatal`   | `7`  |
| `Unknown` | `42` |

Definiere die Funktion `convert_to_short_log()`, die zwei Parameter entgegennimmt:

1. Log-Level: Der Log-Level des gesendeten Logs, z. B. `LogLevel.Error`.
2. Log-Nachricht: Die Nachricht vom Typ `str`.

```python
convert_to_short_log(LogLevel.Error, "Stack overflow")
# => "6:Stack overflow"
```

## 4. Einen Alias erstellen

Anscheinend hat der Nutzer Logs für `LogLevel.Warn` statt für `LogLevel.Warning` erstellt. Erstelle einen `alias` für `LogLevel.Warning` und gib das neue Alias-Member in der Funktion `get_warn_alias` zurück.

Das kannst du in derselben Enum-Klasse `LogLevel` machen, die bereits am Anfang der Datei definiert ist. Beide LogLevel sollten auf denselben Wert zeigen: `"WRN"`.

```python
get_warn_alias()
#=> LogLevel.Warn

get_warn_alias() == LogLevel.Warning
#=> True
```

## 5. Alle Member-Namen und -Werte

Definiere die Funktion `get_members()`.

Diese Funktion sollte eine Liste von Tupeln `(name, value)` zurückgeben, die alle Member des Enums `LogLevel` enthält.

```python
get_members()
#=> [('Trace', 'TRC'), ('Debug', 'DBG'), ('Info', 'INF'), ('Warning', 'WRN'),
# ('Error', 'ERR'), ('Fatal', 'FTL'), ('Unknown', 'UKN')]
```
