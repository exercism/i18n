## Formatierung

Common Lisp ist zwar gleichgültig, wie Code eingerückt und angeordnet ist und ob du Leerzeichen oder Tabs verwendest, doch für Einsendungen bei Exercism ist das wichtig.
Das Code-Widget von Exercism.org kommt mit einer Mischung aus Tabs und Leerzeichen nicht gut zurecht. Verwende deshalb am besten nur Leerzeichen, damit der Code für die menschlichen Reviewer besser lesbar ist.
Schau in den Einstellungen deines Editors nach, wie du das erreichst.
Unten findest du Anleitungen für gängige Editoren für Common Lisp.

### VIM

Mit den folgenden Befehlen stellst du sicher, dass VIM nur Leerzeichen zum Einrücken verwendet:

```vimscript
:set tabstop=2
:set shiftwidth=2
:set expandtab
```

(oder als Einzeiler `:set tabstop=2 shiftwidth=2 expandtab`). Du kannst das in deine `~/.vimrc`-Datei aufnehmen, damit es immer gilt.

### Emacs

Emacs eignet sich hervorragend zum Bearbeiten von Common Lisp und bietet viele leistungsstarke Zusatzpakete. Das Einzige, was du mit einem Standard-Emacs tun musst, damit er gut mit exercism.org funktioniert, ist, den folgenden Code auszuwerten:

`(setq-default indent-tabs-mode nil)`

Du kannst ihn in deine `~/.emacs` (oder `~/.emacs.d/init.el`) aufnehmen, damit er bei jedem Start von Emacs gesetzt ist.

Ein empfohlenes Zusatzpaket für Emacs und Common Lisp ist
[SLIME][slime], das eine enge Integration
mit dem REPL bietet und iteratives Codieren und Testen sehr einfach macht.
