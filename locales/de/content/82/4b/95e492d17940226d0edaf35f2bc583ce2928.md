# Anleitung

Mika, die Veranstaltungsorganisatorin, wurde bei der Arbeit befördert, und im Rahmen ihrer neuen Aufgaben ist sie jetzt für die Veranstaltungsdatenbank zuständig. Ihr ist schnell aufgefallen, dass viele Daten so gespeichert sind, dass man nur schwer damit arbeiten kann. Deshalb tut ihr euch zusammen, um die Daten mit einem einmaligen Skript aufzuräumen.

Da das Skript nur ein einziges Mal ausgeführt wird und du dir bei der Struktur der Daten sicher bist, findest du, dass dies eine gute Gelegenheit ist, Gleams _let assertions_ einzusetzen.

## 1. Fehler extrahieren

Jede vergangene Veranstaltung hat eine Liste von Problemen, die während der Veranstaltung aufgetreten sind. Diese wurden als Results gespeichert, sind aber immer die `Error`-Variante.

Implementiere die Funktion `extract_error`, die ein Result entgegennimmt, das immer ein `Error` sein soll, und den darin enthaltenen Fehlerwert zurückgibt.

```gleam
extract_error(Error("Not enough coffee"))
// -> "Not enough coffee"
```

## 2. Team-Präfix entfernen

Teamnamen wurde das Wort „Team “ vorangestellt, aber das ist nicht nötig. Implementiere die Funktion `remove_team_prefix`, um das Präfix aus einem Teamnamen zu entfernen.

```gleam
remove_team_prefix("Team Turtle")
// -> "Turtle"
```

## 3. Region und Team aufteilen

Jede Veranstaltung wird von einem Team durchgeführt, und jedes Team gehört zu einer Region. In der Datenbank werden beide in einem einzigen String gespeichert, getrennt durch ein Komma.

Implementiere die Funktion `split_region_and_team`, um den String in ein Tupel aus zwei Strings aufzuteilen, einen für die Region und einen für das Team. Das Präfix „Team “ sollte aus dem Teamnamen entfernt werden.

```gleam
split_region_and_team("East,Team Orange")
// -> #("East", "Orange")
```
