# Einleitung

In C# werden Datenstrukturen, die null oder mehr Elemente enthalten können, als _Sammlungen_ bezeichnet. Ein **Array** ist eine Sammlung mit einer festen Größe/Länge, deren Elemente alle vom selben Typ sein müssen. Elemente können einem Array über einen Index zugewiesen oder daraus abgerufen werden. C#-Arrays sind nullbasiert, das heißt, der Index des ersten Elements ist immer null:

```csharp
// Declare array with explicit size (size is 2)
int[] twoInts = new int[2];

// Assign second element by index
twoInts[1] = 8;

// Retrieve the second element by index
twoInts[1] == 8; // => true
```

Arrays können auch mit einer Kurzschreibweise definiert werden, mit der du sowohl das Array erstellen als auch seinen Wert festlegen kannst. Da der Compiler nun erkennen kann, wie viele Elemente das Array haben wird, kann die Länge weggelassen werden:

```csharp
// Three equivalent ways to declare and initialize an array (size is 3)
int[] threeIntsV1 = new int[] { 4, 9, 7 };
int[] threeIntsV2 = new[] { 4, 9, 7 };
int[] threeIntsV3 = { 4, 9, 7 };
```

Arrays lassen sich verändern, indem du entweder auf die Methoden oder Eigenschaften einer Array-Instanz zugreifst oder die statischen Methoden verwendest, die in der `Array`-Klasse definiert sind.
