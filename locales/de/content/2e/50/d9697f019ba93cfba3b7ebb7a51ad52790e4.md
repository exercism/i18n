# Einführung

In F# wird das Zuweisen eines Werts zu einem Namen als _Bindung_ bezeichnet. Bindungen sind unveränderlich, was sie Konstanten in anderen Sprachen ähnlich macht. Da F# eine statisch typisierte Sprache ist, hat jede Bindung zur Kompilierzeit einen Typ.

Bindungen werden mit dem Schlüsselwort `let` definiert. Die Angabe des Typs einer Bindung ist für die meisten Bindungen optional, da die _Typinferenz_ von F# den Typ normalerweise anhand ihres Werts ableiten kann. Eine Bindung sieht so aus:

```fsharp
// Automatically inferred type
let fingers = 10
```

Funktionen sind ebenfalls reguläre Bindungen, allerdings mit einem oder mehreren Parametern. Eine Funktion gibt automatisch ihren letzten Ausdruck zurück. Die Typinferenz funktioniert auch für die meisten Funktionen, indem sie analysiert, mit welchen Werten die Funktion aufgerufen wird und welchen Wert die Funktion zurückgibt.

```fsharp
// Automatically inferred types for parameters and return type
let add x y = x + y
```

Eine Funktion wird aufgerufen, indem man ihren Namen angibt und für jeden Parameter der Funktion ein Argument übergibt.

```fsharp
let five = add 2 3
```

Wenn der Typ einer Bindung nicht abgeleitet werden kann, meldet der Compiler einen Fehler. Um das zu beheben, füge der Bindung eine explizite Typannotation hinzu.

```fsharp
// Explicit type annotation
let fingers: int = 10

// Explicit type annotation (also for parameters)
let add (x: int) (y: int): int = x + y
```

Bindungen in F# können erst _nach_ ihrer Definition verwendet werden. Wird eine Bindung verwendet, bevor sie definiert wurde, führt das zu einem Kompilierfehler.

```fsharp
// Compile error as the add binding has not yet been defined
// let seven = add 3 4

let add x y = x + y
```

F# verwendet signifikanten Leerraum, um den Gültigkeitsbereich festzulegen. Das bedeutet, dass der Gültigkeitsbereich durch Einrücken des Codes mit Leerzeichen relativ zu der Zeile definiert wird, die die Bindung deklariert. Standardmäßig werden vier Leerzeichen zur Einrückung verwendet:

```fsharp
let toes =
    let left = 5
    let right = 5
    left + right

let multiplyPlusTwo x y =
    let product = x * y
    product + 2

// Trying to access the left, right or product bindings
// here would result in a compile error
```

F#-Bindungen (einschließlich Funktionen) sind üblicherweise in Modulen organisiert. Ein Modul gruppiert zusammengehörige Funktionalität und wird mit dem Schlüsselwort `module` definiert. Die Moduldefinition muss vor ihren Bindungen stehen:

```fsharp
module Calculator

let pi = 3.14

let add x y = x + y
```

F# unterstützt zwei Arten von Kommentaren. Einzeilige Kommentare beginnen mit `//` und mehrzeilige Kommentare werden zwischen `(*` und `*)` eingefügt.
