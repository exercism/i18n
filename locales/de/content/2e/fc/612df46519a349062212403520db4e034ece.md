# Einführung

## Erklärung

Neben primitiven Datentypen wie `number` und `string` gibt es in JavaScript einen weiteren wichtigen Datentyp namens `object`.
Objekte sind Sammlungen von Schlüssel-Wert-Paaren.
Als solche können sie als das verwendet werden, was in anderen Sprachen oft Maps oder Wörterbücher genannt wird.

In anderen Sprachen müssen oft alle Werte in einer Map denselben Datentyp haben.
In JavaScript ist nur der Typ des Schlüssels eingeschränkt: Er muss ein String sein.
Die Werte innerhalb eines Objekts können unterschiedliche Typen haben.
Sie können primitive Typen wie Zahlen, aber auch Arrays, andere Objekte oder sogar Funktionen sein.
Das macht Objekte sehr vielseitig, sodass sie auch zentrale Bausteine für die [objektorientierte Programmierung][oop] (OOP) in JavaScript sind.

Im Folgenden konzentrieren wir uns auf Objekte als Sammlungen oder Maps. Andere Anwendungsfälle von Objekten werden in anderen Konzepten behandelt, siehe z. B. [Klassen][concept-classes].

## Ein Objekt erstellen

Du erstellst ein Objekt mit geschweiften Klammern.
Du kannst auch direkt einige Einträge hinzufügen.
Dazu gibst du zuerst den Schlüssel an, gefolgt von einem Doppelpunkt und dem Wert.

```javascript
const emptyObject = {};

const obj = {
  favoriteNumber: 42,
  greeting: 'Hello World',
  useGreeting: true,
  address: {
    street: 'Trincomalee Highway',
    city: 'Batticaloa',
  },
  fruits: ['melon', 'papaya'],
  addNumbers: function (a, b) {
    return a + b;
  },
};
```

Das abschließende Komma nach dem letzten Eintrag ist in JavaScript optional.

Du fragst dich vielleicht, warum die Schlüssel nicht in Anführungszeichen gesetzt sind, obwohl sie Strings sein sollen.
Das ist eine Kurzschreibweise.
Wenn der Schlüssel den Namensregeln für einen JavaScript-[Bezeichner][mdn-identifier] folgt, kannst du die Anführungszeichen weglassen.
Bei Schlüsseln mit Sonderzeichen im Namen musst du die übliche String-Notation verwenden.

```javascript
const obj = {
  '1keyStartsWithNumber': '...',
  'key/with/slashes': '...',
  'key-with-dashes': '...',
  'key with spaces': '...',
  '#&()[]{}èä樹keyWithSpecialChars': '...',
};
```

## Einen Wert abrufen

Es gibt zwei Möglichkeiten, den Wert für einen bestimmten Schlüssel abzurufen: die Punktnotation und die Notation mit eckigen Klammern.

```javascript
const obj = { greeting: 'hello world' };

obj.greeting;
// => hello world

obj['greeting'];
// => hello world

// Bracket notation also works with variables.
const key = 'greeting';
obj[key];
// => hello world
```

Die Punktnotation als Kurzschreibweise hat dieselbe Einschränkung wie das Weglassen der Anführungszeichen.
Sie funktioniert nur, wenn der Schlüssel den Namensregeln für Bezeichner folgt.
Mit anderen Worten: Wenn dein Schlüssel kein einzelnes Wort ist, das nur aus Buchstaben besteht, musst du die Notation mit eckigen Klammern verwenden.

## Einen Wert hinzufügen oder ändern

Du kannst einen Wert mit dem Zuweisungsoperator `=` hinzufügen oder ändern.
Auch hier gibt es die Punktnotation und die Notation mit eckigen Klammern.

```javascript
const obj = { greeting: 'hello world' };

obj.greeting = 'Hi there!';
obj['greeting'] = 'Welcome.';

obj.newKey1 = 'new value 1';
obj['new key 2'] = 'new value 2';

const key = 'new key 3';
obj[key] = 'new value 3';
```

## Einen Eintrag löschen

Du kannst ein Schlüssel-Wert-Paar mit dem `delete`-Schlüsselwort aus einem Objekt löschen.

```javascript
const obj = {
  key1: 'value1',
  key2: 'value2',
};

delete obj.key1;
delete obj['key2'];
```

## Prüfen, ob ein Schlüssel existiert

Du kannst mit der Methode `hasOwnProperty` prüfen, ob ein bestimmter Schlüssel in einem Objekt existiert.

```javascript
const obj = { greeting: 'hello world' };

obj.hasOwnProperty('greeting');
// => true

obj.hasOwnProperty('age');
// => false
```

## Ein Objekt durchlaufen

Es gibt eine spezielle `for...in`-Schleife, um über alle Schlüssel eines Objekts zu iterieren.

```javascript
const obj = {
  name: 'Ali',
  age: 65,
};

for (let key in obj) {
  console.log(key, obj[key]);
}
// name Ali
// age 65
```

Um subtile Fehler zu vermeiden, solltest du immer davon ausgehen, dass die `for...in`-Schleife die Schlüssel in beliebiger Reihenfolge durchläuft.
Beachte auch, dass `for...in` [geerbte Schlüssel][concept-inheritance] in die Iteration einbezieht.
