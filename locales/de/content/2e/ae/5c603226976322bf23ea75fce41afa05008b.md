# Ergänzung zur Anleitung

## Hinweise

Du musst die Funktionen `decode` und `encode` implementieren, die einen `String` mit einer Atbash-Chiffre dekodieren und kodieren.
Wenn du dir bei den Typen unsicher bist, kannst du die vorgegebene Signatur verwenden, aber lass dich davon nicht in deiner Kreativität einschränken.

Diese Übung arbeitet mit Textdaten. Aus historischen Gründen ist der
`String`-Typ von Haskell gleichbedeutend mit `[Char]`, einer Liste von Zeichen. Für den
effizienteren Umgang mit Textdaten kannst du den `Text`-Typ verwenden.

Als optionale Erweiterung dieser Übung kannst du

- dich über [String-Typen](https://haskell-lang.org/tutorial/string-types) in
  Haskell informieren.
- `- text` zu deiner Liste der Abhängigkeiten in package.yaml hinzufügen.
- `Data.Text` auf [die folgende
  Weise](https://hackernoon.com/4-steps-to-a-better-imports-list-in-haskell-43a3d868273c) importieren:

```haskell
import qualified Data.Text as T
import           Data.Text (Text)
```

- den `Text`-Typ verwenden, z. B. `decode :: Text -> Text`, und
  `Data.Text`-Kombinatoren als z. B. `T.pack` ansprechen.
- die Dokumentation zu
  [`Data.Text`](https://hackage.haskell.org/package/text/docs/Data-Text.html) nachschlagen.
- alle Vorkommen von `String` in Atbash.hs durch `Text` ersetzen, d. h.:

```haskell
decode :: Text -> Text
decode cipherText = ...

encode :: Text -> Text
encode plainText = ...
```

Dieser Teil ist völlig optional.
