# Anleitung

In dieser Übung schreibst du Code, um eine Liste von Programmiersprachen zu verwalten, die du auf Exercism lernen möchtest.

Du hast sechs Aufgaben, bei denen es jedes Mal um Listen geht.

## 1. Erstelle eine neue Liste

Um die Sprachen zu verwalten, die du lernen möchtest, brauchst du eine neue Liste. Definiere die Funktion `new_list`, die eine neue, leere Liste zurückgibt.

```gleam
new_list()
// -> []
```

## 2. Definiere eine vorhandene Liste

Aktuell hast du einen Zettel, auf dem die Sprachen stehen, die du lernen möchtest: Gleam, Go und TypeScript. Definiere die Funktion `existing_list`, die diese Liste zurückgibt.

```gleam
existing_list()
// -> ["Gleam", "Go", "TypeScript"]
```

## 3. Füge eine neue Sprache zu einer Liste hinzu

Wenn du Exercism erkundest und weitere interessante Sprachen findest, möchtest du sie zu deiner Liste hinzufügen. Implementiere die Funktion `add_language`, die eine neue Sprache am Anfang deiner Liste einfügt.

```gleam
add_language(["OCaml", "Elixir"], "Scheme")
// -> ["Scheme", "OCaml", "Elixir"]
```

## 4. Zähle die Sprachen in der Liste

Die Sprachen einzeln zu zählen ist umständlich. Implementiere die Funktion `count_languages`, die die Anzahl der Sprachen in deiner Liste zählt.

```gleam
count_languages(["jq", "Elm", "Rust", "Kotlin"])
// -> 4
```

## 5. Kehre die Liste um

Irgendwann fällt dir auf, dass deine Liste tatsächlich in umgekehrter Reihenfolge ist! Implementiere die Funktion `reverse_list`, die deine Liste umkehrt.

```gleam
reverse_list(["Python", "Julia", "Idris", "COBOL"])
// -> ["COBOL", "Idris", "Julia", "Python"]
```

## 6. Prüfe, ob die Liste spannend ist

Du liebst zwar alle Sprachen, aber Gleam hat einen besonderen Platz in deinem Herzen. Deshalb bist du von einer Liste von Sprachen besonders begeistert, wenn:

- Gleam an erster Stelle der Liste steht.
- der zweite Eintrag der Liste Gleam ist und die Liste entweder zwei oder drei Sprachen enthält.

Implementiere die Funktion `exciting_list`, die prüft, ob eine Liste von Sprachen spannend ist:

```gleam
exciting_list(["Lua", "Gleam"])
// -> True
```
