# Ausnahmen

```sather
   raise "Unknown prop: " + prop;
```

```sather
   protect
      ...
   when $STR then
      #OUT + exception.str;
   end;
```

## raise

`raise` nimmt ein beliebiges Objekt entgegen. Eine `STR` auszulösen ist der einfache Fall, und genau das verwendet diese Übung. Eine eigene Klasse transportiert mehr (welcher prop, wie viele gewünscht waren); dafür musst du sie irgendwo definieren.

Eine Ausnahme wandert durch die Aufrufer nach außen, bis ein `protect` sie abfängt. Fängt keiner sie ab, bleibt das Programm stehen und gibt sie aus.

Sather hält nicht fest, welche Ausnahmen eine Routine auslösen kann, und zwingt die Aufrufer nicht, sie zu behandeln. Am Typ einer Routine steht nichts, das besagt, dass sie fehlschlagen kann.

## protect

```sather
   protect
      body
   when $STR then
      ...
   when SOME_CLASS then
      ...
   end;
```

Die Zweige werden der Reihe nach durchprobiert, und der erste, dessen Typ zum ausgelösten Wert passt, wird ausgeführt. `exception` ist dieser Wert und liegt nur im Gültigkeitsbereich eines Zweigs.

Ein `protect` ohne passenden Zweig fängt nichts ab: Die Ausnahme wandert weiter nach außen, als wäre das `protect` gar nicht da.

## Wo abfangen

Fang dort ab, wo man tatsächlich etwas tun kann. Wenn ein `protect` eine Ausnahme verschluckt und mit einem ausgedachten Wert weitermacht, wird aus einem lauten Fehler eine leise falsche Antwort, und das ist schlimmer.

```sather
   -- almost always wrong
   protect
      return risky;
   when $STR then
      return 0;
   end;
```

## Ausnahmen oder Verträge?

Beide drehen sich um Dinge, die schiefgehen, gelten aber für gegensätzliche Fälle.

Eine **Ausnahme** ist für etwas, das wirklich passieren kann und das der Aufrufer vernünftigerweise nicht hätte verhindern können: ein fehlender prop in der Tabelle, eine Datei, die nicht da ist.

Ein **Vertrag**, um den es in der nächsten Übung geht, ist für etwas, das nie passieren darf (ein Aufrufer übergibt ein negatives Gewicht), und er besagt, dass der Aufrufer einen Bug hat. Verträge werden nur geprüft, wenn man es verlangt, und ein verletzter Vertrag stoppt das Programm, statt etwas Abfangbares auszulösen.

Grob gesagt: Wenn ein sorgfältiger Aufrufer trotzdem darauf stoßen könnte, löse aus. Wenn ein Verstoß bedeutet, dass der Aufrufer falsch liegt, schreib es in einen Vertrag.
