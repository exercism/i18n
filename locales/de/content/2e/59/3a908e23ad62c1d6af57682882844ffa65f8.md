# Einführung

Der `readonly`-Modifikator verhindert zwar, dass der Wert oder die Referenz in einem Feld überschrieben wird, doch die Member eines Referenztyps schützt er nicht.

```csharp
readonly List<int> ints = new List<int>();

void Foo()
{
    ints.Add(1);    // ok
    ints = new List<int>(); // fails to compile
}
```

Damit alle Member eines Referenztyps geschützt sind, kannst du die Felder als `readonly` deklarieren und automatische Eigenschaften ohne `set`-Accessor definieren.

Die Base Class Library (BCL) bietet einige schreibgeschützte Varianten von Collections, wenn verhindert werden soll, dass Member einer Collection aktualisiert werden. Diese gibt es in Form von Wrappern:

- `ReadOnlyDictionary<T>` stellt ein `Dictionary<T>` als schreibgeschützt bereit.
- `ReadOnlyCollection<T>` stellt ein `List<T>` als schreibgeschützt bereit.
