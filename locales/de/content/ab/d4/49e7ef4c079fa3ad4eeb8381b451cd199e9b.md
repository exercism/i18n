# Anleitung

Als angehende Magierin muss Elyse einige Grundlagen üben.
Sie hat einen Stapel Karten, den sie bearbeiten möchte.

Um es etwas einfacher zu machen, verwendet sie nur die Karten 1 bis 10, sodass ihr Kartenstapel durch einen Vektor aus Zahlen dargestellt werden kann.
Die Position einer bestimmten Karte entspricht dem Index im Vektor.

## 1. Eine Karte aus einem Stapel entnehmen

Um eine Karte auszuwählen, gib die Karte am Index `position` aus dem gegebenen Stapel zurück.

```julia-repl
julia> stack = [1, 2, 4, 1];
julia> position = 3;
julia> get_item(stack, position)
4
```

## 2. Eine Karte im Stapel austauschen

Führe ein paar Fingerfertigkeiten aus und tausche die Karte am Index `position` gegen die angegebene Ersatzkarte aus.
Gib den angepassten Stapel zurück.

```julia-repl
julia> stack = [1, 2, 4, 1];
julia> position = 3;
julia> replacement_card = 6;
julia> set_item!(stack, position, replacement_card)
[1, 2, 6, 1]
```

## 3. Eine Karte oben auf den Stapel legen

Lass eine Karte erscheinen, indem du eine neue Karte oben auf den Stapel legst.
Gib den angepassten Stapel zurück.

```julia-repl
julia> stack = [5, 9, 7, 1];
julia> new_card = 8;
julia> insert_item_at_top!(stack, new_card)
[5, 9, 7, 1, 8]
```

## 4. Eine Karte aus dem Stapel entfernen

Lass eine Karte verschwinden, indem du die Karte an der angegebenen `position` aus dem Stapel entfernst.
Gib den angepassten Stapel zurück.

```julia-repl
julia> stack = [3, 2, 6, 4, 8];
julia> position = 3;
julia> remove_item!(stack, position)
[3, 2, 4, 8]
```

## 5. Die oberste Karte aus dem Stapel entfernen

Lass eine Karte verschwinden, indem du die oberste Karte des Stapels entfernst.
Gib den angepassten Stapel zurück.

```julia-repl
julia> stack = [3, 2, 6, 4, 8];
julia> remove_item_from_top!(stack)
[3, 2, 6, 4]
```

## 6. Eine Karte unten an den Stapel legen

Lass eine Karte erscheinen, indem du eine neue Karte unten an den Stapel legst.
Gib den angepassten Stapel zurück.

```julia-repl
julia> stack = [5, 9, 7, 1];
julia> new_card = 8;
julia> insert_item_at_bottom!(stack, new_card)
[8, 5, 9, 7, 1]
```

## 7. Eine Karte von unten aus dem Stapel entfernen

Lass eine Karte verschwinden, indem du die unterste Karte des Stapels entfernst.
Gib den angepassten Stapel zurück.

```julia-repl
julia> stack = [8, 5, 9, 7, 1];
julia> remove_item_at_bottom!(stack)
[5, 9, 7, 1]
```

## 8. Die Größe des Stapels prüfen

Prüfe, ob die Größe des Stapels gleich `stack_size` ist oder nicht.

```julia-repl
julia> stack = [3, 2, 6, 4, 8];
julia> stack_size = 4;
julia> check_size_of_stack(stack, stack_size)
false
```
