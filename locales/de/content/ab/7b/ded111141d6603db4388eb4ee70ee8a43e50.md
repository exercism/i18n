# Anweisungen

Es ist Nachtschicht am Kai von Hull. Der Frachter
*Olwen* liegt längsseits vertäut, und eine Crew aus Hafenarbeitern
arbeitet das Manifest parallel ab. Jede Kiste muss gewogen
werden, bevor sie an Bord geht, und der Hafenmeister führt eine
einzige laufende **Tonnagebilanz**, die jeder Hub aktualisiert.
Der Haken daran: Es gibt nur einen einzigen Kai-Kran, deshalb
kann die Bilanz nicht dadurch zerrissen werden, dass zwei
Hafenarbeiter sie gleichzeitig aktualisieren.

Jede Kiste ist ein Array aus den Gewichten ihrer Gegenstände.
Das Gewicht einer Kiste ist die Summe dieser Gegenstände.

## 1. Eine Kiste wiegen

Definiere `weigh-crate` so, dass es eine Kiste entgegennimmt und
ihr Gesamtgewicht zurückgibt. Das ist einfache sequenzielle
Arbeit: eine Kiste rein, eine Zahl raus.

```factor
{ 12 8 15 } weigh-crate .
! => 35
```

## 2. Das ganze Manifest parallel wiegen

Definiere `weigh-all` so, dass es ein Array von Kisten
entgegennimmt und das Array ihrer Gewichte in derselben
Reihenfolge zurückgibt. Verwende `parallel-map`, damit die
Arbeit an den einzelnen Kisten gleichzeitig abläuft.

```factor
{ { 5 5 } { 10 } { 3 4 5 } } weigh-all .
! => { 10 10 12 }
```

## 3. Einen frischen Kran bauen

Definiere `<crane>`, um einen neuen Kran zu konstruieren: ein
Tupel mit einem frischen `<lock>` und einer Tonnage von `0`. Der
Kran ist die gemeinsame Ressource, die die nachfolgenden Aufgaben
schützen werden.

```factor
<crane> tonnage>> .
! => 0
```

## 4. Eine Kiste auf die laufende Bilanz hieven

Definiere `hoist-crate` so, dass es ein `weight` und einen
`crane` entgegennimmt und das Gewicht **unter der Sperre des
Krans** zur Tonnage des Krans hinzufügt, sodass der Ablauf aus
Lesen, Addieren und Schreiben atomar gegenüber anderen
Hafenarbeitern ist, die gleichzeitig hieven.

```factor
<crane>
35 over hoist-crate
17 over hoist-crate
tonnage>> .
! => 52
```

## 5. Die laufende Tonnage auslesen

Definiere `crane-tonnage` so, dass es die aktuelle Tonnage des
Krans zurückgibt, ebenfalls unter der Sperre, damit das Auslesen
keinen zerrissenen Wert mitten im Hieven sieht.

```factor
<crane>
35 over hoist-crate
crane-tonnage .
! => 35
```

## 6. Die Fracht laden

Definiere `load-cargo` so, dass es ein Array von Kisten und einen
Kran entgegennimmt und **für jede Kiste einen
Hafenarbeiter-Thread startet**, der die Kiste wiegt und das
Gewicht auf den Kran hievt. Das Wort kehrt erst zurück, wenn
jeder Hafenarbeiter fertig ist. Verwende `<promise>` und
`?promise`, um das Zusammenführen der Threads zu koordinieren.

```factor
<crane> :> crane
{ { 5 5 } { 10 } { 3 4 5 } } crane load-cargo
crane crane-tonnage .
! => 32
```
