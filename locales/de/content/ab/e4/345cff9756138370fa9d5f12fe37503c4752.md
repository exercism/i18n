# Ergänzende Anweisungen

## Trackspezifische Anweisungen

Für etwas Abwechslung kannst du auch eine Lösung mit einer `unfold`-Funktion ausprobieren. Mit `foldLeft/Right` bist du vermutlich schon vertraut: Du „map“st eine ganze Collection in etwas anderes (meist etwas, das keine Collection ist). `unfold` ist die umgekehrte Operation: Du „map“st etwas (meist etwas, das keine Collection ist) in eine Collection. Das `unfold`en ist also eine logische Ergänzung und Teil des Standardrepertoires der funktionalen Programmierung.

Diese Übung lässt sich als Fall fürs `unfold`en sehen: ein `Int` in einen `String` „map“en (der natürlich implizit ein `Seq[Char]` ist).

Scalas Collections bieten es seit 2.13, zum Beispiel [`List.unfold`][list] und `Iterator.unfold`.
Es nimmt einen Startzustand und eine Funktion, die das nächste Element und den nächsten Zustand zurückgibt, oder `None`, um aufzuhören:

```scala
List.unfold(1234)(n => Option.when(n > 0)((n % 10, n / 10)))
// List(4, 3, 2, 1)
```

[list]: https://www.scala-lang.org/api/current/scala/collection/immutable/List$.html
