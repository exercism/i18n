# Beschreibung

Die klassische Einführungsübung.
Sag einfach „Hello, World!“.

„Hello, World!“ ist das traditionelle erste Programm, wenn man in einer neuen Sprache oder Umgebung mit dem Programmieren anfängt.

Die Ziele sind einfach:

- Ändere den vorgegebenen Code so, dass er den String „Hello, World!“ ausgibt.
- Führe die Test-Suite aus und stelle sicher, dass sie erfolgreich läuft.
- Reiche deine Lösung ein und schau sie dir auf der Website an.

Wenn alles gut geht, kannst du deine erste echte Übung abholen.
