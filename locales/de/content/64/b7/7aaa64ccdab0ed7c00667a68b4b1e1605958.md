# Einführung

## Zufall

In Elixir verwenden wir `Enum.random`, um ein zufälliges Element aus einer aufzählbaren Datenstruktur (z. B. Liste, Range) auszuwählen. Diese Funktion wählt ein einzelnes Element aus, wobei jedes Element mit gleicher Wahrscheinlichkeit gewählt wird.

Elixir hat keine eigenen Funktionen, um eine zufällige Gleitkommazahl auszuwählen. Dafür müssen wir direkt Erlang verwenden.

## Erlang-Bibliotheken

Elixir-Code läuft in der virtuellen Maschine BEAM. BEAM ist Teil des Erlang Run-Time Systems. Elixir wurde von Erlang inspiriert und teilt dessen Laufzeitumgebung, daher bietet Elixir eine hervorragende Interoperabilität mit Erlang-Bibliotheken. Das bedeutet, dass Elixir-Entwickler Erlang-Bibliotheken direkt in ihrem Elixir-Code verwenden können. In der Elixir-Community wird sogar davon abgeraten, Elixir-Bibliotheken für Funktionalität zu schreiben, die Erlang-Bibliotheken bereits bereitstellen.

Daher ist bestimmte Funktionalität, wie mathematische Operationen oder Timer-Funktionen, in Elixir nur über Erlang verfügbar.

Erlangs Standardbibliothek steht in unserem Elixir-Code ohne zusätzliche Schritte zur Verfügung.

Erlang-Funktionen lassen sich genauso aufrufen wie Elixir-Funktionen, mit einem kleinen Unterschied. Erlang-Modulnamen sind Atome in `snake_case`. Um zum Beispiel die Erlang-Funktion `pi/0` aus dem `math`-Modul aufzurufen, schreibst du:

```elixir
:math.pi()
# => 3.141592653589793
```

Die am häufigsten verwendeten Erlang-Funktionen, die kein Äquivalent in Elixir haben, sind:

- `:timer.sleep/1`, die einen Prozess für die angegebene Anzahl von Millisekunden anhält.
- `:rand.uniform/0`, die eine zufällige Gleitkommazahl `x` erzeugt, wobei `0.0 <= x < 1.0` gilt.
- `:io_lib.format/2`, die eine Formatierung im C-Stil (mit Steuersequenzen) bietet. Mit dieser Funktion könnten wir zum Beispiel eine Ganzzahl in jeder Basis zwischen 2 und 36 ausgeben oder eine Gleitkommazahl mit der gewünschten Genauigkeit formatieren. Beachte, dass diese Funktion, wie viele Erlang-Funktionen, eine Charlist zurückgibt.
- Das `math`-Modul, das mathematische Funktionen wie `sin/1`, `cos/1`, `log2/1`, `log10/1`, `pow/2` und mehr bietet.

Um die Standardbibliothek von Erlang zu entdecken, schau dir das [STDLIB-Referenzhandbuch][erl-stdlib-ref] an.

[erl-stdlib-ref]: https://www.erlang.org/doc/apps/stdlib/index.html
