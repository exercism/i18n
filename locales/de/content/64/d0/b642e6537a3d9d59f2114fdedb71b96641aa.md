# Ergänzung zur Anleitung

## Ausgabeformat

Gib die Proteinsequenz als nullterminierten String aus, mit einem Zeilenumbruch nach jedem Protein.

Eine Beispielausgabe wäre `"Methionine\nPhenylalanine\nSerine\n"`

Wenn die Eingabe ungültig ist, gib einen leeren String aus.

## Register

| Register | Verwendung   | Typ      | Beschreibung                           |
| -------- | ------------ | -------- | -------------------------------------- |
| `$a0`    | Eingabe      | Adresse  | nullterminierter Eingabe-String        |
| `$a1`    | Ein-/Ausgabe | Adresse  | nullterminierter Ausgabe-String        |
| `$t0-9`  | temporär     | beliebig | wird als temporärer Speicher verwendet |
