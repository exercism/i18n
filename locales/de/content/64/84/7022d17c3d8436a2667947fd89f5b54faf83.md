# Abstrakte Klassen

Eine Zirkusvorstellung ist eine Liste von Nummern. Jonglage, Trapez und Bodenturnen sind
verschiedene Dinge mit ganz unterschiedlichem Innenleben, aber wer die Programmfolge
zusammenstellt, braucht von jeder nur zwei Dinge: wie sie heißt und wie lange sie
dauert.

Eine **abstrakte Klasse** beschreibt genau das und nicht mehr.

```sather
abstract class $ACT is
   name : STR;
   minutes : INT;
end; -- abstract class $ACT
```

Ihr Name beginnt mit `$`. Sie listet Routinen ohne Rumpf auf: nur Signaturen, jede endet
mit dem Semikolon. Aus ihr lässt sich nichts erzeugen, es gibt kein `create` und kein
`new`.

## Konformität

Eine echte Klasse verspricht, ein `$ACT` zu sein, indem sie ihn hinter `<` schreibt:

```sather
class JUGGLING < $ACT is

   create : SAME is return new; end;

   name : STR is return "Juggling"; end;

   minutes : INT is return 5; end;

end; -- class JUGGLING
```

`<` liest man als „ist ein“. Die Klasse muss jede Routine bereitstellen, die die
abstrakte Klasse auflistet, mit denselben Argumenten und demselben Rückgabetyp. Lässt du
eine weg, ist das ein Compilerfehler und keine Überraschung zur Laufzeit.

Eine Klasse darf zusätzlich einbauen, was immer sie möchte. `TRAPEZE` kann eine Höhe
haben, die keine andere Nummer hat; die abstrakte Klasse weiß davon nichts und kümmert
sich nicht darum.

## Den Typ verwenden

`$ACT` ist ein Typ, also lässt sich damit alles deklarieren:

```sather
   acts : ARRAY{$ACT} := |#JUGGLING, #TRAPEZE(4), #TUMBLING|;
```

Dieses Array enthält auf einmal Objekte aus drei verschiedenen Klassen, was ein
`ARRAY{JUGGLING}` nicht könnte.

## Dispatch

```sather
   loop
      total := total + acts.elt!.minutes;
   end;
```

`acts.elt!` ist ein `$ACT`. Welches `minutes` läuft, entscheidet sich, wenn die Zeile
läuft, danach, was das Objekt tatsächlich ist: `JUGGLING::minutes` für die Jonglage,
`TRAPEZE::minutes` für das Trapez. Diese Auswahl heißt **Dispatch**.

Die Routine, die addiert, fragt nie, welche Art von Nummer sie vor sich hat. Eine vierte
Art von Nummer hinzuzufügen heißt, eine neue Klasse zu schreiben und sonst nichts zu
ändern. Genau das ist der Grund, es so zu machen.
