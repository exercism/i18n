# Ergänzung der Anweisungen

## Implementierung

Definiere eine einzelne Go-Funktion, `Cost`, die die Kosten für eine gegebene Liste von Büchern anhand der definierten Rabatte berechnet.

Verwende die folgende Signatur für die Funktion `Cost`:

```go
func Cost(books []int) int
```

`Cost` gibt die Gesamtkosten (nach Rabatten) in Cent zurück.
Ein einzelnes Buch kostet zum Beispiel 800 Cent, also 8,00 $.
Für diese Übung sind nur Berechnungen mit Ganzzahlen nötig.
