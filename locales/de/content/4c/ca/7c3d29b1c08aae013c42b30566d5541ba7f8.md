# Über

[Conses][hyper-conses] sind ein grundlegender Datentyp in Common Lisp. Sie bestehen aus einem Kopf und einem Rest (aus [historischen Gründen][history] `car` und `cdr` genannt).
Für die Datentypen von Kopf und Rest eines Cons gibt es keine Einschränkung.

Conses werden mit der Funktion [`cons`][hyper-cons] erzeugt, die zwei Objekte entgegennimmt und zu einem Cons auswertet (manchmal auch als „Cons-Zelle“ bezeichnet).

Auf die Teile eines Cons greifst du mit den Funktionen [`car`][hyper-car] und [`cdr`][hyper-cdr] zu.

## Referenz

```lisp
;; Testing for atoms
(atom 'foo)              ; => T
(atom '(bar baz))        ; => NIL

;; Testing for cons
(consp 'foo)             ; => NIL
(consp '(bar baz))       ; => T

;; First item of a cons
(car '(one two three))   ; => ONE
(first '(one two three)) ; => ONE

;; Rest of a cons
(cdr '(one two three))   ; => (TWO THREE)
(rest '(one two three))  ; => (TWO THREE)
```
