# Anleitung

Du hast gerade angefangen, am Empfang einer Kletterhalle zu arbeiten.
Mitglieder kaufen Mitgliedschaften für eine bestimmte Anzahl Monate und melden sich bei jedem Besuch an und wieder ab.
Die Leitung hat dich gebeten, einen Helfer zu schreiben, der die Fragen beantwortet, die Mitglieder am häufigsten stellen.

## 1. Berechne, wann eine Mitgliedschaft endet

Eine Mitgliedschaft, die an einem bestimmten Datum beginnt, endet am selben Tag des Monats, und zwar die angegebene Anzahl Monate später.
Gibt es diesen Tag im Endmonat nicht, endet die Mitgliedschaft stattdessen am letzten Tag dieses Monats.

Implementiere die Methode `FrontDesk.membershipEnd()`, die das Startdatum einer Mitgliedschaft und ihre Anzahl Monate entgegennimmt und das Datum zurückgibt, an dem sie endet:

```java
FrontDesk frontDesk = new FrontDesk();
frontDesk.membershipEnd(LocalDate.of(2024, 3, 10), 1);
// => LocalDate.of(2024, 4, 10)
frontDesk.membershipEnd(LocalDate.of(2025, 1, 31), 1);
// => LocalDate.of(2025, 2, 28)
```

## 2. Zeige, wie lange eine Mitgliedschaft dauert

Auf der Mitgliedskarte gibt die Kletterhalle an, wie lange die Mitgliedschaft in Jahren, Monaten und Tagen dauert.

Implementiere die Methode `FrontDesk.membershipLength()`, die das Start- und das Enddatum einer Mitgliedschaft entgegennimmt und die Dauer der Mitgliedschaft als `Period` zurückgibt:

```java
FrontDesk frontDesk = new FrontDesk();
frontDesk.membershipLength(LocalDate.of(2023, 3, 10), LocalDate.of(2024, 5, 25));
// => Period.of(1, 2, 15)
```

## 3. Zähle die verbleibenden Tage einer Mitgliedschaft

Mitglieder fragen oft, wie viele Tage ihnen bleiben, bis ihre Mitgliedschaft endet.

Implementiere die Methode `FrontDesk.daysLeft()`, die das heutige Datum und das Enddatum einer Mitgliedschaft entgegennimmt und die Gesamtzahl der Tage von heute bis zum Enddatum zurückgibt.
Liegt das Enddatum heute oder ist es bereits vorbei, bleiben keine Tage übrig, und die Methode gibt `0` zurück:

```java
FrontDesk frontDesk = new FrontDesk();
frontDesk.daysLeft(LocalDate.of(2024, 1, 15), LocalDate.of(2024, 3, 20));
// => 65
frontDesk.daysLeft(LocalDate.of(2024, 4, 2), LocalDate.of(2024, 3, 20));
// => 0
```

## 4. Miss einen Besuch

Die Kletterhalle ist rund um die Uhr geöffnet, und das Drehkreuz erfasst Datum und Uhrzeit, zu denen sich ein Mitglied an- und wieder abmeldet.

Implementiere die Methode `FrontDesk.visitDuration()`, die die Anmelde- und die Abmeldezeit eines Besuchs entgegennimmt und zurückgibt, wie lange der Besuch als `Duration` gedauert hat:

```java
FrontDesk frontDesk = new FrontDesk();
frontDesk.visitDuration(LocalDateTime.of(2024, 3, 10, 23, 30), LocalDateTime.of(2024, 3, 11, 1, 15));
// => Duration.ofMinutes(105)
```

## 5. Drucke einen Besuch auf den Kassenbon

Der Kassenbon zeigt die Dauer eines Besuchs in Stunden und Minuten an, etwa `1h 35m`.
Die Minuten werden immer zweistellig geschrieben, Sekunden werden weggelassen, und die Stunden sind nicht auf einen einzigen Tag beschränkt.

Implementiere die Methode `FrontDesk.formatVisit()`, die die Dauer eines Besuchs entgegennimmt und sie in diesem Format zurückgibt:

```java
FrontDesk frontDesk = new FrontDesk();
frontDesk.formatVisit(Duration.ofMinutes(95));
// => "1h 35m"
frontDesk.formatVisit(Duration.ofHours(2).plusMinutes(5));
// => "2h 05m"
frontDesk.formatVisit(Duration.ofHours(26).plusMinutes(10));
// => "26h 10m"
```
