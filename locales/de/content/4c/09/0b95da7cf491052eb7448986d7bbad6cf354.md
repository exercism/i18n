# Anleitung

Ein Partyroboter hängt Wimpelketten für die große Feier auf. Jede
Wimpelkette ist eine waagerechte Reihe aus `n` kleinen Fähnchen, und
das Zeichen jedes Fähnchens hängt davon ab, wo es in der Reihe sitzt,
gezählt von links beginnend bei `0`. Hilf dem Roboter, die folgenden
Muster zusammenzusetzen.

## 1. Alphabet-Wimpelkette

Definiere `alphabet-bunting`, das eine nicht-negative Ganzzahl `n`
vom Stack nimmt und einen String aus den ersten `n` Kleinbuchstaben
des Alphabets zurückgibt.

```factor
5 alphabet-bunting .
! => "abcde"

0 alphabet-bunting .
! => ""
```

Du kannst davon ausgehen, dass `n` höchstens `26` ist.

## 2. Zähl-Wimpelkette

Definiere `counting-bunting`, das `n` nimmt und einen String aus `n`
Ziffern zurückgibt, wobei das Fähnchen an Position `i` `i mod 10`
zeigt.

```factor
12 counting-bunting .
! => "012345678901"
```

## 3. Streifen-Wimpelkette

Definiere `stripe-bunting`, das zwischen zwei Zeichen abwechselt:
gerade Positionen bekommen `*` und ungerade Positionen bekommen `-`.

```factor
6 stripe-bunting .
! => "*-*-*-"

1 stripe-bunting .
! => "*"
```

## 4. Marker-Wimpelkette

Jedes fünfte Fähnchen ist ein besonderer Marker. Definiere
`marker-bunting` so, dass die Positionen `0`, `5`, `10`, … `|`
bekommen und alle übrigen `.`.

```factor
11 marker-bunting .
! => "|....|....|"
```

## 5. Tal-Wimpelkette

Der Roboter hängt eine Wimpelkette mit fester Größe von 10 Fähnchen
auf, die in der Mitte an einem Haken befestigt wird. Gezählt vom
linken Fähnchen an Position `-5` bis (aber ohne) `5` ist das Zeichen
jedes Fähnchens der Abstand zur Mitte, geschrieben als Ziffer.

Definiere `valley-bunting` (ohne Eingabewerte), das diesen festen
String zurückgibt.

```factor
valley-bunting .
! => "5432101234"
```
