# Einführung

Manchmal brauchst du beim Durchgehen einer Sequenz die *Position* eines Elements zusammen mit dem Element selbst. Die `*-index`-Familie in [`sequences`][sequences] übergibt beides an die Quotation, die pro Element ausgeführt wird. `times` ist der nahe Verwandte für die schlichte gezählte Iteration, nützlich, wenn du nur einen Zähler brauchst und keine Sequenz.

## `each-index` und `map-index` – Index in der Quotation

```
each-index ( seq quot: ( elt index -- )       -- )
map-index  ( seq quot: ( elt index -- newelt ) -- newseq )
```

Die Quotation erhält das Element unterhalb des Index – `index` liegt **oben** auf dem Stack:

```factor
USING: io kernel math.parser sequences ;

{ "alice" "bob" "carol" } [
    number>string ": " glue print
] each-index
! prints:
! alice: 0
! bob:   1
! carol: 2

{ 10 20 30 } [ + ] map-index .
! => { 10 21 32 }       (index added to each element)
```

`each-index` führt die Quotation wegen ihres Seiteneffekts aus und gibt nichts zurück. `map-index` sammelt die Ergebnisse pro Element in einer neuen Sequenz derselben Art wie die Eingabe.

## `times` – gezählte Iteration

`times` (aus [`math`][math]) führt seine Quotation `n`-mal aus.

```
times ( n quot: ( -- ) -- )
```

Die veröffentlichte Form `( -- )` ist das *Minimum* – weil `times` `inline` ist, funktioniert eine effekt-balancierte Quotation wie `( str -- str )` problemlos, und der Stack wird über die Iterationen hinweg durchgeschleift. Das gibt dir einen gezählten Akkumulator ganz ohne veränderlichen Zustand:

```factor
USING: kernel sequences ;

"" 3 [ "clop " append ] times .    ! => "clop clop clop "
```

Der Rumpf jeder Iteration sieht den laufenden String, hängt etwas daran an und lässt den neuen String für die nächste Iteration auf dem Stack. Derselbe Trick funktioniert auch für `each-index` und `map-index`, wenn du einen Akkumulator durchschleifen willst.
