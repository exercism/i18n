# SQLite-spezifische Hinweise

- Die Spalte **matrix** enthält die Eingabe, ein JSON-kodiertes Array aus Arrays von Ganzzahlen.
- Die Spalten **result** sollten die Ausgabe enthalten, die Liste der Sattelpunkte.
  Die Ausgabe sollte ein JSON-kodiertes Array von Objekten sein, wobei jedes Objekt zwei Schlüssel hat: row und column.
  Zum Beispiel `[{"row": 2, "column": 1}]`.
