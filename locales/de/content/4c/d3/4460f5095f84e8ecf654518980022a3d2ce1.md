# Einführung

Viele Programme brauchen (pseudo-)zufällige Werte, um Ereignisse aus der echten Welt zu simulieren.

Häufige, bekannte Beispiele sind:

- Ein Münzwurf: ein zufälliger Wert aus ('H', 'T').
- Ein Würfelwurf: eine zufällige Ganzzahl von 1 bis 6.
- Das Mischen eines Kartendecks: eine zufällige Reihenfolge einer Kartenliste.
- Das Erzeugen von Bäumen und Büschen in einer 3-D-Grafiksimulation.

Wirklich zufällige Werte mit einem Computer zu erzeugen, ist eine [überraschend schwierige technische Herausforderung][why-randomness-is-hard]. Deshalb gibt es auch „pseudozufällige“ Generatoren.

## Zufallszahlen erzeugen

In JavaScript kannst du pseudozufällige Zahlen mit der Funktion [`Math.random()`][Math.random] erzeugen.
Sie gibt eine pseudozufällige Gleitkommazahl zwischen 0 (inklusive) und 1 (exklusive) zurück.

Um eine zufällige Zahl zwischen _min_ (inklusive) und _max_ (exklusive) zu erhalten, kannst du eine Funktion wie diese verwenden:

```javascript
function getRandomInRange(min, max) {
  return min + Math.random() * (max - min);
}
getRandomInRange(4, 10);
// => 5.72
```

## Zufällige Ganzzahlen erzeugen

Um eine zufällige Ganzzahl zu erzeugen, kannst du `Math.floor()` oder `Math.ceil()` verwenden, um eine zufällig erzeugte Zahl in eine Ganzzahl umzuwandeln.
