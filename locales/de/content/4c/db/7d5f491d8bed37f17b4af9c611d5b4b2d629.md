# Einführung

## Sets

Ein Set ist eine unveränderliche und ungeordnete Sammlung eindeutiger Werte. Alle Elemente in einem Set müssen vom selben Typ sein.

Das Modul `gleam/set` definiert den Typ `Set` und stellt Funktionen für die Arbeit mit Sets bereit.

Du kannst Listen und Sets mit `set.to_list` und `set.from_list` ineinander umwandeln. Die Reihenfolge der Elemente in einem Set ist nicht garantiert.

```gleam
set.from_list([2, 3, 3, 3, 1, 1, 2])
// -> set.from_list([1, 2, 3])

set.to_list(set.from_list([2, 3, 3, 3, 1, 1, 2]))
// -> [1, 2, 3]
```

Du kannst Sets mit `set.new`, `set.insert` und `set.delete` erstellen und befüllen.

```gleam
set.new()
// -> set.from_list([])

let eighty_eight = set.from_list([88])

set.insert(eighty_eight, 88)
// -> set.from_list([88])

set.insert(eighty_eight, 89)
// -> set.from_list([88, 89])

set.delete(eighty_eight, 89)
// -> set.from_list([88])
```

Du kannst den Inhalt eines Sets mit den Funktionen `set.contains` und `set.size` abfragen.

```gleam
set.contains(eighty_eight, 88)
// -> True

set.size(eighty_eight)
// -> 1
```

Sets lassen sich mit `set.union` und `set.intersection` kombinieren.

```gleam
let a = set.from_list([1, 5, 10])
let b = set.from_list([1, 2, 3, 4, 5])

set.union(a, b)
// -> set.from_list([1, 2, 3, 4, 5, 10])

set.intersection(a, b)
// -> set.from_list([1, 5])
```

Du kannst Sets filtern.

```gleam
let is_small = fn(n) { n <= 3 }

set.filter(b, is_small)
// -> set.from_list([1, 2, 3])
```
