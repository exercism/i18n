# Verwende keine verschachtelten if-Anweisungen

Versuche, die if-Anweisungen so umzuschreiben, dass du tiefe Verschachtelungen vermeidest, denn sie können zu Code führen, der schwerer zu verfolgen ist. Schau dir die folgenden beiden Codebeispiele an:

```csharp
void PrintName(Person p)
{
    if (p != null)
    {
        if (p.Name != null)
        {
            if (p.Age >= 21)
            {
                Console.WriteLine(p.Name);
            }
        }
    }
}
```

Vergleiche das mit dem folgenden Code:

```csharp
void PrintName(Person p)
{
  if (p == null || p.Name == null || p.Age < 21)
  {
      return;
  }

  Console.WriteLine(p.Name);
}
```

Das zweite Beispiel folgt einem ganz bestimmten Aufbau: Alles, was Fehler behandelt, steht in eingerückten Blöcken, während der „Happy Path“ immer ganz links ausgerichtet bleibt. So lässt sich der Code sehr leicht lesen, denn man erkennt schnell, welcher Weg der häufigste und fehlerfreie Pfad durch den Code ist.
