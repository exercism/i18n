# Installation

Es gibt viele Wege, Zig zu installieren, und es werden stetig mehr, je weiter die Sprache reift.
Zum Glück sind alle gängigen Installationsmethoden auf der [Zig-Installationsseite][install-zig] aufgelistet.

## Zig-Version

Exercism verwendet Zig 0.17.0 (veröffentlicht am 2026-10-01).

Eine Übung kann mit einer anderen Zig-Version kompatibel sein, aber das ist nicht garantiert.
Zig hat noch nicht Version 1.0 erreicht, und Änderungen, die bestehenden Code brechen, sind häufig.

## Zusätzliche Tools

### Zig fmt – Gut formatierten Code erzeugen

Wenn du eine Übung löst, kannst du für deine Lösungen ganz verschiedene Code-Stile verwenden.
Außerhalb der Übungen allerdings, etwa wenn du Anwendungen oder Bibliotheken schreibst, ist es meist eine gute Idee, deinen Code einheitlich und lesbar zu halten.
Das ist besonders wichtig, wenn andere, die bei deinen Projekten mithelfen wollen, deinen Code lesen müssen.

Um dieses Problem zu lösen, bringt der Zig-Compiler einen leichtgewichtigen [Linter][linters] mit, der deinen Code bequem formatiert.
Dieser Code-Formatierer folgt dem [Styleguide][style-guide], der bereits in der [Zig-Dokumentation][documentation] festgehalten ist.

Um die Funktionen des nativen Formatierers von Zig zu sehen, verwende folgenden Befehl:

```bash
zig fmt --help
```

### Zig Zen – Regeln fürs Programmieren

Manchmal hilft eine kleine Orientierung bei jeder Aufgabe enorm, sogar beim Schreiben von Code.
Zum Glück ist im Zig-Compiler ein unterhaltsamer Befehl eingebaut, der uns an einige der Ziele erinnert, die hinter gutem Zig-Code stecken.

Um dir diese weisen Worte anzusehen, kannst du folgenden Befehl verwenden:

```bash
zig zen
```

### Der Zig Language Server – Umfassende Editor-Unterstützung für Zig

Diese Software von Drittanbietern bietet Editor-Vervollständigungen und verbesserte Navigationsfunktionen für Zig-Code, die dir helfen können, die Sprache schneller zu lernen.

Die neuesten Anweisungen findest du im [ZLS-Installationsleitfaden][install-zls].
