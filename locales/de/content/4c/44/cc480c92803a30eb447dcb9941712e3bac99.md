# Installation

Die Racket-Distribution kannst du von https://download.racket-lang.org herunterladen.

Installer gibt es für

* Windows
* Linux
* macOS

Weitere Anleitungen findest du auf der Seite [Getting Started](http://docs.racket-lang.org/getting-started/) von Racket.

Der [Racket Guide](https://docs.racket-lang.org/guide/intro.html) führt dich in die Arbeit mit Racket ein.

Wie du die DrRacket-IDE verwendest, erfährst du unter [DrRacket: The Racket Programming Environment](https://docs.racket-lang.org/drracket/index.html).

Eine Einführung in die Racket-Kommandozeilenwerkzeuge und in die Verwendung anderer Editoren findest du unter [Command-Line Tools and Your Editor of Choice](https://docs.racket-lang.org/guide/other-editors.html).


## Über den Linux-Installer:
Der Linux-Build ist so allgemein gehalten, dass er auf den meisten Distributionen funktionieren sollte, auch auf relativ alten.

Nachdem du die Installationsdatei heruntergeladen hast, führe sie so aus:
```
sh racket-8.10-x86_64-linux-cs.sh
```

Möglicherweise musst du dem Befehl `sudo` voranstellen, um an einen Ort zu installieren, der Administratorrechte erfordert.

**Warnung: Racket ist möglicherweise auch über den Paketmanager deiner Distribution verfügbar, allerdings kann diese Version älter als die aktuelle Racket-Version sein.**
Auch wenn du das später machen kannst: Als Lernender hast du eine viel bessere Erfahrung, wenn du bei der aktuellen Version bleibst, die unter https://download.racket-lang.org verfügbar ist.


## Über den macOS-Installer:

Wenn dein Rechner einen Prozessor der M1- oder M2-Reihe verwendet, wähle vor dem Herunterladen im Dropdown-Menü für die Plattform **Apple Silicon** aus.
