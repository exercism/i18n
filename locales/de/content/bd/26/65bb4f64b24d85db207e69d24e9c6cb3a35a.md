# Debug

Wenn ein Test fehlschlägt, wird eine Meldung angezeigt, die beschreibt, was schiefgelaufen ist und bei welcher Eingabe.
Du kannst beliebige Werte in deinem Programm untersuchen, indem du sie an die `debug`-Methode übergibst (verfügbar in `exercism/test_runner`).
Das erfasst die Werte und zeigt dir die Ausgabe.


```gleam
import exercism/test_runner.{ debug }

let value: String = "test"
debug("The value is " <> value)
```
