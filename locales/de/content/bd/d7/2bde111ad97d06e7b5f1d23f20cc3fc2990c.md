# Anleitung

`Two-fer` oder `2-fer` ist die Kurzform von „zwei für eins“.
Eins für dich und eins für mich.

Wenn ein Name übergeben wird, gib einen String mit der Nachricht zurück:

```text
One for name, one for me.
```

Dabei steht „name“ für den übergebenen Namen.

Wenn der Name jedoch fehlt, gib den String zurück:

```text
One for you, one for me.
```

Hier sind einige Beispiele:

|Name    |String to return
|:-------|:------------------
|Alice   |One for Alice, one for me.
|Bob     |One for Bob, one for me.
|        |One for you, one for me.
|Zaphod  |One for Zaphod, one for me.
