# Einführung

Eine [Liste][list] ist eine veränderbare Sammlung von Elementen in einer _Sequenz_.
 Sie sind eine extrem flexible und nützliche Datenstruktur, die viele `built-in`-Methoden und -Operationen in Python als Ausgabe erzeugen.
 Listen können Referenzen auf jeden (oder mehrere) Datentyp(en) enthalten, einschließlich anderer Listen oder Datenstrukturen wie [Tupel][tuples], [Mengen][sets] oder [Dictionaries][dicts].
 Du kannst mit dem Konstrukt `for item in <list>` über den Inhalt iterieren.
 Wenn du Indizes zusammen mit dem Inhalt brauchst, kannst du `for index, item in enumerate(<list>)` verwenden.
 Auf Elemente innerhalb einer `list` kannst du über eine `0-based index`-Nummer von links oder eine `-1-based index`-Nummer von rechts zugreifen.
 Du kannst Listen vollständig oder teilweise mit _Slice-Notation_ oder `<list>.copy()` kopieren.
