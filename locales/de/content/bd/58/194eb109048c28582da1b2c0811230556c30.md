# Einführung

Ein _String_ (Zeichenkette) ist der JavaScript-Datentyp zum Speichern von Textdaten.

## Eine Zeichenkette erstellen

Du erstellst eine Zeichenkette, indem du den Text in einfache oder doppelte Anführungszeichen setzt.
Bei Exercism verwendest du einfache Anführungszeichen.

<!-- prettier-ignore-start -->
```javascript
'Hello, World!'
"Hello, World!"
```
<!-- prettier-ignore-end -->

## Zeichenketten als Listen von Zeichen

Eine Zeichenkette kann als Liste von Zeichen behandelt werden, wobei das erste Zeichen den Index `0` hat.
Du kannst auf ein einzelnes Zeichen der Zeichenkette zugreifen, indem du eckige Klammern und den Index des Zeichens verwendest, das du abrufen möchtest.

```javascript
'cat'[1];
// => 'a'
```

Du kannst die Anzahl der Zeichen in einer Zeichenkette ermitteln, indem du auf die Eigenschaft `length` zugreifst.

```javascript
'cat'.length;
// => 3
```

## Verkettung und Methoden

Die einfachste Möglichkeit, Zeichenketten zu verketten, ist der Additionsoperator `+`.

```javascript
'I like' + ' ' + 'cats.';
// => "I like cats."
```

Zeichenketten bieten viele Hilfsmethoden. Eine vollständige Liste findest du in den [MDN-Dokumenten zu String-Methoden][mdn-string-methods].
Die folgende Liste zeigt einige häufig verwendete Hilfsmethoden.

- [`toUpperCase`][mdn-to-upper-case] und [`toLowerCase`][mdn-to-lower-case] – ändern die Groß- und Kleinschreibung aller Zeichen
- [`trim`][mdn-trim] – entfernt Leerzeichen am Anfang und Ende
- [`includes`][mdn-includes], [`startsWith`][mdn-starts-with] und [`endsWith`][mdn-ends-with] – stellen fest, ob eine andere Zeichenkette Teil der gegebenen Zeichenkette ist
- [`slice`][mdn-slice] – extrahiert einen Abschnitt der Zeichenkette

Zeichenketten sind in JavaScript unveränderlich. Eine „Änderung“, zum Beispiel durch eine der oben genannten Methoden, erzeugt also immer eine neue Zeichenkette.
