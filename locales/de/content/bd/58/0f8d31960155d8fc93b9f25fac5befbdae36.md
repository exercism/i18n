# Einführung

## Erste Schritte

### Variablen

Du kannst Werte speichern und ihnen einen Namen geben, indem du eine [Variable][constants-variables] definierst.
Nachdem du eine Variable definiert hast, kannst du ihren Namen verwenden, um im ganzen Code auf diesen Wert zu verweisen.
Variablen sind _veränderlich_, das heißt, ihre Werte können sich nach der Definition ändern.

Definiere eine Variable mit dem Schlüsselwort `var`:

```swift
var variableName = 10
```

Swift ist eine statisch typisierte Sprache. Das bedeutet, dass jeder Wert zur Kompilierzeit einen bekannten Typ hat.
Du kannst einen Typ explizit mit einer [Typannotation][type annotations] angeben, oder du lässt den Swift-Compiler den Typ aus dem zugewiesenen Wert [ableiten][type-inferring]:

```swift
var explicitVar: Int = 10 // Explicitly typed
var implicitVar = 10      // Implicitly typed (inferred as Int)
```

Du kannst den Wert einer Variablen mit dem Zuweisungsoperator (`=`) aktualisieren:

~~~~exercism/note
Der Typ einer Variablen kann nach der Deklaration nicht mehr geändert werden.

```swift
variableName = 13 // Allowed: same type (Int)

// Compiler error: cannot assign a different type
variableName = "Hello, world!" // Cannot assign value of type 'String' to type 'Int'
```
~~~~

Du kannst eine Variable ohne Anfangswert deklarieren, indem du ihren Typ angibst. Du musst ihr aber einen Wert zuweisen, bevor du sie verwendest:

```swift
var someInt: Int

// This triggers a compiler error:
// print(someInt) // Variable 'someInt' used before being initialized

// Assign a value first
someInt = 169
print(someInt) // Prints 169
```

### Konstanten

[Konstanten][constants-variables] verknüpfen ebenfalls einen Namen mit einem Wert, aber ihre Werte können nach der Zuweisung nicht geändert werden.
Sie sind _unveränderlich_.
Definiere eine Konstante mit dem Schlüsselwort `let`:

```swift
let constantName = 10          // Inferred constant
let explicitConstant: Int = 10 // Explicitly typed constant
```

### Rechenoperatoren

Swift bietet die üblichen [Rechenoperatoren][arithmetical-operators] für einfache Mathematik:

- Addition: `+`
- Subtraktion: `-`
- Multiplikation: `*`

```swift
print(1 + 1) // Prints 2
print(2 - 1) // Prints 1
print(2 * 2) // Prints 4
```

### Funktionen

In Swift sind [Funktionen][functions] eigenständige Blöcke aus Code, die eine bestimmte Aufgabe erfüllen.
Funktionen können Eingabewerte annehmen, einen Wert zurückgeben und wie Werte an andere Funktionen weitergegeben werden.
Definiere eine Funktion mit dem Schlüsselwort `func`, gefolgt vom Funktionsnamen, einer Parameterliste in runden Klammern und einem optionalen Rückgabetyp:

```swift
func functionName(argumentLabel parameterName: ParameterType) -> ReturnType {
    // Function body
}
```

Swift-Funktionen verwenden [Argumentlabels][argument-labels], wodurch sich der Code wie natürliche Sätze liest:

- Das **Argumentlabel** wird beim Aufruf der Funktion verwendet.
- Der **Parametername** wird im Funktionsrumpf verwendet, um auf den Wert zuzugreifen.

Wenn du nur einen Namen angibst, verwendet Swift ihn sowohl als Argumentlabel als auch als Parameternamen:

```swift
func greet(name: String) {
    print("Hello, \(name)!")
}

greet(name: "Alice")
```

Wenn du beim Aufruf der Funktion kein Argumentlabel möchtest, schreibst du einen Unterstrich (`_`) vor den Parameternamen:

```swift
func square(_ number: Int) -> Int {
    return number * number
}

square(5) // Called without an argument label
```

Alle Funktionsparameter sind standardmäßig Konstanten (`let`). Das bedeutet, dass ihre Werte im Funktionsrumpf nicht geändert werden können.

Um einen Wert aus einer Funktion zurückzugeben, gibst du den Rückgabetyp nach `->` an und verwendest das Schlüsselwort `return`:

```swift
func addTen(to value: Int) -> Int {
    return value + 10
}

addTen(to: 10) // Returns 20
```

Wenn eine Funktion keinen Wert zurückgibt, ist ihr Rückgabetyp `Void` (äquivalent zu einem leeren Tupel, `()`).
In solchen Funktionen kannst du sowohl den Rückgabetyp `-> Void` als auch die `return`-Anweisung weglassen.

### Kommentare

Swift unterstützt zwei Formen von [Kommentaren][comments]:

- **Einzeilige Kommentare** beginnen mit `//` und reichen bis zum Ende der Zeile.
- **Mehrzeilige Kommentare** stehen zwischen `/*` und `*/`.

```swift
// This is a single-line comment

/* This is a comment
   that spans multiple lines */
```
