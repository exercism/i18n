# Hinweise

## Allgemein

- Ein [Ganzzahlwert][integers] kann als eine oder mehrere aufeinanderfolgende Ziffern definiert werden.
- Wenn du beim Ausführen der Tests einen `panic`-Fehler siehst, liegt das daran, dass du eine der Funktionen noch nicht implementiert hast (es sollte dort stehen, welche) oder dass du den vorgegebenen Code unverändert gelassen hast.
  Du musst die Zeile `panic!(...)` aus dem vorgegebenen Code entfernen und durch eine echte Implementierung ersetzen.

## 1. Definiere die erwartete Backzeit in Minuten

- Du musst eine [Funktion][functions] ohne Parameter definieren.
- Du musst die erwartete Backzeit in Minuten aus der Funktion [zurückgeben][return].

## 2. Berechne die verbleibende Backzeit in Minuten

- Du musst eine [Funktion][functions] mit einem einzigen Parameter definieren.
- Der Parameter der Funktion ist eine [Ganzzahl][integers].
- Du musst aus einer Funktion [explizit eine Ganzzahl zurückgeben][return].
- Du kannst eine der anderen Funktionen, die du vorher definiert hast, [aufrufen][functions].
- Du kannst den [mathematischen Operator für Subtraktion][operators] verwenden, um Werte zu subtrahieren.

## 3. Berechne die Vorbereitungszeit in Minuten

- Du musst eine [Funktion][functions] mit einem einzigen Parameter definieren.
- Der Parameter der Funktion ist eine [Ganzzahl][integers].
- Du musst aus einer Funktion [explizit eine Ganzzahl zurückgeben][return].
- Du kannst den [mathematischen Operator für Multiplikation][operators] verwenden, um Werte zu multiplizieren.

## 4. Berechne die verstrichene Arbeitszeit in Minuten

- Du musst eine [Funktion][functions] mit zwei Parametern definieren.
- Der Parameter der Funktion ist eine [Ganzzahl][integers].
- Du musst aus einer Funktion [explizit eine Ganzzahl zurückgeben][return].
- Du kannst eine der anderen Funktionen, die du vorher definiert hast, [aufrufen][functions].
- Du kannst den [mathematischen Operator für Addition][operators] verwenden, um Werte zu addieren.
