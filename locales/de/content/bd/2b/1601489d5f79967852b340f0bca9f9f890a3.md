# Einführung

Der Typ `Result` ermöglicht es einer Funktion, einen einzelnen Wert zurückzugeben, der alle folgenden Dinge angibt:

- Ob die Operation erfolgreich war oder fehlgeschlagen ist
- Bei Erfolg den resultierenden Wert der Operation
- Bei einem Fehler den Grund für den Fehler

## Verwendung

`Result` ist ein generischer Typ, der zwei zugrunde liegende Typen enthält:

- Den Typ des resultierenden Werts bei einer erfolgreichen Operation
- Den Typ, der bei einem Fehler den Grund für den Fehler repräsentiert

Der Typ `Result` ist außerdem eine [diskriminierte Union][discriminated-union] mit den folgenden möglichen Fällen:

- `Ok <value>` steht für ein erfolgreiches Ergebnis
- `Error <reason>` steht für einen Fehler

Die folgende Funktion zeigt, wie du einen `Result`-Wert erstellst:

```fsharp
let validateName (name: string) : Result<string, string> =
    match name with
    | null -> Error "Name not found."
    | "" -> Error "Name is empty."
    | _ -> Ok name
```

In diesem Beispiel ist der `Ok`-Wert ein String (der angegebene Name), und der `Error`-Wert ist ebenfalls ein String (die Ursache des Fehlers in für Menschen lesbarer Form).

## Den Inhalt eines `Result`-Werts lesen

Betrachte die folgende Typdefinition und Funktionssignatur:

```
type FileOpenError =
| NotFound
| AccessDenied
| FileLocked

let openFile (filename: string) : Result<int, FileOpenError> =
```

Code, der die Funktion `openFile` aufruft, kann Musterabgleich verwenden, um den Erfolgs- und den Fehlerfall zu behandeln, wie im folgenden Beispiel:

```fsharp
match openFile(filename) with
| Ok handle -> doSomethingWithFile(handle)
| Error NotFound -> printfn $"Error: file {filename} was not found."
| Error AccessDenied -> printfn $"Error: you do not have permission to open the file {filename}."
| Error FileLocked -> printfn $"Error: file {filename} is already in use."
```

[discriminated-union]: https://learn.microsoft.com/en-us/dotnet/fsharp/language-reference/discriminated-unions
