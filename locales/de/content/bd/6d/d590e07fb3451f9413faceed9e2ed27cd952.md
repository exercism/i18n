# Über

## Vererbung

Java unterstützt Vererbung als Kernfunktionalität und nutzt sie, um viele OOP-Prinzipien wie Abstraktion umzusetzen.

Eine Klasse kann eine andere Klasse mit dem `extends`-Schlüsselwort erweitern und von einer Schnittstelle mit dem `implements`-Schlüsselwort erben.

## Zugriffsmodifikatoren

Die Zugriffsmodifikatoren legen Regeln für den Zugriff auf die Membervariablen und Methoden einer Klasse von anderen Klassen (oder von überall im Code) fest.

Es gibt vier Zugriffsmodifikatoren:

- `private`
- `public`
- `protected`
- Standard (kein Schlüsselwort erforderlich)

Mehr darüber kannst du [in diesem Artikel][access-modifiers] lesen.

## Vererbung vs. Komposition

Diese Konzepte sind sehr ähnlich und werden oft verwechselt.

- Vererbung bedeutet, dass die Kindklasse eine IST-EIN-Beziehung zur Elternklasse hat.

```java
interface Animal() {
    public void bark();
}

class Dog implements Animal {
    public void bark() {
        System.out.println("Bark");
    }
}
```

Hier ist `Dog` IST-EIN `Animal`.

- Komposition stellt eine HAT-EINE-Beziehung dar.

```java
interface Engine {

}

class Car {
    private Engine engine;
}
```

Hier ist `Car` HAT-EINE `Engine`.
