# Einführung

## Lebensdauer von Ressourcen

[concept:csharp/resource-cleanup]() verwendet die `IDispose`-Schnittstelle, um zu signalisieren, dass die Ressource eines Objekts oder ein anderer Programmzustand freigegeben oder zurückgesetzt werden muss, sobald das Objekt nicht mehr benötigt wird. Außerdem zeigt sie, dass man sich dabei nicht auf den Garbage Collector verlassen kann, weil dieser das entweder gar nicht erreicht oder nicht die nötige Kontrolle bietet. Die Methode `IDisposable.Dispose()` ist dann der natürliche Ort für solche Aufräumarbeiten.

Es gibt ein weiteres Konstrukt, den `using`-Block, mit dem sich aus Sicht des Aufrufers die gesamte Verwaltung der Lebensdauer von Ressourcen in einer einzigen Anweisung bündeln lässt.

```csharp
using (var file = new File("my_secrets"))
{
    file.WriteSecret("xxxxxxx");
}
```

Im obigen Beispiel werden die mit `file` verbundenen Dateisystemressourcen an das Betriebssystem zurückgegeben, sobald der `using`-Block verlassen wird.

Damit das Muster funktioniert, muss die Variable in der using-Anweisung ein Referenztyp sein, der die `IDisposable`-Schnittstelle implementiert und in seiner `Dispose()`-Methode Ressourcen freigibt beziehungsweise den Programmzustand zurücksetzt.

C# 8 führt eine Verfeinerung dieses Musters ein. Eine using-Anweisung kann an den Anfang eines Blocks gesetzt werden.

```csharp
using var drawingResource = some_provided_or_new_object;
try
{
    drawingResource.DrawSomething();
}
catch (Exception)
{
    throw;
}
```

Java-Entwickler erkennen darin vielleicht ein Analogon zur _automatischen Ressourcenverwaltung_, die in Java 7 eingeführt wurde.
