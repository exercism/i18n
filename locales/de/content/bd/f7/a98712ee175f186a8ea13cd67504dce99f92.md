# Einführung

## Namespaces

Namespaces sind eine Möglichkeit, zusammengehörigen Code zu gruppieren und Namenskonflikte zu vermeiden. In allen außer den trivialsten Codebasen sind sie eigentlich immer vorhanden.

Die Syntax sieht so aus:

```csharp
namespace MyNameSpace
{
    public class MyClass {}

    public class OtherClass {}
}
```

Auf Typen, die in Namespaces eingeschlossen sind, verweist man außerhalb des Gültigkeitsbereichs des Namespace, indem man dem Typnamen die Punkt-Syntax voranstellt. Alternativ, und meistens üblicher, kannst du eine `using`-Direktive an den Anfang der Datei (oder in einen Namespace) setzen, und dann lässt sich der Typ ohne das Präfix verwenden. Innerhalb desselben Namespace musst du Typnamen nicht qualifizieren.

```csharp
namespace MySpace
{
    public class MyClass {}

    public class Foo
    {
        public void Bar()
        {
            var baz = new MyClass();
        }
    }
}

public class Qux
{
    public void Box()
    {
        var nux = new MySpace.MyClass();
    }
}

namespace OtherSpace
{
    using MySpace;

    public class Tix
    {
        public void Jeg()
        {
            var lor = new MyClass();
        }
    }
}
```

Du kannst einen Namespace mit der Syntax `using MyAlias = MySpace;` mit einem Alias versehen und dann den Alias überall dort verwenden, wo der Namespace verwendet werden könnte.
