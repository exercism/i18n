# CLI

Du kannst die Tests ausführen, indem du eine Kommandozeile im Verzeichnis der Übung öffnest und dann den [`stack test`-Befehl][docs-stack-test] ausführst. Wenn dein Code kompiliert, zeigt dir dieser Befehl, welche Tests bestanden wurden und welche fehlgeschlagen sind. Wenn ein Test fehlschlägt, versuche ihn zum Bestehen zu bringen und führe die Tests erneut aus.

Sobald alle Tests bestehen, kannst du deine Lösung einreichen, indem du eine Kommandozeile im Verzeichnis der Übung öffnest und den [`exercism submit`-Befehl][docs-exercism-cli] ausführst.

[docs-stack-test]: https://docs.haskellstack.org/en/stable/build_command/
[docs-exercism-cli]: https://exercism.io/cli
