# Ergänzung zur Anleitung

## Baue deine eigene DSL

In dieser Übung kannst du die Graph-DSL deiner Träume völlig frei entwerfen.

Die Tests verlangen nur, dass du ein paar bestimmte Graphen erstellst. Wie du sie aufbaust, bleibt völlig dir überlassen.

Um den Spaß zu verdoppeln, kannst du optional versuchen, eine Funktion `to_dot` zu implementieren, die deinen Graphen ins DOT-Format umwandelt!

## Darstellung von Graphen

Definiere deine DSL in `Graph.roc` und nutze sie dann, um die Graphen zu konstruieren, die der Stub verlangt.
Die beiden Knoten-IDs in jedem `EdgeId` müssen alphabetisch sortiert sein.

| Definition | Aufzubauender Graph |
| --- | --- |
| `empty_graph` | Ein leerer Graph |
| `graph_with_one_node` | Ein Knoten |
| `graph_with_one_node_with_attribute` | Ein Knoten mit einem Attribut |
| `graph_with_one_edge` | Eine Kante |
| `graph_with_one_attribute` | Ein Graph-Attribut |
| `graph_with_nodes_edges_and_attributes` | Knoten, Kanten und Attribute |
| `multiple_edges_on_one_line` | Mehrere Kanten in einer Zeile |
| `only_1_edge_between_nodes` | Nur eine Kante zwischen jedem Knotenpaar |
