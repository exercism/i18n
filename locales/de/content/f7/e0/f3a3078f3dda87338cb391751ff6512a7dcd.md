# Anleitung

Du bist Lehrassistent und korrigierst die Prüfungen der Schüler.
Die Ergebnisse manuell zu verfolgen, wird mit der Zeit mühsam und fehleranfällig.
Du beschließt, die Sache etwas interessanter zu machen, indem du ein paar Funktionen schreibst, die die Ergebnisse für die Klasse zählen und berechnen.

## 1. Punkte runden

Auch wenn du bei Prüfungsfragen „Teilpunkte“ vergeben kannst, müssen die Gesamtpunkte der Prüfung `int`s sein.
Bevor du also irgendetwas anderes mit den Punkten der Klasse machen kannst, musst du die Noten durchgehen und alle `float`-Punkte in `int`s umwandeln.
Zum Glück hat Python die eingebaute Funktion [`round()`][round], die du verwenden kannst.

Erstelle die Funktion `round_scores(student_scores)`, die eine `list` von `student_scores` entgegennimmt.
Diese Funktion soll die Eingabe-`list` _konsumieren_ und eine neue Liste `return`en, die alle Punkte als `int`s enthält.
Die Reihenfolge der Punkte in der resultierenden `list` ist nicht wichtig.

```python
>>> student_scores = [90.33, 40.5, 55.44, 70.05, 30.55, 25.45, 80.45, 95.3, 38.7, 40.3]
>>> round_scores(student_scores)
...
[40, 39, 95, 80, 25, 31, 70, 55, 40, 90]
```

## 2. Nicht bestandene Schüler

Beim Korrigieren der Prüfung ist dir aufgefallen, dass einige Schüler nicht so gut abschnitten, wie du gehofft hattest.
Aber du warst abgelenkt und hast vergessen, genau zu notieren, _wie viele_ Schüler es waren.

Erstelle die Funktion `count_failed_students(student_scores)`, die eine `list` von `student_scores` entgegennimmt.
Diese Funktion soll die Anzahl der Schüler zählen, die keine bestandene Punktzahl haben, und diese Anzahl als Ganzzahl zurückgeben.
Ein Schüler braucht eine Punktzahl größer als **40**, um die Prüfung zu bestehen.

```python
>>> count_failed_students(student_scores=[90,40,55,70,30,25,80,95,38,40])
5
```

## 3. Die „Besten“

Die Lehrkraft, der du assistierst, möchte die Gruppe von Schülern finden, die bei dieser Prüfung am besten abgeschnitten haben.
Was als „am besten“ gilt, schwankt, also musst du die Punkte der Schüler finden, die **größer oder gleich** dem aktuellen Schwellenwert sind.

Erstelle die Funktion `above_threshold(student_scores, threshold)`, die `student_scores` (eine `list` mit Noten) und `threshold` (den Schwellenwert für die „Höchstpunktzahl“) als Parameter entgegennimmt.
Diese Funktion soll eine `list` mit allen Punkten zurückgeben, die `>=` dem Schwellenwert sind.

```python
>>> above_threshold(student_scores=[90,40,55,70,30,68,70,75,83,96], threshold=75)
[90,75,83,96]
```

## 4. Buchstabennoten berechnen

Die Lehrkraft, der du assistierst, möchte neben numerischen Punkten auch Buchstabennoten vergeben.
Da Schüler bei einer Prüfung selten 100 Punkte erreichen, werden die unteren Schwellenwerte für die Buchstabennoten auf Basis der höchsten erreichten Punktzahl berechnet. Sie steigen gleichmäßig zwischen der Höchstpunktzahl und der Schwelle zum Durchfallen von **<= 40** an.

Erstelle die Funktion `letter_grades(highest)`, die die „höchste“ Punktzahl der Prüfung als Argument entgegennimmt und eine `list` mit unteren Schwellenwerten für jedes „amerikanische“ Notenintervall zurückgibt: `["D", "C", "B", "A"]`.


```python
"""Where the highest score is 100, and failing is <= 40.
       "F" <= 40
 41 <= "D" <= 55
 56 <= "C" <= 70
 71 <= "B" <= 85
 86 <= "A" <= 100
"""

>>> letter_grades(highest=100)
[41, 56, 71, 86]


"""Where the highest score is 88, and failing is <= 40.
       "F" <= 40
 41 <= "D" <= 52
 53 <= "C" <= 64
 65 <= "B" <= 76
 77 <= "A" <= 88
"""

>>> letter_grades(highest=88)
[41, 53, 65, 77]
```

## 5. Namen den Punkten zuordnen

Du hast eine Liste mit Prüfungspunkten in absteigender Reihenfolge und eine weitere Liste mit Schülernamen, die ebenfalls absteigend nach ihren Prüfungspunkten sortiert ist.
Du möchtest jeden Schülernamen seinem Prüfungsergebnis zuordnen und eine Gesamtrangliste der Klasse ausgeben.

Erstelle die Funktion `student_ranking(student_scores, student_names)` mit den Parametern `student_scores` und `student_names`.
Ordne jeden Schülernamen in der student_names-`list` seinem Punktwert aus der student_scores-`list` zu.
Du kannst davon ausgehen, dass jede Argument-`list` vom höchsten zum niedrigsten Punktwert sortiert ist.
Die Funktion soll eine `list` mit Strings im Format `<rank>. <student name>: <student score>` zurückgeben.

```python
>>> student_scores = [100, 99, 90, 84, 66, 53, 47]
>>> student_names =  ['Joci', 'Sara','Kora','Jan','John','Bern', 'Fred']
>>> student_ranking(student_scores, student_names)
...
['1. Joci: 100', '2. Sara: 99', '3. Kora: 90', '4. Jan: 84', '5. John: 66', '6. Bern: 53', '7. Fred: 47']
```

## 6. Eine „perfekte“ Punktzahl

Auch wenn eine „perfekte“ Punktzahl von 100 bei einer Prüfung selten ist, ist es interessant zu wissen, ob mindestens ein Schüler sie erreicht hat.

Erstelle die Funktion `perfect_score(student_info)` mit dem Parameter `student_info`.
`student_info` ist eine `list` von Listen, die den Namen und die Punktzahl jedes Schülers enthalten: `[["Charles", 90], ["Tony", 80]]`.
Die Funktion soll _das erste_ `[<name>, <score>]`-Paar des Schülers `return`en, der 100 Punkte in der Prüfung erreicht hat.

Wenn in `student_info` keine 100 Punkte gefunden werden, soll eine leere Liste `[]` zurückgegeben werden.

```python
>>> perfect_score(student_info=[["Charles", 90], ["Tony", 80], ["Alex", 100]])
["Alex", 100]

>>> perfect_score(student_info=[["Charles", 90], ["Tony", 80]])
[]
```

[round]: https://docs.python.org/3/library/functions.html#round
