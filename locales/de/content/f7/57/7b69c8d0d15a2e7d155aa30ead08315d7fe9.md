# Anleitung

Du betreibst eine Online-Boutique für Mode. Jeder Artikel in deinem
Bestand ist ein Array mit zwei Elementen `{ name price }`, und der
ganze Bestand ist ein Array von Artikeln.

Ein fehlender Preis wird als `f` festgehalten.

## 1. Sortiere den Bestand nach dem Preis

Definiere `sort-by-price` so, dass es ein neues Array mit den nach dem
Preis aufsteigend sortierten Artikeln zurückgibt.

```factor
{ { "Maxi Brown Dress" 65 } { "Red Skirt" 50 } { "Bamboo Socks Cats" 20 } }
sort-by-price .
! => { { "Bamboo Socks Cats" 20 } { "Red Skirt" 50 } { "Maxi Brown Dress" 65 } }
```

## 2. Finde Artikel ohne festgelegten Preis

Definiere `with-missing-price` so, dass es ein Array zurückgibt, das
nur die Artikel enthält, deren Preis `f` ist.

```factor
{ { "Black T-shirt" 40 } { "Denim Pants" f } { "Orange T-shirt" 40 } }
with-missing-price .
! => { { "Denim Pants" f } }
```

## 3. Zähle die teuren Artikel

Definiere `expensive-items` so, dass es einen Bestand und einen
Preisschwellenwert entgegennimmt und zurückgibt, wie viele Artikel
strikt mehr als der Schwellenwert kosten.

```factor
{ { "Skirt" 50 } { "Coat" 120 } { "Hat" 25 } { "Dress" 80 } }
50 expensive-items .
! => 2

{ { "Skirt" 50 } { "Coat" 120 } { "Hat" 25 } { "Dress" 80 } }
0 expensive-items .
! => 4
```

## 4. Finde den günstigsten Artikel

Definiere `cheapest-item` so, dass es den Artikel mit dem niedrigsten
Preis zurückgibt. Artikel ohne Preis (`f`) kommen in der Eingabe nicht
vor.

```factor
{ { "Skirt" 50 } { "Coat" 120 } { "Hat" 25 } } cheapest-item .
! => { "Hat" 25 }
```

## 5. Summiere alle Preise

Definiere `total-price` so, dass es die Summe aller Preise zurückgibt.
Artikel ohne Preis (`f`) kommen in der Eingabe nicht vor.

```factor
{ { "Skirt" 50 } { "Coat" 120 } { "Hat" 25 } } total-price .
! => 195
```

## 6. Formatiere einen Artikel als Preisschild

Definiere `format-price-tag` so, dass es für einen Artikel einen String
der Form `"name: $price"` zurückgibt. Artikel ohne Preis (`f`) kommen
hier nicht vor.

```factor
{ "Skirt" 50 } format-price-tag .
! => "Skirt: $50"
```
