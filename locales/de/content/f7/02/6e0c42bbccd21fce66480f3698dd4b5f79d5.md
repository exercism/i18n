# Hinweise

## Allgemein

- Eine [Map][maps] ist eine assoziative Datenstruktur aus Schlüssel-Wert-Paaren.
- Elixir bietet [viele nützliche Funktionen des Map-Moduls in der Standardbibliothek][map-module].

## 1. Eine neue Highscore-Map definieren

- Sie sollte eine leere [Map][maps] zurückgeben.
- Funktionen des [Map-Moduls][map-module] oder Literalformen können hilfreich sein.

## 2. Spieler zur Highscore-Map hinzufügen

- Die resultierende Map sollte zurückgegeben werden.
- Das [Map-Modul][map-module] enthält Funktionen, mit denen du Maps bearbeiten kannst. [Eine davon][map-put] legt einen Wert unter einem gegebenen Schlüssel in einer Map ab.

## 3. Spieler aus der Highscore-Map entfernen

- Die resultierende Map sollte zurückgegeben werden.
- Das [Map-Modul][map-module] enthält Funktionen, mit denen du Maps bearbeiten kannst. [Eine davon][map-delete] löscht einen Schlüssel aus einer Map.

## 4. Den Punktestand eines Spielers zurücksetzen

- Die resultierende Map sollte zurückgegeben werden, wobei der Punktestand des Spielers auf einen Anfangswert zurückgesetzt ist.
- Das [Map-Modul][map-module] enthält Funktionen, mit denen du Maps bearbeiten kannst. [Eine davon][map-put] legt einen Wert unter einem gegebenen Schlüssel in einer Map ab.

## 5. Den Punktestand eines Spielers aktualisieren

- Die resultierende Map sollte mit dem aktualisierten Punktestand des Spielers zurückgegeben werden.
- Das [Map-Modul][map-module] enthält Funktionen, mit denen du Maps bearbeiten kannst. [Eine davon][map-update] aktualisiert einen Wert unter einem gegebenen Schlüssel in einer Map.

## 6. Eine Liste der Spieler abrufen

- Das [Map-Modul][map-module] enthält Funktionen, mit denen du Maps bearbeiten kannst. [Eine davon][map-keys] gibt eine Liste aller Schlüssel einer Map zurück.
