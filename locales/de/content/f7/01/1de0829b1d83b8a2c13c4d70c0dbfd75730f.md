# Introduction

## Rekursion

Die Fähigkeit, etwas durch sich selbst zu definieren, nennt man Rekursion. In F# begegnet dir Rekursion am häufigsten in rekursiven Funktionen, also Funktionen, die sich selbst aufrufen.

Eine rekursive Funktion braucht mindestens einen _Basisfall_ und mindestens einen _Rekursionsfall_. Ein _Basisfall_ gibt einen Wert zurück, ohne die Funktion erneut aufzurufen. Ein _Rekursionsfall_ ruft die Funktion erneut auf und verändert die Eingabe so, dass sie irgendwann zum Basisfall passt.

Rekursive Funktionen werden wie normale Funktionen definiert, aber mit dem `rec`-Schlüsselwort. Ohne dieses Schlüsselwort kann eine Funktion sich nicht selbst aufrufen, und jeder Versuch, das zu tun, führt zu einem Kompilierungsfehler. Rekursion muss also explizit aktiviert werden.

```fsharp
let rec factorial x =
    // Base case
    if x = 1 then
        1
    // Recursive case
    else
        x * factorial (x - 1)
```

F# unterstützt rekursive Typen auch über diskriminierte Unions. Ein rekursiver diskriminierter Union-Typ hat einen oder mehrere Fälle, die in ihren Daten auf den diskriminierten Union-Typ selbst verweisen. Wie rekursive Funktionen brauchen rekursive Typen einen Basisfall. Anders als rekursive Funktionen verwenden rekursive Typen nicht das `rec`-Schlüsselwort.

```fsharp
type RussianDoll =
    | Doll                 // Base case
    | Layer of RussianDoll // Recursive case
```
