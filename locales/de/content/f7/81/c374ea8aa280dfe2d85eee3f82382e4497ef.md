# Hinweise

## Allgemeines

- Lies in der [offiziellen Anleitung „Erste Schritte"][getting-started-streams] über Enumerables und Streams.
- Lies die offizielle Dokumentation zu [Streams][stream].

## 1. Führe einen Wurf mit einem 6-seitigen Würfel aus

- Ranges implementieren das _Enumerable-Protokoll_.
- Es gibt eine [eingebaute Funktion][enum-random], um einen zufälligen Wert aus einem Enumerable auszuwählen.

## 2. Würfle weiter, solange du Sechsen würfelst

- Es gibt eine [eingebaute Funktion][stream-repeatedly], die einen Stream erzeugt, indem sie eine Funktion wiederholt aufruft.
- Es gibt eine [eingebaute Funktion für Streams][stream-transform], die ähnlich funktioniert wie `Enum.reduce/3`.

## 3. Erlaube die Verwendung eines gezinkten Würfels

- Verwende den [Capture-Operator][special-forms-capture], um die Funktion `roll/0` zu erfassen.
