# Tests

Um die Tests auszuführen, folge diesen Schritten:

- Wechsle in das Verzeichnis der Übung (z. B. `~/Exercism/hello-world`).
- Starte eine `jconsole`-Sitzung (z. B. indem du `jconsole` oder `ijconsole` in einem Terminal eingibst).
- Lade deine Lösungsdatei (z. B. `load 'hello-world.ijs'`)
- Lade das Unit-Test-Framework, indem du `load  'general/unittest'` eingibst.
- Teste deine Lösung, indem du `unittest 'test.ijs'` eingibst.
<br></br>
- Alternativ kannst du die Tests auch in einer einzigen Zeile so ausführen: `jconsole -js "load 'hello-world.ijs'" "echo unittest 'test.ijs'" "exit 0"`.

## Übersprungene Tests

Zuerst ist nur der erste Test aktiviert.
Dieser Ansatz ermutigt dich, die Übung Schritt für Schritt zu lösen.
Jeder Test enthält ein Nomen über seiner Definition, dessen Name auf _'\_ignore'_ endet.
Um den Test auszuführen, ändere seinen Wert auf 0.

### Beispiel:

```
    leap_test_02_ignore=: 1 NB. Change this value to 0 to run this test
    test_leap_test_02  =: monad define
    ...                     NB. test definitions
    )
```
