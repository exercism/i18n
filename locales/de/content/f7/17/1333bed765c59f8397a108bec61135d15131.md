# Ergänzung zu den Anweisungen

## Trackspezifische Anweisungen

Folgendes solltest du über das Eingabeformat wissen:

- **Linkes Argument**: Das Diagramm, das die Anordnung des Gartens darstellt, angegeben als Tabelle von Zeichen mit `tally` gleich 2.
- **Rechtes Argument**: Der Name des Schülers, angegeben als String.

Deine Funktion wird mit diesen Argumenten so aufgerufen:

```j
  diagram=. 2 24$'VRCGVVRVCGGCCGVRGCVCGCGVVRCCCGCRRGVCGCRVVCVGCGCV'
  student=. 'Fred'
  
  diagram plants student
```
