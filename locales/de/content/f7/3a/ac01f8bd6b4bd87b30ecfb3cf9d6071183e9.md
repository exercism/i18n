# Einführung

Der [`enum`-Typ](https://docs.microsoft.com/en-us/dotnet/csharp/language-reference/builtin-types/enum) von C# repräsentiert eine feste Menge benannter Konstanten (eine Enumeration).

Normalerweise kann ein `enum`-Member nur auf genau eine dieser benannten Konstanten verweisen. Manchmal ist es jedoch nützlich, auf mehr als eine Konstante zu verweisen. Dazu kann man das `enum` mit dem [`Flags`-Attribut](https://docs.microsoft.com/en-us/dotnet/api/system.flagsattribute) versehen.

Ein Flags-Enum kann wie folgt definiert werden (unter Verwendung der binären Ganzzahlschreibweise `0b`):

```csharp
[Flags]
enum PhoneFeatures
{
    Call = 0b00000001,
    Text = 0b00000010
}
```

Eine `PhoneFeatures`-Instanz mit dem Wert `0b00000011` hat sowohl das `Call`- _als auch_ das `Text`-Flag gesetzt.

Standardmäßig wird der Typ `int` für die Werte der Enum-Member verwendet. Man kann einen anderen Ganzzahltyp verwenden, indem man den Typ in der Enum-Deklaration angibt:

```csharp
[Flags]
enum PhoneFeatures : byte
{
    Call = 0b00000001,
    Text = 0b00000010
}
```
