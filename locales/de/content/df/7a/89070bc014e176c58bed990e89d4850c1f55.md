# Anleitung

Du bist Lehrer.
Am Ende des Jahres hast du für jeden deiner Schüler eine Note als Zahl erzeugt.
Jetzt musst du diese in eine Buchstabennote umwandeln und zählen, wie viele Schüler jede Buchstabennote erreicht haben

## 1. Eine Note als Zahl in eine Buchstabennote umwandeln

Die Funktion `letter_grade` nimmt eine Note als Zahl entgegen und gibt den Buchstaben aus.
Verwende diese Bereiche:

| Buchstabe |         Note |
| :-------: | -----------: |
|     A     | 90% - 100%   |
|     B     |  80% - 89%   |
|     C     |  70% - 79%   |
|     D     |  60% - 69%   |
|     F     |   0% - 59%   |

Beispiel:

```jq
75 | letter_grade   # => "C"
```

## 2. Die Anzahl der Schüler für jede Buchstabennote zählen

Die Funktion `count_letter_grades` nimmt ein Objekt entgegen, das Schülernamen ihren Noten zuordnet.
Die Ausgabe ist ein Objekt, das jeder Buchstabennote die Anzahl der Schüler mit dieser Note zuordnet.

Beispiel:

```jq
{"Joe": 78, "Jane": 93, "Richard": 72} | count_letter_grades
# => {"A": 1, "B": 0, "C": 2, "D": 0, "F": 0}
```

Es gibt mehrere Möglichkeiten, das zu lösen.
Verwende zum Üben den `reduce`-Filter.
