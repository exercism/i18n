# Einführung

## Zahlen

In Python gibt es drei verschiedene Arten von eingebauten Zahlen: `ints`, `floats` und `complex`. In dieser Übung hast du es jedoch nur mit `ints` und `floats` zu tun.

### ints

`ints` sind ganze Zahlen, z. B. `1234`, `-10`, `20201278`.

Ganzzahlen haben in Python [beliebige Genauigkeit][arbitrary-precision]. Die Anzahl der Ziffern ist nur durch den verfügbaren Arbeitsspeicher des Hostsystems begrenzt.

### floats

`floats` sind Zahlen mit einem Dezimalpunkt, z. B. `0.0`, `3.14`, `-9.01`.

Gleitkommazahlen werden in Python normalerweise mit einem `double` in C implementiert (_15 Dezimalstellen Genauigkeit_), ihre Darstellung hängt aber vom Hostsystem und anderen Implementierungsdetails ab. Das kann beim Arbeiten mit Gleitkommazahlen für Überraschungen sorgen, ist aber für die meisten Situationen „gut genug“.

## Arithmetik

Python unterstützt Arithmetik zwischen `ints` und `floats` vollständig. Bei den binären Rechenoperatoren (`+`, `-`, `*`, `/`, `//` und `%`) wandelt es schmalere Zahlen so um, dass sie zu ihren breiteren Gegenstücken passen.

Python betrachtet `ints` als schmaler als `floats`. Wenn du also eine Gleitkommazahl in einem Ausdruck verwendest, ist das Ergebnis garantiert auch eine Gleitkommazahl. Bei der Division ist das Ergebnis jedoch immer eine Gleitkommazahl, selbst wenn nur Ganzzahlen verwendet werden.

```python
# The int is widened to a float here, and a float type is returned.
>>> 3 + 4.0
7.0
>>> 3 * 4.0
12.0
>>> 3 - 2.0
1.0
# Division always returns a float.
>>> 6 / 2
3.0
>>> 7 / 4
1.75
# Calculating remainders.
>>> 7 % 4
3
>>> 2 % 4
2
>>> 12.75 % 3
0.75
```

Wenn du ein ganzzahliges Ergebnis brauchst, kannst du mit `//` das Ergebnis abschneiden.

```python
>>> 6 // 2
3
>>> 7 // 4
1
```

Um eine Gleitkommazahl in eine Ganzzahl umzuwandeln, kannst du `int()` verwenden. Um eine Ganzzahl in eine Gleitkommazahl umzuwandeln, kannst du `float()` verwenden.

```python
>>> int(6 / 2)
3
>>> float(1 + 2)
3.0
```
