# Über

Der Common Lisp Printer ist die Einrichtung für die Ausgabe von Daten auf Streams. Eine häufig verwendete Funktion dieser Einrichtung ist `format`.

`format` nimmt zwei Pflichtparameter: einen Stream, in den geschrieben wird, und einen Steuerstring. Der Inhalt des Steuerstrings bestimmt, wie alle weiteren Argumente verwendet werden.

Der erste Parameter hat zwei besondere Werte: `t` und `nil`. `t` gibt an, dass der an `*standard-output*` gebundene Stream verwendet werden soll, und `nil` gibt an, dass ein String erzeugt und zurückgegeben werden soll. Außer wenn der Stream-Parameter `nil` ist, gibt `format` `nil` zurück.

Der Steuerstring kann Format-Direktiven enthalten, die durch eine `~` gefolgt von einem Zeichen gekennzeichnet werden (die Groß- oder Kleinschreibung des Zeichens spielt keine Rolle). Die Format-Direktive legt fest, ob Argumente verbraucht werden und wie sie auf den Stream formatiert werden.

Die wichtigsten grundlegenden Format-Direktiven sind:

* `~A` - _ästhetisch_ auf „menschenlesbare“ Weise formatieren.
* `~S` - im _Standard_ formatieren, um „maschinenlesbar“ zu sein.
* `~%` - einen Zeilenumbruch ausgeben
* `~&` - einen Zeilenumbruch ausgeben, außer wenn bereits am Zeilenanfang.
* `~~` - eine Tilde ausgeben.

Beispiele:

```lisp
(format nil "The list is: ~A~%" (list 1 2 3)) ; => "The list is: (1 2 3)
                                                   "
(format nil "(format t ~S)" "hello world")    ; => "(format t \"hello world\""
(format nil "~&fresh~&lines")                 ;=> "fresh
                                                   lines"
(format nil "directives start with a ~~")     ; => "directives start with a ~"
```
