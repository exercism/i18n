# Über

Kombinatoren verwandeln Muster zum Umschichten des Stacks in benannte, kombinierbare Wörter. Wenn du genug Factor geschrieben hast, hörst du auf zu denken „Ich muss `dup` aufrufen, dann F ausführen und das Original behalten“ und schreibst einfach `[ F ] keep`.

| Muster                             | Umordnungen                   | Kombinator      |
|------------------------------------|-------------------------------|-----------------|
| F anwenden, Eingabe erhalten       | `dup F swap`                  | `[ F ] keep`    |
| zwei Funktionen auf eine Eingabe   | `dup F swap G`                | `[ F ] [ G ] bi`|
| drei Funktionen auf eine Eingabe   | haarig                        | `[ F ] [ G ] [ H ] tri` |
| viele Funktionen auf eine Eingabe  | sehr haarig                   | `{ Fs … } cleave`|
| auf Werte *unter* dem obersten operieren | `swap F swap`           | `[ F ] dip`     |
| dieselbe Operation auf zwei Werte  | `swap F swap F`               | `[ F ] bi@`     |
| verschiedene Operationen auf zwei Werte | `swap F swap G`          | `[ F ] [ G ] bi*`|

Die Familie mit der Vorsilbe `2` (`2bi`, `2dip`, `2tri`, `2dup`, `2drop`, `2nip`, `2swap`) tut dasselbe, wenn jede Operation *zwei* Eingaben braucht; `3dup` und `4dup` erweitern das Duplizier-Idiom auf drei oder vier Werte oben auf dem Stack.

Über die cleave/dip/bi-Familie hinaus bietet [`kernel`][kernel] auch Varianten zur Ablaufsteuerung, die `f` sauber weiterreichen:

| Wort        | Wirkung                                             |
|-------------|-----------------------------------------------------|
| `if*`       | Der Wahr-Zweig sieht den Wert, der Falsch-Zweig nicht |
| `?last`     | letztes Element einer Sequenz oder `f`, wenn sie leer ist |
| `pop*`      | verwerfende Variante von `pop` (mutiert einen Vektor) |
| `dupd`      | das *zweite* von oben duplizieren                   |
| `pick`      | das *dritte* von oben nach oben kopieren            |
| `swapd`     | das zweite und dritte von oben vertauschen          |
| `rotd`      | die untersten drei eines vier Elemente tiefen Stacks rotieren |
| `tuck`      | das oberste unter das zweite von oben kopieren      |
| `with`      | einen festen Wert für HOS in eine Quotation einbauen |
| `while`     | Schleife, solange ein Prädikat gilt                 |
| `until`     | Schleife, bis ein Prädikat gilt                     |

Den richtigen Kombinator zu wählen, ist selbst eine Fähigkeit. Die allgemeine Regel: Sobald der Rumpf einer Definition mehr als ein Umordnungswort hintereinander enthält, gibt es meist einen Kombinator, der die Absicht besser ausdrückt.

[kernel]: https://docs.factorcode.org/content/vocab-kernel.html
