# Einführung

Zeichen und Strings bilden in Elm die Grundlage für die Textdarstellung.
Strings kann man sich als Listen von Zeichen vorstellen, und die meisten Funktionen aus `List` haben ihr Gegenstück im Modul `String`.

## Zeichen

Der Typ `Char` stellt ein einzelnes Unicode-Zeichen in einfachen Anführungszeichen dar, z. B. `'a'`. 
Das Modul `Char` bietet Prädikatfunktionen (`Char -> Bool`), mit denen du Eigenschaften eines Zeichens prüfen kannst: `isUpper`, `isLower`, `isAlpha` und `isAlphaNum`.
Außerdem bietet das Modul Funktionen, um ein Zeichen mit `toUpper`, `toLower`, `toLocaleUpper` und `toLocaleLower` umzuwandeln, sowie mit `toCode` und `fromCode` in seinen numerischen Unicode-Wert (`Int`) und wieder zurück.

## Strings

Der Typ `String` bietet eine eingebaute Darstellung für effiziente String-Manipulation und kann jede Folge von Unicode-Zeichen darstellen.
Strings werden in doppelten Anführungszeichen dargestellt: `"this is a string"`.
Mehrzeilige Strings werden mit dreifachen doppelten Anführungszeichen dargestellt und dürfen unmaskierte Anführungszeichen und Zeilenumbrüche enthalten.

```elm 
haiku = 
"""
    Code's strings entwine
    , In binary, thoughts combine
    , Logic's elegant line.
"""
```

## String-Manipulation

`reverse : String -> String` kehrt den String um.
```elm 
reverse "Hello world." 
    --> ".dlrow olleH"
```

`repeat : Int -> String -> String` wiederholt einen String n-mal.
```elm 
repeat 2 "Hello world." 
    --> "Hello world.Hello world."
```

`replace : String -> String -> String -> String` ersetzt alle Vorkommen eines gegebenen Teilstrings.
```elm
replace "Hello" "Goodbye cruel" "Hello world." 
    --> "Goodbye cruel world."
```

`append : String -> String -> String` hängt zwei Strings aneinander.
Der Operator `++` kann dafür ebenfalls verwendet werden.
```elm
append "butter" "fly" 
    --> "butterfly"
"butter" ++ "fly" 
    --> "butterfly"
```

`concat : List String -> String` fügt eine Liste von Strings zu einem einzigen String zusammen.
```elm
concat ["never", "the", "less"] 
    --> "nevertheless"
```

`split : String -> String -> List String` teilt einen String am angegebenen Trennzeichen in eine Liste von Strings auf.
```elm
split ";" "cat;dog;cow" 
    --> ["cat", "dog", "cow"]
```

`join : String -> List String -> String` fügt eine Liste von Strings mit einem gegebenen Trennzeichen zusammen.
```elm
join "a" ["H", "w", "ii", "n"] 
    --> "Hawaiian"
```

`words : String -> List String` zerlegt einen String in Strings, wobei es an Whitespace-Blöcken trennt.
```elm
words "How are \t you? \n Good?" 
    --> ["How", "are", "you?", "Good?"]
```

`lines : String -> List String` zerlegt einen String in Zeilen, wobei es an Zeilenumbrüchen trennt.
```elm
lines "How are you?\nGood?" 
    --> ["How are you?", "Good?"]
```

`cons : Char -> String -> String` fügt ein Zeichen am Anfang eines Strings hinzu.
```elm
cons 'T' "he truth is out there" 
    --> "The truth is out there"
```

`uncons : String -> Maybe ( Char, String )` zerlegt einen nicht leeren String in Kopf und Rest.
Damit kannst du beim Pattern Matching genau so mit Strings arbeiten wie mit Listen.
Leere Strings ergeben `Nothing`.
```elm
uncons "abc" 
    --> Just ('a', "bc")
uncons ""
    --> Nothing
```

## Teilstrings erhalten

`slice : Int -> Int -> String -> String` liefert einen Teilstring, wenn du Start- und Endindex angibst.
Negative Indizes werden vom Ende her gezählt.
```elm
slice 0 6 "snakes on a plane!" 
    --> "snakes"
slice 0 -7 "snakes on a plane!"
    --> "snakes on a"
```

`left : Int -> String -> String` und `right : Int -> String -> String` entnehmen jeweils n Zeichen von der linken bzw. rechten Seite des Strings.

```elm
left 2 "Mulder" 
    --> "Mu"
right 2 "Scully" 
    --> "ly"
```

`dropLeft : Int -> String -> String` und `dropRight : Int -> String -> String` verwerfen jeweils n Zeichen von der linken bzw. rechten Seite eines Strings.
```elm
dropRight 6 "Hello world." 
    --> "Hello"
dropLeft 6 "Hello world." 
    --> "world"
```

## String-Eigenschaften prüfen

`length : String -> Int` gibt die Anzahl der Zeichen in einem String zurück.
```elm 
length "Hello world." 
    --> 12
```

`isEmpty : String -> Bool` stellt fest, ob ein String leer ist. 
```elm 
isEmpty "Hello world." 
    --> False
```

`contains : String -> String -> Bool` prüft, ob der zweite String den ersten enthält.
```elm
contains "the" "theory" 
    --> True
contains "THE" "theory" 
    --> False
```

`startsWith : String -> String -> Bool` und `endsWith : String -> String -> Bool` prüfen, ob der zweite String mit einem gegebenen Teilstring beginnt bzw. endet.
```elm
startsWith "the" "theory" 
    --> True
endsWith "ory" "theory" 
    --> True
```

`indexes : String -> String -> List Int` liefert eine Liste aller Startindizes eines Teilstrings in einem anderen String.
```elm
indexes "ss" "Mississippi"  
    --> [2, 5]
```

## Strings umwandeln
`toInt : String -> Maybe Int` versucht, einen String in `Just Int` umzuwandeln, und gibt für falsch formatierte Strings `Nothing` zurück.
```elm
toInt "-42" 
    --> Just -42
toInt "3.1" 
    --> Nothing
toInt "two" 
    --> Nothing
```

`fromInt : Int -> String` wandelt eine Ganzzahl in einen String um.
```elm
fromInt -42 
    --> "-42"
```

`toFloat : String -> Maybe Float` versucht, einen String in eine Gleitkommazahl umzuwandeln, und scheitert bei falsch formatierten Strings.
```elm
toFloat "-42" 
    --> Just -42.0
toFloat "3.1" 
    --> Just 3.1
toFloat "two" 
    --> Nothing
```

`fromFloat : Float -> String` wandelt eine Gleitkommazahl in einen String um.
```elm
fromFloat 3.9 
    --> "3.9"
```

`toList : String -> List Char` und `fromList : List Char -> String` wandeln einen String in eine Liste von Zeichen um und wieder zurück.
```elm 
toList "abc" 
    --> ['a', 'b', 'c']
fromList ['a', 'b', 'c'] 
    --> "abc"
```

`fromChar : Char -> String` wandelt ein Zeichen in einen String um.
```elm
fromChar 'a' 
    --> "a"
```

## Strings formatieren

`toUpper : String -> String` und `toLower : String -> String` wandeln Strings jeweils in reine Groß- bzw. Kleinschreibung um.
Nützlich für Vergleiche, bei denen die Groß- und Kleinschreibung keine Rolle spielt.
```elm
toUpper "skinner" 
    --> "SKINNER"
toLower "X-FILES" 
    --> "x-files"
```

`pad : Int -> Char -> String -> String` füllt einen String auf beiden Seiten mit dem angegebenen `Char` auf, bis er die gegebene Länge hat.
```elm
pad 5 ' ' "11"  
    --> "  11 "
```
Analog füllen `padLeft` und `padRight` einen String auf einer der beiden Seiten auf, bis er eine gegebene Länge hat.

`trim : String -> String` entfernt Whitespace auf beiden Seiten eines Strings.
```elm
trim "  hats  \n" 
    --> "hats"
```
`trimLeft` und `trimRight` entfernen Whitespace auf einer der beiden Seiten eines Strings.

## Funktionen höherer Ordnung

`map : (Char -> Char) -> String -> String` wandelt jedes Zeichen in einem String mit der angegebenen Funktion um.
Beachte, dass die übergebene Funktion eine Abbildung von `Char` nach `Char` sein muss.
```elm
map (\c -> if c == '/' then '.' else c) "a/b/c" 
    --> "a.b.c"
```

`filter : (Char -> Bool) -> String -> String` behält nur die Zeichen, die den Test bestehen.
```elm
filter isDigit "R2-D2" 
    --> "22"
```

`foldl : (Char -> b -> b) -> b -> String -> b` reduziert einen String beginnend von links.
Die Funktion wird mit dem ersten Zeichen als erstem Parameter und einem übergebenen Anfangswert als zweitem Parameter aufgerufen.
Das Ergebnis der Funktion muss denselben Typ haben wie der übergebene Anfangswert und wird der Reihe nach auf jedes Zeichen angewendet.
```elm
foldl (\c acc -> Char.toCode c + acc) 0 "the sum of my unicode is " 
    --> 2260
```
`foldr` macht dasselbe, beginnt aber auf der rechten Seite des Strings.

`any : (Char -> Bool) -> String -> Bool` stellt fest, ob ein beliebiges Zeichen bei dem übergebenen Prädikat `True` ergibt.
```elm
any isDigit "R2-D2" 
    --> True
any isDigit "heart" 
    --> False
```
`all : (Char -> Bool) -> String -> Bool` stellt fest, ob alle Zeichen in einem String bei dem übergebenen Prädikat `True` ergeben.
```elm
all isDigit "R2-D2" 
    --> False
all isAlpha "heart" 
    --> True
```
