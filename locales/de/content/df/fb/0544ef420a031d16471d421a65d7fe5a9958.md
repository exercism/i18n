# Hinweise

## Allgemeines

- Deine Lösungsdatei wird in eine andere eingebunden, die deine Makros aufruft.
  Behalte den Namen und die Reihenfolge der Argumente jedes Makros genau so bei, wie die Aufgabe sie vorgibt, sonst lässt sich die Datei nicht assemblieren.
- Die Argumente eines Makros sind Tokens, die überall im Rumpf des Makros durch `%1`, `%2`, `%3` ersetzt werden.
  Sie können Register, Adressausdrücke oder Literale sein, solange jede Expansion eine gültige Anweisung ergibt.
- Bei jedem Makro wird geprüft, welche Register es unverändert lässt, nicht nur, was es schreibt.
  Lies in jeder Aufgabe den Hinweis dazu, welche Register überschrieben werden, und ändere nur die Register, die er zulässt.

## 1. Benenne die Formatkonstanten

- Ein einzeiliges `%define` gibt einem Wert einen Namen, sodass der restliche Code den Namen statt einer nackten Zahl lesen kann.
  Bei einer festen Zahl macht `equ` dasselbe und ist die übliche Wahl für eine Konstante.
- Die Byte-Konstanten kannst du entweder als Hexadezimalzahl (`0x20`) oder als Zeichenliteral (`' '`) schreiben.
  Beide assemblieren zum selben Wert.

## 2. Schreibe das Makro `fill_run`

- Du solltest `rcx` den lesbaren Namen `COUNTER` geben.
- `fill_run` ist ein mehrzeiliges Makro, das 3 Argumente entgegennimmt.
  Mehrzeilige Makros werden mit `%macro ... %endmacro` definiert.
- Das erste Argument von `fill_run` ist eine Speicheradresse in einem 64-Bit-Allzweckregister.
  Das zweite ist die Anzahl, die entweder in einem 64-Bit-Allzweckregister oder als Immediate übergeben werden kann.
  Das dritte ist ein Byte, das geschrieben werden soll, als Immediate.
  Du solltest den Code im Makro so planen, dass er diese Vorgaben berücksichtigt.
- Das einzige Register, das `fill_run` ändern darf, ist `COUNTER`.
- Eine Schleife in einem Makro braucht meist ein Label mit dem Präfix `%%`.
  Ohne dieses Präfix wird bei jedem Aufruf des Makros dasselbe Label erzeugt, was zu einem Fehler führen kann, wenn das Makro mehr als einmal aufgerufen wird.

## 3. Schreibe das Makro `lay_columns`

- `lay_columns` ist ein mehrzeiliges Makro, das 2 Argumente entgegennimmt.
  Mehrzeilige Makros werden mit `%macro ... %endmacro` definiert.
- Beide Argumente von `lay_columns` werden in 64-Bit-Allzweckregistern übergeben.
  Das erste ist eine Speicheradresse, das zweite eine Ganzzahl.
  Du solltest den Code im Makro so planen, dass er diese Vorgaben berücksichtigt.
- Die einzigen Register, die `lay_columns` ändern darf, sind die beiden, die als Argumente übergeben werden.
- Die Anzahl der Offsets, die das Makro schreiben muss, steht zur Assemblierungszeit fest.
  Du kannst `%rep ... %endrep` verwenden, um den Code zu wiederholen.
- Die Offset-Berechnung erfolgt mit `offset[i] = margin + i * COLUMN_STRIDE`.
  `margin` ist das zweite Argument des Makros.
  `i` ist ein Schleifenzähler, den du als `%assign`-Variable definieren kannst.

## 4. Schreibe das Makro `set_header`

- `set_header` ist ein mehrzeiliges Makro, das 2 Argumente entgegennimmt.
  Mehrzeilige Makros werden mit `%macro ... %endmacro` definiert.
- Das erste Argument von `set_header` ist der Ausdruck einer effektiven Speicheradresse.
  Er besteht aus einem Basisregister, das mit einem mit `1`, `2`, `4` oder `8` skalierten Indexregister und einem Immediate summiert werden kann.
  Das heißt, ein einfaches `rdi` ist gültig, ebenso `rdi+rax*4+2`.
- Das zweite Argument von `set_header` ist ein Immediate, das die Werte `0`, `1` oder `2` haben kann.
- `set_header` darf überhaupt kein Register ändern.
- Du solltest je nach zweitem Argument zur Assemblierungszeit ein Byte an die Zieladresse kopieren.
  Ein Wert von `0` sollte `PLAIN` kopieren, ein Wert von `1` sollte `RULED` kopieren und ein Wert von `2` sollte `BOXED` kopieren.
