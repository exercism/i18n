# Anleitung

Du bist ein begeisterter Vogelbeobachter und hältst fest, wie viele Vögel in den letzten sieben Tagen deinen Garten besucht haben.

Du hast sechs Aufgaben, die sich alle mit der Anzahl der Vögel befassen, die deinen Garten besucht haben.

## 1. Prüfe, wie die Zählungen letzte Woche waren

Zu Vergleichszwecken hast du immer eine Kopie der Zählungen der letzten Woche in der Nähe, und zwar: 0, 2, 5, 3, 7, 8 und 4. Implementiere die Methode `BirdWatcher.getLastWeek()`, die die Zählungen der letzten Woche zurückgibt:

```java
BirdWatcher.getLastWeek();
// => [0, 2, 5, 3, 7, 8, 4]
```

## 2. Prüfe, wie viele Vögel heute zu Besuch waren

Implementiere die Methode `BirdWatcher.getToday()`, die zurückgibt, wie viele Vögel heute deinen Garten besucht haben. Die Vogelzählungen sind nach Tagen geordnet, wobei das erste Element die Zählung des ältesten Tages ist und das letzte Element die heutige Zählung.

```java
int[] birdsPerDay = { 2, 5, 0, 7, 4, 1 };
BirdWatcher birdCount = new BirdWatcher(birdsPerDay);
birdCount.getToday();
// => 1
```

## 3. Erhöhe die heutige Zählung

Implementiere die Methode `BirdWatcher.incrementTodaysCount()`, um die heutige Zählung zu erhöhen:

```java
int[] birdsPerDay = { 2, 5, 0, 7, 4, 1 };
BirdWatcher birdCount = new BirdWatcher(birdsPerDay);
birdCount.incrementTodaysCount();
birdCount.getToday();
// => 2
```

## 4. Prüfe, ob es einen Tag ohne Vögel gab

Implementiere die Methode `BirdWatcher.hasDayWithoutBirds()`, die `true` zurückgibt, wenn es einen Tag gab, an dem null Vögel den Garten besucht haben; andernfalls gib `false` zurück:

```java
int[] birdsPerDay = { 2, 5, 0, 7, 4, 1 };
BirdWatcher birdCount = new BirdWatcher(birdsPerDay);
birdCount.hasDayWithoutBirds();
// => true
```

## 5. Berechne die Anzahl der Vögel, die in den ersten Tagen zu Besuch waren

Implementiere die Methode `BirdWatcher.getCountForFirstDays()`, die die Anzahl der Vögel zurückgibt, die deinen Garten seit Beginn der Woche besucht haben, aber begrenze die Zählung auf die angegebene Anzahl von Tagen ab Beginn der Woche.

```java
int[] birdsPerDay = { 2, 5, 0, 7, 4, 1 };
BirdWatcher birdCount = new BirdWatcher(birdsPerDay);
birdCount.getCountForFirstDays(4);
// => 14
```

## 6. Berechne die Anzahl der geschäftigen Tage

Manche Tage sind geschäftiger als andere. Ein geschäftiger Tag ist einer, an dem fünf oder mehr Vögel deinen Garten besucht haben.
Implementiere die Methode `BirdWatcher.getBusyDays()`, um die Anzahl der geschäftigen Tage zurückzugeben:

```java
int[] birdsPerDay = { 2, 5, 0, 7, 4, 1 };
BirdWatcher birdCount = new BirdWatcher(birdsPerDay);
birdCount.getBusyDays();
// => 2
```
