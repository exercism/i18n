# Vorbereitung auf den Start

Bevor du deinen Track starten kannst, stelle bitte sicher, dass die folgenden Aufgaben erledigt sind.

## Track-Icon anfragen

Um ein Icon für die Website zu entwerfen, erstelle ein neues Issue im Repository [exercism/website-icons](https://github.com/exercism/website-icons/issues) und beantworte die folgenden Fragen:

- Hat die Sprache ein offizielles Logo? Wenn ja:
  - gib bitte einen Link zu einem Beispiel an
  - liste bitte die Anforderungen an die Namensnennung auf sowie die Rechte, die für die Verwendung dieses Logos eingeräumt werden
- Hat die Sprache ein inoffizielles Logo? Wenn ja:
  - erkläre bitte, wie Menschen das inoffizielle Logo verwenden
  - gib bitte einen Link zu einem Beispiel an
  - liste bitte die Anforderungen an die Namensnennung für dieses Logo auf

## Track-Dokumentation hinzufügen

Füge die folgenden Track-Dokumente hinzu:

- `docs/ABOUT.md`: eine kurze Einführung in die Sprache.
- `docs/INSTALLATION.md`: beschreibe, was Lernende installieren müssen, um mit der Kommandozeile auf ihrem lokalen System an dem Track arbeiten zu können.
- `docs/LEARNING.md`: Links zu Lernressourcen.
- `docs/RESOURCES.md`: Links zu nützlichen Ressourcen.
- `docs/TESTS.md`: beschreibe alles rund um das Ausführen von Tests im Track.

Diese Dokumente helfen Lernenden, mit dem Track loszulegen und mehr über den Track und seine Sprache zu erfahren.
Weitere Informationen findest du in der [Dokumentation zu den Docs](/docs/building/tracks/docs).

## Übungsdokumentation hinzufügen

Füge die folgenden Übungsdokumente hinzu:

- `exercises/shared/.docs/help.md`: enthält Anleitungen speziell für den Track, wie man Hilfe bekommt
- `exercises/shared/.docs/tests.md`: enthält Anleitungen speziell für den Track, wie man die Tests ausführt

## Code-Snippet hinzufügen

Füge ein Code-Snippet zur Datei `docs/SNIPPET.txt` hinzu.
Dieses Snippet vermittelt einen visuellen Eindruck davon, wie die Syntax der Sprache aussieht.
Weitere Informationen findest du in der [Dokumentation zu den Docs](/docs/building/tracks/docs).

## Metadaten aktualisieren

Die Metadaten des Tracks sind in der [config.json-Datei](/docs/building/tracks/config-json) definiert.
Die folgenden Eigenschaften sollten aktualisiert werden:

- `language`: die Sprache des Tracks (z. B. `"C#"`). Die Länge muss <= 255 sein
- `slug`: die Sprache des Tracks als kleingeschriebener String im Kebab-Case (z. B. `"csharp"`). Die Länge muss <= 255 sein
- `blurb`: eine kurze Beschreibung der Sprache. Die Länge muss <= 400 sein
- `online_editor`: ein Objekt, das die Einstellungen für den Online-Editor beschreibt:
  - `indent_style`: entweder `"space"` oder `"tab"`
  - `indent_size`: die Einrückungsgröße als Ganzzahl (z. B. `4`)
  - `highlightjs_language`: der Sprachbezeichner für Highlight.js (siehe die [vollständige Liste der Bezeichner](https://github.com/highlightjs/highlight.js/blob/main/SUPPORTED_LANGUAGES.md)). Wenn es keine Unterstützung für Highlight.js gibt, kann dieses Feld weggelassen werden.
- `key_features`: die Hauptmerkmale der Sprache, die ihre bedeutendsten Eigenschaften kurz beschreiben. Weitere Informationen findest du in der [Dokumentation zu den Hauptmerkmalen](/docs/building/tracks/config-json#h-key-features).
- `tags`: lege die Tags fest, die für diesen Track gelten, sodass er auf der Website gesucht werden kann. Weitere Informationen und die Liste der unterstützten Tags findest du in der [Dokumentation zu den Tags](/docs/building/tracks/config-json#h-tags).
