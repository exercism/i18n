# Installation

## .NET installieren

Der F#-Track baut auf der [.NET](https://dotnet.microsoft.com/learn/dotnet/what-is-dotnet)-Plattform auf, die unter Windows, Linux und macOS läuft. Zum Erstellen von .NET-Projekten kannst du die .NET-Kommandozeile (CLI) verwenden. Diese Kommandozeile ist Teil des .NET SDK, das du installieren kannst, indem du die [Installationsanleitung](https://dotnet.microsoft.com/download) befolgst. Hinweis: Der F#-Track benötigt SDK-Version 8.0 oder höher.

Nach Abschluss der Installation kannst du überprüfen, ob die Kommandozeile erfolgreich installiert wurde, indem du diesen Befehl in einem Terminal ausführst:

```bash
dotnet --version
```

Wenn die Ausgabe eine Version größer oder gleich `8.0.100` ist, wurde das .NET SDK erfolgreich installiert.

## Eine IDE verwenden

Wenn du eine komfortablere Bearbeitungsumgebung mit mehr Funktionen möchtest, ist eine IDE wahrscheinlich genau das Richtige. Das sind die beliebtesten IDEs, die das Erstellen von .NET-Projekten unterstützen:

- [Visual Studio 2022](https://www.visualstudio.com/downloads/)
- [Visual Studio Code](https://code.visualstudio.com/download) mit der [Ionide-fsharp-Erweiterung](https://marketplace.visualstudio.com/items?itemName=Ionide.Ionide-fsharp)
- [Visual Studio for Mac](https://www.visualstudio.com/vs/visual-studio-mac/)
- [Project Rider](https://www.jetbrains.com/rider/download/)

Hinweis: Da sich das .NET-Projektformat deutlich von früheren Versionen unterscheidet, werden ältere IDEs (wie Visual Studio 2015) nicht unterstützt.
