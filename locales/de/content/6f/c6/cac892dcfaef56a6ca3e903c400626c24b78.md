# Hinweise

## 1. Die Highscore-Tabelle erstellen

- Die Highscore-Tabelle muss eine Hash-Tabelle sein.
- Eine Hash-Tabelle kannst du mit `make-hash-table` erstellen.

## 2. Einen Spieler zur Tabelle hinzufügen

- Um ein Schlüssel-Wert-Paar zu einer Hash-Tabelle hinzuzufügen, verwende `(setf (gethash key table) value)`

## 3. Den Punktestand eines Spielers setzen

- Den Punktestand eines Spielers zu setzen ist fast dasselbe wie den Spieler zur Tabelle hinzuzufügen.
- Um ein Schlüssel-Wert-Paar zu einer Hash-Tabelle hinzuzufügen, verwende `(setf (gethash key table) value)`

## 4. Einen Punktestand aus der Tabelle abrufen

- Verwende `gethash`, um einen Wert für einen Schlüssel aus der Hash-Tabelle abzurufen.
- `gethash` hat ein optionales drittes Argument, das den Wert angibt, der verwendet wird, wenn der Schlüssel nicht gefunden wird.

## 5. Einen Spieler aus der Tabelle entfernen

- Verwende `remhash`, um einen Schlüssel aus der Tabelle zu entfernen.
