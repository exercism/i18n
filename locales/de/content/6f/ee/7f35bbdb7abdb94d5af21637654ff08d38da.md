# Einführung

Ein [`Set`][set] ist eine Sammlung von Elementen mit den folgenden Eigenschaften:

- Ungeordnet.
- Elemente sind eindeutig, daher wird das Hinzufügen von Duplikaten stillschweigend ignoriert.
- Unterstützt viele der Operationen, die man von mathematischen Mengen kennt.

Erstelle sie mit dem `Set()`-Konstruktor und gib einen beliebigen Iterator als Parameter an.

```julia-repl
julia> s1 = Set(1:4)
Set([4, 2, 3, 1])
```

Neue Elemente fügst du mit `push!()` hinzu (genauso wie bei Arrays) und entfernst sie mit `delete!()`.

```julia-repl
julia> push!(s1, 5)
Set([5, 4, 2, 3, 1])

# Duplicates are ignored
julia> push!(s1, 3)
Set([5, 4, 2, 3, 1])

julia> delete!(s1, 5)
Set([4, 2, 3, 1])

julia> length(s1)  # length counts entries, despite the non-sequential type
4
```

## Operationen mit Sets

Wie bei mehreren anderen Sammlungstypen prüfst du die Zugehörigkeit mit dem Operator `in` oder `∈` (tippe `\in` und dann die Tabulatortaste für das Symbol).

```julia-repl
julia> 3 ∈ s1
true
```

Die folgenden Operationen auf Paaren von Sets werden unterstützt (Abkürzungen für das Operatorsymbol stehen in Klammern).

- `union(A, B)` oder `A ∪ B` (`\cup`): alle Elemente, die in A oder in B oder in beiden enthalten sind.
- `intersect(A, B)` oder `A ∩ B` (`\cap`): alle Elemente, die sowohl in A als auch in B enthalten sind.
- `setdiff(A, B)` (kein Symbol): Elemente, die in A, aber nicht in B enthalten sind.
- `symdiff(A, B)` (kein Symbol): Elemente, die in A oder in B, aber nicht in beiden enthalten sind.
- `issubset(A, B)` oder `A ⊆ B` (`\subseteq`) oder `B ⊇ A` (`\supseteq`): `true`, wenn alle Elemente von A auch in B enthalten sind.
- `issetequal(A, B)` (kein Symbol): `true`, wenn A und B genau dieselben Elemente enthalten.
- `isdisjoint(A, B)` (kein Symbol): `true`, wenn A und B keine gemeinsamen Elemente haben (die Schnittmenge also leer ist).

```julia-repl
julia> s1 = Set(1:4);
julia> s2 = Set(3:6);
julia> s1 ∪ s2  # union
Set([5, 4, 6, 2, 3, 1])

julia> s1 ∩ s2  # intersect
Set([4, 3])
  
julia> setdiff(s1, s2)
Set([2, 1])

julia> symdiff(s1, s2)
Set([5, 6, 2, 1])
  
julia> s1 ⊇ s2  # issubset
false
```

Von vielen dieser Funktionen gibt es auch mutierende Varianten, bei denen dem Funktionsnamen ein `!` angehängt wird. Eine vollständige Liste der Funktionen findest du im [Handbuch][set].
