# Einführung

Aus [dem Handbuch][man-types]

> jq unterstützt dieselbe Menge an Datentypen wie JSON: Zahlen, Strings, boolesche Werte, Arrays, Objekte (die in JSON-Sprache Hashes mit ausschließlich String-Schlüsseln sind) und „null".

Konzentrieren wir uns auf **Zahlen**.

## Zahlen und numerische Operatoren

Alle Zahlen, ob Ganzzahlen oder nicht, sind IEEE754-Gleitkommazahlen mit doppelter Genauigkeit.
Das begrenzt uns auf 53 Bits Genauigkeit.

Für Zahlen stehen die üblichen Operatoren zur Verfügung:

- Arithmetik: `+`, `-`, `*`, `/`, `%`
- Vergleich: `==`, `!=`, `<`, `<=`, `>=`, `>`
- die standardmäßigen [Mathematikfunktionen][man-math]

  Bei Funktionen mit einem Eingabewert leitest du den Wert über eine Pipe in die Funktion

  ```sh
  $ jq -n '(1 | atan) * 4'
  3.141592653589793
  ```

  Bei Funktionen mit zwei Eingabewerten ignorieren die Funktionen die Eingabe und erwarten
  die Eingabewerte als Parameter (zur Erinnerung: Parameter werden durch Semikolons getrennt)

  ```sh
  $ jq -n 'pow(2; 10)'
  1024
  ```

  Das Semikolon ist das Trennzeichen für Funktionsargumente, nicht das Komma.

## Weitere `jq`-Ausdrücke

Um die Übung zu lösen, musst du bedingte Ausdrücke kennen.

### Bedingte Ausdrücke

`jq` verwendet für **bedingte Ausdrücke** einen [`if-then-else`-Ausdruck][if-then-else].
Als _Ausdruck_ wird er in eine Pipeline gesetzt.

Die Syntax lautet: `if CONDITION then TRUE_EXPR else FALSE_EXPR end`.

Die `else`-Klausel ist optional.

```jq
42 | if . < 33 then "small" else "larger" end
# => "larger"
```

Zusätzliche Bedingungen verwendest du mit `elif`

```jq
42 | if . < 33 then "small"
     elif . < 67 then "medium"
     else "large"
     end
# => "medium"
```
