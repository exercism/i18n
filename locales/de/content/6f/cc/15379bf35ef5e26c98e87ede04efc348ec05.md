# Einführung

Die Definition einer Sammlung enthält normalerweise einen Platzhalter in spitzen Klammern, oft ist das konventionsgemäß T. Eine solche Sammlung nennt man einen generischen Typ. Dadurch kann der Nutzer der Sammlung festlegen, welchen Typ von Elementen sie speichern soll. Im obigen Beispielcode instanziieren wir eine Liste von Strings.

Eine Klasse oder eine Funktion machst du **generisch**, indem du das Attribut `@:generic` verwendest. Dadurch erkennt der Compiler die Klasse oder die Funktion als generisch:

```haxe
@:generic
class MyValue<T> {
  public var value:T;

  public function new(value:T) {
    this.value = value;
  }
}

var a = MyValue<String>("Hello");
trace(a.value); // Hello
```
