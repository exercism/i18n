# Installation

## Voraussetzungen

* Eine 64-Bit-x86-CPU
* Einen modernen C-Compiler
* Das Build-Tool Make
* Den Netwide Assembler (NASM)

Beachte, dass dieser Track nur die Aufrufkonvention der System V AMD64 ABI unterstützt. Unter Windows musst du das Windows Subsystem for Linux (WSL) installieren oder eine virtuelle Linux-Maschine einrichten.

## Linux

Installiere die benötigte Software mit dem Paketmanager deines Systems:

* Ubuntu, Debian: `$ sudo apt-get install gcc make nasm`
* Fedora: `$ sudo dnf install gcc make nasm`
* CentOS, RHEL: `$ sudo yum install gcc make nasm`
* Arch Linux: `$ sudo pacman -S gcc make nasm`
* OpenSUSE: `$ sudo zypper install gcc make nasm`

## macOS

Installiere die Xcode Command Line Tools:

```bash
$ xcode-select --install
```

Installiere NASM mit [Homebrew](http://brew.sh/):

```bash
$ brew install nasm
```

## Windows

Wie du WSL installierst, erfährst du unter https://docs.microsoft.com/en-us/windows/wsl/install-win10.
