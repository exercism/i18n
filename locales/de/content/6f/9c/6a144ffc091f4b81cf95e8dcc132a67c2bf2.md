# Einführung

In JavaScript ist ein Array eine listenartige Struktur ohne feste Länge, die jeden Typ von primitiven Werten oder Objekten aufnehmen kann, sogar gemischte Typen.

Um ein Array zu erstellen, schreibst du die Elemente zwischen eckige Klammern `[]`.
Um aus dem Array zu lesen, setzt du den Index in eckige Klammern `[]` hinter den Bezeichner.
Die Indizes eines Arrays beginnen bei null.

Zum Beispiel:

```javascript
const numbers = [1, 'two', 3, 'four'];
numbers[2];
// => 3
```

Um die Anzahl der Elemente in einem Array zu ermitteln, verwendest du die Eigenschaft `length`:

```javascript
const numbers = [1, 'two', 3, 'four'];
numbers.length;
// => 4
```

Um ein Element im Array zu ändern, weist du dem Index einen Wert zu:

```javascript
const numbers = [1, 'two', 3, 'four'];
numbers[0] = 'one';
numbers;
// => ['one', 'two', 3, 'four']
```

## Methoden

Einige der [Methoden][mdn-array], die auf jedem Array-Objekt verfügbar sind, kannst du verwenden, um etwas zum Array hinzuzufügen oder daraus zu entfernen.
Hier sind ein paar, die du bei dieser Übung beachten solltest:

### push

Ein `value` kann mit `.push(value)` an das Ende eines Arrays _hinzugefügt_ werden.
Die Methode gibt die neue Länge des Arrays zurück.

```javascript
const numbers = [1, 'two', 3, 'four'];
numbers.push(5); // => 5
numbers;
// => [1, 'two', 3, 'four', 5]
```

### pop

Der _letzte_ `value` kann mit `.pop()` aus einem Array _entfernt_ werden.
Die Methode gibt den entfernten Wert zurück.
Die Länge des Arrays verringert sich durch diese Änderung.

```javascript
const numbers = [1, 'two', 3, 'four'];
numbers.pop(); // => four
numbers;
// => [1, 'two', 3]
```

### shift

Der _erste_ `value` kann mit `.shift()` aus einem Array _entfernt_ werden.
Die Methode gibt den entfernten Wert zurück.
Die Länge des Arrays verringert sich durch diese Änderung.

```javascript
const numbers = [1, 'two', 3, 'four'];
numbers.shift(); // => 1
numbers;
// => ['two', 3, 'four']
```

### unshift

Ein `value` kann mit `.unshift(value)` an den Anfang eines Arrays _hinzugefügt_ werden.
Die Methode gibt die neue Länge des Arrays zurück.

```javascript
const numbers = [1, 'two', 3, 'four'];
numbers.unshift('one'); // => 5
numbers;
// => ['one', 1, 'two', 3, 'four']
```

### splice

Ein `value` an einem bestimmten `index` kann mit `.splice(index, 1)` aus einem Array _entfernt_ werden.
Die Methode gibt das entfernte Element bzw. die entfernten Elemente zurück.

```javascript
const numbers = [1, 'two', 3, 'four'];
numbers.splice(2, 1, 'one'); // => [3]
numbers;
// => [1, 'two', 'one', 'four']
```

~~~exercism/advanced
Diese Methoden sind mächtiger, als hier beschrieben:

- Sowohl `push` als auch `unshift` erlauben es dir, mehrere Werte auf einmal hinzuzufügen, indem du weitere Argumente angibst.
  Das ist für diese Übung nicht nötig.
- Splice kann mehrere Werte entfernen, indem du das zweite Argument erhöhst.
  Das ist für diese Übung nicht nötig.
- Splice kann auch mehrere Werte hinzufügen, indem du sie als Argumente nach dem `deleteCount` angibst.
  Damit kannst du Werte ersetzen oder Werte in der Mitte eines Arrays einfügen (zum Beispiel, indem du 0 Elemente entfernst).
  Das ist für diese Übung nicht nötig.
~~~
