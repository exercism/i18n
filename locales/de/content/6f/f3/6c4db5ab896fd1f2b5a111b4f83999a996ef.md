# Einführung

## Boolesche Werte

Boolesche Werte in Java werden durch den Typ `boolean` dargestellt, dessen Werte entweder `true` oder `false` sein können.

Java unterstützt drei boolesche Operatoren:  

- `!` (NOT): negiert den booleschen Wert  
- `&&` (AND): nimmt zwei boolesche Werte und gibt `true` zurück, wenn beide `true` sind
- `||` (OR): gibt `true` zurück, wenn mindestens einer der beiden booleschen Werte `true` ist

### Beispiele

```java
!true // => false
!false // => true
true && false // => false
true && true // => true
false || false // => false
false || true // => true
```
