# Ergänzung zu den Anweisungen

In dieser Übung musst du Ausnahmen behandeln. Eine [Ausnahme](https://docs.oracle.com/javase/tutorial/essential/exceptions/definition.html) ist ein Ereignis, das während der Ausführung eines Programms auftritt und den normalen Ablauf der Anweisungen des Programms unterbricht.

In Java gibt es zwei Arten von Ausnahmen: Checked Exceptions und Unchecked Exceptions.

- [Checked vs Unchecked Exceptions in Java](https://www.geeksforgeeks.org/checked-vs-unchecked-exceptions-in-java/)

- [Unchecked Exceptions — The Controversy](https://docs.oracle.com/javase/tutorial/essential/exceptions/runtime.html)

## Checked Exceptions

Checked Exceptions sind Ausnahmen, die zur [Kompilierzeit](https://en.wikipedia.org/wiki/Compile_time) geprüft werden.

### Praktische Auswirkungen

Du musst sie in der [Methodensignatur](https://docs.oracle.com/javase/tutorial/java/javaOO/methods.html) jeder Methode deklarieren, die eine Checked Exception [werfen](https://docs.oracle.com/javase/tutorial/essential/exceptions/throwing.html) kann, und sie behandeln oder erneut werfen, wenn du eine Methode aufrufst, die eine Checked Exception werfen kann.

Der Grund dafür ist, dass Checked Exceptions zur Laufzeit behandelt werden sollen, das heißt, es sind Fehler, von denen du dich erholen kannst.

### Beispiele für ihre Verwendung

Sie werden oft verwendet, wenn eine Methode kein gültiges Ergebnis zurückgeben kann, zum Beispiel eine Suchmethode, die das gesuchte Element nicht gefunden hat.

Das ist eine Alternative dazu, `null` oder einen Fehlercode zurückzugeben. Eine Checked Exception ist besser als diese Alternativen, weil sie die Nutzer der Methode dazu zwingt, den Fehlerfall zu bedenken.

## Unchecked Exceptions

Unchecked Exceptions sind Ausnahmen, die zur [Kompilierzeit](https://en.wikipedia.org/wiki/Compile_time) nicht geprüft werden.

### Praktische Auswirkungen

Du musst sie nicht in der [Methodensignatur](https://docs.oracle.com/javase/tutorial/java/javaOO/methods.html) von Methoden deklarieren, die eine Unchecked Exception [werfen](https://docs.oracle.com/javase/tutorial/essential/exceptions/throwing.html) können, und sie auch nicht behandeln oder erneut werfen, wenn du eine Methode aufrufst, die eine Unchecked Exception werfen kann.

### Beispiele für ihre Verwendung

Unchecked Exceptions werden typischerweise durch Fehler im Programm verursacht und lassen sich durch sauberes Programmieren vermeiden. Beispiel: `ArrayIndexOutOfBoundsException` lässt sich vermeiden, indem du sicherstellst, dass die Array-Indizes zwischen 0 und der Länge des Arrays liegen.
