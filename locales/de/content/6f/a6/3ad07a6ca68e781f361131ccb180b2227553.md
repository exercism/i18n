# Einführung

## Strings

Ein `String` in Java ist ein Objekt, das unveränderlichen Text als Folge von Unicode-Zeichen (Buchstaben, Ziffern, Satzzeichen usw.) darstellt.
Mit doppelten Anführungszeichen definiert man eine `String`-Instanz:

```java
String fruit = "Apple";
```

Man manipuliert Strings, indem man ihre Methoden aufruft.
Sobald ein String konstruiert wurde, kann sich sein Wert niemals ändern.
Alle Methoden, die einen String zu verändern scheinen, geben tatsächlich einen neuen String zurück.
Die Klasse `String` stellt einige _statische_ Methoden bereit, um Strings umzuwandeln.
