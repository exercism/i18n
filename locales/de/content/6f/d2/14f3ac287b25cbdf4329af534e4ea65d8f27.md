# Blöcke & Procs

Ein [Block][block] ist ein Stück Code, das an eine Methode übergeben werden kann.
In anderen Programmiersprachen nennt man das eine [anonyme Funktion oder ein Lambda][anonymous function].
Eine Methode kann einen Block in einen [Proc][proc] umwandeln, der einen Codeblock darstellt.

```crystal
def my_method(&block)
  1 + yield
end

my_method { 2 }
# => 3
```

Blöcke und Procs werden in Crystal sehr häufig verwendet, etwa für Iterationen und Callbacks.
Aber auch, um [DSLs (domänenspezifische Sprachen)][dsl] zu erstellen. Beispiele für DSLs sind das Web-Framework [Kemal][kemal] oder das Test-Framework [Spec][spec] (mit dem deine Crystal-Lösungen getestet werden).

## Blöcke

Um eine Methode zu erstellen, die einen Block annehmen kann, musst du ein Ampersand (`&`) vor das letzte Argument setzen.
Dadurch wird der Block in einen Proc umgewandelt und dem Argument zugewiesen.
Mit `yield` führst du dann den Block aus, der der Methode übergeben wurde.

```crystal
def my_method(&block)
  1 + yield
end
```

Um einen Block zu übergeben, gibt es zwei Möglichkeiten: entweder mit den Schlüsselwörtern `do ... end` oder mit geschweiften Klammern (`{}`).
Der wichtigste Unterschied ist der Vorrang: `do ... end` unterstützt mehrzeilige Blöcke, geschweifte Klammern (`{}`) nicht.

```crystal
my_method do
  2
end
# => 3

my_method { 2 }
# => 3
```

## yield

[`yield`][yield] ist ein Schlüsselwort, das den Block ausführt, der der Methode übergeben wurde.
Das bedeutet, dass der Block nie ausgeführt wird, wenn `yield` nicht aufgerufen wird.
Ihm können auch Argumente übergeben werden, die dann an den Block weitergereicht werden.
Es gibt keine Begrenzung für die Anzahl der Argumente, die an den Block übergeben werden können.
Um die Argumente im Block zu verwenden, benutzt du die Syntax `|x, y, ...|`.
Dabei sind x, y, ... die Namen der Argumente.

```crystal
def my_method(&block)
  1 + yield 2
end

# With curly braces:

my_method { |x| x * 3 }
# => 7

# With do ... end:

my_method do |x|
  x * 3
end
# => 7
```

Im obigen Beispiel bekommt der Block das Argument `2`, multipliziert es mit `3` und gibt `6` zurück.
Die Methode addiert dann `1` zum Ergebnis und gibt `7` zurück.

Wenn die Anzahl der an `yield` übergebenen Argumente größer ist als die Anzahl der Argumente, die der Block erwartet, wird ein Fehler ausgelöst.

```crystal
def my_method(&block)
  1 + yield
end

my_method { |x| x * 3 }
# Error: too many block parameters (given 1, expected maximum 0)
```

## Arten von Blöcken

Blöcke können explizit oder implizit geschrieben werden.
Implizite Blöcke sind am häufigsten und kommen in den obigen Beispielen vor.
Du kannst dem Block sogar Argumente unterschiedlicher Typen geben, und der Compiler leitet die Typen ab und erstellt einen Union-Typ.

```crystal
def my_method(&block)
  yield "a"
  yield 1
end

my_method do |x|
  p typeof(x)
end

# output: (String | Int32)
```

Bei expliziten Blöcken kannst du die Typen der Argumente und den Rückgabetyp angeben.
Das machst du mit der Syntax `Arg1Type, Arg2Type, ... -> ResultType`.
Dabei werden die Argumente durch Kommas (`,`) getrennt, und der Ergebnistyp wird durch `->` getrennt.

```crystal
def my_method(&block : Int32, Int32 -> Int32)
  1 + yield(2, 3)
end

my_method { |x, y| x * y }
# => 7
```

Wie bei anderen expliziten Typen erzwingt der Compiler auch hier, dass die Typen den Erwartungen entsprechen.
Wenn der Block nicht zum Typ passt, der der Methode übergeben wurde, wird ein Fehler ausgelöst.

## Procs

[`Proc`][proc] hat eine sehr enge Verbindung zu Blöcken.
Der entscheidende Unterschied ist, dass ein `Proc` ein Typ ist und ein Block nicht.
Ein `Proc` repräsentiert einen Funktionszeiger und kann als Variable weitergegeben werden.

Um einen `Proc` zu definieren, benutzt du die Syntax des Proc-Literals `->(args) { ... }`.
Die Argumente werden durch Kommas (`,`) getrennt, und der Block wird durch `{ ... }` abgegrenzt.
Um einen Proc aufzurufen, benutzt du die Methode `call` und übergibst ihr die Argumente.
Die Typen der Parameter sind verpflichtend.
Der Rückgabetyp wird aus dem Code des Procs abgeleitet, kann aber auch explizit angegeben werden.

```crystal
my_proc = ->(x : Int32, y : Int32) : Int32 { x * y }
my_proc.call(2, 3)
# => 6
```

## Blöcke erfassen

[Blöcke erfassen][capturing-blocks] ist eine Möglichkeit, einen `Proc` aus einem Block zu erstellen.
Dazu benutzt du den Operator `&` vor dem letzten Argument einer Methode.
Dadurch wird der Block in einen `Proc` umgewandelt und dem Argument zugewiesen.

```crystal
def my_method(&block)
  block.call
end

my_method { 1 + 2 }
# => 3
```

### Procs an Methoden übergeben

Procs können an Methoden übergeben werden, die einen Block erwarten.
Das ist praktisch, wenn du je nach Bedingung unterschiedliche Blöcke übergeben möchtest.

```crystal
def my_method(&block)
  yield 5
end

my_proc = -> (x) { x * 2 }
my_method(&my_proc)
# => 10
```

### Den Typ von Variablen deklarieren

Beim Deklarieren einer Variablen kannst du die Syntax `: Type` verwenden, um den Typ der Variablen anzugeben.
Für Procs benutzt du die Syntax `Proc((ArgType, ...), ResultType)`.
Der letzte Typ ist immer der Rückgabetyp und die übrigen sind die Argumenttypen.
Das heißt, wenn es nur einen Typ gibt, ist dieser der Rückgabetyp und der Proc nimmt keine Argumente entgegen.

```crystal
my_proc : Proc(Int32, Int32, Int32) = ->(x, y) { x * y }
other_proc : Proc(Int32) = -> { 1 }
```
