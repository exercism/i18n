# Über

[Wörterbücher][dictionaries] gehören zu den primären Sammlungstypen von Swift.
Ein Wörterbuch speichert ungeordnete Zuordnungen zwischen eindeutigen Schlüsseln und den dazugehörigen Werten.
Alle Schlüssel in einem Wörterbuch müssen vom selben Typ sein, und alle Werte müssen ebenfalls denselben Typ haben.

Wörterbuch-Literale werden als kommagetrennte `key: value`-Paare in eckigen Klammern geschrieben:

```swift
var addresses: Dictionary<String, String> = [
    "The Munsters": "1313 Mockingbird Lane",
    "The Simpsons": "742 Evergreen Terrace",
    "Buffy Summers": "1630 Revello Drive"
]

var sequences: [String: [Int]] = [
    "Euler's totient": [1, 1, 2, 2, 4, 2, 6, 4],
    "Lazy caterer": [1, 2, 4, 7, 11, 16, 22, 29, 37],
    "Carmichael": [561, 1105, 1729, 2465, 2821, 6601, 8911, 10585, 15841]
]

let constants = [
    "pi": 3.14159,
    "e": 2.71828,
    "phi": 1.618033,
    "avogadro": 6.02214076e23
]
```

Wörterbuch-Typen kannst du auf zwei Arten explizit schreiben: `Dictionary<Key, Value>` oder mit der Kurzschreibweise `[Key: Value]`.

Um ein leeres Wörterbuch zu erstellen, gibst du seine Schlüssel- und Werttypen explizit an:

```swift
var emptyDict1: [Int: Int] = [:]
var emptyDict2 = [Character: String]()
var emptyDict3 = Dictionary<Int, Double>()
```

## Auf Werte zugreifen

Auf Werte kannst du mit der Subscript-Schreibweise zugreifen: Setze den Schlüssel in eckigen Klammern hinter den Namen des Wörterbuchs.
Da ein Schlüssel möglicherweise nicht im Wörterbuch vorhanden ist, liefert der Subscript-Zugriff ein *Optional* (`Value?`).
Ist der Schlüssel vorhanden, gibt Swift den umschlossenen Wert zurück; ist er nicht vorhanden, gibt Swift `nil` zurück:

```swift
let munster: String? = addresses["The Munsters"]
// Returns Optional("1313 Mockingbird Lane")

let carmichael = sequences["Carmichael"]
// Returns Optional([561, 1105, 1729, 2465, 2821, 6601, 8911, 10585, 15841])

let planck = constants["planck"]
// Returns nil
```

Um nicht mit Optionals arbeiten zu müssen, kannst du mit dem `default`-Parameter einen Standardwert angeben:

```swift
let e: Double = constants["e", default: 0]
// Returns 2.71828

let hoagie: [Int] = sequences["Hoagie", default: []]
// Returns []

let betty = addresses["Betty Cooper", default: "Address unknown"]
// Returns "Address unknown"
```

## Wörterbücher ändern

Bei veränderlichen Wörterbüchern, die mit `var` deklariert wurden, kannst du Schlüssel-Wert-Paare mit einer Subscript-Zuweisung hinzufügen oder aktualisieren:

```swift
sequences["Euler's totient"]?.append(contentsOf: [6, 4])
// sequences["Euler's totient"] is now [1, 1, 2, 2, 4, 2, 6, 4, 6, 4]

addresses["Betty Cooper"] = "111 Queens Ave."
addresses["Betty Cooper", default: "Address unknown"]
// Returns "111 Queens Ave."

constants["Gelfond's"] = 23.140692
// Compiler error: Cannot assign through subscript: 'constants' is a 'let' constant
```

## Über ein Wörterbuch iterieren

Mit einer `for-in`-Schleife kannst du über jedes Schlüssel-Wert-Paar eines Wörterbuchs iterieren.
Jedes Element wird als `(key, value)`-Tupel bereitgestellt:

```swift
for (name, address) in addresses {
    print("\(name) lives at \(address)")
}
```

## Wörterbücher sortieren

Da Wörterbücher ungeordnet sind, ergibt ihr Sortieren ein Array aus Schlüssel-Wert-Paaren.
Du kannst der Methode `sorted(by:)` eine Closure übergeben, die zwei `(key, value)`-Tupel vergleicht und `true` zurückgibt, wenn das erste Tupel vor dem zweiten stehen soll:

```swift
func sortByNameLengthThenValue(_ lhs: (key: String, value: Double), _ rhs: (key: String, value: Double)) -> Bool {
    let left = lhs.value + Double(lhs.key.count)
    let right = rhs.value + Double(rhs.key.count)
    return left < right
}

let sortedConstants = constants.sorted(by: sortByNameLengthThenValue)
```
