# Anleitung

Gegeben sind die Positionen zweier Damen auf einem Schachbrett. Gib an, ob sie so stehen, dass sie sich gegenseitig angreifen können.

Im Schach kann eine Dame Figuren angreifen, die in derselben Zeile, Spalte oder Diagonale stehen.

Ein Schachbrett kann durch ein 8x8-Array dargestellt werden.

Wenn dir also gesagt wird, dass die weiße Dame auf `c5` steht (nullbasiert: Spalte 2, Zeile 3) und die schwarze Dame auf `f2` (nullbasiert: Spalte 5, Zeile 6), dann weißt du, dass der Aufbau so aussieht:

![Ein Schachbrett mit zwei Damen. Pfeile, die von der Dame auf c5 ausgehen, zeigen mögliche Schlagrichtungen entlang Spalte, Zeile und Diagonale.](https://assets.exercism.org/images/exercises/queen-attack/queen-capture.svg)

Du kannst auch beantworten, ob sich die beiden Damen gegenseitig angreifen können.
In diesem Fall wäre die Antwort ja, sie können, weil beide Figuren auf derselben Diagonale stehen.
