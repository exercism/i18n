# Überblick

Um Logik wiederholt auszuführen, kannst du Schleifen verwenden. Eine der häufigsten Schleifenarten in C# ist die `while`-Schleife, die so lange läuft, bis eine boolesche Bedingung zu `false` ausgewertet wird.

```csharp
int x = 23;

while (x > 10)
{
    // Execute logic if x > 10
    x = x - 1;
}
```
