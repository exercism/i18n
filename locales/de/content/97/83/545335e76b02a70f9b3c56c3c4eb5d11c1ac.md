# Instructions

In dieser Übung schreibst du etwas Code, der dir bei der Vorbereitung auf den Kauf eines Fahrzeugs hilft.

Du hast drei Aufgaben: eine, um festzustellen, ob du einen Führerschein brauchst, eine, die dir bei der Wahl zwischen zwei Fahrzeugen hilft, und eine, um den angemessenen Preis für ein gebrauchtes Fahrzeug zu schätzen.

## 1. Feststellen, ob du einen Führerschein brauchst

Einige Fahrzeugarten erfordern zum Führen einen Führerschein.
Geh davon aus, dass nur die Arten `"car"` und `"truck"` einen Führerschein erfordern; alles andere kann ohne Führerschein gefahren werden.

Implementiere die Funktion `needs_license(kind)`, die die Fahrzeugart als String entgegennimmt und einen booleschen Wert zurückgibt, der angibt, ob du für diese Fahrzeugart einen Führerschein brauchst.

```cpp
needs_license("car")
// => true

needs_license("bike")
// => false

needs_license("truck")
// => true
```

## 2. Zwischen zwei möglichen Fahrzeugen wählen

Du vergleichst die Fahrzeuge, die dir zur Verfügung stehen.
Am Ende bleiben zwei Optionen übrig, aber für die endgültige Entscheidung brauchst du Hilfe.
Dafür implementierst du die Funktion `choose_vehicle(option1, option2)`, die zwei Fahrzeuge als Argumente entgegennimmt und eine Entscheidung mit der Option zurückgibt, die in lexikografischer Reihenfolge zuerst kommt.

```cpp
choose_vehicle("Wuling Hongguang", "Toyota Corolla")
// => "Toyota Corolla is clearly the better choice."

choose_vehicle("Volkswagen Beetle", "Volkswagen Golf")
// => "Volkswagen Beetle is clearly the better choice."
```

Der zurückgegebene String sollte dem Muster „<CHOSEN_VEHICLE> is clearly the better choice." folgen, wobei `<CHOSEN_VEHICLE>` die gewählte Option aus den übergebenen Argumenten ist.

## 3. Eine Schätzung für den Preis eines gebrauchten Fahrzeugs berechnen

Jetzt, wo du dich entschieden hast, willst du sichergehen, dass du beim Händler einen fairen Preis bekommst.
Da du ein gebrauchtes Fahrzeug kaufen willst, hängt der Preis davon ab, wie alt das Fahrzeug ist.
Für eine grobe Schätzung geh davon aus, dass das Fahrzeug 80 % des ursprünglichen Neupreises kostet, wenn es weniger als 3 Jahre alt ist.
Ist es mindestens 10 Jahre alt, kostet es 50 %.
Ist das Fahrzeug mindestens 3 Jahre alt, aber weniger als 10 Jahre, kostet es 70 % des ursprünglichen Preises.

Implementiere die Funktion `calculate_resell_price(original_price, age)`, die diese Logik mit `if`, `else if` und `else` umsetzt (es gibt auch andere Möglichkeiten, wenn du üben möchtest).
Sie nimmt den ursprünglichen Preis und das Alter des Fahrzeugs als Argumente entgegen und gibt den geschätzten Preis beim Händler zurück.

```cpp
calculate_resell_price(1000, 1)
// => 800

calculate_resell_price(1000, 5)
// => 700

calculate_resell_price(1000.0, 15)
// => 500
```

> Hinweis: Der Rückgabewert hat den Typ `double`.
