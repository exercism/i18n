# Debug

Wenn ein Test fehlschlägt, wird eine Meldung angezeigt, die beschreibt, was schiefgelaufen ist und bei welcher Eingabe. Du kannst außerdem davon Gebrauch machen, dass auch jede Ausgabe von `console` angezeigt wird. Du kannst mit diesem Code in die Konsole schreiben:

```javascript
console.log('Debug message');
```
