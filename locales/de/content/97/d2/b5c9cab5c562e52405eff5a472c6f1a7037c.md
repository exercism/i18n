# Anweisungen

In dieser Übung organisierst du Rennen zwischen verschiedenen Arten von ferngesteuerten Autos.
Jedes Auto hat seine eigene Geschwindigkeit und seine eigene Batterieentladung.

Autos starten mit vollen Batterien (100 %). Jedes Mal, wenn du das Auto mit der Fernbedienung fährst,
legt es die Geschwindigkeit des Autos in Metern zurück und verringert den verbleibenden Batterieprozentsatz
um seine Batterieentladung.

Wenn die Batterie eines Autos unter seinen Batterieentladungsprozentsatz fällt, kannst du das Auto nicht mehr fahren.

Jede Rennstrecke hat ihre eigene Länge. Autos werden getestet, indem geprüft wird, ob sie die Strecke beenden können,
ohne dass ihnen die Batterie ausgeht.

## 1. Erstelle ein ferngesteuertes Auto

Definiere eine Liste `car` mit den folgenden Elementen:

- speed
- battery_drain
- battery
- distance_traveled

Ermögliche das Erstellen eines ferngesteuerten Autos, indem du eine Funktion `new_car` definierst, die die Geschwindigkeit
des Autos in Metern und den Prozentsatz der Batterieentladung als ihre beiden Parameter entgegennimmt und eine Liste
`car` zurückgibt.

Bei einem neuen Auto ist die Batterie bei 100 % und die zurückgelegte Strecke ist null.

```R
speed <- 5
battery_drain <- 2
car <- new_car(speed, battery_drain)
str(car)
#> List of 4
#>  $ speed             : num 5
#>  $ battery_drain     : num 2
#>  $ battery           : num 100
#>  $ distance_traveled : num 0
```

## 2. Erstelle eine Rennstrecke

Definiere eine weitere Liste namens `track` mit dem einzigen Element `track_length`.
Ermögliche das Erstellen einer Rennstrecke, indem du eine Funktion `new_track` definierst, die die Entfernung der Strecke in Metern entgegennimmt:

```R
track_length <- 800
track <- new_track(track_length)
str(track)
#> List of 1
#>  $ track_length: num 800
```

## 3. Prüfe, ob die Batterie leer ist

Implementiere die Funktion `battery_drained()`, die anzeigt, ob die Batterie leer ist.
Eine Batterie gilt als leer, wenn nicht mehr genug übrig ist, um sich noch einmal zu bewegen.

```R
speed <- 5;
battery_drain <- 2;
car <- new_car(speed, battery_drain);
car <- drive(car);

battery_drained(car);
#> [1] FALSE
```

## 4. Fahre das Auto

Implementiere die Funktion `drive`, die die Anzahl der gefahrenen Meter basierend auf der Geschwindigkeit des Autos
aktualisiert und die Batterie entsprechend der Batterieentladung reduziert.
Wenn nicht genug Batterie übrig ist, um noch einmal zu fahren, bewegt sich das Auto nicht.

```R
speed <- 5
battery_drain <- 2
car <- new_car(speed, battery_drain)
car <- drive(car)
str(car)
#> List of 4
#>  $ speed             : num 5
#>  $ battery_drain     : num 2
#>  $ battery           : num 98
#>  $ distance_traveled : num 5
```

## 5. Prüfe, ob ein ferngesteuertes Auto ein Rennen beenden kann

Um ein Rennen zu beenden, muss ein Auto in der Lage sein, die Länge des Rennens zu fahren. Das bedeutet, dass seine
Batterie nicht leer wird, bevor es die Ziellinie überquert hat.

Implementiere die Funktion `can_finish`, die als Parameter ein `car` und ein `track` entgegennimmt und `TRUE` zurückgibt,
wenn das Auto das Rennen beenden kann; andernfalls gib `FALSE` zurück.

Gehe davon aus, dass du dich gerade an der Startlinie des Rennens befindest und den Motor des Autos für das Rennen startest.
Beachte, dass die Batterie des Autos beim Start des Rennens nicht unbedingt vollständig geladen sein muss.

```R
speed <- 5
battery_drain <- 5
car <- new_car(speed, battery_drain)

name <- "track1"
track_length <- 100
track <- new_track(track_length)

can_finish(car, track)
#> [1] TRUE

# partial battery charge
car$battery <- 50
can_finish(car, track)
#> [1] FALSE
```

## 6. Speichere, ob das Auto eine Strecke mit voller Batterie beenden kann

Du hast mehrere Strecken unterschiedlicher Länge erstellt und musst speichern, ob dein Auto sie mit voller Ladung
abschließen kann.

Implementiere die Funktion `store_track`, die ein Auto, eine Strecke und einen Streckennamen entgegennimmt und ein
aktualisiertes Auto mit einem zusätzlichen Element zurückgibt.
Dieses Element sollte den `name` der Strecke haben, und der Wert sollte eine Unterliste mit der `track_length` und
der Angabe sein, ob das Auto sie `complete` kann.

Das im Argument übergebene Auto ist möglicherweise nicht vollständig geladen, also setze die Batterie und die
zurückgelegte Strecke zurück, bevor du es verwendest.

```R
speed <- 5
battery_drain <- 5
car <- new_car(speed, battery_drain)
car$battery <- 50

name <- "track1"
track_length <- 100
track <- new_track(track_length)

track1 <- store_track(car, track, "Imola")
str(track1)
#> List of 5
#>  $ speed             : num 5
#>  $ battery_drain     : num 5
#>  $ battery           : num 100
#>  $ distance_traveled : num 0
#>  $ Imola             :List of 2
#>   ..$ track_length: num 100
#>   ..$ complete    : logi TRUE
```
