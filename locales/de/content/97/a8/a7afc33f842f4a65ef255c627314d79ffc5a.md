# Ergänzung der Anweisungen

## Arturo-spezifische Informationen

In dieser Übung sollst du die Alter in Form einer [physikalischen Größe] zurückgeben. Diese Größe verwendet eine eigene Einheit, die der Länge eines einzelnen Jahres auf dem jeweiligen Planeten entspricht.
In Arturo besteht eine Größe aus einem numerischen Betrag und einer zugehörigen [Maßeinheit][unit-of-measurement].

```arturo
length: 10`m
units length ; `m
scalar length ; 10

10`m * 10`m ; 100 m²
```

~~~~exercism/caution
Arturos eingebaute `yr-Einheit entspricht 31556952 Sekunden.
Deshalb musst du eine eigene Jahreseinheit definieren und verwenden, die auf der Anzahl der Sekunden aufbaut, die weiter oben in den Anweisungen genannt wurde.
~~~~

Größen kannst du in eine andere kompatible Einheit [umrechnen][convert].
```arturo
convert 1`m `ft ; 1250/381 ft
convert 100`m2 `ft2 ; 156250000/145161 ft²

property `m  ; length
property `m2 ; area

convert 1`m `m2 ; conversion error results
```

~~~~exercism/note
Wegen der begrenzten Genauigkeit von Gleitkommazahlen speichert Arturo den Skalar manchmal als rationale Zahl.
Mit der [`to`-Funktion][to] kannst du den Betrag stattdessen als ungefähre Gleitkommazahl abrufen.

```arturo
length: convert 1`m `ft ; 1250/381 ft
to :floating length ; 3.280839895013123
```

[to]: https://arturo-lang.io/documentation/library/types/to/
~~~~

Außerdem kannst du in Arturo mit [specify] eigene Einheiten für Größen festlegen.

```arturo
specify 'nauMile 1.151`mi
property `nauMile length
specify 'lea 3.00579`nauMile
property `lea ; length
depth: 20000`lea
convert depth `km ; 111355.7993425152 km
```
