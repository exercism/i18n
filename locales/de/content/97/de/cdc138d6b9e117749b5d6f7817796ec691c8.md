# Einführung

Über Zeichenklassen und Quantoren hinaus können reguläre Ausdrücke *Struktur* und *Kontext* beschreiben. Diese Möglichkeiten gehören zum selben Vokabular [`regexp`][regexp] und zum selben Literal `R/ /`.

Runde Klammern `( )` gruppieren einen Teil eines Musters, sodass ein Quantor oder ein `|` („dies oder das“) auf die ganze Gruppe wirkt; ein `?` nach einer Gruppe macht sie optional:

```factor
USING: regexp ;

"abab"    R/ (ab)+/ matches? .             ! => t
"$100"    R/ \$\d+(\.\d{2})?/ matches? .   ! => t   (optional group)
```

Anker legen ein Muster auf eine Position fest: `^` (Anfang), `$` (Ende) und `\b` (eine Wortgrenze).

Ein *Lookaround* gleicht anhand dessen ab, was eine Stelle umgibt, ohne sie zu konsumieren:

```
(?=...)    ! lookahead — ... must follow
(?!...)    ! negative lookahead — ... must not follow
(?<=...)   ! lookbehind — ... must come before
```

```factor
USING: regexp ;

"spent $100 and $25" R/ (?<=\$)\d+/ all-matching-subseqs .
! => { "100" "25" }

"up 5% then 12%" R/ \d+(?=%)/ all-matching-subseqs .
! => { "5" "12" }
```

Ein Optionsbuchstabe nach dem schließenden `/` ändert das ganze Muster;
`i` macht es unabhängig von Groß- und Kleinschreibung:

```factor
USING: regexp ;

"REFUND" R/ refund/i matches? .   ! => t
```

Factor verwendet Lookaround anstelle von Capture-Gruppen: Es gibt keine
Extraktion von Capture-Gruppen, keine Backreferences und keine lazy Quantoren.
