# Tests

Um den Test mit DrRacket auszuführen, öffnest du einfach die Testdatei und klickst auf den Button „Run“ oben rechts.

Um den Test über die Kommandozeile auszuführen, führst du im Verzeichnis der Übung folgenden Befehl aus:

```
raco test <exercise>-test.rkt
```

Dabei ersetzt du `<exercise>` durch den Slug der Übung.
