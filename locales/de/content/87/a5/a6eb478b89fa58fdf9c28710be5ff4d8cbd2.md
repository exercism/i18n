# Einführung

Eine `List` ist einem `Array` sehr ähnlich. Es gibt aber wichtige Unterschiede, die du nicht überspringen solltest:

1. Eine Liste kannst du nicht mit eckigen Klammern indizieren, also `[0]`.
2. Eine Liste kannst du nicht initialisieren.
3. Es gibt keine List Comprehensions.
4. Du kannst die Elemente einer Liste während der Iteration frei verändern.

`List` gehört zum Paket `haxe.ds`. Wenn du Listen verwenden willst, musst du das Paket importieren:

```haxe
import haxe.ds.List;

class Main {
  static function main() {
    var myList = List<Int>();

    for (i in 0...5) {
      myList.add(i);
    }

    trace(myList); // {0, 1, 2, 3, 4}
  }
}
```
