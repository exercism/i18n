# Anweisungen

In dieser Übung verarbeitest du Logzeilen.

Jede Logzeile ist ein String, der wie folgt formatiert ist: `"[<LEVEL>]: <MESSAGE>"`.

Es gibt drei verschiedene Log-Level:

- `INFO`
- `WARNING`
- `ERROR`

Du hast drei Aufgaben. Bei jeder bekommst du eine Logzeile und sollst etwas damit machen.

## 1. Nachricht aus einer Logzeile extrahieren

Implementiere die (_static_) Methode `LogLine.Message()`, um die Nachricht einer Logzeile zurückzugeben:

```csharp
LogLine.Message("[ERROR]: Invalid operation")
// => "Invalid operation"
```

Entferne führende oder nachfolgende Leerzeichen:

```csharp
LogLine.Message("[WARNING]:  Disk almost full\r\n")
// => "Disk almost full"
```

## 2. Log-Level aus einer Logzeile extrahieren

Implementiere die (_static_) Methode `LogLine.LogLevel()`, um das Log-Level einer Logzeile zurückzugeben, wobei es in Kleinbuchstaben zurückgegeben werden soll:

```csharp
LogLine.LogLevel("[ERROR]: Invalid operation")
// => "error"
```

## 3. Logzeile neu formatieren

Implementiere die (_static_) Methode `LogLine.Reformat()`, die die Logzeile neu formatiert: zuerst die Nachricht, danach das Log-Level in Klammern:

```csharp
LogLine.Reformat("[INFO]: Operation completed")
// => "Operation completed (info)"
```
