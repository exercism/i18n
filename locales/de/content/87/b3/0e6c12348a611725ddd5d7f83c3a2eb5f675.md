# Hinweise

## 1. Eine numerische Note in eine Buchstabennote umwandeln

- Verwende einen [`if-then-else`-Ausdruck][jq-man-if] mit so vielen `elif`-Zweigen wie nötig.

## 2. Die Anzahl der Schüler für jede Buchstabennote zählen

- Der `reduce`-Filter braucht einen _Stream_, über den er iterieren kann.
  Die Eingabe ist ein Objekt.
  Verwende den Ausdruck `to_entries`, um das Objekt in ein Array umzuwandeln.
- Das Ergebnisobjekt muss alle möglichen Buchstabennnoten als Schlüssel haben, auch wenn kein Schüler diese Note erreicht hat.
- Die [`+=`-Zuweisung][jq-man-arith-assign] wird nützlich sein.

[jq-man-if]: https://jqlang.org/manual/#if-then-else-end
[jq-man-arith-assign]: https://jqlang.org/manual/#arithmetic-update-assignment
