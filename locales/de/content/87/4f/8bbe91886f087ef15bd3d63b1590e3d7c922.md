# Über Strings

Ein [`string`][ref-string] in Kotlin ist eine unveränderliche Folge von Unicode-Zeichen.

`Immutable` bedeutet, dass jede Operation auf einem String einen neuen String zurückgeben muss: der ursprüngliche String kann sich niemals ändern.

`Unicode` bedeutet, dass die meisten Schriftsysteme der Welt dargestellt werden können, aber (im Gegensatz zu älteren Sprachen wie C) gibt es keine 1:1-Zuordnung zwischen Zeichen und Bytes.
Darauf wird im Konzept [`Chars`][concept-chars] noch genauer eingegangen.

Ein String wird von doppelten Anführungszeichen `" "` umschlossen.

Manche Zeichen muss man escapen: `\\`, dazu die üblichen nicht druckbaren Zeichen wie `\t` (Tabulator) und `\n` (Zeilenumbruch).

```kotlin
val s = "Escape backslash \\."
// Escape backslash \.
```

Mehrzeilige Strings werden von 3 doppelten Anführungszeichen umschlossen und können beliebigen Text enthalten (kein Escaping nötig).

```kotlin
val multi = """I'm a
    multi-line
    string with special characters \ \t """
//I'm a
//    multi-line
//    string with special characters  \ \t 
```

Verwende [trimIndent][trimIndent-doc], um die gemeinsame Einrückung von den Zeilen zu entfernen.
Das ist praktisch, um den String zu formatieren:

```kotlin
val multi = """
    I'm a
      multi-line
    string""".trimIndent()

//I'm a
//  multi-line
//string
```

Alternativ kannst du mit [trimMargin][trimMargin-doc] ein Trennzeichen festlegen.
Jede Zeile im `String` beginnt dann nach dem Trennzeichen.
Standardmäßig ist das Trennzeichen `|`, aber du kannst ein anderes Trennzeichen als Parameter angeben.
Zum Beispiel:

```kotlin
val multi = """
    |I'm a
    |  multi-line
    |string""".trimMargin()

//I'm a
//  multi-line
//string

val multi2 = """
    start>I'm a
    start>  multi-line
    start>string""".trimMargin("start>")

//I'm a
//  multi-line
//string
```

Strings kann man mit `+` verketten, aber das sollte man auf kurze und einfache Fälle beschränken.
Es gibt andere und oft bessere Möglichkeiten.

## String-Templates

`Templates` bezeichnet das, was andere Sprachen „Interpolation“ nennen.

Wenn ein String ein Dollarzeichen `$` enthält, gefolgt von einem Bezeichner, oder geschweifte Klammern (`{expression}`) um einen Ausdruck herum enthält, werden diese jeweils durch den Wert bzw. das Ergebnis des Ausdrucks ersetzt.

```kotlin
val x = 42
val st = "x is $x, x squared is {x * x}"
// x is 42, x squared is 1764
```

## String-Formatierung

Nur auf der JVM-Plattform erlaubt `String.format()` eine präzisere Formatierung als String-Templates, mit einer [Syntax][web-formats], die den (_sehr alten!_) [`printf`][wiki-printf]-Funktionen ähnelt.

```kotlin
String.format("%s %.3f", "π ≈", 3.14159)
//π ≈ 3.142
```

## String-Funktionen

Kotlin bietet _viele_ [`functions`][ref-string-functions], um Strings zu bearbeiten.

Meist sind das [`extensions functions`][ref-extensions] und keine Member der `String`-Klasse, was aber kaum Einfluss darauf hat, wie wir sie verwenden.

~~~~exercism/note
Kotlins recht komplexe [Dokumentationsseiten][ref-string-functions] verstecken Erweiterungsfunktionen in der Standardansicht.
Zum Zeitpunkt des Schreibens verbirgt sich der wertvollste Inhalt in einem Tab namens `Members & Extensions`.
Klick darauf, um diesen Abschnitt aufzuklappen und alle Member und Erweiterungen zu sehen, die in der `String`-Klasse verfügbar sind.

[ref-string-functions]: https://kotlinlang.org/api/core/kotlin-stdlib/kotlin/-string/
~~~~

Das folgende Beispiel zeigt nur eine kleine Auswahl dessen, was verfügbar ist:

```kotlin
val str = "Hello World!"

str.length              // => 12 (a property, not a function)
str.elementAt(6)        // => W
str.elementAtOrNull(20) // => null (index out of range)
str.substring(6, 11)    // => "World"
str.substringAfter(" ") // => "World!"

str.lowercase()         // => "hello world!"
str.uppercase()         // => "HELLO WORLD!"

str.startsWith("Hel")   // => true
str.endsWith("xyz")     // => false
str.indexOf("0")        // => 4

str.toCharArray()       // => [H, e, l, l, o,  , W, o, r, l, d, !]
"42".toInt() + 1        // => 43  (parsing; see also toFloat)

"Howdy!  ".trim()       // => "Howdy"
```

## Einen String aufbauen

Manchmal muss ein langer String schrittweise aufgebaut werden, zum Beispiel innerhalb einer Schleife.

Strings mit `+` zu verketten, ist schnell weder elegant noch performant: Unveränderlichkeit bedeutet, dass _sehr_ viel kopiert werden muss.

Kotlin bietet verschiedene effizientere Möglichkeiten, mehrere Strings zu kombinieren:

- String-Templates, wie oben beschrieben.
- [`joinToString()][ref-jointostring], das im Konzept [Lists][concept-lists] behandelt wird.
- Javas [`StringBuilder`][ref-stringbuilder], der nicht als besonders idiomatisches Kotlin gilt.
- Kotlins [`buildString()`][ref-buildstring], das `StringBuilder` in eine knappere und idiomatischere Syntax einpackt.
Es nimmt die Logik zum Aufbau des Strings als Lambda-Argument entgegen, was in einem späteren Konzept behandelt wird.

Im Kern ist ein `StringBuilder` eine listenähnliche Struktur mit vielen praktischen Methoden.
Hier eine kleine Auswahl:

- [`append()`][ref-sb-append], um etwas ans Ende anzuhängen.
- [`insert()`][ref-sb-insert], um an einer bestimmten Position einzufügen.
- [`deleteAt()`][ref-sb-deleteat] und [`deleteRange()`][ref-sb-deleterange], um an bestimmten Positionen zu löschen.
- `toString()`, um am Ende in einen normalen String umzuwandeln: alles in einer einzigen, performanten Operation zusammenfügen.

```kotlin
// Available, not recommended
val sb = StringBuilder()
sb.append("Hello ")
sb.append("World!")
sb.toString()
//Hello World!
```

Ein Beispiel für `buildString()`, das Syntax aus späteren Konzepten verwendet:

```kotlin
val countDown = buildString {
    for (i in 5 downTo 1) {
        append(i)
        append("_")
    }
}
// countDown is "5_4_3_2_1_"
```
