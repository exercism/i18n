# Einführung

Das ist möglicherweise ein _großes_ Thema!
Man kann ein ganzes Buch darüber schreiben, und einige Leute haben das auch getan (suche bei Amazon nach „unicode book“, um ein paar Beispiele zu sehen).

## Eine sehr kurze Geschichte

Der Umgang mit Zeichen in Computern war in früheren Jahrzehnten viel einfacher, als Programmierer davon ausgingen, dass Englisch die einzige wichtige Sprache sei.
Also: 26 Buchstaben, Groß- und Kleinschreibung, 10 Ziffern, ein paar Satzzeichen und ein Code (0x07), um eine Glocke klingeln zu lassen. Das alles passte in 7 Bit: der [ASCII][wiki-ascii]-Zeichensatz.

Natürlich fingen die Leute an zu fragen, was mit à, ä und Ł ist, dann fragten andere nach ऄ, ஹ und ญ, und junge Leute wollten Emojis 😱.
Was tun?

Um es kurz zu machen: Viele kluge und geduldige Menschen mussten jahrelang in Gremien sitzen und die Details des [Unicode][web-unicode]-Zeichensatzes und von Kodierungen wie [UTF-8][wiki-utf-8] ausarbeiten, und jede Menge Software musste _sehr_ aufwendig umgeschrieben werden.
Außerdem wurden jede Menge neue Bugs eingebaut.

Damit nicht _alles_ kaputtgeht, sorgt das Unicode/UTF-8-Design dafür, dass die ersten 127 Codes mit ASCII identisch sind _(sogar die Glocke)_.

## Zeichen in Kotlin

Sprachen, die nach etwa 2005 entworfen wurden, haben den großen Vorteil, dass bereits ein einigermaßen stabiler Unicode-Standard existierte.

Kotlin (erstmals 2011 veröffentlicht) konnte davon ausgehen, dass Nutzer verschiedene (menschliche) Sprachen verwenden und Unicode brauchen würden, um sie auszudrücken.

Zeichenliterale werden in einfache Anführungszeichen geschrieben und unterscheiden sich von Strings in doppelten Anführungszeichen.
Für Leute aus der C/C++-Welt ist das wahrscheinlich offensichtlich, für Python- und JavaScript-Programmierer aber möglicherweise verwirrend.

```kotlin
val a = 'a'
a::class.qualifiedName  // => kotlin.Char
a.code  // => 97

val jha = 'झ'  // Devanagari alphabet
jha.code  // => 2333

val heart = '❤'  // heart emoji
heart.code  // => 10084

Char.MAX_VALUE.code  // => 65535 (64k, the largest code point allowed)
```

Die Umwandlung zwischen `Char` und `Int` ist einfach:

```kotlin
a.code  // => 97  (a.toInt() is deprecated)
Char(97) // => 'a'
```

Der Compiler erlaubt _einige_ Formen ganzzahliger Arithmetik auf `Char`s:

```kotlin
'a' + 5       // => 'f'
'c' - 'a'   // => 2
'c' + 'a'   // => error!

'f' + ('A' - 'a')  // => 'F' (same as 'f'.uppercase()

'f'.dec() // => 'e' (decrement)
'f'.inc() // => 'g' (increment)
```

## Einige Funktionen für `Char`

Wie immer gibt es viel zu [viele Funktionen][ref-char-lib], um sie hier zu besprechen, deshalb ist das nur eine Auswahl.

- Für passende Alphabete änderst du die Groß-/Kleinschreibung mit [`uppercase()`][ref-uppercase] und [`lowercase()`][ref-lowercase].
- Die Groß-/Kleinschreibung prüfst du mit [`isUpperCase()`][ref-isuppercase] und [`isLowerCase()`][ref-islowercase].
- Den Zeichentyp prüfst du mit:
    - [`isLetter()`][ref-isletter], deckt viele Alphabete ab
    - [`isDigit()`][ref-isdigit], im Bereich 0..9
    - `isLetterOrDigit()`, kombiniert die beiden vorigen
    - [`isWhitespace()`][ref-iswhitespace], jedes beliebige Whitespace-Zeichen

```kotlin
'झ'.isLetter()      // => true
'A'.isLowerCase()   // => false
'4'.isDigit()       // => true
'\t'.isWhitespace() // => true  (tab character)
```

## Umwandlungen zwischen Char-Liste und String

Für die Umwandlung von String zu Char-Liste können wir `toList()` verwenden.

Für die Umwandlung von Char-Liste zu String gibt es die Funktion [`joinToString()`][ref-jointostring], die ein Trennzeichen (oft den leeren String) als Argument nimmt.

```kotlin
val kt = "kotlin".toList()  // => [k, o, t, l, i, n]
kt.joinToString("")   // => "kotlin"
kt.joinToString("_")  // => "k_o_t_l_i_n"
```

Beachte, dass `joinToString()` auf einer Liste oder einem Array arbeitet.
Um ein einzelnes `Char` in einen String mit einem Zeichen umzuwandeln _(casten)_, verwende `toString()`.

```kotlin
'a'.toString() // => "a"
```

Um zu prüfen, ob ein Zeichen in einem `String` oder einer `Char`-Liste bzw. einem `Char`-Array vorhanden ist, gibt es `in`, das auf die Funktion [`contains()`][ref-contains] verweist.

```kotlin
val clist = "kotlin".toList()  // => [k, o, t, l, i, n]
't' in clist     // => true
't' in "kotlin"  // => true
```
