# Ergänzung zur Anleitung

## Words

Definiere ein `rat`-Tupel mit den Slots `numerator` und `denominator`.
`<rat>` sollte seine Argumente so weit wie möglich kürzen, mit dem
Vorzeichen im Zähler (der Nenner ist also immer positiv).

- `<rat> ( numerator denominator -- rat )` – erzeugt eine gekürzte
  rationale Zahl.
- `>rat ( pair -- rat )` – baut ein `rat` aus `{ numerator denominator }`.
- `rat>pair ( rat -- pair )` – gibt `{ numerator denominator }` zurück.
- `r+ ( a b -- c )`, `r- ( a b -- c )`, `r* ( a b -- c )`,
  `r/ ( a b -- c )` – Rechenoperationen mit zwei rationalen Zahlen.
- `r-abs ( a -- |a| )` – Absolutbetrag.
- `r^ ( a n -- a^n )` – potenziert eine rationale Zahl mit einer ganzzahligen
  Potenz (negative Exponenten sind erlaubt).
- `real^r ( x a -- y )` – potenziert eine reelle Zahl mit einem rationalen
  Exponenten und gibt eine Gleitkommazahl zurück.

Die `MATH:`-Generics von Factor (`+`, `-`, `*`, `/`) sind nur für
die eingebaute Mathematik-Hierarchie definiert, deshalb verwendet diese
Übung eigene Word-Namen statt Methoden auf diesen Generics.
