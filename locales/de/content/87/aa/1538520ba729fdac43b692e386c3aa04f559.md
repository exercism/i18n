# Einführung

Destrukturierung ist eine Möglichkeit, zusammengesetzte Werte in Rust zu zerlegen. Häufig wird sie verwendet, um Felder aus Tupeln oder Structs zu extrahieren.

Das folgende Beispiel extrahiert zwei Werte aus einem Tupel:

```rust
let (first, second) = (1, 2);
```

Der Wert `1` wird an die Variable `first` gebunden.
Der Wert `2` wird an die Variable `second` gebunden.
