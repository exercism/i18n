# Assoziierte Elemente

Assoziierte Elemente sind Elemente, die in Traits deklariert oder in Implementierungen definiert werden.

Dazu gehören:

- **Assoziierte Funktionen** (wie Methoden)
- **Assoziierte Typen**
- **Assoziierte Konstanten**
- **Assoziierte Implementierungen**

Sie gruppieren logisch zusammengehörige Funktionalität mit einem Typ.

Zum Beispiel ist die Methode `is_some` in `Option` untrennbar mit `Option` verbunden.

## Assoziierte Typen

Assoziierte Typen definieren Platzhalter für Typen in Traits, die von den Implementierern festgelegt werden.

So bleiben Trait-Definitionen flexibel und knapp.

Beispiel:

```rust
trait Pack<T> {
    type Result;

    fn pack(self: T, other: T) -> Self::Result;
}

impl PackU32Impl of Pack<u32> {
    type Result = u64;

    fn pack(self: u32, other: u32) -> Self::Result {
        let shift: u64 = 0x100000000; // 2^32
        self.into() * shift + other.into()
    }
}
```

Hier ist `Result` ein assoziierter Typ, der von jeder Implementierung festgelegt wird.

Eine Funktion, die diesen Trait verwendet, muss keine zusätzlichen Generics angeben:

```rust
fn combine<T, impl PackImpl: Pack<T>>(a: T, b: T) -> PackImpl::Result {
    a.pack(b)
}
```

## Assoziierte Konstanten

Assoziierte Konstanten sind feste Werte, die an einen Typ gebunden und in einem Trait oder dessen Implementierung definiert sind.

Beispiel:

```rust
trait Shape<T> {
    const SIDES: u32;
    fn describe() -> ByteArray;
}

struct Triangle {}

impl TriangleShape of Shape<Triangle> {
    const SIDES: u32 = 3;
    fn describe() -> ByteArray {
        "I am a triangle."
    }
}

struct Square {}

impl SquareShape of Shape<Square> {
    const SIDES: u32 = 4;
    fn describe() -> ByteArray {
        "I am a square."
    }
}
```

Dadurch werden Konstanten wie `SIDES` an `Shape` gebunden, statt sie anderswo fest zu kodieren.

## Assoziierte Implementierungen

Assoziierte Implementierungen erzwingen Beziehungen zwischen Typen und Traits.

Zum Beispiel:

```rust
// Collection type that contains a simple array
#[derive(Drop)]
pub struct ArrayIter<T> {
    array: Array<T>,
}

// T is the collection type
pub trait Iterator<T> {
    type Item;
    fn next(ref self: T) -> Option<Self::Item>;
}

impl ArrayIterator<T> of Iterator<ArrayIter<T>> {
    type Item = T;
    fn next(ref self: ArrayIter<T>) -> Option<T> {
        self.array.pop_front()
    }
}

/// Turns a collection of values into an iterator
pub trait IntoIterator<T> {
    /// The iterator type that will be created
    type IntoIter;
    impl Iterator: Iterator<Self::IntoIter>;

    fn into_iter(self: T) -> Self::IntoIter;
}

impl ArrayIntoIterator<T> of IntoIterator<Array<T>> {
    type IntoIter = ArrayIter<T>;
    fn into_iter(self: Array<T>) -> Self::IntoIter {
        ArrayIter { array: self }
    }
}
```

Das garantiert, dass `Array` immer in einen Iterator (`IntoIter`) umgewandelt werden kann, was Konsistenz und Typsicherheit gewährleistet.
