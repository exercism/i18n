# Anweisungen

Es ist wieder eine geschäftige Nacht im Rangierbahnhof von Antwerpen. Du bist der diensthabende Disponent: Ankommende Güterwagen müssen zu ausgehenden Zügen umgruppiert, Kupplungen überprüft, Strecken an den Weichen getrennt und identische Ladungen für die Abrechnung zusammengefasst werden.

Jeder *Wagen* ist ein String, der angibt, was er geladen hat: `"coal"`, `"timber"`, `"crates"` usw.

## 1. Wagen zu Zügen kuppeln

Definiere `couple` so, dass es ein Array von Wagen und eine Länge `n` entgegennimmt und nicht überlappende Züge aus jeweils `n` Wagen zurückgibt. Der letzte Zug darf kürzer sein, wenn sich die Anzahl nicht gleichmäßig aufteilen lässt.

```factor
{ "coal" "coal" "coke" "ore" "ore" "timber" "timber" } 3 couple .
! => { { "coal" "coal" "coke" } { "ore" "ore" "timber" } { "timber" } }
```

## 2. Ein Blick auf die Kupplungen

Definiere `peek-couplings` so, dass es ein Array von Wagen entgegennimmt und jedes benachbarte Paar zurückgibt, damit der Prüfer jede Kupplung untersuchen kann.

```factor
{ "coal" "ore" "timber" "crates" } peek-couplings .
! => { { "coal" "ore" } { "ore" "timber" } { "timber" "crates" } }
```

## 3. Die Kette an den Weichen trennen

Definiere `split-at-junctions` so, dass es ein Array von Wagen und ein Array mit `junctions` (Wagen, die eine Trennstelle markieren) entgegennimmt und die Abschnitte zwischen den Weichenwagen zurückgibt. Die Weichenwagen selbst werden nicht behalten.

```factor
{ "coal" "coal" "switch" "ore" "switch" "timber" }
{ "switch" } split-at-junctions .
! => { { "coal" "coal" } { "ore" } { "timber" } }
```

## 4. Identische Ladung zusammenfassen

Definiere `coalesce-cargo` so, dass es ein Array von Wagen entgegennimmt und *aufeinanderfolgende* Wagen mit derselben Ladung zu Gruppen zusammenfasst.

```factor
{ "coal" "coal" "ore" "ore" "ore" "timber" "coal" } coalesce-cargo .
! => { { "coal" "coal" } { "ore" "ore" "ore" } { "timber" } { "coal" } }
```
