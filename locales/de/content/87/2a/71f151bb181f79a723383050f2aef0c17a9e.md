# Anleitung

Deine Nostalgie für Blorkemon™️-Karten lässt nicht nach. Du hast sogar wieder angefangen, sie zu sammeln, und bringst deine Freunde dazu, mitzumachen.

Bei dieser Übung wird eine Kartensammlung durch `Set(String)` dargestellt, da doppelte Karten keine Rolle spielen, wenn dein Ziel ist, alle vorhandenen Karten zu bekommen.

## 1. Starte eine Sammlung

Du möchtest unbedingt, dass deine Freunde bei deinem Blorkemon™️-Wahn mitmachen, und der beste Weg ist, ihre Sammlung mit einer einzigen Karte in Gang zu bringen.

Implementiere `new_collection`, das eine Karte in eine Sammlung umwandelt.

```gleam
new_collection("Newthree")
// -> set.from_list(["Newthree"])
```

## 2. Lass die Sammlung wachsen

Sobald du eine Sammlung hast, entwickelt sie ein Eigenleben und muss wachsen.

Implementiere `add_card`, das eine Karte und eine Sammlung entgegennimmt und ein Tupel mit zwei Werten zurückgibt: einen `Bool`, der angibt, ob die Karte bereits in der Sammlung war, und die Sammlung mit der hinzugefügten Karte.

```gleam
add_card(set.from_list(["Newthree"]), "Scientuna")
// -> #(False, set.from_list(["Newthree", "Scientuna"]))
```

## 3. Beginne zu handeln

Jetzt, wo deine Freunde wieder verrückt nach Blorkemon™️ sind, kannst du das nutzen, um deine eigene Sammlung durch Kartentausch zu vergrößern.

Nicht jeder Tausch lohnt sich oder ist überhaupt möglich.
Du kannst keine Karte tauschen, die du nicht hast, und du solltest keine Karte gegen eine tauschen, die du bereits hast.

Implementiere `trade_card`, das zwei Karten zum Tauschen (deine und ihre) und deine aktuelle Sammlung entgegennimmt.
Der Rückgabewert ist ein Tupel aus zwei Werten: ein `Bool`, der angibt, ob der Tausch möglich ist und sich lohnt, und die Sammlung, die du am Ende hättest, wenn du den Tausch durchführst (auch wenn er nicht wirklich möglich ist).

```gleam
trade_card("Scientuna", "Newthree", set.from_list(["Scientuna"]))
// -> #(True, set.from_list(["Newthree"]))
```

## 4. Karten, die alle haben

Du und deine begeisterten Blorkemon™️-Freunde trefft euch und fragt euch, welche Karten am häufigsten vorkommen.

Implementiere `boring_cards`, das eine Liste von Sammlungen entgegennimmt und eine sortierte Liste der Karten zurückgibt, die in allen Sammlungen vorkommen.

```gleam
boring_cards([set.from_list(["Scientuna"]), set.from_list(["Newthree", "Scientuna"])])
// -> ["Scientuna"]
```

## 5. Alle Karten

Besitzt du zusammen mit deinen Freunden alle Blorkemon™️-Karten?

Implementiere `total_cards`, das eine Liste von Sammlungen entgegennimmt und die Gesamtzahl der verschiedenen Karten in allen Sammlungen zurückgibt.

```gleam
total_cards([set.from_list(["Scientuna"]), set.from_list(["Newthree", "Scientuna"])])
// -> 2
```

## 6. Glänzend zum Sieg

Dein Neffe kommt dich bald besuchen, und du möchtest ihn beeindrucken.
Kinder mögen doch glänzende Dinge, oder?
Blorkemon™️-Karten können glänzend sein!

Implementiere `shiny_cards`, das eine Sammlung entgegennimmt und ein Set zurückgibt, das alle Karten enthält, die mit `"Shiny "` beginnen.

```gleam
shiny_cards(set.from_list(["Newthree", "Scientuna", "Shiny Scientuna"]))
// -> set.from_list(["Shiny Scientuna"])
```
