# Tools konfigurieren

Es gibt drei Tools, die du für deinen Track anpassen solltest:

- Der **[Codezeilen-Zähler](/docs/building/tooling/lines-of-code-counter)**: Dieses Tool hat die Aufgabe, die Codezeilen für jede eingereichte Iteration zu zählen.
- Der **[Snippet-Extraktor](/docs/building/tooling/snippet-extractor)**: Dieses Tool extrahiert für jede Iteration ein Snippet, das auf der Website angezeigt wird.
- Die **[Exercism CLI](/docs/building/tooling/cli)**: Dieses Tool wird von Lernenden genutzt, um lokal auf ihrem eigenen Rechner an einem Track zu arbeiten.

```exercism/note
Auch wenn das Anpassen dieser Tools optional ist, wird es die Integration deines Tracks in die Website _viel_ besser machen.
Deshalb empfehlen wir dir ausdrücklich, alle drei Tools anzupassen.
```
