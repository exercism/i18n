# Überblick

Eine Instanz einer _Klasse_ erstellst du, indem du ihren [_Konstruktor_][constructors] mit dem [`new`-Operator][new] aufrufst. Ein Konstruktor ist eine besondere Art von Methode, deren Aufgabe es ist, eine neu erstellte Instanz zu initialisieren. [Konstruktoren sehen wie reguläre Methoden aus][constructor-syntax], aber sie haben keinen Rückgabetyp und tragen den Namen der Klasse.

```csharp
class Library
{
    private books;

    public Library()
    {
        this.books = 10;
    }
}

// This will call the constructor
var library = new Library();
```

Wie reguläre Methoden können auch Konstruktoren Parameter haben. Die Parameter eines Konstruktors werden meist als (private) [Felder][fields] gespeichert, um später darauf zuzugreifen, oder sie werden für eine einmalige Berechnung verwendet. Argumente kannst du an Konstruktoren genauso übergeben wie an reguläre Methoden.

```csharp
class Building
{
    private int numberOfStories;
    private int totalHeight;

    public Building(int numberOfStories, double storyHeight)
    {
        this.numberOfStories = numberOfStories;
        this.totalHeight = numberOfStories * storyHeight;
    }
}

// Call a constructor with two arguments
var largeBuilding = new Building(55, 6.2);
```

Einen Konstruktor anzugeben ist optional. Gibst du keinen an, erzeugt der Compiler einen [parameterlosen Konstruktor][parameterless-constructors]:

```csharp
class Elevator
{
}

// This will call the (empty) generated constructor
var elevator = new Elevator();
```

Wenn Feldern ein Anfangswert zugewiesen wird, erzeugt der Compiler Code, in dem diese Zuweisung tatsächlich im Konstruktor ausgeführt wird. Die folgenden Klassendeklarationen sind daher (funktional) äquivalent:

```csharp
class UsingFieldInitialization
{
    private int players = 5;
}

class UsingConstructorInitialization
{
    private int players;

    public UsingConstructorInitialization()
    {
        players = 5;
    }
}
```
