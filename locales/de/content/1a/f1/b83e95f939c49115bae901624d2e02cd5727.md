# Hinweise

## Allgemein

- Eine Gleitkommazahl wird in `xmm0` zurückgegeben.
- Die ersten 8 Gleitkommaargumente werden in `xmm0` bis `xmm7` übergeben.

## 1. Berechne den Tagessatz bei gegebenem Stundensatz

- Eine Gleitkommazahl wird in `xmm0` zurückgegeben.
- Die ersten 8 Gleitkommaargumente werden in `xmm0` bis `xmm7` übergeben.
- Eine 64-Bit-Ganzzahl kann mit `cvtsi2sd` in eine Gleitkommazahl mit doppelter Genauigkeit umgewandelt werden.
- Ein Immediate-Wert (eine konstante Zahl) muss in einem Allzweckregister gespeichert werden, bevor er in eine Gleitkommazahl umgewandelt wird.
- Zwei Gleitkommazahlen mit doppelter Genauigkeit können mit `mulsd` multipliziert werden.

## 2. Berechne einen rabattierten Preis

- Eine Gleitkommazahl wird in `xmm0` zurückgegeben.
- Die ersten 8 Gleitkommaargumente werden in `xmm0` bis `xmm7` übergeben.
- Zwei Gleitkommazahlen mit doppelter Genauigkeit können mit `divsd` dividiert werden.
- Eine Gleitkommazahl mit doppelter Genauigkeit kann mit `subsd` von einer anderen subtrahiert werden.

## 3. Berechne den Monatssatz bei gegebenem Stundensatz und Rabatt

- Eine Gleitkommazahl wird in `xmm0` zurückgegeben.
- Die ersten 8 Gleitkommaargumente werden in `xmm0` bis `xmm7` übergeben.
- Du kannst `roundsd` verwenden, um eine Gleitkommazahl mit doppelter Genauigkeit zu runden, wobei ein dritter Operand den Rundungsmodus angibt.
- Die Zahl für das Aufrunden (Ceiling) ist `2`.
- Du kannst `cvtsd2si` verwenden, um eine Gleitkommazahl mit doppelter Genauigkeit in eine 64-Bit-Ganzzahl umzuwandeln.

## 4. Berechne die Anzahl der Arbeitstage bei gegebenem Budget, Stundensatz und Rabatt

- Eine Gleitkommazahl wird in `xmm0` zurückgegeben.
- Die ersten 8 Gleitkommaargumente werden in `xmm0` bis `xmm7` übergeben.
- Du kannst `roundsd` verwenden, um eine Gleitkommazahl mit doppelter Genauigkeit zu runden, wobei ein dritter Operand den Rundungsmodus angibt.
- Die Zahl für das Abrunden (Floor) ist `1`.
- Du kannst `cvtsd2si` verwenden, um eine Gleitkommazahl mit doppelter Genauigkeit in eine 32-Bit-Ganzzahl umzuwandeln.
