# Anleitung

In dieser Übung implementierst du ein Programm, das den Zustand eines [tic-tac-toe][]-Spiels bestimmt.
(_Vielleicht kennst du das Spiel auch als „noughts and crosses" oder „Xs and Os"._)

Das Spiel wird auf einem 3×3-Raster gespielt.
Die Spieler setzen abwechselnd `X`s und `O`s auf das Raster.
Das Spiel endet, wenn ein Spieler gewinnt, indem er drei seiner Markierungen in einer Reihe, einer Spalte oder einer Diagonale des Rasters platziert, oder wenn das gesamte Raster gefüllt ist.

In dieser Übung gehen wir davon aus, dass `X` beginnt.

Deine Aufgabe ist es, festzustellen, in welchem Zustand sich ein gegebenes Spiel befindet.

Es gibt drei mögliche Spielzustände:

- Das Spiel ist **ongoing**.
- Das Spiel endete mit dem Ergebnis **draw**.
- Das Spiel endete mit dem Ergebnis **win**.

Wenn das gegebene Spielfeld ungültig ist, wirf einen passenden Fehler.

Ein Spielfeld ist ungültig, wenn es die folgenden Bedingungen erfüllt:

- Das gegebene Spielfeld kann nicht erreicht werden, wenn die Züge in der richtigen Reihenfolge ausgeführt werden (denk daran, dass `X` beginnt).
- Das Spiel wurde fortgesetzt, nachdem es bereits beendet war.

## Beispiele

### Laufendes Spiel

```text
   |   |
 X |   |
___|___|___
   |   |
   | X | O
___|___|___
   |   |
 O | X |
   |   |
```

### Unentschieden

```text
   |   |
 X | O | X
___|___|___
   |   |
 X | X | O
___|___|___
   |   |
 O | X | O
   |   |
```

### Sieg

```text
   |   |
 X | X | X
___|___|___
   |   |
   | O | O
___|___|___
   |   |
   |   |
   |   |
```

### Ungültig

#### Falsche Zugreihenfolge

```text
   |   |
 O | O | X
___|___|___
   |   |
   |   |
___|___|___
   |   |
   |   |
   |   |
```

#### Nach dem Sieg weitergespielt

```text
   |   |
 X | X | X
___|___|___
   |   |
 O | O | O
___|___|___
   |   |
   |   |
   |   |
```

[tic-tac-toe]: https://en.wikipedia.org/wiki/Tic-tac-toe
