# Anweisungen

In dieser Übung schreibst du Code, um eine Liste von Programmiersprachen im Blick zu behalten, die du auf Exercism lernen möchtest.
Du hast sechs Aufgaben, bei denen es immer um Listen geht.

## 1. Eine neue Liste erstellen

Um die Sprachen im Blick zu behalten, die du lernen möchtest, brauchst du eine neue Liste.
Definiere die Konstante `newList`, die eine neue, leere Liste enthält.

```elm
newList
    --> []
```

## 2. Eine vorhandene Liste definieren

Momentan hast du einen Zettel, auf dem die Sprachen stehen, die du lernen möchtest: Elm, Clojure und Haskell.
Definiere die Konstante `existingList`, die diese Liste repräsentiert.

```elm
existingList
    --> [ "Elm", "Clojure", "Haskell" ]
```

## 3. Eine neue Sprache zu einer Liste hinzufügen

Wenn du Exercism erkundest und weitere interessante Sprachen findest, möchtest du sie deiner Liste hinzufügen.
Implementiere die Funktion `addLanguage`, um eine neue Sprache an den Anfang deiner Liste hinzuzufügen.

```elm
addLanguage "TypeScript" [ "JavaScript", "CoffeeScript" ]
    --> [ "TypeScript", "JavaScript", "CoffeeScript" ]
```

## 4. Die Sprachen in der Liste zählen

Es ist unpraktisch, die Sprachen manuell zu zählen.
Implementiere die Funktion `countLanguages`, um die Anzahl der Sprachen in deiner Liste zu zählen.

```elm
countLanguages [ "C#", "Racket", "Rust", "Ruby" ]
    --> 4
```

## 5. Die Liste umkehren

Irgendwann stellst du fest, dass deine Liste tatsächlich rückwärts angeordnet ist!
Implementiere die Funktion `reverseList`, um deine Liste umzukehren.

```elm
reverseList [ "Prolog", "C", "Idris", "Assembly" ]
    --> [ "Assembly", "Idris", "C", "Prolog" ]
```

## 6. Prüfen, ob eine Liste spannend ist

Du liebst zwar alle Sprachen, aber Elm hat einen besonderen Platz in deinem Herzen.
Deshalb bist du von einer Liste von Sprachen richtig begeistert, wenn:

- Das erste Element der Liste Elm ist.
- Oder das zweite Element der Liste Elm ist und die Liste drei oder weniger Sprachen enthält.

Implementiere die Funktion `excitingList`, um zu prüfen, ob eine Liste von Sprachen spannend ist:

```elm
excitingList [ "Nim", "Elm" ]
    --> True
```
