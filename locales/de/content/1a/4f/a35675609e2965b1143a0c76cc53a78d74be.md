# Einführung
## Switch

Eine [switch-Anweisung][switch] ermöglicht es dir, einen Wert mit mehreren möglichen übereinstimmenden Werten zu vergleichen.
Damit kannst du prägnanteren Code schreiben als mit mehreren `else-if`-Anweisungen.
Eine switch-Anweisung beginnt mit dem Schlüsselwort `switch`, gefolgt von dem Wert, der verglichen werden soll.
Danach definierst du die Fälle mit dem Schlüsselwort `case`, gefolgt von dem Wert, mit dem verglichen wird.
Mit dem Schlüsselwort `default` definierst du den Standardfall, wenn keiner der Fälle passt.
Wie `else-if`-Anweisungen führen `switch`-Anweisungen nur den Block aus, der zum ersten passenden Fall gehört.

```swift
switch value {
case 1:
    print("One")
case 2:
    print("Two")
default:
    print("Other")
}
```

Schauen wir uns das folgende Beispiel an:

```swift
if str == "apple" {
    print("Let's bake an apple crumble")
} else if str == "lemon" {
    print("Let's bake a lemon meringue pie!")
} else if str == "peach" {
    print("Let's bake a peach pie!")
} else {
    print("Let's buy ice cream.")
}
```

Das lässt sich stattdessen auch so schreiben:

```swift
switch str {
case "apple":
    print("Let's bake an apple crumble")
case "lemon":
    print("Let's bake a lemon meringue pie!")
case "peach":
    print("Let's bake a peach pie!")
default:
    print("Let's buy ice cream.")
}
```

## while-Schleifen

Eine [while-Schleife][while-loops] ist eine Anweisung, mit der du Code so lange ausführen kannst, wie eine bestimmte Bedingung wahr ist.
Swift bietet zwei Arten von while-Schleifen: while- und repeat-while-Schleifen.
Bei einer while-Schleife wird die Bedingung ausgewertet, bevor der Schleifenblock ausgeführt wird. Ist die Bedingung falsch, wird der Schleifenblock gar nicht ausgeführt.
while-Schleifen haben in Swift folgenden Aufbau:

```swift
while <#condition#> {
  <#code#>
}
```

Hier wird die Schleife so lange ausgeführt, wie count größer als 0 ist, und gibt dabei die Zahlen 2, 1 und „Liftoff!“ aus.

```swift
var count = 2
while count > 0 {
  print("\(count)…")
  count -= 1
}
print("Liftoff!")

// prints:
// 2…
// 1…
// Liftoff!
```

Eine [repeat-while-Schleife][while-loops] ähnelt einer while-Schleife, doch die Bedingung wird ausgewertet, nachdem der Schleifenblock ausgeführt wurde.
Das heißt, der Schleifenblock wird immer mindestens einmal ausgeführt, selbst wenn die Bedingung falsch ist.
repeat-while-Schleifen haben in Swift folgenden Aufbau:

```swift
repeat {
  <#code#>
} while <#condition#>
```

Hier wird die Schleife nur einmal ausgeführt, da die Bedingung falsch ist.
Da es eine repeat-while-Schleife ist, wird der Schleifenblock einmal ausgeführt, bevor die Bedingung ausgewertet wird.

```swift
var count = 2
repeat {
  print("\(count)…")
} while count < 0
print("Liftoff!")
```

## Kontrollübertragung

Swift hat einige Anweisungen, mit denen du den normalen Kontrollfluss von Schleifen ändern kannst.
Man nennt sie Kontrollübertragungsanweisungen.
`return` kennst du bereits; in diesem Konzept lernst du weitere kennen, darunter `continue`, `break` und Labels.
`fallthrough` behandeln wir in diesem Konzept nicht, aber du kannst im [Swift-Buch][fallthrough] darüber lesen.

### Continue

Manchmal ist es nötig, vorzeitig zur nächsten Iteration einer Schleife zu springen, ohne die übrigen Anweisungen in der aktuellen Iteration der Schleife auszuführen.
Dafür kannst du das Schlüsselwort `continue` verwenden.
Wenn `continue` ausgeführt wird, springt die Schleife zur nächsten Prüfung, ob die nächste Iteration der Schleife ausgeführt werden kann, also zum `while` in while- und repeat-while-Schleifen oder zur Prüfung, ob die Sequenz in for-in-Schleifen ein weiteres Element enthält.

```swift
count = 1
while count < 6 {
  count += 1
  if count == 4 { continue }
  print(count)
}

// prints:
// 2
// 3
// 5
```

### Break

Break wird verwendet, um eine Schleife vorzeitig zu verlassen.
Wenn `break` ausgeführt wird, wird die Schleife sofort beendet und das Programm fährt mit der ersten Anweisung nach der Schleife fort.

```swift
for fruit in ["banana", "grapes", "apple", "strawberry", "kiwi", "lemon"] {
  if !fruit.count.isMultiple(of: 2) { break }
  print(fruit)
}

// prints:
// banana
// grapes
```

### Labels

Wenn Schleifen verschachtelt sind, kann es vorkommen, dass du mit `break` oder `continue` die äußeren Schleifen verlassen oder neu starten möchtest, die die Schleife enthalten, in der `break` oder `continue` stehen.
In solchen Fällen kannst du mit Labels angeben, welche Schleife verlassen oder neu gestartet werden soll.
Du kannst eine Schleife mit einem Label versehen, indem du einen Namen gefolgt von einem Doppelpunkt vor das `while`, `repeat` oder `for` setzt, das die Schleife beginnt.

Um die Wirkung von Labels zu sehen, schauen wir uns die folgende Schleife an.

```swift
outerLoop: for fruit in ["banana", "grapes", "apple", "strawberry", "kiwi", "lemon"] {
  print("\n--- \(fruit) ---")
  for letter in fruit {
    guard letter != "n" else { break outerLoop }
    print(letter)
  }
}

// prints:
// --- banana ---
// b
// a
```
