# Einführung

## Hintergrund

Eine Zeichenkette ist ein Stück Text zwischen Anführungszeichen.
Jede aktuell unterstützte R-Version kodiert Zeichenketten in UTF-8, deshalb lassen sich die meisten Sprachen der Welt abdecken.

```R
mystring <- "some text"
mystring
#> [1] "some text"
typeof(mystring)
#> [1] "character"
```

Leider kann die Terminologie für Programmierer verwirrend sein, die andere Sprachen kennen.

Obwohl der `type` `character` ist, unterscheidet R nicht zwischen einem einzelnen Buchstaben (in einigen anderen Sprachen `char` genannt, in R aber _nicht_) und einer langen Zeichenkette.
Beides ist ein einzelnes Element und kann wahlweise in einfachen `' '` oder doppelten `" "` Anführungszeichen stehen.

Der Styleguide empfiehlt doppelte Anführungszeichen, außer wenn du doppelte Anführungszeichen innerhalb der Zeichenkette verwenden möchtest, ohne sie zu escapen.

```R
str2 <- 'String with "quotes"'  # convenience format
str2
#> [1] "String with \"quotes\""    # standard format
```

Ein `character vector` ist also ein Vektor von Zeichenketten, wobei jede Zeichenkette ein einzelnes Element ist.

```R
s <- c("some", "strings")
s
#> [1] "some"    "strings"
length(s)
#> [1] 2
length(s[1])  # the number of vector elements, not the string length
#> [1] 1

nchar(s[1])  # the number of characters in the string "some"
#> [1] 4
```

Im obigen Beispiel ist `length(s[1])` gleichbedeutend mit `length("some")`: die Anzahl der _Vektorelemente_, nicht die _Länge der Zeichenkette_.

Eine einzelne Zeichenkette zu bearbeiten ist natürlich möglich, wie bei `nchar()` im obigen Beispiel, erfordert aber bestimmte Funktionen, die weiter unten besprochen werden.

### Zeichenkettenfunktionen

In base R ist vieles _möglich_, aber viele Programmierer finden die Unterstützung für die Bearbeitung von Zeichenketten recht begrenzt und verwirrend.

Zum Glück gibt es `tidyverse`-Pakete, die viel intuitiver, flexibler und in sich konsistent sind.

### Base R

Es gibt immer noch viel Legacy-Code, der Zeichenkettenfunktionen im alten Stil verwendet.
Dazu gehören die meisten Community-Lösungen auf Exercism.

Außerdem kann es bei kleinen Aufgaben nützlich sein, eingebaute Funktionen zu verwenden, statt eine große Bibliothek zu importieren.
Die Maintainer des R-Tracks wählen diesen Ansatz gerne, wenn sie Musterlösungen schreiben, um die Übungen zu validieren.

Deshalb lohnt es sich nach wie vor, die alten Ansätze ein wenig kennenzulernen.

#### `nchar`

Gibt die Anzahl der Zeichen in einer Zeichenkette zurück.

```R
nchar("string")
#> [1] 6

nchar("Hrōðgār") # a person in Beowulf, written in Old English
#> [1] 7
```

Das Thema, was „character“ eigentlich bedeutet, ist (_kompliziert!_) und geht über unseren Rahmen hinaus.
Beachte nur ein paar Punkte in den Beispielen oben:

- Zeichenketten sind in R intern zwar in C implementiert, aber nicht `\0`-terminiert (was 1 zur Länge hinzufügen würde).
- Mehrbyte-Unicode-Zeichen werden so behandelt, wie du es erwartest oder erhoffst. „Hrōðgār“ hat 7 Zeichen (auch „Runen“ oder „Codepunkte“ genannt), braucht aber 10 Byte Speicher.

#### `paste` und `paste0`

Kombiniert eine beliebige Anzahl von Zeichenketten zu einer einzigen Zeichenkette.

Optional kann für `paste` ein Trennzeichen angegeben werden: Standard ist ein Leerzeichen.

`paste0(v)` entspricht `paste(v, sep = "")`.

```R
paste("bits", "of", "a", "string")
#> [1] "bits of a string"
paste0("bits", "of", "a", "string")
#> [1] "bitsofastring"
```

#### `sprintf`

Für eine feinere Kontrolle beim Zusammensetzen von Zeichenketten übernimmt R die Funktion `sprintf` aus C (und mehreren späteren Sprachen: Wikipedia [listet][wiki-printf-ports] etwa 30 auf).

```R
r <- 5.3
pi <- 3.14159
sprintf("A circle of radius %.1f has area %.2f", r, pi * r^2)
#> [1] "A circle of radius 5.3 has area 88.25"
```

#### `trimws`

Führende und/oder nachfolgende Leerzeichen lassen sich mit `trimws()` entfernen:

```R
s <- "    messy string   "
trimws(s)
#> [1] "messy string"
```

Es gibt einen Parameter `which = "left"` (oder "right"), um zu vermeiden, dass an beiden Enden getrimmt wird.

#### `substr`

Wirkt auf eine einzelne Zeichenkette und gibt die Teilzeichenkette zwischen zwei (inklusive) Grenzen zurück.

```R
substr("Exercism", 5, 7)
#> [1] "cis"
```

#### `strsplit`

Zerlegt eine Zeichenkette anhand einer Zeichenkette als Trennzeichen in eine R-Liste.
Das Trennzeichen ist erforderlich (es gibt keinen Standardwert), kann aber eine leere Zeichenkette sein.

```R
strsplit("R, Python, Julia", ", ")
[[1]]
#> [1] "R"      "Python" "Julia" 

strsplit("Exercism", "")
[[1]]
#> [1] "E" "x" "e" "r" "c" "i" "s" "m"
```

Listen werden in einem eigenen [Konzept][concept-lists] behandelt.
Wenn du diesen Teil des Lehrplans noch nicht erreicht hast, merke dir vorerst nur, dass die Funktion `unlist()` (in diesem Fall) eine Liste in einen Vektor umwandelt.

```R
unlist(strsplit("Exercism", ""))
#> [1] "E" "x" "e" "r" "c" "i" "s" "m"
```

### Tidyverse

Wohlwollend formuliert könnte man sagen, dass die Zeichenkettenfunktionen im alten Stil nicht das Beste sind, was R zu bieten hat (_es gibt auch weniger wohlwollende Meinungen_).

Um die Lage zu verbessern, wird die Bibliothek `stringr` seit 2009 entwickelt und ist heute ein zentraler Teil der Tidyverse-Sammlung.

Importiere sie mit `library(stringr)` oder `library(tidyverse)` in deinen Namensraum.

Einige wichtige Merkmale sind:

- Alle Funktionsnamen haben das Präfix `str_` und sollen ihren Zweck klar erkennbar machen.
- Die Reihenfolge der Argumente ist möglichst einheitlich, wobei die Eingabedaten das erste Argument sind.
- Die Eingaben reichen von einer einzelnen Zeichenkette bis zu komplexen Datenstrukturen. Die Funktionen versuchen, sich anzupassen, und tun das Sinnvollste.

Wie alle Tidyverse-Pakete hat `stringr` eine gute Dokumentation, die meist von den Autorinnen und Autoren des Pakets geschrieben wird.

- Eine [Referenz-Website][ref-stringr]
- Ein [Cheatsheet][cheat-stringr]
- Ein [Kapitel][book-strings] in „R for Data Science“.

#### Abschweifung: Eine kurze Einführung in Pipes

Die Verwendung von Pipes `|>` zum Verbinden von Funktionen wird an anderen Stellen des Lehrplans ausführlicher behandelt.

Für den Moment ist es nützlich zu wissen, dass:

- Ein Ergebnis links von der Pipe zum ersten Argument der Funktion rechts davon wird (wobei „rechts“ optionale Zeilenumbrüche ignoriert).
- Alle übrigen Argumente können im Funktionsaufruf angegeben werden.
- In R müssen wir an einen Funktions_aufruf_ pipen, nicht nur an einen _Namen_, daher sind runde Klammern immer erforderlich (_anders als in einigen anderen Sprachen_).

Das folgende Beispiel veranschaulicht die Syntax.
Die einzelnen Funktionen werden später besprochen.

```R
library(stringr)

"Monday-25-February" |> 
  str_split("-") |>     
  unlist() |>               # [1] "Monday"   "25"       "February"
  str_sub(1, 3) |>          # [1] "Mon" "25"  "Feb"
  str_to_upper() |>         # [1] "MON" "25"  "FEB"
  str_flatten(collapse = ", ")
#> [1] "MON, 25, FEB"
```

#### Längen verwalten

`str_length` zählt Codepunkte (ähnlich wie `nchars`).

Verschiedene andere Funktionen bearbeiten Leerzeichen, darunter `str_trim()` und `str_squish()`.
Das ist oft eine wichtige Aufräumarbeit am Anfang jedes Data-Science-Projekts.

```R
# The first 3 kernels in JuPyteR notebooks:
str_length(c("Julia", "Python", "R"))           #> [1] 1 6 5
#> [1] 5 6 1
str_pad(c("Julia", "Python", "R"), 8, "right")  # add spaces if necessary
#> [1] "Julia   " "Python  " "R       "

str_trim("Julia    Python    R    ")   # remove leading & trailing whitespace
#> [1] "Julia    Python    R"
str_squish("Julia   Python  R    ")  # trim, collapse multiple spaces 
#> [1] "Julia Python R"
```

#### Teilzeichenketten entnehmen

Die Funktion `str_sub(string, start, end)` gibt die Teilzeichenkette von `start` bis `end` (einschließlich) zurück, während `str_sub_all()` mehrere Zeichenketten bearbeiten kann.

Das Ganze ist sehr flexibel.
`start` und `end` stehen standardmäßig für das erste bzw. letzte Zeichen.
Sie können Vektoren von Indizes sein.
Erfreulicherweise zählen negative Werte, anders als bei der Vektorindizierung, vom Ende der Zeichenkette rückwärts, wie in Python.

```R
s <- "abcdefgh"
str_sub(s, 2, 4)
#> [1] "bcd"
str_sub(s, 5)
#> [1] "efgh"
str_sub(s, -3, -2)
#> [1] "fg"
str_sub(s, c(1, 4), c(2, 5))
#> [1] "ab" "de"
str_sub(s, c(1, 4, 6), c(2, 5, -1))
#> [1] "ab"  "de"  "fgh"

s |> str_sub(2, 4) # these functions are designed for pipes
#> [1] "bcd"
```

#### Zeichenketten verbinden

`str_flatten` wandelt einen Zeichenvektor in eine einzelne Zeichenkette um.
Das Argument `collapse` wird zwischen die einzelnen Elemente eingefügt und hat den Standardwert `""`.

```R
c("R", "Julia", "Python") |> str_flatten()
#> [1] "RJuliaPython"
c("R", "Julia", "Python") |> str_flatten(collapse = " - ")
#> [1] "R - Julia - Python"
```

`str_c` wandelt mehrere Zeichenvektoren in einen einzelnen Zeichenvektor um, wobei bei Bedarf recycelt wird.

```R
str_c(LETTERS[1:8], 1:8, sep = ":")
#> [1] "A:1" "B:2" "C:3" "D:4" "E:5" "F:6" "G:7" "H:8"
```

`str_glue` bringt einfache Zeichenketteninterpolation nach R.
Ausdrücke in geschweiften Klammern `{ }` werden ausgewertet und ihre Textdarstellung wird eingesetzt.

```R
r <- 5.3
pi <- 3.14159
str_glue("A circle of radius {r} has area {pi * r^2}")
A circle of radius 5.3 has area 88.2472631
```

#### Zeichenketten zerlegen

Eine sehr häufige Verwendung von R besteht darin, unordentliche Daten für die Analyse in ein einheitliches Format zu bringen.
Um das zu erleichtern, gibt es mehrere Möglichkeiten, Text in Teilzeichenketten zu zerlegen.
Die meisten davon gehen über den hier behandelten Umfang hinaus.

`str_split_1` ist die einfachste: Sie wandelt eine einzelne Zeichenkette in einen Vektor von Teilen um, die an einem angegebenen Muster getrennt werden (ein Standardmuster gibt es nicht).

```R
s <- "R Julia Python"
str_split_1(s, " ")
#> [1] "R"      "Julia"  "Python"
```

#### Zeichenketten verändern

Einige Sprachen (vor allem europäische) unterscheiden zwischen Groß- und Kleinbuchstaben.
Es gibt eine Reihe von `stringr`-Funktionen, mit denen sich diese umwandeln lassen, und zwar passend zur jeweiligen Locale:

- `str_to_lower()`
- `str_to_upper()`
- `str_to_title()` : erster Buchstabe jedes Wortes groß
- `str_to_sentence()` : erster Buchstabe des Satzes groß

```R
str_to_upper("elixir")    # defaults to locale = "en"
#> [1] "ELIXIR"
str_to_upper("ελληνικά")  # infers Greek
#> [1] "ΕΛΛΗΝΙΚΆ"

str_to_title("the cat sat on the mat")
#> [1] "The Cat Sat On The Mat"
str_to_sentence("the cat sat on the mat")
#> [1] "The cat sat on the mat"
```

Für das Ersetzen von Teilzeichenketten per Mustersuche ändert `str_replace()` das erste Vorkommen des Musters, `str_replace_all()` alle Vorkommen.

Für das Ersetzen von Teilzeichenketten über Zeichenindizes gibt es eine Zuweisungsform von str_sub().

```R
 s <- "abcde"
str_sub(s, 3, 4) <- "yz"
s
#> [1] "abyze"
```
