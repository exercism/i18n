# Tests

  ## Kurzer Überblick

  1. Nimm deine Änderungen in der Datei `<myFileName>.u` vor
  2. Speichere die Datei `<myFileName>.u`
  3. Wenn die Datei die Typprüfung besteht, führe die UCM-Befehle `add` oder `update` aus
    * Wenn die Datei die Typprüfung nicht besteht, ändere den Code in deiner Datei `<myFileName>.u` so lange, bis er kompiliert. Denk daran, deine Funktionen nach deinen Änderungen mit `update` zu aktualisieren!
  4. Führe den Befehl `load <myFileName>.test.u` in der UCM-Kommandozeile aus, um die Tests in den Gültigkeitsbereich zu holen und sie auszuführen

  ## Schritt für Schritt

  Wenn du an einer Exercism-Übung auf der Kommandozeile arbeitest, implementierst du deine Lösung höchstwahrscheinlich in dem Verzeichnis, das nach der jeweiligen Übung benannt ist. Wenn die Übung zum Beispiel `hello-world` heißt, solltest du die `ucm` von der Kommandozeile aus öffnen, nachdem du mit `cd` in `~/exercism/unison/hello-world` gewechselt bist. Nimm deine Änderungen an der Implementierung in der Datei `hello.u` vor, und wenn du mit deiner Implementierung zufrieden bist, gib den Befehl `add` oder `update` in der Kommandozeile des Unison Codebase Managers (UCM) ein, um deine Arbeit aus der Datei in die Codebase zu übernehmen.

  Die Datei, die die Tests für jede Übung enthält, hat die Endung `.test.u`. Am besten verwendest du den Befehl `load` in der UCM, um die Tests in den Gültigkeitsbereich zu holen und sie auszuführen. Der Befehl `load` nimmt einen Dateipfad als Argument. Für die Übung hello world könnte das so aussehen:

  ```
  .> load hello.test.u
  ```

  Du solltest eine Meldung von der UCM über die Begriffe sehen, die in den Gültigkeitsbereich geholt wurden, und, was wichtig ist, das Ergebnis des Testlaufs:

  ```

    ⍟ These new definitions are ok to `add`:

      hello.test : Test.Test
      tests      : [Result]

  Now evaluating any watch expressions (lines starting with
  `>`)... Ctrl+C cancels.


    6 | test> tests = runAll [hello.test]

    🚫 FAILED
  ```

  Angenommen, deine Tests sind beim ersten Mal nicht durchgelaufen. Wechsle zurück zum Bearbeiten deiner Datei `myExercise.u`, und nach dem Speichern kannst du `update` ausführen

  ```
  I found and typechecked these definitions in ~/Exercism/unison/hello-world/hello.u. If you do an
  `add` or `update`, here's how your codebase would change:

    ⍟ These names already exist. You can `update` them to your new definition:

      hello : Text

  .> update

  ⍟ I've updated these names to your new definition:

    hello : Text
  ```

  Als Nächstes können wir unsere Tests neu laden, um zu sehen, ob sich etwas geändert hat!

  ```
  .> load hello.test.u
    Now evaluating any watch expressions (lines starting with `>`)... Ctrl+C cancels.


    6 | test> tests = runAll [hello.test]

    ✅ Passed : Passed 1 tests.
  ```
