# Vergleiche boolesche Werte nicht mit true oder false

Boolesche Werte mit true oder false zu vergleichen, ist überflüssig.
Der Operator `==` liefert einen booleschen Wert, deshalb ist es unnötig, ihn mit einem weiteren fest im Code stehenden booleschen Wert zu vergleichen.
Wenn du den booleschen Wert umkehren möchtest, verwende den Operator `!`.

```crystal
# Rather than:
some_bool == true
some_bool == false

# Consider:
some_bool
!some_bool
```
