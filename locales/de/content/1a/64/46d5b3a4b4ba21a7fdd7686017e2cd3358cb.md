# Debuggen

Um beim Debuggen zu helfen, kannst du die Tatsache nutzen, dass alle Konsolenausgaben erfasst und im Testergebnisfenster angezeigt werden.
Du kannst jeden beliebigen Wert ausgeben, indem du ihn an `@show` übergibst.

`@show` zeigt einen Ausdruck und sein Ergebnis an und gibt dabei sein Ergebnis zurück.

```julia
@show uppercase("hello") # HELLO will be shown as debug output
```

```julia-repl
julia> function f(a, b)
           @show a b
           return (@show a^b) / 1000
       end
f (generic function with 1 method)

julia> f(3, 5)
a = 3
b = 5
a ^ b = 243
0.243
```

Du kannst auch [`println`](https://docs.julialang.org/en/v1/base/io-network/#Base.println) oder jede andere Methode verwenden, die Ausgaben nach [`stdout`](https://en.wikipedia.org/wiki/Standard_streams#Standard_output_(stdout)) schreibt.
