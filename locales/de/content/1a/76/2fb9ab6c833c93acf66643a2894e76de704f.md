## 2. Schreibe einen Iterator-Adapter `evens`, der die geraden Elemente aus einem beliebigen Iterator zurückgibt

- Verkette einfach die vorgeschlagenen Methoden miteinander, dann funktioniert alles.
- Eine Zahl `n` ist gerade, wenn `n % 2 == 0` gilt.
- Eine Closure ist eine Funktion mit verkürzter Syntax: Die Argumentnamen stehen zwischen zwei `|`-Zeichen, und danach folgt der Ausdruck.
  Anders als bei normalen Funktionen musst du nicht immer den Typ jedes Arguments angeben, der Name genügt.
  So kannst du zum Beispiel einen Iterator mit ungeraden Quadratzahlen erzeugen: `(0..).map(|n| 2 * n + 1).map(|n| n * n)`.

## 3. Implementiere eine `manhattan`-Methode für eine `Position`-Tupelstruktur

- Mach dir keine Gedanken über die Methodensyntax; es genügt, den `todo`-Teil innerhalb des `impl Position`-Blocks zu ersetzen, dann macht der Code das Richtige.
- Bedenke, dass einige Werte in einer `Position` negativ sein können, eine Distanz aber niemals negativ ist.
- Die Berechnung des Absolutwerts wird irgendwann in Cairo nativ unterstützt. Bis dahin haben wir ein Hilfs-Trait bereitgestellt, das du verwenden kannst.
