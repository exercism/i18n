# Hinweise

## Allgemein

- `MACRO:` steht in [`macros`][macros]. Die Bausteine findest du in
  `kernel` (`dup`, `curry`), `sequences` (`append`, `concat`,
  `<repetition>`, `map`) und `quotations` (`>quotation`).
- Ein Makro-Rumpf muss **ein Quotation** auf dem Stack hinterlassen. Wenn
  dein Rumpf ein Array aus Code erzeugt, schließe mit `>quotation` ab.
- Um dein Denken zu überprüfen, führe die Wörter des Rumpfs im Listener
  auf einem Literal aus und schau dir das Quotation an, das du
  zurückbekommst. Es sollte der geradlinige Code aus der Zeile
  „Kompiliert zu“ der Aufgabe sein.

## 1. Zweimal anwenden

- Du bekommst `[ A ]` und willst `[ A A ]`. Mach eine Kopie und füge
  sie zusammen: `dup append`.

## 2. N Wiederholungen

- Du bekommst `[ A ] n` und willst `n` aneinandergefügte Kopien.
- `<repetition>` erzeugt die Kopien, aber seine Wirkung ist
  `( length elt -- repetition )`. Die Anzahl muss obenauf liegen, also
  erst `swap`.
- Dann abflachen und umwandeln: `swap <repetition> concat >quotation`.

  ```factor
  ! stack: [ 1 + ] 3
  swap <repetition>     ! 3 copies of [ 1 + ]
  concat >quotation     ! => [ 1 + 1 + 1 + ]
  ```

## 3. Viele zusammensetzen

- Das Array aus Quotations bekommst du schon; du musst es nur zu einem
  zusammenfassen. `concat >quotation` ist der ganze Rumpf.

## 4. Entrollte Iteration

Du bekommst eine Sequenz und ein Quotation, z. B. `{ 10 20 30 } [ + ]`,
und willst `[ 10 + 20 + 30 + ]`. Bau das in drei Schritten auf.

**Ein Element.** Ein Element in das Quotation einzubacken ist genau
das, was `curry` macht:

```factor
10 [ + ] curry .   ! => [ 10 + ]
```

**Jedes Element.** Du willst das mit `map` über die Sequenz laufen
lassen. Aber `map` übergibt dem Mapping-Quotation nur eine Eingabe (das
Element), während du jedes Mal auch `[ + ]` zur Hand haben musst. Backe
`[ + ]` also zuerst in das Mapping-Quotation ein, wieder mit `curry`:

```factor
! stack: { 10 20 30 } [ + ]
[ curry ] curry    ! => { 10 20 30 } [ [ + ] curry ]
map                ! runs  10 [ + ] curry,  20 [ + ] curry, …
                   ! => { [ 10 + ] [ 20 + ] [ 30 + ] }
```

`[ curry ] curry` liest sich als „schieb das kleine Quotation
`[ curry ]` auf den Stack und curry dann `[ + ]` hinein“, und das ergibt
`[ [ + ] curry ]`. Wenn du das über ein Element `e` mappst, läuft
`e [ + ] curry`, was `[ e + ]` ergibt.

**Zusammenfügen.** Derselbe Abschluss wie bei den anderen Aufgaben:

```factor
concat >quotation  ! => [ 10 + 20 + 30 + ]
```

- Der ganze Rumpf: `[ curry ] curry map concat >quotation`.
