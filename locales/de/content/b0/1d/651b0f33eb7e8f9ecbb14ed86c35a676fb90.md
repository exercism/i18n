# Konstante auf oberster Ebene bevorzugen

Ziehe in Betracht, die Zahl `GIGASECOND` in eine Konstante auszulagern:

```javascript
const %{name} = %{value}

// the rest of your code below it
export const gigasecond = (...)
```

Nur Funktionen, Klassen und Konstanten, die mit `export` exportiert werden, sind von außen sichtbar und zugänglich. Es ist meist sinnvoll, [Magic Numbers](https://en.wikipedia.org/wiki/Magic_number_%%28programming%%29) einen Namen zu geben, denn das verbessert die Wartbarkeit. Diese Konstanten können in derselben Datei liegen, ohne für anderen Code sichtbar zu sein.
