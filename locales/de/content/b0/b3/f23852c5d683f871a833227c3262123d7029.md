# Ignorieren

## CoffeeScript-spezifische Anweisungen

Eine Instanz von BinarySearchTree muss 3 Eigenschaften haben: `data`, `left` und `right`.

Eine Instanz muss diese Methoden haben:

* `insert`, die ein neues Datenelement zum Baum hinzufügt. Dabei wird irgendwo im Baum ein neuer „Blatt“-Knoten angelegt.
* `each`, die ein „Callback“-Argument entgegennimmt. Das ist eine Funktion, die für _jedes Datenelement_ im Baum **in der Reihenfolge** aufgerufen wird.

Diese Übung ist ein großartiger Ort, um **Rekursion** zu üben.
