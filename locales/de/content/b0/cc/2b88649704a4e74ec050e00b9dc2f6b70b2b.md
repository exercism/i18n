# Ergänzung zu den Anweisungen

## Register

| Register | Verwendung   | Typ     | Beschreibung                                  |
| -------- | ------------ | ------- | --------------------------------------------- |
| `$a0`    | Eingabewert  | Adresse | nullterminierter Frage-String                 |
| `$v0`    | Rückgabewert | Ganzzahl | Ergebnis, 0, wenn die Frage nicht gültig ist |
| `$t0-9`  | temporär     | beliebig | zur temporären Speicherung                    |
