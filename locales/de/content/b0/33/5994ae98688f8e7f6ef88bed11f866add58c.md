# Über

Jede Instanz eines Structs oder einer Klasse hat eine implizite Eigenschaft namens `self`, die sich auf die Instanz selbst bezieht.
Am häufigsten verwendest du `self`, um zwischen einer Eigenschaft der Instanz und einem Parameter mit demselben Namen zu unterscheiden:

```swift
struct Position {
    var x = 0

    mutating func move(x: Int) {
        // Here, 'self.x' refers to the struct's property,
        // while 'x' refers to the parameter passed to the method.
        self.x = x
    }
}
```

Swift-Typen bieten außerdem das großgeschriebene Schlüsselwort `Self`, das sich auf den *Typ* der Instanz bezieht und nicht auf die Instanz selbst.
