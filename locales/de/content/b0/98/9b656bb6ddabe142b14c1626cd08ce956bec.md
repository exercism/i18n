# Einführung

Ein `String` in Julia ist eine geordnete Folge von Zeichen. Wie das Handbuch anmerkt: „Der eigentliche Ärger beginnt natürlich, wenn man fragt, was ein Zeichen überhaupt ist."

Ein Großteil dieser Komplexität wird im Konzept `Chars` ausführlicher behandelt, doch kurz gesagt:

- Alle Strings in Julia sind Unicode.
- Strings, die zufällig auch ASCII sind (englische Buchstaben A bis Z in Groß- und Kleinschreibung, Ziffern und ein paar Satzzeichen), sind _einfach_ zu handhaben.
- Die meisten anderen Schriftsysteme der Welt lassen sich _verwenden_, erfordern aber mehr Sorgfalt.

## String-Literale

Im Allgemeinen werden Strings in doppelte Anführungszeichen `" "` eingeschlossen.
Einfache Anführungszeichen `' '` werden nur für `Chars` verwendet.

Es ist auch möglich, dreifache doppelte Anführungszeichen `""" """` zu verwenden, wodurch `"` innerhalb des Strings ohne Escaping benutzt werden kann.
Noch wichtiger: Unerwünschte zusätzliche Einrückung wird bei mehrzeiligen Strings entfernt.

```julia-repl
julia> """
       Multiline
       String
       """
"Multiline\nString\n"
```

### Zeichen escapen

Wie die meisten Sprachen seit C verwendet Julia einen Backslash `\` zum Escapen:

1. Um nicht druckbare Zeichen einzugeben, etwa den Zeilenumbruch `\n` im vorherigen Beispiel.
2. Um Zeichen zu schützen, die sonst eine besondere Bedeutung hätten, etwa `\$` (siehe unten).

## Indexierung

Im Prinzip lassen sich Strings genau wie Vektoren indexieren:

```julia-repl
julia> s[1], s[5]
('J', 'a')
```

Das funktioniert offensichtlich für einen ASCII-String wie „Julia", ignoriert aber die meisten Sprachen der Welt.

Betrachte eines der Zeichen aus Beowulf, das vor etwa 15 Jahrhunderten im Altenglischen geschrieben wurde.

„Hrōðgār" besteht eindeutig aus 7 Zeichen, aber nicht alle davon sind ASCII.

```julia-repl
julia> king = "Hrōðgār"
"Hrōðgār"

julia> length(king)
7

julia> isascii(king)
false

# collect() converts to a Char vector:
julia> collect(king)
7-element Vector{Char}:
 'H': ASCII/Unicode U+0048 (category Lu: Letter, uppercase)
 'r': ASCII/Unicode U+0072 (category Ll: Letter, lowercase)
 'ō': Unicode U+014D (category Ll: Letter, lowercase)
 'ð': Unicode U+00F0 (category Ll: Letter, lowercase)
 'g': ASCII/Unicode U+0067 (category Ll: Letter, lowercase)
 'ā': Unicode U+0101 (category Ll: Letter, lowercase)
 'r': ASCII/Unicode U+0072 (category Ll: Letter, lowercase)
```

Eine solche Indexierung in einen String beginnt gut, bricht aber irgendwann zusammen:

```julia-repl
julia> king[3]
'ō': Unicode U+014D (category Ll: Letter, lowercase)

julia> king[4]
ERROR: StringIndexError: invalid index [4], valid nearby indices [3]=>'ō', [5]=>'ð'
```

Das Problem ist, dass eine solche Indexierung _Bytes_ zählt, die bei Nicht-ASCII-Strings keine 1:1-Beziehung zu Zeichen haben.
Ein Unicode/UTF-8-Zeichen braucht möglicherweise bis zu 4 Bytes, um es darzustellen, und das Konzept `Chars` geht näher darauf ein.

## Strings aufbauen

### Verkettung

Viele Sprachen verwenden `+` als Operator zur String-Verkettung, Julia aber nicht.
Immerhin ist die Fehlermeldung hilfreich.

```julia-repl
julia> "s1 " + "s2"
ERROR: MethodError: no method matching +(::String, ::String)
The function `+` exists, but no method is defined for this combination of argument types.
String concatenation is performed with * 

julia> "s1 " * "s2"
"s1 s2"
```

Die Funktion `string()` verkettet eine beliebige Anzahl von Strings.

```julia-repl
julia> string("lots ", "of ", "bits")
"lots of bits"
```

Die Funktion `join()` macht dasselbe und nimmt außerdem einen Vektor von Strings und verkettet sie mit einem angegebenen Trennzeichen (standardmäßig `""`).

```julia-repl
julia> join(["lots", "of", "bits"], "_")
"lots_of_bits"
```

Beachte, dass Strings unveränderlich sind und Verkettung kopiert.
Daher sind wiederholte Verkettungen innerhalb einer Schleife ineffizient; besser sammelst du die Fragmente in einem Vektor und fügst sie am Ende zusammen.

### Wiederholung

Einfach:

```julia-repl
julia> repeat("Abc", 5)
"AbcAbcAbcAbcAbc"
```

### Interpolation

Viele Sprachen haben eine Möglichkeit, berechnete Werte in Strings einzufügen, doch über die beste Syntax dafür herrscht außergewöhnlich große Uneinigkeit.

In Julia steht vor interpolierten Werten ein `$`.

```julia-repl
julia> myvar = 42
42

julia> "myvar evaluates to $myvar"
"myvar evaluates to 42"

julia> r = 5.3
5.3

julia> "A circle of radius $r has area $(π * r^2)"
"A circle of radius 5.3 has area 88.24733763933729"
```

Klammern sind nötig, wenn das Weglassen zu Mehrdeutigkeit führen würde, bei einem einzelnen Bezeichner gefolgt von Leerraum aber optional.

Um ein $ in den String aufzunehmen, escape es als `\$`.

Beachte die Einschränkung, dass Interpolation derzeit keine Formatierung erlaubt, etwa die Anzahl der anzuzeigenden Nachkommastellen.

### `@sprintf()`

Für eine feinere Kontrolle über den Zusammenbau von Strings übernimmt Julia die Funktion `sprintf` aus C (und mehreren späteren Sprachen: Wikipedia listet etwa 30 auf).

In Julia ist dies als `macro` im Modul `Printf` implementiert, daher das Präfix `@`.

```julia-repl
julia> using Printf

julia> r = 5.3
5.3

julia> @sprintf("A circle of radius %.1f has area %.2f", r, π * r^2)
"A circle of radius 5.3 has area 88.25"
```

## String-Funktionen

Der Einfachheit halber konzentriert sich dieser Abschnitt auf Funktionen, die einen neuen String zurückgeben und die Eingabe unverändert lassen.
Viele haben ein Gegenstück mit dem Suffix `!`, das die Eingabe direkt verändert.

### Länge

Wie lang ist ein String?
Manchmal hängt es davon ab, wie du zählst.

Der einfache Fall sind ASCII-Strings, bei denen jedes Zeichen 1 Byte belegt.

```julia-repl
julia> string_asc = "Julia"
"Julia"

julia> length(string_asc)
5

julia> sizeof(string_asc)
5
```

Die Funktion `length()` gibt die Anzahl der _Zeichen_ zurück, die Funktion `sizeof()` die Anzahl der _Bytes_.

Bei anderen Zeichensätzen wird dieser Unterschied wichtig:

```julia-repl
julia> king = "Hrōðgār"
"Hrōðgār"

julia> length(king)
7

julia> sizeof(king)
10
```

### Aufteilen

Eine häufige Operation beim Programmieren besteht darin, einen langen String anhand eines Trennstrings aus einem oder mehreren Zeichen in Stücke zu zerlegen.

Meist verwenden wir die Funktion `split()`.
Das Trennzeichen ist standardmäßig (beliebiger) Leerraum, es können aber auch andere angegeben werden.

```julia-repl
julia> split("my little string")
3-element Vector{SubString{String}}:
 "my"
 "little"
 "string"

julia> split("My_snake_case_string", "_")
4-element Vector{SubString{String}}:
 "My"
 "snake"
 "case"
 "string"
```

Diese Beispiele zerlegen einen String in kleinere _Strings_.
Einen String in _Zeichen_ zu zerlegen, ist eine andere Operation.

### Suchen und Ersetzen

Enthält ein String einen bestimmten Teilstring?
Seltsamerweise gibt es zwei Funktionen, um das zu prüfen: `occursin()` und `contains()` unterscheiden sich nur in der Reihenfolge ihrer Argumente.

```julia-repl
julia> needle = "Julia"
"Julia"

julia> haystack = "Python, Julia and R"
"Python, Julia and R"

julia> occursin(needle, haystack)
true

julia> contains(haystack, needle)
true
```

Um genauer auf die Position einzugehen:

```julia-repl
julia> startswith(haystack, "Python")
true

julia> endswith(haystack, "Python")
false
```

Um die start:end-Indizes eines Teilstrings zu erhalten, haben wir mehrere Funktionen:

- `findfirst()`
- `findlast()`
- `findprev()`
- `findnext()`

```julia-repl
julia> findfirst(needle, haystack)
9:13
```

Um Teilstrings zu ersetzen, liste die Änderungen mit der Syntax `x => y` auf.

```julia-repl
julia> replace("abc", "a"=>"b", "b"=>"c", "c"=>"a")
"bca"
```

Seit Julia 1.7 kann die Funktion `replace` eine beliebige Anzahl von Änderungen annehmen, mit der Garantie, dass während des Ersetzens kein Zeichen mehr als einmal geändert wird.

Die Syntax `x => y` heißt `pair`, ein wichtiger Typ in Julia, der im Konzept `Dicts and Pairs` ausführlicher behandelt wird.

### Leerraum

Oft müssen wir führenden und/oder abschließenden Leerraum aus einem String entfernen.

Funktionen dafür sind `lstrip()` (links), `rstrip()` (rechts), `strip()` (beides).

```julia-repl
julia> strip("\n\t  useful_bit\n\n")
"useful_bit"
```

### Groß-/Kleinschreibung ändern

Diese Funktionen haben ziemlich selbsterklärende Namen:

```julia-repl
julia> s = repeat("aBcD ", 5)
"aBcD aBcD aBcD aBcD aBcD "

julia> uppercase(s)
"ABCD ABCD ABCD ABCD ABCD "

julia> lowercase(s)
"abcd abcd abcd abcd abcd "

julia> titlecase(s)  # Initial letter of each word uppercase
"Abcd Abcd Abcd Abcd Abcd "
```
