# Einführung

## while-Schleifen

Mit einer while-Schleife kannst du Code so lange wiederholt ausführen, wie eine bestimmte Bedingung erfüllt ist.
Sie wird mit dem Schlüsselwort `while` geschrieben, gefolgt von einer Bedingung in runden Klammern und einem Block in geschweiften Klammern, der den _Schleifenblock_ enthält.

```javascript
while (condition) {
  // code that is executed repeatedly as long as the condition is true
}
```

JavaScript hat auch eine do-while-Schleife.
Hier wird die Bedingung überprüft, nachdem der Schleifenblock ausgeführt wurde.
Das ist nützlich, wenn die Bedingung von Auswertungen abhängt, die im Block vorgenommen werden.

```javascript
do {
  // The code here will always be executed once and then
  // repeatedly while the condition is true.
} while (condition);
```

Innerhalb eines Schleifenblocks kannst du das Schlüsselwort `break` verwenden, um die Ausführung der Schleife vollständig zu beenden.
Im Gegensatz dazu stoppt das Schlüsselwort `continue` nur die Ausführung der aktuellen Iteration und fährt mit der nächsten fort.
Mit `continue` kannst du oft vermeiden, große Teile des Schleifenblocks in eine if-Anweisung zu packen.

```javascript
let i = 0;

while (i < 100) {
  i = i + 2;

  if (i % 3 === 0) {
    continue;
  }

  // The code here will only be executed when i was not divisible
  // by 3 in the check above.
}
```

## switch-Anweisungen

Neben der if-Anweisung hat JavaScript auch eine switch-Anweisung, um Logik bedingt auszuführen.
Sie wird verwendet, wenn eine einzelne Variable mit mehreren Varianten verglichen werden muss.
Der Vergleich erfolgt durch Prüfen auf strikte Gleichheit (`===`), siehe [Konzept Vergleich][concept-comparison].
Für eine Variable `x` hat die switch-Anweisung in JavaScript die folgende Syntax.

<!-- prettier-ignore-start -->
```javascript
switch (x) {
  case option1:
    // code that is executed when "x === option1" is true
    break;
  case option2:
    // code that is executed when "x === option2" is true
    break;
  default:
    // code that is executed when x does not equal any of the options
}
```
<!-- prettier-ignore-end -->

Der `default`-Fall ist optional und wird verwendet, wenn du Code ausführen möchtest, falls keine der anderen Optionen zur Variable passt.

Die `break`-Anweisungen oben sind nötig, weil standardmäßig alle Fälle in JavaScript „durchfallen" (Fallthrough).
Das heißt, ohne eine `break`-Anweisung würde der gesamte Code in den Fällen unterhalb der ersten passenden Option ausgeführt, obwohl `x` nicht zu diesen Optionen passte.
Dieses Verhalten „standardmäßig durchfallen" ist eine häufige Fallgrube bei der Verwendung von `switch` in JavaScript.
Innerhalb einer Funktion kann auch `return` anstelle von `break` verwendet werden, um dieses Problem zu vermeiden.
