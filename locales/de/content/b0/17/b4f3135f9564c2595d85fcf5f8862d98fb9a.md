# Über

Go enthält grundlegende numerische Typen, die Mengen von Ganzzahl- oder Gleitkommawerten darstellen können.
Es gibt verschiedene Typen, je nachdem, welche Größe des Werts du brauchst und welche Architektur der Computer hat, auf dem die Anwendung läuft (z. B. 32-Bit und 64-Bit).

Dieses Konzept konzentriert sich auf zwei Zahlentypen:

- `int`: z. B. `0`, `255`, `2147483647`.
   Eine vorzeichenbehaftete Ganzzahl, die mindestens 32 Bit groß ist (Wertebereich: -2147483648 bis 2147483647).
   Das hängt aber von der Architektur des Systems ab.
   Die meisten modernen Computer sind 64-Bit, deshalb ist `int` 64 Bit groß (Wertebereich: -9223372036854775808 bis 9223372036854775807).

- `float64`: z. B. `0.0`, `3.14`.
   Enthält die Menge aller 64-Bit-Gleitkommazahlen.

Eine vollständige Liste der verfügbaren numerischen Typen und weitere Details findest du in den folgenden Ressourcen:

- [Deklarationen der eingebauten Typen in Go][go-builtins]
- [Digital Ocean: Datentypen in Go verstehen][do-understanding-types]
- [Arden Labs: Typen in Go verstehen][arden-understanding-types]

Go unterstützt die üblichen arithmetischen Operatoren `+`, `-`, `*`, `/` und `%` (Rest, nicht Modulo).

In Go erfordert die Zuweisung eines Werts zwischen verschiedenen Typen eine explizite Konvertierung.
Um zum Beispiel einen `int` in einen `float64` umzuwandeln, gehst du so vor:

```go
var x int = 42
f := float64(x)

fmt.Printf("x is of type: %s\n", reflect.TypeOf(x))
// Output: x is of type: int

fmt.Printf("f is of type: %s\n", reflect.TypeOf(f))
// Output: f is of type: float64
```

Weitere Informationen zur Typkonvertierung findest du in [A Tour of Go: Typkonvertierungen][type-conversion]
