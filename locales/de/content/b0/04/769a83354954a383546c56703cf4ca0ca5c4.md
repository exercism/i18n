# Anleitung

In dieser Übung baust du die Fehlerbehandlung für einen einfachen Taschenrechner.

Das Ziel ist ein funktionierender Taschenrechner, der einen String nach folgendem Muster zurückgibt: `16 + 51 = 67`, wenn er die Argumente `16`, `51` und `+` erhält.

```ruby
SimpleCalculator.calculate(16, 51, "+")
# => "16 + 51 = 67"
SimpleCalculator.calculate(32, 6, "*")
# => "32 * 6 = 192"
SimpleCalculator.calculate(512, 4, "/")
# => "512 / 4 = 128"
```

## 1. Behandle den Code, der innerhalb der Methode `calculate` Fehler auslösen kann

Die Hauptmethode, die du in dieser Aufgabe implementierst, ist die Klassenmethode `SimpleCalculator.calculate()`.
Sie nimmt drei Argumente entgegen.
Die ersten beiden Argumente sind Zahlen, mit denen eine Operation durchgeführt wird.
Das dritte Argument ist vom Typ String, und für diese Übung ist es notwendig, die folgenden Operationen zu implementieren:

- Addition mit dem String `+`
- Multiplikation mit dem String `*`
- Division mit dem String `/`

## 2. Behandle unzulässige Operationen

Passe die Methode `SimpleCalculator.calculate()` so an, dass sie für unbekannte Operationssymbole eine Ausnahme vom Typ `UnsupportedOperation` auslöst.

```ruby
SimpleCalculator.calculate(1, 2, '-')
# => Raises an UnsupportedOperation
```

~~~~exercism/note
In dieser Übung wird von dir erwartet, dass du die Ausnahme `UnsupportedOperation` für einen bestimmten Gültigkeitsbereich definierst.
~~~~

## 3. Behandle ungültige Argumente

Passe die Methode `SimpleCalculator.calculate()` so an, dass sie bei ungültigen Argumenttypen eine Ausnahme vom Typ `ArgumentError` auslöst.

```ruby
SimpleCalculator.calculate(1, '2', '*')
# => Raises an ArgumentError
```

## 4. Behandle DivideByZero-Ausnahmen

Passe `SimpleCalculator.calculate()` so an, dass Ausnahmen vom Typ `ZeroDivisionError` behandelt werden.
Der Code zur Behandlung sollte den String mit dem Inhalt `Division by zero is not allowed.` zurückgeben.
Alle anderen Ausnahmen sollten von der Methode `SimpleCalculator.calculate()` nicht behandelt werden.

```ruby
SimpleCalculator.calculate(512, 0, "/")
# => returns "Division by zero is not allowed."
```
