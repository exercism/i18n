# Hinweise

## 1. Baue ein Schild für einen Anlass

- [Template-Strings][mdn-template-strings] (Template Literals) erlauben das Einsetzen von einem oder mehreren Strings und eingebetteten Ausdrücken

## 2. Baue ein Geburtstagsschild

- [Template-Strings][mdn-template-strings] (Template Literals) erlauben das Einsetzen von Strings und eingebetteten Ausdrücken
- Der [ternäre Operator][mdn-ternary-operator] ist eine Kurzschreibweise, um mit Bedingungen zu arbeiten, ähnlich wie `if/else`. In Template-Strings ist er oft einfacher zu verwenden, weil er kompakter ist.

## 3. Baue ein Abschlussschild

- Mit [Template-Strings][mdn-template-strings] können Strings über mehrere Zeilen gehen.

## 4. Berechne die Kosten für ein Schild

- Ermittle die [`length`][mdn-string-length] der Zeichen.
- Zeige nur die ersten beiden Dezimalstellen mit [Festkomma][mdn-to-fixed]-Notation an.
