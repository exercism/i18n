# Einführung

Die meisten Daten in Factor stecken in *Sequenzen*. Arrays (`{ … }`),
Vektoren (`V{ … }`) und Strings teilen sich alle dasselbe
[Protokoll][sequence-protocol] aus [`sequences`][sequences].

```factor
{ 1 2 3 } length .    ! => 3
{ 1 2 3 } first .     ! => 1
{ 1 2 3 } last .      ! => 3
{ 1 2 3 4 5 } 3 head .! => { 1 2 3 }
```

Aggregationen wie `sum`, `count`, `any?` und `all?` sowie Prädikate wie
`empty?` und `member?` funktionieren bei jedem Sequenztyp gleich.
Neue Sequenzen kannst du ohne Mutation aufbauen: `prefix`, `suffix`,
`append`, `unclip`, `unclip-last`.

`>array`, `>vector` und `>string` (in
[`arrays`][arrays] und den zugehörigen Vokabularen) wandeln
zwischen Sequenztypen um, wenn du aus einer generischen Operation
wieder eine bestimmte konkrete Sequenz zurückbekommen willst.

[arrays]: https://docs.factorcode.org/content/vocab-arrays.html

[sequences]: https://docs.factorcode.org/content/vocab-sequences.html
[sequence-protocol]: https://docs.factorcode.org/content/article-sequence-protocol.html
