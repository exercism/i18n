# Anweisungen

Zwei Violinisten proben ein Duett. Jede Stimme ist ein Array, das die Anzahl der Noten in jedem Takt enthält, und die Stimmen sind nicht immer gleich lang.

Alle vier Aufgaben gehören in die Klasse `DUET_PRACTICE`.

## 1. Wie viele Takte spielen sie gemeinsam?

Sie spielen so lange zusammen, wie beide Stimmen noch einen Takt übrig haben.

```sather
DUET_PRACTICE::bars_together(|4, 4, 8, 8|, |4, 4|)
-- => 2
```

## 2. Wie viele Takte stimmen überein?

Zähle die Takte, in denen beide Stimmen die gleiche Anzahl Noten haben. Nur Takte, die beide haben, können übereinstimmen.

```sather
DUET_PRACTICE::in_unison(|4, 4, 8|, |4, 2, 8|)
-- => 2
```

## 3. Wer hat mehr zu tun?

Zähle die Takte, in denen die erste Stimme mehr Noten hat als die zweite.

```sather
DUET_PRACTICE::louder_bars(|4, 8, 2|, |4, 2, 8|)
-- => 1
```

## 4. Gewichte die Takte

Spätere Takte sind schwieriger, deshalb zählt ein Takt so viel wie seine Position: Der erste Takt zählt einfach, der zweite doppelt, der dritte dreifach. Multipliziere die Noten jedes Takts mit seiner Nummer und addiere alles zusammen.

```sather
DUET_PRACTICE::weighted_total(|4, 4, 8|)
-- => 36
```

Das ergibt 1×4 + 2×4 + 3×8. Die Takte werden ab eins nummeriert, nicht ab null.
