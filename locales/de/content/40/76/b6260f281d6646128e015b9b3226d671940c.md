# Tests

Bevor du versuchst, die Tests auszuführen, stelle sicher, dass der Übungsordner korrekt eingerichtet ist. Folge dazu den Installationsschritten, nämlich `corepack yarn install` und der Einrichtung des Editor SDK.

Führe die Tests so aus:

```bash
$ corepack yarn test
```

## Übersprungene Tests

In den Testsuiten wurden alle Tests außer dem ersten übersprungen.

Sobald ein Test erfolgreich läuft, kannst du den nächsten aktivieren, indem du `xit` in `it` änderst.
Außerdem können Tests mit `xdescribe` gruppiert werden.
Aktiviere die Gruppe, indem du das in `describe` änderst.
Schließlich können manche Übungen optionale Tests mit `it.skip` enthalten.
Entferne `.skip`, um den optionalen Test auszuführen.
