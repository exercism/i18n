# Über

Typen, die die Schnittstelle [`IEnumerable<T>`][IEnumerable] implementieren, werden als _Enumerable_ bezeichnet.
Alle integrierten Auflistungstypen implementieren diese Schnittstelle.

Ein Enumerable-Typ kann mit einer `foreach`-Schleife durchlaufen werden:

```csharp
var primes = new[] { 2, 3, 5, 7 };
foreach (var prime in primes)
{
    Console.Write(prime);
}
// => 2357
```

Um `IEnumerable<T>` zu implementieren, muss ein Typ eine einzige Methode implementieren: `IEnumerator<T> GetEnumerator()`.
Wie man sieht, überlässt ein Enumerable das eigentliche Durchlaufen einer Auflistung einem `IEnumerator<T>`-Typ.
Diese Schnittstelle hat eine Eigenschaft und drei Methoden, die implementiert werden müssen:

- `public T Current { get; }`: liefert das aktuelle Element.
- `public bool MoveNext ();`: rückt zum nächsten Element vor und gibt `true` zurück, wenn der Wechsel zum nächsten Element erfolgreich war, und `false`, wenn nicht (keine weiteren Elemente).
- `public void Reset ();`: setzt den Enumerator auf seinen Anfangszustand zurück (vor dem ersten Element).

[IEnumerable]: https://docs.microsoft.com/en-us/dotnet/api/system.collections.generic.ienumerable-1
