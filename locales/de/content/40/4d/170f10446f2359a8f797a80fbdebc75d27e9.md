# Installation

## Welche Version solltest du wählen?

Wir empfehlen eine stabile PHP-Version mit aktiver Unterstützung.
Aktuell sind das **PHP 8.2, 8.3 und 8.4**.
Details zu den aktuellen Versionen und ihren Zeitplänen findest du in [der offiziellen PHP-Dokumentation](https://www.php.net/supported-versions.php).

## PHP installieren

Die meisten Paketmanager für Linux / macOS bieten vorgefertigte Pakete an.
PHP kann auch heruntergeladen und aus dem Quellcode gebaut werden. Das ist verfügbar unter [php.net/downloads.php](https://php.net/downloads.php) oder [windows.php.net/download](https://windows.php.net/download).

~~~~exercism/note
Ein Webserver wie nginx oder Apache HTTP Server ist nicht nötig, um die Übungen zu lösen.
~~~~

### Linux

Verschiedene Distributionen verwenden unterschiedliche Methoden.
Je nach deinem Paketmanager solltest du einen der folgenden Befehle ausführen können:

```shell
yum install php
```

oder

```shell
apt-get install php
```

Weitere Anweisungen findest du im PHP-Handbuch unter [Installation unter Unix-Systemen](https://www.php.net/manual/en/install.unix.php).

### macOS

PHP ist zwar oft schon in macOS enthalten, aber häufig veraltet.
Wir empfehlen, PHP über [Homebrew](https://brew.sh/) zu installieren.
Homebrew kannst du nach der Anleitung [auf der Homepage](https://brew.sh/#install) installieren.

Um die Installation zu überprüfen, führe folgenden Befehl aus. Er sollte zum Zeitpunkt dieses Textes Homebrew `4.5.x` ausgeben.

```shell
brew --version 
```

Installiere PHP über Homebrew

```shell
brew install php@8.4
```

Das sollte die jetzt installierte PHP-Version anzeigen, mindestens Version `8.2.0`.

```shell
php -v
```

Weitere Anweisungen findest du im Handbuch unter [Installation unter macOS](https://www.php.net/manual/en/install.macosx.php).

### Windows

Offizielle PHP-Binärdateien für Windows kannst du von [windows.php.net/download](https://windows.php.net/download) herunterladen.

Es gibt auch vorgefertigte Pakete wie [WAMP](https://www.wampserver.com/en/) (Windows, Apache, MySQL, PHP) und [XAMPP](https://www.apachefriends.org/de/index.html).

Weitere Anweisungen findest du im Handbuch unter [Installation unter Windows-Systemen](https://www.php.net/manual/en/install.windows.php).

### Docker

Wenn du containerisierte Lösungen bevorzugst, kannst du das [offizielle PHP-Image von Docker Hub](https://hub.docker.com/_/php) herunterladen.
Außerdem brauchst du [Docker](https://docs.docker.com/engine/install/).

### Sonstiges

Wenn du ein anderes Betriebssystem verwenden möchtest, lies die Anleitung unter [php.net/manual/en/install](https://www.php.net/manual/en/install.php).

### Über das PHP-Archiv (PHAR)

Der einfachste Weg, PHPUnit für Exercism-Übungen zu verwenden, ist eine Distribution herunterzuladen, die als PHP-Archiv (PHAR) gepackt ist. Das ist auch der empfohlene Weg, PHPUnit zu nutzen.
Lege die PHAR-Datei dort ab, wo du die `exercism`-CLI abgelegt hast, damit du PHPUnit von überall aus ausführen kannst.

Du kannst eine Veröffentlichung der PHPUnit-Pakete als PHP-Archiv herunterladen:

```shell
wget -O phpunit.phar https://phar.phpunit.de/phpunit-11.phar
```

Mach die heruntergeladene Datei dann ausführbar:

```shell
chmod +x phpunit.phar
```

Und verschiebe sie an dieselbe Stelle, an die du die `exercism`-CLI verschoben hast, und nenne den Befehl `phpunit`:

```shell
mv phpunit.phar ~/bin/phpunit
```

Jetzt kannst du `phpunit` von überall aus ausführen, wie in der [Test-Dokumentation des PHP-Tracks](https://exercism.org/docs/tracks/php/tests) beschrieben:

```shell
phpunit --version
```

Die Ausgabe sollte so aussehen:

```text
PHPUnit 11.5.45 by Sebastian Bergmann and contributors.
```

Du kannst PHPUnit auch mit der offiziellen Anleitung [Installation von PHPUnit](https://docs.phpunit.de/en/11.5/installation.html#installing-phpunit) installieren.

### Über Composer

PHPUnit Version 11 lässt sich auch über [Composer](https://getcomposer.org) installieren.

#### Composer installieren

Installiere [Composer](https://getcomposer.org) nach den [Installationsanweisungen](https://getcomposer.org/doc/00-intro.md) für das Betriebssystem deines Geräts. Wir empfehlen, es der Einfachheit halber global zu installieren.

#### PHPUnit als globales Tool hinzufügen

Verwende dazu folgenden Befehl:

```shell
composer global require phpunit/phpunit ^11.5
```

Achte bitte darauf, dass du Version 11.5 oder neuer installierst.
