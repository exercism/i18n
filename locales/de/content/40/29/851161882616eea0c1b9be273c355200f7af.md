# Hinweise

## 1. Erstelle den Bezeichner für die Häfen

- Du musst eine [Konstante][constants] definieren, die den in den Anweisungen angegebenen Symbolwert enthalten soll.

## 2. Hole Bezeichner für andere Häfen

- Mit [slice][slice] kannst du Teile eines Strings erhalten.
- `Strings` haben eine [Methode][upcase], um die Buchstaben in Großbuchstaben umzuwandeln.
- `Strings` haben eine [Methode][to_sym], um einen String in ein Symbol umzuwandeln.

## 3. Bestimme, an welchem Terminal ein Schiff anlegen soll

- Ein Symbol hat eine [Methode][to_s], um ein Symbol in einen String umzuwandeln.
- Mit [slice][slice] kannst du Teile eines Strings erhalten.
- Verwende ein bedingtes [`if`][doc-if], um zu prüfen, ob das Schiff `"OIL"` oder `"GAS"` geladen hat.
