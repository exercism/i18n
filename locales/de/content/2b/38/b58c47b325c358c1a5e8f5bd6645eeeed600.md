# Hinweise

## Allgemeines

- Sieh dir die Funktionen an, die im [`NaiveDateTime`-Modul][naive-date-time], im [`Date`-Modul][date] und im [`Time`-Modul][time] verfügbar sind.

## 1. Die gespeicherten Datetimes parsen

- Es gibt eine [eingebaute Funktion][naive-date-time-from-iso8601], die einen ISO8601-Datetime-String parst und ein `NaiveDateTime`-Struct zurückgibt.

## 2. Feststellen, ob ein Buch vor Mittag ausgeliehen wurde

- Du kannst ein `Time`-Literal mit dem [`~T`-Sigil][time-sigil] definieren.
- Es gibt eine [eingebaute Funktion][naive-date-time-to-time], die ein `NaiveDateTime`-Struct in ein `Time`-Struct umwandelt.
- Es gibt eine [eingebaute Funktion][time-compare], die prüft, welches von zwei `Time`-Structs größer ist.

## 3. Das Rückgabedatum berechnen

- Ein Tag hat `24 * 60 * 60` Sekunden.
- Es gibt eine [eingebaute Funktion][naive-date-time-add], die eine gegebene Anzahl Sekunden zu einem `NaiveDateTime`-Struct addiert.
- Es gibt eine [eingebaute Funktion][naive-date-time-to-date], die ein `NaiveDateTime`-Struct in ein `Date`-Struct umwandelt.

## 4. Feststellen, wie spät das Buch zurückgegeben wurde

- Es gibt eine [eingebaute Funktion][naive-date-time-to-date], die ein `NaiveDateTime`-Struct in ein `Date`-Struct umwandelt.
- Es gibt eine [eingebaute Funktion][date-diff], die die Differenz in Tagen zwischen zwei `Date`-Structs berechnet.

## 5. Feststellen, ob das Buch an einem Montag zurückgegeben wurde

- Es gibt eine [eingebaute Funktion][naive-date-time-to-date], die ein `NaiveDateTime`-Struct in ein `Date`-Struct umwandelt.
- Es gibt eine [eingebaute Funktion][date-day-of-week], die den Wochentag für ein gegebenes `Date`-Struct zurückgibt.

## 6. Die Mahngebühr berechnen

- Kombiniere alle Funktionen, die du in den vorherigen Schritten definiert hast.
