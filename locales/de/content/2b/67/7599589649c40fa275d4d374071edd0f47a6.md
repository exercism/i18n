# Anweisungen

Elena, die neue Qualitätsmanagerin in einer Zeitungsfabrik, bittet dich, ein kleines Programm zu schreiben, das den Produktionsraum überwacht.

## 1. Definiere einen eigenen Fehler

Definiere mit dem Parsing-Wort `ERROR:` eine Fehler-Tupelklasse `machine-error`. Sie braucht keine Slots.

```factor
machine-error   ! throws a fresh machine-error
```

## 2. Prüfe die Luftfeuchtigkeit

Definiere `check-humidity`. Die Funktion nimmt einen Luftfeuchtigkeitswert vom Stack und `throw`t den String `"humidity too high"`, wenn der Wert echt größer als `70` ist. Andernfalls gibt sie nichts zurück.

```factor
50 check-humidity   ! returns nothing
80 check-humidity   ! throws "humidity too high"
```

## 3. Prüfe die Temperatur

Definiere `check-temperature`. Die Funktion nimmt einen Temperaturwert und `throw`t den String `"temperature too high"`, wenn der Wert echt größer als `500` ist. Andernfalls gibt sie nichts zurück.

```factor
400 check-temperature   ! returns nothing
600 check-temperature   ! throws "temperature too high"
```

## 4. Überwache die Maschine

Definiere `monitor` so, dass die Funktion eine Luftfeuchtigkeit und eine Temperatur vom Stack nimmt und beide Prüfungen ausführt. Wenn eine der Prüfungen einen Fehler wirft, soll `monitor` stattdessen einen frischen `machine-error` werfen. Wenn beide bestehen, gibt `monitor` nichts zurück.

```factor
50 400 monitor   ! returns nothing
80 400 monitor   ! throws a machine-error
50 600 monitor   ! throws a machine-error
```

## 5. Überwache eine Reihe von Messwerten

Definiere `monitor-batch` so, dass die Funktion ein Array von `{ humidity temperature }`-Messwerten nimmt und zurückgibt, wie viele davon fehlschlagen würden (d. h., wie viele `monitor` zum Werfen bringen würden).

```factor
{ { 50 400 } { 80 400 } { 50 600 } { 60 200 } } monitor-batch .
! => 2
```
