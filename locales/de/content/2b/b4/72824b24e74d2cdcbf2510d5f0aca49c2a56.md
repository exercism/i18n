# Ergänzung zu den Anweisungen

Eine mögliche Lösung für diese Übung ist, deine eigene Funktion für die modulare Exponentiation zu implementieren.
Mehr darüber erfährst du auf der [folgenden Seite](https://en.wikipedia.org/wiki/Modular_exponentiation).

## Für Bonuspunkte

Viele Implementierungen funktionieren nicht für den gesamten Bereich möglicher Eingaben.
Es gibt zusätzliche optionale Tests, die sicherstellen helfen, dass alle gültigen Eingaben gültige Ergebnisse liefern.

Um die Bonustests auszuführen, entferne das Flag `#[ignore]` und führe die Tests mit dem Feature `big-primes` aus, so wie hier:

```bash
$ cargo test --features big-primes
```
