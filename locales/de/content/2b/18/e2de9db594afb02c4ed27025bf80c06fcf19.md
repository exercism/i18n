# Installation

Das Einzige, was du zum Ausführen dieser Übungen brauchst, ist eine installierte [CommandBox CLI](https://commandbox.ortusbooks.com/getting-started-guide) und [Java 8](https://java.com/en/download/). CommandBox CLI läuft auf Mac, Linux und Windows. Die Installationsanleitung findest du hier:

[https://commandbox.ortusbooks.com/setup/installation](https://commandbox.ortusbooks.com/setup/installation)

Wenn du auf dem Mac Homebrew nutzt, sieht das Einrichten von CommandBox CLI zum Beispiel so aus:

```bash
brew install commandbox
```

Sobald du die CLI installiert hast, kannst du mit der REPL herumprobieren:

```bash
box repl
```

Du kannst `.cfm`-Seiten direkt ausführen:

```bash
box exec myTest.cfm
```

Und du kannst sogar in jedem Verzeichnis deiner Festplatte einen Webserver starten:

```bash
box server start
```

CommandBox hat eine interaktive Shell, die du nutzen kannst. Sie bietet eine erweiterte Tab-Vervollständigung und läuft schneller. Du startest sie, indem du die Binärdatei `box` ohne Argumente ausführst.

```bash
box
```
