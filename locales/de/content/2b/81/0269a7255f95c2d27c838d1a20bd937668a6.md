# Über

Lua verwendet zwei Darstellungen für Zahlen: 64-Bit-Ganzzahlen und Gleitkommazahlen mit doppelter Genauigkeit.

~~~exercism/note
Vor Version 5.3 stellte Lua alle Zahlen im Gleitkommaformat mit doppelter Genauigkeit dar.
~~~

Zahlen können mit einem optionalen Nachkommateil und einem optionalen Dezimalexponenten geschrieben werden.
```lua
1               --> 1
0.2             --> 0.2
0.3e4           --> 3000.0
4.0e-3          --> 0.004
5.0e+20         --> 5e+20
```

Eine Zahl mit einem Dezimalpunkt oder einem Exponenten gilt als Gleitkommazahl, ohne einen solchen wird sie als Ganzzahl behandelt, aber beide haben den Typ 'number'.
```lua
type(1)         --> number
type(2.0)       --> number
```

Wenn wir zwischen Gleitkommazahlen und Ganzzahlen unterscheiden wollen, können wir die Funktion `type` aus dem Modul `math` verwenden.
```lua
math.type(1)    --> integer
math.type(2.0)  --> float
```

## Vergleich

Ganzzahlen und Gleitkommazahlen mit demselben Wert gelten als gleich:
```lua
1 == 1.0        --> true
-2 == -2.0      --> true
0.3e3 == 300    --> true
```

## Arithmetik

Lua unterstützt die üblichen arithmetischen Operatoren: Addition, Subtraktion, Multiplikation, Division und Negation. Darüber hinaus unterstützt es die Floor-Division, Modulo und Potenzierung.

### Addition, Subtraktion, Multiplikation und Negation

Wenn beide Operanden Ganzzahlen sind, ist das Ergebnis der Operation eine Ganzzahl. Dasselbe gilt für Gleitkommazahlen.
```lua
1 + 2     --> 3
1.0 + 2.0 --> 3.0
```

Wenn ein Operand eine Gleitkommazahl ist, werden die übrigen Ganzzahlen ebenfalls in Gleitkommazahlen umgewandelt, und die Operation ergibt eine Gleitkommazahl.
```lua
1.0 + 2   --> 3.0
```

### Division

Die Division arbeitet immer mit Gleitkommazahlen und liefert als Ergebnis eine Gleitkommazahl.
```lua
1.0 / 2.0 --> 0.5
2 / 1     --> 2.0
```

Eine Division durch null ergibt `inf` oder `-inf`. Null durch null geteilt ergibt `-nan`.
```lua
1 / 0     --> inf
-1 / 0    --> -inf
0 / 0     --> -nan
```

### Floor-Division

Wenn ein ganzzahliges Ergebnis benötigt wird, kann die Floor-Division verwendet werden. Die Floor-Division rundet den Quotienten immer in Richtung minus unendlich, wodurch für alle Operanden ein ganzzahliges Ergebnis entsteht.

~~~exercism/note
Vor Version 5.3 hatte Lua keinen arithmetischen Operator für die Floor-Division.
~~~

```lua
3 // 2    --> 1
6 // 2    --> 3
```

Die Floor-Division folgt denselben Regeln wie die Operatoren für Addition, Subtraktion, Multiplikation und Negation: Sind beide Operanden Ganzzahlen, ist das Ergebnis der Operation eine Ganzzahl, andernfalls ist das Ergebnis eine Gleitkommazahl.

```lua
3.0 // 2   --> 1.0
6.0 // 2.0 --> 3.0
```

Bei einer Division durch null mit der Floor-Division löst Lua einen Fehler aus.
```lua
3 // 0     --> stdin:1: attempt to divide by zero
```

### Modulo

Modulo wird verwendet, um den Rest der Division zweier Operanden zu erhalten.
```lua
8 % 2      --> 0
13 % 9     --> 4
-13 % -9   --> -4
-13 % 9    --> 5
13 % -9    --> -5
0.3 % 0.2  --> 0.1
```

### Potenzierung

Wie die Division arbeitet auch die Potenzierung mit Gleitkommazahlen und liefert Gleitkommazahlen als Ergebnisse.
```lua
10 ^ 2    --> 100.0
```

## Operatorrangfolge

Alle Operationen werden gemäß der [Operatorrangfolge](https://www.lua.org/manual/5.4/manual.html#3.4.8) ausgewertet. Mit runden Klammern kann die Rangfolge eines Ausdrucks geändert werden.

```lua
1 + 2 * 3   --> 7
(1 + 2) * 3 --> 9
```

## Runden

Das Modul `math` bietet drei Rundungsfunktionen: `floor` rundet „ab“ (in Richtung negative Unendlichkeit), `ceil` rundet „auf“ (in Richtung positive Unendlichkeit) und `modf` rundet in Richtung null.

### `math.floor`

`floor` rundet in Richtung negative Unendlichkeit.
```lua
math.floor(1.3)    --> 1
math.floor(-1.3)   --> -2
```

### `math.ceil`

`ceil` rundet in Richtung positive Unendlichkeit.
```lua
math.ceil(1.3)    --> 2
math.ceil(-1.3)   --> -1
```

### `math.modf`

`modf` rundet in Richtung null. Die Funktion gibt sowohl den gerundeten Wert als auch den Nachkommateil der Zahl zurück, der immer eine Gleitkommazahl ist.
```lua
math.modf(1.3)    --> 1    0.3
math.modf(-1.3)   --> -1   -0.3
```

## Umwandlung

Wenn wir eine Ganzzahl in eine Gleitkommazahl umwandeln wollen, können wir `0.0` dazu addieren.
```lua
1 + 0.0         --> 1.0
```

Wenn wir eine Gleitkommazahl in eine Ganzzahl umwandeln wollen, können wir sie bitweise mit null ODER-verknüpfen oder die Funktion `tointeger` aus dem Modul `math` verwenden.
```lua
1.0 | 0              --> 1
math.tointeger(1.0)  --> 1
```

Wenn die Zahl nicht in eine Ganzzahl umgewandelt werden kann, löst der OR-Operator einen Fehler aus und die Funktion `tointeger` gibt `nil` zurück.
```lua
1.1 | 0              --> stdin:1: number has no integer representation
math.tointeger(1.1)  --> nil
```

## Hexadezimalzahlen

Wie viele andere Programmiersprachen unterstützt Lua Hexadezimalzahlen, indem man ihnen `0x` voranstellt, aber anders als viele andere Programmiersprachen unterstützt Lua auch hexadezimale Gleitkommazahlen. Sie können einen Nachkommateil und einen binären Exponenten haben, dem ein 'p' oder 'P' vorangestellt ist.
```lua
0xff            --> 255
0x0.2           --> 0.125
0x3p-1          --> 1.5
0xa.bp2         --> 42.75
```
