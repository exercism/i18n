# Anleitung

Du bist ein großer Fan von Modelleisenbahnen und hast beschlossen, deine Leidenschaft mit der Welt zu teilen, indem du einen Newsletter startest. Zum Anfang schickst du die erste Ausgabe deines Newsletters an deine Freunde und Bekannten, die dein Hobby teilen. Du hast eine Textdatei mit einer Liste ihrer E-Mail-Adressen.

## 1. E-Mail-Adressen aus einer Datei lesen

Implementiere die Funktion `Newsletter.read_emails/1`. Sie erwartet einen Dateipfad. Die Datei ist eine Textdatei, die E-Mail-Adressen enthält, die durch Zeilenumbrüche getrennt sind. Die Funktion gibt eine Liste der E-Mail-Adressen aus der Datei zurück.

```elixir
Newsletter.read_emails("/home/my_user/documents/model_train_friends_emails.txt")
# => ["rick@example.com", "choochoo42@example.com", "anna@example.com"]
```

## 2. Eine Logdatei zum Schreiben öffnen

Das Senden einer E-Mail ist eine Aufgabe, die aus vielen unvorhersehbaren Gründen fehlschlagen kann, zum Beispiel wegen eines Tippfehlers in der E-Mail-Adresse oder vorübergehender Netzwerkprobleme. Damit du das Senden der E-Mails an alle deine Freunde wiederholen kannst, ohne Duplikate zu verschicken, musst du die E-Mail-Adressen protokollieren, die die E-Mail bereits erhalten haben. Dafür brauchst du eine Logdatei.

Implementiere die Funktion `Newsletter.open_log/1`. Sie erwartet einen Dateipfad, öffnet die Datei zum Schreiben und gibt die PID des Prozesses zurück, der die Datei verwaltet.

```elixir
Newsletter.open_log("/home/my_user/documents/newsletter_issue1_log.txt")
# => #PID<0.145.0>
```

## 3. Eine gesendete E-Mail protokollieren

Implementiere die Funktion `Newsletter.log_sent_email/2`. Sie erwartet die PID des Prozesses, der die Datei verwaltet, und einen String mit der E-Mail-Adresse. Sie schreibt die E-Mail-Adresse in die Datei, gefolgt von einem Zeilenumbruch.

```elixir
Newsletter.log_sent_email(pid, "joe@example.com")
# => :ok
```

## 4. Die Logdatei schließen

Implementiere die Funktion `Newsletter.close_log/1`. Sie erwartet die PID des Prozesses, der die Datei verwaltet, und schließt die Datei.

```elixir
Newsletter.close_log(pid)
# => :ok
```

## 5. Den Newsletter verschicken

Jetzt, wo du alle Bausteine für das Versenden der E-Mails hast, musst du sie in einer einzigen Funktion zusammenführen.

Implementiere die Funktion `Newsletter.send_newsletter/3`. Sie erwartet den Pfad der Datei mit den E-Mail-Adressen, den Pfad einer Logdatei und eine anonyme Funktion, die eine E-Mail an eine bestimmte E-Mail-Adresse sendet. Sie liest alle E-Mail-Adressen aus der angegebenen Datei und versucht, an jede von ihnen eine E-Mail zu senden. Wenn die anonyme Funktion, die die E-Mail sendet, `:ok` zurückgibt, schreibe die E-Mail-Adresse in die Logdatei, gefolgt von einem Zeilenumbruch. Achte darauf, dass du das sofort tust, sobald die E-Mail gesendet wurde. Nachdem alle E-Mails gesendet wurden, schließe die Logdatei.

```elixir
Newsletter.send_newsletter(
  "model_train_friends_emails.txt",
  "newsletter_issue1_log.txt",
  fn email -> :ok end
)

# => :ok
```
