# print-Anweisungen vermeiden

Versuche, Anweisungen wie `System.out.println()` aus deinem Code zu entfernen.
Die Tests der Übung verlangen, dass die Lösung Werte aus Methoden _zurückgibt_, statt sie auszugeben.

Normalerweise fügt man solche Anweisungen hinzu, um den Code zu debuggen.
Ein besserer Ansatz ist jedoch, den Code zu debuggen, während ein oder mehrere Unit-Tests laufen.
Das hat den zusätzlichen Vorteil, dass du dich auf das Debuggen eines bestimmten Testfalls konzentrieren kannst.

Hier sind einige Links, die erklären, wie du Java-Code beim Ausführen von Unit-Tests in verschiedenen IDEs debuggen kannst:

- [Java-Tests in Visual Studio Code ausführen und debuggen](https://code.visualstudio.com/docs/java/java-testing#_rundebug-test-cases)
- [Tests in IntelliJ IDEA debuggen](https://www.jetbrains.com/help/idea/performing-tests.html#RedebugFailedTests)
