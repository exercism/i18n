# Codepunkt direkt in einen String umwandeln

Der einfachste Weg, einen Zeichen-Codepunkt in einen String mit diesem Zeichen umzuwandeln, ist die spezielle Form `<<>>` zu verwenden. Du brauchst keine Charlist als Zwischenschritt.

```elixir
# instead of:
to_string([?A])
# => "A"

# use:
<<?A>>
# => "A"
```
