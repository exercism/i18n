# Einführung

In Go wird eine Anwendung in Pakete organisiert.
Ein Paket ist eine Sammlung von Quelldateien, die im selben Ordner liegen.
Alle Quelldateien in einem Ordner müssen oben in der Datei denselben Paketnamen haben.
Nach Konvention benennt man ein Paket genauso wie den Ordner, in dem es liegt.

```go
package greeting
```

Go bietet eine umfangreiche Standardbibliothek mit Paketen, die du in deinem Programm mit dem Schlüsselwort `import` verwenden kannst.
Pakete aus der Standardbibliothek importierst du über ihren Namen.

```go
package greeting

import "fmt"
```

Ein importiertes Paket sprichst du dann über den Paketnamen an:

```go
world := "World"
fmt.Sprintf("Hello %s", world)
```

Ob Code in anderen Paketen auf ein Element zugreifen kann, entscheidet Go anhand seiner Deklaration.
Damit eine Funktion, ein Typ, eine Variable, eine Konstante oder ein Struct-Feld von außen sichtbar ist (man nennt das _exportiert_), muss der Name mit einem Großbuchstaben beginnen.
Das ist analog dazu, wie andere Programmiersprachen wie Java Zugriffsmodifizierer wie `public` und `private` verwenden.

```go
package greeting

// Hello is a public function (callable from other packages).
func Hello(name string) string {
    return "Hello " + name
}

// hello is a private function (not callable from other packages).
func hello(name string) string {
    return "Hello " + name
}
```
