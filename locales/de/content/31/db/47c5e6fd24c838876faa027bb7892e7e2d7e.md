# Anleitung

Elaine arbeitet an einem neuen Kinderspiel, in dem Tiere und Zauberstäbe vorkommen. Jetzt ist es Zeit, Funktionen für das Würfeln, das Erzeugen zufälliger Zauberstab-Energie und das Mischen eines Slice zu programmieren.

## 1. Einen Würfel würfeln

Implementiere eine Funktion `RollADie`.

Das ist der klassische zwanzigseitige Würfel mit den Zahlen 1 bis 20.

```go
d := RollADie() // d will be assigned a random int, 1 <= d <= 20
```

## 2. Zauberstab-Energie erzeugen

Implementiere eine Funktion `GenerateWandEnergy`.
Die Zauberstab-Energie sollte eine zufällige Gleitkommazahl sein, die größer oder gleich 0.0 und kleiner als 12.0 ist.

```go
f := GenerateWandEnergy()  // f will be assigned a random float64, 0.0 <= f < 12.0
```

## 3. Ein Slice mischen

Das Spiel enthält acht verschiedene Tiere:

- ant
- beaver
- cat
- dog
- elephant
- fox
- giraffe
- hedgehog

Schreibe eine Funktion `ShuffleAnimals`, die ein Slice mit den acht Tieren in zufälliger Reihenfolge zurückgibt.
