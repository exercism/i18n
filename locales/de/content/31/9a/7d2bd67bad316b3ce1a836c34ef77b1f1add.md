# Anweisungen

In dieser Übung verarbeitest du Logzeilen.

Jede Logzeile ist ein String mit folgendem Format: `"[<LEVEL>]: <MESSAGE>"`.

Es gibt drei verschiedene Log-Level:

- `INFO`
- `WARNING`
- `ERROR`

Du hast drei Aufgaben. Jede bekommt eine Logzeile, und du sollst etwas damit machen.

Du kannst entweder die alten Funktionen aus base R oder die Bibliothek `stringr` verwenden. Beide führen zu kurzen, brauchbaren Lösungen.

## 1. Nachricht aus einer Logzeile auslesen

Implementiere die Funktion `message`, die die Nachricht einer Logzeile zurückgibt:

```R
message("[ERROR]: Invalid operation")
#> "Invalid operation"
```

Führender und nachfolgender Leerraum soll entfernt werden:

```R
message("[WARNING]:  Disk almost full\r\n")
#> "Disk almost full"
```

## 2. Log-Level aus einer Logzeile auslesen

Implementiere die Funktion `log_level`, die das Log-Level einer Logzeile zurückgibt. Es soll in Kleinbuchstaben zurückgegeben werden:

```R
log_level("[ERROR]: Invalid operation")
#> "error"
```

## 3. Eine Logzeile umformatieren

Implementiere die Funktion `reformat`, die die Logzeile umformatiert. Die Nachricht steht zuerst, danach folgt das Log-Level in Klammern:

```R
reformat("[INFO]: Operation completed")
#> "Operation completed (info)"
```
