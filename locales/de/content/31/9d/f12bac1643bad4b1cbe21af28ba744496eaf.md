# Vergleichsoperatoren

PHP hat zehn eingebaute Vergleichsoperatoren:

| Name  | Beispiel    | Ergebnis                                             |
| ----- | ---------- | -------------------------------------------------- |
| Gleich | `$a == $b` | wahr, wenn `$a` nach der Typumwandlung gleich `$b` ist. |
| Identisch | `$a === $b` | wahr, wenn `$a` gleich `$b` ist und denselben Typ hat. |
| Ungleich | `$a != $b` | wahr, wenn `$a` nach der Typumwandlung nicht gleich `$b` ist. |
| Ungleich | `$a <> $b` | wahr, wenn `$a` nach der Typumwandlung nicht gleich `$b` ist. |
| Nicht identisch | `$a !== $b` | wahr, wenn `$a` nicht gleich `$b` ist oder nicht denselben Typ hat. |
| Kleiner als | `$a < $b` | wahr, wenn `$a` echt kleiner als `$b` ist. |
| Größer als | `$a > $b` | wahr, wenn `$a` echt größer als `$b` ist. |
| Kleiner oder gleich | `$a <= $b` | wahr, wenn `$a` kleiner oder gleich `$b` ist. |
| Größer oder gleich | `$a >= $b` | wahr, wenn `$a` größer oder gleich `$b` ist. |
| Spaceship | `$a <=> $b` | gibt eine Ganzzahl zurück, die kleiner, gleich oder größer als `0`i ist, wenn `$a`. |

PHP hat unterschiedliche Definitionen, die zwischen `equal` und `identical` unterscheiden. Manchmal wird `identical` auch als `strictly equal` bezeichnet.

```php
<?php

// Comparisons between integer and numeric string values
1 == "1"; // => true, equal
1 === "1"; // => false, not identical

// Comparisons between integers and floating point values
1 == 1.0; // => true
1 === 1.0; // => false

// Comparisons between object instances
new stdClass() == new stdClass(); // => true, properties are equal
new stdClass() === new stdClass(); // => false, references are not identical
```
