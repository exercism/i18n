# Installation

## Node.js installieren

**Windows- und OS-X-Nutzer**: Installiere [Node.js][node] [über den Paketmanager][node-download].

**Linux-Nutzer**: Installiere [Node.js][node] nach der Anleitung, die du für deine Distribution auf der Seite [Paketmanager für Node.js][linstall] findest.

## `jasmine-node` und `coffeescript` installieren

Für die meisten Nutzer genügt es, den folgenden Befehl auszuführen:

```bash
$ npm install -g jasmine-node coffeescript
```

Je nach deinem Setup brauchst du möglicherweise Superuser-Rechte, um ein `npm`-Modul global zu installieren.
Das ist der Fall, wenn du den oben verlinkten offiziellen Installer verwendet hast.
Wenn npm dir einen Fehler meldet, dass du keinen Zugriff hast, setze `sudo` vor den obigen Befehl:

```bash
$ sudo npm install -g jasmine-node coffeescript
```

Wenn du den offiziellen Installer verwendet hast, sollte dein `PATH` automatisch konfiguriert worden sein. Wenn deine Shell aber Probleme hat, deine global installierten Module zu finden, oder wenn du Node.js aus dem Quellcode baust.
Dann erweitere deinen `PATH` um die `npm`-Binärdateien, indem du das Folgende entweder zu `~/.bash_profile` oder zu `~/.zshrc` hinzufügst:

```bash
$ export PATH=/usr/local/share/npm/bin:$PATH
```
