# Über

[Klassen](https://docs.microsoft.com/en-us/dotnet/fsharp/language-reference/classes) sind das primäre Konstrukt für objektorientierte Programmierung in F#.

Eine Klasse in F# besteht aus ihren Feldern und Methoden. Die Felder und Methoden einer Klasse nennt man ihre _Member_.

Klassen in F# werden mit dem Schlüsselwort `type` definiert. Methoden werden mit dem Schlüsselwort `member` definiert und sind immer öffentlich. Um (private) Felder zu definieren, kannst du `let`-Bindungen verwenden.

```fsharp
type Shoe() =
    let size = 8

    member this.Describe() = $"This is a size {size} shoe"
```

Klassen sind Vorlagen, mit denen du Objekte erstellst. Um eine Instanz einer Klasse zu erstellen, rufst du den Namen der Klasse wie eine Funktion auf. Eine Instanz einer Klasse nennt man auch _Objekt_.

Mit der Punktnotation kannst du auf die Member eines Objekts zugreifen.

```fsharp
let myShoe = Shoe()
myShoe.Describe()
// => "This is a size 8 shoe"
```
