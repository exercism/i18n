# Einführung

## Ausnahmen filtern

`when` ist das Schlüsselwort zum Filtern von Ausnahmen. Es steht nach der `catch`-Anweisung und kann einen booleschen Ausdruck annehmen, der alle Werte enthält, die zu diesem Zeitpunkt im Gültigkeitsbereich liegen. Ergibt der Ausdruck wahr, wird der Block ausgeführt, der zu dieser `catch`-Anweisung gehört. Andernfalls wird die nächste `catch`-Anweisung geprüft, falls es eine gibt.

```csharp
try
{
    // do stuff
}
catch (Exception ex) when (ex.Message != "")
{
    // output the message when it is not empty
}
catch (Exception ex)
{
    // show stack trace or something.
}
```

## Benutzerdefinierte Ausnahmen

Eine benutzerdefinierte Ausnahme ist jede Klasse, die in deinem Code definiert und von `System.Exception` abgeleitet ist. Für sie gelten alle Regeln der Klassenvererbung. Zusätzlich behandeln der Compiler und die Laufzeitumgebung solche Klassen aber auf besondere Weise: Ihre Instanzen können, wie in der Übung `exceptions` besprochen, außerhalb des normalen Kontrollflusses ausgelöst und abgefangen werden.

Benutzerdefinierte Ausnahmen werden oft genutzt, um zusätzliche Informationen wie eine Nachricht und andere relevante Daten an die abfangenden Routinen weiterzugeben.
