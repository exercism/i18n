# Einführung

## Grundlagen

Zum Einstieg in die C++-Reise beginnen wir mit Variablen, Funktionsaufrufen und Kommentaren.

### Kommentare

Kommentare gibt es in zwei Varianten: einzeilig und mehrzeilig.
Alles, was nach `//` in derselben Zeile steht, wird vom Compiler ignoriert.
Mehrzeilige Kommentare werden auch als C-Stil-Kommentare bezeichnet.
Sie werden von `/*` und `*/` umschlossen.
Alles, was dazwischen steht, wird ebenfalls ignoriert.

### Variablen

C++ ist eine typisierte Sprache.
Alle Typen müssen zur Kompilierzeit bekannt sein, und du musst sie in der Regel explizit angeben.
Der Typ einer Variablen kann sich nicht ändern.
Eine Variable vom Typ Ganzzahl mit dem Namen `years` kann so deklariert werden:

```cpp
int years;
```

Es ist gute Praxis, Variablen bei der Deklaration zu initialisieren.
C++ bietet verschiedene Mechanismen dafür.
Die Version mit den geschweiften Klammern entspricht eher modernem C++, aber die Version mit dem Gleichheitszeichen ist ebenfalls sehr verbreitet.

```cpp
int tomatoes{80};
int potatoes = 40;
```

~~~~exercism/caution
C++ erlaubt es tatsächlich, uninitialisierte Variablen zu verwenden.
Bis die Variable bewusst gesetzt wird, ist sie undefiniert und kann irgendetwas enthalten.
Um Fehler durch Verwendung vor dem Setzen und undefiniertes Verhalten zu vermeiden, solltest du **immer initialisieren**.
Undefiniertes Verhalten kann dein Programm im ungünstigsten Moment zum Absturz bringen, obwohl es vorher einwandfrei lief.
Man kann es nicht oft genug betonen: Vermeide undefiniertes Verhalten um jeden Preis.
~~~~

### Arithmetische Operationen

Arithmetische Operatoren wie `*`, `+` oder `-` können Teil eines Ausdrucks wie `3 * 2` oder `tomatoes + potatoes` sein.

### Variablen aktualisieren

Du kannst Variablen neu zuweisen, solange sie ihren Typ behalten:

```cpp
tomatoes = tomatoes - 5; // tomatoes is now 75
potatoes = (32 * 2) + 11; // potatoes is now 75 as well
```

### Funktionen

Funktionen haben einen Namen, einen Rückgabetyp und eine (möglicherweise leere) Parameterliste.
Ein Beispiel für eine Funktion namens `always_fortyseven`, die immer 47 zurückgeben würde, sieht so aus:

```cpp
int always_fortyseven() {
    return 47;
}
```

Hier ist `vip_fee`, die einen Parameter hat:

```cpp
int vip_fee(int standard_fee) {
    /*
    vip_fee calculates the vip fee based on the standard_fee.
    */
    int vip_multi{3};
    return standard_fee * vip_multi;
}
```

Oder `total_fee`, eine Funktion mit drei Parametern und einem Aufruf einer anderen Funktion.

```cpp
int total_fee(int vips, int adults, int kids) {
    /*
    total_fee calculates the total price for a group of VIP and adult guests with kids.
    Kids get a flat discount on the standard fee.
    VIP guest fees are calculated by calling vip_fee.
    */
    int standard_fee{30};
    int kids_discount{15};

    int kids_total_fee = kids * (standard_fee - kids_discount);
    int vips_total_fee = vips * vip_fee(standard_fee);
    int adult_total_fee = adults * standard_fee;

    return vips_total_fee + adult_total_fee + kids_total_fee;
}
```

Funktionen in C++ geben nicht den Wert der letzten Anweisung zurück, wie in einigen anderen Sprachen.
Das Schlüsselwort `return` ist erforderlich, damit der Code kompiliert.

### Whitespace

Whitespace wird zum Formatieren von Quellcode verwendet und umfasst Leerzeichen, Tabulatoren oder Zeilenumbrüche.
Da der Compiler unnötigen Whitespace ignoriert, kannst du ihn verwenden, um deinen Code zu strukturieren.
Ein kluger Einsatz von Whitespace kann die Lesbarkeit deines Codes verbessern.
Es gibt verschiedene Formatierungsstandards, aber sie sind alle konventionell und werden nicht vom Compiler erzwungen.

```cpp
// Formatting makes it easier to find bugs

int eggs_yolks =  3;
int      yeast = 15;

int flour=500;int sugar=200;// compact, but difficult to read
```
