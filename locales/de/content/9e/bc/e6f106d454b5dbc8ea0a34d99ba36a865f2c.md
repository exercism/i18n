# Anweisungen

In dieser Übung arbeitest du in einer Pizzeria, die an Kunden liefert.

Du bietest drei Pizzaarten an:

- Margherita: \$7
- Caprese: \$9
- Formaggio: \$10

Kunden können außerdem zwei zusätzliche Optionen gegen eine kleine Zusatzgebühr wählen:

1. Extrasoße: \$1
1. Extra-Belag: \$2

Wenn Kunden eine Bestellung aufgeben, wird eine zusätzliche Gebühr berechnet, wenn sie nur eine oder zwei Pizzen bestellen:

- 1 Pizza: \$3
- 2 Pizzen: \$2

Du hast drei Aufgaben, die sich jeweils mit Pizzen und ihrem Preis beschäftigen.

## 1. Definiere die Pizzatypen und Optionen

Definiere die diskriminierte Union `Pizza`, um die Pizzatypen und die beiden zusätzlichen Optionen darzustellen, die einer Pizza hinzugefügt werden können:

- `Margherita`
- `Caprese`
- `Formaggio`
- `ExtraSauce`
- `ExtraToppings`

## 2. Berechne den Preis einer Pizza

Implementiere die Funktion `pizzaPrice`, um den Preis einer Pizza zu berechnen:

```fsharp
pizzaPrice Caprese
// => 9
```

## 3. Berechne den Preis einer Bestellung

Implementiere die Funktion `orderPrice`, um den Preis einer Pizzabestellung zu berechnen:

```fsharp
orderPrice [Margherita; Formaggio]
// => 19
```
