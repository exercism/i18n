# Tests

## Interaktiv testen

Starte deine Common-Lisp-Implementierung in dem Verzeichnis der Übung, an der du gerade arbeitest (oder wechsle mit einer bereits laufenden Common-Lisp-Implementierung in dieses Verzeichnis).
Mit roswell machst du das mit `ros run`.

(Alle Beispiele hier gehen von einer Übung namens `exercise-name` aus. Passe das nach Bedarf an.)

Lade die Testdatei in deine laufende Lisp-Implementierung, zum Beispiel mit `(load "exercise-name-test")`.
(Damit wird auch die Lösungsdatei für dich geladen.)
Nachdem die Testdatei geladen ist, kannst du die Tests ausführen, indem du `(exercise-name-test:run-tests)` in der REPL auswertest.

Wenn du Änderungen an der Lösung vornimmst, die du gerade schreibst, nutze die Funktionen deines Editors, um die Änderungen zu laden, oder werte `(load "exercise-name")` aus, um deine Lösungsdatei zu laden.

Denk daran, `(exercise-name-test:run-tests)` auszuwerten, um die Tests erneut auszuführen, nachdem du deine aktualisierte Lösung geladen hast.

## Tests von der Kommandozeile aus

Du kannst die Tests mit diesem Kommandozeilenaufruf starten (ersetze wieder „exercise“ an zwei Stellen durch den passenden Namen)

```sh
ros run --load exercise-test.lisp --eval '(uiop:quit (if (exercise-test:run-tests) 0 1))'
```

Dieser Befehl ist ziemlich unhandlich.
Ein Contributor hat ein paar Notizen dazu geschrieben, [wie man ihn einfacher aufrufen kann](https://glennj.github.io/exercism/cli).
