# Einführung

Neben `cond` bietet Elixir auch das Makro [`if/2`][getting-started-if], das nützlich ist, wenn du nur eine einzige Bedingung prüfen musst.

[`if/2`][kernel-if] akzeptiert eine Bedingung und zwei Optionen. Es gibt die erste Option zurück, wenn die Bedingung _truthy_ ist, und die zweite Option, wenn die Bedingung _falsy_ ist.

```elixir
age = 15

if age >= 16 do
  "You are allowed to drink beer in Germany."
else
  "No beer for you!"
end

# => "No beer for you!"
```

Es ist auch möglich, einen `if`-Ausdruck in einer einzigen Zeile zu schreiben. Beachte das Komma nach der Bedingung.

```elixir
if age > 16, do: "beer", else: "no beer"
```

Diese Syntax ist hilfreich für sehr kurze Ausdrücke, sollte aber vermieden werden, wenn der Ausdruck nicht in eine einzige Zeile passt.

## _Truthy_ und _Falsy_

In Elixir ergeben alle Datentypen einen _truthy_- oder _falsy_-Wert, wenn sie in einem booleschen Kontext (wie einem `if`-Ausdruck) auftauchen. Alle Daten gelten als _truthy_, **außer** `false` und `nil`. Insbesondere leere Strings, die Ganzzahl `0` und leere Listen gelten in Elixir alle als _truthy_.
