# Überblick

[Ranges][range] stehen für eine Folge von einer oder mehreren aufeinanderfolgenden Ganzzahlen. Sie:

- werden mit dem [`..`-Operator][range-operator] erzeugt und können sowohl aufsteigend als auch absteigend sein.
- haben die Standardschrittweite `1`, die sich mit dem [`..//`-Operator][range-operator-with-step] ändern lässt (seit Elixir 1.12).
- schließen den ersten und den letzten Wert ein.
- implementieren das [_Enumerable-Protokoll_][enumerable].
- werden intern als Struct dargestellt, lassen sich aber mit `..` per Pattern Matching abgleichen.
- können mit Ganzzahlen in binärer, oktaler, hexadezimaler und Codepoint-Notation verwendet werden.
- lassen sich mit Funktionen wie [`Enum.to_list/1`][enum-to-list] oder [`Enum.map/2`][enum-map] in Listen umwandeln.

```elixir
Enum.to_list(9..1)
# => [9, 8, 7, 6, 5, 4, 3, 2, 1]

Enum.map(?A..?F, &<<&1>>)
["A", "B", "C", "D", "E", "F"]
```
