## Boolesche Werte

Raku hat die booleschen Literale `True` und `False`.
Im booleschen Kontext gilt alles Undefinierte als `False`.
Neben `Bool::False` selbst gelten unter anderem `0`, `NaN`, `()` (leere Liste), `""` (leerer String) und Objekte vom Typ `Failure` als `False`.

Der [Präfix-Operator `?`][&prefix:<?>] erzwingt booleschen Kontext für ein Objekt.
Sein Verhalten entspricht dem Aufruf der Methode [`Bool`][routine/Bool] auf diesem Objekt.
Der [Präfix-Operator `!`][&prefix:<!>] liefert die Umkehrung des Präfix-Operators `?`.

## Boolesche Infix-Operatoren

### Smartmatch

Der [Infix-Operator `~~`][&infix:<~~>], auch als Smartmatch-Operator bekannt, ist ein häufig verwendetes Werkzeug in Raku.
Sein Verhalten hängt davon ab, welches Objekt auf der rechten Seite des Operators steht, denn er ist eine Kurzform für die Methode [`ACCEPTS`][routine/ACCEPTS] dieses Objekts.
Der Wert auf der linken Seite wird als Argument an `ACCEPTS` übergeben.
Das Ergebnis ist ein boolescher Wert.

### Logisches AND/OR

Raku hat die Operatoren [`&&`][&infix:<&&>]/[`and`][&infix:<and>], [`||`][&infix:<||>]/[`or`][&infix:<or>], [`//`][&infix:<//>]/[`orelse`][&infix:<orelse>] und [`^^`][&infix:<^^>]/[`xor`][&infix:<xor>] für die boolesche Logik (mit fester bzw. lockerer Präzedenz).
Diese lassen sich verketten.

```raku
1 xor 1 xor 1;
# Nil in Raku, 1 in Perl (because the latter makes the first pair false).
```

### Ternärer Operator

Raku hat einen ternären bzw. bedingten [Infix-Operator `?? !!`][infix-??-!!], der als `$condition ?? $true !! $false` geschrieben wird.

## Kontrollfluss

### if/elsif/else

Mit einer [`if`][control-if]-Anweisung führst du einen Block Code bedingt aus.
Um eine `if`-Anweisung zu erstellen, folgt auf das Schlüsselwort `if` ein [Ausdruck][statements-and-expressions] und danach ein [Block][control-block].

Der Ausdruck wird im [booleschen Kontext][contexts-boolean] ausgewertet, und der Block wird ausgeführt, wenn der Ausdruck `True` ergibt.

Eine `if`-Anweisung lässt sich mit den Schlüsselwörtern [`elsif` und `else`][control-else/elsif] erweitern, die genauso wie `if` geschrieben werden. Ein `else`-Block wird ausgeführt, wenn alle vorherigen Ausdrücke `False` ergeben, und ein `elsif`-Block wird genauso ausgeführt, wenn sein eigener Ausdruck `True` ergibt.

Alternativ kannst du `if` in der Form des Anweisungsmodifikators verwenden:

```raku
say 'success' if True;
```

Der Anweisungsmodifikator kann nicht mit `elsif` oder `else` verwendet werden.

### given/when/default

Die [`given`][control-given]-Anweisung ist Rakus topikalisierendes Schlüsselwort, ähnlich wie `switch` in Sprachen wie C topikalisiert.
Die Schlüsselwörter für die einzelnen Fälle sind [`when` und `default`][control-default-and-when].

### for/while/loop

Eine [`for`][control-for]-Anweisung durchläuft eine gegebene Liste und führt für jedes darin enthaltene Element einen Block aus.

Eine [`while`][control-while]-Anweisung führt einen Block wiederholt aus, solange ihr gegebener Ausdruck `True` ergibt.

Eine [`loop`][control-loop]-Anweisung kann auf zwei Arten geschrieben werden.
Wird ihr nur ein Block übergeben, führt sie diesen Block wiederholt aus, bis etwas die Schleife explizit abbricht.
Sie kann auch als `for`-Schleife im C-Stil geschrieben werden, mit einer Initialisierung, einer Bedingung und einer Erhöhung in runden Klammern vor dem Block.

```raku
loop (my $i = 0; $i < 10; $i++) {
    say $i;
}
```
