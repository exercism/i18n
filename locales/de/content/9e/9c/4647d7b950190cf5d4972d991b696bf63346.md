# Anleitung

Jen arbeitet im Sortierraum einer großen Fabrik.
Der Sortierraum muss alles verarbeiten, was hereinkommt, indem er es kategorisiert und mit einem Etikett versieht.
Jen ist für Dinge zuständig, die bereits als Zahlen vorkategorisiert wurden, und braucht ein Programm, das ihr beim Sortieren hilft.

Die meisten primitiven Werte sollten unkomplizierte Etiketten bekommen.
Für Zahlen möchte sie Strings, die `"This is the number 2.0"` lauten (wenn die Zahl 2 war).
Jen möchte dieselbe Ausgabe für Ganzzahlen und Gleitkommazahlen.

Es gibt ein paar `Box`-Schnittstellen, die entpackt werden müssen, um an ihren Inhalt zu kommen.
Für eine `NumberBox` möchte sie Strings, die `"This is a box containing the number 3.0"` lauten (wenn die Methode `Number()` 3 zurückgibt).
Für eine `FancyNumberBox` möchte sie Strings, die `"This is a fancy box containing the number 4.0"` lauten, aber nur, wenn der Typ ein `FancyNumber` ist.

Alles Unerwartete sollte `"Return to sender"` ausgeben, damit Jen es dorthin zurückschicken kann, wo es hergekommen ist.

## 1. Einfache Zahlen beschreiben

Jen möchte, dass Zahlen Strings wie `"This is the number 2.0"` zurückgeben (mit einer Nachkommastelle):

```go
fmt.Println(DescribeNumber(-12.345))
// Output: This is the number -12.3
```

## 2. Eine Zahlenbox beschreiben

Jen möchte, dass Zahlenboxen Strings wie `"This is a box containing the number 2.0"` zurückgeben (wieder mit einer Nachkommastelle):

```go
fmt.Println(DescribeNumberBox(numberBoxContaining{12}))
// Output: This is a box containing the number 12.0
```

## 3. Eine Methode implementieren, die die Zahl aus einer Fancy-Number-Box extrahiert

Jen braucht eine Hilfsfunktion, um die Zahl aus einer `FancyNumberBox` zu extrahieren.
Wenn die `FancyNumberBox` ein `FancyNumber` ist, extrahiere ihren Wert und wandle ihn von einem `string` in einen `int` um.
Jeder andere Typ von `FancyNumberBox` sollte 0 zurückgeben.

```go
fmt.Println(ExtractFancyNumber(FancyNumber{"10"}))
// Output: 10
fmt.Println(ExtractFancyNumber(AnotherFancyNumber{"4"}))
// Output: 0
```

## 4. Eine Fancy-Number-Box beschreiben

Wenn die `FancyNumberBox` ein `FancyNumber` ist, möchte Jen Strings, die `"This is a fancy box containing the number 4.0"` lauten.
Jeder andere Typ von `FancyNumberBox` sollte `"This is a fancy box containing the number 0.0"` ausgeben.

```go
fmt.Println(DescribeFancyNumberBox(FancyNumber{"10"}))
// Output: This is a fancy box containing the number 10.0
fmt.Println(DescribeFancyNumberBox(AnotherFancyNumber{"4"}))
// Output: This is a fancy box containing the number 0.0
```

HINWEIS: Wir sollten die Funktion `ExtractFancyNumber` verwenden!

## 5. `DescribeAnything` implementieren, das alle anderen nutzt

Das ist die Hauptfunktion, die Jen braucht und die jede beliebige Eingabe annimmt.
`DescribeAnything` sollte anhand des Typs des übergebenen Werts an die anderen Funktionen delegieren.
Genauer gesagt:

- `int` und `float64` sollten beide an `DescribeNumber` delegieren
- `NumberBox` sollte an `DescribeNumberBox` delegieren
- `FancyNumberBox` sollte an `DescribeFancyNumberBox` delegieren
- alles andere sollte `"Return to sender"` ergeben

```go
fmt.Println(DescribeAnything(numberBoxContaining{12.345}))
// Output: This is a box containing the number 12.3
fmt.Println(DescribeAnything("some string"))
// Output: Return to sender
```
