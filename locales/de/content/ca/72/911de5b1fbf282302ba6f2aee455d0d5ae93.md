# Einführung

## Aufzählungen

Bisher haben wir uns überwiegend mit Zahlen und Strings beschäftigt.
Um die reale Welt abzubilden, möchten wir vielleicht eine begrenzte Anzahl von Werten haben, die eine Variable annehmen kann.
Vielleicht möchtest du einen eigenen Typ mit ein paar unterschiedlichen Werten mit unterschiedlichen Namen.
Zum Beispiel in einer Skateboard-Fabrik, wo das Material des Decks nur maple, bamboo oder plastic sein kann.

Du könntest Ganzzahlen verwenden, um diese Werte zu kodieren, aber du müsstest zusätzlichen Code schreiben, um zu prüfen, ob ein ungültiger Wert für das Material aus dem System kommt.
Die Bedeutung dieser [_Magische Zahlen_][magic numbers] lässt sich im Quellcode schwer nachvollziehen, und sie führen leicht zu Verwechslungen.
Mit `enumerations` förderst du ausdrucksstarken Code und schränkst unbeabsichtigte Vergleichsfehler ein.

## Anwendungsbeispiel

Der genaue Begriff für diese Art von Aufzählung ist `scoped enumeration`.
Das folgende Codefragment zeigt, wie du eine `enumeration` namens `DeckMaterial` schreibst.
Beachte das Schlüsselwort `enum class` und das `;` am Ende der Definition:

```cpp
enum class DeckMaterial {
    maple,
    bamboo,
    plastic
};
```
Schau dir jetzt eine Preisfunktion im Skateboard-Laden an und beachte den Bereichsauflösungsoperator (`::`), der einen `enumerator` aus der `enumeration` angibt:

```cpp
double deck_price(double base_price, DeckMaterial material) {
    if(material == DeckMaterial::plastic) {
        return base_price * 0.9;
    }
    return base_price * 1.3;
}
```

## Gültigkeitsbereiche

Stell dir vor, du hast eine zweite `enumeration` für das Material der Rollen:

```cpp
enum class WheelMaterial {
    steel,
    clay,
    plastic
};
```
Obwohl die Rollen und das Deck beide aus _plastic_ bestehen können, lassen sich die beiden nicht verwechseln.
Sie sind verschiedene _Typen_: `DeckMaterial` plastic und `WheelMaterial` plastic.
Jede `enumeration` hat ihre `enumerators` in ihrem eigenen Gültigkeitsbereich, ihrem eigenen `namespace`.
Deshalb heißen sie `scoped enumerations`.

## Aufzählungen ohne Gültigkeitsbereich
Vielleicht denkst du, dass es bei einem Namen wie `scoped` auch _`unscoped`_ Aufzählungen geben müsste, und du hast recht.
`Unscoped enumerations` werden immer unbeliebter, weil sie sich alle denselben globalen Namensraum teilen.
Weil sie sich denselben Namensraum teilen, könntest du nicht zwei `unscoped enumerations` haben, deren `enumerators` gleich heißen, wie _plastic_ im Beispiel oben.

Außerdem werden `unscoped enumerations` implizit in Ganzzahlen umgewandelt.
Schau dir das folgende Beispiel an, das ein überraschendes Ergebnis liefert:

```cpp
enum CitrusFruits {
    lemons,  // 0
    oranges, //1
};

enum IceCream {
    walnut,  // 0
    apples,  // 1
};

bool comparison{apples == oranges};
// => true

// Example from above:
bool comparison{DeckMaterial::plastic == WheelMaterial::plastic};
// => Does not compile!
```

Wenn du `scoped enumerations` in Ganzzahlen umwandeln willst, kannst du `static_cast<int>` verwenden.

## switch-Anweisungen

Wie andere Sprachen bietet auch C++ eine `switch`-Anweisung.
Eine switch-Anweisung ist eine kürzere Schreibweise für lange `if ... else if`-Anweisungen.
Um eine switch-Anweisung zu erstellen, beginnen wir mit dem Schlüsselwort `switch`, gefolgt von einer Ganzzahl.
Danach deklarieren wir jede einzelne Bedingung mit dem Schlüsselwort `case`.
Wir können außerdem einen `default`-Fall deklarieren, der ausgeführt wird, wenn keine der vorherigen `case`-Bedingungen zutrifft.
Jeder Fall sollte mit einer `break`- (oder `return`-)Anweisung enden.

```cpp
int price{0};
int adults{3};
int kids{2};

switch (int group_size{adults + kids}) {
    case 1:
        price = 50;
        break;
    case 2:
        price = 70;
        break;
    default:
        price = group_size * 30;
}
```

## Fallthrough

Ein wichtiger Punkt am switch-Konstrukt ist, dass der Code so lange weiter ausgeführt wird, bis er durch eine `break`- (oder `return`-)Anweisung gestoppt wird.
Das kann zu unerwartetem Verhalten führen.

```cpp
int adults{1};
int kids{0};
switch (int group_size{adults + kids}) {
    case 1:
        price = 50;
    case 2:
        price = 70;
    default:
        price = group_size * 30;
}
// price will be 30!
```

Der wichtigste Anwendungsfall für diese fortgesetzte Ausführung ist eine Anweisung mit mehreren Marken.
Mehrere switch-Ergebnisse können auf denselben auszuführenden Codeabschnitt verweisen.
So kann zum Beispiel in einer Buchungs-App die aufgerufene Funktion für die Gruppengrößen 2 und 3 dieselbe sein:
```cpp
switch (group_size) {
case 1:
    book_room();
    break;
case 2:
case 3:
    book_apartment(group_size);
    break;
default:
    book_house(group_size);
}
// book_apartment happens when group_size is 2 or 3
```
