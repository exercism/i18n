# Tests ausführen

SWI Prolog kannst du entweder interaktiv ausführen oder direkt auf der Kommandozeile starten.

## Kommandozeile

Mit dem folgenden Befehl kannst du die Tests von der Kommandozeile aus ausführen:

```bash
swipl -f <exercise>.pl -s <exercise>_tests.plt -g run_tests,halt -t 'halt(1)'
```

Ersetze `<exercise>` durch den Namen der Übung, die du gerade bearbeitest.

## Interaktiv

Um Prolog interaktiv auszuführen, starte zuerst:

```bash
swipl
```

Nachdem die Prolog-Konsole gestartet ist, lädst du deine Implementierung und führst die Tests so aus:

```
?- ["<exercise>.pl"].
?- ["<exercise>_tests.plt"].
?- run_tests.
```

Ersetze `<exercise>` durch den Namen der Übung, die du gerade bearbeitest.

### Änderungen neu laden

Sobald die oben genannten Dateien geladen sind, kannst du deine Änderungen mit folgendem Befehl übernehmen:

```
?- make.
```

## Übersprungene Tests

Wenn du mit einer Übung beginnst, wird nur der erste Test ausgeführt. Die übrigen wurden übersprungen, indem `condition(pending)` zum `test`-Ziel hinzugefügt wurde.
Sobald der erste Test bestanden ist, hebst du die Überspringung des nächsten Tests auf, indem du `pending` in `condition(pending)` zu `true` änderst.
Wiederhole das für jeden Test, bis alle ausgeführt werden und bestehen.

### Kommandozeile

Hänge das Argument `-- --all` an das Ende des Befehls an, um auch alle noch ausstehenden Tests auszuführen:

```bash
swipl -f <exercise>.pl -s <exercise>_tests.plt -g run_tests,halt -t 'halt(1)' -- --all
```
