# Über

Haxe bietet integrierte Unterstützung für reguläre Ausdrücke. Mit ihnen kannst du das Format eines Strings überprüfen, einen String umwandeln oder einige reguläre Daten aus einem gegebenen Text extrahieren.

Um einen regulären Ausdruck zu erstellen, gib zwischen `~/` und `/` ein:

```haxe
var r = ~/haxe/i;
```

Eine andere Möglichkeit besteht darin, eine `EReg()`-Instanz zu verwenden:

```haxe
var r = new EReg("haxe", "i");
```

Hierbei ist `i` ein Flag, das das Muster unabhängig von Groß- und Kleinschreibung macht. Es gibt noch weitere Flags, darunter:

- `g`: globales Ersetzen.
- `m`: mehrzeiliger Abgleich

Zwischen `~/` und `/` gibst du die Muster für den regulären Ausdruck ein. Zum Beispiel möchtest du nach einem String suchen, der Buchstaben von A bis Z enthält. Hier können wir das Bereichsmuster `[A-Z]` verwenden. Es gibt viele Ausdrucksmuster, darunter:

- `.`: jedes Zeichen
- `*`: null oder mehr Wiederholungen
- `+`: eine oder mehrere Wiederholungen
- `[A-Z0-9]`: Zeichenbereiche
