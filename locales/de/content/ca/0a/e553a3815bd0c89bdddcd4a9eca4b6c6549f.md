# Einführung

Go-Funktionen und -Methoden können mehrere Werte zurückgeben:

```go
func GetCard() (Card, error) { ... }
```

Jeder Rückgabewert muss der Reihe nach zugewiesen und durch Kommas getrennt werden:

```go
card, err := GetCard()
```

Jede Position in der Zuweisung deklariert eine Variable.
Go lässt sich nicht kompilieren, wenn eine deklarierte Variable nie verwendet wird.
Der Blank Identifier `_` tritt an die Stelle eines Variablennamens, um diesen Rückgabewert zu überspringen:

```go
card, _ := GetCard()
```

`error` ist ein eingebautes Interface.
Ist der Fehler `nil`, ist kein Fehler aufgetreten; jeder andere Wert bedeutet, dass etwas schiefgelaufen ist.
Nach Konvention sollten Funktionen, die fehlschlagen können, als letzten Wert einen `error` zurückgeben.
Der Aufrufer muss ihn prüfen, bevor er weitere Rückgabewerte verwendet:

```go
card, err := GetCard()
if err != nil {
    return err // do not use card here
}
// safe to use card here
```
