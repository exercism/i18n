# Überblick

Bedingte Ausdrücke führen Code aus, je nachdem, **ob** eine Bedingung **wahr** oder **falsch** ist. Diese Ausdrücke werden so geschrieben:

```haxe
if (condition) {
  expressions
};
```

Die Ausgabe der Bedingung ist vom Typ `Bool`. Wenn die Ausgabe `true` ist, werden die Ausdrücke ausgeführt.

Manchmal ist die Bedingung aber `false` und wir möchten, dass ein anderer Teil des Codes ausgeführt wird. Genau dafür gibt es den `else`-Ausdruck. `else` führt Ausdrücke aus, wenn die ursprüngliche Bedingung `false` ist. Was aber, wenn wir die Bedingung auf mehrere Möglichkeiten prüfen wollen? Dann verwenden wir `else if (condition)`. Hier ist ein vollständiges Beispiel:

```haxe
var a = 10;

if (a == 2) {
  trace("a is 2");
} else if (a == 5) {
  trace("a is 5");
} else {
  trace("a is 10");
}

// a is 10
```
