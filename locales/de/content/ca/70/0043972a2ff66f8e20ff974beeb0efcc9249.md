# Anhang zu den Anweisungen

## Mit Datumsangaben in Prolog arbeiten

Die eingebaute Unterstützung von Prolog für Datumsangaben ist [ziemlich rudimentär][built-in-dates-support]. Du kannst diese Übung zwar mit den Bordmitteln von Prolog lösen, aber viel angenehmer arbeitest du mit Datumsangaben über das [date_time-Paket][date-time-package].

### Das date_time-Paket installieren

Wenn deine installierte Swipl-Version einigermaßen aktuell ist, kannst du das Paket so installieren:

```bash
swipl pack install date_time
```

Falls das nicht funktioniert, kannst du Folgendes ausführen:

```shell
swipl -g 'pack_install(date_time)'
```

~~~~exercism/note
Wenn du den Online-Editor verwendest, musst du nichts manuell installieren.
~~~~

### Das date_time-Paket verwenden

Füge den folgenden Code an den Anfang deiner Lösungsdatei ein, um das `date_time`-Paket zu verwenden:

```prolog
:- use_module(library(date_time)).
```

~~~~exercism/note
Tipp: Der [Quellcode des date_time-Pakets][date-time-package-source] ist gut dokumentiert und kann dir eine große Hilfe sein!
