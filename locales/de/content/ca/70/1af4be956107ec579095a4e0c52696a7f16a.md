# Anleitung

Du arbeitest mit einem Freizeitpark zusammen und hast eine Spezifikation erhalten, um ein System für die Verwaltung von Besuchern und Fahrgeschäften zu entwerfen. Deine Aufgabe ist es, den Attendee (die Person, die den Park besucht) zu modellieren.

## 1. Neue Besucher anlegen

Implementiere die Methode `Attendee#initialize` der Klasse `Attendee`. Sie soll eine Größe (in Zentimetern) entgegennehmen und als Instanzvariable speichern.

```ruby
Attendee.new(106)
# => #<Attendee:0x000055c33e6c7e18 @height=106>
```

## 2. Wie groß ist der Besucher

Implementiere den Getter `Attendee#height` der Klasse `Attendee`. Er soll die Größe der Instanz zurückgeben.

```ruby
Attendee.new(106).height
# => 106
```

## 3. Wie lautet die Fahrpass-ID

Nicht alle Besucher haben einen Fahrpass gekauft, aber wir müssen wissen, ob sie einen haben oder nicht. Implementiere den Getter `Attendee#pass_id` für die Klasse `Attendee`. Er soll die pass_id der Instanz zurückgeben oder `nil`, wenn der Attendee keinen hat.

```ruby
Attendee.new(106).pass_id
# => nil
```

## 4. Erlaube Besuchern, einen Fahrpass zu kaufen

Implementiere `Attendee#issue_pass!`, um den Zustand der Instanz zu verändern, und setze die Instanzvariable für die Pass-ID auf das Argument. Die Methode soll die Pass-ID zurückgeben.

```ruby
attendee = Attendee.new(106)
attendee.issue_pass!(42)
attendee.pass_id
# => 42
```

## 5. Den Fahrpass entziehen

Manche Gäste brechen die Regeln mit unsicherem Verhalten, deshalb möchte der Park Pässe entziehen können. Implementiere `Attendee#revoke_pass!`, um den Zustand der Instanz zu verändern, und setze die Pass-ID auf `nil`.

```ruby
attendee = Attendee.new(106)
attendee.issue_pass!(42)
attendee.revoke_pass!
attendee.pass_id
# => nil
```
