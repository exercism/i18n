# Einführung

## Bit-Arrays

Die Arbeit mit binären Daten kann knifflig sein, deshalb bietet Gleam den Typ `BitArray` und eine passende Syntax, um binäre Daten zu konstruieren und per Pattern Matching zu verarbeiten.

Bit-Array-Literale werden mit der Syntax `<<>>` definiert. Ein Bit-Array-Literal wird in Segmenten definiert. Jedes Segment hat einen Wert und eine Annotation, die durch ein `:` getrennt werden. Die Annotation gibt an, wie viele Bits zum Kodieren des Werts verwendet werden, und kann ganz weggelassen werden; dann wird standardmäßig ein 8-Bit-Ganzzahlwert verwendet.

```gleam
// This defines a bit array with three segments of a single bit each
<<0:1, 1:1, 0:1>>

// This defines a bit array with three segments of 8 bits each
<<0, 1, 0>>
```

Die Angabe des Typs als `:1` ist eine Kurzform für `:size(1)`. Du musst die längere Syntax verwenden, wenn die Bitgröße aus einer Variable kommt.

```gleam
let segment_size = 1
<<0:size(segment_size), 1:size(segment_size), 0:size(segment_size)>>
```

### Binär

Beim Schreiben von binären Ganzzahlliteralen kannst du sie direkt in Basis-2-Schreibweise schreiben, indem du dem Literal `0b` voranstellst. Beachte, dass sie als Dezimalzahlen angezeigt werden, wenn sie in Tests oder in deinem Programm ausgegeben werden.

```gleam
<<0b1011:4>> == <<11:4>>
// -> True
```

### Abschneiden

Wenn der Wert des Segments die Kapazität des Segmenttyps überschreitet, wird er von links abgeschnitten.

```gleam
<<0b1011:3>> == <<0b0011:3>>
// -> True
```

### Voranstellen und Anhängen

Du kannst an ein vorhandenes Bit-Array sowohl etwas voranstellen als auch etwas anhängen, indem du die Bit-Array-Syntax verwendest. Für das vorhandene Bit-Array muss die Annotation `:bits` verwendet werden.

```gleam
let value = <<0b110:3, 0b001:3>>
let new_value = <<0b011:3, value:bits, 0b000:3>>
// -> <<120, 8:size(4)>>
```

### Verketten

Wir können Bit-Arrays, die in Variablen gespeichert sind, mit der Bit-Array-Syntax verketten. Beim Verketten zweier Bit-Arrays mit variablen Größen muss die Annotation `:bits` verwendet werden.

```gleam
let first = <<0b110:3>>
let second = <<0b001:3>>
let concatenated = <<first:bits, second:bits>>
// -> <<49:size(6)>>
```

### Pattern Matching

Mit Pattern Matching kannst du auch Werte aus dem Bit-Array herauslesen. Du musst die Anzahl der Bits für jedes Segment kennen, das du erfassen willst, mit einer Ausnahme: Die Annotation `:bits` kann für Pattern Matching auf einem Bit-Array unbekannter Größe verwendet werden, aber das ist nur beim letzten Segment möglich.

```gleam
let assert <<value:4, rest:bits>> = <<0b01101001:8>>
value == 0b0110
// -> True
```

### Bit-Arrays untersuchen

~~~~exercism/note
Bit-Arrays werden manchmal in einem anderen Format ausgegeben als dem, in dem
sie erstellt wurden. Das führt beim Lernen von Bit-Arrays oft zu Verwirrung.
~~~~

Standardmäßig werden Bit-Arrays in Segmenten von 8 Bits (einem Byte) angezeigt, selbst wenn du sie mit Segmenten einer anderen Größe erstellt hast.

```gleam
<<2011:11>>
// -> <<251, 3:size(3)>>
```

Wenn du ein Bit-Array erstellst, das einen druckbaren UTF-8-kodierten String darstellt, kann es von Funktionen wie `io.debug` als String angezeigt werden. Das liegt an einem Implementierungsdetail, wie Gleam Strings intern darstellt.

```gleam
<<>>
// -> ""

<<65, 66, 67>>
// -> "ABC"
```
