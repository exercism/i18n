# Hinweise

## Allgemeines

- Ein [Ganzzahlwert][ints] kann als eine oder mehrere aufeinanderfolgende Ziffern definiert werden.
- [String][string]-Literale (Zeichenkette) sind eine Folge von Zeichen, die von doppelten Anführungszeichen umgeben sind.

## 1. Definiere die erwartete Ofenzeit in Minuten

- Du musst eine [Funktion][functions] ohne Argumente definieren.
- Du musst eine [Ganzzahl][ints] zurückgeben.

## 2. Berechne die verbleibende Ofenzeit in Minuten

- Du musst eine [Funktion][functions] mit einem einzigen Argument definieren.
- Du musst aus einer Funktion eine Ganzzahl zurückgeben.
- Das Argument der Funktion ist eine [Ganzzahl][ints].
- Du kannst den [mathematischen Operator für die Subtraktion][ints] verwenden, um Werte zu subtrahieren.

## 3. Berechne die Vorbereitungszeit in Minuten

- Du musst eine [Funktion][functions] mit einem einzigen Argument definieren.
- Du musst aus einer Funktion eine Ganzzahl zurückgeben.
- Das Argument der Funktion ist eine [Ganzzahl][ints].
- Du kannst den [mathematischen Operator für die Multiplikation][ints] verwenden, um Werte zu multiplizieren.

## 4. Berechne die gesamte Arbeitszeit in Minuten

- Du musst eine [Funktion][functions] mit zwei Argumenten definieren.
- Du musst aus einer Funktion eine Ganzzahl zurückgeben.
- Das Argument der Funktion ist eine [Ganzzahl][ints].
- Du kannst eine der anderen Funktionen aufrufen, die du zuvor definiert hast.
- Du kannst den [mathematischen Operator für die Addition][ints] verwenden, um Werte zu addieren.

## 5. Erstelle eine Benachrichtigung, dass die Lasagne fertig ist

- Du musst eine [Funktion][functions] ohne Argumente definieren.
- Du musst einen [String][string] zurückgeben.

[functions]: https://gleam.run/book/tour/functions.html
[ints]: https://gleam.run/book/tour/ints-and-floats.html
[string]: https://gleam.run/book/tour/strings.html
