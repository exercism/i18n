# Einführung

Der [Zen of Python][zen-of-python] behauptet, es solle „einen _offensichtlichen_ Weg geben, etwas in Python zu tun“.
Für Python 3.6+ ist die [**literale String-Interpolation**][string-interpolation] ([**`f-string`s**][f-string]) oft der offensichtliche und bevorzugte Weg, Strings zu formatieren:

```python
>>> adjective = "easy"
>>> f"This is an {adjective} way to format strings!"
'This is an easy way to format strings!'
```

Angesichts der langen Geschichte von Python und der verschiedenen Anwendungsfälle überrascht es allerdings kaum, dass es **drei** weitere gängige Wege gibt, in Python Strings zu formatieren:

1. [`str.format()`][str-format] ist vielseitig, sehr mächtig und sowohl mit [`gnu gettext`][gettext] als auch mit den meisten Python-Versionen kompatibel.
2. Wenn du Einfachheit, Sicherheit und/oder umfangreiche Internationalisierung brauchst, kannst du [`string.Template()`][string-template] verwenden, um Risiken zu mindern, wenn Eingaben verarbeitet werden müssen, und um Übersetzungs-Strings zu umschließen.
3. Der `%`-Operator gilt für neuen Code allgemein als veraltet, funktioniert in modernem Python aber noch.
  Er sollte vor allem für die Kompatibilität mit älteren Codebasen verwendet werden.
  Das Formatieren mit `%` kann Probleme bei der Darstellung von Nicht-ASCII- und Unicode-Zeichen verursachen und ist fehleranfälliger und weniger funktionsreich als andere Methoden.
  Prüfe deine spezifische Python-Distribution auf Unterstützungsdetails, wenn du ihn verwenden willst.
