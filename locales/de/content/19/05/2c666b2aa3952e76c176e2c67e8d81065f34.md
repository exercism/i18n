# Einführung

Mit dem bedingten ternären Operator schreibst du einen kompakten Ausdruck, der abhängig von einer Bedingung einen von zwei alternativen Werten zurückgibt.
Er wird oft als „ternärer Operator“ bezeichnet.
Der Name kommt daher, dass der Operator drei Operanden hat: `predicate ? consequent-expression : alternative-expression`
Er kann als Ersatz für kurze if-else-Anweisungen verwendet werden.

Ähnlich wie bei `if`-Anweisungen führt JavaScript eine implizite Typumwandlung durch, um die Bedingung auszuwerten.
Wenn die Bedingung truthy ist, gibt der Operator den Operanden links vom Doppelpunkt zurück.
Andernfalls ist das Ergebnis des ternären Ausdrucks der Operand rechts vom Doppelpunkt.

```javascript
const year = 2020;

year > 2000 ? 'in the past years' : 'a long time ago';
// => 'in the past years'
```
