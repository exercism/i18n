# Test Runner

Ein Test Runner ist eine Software, die die Tests einer Übung mit dem Code eines Lernenden ausführt.

Test Runner bieten uns zwei Vorteile:

1. Sie ermöglichen das Programmieren direkt im Browser, wo Lernende an einer Lösung arbeiten und dabei sehen, ob die Tests bestehen oder fehlschlagen.
2. Sie erlauben uns, Mentoren darüber zu informieren, ob der Code eines Lernenden „funktioniert“ oder nicht.

## Einen Test Runner bauen

Wenn du daran interessiert bist, einen Test Runner zu bauen, schau dir die [Dokumentation zu Test Runnern](/docs/building/tooling/test-runners) an, um mehr zu erfahren.
