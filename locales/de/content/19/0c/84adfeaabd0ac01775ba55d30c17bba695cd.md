# Anhang zu den Anweisungen

## Register

| Register | Verwendung | Typ     | Beschreibung                                                     |
| -------- | ---------- | ------- | ---------------------------------------------------------------- |
| `$a0`    | Eingabe    | Adresse | Elemente des ersten Arrays                                       |
| `$a1`    | Eingabe    | Ganzzahl | Größe des ersten Arrays, in Wörtern                              |
| `$a2`    | Eingabe    | Adresse | Elemente des zweiten Arrays                                      |
| `$a3`    | Eingabe    | Ganzzahl | Größe des zweiten Arrays, in Wörtern                             |
| `$v0`    | Ausgabe    | Ganzzahl | `0` = gleich, `1` = ungleich, `2` = Unterliste, `3` = Oberliste  |
| `$t0-9`  | temporär   | beliebig | wird für die temporäre Speicherung verwendet                     |
