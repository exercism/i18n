# Ergänzung zur Anleitung

## Register

| Register | Verwendung | Typ      | Beschreibung                     |
| -------- | ---------- | -------- | -------------------------------- |
| `$a0`    | Eingabe    | Adresse  | erster nullterminierter String   |
| `$a1`    | Eingabe    | Adresse  | zweiter nullterminierter String  |
| `$v0`    | Ausgabe    | Ganzzahl | Hamming-Distanz                  |
| `$t0-9`  | temporär   | beliebig | für die temporäre Speicherung    |
