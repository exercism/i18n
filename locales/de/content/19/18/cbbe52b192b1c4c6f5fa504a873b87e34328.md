# Hinweise

## 1. `assign-bibs`

- Verwende `map-index`. Die Quotation hat `index` oben auf dem
  Stack, mit `name` darunter. Um ein Paar `{ position name }`
  zu erzeugen, willst du sie vor dem Aufruf von `2array` in
  der umgekehrten Reihenfolge haben.

## 2. `lane-labels`

- Verwende `map-index`.
- `sprintf` liest seine Argumente von unten nach oben: der
  linkeste `%`-Platzhalter nimmt das unterste Argument, der
  rechteste das oberste.
- Für `"Lane %d: %s"` willst du, dass `index` (eine Zahl) `%d`
  speist und `name` (ein String) `%s`. Ordne den Stack
  innerhalb der Quotation entsprechend um.

## 3. `tag-racers`

- Das Argument `tag` muss für jeden Aufruf pro Element
  verfügbar sein. `curry` (oder `fry`) bindet es fest ein.
- Innerhalb der Quotation hast du drei Werte, die du `sprintf`
  zuführen musst: das Tag, den Index und den Namen. `spin`
  dreht die obersten drei Elemente des Stacks um, und genau
  das brauchst du hier.

## 4. `record-finishes`

- Das Ledger muss für jeden Aufruf pro Element verfügbar sein.
  `fry` (`'[ … _ … ]`) ist der natürliche Weg: das `_` wird zum
  Ledger.
- Baue den String pro Fahrer mit `sprintf` auf und schiebe ihn
  dann mit `push` auf das Ledger.
- `each-index` gibt nichts zurück; die Mutation *ist* das
  Ergebnis.

## 5. `lap-bells`

- `times` ist `inline`, deshalb kann seine Quotation einen
  anderen Effekt als `( -- )` haben. Verwende eine Quotation
  mit dem Effekt `( str -- str )`, um einen laufenden String
  durch die Iterationen zu führen.
- Beginne mit dem leeren String `""` auf dem Stack.
