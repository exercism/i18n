# Anleitung

In dieser Übung verarbeitest du Logzeilen.

Jede Logzeile ist ein String, der wie folgt formatiert ist: `"[<LEVEL>]: <MESSAGE>"`.

Es gibt drei verschiedene Log-Level:

- `INFO`
- `WARNING`
- `ERROR`

Du hast drei Aufgaben. Bei jeder Aufgabe bekommst du eine Logzeile und sollst etwas damit tun.
Es gibt viele Wege, diese Aufgaben zu lösen. Wähle deine Lieblingsmethoden aus den Beispielen oben und schau, was du hinbekommst.

## 1. Nachricht aus einer Logzeile ermitteln

Implementiere die Methode `LogLineParser#message`, um die Nachricht einer Logzeile zurückzugeben:

```ruby
LogLineParser.new('[ERROR]: Invalid operation').message
# => "Invalid operation"
```

Führende oder nachfolgende Leerzeichen sollen entfernt werden:

```ruby
LogLineParser.new("[WARNING]:  Disk almost full\r\n").message
# => "Disk almost full"
```

## 2. Log-Level aus einer Logzeile ermitteln

Implementiere die Methode `LogLineParser#log_level`, um das Log-Level einer Logzeile in Kleinbuchstaben zurückzugeben:

```ruby
LogLineParser.new('[ERROR]: Invalid operation').log_level
# => "error"
```

## 3. Eine Logzeile neu formatieren

Implementiere die Methode `LogLineParser#reformat`, die die Logzeile neu formatiert: zuerst die Nachricht, danach das Log-Level in runden Klammern:

```ruby
LogLineParser.new('[INFO]: Operation completed').reformat
# => "Operation completed (info)"
```
