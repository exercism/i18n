# Einführung

Der `const`-Modifizierer kann (und sollte im Allgemeinen) auf jedes Feld angewendet werden, dessen Wert zur Kompilierzeit bekannt ist und sich während der Lebensdauer des Programms nicht ändert.

```csharp
private const int num = 1729;
public const string title = "Grand" + " Master";
```

Der `readonly`-Modifizierer kann (und sollte im Allgemeinen) auf jedes Feld angewendet werden, das nicht als `const` deklariert werden kann, dessen Wert sich während der Lebensdauer des Programms nicht ändert und das entweder durch einen Inline-Initialisierer oder während der Instanziierung festgelegt wird (durch den Konstruktor oder eine vom Konstruktor aufgerufene Methode).

```csharp
private readonly int num;
private readonly System.Random rand = new System.Random();

public MyClass(int num)
{
    this.num = num;
}
```
