# Über

In Swift ist ein `String` eine geordnete Sammlung von `Character`-Werten, die menschenlesbaren Text darstellen. Swift-Strings unterstützen Unicode-Zeichen und Emojis vollständig.

Du erstellst einen String mit einem String-Literal, indem du Text in doppelte Anführungszeichen (`"`) einschließt. Für Sonderzeichen verwendest du Escape-Sequenzen: Zum Beispiel steht `\n` für einen Zeilenumbruch und `\"` für ein maskiertes doppeltes Anführungszeichen innerhalb eines String-Literals.

Du schreibst einen leeren String als Paar doppelter Anführungszeichen ohne Inhalt dazwischen (`""`).

```swift
let hello = "Hello, World!"
let sausage = "Weißwurst is a tasty sausage."
var family = "This is my family: 👨‍👩‍👦‍👦, this is our dog: 🐶"
var empty = ""
```
