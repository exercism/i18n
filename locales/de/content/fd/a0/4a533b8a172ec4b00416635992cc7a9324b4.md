# Tests

Du kannst die Tests ausführen, indem du eine Kommandozeile im Verzeichnis der Übung öffnest und dann den [`dotnet test`-Befehl](https://docs.microsoft.com/en-us/dotnet/core/tools/dotnet-test) ausführst.
Alternativ bieten die meisten IDEs integrierte Unterstützung für das Ausführen von Tests, darunter [Visual Studio](https://docs.microsoft.com/en-us/visualstudio/test/run-unit-tests-with-test-explorer), [Rider](https://www.jetbrains.com/help/rider/Unit_Testing_in_Solution.html) und [Visual Studio code](https://github.com/OmniSharp/omnisharp-vscode/wiki/How-to-run-and-debug-unit-tests).
Weitere Informationen findest du auf der [Tests-Seite](https://exercism.org/docs/tracks/csharp/tests).

## Übersprungene Tests

Anfangs ist nur der erste Test aktiviert.
Das soll dich dazu anregen, die Übung Schritt für Schritt zu lösen.
Sobald der erste Test bestanden ist, entferne die Eigenschaft `Skip` aus dem nächsten Test und arbeite daran, auch diesen Test zu bestehen.
