# Einführung

In Go ist eine Konstante ein einfacher, unveränderlicher Wert, der mit dem Schlüsselwort `const` einem Namen zugewiesen wird:

```go
const myWebsite = "Exercism"
```

Solche Konstanten sind untypisiert, aber sie bekommen einen Standardtyp, der auf ihrer Syntax basiert, sobald ein Typ benötigt wird, zum Beispiel wenn sie an eine Methode übergeben werden.
Typisierte Konstanten erstellst du, indem du ausdrücklich einen Typ hinzufügst:

```go
const myWebsite string = "Exercism"
```

Go hat keine Enums wie einige andere Sprachen, aber es gibt einen vordeklarierten Bezeichner namens `iota`, mit dem du Aufzählungskonstanten erstellen kannst.
Konstanten in einem Block werden implizit wiederholt:

```go
const (
    a = 9
    b
    c
    d = iota
    e
    f
    g
)
fmt.Print(a, b, c, d, e, f, g)
// Output: 9 9 9 3 4 5 6
```
