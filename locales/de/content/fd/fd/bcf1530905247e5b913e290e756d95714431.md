# Einleitung

Ein *Heap* ist eine Sammlung, die immer ihr kleinstes Element kennt und es schnell entfernen lässt, die natürliche Umsetzung einer *Prioritätswarteschlange*. Heaps findest du im Vokabular [`heaps`][heaps].

`<min-heap>` erzeugt einen leeren Heap, bei dem der kleinste Schlüssel zuerst herauskommt; `<max-heap>` ist das Spiegelbild. Jedes Element ist ein *Wert*, der unter einem *Schlüssel* gespeichert wird, und der Schlüssel ist die Priorität:

```
<min-heap> ( -- min-heap )
heap-push  ( value key heap -- )
```

```factor
USING: heaps ;

<min-heap>
"alice" 5 pick heap-push
"bob"   2 pick heap-push
```

Ein Heap ist *veränderlich*: `heap-push` verändert ihn an Ort und Stelle. `heap-peek` gibt den vordersten Wert und Schlüssel zurück, ohne ihn zu entfernen, `heap-pop` entfernt ihn und gibt ihn zurück, und `heap-pop-all` entleert den Heap in eine Assoziationsliste aus `{ key value }`-Paaren in der Reihenfolge ihrer Priorität:

```
heap-peek    ( heap -- value key )
heap-pop     ( heap -- value key )
heap-pop-all ( heap -- alist )
```

```factor
USING: heaps kernel prettyprint ;

<min-heap>
"alice" 5 pick heap-push
"bob"   2 pick heap-push
dup heap-peek drop .     ! => "bob"
heap-pop-all .           ! => { { 2 "bob" } { 5 "alice" } }
```
