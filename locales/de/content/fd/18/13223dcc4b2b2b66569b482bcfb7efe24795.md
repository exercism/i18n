# Ergänzung zu den Anweisungen

## Ausnahmen anpassen und auslösen

Manchmal ist es notwendig, Ausnahmen in deinem Code sowohl [anzupassen](https://docs.python.org/3/tutorial/errors.html#user-defined-exceptions) als auch mit [`raise`](https://docs.python.org/3/tutorial/errors.html#raising-exceptions) auszulösen. Wenn du das tust, solltest du immer eine **aussagekräftige Fehlermeldung** angeben, die zeigt, woher der Fehler stammt. Das macht deinen Code lesbarer und hilft erheblich beim Debugging.

Benutzerdefinierte Ausnahmen kannst du über neue Ausnahmeklassen erstellen (siehe [`classes`](https://docs.python.org/3/tutorial/classes.html#tut-classes) für mehr Details), die typischerweise Unterklassen von [`Exception`](https://docs.python.org/3/library/exceptions.html#Exception) sind.

Wenn du weißt, dass die Fehlerquelle von einem bestimmten Ausnahmetyp abgeleitet ist, kannst du von einem der [`built in error types`](https://docs.python.org/3/library/exceptions.html#base-classes) unter der Klasse _Exception_ erben. Beim Auslösen des Fehlers solltest du trotzdem eine aussagekräftige Meldung angeben.

Diese Übung erfordert, dass du eine _benutzerdefinierte Ausnahme_ erstellst, die [ausgelöst](https://docs.python.org/3/reference/simple_stmts.html#the-raise-statement)/„geworfen“ wird, wenn der Stack nicht ausreichend gefüllt ist. Die Tests bestehen nur, wenn du eine passende Ausnahme anpasst, diese Ausnahme mit `raise` auslöst und passende Fehlermeldungen angibst.


```python
# subclassing the Exception to create a StackUnderflowError
class StackUnderflowError(Exception):
    """Exception raised when Stack is not full.
       message: explanation of the error.
    """
    def __init__(self, message):
        self.message = message

        
# raising a StackUnderflowError
raise StackUnderflowError("Insufficient number of items in stack")
```

Zusätzlich erfordert diese Übung, dass du mehrere `built-in exceptions` mit Fehlermeldungen auslöst.
Um eine `built-in exception` mit einer Meldung auszulösen, schreibe die Meldung als Argument an den `exception`-Typ:

```python
# an example when division by zero is attempted.
raise ZeroDivisionError("divide by zero")

#an example when the operation is undefined.
raise ValueError("undefined operation")
```
