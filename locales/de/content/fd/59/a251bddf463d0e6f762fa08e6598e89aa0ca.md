# Anleitung

In dieser Übung schreibst du Code, um die Produktion eines Fließbands in einer Autofabrik zu analysieren. Die Geschwindigkeit des Fließbands reicht von `0` (aus) bis `10` (Maximum).

Bei der niedrigsten Geschwindigkeit (`1`) werden `221` Autos pro Stunde produziert. Die Produktion steigt linear mit der Geschwindigkeit. Bei einer Geschwindigkeit von `4` sollten also `4 * 221 = 884` Autos pro Stunde produziert werden. Höhere Geschwindigkeiten erhöhen jedoch die Wahrscheinlichkeit, dass fehlerhafte Autos produziert werden, die dann aussortiert werden müssen.

Du hast drei Aufgaben.

## 1. Berechne die Erfolgsquote

Implementiere die Methode `success_rate()`, um für eine gegebene Geschwindigkeit die Quote zu berechnen, mit der ein Element fehlerfrei hergestellt wird. Die folgende Tabelle zeigt, wie die Geschwindigkeit die Erfolgsquote beeinflusst:

- `0`: 0 % Erfolgsquote.
- `1` bis `4`: 100 % Erfolgsquote.
- `5` bis `8`: 90 % Erfolgsquote.
- `9`: 80 % Erfolgsquote.
- `10`: 77 % Erfolgsquote.

```R
success_rate(10)
# => 0.77
```

## 2. Berechne die Produktionsrate pro Stunde

Implementiere die Methode `production_rate_per_hour()`, um die Produktionsrate des Fließbands pro Stunde zu berechnen und dabei seine Erfolgsquote zu berücksichtigen:

```R
production_rate_per_hour(6)
# => 1193.4
```

Beachte, dass der zurückgegebene Wert ein `double` ist.

## 3. Berechne die Anzahl der pro Minute produzierten funktionsfähigen Autos

Implementiere die Methode `working_items_per_minute()`, um zu berechnen, wie viele funktionsfähige Autos pro Minute produziert werden:

```R
working_items_per_minute(6)
# => 19
```

Beachte, dass der zurückgegebene Wert eine Ganzzahl ist: unvollständige Elemente werden nicht mitgezählt.
