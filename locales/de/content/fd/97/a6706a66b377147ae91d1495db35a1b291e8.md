# Anleitung

Gegeben ist ein String aus Ziffern. Gib alle zusammenhängenden Teilstrings der Länge `n` in diesem String in der Reihenfolge aus, in der sie vorkommen.

Zum Beispiel hat der String "49142" die folgenden dreistelligen Serien:

- "491"
- "914"
- "142"

Und die folgenden vierstelligen Serien:

- "4914"
- "9142"

Und wenn du von einem fünfstelligen String eine sechsstellige Serie verlangst, dann hast du es nicht anders verdient.

Beachte, dass diese Serien in der Eingabe nur _benachbarte Positionen_ einnehmen müssen; die Ziffern müssen nicht _aufeinanderfolgende Zahlenwerte_ sein.
