# Einführung

Die nützlichsten Wörter für Sequenzen nehmen eine *Quotation* als einen ihrer
Eingabewerte und steuern damit die Operation:

```
each   ( seq quot -- )
map    ( seq quot -- newseq )
filter ( seq quot -- newseq )
reject ( seq quot -- newseq )
count  ( seq quot -- n )
any?   ( seq quot -- ? )
all?   ( seq quot -- ? )
```

```factor
{ 1 2 3 4 5 } [ even? ] filter .   ! => { 2 4 }
{ 1 2 3 4 5 } [ sq ] map .         ! => { 1 4 9 16 25 }
{ 1 2 3 4 5 } [ 2 > ] count .      ! => 3
```

`map-sum` (ebenfalls in `sequences`) legt eine Quotation über die
Sequenz und addiert die Ergebnisse in einem Durchlauf. Dasselbe
Muster steuert `sort-by` (in [`sorting`][sorting]) und `minimum-by` /
`maximum-by` (in `sequences`).

[sorting]: https://docs.factorcode.org/content/vocab-sorting.html
