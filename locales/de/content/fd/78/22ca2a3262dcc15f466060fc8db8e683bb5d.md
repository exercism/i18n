# Einführung

Swift kennt eine Reihe von Anweisungen, mit denen du den normalen Ablauf von Schleifen verändern kannst. Man nennt sie Kontrolltransfer-Anweisungen.
`return` kennst du bereits; in diesem Konzept lernst du weitere kennen, darunter `continue`, `break` und Labels.
`fallthrough` behandeln wir in diesem Konzept nicht, aber du kannst im [Swift-Buch][fallthrough] darüber lesen.

## Continue

Manchmal ist es nötig, früh zur nächsten Iteration einer Schleife zu springen, ohne die restlichen Anweisungen der aktuellen Iteration auszuführen.
Dafür kannst du das Schlüsselwort `continue` verwenden.
Wenn `continue` ausgeführt wird, springt die Schleife zur nächsten Prüfung, ob die nächste Iteration der Schleife ausgeführt werden kann, also zum `while` in while- und repeat-while-Schleifen oder zur Prüfung, ob die Sequenz noch ein weiteres Element enthält, in for-in-Schleifen.

```swift
count = 1
while count < 6 {
  count += 1
  if count == 4 { continue }
  print(count)
}

// prints:
// 2
// 3
// 5
```

## Break

Mit `break` kannst du eine Schleife vorzeitig verlassen.
Wenn `break` ausgeführt wird, wird die Schleife sofort beendet und das Programm fährt mit der ersten Anweisung nach der Schleife fort.

```swift
for fruit in ["banana", "grapes", "apple", "strawberry", "kiwi", "lemon"] {
  if !fruit.count.isMultiple(of: 2) { break }
  print(fruit)
}

// prints:
// banana
// grapes
```

## Labels

Wenn Schleifen verschachtelt sind, möchte man manchmal mit `break` oder `continue` die äußeren Schleifen verlassen oder neu starten, die die Schleife umschließen, in der `break` oder `continue` steht.
In solchen Fällen kannst du mit Labels festlegen, welche Schleife verlassen oder neu gestartet werden soll.
Du kannst eine Schleife mit einem Label versehen, indem du einen Namen und einen Doppelpunkt vor das `while`, `repeat` oder `for` setzt, das die Schleife beginnt.

Um die Wirkung solcher Labels zu sehen, schau dir die folgende Schleife an.

```swift
outerLoop: for fruit in ["banana", "grapes", "apple", "strawberry", "kiwi", "lemon"] {
  print("\n--- \(fruit) ---")
  for letter in fruit {
    guard letter != "n" else { break outerLoop }
    print(letter)
  }
}

// prints:
// --- banana ---
// b
// a
```
