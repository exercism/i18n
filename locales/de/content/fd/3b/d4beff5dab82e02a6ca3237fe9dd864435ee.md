# Tests

Um die Tests im Übungsverzeichnis auszuführen, führe folgenden Befehl aus:

```sh
odin test .
```

Beim Testen kann Odin deinen Code „vetten": Es sucht nach Dingen wie ungenutzten Imports und Variablen. Führe deine Tests so aus:

```sh
odin test . -vet
```

Weitere Optionen findest du mit `odin test -help`.
