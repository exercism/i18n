# Einführung

Um in Common Lisp eine globale Funktion zu definieren, verwendet man den Ausdruck `defun`.
Dieser Ausdruck nimmt als erstes Argument eine Liste von Parametern (eine leere Liste bedeutet, dass die Funktion keine Parameter hat).
Darauf folgt ein optionaler Dokumentationsstring (siehe unten), dann null oder mehr Ausdrücke, die den „Körper“ der Funktion bilden.

Funktionen können null oder mehr Parameter haben.

```lisp
(defun no-args () (+ 1 1))

(defun add-one (x) (1+ x))

(defun add-nums (x y) (+ x y))
```

Eine Funktion ruft man auf, indem man einen Ausdruck auswertet, bei dem das Symbol, das die Funktion bezeichnet, das erste Element des Ausdrucks ist und die Argumente der Funktion (falls vorhanden) die übrigen Elemente des Ausdrucks sind.

Der Wert, zu dem eine Funktion auswertet, ist der Wert des zuletzt ausgewerteten Ausdrucks im Körper der Funktion.
Alle Funktionen werten zu einem Wert aus.

```lisp
(add-nums 2 2) ;; => 4
```

Funktionen können außerdem optional einen Dokumentationsstring haben (auch „Docstring“ genannt).
Falls vorhanden, steht er nach der Argumentliste, aber vor dem Körper der Funktion.
Auf den Dokumentationsstring kann man über `documentation` zugreifen.

```lisp
(defun add-nums (x y) "Add X and Y together" (+ x y))

(documentation 'add-nums 'function) ;; => "Add X and Y together"

;; Note that if one provides a docstring but fails to provide a body
;; then the docstring is interpreted by Common Lisp as the body, not
;; the docstring
(defun no-body ())
(no-body) ;; => NIL

(defun mistake () "This is not a docstring")
(mistake) ;; => "This is not a docstring"
(documentation 'mistake 'function) ;; => NIL
```
