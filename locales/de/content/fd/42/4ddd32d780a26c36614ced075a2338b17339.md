# Anleitung

Du bist ein großer Fan des [Numberphile-YouTube-Kanals](https://www.youtube.com/watch?v=PeUbRXnbmms) und hast gerade ein cooles Video über die _Lucas-Folge_ gesehen. Du möchtest diese Folge mit Elixir erzeugen.

Beim Entwurf deiner Funktion möchtest du _Lazy Evaluation_ nutzen, damit du so viele Zahlen erzeugen kannst, wie du willst, aber nur, wenn du sie wirklich brauchst. Also entscheidest du dich für einen Stream.

## 1. Ungültige Argumente abfangen

Füge eine Guard-Klausel hinzu, die einen Fehler auslöst, wenn die Folge mit etwas anderem als einer Ganzzahl oder mit einer Ganzzahl kleiner als 1 erzeugt wird. Wenn du das als ersten Schritt erledigst, vermeidest du Fehler durch unendliche Rekursion in späteren Schritten.

```elixir
LucasNumbers.generate("Hello World")
# => ** (ArgumentError) count must be specified as an integer >= 1
```

## 2. Die Basisfälle erzeugen

Du weißt, dass die Folge zwei Startzahlen hat, die nicht derselben Regel folgen. Schreibe zwei Klauseln für die Basisfälle, die diese Zahlen zurückgeben:

```elixir
LucasNumbers.generate(1)
# => [2]

LucasNumbers.generate(2)
# => [2, 1]
```

## 3. Den verallgemeinerten Fall erstellen

Bei jeder Folge, die länger als 2 ist, weißt du, dass du die beiden vorherigen Zahlen addieren musst, um die nächste Zahl zu erhalten, und so weiter. Schreibe den verallgemeinerten Fall.

```elixir
LucasNumbers.generate(3)
# => [2, 1, 3]

LucasNumbers.generate(4)
# => [2, 1, 3, 4]
```
