# Einführung

Wenn du etwas mit einem Raspberry Pi bauen möchtest, wirst du wahrscheinlich _Widerstände_ verwenden. Wie bei den vorherigen Übungen `Resistor Color Duo` und `Resistor Color Trio` wirst du die Farbbänder von Widerständen in für Menschen lesbare Bezeichnungen übersetzen.

- Jeder Widerstand hat einen Widerstandswert.
- Widerstände sind klein, so klein, dass es schwer zu lesen wäre, wenn man den Widerstandswert auf sie drucken würde.
  Um dieses Problem zu umgehen, drucken Hersteller farbcodierte Bänder auf die Widerstände, um deren Widerstandswert anzugeben.
- Jedes Band steht für eine Ziffer einer Zahl.
  Wenn ein Hersteller zum Beispiel ein brown-Band (Wert 1), gefolgt von einem green-Band (Wert 5), aufdrucken würde, ergäbe das die Zahl 15.
