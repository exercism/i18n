# Anleitung

In dieser Übung verarbeitest du Logzeilen.

Jede Logzeile ist ein String mit folgendem Format: `"[<LEVEL>]: <MESSAGE>"`.

Es gibt drei verschiedene Log-Level:

- `INFO`
- `WARNING`
- `ERROR`

Du hast drei Aufgaben. Jede nimmt eine Logzeile und verlangt, dass du etwas damit machst.

## 1. Die Nachricht aus einer Logzeile holen

Implementiere die Funktion `message()`, die die Nachricht einer Logzeile zurückgibt:

```haxe
message("[ERROR]: Invalid operation")
// => "Invalid operation"
```

Führende und nachfolgende Leerzeichen sollen entfernt werden:

```haxe
message("[WARNING]:  Disk almost full\r\n")/ => "Disk almost full"
```

## 2. Das Log-Level aus einer Logzeile holen

Implementiere die Funktion `logLevel()`, die das Log-Level einer Logzeile zurückgibt. Es soll in Kleinbuchstaben zurückgegeben werden:

```haxe
logLevel("[ERROR]: Invalid operation")
// => "error"
```

## 3. Eine Logzeile umformatieren

Implementiere die Funktion `reformat()`, die die Logzeile umformatiert: die Nachricht steht zuerst, danach das Log-Level in Klammern:

```haxe
reformat("[INFO]: Operation completed")
// => "Operation completed (info)"
```
