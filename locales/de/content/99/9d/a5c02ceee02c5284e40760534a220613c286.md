# Über

JavaScript ist eine Programmiersprache, mit der Webseiten dynamisch werden. Sie ist eine interpretierte Sprache, das heißt, sie muss nicht kompiliert werden: Stattdessen liest der Interpreter (etwa ein Webbrowser) den Code und wandelt ihn in Code um, den der Rechner ausführen kann. Damit lassen sich dynamische Webseiten erstellen, die in jedem Browser _auf jedem Computer_ laufen!

JavaScript wird nicht nur im Browser verwendet. JavaScript-Laufzeitumgebungen wie [Node.js][web-nodejs] und [Deno][web-deno] ermöglichen es dir, Anfragen auf Webservern zu schreiben, zu starten und zu beantworten.
Andere Frameworks wie [Electron][web-electron] nutzen JavaScript, um _plattformübergreifende Anwendungen_ für Windows, Linux und macOS zu schreiben.
Auch die Entwicklung mobiler Apps ist möglich, mit [React Native][web-react-native], [Ionic][web-ionic] und diversen anderen; [Expo][web-expo] erlaubt es inzwischen, Android, iOS und das Web auf einmal anzusprechen.

ECMAScript ist der [Standard][web-ecma], der JavaScript definiert.

> „ECMAScript hat sich zu einer der weltweit am meisten genutzten Allzweck-Programmiersprachen entwickelt.
> Am bekanntesten ist sie als die Sprache, die in Webbrowser eingebettet ist, doch sie wurde auch vielfach für Server- und eingebettete Anwendungen übernommen."
> – [ECMA International Language Specification][web-ecma-2019]

Seit der 6. Ausgabe (allgemein bekannt als ES2015 oder ES6) aus dem Jahr 2015 erscheint jedes Jahr eine neue Ausgabe des Standards.
Die 6. Ausgabe war ein großes Update, das viele Verbesserungen gegenüber ES5 brachte, darunter vor allem Template-Strings, die ausdrucksstarke Syntax von Arrow-Funktionen und eine sauberere Syntax zum Definieren von Klassen.

Doch weil _jedes Jahr_ neue Syntax und neue Features zu JavaScript hinzukommen, ist die Unterstützung dieser Änderungen in [aktuellen Browsern][web-compat-browsers] und [im neuesten Node.js][web-compat-node] oft unvollständig.
Das heißt aber nicht, dass wir sie nicht nutzen können.
Tools wie [Babel][web-babel] bieten [Transpilation][wiki-transpilation] für die meisten Features an, sodass wir so _schreiben_ können, als wäre es schon die Zukunft.

**Hinweis**: Dieser Track unterstützt die neueste ECMAScript-Syntax über Babel und das Plugin [@babel/preset-env][web-babel-preset-env]; neue experimentelle Features werden mit jedem Update dieses Plugins aktiviert, passend zur Veröffentlichung der Spezifikationen.
Er passt sich automatisch an _deine lokale Node.js-Installation_ an.
Das bedeutet, du musst dir keine Gedanken darüber machen, was unterstützt wird und was nicht.
