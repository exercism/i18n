# Einführung

Die Veränderbarkeit ist eine Eigenschaft einer bestimmten Bindung in Rust. Eine Bindung ist entweder unveränderlich oder veränderlich. Der Wert einer unveränderlichen Bindung darf nicht geändert werden; der Wert einer veränderlichen Bindung kann geändert werden. Alle Bindungen sind standardmäßig unveränderlich.
