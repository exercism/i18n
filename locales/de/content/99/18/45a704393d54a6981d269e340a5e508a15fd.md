# Anleitung

Du hilfst deiner kleinen Schwester bei ihren Englisch-Vokabelhausaufgaben, die sie sehr mühsam findet.
 Ihre Klasse lernt gerade, neue Wörter zu bilden, indem sie _Präfixe_ und _Suffixe_ anhängt.
 Bei einer vorgegebenen Menge von Wörtern sucht die Lehrerin nach korrekt umgewandelten Wörtern mit korrekter Schreibweise, indem das Präfix an den Anfang oder das Suffix an das Ende gesetzt wird.

Die Aufgabe besteht aus vier Aktivitäten, jede mit einem Text oder einer Wortliste, mit der du arbeitest.


## 1. Füge einem Wort ein Präfix hinzu

Eines der häufigsten Präfixe im Englischen ist `un`, es bedeutet „nicht".
 In dieser Aktivität muss deine Schwester negative Wörter, also „Nicht"-Wörter, bilden, indem sie `un` davor setzt.

Implementiere die Funktion `add_prefix_un(<word>)`, die `word` als Parameter nimmt und ein neues Wort mit vorangestelltem `un` zurückgibt:


```python
>>> add_prefix_un("happy")
'unhappy'

>>> add_prefix_un("manageable")
'unmanageable'
```


## 2. Füge Präfixe zu Wortgruppen hinzu

Deine Schwester und ihre Klasse beschäftigen sich noch mit vier weiteren häufigen Präfixen:
 `en` (_bedeutet „hineinstecken" oder „bedecken"_),
 `pre` (_bedeutet „vor" oder „vorwärts"_),
 `auto` (_bedeutet „selbst" oder „gleich"_)
  und `inter` (_bedeutet „zwischen" oder „unter"_).

 In dieser Übung bildet die Klasse Wortgruppen mit diesen Präfixen, damit sie gemeinsam gelernt werden können.
 Jedes Präfix kommt in einer Liste mit häufigen Wörtern vor, mit denen es verwendet wird.
 Die Schülerinnen und Schüler müssen das Präfix anwenden und einen String erzeugen, der das Präfix vor allen Wörtern zeigt.

Implementiere die Funktion `make_word_groups(<vocab_words>)`, die `vocab_words` als Parameter in folgender Form nimmt:
 `[<prefix>, <word_1>, <word_2> .... <word_n>]`, und einen String zurückgibt, bei dem das Präfix vor jedem Wort steht und der so aussieht:
  `'<prefix> :: <prefix><word_1> :: <prefix><word_2> :: <prefix><word_n>'`.

Eine `for`- oder `while`-Schleife zum Verarbeiten der Eingabe ist hier nicht nötig.
Überlege genau, welche String-Methoden (und Trennzeichen) du stattdessen verwenden könntest.


```python
>>> make_word_groups(['en', 'close', 'joy', 'lighten'])
'en :: enclose :: enjoy :: enlighten'

>>> make_word_groups(['pre', 'serve', 'dispose', 'position'])
'pre :: preserve :: predispose :: preposition'

>> make_word_groups(['auto', 'didactic', 'graph', 'mate'])
'auto :: autodidactic :: autograph :: automate'

>>> make_word_groups(['inter', 'twine', 'connected', 'dependent'])
'inter :: intertwine :: interconnected :: interdependent'
```


## 3. Entferne ein Suffix von einem Wort

`ness` ist ein häufiges Suffix und bedeutet _„Zustand des Seins"_.
 In dieser Aktivität muss deine Schwester das ursprüngliche Wort finden, indem sie das Suffix `ness` entfernt.
  Aber natürlich gibt es lästige Rechtschreibregeln: Wenn das ursprüngliche Wort auf einen Konsonanten gefolgt von einem „y" endete, wurde das „y" zu einem „i".
 Beim Entfernen von „ness" muss das „y" in diesen ursprünglichen Wörtern wiederhergestellt werden. z. B. `happiness` --> `happi` --> `happy`.

Implementiere die Funktion `remove_suffix_ness(<word>)`, die ein `word` nimmt und das ursprüngliche Wort ohne das Suffix `ness` zurückgibt.


```python
>>> remove_suffix_ness("heaviness")
'heavy'

>>> remove_suffix_ness("sadness")
'sad'
```

## 4. Extrahiere und wandle ein Wort um

Suffixe werden oft verwendet, um die Wortart eines Wortes zu ändern.
 Im Englischen ist es üblich, Wörter zu „verben" oder zu „verbifizieren": Ein Adjektiv _wird_ zu einem Verb, indem man das Suffix `en` anhängt.

In dieser Aufgabe übt deine Schwester das „Verben" von Wörtern, indem sie ein Adjektiv aus einem Satz extrahiert und in ein Verb umwandelt.
 Glücklicherweise sind alle Wörter, die hier umgewandelt werden müssen, „regelmäßig", sie brauchen keine Änderungen der Schreibweise, um das Suffix anzuhängen.

Implementiere die Funktion `adjective_to_verb(<sentence>, <index>)`, die zwei Parameter nimmt.
 Einen `sentence` mit dem Vokabelwort und den `index` des Wortes, sobald der Satz aufgeteilt ist.
 Die Funktion sollte das extrahierte Adjektiv als Verb zurückgeben.


```python
>>> adjective_to_verb('I need to make that bright.', -1 )
'brighten'

>>> adjective_to_verb('It got dark as the sun set.', 2)
'darken'
```
