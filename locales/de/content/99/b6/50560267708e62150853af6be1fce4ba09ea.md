# Installation

Bitte verwende die `full`-Binary für deine Plattform von [der offiziellen Release-Seite][official-releases].
Derzeit zielt der Track auf das Release Arturo 0.10.0 Arizona Bark ab.

~~~~exercism/caution
Homebrew ist eine beliebte Drittanbieter-Methode, um Software auf macOS- und Linux-Plattformen zu installieren.
Allerdings zielt sein Rezept für Arturo auf den `mini`-Build ab, der mit diesem Track nicht kompatibel ist.
~~~~

Für weitere Hilfe bei der Installation von Arturo schau bitte im [offiziellen Arturo-Discord][discord] vorbei.

## Arturo-Code ausführen

Jetzt bist du bereit, mit dem Schreiben von Arturo-Code zu beginnen!
Um die Arturo-REPL zu öffnen, führe `arturo` in der Kommandozeile aus.
Um ein Arturo-Skript auszuführen, führe `arturo <file>` in der Kommandozeile aus.

[official-releases]: https://arturo-lang.io/#download
[discord]: https://discord.gg/YdVK2CB
