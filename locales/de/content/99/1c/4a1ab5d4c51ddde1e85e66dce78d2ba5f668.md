# Über

Die .NET-Basisklassenbibliotheken stellen die [`Regex`][regex]-Klasse zur Verarbeitung von regulären Ausdrücken bereit.

In diesem [Artikel][regex-comparison] findest du einen Vergleich von C# mit anderen Varianten regulärer Ausdrücke.

## Capture-Gruppen

Ein Aspekt, den man berücksichtigen sollte, sind die Capture-Gruppen, die Textteile zurückgeben, die auf verschiedene Teile des Regex-Musters passen. Der Umgang mit Capture-Gruppen erfordert etwas Eingewöhnung. Sieh dir diese [Dokumentation][capture] an.

Beachte, dass es eine Hierarchie gibt, in der Capture-Gruppen, `(?<capture-name>pattern)`, eine Rolle spielen:

- wobei eine Menge von null oder mehr Treffern zurückgegeben wird (einer für jeden im Text gefundenen Treffer).
- Jeder Treffer enthält eine Anzahl von Capture-Gruppen
- Jede Gruppe enthält eine Anzahl von Captures.

Außerdem:

- `Match` ist von `Group` abgeleitet
- `Group` ist von `Capture` abgeleitet

Zu beachten:

- Der sicherste Weg ist, benannte Captures zu verwenden.
- Capture-Gruppen treten in der `Groups`-Auflistung im Allgemeinen in derselben Reihenfolge auf, in der sie im Text erscheinen.
- `Groups[0]` scheint sich auf den gesamten Treffer zu beziehen.
- `Groups[<capture name>].Value` ist mit ziemlicher Sicherheit das, was dich interessiert. Einzelne Captures (außer `Caputures[0]`) scheinen, wenn sie vorhanden sind, für diagnostische Zwecke gedacht zu sein.

## Regex-Optionen

Mach dich mit [`RegexOptions`][regex-options] vertraut.

Neben den üblichen `IgnoreCase`-Optionen gibt es welche für `MultiLine`, die nützlich ist, um mehrere Textzeilen auf einmal zu verarbeiten, und für `IgnorePatternWhitespace`, die in Kombination mit Verbatim-Strings, String-Interpolation und Kommentaren sehr ausdrucksstark sein kann, wie dieses Beispiel zeigt:

```csharp
const string PREAMBLE = "preamble";
const string PWTEXT = "pwtext";
const string PW = "pw";
const string SPACE = "space";
const string POSTAMBLE = "postamble";

var pattern = $@"
    ^
    (?<{PREAMBLE}>.*)          # any text
    (?<{PWTEXT}>password)      # the literal text - password
    (?<{SPACE}>\s+)
    (?<{PW}>\w*)               # the password itself
    (?<{POSTAMBLE}>.*)         # any text
    $
  ";

var rewrittenLine = $"{grps[PREAMBLE].Value}{grps[PWTEXT].Value}{grps[SPACE].Value}{mask}{grps[POSTAMBLE].Value}";
```

Eine weitere interessante Option ist `RegexOptions.Compiled` für [kompilierte][regex-compilation] reguläre Ausdrücke.
