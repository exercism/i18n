# Kotlin installieren

Neben dem Exercism CLI und deinem Lieblingstexteditor brauchst du für das Üben mit Exercism-Übungen in Kotlin

* das **Java Development Kit** (JDK). Kotlin kompiliert zu Java-Bytecode, deshalb musst du das JDK installieren, das sowohl eine Java Runtime *als auch* Entwicklungswerkzeuge enthält (allen voran den Java-Compiler). Und
* **Gradle**, ein Build-Tool speziell für JVM-basierte Projekte, das Kotlin unterstützt.

Wähle dein Betriebssystem:

* [Windows](#h-windows)
* [macOS](#h-macos)
* [Linux](#h-linux)

... oder ...
* wenn du keinen Paketmanager verwenden möchtest, kannst du [manuell installieren](#h-install-manually).

Optional kannst du auch eine [Java-IDE](#h-java-ides) verwenden.

----

## Windows

Öffne eine Eingabeaufforderung als Administrator. (Wenn du Hilfe beim Öffnen einer Administrator-Eingabeaufforderung brauchst, siehe [eine erhöhte Eingabeaufforderung unter Windows 8+ öffnen](http://www.howtogeek.com/194041/how-to-open-the-command-prompt-as-administrator-in-windows-8.1/) (oder [Windows 7](http://www.howtogeek.com/howto/windows-vista/run-a-command-as-administrator-from-the-windows-vista-run-box/)).

1. Wenn du Chocolatey noch nicht installiert hast, tu es jetzt:

      ```batchfile
        C:\Windows\system32> @powershell -NoProfile -ExecutionPolicy unrestricted -Command "iex ((new-object net.webclient).DownloadString('https://chocolatey.org/install.ps1'))" && SET PATH=%PATH%;%ALLUSERSPROFILE%\chocolatey\bin
      ```

2.  Installiere das JDK:

       ```batchfile
        C:\Windows\system32> choco install openjdk11
        ...
        C:\Windows\system32> refreshenv
        ...
       ```

Wir empfehlen, die Administrator-Eingabeaufforderung zu schließen und eine neue Eingabeaufforderung zu öffnen. Zum Üben der Exercism-Übungen brauchst du keine Administratorrechte.

Jetzt kannst du mit dem Kotlin-Track von Exercism loslegen!

Wie du loslegst, steht unter „[Tests ausführen](https://exercism.org/docs/tracks/kotlin/tests)“.

## macOS

Im Folgenden findest du Anweisungen für die Installation mit der gebräuchlichsten Methode, nämlich Homebrew. Wenn du lieber möchtest, kannst du auch [unter macOS ohne Homebrew installieren](#h-installing-on-macos-without-homebrew).

### Installation

1. Wenn du [Homebrew](http://brew.sh) noch nicht installiert hast, tu es jetzt:

      ```sh
        $ /usr/bin/ruby -e "$(curl -fsSL https://raw.githubusercontent.com/Homebrew/install/master/install)"
      ```

2. Tippe den [Homebrew Cask](https://caskroom.github.io/) an. Damit können wir vorgefertigte Binärdateien wie das JDK installieren.

      ```
        $ brew tap adoptopenjdk/openjdk
      ```

3.  Installiere das JDK:

       ```
        $ brew install --cask adoptopenjdk11
       ```

Jetzt kannst du mit dem Kotlin-Track von Exercism loslegen!

Wie du loslegst, steht unter „[Tests ausführen](https://exercism.org/docs/tracks/kotlin/tests)“.

## Linux

Im Folgenden findest du Anweisungen für die Installation mit dem Paketmanager deiner Distribution. Wenn du lieber möchtest, kannst du auch [unter Linux ohne Paketmanager installieren](#h-installing-on-linux-without-a-package-manager).

* [Debian](#h-debian)
* [Andere Linux-Distributionen](#h-other-linux-distributions)

### Debian

Wenn du Debian oder eine davon abgeleitete Distribution verwendest (etwa Ubuntu oder Linux Mint), nutze APT:

*(getestet mit: Ubuntu 14, 16 und 18)*

1. Installiere das JDK:

      ```sh
        $ sudo apt-get update
        $ sudo apt-get install software-properties-common
        $ sudo add-apt-repository ppa:openjdk-r/ppa
        $ sudo apt-get update
        $ sudo apt-get install openjdk-11-jdk
      ```


Jetzt kannst du mit dem Kotlin-Track von Exercism loslegen!

Wie du loslegst, steht unter „[Tests ausführen](https://exercism.org/docs/tracks/kotlin/tests)“.

----

### Andere Linux-Distributionen

Es gibt viele Möglichkeiten, JDK 11 zu installieren, aber eine der einfachsten ist SDKMAN, 
damit kannst du OpenJDK 11 mühelos installieren. Gehe so vor:

1. Installiere SDKMAN:
    ```sh
    $ curl -s "https://get.sdkman.io" | bash
    ``` 
    (falls das nicht funktioniert, schau dir die Anleitung hier an: https://sdkman.io/install )
1. Installiere OpenJDK 11:
    ```
    $ sdk install java 11.0.2-open
    ``` 

Jetzt kannst du mit dem Kotlin-Track von Exercism loslegen!

Wie du loslegst, steht unter „[Tests ausführen](https://exercism.org/docs/tracks/kotlin/tests)“.

### Manuell unter Windows installieren

*HINWEIS: Diese Anleitung richtet sich an erfahrene Windows-Nutzer. Wenn du nicht bereits weißt, wie man Umgebungsvariablen setzt, oder dich mit der Verwaltung der Verzeichnisstruktur nicht wohlfühlst, empfehlen wir dir dringend die Chocolatey-basierte Installation [oben](#h-windows).*

1. Installiere das JDK:
   1. Lade „**OpenJDK 11 (LTS)**“ von [AdoptOpenJDK](https://adoptopenjdk.net/releases.html?variant=openjdk11#x64_win) herunter (wähle **„Install JDK“**).
   -  Führe den Installer aus und verwende überall die Standardeinstellungen.

Jetzt kannst du mit dem Kotlin-Track von Exercism loslegen!

Wie du loslegst, steht unter „[Tests ausführen](https://exercism.org/docs/tracks/kotlin/tests)“.

## Java-IDEs

Es gibt viele Java-IDEs. Die drei beliebtesten sind:

* [IntelliJ IDEA](https://www.jetbrains.com/idea/download/) (lade die Edition „Community“ herunter)
  - Von den Machern von Kotlin. Diese IDE bietet die beste Unterstützung für die Sprache.
- [Eclipse](https://www.eclipse.org/downloads/)
- [NetBeans](https://netbeans.org/downloads/) (lade das Paket „Java SE“ herunter)

und es gibt [weitere](https://en.wikibooks.org/wiki/Java_Programming/Java_IDEs).
