# Standardwert verwenden

Versuche, einen Standardwert für den Parameter `%{name}` anzugeben.

Auf [dieser Seite](https://docs.microsoft.com/en-us/dotnet/csharp/programming-guide/classes-and-structs/named-and-optional-arguments#optional-arguments) erfährst du mehr darüber, wie du Standardwerte für Parameter angibst. Diese werden auch als optionale Parameter bezeichnet.
