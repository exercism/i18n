# Einführung

Python stellt wahre und falsche Werte mit dem Typ [`bool`][bools] dar, der ein Untertyp von `int` ist. Dieser Typ kennt nur zwei Werte: `True` und `False`. Du kannst diese Werte an eine Variable binden:

```python
>>> true_variable = True
>>> false_variable = False
```

Mit den Operatoren `and`, `or` und `not` können wir boolesche Ausdrücke auswerten:

```python
>>> true_variable = True and True
>>> false_variable = True and False

>>> true_variable = False or True
>>> false_variable = False or False

>>> true_variable = not False
>>> false_variable = not True
```

[bools]: https://docs.python.org/3/library/stdtypes.html#typebool
