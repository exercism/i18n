# Hinweise

## 1. Erstelle eine Reihe nützlicher Strings

- [Strings][strings-and-characters] werden als Literale definiert, indem du null oder mehr Zeichen in doppelte Anführungszeichen (`"`) einschließt.

## 2. Erstelle eine Reihe nützlicher Zeichen

- [Zeichen][strings-and-characters] werden als Literale definiert, indem du genau ein Zeichen in doppelte Anführungszeichen (`"`) einschließt.
- Zeichen, die als Literale definiert werden, brauchen eine explizite Typannotation `Character`, damit der Compiler sie nicht als Strings interpretiert.

## 3. Kombiniere Phrasen zu Nachrichten

- Strings kannst du mit [dem passenden String-Operator][string-docs] verketten.
- Zeichen lassen sich nicht mit Strings verketten.
  Sie müssen zuerst in Strings umgewandelt werden.

## 4. Erstelle ein Abschlussschild

- Bei der [String-Interpolation][string-interpolation] setzt du den Ausdruck, dessen Wert du in den String einfügen willst, in runde Klammern, denen ein Backslash vorangestellt ist.

## 5. Berechne die Kosten eines Schilds

- Swift hat [eine String-Eigenschaft][string-count-docs], die die Anzahl der Zeichen in einem String zurückgibt.
