# Debug

Wenn ein Test fehlschlägt, wird eine Meldung angezeigt, die beschreibt, was schiefgelaufen ist und für welche Eingabe. Du kannst beliebige Werte in deinem Programm untersuchen, indem du sie an die `debug`-Methode übergibst. Das erfasst die Werte und zeigt dir die Ausgabe.

```ruby
debug "The value is #{value}."
debug "The input is #{input.inspect}"
```
