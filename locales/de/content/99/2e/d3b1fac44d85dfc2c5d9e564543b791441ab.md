# Anhang zu den Anweisungen

## Register

| Register | Verwendung   | Typ     | Beschreibung                     |
| -------- | ------------ | ------- | -------------------------------- |
| `$a0`    | Eingabe      | Ganzzahl | N, Summe der Seiten des Dreiecks |
| `$a1`    | Ein-/Ausgabe | Adresse | Werte für a                      |
| `$a2`    | Ein-/Ausgabe | Adresse | Werte für b                      |
| `$a3`    | Ein-/Ausgabe | Adresse | Werte für c                      |
| `$v0`    | Ausgabe      | Ganzzahl | Anzahl der Tripel                |
| `$t0-9`  | temporär     | beliebig | für die temporäre Speicherung    |
