# Einführung

Bevor die Klasse `Promise` eingeführt wurde, gab es nur einen Weg, mit asynchronem Code umzugehen: das _Callback-Muster_.

Ein Callback ist eine Funktion, die als Argument an eine andere Funktion übergeben wird und aufgerufen wird, sobald eine Aktion in dieser anderen Funktion abgeschlossen ist. Ein verbreitetes Muster für solche Callback-Funktionen ist, dass sie als ersten Parameter einen „error" akzeptieren (siehe Beispiel unten).

```javascript
function callback(error, arg2, arg3) {}
```

Wie hängt das mit asynchronem Code zusammen?

Historisch wurden Callbacks verwendet, um nach dem Abschluss einer asynchronen Aufgabe noch etwas zu erledigen, ohne das gesamte Programm zu blockieren.

```javascript
fetchProduct(productId, function (error, data) {
  if (error) {
    // Handle the error
  } else {
    // Do some work
  }
});
```

Im obigen Beispiel nimmt die Funktion `fetchProduct` (die asynchron ist) ein Callback als zweites Argument entgegen, das entscheidet, was zu tun ist, wenn die Produktdaten abgerufen wurden.
