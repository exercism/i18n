# Übungen lokal lösen

Wenn du Übungen auf deinem eigenen Rechner löst, kannst du den ganzen Code in einer Umgebung schreiben, mit der du vertraut bist.

## Die Kommandozeile installieren

Um eine Übung auf deinem eigenen Rechner zu lösen, musst du zuerst die Kommandozeile von Exercism mit [dieser Anleitung](https://exercism.org/cli-walkthrough) installieren und einrichten.

### Konfiguration

Du musst der Kommandozeile sagen, wer du bist, damit wir alles richtig herunterladen können.
Deinen Token findest du auf deiner [Einstellungsseite](/settings/api_cli).
Danach kannst du die Kommandozeile wie folgt konfigurieren, wobei du `<your-api-token>` durch den Wert auf der Einstellungsseite ersetzt:

```
exercism configure --token=<your-api-token>
```

## Die Übung herunterladen

Nach der Installation kannst du die Übung mit dem folgenden Befehl auf deinen Rechner herunterladen (dabei ersetzt du `<exercise-slug>` und `<track-slug>` durch die passenden Werte):

```
exercism download --exercise=<exercise-slug> --track=<track-slug>
```

Du musst dir diesen Befehlsaufbau nicht merken, denn auf der Seite der Übung steht der passende Befehl für diese Übung.

Wenn der Download abgeschlossen ist, werden die Dateien der Übung auf deinen Rechner heruntergeladen.

## Die Übung lösen

Das Ziel jeder Übung ist eine Implementierung, die alle Tests besteht.
So eine Implementierung nennt man eine _Lösung_.

Damit du das schaffst, enthält jede Übung die folgenden Dateien:

- README.md: die Anleitung, die erklärt, was von dir erwartet wird
- HELP.md: Informationen dazu, wie du die Tests ausführst und wie du Hilfe bekommst, wenn du nicht weiterkommst
- HINTS.md (optional): Hinweise, die dir beim Lösen der Übung helfen
- Testdatei(en): sie enthalten die Tests, die die Korrektheit deiner Lösung überprüfen
- Stub-Datei(en): sie geben dir einen Ausgangspunkt, damit du mit deiner Implementierung loslegen kannst

Je nach Track kann es weitere Dateien geben, die das Tooling des Tracks braucht, damit die Tests laufen.

## Deine Lösung einreichen

Sobald deine Lösung alle Tests besteht, kannst du sie mit dem folgenden Befehl einreichen:

```
exercism submit <implementation_file_paths>
```

Dieser Befehl lädt deine Lösung auf die Exercism-Website hoch und gibt die URL der Lösungsseite aus.

Auch diesen Befehl musst du dir nicht merken, denn in der Datei `HELP.md` der Übung steht der richtige Befehl.

Du kannst auch eine unvollständige Lösung einreichen. Damit kannst du:

- sehen, wie andere die Übung gelöst haben
- einen Mentor um Hilfe bitten

## Weitere Funktionen der Kommandozeile

### Alle Befehle ansehen

Führe den Hilfe-Unterbefehl aus, um die vollständige Liste der verfügbaren Befehle zu erhalten.

```bash
exercism help
```

### Fehlersuche

Stelle sicher, dass du die neueste Version verwendest.

Prüfe, welche Version du verwendest:

```bash
exercism version
```

Vergleiche sie mit dem neuesten Release und aktualisiere, falls deine Version nicht die aktuellste ist.

Prüfe nach dem Upgrade die Version noch einmal. Wenn sich die Version nicht geändert hat, stelle sicher, dass du die aktualisierte Binärdatei ausführst.

```bash
which exercism
```

Wenn du weiterhin Probleme hast, öffne ein Issue in exercism/cli auf GitHub mit der Ausgabe des Troubleshoot-Befehls.

```bash
exercism troubleshoot
```

Du kannst Issues in [unserem Issue-Tracker](https://github.com/exercism/exercism/issues) öffnen, und die Community versucht, dir zu helfen. **Bitte stelle sicher, dass du die [interaktive Einführung](https://exercism.org/cli-walkthrough) durchgearbeitet hast, bevor du ein Issue öffnest.**
