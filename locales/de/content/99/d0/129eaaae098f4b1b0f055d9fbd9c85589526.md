# Anleitung

Dein Freund Linus ist Lokomotivführer und fährt Güterzüge zwischen Städten.
Züge zu steuern liegt ihm zwar im Blut, aber mit Logistik und Computern kennt er sich nicht so gut aus.
Er würde gerne deine Programmierhilfe in Anspruch nehmen, um Zugdaten zu organisieren und Fehler in den Routendaten zu korrigieren.

~~~~exercism/note
Diese Übung ließe sich leicht mit Slicing, Indexing und verschiedenen `dict`-Methoden lösen.
Wir möchten aber, dass du beim Lösen der folgenden Aufgaben das Packen, Entpacken und die Mehrfachzuweisung übst.
~~~~

## 1. Erstelle eine Liste aller Waggons

Dein Freund hat bisher jede Waggon-Kennung (ID) mitgeschrieben, aber er weiß nie genau, wie viele Waggons das System zu einem bestimmten Zeitpunkt verarbeiten muss. Für den Rest des Logistikprogramms wäre es viel einfacher, wenn diese Daten in einer einheitlichen `list` gebündelt vorliegen würden.

Implementiere eine Funktion `get_list_of_wagons()`, die eine beliebige Anzahl von Waggon-IDs entgegennimmt.
Jede ID ist eine positive Ganzzahl.
Die Funktion soll die übergebenen IDs dann per `return` als eine einzelne `list` zurückgeben.

```python
>>> get_list_of_wagons(1, 7, 12, 3, 14, 8, 5)
[1, 7, 12, 3, 14, 8, 5]
```

## 2. Korrigiere die Liste der Waggons

Mittlerweile bekommst du ein Gefühl für die Daten und dafür, wie sie im Logistikprogramm verwendet werden.
Das ID-System vergibt an die Lokomotive immer die ID **1**, während die übrigen Waggons im Zug eine zufällig gewählte ID größer als **1** erhalten.

Dein Freund musste zwei neue Waggons an den Zug anhängen und hat vergessen, das System zu aktualisieren!
Jetzt müssen die ersten beiden Waggons in der `list` des Zuges ans Ende verschoben werden, sonst gerät alles durcheinander.

Erschwerend kommt hinzu, dass dein Freund gerade eine zweite `list` entdeckt hat, die offenbar fehlende Waggon-IDs enthält.
Er kann sich nur noch daran erinnern, dass die IDs aus dieser zweiten `list` direkt hinter der dafür vorgesehenen Lokomotive platziert werden sollen, sobald die neuen Waggons verschoben sind.

Linus wäre dir sehr dankbar, wenn du seine Fehler behebst und die Daten zusammenführst.

Implementiere eine Funktion `fix_list_of_wagons()`, die zwei `lists` mit Waggon-IDs entgegennimmt.
Sie soll die ersten beiden Elemente der ersten `list` ans Ende verschieben und die Werte aus der zweiten `list` hinter (_rechts von_) der Lokomotiv-ID (**1**) einfügen.
Die Funktion soll dann eine `list` mit den Änderungen per `return` zurückgeben.

```python
>>> fix_list_of_wagons([2, 5, 1, 7, 4, 12, 6, 3, 13], [3, 17, 6, 15])
[1, 3, 17, 6, 15, 7, 4, 12, 6, 3, 13, 2, 5]
```

## 3. Fehlende Halte hinzufügen

Jetzt, wo alle Waggondaten korrekt sind, möchte Linus, dass du die Routing-Informationen des Systems aktualisierst.
Auf einer Transportroute hält ein Zug unter Umständen an ein paar verschiedenen Bahnhöfen, um Fracht aufzunehmen und/oder abzuladen.
Jede Fahrt kann eine unterschiedliche Anzahl dieser Zwischenstationen haben.
Dein Freund möchte, dass du das Routing-`dict` des Systems um alle fehlenden/zusätzlichen Lieferinformationen ergänzt.

Implementiere eine Funktion `add_missing_stops()`, die ein Routing-`dict` gefolgt von einer variablen Anzahl von Schlüsselwortargumenten entgegennimmt.
Diese Argumente können in Form eines `dict` vorliegen, das einen oder mehrere Halte enthält, oder als beliebig viele `stop_number=city`-Schlüsselwortpaare.
Deine Funktion soll dann das Routing-`dict` zurückgeben, ergänzt um einen zusätzlichen `key`, der eine `list` aller hinzugefügten Halte in der richtigen Reihenfolge enthält.

```python
>>> add_missing_stops({"from": "New York", "to": "Miami"},
                      stop_1="Washington, DC", stop_2="Charlotte", stop_3="Atlanta",
                      stop_4="Jacksonville", stop_5="Orlando")

{"from": "New York", "to": "Miami", "stops": ["Washington, DC", "Charlotte", "Atlanta", "Jacksonville", "Orlando"]}
```

## 4. Routing-Informationen erweitern

Linus hat am Routing-Programm gearbeitet und bemerkt, dass bei bestimmten Routen einige wichtige Details fehlen.
Die ursprünglichen Routeninformationen wurden als `dict` angelegt, und dein Freund möchte, dass du dieses `dict` um alles ergänzt, was fehlen könnte.
Jede Route im System braucht etwas andere Details, deshalb wäre Linus eine generische Lösung wirklich lieber.

Implementiere eine Funktion namens `extend_route_information()`, die zwei `dicts` entgegennimmt.
Das erste `dict` enthält die Start- und Zielstädte, zwischen denen die Zugroute verläuft.

Das zweite `dict` enthält weitere Routing-Details wie Geschwindigkeit, Länge oder Temperatur des Zuges.
Die Funktion soll ein zusammengeführtes `dict` mit allen Routing-Informationen zurückgeben.

~~~~exercism/note
Das zweite `dict` kann andere/mehr Eigenschaften enthalten als die im Beispiel gezeigten.
~~~~

```python
>>> extend_route_information({"from": "Berlin", "to": "Hamburg"}, {"length": "100", "speed": "50"})
{"from": "Berlin", "to": "Hamburg", "length": "100", "speed": "50"}
```

## 5. Das Waggondepot in Ordnung bringen

Als Linus das Waggondepot inspizierte, bemerkte er, dass die Waggons nicht in der richtigen Reihenfolge gelagert wurden.
Neben einer ID hat jeder Waggon eine Farbe, die der Art der Fracht entspricht, die er transportiert.
Im Depot werden die Waggons in Rastern gelagert, wobei jede Spalte im Raster Waggons derselben Farbe enthält.

Allerdings zeigt das Logistiksystem, dass bei den `lists` der im Depot zu lagernden Waggons die _Zeilen_ nach Farbe gruppiert sind.
Damit das Lagerraster aber korrekt funktioniert, sollte jede _Zeile_ drei verschiedene Farben haben, damit die _Spalten_ nach Farbe ausgerichtet sind.
Dein Freund möchte, dass du die `lists` des Waggondepots sortierst, damit die Waggons korrekt gelagert werden.

Implementiere eine Funktion namens `fix_wagon_depot()`, die eine `list` mit drei Elementen entgegennimmt.
Jedes Element der `list` ist eine Unterliste (oder „Zeile“), die drei `tuples` enthält.
Jedes `tuple` ist ein Paar `(<wagon ID>, <wagon color>)`.

Deine Funktion soll eine `list` zurückgeben, in der die drei „Zeilen“-`lists` so umsortiert sind, dass die Waggons an ihren richtigen Positionen stehen.

```python
>>> fix_wagon_depot([
                    [(2, "red"), (4, "red"), (8, "red")],
                    [(5, "blue"), (9, "blue"), (13,"blue")],
                    [(3, "orange"), (7, "orange"), (11, "orange")],
                    ])

[
[(2, "red"), (5, "blue"), (3, "orange")],
[(4, "red"), (9, "blue"), (7, "orange")],
[(8, "red"), (13,"blue"), (11, "orange")]
]
```
