# Anleitung

Ein Pirat plant eine Route durch eine Karte versteckter Buchten. Die Karte ist eine Hashtabelle mit Buchtennamen als Schlüssel; jeder Wert ist ein Array der Buchten, die man von dieser Bucht aus direkt erreichen kann.

## 1. Die Gezeiten-Warteschlange leeren

Definiere `tide-queue` so, dass es ein Array von Elementen entgegennimmt, jedes der Reihe nach auf ein neues Deque pusht und sie dann alle wieder in ein Array poppt, das die ursprüngliche Reihenfolge beibehält. Das ist das FIFO-Muster: hinten pushen, vorne poppen.

```factor
{ "alpha" "bravo" "charlie" } tide-queue .
! => { "alpha" "bravo" "charlie" }
```

## 2. Erreichbare Buchten

Definiere `coves-reachable` so, dass es eine Startbucht und eine Karte entgegennimmt und ein Hash-Set aller von `start` aus erreichbaren Buchten zurückgibt, einschließlich `start` selbst.

```factor
"Skull Bay" H{
    { "Skull Bay"   { "Hidden Cove" } }
    { "Hidden Cove" { "Reef Point"  } }
    { "Reef Point"  { } }
} coves-reachable .
! => HS{ "Skull Bay" "Hidden Cove" "Reef Point" }
```

Verwende eine `<dlist>` als Front für die Breitensuche und ein `HS{ }` für die Menge der bereits besuchten Einträge.

## 3. Sprungzahl

Definiere `hop-count` so, dass es eine Startbucht, eine Zielbucht und eine Karte entgegennimmt und die minimale Anzahl an Sprüngen zwischen ihnen zurückgibt, oder `f`, wenn das Ziel nicht erreichbar ist.

```factor
"Skull Bay" "Hidden Cove"
H{
    { "Skull Bay"   { "Hidden Cove" } }
    { "Hidden Cove" { } }
} hop-count .
! => 1
```

Führe jede Bucht zusammen mit ihrem Abstand zum Start im Deque mit (ein Array mit zwei Elementen funktioniert).

## 4. Goldmenge

Der Stub deklariert `gold-count` mit `:`. Ändere das zu `MEMO:` (nicht `:`), damit das Ergebnis für jede Bucht nur einmal berechnet und zwischengespeichert wird. Schlage das Gold für die Bucht in der Konstante `gold-distribution` nach, die die Übung bereitstellt. Eine Bucht, die nicht in der Verteilung vorkommt, hat null Gold.

```factor
"Smuggler's Hollow" gold-count .   ! => 200
"Davy Jones' Locker" gold-count .  ! => 0
```

## 5. Schatzroute

Definiere `treasure-route` so, dass es eine Startbucht und eine Karte entgegennimmt und die erreichbare Bucht mit dem meisten Gold zurückgibt. Verwende `coves-reachable` aus Aufgabe 2 und `gold-count` aus Aufgabe 4.

```factor
"Skull Bay" some-chart treasure-route .
! => "Smuggler's Hollow"   (the richest reachable cove)
```

Das memoisierte `gold-count` macht wiederholte Nachschlagevorgänge kostenlos, was nützlich ist, wenn mehrere Teile des Algorithmus dieselbe Bucht konsultieren.
