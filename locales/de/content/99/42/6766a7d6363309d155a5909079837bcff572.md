# Ergänzung der Anweisungen

## Tipp

Eine Funktion mit einem *Rückgabetyp* kann nur Daten dieses *Typs* und `null` zurückgeben.
Der Aufrufer der Funktion erwartet jedoch nur einen Datentyp.

Beispiel:
```dart
String hello(int a){
    if ( a == 0){
        return "a";
    } else {
        return null;
    }
}
```
Um klarer zu machen, dass diese Funktion auch `null` oder weitere Datentypen zurückgeben kann, verwende `dynamic`.
```dart
dynamic hello(int a){
    if ( a == 0){
        return "a";
    } else {
        return null;
    }
}
