# Einführung

**Closures** sind ein Programmiermuster [in Clojure][clojure-guide-closures], das es erlaubt, Variablen aus einem äußeren [lexikalischen Gültigkeitsbereich][wiki-lexical-scope] innerhalb einer Funktion zu verwenden. Clojure unterstützt Closures transparent, und sie werden oft verwendet, ohne zu wissen, was sie sind.

```clojure
;; Top-level definitions are global-scope
(def dozen 12)

;; Functions create a new scope.
;; Referencing the outer variable here is a closure.
(fn [n] (* dozen n))
```

## Closures, um Zustand zu speichern und Werte weiterzugeben

Mit einem Atom lässt sich ein Zustand bewahren:

```clojure
;; This function closure increments the counter's state
;; in the outer lexical context.
;; This way the counter can be shared between many calling contexts.

(def increment
  (let [counter (atom 0)]
    (fn [] (swap! counter inc))))
```

Jeder weitere Aufruf von `increment` erhöht den zugehörigen Zähler:

``` clojure
(increment)
;;=> 1
(increment)
;;=> 2
```
