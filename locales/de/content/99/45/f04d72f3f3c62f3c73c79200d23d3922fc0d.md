# Anleitung

Hinweis: Diese Übung ist eine Fortsetzung der Übung `need-for-speed`.

In dieser Übung organisierst du Rennen zwischen verschiedenen Arten von ferngesteuerten Autos.
Jedes Auto hat seine eigene Geschwindigkeit und seinen eigenen Batterieverbrauch.

Die Autos starten mit vollen (100 %) Batterien.
Jedes Mal, wenn du das Auto mit der Fernbedienung fährst, legt es die Geschwindigkeit des Autos in Metern zurück und verringert den verbleibenden Batteriestand um seinen Batterieverbrauch.

Wenn der Batteriestand eines Autos niedriger ist als sein Batterieverbrauch, kannst du das Auto nicht mehr fahren.

Das ferngesteuerte Auto hat eine schicke LED-Anzeige, die zwei Informationen anzeigt:

- Die insgesamt zurückgelegte Strecke, angezeigt als: `"Driven <METERS> meters"`.
- Die verbleibende Batterieladung, angezeigt als: `"Battery at <PERCENTAGE>%"`.

Jede Rennstrecke hat ihre eigene Distanz.
Die Autos werden getestet, indem geprüft wird, ob sie die Strecke beenden können, ohne dass ihnen die Batterie ausgeht.

## 1. Fahre das Auto

Implementiere die Methode `Drive` auf `Car`, die die Anzahl der gefahrenen Meter anhand der Geschwindigkeit des Autos aktualisiert und die Batterie entsprechend dem Batterieverbrauch reduziert:

```go
speed := 5
batteryDrain := 2
car := NewCar(speed, batteryDrain)
car.Drive()
// car is now Car{speed: 5, batteryDrain: 2, battery: 98, distance: 5}
```

Hinweis: Du solltest nicht versuchen, das Auto zu fahren, wenn dadurch der Batteriestand unter 0 fallen würde.

## 2. Zeige die gefahrene Strecke an

Implementiere eine Methode `DisplayDistance` auf `Car`, die die Distanz so als `string` zurückgibt, wie sie auf der LED-Anzeige angezeigt wird:

```go
speed := 5
batteryDrain := 2
car := NewCar(speed, batteryDrain)

fmt.Println(car.DisplayDistance())
// Output: "Driven 0 meters"
```

## 3. Zeige den Batteriestand in Prozent an

Implementiere die Methode `DisplayBattery` auf `Car`, die den Batteriestand in Prozent so als `string` zurückgibt, wie er auf der LED-Anzeige angezeigt wird:

```go
speed := 5
batteryDrain := 2
car := NewCar(speed, batteryDrain)

fmt.Println(car.DisplayBattery())
// Output: "Battery at 100%"
```

## 4. Prüfe, ob ein ferngesteuertes Auto ein Rennen beenden kann

Um ein Rennen zu beenden, muss ein Auto die Distanz des Rennens fahren können.
Das bedeutet, dass seine Batterie nicht leer sein darf, bevor es die Ziellinie überquert hat.
Implementiere die Methode `CanFinish`, die einen `trackDistance int` als Parameter entgegennimmt und `true` zurückgibt, wenn das Auto das Rennen beenden kann; andernfalls gib `false` zurück:

```go
speed := 5
batteryDrain := 2
car := NewCar(speed, batteryDrain)

trackDistance := 100

car.CanFinish(trackDistance)
// => true
```
