# Einführung

In Common Lisp kann eine Funktion Argumente haben, die optional sind.
Diese werden in der Lambda-Liste durch das Lambda-Listen-Schlüsselwort `&optional` gekennzeichnet.
Wird ein Parameter nicht angegeben, wird er an den Wert `nil` gebunden.
Gibt es mehrere optionale Parameter, werden sie der Reihe nach gebunden.
Für optionale Parameter lassen sich Standardwerte angeben.
Schließlich kann für jeden optionalen Parameter ein Symbol angegeben werden, das an wahr oder falsch gebunden wird, je nachdem, ob der Aufrufer der Funktion diesen Parameter übergeben hat (man spricht hier vom „supplied-p-Parameter").

```lisp
(defun optional-parameters (&optional x (y 'default) (z nil z-supplied-p))
  (list x y (if z-supplied-p (list :z-was-supplied z)
                             (list :z-was-not-supplied z))))

(optional-parameters)          ; => (NIL DEFAULT (:Z-WAS-NOT-SUPPLIED NIL))
(optional-parameters 5 nil 10) ; => (5 NIL (:Z-WAS-SUPPLIED 10))
```
