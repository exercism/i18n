# Anleitung

Bei dieser Übung implementierst du eine Teilmenge von Hilfsroutinen, mit denen ein Entwickler Bezeichnernamen bereinigen kann.

In den 6 Aufgaben baust du nach und nach die Funktionen `transform` zum Umwandeln einzelner Zeichen und `clean` zum Umwandeln von Strings auf.

Ein gültiger Bezeichner besteht aus null oder mehr Buchstaben, Unterstrichen, Bindestrichen, Fragezeichen und Emojis.

Wenn ein leerer String an die Funktion `clean` übergeben wird, sollte ein leerer String zurückgegeben werden.

## 1. Ersetze alle vorkommenden Bindestriche durch Unterstriche

Implementiere die Funktion `transform`, um alle Bindestriche durch Unterstriche zu ersetzen.

```fsharp
transform '-'  // => "_"
```

## 2. Entferne alle Whitespace-Zeichen

Entferne alle Whitespace-Zeichen.
Das umfasst auch Whitespace am Anfang und am Ende.

```fsharp
transform ' '  // => ""
```

## 3. Wandle camelCase in kebab-case um

Ändere die Funktion `transform` so, dass sie camelCase in kebab-case umwandelt

```fsharp
transform 'D'  // => "-d"
```

## 4. Lasse Zeichen weg, die Ziffern sind

Ändere die Funktion `transform` so, dass sie alle Zeichen weglässt, die numerisch sind.

```fsharp
transform '7'  // => ""
```

## 5. Ersetze griechische Kleinbuchstaben durch Fragezeichen

Ändere die Funktion `transform` so, dass sie alle griechischen Buchstaben im Bereich 'α' bis 'ω' ersetzt.

```fsharp
transform 'β' // => "?"
```

## 6. Kombiniere diese Operationen, um einen String zu verarbeiten

Implementiere die Funktion `clean`, um diese Operationen auf einen ganzen String anzuwenden.

Zeichen, die außerhalb der Regeln liegen, sollten unverändert durchgereicht werden.

```fsharp
clean "  a2b Cd-ω😀  " //  => "ab-cd_?😀"
```

## Einen String aus Zeichen zusammensetzen

Dieses Thema wird später im Lehrplan ausführlich behandelt.

Für den Moment könnte es nützlich sein zu wissen, dass es eine [Funktion höherer Ordnung][higher-order-function] namens [`String.collect`][string-collect] gibt, die eine Sammlung von `char`s mithilfe einer Funktion, die du bereitstellst, in einen String umwandelt.

```fsharp
let transform ch = $"{ch}_"
String.collect transform "abc"  // =>  "a_b_c_"
```
