# Einführung

In JavaScript können Werte von unterschiedlichem Typ sein. Den Typ einer Variable kannst du durch eine explizite _Typkonvertierung_ ändern.
Außerdem führt JavaScript eine _Typumwandlung_ (implizite Typkonvertierung) durch, wenn der Kontext es erfordert.

## Typkonvertierung

Anders als viele andere Sprachen hat JavaScript kein Konstrukt, um in einen (anderen) Typ umzuwandeln. Stattdessen kannst du einige eingebaute Hilfsfunktionen verwenden.
Vor allem `Boolean`, `Number` und `String` kannst du als Funktionen verwenden, um einen Wert in den jeweiligen Typ umzuwandeln.

### In einen booleschen Wert umwandeln (Truthy-/Falsy-Werte)

Mit `Boolean(value)` kannst du jeden Wert in einen booleschen Wert umwandeln.
Es gibt eine feste Menge von Werten, die sogenannten _falsy_ Werte, die zu `false` werden.
Vor allem `false`, `0`, der leere String, `null`, `undefined` und `NaN` sind falsy.

Für alle anderen Werte gibt `Boolean` `true` zurück.
Diese Werte heißen _truthy_.

```javascript
Boolean(-1);
// => true

Boolean(0);
// => false

Boolean(' ');
// => true

Boolean('');
// => false
```

Beachte, dass wegen der beschriebenen Regeln `'0'`, `'false'`, `[]` und `{}` in JavaScript **truthy** sind.

### In eine Zahl umwandeln

Mit `Number(value)` kannst du einen Wert in eine Zahl umwandeln.
Leerzeichen am Anfang und am Ende eines Strings werden ignoriert, und ein leerer String wird zu `0`.
Wenn du versuchst, einen nicht-primitiven Wert oder einen String umzuwandeln, der keine Zahl darstellt, ist das Ergebnis `NaN` ([Not-A-Number][mdn-nan]).

```javascript
Number('  -12.34  ');
// => -12.34

Number('1,2');
// => NaN

Number('');
// => 0

Number({ num: 123 });
// => NaN
```

### In einen String umwandeln

Mit `String(value)` kannst du einen Wert in einen String umwandeln.
Bei primitiven Werten ist das Ergebnis so, wie du es erwartest.

```javascript
String(12.34);
// => '12.34'

String(false);
// => 'false'

String(null);
// => 'null'

String(undefined);
// => 'undefined'
```

Bei Arrays wendet die `String`-Funktion die String-Konvertierung auf jedes Element an und verbindet die Ergebnisse mit einem Komma.
Du kannst auch selbst die [`join`-Methode][mdn-join] verwenden, zum Beispiel um das Trennzeichen anzupassen.
Beachte, dass in diesen Fällen `null` und `undefined` in einen leeren String umgewandelt werden.

```javascript
String([42, null, true, 'abc']);
// => '42,,true,abc'
```

Bei Objekten gibt `String` standardmäßig einen wenig hilfreichen Text zurück.

```javascript
String({ key: 'value' });
// => '[object Object]'
```

## Typumwandlung

In bestimmten Kontexten wandelt JavaScript einen Wert automatisch in einen anderen Datentyp um, bevor es eine Anweisung auswertet.
Diese implizite Konvertierung heißt _Typumwandlung_.

### Boolescher Kontext

Wenn ein nicht-boolescher Wert in einem booleschen Kontext verwendet wird, wendet JavaScript dieselben Regeln an wie die `Boolean`-Funktion, um den Wert implizit umzuwandeln.

Eine Umwandlung in einen booleschen Wert findet häufig statt bei

- der Bedingung einer [if-Anweisung][concept-conditionals]
- dem ersten Operanden des [ternären Operators][mdn-ternary] `?`
- dem Operanden des logischen NICHT-Operators `!`
- den Operanden der logischen Operatoren UND `&&` und ODER `||` (das Ergebnis des Ausdrucks ist einer der Operanden, nicht unbedingt ein boolescher Wert)

```javascript
const num = 0;
if (num) {
  // this block is NOT executed because 0 is falsy
}
```

### String-Kontext

Wenn der Additionsoperator `+` auf primitive Werte angewendet wird und ein Operand ein String ist, wird der andere ebenfalls in einen String umgewandelt.
Die Konvertierungslogik ist dieselbe wie bei der `String`-Funktion.
Anschließend werden die beiden Strings verkettet.

```javascript
let name;
'hello ' + name;
// => 'hello undefined'
```

### Numerischer Kontext

Viele Operatoren wandeln ihre Operanden (falls nötig) nach der oben erklärten Logik der `Number`-Funktion in Zahlen um.

- Arithmetische Operatoren: `+` (wenn kein String beteiligt ist), `-`, `*`, `/`, `%`, `**`
- Unäre Plus- und Negationsoperatoren: `+`, `-`
- Vergleichsoperatoren (für Operanden, die keine Strings sind): `>`, `>=`, `<`, `<=`
- Bitweise Operatoren: `|`, `&`, `^`, `~`

Weitere Details zu diesen Operatoren findest du in der [MDN-Liste der Operatoren][mdn-operators].

Um Fehler zu vermeiden, solltest du `Number` immer explizit aufrufen, bevor du diese Operatoren anwendest.
