# Anleitung

Implementiere eine Funktion, die aus zwei Punkten auf der 2D-Koordinatenebene einen dritten Punkt erzeugt, sodass die Verbindung dieser Punkte ein gleichseitiges Dreieck ergibt. Die Funktion gibt zwei Punkte zurück, denn es gibt zwei mögliche „dritte“ Punkte, die mit den beiden Ausgangspunkten ein gleichseitiges Dreieck bilden. Erwähnenswert ist, dass ein gleichseitiges Dreieck als eine dreiseitige Form definiert ist, bei der alle drei Seiten gleich lang sind.

Die Funktion nimmt zwei Python-Tupel entgegen, von denen jedes die x- und die y-Koordinate eines Punktes als Gleitkommazahl angibt. Zum Beispiel könnten (0.0, 0.0) und (1.0, 1.0) die Eingaben sein.

Die Funktion sollte ein Tupel zurückgeben, das aus zwei Tupeln besteht, von denen jedes die x- und die y-Koordinate eines Punktes als Gleitkommazahl angibt. Zum Beispiel könnte ((0.0, 0.0), (1.0, 1.0)) ein möglicher Rückgabewert sein.

Die Funktion sollte die in Python eingebaute Ausnahme ArithmeticError auslösen, wenn der Z3-Solver ein Ergebnis liefert, das nicht erfüllbar ist. Auch wenn beide Eingabepunkte identisch sind, sollte die Funktion einen ArithmeticError auslösen.

Die Funktion sollte nicht die Funktion „set_option()“ aus der z3-Bibliothek verwenden, um globale Parameter zu setzen. Das geschieht in den Testfällen, um sicherzustellen, dass die Gleitkommazahlen die erwartete Genauigkeit (Anzahl der Nachkommastellen) haben.

Da die Modellinterpretation einer Real-Variable in Z3 eine Instanz von AlgebraicNumRef, IntNumRef oder RatNumRef ist, wird eine Funktion bereitgestellt, die diese Instanz in eine Gleitkommazahl umwandelt.
