# Anleitung

In dieser Übung implementierst du eine Möglichkeit, die Bestenliste für das beliebteste Spiel in deiner örtlichen Spielhalle im Blick zu behalten.

Du sollst 5 Funktionen implementieren, die sich größtenteils darum drehen, ein Objekt zu bearbeiten, das die Bestenliste speichert.

## 1. Erstelle eine neue Bestenliste

Erstelle eine Funktion `create_score_board`, die ein Wörterbuch zurückgibt, das als Bestenliste dient.
Die Schlüssel dieses Objekts sind die Namen der Spieler, die Werte sind ihre Punktzahlen.
Zu Testzwecken sollst du direkt einen Eintrag in das Objekt aufnehmen.
Dieser anfängliche Eintrag sollte aus `"The Best Ever"` als Spielernamen und `1_000_000` als Punktzahl bestehen.

```gleam
create_score_board()
// returns an object with one initial entry
```

## 2. Füge Spieler zu einer Bestenliste hinzu

Um einen Spieler zur Bestenliste hinzuzufügen, definiere die Funktion `add_player`.
Sie akzeptiert 3 Parameter:

- Der erste Parameter ist die Bestenliste als Wörterbuch.
- Der zweite Parameter ist der Name eines Spielers als String.
- Der dritte Parameter ist die Punktzahl als Ganzzahl.

Die Funktion gibt das Wörterbuch mit dem neuen Spieler und seiner Punktzahl zurück.

## 3. Entferne Spieler aus einer Bestenliste

Wenn Spieler gegen die Regeln der Spielhalle verstoßen, werden sie manuell aus der Bestenliste entfernt.
Definiere `remove_player`, die 2 Parameter entgegennimmt:

- Der erste Parameter ist die Bestenliste als Wörterbuch.
- Der zweite Parameter ist der Name des Spielers als String.

Diese Funktion sollte das Wörterbuch ohne den Spieler zurückgeben, der entfernt wurde.

Wenn der Spieler gar nicht auf der Bestenliste stand, sollte sich an der Bestenliste nichts ändern, sie sollte unverändert zurückgegeben werden.

## 4. Erhöhe die Punktzahl eines Spielers

Wenn ein Spieler in der Spielhalle ein weiteres Spiel beendet, wird eine bestimmte Anzahl Punkte zur bisherigen Punktzahl auf der Bestenliste addiert.
Implementiere `update_score`, die 3 Parameter entgegennimmt:

- Der erste Parameter ist die Bestenliste als Wörterbuch.
- Der zweite Parameter ist der Name des Spielers, dessen Punktzahl erhöht werden soll.
- Der dritte Parameter ist die Punktzahl, die du zur gespeicherten Punktzahl **addieren** möchtest.

Die Funktion sollte das Wörterbuch mit der aktualisierten Punktzahl zurückgeben.

Wenn der Spieler gar nicht auf der Bestenliste stand, sollte sich an der Bestenliste nichts ändern, sie sollte unverändert zurückgegeben werden.

## 5. Wende die Bonuspunkte für Montag an

Die Spielhalle führt montags eine separate Bestenliste.
Am Ende des Tages bekommt jeder Spieler auf dieser Bestenliste 100 zusätzliche Punkte.

Implementiere die Funktion `apply_monday_bonus`, die eine Bestenliste entgegennimmt.
Die Funktion gibt das Wörterbuch zurück, in dem für jeden Spieler auf dieser Bestenliste die Bonuspunkte hinzugefügt wurden.
