# Einführung

Oft möchten wir Code schreiben, der abhängig von einer Bedingung verzweigen kann. In Elixir gibt es dafür viele Möglichkeiten, doch eine der einfachsten ist `cond/1`.

Ganz einfach ausgedrückt folgt `cond` mit einem oder mehreren Zweigen dem ersten Pfad, der zu `true` ausgewertet wird:

```elixir
cond do
  x > 10 -> :this_might_be_the_way
  y < 7 -> :or_that_might_be_the_way
  true -> :this_is_the_default_way
end
```

Wenn kein Pfad zu `true` ausgewertet wird, löst die Laufzeitumgebung einen Fehler aus.
