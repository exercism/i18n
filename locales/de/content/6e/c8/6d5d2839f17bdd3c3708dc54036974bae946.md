# Einführung

Elixir bietet eine elegante Syntax für die Arbeit mit Binärdaten, wie wir sie schon bei der speziellen Form `<<>>` für die Arbeit mit [Bitstrings][exercism-bitstrings] gesehen haben.

Der Typ Binary ist eine Spezialisierung des Bitstring-Typs. Während Bitstrings beliebig lang sein können (jede Anzahl von [Bits][wiki-bit]), gilt für Binaries, dass die Anzahl der Bits ohne Rest durch 8 teilbar ist. Bei der Arbeit mit Binaries denken wir also oft in [Bytes][wiki-byte] (8 Bits). Ein Byte kann Ganzzahlen von `0` bis `255` darstellen. Es ist üblich, Byte-Werte in [hexadezimaler Form][wiki-hexadecimal] zu schreiben, `0x00 - 0xFF`.

Binärliterale werden mit der speziellen Bitstring-Form `<<>>` definiert. Beim Definieren eines Binärliterals können wir Ganzzahl- und String-Literale verwenden. Ganzzahlwerte größer als 255 laufen über, und nur die letzten 8 Bits der Ganzzahl werden verwendet. Standardmäßig wird der Modifizierer `::binary` auf den Wert angewendet. Wir können Binaries mit dem Operator `<>/2` aneinanderhängen.

```elixir
<<255>> == <<0xFF>>
# Overflowing bits are truncated
<<256>> == <<0>>
<<2, 4, 6, 8, 10, 12, 14, 16>> == <<0x02, 0x04, 0x06, 0x08, 0x0A, 0x0C, 0x0E, 0x10>>
```

Ein _Null-Byte_ ist ein anderer Name für `<<0>>`.

## Musterabgleich mit Binärdaten

[Musterabgleich][exercism-pattern-matching] funktioniert sogar mit Binaries, und wir können einen Teil der Binärdaten abgleichen, ähnlich wie bei einer Liste.

```elixir
# Ignore the first 8 bytes, match and bind the remaining to `body`
<<_::binary-size(8), body::binary>>
```

Wie bei anderen Formen des Musterabgleichs können wir das in Funktionssignaturen verwenden, um beim Auswählen aus mehreren Funktionsklauseln das passende Muster zu treffen.
