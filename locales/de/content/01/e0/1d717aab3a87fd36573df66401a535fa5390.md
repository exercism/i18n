# Ergänzung zu den Anweisungen

## Ausgabeformat

Gib den Songtext als nullterminierten String aus.

## Register

| Register | Verwendung   | Typ     | Beschreibung                  |
| -------- | ------------ | ------- | ----------------------------- |
| `$a0`    | Eingabe      | Ganzzahl | Startstrophe                 |
| `$a1`    | Eingabe      | Ganzzahl | Endstrophe                   |
| `$a2`    | Ein-/Ausgabe | Adresse | nullterminierter Ausgabe-String |
| `$t0-9`  | temporär     | beliebig | für temporäre Speicherung    |
