# Einführung

## Strings

Ein String (Zeichenkette), in F# als `string` geschrieben, ist ein Objekt, das unveränderlichen Text als Folge von Unicode-Zeichen (Buchstaben, Ziffern, Satzzeichen usw.) darstellt und wie folgt definiert wird:

```fsharp
let fruit = "Apple"
```

Strings werden manipuliert, indem du entweder die Methoden des Strings aufrufst oder die Funktionen des `String`-Moduls verwendest. Sobald ein String erstellt wurde, kann sich sein Wert nie mehr ändern. Alle Methoden oder Funktionen, die einen String zu verändern scheinen, geben in Wirklichkeit einen neuen String zurück.

Strings lassen sich auf verschiedene Weise verketten oder formatieren.
* Du kannst den `+`-Operator zum Verketten verwenden:
```fsharp
let sentence = "Apple" + " is a type of fruit."
```
* Du kannst die Funktion `sprintf` zum Formatieren von Text verwenden. Dabei hast du Platzhalter in einem Formattext (`%s` für einen `string`) und übergibst die Werte als Argumente:
```fsharp
let sentence = sprintf "%s is a type of %s." "Apple" "fruit"
```
