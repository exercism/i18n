# Einführung

In Elixir ist Dokumentation ein zentraler Bestandteil der Sprache.

Es gibt zwei Modulattribute, die häufig verwendet werden, um deinen Code zu dokumentieren: `@moduledoc` zum Dokumentieren eines Moduls und `@doc` zum Dokumentieren einer Funktion, die auf das Attribut folgt. Das Attribut `@moduledoc` steht meist in der ersten Zeile des Moduls, und das Attribut `@doc` steht meist direkt vor einer Funktionsdefinition oder vor dem Typespec der Funktion, falls es eines gibt. Die Dokumentation wird üblicherweise in einem mehrzeiligen String in der Heredoc-Syntax geschrieben.

Elixir-Dokumentation wird in [**Markdown**][markdown] geschrieben.

```elixir
defmodule String do
  @moduledoc """
  Strings in Elixir are UTF-8 encoded binaries.
  """

  @doc """
  Converts all characters in the given string to uppercase according to `mode`.

  ## Examples

      iex> String.upcase("abcd")
      "ABCD"

      iex> String.upcase("olá")
      "OLÁ"
  """
  def upcase(string, mode \\ :default)
end
```

[markdown]: https://docs.github.com/en/github/writing-on-github/basic-writing-and-formatting-syntax
