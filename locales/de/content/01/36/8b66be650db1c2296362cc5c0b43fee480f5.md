# Debug

Mit [Debug.log](https://package.elm-lang.org/packages/elm/core/latest/Debug#log) kannst du Meldungen an fehlschlagende Tests anhängen, und zwar so:

```elm
hoursToSeconds : Int -> Int
hoursToSeconds hours =
    let
        secondsInOneHour =
            Debug.log "secondsInOneHour" (60 * 60)
    in
    hours * secondsInOneHour
```

Bei einem fehlschlagenden Test lautet das angehängte Log `secondsInOneHour: 3600`.

Es gibt einen Haken: Konstanten auf oberster Ebene werden nur einmal ausgewertet, bevor die Tests starten. Deshalb können Tests ihre Log-Meldungen nicht erfassen. Zum Beispiel:

```elm
secondsInOneHour : Int
secondsInOneHour =
    Debug.log "secondsInOneHour" (60 * 60)
```

erzeugt während der Tests keine Log-Meldung, weil die JavaScript-Variable, die zu `secondsInOneHour` gehört, bereits zum Wert 3600 ausgewertet wurde.
