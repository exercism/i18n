# Funktionen

Funktionen sind in Cairo grundlegend.

Konventionell verwendet Cairo **snake case** für Funktions- und Variablennamen: Die Wörter stehen in Kleinbuchstaben und werden durch Unterstriche getrennt.

Hier ist ein Beispiel:

```rust
fn another_function() {
    println!("Another function.");
}

fn main() {
    println!("Hello, world!");
    another_function();
}
```

Funktionen werden mit `fn` definiert, gefolgt von einem Namen, runden Klammern für Parameter (falls vorhanden) und einem Körper in geschweiften Klammern.

Du kannst eine Funktion über ihren Namen aufrufen, dem runde Klammern folgen.

Die Reihenfolge der Funktionen spielt keine Rolle, solange sie im Gültigkeitsbereich liegen.

## Parameter

Funktionen können **Parameter** entgegennehmen. Das sind Variablen, die in der Funktionssignatur definiert werden.

Beim Aufruf der Funktion übergibst du **Argumente**, also die Werte, die an diese Parameter übergeben werden.

```rust
fn main() {
    another_function(5);
}

fn another_function(x: felt252) {
    println!("The value of x is: {}", x);
}
```

Hier ist `x` ein Parameter vom Typ `felt252`.

Beim Aufruf mit `5` gibt die Funktion „The value of x is: 5" aus.

Mehrere Parameter werden durch Kommas getrennt:

```rust
fn main() {
    print_labeled_measurement(5, "h");
}

fn print_labeled_measurement(value: u128, unit_label: ByteArray) {
    println!("The measurement is: {value}{unit_label}");
}
```

Das gibt `The measurement is: 5h` aus.

## Anweisungen und Ausdrücke

Cairo-Funktionen bestehen aus **Anweisungen** und **Ausdrücken**:

- **Anweisungen** führen Aktionen aus, geben aber keine Werte zurück.
Zum Beispiel ist `let x = 3;` eine Anweisung.
- **Ausdrücke** werden zu einem Wert ausgewertet.
Zum Beispiel wird `5 + 6` zu `11` ausgewertet.

Blöcke in geschweiften Klammern sind ebenfalls Ausdrücke, und ihr letzter Wert wird zurückgegeben:

```rust
fn main() {
    let y = {
        let x = 3;
        x + 1
    };
    println!("The value of y is: {}", y);
}
```

Hier wird `y` der Wert `4` zugewiesen.

## Rückgabewerte

Funktionen können Werte zurückgeben. Mit der Syntax `->` gibst du den Rückgabetyp an.

Standardmäßig gibt eine Funktion den Wert ihres letzten Ausdrucks zurück:

```rust
fn five() -> u32 {
    5
}

fn main() {
    let x = five();
    println!("The value of x is: {}", x);
}
```

Das gibt `The value of x is: 5` aus.

Für komplexere Fälle:

```rust
fn plus_one(x: u32) -> u32 {
    x + 1
}

fn main() {
    let x = plus_one(5);
    println!("The value of x is: {}", x);
}
```

Das gibt `The value of x is: 6` aus.

Achte darauf, am Ende des letzten Ausdrucks kein Semikolon zu setzen. Es würde den Ausdruck in eine Anweisung verwandeln, wodurch die Funktion statt des erwarteten Werts `()` (Unit-Typ) zurückgibt.
