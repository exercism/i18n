# Einführung

Bedingte Anweisungen führen, je nachdem ob eine Bedingung `true` oder `false` ist, unterschiedlichen Code aus.

Eine `if`-Anweisung führt ihren Block nur aus, wenn ihre Bedingung `true` ist.
Go kennt keine truthy- oder falsy-Werte, deshalb muss die Bedingung vom Typ `bool` sein.
Ausdrücke wie `if mySlice { ... }` oder `if 1 { ... }` sind Kompilierfehler.

```go
func describe(val string) string {
    if val == "val" {
        return "was val"
    }
    return "was not val"
}
```

Mit `else if` prüfst du weitere Bedingungen, und `else` dient als Fallback, wenn keine davon zutrifft.
Die Bedingungen werden von oben nach unten ausgewertet, und nur der erste Zweig, dessen Bedingung wahr ist, wird ausgeführt.

```go
number := 0
result := "This number is "

if number > 0 {
    result += "positive"
} else if number < 0 {
    result += "negative"
} else {
    result += "zero"
}
```

Eine `if`-Anweisung kann auch eine kurze Initialisierungsanweisung enthalten.
Variablen, die auf diese Weise deklariert werden, sind nur innerhalb der gesamten `if`/`else`-Kette im Gültigkeitsbereich.

```go
num := 7
if v := 2 * num; v > 10 {
    fmt.Println(v)
} else {
    fmt.Println(num)
}
// Output: 14
```
