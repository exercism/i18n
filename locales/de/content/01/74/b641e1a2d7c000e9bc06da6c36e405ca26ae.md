# Verwende Endrekursion

Das Ziel dieser Übung ist es, dir die Endrekursion beizubringen. Löse sie, ohne rekursive Funktionen zu verwenden, die nicht endrekursiv sind.

Endrekursive Funktionen in deiner Lösung: %{tail_call_recursive_functions}. Weitere rekursive Funktionen in deiner Lösung: %{non_tail_call_recursive_functions}.

Denk daran: Endrekursion liegt vor, wenn der _letzte_ Ausdruck, den die Funktion auswertet, ein Aufruf an sich selbst ist.

```elixir
# this is tail call recursion,
# the last expression is a call to `do_encode`
defp do_encode([n | rest], acc) do
  do_encode(rest, <<acc::bitstring, encode_nucleotide(n)::4>>)
end

# this is not tail call recursion,
# the last expression is a call to `<<>>`
def encode([head | tail]) do
  <<encode_nucleotide(head)::4, encode(tail)::bitstring>>
end
```
