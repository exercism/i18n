# Installation

Folge den Anweisungen für dein System auf der Installationsseite unter [golang.org][go-install].


## Go-Version

Dieser Track verwendet Go 1.27.

Eine ältere Version von Go kannst du verwenden, indem du die `go.mod`-Datei der jeweiligen Übung änderst und die Zeile `go 1.27` anpasst.
Die Tests verwenden jedoch Funktionen, die in Go 1.22 eingeführt wurden, und funktionieren mit einer älteren Version nicht ohne Änderungen.

[go-install]: https://go.dev/doc/install
