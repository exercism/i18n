# Anleitung

Dein Freund hat dir gerade eine Nachricht mit einem wichtigen Geheimnis geschickt. Damit es andere nicht leicht lesen können, wurde die Nachricht durch eine Reihe von Bitmanipulationen verschlüsselt. Du musst die Wörter schreiben, mit denen du die Nachricht entschlüsseln kannst.

## 1. Verschiebe die Bits zurück

Der erste Schritt beim Entschlüsseln der Nachricht besteht darin, die Verschiebung aus dem Verschlüsselungsprozess rückgängig zu machen, indem du die Bits wieder nach rechts verschiebst. Die späteren Schritte gehen davon aus, dass von links Nullen eingefügt werden.

Definiere `shift-back`, das einen 32-Bit-Wert und eine Anzahl entgegennimmt und den Wert zurückgibt, der um diese Anzahl nach rechts verschoben und mit Nullen aufgefüllt wurde.

```factor
0b1001 2 shift-back .
! => 0b0010
```

## 2. Setze einige Bits

Als Nächstes gibt es einige Bits, die auf 1 gesetzt werden müssen.

Definiere `set-bits`, das einen Wert und eine Maske entgegennimmt. Jedes Bit von `value`, bei dem das entsprechende Bit von `mask` 1 ist, soll auf 1 gesetzt werden; alle anderen Bits bleiben unverändert.

```factor
0b0110 0b0101 set-bits .
! => 0b0111
```

## 3. Kippe bestimmte Bits

Während der Verschlüsselung werden einige Bits gekippt. Sie müssen zurückgekippt werden, um die Nachricht zu entschlüsseln.

Definiere `flip-bits`, das einen Wert und eine Maske entgegennimmt. Jedes Bit von `value`, bei dem das entsprechende Bit von `mask` 1 ist, soll gekippt werden; alle anderen Bits bleiben unverändert.

```factor
0b1100 0b0101 flip-bits .
! => 0b1001
```

## 4. Lösche bestimmte Bits

Zuletzt gibt es noch bestimmte Bits, die immer zu 0 entschlüsselt werden.

Definiere `clear-bits`, das einen Wert und eine Maske entgegennimmt. Jedes Bit von `value`, bei dem das entsprechende Bit von `mask` 1 ist, soll auf 0 gelöscht werden; alle anderen Bits bleiben unverändert.

```factor
0b0110 0b0101 clear-bits .
! => 0b0010
```
