# Hinweise

## Allgemein

- Das `locals`-Vokabular stellt `::` und `[| | ]` bereit.
- Locals ersetzen keinen Stack-Code. Setze sie dort ein, wo sie für
  Klarheit sorgen.

## 1. Den Kochstatus bestimmen

- `cond` aus [`combinators`][combinators] hat die richtige Form: Ein
  Zweig prüft `dup not` (der Timer ist `f`), ein weiterer prüft
  `dup zero?`, und ein Standardfall behandelt den Rest. Jeder Zweig
  sollte den Timer mit `drop` entfernen, bevor er den String auf den
  Stack legt.

## 2. Die Vorbereitungszeit schätzen

- `:: preparation-time ( layers minutes-per-layer -- total )`
  mit `layers length minutes-per-layer *`.

## 3. Die benötigten Nudeln und Soße berechnen

- Mit Locals kannst du `layers` zweimal referenzieren, ohne `dup`. `count`
  mit dem Prädikat `[ "noodles" = ]` (oder `"sauce" =`) liefert dir die
  Anzahl für jede Lage.
- `1/5` ist ein rationales Literal in Factor.

## 4. Die geheime Zutat hinzufügen

- `last` (in [`sequences`][sequences]) liest das letzte Element;
  `suffix` hängt eines ans Ende an.

## 5. Das Rezept skalieren

- Der Skalierungsfaktor ist `portions / 2`. Mit Locals kannst du
  `portions` innerhalb des Lambda referenzieren.
- `assoc-map` aus [`assocs`][assocs] nimmt eine Quotation `( key value -- newkey newvalue )`.
  Innerhalb von `[| key value | … ]` gibst du beide Werte zurück, um
  denselben Schlüssel beizubehalten und einen neuen Wert zu erzeugen.
