# Anleitung

Lucians Freundin ist auf dem Weg nach Hause und er hat das Abendessen zu ihrem Jahrestag noch nicht gekocht!

In dieser Übung schreibst du etwas Code, um Lucian dabei zu helfen, eine köstliche Lasagne aus seinem Lieblingskochbuch zu kochen.

Es gibt vier Aufgaben und alle drehen sich um die Zeit, die für das Kochen der Lasagne benötigt wird.

## 1. Definiere die erwartete Backofenzeit in Minuten

Definiere die Methode `Lasagna.ExpectedMinutesInOven()`, die keine Parameter entgegennimmt und zurückgibt, wie viele Minuten die Lasagne im Ofen sein sollte. Laut dem Kochbuch beträgt die erwartete Backofenzeit 40 Minuten:

```csharp
var lasagna = new Lasagna();
lasagna.ExpectedMinutesInOven();
// => 40
```

## 2. Berechne die verbleibende Backofenzeit in Minuten

Definiere die Methode `Lasagna.RemainingMinutesInOven()`, die die tatsächlichen Minuten, die die Lasagne bereits im Ofen war, als Parameter entgegennimmt und zurückgibt, wie viele Minuten die Lasagne noch im Ofen bleiben muss. Dabei gehst du von der erwarteten Backofenzeit aus der vorherigen Aufgabe aus.

```csharp
var lasagna = new Lasagna();
lasagna.RemainingMinutesInOven(30);
// => 10
```

## 3. Berechne die Vorbereitungszeit in Minuten

Definiere die Methode `Lasagna.PreparationTimeInMinutes()`, die die Anzahl der Schichten, die du der Lasagne hinzugefügt hast, als Parameter entgegennimmt und zurückgibt, wie viele Minuten du mit der Vorbereitung der Lasagne verbracht hast. Dabei gehst du davon aus, dass jede Schicht 2 Minuten zum Vorbereiten braucht.

```csharp
var lasagna = new Lasagna();
lasagna.PreparationTimeInMinutes(2);
// => 4
```

## 4. Berechne die verstrichene Zeit in Minuten

Definiere die Methode `Lasagna.ElapsedTimeInMinutes()`, die zwei Parameter entgegennimmt: Der erste Parameter ist die Anzahl der Schichten, die du der Lasagne hinzugefügt hast, und der zweite Parameter ist die Anzahl der Minuten, die die Lasagne bereits im Ofen war. Die Funktion sollte zurückgeben, wie viele Minuten du mit dem Kochen der Lasagne verbracht hast, also die Summe aus der Vorbereitungszeit in Minuten und der Zeit in Minuten, die die Lasagne gerade im Ofen verbracht hat.

```csharp
var lasagna = new Lasagna();
lasagna.ElapsedTimeInMinutes(3, 20);
// => 26
```
