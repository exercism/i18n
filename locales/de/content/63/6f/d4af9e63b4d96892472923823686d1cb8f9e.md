# Lernen

Haskell ist eine rein funktionale Sprache. Dieses Paradigma unterscheidet sich grundlegend von dem häufiger gelehrten [objektorientierten Ansatz](https://en.wikipedia.org/wiki/Object-oriented_programming). Deshalb kann sich das Lernen von Haskell anders anfühlen, als einfach eine weitere Sprache zu lernen.

Zum Glück gibt es zahlreiche Ressourcen, die bereits etwas Programmiererfahrung voraussetzen, zum Beispiel

  - Ein meinungsstarker Einsteigerleitfaden zu Haskell ([2019](https://github.com/theindigamer/not-a-blog/blob/master/opinionated-haskell-guide-2019.md), [2018](https://lexi-lambda.github.io/blog/2018/02/10/an-opinionated-guide-to-haskell-in-2018/))
  - das beliebte und kostenlose Online-Buch [Learn You a Haskell For Great Good!](https://learnyouahaskell.github.io/)
  - den Kurs [Functional Programming in Haskell](https://www.futurelearn.com/courses/functional-programming-haskell) der University of Glasgow
  - die [School of Haskell](https://www.schoolofhaskell.com/) von FP Complete
  - das [Happy Learn Haskell Tutorial](http://www.happylearnhaskelltutorial.com/)
  - die Tutorials von [Haskell for Mac](http://learn.hfm.io/)

Einige neuere Haskell-Bücher sind
  - [Haskell Programming From First Principles](https://haskellbook.com) von Christopher Allen und Julie Moronuki (dieses Buch setzt keine Programmierkenntnisse voraus)
  - [Programming in Haskell](https://www.cambridge.org/us/academic/subjects/computer-science/programming-languages-and-applied-logic/programming-haskell-2nd-edition?format=PB&isbn=9781316626221) von Graham Hutton

Du kannst auch im [Haskell wiki](https://wiki.haskell.org/Learning_Haskell#Online_tutorials) nachschlagen, wo du zahlreiche weitere Ressourcen für den Einstieg findest.
