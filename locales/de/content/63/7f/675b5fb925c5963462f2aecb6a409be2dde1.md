# Anleitung

In dieser Übung hilfst du dabei, ein sicheres Kommunikationssystem zu verwalten und zu überprüfen.
Das System stützt sich stark auf Körperelemente, genauer gesagt auf den Typ `felt252` in Cairo, um sicherzustellen, dass alle arithmetischen Operationen innerhalb eines festgelegten Bereichs bleiben.

## 1. Berechne die Summe zweier Nachrichten

Zwei verschlüsselte Nachrichten, jede durch ein `felt252` dargestellt, müssen addiert werden, um eine kombinierte Nachricht zu erzeugen.
Aufgrund der Verschlüsselung muss jedoch jedes Ergebnis, das den Maximalwert $P - 1$ überschreitet, mithilfe von Modulo $P$ zurückgeführt werden.

Implementiere eine Funktion, die zwei `felt252`-Werte entgegennimmt und ihre Summe zurückgibt, wobei das Ergebnis im gültigen Bereich bleiben muss:

```rust
add_messages(3618502788666131213697322783095070105623107215331596699973092056135007822949, 987654321)
// => 123456789
```

> **Hinweis:** Der Rückgabewert sollte ein `felt252` sein.

## 2. Berechne die Differenz zweier Nachrichten

Manchmal müssen Nachrichten subtrahiert werden, um die ursprünglichen Daten wiederzugewinnen.
Ist das Ergebnis der Subtraktion negativ, passt das System es automatisch an, indem es $P$ addiert, um es wieder in den Wertebereich eines gültigen `felt252`-Werts zu bringen.

Implementiere eine Funktion, die zwei `felt252`-Werte entgegennimmt und ihre Differenz zurückgibt, wobei das Ergebnis im gültigen Bereich bleiben muss:

```rust
subtract_messages(123456789, 987654321)
// => 3618502788666131213697322783095070105623107215331596699973092056135007822949
```

> **Hinweis:** Der Rückgabewert sollte ein `felt252` sein.

## 3. Berechne ein gültiges Produkt zweier Nachrichten

Um die Integrität verschlüsselter Daten zu gewährleisten, multipliziert das kryptografische System oft zwei Nachrichten (`felt252`), damit ihr Produkt in einem gültigen Bereich bleibt.
Das Ergebnis muss modulo $P$ berechnet werden, damit es im gültigen Bereich bleibt.

Implementiere eine Funktion, die zwei `felt252`-Werte entgegennimmt und ihr Produkt zurückgibt, wobei das Ergebnis im gültigen Bereich bleiben muss:

```rust
multiply_messages(382927772233671078546147897004315551461400594453673204174697055647611, 9449570)
// => 123456789
```

> **Hinweis:** Der Rückgabewert sollte ein `felt252` sein.
