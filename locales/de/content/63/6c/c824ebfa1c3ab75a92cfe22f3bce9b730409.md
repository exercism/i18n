# Boolesche Werte

Manche Fragen haben nur zwei Antworten: ja oder nein. In Sather heißt der Typ für so eine Antwort `BOOL`, und die beiden Antworten schreibt man `true` und `false`.

```sather
   ready : BOOL is
      return true;
   end;
```

## Vergleichen

Wenn du zwei Zahlen vergleichst, bekommst du einen `BOOL`.

| Operator | Fragt |
| --- | --- |
| `=` | sind sie gleich? |
| `/=` | sind sie verschieden? |
| `<` | ist die linke kleiner? |
| `<=` | kleiner oder gleich? |
| `>` | ist die linke größer? |
| `>=` | größer oder gleich? |

```sather
   old_enough(age : INT) : BOOL is
      return age >= 13;
   end;
```

Beachte, dass `=` eine Frage stellt. Einen Wert *in* etwas hineinzuschreiben, dafür steht `:=`, das du schon gesehen hast, und die beiden sind nicht dasselbe.

## Kombinieren

Mit drei Operatoren baust du aus kleineren Fragen größere.

`and` ist wahr, wenn **beide** Seiten wahr sind.

```sather
harness_on and rope_checked
```

`or` ist wahr, wenn **eine** der beiden Seiten wahr ist, oder beide.

```sather
mat_below or net_below
```

`~` dreht eine Antwort um: es macht aus wahr falsch und aus falsch wahr.

```sather
~ready       -- true exactly when ready is false
```

`and` und `or` stehen zwischen zwei Antworten; `~` steht vor einer.
