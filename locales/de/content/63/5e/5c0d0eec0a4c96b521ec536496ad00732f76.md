# Anleitung

Du führst einen Feldführer: eine Zuordnung vom Namen eines Tiers zu seinem Lebensraum.

Alle fünf Aufgaben kommen in die Klasse `FIELD_GUIDE`.

## 1. Steht es im Feldführer?

```sather
FIELD_GUIDE::is_listed(guide, "emu")
-- => true
```

## 2. Wo lebt es?

Gib den Lebensraum zurück, der für ein Tier eingetragen ist. Wenn der Feldführer noch nie von ihm gehört hat, gib `"Unknown"` zurück.

```sather
FIELD_GUIDE::habitat_of(guide, "emu")
-- => "grassland"
FIELD_GUIDE::habitat_of(guide, "moa")
-- => "Unknown"
```

## 3. Füge einen Eintrag hinzu

Gib den Feldführer mit einem zusätzlichen Tier darin zurück. Ist ein Tier bereits aufgeführt, wird sein Lebensraum ersetzt.

```sather
FIELD_GUIDE::add_entry(guide, "wombat", "forest")
-- => the guide, now with wombat in it
```

Was dabei zurückkommt, ist der Feldführer, den du von da an verwendest. Es funktioniert, einem völlig leeren Feldführer einen Eintrag hinzuzufügen, und du bekommst einen Feldführer mit einem Tier darin.

## 4. Wie viele Tiere?

```sather
FIELD_GUIDE::entry_count(guide)
-- => 3
```

## 5. Welche Lebensräume?

Gib die Menge der Lebensräume zurück, die im Feldführer vorkommen. Mehrere Tiere können sich einen Lebensraum teilen, und er sollte nur einmal auftauchen.

```sather
FIELD_GUIDE::all_habitats(guide)
-- => a set holding "grassland" and "forest"
```
