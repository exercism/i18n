# Elm-Syntax-Grundlagen 2

## Funktionen exportieren

Wie du Funktionen exportierst, haben wir im ersten Konzept behandelt. Hier ist eine kurze Auffrischung.

Jede Datei in Elm ist ein Modul und muss vor dem restlichen Code eine `module`-Anweisung enthalten.

Modulnamen müssen mit ihrem Dateinamen übereinstimmen. Das Modul `Calculator` muss also in der Datei Calculator.elm liegen und das Modul `Parser.Utils` in der Datei Parser/Utils.elm.

Alles, was in einem Modul definiert wird, ist privat und von außerhalb dieses Moduls nicht zugänglich, es sei denn, es steht in `exposing`.

```elm
-- Calculator.elm
-- Define the Calculator module, and expose the `add` function
module Calculator exposing (add)

six = 3 + 3

add number1 number2 = number1 + number2
```

```elm
-- Calculator.elm
-- Define the Calculator module, and expose everything within: `six` and `add`
module Calculator exposing (..)

six = 3 + 3

add number1 number2 = number1 + number2
```

https://elm-lang.org/docs/syntax#modules

## Funktionen aus anderen Modulen importieren

Auf Funktionen, die in anderen Modulen definiert sind, greifst du über Importe zu.
Beim Importieren eines Moduls werden alle Funktionen darin zugänglich, die dieses Modul freigegeben hat.
Wie du aber darauf zugreifst, hängt davon ab, wie das Modul importiert wird.

Qualifizierte Importe sind der Standard. Auf eine Funktion in einem solchen Modul (zum Beispiel die Funktion `map` im Modul `List`) greifst du zu, indem du den Modulnamen voranstellst (`List.map`).

Offene Importe ermöglichen den direkten Zugriff auf die freigegebenen Funktionen dieses Moduls ohne Präfix. Sie erfolgen mit dem Schlüsselwort `exposing`, als Gegenstück zu dem Schlüsselwort, das du beim Export verwendest. Du kannst alle verfügbaren Funktionen freigeben (mit `..`) oder nur bestimmte (zum Beispiel `map`).

Du kannst auch Typen und ihre Konstruktoren aus anderen Modulen importieren; das kommt in einem späteren Konzept.

Qualifizierte Importe sind zu bevorzugen, da sie die Klarheit fördern und Namenskonflikte vermeiden.

```elm
-- qualified imports
import List                            -- List.map, List.foldl
import List as L                       -- L.map, L.foldl

-- open imports
import List exposing (..)              -- map, foldl, concat, ...
import List exposing ( map, foldl )    -- map, foldl, List.concat
```

https://elm-lang.org/docs/syntax#modules

## Typannotationen

Typannotationen werden mit `name : parameter types -> return type` definiert, wobei auch die Parametertypen durch `->` getrennt werden.

```elm
add : Int -> Int -> Int
add number1 number2 = number1 + number2
```

Mit runden Klammern kannst du Funktionsparameter definieren (die selbst mit derselben Syntax definiert werden, daher die Notwendigkeit der Klammern).

```elm
-- Transform every character in a string
map : (Char -> Char) -> String -> String
map charMapperFunction string =
    -- ...
```

https://elm-lang.org/docs/syntax#type-annotations

## Zahlen

In Elm gibt es zwei Arten von Zahlen, die durch die Typen `Int` und `Float` definiert werden.
`Int` entspricht der Menge der positiven und negativen Ganzzahlen.
`Float` entspricht der Menge der reellen Zahlen, begrenzt durch die Genauigkeit des Computers.
Operationen, die für Zahlen definiert sind, funktionieren meist nur mit dem einen oder dem anderen Typ, aber nicht mit einer Mischung aus beiden.
Es gibt Funktionen, um zwischen den beiden umzuwandeln, etwa `toFloat`, das `Int` in `Float` umwandelt, und `round`, `floor`, `ceiling` oder `truncate`, die einen `Float` mit unterschiedlicher Semantik in einen `Int` umwandeln.

https://package.elm-lang.org/packages/elm/core/latest/Basics#Int

## String-Operationen

Um Wörter und Sätze im Code zu beschreiben, hat Elm einen nativen Typ `String`.
String-Literale schreibst du zwischen doppelte Anführungszeichen, zum Beispiel `"Hello World!"`.
Ein Verkettungsoperator `++` für Strings und ein Gleichheitsoperator `==` sind standardmäßig verfügbar.

```elm
hello : String -> String
hello subject = "Hello " ++ subject

hello "World!" --> "Hello World!"
```

Die meisten anderen String-Funktionen stecken im Modul `String`, das importiert werden muss.

https://package.elm-lang.org/packages/elm/core/latest/String
