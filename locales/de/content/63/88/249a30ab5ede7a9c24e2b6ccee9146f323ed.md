# Einführung

**Union-Typ-Deklarationen** sind ab `PHP 8.0.0` verfügbar und akzeptieren Werte mehrerer verschiedener Typen statt eines einzelnen Typs. Bei Union-Typ-Deklarationen werden die Typen durch das Pipe-Zeichen (`|`) getrennt.

```php
function add(int|float $a, int|float $b): int|float
{
    return $a + $b;
}
```

Im strikten Modus wirft PHP einen `TypeError`, wenn die übergebenen Parameter weder ein `float` noch ein `int` sind. Im nicht-strikten Modus wird ein TypeError geworfen, wenn die übergebenen Parameter nicht in ein `float` oder ein `int` umgewandelt werden können.

Genauso wirft PHP zur Laufzeit einen `TypeError`, wenn die Funktion keinen der deklarierten Typen zurückgibt.
