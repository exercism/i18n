# Anleitung

In dieser Übung übersetzt du einige Regeln aus dem klassischen Spiel Pac-Man in Haskell-Funktionen.

Du hast vier Regeln zu übersetzen, die alle mit den Spielzuständen zusammenhängen.

> Mach dir keine Gedanken darüber, wie die Argumente zustande kommen. Konzentriere dich einfach darauf, die Argumente zu kombinieren, um das beabsichtigte Ergebnis zurückzugeben.

## 1. Definiere, ob Pac-Man einen Geist frisst

Definiere die Funktion `eatsGhost`, die zwei Argumente entgegennimmt (_ob bei Pac-Man eine Kraftpille aktiv ist_ und _ob Pac-Man einen Geist berührt_) und einen `Bool`-Wert zurückgibt, wenn Pac-Man den Geist fressen kann.
Die Funktion sollte nur dann `True` zurückgeben, wenn bei Pac-Man eine Kraftpille aktiv ist und er einen Geist berührt.

```haskell
eatsGhost False True
-- -> False
```

## 2. Definiere, ob Pac-Man punktet

Definiere die Funktion `scores`, die zwei Argumente entgegennimmt (_ob Pac-Man eine Kraftpille berührt_ und _ob Pac-Man einen Punkt berührt_) und einen `Bool`-Wert zurückgibt, wenn Pac-Man punktet.
Die Funktion sollte `True` zurückgeben, wenn Pac-Man eine Kraftpille oder einen Punkt berührt.

```haskell
scores True True
-- -> True
```

## 3. Definiere, ob Pac-Man verliert

Definiere die Funktion `loses`, die zwei Argumente entgegennimmt (_ob bei Pac-Man eine Kraftpille aktiv ist_ und _ob Pac-Man einen Geist berührt_) und einen `Bool`-Wert zurückgibt, wenn Pac-Man verliert.
Die Funktion sollte `True` zurückgeben, wenn Pac-Man einen Geist berührt und keine Kraftpille aktiv hat.

```haskell
loses False True
-- -> True
```

## 4. Definiere, ob Pac-Man gewinnt

Definiere die Funktion `wins`, die drei Argumente entgegennimmt (_ob Pac-Man alle Punkte gefressen hat_, _ob bei Pac-Man eine Kraftpille aktiv ist_ und _ob Pac-Man einen Geist berührt_) und einen `Bool`-Wert zurückgibt, wenn Pac-Man gewinnt.
Die Funktion sollte `True` zurückgeben, wenn Pac-Man alle Punkte gefressen hat _und_ basierend auf den in Teil 3 definierten Argumenten nicht verloren hat.

```haskell
wins False True False
-- -> False
```
