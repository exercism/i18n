# Über

Boolesche Werte in Kotlin werden durch den Typ `Boolean` dargestellt. Seine Werte sind entweder `true` oder `false`.

Kotlin unterstützt drei eingebaute [boolesche Operatoren][reference]: `!` (Negation, auch NOT genannt), `&&` (faule Konjunktion, auch AND genannt) und `||` (faule Disjunktion, auch OR genannt). Die Operatoren `&&` und `||` verwenden die _Kurzschlussauswertung_. Das heißt, die rechte Seite des Operators wird nur ausgewertet, wenn es nötig ist.

```kotlin
true || false // => true
true && false // => false
```

Die drei booleschen Operatoren haben jeweils eine andere [_Operatorpriorität_][precedence]. Deshalb werden sie in dieser Reihenfolge ausgewertet: zuerst `!`, dann `&&` und schließlich `||`. Wenn du diese Regeln „umgehen“ möchtest, kannst du einen booleschen Ausdruck in runde Klammern (`()`) setzen, denn die Klammern haben eine noch höhere Operatorpriorität.

```kotlin
!true && false   // => false
!(true && false) // => true
```

[reference]: https://kotlinlang.org/docs/reference/basic-types.html#booleans
[precedence]: https://kotlinlang.org/docs/reference/grammar.html#expressions
