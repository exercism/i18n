# Einführung

In Ruby sind **Arrays** geordnete, mit ganzen Zahlen indizierte Sammlungen beliebiger Objekte.
Die Indizierung von Arrays beginnt bei `0`.
Ein negativer Index bezieht sich auf das Ende des Arrays, das heißt, ein Index von `-1` bezeichnet das letzte Element des Arrays, `-2` das vorletzte Element und so weiter.
Arrays in Ruby binden das [Enumerable-Modul][enumerable-module] ein, das mehrere Methoden zum Durchlaufen und Suchen sowie die Möglichkeit zum Sortieren hinzufügt.

## Array erstellen

- Ein Array in Ruby kann Objekte unterschiedlicher Typen enthalten.

```ruby
array = [1, "two", 3.0] #=> [1, "two", 3.0]
```

## Elemente zuweisen

Auf Elemente kannst du über Indizes zugreifen und sie ändern.
Auf Teil-Arrays kannst du zugreifen, indem du einen Startindex und eine Größe angibst.

```ruby
a = ["", "", "", "", ""]

a[4] = "hello"  #=> [nil, nil, nil, nil, "hello"]
a[0, 3] = [ 'a', 'b', 'c' ] #=> ["a", "b", "c", nil, "hello"]
```

- Negative Indizes zählen vom Ende des Arrays rückwärts.

```ruby
a = ['a', 'b']

a[-1] = "Z"
a #=> ["a", "Z"]
```

## Auf Elemente zugreifen

- Die Elemente eines Arrays kannst du mit der Methode #[] abrufen.
- Sie gibt das Element am Index zurück oder ein Teil-Array, das beim Startindex beginnt und sich über die angegebene Länge erstreckt.

```ruby
a = [ "a", "b", "c", "d", "e" ]

a[2]    #=> "c"
a[6]    #=> nil
a[1, 2] #=> [ "b", "c" ]
```

- Negative Indizes zählen vom Ende des Arrays rückwärts (-1 ist das letzte Element)

```ruby
a = [ "a", "b", "c", "d", "e" ]

a[-2]    #=> "d"
a[-3, 3] #=> [ "c", "d", "e" ]
```

## Informationen über ein Array erhalten

Arrays kennen ihre eigene Länge jederzeit.
Um die Anzahl der Elemente eines Arrays abzufragen, kannst du length, count oder size verwenden.

```ruby
browsers = ['Chrome', 'Firefox', 'Safari', 'Opera', 'IE']
browsers.length #=> 5
browsers.count  #=> 5
browsers.size   #=> 5
```

## Elemente zu einem Array hinzufügen

Du kannst Elemente mit `push` oder `<<` am Ende eines Arrays hinzufügen:

```ruby
arr = [1, 2, 3, 4]
arr.push(5) #=> [1, 2, 3, 4, 5]
arr << 6    #=> [1, 2, 3, 4, 5, 6]
```

## Elemente aus einem Array entfernen

Die Methode pop entfernt das letzte Element eines Arrays und gibt es zurück:

```ruby
arr = [1, 2, 3, 4, 5, 6]
arr.pop #=> 6
arr     #=> [1, 2, 3, 4, 5]
```
