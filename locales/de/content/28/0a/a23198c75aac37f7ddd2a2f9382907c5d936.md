# Debuggen

Anders als in vielen Sprachen hat WebAssembly-Code nicht automatisch Zugriff auf globale Ressourcen wie die Konsole. Solche Funktionalität muss stattdessen über Imports bereitgestellt werden.

Um eine Funktionalität wie `console.log` und ein paar andere Annehmlichkeiten bereitzustellen, stellt der WebAssembly-Track von Exercism eine Standardbibliothek mit Funktionen für alle Übungen bereit.

Diese Funktionen müssen oben in deinem WebAssembly-Modul importiert werden und können dann aus deinem WebAssembly-Code heraus aufgerufen werden.

Die Funktionen `log_mem_*` erwarten, auf den linearen Speicher deines WebAssembly-Moduls zugreifen zu können. Standardmäßig ist dieser privat, also musst du deinen linearen Speicher unter dem Exportnamen `mem` exportieren, damit er zugänglich ist. Das machst du so:

```wasm
(memory (export "mem") 1)
```

# Lokale und globale Variablen loggen

Wir stellen Logging-Funktionen für jeden der primitiven WebAssembly-Typen bereit. Das ist nützlich, um globale und lokale Variablen zu loggen.

## log_i32_s - Eine vorzeichenbehaftete 32-Bit-Ganzzahl an der Konsole loggen

```wasm
(module
  (import "console" "log_i32_s" (func $log_i32_s (param i32)))
  (func $main
    ;; logs -1
    (call $log_i32_s (i32.const -1))
  )
)
```

# Aus dem linearen Speicher loggen

Der lineare Speicher von WebAssembly ist ein byte-addressierbares Array von Werten. Er dient als das Äquivalent zum virtuellen Speicher für WebAssembly-Programme.

Wir stellen Logging-Funktionen bereit, um einen Bereich von Adressen im linearen Speicher als statische Arrays bestimmter Typen zu interpretieren. Das funktioniert ähnlich wie die TypedArrays von JavaScript. Die Längenparameter werden nicht in Bytes gemessen, sondern in der Anzahl aufeinanderfolgender Elemente des Typs, der zur Funktion gehört.

**Damit diese Funktionen funktionieren, muss dein WebAssembly-Modul seinen linearen Speicher deklarieren und mit dem benannten Export „mem" exportieren.**

```wasm
(memory (export "mem") 1)
```

## log_mem_as_utf8 - Eine Folge von UTF8-Zeichen an der Konsole loggen

```wasm
(module
  (import "console" "log_mem_as_utf8" (func $log_mem_as_utf8 (param $byteOffset i32) (param $length i32)))
  (memory (export "mem") 1)
  (data (i32.const 64) "Goodbye, Mars!")
  (func $main
    ;; Logs "Goodbye, Mars!" to console
    (call $log_mem_as_utf8 (i32.const 64) (i32.const 14))
  )
)
```

(module
