# Einführung

Initialisierer sind spezielle Methoden, mit denen du einen Wert des Enums erzeugst. Ihre Definition sieht einer Methode sehr ähnlich, nur gibt es kein `func`-Schlüsselwort und keinen Rückgabetyp, der Name muss `init` sein, und der Initialisierer _muss_ `self` einen Wert des Enums zuweisen. Initialisierer rufst du entweder über die Punktnotation auf oder indem du die Parameter des Initialisierers an den Namen des Enums übergibst.

```swift
enum Coin {
  case heads
  case tails

  init(_ i: Int) {
    if i.isMultiple(of: 2) {
      self = .heads
    } else {
      self = .tails
    }
  }

  func flip() -> Self {
    switch self {
    case .heads: return .tails
    case .tails: return .heads
    }
  }
}

let tails = Coin.init(13)
// .tails
let heads = Coin(0)
// .heads
let anotherTails = heads.flip()
// .tails
```
