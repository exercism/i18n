# Anweisungen

Bei dieser Übung spielst du ein Rollenspiel namens _Zauberer und Krieger_.
Um dieses Spiel zu spielen, brauchst du eine universelle Methode zum Würfeln, mit der du verschiedene Ergebnisse ermittelst.
Dabei handelt es sich um den traditionellen 18-seitigen Würfel mit den Zahlen von 1 bis 18.
Außerdem müssen die Spieler eine zufällige Zauberstärke erzeugen.

## 1. Ermögliche einem Spieler von _Zauberer und Krieger_, einen Würfel zu werfen

Implementiere eine Methode `RollDie()` in der Klasse `Player`.

```csharp
var player = new Player();
player.RollDie();
// => >= 1 <= 18
```

## 2. Spieler brauchen ihre Stärke. Schaffe eine Möglichkeit, die Zauberstärke zu erzeugen

Implementiere eine Methode `GenerateSpellStrength()` in der Spielerklasse.
Die Zauberstärke liegt zwischen 0.0 und 100.0, wobei 100.0 nicht enthalten ist.

Beachte, dass die Zauberstärke eine Gleitkommazahl sein muss (keine Ganzzahl), um die Wahrscheinlichkeit eines Gleichstands zu verringern, wenn die Stärken zweier Gegner verglichen werden.

```csharp
var player = new Player();
player.GenerateSpellStrength();
// => >= 0.0 < 100.0
```
