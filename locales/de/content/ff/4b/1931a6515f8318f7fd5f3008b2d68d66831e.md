# Anleitung

Als Schachfan möchtest du deine eigene Version des Spiels schreiben.
Ja, es gibt online vielleicht schon jede Menge Schach-Implementierungen, aber deine wird einzigartig sein!

Du beginnst damit, ein einfaches Bewegungssystem für die Figuren zu implementieren.

Das Schachspiel wird auf einem Brett gespielt, das 8 Felder breit und 8 Felder lang ist.
Die Felder werden durch einen Buchstaben und eine Zahl bezeichnet.

## 1. Definiere den Bereich für Reihen und Linien

Das Spiel muss die Reihen des Bretts speichern.
Die Reihen sind die Zeilen des Bretts und sind von 1 bis 8 nummeriert.

Das Spiel muss außerdem die Linien des Bretts speichern.
Die Linien sind die Spalten des Bretts und werden durch die Buchstaben A bis H bezeichnet.

Definiere die Konstanten `Chess::RANKS` und `Chess::FILES`, die den Bereich der Reihen bzw. der Linien speichern.

```ruby
Chess::RANKS
# => 1..8

Chess::FILES
# => 'A'..'H'
```

## 2. Prüfe, ob ein Feld gültig ist

Das Spiel muss prüfen, ob ein Feld gültig ist.
Ein Feld ist gültig, wenn die Reihe und die Linie innerhalb der Bereiche der Reihen und Linien liegen.

Definiere die Methode `Chess.valid_square?`, die die Argumente `rank`, das eine Ganzzahl für die Reihe enthält, und `file`, das ein Zeichen für die Linie enthält, entgegennimmt.
Die Methode soll `true` zurückgeben, wenn Reihe und Linie innerhalb der Bereiche der Reihen und Linien liegen, und andernfalls `false`.

```ruby
Chess.valid_square?(1, 'A')
# => true
```

## 3. Ermittle den Spitznamen des Spielers

Das Spiel muss den Spitznamen des Spielers ermitteln.
Der Spitzname besteht aus den ersten 2 Zeichen des Vornamens und den letzten 2 Zeichen des Nachnamens des Spielers.
Der Spitzname soll großgeschrieben werden.

Definiere die Methode `Chess.nickname`, die die Argumente `first_name`, das einen String mit dem Vornamen des Spielers enthält, und `last_name`, das einen String mit dem Nachnamen des Spielers enthält, entgegennimmt.
Die Methode soll den Spitznamen des Spielers als großgeschriebenen String zurückgeben.

```ruby
Chess.nickname("John", "Doe")
# => "JOOE"
```

## 4. Erstelle eine Zugnachricht

Das Spiel muss eine Nachricht für einen Zug erstellen, die angibt, welcher Spieler auf welches Feld gezogen ist.
Die Nachricht soll den Spitznamen des Spielers und das Feld, auf das er gezogen ist, verwenden.
Außerdem muss das Spiel feststellen, ob der Zug gültig ist, indem es prüft, ob Linie und Reihe des Feldes innerhalb der Bereiche der Linien und Reihen liegen.

Wenn der Zug gültig ist, soll die Nachricht lauten: `"{nickname} moved to {square}"`.
Wenn der Zug ungültig ist, soll die Nachricht lauten: `"{nickname} attempted to move to {square}, but that is not a valid square"`.

Definiere die Methode `Chess.move_message`, die die Argumente `first_name`, das einen String mit dem Vornamen des Spielers enthält, `last_name`, das einen String mit dem Nachnamen des Spielers enthält, und `square`, das einen String mit dem Feld enthält, auf das der Spieler gezogen ist, entgegennimmt.
Die Methode soll die Nachricht für den Zug als String zurückgeben.

```ruby
Chess.move_message("John", "Doe", "A1")
# => "JOOE moved to A1"
```
