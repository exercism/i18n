# Parameter ohne vorangestellten Unterstrich bevorzugen

Anders als in anderen Sprachen bedeutet `_identifier` nicht, dass eine Funktion, ein Parameter oder eine Variable **private** ist.

Stattdessen verhindert in JavaScript ein Unterstrich vor einem Parameter, dass die meisten IDEs diesen Parameter hervorheben, wenn er nicht verwendet wird. Entferne den Unterstrich (`_`) am Anfang von `%{parameter.name}`, um das zu beheben.
