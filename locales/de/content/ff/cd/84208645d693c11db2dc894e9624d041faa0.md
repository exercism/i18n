# Über

Eine `Map` wird verwendet, um Paare aus **Schlüssel** und **Wert** zu speichern. `Maps` werden genau wie ein Array initialisiert, verwenden aber den Map-Literal-Operator `=>`. Ihre Schlüssel-Wert-Typen können auch explizit angegeben werden, oder die Typen können abgeleitet werden. Schlüssel müssen eindeutig sein, sonst wird ein Fehler geworfen.

```haxe
var map1:Map<Int, String> = [1 => "one", 2 => "two", 3 => "three"];

var map2 = ["one" => 1, "two" => 2, "three" => 3];

var map3 = [1 => "cat", 1 => "dog"]; // Error: Duplicate Key

var map4 = ["h" => "Hello", "b" => "Bye"];
trace(map4["h"]); // Hello
```

Du kannst eine `Map` mit einer `for`-Schleife durchlaufen. Du kannst entweder über die Werte oder die Schlüssel iterieren:

```haxe
for (value in map) {
  // ...
}

for (key in map.keys()) {
  // ...
}
```

Unter der Haube ist eine `Map` ein abstrakter Typ. Zur Kompilierzeit wird sie abhängig vom Schlüsseltyp in einen von mehreren spezialisierten Typen umgewandelt:

- `String`: `haxe.ds.StringMap`
- `Int`: `haxe.ds.IntMap`
- `EnumValue`: `haxe.ds.EnumValueMap`
- `{}`: `haxe.ds.ObjectMap`

Der Typ `Map` existiert zur Laufzeit nicht und wurde durch eines der oben genannten Objekte ersetzt.
