# Lernen

* [The Rust Programming Language](https://doc.rust-lang.org/book/) ist eine großartige Ressource, um mit Rust anzufangen und tiefer in bestimmte Funktionen von Rust einzutauchen.
* [Rust by Example](https://doc.rust-lang.org/stable/rust-by-example/) zeigt dir Beispiele für die gängigsten Dinge, die du in Rust schreiben wirst.
* [Into_rust()](http://intorust.com/) „Screencasts zum Rust-Lernen.“
* [Rustlings](https://github.com/carols10cents/rustlings) „Kleine Übungen, mit denen du dich an das Lesen und Schreiben von Rust-Code gewöhnst.“
* Das [Rust User Forum](http://users.rust-lang.org) beantwortet Fragen auf allen Niveaus
