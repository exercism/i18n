# Einführung

## switch-Anweisungen

Wie bei einer _if/else_-Anweisung kannst du mit einer `switch`-Anweisung den Ablauf des Programms ändern, indem du Code abhängig von Bedingungen ausführst.
Der Unterschied ist, dass eine `switch`-Anweisung den Wert eines primitiven Ausdrucks oder eines Strings nur mit vordefinierten konstanten Werten vergleichen kann.

Bei einer switch-Anweisung sind einige Schlüsselwörter nützlich.

- `switch`: Mit diesem Schlüsselwort legst du die Struktur der switch-Anweisung fest.
  Danach folgt der Ausdruck oder die Variable, die das Ergebnis bestimmt.
- `case`: Mit diesem Schlüsselwort gibst du die verschiedenen Möglichkeiten für das Ergebnis an.
- `break`: Das Schlüsselwort `break` ist sehr nützlich, um die Ausführung der switch-Anweisung am Ende des gewünschten Ablaufs zu beenden.
  Wenn du es vergisst, läuft das Programm weiter und das kann zu unerwarteten Ergebnissen führen.
- `default`: Wie der Name schon sagt, verwendest du es als Standardergebnis, wenn kein anderer `case` zum Ergebnis deines Ausdrucks passt.

Im einfachsten Fall prüfen sie einen primitiven Ausdruck oder einen String und treffen anhand seines Werts eine Entscheidung.
Zum Beispiel:

```java
String direction = getDirection();
switch (direction) {
    case "left":
        goLeft();
        break;
    case "right":
        goRight();
        break;
    default:
        // otherwise
        markTime();
        break;
}
```
