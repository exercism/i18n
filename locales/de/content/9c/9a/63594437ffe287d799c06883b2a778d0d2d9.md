# Anweisungen

Wellingtons Wetterstation ersetzt ihr manuelles System zur Temperaturaufzeichnung durch ein neues digitales.
Im alten System wurden die Berechnungen manuell durchgeführt.
Im neuen System werden sie automatisiert.
Zu den Berechnungen gehören die Umrechnung der Temperatur von Celsius in Fahrenheit und die Ermittlung der Durchschnittstemperatur.
Das neue System hat Sensoren, um Temperaturdaten in Celsius aufzuzeichnen.

Wellingtons Wetterstation möchte, dass du ihr bei dem neuen System hilfst.

## 1. Die Temperatur von Celsius in Kelvin umrechnen

Die Wetterstation hat einen Bereich auf ihrer Website, der für Forscher bestimmt ist.
Die Forscher interessieren sich für die Temperatur in Kelvin.

Kelvin ist eine Einheit zur Messung der Temperatur.
Sie liegt auf derselben Skala wie Celsius, hat aber einen anderen Ausgangspunkt.
Ihr Ausgangspunkt ist der absolute Nullpunkt, also 0K (Kelvin) oder -273.15°C (Celsius).

Hier ist eine Tabelle mit der Umrechnung zwischen Celsius und Kelvin:

| Celsius(°C) | Kelvin(K) |
| ----------- | --------- |
| -273.15     | 0         |
| -100        | 173.15    |
| 0           | 273.15    |
| 100         | 373.15    |

Die Wetterstation möchte, dass du eine Methode implementierst, die eine Temperatur von Celsius in Kelvin umrechnet.

Implementiere die Methode `Temperature#to_kelvin`, die ein Argument `celsius` entgegennimmt und die Temperatur in Kelvin zurückgibt, indem sie 273.15 zum übergebenen Wert `celsius` addiert.

```crystal
Temperature.new.to_kelvin(0)
# => 273.15
```

## 2. Die Temperatur runden

Der Temperatursensor der Wetterstation ist exakt.
Er kann die Temperatur auf 0.0001°C genau messen.
Die Wetterstation möchte die Temperatur nur auf 1 Nachkommastelle gerundet anzeigen, da die meisten Nutzer an dieser Genauigkeit nicht interessiert sind.

Die Wetterstation möchte, dass du eine Methode implementierst, die die Temperatur auf 1 Nachkommastelle rundet.

Implementiere die Methode `Temperature#round`, die ein Argument `celsius` entgegennimmt und die Temperatur auf 1 Nachkommastelle gerundet zurückgibt.

```crystal
Temperature.new.round(10.1234)
# => 10.1

Temperature.new.round(10.1567)
# => 10.2
```

## 3. Die Temperatur von Celsius in Fahrenheit umrechnen

Die Wetterstation hat einen Bereich auf ihrer Website, der für Touristen bestimmt ist.
Die Touristen interessieren sich für die Temperatur in Fahrenheit.

Fahrenheit ist eine Einheit zur Temperaturmessung.
Sie verwendet eine andere Skala als Celsius.
0°C entspricht 32°F, und 1 Grad Celsius entspricht 1.8 Grad Fahrenheit.

Hier ist eine Tabelle mit der Umrechnung zwischen Celsius und Fahrenheit:

| Celsius(°C) | Fahrenheit(°F) |
| ----------- | -------------- |
| -273.15     | -459.8         |
| -100        | -148           |
| 0           | 32             |
| 100         | 212            |

Die Wetterstation möchte, dass du eine Methode implementierst, die Temperaturen von Celsius in Fahrenheit umrechnet.

Implementiere die Methode `Temperature#to_fahrenheit`, die ein Argument `celsius` entgegennimmt und die Temperatur in Fahrenheit als Ganzzahl zurückgibt.

```crystal
Temperature.new.to_fahrenheit(10)
# => 50
```

## 4. Die Anzahl der fehlenden Sensoren ermitteln

Bei der Installation der Temperatursensoren stellten die Wartungsarbeiter fest, dass einige Sensoren fehlten.
Jede Temperaturmesseinheit benötigt vier Temperatursensoren.
Das Wartungsteam zählte, wie viele Sensoren es hatte, musste aber wissen, wie viele fehlten.
Es hätte gern Hilfe dabei, zu zählen, wie viele Sensoren es kaufen muss, um eine weitere vollständige Temperaturmesseinheit zu bauen.

Implementiere die Methode `Temperature#number_missing_sensors`, die ein Argument `number_of_sensors` entgegennimmt und die Anzahl der fehlenden Sensoren zurückgibt.

```crystal
Temperature.new.number_missing_sensors(10)
# => 2
```
