# Code-Einbindung

`circus-acts` hat mit `<` gesagt, dass eine Klasse *kann*, was eine abstrakte Klasse beschreibt. Über das Wie sagte es nichts.

`include` ist die andere Hälfte: Es nimmt den tatsächlichen Code aus einer anderen Klasse und legt eine Kopie davon in diese hier.

```sather
class WARM_UP is

   count : INT is return 8; end;

   describe : STR is return count + " counts"; end;

end; -- class WARM_UP

class JAZZ_ROUTINE is

   include WARM_UP;

   -- count and describe are now here too, as though written out.

end; -- class JAZZ_ROUTINE
```

`JAZZ_ROUTINE::count` ist 8, ohne dass `JAZZ_ROUTINE` es erwähnt.

## Das sind zwei getrennte Entscheidungen

Die meisten Sprachen verbinden beides: Ein `extends` vererbt den Code und macht die Unterklasse überall verwendbar, wo die Oberklasse steht. Sather hält beides getrennt.

| Geschrieben | Sagt aus |
| --- | --- |
| `class A < $B` | ein `A` kann überall verwendet werden, wo ein `$B` gewünscht ist |
| `class A is include B` | `A` beginnt mit einer Kopie des Codes von `B` |

Entweder das eine ohne das andere, oder beides. Eine Klasse einzubinden macht sie **nicht** zu einem Untertyp: Nach `include WARM_UP` kann eine `JAZZ_ROUTINE` immer noch nicht dort verwendet werden, wo eine `WARM_UP` gewünscht ist, und nichts tut so, als wäre es anders.

## Umbenennen

Eine eingebundene Routine kann unter einem anderen Namen hereingeholt werden:

```sather
   include WARM_UP count -> warm_up_count;
```

Mehrere werden durch Kommas getrennt:

```sather
   include WARM_UP count -> warm_up_count, describe -> warm_up_describe;
```

## Eine weglassen

Ein Umbenennen auf *nichts* lässt sie weg, und so ersetzt du sie:

```sather
class TAP_ROUTINE is

   include WARM_UP describe -> ;

   describe : STR is return "Tap: " + count + " counts"; end;

end; -- class TAP_ROUTINE
```

`count` kommt wie gewohnt mit; `describe` nicht, also ist es kein Konflikt, hier eine zu schreiben. Ohne das `describe -> ;` würde der Compiler ablehnen: zwei Routinen mit demselben Namen und denselben Argumenten in einer Klasse sind ein Fehler, und Sather rät nicht, welche du gemeint hast.

Das ist der Unterschied zum Überschreiben in den meisten Sprachen: Der Ersatz wird angekündigt statt stillschweigend angenommen.
