# Einführung

Mit Schleifen wiederholst du Blöcke von Code. In Rust gibt es drei Arten von Schleifen: die `for`-Schleife, die `while`-Schleife und die `loop`-Schleife.

Die `for`-Schleife läuft über die Elemente eines Iterators oder einer Sammlung, genauer gesagt über Werte jedes Typs, der das `IntoIterator`-Trait implementiert. Die `while`-Schleife wiederholt einen Block von Code, solange eine Bedingung erfüllt ist. Die `loop`-Schleife wiederholt Code endlos, bis du explizit ein `break` aufrufst.
