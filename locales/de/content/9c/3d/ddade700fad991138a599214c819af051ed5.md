# Einführung

In Go hat jede Variable einen Wert.
Wenn du eine Variable deklarierst, ohne ihr einen Wert zuzuweisen, wird sie auf den Nullwert für ihren Typ gesetzt.

Basistypen wie `bool`, numerische Typen und `string` haben jeweils einen festen Nullwert:

| Typ                    | Nullwert |
| ---------------------- | -------- |
| bool                   | `false`  |
| int, int8, int64, usw. | `0`      |
| float32, float64       | `0`      |
| complex64, complex128  | `0+0i`   |
| string                 | `""`     |

Zeiger, Funktionen, Interfaces, Slices, Channels und Maps haben jeweils den Nullwert `nil`.

Arrays und Structs sind niemals `nil`, weil sie die Daten direkt enthalten und nicht eine Referenz darauf.
Jedes Element eines Arrays und jedes Feld eines Structs wird auf den Nullwert seines eigenen Typs initialisiert.
Zum Beispiel erzeugt `var a [3]int` das Array `[0, 0, 0]`.

## Nullwerte deklarieren

Verwende `var` für eine Deklaration:

```go
var myBool bool   // false
var mySlice []int // nil
```

Verwende für Structs ein zusammengesetztes Literal `T{}`:

```go
type Person struct {
    Name string
    Age  int
}

myPerson := Person{} // Person{Name: "", Age: 0}
```
