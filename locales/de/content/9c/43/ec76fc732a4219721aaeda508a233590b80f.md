# Einführung

Arrays sind Factors wichtigster Sequenztyp mit fester Länge, geschrieben
`{ … }`: Die Elemente kannst du ändern, die Länge nicht. Die Vokabulare
`arrays` und `sequences` geben dir zusammen kleine Konstruktoren, die
Werte vom Stack nehmen, dazu alltägliche Operationen zum Zusammenfügen,
Umkehren und Nachschlagen von Elementen.

```factor
USING: arrays sequences ;

42 1array .                ! => { 42 }
"a" "b" "c" 3array .       ! => { "a" "b" "c" }
{ { 1 2 } { 3 4 } } concat .   ! => { 1 2 3 4 }
{ 1 2 3 } reverse .            ! => { 3 2 1 }
```
