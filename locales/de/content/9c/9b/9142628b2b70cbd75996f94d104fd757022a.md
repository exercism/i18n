# Hinweise

## 1. Die Bits zurückverschieben
- Crystal hat einen [Operator][shifts] zum Linksverschieben von Bits.

## 2. Eine Bitmaske anwenden
- Crystal hat einen [bitweisen AND][binary]-Operator.

## 3. Einige Bits setzen
- Crystal hat einen [bitweisen OR][binary]-Operator.

## 4. XOR umkehren
- Ein XOR kannst du umkehren, indem du das XOR erneut auf denselben Wert anwendest.
- Crystal hat Operatoren für [bitweises NICHT][not] und bitweises [XOR][xor].

[binary]: https://crystal-lang.org/reference/syntax_and_semantics/operators.html#binary

[xor]: https://crystal-lang.org/reference/syntax_and_semantics/operators.html#binary
