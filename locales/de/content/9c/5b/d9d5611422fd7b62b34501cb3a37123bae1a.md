# Einführung

Eine Typdefinition erstellt einen neuen benannten Typ, der sich von jedem anderen Typ unterscheidet, selbst von einem, der denselben zugrunde liegenden Typ hat.

## Typen definieren

Eine Typdefinition beginnt mit dem Schlüsselwort `type`, gefolgt vom Namen des neuen Typs und seinem zugrunde liegenden Typ:

```go
type File []bool
```

`File` bezeichnet hier eine einzelne senkrechte Spalte auf einem Schachbrett, die man üblicherweise mit A bis H bezeichnet.
Jedes Feld in dieser Spalte wird durch einen booleschen Wert dargestellt, der angibt, ob es besetzt ist oder nicht.
Da `File` jetzt definiert ist, können wir es in anderen Definitionen verwenden:

```go
type Chessboard map[string]File

board := Chessboard{
    "A": File{true, false, true},
    "B": File{false, true, false},
}
```

`Chessboard` bildet Spalten-Bezeichner auf `File`-Werte ab.
Jedes `File` ist ein Slice von booleschen Werten, die die Felder in einer Schachspalte darstellen.
Ohne diese Typdefinitionen wäre `board` ein `map[string][]bool`, wodurch es schwerer zu verstehen wäre, was wir darstellen.
