# Einführung

## Arrays

In Java sind Arrays eine Möglichkeit, mehrere Werte desselben Typs in einer einzigen Struktur zu speichern.
Anders als andere Datenstrukturen haben Arrays nach dem Erstellen eine feste Größe.
Elemente können einem Array über einen Index zugewiesen oder daraus abgerufen werden.
Java-Arrays verwenden nullbasierte Indizierung: Der Index des ersten Elements ist 0, der Index des zweiten Elements ist 1, usw.

Hier ist die Standardsyntax zum Initialisieren eines Arrays:

```java
type[] variableName = new type[size];
```

Der `type` ist der Typ der Elemente im Array. Er kann ein primitiver Typ (z. B. `int`) oder eine Klasse (z. B. `String`) sein.

Die `size` ist die Anzahl der Elemente, die dieses Array aufnehmen kann (sie lässt sich später nicht mehr ändern).
Nach dem Erstellen des Arrays werden die Elemente mit ihren Standardwerten initialisiert (typischerweise `0`, `false` oder `null`).

```java
// Declare array with explicit size (size is 2)
int[] twoInts = new int[2];
```

Arrays können auch mit einer Kurzschreibweise definiert werden, mit der du das Array sowohl erstellst als auch seine Werte festlegst:

```java
// Two equivalent ways to declare and initialize an array (size is 3)
int[] threeIntsV1 = new int[] { 4, 9, 7 };
int[] threeIntsV2 = { 4, 9, 7 };
```

Da der Compiler nun erkennen kann, wie viele Elemente das Array haben wird, kann die Länge weggelassen werden.

Auf Array-Elemente kann mit einer Indizierung in eckigen Klammern zugegriffen und sie können damit zugewiesen werden:

```java
// Assign second element by index
twoInts[1] = 8;

// Retrieve the second element by index and assign to the int element
int secondElement = twoInts[1];
```

Der Zugriff auf einen Index außerhalb der gültigen Indizes des Arrays führt zu einer `IndexOutOfBoundsException`.

Arrays können bearbeitet werden, indem du entweder die Methoden oder Eigenschaften einer Array-Instanz aufrufst oder die statischen Methoden verwendest, die in der Klasse `Arrays` definiert sind (typischerweise nur in generischem Code verwendet).
Die Eigenschaft `length` enthält die Länge eines Arrays.
Du kannst sie so abrufen:

```java
int arrayLength = someArray.length;
```

Java bietet außerdem eine hilfreiche Hilfsklasse [`java.util.Arrays`](https://docs.oracle.com/en/java/javase/11/docs/api/java.base/java/util/Arrays.html), die viele nützliche Array-bezogene Methoden enthält (z. B. `Arrays.equals`).

Java unterstützt außerdem [mehrdimensionale Arrays](https://www.programiz.com/java-programming/multidimensional-array) wie `int[][] arr = new int[3][4];`, die sehr nützlich sein können.

Die Tatsache, dass ein Array auch eine _Sammlung_ ist, bedeutet, dass du neben dem Zugriff auf Werte über den Index auch über _alle_ seine Werte mit einer `for-each`-Schleife iterieren kannst:

```java
char[] vowels = { 'a', 'e', 'i', 'o', 'u' };

for(char vowel: vowels) {
    // Output the vowel
    System.out.print(vowel);
}

// => aeiou
```

Wenn du mehr Kontrolle darüber haben möchtest, über welche Werte du iterierst, kannst du eine `for`-Schleife verwenden:

```java
char[] vowels = { 'a', 'e', 'i', 'o', 'u' };

for (int i = 0; i < 3; i++) {
    // Output the vowel
    System.out.print(vowels[i]);
}

// => aei
```
