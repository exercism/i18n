# Einführung

In Go ist `map` ein eingebauter Datentyp, der Schlüssel auf Werte abbildet.
In anderen Programmiersprachen kennst du das Konzept von `map` vielleicht als Wörterbuch, Hash-Tabelle, Schlüssel-Wert-Speicher oder assoziatives Array.

Syntaktisch sieht `map` so aus:

```go
map[KeyType]ElementType
```

Wichtig ist auch, dass jeder Schlüssel eindeutig ist: Wenn du denselben Schlüssel zweimal zuweist, wird der Wert des entsprechenden Schlüssels überschrieben.

Um eine Map zu erstellen, kannst du Folgendes tun:

```go
  // With map literal
  foo := map[string]int{}
```

oder

```go
  // or with make function
  foo := make(map[string]int)
```

Hier sind einige Operationen, die du mit einer Map ausführen kannst

```go
  // Add a value in a map with the `=` operator:
  foo["bar"] = 42
  // Here we update the element of `bar`
  foo["bar"] = 73
  // To retrieve a map value, you can use
  baz := foo["bar"]
  // To delete an item from a map, you can use
  delete(foo, "bar")
```

Wenn du versuchst, den Wert für einen Schlüssel abzurufen, der nicht in der Map existiert, wird der Nullwert des Werttyps zurückgegeben.
Das kann verwirrend sein, besonders wenn der Standardwert deines `ElementType` (zum Beispiel 0 für ein int) ein gültiger Wert ist.
Um zu prüfen, ob ein Schlüssel in deiner Map existiert, kannst du Folgendes verwenden

```go
  value, exists := foo["baz"]
  // If the key "baz" does not exist,
  // value: 0; exists: false
```
