# Einführung

Maps sind in Elixir die Datenstruktur, um Informationen in Schlüssel-Wert-Paaren zu speichern. In anderen Sprachen sind sie auch als assoziative Arrays (PHP), Hashes (Perl 5, Raku) oder Wörterbücher (Python) bekannt.

Schlüssel und Werte können von beliebigem Datentyp sein, aber wenn der Schlüssel ein Atom ist, können wir eine Kurzschreibweise verwenden. Beim Zugriff oder bei der Rückgabe garantieren Maps nicht die Reihenfolge ihrer Einträge.

## Literale Schreibweise

Eine leere Map wird einfach mit `%{}` deklariert. Wenn wir einem Map-Literal Einträge hinzufügen wollen, können wir zwei Formen verwenden:

```elixir
# If the key is an atom:
%{atom_key: 1}

# If the key is a different type:
%{1 => :atom_value}

# You can even mix these if the atom form comes second:
%{"first_form" => :a, atom_form: :b}
```

Es gibt kein kanonisches Format, wähle aber eine einheitliche Art, die Schlüssel-Wert-Paare des Literals darzustellen.

## Funktionen des Map-Moduls

Elixir bietet viele Funktionen für die Arbeit mit Maps im _Map-Modul_. Einige Funktionen des _Map-Moduls_ erwarten, dass eine _anonyme_ Funktion übergeben wird, die bei der Transformation der Map hilft.
