# Anleitung

In dieser Übung schreibst du etwas Code, der dir hilft, eine großartige Lasagne aus deinem Lieblingskochbuch zu kochen.

Du hast vier Aufgaben, die sich alle mit der Zeit befassen, die du für das Kochen der Lasagne brauchst.

~~~~exercism/note
Das sind die Anweisungen, die in diesem Konzept erwähnt werden:

| Anweisung   | Beschreibung                     |
|-------------|----------------------------------|
| mov a, b    | kopiert den Inhalt von b nach a  |
| add a, b    | a = a + b                        |
| sub a, b    | a = a - b                        |
| imul a, b   | a = a * b                        |
| call a      | ruft Funktion a auf              |
| ret         | kehrt aus einer Funktion zurück  |
~~~~

## 1. Definiere die erwartete Backzeit in Minuten

Definiere die Funktion `expected_minutes_in_oven`, die keine Parameter entgegennimmt und zurückgibt, wie viele Minuten die Lasagne im Ofen bleiben sollte.
Laut Kochbuch beträgt die erwartete Backzeit 40 Minuten:

```c
expected_minutes_in_oven();
// => 40
```

## 2. Berechne die verbleibende Backzeit in Minuten

Definiere die Funktion `remaining_minutes_in_oven`, die die tatsächlichen Minuten, die die Lasagne schon im Ofen war, als Parameter entgegennimmt und zurückgibt, wie viele Minuten die Lasagne noch im Ofen bleiben muss. Dabei gehst du von der erwarteten Backzeit aus der vorherigen Aufgabe aus.

```c
remaining_minutes_in_oven(30);
// => 10
```

## 3. Berechne die Zubereitungszeit in Minuten

Definiere die Funktion `preparation_time_in_minutes`, die die Anzahl der Schichten, die du der Lasagne hinzugefügt hast, als Parameter entgegennimmt und zurückgibt, wie viele Minuten du mit der Zubereitung der Lasagne verbracht hast. Dabei gehst du davon aus, dass jede Schicht 2 Minuten zum Vorbereiten braucht.

```c
preparation_time_in_minutes(2);
// => 4
```

## 4. Berechne die verstrichene Zeit in Minuten

Definiere die Funktion `elapsed_time_in_minutes`, die zwei Parameter entgegennimmt, und zwar in dieser Reihenfolge:

1. Die Anzahl der Schichten, die du der Lasagne hinzugefügt hast.
2. Die Anzahl der Minuten, die die Lasagne schon im Ofen war.

Die Funktion sollte zurückgeben, wie viele Minuten du mit dem Kochen der Lasagne verbracht hast.
Das ist die Summe aus der Zubereitungszeit in Minuten und der Zeit in Minuten, die die Lasagne bis zu diesem Zeitpunkt im Ofen verbracht hat.

```c
elapsed_time_in_minutes(3, 20);
// => 26
```
