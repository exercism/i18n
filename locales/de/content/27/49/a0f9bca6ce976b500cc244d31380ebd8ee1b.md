# Anleitung

In dieser Übung verarbeitest du Logzeilen.

Jede Logzeile ist ein String, der wie folgt formatiert ist: `"[<LVL>]: <MESSAGE>"`.

Das sind die verschiedenen Log-Level:

- `TRC` (trace)
- `DBG` (debug)
- `INF` (info)
- `WRN` (warning)
- `ERR` (error)
- `FTL` (fatal)

Du hast drei Aufgaben.

## 1. Log-Level parsen

Definiere ein `LogLevel`-Enum mit sechs Elementen, die den oben genannten Log-Leveln entsprechen.

- `Trace`
- `Debug`
- `Info`
- `Warning`
- `Error`
- `Fatal`

Implementiere als Nächstes die (_statische_) `LogLine.ParseLogLevel()`-Methode, um den Log-Level einer Logzeile zu parsen:

```csharp
LogLine.ParseLogLevel("[INF]: File deleted")
// => LogLevel.Info
```

## 2. Unbekannte Log-Level unterstützen

Leider haben gelegentlich einige Logzeilen einen unbekannten Log-Level. Um solche Logzeilen sauber zu behandeln, füge dem `LogLevel`-Enum ein `Unknown`-Element hinzu, das beim Parsen eines unbekannten Log-Levels zurückgegeben werden soll:

```csharp
LogLine.ParseLogLevel("[XYZ]: Overly specific, out of context message")
// => LogLevel.Unknown
```

## 3. Logzeile in das Kurzformat umwandeln

Der Log-Level einer Logzeile ist recht ausführlich. Um den Speicherplatz zu reduzieren, der zum Speichern der Logzeilen benötigt wird, wurde ein Kurzformat entwickelt: `"[<ENCODED_LEVEL>]:<MESSAGE>"`.

Der kodierte Log-Level ist eine einfache Zuordnung eines Log-Levels zu einer Zahl:

- `Unknown` - `0`
- `Trace` - `1`
- `Debug` - `2`
- `Info` - `4`
- `Warning` - `5`
- `Error` - `6`
- `Fatal` - `42`

Implementiere die (_statische_) `LogLine.OutputForShortLog()`-Methode, die eine Logzeile im Kurzformat ausgeben kann:

```csharp
LogLine.OutputForShortLog(LogLevel.Error, "Stack overflow")
// => "6:Stack overflow"
```
