# Einführung

Ein `string` in F# ist ein Objekt, das unveränderlichen Text als Folge von Unicode-Zeichen (Buchstaben, Ziffern, Satzzeichen usw.) darstellt und wie folgt definiert wird:

```fsharp
let fruit = "Apple"
```

Um Strings zu bearbeiten, rufst du entweder die Methoden des Strings auf oder du verwendest die Funktionen des `String`-Moduls. Sobald ein String erstellt wurde, kann sich sein Wert nie mehr ändern. Alle Methoden oder Funktionen, die einen String zu verändern scheinen, geben in Wirklichkeit einen neuen String zurück.

Strings lassen sich auf verschiedene Arten verketten oder formatieren.
* Zum Verketten kannst du den `+`-Operator verwenden:
```fsharp
let sentence = "Apple" + " is a type of fruit."
```
* Du kannst die Funktion `sprintf` verwenden, um Text zu formatieren. Dabei hast du Platzhalter in einem Formattext (`%s` für einen `string`) und übergibst die Werte als Argumente:
```fsharp
let sentence = sprintf "%s is a type of %s." "Apple" "fruit"
```
