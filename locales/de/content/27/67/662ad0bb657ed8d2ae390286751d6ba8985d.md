# Einführung

Die Fähigkeit, etwas durch sich selbst zu definieren, nennt man Rekursion. In F# begegnet dir Rekursion am häufigsten in rekursiven Funktionen, also Funktionen, die sich selbst aufrufen.

Eine rekursive Funktion braucht mindestens einen _Basisfall_ und mindestens einen _Rekursionsfall_. Ein _Basisfall_ gibt einen Wert zurück, ohne die Funktion erneut aufzurufen. Ein _Rekursionsfall_ ruft die Funktion erneut auf und verändert dabei die Eingabe so, dass sie irgendwann zum Basisfall passt.

Rekursive Funktionen werden wie normale Funktionen definiert, aber mit dem `rec`-Modifizierer. Ohne diesen Modifizierer kann eine Funktion sich _nicht_ selbst aufrufen, und jeder Versuch, das zu tun, führt zu einem Kompilierfehler. Rekursion muss also explizit aktiviert werden.

```fsharp
let rec factorial x =
    // Base case
    if x = 1 then
        1
    // Recursive case
    else
        x * factorial (x - 1)
```

F# unterstützt außerdem rekursive Typen über diskriminierte Unions. Bei einer rekursiven diskriminierten Union verweist einer oder mehrere ihrer Fälle in ihren Daten auf die diskriminierte Union selbst. Wie rekursive Funktionen brauchen auch rekursive Typen einen Basisfall. Anders als rekursive Funktionen verwenden rekursive Typen nicht das Schlüsselwort `rec`.

```fsharp
type RussianDoll =
    | Doll                 // Base case
    | Layer of RussianDoll // Recursive case
```
