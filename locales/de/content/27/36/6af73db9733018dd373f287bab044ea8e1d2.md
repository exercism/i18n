# Einführung

Ein Tupel ist ein geordneter Container von Werten. Wie alle Gleam-Datentypen sind Tupel unveränderlich. Jedes Element eines Tupels kann einen anderen Typ haben, es kann sogar selbst ein Tupel sein.

Tupel werden als kommagetrennte Werte zwischen `#(` und `)` definiert: `#(1, 2.0, "Three")`.

```gleam
#("one", 2)      // Tuple pair (2 values)
#("one", 2, 3.0) // Tuple triplet (3 values)
```

Tupel mit derselben Länge und denselben Typen (in derselben Reihenfolge) kannst du auf Gleichheit vergleichen.

```gleam
#(1, 2) == #(1, 2) // Same length, same types, same values, same order
// -> True

#(1, 2) == #(2, 1) // Same length, same types, same values, different order
// -> False

#(1, 2) == #(1, "2") // Same length, different types
// Compile error!

#(1, 2) == #(1, 2, 3) // Different length
// Compile error!
```

Es gibt drei Möglichkeiten, wie du die enthaltenen Werte aus einem Tupel herausbekommst:

- Indexierung.
- Pattern Matching mit `let`.
- Pattern Matching mit `case`.

```gleam
let person = #("Jordan", 52)

// Option 1: Indexing
person.0 // -> "Jordan"
person.1 // -> 52

// Option 2: let
let #(name2, length2) = person
// -> name2 = "Jordan"
// -> length2 = 52

// Option 3: case
case person {
  #(name3, length3) -> {
    name3   // -> "Jordan"
    length3 // -> 52
  }
}
```

Die Indexierung von Tupeln kannst du auch in den Guards von `case`-Ausdrücken verwenden.

```gleam
pub fn is_18(person) {
  case person {
    _ if person.1 >= 18 -> True
    _ -> False
  }
}
```
