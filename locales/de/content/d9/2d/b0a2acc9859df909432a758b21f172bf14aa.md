# Einführung

In PHP kannst du eine Variable als Funktion aufrufen, indem du runde Klammern [`()`] an sie anhängst. Wenn PHP versucht, die Funktion aufzurufen, sucht es nach einer Funktion mit demselben Namen wie der Wert der Variable.

```php
function foo(): string
{
    return "foo() invoked";
}

$func = 'foo';
$func(); // This calls foo()
```
