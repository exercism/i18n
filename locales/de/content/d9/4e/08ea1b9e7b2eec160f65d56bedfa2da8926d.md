# Einführung

Ein Vektor ist ein eindimensionales Array.
Er kann Elemente unterschiedlicher Typen enthalten.

## Vektoren erstellen

Vektoren lassen sich mit der Funktion `vector` oder über ihre Reader-Form `#()` erstellen.

```lisp
(vector 1 t "foo" 'b) ; => #(1 T "foo" B)
#(2 nil "bar" a)      ; => #(2 NIL "bar" A)
```

Da sie Arrays sind, lassen sie sich auch mit `make-array` erstellen:

```lisp
(make-array 3 :initial-element 'x)        ; => #(X X X)
(make-array 3 :initial-contents '(a b c)) ; => #(A B C)
```

## Vektor-Prädikat

Um zu prüfen, ob ein Objekt ein Vektor ist, verwendest du einfach das Prädikat `vectorp`.

## Auf Elemente zugreifen

Um auf Elemente eines Vektors zuzugreifen, verwendest du `aref`; die Indizes beginnen bei null:

```lisp
(aref #(1 2 3) 1) ; => 2
(aref #(a b c) 0) ; => A
```
