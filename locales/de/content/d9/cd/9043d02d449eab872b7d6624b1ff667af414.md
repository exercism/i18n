# Einführung in generische Typen

Ein **generischer Typ** ist eine generische Klasse oder ein generisches Interface, das über Typen parametrisiert wird. Damit kann der Compiler die Typsicherheit für die Klasse oder das Interface erzwingen.

Schauen wir uns dieses nicht-generische `Container`-Interface an:

```java
class Container {
    private Object object;

    public void set(Object object) { this.object = object; }
    public Object get() { return object; }
}
```

Da es Object-Typen annimmt und zurückgibt, funktioniert es mit jedem nicht-primitiven Typ. Das hat jedoch seinen Preis: Ein Teil des Codes ruft vielleicht `get` auf und erwartet `Integer`s, während ein anderer Teil `set` aufruft und `String`s hinzufügt. Das führt zu einer Laufzeitausnahme.

Eine **generische Klasse** und ein **generisches Interface** haben folgende Form:

```java
class ClassName<T1, T2, ..., Tn> { ... }
interface InterfaceName<T1, T2, ..., Tn> { ... }
```

Der Abschnitt für die Typparameter, der in spitzen Klammern (`<>`) steht und auf den Namen der Klasse oder des Interface folgt, legt die Typparameter (auch Typvariablen genannt) `T1`, `T2`, ..., und `Tn` fest. Du kannst sie im Inneren der Klasse oder des Interface verwenden, um generische Typsicherheit zu bekommen.

Hier ist die generische Version von `Container`:

```java
class Container<E> {
    private E object;

    public void set(E object) { this.object = object; }
    public E get() { return object; }
}
```

Beim Erstellen müssen wir jetzt angeben, welchen Typ es enthält, und der Compiler erzwingt diese Einschränkung:

```java
// empty <> can infer from context
Container<String> stringContainer = new Container<>();
// compiler knows this is a String, so it is allowed
stringContainer.set("Some string");
// no cast needed, compiler knows it is a String
String result = stringContainer.get();
// this causes a compiler error:
stringContainer.set(42);
```
