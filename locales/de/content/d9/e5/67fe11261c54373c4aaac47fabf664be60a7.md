# Grundlagen

## Allgemeine Syntax

PHP ist eine interpretierte Sprache, was bedeutet, dass sie den von dir geschriebenen Code direkt ausführt.
PHP-Codedateien sind Textdateien, die ein PHP-Starttag `<?php` enthalten, um den Beginn des PHP-Codes zu markieren.
Wenn die Datei nur PHP-Code enthält, kann das schließende Tag `?>` weggelassen werden, das verwendet wird, um das Ende des PHP-Codes zu markieren.
Siehe [PHP-Tag-Dokumentation][php-tag], um mehr über das PHP-Tag zu erfahren.

```php
<?php

// All PHP code goes here

// No closing tag required at the end
```

Zur besseren Lesbarkeit lassen alle Codebeispiele das PHP-Starttag `<?php` weg.
Aber wir haben es in allen PHP-Übungen, du musst es also nicht selbst hinzufügen.

Alle Anweisungen, wie Zuweisungen oder Funktionsaufrufe, müssen mit einem `;` zur Anweisungstrennung enden.
Das Weglassen von `;` (wie in JavaScript) ist nicht erlaubt und führt zu Syntaxfehlern.
Erfahre mehr über [Anweisungstrennung][php-semicolon] in der PHP-Dokumentation.

```php
$message = "Success!"; // Statement correctly ends with `;`
$message = "I know JavaScript." // PHP Parse error: syntax error, [...]
```

## Werte und Variablen

PHP ist eine dynamisch typisierte Programmiersprache.
Werttypen werden nur während der Programmausführung überprüft.
Mit dem Zuweisungsoperator `=` kann jeder Werttyp jedem Variablennamen zugewiesen werden.
Variablennamen müssen mit einem Dollarzeichen `$` beginnen.
Um tiefer in Variablen einzusteigen, siehe [PHP-Variablen-Dokumentation][php-variables].

```php
$count = 1; // Assign an integer value of 1
$count = 2; // Re-assign a new value to the variable

$count = false; // You may assign any value type

// Strings can be created by enclosing the characters
// within single `'` quotes or double `"` quotes.
$message = "Success!";
```

## Funktionen und Methoden

Literale Werte und in Variablen gespeicherte Werte können an Funktionen übergeben werden.
Neue Variablen werden erstellt, wenn Funktionsargumente definiert werden, um übergebene Werte aufzunehmen.

```php
// Declare the window_width function
function window_width($width)
{
    echo $width; // Access the value passed into the function as $width
    // ...
}

window_width(100); // Call the function with the literal value 100

$newWidth = 100;
window_width($newWidth); // Call the function with the value stored in $newWidth
```

Funktionen können Werte mit dem Schlüsselwort `return` zurückgeben.
Werte, die zurückgegeben werden, können Literale, in Variablen gespeicherte Werte oder das Ergebnis einer Anweisung sein.

```php
function window_height()
{
    $heightOffset = 10;

    return 100 + $heightOffset;
}
```

Funktionen innerhalb von Klassen und ihren Instanzen werden Methoden genannt.
Um eine Methode aufzurufen, wird dem Namen die Instanz und `->` vorangestellt.
Eine Klasseninstanz wird durch die `new`-Operation erstellt.
Methoden haben Zugriff auf die spezielle Variable `$this`, die sich auf die aktuelle Instanz bezieht.

```php
<?php
// Calculator.php

class Calculator {
    // ...

    public function sub($x, $y)
    {
        return $this->add($x, -$y); // Calls the method add() of the current instance
    }

    public function add($x, $y)
    {
        return $x + $y;
    }
}

$calculator = new Calculator(); // Creates a new instance of Calculator class
$calculator->sub(3, 1); // Calls the method sub() of the instance stored in $calculator
// => 2
```

Wir werden in späteren Übungen tiefer in Funktionen und Klassen eintauchen.

## Einfaches Debugging

Als grundlegende Form des Debuggings hilft das Ausgeben von Werten und Inhalten von Variablen dabei, zu verstehen, was passiert.
PHP kann Werte ausgeben mit:

- `echo $variable;`, um eine String-Darstellung des Wertes auszugeben
- `print $variable;`, was dasselbe ist wie `echo $variable;`
- `var_dump($variable);`, um mehr Einblick in den Wert zu erhalten, z. B. den Typ, den PHP sieht

Bei Verwendung von `echo` oder `print`: Leere Strings, `false` und `null` werden nicht angezeigt.
Und Klassen und Instanzen führen zu Fehlern.
Verwende `var_dump()`, um diese zu sehen.

Im Online-Editor wird die Ausgabe, die du erzeugst, zusammen mit den Testergebnissen angezeigt.
Wenn du die Kommandozeile verwendest, erscheint die Ausgabe gemischt mit dem Fortschrittsindikator vor der Testzusammenfassung.

## Code-Organisation

Dateien sind grundlegende Einheiten der Code-Organisation in PHP und vielen anderen Sprachen.
Um den Namen der Datei anzuzeigen, die in einem Block betrachtet werden soll, verwenden wir einen Kommentar.
Du musst solche Kommentare nie zu deinen Dateien hinzufügen:

```php
<?php
// NameOfPhpFile.php

[...]
```

Code, Funktionen und Klassen können alle in einer einzigen Datei vorhanden sein.
Aber normalerweise sind diese Arten von Codeeinheiten in separaten Dateien.

Es ist üblich, eine Klasse pro Datei zu haben, wobei der Dateiname mit der Klasse übereinstimmt.

```php
<?php
// Calculator.php

class Calculator {
    // ...

    function add($x, $y)
    {
        return $x + $y;
    }
}
```

Funktionen werden normalerweise in Dateien gruppiert, die ihr gemeinsames Thema beschreiben.

```php
<?php
// window_handling.php

function window_paint()
{
    // ...
}

function window_size($width, $height)
{
    // ...
}

function window_move($x, $y)
{
    // ...
}
```

Und oft gibt es Dateien, die Anweisungen zur direkten Ausführung enthalten, wie eine `index.php`, die üblicherweise als Einstiegspunkt einer Webanwendung verwendet wird.

```php
<?php
// index.php

$sum = add(1, 2);
// ...
```

## Namenskonventionen

Klassennamen sollten alle `PascalCase` sein.
Je nach Style-Standard können Variablen-, Funktions- und Methodennamen entweder `camelCase` oder `snake_case` sein.
Namen dürfen Buchstaben `a-zA-Z`, Zahlen `0-9` und Unterstriche `_` enthalten, aber sie dürfen nicht mit einer Zahl beginnen.

## Kommentare

Einzeilige Kommentare beginnen mit `//`, und ein Textblock kann mit `/*` und `*/` umschlossen werden, um zu einem mehrzeiligen Kommentar zu werden.

```php
// Single-line comment

/*
  Multi-line comment
*/
```
