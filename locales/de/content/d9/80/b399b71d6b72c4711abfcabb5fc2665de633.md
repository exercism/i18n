# Hinweise

## 1. Bestimme die Gesamtzahl der Vögel, die du bisher gezählt hast

- In der Einleitung zur Übung findest du ein Beispiel, wie du mit einer for-Schleife über ein Array iterierst.
- Verwende eine Hilfsvariable, um die Gesamtzahl zu speichern, und erhöhe diese Variable, während du durch das Array gehst.
- Denk über den richtigen Startwert für diese Hilfsvariable nach.
- Schau dir noch einmal das [Array-Konzept][concept-arrays] an, um zu wiederholen, wie du Werte aus einem Array ausliest.

## 2. Berechne die Anzahl der Gastvögel in einer bestimmten Woche

- Diese Aufgabe ähnelt der ersten.
  Du kannst deinen Code als Ausgangspunkt kopieren.
- Überlege, welche Indizes im Array du für Woche 1 bzw. 2 berücksichtigen musst.
- Finde nun einen allgemeinen Weg, um den ersten und den letzten Index zu berechnen, die berücksichtigt werden sollen.
- Damit kannst du die for-Schleife so einrichten, dass sie nur über den relevanten Abschnitt des Arrays iteriert.

## 3. Korrigiere einen Zählfehler

- Auch hier musst du eine for-Schleife einrichten, um über das gesamte Array der Vogelzählung zu iterieren.
- Diesmal musst du nur jeden zweiten Eintrag im Array betrachten.
- Ändere die Schrittweite, sodass die Zählvariable nach jeder Iteration entsprechend erhöht wird.
- Im Schleifenblock der for-Schleife kannst du den Inkrement-Operator verwenden, um den Wert eines Elements in einem Array direkt zu ändern.
