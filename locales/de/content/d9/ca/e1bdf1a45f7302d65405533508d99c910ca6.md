# Einführung

Ein *generisches Wort* deklariert eine Operation, die je nach Klasse ihres Arguments unterschiedliche Implementierungen haben kann. Methoden fügst du mit `M:` hinzu.

```factor
USING: kernel math ;

GENERIC: area ( shape -- n )

TUPLE: square side ;
TUPLE: circle radius ;

M: square area side>> dup * ;
M: circle area radius>> dup * 3.14159 * ;
```

```factor
T{ square { side 4 } } area .    ! => 16
T{ circle { radius 2 } } area .  ! => 12.56636
```

`GENERIC:` deklariert das Wort und seinen Stack-Effekt. `M:` definiert eine Methode für eine bestimmte Klasse. Factor wählt zur Laufzeit anhand der Klasse des obersten Arguments die passende Methode aus.

Du kannst das generische Wort fragen, für welche Klassen es Methoden hat, und Methoden auch nachträglich hinzufügen oder entfernen. Eine spezielle Syntax für Vererbung gibt es nicht: Auf jeder Tupel-Klasse lassen sich automatisch Methoden definieren.
