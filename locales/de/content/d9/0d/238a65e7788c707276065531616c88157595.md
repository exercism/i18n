# main-Funktion entfernen und Paketnamen korrigieren

Entferne die `main`-Funktion, benenne das Paket wieder in `twofer` um und führe die Tests aus.

Eine `main`-Funktion dient als Einstiegspunkt in ein Programm. Exercism setzt auf TDD ([Test Driven Development](http://testfirst.org/about#tdd)).
Das bedeutet, dass dein Code ausgeführt wird, wenn du die Tests startest, damit sie bestehen. Um die Tests zu starten, führe im Terminal `go test` aus.
Die Tests bestehen, wenn die Funktionalität korrekt implementiert ist.
