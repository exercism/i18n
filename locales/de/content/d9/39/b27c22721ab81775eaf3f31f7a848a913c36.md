# Installation

Du brauchst [Vim](http://www.vim.org), um die Übungen zu lösen:

- [macOS](#macos)
- [Ubuntu / Debian](#ubuntu--debian)
- [Windows](#windows)
- [Quellcode](#source)

## macOS

Das Betriebssystem wird standardmäßig mit Vim ausgeliefert, doch die mitgelieferte Version ist hoffnungslos veraltet.

Wahrscheinlich nutzt du entweder [MacPorts](https://www.macports.org) oder
[Homebrew](https://brew.sh), um Software zu installieren.

Homebrew:

```
$ brew update
$ brew install vim
```

MacPorts:

```
$ sudo port install vim +huge
```

Wenn du eine grafische Benutzeroberfläche möchtest, schau dir stattdessen
[MacVim](https://macvim-dev.github.io/macvim) an.

## Ubuntu / Debian

Installiere ein vollwertiges Vim mit grafischer Oberfläche (`gvim`):

```
$ sudo apt-get update
$ sudo apt-get install vim-gtk
```

## Windows

Mit [Chocolatey](https://chocolatey.org):

```
C:\> choco install vim
```

Oder lade es direkt von [hier](http://www.vim.org/download.php#pc) herunter und installiere es.

## Quellcode

Wenn du das neueste Vim selbst kompilieren möchtest, schau dir das [offizielle
Repository auf GitHub](https://github.com/vim/vim) an.
