# Einführung

## Konstanten

Konstanten in Gleam sind eine Möglichkeit, Werten Namen zu geben. Sie werden mit dem `const`-Schlüsselwort definiert.

```gleam
pub const pi: Float = 3.14159

pub fn circle_area(radius: Float) -> Float {
  radius *. radius *. pi
}
```

Wenn sie mit dem `pub`-Schlüsselwort definiert werden, kann aus anderen Modulen auf Modulkonstanten zugegriffen werden. Andernfalls kann nur innerhalb des Moduls auf sie zugegriffen werden, in dem sie definiert wurden.

## Ordnungen

Das Modul `gleam/order` in der Standardbibliothek von Gleam enthält den Typ `Order`, mit dem Werte verglichen werden.

Die Definition von `Order` sieht so aus:

```gleam
pub type Order {
  Gt
  Eq
  Lt
}
```

Der Typ hat drei Varianten, die jeweils die Beziehung zwischen einem Wert und einem anderen Wert darstellen:

- `Gt`: Der Wert ist _größer als_ der andere Wert.
- `Eq`: Der Wert ist _gleich_ dem anderen Wert.
- `Lt`: Der Wert ist _kleiner als_ der andere Wert.

Wenn ein Datentyp nach seiner Größe verglichen werden kann, ist es üblich, dass das Modul eine `compare`-Funktion definiert, die einen `Order`-Wert zurückgibt. Zum Beispiel definieren `gleam/float` und `gleam/int` `compare`-Funktionen, die auf Gleitkommazahlen bzw. Ganzzahlen arbeiten.

```gleam
int.compare(1, 2)
// -> Lt

int.compare(2, 2)
// -> Eq

float.compare(1.0, 2.0)
// -> Lt
```

Sortierfunktionen wie `list.sort` nehmen häufig eine Funktion entgegen, die einen `Order`-Wert zurückgibt, sodass der Aufrufer festlegen kann, wie die Liste sortiert werden soll.

```gleam
list.sort([3, 7, 3, 1], by: int.compare)
// -> [1, 3, 3, 7]
```
