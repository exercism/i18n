# Über

Die Klasse [`TimeZoneInfo`][TimeZoneInfo] bietet Routinen für den Umgang mit den Unterschieden zwischen Zeitzonen. Die Klasse `TimeZoneInfo` enthält außerdem Methoden, die den Umgang mit der Sommerzeit erleichtern.

Die Klasse [`CultureInfo`][CultureInfo] unterstützt gebietsschemaabhängige Datums- und Zeitformate.

Um plattformübergreifendes Programmieren zu unterstützen, kannst du mit der Klasse [`RuntimeInformation`][RuntimeInformation] feststellen, unter welchem Betriebssystem dein Code gerade ausgeführt wird: Linux, Windows oder OSX.

[TimeZoneInfo]: https://docs.microsoft.com/en-us/dotnet/api/system.timezoneinfo
[CultureInfo]: https://docs.microsoft.com/en-us/dotnet/api/system.globalization.cultureinfo
[RuntimeInformation]: https://docs.microsoft.com/en-us/dotnet/api/system.runtime.interopservices.runtimeinformation
