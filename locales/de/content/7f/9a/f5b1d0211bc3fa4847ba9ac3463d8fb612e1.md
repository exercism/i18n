# Anleitung

Eine Zirkusshow ist eine Abfolge von Nummern. Die einzelnen Nummern sind von
innen völlig verschieden, und wer die Show zusammenstellt, braucht von jeder
dieselben zwei Dinge.

Das ist die erste Übung, in der du mehrere Klassen in einer Datei schreibst.
Das Gerüst gibt dir die abstrakte Klasse vor; den Rest schreibst du darunter.

## 1. Die drei Nummern

Schreibe drei Klassen, jede ein `$ACT`.

| Klasse | `name` | `minutes` |
| --- | --- | --- |
| `JUGGLING` | `"Juggling"` | 5 |
| `TUMBLING` | `"Tumbling"` | 3 |
| `TRAPEZE` | `"Trapeze at "` dann die Höhe, dann `"m"` | 8 |

`JUGGLING` und `TUMBLING` werden ohne Argumente erzeugt. `TRAPEZE` wird mit der
Höhe in Metern erzeugt:

```sather
#JUGGLING
#TRAPEZE(4)
```

also ist `#TRAPEZE(4).name` gleich `"Trapeze at 4m"`.

## 2. Die Show

Schreibe eine Klasse `CIRCUS_ACTS` mit drei Routinen, die jeweils die Abfolge
als `ARRAY{$ACT}` entgegennehmen.

**`total_minutes`**: wie lange die ganze Show dauert.

```sather
CIRCUS_ACTS::total_minutes(|#JUGGLING, #TUMBLING|)
-- => 8
```

**`billing`**: die Namen der Nummern, verbunden mit `", "`.

```sather
CIRCUS_ACTS::billing(|#JUGGLING, #TUMBLING|)
-- => "Juggling, Tumbling"
```

**`longest`**: der Name der Nummer, die am längsten dauert. Sind zwei gleich
lang, gewinnt die frühere. Eine leere Show hat keine längste Nummer, also ist
die Antwort `""`.

```sather
CIRCUS_ACTS::longest(|#JUGGLING, #TUMBLING|)
-- => "Juggling"
```

Keine der drei darf abfragen, um welche Art von Nummer es sich handelt.
