# Über

Das Modul `gleam/order` in der Standardbibliothek von Gleam enthält den Typ `Order`, mit dem du Werte vergleichen kannst.

Die Definition von `Order` sieht so aus:

```gleam
pub type Order {
  Gt
  Eq
  Lt
}
```

Der Typ hat drei Varianten, die jeweils die Beziehung zwischen einem Wert und einem anderen Wert beschreiben:

- `Gt` - der Wert ist _größer_ als der andere Wert.
- `Eq` - der Wert ist _gleich_ dem anderen Wert.
- `Lt` - der Wert ist _kleiner_ als der andere Wert.

Wenn ein Datentyp nach seiner Größe verglichen werden kann, definiert das Modul üblicherweise eine `compare`-Funktion, die einen Wert vom Typ `Order` zurückgibt. Zum Beispiel definieren `gleam/float` und `gleam/int` jeweils `compare`-Funktionen, die auf Gleitkommazahlen bzw. Ganzzahlen arbeiten.

```gleam
int.compare(1, 2)
// -> Lt

int.compare(2, 2)
// -> Eq

float.compare(1.0, 2.0)
// -> Lt
```

Sortierfunktionen wie `list.sort` bekommen häufig eine Funktion übergeben, die einen Wert vom Typ `Order` zurückgibt. So kann der Aufrufer festlegen, wie die Liste sortiert werden soll.

```gleam
list.sort([3, 7, 3, 1], by: int.compare)
// -> [1, 3, 3, 7]
```
