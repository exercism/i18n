# Einführung

## Warteschlangen

Die Gleam-Standardbibliothek implementiert im Modul `gleam/queue` einen `Queue`-Typ. Er ähnelt dem `List`-Typ, hat aber ein paar wichtige Unterschiede:

- Der `Queue`-Typ hat keine Literalsyntax, mit der man Warteschlangen erzeugen oder Musterabgleich auf ihnen betreiben kann.
- Bei einem `Queue`-Typ lassen sich Elemente effizient vorne und hinten hinzufügen und entfernen, während sich beim `List`-Typ Elemente nur vorne effizient hinzufügen und entfernen lassen.

Meistens willst du den `List`-Typ verwenden, aber wenn du am Ende einer Sammlung hinzufügen und entfernen können musst, ist der `Queue`-Typ eine gute Wahl.

Warteschlangen kannst du mit den Funktionen `queue.new` und `queue.from_list` erzeugen:

```gleam
let empty = queue.new()
let one_to_four = queue.from_list([1, 2, 3, 4])
```

Elemente kannst du mit den Funktionen `queue.push_front` und `queue.push_back` zur Warteschlange hinzufügen:

```gleam
let one_to_four = queue.from_list([1, 2, 3, 4])
let one_to_five = queue.push_back(one_to_four, 5)
let zero_to_five = queue.push_front(one_to_five, 0)
```

Elemente kannst du mit den Funktionen `queue.pop_front` und `queue.pop_back` aus der Warteschlange entfernen:

```gleam
let one_to_four = queue.from_list([1, 2, 3, 4])

queue.pop_back(one_to_four)
// -> Ok(#(4, queue.from_list([1, 2, 3])))

queue.pop_front(one_to_four)
// -> Ok(#(1, queue.from_list([2, 3, 4])))

queue.pop_front(queue.new())
// -> Error(Nil)
```

Mit der Funktion `queue.to_list` kannst du eine Warteschlange in eine Liste umwandeln:

```gleam
let one_to_four = queue.from_list([1, 2, 3, 4])
queue.to_list(one_to_four)
// -> [1, 2, 3, 4]
```

### Gleichheit von Warteschlangen

Aufgrund der Art und Weise, wie Warteschlangen implementiert werden, können zwei Warteschlangen mit denselben Elementen in derselben Reihenfolge nach dem `==`-Operator ungleich sein, der Werte strukturell vergleicht. Zum Beispiel:

```gleam
let empty = queue.new()
let a = queue.push_front(empty, 1)
let b = queue.push_back(empty, 1)
a == b
// -> False
```

Wenn du zwei Warteschlangen auf Gleichheit vergleichen musst, kannst du die Funktion `queue.is_logically_equal` verwenden.

```gleam
queue.is_logically_equal(a, b, fn(x, y) { x == y })))
// -> True
```
