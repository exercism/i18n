# Einführung

Listen sind in die Sprache Elixir eingebaut. Sie gelten als grundlegender Typ und werden mit eckigen Klammern geschrieben. Listen können leer sein oder beliebig viele Elemente beliebigen Typs enthalten. Zum Beispiel:

```elixir
empty_list = []
one_item_list = [1]
two_item_list = [1, 2]
multiple_type_list = [1, :pi, 3.14, "four"]
```

Elixir implementiert Listen als verkettete Liste, bei der jeder Knoten zwei Werte speichert: das erste Element und eine weitere Liste mit allen übrigen Elementen. Das erste Element der Liste wird als _Kopf_ bezeichnet, die verbleibende Liste der Elemente als _Rest_. Diese Notation können wir im Code verwenden:

```elixir
# [1] represented in [head | tail] notation
[1 | []]

# [1, 2, 3] represented in [head | tail] notation
[1 | [2 | [3 | []]]]
```

Mit der Notation _`[head | tail]`_ können wir Elemente an den Anfang einer Liste setzen:

```elixir
# Suppose
list = [2, 1]

[3, 2, 1] == [3 | list]
# => true
```

Im Modul `Kernel` gibt es mehrere Funktionen für die Arbeit mit Listen, und dazu das komplette Modul `List`.

```elixir
# Check if 1 is a member of the list
1 in [1, 2, 3, 4]
# => true
```
