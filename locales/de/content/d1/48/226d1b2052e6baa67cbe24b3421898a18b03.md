# Hinweise

## Allgemein

- Eine Routine, die mit Text antwortet, wird mit `: STR` deklariert. Eine, die mit einer ganzen Zahl antwortet, wird mit `: INT` deklariert.
- Zwei Argumente desselben Typs können sich eine Deklaration teilen:
  `full_title(piece, composer : STR) : STR`.

## 1. Nenne das Stück und seinen Komponisten

- Drei Textstücke, die mit `+` verbunden werden: das Stück, dann `" by "`, dann der Komponist.
- Die Leerzeichen stehen innerhalb der Anführungszeichen. `+` fügt von sich aus nichts hinzu.

## 2. Miss eine Zeile

- `.size`, ohne Klammern dahinter.

## 3. Die ersten paar Buchstaben

- `.head` nimmt die Zahl in Klammern entgegen: `title.head(count)`.

## 4. Die letzten paar Buchstaben

- `.tail` ist `.head`, nur vom anderen Ende gezählt.

## 5. Kürze einen langen Titel

- Sechs Buchstaben von vorne, dann `"..."` mit `+` anhängen.
- Die Anzahl der Buchstaben ist immer sechs, sie kann also direkt in den Aufruf geschrieben werden, statt sie zu übergeben.
