# Einleitung

Wenn du mit `java.time`-Objekten wie `LocalDate` arbeitest, musst du oft komplexe Datumsanpassungen vornehmen, zum Beispiel den „zweiten Dienstag des Monats“ finden.
Statt das von Hand zu berechnen, kannst du **`TemporalAdjusters`** verwenden.

Die Utility-Klasse `java.time.temporal.TemporalAdjusters` (beachte das Plural-s) bietet statische Methoden für viele gängige Datumsanpassungen.
Du wendest diese Anpassungen mit der Methode `.with()` auf ein Temporal-Objekt (wie `LocalDate`) an.

```exercism/note
Die Verwendung von `with(TemporalAdjuster)` liefert eine _neue_ Instanz zurück und aktualisiert die bestehende Instanz nicht, da `java.time`-Objekte unveränderlich sind.
```

```java
import java.time.LocalDate;
import java.time.Month;
import java.time.DayOfWeek;
import java.time.temporal.TemporalAdjusters;

LocalDate date = LocalDate.of(2024, Month.AUGUST, 15); // 2024-08-15 (a Thursday)

// Use a predefined adjuster: find the last day of the month
LocalDate lastDay = date.with(TemporalAdjusters.lastDayOfMonth());
// => 2024-08-31
```

Hier sind einige wichtige Adjuster, die für Terminberechnungen nützlich sind:

## Den n-ten Wochentag im Monat finden

Mit `dayOfWeekInMonth(int ordinal, DayOfWeek dayOfWeek)` findest du das n-te Vorkommen eines Wochentags.

```java
// Find the second Tuesday of August 2024
LocalDate secondTuesday = date.with(TemporalAdjusters.dayOfWeekInMonth(2, DayOfWeek.TUESDAY));
// => 2024-08-13
```

## Den ersten bzw. letzten Wochentag im Monat finden

Verwende `firstInMonth(DayOfWeek dayOfWeek)` oder `lastInMonth(DayOfWeek dayOfWeek)`.

```java
// Find the last Monday of August 2024
LocalDate lastMonday = date.with(TemporalAdjusters.lastInMonth(DayOfWeek.MONDAY));
// => 2024-08-26
```

## Relative Anpassungen (nächster/vorheriger)

Adjuster wie `next()`, `previous()`, `nextOrSame()` und `previousOrSame()` finden das nächste oder vorherige Vorkommen eines gegebenen Wochentags relativ zum aktuellen Datum.

- `next()`/`previous()`: Schließen das aktuelle Datum aus, wenn es übereinstimmt.
- `nextOrSame()`/`previousOrSame()`: Schließen das aktuelle Datum ein, wenn es übereinstimmt.

```java
LocalDate thursday = LocalDate.of(2024, Month.AUGUST, 15); // A Thursday

// Find the next Thursday (exclusive)
LocalDate nextThursday = thursday.with(TemporalAdjusters.next(DayOfWeek.THURSDAY));
// => 2024-08-22

// Find the next Thursday (inclusive) - returns the same date
LocalDate nextOrSameThursday = thursday.with(TemporalAdjusters.nextOrSame(DayOfWeek.THURSDAY));
// => 2024-08-15

// Find the previous Monday (exclusive)
LocalDate previousMonday = thursday.with(TemporalAdjusters.previous(DayOfWeek.MONDAY));
// => 2024-08-12
```

## Eigene Adjuster

`TemporalAdjuster` ist ein funktionales Interface, du kannst also einen eigenen Adjuster als Lambda schreiben, das das anzupassende Temporal-Objekt entgegennimmt und das angepasste zurückgibt.
Er wird genau wie die vordefinierten Adjuster mit `.with()` angewendet und kann diese intern selbst nutzen.

```java
import java.time.temporal.TemporalAdjuster;

// An adjuster that moves a weekend date to the following Monday
TemporalAdjuster skipWeekend = temporal -> {
    DayOfWeek day = DayOfWeek.from(temporal);
    if (day == DayOfWeek.SATURDAY || day == DayOfWeek.SUNDAY) {
        return temporal.with(TemporalAdjusters.next(DayOfWeek.MONDAY));
    }
    return temporal;
};

LocalDate saturday = LocalDate.of(2024, Month.AUGUST, 17);
LocalDate monday = saturday.with(skipWeekend);
// => 2024-08-19
```

Mit diesen Adjustern aus der Klasse `TemporalAdjusters` lassen sich Datumsmanipulationen deutlich vereinfachen.
