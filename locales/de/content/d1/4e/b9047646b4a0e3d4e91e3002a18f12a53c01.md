# Einführung

In Common Lisp kann eine Funktion benannte Parameter haben (man nennt sie „Schlüsselwortparameter"). In der Lambda-Liste werden sie durch das Schlüsselwort `&key` gekennzeichnet. Schlüsselwortparameter sind keine erforderlichen Parameter. Wie optionale Parameter können sie Standardwerte bekommen und Symbole, die an ihren Zustand „übergeben oder nicht übergeben" gebunden werden.

Beim Aufruf einer Funktion mit Schlüsselwortparametern wird der Name des Parameters als Schlüsselwort vor den Parameterwert gesetzt. Schlüsselwortparameter können vom Aufrufer der Funktion in beliebiger Reihenfolge angegeben werden.

```lisp
(defun keyword-parameters (&key x (y 'default) (z nil z-supplied-p))
  (list x y (if z-supplied-p (list :z-was-supplied z)
                             (list :z-was-not-supplied z))))

(keyword-parameters)            ; => (NIL DEFAULT (:Z-WAS-NOT-SUPPLIED NIL))
(keyword-parameters :y 5)       ; => (NIL 5 (:Z-WAS-NOT-SUPPLIED NIL))
(keyword-parameters :z 10 :x 5) ; => (5 DEFAULT (:Z-WAS-SUPPLIED 10))
```

Sei vorsichtig, wenn du optionale und Schlüsselwortparameter kombinierst, denn der Schlüsselwortname und das Argument könnten von den optionalen Parametern verbraucht werden:

```lisp
(defun could-be-confusing (&optional x y &key z) (list x y z))
(could-be-confusing :z 'huh?) ; => (:Z HUH? NIL)
```
