# Tests ausführen

Wenn `sbt` installiert ist, kannst du die Tests von der Kommandozeile aus so ausführen:

```bash
$ sbt test
```

Beachte, dass es langsam ist, jedes Mal `sbt test` auszuführen, weil `sbt` bei jedem Aufruf neu initialisiert wird.

`sbt` funktioniert wie eine Shell: Sobald es gestartet ist, kannst du Befehle darin ausführen.

Zum Beispiel kannst du `sbt` verwenden, um deine Tests erneut auszuführen, wann immer sich die Quelldateien ändern:
```bash
$ sbt
>~ test
```

Beachte, dass alle Tests bis auf den ersten deaktiviert wurden, damit du an ihm arbeiten kannst.
Um fortzufahren, entfernst du einfach das Schlüsselwort `pending` am Anfang jedes Testfalls.

Geh [hierhin](https://www.scala-sbt.org/), um mehr über `sbt` zu erfahren.


Tests können auch in den folgenden IDEs ausgeführt werden:

* [Metals](https://scalameta.org/metals/docs/#running-tests)
* [IntelliJ IDEA with Scala Plugin](https://www.jetbrains.com/idea/)
