# Case

[`case`][case] (in anderen Sprachen oft „switch“ genannt) ist eine Art Kontrollausdruck, ähnlich wie if-else.
Mit `case` lassen sich mehrere if-else-if-Anweisungen verketten, das kann lesbarer sein und ermöglicht mächtige Konstrukte.

Ein `case` wird durch das Schlüsselwort `case` eingeleitet, auf das ein optionaler Ausdruck folgt.
Dann wird für jeden Fall das Schlüsselwort `when` verwendet, gefolgt von einem Ausdruck, der mit dem case-Ausdruck verglichen wird.
Das Schlüsselwort `when` sollte nicht gegenüber dem Schlüsselwort `case` eingerückt werden.
Nach dem Schlüsselwort `when` folgt der Code, der ausgeführt werden soll, wenn der case-Ausdruck zum when-Ausdruck passt.
Case erlaubt eine optionale `else`-Anweisung, die ausgeführt wird, wenn kein anderer Fall passt.

Der case-Ausdruck wird ausgewertet und dann mit jedem when-Ausdruck verglichen.
Der Vergleich erfolgt mit dem [Case-Subsumptionsoperator (`===`)][case-subsumption].

```Crystal
case 1
when 1
  puts "One"
when 2
  puts "Two"
else
  puts "Other"
end
# => One

# This is the same as:
tmp = 1
if 1 === tmp
  puts "One"
elsif 2 === tmp
  puts "Two"
else
  puts "Other"
end
```

## Case-Subsumptionsoperator (`===`)

Der Case-Subsumptionsoperator (`===`) unterscheidet sich ein wenig vom Gleichheitsoperator (`==`).
Der Operator prüft, ob die rechte Seite ein Element der Menge ist, die die linke Seite beschreibt.
Das bedeutet, dass es sehr wohl darauf ankommt, an welcher Stelle die einzelnen Operanden stehen.
Wie das genau funktioniert, hängt vom Typ der linken Seite ab: Eine `Range` prüft zum Beispiel, ob die rechte Seite im Bereich liegt, und ein `Object` prüft, ob die rechte Seite eine Instanz des `Object` ist.

```Crystal
(1..3) == 1  # => false
(1..3) === 1 # => true

String == "foo"  # => false
String === "foo" # => true
```

## Case mit mehreren Ausdrücken

In einem Case lassen sich mehrere Ausdrücke gleichzeitig abgleichen, wobei die einzelnen möglichen Werte durch ein Komma getrennt werden.
Der Code wird ausgeführt, wenn einer der Ausdrücke passt.
Das ist nützlich, wenn ein einzelner Fall mehrere mögliche Werte haben kann.

```Crystal
case 1
when 1, 2
  puts "One or two"
else
  puts "Other"
end
```

## Cases mit Bereichen

Ein Case kann auch prüfen, ob ein Wert in einem Bereich liegt.
Dazu verwendest du einen Bereich als when-Ausdruck.

```Crystal
case var
when 1..3
  puts "One to three"
else
  puts "Other"
end
```

## Cases ohne case-Ausdruck

Wenn du keinen case-Ausdruck brauchst, kannst du ihn weglassen.
Dadurch wird jeder when-Ausdruck auf seinen Wahrheitswert geprüft.
So verhalten sie sich wie if-else-if-Anweisungen.

```Crystal
case
when 1 == 1
  puts "One is equal to one"
when 1 > 2
  puts "One is greater than two"
else
  puts "Other"
end
```

## Einzeiliges when

Crystal erlaubt einzeilige Case-Anweisungen.
Das bietet sich an, wenn du eine einfache einzeilige Anweisung hast.
Die einzeilige when-Anweisung wird als `when <expression> then <statement>.` geschrieben.
Und in der else-Anweisung wird sie als `else <statement>` geschrieben.

```Crystal
case var
when 1 then puts "One"
when 2 then puts "Two"
else puts "Other"
end
```

## Case mit Typen

Case erlaubt auch den Abgleich mit Typen.
Der Vergleich verwendet den Operator `is_a?`, um den Typ der Variable zu prüfen.
So kannst du zum Beispiel für jeden Typ eines Union-Typs einen eigenen Zweig angeben.

```Crystal
case var
when Int32
  puts "Int32"
when String
  puts "String"
else
  puts "Other"
end
```

## Implizites Objekt

Case erlaubt die Verwendung eines impliziten Objekts.
Damit kann ein when-Ausdruck zum Beispiel ein Methodenaufruf auf dem case-Ausdruck sein.
Je nachdem, ob die Methode einen truthy- oder falsey-Wert zurückgibt, passt das Case oder nicht.

```Crystal
case 1
when .odd?
  puts "Odd"
when .even?
  puts "Even"
end
```
