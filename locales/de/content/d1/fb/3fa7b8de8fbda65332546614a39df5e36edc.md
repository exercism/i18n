# Ergänzung zu den Anweisungen

## Hinweise

Du musst die Funktion `responseFor` implementieren, die Bobs Antwort für eine gegebene Eingabe zurückgibt. Wenn du dir bei den Typen unsicher bist, kannst du die vorgegebene Signatur verwenden, aber lass dich davon nicht in deiner Kreativität einschränken:

```haskell
responseFor :: String -> String
```

Um diese Übung zu lösen, kannst du dich über Folgendes informieren:

- [Guards][guards]

[guards]: https://www.futurelearn.com/courses/functional-programming-haskell/0/steps/27226

Diese Übung arbeitet mit Textdaten. Aus historischen Gründen ist der Typ `String` in Haskell gleichbedeutend mit `[Char]`, einer Liste von Zeichen. Für eine effizientere Verarbeitung von Textdaten kann der Typ `Text` verwendet werden.

Als optionale Erweiterung dieser Übung kannst du

- etwas über [String-Typen](https://haskell-lang.org/tutorial/string-types) in Haskell lesen.
- `- text` zu deiner Liste der Abhängigkeiten in package.yaml hinzufügen.
- `Data.Text` [wie folgt](https://hackernoon.com/4-steps-to-a-better-imports-list-in-haskell-43a3d868273c) importieren:

    ```haskell
    import qualified Data.Text as T
    import           Data.Text (Text)
    ```

- Jetzt kannst du z. B. `responseFor :: Text -> Text` schreiben und `Data.Text`-Kombinatoren wie z. B. `T.isSuffixOf` verwenden.
- die Dokumentation für [`Data.Text`](https://hackage.haskell.org/package/text/docs/Data-Text.html) nachschlagen.
- Anschließend kannst du in Bob.hs alle Vorkommen von `String` durch `Text` ersetzen:

    ```haskell
    responseFor :: Text -> Text
    ```

Dieser Teil ist völlig optional.
