# Tests

## Tests ausführen

Wenn du dich im Verzeichnis einer Übung befindest, solltest du zwei Unterverzeichnisse sehen:

* `Sources/<Exercise>` enthält deine Lösung für die Übung
* `Tests/<Exercise>Tests` enthält die Tests, die für die Übung ausgeführt werden

Wenn du dich im richtigen Verzeichnis befindest (also in dem, das `Sources` und `Tests` enthält), kannst du die Tests für diese Übung mit `swift test` ausführen:

```bash
$ pwd
/Users/johndoe/Code/exercism/swift/hello-world

$ ls
HELP.md  Package.swift  README.md  Sources  Tests

$ swift test
```

Wenn ein Test läuft, entferne `.enabled(if: RUNALL)` in der `@Test`-Anweisung, um den nächsten Test zu aktivieren. Alternativ kannst du unter Linux oder macOS alle Tests ausführen, indem du die Umgebungsvariable `RUNALL` auf `true` setzt:

```bash
$ export RUNALL=true
```

Oder, wenn du unter Windows PowerShell verwendest:

```powershell
set RUNALL=true
```

## Deine Lösung einreichen

Um eine Lösung bei Exercism hochzuladen, musst du dich im Verzeichnis befinden, das die Verzeichnisse `Sources` und `Tests` enthält.

```bash
$ exercism submit 
```
