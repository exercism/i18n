# Anleitung

Dein Nachbarschaftsverein hat dich gebeten, eine einfache Registrierungsanwendung zu implementieren, mit der du die Anmeldungen für den Gemeinschaftsgarten verwalten kannst. Das `Plot`-Struct wurde dir bereits zur Verfügung gestellt.

## 1. Öffne den Garten

Implementiere die Funktion `CommunityGarden.start/1`. Sie sollte eine optionale Keyword-Liste mit Optionen entgegennehmen, die an den _Agent-Prozess_ weitergegeben werden. Der Anfangszustand des Gartens sollte als leere Sammlung von Beeten initialisiert werden. Sie sollte ein `:ok`-Tupel mit der pid des Gartens zurückgeben.

```elixir
{:ok, pid} = CommunityGarden.start()
# => {:ok, #PID<0.112.0>}
```

## 2. Liste die Registrierungen auf

Implementiere die Funktion `CommunityGarden.list_registrations/1`. Sie sollte die `pid` des Gemeinschaftsgartens entgegennehmen. Sie sollte eine Liste der gespeicherten Beete zurückgeben, die registriert sind.

```elixir
CommunityGarden.list_registrations(pid)
# => []
```

> An diesem Punkt haben wir noch nicht die Möglichkeit hinzugefügt, ein Beet zu registrieren, also sollte diese Liste leer sein

## 3. Registriere Beete für eine Person

Implementiere die Funktion `CommunityGarden.register/2`. Sie sollte die `pid` des Gemeinschaftsgartens und einen Namen entgegennehmen, um das Beet zu registrieren. Bei Erfolg sollte sie das `Plot`-Struct mit der id des Beets und der registrierten Person zurückgeben.

Die ids sollten fortlaufend und eindeutig sein. Du kannst einen id-Zähler im Zustand des Agenten führen.

```elixir
CommunityGarden.register(pid, "Emma Balan")
# => %Plot{plot_id: 1, registered_to: "Emma Balan"}
CommunityGarden.list_registrations(pid)
# => [%Plot{plot_id: 1, registered_to: "Emma Balan"}]
```

## 4. Gib Beete frei

Implementiere die Funktion `CommunityGarden.release/2`. Sie sollte die `pid` und die `id` des freizugebenden Beets entgegennehmen. Bei Erfolg sollte sie `:ok` zurückgeben. Wenn ein Beet freigegeben wird, wird die id nicht wiederverwendet, sie dient nur als eindeutiger Bezeichner.

```elixir
CommunityGarden.release(pid, 1)
# => :ok
CommunityGarden.list_registrations(pid)
# => []
```

## 5. Rufe ein registriertes Beet ab

Implementiere die Funktion `CommunityGarden.get_registration/2`. Sie sollte die `pid` und die `id` des zu prüfenden Beets entgegennehmen. Wenn das Beet registriert ist, sollte sie es zurückgeben, und `:not_found`, wenn es nicht registriert ist.

```elixir
CommunityGarden.get_registration(pid, 1)
# => %Plot{plot_id: 1, registered_to: "Emma Balan"}
CommunityGarden.get_registration(pid, 7)
# => {:not_found, "plot is unregistered"}
```
