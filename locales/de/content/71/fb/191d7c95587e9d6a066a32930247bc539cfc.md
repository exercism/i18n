# Einführung

## Grundlagen

Java ist eine statisch typisierte Sprache. Das bedeutet, dass der Typ einer Variablen zur Kompilierzeit bekannt ist.
Wenn du einem Namen einen Wert zuweist, nennt man das Definieren einer Variablen.
Eine Variable wird definiert, indem du ihren Typ explizit angibst.

```java
int explicitVar = 10;
```

Den Wert einer Variablen aktualisierst du mit dem `=`-Operator.
Hier steht `=` nicht für mathematische Gleichheit.
Es weist einer Variablen einfach einen Wert zu.
Sobald eine Variable definiert ist, kann sich ihr Typ nie mehr ändern.

```java
int count = 1; // Assign initial value
count = 2;     // Update to new value

// Compiler error when assigning a different type
// count = false;
```

Java ist eine [objektorientierte Sprache][object-oriented-programming] und verlangt, dass alle Funktionen in einer _Klasse_ definiert werden.
Mit dem Schlüsselwort `class` definierst du eine Klasse.

```java
class Calculator {
    // ...
}
```

Eine Funktion innerhalb einer Klasse nennt man _Methode_.
Jede Methode kann null oder mehr Parameter haben.
Alle Parameter müssen explizit typisiert sein, für Parameter gibt es keine Typinferenz.
Ebenso muss auch der Rückgabetyp explizit angegeben werden.
Mit dem Schlüsselwort `return` gibst du Werte aus Methoden zurück.
Damit andere Klassen eine Methode aufrufen können, musst du den Zugriffsmodifizierer `public` hinzufügen.

```java
class Calculator {
    public int add(int x, int y) {
        return x + y;
    }
}
```

Um eine Methode aufzurufen, gibst du ihren Klassennamen und ihren Methodennamen an und übergibst Argumente für jeden Parameter der Methode.

```java
int sum = new Calculator().add(1, 2);  // here the  "add" method has been called to perform the task of addition
```

Der Gültigkeitsbereich wird in Java zwischen den Zeichen `{` und `}` definiert.

Java unterstützt zwei Arten von Kommentaren.
Einzeilige Kommentare beginnen mit `//`, mehrzeilige Kommentare stehen zwischen `/*` und `*/`.

[object-oriented-programming]: https://docs.oracle.com/javase/tutorial/java/javaOO/index.html
