Du sollst einen Dienst schreiben, der Ereignisse entgegennimmt. Jedes Ereignis hat ein zugehöriges Datum, aber dir fällt auf, dass drei verschiedene Formate an den Endpunkt deines Dienstes geschickt werden:

- `"01/01/1970"`
- `"January 1, 1970"`
- `"Thursday, January 1, 1970"`

Du erkennst, dass es zwischen ihnen einige Gemeinsamkeiten gibt, und beschließt, einige zusammensetzbare Muster für reguläre Ausdrücke zu schreiben.

## 1. Tag, Monat und Jahr aus einem Datum abgleichen

Implementiere `day`, `month` und `year`, sodass sie ein String-Muster zurückgeben, das bei Ausführung die numerischen Bestandteile in `"01/01/1970"` (`dd/mm/yyyy`) abgleicht. Tag und Monat können als `1` oder `01` auftreten (mit führenden Nullen aufgefüllt).

Mach dir keine Gedanken über die Fehlerprüfung. Du kannst davon ausgehen, dass dir immer eine gültige numerische Komponente übergeben wird.

```clojure
(day "31")
;;=> "31"
(month "12")
;;=> "12"
(year "1970")
;;=> "1970"
```

## 2. Den Wochentag und den Monatsnamen abgleichen

Implementiere `day-name` und `month-name`, sodass sie ein String-Muster zurückgeben, das bei Ausführung jeden ausgeschriebenen Wochentag bzw. jeden ausgeschriebenen Monat abgleicht.

```clojure
(day-name "Tuesday")
;;=> "Tuesday"
(month-name "June")
;;=> "June"
```

## 3. Tag, Monat und Jahr erfassen

Implementiere `capture-day`, `capture-month`, `capture-year`, `capture-day-name` und `capture-month-name`, sodass sie eine Map zurückgeben, die die jeweiligen Bestandteile auf die Namen `"day"`, `"month"`, `"year"`, `"day-name"` und `"month-name"` abbildet.

```clojure
(capture-month-name "December")
;;=> {:month-name "December"}
```

## 4. Die erfassten Teile kombinieren, um das ganze Datum zu erfassen

Implementiere `capture-numeric-date`, `capture-month-name-date` und `capture-day-month-name-date`, sodass sie eine Map der Bestandteile aus Teil 3 im jeweiligen Datumsformat zurückgeben.

```clojure
(capture-numeric-date "01/01/1970")
;;=> {:day "01", :month "01", :year "1970"}
```
