# Einführung

Die meisten Sequenz-Wörter in Factor geben *neue* Sequenzen zurück und lassen ihre Eingaben unangetastet. Arrays und Vektoren unterstützen jedoch beide auch **Mutation an Ort und Stelle**, wenn du einen Zustand festhalten willst, der sich mit der Zeit verändert.

`set-nth` und `change-nth` ändern eine Position an Ort und Stelle und funktionieren sowohl mit einem Array als auch mit einem Vektor. `<array>` erzeugt ein veränderbares Array mit fester Länge; `V{ }`-Literale, `<vector>`, `push` und `pop` gibt es nur für Vektoren, denn Arrays können ihre Länge nicht ändern. `clone` dupliziert die Sequenz, damit weitere Mutationen nicht auf das Original durchschlagen.

```factor
USING: arrays kernel sequences ;

5 0 <array>                 ! a fresh array { 0 0 0 0 0 }
dup 7 2 swap set-nth        ! { 0 0 7 0 0 } — set position 2 to 7
.

V{ } clone                  ! a fresh, empty vector
"alice" over push           ! V{ "alice" }
"bob" over push             ! V{ "alice" "bob" }
dup pop .                   ! "bob"
.                           ! V{ "alice" }
```
