# Anleitung

In dieser Übung implementierst du die Mechaniken eines Rollenspiels.
Die Spielfigur eines Spielers wird durch den folgenden Typ dargestellt:

```elm
type alias Player =
    { name : Maybe String
    , level : Int
    , health : Int
    , mana : Maybe Int
    }
```

Spieler in diesem Spiel müssen Level 10 erreichen, bevor sie einen Manavorrat freischalten, damit sie Zauber wirken können.
Du arbeitest in diesem Spiel an zwei Mechaniken: dem Wiederbeleben und dem Zauberwirken.

## 1. Stell dich vor

Schreibe den Inhalt der `introduce`-Funktion.
Heimliche Spieler verbergen möglicherweise ihren Namen und werden als `"Mighty Magician"` vorgestellt.
Ansonsten stellst du dich einfach mit deinem Namen vor.

```elm
introduce { name = Nothing, level = 2, health = 8, mana = Nothing }
    --> "Mighty Magician"

introduce { name = Just "Merlin", level = 2, health = 8, mana = Nothing }
    --> "Merlin"
```

## 2. Implementiere die Mechanik zum Wiederbeleben

Die `revive`-Funktion sollte prüfen, dass die Spielfigur tatsächlich tot ist (ihre Gesundheit hat 0 erreicht).
Wenn ja, sollte sie eine neue `Player`-Instanz mit 100 Gesundheit zurückgeben.
Andernfalls, wenn die Spielfigur nicht tot ist, gibt die `revive`-Funktion `Nothing` zurück.

Wenn das Level des Spielers 10 oder höher ist, sollte er auch mit 100 Mana wiederbelebt werden.
Wenn das Level des Spielers unter 10 liegt, sollte sein Mana `Nothing` sein.
Die `revive`-Funktion sollte das Level des Spielers beibehalten.

```elm
deadPlayer = { name = Nothing, level = 2, health = 0, mana = Nothing }

revive deadPlayer
    --> Just { name = Nothing, level = 2, health = 100, mana = Nothing }
```

Wenn die `revive`-Methode für einen Spieler aufgerufen wird, dessen Gesundheit 1 oder höher ist, sollte die Funktion `Nothing` zurückgeben.

```elm
alivePlayer = { name = Nothing, level = 2, health = 42, mana = Nothing }

revive alivePlayer
    --> Nothing
```

## 3. Implementiere die Mechanik zum Zauberwirken

Die `castSpell`-Funktion nimmt als Argumente einen `Int`, der angibt, wie viel Mana der Zauber kostet, sowie einen `Player`.
Sie gibt den aktualisierten Spieler sowie die Menge an Schaden zurück, den der gewirkte Zauber verursacht.
Ein erfolgreich gewirkter Zauber verursacht Schaden in Höhe des Doppelten der Manakosten des Zaubers.
Wenn der Spieler jedoch nicht genug Mana hat, passiert nichts: Der Spieler bleibt unverändert und es wird kein Schaden verursacht.
Wenn der Spieler nicht einmal einen Manavorrat hat, muss der Versuch, den Zauber zu wirken, seine Gesundheit um die Manakosten des Zaubers verringern und verursacht keinen Schaden.

```elm
wizard = { name = Nothing, level = 18, health = 123, mana = Just 30 }

( updatedWizard, damage ) = castSpell 14 wizard

updatedWizard.mana --> Just 16
damage             --> 28
```
