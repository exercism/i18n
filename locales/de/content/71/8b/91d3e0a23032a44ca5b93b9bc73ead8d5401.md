# Anweisungen

In dieser Übung verwaltest du ein Inventarsystem.

Das Inventar sollte nach dem Namen der Gegenstände organisiert sein und die Anzahl der verfügbaren Gegenstände im Blick behalten.

Du musst dich um das Hinzufügen von Gegenständen zu einem Inventar kümmern.
Jedes Mal, wenn ein Gegenstand in einer gegebenen Liste auftaucht, sollte seine Menge im Inventar um `1` erhöht werden.
Außerdem musst du das Löschen von Gegenständen aus einem Inventar handhaben, indem du die Mengen auf Anfrage um `1` verringerst.

Schließlich implementierst du eine Funktion, die alle Schlüssel-Wert-Paare eines gegebenen Inventars als `list` von `tuples` zurückgibt.


## 1. Erstelle ein Inventar anhand einer Liste

Implementiere die Funktion `create_inventory(<input list>)`, die aus einer Eingabeliste von Gegenständen ein „Inventar“ erstellt.
Sie sollte ein `dict` zurückgeben, das jeden Gegenstandsnamen mit der jeweiligen Menge paart.

```python
>>> create_inventory(["coal", "wood", "wood", "diamond", "diamond", "diamond"])
{"coal":1, "wood":2, "diamond":3}
```

## 2. Füge Gegenstände aus einer Liste zu einem bestehenden Dictionary hinzu

Implementiere die Funktion `add_items(<inventory dict>, <item list>)`, die eine Liste von Gegenständen zum übergebenen Inventar hinzufügt:

```python
>>> add_items({"coal":1}, ["wood", "iron", "coal", "wood"])
{"coal":2, "wood":2, "iron":1}
```

## 3. Verringere Gegenstände im Inventar

Implementiere die Funktion `decrement_items(<inventory dict>, <items list>)`, die eine `list` von Gegenständen entgegennimmt.
Deine Funktion sollte `1` von der Anzahl eines Gegenstands für jedes Mal abziehen, wenn dieser Gegenstand in der `list` auftaucht:

```python
>>> decrement_items({"coal":3, "diamond":1, "iron":5}, ["diamond", "coal", "iron", "iron"])
{"coal":2, "diamond":0, "iron":3}
```

Die Anzahl der Gegenstände im Inventar darf nicht unter 0 fallen.
 Wenn die Anzahl, mit der ein Gegenstand in der Eingabe-`list` auftaucht, die verfügbare Menge übersteigt, sollte die für diesen Gegenstand angegebene Menge bei 0 bleiben.
 Weitere Anfragen zum Verringern der Anzahl sollten ignoriert werden, sobald die Anzahl auf null fällt.

```python
>>> decrement_items({"coal":2, "wood":1, "diamond":2}, ["coal", "coal", "wood", "wood", "diamond"])
{"coal":0, "wood":0, "diamond":1}
```

## 4. Entferne einen Eintrag vollständig aus dem Inventar

Implementiere die Funktion `remove_item(<inventory dict>, <item>)`, die einen Gegenstand und seine Anzahl vollständig aus einem Inventar entfernt:

```python
>>> remove_item({"coal":2, "wood":1, "diamond":2}, "coal")
{"wood":1, "diamond":2}
```

Wenn der Gegenstand im Inventar nicht gefunden wird, sollte die Funktion das ursprüngliche Inventar unverändert zurückgeben.

```python
>>> remove_item({"coal":2, "wood":1, "diamond":2}, "gold")
{"coal":2, "wood":1, "diamond":2}
```

## 5. Gib den gesamten Inhalt des Inventars zurück

Implementiere die Funktion `list_inventory(<inventory dict>)`, die ein Inventar entgegennimmt und eine Liste mit `(item, quantity)`-Tupeln zurückgibt.
Die Liste sollte nur die _verfügbaren_ Gegenstände enthalten (_mit einer Menge größer als null_):

```python
>>> list_inventory({"coal":7, "wood":11, "diamond":2, "iron":7, "silver":0})
[('coal', 7), ('diamond', 2), ('iron', 7), ('wood', 11)]
```
