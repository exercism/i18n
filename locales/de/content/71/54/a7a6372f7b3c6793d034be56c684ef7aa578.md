# Anweisungen

Als angehende Zauberin muss Elyse ein paar Grundlagen üben.
Sie hat einen Stapel Karten, den sie manipulieren möchte.

Um es etwas einfacher zu machen, benutzt sie nur die Karten 1 bis 10.

## 1. Einen Slice mit bestimmten Karten erstellen

Beim Üben mit ihren Karten beginnt Elyse am liebsten mit ihren drei Lieblingskarten des Decks: 2, 6 und 9.
Schreibe eine Funktion `FavoriteCards`, die einen Slice mit diesen Karten in dieser Reihenfolge zurückgibt.

```go
cards := FavoriteCards()
fmt.Println(cards)
// Output: [2 6 9]
```

## 2. Eine Karte aus einem Stapel abrufen

Gib die Karte an der Position `index` aus dem gegebenen Stapel zurück.

```go
card := GetItem([]int{1, 2, 4, 1}, 2) // card == 4
```

Wenn der Index außerhalb des gültigen Bereichs liegt (also negativ ist oder hinter dem Ende des Stapels), möchten wir `-1` zurückgeben:

```go
card := GetItem([]int{1, 2, 4, 1}, 10) // card == -1
```

~~~~exercism/note
Nach Konvention in Go gibt man einen Fehler zurück, statt einen „out-of-bounds"-Wert zurückzugeben.
Hier ist der „out-of-bounds"-Wert `-1`, wenn eine positive Ganzzahl erwartet wird.
Wenn man einen Fehler zurückgibt, gilt es als idiomatisch, den [`zero value`](https://www.geeksforgeeks.org/zero-value-in-golang/) zusammen mit dem Fehler zurückzugeben.
Einen Fehler mit dem passenden Rückgabewert zurückzugeben, wird in einer späteren Übung behandelt.
~~~~

## 3. Eine Karte im Stapel austauschen

Tausche die Karte an der Position `index` gegen die angegebene neue Karte aus und gib den angepassten Stapel zurück.
Beachte, dass dies den Eingabe-Slice verändert, was das erwartete Verhalten ist.

```go
index := 2
newCard := 6
cards := SetItem([]int{1, 2, 4, 1}, index, newCard)
fmt.Println(cards)
// Output: [1 2 6 1]
```

Wenn der Index außerhalb des gültigen Bereichs liegt (also negativ ist oder hinter dem Ende des Stapels), möchten wir die neue Karte am Ende des Stapels anhängen:

```go
index := -1
newCard := 6
cards := SetItem([]int{1, 2, 4, 1}, index, newCard)
fmt.Println(cards)
// Output: [1 2 4 1 6]
```

## 4. Karten oben auf den Stapel legen

Füge die im Parameter `value` angegebenen Karten oben auf den Stapel hinzu.

```go
slice := []int{3, 2, 6, 4, 8}
cards := PrependItems(slice, 5, 1)
fmt.Println(cards)
// Output: [5 1 3 2 6 4 8]
```

Wenn kein Argument für den Parameter `value` angegeben wird, dann entspricht das Ergebnis dem ursprünglichen Slice.

```go
slice := []int{3, 2, 6, 4, 8}
cards := PrependItems(slice)
fmt.Println(cards)
// Output: [3 2 6 4 8]
```

## 5. Eine Karte aus dem Stapel entfernen

Entferne die Karte an der Position `index` aus dem Stapel und gib den Stapel zurück.
Beachte, dass dies den Eingabe-Slice verändern kann, was in Ordnung ist.

```go
cards := RemoveItem([]int{3, 2, 6, 4, 8}, 2)
fmt.Println(cards)
// Output: [3 2 4 8]
```

Wenn der Index außerhalb des gültigen Bereichs liegt (also negativ ist oder hinter dem Ende des Stapels), möchten wir den Stapel unverändert lassen:

```go
cards := RemoveItem([]int{3, 2, 6, 4, 8}, 11)
fmt.Println(cards)
// Output: [3 2 6 4 8]
```
