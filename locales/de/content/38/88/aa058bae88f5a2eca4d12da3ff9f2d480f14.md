# Überblick

Swift bietet einen eingebauten Typ namens [`Bool`][bools], um Wahrheitswerte darzustellen: `true` und `false`.

## Logische Operatoren

Swift bietet drei [logische Operatoren][logical-operators] (`!`, `&&` und `||`), um boolesche Ausdrücke zu kombinieren und auszuwerten.

### Logisches UND (`&&`)

Der [_Und_-Operator][and] (`&&`) gibt nur dann `true` zurück, wenn beide Operanden `true` sind.
Ist einer der Operanden `false`, gibt er `false` zurück.
Setze auf jede Seite des `&&`-Symbols einen Ausdruck oder einen booleschen Wert:

```swift
true && true  // true
true && false // false
```

### Logisches ODER (`||`)

Der [_Oder_-Operator][or] (`||`) gibt `true` zurück, wenn **mindestens einer** der Operanden `true` ist.
Er gibt nur dann `false` zurück, wenn beide Operanden `false` sind.
Setze auf jede Seite des `||`-Symbols einen Ausdruck oder einen booleschen Wert:

```swift
true || true   // true
true || false  // true
false || false // false
```

### Logisches NICHT (`!`)

Der [_Nicht_-Operator][not] (`!`) kehrt einen booleschen Wert um.
Er gibt `true` zurück, wenn der Wert `false` ist, und `false`, wenn der Wert `true` ist.
Setze den `!`-Operator direkt vor den Wert oder den Ausdruck:

```swift
!true  // false
!false // true
```

## Runde Klammern verwenden (`()`)

Mit [runden Klammern][explicit-parentheses] kannst du Ausdrücke gruppieren und die Reihenfolge der Auswertung steuern.
In Swift werden Ausdrücke in runden Klammern zuerst ausgewertet:

```swift
true && false && false || true   // true
true && false && (false || true) // false
```

Die Gruppierung mit runden Klammern bestimmt auch, wie der NICHT-Operator auf komplexe Ausdrücke angewendet wird:

```swift
!true && false   // false (evaluates (!true) first, then false && false)
!(true && false) // true  (evaluates (true && false) first to false, then !false)
```

~~~~exercism/note
Nutze runde Klammern, wenn du die Auswertungsreihenfolge verdeutlichen oder komplexe Bedingungen lesbarer machen willst.
Vermeide überflüssige Klammern, wenn die Standardrangfolge ohnehin klar ist.
~~~~
