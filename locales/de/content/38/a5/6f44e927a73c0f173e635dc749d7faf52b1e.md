# Einführung

## Fehler

Fehler sind nützlich, um zu melden, wenn in einem Programm oder einem Codeabschnitt etwas schiefgeht oder unerwartet passiert.

Es sind JavaScript-Objekte.

Die wichtigste Eigenschaft dieses Objekts ist `message`:

```javascript
const error = new Error('Oops, something went wrong');

console.log(error.message);
// => "Oops, something went wrong"
```

Mit der `throw`-Syntax kannst du einen Error werfen.

```javascript
throw new Error('Oops');
```

Wenn ein Fehler geworfen wird, wird die aktuelle Ausführung gestoppt und im ersten catch-Block des Aufrufstapels fortgesetzt.

```javascript
try {
  throw new Error('Oops');
} catch (error) {
  console.log(error.message);
  // => "Oops"
}
```

## Vererbung

Vererbung ist eine Möglichkeit, Eltern-Kind-Beziehungen zwischen Klassen herzustellen.
Die Kindklasse (manchmal auch _Unterklasse_ genannt) hat Zugriff auf das Verhalten und die Daten, die von der Elternklasse (manchmal auch _Oberklasse_ genannt) definiert werden.

```javascript
class Pet {
  constructor(name) {
    this.name = name;
  }

  introduce() {
    console.log(`This is my pet, ${this.name}.`);
  }
}

class Dog extends Pet {}

const dog = new Dog('Otis');
dog.introduce();
// => This is my pet, Otis.
```

Das Schlüsselwort `extends` in der Deklaration der Kindklasse stellt über die [Prototypkette][prototype-chain] eine Beziehung zur Elternklasse her.

Objekte, die vom Konstruktor der Kindklasse erzeugt werden, haben das Prototyp der Elternklasse in ihrer Prototypkette und erhalten dadurch Zugriff auf alle Methoden und Daten, die von der Elternklasse definiert werden.

```javascript
const dog = new Dog('Otis');

Dog.prototype.isPrototypeOf(dog); // => true
Pet.prototype.isPrototypeOf(dog); // => true
Pet.prototype.isPrototypeOf(Dog.prototype); // => true

Pet.prototype.hasOwnProperty('introduce'); // => true
Dog.prototype.hasOwnProperty('introduce'); // => false
dog.hasOwnProperty('introduce'); // => false
```

Wie bei jeder Klasse in JavaScript können Unterklassen mithilfe des Schlüsselworts `extends` von `Error` erben, um eigene Fehler zu erstellen.
Die `instanceof`-Syntax prüft, ob der gefangene Fehler eine Instanz einer bestimmten Unterklasse von `Error` ist.

```javascript
class CustomError extends Error {}

try {
  // ... Code that may throw an error
} catch (error) {
  if (error instanceof CustomError) {
    console.log('The error thrown is an instance of the CustomError');
  }
}
```

[prototype-chain]: https://developer.mozilla.org/en-US/docs/Web/JavaScript/Inheritance_and_the_prototype_chain
