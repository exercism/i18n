# Anhang zur Anleitung

## Trackspezifische Hinweise

Es gibt eine eingebaute Funktion, die das fast für dich erledigt, und es ist keine Schande, sie zu benutzen.
(Natürlich ist es auch keine Schande, diese Aufgabe mit vollständig ausgeschriebenem, langatmigem Code zu lösen.)
Tipp: Die eingebaute Funktion gibt `{1}` statt der `{}` zurück, die diese Übung verlangt, und du müsstest beide Standardparameter überschreiben, damit sie das Richtige zurückgibt.
