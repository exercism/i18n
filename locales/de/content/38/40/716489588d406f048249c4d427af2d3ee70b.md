# Sprachliste

## Story

Diese Story erleichtert die Erkundung von [Listen][types-list] in einer Programmiersprache.

Die Grundidee ist, dass jemand auf der Website von Exercism eine [Liste][types-list] mit Sprachen pflegen möchte, die er lernen will.

## Aufgaben

Die Übung zeigt den Lernenden im Allgemeinen, wie sie:

- eine Liste erstellen.
- etwas zu einer Liste hinzufügen.
- etwas aus einer Liste entfernen.
- die Länge einer Liste ermitteln.
- das erste Element einer Liste abrufen.
- prüfen, ob ein Element in einer Liste enthalten ist.
