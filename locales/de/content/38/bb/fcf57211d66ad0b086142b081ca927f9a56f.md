# Einführung

## Methodenüberladung

In Java ist die Methodenüberladung ein Feature, das einer Klasse erlaubt, mehr als eine Methode mit demselben Namen zu haben, wenn sich ihre Parameterlisten unterscheiden.
Sie hängt mit der Polymorphie zur Compile-Zeit (oder statischen Polymorphie) zusammen.
Dieses Konzept ist entscheidend, um
Methoden zu erstellen, die ähnliche Aufgaben erledigen, aber mit unterschiedlichen Eingabewerten.

### Warum Methoden überladen?

Methodenüberladung erhöht die Lesbarkeit des Programms.
Verschiedene Methoden können denselben Namen bekommen, aber
unterschiedliche Parameter haben.
Je nach Anzahl oder Typ der Parameter wird die passende Methode aufgerufen.

### Wie überlädt man Methoden?

Der Schlüssel zur Methodenüberladung ist die Signatur einer Methode.
Zwei Methoden gelten als unterschiedlich, wenn sie unterschiedliche Signaturen haben.
Es gibt zwei Möglichkeiten, eine Methode zu überladen:

1. **Unterschiedliche Anzahl an Parametern**: Methoden können denselben Namen haben, aber eine unterschiedliche Anzahl an Parametern.

   ```java
   public class Display {

       public void show(int x) {
           System.out.println("Show with int: " + x);
       }

       public void show(int x, int y) {
           System.out.println("Show with two ints: " + x + ", " + y);
       }
   }
   ```

2. **Unterschiedliche Parametertypen**: Methoden können denselben Namen und dieselbe Anzahl an Parametern haben, aber
   unterschiedliche Typen.

   ```java
   public class Display {

       public void show(int x) {
           System.out.println("Show with int: " + x);
       }

       public void show(String s) {
           System.out.println("Show with String: " + s);
       }
   }
   ```

### Dinge, die du dir merken solltest

- Überladene Methoden müssen die Argumentliste ändern.
- Überladene Methoden können auch den Rückgabetyp ändern, aber eine bloße Änderung des Rückgabetyps ist noch keine
  Methodenüberladung.
- Methoden können in derselben Klasse oder in einer Unterklasse überladen werden.
