## Editoren

### Kostenlos/Open Source

- [VS Code](https://code.visualstudio.com)

  VS Code ist ein quelloffener Code-Editor. Wie du TypeScript einrichtest, erfährst du [hier](https://code.visualstudio.com/docs/languages/typescript). VS Code ist ein beliebter Editor für TypeScript, weil Microsoft sowohl VS Code als auch TypeScript pflegt und beides daher gut zusammenpasst; VS Code unterstützt TS ohne zusätzliche Konfiguration. Tatsächlich wurde VS Code in TypeScript geschrieben!

  Ein häufiges Problem mit VS Code und TS ist, dass die Versionen von Editor und Projekt unterschiedlich sind. Dann zeigt VS Code unter Umständen eine verwirrende Fehlermeldung an. Wie du mit diesem Fehler umgehst, steht [hier](https://code.visualstudio.com/docs/typescript/typescript-compiling#_using-newer-typescript-versions)

### Kostenpflichtig

- [Sublime Text](https://www.sublimetext.com)

  Sublime Text ist ein beliebter Code-Editor, der die meisten Sprachen über installierbare Plugins unterstützt. Du kannst ihn kostenlos testen, aber du wirst regelmäßig daran erinnert, eine Lizenz zu kaufen, die derzeit \$70 USD kostet.

- [WebStorm](https://www.jetbrains.com/webstorm/)

  WebStorm ist eine voll ausgestattete JavaScript/TypeScript-IDE (integrierte Entwicklungsumgebung). Sie unterstützt TypeScript ohne zusätzliche Konfiguration und bietet integrierte Tests, Debugging und Codeanalyse. Du kannst sie 30 Tage lang kostenlos testen, danach kostet eine Jahreslizenz im ersten Jahr \$129 USD.
