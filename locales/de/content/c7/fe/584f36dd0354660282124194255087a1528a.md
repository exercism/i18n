# Überblick

In einer rein funktionalen Sprache wie Elm muss eine Funktion, die mit denselben Argumenten aufgerufen wird, immer denselben Wert zurückgeben.
Deshalb lässt sich eine Funktion mit der Typsignatur `rand : Int` nur als (`rand = 4`)[xkcd-random] implementieren, was für das Erzeugen zufälliger Ganzzahlen nichts Gutes verheißt.

Wie erzeugen wir also zufällige Werte in Elm?
Wir teilen das Problem in zwei Teile: Zuerst beschreiben wir den Wert, den wir erzeugen wollen, mit einem `Random.Generator a`, dann erzeugen wir einen Wert.

Der erste Weg, einen Wert zu erzeugen, ist, über `initialSeed : Int -> Seed` einen `Random.Seed` zu erstellen.
Ein `Seed` ist ein opaker Typ, der eine Ganzzahl enthält und weiß, wie er diese Ganzzahl so umwandeln kann, dass sie zufällig erscheint (man nennt das pseudozufällig).
Sobald du einen `Seed` hast, kannst du ihn verwenden, um mit einem `Generator a` einen Wert zu erzeugen.
Ein `Generator a` ist ein opaker Typ, der weiß, wie er die Ganzzahl in einem Seed verwendet, um einen pseudozufälligen Wert vom Typ `a` sowie einen neuen Seed mit einer aktualisierten Ganzzahl zu erstellen.

Um einen Wert zu erzeugen, können wir `step : Generator a -> Seed -> ( a, Seed )` verwenden. Diese Funktion gibt einen Wert und einen neuen Seed zurück, den wir verwenden können, um weitere Werte zu erzeugen.

Verwenden wir diese Funktionen, um `n` zufällige Werte aus einem Generator zu extrahieren:

```elm
generate : Int -> Generator a -> List a
generate n generator = generateValuesFromSeed n generator (Random.initialSeed 42)

generateValuesFromSeed : Int -> Generator a -> Seed -> List a
generateValuesFromSeed n generator seed =
    if n <= 0 then
        []
    else
        let ( value, nextSeed ) = Random.step generator seed
        in value :: generateValuesFromSeed (n - 1) generator nextSeed
```

Beachte, dass alle diese Funktionen rein sind. Wenn du sie zweimal mit denselben Argumenten aufrufst, erzeugen sie dieselben Werte.

```elm
generate 10 (Random.int 1 6)
    --> [4, 5, 3, 3, 5, 1, 2, 4, 6, 6]

generate 10 (Random.int 1 6)
    --> [4, 5, 3, 3, 5, 1, 2, 4, 6, 6]
```

Der zweite Weg, einen Wert zu erzeugen, ist die Verwendung von `Random.generate : (a -> msg) -> Generator a -> Cmd msg`. Das geht allerdings nur innerhalb einer Elm-Anwendung.
In diesem Fall kann die Elm-Laufzeitumgebung sowohl `step` als auch äußere, nicht-reine Ressourcen verwenden, um Seeds zu erzeugen. Wenn du dieselbe Funktion zweimal aufrufst, erhältst du unterschiedliche Ergebnisse.

Von nun an konzentrieren wir uns auf Generatoren.

Das Modul `Random` bietet zwei grundlegende Generatoren, um Ganzzahlen und Gleitkommazahlen innerhalb eines bestimmten Bereichs zu erzeugen:

```elm
generate 5 (Random.int -5 5)
    --> [0, 3, -5, 5, 0]

generate 3 (Random.float 0 5)
    --> [1.61803, 3.14159, 2.71828]
```

Diese Werte lassen sich zu Tupeln oder zu Listen von Werten kombinieren:

```elm
generate 2 (Random.list 3 (Random.int 0 3))
    --> [[0, 3, 3], [1, 3, 2]]

generate 2 (Random.pair (Random.int 0 3) (Random.float 10 10.3))
    --> [(0, 10.23412), (2, 10.17094)]
```

Das Paket (`elm-community/random-extra`)[random-extra] bietet viel mehr Generatoren für verschiedene Datenstrukturen: Strings, Datumsangaben, Wörterbücher, Arrays, Mengen usw.

Mit `Random.constant` können wir Generatoren erstellen, die nur einen einzigen Wert zurückgeben:

```elm
generate 4 (Random.constant "hello")
    --> ["hello", "hello", "hello", "hello"]
```

Mit `Random.uniform` können wir mit gleicher Wahrscheinlichkeit zufällig aus den gegebenen Elementen auswählen:

```elm
generate 5 (Random.uniform Red [Green, Blue])
    --> [Red, Blue, Blue, Green, Red]
```

`Random.uniform` nimmt zwei Argumente (`Red` und `[Green, Blue]`), um zu garantieren, dass es mindestens einen Wert zur Auswahl gibt, da eine einzelne Liste leer sein könnte.

Wir können die Wahrscheinlichkeiten auch mit `Random.weighted` anpassen:

```elm
generate 5 (Random.weighted (80, Red) [(15, Green), (5, Blue)])
    --> [Red, Red, Green, Red, Red]
```

Die Werte müssen sich nicht zu 100 addieren, sie werden ohnehin neu normalisiert.

Mit `Random.map` können wir in das Innere eines Generators gelangen:

```elm
generate 3 (Random.int 1 6 |> Random.map (\n -> n * 10))
    --> [30, 60, 10]
```

Wir können auch `Random.map2` bis hin zu `Random.map5` verwenden, um mehr Generatoren zu kombinieren:

```elm
position =
    Random.map3
      (\x y z -> Position x y z)
      (Random.float -100 100)
      (Random.float -100 100)
      (Random.float -100 100)

generate 1 position
    --> [Position 33.788 -98.321 10.0845]
```

Für komplexere Anwendungsfälle gibt es `Random.andThen : (a -> Generator b) -> Generator a -> Generator b`. Damit kann der von einem Generator erzeugte Wert verwendet werden, um einen anderen zu erstellen:

```elm
bool = Random.uniform True [False]

failHalfOfTheTime : Generator a -> Generator (Maybe a)
failHalfOfTheTime generator =
    bool
        |> Random.andThen
            (\boolResult ->
                if boolResult then
                    Random.map Just generator

                else
                    Random.constant Nothing
            )

generate 6 (Random.int 0 1 |> failHalfOfTheTime)
    --> [Nothing, Just 1, Just 0, Nothing, Just 1, Nothing]
```

Manchmal ist es nützlich, einen Generator selbstrekursiv zu definieren.
In solchen Fällen musst du möglicherweise `Random.lazy` verwenden, um den Compiler davon abzuhalten, den Generator unendlich weit zu entfalten.

```elm
type Peano
    = Zero
    | Next Peano


peano : Generator Peano
peano =
    Random.uniform (Random.constant Zero)
        [ Random.map Next (Random.lazy (\_ -> peano))
        ]
        |> Random.andThen identity

generate 12 peano
    --> [Zero, Next(Next(Zero)), Zero, Next(Zero), Zero, Zero, Next(Zero), Zero, Zero, Next(Zero), Next(Next(Next(Zero)))]
```

Dieses Beispiel ist etwas schwer, also gehen wir es Schritt für Schritt durch.

`Peano` ist ein Typ, der positive Ganzzahlen darstellt: `Zero` ist 0, `Next(Zero)` ist 1, `Next(Next(Zero))` ist 2, usw.
Wir definieren `peano`, um eine zufällige `Peano`-Zahl zu erhalten.

Beachte zunächst, dass `Random.lazy` nichts zur Logik beiträgt. Es verhindert lediglich, dass der Compiler `peano` endlos in `peano` einsetzt.

Wir verwenden `Random.uniform`, um zwischen null (mit 50 % Wahrscheinlichkeit) und einer anderen `Peano`-Zahl plus eins (mit 50 % Wahrscheinlichkeit) auszuwählen.
Anders als im vorherigen Beispiel wählt `Random.uniform` jedoch nicht aus Werten (wie `Zero`) aus, sondern aus Generatoren (wie `Random.constant Zero`), da wir `peano` selbst verwenden wollen.
Das bedeutet, dass `Random.uniform` einen Wert vom Typ `Generator (Generator Peano)` zurückgibt, was nicht das ist, was wir brauchen.

Um den Generator zu „abflachen“, leiten wir ihn in `Random.andThen : (a -> Generator b) -> Generator a -> Generator b` weiter, wobei `b` gleich `Peano` sein soll.
Da `Generator a` gleich `Generator (Generator Peano)` ist, muss `a` gleich `Generator Peano` sein, und die Funktion `(a -> Generator b)` muss vom Typ `(Generator Peano -> Generator Peano)` sein.
Wir wollen nichts verändern, also ist `identity` die richtige Wahl.

Und schließlich: Was für Zahlen wird `peano` erzeugen?
Wir wissen, dass es in 50 % der Fälle 0 erzeugt, oder in 50 % der Fälle eine weitere Iteration von sich selbst plus eins.
Das bedeutet, die Zahlen sind 0 (in 50 % der Fälle), 1 (in 25 % der Fälle), 2 (in 12 % der Fälle), 3 (in 6 % der Fälle) usw.
`peano` kann beliebig große Zahlen erzeugen, aber mit exponentiell abnehmender Wahrscheinlichkeit.
