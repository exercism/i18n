# Hinweise

## Allgemein

- Jeder Name hier endet auf `!`, und jeder übergibt Werte mit `yield` statt mit `return`.
- Markiere die Argumente mit `once`. Hier soll kein Argument bei jedem Durchlauf neu ausgewertet werden.
- Teste einen, indem du eine Schleife darum herum schreibst. Ein Iterator kann nicht allein aufgerufen werden, also gibt es ohne `loop` nichts auszugeben.

## 1. Die Markierungen

- Eine `loop` im Iterator, gesteuert von `1.upto!(count)`, die die Zahl `spacing`-mal übergibt.
- Für eine Anzahl von null ist nichts Besonderes nötig: `1.upto!(0)` liefert nichts, also endet die innere Schleife sofort und der Iterator ist vorbei.

## 2. Bis die Strecke endet

- Durchlaufe das Array mit `elt!` und `quit`, wenn der Wert `"end"` ist.
- Die Reihenfolge ist wichtig: `quit` vor dem `yield`, sonst wird `"end"` noch übergeben, bevor du stoppst.
- Für ein Array ohne `"end"` ist nichts nötig. Das `elt!` läuft aus und der Iterator ist vorbei.

## 3. Nur die Vögel

- Durchlaufe das Array und `yield` nur innerhalb eines `if`. Ein Durchlauf, der nichts übergibt, läuft einfach weiter. Ein Iterator muss nicht bei jedem Durchlauf etwas übergeben.
- Ein Name beginnt mit einem Großbuchstaben, wenn sein erstes Zeichen `.is_upper` ist.
- Prüfe auf einen leeren String, bevor du auf sein erstes Zeichen zugreifst.

## 4. Nummeriert

- Zwei Iteratoren in deinem eigenen Iterator: `1.up!` für die Nummer und `elt!` für die Sichtung. Das ist das Paar aus `duet-practice`, jetzt in etwas, das du selbst geschrieben hast.
- Baue den String mit `+` zusammen. Die Zahl kommt zuerst, also beginne mit `number.str`, denn zu einem String lässt sich eine Zahl addieren, aber nicht umgekehrt.
