Blöcke werden in Raku großzügig verwendet.
Sie sind grundlegend für Funktionen, aber auch in Tools wie `grep` und `map`, als Blöcke von `if`-, `for`-, `while`- und `given`-Anweisungen und sogar als Array-Indizes.

## Routinen

[`Subs`][type/Sub] und [`Methods`][type/Method] sind Typen von [`Routines`][type/Routine] in Raku.

Du kannst eine Routine jederzeit mit einem Rückgabewert über das Schlüsselwort [`return`][control-return] verlassen, ein nützliches Werkzeug zum Erstellen von Funktionen.
Wenn kein `return` angegeben wird, ist die letzte Anweisung der Routine ihr impliziter Rückgabewert.

Eine Routine kann eine [`Signature`][language/signatures] in runden Klammern vor dem Block haben.

[`Routine`][type/Routine] ist eine Unterklasse von [`Block`][type/Block].

```raku
sub add ($x, $y --> Int) { return $x + $y }
say add(1, 2); # 3
```

Methoden werden in einem separaten Konzept zu Klassen und Objekten behandelt.

## Blöcke

Ein [`Block`][type/Block] ist ein wiederverwendbares Codeobjekt, das typischerweise zum Erstellen von Lambdas verwendet wird.

Die letzte Anweisung eines Blocks ist sein impliziter Rückgabewert.

Ein Block kann eine [`Signature`][language/signatures] haben, der `->` vorangestellt ist.

[`Block`][type/Block] ist eine Unterklasse von [`Code`][type/Code], der ultimativen Basisklasse aller Codeobjekte in Raku.

```raku
my $add = -> $x, $y { $x + $y };
say $add(1, 2); # 3
```

## Signaturen

Eine [`Signature`][language/signatures] besteht aus null oder mehr [`Parameters`][type/Parameter], die durch Kommas getrennt sind.

Am Ende einer Signatur kann mit einem [Rückgabetyp-Pfeil][signatures-return-type-arrow] `-->` ein Rückgabetyp angegeben werden.

Eine Signatur kann verwendet werden, um die Argumente anzugeben, die ein `Block` akzeptiert.

Dieses Konzept hält Signaturen einfach: nur positionale Parameter mit Variablen, die ein Skalar-Sigil tragen, und einen Rückgabetyp.
Darauf wird in anderen Konzepten näher eingegangen.

## Multi-Dispatch

Raku erlaubt es, mehrere Routinen mit demselben Namen, aber unterschiedlichen Signaturen zu schreiben, indem du das Schlüsselwort `multi` verwendest.
Dieses Feature ist als [Multi-Dispatch][multi-dispatch] bekannt.
Wenn die Routine über ihren Namen aufgerufen wird, bestimmt die Laufzeitumgebung den passenden Kandidaten und ruft ihn auf.

Darauf wird in einem Konzept zu Typen ausführlicher eingegangen.

```raku
multi foo () { say 'No arguments given'}

multi foo ($bar) { say "One argument given: $bar" }
```

## WhateverCode

Wenn du einen [`Whatever`][type/Whatever]-Stern `*` in Kombination mit den meisten Operatoren verwendest, wird ein [`WhateverCode`][type/WhateverCode]-Objekt erstellt.
So kannst du Blöcke mit einer einfacheren Syntax erstellen.

```raku
# These will all give code blocks that increment a single argument by 1:
-> $x { $x  + 1 }; # Explicit signature
      { $^x + 1 }; # Signature via placeholder variable
      { $_  + 1 }; # Topic variable
          * + 1;   # WhateverCode
```
