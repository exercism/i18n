## Tupel

[Tupel][tuple] werden häufig verwendet, um Informationen zu gruppieren. Sie unterscheiden sich von Listen darin, dass sie eine feste Größe haben und verschiedene Datentypen enthalten können.
Tupel erstellst du mit runden Klammern `()` und sie werden oft genutzt, um mehrere Werte aus einer Funktion zurückzugeben.

```haskell
tuple = (1, "abc", False)
```

Das ist zum Beispiel nützlich, wenn du eine Koordinate in einem 2D-Raum speichern willst. Dann weißt du, dass das Tupel immer zwei Elemente hat: die x- und die y-Koordinate.

```haskell
coordinate = (3, 4)
```

### Auf Elemente zugreifen

Oft arbeitest du mit kurzen Tupeln. Auf ihre Elemente kannst du mit den Funktionen `fst` und `snd` zugreifen.

```haskell
x = fst coordinate
-- x = 3
y = snd coordinate
-- y = 4
```

## Mustervergleich

Wenn du Haskell-Funktionen schreibst, kannst du einen [assertiven Stil][assertive-style] mit [Mustervergleich][pattern-match-doc] verwenden:
Der Mustervergleich ist eine sehr mächtige Funktion von Haskell. Er erlaubt es dir, Datenkonstruktoren abzugleichen und Variablen an die darin enthaltenen Werte zu binden.
Wie der Name schon sagt, gleichen wir Werte mit Mustern ab. Passt der Wert zum Muster, können wir Variablen an die Werte innerhalb des Musters binden.
Der Mustervergleich baut im Wesentlichen auf diesen Konzepten auf: Werte erkennen, Variablen binden und Werte zerlegen.

Nimm zum Beispiel diese Funktion:

```haskell
lucky :: Int -> String
lucky 7 = "Lucky number seven!"
lucky x = "Sorry, you're out of luck, pal!"
```

Hier haben wir eine Funktion `lucky`, die einen `Int` entgegennimmt und einen `String` zurückgibt.
Wir haben zwei Muster für die Funktion definiert: eines, das zur Zahl `7` passt, und eines, das zu jeder anderen Zahl passt. Der Name kann beliebig sein (solange er der Haskell-Namenskonvention folgt), aber wir verwenden hier `x`.
Ist die Zahl `7`, gibt die Funktion `"Lucky number seven!"` zurück, andernfalls `"Sorry, you're out of luck, pal!"`.
Wichtig ist, dass die Muster von oben nach unten geprüft werden. Hätten wir die Reihenfolge der Muster vertauscht, würde die Funktion immer `"Lucky number seven!"` zurückgeben.

### Listenmuster

Ein sehr häufiges Muster ist der Abgleich auf Listen, indem du den Kopf und den Rest der Liste nimmst.
Das liegt daran, dass Listen als verkettete Liste aufgebaut sind.
Hier ist ein Beispiel für eine Funktion, die den Kopf und den Rest einer Liste zurückgibt:

```haskell
headAndTail :: [Int] -> (Int, [Int])
headAndTail [] = error "Can't call head on an empty list"
headAndTail (x:xs) = (x, xs)
```

Wir haben hier zwei Muster: eines, das zu einer leeren Liste passt, und eines, das zu einer Liste mit mindestens einem Element passt.
Denn wenn die Liste leer ist, brauchen wir einen Fall dafür, sonst bekämen wir einen Laufzeitfehler.
Ist die Liste nicht leer, können wir den Kopf der Liste an `x` und den Rest der Liste an `xs` binden.
Das machen wir mit dem `:`-Operator (cons), der ein Element vorne an eine Liste anhängt.
Beim Mustervergleich erlaubt er uns aber, eine Liste in ihren Kopf und ihren Rest zu zerlegen, also gewissermaßen das Gegenteil.

`xs` ist ein gebräuchlicher Name für den Rest einer Liste und macht deutlich, dass es sich um eine Liste handelt. Arbeitest du mit einer verschachtelten Liste, kannst du `xss` verwenden, um deutlich zu machen, dass es eine Liste von Listen ist.

### Tupelmuster

Wie bei Listen können wir auch Tupel abgleichen.
Hier ist ein Beispiel für eine Funktion, die ein Tupel entgegennimmt und das erste und zweite Element zurückgibt:

```haskell
sumTuple :: (Int, Int) -> Int
sumTuple (x, y) = x + y
```

Hier haben wir ein Muster, das zu einem Tupel mit zwei Elementen passt: Das erste Element wird an `x` gebunden und das zweite an `y`.

### Wildcard-Muster

Manchmal interessiert uns der Wert einer Variablen nicht, wir wollen nur das Muster abgleichen.
Dafür gibt es das Wildcard-Muster, das durch einen Unterstrich `_` dargestellt wird.

Hier ist ein Beispiel für eine Funktion, die das erste Element einer Liste zurückgibt:

```haskell
head' :: [Int] -> Int
head' [] = error "Can't call head on an empty list"
head' (x:_) = x
```

Hier sagen wir, dass wir den Rest der Liste nicht brauchen, also verwenden wir das Wildcard-Muster, um ihn zu ignorieren.

### Typpmuster

Wir können auch auf Typen abgleichen, und zwar mit dem Konstruktor des jeweiligen Typs.
Außerdem können wir Werte aus dem Typ herausziehen, so wie wir es bei Tupeln gemacht haben.

```haskell
data AccountType = Guest | User String 

greet :: AccountType -> String
greet Guest = "Welcome, guest!"
greet (User name) = "Welcome, " ++ name ++ "!"
```

Im ersten Muster gleichen wir auf den Konstruktor `Guest` ab, im zweiten auf den Konstruktor `User`, wobei wir den darin enthaltenen Wert an `name` binden.
