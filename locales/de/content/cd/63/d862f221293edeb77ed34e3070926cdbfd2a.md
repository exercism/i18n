# Konstante auf oberster Ebene extrahieren

Anstatt die Konstante _innerhalb_ der Funktion zu definieren, kannst du sie auf die oberste Ebene auslagern. Konstanten, Funktionen und Klassen, die nicht `export`iert werden, sind von außerhalb der Datei nicht erreichbar.

```javascript
const %{name} = %{value}

export const gigasecond = (...)
```
