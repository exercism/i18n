# Anleitung

Jeder von uns erbt von seinen biologischen Eltern eine Reihe chemischer Anweisungen, die als DNA bekannt sind und die beeinflussen, wie unser Körper aufgebaut wird. Alles bekannte Leben hängt von der DNA ab!

> Hinweis: Du musst nichts über Nukleotide oder DNA verstehen, um diese Übung zu lösen.

Die DNA ist eine lange Kette aus anderen Chemikalien, und die wichtigsten davon sind die vier Nukleotide Adenin, Cytosin, Guanin und Thymin. Eine einzelne DNA-Kette kann Milliarden dieser vier Nukleotide enthalten, und die Reihenfolge, in der sie vorkommen, ist wichtig!
Die Reihenfolge dieser Nukleotide in einem Stück DNA nennen wir eine „DNA-Sequenz".

Wir stellen eine DNA-Sequenz als geordnete Sammlung dieser vier Nukleotide dar, und eine übliche Methode dafür ist ein String aus Zeichen wie "ATTACG" für eine DNA-Sequenz aus 6 Nukleotiden.
'A' für Adenin, 'C' für Cytosin, 'G' für Guanin und 'T' für Thymin.

Gegeben sei ein String, der eine DNA-Sequenz darstellt: Zähle, wie viele von jedem Nukleotid vorhanden sind.
Wenn der String Zeichen enthält, die nicht A, C, G oder T sind, dann ist er ungültig, und du solltest einen Fehler melden.

Zum Beispiel:

```
"GATTACA" -> 'A': 3, 'C': 1, 'G': 1, 'T': 2
"INVALID" -> error
```
