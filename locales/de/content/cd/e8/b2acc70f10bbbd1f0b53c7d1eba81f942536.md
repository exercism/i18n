# Anleitung

In dieser Übung implementierst du einige Regeln aus [Pac-Man][Pac-Man], dem klassischen Arcade-Spiel aus den 1980er-Jahren.

Insgesamt gibt es sechs Aufgaben, vier davon sind Regeln zu den Spielzuständen.

> _Mach dir keine Gedanken darüber, wie die Argumente in den Funktionen hergeleitet werden. Konzentriere dich darauf, die Argumente zu kombinieren, um das gewünschte Ergebnis zurückzugeben._


## 0. Definiere einen Kraftzustand

Definiere eine Variable namens `PowerOn` mit einem Wert, der ausdrückt, dass die Kraft tatsächlich aktiv ist.

```powershell
> $PowerOn
True
```

## 1. Definiere, ob Pac-Man einen Geist frisst

Definiere die Funktion `EatGhost`, die zwei Parameter entgegennimmt (_ob Pac-Man eine aktive Kraftpille hat_ und _ob Pac-Man einen Geist berührt_) und einen booleschen Wert zurückgibt, ob Pac-Man den Geist fressen kann.
Die Funktion sollte nur dann `True` zurückgeben, wenn Pac-Man eine aktive Kraftpille hat und einen Geist berührt.

```powershell
> EatGhost -ActivePower $false -TouchingGhost $true
False
```

## 2. Definiere, ob Pac-Man punktet

Definiere die Funktion `Score`, die zwei Parameter entgegennimmt (_ob Pac-Man eine Kraftpille berührt_ und _ob Pac-Man einen Punkt berührt_) und einen booleschen Wert zurückgibt, ob Pac-Man gepunktet hat.
Die Funktion sollte `True` zurückgeben, wenn Pac-Man eine Kraftpille oder einen Punkt berührt.

```powershell
> Score -TouchDot $true -TouchPowerPellet $true
4
```

## 3. Definiere, ob Pac-Man verliert

Definiere die Funktion `Lose`, die zwei Parameter entgegennimmt (_ob Pac-Man eine aktive Kraftpille hat_ und _ob Pac-Man einen Geist berührt_) und einen booleschen Wert zurückgibt, ob Pac-Man verliert.
Die Funktion sollte `True` zurückgeben, wenn Pac-Man einen Geist berührt und keine aktive Kraftpille hat.

```powershell
> Lose -ActivePower $false -TouchingGhost $true
True
```

## 4. Definiere, ob Pac-Man gewinnt

Definiere die Funktion `Win`, die drei Parameter entgegennimmt (_ob Pac-Man alle Punkte gefressen hat_, _ob Pac-Man eine aktive Kraftpille hat_ und _ob Pac-Man einen Geist berührt_) und einen booleschen Wert zurückgibt, ob Pac-Man gewinnt.
Die Funktion sollte `True` zurückgeben, wenn Pac-Man alle Punkte gefressen hat und gemäß den in Teil 3 definierten Parametern nicht verloren hat.

```powershell
> Win -EatenAllDots $false -ActivePower $true -TouchingGhost $false
False
```

## 5. Schreibe eine Synopsis für die Gewinnbedingung

Geh zur letzten Funktion zurück und füge dem Kommentarblock einen `Synopsis`-Abschnitt als kurze Beschreibung dafür hinzu, wie man das Spiel gewinnt.
Die Beschreibung sollte mindestens zehn Zeichen lang sein.

```powershell
function MyFunc($Arg) {
    <#
    .DESCRIPTION
    This is a demonstration of the comment-based help with the description keyword.
    #>
}
```
