# Hinweise

## Allgemeines

- Achte genau auf die Pointer-Syntax.
  Du wirst `*` (Dereferenzierungsoperator) und `->` (Zugriff auf ein Member über einen Pointer) verwenden.
- Prüfe bei Bedarf auf Null-Pointer (`nullptr`), um den Zugriff auf ungültigen Speicher zu vermeiden.
- Du kannst die Tests auch ausführen, wenn dein Code noch nicht vollständig ist; eine grobe Struktur reicht aus, um die Testergebnisse zu sehen.
- Alle Funktionen, die von den Tests verwendet werden, müssen in der Header-Datei deklariert sein.
- Wenn dein Programm abstürzt oder sich unerwartet verhält, liegt das oft an der Dereferenzierung eines Null-Pointers.
  Prüfe noch einmal, ob du `nullptr` korrekt behandelst.
- Wenn du Pointer-Arithmetik verwendest, achte darauf, dass du innerhalb der Grenzen des Sensor-Arrays bleibst.
  Wenn du die Kapazität des Arrays überschreitest, kann das zu Speicherproblemen führen.

## 1. Sensorverbindung prüfen (`connection_check`)

- Bei dieser Aufgabe geht es hauptsächlich darum zu prüfen, ob ein Pointer null ist oder nicht.
- Verwende den Vergleichsoperator `!=`, um zu prüfen, ob ein Pointer gültig ist.
- Wenn du unsicher bist, ob du den Pointer richtig prüfst, überlege, was `nullptr` darstellt (das Fehlen einer gültigen Speicheradresse).


## 2. Aktivität der Sensoren zählen (`activity_counter`)

- Du musst über das Array von Sensoren iterieren.
  Ein Array in C++ kann als Pointer auf sein erstes Element behandelt werden.
- Verwende Pointer-Arithmetik (`sensor_array + i`), um auf den Sensor am Index `i` zuzugreifen.
- Der Operator `->` wird verwendet, um über einen Pointer auf ein Member der Struktur zuzugreifen.

### Beispiel

```cpp
int sum = (sensor_array + i)->activity; // Access activity using pointer arithmetic
```

## 3. Alarmsteuerung (`alarm_control`)

- Prüfe zuerst, ob der Pointer null ist, bevor du auf den Sensor zugreifst.
- Verwende den Operator `->`, um auf das Member `activity` der Struktur `pillar_men_sensor` zuzugreifen.
- Überlege genau, was passieren soll, wenn der Aktivitätswert des Sensors `0` ist.
  Soll der Alarm ausgelöst werden?

## 4. Die Daten mit der Funktion `uv_alarm` auf Anomalien prüfen

- Verwende den Operator `&`, um einen Pointer auf das Daten-Array des Sensors an die Funktion `uv_light_heuristic` zu übergeben.
- Stelle sicher, dass du vor dem Zugriff auf die Daten des Sensors korrekt auf einen Null-Pointer prüfst.
- Vergleiche das Ergebnis von `uv_light_heuristic` mit dem Wert `activity` des Sensors, um zu entscheiden, ob der Alarm ausgelöst werden soll.
