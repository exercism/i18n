# Hinweise

## 1. Erfasse die Informationen, die du zum Erzeugen der Karten brauchst, mit regulären Ausdrücken

- `\p{L}` stimmt mit jeder Art von Buchstabe aus jeder Sprache überein.
- Mit dem folgenden Ausdruck kannst du die Informationen erfassen:
  ```julia
  re = r"""»(.*)«                     # title
           \ –\ (.*?)                 # name
           (?:\ \((.*?)\)|)           # optional pronouns
           (?:,\ from\ (.*?)|).       # optional organisation
           \ Start:\ (.*?),\          # start time
           (?:Q&A:\ (.*?),\ |)        # optional Q&A time
           End:\ (.*)                 # end time
        """x
  ```
