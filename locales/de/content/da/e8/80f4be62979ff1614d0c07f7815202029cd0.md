# Einführung

Konstanten sind Werte, die zur Kompilierzeit festgelegt werden und nicht neu zugewiesen werden können.
Mit dem Schlüsselwort `const` deklarierst du eine einzelne Konstante:

```go
const greeting = "hello"
```

Mehrere Konstanten lassen sich in einem Block deklarieren.
Innerhalb eines Blocks wiederholt eine Konstante ohne explizit gesetzten Wert den vorherigen Ausdruck:

```go
const (
    greeting    = "hello"
    buffSize    = 4096
    chunkSize   // 4096
)
```

Konstanten werden typischerweise auf Paketebene deklariert, können aber auch innerhalb einer Funktion deklariert werden.

## Typisierte und untypisierte Konstanten

Wenn du eine Konstante deklarierst, ohne einen Typ anzugeben, ist sie untypisiert.
Eine untypisierte Konstante hat keinen festen Typ; ihr Wert bestimmt, mit welchen Typen sie kompatibel ist.
Solange der zugrunde liegende Wert kompatibel ist, wandelt der Compiler ihn bei jeder Verwendung in den benötigten Typ um:

```go
const numA = 2

math.Sqrt(numA)  // numA is treated as float64 here
var numB int = numA  // numA is treated as int here
```

Eine typisierte Konstante legt den Typ schon bei der Deklaration fest:

```go
const num int = 2

math.Sqrt(num)  // compile error because a float is expected
```

## Was eine Konstante sein kann

Konstanten können nur boolesche Werte, Zahlen, Strings und Runes enthalten.
Da die Werte zur Kompilierzeit festgelegt werden, kannst du die Ergebnisse eines Funktionsaufrufs nicht für eine Konstante verwenden.

```go
const s = math.Sqrt(4)  // compile error because the value isn't known at compile time
```

## Iota

Innerhalb eines Blocks von Konstanten gibt `iota` die Position einer Konstante innerhalb des Blocks an:

```go
const (
    Sunday    = iota // 0
    Monday           // 1
    Tuesday          // 2
    Wednesday        // 3
)
```

Jede Konstante nach der ersten übernimmt denselben Ausdruck, wobei `iota` um eins erhöht wird.

`iota` funktioniert auch in Ausdrücken.

```go
const (
    _  = iota             // position 0: value discarded
    KB = 1 << (10 * iota) // position 1: 1 << 10 = 1024
    MB                    // position 2: 1 << 20 = 1048576
    GB                    // position 3: 1 << 30 = 1073741824
)
```
