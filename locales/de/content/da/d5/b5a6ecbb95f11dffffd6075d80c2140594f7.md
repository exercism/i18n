# Anleitung

Die einfache Take-A-Number-Maschine verkaufte sich sehr gut, aber einige Nutzer beschwerten sich über die fehlenden erweiterten Funktionen im Vergleich zu anderen auf dem Markt erhältlichen Modellen.

Der Hersteller hörte auf das Feedback der Nutzer und beschloss, ein Deluxe-Modell mit mehr Funktionen auf den Markt zu bringen. Du wurdest erneut damit beauftragt, die Software für diese Maschine zu schreiben.

Zu den neuen Funktionen des Deluxe-Modells gehören:
- Den Überblick über die aktuell in der Warteschlange stehenden Nummern behalten.
- Die minimale und die maximale Nummer festlegen. So lassen sich mehrere Deluxe-Take-A-Number-Maschinen einsetzen, um Kunden an verschiedene Abteilungen derselben Einrichtung zu verteilen, und die Abteilungen lassen sich am Nummernbereich unterscheiden.
- Bestimmten Nummern erlauben, die Warteschlange zu überspringen, um Schwangeren und älteren Menschen eine bevorzugte Bedienung zu bieten.
- Automatisches Herunterfahren, damit die Maschine nicht versehentlich das ganze Wochenende über eingeschaltet bleibt und Energie verschwendet.

Die Geschäftslogik der Maschine wurde bereits von deinem Kollegen implementiert und befindet sich im Modul `TakeANumberDeluxe.State`. Jetzt ist es deine Aufgabe, sie in einen `GenServer` zu verpacken.

## 1. Starte die Maschine

Verwende das `GenServer`-Verhalten im Modul `TakeANumberDeluxe`.

Implementiere die Funktion `start_link/1` und den nötigen `GenServer`-Callback.

Das an `start_link/1` übergebene Argument ist eine Keyword-Liste. Sie enthält die Schlüssel `:min_number` und `:max_number`. Die Werte unter diesen Schlüsseln müssen an die Funktion `TakeANumberDeluxe.State.new/2` übergeben werden.

Wenn `TakeANumberDeluxe.State.new/2` ein Tupel `{:ok, state}` zurückgibt, soll die Maschine starten und den zurückgegebenen Zustand als ihren Zustand verwenden. Gibt sie stattdessen ein Tupel `{:error, error}` zurück, soll die Maschine stoppen und den zurückgegebenen Fehler als Grund für das Stoppen angeben.

```elixir
TakeANumberDeluxe.start_link(min_number: 1, max_number: 9)
# => {:ok, #PID<0.174.0>}

TakeANumberDeluxe.start_link(min_number: 9, max_number: 1)
# => {:error, :invalid_configuration}
```

Du hast vielleicht bemerkt, dass die Funktion `TakeANumberDeluxe.State.new/2` auch ein optionales drittes Argument entgegennimmt, `auto_shutdown_timeout`. Wir werden es im letzten Schritt dieser Übung verwenden.

## 2. Melde den Zustand der Maschine

Implementiere die Funktion `report_state/1` und den nötigen `GenServer`-Callback. Die Maschine soll dem Aufrufer ihren aktuellen Zustand zurückgeben.

```elixir
{:ok, machine} = TakeANumberDeluxe.start_link(min_number: 1, max_number: 10)
TakeANumberDeluxe.report_state(machine)
# => %TakeANumberDeluxe.State{
#      max_number: 10,
#      min_number: 1,
#      queue: %TakeANumberDeluxe.Queue{in: [], out: []},
#      auto_shutdown_timeout: :infinity,
#    }
```

## 3. Neue Nummern in die Warteschlange einreihen

Implementiere die Funktion `queue_new_number/1` und den nötigen `GenServer`-Callback.

Sie soll die Funktion `TakeANumberDeluxe.State.queue_new_number/1` mit dem aktuellen Zustand der Maschine aufrufen.

Wenn `TakeANumberDeluxe.State.queue_new_number/1` ein Tupel `{:ok, new_number, new_state}` zurückgibt, soll die Maschine dem Aufrufer die neue Nummer zurückgeben und den neuen Zustand als ihren Zustand setzen. Gibt sie stattdessen ein Tupel `{:error, error}` zurück, soll die Maschine dem Aufrufer den Fehler zurückgeben und ihren Zustand nicht ändern.

```elixir
{:ok, machine} = TakeANumberDeluxe.start_link(min_number: 1, max_number: 2)
TakeANumberDeluxe.queue_new_number(machine)
# => {:ok, 1}

TakeANumberDeluxe.queue_new_number(machine)
# => {:ok, 2}

TakeANumberDeluxe.queue_new_number(machine)
# => {:error, :all_possible_numbers_are_in_use}
```

## 4. Die nächste Nummer aus der Warteschlange bedienen

Implementiere die Funktion `serve_next_queued_number/2` und den nötigen `GenServer`-Callback.

Sie soll die Funktion `TakeANumberDeluxe.State.serve_next_queued_number/2` mit dem aktuellen Zustand der Maschine und ihrem zweiten optionalen Argument `priority_number` aufrufen.

Wenn `TakeANumberDeluxe.State.serve_next_queued_number/2` ein Tupel `{:ok, next_number, new_state}` zurückgibt, soll die Maschine dem Aufrufer die nächste Nummer zurückgeben und den neuen Zustand als ihren Zustand setzen. Gibt sie stattdessen ein Tupel `{:error, error}` zurück, soll die Maschine dem Aufrufer den Fehler zurückgeben und ihren Zustand nicht ändern.

```elixir
{:ok, machine} = TakeANumberDeluxe.start_link(min_number: 1, max_number: 10)
TakeANumberDeluxe.queue_new_number(machine)
# => {:ok, 1}

TakeANumberDeluxe.serve_next_queued_number(machine)
# => {:ok, 1}

TakeANumberDeluxe.serve_next_queued_number(machine)
# => {:error, :empty_queue}
```

## 5. Zustand zurücksetzen

Implementiere die Funktion `reset_state/1` und den nötigen `GenServer`-Callback.

Sie soll die Funktion `TakeANumberDeluxe.State.new/2` aufrufen, um mit `min_number` und `max_number` des aktuellen Zustands einen neuen Zustand zu erzeugen. Die Maschine soll den neuen Zustand als ihren Zustand setzen. Sie soll dem Aufrufer nichts zurückgeben.

```elixir
{:ok, machine} = TakeANumberDeluxe.start_link(min_number: 1, max_number: 10)

TakeANumberDeluxe.reset_state(machine)
# => :ok
```

## 6. Automatisches Herunterfahren implementieren

Ändere das Starten der Maschine. Sie soll den Wert unter dem Schlüssel `:auto_shutdown_timeout` in der als `init_arg` übergebenen Keyword-Liste auslesen und ihn als drittes Argument an `TakeANumberDeluxe.State.new/3` übergeben. Verwende den Standardwert `:infinity`, wenn `:auto_shutdown_timeout` nicht angegeben wurde.

Ändere das Zurücksetzen des Maschinenzustands so, dass `auto_shutdown_timeout` ebenfalls an `TakeANumberDeluxe.State.new/3` übergeben wird.

Ändere die Rückgabewerte aller implementierten Callbacks (`init/1` und alle `handle_*`-Callbacks) so, dass sie ein Timeout setzen. Verwende den Wert unter dem Schlüssel `:auto_shutdown_timeout` im aktuellen Zustand der Maschine. Füge das Timeout nicht zum Rückgabewert `{:stop, reason}` von `init/1` hinzu. Timeouts gelten erst, nachdem der Server seine Empfangsschleife gestartet hat.

Implementiere einen `GenServer`-Callback, der die `:timeout`-Nachricht behandelt, die an die Maschine gesendet wird, wenn sie innerhalb des angegebenen Timeouts keine anderen Nachrichten empfängt. Er soll den Prozess mit dem Grund `:normal` beenden.

Stelle außerdem sicher, dass du unerwartete Nachrichten behandelst, indem du sie ignorierst.

```elixir
{:ok, machine} =
  TakeANumberDeluxe.start_link(
    min_number: 1,
    max_number: 10,
    auto_shutdown_timeout: :timer.hours(2)
  )

# after 3 hours...

TakeANumberDeluxe.queue_new_number(machine)
# => ** (exit) exited in: GenServer.call(#PID<0.171.0>, :queue_new_number, 5000)
#        ** (EXIT) no process: the process is not alive or there's no process currently associated with the given name, possibly because its application isn't started
#       (elixir 1.13.0) lib/gen_server.ex:1030: GenServer.call/3
```
