# Break, Continue

Wenn du eine Schleife oder eine iterierende Kontrollstruktur verwendest, helfen dir die Schlüsselwörter `break` und `continue`, den Ablauf eines Programms zu steuern.
Das Schlüsselwort `break` verlässt den Schleifenkontext in den äußeren Gültigkeitsbereich und beendet damit die Schleife.
Das Schlüsselwort `continue` überspringt den Rest der aktuellen Iteration und setzt den Schleifenkontext am Anfang der nächsten Iteration fort.
Das ist zwar ungewöhnlich, aber du kannst dem Schlüsselwort eine Zahl mitgeben, um zu steuern, aus wie vielen Kontexten du ausbrichst bzw. wie viele Iterationen du überspringst.

```php
<?php
$i = 1;
while ($i <= 10) {

    if ($i <= 5) {
        i += 1;
        continue;
    }
    break;
}
```

Im vorherigen Beispiel wird `continue` fünf (5) Mal ausgeführt, doch in der sechsten (6) Iteration wird `break` ausgeführt, wodurch der Code die Schleife verlässt.
