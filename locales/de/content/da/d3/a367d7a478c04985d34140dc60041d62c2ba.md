# Anleitung

In dieser Übung schreibst du noch etwas mehr Code rund um die Vorbereitung und das Kochen deiner großartigen Lasagne aus deinem Lieblingskochbuch.

Du hast vier Aufgaben.
Die erste dreht sich ums Kochen selbst, die anderen drei um die perfekte Vorbereitung.

## 1. Schätze die Vorbereitungszeit ein

Für die nächste Lasagne, die du zubereiten wirst, möchtest du sicherstellen, dass du genug Zeit eingeplant hast, damit du das Kochen genießen kannst.
Du hast bereits geplant, welche Schichten deine Lasagne haben wird.
Jetzt möchtest du auf dieser Grundlage einschätzen, wie lange die Vorbereitung dauern wird.

Implementiere eine Funktion `PreparationTime`, die einen Slice von Schichten als `[]string` und die durchschnittliche Vorbereitungszeit pro Schicht in Minuten als `int` entgegennimmt.
Die Funktion sollte die Schätzung für die gesamte Vorbereitungszeit basierend auf der Anzahl der Schichten als `int` zurückgeben.
Go hat keine Standardwerte für Funktionen.
Wenn die durchschnittliche Vorbereitungszeit als `0` übergeben wird (der Standardinitialwert für ein `int`), dann sollte der Standardwert `2` verwendet werden.

```go
layers := []string{"sauce", "noodles", "sauce", "meat", "mozzarella", "noodles"}
PreparationTime(layers, 3)
// => 18
PreparationTime(layers, 0)
// => 12
```

## 2. Berechne die benötigten Mengen an Nudeln und Soße

Neben der Zeit möchtest du auch sicherstellen, dass du genug Soße und Nudeln hast, um die Lasagne deiner Träume zu kochen.
Für jede Nudelschicht in deiner Lasagne brauchst du 50 Gramm Nudeln.
Für jede Soßenschicht in deiner Lasagne brauchst du 0,2 Liter Soße.

Definiere die Funktion `Quantities`, die einen Slice von Schichten als Parameter vom Typ `[]string` entgegennimmt.
Die Funktion ermittelt dann die Menge an Nudeln und Soße, die du für dein Essen brauchst.
Das Ergebnis sollte als zwei Werte zurückgegeben werden: `noodles` als `int` und `sauce` als `float64`.

```go
Quantities([]string{"sauce", "noodles", "sauce", "meat", "mozzarella", "noodles"})
// => 100, 0.4
```

## 3. Füge die geheime Zutat hinzu

Vor einer Weile hast du einen Freund besucht und dort Lasagne gegessen.
Sie war fantastisch und hatte etwas Besonderes an sich.
Der Freund hat dir die Zutatenliste geschickt und gesagt, dass der letzte Eintrag auf der Liste die „geheime Zutat“ ist, die das Essen so besonders gemacht hat.
Jetzt möchtest du diese geheime Zutat auch zu deinem Rezept hinzufügen.

Schreibe eine Funktion `AddSecretIngredient`, die zwei Slices von Zutaten vom Typ `[]string` als Parameter entgegennimmt.
Der erste Parameter ist die Liste, die dir dein Freund geschickt hat, der zweite ist die Zutatenliste deines eigenen Rezepts.
Das letzte Element in deiner Zutatenliste ist immer `"?"`.
Die Funktion sollte es durch den letzten Eintrag aus der Liste deines Freundes ersetzen.
**Hinweis:** `AddSecretIngredient` gibt nichts zurück, du solltest die Liste deiner Zutaten direkt ändern.
Die Liste mit den Zutaten deines Freundes sollte **nicht** geändert werden.
Außerdem wird `slice` als Pointer an eine Funktion übergeben, daher werden Änderungen an den beiden `[]string`-Argumenten, die an `AddSecretIngredient` übergeben werden, direkt übernommen.

```go
friendsList := []string{"noodles", "sauce", "mozzarella", "kampot pepper"}
myList := []string{"noodles", "meat", "sauce", "mozzarella","?"}

AddSecretIngredient(friendsList, myList)
// myList => []string{"noodles", "meat", "sauce", "mozzarella", "kampot pepper"}
```

## 4. Skaliere das Rezept

Die Mengen in deinem Kochbuch ergeben nur genug Lasagne für zwei Portionen.
Da du nächstes Mal für mehr Personen kochen möchtest, willst du die Mengen für unterschiedliche Portionszahlen berechnen.

Implementiere eine Funktion `ScaleRecipe`, die zwei Parameter entgegennimmt.

- Ein Slice von `float64`-Mengen, die für 2 Portionen benötigt werden.
- Die Anzahl der Portionen, die du kochen möchtest.

Die Funktion sollte ein Slice von `float64` mit den Mengen zurückgeben, die für die gewünschte Anzahl an Portionen benötigt werden.
Das ursprüngliche Rezept möchtest du aber beibehalten.
Das bedeutet, dass das Argument `quantities` in dieser Funktion nicht geändert werden sollte.

```go
quantities := []float64{ 1.2, 3.6, 10.5 }
scaledQuantities := ScaleRecipe(quantities, 4)
// => []float64{ 2.4, 7.2, 21 }
```
