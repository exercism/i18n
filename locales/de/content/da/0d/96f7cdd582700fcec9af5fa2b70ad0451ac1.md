# Einführung

Die [spezielle Form with][with] bietet eine Möglichkeit, sich auf den „Happy Path“ einer Reihe von möglicherweise fehlschlagenden Schritten zu konzentrieren und die Fehler erst später zu behandeln.

```elixir
with {:ok, id} <- get_id(username),
     {:ok, avatar} <- fetch_avatar(id),
     {:ok, image_type} <- check_valid_image_type(avatar) do
  {:ok, image_type, avatar}
else
  :not_found ->
    {:error, "invalid username"}

  {:error, "not an image"} ->
    {:error, "avatar associated to #{username} is not an image"}

  err ->
    err
end
```

Bei jedem Schritt gilt: Passt eine Klausel, läuft die Kette weiter, bis der `do`-Block ausgeführt wird. Schlägt eine Übereinstimmung fehl, endet die Kette und die nicht passende Klausel wird zurückgegeben. Du hast die Möglichkeit, einen `else`-Block zu verwenden, um fehlgeschlagene Übereinstimmungen abzufangen und den Rückgabewert anzupassen.

[with]: https://hexdocs.pm/elixir/Kernel.SpecialForms.html#with/1
