# Einführung

Eine Funktion in Cairo ermöglicht es dir, Code zu einer wiederverwendbaren Einheit zusammenzufassen. So werden deine Programme modularer und leichter zu verstehen.
Funktionen in Cairo bestehen aus dem Schlüsselwort `fn`, gefolgt vom Funktionsnamen, einer Liste von Parametern in runden Klammern und einem Block, der festlegt, was die Funktion tut.

## Funktionsparameter

In Cairo müssen alle Funktionsparameter explizit typisiert sein.
Anders als in manchen Sprachen leitet Cairo Typen nicht ab, und es gibt keine Standardwerte für Parameter. Deshalb sind alle Parameter erforderlich.

```rust
// Function with no parameters
fn print_hello() {
    // Function body
}

// Function with two parameters
fn print_greeting_name(greeting: ByteArray, name: ByteArray) {
    // Function body
}
```

## Parameter und Argumente

Es ist wichtig, zwischen `parameters` und `arguments` zu unterscheiden:

- **Parameter** sind die Variablennamen, die in der Funktionsdefinition verwendet werden, wie `greeting` und `name` in der Funktion `print_greeting_name`.
- **Argumente** sind die tatsächlichen Werte, die beim Aufruf an die Funktion übergeben werden.

```rust
// Calling the function with arguments
print_greeting_name(123, 456)
```

## Anweisungen und Ausdrücke

Der Funktionskörper besteht aus einer Reihe von Anweisungen, die optional mit einem Ausdruck enden.

- Anweisungen führen eine Aktion aus und geben keinen Wert zurück.
- Ausdrücke werten zu einem resultierenden Wert aus.

Das Erstellen einer Variablen und das Zuweisen eines Werts mit dem Schlüsselwort `let` ist eine Anweisung.

```rust
let y = 6;
```

Aber die `6` in der obigen Anweisung ist ein Ausdruck, der zum Wert `6` ausgewertet wird.

Der Aufruf einer Funktion ist ein Ausdruck, denn er wird immer zu einem Wert ausgewertet: dem expliziten Rückgabewert der Funktion, falls angegeben, ansonsten dem Unit-Typ `()`.

## Rückgabewerte

Cairo-Funktionen können Werte an den Code zurückgeben, der sie aufruft.
Rückgabewerte werden nach den Parametern aufgeführt und durch einen Pfeil `->` getrennt.
In Cairo ist der Rückgabewert der Funktion gleichbedeutend mit dem Wert des letzten Ausdrucks im Block des Funktionskörpers.
Du kannst vorzeitig aus einer Funktion zurückkehren, indem du das Schlüsselwort `return` verwendest und einen Wert angibst.

```rust
// Function returning the last (and only) expression
fn hello(name: ByteArray) -> ByteArray {
    "Hello " + name
}

// Function returning using the `return` keyword
fn double_if_even(value: u32) -> u32 {
    if value % 2 == 0 {
        return value * 2;
    }
    return value;
}
```

## Funktionen aufrufen

Um eine Funktion in Cairo aufzurufen, verwendest du einfach den Funktionsnamen, gefolgt von Argumenten in runden Klammern.

```rust
// Calling a function with no parameters
print_hello()

// Calling a function with one parameter
let greeting = hello("John")

// Calling a function with multiple parameters
print_greeting_name("Howdy", "Joel")
```
