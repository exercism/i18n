# Überblick

Das `<iota>` von Factor erzeugt eine *virtuelle* Sequenz der ganzen Zahlen
`0, 1, …, n-1`. Wenn du sie mit `map` durchläufst, erhältst du eine
tabellierte Sequenz, bei der jedes Element eine Funktion seiner Position ist:

```factor
USING: math sequences ;

5 <iota> [ sq ] map .         ! => { 0 1 4 9 16 }
8 <iota> [ 1 + ] map .        ! => { 1 2 3 4 5 6 7 8 }
```

Zwei Bausteine ermöglichen es dir, eine Sequenz von Ganzzahl-Codes in einen
String umzuwandeln:

| Wort      | Rolle                                                   |
|-----------|---------------------------------------------------------|
| `CHAR:`   | Literal zur Parse-Zeit, das den Codepoint eines Zeichens auf den Stack legt |
| `>string` | wandelt eine Sequenz von Codepoints in einen String um  |

Zusammen bilden sie das Standard-Idiom, um eine Reihe von Zeichen aufzubauen,
die nach ihrer Position indiziert ist:

```factor
USING: kernel math sequences strings ;

10 <iota> [ 2 mod zero? [ CHAR: O ] [ CHAR: . ] if ] map >string .
! => "O.O.O.O.O."
```

Wenn du das Zeichen innerhalb der Quotation mit `if` (oder `?`) auswählst,
bleibt die Entscheidung pro Position nah an dem Index, von dem sie abhängt.
