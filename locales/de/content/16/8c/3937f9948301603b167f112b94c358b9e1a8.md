# Hinweise

## 1. Generiere einen zufälligen Planeten

- Java bietet keine Funktion, um ein Element zufällig aus einer Sammlung auszuwählen.
- Denk daran, dass du ein Element über seinen Index aus einem Array abrufen kannst. Der Index ist eine Ganzzahl.

## 2. Generiere eine zufällige Registriernummer für ein Raumschiff

- Die Klasse `java.util.Random` bietet eine Methode, um eine zufällige `int`-Ganzzahl zwischen 0 und einem angegebenen Maximum zu erzeugen.

## 3. Generiere eine zufällige Sternzeit

- Die Methode der Klasse `java.util.Random` zum Erzeugen einer zufälligen `double`-Gleitkommazahl gibt immer eine Zahl zwischen `0.0` und `1.0` zurück.
