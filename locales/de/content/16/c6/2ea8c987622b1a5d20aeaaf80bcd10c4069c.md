# Einführung

In Clojure gibt es ein paar grundlegende Konstrukte zur [Ablaufsteuerung](https://clojure.org/guides/learn/flow). `if` ist der wichtigste bedingte Ausdruck. Er besteht aus einer Bedingung, einem „Dann“ und einem optionalen „Sonst“. `if` wertet nur den Zweig aus, den die Bedingung auswählt.

```clojure
(if (even? 2) "even" "odd")
```

`cond` ist eine Reihe von Tests und Ausdrücken. Jeder Test wird der Reihe nach ausgewertet, und für den ersten Test, der wahr ist, wird der Ausdruck ausgewertet und zurückgegeben.

```clojure
(cond (= x 5) "Expression to evaluate when x equals 5"
      (> x 7) "Expression to evaluate when x is greater than 7"
      :else   "Expression to evaluate in all other cases")
```
