# Anleitung

Dein Freund Johannes liebt es, DIY-Hardware (also Hardware zum Selbermachen) zu bauen.
Gerade hat er einen Entsafter gebaut, und Johannes freut sich riesig darüber.
Johannes' Ziel ist es, jeden Morgen frischen Saft machen zu können.

Johannes' Entsafter hat jede Menge raffinierte Funktionen.
Zum Beispiel ein eingebautes Messsystem, das dir sagt, wie viel Saft im Becher ist.
Außerdem hat er einen Timer, der dir sagt, wie lange die Maschine schon läuft.

Johannes ist nicht der beste Programmierer, aber er möchte ein Programm schreiben, das die Maschine steuert.
Deshalb hat er dich um Hilfe gebeten.

## 1. Debug-Licht

Die Maschine hat ein Debug-Licht. Es ist ganz einfach: Wenn die Maschine Strom hat, leuchtet das Debug-Licht.
Das Programm läuft nur, wenn das Debug-Licht leuchtet.

Diese Methode sollte eine Klassenmethode namens `JuiceMaker` sein.

Definiere die Klassenmethode `JuiceMaker.debug_light_on?`, die `true` zurückgibt.

```crystal
JuiceMaker.debug_light_on?
#=> true
```

## 2. Die Maschine initialisieren

Wenn die Maschine eingeschaltet wird, sollte sie eine Instanz einer Klasse namens `JuiceMaker` erzeugen.
Die Maschine soll einen initialisierten Zustand haben.
Der initialisierte Zustand sollte die folgenden Informationen enthalten:

1. Ob die Maschine läuft oder nicht. Beim Einschalten der Maschine sollte das immer `false` sein.
2. Die Menge Saft im Becher. Das wird ein Sensor sein, der die Saftmenge im Becher misst.

Definiere den initialisierten Zustand, der die Menge Saft im Becher als Parameter entgegennimmt, und konstruiere den initialisierten Zustand.
Der initialisierte Zustand sollte eine Instanzvariable `@running` enthalten, die auf `false` gesetzt ist, und eine Instanzvariable `@fluid`, die auf einem Argument basiert, das beim Initialisieren der Klasse übergeben wird.

```crystal
JuiceMaker.new(5)
#=> #<JuiceMaker:0x10f0b8 @running=false, @fluid=5>
```

## 3. Die Maschine einschalten

Die Maschine kann ein- und ausgeschaltet werden.
Du musst eine Methode definieren, die die Maschine einschaltet.
Wenn die Maschine eingeschaltet wird, sollte der Laufzustand auf `true` gesetzt werden.

Definiere die Methode `JuiceMaker#start`, die die Maschine einschaltet.

```crystal
juice_maker = JuiceMaker.new(5)
juice_maker.start

juice_maker
#=> #<JuiceMaker:0x10f0b8 @running=true, @fluid=5>
```

## 4. Status der Maschine

Die Maschine muss dir ihren Status mitteilen können.
Sie sollte `true` zurückgeben, wenn die Maschine läuft, und `false`, wenn die Maschine nicht läuft.

Definiere die Methode `JuiceMaker#running?`, die den Status der Maschine zurückgibt.

```crystal
juice_maker = JuiceMaker.new(5)
juice_maker.start

juice_maker.running?
#=> true
```

## 5. Saft hinzufügen

Die Maschine kann Saft in den Becher füllen.
Die Maschine kann sagen, wie viel Saft in den Becher gefüllt wurde.
Die Maschine braucht Hilfe, um zu wissen, wie viel Saft nach dem Hinzufügen im Becher ist.

Definiere die Methode `JuiceMaker#add_fluid`, die die hinzugefügte Saftmenge als Parameter entgegennimmt und die Saftmenge im Becher aktualisiert.

```crystal
juice_maker = JuiceMaker.new(5)
juice_maker.add_fluid(5)

juice_maker
#=> #<JuiceMaker:0x10f0b8 @running=false, @fluid=10>
```

## 6. Die Maschine ausschalten

Die Maschine kann ein- und ausgeschaltet werden.
Du musst eine Methode definieren, die die Maschine ausschaltet.
Diese Methode wird nur aufgerufen, wenn die Maschine läuft.
Wenn die Maschine ausgeschaltet wird, sollte der Laufzustand auf `false` gesetzt werden.
Die Maschine braucht außerdem Hilfe bei der Bestimmung, wie viel Saft nach dem Ausschalten im Becher ist.
Die Maschine verbraucht fünf Einheiten Saft pro Minute.

Definiere die Methode `JuiceMaker#stop`, die die Anzahl der Minuten, die die Maschine gelaufen ist, als Parameter entgegennimmt und die Saftmenge im Becher zurückgibt, nachdem die Maschine ausgeschaltet wurde.

```crystal
juice_maker = JuiceMaker.new(5)

juice_maker.start
juice_maker
#=> <JuiceMaker:0x10f0b8 @running=true, @fluid=5>

juice_maker.stop(1)
#=> #<JuiceMaker:0x10f0b8 @running=false, @fluid=0>
```
