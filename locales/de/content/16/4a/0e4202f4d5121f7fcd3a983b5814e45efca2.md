# Einführung

Viele Programme brauchen (_scheinbar_) zufällige Werte, um Ereignisse aus der realen Welt zu simulieren.

Häufige, bekannte Beispiele sind:
- Ein Münzwurf: ein zufälliger Wert aus `('Heads', 'Tails')`.
- Der Wurf eines Würfels: eine zufällige Ganzzahl von 1 bis 6.
- Das Mischen eines Kartendecks: eine zufällige Reihenfolge einer Kartenliste.
- Das Erzeugen von Bäumen und Büschen in einer 3-D-Grafiksimulation.

Mit einem Computer _wirklich_ zufällige Werte zu erzeugen, ist eine [überraschend schwierige technische Herausforderung][truly-random], deshalb werden solche Ergebnisse oft als „pseudozufällig“ bezeichnet.

In der Praxis ist eine gut konzipierte Bibliothek wie das Modul [`random`][random] in der Python-Standardbibliothek schnell, flexibel und liefert Ergebnisse, die für die meisten Anwendungen in Modellierung, Simulation und Spielen vollkommen ausreichen.

In dieser kurzen Einführung zeigen wir die vier am häufigsten verwendeten Funktionen aus dem Modul.
Schau dir ruhig die vollständige Dokumentation zu [`random`][random] an, denn es gibt viele Werkzeuge und Optionen.

Bevor du die Werkzeuge im `random`-Modul nutzen kannst, musst du es zuerst importieren:

```python
>>> import random

# Choose random integer from a range
>>> random.randrange(1000)
360

>>> random.randrange(-1, 500)
228

>>> random.randrange(-10, 11, 2)
-8

# Choose random integer between two values (inclusive)
>>> random.randint(5, 25)
22

```

Um nicht jedes Mal den Namen des Moduls tippen zu müssen, kannst du bestimmte Funktionen direkt mit ihrem Namen importieren:

```python
>>> from random import choice, choices

# Using choice() to pick Heads or Tails 10 times
>>> tosses = []
... for side in range(10):
...    tosses.append(choice(['H', 'T']))    

>>> print(tosses)
['H', 'H', 'H', 'H', 'H', 'H', 'H', 'T', 'T', 'H']


# Using choices() to pick Heads or Tails 8 times
>>> picks = []
... picks.extend(choices(['H', 'T'], k=8))
... print(picks)
['T', 'H', 'H', 'T', 'H', 'H', 'T', 'T']
```



## `randrange()` und `randint()`

Wie im ersten Beispiel oben zu sehen, hat die Funktion `randrange()` drei Formen:

1. `randrange(stop)` liefert eine Ganzzahl `n` mit `0 <= n < stop`
2. `randrange(start, stop)` liefert eine Ganzzahl `n` mit `start <= n < stop`
3. `randrange(start, stop, step)` liefert eine Ganzzahl `n` mit `start <= n < stop`
    und `n` liegt in der Folge `start, start + step, start + 2*step...`

Für den häufigsten Fall, in dem `step == 1` gilt, ist `randint(a, b)` oft praktischer und besser lesbar.
Mögliche Ergebnisse von `randint()` _umfassen_ die obere Grenze, daher entspricht `randint(a, b)` der Verwendung von `randrange(a, b+1)`.



## `choice()` und `choices()`

Bei diesen beiden Funktionen gehst du von einer [Sequenz][sequence-types] oder einem anderen Container aus.
Meist ist das eine `list`, mit einigen Einschränkungen auch ein `tuple` oder ein `set` (_ein `tuple` ist unveränderlich und ein `set` hat keine feste Reihenfolge_).

Die Funktion `choice()` gibt ein zufällig ausgewähltes Element aus einer gegebenen Sequenz zurück, und `choices()` gibt eine bestimmte Anzahl von Elementen (`k`) zurück, die zufällig aus einer gegebenen Sequenz ausgewählt wurden.
In den oben gezeigten Beispielen sind wir von einer fairen Münze mit gleicher Wahrscheinlichkeit für Kopf oder Zahl ausgegangen, aber es können auch Gewichtungen angegeben werden.

Angenommen, in einem Beutel befinden sich 10 rote und 15 grüne Kugeln, und wir möchten eine zufällig herausziehen:


```python
>>> random.choices(['red', 'green'], [10, 15])
['red']
```
