# Stringformat

Neben der Methode `String#%%` ist die [Stringinterpolation](http://ruby-for-beginners.rubymonstas.org/bonus/string_interpolation.html) ein üblicher Weg, in Ruby Strings zu erstellen. Zum Beispiel:

```ruby
# Rather than:
"One for %%s, one for me." %% %{name_variable}

# Consider:
"One for #{%{name_variable}}, one for me."
```
