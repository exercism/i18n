# Einführung

Das Modul `gleam/order` in der Standardbibliothek von Gleam enthält den Typ `Order`, mit dem du Werte vergleichen kannst.

Die Definition von `Order` sieht so aus:

```gleam
pub type Order {
  Gt
  Eq
  Lt
}
```

Der Typ hat drei Varianten. Jede davon stellt die Beziehung zwischen einem Wert und einem anderen Wert dar:

- `Gt`: Der Wert ist _größer_ als der andere Wert.
- `Eq`: Der Wert ist _gleich_ dem anderen Wert.
- `Lt`: Der Wert ist _kleiner_ als der andere Wert.

Wenn sich ein Datentyp der Größe nach vergleichen lässt, ist es üblich, dass das Modul eine `compare`-Funktion definiert, die einen `Order`-Wert zurückgibt. Zum Beispiel definieren `gleam/float` und `gleam/int` `compare`-Funktionen, die auf Gleitkommazahlen bzw. Ganzzahlen arbeiten.

```gleam
int.compare(1, 2)
// -> Lt

int.compare(2, 2)
// -> Eq

float.compare(1.0, 2.0)
// -> Lt
```

Sortierfunktionen wie `list.sort` nehmen üblicherweise eine Funktion entgegen, die einen `Order`-Wert zurückgibt, sodass der Aufrufer festlegen kann, wie die Liste sortiert werden soll.

```gleam
list.sort([3, 7, 3, 1], by: int.compare)
// -> [1, 3, 3, 7]
```
