# Einführung

## Switch

Eine [switch-Anweisung][switch] vergleicht einen Wert mit mehreren möglichen passenden Mustern.
Sie bietet eine sauberere und besser lesbare Alternative, als mehrere `if-else`-Anweisungen aneinanderzureihen.

Eine `switch`-Anweisung beginnt mit dem Schlüsselwort `switch`, gefolgt von dem Wert, der geprüft werden soll.
Jede mögliche Übereinstimmung wird mit dem Schlüsselwort `case` eingeleitet.
Mit dem Schlüsselwort `default` definierst du einen Standardfall, der ausgeführt wird, wenn keiner der expliziten Fälle passt.
Wie `if-else`-Ketten führt eine `switch`-Anweisung nur den Block aus, der zum ersten passenden Fall gehört.

```swift
switch value {
case 1:
    print("One")
case 2:
    print("Two")
default:
    print("Other")
}
```

Schauen wir uns die folgende `if-else`-Kette an:

```swift
if str == "apple" {
    print("Let's bake an apple crumble")
} else if str == "lemon" {
    print("Let's bake a lemon meringue pie!")
} else if str == "peach" {
    print("Let's bake a peach pie!")
} else {
    print("Let's buy ice cream.")
}
```

Das lässt sich mit einer `switch`-Anweisung übersichtlicher schreiben:

```swift
switch str {
case "apple":
    print("Let's bake an apple crumble")
case "lemon":
    print("Let's bake a lemon meringue pie!")
case "peach":
    print("Let's bake a peach pie!")
default:
    print("Let's buy ice cream.")
}
```

## while-Schleifen

Eine [while-Schleife][while-loops] ist eine Anweisung, mit der du Code so lange ausführen kannst, wie eine bestimmte Bedingung wahr ist.
Swift bietet zwei Arten von while-Schleifen: while- und repeat-while-Schleifen.
Bei einer while-Schleife wird die Bedingung ausgewertet, bevor der Schleifenblock ausgeführt wird. Ist die Bedingung falsch, wird der Schleifenblock gar nicht ausgeführt.
while-Schleifen haben in Swift folgenden Aufbau:

```swift
while <#condition#> {
  <#code#>
}
```

Hier wird die Schleife so lange ausgeführt, wie count größer als 0 ist, und gibt dabei die Zahlen 2, 1 und „Liftoff!“ aus.

```swift
var count = 2
while count > 0 {
  print("\(count)…")
  count -= 1
}
print("Liftoff!")

// prints:
// 2…
// 1…
// Liftoff!
```

Eine [repeat-while-Schleife][while-loops] ähnelt einer while-Schleife, doch die Bedingung wird ausgewertet, nachdem der Schleifenblock ausgeführt wurde.
Das heißt, der Schleifenblock wird immer mindestens einmal ausgeführt, selbst wenn die Bedingung falsch ist.
repeat-while-Schleifen haben in Swift folgenden Aufbau:

```swift
repeat {
  <#code#>
} while <#condition#>
```

Hier wird die Schleife nur einmal ausgeführt, da die Bedingung falsch ist.
Da es eine repeat-while-Schleife ist, wird der Schleifenblock einmal ausgeführt, bevor die Bedingung ausgewertet wird.

```swift
var count = 2
repeat {
  print("\(count)…")
} while count < 0
print("Liftoff!")
```

## Kontrollübertragung

Swift bietet Kontrollübertragungsanweisungen, mit denen du den Ausführungsablauf von Schleifen und switch-Anweisungen änderst.
Neben `return` gibt es in Swift `continue`, `break`, Labels für Schleifen und `fallthrough`.

### Continue

Die Anweisung `continue` weist eine Schleife an, die aktuelle Iteration abzubrechen und sofort mit der nächsten zu beginnen.
In einer `while`- oder `repeat-while`-Schleife springt sie direkt zur Bedingungsprüfung.
In einer `for-in`-Schleife rückt sie zum nächsten Element in der Sequenz vor.

```swift
var count = 1
while count < 6 {
    count += 1
    if count == 4 {
        continue
    }
    print(count)
}

// Prints:
// 2
// 3
// 5
// 6
```

### Break

Die Anweisung `break` beendet eine ganze Schleife oder switch-Anweisung sofort.
Die Ausführung wird in der ersten Codezeile nach der Schleife bzw. der switch-Anweisung fortgesetzt.

```swift
for fruit in ["banana", "grapes", "apple", "strawberry", "kiwi", "lemon"] {
    if !fruit.count.isMultiple(of: 2) {
        break
    }
    print(fruit)
}

// Prints:
// banana
// grapes
```

### Anweisungen mit Label

In verschachtelten Schleifen möchtest du mit `break` oder `continue` vielleicht eine äußere Schleife ansprechen statt der innersten.
Du kannst eine Schleife mit einem Label versehen, indem du einen Namen und einen Doppelpunkt davorstellst (`labelName:`).
Dieses Label kannst du dann an `break` oder `continue` übergeben:

```swift
outerLoop: for fruit in ["banana", "grapes", "apple", "strawberry", "kiwi", "lemon"] {
    print("\n--- \(fruit) ---")
    for letter in fruit {
        guard letter != "n" else {
            break outerLoop
        }
        print(letter)
    }
}

// Prints:
// --- banana ---
// b
// a
```
