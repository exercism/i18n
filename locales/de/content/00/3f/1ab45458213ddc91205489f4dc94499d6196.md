# Einführung

Ein `Tuple` ist einem `Vector` (einem eindimensionalen `array`) in vielerlei Hinsicht sehr ähnlich.
Es gibt jedoch ein paar wichtige Unterschiede.

- Tupel werden in runde Klammern `( )` geschrieben, nicht in eckige `[ ]`. Die Klammern kannst du allerdings weglassen, wenn die Bedeutung eindeutig ist.
- Tupel müssen nicht homogen sein: Der Typ jedes Elements wird einzeln gespeichert.
- Tupel sind unveränderlich.

Die Unveränderlichkeit ermöglicht mehr Compiler-Optimierungen und macht Tupel leistungsfähiger als Vektoren. Deshalb solltest du sie bevorzugen, wenn Veränderlichkeit nicht nötig ist.

```julia-repl
julia> t = (3, 5.2, "xyz")
(3, 5.2, "xyz")

# Non-homogeneous:
julia> dump(t)
Tuple{Int64, Float64, String}
  1: Int64 3
  2: Float64 5.2
  3: String "xyz"

julia> t[2]
5.2

# Immutable:
julia> t[2] = 7.3
ERROR: MethodError: no method matching setindex!(::Tuple{Int64, Float64, String})
```

Es gibt außerdem einen Konstruktor `Tuple()`, der jede iterierbare Sammlung in ein Tupel umwandelt. Praktischerweise wird ein String dabei als iterierbare Sammlung von Zeichen behandelt.

```julia-repl
julia> Tuple("Julia")
('J', 'u', 'l', 'i', 'a')
```

Bei jedem Tupel kannst du über den Index auf die Elemente zugreifen oder sie mit einer Schleife durchlaufen.

Jedes rein numerische Tupel kannst du außerdem in mathematischen Funktionen wie `sum()` verwenden, genau wie Arrays.

## Entpacken

Ein Tupel lässt sich mit einer Mehrfachzuweisung in einzelne Elemente entpacken.
Für Elemente, die du nicht brauchst, verwendest du den Unterstrich `_` als Platzhaltervariable.

```julia-repl
julia> tup = (1, "Julia", true)
(1, "Julia", true)

julia> num, name, _ = tup
(1, "Julia", true)

julia> uppercase(name), 2num
("JULIA", 2)
```

Wer Python programmiert, kennt diese Syntax der Mehrfachzuweisung nur zu gut.

## Benannte Tupel

Ein `Tuple` enthält nur Werte.
Ein `NamedTuple` verbindet jeden Wert mit einem Namen.

Auf die einzelnen Felder kannst du dann mit der Punktnotation zugreifen:

```jullia-repl
julia> nt = (a = 1, b = 7.3)
(a = 1, b = 7.3)

julia> dump(nt)
@NamedTuple{a::Int64, b::Float64}
  a: Int64 1
  b: Float64 7.3

julia> nt.b
7.3
```

Der Name wird intern als `Symbol` gespeichert (ein unveränderlicher Typ, und dem Namen wird ein Doppelpunkt `:` vorangestellt). Deshalb gibt es eine alternative Syntax:

```julia-repl
julia> nt[:b]
7.3
```

Die Namen (auch „Schlüssel“ genannt) oder die Werte kannst du auch getrennt abrufen:

```julia-repl
julia> nt
(a = 1, b = 7.3)

julia> keys(nt)
(:a, :b)

julia> values(nt)
(1, 7.3)
```

Beachte, dass eine Iteration über ein benanntes Tupel nur die _Werte_ liefert; die _Namen_ werden ignoriert.

Tupel, ob benannt oder nicht, sind ein sehr gebräuchlicher Weg, strukturierte Daten an Funktionen zu übergeben und von ihnen zurückzubekommen.
Die Unveränderlichkeit ist hier von Vorteil: Sie sorgt für Datensicherheit und erlaubt aggressivere Compiler-Optimierungen.
