# Einführung

Manchmal musst du eine Sequenz als eine Reihe von *Stücken* betrachten statt Element für Element. Die Vokabulare [`grouping`][grouping], [`splitting`][splitting] und [`splitting.monotonic`][splitting.monotonic] geben dir vier Möglichkeiten dafür.

## `group`: disjunkte Stücke der Größe *n*

```
group ( seq n -- groups )
```

```factor
USING: grouping ;

{ 1 2 3 4 5 6 7 } 3 group .
! => { { 1 2 3 } { 4 5 6 } { 7 } }
```

Wenn die Länge der Sequenz kein Vielfaches von *n* ist, ist die letzte Gruppe kürzer als *n*.

## `clump`: überlappendes, gleitendes Fenster der Größe *n*

```
clump ( seq n -- clumps )
```

```factor
USING: grouping ;

{ 1 2 3 4 5 } 2 clump .
! => { { 1 2 } { 2 3 } { 3 4 } { 4 5 } }
```

Ist die Sequenz kürzer als *n*, ist das Ergebnis leer.

## `split-when`: aufteilen, wo immer ein Prädikat zutrifft

```
split-when ( seq quot: ( elt -- ? ) -- pieces )
```

```factor
USING: splitting ;

{ 1 2 0 3 4 0 5 } [ zero? ] split-when .
! => { { 1 2 } { 3 4 } { 5 } }
```

Jedes Element bekommt seinen eigenen Aufruf des Prädikats. Elemente, für die es einen wahren Wert liefert, sind die *Bruchstellen* und werden nicht ins Ergebnis übernommen.

## `monotonic-split`: Läufe trennen, wo eine Prüfung benachbarter Paare fehlschlägt

```
monotonic-split ( seq quot: ( a b -- ? ) -- pieces )
```

```factor
USING: splitting.monotonic ;

{ 1 1 2 2 2 3 } [ = ] monotonic-split .
! => { { 1 1 } { 2 2 2 } { 3 } }
```

Das Prädikat wird auf *benachbarte Paare* angewendet. Solange es einen wahren Wert zurückgibt, läuft der aktuelle Lauf weiter; sobald es `f` zurückgibt, beginnt ein neues Stück. Mit `[ = ]` bekommst du Läufe aus gleichen Elementen, mit `[ <= ]` nicht absteigende Läufe und so weiter.

## Wann du zu welchem greifst

- **`group`/`clump`**: du kennst die *Größe*, die du haben willst.
- **`split-when`**: du weißt, wie ein *Bruchelement* aussieht.
- **`monotonic-split`**: du weißt, was zwei benachbarte Elemente *weiterhin zusammengehören* lässt.
