# Einführung

Common Lisp kennt ein Konzept namens The Printer, zu dem alle Funktionen gehören, die textuelle Darstellungen von Lisp-Daten schreiben. Eine dieser Funktionen ist `format`, mit der du die Daten nach deinen Wünschen formatieren kannst.

Die Möglichkeiten von `format` und des Lisp-Printers im Allgemeinen sind ein großes Thema; hier werden die Grundlagen der Verwendung von `format` beschrieben.

## Die Funktion FORMAT

Die Funktion `format` nimmt mindestens zwei Argumente: einen Stream, in den geschrieben wird, und einen Kontroll-String, der festlegt, was und wie ausgegeben wird.

Streams sind ein eigenes Konzept und werden an anderer Stelle beschrieben. Vorerst musst du nur wissen, dass die Ausgabe in den Stream erfolgt und dass es für dieses Argument zwei besondere Werte gibt: `t` und `nil`. `t` bedeutet, in die Standardausgabe zu schreiben (genauer: in den Stream, an den die Variable `*standard-output*` gebunden ist). Und `nil` bedeutet, einen String zu erzeugen und zurückzugeben.

Beachte, dass `format` immer `nil` ergibt, außer in diesem letzteren Fall, in dem `nil` als Stream angegeben wird. Das ist eine übliche Methode, um auf einfache Weise einen String zu interpolieren oder zusammenzusetzen.

```lisp
(format nil "hello world") ; => "hello world"
(format t "hello world")   ; => NIL (but "hello world" is printed to standard output)
```

## Formatdirektiven

Der Kontroll-String kann „Formatdirektiven“ enthalten, die `format` Anweisungen darüber geben, was auszugeben ist und wie alle weiteren Parameter von `format` zu interpretieren sind. In gewissem Sinn ist der Kontroll-String ein Programm, das `format` interpretiert und ausführt. Alle Direktiven beginnen mit `~`, auf das ein Zeichen folgt (_z. B._ `~A`, `~D`, `~&`). Die Groß- oder Kleinschreibung des Zeichens spielt keine Rolle.

Die meisten Formatdirektiven setzen einfach ein Argument von `format` in die Ausgabe ein. Man sagt, sie „verbrauchen“ das Argument. Manche Direktiven verbrauchen kein Argument oder mehr als eines. Eine Direktive erlaubt es sogar, in der Argumentliste zu springen oder Argumente zu überspringen.

## Grundlegende Formatierung

Eine sehr universell einsetzbare Formatdirektive ist `~A`. Sie gibt eine „menschenlesbare“ Version der Daten aus.

```lisp
(format nil "Value = ~a" 10)                ; => "10"
(format nil "hello ~a" "world")             ; => "hello world"
(format nil "The list is: ~A" (list 1 2 3)) ; => "The list is: (1 2 3)"
```

Eine weitere nützliche Formatdirektive ist `~S`. Sie gibt eine „maschinenlesbare“ Version der Daten aus. Das kann sehr nützlich sein, wenn du die erzeugte Ausgabe als Lisp-Daten interpretieren können willst. Für vieles sieht sie aus wie `~A`, aber beachte, dass bei Strings die Ausgabe zum Beispiel die Anführungszeichen enthält (escaped, wenn sie in einem anderen String stehen), sodass der Wert wieder als String-Parameter eingelesen werden könnte.

```lisp
(format nil "~s" 10)            ; => "10"
(format nil "~s" "hello world") ; => "\"hello world\""
(format nil "~s" (list 1 2 3))  ; => "(1 2 3)"
```

Zwei weitere sehr nützliche Direktiven sind `~%` und `~&`. Die erste gibt ein Zeilenumbruchzeichen aus, die letztere gibt eine „frische Zeile“ aus. Der Unterschied ist, dass `~%` immer einen Zeilenumbruch ausgibt, während `~&` nur dann einen ausgibt, wenn die Ausgabe gerade nicht am Zeilenanfang steht. Keine von beiden verbraucht ein Argument.

```lisp
(format nil "~%new~%lines") ; => "
                                  new
                                  lines"

(format nil "~&new~&lines"  ; => "new
                                  lines"
```

Schließlich ist `~~` eine einfache Direktive, die ein literales `~` ausgibt.
