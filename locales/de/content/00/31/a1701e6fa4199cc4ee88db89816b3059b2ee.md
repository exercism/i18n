# Einführung

Ein `string` in Go ist eine unveränderliche Folge von Bytes, die nicht unbedingt Zeichen darstellen müssen.

Ein Zeichenkettenliteral wird zwischen doppelten Anführungszeichen definiert:

```go
const name = "Jane"
```

Zeichenketten lassen sich mit dem `+`-Operator verketten:

```go
"Jane" + " " + "Austen"
// => "Jane Austen"
```

Einige Sonderzeichen müssen mit einem vorangestellten Backslash maskiert werden, zum Beispiel `\t` für einen Tabulator und `\n` für einen Zeilenumbruch in Zeichenketten.

```go
"How is the weather today?\nIt's sunny"  
// =>
// How is the weather today?
// It's sunny
```

Das Paket `strings` enthält viele nützliche Funktionen, mit denen du Zeichenketten bearbeiten kannst.
Weitere Informationen zu Zeichenkettenfunktionen findest du in der [strings-Paketdokumentation](https://pkg.go.dev/strings).
Hier sind einige Beispiele:

```go
import "strings"

// strings.ToLower returns the string given as argument with all its characters lowercased
strings.ToLower("MaKEmeLoweRCase")
// => "makemelowercase"

// strings.Repeat returns a string with a substring given as argument repeated many times
strings.Repeat("Go", 3)
// => "GoGoGo"
```
