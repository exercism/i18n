# Einführung

Tupel sind eine einfache Möglichkeit, eine feste Anzahl beliebiger Datentypen zusammenzufassen. Ein Tupel hat keinen bestimmten Namen; sobald du einer Datenstruktur einen Namen gibst, wird daraus ein `struct`. Die Felder eines Tupels haben keine Namen; auf sie greifst du über Destrukturierung oder über ihre Position zu.

## Syntax

### Erstellung

Tupel werden immer mit einem Tupelausdruck erstellt:

```rust
// pointless but legal
let unit = ();
// single element
let single_element = ("note the comma",);
// two element
let two_element = (123, "elements can be of differing types");
```

Tupel können eine beliebige Anzahl von Elementen haben.

### Zugriff durch Destrukturierung

Du kannst auf die Elemente eines Tupels durch Destrukturierung zugreifen. Das bedeutet, dass du den einzelnen Elementen des Tupels Variablennamen zuweist und das Tupel dabei verbrauchst.

```rust
let (elem1, _elem2) = two_element;
assert_eq!(elem1, 123);
```

### Zugriff über die Position

Du kannst auf die Elemente eines Tupels auch über ihren numerischen Positionsindex zugreifen. Die Indexierung beginnt wie immer bei 0.

```rust
let notation = single_element.0;
assert_eq!(notation, "note the comma");
```

## Tupelstrukturen

Außerdem wirst du mit Tupelstrukturen arbeiten. Wie normale Strukturen sind sie benannte Typen; anders als normale Strukturen haben sie anonyme Felder. Ihre Syntax ist der normalen Tupelsyntax sehr ähnlich. Du darfst sowohl Destrukturierung als auch den Zugriff über die Position verwenden.

```rust
struct TupleStruct(u8, i32);
let my_tuple_struct = TupleStruct(123, -321);
let neg = my_tuple_struct.1;
let TupleStruct(byte, _) = my_tuple_struct;
assert_eq!(neg, -321);
assert_eq!(byte, 123);
```

### Sichtbarkeit von Feldern

Alle Felder anonymer Tupel sind immer öffentlich. Die Felder von Tupelstrukturen haben dagegen jeweils eine eigene Sichtbarkeit, die standardmäßig privat ist, genau wie die Felder normaler Strukturen. Mit dem Modifizierer `pub` kannst du die Felder öffentlich machen, genau wie bei einer normalen Struktur.

```rust
// fails due to private fields
mod tuple { pub struct TupleStruct(u8, i32); }
fn main() { let _my_tuple_struct = tuple::TupleStruct(123, -321); }
```

```rust
// succeeds: fields are public
mod tuple { pub struct TupleStruct(pub u8, pub i32); }
fn main() { let _my_tuple_struct = tuple::TupleStruct(123, -321); }
```
