# Grundlagen

Ein Sather-Programm besteht aus **Klassen**. Eine Klasse ist eine benannte Kiste, die Routinen enthält. Eine **Routine** ist eine benannte Arbeit, die ein Ergebnis liefert.

```sather
class GREETER is

   hello : STR is
      return "Hello!";
   end;

end; -- class GREETER
```

Von oben gelesen:

- `class GREETER is` öffnet die Kiste und gibt ihr einen Namen. Klassennamen werden in Großbuchstaben geschrieben.
- `hello : STR is` startet eine Routine namens `hello`, die einen `STR` erzeugt, also ein Stück Text, das man *String* nennt. Das `: STR` ist ein Versprechen darüber, welche Art von Ergebnis zurückkommt.
- `return "Hello!";` gibt das Ergebnis zurück. Text wird zwischen doppelten Anführungszeichen geschrieben.
- `end;` schließt die Routine, und das zweite `end;` schließt die Klasse.

Alles, was in einer Zeile nach `--` steht, ist ein **Kommentar**. Sather ignoriert ihn; er ist für die Menschen da.

```sather
-- This line is for the reader, not the computer.
```

Um eine Routine von woanders zu verwenden, schreibst du den Klassennamen, zwei Doppelpunkte und den Routinennamen:

```sather
GREETER::hello        -- this is "Hello!"
```

Innerhalb derselben Klasse kannst du den Klassennamen weglassen:

```sather
class GREETER is

   hello : STR is
      return "Hello!";
   end;

   greeting_again : STR is
      return hello;      -- calls the routine just above
   end;

end; -- class GREETER
```

Eine Routine, die keine Argumente entgegennimmt, wird ohne runde Klammern aufgerufen: `hello`, nicht `hello()`.
