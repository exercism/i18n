# Anleitung

Jedes Sicherheitsgeschirr im Zirkus ist für eine Last in Kilogramm zugelassen, und niemand steigt hinauf, bevor die Werte geprüft worden sind.

Die Klasse `SAFETY_HARNESS` braucht Folgendes. Das Stub gibt dir die Klasse und ihr Attribut; den Rest fügst du hinzu. Jede der unten stehenden Routinen hat einen Kontrakt; die Hinweise verraten dir, welche.

## 1. Ein Sicherheitsgeschirr aufbauen

`create` nimmt die Last entgegen, für die das Sicherheitsgeschirr zugelassen ist, und gibt ein Sicherheitsgeschirr zurück. Eine Zulassung von null oder weniger ist überhaupt kein Sicherheitsgeschirr, das ist also ein `pre`.

```sather
harness ::= #SAFETY_HARNESS(120);
harness.limit
-- => 120
```

## 2. Wie viel ist noch frei?

`spare_capacity` nimmt die Last auf dem Sicherheitsgeschirr und gibt zurück, wie viel mehr es tragen könnte. Die Last darf nicht negativ sein und darf das Limit nicht überschreiten, beides `pre`. Die Antwort ist nie negativ, das ist ein `post`.

```sather
harness.spare_capacity(40)
-- => 80
```

## 3. Wie voll ist es?

`percent_used` nimmt die Last und gibt sie als Prozentwert des Limits zurück, abgerundet. Die Last darf nicht negativ sein, und die Antwort ist nie negativ.

```sather
harness.percent_used(60)
-- => 50
```

## 4. Ist es sicher?

`is_safe` nimmt die Last und beantwortet, ob sie innerhalb des Limits liegt. Du kannst nach jeder beliebigen Last fragen, auch nach einer unsinnigen. Deshalb gibt es kein `pre` für die Last. Aber schreibe ein `post`, das besagt, dass die Antwort genau dann wahr ist, wenn die Last innerhalb des Limits liegt.

```sather
harness.is_safe(200)
-- => false
```
