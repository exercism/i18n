# Anleitung

Während du bei _Instruments of Texas_ arbeitest, sollst du an einem experimentellen Rechner für die umgekehrte polnische Notation [RPN] arbeiten, der in Elixir geschrieben ist. Dein Team hat ein Problem damit, dass einige Operationen Fehler auslösen und den Prozess zum Absturz bringen. Du sollst eine Funktion schreiben, die die Operationsfunktion verpackt, damit die Fehler mit idiomatischem Elixir-Code eleganter behandelt werden können.

## 1. Warne das Team

Implementiere die Funktion `calculate!/2`, um die Operationsfunktion mit dem Stack als einzigem Argument aufzurufen. Die Operationsfunktion ist woanders definiert, aber du weißt, dass sie entweder erfolgreich abgeschlossen wird oder einen Fehler auslöst.

```elixir
stack = []
operation = fn _ -> :ok end
RPNCalculator.calculate!(stack, operation)
# => :ok

stack = []
operation = fn _ -> raise ArgumentError, "An error occurred" end
RPNCalculator.calculate!(stack, operation)
# => ** (ArgumentError) An error occurred
```

> Funktionsnamen, die auf `!` enden, sind eine Warnung an Programmierer, dass diese Funktion einen Fehler auslösen kann

## 2. Verpacke den Fehler

Bei weiterer Recherche fällt dir auf, dass viele Funktionen Atome und Tupel verwenden, um ihren Erfolg oder Misserfolg anzuzeigen. Implementiere `calculate/2` mit dieser Strategie.

```elixir
stack = []
operation = fn _ -> "operation completed" end
RPNCalculator.calculate(stack, operation)
# => {:ok, "operation completed"}

stack = []
operation = fn _ -> raise ArgumentError, "An error occurred" end
RPNCalculator.calculate(stack, operation)
# => :error
```

## 3. Gib die Nachricht weiter

Einige der Fehler enthalten wichtige Informationen, die deine Kollegen brauchen, um den korrekten Betrieb des Systems sicherzustellen. Implementiere `calculate_verbose/2`, um die Fehlermeldung weiterzugeben. Der Fehler ist ein Struct, das ein Feld `:message` hat.

```elixir
stack = []
operation = fn _ -> "operation completed" end
RPNCalculator.calculate_verbose(stack, operation)
# => {:ok, "operation completed"}

stack = []
operation = fn _ -> raise ArgumentError, "An error occurred" end
RPNCalculator.calculate_verbose(stack, operation)
# => {:error, "An error occurred"}
```
