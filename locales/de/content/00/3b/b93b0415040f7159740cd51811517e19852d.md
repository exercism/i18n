# Tests

Um den Test-Runner zu verwenden, musst du [Godot korrekt installiert][installation] haben.

## Tests ausführen

Mit dem [Test-Runner][test runner] lädst du Lösungen und testest sie.
Um den Test-Runner auszuführen, lädst du ihn herunter und startest ihn anschließend mit `godot`.
In Zukunft wird der Test-Runner automatisch zusammen mit den Übungen heruntergeladen, wenn du `exercism download` verwendest.

### Test-Runner herunterladen

Mit dem folgenden Shell-Snippet kannst du den Test-Runner herunterladen.

```bash
exercism download --track gdscript --exercise hello-world
cd "$(exercism workspace)/gdscript"
curl --remote-name https://raw.githubusercontent.com/exercism/gdscript-test-runner/refs/heads/main/bin/test_runner.gd
```

### Den Test-Runner ausführen

Der Test-Runner wird mit `godot` im Headless-Modus (ohne IDE) ausgeführt.
`-s` oder `--script` weist Godot an, das Skript des Test-Runners auszuführen.
Der Test-Runner erwartet zwei Argumente: den Slug und den Pfad zum Verzeichnis der Lösung.

```bash
godot --headless -s to/test_runner.gd -- <solution-slug> <path/to/solution>
```

Zum Beispiel:

```bash
godot --headless -s "$(exercism workspace)/gdscript/test_runner.gd" -- hello-world "$(exercism workspace)/gdscript/hello-world
```
