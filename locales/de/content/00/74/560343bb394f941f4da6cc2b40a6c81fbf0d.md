# Anleitung

Wandle eine Oktalzahl, die als String dargestellt wird (z. B. '1735263'), nach den Grundprinzipien in ihr Dezimaläquivalent um (d. h. nein, du darfst keine eingebauten oder externen Bibliotheken verwenden, um die Umwandlung durchzuführen).

Implementiere die Umwandlung von Oktal zu Dezimal.
Wenn dein Programm einen Oktal-String als Eingabe erhält, soll es eine Dezimalzahl als Ausgabe liefern.

## Hinweis

- Implementiere die Umwandlung selbst.
  Verlass dich nicht auf etwas anderes, das die Umwandlung für dich durchführt.
- Behandle ungültige Eingaben wie die Oktalzahl 0.

## Über Oktal (Basis 8)

Dezimal ist ein System zur Basis 10.

Eine Zahl 233 in der Basis-10-Schreibweise lässt sich als Linearkombination von Potenzen von 10 verstehen:

- Die rechteste Ziffer wird mit 10^0 = 1 multipliziert
- Die nächste Ziffer wird mit 10^1 = 10 multipliziert
- ...
- Die n-te Ziffer wird mit 10^_(n-1)_ multipliziert.
- Alle diese Werte werden addiert.

Also:

```text
   233 # decimal
 = 2*10^2 + 3*10^1 + 3*10^0
 = 2*100  + 3*10   + 3*1
```

Oktal ist ähnlich, verwendet aber Potenzen von 8 statt Potenzen von 10.

Also:

```text
   233 # octal
 = 2*8^2 + 3*8^1 + 3*8^0
 = 2*64  + 3*8   + 3*1
 = 128   + 24    + 3
 = 155
```
