# Einführung

## Klassen

Klassen sind eine Einheit zur Organisation von Code in PHP.
Code, der das Verhalten eines Gegenstands oder das Verhalten eines Prozesses beschreibt, kann in einer Klasse zusammengefasst werden.
Funktionen, die einer Klasse zugeordnet sind, nennt man üblicherweise `methods`.

```php
<?php

class Door
{
    function lock()
    {
        // ...
    }

    function unlock()
    {
        // ...
    }
}
```

Klassen werden mit dem Schlüsselwort `new` instanziiert. Das weist Speicher für die Klasseninstanz zu und ruft die Konstruktormethode der Klasse auf.
Instanziierte Klassen können einer Variable zugewiesen werden.
Um die Methoden einer Klasseninstanz aufzurufen, verwenden wir den Zugriffsoperator `->`.

```php
<?php

$a_door = new Door();
$a_door->lock();
$a_door->unlock();
```

Eine instanziierte Klasse kann über die spezielle Variable `$this` auf ihre eigene Instanz verweisen.
Klassen können außerdem Eigenschaften haben. Sie wirken wie Variablen, die an die Instanz des Klassenobjekts gebunden sind.
Auf diese Eigenschaften kann intern oder extern zugegriffen werden.

```php
<?php

class Car
{
    public $color;

    function __construct($color)
    {
        $this->color = $color;
    }

    function getColor()
    {
        return $this->color;
    }
}

$a_car = new Car("red");
$a_car->color; // => "red" by accessing the property
$a_car->getColor(); // => "red" by invoking the instance method
```
