# Über

Funktionen in Elixir lassen sich dynamisch aufrufen.

Alle Modulnamen sind Atome. Beim Kompilieren wird allen Elixir-Modulnamen automatisch `Elixir.` vorangestellt.

```elixir
is_atom(Enum)
# => true
Enum == Elixir.Enum
# => true
```

Elixir kann zur Laufzeit auflösen, welche Funktion aufgerufen wird, indem es über den Namen des Moduls nachschlägt. Diese Suche kann dynamisch erfolgen, wenn der Name des Moduls an eine Variable gebunden ist.

```elixir
defmodule MyModule do
  def message(), do: "My message"
end

atom = MyModule
atom.message()
# => "My message"
```
