# Einführung

Ein *regulärer Ausdruck* (Regex) ist ein kleines Muster, das beschreibt, wie ein Text aussehen soll. Die Regex-Werkzeuge von Factor findest du im Vokabular [`regexp`][regexp], und ein Muster schreibst du zwischen `R/ ` und `/`.

Die meisten Zeichen in einem Muster stehen für sich selbst. Ein paar besondere Bausteine stehen für *Arten* von Zeichen oder dafür, *wie viele* es sein sollen:

```
\d        ! any digit 0–9
\s        ! any whitespace; \S means any non-whitespace
[A-Z]     ! any one capital letter
.         ! any single character

{4}       ! exactly 4 times       +   ! one or more
{2,5}     ! 2 to 5 times          *   ! zero or more
?         ! optional (0 or 1)
```

So bedeutet `R/ [A-Z]{2}-\d{4}/` so viel wie „zwei Großbuchstaben, ein Bindestrich, vier Ziffern“.

`matches?` prüft, ob ein *ganzer* String zum Muster passt:

```
matches? ( string regexp -- ? )
```

```factor
USING: regexp ;

"NS-1024" R/ [A-Z]{2}-\d{4}/ matches? .   ! => t
"NS-10"   R/ [A-Z]{2}-\d{4}/ matches? .   ! => f
```

Andere Wörter schauen *in* einen String hinein: `all-matching-subseqs` gibt jeden Treffer zurück, `count-matches` zählt sie, `re-contains?` gibt an, ob es einen Treffer gibt, und `re-replace` ersetzt jeden Treffer durch neuen Text:

```
all-matching-subseqs ( string regexp -- seq )
count-matches        ( string regexp -- n )
re-contains?         ( string regexp -- ? )
re-replace           ( string regexp replacement -- result )
```

```factor
USING: regexp ;

"seen NS-1024 then AB-0007" R/ [A-Z]{2}-\d{4}/ all-matching-subseqs .
! => { "NS-1024" "AB-0007" }

"user=alice pass=hunter2" R/ pass=\S+/ "pass=****" re-replace .
! => "user=alice pass=****"
```
