# Hinweise

Dein Code sollte eine Funktion frequency :: Int -> [Text] -> Map Char Int enthalten, die eine Anzahl von Workern für die parallele Verarbeitung sowie eine Liste von Texten entgegennimmt und die Gesamthäufigkeit jedes Buchstabens im Text zurückgibt.

## Benchmark

Finde heraus, wie sich eine geänderte Anzahl von Workern auf die Performance deiner Lösung auswirkt, indem du den Benchmark ausführst. Verwende `stack bench`, um ihn auszuführen. Du kannst `bench/Benchmark.hs` gerne anpassen, um die Performance deiner Lösung mit verschiedenen Eingaben zu untersuchen.
