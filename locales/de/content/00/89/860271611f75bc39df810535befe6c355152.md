# Stub-Kommentare ersetzen

Ersetze die Stub-Kommentare durch eine kurze, aber hilfreiche Beschreibung des Pakets und ein bis zwei Sätze, die erklären, was die Funktion tut, welche Parameter sie entgegennimmt und was sie zurückgibt.
Genaue und hilfreiche Kommentare zur Verwendung des Codes sind für Go-Entwickler sehr wichtig.
Dies ist eine großartige Anleitung zum Schreiben guter Kommentare: [Effective Go: Commentary](https://golang.org/doc/effective_go.html#commentary).
Das Tool `godoc` erzeugt beim Ausführen automatisch eine Dokumentation aus den Kommentaren im Code.
Unter [godoc.org](https://godoc.org) findest du Beispiele dafür, wie das aussieht.
