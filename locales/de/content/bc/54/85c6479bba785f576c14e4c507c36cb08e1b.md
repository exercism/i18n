# Einführung

## Anonyme Funktionen

Gleam hat Funktionen als Werte erster Klasse. Das bedeutet, dass Funktionen normale Werte sind: Du kannst sie Variablen zuweisen, als Argumente übergeben und aus anderen Funktionen zurückgeben.

Eine benannte Funktion, die in einem Modul definiert ist, kannst du über ihren Namen referenzieren.

```gleam
pub fn main() {
  // Assign the function to a variable
  let f = add_one
  
  // Invoke the function
  f(1) // -> 2
  f(2) // -> 3
}

fn add_one(x) {
  x + 1
}
```

Gleam kennt außerdem anonyme Funktionen, die du innerhalb anderer Funktionen definierst.

```gleam
// Define the function
let f = fn(x) { x + 1 }

// Invoke the function
f(1) // -> 2
f(2) // -> 3
```

Den Typ einer Funktion schreibst du mit einer ähnlichen Syntax wie anonyme Funktionen. Der Typ einer Funktion, die einen `Int` und einen `Float` entgegennimmt und einen `Int` zurückgibt, sieht so aus:

```gleam
fn(Int, Float) -> Int
```

Anonyme Funktionen können auf Variablen zugreifen, die sich beim Definieren im Gültigkeitsbereich befanden. Dadurch sind sie _Closures_.

```gleam
let secret_number = 42

// This function always returns 42
fn() { secret_number }
```

Die Syntax der _Function Capture_ bietet eine praktische Kurzschreibweise, um anonyme Funktionen zu erstellen, die ein einzelnes Argument an eine Funktion übergeben. Diese beiden Ausdrücke sind äquivalent:

```gleam
// Anonymous function syntax
let f = fn(x) { my_function(1, 2, x) }

// Function capture syntax
let f = my_function(1, 2, _)
```
