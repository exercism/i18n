# Strings

Ein **String (Zeichenkette)** ist ein Stück Text. Sathers Typ dafür ist `STR`, und ein String wird zwischen doppelten Anführungszeichen geschrieben.

```sather
   composer : STR is
      return "Sibelius";
   end;
```

## Strings verbinden

`+` hängt zwei Strings aneinander.

```sather
"Jean" + " " + "Sibelius"      -- "Jean Sibelius"
```

Zwischen ihnen wird nichts eingefügt, deshalb musst du ein Leerzeichen ausdrücklich angeben. Lässt du es weg, erhältst du `"JeanSibelius"`.

## Wie lang ist ein String?

`.size` gibt an, wie viele Zeichen ein String enthält. Das ist eine Ganzzahl, also ist sein Typ `INT`.

```sather
"Sibelius".size      -- 8
```

Nach `.size` stehen keine runden Klammern, genau wie bei einer Routine, die keine Argumente entgegennimmt.

## Ein Stück herausnehmen

`.head(n)` liefert die ersten `n` Zeichen. `.tail(n)` liefert die letzten `n`.

```sather
"Sibelius".head(3)   -- "Sib"
"Sibelius".tail(4)   -- "lius"
```

`head` zählt von vorne, `tail` zählt von hinten. Beide lassen den ursprünglichen String unverändert und geben einen neuen zurück.
