# Über

[ABAP][abap] ist eine Programmiersprache, die SAP für die Entwicklung von Geschäftsanwendungen mit der ABAP-Entwicklungsumgebung einer ABAP Platform entwickelt hat.

ABAP unterstützt Folgendes:

- Ein objektorientiertes Programmiermodell, das auf Klassen und Schnittstellen von ABAP Objects basiert.
- Ein prozedurales Programmiermodell, das auf Funktionsbausteinen und Unterprogrammen basiert.

Beide Modelle sind interoperabel, auf Exercism liegt der Schwerpunkt jedoch ausschließlich auf dem objektorientierten Programmiermodell.

Weitere Informationen findest du in der [Dokumentation zum ABAP-Track][docs].
