# Einführung

Unison stellt die Werte wahr und falsch mit dem Typ `Boolean` dar. Es gibt nur zwei Werte: `true` und `false`.

```unison
trueVariable = true
falseVariable = false
```

Boolesche Ausdrücke werten wir mit den Operatoren und (dargestellt durch `&&`), oder (dargestellt durch `||`) und nicht (dargestellt durch `not`) aus.

```unison
trueVariable = true && true
falseVariable = true && false

trueVariable = false || true
falseVariable = false || false

trueVariable = not false
falseVariable = not true
```

Boolesche Ausdrücke in Unison erlauben die Kurzschlussauswertung: Ist das erste Argument eines `&&`-Ausdrucks `false`, gibt es keinen Grund, das zweite Argument weiter auszuwerten. Ebenso gibt der Ausdruck sofort `true` zurück, wenn das erste Argument eines `||`-Ausdrucks `true` ist.

```unison
> false && (base.bug "oh no")
  ⧩
  false
```

```unison
> true || (base.bug "oh no")
  ⧩
  true
```
