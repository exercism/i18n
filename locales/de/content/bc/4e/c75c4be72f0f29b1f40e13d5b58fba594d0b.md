# Waage

## Geschichte

In dieser Übung modellierst du eine Waage.

Das Gewicht kann in Pfund oder Kilogramm gesetzt und abgerufen werden und darf nicht negativ sein.

Das Gewicht kann in SI-Einheiten oder in US-Einheiten angezeigt werden, also Pfund und Unzen.

Auf das Gewicht kann eine Tara-Anpassung angewendet werden (zum Beispiel, um das Gewicht eines Behälters abzuziehen). Dieser Wert kann beliebig sein (sogar negativ oder ein Wert, der das angezeigte Gewicht negativ macht), da Zweifel an der Genauigkeit der Waage bestehen. Aus Sicherheitsgründen kann dieser Wert nicht abgerufen werden.

Beachte:

```
display-weight = input-weight - tare-adjustment
```

Die Umrechnungsfaktoren lauten:

- 16 Unzen entsprechen einem Pfund
- 2,20462 kg entsprechen einem Pfund

Zum Beispiel:

- 60 Kilogramm == 132,2772 Pfund
- 132,2772 Pfund == 132 Pfund 4 Unzen

## Aufgaben

Dies sind Beispielaufgaben, die zur Übung „Waage“ passen:

- Erlaube, das Gewicht der Waage festzulegen
- Stelle sicher, dass ein negatives Eingabegewicht abgelehnt wird
- Erlaube, das US-Gewicht abzurufen
- Erlaube, die Einheiten der Waage auf Pfund einzustellen
- Erlaube, eine Tara-Anpassung auf die Waage anzuwenden
