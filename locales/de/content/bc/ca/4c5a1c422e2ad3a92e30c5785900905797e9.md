# Repo-Berechtigungen für Maintainer

Ein Track-Maintainer ist jemand, der Mitglied im GitHub-Team eines Tracks ist.
Mitglied in einem Track-Team zu werden, ist _nur auf Einladung_ möglich.

```exercism/note
Wenn du ein Track-Maintainer werden möchtest, eröffne bitte ein Thema im [Forum](https://forum.exercism.org/c/exercism/building-exercism/125).
```

## Wartungskategorie

Es gibt fünf Wartungskategorien:

1. `wip-track`
2. `unmaintained`
3. `maintained-solitary`
4. `maintained-autonomous`
5. `maintained`

Die Wartungskategorie eines Tracks wird durch drei Variablen bestimmt:

1. Ob der Track aktiv ist (d. h., Lernende können dem Track auf der Website beitreten)
2. Die Anzahl der Track-Maintainer
3. Die Anzahl der Track-Maintainer, die außerdem im GitHub-Team `cross-track-maintainers` sind

Um die Wartungskategorie zu bestimmen, suche in dieser Tabelle die erste Kategorie, die auf den Track zutrifft:

| Kategorie             | Aktiv? | Anzahl der Maintainer | Anzahl der Cross-Track-Maintainer |
| --------------------- | ------ | --------------------- | --------------------------------- |
| wip-track             | Nein   | Beliebig             | Beliebig                          |
| unmaintained          | Ja     | 0                     | 0                                 |
| maintained-autonomous | Ja     | > 0                   | = Anzahl der Maintainer           |
| maintained-solitary   | Ja     | 1                     | 0                                 |
| maintained            | Ja     | > 1                   | < Anzahl der Maintainer           |

## Repo-Berechtigungen

Die Wartungskategorie wird verwendet, um die Berechtigungen der GitHub-Repos eines Tracks festzulegen.

| Kategorie             | Erfordert PR | Erfordert PR-Genehmigung | Reviews des Cross-Track-Teams |
| --------------------- | ------------ | ------------------------ | ----------------------------- |
| wip-track             | Nein         | Nein                     | Nein                          |
| unmaintained          | Ja           | Ja                       | Ja                            |
| maintained-solitary   | Ja           | Ja                       | Ja                            |
| maintained-autonomous | Ja           | Nein                     | Nein                          |
| maintained            | Ja           | Nein                     | Nein                          |

```exercism/caution
Die Kategorie `wip-track` ist die einzige Kategorie, die es Maintainern erlaubt, nach `main` zu pushen.
```

```exercism/caution
Tooling-Repos erfordern _immer_ eine PR-Genehmigung, da ihr Inhalt über eine [CODEOWNERS-Datei](https://docs.github.com/en/repositories/managing-your-repositorys-settings-and-features/customizing-your-repository/about-code-owners) geschützt ist.
```
