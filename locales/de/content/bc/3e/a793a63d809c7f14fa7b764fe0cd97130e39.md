# Über

In Elixir gibt es zwei verschiedene Arten von Zahlen: Ganzzahlen und Gleitkommazahlen.

Ganzzahlen sind Zahlen ohne Nachkommastellen.

```elixir
integer = 3
# => 3
```

Ein paar nützliche Funktionen für die Arbeit mit Ganzzahlen findest du im Modul [`Integer`][integer].

```elixir
Integer.digits(123)
# => [1, 2, 3]
```

Große Ganzzahlen (aber auch Gleitkommazahlen) werden üblicherweise formatiert, indem man jeweils 3 Ziffern mit einem Unterstrich zu einer Gruppe zusammenfasst.

```elixir
1_000_000
# => 1000000
```

Die maximale Größe von Zahlen in Elixir ist nur durch den Speicher begrenzt, der auf dem System verfügbar ist, weil Elixir [Arithmetik mit beliebiger Genauigkeit][arbitrary-precision-arithmetic] verwendet.

Elixir unterstützt außerdem Kurzschreibweisen für die Eingabe von [Ganzzahlen zur Basis 2, 8 und 16][integers-in-other-bases].

```elixir
0b0100
# => 4

0o555
# => 365

0xFF
# => 255
```

## Vergleich

Ganzzahlen und Gleitkommazahlen können als gleich ([`==`][kernel-equal]) gelten, wenn sie denselben Wert haben. Da es sich aber um unterschiedliche Typen handelt, sind sie niemals streng gleich ([`===`][kernel-strictly-equal]).

```elixir
1 == 1.0
# => true

1 === 1.0
# => false
```
