# Einführung

Ein Switch-Ausdruck kann einen Wert einem Fall aus einer Menge von Mustern zuordnen und den zugehörigen Wert zurückgeben oder die zugehörige Aktion ausführen. Die Zuordnung wird durch das Symbol `=>` angegeben. Außerdem kann jedes Muster eine optionale Case Guard haben, die mit dem Schlüsselwort `when` eingeleitet wird. Der Ausdruck der Case Guard muss wahr ergeben, damit dieser „Arm“ des Switch-Ausdrucks ausgewählt wird. Die Fälle (auch _Switch-Arme_ genannt) werden in der Reihenfolge ausgewertet, in der sie im Text stehen. Sobald eine Übereinstimmung gefunden wird, wird die Auswertung abgebrochen und der zugehörige Wert zurückgegeben.

```csharp
double xx = 42d;

string interesting = xx switch
{
    0 => "I suppose zero is interesting",
    3.14 when DateTime.Now.Day == 14 && DateTime.Now.Month == 3 => "Mmm pie!",
    3.14 => "π",
    42 => "a bit of a cliché",
    1729 => "only if you are a pure mathematician",
    _ => "not interesting"
};

// => interesting == "a bit of a cliché"
```
