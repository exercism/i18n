# Tests

Sorge dafür, dass der erste Test kompiliert, linkt und besteht, indem du den [drei Regeln der testgetriebenen Entwicklung][3-tdd-rules] folgst.

Mit dem mitgelieferten Makefile kannst du die Tests mit dem `test`-Task erstellen und ausführen.

```console
$ make test
```

Erstelle nur die Funktionen, die du brauchst, um etwaige Compilerfehler zu beheben, und sorge dafür, dass der Test fehlschlägt.
Dann schreib gerade so viel Code, dass der Test besteht.
Wenn du das geschafft hast, geht es weiter mit dem nächsten Test.

Während du dich durch die Tests arbeitest, nimm dir die Zeit, deine Implementierung auf Lesbarkeit und Ausdruckskraft hin zu refaktorieren, und mach dann mit dem nächsten Test weiter.

Versuche, die Standardmittel von C99 zu verwenden, anstatt deine eigenen Low-Level-Algorithmen oder -Einrichtungen von Hand zu schreiben.

## Auf Speicherlecks prüfen

Das Makefile enthält außerdem einen Build, der einige häufige Fehler in Bezug auf Speicherlecks und Zugriffe außerhalb der Array-Grenzen prüft.
Um diese Prüfungen auszuführen, verwendest du auf der Kommandozeile Folgendes:

```console
$ make memcheck
```
