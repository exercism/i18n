# Einführung

Ein [`string`][ref-string] in Kotlin ist eine unveränderliche Folge von Unicode-Zeichen.

`Immutable` bedeutet, dass jede Operation auf einem String einen neuen String zurückgeben muss: Der ursprüngliche String kann sich niemals ändern.

`Unicode` bedeutet, dass die meisten Schriftsysteme der Welt dargestellt werden können, aber (im Gegensatz zu älteren Sprachen wie C) gibt es keine 1:1-Zuordnung zwischen Zeichen und Bytes.

Ein String wird normalerweise von doppelten Anführungszeichen `" "` umschlossen.

Einige Zeichen müssen escaped werden: `\'`, `\\`, außerdem die üblichen nicht druckbaren Zeichen wie `\t` (Tabulator) und `\n` (Zeilenumbruch).

```kotlin
val s = "Escape apostrophe \' and backslash \\."
// Escape apostrophe ' and backslash \.
```

Mehrzeilige Strings werden von 3 doppelten Anführungszeichen umschlossen und können beliebigen Text enthalten (kein Escaping nötig).

```kotlin
val multi = """I'm a
    multi-line
    string with special characters \ \t """
//I'm a
//    multi-line
//    string with special characters  \ \t 
```

Nutze [trimIndent][trimIndent-doc], um die gemeinsame Einrückung der Zeilen zu entfernen.
Das ist praktisch, um den String zu formatieren:

```kotlin
val multi = """
    I'm a
      multi-line
    string""".trimIndent()

//I'm a
//  multi-line
//string
```

Alternativ kannst du mit [trimMargin][trimMargin-doc] ein Trennzeichen festlegen.
Jede Zeile im `String` beginnt dann nach dem Trennzeichen.
Standardmäßig ist das Trennzeichen `|`, aber du kannst als Parameter ein anderes Trennzeichen angeben.
Zum Beispiel:

```kotlin
val multi = """
    |I'm a
    |  multi-line
    |string""".trimMargin()

//I'm a
//  multi-line
//string

val multi2 = """
    start>I'm a
    start>  multi-line
    start>string""".trimMargin("start>")

//I'm a
//  multi-line
//string
```

Strings lassen sich mit `+` verketten, aber das sollte man auf kurze und einfache Fälle beschränken.
Es gibt andere und oft bessere Möglichkeiten.

## String-Templates

Damit ist gemeint, was andere Sprachen „Interpolation“ nennen.

Wenn ein String ein Dollarzeichen `$` enthält, auf das ein Bezeichner folgt, oder Klammern (`{expression}`) um einen Ausdruck herum, dann werden diese durch den Wert bzw. das Ergebnis des Ausdrucks ersetzt.

```kotlin
val x = 42
val st = "x is $x, x squared is {x * x}"
// x is 42, x squared is 1764
```

Die Klammern `{ }` sind um Ausdrücke herum nötig, wenn das Parsen sonst mehrdeutig wäre.

Im Allgemeinen sind String-Templates eine effizientere und idiomatischere Art, Strings zu kombinieren, als `+` zu verwenden.

## String-Funktionen

Kotlin bietet _viele_ [`functions`][ref-string-functions], um Strings zu bearbeiten.

Meist sind das [`extensions functions`][ref-extensions] und keine Member der `String`-Klasse, was aber wenig Einfluss darauf hat, wie wir sie verwenden.

~~~~exercism/note
Die recht komplexen [Dokumentationsseiten][ref-string-functions] von Kotlin verstecken Erweiterungsfunktionen in der Standardansicht.
Klicke unbedingt auf `Members & Extensions`, um diesen Bereich aufzuklappen.

[ref-string-functions]: https://kotlinlang.org/api/core/kotlin-stdlib/kotlin/-string/
~~~~

Die folgenden Beispiele zeigen nur eine kleine Auswahl dessen, was es gibt:

```kotlin
val str = "Hello World!"

str.length              // => 12 (a property, not a function)
str.elementAt(6)        // => W
str.elementAtOrNull(20) // => null (index out of range)
str.substring(6, 11)    // => "World"
str.substringAfter(" ") // => "World!"

str.lowercase()         // => "hello world!"
str.uppercase()         // => "HELLO WORLD!"

str.startsWith("Hel")   // => true
str.endsWith("xyz")     // => false
str.indexOf("0")        // => 4

str.toCharArray()       // => [H, e, l, l, o,  , W, o, r, l, d, !]
"42".toInt() + 1        // => 43  (parsing; see also toFloat)

"Howdy!  ".trim()       // => "Howdy"
```
