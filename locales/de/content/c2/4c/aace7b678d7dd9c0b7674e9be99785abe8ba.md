# Einführung

Elixir ist eine dynamisch typisierte Sprache, das heißt, sie bietet keine Typprüfung zur Kompilierzeit. Trotzdem können Typspezifikationen als eine Form der Dokumentation verwendet werden.

Eine Typspezifikation kann mithilfe des Modulattributs `@spec` direkt vor der Funktionsdefinition zu einer Funktion hinzugefügt werden. Auf `@spec` folgen der Funktionsname und eine Liste der Typen aller ihrer Argumente in runden Klammern, durch Kommas getrennt. Der Typ des Rückgabewerts wird mit einem doppelten Doppelpunkt `::` von den Argumenten der Funktion getrennt.

```elixir
@spec longer_than?(String.t(), non_neg_integer()) :: boolean()
def longer_than?(string, length), do: String.length(string) > length
```

## Typen

Zu den am häufigsten verwendeten Typen gehören:

- boolesche Werte: `boolean()`
- Strings: `String.t()`
- Zahlen: `integer()`, `non_neg_integer()`, `pos_integer()`, `float()`
- Listen: `list()`
- ein Wert eines beliebigen Typs: `any()`

Einige Typen können auch parametrisiert werden, zum Beispiel ist `list(integer)` eine Liste von Ganzzahlen.

Auch Literalwerte können als Typen verwendet werden.

Eine Vereinigung von Typen kann mit dem Pipe-Zeichen `|` geschrieben werden. Zum Beispiel bedeutet `integer() | :error` entweder eine Ganzzahl oder das Atom-Literal `:error`.

Eine vollständige Liste aller Typen findest du im Abschnitt ["Typespecs" der offiziellen Dokumentation][types].

## Argumente benennen

Argumente in der Typspezifikation können auch benannt werden, was nützlich ist, um mehrere Argumente desselben Typs zu unterscheiden. Der Argumentname, gefolgt von einem doppelten Doppelpunkt, steht vor dem Typ des Arguments.

```elixir
@spec to_hex({hue :: integer, saturation :: integer, lightness :: integer}) :: String.t()
```

## Benutzerdefinierte Typen

Typspezifikationen sind nicht auf die eingebauten Typen beschränkt. Benutzerdefinierte Typen können mit dem Modulattribut `@type` definiert werden. Eine benutzerdefinierte Typdefinition beginnt mit dem Namen des Typs, gefolgt von einem doppelten Doppelpunkt und dann dem Typ selbst.

```elixir
@type color :: {hue :: integer, saturation :: integer, lightness :: integer}

@spec to_hex(color()) :: String.t()
```

Ein benutzerdefinierter Typ kann aus demselben Modul verwendet werden, in dem er definiert ist, oder aus einem anderen Modul.
