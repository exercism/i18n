# Installation

Wir verwenden *PolyML* als unsere Implementierung von Standard ML.

Wenn du Windows verwendest, kannst du einen Installer von [https://github.com/polyml/polyml/releases](https://github.com/polyml/polyml/releases) herunterladen.
Allgemeine Anleitungen für Linux/OS X/Free BSD findest du unter [https://github.com/polyml/polyml#readme](https://github.com/polyml/polyml#readme).

Wenn du aus dem Quellcode installieren möchtest, ist der Vorgang ganz einfach:

```sh
$ git clone https://github.com/polyml/polyml.git
$ cd polyml
$ ./configure
```

Wenn du es an einem eigenen Ort installieren möchtest, zum Beispiel in `$HOME/.local`:

```sh
$ ./configure --prefix=$HOME/.local
```

Letzter Schritt:

```sh
$ make compiler
$ make install
```

Prüfe, ob es korrekt installiert wurde:

```sh
$ poly
```

Wenn du den Interpreter siehst, kann es losgehen!
Wenn nicht, musst du wahrscheinlich `$HOME/.local/bin` (oder `<you prefix>/bin`) zu deinem `$PATH` hinzufügen.
