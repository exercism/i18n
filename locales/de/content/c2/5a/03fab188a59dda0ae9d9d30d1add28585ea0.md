# Anleitung

Implementiere die `accumulate`-Operation: Sie bekommt eine Sammlung und eine Operation, die auf jedes Element der Sammlung angewendet wird, und gibt eine neue Sammlung zurück, die das Ergebnis der Anwendung dieser Operation auf jedes Element der Eingabesammlung enthält.

Gegeben sei die Sammlung von Zahlen:

- 1, 2, 3, 4, 5

Und die Operation:

- eine Zahl quadrieren (`x => x * x`)

Dein Code sollte in der Lage sein, die Sammlung der Quadrate zu erzeugen:

- 1, 4, 9, 16, 25

Schau dir die Testsuite an, um die erwartete Funktionssignatur zu sehen.
