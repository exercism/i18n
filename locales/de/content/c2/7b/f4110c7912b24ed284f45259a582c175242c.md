# Einführung

## Zahlen

Die zwei häufigsten Zahlentypen in Ruby sind:

- **Ganzzahlen:** Zahlen ohne Nachkommastellen (ganze Zahlen). Beispiele sind `-6`, `0`, `1`, `25`, `976` und `500000`.
- **Gleitkommazahlen:** Zahlen mit einer oder mehreren Nachkommastellen. Beispiele sind `-2.4`, `0.1`, `3.14`, `16.984025` und `1024.0`.

Sie werden durch die Klassen `Integer` und `Float` implementiert.

Diese Klassen haben Methoden, mit denen sich Werte von einem Typ in den anderen umwandeln lassen. `Integer`-Zahlen sind auf eine ganze Einheit genau, während `Float` auch Bruchteile einer ganzen Zahl darstellen kann:
- `Integer#to_f`: In eine neue Gleitkommazahl umwandeln
- `Float#ceil`: Auf die nächste Ganzzahl aufrunden
- `Float#floor`: Auf die nächste Ganzzahl abrunden
- `Float#round`: Auf die nächste Ganzzahl runden
- `Float#to_i`: Zur nächsten Ganzzahl abschneiden

## Bedingte Anweisungen

Ruby kennt sogenannte Ausdrücke zur Ablaufsteuerung. Mit ihnen steuerst du, wie das Programm abläuft, und sie nehmen einen truthy- oder falsey-Wert an.
Es gibt Operatoren, mit denen sich truthy- oder falsey-Werte erzeugen lassen; diese heißen [Vergleichsoperatoren][comparison-operators].

Es gibt zwei wichtige Steuerausdrücke, mit denen du steuerst, welcher Code ausgeführt wird und welcher nicht.
Sie legen also fest, welcher Zweig ausgeführt wird.

Diese beiden sind: `if` und der `unless`-Ausdruck.

## Vergleichsoperatoren

[Vergleichsoperatoren][comparison-operators] werden verwendet, um Werte zu vergleichen und einen `true`- oder `false`-Wert zurückzugeben.
Die folgenden Operatoren verlangen zwei Werte desselben Typs, die verglichen werden.
Wenn die Werte nicht vom selben Typ sind, wirft der Compiler einen Fehler.
Hier ist eine Liste der Operatoren und je ein Beispiel, wann sie einen `true`-Wert liefern:

| Methode | Beschreibung          | Beispiel |
| ------- | --------------------- | -------- |
| <       | kleiner als           | 4 < 5    |
| <=      | kleiner oder gleich   | 4 <= 4   |
| >       | größer als            | 3 > 1    |
| >=      | größer oder gleich    | 2 >= 2   |

Die Gleichheits- und Ungleichheitsoperatoren können, anders als die bereits genannten Operatoren, Werte jeden Typs vergleichen.
Der Operator `==` prüft, ob zwei Werte gleich sind, und das schließt die Prüfung des Werttyps mit ein.
Der Operator `!=` funktioniert genauso, gibt aber `true` zurück, wenn die Werte nicht gleich sind, und `false`, wenn sie gleich sind.
Hier ist eine Liste der Gleichheits- und Ungleichheitsoperatoren und je ein Beispiel, wann sie einen `true`-Wert liefern:

| Methode | Beschreibung | Beispiel |
| ------- | ------------ | -------- |
| ==      | gleich       | 4 == 4   |
| !=      | nicht gleich | 5 != 4   |

## if-Anweisung

Die [`if`][if]-Anweisung prüft, ob eine gegebene Bedingung „truthy" oder „falsey" ist.
Wenn die Bedingung truthy ist, wird der Code innerhalb der if-Anweisung ausgeführt.
Eine `if`-Anweisung endet mit dem Schlüsselwort `end`.

```ruby
value = 1
if value == 1
  "1 is equal to 1"
end
# => "1 is equal to 1"

if value > 2
  "1 is greater than 2"
end
# => nil
```

## unless-Anweisung

Die `unless`-Anweisung funktioniert sehr ähnlich wie die `if`-Anweisung, führt aber den Code innerhalb der `unless`-Anweisung aus, wenn die Bedingung falsey ist.

```ruby
value = 1
unless value == 1
  "1 is not equal to 1"
end
# => nil

unless value > 2
  "1 is not greater than 2"
end
# => "1 is not greater than 2"
```

## else-Anweisung

Die `else`-Anweisung kann zusammen mit der `if`-Anweisung verwendet werden.
Die `else`-Anweisung wird ausgeführt, wenn der `if`-Zweig nicht ausgeführt wird.

```ruby
value = 1
if value == 1
  "1 is equal to 1"
else
  "1 is not equal to 1"
end
# => "1 is equal to 1"
```

## Kaskadierende if-Anweisungen

Die `elsif`-Anweisung kann zusammen mit der if-Anweisung verwendet werden.
Die `elsif`-Anweisung wird ausgeführt, wenn der if-Zweig nicht ausgeführt wird und die Bedingung der elsif-Anweisung truthy ist.
elsif-Anweisungen lassen sich aneinanderreihen, und die erste truthy-Bedingung wird ausgeführt.
Außerdem kann am Ende der if-Anweisung eine else-Anweisung stehen, die ausgeführt wird, wenn keine der vorherigen Anweisungen zutraf.

```ruby
value = 1
if value != 1
  "1 is not equal to 1"
elsif value > 2
  "1 is greater than 2"
else
  "1 is not equal to 1 and 1 is not greater than 2"
end
# => "1 is not equal to 1 and 1 is not greater than 2"
```
