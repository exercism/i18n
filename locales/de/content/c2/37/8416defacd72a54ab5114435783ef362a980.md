# Installation

## tclsh installieren

Das einzige Tool, das du brauchst, ist der TCL-Interpreter, `tclsh`.

Für Windows ist [der Tcl-Installer von Magicsplat][magicsplat] die beste Bezugsquelle.

Unter MacOS und Unix-ähnlichen Betriebssystemen ist `tclsh` normalerweise bereits installiert.
Typischerweise ist die installierte Version 8.6.*irgendwas*.
Um die aktuelle stabile Version 9.1 zu installieren:
 - unter MacOS verwendest du [Homebrew][brew].
 - unter Linux schaust du in deinem Paketmanager nach.
 - oder du [lädst den Quellcode herunter][download] und [kompilierst ihn][build].

Für das Lösen von Übungen über die Exercism-Weboberfläche verwendet der Test-Runner (Stand Februar 2023) Tcl in Version 8.7a4.

## Die interaktive tclsh-Shell verwenden

Es ist üblich, eine interaktive [`tclsh`][tclsh]-Sitzung zu starten, um Befehle auszuprobieren, während du programmierst.
Allerdings bietet tclsh nur einen sehr einfachen REPL-Interpreter ohne Kommandozeilenbearbeitung und ohne Befehlshistorie.
Für ein komfortableres Erlebnis gibt es ein Programm namens `rlwrap`, das Readline-Funktionalität hinzufügt:

```bash
rlwrap tclsh
```

Um rlwrap zu installieren:
 - unter MacOS verwendest du [Homebrew][brew].
 - unter Linux schaust du in deinem Paketmanager nach.
 - oder du [lädst den Quellcode herunter][rlwrap-download] und [kompilierst ihn][rlwrap-build].

Es ist so praktisch, dass du es immer verwenden möchtest: Füge dies zu deiner ~/.bashrc hinzu.

```bash
command -v rlwrap && alias tclsh='rlwrap tclsh'
```

## Welche Version solltest du verwenden?

Die aktuelle stabile Version ist 9.1.
Wie oben erwähnt, ist Version 8.6 noch weit verbreitet.

Du kannst testen, welche Version von `tclsh` du installiert hast, indem du den folgenden Befehl ausführst:

```bash
echo 'puts [info patchlevel]' | tclsh
```
