# Ergänzung

## „Null“ in Tcl

Tcl hat keinen `null`- oder `nil`-Wert.
In der Praxis wird der leere String oft verwendet, um „kein Wert“ auszudrücken.
Das kann jedoch knifflig werden, wenn der leere String tatsächlich ein gültiger Wert ist, zum Beispiel in einer Liste, die eine Zeile aus CSV-Daten darstellt.

Behandle den leeren String in dieser Übung als Nullwert, der verworfen werden soll.
