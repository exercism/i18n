# Übungen testen

Folge den Schritten unten, um eine Lösung für eine Übung zu entwickeln und sie lokal zu testen.

## Lade die Übung herunter

Öffne ein Command Prompt und führe den unten stehenden Befehl mit dem Namen der gewünschten Übung aus, um sie herunterzuladen.

```sh
exercism download --track ballerina --exercise <exercise-name>
```

## Entwickle deine Lösung

1. Führe den unten stehenden Befehl aus, um in das Verzeichnis der gerade heruntergeladenen Übung zu wechseln.

     >**Tipp:** Der Verzeichnispfad im unten stehenden Befehl hängt von deinem Betriebssystem und deinem konfigurierten Exercism-Arbeitsbereich ab. Wo dein Arbeitsbereich liegt, findest du heraus, indem du den Befehl `exercism configure` ausführst.

     ```sh
     cd ~/exercism/ballerina/hello-world/
     ```

2. Folge den bereitgestellten Anweisungen und entwickle eine Lösung für die Übung.

## Teste deine Lösung

Manche Ballerina-Übungen haben einen einzelnen Test, andere mehrere Tests. Die Tests findest du in der jeweiligen Testdatei im Verzeichnis `/tests` im Stammverzeichnis der Übung.

### Übung mit einem einzelnen Test testen

Führe den unten stehenden Befehl aus, um den Test der Übung auszuführen.

Standardmäßig ist nur der erste Test aktiviert. Das ist Absicht, denn so kannst du dich darauf konzentrieren, genau diesen einen Test zu bestehen.

```sh
bal test
```

### Übung mit mehreren Tests testen

Folge den Schritten unten, um eine Übung mit mehreren Tests zu testen.

1. Sobald der erste Test bestanden ist, aktiviere den nächsten Test, indem du die Eigenschaft `enable: false` der Annotation `@test:Config` entfernst.

     ```ballerina
     @test:Config {
       enable: false
     }
     function nextTestCase() {
     }
     ``` 

2.  Führe den unten stehenden Befehl aus, um den aktivierten Test auszuführen.

   ```sh
     bal test
   ```

3. Wiederhole die beiden Schritte oben, um die restlichen Tests zu aktivieren.

Du hast die Übung erfolgreich abgeschlossen, indem du alle Tests aktiviert und dafür gesorgt hast, dass deine Implementierung jeden einzelnen besteht.
