# Anleitung

Du bist ein begeisterter Vogelbeobachter und hältst fest, wie viele Vögel in den letzten sieben Tagen deinen Garten besucht haben.

Du hast sechs Aufgaben, die sich alle mit der Anzahl der Vögel befassen, die deinen Garten besucht haben.

## 1. Prüfe, wie viele Vögel heute zu Besuch waren

Implementiere die Funktion `today()`, die zurückgibt, wie viele Vögel heute deinen Garten besucht haben.
Die Vogelzahlen sind nach Tagen geordnet: Das erste Element ist die Anzahl des ältesten Tages, das letzte Element die Anzahl von heute.

```julia-repl
julia> birds_per_day = [2, 5, 0, 7, 4, 1]
julia> today(birds_per_day)
1
```

## 2. Erhöhe die heutige Anzahl

Implementiere die Funktion `increment_todays_count()`, die die heutige Anzahl erhöht:

```julia-repl
julia> birds_per_day = [2, 5, 0, 7, 4, 1]
julia> increment_todays_count(birds_per_day)
[2, 5, 0, 7, 4, 2]
```

## 3. Prüfe, ob es einen Tag ohne Vögel gab

Implementiere die Funktion `has_day_without_birds()`, die `true` zurückgibt, wenn es einen Tag gab, an dem null Vögel den Garten besucht haben; andernfalls gib `false` zurück:

```julia-repl
julia> birds_per_day = [2, 5, 0, 7, 4, 1]
julia> has_day_without_birds(birds_per_day)
true
```

## 4. Berechne die Anzahl der Vögel für die ersten Tage

Implementiere die Funktion `count_for_first_days()`, die die Anzahl der Vögel zurückgibt, die seit Beginn der Woche deinen Garten besucht haben. Beschränke die Zählung dabei auf die angegebene Anzahl von Tagen ab Beginn der Woche.

```julia-repl
julia> birds_per_day = [2, 5, 0, 7, 4, 1]
julia> count_for_first_days(birds_per_day, 4)
14
```

## 5. Berechne die Anzahl der geschäftigen Tage

Manche Tage sind geschäftiger als andere.
Ein geschäftiger Tag ist ein Tag, an dem fünf oder mehr Vögel deinen Garten besucht haben.
Implementiere die Funktion `busy_days()`, die die Anzahl der geschäftigen Tage zurückgibt:

```julia-repl
julia> birds_per_day = [2, 5, 0, 7, 4, 1]
julia> busy_days(birds_per_day)
2
```

## 6. Berechne den Durchschnitt pro Wochentag

Du beschließt, deine Aufzeichnungen zu erweitern, indem du die Zahlen für mehrere Wochen führst.
In jedem Fall sind die Zahlen nach Wochentagen geordnet, vom Montag als erstem Eintrag bis zum Sonntag als letztem.

Implementiere die Funktion `average_per_day()`, die den Durchschnitt für 2 Wochen zurückgibt.

```julia-repl
julia> week1 = [7, 2, 9, 1, 3, 0, 10]
julia> week2 = [2, 6, 4, 1, 3, 8, 9]
julia> average_per_day(week1, week2)
[4.5, 4.0, 6.5, 1.0, 4.0, 3.0, 9.5]
```
