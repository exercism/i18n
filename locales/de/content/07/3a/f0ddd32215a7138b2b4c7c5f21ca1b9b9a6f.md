# Über

Es gibt im Wesentlichen zwei Arten von Schleifen:

1. Wiederhole, bis eine Bedingung erfüllt ist.
2. Iteriere über die Elemente einer Sammlung.

Beides ist [in R möglich][web-loops], wobei die erste Variante wohl häufiger ist.

## `while` und `repeat`

Für Probleme ohne festes Ende, bei denen nicht im Voraus bekannt ist, wie oft die Schleife durchlaufen wird, hat R die [`while`][ref-control]-Schleife mit einer Bedingung und die [`repeat`][ref-control]-Schleife ohne Bedingung (entspricht `while (TRUE)`).

Die Grundform ist recht einfach:

```R
while (condition) {
  do_something()
}
```

In diesem Fall läuft das Programm so lange durch die Schleife, bis `condition` nicht mehr `TRUE` ist.

Es gibt zwei Möglichkeiten, die Schleife vorzeitig zu verlassen:

- Ein `break` beendet die Schleife, und die Ausführung wird in der nächsten Zeile nach der schließenden geschweiften Klammer `}` der Schleife fortgesetzt.
- Ein `return(x)` beendet die Ausführung der aktuellen Funktion und gibt den Rückgabewert `x` an den Aufrufer zurück.

Mit diesen Möglichkeiten kann es manchmal praktisch sein, eine „unendliche“ Schleife mit `repeat { ... }` zu erstellen und dann im Schleifenblock eine Abbruchbedingung zu finden, die ein `break` oder `return` auslöst.

Diese drei Varianten sind gleichwertig und enden alle mit `x == 0.4444...`

```R
x <- 12
while (x > 1) {
  x <- x / 3
}

x <- 12
while (TRUE) {
  x <- x/3
  if (x <= 1) break
}

x <- 12
# no boolean clause 
repeat { 
  x <- x/3
  if (x <= 1) break
}
```

## Über einen Vektor (oder eine andere Sammlung) iterieren

In R ist das oft nicht nötig.
Wie in anderen Konzepten beschrieben, arbeiten viele Funktionen direkt mit ganzen Vektoren.

Manchmal sind explizite Schleifen jedoch unvermeidlich.
Das gilt besonders, wenn:

- Der Schleifenblock Nebenwirkungen hat, etwa Ausgaben oder Datei-Ein-/Ausgabe.
- Die Schleife so lange läuft, bis ein Kriterium erreicht ist, nach einer unvorhersehbaren Anzahl von Iterationen.

Die Schleifenbedingung muss in runden Klammern stehen.
Wie bei Funktionskörpern sind geschweifte Klammern bei einzeiligen Schleifenblöcken optional (werden aber oft verwendet).

```R
words <- c("This", "is", "a", "loop")
for (w in words) { print(w) } # the braces are optional here
#> [1] "This"
#> [1] "is"
#> [1] "a"
#> [1] "loop"
```

Wenn die aktuelle Iteration eine Bedingung nicht erfüllt, kannst du mit `next` sofort zur nächsten Iteration springen:

```R
for (n in 1:5) {
  if (n %% 2 == 0) next
  print(n)
}
#> [1] 1
#> [1] 3
#> [1] 5
```

Wenn du den numerischen Index brauchst, verwende [`seq_along()`][ref-seq_along].

```R
v <- LETTERS[1:3]
v
#> [1] "A" "B" "C"

for (i in seq_along(v)) { print(sprintf("%s%i", v[i], i)) }
#> [1] "A1"
#> [1] "B2"
#> [1] "C3"
```

Die Verwendung von `i in 1:length(v)` ist _nicht_ zu empfehlen, da sie Probleme verursachen kann, wenn `length(v)` null ist.
Der Bereich `1:0` entspricht `c(1, 0)`, also wird der Schleifenblock ausgeführt und schlägt wahrscheinlich fehl.
Die Funktion `seq_along()` ist dafür ausgelegt, diesen Fall korrekt zu behandeln.
