# Anleitung

Bestimme, ob sich eine gegebene Menge aus drei Dominosteinen so anordnen lässt, dass sie eine korrekte Dominokette ergibt (die Punkte auf einer Hälfte eines Steins stimmen mit den Punkten auf der benachbarten Hälfte eines angrenzenden Steins überein) und dass die Punkte auf den Hälften der Steine ohne Nachbarn (der erste und der letzte Stein) zueinander passen. Einige Testfälle verwenden möglicherweise doppelte Steine in einer Lösung der Kette. Gib `True` zurück, wenn sich eine korrekte Dominokette anordnen lässt, andernfalls `False`.

```text
For example, given: [(2,1),(2,3),(1,3)]
    True

For example, given: [(1,2),(4,1),(2,3)]
    False
```
