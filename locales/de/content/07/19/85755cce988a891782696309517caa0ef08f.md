# Hinweise

## Allgemein

- In einer unveränderlichen Klasse gibt es kein `new`. `create` beginnt mit einer
  Variable der Klasse, die bereits existiert:

  ```sather
     create(d : INT) : SAME is
        b : SAME;
        return b.degrees(...);
     end;
  ```

- `b.degrees(x)` verändert `b` nicht. Es liefert eine neue Peilung, und
  deshalb ist sie das, was zurückgegeben wird.

## 1. Eine Peilung bestimmen

- `%` bringt eine Zahl in den gültigen Bereich, aber `-10 % 360` ergibt nur
  deshalb `350`, weil Sathers `%` bei einer positiven rechten Seite nie
  negativ wird. `d % 360` reicht also allein aus.

## 2. Drehen

- Addiere die Drehung zu den Grad und bilde aus der Summe eine neue Peilung:
  `#BEARING(degrees + by)`.
- `create` bringt die Antwort bereits wieder in den gültigen Bereich, du musst
  dich also nicht darum kümmern, über Norden hinaus zu drehen.

## 3. Vergleichen

- Eine Zeile: Vergleiche die beiden `degrees`.
- Der Typ des Arguments ist `SAME`, und du liest sein Attribut wie gewohnt:
  `other.degrees`.

## 4. Den Punkt benennen

- Der Trick ist, vor dem Dividieren um ein halbes Segment zu verschieben,
  damit jeder Punkt von seiner *Mitte* aus gemessen wird:
  `((degrees + 22) / 45) % 8` ergibt 0 für Nord, 1 für Nordost und so
  weiter.
- Dann ein `case` über diese Zahl mit den acht Namen, und ein `else`, das
  `case` immer braucht, auch wenn die acht Zweige jeden möglichen Wert
  abdecken.

## 5. Aufschreiben

- `+` verbindet die Teile, aber nur an einen String dürfen Dinge angehängt
  werden. Die Zahl steht hier zuerst, also braucht sie `degrees.str`, damit
  die Verbindung beginnt. `"a" + 1` ist in Ordnung; `1 + "a"` lässt sich
  nicht kompilieren.
- Rufe `point` auf, statt den Namen noch einmal zu berechnen.
