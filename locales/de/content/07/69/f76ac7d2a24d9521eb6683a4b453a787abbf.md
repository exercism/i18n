# Wie du eine gute Support-Anfrage schreibst

Brauchst du Hilfe bei einer Übung auf Exercism?
Dann erhöhe deine Chancen auf eine gute Antwort, indem du lernst, eine gute Support-Anfrage zu schreiben und unsere Community dazu zu ermuntern, dich zu unterstützen.

Hier sind ein paar wichtige Tipps.

## Verwende Blöcke, keine Bilder

Wenn du Code teilen willst (sei es selbst geschriebenen oder Anweisungen), nutze einen Block, kein Bild.

Als Entwickler lesen wir Code viel schneller, als wir in ein Bild hineinzoomen müssen, um etwas zu erkennen.
Und viele unserer Nutzer verwenden Screenreader, die Bilder nicht vorlesen können.
Wenn du also ein guter Teil unserer Community sein willst, unsere Freiwilligen dazu ermuntern willst, dir zu helfen, und wie ein Profi wirken willst, dann teile deinen Code als Text und nicht als Bild!

Zum Beispiel kannst du Folgendes eingeben:

````
```
for number in range(10):
  total += number;
```
````

Das wird dann so dargestellt:

```
for number in range(10):
  total += number;
```

Du kannst sogar Syntax-Hervorhebung bekommen, indem du die Sprache an den Anfang des Blocks schreibst:

````
```python
for number in range(10):
  total += number;
```
````

Das ergibt dann:

```python
for number in range(10):
  total += number;
```

## Verwende inklusive Sprache

Exercism besteht aus Menschen unterschiedlicher Geschlechter.
Wenn du in unserem Discord auftauchst und Dinge sagst wie „Hey boys“, schließt du sofort die Hälfte unserer Community aus.
Das bedeutet, dass sie dir weniger wahrscheinlich helfen. Aber auch der Rest der Community hilft dir dann weniger wahrscheinlich, denn bei Exercism legen wir Wert auf Inklusivität.

Wenn du also Hilfe bekommen willst und ein netter Mensch sein willst, verwende keine geschlechtsspezifische Sprache.
Versuch es mit „Hey folks“, „Hey everyone“ oder sei richtig mutig und wähle „Hey fellow Exercists!“

Mehr dazu findest du in unserem Artikel über [die Wörter, die wir verwenden](./the-words-that-we-use).
