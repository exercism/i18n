# Über Listen

**Listen** sind in Java die Sammlung für geordnete Sequenzen.
Anders als Arrays kann eine [`List`](https://docs.oracle.com/en/java/javase/11/docs/api/java.base/java/util/List.html) in ihrer Größe wachsen, um beliebig viele Elemente aufzunehmen.
Eine Standardimplementierung ist die `ArrayList`, die auf einem Array mit veränderbarer Größe basiert.
Eine weitere Standardimplementierung ist die Klasse `LinkedList`, die auf einer doppelt verketteten Liste basiert.

`List`s können leer sein oder beliebig viele Elemente enthalten (auch Duplikate).
`List`s sind ein **generisches Interface**, das typisiert ist, um anzugeben, welche Art von Objekten sie enthalten können.
Zum Beispiel:

```java
List<String> emptyListOfStrings = List.of();
List<Integer> singleInteger = List.of(1);
List<Boolean> threeBooleans = List.of(true, false, true);
List<Object> listWithMultipleTypes = List.of("hello", 1, true);
```

`List`s bieten verschiedene hilfreiche Methoden, um ein Element hinzuzufügen, zu entfernen, abzurufen und zu prüfen, ob es vorhanden ist:

```java
List<Character> vowels = new ArrayList<>(List.of('a', 'e', 'i', 'o', 'i', 'e', 'a'));
int startingSize = vowels.size(); // 7
vowels.add('u'); // vowels is now ['a', 'e', 'i', 'o', 'i', 'e', 'a', 'u']
char a = vowels.get(0); // 'a'
boolean hadI = vowels.remove('i'); // true and vowels is now ['a', 'e', 'o', 'i', 'e', 'a', 'u']
boolean hasI = vowels.contains('i'); // true (still have one more left)
```

Die Klasse [`Collections`](https://docs.oracle.com/en/java/javase/11/docs/api/java.base/java/util/Collections.html) bietet ebenfalls einige hilfreiche Werkzeuge für den Umgang mit Sammlungen wie `List`:

```java
List<Integer> numbers = new ArrayList<>(List.of(1, 5, 3, 2, 4));
Collections.sort(numbers); // [1, 2, 3, 4, 5]
Collections.reverse(numbers); // [5, 4, 3, 2, 1]
Collections.fill(numbers, 42); // [42, 42, 42, 42, 42]
List<Integer> fiveNines = Collections.nCopies(5, 9); // [9, 9, 9, 9, 9]
```
