# Einführung

## Boolesche Werte

Gleam stellt wahre und falsche Werte mit dem Typ `Bool` dar. Es gibt nur zwei Werte: `True` und `False`. Diese Werte kannst du an eine Variable binden:

```gleam
let true_variable = True
let false_variable = False
```

Mit den Operatoren `&&`, `||` und `!` kannst du boolesche Werte manipulieren:

```gleam
True && True  // -> True
True && False // -> False

False || True  // -> True
False || False // -> False

!False // -> True
!True  // -> False
```

Die Operatoren `&&` und `||` verwenden die Kurzschlussauswertung. Das bedeutet, dass Gleam den Ausdruck auf der rechten Seite des Operators nur auswertet, wenn es nötig ist.

Die Operatoren haben unterschiedliche Prioritäten: Gleam wertet `!` vor `&&` und `||` aus. Mit geschweiften Klammern kannst du einen Teil des Ausdrucks vor den anderen auswerten:

```gleam
!True && False   // -> False
!{True && False} // -> True
```
