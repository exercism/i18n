# Einführung

## Standardwerte für Parameter

[Standardwerte für Parameter][default-parameter-values] kannst du für jeden Parameter einer Funktion angeben, indem du in der Parameterliste nach der Typannotation des Parameters einen Wert zuweist. Wenn ein Standardwert für einen Parameter angegeben ist, kann der Aufrufer der Funktion diesen Parameter beim Aufruf weglassen, und stattdessen wird der Standardwert verwendet.

```swift
func greeting(name: String = "guest", duration: Int = 2) -> String {
  "Welcome, \(name). Enjoy your \(duration) night stay."
}

greeting(name: "Bobo", duration: 7)
// Returns "Welcome, Bobo. Enjoy your 7 night stay."
greeting(duration: 3)
// Returns "Welcome, guest. Enjoy your 3 night stay."
greeting(name: "Wynona")
// Returns "Welcome, Wynona. Enjoy your 2 night stay."
greeting()
// Returns "Welcome, guest. Enjoy your 2 night stay."
```

## Variadische Parameter

Mit [_variadischen Parametern_][variadic-parameters] kannst du in Swift null oder mehr Werte desselben Typs an einen einzelnen Parameter einer Funktion übergeben. Das zeigst du an, indem du `...` an die Typannotation des Parameters anhängst.

Diese Werte werden automatisch zu einem Array zusammengefasst, dessen Elemente denselben Typ haben wie der Typ des variadischen Parameters.

```swift
func geometricMean(_ numbers: Double...) -> Double {
  var total = 1.0
  for number in numbers {
      total *= number
  }
  return pow(total, 1.0 / Double(numbers.count))
}

geometricMean(1, 2, 3, 4, 5)
// => 2.605171084697352
```

Beachte, dass Swift bei variadischen Parametern eine Einschränkung hat.
Wenn in der Definition einer Funktion Parameter auf den variadischen Parameter folgen, dann _muss_ der erste Parameter nach dem variadischen Parameter ein Argumentlabel haben.

## In-out-Parameter

Innerhalb des Körpers einer Funktion werden Parameter als Konstanten behandelt, nicht als Variablen; der Versuch, den Wert eines Parameters zu ändern, führt zu einem Kompilierfehler.
Wenn eine Funktion den Wert eines Parameters ändern möchte, muss sie einen [_In-out-Parameter_][in-out-parameters] verwenden, um diese Veränderbarkeit ausdrücklich zu machen.

Um In-out-Parameter zu verwenden, muss man auf drei Dinge achten:

1. In der Funktionsdefinition müssen In-out-Parameter ausdrücklich gekennzeichnet werden, indem du das Schlüsselwort `inout` in der Typannotation des Parameters zwischen dem `:` und dem Typnamen schreibst.
2. Der Wert, der an den In-out-Parameter übergeben wird, muss als Variable deklariert sein, nicht als Konstante. Ebenso darf er kein Literal sein.
3. Beim Aufruf der Funktion muss dem Variablennamen ein `&` vorangestellt werden, um ihn ausdrücklich als veränderbar zu kennzeichnen.

Wenn dies geschieht, erstellt die Funktion eine interne Kopie des In-out-Parameters, ändert sie wie im Körper der Funktion beschrieben und kopiert den geänderten Wert dann zurück in die Variable, die übergeben wurde, sobald die Funktion zurückkehrt.

```swift
func updateVersion(_ record: inout (version: Int, title: String)) {
  record.version += 1
}

var dbRecord = (version: 2, title: "Exercism")
updateVersion(&dbRecord)

// dbRecord is now (3, "Exercism")
```

~~~~exercism/warning
Bei In-out-Parametern gibt es noch ein paar zusätzliche Regeln, die du kennen solltest.

1  Innerhalb einer Funktion mit In-out-Parametern darfst du nicht auf die Variable verweisen, die als In-out-Parameter übergeben wurde.
2. Dieselbe Variable kann in derselben Funktion nicht als mehrere In-out-Parameter übergeben werden.
   Zum Beispiel löst `inoutFunc(&mutVar, &mutVar)` einen Compilerfehler aus.
~~~~

## Verschachtelte Funktionen

In Swift kannst du [Funktionen in anderen Funktionen definieren][nested-functions].
Diese nennt man **verschachtelte Funktionen**.

Verschachtelte Funktionen werden häufig als private Hilfsfunktionen verwendet, die bestimmte Aufgaben für die umgebende Funktion erledigen, ohne den äußeren Gültigkeitsbereich zu überladen:

```swift
func makeNumber(_ number: Int) -> Int {
    func double(_ x: Int) -> Int {
        x * 2
    }

    func increment(_ x: Int) -> Int {
        x + 1
    }

    return number.isMultiple(of: 2) ? increment(double(number)) : double(number)
}

print(makeNumber(3)) // Prints 6
print(makeNumber(4)) // Prints 9
```

Verschachtelte Funktionen verhalten sich wie normale Funktionen, aber ihre Sichtbarkeit ist auf den Körper der umgebenden Funktion beschränkt.
