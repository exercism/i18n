# Tests

Für jede Übung gibt es eine einmalige Einrichtung, die ein paar Minuten dauern kann:

```
npm install
```

Öffne zwei Shells und starte in der ersten den Build-Prozess.

```
npm start
```

In der zweiten startest du die Tests.

```
npm test
```

Während du den Code bearbeitest, bauen die beiden Prozesse fortlaufend neu und führen die Tests erneut aus.
