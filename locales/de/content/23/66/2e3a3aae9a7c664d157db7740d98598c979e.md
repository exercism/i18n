# Tests

## Kommandozeile

Mit dem folgenden Befehl kannst du die Tests von der Kommandozeile aus ausführen:

```bash
swipl -f <exercise>.pl -s <exercise>_tests.plt -g run_tests,halt -t 'halt(1)'
```

Ersetze `<exercise>` durch den Namen der Übung, die du implementierst.

## Interaktiv

Um Prolog interaktiv auszuführen, führe zuerst Folgendes aus:

```bash
swipl
```

Nachdem die Prolog-Konsole gestartet ist, lädst du deine Implementierung und führst die Tests aus mit:

```
?- ["<exercise>.pl"].
?- ["<exercise>_tests.plt"].
?- run_tests.
```

Ersetze `<exercise>` durch den Namen der Übung, die du implementierst.

### Änderungen neu laden

Sobald die oben genannten Dateien geladen sind, kannst du deine Änderungen übernehmen, indem du Folgendes ausführst:

```
?- make.
```

## Übersprungene Tests

Wenn du eine Übung zum ersten Mal beginnst, wird nur der erste Test ausgeführt. Die übrigen wurden übersprungen, indem `condition(pending)` zum `test`-Ziel hinzugefügt wurde. Sobald der erste Test erfolgreich ist, hebst du die Überspringung des nächsten Tests auf, indem du `pending` in `condition(pending)` zu `true` änderst. Wiederhole das für jeden Test, bis alle laufen und erfolgreich sind.

### Kommandozeile

Hänge das Argument `-- --all` an das Ende des Befehls an, um auch alle noch übersprungenen Tests auszuführen:

```bash
swipl -f <exercise>.pl -s <exercise>_tests.plt -g run_tests,halt -t 'halt(1)' -- --all
```
