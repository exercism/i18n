# Anleitung

Als angehende Magierin muss Elyse ihr Kartendeck auf viele verschiedene Arten analysieren.
Um es einfach zu halten, benutzt sie nur Karten mit Werten von 1 bis 10.

## 1. Bestimme, wie viele Karten eines bestimmten Typs im Deck sind

Elyse möchte wissen, wie viele Karten eines bestimmten Typs sie in ihrem Deck hat.

Schreibe eine Funktion `cardTypeCheck`, die zwei Parameter entgegennimmt: ein Array mit Karten (Elyses Deck) und den Typ der Karte, die gezählt werden soll.

<!--prettier-ignore -->
~~~exercism/note
Die Funktion sollte `forEach` verwenden und die Anzahl der Karten des angegebenen Typs im Deck zurückgeben.
~~~

```javascript
const cardType = 3;
cardTypeCheck([1, 2, 3, 4], cardType);
// => 1
```

## 2. Bestimme, wie viele ungerade oder gerade Karten es gibt

Für einen weiteren Trick muss Elyse wissen, wie viele ungerade oder gerade Karten in ihrem Deck sind.

Implementiere eine Funktion `determineOddEvenCards`, die zwei Parameter entgegennimmt: ein Array mit Karten (Elyses Deck) und einen booleschen Wert (wahr entspricht „gerade" und falsch entspricht „ungerade").

Diese Funktion sollte eine einzelne Zahl zurückgeben: die Anzahl der ungeraden oder geraden Karten im Deck (je nach Wert des zweiten Arguments).

<!--prettier-ignore -->
~~~exercism/note
Zum Üben verwende diesmal eine `for...of`-Schleife in der Implementierung der Funktion.
~~~

```javascript
determineOddEvenCards([1, 2, 3, 1, 5, 6], true);
// => 2

determineOddEvenCards([1, 2, 3, 1, 5, 6], false);
// => 4
```
