# Über

[`Rational numbers`][rational] sind Brüche mit einem ganzzahligen Zähler, geteilt durch einen ganzzahligen Nenner.

Zum Beispiel können wir `2//3` als exakten Bruch speichern, statt als ungefähren `Float64`-Wert `0.6666...`

Der Vorteil ist, dass (außer im Extremfall eines [Ganzzahlüberlaufs][integer-overflow]) eine rationale Zahl exakt bleibt und die Rundungsfehler vermeidet, die bei Gleitkommazahlen oft unvermeidlich sind.

Weitere Details stehen in der Julia-[Handbuchseite][julia-rational].

Rationale Zahlen sind ein recht einfacher numerischer Typ und verhalten sich im Großen und Ganzen so, wie du es erwartest.
Da sie seit den frühen Versionen ein Standardtyp in Julia sind, akzeptieren die meisten Funktionen sie als Eingabewert genauso wie Ganzzahlen und Gleitkommazahlen.

## Rationale Zahlen erstellen

Du erstellst sie ganz einfach, indem du `//` zwischen zwei Ganzzahlen setzt.

```julia-repl
julia> 3//4
3//4

julia> a = 3; b = 4;

julia> a//b
3//4
```

Gemeinsame Faktoren werden automatisch entfernt, wodurch der Bruch in seine [„vollständig gekürzte Form“][lowest-terms] gebracht wird: die kleinsten Ganzzahlen, die den Bruch genau darstellen, und mit einem nicht-negativen Nenner.

```julia-repl
julia> 5//15
1//3

julia> 5//-15
-1//3
```

Unendliche Ergebnisse werden akzeptiert, jedoch nicht [`NaN`][NaN].

```julia-repl
julia> 1//0
1//0

julia> float(1//0)
Inf

julia> 0//0
ERROR: ArgumentError: invalid rational: zero(Int64)//zero(Int64)
```

## Rechnen mit rationalen Zahlen

Die üblichen [`arithmetic operators`][operators] `+ - * / ^ %` funktionieren mit rationalen Zahlen, im Wesentlichen genauso wie mit anderen numerischen Typen.

Ganzzahlen und andere `Rational`s können einbezogen werden und ergeben ein `Rational`-Ergebnis.
Wird ein `float` in den Ausdruck einbezogen, ergibt das eine `float`-Ausgabe, mit einem daraus folgenden (möglichen) Verlust an Genauigkeit.

Wenn ein `float` gewünscht ist, verwende einfach die Funktion `float()`, um eine rationale Zahl umzuwandeln.
Es ist ganz normal, rationale Zahlen zu verwenden, um die Genauigkeit über eine lange Berechnung hinweg zu bewahren und erst am Ende in eine Gleitkommazahl umzuwandeln.

```julia-repl
julia> 3//4 + 1//3  # addition
13//12

julia> 3//4 * 1//3  # multiplication
1//4

julia> 3//4 / 1//3  # division
9//4

julia> 3//4 ^ 2  # exponentiation
3//16

julia> 3//4 + 5  # rational and int => rational
23//4

julia> 3//4 + 5.3  # rational and float => float
6.05

julia> float(3//4)  # casting
0.75
```

Rationale Zahlen und [komplexe Zahlen][complex] können ebenfalls kombiniert werden.
Komplexe Zahlen werden in einem [eigenen Konzept][complex-concept] behandelt.

## Weitere Operationen

In Julia sind rationale Zahlen einfach Zahlen.
Der Compiler konvertiert Typen normalerweise nach Bedarf.

Sei allerdings vorsichtig: Vergleiche funktionieren bei Brüchen mit endlicher Dezimaldarstellung:

```julia-repl
julia> 3//4 == 0.75
true

julia> 3//4 < 0.74
false
```

Andernfalls sollte ein `Rational` für Vergleiche in einen `Float` umgewandelt werden:

```julia-repl
julia> 1//3 == 1/3
false

julia> float(1//3) == 1/3
true
```

Mathematische Funktionen akzeptieren rationale Zahlen als Eingabewert, können aber ein Ergebnis als Gleitkommazahl liefern:

```julia-repl
julia> sqrt(9//16)
0.75
```
