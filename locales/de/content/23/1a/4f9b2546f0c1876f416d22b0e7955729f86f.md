# Einführung

In C# kann eine Hierarchie von _Klassen_ mithilfe von _Vererbung_ definiert werden. Dadurch kann eine abgeleitete Klasse (`Car`) das Verhalten und die Daten ihrer Elternklasse (`Vehicle`) erben. Wenn keine Elternklasse angegeben wird, erbt die Klasse von der `object`-Klasse.

Elternklassen können abgeleiteten Klassen auf drei Arten Funktionalität bereitstellen:

- Eine reguläre Methode definieren.
- Eine `virtual`-Methode definieren. Sie ist wie eine reguläre Methode, aber abgeleitete Klassen _können_ sie ändern.
- Eine `abstract`-Methode definieren. Das ist eine Methode ohne Implementierung, die abgeleitete Klassen _implementieren müssen_. Eine Klasse mit `abstract`-Methoden muss ebenfalls als `abstract` gekennzeichnet sein. Abstrakte Klassen können nicht instanziiert werden.

Der Zugriffsmodifizierer `protected` erlaubt den Zugriff auf ein Mitglied einer Elternklasse in einer abgeleiteten Klasse, blockiert aber den Zugriff aus anderen Klassen.

Abgeleitete Klassen können über das Schlüsselwort `base` auf Mitglieder der Elternklasse zugreifen.

```csharp
// Inherits from the 'object' class
abstract class Vehicle
{
    // Can be overridden
    public virtual void Drive()
    {
    }

    // Must be overridden
    protected abstract int Speed();
}

class Car : Vehicle
{
    public override void Drive()
    {
        // Override virtual method

        // Call parent implementation
        base.Drive();
    }

    protected override int Speed()
    {
        // Implement abstract method
    }
}
```

Der Konstruktor einer abgeleiteten Klasse ruft automatisch den Konstruktor ihrer Elternklasse auf, _bevor_ er die Logik seines eigenen Konstruktors ausführt. Argumente können über das Schlüsselwort `base` an den Konstruktor einer Elternklasse übergeben werden:

```csharp
abstract class Vehicle
{
    protected Vehicle(int wheels)
    {
        Console.WriteLine("Called first");
    }
}

class Car : Vehicle
{
    public Car() : base(4)
    {
        Console.WriteLine("Called second");
    }
}
```

Wenn mehr als eine Klasse von einer Basisklasse abgeleitet ist, implementieren die zwei (oder mehr) Klassen oft unterschiedliche Versionen einer Methode der Basisklasse. Das ist ein sehr wichtiges Prinzip, das Polymorphismus genannt wird. In einer Variante des obigen Beispiels zeigen wir, wie Code, der `Vehicle` verwendet, sein Verhalten je nachdem ändern kann, welcher Fahrzeugtyp instanziiert wurde.

```csharp
abstract class Vehicle
{
   public abstract string GetDescription();
}

class Car : Vehicle
{
   public Car()
   {
   }

   public override string GetDescription()
   {
      return "Runabout";
   }
}

class Rig : Vehicle
{
   public Rig()
   {
   }

   public override string GetDescription()
   {
      return "Big Rig";
   }
}

Vehicle v1 = new Car();
Vehicle v2 = new Rig();

v1.GetDescription();
// => Runabout
v2.GetDescription();
// => Big Rig
```
