# Einführung

[Arrays][arrays-concept] haben eingebaute Methoden, mit denen du den Inhalt des Arrays analysieren kannst.
Die meisten dieser Methoden erwarten als Argument eine Funktion, die wahr oder falsch zurückgibt.
Eine solche Funktion heißt [`predicate`][predicate_in_programming].

Die eingebauten Methoden sind dazu gedacht, _statt einer `for`-Schleife_ oder der eingebauten `forEach`-Methode verwendet zu werden:

Beispiel für eine Analyse mit einer for-Schleife:

```javascript
const numbers = [1, 'two', 3, 'four'];
for (var i = 0; i < numbers.length; i++) {
  if (numbers[i] === 'two') {
    return i;
  }
}
// => 1
```

Beispiel für eine Analyse mit einer eingebauten Methode:

```javascript
const numbers = [1, 'two', 3, 'four'];
numbers.indexOf('two');
// => 1
```

Einige weitere hilfreiche eingebaute Methoden, mit denen du ein Array analysieren kannst, sind unten aufgeführt. Eine vollständige Liste der Array-Methoden findest du bei [MDN][mdn-array-methods].

## `includes`

> Die Methode includes() bestimmt, ob ein Array einen bestimmten Wert unter seinen Einträgen enthält, und gibt entsprechend wahr oder falsch zurück. [^1]

```javascript
const numbers = [1, 'two', 3, 'four'];
numbers.includes(1);
// => true
numbers.includes('one');
// => false
```

## `every`

> Die Methode every() prüft, ob alle Elemente im Array den Test bestehen, den die übergebene Funktion implementiert. Sie gibt einen booleschen Wert zurück. [^2]

```javascript
const numbers = [1, 3, 5, 7, 9];
numbers.every((num) => num % 2 !== 0);
// => true
```

## `some`

> Die Methode some() prüft, ob mindestens ein Element im Array den Test besteht, den die übergebene Funktion implementiert. [^3]

```javascript
const numbers = [1, 3, 5, 7, 9];
numbers.some((num) => num % 2 !== 0);
// => true
```

## `find`

> Die Methode find() gibt den Wert des ersten Elements im übergebenen Array zurück, das die übergebene Testfunktion erfüllt. Wenn kein Wert die Testfunktion erfüllt, wird undefined zurückgegeben. [^4]

```javascript
const numbers = [1, 3, 5, 7, 9];
numbers.find((num) => num < 5);
// => 1
```

## `findIndex`

> Die Methode findIndex() gibt den Index des ersten Elements im Array zurück, das die übergebene Testfunktion erfüllt. Andernfalls gibt sie -1 zurück, was bedeutet, dass kein Element den Test bestanden hat. [^5]

```javascript
const numbers = [1, 3, 5, 7, 9];
numbers.findIndex((num) => num > 7);
// => 4
numbers.findIndex((num) => num > 9);
// => -1
```
