# Anleitung

Ein Freund von dir hat einen alten Großhandel namens **Gross Store**.
Der Name kommt daher, dass der Laden seine Waren in [Gros-Einheiten][gross-unit] verkauft.
Dein Freund hat dich gebeten, für seinen Laden ein Kassensystem (POS) zu entwickeln.
**Zuerst möchtest du einen Prototyp dafür bauen.**
**In deinem Prototyp erfasst dein System nur die Menge.**
Dein Freund hat dir eine Liste mit Maßeinheiten gegeben, die dir helfen soll:

| Einheit            | Wert  |
| ------------------ | ----- |
| quarter_of_a_dozen | 3     |
| half_of_a_dozen    | 6     |
| dozen              | 12    |
| small_gross        | 120   |
| gross              | 144   |
| great_gross        | 1728  |

## 1. Speichere die Maßeinheit in deinem Programm

Um die Maßeinheit verwenden zu können, musst du sie in deinem Programm speichern.

```go
units := Units()
fmt.Println(units)
// Output: map[...] with entries like ("dozen": 12)
```

## 2. Erstelle eine neue Kundenrechnung

Du musst eine Funktion implementieren, die eine neue (leere) Rechnung für den Kunden erstellt.

```go
bill := NewBill()
fmt.Println(bill)
// Output: map[]
```

## 3. Füge einen Artikel zur Kundenrechnung hinzu

Dafür musst du Folgendes tun:

- Gib `false` zurück, wenn die angegebene `unit` nicht in der `units`-Map enthalten ist.
- Andernfalls füge den Artikel der `bill` des Kunden hinzu, mit dem Artikelnamen als Schlüssel, und gib dann `true` zurück.
- Wenn der Artikel bereits in der Rechnung vorhanden ist, erhöhe seine Menge um den Betrag, der zur angegebenen `unit` gehört.

```go
bill := NewBill()
units := Units()
ok := AddItem(bill, units, "carrot", "dozen")
fmt.Println(ok)
// Output: true (since dozen is a valid unit)
```

> Beachte, dass der Rückgabewert vom Typ `bool` ist.

## 4. Entferne einen Artikel aus der Kundenrechnung

Dafür musst du Folgendes tun:

- Gib `false` zurück, wenn der angegebene Artikel **nicht** in der Rechnung ist
- Gib `false` zurück, wenn die angegebene `unit` nicht in der `units`-Map enthalten ist.
- Gib `false` zurück, wenn die neue Menge kleiner als 0 wäre.
- Wenn die neue Menge 0 ist, entferne den Artikel vollständig aus der `bill` und gib dann `true` zurück.
- Andernfalls reduziere die Menge des Artikels und gib `true` zurück.

```go
bill := NewBill()
units := Units()
ok := RemoveItem(bill, units, "carrot", "dozen")
fmt.Println(ok)
// Output: false (because there are no carrots in the bill)
```

> Beachte, dass der Rückgabewert vom Typ `bool` ist.

## 5. Gib die Menge eines bestimmten Artikels in der Kundenrechnung zurück

Dafür musst du Folgendes tun:

- Gib `0` und `false` zurück, wenn der `item` nicht in der Rechnung ist.
- Andernfalls gib die Menge des Artikels in der `bill` und `true` zurück.

```go
bill := map[string]int{"carrot": 12, "grapes": 3}
qty, ok := GetItem(bill, "carrot")
fmt.Println(qty)
// Output: 12
fmt.Println(ok)
// Output: true
```

> Beachte, dass die Rückgabewerte die Typen `int` und `bool` haben.

[gross-unit]: https://en.wikipedia.org/wiki/Gross_(unit)
