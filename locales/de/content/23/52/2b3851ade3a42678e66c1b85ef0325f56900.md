# Readonly-Klassen und -Eigenschaften

Readonly-Klassen und -Eigenschaften ermöglichen es Klassen, öffentliche Eigenschaften für einen einfachen Zugriff anzugeben, verhindern aber deren Änderung.
Um eine Eigenschaft als `readonly` zu deklarieren, muss `readonly` vor der Typangabe stehen.
Die Eigenschaft darf einmal zugewiesen werden, aber jeder Versuch, den Wert erneut zuzuweisen oder zu ändern, führt zu einem Error.

```php
<?php

class Block
{
    public function __construct(
        public readonly int $length;
        public readonly int $width;
    ) {
    }
}
```

Readonly-Klassen bauen auf diesem Verhalten auf und wenden, wenn sie als `readonly` deklariert werden, die Readonly-Deklaration auf jede Eigenschaft an.
Außerdem verhindern sie das Hinzufügen dynamischer Eigenschaften.

```php
<?php

readonly class Block
{
    public function __construct(
        public int $length;
        public int $width;
    ) {
    }
}
```
