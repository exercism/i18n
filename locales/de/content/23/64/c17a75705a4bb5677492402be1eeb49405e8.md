# Über

`jq` ist ein Tool zum Parsen und Umwandeln von JSON-Daten.
`jq` ist für JSON-Daten das, was `sed` für Text ist: Du kannst strukturierte Daten genauso mühelos aufteilen, filtern, abbilden und umwandeln, wie du mit `sed`, `awk`, `grep` und Co. mit Text arbeitest.

`jq` ist eine dynamisch typisierte funktionale Programmiersprache.
Alle Werte sind unveränderlich.

`jq`-Programme bestehen aus Pipelines von „Filtern“: Jeder Filter nimmt ein einzelnes Element als Eingabewert entgegen, verarbeitet es und gibt null oder mehr umgewandelte Elemente aus.
Einen „Filter“ kann man auch einen „Ausdruck“ nennen.

Die Ausgaben eines Ausdrucks können mit dem Operator `|` an einen anderen weitergegeben werden.
`expressionA | expressionB` wendet `expressionA` auf eine Eingabe an; anschließend wird `expressionB` für jede der Ausgaben von `expressionA` wiederholt ausgeführt.

Die Eingabe eines Ausdrucks kann explizit mit `.` referenziert werden.
Ein Ausdruck, der `1` zu seiner Eingabe addiert, sieht so aus: `. + 1` (oder `1 + .`).

## `jq` (das Programm) versus `jq` (die Sprache)

`jq` ist ein Programm, das du als Paket auf verschiedenen Betriebssystemen installieren oder aus dem Quellcode selbst bauen kannst (es ist in C geschrieben).
Es hat mehrere nützliche [Kommandozeilenoptionen][cli-options] und ist ziemlich schnell.

Das `jq`-Programm implementiert außerdem eine _Sprache_, mit der sich die Eingabedaten beliebig komplex bearbeiten lassen.

Dieser Exercism-Track konzentriert sich auf die Sprache.
In den Tests wirst du die Verwendung des `jq`-Programms sehen.

## JSON

Von [json.org][json]:

> JSON (JavaScript Object Notation) ist ein leichtgewichtiges Datenaustauschformat.
> Es ist für Menschen leicht zu lesen und zu schreiben.
> Es ist für Maschinen leicht zu parsen und zu generieren.
> Es basiert auf einer Teilmenge des Standards der Programmiersprache JavaScript, ECMA-262, 3. Ausgabe, Dezember 1999.
> JSON ist ein Textformat, das völlig unabhängig von der Programmiersprache ist, aber Konventionen verwendet, die Programmierern der C-Familie vertraut sind, darunter C, C++, C#, Java, JavaScript, Perl, Python und viele andere.
> Diese Eigenschaften machen JSON zu einer idealen Datenaustauschsprache.

In diesem Track geht es um `jq`, nicht um JSON.
Wir gehen davon aus, dass du mit der [JSON-Syntax und den JSON-Datentypen][wiki-json] vertraut bist.
