# Überblick

Ein [C# `Attribute`][attribute-concept] bietet eine Möglichkeit, eine Deklaration zu dekorieren, um ihr Metadaten zuzuordnen: einer Klasse, einer Methode, einem Enum, einem Feld, einer Eigenschaft oder jeder [anderen unterstützten][attribute-targets] Deklaration.

Du kannst [ein Attribut][attribute] auf eine Deklaration anwenden, indem du es in eckigen Klammern `[]` vor die Deklaration setzt. Das folgende Beispiel verwendet sowohl ein `ClassAttribute` als auch ein `FieldAttribute`:

```csharp
[Class]
public class MyClass
{
    [Field] public int myField;
}
```

Die deklarativen Metadaten ordnen dem Code lediglich zusätzliche strukturierte Informationen zu und verändern sein Verhalten nicht. Ein anderer Teil des Codes verwendet diese Metadaten aber, um das Verhalten ihres Ziels zu ändern oder einige seiner Funktionalitäten hinzuzufügen, zu ändern, zu entfernen oder einzuschränken.

Es gibt mehrere vordefinierte Attribute wie: `Flags`, `Obsolete`, `Conditional`. Beachte, dass der vollständige Name des [`Flags`-Attributs][flags-attribute] `FlagsAttribute` lautet, das Suffix „Attribute“ kann beim Verwenden des Attributs aber weggelassen werden.

Die folgenden vier vordefinierten Attribute werden regelmäßig verwendet:

- `[Flags]`: Vordefiniert im System-Namespace. Zeigt an, dass das Enum sowohl bitweise Operationen als auch die Methode `Enum.HasFlag()` unterstützt, zusätzlich würde `ToString` alle Flags anzeigen: [siehe Beispiel][flags-example].
- `[Obsolete]`: Vordefiniert im System-Namespace. Ermöglicht es, eine Meldung hinzuzufügen, warum der Code veraltet ist, und kann verwendet werden, um Compilerwarnungen oder -fehler anzuzeigen.
- `[Conditional]`: Vordefiniert im System.Diagnostics-Namespace. Ermöglicht es, zur Kompilierzeit einige Methodenaufrufe zu Debugging-Zwecken (Diagnose) zu entfernen.
- `[CallerMemberName]`: Vordefiniert im System.Runtime.CompilerServices-Namespace. Ermöglicht es einer Methode, Informationen über ihren Aufrufer zu erhalten.
