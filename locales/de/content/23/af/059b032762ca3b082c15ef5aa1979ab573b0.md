# Einführung

Vererbung ist ein Kernkonzept der OOP (objektorientierte Programmierung).
Sie beschreibt eine IS-A-Beziehung.
In der Programmierung bedeutet sie dasselbe wie im Englischen: Merkmale von der Elternklasse zu erben (in der Programmierung sind diese Merkmale normalerweise Funktionen und Variablen).

Betrachte eine Klasse `Animal` wie hier gezeigt,

```java
//Creating an Animal class with bark() as a member function.
public class Animal {

    public void bark() {
        System.out.println("This is an animal");
    }

}
```

`Animal` ist eine Elternklasse, weil die Eigenschaften dieser Klasse auf alle Tiere im Allgemeinen erweitert werden können.

Betrachte ein Tier namens `Lion` mit einer Klasse wie dieser:

```java
//Lion class is a child class of Animal.
public class Lion extends Animal {

    @Override
    public void bark() {
        System.out.println("Lion here!!");
    }

}
```

~~~~exercism/note
Die Annotation `Override` zeigt an, dass eine Methode in einer Unterklasse eine Methode ihrer Oberklasse überschreibt.
Sie ist nicht zwingend nötig, aber es ist eine bewährte Vorgehensweise, sie zu verwenden.
~~~~

Wenn wir nun Folgendes machen,

```java
Animal animal = new Lion(); //creating instance of Animal, of type Lion
animal.bark();
```

Hinweis: Hier wird die Klasse `Animal` mit `Lion` initialisiert.
Die Ausgabe sieht dann so aus

```java
Lion here!!
```

In der OOP gibt es viele Arten der Vererbung, aber Java unterstützt nur einige davon (mehrstufige und hierarchische Vererbung).
Mehr dazu erfährst du in [diesem Artikel][java-inheritance].
