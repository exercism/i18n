# Anweisungen (Ergänzung)

## Vektoren

Der Rückgabewert der `plants`-Funktion ist ein `Vector Plant 4`.

Vektoren stellen Arrays mit einer festen Länge dar.
Diese Länge kann auch zur Laufzeit bestimmt werden.
Man kann sie sich als ein Paar aus einem `Array` und einem Beweis vorstellen, dass das Array die erforderliche Länge hat.
Das bedeutet, dass du diesen Beweis liefern musst, um einen `Vector` zu konstruieren.

[Dieses Kapitel][introduction] bietet eine gute Einführung in das Theorembeweisen in Lean.
Für einen tieferen Einstieg wird [dieses Buch][advanced] als offizielle Ressource auf der Lean-Website aufgeführt.

Lean bietet viele Taktiken, die einen Beweis oder Teile davon automatisieren können. 
Vielleicht möchtest du eine [Sprachreferenz][reference] anschauen.
