# Einführung

[Tupel][tuples] fassen mehrere Werte zu einem einzigen zusammengesetzten Wert zusammen.
Anders als bei Arrays müssen die Werte in einem Tupel nicht denselben Typ haben, und die Größe eines Tupels ist nach dem Erstellen festgelegt.

Du erstellst ein Tupel, indem du kommagetrennte Werte in runde Klammern setzt:

```swift
let order = ("biscuits", 2.99, 3)
```

Du kannst Typannotationen auch explizit angeben:

```swift
let order: (String, Double, Int) = ("biscuits", 2.99, 3)
```

Um einzelne Elemente aus einem unbenannten Tupel zu extrahieren, verwendest du die Indexsyntax mit Nullbasis (`.0`, `.1` usw.):

```swift
let item = order.0     // "biscuits"
let quantity = order.2 // 3
```

## Benannte Tupel

Du kannst einzelnen Tupelelementen beim Definieren des Tupels Namen geben:

```swift
let order = (item: "biscuits", price: 2.99, quantity: 3)
```

Benannte Elemente machen den Code lesbarer und du kannst mit der Punktnotation über ihre Bezeichnungen auf die Elemente zugreifen:

```swift
let item = order.item         // "biscuits"
let quantity = order.quantity // 3
```

Du kannst Elementnamen auch in die Typannotation aufnehmen:

```swift
let order: (item: String, price: Double, quantity: Int) = (item: "biscuits", price: 2.99, quantity: 3)
```

## Tupel verändern

Wenn ein Tupel als Variable (`var`) deklariert ist, kannst du seine Elemente ändern:

```swift
var order = ("biscuits", 2.99, 3)
order.0 = "cookies"
order.1 = 1.99
order.2 = 5

print(order)
// Prints ("cookies", 1.99, 5)
```

## Mehrere Werte zurückgeben

Swift-Funktionen können nur einen einzigen Wert zurückgeben. Wenn du ein Tupel zurückgibst, kannst du jedoch mehrere Werte bündeln und [mehrere Werte aus einer Funktion zurückgeben][multiple-return-values]:

```swift
func divide(_ dividend: Int, by divisor: Int) -> (quotient: Int, remainder: Int) {
    let quotient = dividend / divisor
    let remainder = dividend % divisor
    return (quotient, remainder)
}

let result = divide(14, by: 4)
print("Quotient: \(result.quotient), Remainder: \(result.remainder)")
// Prints "Quotient: 3, Remainder: 2"
```

## Tupel zerlegen

Du kannst die Werte eines Tupels in einzelne Konstanten oder Variablen zerlegen (entpacken):

```swift
let order = ("biscuits", 2.99, 3)
let (item, price, quantity) = order

print(item) // Prints "biscuits"
```

Das Zerlegen von Tupeln funktioniert auch direkt in `for-in`-Schleifen:

```swift
let orders = [("biscuits", 2.99, 3), ("cookies", 1.99, 5)]

for (item, price, quantity) in orders {
    print("Item: \(item), Price: \(price), Quantity: \(quantity)")
}
```
