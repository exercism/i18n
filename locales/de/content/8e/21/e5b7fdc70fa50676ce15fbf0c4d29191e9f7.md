# Operatorüberladung

Operatorüberladung ist ein Merkmal mancher Programmiersprachen: Sie erlaubt es, Standardoperatoren wie Addition (`+`), Subtraktion (`-`), Multiplikation (`*`) und Division (`/`) so neu zu definieren, dass sie mit benutzerdefinierten Typen funktionieren.

Dadurch kann die Syntax des Codes intuitiver werden, weil sich Operationen auf benutzerdefinierte Typen genauso ausdrücken lassen wie Operationen auf primitive Typen.

In Cairo erreicht man Operatorüberladung durch die Implementierung bestimmter Traits.

Jeder Operator hat ein zugehöriges Trait, und zum Überladen dieses Operators musst du eine Implementierung dieses Traits für einen eigenen Typ bereitstellen.
Allerdings solltest du Operatorüberladung mit Bedacht einsetzen.

Ein Missbrauch kann zu Verwirrung führen und den Code schwerer wartbar machen, etwa wenn der überladene Operator keine semantische Bedeutung hat.

Betrachten wir ein Beispiel, bei dem zwei `Potions` kombiniert werden müssen.

`Potions` haben zwei Datenfelder: mana und health.

Beim Kombinieren zweier `Potions` sollten ihre jeweiligen Felder addiert werden.

```rust
struct Potion {
    health: felt252,
    mana: felt252,
}

impl PotionAdd of Add<Potion> {
    fn add(lhs: Potion, rhs: Potion) -> Potion {
        Potion { health: lhs.health + rhs.health, mana: lhs.mana + rhs.mana }
    }
}

fn main() {
    let health_potion: Potion = Potion { health: 100, mana: 0 };
    let mana_potion: Potion = Potion { health: 0, mana: 100 };
    let super_potion: Potion = health_potion + mana_potion;
    // Both potions were combined with the `+` operator.
    assert(super_potion.health == 100, '');
    assert(super_potion.mana == 100, '');
}
```

Im obigen Code implementieren wir das `Add`-Trait für den Typ `Potion`.

Die add-Funktion nimmt zwei Argumente entgegen: `lhs` und `rhs` (linke und rechte Seite).

Der Funktionsrumpf gibt eine neue `Potion`-Instanz zurück, wobei ihre Feldwerte eine Kombination aus `lhs` und `rhs` sind.

Wie das Beispiel zeigt, musst du beim Überladen eines Operators den konkreten Typ angeben, der überladen wird.

Das überladene generische Trait ist `Add<T>`, und wir definieren eine konkrete Implementierung für den Typ `Potion` mit `Add<Potion>`.
