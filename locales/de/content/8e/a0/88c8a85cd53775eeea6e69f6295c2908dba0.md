# Anleitung

In dieser Übung schreibst du Code, der einem Freelancer hilft, mit seinen Kunden über die Preise bestimmter Projekte zu kommunizieren.
Du schreibst ein paar Hilfsmethoden, mit denen du die Kosten für die Kunden schnell berechnen kannst.

```exercism/note
Der Parameter `rate_per_hour` und die Methode `day_rate` haben beide mit Geld zu tun.
Die Maßeinheit ist Geld pro Zeiteinheit, also jeweils Stunden bzw. Tage.
```

## 1. Berechne den Tagessatz aus einem Stundensatz

Ein Kunde kontaktiert den Freelancer, um sich nach seinen Sätzen zu erkundigen.
Der Freelancer erklärt, dass er **_8 Stunden am Tag arbeitet._**
Er kennt allerdings nur seine Stundensätze für das Projekt.
Hilf ihm, aus einem Stundensatz einen Tagessatz zu schätzen.

```abap
DATA(freelancer_rates) = NEW zcl_freelancer_rates( ).

freelancer_rates->day_rate( 89 ).
// => 712
```

Der Tagessatz muss nicht gerundet oder auf eine „feste" Genauigkeit geändert werden.

## 2. Berechne die Anzahl der Arbeitstage bei festem Budget

Eines Tages bietet ein Projektmanager dem Freelancer an, an einem Projekt mit festem Budget zu arbeiten.
Hilf ihm, aus dem festen Budget und seinem Stundensatz die Anzahl der Tage zu berechnen, die er arbeiten würde, bis das Budget aufgebraucht ist.
Das Ergebnis _muss_ auf die nächste ganze Zahl **abgerundet** werden.

```abap
freelancer_rates->days_in_budget(
  budget        = 20000
  rate_per_hour = 89 ).
// => 28
```

## 3. Berechne den rabattierten Satz für große Projekte

Oft beauftragen die Kunden des Freelancers ihn mit Projekten, die sich über mehrere Monate erstrecken.
In solchen Fällen beschließt der Freelancer, für jeden vollen Monat einen Rabatt zu gewähren, und die restlichen Tage werden zum Tagessatz abgerechnet.
Dank deiner hervorragenden Work-Life-Balance arbeitest du nur 22 Tage pro Kalendermonat, also **_hat jeder Monat 22 abrechenbare Tage._**
Hilf ihm, die Kosten für solche Projekte zu schätzen, wenn ein Stundensatz, die Anzahl der abrechenbaren Tage des Projekts und ein monatlicher Rabatt gegeben sind.
Der Rabatt wird immer als Zahl übergeben, wobei aus `42%` `0.42` wird. Das Ergebnis _muss_ auf die nächste ganze Zahl **aufgerundet** werden.

```abap
freelancer_rates->price_with_monthly_discount(
  rate_per_hour = 89
  num_days      = 230
  discount      = '0.42' ).
// => 97972
```
