# Einführung

Swift hat eine Reihe von Anweisungen, mit denen du den normalen Kontrollfluss von Schleifen verändern kannst.
Man nennt sie Kontrollübertragungsanweisungen.
Du kennst bereits `return`; in diesem Konzept lernst du weitere kennen, darunter `continue`, `break` und Labels.

## Continue

Manchmal ist es nötig, vorzeitig zur nächsten Iteration einer Schleife zu springen, ohne die restlichen Anweisungen in der aktuellen Iteration der Schleife auszuführen.
Dafür kannst du das Schlüsselwort `continue` verwenden.
Wenn `continue` ausgeführt wird, springt die Schleife zur nächsten Prüfung, ob die nächste Iteration der Schleife ausgeführt werden kann, also zum `while` in while- und repeat-while-Schleifen oder zur Prüfung, ob es in for-in-Schleifen ein weiteres Element in der Sequenz gibt.

```swift
count = 1
while count < 6 {
  count += 1
  if count == 4 { continue }
  print(count)
}

// prints:
// 2
// 3
// 5
```

## Break

Mit Break kannst du eine Schleife vorzeitig verlassen.
Wenn `break` ausgeführt wird, wird die Schleife sofort verlassen und das Programm fährt mit der ersten Anweisung nach der Schleife fort.

```swift
for fruit in ["banana", "grapes", "apple", "strawberry", "kiwi", "lemon"] {
  if !fruit.count.isMultiple(of: 2) { break }
  print(fruit)
}

// prints:
// banana
// grapes
```

## Labels

Wenn Schleifen verschachtelt sind, kann es vorkommen, dass du mit `break` oder `continue` äußere Schleifen verlassen oder neu starten möchtest, die die Schleife enthalten, in der `break` oder `continue` verwendet wird.
In solchen Fällen kannst du mit Labels festlegen, welche Schleife verlassen oder neu gestartet werden soll.
Du kannst eine Schleife mit einem Label versehen, indem du einen Namen und einen Doppelpunkt vor das `while`, `repeat` oder `for` setzt, das die Schleife beginnt.

Um die Wirkung solcher Labels zu sehen, schau dir die folgende Schleife an.

```swift
outerLoop: for fruit in ["banana", "grapes", "apple", "strawberry", "kiwi", "lemon"] {
  print("\n--- \(fruit) ---")
  for letter in fruit {
    guard letter != "n" else { break outerLoop }
    print(letter)
  }
}

// prints:
// --- banana ---
// b
// a
```

## Fallthrough

Mit dem Schlüsselwort `fallthrough` springst du zum nächsten Fall in einer switch-Anweisung.
Das bedeutet, dass der Code im nächsten Fall ausgeführt wird, ohne dass seine Bedingung(en) geprüft werden.
Dadurch verhält sich die switch-Anweisung wie in anderen Programmiersprachen, in denen die `break`-Anweisung nicht nötig ist, um die switch-Anweisung nach einem passenden Fall zu verlassen.
Mehr über `fallthrough` erfährst du im [Swift-Buch][fallthrough].

```swift
let value = 1
switch value {
case 1:
  print("One")
  fallthrough
case 2:
  print("Two")
}

// prints:
// One
// Two
```
