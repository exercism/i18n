# Tests

Um die Tests auszuführen, führe den Befehl `bal test --offline` im Verzeichnis der Übung aus.

## Übersprungene Tests

Anfangs ist nur der erste Test aktiviert.
So ermutigen wir dich, die Übung Schritt für Schritt zu lösen.
Sobald der erste Test läuft, entferne die Eigenschaft `enable: false` aus dem nächsten Test und arbeite daran, auch diesen Test zum Laufen zu bringen.
