# Tests

## Clojure CLI

Die Clojure-Übungen auf Exercism enthalten eine `deps.edn`-Datei mit einem `:test`-Alias, um den [cognitect-labs test-runner](https://github.com/cognitect-labs/test-runner) aufzurufen:

``` bash
$ clj -X:test
```

## Leiningen

Du kannst die Tests der Übung auch mit Leiningen ausführen. Führe dazu den folgenden Befehl im Verzeichnis der Übung aus:

```bash
lein test
```

## REPL

Um die Tests der Übung mit der REPL auszuführen, führe den folgenden Befehl im Verzeichnis der Übung aus:

```bash
$ clj
```

-oder-

```bash
$ lein repl
```

Lade dann mit `require` den Test-Namespace der Übung und den Clojure-Test-Namespace):

```clojure
;; replace <exercise> with the exercise's name
=> (require '<exercise>-test)
```

Rufe dann `run-tests` für `<exercise>-test` auf:

```clojure
;; replace <exercise> with the exercise's name
=> (clojure.test/run-tests '<exercise>-test)
```
