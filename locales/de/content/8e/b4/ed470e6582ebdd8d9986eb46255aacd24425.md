# Anweisungen

Zähle die Rechtecke in einem ASCII-Diagramm wie dem folgenden.

```text
   +--+
  ++  |
+-++--+
|  |  |
+--+--+
```

Das obige Diagramm enthält diese 6 Rechtecke:

```text


+-----+
|     |
+-----+
```

```text
   +--+
   |  |
   |  |
   |  |
   +--+
```

```text
   +--+
   |  |
   +--+


```

```text


   +--+
   |  |
   +--+
```

```text


+--+
|  |
+--+
```

```text

  ++
  ++


```

Du kannst davon ausgehen, dass die Eingabe immer ein sauberes Rechteck ist (d. h. jede Zeile ist genauso lang wie die erste Zeile).
