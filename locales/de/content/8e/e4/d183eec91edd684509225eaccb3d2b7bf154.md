# Hinweise

## Allgemein

- Lies in der offiziellen [Einstiegsanleitung][getting-started-keyword-lists] über Keyword-Listen.
- Lies auf [elixirschool.com][elixir-school-keyword-lists] über Keyword-Listen.
- Wirf einen Blick in die [Dokumentation des Moduls `Keyword`][keyword].

## 1. Erkläre die Weinfarben

- Du musst die in der Tabelle angegebenen Informationen als Keyword-Liste schreiben.
- Schau dir einige [Beispiele][keyword-examples] an, wie man eine Keyword-Liste definiert.

## 2. Ermittle alle Weine einer bestimmten Farbe

- Es gibt eine [eingebaute Funktion][keyword-get-values], mit der du die Liste aller Werte für einen bestimmten Schlüssel erhältst.

## 3. Ermittle alle Weine einer bestimmten Farbe, die in einem bestimmten Jahr abgefüllt wurden

- Es gibt eine [eingebaute Funktion][keyword-get], mit der du einen einzelnen Wert für einen bestimmten Schlüssel erhältst.
- Du musst das Filtern der Flaschen nicht selbst implementieren. Du musst nur bedingt die bereits implementierte Funktion `filter_by_year/2` verwenden.

## 4. Ermittle alle Weine einer bestimmten Farbe, die in einem bestimmten Land abgefüllt wurden

- Es gibt eine [eingebaute Funktion][keyword-get], mit der du einen einzelnen Wert für einen bestimmten Schlüssel erhältst.
- Du musst das Filtern der Flaschen nicht selbst implementieren. Du musst nur bedingt die bereits implementierte Funktion `filter_by_country/2` verwenden.
