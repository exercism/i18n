# Ergänzung zu den Anweisungen

## Implementierung

Es kann passieren, dass die Roboternamen ausgehen. Sobald jeder mögliche Robotername vergeben ist, sollte ein Fehler zurückgegeben werden.

## Bonus-Test

Sobald `go test` durchläuft, wirst du feststellen, dass es in der Testsuite einen Test namens `TestCollisions` gibt, der standardmäßig übersprungen wird, weil er lange dauern kann.
Dieser Test erstellt neue Roboter, bis dem Roboter keine neuen Namen mehr zugewiesen werden können.

Damit der Test ausgeführt wird, entferne diese Zeile:

```go
t.Skip("skipping test as it can take a long time to run if solution is sub-optimal.")
```

Damit dieser Test durchläuft, musst du sicherstellen, dass der Name eines Roboters nicht schon einmal verwendet wurde und dass Namen effizient vergeben werden können.
