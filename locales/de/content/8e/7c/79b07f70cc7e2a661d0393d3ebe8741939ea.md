# Einführung

Haxe ist stark typisiert, aber das Typsystem lässt sich bei Bedarf umgehen. Wenn du einem Namen einen Wert zuweist, nennt man das Definieren einer Variable. Du kannst eine Variable definieren, indem du ihren Typ explizit angibst oder den Haxe-Compiler den Typ ableiten lässt. Die folgenden beiden Variablendefinitionen sind also gleichwertig:

```haxe
var explicitVariable:Int = 10; // Explicitly typed
var implicitVariable = 10; // Implicit typed
```

Eine Variable aktualisierst du mit dem `=`-Operator:

```haxe
var number = 0; // Initial value
number = 1; // Updated value
```

Der Compiler wirft einen Fehler, wenn du einen Wert zuweisen willst, dessen Typ sich von dem der Variable unterscheidet:

```haxe
var number = 1; // Variable number is of integer type
number = "Hello" // Error trying to assign a string to an integer variable
```

Eine Funktion, die sich innerhalb einer Klasse befindet, heißt _Methode_. Methoden können keinen oder mehrere Parameter haben. Alle Parameter müssen explizit typisiert sein. Genau wie die Parameter lässt sich der Rückgabetyp einer Methode nicht ableiten, er muss angegeben werden. Mit dem Schlüsselwort `return` gibst du Werte aus einer Methode zurück:

```haxe
function add(x:Int, y:Int):Int {
  return x + y;
}
```

Eine Methode rufst du auf, indem du ihre Klasse und ihren Methodennamen angibst und Argumente übergibst:

```haxe
var sum = add(1, 2) // sum = 3
```

Der Gültigkeitsbereich wird in Haxe durch die Zeichen `{` und `}` festgelegt.

Haxe unterstützt zwei Arten von Kommentaren. Einzeilige werden mit `//` eingeleitet, mehrzeilige stehen zwischen `/*` und `*/`.
