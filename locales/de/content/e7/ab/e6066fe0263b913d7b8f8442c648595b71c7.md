# Ergänzung zu den Anweisungen

## Hinweise

Um den Test zu bestehen, musst du einige Typen anlegen, mit denen dein Code arbeiten kann. Du brauchst ein Objekt für `School`, das eine Sequenz vom Typ `Student` aufnimmt. `Student` ist ein Tupel aus `string` und `int`, das Name und Klassenstufe der Schüler speichert.

Hier ist etwas Code für die Typen, der dir beim Einstieg helfen kann:

```nim
type
  Student* = tuple[name: string, grade: int]
  School* = object
    students*: seq[Student]
```
