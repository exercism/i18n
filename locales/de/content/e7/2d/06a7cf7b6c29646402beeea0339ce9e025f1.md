# kein benannter Export

Es wurde kein [Export](https://developer.mozilla.org/en-US/docs/Web/JavaScript/Reference/Statements/export) mit dem Namen `%{export.name}` gefunden. Ohne ihn bestehen die Tests nicht.

Stelle sicher, dass es `%{export.name}` gibt, und setze `export` davor:
```javascript
// exporting a "const"
export const %{export.name} = /*...*/

// exporting a named function declaration
export function %{export.name}() { /* ... */ }
```
