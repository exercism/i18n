# Anleitung

In dieser Übung implementierst du eine Teilmenge von Hilfsroutinen, mit denen ein Entwickler Bezeichnernamen bereinigen kann.

In den 4 Aufgaben baust du die Routine `clean` nach und nach auf. Ein gültiger Bezeichner besteht aus null oder mehr Buchstaben und Unterstrichen.

In allen Fällen ist der Eingabe-String garantiert nicht nil. Wenn ein leerer String an die Funktion `clean` übergeben wird, soll ein leerer String zurückgegeben werden.

Beachte, dass der Aufrufer die Routine `clean` nicht mit einem leeren Bezeichner aufrufen sollte, da solche Bezeichner wirkungslos sind.

## 1. Ersetze alle vorkommenden Leerzeichen durch Unterstriche

Implementiere die Funktion `clean` so, dass sie alle Leerzeichen durch Unterstriche ersetzt. Das gilt auch für führende und nachfolgende Leerzeichen.

```clojure
(clean "my   Id")
;;=> "my___Id"
```

## 2. Ersetze Steuerzeichen durch den String "CTRL" in Großbuchstaben

Ändere die Funktion `clean` so, dass sie Steuerzeichen durch den String `"CTRL"` in Großbuchstaben ersetzt.

```clojure
(clean "my\0Id")
;;=> "myCTRLId"
```

## 3. Wandle kebab-case in camelCase um

Ändere die Funktion `clean` so, dass sie kebab-case in camelCase umwandelt.

```clojure
(clean "à-ḃç")
;;=> "àḂç"
```

## 4. Lass griechische Kleinbuchstaben weg

Ändere die Funktion `clean` so, dass sie alle griechischen Buchstaben im Bereich 'α' bis 'ω' weglässt.

```clojure
(clean "MyΟβιεγτFinder")
;;=> "MyΟFinder"
```
