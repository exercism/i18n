# Anleitung

In dieser Übung schreibst du noch etwas mehr Code, um dir beim Kochen deiner brillanten Lasagne aus deinem Lieblingskochbuch zu helfen.

Es gibt fünf Aufgaben, die sich alle mit der Zeit befassen, die du für das Kochen der Lasagne brauchst.

## 1. Das Ändern der erwarteten Ofenzeit ermöglichen

Du möchtest eine verbesserte Funktion `remainingMinutesInOven` schreiben, die die Anzahl der verstrichenen Minuten, die die Lasagne im Ofen war, als Parameter entgegennimmt und zurückgibt, wie viele Minuten die Lasagne noch im Ofen bleiben muss, basierend auf der erwarteten Ofenzeit in Minuten aus der vorherigen Aufgabe.
Bisher hast du dich auf einen konstanten Wert `expectedMinutesInOven` verlassen, der von außerhalb der Funktion `remainingMinutesInOven` kam.
Das war dir sowohl etwas zu unübersichtlich als auch nicht flexibel genug, denn es erlaubt dir nicht, die erwartete Zeit im Ofen zu ändern.

Um das aufzuräumen, definiere die Funktion `remainingMinutesInOven`, die die Anzahl der verstrichenen Minuten, die die Lasagne im Ofen war, als Parameter entgegennimmt, sowie einen Parameter `expectedMinutesInOven` mit dem Standardwert 40.
Deine Funktion sollte zurückgeben, wie viele Minuten die Lasagne noch im Ofen bleiben muss, basierend auf der erwarteten Ofenzeit in Minuten aus der vorherigen Aufgabe.

```swift
remainingMinutesInOven(elapsedMinutes: 30)
// Returns 10
remainingMinutesInOven(elapsedMinutes: 30, expectedMinutesInOven: 75)
// Returns 45
```

## 2. Unterschiedliche Anzahlen von Schichten ermöglichen

Zuvor hattest du eine Funktion `preparationTimeInMinutes` geschrieben, die die Anzahl der Schichten, die du der Lasagne hinzugefügt hast, als Parameter entgegennimmt und zurückgibt, wie viele Minuten du für die Vorbereitung der Lasagne gebraucht hast, wobei du davon ausgehst, dass jede Schicht 2 Minuten Vorbereitung dauert.
Mit dieser Funktion bist du allerdings nicht besonders zufrieden, denn du musst die Anzahl der Schichten in deiner Lasagne selbst zählen, bevor du diese Funktion aufrufen kannst, und wer hat schon Zeit dafür?

Um es dir einfacher zu machen, schreibe eine Funktion `preparationTimeInMinutes`, die einen variadischen Parameter `layers` vom Typ `String` entgegennimmt, in dem du die verschiedenen Schichten deiner Lasagne auflistest.
Die Funktion zählt dann die Anzahl der Schichten in deiner Lasagne und gibt die benötigte Vorbereitungszeit zurück.

```swift
preparationTimeInMinutes(layers: "sauce", "noodles")
// Returns 4
preparationTimeInMinutes(layers: "sauce", "noodles", "sauce", "meat", "mozzarella", "noodles", "sauce", "eggplant", "béchamel", "noodles", "sauce", "mozzarella")
// Returns 24
```

## 3. Mengen an Nudeln und Soße berechnen

Bevor du anfängst, deine Lasagne zusammenzubauen, möchtest du sicherstellen, dass du genug Soße und Nudeln hast, um die Lasagne deiner Träume zu bauen.
Für jede Nudelschicht in deiner Lasagne brauchst du 3 Nudeln.
Für jede Soßenschicht in deiner Lasagne brauchst du 0,2 Liter Soße.

Definiere die Funktion `quantities`, die einen variadischen Parameter `layers` vom Typ `String` entgegennimmt, in dem du die verschiedenen Schichten deiner Lasagne auflistest.
Die Funktion bestimmt dann die Menge an Nudeln und Soße, die für dein Gericht benötigt wird. Das Ergebnis sollte in einem Tupel vom Typ `(noodles: Int, sauce: Double)` zurückgegeben werden.

```swift
quantities(layers: "sauce", "noodles", "sauce", "meat", "mozzarella", "noodles", "sauce", "eggplant", "béchamel", "noodles", "sauce", "mozzarella")
// Returns (noodles: 9, sauce: 0.8)
quantities(layers: "sauce", "noodles", "sauce", "noodles", "meat", "noodles", "mozzarella")
// Returns (noodles: 9, sauce: 0.4)
```

## 4. Liter direkt in Flüssigunzen umrechnen

Leider ist das Volumen der Soße, die du zur Hand hast, in Flüssigunzen statt in Litern angegeben.
Um dir zu helfen, festzustellen, ob du genug Soße zur Hand hast, schreibe eine Funktion `toOz`, die einen In-Out-Tupel-Parameter `(noodles: Int, sauce: Double)` entgegennimmt und die Soßenmenge in Flüssigunzen umrechnet.
Beachte, dass ein Liter 33,814 Flüssigunzen entspricht.

```swift
var amount = (noodles: 9, sauce: 0.8)
toOz(&amount)

amount
// Returns (noodles: 9, sauce: 27.0512)
```

## 5. Den besten Wein zum Servieren bestimmen

Zum Schluss möchtest du wissen, welche Art von Wein du zu deiner Lasagne servieren solltest.
Du hast gehört, dass du Weißwein servieren solltest, wenn mehr Mozzarella, Ricotta und Béchamel in der Lasagne sind als Fleisch und Soße, und ansonsten Rotwein.
Schreibe eine Funktion `redWine`, die einen variadischen Parameter `layers` vom Typ `String` entgegennimmt, in dem du die verschiedenen Schichten deiner Lasagne auflistest.
Die Funktion verwendet fünf verschachtelte Funktionen, um die Anzahl der Schichten von Mozzarella, Ricotta, Béchamel, Soße und Fleisch in der Lasagne zu bestimmen, und vergleicht die Anzahlen der Schichten, um zu entscheiden, ob Rotwein serviert werden sollte. Dabei gibt sie `true` zurück, wenn ja, und `false`, wenn nicht.

```swift
redWine(layers: "sauce", "noodles", "sauce", "meat", "mozzarella", "noodles", "sauce", "eggplant", "béchamel", "noodles", "sauce", "mozzarella")
// Returns true
redWine(layers: "sauce", "noodles", "béchamel", "meat", "mozzarella", "noodles", "ricotta", "eggplant", "béchamel", "noodles", "sauce", "mozzarella")
// Returns false
```
