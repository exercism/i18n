# Einführung

Eine [Liste][list] ist eine veränderliche Sammlung von Elementen _in einer Reihenfolge_.
Listen können Verweise auf beliebige (oder mehrere) Datentypen enthalten, auch auf andere Listen oder Datenstrukturen wie [Tupel][tuples], [Mengen][sets] oder [Wörterbücher][dicts].
Den Inhalt kannst du mit dem Konstrukt `for item in <list>` durchlaufen.
Wenn du zusätzlich die Indizes brauchst, kannst du `for index, item in enumerate(<list>)` verwenden.
Auf die Elemente einer `list` greifst du über einen `0-based index` von links oder einen `-1-based index` von rechts zu.
Listen lassen sich ganz oder teilweise mit der _Slice-Notation_ oder `<list>.copy()` kopieren.
Python bietet viele nützliche und praktische [Methoden][list-methods] für die Arbeit mit Listen.
