# Einführung

In Julia gibt es drei grundlegende bedingte Anweisungen:

- `if`-Ausdrücke
- Der ternäre Operator
- Die Kurzschlussauswertung

## `if`-Ausdrücke

`if`-Ausdrücke sind in Julia denen anderer Sprachen ähnlich:

```julia-repl
julia> function say_if_positive(n)
           if n > 0
               println("n is positive!")
           else
               println("n is not positive!")
           end
       end
say_if_positive (generic function with 1 method)

julia> say_if_positive(10)
n is positive!

julia> say_if_positive(-10)
n is not positive!
```

Wenn der boolesche Ausdruck nach dem `if` zu `true` ausgewertet wird, wird der erste Block ausgeführt und der zweite übersprungen.
Wenn der boolesche Ausdruck nach dem `if` zu `false` ausgewertet wird, wird der erste Block übersprungen und der zweite ausgeführt.
Das Programm läuft dann ab der ersten Codezeile nach dem Schlüsselwort `end` weiter.

~~~~exercism/note
In Julia kennzeichnet das Schlüsselwort `end` das Ende aller Blockausdrücke.
Diese Syntax gilt nicht nur für `if`-Ausdrücke oder Funktionsdefinitionen.
~~~~

Wenn der zweite Block selbst wieder nur ein `if`-Ausdruck wäre, können wir mit `elseif` vermeiden, `if`-Ausdrücke ineinander zu verschachteln:

```julia-repl
julia> function dessert(fruit)
           if fruit == "apple"
               return "Apple Crumble"
           elseif fruit == "lemon"
               return "Lemon Meringue Pie"
           else
               return "Fruit Salad"
           end
       end
dessert (generic function with 1 method)

julia> dessert("apple")
"Apple Crumble"

julia> dessert("lemon")
"Lemon Meringue Pie"

julia> dessert("peach")
"Fruit Salad"
```

Wenn ein `if`-Ausdruck nur für einen der Fälle Code ausführen soll, musst du den `else`-Zweig nicht schreiben.

## Ternärer Operator

Einfache `if-else`-Anweisungen kannst du auch mit dem ternären Operator `a ? b : c` schreiben.
Ist `a` wahr, wird `b` ausgewertet.
Andernfalls wird `c` ausgewertet.

Zum Beispiel lässt sich die folgende Funktion

```julia-repl
julia> function diagnose(heartrate)
           if heartrate > 100
               println("Elevated heart rate.")
           else
               println("Nominal heart rate or dead.")
           end
       end
diagnose (generic function with 1 method)
```

auch so schreiben:

```julia-repl
julia> diagnose(heartrate) = heartrate > 100 ? println("Elevated heart rate.") : println("Nominal heart rate or dead.")
diagnose (generic function with 1 method)
```

Das ist besonders nützlich, wenn du einer Variable je nach Bedingung einen anderen Wert zuweisen möchtest.
`x = a ? b : c` weist `x` den Wert `b` zu, wenn `a` `true` ist, andernfalls weist es `x` den Wert `c` zu.
Zum Beispiel:

```julia-repl
julia> function patient_status(heartrate)
           status = heartrate > 0 ? "alive" : "dead"

           println("The patient is ", status)
       end

julia> patient_status(100)
The patient is alive

julia> patient_status(0)
The patient is dead
```

## Kurzschlussauswertung

Wenn mehrere boolesche Ausdrücke mit den Operatoren `&&` und `||` verkettet werden, wertet Julia nur so viele Ausdrücke aus, wie nötig sind, um den Wert der gesamten Kette zu bestimmen.

Betrachte zum Beispiel die Ausdruckskette `n > 0 && k > 10`.
Wenn `n` gleich `5` ist, ist der erste Teil der Kette, `n > 0`, `true`, und der zweite Ausdruck `k > 10` muss ausgewertet werden, um festzustellen, ob der gesamte Ausdruck `true` ist.
Wenn `n` jedoch gleich `-5` ist, wissen wir, dass die Kette als Ganzes **nicht** `true` sein kann, weil ihr erster Ausdruck `false` ist.

Betrachten wir stattdessen `n > 0 || k > 10`, passiert das Gegenteil.
Wenn `n` gleich `5` ist, ist der erste Teil der Kette, `n > 0`, `true`, und wir wissen, dass die ganze Kette unabhängig vom zweiten Ausdruck `true` sein wird.
Wenn `n` jedoch gleich `-5` ist, muss der zweite Ausdruck ausgewertet werden.

Dieses Verhalten kannst du nutzen, um sehr kurze `if`-Anweisungen zu schreiben:

```julia
if a
    b
end
```

ist äquivalent zu

```julia
a && b
```

Der letzte Ausdruck in einer Kette aus `&&` und `||` muss kein boolescher Ausdruck sein.
Diese Funktion wird oft für frühe Fehler oder Rückgaben verwendet.
Ein Beispiel: Mit der Funktion `dessert(fruit)` von oben:

```julia-repl
julia> function whats_for_dessert(fruit, allergic_to)
           fruit == allergic_to && return "I can't eat that, guess I'll not have dessert tonight!"

           return dessert(fruit)
       end
whats_for_dinner (generic function with 1 method)

julia> whats_for_dinner("apple", "peach")
"Apple Crumble"

julia> whats_for_dinner("apple", "apple")
"I can't eat that, guess I'll not have dessert tonight!"
```
