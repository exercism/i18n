# Über

Das Flags-Attribut ermöglicht es, die in einer diskriminierten Union definierten Werte als Bitpositionen (d. h. Flags) darzustellen.
Als Flags lassen sich solche Werte kombinieren, sodass mehrere boolesche Bedingungen in einem einzigen Wert dargestellt werden können.

```fsharp
[<Flags>]
type PhoneFeatures =
| Call = 1
| Text = 2
```

```fsharp
[<Flags>]
type PhoneFeaturesBinary =
| Call = 0b00000001
| Text = 0b00000010
```

Das Setzen eines Flags kann mit dem bitweisen OR-Operator (`|||`) erfolgen; das Zurücksetzen eines Flags kann mit einer Kombination aus dem bitweisen AND-Operator (`&&&`) und dem bitweisen Negationsoperator (`~~~`) erfolgen.
Während der Zustand eines Flags mit dem bitweisen AND-Operator geprüft werden kann, kannst du auch die HasFlag()-Methode verwenden.

```fsharp
let features = PhoneFeatures.Call

// Set the Text flag
let moreFeatures = features ||| PhoneFeatures.Text

moreFeatures.HasFlag(PhoneFeatures.Call) // => true
moreFeatures.HasFlag(PhoneFeatures.Text) // => true

// Unset the Call flag
let lessFeatures = features &&& ~~~PhoneFeatures.Call

lessFeatures.HasFlag(PhoneFeatures.Call) // => false
lessFeatures.HasFlag(PhoneFeatures.Text) // => true
```

Eine vollständige Liste der in der F#-Sprache verfügbaren bitweisen Operatoren findest du in der [Zusammenfassung der bitweisen Operatoren][bitwise-operators].
