# Einführung

## Mustervergleich mit Literalen

Mit `if/else`-Ausdrücken kannst du bedingte Logik ausführen, aber Haskell bietet noch einen mächtigeren Weg, bedingte Logik umzusetzen: den [Mustervergleich][pattern-matching].
Beim Mustervergleich wird ein Wert gegen ein oder mehrere _Muster_ geprüft.
Ein Beispiel für ein solches Muster ist das _Konstantenmuster_, das einen Wert gegen eine Konstante abgleicht (z. B. `1` oder `"hello"`).

Wenn du Funktionen definierst, kannst du für verschiedene Muster separate Funktionsrümpfe angeben.
Das führt zu sauberem Code, der einfach und lesbar ist.
Du kannst bei jedem Datentyp Muster abgleichen: Zahlen, Zeichen, Listen, Tupel usw.

Eine einfache Funktion, die eine ganze Zahl (`Int`) entgegennimmt und sie _1_ näher an _0_ heranbringt, könnte man zum Beispiel so ausdrücken:

```haskell
closerToZero :: Int -> Int
closerToZero 0 = 0
closerToZero 1 = 0
```

Der Mustervergleich spielt seine Stärken erst aus, wenn du ihn mit anderen Mustern kombinierst, zum Beispiel dem _Variablenmuster_:

```haskell
closerToZero :: Int -> Int
closerToZero 0 = 0
closerToZero n = n - 1
```

Das obige Beispiel behandelt alle Eingaben außer _0_ gleich und würde für negative Zahlen falsche Ergebnisse liefern.
Das lässt sich mit bedingten Mustern lösen, den sogenannten _Guards_, die mit dem Symbol `|` ausgedrückt werden:

```haskell
closerToZero :: Int -> Int
closerToZero n
    | n < 0 = n + 1
    | n > 0 = n - 1
```

In den obigen Beispielen gibt es nicht für alle möglichen Eingaben ein passendes Muster.
Der Compiler erkennt das und gibt eine Warnung aus.
Das ist ein sehr nützliches Merkmal von Haskell: Es hilft sicherzustellen, dass alle möglichen Pfade abgedeckt sind, um Laufzeitfehler zu vermeiden.
Man nennt das _Vollständigkeitsprüfung_.
Um die Warnung zu beheben, musst du alle Fälle behandeln.
Innerhalb von _Guards_ kannst du den Ausdruck `otherwise` als syntaktischen Zucker für `True` verwenden, um alle übrigen Muster abzufangen.

```haskell
closerToZero :: Int -> Int
closerToZero n
    | n < 0 = n + 1
    | n > 0 = n - 1
    | otherwise = 0
```

Der Mustervergleich prüft einen Wert von oben nach unten gegen jedes Muster, bis er ein passendes Muster findet und die zugehörige Logik ausführt.
**Die Reihenfolge der Muster ist wichtig!**
