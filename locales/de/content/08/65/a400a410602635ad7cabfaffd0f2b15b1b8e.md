# Konzepte, die für die Übung Makros benötigt werden

Es gibt viele Möglichkeiten, eine Übung zu lösen, aber ich schaue mir das [kanonische Beispiel](https://github.com/exercism/rust/blob/666c366fc0d39d9f6fd8e837facea8afe2153ae2/exercises/macros/example.rs) als meine wichtigste Referenz dafür an, welche Konzepte verwendet werden.

Wenn wir von der Liste der Konzepte sprechen, meinen wir [diese Liste](https://github.com/exercism/v3/blob/master/languages/rust/reference/README.md)

Beachte, dass sowohl bei Konzept- als auch bei Praxisübungen die Liste der vorausgesetzten Konzepte so klein wie möglich sein sollte. Das Ziel ist hier nicht, alle Konzepte aufzuzählen, die in allen möglichen Lösungsansätzen für das Problem verwendet werden könnten; es geht darum, die minimale Menge an Wissen aufzuzählen, mit der entschlossene Lernende das Problem voraussichtlich lösen könnten.

Beachte, dass diese Übung sehr wahrscheinlich eine Konzeptübung für das Konzept „Schreiben deklarativer Makros" wird.

## Benötigte Konzepte

### Bereits vorhanden

- Structs
- (Un-)Veränderlichkeit
- `Hashmap<K, V>`

### Sollten hinzugefügt werden

- Variablenzuweisung (Teil von `fundamentals`)
- Gültigkeitsbereich von Variablen / Namensräume (Teil von `fundamentals`)
- Methoden und zugehörige Funktionen (hängt von `structs` ab)
