# SQLite-spezifische Anleitung

In dieser Übung musst du die Spalte `result` der Tabelle `color_code` auf den richtigen Wert setzen. Der richtige Wert richtet sich nach der Farbe, die in der Spalte `color` steht.

## Tabellenschema

```sql
CREATE TABLE "color_code" ("color" TEXT, "result" INT);
```
