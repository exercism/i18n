# Über Grundlagen

Das Konzept Grundlagen führte [Go](https://golang.org) als statisch typisierte, kompilierte Programmiersprache ein.
Die Sprache wird wegen ihres früheren Domainnamens golang.org oft Golang genannt, aber der richtige Name ist Go.

Das Konzept Grundlagen stellt drei wichtige Sprachmerkmale vor: Pakete, Funktionen und Variablen.

## Pakete

Go-Anwendungen sind in Pakete organisiert.
Ein Paket ist eine Sammlung von Quelldateien im selben Verzeichnis.
Alle Quelldateien in einem Verzeichnis müssen denselben Paketnamen haben.
Üblicherweise ist der Paketname das letzte Verzeichnis im Importpfad.
Zum Beispiel beginnen die Dateien im [„math/rand“-Paket](https://golang.org/src/math/rand/) mit der Anweisung `package rand`.
Wenn ein Paket importiert wird, können nur Entitäten (Funktionen, Typen, Variablen, Konstanten), deren Namen mit einem Großbuchstaben beginnen, verwendet bzw. erreicht werden.
Der empfohlene Namensstil in Go ist, dass Bezeichner in `camelCase` geschrieben werden, außer denen, die paketübergreifend zugänglich sein sollen; diese sollten in `PascalCase` geschrieben werden.

```go
package lasagna
```

## Variablen

Go ist statisch typisiert, was bedeutet, dass alle Variablen zur Kompilierzeit [einen definierten Typ haben müssen](https://en.wikipedia.org/wiki/Type_system).

Variablen können definiert werden, indem du einen Typ explizit angibst:

```go
var explicit int // Explicitly typed
```

Du kannst auch einen Initialisierer verwenden; der Compiler weist der Variablen dann den Typ zu, der zum Typ des Initialisierers passt.

```go
implicit := 10   // Implicitly typed as an int
```

Sobald eine Variable deklariert ist, kannst du ihr mit dem Operator `=` Werte zuweisen.
Sobald eine Variable deklariert ist, kann ihr Typ nie geändert werden.

```go
count := 1 // Assign initial value
count = 2  // Update to new value

count = false // This throws a compiler error due to assigning a non `int` type
```

## Konstanten

Konstanten enthalten genau wie Variablen einen Datenwert, aber ihr Wert kann sich während der Ausführung des Programms nicht ändern.

Konstanten werden mit dem Schlüsselwort `const` definiert und können Zahlen, Zeichen, Strings oder boolesche Werte sein:

```go
const Age = 21 // Defines a numeric constant 'Age' with the value of 21
```

## Funktionen

Go-Funktionen akzeptieren null oder mehr Parameter.
Parameter müssen explizit typisiert sein; es gibt keine Typinferenz.

Werte werden mit dem Schlüsselwort `return` von Funktionen zurückgegeben.

Eine Funktion wird aufgerufen, indem du den Funktionsnamen angibst und für jeden Parameter der Funktion ein Argument übergibst.

Beachte, dass Go zwei Arten von Kommentaren unterstützt.
Einzeilige Kommentare werden mit `//` eingeleitet, mehrzeilige Kommentare stehen zwischen `/*` und `*/`.

```go
package greeting

// Hello is a public function.
func Hello (name string) string {
    return hi(name)
}

// hi is a private function.
func hi (name string) string {
    return "hi " + name
}
```
