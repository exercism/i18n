# Überblick

In Go können wir Werte mit den Gleichheits- und Ordnungsoperatoren vergleichen.
Es gibt 6 dieser Operatoren:

| Comparison        | Operator  |
| ------------------| --------- |
| gleich            | `==`      |
| ungleich          | `!=`      |
| kleiner           | `<`       |
| kleiner oder gleich | `<=`    |
| größer            | `>`       |
| größer oder gleich | `>=`     |

Das Ergebnis eines Vergleichs ist immer ein boolescher Wert:

```go
a := 3

a != 4 // true
a > 5  // false
```

## Gleichheitsoperatoren

Die Gleichheitsoperatoren `==` und `!=` prüfen, ob ein Wert gleich einem anderen ist oder nicht.
In Go können wir die Gleichheitsoperatoren auf die meisten Typen anwenden.
Hier sind einige typische Beispiele:

```go
2 == 3 // false, integer comparison

2.1 != 2.2 // true, float comparison 

"hello" == "hello" // true, string comparison

'a' != 'b' // true, rune/byte comparison
```

## Ordnungsoperatoren

Ordnungsoperatoren prüfen, ob ein Wert größer (`>`), größer oder gleich (`>=`), kleiner (`<`) oder kleiner oder gleich (`<=`) einem anderen Wert ist.
Diese Art von Vergleich gibt es für Zahlen, Bytes, Runes und Strings.
Beim Vergleich von Strings wird die Wörterbuchreihenfolge (auch lexikografische Reihenfolge genannt) verwendet.

```go
2 > 3 // false, integer comparison

1.2 < 1.3 // true, float comparison

'a' > 'b' // false, rune/byte comparison

"Hello" < "World" // true, string comparison
```
