# Einführung

Mit dem Kontrollfluss in Cairo kannst du den Ausführungspfad deiner Programme anhand von Bedingungen und Wiederholungen steuern.

## Bedingte Ausführung

Mit `if`-Ausdrücken führst du Code abhängig von Bedingungen aus:

```rust
let number = 42;
if number > 0 {
    println!("Positive number");
} else if number < 0 {
    println!("Negative number");  
} else {
    println!("Zero");
}
```

`if` ist ein Ausdruck und kann daher Werte zurückgeben:

```rust
let result = if condition { 5 } else { 10 };
```

## Schleifen

Mit `loop` wiederholst du Code.
Eine Schleife läuft endlos, bis du sie stoppst. Mit `break` brichst du die Schleife ab, sobald eine Bedingung erfüllt ist.

```rust
let mut counter = 0;
loop {
    if counter == 5 {
        break;
    }
    println!("Counter: {}", counter);
    counter += 1;
}
```

Schleifen können mit `break` Werte zurückgeben:

```rust
let result = loop {
    counter += 1;
    if counter == 10 {
        break counter * 2; // Returns 20
    }
};
```

Mit `continue` springst du zur nächsten Iteration:

```rust
let mut i = 0;
loop {
    i += 1;
    if i % 2 == 0 {
        continue; // Skip even numbers
    }
    if i > 10 {
        break;
    }
    println!("{}", i); // Only prints odd numbers
}
```
