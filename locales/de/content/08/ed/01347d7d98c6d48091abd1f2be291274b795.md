# Installation


## Hol dir GHCup

Der empfohlene Weg, Haskell-Tools zu installieren, führt über [GHCup][ghcup].

Mit GHCup kannst du deine installierten Compiler, Projekt- und Paketmanager sowie den Language Server verwalten.


## Stack installieren

Um die Übungen auf Exercism zu machen, brauchst du nur Stack.

Um Stack zu installieren, führe den Installationsbefehl oder das Installationsskript von GHCup aus.
Folge den Standardeinstellungen, gib aber an, dass du Stack ebenfalls installieren möchtest.

Hast du die Installation von Stack versehentlich übersprungen?
Kein Problem: Führe danach einfach `ghcup install stack` aus.

GHCup installiert

- **Einen Compiler** (GHC: der Glasgow Haskell Compiler)

  Genau genommen brauchst du ihn für Exercism nicht, aber er ist praktisch, wenn du außerhalb der Übungsverzeichnisse mit [GHCi][ghc-guide-ghci] herumspielen möchtest.

- **Cabal**

  Ein Projekt- und Paketmanager.
  Für Exercism brauchst du ihn nicht.

- **Stack**

  Der Projekt- und Paketmanager, den du für Exercism verwendest.
  Er sorgt dafür, dass du für jedes einzelne Projekt (jede Übung) den richtigen Compiler und die richtigen Bibliotheken hast.

Um zu prüfen, ob die Installation erfolgreich war, führe einen der beiden Befehle aus

- `ghcup list`: Bei Erfolg siehst du eine lange Liste von Tool-Versionen, in der Stack als installiert markiert ist
- `stack --version`: Bei Erfolg steht dort `Version 2.7.5, Git revision ...`


## Hol dir die richtige GHC-Version

Stack lädt GHC bei Bedarf automatisch herunter und installiert es.
Du kannst die Installation starten und überprüfen, indem du die folgenden Befehle in einem Terminal ausführst:

```bash
# Note: it only makes sense to run Stack
# inside projects, so navigate into an
# exercise directory first!
exercism download --exercise=hello-world --track=haskell
cd ~/Exercism/haskell/hello-world
stack ghc -- --version
```

Wenn die Ausgabe ungefähr so aussieht

```
The Glorious Glasgow Haskell Compilation System, version 8.8.4
```

dann ist GHC korrekt installiert.


## Richte deinen Editor für Haskell ein

Die Haskell-Unterstützung wird vom Haskell Language Server (HLS) bereitgestellt.
Die Sprachunterstützung ist nicht erforderlich, aber sehr zu empfehlen.


### Visual Studio Code (empfohlen)

Hol dir einfach die [Haskell-Erweiterung für Visual Studio Code][vscode-haskell].
Sie verwendet GHCup, um HLS automatisch zu installieren, danach ist alles eingerichtet.

**Hinweis:** Bei frisch heruntergeladenen Übungen kann HLS Probleme beim Starten haben.
Falls das passiert, führe `stack test` aus und starte den Language Server neu.


### Andere Editoren

Sieh dir die [HLS-Dokumentation zur Editor-Konfiguration][hls-editor-config] an.
Möglicherweise musst du HLS manuell installieren.
Führe dazu `ghcup install hls` aus.
