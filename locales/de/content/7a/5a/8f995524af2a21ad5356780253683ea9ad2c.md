Chapel ist eine Programmiersprache, die für produktives paralleles Rechnen in großem Maßstab entwickelt wurde.
Sie soll Forschenden und Fachleuten aus der Industrie ermöglichen, die Leistungsfähigkeit von High-Performance-Computing einfach zu nutzen, ohne dabei Produktivität und Lesbarkeit zu opfern.

### Hauptmerkmale

- **produktiv**: Der Code ist ähnlich lesbar und schreibbar wie Python
- **skalierbar**: läuft auf Laptops, Clustern, in der Cloud und auf HPC-Systemen
- **schnell**: Die Leistung hält mit C/C++ und MPI und OpenMP mit oder übertrifft sie
- **portabel**: lässt sich in praktisch jeder \*nix-Umgebung kompilieren und ausführen
- **Open Source**: auf GitHub gehostet, unter einer freizügigen Lizenz veröffentlicht.
