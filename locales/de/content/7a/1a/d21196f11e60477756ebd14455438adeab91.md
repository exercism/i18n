# Hinweise

## Allgemein

- Schau dir bei Bedarf das [Objekte-Konzept][concept-class-basics] noch einmal an, um deine Grundlagen aufzufrischen.
- Lies die Anleitung zur Positionierung der Parameter `x`, `y`, `width` und `height` sorgfältig. Sie lassen sich leicht verwechseln.

## 1. Definiere eine ProgramWindow-Klasse

- Denk daran, für diese Aufgabe die [Klassensyntax][php-class] zu verwenden.
- Definiere [Eigenschaften][php-properties], indem du sie der Klassendeklaration hinzufügst.

## 2. Definiere eine Konstruktorfunktion für die ProgramWindow-Klasse

- Prüfe, dass deine Konstruktorfunktion keine Argumente entgegennimmt.
- Prüfe, dass jede Eigenschaft auf den erwarteten Ganzzahl-Wert gesetzt wird.

## 3. Füge eine Methode hinzu, um die Größe des Fensters zu ändern

- Denk daran, für diese Aufgabe eine neue [Klasse][php-class] in der Datei `Size.php` zu verwenden.
  - Konventionell enthalten Dateien normalerweise nur eine einzige Klasse.
- Der Konstruktor von `Size` sollte Argumente für die Anfangswerte der [Eigenschaften][php-properties] der Klasse annehmen.
- Erstelle eine `resize`-Methode des Objekts `ProgramWindow`, um die Änderung mit einer Instanz von `Size` anzuwenden.

## 4. Füge eine Methode hinzu, um das Fenster zu verschieben

- Denk daran, für diese Aufgabe eine neue [Klasse][php-class] in der Datei `Position.php` zu verwenden.
  - Konventionell enthalten Dateien normalerweise nur eine einzige Klasse.
- Der Konstruktor von `Position` sollte Argumente für die Anfangswerte der [Eigenschaften][php-properties] der Klasse annehmen.
- Erstelle eine `move`-Methode des Objekts `ProgramWindow`, um die Änderung mit einer Instanz von `Position` anzuwenden.
