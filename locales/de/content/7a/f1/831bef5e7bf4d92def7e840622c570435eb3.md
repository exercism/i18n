# Einführung

Eine `list` in R ist eine geordnete Sammlung von Elementen, die sich in einigen Punkten von `vectors` unterscheidet:

- Die Elemente können verschiedene Typen haben (z. B. `numeric` mit `character` gemischt).
- Die Elemente können komplexe Strukturen sein (z. B. Vektoren, andere Listen usw.).
- Für den Zugriff auf Elemente gibt es eine etwas andere Syntax.

Analogien zu anderen Sprachen sind ungenau.
Eine R-`list` ähnelt in etwa einem Python-Wörterbuch, aber die `list` ist geordnet und kann über einen numerischen Index angesprochen werden.
Sie ähnelt in etwa einem C-`struct`, außer dass die `list` zur Laufzeit leicht erweitert werden kann.

## Listen erstellen

Elementen Namen zu geben (oft „Tags“ genannt) ist bei Listen üblicher als bei Vektoren:

```R
list(x = 5.3, y = 4.2, color = "blue")
$x
#> [1] 5.3

$y
#> [1] 4.2

$color
#> [1] "blue"
```

Tags sind jedoch optional, und R verwendet dann einfach Indexnummern:

```R
list(5.3, 4.2, "blue")
#> [[1]]
#> [1] 5.3

#> [[2]]
#> [1] 4.2

#> [[3]]
#> [1] "blue"
```

## Zugriff auf Listenelemente

Dafür gibt es drei Möglichkeiten, die jeweils in unterschiedlichen Kontexten nützlich sind.

### 1. Mit der `$tag`-Notation

Sehr verbreitet, wenn die Tag-Namen im Voraus bekannt sind.

```R
point <- list(x = 5.3, y = 4.2, color = "blue")
point$x
#> [1] 5.3
point$color
#> [1] "blue"
```

### 2. Mit der `[[tag]]`-Notation

Das hat den Vorteil, dass der Tag-Name zur Laufzeit gewählt werden kann.
Beachte die doppelten eckigen Klammern.

```R
want <- "y"
point[[want]] # same as point$y
#> [1] 4.2
```

### 3. Mit Positionsindex

Das funktioniert, egal ob die Liste Tags hat oder nicht.
Auch hier sind die eckigen Klammern doppelt.

```R
point[[3]] # same as point$color
#> [1] "blue"
```

## Elemente hinzufügen und löschen

Ganz einfach: Eine Zuweisung zu einem Element ändert es, wenn es existiert, oder fügt es ein, wenn es neu ist.

```R
point$color <- "red"
point$trust <- TRUE
str(point)
#> List of 4
#>  $ x    : num 5.3
#>  $ y    : num 4.2
#>  $ color: chr "red"
#>  $ trust: logi TRUE
```

Um zu löschen, weist du dem unerwünschten Element `NULL` zu.

```R
point$trust <- NULL
str(point)
#> List of 3
#>  $ x    : num 5.3
#>  $ y    : num 4.2
#>  $ color: chr "red"
```
