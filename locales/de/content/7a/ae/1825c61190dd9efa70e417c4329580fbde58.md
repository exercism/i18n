# Tests

So führst du die Testsuite aus:
```bash
tclsh exercise.test
```

## Übersprungene Tests

Eine Übung zu lösen heißt, alle ihre Tests zu bestehen. Standardmäßig führst du nur einen Test (den ersten) aus, wenn du die Tests ausführst. Das ist Absicht, denn so kannst du dich darauf konzentrieren, nur diesen einen Test zu bestehen. Sobald er bestanden ist, kannst du den nächsten Test aktivieren, indem du den `skip`-Befehl davor auskommentierst oder entfernst.

Alternativ kannst du alle Tests unabhängig davon ausführen, ob sie „übersprungen“ sind:
```bash
RUN_ALL=1 tclsh exercise.test
```
