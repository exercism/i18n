# Binär, Oktal und Hexadezimal

Binär, Oktal und Hexadezimal (_auch als Hex bekannt_) sind verschiedene [Zahlensysteme][numeral-systems] mit unterschiedlichen Basen.
Binär hat die Basis 2, Oktal die Basis 8 und Hexadezimal die Basis 16.
Normale Ganzzahlen haben in Crystal die Basis 10.
Binär, Oktal und Hexadezimal sind alles Darstellungen von Ganzzahlen.
Das bedeutet, dass sie positive und negative Zahlen (_einschließlich der Null_) ohne Brüche oder Nachkommastellen darstellen und alle Operationen unterstützen, die wir mit Ganzzahlen durchführen können.

## Binär

[Binär][binary] ist ein Zahlensystem zur Basis 2, das nur die Ziffern 0 und 1 verwendet.
Es stellt üblicherweise die Zustände 0 („aus“) und 1 („ein“) des elektrischen Flusses durch Transistoren und Schalter in Computern dar, ebenso wie die positiven und negativen Ladungen in magnetischen Speichermedien.
Binär kann alle Ganzzahlen darstellen, die zur Basis 10 verwendet werden.

Ein Ausschnitt aus dem System zur Basis 2 sieht so aus, obwohl es unendlich weitergeht und nicht bei 128 endet:

| 128      | 64       | 32       | 16       | 8        | 4        | 2        | 1        |
| -------- | -------- | -------- | -------- | -------- | -------- | -------- | -------- |
| 2 \*\* 7 | 2 \*\* 6 | 2 \*\* 5 | 2 \*\* 4 | 2 \*\* 3 | 2 \*\* 2 | 2 \*\* 1 | 2 \*\* 0 |

Wenn wir also die Zahl 6 darstellen wollen, wäre das binär: 110

| Stellenwert | 4   | 2   | 1   |
| ----------- | --- | --- | --- |
| Binärzahl   | 1   | 1   | 0   |

Und die Rechnung wäre: `4 + 2 + 0 = 6`

Ein weiteres Beispiel: 19

| Stellenwert | 16  | 8   | 4   | 2   | 1   |
| ----------- | --- | --- | --- | --- | --- |
| Binärzahl   | 1   | 0   | 0   | 1   | 1   |

Die Binärzahl wäre: 10011
Und die Rechnung wäre: `16 + 0 + 0 + 2 + 1 = 19`

## Binär in Crystal

In Crystal können wir Binärliterale mit dem Präfix `0b` darstellen.
Wenn wir `0b10011` schreiben, interpretiert Crystal es als Binärzahl und wandelt es in die Basis 10 um.

```crystal
0b10011
# => 19

typeof(0b10011)
# => Int32
```

Wenn du eine Zahl mit einem `0b`-Präfix schreibst, die nicht im Binärsystem ist, wird ein Kompilierfehler ausgelöst.

```crystal
0b10211
# => Error: unexpected token: "211"
```

### Rechnen mit Binärzahlen

Da Binärzahlen Ganzzahlen sind, können wir mit ihnen alle Operationen durchführen, die wir mit Ganzzahlen durchführen können.

```crystal
0b10011 + 0b10011
# => 38

0b10011 * 0b10011
# => 361

0b10011 / 3
# => 6.333333333333333
```

### Umwandlung in die Binärdarstellung und zurück

Crystal wandelt ein Binärliteral automatisch in einen `Int32` um.
Um einen `Int32` in eine Binärdarstellung umzuwandeln, verwendest du die Methode [`<int>.to_s(base)`][to_s] und setzt das Argument base auf 2.
Die Methode gibt eine String-Darstellung der Binärzahl zurück:

```crystal
19.to_s(2)
# => "10011"
```

Um eine String-Darstellung einer Binärzahl in eine Ganzzahl umzuwandeln, können wir die Methode [`<int>.to_i(base)`][to_i] verwenden und die Basis (2) als Argument übergeben:

```crystal
"10011".to_i(2)
# => 19
```

Wenn du die falsche Basis angibst (_oder eine ungültige Binärdarstellung_), wird ein `ArgumentError` ausgelöst:

```crystal
"011021".to_i(2)
# => Invalid Int32: "011021" (ArgumentError)
```

### Methoden für Binärzahlen

Es gibt bestimmte Methoden, die auf Ganzzahlen angewendet werden können, um Informationen über die Binärdarstellung der Zahl zu erhalten.

[`<int>.bit_length`][bit_length] gibt die Anzahl der Bits zurück, die benötigt werden, um die Zahl darzustellen:

```crystal
19.bit_length
# => 5
```

[`<int>.bit(index)`][bit] gibt das Bit am angegebenen Index zurück, vom rechten Rand aus gezählt (_niedrigstwertiges Bit_):

```crystal
19.bit(0)
# => 1

0b10011.bit(1)
# => 1
```

## Oktal

[Oktal][octal] ist ein Zahlensystem zur Basis 8.
Es verwendet die Ziffern 0, 1, 2, 3, 4, 5, 6 und 7.

In Crystal können wir Oktalzahlen mit dem Präfix `0o` darstellen.
Wie bei Binär wandelt Crystal eine Oktaldarstellung automatisch in einen `Int32` um.

```crystal
0o123
# => 83
```

Wenn du einer Zahl `0o` voranstellst, die nicht im Oktalsystem ist, wird ein Kompilierfehler ausgelöst.

### Umwandlung in die Oktaldarstellung und zurück

Wie bei Binär können wir die Methode [`<int>.to_s(base)`][to_s] verwenden, um einen `Int32` in eine Oktaldarstellung umzuwandeln.
Und wir können die Methode [`<int>.to_i(base)`][to_s] verwenden, um eine Oktaldarstellung in einen `Int32` umzuwandeln.

```crystal
83.to_s(8)
# => "123"

"123".to_i(8)
# => 83
```

Wie bei Binär wird ein `ArgumentError` ausgelöst, wenn du die falsche Basis angibst.

## Hexadezimal

[Hexadezimal][hexadecimal] ist ein Zahlensystem zur Basis 16.
Es verwendet die Ziffern 0 bis 9 und die Buchstaben A, B, C, D, E und F.
A ist 10, B ist 11, C ist 12, D ist 13, E ist 14 und F ist 15.

In Crystal können wir Hexadezimalzahlen mit dem Präfix `0x` darstellen.
Wie bei Binär und Oktal wandelt Crystal Hexadezimalliterale automatisch in `Int32` um.

```crystal
#=> 0x123
291
```

Wenn du einer Nicht-Hexadezimalzahl `0x` voranstellst, wird ein Kompilierfehler ausgelöst.

### Umwandlung in die Hexadezimaldarstellung und zurück

Wie bei Binär können wir die Methode [`<int>.to_s(base)`][to_i] verwenden, um einen `Int32` in eine Hexadezimaldarstellung umzuwandeln.
Und wir können die Methode [`<int>.to_i(base)`][to_s] verwenden, um eine Hexadezimaldarstellung in einen `Int32` umzuwandeln.

```crystal
291.to_s(16)
# => "123"

"123".to_i(16)
# => 291
```

Wie bei Binär und Oktal wird ein `ArgumentError` ausgelöst, wenn du die falsche Basis angibst.

## Genauigkeit

Wenn wir eine Zahl in eine String-Darstellung umwandeln, können wir die Genauigkeit der Zahl angeben.
Das bedeutet die **minimale** Anzahl an Ziffern, die zur Darstellung der Zahl verwendet wird.
Wenn die Zahl weniger Ziffern als die Genauigkeit hat, werden führende Nullen an die String-Darstellung angehängt.
Dazu übergibst du das Argument `precision` an die Methode [`<int>.to_s(<base>, precision: <value>)`][to_s].

```crystal
291.to_s(16, precision: 5)
# => "00123"

543.to_s(precision: 2)
# => "543"
```

## Großschreibung

Wenn wir eine Zahl in eine String-Darstellung umwandeln, können wir angeben, ob die Buchstaben im String großgeschrieben werden sollen.
Dazu übergibst du das Argument `upcase` an die Methode [`<int>.to_s(<base>, upcase: <value>)`][to_s].

```crystal
255.to_s(16, upcase: true)
# => "FF"

255.to_s(16, upcase: false)
# => "ff"
```
