# Hinweise

## Allgemein

- `n <iota>` erzeugt eine virtuelle Sequenz der Ganzzahlen
  `0, 1, …, n-1`.
- `map` (in [`sequences`][sequences]) führt deine Quotation für jedes
  Element aus und sammelt die Ergebnisse.
- `>string` (in [`strings`][strings]) wandelt eine Sequenz von
  Zeichencodes in einen String um.

## 1. Alphabet-Wimpelkette

- `CHAR: a` parst zur Ganzzahl `97`. Addierst du den Index `i`,
  erhältst du den Code für den `i`-ten Kleinbuchstaben.

## 2. Zähl-Wimpelkette

- `mod` (in [`math`][math]) gibt den Rest der
  Ganzzahldivision zurück.
- Die Zeichencodes für Ziffern sind aufeinanderfolgend (`CHAR: 0`,
  `CHAR: 1`, …). Daher wandelt `CHAR: 0 +` eine Ganzzahl in `0..9` in
  das passende Ziffernzeichen um.

## 3. Streifen-Wimpelkette

- `even?` (in [`math`][math]) ist `t` für gerade Ganzzahlen und sonst
  `f`.
- Innerhalb der `map`-Quotation wählt `if` anhand des Tests eines von
  zwei Zeichenliteralen aus.

## 4. Markierungs-Wimpelkette

- `5 mod zero?` ist `t` genau an den Positionen `0`, `5`, `10`, … .

## 5. Tal-Wimpelkette

- `-5 5 [a..b)` (in [`ranges`][ranges]) ist der halboffene Bereich
  `-5, -4, …, 4`.
- `abs` (in [`math`][math]) wandelt eine negative Ganzzahl in ihr
  positives Gegenstück um und lässt nicht-negative Ganzzahlen
  unverändert.
