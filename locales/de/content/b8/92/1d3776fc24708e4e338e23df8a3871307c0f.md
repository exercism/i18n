# Einführung

## Wahr und falsch

Wahre und falsche logische Zustände werden in Ruby mit `true` und `false` dargestellt.
Sie können entweder allein als Literale verwendet werden oder als Ergebnis logischer oder vergleichender Methoden.

```ruby
happy = true
sad = false

true && false
# => false

1 < 2
# => true
```

## _Truthy_ und _falsey_

Wenn Objekte in `if`-Anweisungen oder anderen booleschen Kontexten ausgewertet werden, werden alle Objekte als _truthy_ ausgewertet, **außer** `false` und `nil`.

## Kontrollfluss

_Truthy_- und _falsey_-Auswertungen sind im Zusammenhang mit Kontrollfluss nützlich.
Wie in prozeduralen Sprachen gibt es in Ruby ein `if`...`else`-Konstrukt, aber häufiger verwendest du vielleicht `if` als „bewachende" Anweisung, um die Auswertung eines Ausdrucks zu verändern.

```ruby
def falsey
  nil || false
end

def truthy
  not falsey
end

if truthy
  # this block is evaluated
end

if falsey
  # this block is not evaluated
else
  # this block is evaluated
end

1 + 1 if truthy
# this will evaluate and return 2

2 + 2 if falsey
# the numbers are not added because of the modifier, nil is returned
```

Ruby bietet `unless`, damit sich Code gut liest.
Zum Beispiel können wir statt `eat_desert if not too_full` auch `eat_desert unless too_full` schreiben.

```ruby
3 + 3 unless truthy
# the numbers are not added because of the modifier, nil is returned

4 + 4 unless falsey
# this will evaluate and return 8
```
