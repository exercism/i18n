# Hinweise

## 1. Karte im Deck finden

- Es gibt eine [eingebaute Methode][index], die das erste Element in der Sammlung findet, das die im Block angegebene Bedingung erfüllt, und deren Index zurückgibt, oder `nil`, falls kein Element gefunden wird.

## 2. Alle Zeichen großschreiben

- Es gibt eine [eingebaute Methode][map], um alle Elemente in der Sammlung umzuwandeln.
- Es gibt eine [eingebaute Methode][capitalize], um Wörter bei einem `String` großzuschreiben.

## 3. Die Stärke aller Karten berechnen

- Du kannst die [`sum`-Methode] verwenden, um die Gesamtstärke aller Karten zu berechnen.
- Die `sum`-Methode kann auch einen Block annehmen, um die Elemente vor dem Summieren umzuwandeln.

## 4. Eine Karte dekodieren

- Es gibt eine [eingebaute Methode][each_char_with_index], um mit einem Index über die Zeichen eines `String` zu iterieren.
