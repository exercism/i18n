# Überblick

[Ranges][range] repräsentieren ein Intervall zwischen zwei Werten.
Ranges werden häufig mit Typen wie `Int`, `String` und `Character` verwendet, um über Sequenzen zu iterieren, Collections zu zerschneiden oder zu prüfen, ob ein Wert innerhalb der Grenzen liegt.

Swift bietet zwei zentrale Range-Operatoren:

- **Geschlossener Range-Operator (`...`)**: Schließt sowohl den Start- als auch den Endwert ein (`1...5` enthält 1, 2, 3, 4 und 5).
- **Halboffener Range-Operator (`..<`)**: Schließt den Startwert ein, aber nicht den Endwert (`1..<5` enthält 1, 2, 3 und 4).

```swift
let closed = 1...5
let halfOpen = 1..<5
```

~~~~exercism/note
Wenn du eine Methode direkt auf einem Range-Literal aufrufst, setze den Range-Ausdruck in runde Klammern, damit der Compiler zuerst den Range auswertet:

```swift
(1...5).contains(3) // Returns true
// 1...5.contains(3) // Error: value of type 'Int' has no member 'contains'
```
~~~~

## Ein Range in ein Array umwandeln

Mit dem Initialisierer `Array(_:)` kannst du einen Range von Zahlen in ein `Array` umwandeln:

```swift
let range = 1...5
let numbers = Array(range)
// numbers is [1, 2, 3, 4, 5]
```

## Ein Array mit Ranges zerschneiden

Du kannst Ranges verwenden, um Teilabschnitte eines Arrays herauszuschneiden:

```swift
let array = [10, 20, 30, 40, 50]
let slice = array[1...3]
// slice contains [20, 30, 40]
```

## Eigenschaften und Methoden von Ranges

Häufige Operationen auf Ranges sind:

| Member                  | Beschreibung                                                | Beispiel                              |
| ----------------------- | ---------------------------------------------------------- | ------------------------------------ |
| `count`                 | Gibt die Anzahl der Elemente im Range zurück                | `(1...5).count` gibt `5` zurück          |
| [`contains(_:)`][contains] | Gibt `true` zurück, wenn der Range den angegebenen Wert enthält | `(1...5).contains(3)` gibt `true` zurück |

## Einseitige Ranges

Swift unterstützt auch einseitige (partielle) Ranges, bei denen du entweder den Start- oder den Endwert weglässt:

- `array[2...]`: Von Index 2 bis zum Ende der Collection.
- `array[...2]`: Vom Anfang der Collection bis einschließlich Index 2.
- `array[..<2]`: Vom Anfang der Collection bis vor Index 2.

## String- und Character-Ranges

Ranges lassen sich auch zwischen Characters oder Strings erstellen, die konform zu `Comparable` sind:

```swift
let letters = "a"..."z"
print(letters.contains("m")) // Prints true
print(letters.contains("A")) // Prints false
```
