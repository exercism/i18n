# Ranges

[Ranges][range] stellen ein Intervall zwischen zwei Werten dar.
Die häufigsten Typen, die Ranges unterstützen, sind `Int`, `Char` und `String`.
Du kannst sie für vieles verwenden, zum Beispiel um schnell eine Sammlung zu erstellen, Strings zu zerschneiden, zu prüfen, ob ein Wert in einem Range liegt, und für Iterationen.
Sie werden mit dem Range-Operator `..` oder `...` erstellt (inklusiv bzw. exklusiv).

```crystal
1..5  # A range containing 1, 2, 3, 4, 5
1...5 # A range containing 1, 2, 3, 4
```

Der Grund für zwei Range-Operatoren ist, dass du Ranges erstellen kannst, die den Endwert einschließen oder ausschließen.
Das ist zum Beispiel nützlich, wenn du mit nullbasierten Indizes arbeitest.

Ranges kannst du auch mit dem `Range`-Initialisierer erstellen.

```crystal
Range.new(1, 5) # A range containing 1, 2, 3, 4, 5
```

~~~~exercism/note
Wenn du in Crystal mit den Range-Operatoren `..` oder `...` einen Range erstellst und eine Methode auf dem Range aufrufen möchtest, musst du den Range in runde Klammern setzen.
Sonst wird die Methode nämlich auf dem zweiten Argument des Range-Operators aufgerufen.

```crystal
(1..5).size # => 5
1..5.size # => Error: undefined method 'size' for Int32
```
~~~~

## Teilstrings

Wenn du einen String zerschneiden möchtest, kannst du den Range-Operator verwenden, um einen Teilstring zu erhalten.
Dazu erstellst du einen Range mit dem Start- und Endindex des Teilstrings.

```crystal
"Hello World"[0..4] # => "Hello"
"Hello World"[6..10] # => "World"
```

Du kannst auch negative Indizes verwenden, um den Teilstring vom Ende des Strings zu erhalten.

```crystal
"Hello World"[-5..-1] # => "World"
"Hello World"[6..-4] # => "Wo"
```

## Range-Methoden

Ranges haben eine Reihe von Methoden, mit denen du arbeiten kannst.
Mit diesen Methoden kannst du zum Beispiel die Summe aller Werte im Range berechnen oder prüfen, ob der Range einen Wert enthält.

| Methode                 | Beschreibung                                                            | Beispiel                         |
|-------------------------|-------------------------------------------------------------------------|---------------------------------|
| [`sum`][sum]            | Gibt die Summe aller Werte im Range zurück                              | `(1..5).sum # => 15`            |
| [`size`][size]          | Gibt die Größe des Ranges zurück                                        | `(1..5).size # => 5`            |
| [`includes?`][indludes] | Gibt `true` zurück, wenn der Range den gegebenen Wert enthält, sonst `false` | `(1..5).includes?(3) # => true` |

## Endlose und anfangslose Ranges

Ein Range kann endlos und anfangslos sein.
Bei einem endlosen oder anfangslosen Range ist der Start- oder Endwert `nil`. Beim Definieren des Ranges kannst du `nil` aber weglassen.

Anfangslose und endlose Ranges sind nützlich, wenn du zum Beispiel einen String von Anfang an oder bis zum Ende zerschneiden möchtest.

```crystal
"Hello World"[0..] # => "Hello World"
"Hello World"[4..] # => "o World"
"Hello World"[..5] # => "Hello"
```

~~~~exercism/caution
Wenn ein endloser Range nicht auf eine Sammlung angewendet wird, kann er eine endlose Sequenz erzeugen. Sei also vorsichtig.
~~~~

## Char-Ranges

Chars können in Ranges verwendet werden und ermöglichen es dir, ein Intervall von Chars zwischen zwei Chars zu erhalten.
Das ist zum Beispiel praktisch, wenn du das Alphabet erhalten möchtest.

```crystal
'a'..'z' # A range containing ['a', 'b', 'c', ..., 'z']
```

## String-Ranges

Strings können ebenfalls in Ranges verwendet werden. So kannst du ein Intervall von Strings zwischen zwei Strings erhalten.
Das Verhalten unterscheidet sich jedoch leicht von dem von `Char`, wenn mehrere Zeichen in einem String-Range verwendet werden.
Bei komplexeren String-Ranges kann das Verhalten verwirrend werden. Sei also vorsichtig.

```crystal
("aa".."az") # A range containing ["aa", "ab", "ac", ..., "az"]
```
