# Ergänzung zu den Anweisungen

## Hinweise

Das Sgf-Modul sollte ein parseSgf-Modul mit der folgenden Signatur exportieren:

```haskell
parseSgf :: Text -> Maybe (Tree (Map Text [Text]))
```

Vielleicht hilft es dir, die folgenden Definitionen für SgfTree
und SgfNode zu kopieren:

```haskell
-- | A tree of nodes.
type SgfTree = Tree SgfNode

-- | A node is a property list, each key can only occur once.
-- Keys may have multiple values associated with them.
type SgfNode = Map Text [Text]
```

Die Bibliothek parsec ist Teil der Haskell Platform. Setze sie zu
deinem Vorteil ein.
