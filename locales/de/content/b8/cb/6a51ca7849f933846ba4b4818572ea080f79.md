# Ergänzung der Anweisungen

## Hinweise

Du kannst dir diese Datenstruktur als einen [`Rose Tree`](https://en.wikipedia.org/wiki/Rose_tree) vorstellen.
Du bekommst einen Datentyp `'a tree`, der diese Datenstruktur repräsentiert.

**Anmerkungen**

- In dieser Übung steht `Empty` für `null`
- Die verschachtelte Liste wird durch `List [...]` dargestellt.
- Das Eingabebeispiel wird durch `List [Elem 1, List [Elem 2, Elem 3, Empty, Elem 4], List [Empty], Elem 5]` dargestellt
