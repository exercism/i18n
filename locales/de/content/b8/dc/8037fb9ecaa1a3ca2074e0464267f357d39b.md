# Klassen mit Zustand

```sather
class SCOREBOARD is

   attr home_team, away_team : STR;
   attr home_score, away_score : INT;

   create(home, away : STR) : SAME is
      board ::= new;
      board.home_team := home;
      board.away_team := away;
      return board;
   end;

   home_goal is home_score := home_score + 1; end;

end; -- class SCOREBOARD
```

## attr, readonly attr, private attr

| Geschrieben | Von außen lesbar | Von außen änderbar |
| --- | --- | --- |
| `attr x : INT` | ja | ja |
| `readonly attr x : INT` | ja | nein |
| `private attr x : INT` | nein | nein |

`readonly` ist die Variante, zu der du standardmäßig greifen solltest. Sie lässt
jeden den Spielstand sehen und besteht darauf, dass Änderungen über `home_goal`
laufen, denn dort stehen die Regeln zum Punkten.

## create und new

`new` erzeugt ein Objekt dieser Klasse, bei dem jedes Attribut leer ist. Es darf
nur innerhalb der Klasse verwendet werden.

`create` ist eine gewöhnliche Routine mit einem festgelegten Namen: `#C(args)`
ist genau `C::create(args)`. Eine Klasse kann mehrere haben, die sich durch ihre
Argumente unterscheiden, und eine Klasse ohne eine solche lässt sich mit `#`
einfach nicht erzeugen.

## SAME

`SAME` steht für die Klasse, in der es geschrieben wird. In `create` ist es der
Rückgabetyp; es dient auch in einem Argument, und es ist das, was eine geerbte
Routine von der erbenden Klasse sprechen lässt statt von der, aus der sie
stammt.

## Routinen ohne Rückgabetyp

```sather
   home_goal is
      home_score := home_score + 1;
   end;
```

Kein `:` und kein Typ. Eine solche Routine wird als Anweisung aufgerufen und
kann nicht in einem Ausdruck vorkommen. Sie ist das Zeichen dafür, dass es beim
Aufruf um die Änderung geht, die er bewirkt.

## self

Innerhalb einer Routine ist `self` das Objekt, auf dem sie aufgerufen wurde. Es
wird selten geschrieben, weil ein Attribut oder eine Routine, die allein genannt
wird, bereits die von `self` meint. Es wird gebraucht, wenn das Objekt
weitergegeben oder zurückgegeben werden muss:

```sather
   with_goal : SAME is
      home_score := home_score + 1;
      return self;
   end;
```

`self`, `new`, `void`, `result`, `value` und `out` sind alles Wörter, die Sather
belegt hat, und keines davon kannst du als eigenen Namen verwenden.

## Referenz, kein Wert

Auf ein Objekt greifst du über eine Referenz zu. Zwei Namen für dieselbe
Anzeigetafel sehen denselben Spielstand:

```sather
   a ::= #SCOREBOARD("Vixens", "Magpies");
   b ::= a;         -- not a copy
   b.home_goal;
   a.home_score     -- 1
```

`immutable class` ist später der Weg, um das andere Verhalten zu bekommen.
