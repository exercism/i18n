# Über

Manchmal brauchst du den Aufwand nicht, ein Objekt mit Zustand zu erstellen.
In solchen Fällen kannst du ein `module` verwenden.

Ein Modul ist einer Klasse sehr ähnlich (tatsächlich ist `Module` in der Objekthierarchie das Elternelement von `Classes`). Der wichtigste Unterschied: Statt Instanzmethoden verwenden wir Klassenmethoden.
Klassenmethoden beginnen mit `self.` und werden direkt auf einem Modul aufgerufen.

Zum Beispiel:

```ruby
module Speaker
  def self.echo(something)
    "#{something} ... #{something}"
  end
end

Speaker.echo("Hello")   #=> "Hello ... Hello"
```
