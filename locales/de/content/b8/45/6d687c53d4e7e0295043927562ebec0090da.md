# Einführung

Das [`strings`-Paket](https://pkg.go.dev/strings) bietet Funktionen für die Arbeit mit Strings.
Unten findest du einige der Funktionen aus dem Paket; schau in die Dokumentation, um die restlichen zu sehen!

| Rolle                  | Funktion                                            | Zweck                                                             |
| --------------------- | --------------------------------------------------- | ------------------------------------------------------------------- |
| Schreibweise umwandeln | [ToLower](https://pkg.go.dev/strings#ToLower)       | Wandelt einen String in Kleinbuchstaben um                                      |
| Schreibweise umwandeln | [ToUpper](https://pkg.go.dev/strings#ToUpper)       | Wandelt einen String in Großbuchstaben um                                      |
| Suchen             | [Contains](https://pkg.go.dev/strings#Contains)     | Prüft, ob ein String einen bestimmten Teilstring enthält                     |
| Suchen             | [Count](https://pkg.go.dev/strings#Count)           | Zählt nicht überlappende Vorkommen eines Teilstrings                    |
| Suchen             | [HasPrefix](https://pkg.go.dev/strings#HasPrefix)   | Prüft, ob ein String mit einem bestimmten Teilstring beginnt                  |
| Suchen             | [HasSuffix](https://pkg.go.dev/strings#HasSuffix)   | Prüft, ob ein String mit einem bestimmten Teilstring endet                    |
| Suchen             | [Index](https://pkg.go.dev/strings#Index)           | Gibt den Index des ersten Vorkommens eines Teilstrings zurück, oder -1      |
| Bearbeiten             | [Replace](https://pkg.go.dev/strings#Replace)       | Ersetzt bis zu n Vorkommen eines Teilstrings                          |
| Bearbeiten             | [ReplaceAll](https://pkg.go.dev/strings#ReplaceAll) | Ersetzt alle Vorkommen eines Teilstrings                              |
| Bearbeiten             | [TrimSpace](https://pkg.go.dev/strings#TrimSpace)   | Entfernt führende und nachfolgende Leerzeichen                              |
| Aufteilen oder Zusammenfügen  | [Fields](https://pkg.go.dev/strings#Fields)         | Teilt einen String an Leerzeichen in Wörter auf                             |
| Aufteilen oder Zusammenfügen  | [FieldsSeq](https://pkg.go.dev/strings#FieldsSeq)   | Gibt jedes Wort einzeln zurück                                         |
| Aufteilen oder Zusammenfügen  | [Join](https://pkg.go.dev/strings#Join)             | Fügt einen Slice von Strings mit einem Trennzeichen zusammen                            |
| Aufteilen oder Zusammenfügen  | [Split](https://pkg.go.dev/strings#Split)           | Teilt einen String an einem Trennzeichen in Teile auf                            |
| Aufteilen oder Zusammenfügen  | [SplitSeq](https://pkg.go.dev/strings#SplitSeq)     | Gibt jeden Teil einzeln zurück                                         |

```go
import (
    "fmt"
    "strings"
)

// Case conversion
strings.ToLower("Gopher")              // "gopher"
strings.ToUpper("Gopher")              // "GOPHER"

// Searching
strings.Contains("Apple", "le")        // true
strings.Index("Apple", "le")           // 3
strings.Index("Apple", "xyz")          // -1
strings.Count("test", "t")             // 2
strings.HasPrefix("Gopher", "Go")      // true
strings.HasSuffix("Gopher", "er")      // true

// Modifying
strings.TrimSpace("  hello  ")         // "hello"
strings.Replace("aabbcc", "b", "x", 1) // "aaxbcc"
strings.ReplaceAll("aabbcc", "b", "x") // "aaxxcc"

// Splitting or Joining
strings.Fields("  a b\tc  ")               // []string{"a", "b", "c"}
strings.Split("a,b,c", ",")                // []string{"a", "b", "c"}
strings.Join([]string{"a", "b", "c"}, ",") // "a,b,c"

// You do not need to worry about this range syntax yet.
// It is covered later in the range iteration concept.
for word := range strings.FieldsSeq("  a b\tc  ") {
    fmt.Println(word)
}
// Output:
// a
// b
// c

for part := range strings.SplitSeq("a,b,c", ",") {
    fmt.Println(part)
}
// Output:
// a
// b
// c
```
