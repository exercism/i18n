# Anleitung

Optische Zeichenerkennung, kurz OCR (von englisch *Optical Character Recognition*), ist Software, die Bilder von Text in maschinenlesbaren Text umwandelt.
Wenn du ein Raster aus Zeichen bekommst, das einige Ziffern darstellt, wandle das Raster in einen String aus Ziffern um.
Wenn das Raster mehrere Zeilen von Zellen hat, sollten die Zeilen in der Ausgabe mit einem `","` getrennt werden.

- Das Raster besteht aus einer oder mehreren Zeilen von Zellen.
- Jede Zeile des Rasters besteht aus einer oder mehreren Zellen.
- Jede Zelle ist drei Spalten breit und vier Zeilen hoch (3x4) und stellt eine Ziffer dar.
- Ziffern werden mit senkrechten Strichen (`"|"`), Unterstrichen (`"_"`) und Leerzeichen (`" "`) gezeichnet.

## Randfälle

- Wenn die Eingabe keine gültige Größe hat, sollte dein Programm anzeigen, dass ein Fehler vorliegt.
- Wenn die Eingabe die richtige Größe hat, aber eine Zelle nicht erkennbar ist, sollte dein Programm für dieses Zeichen ein `"?"` ausgeben.

## Beispiele

Die folgende Eingabe (ohne die Kommentare) wird in `"1234567890"` umgewandelt.

```text
      _  _     _  _  _  _  _  _  #
    | _| _||_||_ |_   ||_||_|| | # Decimal numbers.
    ||_  _|  | _||_|  ||_| _||_| #
                                 # The fourth line is always blank,
```

Die folgende Eingabe wird in `"123,456,789"` umgewandelt.
