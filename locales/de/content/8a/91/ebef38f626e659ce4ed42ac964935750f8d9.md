# Einführung

Diese Übung baut auf der Ganzzahl-Arithmetik aus [Leahs leckere Lasagne][lasagna] auf. Hier arbeitest du mit Gleitkommazahlen und lernst, das passende Divisionswort zu wählen.

## Ganzzahlen und Gleitkommazahlen

Factor unterscheidet Ganzzahlen (`1`, `42`, `1_000_000`) von Gleitkommazahlen (`1.0`, `3.14`, `6.02e23`). Wenn du in einer Berechnung eine Ganzzahl und eine Gleitkommazahl mischst, ist das Ergebnis eine Gleitkommazahl:

```factor
2 3 + .      ! => 5
2 3.0 + .    ! => 5.0
```

Du kannst Unterstriche in eine Zahl schreiben, um die Ziffern zu gruppieren, etwa `1_000_000`. Factor ignoriert sie einfach.

## Divisionswörter

Factor hat eigene Divisionswörter. Sie alle gehören zum Vokabular [`math`][math].

```
/    ( x y -- x/y )    ! exact: ratio for two integers, float if either is a float
/f   ( x y -- f   )    ! always a float
/i   ( x y -- q   )    ! integer division (truncates toward zero)
mod  ( x y -- r   )    ! remainder
/mod ( x y -- q r )    ! quotient and remainder together
```

```factor
1 2 / .        ! => 1/2     (a proper ratio)
16 3 / .       ! => 5+1/3   (an improper ratio, printed as a mixed numeral)
16 3 /f .      ! => 5.333333333333333
16 3 /i .      ! => 5      (truncated)
16 3 mod .     ! => 1
16 3 /mod .s   ! quotient and remainder in one pass
! => 5
! => 1
16.0 3 / .     ! => 5.333333333333333
```

`/` liefert bei zwei Ganzzahlen einen `ratio` (Factors exakter rationaler Typ) oder einen `float`, wenn einer der Eingabewerte eine Gleitkommazahl ist. `/f` erzwingt ein Gleitkommaergebnis, auch bei zwei Ganzzahlen. `/i` schneidet immer in Richtung null ab.

## Prüfen

Zahlenprädikate aus [`math`][math], [`math.functions`][math.functions] und [`math.primes`][math.primes]:

```
zero?    ( x       -- ? )
even?    ( x       -- ? )
odd?     ( x       -- ? )
prime?   ( x       -- ? )
divisor? ( m n     -- ? )    ! true when n divides m
integer? ( x       -- ? )    ! true for ints (fixnum or bignum)
float?   ( x       -- ? )    ! true for floats
number?  ( x       -- ? )    ! true for any numeric kind
```

```factor
0 zero? .            ! => t
0.0 zero? .          ! => t
3 zero? .            ! => f

4 even? .            ! => t
7 even? .            ! => f
7 odd? .             ! => t

7 prime? .           ! => t
9 prime? .           ! => f

15 5 divisor? .      ! => t   (5 divides 15)
15 4 divisor? .      ! => f
```

## Gleitkommazahl zu Ganzzahl

`floor`, `ceiling` und `round` aus dem Vokabular [`math.functions`][math.functions] geben alle eine Gleitkommazahl zurück (`3.0`, nicht `3`). Um eine echte Ganzzahl zu bekommen, hängst du `>integer` an:

```factor
3.7 floor >integer .       ! => 3
3.2 ceiling >integer .     ! => 4
```

## Potenzen und Betrag

`sq`, `^` und `abs` (in [`math.functions`][math.functions]) berechnen Quadrate, beliebige Potenzen und Beträge:

```
sq  ( x   -- x*x )
^   ( x y -- x^y )
abs ( x   -- |x| )
```

```factor
5 sq .          ! => 25
2 10 ^ .        ! => 1024
2 0.5 ^ .       ! => 1.4142135623730951
-7 abs .        ! => 7
3 abs .         ! => 3
```

## Minimum und Maximum

`min ( x y -- z )` und `max ( x y -- z )` (in [`math.order`][math.order]) geben die kleinere bzw. größere von zwei Zahlen zurück:

```factor
3 7 min .       ! => 3
3 7 max .       ! => 7
```

Am häufigsten werden sie zum *Begrenzen* verwendet: Du nagelst einen Wert mit `max` auf eine Untergrenze fest (zum Beispiel hält `0 max` einen Wert nicht-negativ) oder mit `min` auf eine Obergrenze.

## Vergleichsprädikate

`math.order` bietet außerdem `before?`, `after?`, `before=?` und `after=?`: Vergleichsprädikate, die mit jedem Typ arbeiten, der eine Ordnung hat, also mit Zahlen, Strings und Zeichen:

```
before?  ( obj1 obj2 -- ? )   ! obj1 <  obj2
before=? ( obj1 obj2 -- ? )   ! obj1 <= obj2
after?   ( obj1 obj2 -- ? )   ! obj1 >  obj2
after=?  ( obj1 obj2 -- ? )   ! obj1 >= obj2
```

Nutze sie anstelle von `<`/`<=`, wenn es sich bei den Werten um Strings handeln könnte, denn die arithmetischen Operatoren sind nicht für Strings definiert.
