# Über

Um Logik wiederholt auszuführen, kannst du Schleifen verwenden. Wenn der Code in einer Schleife immer mindestens einmal ausgeführt werden soll, kannst du eine `do`/`while`-Schleife verwenden:

```csharp
int x = 0;

do
{
    x = GetX();
    // do something with x
}
while (x != 0);
```

Sie wird seltener verwendet als eine `while`-Schleife, führt aber in manchen Fällen zu Code, der natürlicher aussieht.
