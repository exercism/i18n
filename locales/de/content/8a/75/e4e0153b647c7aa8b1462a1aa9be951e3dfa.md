# Über

Die bedingten Anweisungen in Factor nehmen alle **Quotations** als ihre Zweige: Code in eckigen Klammern, `[ ... ]`, der als Wert auf den Stack gelegt wird, statt ausgeführt zu werden, bis die bedingte Anweisung ihn auswählt. (Quotations selbst werden in einer späteren Übung ausführlich behandelt.)

Die drei grundlegenden findest du in `kernel`:

```
if      ( ? then-quot else-quot -- )
when    ( ? quot -- )
unless  ( ? quot -- )
```

Zwei mit Sternchen versehene Varianten behandeln den booleschen Wert als einen Wert, den man verwenden kann, wenn er truthy ist: das kanonische Paar „Wert-oder-`f`“:

```
if*     ( ? true false -- )    ! truthy: true called WITH value
unless* ( ? false      -- )    ! falsy: false runs and pushes default
```

```factor
: abs   ( x -- y ) dup 0 < [ neg ] [ ] if ;
: shout ( s -- )   dup empty? [ drop ] [ >upper print ] if ;
```

Für mehr als zwei Zweige durchläuft `cond` (in `combinators`) ein Array aus `{ predicate body }`-Paaren und führt den Code des ersten Prädikats aus, das zutrifft. Das übliche Muster verwendet in jedem Prädikat `dup`, damit der Eingabewert erhalten bleibt, und der Code beginnt mit einem `drop`, um ihn zu verwerfen, bevor das Ergebnis auf den Stack gelegt wird:

```factor
{
    { [ dup 0 <  ] [ drop "negative" ] }
    { [ dup 0 =  ] [ drop "zero"     ] }
    [ drop "positive" ]
} cond
```

Ein abschließender Eintrag ohne Prädikat ist der Standardzweig.
