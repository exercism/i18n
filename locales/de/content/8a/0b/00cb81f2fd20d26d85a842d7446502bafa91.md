# Einführung

Wie viele andere Sprachen kennt auch Common Lisp Ganzzahlen.
Das sind ganze Zahlen ohne Dezimalpunkt (wie `-6`, `0`, `25`, `1234` usw.).

Common Lisp setzt keine Grenzen für die Größe von Ganzzahlen.
Ganzzahlen können beliebig groß sein (oder klein, wenn sie negativ sind).

Wenn du nur mit ganzen Zahlen arbeitest, solltest du im Allgemeinen Ganzzahlen bevorzugen, denn sie leiden nicht unter demselben Genauigkeitsverlust wie Gleitkommazahlen bei vielen Berechnungen.
