# Guards auf Funktionsebene verwenden

[comment]: # (Dieser Fehler wird ausgelöst, wenn die Lösung Guards verwendet, aber nicht in der Funktionsklausel)

Verwende [Guards](https://hexdocs.pm/elixir/master/guards.html) in der Funktionsklausel, damit `two_fer/1` keinen Code mit nicht-binären Eingaben ausführt.

```elixir
def hello(what) when is_binary(what) do
  "Hello, #{what}!"
end
```

Wenn eine Funktion mit Argumenten aufgerufen wird, die zu keiner der angegebenen Klauseln passen, wird ein `FunctionClauseError` ausgelöst.

```elixir
hello(123)

# => ** (FunctionClauseError) no function clause matching in hello/1
#
#    The following arguments were given to Foo.hello/1:
#
#    # 1
#    123
```
