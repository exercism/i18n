# Tests

Jede Übung enthält eine Testdatei.
Führe die Tests mit dem Programm `bats` aus.

```bash
bats hello_world.bats
```

Wenn du beim lokalen Ausführen der Tests Debug-Ausgaben ausgeben möchtest, schau dir [Lokales Debugging][debugging] an.

`bats` muss zuerst installiert werden.
Auf der Seite [Tests im Bash-Track][tests] findest du Anleitungen, wie du `bats` für dein System installierst.

[tests]: https://exercism.org/docs/tracks/bash/tests
[debugging]: https://exercism.org/docs/tracks/bash/debugging

## Hilfe zu assert-Funktionen

Die Tests verwenden Funktionen aus der Bibliothek [bats-assert][bats-assert].
Dort findest du Hilfe zu den verschiedenen `assert*`-Funktionen.

[bats-assert]: https://github.com/bats-core/bats-assert

## Übersprungene Tests

Eine Übung zu lösen bedeutet, alle ihre Tests zu bestehen.
Standardmäßig wird nur ein Test (der erste) ausgeführt, wenn du die Tests laufen lässt.
Das ist Absicht, denn so kannst du dich ganz darauf konzentrieren, diesen einen Test zu bestehen.
Sobald er besteht, kannst du den nächsten Test aktivieren, indem du die nächste Annotation auskommentierst oder entfernst:

```bash
[[ $BATS_RUN_SKIPPED == true ]] || skip
```

## Überspringen aufheben

Um alle Tests auszuführen, auch die mit `skip`-Annotationen, kannst du Folgendes ausführen:

```bash
BATS_RUN_SKIPPED=true bats exercise_name.bats
```

Praktisch kann es sein, eine Wrapper-Funktion zu verwenden, um Tipparbeit zu sparen:

```bash
bats() {
    BATS_RUN_SKIPPED=true command bats *.bats
}
```

Dann genügt zum Ausführen der Tests:

```bash
bats
```
