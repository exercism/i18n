# Einführung

Common Lisp hat viele verschiedene Gleichheitsprädikate.
Das unterscheidet sich von anderen Programmiersprachen, die vielleicht nur ein oder zwei haben (zum Beispiel `==` und `===`).
Einige dieser Prädikate in Common Lisp sind spezifisch für bestimmte Typen, andere sind generisch.
Um Letztere geht es hier.

Es gibt vier generische Gleichheitsprädikate, und sie unterscheiden sich darin, wie streng sie sind, wenn es darum geht, was sie als „gleich“ betrachten.
Von der strengsten zur am wenigsten strengen sind das: `eq`, `eql`, `equal` und `equalp`.

Eine kurze Sammlung von Definitionen (ein paar Details lassen wir weg) sieht so aus:

- `eq`: definiert Gleichheit als: die beiden Objekte sind identisch.
  _z. B._:

```lisp
(eq 'a 'a)                 ; => T
(eq (list 1 2) (list 1 2)) ; => NIL
```

- `eql`: definiert Gleichheit als: zwei Zahlen haben denselben Typ und denselben Wert, zwei Zeichen sind gleich, oder, für alles andere, dass sie `eq` sind.
  _z. B._:

```lisp
(eql 1 1)     ; => T
(eql #\a #\a) ; => T
(eql 1 1.0)   ; => NIL
(eql #\a #\A) ; => NIL
```

- `equal`: definiert Gleichheit als: zwei Listen sind `equal`, wenn auch jedes Element `equal` ist; zwei Strings sind `equal`, wenn jedes Element `eql` ist; zwei Arrays sind `equal`, wenn sie `eq` sind; alles andere ist `equal`, wenn es `eql` ist.
  _z. B._:

```lisp
(equal (list 1 2) (list 1 2)) ; => T
(equal #(1 2) #(1 2))         ; => NIL
(equal "foo" "foo")           ; => T
```

- `equalp`: definiert Gleichheit als: Strings und Zeichen werden ohne Beachtung der Groß- und Kleinschreibung verglichen; Zahlen werden mit einer gewissen Typumwandlung verglichen; Listen und Arrays sind `equalp`, wenn jedes Element ebenfalls `equalp` ist, Strukturen, wenn sie denselben Typ haben und alle Slots `equalp` sind, und Hash-Tabellen, wenn ihre Schlüssel und Werte `equalp` sind
  _z. B._:

```lisp
(equalp "foo" "FoO")                          ; => T
(equalp 3 3.0)                                ; => T
(equalp (make-a-structure :slot1 1 :slot2 2) 
        (make-a-structure :slot1 1 :slot2 2)) ; => T
```
