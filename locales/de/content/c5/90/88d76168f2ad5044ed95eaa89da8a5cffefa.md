# Anleitung

Eine Schule in deiner Nähe hat eine sehr aktive Schülervereinigung.
Die Schülervereinigung wird von einem Präsidenten geleitet, und alle 2 Jahre
finden Wahlen statt, um einen neuen Präsidenten zu wählen.

Bei der diesjährigen Wahl wurde entschieden, dass ein neues digitales System zum Auszählen der Stimmen benötigt wird.
Die Schule braucht deine Hilfe beim Aufbau dieses neuen Systems.

## 1. Erstelle einen Stimmenzähler

Eines der ersten Dinge, die das neue Wahlsystem braucht, ist ein Stimmenzähler.
Dieser Zähler ist eine Möglichkeit, die Stimmen eines bestimmten Kandidaten im Blick zu behalten.

Erstelle eine Funktion `NewVoteCounter`, die die Anzahl der anfänglichen Stimmen für einen Kandidaten entgegennimmt und einen Zeiger auf einen `int` zurückgibt, der mit der angegebenen Anzahl anfänglicher Stimmen initialisiert ist.

```go
var initialVotes int
initialVotes = 2

var counter *int
counter = NewVoteCounter(initialVotes)
*counter == initialVotes // true
```

## 2. Ermittle die Anzahl der Stimmen aus einem Zähler

Jetzt hast du eine Möglichkeit, neue Zähler zu erstellen! Aber jetzt stellst du fest, dass das neue System auch eine Möglichkeit braucht, die Anzahl der Stimmen aus einem Zähler zu ermitteln.

Erstelle eine Funktion `VoteCount`, die einen Zähler (`*int`) als Argument entgegennimmt und die Anzahl der Stimmen im Zähler zurückgibt.
Wenn der Zähler `nil` ist, solltest du davon ausgehen, dass der Zähler keine Stimmen hat:

```go
var votes int
votes = 3

var voteCounter *int
voteCounter = &votes

VoteCount(voteCounter)
// => 3

var nilVoteCounter *int
VoteCount(nilVoteCounter)
// => 0
```

## 3. Erhöhe die Stimmen eines Zählers

Endlich ist es Zeit, die Stimmen auszuzählen! Jetzt brauchst du eine Möglichkeit, die Stimmen in einem Zähler zu erhöhen.

Erstelle eine Funktion `IncrementVoteCount`, die einen Zähler (`*int`) als Argument und eine Anzahl von Stimmen entgegennimmt und den Zähler um diese Anzahl von Stimmen erhöht.
Du kannst davon ausgehen, dass der übergebene Zeiger nie `nil` ist.

```go
var votes int
votes = 3

var voteCounter *int
voteCounter = &votes

IncrementVoteCount(voteCounter, 2)

votes == 5          // true
*voteCounter == 5   // true
```

## 4. Erstelle die Wahlergebnisse

Da nun alle Stimmen ausgezählt sind, ist es Zeit, die Bekanntgabe der Ergebnisse für die ganze Schule vorzubereiten.
Dabei fällt dir auf, dass es nicht ausreicht, nur Zähler für die Stimmen zu haben.
Es muss eine Möglichkeit geben, die Anzahl der Stimmen einem bestimmten Kandidaten zuzuordnen.

Erstelle eine Funktion `NewElectionResult`, die den Namen eines Kandidaten und seine Anzahl an Stimmen entgegennimmt und
ein neues Wahlergebnis zurückgibt.

```go
var result *ElectionResult
result = NewElectionResult("Peter", 3)

result.Name == "Peter"  // true
result.Votes == 3       // true
```

Das Struct für das Wahlergebnis ist bereits für dich erstellt und ist wie folgt definiert:

```go
type ElectionResult struct {
    // Name of the candidate
    Name    string
    // Votes of votes the candidate had
    Votes   int
}
```

## 5. Verkünde die Ergebnisse

Es ist Zeit, der Schule den neuen Präsidenten bekanntzugeben!
Der Präsident wird auf den kleinen digitalen Anzeigetafeln bekanntgegeben, die die Schule hat.
Die Nachricht sollte den Namen des neuen Präsidenten und die Anzahl seiner Stimmen im folgenden Format anzeigen: `<candidate_name> (<votes>)`.
Ein Beispiel für eine solche Nachricht ist: `"Peter (51)"`.

Erstelle eine Funktion `DisplayResult`, die ein `*ElectionResult` als Argument entgegennimmt und einen String mit der anzuzeigenden Nachricht zurückgibt.

```go
var result *ElectionResult
result = &ElectionResult{
    Name: "John",
    Votes: 32,
}

DisplayResult(result)
// => John (32)
```

## 6. Neuauszählung der Stimmen

Um sicherzustellen, dass die endgültigen Ergebnisse korrekt waren, wurden die Stimmen neu ausgezählt.
Bei der Neuauszählung stellte sich heraus, dass die Anzahl der Stimmen für einige Kandidaten um eins abwich.

Erstelle eine Funktion `DecrementVotesOfCandidate`, die die endgültigen Ergebnisse und den Namen eines Kandidaten entgegennimmt, für den du seine Stimmenzahl verringern sollst.
Die endgültigen Ergebnisse werden in Form einer `map[string]int` angegeben, wobei die Schlüssel die Namen der Kandidaten und die Werte ihre Gesamtstimmen sind.

```go
var finalResults = map[string]int{
    "Mary":  10,
    "John":  51,
}

DecrementVotesOfCandidate(finalResults, "Mary")

finalResults["Mary"]
// => 9
```
