# Anleitung

In dieser Übung erzeugst du halbstrukturierte Log-Nachrichten.

## Gib halbstrukturierte Nachrichten aus

Du startest mit einigen vorgegebenen Stub-Funktionen und dem folgenden Enum:

```rust
#[derive(Drop, Clone, PartialEq, Debug)]
pub enum LogLevel {
    Info,
    Warning,
    Error,
    Debug
}
```

Dein Ziel ist es, eine Log-Nachricht nach folgendem Muster auszugeben: `"[<LEVEL>]: <MESSAGE>"`.
Dafür musst du Funktionen implementieren, die den Log-Leveln entsprechen.

Der folgende Ausschnitt zeigt zum Beispiel eine erwartete Ausgabe für die Funktion `log`.

```rust
log(LogLevel::Error, "Stack overflow")
// Returns: "[ERROR]: Stack overflow"
```

Und für `info`:

```rust
info("Timezone changed")
// Returns: "[INFO]: Timezone changed"
```

Viel Spaß!
