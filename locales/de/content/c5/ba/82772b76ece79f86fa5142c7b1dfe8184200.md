# Überblick

In Haxe ist ein **Array** eine Sammlung von Elementen, die (meistens) denselben Typ haben. Es gibt drei Wege, in Haxe ein Array zu erstellen: entweder per Konstruktor oder über eine Deklarationssyntax. In Haxe hat das erste Element eines Arrays den Index null:

```haxe
var a = [1, 2, 3];
trace(a); // [1,2,3]

// Here the second element is called by index
trace(a[1]); // 2

// The actual first element's index is 0
trace(a[0]); // 1
```

Um ein Array mit einem Konstruktor zu erstellen, musst du den Typ der Elemente übergeben, die im Array enthalten sein sollen:

```haxe
var a:Array<Int> = [0, 1, 2, 3];
a[1] = "Hello"; // Error: the array a takes integers only
```

Da der Zugriff auf Arrays in Haxe unbegrenzt ist, das heißt, es ist garantiert, dass keine Exception geworfen wird, bedarf das einer genaueren Betrachtung:

- Bei einem Lesezugriff auf einen nicht existierenden Index wird ein zielabhängiger Wert zurückgegeben.
- Bei einem Schreibzugriff mit einem positiven Index, der außerhalb der Grenzen liegt, wird `null` (oder der Standardwert für Basistypen auf statischen Targets) an allen Positionen zwischen dem letzten definierten Index und dem neu geschriebenen Index eingefügt.
- Bei einem Schreibzugriff mit einem negativen Index ist das Ergebnis nicht festgelegt.

Wenn ein Array Elemente verschiedener Typen enthalten soll, fügen wir den Typ `Dynamic` zur Typangabe hinzu:

```haxe
var a:Array<Dynamic> = [10, "Bob", true]
```

## Iteration

Arrays lassen sich mit einer `for`-Schleife durchlaufen:

```haxe
var nums = [2, 3, 5];
var sum = 0;
for (num in nums) {
  sum += num;
}
trace(sum); // 10
```
