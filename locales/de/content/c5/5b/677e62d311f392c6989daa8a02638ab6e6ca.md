# Einführung

## Typkonvertierung

Go erfordert eine explizite Konvertierung zwischen verschiedenen Typen.
Die Konvertierung zwischen Typen (auch bekannt als **Typumwandlung**) erfolgt über eine Funktion mit dem Namen des Typs, in den konvertiert werden soll.
Um zum Beispiel einen `int` in einen `float64` umzuwandeln, gehst du wie folgt vor:

```go
var x int = 42 // x has type int
f := float64(x) // f has type float64 (ie. 42.0)
```

## Konvertierung zwischen primitiven Typen und Strings

Es gibt ein `strconv`-Paket für die Konvertierung zwischen primitiven Typen (wie `int`) und `string`.

```go
import "strconv"

var intString string = "42"
var i, err = strconv.Atoi(intString)

var number int = 12
var s string = strconv.Itoa(number)
```

## Typzusicherungen

Interfaces in Go können zu Mehrdeutigkeit hinsichtlich des zugrunde liegenden Typs führen.
Eine Typzusicherung ermöglicht es uns, den zugrunde liegenden konkreten Wert des Interface-Werts mit dieser Syntax zu extrahieren: `interfaceVariable.(concreteType)`.

Zum Beispiel:

```go
var input any = 12
number := input.(int)
```

HINWEIS: Dies führt zu einer Panik, wenn die Interface-Variable keinen Wert des konkreten Typs enthält.

Wir können testen, ob ein Interface-Wert einen bestimmten konkreten Typ enthält, indem wir beide Rückgabewerte der Typzusicherung nutzen: den zugrunde liegenden Wert und einen booleschen Wert, der angibt, ob die Zusicherung erfolgreich war.
Zum Beispiel:

```go
str, ok := input.(string) // no panic if input is not a string
```

Wenn `input` einen `string` enthält, dann ist `str` der zugrunde liegende Wert und `ok` ist wahr.
Wenn `input` keinen `string` enthält, dann ist `str` der Nullwert vom Typ `string` (d. h. `""`, der leere String) und `ok` ist falsch.
In keinem Fall tritt eine Panik auf.

## Typweichen

Eine **Typweiche** kann mehrere Typzusicherungen nacheinander ausführen.
Sie hat dieselbe Syntax wie eine Typzusicherung (`interfaceVariable.(concreteType)`), aber der `concreteType` wird durch das Schlüsselwort `type` ersetzt.
Hier ist ein Beispiel:

```go
var i any = 12 // try: 12.3, true, int64(12), []int{}, map[string]int{}

switch v := i.(type) {
case int:
    fmt.Printf("the integer %d\n", v)
case string:
    fmt.Printf("the string %s\n", v)
default:
    fmt.Printf("type, %T, not handled explicitly: %#v\n", v, v)
}
```
