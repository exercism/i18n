# Einführung

`for`-Schleifen sind der komplexeste Schleifentyp in PHP. Sie verhalten sich wie `for`-Schleifen in `C`, `Java` und `JavaScript`. Ihre Grundform ist:

```php
for (expr1; expr2; expr3) {
  // statements
}
```

Der erste Ausdruck (_expr1_) wird ausgewertet, bevor die Schleife beginnt. Der zweite Ausdruck (_expr2_) wird vor jeder Iteration ausgewertet. Ergibt er einen Wert, der _truthy_ ist, werden die Anweisungen ausgeführt. Nach den ausgeführten Anweisungen wird der dritte Ausdruck (_expr3_) ausgewertet.
