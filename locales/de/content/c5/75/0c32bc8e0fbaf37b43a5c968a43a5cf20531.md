# Anleitung

In dieser Übung schreibst du Code, um die Produktion an einem Fließband in einer Autofabrik zu analysieren. 
Die Geschwindigkeit des Fließbands kann von `0` (aus) bis `10` (Maximum) reichen.

Bei seiner langsamsten Geschwindigkeit (`1`) produziert es `221` Autos pro Stunde. 
Die Produktion steigt linear mit der Geschwindigkeit. 
Bei einer Geschwindigkeit von `4` sollte es also `4 * 221 = 884` Autos pro Stunde produzieren. 
Höhere Geschwindigkeiten erhöhen jedoch die Wahrscheinlichkeit, dass fehlerhafte Autos produziert werden, die dann aussortiert werden müssen. 
Die folgende Tabelle zeigt, wie die Geschwindigkeit die Erfolgsquote beeinflusst:

- `1` bis `4`: 100 % Erfolgsquote.
- `5` bis `8`: 90 % Erfolgsquote.
- `9`: 80 % Erfolgsquote.
- `10`: 77 % Erfolgsquote.

Du hast zwei Aufgaben.

## 1. Berechne die Produktionsrate pro Stunde

Implementiere die Methode `AssemblyLine#production_rate_per_hour`, um die Produktionsrate des Fließbands pro Stunde zu berechnen und dabei die Erfolgsquote zu berücksichtigen.
Beachte, dass der Rückgabewert eine Instanz von `Float` ist.

```ruby
AssemblyLine.new(6).production_rate_per_hour
#=> 1193.4
```

## 2. Berechne die Anzahl der funktionierenden Teile, die pro Minute produziert werden

Implementiere die Methode `AssemblyLine#working_items_per_minute`, um zu berechnen, wie viele **fertige, funktionierende Autos** pro Minute produziert werden.
Beachte, dass der Rückgabewert eine Instanz von `Integer` ist.

```ruby
AssemblyLine.new(6).working_items_per_minute
#=> 19
```
