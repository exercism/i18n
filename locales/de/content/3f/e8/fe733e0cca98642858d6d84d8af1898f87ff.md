# Hinweise

## 1. Beschreibe einfache Zahlen

- Verwende `fmt.Sprintf` zum Formatieren

## 2. Beschreibe eine Zahlenbox

- Ermittle das Ergebnis mit der `Number()`-Methode
- Verwende `fmt.Sprintf` zum Formatieren

## 3. Implementiere eine Methode, die die Zahl aus einer ausgefallenen Zahlenbox extrahiert

- Verwende eine Type Assertion, um zu prüfen, ob der Wert vom Typ `FancyNumber` ist
- Hole den `string` aus der `Value()`-Methode
- Verwende `strconv.Atoi`, um den `string` in einen `int` umzuwandeln (den Fehler kannst du verwerfen, denn wir wollen 0, wenn er nicht in einen `int` umgewandelt werden kann)

## 4. Beschreibe eine ausgefallene Zahlenbox

- Verwende `ExtractFancyNumber`, um den `int`-Wert zu erhalten
- Wandle den `int` in einen `float64` um
- Verwende `fmt.Sprintf` zum Formatieren

## 5. Implementiere `DescribeAnything`, das alle verwendet

- Verwende entweder Type Assertions (z. B. `i.(someType)`) oder einen Type Switch (`switch v := i.(type)`)
- Denk daran, `int` in einen `float64` umzuwandeln
