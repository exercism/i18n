# Einführung

## Parameter

In dieser Übung geht es um einige Details von Methodenparametern und ihrer Verwendung in C#.

Parameter übermitteln Informationen von einer aufrufenden Methode an eine aufgerufene Methode.

- Das Verhalten von Parametern lässt sich durch Modifizierer wie `ref` und `out` ändern.

- Ein Parameter mit dem `out`-Modifizierer übermittelt einen Wert von der aufgerufenen Methode zurück an den Aufrufer. Der Parameter kann an die aufgerufene Methode übergeben werden, ohne initialisiert zu sein, und wird in der aufgerufenen Methode in jedem Fall so behandelt, als wäre er beim Eintritt nicht initialisiert gewesen. Wie Parameter-Modifizierer sich verhalten und welche Regeln dafür gelten, verstehst du am einfachsten anhand von Beispielen (siehe unten) und Compilermeldungen.

```csharp
void Foo(out int val)
{
    val = 42;
}
void Bar(int val)
{
    val = 42;
}

int importantValue = 1729;
Foo(out importantValue);
var result = importantValue == 42;
// => true

importantValue = 1729;
Bar(importantValue);
result = importantValue == 1729;
// => true
```

- `out`-Parameter müssen innerhalb einer aufgerufenen Methode zugewiesen werden.

- Ein Parameter mit dem `ref`-Modifizierer übergibt einen Wert an eine aufgerufene Methode. Wenn die Methode zurückkehrt, findet der Aufrufer in diesem Parameter alle Aktualisierungen, die die aufgerufene Methode vorgenommen hat.

```csharp
void Foo(ref int val)
{
    val *= 7;
}

int importantValue = 6;
Foo(ref importantValue);
return importantValue;
// => 42
```

- `ref`-Parameter müssen Variablen sein, da die aufgerufene Methode direkt mit dem Parameter arbeitet, wie der Aufrufer ihn sieht.
- Die Modifizierer `out` und `ref` sind sowohl in der Signatur der aufgerufenen Methode als auch an der Aufrufstelle erforderlich.
