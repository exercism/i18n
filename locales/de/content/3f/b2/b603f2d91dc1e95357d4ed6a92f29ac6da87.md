# Ergänzung zur Anleitung

## Hinweise

Um diese Übung abzuschließen, musst du die Funktion `slices` implementieren,
die einen *Text* nimmt und die Teilfolgen von Ziffern einer bestimmten Länge
zurückgibt:

Wenn du diese Übung zum ersten Mal löst, empfehlen wir dir, dich an die
vorgegebene Signatur zu halten:

```haskell
slices :: Int -> String -> [[Int]]
```

Später kann es eine gute Idee sein, dieses Problem noch einmal aufzugreifen
und mit anderen Datentypen und Bibliotheken zu spielen:

- `ByteString`, aus dem Paket *bytestring*.
- `Sequence`, aus dem Paket *containers*.
- `Text`, aus dem Paket *text*.
- `Vector`, aus dem Paket *vector*.

Die Testsuite wurde absichtlich so entworfen, dass sie fast jede sinnvolle
Typsignatur akzeptiert. Deshalb ermutigen wir dich, die zu finden, die du für
die beste hältst.
