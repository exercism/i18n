# Einführung

## Klassen

Das primäre objektorientierte Konstrukt in Java ist die _Klasse_, eine Kombination aus Daten (_Felder_) und Verhalten (_Methoden_).
Die Felder und Methoden einer Klasse werden als ihre _Mitglieder_ bezeichnet.

Der Zugriff auf Mitglieder kann über Zugriffsmodifikatoren gesteuert werden. Die beiden gebräuchlichsten sind:

- `public`: Auf das Mitglied kann jeder Code zugreifen (keine Einschränkungen).
- `private`: Auf das Mitglied kann nur Code in derselben Klasse zugreifen.

Du kannst dir eine Klasse als Vorlage für das Erstellen von Instanzen dieser Klasse vorstellen.
Um eine Instanz einer Klasse zu erstellen (auch als _Objekt_ bekannt), wird das Schlüsselwort `new` verwendet:

```java
class Car {
}

// Create two car instances
Car myCar = new Car();
Car yourCar = new Car();
```

Felder haben einen Typ und einen Namen (in camelCase geschrieben) und können überall in einer Klasse definiert werden (Klassen schreibt man konventionsgemäß in PascalCase):

```java
class Car {
    // Accessible by anyone
    public int weight;

    // Only accessible by code in this class
    private String color;
}
```

Du kannst einem Feld optional einen Anfangswert zuweisen.
Wenn ein Feld _keinen_ Anfangswert angibt, wird es auf den Standardwert seines Typs gesetzt.
Die Feldwerte einer Instanz lassen sich mit der Punktnotation abrufen und aktualisieren.

```java
class Car {
    // Will be set to specified value
    public int weight = 2500;

    // Will be set to default value (0)
    public int year;
}

Car newCar = new Car();
newCar.weight; // => 2500
newCar.year;   // => 0

// Update value of the field
newCar.year = 2018;
```

Private Felder werden normalerweise als Seiteneffekt beim Aufruf einer Methode aktualisiert.
Solche Methoden geben üblicherweise keinen Wert zurück. In diesem Fall sollte der Rückgabetyp `void` sein:

```java
class CarImporter {
    private int carsImported;

    public void importCars(int numberOfCars)
    {
        // Update private field from public method
        carsImported = carsImported + numberOfCars;
    }
}
```
