# Einführung

## Anonyme Funktionen

In Elixir sind Funktionen Bürger erster Klasse. Das bedeutet:

- Benannte und anonyme Funktionen können Variablen zugewiesen werden.
- Benannte und anonyme Funktionen können wie Daten als Argumente und Rückgabewerte weitergegeben werden.
- Anonyme Funktionen können dynamisch erstellt werden.

Anonyme Funktionen haben, im Gegensatz zu benannten Funktionen, keine statische Referenz, die ihnen zur Verfügung steht. Sie sind nur dann verfügbar, wenn du sie einer Variablen zuweist oder sie sofort aufrufst.

Wir können anonyme Funktionen unter anderem verwenden, um:

- Daten mithilfe des lexikalischen Gültigkeitsbereichs zu verbergen (auch als Closure bekannt).
- Funktionen zur Laufzeit dynamisch zu erstellen.

Anonyme Funktionen beginnen mit dem reservierten Wort `fn`, die Argumente werden mit dem Token `->` vom Funktionskörper getrennt, und sie enden mit einem `end`. Wie bei benannten Funktionen wird der letzte Ausdruck in der Funktion _implizit zurückgegeben_, und zwar an die aufrufende Funktion.

Um eine Funktionsreferenz aufzurufen, musst du einen `.` zwischen die Referenzvariable und die Liste der Argumente setzen:

```elixir
function_variable = fn param ->
  param + 1
end

function_variable.(1)
# => 2
```

Du kannst sogar die Kurzform der Capture-Notation verwenden, um das noch kompakter zu machen:

```elixir
variable = &(&1 + 1)

variable.(1)
# => 2
```

## Bit-Manipulation

Elixir unterstützt viele Funktionen für die Arbeit mit Bits, die im _Bitwise-Modul_ zu finden sind.

- `band/2`: Bitweises UND
- `bsl/2`: Bitweises Verschieben nach links
- `bsr/2`: Bitweises Verschieben nach rechts
- `bxor/2`: Bitweises XOR
- `bor/2`: Bitweises ODER
- `bnot/1`: Bitweises NICHT

Hier ist ein Beispiel, wie du eine bitweise Funktion verwendest:

```elixir
Bitwise.bsl(1, 3)
# => 8
```

Alle bitweisen Funktionen arbeiten nur mit Ganzzahlen.

Wenn du Elixir in Version 1.9 oder älter verwendest, musst du `require Bitwise` am Anfang der Moduldefinition aufrufen, um das _Bitwise_-Modul verwenden zu können.
