# Anweisungen

Beim Vorbereiten von Keksen für deine Freunde hast du festgestellt, dass du einige der im Rezept verwendeten Mengenangaben umrechnen musst.
Da du nur das metrische System kennst, brauchst du eine Möglichkeit, gängige US-Backmaßeinheiten in Milliliter (mL) umzurechnen, um es dir einfacher zu machen.

Verwende diese Umrechnungstabelle für deine Lösung:

| Umzurechnende Einheit | Volumen | in Millilitern (mL) |
| --------------- | ------ | ------------------- |
| mL              | 1      | 1                   |
| US-Cup          | 1      | 240                 |
| US-Flüssigunze  | 1      | 30                  |
| US-Teelöffel    | 1      | 5                   |
| US-Esslöffel    | 1      | 15                  |

Als talentierter Programmierer in Ausbildung entscheidest du dich, Milliliter als Zwischeneinheit zu verwenden, um die Umrechnung von jeder aufgeführten Einheit in jede andere (sogar in sich selbst) zu erleichtern.

## 1. Die numerische Komponente aus einem Volumenpaar ermitteln

Implementiere die Funktion `getVolume`. Wenn sie ein Volumenpaar als Tupel erhält, soll sie nur die numerische Komponente zurückgeben.

```haskell
getVolume (Cup, 2.0)
-- -> 2.0
```

## 2. Das Volumenpaar in Milliliter umrechnen

Implementiere die Funktion `toMilliliter`. Wenn sie ein Volumenpaar als Tupel erhält, soll sie das Volumen mit der Umrechnungstabelle in Milliliter umrechnen.

Verwende mehrere Funktionsklauseln und Pattern Matching, um die Funktionen für jede Einheit zu erstellen. Die Atome, mit denen die einzelnen Einheiten bezeichnet werden, sind: `Cup`, `FluidOunce`, `Teaspoon`, `Tablespoon`, `Milliliter`.
Verpacke das Ergebnis der Umrechnung in ein Tupel und gib es zurück.

```haskell
toMilliliter (Cup, 2.5)
-- -> (Milliliter, 600.0)
```

## 3. Das Volumenpaar mit Millilitern in eine andere Einheit umrechnen

Implementiere die Funktion `fromMilliliter`. Wenn sie ein Volumenpaar als Tupel und die gewünschte Einheit erhält, soll sie das Volumen mit der Umrechnungstabelle in die gewünschte Einheit umrechnen.

Verwende mehrere Funktionsklauseln und Pattern Matching, um die Funktionen für jede Einheit zu erstellen. Die Atome, mit denen die einzelnen Einheiten bezeichnet werden, sind: `Cup`, `FluidOunce`, `Teaspoon`, `Tablespoon`, `Milliliter`.

```haskell
fromMilliliter (Milliliter, 1320.0) Cup
-- -> (Cup, 5.5)
```

## 4. Von jeder Einheit in jede Einheit umrechnen

Implementiere die Funktion `convert`. Wenn sie ein Volumenpaar als Tupel und die gewünschte Einheit erhält, soll sie das angegebene Volumen in die gewünschte Einheit umrechnen.

```haskell
convert (Teaspoon, 9.0) Tablespoon
-- -> (Tablespoon, 3.0)
```
