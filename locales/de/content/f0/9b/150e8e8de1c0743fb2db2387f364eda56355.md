# Debug

```pyret
fun print-forty-two():
  print(42) # 42
end
```

```pyret
fun return-forty-two() block:
  print(42) # 42
  42
end
```

[print][print] ist ein Ausdruck, der einen Wert zurückgibt.
Pyret erlaubt nur einen einzigen Ausdruck in einem gegebenen Block, sofern der äußere Block nicht mit `block` gekennzeichnet ist.
Im zweiten Beispiel sorgt das Hinzufügen von `block` zur Funktionsdeklaration dafür, dass wir 42 ausgeben können, bevor die Funktion den Wert zurückgibt.

## Spy-Anweisungen

```pyret
fun do-something():
    x = "foo"
    y = "bar"
    spy "strings": x, y end
    a = 1
    b = 2
    spy "numbers": a, b end
end
do-something();

# Spying "strings" (at <clipped>/example.arr:4:4-4:27)
#  x: "foo"
#  y: "bar"
# Spying "numbers" (at <clipped>/example.arr:7:4-7:27)
#  a: 1
#  b: 2
```

Eine spy-Anweisung nimmt ein optionales Label, eine oder mehrere Variablen und gibt jede Variable und ihren Wert aus.
Da sie kein Ausdruck ist, kann eine spy-Anweisung in einem Block verwendet werden, ohne dass der äußere Block mit `block` gekennzeichnet werden muss.

[print]: https://pyret.org/docs/latest/_global_.html#%28idx._%28gentag._57%29%29
[spy]: https://pyret.org/docs/latest/s_spies.html
