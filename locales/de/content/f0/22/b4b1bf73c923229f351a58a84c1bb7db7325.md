# Tests ausführen

Wechsle im Terminal in das Basisverzeichnis der Übung und führe die Tests dann so aus:

```bash
$ mix test
```

Damit wird die Testdatei im Unterordner `test` ausgeführt, also eine Datei, die auf `_test.exs` endet.

Dokumentation:

* [`mix test` - Elixirs Werkzeug zum Ausführen von Tests](https://hexdocs.pm/mix/Mix.Tasks.Test.html)
* [`ExUnit` - Elixirs Bibliothek für Unit-Tests](https://hexdocs.pm/ex_unit/ExUnit.html)

## Ausstehende Tests

In den Testsuiten von Übungen sind alle Tests außer dem ersten als übersprungen markiert.

Sobald ein Test durchläuft, kannst du den nächsten wieder aktivieren, indem du das entsprechende `@tag :pending` mit einem `#` auskommentierst.

Zum Beispiel:

```elixir
# @tag :pending
test "shouting" do
  assert Bob.hey("WATCH OUT!") == "Whoa, chill out!"
end
```

Wenn du alle Tests auf einmal ausführen möchtest, kannst du alle übersprungenen Tests mit dem `--include`-Flag beim Befehl `mix test` einbeziehen:

```bash
$ mix test --include pending
```

Oder du aktivierst alle Tests, indem du die Zeile `ExUnit.configure` in der Datei `test/test_helper.exs` auskommentierst.

```elixir
# ExUnit.configure(exclude: :pending, trace: true)
```

## Nützliche Optionen für `mix test`

* `test/<FILE>.exs:LINENUM` - führt nur einen einzelnen Test aus, nämlich den Test aus `<FILE>.exs`, dessen Definition in Zeile `LINENUM` steht
* `--failed` - führt nur Tests aus, die beim letzten Durchlauf fehlgeschlagen sind
* `--max-failures` - die Suite hört auf, Tests auszuwerten, sobald diese Anzahl an fehlgeschlagenen Tests erreicht ist
* `--seed 0` - deaktiviert die Zufallsreihenfolge, sodass die Tests in einer Datei immer in der Reihenfolge ausgeführt werden, in der sie definiert wurden
