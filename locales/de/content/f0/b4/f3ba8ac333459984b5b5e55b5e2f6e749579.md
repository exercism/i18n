# Über

Wenn sich die Typen der Parameter ableiten lassen, erlaubt Swift es auch, die Parameternamen und das Schlüsselwort `in` in der Closure-Definition wegzulassen. Stattdessen kannst du die Parameter über eine [spezielle Kurzschreibweise][shorthand-argument-names] ansprechen, wobei `$0` für den ersten Parameter steht, `$1` für den zweiten und so weiter.

```swift
let mean: (Double, Double) -> Double = { $0 + $1 / 2.0 }

["apple", "ball", "carrot"].sorted(by: { $0.count < $1.count })
```

Dieser Stil wird am häufigsten verwendet, wenn Closures in Funktionen höherer Ordnung übergeben werden und Kürze gefragt ist.

[shorthand-argument-names]: https://docs.swift.org/swift-book/LanguageGuide/Closures.html#ID100
