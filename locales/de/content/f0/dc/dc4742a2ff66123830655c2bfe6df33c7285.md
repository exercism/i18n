# Einführung

In Factor definierst du ein neues Wort mit `: name ( stack-effect ) body ;`.
Der Rumpf ist eine Folge von Wörtern; wenn du dein neues Wort aufrufst,
werden sie der Reihe nach ausgeführt.

```factor
USING: kernel ;
IN: my-vocab

: shout ( str -- str ) "!" append ;
```

Wenn eine Routine groß wird, kannst du sie, und solltest das auch,
*faktorisieren*: Fasse Gruppen von Wörtern zu kleineren benannten Wörtern
zusammen, von denen jedes eine einzige Aufgabe hat. Die Sprache heißt nicht
umsonst so.

## Vokabulare

Jede `.factor`-Datei deklariert ein Vokabular mit `IN:`. Wörter in einem
Vokabular können Wörter aus einem anderen aufrufen, indem sie das andere
Vokabular in `USING:` auflisten.

```factor
! file: my-vocab/helpers/helpers.factor
USING: kernel ;
IN: my-vocab.helpers

: shout-line ( str -- str ) "!" append ;
```

```factor
! file: my-vocab/my-vocab.factor
USING: kernel my-vocab.helpers sequences ;
IN: my-vocab

: announce ( names -- strs )
    [ shout-line ] map ;
```

Der Verzeichnisaufbau folgt dem Vokabelnamen mit Punkten: Das Vokabular
`my-vocab` liegt in `my-vocab/my-vocab.factor`; das Vokabular
`my-vocab.helpers` liegt in `my-vocab/helpers/helpers.factor`. Der Loader
von Factor folgt den `USING:`-Deklarationen transitiv und lädt jedes
Vokabular bei Bedarf.
