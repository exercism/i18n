# Rückgabe

In Crystal gibt der letzte Ausdruck in einer Methode seinen Wert zurück.
Manchmal musst du aber einen Wert zurückgeben, bevor der letzte Ausdruck erreicht ist.
Dafür kannst du das Schlüsselwort `return` verwenden, das den Wert des folgenden Ausdrucks zurückgibt.
Code, der nach einem `return` steht, wird nicht ausgeführt.

```crystal
def speed_limit(road_number)
    if road_number == 1
        return 50
        puts "This will not be executed"
    elsif road_number == 2
        return 80
        puts "This will not be executed"
    end
    100
end

p speed_limit(1) # => 50
p speed_limit(2) # => 80
p speed_limit(3) # => 100
```

~~~~exercism/note
Das Schlüsselwort `return` solltest du weglassen, wenn der letzte Ausdruck in einer Methode der Wert ist, der zurückgegeben werden soll.
~~~~
