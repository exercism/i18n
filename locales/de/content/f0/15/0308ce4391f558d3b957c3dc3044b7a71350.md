# Über

## Zahlen und numerische Operatoren

Alle **Zahlen**, ob Ganzzahlen oder nicht, sind IEEE754-Gleitkommazahlen mit doppelter Genauigkeit.
Die Implementierung von `jq` verwendet den C-Typ `double`.
Das beschränkt uns auf 53 Bit Genauigkeit.

Die üblichen Operatoren stehen für die Arbeit mit Zahlen zur Verfügung:

- Arithmetik: `+`, `-`, `*`, `/`, `%`
- Vergleich: `==`, `!=`, `<`, `<=`, `>=`, `>`
- standardmäßige [Mathematikfunktionen][man-math]

  Bei Funktionen mit einem Eingabewert leitest du den Wert per Pipe in die Funktion

  ```sh
  $ jq -n '(1 | atan) * 4'
  3.141592653589793
  ```

  Bei Funktionen mit zwei Eingabewerten ignorieren die Funktionen die Eingabe und erwarten die Werte als Parameter

  ```sh
  $ jq -n 'pow(2; 10)'
  1024
  ```

  Das Semikolon ist das Trennzeichen für Funktionsargumente, nicht das Komma.

~~~~exercism/caution
Was bedeutet der Satz „Das beschränkt uns auf 53 Bit Genauigkeit"?

Eine Demonstration:

```sh
$ jq -n 'pow(2;52) as $n | [$n, $n+1]'
[
  4503599627370496,
  4503599627370497
]
```

Das sieht gut aus. Was, wenn wir den Exponenten erhöhen?

```sh
$ jq -n 'pow(2;53) as $n | [$n, $n+1]'
[
  9007199254740992,
  9007199254740992
]
```

Diese Zahlen sollten nicht gleich sein. 
So sieht „Genauigkeitsverlust" aus.
Das bedeutet, dass `jq` nicht in der Lage ist, beliebig große Zahlen zu verarbeiten.
~~~~

## Bedingte Ausdrücke

`jq` verwendet einen [`if-then-else`-Ausdruck][if-then-else] für **bedingte Ausdrücke**.
Als _Ausdruck_ wird er in eine Pipeline eingefügt.

Die Syntax lautet: `if CONDTITION then TRUE_EXPR else FALSE_EXPR end`.

Die `else`-Klausel ist optional.

```jq
42 | if . < 33 then "small" else "larger" end
# => "larger"
```

Zusätzliche Bedingungen verwenden `elif`

```jq
42 | if . < 33 then "small"
     elif . < 67 then "medium"
     else "large"
     end
# => "medium"
```
