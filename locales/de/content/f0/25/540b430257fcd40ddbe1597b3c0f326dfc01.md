# Über

Eine [`List`][lists] in Elm ist eine unveränderliche Sammlung von null oder mehr Werten desselben Typs.
Da Listen unveränderlich sind, kann sich der Wert einer Liste nach ihrer Konstruktion nie ändern.
Elm-Listen haben einen _Kopf_ (das erste Element) und einen _Rest_ (alles nach dem ersten Element).
Der _Rest_ einer Liste ist selbst eine Liste.

Typannotationen für Listen kannst du so definieren:

```elm
List String --> a list of String
List Int --> a list of Int
```

Listen definierst du so:

```elm
empty : List Char
empty = []

singleValue = [ 5 ] --> List Int
singleValueAlternative = List.singleton 5 --> List Int

threeValues = [ "a", "b", "c" ] --> List String
```

Am gebräuchlichsten ist es, ein Element mit dem `::`-Operator (cons) zu einer Liste hinzuzufügen:

```elm
twoToFour = [ 2, 3, 4 ]
oneToFour = 1 :: twoToFour --> [1; 2; 3; 4]
```

Listen kannst du mit dem `++`-Operator oder `List.append` anhängen:

```elm
[ 6, 7 ] ++ [ 8, 9 ]           --> [6, 7, 8, 9]
List.append [ 6, 7 ] [ 8, 9 ]  --> [6, 7, 8, 9]
```

Listen werden durch Funktionen und Operatoren manipuliert, die im [`List`-Modul][list-module] definiert sind.

```elm
List.length [ 7, 8 ] --> 2
```

Alle Funktionen und Operatoren, die den Eindruck erwecken, eine Liste zu verändern (etwa das Hinzufügen eines Elements), geben tatsächlich eine neue Liste zurück.
Die Performance ist normalerweise kein Problem, da die Implementierung von Listen unnötige Allokationen und Kopien vermeidet.

Listen kannst du auch mit [Musterabgleich][list-destructuring] verarbeiten.

```elm
describe : List String -> String
describe list =
    case list of
        [] ->
            "Empty list"

        [ "hello" ] ->
            "Singleton list with: hello"

        x :: xs ->
            "Non-empty list with head: " ++ x

describe []                   --> "Empty list"
describe [ "hello" ]          --> "Singleton list with: hello"
describe [ "hello", "world" ] --> "Non-empty list with head: hello"
```
