# Hinweise

## Allgemein

- Das Vokabular [`sequences`][sequences] deckt fast alles ab,
  einschließlich `sum`.

## 1. Die heutige Anzahl

- `last` gibt das letzte Element einer Sequenz zurück.

## 2. Erhöhe die heutige Anzahl

- `unclip-last` löst das letzte Element ab, sodass du es umwandeln kannst,
  und `suffix` hängt ein Element an eine Sequenz an. Zusammen ergeben sie
  ein nicht-destruktives Muster, um „das letzte Element zu ändern“.

## 3. Gab es einen Tag ohne Vögel?

- `any?` nimmt eine Sequenz und eine Prädikat-Quotation und gibt `t`
  zurück, wenn das Prädikat für mindestens ein Element zutraf.
- Die Prädikat-Quotation für „ist diese Zahl null?“ lautet `[ zero? ]`.

## 4. Summiere die ersten paar Tage

- `head` nimmt eine Sequenz und eine Anzahl `n` und gibt die ersten `n`
  Elemente zurück.
- Summiere dann das Ergebnis.

## 5. Zähle die ereignisreichen Tage

- `count` nimmt eine Sequenz und ein Prädikat, wie `any?`, gibt aber
  zurück, *wie viele* Elemente übereinstimmten.

## 6. Fehlende Tage auffüllen

- `pad-tail` nimmt eine Sequenz, eine Ziellänge und ein Füllelement
  und erweitert die Sequenz auf diese Länge, indem es Kopien des
  Elements anhängt. Ist die Sequenz bereits lang genug, wird sie
  unverändert zurückgegeben.
