# Einführung

## Case-Ausdrücke

In Gleam kannst du mit einem `case`-Ausdruck Code bedingt ausführen. Mit einem `case`-Ausdruck kann ein Wert gegen ein oder mehrere _Muster_ geprüft werden. Ein Beispiel für so ein Muster ist das _Literalmuster_, das einen Wert mit einem literalen Wert vergleicht (z. B. `1` oder `"hello"`).

Case-Ausdrücke werden mit dem Schlüsselwort `case` geschrieben:

```gleam
pub fn describe(number: Int) -> String {
  case number {
    0 -> "Zero"
    1 -> "One"
  }
}
```

Auch wenn das wie `switch`-Anweisungen in anderen Sprachen aussehen mag, zeigt der Musterabgleich erst seine Stärke, wenn du auch andere Muster verwendest. Ein solches Muster ist das _Variablenmuster_, mit dem du einer Variablen einen Wert zuweisen kannst. In diesem Beispiel bekommt die Variable `i` den Wert von `number`, wenn `number` nicht `0` ist:

```gleam
pub fn describe(number: Int) -> String {
  case number {
    0 -> "Zero"
    i -> "Non zero"
  }
}
```

Manchmal möchtest du einem Muster eine zusätzliche Bedingung hinzufügen. Das nennt man einen _Guard_ (eine Klausel), den du mit dem Schlüsselwort `if` hinzufügen kannst:

```gleam
pub fn describe(number: Int) -> String {
  case number {
    0 -> "Zero"
    i if i < 0 -> "Negative number"
  }
}
```

Aus Performancegründen sind in Guards nur grundlegende mathematische und boolesche Operatoren erlaubt, andere Funktionen kannst du in Guards nicht verwenden.

Im obigen Beispiel gibt es nicht für jede mögliche Eingabe ein passendes Muster. Der Compiler erkennt das und gibt einen Fehler aus. Das nennt man _Vollständigkeitsprüfung_. Um die Warnung zu beheben, musst du alle Fälle abdecken. Dafür kannst du das _Verwerfungsmuster_ verwenden, ein Muster, das auf jeden Wert passt:

```gleam
pub fn describe(number: Int) -> String {
  case number {
    0 -> "Zero"
    i if i < 0 -> "Negative number"
    _ -> "Positive number"
  }
}

// No compiler error
```

In einer Klausel kannst du mehrere Muster abgleichen, indem du sie mit `|` voneinander trennst. Pro Klausel ist nur ein Guard möglich:

```gleam
pub fn describe(number: Int) -> String {
  let yell = True
  case number {
    0 -> "Zero"
    3 | 5 -> "One of the first odd prime numbers"
    2 | 4 | 6 | 8 if !yell -> "One of the even numbers less than 10"
    i if i % 2 == 0 && yell -> "[Yelling] I'm telling you! It's a even nunber"
    i if i < 0 -> "Negative number"
    _ -> "Positive number"
  }
}
// No compiler error
```

Case-Ausdrücke prüfen einen Wert von oben nach unten gegen jedes Muster, bis sie ein passendes Muster finden und die dazugehörige Logik ausführen. Die Reihenfolge der Muster ist wichtig!
