# Instructions

Dein Design-Team wechselt für einen Teil seiner Layout-Arbeit von CSS-Transformationen zu Factor. Damit der Rest des Teams zufrieden bleibt, baust du kleine, wiederverwendbare Transformationen als Quotations, die einen 2D-Punkt nehmen und einen 2D-Punkt zurückgeben.

Ein Punkt ist ein 2-Array `{ x y }`.

## 1. Die Koordinaten verschieben

Definiere `translate-2d`, das zwei Werte `dx` und `dy` vom Stack nimmt und eine Quotation zurückgibt, die einen Punkt um `(dx, dy)` verschiebt.

```factor
{ 4 8 } 2 0 translate-2d call( p -- p' ) .
! => { 6 8 }
```

## 2. Die Koordinaten skalieren

Definiere `scale-2d` genauso. Die zurückgegebene Quotation skaliert einen Punkt um `(sx, sy)`.

```factor
{ 6 -3 } 2 2 scale-2d call( p -- p' ) .
! => { 12 -6 }
```

## 3. Zwei Transformationen kombinieren

Definiere `compose-transformations`, das zwei Transformations-Quotations `f` und `g` nimmt und eine einzelne Quotation zurückgibt, die zuerst `f` und dann `g` anwendet.

```factor
{ 0 1 } 2 0 translate-2d 2 2 scale-2d compose-transformations
call( p -- p' ) .
! => { 4 2 }
```

## 4. Eine Transformation anwenden

Definiere `apply-transformation`, das einen Punkt und eine Transformations-Quotation vom Stack nimmt und den transformierten Punkt zurückgibt.

```factor
{ 4 8 } 2 0 translate-2d apply-transformation .
! => { 6 8 }
```

## 5. Viele Punkte auf einmal transformieren

Definiere `transform-points`, das ein Array von Punkten und eine Transformations-Quotation nimmt und das Array der transformierten Punkte zurückgibt.

```factor
{ { 0 0 } { 1 1 } { 2 2 } } 1 0 translate-2d transform-points .
! => { { 1 0 } { 2 1 } { 3 2 } }
```
