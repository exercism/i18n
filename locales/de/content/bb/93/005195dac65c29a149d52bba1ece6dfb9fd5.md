# Klassen mit Zustand

Bisher war jede Klasse eine Kiste voller Routinen. Jede nahm ihre Argumente,
berechnete eine Antwort und vergaß alles.

Eine Klasse kann sich stattdessen Dinge **merken**. Eine Anzeigetafel muss
das: Der Spielstand hängt inzwischen von jedem Tor seit Spielbeginn ab.

## Attribute

`attr` gibt einer Klasse etwas, das sie sich merken kann.

```sather
class SCOREBOARD is

   attr home_score : INT;
   attr away_score : INT;

end; -- class SCOREBOARD
```

Jedes `attr` erzeugt eine Routine, die den Wert liest, und eine, die ihn
ändert:

```sather
   board.home_score            -- read it
   board.home_score := 4;      -- change it
```

Attribute desselben Typs können sich eine Deklaration teilen, so wie
Argumente es können:

```sather
   attr home_score, away_score : INT;
```

## Objekte

Eine Klasse mit Attributen ist ein Muster zum Erzeugen von **Objekten**.
Jedes Objekt hat seine eigenen Kopien der Attribute, zwei Anzeigetafeln
halten also zwei Spielstände.

`new` erzeugt ein Objekt. Es steht in einer Routine namens `create`, die das
Objekt dann auffüllt und zurückgibt:

```sather
   create(home, away : STR) : SAME is
      board ::= new;
      board.home_team := home;
      board.away_team := away;
      return board;
   end;
```

`SAME` bedeutet „diese Klasse“. Würdest du dort `SCOREBOARD` schreiben, wäre
das dasselbe, aber `SAME` funktioniert weiter, wenn die Klasse umbenannt
wird.

## Ein Objekt erzeugen

`#` ruft `create` auf:

```sather
   board ::= #SCOREBOARD("Vixens", "Magpies");
```

Du verwendest `#` schon seit `rehearsal-script`. `#FSTR` ist genau das.

## Routinen, die das Objekt verändern

Innerhalb der Klasse verwendest du ein Attribut über seinen Namen, ohne
Objekt davor. Damit ist das Objekt gemeint, für das die Routine aufgerufen
wurde.

```sather
   home_goal is
      home_score := home_score + 1;
   end;
```

`home_goal` deklariert keinen Rückgabetyp, denn es liefert nichts zurück,
sondern verändert das Objekt. Ruf es als Anweisung auf:

```sather
   board.home_goal;
```

## Attribute beginnen leer

Ein Attribut, das niemand gesetzt hat, enthält null für ein `INT`, `false`
für ein `BOOL` und void für einen String oder ein Objekt. Eine neue
Anzeigetafel steht also auf 0 zu 0, ohne dass das jemand sagen müsste.
