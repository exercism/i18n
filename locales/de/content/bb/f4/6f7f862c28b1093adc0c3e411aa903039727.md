# Anleitung

In dieser Übung arbeitest du weiter an ferngesteuerten Autos.

Ein Experimentalauto wurde entwickelt, und die Teststrecke muss angepasst werden, damit sie sowohl mit Serien- als auch mit Experimentalmodellen umgehen kann.
Die beiden Fahrzeugtypen sind bereits gebaut, und du musst einen Weg finden, auf der Teststrecke mit beiden umzugehen.

Außerdem beginnen die Serienautos, erste Erfolge zu erzielen.
Der Teamchef möchte den Wettbewerbsgeist erhalten, indem er eine Rangliste der Serienautos veröffentlicht.

## 1. Implementiere die Schnittstelle

Bitte füge der Schnittstelle `RemoteControlCar` zwei Methoden hinzu:

- `drive()`, die nichts zurückgibt, und
- `getDistanceTravelled()`, die ein `int` zurückgibt.

Dann lass `ProductionRemoteControlCar` und `ExperimentalRemoteControlCar` die Schnittstelle `RemoteControlCar` implementieren.
Dazu gehört es, alle Methoden zu implementieren, die die Schnittstelle vorschreibt.

## 2. Fahren

Jeder Aufruf von `.drive()` soll das Auto eine bestimmte Strecke fahren lassen:

- ein `ProductionRemoteControlCar` fährt 10 Einheiten,
- ein `ExperimentalRemoteControlCar` fährt 20 Einheiten.

Die Methode `.getDistanceTravelled()` soll die Anzahl der Einheiten zurückgeben, die das Auto insgesamt zurückgelegt hat.

```java
ProductionRemoteControlCar prod = new ProductionRemoteControlCar();
prod.drive();
prod.getDistanceTravelled();
// => 10
        
ExperimentalRemoteControlCar exp = new ExperimentalRemoteControlCar();
exp.drive();
exp.getDistanceTravelled();
// => 20
```

## 3. Rennen

Implementiere die Methode `TestTrack.race(RemoteControlCar car)`, in der die `car`-Objekte `drive()` aufrufen dürfen.

```java
TestTrack.race(new ProductionRemoteControlCar());
TestTrack.race(new ExperimentalRemoteControlCar());
// this should execute without an exception being thrown
```

## 4. Die Serienautos sortierbar machen

Bitte implementiere die Schnittstelle `Comparable<T>` in der Klasse `ProductionRemoteControlCar`.
Die standardmäßige Sortierreihenfolge der Autos soll nach der Anzahl der Siege absteigend sein.

Implementiere die statische Methode `TestTrack.getRankedCars()`, die die übergebenen Autos zurückgibt, absteigend nach der Anzahl der Siege sortiert.

```java
ProductionRemoteControlCar prc1 = new ProductionRemoteControlCar();
ProductionRemoteControlCar prc2 = new ProductionRemoteControlCar();
prc1.setNumberOfVictories(2);
prc2.setNumberOfVictories(3);
List<ProductionRemoteControlCar> unsortedCars = new ArrayList<>();
unsortedCars.add(prc1);
unsortedCars.add(prc2);
List<ProductionRemoteControlCar> rankings = TestTrack.getRankedCars(unsortedCars);
// => rankings.get(0) == prc2
// => rankings.get(1) == prc1
```
