# Anleitung

Deine Aufgabe ist es, herauszufinden, was Bob antwortet, wenn ihm jemand etwas sagt oder ihm eine Frage stellt.

Bob antwortet immer nur auf eine von fünf Arten:

- **„Sure.“**
  So antwortet er, wenn du ihm eine Frage stellst, zum Beispiel „How are you?“
  Die Konvention für Fragen ist, dass sie mit einem Fragezeichen enden.
- **„Whoa, chill out!“**
  So antwortet er, wenn du ihn anschreist.
  Die Konvention für Schreien ist, alles in Großbuchstaben zu schreiben.
- **„Calm down, I know what I'm doing!“**
  Das sagt er, wenn du ihm eine Frage entgegenschreist.
- **„Fine. Be that way!“**
  So reagiert er auf Stille.
  Die Konvention für Stille ist nichts oder verschiedene Kombinationen von Whitespace-Zeichen.
- **„Whatever.“**
  Das antwortet er auf alles andere.
