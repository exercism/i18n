# Überblick

C#-Typen können innerhalb des Gültigkeitsbereichs einer Klasse oder eines Structs definiert werden. Der umschließende Typ stellt eine Art Namespace bereit. Auf den Typ greifst du über den umschließenden Typ mit Punktnotation zu.

```csharp
class Outer
{
    public interface IInner {}
    public enum EInner {}
    public class CInner {}
    public struct SInner {}
}

var outer = new Outer();
var inner = new Outer.CInner();
```

## Zugriffsebenen

Auf die inneren Typen können Zugriffsebenen angewendet werden. Wenn eine Klasse zum Beispiel `private` ist, ist sie außerhalb des Gültigkeitsbereichs des umschließenden Typs nicht sichtbar, und natürlich sind Instanzen außerhalb dieses Bereichs weder sichtbar noch nutzbar.

Die privaten Member der äußeren Klasse liegen für alle Member der inneren Klasse im Gültigkeitsbereich, aber nur die nicht-privaten Member der inneren Klasse liegen für die Member der äußeren Klasse im Gültigkeitsbereich. Um auf die Member der äußeren Klasse zugreifen zu können, muss der inneren Klasse eine Instanz der äußeren Klasse übergeben werden.

Das siehst du im folgenden Beispiel:

```csharp
class Outer
{
    public class InnerImpl
    {
        private Outer outer;

        public int Interesting = 42;

        public InnerImpl(Outer outer, int interesting)
        {
            this.outer = outer;
            Interesting = interesting;
        }

    }

    public InnerImpl Inner;
    public Outer()
    {
        Inner = new InnerImpl(this, 42);
    }
}

var outer = new Outer();
outer.Inner.Interesting
// => 42
var inner = new Outer.InnerImpl(outer, 1729);
outer.Inner.Interesting
// => 1729
```

## Unabhängige Instanziierung verhindern

Es gibt ein Muster, mit dem du verhinderst, dass ein instanziierbarer Typ außerhalb des umschließenden Typs erzeugt wird. Du stellst eine öffentliche Schnittstelle bereit, behältst aber die implementierende Klasse privat.

```csharp
class Outer
{
    public interface IInner
    {
        void DoSomething();
    }

    private class InnerImpl : IInner
    {
        private Outer outer;
        public InnerImpl(Outer outer)
        {
            this.outer = outer;
        }
        public void DoSomething()
        {
            outer.DoSomethingElse();
        }
    }

    public IInner Inner;

    public Outer()
    {
        Inner = new InnerImpl(this);
    }
    private void DoSomethingElse()
    {
    }
}

var outer = new Outer();
outer.Inner.DoSomething();

// NOT var inner = new Outer.Inner(outer);
```

## Hinweis für Java-Entwickler

Die verschachtelten Klassen von C# sind eine Mischung aus den statischen verschachtelten Klassen und den inneren Klassen von Java. In C# liegen die privaten Member der umschließenden Klasse für die Member der verschachtelten Klasse im Gültigkeitsbereich, aber es gibt keine besondere Syntax, um sie zu instanziieren und mit einer Instanz der umschließenden Klasse zu verknüpfen. Du musst eine Variante des Musters verwenden, das in den obigen Beispielen gezeigt wird.

C# hat zwar statische verschachtelte Klassen, aber das sind einfach eingeschlossene Klassen mit statischem Verhalten.
