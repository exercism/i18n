# Einführung

## Zeichen

Der primitive Java-Typ `char` ist eine 16-Bit-Darstellung eines einzelnen Zeichens.
Mehrere `char`s können zusammen einen String bilden, wie zum Beispiel `"word"`, oder `char`s können unabhängig voneinander verarbeitet werden.
Ein `char`-Literal wird von einfachen Anführungszeichen umschlossen (z. B. `'A'`).

```java
char lowerA = 'a';
char upperB = 'B';
```

## Die `char`s eines `String` ermitteln

Die Methode `String.toCharArray` gibt die Zeichen eines Strings als Array zurück.
Wie bereits bei den Arrays erwähnt, kannst du eine `for`-Schleife verwenden, um über das Array zu iterieren.

```java
String text = "Hello";
char[] asArray = text.toCharArray();

for (char ch: asArray) {
    System.out.println(ch);
}

// Outputs:
// H
// e
// l
// l
// o
```

## Die Character-Klasse

Es gibt viele eingebaute Methoden der Standardbibliothek, um `char`s zu untersuchen und zu bearbeiten.
Du findest sie als statische Methoden der Klasse `java.lang.Character`.
Hier sind einige Beispiele:

```java
Character.isWhitespace(' ');    // true
Character.isWhitespace('#');    // false

Character.isLetter('a');        // true
Character.isLetter('3');        // false

Character.isDigit('6');         // true
Character.isDigit('?');         // false
```

## Ein `char` zu einem `String` hinzufügen

Mit dem Operator `+` kannst du ein `char` zu einem `String` hinzufügen.

```java
'a' + " banana"     // => "a banana"
"banana " + 'a'     // => "banana a"
```

~~~~exercism/caution
Achte darauf, `+` _nicht_ zu verwenden, um zwei `char`s zu einem `String` zusammenzufügen!
Wenn du zwei `char`s so addierst, erhältst du ein `int`, _nicht_ einen `String`!
Zum Beispiel:

```java
'b' + 'c';
// => 197 (not the String "bc")
```

Das liegt daran, dass Java das `char` zu einem `int` hochstuft (siehe [4.2 Primitive Types and Values ][jls-primitives] der [Java Language Specification][jls-main]).

[jls-main]: https://docs.oracle.com/javase/specs/jls/se21/html/
[jls-primitives]: https://docs.oracle.com/javase/specs/jls/se21/html/jls-4.html#jls-4.2
~~~~

Wenn du allerdings viele Zeichen aneinanderfügen möchtest, kann es effizienter sein, stattdessen einen `StringBuilder` zu verwenden:

```java
StringBuilder builder = new StringBuilder();
builder.append('a');
builder.append('b');
builder.append('c');

String builtString = builder.toString();
// => abc
```
