# Einführung

Neben der `if`-Anweisung gibt es auch eine `switch`-Anweisung, um Logik bedingt auszuführen. Du verwendest sie, wenn du eine einzelne Variable mit mehreren Varianten vergleichen musst. Für eine Variable x hat die `switch`-Anweisung in Haxe die folgende Syntax:

```haxe
var a = 2;

switch (a) {
  case 0:
    trace("a is 0");
  case 1:
    trace("a is 1");
  case 2:
    trace("a is 2");
  default:
    trace("a is something else");
}

// a is 2
```

Der `default`-Fall wird ausgeführt, wenn kein anderer Fall zutrifft.
