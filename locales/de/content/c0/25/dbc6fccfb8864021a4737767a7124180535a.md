# Tests

## Clojure CLI

Die Clojure-Übungen auf Exercism werden mit einer `deps.edn`-Datei ausgeliefert, die einen `:test`-Alias enthält, um den [cognitect-labs test-runner](https://github.com/cognitect-labs/test-runner) aufzurufen:

``` bash
$ clj -X:test
```

Damit durchsucht er das `test`-Verzeichnis deines Projekts nach allen Tests, die mit `clojure.test` definiert sind, und führt sie aus.

## Leiningen

Um die Tests einer Übung mit Leiningen auszuführen, ruf einfach Folgendes auf:

``` bash
$ lein test

lein test bob-test

Ran 14 tests containing 14 assertions.
0 failures, 0 errors.
```
