# Einführung

Eine Datei ist im Grunde nur ein Stream mit einem Namen auf der Festplatte. Das Vokabular [`io.files`][io.files] gibt dir zwei Möglichkeiten, mit einer zu arbeiten: bequeme Wörter für ganze Dateien, die alles in einem einzigen Aufruf lesen oder schreiben, und Stream-Öffner für den Fall, dass du schrittweise lesen oder schreiben möchtest.

Jedes Wort, das auf eine Datei zugreift, braucht eine **Kodierung**: das Schema, das Bytes in Zeichen und zurück umwandelt. Für Text ist das fast immer [`utf8`][utf8] aus `io.encodings.utf8`.

## Eine ganze Datei lesen

```
file-contents   ( path encoding -- str )
file-lines      ( path encoding -- seq )
```

`file-contents` gibt die ganze Datei als einen String zurück; `file-lines` gibt ein Array ihrer Zeilen zurück, wobei die Zeilenumbrüche entfernt sind.

```factor
USING: io.encodings.utf8 io.files prettyprint ;

"sunny\ncloudy\n" "forecast.txt" utf8 set-file-contents

"forecast.txt" utf8 file-contents .
! => "sunny\ncloudy\n"

"forecast.txt" utf8 file-lines .
! => { "sunny" "cloudy" }
```

## Eine ganze Datei schreiben

```
set-file-contents   ( str path encoding -- )
set-file-lines      ( seq path encoding -- )
```

Beide **ersetzen** den Inhalt der Datei (und legen sie an, falls nötig). `set-file-contents` schreibt einen String unverändert; `set-file-lines` schreibt jedes Element einer Sequenz in eine eigene Zeile und fügt die Zeilenumbrüche für dich hinzu.

```factor
USING: io.encodings.utf8 io.files prettyprint ;

{ "sunny" "cloudy" } "forecast.txt" utf8 set-file-lines
"forecast.txt" utf8 file-contents .
! => "sunny\ncloudy\n"
```

## An eine Datei anhängen

Um etwas an eine Datei anzuhängen, ohne zu löschen, was schon da ist, öffnest du sie mit einem `with-…`-Kombinator und schreibst innerhalb der Quotation in den umgebenden Stream:

```
with-file-appender   ( path encoding quot -- )
with-file-reader     ( path encoding quot -- )
with-file-writer     ( path encoding quot -- )
```

```factor
USING: io io.encodings.utf8 io.files prettyprint ;

"sunny\ncloudy\n" "forecast.txt" utf8 set-file-contents
"forecast.txt" utf8 [ "rainy" print ] with-file-appender
"forecast.txt" utf8 file-contents .
! => "sunny\ncloudy\nrainy\n"
```

Wie jeder `with-…`-Kombinator sind diese Destruktor-Gültigkeitsbereiche: Das Datei-Handle wird geschlossen, wenn die Quotation endet, selbst wenn sie eine Ausnahme wirft.
