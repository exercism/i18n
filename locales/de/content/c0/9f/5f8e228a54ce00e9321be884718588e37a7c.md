# Anleitung

Die Arbeit am ferngesteuerten Auto geht weiter. Die Bandbreite im Telemetriesystem ist äußerst knapp, und du wurdest gebeten, ein Nachrichtenprotokoll für die Übertragung von Telemetriedaten zu implementieren.

Die Daten werden in einem Puffer (Byte-Array) übertragen. Beim Senden von Ganzzahlen wird die Größe des Puffers reduziert, indem das unten beschriebene Protokoll verwendet wird.

Jeder Wert sollte im kleinstmöglichen Ganzzahltyp dargestellt werden (die Typen `byte` und `sbyte` sind nicht enthalten, da die Einsparung vernachlässigbar wäre):

| Von                        | Bis                       | Typ      |
| -------------------------- | ------------------------- | -------- |
| 4_294_967_296              | 9_223_372_036_854_775_807 | `long`   |
| 2_147_483_648              | 4_294_967_295             | `uint`   |
| 65_536                     | 2_147_483_647             | `int`    |
| 0                          | 65_535                    | `ushort` |
| -32_768                    | -1                        | `short`  |
| -2_147_483_648             | -32_769                   | `int`    |
| -9_223_372_036_854_775_808 | -2_147_483_649            | `long`   |

Der Wert sollte in die passende Anzahl von Bytes für seinen zugewiesenen Typ umgewandelt werden. Der vollständige Puffer besteht aus einem Byte, das die Anzahl der zusätzlichen Bytes im Puffer angibt (_Präfixbyte_), gefolgt von den Bytes, die die Ganzzahl enthalten (_Nutzbytes_).

Einige der Typen verwenden eine identische Anzahl von Bytes (z. B. die Typen `uint` und `int`). Normalerweise hätten sie dasselbe _Präfixbyte_, aber das würde die Dekodierung problematisch machen. Um dem entgegenzuwirken, führt das Protokoll einen kleinen Trick ein: Bei vorzeichenbehafteten Typen ist der Wert ihres _Präfixbytes_ `256` minus der Anzahl der zusätzlichen Bytes im Puffer.

In der Kommunikation werden nur das Präfixbyte und die Anzahl der darauffolgenden Bytes gesendet, die das Präfix angibt. Intern wird sowohl beim Senden als auch beim Empfangen ein 9 Byte großer Puffer verwendet (mit abschließenden Nullen, falls nötig).

## 1. Einen Ganzzahlwert zum Senden kodieren

Bitte implementiere die statische Methode `TelemetryBuffer.ToBuffer()`, die einen Puffer kodiert und dabei den an die Methode übergebenen Parameter verwendet.

```csharp
// Type: ushort, bytes: 2, signed: no, prefix byte: 2
TelemetryBuffer.ToBuffer(5)
// => {0x2, 0x5, 0x0, 0x0, 0x0, 0x0, 0x0, 0x0, 0x0 };

// Type: int, bytes: 4, signed: yes, prefix byte: 256 - 4
TelemetryBuffer.ToBuffer(Int32.MaxValue)
// => {0xfc, 0xff, 0xff, 0xff, 0x7f, 0x0, 0x0, 0x0, 0x0 };
```

## 2. Einen empfangenen Puffer dekodieren

Bitte implementiere die statische Methode `TelemetryBuffer.FromBuffer()`, um den empfangenen Puffer zu dekodieren und den Wert in Form eines `long` zurückzugeben.

```csharp
TelemetryBuffer.FromBuffer(new byte[] {0xfc, 0xff, 0xff, 0xff, 0x7f, 0x0, 0x0, 0x0, 0x0 })
// => 2147483647
```

Wenn das Präfixbyte einen unerwarteten Wert hat, sollte `0` zurückgegeben werden.
