# Hinweise

## Allgemeines

- In dieser Übung geht es darum, einen [_Stack_][Baeldung: The Stack Data Structure] mithilfe einer [einfach verknüpften Liste][singly linked list] zu erstellen.
- Anders als bei Stacks, die auf `lists`, `collections.deque` oder `queue.LifoQueue` aufbauen, bitten wir dich, eigene `Node`- und `LinkedList`-[`classes`][classes tutorial] zu erstellen, um Elemente zu speichern und zu verknüpfen.

![Diagramm, das einen Stack darstellt, der mit einer verknüpften Liste umgesetzt ist. Ganz links befindet sich ein Kreis mit gestricheltem Rand namens New_Node, von dem zwei gepunktete Pfeillinien nach rechts zeigen. New_Node liest „(becomes head) - New_Node - next = node_6". Die obere gepunktete Pfeillinie ist mit „push" beschriftet und zeigt nach oben rechts auf Node_6. Node_6 liest „(current) head - Node_6 - next = node_5". Die untere gepunktete Pfeillinie ist mit „pop" beschriftet und zeigt auf ein Kästchen, das „gets removed on pop()" liest. Node_6 hat einen durchgezogenen Pfeil, der nach rechts auf Node_5 zeigt, der „Node_5 - next = node_4" liest. Node_5 hat einen durchgezogenen Pfeil, der nach rechts auf Node_4 zeigt, der „Node_4 - next = node_3" liest. Dieses Muster setzt sich fort bis Node_1, der „(current) tail - Node_1 - next = None" liest. Node_1 hat einen gepunkteten Pfeil, der nach rechts auf einen Knoten zeigt, der „None" sagt.](https://assets.exercism.org/images/tracks/python/simple-linked-list/linked-list.svg)

- [Real Python: Linked Lists][Real Python Linked Lists], [Towards Data Science: Demystifying the Linked List][towards data science demystifying the linked list] und [ADS Stack in Python][Koder Dojo Coding an ADS Stack in Python] können hilfreich sein, wenn du Details zur Umsetzung nachlesen möchtest.
- Deine `LinkedList` sollte ein `list`-Argument an ihren _Konstruktor_ akzeptieren, aber keine `list` verwenden, um Knoten oder Elemente zu speichern.
- `len()` ist eine eingebaute Funktion für die meisten Python-Objekte.
Damit _benutzerdefinierte Objekte_ `len()` unterstützen, muss die spezielle Methode [`__len__`][__len__] definiert werden.
- Iteration wird in Python für die meisten Objekte der Typen Sequenz, Container oder Collection unterstützt.
Damit ein _benutzerdefiniertes_ Objekt Schleifen oder Umordnungen unterstützt, muss die spezielle Methode `__iter__` definiert werden.
[Einen Iterator für eine Klasse implementieren][implementing iterators] kann dir zeigen, wie das geht.
