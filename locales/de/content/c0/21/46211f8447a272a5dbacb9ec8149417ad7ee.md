# Einführung

Cairo stellt Wörterbücher als Teil seiner Kernbibliotheken bereit, die durch den Typ `Felt252Dict<T>` repräsentiert werden.

Der Schlüsseltyp eines Wörterbuchs ist in Cairo auf `felt252` beschränkt. Das unterscheidet sich von anderen Sprachen, in denen man den Typ des Schlüssels selbst festlegen kann.

Um ein Wörterbuch zu erstellen, kannst du die Methode `default` des Traits `Default` verwenden, etwa so:

```rust
let mut foo: Felt252Dict<u32> = Default::default();
```

Die grundlegenden Operationen, die am häufigsten verwendet werden, sind:

1. `insert(felt252, T) -> ()`, um Werte in eine Wörterbuch-Instanz zu schreiben, und
2. `get(felt252) -> T`, um Werte daraus zu lesen.

Und so verwendest du diese Operationen:

```rust
let mut foo: Felt252Dict<u32> = Default::default();
// Add a value to the dictionariy
foo.insert('bar', 42);
// Here we update the element of 'bar'
foo.insert('bar', 73);
// To retrieve a dictionary value, you can use
baz = foo.get('bar');
```

Wenn du den Wert für einen Schlüssel abrufen willst, der nicht im Wörterbuch existiert, wird der Nullwert des Werttyps zurückgegeben.

Das kann verwirrend sein, besonders wenn der Standardwert deines Werttyps (zum Beispiel 0 bei einer Ganzzahl) ein gültiger Wert ist.

Das bedeutet außerdem, dass es keine Möglichkeit gibt, Daten aus einem Wörterbuch zu löschen.

Das solltest du bedenken, wenn du diese Struktur in deinen Code einbaust.
