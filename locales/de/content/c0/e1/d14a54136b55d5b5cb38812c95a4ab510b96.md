# Anleitung

Gegeben sei ein Eingabetext, gib ihn transponiert aus.

Grob erklärt ist die Transponierte einer Matrix:

```text
ABC
DEF
```

gegeben durch:

```text
AD
BE
CF
```

Zeilen werden zu Spalten und Spalten werden zu Zeilen. Siehe <https://en.wikipedia.org/wiki/Transpose>.

Wenn die Eingabe Zeilen unterschiedlicher Länge hat, gehst du wie folgt vor:

- Fülle links mit Leerzeichen auf.
- Rechts wird nicht aufgefüllt.

Deshalb ergibt das Transponieren dieser Matrix:

```text
ABC
DE
```

Folgendes:

```text
AD
BE
C
```

Und das Transponieren von:

```text
AB
DEF
```

ergibt:

```text
AD
BE
 F
```

Im Allgemeinen sollten alle Zeichen aus der Eingabe auch in der transponierten Ausgabe vorkommen.
Das heißt, wenn eine Spalte im Eingabetext in ihrer untersten Zeile (oder den untersten Zeilen) nur Leerzeichen enthält, sollte die entsprechende Ausgabezeile die Leerzeichen in ihrer rechtesten Spalte (oder den rechtesten Spalten) enthalten.
