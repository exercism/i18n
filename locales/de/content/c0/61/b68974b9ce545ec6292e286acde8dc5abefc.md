# Einführung

Jede Instanz eines Structs oder einer Klasse hat eine implizite Eigenschaft namens `self`, die auf die Instanz selbst verweist.
Am häufigsten wird `self` verwendet, um zwischen einer Instanzeigenschaft und einem Parameter mit demselben Namen zu unterscheiden:

```swift
struct Position {
    var x = 0

    mutating func move(x: Int) {
        // Here, 'self.x' refers to the struct's property,
        // while 'x' refers to the parameter passed to the method.
        self.x = x
    }
}
```

Swift-Typen bieten außerdem das großgeschriebene Schlüsselwort `Self`, das auf den *Typ* der Instanz verweist und nicht auf die Instanz selbst.
