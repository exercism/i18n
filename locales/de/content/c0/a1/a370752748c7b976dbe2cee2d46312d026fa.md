# Über Ceylon

Ceylon ist eine universell einsetzbare Programmiersprache mit einer Syntax, die an Java und C# erinnert. Sie ist imperativ, statisch typisiert, blockstrukturiert, objektorientiert und höherer Ordnung. Mit _statisch typisiert_ meinen wir, dass der Compiler mithilfe von Typannotationen, die im Code stehen, eine umfangreiche Typprüfung durchführt. Mit _objektorientiert_ meinen wir, dass die Sprache benutzerdefinierte Typen unterstützt und ein nominatives Typsystem bietet, in dem ein Typ eine Menge benannter Attribute und Operationen ist, und dass sie Vererbung und Subtyppolymorphismus unterstützt. Mit _höherer Ordnung_ meinen wir, dass jedes referenzierbare Programmelement (jedes Attribut, jede Operation und jeder Typ) zugleich ein Wert ist. Mit _blockstrukturiert_ meinen wir, dass die Sprache lexikalische Gültigkeitsbereiche und eine äußerst regelmäßige, rekursive Syntax für Deklarationen und Anweisungen bietet.

Ceylon baut auf der Sprache Java und ihrem Typsystem auf und macht den Code dadurch weniger weitschweifig und typsicherer als bei Java und C#. Ceylon fördert einen funktionaleren, etwas weniger imperativen Programmierstil. Der Code lässt sich dadurch leichter nachvollziehen und einfacher refaktorisieren.
