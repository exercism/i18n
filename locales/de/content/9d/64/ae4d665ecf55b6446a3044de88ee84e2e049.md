# Ergänzung zur Aufgabenstellung

## Umsetzung

Um diese Übung abzuschließen, musst du die Struktur implementieren. Definiere dazu den Datentyp `school` und implementiere die folgenden Funktionen:

- newSchool
- add
- roster
- grade

Kapitel 3 von [Notes on Programming SML/NJ][notes] behandelt die Verwendung von Signaturen und Strukturen.
