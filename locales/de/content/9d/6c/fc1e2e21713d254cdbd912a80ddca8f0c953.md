# Überblick

[Wörtliche Strings][verbatim-strings] erlauben mehrzeilige Strings. Sie werden mit einem @ eingeleitet. Sie lassen sich auch mit String-Interpolation verwenden. Setze einfach ein „\$“ vor das öffnende Anführungszeichen.

```csharp
string str = @"
See no wretched
quotes everywhere
";
```

[verbatim-strings]: https://docs.microsoft.com/en-us/dotnet/csharp/programming-guide/strings/#regular-and-verbatim-string-literals
