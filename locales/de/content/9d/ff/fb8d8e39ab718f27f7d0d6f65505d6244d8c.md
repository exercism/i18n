# Ergänzung zu den Anweisungen

Die Ausgabe sollte in [zeilenweiser Anordnung](https://en.wikipedia.org/wiki/Row-_and_column-major_order) erfolgen: zuerst alle Wörter der ersten Zeile, dann die Wörter der zweiten Zeile und so weiter.

## Register

| Register | Verwendung   | Typ     | Beschreibung                        |
| -------- | ------------ | ------- | ----------------------------------- |
| `$a0`    | Eingabe      | Ganzzahl | Größe                               |
| `$a1`    | Eingabe/Ausgabe | Adresse | Matrix aus Wörtern, in zeilenweiser Anordnung |
| `$v0`    | Ausgabe      | Ganzzahl | Anzahl der Wörter in der Matrix     |
| `$t0-9`  | temporär     | beliebig | für die temporäre Speicherung       |
