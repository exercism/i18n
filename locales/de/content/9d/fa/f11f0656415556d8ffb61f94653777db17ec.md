# Anleitung

In dieser Übung schreibst du Code, um die Produktion in einer Autofabrik zu analysieren.

## 1. Berechne die Anzahl der funktionierenden Autos, die pro Stunde produziert werden

Die Autos werden am Fließband produziert.
Das Fließband hat eine bestimmte Geschwindigkeit, die sich ändern lässt.
Je schneller das Fließband läuft, desto mehr Autos werden produziert.
Wenn du jedoch die Geschwindigkeit des Fließbands änderst, ändert sich auch die Anzahl der Autos, die erfolgreich produziert werden, also der Autos ohne Fehler in ihrer Produktion.

Implementiere eine Funktion, die die Anzahl der pro Stunde produzierten Autos und die Erfolgsquote entgegennimmt und die Anzahl der pro Stunde erfolgreich hergestellten Autos berechnet.
Die Erfolgsquote wird als Prozentwert angegeben, von `0` bis `100`:

```go
CalculateWorkingCarsPerHour(1547, 90)
// => 1392.3
```

**Hinweis:** Der Rückgabewert sollte ein `float64` sein.

## 2. Berechne die Anzahl der funktionierenden Autos, die pro Minute produziert werden

Implementiere eine Funktion, die die Anzahl der pro Stunde produzierten Autos und die Erfolgsquote entgegennimmt und berechnet, wie viele Autos pro Minute erfolgreich produziert werden:

```go
CalculateWorkingCarsPerMinute(1105, 90)
// => 16
```

**Hinweis:** Der Rückgabewert sollte ein `int` sein.

## 3. Berechne die Produktionskosten

Jedes Auto kostet normalerweise 10.000 $ in der Einzelproduktion, unabhängig davon, ob es erfolgreich ist oder nicht.
Mit etwas Planung lassen sich aber 10 Autos zusammen für 95.000 $ produzieren.

Zum Beispiel lassen sich 37 Autos so produzieren:
37 = 3 x Gruppen zu zehn + 7 einzelne Autos

Die Kosten für 37 Autos sind also:
3\*95.000+7\*10.000=355.000

Implementiere die Funktion `CalculateCost`, die die Kosten für die Produktion einer Anzahl von Autos berechnet, unabhängig davon, ob sie erfolgreich sind:

```go
CalculateCost(37)
// => 355000

CalculateCost(21)
// => 200000
```

**Hinweis:** Der Rückgabewert sollte ein `uint` sein.
