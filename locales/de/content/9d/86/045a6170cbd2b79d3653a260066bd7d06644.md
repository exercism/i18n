# Installation

Für diese Übungen verwenden wir den beliebten MIPS-Simulator [MARS](https://dpetersanderson.github.io/Help/MarsHelpIntro.html). Lade das JAR-Archiv von MARS von [GitHub](https://github.com/dpetersanderson/MARS/releases) herunter und lege es an einem gut erreichbaren Ort ab. Installiere außerdem das Java SDK, falls du es noch nicht hast.
