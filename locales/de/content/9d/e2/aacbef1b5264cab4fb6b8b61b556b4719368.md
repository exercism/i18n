# Tests

Mit einer Clojurescript-REPL kannst du ganz einfach Code ausführen und bekommst sofort Feedback. Du kannst sie auch verwenden, um Tests auszuführen.

## Leiningen
Um eine REPL mit der Clojure CLI zu öffnen, wechsle in das Verzeichnis, das die Übung enthält, und führe Folgendes aus:
``` bash
$ clojure -m cljs.main -re node
```

Beachte, dass Node auf deinem System installiert sein muss.

Sobald du bereit bist, an einer Übung zu arbeiten, und eine Datei für deine Lösung erstellt hast (zum Beispiel `bob.cljs`), kannst du die Tests in deinem Terminal mit `$ clojure -A:test` ausführen.

Zuerst lädst du den Test-Namensraum mit `require`:
``` clojure
=> (require 'bob-test)
nil
;; and the test namespace
=> (require 'cljs.test)
```

Wechsle mit ns in den Test-Namensraum:
```clojure
=> (ns bob-test)
nil
```

Dann rufst du `run-tests` für `bob-test` auf:
``` clojure
=> (cljs.test/run-tests)

Testing bob-test

Ran 14 tests containing 14 assertions.
0 failures, 0 errors.
{:test 14, :pass 14, :fail 0, :error 0, :type :summary}
```

Um die Tests einer Übung mit der Clojure CLI auszuführen, rufst du einfach Folgendes auf:
``` bash
$ clojure -M:test

Testing bob-tests

Ran 14 tests containing 14 assertions.
0 failures, 0 errors.
```
