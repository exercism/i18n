# Lernen

- [The Zig Programming Language Documentation][documentation] ist ein großartiger Überblick über alle Sprachfeatures, die Zig bietet.
- [Awesome Zig][awesome-zig] ist eine gute Sammlung von Zig-Projekten, die von verschiedenen Leuten erstellt wurden.
  Die Sammlung enthält Projekte mit gut entwickeltem Zig-Code.
- [Zighelp][zighelp] ist eine hervorragende Einführung, die die Sprachfeatures erklärt, die Zig zu bieten hat.
- [Ziglings][ziglings] ist sehr empfehlenswert.
  Lerne Zig, indem du kleine fehlerhafte Programme reparierst.
- [Zig SHOWTIME][zig-showtime] ist eine Live-Stream-Show, in der Mitglieder der Zig-Community Code und Ideen austauschen.

[awesome-zig]: https://github.com/catdevnull/awesome-zig
[documentation]: https://ziglang.org/documentation/master/
[zighelp]: https://zighelp.org/
[zig-showtime]: https://zig.show/
[ziglings]: https://codeberg.org/ziglings/exercises
