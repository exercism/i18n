# Anleitung

In dieser Übung schreibst du Code, der einem Schilderunternehmen dabei hilft, individuelle Nachrichten für seine Schilder zu erstellen.

## 1. Erstelle eine Reihe nützlicher Strings

Definiere die folgenden konstanten Strings, die zum Erstellen von Schildern verwendet werden:

- `birthday`: Enthält den Wert „Birthday“
- `valentine`: Enthält den Wert „Valentine's Day“
- `anniversary`: Enthält den String „Anniversary“

## 2. Erstelle eine Reihe nützlicher Zeichen

Definiere die folgenden konstanten Zeichen, die zum Erstellen von Schildern verwendet werden:

- `space`: Enthält den Wert „ “ (ein einzelnes Leerzeichen)
- `exclamation`: Enthält den Wert „!“

## 3. Kombiniere Phrasen zu Nachrichten

Implementiere die Funktion `buildSign(for:name:)`. Sie nimmt das Argument `for` entgegen, das einen der drei Strings enthält, die du in der ersten Aufgabe definiert hast, und das Argument `name`, einen String mit dem Namen der Person, für die das Schild bestimmt ist.
Verwende Konkatenation, um die Nachricht für das Schild zusammenzusetzen, und denk daran, die bereits definierten Konstanten wiederzuverwenden.
Die Funktion soll die Nachricht des Schilds als String zurückgeben.

```swift
buildSign(for: birthday, name: "Otto")
// returns "Happy Birthday Otto!"

buildSign(for: anniversary, name: "Valentina")
// returns "Happy Anniversary Valentina!"
```

## 4. Erstelle ein Abschlussschild

Implementiere die Funktion `graduationFor(name:year:)`. Sie nimmt das Argument `name` entgegen, einen String mit dem Namen der Person, für die das Schild bestimmt ist, und das Argument `year`, eine Ganzzahl mit dem Jahr, in dem die Person ihren Abschluss macht.
Verwende Template-Strings, um die Nachricht für das Schild aufzubauen.
Die Funktion soll die Nachricht des Schilds als String zurückgeben.

```swift
graduationFor(name: "Padma", year: 2023)
// returns "Congratulations Padma!\nClass of 2023"
```

## 5. Berechne die Kosten für ein Schild

Implementiere die Funktion `costOf(sign:)`. Sie nimmt das Argument `sign` entgegen, einen String mit der Nachricht für das Schild.
Das Schild hat einen Grundpreis von 20 in der gegebenen Währung. Zusätzlich kostet jeder Buchstabe 2 (Leerzeichen werden in die Berechnung einbezogen).
Die Funktion soll die Kosten des Schilds als Ganzzahl zurückgeben.

```swift
costOf(sign: "Happy Birthday Grandma!")
// returns 66
```
