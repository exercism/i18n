# Anleitung

In dieser Übung implementierst du eine Möglichkeit, die Bestenliste für das beliebteste Spiel in deiner örtlichen Spielhalle zu verwalten.

## 1. Spieler zur Bestenliste hinzufügen

Um einen Spieler zur Bestenliste hinzuzufügen, definiere zwei `add_player!`-Methoden, die folgende Argumente entgegennehmen:

- Das erste Argument ist das Wörterbuch der Punktestände.
- Das zweite Argument ist der Name eines Spielers als String.
- Das dritte Argument ist der Punktestand als Ganzzahl.
  Dieses Argument ist optional. Wenn kein Wert angegeben wird, sollte der Punktestand auf 0 gesetzt werden.

```julia-repl
julia> scores = Dict{String, Int}()
Dict{String, Int64}()

julia> add_player!(scores, "Liselot", 486373)
Dict{String, Int64} with 1 entry:
  "Liselot" => 486373

julia> add_player!(scores, "Éimhín")
Dict{String, Int64} with 2 entries:
  "Liselot" => 486373
  "Éimhín"  => 0
```

## 2. Spieler von der Bestenliste entfernen

Um einen Spieler von der Bestenliste zu entfernen, definiere `remove_player!`, das 2 Argumente entgegennimmt:

- Das erste Argument ist das Wörterbuch der Punktestände.
- Das zweite Argument ist der Name des Spielers als String.

```julia-repl
julia> scores = Dict(
           "Liselot" => 486373,
           "Éimhín"  => 0,
       )
Dict{String, Int64} with 2 entries:
  "Liselot" => 486373
  "Éimhín"  => 0

julia> remove_player!(scores, "Liselot")
Dict{String, Int64} with 1 entry:
  "Éimhín" => 0
```

## 3. Den Punktestand eines Spielers aktualisieren

Um den Punktestand eines Spielers zu aktualisieren, indem du den vorherigen Punktestand ersetzt, definiere `update_score!`, das 3 Argumente entgegennimmt:

- Das erste Argument ist das Wörterbuch der Punktestände.
- Das zweite Argument ist der Name des Spielers als String, dessen Punktestand du aktualisieren möchtest.
- Das dritte Argument ist der Punktestand, auf den du den gespeicherten Punktestand setzen möchtest.

```julia-repl
julia> scores = Dict(
           "Liselot" => 486373,
           "Éimhín"  => 0,
       )
Dict{String, Int64} with 2 entries:
  "Liselot" => 486373
  "Éimhín"  => 0

julia> update_score!(scores, "Éimhín", 89479) # TODO: Should this return the dict?
89479

julia> scores
Dict{String, Int64} with 2 entries:
  "Liselot" => 486373
  "Éimhín"  => 89479
```

## 4. Den Punktestand eines Spielers zurücksetzen

Um den Punktestand eines Spielers zurückzusetzen, definiere `reset_score!`, das 2 Argumente entgegennimmt:

- Das erste Argument ist das Wörterbuch der Punktestände.
- Das zweite Argument ist der Name des Spielers als String, dessen Punktestand du zurücksetzen möchtest.

```julia-repl
julia> scores = Dict(
           "Liselot" => 486373,
           "Éimhín"  => 0,
       )
Dict{String, Int64} with 2 entries:
  "Liselot" => 486373
  "Éimhín"  => 0

julia> reset_score!(scores, "Liselot") # TODO: Should this return the dict?
0

julia> scores

  "Liselot" => 0
  "Éimhín"  => 0
```

## 5. Eine Liste der Spieler abrufen

Um eine Liste der Spieler abzurufen, definiere `players`, das 1 Argument entgegennimmt:

- Das erste Argument ist das Wörterbuch der Punktestände.

```julia-repl
julia> scores = Dict(
           "Liselot" => 486373,
           "Éimhín"  => 0,
       )
Dict{String, Int64} with 2 entries:
  "Liselot" => 486373
  "Éimhín"  => 0

julia> players(scores)
2-element Vector{String}:
 "Liselot"
 "Éimhín"
```
