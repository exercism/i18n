# Ergänzung zur Anleitung

## Einen induktiven Typ definieren

Diese Übung erwartet als Rückgabewert einen [induktiven Typ][inductive] `Classification`, den du selbst definieren musst.

Dieser Typ muss eine [BEq][beq]-Instanz haben, also einen booleschen Gleichheitstest zulassen, und eine [Repr][repr]-Instanz, das heißt, Werte des Typs lassen sich für die Ausgabe formatieren.

Wie du Instanzen deklarierst, erfährst du auf [dieser Seite][instance].
Lean kann für viele Klassen automatisch [Instanzen generieren][deriving].

## Untertypen

Das Argument der Funktion `classify` ist ein [Untertyp][subtype] namens `Positive`:

```
def Positive := { x : Nat // x > 0 }
```

Untertypen repräsentieren Elemente eines bestimmten Typs, die ein Prädikat erfüllen.
`Positive` repräsentiert die Elemente von `Nat`, die größer als `0` sind.

Jedes Element eines Untertyps kann man sich als Paar vorstellen, das aus einem Wert des zugrunde liegenden Typs und einem Beweis im mathematischen Sinn besteht, dass dieser Wert das entsprechende Prädikat erfüllt.

Untertypen erzwingen Invarianten auf Typebene und stellen so sicher, dass sich fehlerhaft gebildete Werte nicht konstruieren lassen.
