# Hinweise

## 1. Eine Karte aus einem Stapel entnehmen

- Die Indizes von `Vector` beginnen bei `1`.
- Du kannst den `n`-ten Wert in einem Vektor `v` mit `v[n]` abrufen.

## 2. Eine Karte im Stapel austauschen

- `Vector`s sind veränderbar, du kannst ihren Inhalt jederzeit ändern, indem du einen neuen Wert zuweist.

## 3. Eine Karte oben auf den Stapel legen

- In Base gibt es eine Methode [`push!`][push], um einen neuen Wert am Ende einer Sammlung hinzuzufügen.

## 4. Eine Karte aus dem Stapel entfernen

- In Base gibt es eine Methode [`deleteat!`][deleteat], um ein Element an einem gegebenen Index aus einem `Vector` zu löschen.

## 5. Die oberste Karte vom Stapel entfernen

- In Base gibt es eine Methode [`pop!`][pop], um ein Element am Ende einer Sammlung zu entfernen.

## 6. Eine Karte unten in den Stapel einfügen

- In Base gibt es eine Methode [`pushfirst!`][pushfirst], um einen neuen Wert am Anfang einer Sammlung einzufügen.

## 7. Eine Karte von unten aus dem Stapel entfernen

- In Base gibt es eine Methode [`popfirst!`][popfirst], um ein Element am Anfang einer Sammlung zu entfernen.

## 8. Die Größe des Stapels prüfen

- In Base gibt es eine Methode [`length`][length], um die Länge einer Sammlung abzurufen.
