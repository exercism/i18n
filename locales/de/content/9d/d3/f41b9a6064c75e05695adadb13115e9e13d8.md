# Anhang zu den Anweisungen

## Fortgeschritten

Wenn du Methoden für ein generisches Enumerable definierst, ist es üblich, `#to_enum` aufzurufen, falls kein Block übergeben wird.

Hier ist ein zusätzlicher Test, den du hinzufügen könntest:

```ruby
def test_accumulate_when_block_is_deferred
  skip
  accumulate_enumerator = [1, 2, 3].accumulate
  accumulated_result = accumulate_enumerator.map do |number|
    number * number
  end
  assert_equal [1, 4, 9], accumulated_result
end
```

[to_enum]: https://docs.ruby-lang.org/en/master/Object.html#method-i-to_enum
