# Einführung

Wenn Elixir entscheidet, welche Funktion aufgerufen wird, schlägt es den Namen des Moduls nach. Dieser Nachschlagevorgang kann dynamisch ablaufen, wenn der Name des Moduls an eine Variable gebunden ist.

```elixir
defmodule MyModule do
  def message(), do: "My message"
end

atom = MyModule
atom.message()
# => "My message"
```

Intern ist der Name eines Moduls ein Atom. Alle Modul-Atome in Elixir bekommen automatisch das Präfix `Elixir.`

```elixir
is_atom(Enum)
# => true
Enum == Elixir.Enum
# => true
```
