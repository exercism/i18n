# Anleitung

## Chromatische Tonleitern

Tonleitern in der westlichen Musik basieren auf der chromatischen Tonleiter (12 Töne).
Diese Tonleiter lässt sich als die folgende Gruppe von Tönen darstellen:

> A, A♯, B, C, C♯, D, D♯, E, F, F♯, G, G♯

Ein bestimmter Kreuz-Ton (gekennzeichnet durch ein ♯) lässt sich auch als Be des darüberliegenden Tons ausdrücken (gekennzeichnet durch ein ♭). Die chromatische Tonleiter kann also auch so geschrieben werden:

> A, B♭, B, C, D♭, D, E♭, E, F, G♭, G, A♭

Die Dur- und die Moll-Tonleiter sowie die Modi sind Teilmengen dieser Sammlung von zwölf Tönen.
Sie haben sieben Töne und heißen diatonische Tonleitern.
Die Noten in diesen Tonleitern werden entweder mit Kreuzen oder mit Be geschrieben, je nach Tonika (Anfangston).
Die folgende Tabelle zeigt, ob für eine bestimmte Tonika die Be- oder die Kreuz-Schreibweise der Tonleiter verwendet wird:

| Vorzeichen        | Dur                   | Moll                 |
| ----------------- | --------------------- | -------------------- |
| Ohne Vorzeichen   | C                     | a                    |
| Mit Kreuz         | G, D, A, E, B, F♯     | e, b, f♯, c♯, g♯, d♯ |
| Mit Be            | F, B♭, E♭, A♭, D♭, G♭ | d, g, c, f, b♭, e♭   |

Beachte, dass nach allgemeiner musiktheoretischer Konvention die Noten ohne Vorzeichen „C“ und „a“ beim Aufsteigen der Kreuz-Tonleiter und beim Absteigen der Be-Tonleiter folgen.
Im Rahmen dieser Übung ist die Tonleiter nur aufsteigend.

### Aufgabe

Gegeben sei eine Tonika. Erzeuge die chromatische Tonleiter mit 12 Noten, beginnend mit der Tonika.

- Verschiebe die Grundtonleiter so, dass alle 12 Noten zurückgegeben werden und mit der gegebenen Tonika beginnen.
- Bestimme für die gegebene Tonika, ob die Tonleiter mit Be oder mit Kreuzen zurückgegeben werden soll.
- Gib alle Noten in Großbuchstaben zurück (außer dem `b` für Be), unabhängig davon, ob die gegebene Tonika groß- oder kleingeschrieben ist.

## Diatonische Tonleitern

Die diatonischen Tonleitern und alle anderen Tonleitern, die sich von der chromatischen Tonleiter ableiten, bauen auf Intervallen auf.
Ein Intervall ist der Abstand zwischen zwei Tönen.

Das einfachste Intervall liegt zwischen zwei benachbarten Noten und heißt „Halbtonschritt“ oder „kleine Sekunde“ (manchmal mit einem kleinen „m“ geschrieben).
Das Intervall zwischen zwei Noten, zwischen denen eine weitere Note liegt, heißt „Ganztonschritt“ oder „große Sekunde“ (geschrieben als großes „M“).
Die diatonischen Tonleitern werden nur mit diesen beiden Intervallen zwischen benachbarten Noten gebildet.

Nicht-diatonische Tonleitern können andere Intervalle enthalten.
Ein Intervall „übermäßige Sekunde“, geschrieben „A“, hat zwei dazwischenliegende Noten (z. B. von A nach C oder von D♭ nach E) oder einen „Ganztonschritt“ plus einen „Halbtonschritt“.
Es gibt auch kleinere und größere Intervalle, aber sie spielen in dieser Übung keine Rolle.

### Aufgabe

Gegeben seien eine Tonika und eine Menge von Intervallen. Erzeuge die Tonleiter, die mit der Tonika beginnt und dem angegebenen Intervallmuster folgt.

Das ähnelt dem Erzeugen chromatischer Tonleitern, nur dass du statt 12 Noten N+1 Noten für N Intervalle zurückgibst.
Die erste Note ist immer die gegebene Tonika.
Dann wird für jedes Intervall im Muster die nächste Note bestimmt, indem du von der vorherigen Note ausgehst und so viele Noten überspringst, wie das Intervall angibt.

Wenn du zum Beispiel mit G beginnst und die sieben Intervalle MMmMMMm verwendest, ergeben sich die folgenden acht Noten:

| Note | Begründung                                             |
| ---- | ------------------------------------------------------ |
| G    | Tonika                                                 |
| A    | M steht für einen Ganztonschritt von G, G♯ wird übersprungen |
| B    | M steht für einen Ganztonschritt von A, A♯ wird übersprungen |
| C    | m steht für einen Halbtonschritt von B, es wird nichts übersprungen |
| D    | M steht für einen Ganztonschritt von C, C♯ wird übersprungen |
| E    | M steht für einen Ganztonschritt von D, D♯ wird übersprungen |
| F♯   | M steht für einen Ganztonschritt von E, F wird übersprungen |
| G    | m steht für einen Halbtonschritt von F♯, es wird nichts übersprungen |
