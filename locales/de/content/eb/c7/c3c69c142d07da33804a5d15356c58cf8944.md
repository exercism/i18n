# Nachtrag zu den Anweisungen

## Register

| Register | Verwendung   | Typ     | Beschreibung                                |
| -------- | ------------ | ------- | ------------------------------------------- |
| `$a0`    | Eingabe      | Ganzzahl | Anzahl der Eingabemünzen                    |
| `$a1`    | Eingabe      | Ganzzahl | Zielbetrag                                  |
| `$a2`    | Eingabe/Ausgabe | Adresse | überschreibbares Array von Münzwörtern      |
| `$v0`    | Ausgabe      | Ganzzahl | Anzahl der Ausgabemünzen, -1 wenn die Eingabe ungültig ist |
| `$t0-9`  | temporär     | beliebig | dient der temporären Speicherung            |
