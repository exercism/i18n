# Anweisungen

In dieser Übung schreibst du etwas Code, der dir dabei hilft, eine großartige Lasagne nach deinem Lieblingskochbuch zu kochen.

Du hast vier Aufgaben, die alle mit der Zeit zu tun haben, die du für das Kochen der Lasagne brauchst.

## 1. Definiere die erwartete Ofenzeit in Minuten

Definiere die Methode `Lasagna.expectedMinutesInOven()`, die keine Parameter entgegennimmt und zurückgibt, wie viele Minuten die Lasagne im Ofen bleiben sollte. Laut dem Kochbuch beträgt die erwartete Ofenzeit 40 Minuten:

```scala
val lasagna = new Lasagna()
lasagna.expectedMinutesInOven()
// => 40
```

## 2. Berechne die verbleibende Ofenzeit in Minuten

Definiere die Methode `Lasagna.remainingMinutesInOven()`, die die tatsächlichen Minuten, die die Lasagne schon im Ofen war, als Parameter entgegennimmt und zurückgibt, wie viele Minuten die Lasagne noch im Ofen bleiben muss, basierend auf der erwarteten Ofenzeit in Minuten aus der vorherigen Aufgabe.

```scala
val lasagna = new Lasagna()
lasagna.remainingMinutesInOven(30)
// => 10
```

## 3. Berechne die Vorbereitungszeit in Minuten

Definiere die Methode `Lasagna.preparationTimeInMinutes()`, die die Anzahl der Schichten, die du der Lasagne hinzugefügt hast, als Parameter entgegennimmt und zurückgibt, wie viele Minuten du für die Vorbereitung der Lasagne gebraucht hast. Dabei gehst du davon aus, dass jede Schicht 2 Minuten Vorbereitung braucht.

```scala
val lasagna = new Lasagna()
lasagna.preparationTimeInMinutes(2)
// => 4
```

## 4. Berechne die verstrichene Zeit in Minuten

Definiere die Methode `Lasagna.elapsedTimeInMinutes()`, die zwei Parameter entgegennimmt: Der erste Parameter ist die Anzahl der Schichten, die du der Lasagne hinzugefügt hast, und der zweite Parameter ist die Anzahl der Minuten, die die Lasagne im Ofen war. Die Funktion sollte zurückgeben, wie viele Minuten du mit dem Kochen der Lasagne verbracht hast, also die Summe aus der Vorbereitungszeit in Minuten und der Zeit in Minuten, die die Lasagne bis zu diesem Moment im Ofen verbracht hat.

```scala
var lasagna = new Lasagna()
lasagna.elapsedTimeInMinutes(3, 20)
// => 26
```
