# Hinweise

## Allgemein

- Das Paket [`roc-isodate`](https://github.com/ageron/roc-isodate) ist im Header von `gigasecond-test.roc` verfügbar (mit dem Alias `isodate`).
  Dieses Paket ist ein (temporärer) Fork von [dem Paket von @imclerran](https://github.com/imclerran/roc-isodate).
  Du kannst es in deiner Lösung verwenden, wenn du möchtest, zum Beispiel indem du `isodate.DateTime` importierst.
