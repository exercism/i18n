# Fehlerbehandlung

In dieser Übung implementierst du eine Funktion namens `processString`, die einen übergebenen String mit ordentlicher Fehlerbehandlung verarbeitet.

Du lernst, wie du:

- Eingabetypen prüfst und bei ungültigen Eingaben Fehler wirfst.
- für bestimmte Fälle Fehler wirfst (z. B. leere Strings).
- die Großbuchstabenversion des Strings zurückgibst, wenn er gültig ist.
- Fehler mit einem try..catch-Block behandelst und abfängst


Implementiere die Funktion `processString` mit einem `try…catch`-Block.

Im `try`-Block:
- Wenn die Eingabe kein String ist, wirf einen `TypeError`.
- Wenn die Eingabe ein leerer String ist, gib `null` zurück.
- Wenn die Länge der Eingabe größer als 100 oder kleiner als 10 ist, wirf einen `RangeError`.
- Wenn die Eingabe eine Mischung aus Buchstaben und Zahlen enthält, wirf einen `SyntaxError`.
- Andernfalls gib die Eingabe in `uppercase` zurück.

*Vergiss nicht, beim Werfen passende Fehlermeldungen anzuhängen! Eine informative und gut strukturierte Fehlermeldung kann dir Stunden beim Debuggen ersparen.*

Im `catch`-Block:
- Gib die Fehlermeldung mit `console.log` aus
- `throw` den `error`, damit sein Typ getestet werden kann.
