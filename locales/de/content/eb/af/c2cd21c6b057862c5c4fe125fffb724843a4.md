# Rune-Index mit Bytes verwendet

In diesem Fall ist es sicher, über `runes` zu iterieren und den Index zu verwenden, um einzelne `bytes` zu erhalten, denn die Eingabe besteht ausschließlich aus ASCII-Zeichen.
Um zu sehen, was passiert, wenn Nicht-ASCII-Zeichen verwendet werden, füge diesen Testfall hinzu:

```go
{
	s1:          "aüa",
	s2:          "aÃa",
	want:        1,
	expectError: false,
}
```
