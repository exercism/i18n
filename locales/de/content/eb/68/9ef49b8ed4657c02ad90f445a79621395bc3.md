# Über

Die meiste Iteration in Factor drückt man mit Kombinatoren aus (`each`,
`map`, `reduce`), aber explizite Rekursion hat trotzdem ihren Platz: wenn
die Rekursion nicht listenförmig ist, wenn der Basisfall nicht trivial
ist oder wenn du selbst einen Kombinator implementierst.

```factor
: total ( seq -- sum )
    [ 0 ] [ unclip swap total + ] if-empty ;

: gcd ( a b -- g )
    dup zero? [ drop ] [ tuck mod gcd ] if ;
```

Ein paar Dinge, die du wissen solltest:

- Einfache Definitionen mit `:` können ohne besondere Syntax rekursieren.
  Der Compiler leitet die Stackeffekte über den rekursiven Aufruf hinweg ab.
- `loop ( quot -- )` lässt dich eine Quotation iterieren, die einen
  booleschen Wert zurückgibt. Mach weiter, solange sie wahr ist.
- Tail Calls werden zu Sprüngen kompiliert, sodass tief rekursive Wörter
  den Stack nicht sprengen.

Das Paar `unclip` / `if-empty` ist die übliche Form für Sequenzrekursion;
`cond` ist die übliche Form für die Verzweigung über mehrere Fälle.
