# Anweisungen

HTTP-Endpunkte sind mit Typprüfung einfach besser. Wenn du einer POST-Anfrage einen Record-Typ hinzufügst, stellst du sicher, dass jedes Mal die richtigen Daten gesendet werden.

## Ziele

- Ändere den vorgegebenen Code.
- Füge diesem Record die nötigen Attribute hinzu, sodass er zwei Operanden und einen Operator akzeptiert.
- Füge eine HTTP-Ressourcenfunktion hinzu, die eine POST-Anfrage auf dem Pfad '/calc' annimmt.
- Die Funktion soll den Record-Typ Calculation als Payload annehmen und ein generisches JSON-Objekt zurückgeben.

### Eingabe

```json
{ "operand1": 4, "operand2": 10.2, "operator": "+" }
```

### Ausgabe

```json
{ "expression": "4+10.2", "result": 14.2 }
```
