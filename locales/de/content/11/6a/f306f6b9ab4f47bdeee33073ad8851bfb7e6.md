# Über

`TUPLE:` deklariert eine Klasse mit benannten Slots. Factor erzeugt automatisch ein Konstruktorwort, dessen Name der Klassenname mit angehängtem `new` ist, einen `boa`-Konstruktor („in der Reihenfolge der Argumente“), eine Literalsyntax `T{ class … }` und Zugriffswörter pro Slot.

```factor
TUPLE: player
    { name initial: f }
    { level initial: 0 }
    { health initial: 100 } ;

player new .                                    ! T{ player }
3 100 "Merlin" player boa .                     ! by-order construction
T{ player { name "Merlin" } { health 50 } } .   ! literal syntax
```

Das Zugriffssystem in [`accessors`][accessors] stellt vier Varianten pro Slot bereit: `name>>`, `>>name`, `change-name` und das mutierende Paar `[ … ] change-name`. `>>name` und `change-name` verändern das Tupel; rufe zuerst `clone` auf, wenn du das Original unverändert lassen willst.

Tupel unterstützen `=` durch strukturelle Gleichheit und geben dabei ihre vom Standard abweichenden Slot-Werte aus.

[accessors]: https://docs.factorcode.org/content/vocab-accessors.html
