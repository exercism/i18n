## Anweisungen

Du wurdest von einem Recyclingzentrum eingestellt.
Aus Platzmangel landen alle Produkte auf demselben Förderband, aber dadurch vermischen sich die verschiedenen Materialien und werden unbrauchbar.
Um das zu beheben, sollst du Funktionen schreiben, die den Typ eines Produkts erkennen.

### 1. Prüfe, ob ein Wert ein boolescher Wert ist

Implementiere die `isBoolean`-Funktion, die prüft, ob ein Wert ein boolescher Wert ist.

```javascript
isBoolean(true);
// => true

isBoolean(null);
// => false
```

### 2. Prüfe, ob ein Wert eine Zahl ist.

Implementiere die `isNumber`-Funktion, die prüft, ob ein Wert eine _endliche_ `number` oder `bigint` ist, also nicht `NaN` oder `Infinity`.

Manchmal versagt das Gerät zum Lesen von IDs und liest einen nicht-numerischen Wert als `NaN` (Not a Number) oder `Infinity` ein.
Deine Funktion sollte auch das korrekt behandeln können.

```javascript
isNumber(42);
// => true

isNumber('Hello, World!');
// => false

isNumber(42n);
// => true

isNumber(NaN);
// => false
```

### 3. Prüfe, ob ein Wert ein Objekt ist

Implementiere die `isObject`-Funktion, die prüfen soll, ob der Wert ein Objekt ist.
Auf dem Förderband ist `null` nichts und wird nicht als Objekt betrachtet.

```javascript
isObject({ greeting: 'Hello' });
// => true

isObject(25n);
// => false
```

### 4. Prüfe, ob ein String numerisch ist

Implementiere die `isNumericString`-Funktion, die prüfen soll, ob der Wert ein String ist, der nur aus Ziffern besteht oder aus einem Minuszeichen gefolgt von Ziffern, was eine negative Zahl angibt.
Es sollen nur Ganzzahlen berücksichtigt werden, Gleitkommazahlen gelten für diese Prüfung des Recyclingroboters nicht als numerisch.

```javascript
isNumericString(42);
// => false

isNumericString('42');
// => true

isNumericString('Hi!');
// => false
```

### 5. Prüfe, ob ein Objekt elektronisch ist

Implementiere die `isElectronic`-Funktion, die prüft, ob ein Objekt eine Instanz der vorgegebenen Klasse `ElectronicDevice` oder einer ihrer Unterklassen ist.

```javascript
class Duck {
  //...
}

class WashingMachine extends ElectronicDevice {
  //...
}

isElectronic(new Duck());
// => false

isElectronic(new WashingMachine());
// => true
```

### 6. Prüfe, ob ein Wert ein nicht leeres Array ist

Implementiere die `isNonEmptyArray`-Funktion, die prüft, ob ein Wert ein nicht leeres Array ist.

```javascript
isNonEmptyArray([1, 2, 3]);
// => true

isNonEmptyArray([]);
// => false
```

### 7. Prüfe, ob ein Wert ein leeres Array ist

Implementiere die `isEmptyArray`-Funktion, die prüft, ob ein Wert ein leeres Array ist.

```javascript
isEmptyArray([1, 2, 3]);
// => false

isEmptyArray([]);
// => true
```

### 8. Prüfe, ob ein Objekt eine `type`-Eigenschaft oder -Methode hat

Implementiere die `hasType`-Funktion, die prüft, ob ein Objekt eine `type`-Eigenschaft oder -Methode hat.

```javascript
class Keyboard(){
  type(){
    // ...
  }
}
hasType({ type:"car", color:"red" })
// => true

hasType({ color:"green" })
// => false

hasType(new Keyboard())
// => true
```

### 9. Löse einen Fehler aus, wenn ein Objekt keine `id`-Eigenschaft oder -Methode hat

Implementiere die `assertHasId`-Funktion, die einen `Error` auslöst, wenn bei einem Objekt die `id`-Eigenschaft fehlt.

Wenn ein Objekt die `id`-Eigenschaft hat, soll sie nichts zurückgeben.

```javascript
assertHasId({ id: 42, color: 'red' });
// => undefined

assertHasId({ color: 'green' });
// Error: "Object is missing the 'id' property"
```

### 10. Prüfe, ob ein Objekt eine `id`-Eigenschaft hat

Implementiere die `hasIdProperty`-Funktion, die prüft, ob ein Objekt eine `id`-Eigenschaft hat.

```javascript
class SimpleData {
  constructor() {
    this.number = '42';
    this.id = 'BC269327FE1D9B95';
  }
}

class StealingData extends SimpleData {}

class MethodData {
  constructor() {
    this.number = '42';
    this._id = 'BC269327FE1D9B95';
  }

  get id() {
    return this._id;
  }
}

hasIdProperty(new SimpleData());
// => true

hasIdProperty(new MethodData());
// => false

hasIdProperty(new StealingData());
// => false
```

### 11. Prüfe, ob ein Objekt eine definierte `type`-Eigenschaft hat

Implementiere die `hasDefinedType`-Funktion, die prüft, ob ein Objekt eine `type`-Eigenschaft hat, die nicht `undefined` ist.

```javascript
hasDefinedType({ type: undefined, color: 'red' });
// => false

hasDefinedType({ type: 'car', color: 'green' });
// => true
```
