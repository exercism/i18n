# Über

## Iteration über Arrays

Eine `for`-Schleife ermöglicht es, über ein Array zu iterieren und den Code für jedes Element zu wiederholen:

```haxe
var fruitList = ["apple", "banana", "pear"];

for (fruit in fruitList) {
  trace(fruit);
}

// apple
// banana
// pear
```

Im obigen Beispiel ist `fruit` die Variable, die den Wert eines einzelnen Elements des Arrays `fruitList` enthält. Der Compiler stellt sicher, dass über `fruitList` iteriert werden kann, andernfalls bricht er die Ausführung ab.

## Iteration über Bereiche

Du kannst über Zahlen iterieren, indem du den Bereichsoperator verwendest. Der Operator nimmt zwei `Int`-Operanden und wird als `min...max` geschrieben. `min` ist inklusive und `max` ist exklusiv (`min` <= i UND `max` > i)

```haxe
for (i in 0...10) {
  trace(i); // from 0 to 9
}
```

## Iteration über Schlüssel-Wert-Paare

Es ist möglich, über Sammlungen von Schlüssel-Wert-Paaren zu iterieren. Der einzige Unterschied in der Syntax besteht darin, dass statt einer einzelnen Variable ein Bezeichner für die Schlüsselvariable verwendet wird, gefolgt von `=>`, gefolgt von einem Bezeichner für die Wertvariable:

```haxe
var map = [1 => 101, 2 => 202, 3 => 303];

for (k => v in map) {
  trace(key, value);
}

// 1, 101
// 2, 202
// 3, 303
```
