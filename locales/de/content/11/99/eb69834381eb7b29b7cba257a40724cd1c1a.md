# Einführung

Der `enum`-Typ in C# stellt einen festen Satz benannter Konstanten dar (eine Enumeration). Sein Hauptzweck ist es, eine typsichere Möglichkeit für den Umgang mit numerischen Konstanten zu bieten und die verfügbaren Werte auf einen vorher festgelegten Satz zu beschränken. Ein einfaches Enum definierst du so:

```csharp
enum Season
{
    Spring,
    Summer,
    Autumn,
    Winter
}
```

Wenn du nichts anderes angibst, bekommen die Enum-Mitglieder automatisch aufsteigende Ganzzahlwerte zugewiesen, wobei der erste Wert null ist. Du kannst die Werte aber auch explizit zuweisen:

```csharp
enum Answer
{
    Maybe = 1,
    Yes = 3,
    No = 5
}
```
