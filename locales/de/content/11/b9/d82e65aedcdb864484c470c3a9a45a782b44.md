# Anleitung

Andrew, ein Entwickler bei seinem Unternehmen, hat vor Kurzem ein leichtgewichtiges Hilfsprogramm zur Erzeugung von SQL-Abfragen für ein Tool zur Datenbankmigration gebaut.
Seine erste naive Implementierung funktionierte für kleine Datenmengen einwandfrei.
Bei großen Produktionsmigrationen begann die Anwendung jedoch, übermäßig viel Speicher zu verbrauchen, und kam bei hoher Last an ihre Grenzen.
Nachdem er die Anwendung profiliert hatte, erkannte Andrew, dass die normale String-Verkettung innerhalb von Schleifen Go dazu zwang, ständig neuen Speicher zuzuweisen.
Jetzt braucht er deine Hilfe, um das Hilfsprogramm mit Gos `strings.Builder` zu refaktorieren, damit die Anwendung gut skaliert und große Textmengen verarbeitet, ohne den Heap-Speicher zu überlasten.

## 1. SELECT-Abfragen generieren

Implementiere die Funktion `BuildSelectQuery`.
Sie nimmt einen Tabellennamen (`string`) und einen Slice mit Spaltennamen (`[]string`) entgegen.
Sie soll eine vollständig aufgebaute SQL-`SELECT`-Anweisung zurückgeben, die mit einem Semikolon endet.
Wenn der Slice mit den Spalten leer ist oder `nil`, soll die Abfrage stattdessen den Platzhalter `*` verwenden, um alle Spalten auszuwählen.

```go
columns := []string{"id", "name", "email"}
BuildSelectQuery("users", columns)
// Function return: "SELECT id, name, email FROM users;"

BuildSelectQuery("orders", nil)
// Function return: "SELECT * FROM orders;"
```

## 2. Batch-INSERT-Anweisungen generieren

Implementiere die Funktion `BuildBatchInserts`.
Sie nimmt einen Tabellennamen (`string`) und einen zweidimensionalen Slice entgegen, der Datenbankzeilen darstellt (`[][]ColumnValue`).
Jedes Element in einer Zeile verknüpft einen bestimmten Spaltennamen mit seinem String-Wert.
Die Funktion muss einen Slice mit einzelnen `INSERT`-SQL-Strings zurückgeben.
Das strukturierte Slice-Format garantiert eine vorhersehbare und stabile Reihenfolge der Abfrageausgabe.
Wenn der eingegebene Slice mit Zeilen leer ist, gib einen leeren Slice von Strings zurück.
Wenn eine einzelne Zeile leer ist, überspringe sie.
String-Werte in der `VALUES`-Klausel müssen in einfache Anführungszeichen `'` eingeschlossen werden.

```go
rows := [][]ColumnValue{
    {
        {Column: "title", Value: "Book"},
        {Column: "price", Value: "100"},
    },
    {
        {Column: "title", Value: "Magazine"},
        {Column: "price", Value: "15"},
    },
}

BuildBatchInserts("products", rows)
// Function returns string slice: [
//   "INSERT INTO products (title, price) VALUES ('Book', '100');",
//   "INSERT INTO products (title, price) VALUES ('Magazine', '15');"
// ]
```
