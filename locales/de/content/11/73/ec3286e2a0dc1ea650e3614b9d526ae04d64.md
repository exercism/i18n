# Installation

## Dart installieren

Eine Anleitung zur Installation des Dart SDK findest du auf der Dart-Website: [Dart herunterladen][get-dart]

## Dart-Plugin für deine IDE oder deinen Editor

Wenn du eine IDE oder einen Editor verwendest, [füge ein Dart-Plugin hinzu][editors], sofern es eines für deinen bevorzugten Editor gibt.

[get-dart]: https://dart.dev/get-dart
[editors]:  https://dart.dev/tools#editors
