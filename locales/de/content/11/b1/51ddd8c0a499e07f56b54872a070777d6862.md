# Ergänzung der Anweisungen

Die Potenzierung komplexer Zahlen erfordert eine Exponentialfunktion sowie eine Sinus- und eine Kosinusfunktion, die in WebAssembly nicht verfügbar sind. Glücklicherweise kannst du eine [Taylorreihe](https://en.wikipedia.org/wiki/Taylor_series) verwenden, um diese zu berechnen. Du solltest mindestens eine Genauigkeit von `1/26!` haben, um mit den erwarteten Werten übereinzustimmen.

## Exponentialfunktion

```
exp(x) ≃ 1 + x + x ^ 2 / 2! + x ^ 3 / 3! + x ^ 4 / 4! + ... + x ^ n / n!
```

## Sinusfunktion

```
sin(x) ≃ x - x ^ 3 / 3! + x ^ 5 / 5! - x ^ 7 / 7! + ... - x ^ n / n!
```

## Kosinusfunktion

```
cos(x) ≃ 1 - x ^ 2 / 2! + x ^ 4 / 4! - x ^ 6 / 6! + ... - x ^ n / n!
```
