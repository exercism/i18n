# Einführung

In Cairo gilt das Konzept Ownership für _Variablen_ und definiert die Regeln dafür, wer diese Variablen verwenden kann.
Jede deklarierte Variable kann nur einmal verwendet werden. Das bedeutet: Sobald eine Variable verwendet wird, wird sie entweder zerstört oder verschoben, je nach Art der Verwendung.

_Zerstörung_ kann auf verschiedene Weise geschehen:

- eine Variable verlässt den Gültigkeitsbereich (mit/ohne Verwendung).
- ein Struct wird destrukturiert.
- explizite Zerstörung mit `destruct()`

Das _Verschieben_ eines Werts bedeutet einfach, diesen Wert an eine andere Funktion zu übergeben.

Die Sprache Cairo verwendet ein lineares Typsystem. Damit sorgt sie dafür, dass der gesamte Code beweisbar (und verifizierbar) ist, und abstrahiert zugleich vom unveränderlichen Speicher der Cairo VM.
