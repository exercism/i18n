# Tests

Um die Tests in der Kommandozeile auszuführen, führe den folgenden Befehl im Verzeichnis der Übung aus:

```bash
java -jar /path/to/mars.jar nc runner.mips impl.mips
```

## GUI

Um die Tests über die GUI des MARS-Simulators auszuführen, `include` deine Implementierung am Ende von `runner.mips`, indem du die letzte Zeile auskommentierst.
