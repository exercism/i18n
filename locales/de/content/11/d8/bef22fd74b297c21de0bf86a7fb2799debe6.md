# Anleitung

Du bist der Wachoffizier an Bord eines Kutters, der die Beringstraße durchquert. Drei Quellen melden die Position jeder Eisscholle und jedes Kaps in Sichtweite:

- Der **Kartentisch** spricht in Kompassrichtungen: `north`, `east`, `south`, `west`. Nur eine Richtung, keine Entfernung.
- Der **Navigator** spricht in *Polarkoordinaten* ausgehend von der letzten Ortsbestimmung des Kutters: ein Betrag in Seemeilen und eine Peilung in Grad, im Uhrzeigersinn von Norden aus gezählt (also ist `0` Norden, `90` Osten, `180` Süden und `270` Westen).
- Der **Mastausguck** spricht in *relativen* Koordinaten: eine Entfernung voraus und eine von `ahead`, `starboard`, `behind`, `port`. Relative Peilungen werden gegen *den aktuellen Kurs des Schiffes* gemessen. Diesen Kurs gibt der Kapitän vor jeder Wache auf der Brücke bekannt.

Deine Aufgabe ist es, alle drei in ein gemeinsames kartesisches Koordinatensystem `(x, y)` umzurechnen, damit die Karte gezeichnet werden kann. Peilungen werden in Grad angegeben; `(0, 1)` ist eine Seemeile nach Norden, `(1, 0)` ist eine Seemeile nach Osten.

## 1. Das Datenmodell und kartesisch für Kardinalrichtungen

Zuerst legst du die Bausteine an, die sich durch die ganze Übung ziehen:

- Definiere drei Tupel: `cardinal` (ein Slot, `direction`), `polar` (Slots `magnitude` und `bearing`) und `relative` (Slots `distance` und `bearing`).
- Deklariere die Richtungssymbole mit `SYMBOLS:`: `north`, `east`, `south`, `west`, `ahead`, `starboard`, `behind`, `port`.
- Deklariere mit `SYMBOL:` eine dynamische Variable `heading` (Aufgabe 3 verwendet sie).
- Deklariere zwei generische Wörter: `GENERIC: >cartesian ( direction -- x y )` und `GENERIC: flip ( direction -- direction' )`. Ihre Methoden fügst du in den nächsten Aufgaben hinzu.

Dann füge die Methode `M: cardinal` von `>cartesian` hinzu, die den Einheitsvektor für die benannte Richtung zurückgibt.

```factor
T{ cardinal { direction north } } >cartesian . .
! => 1
! => 0
! (top of stack is `y`, just below it is `x`)
```

## 2. Kartesisch für Polarkoordinaten

Füge `>cartesian` eine Methode `M: polar` hinzu, die die Polarform in `(x, y)` umrechnet:

```
x = magnitude * sin(bearing-in-radians)
y = magnitude * cos(bearing-in-radians)
```

```factor
T{ polar { magnitude 10 } { bearing 90 } } >cartesian . .
! => 0   (close to zero — the cosine of π/2 isn't exactly 0 in floats)
! => 10
```

## 3. Kartesisch für relative Koordinaten

Füge `>cartesian` eine Methode `M: relative` hinzu. Der Haken: Eine relative Peilung wird gegen den *aktuellen Kurs* des Schiffes gemessen, und der ist nicht Teil des Tupels. Lies die Variable `heading` (in Aufgabe 1 deklariert) mit `heading get` aus, addiere den Peilungsversatz (`ahead = 0`, `starboard = 90`, `behind = 180`, `port = 270`) und erzeuge den kartesischen Punkt. Der Aufrufer setzt `heading` innerhalb eines `with-variable`-Blocks.

```factor
0 heading [
    T{ relative { distance 5 } { bearing starboard } } >cartesian
] with-variable . .
! => 0   (heading 0 is north; starboard is east; (5, 0))
! => 5
```

## 4. Umdrehen

Füge die Methoden des generischen Worts `flip` hinzu (in Aufgabe 1 deklariert), sodass es die entgegengesetzte Richtung zurückgibt.

- Für `cardinal`: Norden ↔ Süden, Osten ↔ Westen.
- Für `polar`: Addiere 180° zur Peilung (modulo 360).
- Für `relative`: voraus ↔ hinten, Steuerbord ↔ Backbord.

```factor
T{ cardinal { direction north } } flip .
! => T{ cardinal { direction south } }

T{ polar { magnitude 10 } { bearing 90 } } flip .
! => T{ polar { magnitude 10 } { bearing 270 } }

T{ relative { distance 5 } { bearing ahead } } flip .
! => T{ relative { distance 5 } { bearing behind } }
```

## 5. Peilungen addieren

Definiere `add-bearings ( a b -- x y )`, das beide Richtungen in kartesische Koordinaten umrechnet und ihre Summe zurückgibt. Es funktioniert für jede Mischung aus `cardinal`, `polar` und `relative`. Das ist der Lohn dafür, dass du für `>cartesian` ein generisches Wort verwendest.

```factor
T{ cardinal { direction north } } T{ cardinal { direction east } } add-bearings . .
! => 1
! => 1
```
