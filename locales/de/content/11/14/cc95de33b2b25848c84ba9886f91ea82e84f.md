# Anleitung

Ergänze die Minenzahlen in einem fertigen Minesweeper-Spielfeld.

Minesweeper ist ein beliebtes Spiel, bei dem du die Minen mithilfe von Zahlenhinweisen finden musst. Diese Hinweise zeigen an, wie viele Minen direkt an ein Feld angrenzen (waagerecht, senkrecht, diagonal).

In dieser Übung schreibst du Code, der die Anzahl der Minen zählt, die an ein bestimmtes leeres Feld angrenzen, und dieses Feld durch die Anzahl ersetzt.

Das Spielfeld ist ein Rechteck aus Leerzeichen (' '). Eine Mine wird durch ein Sternchen ('\*') dargestellt.

Wenn an ein Feld überhaupt keine Mine angrenzt, lass dieses Feld leer.

## Beispiele

Zum Beispiel kannst du ein Spielfeld mit 5 x 4 Feldern wie dieses erhalten (leere Felder werden hier zur Anzeige auf dem Bildschirm mit dem Zeichen '·' dargestellt):

```
·*·*·
··*··
··*··
·····
```

Und dein Code verwandelt es in Folgendes:

```
1*3*1
13*31
·2*2·
·111·
```
