# Anleitung

Du betreibst einen kleinen Wetterposten am Ufer der Moldau in Prag und notierst in jeder Schicht die Temperaturwerte in einem einfachen Textprotokoll, einen Wert pro Zeile. Fünf kleine Wörter erledigen die Buchführung einer ganzen Schicht.

Jedem Wort wird der Pfad zur Protokolldatei übergeben.

## 1. Lies jeden Messwert

Definiere `read-readings`, sodass alle Messwerte des Protokolls als Array von Strings zurückgegeben werden, einen pro Zeile.

```factor
"weather.log" read-readings .
! => { "21.5" "19.0" "22.3" }
```

## 2. Finde den neuesten Messwert

Definiere `latest-reading`, sodass der neueste Messwert zurückgegeben wird, also die letzte Zeile des Protokolls.

```factor
"weather.log" latest-reading .
! => "22.3"
```

## 3. Lies das Rohprotokoll

Definiere `log-text`, sodass die gesamte Protokolldatei als ein einzelner String zurückgegeben wird, genau so, wie sie gespeichert ist.

```factor
"weather.log" log-text .
! => "21.5\n19.0\n22.3\n"
```

## 4. Erfasse einen Messwert

Definiere `record-reading`, sodass ein neuer Messwert als eigene Zeile an das Ende des Protokolls angehängt wird, ohne die früheren Messwerte zu verändern. Gibt nichts zurück.

```factor
"23.1" "weather.log" record-reading
"weather.log" log-text .
! => "21.5\n19.0\n22.3\n23.1\n"
```

## 5. Schreibe das Protokoll neu

Definiere `rewrite-log`, sodass das gesamte Protokoll durch ein neues Array von Messwerten ersetzt wird, einen pro Zeile.

```factor
{ "10.0" "11.0" } "weather.log" rewrite-log
"weather.log" log-text .
! => "10.0\n11.0\n"
```
