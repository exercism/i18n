# Anleitung

Du wirst etwas Code schreiben, um eine Liste von Programmiersprachen zu verwalten, die du lernen möchtest.

## 1. Eine Sprache zu einer Liste hinzufügen

Ändere die `add-language`-Subroutine, die eine Liste von Sprachen und einen Sprachnamen als Argumente entgegennimmt, so, dass sie eine Liste zurückgibt, an deren Ende die neue Sprache angehängt ist.

## 2. Eine Sprache aus einer Liste entfernen

Ändere die `remove-language`-Subroutine so, dass sie die letzte Sprache aus einer gegebenen Liste entfernt.

## 3. Die erste Sprache aus einer Liste abrufen

Ändere die `first-language`-Subroutine so, dass sie die erste Sprache aus einer gegebenen Liste zurückgibt.

## 4. Die letzte Sprache aus einer Liste abrufen

Ändere die `last-language`-Subroutine so, dass sie die letzte Sprache aus einer gegebenen Liste zurückgibt.

## 5. Einen Ausschnitt von Sprachen aus einer Liste abrufen

Ändere die `get-languages`-Subroutine, die eine Liste von Sprachen und eine Liste von Zahlen für gewünschte Elemente entgegennimmt, so, dass sie einen Ausschnitt der gegebenen Liste zurückgibt.

## 6. Prüfen, ob eine Sprache in einer Liste enthalten ist

Ändere die `has-language`-Subroutine, die eine Sprachenliste und einen Sprachnamen als Argumente entgegennimmt, so, dass sie entweder `True` oder `False` zurückgibt, je nachdem, ob die Sprache in der gegebenen Liste enthalten ist.
