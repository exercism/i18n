# Typumwandlung

Typumwandlung ist auch unter dem Namen Typkonvertierung bekannt.
Von Typumwandlung spricht man, wenn zwei Werte unterschiedlichen Typs in denselben Typ umgewandelt werden, um eine Operation durchzuführen.

```php
$baskets = 5 // int
$apples_per_basket = "3" // string
$baskets * $apples_per_basket
# => 15 // int
```

Wenn der Ausdruck ausgewertet wird, wird der String-Wert implizit in einen `int` umgewandelt, um der Erwartung des `*`-Operators zu entsprechen.
Welchen Typ PHP umwandelt, entscheidet es nach den Regeln der jeweiligen Operation, und diese Regeln unterscheiden sich stark.

Zu einer Typumwandlung kommt es auch beim Aufrufen von Funktionen und Methoden:

```php
strlen(12321);
# => 5
```

## Typcasting

Statt sich auf die implizite Umwandlung zu verlassen, können wir einen Wert mit einem Typcasting im `C`-Stil explizit als einen bestimmten Typ auswerten lassen:

```php
$apples_per_basket = "3" // string
$my_number = (int) $apples_per_basket // cast string to int
# => 3 // int
```

Dabei wird der Wert in den Typ umgewandelt, der in den runden Klammern `(...)` angegeben ist.
Als Zieltyp lassen sich alle primitiven Typen verwenden: `bool`, `int`, `float`, `string`, `array`, `object`.

## Nur vorübergehende Umwandlung

Die Typumwandlung oder das Casting **ändert nicht** den Typ des Werts, der in einer Variable gespeichert ist.
Nur die Eingabe der Operation wird umgewandelt.

```php
$apples_per_basket = "3" // string
5 * $apples_per_basket
# $apples_per_basket => "3" // string

$my_number = (int) $apples_per_basket // cast string to int
# $apples_per_basket => "3" // string
```

## Informationsverlust

Wenn ein Wert in einen anderen Typ umgewandelt wird, kann dabei Information verloren gehen:

```php
$exact_distance = 15.5
$rough_distance = (int) $exact_distance
// => 15

$is_distant = (bool) $exact_distance
// => true

$erroneous_distance = (float) $is_distant
// => 1.0
```

Wer sich auf das Casting verlässt, ob explizit oder implizit, kann in einem größeren System Fehler erzeugen.

## Explizites Casting zu `array` und `object`

Werte lassen sich auch zu den Typen `array` und `object` casten.
Wenn ein Wert, der weder ein Array noch ein Objekt ist, zu einem `array` gecastet wird, wird er in ein einzelnes Element umgewandelt, das in einem Array liegt:

```php
$day_of_the_week = 'Monday';
(array) $day_of_the_week
// => array(1) {
//      [0]=>
//        string(6) "Monday"
//    }
```

Beim Casten zu einem `object` wird der Wert in eine öffentliche Eigenschaft namens `scalar` gesetzt:

```php
$car = "Honda"
(object) $car
// => object(stdClass)#1 (1) {
//      ["scalar"]=>
//        string(5) "Honda"
//    }
```

> `stdClass` ist der Typ einer anonymen Klasse, die in PHP eingebaut ist.
