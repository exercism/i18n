# Ergänzung zur Anleitung

## Implementierung

Manchmal musst du auf unerwartete Probleme reagieren, die auftreten, während dein Code läuft.
In Dart kannst du dafür Exceptions verwenden.

Um in Dart eine Exception zu werfen, benutzt du das Schlüsselwort `throw`, gefolgt von einer Instanz der Exception, die du auslösen möchtest.
Zum Beispiel wirft `throw Exception()` eine Instanz des Basistyps `Exception`.

In dieser Übung musst du eine eigene Exception namens `InvalidNucleotideException` definieren.
Diese Exception soll geworfen werden, wenn ein ungültiges Nukleotid auftritt.
Die Testsuite prüft nur, dass eine Instanz von `InvalidNucleotideException` übergeben wird. Du kannst sie also so umsetzen, wie du möchtest, solange sie korrekt geworfen wird.

Mehr über Exceptions in Dart findest du in der [Dokumentation zu Exceptions](https://dart.dev/language/error-handling).
Eigene Exceptions kannst du erstellen, indem du das [Exception-Interface implementierst](https://dart.dev/language#interfaces-and-abstract-classes).
