# Ergänzung zur Anleitung

## Implementierung

Deine Funktion bekommt ein Array von Strings.
Jeder String steht für eine Hand aus 5 Karten, die durch Leerzeichen getrennt sind.
Eine Karte wird durch eine Zahl und ihre Farbe dargestellt.

Du gibst ein Array zurück, das entweder die beste Hand oder bei Gleichstand die besten Hände enthält.
Jede Hand muss ein String im gleichen Format sein, wie du es anfangs als Eingabe bekommen hast.
