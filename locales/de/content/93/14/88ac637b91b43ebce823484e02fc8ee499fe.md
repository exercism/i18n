# Hinweise

## 1. Gib einen Ausweis für einen Mitarbeiter aus

- Mit [String-Templates][string-template] kannst du Beschreibungs-Strings erstellen.
- Es gibt eine [eingebaute Methode, um einen String in Großbuchstaben umzuwandeln][to-upper-case].

## 2. Gib einen Ausweis für einen neuen Mitarbeiter aus

- Du solltest prüfen, ob die ID `null` ist, bevor du sie verwendest.
- Du kannst einen [Gleichheitsoperator][kotlin-operators] verwenden, um zu prüfen, ob ein Wert `null` ist.

## 3. Gib einen Ausweis für den Inhaber aus

- Du kannst den [Elvis-Operator][elvis-operator] verwenden, um einen Ersatzwert zu nutzen, wenn eine Variable `null` ist.
