# Einführung

Der `null`-Wert wird verwendet, um die _Abwesenheit_ eines Werts zu bezeichnen. Ein **nullbarer** Typ ist ein Typ, der es einer Variable erlaubt, den `null`-Wert anzunehmen. Um einen beliebigen Typ nullbar zu machen, umschließen wir ihn mit `Null<T>`:

```haxe
var a:Int = null; // Error
var b:Null<Int> = null; // Allowed
```

Um zu prüfen, ob ein Wert gerade `null` ist, verwendest du einfach einen `if`-Ausdruck:

```haxe
var a:Null<Int> = 10;

if (a != null) {
  trace("a is not null"); // a is not null
}
```
