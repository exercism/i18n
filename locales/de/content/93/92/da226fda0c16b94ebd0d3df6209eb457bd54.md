# Überblick

Listen in C# sind Sammlungen primitiver Werte oder Instanzen von Strukturen oder Klassen. Sie sind in der Basisklassenbibliothek als [`List<T>`][lists-docs] implementiert, wobei `T` der Typ der Elemente in der Liste ist. Die API bietet einen umfangreichen Satz von Methoden zum Erstellen und Bearbeiten von Listen.

```csharp
var listOfStrings = new List<string>();
var listOfIntegers = new List<int>();
var listOfRandoms = new List<Random>();
var listOfBigIntegers = new List<BigInteger>();
```

Eine Sammlungsdefinition enthält typischerweise einen Platzhalter in spitzen Klammern, üblicherweise `T`. Dadurch kann der Nutzer der Sammlung festlegen, welchen Elementtyp die Sammlung speichern soll.

Im Gegensatz zu [concept:csharp/arrays]() können Listen ihre Größe dynamisch ändern.

## LINQ

Die eingebaute API von `List<T>` ist zwar umfangreich (einschließlich Zuordnungen und Filtern wie `ConvertAll`, `FindAll` und `Foreach`), und ihre [Schleifensyntax][for-each] ist sehr klar, und du musst dich mit dieser API auf jeden Fall auskennen. Trotzdem steht Language Integrated Query ([LINQ][linq]) für viele Aufgaben zur Verfügung, ist sogar noch leistungsfähiger und wird häufiger verwendet. Außerdem bietet es den Vorteil einer einheitlichen Schnittstelle für Bibliotheksammlungen, Sammlungen von Drittanbietern und deine eigenen Klassen.
