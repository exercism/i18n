# Überblick

Perl ist eine Programmiersprache, die von Larry Wall entwickelt und erstmals 1987 veröffentlicht wurde.

## Pakete und Module

Ein Paket ist eine Sammlung von Code, die oft in einer Moduldatei gleichen Namens mit der Dateiendung `.pm` liegt.
Das Modul kann dann in eine andere Datei importiert werden, in der Regel mit dem Schlüsselwort `use`.

```perl
# Foo.pm
package Foo;

# Accessible with `Foo::bar` when module is used
# or just `bar` if the subroutine is exported.
sub bar () {
    return 1;
}
```

## Variablen

Es gibt skalare Variablen (`$foo`), Array-Variablen (`@bar`) und Hash-Variablen (`%baz`).
Um es einfach zu halten, werden hier nur skalare Variablen verwendet.
Ein skalarer Wert kann Folgendes sein: ein String, eine Zahl, ein boolescher Wert oder eine [Referenz][perlreftut] auf etwas.
Das Fehlen eines Werts ist `undef`.


Die Schlüsselwörter `my` und `our` deklarieren eine Variable im lexikalischen Gültigkeitsbereich, z. B. `my $foo;`.
Bei `our` erhält die Variable zusätzlich einen Alias auf eine Paketvariable gleichen Namens.
Es gibt weitere Möglichkeiten, Variablen zu deklarieren, die hier nicht behandelt werden.

Du kannst einer Variablen mit dem Operator `=` einen Wert zuweisen, z. B. `$foo = 1;`. Das kannst du auch gleichzeitig mit der Deklaration tun, z. B. `my $foo = 1;`.

```perl
package Foo;

sub baz () {
    our $bar = 1; # Sets both $bar and $Foo::bar as 1.
    return $bar;
}

$Foo::bar = 2; # $bar is not accessible here, but $Foo::bar is.

# Both of these will print 1.
say baz;
say $Foo::bar;
```

## Subroutinen

Das Schlüsselwort `sub` deklariert eine [Subroutine][perlsub].
Das Schlüsselwort `return` beendet die Subroutine und gibt die angegebenen Werte zurück, oder eine leere Liste, wenn nichts angegeben ist.
Ohne ein angegebenes `return` wird der Rückgabewert durch den Kontext (skalar, Liste oder Void) bestimmt, in dem die Subroutine verwendet wird, sowie durch ihre letzte Anweisung.

```perl
sub hello () {
    return 'Hello, World!';
}
```

Neuere Perl-Versionen erlauben es dir, formale Parameter in einer [Signatur][perlsubsig] anzugeben.
Die Parameterliste kann skalare Variablen, Array-Variablen oder Hash-Variablen enthalten.
Eine leere Parameterliste bedeutet, dass die Subroutine keine Argumente akzeptiert.
Ältere Perl-Versionen erforderten, dass man die Argumente aus der speziellen Variable `@_` holt, was hier nicht behandelt wird.
