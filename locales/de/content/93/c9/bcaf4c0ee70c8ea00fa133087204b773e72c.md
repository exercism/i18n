# Hinweise

## Allgemeines

- `cond` in [`combinators`][combinators] ist der sauberste Weg, um eine Geschwindigkeit auf eine Erfolgsrate abzubilden.
- Die Wörter für die Arithmetik findest du in [`math`][math]; die Helfer `floor` und `>integer` für die Umwandlung von Gleitkommazahlen in Ganzzahlen findest du in [`math.functions`][math.functions] bzw. in `math`.

## 1. Melde, ob das Fließband läuft

- `zero?` (in [`math`][math]) prüft, ob die Geschwindigkeit `0` ist.
- `if` nimmt einen booleschen Wert und zwei Quotations entgegen, `[ "stopped" ] [ "running" ]`, und führt die passende aus. Hier wird die Geschwindigkeit vom Test verbraucht, deshalb braucht keine der beiden Quotations ein `drop`.

## 2. Berechne die Erfolgsrate

- Eine `cond`-Klausel ist `{ [ predicate ] [ body ] }`. Jedes Prädikat untersucht die Geschwindigkeit, sollte den Stack aber so hinterlassen, wie es ihn vorgefunden hat (ein `dup` … `<test>` macht genau das). Der Rumpf beginnt normalerweise mit `drop`.
- Die Reihenfolge ist wichtig: Prüfe `zero?` vor `4 <=`, denn `0 4 <=` ergibt `t`.
- Verwende einen letzten Eintrag ohne Prädikat als Standard für die Geschwindigkeit `10`.

## 3. Berechne die Produktionsrate pro Stunde

- Definiere `base-speed` als `CONSTANT:` am Anfang der Datei (genau wie `expected-bake-time` in `lasagna`).
- Berechne `base-speed * speed * success-rate`. Eine Möglichkeit ist, `bi` aus `kernel` zu verwenden: Es führt zwei Quotations mit derselben Eingabe aus und lässt beide Ergebnisse auf dem Stack.

## 4. Berechne die Anzahl der pro Minute produzierten funktionierenden Teile

- Teile die Stundenrate durch 60.
- Verwende `floor`, um den Nachkommaanteil zu verwerfen, und dann `>integer`, um das Gleitkomma-Ergebnis in eine Ganzzahl umzuwandeln.
