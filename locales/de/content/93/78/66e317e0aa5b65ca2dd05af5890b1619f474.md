# Modulo

Modulo-Vergleiche sind in Crystal völlig in Ordnung, aber lesbarer ist es, den Rest einer Division mit der Methode [`divisible_by?`][divisible_by] zu vergleichen.
Zum Beispiel:

```crystal
# Rather than:
number %% 2 == 0

# Consider:
number.divisible_by?(2)
```

[divisible_by]: https://crystal-lang.org/api/latest/Int.html#divisible_by%%3F%%28num%%29%%3ABool-instance-method
