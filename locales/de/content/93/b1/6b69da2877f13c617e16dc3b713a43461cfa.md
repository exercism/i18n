# Einführung

## Callback-Funktionen

Callback-Funktionen sind Funktionen, die als Argumente übergeben werden. Dieses Programmiermuster erzeugt eine Abfolge von Funktionsaufrufen, sowohl in der synchronen als auch in der asynchronen Programmierung. Eine Callback-Funktion zu schreiben, unterscheidet sich nicht vom Schreiben einer Funktion; die Callback-Funktion muss jedoch zu der Signatur passen, die die aufrufende Funktion vorgibt.

```javascript
const sideLength = 5;

// Caller function takes a callback function
function applySideLength(callback) {
  return callback(sideLength);
}

// Callback must expect the possible argument from the calling function
function areaOfSquare(side) {
  return side * side;
}

applySideLength(areaOfSquare); // => 25
```

Du kannst Callbacks auch als Funktionsausdruck schreiben:

```javascript
applySideLength(function squarePerimeterLength(side) {
  return side * 4;
});
```
