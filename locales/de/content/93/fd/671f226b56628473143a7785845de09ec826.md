# Anleitung

In dieser Übung schreibst du Code, um die Produktion eines Fließbands in einer Autofabrik zu analysieren. Die Geschwindigkeit des Fließbands reicht von `0` (aus) bis `10` (Maximum).

Bei der niedrigsten Geschwindigkeit (`1`) werden `221` Autos pro Stunde produziert. Die Produktion steigt linear mit der Geschwindigkeit. Bei einer Geschwindigkeit von `4` sollten es also `4 * 221 = 884` Autos pro Stunde sein. Höhere Geschwindigkeiten erhöhen jedoch die Wahrscheinlichkeit, dass fehlerhafte Autos produziert werden, die dann aussortiert werden müssen. Die folgende Tabelle zeigt, wie die Geschwindigkeit die Erfolgsquote beeinflusst:

- `0`: 0 % Erfolgsquote.
- `1` bis `4`: 100 % Erfolgsquote.
- `5` bis `8`: 90 % Erfolgsquote.
- `9`: 80 % Erfolgsquote.
- `10`: 77 % Erfolgsquote.

Du hast drei Aufgaben.

## 1. Berechne die Erfolgsquote

Implementiere die Funktion `successRate`, um die Erfolgsquote basierend auf der Produktionsgeschwindigkeit zu berechnen:

```fsharp
successRate 6
// => 0.9
```

## 2. Berechne die Produktionsrate pro Stunde

Implementiere die Funktion `productionRatePerHour`, um die Produktionsrate des Fließbands pro Stunde zu berechnen, wobei du die Erfolgsquote berücksichtigst:

```fsharp
productionRatePerHour 6
// => 1193.4
```

Beachte, dass der Rückgabewert ein `float` ist.

## 3. Berechne die Anzahl der pro Minute produzierten funktionsfähigen Autos

Implementiere die Funktion `workingItemsPerMinute`, um zu berechnen, wie viele funktionsfähige Autos pro Minute produziert werden:

```fsharp
workingItemsPerMinute 6
// => 19
```

Beachte, dass der Rückgabewert ein `int` ist.
