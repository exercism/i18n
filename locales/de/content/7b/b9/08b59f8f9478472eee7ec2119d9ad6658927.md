Elixir hat eigene Namenskonventionen. Dazu gehört auch die Frage, wie [Funktionen benannt werden, die einen booleschen Wert zurückgeben](https://hexdocs.pm/elixir/naming-conventions.html#trailing-question-mark-foo):

> Funktionen, die einen booleschen Wert zurückgeben, werden mit einem Fragezeichen am Ende benannt.

```elixir
# this is the expected name of functions that return a boolean

%{expected}

# this is the current name

%{actual}
```

Beachte, dass Guards, einige eingebaute Funktionen und Makros, die boolesche Werte zurückgeben und in Guards gültig sind, einer anderen Konvention folgen und mit dem Präfix `is_` benannt werden (`def is_integer`, `defguard is_foo`, `defmacro is_foo`). Die beiden Konventionen dürfen nicht gemischt werden.
