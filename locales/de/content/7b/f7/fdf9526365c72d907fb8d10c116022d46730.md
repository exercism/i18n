# Anhang zur Anleitung

## Hinweise

Du musst die Funktion `recite` implementieren, die den Liedtext von „The Twelve Days of Christmas“ ausgibt. Du kannst die vorgegebene Signatur verwenden, wenn du dir bei den Typen unsicher bist, aber lass dich davon nicht in deiner Kreativität einschränken.

Diese Übung arbeitet mit Textdaten. Aus historischen Gründen ist der Typ `String` in Haskell gleichbedeutend mit `[Char]`, einer Liste von Zeichen. Für einen effizienteren Umgang mit Textdaten kannst du den Typ `Text` verwenden.

Als optionale Erweiterung dieser Übung kannst du

- etwas über [String-Typen](https://haskell-lang.org/tutorial/string-types) in
  Haskell lesen.
- `- text` zu deiner Liste der Abhängigkeiten in package.yaml hinzufügen.
- `Data.Text` auf [die folgende
  Weise](https://hackernoon.com/4-steps-to-a-better-imports-list-in-haskell-43a3d868273c)
  importieren:

```haskell
import qualified Data.Text as T
import           Data.Text (Text)
```

- zum Beispiel `recite :: Int -> Int -> [Text]` schreiben und auf
  `Data.Text`-Kombinatoren wie z. B. `T.pack` verweisen.
- die Dokumentation für
  [`Data.Text`](https://hackage.haskell.org/package/text/docs/Data-Text.html) nachschlagen.
- alle Vorkommen von `String` in TwelveDays.hs durch `Text` ersetzen, also:

```haskell
recite :: Int -> Int -> [Text]
```

Dieser Teil ist völlig optional.
