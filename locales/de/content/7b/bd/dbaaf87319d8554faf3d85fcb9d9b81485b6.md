# Einführung

Cairo hat keinen nativen Typ für Zeichenketten, bietet aber zwei Möglichkeiten, mit ihnen umzugehen: kurze Zeichenketten mit einfachen Anführungszeichen und `ByteArray` mit doppelten Anführungszeichen.

Eine kurze Zeichenkette ist eine ASCII-Zeichenkette, bei der jedes Zeichen mit einem Byte kodiert wird.

Der Typ, den Cairo standardmäßig für kurze Zeichenketten verwendet, ist `felt252`, wodurch ihre maximale Länge nur 31 Zeichen beträgt.

```rust
// below are different ways to write the same value
let name: felt252 = 'Jane';     // short string format
let name: felt252 = 0x4a616e65; // byte format
let name: felt252 = 1247899237; // decimal format
```

Technisch gesehen kann jeder Ganzzahltyp, der kleiner als `felt252` ist, im Format für kurze Zeichenketten dargestellt werden.

```rust
// all of the below are equal u8 values, they are just written using different formats!
let lowercase_a_in_ascii: u8 = 'a';  // short string format
let lowercase_a_in_ascii: u8 = 0x61; // byte format
let lowercase_a_in_ascii: u8 = 97;   // decimal format
```

Für Zeichenketten, die länger als 31 Zeichen sind, stellt Cairo `ByteArray` bereit, das eine unbegrenzte Länge hat.

```rust
let long_string: ByteArray = "this is a string which has more than 31 characters";
```

ByteArrays können mit dem `+`-Operator verkettet werden:

```rust
"Jane" + " " + "Austen"
// => "Jane Austen"
```

Einige Sonderzeichen müssen mit einem vorangestellten Backslash maskiert werden, wie `\t` für einen Tabulator und `\n` für einen Zeilenumbruch in Zeichenketten.

```rust
"How is the weather today?\nIt's sunny"  
// =>
// How is the weather today?
// It's sunny
```

Sogar auf einzelne Bytes innerhalb eines ByteArrays kannst du über dessen Index zugreifen.

Sei aber vorsichtig: Der Typ des zurückgegebenen Bytes ist `u8` und nicht `ByteArray`!

```rust
let hello: ByteArray = "Hello World!";
let exclamation_mark: u8 = hello[11];
// => 33
```

Die Kernbibliothek bietet viele nützliche Methoden und Operatoren, um mit ByteArrays zu arbeiten.

Für weitere Informationen zu ByteArray-Methoden schau dir die [ByteArrayTrait-Dokumentation][docs] an.

Hier sind einige Beispiele:

```rust
let name: felt252 = 'Jane';
let mut greeting: ByteArray = "Welcome ";

// append_word appends a single word of a given number of bytes to the end of the ByteArray 
greeting.append_word(name, 4);
// => "Welcome Jane"

// rev returns a ByteArray with the all characters reversed
let rev_greeting = greeting.rev();
// => "enaJ emocleW"
```

[docs]: https://docs.swmansion.com/scarb/corelib/core-byte_array-ByteArrayTrait.html
