# Einführung

[repeat-while-Schleifen][repeat-loops] funktionieren ähnlich wie `while`-Schleifen, haben aber einen entscheidenden Unterschied: Die Bedingung wird erst geprüft, nachdem der Schleifenblock ausgeführt wurde, und nicht davor.
Deshalb führt eine `repeat-while`-Schleife ihren Block garantiert mindestens einmal aus.

```swift
repeat {
    print("This runs at least once")
} while false

print("Loop done")

// Prints:
// This runs at least once
// Loop done
```

[repeat-loops]: https://docs.swift.org/swift-book/LanguageGuide/ControlFlow.html#ID126
