# Anweisungen

Eure Majestät richtet in Kopenhagen, der Hauptstadt der [Kalmarer Union][kalmar_union], ein Abendessen aus.
Es ist die größte Feier des Jahres und alle Adligen sind eingeladen.
Doch im ganzen Land verbreiten sich Gerüchte, dass es eine Verschwörung gibt, Eure Majestät zu vergiften.

Ihre Majestät hat dich, den königlichen Giftfinder, gebeten, herauszufinden, ob Speisen oder Getränke vergiftet sind.
Ihre Majestät plant, als Speise nur **Mushroom pasties** zu servieren, aber bei den Getränken gibt es eine große Auswahl.

## 1. Prüfe, ob die Speise richtig ist

Es ist sehr wahrscheinlich, dass die Speise vergiftet ist, wenn sie nicht die ist, die Ihre Majestät bestellt hat.
Ist die Speise nicht die, die Ihre Majestät bestellt hat, sollte sie weggeworfen werden.

Implementiere die Methode `check_food?`, die das Argument `food` entgegennimmt, das den Namen der Speise als `String` enthält.
Die Methode sollte die Speise zurückgeben, wenn sie `Mushroom pasties` ist; andernfalls sollte sie `nil` zurückgeben.

```crystal
CastleDinner.check_food?("Mushroom pasties")
# => "Mushroom pasties"

CastleDinner.check_food?("Bread")
# => nil
```

## 2. Prüfe, ob das Getränk vergiftet ist

Es ist möglich, dass das Getränk vergiftet ist, aber es ist etwas schwieriger, das festzustellen.
Das Getränk ist vergiftet, wenn der Name den Buchstaben `i` **nicht** enthält; die Groß- und Kleinschreibung spielt keine Rolle.
Ist das Getränk vergiftet, sollte es weggeworfen werden.

Implementiere die Methode `check_drink?`, die das Argument `drink` entgegennimmt, das den Namen des Getränks als `String` enthält.
Die Methode sollte das Getränk zurückgeben, wenn es nicht vergiftet ist, andernfalls sollte sie `nil` zurückgeben.

```crystal
CastleDinner.check_drink?("Apple juice")
# => "Apple juice"

CastleDinner.check_drink?("Tea")
# => nil
```

## 3. Ersetze das Getränk

Eure Majestät möchte ihre Gäste schließlich nicht wegen Gift in ihrem Essen beunruhigen.
Wenn das Getränk also vergiftet ist, sollte es durch ein neues Getränk ersetzt werden, und zwar durch **Apple juice**.

Implementiere die Methode `replace_drink`, die das Argument `drink` entgegennimmt, das den Namen des Getränks als `String` enthält.
Die Methode sollte das Getränk zurückgeben, wenn es nicht vergiftet ist, andernfalls sollte sie `"Apple juice"` zurückgeben.

```crystal
CastleDinner.replace_drink("Orange juice")
# => "Orange juice"

CastleDinner.replace_drink("Tea")
# => "Apple juice"
```
