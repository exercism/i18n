# Ergänzung zu den Anweisungen

## Hinweise

Du sollst die Funktion `rotate` implementieren, die einen `Int` und einen `String` entgegennimmt und den String anschließend mit einer Rotationschiffre verschlüsselt.
Du kannst die vorgegebene Signatur verwenden, wenn du dir bei den Typen unsicher bist, aber lass dich davon nicht in deiner Kreativität einschränken.

Diese Übung arbeitet mit Textdaten. Aus historischen Gründen ist der Typ `String` in Haskell gleichbedeutend mit `[Char]`, einer Liste von Zeichen. Für einen effizienteren Umgang mit Textdaten kannst du den Typ `Text` verwenden.

Als optionale Erweiterung dieser Übung kannst du

- dich über [String-Typen](https://haskell-lang.org/tutorial/string-types) in Haskell informieren.
- `- text` zu deiner Liste der Abhängigkeiten in package.yaml hinzufügen.
- `Data.Text` auf [die folgende Weise](https://hackernoon.com/4-steps-to-a-better-imports-list-in-haskell-43a3d868273c) importieren:

```haskell
import qualified Data.Text as T
import           Data.Text (Text)
```

- den Typ `Text` verwenden, z. B. `rotate :: Int -> Text -> Text`, und `Data.Text`-Kombinatoren zum Beispiel als `T.pack` ansprechen.
- die Dokumentation für [`Data.Text`](https://hackage.haskell.org/package/text/docs/Data-Text.html) nachschlagen.
- in RotationalCipher.hs alle Vorkommen von `String` durch `Text` ersetzen, d. h.:

```haskell
rotate :: Int -> Text -> Text
```

Dieser Teil ist völlig optional.
