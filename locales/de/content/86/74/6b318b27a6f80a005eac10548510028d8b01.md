# Anleitung

In dieser Übung arbeitest du an einem Terminplaner für einen Schönheitssalon in New York, der am 15. September 2012 eröffnet wurde.

Du hast vier Aufgaben, bei denen es jeweils um Termindaten geht. Datum und Uhrzeit verwenden eines der folgenden drei Formate:

- `"7/25/2019 13:45:00"`
- `"July 25, 2019 13:45:00"`
- `"Thursday, July 25, 2019 13:45:00"`

Die Tests setzen die Kultur automatisch auf `en-US`. Du musst die Kultur nicht selbst festlegen oder angeben.

## 1. Termindatum parsen

Implementiere die (_statische_) Methode `Appointment.Schedule()`, um eine textuelle Darstellung eines Termindatums in das entsprechende `DateTime`-Format zu parsen:

```csharp
Appointment.Schedule("7/25/2019 13:45:00")
// => new DateTime(2019, 7, 25, 13, 45, 0)
```

## 2. Prüfen, ob ein Termin bereits vorbei ist

Implementiere die (_statische_) Methode `Appointment.HasPassed()`, die ein Termindatum entgegennimmt und prüft, ob der Termin irgendwann in der Vergangenheit lag:

```csharp
Appointment.HasPassed(new DateTime(1999, 12, 31, 9, 0, 0))
// => true
```

## 3. Prüfen, ob ein Termin am Nachmittag liegt

Implementiere die (_statische_) Methode `Appointment.IsAfternoonAppointment()`, die ein Termindatum entgegennimmt und prüft, ob der Termin am Nachmittag liegt (>= 12:00 und < 18:00):

```csharp
Appointment.IsAfternoonAppointment(new DateTime(2019, 03, 29, 15, 0, 0))
// => true
```

## 4. Zeit und Datum des Termins beschreiben

Implementiere die (_statische_) Methode `Appointment.Description()`, die ein Termindatum entgegennimmt und eine Beschreibung dieses Datums und dieser Uhrzeit zurückgibt:

```csharp
Appointment.Description(new DateTime(2019, 03, 29, 15, 0, 0))
// => "You have an appointment on 3/29/2019 3:00:00 PM."
```

## 5. Das Jubiläumsdatum zurückgeben

Implementiere die (_statische_) Methode `Appointment.AnniversaryDate()`, die das diesjährige Jubiläumsdatum zurückgibt, den 15. September:

```csharp
Appointment.AnniversaryDate()
// => new DateTime(2019, 9, 15, 0, 0, 0)
```
