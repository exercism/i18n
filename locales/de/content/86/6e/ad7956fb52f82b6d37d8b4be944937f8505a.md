# Über

In Common Lisp wird die Zeit auf drei Arten dargestellt:

- Die universelle Zeit ist eine absolute Zeit, eine Ganzzahl, die die Anzahl der Sekunden seit `1900-01-01T00:00:00Z` angibt (also Mitternacht am 1. Januar 1900 in UTC).
- Die dekodierte Zeit ist ein Tupel aus 9 Werten, die zusammen einen bestimmten Kalenderzeitpunkt darstellen: Sekunden, Minuten, Stunde, Tag des Monats, Monat, Jahr, Wochentag, Sommerzeit-Flag, Zeitzone.
(Wird unten ausführlich behandelt.)
- Die interne Zeit ist eine positive Ganzzahl in implementierungsabhängigen ‚internen Zeiteinheiten', mit denen man die Laufzeit messen kann.

## Universelle Zeit

Um die aktuelle universelle Zeit zu erhalten, verwendet man `get-universal-time` oder `get-decoded-time`.
Ersteres gibt die aktuellen Sekunden seit `1900-01-01T00:00Z` zurück, Letzteres dieselben Daten im dekodierten Format.

Beachte, dass es unmöglich ist, Datumsangaben von vor 1900 zu kodieren, da diese Zahl eine positive Ganzzahl ist.

## Dekodierte Zeit

`decode-universal-time` und `encode-universal-time` sind die wichtigsten Funktionen für die Arbeit mit Zeit.
Ersteres nimmt eine universelle Zeit entgegen und gibt einen dekodierten Zeitwert als [mehrere Werte][concept-multiple-values] zurück, Letzteres nimmt die dekodierten Zeitwerte als Argumente entgegen und gibt eine universelle Zeit zurück.

Beide nehmen ein optionales Zeitzonen-Argument entgegen.
Das Format der Zeitzone wird unten beschrieben.

Eine dekodierte Zeit ist eine Menge von Werten:

- *Sekunden*: eine Ganzzahl zwischen 0 und 59
- *Minuten*: eine Ganzzahl zwischen 0 und 59
- *Stunde*: eine Ganzzahl zwischen 0 und 23
- *Tag des Monats*: eine Ganzzahl zwischen 1 und 31 (die Obergrenze hängt natürlich vom Monat und vom Jahr ab)
- *Monat*: eine Ganzzahl zwischen 1 und 12
- *Jahr*: eine Ganzzahl, die das Jahr angibt.
- *Wochentag*: eine Ganzzahl zwischen 0 und 6. 0 bedeutet Montag, 1 bedeutet Dienstag usw. ... 6 bedeutet Sonntag.
- *Sommerzeit-Flag*: ein wahrer Wert zeigt an, dass die Sommerzeit in Kraft ist.
- *Zeitzone*: eine Anzahl von Stunden zwischen -24 und 24, die den Versatz zu UTC angibt.
Die Zahl ist eine rationale Zahl und muss ein Vielfaches von `1/3600` sein.

```lisp
(encode-universal-time 1 2 3 4 5 2000 0) ; => 3166398121
(decode-universal-time 3166398121 0)     ; => 1
                                         ;    2
                                         ;    3
                                         ;    4
                                         ;    5
                                         ;    2000
                                         ;    3 (Thursday)
                                         ;    NIL
                                         ;    0
(decode-universal-time 2208988800 0)     ; => 0
                                         ;    0
                                         ;    0
                                         ;    1
                                         ;    1
                                         ;    1970
                                         ;    3
                                         ;    NIL
                                         ;    0
```

Beachte, dass es ein interessantes Verhalten gibt, wenn der Zeitzonen-Parameter nicht angegeben wird.
Weitere Details findest du in der Dokumentation zu [`decode-universal-time`][hyperspec-decode-universal-time] und [`encode-universal-time`][hyperspec-encode-universal-time].

## Interne Zeit

Eine interne Zeit ist eine positive Ganzzahl von ‚internen Zeiteinheiten'.
Die Differenz zwischen zwei davon kann verwendet werden, um die Zeit während der Laufzeit zu messen.

- `get-internal-real-time` gibt die aktuelle „reale" oder „Uhrzeit" zurück.
- `get-internal-run-time` ist stark von der Implementierung abhängig und kann zum Beispiel Zeit für Paging oder Garbage Collection enthalten oder auch nicht.

Die Variable `internal-time-units-per-second` enthält einen Wert, der die Anzahl der ‚internen Zeiteinheiten' pro Sekunde für die aktuelle laufende Lisp-Umgebung angibt.
