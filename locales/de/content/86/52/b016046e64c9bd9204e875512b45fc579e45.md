# Anleitung

Der Schönheitssalon in New York, dem du in der Übung „Booking Up For Beauty“ geholfen hast, läuft gut, und viele seiner Kundinnen und Kunden sind inzwischen Stammkunden.
Statt jeden Termin einzeln zu buchen, hat ein Stammkunde eine feste Abmachung: „jeden zweiten Dienstag“, „den letzten Freitag im Monat“ und so weiter.
Die Inhaberin hat dich um einen Helfer gebeten, der die Termine hinter diesen Abmachungen ausrechnet, ebenso wie die Termine der monatlichen Routine des Salons.

## 1. Den festen Termin eines Stammkunden finden

Implementiere die Methode `SalonCalendar.standingAppointment()`, die ein Jahr, einen Monat, ein Vorkommen (`1` für das erste, `2` für das zweite und so weiter) und einen Wochentag entgegennimmt.
Sie gibt das Datum zurück, auf das dieses Vorkommen des Wochentags im Monat fällt:

```java
SalonCalendar calendar = new SalonCalendar();
calendar.standingAppointment(2024, Month.AUGUST, 2, DayOfWeek.TUESDAY);
// => LocalDate.of(2024, 8, 13)
```

## 2. Den letzten Termin eines Stammkunden im Monat finden

Manche Stammkunden bevorzugen das letzte Vorkommen ihres Wochentags im Monat.
Implementiere die Methode `SalonCalendar.lastAppointment()`, die ein Jahr, einen Monat und einen Wochentag entgegennimmt und das Datum des letzten Vorkommens dieses Wochentags im Monat zurückgibt:

```java
SalonCalendar calendar = new SalonCalendar();
calendar.lastAppointment(2024, Month.AUGUST, DayOfWeek.FRIDAY);
// => LocalDate.of(2024, 8, 30)
```

## 3. Den nächsten freien Tag für einen Laufkunden finden

Eine Kundin am Empfang fragt nach „dem nächsten Samstag“.
Ist der Tag, an dem sie fragt, selbst schon ein Samstag, meint sie genau diesen Tag.
Implementiere die Methode `SalonCalendar.nextAvailable()`, die ein Datum und einen Wochentag entgegennimmt und das erste Datum ab dem angegebenen Datum zurückgibt, das auf diesen Wochentag fällt:

```java
SalonCalendar calendar = new SalonCalendar();
calendar.nextAvailable(LocalDate.of(2024, 8, 15), DayOfWeek.SATURDAY);
// => LocalDate.of(2024, 8, 17)
calendar.nextAvailable(LocalDate.of(2024, 8, 17), DayOfWeek.SATURDAY);
// => LocalDate.of(2024, 8, 17)
```

## 4. Den Buchhaltungstag finden

Der Salon schließt seine Bücher am letzten Tag jedes Monats.
Am Wochenende ist der Salon allerdings geschlossen. Fällt der letzte Tag des Monats also auf einen Samstag oder einen Sonntag, werden die Bücher am Freitag davor geschlossen.
Implementiere die Methode `SalonCalendar.bookkeepingDay()`, die ein Jahr und einen Monat entgegennimmt und den Buchhaltungstag dieses Monats zurückgibt:

```java
SalonCalendar calendar = new SalonCalendar();
calendar.bookkeepingDay(2024, Month.SEPTEMBER);
// => LocalDate.of(2024, 9, 30)
calendar.bookkeepingDay(2024, Month.AUGUST);
// => LocalDate.of(2024, 8, 30)
```

## 5. Die Wochenendregel für den Zahltag wiederverwenden

Das Personal wird am 15. jedes Monats bezahlt, mit derselben Wochenendregel: Fällt der 15. auf einen Samstag oder einen Sonntag, ist der Zahltag der Freitag davor.
Statt die Regel ein zweites Mal zu schreiben, machst du daraus einen wiederverwendbaren Adjuster.

Implementiere die Methode `SalonCalendar.precedingWorkday()`, die einen `TemporalAdjuster` zurückgibt, der einen Wochentag unverändert lässt und einen Samstag oder einen Sonntag auf den vorhergehenden Freitag zurückschiebt.
Implementiere dann die Methode `SalonCalendar.payday()`, die ein Jahr und einen Monat entgegennimmt und dabei diesen Adjuster verwendet:

```java
SalonCalendar calendar = new SalonCalendar();
LocalDate.of(2024, 6, 15).with(calendar.precedingWorkday());
// => LocalDate.of(2024, 6, 14)
calendar.payday(2024, Month.JUNE);
// => LocalDate.of(2024, 6, 14)
calendar.payday(2024, Month.AUGUST);
// => LocalDate.of(2024, 8, 15)
```

Du kannst gern zurückgehen und den Adjuster auch in `bookkeepingDay()` verwenden.
