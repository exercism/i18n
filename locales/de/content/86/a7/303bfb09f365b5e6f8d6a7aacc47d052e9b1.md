# Tests

Um die Tests auszuführen, baust du die Test-Runner-Datei für eine gegebene Übung zusammen und führst sie aus, entweder über die GUI des MARS-Simulators oder auf der Kommandozeile. Um sie auf der Kommandozeile auszuführen, gibst du zuerst die Runner-Datei und dann deine Implementierung an, und zwar so:

    java -jar /path/to/mars.jar nc runner.mips impl.mips

Um sie in der GUI auszuführen, `include` deine Implementierung am Ende von „runner.mips“, indem du die letzte Zeile auskommentierst.

Der Test-Runner endet entweder mit einer „success“-Meldung oder bricht bei einem fehlgeschlagenen Test mit einer Meldung ab, die den Eingabewert angibt, für den dieser Test fehlgeschlagen ist.
