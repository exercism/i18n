# Hinweise

## Allgemein

- Verwende den eingebauten [Array-Typ][array].

## 1. Definiere eine Methode, die ein leeres Sprachen-Array zurückgibt

- Die Funktion muss ein leeres Array mit dem Typ `Array(String)` zurückgeben.
- Die Syntax zum Erstellen eines leeren Arrays ist `[]`.
  Der Typ kann mit `of String` angegeben werden.

## 2. Definiere eine Methode, die dem Array eine Sprache hinzufügt

- Ein Element kann mit `<<` an ein Array angehängt werden.

## 3. Definiere eine Methode, die eine Sprache aus dem Array entfernt

- Crystal [bietet eine Methode][pop], um das letzte Element aus einem Array zu entfernen.

## 4. Definiere eine Methode, die das n-te Element im Array zurückgibt

- Crystal [bietet eine Methode][index], um das Element an einem bestimmten Index in einem Array zu erhalten.

## 5. Definiere eine Methode, die einen String aus Sprachen parst

- Crystal [bietet eine Methode][split], um einen String mithilfe eines Trennzeichens in ein Array umzuwandeln.
