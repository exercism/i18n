# Hinweise

In dieser Übung geht es um veränderlichen Zustand, auf den aus mehreren Threads sicher zugegriffen werden kann. Scala bietet eine Reihe von Möglichkeiten, veränderlichen Zustand zu schützen. Wenn du dich mit Nebenläufigkeit in Java auskennst, kannst du in Scala die Nebenläufigkeitsunterstützung von Java nutzen, etwa den synchronized-Block von Java.

## Häufige Stolperfallen

In Scala gibt es zwei Wege, veränderlichen Zustand zu erreichen: Du verwendest ein „var" oder ein veränderliches Objekt.
Zwei häufige Fehler dabei sind:
- Verwende kein „var", das gleichzeitig ein veränderliches Objekt ist. Eines von beidem reicht, aber nicht beides zusammen.
- Gib das „var" oder das veränderliche Objekt nicht nach außen preis. Mach sie also „private" und wandle das veränderliche Objekt in ein unveränderliches um, bevor du es als Wert zurückgibst.
