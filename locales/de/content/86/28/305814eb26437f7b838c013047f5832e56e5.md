# Einführung

Zu wissen, welchen Typ ein Datenelement hat, ist oft sehr wichtig, damit Code reibungslos und ohne Fehler läuft.

JavaScript bietet mehrere Möglichkeiten, den Typ eines Werts oder Objekts zu prüfen.

```exercism/note
Die Mechanismen von JavaScript zur Typprüfung können etwas unzuverlässig sein.

Für bessere Typsicherheit und stärkere Typen solltest du wahrscheinlich TypeScript verwenden, eine Sprache, die auf JavaScript aufbaut, aber die Typsyntax einer statisch typisierten Sprache mitbringt.
```

## Der Operator `typeof`

Der Operator `typeof` gibt den Typ seines Operanden zurück.
Die Ausgabe ist ein String, der dem Namen eines der [primitiven Datentypen][primitives] entspricht, außer bei `"null"`.
Er kann auch `"function"` oder `"object"` sein.

```javascript
typeof undefined;
// => "undefined"

typeof true;
// => "boolean"

typeof 42;
// => "number"

typeof 'Hello, World!';
// => "string"

typeof function () {
  return 'Hello, World';
};
// => "function"

typeof [1, 2, 3, 4];
// => "object"

typeof { city: 'Stockholm', country: 'Sweden' };
// => "object"
```

Aus [historischen Gründen][`typeof null` is `"object"`].

## Der Operator `instanceof`

Um den Typ eines Objekts zu prüfen, kannst du den Operator `instanceof` verwenden.
Er ergibt einen `boolean`-Wert, je nachdem, ob der zweite Operand in der [Prototypkette][prototype chain] des ersten Operanden enthalten ist.
Zur Klarstellung: `instanceof` gibt zurück, ob der erste Operand eine Instanz des zweiten Operanden oder einer seiner Unterklassen ist.
`instanceof` funktioniert nur mit Objekten.

```javascript
class Beverage {
  // ...
}

// The Coffee class is a child of the Beverage class.
class Coffee extends Beverage {
  // ...
}

const java = new Coffee();

java instanceof Coffee;
// => true

java instanceof Beverage;
// => true
```

````exercism/advanced
Die Klasse `Array` hat eine Methode namens `Array.isArray()`, die prüft, ob ihr Argument ein Array ist.

Während `instanceof Array` bei einem Array nicht funktioniert, das in einem anderen Realm erstellt wurde, etwa einem `iframe` in einer Webseite, funktioniert `Array.isArray()`.

Das liegt daran, dass die Klasse Array in jedem Realm einen anderen Konstruktor hat und jeder `iframe` seinen eigenen Realm besitzt. Die Funktion in der Prototypkette ist also eine andere, wodurch `instanceof Array` fehlschlägt.
`Array.isArray()` kann das ignorieren und sollte nach Möglichkeit immer verwendet werden.

Außerdem vermeidet es falsch-positive Ergebnisse, bei denen ein Objekt gar kein `Array` ist und `Array` nur in seiner Prototypkette hat.

```javascript
({ __proto__: Array.prototype }) instanceof Array
// => true

Array.isArray({ __proto__: Array.prototype })
// => false
```

````

## Der Operator `in`

Der Operator `in` gibt zurück, ob der erste Operand eine Eigenschaft des zweiten Operanden ist.
Er prüft nicht, ob die Eigenschaft einen definierten Wert hat.
Eine Eigenschaft, die auf `undefined` gesetzt ist, wird von `in` trotzdem erkannt.

```javascript
class Coffee {
  constructor() {
    this.temperature = 'hot';
    this.isDarkMatter = undefined;
  }

  coolDown() {
    this.temperature = 'warm';
  }
}

const espresso = new Coffee();

'temperature' in espresso;
// => true

'color' in espresso;
// => false

'isDarkMatter' in espresso;
// => true
```

````exercism/note
`in` gibt bei geerbten Eigenschaften und Methoden `true` zurück.

```javascript
"coolDown" in espresso
// => true

"constructor" in espresso
// => true
```

Um das zu vermeiden, verwende stattdessen `Object.hasOwn()`
````

## Die Funktion `Object.hasOwn()`

Die Methode `Object.hasOwn()` gibt zurück, ob das angegebene Objekt _die angegebene Eigenschaft selbst besitzt_ (sie also nicht geerbt wurde und keine Methode ist).

```javascript
class Coffee {
  constructor() {
    this.temperature = 'hot';
  }

  coolDown() {
    this.temperature = 'warm';
  }
}
const cappuccino = new Coffee();

Object.hasOwn(cappucino, 'temperature');
// => true

Object.hasOwn(cappucino, 'constructor');
// => false

Object.hasOwn(cappucino, 'coolDown');
// => false
```
