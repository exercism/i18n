# Über

Wenn du Daten modellierst, die nur eine bestimmte Menge möglicher Zustände annehmen können, etwa Wochentage, Himmelsrichtungen oder Tasten auf einem Controller, dann haben einfache Typen wie `Int` oder `String` große Nachteile.
Bei Ganzzahlen oder Strings muss dein Code ständig auf ungültige Werte prüfen (etwa einen Statuscode wie `999` oder einen Tippfehler wie `"leftt"`), und menschliche Leser können nicht leicht erkennen, wofür die Zahlen stehen.

Swift löst dieses Problem mit [_Enumerationen_][enumerations] (oft kurz *Enums* genannt).
Eine Enumeration definiert einen gemeinsamen Typ für eine Gruppe zusammengehöriger, benannter Werte. Da der Compiler alle möglichen Fälle im Voraus kennt, kann er deinen Code zur Compile-Zeit auf Korrektheit und Vollständigkeit prüfen.
Enumerationen können außerdem Methoden, Initialisierer und berechnete Eigenschaften haben.

## Enumerationen definieren

Definiere eine Enumeration mit dem Schlüsselwort `enum`, gefolgt vom Typnamen, und liste ihre Fälle in geschweiften Klammern auf.
Nach Swift-Konvention verwendet der Typname `UpperCamelCase`, während jeder Fall `lowerCamelCase` verwendet:

```swift
enum NESButton {
    case up
    case down
    case left
    case right
    case a
    case b
    case select
    case start
}
```

Du kannst auch mehrere Fälle in einer Zeile definieren, durch Kommas getrennt:

```swift
enum NESButton {
    case up, down, left, right, a, b, select, start
}
```

Um auf einen Fall einer Enumeration zu verweisen, schreibst du den Typnamen der Enumeration, einen Punkt (`.`) und den Namen des Falls. Sobald der Typ bekannt ist oder vom Compiler abgeleitet werden kann, kannst du den Typnamen weglassen und die kürzere Punkt-Syntax verwenden:

```swift
var lastPressed = NESButton.up

// Swift infers the type, so you can omit the type name:
lastPressed = .down

let konamiCode: [NESButton] = [.up, .up, .down, .down, .left, .right, .left, .right, .b, .a]
```

## Enumerationen und switch-Anweisungen

Enumerationen lassen sich nahtlos mit [`switch`-Anweisungen][enums-and-switches] kombinieren.
Da ein `switch` in Swift vollständig sein muss, stellt der Compiler sicher, dass du jeden möglichen Fall behandelst:

```swift
lastPressed = .left
switch lastPressed {
case .up: print("You pressed the UP button")
case .down: print("You pressed the DOWN button")
case .left: print("You pressed the LEFT button")
case .right: print("You pressed the RIGHT button")
case .a: print("You pressed the A button")
case .b: print("You pressed the B button")
case .select: print("You pressed the SELECT button")
case .start: print("You pressed the START button")
}
// Prints "You pressed the LEFT button"
```

Wenn du einen Fall auslässt, ohne eine `default`-Klausel anzugeben, meldet der Compiler einen Fehler:

```swift
switch lastPressed {
case .up, .down, .left, .right:
    print("You pressed a direction button.")
}
// Error: Switch must be exhaustive
```

Alle Fälle explizit aufzulisten ist oft besser, als `default` zu verwenden. So wird der Compiler dich sofort darauf hinweisen, jede `switch`-Anweisung zu aktualisieren, die diese Enumeration behandelt, wenn du später einen neuen Fall hinzufügst.

## Methoden und Initialisierer

Enumerationen können genau wie Klassen und Structs Methoden und eigene Initialisierer definieren. Innerhalb einer Methode einer Enumeration bezieht sich `self` auf den aktuellen Fallwert:

```swift
enum Coin {
    case heads
    case tails

    init(_ value: Int) {
        if value.isMultiple(of: 2) {
            self = .heads
        } else {
            self = .tails
        }
    }

    func flip() -> Coin {
        switch self {
        case .heads: return .tails
        case .tails: return .heads
        }
    }
}

let tails = Coin(13)     // .tails
let heads = Coin(0)      // .heads
let flipped = heads.flip() // .tails
```

## Rohwerte

Fälle einer Enumeration können mit Standardwerten vorbelegt werden, den sogenannten [_Rohwerten_][raw-values].
Alle Rohwerte einer Enumeration müssen denselben Typ haben (etwa `Int`, `String` oder `Character`):

```swift
enum NESButton: Character {
    case up = "⬆️"
    case down = "⬇️"
    case left = "⬅️"
    case right = "➡️"
    case a = "🅰️"
    case b = "🅱️"
    case select = "✅"
    case start = "🚦"
}

print(NESButton.left.rawValue) // Prints "⬅️"
```

Du kannst eine Enumeration mit `init(rawValue:)` aus einem Rohwert initialisieren. Da ein ungültiger Rohwert übergeben werden kann, gibt dieser Initialisierer einen Optional zurück:

```swift
let upButton = NESButton(rawValue: "⬆️") // Optional(NESButton.up)
let invalid = NESButton(rawValue: "🙄")  // nil
```

Swift kann für Enumerationen mit `String` und `Int` automatisch Rohwerte vergeben:

- Bei `String`-Enumerationen entspricht der Rohwert jedes Falls standardmäßig dem Namen des Falls.
- Bei `Int`-Enumerationen beginnen die Rohwerte bei `0` und werden, sofern nicht anders angegeben, um 1 erhöht.

```swift
enum Planet: Int {
    case mercury = 1, venus, earth, mars
}

print(Planet.earth.rawValue) // Prints 3
```

## Assoziierte Werte

Fälle einer Enumeration können zusätzlich eigene Werte unterschiedlicher Typen speichern, die als [_assoziierte Werte_][associated-values] bezeichnet werden:

```swift
enum Suit: Character {
    case diamonds = "♦️", clubs = "♣️", hearts = "♥️", spades = "♠️"
}

enum Card {
    case ace(Suit)
    case king(Suit)
    case queen(Suit)
    case jack(Suit)
    case number(Suit, Int)

    func description() -> String {
        switch self {
        case .ace(let suit): return "A\(suit.rawValue)"
        case .king(let suit): return "K\(suit.rawValue)"
        case .queen(let suit): return "Q\(suit.rawValue)"
        case .jack(let suit): return "J\(suit.rawValue)"
        case let .number(suit, value): return "\(value)\(suit.rawValue)"
        }
    }
}

let aceOfSpades = Card.ace(.spades)
let twoOfHearts = Card.number(.hearts, 2)

print(aceOfSpades.description()) // Prints "A♠️"
print(twoOfHearts.description()) // Prints "2♥️"
```

Eine Enumeration kann entweder Rohwerte oder assoziierte Werte verwenden, aber nicht beides.

## Rekursive Enumerationen

Eine [rekursive Enumeration][recursive-enumerations] ist eine Enumeration, die für einen oder mehrere Fälle eine weitere Instanz der Enumeration als assoziierten Wert enthält.
Um die Rekursion zu ermöglichen, versiehst du den Fall (oder die gesamte Enumeration) mit dem Schlüsselwort `indirect`:

```swift
enum BinaryTree {
    case leaf(value: Int)
    indirect case node(left: BinaryTree, value: Int, right: BinaryTree)
}

let tree: BinaryTree = .node(
    left: .leaf(value: 1),
    value: 3,
    right: .node(left: .leaf(value: 5), value: 6, right: .leaf(value: 9))
)
```
