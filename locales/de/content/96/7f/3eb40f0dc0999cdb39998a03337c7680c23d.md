# Ergänzung zu den Anweisungen

## Theoreme in Lean beweisen

Das Beweisen von Theoremen ist ein fester Bestandteil von Lean.
Es ermöglicht Programmierenden, Eigenschaften ihrer Programme zu beweisen, Rückschlüsse auf deren Verhalten zu ziehen und Einschränkungen und Spezifikationen auf Typebene zu kodieren.

[Dieses Kapitel][introduction] bietet eine gute Einführung in das Beweisen von Theoremen in Lean.
Für einen tieferen Einblick ist [dieses Buch][advanced] als offizielle Ressource auf der Lean-Website aufgeführt.

Lean bietet viele Taktiken, mit denen sich Beweise oder Teile davon automatisieren lassen. 
Vielleicht möchtest du einen Blick in eine [Sprachreferenz][reference] werfen.

~~~~exercism/advanced
Wir können das Compiler-Attribut `csimp` für ein Theorem verwenden, das die Gleichheit zweier Definitionen beweist.
Dieses Attribut weist den Compiler an, die zweite Definition anstelle der ersten zu verwenden:

```lean
@[csimp]
theorem custom_reverse_eq_spec_reverse : @Extra.custom_reverse = @List.reverse := by
    ... -- proof here

-- now any occurrence of `Extra.custom_reverse` may now compile to `List.reverse`.
```

Besonders nützlich ist es, wenn eine Implementierung effizienter, aber weniger klar ist.
Wir können eine einfache Spezifikation schreiben und den kompilierten Code stattdessen die effizientere Implementierung verwenden lassen.
Viele Funktionen von `List` und `Array` folgen diesem Muster.
~~~~
