# Über

In C# wird das [`null`-Literal][null-keyword] verwendet, um das Fehlen eines Werts auszudrücken. Ein _nullable_-Typ ist ein Typ, der `null`-Werte zulässt.

Vor C# 8.0 waren Verweistypen immer nullable und Werttypen nicht. Ein [Werttyp kann jedoch nullable gemacht werden][nullable-value-types], indem du ein Fragezeichen (`?`) anhängst.

```csharp
string nullableReferenceType = "hello";
nullableReferenceType = null; // Valid as type is nullable

int nonNullableValueType = 5;
nonNullableValueType = null; // Compile error as type is not nullable

int? nullableValueType = 5; // Define nullable value type
nullableValueType = null;   // Valid as type is nullable
```

Der Zugriff auf einen Member einer Variable, deren Wert `null` ist, lässt sich problemlos kompilieren, führt aber zur Laufzeit dazu, dass eine `NullReferenceException` ausgelöst wird:

```csharp
string sentence = "What a nice day!";

// Throws NullReferenceException at runtime
sentence.Length;
```

Um dieser häufigen Art von Fehlern entgegenzuwirken, kannst du in C# 8 ein [Feature aktivieren][nullable-csharp-8], durch das [Verweistypen standardmäßig nicht nullable sind][nullable-reference-types]:

```csharp
string nonNullableReferenceType = "book";
nonNullableReferenceType = null; // Compile warning (no error!)

string? nullableReferenceType = "movie";
nullableReferenceType = null; // Valid as type is nullable
```

Um [sicher mit nullable Werten zu arbeiten][nullable-types-tutorial], solltest du prüfen, ob sie `null` sind, bevor du mit ihnen arbeitest:

```csharp
string NormalizedName(string? name)
{
    if (name == null)
    {
        return "UNKNOWN";
    }
    else
    {
        // Value is not null at this point, so no compile warning
        // and no runtime NullReferenceException being thrown
        return name.ToUpper();
    }
}

NormalizedName(null); // => "UNKNOWN"
NormalizedName("Elisabeth"); // => "ELISABETH"
```

Der [`??`-Operator][null-coalescing-operator] ermöglicht es, einen Standardwert zurückzugeben, wenn der Wert `null` ist:

```csharp
string? name1 = "John";
name1 ?? "Paul"; // => "John"

string? name2 = null;
name2 ?? "George"; // => "George"
```

Der [`?.`-Operator][null-conditional-operator] ermöglicht es, Member auf einem möglicherweise `null`-Wert sicher aufzurufen:

```csharp
string? fruit = "apple";
fruit?.Length; // => 5

string? vegetable = null;
vegetable?.Length; // => null
```

Wenn der Compiler glaubt, dass ein Wert `null` sein könnte, du aber sicher bist, dass er es nicht ist, kannst du den [`!.`-Operator][null-forgiving-operator] verwenden, um die Warnung zu unterdrücken. Verwende diesen Operator aber nur als letztes Mittel.

```csharp
void PrintName(string? name)
{
    // Assume that the IsValid() method only return true
    // when its argument is not null
    if (IsValid(name))
    {
        // No compile warning
        Console.WriteLine(name!.Length);
    }
}
```
