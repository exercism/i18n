# Unnötige if-Anweisung

Statt einen Block mit `if (...) {}` zu erstellen, kannst du direkt den booleschen Wert zurückgeben, den die Prüfung des Parameterwerts liefert.

Zum Beispiel wird aus dem Folgenden:

```javascript
if (param === true) {
  return true;
}
```

das hier:

```javascript
return param === true;
```
