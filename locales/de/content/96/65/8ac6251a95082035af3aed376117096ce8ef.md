# Anleitung

In dieser Übung schreibst du etwas Code, der dir bei der Vorbereitung auf den Kauf eines Fahrzeugs hilft.

Du hast drei Aufgaben: eine, um festzustellen, ob du einen Führerschein brauchst, eine, die dir bei der Wahl zwischen zwei Fahrzeugen hilft, und eine, um den akzeptablen Preis für ein gebrauchtes Fahrzeug zu schätzen.

## 1. Finde heraus, ob du einen Führerschein brauchst

Manche Fahrzeugarten darfst du nur mit einem Führerschein fahren.
Geh davon aus, dass nur die Arten `"car"` und `"truck"` einen Führerschein erfordern. Alles andere darfst du ohne Führerschein fahren.

Implementiere die Funktion `NeedsLicense(kind)`, die die Fahrzeugart entgegennimmt und einen booleschen Wert zurückgibt, der angibt, ob du für diese Fahrzeugart einen Führerschein brauchst.

```go
needLicense := NeedsLicense("car")
// => true

needLicense = NeedsLicense("bike")
// => false

needLicense = NeedsLicense("truck")
// => true
```

## 2. Wähle zwischen zwei möglichen Fahrzeugen

Du vergleichst deine Optionen an verfügbaren Fahrzeugen.
Du schaffst es, die Auswahl auf zwei Optionen einzugrenzen, aber bei der endgültigen Entscheidung brauchst du Hilfe.
Dafür implementierst du die Funktion `ChooseVehicle(option1, option2)`, die zwei Fahrzeuge als Argumente entgegennimmt und eine Entscheidung zurückgibt, die die Option enthält, die in lexikografischer Reihenfolge zuerst kommt.

```go
vehicle := ChooseVehicle("Wuling Hongguang", "Toyota Corolla")
// => "Toyota Corolla is clearly the better choice."

ChooseVehicle("Volkswagen Beetle", "Volkswagen Golf")
// => "Volkswagen Beetle is clearly the better choice."
```

## 3. Schätze den Preis für ein gebrauchtes Fahrzeug

Jetzt, wo du dich entschieden hast, willst du sicherstellen, dass du beim Händler einen fairen Preis bekommst.
Da du ein gebrauchtes Fahrzeug kaufen möchtest, hängt der Preis davon ab, wie alt das Fahrzeug ist.
Für eine grobe Schätzung geh davon aus, dass das Fahrzeug 80 % des ursprünglichen Preises kostet, wenn es weniger als 3 Jahre alt ist.
Ist es mindestens 10 Jahre alt, kostet es 50 %.
Ist das Fahrzeug mindestens 3 Jahre alt, aber weniger als 10 Jahre, kostet es 70 % des ursprünglichen Preises.

Implementiere die Funktion `CalculateResellPrice(originalPrice, age)`, die diese Logik mit `if`, `else if` und `else` umsetzt (es gibt auch andere Wege, wenn du üben möchtest).
Sie nimmt den ursprünglichen Preis und das Alter des Fahrzeugs als Argumente entgegen und gibt den geschätzten Preis beim Händler zurück.

```go
CalculateResellPrice(1000, 1)
// => 800

CalculateResellPrice(1000, 5)
// => 700

CalculateResellPrice(1000, 15)
// => 500
```

**Hinweis:** Der Rückgabewert ist ein `float64`.
