# Anleitung

Täglich hält der Bootsmann an Deck ein Briefing zur Wache ab: eine feste Begrüßung, einen Appell der Crew im Dienst und zum Schluss eine Verabschiedung. Zerlege das Briefing in kleine benannte Zeilen und setze sie zusammen.

Für diese Übung bearbeitest du **zwei Dateien**:

- `bosuns-briefing/helpers/helpers.factor`: kleine wiederverwendbare Bausteine. Vokabular: `bosuns-briefing.helpers`.
- `bosuns-briefing/bosuns-briefing.factor`: die Hauptdatei, die die Helfer zusammensetzt. Vokabular: `bosuns-briefing`.

## 1. Begrüßung

Definiere in `helpers.factor` `greeting` so, dass die Definition den festen Eröffnungs-String `"All hands, attention!"` zurückgibt.

```factor
greeting .
! => "All hands, attention!"
```

## 2. Crew-Zeile

Definiere in `helpers.factor` `crew-line` so, dass die Definition einen Namens-String entgegennimmt und diesen Namen mit dem Präfix `"  - "` zurückgibt (zwei Leerzeichen, ein Bindestrich, ein Leerzeichen).

```factor
"Lopez" crew-line .
! => "  - Lopez"
```

## 3. Verabschiedung

Definiere in `helpers.factor` `closing` so, dass die Definition den festen Verabschiedungs-String `"Carry on."` zurückgibt.

```factor
closing .
! => "Carry on."
```

## 4. Namensliste

Definiere in `bosuns-briefing.factor` `roster` so, dass die Definition ein Array von Crew-Namen entgegennimmt und einen einzelnen mehrzeiligen String zurückgibt, in dem jeder Name durch `crew-line` formatiert und die Einträge durch Zeilenumbrüche verbunden sind.

```factor
{ "Lopez" "Mwangi" } roster .
! => "  - Lopez\n  - Mwangi"

{ } roster .
! => ""
```

## 5. Briefing

Definiere in `bosuns-briefing.factor` `briefing` so, dass die Definition ein Array von Crew-Namen entgegennimmt und das vollständige Briefing als einzelnen String zurückgibt: die Begrüßung in der ersten Zeile, die Namensliste in den folgenden Zeilen und die Verabschiedung in der letzten Zeile. Nutze dazu die Helfer und `roster`.

```factor
{ "Lopez" "Mwangi" } briefing .
! => "All hands, attention!\n  - Lopez\n  - Mwangi\nCarry on."

{ } briefing .
! => "All hands, attention!\n\nCarry on."
```
