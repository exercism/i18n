# Einführung

## Konstanten und Funktionen

Haskell-Programme bestehen aus Definitionen und Ausdrücken.

Ein konstanter Wert wird mit `name = expression` definiert.

```haskell
five = 5

six = 3 + 3
```

Funktionen werden mit `name parameters... = expression` definiert, wobei Parameter nur durch Leerzeichen getrennt werden.

```haskell
add number1 number2 = number1 + number2
```

Eine Funktion aufzurufen ist ebenfalls ein Ausdruck. Du gibst dabei ihren Namen an und übergibst Argumente für jeden Parameter der Funktion, durch Leerzeichen getrennt, genau wie bei Funktionsdefinitionen.

```haskell
five = add 2 3
```

Mit runden Klammern kannst du die Reihenfolge der Auswertung eines Ausdrucks festlegen.

```haskell
six = add 2 (1 * 4)

twelve = add 2 1 * 4
```

## Einrückung / signifikanter Whitespace

Haskell verwendet Whitespace und Einrückung, um Codegrenzen festzulegen.
***Code, der Teil eines Ausdrucks ist, muss weiter eingerückt sein als der Anfang dieses Ausdrucks.***

- Moduldefinitionen, Import-Anweisungen und Top-Level-Funktionsdefinitionen müssen in der am weitesten links liegenden Spalte beginnen.
- Wenn ein Ausdruck auf mehrere Zeilen aufgeteilt wird, muss der Code, der Teil dieses Ausdrucks ist, unter diesem Ausdruck mit mindestens einem Leerzeichen eingerückt werden.
- Teile des Ausdrucks, die zusammengehören, sollten mit gleich vielen Leerzeichen eingerückt werden.

```haskell
-- A function split over multiple lines, so subsequent lines must be indented
add number1 number2 =
    number1 + number2
```

## Module

Module exportieren Funktionen.
Das bedeutet, dass du die Funktionen verwenden kannst, die das Modul in seiner Export-Deklaration bereitstellt.
Ein Modul kann auch Funktionen nur für den internen Gebrauch definieren.
Standardmäßig können Funktionen, die nicht explizit exportiert werden, nicht von außerhalb des Moduls verwendet werden.

Am Anfang eines Moduls geben wir den Modulnamen an.
Wenn wir eine Datei namens Calculator.hs haben, sollten wir unser Modul Calculator nennen.
Dann geben wir die Funktionen an, die es exportiert, und danach können wir mit dem Schreiben der Funktionen beginnen.
Fangen wir also damit an.

```haskell
module Calculator ( add ) where
```

https://learnyouahaskell.github.io/modules#making-our-own-modules

## Kommentare

Ein Kommentar ist ein Text innerhalb der Haskell-Datei, der nicht als Code interpretiert wird.
Er ist hauptsächlich dafür gedacht, von dir und anderen Programmierern gelesen zu werden.
Es gibt eine einfache Syntax für einzeilige Kommentare, die auf doppelten Bindestrichen basiert.
Mehrzeilige Kommentare sind ebenfalls mit dem Paar aus öffnendem und schließendem Begrenzungszeichen `{-` und `-}` möglich.

```haskell
-- a single line comment
-- another single line comment

{- a multiline comment
   spanning multiple lines
-}
```
