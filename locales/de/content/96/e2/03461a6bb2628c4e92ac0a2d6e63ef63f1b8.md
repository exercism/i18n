# Anhang zu den Anweisungen

## Über die Stream-Ability

Ein `Stream` ist eine Unison-Ability, mit der du Werte ausgeben kannst.

Du könntest die `Stream`-Ability verwenden, wenn du eine Funktion hast, die beim Aufruf nebenbei Werte erzeugen soll. Diese Funktion gibt zum Beispiel den letzten Wert der Liste zurück, gibt aber eine laufende Summe aus, sobald sie ein Element sieht:

```
emitRunningTotal : '{Stream Nat} Nat
emitRunningTotal = 'let
  use Nat +
  List.foldLeft (
    acc a -> let
      runningTotal = acc + a
      Stream.emit runningTotal
      a
    ) 0 [1,2,3,4,5]
```

Mit einem Ability-Handler kannst du den Stream zusammen mit dem Rückgabewert der Funktion, die ihn erzeugt, als Liste materialisieren:

```
> Stream.toListWithResult! emitRunningTotal
  ⧩
  ([1, 3, 5, 7, 9], 5)
```
