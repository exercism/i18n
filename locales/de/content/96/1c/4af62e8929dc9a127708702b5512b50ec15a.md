# Einführung

## Variablen

Elixir ist eine dynamisch typisierte Sprache. Das bedeutet, dass der Typ einer Variable erst zur Laufzeit geprüft wird. Mit dem Match-Operator `=` können wir einen Wert beliebigen Typs an einen Variablennamen binden:

```elixir
# Bound an integer value of 1
count = 1
# You may re-bind variables
count = 2

# You may re-bind any type to a variable
count = false

# Strings can be created by enclosing characters within double quotes
message = "Success!"
```

## Module

Elixir ist eine [funktionale Programmiersprache][functional-programming] und verlangt, dass alle benannten Funktionen in einem _Modul_ definiert sind. Mit dem Schlüsselwort `defmodule` definierst du ein Modul. Zur Laufzeit stehen alle Module allen anderen Modulen zur Verfügung. Sie brauchen keinen _Zugriffsmodifikator_, um für andere Teile des Programms sichtbar zu sein. Ein _Modul_ ist das Gegenstück zu einer _Klasse_ in anderen Programmiersprachen.

```elixir
defmodule Calculator do
  # ...
end
```

## Benannte Funktionen

_Benannte Funktionen_ müssen in einem Modul definiert werden. Mit dem Schlüsselwort `def` definierst du eine _öffentliche_ Funktion.

Jede Funktion kann null oder mehr Argumente haben. Der Wert des letzten Ausdrucks in einer Funktion wird immer _implizit zurückgegeben_.

```elixir
defmodule Calculator do
  def add(x, y) do
    x + y
  end
end
```

Um eine Funktion aufzurufen, gibst du ihren Modul- und Funktionsnamen an und übergibst Argumente für jeden Parameter der Funktion.

```elixir
sum = Calculator.add(1, 2)
# => 3
```

Statt `def` kannst du das Schlüsselwort `defp` verwenden, um eine _private_ Funktion zu definieren. Private Funktionen kannst du nur innerhalb des Moduls verwenden, das sie definiert hat.

Wenn du eine Funktion innerhalb des Moduls aufrufst, in dem sie definiert ist, kannst du den Modulnamen weglassen.

Du kannst kurze Funktionen auch in einer einzeiligen Syntax schreiben (beachte das Komma `,` und den Doppelpunkt `:` um das Schlüsselwort `do`).

```elixir
defmodule Calculator do
  def subtract(x, y) do
    private_subtract(x, y)
  end

  defp private_subtract(x, y), do: x - y
end

difference = Calculator.subtract(7, 2)
# => 5

difference = Calculator.private_subtract(7, 2)
# => ** (UndefinedFunctionError) function Calculator.private_subtract/2 is undefined or private
#       Calculator.private_subtract(7, 2)
```

## Stelligkeit von Funktionen

Häufig spricht man bei Funktionen von ihrer _Stelligkeit_. Die _Stelligkeit_ einer Funktion ist die Anzahl der Argumente, die sie entgegennimmt.

```elixir
# add/3 because this function has three arguments, thus an arity of 3
def add(x, y, z) do
  x + y + z
end
```

## Namenskonventionen

Modulnamen sollten `PascalCase` verwenden. Ein Modulname muss mit einem Großbuchstaben `A-Z` beginnen und darf Buchstaben `a-zA-Z`, Zahlen `0-9` und Unterstriche `_` enthalten.

Variablen- und Funktionsnamen sollten `snake_case` verwenden. Ein Variablen- oder Funktionsname muss mit einem Kleinbuchstaben `a-z` oder einem Unterstrich `_` beginnen, darf Buchstaben `a-zA-Z`, Zahlen `0-9` und Unterstriche `_` enthalten und kann mit einem Fragezeichen `?` oder einem Ausrufezeichen `!` enden.

## Standardbibliothek

Elixir hat eine sehr umfangreiche und gut dokumentierte Standardbibliothek. Die Dokumentation findest du online unter [hexdocs.pm/elixir][docs]. Speichere diesen Link gut ab, du wirst ihn oft brauchen!

Die meisten eingebauten Datentypen haben ein entsprechendes Modul, das Funktionen für die Arbeit mit diesem Datentyp bietet. Es gibt zum Beispiel das Modul `Integer` für Ganzzahlen, das Modul `String` für Strings, das Modul `List` für Listen und so weiter.

Ein bemerkenswertes Modul ist das Modul `Kernel`. Es stellt die grundlegenden Fähigkeiten bereit, auf denen der Rest der Standardbibliothek aufbaut, etwa arithmetische Operatoren, Makros für den Kontrollfluss und vieles mehr. Die Funktionen des `Kernel`-Moduls werden automatisch importiert. Du kannst sie also ohne das Präfix `Kernel.` verwenden.
