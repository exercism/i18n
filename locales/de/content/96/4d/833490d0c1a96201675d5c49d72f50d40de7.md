# Hinweise

## Allgemein

- Arrays in Swift verwenden nullbasierte Indizes. Der erste Index in einem Array ist `0`.

## 1. Eine Karte vom Stapel nehmen

- Um das `n`-te Element eines Slices zu erhalten, [verwende einen Subscript][array-access].
- Ein Array beginnt immer mit dem Index `0`.

## 2. Eine Karte im Stapel austauschen

- Um das `n`-te Element in einem Array zu setzen, [verwende einen Subscript][array-access] und weise ihm einen neuen Wert zu.
- Ein Array beginnt immer mit dem Index `0`.

## 3. Eine Karte oben auf den Stapel legen

- Es gibt eine [Array-Methode][array-append-docs], um einen neuen Wert am Ende des Arrays hinzuzufügen.

## 4. Eine Karte aus dem Stapel entfernen

- Es gibt eine [Array-Methode][array-removeat-docs], mit der du Elemente an einem bestimmten Index entfernen kannst.

## 5. Die oberste Karte vom Stapel entfernen

- Es gibt eine [Array-Methode][array-removelast-docs], um das letzte Element aus dem Array zu entfernen.

## 6. Eine Karte unten an den Stapel anfügen

- Es gibt eine [Array-Methode][array-insert-docs], um einen neuen Wert an einem bestimmten Index des Arrays hinzuzufügen.
- Ein Array beginnt immer mit dem Index `0`.

## 7. Eine Karte von unten aus dem Stapel entfernen

- Es gibt eine [Array-Methode][array-removefirst-docs], um das erste Element aus dem Array zu entfernen.

## 8. Die Größe des Stapels prüfen

- Arrays haben eine [Eigenschaft][array-count-docs], um ihre Länge abzurufen.

## 9. Die Anzahl der geraden Karten im Stapel zählen

- Du kannst die Elemente eines Arrays mit einer [for-in-Schleife][for-in-loops] durchlaufen.
- Ganzzahltypen in Swift haben die Methode [`isMultiple(of:)`][int-ismultiple-docs], mit der du prüfen kannst, ob sie ein Vielfaches einer anderen Ganzzahl sind.
