# Einführung

Der `Result`-Typ ist in der Sprache Elm die Lösung für die Fehlerberichterstattung und ermöglicht die Wiederherstellung nach Fehlern. Er ist dem `Maybe`-Typ etwas ähnlich, aber Maybe kann zwar von Funktionen zurückgegeben werden, die fehlschlagen können, doch es verrät dir nichts darüber, warum etwas fehlgeschlagen ist. Result enthält diesen Kontext darüber, warum etwas fehlgeschlagen ist.

Der `Result`-Typ ist wie folgt definiert:

```elm
type Result error value
  = Ok value
  | Err error
```

In der Elm-Terminologie nennt man das eine Definition eines „benutzerdefinierten Typs“.
Die `error` und `value` in `OK value` und `Error error` stehen für eine Typvariable, die ein beliebiger Typ sein kann, wie `Int`, `Bool` oder `String`.
Somit ist ein `Result String Int` eine Variable, die einen `Int` enthalten soll. Wenn ein Fehler auftritt, wird dieser als `String` dargestellt.
Es gibt ein [Result-Modul](https://package.elm-lang.org/packages/elm/core/latest/Result) mit vielen nützlichen Hilfsfunktionen für Result.
