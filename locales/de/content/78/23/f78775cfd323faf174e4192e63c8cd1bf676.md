# Lernen

Tcl wurde mit dem Ziel entwickelt, sehr einfach und trotzdem mächtig zu sein. Deshalb ist es ziemlich leicht, [die grundlegende Syntax von Tcl][syntax] zu lernen.

Ein praktisches Tutorial findest du hier: [Learn X in Y minutes: Tcl][X-in-Y].

Ein umfassendes Tutorial in mehreren Teilen:
 - [Das Tcl-Tutorial][tutorial] behandelt Tcl-Version 8.5 (aktuell stabil ist Version 9.1)
 - Die Unterstützung für objektorientierte Programmierung kam in Version 8.6 zum Tcl-Kern hinzu. Magicsplat bietet ein ausführliches [OO-Tutorial][oo-tutorial] zu diesem Thema.
