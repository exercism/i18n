# Anleitung

In dieser Übung schreibst du Code, um eine Liste von Programmiersprachen zu verwalten, die du auf Exercism lernen möchtest.

Du hast sechs Aufgaben, die sich alle mit Listen befassen.

## 1. Erstelle eine neue Liste

Um die Sprachen, die du lernen möchtest, im Blick zu behalten, musst du eine neue Liste erstellen. Definiere die Bindung `newList`, die eine neue, leere Liste enthält.

```fsharp
newList
// => []
```

## 2. Definiere eine vorhandene Liste

Momentan hast du einen Zettel, auf dem die Sprachen stehen, die du lernen möchtest: F#, Clojure und Haskell. Definiere die Bindung `existingList`, um diese Liste darzustellen.

```fsharp
existingList
// => ["F#"; "Clojure"; "Haskell"]
```

## 3. Füge einer Liste eine neue Sprache hinzu

Wenn du Exercism erkundest und weitere interessante Sprachen findest, möchtest du sie deiner Liste hinzufügen. Implementiere die Funktion `addLanguage`, um eine neue Sprache an den Anfang deiner Liste einzufügen.

```fsharp
addLanguage "TypeScript" ["JavaScript"; "CoffeeScript"]
// => ["TypeScript"; "JavaScript"; "CoffeeScript"]
```

## 4. Zähle die Sprachen in der Liste

Die Sprachen einzeln zu zählen ist umständlich. Implementiere die Funktion `countLanguages`, um die Anzahl der Sprachen in deiner Liste zu zählen.

```fsharp
countLanguages ["C#"; "Racket"; "Rust"; "Ruby"]
// => 4
```

## 5. Kehre die Liste um

Irgendwann stellst du fest, dass deine Liste tatsächlich rückwärts sortiert ist! Implementiere die Funktion `reverseList`, um deine Liste umzukehren.

```fsharp
reverseList ["Prolog"; "C"; "Idris"; "Assembly"]
// => ["Assembly"; "Idris"; "C"; "Prolog"]
```

## 6. Prüfe, ob die Liste spannend ist

Obwohl du alle Sprachen liebst, hat F# einen besonderen Platz in deinem Herzen. Deshalb begeistert dich eine Liste von Sprachen richtig, wenn:

- Das erste Element in der Liste ist F#.
- Das zweite Element in der Liste ist F# und die Liste enthält entweder zwei oder drei Sprachen.

Implementiere die Funktion `excitingList`, um zu prüfen, ob eine Liste von Sprachen spannend ist:

```fsharp
excitingList ["Nim"; "F#"]
// => true
```
