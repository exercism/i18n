# Einleitung

## AST

Der abstrakte Syntaxbaum (AST), auch _quotierter Ausdruck_ genannt, ist eine Möglichkeit, Code als Daten darzustellen.

Jeder Knoten im AST ist ein Tupel mit drei Elementen.

```elixir
# AST representation of:
# 2 + 3
{:+, [], [2, 3]}
```

Das erste Element, ein Atom, ist die Operation. Das zweite Element, eine Schlüsselwortliste, sind die Metadaten. Das dritte Element ist eine Liste von Argumenten, die weitere Knoten enthält. Literale Werte wie Ganzzahlen, Atome und Strings werden im AST als sie selbst dargestellt und nicht als Tupel mit drei Elementen.

### Code in ASTs umwandeln

Elixir-Code in ASTs umzuwandeln und ASTs wieder zurück in Code ist Teil der Standardbibliothek. Funktionen für die Arbeit mit ASTs findest du in den Modulen `Code` (z. B. um einen String mit Code in einen AST umzuwandeln) und `Macro` (z. B. um den AST zu durchlaufen oder ihn in einen String umzuwandeln).

Beachte, dass alle Funktionen der Standardbibliothek den Namen „quoted“ verwenden, um den AST zu bezeichnen (kurz für _quotierter Ausdruck_).

Die Spezialform, mit der du Code in einen AST umwandelst, heißt `quote`. Sie nimmt einen Block entgegen und gibt dessen AST zurück.

```elixir
quote do
  2 + 3 - 1
end

# => {:-, [], [
#      {:+, [], [2, 3]},
#      1
#    ]}
```

### Anwendungsfälle

Die Fähigkeit, Code als AST darzustellen, ist der Kern der Metaprogrammierung in Elixir. _Makros_, also die Möglichkeit, Elixir-Code zu schreiben, der Elixir-Code erzeugt, funktionieren, indem sie ASTs als Ergebnis liefern.

Ein weiterer Anwendungsfall für ASTs ist die statische Codeanalyse, etwa durch das eigene Tool Analyzer von Exercism, das du vielleicht schon als den kleinen Bot kennst, der Kommentare zu deinen Lösungen hinterlässt.
