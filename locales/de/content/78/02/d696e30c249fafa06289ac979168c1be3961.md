# Hinweise

## Allgemein

- Die Arrays mit den Vogelzählungen enthalten immer genau 7 Ganzzahlen.

## 1. Prüfe, wie die Zählungen letzte Woche aussahen

- Es gibt [mehrere Möglichkeiten, ein Array zu definieren][creating-arrays].

## 2. Prüfe, wie viele Vögel gestern zu Besuch waren

- Denk daran, dass die Zählungen nach Tagen geordnet sind, vom ältesten zum neuesten, wobei das letzte Element für heute steht.
- Auf das zweitletzte Element kannst du entweder über seinen (festen) Index zugreifen (denk daran, bei null mit dem Zählen zu beginnen) oder seinen Index mithilfe der Länge des Arrays berechnen, sei es über eine [Funktion im `Array`-Modul][length-function] oder über eine der [Eigenschaften][length-property] des Arrays.

## 3. Berechne die Gesamtzahl der Vögel, die zu Besuch kamen

- Das `Array`-Modul hat eine [Funktion, um die Werte eines Arrays zu summieren][sum-function].

## 4. Prüfe, ob es einen Tag gab, an dem keine Vögel zu Besuch waren

- Das `Array`-Modul hat eine [Funktion, mit der du prüfen kannst, ob ein Array einen bestimmten Wert enthält][contains-function].

## 5. Erhöhe die Zählung von heute

- Es gibt zwei Möglichkeiten, einen Wert in einem Array zu aktualisieren:
  - Der `<-`-Operator ermöglicht es, einen Wert in einem Array zu aktualisieren.
  - Das `Array`-Modul hat eine [Funktion, um einen Wert in einem Array zu aktualisieren][set-function].
- Die oben genannte Funktion zum Aktualisieren eines Werts in einem Array gibt keinen Wert zurück. Du solltest das aktualisierte Array deshalb nach dem Setzen seines Werts selbst zurückgeben.

## 6. Prüfe, ob die Woche ungewöhnlich ist

- Anstatt alle einzelnen Werte zu prüfen, verwende den [Musterabgleich][pattern-matching-array].
