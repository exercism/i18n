# Ergänzung zu den Anweisungen

## Callable

In PHP gibt es das Konzept des [Callable](https://www.php.net/manual/en/language.types.callable.php).

Es gibt sie in verschiedenen Formen, aber wir konzentrieren uns auf [anonyme Funktionen](https://www.php.net/manual/en/functions.anonymous.php).

Du kannst eine anonyme Funktion in einer Variable erzeugen und sie mit Parametern aufrufen:

```php
$double = function ($number) {
    return $number * 2;
};

$double(2); // returns 4
$double(4); // returns 8
```
