# Einführung

Diskriminierte Unions werden in F# häufig verwendet, um eine feste Menge benannter Konstanten darzustellen: eine Struktur, die in anderen Sprachen „Enum“ heißt.

Normalerweise kann jeder Fall einer solchen diskriminierten Union genau eine dieser benannten Konstanten bezeichnen. Manchmal ist es jedoch nützlich, mehr als eine Konstante zu bezeichnen. Dazu kannst du die diskriminierte Union mit dem Flags-Attribut annotieren.

Eine diskriminierte Union mit dem Flags-Attribut kannst du so definieren (unter Verwendung der binären Ganzzahlschreibweise 0b):

```fsharp
[<Flags>]
type PhoneFeatures =
| Call = 0b00000001
| Text = 0b00000010
```

Bei einer `PhoneFeatures`-Instanz mit dem Wert `0b00000011` sind sowohl das `Call`- als auch das `Text`-Flag gesetzt.
