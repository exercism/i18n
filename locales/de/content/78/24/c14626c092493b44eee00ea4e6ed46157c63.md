# Einführung

Der Name der Sprache, die wir hier verwenden, Lisp, steht für _LIST Processing_. Da könnte man annehmen, dass die Sprache Werkzeuge für den Umgang mit Listen von Elementen mitbringt. Und damit hast du recht!

Common Lisp kennt zwar auch andere Datenstrukturen als Listen, aber Listen werden trotzdem sehr viel verwendet.

Eine Liste in Common Lisp ist eine Folge von Elementen. Sie wird auch **cons** genannt (hauptsächlich aus historischen Gründen).
Die Elemente selbst müssen nicht vom selben Typ sein.
Du kannst zum Beispiel eine Liste aus `1`, `two`, `"III"` haben.

## Listen erstellen

Du kannst einfach eine quotierte Liste wie diese eintippen: `'(1 two "III")`. Damit wird eine Liste erstellt und ausgewertet (sie ergibt `(1 two "III")`).

Es gibt außerdem zwei wichtige Funktionen, mit denen du Listen erstellst: `list` und `cons`.

`list` nimmt null oder mehr Argumente und ergibt eine Liste, die mit diesen Werten erstellt wird:

```lisp
(list 1 'two "III") ; => (1 two "III")
```

`cons` nimmt zwei Elemente und erstellt eine Liste, bei der das erste Element ihr `car` ist (der Kopf der Liste) und das zweite Element ihr `cdr` (der Rest der Liste):

```lisp
(cons 1 2)            ; => (1 . 2) ;; (a list without `nil` as its `cdr` is printed in this way)
(cons 1 nil)          ; => (1)
(cons 1 (cons 2 nil)) ; => (1 2)
```

Mit den Funktionen `car` und `cdr` kannst du auf das `car` und das `cdr` einer Liste zugreifen.

(`first` und `rest` sind Synonyme für `car` und `cdr` und funktionieren genau gleich.)

## Länge und wahlfreier Zugriff

Die Länge einer Liste kannst du mit `length` bestimmen.
Eine leere Liste hat die Länge null.

Auf ein beliebiges Element kannst du mit `nth` zugreifen (beachte, dass Listen nullbasiert sind).

Es ist _kein_ Fehler, einen Index abzufragen, der größer ist als die Liste lang ist.
Stattdessen ist das Ergebnis `nil`:

```lisp
(nth 23 '(short list)) ; => nil
```

Es gibt außerdem mehrere Hilfsfunktionen, um auf die ersten Elemente einer Liste zuzugreifen: `first`, `second`, `third`, und so weiter bis `tenth`. Praktisch, oder?

## Listen zusammenfügen

Zwei oder mehr Listen kannst du mit `append` zusammenfügen: 

```lisp
(append '(a b c) '(1 2 3)) ; => (A B C 1 2 3)
(append '(a b c) '())     ; => (A B C)
```

Jedes Argument, das du `append` übergibst, muss eine Liste sein.
