# Über

ARM64/AArch64-Assembly ist die 64-Bit-Version des ARM-Befehlssatzes.
Sie basiert auf dem ARMv7-Befehlssatz, der wiederum lose an die älteren ARM-Classic-Befehlssätze angelehnt ist.

In diesem Track programmierst du in ARM64-Assembly. Assembliert und ausgeführt wird der Code auf einem plattformübergreifenden Simulator.
