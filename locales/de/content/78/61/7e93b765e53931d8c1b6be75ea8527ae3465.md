# Einführung

## Zahlen

In C# gibt es zwei verschiedene Arten von Zahlen:

- Ganzzahlen: Zahlen ohne Nachkommastellen (ganze Zahlen). Beispiele sind `-6`, `0`, `1`, `25`, `976` und `500000`.
- Gleitkommazahlen: Zahlen mit null oder mehr Nachkommastellen. Beispiele sind `-2.4`, `0.1`, `3.14`, `16.984025` und `1024.0`.

Die beiden häufigsten numerischen Datentypen in C# sind `int` und `double`. Ein `int` ist eine 32-Bit-Ganzzahl und ein `double` ist eine 64-Bit-Gleitkommazahl.

Für Rechnungen verwendest du die üblichen arithmetischen Operatoren. Zahlen kannst du mit den üblichen numerischen Vergleichsoperatoren sowie den Operatoren für Gleichheit (`==`) und Ungleichheit (`!=`) vergleichen.

In C# gibt es zwei Arten von numerischen Konvertierungen:

1. Implizite Konvertierungen: Es gehen keine Daten verloren und du brauchst keine zusätzliche Syntax.
2. Explizite Konvertierungen: Daten könnten verloren gehen und du brauchst zusätzliche Syntax in Form eines _Casts_.

Da ein `int` weniger präzise ist als ein `double`, ist die Konvertierung von einem `int` in einen `double` sicher und damit implizit. Die Konvertierung von einem `double` in einen `int` kann jedoch Datenverlust bedeuten, deshalb ist sie explizit.

```csharp
int softCool = 1358938113;
double notLost = 4.8151623;

// implicit cast: no loss of information
double macDebug = softCool;         // 1358938113.0

// explicit cast: possible loss of information 
int somethingLost = (int)notLost;   // 4
```

## if-Anweisungen

In dieser Übung musst du Logik abhängig von Bedingungen ausführen. Am häufigsten machst du das in C# mit einer `if/else`-Anweisung:

```csharp
int x = 6;

if (x == 5)
{
    // Execute logic if x equals 5
}
else if (x > 7)
{
    // Execute logic if x greater than 7
}
else
{
    // Execute logic in all other cases
}
```

Die Bedingung einer `if`-Anweisung muss vom Typ `bool` sein. In C# gibt es kein Konzept von _truthy_-Werten.
