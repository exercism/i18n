# Einführung

ABAP hat mehrere numerische Typen. In dieser Übung verwendest du zwei davon:

- `i` für Ganzzahlen, etwa eine Anzahl von Tagen.
- `p` für gepackte Dezimalzahlen, etwa einen Stundensatz oder einen Rabatt.

```abap
DATA billable_days TYPE i VALUE 22.
DATA rate_per_hour TYPE p LENGTH 8 DECIMALS 2 VALUE '89.89'.
```

Gepackte Zahlen legen ihre maximale Länge und die Anzahl der Nachkommastellen fest. Dezimalliterale werden üblicherweise als Textwerte geschrieben und vom Compiler oder mit `CONV` in den Ziel-Dezimaltyp umgewandelt.

```abap
TYPES discount_rate TYPE p LENGTH 8 DECIMALS 6.

DATA discount TYPE discount_rate.
discount = CONV discount_rate( '0.15' ).
```

ABAP bietet integrierte numerische Funktionen zum Runden. Die Funktion `floor` rundet auf die nächste ganze Zahl ab, und `ceil` rundet auf die nächste ganze Zahl auf.

```abap
DATA full_months TYPE i.
full_months = floor( 70 / 22 ).

DATA rounded_cost TYPE i.
rounded_cost = ceil( '14527.2' ).
```
