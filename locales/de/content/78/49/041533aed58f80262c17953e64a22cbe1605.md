# Installation

Um an den Übungen zu arbeiten, brauchst du diese Programme:

1. [`OPAM`, der OCaml-Paketmanager](https://opam.ocaml.org/)

   Unter [Real World Ocaml, 2nd Ed.: Installation Instructions](https://dev.realworldocaml.org/install.html) erfährst du, wie du `OPAM` für dein Betriebssystem installierst und konfigurierst.

2. Der OCaml-Compiler

   So siehst du eine Liste der verfügbaren Versionen:

   ```bash
   opam switch
   ```

   Wenn du bereits einen Switch für OCaml 5.1 hast, kannst du ihn entweder mit `opam switch <switch-name>` laden oder einen neuen Switch erstellen mit:

   ```bash
   opam switch create exercism 5.4.0
   ```

   Der Name `exercism` ist hier optional, aber es ist gute Praxis, deinen Switches Namen zu geben.

3. Installiere erweiterte Standardbibliotheken und Testbibliotheken

   Führe Folgendes aus, um die für diesen Track benötigten Abhängigkeiten zu installieren:

   ```bash
   opam install base core_kernel ounit qcheck
   ```

   Einige Übungen verwenden nur die OCaml-Standardbibliothek, andere nutzen die erweiterten Bibliotheken von Jane Street namens Base und Core_kernel.
   Die Testbibliothek heißt OUnit, und einige Übungen verwenden zusätzlich die QCheck-Bibliothek für eigenschaftsbasierte Tests.
   Mit dem obigen Befehl installierst du diese Bibliotheken.

4. Interaktive Shell installieren und verwenden (optional)

   Eine Zusammenfassung von [Setting up and using `utop`](https://dev.realworldocaml.org/install.html):

   ```bash
   opam install utop
   ```

   Erstelle eine neue Datei namens `.ocamlinit` in deinem Home-Verzeichnis und füge die folgenden Zeilen hinzu:

   ```ocaml
   #use "topfind";;
   #require "base";;
   open Base
   ```

5. Tools in VS Code installieren (optional)

   Wenn du VS Code verwendest:
   - Installiere den OCaml-Sprachserver von [hier](https://github.com/ocaml/ocaml-lsp).
   - Installiere die OCaml-Erweiterung für VS Code von [hier](https://marketplace.visualstudio.com/items?itemName=ocamllabs.ocaml-platform) oder suche nach `OCaml Platform` von Ocaml Labs.
