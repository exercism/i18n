# Einführung

Viele Programme brauchen (pseudo-)zufällige Werte, um Ereignisse aus der realen Welt zu simulieren.

Häufige, bekannte Beispiele sind:

- Ein Münzwurf: ein zufälliger Wert aus ('H', 'T').
- Der Wurf eines Würfels: eine zufällige Ganzzahl von 1 bis 6.
- Das Mischen eines Kartendecks: eine zufällige Reihenfolge einer Kartenliste.
- Das Erzeugen von Bäumen und Büschen in einer 3D-Grafiksimulation.

Wirklich zufällige Werte mit einem Computer zu erzeugen, ist eine [überraschend schwierige technische Herausforderung][why-randomness-is-hard]. Deshalb gibt es auch „pseudozufällige" Generatoren.

## Zufallszahlen erzeugen

In JavaScript kannst du mit der Funktion [`Math.random()`][Math.random] Pseudozufallszahlen erzeugen.
Sie gibt eine Pseudozufallszahl als Gleitkommazahl zwischen 0 (einschließlich) und 1 (ausschließlich) zurück.

Um eine Zufallszahl zwischen _min_ (einschließlich) und _max_ (ausschließlich) zu bekommen, kannst du eine Funktion wie diese verwenden:

```javascript
function getRandomInRange(min, max) {
  return min + Math.random() * (max - min);
}
getRandomInRange(4, 10);
// => 5.72
```

~~~exercism/advanced
Die meisten einfachen Techniken, mit einer zufällig erzeugten Zahl einen Zahlenbereich abzubilden, [führen zu einer Verzerrung][bias].
Das bedeutet, dass einige Zahlen wahrscheinlicher gewürfelt werden als andere.
Bei der Multiplikationstechnik verteilt sich die Verzerrung über den gesamten Bereich, sodass sie weniger auffällt und in den meisten Fällen kein großes Problem ist. Trotzdem solltest du dir dessen bewusst sein.

[bias]: https://adammil.net/blog/v134_Efficiently_generating_random_numbers_without_bias.html

## Zufällige Ganzzahlen erzeugen

Um eine zufällige Ganzzahl zu erzeugen, kannst du mit `Math.floor()` oder `Math.ceil()` eine zufällig erzeugte Zahl in eine Ganzzahl umwandeln.
