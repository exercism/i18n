# Ergänzung zu den Anweisungen

## Implementierung

Die Gegenstände werden durch [Records](https://lfe.gitbooks.io/reference-guide/content/16.html) dargestellt, die in `item.lfe` definiert sind.
Verwende `item-weight`, um das Gewicht zu bekommen, und `item-value`, um den Wert zu bekommen.

```
;; Create an item with weight=5, value=50
(set item (make-item weight 5 value 50))

;; Get the weight. Returns 5.
(item-weight item)

;; Get the value. Returns 50.
(item-value item)
```
