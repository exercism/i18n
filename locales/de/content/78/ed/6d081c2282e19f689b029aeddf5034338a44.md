# Override-Annotation verwenden

Auch wenn es nicht unbedingt notwendig ist, ist es eine gute Praxis, die `@Override`-Annotation zu verwenden, wenn du Methoden aus einer Oberklasse überschreibst.

Das kann helfen, Fehler zu vermeiden: Wenn eine mit `@Override` gekennzeichnete Methode eine Methode in einer ihrer Oberklassen nicht korrekt überschreibt, gibt der Compiler einen Fehler aus.
