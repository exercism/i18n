# Über

Eine [Funktion höherer Ordnung](https://docs.microsoft.com/en-us/dotnet/fsharp/introduction-to-functional-programming/first-class-functions) ist eine Funktion, die entweder:

- eine Funktion als Argument entgegennimmt
- eine Funktion zurückgibt

Ein Funktionsargument ist ganz einfach ein normales Argument, nur dass du es aufrufen kannst.

```fsharp
let double = fun x -> x * 2

let apply f x = f x

apply double 3
// => 6
```
