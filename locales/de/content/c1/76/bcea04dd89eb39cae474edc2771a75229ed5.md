# Ergänzung zu den Anweisungen

## Implementierung

In dieser Übung implementierst du eine Prozedur, die den String, den sie zurückgibt, allokieren soll. Der Aufrufer der Prozedur ist dafür verantwortlich, den String freizugeben.

```odin
// The procedure will be called like that:
converted := convert(3)
// ...
// and eventually the caller will delete the string
delete(converted)
```
