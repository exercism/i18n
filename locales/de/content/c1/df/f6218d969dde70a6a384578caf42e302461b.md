# Anweisungen

In dieser Übung verarbeitest du Log-Zeilen.

Jede Log-Zeile ist ein String mit folgendem Format: `"[<LVL>]: <MESSAGE>"`.

Das sind die verschiedenen Log-Level:

- `TRC` (trace)
- `DBG` (debug)
- `INF` (info)
- `WRN` (warning)
- `ERR` (error)
- `FTL` (fatal)

Du hast drei Aufgaben.

## 1. Log-Level parsen

Definiere ein `LogLevel`-Enum mit sechs Elementen, die den oben genannten Log-Leveln entsprechen.

- `TRACE`
- `DEBUG`
- `INFO`
- `WARNING`
- `ERROR`
- `FATAL`

Implementiere als Nächstes die Methode `LogLine.getLogLevel()`, die den geparsten Log-Level einer Log-Zeile zurückgibt:

```java
var logLine = new LogLine("[INF]: File deleted");
logLine.getLogLevel();
// => LogLevel.INFO
```

## 2. Unbekannte Log-Level unterstützen

Leider haben gelegentlich einige Log-Zeilen einen unbekannten Log-Level.
Um diese Log-Zeilen sauber zu behandeln, füge dem `LogLevel`-Enum ein Element `UNKNOWN` hinzu, das beim Parsen eines unbekannten Log-Levels zurückgegeben werden soll:

```java
var logLine = new LogLine("[XYZ]: Overly specific, out of context message");
logLine.getLogLevel();
// => LogLevel.UNKNOWN
```

## 3. Log-Zeile in ein Kurzformat umwandeln

Der Log-Level einer Log-Zeile ist recht ausführlich.
Um den Speicherplatz zu reduzieren, der zum Speichern der Log-Zeilen nötig ist, wurde ein Kurzformat entwickelt: `"[<ENCODED_LEVEL>]:<MESSAGE>"`.

Der kodierte Log-Level ist eine einfache Zuordnung eines Log-Levels zu einer Zahl:

- `UNKNOWN` - `0`
- `TRACE` - `1`
- `DEBUG` - `2`
- `INFO` - `4`
- `WARNING` - `5`
- `ERROR` - `6`
- `FATAL` - `42`

Implementiere die Methode `LogLine.getOutputForShortLog()`, die das verkürzte Log-Zeilen-Format ausgeben kann:

```java
var logLine = new LogLine("[ERR]: Stack Overflow");
logLine.getOutputForShortLog();
// => "6:Stack Overflow"
```
