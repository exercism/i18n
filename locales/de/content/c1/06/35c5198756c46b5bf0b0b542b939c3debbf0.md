# Ergänzung zu den Anweisungen

## Sortierpaket

Für diese Übung musst du ein Array sortieren, aber das ist in der Standardbibliothek nicht enthalten. Du könntest deine eigene Sortierbibliothek schreiben, aber besser ist es, das [sorts-Paket](https://github.com/diku-dk/sorts) zu verwenden.

Du kannst dieses Paket in deiner Lösung verwenden, indem du den folgenden Befehl im Verzeichnis der Lösung ausführst:

```shell
futhark pkg add github.com/diku-dk/sorts
futhark pkg sync
```

Danach importierst du deine [gewünschten Sortieralgorithmen](https://github.com/diku-dk/sorts/tree/master/lib/github.com/diku-dk/sorts) mit:

```futhark
import "lib/github.com/diku-dk/sorts/<sorting algorithm>"
```
