# Über

## Funktionstypen

Wir haben bereits gesehen, wie Funktionssignaturen definiert werden: mit einem Funktionsnamen, gefolgt von einer kommagetrennten Liste von Parameterbezeichnungen zusammen mit ihren Typen, gefolgt von `->` und dem Typ der von der Funktion zurückgegebenen Werte.

Wenn man alle Namen und Bezeichnungen aus dieser Signatur entfernen würde, bliebe der [Typ der Funktion][function-types] übrig.

```swift
func shoppingList(item: String, quantity: Int) -> String {
  "You need to buy \(quantity) \(item)."
}
// shoppingList: (String, Int) -> String

func repeater(_ phrase: String, times: Int) -> String {
  var result = ""
  for _ in 1...times {
    result += phrase
  }
  return result
}
// repeater: (String, Int) -> String

func printString(line: String) {
  print(line)
}
// printString: (String) -> ()
```

Beachte, dass die Typen der ersten beiden Funktionen gleich sind, `(String, Int) -> String`, obwohl die beiden Funktionen sehr unterschiedlich arbeiten. Beide nehmen einen `String` und einen `Int` als Eingabe und geben einen `String` zurück. Und wie man am Typ der dritten Funktion sieht, gibt sie, obwohl sie nichts zurückzugeben scheint, tatsächlich `()` zurück, den einzigen Wert vom Typ `Void`. Beachte, dass `()` und `Void` als Typnamen austauschbar sind, sodass der Typ von `printString` auch als `String) -> Void` geschrieben werden könnte.

```swift
var stringAndIntToString: (String, Int) -> String

stringAndIntToString = shoppingList
stringAndIntToString("carrots", 3)
// => "You need to buy 3 carrots."

stringAndIntToString = repeater
stringAndIntToString("carrots", 3)
// => "carrotscarrotscarrots"
```

Wie bei anderen Variablen/Konstanten muss der Wert, den du ihr zuweist, vom richtigen Typ sein:

```swift
stringAndIntToString = printShoppingList
// Error: Cannot assign value of type '(String) -> ()' to type '(String, Int) -> String'
```

## Funktionstypen als Parametertypen

Da Funktionstypen überall dort verwendet werden können, wo auch andere Typen verwendet werden können, folgt daraus, dass [sie als Parametertypen verwendet werden können][functions-as-parameters] und an andere Funktionen übergeben und aus diesen Funktionen heraus aufgerufen werden können.

```swift
func apply3(to str: String, function f: (String, Int) -> String) -> String {
  f(str,3)
}
// apply3: ([String], (String, Int) -> String) -> [String]

apply3(to: "eggs", function: shoppingList)
// => "You need to buy 3 eggs."

apply3(to: "eggs", function: repeater)
// => "eggseggseggs"

func apply(functions fs: [(String, Int) -> String],
           to string: String,
          ) -> [String] {
  var result = [String]()
  for f in fs {
    result.append(f(string, 3))
  }
  return result

}
// apply: ([(String, Int) -> String], String) -> [String]


apply(functions: [shoppingList, repeater], to: "carrots")
// => ["You need to buy 3 carrots.", "carrotscarrotscarrots"]
```

## Funktionstypen als Rückgabetypen

Ähnlich können [Funktionstypen als Rückgabetypen][functions-as-returns] für Funktionen verwendet werden. Mit anderen Worten: Man kann Funktionen schreiben, die andere Funktionen erzeugen und zurückgeben. Wenn man diese Funktionen erstellt, kann die zurückgegebene Funktion die anderen an die Funktion übergebenen Parameter oder die innerhalb der übergeordneten Funktion erstellten lokalen Variablen verwenden.

```swift
func makeAdder(base: Int) -> (Int) -> Int {
  func adder(_ i: Int) -> Int {
    base + i
  }
  return adder
}
// makeAdder: (Int) -> (Int) -> Int

let add10 = makeAdder(base: 10)
// add10: (Int) -> Int

let subtract20 = makeAdder(base: -20)
// subtract10: (Int) -> Int

add10(5)
// => 15

subtract20(5)
// => -15
```

## Werte erfassen

Wie bei der Funktion `makeAdder(base:)` oben zu sehen, können verschachtelte Funktionen auf die Parameter und Variablen ihrer umgebenden Funktionen zugreifen. Darüber hinaus können sie den Zugriff auf diese Werte aufrechterhalten, nachdem die umgebende Funktion beendet ist. Dieses Erlangen und Aufrechterhalten des Zugriffs wird als [_Erfassen_][capturing-values] bezeichnet.

## Funktionen höherer Ordnung

Funktionen, die Funktionen als Parameter nehmen und/oder Funktionen zurückgeben, werden als Funktionen höherer Ordnung bezeichnet. Swift hat viele Funktionen höherer Ordnung in seinen verschiedenen Bibliotheken. Zum Beispiel die Methode `sorted(by:)`, die auf Swift-Sammlungen wie `Array` verfügbar ist. Für ein Array mit Elementen vom Typ `T` nimmt sie eine Funktion vom Typ `(T, T) -> Bool`, die bestimmt, welcher von zwei Werten in einem sortierten Array vor dem anderen kommen soll, und `true` zurückgibt, wenn der linke Wert zuerst erscheinen soll, und `false`, wenn der rechte Wert zuerst erscheinen soll.

Ein weiteres Beispiel ist die Methode `contains(where:)` auf Sammlungen. Für eine Sammlung mit Elementen vom Typ `T` nimmt sie eine Funktion vom Typ `(T) -> Bool`, die `true` zurückgibt, wenn das Element eine bestimmte Eigenschaft erfüllt, und andernfalls `false`. `contains(where:)` gibt dann `true` zurück, wenn ein Element in der Sammlung diese Eigenschaft erfüllt.

```swift
func longer(_ strA: String, _ strB: String) -> Bool {
  strA.count > strB.count
}
// longer: (String, String) -> Bool

["apple", "ball", "carrot"].sorted(by: longer)
// => ["carrot", "apple", "ball"]

["apple", "ball", "carrot"].sorted(by: >)
// => ["carrot", "ball", "apple"]


func isBig(_ i: Int) -> Bool {
  i > 100
}
// isBig: (Int) -> Bool

func isVowel(_ char: Character) -> Bool {
  switch char.lowercased() {
  case "a", "e", "i", "o", "u": return true
  default: return false
  }
}
// isVowel: (Character) -> Bool

[1, 75, 3, 99].contains(where: isBig)
// => false

"Owl".contains(where: isVowel)
// => true

```
