# Einführung

Der Typ der diskriminierten Union repräsentiert eine feste Anzahl benannter Fälle. Jeder Wert einer diskriminierten Union entspricht genau einem der benannten Fälle.

Eine diskriminierte Union wird mit dem Schlüsselwort `type` definiert, wobei die Fälle durch Pipe-Zeichen (`|`) getrennt werden:

```fsharp
type Season =
    | Spring
    | Summer
    | Autumn
    | Winter
```

Jeder Fall einer diskriminierten Union kann optional Daten enthalten, und verschiedene Fälle können verschiedene Datentypen haben. Wenn kein Fall Daten enthält, ähnelt die diskriminierte Union dem, was andere Sprachen üblicherweise als _Aufzählung_ (oder _Enum_) bezeichnen.

```fsharp
type Number =
    | Integer of int
    | Float of float
    | Invalid
```

Einen Wert für einen bestimmten Fall erzeugst du, indem du auf seinen Namen verweist (z. B. `Success`). Da Fallnamen einfach Konstruktorfunktionen sind, kannst du zugehörige Daten als reguläres Funktionsargument übergeben. Wenn eine andere diskriminierte Union einen Fall mit demselben Namen definiert hat, musst du den vollständigen Namen verwenden (z. B. `Result.Success`).

```fsharp
let byName = Integer 2
let byFullName = Number.Invalid
```

Diskriminierte Unions haben _strukturelle Gleichheit_. Das bedeutet, dass zwei Werte für denselben Fall mit denselben (optionalen) Daten äquivalent sind.

Du kannst zwar `if/elif/else`-Ausdrücke verwenden, um mit diskriminierten Unions zu arbeiten, aber der empfohlene Weg ist der Musterabgleich mit dem _Bezeichnermuster_:

```fsharp
let describe number =
    match number with
    | Integer i -> sprintf "Integer: %d" i
    | Float d  -> sprintf "Float: %f" d
    | Invalid   -> "Invalid"
```
