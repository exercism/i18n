# Einführung

Bindung (Linkage) beschreibt, von wo aus im Code auf einen Bezeichner zugegriffen werden kann.
Werte mit dem Gültigkeitsbereich eines Blocks, einer Funktion oder eines Funktionsprototyps haben keine Bindung.
Das bedeutet, dass von außerhalb ihres Gültigkeitsbereichs nicht auf sie zugegriffen werden kann.
Mehr zum Gültigkeitsbereich findest du im [Konzept Gültigkeitsbereich](../scope/introduction.md#Introduction).

## Externe Bindung

Bezeichner mit Dateigültigkeitsbereich haben standardmäßig externe Bindung.
Ein Bezeichner mit externer Bindung kann aus jeder Datei des Programms aufgerufen werden.

## Interne Bindung

Ein Bezeichner mit Dateigültigkeitsbereich kann mit dem Spezifizierer `static` interne Bindung erhalten.
Ein Bezeichner mit interner Bindung kann nur innerhalb seiner Datei verwendet werden.

Zum Beispiel

```c
int public_count = 0; // file scope, external linkage by default
static int private_count = 0;  // file scope, internal linkage 

// file scope, internal linkage
static void some_function()
{
    // code snipped
}

// file scope, external linkage by default
int main()
{
    // code snipped
}
```

Statische Bindung sollte nicht mit der statischen Speicherdauer verwechselt werden.
Mehr zur statischen Speicherdauer findest du im [Konzept Speicherdauer](https://github.com/exercism/c/blob/main/concepts/storage-class-specifiers/about.md#static-the-storage-specifier-not-to-be-confused-with-the-static-linkage-type).
