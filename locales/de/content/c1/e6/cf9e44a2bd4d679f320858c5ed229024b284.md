# Ergänzung zu den Anweisungen

## Eingabeformat

Jede Liste von Eingaben wird als nullterminierter String dargestellt, mit einem Zeilenumbruch am Ende jeder Eingabe.

Ein Beispiel wäre `"nail\nshoe\nhorse\nrider\nmessage\nbattle\nkingdom\n"`

## Register

| Register | Verwendung   | Typ     | Beschreibung                                                  |
| -------- | ------------ | ------- | ------------------------------------------------------------- |
| `$a0`    | Eingabe      | Adresse | nullterminierter Eingabe-String mit Zeilenumbruch nach jeder Eingabe |
| `$a1`    | Ein-/Ausgabe | Adresse | nullterminierter Ausgabe-String                               |
| `$t0-9`  | temporär     | beliebig | für die temporäre Speicherung                                 |
