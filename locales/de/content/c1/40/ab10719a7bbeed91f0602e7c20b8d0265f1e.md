# Einführung

## Musterabgleich

Mit einem `if/elif/else`-Ausdruck kannst du Logik bedingt ausführen. F# bietet aber noch eine andere, mächtigere Möglichkeit, Logik bedingt auszuführen: den Musterabgleich. Beim Musterabgleich wird ein Wert gegen ein oder mehrere _Muster_ geprüft. Ein Beispiel für ein solches Muster ist das _Konstantenmuster_, das einen Wert gegen eine Konstante abgleicht (z. B. `1` oder `"hello"`).

In F# verwendest du für den Musterabgleich das Schlüsselwort `match`:

```fsharp
let describe number =
    match number with
    | 0 -> "Zero"
    | 1 -> "One"
```

Das mag wie `switch`-Anweisungen in anderen Sprachen aussehen, doch der Musterabgleich glänzt erst so richtig, wenn du auch andere Muster verwendest. Ein solches Muster ist das _Variablenmuster_, mit dem du einen Wert erfassen kannst:

```fsharp
match number with
| 0 -> "Zero"
| i -> sprintf "Non zero: %d" i
```

In manchen Fällen möchtest du vielleicht eine zusätzliche Bedingung zu einem Muster hinzufügen. Das nennt man _Guard_ (Klausel), die du mit dem Schlüsselwort `when` hinzufügen kannst:

```fsharp
match number with
| 0 -> "Zero"
| i when i < 0 -> "Negative number"
```

Im obigen Beispiel gibt es nicht für jede mögliche Eingabe ein passendes Muster. Der Compiler erkennt das und gibt eine Warnung aus. Das nennt man _Vollständigkeitsprüfung_. Um die Warnung zu beheben, musst du alle Fälle behandeln. Dafür kannst du das _Wildcard-Muster_ verwenden, ein Muster, das auf jeden Wert passt:

```fsharp
match number with
| i when i < 0 -> "Negative number"
| _ -> "Positive number"

// No compiler warning
```

Der Musterabgleich prüft einen Wert von oben nach unten gegen jedes Muster, bis er ein passendes Muster findet und die zugehörige Logik ausführt. Die Reihenfolge der Muster ist wichtig!
