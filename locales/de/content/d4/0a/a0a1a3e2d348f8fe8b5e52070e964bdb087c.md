# Tests

Um deine Lösung zu testen, öffne das Terminal und führe

```
mason test
```

im Übungsordner aus (also im Ordner mit der Datei `Mason.toml` und den Ordnern `src/` und `test/`).

Wenn du findest, dass die Fehlermeldung nicht genug aussagt, kannst du Folgendes ausprobieren, um eine ausführlichere Meldung zu bekommen.

```
mason test --show
```
