# Ergänzung zu den Anweisungen

## Hinweise

Eine [doppelt verkettete Liste](https://en.wikipedia.org/wiki/Doubly_linked_list) ist eine veränderliche Datenstruktur. Da F# eine funktional ausgerichtete Sprache ist, wird Unveränderlichkeit im Allgemeinen bevorzugt, aber es gibt Sprachmerkmale, die den Einsatz von Mutation ermöglichen, wo sie nötig ist.

- Das Schlüsselwort `mutable` kann vor `let`-Bindungen und vor den Feldern von [Records](https://docs.microsoft.com/en-us/dotnet/articles/fsharp/language-reference/records) stehen, sodass du ihnen neue Werte zuweisen kannst.

- Die Eigenschaften einer [Klasse](https://fsharpforfunandprofit.com/posts/classes) lassen sich veränderlich machen, indem du mit dem Schlüsselwort `set` einen Setter für die Eigenschaft angibst.

Veränderliche Bindungen müssen mit `<-` neu zugewiesen werden

```fsharp
let mutable x = "initial value"
x <- "new value"
```
