# Ergänzung zu den Anweisungen

## Register

| Register | Verwendung | Typ     | Zweck                          |
| -------- | ---------- | ------- | ------------------------------ |
| `$a0`    | Eingabe    | Ganzzahl | vorgegebener Wert             |
| `$v0`    | Ausgabe    | Ganzzahl | Differenz der Quadrate        |
| `$t0-9`  | temporär   | beliebig | dient als temporärer Speicher |
