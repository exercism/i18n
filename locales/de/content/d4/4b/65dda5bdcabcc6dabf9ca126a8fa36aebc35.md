# Ergänzung zu den Anweisungen

## Implementierung

Die Funktionen in dieser Übung erwarten ein Array mit einer oder mehreren Zahlen. Jede Zahl steht für ein Spielergebnis.

Die Spielergebnisse lassen sich so auslesen:

| `scores`   |
|---|
| `scores[0]` |
| `scores[1]` |
| ... |
| `scores[scores_len - 1]` |

`personal_top_three()` sollte die besten Spielergebnisse des Spielers hierhin schreiben:

| `output`   |
|---|
| `output[0]` |
| ... |
