# Anleitung

Willkommen in der Welt von *ChronoRealms*, einem magischen Land, in dem mächtige Timekeepers den Fluss der Zeit kontrollieren.

In diesem Reich verwalten die Timekeepers „TimeShards“, besondere Einheiten, die man addieren, subtrahieren, vergleichen und sogar auf Gleichheit prüfen kann.

Deine Aufgabe ist es, den Timekeepers zu helfen, indem du eigene Operatoren für den Umgang mit diesen TimeShards implementierst.

Die Timekeepers brauchen von dir einen eigenen Struct `TimeShard`, der die folgenden Operationen unterstützt:

1. **TimeShards addieren und subtrahieren**: Die Timekeepers müssen TimeShards addieren und subtrahieren können, um die Zeitlinie zu steuern.
2. **TimeShards vergleichen**: Manchmal müssen TimeShards verglichen werden, um zu sehen, welche größer ist oder ob sie gleich sind.
3. **Gleichheit prüfen**: Die Timekeepers müssen prüfen können, ob zwei TimeShards denselben Wert haben.

Deine Mission ist es, die folgenden Traits für den Struct `TimeShard` zu implementieren:

1. **Addition (`Add`)**: Ermöglicht das Addieren zweier `TimeShard`-Instanzen.
2. **Subtraktion (`Sub`)**: Ermöglicht das Subtrahieren eines `TimeShard` von einem anderen.
3. **Gleichheit (`PartialEq`)**: Erlaubt es den Timekeepers zu prüfen, ob zwei `TimeShard`-Instanzen gleich sind.
4. **Vergleich (`PartialOrd`)**: Erlaubt den Vergleich zweier `TimeShard`-Instanzen, um zu sehen, welche größer oder kleiner ist.

Ein `TimeShard` wird durch einen Struct dargestellt, der eine Ganzzahl (`i32`) enthält.

Implementiere die nötigen Traits, damit die Timekeepers ihre Arbeit leichter haben.

```rust
let shard1 = TimeShard { value: 5 };
let shard2 = TimeShard { value: 3 };

// Adding TimeShards
let sum = shard1 + shard2; // TimeShard { value: 8 }

// Subtracting TimeShards
let difference = shard1 - shard2; // TimeShard { value: 2 }

// Checking equality
let are_equal = shard1 == shard2; // false

// Comparing TimeShards
let is_greater = shard1 > shard2; // true
```
