# Hinweise

## 1. Bestimmen, wie lange das Mixen eines Safts dauert

- Julia kennt keine `switch`-Anweisung, anders als viele andere Sprachen.
- Die Syntax `if` ... `elsefif` ... `else` wurde im Konzept Conditionals behandelt.

## 2. Den Vorrat an Limettenachteln auffüllen

- Eine `while`-Schleife kann so lange laufen, bis du genug Limettenachteln hast.
- Die Funktion `popfirst!()` wurde im Konzept Vectors behandelt.

## 3. Die Mixzeiten für jede Bestellung in der Warteschlange auflisten

- Mit `for` ... `in` ist das Durchlaufen eines Vektors einfach.
- Zum Aufbauen eines neuen Vektors kannst du `push!()` verwenden, das im Konzept Vectors behandelt wurde.
- Später im Lehrplan schauen wir uns verschiedene andere Möglichkeiten an, das in Julia zu machen.
