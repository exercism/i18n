# Hinweise

## 1. Eine Karte oben auf den Stapel legen

- Mit der [`ArrayTrait::append`-Funktion][append] kannst du ein Element hinten an ein Array anhängen.

## 2. Die oberste Karte vom Stapel nehmen

- Du kannst ein Array jederzeit in einen Span umwandeln und dann mit der [`SpanTrait::pop_back`-Funktion][pop-back] ein Element vom Ende eines Arrays entfernen.

## 3. Eine Karte unten in den Stapel legen

- Es gibt keine Möglichkeit, ein Element vorne an das Array anzuhängen, aber ein Ausweg ist, ein neues Array mit einem einzigen Element zu erstellen und das alte als Span mit [`ArrayTrait::append_span`][append-span] anzuhängen.

## 4. Eine Karte vom unteren Ende des Stapels nehmen

- Mit der [`ArrayTrait::pop_front`-Funktion][pop-front] kannst du ein Element von vorne aus einem Array entfernen.

## 5. Die Größe des Stapels prüfen

- Mit der [`ArrayTrait::len`-Funktion][len] kannst du die Länge eines Arrays ermitteln.
