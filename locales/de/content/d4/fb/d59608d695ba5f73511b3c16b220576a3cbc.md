# Einführung

Das in Java 8 eingeführte Paket `java.time` enthält mehrere Klassen für die Arbeit mit Datum und Uhrzeit.

## `LocalDate`

Die Klasse `java.time.LocalDate` repräsentiert ein Datum ohne Zeitzone im [ISO-8601-Kalendersystem][iso-8601], zum Beispiel `2007-12-03`:

```java
LocalDate date = LocalDate.of(2007, 12, 3);
```

Daten lassen sich mit anderen Daten vergleichen:

```java
LocalDate date1 = LocalDate.of(2007, 12, 3);
LocalDate date2 = LocalDate.of(2007, 12, 4);

date1.isBefore(date2);
// => true

date1.isAfter(date2);
// => false
```

Eine `LocalDate`-Instanz bietet Getter-Methoden, um einzelne Datumsbestandteile aus ihr auszulesen:

```java
LocalDate date = LocalDate.of(2007, 12, 3);

date.getDayOfMonth();
// => 3
```

Eine `LocalDate`-Instanz hat Methoden, mit denen du Zeiteinheiten hinzufügen kannst:

```exercism/note
Diese Methoden geben eine _neue_ `LocalDate`-Instanz zurück und ändern die bestehende Instanz nicht, denn die Klasse `LocalDate` ist unveränderlich.
```

```java
LocalDate date = LocalDate.of(2007, 12, 3);

date.plusDays(3);
// => 2007-12-06
```

## `LocalDateTime`

Die Klasse `java.time.LocalDateTime` repräsentiert einen Zeitpunkt ohne Zeitzone im [ISO-8601-Kalendersystem][iso-8601], zum Beispiel `2007-12-03T10:15:30`:

```java
LocalDateTime datetime = LocalDateTime.of(2007, 12, 3, 10, 15, 30);
```

Du kannst eine `LocalDate`-Instanz in ein `LocalDateTime` umwandeln:

```java
LocalDate date = LocalDate.of(2007, 12, 3);
LocalDateTime datetime = date.atTime(10, 15, 30);
datetime.toString();
// => "2007-12-03T10:15:30"
```

## Datum und Uhrzeit formatieren

Sowohl `LocalDate` als auch `LocalDateTime` verwenden die Standardnotation nach [ISO-8601][iso-8601], wenn sie von einem `String` oder in einen `String` umgewandelt werden.

```java
LocalDateTime datetime = LocalDateTime.of(2007, 12, 3, 10, 15, 30);
LocalDateTime parsed = LocalDateTime.parse("2007-12-03T10:15:30");

datetime.isEqual(parsed);
// => true
```

Es ist nicht möglich, ein `LocalDate` oder `LocalDateTime` auf diese Weise mit einem anderen Format aus einem `String` zu parsen.
Stattdessen solltest du zum Formatieren von Datumsangaben mit einem eigenen Format den `java.time.format.DateTimeFormatter` verwenden:

```java
DateTimeFormatter parser = DateTimeFormatter.ofPattern("dd/MM/yyyy");
LocalDate date = LocalDate.parse("03/12/2007", parser);

DateTimeFormatter printer = DateTimeFormatter.ofPattern("MMMM d, yyyy");
printer.format(date);
// => "December 3, 2007"
```

Beim Erstellen des eigenen Formats kannst du auch eine Locale angeben, um für verschiedene Regionen zu formatieren und zu parsen:

```java
DateTimeFormatter.ofPattern("MMMM d, yyyy", Locale.FRENCH).format(date);
// => décembre 3, 2007

DateTimeFormatter.ofPattern("MMMM d, yyyy", Locale.of("pt")).format(date);
// => dezembro 3, 2007
```

[iso-8601]: https://en.wikipedia.org/wiki/ISO_8601
