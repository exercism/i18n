# Einführung

JavaScript hat ein eingebautes Objekt `Date`, das Datum und Uhrzeit speichert und Methoden für deren Verwaltung bereitstellt.

Diese Übung konzentriert sich auf `Date`, das bis zum Ende von JavaScript relevant bleiben wird.

## Erstellung

Ein `Date`-Objekt ist eine Instanz der Klasse `Date`.
Es kann erstellt werden, ohne Argumente an die Konstruktorfunktion zu übergeben.
Das ergibt ein `Date`-Objekt, das das aktuelle Datum und die aktuelle Uhrzeit repräsentiert:

```javascript
const now = new Date();
// => Thu Apr 14 2022 11:46:08 GMT+0530 (India Standard Time)
// Shows current day, date and time (in your time zone).
```

### **Unix-Zeitstempel (Zahl)**

Wenn eine Zahl übergeben wird, wird sie als `timestamp` interpretiert.
Ein Zeitstempel ist eine Ganzzahl, die die Anzahl der **Millisekunden** angibt, die seit dem **1. Januar 1970 [UTC][defn-utc]+0** vergangen sind.

```javascript
const epoch = new Date(0);
// Thu Jan 01 1970 01:00:00 GMT+0100 (Central European Standard Time)

const another = new Date(1749508766627);
// Tue Jun 10 2025 00:39:26 GMT+0200 (Central European Summer Time)
```

Man könnte erwarten, dass `new Date(0)` das „früheste“ Datumsobjekt erzeugt, aber JavaScript wandelt das Datum in deine lokale Zeitzone um.
Das bedeutet, dass nur diejenigen rund um die Zeitzone [GMT / mit UTC+0][defn-gmt] tatsächlich den Wert der [Unix-Epoche][defn-unix-epoch] erhalten.

### **ISO-8601-Zeitstempel (String)**

Du kannst einen String, der ein Datum repräsentiert, an den `Date`-Konstruktor übergeben.
Das **einzige** Format, das über alle Implementierungen hinweg konsistent ist, ist die [vereinfachte Version][mdn-date-string-format] der international anerkannten und standardisierten sogenannten [ISO-8601-Zeitstempel-Strings][defn-iso8601].

Ein Zeitpunkt in [UTC][defn-gmt] sieht so aus:

```text
YYYY-MM-DDTHH:mm:ss.mssZ
YYYYMMDDTHHmmss.mssZ
```

Dabei gelten folgende Ersetzungen:

| Schlüssel | Beschreibung                                       | Standard |
| --------- | -------------------------------------------------- | -------- |
| YYYY      | Das Kalenderjahr, dargestellt mit 4 Ziffern        |          |
| MM        | Der Kalendermonat, dargestellt mit 2 Ziffern       | 01       |
| DD        | Der Kalendertag, dargestellt mit 2 Ziffern         | 01       |
| T         | Ein wörtlicher Buchstabe T, der Datum und Uhrzeit trennt |    |
| HH        | Die Stunden im 24-Stunden-Format, 2 Ziffern        | 00       |
| mm        | Die Minuten, 2 Ziffern                             | 00       |
| ss        | Die Sekunden, 2 Ziffern                            | 00       |
| mss       | Die Millisekunden, 3 Ziffern                       | 000      |
| Z         | Ein wörtlicher Buchstabe Z oder ein Offset `+/-HH:mm` |       |

Der wörtliche Buchstabe `Z` steht für UTC (keine Zeitzone, keine Sommerzeit).

Weil es für die meisten Komponenten Standardwerte gibt, ist es zulässig, Teile am Ende wegzulassen:

```text
YYYY-MM-DD
```

Standardwert ist die Uhrzeit 00:00:00.000.

Wenn der Zeitstempel nicht auf `Z` endet und nicht mit `+HH:mm` oder `-HH:mm` endet (was einen Zeitzonen-Offset angibt), gilt aus historischen Gründen Folgendes:

> Wenn der Zeitzonen-Offset fehlt, werden reine Datumsformen als UTC-Zeit und Datum-Uhrzeit-Formen als lokale Zeit interpretiert.
> Die Interpretation als UTC-Zeit geht auf einen historischen Fehler in der Spezifikation zurück, der nicht mit ISO 8601 übereinstimmte, aber aufgrund der Web-Kompatibilität nicht geändert werden konnte.
> Siehe [Broken Parser – A Web Reality Issue][ref-broken-parser].

### **Date-Objekt**

Ein bestehendes Datumsobjekt kann ebenfalls als Argument an den Konstruktor übergeben werden.
Dabei wird eine Kopie des bestehenden `Date`-Objekts mit demselben Datum und derselben Uhrzeit erstellt.

```javascript
const t1 = new Date();
const t2 = new Date(t1);
// Values of t1 and t2 will be the same.
```

### **Einzelne Datums- und Uhrzeitkomponenten übergeben**

Ein Datumsobjekt, das nur ein Datum repräsentiert, kann durch Übergabe von drei Zahlen erstellt werden.
Ein Datumsobjekt, das Datum und Uhrzeit repräsentiert, kann durch Übergabe von 6 Zahlen erstellt werden.

```javascript
const date1 = new Date(95, 11, 17);
// Creates Date for Dec 17 1995 00:00 if your local timezone is equivalent to UTC.

const date2 = new Date(2013, 12, 5, 13, 24, 0);
// Creates Date for Jan 5 2014 13:24 if your local timezone is equivalent to UTC.
```

Der zweite Wert ist der `month`, der bei `0` für Januar beginnt und bis `11` für Dezember reicht.

## `Date.parse()`

Möglicherweise stößt du auf Erwähnungen oder Verweise auf eine Funktion zum Parsen von Datumsangaben, `Date.parse`.
Weil es für diese Funktion nur wenige Invarianten (Wahrheiten) gibt und der Rest der Implementierung nicht spezifiziert (und damit nicht standardisiert) ist, solltest du sie nicht verwenden.

## Zugriff auf `Date`-Komponenten

Es gibt verschiedene Methoden auf Datumsobjekten, die die Komponenten des Datums zurückgeben:

```javascript
getFullYear(); // Get the year (4 digits)
getMonth(); // Get the month, from 0 to 11.
getDate(); // Get the day of month, from 1 to 31.
getHours(); // Get the hour in a 24 clock, from 0 to 23
getMinutes(); // Get the minutes, from 0 to 59
getSeconds(); // Get the seconds, from 0 to 59
getMilliseconds(); // Get the milliseconds, from 0 and 999
getDay(); // Get the day of week, from 0 (Sunday) to 6 (Saturday).
```

Jede dieser Methoden hat eine passende `set`-Variante (z. B. `setFullYear`), um den Wert zu aktualisieren.
Jeder überlaufende Wert geht auf die nächste Komponente über:

```javascript
const date = new Date('2025-02-28T12:42:00Z');
// => Fri Feb 28 2025 13:42:00 GMT+0100 (Central European Standard Time)

date.setDate(29);
// there was no February 29th in 2025.

date.getDate();
// => 1

date.toString();
// => Sat Mar 01 2025 13:42:00 GMT+0100 (Central European Standard Time)
```

Für alle Methoden gibt es UTC-Varianten, die die lokale Zeitzone ignorieren.

## Umwandlung eines Datums

Datumsobjekte haben eine Methode `getTime()`, die den UNIX-Zeitstempel in Millisekunden zurückgibt, also die Anzahl der Millisekunden seit Mitternacht am Beginn des 1. Januar 1970 UTC.
Zusätzlich gibt es eine Methode `toISOString()`, um ein Datumsobjekt in einen ISO-8601-Zeitstempel-String umzuwandeln.

## Datumsangaben vergleichen

Größer als (`>`) und größer oder gleich (`>=`) sowie kleiner als (`<`) und kleiner oder gleich (`<=`) können direkt zwischen zwei Datumsangaben oder zwischen einem Datum und einer Zahl verwendet werden.
Das funktioniert, weil JavaScript versucht, das Datum in einen primitiven Wert umzuwandeln.

Letzteres entspricht einem Aufruf von [`date.getTime()`][mdn-date-get-time].

Wenn du dich nicht auf dieses Verhalten verlassen möchtest, wandle den Wert zuerst mit `getTime()` in eine Zahl um.
