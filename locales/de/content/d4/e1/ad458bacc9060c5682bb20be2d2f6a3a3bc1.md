# Einführung

In Cairo kannst du mit Operator Overloading benutzerdefiniertes Verhalten für Standardoperatoren wie `+`, `-`, `==`, `<` usw. festlegen, wenn du mit eigenen Typen arbeitest.

Dazu implementierst du bestimmte Traits für deine eigenen Typen.

## Zentrale Traits für Operatoren

### `Add` und `Sub`

Mit den Traits `Add` und `Sub` legst du fest, wie die Addition (`+`) und die Subtraktion (`-`) mit deinem Typ funktionieren:

```rust
impl MyTypeAdd of Add<MyType> {
    fn add(lhs: MyType, rhs: MyType) -> MyType {
        // Define addition behavior
    }
}
```

### `PartialEq`

Der Trait `PartialEq` ermöglicht den Gleichheitsvergleich (`==` und `!=`) zwischen Instanzen deines Typs.

Häufig kannst du ihn automatisch mit `#[derive(PartialEq)]` ableiten.

### `PartialOrd`

Der Trait `PartialOrd` erlaubt Vergleichsoperationen (`<`, `>`, `<=`, `>=`) zwischen Instanzen deines Typs.

Du musst mindestens die Methode `lt` (less than, kleiner als) implementieren:

```rust
impl MyTypePartialOrd of PartialOrd<MyType> {
    fn lt(lhs: MyType, rhs: MyType) -> bool {
        // Define "less than" behavior
    }
}
```
