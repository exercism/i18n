# Über

In Common Lisp werden globale, benannte Funktionen mit `defun` definiert.

Diese Form nimmt als erstes Argument eine Liste von Parametern für die zu definierende Funktion entgegen (die Parameterliste wird auch „Lambda-Liste“ genannt).
Danach kann sie optional einen String als Dokumentation für diese Funktion entgegennehmen.
Schließlich folgen null oder mehr Ausdrücke, die den Funktionskörper der Funktion bilden.

Eine Funktion wird aufgerufen, indem man den Namen der Funktion als erstes Element eines Ausdrucks verwendet, gefolgt von den Argumenten für diese Funktion.

```lisp
(defun add-one (x) (1+ x))

(add-one 3) ;; => 4
```

Funktionen können auch [optionale Parameter][concept-optional-parameters], [Schlüsselwortparameter][concept-keyword-parameters] und [Rest-Parameter][concept-rest-parameters] entgegennehmen.
Diese werden in späteren Konzepten behandelt.

Der Name der Funktion ist im Funktionskörper im Gültigkeitsbereich, sodass Rekursion möglich ist.

```lisp
(defun countdown (x)
  (if (zerop x) (print 'BLAST-OFF)
    (progn (print x) (countdown (1- x)))))

(countdown 3) ;; will print "3","2", "1" and "BLAST-OFF" to
              ;; standard output before evalutaing to 'BLAST-OFF
```
