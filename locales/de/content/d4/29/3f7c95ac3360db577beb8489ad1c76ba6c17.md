# Anweisungen

Du baust einen kleinen Taschenrechner für die umgekehrte polnische Notation (UPN).
Der Zustand des Taschenrechners ist ein *Stapel von Werten*, dargestellt als Factor-Array, und eine *Operation* ist eine Quotation, die einen solchen Stapel entgegennimmt und einen neuen zurückgibt.

```factor
{ 3 4 }   ! the calculator's stack: 3 is below 4
[ ... ]   ! an operation that consumes some values and pushes a result
```

## 1. Implementiere die Addition

Definiere `add-op`, um die obersten beiden Werte vom Stapel zu nehmen, ihre Summe zu pushen und den neuen Stapel zurückzugeben.

```factor
{ 3 4 } add-op .
! => { 7 }

{ 1 2 3 4 } add-op .
! => { 1 2 7 }
```

## 2. Implementiere die Multiplikation

Definiere `multiply-op` genauso, aber für die Multiplikation.

```factor
{ 3 4 } multiply-op .
! => { 12 }
```

## 3. Wende eine einzelne Operation an

Definiere `apply-op`, um einen Stapel und eine Operation (eine Quotation) vom Datenstapel zu nehmen und den neuen Taschenrechner-Stapel zurückzugeben.

```factor
{ 3 4 } [ add-op ] apply-op .
! => { 7 }
```

## 4. Werte ein Programm aus

Definiere `evaluate`, um einen Startstapel und ein Array von Operationen zu nehmen und jede Operation der Reihe nach anzuwenden, wobei der endgültige Stapel zurückgegeben wird.

```factor
{ 3 4 5 } { [ add-op ] [ multiply-op ] } evaluate .
! => { 27 }
```

## 5. Nach Namen auswerten

Jetzt ist das Programm eine Liste von *Operatornamen* (Strings), und der Taschenrechner schlägt jeden Namen in einem Assoc nach, das Namen auf Operationen abbildet.

Definiere `evaluate-named`, um einen Startstapel, ein Assoc mit benannten Operationen und ein Array von Namen zu nehmen und den endgültigen Stapel zurückzugeben.

```factor
{ 3 4 5 } H{ { "+" [ add-op ] } { "*" [ multiply-op ] } } { "+" "*" }
evaluate-named .
! => { 27 }
```

## 6. Sicher dividieren

Ein echter Taschenrechner darf nicht stillschweigend Unsinn produzieren, wenn er durch null teilen soll. Die Fehlerklasse `zero-divisor-error` ist bereits für dich definiert. Implementiere `divide-op` analog zu `add-op` und `multiply-op`, außer dass es einen neuen `zero-divisor-error` `throw`t, wenn der Divisor oben auf dem Stapel `0` ist.

```factor
{ 12 4 } divide-op .
! => { 3 }

{ 1 5 6 2 } divide-op .
! => { 1 5 3 }

{ 5 0 } divide-op
! throws zero-divisor-error
```
