# Lernen

Die Programmiersprache Pascal hat eine lange Geschichte, und ein Großteil der Online-Dokumentation richtet sich an Anfänger. Die meisten dieser Tutorials befassen sich mit Konsolenprogrammen, bei denen du Informationen auf dem Bildschirm ausgibst und/oder Benutzereingaben einliest. Eines der häufigsten Anfänger-Tutorials ist zum Beispiel ein Programm, das 'Hello World' auf dem Bildschirm ausgibt:

```pascal
program HelloWorld;
begin
  writeln('Hello World!');
end.
```

Wenn du dieses Programm in einer Konsole bzw. einem Terminal ausführst, gibt es 'Hello World' auf dem Bildschirm aus.

Hier bei Exercism verwenden wir automatisierte Tests, um sicherzustellen, dass deine Lösungen korrekt sind. Deshalb brauchen wir eine **unit** statt eines **program**. Der wichtigste Unterschied: Du gibst einen Wert aus einer Funktion zurück, statt etwas ins Terminal zu schreiben:

```pascal
writeln('Hello World!');
```

wurde zu

```pascal
result := 'Hello World!'
```

Die Befehle write/writeln sind weiterhin nützlich, um Informationen anzuzeigen oder eine textuelle Darstellung der Ausgabe eines Befehls, einer mathematischen Operation usw. zu erhalten.
