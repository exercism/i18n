# Wiederverwendung von Funktionen

Wenn du eine bereits geschriebene Funktion wiederverwendest, hilft dir das, wartbaren Code zu schreiben.

Verwende vorhandene Funktionen wieder:
- `remaining_minutes_in_oven/1` kann `expected_minutes_in_oven/0` wiederverwenden
- `total_time_in_minutes/2` kann `preparation_time_in_minutes/1` wiederverwenden
