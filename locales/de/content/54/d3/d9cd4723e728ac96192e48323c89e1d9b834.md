# Über

In Gleam kannst du mit einem `case`-Ausdruck Code bedingt ausführen. Mit einem `case`-Ausdruck kannst du einen Wert gegen ein oder mehrere _Muster_ prüfen. Ein Beispiel für ein solches Muster ist das _literale Muster_, das einen Wert mit einem Literalwert abgleicht (z. B. `1` oder `"hello"`).

`case`-Ausdrücke schreibst du mit dem Schlüsselwort `case`:

```gleam
pub fn describe(number: Int) -> String {
  case number {
    0 -> "Zero"
    1 -> "One"
  }
}
```

Auch wenn das wie `switch`-Anweisungen in anderen Sprachen aussieht: Pattern Matching zeigt erst dann seine Stärke, wenn du auch andere Muster verwendest. Ein solches Muster ist das _Variablenmuster_, mit dem du einem Wert eine Variable zuweisen kannst. In diesem Beispiel bekommt die Variable `i` den Wert von `number`, wenn dieser nicht `0` ist:

```gleam
pub fn describe(number: Int) -> String {
  case number {
    0 -> "Zero"
    i -> "Non zero"
  }
}
```

Manchmal möchtest du einem Muster eine zusätzliche Bedingung hinzufügen. Man nennt das einen _Guard_ (Klausel), den du mit dem Schlüsselwort `if` hinzufügen kannst:

```gleam
pub fn describe(number: Int) -> String {
  case number {
    0 -> "Zero"
    i if i < 0 -> "Negative number"
  }
}
```

Aus Gründen der Performance sind in Guards nur einfache mathematische und boolesche Operatoren erlaubt, andere Funktionen lassen sich in Guards nicht verwenden.

Im obigen Beispiel gibt es nicht für jede mögliche Eingabe ein passendes Muster. Der Compiler erkennt das und gibt einen Fehler aus. Das nennt man _Vollständigkeitsprüfung_. Um die Warnung aufzulösen, musst du alle Fälle abdecken. Dafür kannst du das _Discard-Muster_ verwenden, ein Muster, das auf jeden Wert passt:

```gleam
pub fn describe(number: Int) -> String {
  case number {
    0 -> "Zero"
    i if i < 0 -> "Negative number"
    _ -> "Positive number"
  }
}

// No compiler error
```

Ein `case`-Ausdruck prüft einen Wert von oben nach unten gegen jedes Muster, bis er ein passendes Muster findet und die dazugehörige Logik ausführt. Die Reihenfolge der Muster ist entscheidend!
