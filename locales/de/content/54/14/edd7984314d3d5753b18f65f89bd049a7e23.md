# Einführung

Ein `String` (Zeichenkette) in Julia ist eine unveränderliche, endliche Folge von [Unicode](https://en.wikipedia.org/wiki/Unicode)-Zeichen in [UTF-8](https://en.wikipedia.org/wiki/UTF-8)-Kodierung.

Ein `String`-Literal ist eine Folge von Zeichen, die in doppelte Anführungszeichen eingeschlossen ist:

```julia-repl
julia> "Christopher"
"Christopher"
```

Strings lassen sich mit dem `*`-Operator verketten:

```julia-repl
julia> "Christopher" * " " * "Paolini"
"Christopher Paolini"
```

~~~~exercism/advanced
Wenn du neugierig bist, warum Julia zum Verketten von Strings `*` statt `+` verwendet, wirf einen Blick in das [Julia-Handbuch](https://docs.julialang.org/en/v1/manual/strings/#man-concatenation).
~~~~

Einige Sonderzeichen müssen mit einem vorangestellten Backslash maskiert werden:

```julia-repl
julia> println("\t or spaces?")
         or spaces?
```

Julia bringt von Haus aus viele nützliche Funktionen mit, um mit Strings zu arbeiten:

```julia-repl
julia> lowercase("TEST")
"test"

julia> titlecase("TEST")
"Test"
```
