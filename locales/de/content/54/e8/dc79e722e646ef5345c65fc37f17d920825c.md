# Über

Idris ist eine rein funktionale Allzweck-Programmiersprache mit [abhängigen Typen](http://en.wikipedia.org/wiki/Dependent_type).
Abhängige Typen erlauben es, Typen von Werten abhängig zu machen,
das heißt, manche Aspekte des Verhaltens eines Programms lassen sich präzise im Typ angeben.
Die Sprache wird kompiliert und verwendet [strikte Auswertung](http://en.wikipedia.org/wiki/Eager_evaluation).
Ihre Merkmale sind von Haskell und ML beeinflusst und umfassen:

- Vollständige abhängige Typen mit abhängigem Pattern Matching
- Einfaches Foreign Function Interface (zu C)
- Vom Compiler unterstütztes interaktives Editieren: Der Compiler hilft dir, Code mithilfe der Typen zu schreiben
- where-Klauseln, mit rule, einfachen case-Ausdrücken, Pattern-Matching-let- und lambda-Bindungen
- Abhängige Records mit Projektion und Update
- Interfaces (ähnlich den Typklassen in Haskell)
- Typgesteuerte Auflösung von Überladungen
- do-Notation und Idiom-Klammern
- Syntax, in der Einrückung bedeutsam ist
- Erweiterbare Syntax
- Kumulative Universen
- Totalitätsprüfung
- Interaktive Umgebung im Stil von [Hugs](http://www.haskell.org/hugs/)
