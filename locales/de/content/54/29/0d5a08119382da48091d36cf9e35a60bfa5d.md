# Einführung

## Vergleichsoperatoren

Vergleichsoperatoren funktionieren ähnlich wie in vielen anderen Sprachen.

Für Gleichheit gibt es die Operatoren `==` (gleich) und `!=` (ungleich).

```Kotlin
val txt = "abc"
txt == "abc" // => true
txt != "abc" // => false
```

Auch die Operatoren für größer und kleiner sind wie gewohnt.

```Kotlin
1 < 3 // => true
3 > 3 // => false
3 <= 3 // => true
4 >= 3 // => true
```

## Verzweigungen mit `if`

Das ist die vollständige Form eines `if`-Ausdrucks:

```Kotlin
if (conditional1) {
//    something...
} else if (conditional2) {
//    something...
} else {
//    something...
}
```

- Die runden Klammern `()` um jede Bedingung sind erforderlich.
- Eine Bedingung muss sich zu einem booleschen Wert `true` oder `false` auswerten lassen.
  Kotlin kennt kein Konzept von „truthy" und „falsy", wie es in manchen Sprachen existiert.
- Die geschweiften Klammern `{}` sind optional, wenn nur ein einziger Ausdruck vorhanden ist.
- Sowohl `else if` als auch `else` sind optional, und es kann mehrere `else if`-Blöcke geben.

Ein `if`-Ausdruck kann auch verwendet werden, um einen Wert „auszuwählen":

```Kotlin
val number = 100000
val description = if (number > 100) "number is over 100" else "number is less than 100"
// => description = "number is over 100"
```

## Alternativen?

Ganz bewusst gibt es in Kotlin den ternären Operator `? :` aus Java _nicht_.
Bevorzugt wird eine knappe Form von `if ... else`:

```Kotlin
return if (isOK) goodValue else badValue
```
