# Im Detail

Gleitkommazahlen sind Zahlen mit einer oder mehreren Ziffern hinter dem Dezimaltrennzeichen.

```gleam
let float = 3.45
// -> 3.45
```

Gleitkommazahlen haben außerdem ihre eigenen Operatoren.

```gleam
1.0 +. 1.4 // -> 2.4
5.0 -. 1.5 // -> 3.5
5.0 /. 2.0 // -> 2.5
3.0 *. 3.1 // -> 9.3

2.0 >. 1.0  // -> True
2.0 <. 1.0  // -> False
2.0 >=. 1.0 // -> True
2.0 <=. 1.0 // -> False
```

Zur besseren Lesbarkeit kannst du Gleitkommazahlen auch Unterstriche hinzufügen.

```gleam
1_000_000.0 // One million
```

Für Gleitkommazahlen kannst du auch die wissenschaftliche Notation verwenden:

```gleam
1.01e3 // -> 1010
15.1e-3 // -> 0.0151
```
