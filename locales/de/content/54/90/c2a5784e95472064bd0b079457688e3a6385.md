# Hilfe

Orte, an denen du Hilfe zu Tcl-Fragen findest:

* Der `tcl`-Tag auf [Stack Overflow](https://stackoverflow.com/tags/tcl).
* Sieh dir den Abschnitt „Resources“ auf der [Infoseite zum `tcl`-Tag von Stack Overflow](https://stackoverflow.com/tags/tcl/info) an.
* Erstelle ein Issue im Repository [exercism/tcl](https://github.com/exercism/tcl) auf GitHub.
