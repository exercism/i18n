# Über

Ein [`array`][arrays] in F# ist eine veränderbare Sammlung von null oder mehr Werten mit fester Länge. Das heißt, sobald ein Array erstellt wurde, kann sich seine Größe nicht mehr ändern, seine Werte aber schon. Alle Werte in einem Array müssen den gleichen Typ haben. [Arrays können wie folgt definiert werden][creating-arrays]:

```fsharp
let empty = [| |]
let emptyAlternative = Array.empty

let singleValue = [| 5 |]
let singleValueAlternative = Array.singleton 5

let threeValues = [| "a"; "b"; "c" |]
```

Elemente können einem Array zugewiesen oder [über einen Index][array-indexer] daraus ausgelesen werden. F#-Arrays sind nullbasiert, das heißt, der Index des ersten Elements ist immer null:

```fsharp
let numbers = [| 2; 3; 5 |]

// Update value in array
numbers[2] <- 9

// Read value from array
numbers[2]
// => 9
```

Arrays werden durch Funktionen und Operatoren bearbeitet, die im [`Array`-Modul][array-module] definiert sind. Einige dieser Funktionen sind auch als [Eigenschaften][array-properties] einer `array`-Instanz verfügbar:

```fsharp
Array.length [| 7; 8 |] // => 2
[| 7; 8 |].Length       // => 2
```

Hier gibt es keine richtige oder falsche Option. Im Allgemeinen harmonieren die Funktionen im `Array`-Modul besser mit der Typinferenz, während die Eigenschaften prägnanteren Code ermöglichen.

Das [_Array-Muster_][array-pattern] ermöglicht den Musterabgleich mit Arrays:

```fsharp
let describe array =
    match array with
    | [| |] -> "Empty"
    | [| 1; 2; three |] -> sprintf "1, 2, %d" three
    | _ -> "Other"

describe [| |]         // => "Empty"
describe [| 1; 2; 4 |] // => "1, 2, 4"
describe [| 5; 7; 9 |] // => "Other"
```

Beim Musterabgleich kannst du einen Wert auch _verwerfen_. Wenn dir ein Wert in einem bestimmten Fall _nicht_ wichtig ist (du den Wert also nicht _verwenden_ wirst), kannst du einen Unterstrich (`'_'`) verwenden, um das auszudrücken:

```fsharp
let describe array =
    match array with
    | [| |] -> "Empty array"
    | [| x |] -> "Array with one item"
    | [| _; y |] -> "Array with two items (first item ignored)"
    | _ -> "Array with many items (all items ignored)"

describe [| |]          // => "Empty array"
describe [| 1 |]        // => "Array with one item"
describe [| 5; 7 |]     // => "Array with two items (first item ignored)"
describe [| 5; 7; 9 |]  // => "Array with many items (all items ignored)"
```

Der einzelne `'_'` sollte beim Musterabgleich immer _zuletzt_ stehen; jeder Wert, der auf keinen der anderen Fälle _passt_, wird von diesem Fall behandelt.
