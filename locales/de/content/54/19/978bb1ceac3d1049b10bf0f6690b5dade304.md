# Anhang zu den Anweisungen

## Wörter

`smallest` und `largest` geben jeweils **zwei** Stack-Werte zurück: den Palindromwert (oder `f`, wenn im Bereich keiner existiert) und ein Array von Faktorpaaren.

- `smallest ( mn mx -- value factors )`
- `largest  ( mn mx -- value factors )`

Jedes Paar in `factors` ist ein zweielementiges Array `{ a b }`. Wirf den String `"min must be <= max"`, wenn `mn > mx` gilt.
