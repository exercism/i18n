# Über

Ein `SYMBOL:` *enthält* keinen Wert. Es ist nur ein Name. Der Wert
lebt in einem Namespace, und der Name ist der Schlüssel dazu.

```factor
USING: namespaces ;

SYMBOL: history

V{ } clone history set-global
"first event" history get-global push
"second event" history get-global push
history get-global .
! => V{ "first event" "second event" }
```

Zwei Gültigkeitsbereiche:

- **global**: geschrieben/gelesen mit `set-global`, `get-global`,
  `change-global`. Werte bleiben für die Lebensdauer des
  Prozesses erhalten.
- **dynamisch**: geschrieben/gelesen mit `set`, `get`, `change`.
  Bindungen gelten für die Dauer eines `with-variable`-Konstrukts.
  So kann äußerer Code einen Wert „injizieren“, den innerer Code
  sieht, ohne jede Signatur dazwischen zu ändern.

```factor
"verbose" log-level [
    log-level get .   ! => "verbose"
] with-variable
```

`SYMBOL:` und `SYMBOLS:` deklarieren Symbole zur Ladezeit des
Vokabulars und machen sie so zu Referenzen, die dateiübergreifend
gemeinsam genutzt werden können.
