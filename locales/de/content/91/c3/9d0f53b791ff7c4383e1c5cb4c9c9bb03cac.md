# Anleitung

Elyse, eine angehende Magierin, setzt ihre Ausbildung fort.
Sie bekommt mehrere Kartendecks, mit denen sie ihre Tricks vorführen muss.
Um es etwas einfacher zu machen, benutzt sie nur die Karten 1 bis 10.
Von jeder Karte hat sie nur eine, es gibt keine Duplikate in ihren Kartendecks.

In dieser Übung benutzt du Methoden aus Julias Base-Bibliothek, um den Inhalt eines Arrays zu analysieren.

## 1. Feststellen, ob eine Karte vorhanden ist

Elyse möchte feststellen, ob eine Karte im Deck vorhanden ist, mit anderen Worten, ob das Deck eine bestimmte Zahl enthält.

```julia-repl
julia> card = 3;

julia> has_card([2, 3, 4, 5], card)
true
```

## 2. Die Position einer Karte finden

Elyse möchte die Position (den Index) einer Karte im Deck wissen.
Wenn die Karte nicht im Deck ist, gib `nothing` zurück.

```julia-repl
julia> card = 2;

julia> find_card([9, 7, 3, 2], card)
4
```

## 3. Feststellen, ob jede Karte gerade ist

Elyse möchte wissen, ob jede Karte gerade ist, mit anderen Worten, ob jede Zahl im Deck gerade ist.

```julia-repl
julia> all_cards_even([2, 4, 6, 7])
false
```

## 4. Prüfen, ob das Deck eine Karte mit ungeradem Wert enthält

Elyse möchte wissen, ob es eine ungerade Zahl im Deck gibt.

```julia-repl
julia> any_odd_cards([3, 2, 6, 4, 8])
true
```

## 5. Die Position der ersten geraden Karte feststellen

Elyse möchte die Position der ersten Karte wissen, die gerade ist.
Wenn es keine geraden Karten im Deck gibt, gib `nothing` zurück.

```julia-repl
julia> first_even_card_idx([5, 2, 3, 1])
2
```

## 6. Die erste ungerade Karte aus dem Deck holen

Elyse möchte den Wert der ersten Karte wissen, die ungerade ist.
Wenn es keine ungeraden Karten im Deck gibt, gib `nothing` zurück.

```julia-repl
julia> first_odd_card([4, 2, 8, 7, 9])
7
```
