# Über

Gleitkommazahlen sind gebrochene oder ganze Zahlen mit einem Dezimalpunkt (wie `3.14`, `-1.7`, `99.99`, `2048.0`)

Der Typ Gleitkommazahl in Common Lisp ist in mehrere Untertypen unterteilt, die jeweils eigene Eigenschaften und Genauigkeiten haben: short-float, single-float, double-float und long-float.

Der Untertyp short-float belegt normalerweise den wenigsten Speicher und bietet unter den vier Untertypen die geringste Genauigkeit. Er eignet sich für Situationen, in denen der Speicherverbrauch wichtig ist, eine geringere Genauigkeit aber akzeptabel ist.

Der Untertyp single-float bietet einen Kompromiss zwischen Speicherverbrauch und Genauigkeit. Er wird häufig für allgemeine Berechnungen mit Gleitkommazahlen verwendet.

Der Untertyp double-float bietet eine höhere Genauigkeit als single-float und eignet sich für Anwendungen, die genauere Berechnungen erfordern, etwa wissenschaftliche Berechnungen und numerische Simulationen.

Der Untertyp long-float bietet die höchste Genauigkeit der vier Untertypen, benötigt aber möglicherweise mehr Speicher als die anderen. Er wird normalerweise für spezialisierte Anwendungen verwendet, die extrem genaue Berechnungen verlangen.

Diese Untertypen ermöglichen es Programmierern von Common Lisp, die passende Genauigkeit und den passenden Speicherverbrauch für die Anforderungen ihrer jeweiligen Anwendung zu wählen.

Wenn du nur mit ganzen Zahlen arbeitest, solltest du im Allgemeinen Ganzzahlen bevorzugen, da sie nicht unter demselben Genauigkeitsverlust leiden wie Gleitkommazahlen bei vielen Berechnungen.

## Referenz

```lisp
;; Rounding to the Nearest Whole Number
(round 3.14)  ; => 3
(round -3.14) ; => -3
(round 2.72)  ; => 3
(round -2.72) ; => -3

;; Rounding Towards Zero
(truncate 3.14)  ; => 3
(truncate -3.14) ; => -3
(truncate 2.72)  ; => 2
(truncate -2.72) ; => -2

;; Rounding Towards Negative Infinity
(floor 3.14)  ; => 3
(floor -3.14) ; => -4
(floor 2.72)  ; => 2
(floor -2.72) ; => -3

;; Rounding Towards Positive Infinity
(ceiling 3.14)  ; => 4
(ceiling -3.14) ; => -3
(ceiling 2.72)  ; => 3
(ceiling -2.72) ; => -2
```
