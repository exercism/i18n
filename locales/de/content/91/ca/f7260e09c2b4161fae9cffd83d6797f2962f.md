# Debug

Wenn ein Test fehlschlägt, wird eine Meldung angezeigt, die beschreibt, was schiefgelaufen ist und bei welcher Eingabe. Du kannst außerdem davon ausgehen, dass die [Konsolenausgabe][fmt-println] ebenfalls angezeigt wird. Du kannst so in die Konsole schreiben:

```go
import "fmt"
fmt.Println("Debug message")
```

[fmt-println]: https://pkg.go.dev/fmt#Println

Hinweis: Wenn du mit dem Editor im Browser debugst, fügt die Verwendung von z. B. `fmt.Print` keine neue Zeile nach der Ausgabe hinzu. Das kann einen Bug in `go test --json` auslösen und dazu führen, dass die Testausgabe durcheinandergerät.
