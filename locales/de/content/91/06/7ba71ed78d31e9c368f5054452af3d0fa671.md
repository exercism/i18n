# Instructions

Es war einmal ein exzentrischer Programmierer, der in einem seltsamen Haus mit vergitterten Fenstern lebte.
Eines Tages nahm er über ein Online-Jobportal einen Auftrag an: Er sollte einen Partyroboter bauen.
Der Roboter soll Gäste begrüßen und ihnen zu ihren Plätzen helfen.
Die erste Version war sehr technisch und zeigte, dass dem Programmierer der Umgang mit Menschen fehlte.
Einiges davon schaffte es auch in die nächste Version.

## 1. Begrüße einen neuen Gast auf der Party

Implementiere die Funktion `Welcome`, die eine Begrüßungsnachricht mit dem übergebenen Namen zurückgibt:

```go
Welcome("Christiane")
// => Welcome to my party, Christiane!
```

## 2. Begrüße einen neuen Gast, der heute Geburtstag hat

Implementiere die Funktion `HappyBirthday`, die eine Geburtstagsnachricht mit dem übergebenen Namen und Alter der Person zurückgibt.
Leider ist der Programmierer ein kleiner Angeber, also muss der Roboter sein Wissen über den Geburtstag jedes Gastes unter Beweis stellen.

```go
HappyBirthday("Frank", 58)
// => Happy birthday Frank! You are now 58 years old!
```

## 3. Gib Wegbeschreibungen

Implementiere die Funktion `AssignTable`, die Wegbeschreibungen gibt.
Sie soll 5 Parameter akzeptieren.

- Der Name des neuen Gastes, der begrüßt werden soll (`string`)
- Die Tischnummer (`int`)
- Der Name des Sitznachbarn (`string`)
- Die Richtung, in der der Tisch zu finden ist (`string`)
- Die Entfernung zum Tisch (`float64`)

Das genaue Format des Ergebnisses ist im Beispiel unten zu sehen.

Der Roboter gibt die Tischnummer in einem Format mit 3 Ziffern an.
Ist die Zahl kürzer als 3 Ziffern, bekommt sie führende Nullen, bis sie 3 Ziffern hat (z. B. wird aus 3 die 003).
Der Roboter nennt außerdem die Entfernung des Tisches.
Zum Glück nur mit einer Genauigkeit von 1 Nachkommastelle.

```go
AssignTable("Christiane", 27, "Frank", "on the left", 23.7834298)
// =>
// Welcome to my party, Christiane!
// You have been assigned to table 027. Your table is on the left, exactly 23.8 meters from here.
// You will be sitting next to Frank.
```
