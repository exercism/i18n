# Anweisungen

Als Schachfan möchtest du deine eigene Version des Spiels schreiben.
Ja, es gibt online vielleicht schon viele Schach-Implementierungen, aber deine wird einzigartig sein!

Du beginnst damit, ein einfaches Bewegungssystem für die Figuren zu implementieren.

Das Schachspiel wird auf einem acht Felder breiten und acht Felder langen Brett gespielt.
Die Felder werden durch einen Buchstaben und eine Zahl gekennzeichnet.

## 1. Definiere den Bereich der Reihen und Linien

Das Spiel muss die Reihen des Bretts speichern.
Die Reihen sind die Zeilen des Bretts und von 1 bis 8 nummeriert.

Das Spiel muss auch die Linien des Bretts speichern.
Die Linien sind die Spalten des Bretts und werden durch die Buchstaben A bis H gekennzeichnet.

Definiere die Konstanten `Chess::RANKS` und `Chess::FILES`, die den Bereich der Reihen bzw. Linien speichern.

```crystal
Chess::RANKS
# => 1..8

Chess::FILES
# => 'A'..'H'
```

## 2. Prüfe, ob ein Feld gültig ist

Das Spiel muss prüfen, ob ein Feld gültig ist.
Ein Feld ist gültig, wenn die Reihe und die Linie innerhalb der Bereiche der Reihen und Linien liegen.

Definiere die Methode `Chess.valid_square?`, die die Argumente `rank` (eine Ganzzahl für die Reihe) und `file` (ein Zeichen für die Linie) entgegennimmt.
Die Methode sollte `true` zurückgeben, wenn die Reihe und die Linie innerhalb der Bereiche der Reihen und Linien liegen, und andernfalls `false` zurückgeben.

```crystal
Chess.valid_square?(1, 'A')
# => true
```

## 3. Ermittle den Spitznamen des Spielers

Das Spiel muss den Spitznamen des Spielers ermitteln.
Der Spitzname besteht aus den ersten zwei Zeichen des Vornamens und den letzten zwei Zeichen des Nachnamens des Spielers.
Der Spitzname sollte in Großbuchstaben geschrieben werden.

Definiere die Methode `Chess.nickname`, die die Argumente `first_name` (ein String des Vornamens) und `last_name` (ein String des Nachnamens) entgegennimmt.
Die Methode sollte den Spitznamen des Spielers als String in Großbuchstaben zurückgeben.

```crystal
Chess.nickname("John", "Doe")
# => "JOOE"
```

## 4. Erstelle eine Zugnachricht

Das Spiel muss eine Nachricht für einen Zug erstellen, die angibt, welcher Spieler auf welches Feld gezogen ist.
Die Nachricht sollte den Spitznamen des Spielers und das Feld, auf das gezogen wurde, verwenden.
Das Spiel muss außerdem feststellen, ob der Zug gültig ist, indem es prüft, ob die Linie und die Reihe des Feldes innerhalb der Bereiche der Linien und Reihen liegen.

Wenn der Zug gültig ist, sollte die Nachricht lauten: `"{nickname} moved to {square}"`
Wenn der Zug ungültig ist, sollte die Nachricht lauten: `"{nickname} attempted to move to {square}, but that is not a valid square"`

Definiere die Methode `Chess.move_message`, die die Argumente `first_name` (ein String des Vornamens), `last_name` (ein String des Nachnamens) und `square` (ein String des Feldes, auf das der Spieler gezogen ist) entgegennimmt.
Die Methode sollte die Nachricht für den Zug als String zurückgeben.

```crystal
Chess.move_message("John", "Doe", "A1")
# => "JOOE moved to A1"
```
