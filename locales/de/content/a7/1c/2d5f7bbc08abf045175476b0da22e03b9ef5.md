# Anweisungen

Lucy, das Lisp-Alien, mag Zahlen und findet einige davon „großartig“.

Sie bittet dich, ihr zu helfen, Funktionen zu schreiben, mit denen Zahlen großartiger werden.

Was für Lucy eine Zahl großartig macht, kann sich ändern, deshalb müssen die Funktionen flexibel sein.

## 1. Großartig machen

Um aus einer Liste von Zahlen eine Liste großartigerer Zahlen zu machen, musst du eine Funktion `make-magnificent-maybe` schreiben, die eine Funktion, die auf die Zahlen angewendet wird, und eine Liste von Zahlen entgegennimmt.
Sie sollte zu einer Liste von Zahlen ausgewertet werden, die (gemäß der übergebenen Funktion) großartiger sind.

```lisp
(make-magnificent-maybe #'square '(1 2 3)) ; => (1 4 9)
(make-magnificent-maybe #'1+ '(1 2 3))     ; => (2 3 4)
```

## 2. Nur die Besten

Nachdem Lucy die Zahlen (hoffentlich) großartiger gemacht hat, möchte sie nur noch die Zahlen sehen, die wirklich großartig sind.

Sie weiß ganz sicher, dass 1 *niemals* großartig ist, also musst du die einfach entfernen.

Aber abgesehen davon ändert Lucy manchmal ihre Meinung, also gibt sie dir wieder eine Funktion, die dir sagt, ob eine Zahl großartig ist oder nicht.

Du musst eine Funktion `only-the-best` schreiben, die eine Funktion und eine Liste von Zahlen entgegennimmt und nur die besten Zahlen zurückgibt (nicht `1` und keine Zahlen, für die die Funktion wahr ergibt).

```lisp
(only-the-best #'evenp '(1 2 3 4 5)) ; => (3 5)
(only-the-best #'oddp '(1 3 5))    ; => ()
```
