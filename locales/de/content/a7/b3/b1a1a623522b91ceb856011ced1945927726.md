# Über

JavaScript hat einen Inkrement- und einen Dekrementoperator.
Sie verändern eine Variable direkt.
`++` addiert eins zu einer Zahl, `--` subtrahiert eins von einer Zahl.

```javascript
let i = 3;
i++;
// i is now 4

let j = 0;
j--;
// j is now -1
```

Das Beispiel oben zeigt den Postfix-Operator für Inkrement und Dekrement.
Dabei steht der Operator hinter der Variable, und der Rückgabewert des Ausdrucks ist der Wert der Variable _vor_ der Erhöhung bzw. Verringerung.

```javascript
let a = 3;
let b = a++;
// a = 4
// b = 3
```

Es gibt auch die Präfix-Variante, bei der der Operator vor der Variable steht.
Dann ist der Rückgabewert der Wert der Variable _nach_ der Erhöhung bzw. Verringerung.

```javascript
let a = 3;
let b = ++a;
// a = 4
// b = 4
```
