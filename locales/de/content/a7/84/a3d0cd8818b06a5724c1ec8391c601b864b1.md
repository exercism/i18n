# Parameter ohne vorangestellten Unterstrich bevorzugen

Anders als in anderen Sprachen bedeutet `_identifier` nicht, dass eine Funktion, ein Parameter oder eine Variable **private** ist.

In TypeScript verhindert ein vorangestellter Unterstrich bei einem Parameter stattdessen, dass viele IDEs diesen Parameter hervorheben, wenn er nicht verwendet wird. Entferne den Unterstrich (`_`) am Anfang von `%{parameter.name}`, um das zu beheben.
