# Repräsentationen

Der [Representer][representer] wendet die folgenden Normalisierungen an:

- [Alle Kommentare und Docs werden entfernt][remove-comments-and-docs]
- [Imports in Modulen und Funktionen werden sortiert][sort-imports-order]
- [Der Code wird mit `mix format` formatiert][format-code]
- [Bezeichner werden zu einem Platzhalterwert normalisiert][normalize-identifiers]
- [Schlüssel werden in Maps und Structs sortiert][sort-keys-in-maps-and-structs]
