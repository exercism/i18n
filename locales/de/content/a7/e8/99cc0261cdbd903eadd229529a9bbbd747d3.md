# Einführung

## Vererbung

Vererbung ist ein Kernkonzept der OOP (objektorientierte Programmierung).
Sie stellt eine IS-A-Beziehung dar.
In der Programmierung bedeutet sie genau das, was sie auch im Englischen bedeutet: Man erbt Merkmale von der Elternklasse (in der Programmierung sind diese Merkmale normalerweise Funktionen und Variablen).

Betrachte eine Klasse `Animal` wie hier gezeigt:

```java
//Creating an Animal class with bark() as a member function.
public class Animal {

    public void bark() {
        System.out.println("This is an animal");
    }

}
```

`Animal` ist eine Elternklasse, weil ihre Merkmale auf alle Tiere im Allgemeinen erweitert werden können.

Betrachte ein Tier namens `Lion` mit einer Klasse wie dieser:

```java
//Lion class is a child class of Animal.
public class Lion extends Animal {

    @Override
    public void bark() {
        System.out.println("Lion here!!");
    }

}
```

~~~~exercism/note
Die `Override`-Annotation zeigt an, dass eine Methode in einer Unterklasse eine Methode ihrer Oberklasse überschreibt.
Sie ist nicht unbedingt nötig, aber es gilt als bewährte Praxis, sie zu verwenden.
~~~~

Wenn wir nun Folgendes schreiben:

```java
Animal animal = new Lion(); //creating instance of Animal, of type Lion
animal.bark();
```

Beachte: Hier wird die Klasse `Animal` mit `Lion` initialisiert.
Die Ausgabe sieht dann so aus:

```java
Lion here!!
```

In der OOP gibt es viele Arten der Vererbung, aber Java unterstützt nur einige davon (mehrstufige und hierarchische Vererbung).
Mehr dazu erfährst du [hier][java-inheritance].
