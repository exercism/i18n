# Hinweise

## 1. Ermittle, wie lange das Mixen eines Safts dauert

- Schau dir noch einmal das Konzept [Switch][concept-switch] an, um Ansätze dafür zu finden.

## 2. Fülle den Vorrat an Limettenachteln wieder auf

- Schleife so lange, bis eine der Bedingungen aus der Aufgabenstellung erfüllt ist.
- Es kann hilfreich sein, aber nicht erforderlich, eine kleine Hilfsfunktion zu haben, die Limettengrößen mit der Anzahl der Achtel in Beziehung setzt, die daraus entstehen.
- Auch hier kann das Konzept [Switch][concept-switch] praktische Ansätze nahelegen.
- Gib zurück, wie viele Limetten tatsächlich geschnitten wurden.

## 3. Liste die Zeiten auf, um jede Bestellung in der Warteschlange zu mixen

- In diesem Stadium des Lehrplans ist der einfachste Ansatz eine `for`-Schleife über `orders`, aber es geht auch mit `seq_along`.
- Eine frühere Aufgabe kann eine nützliche Funktion liefern.
- Gib die Zeiten der Reihe nach mit [`print()`][print-function] aus (siehe Einleitung für ein Beispiel).
- Für diese Übung sollst du nichts zurückgeben.

## 4. Beende die Schicht

- Schleife so lange, wie es Bestellungen und noch etwas Zeit gibt.
- Gib einen Vektor der Bestellungen zurück, die nicht begonnen wurden.
