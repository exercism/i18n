# Einführung

Das Vokabular [`random`][random] von Factor stellt ein einziges generisches Wort bereit, `random`, das sich an sein Argument anpasst, dazu Hilfswörter zum Mischen und Ziehen von Stichproben aus Sequenzen.

```factor
USING: random ;

6 random .                       ! a value from 0..5
{ "rock" "paper" "scissors" } random .   ! a random element
{ 1 2 3 4 5 } randomize .        ! the same cards, reordered
{ 1 2 3 4 5 } 2 sample .         ! two distinct elements
```

Auf eine Ganzzahl `n` angewendet liefert `random` einen Wert in `[0, n)`; auf eine Sequenz angewendet liefert es ein zufälliges Element. `randomize` mischt an Ort und Stelle, und `sample` zieht verschiedene Elemente.

Standardmäßig stammen diese Werte aus einem globalen Generator, der mit der Systemuhr als Startwert initialisiert wird. Damit die Ergebnisse reproduzierbar sind, installierst du einen Generator mit festem Startwert über `<mersenne-twister>` (aus [`random.mersenne-twister`][mt]) und `with-random`:

```factor
USING: random random.mersenne-twister ;

42 <mersenne-twister> [ 6 random ] with-random .   ! same value every run
```

[random]: https://docs.factorcode.org/content/vocab-random.html
[mt]: https://docs.factorcode.org/content/vocab-random.mersenne-twister.html
