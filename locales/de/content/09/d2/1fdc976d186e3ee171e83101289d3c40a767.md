# Hinweise

## Allgemein

- Damit ein Name mehrere verschiedene Typen haben kann, musst du einen [Union-Typ][union-type] verwenden.
- Damit eine Instanzvariable in einem Kontrollausdruck [`if var.is_a?(Type)`][if-is-a] verwendet werden kann, muss sie zuerst einer lokalen Variable zugewiesen werden.

## 1. Ein Passwort festlegen

- Du musst eine Klasse mit dem Namen `PasswordLock` definieren.
- Du musst eine initialize-Methode definieren, die entweder einen `String`, `Int32` oder `Float64` als Argument entgegennimmt.
- Du musst eine [Instanzvariable][instance-variable] `@password` definieren, die auf das Argument gesetzt wird, das dem Konstruktor übergeben wurde.

## 2. Das Passwort verschlüsseln

- Definiere eine Instanzmethode namens `encrypt`.
- Die Methode sollte die [Instanzvariable][instance-variable] `@password` so verändern, dass sie verschlüsselt wird.
- Damit ein bestimmter Zweig nur ausgeführt werden kann, wenn die Variable einen bestimmten Typ hat, musst du die Methode [`is_a?`][is-a] in einem Kontrollausdruck verwenden.

## 3. Prüfen, ob ein Passwort korrekt ist

- Du kannst bereits definierte Methoden verwenden, um den übergebenen Passwortversuch zu verschlüsseln.
