# nicht in die Konsole schreiben

Entferne die Funktion(en), die in die Konsole schreiben, denn die Tests benötigen sie nicht und sie machen den Code etwas schwerer lesbar.

Normalerweise werden solche Anweisungen hinzugefügt, um den Code zu debuggen. Ein besserer Ansatz ist es jedoch, den Code beim Ausführen von einem oder mehreren Unit-Tests zu debuggen. Das hat den zusätzlichen Vorteil, dass du dich auf das Debuggen eines bestimmten Testfalls konzentrieren kannst. Hier sind ein paar Links, die erklären, wie du Scala-Code beim Ausführen von Unit-Tests in verschiedenen IDEs debuggen kannst:

- [IntelliJ](https://www.jetbrains.com/help/idea/run-debug-and-test-scala.html)
- [Eclipse](http://scala-ide.org/docs/current-user-doc/features/scaladebugger/index.html)
