# Über

Wenn wir Code mit Verzweigungen brauchen, können wir [`cond/1`][cond] verwenden:

```elixir
cond do
  x > 10 -> :this_might_be_the_way
  y < 7 -> :or_that_might_be_the_way
  true -> :this_is_the_default_way
end
```

`cond` folgt dem ersten Pfad, der zu `true` ausgewertet wird. Mindestens eine Klausel sollte zu `true` ausgewertet werden, sonst wird ein Laufzeitfehler ausgelöst.

Die `cond`-Bedingung wird normalerweise verwendet, wenn es mehr als zwei logische Zweige gibt und jeder Zweig eine Bedingung hat, die auf unterschiedlichen Variablen basiert. Wenn alle Bedingungen auf denselben Variablen basieren, ist eine [`case`][case]-Bedingung besser geeignet. Wenn es nur zwei logische Zweige gibt, verwende stattdessen eine [`if`][if]-Bedingung.

[cond]: https://hexdocs.pm/elixir/case-cond-and-if.html#cond
[case]: https://hexdocs.pm/elixir/case-cond-and-if.html#case
[if]: https://hexdocs.pm/elixir/case-cond-and-if.html#if
