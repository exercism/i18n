Doch die Dinge sind etwas unordentlich: Aazras Koordinaten scheinen anders formatiert und sortiert zu sein als die von Rui, und die beiden müssen ständig von einer Liste zur anderen schauen, um herauszufinden, welche Schätze zu welchen Orten gehören. Als angehende Gleamlins kommen sie zu dir und bitten um Hilfe beim Schreiben eines kleinen Programms (genauer gesagt: einer Reihe von Funktionen), mit dem sie ihre Jagdinformationen besser organisieren können.

## 1. Orte umwandeln

Implementiere die Funktion `place_location_to_treasure_location`, die einen Ortsort (etwa `#("C", 1)`) entgegennimmt und ihn in einen Schatzort (etwa `#(1, "C")`) umwandelt.

```gleam
place_location_to_treasure_location(#("C", 1))
// -> #(1, "C")
```

## 2. Schatz- und Ortsorte vergleichen

Implementiere die Funktion `treasure_location_matches_place_location`, die einen Ortsort (etwa `#("C", 1)`) entgegennimmt und `True` zurückgibt, wenn er zu einem Schatzort (etwa `#(1, "C")`) passt.

```gleam
treasure_location_matches_place_location(#("C", 1), #(1, "C"))
// -> True

treasure_location_matches_place_location(#("C", 1), #(2, "C"))
// -> False
```

## 3. Schatzorte zählen

Implementiere die Funktion `count_place_treasures`, die einen Ort (etwa `#("Aqua Lagoon (Island of Mystery)", #("F", 1))`) und die Liste der Schätze entgegennimmt und die Anzahl der Schätze zurückgibt, die dort zu finden sind.

```gleam
let place = #("Aqua Lagoon (Island of Mystery)", #("F", 1))

count_place_treasures(place, treasures)
// -> 2
```

## 4. Besondere Orte

Implementiere die Funktion `special_case_swap_possible`, die einen Schatz (etwa `#("Amethyst Octopus", #(1, "F"))`), einen Ort (etwa `#("Seaside Cottages", #("C", 1))`) und einen gewünschten Schatz (etwa `#("Crystal Crab", #(6, "A"))`) entgegennimmt und für die folgenden Kombinationen `True` zurückgibt:

- Brass Spyglass kann am Abandoned Lighthouse gegen jeden anderen Schatz getauscht werden.
- Amethyst Octopus kann am Stormy Breakwater gegen Crystal Crab oder Glass Starfish getauscht werden.
- Vintage Pirate Hat kann im Harbor Managers Office gegen Model Ship in Large Bottle oder Antique Glass Fishnet Float getauscht werden.
