# Einführung

## Pakete und Module

### Importieren

Ein Modul wird normalerweise mit dem Schlüsselwort `use` geladen.
Dadurch wird das Modul geladen und die `import`-Methode darauf aufgerufen, wodurch alle exportierten Symbole importiert werden.

Symbole im `@EXPORT`-Array des Pakets werden standardmäßig importiert.
Symbole im `@EXPORT_OK`-Array des Pakets müssen explizit importiert werden.

### Exportieren

Damit ein Symbol importiert werden kann, muss es zuerst exportiert werden.
Das Modul [Exporter][Exporter] ist Teil von Perl und eine der bequemsten Möglichkeiten zum Exportieren.

Definieren des Moduls:
```perl
package Foo;

use Exporter ('import');
our @EXPORT_OK = ('bar');

sub bar { ... }
```

Verwenden des Moduls:
```perl
use Foo ('bar');

bar();
```

### Kernmodule

Neben [Exporter][Exporter] bietet Perl eine große Auswahl an [Kernmodulen][perl-core-modules], die du verwenden kannst.
Einige nützliche Beispiele für Übungen, auf die du hier stoßen kannst, sind [List::Util][List::Util], [Time::Piece][Time::Piece] und [Math::BigRat][Math::BigRat].

### CPAN

Zusätzlich zu den Kernmodulen bietet [CPAN][metacpan] Tausende weiterer Module, die von der Perl-Community erstellt wurden und installiert werden können.
Der Perl-Track verwendet eine [cpanfile][test-runner-cpanfile], um eine Auswahl von Modulen zu installieren, die mit dem Perl-Test-Runner von Exercism verwendet werden können.
