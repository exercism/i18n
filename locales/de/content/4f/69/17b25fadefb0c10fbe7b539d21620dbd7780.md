# Anleitung

Dein Freund hat dir gerade eine Nachricht mit einem wichtigen Geheimnis geschickt.
Weil er es anderen nicht leicht machen wollte, sie zu lesen, wurde die Nachricht durch eine Reihe von Bitmanipulationen verschlüsselt.
Du musst die Funktionen schreiben, die beim Entschlüsseln der Nachricht helfen.

## 1. Verschiebe die Bits zurück

Der erste Schritt beim Entschlüsseln der Nachricht besteht darin, die Verschiebung aus dem Verschlüsselungsprozess rückgängig zu machen, indem du die Bits wieder nach rechts verschiebst.
In den weiteren Schritten der Entschlüsselung wird davon ausgegangen, dass von der linken Seite 0en eingefügt werden.

Implementiere die Funktion `shift_back()`, die einen Wert und die Anzahl der Stellen zum Verschieben entgegennimmt und die Verschiebung durchführt.

```julia
shift_back(0b1001, 2) # => 0b0010
```

## 2. Setze einige Bits

Als Nächstes gibt es einige Bits, die auf 1 gesetzt werden müssen.

Implementiere die Funktion `set_bits()`, die einen Wert und eine Maske entgegennimmt und das Ergebnis davon zurückgibt, dass die Bits in value auf 1 gesetzt werden.
Ein Bit aus `value` sollte auf 1 gesetzt werden, wenn das Bit in der `mask` ebenfalls 1 ist.
Alle anderen Bits bleiben unverändert.

```julia
set_bits(0b0110, 0b0101) # => 0b0111
```

## 3. Drehe bestimmte Bits um

Beim Verschlüsseln werden einige Bits umgedreht.
Um die Nachricht zu entschlüsseln, müssen sie wieder zurückgedreht werden.

Implementiere die Funktion `flip_bits()`, die einen Wert und die Maske entgegennimmt.
Die Maske gibt an, welche Bits im Wert umgedreht werden.
Wenn das Bit in `mask` 1 ist, wird das Bit im `value` umgedreht.
Alle anderen Bits bleiben unverändert.

```julia
flip_bits(0b1100, 0b0101) # => 0b1001
```

## 4. Lösche bestimmte Bits

Zuletzt gibt es außerdem bestimmte Bits, die immer zu 0 entschlüsselt werden.

Implementiere die Funktion `clear_bits()`, die einen Wert und eine Maske entgegennimmt.
Die Bits im `value` sollten auf 0 gesetzt werden, wenn das Bit in der Maske 1 ist.
Alle anderen Bits bleiben unverändert.

```julia
clear_bits(0b0110, 0b0101) # => 0b0010
```
