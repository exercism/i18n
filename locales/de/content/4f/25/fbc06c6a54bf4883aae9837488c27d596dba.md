# Tests ausführen

Wechsle im Terminal in das Basisverzeichnis der Übung und führe dann die Tests aus mit:

```bash
$ gleam test
```

Damit wird die Testdatei im Unterordner `test` ausgeführt, also eine Datei, die auf `_test.gleam` endet.

## Testfunktionen

Die Tests verwenden ein [eigenes Test-Framework](https://github.com/exercism/gleam-test-runner/tree/main/runner).
Jede öffentliche Funktion im Verzeichnis `test`, deren Name auf `_test` endet, wird vom Test-Framework als Test betrachtet.

Zum Beispiel:

```gleam
import bob
import exercism/should

pub fn shouting_test {
  bob.hey("WATCH OUT!")
  |> should.equal("Whoa, chill out!")
}
```
