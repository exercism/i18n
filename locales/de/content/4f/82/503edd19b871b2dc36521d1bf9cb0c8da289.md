# Einführung

Python hat zwei Schleifenkonstrukte.
`while`-Schleifen für die _unbestimmte_ (ungezählte) Iteration und `for`-Schleifen für die _bestimmte_ (gezählte) Iteration.
Die Schlüsselwörter `break`, `continue` und `else` helfen dabei, das Verhalten einer Schleife anzupassen.
Die Funktionen `range(<length of sequence>)` und `enumerate(<iterable>)` helfen beim Zählen der Durchläufe und beim Indizieren.

`while`-Schleifen haben keine festgelegte Anzahl an Durchläufen und laufen so lange weiter, wie der `loop`-Ausdruck oder der „Test“ als `True` ausgewertet wird.
Die Schleife wird beendet, wenn der Schleifenausdruck als `False` ausgewertet wird.

```python
while expression:
    set_of_statements
```

`for`-Schleifen durchlaufen die Werte einer beliebigen Sequenz und enden, wenn keine weiteren Werte mehr zurückgegeben werden.
Die Funktion `range(<length of sequence>)` stellt einen `loop`-Zähler oder eine Sequenz bereit, wenn es keine Datenstruktur oder ein anderes iterierbares Objekt gibt, über das du iterieren kannst.

```python
# Python will keep track of the loop count internally.
for item in sequence:
    set_of_statements
    
# `range()` is used as an explicit loop counter.  
# This will loop 12 times, from index 0 to index 11.
for item in range(12):
    set_of_statements
```
