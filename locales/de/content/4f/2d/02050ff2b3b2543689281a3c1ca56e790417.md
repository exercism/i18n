# Hinweise

## 1. Die drei Nummern

- Der Klassenkopf gibt hinter `<` die abstrakte Klasse an:
  `class JUGGLING < $ACT is`.
- Jede muss sowohl `name` als auch `minutes` definieren, genau so, wie die abstrakte
  Klasse sie deklariert. Fehlt eine davon, meldet der Compiler einen Fehler und nennt
  die Routine.
- Jede braucht außerdem ein `create`, sonst hat `#JUGGLING` nichts zum Aufrufen.
  `create : SAME is return new; end;` ist für zwei von ihnen alles, was nötig ist.
- `TRAPEZE` braucht ein Attribut für die Höhe und ein `create`, das sie entgegennimmt.
- `+` hängt eine Zahl an einen String an, also braucht `"Trapeze at " + height + "m"`
  keine Umwandlung.

## 2. Die Vorstellung

- Der Argumenttyp ist `ARRAY{$ACT}`. Damit kann ein Array alle drei Arten aufnehmen.
- `acts.elt!` liefert ein `$ACT`. Ein Aufruf von `.minutes` darauf führt automatisch
  die richtige aus. Das ist Dispatch und genau darum geht es in der Übung. Es gibt
  nichts zu prüfen und kein `typecase` zu schreiben.
- `billing` baut in einer Schleife einen String auf, also `FSTR`, und das `", "` steht
  vor jedem Namen außer dem ersten.
- `longest` behält die bisher beste Nummer. Die besten Minuten bei `-1` zu starten
  heißt, dass die erste Nummer sie immer schlägt; das fängt die leere Vorstellung
  ohne Sonderfall ab: Der Name bleibt `""`.
