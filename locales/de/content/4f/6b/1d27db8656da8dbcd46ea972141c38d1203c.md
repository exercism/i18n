# Debug

Um dir beim Debuggen zu helfen, sind in einer [debug.mac-Datei][debug] verschiedene Makros definiert.
Du kannst sie mit einem oder mehreren Argumenten des passenden Typs und der passenden Größe aufrufen.
Zum Beispiel:

```x86asm
debugf32 xmm0, xmm1 ; prints the value of two 32-bit floating-point numbers
debugd16 ax, cx, dx ; prints the value of three signed 16-bit integers
debugx64 [rax]      ; prints the value of a 64-bit integer in hexadecimal format
debugs rel mem, rsi ; prints two NUL-terminated strings
debugu8_xmm xmm1    ; prints 16 packed 8-bit unsigned integers
debug_flag e        ; prints true if je would jump, and false otherwise
```

Um eines dieser Makros zu verwenden, muss `debug.mac` am Anfang der Lösungsdatei eingebunden werden:

```x86asm
%include "debug.mac"
```

Beachte, dass alle Makros `rsp` vorübergehend verändern.
Um einen Wert auf dem Stack zu debuggen, lade ihn oder seine Adresse zuerst in ein anderes Register.

[debug]: https://github.com/exercism/x86-64-assembly/tree/main/templates/debug.mac
