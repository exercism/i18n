Du kannst Strings in Haxe zwar manuell verketten, aber Haxe unterstützt die [Stringinterpolation][string-interpolation], die eine kürzere und bequemere Syntax bietet:

```haxe
var x = 42;
//The following two statements are equivalent:

// manual concatenation
trace("the number is " + x);

// using interpolation
trace('the number is $x');
```

Wie oben zu sehen, werden interpolierte Strings von einfachen Anführungszeichen (`'`) umschlossen, anders als normale [Strings][strings], und können spezielle Bezeichner enthalten, die durch das Dollarzeichen (`$`) gekennzeichnet sind und die Interpolation auslösen.

Du kannst auch ganze Ausdrücke einbinden, indem du `${expr}` verwendest, wobei `expr` ein beliebiger gültiger Haxe-Ausdruck ist:

```haxe
trace('the next number is ${x + 1}');
```

Wenn du ein echtes Dollarzeichen ausgeben willst und die Interpolation unterdrücken möchtest, kannst du `$$` verwenden:

```haxe
trace('the price is $$42'); // outputs: the price is $42
```

Beachte zum Schluss, dass die Stringinterpolation ein Feature zur Kompilierzeit ist und keinen Einfluss auf die Laufzeitleistung hat. Intern erzeugt der Haxe-Compiler denselben Code, den auch die manuelle Verkettung erzeugt.

[string-interpolation]: https://haxe.org/manual/lf-string-interpolation.html
[strings]: https://haxe.org/manual/std-String.html
