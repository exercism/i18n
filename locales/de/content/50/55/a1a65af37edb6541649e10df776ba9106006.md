# Tests

Um die Tests auszuführen, führe den folgenden Befehl aus:

```bash
make
```

## Übersprungene Tests

Eine Übung zu lösen heißt, alle ihre Tests zu bestehen.
Standardmäßig wird nur ein Test (der erste) ausgeführt, wenn du die Tests startest.
Das ist Absicht, denn so kannst du dich ganz darauf konzentrieren, diesen einen Test zu bestehen.
Sobald er besteht, kannst du den nächsten Test aktivieren, indem du die Zeile `TEST_IGNORE()` entfernst.
Wenn alle Tests aktiviert sind und deine Implementierung sie alle besteht, hast du die Übung gelöst!

## Debugging

Als Hilfe beim Debugging gibt es verschiedene Makros, die in einer Datei `debug.mac` definiert sind.
Du kannst sie mit einem oder mehreren Argumenten der passenden Größe aufrufen.
Zum Beispiel:

```x86asm
debugf32 xmm0, xmm1 ; prints the value of two 32-bit floating-point numbers
debugd16 ax, cx, dx ; prints the value of three signed 16-bit integers
debugx64 [rax]      ; prints the value of a 64-bit integer in hexadecimal format
debugs rsi          ; prints a NUL-terminated string whose address is stored in `rsi`
debugu8_xmm xmm1    ; prints 16 packed 8-bit unsigned integers
```

Um eines dieser Makros zu verwenden, muss `debug.mac` oben in der Lösungsdatei eingebunden werden:

```x86asm
%include "debug.mac"
```
