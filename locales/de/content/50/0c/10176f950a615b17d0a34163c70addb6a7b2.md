# Über

Wie andere Sprachen bietet auch C++ eine `switch`-Anweisung.
Switch-Anweisungen sind eine kürzere Schreibweise für lange `if ... else if`-Anweisungen.
Um eine `switch`-Anweisung zu erstellen, beginnen wir mit dem Schlüsselwort `switch`, gefolgt von einer Ganzzahl.
Danach deklarieren wir jede einzelne der Bedingungen mit dem Schlüsselwort `case`.
Wir können außerdem einen `default`-Fall deklarieren, der ausgeführt wird, wenn keine der vorherigen `case`-Bedingungen zutrifft.
Jeder Fall sollte mit einer `break`-Anweisung (oder `return`-Anweisung) enden.

```cpp
int price{0};
int adults{3};
int kids{2};

switch (int group_size{adults + kids}) {
    case 1:
        price = 50;
        break;
    case 2:
        price = 70;
        break;
    default:
        price = group_size * 30;
}
```

## Fall-through

Wichtig beim `switch`-Konstrukt ist, dass der Code weiter ausgeführt wird, bis er durch eine `break`-Anweisung (oder `return`-Anweisung) gestoppt wird.
Das kann zu unerwartetem Verhalten führen.

```cpp
int adults{1};
int kids{0};
switch (int group_size{adults + kids}) {
    case 1:
        price = 50;
    case 2:
        price = 70;
    default:
        price = group_size * 30;
}
// price will be 30!
```

Der wichtigste Anwendungsfall für dieses Weiterlaufen ist eine Anweisung mit mehreren Labels.
Mehrere Switch-Ergebnisse können auf denselben auszuführenden Codeabschnitt verweisen.
So kann zum Beispiel in einer Buchungs-App die aufgerufene Funktion für die Gruppengrößen 2 und 3 dieselbe sein:
```cpp
switch (group_size) {
case 1:
    book_room();
    break;
case 2:
case 3:
    book_apartment(group_size);
    break;
default:
    book_house(group_size);
}
// book_apartment happens wheng roup_size is 2 or 3
```

~~~~exercism/note
Wie du gesehen hast, ist die `switch`-Anweisung in C++ im Vergleich zu anderen Sprachen sehr eingeschränkt.
Viele Sprachen können Switches auf Basis von booleschen Ausdrücken oder sogar regulären Ausdrücken ausführen.
Du kannst dir die C++-Version als ein erweitertes goto/switch-Konstrukt vorstellen.
Nur die `switch`-Anweisung kann zu einem Label springen.
Danach werden alle anderen Labels ignoriert, und du musst die `break`-Anweisung verwenden, um aus dem Block auszubrechen.
~~~~
