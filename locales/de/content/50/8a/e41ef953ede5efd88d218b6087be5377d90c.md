# Über

Java ist eine statisch typisierte Sprache. Das bedeutet, dass zur Compile-Zeit alles einen Typ hat.
Einem Namen einen Wert zuzuweisen, nennt man das Definieren einer Variablen.

```java
int explicitVar = 10; // Explicitly typed
```

Der Wert einer Variablen kann mit dem [`=`-Operator][assignment] zugewiesen und aktualisiert werden.
Sobald eine Variable definiert ist, kann sich ihr Typ nie mehr ändern.

```java
int count = 1; // Assign initial value
count = 2;     // Update to new value

// Compiler error when assigning different type
// count = false;
```

Java ist eine objektorientierte Sprache und verlangt, dass alle Funktionen in einer _Klasse_ definiert werden. Klassen werden mit dem [`class`-Schlüsselwort][classes] definiert.
Eine Funktion innerhalb einer Klasse wird als _Methode_ bezeichnet.
Jede [Methode][methods] kann null oder mehr Parameter haben.
Alle Parameter müssen explizit typisiert werden, für Parameter gibt es keine Typinferenz.
Ebenso muss auch der Rückgabetyp explizit angegeben werden.
Werte werden mit dem [`return`-Schlüsselwort][return] aus Funktionen zurückgegeben.
Damit eine Methode von anderen Klassen aufgerufen werden kann, muss der Zugriffsmodifikator `public` hinzugefügt werden.

```java
class Calculator {
    public int add(int x, int y) {
        return x + y;
    }
}
```

Eine Methode rufst du auf, indem du ihre Klasse und ihren Methodennamen angibst und für jeden Parameter der Methode ein Argument übergibst.

```java
int sum = new Calculator().add(1, 2);
```

Wenn eine Methode keinen _Zustand_ der Klasse verwendet (was in dieser Übung der Fall ist), kannst du die Methode mit dem `static`-Modifikator _statisch_ machen.
Wenn eine Klasse nur statische Methoden hat, kannst du ebenso auch sie mit dem `static`-Modifikator statisch machen.

```java
static class Calculator {
    public static int multiply(int x, int y) {
        return x * y;
    }
}
```

Der Gültigkeitsbereich wird in Java zwischen den Zeichen `{` und `}` definiert.

Java unterstützt zwei Arten von [Kommentaren][comments].
Einzeilige Kommentare werden mit `//` eingeleitet, mehrzeilige Kommentare zwischen `/*` und `*/` eingefügt.

Ganzzahlwerte werden als eine oder mehrere (aufeinanderfolgende) Ziffern definiert und unterstützen die [üblichen mathematischen Operatoren][operators].
