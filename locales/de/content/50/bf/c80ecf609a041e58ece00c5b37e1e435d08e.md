# Überblick

Variablen, die mit dem Schlüsselwort `final` statt mit `var` deklariert werden, können nur einmal einen Wert erhalten.

```haxe
final a = "hello";
var b = "world";
trace(a, b); // hello, world
b = "haxe";
trace(a, b); // hello, haxe

// The following line would cause a compilation error:
// a = "bye";
```

Es ist wichtig zu beachten, dass `final` bei nicht unveränderlichen Typen wie Arrays oder Objekten möglicherweise nicht die beabsichtigte Wirkung hat:

```haxe
final a = [0, 1, 2];
trace(a); // [0,1,2]

// this would cause a compilation error:
// a = [0, 1, 2, 3];

// but the following line works:
a.push(3);
trace(a); // [0,1,2,3]
```
