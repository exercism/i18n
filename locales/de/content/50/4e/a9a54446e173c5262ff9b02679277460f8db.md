# Anleitung

In dieser Übung spielst du mit deinen besten Freunden ein Rollenspiel namens „Wizard and Warriors“. Du bist der Spielleiter, also die Person, die die Spielwelt für die Spieler zum Leben erweckt. Ein wichtiger Aspekt dabei ist, das Spiel für die Spieler zu beschreiben: Wie ist der Status eines Charakters, wie sieht die Stadt aus, die sie gerade besuchen, und so weiter.

Du hast fünf Aufgaben, in denen du den Spielern Teile des Spiels beschreibst.

## 1. Beschreibe einen Charakter

Jeder Charakter hat eine Klasse, eine Stufe und eine Anzahl Trefferpunkte und wird so beschrieben: `"You're a level <LEVEL> <CLASS> with <HIT_POINTS> hit points."`. Implementiere die (statische) Methode `GameMaster.Describe`, die einen `Character` als einzigen Parameter nimmt und dessen Beschreibung zurückgibt.

```csharp
var character = new Character();
character.Class = "Wizard";
character.Level = 4;
character.HitPoints = 28;

GameMaster.Describe(character);
// => "You're a level 4 Wizard with 28 hit points."
```

## 2. Beschreibe ein Reiseziel

Jedes Reiseziel hat einen Namen und eine Anzahl Einwohner und wird so beschrieben: `"You've arrived at <NAME>, which has <INHABITANTS> inhabitants."`. Implementiere die (statische) Methode `GameMaster.Describe`, die ein `Destination` als einzigen Parameter nimmt und dessen Beschreibung zurückgibt.

```csharp
var destination = new Destination();
destination.Name = "Muros";
destination.Inhabitants = 732;

GameMaster.Describe(destination);
// => "You've arrived at Muros, which has 732 inhabitants."
```

## 3. Beschreibe die Reisemethode

Charaktere können auf zwei Arten zu einem Reiseziel reisen:

- Zu Fuß, beschrieben als: `"You're traveling to your destination by walking."`
- Zu Pferd, beschrieben als: `"You're traveling to your destination on horseback."`

Implementiere die (statische) Methode `GameMaster.Describe`, die einen `TravelMethod` als einzigen Parameter nimmt und dessen Beschreibung zurückgibt.

```csharp
GameMaster.Describe(TravelMethod.Horseback);
// => "You're traveling to your destination on horseback."
```

## 4. Beschreibe einen Charakter, der zu einem Reiseziel reist

Wenn ein Charakter zu einem Reiseziel reist, wird das als Kombination der einzelnen Beschreibungen dargestellt: `"<CHARACTER> <TRAVEL_METHOD> <DESTINATION>"`. Implementiere die (statische) Methode `GameMaster.Describe`, die einen `Character`, ein `Destination` und einen `TravelMethod` als Parameter nimmt und dessen Beschreibung zurückgibt.

```csharp
var character = new Character();
character.Class = "Wizard";
character.Level = 4;
character.HitPoints = 28;

var destination = new Destination();
destination.Name = "Muros";
destination.Inhabitants = 732;

GameMaster.Describe(character, destination, TravelMethod.Horseback);
// => "You're a level 4 Wizard with 28 hit points. You're traveling to your destination on horseback. You've arrived at Muros, which has 732 inhabitants."
```

## 5. Beschreibe einen Charakter, der zu einem Reiseziel reist, ohne die Reisemethode anzugeben

In der Mehrheit der Fälle reisen Charaktere zu Fuß zu einem Reiseziel. Der Einfachheit halber dürfen Spieler ihre Reisemethode weglassen. In diesem Fall wird angenommen, dass sie zu Fuß unterwegs sind. Implementiere die (statische) Methode `GameMaster.Describe`, die einen `Character` und ein `Destination` als Parameter nimmt und dessen Beschreibung zurückgibt.

```csharp
var character = new Character();
character.Class = "Wizard";
character.Level = 4;
character.HitPoints = 28;

var destination = new Destination();
destination.Name = "Muros";
destination.Inhabitants = 732;

GameMaster.Describe(character, destination);
// => "You're a level 4 Wizard with 28 hit points. You're traveling to your destination by walking. You've arrived at Muros, which has 732 inhabitants."
```
