# Hinweise

## Allgemein

- Das Paket [`roc-isodate`](https://github.com/ageron/roc-isodate) steht im Header von `meetup-test.roc` zur Verfügung (mit dem Alias `isodate`).
  Dieses Paket ist ein (vorübergehender) Fork von [dem Paket von @imclerran](https://github.com/imclerran/roc-isodate).
  Du kannst es in deiner Lösung verwenden, wenn du möchtest, zum Beispiel indem du `isodate.Date` importierst.
