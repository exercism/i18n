# Anleitung

In dieser Übung implementierst du einen Teil einer Sammlung von Hilfsroutinen, die einem Entwickler dabei helfen, Bezeichnernamen aufzuräumen.

In den 6 Aufgaben baust du nach und nach die Funktionen `transform` zum Umwandeln einzelner Zeichen und `clean` zum Umwandeln von Strings auf.

Ein gültiger Bezeichner besteht aus null oder mehr Buchstaben, Unterstrichen, Bindestrichen, Fragezeichen und Emojis.

Wenn der `clean`-Funktion ein leerer String übergeben wird, soll ein leerer String zurückgegeben werden.

## 1. Ersetze alle vorkommenden Bindestriche durch Unterstriche

Implementiere die `transform`-Funktion, um alle Bindestriche durch Unterstriche zu ersetzen.

```julia
julia> transform('-')
"_"
```

## 2. Entferne alle Whitespace-Zeichen

Entferne alle Whitespace-Zeichen.
Dazu gehören auch führende und abschließende Whitespace-Zeichen.

```julia
julia> transform(' ')
""
```

## 3. Wandle camelCase in kebab-case um

Ändere die `transform`-Funktion so, dass sie camelCase in kebab-case umwandelt.

```julia
julia> transform('D')
"-d"
```

## 4. Lass Zeichen weg, die Ziffern sind

Ändere die `transform`-Funktion so, dass sie alle Zeichen weglässt, die numerisch sind.

```julia
julia> transform('7')
""
```

## 5. Ersetze griechische Kleinbuchstaben durch Fragezeichen

Ändere die `transform`-Funktion so, dass sie alle griechischen Buchstaben im Bereich 'α' bis 'ω' ersetzt.

```julia
julia> transform('β')
"?"
```

## 6. Kombiniere diese Operationen, um einen String zu bearbeiten

Implementiere die `clean`-Funktion, um diese Operationen auf einen gesamten String anzuwenden.

Zeichen, die nicht unter diese Regeln fallen, sollen unverändert durchgeleitet werden.

```julia
julia> clean("  a2b Cd-ω😀  ")
"ab-cd_?😀"
```
