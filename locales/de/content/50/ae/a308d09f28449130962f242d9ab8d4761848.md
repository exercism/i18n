# Über

Locals ersetzen keinen Stack-Code. Sie existieren daneben. Nutze sie, wenn:

- Derselbe Eingabewert mehr als einmal referenziert wird.
- Die natürliche Reihenfolge der Operationen nicht der Reihenfolge auf dem Stack entspricht.
- Du dich in einem Wort höherer Ordnung befindest, das dem Lambda mehrere Werte auf einmal übergibt (`( key value -- newkey newvalue )` von `assoc-map`).

```factor
USING: locals ;

! Two references to ratio: stack-shuffled vs. local.
: average  ( a b -- avg ) + 2 / ;
:: average ( a b -- avg ) a b + 2 / ;        ! same effect
```

`[let code :> name code :> name ... body ]` führt lokale Bindungen innerhalb einer Quotation oder am Listener ein, wo `:>` sonst keinen lexikalischen Gültigkeitsbereich hätte, an den es binden könnte:

```factor
[let 5 :> x 10 :> y x y + ] .   ! => 15
```

Mit dem Mutations-Suffix `:>` kannst du ein Local neu binden. Das ist nützlich in Schleifen, die sich imperativ anfühlen:

```factor
:: collatz ( n -- count )
    n :> current!
    0 :> count!
    [ current 1 = ] [
        current odd?
        [ current 3 * 1 + current! ]
        [ current 2 / current! ] if
        count 1 + count!
    ] until
    count ;
```
