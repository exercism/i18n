# Einführung

In Java wird das Literal `null` verwendet, um das Fehlen eines Werts auszudrücken.

Primitive Datentypen in Java haben alle einen Standardwert und können daher niemals `null` sein.
Konventionell beginnen sie mit einem Kleinbuchstaben, z. B. `int`.

Referenztypen enthalten die Speicheradresse eines Objekts und können den Wert `null` haben.
Sie beginnen in der Regel mit einem Großbuchstaben, z. B. `String`.

Wenn du versuchst, einer primitiven Variablen den Wert `null` zuzuweisen, führt das zu einem Kompilierfehler, denn die Variable hält immer einen primitiven Wert des zugewiesenen Typs.

```java
//Throws compile time error stating the required type is int, but null was provided
int number = null;
```

Wenn du einer Referenzvariablen den Wert `null` zuweist, entsteht kein Kompilierfehler, denn Referenzvariablen können `null` sein.

```java
//No error will occur as the String variable str is nullable
String str = null;
```
