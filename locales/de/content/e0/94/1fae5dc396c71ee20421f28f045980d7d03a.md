# Installation

Die Installationsanweisungen findest du im [`jq`-Wiki][jq-wiki-install].

## Versionsinformationen

Stand Juni 2025 ist die aktuelle jq-Version **1.8**.
Diese Version wird im Online-Test-Runner für jq verwendet.

Viele Linux-Paketmanager installieren eine ältere Version, nämlich 1.6.
Du solltest manuell eine neuere Version installieren, denn seit der Veröffentlichung von v1.6 im Jahr 2018 gab es viele nützliche Änderungen.

[jq-wiki-install]: https://github.com/jqlang/jq/wiki/Installation
