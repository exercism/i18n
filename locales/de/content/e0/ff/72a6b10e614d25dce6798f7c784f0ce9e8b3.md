# Einführung

Eine `for`-Schleife ermöglicht es, Code so lange wiederholt in einer Schleife auszuführen, bis eine Bedingung erfüllt ist.

```csharp
for (int i = 0; i < 5; i++)
{
    System.Console.Write(i);
}

// => 01234
```

Eine `for`-Schleife besteht aus vier Teilen:

1. Der Initialisierer: wird einmal vor dem Betreten der Schleife ausgeführt. Wird normalerweise verwendet, um Variablen zu definieren, die innerhalb der Schleife verwendet werden.
2. Die Bedingung: wird vor jeder Iteration der Schleife ausgeführt. Die Schleife wird weiter ausgeführt, solange diese `true` ergibt.
3. Der Iterator: wird nach jeder Iteration der Schleife ausgeführt. Wird normalerweise verwendet, um die Schleifenvariable(n) zu ändern (oft: zu erhöhen oder zu verringern).
4. Der Schleifenblock: der Code, der bei jeder Iteration der Schleife ausgeführt wird.
