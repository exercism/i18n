# Anhang zu den Anweisungen

## Track-spezifische Anweisungen

In dieser Übung erhält dein Verb zwei Argumente:

- **Linkes Argument**: Eine Liste von Ganzzahlen, die die Menge der gesammelten magischen Gegenstände darstellt.
- **Rechtes Argument**: Eine Ganzzahl, die das abgeschlossene Level darstellt.

Dein Verb sollte so definiert werden, dass es diese Eingabewerte wie folgt verarbeitet:

```j
  factors =. 3 5
  limit   =. 20
  
  multiplesList sum upperLimit
```
