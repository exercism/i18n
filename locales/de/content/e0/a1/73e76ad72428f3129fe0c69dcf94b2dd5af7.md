# Überblick

Das grundlegende objektorientierte Konstrukt in Java ist die _Klasse_. Sie kombiniert Daten ([_Felder_][fields]), auch Instanzvariablen genannt, mit Verhalten ([_Methoden_][methods]).
Die Felder und Methoden einer Klasse bezeichnet man als ihre _Mitglieder_.

Der Zugriff auf Mitglieder lässt sich über Zugriffsmodifizierer steuern. Die zwei häufigsten sind:

- [`public`][public]: Auf das Mitglied kann jeder Code zugreifen (keine Einschränkungen).
- [`private`][private]: Auf das Mitglied kann nur Code in derselben Klasse zugreifen.

Wenn in Java kein Zugriffsmodifizierer angegeben wird, gilt standardmäßig die _Paketsichtbarkeit_.
Dann ist das Mitglied für alle Klassen sichtbar, die im selben Paket definiert sind.

Dieses Zusammenfassen zusammengehöriger Daten und Verhaltensweisen und das Einschränken des Zugriffs auf Mitglieder nennt man [_Kapselung_][encapsulation]. Sie ist eines der Kernkonzepte der Objektorientierung.

Du kannst dir eine Klasse als Vorlage für das Erzeugen von Instanzen dieser Klasse vorstellen.
Um [eine Instanz einer Klasse zu erzeugen][creating-objects] (auch _Objekt_ genannt), verwendest du das [`new`-Schlüsselwort][new]:

```java
class Car {
}

// Create two car instances
Car myCar = new Car();
Car yourCar = new Car();
```

[Felder][fields] haben einen Typ und einen Namen (in [camelCase][camel-case] geschrieben) und können überall in einer Klasse definiert werden (in [PascalCase][pascal-case] geschrieben).

```java
class Car {
    // Accessible by anyone
    public int weight;

    // Only accessible by code in this class
    private String color;
}
```

Du kannst einem Feld optional einen Anfangswert zuweisen.
Wenn ein Feld _keinen_ Anfangswert angibt, wird es auf den [Standardwert][default-values] seines Typs gesetzt.
Die Feldwerte einer Instanz kannst du mit der Punktnotation lesen und ändern.

```java
class Car {
    // Will be set to specified value
    public int weight = 2500;

    // Will be set to default value (0)
    public int year;
}

Car newCar = new Car();
newCar.weight; // => 2500
newCar.year;   // => 0

// Update value of the field
newCar.year = 2018;
```

Private Felder werden meist als Nebeneffekt eines Methodenaufrufs aktualisiert.
Solche Methoden geben üblicherweise keinen Wert zurück; in diesem Fall sollte der Rückgabetyp [`void`][void] sein:

```java
class CarImporter {
    private int carsImported;

    public void importCars(int numberOfCars)
    {
        // Update private field
        carsImported = carsImported + numberOfCars;
    }
}
```

Beachte, dass es in Java-Klassen unüblich ist, öffentliche Felder zu verwenden.
Üblicherweise nutzt man private Felder, auf die man über [_Getter_ und _Setter_][so-getters-setters] zugreift.

Innerhalb einer Klasse verweist das [`this`-Schlüsselwort][this] auf die aktuelle Klasse.
Das ist besonders nützlich, wenn ein Parameter denselben Namen wie ein Feld hat:

```java
class CarImporter {
    private int carsImported;

    public void setImportedCars(int carsImported)
    {
        // Update private field from public method
        this.carsImported = carsImported;
    }
}
```
