# Beispiel

```riscvasm
.equ FRAME_SIZE, 16

.text
.global is_triple
```

Zeilen, die mit einem Punkt beginnen, sind _Direktiven_: Anweisungen für den Assembler, nicht für den Prozessor.
`.equ` gibt der Zahl 16 den Namen `FRAME_SIZE`.
`.text` sagt, dass das Folgende Code ist.
`.global` macht das Label `is_triple` außerhalb dieser Datei sichtbar, sodass anderer Code es aufrufen kann.
Du siehst vielleicht auch `.globl`, was dasselbe bedeutet.

```riscvasm
/* bool is_triple(unsigned a, unsigned b, unsigned c); */
is_triple:
```

`is_triple` prüft, ob `a² + b² = c²` gilt, und gibt 1 zurück, wenn das zutrifft, sonst 0.
Zum Beispiel ergibt `(6, 8, 10)` den Wert 1, weil `36 + 64 = 100`.
Das Label `is_triple` markiert, wo die Funktion beginnt.
Sie wird mit `a`, `b` und `c` in den Registern `a0`, `a1` und `a2` aufgerufen.

```riscvasm
        addi    sp, sp, -FRAME_SIZE
        sw      ra, 12(sp)      /* save the return address */
        sw      a1, 8(sp)       /* save b */
        sw      a2, 4(sp)       /* save c */
```

Das Register `ra` enthält die _Rücksprungadresse_, also die Stelle im Aufrufer, zu der wir zurückkehren, wenn wir fertig sind.
Jeder `call` überschreibt `ra`, deshalb sichern wir sie zuerst auf dem _Stack_.
Der Stack wächst nach unten, zu kleineren Adressen hin. Deshalb reservieren wir 16 Bytes für uns, indem wir 16 vom Stackpointer `sp` subtrahieren.
(`sp` muss immer ein Vielfaches von 16 sein.)
Wir sichern auch `b` und `c`, weil eine Funktion, die wir aufrufen, die `a`-Register ändern darf.

```riscvasm
        call    square          /* a0 = a * a */
        sw      a0, 0(sp)       /* save a * a */
```

`a` steht bereits in `a0`, wo `square` seinen Eingabewert erwartet.
`call` setzt `ra` auf die nächste Anweisung und springt zu `square`, das sein Ergebnis in `a0` zurückgibt.

```riscvasm
        lw      a0, 8(sp)       /* a0 = b */
        call    square          /* a0 = b * b */
        lw      t0, 0(sp)       /* t0 = a * a */
        add     t0, t0, a0      /* t0 = a * a + b * b */
        sw      t0, 0(sp)       /* save a * a + b * b */
```

Wir laden `b` wieder vom Stack, quadrieren es und addieren es zu `a * a`.

```riscvasm
        lw      a0, 4(sp)       /* a0 = c */
        call    square          /* a0 = c * c */
        lw      t0, 0(sp)       /* t0 = a * a + b * b */
        sub     a0, t0, a0      /* a0 = a * a + b * b - c * c */
        seqz    a0, a0          /* a0 = 1 if that is zero, otherwise 0 */
```

Die Differenz ist genau dann null, wenn `a² + b² = c²` gilt.
`seqz` („set if equal to zero“) macht daraus 1 oder 0.

```riscvasm
        lw      ra, 12(sp)      /* restore the return address */
        addi    sp, sp, FRAME_SIZE
        ret
```

Wir stellen `ra` wieder her und geben die 16 Bytes Stack zurück.
`ret` springt dann zur Adresse in `ra`, zurück zum Aufrufer.

```riscvasm
/* unsigned square(unsigned n); */
square:
        mul     a0, a0, a0      /* n * n */
        ret
```

`square` ruft keine andere Funktion auf, also bleibt `ra` unversehrt und es gibt nichts zu sichern.
Es ist nicht als `.global` markiert, weil nur `is_triple` es verwendet.
