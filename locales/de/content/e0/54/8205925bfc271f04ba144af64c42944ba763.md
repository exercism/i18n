# Hinweise zu Klammern

Tcl ist eine [sehr einfache Sprache](https://tcl.tk/man/tcl8.6/TclCmd/Tcl.htm), aber die Art und Weise, wie der Interpreter Code parst, hat ein paar unangenehme Randfälle.

## Geschweifte Klammern

Geschweifte Klammern sind in Tcl einfach eine Möglichkeit, einen Textblock zusammenzufassen. Dieser Text kann als Code oder als Daten interpretiert werden. Innerhalb geschweifter Klammern dürfen verschachtelte Klammern vorkommen, aber die verschachtelten Klammern müssen ausbalanciert sein. In der Tcl-Manpage steht dazu:

> Klammern verschachteln sich innerhalb des Wortes: für jede zusätzliche öffnende Klammer muss es eine zusätzliche schließende Klammer geben (wenn jedoch eine öffnende oder schließende Klammer innerhalb des Wortes _mit einem Backslash maskiert_ ist, wird sie beim Auffinden der passenden schließenden Klammer nicht gezählt).

Die Formulierung dort ist recht genau: Wenn du ein nicht zugeordnetes öffnendes oder schließendes Klammerzeichen haben willst, muss es mit einem Backslash maskiert werden. Also mach das hier nicht:
```tcl
proc isOpenBrace {char} {
    return [expr {$char eq "{"}]
    # ......................^ will not work
}
```
So musst du es machen:
```tcl
proc isOpenBrace {char} {
    return [expr {$char eq "\{"}]
    # ......................^^ will work
}
```

Das kann in Verbindung mit der Art und Weise, wie Tcl Kommentare parst, problematisch sein, denn das unterscheidet sich von den meisten Sprachen. Mehr dazu steht im [Tcl-Wiki](https://wiki.tcl-lang.org/page/Why+can+I+not+place+unmatched+braces+in+Tcl+comments).

## Eckige Klammern

Ebenso: Da Tcl eckige Klammern für die [Befehlssubstitution.](https://tcl.tk/man/tcl8.6/TclCmd/Tcl.htm#M11) verwendet, sogar innerhalb von Zeichenketten in doppelten Anführungszeichen, musst du beim Maskieren öffnender Klammern aufpassen.

## Runde Klammern

Mit Ausnahme von [assoziativen Array-Variablen](https://tcl.tk/man/tcl8.6/TclCmd/Tcl.htm#M12) sind runde Klammern einfach gewöhnliche Zeichen.
