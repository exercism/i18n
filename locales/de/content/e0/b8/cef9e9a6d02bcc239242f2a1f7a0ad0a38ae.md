# Hinweise

## Allgemein

- Die ersten sechs Ganzzahlargumente werden in `rdi`, `rsi`, `rdx`, `rcx`, `r8` und `r9` an eine Funktion übergeben.
- Adressen im Speicher sind 64-Bit-Werte (8 Bytes).

## 1. Erstelle einen Eintrag für jeden Gegenstand

- Die ersten sechs Ganzzahlargumente werden in `rdi`, `rsi`, `rdx`, `rcx`, `r8` und `r9` an eine Funktion übergeben.
- Adressen im Speicher sind 64-Bit-Werte (8 Bytes).
- Alle Ganzzahlargumente nach dem sechsten werden auf dem Stack übergeben, wobei das erste in `rsp + 8` liegt.
- Die Anzahl der zusätzlichen Argumente entspricht der Anzahl der Kategorien, die in `r9` übergeben wird.
- Du kannst in einer Schleife die zusätzlichen Argumente einzeln hinzufügen oder [movsq][movs] zusammen mit [rep][rep] verwenden.

## 2. Reserviere Speicher für eine monatliche Liste von Gegenständen

- Die ersten sechs Ganzzahlargumente werden in `rdi`, `rsi`, `rdx`, `rcx`, `r8` und `r9` an eine Funktion übergeben.
- Adressen im Speicher sind 64-Bit-Werte (8 Bytes).
- Du musst die Größe des Arrays kennen, um nach dem Aufruf der allokierenden Funktion seine Bytes zu löschen.
- Wenn du eine externe Funktion aufrufst, kann sie den Wert in jedem _caller-saved_ Register verändern.
- Du kannst den Wert eines Registers auf dem Stack bewahren, indem du [push][push] verwendest oder `rsp` direkt manipulierst.
- Jede Änderung an `rsp`, auch durch `push`, muss vor der Rückkehr der Funktion rückgängig gemacht werden, entweder mit [pop][pop] oder indem du `rsp` direkt änderst.

## 3. Füge einen Gegenstand in die monatliche Liste ein

- Die ersten sechs Ganzzahlargumente werden in `rdi`, `rsi`, `rdx`, `rcx`, `r8` und `r9` an eine Funktion übergeben.
- Adressen im Speicher sind 64-Bit-Werte (8 Bytes).
- Ein Wert, der nicht in ein Register passt, wird an eine Funktion auf dem Stack übergeben.
- Jeder Eintrag für einen Gegenstand belegt 120 Bytes, was viel größer ist als die maximale Größe eines Registers (8 Bytes).
- Auf dem Stack übergebene Argumente findest du an Adressen ab `rsp + 8`.
- Du kannst in einer Schleife die Werte an die Speicherstelle im Ziel hinzufügen oder [movsb][movs] zusammen mit [rep][rep] verwenden.

## 4. Gib einen Gegenstand aus

- Die ersten sechs Ganzzahlargumente werden in `rdi`, `rsi`, `rdx`, `rcx`, `r8` und `r9` an eine Funktion übergeben.
- Adressen im Speicher sind 64-Bit-Werte (8 Bytes).
- Der einleitende String ist optional; du kannst die Ausgabefunktion stattdessen mit `0` aufrufen.
- Wenn der einleitende String an die Ausgabefunktion übergeben wird, darf er höchstens 50 ASCII-Zeichen enthalten, wobei der NUL-Terminator (Wert `0`) bereits mitgezählt wird.
- Immer wenn du eine Funktion aufrufst, musst du auf dem Stack Platz für jedes Argument nach dem sechsten reservieren.
- Die System V ABI schreibt vor, dass der Stack vor dem Aufruf einer Funktion 16-Byte-ausgerichtet sein sollte, was besonders für externe Funktionen wichtig ist.
- Jeder Eintrag für einen Gegenstand in der Liste belegt 120 Bytes.
