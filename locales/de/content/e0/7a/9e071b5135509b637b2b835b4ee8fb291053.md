# Anleitung

In dieser Übung überprüfst du die Berechtigungen von Benutzerkonten in einem Internetforum. Das Forum unterstützt drei verschiedene Berechtigungen:

- Read
- Write
- Delete

Es gibt drei Arten von Konten, jede mit anderen Standardberechtigungen:

- Gäste: können Beiträge lesen.
- Benutzer: können Beiträge lesen und schreiben.
- Moderatoren: können Beiträge lesen, schreiben und löschen, sie haben alle Berechtigungen.

Manchmal können einzelne Berechtigungen geändert werden. So ist es zum Beispiel möglich, einem Gastkonto die Berechtigung zum Schreiben von Beiträgen zu geben, oder einem Konto alle Berechtigungen zu entziehen, sodass es keine der Berechtigungen mehr hat.

## 1. Standardberechtigungen für einen Kontotyp ermitteln

Definiere zuerst ein `AccountType`-Enum, das die drei Kontotypen repräsentiert: `Guest`, `User` und `Moderator`.

Definiere als Nächstes ein `Permission`-Enum, das die drei Berechtigungstypen repräsentiert: `Read`, `Write`, `Delete`, und zwei zusätzliche: `All` für alle Berechtigungen und `None` für keine der Berechtigungen.

Implementiere dann die (_statische_) Methode `Permissions.Default()`, die die Standardberechtigungen für einen bestimmten Kontotyp zurückgibt:

```csharp
Permissions.Default(AccountType.Guest)
// => Permission.Read
```

## 2. Eine Berechtigung erteilen

Implementiere die (_statische_) Methode `Permissions.Grant()`, die eine Berechtigung erteilt (hinzufügt):

```csharp
Permissions.Grant(current: Permission.None, grant: Permission.Read)
// => Permission.Read
```

## 3. Eine Berechtigung entziehen

Implementiere die (_statische_) Methode `Permissions.Revoke()`, die eine Berechtigung entzieht (entfernt):

```csharp
Permissions.Revoke(current: Permission.Read, revoke: Permission.Read)
// => Permission.None
```

## 4. Eine Berechtigung überprüfen

Implementiere die (_statische_) Methode `Permissions.Check()`, die die aktuellen Berechtigungen des Kontos entgegennimmt und überprüft, ob das Konto für eine bestimmte Berechtigung autorisiert ist:

```csharp
Permissions.Check(current: Permission.Write, check: Permission.Read)
// => false
```
