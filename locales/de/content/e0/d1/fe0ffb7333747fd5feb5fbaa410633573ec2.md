## 1. Kritikalität prüfen

- Vergleichsoperatoren ([Vergleiche][comparisons review]) und Boolesche Operationen ([concept:python/bools]()) lassen sich kombinieren und zusammen mit Bedingungen verwenden.
- Bedingte Ausdrücke müssen zu `True` oder `False` ausgewertet werden.
- Mit `else` gibst du einen Block an, der ausgeführt wird, wenn alle Bedingungstests `False` zurückgeben.

  ```python
     >>> item = 'blue'
     >>> item_2 = 'green'
     
     >>>  if len(item) >= 3 and len(item_2) < 5:
            print('Both pass the test!')
          elif len(item) >= 3 or len(item_2) < 5:
            print('One passes the test!')
          else:
            print('None pass the test!')
    ...
    One passes the test!
  ```

## 2. Den Bereich der Leistungsabgabe bestimmen

- Vergleichsoperatoren lassen sich kombinieren und zusammen mit Bedingungen verwenden.
- Beliebig viele `elif`-Anweisungen können als Entscheidungszweige genutzt werden.
- Jeder Zweig kann ein eigenes `return` haben, obwohl Linting-Tools das als „schlechten Stil“ ansehen könnten.
- Wenn der Linter sich beschwert, kannst du die Ausgabe eines Zweigs einer gemeinsamen Variable zuweisen und diese Variable dann mit `return` zurückgeben.
