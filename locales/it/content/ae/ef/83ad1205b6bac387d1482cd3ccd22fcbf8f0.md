# Istruzioni

In questo esercizio, gestirai un sistema di inventario.

L'inventario dovrebbe essere organizzato per nome dell'articolo e dovrebbe tenere traccia del numero di articoli disponibili.

Dovrai gestire l'aggiunta di articoli a un inventario.
Ogni volta che un articolo compare in un dato vettore, la quantità di quell'articolo nell'inventario va aumentata di `1`.
Dovrai anche gestire l'eliminazione di articoli da un inventario, diminuendo le quantità di `1` quando richiesto.

Infine, dovrai implementare una funzione che restituisca tutte le coppie chiave-valore in un dato inventario come un `vector` di `pair`.

~~~~exercism/note
I test in questo esercizio sono agnostici rispetto alla mutazione, ma i nomi delle funzioni indicano che queste dovrebbero essere non mutanti.
Se vuoi usare le funzioni dell'introduzione senza mutare l'input, la funzione `copy()` ti sarà utile.
~~~~

## 1. Crea un inventario basato su un vettore

Implementa la funzione `create_inventory(<input vector>)` che crea un «inventario» da un vettore di input di articoli.
Dovrebbe restituire un `dict` che associa ogni nome di articolo alla rispettiva quantità.

```julia-repl
julia> create_inventory(["coal", "wood", "wood", "diamond", "diamond", "diamond"])
Dict("coal" => 1, "wood" => 2, "diamond" => 3)
```

## 2. Aggiungi articoli da un vettore a un dizionario esistente

Implementa la funzione `add_items(<inventory dict>, <item vector>)` che aggiunge un vettore di articoli all'inventario passato:

```julia-repl
julia> add_items(Dict("coal" => 1), ["wood", "iron", "coal", "wood"])
Dict("coal" => 2, "wood" => 2, "iron" => 1)
```

## 3. Diminuisci gli articoli dall'inventario

Implementa la funzione `decrement_items(<inventory dict>, <items vector>)` che prende un `vector` di articoli.
La funzione dovrebbe sottrarre `1` al conteggio di un articolo per ogni volta che quell'articolo compare nel `vector`:

```julia-repl
julia> decrement_items(Dict("coal" => 3, "diamond" => 1, "iron" => 5), ["diamond", "coal", "iron", "iron"])
Dict("coal" => 2, "diamond" => 0, "iron" => 3)
```

I conteggi degli articoli nell'inventario non devono poter scendere sotto 0.
Se il numero di volte in cui un articolo compare nel `vector` di input supera il conteggio disponibile, la quantità indicata per quell'articolo deve rimanere a 0.
Le richieste aggiuntive di rimozione di conteggi devono essere ignorate una volta che il conteggio scende a zero.

```julia-repl
julia> decrement_items(Dict("coal" => 2, "wood" => 1, "diamond" => 2), ["coal", "coal", "wood", "wood", "diamond"])
Dict("coal" => 0, "wood" => 0, "diamond" => 1)
```

## 4. Rimuovi completamente una voce dall'inventario

Implementa la funzione `remove_item(<inventory dict>, <item>)` che rimuove completamente un articolo e il suo conteggio da un inventario:

```julia-repl
julia> remove_item!(Dict("coal" => 2, "wood" => 1, "diamond" => 2), "coal")
Dict("wood" => 1, "diamond" => 2)
```

Se l'articolo non viene trovato nell'inventario, la funzione dovrebbe restituire l'inventario originale invariato.

```julia-repl
julia> remove_item(Dict("coal" => 2, "wood" => 1, "diamond" => 2), "gold")
Dict("coal" => 2, "wood" => 1, "diamond" => 2)
```

## 5. Restituisci l'intero contenuto dell'inventario

Implementa la funzione `list_inventory(<inventory dict>)` che prende un inventario e restituisce un vettore di coppie `(item, quantity)`.

Il vettore deve includere solo gli articoli _disponibili_ (_con una quantità maggiore di zero_) e deve essere ordinato in ordine alfabetico per articolo:

```julia-repl
julia> list_inventory(Dict("coal" => 7, "wood" => 11, "diamond" => 2, "iron" => 7, "silver" => 0))
["coal" => 7, "diamond" => 2, "iron" => 7, "wood" => 11]
```
