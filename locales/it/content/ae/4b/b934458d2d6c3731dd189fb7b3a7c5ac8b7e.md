# Introduzione

Le strutture condizionali in C++ sono simili a quelle di altri linguaggi.
Il tipo sottostante di qualsiasi operazione condizionale è il tipo `bool`, che può avere il valore `true` o `false`.
Le strutture condizionali sono spesso usate come meccanismi di controllo del flusso per verificare varie condizioni.

Si può usare un'istruzione `if`, che esegue il suo codice se la condizione sottostante è `true`, in questo modo:

```cpp
std::string value{"val"};

if (value == "val") {
    return "was val";
}
```

Quando una situazione prevede più di un caso, si possono concatenare più istruzioni `if` usando le istruzioni `else if` ed `else`.

```cpp
int number{33};

if (number > 0) {
   return "positive";
} else if (number < 0) {
    return "negative";
} else {
   return "zero";
}
```

Dal C++17, le istruzioni if possono includere anche una breve istruzione di inizializzazione, che può servire a inizializzare una o più variabili per l'istruzione if.
Per esempio:

```cpp
int num{7};
if (int v{2 * num}; v > 10) {
    return v;
} else {
    return num;
}
// => 14
```

> Nota: le variabili create nell'inizializzazione non sono accessibili dopo la fine dell'istruzione if.
