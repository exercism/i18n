[I booleani][booleans] in Haxe sono rappresentati dal tipo `Bool`, i cui valori possono essere `true` o `false`.

Haxe supporta tre [operatori booleani][operators]: `!` (NOT unario), `&&` (AND binario) e `||` (OR binario).

Le espressioni booleane composte (`&&` e `||`) usano la valutazione _short-circuit_, in cui le espressioni vengono valutate da sinistra a destra ma solo per quanto necessario. Questo è importante in casi come il seguente:

```haxe
object != null && object.field == x
```

Il primo controllo booleano garantisce che si acceda a `object.field` solo se `object` non è `null`, evitando un errore a runtime.

I tre operatori booleani hanno una [precedenza][precedence] diversa e vengono valutati in questo ordine: `!` -> `&&` -> `||`.

Racchiudere le espressioni tra parentesi tonde (`()`) permette di sovrascrivere queste regole di precedenza, dato che le parentesi hanno una precedenza maggiore.

```haxe
!true && false   // => false
!(true && false) // => true
```
