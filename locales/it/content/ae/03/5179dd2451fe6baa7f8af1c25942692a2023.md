# Introduzione

In Haxe, gli iteratori si usano per iterare su un valore con un ciclo `for`. Esistono due tipi di iteratori:

- `Iterator`, che itera su un valore.
- dati di tipo `Iterable`, che permettono di iterare su un tipo di dato.

Entrambi questi concetti sono rappresentati da `Iterator<T>` e `Iterable<T>`:

```haxe
typedef Iterator<T> = {
  function hasNext():Bool;
  function next():T;
}

typedef Iterable<T> = {
  function iterator():Iterator<T>;
}
```

Qualsiasi classe che unifica con uno di questi tipi può essere iterata con un ciclo `for`. Se una classe definisce i metodi `hasNext` e `next`, è considerata un iteratore; se invece definisce un metodo `iterator`, è considerata un tipo iterabile.
