# Installazione

## Prerequisiti

Il percorso C++ richiede che sul tuo sistema sia installato il seguente software:
* un compilatore C++14 moderno
* il sistema di build multipiattaforma CMake

Per i test usiamo [Catch2](https://github.com/catchorg/Catch2), una libreria header-only che viene fornita insieme agli esercizi.

Queste dipendenze sono molto comuni nei progetti C++, quindi se hai problemi a configurarle troverai molte risorse utili online.

Molti IDE, tra cui Visual Studio di Microsoft, Xcode di Apple e CLion di JetBrains, includono insieme un compilatore e CMake, quindi ti basterà installare solo l'IDE.

### Un compilatore C++14 moderno

Questo percorso richiede un compilatore con il supporto a [C++14](http://en.wikipedia.org/wiki/C%2B%2B14), rilasciato nel 2014. Tutti i principali compilatori rilasciati negli ultimi anni dovrebbero essere compatibili, quindi se usi una versione abbastanza recente dovresti essere a posto. In particolare, GCC versione 7 o successiva, Clang versione 6 o successiva, oppure Visual Studio 2017 o successivo.

### CMake

CMake è un sistema di build multipiattaforma open source che genera script di build per il tuo sistema di build nativo (`make`, Visual Studio, Xcode, ecc.). Il percorso C++ di Exercism usa CMake per offrirti una build già pronta che:

* compila i test
* compila la soluzione
* collega l'eseguibile dei test
* esegue automaticamente i test a ogni build
* fa fallire la build se uno qualsiasi dei test fallisce

Usare CMake permette a Exercism di fornire uno script di build multipiattaforma in grado di generare i file di progetto per ambienti di sviluppo integrati come Visual Studio e Xcode. Così puoi concentrarti sul problema senza preoccuparti di configurare una build per ogni esercizio.

Ottenere una build portabile non è semplice e richiede l'accesso a molti tipi di sistemi. Se incontri problemi con la ricetta CMake fornita, [segnala il problema](https://github.com/exercism/cpp/issues) così possiamo migliorare il supporto a CMake.

Per usare la ricetta di build fornita è richiesto [CMake 3.5.1 o successivo](http://www.cmake.org/).

## Windows

Gli utenti Windows possono scaricare gratuitamente [Visual Studio Community](https://www.visualstudio.com/vs/community/), che fornisce l'IDE Visual Studio e l'ultima versione del compilatore Microsoft Visual C++.

1. Segui [le istruzioni qui](https://docs.microsoft.com/en-us/cpp/build/cmake-projects-in-visual-studio) per configurare CMake.
1. Scarica l'esercizio con lo strumento [exercism cli](https://exercism.io/cli-walkthrough).
1. Apri Visual Studio 2017 o versione successiva (con gli strumenti Visual C++ per CMake installati come descritto nel link sopra).
1. Apri la cartella dell'esercizio in VS.
1. Seleziona "Build->Build the solution". I test verranno eseguiti insieme alla build, con l'output che finisce nella finestra di build. Dato che i test vengono eseguiti durante la build, VS segnalerà un errore di build se uno dei test fallisce, e i messaggi di errore dei test compariranno nella finestra di output della build.

Allo stesso modo dovresti poter usare altri IDE integrati come CLion di JetBrains.

### Installare Boost su Windows

Gli esercizi `meetup` e `gigasecond` dipendono dalle librerie [Boost][boost-website]. I passaggi seguenti descrivono come configurarle.

1. Scarica le [librerie precompilate per Windows][sourceforge-boost-binaries] di Boost.
   - Gli esercizi richiedono come minimo la versione 1.58 di Boost.
   - Puoi trovare la versione di MSVC facendo clic su "Modify" nel Visual Studio Installer.
1. Estrai le librerie in una cartella locale.
1. Imposta la variabile d'ambiente `BOOST_ROOT` sulla cartella in cui hai installato le librerie Boost.
1. Se hai tenuto Visual Studio aperto mentre facevi questo, chiudilo per assicurarti che il valore di `BOOST_ROOT` venga letto.
1. Avvia Visual Studio e apri la cartella che contiene l'esercizio `gigasecond` o `meetup`.
1. La "Startup Item" dovrebbe essere `gigasecond.exe` o `meetup.exe` e dovresti ricevere errori di build in `gigasecond_test.cpp` o `meetup_test.cpp` che ti dicono di implementare gli elementi mancanti, come negli altri esercizi.

## Linux

Tutte le versioni recenti delle distribuzioni Linux hanno compilatori C++14 compatibili, quindi dovresti riuscire a installarlo usando il gestore di pacchetti. Le versioni che supportiamo sono quelle installate di default in Ubuntu LTS 18.04.

Per esempio, su Ubuntu useresti il comando seguente per installare gcc.

```bash
$ sudo apt-get install gcc
$ gcc --version
```

Se usi una distribuzione più vecchia, potresti non avere un compilatore che supporta C++14. In tal caso dovrai vedere con la tua distribuzione come installare la versione minima del compilatore.

## MacOS

Gli utenti MacOS possono installare GCC con [Homebrew](http://brew.sh/) tramite `brew install gcc`.
