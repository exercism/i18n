# If, elseif, else

Le istruzioni condizionali che usano `if`, `elseif` ed `else` sono una parte fondamentale del flusso di controllo del programma.
L'istruzione `if` valuta un'espressione e, se è `true`, esegue il ramo di codice.

```php
<?php

if ($expression) {
    // .. executed if $expression is true
}
```

Se l'espressione non è un valore booleano, la valutazione determina se il valore è «vero» o «non falso».
In PHP, i seguenti valori sono considerati uguali a false:

- il valore booleano `false`
- il numero intero `0`
- il numero in virgola mobile `0.0` e `-0.0`
- un array vuoto `[]`
- una stringa vuota `""` o una stringa numerica `"0"`
- `null`

Tutti gli altri valori sono considerati veri.

## Rispondere a più condizioni

Dopo un'istruzione `if`, puoi concatenare più condizioni usando `elseif` ed `else`.

```php
<?php

if ($value === 0) {
    // .. do something
} elseif ($value === 1) {
    // .. do something else
} else {
    // ,, do this if nothing else
}
```

Verrà eseguita una sola istruzione condizionale valutata come vera.
Quindi, se più condizioni possono risultare vere, l'ordine in cui sono scritte è importante.

```php
<?php

if (true) {
    // .. always do something
} elseif (true)
    // .. will never be executed
} else {
    // .. will never be executed
}
```
