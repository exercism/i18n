# Istruzioni

In questo esercizio devi implementare alcune funzioni per manipolare un array di linguaggi di programmazione.

## 1. Definisci una funzione che restituisca un array di linguaggi vuoto

Definisci la funzione `language_list` che non accetta argomenti e restituisce un array vuoto.

```php
<?php

language_list();
// => []
```

## 2. Modifica la funzione per creare un array da un numero qualsiasi di linguaggi

Modifica la funzione `language_list` in modo che accetti un argomento variadico di linguaggi (stringhe).
Dovrebbe restituire l'array risultante contenente i linguaggi.

```php
<?php

$language_list = language_list();
// => []
$language_list = language_list("Clojure", "PHP");
// => ["Clojure", "PHP"]
$language_list = language_list("PHP", "Haskell", "Java", "C++", "Rust")
// => ["PHP", "Haskell", "Java", "C++", "Rust"]
```

## 3. Definisci una funzione per aggiungere un linguaggio all'array

Definisci la funzione `add_to_language_list` che prende 2 argomenti, un array di linguaggi e il nuovo linguaggio.

```php
<?php

$language_list = language_list();
// => []
$language_list = add_to_language_list($language_list, "Clojure");
// => ["Clojure"]
```

## 4. Definisci una funzione per rimuovere un elemento dall'array di linguaggi

Definisci la funzione `prune_language_list` per rimuovere il primo linguaggio dall'array di linguaggi.

```php
<?php

$language_list = language_list("PHP");
// => ["PHP"]
$language_list = prune_language_list($language_list);
// => []
```

## 5. Definisci una funzione per ottenere il primo elemento dell'array

Definisci la funzione `current_language` che prende 1 argomento (un _array di linguaggi_).
Dovrebbe restituire il primo linguaggio dell'array.
Presumi che l'array abbia sempre almeno un elemento.

```php
<?php

$language_list = language_list("PHP", "Prolog");
// => ["PHP", "Prolog"]
$first = current_language($language_list);
// => "PHP"
```

## 6. Definisci una funzione che restituisca quanti linguaggi ci sono nell'array

Definisci la funzione `language_list_length` che prende 1 argomento (un _array di linguaggi_).
Dovrebbe restituire il numero di linguaggi nell'array.

```php
<?php

$language_list = language_list("PHP", "Prolog", "Wren");
// => ["PHP", "Prolog", "Wren"]
language_list_length($language_list);
// => 3
```
