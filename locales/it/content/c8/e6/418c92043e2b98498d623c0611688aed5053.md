# Suggerimenti

## 1. Estrai gli errori

- Sugli errori si può fare pattern matching usando la sintassi del pattern `Error(value)`.

## 2. Rimuovi il prefisso del team

- Sui prefissi delle stringhe si può fare pattern matching usando la sintassi del pattern `"prefix" <> rest`.

## 3. Dividi regione e team

- Le stringhe si possono dividere su un carattere usando la [funzione `string.split`][split].
- Sulle liste si può fare pattern matching usando la sintassi del pattern `[a, b, c]`.

[split]: https://hexdocs.pm/gleam_stdlib/gleam/string.html#split
