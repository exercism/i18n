# Introduzione

Un vettore è un array monodimensionale.
Possono contenere elementi di tipi diversi.

## Creare i vettori

I vettori si possono creare con la funzione `vector` oppure usando la sua forma di lettura `#()`.

```lisp
(vector 1 t "foo" 'b) ; => #(1 t "foo" B)
#(2 nil "bar" a)      ; => #(2 nil "bar" A)
```

## Accedere agli elementi

Per accedere agli elementi di un vettore usa `aref`: gli indici partono da zero.

```lisp
(aref #(1 2 3) 1) ; => 2
(aref #(a b c) 0) ; => A
```
