# Informazioni

Un crate è un'unità di compilazione in Rust. Un crate può essere compilato in un binario o in una libreria. Il più delle volte userai `cargo` per gestire le dipendenze esterne. Aggiungere una dipendenza può essere semplice quanto aggiungere una riga al file `Cargo.toml`.

- [un'introduzione ai pacchetti e a Cargo nel libro di Rust](https://doc.rust-lang.org/book/ch07-00-managing-growing-projects-with-packages-crates-and-modules.html)
