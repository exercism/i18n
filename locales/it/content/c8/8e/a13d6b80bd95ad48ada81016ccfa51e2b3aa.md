# Le basi

Un programma Sather è fatto di **classi** che contengono **routine**.

```sather
class GREETER is

   hello : STR is
      return "Hello!";
   end;

end; -- class GREETER
```

## Le classi

Il nome di una classe si scrive in maiuscolo, con i trattini bassi tra le
parole: `GREETER`, `STAGE_DIRECTIONS`. Di solito il nome del file corrisponde,
in minuscolo: `stage_directions.sa`.

Ogni routine vive all'interno di una classe. Non c'è codice al di fuori di
essa.

## Le routine

Una routine che produce una risposta dichiara il tipo di risposta dopo i due
punti:

```sather
   hello : STR is
      return "Hello!";
   end;
```

`STR` è il tipo per il testo. Una routine che non accetta argomenti si scrive
e si chiama senza parentesi.

Una routine può accettare argomenti, scritti tra parentesi dopo il nome:

```sather
   louder(word : STR) : STR is
      return word;
   end;
```

`return` restituisce una risposta e ferma subito la routine, quindi tutte le
righe che seguono vengono saltate.

## Chiamare

Da fuori la classe, scrivi il nome della classe, poi `::`, poi la routine:

```sather
GREETER::hello
```

Dall'interno della stessa classe, il nome della classe si può omettere. È il
modo abituale con cui una routine ne chiama un'altra:

```sather
   greeting_again : STR is
      return hello;
   end;
```

## I commenti

Due trattini iniziano un commento che arriva fino alla fine della riga.

```sather
   -- Explain why, not what: the code already says what.
   hello : STR is
      return "Hello!";   -- a trailing comment is fine too
   end;
```

Per convenzione una classe termina con un commento che ne riporta il nome.
Routine, cicli e classi si chiudono tutti con `end;`, quindi il commento dice a
quale di essi appartiene questo `end;`:

```sather
end; -- class GREETER
```

## Punto e virgola

Le istruzioni terminano con un punto e virgola. Il punto e virgola dopo
l'ultima istruzione di una routine è facoltativo, ma scriverlo ogni volta è una
cosa in meno a cui pensare.
