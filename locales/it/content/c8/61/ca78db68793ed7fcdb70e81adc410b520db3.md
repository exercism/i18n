# Informazioni

Uno degli aspetti chiave quando si lavora con i numeri in F# è la distinzione tra i numeri interi (numeri senza cifre dopo il separatore decimale) e i numeri in virgola mobile (numeri con zero o più cifre dopo il separatore decimale).

I due tipi numerici più usati in F# sono `int` (un intero a 32 bit) e `float` (un numero in virgola mobile a 64 bit).

```fsharp
let i = 123   // Type is `int`
let d = 54.29 // Type is `float`
```

Sia i numeri interi sia i numeri in virgola mobile possono usare il carattere `_` come _separatore di cifre_, cosa che può aiutare quando si definiscono numeri grandi:

```fsharp
let largeInt = 1_000_000
// => 1000000

let largeFloat = 9_876_543.21
// => 9876543.21
```

L'aritmetica si basa sui [normali operatori aritmetici][arithmetic-operators] (`+`, `-`, `*`, ecc.). I numeri si possono confrontare usando i [normali operatori di confronto][comparison-operators] (`<`, `>=`, ecc.) e gli operatori di uguaglianza (`=`) e disuguaglianza (`<>`).

```fsharp
5 * 6
// => 30

1.2 > 0.8
// => true

2 <> 4
// => true
```

Per convertire un tipo numerico in un altro, bisogna usare gli [operatori di conversione][conversion-operators] integrati. Questi operatori prendono il nome dal tipo in cui convertono.

```fsharp
let floatFromInt = float 2
let intFromFloat = int 3.39
```

Quando si converte tra tipi, bisogna sempre stare attenti. Se un valore non può essere rappresentato dal tipo di destinazione, il valore andrà in _overflow_.
