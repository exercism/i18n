# Istruzioni

Josh sta lavorando a un nuovo gioco di ruolo e ha bisogno del tuo aiuto per implementare alcune meccaniche.

## 1. Definisci le unioni di tipi

Definisci un'unione di tipi tra `String` e `Missing` denominata `StringOrMissing`, che potrà essere usata nel codice successivo.
Definisci un'unione di tipi tra `Int64` e `Nothing` denominata `IntOrNothing`, che potrà essere usata nel codice successivo.

## 2. Implementa il tipo composito Player

Il tipo composito Player deve contenere quattro campi, ognuno con un'annotazione di tipo e un valore predefinito:
- Il campo `name` è di tipo `StringOrMissing`, con valore predefinito `missing`
- Il campo `level` è di tipo `Int64`, con valore predefinito `0`
- Il campo `health` è di tipo `Int64`, con valore predefinito `100`
- Il campo `mana` è di tipo `IntOrNothing`, con valore predefinito `nothing`

```julia-repl
julia> defaultplayer = Player()
Player(missing, 0, 100, nothing)

julia> wealthyplayer = Player(mana=100)
Player(missing, 0, 100, 100)

julia> namedplayer = Player(name="Guilian", level=10)
Player("Guilian", 10, 100, nothing)
```

## 3. Presentati

Implementa la funzione `introduce`.

I giocatori furtivi potrebbero nascondere il loro nome e verranno presentati come `"Mighty Magician"`.
Altrimenti, presenta il giocatore usando semplicemente il suo nome.

```julia-repl
julia> introduce(Player(level=2, health=8))
"Mighty Magician"

julia> introduce(Player(name="Merlin", level=2, health=8))
"Merlin"
```

## 4. Implementa i metodi increment

La funzione ausiliaria `increment` ha due metodi, ognuno con una firma di funzione diversa.
L'argomento di ciascuno richiede un'annotazione di tipo per rendere esplicita la firma.

Il metodo `increment` per i nomi deve ricevere il `name` di un giocatore.
- Se il nome è `missing`, restituisci il titolo "The Great".
- Altrimenti, al nome viene aggiunto il titolo " the Great".

Questo metodo `increment` restituisce il nuovo nome.

```julia-repl
julia> player1 = Player(name="Ogre", level=5, health=49, mana=26)
Player("Ogre", 5, 49, 26)

julia> increment(player1.name)
"Ogre the Great"

julia> player2 = Player(level=32, mana=57)
Player(missing, 32, 100, 57)

julia> increment(player2.name)
"The Great"
```

Il metodo `increment` per il mana deve ricevere il `mana` di un giocatore.
- Se il mana del giocatore è `missing`, restituisci il valore `50`.
- Altrimenti, il mana viene aumentato di `100`.

Questo metodo `increment` restituisce il mana aggiornato.

```julia-repl
julia> player3 = Player(level=3)
Player(missing, 3, 100, nothing)

julia> increment(player3.mana)
50

julia> player4 = Player("Goblin", level=15, health=49, mana=26)
Player("Goblin", 5, 49, 26)

julia> increment(player4.mana)
126
```

## 5. Implementa la funzione title

Il livello più alto del gioco è `42`. Per riconoscere l'impresa dei giocatori che raggiungono questo livello, ai loro nomi viene aggiunto un titolo. La funzione `title!` aggiorna il nome di un giocatore nel modo seguente.

- Se il livello del giocatore è 42, il nome viene aggiornato usando la funzione `increment`.
- Altrimenti, il nome rimane invariato.

In entrambi i casi, la funzione `title!` restituisce il nome del giocatore.

```julia-repl
julia> player1 = Player(level=42, health=12)
Player(missing, 42, 12, nothing)

julia> title!(player1)
"The Great"

julia> player1.name
"The Great"

julia> player2 = Player(name="Svengali", level=42, health=36, mana=54)
Player("Svengali", 42, 36, 54)

julia> title!(player2)
"Svengali the Great"

julia> player2.name
"Svengali the Great"

julia> player3 = Player(name="Rasputin", level=21, health=100, mana=54)
Player("Rasputin", 21, 100, 54)

julia> title!(player3)
"Rasputin"

julia> player3.name
"Rasputin"
```

## 6. Implementa la funzione revive

La funzione `revive!` deve verificare che il personaggio del giocatore sia effettivamente morto (la sua salute ha raggiunto `0`).

Se il giocatore è morto:
- Il giocatore deve essere rianimato con `100` di salute.
- Il mana del giocatore deve essere incrementato usando la funzione `increment`.

Se il giocatore è vivo, non gli succede nulla

La funzione `revive!` deve restituire il giocatore.

```julia-repl
julia> deadplayer1 = Player(level=2, health=0)
Player(missing, 2, 0, nothing)

julia> revive!(deadplayer1)
Player(missing, 2, 100, 50)

julia> deadplayer2 = Player(level=12, health=0, mana=5)
Player(missing, 12, 0, 5)

julia> revive!(deadplayer2)
Player(missing, 12, 100, 105)

julia> aliveplayer = Player(level=23, health=1)
Player(missing, 23, 1, nothing)

julia> revive!(aliveplayer)
Player(missing, 23, 1, nothing)
```
