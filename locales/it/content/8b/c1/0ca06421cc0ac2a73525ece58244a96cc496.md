# Introduzione

A differenza di molti altri linguaggi, in JavaScript ci sono due entità diverse che rappresentano l'assenza di un valore (significativo): `null` e `undefined`.

## Null

Il valore primitivo `null` viene usato come «valore vuoto» intenzionale per variabili di qualsiasi tipo.

```javascript
let name = null;
// name is intentionally set to "empty" because it is not
// available
```

Puoi verificare se una variabile è null usando l'[operatore di uguaglianza stretta][mdn-strict-equality] `===`.

```javascript
let name = null;

name === null;
// => true
```

## Undefined

> Una variabile a cui non è stato assegnato un valore è di tipo `undefined`.<sup>1</sup>

Questo significa che mentre `null` rappresenta un valore vuoto (ma pur sempre un valore), `undefined` rappresenta l'assenza totale di un valore. 🤯

`undefined` compare in contesti diversi.

- Se una variabile viene dichiarata senza un valore (inizializzazione), è `undefined`.
- Se provi ad accedere al valore di una chiave inesistente in un oggetto, ottieni `undefined`.
- Se una funzione non restituisce un valore, il risultato è `undefined`.
- Se a una funzione non viene passato un argomento, questo è `undefined`, a meno che quell'argomento non abbia un valore predefinito.

```javascript
let name;
console.log(name);
// => undefined
```

Puoi verificare se una variabile è undefined usando l'operatore di uguaglianza stretta `===`.

```javascript
let name;

name === undefined;
// => true
```

## Concatenamento opzionale

Se provi a recuperare un valore annidato in un oggetto ma la chiave genitore non esiste, JavaScript genera un errore.
Per evitarlo facilmente, il concatenamento opzionale è stato aggiunto alla specifica del linguaggio nel 2020.
Con l'operatore di concatenamento opzionale `?.` puoi assicurarti che JavaScript provi ad accedere alla chiave annidata solo se il genitore non è `null` o `undefined`.
Altrimenti, viene restituito `undefined`.

```javascript
const obj = {
  address: {
    street: 'Trincomalee Highway',
    city: 'Batticaloa',
  },
};

obj.address.zipCode;
// => undefined

obj.residence.street;
// => TypeError: Cannot read property 'street' of undefined

obj.residence?.street;
// => undefined
```

## Coalescenza nullish

Ci sono situazioni in cui vuoi applicare un valore predefinito nel caso in cui una variabile sia null o undefined (ma solo in quel caso).
Per risolvere questo problema, l'operatore di coalescenza nullish `??` è stato introdotto nel 2020.
Restituisce l'operando di destra solo quando l'operando di sinistra è `null` o `undefined`.
Altrimenti, viene restituito l'operando di sinistra.

```javascript
let amount = null;
amount = amount ?? 1;
// => 1

amount = 0;
amount = amount ?? 1;
// => 0
```
