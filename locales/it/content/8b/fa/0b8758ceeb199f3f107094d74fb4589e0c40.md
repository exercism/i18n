# Rappresentazioni

Il [Java representer][github-java-representer] applica le seguenti normalizzazioni:

- Tutti i commenti vengono rimossi
- Tutte le dichiarazioni di import vengono rimosse
- Gli identificatori vengono normalizzati a un valore segnaposto

Dopo aver applicato le normalizzazioni precedenti, la rappresentazione risultante viene formattata secondo [Google Java Style][google-java-style], per eliminare eventuali differenze rimanenti nella formattazione del codice.

## Prima di inviare

Controlla le seguenti cose:

- Non duplicare il feedback fornito dall'analyzer.
- Controlla la scheda "esempi" nella finestra di invio e verifica se il feedback ha senso per tutte le schede.
- Controlla di non aver fatto riferimento a spazi bianchi o commenti.
- Controlla di non fare riferimento ai nomi delle funzioni o delle variabili così come appaiono nella soluzione, ma di usare la mappatura fornita (oppure di omettere i nomi).
  Solo agli identificatori usati dai test dell'esercizio si può fare riferimento in tutta sicurezza, perché sono sempre gli stessi per tutti.
