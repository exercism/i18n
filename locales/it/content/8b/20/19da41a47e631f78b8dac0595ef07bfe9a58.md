# Istruzioni specifiche per SQLite

La colonna **result** deve contenere un oggetto JSON di oggetti, con ogni parola come chiave e il conteggio come numero intero.

Ad esempio, considera la frase qui sopra: `"That's the password: 'PASSWORD 123'!", cried the Special Agent.\nSo I fled.`
Il **result** per questo input dovrebbe essere:

```json
{"123":1,"agent":1,"cried":1,"fled":1,"i":1,"password":2,"so":1,"special":1,"that's":1,"the":2}
```

## Schema della tabella

```sql
CREATE TABLE "word-count" (
    sentence TEXT NOT NULL,
    result   TEXT               -- json object
);
```
