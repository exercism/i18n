# Debug

Quando un test fallisce, viene mostrato un messaggio che descrive cosa è andato storto e per quale input. Inoltre, puoi sfruttare il fatto che verrà mostrato anche qualsiasi [output della console][programiz.com-basic-input-output]. Per scrivere nella console puoi usare:

```csharp
Console.WriteLine("Debug message");
```
