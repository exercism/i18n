# Introduzione

## Funzioni esterne

Gleam può essere eseguito sulla macchina virtuale Erlang (BEAM), oppure su runtime JavaScript. Ci sono molti altri linguaggi che usano questi runtime, ed è spesso utile poter chiamare da Gleam codice scritto in questi linguaggi.

La funzionalità delle _funzioni esterne_ di Gleam permette di importare in Gleam funzioni scritte in altri linguaggi e di chiamarle senza alcun overhead a runtime.

Se il tuo progetto Gleam viene eseguito sulla macchina virtuale Erlang e vuoi chiamare la funzione `reverse` dal modulo `lists` di Erlang, puoi farlo aggiungendo l'attributo `@external` a una testa di funzione Gleam in questo modo:

```gleam
@external(erlang, "lists", "reverse")
pub fn reverse_list(x: List(a)) -> List(a)
```

Questa può quindi essere chiamata come una normale funzione Gleam:

```gleam
let reversed = reverse_list([1, 2, 3])
// -> [3, 2, 1]
```

Se provi a compilare questo codice per runtime JavaScript, fallirà con un messaggio di errore, perché non esiste un'implementazione per JavaScript. Un'altra implementazione può essere specificata per i runtime JavaScript in questo modo:

```gleam
@external(erlang, "lists", "reverse")
@external(javascript, "./my_module.mjs", "reverse")
pub fn reverse_list(x: List(a)) -> List(a)
```

È anche possibile scrivere un'implementazione Gleam che verrà usata quando non c'è un'implementazione esterna per il target di compilazione corrente:

```gleam
@external(erlang, "lists", "reverse")
pub fn reverse_list(x: List(a)) -> List(a) {
  tail_recursive_reverse(x, [])
}

fn tail_recursive_reverse(list, reversed) {
  case list {
    [] -> reversed
    [x, ..xs] -> tail_recursive_reverse(xs, [x, ..reversed])
  }
}
```

## Tipi esterni

I tipi esterni possono essere usati per riferirsi a tipi di dati definiti in altri linguaggi, come Erlang o JavaScript.

Per definire un tipo esterno, dichiara un tipo ma non fornire alcun costruttore. Questo può quindi essere usato allo stesso modo di qualsiasi altro tipo.

```gleam
pub type OrderedDictionary(element)
```
