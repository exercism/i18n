# Introduzione

## Ricorsione

Le funzioni ricorsive sono funzioni che chiamano se stesse.

Una funzione ricorsiva deve avere almeno un _caso base_ ed almeno un _caso ricorsivo_.

Un _caso base_ restituisce un valore senza chiamare di nuovo la funzione.
Un _caso ricorsivo_ chiama di nuovo la funzione, modificando l'input in modo che prima o poi corrisponda al caso base.

In Elm, le funzioni ricorsive si definiscono tipicamente tramite pattern matching, con espressioni `case` o più clausole di funzione.

```elm
count : List a -> Int
count list =
    case list of
        [] ->
            0  -- base case

        _ :: tail ->
            1 + count tail  -- recursive case
```

### I cicli tramite la ricorsione

A causa dell'immutabilità, in Elm i cicli si scrivono diversamente rispetto ai linguaggi imperativi.
Per esempio, i cicli hanno spesso questo aspetto:

```c
for(i = 0; i < array.length; i++) {
  // do something with array[i]
}
```

In un linguaggio funzionale come Elm, non è possibile modificare le variabili.
Quindi i cicli vanno implementati con la ricorsione.

L'equivalente di un ciclo `for` in Elm sarebbe questo:

```elm
loop : List a -> (a -> b) -> List b
loop list f =
    case list of
        [] ->
            []

        head :: tail ->
            f head :: loop tail f
```

In pratica, per iterare su array e altre strutture dati in Elm si usano più spesso funzioni del modulo `List`, come `List.map`, `List.filter` e `List.foldl`.
Dietro le quinte, queste funzioni sono implementate con la ricorsione.
