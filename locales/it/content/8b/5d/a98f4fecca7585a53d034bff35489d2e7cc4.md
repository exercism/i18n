# Workflow di rilascio

Il workflow di rilascio viene usato per rilasciare gli [strumenti del track](/docs/building/tooling) su:

1. [Docker Hub](https://hub.docker.com/): usato negli script o per i test in locale.
   Disponibile pubblicamente.
2. [ECR](https://aws.amazon.com/ecr/): usato nell'ambiente di produzione per testare le soluzioni inviate.
   Privato.

## Sorgente

Il workflow è definito nel file `.github/workflows/deploy.yml`.
