# Introduzione

In Gleam esistono due tipi diversi di numeri: gli interi e i numeri in virgola mobile.

Gli interi sono numeri senza parte decimale.

```gleam
let integer = 3
// -> 3
```

Per maggiore chiarezza, agli interi si possono aggiungere anche gli underscore.

```gleam
1_000_000 // One million
```

Gleam ha diversi operatori che funzionano con gli interi.

```gleam
1 + 1 // -> 2
5 - 1 // -> 4
5 / 2 // -> 2
3 * 3 // -> 9
5 % 2 // -> 1

2 > 1  // -> True
2 < 1  // -> False
2 >= 1 // -> True
2 <= 1 // -> False
```
