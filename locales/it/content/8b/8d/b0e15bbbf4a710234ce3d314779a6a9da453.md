# Istruzioni

Stai scrivendo un sistema embedded per una macchina che distribuisce numeri. È un modello molto semplice. Può distribuire numeri consecutivi e riportare qual è stato l'ultimo numero distribuito.

## 1. Avvia la macchina

Implementa la funzione `start/0`. Deve avviare un nuovo processo e restituire il PID del processo. Il nuovo processo non deve ancora fare nulla.

```elixir
TakeANumber.start()
# => #PID<0.138.0>
```

Nota che ogni volta che esegui questo codice, il PID può essere diverso.

## 2. Riporta lo stato della macchina

Modifica la macchina in modo che il processo appena avviato sia pronto a ricevere messaggi (avvia un _ciclo di ricezione_) con uno stato iniziale di `0`. Deve essere in grado di ricevere messaggi `{:report_state, sender_pid}`. In risposta a questi messaggi, deve inviare il suo stato attuale (il numero dell'ultimo biglietto distribuito) a `sender_pid` e poi aspettare altri messaggi.

```elixir
machine_pid = TakeANumber.start()

# a client sending a message to the machine
send(machine_pid, {:report_state, self()})

# a client receiving a message from the machine
receive do
  msg -> msg
end

# => 0
```

## 3. Distribuisci i numeri

Modifica la macchina in modo che possa ricevere messaggi `{:take_a_number, sender_pid}`. Deve aumentare il suo stato di 1, inviare il nuovo stato a `sender_pid` e poi aspettare altri messaggi.

```elixir
machine_pid = TakeANumber.start()

# a client sending a message to the machine
send(machine_pid, {:take_a_number, self()})

# a client receiving a message from the machine
receive do
  msg -> msg
end

# => 1
```

## 4. Ferma la macchina

Modifica la macchina in modo che possa ricevere un messaggio `:stop`. Deve smettere di aspettare altri messaggi.

## 5. Ignora i messaggi inaspettati

Modifica la macchina in modo che, quando riceve un messaggio inaspettato, lo ignori e continui ad aspettare altri messaggi.
