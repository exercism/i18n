# Introduzione

## Enum

Un _tipo enum_ è un tipo di dato speciale che consente a una variabile di assumere un insieme di costanti predefinite.
La variabile deve essere uguale a uno dei valori predefiniti per quel tipo.
Esempi comuni sono i punti cardinali (i valori `NORTH`, `SOUTH`, `EAST` e `WEST`) e i giorni della settimana.

Poiché sono costanti, i nomi dei campi di un tipo enum si scrivono in lettere maiuscole.

### Definire un tipo enum

Nel linguaggio di programmazione Java, definisci un tipo enum usando la parola chiave `enum`.
Per esempio, un tipo enum per i giorni della settimana si specifica così:

```java
public enum DayOfWeek {
    SUNDAY,
    MONDAY,
    TUESDAY,
    WEDNESDAY,
    THURSDAY,
    FRIDAY,
    SATURDAY
}
```

Dovresti usare i tipi enum ogni volta che devi rappresentare un insieme fisso di costanti.
Questo vale anche per i tipi enum naturali, come i pianeti del nostro sistema solare, e per gli insiemi di dati in cui conosci tutti i valori possibili al momento della compilazione: per esempio, le voci di un menu, i flag della riga di comando e così via.

### Usare un tipo enum

Ecco un po' di codice che mostra come usare l'enum `DayOfWeek` definito sopra:

```java
public class Shop {
    public String getOpeningHours(DayOfWeek dayOfWeek) {
        switch (dayOfWeek) {
            case MONDAY:
            case TUESDAY:
            case WEDNESDAY:
            case THURSDAY:
            case FRIDAY:
                return "9am - 5pm";
            case SATURDAY:
                return "10am - 4pm"
            case SUNDAY:
                return "Closed.";
        }
    }
}
```

```java
var shop = new Shop();
shop.getOpeningHours(DayOfWeek.WEDNESDAY);
// => "9am - 5pm"
```

### Aggiungere metodi e campi

I tipi enum del linguaggio di programmazione Java sono molto più potenti dei loro equivalenti in altri linguaggi.
La dichiarazione `enum` definisce una _classe_ (chiamata _tipo enum_).
Il corpo della classe enum può includere metodi e altri campi:

```java
public enum Rating {
    GREAT(5),
    GOOD(4),
    OK(3),
    BAD(2),
    TERRIBLE(1);

    private final int numberOfStars;

    Rating(int numberOfStars) {
        this.numberOfStars = numberOfStars;
    }

    public int getNumberOfStars() {
        return this.numberOfStars;
    }
}
```

Chiamare il metodo `getNumberOfStars` su un membro del tipo enum `Rating`:

```java
Rating.GOOD.getNumberOfStars();
// => 4
```
