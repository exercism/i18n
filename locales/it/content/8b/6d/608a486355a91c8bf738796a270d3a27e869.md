# Test


Usiamo [pytest][pytest: Getting Started Guide] come test runner per il nostro sito.
Dovrai installare `pytest` sulla tua macchina di sviluppo se vuoi eseguire i test del track Python in locale.
Ti conviene installare anche i seguenti plugin di `pytest`:

- [pytest-cache][pytest-cache]
- [pytest-subtests][pytest-subtests]

Trovi informazioni più approfondite nella [guida ai test per Python][Python track tests page] sul nostro sito.


### Eseguire i test

Per eseguire i test inclusi, spostati nella cartella in cui è archiviato l'esercizio usando `cd` nel terminale (_sostituisci `<exercise-folder-location>` qui sotto con il tuo percorso_).
I file di test di solito terminano in `_test.py` e sono gli stessi test che vengono eseguiti sul sito quando si carica una soluzione.

Linux/MacOS
```bash
$ cd <path/to/exercise-folder-location>
```

Windows
```powershell
PS C:\Users\foobar> cd <path\to\exercise-folder-location>
```

<br>

Ora esegui il comando `pytest` nel terminale, sostituendo `<exercise_test.py>` con il nome del file di test:

Linux/MacOS
```bash
$ python3 -m pytest -o markers=task <exercise_test.py>
==================== 7 passed in 0.08s ====================
```

Windows
```powershell
PS C:\Users\foobar> py -m pytest -o markers=task <exercise_test.py>
==================== 7 passed in 0.08s ====================
```


### Opzioni comuni
- `-o` : sovrascrive il valore predefinito di `pytest.ini` (_puoi usarlo per evitare gli avvisi sui marker_)
- `-v` : abilita l'output dettagliato.
- `-x` : interrompe l'esecuzione dei test al primo fallimento.
- `--ff` : esegue i test falliti in precedenza prima degli altri casi di test.

Per ulteriori opzioni, usa `python3 -m pytest -h` o `py -m pytest -h`.


### Risolvere gli avvisi

Se non usi `pytest -o markers=task` quando chiami `pytest`, potresti ricevere un `PytestUnknownMarkWarning` per i test che usano la nostra nuova sintassi:

```bash
PytestUnknownMarkWarning: Unknown pytest.mark.task - is this a typo?  You can register custom marks to avoid this warning - for details, see https://docs.pytest.org/en/stable/mark.html
```

Per evitare di digitare `pytest -o markers=task` per ogni test che esegui, puoi usare un file di configurazione `pytest.ini`.
Ne abbiamo preparato uno che puoi scaricare dalla cartella principale del track Python: [pytest.ini][pytest.ini].

Puoi anche creare un tuo file `pytest.ini` con il seguente contenuto:

```ini
[pytest]
markers =
    task: A concept exercise task.
```

Se metti il file `pytest.ini` nella cartella _root_ o _working_ dei tuoi esercizi del track Python, i marker vengono registrati e gli avvisi spariscono.
Trovi maggiori informazioni sui marker di pytest nella documentazione di `pytest` su [come contrassegnare le funzioni di test][pytest: marking test functions with attributes] e nella documentazione di `pytest` su [come usare i marker personalizzati][pytest: working with custom markers].

Trovi informazioni su come personalizzare le configurazioni di pytest nella documentazione di `pytest` sui [formati dei file di configurazione][pytest: configuration file formats].
