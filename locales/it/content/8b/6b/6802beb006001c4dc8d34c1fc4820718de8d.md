# Istruzioni

Il tuo compito è creare un verificatore di password.
Un verificatore di password convalida la password proposta da un utente per assicurarsi che soddisfi una serie di requisiti definiti dall'organizzazione che controlla l'accesso alla risorsa in questione.

Per questo esercizio, i requisiti della password sono:
* Deve avere 12 o più caratteri
* Deve contenere almeno una lettera maiuscola
* Deve contenere almeno una lettera minuscola
* Deve contenere almeno una cifra
* Deve contenere almeno un simbolo dell'insieme !@#$%^&*

La soluzione deve usare un `Result` per incapsulare lo stato di successo o di fallimento.
Nel caso di successo, il `Result` deve riportare la password convalidata sotto forma di stringa.
Nel caso di fallimento, il `Result` deve riportare la regola che è stata violata.

~~~~exercism/note
Per questo esercizio, il verificatore di password sarà molto semplice: indicherà solo quando è stata violata una singola regola.
Un esercizio successivo esplorerà un verificatore di password più realistico, in grado di indicare quando più regole sono state violate contemporaneamente.
~~~~

## 1. Implementa la funzione `checkPassword`

La funzione `checkPassword` verifica la password data rispetto ai requisiti menzionati sopra. In caso di fallimento, indica la regola violata incapsulando uno dei valori di `PasswordRule` all'interno del valore risultante.

```fsharp
checkPassword "abcdefghij5#"
// => Error MissingUppercaseLetter
```

## 2. Implementa la funzione ``getStatusMessage`

La funzione `getStatusMessage` restituisce una stringa contenente un messaggio leggibile da una persona che indica il significato del risultato restituito da `checkPassword`.

```fsharp
getStatusMessage (Error MissingDigit)
// => "Error: does not have at least one digit"
```
