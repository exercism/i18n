# Introduzione

Le funzioni e i metodi di Go possono restituire più valori:

```go
func GetCard() (Card, error) { ... }
```

Ogni valore restituito deve essere assegnato in ordine e separato da virgole:

```go
card, err := GetCard()
```

Ogni posizione nell'assegnazione dichiara una variabile.
Go non compila se una variabile dichiarata non viene mai usata.
L'identificatore vuoto `_` prende il posto di un nome di variabile per saltare quel valore restituito:

```go
card, _ := GetCard()
```

`error` è un'interfaccia predefinita.
Un errore `nil` significa che non si è verificato alcun errore; qualsiasi valore non-nil significa che qualcosa è andato storto.
Per convenzione, le funzioni che possono fallire dovrebbero restituire un `error` come ultimo valore.
Chi chiama la funzione deve verificarlo prima di usare qualsiasi altro valore restituito:

```go
card, err := GetCard()
if err != nil {
    return err // do not use card here
}
// safe to use card here
```
