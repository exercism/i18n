# Eseguire i test

SWI Prolog può essere eseguito in modo interattivo oppure direttamente dalla riga di comando.

## Riga di comando

Per eseguire i test dalla riga di comando, puoi usare il comando seguente:

```bash
swipl -f <exercise>.pl -s <exercise>_tests.plt -g run_tests,halt -t 'halt(1)'
```

Sostituisci `<exercise>` con il nome dell'esercizio che stai implementando.

## Modalità interattiva

Per eseguire Prolog in modo interattivo, per prima cosa esegui:

```bash
swipl
```

Dopo che la console di Prolog si è avviata, carica l'implementazione ed esegui i test con:

```
?- ["<exercise>.pl"].
?- ["<exercise>_tests.plt"].
?- run_tests.
```

Sostituisci `<exercise>` con il nome dell'esercizio che stai implementando.

### Ricaricare le modifiche

Una volta caricati i file qui sopra, puoi applicare le modifiche che hai fatto eseguendo:

```
?- make.
```

## Test saltati

Quando inizi un esercizio, viene eseguito solo il primo test. Gli altri sono stati saltati aggiungendo `condition(pending)` al goal `test`.
Una volta che il primo test passa, riattiva il test successivo cambiando `pending` in `condition(pending)` con `true`.
Ripeti per ogni test finché non vengono eseguiti e superati tutti.

### Riga di comando

Aggiungi l'argomento `-- --all` alla fine del comando per eseguire anche i test ancora in sospeso:

```bash
swipl -f <exercise>.pl -s <exercise>_tests.plt -g run_tests,halt -t 'halt(1)' -- --all
```
