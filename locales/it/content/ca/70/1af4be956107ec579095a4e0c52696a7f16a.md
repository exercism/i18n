# Istruzioni

Lavorando con un parco divertimenti, ti è stata consegnata una specifica per progettare un sistema che gestisca le presenze e le giostre. Il tuo compito è modellare l'Attendee (la persona che visita il parco).

## 1. Crea nuovi Attendee

Implementa il metodo `Attendee#initialize` della classe `Attendee`: deve accettare un'altezza (in centimetri) e memorizzarla in una variabile di istanza

```ruby
Attendee.new(106)
# => #<Attendee:0x000055c33e6c7e18 @height=106>
```

## 2. Quanto è alto l'Attendee

Implementa il getter `Attendee#height` della classe `Attendee`: deve restituire l'altezza dell'istanza

```ruby
Attendee.new(106).height
# => 106
```

## 3. Qual è l'id del pass per le giostre

Non tutti gli Attendee hanno acquistato un pass per le giostre, ma dobbiamo sapere se ne hanno uno o no. Implementa il getter `Attendee#pass_id` della classe `Attendee`: deve restituire il pass_id dell'istanza, oppure `nil` se l'Attendee non ne ha uno.

```ruby
Attendee.new(106).pass_id
# => nil
```

## 4. Consenti alle persone di acquistare un pass

Implementa `Attendee#issue_pass!` per mutare lo stato dell'istanza ed impostare la variabile di istanza del pass id all'argomento. Deve restituire il pass id.

```ruby
attendee = Attendee.new(106)
attendee.issue_pass!(42)
attendee.pass_id
# => 42
```

## 5. Revoca il pass

Alcuni ospiti infrangono le regole con comportamenti pericolosi, quindi il parco vuole poter revocare i pass. Implementa `Attendee#revoke_pass!` per mutare lo stato dell'istanza ed impostare il pass id su `nil`

```ruby
attendee = Attendee.new(106)
attendee.issue_pass!(42)
attendee.revoke_pass!
attendee.pass_id
# => nil
```
