# Risorse

- La risorsa più importante è la [documentazione ufficiale][docs]
- Per modificare il codice online, usa [Uiua Pad][pad]
- Esplora il codice sorgente nel [repository GitHub][github] di Uiua
- Resta aggiornato con il [blog ufficiale di Uiua][blog]

Anche il [sito principale][main] include un link al server Discord, dove puoi parlare di Uiua con altri appassionati.

[docs]: https://www.uiua.org/docs
[github]: https://github.com/uiua-lang/uiua
[pad]: https://www.uiua.org/pad
[blog]: https://www.uiua.org/blog
[main]: https://www.uiua.org
