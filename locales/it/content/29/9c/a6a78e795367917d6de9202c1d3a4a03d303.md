# Introduzione

## Spiegazione

Oltre ai tipi di dati primitivi come `number` e `string`, in JavaScript esiste un altro tipo di dati importante chiamato `object`.
Gli oggetti sono raccolte di coppie chiave-valore.
Per questo motivo, si possono usare allo stesso modo di quelle che in altri linguaggi vengono spesso chiamate mappe o dizionari.

In altri linguaggi, spesso tutti i valori di una mappa devono avere lo stesso tipo di dati.
In JavaScript, invece, è vincolato solo il tipo della chiave: deve essere di tipo `string`.
I valori all'interno di uno stesso oggetto possono avere tipi diversi.
Possono essere tipi primitivi come i numeri, ma anche array, altri oggetti o persino funzioni.
Questo rende gli oggetti molto versatili, al punto che sono anche elementi chiave della [programmazione orientata agli oggetti][oop] (OOP) in JavaScript.

Nel seguito ci concentreremo sugli oggetti come raccolte o mappe.
Altri casi d'uso degli oggetti saranno trattati in altri concetti, vedi ad esempio [Classi][concept-classes].

## Creare un oggetto

Un oggetto si crea usando le parentesi graffe.
Puoi anche includere direttamente alcune voci.
Per farlo, indica prima la chiave, poi due punti e il valore.

```javascript
const emptyObject = {};

const obj = {
  favoriteNumber: 42,
  greeting: 'Hello World',
  useGreeting: true,
  address: {
    street: 'Trincomalee Highway',
    city: 'Batticaloa',
  },
  fruits: ['melon', 'papaya'],
  addNumbers: function (a, b) {
    return a + b;
  },
};
```

La virgola finale dopo l'ultima voce è opzionale in JavaScript.

Forse ti chiederai perché le chiavi non sono racchiuse tra virgolette anche se dovrebbero essere delle stringhe.
Questa è una notazione abbreviata.
Se la chiave segue le regole di denominazione per un [identificatore][mdn-identifier] JavaScript, puoi omettere le virgolette.
Per le chiavi con caratteri speciali nel nome, devi usare la solita notazione delle stringhe.

```javascript
const obj = {
  '1keyStartsWithNumber': '...',
  'key/with/slashes': '...',
  'key-with-dashes': '...',
  'key with spaces': '...',
  '#&()[]{}èä樹keyWithSpecialChars': '...',
};
```

## Recuperare un valore

Ci sono due modi per recuperare il valore di una determinata chiave: la notazione con punto e la notazione con parentesi quadre.

```javascript
const obj = { greeting: 'hello world' };

obj.greeting;
// => hello world

obj['greeting'];
// => hello world

// Bracket notation also works with variables.
const key = 'greeting';
obj[key];
// => hello world
```

Usare la notazione con punto come abbreviazione ha la stessa restrizione dell'omettere le virgolette.
Funziona solo se la chiave segue le regole di denominazione degli identificatori.

## Aggiungere o modificare un valore

Puoi aggiungere o modificare un valore usando l'operatore di assegnazione `=`.
Anche in questo caso sono disponibili la notazione con punto e quella con parentesi quadre.

```javascript
const obj = { greeting: 'hello world' };

obj.greeting = 'Hi there!';
obj['greeting'] = 'Welcome.';

obj.newKey1 = 'new value 1';
obj['new key 2'] = 'new value 2';

const key = 'new key 3';
obj[key] = 'new value 3';
```

## Eliminare una voce

Puoi eliminare una coppia chiave-valore da un oggetto usando la parola chiave `delete`.

```javascript
const obj = {
  key1: 'value1',
  key2: 'value2',
};

delete obj.key1;
delete obj['key2'];
```

## Verificare se una chiave esiste

Puoi verificare se una determinata chiave esiste in un oggetto con il metodo `hasOwnProperty`.

```javascript
const obj = { greeting: 'hello world' };

obj.hasOwnProperty('greeting');
// => true

obj.hasOwnProperty('age');
// => false
```

## Iterare su un oggetto

Esiste un ciclo speciale `for...in` per iterare su tutte le chiavi di un oggetto.

```javascript
const obj = {
  name: 'Ali',
  age: 65,
};

for (let key in obj) {
  console.log(key, obj[key]);
}
// name Ali
// age 65
```

Per evitare errori sottili, dovresti sempre presumere che il ciclo `for...in` visiti le chiavi in un ordine arbitrario.
Inoltre, tieni presente che `for...in` include nell'iterazione anche le [chiavi ereditate][concept-inheritance].
