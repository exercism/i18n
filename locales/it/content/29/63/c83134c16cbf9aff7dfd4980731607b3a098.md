# Introduzione

Come altri linguaggi, anche il C++ fornisce un'istruzione `switch`.
Le istruzioni switch sono un modo più breve per scrivere lunghe istruzioni `if ... else if`.
Per creare uno switch, iniziamo usando la parola chiave `switch` seguita da un numero intero.
Poi dichiariamo ciascuna delle condizioni con la parola chiave `case`.
Possiamo anche dichiarare un caso `default`, che viene eseguito quando nessuna delle condizioni `case` precedenti corrisponde.
Ogni caso dovrebbe terminare con un'istruzione `break` (o `return`).

```cpp
int price{0};
int adults{3};
int kids{2};

switch (int group_size{adults + kids}) {
    case 1:
        price = 50;
        break;
    case 2:
        price = 70;
        break;
    default:
        price = group_size * 30;
}
```

## Fall-through

Una cosa importante della costruzione switch è che il codice continua a essere eseguito finché non viene fermato da un'istruzione `break` (o `return`).
Questo può portare a comportamenti inattesi.

```cpp
int adults{1};
int kids{0};
switch (int group_size{adults + kids}) {
    case 1:
        price = 50;
    case 2:
        price = 70;
    default:
        price = group_size * 30;
}
// price will be 30!
```

Il caso d'uso principale di questa esecuzione continuata è un'istruzione con più etichette.
Più risultati dello switch possono rimandare alla stessa porzione di codice da eseguire.
In questo modo, per esempio in un'app di prenotazioni, la funzione chiamata per gruppi di 2 e 3 persone può essere la stessa:
```cpp
switch (group_size) {
case 1:
    book_room();
    break;
case 2:
case 3:
    book_apartment(group_size);
    break;
default:
    book_house(group_size);
}
// book_apartment happens when group_size is 2 or 3
```
