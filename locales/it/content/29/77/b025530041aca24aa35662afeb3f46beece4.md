# Appendice alle istruzioni

## Suggerimenti

Devi implementare la funzione `convert` che restituisce il numero convertito in un suono di goccia di pioggia. Puoi usare la firma fornita se non sei sicuro dei tipi, ma non lasciare che limiti la tua creatività:

```haskell
convert :: Int -> String
```

Questo esercizio lavora con dati testuali. Per ragioni storiche, il tipo `String` di Haskell è sinonimo di `[Char]`, una lista di caratteri. Per una gestione più efficiente dei dati testuali, si può usare il tipo `Text`.

Come estensione facoltativa di questo esercizio, puoi

- Leggi qualcosa sui [tipi di stringa](https://haskell-lang.org/tutorial/string-types) in Haskell.
- Aggiungi `- text` all'elenco delle dipendenze in package.yaml.
- Importa `Data.Text` nel [modo seguente](https://hackernoon.com/4-steps-to-a-better-imports-list-in-haskell-43a3d868273c):

```haskell
import qualified Data.Text as T
import           Data.Text (Text)
```

- Ora puoi scrivere ad esempio `convert :: Int -> Text` e fare riferimento ai combinatori di `Data.Text` come ad esempio `T.pack`.
- Consulta la documentazione per [`Data.Text`](https://hackage.haskell.org/package/text/docs/Data-Text.html),
- Puoi quindi sostituire tutte le occorrenze di `String` con `Text` in Raindrops.hs:

```haskell
convert :: Int -> Text
```

Questa parte è del tutto facoltativa.
