# Approfondimento

Le stringhe di F# sono oggetti immutabili che rappresentano testo come una sequenza di caratteri Unicode (lettere, cifre, punteggiatura, ecc.). Per definire un'istanza di `string` si usano le virgolette doppie:

```fsharp
let fruit = "Apple"
```

Per manipolare una stringa si possono chiamare uno dei suoi [metodi][methods] o una delle sue [proprietà][properties], oppure usare una delle funzioni del [modulo `String`][string-module]. Poiché il valore di una stringa non può mai cambiare dopo essere stato definito, tutti i metodi e le funzioni di manipolazione delle stringhe restituiscono una nuova stringa.

Una stringa è delimitata da virgolette doppie (`"`). Alcuni caratteri speciali vanno [sottoposti a escape][escaping] usando il carattere barra rovesciata (`\`). Le stringhe possono anche essere precedute dal simbolo at (`@`), che le trasforma in una [stringa verbatim][verbatim], in cui i caratteri di escape vengono ignorati.

```fsharp
let escaped = "c:\\test.txt"
let verbatim = @"c:\test.txt"
escaped = verbatim
// => true
```

In alternativa, le stringhe si possono definire con le [triple virgolette][triple-quoted] (`"""`), che permettono di usare una virgoletta doppia all'interno della stringa senza doverla sottoporre a escape.

```fsharp
let tripledQuoted = """<movie title="Se7en" />"""
// => "<movie title="Se7en" />
```

Infine, si possono concatenare le stringhe con l'[operatore `+`][plus-operator]:

```fsharp
let name = "Jane"
"Hello " + name + "!"
// => "Hello Jane!"
```
