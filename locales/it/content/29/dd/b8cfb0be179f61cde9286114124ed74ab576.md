# Istruzioni

In questo esercizio implementerai la logica delle missioni di un nuovo gioco di ruolo a cui sta lavorando un amico.
La protagonista del gioco è Annalyn, una ragazza coraggiosa con un cane da compagnia feroce e fedele.
Purtroppo arriva la catastrofe: la sua migliore amica è stata rapita mentre cercava le bacche nel bosco.
Annalyn proverà a trovare e liberare la sua migliore amica, portando con sé il cane, se vuole.

Dopo aver seguito per un po' le tracce della sua migliore amica, trova l'accampamento in cui è imprigionata.
Scopre che i rapitori sono due: un cavaliere possente e un arciere astuto.

Avendo trovato i rapitori, Annalyn valuta quali delle seguenti azioni può intraprendere:

- _Attacco rapido_: si può sferrare un attacco rapido se il **cavaliere** sta **_dormendo_**, perché gli serve tempo per indossare l'armatura e quindi sarà vulnerabile.
- _Spia_: si può spiare il gruppo se **almeno uno** di loro è **_sveglio_**. Altrimenti spiare è una perdita di tempo.
- _Segnala il prigioniero_: si può inviare un segnale al prigioniero usando versi di uccelli se il **prigioniero** è **_sveglio_** e l'**arciere** sta **_dormendo_**, perché gli arcieri sono addestrati ai richiami degli uccelli e potrebbero intercettare il messaggio.
- _Libera il prigioniero_: Annalyn può provare a intrufolarsi nell'accampamento per liberare il prigioniero.
  È un'impresa rischiosa e può riuscire solo in uno dei due modi seguenti:
  - Se Annalyn ha con sé il suo cane, può liberare il prigioniero se l'**arciere** sta **_dormendo_**.
    Il cavaliere ha paura del cane e l'arciere non farà in tempo a prepararsi prima che Annalyn e il prigioniero riescano a scappare.
  - Se Annalyn non ha il cane, lei e il prigioniero devono essere molto furtivi!
    Annalyn può liberare il prigioniero se il **prigioniero** è **_sveglio_** e il **cavaliere** e l'**arciere** stanno entrambi **_dormendo_**, ma se il **prigioniero** sta **_dormendo_** non si può liberarlo: si spaventerebbe per l'apparizione improvvisa di Annalyn e sveglierebbe il cavaliere e l'arciere.

Hai quattro compiti: implementare la logica che determina se le azioni precedenti sono disponibili in base allo stato dei tre personaggi trovati nel bosco e alla presenza o meno del cane di Annalyn.

## 1. Verifica se l'azione «Attacco rapido» è possibile

Implementa una funzione chiamata `canFastAttack` che riceve un valore booleano che indica se il cavaliere è sveglio.
Questa funzione restituisce `true` se l'azione «Attacco rapido» è disponibile in base allo stato del personaggio.
Altrimenti restituisce `false`:

```php
<?php
$is_knight_awake = true;

$infiltration = new AnnalynsInfiltration();
$infiltration->canFastAttack($is_knight_awake);
// => false
```

## 2. Verifica se l'azione «Spia» è possibile

Implementa una funzione chiamata `canSpy` che riceve tre valori booleani, che indicano rispettivamente se il cavaliere, l'arciere e il prigioniero sono svegli.
La funzione restituisce `true` se l'azione «Spia» è disponibile in base allo stato dei personaggi.
Altrimenti restituisce `false`:

```php
<?php
$is_knight_awake = false;
$is_archer_awake = true;
$is_prisoner_awake = false;

$infiltration = new AnnalynsInfiltration();
$infiltration->canSpy($is_knight_awake, $is_archer_awake, $is_prisoner_awake);
// => true
```

## 3. Verifica se l'azione «Segnala il prigioniero» è possibile

Implementa una funzione chiamata `canSignal` che riceve due valori booleani, che indicano rispettivamente se l'arciere e il prigioniero sono svegli.
La funzione restituisce `true` se l'azione «Segnala il prigioniero» è disponibile in base allo stato dei personaggi.
Altrimenti restituisce `false`:

```php
<?php
$is_archer_awake = false;
$is_prisoner_awake = true;

$infiltration = new AnnalynsInfiltration();
$infiltration->canSignal($is_archer_awake, $is_prisoner_awake);
// => true
```

## 4. Verifica se l'azione «Libera il prigioniero» è possibile

Implementa una funzione chiamata `canLiberate` che riceve quattro valori booleani.
I primi tre parametri indicano rispettivamente se il cavaliere, l'arciere e il prigioniero sono svegli.
L'ultimo parametro indica se il cane di Annalyn è presente.
La funzione restituisce `true` se l'azione «Libera il prigioniero» è disponibile in base allo stato dei personaggi e alla presenza del cane di Annalyn.
Altrimenti restituisce `false`:

```php
<?php
$is_knight_awake = false;
$is_archer_awake = true;
$is_prisoner_awake = false;
$is_dog_present = false;

$infiltration = new AnnalynsInfiltration();
$infiltration->canLiberate(
    $is_knight_awake,
    $is_archer_awake,
    $is_prisoner_awake,
    $is_dog_present
);
// => false
```
