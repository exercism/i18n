## Eseguire i test

Per eseguire i test, lancia il comando seguente:

```bash
bats test-<exercise-slug>.bats
```

### bats è implementato in bash

Il file bats è uno script bash, con alcune funzioni speciali riconosciute dal comando `bats`.
Vedrai alcuni test che assomigliano a

```bash
sed -E -f <exercise-slug>.sed <<< "$input"
```

Quella sintassi `<<<` è una *Here String* di bash.
Invia la stringa a destra nell'input standard del programma a sinistra.
È più o meno equivalente a

```bash
echo "$input" | sed -E -f <exercise-slug>.sed
```

## Test saltati

Risolvere un esercizio significa far passare tutti i suoi test.
Per impostazione predefinita, quando esegui i test viene eseguito un solo test (il primo).
È intenzionale: così puoi concentrarti solo sul far passare quel test.
Una volta che passa, puoi abilitare il test successivo commentando o rimuovendo le

    [[ $BATS_RUN_SKIPPED == true ]] || skip

annotazioni anteposte agli altri test.

## Sovrascrivere i salti

Per eseguire tutti i test, compresi quelli con le annotazioni `skip`, puoi lanciare:

```bash
BATS_RUN_SKIPPED=true bats test-<exercise-slug>.bats
```

oppure puoi commentare o eliminare la riga:

```bash
[[ $BATS_RUN_SKIPPED == "true" ]] || skip
```

dal file di test.
