# Suggerimenti

## In generale

- Prova a suddividere un problema in un caso base e un caso ricorsivo. Per esempio, supponi di voler contare quanti biscotti ci sono nel barattolo dei biscotti con un approccio ricorsivo. Il caso base è un barattolo vuoto: contiene zero biscotti. Se il barattolo non è vuoto, allora il numero di biscotti nel barattolo è uguale a un biscotto più il numero di biscotti nel barattolo dopo averne rimosso uno.

## 1. Controlla quanti uccelli sono venuti oggi

- Questo compito non richiede la ricorsione.
- Per accedere al primo elemento di un array si può usare un'espressione case.

## 2. Incrementa il conteggio di oggi

- Questo compito non richiede la ricorsione.
- Per accedere al primo elemento di un array e al resto dell'array si può usare un'espressione case.

## 3. Controlla se c'è stato un giorno senza uccelli in visita

- Usa la ricorsione per iterare sugli elementi dell'array finché non trovi un giorno senza uccelli in visita.
- Il caso base è un array vuoto.

## 4. Calcola il numero totale di uccelli in visita

- Usa la ricorsione per iterare su ogni elemento dell'array.
- Il caso base è un array vuoto.

## 5. Calcola il numero di giorni affollati

- Usa la ricorsione per iterare su ogni elemento dell'array.
- Il caso base è un array vuoto.
- Usa una guardia per una delle clausole dell'espressione case.
