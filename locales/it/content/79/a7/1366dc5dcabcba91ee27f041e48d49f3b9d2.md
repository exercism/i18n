# Istruzioni

In questo esercizio organizzerai gare tra vari tipi di auto radiocomandate.
Ogni auto ha le proprie caratteristiche e gareggia su molte piste diverse nel corso della stagione del torneo.

~~~~exercism/note
Le funzioni in questo esercizio sono dichiarate in un file sorgente C con le firme fornite.
Il codice in assembly x86-64 deve seguire queste specifiche.
~~~~

## 1. Creare un'auto radiocomandata

Hai definito una struct `car_t` per rappresentare un'auto radiocomandata:

```c
struct car_t {
    char name[10];
    int16_t speed;
    float battery;
};
```

Consenti di creare un'auto radiocomandata definendo una funzione `new_car` in assembly x86-64.
Il campo `battery` inizia sempre con il valore `100.0`.

```c
struct car_t new_car(short speed, const char name[]);
```

## 2. Creare una nuova pista

Le piste sono rappresentate da una struct `track_t`:

```c
struct track_t {
    enum surface_t surface;
    size_t distance;
};
```

Il tipo `enum surface_t` tiene traccia delle diverse superfici di una pista:

```c
enum surface_t {
    ASPHALT,
    SAND,
    ICE,
    CLAY
};
```

Consenti di creare una nuova pista definendo una funzione `new_track` in assembly x86-64.

```c
struct track_t new_track(enum surface_t surface, size_t distance);
```

## 3. Creare un evento di gara

Fino a 6 auto partecipano a ogni gara, percorrendo un numero specificato di giri su una pista.
Le gare sono rappresentate da una struct `race_t`:

```c
struct race_t {
    struct track_t track;
    uint8_t num_of_laps;
    struct car_t cars[6];
    uint8_t num_of_running_cars;
};
```

Definisci una funzione `new_race` in assembly x86-64.
All'inizio, non ci sono auto la cui partecipazione sia confermata per la gara:

```c
struct race_t new_race(struct track_t track, uint8_t num_of_laps);
```

## 4. Confermare la partecipazione di un'auto alla gara

Quando il proprietario di un'auto chiede che partecipi a una gara, la sua partecipazione viene confermata solo se l'array non è già pieno.

Definisci una funzione `add_participant` in assembly x86-64.
Se c'è spazio per un altro partecipante nella gara, l'auto viene aggiunta all'array, aggiornando il contatore, e la sua partecipazione viene confermata.
Altrimenti, gli organizzatori della gara devono informare il proprietario dell'auto che questa volta non può partecipare.

```c
bool add_participant(struct race_t *race, struct car_t car);
```

## 5. Creare un torneo

Tieni traccia delle gare programmate per la stagione in una struct `tournament_t`:

```c
struct tournament_t {
    struct race_t races[20];
    size_t num_of_races;
};
```

Definisci una funzione `add_race` in assembly x86, per aggiungere una gara all'array del torneo e aggiornarne anche il contatore.
Puoi considerare che ci sarà sempre spazio sufficiente nell'array `races` per la nuova gara.

```c
void add_race(struct tournament_t *tournament, struct race_t race);
```
