# Introduzione

## Confrontare i numeri

In JavaScript i numeri si possono confrontare usando i seguenti operatori relazionali e di uguaglianza.

| Confronto              | Operatore |
| ---------------------- | --------- |
| Maggiore di            | `a > b`   |
| Maggiore o uguale a    | `a >= b`  |
| Minore di              | `a < b`   |
| Minore o uguale a      | `a <= b`  |
| Uguale (stretto)       | `a === b` |
| Non uguale (stretto)   | `a !== b` |

Il risultato del confronto è sempre un valore booleano, quindi `true` oppure `false`.

```javascript
1 < 3;
// => true

2 !== 2;
// => false

1 === 1.0;
// => true
// All numbers are floating-points, so this is different syntax for
// the exact same value.
```

## Confrontare le stringhe

In JavaScript, gli operatori di confronto visti sopra si possono usare anche per confrontare le stringhe.
In questo caso si applica un ordine alfabetico (lessicografico).
Puoi trovare un elenco con l'ordine esatto di tutti i caratteri [qui][utf-16-list].

```javascript
'Apple' > 'Pear';
// => false

'a' < 'above';
// => true

'a' === 'A';
// => false
```

## Uguaglianza stretta

Forse ti starai chiedendo perché in JavaScript per verificare l'uguaglianza si usano tre segni di uguale.
`===` rappresenta il controllo di _uguaglianza stretta_: significa che non viene eseguita alcuna conversione di tipo e che valori di tipi diversi sono sempre diversi.

```javascript
'3' === 3;
// => false
// The value on the left has type string, the value on the right has type number.

1 === 1n;
// => false
// The value on the left has type number, the value on the right has type bigint.
```

Usare `===` e `!==` è il modo consigliato per verificare l'uguaglianza in JavaScript.

Esistono anche `==` e `!=`, che rappresentano il controllo di _uguaglianza debole_.
È meglio evitarli, perché applicano una conversione di tipo implicita prima di eseguire il confronto.
In questi casi i risultati sono difficili da prevedere e talvolta non sono quelli che ti aspetti.

```javascript
0 == false;
// => true
```
