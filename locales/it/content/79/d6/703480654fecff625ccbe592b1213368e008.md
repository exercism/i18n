# Istruzioni

Ciao di nuovo, agente Double-Null0111.

Le forze di UMBRA si stanno muovendo di nuovo, e tocca a te sventare il loro ultimo piano.
Il nostro reparto di intelligence ci informa che quei Minions hanno in programma di far scoppiare una bomba puzzolente al ballo del Governatore.

Dato che i Minions sono così maldestri, spesso armano per sbaglio le bombe puzzolenti nei loro laboratori e nei loro uffici.
E dato che continuano a dimenticare come disinnescarle, hanno messo in piedi un sistema che genera le istruzioni di disinnesco, elencando l'ordine in cui i fili devono essere tagliati a partire dal numero ID della bomba.

Il tuo compito è scrivere il codice che ti permetterà di disinnescare la bomba puzzolente del ballo prima che esploda.

## 1. Scrivi una closure per scambiare due fili

Ogni bomba puzzolente ha tre fili di colori diversi.
Scrivi una closure che prende una tupla `(String, String, String)` e restituisce la tupla con l'ordine dei primi due elementi scambiato.
Assegna questa closure al nome `flip`.

È importante notare che il tipo deve essere `ChangeClosure` (o un tipo sendable), la definizione del tipo è fornita nel file stub.
Altrimenti il codice non compilerà.

```swift
flip(("red", "yellow", "blue"))
// Returns ("yellow", "red", "blue")
```

## 2. Scrivi una closure per ruotare i fili

Scrivi una closure che prende una tupla `(String, String, String)` e restituisce la tupla con l'ordine dei fili ruotato verso sinistra.
Assegna questa closure al nome `rotate`.

È importante notare che il tipo deve essere `ChangeClosure` (o un tipo sendable), la definizione del tipo è fornita nel file stub.

```swift
rotate(("red", "yellow", "blue"))
// Returns ("yellow", "blue", "red")
```

## 3. Implementa un generatore di mescolamento dei fili

Per capire in quale ordine tagliare i fili della bomba puzzolente, dovrai implementare una funzione che genera la giusta funzione di mescolamento in base al numero ID della bomba puzzolente.

Implementa la funzione:

```swift
makeShuffle(
  flipper: @escaping ((String, String, String)) -> (String, String, String),
  rotator: @escaping ((String, String, String)) -> (String, String, String)
) -> ([UInt8], (String, String, String)) -> (String, String, String)
```

che prende in input una closure che scambia due fili ed una closure che ruota i tre fili, e restituisce una closure.
Questa closure restituita prende il numero ID della bomba puzzolente e l'ordine dei tre fili, e poi calcola l'ordine in cui i fili devono essere tagliati.
Il numero ID è composto da otto bit, ed ogni bit determina se scambiare o ruotare i fili.

Per ogni bit del numero ID, partendo da quello più a destra, applicherai la closure `flipper` alla tupla dei fili se il bit è 0, ed applicherai la closure `rotator` se è 1, ottenendo il nuovo stato dei fili.
Dopo aver applicato le closure appropriate per tutti gli otto bit dell'ID, lo stato finale dei fili è l'ordine in cui devono essere tagliati.

```swift
let shuffler = makeShuffle(flipper: flip, rotator: rotate)
// Returns ([UInt8], (String, String, String)) -> (String, String, String)
shuffler([1, 0, 0, 1, 1, 0, 1, 1], ("red", "yellow", "blue"))
// Returns ("red", "blue", "yellow")
```
