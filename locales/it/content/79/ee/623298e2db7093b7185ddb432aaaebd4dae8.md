# Appendice alle istruzioni

## Formati di output

La funzione `treeFromTraversals` deve restituire un oggetto con 3 proprietà:

- `value` Il valore del nodo corrente
- `left` Un oggetto che contiene il figlio sinistro del nodo
- `right` Un oggetto che contiene il figlio destro del nodo

```javascript
{
    value: 'a',
    left: { value: 'i', left: {}, right: {} },
    right: { value: 'x', left: {}, right: {} },
}
```

Se l'albero è vuoto, va restituito un oggetto vuoto.
