# Informazioni

In Common Lisp, i valori falsi sono rappresentati dalla lista vuota (`()`) o dal simbolo `nil`.
Questi valori possono essere quotati o non quotati.

```lisp
;; Equivalent False Values
()   ; => NIL
nil  ; => NIL
'()  ; => NIL
'nil ; => NIL
```

Tutti gli altri valori in Lisp rappresentano il vero.
Esiste anche il simbolo costante speciale `t`, che è sempre uguale a `t` (ed è quindi sempre vero).

```lisp
;; Some Different True Values
42                        ; => 42
"this statement is false" ; => "this statement is false"
t                         ; => T
't                        ; => T
```
