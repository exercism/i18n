# Introduzione

In C#, il letterale `null` viene usato per indicare l'assenza di un valore. Un tipo _nullable_ è un tipo che ammette valori `null`.

Prima di C# 8.0, i tipi di riferimento erano sempre nullable e i tipi valore no. Un tipo valore può comunque essere reso nullable aggiungendogli un punto interrogativo (`?`).

```csharp
string nullableReferenceType = "hello";
nullableReferenceType = null; // Valid as type is nullable

int nonNullableValueType = 5;
nonNullableValueType = null; // Compile error as type is not nullable

int? nullableValueType = 5; // Define nullable value type
nullableValueType = null;   // Valid as type is nullable
```

Accedere a un membro di una variabile il cui valore è `null` viene compilato senza problemi, ma in fase di esecuzione comporta la generazione di un'eccezione `NullReferenceException`:

```csharp
string sentence = null;

// Throws NullReferenceException at runtime
sentence.Length;
```

Per contrastare questo tipo comune di errore, C# 8 permette di attivare una funzionalità che rende i tipi di riferimento non nullable per impostazione predefinita:

```csharp
string nonNullableReferenceType = "book";
nonNullableReferenceType = null; // Compile warning (no error!)

string? nullableReferenceType = "movie";
nullableReferenceType = null; // Valid as type is nullable
```

Per lavorare in sicurezza con valori nullable, conviene controllare se sono `null` prima di usarli:

```csharp
string NormalizedName(string? name)
{
    if (name == null)
    {
        return "UNKNOWN";
    }
    else
    {
        // Value is not null at this point, so no compile warning
        // and no runtime NullReferenceException being thrown
        return name.ToUpper();
    }
}

NormalizedName(null); // => "UNKNOWN"
NormalizedName("Elisabeth"); // => "ELISABETH"
```

L'operatore `??` permette di restituire un valore predefinito quando il valore è `null`:

```csharp
string? name1 = "John";
name1 ?? "Paul"; // => "John"

string? name2 = null;
name2 ?? "George"; // => "George"
```

L'operatore `?.` permette di chiamare i membri in sicurezza su un valore che potrebbe essere `null`:

```csharp
string? fruit = "apple";
fruit?.Length; // => 5

string? vegetable = null;
vegetable?.Length; // => null
```
