# Istruzioni

La tua associazione di quartiere ti ha chiesto di realizzare una semplice applicazione di registro per gestire le registrazioni dell'orto comunitario. La struct `Plot` è già stata fornita.

## 1. Apri l'orto

Implementa la funzione `CommunityGarden.start/1`: deve ricevere una keyword list facoltativa di opzioni da inoltrare al processo _agent_. Lo stato iniziale dell'orto va inizializzato in modo che rappresenti una collezione vuota di appezzamenti. Deve restituire una tupla `:ok` con il pid dell'orto.

```elixir
{:ok, pid} = CommunityGarden.start()
# => {:ok, #PID<0.112.0>}
```

## 2. Elenca le registrazioni

Implementa la funzione `CommunityGarden.list_registrations/1`. Deve ricevere il `pid` dell'orto comunitario. Deve restituire una lista degli appezzamenti memorizzati che sono registrati.

```elixir
CommunityGarden.list_registrations(pid)
# => []
```

> A questo punto, non abbiamo ancora aggiunto la possibilità di registrare un appezzamento, quindi questa lista dovrebbe essere vuota

## 3. Registra gli appezzamenti a una persona

Implementa la funzione `CommunityGarden.register/2`. Deve ricevere il `pid` dell'orto comunitario e un nome a cui registrare l'appezzamento. In caso di successo, deve restituire la struct `Plot` con l'id dell'appezzamento e la persona a cui è registrato.

Gli id devono essere incrementali e unici. Puoi tenere un contatore di id nello stato dell'agent.

```elixir
CommunityGarden.register(pid, "Emma Balan")
# => %Plot{plot_id: 1, registered_to: "Emma Balan"}
CommunityGarden.list_registrations(pid)
# => [%Plot{plot_id: 1, registered_to: "Emma Balan"}]
```

## 4. Rilascia gli appezzamenti

Implementa la funzione `CommunityGarden.release/2`. Deve ricevere il `pid` e l'`id` dell'appezzamento da rilasciare. Deve restituire `:ok` in caso di successo. Quando un appezzamento viene rilasciato, l'id non viene riutilizzato: serve solo come identificatore unico.

```elixir
CommunityGarden.release(pid, 1)
# => :ok
CommunityGarden.list_registrations(pid)
# => []
```

## 5. Ottieni un appezzamento registrato

Implementa la funzione `CommunityGarden.get_registration/2`. Deve ricevere il `pid` e l'`id` dell'appezzamento da controllare. Deve restituire l'appezzamento se è registrato, e `:not_found` se non è registrato.

```elixir
CommunityGarden.get_registration(pid, 1)
# => %Plot{plot_id: 1, registered_to: "Emma Balan"}
CommunityGarden.get_registration(pid, 7)
# => {:not_found, "plot is unregistered"}
```
