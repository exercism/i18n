# Istruzioni

In questo esercizio, implementerai le meccaniche di un gioco di ruolo.
Il personaggio di un giocatore è rappresentato dal seguente tipo:

```elm
type alias Player =
    { name : Maybe String
    , level : Int
    , health : Int
    , mana : Maybe Int
    }
```

In questo gioco, i giocatori devono raggiungere il livello 10 prima di sbloccare una riserva di mana, così da poter iniziare a lanciare incantesimi.
Stai lavorando a due funzionalità di questo gioco: la meccanica di rianimazione e quella di lancio degli incantesimi.

## 1. Presentati

Scrivi il contenuto della funzione `introduce`.
I giocatori furtivi potrebbero nascondere il proprio nome e verranno presentati come `"Mighty Magician"`.
Altrimenti, usa semplicemente il tuo nome per presentarti.

```elm
introduce { name = Nothing, level = 2, health = 8, mana = Nothing }
    --> "Mighty Magician"

introduce { name = Just "Merlin", level = 2, health = 8, mana = Nothing }
    --> "Merlin"
```

## 2. Implementa la meccanica di rianimazione

La funzione `revive` deve controllare che il personaggio del giocatore sia effettivamente morto (la sua salute ha raggiunto 0).
Se lo è, deve restituire una nuova istanza di `Player` con 100 di salute.
Altrimenti, se il personaggio del giocatore non è morto, la funzione `revive` restituisce `Nothing`.

Se il livello del giocatore è pari o superiore a 10, deve essere rianimato anche con 100 di mana.
Se il livello del giocatore è inferiore a 10, il suo mana deve essere `Nothing`.
La funzione `revive` deve preservare il livello del giocatore.

```elm
deadPlayer = { name = Nothing, level = 2, health = 0, mana = Nothing }

revive deadPlayer
    --> Just { name = Nothing, level = 2, health = 100, mana = Nothing }
```

Se il metodo `revive` viene chiamato su un giocatore la cui salute è pari o superiore a 1, la funzione deve restituire `Nothing`.

```elm
alivePlayer = { name = Nothing, level = 2, health = 42, mana = Nothing }

revive alivePlayer
    --> Nothing
```

## 3. Implementa la meccanica di lancio degli incantesimi

La funzione `castSpell` prende come argomenti un `Int` che indica quanto mana costa l'incantesimo, oltre a un `Player`.
Restituisce il giocatore aggiornato, oltre alla quantità di danno che l'incantesimo lanciato infligge.
Un incantesimo lanciato con successo infligge un danno pari al doppio del costo in mana dell'incantesimo.
Tuttavia, se il giocatore ha mana insufficiente, non succede nulla, il giocatore rimane invariato e non viene inflitto alcun danno.
Se il giocatore non ha nemmeno una riserva di mana, il tentativo di lanciare l'incantesimo deve ridurre la sua salute del costo in mana dell'incantesimo e non infliggere alcun danno.

```elm
wizard = { name = Nothing, level = 18, health = 123, mana = Just 30 }

( updatedWizard, damage ) = castSpell 14 wizard

updatedWizard.mana --> Just 16
damage             --> 28
```
