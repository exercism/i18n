# Introduzione

La maggior parte delle parole di Factor che lavorano sulle sequenze restituisce sequenze *nuove* e lascia invariati i loro input, ma sia gli array sia i vettori supportano anche la **mutazione in place** quando vuoi registrare uno stato che si evolve nel tempo.

`set-nth` e `change-nth` modificano una posizione in place, e funzionano sia su un array sia su un vettore. `<array>` costruisce un array mutabile a lunghezza fissa; i letterali `V{ }`, `<vector>`, `push` e `pop` sono riservati ai soli vettori, dato che gli array non possono cambiare lunghezza. `clone` duplica la sequenza, così le mutazioni successive non si ripercuotono sull'originale.

```factor
USING: arrays kernel sequences ;

5 0 <array>                 ! a fresh array { 0 0 0 0 0 }
dup 7 2 swap set-nth        ! { 0 0 7 0 0 } — set position 2 to 7
.

V{ } clone                  ! a fresh, empty vector
"alice" over push           ! V{ "alice" }
"bob" over push             ! V{ "alice" "bob" }
dup pop .                   ! "bob"
.                           ! V{ "alice" }
```
