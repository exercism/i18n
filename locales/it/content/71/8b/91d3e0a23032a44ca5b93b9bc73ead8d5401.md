# Istruzioni

In questo esercizio gestirai un sistema di inventario.

L'inventario dovrebbe essere organizzato in base al nome degli elementi e tenere traccia del numero di elementi disponibili.

Dovrai occuparti di aggiungere elementi a un inventario.
Ogni volta che un elemento compare in un array dato, la sua quantità nell'inventario dovrebbe aumentare di `1`.
Dovrai anche occuparti di eliminare elementi da un inventario diminuendo le quantità di `1` quando richiesto.

Infine, dovrai implementare una funzione che restituisca tutte le coppie chiave-valore di un inventario dato come `list` di `tuples`.


## 1. Crea un inventario a partire da un array

Implementa la funzione `create_inventory(<input list>)` che crea un «inventario» a partire da un array di elementi in input.
Dovrebbe restituire un `dict` che associa a ogni nome di elemento la rispettiva quantità.

```python
>>> create_inventory(["coal", "wood", "wood", "diamond", "diamond", "diamond"])
{"coal":1, "wood":2, "diamond":3}
```

## 2. Aggiungi elementi da un array a un dizionario esistente

Implementa la funzione `add_items(<inventory dict>, <item list>)` che aggiunge un array di elementi all'inventario passato:

```python
>>> add_items({"coal":1}, ["wood", "iron", "coal", "wood"])
{"coal":2, "wood":2, "iron":1}
```

## 3. Decrementa gli elementi dell'inventario

Implementa la funzione `decrement_items(<inventory dict>, <items list>)` che riceve una `list` di elementi.
La funzione dovrebbe sottrarre `1` al conteggio di un elemento ogni volta che quell'elemento compare nella `list`:

```python
>>> decrement_items({"coal":3, "diamond":1, "iron":5}, ["diamond", "coal", "iron", "iron"])
{"coal":2, "diamond":0, "iron":3}
```

I conteggi degli elementi nell'inventario non dovrebbero mai scendere sotto 0.
Se il numero di volte in cui un elemento compare nella `list` di input supera la quantità disponibile, la quantità indicata per quell'elemento dovrebbe restare a 0.
Le ulteriori richieste di rimozione vanno ignorate una volta che il conteggio arriva a zero.

```python
>>> decrement_items({"coal":2, "wood":1, "diamond":2}, ["coal", "coal", "wood", "wood", "diamond"])
{"coal":0, "wood":0, "diamond":1}
```

## 4. Rimuovi del tutto una voce dall'inventario

Implementa la funzione `remove_item(<inventory dict>, <item>)` che rimuove completamente un elemento ed il suo conteggio da un inventario:

```python
>>> remove_item({"coal":2, "wood":1, "diamond":2}, "coal")
{"wood":1, "diamond":2}
```

Se l'elemento non si trova nell'inventario, la funzione dovrebbe restituire l'inventario originale invariato.

```python
>>> remove_item({"coal":2, "wood":1, "diamond":2}, "gold")
{"coal":2, "wood":1, "diamond":2}
```

## 5. Restituisci l'intero contenuto dell'inventario

Implementa la funzione `list_inventory(<inventory dict>)` che riceve un inventario e restituisce un array di tuple `(item, quantity)`.
L'array dovrebbe includere solo gli elementi _disponibili_ (_con una quantità maggiore di zero_):

```python
>>> list_inventory({"coal":7, "wood":11, "diamond":2, "iron":7, "silver":0})
[('coal', 7), ('diamond', 2), ('iron', 7), ('wood', 11)]
```
