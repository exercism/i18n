# Introduzione

## Le basi

Java è un linguaggio a tipizzazione statica: il tipo di una variabile è noto in fase di compilazione.
Assegnare un valore a un nome si chiama definire una variabile.
Una variabile si definisce specificando esplicitamente il suo tipo.

```java
int explicitVar = 10;
```

L'aggiornamento del valore di una variabile avviene tramite l'operatore `=`.
Qui, `=` non rappresenta l'uguaglianza matematica.
Assegna semplicemente un valore a una variabile.
Una volta definita, il tipo di una variabile non può mai cambiare.

```java
int count = 1; // Assign initial value
count = 2;     // Update to new value

// Compiler error when assigning a different type
// count = false;
```

Java è un [linguaggio orientato agli oggetti][object-oriented-programming] e richiede che tutte le funzioni siano definite all'interno di una _classe_.
La parola chiave `class` serve a definire una classe.

```java
class Calculator {
    // ...
}
```

Una funzione all'interno di una classe viene chiamata _metodo_.
Ogni metodo può avere zero o più parametri.
Tutti i parametri devono avere un tipo esplicito: non c'è inferenza di tipo per i parametri.
Allo stesso modo, anche il tipo restituito deve essere esplicito.
I valori vengono restituiti dai metodi tramite la parola chiave `return`.
Per permettere che un metodo venga chiamato da altre classi, bisogna aggiungere il modificatore di accesso `public`.

```java
class Calculator {
    public int add(int x, int y) {
        return x + y;
    }
}
```

Per chiamare un metodo, si specificano il nome della classe e quello del metodo e si passano gli argomenti per ciascuno dei parametri del metodo.

```java
int sum = new Calculator().add(1, 2);  // here the  "add" method has been called to perform the task of addition
```

Lo scope in Java è definito tra i caratteri `{` e `}`.

Java supporta due tipi di commenti.
I commenti su una sola riga sono preceduti da `//`, mentre i commenti su più righe sono inseriti tra `/*` e `*/`.

[object-oriented-programming]: https://docs.oracle.com/javase/tutorial/java/javaOO/index.html
