# Test

## Eseguire i test

Quando ti trovi nella directory di un esercizio, dovresti vedere due sottodirectory:

* `Sources/<Exercise>` contiene la soluzione dell'esercizio
* `Tests/<Exercise>Tests` contiene i test da eseguire per l'esercizio

Se ti trovi nella directory giusta (cioè quella che contiene `Sources` e `Tests`), puoi eseguire i test per quell'esercizio con il comando `swift test`:

```bash
$ pwd
/Users/johndoe/Code/exercism/swift/hello-world

$ ls
HELP.md  Package.swift  README.md  Sources  Tests

$ swift test
```

Quando riesci a far passare un test, rimuovi `.enabled(if: RUNALL)` nell'istruzione `@Test` per abilitare il test successivo. In alternativa, puoi eseguire tutti i test impostando la variabile d'ambiente `RUNALL` su `true` su Linux o macOS:

```bash
$ export RUNALL=true
```

Oppure, se usi PowerShell su Windows:

```powershell
set RUNALL=true
```

## Inviare la soluzione

Per inviare una soluzione a Exercism, devi trovarti nella directory che contiene le directory `Sources` e `Tests`.

```bash
$ exercism submit 
```
