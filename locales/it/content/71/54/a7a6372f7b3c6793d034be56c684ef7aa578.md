# Istruzioni

Elyse, aspirante maga, deve fare pratica con alcune basi.
Ha una pila di carte che vuole manipolare.

Per rendere le cose un po' più semplici, usa solo le carte dall'1 al 10.

## 1. Crea una slice con determinate carte

Quando si esercita con le sue carte, Elyse preferisce iniziare con le sue tre carte preferite del mazzo: 2, 6 e 9.
Scrivi una funzione `FavoriteCards` che restituisce una slice con quelle carte in quell'ordine.

```go
cards := FavoriteCards()
fmt.Println(cards)
// Output: [2 6 9]
```

## 2. Recupera una carta da una pila

Restituisci la carta alla posizione `index` della pila data.

```go
card := GetItem([]int{1, 2, 4, 1}, 2) // card == 4
```

Se l'indice è fuori dai limiti (cioè se è negativo o oltre la fine della pila), vogliamo restituire `-1`:

```go
card := GetItem([]int{1, 2, 4, 1}, 10) // card == -1
```

~~~~exercism/note
Per convenzione in Go, si restituisce un errore invece di restituire un valore «fuori dai limiti».
Qui il valore «fuori dai limiti» è `-1` quando ci si aspetta un intero positivo.
Quando si restituisce un errore, è considerato idiomatico restituire lo [`zero value`](https://www.geeksforgeeks.org/zero-value-in-golang/) insieme all'errore.
Restituire un errore con il valore restituito corretto sarà trattato in un esercizio futuro.
~~~~

## 3. Scambia una carta nella pila

Scambia la carta alla posizione `index` con la nuova carta fornita e restituisci la pila aggiornata.
Nota che questo modificherà la slice di input, che è il comportamento previsto.

```go
index := 2
newCard := 6
cards := SetItem([]int{1, 2, 4, 1}, index, newCard)
fmt.Println(cards)
// Output: [1 2 6 1]
```

Se l'indice è fuori dai limiti (cioè se è negativo o oltre la fine della pila), vogliamo aggiungere la nuova carta in fondo alla pila:

```go
index := -1
newCard := 6
cards := SetItem([]int{1, 2, 4, 1}, index, newCard)
fmt.Println(cards)
// Output: [1 2 4 1 6]
```

## 4. Aggiungi carte in cima alla pila

Aggiungi la carta (o le carte) specificate nel parametro `value` in cima alla pila.

```go
slice := []int{3, 2, 6, 4, 8}
cards := PrependItems(slice, 5, 1)
fmt.Println(cards)
// Output: [5 1 3 2 6 4 8]
```

Se non viene fornito alcun argomento per il parametro `value`, il risultato è uguale alla slice originale.

```go
slice := []int{3, 2, 6, 4, 8}
cards := PrependItems(slice)
fmt.Println(cards)
// Output: [3 2 6 4 8]
```

## 5. Rimuovi una carta dalla pila

Rimuovi la carta alla posizione `index` dalla pila e restituisci la pila.
Nota che questo potrebbe modificare la slice di input, il che va bene.

```go
cards := RemoveItem([]int{3, 2, 6, 4, 8}, 2)
fmt.Println(cards)
// Output: [3 2 4 8]
```

Se l'indice è fuori dai limiti (cioè se è negativo o oltre la fine della pila), vogliamo lasciare la pila invariata:

```go
cards := RemoveItem([]int{3, 2, 6, 4, 8}, 11)
fmt.Println(cards)
// Output: [3 2 6 4 8]
```
