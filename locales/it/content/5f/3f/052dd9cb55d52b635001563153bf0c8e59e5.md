# Introduzione

## I record

Un record è una raccolta di campi (che possono essere di tipi diversi) che stanno insieme. Per definire un record si usa la parola chiave `type`. I campi di un record si definiscono tra i caratteri `{` e `}`, e ogni campo ha un nome _e_ un tipo. Per creare un record, specifica i nomi dei campi e assegna loro un valore tra i caratteri `{` e `}`. Quando crei un record, a tutti i campi va assegnato un valore. I valori dei campi di un'istanza di un record si possono leggere con la notazione con il punto.

Quando definisci o crei un record, ogni campo deve stare su una riga separata oppure, se sono tutti su una sola riga, essere separati da punti e virgola (`;`).

```fsharp
// Define a record
type Address =
    { Street: string
      HouseNumber: int }

// Create a record
let oldAddress: Address =
    { Street = "Main Street"
      HouseNumber = 17 }

// Single-line alternative
type ConciseAddress = { Street: string; HouseNumber: int }
let conciseAddress: ConciseAddress = { Street = "Main Street"; HouseNumber = 17 }
```

Poiché i record sono immutabili, una volta costruito un record i valori dei suoi campi non possono più cambiare. Se vuoi cambiare i valori di un record, la parola chiave `with` ti permette di creare una copia di un record esistente, ma con nuovi valori per uno o più campi.

```fsharp
// Copy the old address but change the house number
let newAddress: Address = { oldAddress with HouseNumber = 86 }
newAddress.Street      // => "Main Street"
newAddress.HouseNumber // => 86
```

I record hanno l'_uguaglianza strutturale_: due istanze dello stesso record con valori identici sono equivalenti.

Oltre a poter usare la notazione con il punto per accedere ai campi di un record, i record si possono anche _destrutturare_ nei binding e nel pattern matching:

```fsharp
let myAddress: Address = { Street = "Broadway"; HouseNumber = 123 }
let { Street = myStreet; HouseNumber = myHouseNumber } = myAddress

match myAddress with
| { HouseNumber = 1 } -> printfn "First house"
| { HouseNumber = houseNumber; Street = street } -> printfn "House number %d on %s" houseNumber street
// => "House number 123 on Broadway
```
