# Test

## Scrivere il codice

Scrivi il codice in `src/lib.cairo`.
Gli esercizi includono un file stub in `src/lib.cairo` che ti mostrerà le firme del codice che dovrai scrivere.

Per la maggior parte degli esercizi, conviene scrivere tutto il codice nel file `src/lib.cairo`.
Se vuoi dividere la soluzione in più file, consulta il [capitolo sui moduli][chapter-modules] di The Cairo Book.

[chapter-modules]: https://book.cairo-lang.org/ch07-02-defining-modules-to-control-scope.html

## Eseguire i test

Per eseguire i test, per prima cosa devi spostarti nella directory dell'esercizio che vuoi testare:

```bash
cd path/to/exercise
```

Poi esegui questo comando:

```bash
scarb cairo-test
```

Per impostazione predefinita è abilitato solo il primo test.
Quando sei pronto a superare il test successivo, rimuovi il flag `ignore` dal test successivo (`#[ignore]`).

Per eseguire tutti i test, compresi quelli ignorati, puoi rimuovere il flag `ignore` da tutti i test oppure eseguire semplicemente:

```bash
scarb cairo-test --include-ignored
```

Scrivi pure il minimo indispensabile di codice per far passare i test.
I test che falliscono ti indicheranno cosa scrivere dopo.

Poiché Cairo controlla tutto il codice al momento della compilazione, potresti scoprire che i test non si compilano finché non scrivi il codice richiesto.
Anche i test contrassegnati con `ignore` vengono controllati al momento della compilazione.
Puoi [trasformare in commento][comments] i test che non si compilano iniziando ogni riga con `//`.
Poi, quando sei pronto a lavorare su quel test, puoi rimuovere il commento.
Cairo ha anche una macro speciale chiamata `panic!()`, che puoi usare nei percorsi di codice non ancora completati per far compilare il programma.

[comments]: https://book.cairo-lang.org/ch02-04-comments.html
