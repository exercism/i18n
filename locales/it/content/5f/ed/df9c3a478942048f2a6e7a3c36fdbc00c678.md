# Informazioni

Gli [operatori ternari][ternary-operators] permettono di definire condizioni if dentro le espressioni anziché in blocchi di istruzioni. Questo richiama gli approcci della programmazione funzionale e spesso rende il codice più espressivo e meno soggetto a errori.

L'operatore ternario combina 3 espressioni: una condizione seguita da un'espressione che viene valutata e restituita se la condizione è vera (la parte `if`, introdotta da `?`) e da un'espressione che viene valutata e restituita se la condizione è falsa (la parte `else`, introdotta da `:`).

```csharp
int a = 3, b = 4;
int max = a > b ? a : b;
// => 4
```

[ternary-operators]: https://docs.microsoft.com/en-us/dotnet/csharp/language-reference/operators/conditional-operator
