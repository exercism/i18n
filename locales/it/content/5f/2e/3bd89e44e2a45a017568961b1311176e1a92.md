# Installazione

## Linux

Bash, in quanto shell GNU, si trova su qualsiasi sistema GNU/Linux.
Su BSD e sugli altri derivati di UNIX probabilmente sarai tu a doverlo installare.
Se usi BSD, AIX o una distribuzione Linux che non include bash, consulta le risorse del tuo sistema operativo per l'installazione dei pacchetti non essenziali.

Nell'interfaccia grafica che preferisci, cerca un'applicazione chiamata "Terminal": potresti trovarla in una sezione "Administrative/System Tools".

Per verificare la versione di Bash disponibile, dalla riga di comando o dal terminale, esegui:

    echo $BASH_VERSION

Se la tua shell è `bash`, dovrebbe mostrare qualcosa di simile a:

    4.4.19(1)-release

A questo punto non dovresti aver bisogno di fare altro: bash è installato ed è nel tuo PATH, dato che è la tua shell attuale.

Se la tua shell non è bash, non c'è motivo di cambiarla.
Puoi scrivere ed eseguire script bash senza essere in una shell bash.

Per verificare la versione di bash installata, esegui:

```plain
bash --version
```

Mostrerà qualcosa di simile a questo:

```
GNU bash, version 4.4.19(1)-release (x86_64-pc-linux-gnu)
Copyright (C) 2016 Free Software Foundation, Inc.
License GPLv3+: GNU GPL version 3 or later <http://gnu.org/licenses/gpl.html>

This is free software; you are free to change and redistribute it.
There is NO WARRANTY, to the extent permitted by law.
```

Se non lo fa, è possibile che bash non sia installato.
Dovresti installarlo usando il gestore di pacchetti della tua distribuzione.

## Windows

Su Windows 10 puoi installare [WSL](https://docs.microsoft.com/en-us/windows/wsl/about).
Installa una distribuzione Linux completa (beh, i componenti senza interfaccia grafica) che gira nativamente su Windows.

In alternativa, puoi installare:

* [Cygwin](https://cygwin.com/)
* [git for windows](https://gitforwindows.org/)
* [MinGW](http://mingw.org/)
* una distribuzione Linux completa in [una macchina virtuale](https://docs.microsoft.com/en-us/virtualization/hyper-v-on-windows/about/)

## MacOS

Per Apple OSX:

* apri Finder,
* apri la cartella Applicazioni,
* apri la cartella Utility,
* infine apri l'applicazione `Terminal`.

Nota che la versione di bash installata su MacOS è molto vecchia, la 3.2.
Questo perché (i) le versioni più recenti di bash sono distribuite con licenza GPLv3 e (ii) Apple non vuole essere costretta a rispettare i termini di quella licenza.
Inoltre, Apple ha annunciato che bash scomparirà da MacOS: di recente la shell di login predefinita è stata [cambiata da bash a zsh](https://support.apple.com/en-us/HT208050).

Per ottenere una versione aggiornata di bash sul tuo Mac:

1. installa [Homebrew](https://brew.sh)
1. in un terminale, digita: `brew install bash`

Installa una versione aggiornata di bash in (credo) `/usr/local/bin/bash`, così la bash predefinita del sistema non viene sovrascritta: altri strumenti potrebbero fare affidamento su /bin/bash.

Se vuoi che venga avviata la bash di Homebrew quando digiti `bash`, modifica il file ~/.bash_profile (o ~/.profile) per mettere /usr/local/bin *prima* di /bin nel PATH:

    PATH=/usr/local/bin:$PATH
