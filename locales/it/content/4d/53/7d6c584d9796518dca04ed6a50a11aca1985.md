# Installazione

## Ubuntu (e la maggior parte delle altre distribuzioni basate su Debian)

Per compilare il codice in locale ti servono gcc e make, che puoi installare con

```shell
sudo apt install gcc make
```

Se non stai usando hardware ARM64, installa l'emulatore [QEMU][] e il cross-toolchain GCC per ARM64 con

```shell
sudo apt install qemu-user libc6-dev-arm64-cross gcc-aarch64-linux-gnu
```

## Windows

Usa il [Windows Subsystem for Linux][] con una distribuzione basata su Debian e segui le istruzioni per Ubuntu qui sopra.
In alternativa, configura una macchina virtuale Linux.

## macOS

Puoi avviare una macchina virtuale Linux con qualsiasi soluzione di virtualizzazione adatta (ad esempio [Lima][]).

[QEMU]: https://www.qemu.org/
[Windows Subsystem for Linux]: https://docs.microsoft.com/en-gb/windows/wsl/about
[Lima]: https://lima-vm.io/
