- Implementa il modulo, specificando il messaggio con una speciale [macro integrata per definire le eccezioni][defexception].
- I moduli possono essere annidati all'interno di altri moduli.

## 2. Errore quando si incontra uno stack underflow

- Implementa il modulo, specificando il messaggio con una speciale [macro integrata per definire le eccezioni][defexception].
- Puoi usare una delle callback del behaviour Exception per definire un'eccezione il cui messaggio cambia in base agli argomenti passati a `raise/2`.
- I moduli possono essere annidati all'interno di altri moduli.

## 3. Scrivi una funzione di divisione

- Scrivi una funzione a più clausole usando le guardie per il flusso di controllo.
- Puoi usare il pattern matching nella lista degli argomenti della funzione per associare i valori dello stack a delle variabili.
