# Suggerimenti

## 1. Ottieni la prima lettera del titolo

- Esiste [un metodo][index] che restituisce un `Char` da una `String` a un determinato indice.

## 2. Ottieni le iniziali degli autori

- Puoi usare metodi già implementati per ottenere la prima lettera di una `String`.
- Per combinare dei valori in una `String` puoi usare l'[interpolazione di stringhe][string-interpolation].

## 3. Decifra la lettera

- Esiste [un metodo][uppercase] per verificare se un `Char` è maiuscolo.
- Esiste [un metodo][ord] per ottenere il code point di un `Char`.

## 4. Decifra il testo

- Puoi usare un [ciclo][while] per eseguire il codice più volte.
