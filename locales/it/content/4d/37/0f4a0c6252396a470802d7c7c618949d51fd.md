# Suggerimenti

## 1. Trovare la posizione di una carta

- Gli indici degli array iniziano da `0`.
- Esiste un metodo [integrato][indexof_method_docs] per ottenere l'indice di un dato valore.

## 2. Determinare se una carta è presente

- Esiste un metodo [integrato][includes_method_docs] per verificare se il valore è presente nell'array

## 3. Determinare se ogni carta è pari

- Esiste un metodo [integrato][every_method_docs] per verificare se ogni valore supera un predicato

## 4. Verificare se la pila contiene una carta con valore dispari

- Esiste un metodo [integrato][some_method_docs] per verificare se almeno un valore supera un predicato

## 5. Ottenere la prima carta dispari dalla pila

- Esiste un metodo [integrato][find_method_docs] per ottenere il primo elemento che supera un predicato

## 6. Determinare la posizione della prima carta pari

- Esiste un metodo [integrato][findindex_method_docs] per ottenere il primo indice nell'array in cui il valore
