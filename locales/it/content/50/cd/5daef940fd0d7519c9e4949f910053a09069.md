# Collegamenti interni

I link renderizzati dal parser Markdown di Exercism vengono controllati per verificare se sono interni e, in tal caso, possono essere decorati con dei tooltip.

Un tooltip per un concetto potrebbe apparire così:

<img src="https://raw.githubusercontent.com/exercism/docs/main/.imgs/concept-tooltip.png" height="200">

## Utilizzo

Non esiste una sintassi speciale per decorare i link in questo modo.
Controlliamo invece se l'href del link segue una delle due forme:

- Un URL. Ad esempio https://exercism.org/tracks/ruby/concepts/basics
- Un percorso assoluto. Ad esempio /tracks/ruby/concepts/basics

Al momento non supportiamo gli URL relativi (ad esempio quelli che iniziano con `./` o `../`) perché il parser Markdown non conosce il contesto del documento che renderizza, il contesto in cui sta renderizzando, né la struttura di un repository git.

## Alternative

Invece di usare link normali, potresti voler renderizzare dei widget.
Questi vengono in genere usati alla fine di un documento per suggerire letture aggiuntive o buoni esercizi da cui imparare qualcosa.

Vedi [la documentazione sui widget](/docs/building/markdown/widgets) per maggiori dettagli.
