# Informazioni

Le variabili locali non sostituiscono il codice basato sullo stack: convivono con esso. Ricorri alle variabili locali quando:

- Lo stesso input viene referenziato più di una volta.
- L'ordine naturale delle operazioni non corrisponde all'ordine dello stack.
- Ti trovi dentro una parola di ordine superiore che passa più valori in una volta sola alla lambda (la `( key value -- newkey newvalue )` di `assoc-map`).

```factor
USING: locals ;

! Two references to ratio: stack-shuffled vs. local.
: average  ( a b -- avg ) + 2 / ;
:: average ( a b -- avg ) a b + 2 / ;        ! same effect
```

`[let code :> name code :> name ... body ]` introduce associazioni locali all'interno di una quotation o al listener, dove altrimenti `:>` non avrebbe uno scope lessicale in cui legare:

```factor
[let 5 :> x 10 :> y x y + ] .   ! => 15
```

Il suffisso di mutazione `:>` ti permette di riassociare una variabile locale: è utile nei cicli dal sapore imperativo:

```factor
:: collatz ( n -- count )
    n :> current!
    0 :> count!
    [ current 1 = ] [
        current odd?
        [ current 3 * 1 + current! ]
        [ current 2 / current! ] if
        count 1 + count!
    ] until
    count ;
```
