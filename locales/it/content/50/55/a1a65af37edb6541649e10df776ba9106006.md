# Test

Per eseguire i test, esegui il seguente comando:

```bash
make
```

## Test saltati

Risolvere un esercizio significa far passare tutti i suoi test.
Per impostazione predefinita, quando esegui i test viene eseguito un solo test, il primo.
La cosa è intenzionale: così puoi concentrarti solo sul far passare quel test.
Una volta che passa, puoi abilitare il test successivo rimuovendo la riga `TEST_IGNORE()`.
Quando tutti i test saranno abilitati e l'implementazione li farà passare tutti, avrai risolto l'esercizio!

## Debug

Per aiutarti con il debug, ci sono diverse macro definite in un file `debug.mac`.
Si possono chiamare con uno o più argomenti della dimensione appropriata.
Ad esempio:

```x86asm
debugf32 xmm0, xmm1 ; prints the value of two 32-bit floating-point numbers
debugd16 ax, cx, dx ; prints the value of three signed 16-bit integers
debugx64 [rax]      ; prints the value of a 64-bit integer in hexadecimal format
debugs rsi          ; prints a NUL-terminated string whose address is stored in `rsi`
debugu8_xmm xmm1    ; prints 16 packed 8-bit unsigned integers
```

Per usare una qualsiasi di queste macro, `debug.mac` deve essere incluso all'inizio del file della soluzione:

```x86asm
%include "debug.mac"
```
