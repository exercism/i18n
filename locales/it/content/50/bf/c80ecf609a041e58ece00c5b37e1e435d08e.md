# Informazioni

Le variabili dichiarate con la parola chiave `final` invece di `var` possono ricevere un valore una sola volta.

```haxe
final a = "hello";
var b = "world";
trace(a, b); // hello, world
b = "haxe";
trace(a, b); // hello, haxe

// The following line would cause a compilation error:
// a = "bye";
```

È importante notare che `final` potrebbe non avere l'effetto desiderato con i tipi che non sono immutabili, come gli array o gli oggetti:

```haxe
final a = [0, 1, 2];
trace(a); // [0,1,2]

// this would cause a compilation error:
// a = [0, 1, 2, 3];

// but the following line works:
a.push(3);
trace(a); // [0,1,2,3]
```
