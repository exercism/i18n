# Informazioni

La classe Lambda è una raccolta di metodi funzionali che permettono di usare la programmazione in stile funzionale con Haxe. Ci consente di operare su un intero Iterable in una sola volta. Spesso è preferibile rispetto ai cicli, perché è meno soggetto a errori e più facile da leggere. Per comodità, le classi Array e List contengono alcuni dei metodi più usati della classe Lambda.

Alcune delle funzioni della classe `Lambda` sono:

- `Lambda.array`, `Lambda.list` Convertono un Iterable in un Array o in una List. Restituiscono sempre una nuova istanza.
- `Lambda.count` Conta il numero di elementi. Se l'Iterable è un Array o una List, è più veloce usare la sua proprietà length.
- `Lambda.has` Determina se l'elemento specificato è presente nell'Iterable.
- `Lambda.indexOf` Trova l'indice dell'elemento specificato.
- `Lambda.find` Trova il primo elemento in base alla funzione di ricerca specificata.
- `Lambda.concat` Unisce due Iterable, restituendo una nuova List.
- `Lambda.filter` Trova gli elementi che soddisfano un criterio, restituendo una nuova List.

Un esempio che mostra alcune di queste funzioni:

```haxe
using Lambda;

class Main {
  static function main() {
    var words = ["boat", "dog", "phone", "cat", "food"];

    var isThreeLetters = function(word) return word.length == 3;

    trace(words.filter(isThreeLetters)); // [dog,cat]
  }
}
```
