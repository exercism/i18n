# Descrizione

La libreria di sequenze di Factor si affida molto alle *quotation*, cioè a codice racchiuso tra parentesi quadre (`[ ]`), per parametrizzare l'iterazione. La forma è sempre la stessa: passi una sequenza e una quotation, e la parola di ordine superiore esegue la quotation su ogni elemento.

```factor
{ 1 2 3 4 5 } [ even? ] filter .   ! => { 2 4 }
{ 1 2 3 4 5 } [ even? ] reject .   ! => { 1 3 5 }
{ 1 2 3 4 5 } [ 3 > ] find .s      ! => 3 / 4 (index, element)
{ 1 2 3 4 5 } [ sq ] map .         ! => { 1 4 9 16 25 }
{ 1 2 3 4 5 } [ . ] each           ! prints each element
0 { 1 2 3 4 5 } [ + ] reduce .     ! => 15
```

Ecco il repertorio comune completo:

| parola       | forma                                      |
|--------------|--------------------------------------------|
| `each`       | `( seq quot -- )`                          |
| `map`        | `( seq quot -- newseq )`                   |
| `filter`     | `( seq quot -- newseq )`                   |
| `reject`     | `( seq quot -- newseq )`                   |
| `find`       | `( seq quot -- i/f elt/f )`                |
| `find-last`  | `( seq quot -- i/f elt/f )`                |
| `reduce`     | `( seq init quot -- result )`              |
| `map-sum`    | `( seq quot -- n )`                        |
| `count`      | `( seq quot -- n )`                        |
| `any?`       | `( seq quot -- ? )`                        |
| `all?`       | `( seq quot -- ? )`                        |
| `with`       | `( value seq quot -- seq curry )`          |
| `without`    | `( seq exclude -- newseq )`                |
| `sort`       | `( seq -- sortedseq )`                     |
| `sum`        | `( seq -- n )`                             |
| `minimum`    | `( seq -- elt )`                           |
| `maximum`    | `( seq -- elt )`                           |
| `minimum-by` | `( seq quot -- elt )`                      |
| `maximum-by` | `( seq quot -- elt )`                      |

Quando la *tua* parola inoltra una quotation di runtime a uno di questi combinatori, dichiarala con `; inline`, così l'inferenza degli effetti del combinatore riesce a vedere la forma della quotation nel punto di chiamata. Le parole costruite solo con quotation letterali non ne hanno bisogno.

Oltre alle operazioni di base sulle sequenze:

| vocabolario       | fornisce                                      |
|--------------------|-----------------------------------------------|
| [`sorting`][sorting]          | `sort`, `sort-by`                             |
| [`math.statistics`][math.statistics]  | `cum-sum`, `cum-product`, `cum-min`, `cum-max` |
| [`grouping`][grouping]         | `group`, `clump`, `monotonic-split`           |
| [`sets`][sets]             | `members`, `all-unique?`                      |

Le coppie (`bi`, `tri`) e i combinatori «n-ary» (`2map`, `2each`, `zip`) estendono lo stesso schema quando la quotation richiede più di un input.
