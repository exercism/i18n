# Introduzione

L'I/O di Factor si basa sugli *stream*: oggetti da cui leggi byte o caratteri, oppure a cui li scrivi. Il vocabolario [`io`][io] ti offre due viste dello stesso [protocollo][stream-protocol].

## Le due viste

Le parole a **stream esplicito** prendono lo stream come argomento. Iniziano tutte con `stream-`:

```
stream-read       ( n stream -- seq/f )
stream-readln     ( stream -- str/f )
stream-write      ( seq stream -- )
stream-flush      ( stream -- )
stream-contents   ( stream -- seq )
stream-lines      ( stream -- seq )
```

Le parole ad **stream ambientale** leggono o scrivono sullo stream *attualmente associato*, la variabile dinamica a livello di programma `input-stream` o `output-stream`. Hanno nomi brevi:

```
read1 read readln write write1 print flush
```

La forma ambientale è quella che usa la maggior parte del codice di tutti i giorni. La forma esplicita è quella a cui ricorri quando hai tra le mani uno stream specifico e non vuoi sostituire quello ambientale.

## Stream in memoria

Per l'esercizio lavorerai con stream basati su stringhe, presi da [`io.streams.string`][io.streams.string]:

```
<string-reader>   ( str -- reader )
<string-writer>   ( -- writer )
```

Uno `<string-reader>` legge da una stringa letterale come se fosse un file; uno `<string-writer>` raccoglie tutto ciò che vi viene scritto, così puoi rileggerlo in seguito. Entrambi implementano lo stesso protocollo degli stream su file, quindi le lezioni si applicano direttamente a `<file-reader>` / `<file-writer>`.

## Definire lo scope con `with-…`

Per associare uno stream esplicito come quello ambientale per una quotation e rilasciarlo in seguito, usa un combinatore `with-…`:

```
with-input-stream    ( stream quot -- )
with-output-stream   ( stream quot -- )
with-string-writer   ( quot -- str )
with-file-reader     ( path encoding quot -- )
with-file-writer     ( path encoding quot -- )
```

[`with-string-writer`][with-string-writer] è la forma comoda per «raccogli ciò che stampa questa quotation»: costruisce il writer, esegue la quotation con quel writer come output ambientale e restituisce la stringa catturata:

```factor
USING: io io.streams.string ;

[ "captured" print ] with-string-writer .
! => "captured\n"
```

Tutti i combinatori `with-…` sono combinatori distruttori (della stessa famiglia di `with-disposal` e `with-destructors` di [`boatswains-bilge`][boatswains-bilge]): lo stream viene rilasciato all'uscita anche se la quotation solleva un'eccezione.
