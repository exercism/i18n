# Informazioni

[F#](https://try.fsharp.org/) è un linguaggio funzionale fortemente tipizzato, che fa parte dello stack di linguaggi .NET di Microsoft.

Sebbene F# sia ottimo per i problemi di data science, riesce a gestire con eleganza quasi ogni problema gli si presenti.

Poiché F# gira sul runtime .NET, hai accesso all'intero ecosistema .NET, compresi tutti i pacchetti su [nuget.org](https://www.nuget.org/).

L'integrazione con il codice .NET esistente è inoltre semplificata dal fatto che F# permette anche di scrivere codice orientato agli oggetti.

La home page di F# è [fsharp.org](http://fsharp.org/) e una splendida introduzione a F# si trova sul sito [F# for fun and profit](http://fsharpforfunandprofit.com/).
