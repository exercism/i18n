# Istruzioni

In questo esercizio lavorerai a un sistema di pianificazione degli appuntamenti per un salone di bellezza che ha aperto il 15 settembre 2012.

Hai cinque attività, che riguarderanno tutte le date degli appuntamenti.

## 1. Analizzare la data di un appuntamento

Implementa la funzione `Schedule` che analizza una rappresentazione testuale della data di un appuntamento e la converte nel formato `time.Time` corrispondente:

```go
Schedule("7/25/2019 13:45:00")
// => 2019-07-25 13:45:00 +0000 UTC
```

## 2. Verificare se un appuntamento è già passato

Implementa la funzione `HasPassed` che riceve una data di appuntamento e verifica se l'appuntamento è ormai nel passato:

```go
HasPassed("July 25, 2019 13:45:00")
// => true
```

## 3. Verificare se un appuntamento è nel pomeriggio

Implementa la funzione `IsAfternoonAppointment` che riceve una data di appuntamento e verifica se l'appuntamento cade nel pomeriggio (>= 12:00 e < 18:00):

```go
IsAfternoonAppointment("Thursday, July 25, 2019 13:45:00")
// => true
```

## 4. Descrivere l'ora e la data dell'appuntamento

Implementa la funzione `Description` che riceve una data di appuntamento e restituisce una descrizione di quella data e di quell'ora:

```go
Description("7/25/2019 13:45:00")
// => "You have an appointment on Thursday, July 25, 2019, at 13:45."
```

## 5. Restituire la data dell'anniversario dell'apertura del salone

Implementa la funzione `AnniversaryDate` che restituisce la data dell'anniversario dell'apertura del salone per l'anno corrente in UTC.

Ipotizzando che l'anno corrente sia il 2020:

```go
AnniversaryDate()

// => 2020-09-15 00:00:00 +0000 UTC
```

**Nota:** il valore restituito è un `time.Time` e l'ora del giorno non ha importanza.
