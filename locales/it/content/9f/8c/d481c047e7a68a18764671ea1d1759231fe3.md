# Istruzioni

Continuando il tuo lavoro al parco divertimenti, il tuo compito è scrivere alcuni metodi di utilità che aiutino a controllare se un visitatore può salire su un'attrazione.

## 1. Controlla se un visitatore ha un pass per l'attrazione

Implementa il metodo `Attendee#has_pass?` in modo che restituisca un valore booleano (`true`/`false`) in base alla presenza di un pass per l'attrazione.

```ruby
Attendee.new(100).has_pass?
# => false
```

## 2. Controlla se un visitatore è abbastanza alto per un'attrazione

Implementa il metodo `Attendee#fits_ride?` per verificare se un visitatore è abbastanza alto per un'attrazione, in base alla sua altezza.
L'altezza minima richiesta dall'attrazione viene fornita come argomento.
Un visitatore deve avere un'altezza maggiore o uguale all'altezza minima richiesta dall'attrazione.

```ruby
Attendee.new(140).fits_ride?(100)
# => true
```

## 3. Controlla se un visitatore è autorizzato a salire su un'attrazione

Implementa il metodo `Attendee#allowed_to_ride?` per verificare se un visitatore è autorizzato a salire su un'attrazione. L'altezza minima richiesta dall'attrazione viene fornita come argomento. Un visitatore deve avere un pass per l'attrazione ed essere abbastanza alto per l'attrazione.

```ruby
attendee = Attendee.new(100)
attendee.issue_pass!(42)
attendee.allowed_to_ride?(120)
# => false
```
