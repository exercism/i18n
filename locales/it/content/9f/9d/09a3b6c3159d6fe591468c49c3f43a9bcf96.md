# Le struct

Le struct sono tipi di dato personalizzati che ti permettono di dare un nome e raggruppare insieme più valori correlati.
Sono simili alle tuple, ma più flessibili e ti permettono di dare un nome a ogni dato, rendendo il codice più chiaro.
Le struct in Cairo hanno queste proprietà:

- Ogni tipo struct ha un nome specifico.
- Ogni membro di una struct è chiamato **campo**.
- Ogni campo di una struct ha un nome specifico.
- La visibilità è tracciata a livello di campo: ogni campo può essere indipendentemente pubblico o privato.

## Definire e istanziare le struct

Per definire una struct, usa la parola chiave `struct` seguita da un nome e da parentesi graffe che contengono i campi con i loro nomi e tipi:

```rust
#[derive(Drop)]
struct User {
    active: bool,
    username: ByteArray,
    email: ByteArray,
    sign_in_count: u64,
}
```

Per creare un'istanza di una `struct`, specifica il nome della `struct` e usa le parentesi graffe con coppie chiave-valore per i campi.
Nota che puoi elencare i campi in qualsiasi ordine quando crei un'istanza:

```rust
let user1 = User {
   active: true, username: "someusername123", email: "someone@example.com", sign_in_count: 1
};

let user2 = User {
    sign_in_count: 1, username: "someusername123", active: true, email: "someone@example.com"
};
```

## Interagire con un'istanza di una struct

Usa la notazione con il punto per accedere o modificare i campi di un'istanza di una `struct`.
Nota che per modificare un campo, l'istanza deve essere mutabile:

```rust
let mut user1 = User {
    active: true, username: "someusername123", email: "someone@example.com", sign_in_count: 1
};
user1.email = "anotheremail@example.com";
```

Come con qualsiasi espressione, possiamo costruire una nuova istanza della `struct` come ultima espressione nel corpo della funzione per restituire implicitamente quella nuova istanza:

```rust
fn build_user(email: ByteArray, username: ByteArray) -> User {
    User {
        email: email,
        username: username,
        active: true,
        sign_in_count: 1,
    }
}
```

## Abbreviazione per l'inizializzazione dei campi

Nell'ultimo esempio aveva senso dare ai parametri della funzione `email` e `username` gli stessi nomi dei campi della `struct`, ma doverli ripetere quando li assegniamo ai campi della struct è un po' noioso.
Per fortuna, esiste una comoda scorciatoia per inizializzare i campi di una struct da variabili con gli stessi nomi:

```rust
fn build_user_short(email: ByteArray, username: ByteArray) -> User {
    User { email, username, active: true, sign_in_count: 1, }
}
```

## Creare istanze da altre istanze con la sintassi di aggiornamento delle struct

Usa la sintassi di aggiornamento delle struct per creare una nuova istanza da una già esistente, cambiando alcuni campi e mantenendo gli altri uguali.
Questo si ottiene usando l'operatore `..`.

Senza la sintassi di aggiornamento:

```rust
let user2 = User {
    active: user1.active,
    username: user1.username,
    email: "another@example.com",
    sign_in_count: user1.sign_in_count,
};
```

Con la sintassi di aggiornamento:

```rust
let user2 = User { email: "another@example.com", ..user1 };
```

La sintassi `..user1` copia i campi rimanenti da `user1` a `user2`.
Nota che questo sposta i dati da `user1` a `user2`, quindi `user1` non può essere usato in seguito se contiene tipi non copiabili.
