# Appendice alle istruzioni

## Istruzioni specifiche della traccia

Per questo esercizio devi definire un **locale** chiamato `robot` che definisce i **sostantivi** `position` e `direction` e un **verbo** `move`.

- Il verbo `create` di `robot` prende la posizione e la direzione iniziali come array di box.
    
    ```j
      r=. (0 0;'north') conew 'robot'
    ```
- `move` aggiorna i valori di `position` e `direction` nell'**istanza** creata.
    ```j
      r=. (0,0;'north') conew 'robot'
      
      NB. initial state
      NB. ====================================
      position__r
        0 0
      direction__r
        north
      
      NB. new states after `move` is executed 
      NB. ====================================
      move__r 'LA'
      position__r
        _1 0
      direction__r
        west      
    ```
