# Numeri interi

I numeri interi sono numeri senza parte decimale che appartengono all'insieme `{..., -2, -1, 0, 1, 2, ...}`.
I valori massimi e minimi di un numero intero sono determinati dal sistema in cui PHP viene eseguito.
In genere, sulla maggior parte dei sistemi moderni, un numero intero è un valore a 64 bit, il che significa che può rappresentare da `-9_223_372_036_854_775_808` a `9_223_372_036_854_775_807` inclusi.

```php
<?php

$a = 1234;
$a = 1_234_567;
```

Puoi scrivere valori letterali interi in basi diverse dalla base 10 usando un prefisso di base:

```php
<?php

$a = 0123; // octal number (equivalent to 83 decimal)
$a = 0o123; // octal number (as of PHP 8.1.0)
$a = 0x1A; // hexadecimal number (equivalent to 26 decimal)
$a = 0b11111111; // binary number (equivalent to 255 decimal)
```
