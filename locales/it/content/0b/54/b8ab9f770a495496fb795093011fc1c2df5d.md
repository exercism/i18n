# Ignora

## Opzioni aggiuntive della riga di comando di jq

Noterai delle opzioni aggiuntive per `jq` nei test.

```sh
run jq -s -R -c -f flower-field.jq << 'END_INPUT'
```

Cosa sono?

- `-s`

  Questa è la modalità «slurp».
  Invece di gestire l'input come un flusso di oggetti JSON,
  l'intero input verrà raccolto in un array.

  ```sh
  $ seq 5 | jq -c '.'
  1
  2
  3
  4
  5
  $ seq 5 | jq -s -c '.'
  [1,2,3,4,5]
  ```

- `-R`

  Potresti aver già visto `-r`, per produrre stringhe «raw» (senza virgolette).
  Questa è l'opzione opposta.
  Ogni riga di input viene considerata una stringa.

  Due esempi:

  ```sh
  $ seq 5 | jq -R -c .
  "1"
  "2"
  "3"
  "4"
  "5"

  $ echo 42 | jq '. * 2'      # input is a JSON number
  84
  $ echo 42 | jq -R '. * 2'   # input is a JSON string
  "4242"
  ```

Quando combini queste due opzioni, _non_ ottieni un array di stringhe:
ottieni l'intero input come un'unica stringa, compresi i caratteri di nuova riga a fine riga.

```sh
$ seq 5 | jq -s -R -c .
"1\n2\n3\n4\n5\n"
```

Gestire questo fa parte della sfida di questo esercizio.
