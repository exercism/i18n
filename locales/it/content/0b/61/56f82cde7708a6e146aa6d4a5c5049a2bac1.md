# Informazioni

Gli argomenti di una funzione possono essere specificati in modo che la funzione accetti un numero qualsiasi di argomenti:

```php
<?php

function actOnItems(...$items) {
  // $items is an array containing 0 or more values
  // used to call the function.
}

actOnItems(1, 2, 3, 4); // $items => [1, 2, 3, 4]
```
