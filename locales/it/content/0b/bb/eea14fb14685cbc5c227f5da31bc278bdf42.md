# funzione main

Rimuovi la funzione `Main`: i test non ne hanno bisogno e rende il codice un po' più difficile da leggere.

Di solito la funzione `Main` viene aggiunta per aiutare a fare il debug del codice. Tuttavia, un approccio migliore è fare il debug del codice mentre si eseguono uno o più test unitari. Questo offre il vantaggio aggiuntivo di potersi concentrare sul debug di un caso di test specifico. Ecco alcuni link che spiegano come fare il debug del codice Scala mentre si eseguono i test unitari in vari IDE:

- [IntelliJ](https://www.jetbrains.com/help/idea/run-debug-and-test-scala.html)
- [Eclipse](http://scala-ide.org/docs/current-user-doc/features/scaladebugger/index.html)
