# Introduzione

Un record è una raccolta di campi (che possono essere di tipi diversi) che stanno insieme. Per definire un record si usa la parola chiave `type`. I campi di un record sono definiti tra i caratteri `{` e `}`, e ogni campo ha un nome _e_ un tipo. Per creare un record, specifica i nomi dei campi e assegna loro un valore tra i caratteri `{` e `}`. Tutti i campi devono ricevere un valore quando si crea un record. Si può accedere ai valori dei campi di un'istanza di record usando la notazione puntata.

Quando definisci o crei un record, ogni campo deve trovarsi su una riga separata oppure, se si trova sulla stessa riga, essere separato da punti e virgola (`;`).

```fsharp
// Define a record
type Address =
    { Street: string
      HouseNumber: int }

// Create a record
let oldAddress: Address =
    { Street = "Main Street"
      HouseNumber = 17 }

// Single-line alternative
type ConciseAddress = { Street: string; HouseNumber: int }
let conciseAddress: ConciseAddress = { Street = "Main Street"; HouseNumber = 17 }
```

Poiché i record sono immutabili, una volta costruito un record, i valori dei suoi campi non possono mai cambiare. Se vuoi cambiare i valori di un record, la parola chiave `with` consente di creare una copia di un record esistente, ma con nuovi valori per uno o più campi.

```fsharp
// Copy the old address but change the house number
let newAddress: Address = { oldAddress with HouseNumber = 86 }
newAddress.Street      // => "Main Street"
newAddress.HouseNumber // => 86
```

I record hanno _uguaglianza strutturale_, il che significa che due istanze dello stesso record con valori identici sono equivalenti.

Oltre a poter usare la notazione puntata per accedere ai campi di un record, i record possono anche essere _destrutturati_ nei binding e nel pattern matching:

```fsharp
let myAddress: Address = { Street = "Broadway"; HouseNumber = 123 }
let { Street = myStreet; HouseNumber = myHouseNumber } = myAddress

match myAddress with
| { HouseNumber = 1 } -> printfn "First house"
| { HouseNumber = houseNumber; Street = street } -> printfn "House number %d on %s" houseNumber street
// => "House number 123 on Broadway
```
