# Installazione

Il modo più semplice per installare PureScript è tramite Node.js e NPM.

Se non hai già Node.js installato sul computer, puoi scaricarlo dal [sito di Node.js](https://nodejs.org/). Una volta che Node.js è installato e funzionante, digita questo comando nel terminale per installare il compilatore PureScript e lo strumento di build Spago:

    npm install --global purescript spago

Trovi maggiori informazioni nel [repository di PureScript](https://github.com/purescript/purescript/blob/master/INSTALL.md).
