# Istruzioni

Alcuni «altri» sviluppatori hanno lavorato al progetto dell'auto radiocomandata [exercise:csharp/remote-control-competition](). Ti hanno chiamato per ripulire il codice.

## 1. Separa le responsabilità tra l'auto stessa e il sistema di telemetria

Riorganizza la classe `RemoteControlCar` in modo da separare i metodi e le proprietà di telemetria, accessibili tramite una proprietà `Telemetry`.

```csharp
var car = new RemoteControlCar();
car.Telemetry.Calibrate();
car.Telemetry.SelfTest();
car.Telemetry.ShowSponsor("Walker Industries Inc.");
car.CurrentSponsor
// => "Walker Industries Inc."
car.Telemetry.SetSpeed(100, "cps");
car.GetSpeed()
// => "100 centimeters per second"
```

## 2. Impedisci ad altro codice di dipendere troppo dal tipo Telemetry

Assicurati che l'istanza di `Telemetry` non possa essere creata al di fuori dello scope dell'auto.

## 3. Impedisci ad altro codice di dipendere dalla struct Speed

Assicurati che la struct `Speed` non possa essere usata al di fuori dello scope della classe `RemoteControlCar`.

## 4. Impedisci ad altro codice di dipendere dall'enum SpeedUnits

Assicurati che l'enum `SpeedUnits` non possa essere usato al di fuori dello scope della classe `RemoteControlCar`.
