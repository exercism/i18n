# Istruzioni

Il problema delle otto regine è una classica domanda nei colloqui di programmazione. Per fortuna, con Z3 è facile risolverlo.
Il problema è questo: disporre 8 regine su una scacchiera in modo che nessuna coppia di regine possa catturarsi a vicenda. Negli scacchi,
le regine possono muoversi di qualsiasi numero di caselle in una sola direzione (avanti, indietro, a sinistra, a destra, in diagonale). Scrivi una
funzione che restituisce un array di tuple Python con le posizioni delle 8 regine.
