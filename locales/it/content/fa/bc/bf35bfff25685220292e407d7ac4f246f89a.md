# Appendice alle istruzioni

Questo è un buon esercizio per sperimentare con letterali stringa non standard e con la metaprogrammazione.

Una breve introduzione ai letterali stringa non standard si trova in questo [post del blog](https://web.archive.org/web/20170625222109/https://iaindunning.com/blog/julia-unicode.html). Una guida dettagliata alla metaprogrammazione si trova nel [manuale](https://docs.julialang.org/en/v1/manual/metaprogramming/).

Puoi estendere la soluzione aggiungendo la funzionalità descritta di seguito.

Il bonus A richiede solo le basi illustrate nel post del blog. Il bonus B richiede una conoscenza molto più approfondita della metaprogrammazione in Julia.

## Bonus A
Implementa un letterale stringa che applica `ROT13` alla stringa:
```julia
R13"abcdefghijklmnopqrstuvwxyz" == "nopqrstuvwxyzabcdefghijklm"
```

## Bonus B
Implementa i letterali stringa `R<i>`, `i = 0, ..., 26`, che spostano la stringa di `i` valori:
```julia
R0"Hello, World!" == "Hello, World!"
R4"Testing 1 2 3 testing" == "Xiwxmrk 1 2 3 xiwxmrk"
R13"abcdefghijklmnopqrstuvwxyz" == "nopqrstuvwxyzabcdefghijklm"
```
