# Classi

Le classi sono un concetto centrale nella [programmazione orientata agli oggetti][object-oriented-programming].
[In Crystal, tutto è un oggetto][everything-is-an-object], ogni oggetto ha un tipo e può rispondere ad alcuni metodi.
Le classi sono modelli per creare oggetti: forniscono valori iniziali per lo stato, come le variabili, e implementazioni di comportamento, come i metodi.
Gli oggetti sono istanze di classe che contengono tutte le variabili di istanza e gli stati.

## Definizione di una classe

Una classe si definisce con la parola chiave `class`, seguita dal nome della classe scritto in `UpperCamelCase`.

```crystal
class Account
end
```

## Creare un'istanza

Per [creare un'istanza di una classe][new-initialize], chiama il nome della classe usando il metodo `new`.

```crystal
class Account
end

account = Account.new
```

Nell'esempio qui sopra, la variabile `account` è un'istanza della classe `Account`.

Quando si crea un'istanza, un metodo speciale chiamato `initialize` funge da costruttore.
Viene chiamato quando si crea un'istanza.
Il costruttore permette di impostare lo stato iniziale dell'istanza.
Il metodo `initialize` può accettare argomenti, che vengono passati quando si crea un'istanza.

```crystal
class Account
  def initialize(number)
    5 + number # => 9
  end
end

Account.new(4)
```

~~~~exercism/note
Il metodo `initialize` non può restituire manualmente un valore: al suo posto, `new` restituisce l'istanza appena creata.

```crystal
class Account
  def initialize(number)
    5 + number
  end
end

Account.new(4)
# => #<Account:0x7f5dc33dcea0>
```
~~~~

## Metodi di istanza

Un metodo di istanza è un metodo disponibile per un'istanza di una classe, e può essere chiamato su quell'istanza.
I metodi di istanza si definiscono con la parola chiave `def`, seguita dal nome del metodo.
Si definiscono all'interno della definizione della classe.

```crystal
class Account
  def balance
    100
  end
end

account = Account.new
account.balance # => 100
```

## Variabili di istanza

Le [variabili di istanza][instance-variable] sono variabili disponibili in tutti i metodi dell'istanza.
Per accedere a una variabile di istanza devi definire un metodo di istanza.
Possono essere inizializzate nel metodo `initialize`.
Si definiscono usando il prefisso `@`.

```crystal
class Account
  def initialize
    @balance = 100
  end

  def balance
    @balance
  end
end

account = Account.new
account.balance
# => 100
```

Le variabili di istanza possono anche essere definite all'interno della definizione della classe.

```crystal
class Account
  @age = 0
end
```

### Variabili di istanza con inizializzazione

Le variabili di istanza possono essere inizializzate con un argomento passato al metodo `initialize`.
Poiché Crystal non riesce a inferire il tipo dell'argomento usato durante l'inizializzazione, questo va specificato.
Se vuoi saperne di più, puoi leggere: [type-inference][type-inference].
Per specificare il tipo della variabile puoi usare il simbolo `:`, seguito dal tipo.
Per esempio, se vuoi creare una variabile di istanza chiamata `balance` di tipo `Int32`, puoi fare così: `@balance : Int32`.
Oppure, se vuoi creare una variabile di istanza chiamata `raining` di tipo `Bool`, puoi fare così: `@raining : Bool`.

Ci sono diversi modi per farlo. Uno è dichiarare l'argomento con il tipo nel metodo `initialize` e poi assegnare la variabile di istanza all'argomento, come nell'esempio seguente:

```crystal
class Account
  def initialize(balance : Int32)
    @balance = balance
  end

  def balance
    @balance
  end
end

account = Account.new(1)
account_2 = Account.new(5)

account.balance
# => 1

account_2.balance
# => 5
```

Un altro modo è dichiarare il tipo della variabile di istanza nella definizione della classe nella forma: `@<variable> : <Type>`, come nell'esempio seguente:

```crystal
class Weather

  @raining : Bool

  def initialize(raining)
    @raining = raining
  end

  def raining
    @raining
  end
end

weather = Weather.new(true)
weather.raining
# => true
```

## Modificare le variabili di istanza

I metodi possono modificare le variabili di istanza.
Questi metodi possono essere chiamati sull'istanza della classe.
Quando un metodo modifica una variabile di istanza, quella modifica è disponibile solo nell'istanza della classe su cui l'hai chiamato.

```crystal
class Account
  def initialize(balance : Int32)
    @balance = balance
  end

  def withdraw(amount)
    @balance -= amount
  end

  def balance
    @balance
  end
end

account = Account.new(10)
account_2 = Account.new(10)
account.balance
# => 10

account_2.balance
# => 10

account.withdraw(5)
account.balance
# => 5

account_2.balance
# => 10
```

## Metodi di classe

I [metodi di classe][class-methods] sono metodi definiti per una classe, ma non per le sue istanze.
Offrono un modo per creare metodi che non dipendono dallo stato dell'istanza.
Si definiscono con la parola chiave `def`, seguita da `self.<method name>`.
`self` è un riferimento al namespace da cui viene chiamato self.
In questo caso, si riferisce alla classe `Account`.
Sarebbe lo stesso che scrivere `Account.`, ma `self.` è il modo preferito.

```crystal
class Account
  def self.balance
    100
  end
end

Account.balance
# => 100
```
