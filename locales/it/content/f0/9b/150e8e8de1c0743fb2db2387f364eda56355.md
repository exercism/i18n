# Debug

```pyret
fun print-forty-two():
  print(42) # 42
end
```

```pyret
fun return-forty-two() block:
  print(42) # 42
  42
end
```

[print][print] è un'espressione che restituisce un valore.
Pyret consente una sola espressione all'interno di un dato blocco di codice, a meno che il blocco esterno non sia contrassegnato con `block`.
Nel secondo esempio, aggiungere `block` alla dichiarazione della funzione ci permette di stampare 42 prima di restituirlo.

## Spie

```pyret
fun do-something():
    x = "foo"
    y = "bar"
    spy "strings": x, y end
    a = 1
    b = 2
    spy "numbers": a, b end
end
do-something();

# Spying "strings" (at <clipped>/example.arr:4:4-4:27)
#  x: "foo"
#  y: "bar"
# Spying "numbers" (at <clipped>/example.arr:7:4-7:27)
#  a: 1
#  b: 2
```

Un'istruzione `spy` accetta un'etichetta opzionale, una o più variabili e riporta ogni variabile con il suo valore.
Dato che non è un'espressione, uno `spy` si può usare in un blocco senza che il blocco esterno debba essere contrassegnato con `block`.

[print]: https://pyret.org/docs/latest/_global_.html#%28idx._%28gentag._57%29%29
[spy]: https://pyret.org/docs/latest/s_spies.html
