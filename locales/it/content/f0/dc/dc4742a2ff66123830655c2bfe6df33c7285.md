# Introduzione

In Factor, definisci una nuova parola con `: name ( stack-effect ) body ;`.
Il corpo è una sequenza di parole; chiamare la nuova parola le esegue in
ordine.

```factor
USING: kernel ;
IN: my-vocab

: shout ( str -- str ) "!" append ;
```

Quando una routine diventa grande, puoi, anzi dovresti, *fattorizzarla*: estrarre
gruppi di parole in parole più piccole e con un nome, ognuna con un solo compito. Il
linguaggio prende il suo nome proprio da questo.

## Vocabolari

Ogni file `.factor` dichiara un vocabolario con `IN:`. Le parole di un
vocabolario possono chiamare parole di un altro elencando l'altro vocab in
`USING:`.

```factor
! file: my-vocab/helpers/helpers.factor
USING: kernel ;
IN: my-vocab.helpers

: shout-line ( str -- str ) "!" append ;
```

```factor
! file: my-vocab/my-vocab.factor
USING: kernel my-vocab.helpers sequences ;
IN: my-vocab

: announce ( names -- strs )
    [ shout-line ] map ;
```

La struttura delle directory segue il nome del vocab punteggiato: il vocab `my-vocab`
si trova in `my-vocab/my-vocab.factor`; il vocab `my-vocab.helpers` si trova
in `my-vocab/helpers/helpers.factor`. Il loader di Factor segue le
dichiarazioni `USING:` in modo transitivo, caricando ogni vocab quando serve.
