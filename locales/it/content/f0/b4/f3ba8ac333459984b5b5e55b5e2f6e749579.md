# Informazioni

Se i tipi dei parametri possono essere inferiti, Swift permette anche di omettere dalla definizione della closure i nomi dei parametri e la parola chiave `in`. Al loro posto, si può fare riferimento ai parametri con una [sintassi abbreviata speciale][shorthand-argument-names], in cui `$0` si riferisce al primo parametro, `$1` al secondo, e così via.

```swift
let mean: (Double, Double) -> Double = { $0 + $1 / 2.0 }

["apple", "ball", "carrot"].sorted(by: { $0.count < $1.count })
```

Questo stile si usa molto spesso quando si passano closure a funzioni di ordine superiore e la brevità è importante.

[shorthand-argument-names]: https://docs.swift.org/swift-book/LanguageGuide/Closures.html#ID100
