# Informazioni

Una [`List`][lists] in Elm è una collezione immutabile di zero o più valori dello stesso tipo.
Poiché le liste sono immutabili, una volta che una lista è stata costruita, il suo valore non può mai cambiare.
Le liste in Elm hanno una _testa_ (il primo elemento) e una _coda_ (tutto ciò che viene dopo il primo elemento).
La coda di una lista è essa stessa una lista.

Le annotazioni di tipo per le liste si possono definire come segue

```elm
List String --> a list of String
List Int --> a list of Int
```

Le liste si possono definire come segue:

```elm
empty : List Char
empty = []

singleValue = [ 5 ] --> List Int
singleValueAlternative = List.singleton 5 --> List Int

threeValues = [ "a", "b", "c" ] --> List String
```

Il modo più comune per aggiungere un elemento a una lista è tramite l'operatore `::` (cons):

```elm
twoToFour = [ 2, 3, 4 ]
oneToFour = 1 :: twoToFour --> [1; 2; 3; 4]
```

Si può aggiungere una lista a un'altra usando l'operatore `++` o `List.append`:

```elm
[ 6, 7 ] ++ [ 8, 9 ]           --> [6, 7, 8, 9]
List.append [ 6, 7 ] [ 8, 9 ]  --> [6, 7, 8, 9]
```

Le liste vengono manipolate tramite funzioni e operatori definiti nel [modulo `List`][list-module].

```elm
List.length [ 7, 8 ] --> 2
```

Qualsiasi funzione o operatore che sembri modificare una lista (ad esempio aggiungendo un elemento), in realtà restituisce una nuova lista.
Di solito le prestazioni non sono un problema, dato che l'implementazione delle liste evita allocazioni e copie inutili.

Le liste si possono anche elaborare usando il [pattern matching][list-destructuring].

```elm
describe : List String -> String
describe list =
    case list of
        [] ->
            "Empty list"

        [ "hello" ] ->
            "Singleton list with: hello"

        x :: xs ->
            "Non-empty list with head: " ++ x

describe []                   --> "Empty list"
describe [ "hello" ]          --> "Singleton list with: hello"
describe [ "hello", "world" ] --> "Non-empty list with head: hello"
```
