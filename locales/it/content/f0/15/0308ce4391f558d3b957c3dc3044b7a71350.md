# Informazioni

## I numeri e gli operatori numerici

Tutti i **numeri**, siano essi interi o no, sono numeri in virgola mobile a doppia precisione IEEE 754.
L'implementazione di `jq` usa il tipo `double` del C.
Questo ci limita a 53 bit di precisione.

Con i numeri sono disponibili i soliti operatori:

- aritmetica: `+`, `-`, `*`, `/`, `%`
- confronto: `==`, `!=`, `<`, `<=`, `>=`, `>`
- [funzioni matematiche][man-math] standard

  Per le funzioni a un input, passa il valore alla funzione con una pipe

  ```sh
  $ jq -n '(1 | atan) * 4'
  3.141592653589793
  ```

  Per le funzioni a due input, la funzione ignora l'input e si aspetta che gli
  input siano passati come parametri

  ```sh
  $ jq -n 'pow(2; 10)'
  1024
  ```

  Il separatore degli argomenti di una funzione è il punto e virgola, non la virgola.

~~~~exercism/caution
Che cosa significa dire «Questo ci limita a 53 bit di precisione»?

Una dimostrazione:

```sh
$ jq -n 'pow(2;52) as $n | [$n, $n+1]'
[
  4503599627370496,
  4503599627370497
]
```

Sembra tutto a posto. E se aumentiamo l'esponente?

```sh
$ jq -n 'pow(2;53) as $n | [$n, $n+1]'
[
  9007199254740992,
  9007199254740992
]
```

Quei numeri non dovrebbero essere uguali.
Ecco come si presenta una «perdita di precisione».
Questo significa che `jq` non è in grado di gestire numeri arbitrariamente grandi.
~~~~

## Espressioni condizionali

`jq` usa un'[espressione `if-then-else`][if-then-else] per le **espressioni condizionali**.
Essendo un'_espressione_, si colloca all'interno di una pipeline.

La sintassi è: `if CONDTITION then TRUE_EXPR else FALSE_EXPR end`.

La clausola `else` è facoltativa.

```jq
42 | if . < 33 then "small" else "larger" end
# => "larger"
```

Per condizioni aggiuntive si usa `elif`

```jq
42 | if . < 33 then "small"
     elif . < 67 then "medium"
     else "large"
     end
# => "medium"
```
