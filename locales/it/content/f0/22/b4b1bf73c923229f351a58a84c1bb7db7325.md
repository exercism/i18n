# Eseguire i test

Dal terminale, spostati nella directory principale dell'esercizio e poi esegui i test con:

```bash
$ mix test
```

Questo eseguirà il file di test che si trova nella sottocartella `test`, un file che termina con `_test.exs`

Documentazione:

* [`mix test`: lo strumento di Elixir per eseguire i test](https://hexdocs.pm/mix/Mix.Tasks.Test.html)
* [`ExUnit`: la libreria di unit test di Elixir](https://hexdocs.pm/ex_unit/ExUnit.html)

## Test in sospeso

Nelle suite di test degli esercizi di pratica, tutti i test tranne il primo sono stati contrassegnati per essere saltati.

Una volta che un test passa, puoi riattivare il successivo trasformando in commento il relativo `@tag :pending` con un simbolo `#`.

Per esempio:

```elixir
# @tag :pending
test "shouting" do
  assert Bob.hey("WATCH OUT!") == "Whoa, chill out!"
end
```

Se vuoi eseguire tutti i test in una volta sola, puoi includere tutti i test saltati usando il flag `--include` sul comando `mix test`:

```bash
$ mix test --include pending
```

Oppure puoi abilitare tutti i test trasformando in commento la riga `ExUnit.configure` nel file `test/test_helper.exs`.

```elixir
# ExUnit.configure(exclude: :pending, trace: true)
```

## Opzioni utili di `mix test`

* `test/<FILE>.exs:LINENUM`: esegue un solo test, quello di `<FILE>.exs` la cui definizione si trova alla riga `LINENUM`
* `--failed`: esegue solo i test che hanno fallito l'ultima volta che sono stati eseguiti
* `--max-failures`: la suite smette di valutare i test quando viene raggiunto questo numero di test falliti
* `--seed 0`: disabilita la randomizzazione, così i test in un singolo file verranno sempre eseguiti nello stesso ordine in cui sono stati definiti
