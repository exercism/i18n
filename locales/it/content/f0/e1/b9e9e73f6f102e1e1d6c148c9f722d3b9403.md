# Istruzioni

Mentre ti prepari a cuocere dei biscotti per i tuoi amici, ti accorgi di dover convertire alcune delle misure usate nella ricetta. Conoscendo solo il sistema metrico, devi trovare un modo per convertire le comuni misure di cucina americane in millilitri (mL) per tua comodità.

Usa questa tabella di conversione per la soluzione:

| Unità da convertire | volume | in millilitri (mL) |
| --------------- | ------ | ------------------- |
| mL              | 1      | 1                   |
| tazza americana          | 1      | 240                 |
| oncia liquida americana  | 1      | 30                  |
| cucchiaino americano     | 1      | 5                   |
| cucchiaio americano   | 1      | 15                  |

Dato che sei un programmatore di talento in formazione, decidi di usare i millilitri come unità di transizione per facilitare la conversione da qualsiasi unità elencata a qualsiasi altra (anche a se stessa).

## 1. Ottenere la componente numerica da una coppia unità-volume

Implementa la funzione `getVolume`. Data una tupla coppia unità-volume, deve restituire solo la componente numerica.

```haskell
getVolume (Cup, 2.0)
-- -> 2.0
```

## 2. Convertire la coppia unità-volume in millilitri

Implementa la funzione `toMilliliter`. Data una tupla coppia unità-volume, deve convertire il volume in millilitri usando la tabella di conversione.

Usa più clausole di funzione e il pattern matching per creare le funzioni per ogni unità. Gli atomi usati per indicare ogni unità sono: `Cup`, `FluidOunce`, `Teaspoon`, `Tablespoon`, `Milliliter`.
Restituisci il risultato della conversione avvolto in una tupla.

```haskell
toMilliliter (Cup, 2.5)
-- -> (Milliliter, 600.0)
```

## 3. Convertire in un'altra unità una coppia unità-volume in millilitri

Implementa la funzione `fromMilliliter`. Data una tupla coppia unità-volume e l'unità desiderata, deve convertire il volume nell'unità desiderata usando la tabella di conversione.

Usa più clausole di funzione e il pattern matching per creare le funzioni per ogni unità. Gli atomi usati per indicare ogni unità sono: `Cup`, `FluidOunce`, `Teaspoon`, `Tablespoon`, `Milliliter`.

```haskell
fromMilliliter (Milliliter, 1320.0) Cup
-- -> (Cup, 5.5)
```

## 4. Convertire da qualsiasi unità a qualsiasi unità

Implementa la funzione `convert`. Data una tupla coppia unità-volume e l'unità desiderata, deve convertire il volume dato nell'unità desiderata.

```haskell
convert (Teaspoon, 9.0) Tablespoon
-- -> (Tablespoon, 3.0)
```
