# Analyzer

Gli analyzer di Exercism valutano automaticamente le soluzioni inviate dagli studenti e forniscono commenti in stile mentore.

## Contribuire agli analyzer

Ogni linguaggio ha il proprio analyzer, scritto in quel linguaggio.
Il sito web fa da orchestratore tra gli analyzer e le soluzioni inviate dagli studenti.

Ogni analyzer si trova nell'organizzazione GitHub di Exercism, in un repository chiamato `<track_slug>-analyzer` (ad es. [`exercism/ruby-analyzer`](https://github.com/exercism/ruby-analyzer)).
Qui puoi dare un'occhiata agli analyzer esistenti: [link](https://github.com/search?q=topic%3Aexercism-analyzer&type=repositories).

Se vuoi dare una mano con un analyzer esistente, apri una issue nel suo repository e chiedi se c'è un punto in cui puoi essere d'aiuto.
Se invece vuoi creare un analyzer per un linguaggio che al momento non ne ha uno, segui le istruzioni su [creare un analyzer](/docs/building/tooling/analyzers/creating-from-scratch).
