# Generale

La documentazione sull'[istruzione switch][switch-statement] fornisce un'introduzione alle istruzioni `switch`.

## 1. Genera le descrizioni dei giocatori in base al numero di maglia

- L'istruzione [`break`][break] è utile.

## 2. Gestisci i numeri di maglia sconosciuti

- L'istruzione [`default`][default] è utile.

## 3. Estendi la copertura per includere le attività fuori dal campo

- Il [pattern matching sui tipi][switch-pattern-matching] è la chiave di questo compito.
- Usa l'istruzione [`default`][default] per corrispondere a qualsiasi altro tipo.

## 5. Descrivi i manager dei club

- Consulta questa [documentazione][switch-when] per la parola chiave `when`.
