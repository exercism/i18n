# Appendice alle istruzioni

## Parole

Definisci una tupla `custom-set` e dichiarala un'istanza del mixin `set` con `INSTANCE: custom-set set`.

- `<custom-set> ( -- set )`: costruisce un insieme vuoto.
- `>custom-set ( seq -- set )`: costruisce un insieme a partire da una sequenza, scartando silenziosamente i duplicati.

Poi fornisci i metodi `M:` (da `sets`) su `members`, `in?`, `adjoin` e `set-like` per `custom-set`. Con la dichiarazione `INSTANCE:` e questi quattro metodi a posto, `null?`, `union`, `intersect`, `diff`, `subset?`, `set=` e `intersects?` del vocabolario `sets` funzionano tutti sull'insieme grazie alle implementazioni predefinite del protocollo: i test chiamano direttamente queste parole.

`adjoin ( elt set -- )` è mutante: aggiunge `elt` a `set` sul posto se non è già presente.
