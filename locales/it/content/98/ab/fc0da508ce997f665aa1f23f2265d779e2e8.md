# Appendice alle istruzioni

## Except

Il valore restituito dalla funzione `guess` è di tipo `Except String Result`.

Un [`Except ε α`][except] rappresenta un calcolo che può produrre un errore di tipo `ε` oppure un valore riuscito di tipo `α`. 
È una monade, che permette di comporre questo tipo di calcoli.

## Programmazione reattiva

Per ragioni pratiche, questo esercizio non richiede un approccio di programmazione reattiva.
Invece, prova a implementare una [macchina a stati finiti][finite-state-machine].
