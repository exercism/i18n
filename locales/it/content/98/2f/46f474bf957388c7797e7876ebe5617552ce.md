# Cicli while e until

Un ciclo è una struttura di controllo che permette di eseguire ripetutamente del codice in base a una condizione data.

## Cicli while

Un ciclo while è una struttura di controllo che permette di eseguire ripetutamente del codice in base a una condizione data.
Il codice all'interno di un ciclo while continua a essere eseguito finché la condizione è vera.
I cicli while si usano spesso quando il numero di iterazioni non è noto in anticipo, ma possono essere usati in qualsiasi situazione in cui serve un ciclo.

La condizione viene valutata prima che il codice all'interno del ciclo venga eseguito: se la condizione è falsa, il codice all'interno del ciclo non verrà mai eseguito.

```crystal
i = 0
while i < 3
  puts i
  i += 1
end

# Output:
# 0
# 1
# 2
```

Quando vuoi iterare su una stringa, puoi farlo usando la sua lunghezza.

```crystal
str = "Hello"
i = 0
while i < str.size
  puts str[i]
  i += 1
end

# Output:
# H
# e
# l
# l
# o
```

## Cicli until

I cicli until funzionano come i cicli while, con la differenza che il codice all'interno del ciclo continua a essere eseguito finché la condizione non è vera.
È la stessa differenza che c'è tra `if` e `unless`.

```crystal
i = 0
until i == 3
  puts i
  i += 1
end
```

### Cicli infiniti

Un errore comune con i cicli while è finire in un «ciclo infinito», che non termina mai.
Un ciclo infinito può essere causato da una condizione che non risulta _mai_ vera né falsa.
Spesso è dovuto a un errore del programmatore: per esempio, dimenticare di incrementare la variabile del ciclo.
Ma a volte un ciclo infinito è il modo più chiaro per implementare la logica del programma.
Oppure è essenziale iterare all'infinito: per esempio, un server HTTP aspetta una connessione in arrivo, la gestisce e poi aspetta la connessione successiva.

## Break

La parola chiave `break` può essere usata per uscire anticipatamente da un ciclo.
Può essere comodo quando vuoi uscire da un ciclo in anticipo al verificarsi di certe condizioni.

```crystal
i = 0
while i <= 3
  puts i
  i += 1
  if i == 2
    break
  end
end

# Output:
# 0
# 1
```

## Next

La parola chiave `next` può essere usata per saltare all'iterazione successiva di un ciclo.
Può essere comodo quando vuoi saltare alcune iterazioni specifiche di un ciclo.

```crystal
i = 0
while i <= 3
  i += 1
  if i == 2
    next
  end
  puts i
end

# Output:
# 1
# 3
```

## I tipi all'interno di un ciclo

Il tipo di una variabile può cambiare all'interno di un ciclo.
Nell'esempio seguente, il tipo di `a` è `Int32 | String` perché nella prima parte del ciclo può essere `Int32` o `String`.
La variabile `a` assume il tipo `Int32 | String` solo nella prima parte del ciclo, dato che all'inizio del ciclo contiene un `Int32` e nella seconda iterazione contiene una `String`.
Questo sistema a più tipi sarà spiegato in dettaglio più avanti.
Ma poiché sappiamo per certo che nella seconda parte del ciclo ci sarà solo una `String`, il tipo di `a` è `String` nella seconda parte del ciclo.
A runtime non conterrà mai contemporaneamente un `Int32` e una `String`.

```crystal
i = 0
a = 4
while i < 3
  p typeof(a)
  # => Int32 | String
  a = "4"
  p typeof(a)
  # => String
  i += 1
end
```
