# Introduzione

Gli hash sono un tipo di dato di Perl che contiene una raccolta non ordinata di chiavi di tipo stringa abbinate a valori scalari.

Di solito una variabile hash si popola assegnandole una lista, ad esempio `my %scores = (Alice => 10, Bob => 15, Charlie => 20);`.

Gli elementi di una lista sono di solito separati da virgole, ma vedrai spesso quella che viene chiamata «virgola grassa» (`=>`) per separare chiavi e valori all'interno di una lista.
Il suo comportamento è quasi identico a quello di una virgola, ma ha il vantaggio aggiuntivo di interpretare l'elemento alla sua sinistra come una stringa.

Gli hash si possono popolare anche assegnando valori alle singole chiavi, ad esempio `$scores{Alice} = 10;`.

Si può accedere ai valori di un hash specificando le chiavi tramite un pedice, ad esempio `$scores{Bob} # 15`.

Le chiavi di un hash sono uniche.
Se una chiave viene indicata più volte, viene mantenuto solo l'ultimo valore assegnato.

## Funzioni

Tra le funzioni per lavorare con gli hash ci sono [keys][keys] e [values][values], che permettono di recuperare le rispettive parti di un hash sotto forma di lista.
Le liste restituite dalle funzioni [keys][keys] e [values][values] possono essere utili con funzioni che operano sulle liste come [grep][grep], [map][map] e [sort][sort], oltre che nei cicli [for][for].

Altre funzioni per gli hash includono [exists][exists], che verifica se una chiave esiste in un hash (anche quando il suo valore è `undef`), e [delete][delete], che rimuove una chiave da un hash.

## Variazione dei sigil

Quando si ottengono i valori di un hash, il sigil presente determina il risultato.
È il pedice `{}` alla fine del nome della variabile a indicare a Perl che stai accedendo a un hash con quel nome.

```perl
my %names = (Alice => 10, Bob => 15, Charlie => 20);

$names{Alice}; # 10            <- A scalar
@names{Alice}; # (10)          <- A slice (with only one key, this probably isn't what you want. There will be a warning.)
%names{Alice}; # ('Alice', 10) <- A key/index + value slice

$names{'Bob', 'Charlie'}; #                            <- An error (disabled syntax for an ancient feature.)
@names{'Bob', 'Charlie'}; # (15, 20)                   <- A slice
%names{'Bob', 'Charlie'}; # ('Bob', 15, 'Charlie', 20) <- A key/index + value slice
```

Anche se è consentito, per una questione di leggibilità è consigliabile evitare che variabili di tipo diverso condividano lo stesso nome.
