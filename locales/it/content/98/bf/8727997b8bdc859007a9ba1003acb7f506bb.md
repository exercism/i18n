# Istruzioni

In questo esercizio scriverai del codice che ti aiuterà a prepararti all'acquisto di un veicolo.

Hai tre attività: una per determinare se ti serve una patente, una per aiutarti a scegliere tra due veicoli e una per stimare il prezzo accettabile di un veicolo usato.

## 1. Stabilire se ti servirà una patente di guida

Alcuni tipi di veicolo richiedono una patente di guida per essere guidati.
Partiamo dal presupposto che solo i tipi `"car"` e `"truck"` richiedano una patente: tutto il resto si può guidare senza.

Implementa la funzione `needsLicense(kind)`, che prende il tipo di veicolo e restituisce un valore booleano che indica se per quel tipo di veicolo serve una patente.

```kotlin
needsLicense("car")
// => true

needsLicense("bike")
// => false

needsLicense("truck")
// => true
```

## 2. Scegliere tra due possibili veicoli da acquistare

Valuti le opzioni tra i veicoli disponibili.
Riesci a restringerle a due, ma ti serve una mano per prendere la decisione finale.
Per questo, implementa la funzione `chooseVehicle(option1, option2)`, che prende due veicoli come argomenti e restituisce una decisione che include l'opzione che viene prima in [ordine lessicografico][lexicographical-order].

```kotlin
chooseVehicle("Wuling Hongguang", "Toyota Corolla")
// => "Toyota Corolla is clearly the better choice."

chooseVehicle("Volkswagen Beetle", "Volkswagen Golf")
// => "Volkswagen Beetle is clearly the better choice."
```

## 3. Calcolare una stima del prezzo di un veicolo usato

Ora che hai preso una decisione, vuoi assicurarti di ottenere un prezzo equo dal concessionario.
Dato che ti interessa comprare un veicolo usato, il prezzo dipende da quanto è vecchio il veicolo.
Per una stima approssimativa, supponi che se il veicolo ha meno di 3 anni costi l'80% del prezzo originale che aveva quando era nuovo di zecca.
Se ha almeno 10 anni, costa il 50%.
Se il veicolo ha almeno 3 anni ma meno di 10, costa il 70% del prezzo originale.

Implementa la funzione `calculateResellPrice(originalPrice, age)`, che applica questa logica usando `if`, `else if` ed `else` (ci sono altri modi, se vuoi esercitarti).
Prende come argomenti il prezzo originale e l'età del veicolo, e restituisce il prezzo stimato dal concessionario.

```kotlin
calculateResellPrice(1000, 1)
// => 800

calculateResellPrice(1000, 5)
// => 700

calculateResellPrice(1000, 15)
// => 500
```

[lexicographical-order]: https://en.wikipedia.org/wiki/Lexicographic_order
