# Istruzioni

In questo esercizio lavorerai a un pianificatore di appuntamenti per un salone di bellezza a New York, aperto il 15 settembre 2012.

## 1. Analizza la data dell'appuntamento

Implementa il metodo `AppointmentScheduler.schedule()` per analizzare una rappresentazione testuale della data di un appuntamento e convertirla nel `LocalDateTime` corrispondente:

```java
AppointmentScheduler scheduler = new AppointmentScheduler();
scheduler.schedule("7/25/2019 13:45:00");
// => LocalDateTime.of(2019, 7, 25, 13, 45, 0)
```

## 2. Verifica se un appuntamento è già passato

Implementa il metodo `AppointmentScheduler.hasPassed()`, che riceve la data di un appuntamento e verifica se l'appuntamento è nel passato:

```java
AppointmentScheduler scheduler = new AppointmentScheduler();
scheduler.hasPassed(LocalDateTime.of(1999, 12, 31, 9, 0, 0));
// => true
```

## 3. Verifica se l'appuntamento è nel pomeriggio

Implementa il metodo `AppointmentScheduler.isAfternoonAppointment()`, che riceve la data di un appuntamento e verifica se l'appuntamento è nel pomeriggio (>= 12:00 e < 18:00):

```java
AppointmentScheduler scheduler = new AppointmentScheduler();
scheduler.isAfternoonAppointment(LocalDateTime.of(2019, 03, 29, 15, 0, 0))
// => true
```

## 4. Descrivi l'ora e la data dell'appuntamento

Implementa il metodo `AppointmentScheduler.getDescription()`, che riceve la data di un appuntamento e restituisce una descrizione di quella data e di quell'ora:

```java
AppointmentScheduler scheduler = new AppointmentScheduler();
scheduler.getDescription(LocalDateTime.of(2019, 03, 29, 15, 0, 0))
// => "You have an appointment on Friday, March 29, 2019, at 3:00 PM."
```

## 5. Restituisci la data dell'anniversario

Implementa il metodo `AppointmentScheduler.getAnniversaryDate()`, che restituisce la data dell'anniversario di quest'anno, cioè il 15 settembre:

```java
AppointmentScheduler scheduler = new AppointmentScheduler();
scheduler.getAnniversaryDate()
// => LocalDate.of(<current year>, 9, 15)
```
