# Costruttori di stringhe

Una `STR` non cambia mai. Quindi `+` non può aggiungere nulla a una `STR` già esistente: deve creare una stringa nuova con il contenuto di entrambe.

Va bene una volta sola. In un ciclo, invece, no:

```sather
   -- don't
   script ::= "";
   loop
      script := script + lines.elt!;
   end;
```

Ogni giro copia in una nuova stringa tutto ciò che è stato costruito fino a quel momento e butta via quella vecchia. Dieci righe significano dieci copie, ognuna più lunga della precedente. Cento righe significano cento copie. Il lavoro cresce con il *quadrato* del numero di righe: un ciclo che sembra innocuo diventa la parte lenta del programma.

## FSTR

`FSTR` è una stringa che *può* essere modificata, un **costruttore di stringhe**. Di solito, aggiungere qualcosa scrive semplicemente nello spazio che ha già, quindi un ciclo su cento righe fa all'incirca il lavoro di cento righe invece di cento copie.

```sather
   script ::= #FSTR;
   loop
      script := script + lines.elt!;
   end;
   return script.str;
```

Tre cose da notare.

**`#FSTR` ne crea uno vuoto.** `#FSTR(100)` ne crea uno con spazio già riservato per cento caratteri, cosa che vale la pena fare quando la dimensione è nota.

**Devi riassegnare il risultato.** `script := script + ...`, mai `script + ...` da solo. Di solito il risultato è la stessa FSTR di partenza, ma quando lo spazio è finito è una FSTR nuova e più grande: se lo trascuri, continui a scrivere in quella vecchia.

**`.str` alla fine.** Una routine che promette `: STR` deve restituire una `STR`, e `.str` ne ricava una dalla FSTR.

## Cosa si può aggiungere

`+` su una `FSTR` accetta una stringa, un carattere, un numero intero o un booleano, quindi di solito non serve convertire prima:

```sather
   line ::= #FSTR;
   line := line + 1 + ". " + "Enter" + '!';   -- "1. Enter!"
```

## Nuove righe

`"\n"` all'interno di una stringa è una nuova riga: un solo carattere, scritto con due.

```sather
   script := script + "Enter" + "\n" + "Exit";
```
