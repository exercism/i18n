# Suggerimenti

## 1. Definisci l'approvazione

- I tipi personalizzati si possono definire con la sintassi `pub type Name { Variant1 }`.

## 4. Definisci l'attività

- I tipi personalizzati che contengono dati si possono definire con la sintassi `pub type Name { Variant1(SomeType) }`.

## 5. Valuta l'attività

- Si può fare pattern matching sulle varianti di un tipo personalizzato usando le espressioni case.
- Se vuoi aggiungere una condizione in più a un pattern, puoi aggiungere una guardia al pattern usando la parola chiave `if`.
