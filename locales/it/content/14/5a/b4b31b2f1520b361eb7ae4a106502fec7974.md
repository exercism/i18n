# Introduzione

In Haxe, una `class` è la struttura dati principale, che incapsula dati (campi) e comportamento (metodi). I campi e i metodi sono anche chiamati membri di una classe.

L'accesso ai membri può essere limitato tramite i modificatori di accesso, che sono:

- `public`: il membro è accessibile da qualsiasi punto.
- `private`: il membro è accessibile solo dalla stessa classe.

Possiamo pensare alle classi come a dei modelli per creare istanze. Per creare un'istanza, basta usare la parola chiave `new`:

```haxe
class Car {
  public function new() {}
}

var myCar = new Car();
var yourCar = new Car();
```

Per definire un campo, usa un modificatore di accesso seguito dal nome della variabile e dal tipo:

```haxe
class Car {
  public var weight:Int; // Accessable by anyone

  private var color:String; // Accessable only within this class
}
```

Quando definisci un campo, puoi anche assegnargli un valore iniziale. Se un campo non specifica un valore iniziale, assume il valore `null`. Puoi accedere a un campo usando la notazione con il punto:

```haxe
class Car {
  public var weight:Int = 2500; // Weight will be set to 2500
  public var year:Int; // year will be null

  public function new() {}
}

var newCar = new Car();
newCar.weight; // 2500
newCar.year; // null

// Update value of field
newCar.year = 2020;
```
