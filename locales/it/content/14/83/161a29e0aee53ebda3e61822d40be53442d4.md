# Introduzione

Una dichiarazione `MACRO:` è simile a `:`, ma il corpo viene eseguito in *tempo di compilazione* e deve restituire una quotation. Il compilatore sostituisce quella quotation restituita alla chiamata della macro. Poiché il corpo è normale codice Factor, costruire la quotation risultante significa semplicemente manipolare sequenze di parole.

```factor
USING: kernel macros sequences ;

MACRO: twice ( quot -- compound )
    dup append ;

: shout-twice ( name -- ) [ " ahoy!" append print ] twice ;
! At compile time, the call site is replaced with
! [ " ahoy!" append print " ahoy!" append print ].
```

Gli input di una macro sono *valori letterali nel punto di chiamata*. Se passi un valore non letterale, il compilatore si rifiuterà di specializzare: il corpo della macro ha bisogno del valore in tempo di compilazione, non in tempo di esecuzione.

Un parente stretto è il blocco di valutazione in fase di analisi `<< … >>`, che esegue codice Factor arbitrario in tempo di compilazione senza il vincolo di restituire una quotation. Entrambi rientrano nel meccanismo [`macros`][macros] di Factor.
