# Indennità carburante

## Descrizione del problema

Ogni dipendente di ABC Corp riceve un'indennità carburante illimitata. I dipendenti devono inviare un record ogni volta che fanno rifornimento ai loro veicoli. Questi record vengono aggiunti allo stesso file CSV e vengono elaborati a fine mese.

Come membro del team delle operazioni digitali, il tuo compito è leggere questo file CSV e scrivere i risultati in un altro file CSV. Il file di output deve contenere una voce per ogni dipendente con i seguenti dettagli:

- Numero del dipendente
- Numero di rifornimenti
- Costo totale del carburante
- Totale galloni
- Totale miglia accumulate

Ricevi due argomenti di tipo `string`.

1. Il percorso del file CSV di input
1. Il percorso del file CSV di output

Il file CSV di input ha `n` righe e ogni riga ha la seguente forma.

| Nome della colonna      | Tipo Ballerina |
| ----------- | ----------- |
| employee_id      | `int`       |
| odometer_reading   | `int`       |
| gallons   | `decimal` |
| gas_price(USD)  |`decimal`|

Il file di output deve contenere una voce per ogni dipendente, ordinata in ordine crescente per `employee_id`. Ogni riga ha la seguente forma:

| Nome della colonna      | Tipo Ballerina |
| ----------- | ----------- |
| employee_id      | `int`       |
| gas_fill_up_count   | `int`        |
| total_fuel_cost(USD)   | `decimal` |
| total_gallons  |`decimal`|
| total_miles_accrued  |`int`|

## Vincoli

- Numero di righe `n` nel file CSV di input: 2 <= n <= 1000
- Numero di dipendenti dell'azienda: 97
- Il prezzo del carburante è per gallone
- Nessun record di rifornimento mancante

## Esempio 1

- Input: `example01_input.csv`

```csv
2312,230,18.561,4.56
2312,500,19.345,4.89
```

- Output: `example01_output.csv`

```csv
2312,2,179.23521,37.906,270
```
