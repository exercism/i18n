# Introduzione

## Array

Gli array sono integrati nel linguaggio Elixir. Sono considerati un tipo di base, indicati dalle parentesi quadre (`[]`). Gli array possono essere vuoti o contenere un numero qualsiasi di elementi di qualsiasi tipo. Per esempio:

```elixir
empty_list = []
one_item_list = [1]
two_item_list = [1, 2]
multiple_type_list = [1, :pi, 3.14, "four"]
```

Elixir implementa gli array come una lista concatenata, in cui ogni nodo memorizza due valori: il primo elemento e un altro array con tutti gli elementi rimanenti. Il primo elemento dell'array è chiamato «head» e l'array di elementi rimanenti è chiamato «tail». Possiamo usare questa notazione nel codice:

```elixir
# [1] represented in [head | tail] notation
[1 | []]

# [1, 2, 3] represented in [head | tail] notation
[1 | [2 | [3 | []]]]
```

Possiamo usare la notazione _`[head | tail]`_ per anteporre elementi a un array:

```elixir
# Suppose
list = [2, 1]

[3, 2, 1] == [3 | list]
# => true
```

Ci sono diverse funzioni nel modulo `Kernel` per lavorare con gli array, oltre all'intero modulo `List`.

```elixir
# Check if 1 is a member of the list
1 in [1, 2, 3, 4]
# => true
```
