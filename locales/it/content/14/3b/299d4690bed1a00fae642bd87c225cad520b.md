# Introduzione

Lo scope di un valore, cioè l'ambito di visibilità, riguarda il punto del programma in cui si può accedere a quel valore.

## I quattro tipi di scope: blocco; funzione; prototipo di funzione; file

### Scope di blocco

Un valore con scope di blocco è accessibile solo dall'interno del blocco in cui è definito. Per saperne di più sui blocchi, vedi il [concetto di blocco](../blocks/introduction.md#Introduction).

### Scope di funzione

Lo scope di funzione è un tipo speciale di scope che si applica alle etichette usate con le istruzioni `goto`. Due etichette con lo stesso nome non possono essere usate nella stessa funzione, anche se definite in blocchi separati all'interno della funzione.

### Scope del prototipo di funzione

Lo scope del prototipo di funzione è un altro tipo speciale di scope, che si applica solo ai parametri nominati nel prototipo (detto anche dichiarazione, tenendo presente che non tutte le dichiarazioni sono prototipi). Il nome di un parametro di solito è facoltativo in una dichiarazione di funzione. Lo scope di un nome è rilevante solo all'interno della dichiarazione. Una definizione di funzione non deve usare per un parametro lo stesso nome usato nella dichiarazione della funzione.

### Scope di file

Un valore con scope di file è accessibile da qualsiasi punto del file. Un valore di questo tipo è definito al di fuori di una funzione.
