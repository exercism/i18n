# Introduzione

Un buffer di stringhe è un modo efficiente per costruire una stringa grande aggiungendo piccoli elementi l'uno all'altro. A differenza di String, un'istanza di StringBuf non è immutabile: può essere passata come argomento a funzioni che la modificano aggiungendo altri valori.

```haxe
var a = new StringBuf();
a.add("Hello");
trace(a.toString()); // Hello
a.add("Haxe!");
trace(a.toString()); // HelloHaxe
```
