# Informazioni

Una stringa rappresenta dati testuali.
In Swift, una [`String`][strings-and-characters] è una raccolta ordinata di valori `Character`, dove ogni carattere rappresenta un carattere Unicode.

Per creare una stringa si usa un letterale di stringa, cioè una sequenza di caratteri racchiusa tra virgolette doppie (`"`).
Per le stringhe su più righe, usa tre virgolette doppie (`"""`):

```swift
let hello: String = "Hello, World!"

let poem: String = """
Roses are red,
Violets are blue.
Sugar is sweet,
And so are you.
"""
```

Le stringhe di Swift si integrano senza problemi con la classe [`NSString`][nsstring-docs] del framework Foundation, offrendo accesso a vaste capacità di elaborazione del testo.

## Caratteri

Un `Character` rappresenta un singolo cluster di grafemi esteso, cioè un carattere leggibile da una persona composto da uno o più [valori scalari Unicode][unicode-scalar-values].
Un valore scalare Unicode è un code point a 21 bit nell'intervallo da `U+0000` a `U+D7FF` incluso, oppure da `U+E000` a `U+10FFFF` incluso.

```swift
let aChar: Character = "A"
```

## Inferenza di tipo

Quando scrivi un letterale di stringa, Swift ne deduce automaticamente il tipo come `String`.
Per memorizzare un singolo carattere come `Character`, devi fornire un'annotazione di tipo esplicita:

```swift
let aString = "A"        // Inferred as String
let aChar: Character = "A" // Explicitly typed as Character
print(type(of: aString)) // Prints String
print(type(of: aChar))   // Prints Character

// The following code will not compile:
let badChar: Character = "Too many characters"
// Error: Cannot convert value of type 'String' to specified type 'Character'
```

## Concatenazione

Puoi unire più stringhe con l'operatore di addizione (`+`):

```swift
print("honey" + "comb")
// Prints "honeycomb"
```

Non puoi concatenare direttamente un `Character` a una `String` con `+` senza prima convertire il carattere in una stringa.
Puoi però usare il metodo [`append(_:)`][append] per aggiungere direttamente una stringa o un carattere a una stringa mutabile:

```swift
var greeting = "Hello"
let world = ", world"
let period: Character = "."

greeting.append(world)
print(greeting) // Prints "Hello, world"

greeting.append(period)
print(greeting) // Prints "Hello, world."
```

## Interpolazione di stringhe

[L'interpolazione di stringhe][string-interpolation] consente di costruire una stringa inserendo costanti, variabili, letterali ed espressioni all'interno di un letterale di stringa.
Racchiudi ogni espressione tra parentesi precedute da una barra rovesciata (`\(` ... `)`):

```swift
let radius = 5.0
let circle = "The area of a circle with radius \(radius) is \(Double.pi * radius * radius)"
print(circle) // Prints "The area of a circle with radius 5.0 is 78.53981633974483"
```

## Proprietà delle stringhe e dei caratteri

Le stringhe e i caratteri offrono diverse proprietà per ispezionarne il contenuto.

### Proprietà delle stringhe

Tra le proprietà più comuni delle stringhe ci sono:

| Proprietà | Descrizione                                    | Esempio                          |
| --------- | ---------------------------------------------- | -------------------------------- |
| `isEmpty` | Restituisce `true` se la stringa non ha caratteri | `"Hello".isEmpty` restituisce `false` |
| `count`   | Restituisce il numero di caratteri nella stringa | `"Hello".count` restituisce `5`       |

Per un elenco completo delle proprietà, consulta la [documentazione Apple su String][string-docs].

### Proprietà dei caratteri

Tra le proprietà più comuni dei caratteri ci sono:

| Proprietà      | Descrizione                                   | Esempio                              |
| -------------- | --------------------------------------------- | ------------------------------------ |
| `isLowercase`  | Restituisce `true` se il carattere è minuscolo  | `"a".isLowercase` restituisce `true` |
| `isUppercase`  | Restituisce `true` se il carattere è maiuscolo  | `"A".isUppercase` restituisce `true` |
| `isNumber`     | Restituisce `true` se il carattere è una cifra    | `"1".isNumber` restituisce `true`    |
| `isWhitespace` | Restituisce `true` se il carattere è uno spazio bianco | `" ".isWhitespace` restituisce `true`|

Per un elenco completo delle proprietà, consulta la [documentazione Apple su Character][character-docs].

## Conversione di tipo

Puoi convertire altri tipi in stringhe usando l'inizializzatore `String(_:)`, che supporta i tipi standard come `Int`, `Double` e `Character`:

```swift
let charX: Character = "x"
print(String(charX))     // Prints "x"
print(String(110))       // Prints "110"
print(String(Double.pi)) // Prints "3.141592653589793"
```

## Caratteri speciali

I letterali di stringa di Swift supportano diverse [sequenze di escape][special-characters] per i caratteri speciali:

| Sequenza   | Descrizione                   |
| ---------- | ----------------------------- |
| `\0`       | Carattere nullo                |
| `\\`       | Barra rovesciata                     |
| `\t`       | Tabulazione orizzontale                |
| `\n`       | Avanzamento di riga (newline)           |
| `\r`       | Ritorno carrello               |
| `\'`       | Virgoletta singola         |
| `\"`       | Virgoletta doppia         |
| `\u{n}`    | Scalare Unicode arbitrario (esadecimale) |

```swift
let quote: String = "\"Hello\", he said."
print(quote) // Prints "Hello", he said.

let unicode: Character = "\u{1F496}"
print(unicode) // Prints 💖
```
