# Istruzioni

Izzy è un'appassionata osservatrice di uccelli che tiene traccia di quanti uccelli hanno visitato il suo giardino in un dato giorno.

Ti ha chiesto di aiutarla a portare il suo birdwatching a un nuovo livello e di realizzare alcuni strumenti che la aiutino a tracciare ed elaborare i dati.

Hai scelto di memorizzare i dati come un array di numeri interi. Il primo numero dell'array è il numero di uccelli che hanno visitato il tuo giardino oggi, il secondo quelli di ieri e così via.

## 1. Controlla quanti uccelli hanno visitato il giardino oggi

Implementa la funzione `today`. Dovrebbe prendere un array con i conteggi giornalieri degli uccelli e restituire il conteggio di oggi. Se l'array è vuoto, dovrebbe restituire `0`.

```gleam
today([2, 5, 1])
// -> 2
```

## 2. Incrementa il conteggio di oggi

Implementa la funzione `increment_day_count`. Dovrebbe prendere un array con i conteggi giornalieri degli uccelli e incrementare di 1 il conteggio di oggi. Se l'array è vuoto, restituisci `[1]`.

```gleam
increment_day_count([4, 0, 2])
// -> [5, 0, 2]
```

## 3. Controlla se c'è stato un giorno senza uccelli in visita

Implementa la funzione `has_day_without_birds`. Dovrebbe prendere un array con i conteggi giornalieri degli uccelli. Dovrebbe restituire `True` se c'è stato almeno un giorno in cui nessun uccello ha visitato il giardino, e `False` altrimenti. Se l'array è vuoto, questo conta come nessun uccello registrato _ancora_: restituisci `False`.

```gleam
has_day_without_birds([2, 0, 4])
// -> True

has_day_without_birds([3, 8, 1, 5])
// -> False
```

## 4. Calcola il numero totale di uccelli in visita

Implementa la funzione `total`. Dovrebbe prendere un array con i conteggi giornalieri degli uccelli e restituire il numero totale di quelli che hanno visitato il tuo giardino da quando hai iniziato a raccogliere i dati.

```gleam
total([4, 0, 9, 0, 5])
// -> 18
```

## 5. Calcola il numero di giorni intensi

Alcuni giorni sono più intensi di altri. Un giorno intenso è un giorno in cui cinque o più uccelli hanno visitato il tuo giardino.

Implementa la funzione `busy_days`. Dovrebbe prendere un array con i conteggi giornalieri degli uccelli e restituire il numero di giorni intensi.

```gleam
busy_days([4, 5, 0, 0, 6])
// -> 2
```
