# Installazione

Questo track usa ReScript 12 e richiede [Node.js][nodejs] 22 o superiore.
Molti sistemi lo hanno già preinstallato, oppure potresti averlo installato in precedenza per un altro track.

Apri un terminale ed esegui:

```sh
node -v
```

Se Node non è installato o se viene indicata una versione più vecchia, segui le [istruzioni ufficiali per l'installazione di Node.js][nodejs-install] per la tua piattaforma.

## Installare le dipendenze

Ogni esercizio ReScript è un progetto npm autonomo.
Dopo aver scaricato un esercizio con la [CLI di Exercism][exercism-cli], installa le dipendenze del progetto, ReScript compreso, e sei pronto a iniziare:

```sh
cd /path/to/exercise
npm install
```
