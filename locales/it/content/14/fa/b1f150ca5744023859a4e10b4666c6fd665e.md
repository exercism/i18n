# Suggerimenti

## Generali

- [Il tutorial sul dizionario di Python][dict-tutorial] è un ottimo punto di partenza.
- Anche la documentazione di Python su [Mapping Types - dicts][dict docs] è piuttosto utile.

## 1. Crea un inventario a partire da una lista

- Ti serve un [ciclo for][for-loop] per iterare la lista di elementi, poi inserisci ogni elemento nel dizionario se manca e incrementa il conteggio dell'elemento usando l'accessor del dizionario.
- Puoi usare [`dict.setdefault`][dict setdefault] per assicurarti che il valore sia impostato prima di incrementare il conteggio dell'elemento.
- Questa funzione dovrebbe [restituire][return-keyword] un dict.

## 2. Aggiungi elementi da una lista a un dizionario esistente

- Ti serve un [ciclo for][for-loop] per iterare la lista di elementi, poi inserisci ogni elemento se non è già nel dizionario e [incrementa][increment] il conteggio dell'elemento usando l'accessor del dizionario.
- Puoi usare [`dict.setdefault`][dict setdefault] per assicurarti che il valore sia impostato prima di incrementare il conteggio dell'elemento.
- La funzione `add_items` può essere usata dalla funzione `create_inventory` passando un dizionario vuoto come parametro.
- Questa funzione dovrebbe [restituire][return-keyword] un dict.

## 3. Decrementa gli elementi dell'inventario

- Ti serve un [ciclo for][for-loop] per iterare la lista di elementi; se il numero di elementi non è `0`, allora [decrementa][decrement] il numero attuale di elementi.
- Puoi usare il controllo `key in dict`, che restituisce `True` se la chiave esiste, per assicurarti che il valore sia nel dizionario prima di decrementare il numero di elementi.
- Questa funzione dovrebbe [restituire][return-keyword] un dict.

## 4. Rimuovi completamente un elemento dall'inventario

- Se l'elemento è nel dizionario, [rimuovilo][dict-pop].
- Se l'elemento non è nel dizionario, non fare nulla.
- Questa funzione dovrebbe [restituire][return-keyword] un dict.

## 5. Restituisci il contenuto dell'inventario

- Devi usare un [ciclo for][for-loop] sull'inventario e, se il numero dell'elemento è maggiore di `0`, aggiungere la `tuple` a una `list`.
- Puoi usare [`dict.items()`][dict items] per iterare contemporaneamente sull'elemento e sul valore: `items()` restituisce una `tuple` che puoi usare o destrutturare, se necessario.
- Questa funzione dovrebbe [restituire][return-keyword] una [list][list] di [tuples][tuples].
