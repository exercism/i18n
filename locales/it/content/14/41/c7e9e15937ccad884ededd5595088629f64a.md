# Istruzioni

Un disco cifrante è formato da due dischi, uno dentro l'altro, che fanno girare l'alfabeto: impostalo su 3 e ogni lettera diventa quella tre posizioni più avanti, con la `z` che torna indietro fino alla `a`. I detective li usano da secoli. Adesso ne costruirai uno.

Tutte e cinque le attività vanno nella classe `CIPHER_WHEEL`.

## 1. È una lettera?

```sather
CIPHER_WHEEL::is_letter('m')
-- => true
CIPHER_WHEEL::is_letter('7')
-- => false
```

## 2. Urlalo

Restituisci la maiuscola di un carattere. Tutto ciò che non è una lettera viene restituito invariato.

```sather
CIPHER_WHEEL::shout('m')
-- => 'M'
```

## 3. Che numero è?

Restituisci il numero che rappresenta un carattere.

```sather
CIPHER_WHEEL::code('a')
-- => 97
```

## 4. Il primo carattere

Restituisci il primo carattere di una stringa.

```sather
CIPHER_WHEEL::first_character("Marlowe")
-- => 'M'
```

## 5. Gira la ruota

Date una lettera minuscola e un numero di posizioni, restituisci la lettera che si trova altrettante posizioni più avanti nell'alfabeto. Oltre la `z` si torna indietro fino alla `a`.

```sather
CIPHER_WHEEL::turn('a', 3)
-- => 'd'
CIPHER_WHEEL::turn('z', 1)
-- => 'a'
```

Funziona anche girando all'indietro, con un numero di posizioni negativo.

```sather
CIPHER_WHEEL::turn('a', -1)
-- => 'z'
```

Puoi dare per scontato che il carattere ricevuto sia una lettera minuscola.
