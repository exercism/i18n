# Classi e proprietà readonly

Le classi e le proprietà readonly permettono a una classe di specificare proprietà pubbliche per accedervi facilmente, ma ne impediscono la modifica.
Per dichiarare una proprietà come readonly, bisogna aggiungere `readonly` prima della specifica del tipo.
La proprietà può essere assegnata una sola volta, ma qualsiasi tentativo di riassegnare o modificare il valore darà un errore.

```php
<?php

class Block
{
    public function __construct(
        public readonly int $length,
        public readonly int $width,
    ) {
    }
}
```

Le classi readonly si basano su questo comportamento: se dichiarate `readonly`, applicano la dichiarazione readonly a ogni proprietà.
Inoltre impediscono l'aggiunta di proprietà dinamiche.

```php
<?php

readonly class Block
{
    public function __construct(
        public int $length,
        public int $width,
    ) {
    }
}
```
