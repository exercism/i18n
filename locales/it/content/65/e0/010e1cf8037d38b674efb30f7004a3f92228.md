# Contribuire tramite GitHub

I contributi alla codebase di Exercism passano da [GitHub][github].

Come suggerisce il nome, GitHub usa [git][git] come sistema di controllo di versione. Se Git non ti è familiare, la migliore risorsa online è [Pro Git][pro-git].

Se invece non hai familiarità con GitHub e con il flusso di lavoro dei contributi, ecco alcune risorse che possono aiutarti a iniziare:

- [Introduzione a GitHub: corso interattivo][github-course]
- [Come creare una pull request su GitHub: tutorial][pr-tutorial]
- [Come fare una semplice pull request su GitHub: video di anthonywritescode][anthonywritescode]

## Guide

Puoi leggere di più su come assicurarti che il tuo contributo sia ben accolto nella guida [Come creare una buona pull request][great-pr].

Abbiamo anche diverse guide alle pull request specifiche di Exercism:

- [Come creare una buona pull request][how-to-make-a-great-pr]
- [La guida ai contributori per le pull request][contributors-pr-guide]
- [La guida ai maintainer per le pull request][maintainers-pr-guide]
- [Permessi dei maintainer sul repository][maintainers-repo-permissions]
