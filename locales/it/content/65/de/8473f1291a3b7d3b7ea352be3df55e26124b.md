# Informazioni

Una definizione di tipo crea un nuovo tipo con un nome, distinto da ogni altro tipo, anche da uno con lo stesso tipo sottostante.

## Definire i tipi

Una definizione di tipo inizia con la parola chiave `type`, seguita dal nome del nuovo tipo e dal suo tipo sottostante:

```go
type File []bool
```

Qui `File` si riferisce a una singola colonna verticale di una scacchiera, comunemente indicata con le lettere dalla A alla H.
Ogni casella di questa colonna è rappresentata da un valore booleano che indica se è occupata o meno.
Ora che `File` è definito, possiamo usarlo all'interno di altre definizioni:

```go
type Chessboard map[string]File

board := Chessboard{
    "A": File{true, false, true},
    "B": File{false, true, false},
}
```

`Chessboard` associa gli identificatori delle colonne a valori `File`.
Ogni `File` è una slice di booleani che rappresentano le caselle di una colonna della scacchiera.
Senza queste definizioni di tipo, `board` sarebbe una `map[string][]bool`, il che renderebbe più difficile capire cosa stiamo rappresentando.

## I tipi definiti sono distinti

Anche se `Score` e `int` contengono entrambi valori interi, per convertire dall'uno all'altro serve una conversione esplicita:

```go
type Score int

var number int = 42

// var score Score = number is a compile error
var score Score = Score(number)
var converted int = int(score)
```

`42` è una costante non tipizzata, quindi può essere assegnata direttamente a una variabile di tipo `Score`.

I tipi definiti possono anche avere metodi, trattati nel concetto Metodi.

## Tipi struct

Le definizioni di struct usano la stessa parola chiave `type`:

```go
type Player struct {
    Name  string
    Score Score
}
```

I tipi struct sono trattati nel concetto Structs.

## Alias di tipo

Un alias di tipo crea un altro nome per un tipo esistente, invece di creare un nuovo tipo.
Dato che un alias e il suo tipo originale sono identici, i loro valori si possono usare in modo intercambiabile.
Gli alias si dichiarano usando la parola chiave `type`, il nome dell'alias, il segno di uguale (`=`) e il tipo esistente.

```go
type Square = bool

var isOccupied bool = true
var square Square = isOccupied // no conversion needed
```
