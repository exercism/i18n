# Introduzione

Le classi sono il costrutto principale per fare programmazione orientata agli oggetti in F#.

Una classe in F# è composta dai suoi campi e dai suoi metodi. I campi e i metodi di una classe sono noti come i suoi _membri_.

Le classi in F# si definiscono con la parola chiave `type`. I metodi si definiscono con la parola chiave `member` e sono sempre pubblici. Per definire i campi (privati) si possono usare i binding `let`.

```fsharp
type Shoe() =
    let size = 8

    member this.Describe() = $"This is a size {size} shoe"
```

Le classi sono modelli con cui creare oggetti. Per creare un'istanza di una classe, chiama il nome della classe come una funzione. Un'istanza di una classe è nota anche come _oggetto_.

Si può accedere ai membri di un oggetto usando la notazione puntata.

```fsharp
let myShoe = Shoe()
myShoe.Describe()
// => "This is a size 8 shoe"
```
