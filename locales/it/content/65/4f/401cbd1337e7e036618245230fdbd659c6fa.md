# Informazioni

Può essere difficile trovare un linguaggio di programmazione più espressivo. [Raku](https://raku.org/) è un linguaggio moderno e multi-paradigma. Raku offre metodologie di programmazione [procedurale](https://docs.raku.org/language/functions), [orientata agli oggetti](https://docs.raku.org/language/objects) e [funzionale](https://docs.raku.org/language/functions#Functions_are_first-class_objects).

[Curioso?](https://raku.org/) Scopri di più nella [documentazione](https://docs.raku.org/) o nel [repository](https://raku.land/) dei moduli (come pypi o CPAN).

È un linguaggio estremamente [flessibile](https://docs.raku.org/language/operators), che [si adatta](https://docs.raku.org/language/glossary#gradual_typing) al tuo stile di programmazione, che si tratti di rapidi [one-liner](https://docs.raku.org/language/create-cli) per gli amministratori di sistema, di script per gestire l'importazione di un database o dell'intero stack di moduli necessari per realizzare un [sito web completo](https://cro.services/).

Raku impara dagli altri linguaggi:

* Migliora l'attrattiva a lungo termine di Perl con un vero sistema a oggetti che include [ruoli](https://docs.raku.org/language/typesystem#role), [threading](https://docs.raku.org/language/concurrency) e dispatch [multi-method](https://docs.raku.org/language/glossary#Multi-dispatch).
* Prende il threading da Java, [semplificandolo](https://docs.raku.org/language/concurrency) a una manciata di metodi.
* Usare le [interfacce foreign-function](https://docs.raku.org/language/nativecall) di Lisp rende l'accesso alle librerie semplice come una riga di codice.
* Le [espressioni regolari](https://docs.raku.org/language/regexes) ora sono portate a 11, con l'introduzione delle Parser Expression [Grammars](https://docs.raku.org/language/grammars), che ti permettono di affrontare enormi attività di parsing.
* Le strictures e i warnings ora sono automatici, eliminando ampie porzioni di potenziali errori.
* ... e sa fare [matematica](https://docs.raku.org/language/math): ```1/10 * 3 == 0.3 ```, provaci nel tuo linguaggio preferito!

I motti di Raku:
* «Raku è progettato per rendere facili i compiti facili, senza rendere impossibili quelli difficili.»
* «C'è più di un modo per farlo, ora con ancora più -Ofun (ottimizzato per il divertimento).»
