# Imparare

Ti interessa iniziare con Groovy, o imparare qualcosa di più mentre lavori sugli esercizi?

Prova Groovy con

* [un browser che usa un interprete online](https://www.jdoodle.com/execute-groovy-online)
* [la Groovy Console](http://groovy-lang.org/groovyconsole.html), digitando `groovyConsole` da riga di comando
* [la Groovy Shell](http://groovy-lang.org/groovyconsole.html), digitando `groovysh` da riga di comando

Fai un rapido tour di Groovy con

* [Groovy Tutorial for Java Developers](https://www.timroes.de/2015/06/27/groovy-tutorial-for-java-developers/) di Tim Rows, altrettanto utile per chi non sviluppa in Java
* [Learn X in Y minutes, Where X=Groovy ](https://learnxinyminutes.com/docs/groovy/)
* [Groovy Basics](http://docs.smartthings.com/en/latest/getting-started/groovy-basics.html) di SmartThings
* alcuni degli [online Groovy Koans](http://www.groovy-koans.org/) di JDriven

Approfondisci con

* la [Groovy Documentation](http://www.groovy-lang.org/documentation.html)
* [Groovy In Action](https://www.manning.com/books/groovy-in-action-second-edition), _il libro_ su Groovy
* [Making Java Groovy](https://www.manning.com/books/making-java-groovy) di Ken Kousen
