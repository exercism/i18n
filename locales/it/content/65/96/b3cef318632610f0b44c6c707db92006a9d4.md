# Introduzione

Una definizione `:` può chiamare se stessa direttamente. Il compilatore di Factor deduce l'effetto sullo stack delle parole ricorsive come per qualsiasi altra: per la semplice ricorsione non serve alcuna dichiarazione speciale.

```factor
: total ( seq -- sum )
    [ 0 ] [ unclip swap total + ] if-empty ;

{ 4 0 9 0 5 } total .    ! => 18
```

Le due metà sono il *caso base* della ricorsione (qui, la sequenza vuota ha come somma `0`) e il *passo ricorsivo* (stacca il primo elemento, chiama di nuovo se stessa sul resto, combina i risultati).

`if-empty` e `unclip` sono i compagni canonici per la ricorsione sulle sequenze. `if-empty ( seq emptyquot nonemptyquot -- )` esegue una delle due quotation a seconda della sequenza; `unclip` stacca il primo elemento, così il passo ricorsivo ha qualcosa di più semplice.
