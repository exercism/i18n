# Introduzione

Le conversioni di tipo in Cairo ti permettono di trasformare i dati da un tipo a un altro, consentendo una manipolazione dei dati flessibile e sicura.

## Le basi

Cairo mette a disposizione diversi meccanismi per la conversione di tipo:

### Cast diretto

Per i tipi numerici compatibili, puoi usare il cast diretto:

```rust
let small_number: u8 = 42;
let big_number: u32 = small_number.into();
```

### Il trait Into

Il trait `Into` permette la conversione da un tipo a un altro:

```rust
let value: u16 = 100;
let converted: u32 = value.into();
```

### Il trait TryInto

Per le conversioni che potrebbero fallire, usa `TryInto`, che restituisce un `Option`:

```rust
let large_value: u32 = 70000;
let small_value: Option<u16> = large_value.try_into();

match small_value {
    Option::Some(v) => println!("Converted: {}", v),
    Option::None => println!("Conversion failed"),
}
```

## Conversioni di tipo personalizzate

Puoi implementare `Into` per i tuoi tipi:

```rust
#[derive(Drop)]
struct Celsius {
    value: i32,
}

#[derive(Drop)]
struct Fahrenheit {
    value: i32,
}

impl CelsiusIntoFahrenheit of Into<Celsius, Fahrenheit> {
    fn into(self: Celsius) -> Fahrenheit {
        Fahrenheit { value: (self.value * 9) / 5 + 32 }
    }
}
```

## Considerazioni sulla sicurezza

- Usa `TryInto` quando la conversione potrebbe fallire (ad esempio, da un tipo grande a uno piccolo)
- Usa `Into` quando la conversione riesce sempre
- Gestisci sempre i casi `Option::None` restituiti da `TryInto`
- Tieni conto di overflow e underflow quando converti tra tipi con segno e tipi senza segno
