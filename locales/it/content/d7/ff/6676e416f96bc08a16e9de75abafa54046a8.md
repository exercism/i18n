# Test

## Eseguire i test

Per eseguire i test, lancia il comando seguente:

```bash
make
```

## Risolvere l'esercizio

Risolvere un esercizio significa far passare tutti i suoi test. Per impostazione predefinita, quando esegui i test ne viene eseguito solo uno (il primo). È una scelta voluta: così puoi concentrarti su quel singolo test e farlo passare. Una volta che passa, puoi abilitare il test successivo rimuovendo la riga `TEST_IGNORE()`. Quando avrai abilitato tutti i test e la tua implementazione li farà passare tutti, avrai risolto l'esercizio!
