# Istruzioni

Sarah sta lavorando a un nuovo gioco di ruolo e ha bisogno del tuo aiuto con
le meccaniche del giocatore.

## 1. Definisci la tupla `player`

Definisci una classe tupla `player` con quattro slot e valori predefiniti:

| slot     | predefinito |
| -------- | ------- |
| `name`   | `f`     |
| `level`  | `0`     |
| `health` | `100`   |
| `mana`   | `f`     |

Una volta definita, puoi costruire un giocatore usando un letterale:

```factor
T{ player { name "Merlin" } { level 5 } } .
! => T{ player { name "Merlin" } { level 5 } }
```

## 2. Presenta il giocatore

Definisci `introduce` in modo che restituisca il nome del giocatore. I giocatori
furtivi nascondono il proprio nome (`name` è `f`) e devono essere presentati come
`"Mighty Magician"`.

```factor
T{ player { name "Merlin" } } introduce .
! => "Merlin"

T{ player { health 8 } } introduce .
! => "Mighty Magician"
```

## 3. Rianima un giocatore caduto

Definisci `revive` in modo che restituisca un *nuovo* giocatore con `health`
impostato a 100 e `mana` impostato a 100, ma solo se il `health` del giocatore
è `0`. Se il giocatore è ancora vivo, restituisci `f`.

```factor
T{ player { name "Merlin" } { health 0 } } revive .
! => T{ player { name "Merlin" } { health 100 } { mana 100 } }

T{ player { health 50 } } revive .
! => f
```

## 4. Subisci danni

Definisci `take-damage` in modo che restituisca un *nuovo* giocatore il cui
`health` è stato ridotto della quantità indicata, senza mai scendere sotto `0`.

```factor
T{ player { health 100 } } 30 take-damage .
! => T{ player { health 70 } }

T{ player { health 5 } } 30 take-damage .
! => T{ player { health 0 } }
```
