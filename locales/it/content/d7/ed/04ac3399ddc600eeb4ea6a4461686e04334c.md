# Appendice alle istruzioni

## Note di implementazione

Un programma Factor è costruito a partire da *parole*, raggruppate in *vocabolari*.

Factor carica un *vocabolario* da una directory con lo stesso nome, quindi il vocabolario `hello-world` è il file `hello-world.factor` all'interno di una directory `hello-world/`.

`: say-hello ( -- str ) … ;` definisce la parola `say-hello`.
La parte tra parentesi è il suo *stack effect*: se non c'è nulla a sinistra di `--` significa che non accetta input, mentre `str` a destra significa che lascia un valore (il nome è solo documentazione, non un tipo).
Tutto ciò che sta tra lo stack effect e il `;` di chiusura è il corpo: il codice che viene eseguito quando la parola viene chiamata.

La suite di test chiama `say-hello` e controlla il valore che lascia sullo stack.
Modifica il corpo in modo che la parola lasci invece `"Hello, World!"`, poi esegui i test.
