# Introduzione

## Esportare le funzioni

L'esportazione delle funzioni è già stata trattata nel primo concetto: ecco un breve ripasso.

In Elm ogni file è un modulo e deve contenere un'istruzione `module` prima di qualsiasi altro codice.

I nomi dei moduli devono corrispondere al nome del loro file: il modulo `Calculator` deve stare nel file Calculator.elm, e il modulo `Parser.Utils` nel file Parser/Utils.elm.

Tutto ciò che è definito all'interno di un modulo ha uno scope privato e non è accessibile dall'esterno, a meno che non sia elencato in `exposing`.

```elm
-- Calculator.elm
-- Define the Calculator module, and expose the `add` function
module Calculator exposing (add)

six = 3 + 3

add number1 number2 = number1 + number2
```

```elm
-- Calculator.elm
-- Define the Calculator module, and expose everything within: `six` and `add`
module Calculator exposing (..)

six = 3 + 3

add number1 number2 = number1 + number2
```

https://elm-lang.org/docs/syntax#modules

## Importare funzioni da altri moduli

Per accedere alle funzioni definite in altri moduli si usano gli import.
Quando importi un modulo, tutte le funzioni che esso ha esposto diventano accessibili.
Il modo in cui vi si accede, però, dipende da come il modulo viene importato.

Gli import qualificati sono quelli predefiniti: per accedere a una funzione di un modulo importato così (per esempio la funzione `map` del modulo `List`) si antepone il nome del modulo (`List.map`).

Gli import aperti consentono di accedere direttamente alle funzioni esposte da quel modulo, senza anteporre nulla. Si fanno con la parola chiave `exposing`, come specchio di quella usata nelle esportazioni. Puoi esporre tutte le funzioni disponibili (con `..`) oppure solo alcune (per esempio `map`).

Puoi anche importare i tipi e i loro costruttori da altri moduli, ma è un concetto che affronteremo più avanti.

Gli import qualificati sono preferibili, perché rendono il codice più chiaro ed evitano le collisioni di nomi.

```elm
-- qualified imports
import List                            -- List.map, List.foldl
import List as L                       -- L.map, L.foldl

-- open imports
import List exposing (..)              -- map, foldl, concat, ...
import List exposing ( map, foldl )    -- map, foldl, List.concat
```

https://elm-lang.org/docs/syntax#modules

## Le annotazioni di tipo

Le annotazioni di tipo si definiscono con `name : parameter types -> return type`, dove anche i tipi dei parametri sono separati da `->`.

```elm
add : Int -> Int -> Int
add number1 number2 = number1 + number2
```

Le parentesi si possono usare per definire i parametri di una funzione (che a loro volta si definiscono con la stessa sintassi, da cui la necessità delle parentesi).

```elm
-- Transform every character in a string
map : (Char -> Char) -> String -> String
map charMapperFunction string =
    -- ...
```

https://elm-lang.org/docs/syntax#type-annotations

## I numeri

In Elm ci sono due tipi di numeri, definiti dai tipi `Int` e `Float`.
`Int` corrisponde all'insieme dei numeri interi positivi e negativi.
`Float` corrisponde all'insieme dei numeri reali, limitato dalla precisione del computer.
Le operazioni definite sui numeri di solito funzionano su un tipo o sull'altro, ma non mescolando i due.
Esistono funzioni per convertire tra i due: `toFloat`, che converte un `Int` in un `Float`, e `round`, `floor`, `ceiling` o `truncate`, che convertono un `Float` in un `Int` con semantiche diverse.

https://package.elm-lang.org/packages/elm/core/latest/Basics#Int

## Le operazioni sulle stringhe

Per descrivere parole e frasi nel codice, Elm ha un tipo `String` nativo.
I letterali stringa si scrivono tra virgolette doppie, come `"Hello World!"`.
L'operatore di concatenazione di stringhe `++` e l'operatore di uguaglianza `==` sono disponibili di default.

```elm
hello : String -> String
hello subject = "Hello " ++ subject

hello "World!" --> "Hello World!"
```

La maggior parte delle altre funzioni per le stringhe si trova nel modulo `String`, che va importato.

https://package.elm-lang.org/packages/elm/core/latest/String
