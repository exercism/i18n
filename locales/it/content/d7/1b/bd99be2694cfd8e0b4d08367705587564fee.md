# Istruzioni

Il tuo amico Kojo è un grande appassionato di numeri.
Ha un piccolo sito web chiamato "fun-with-numbers".
Kojo non è molto bravo a programmare, quindi ti ha chiesto aiuto.

Costruirai due funzioni ausiliarie per i nuovi giochi con i numeri sul sito di Kojo e una terza per convalidare l'input che un utente può inserire.

## 1. Calcola la somma dei numeri sulla slot machine

Uno dei giochi sul sito di Kojo assomiglia a una slot machine che mostra due gruppi di rotelle con delle cifre.
Ogni gruppo di cifre rappresenta un numero.
Per la meccanica del gioco, Kojo ha bisogno di conoscere la somma di quei due numeri.

Scrivi una funzione `twoSum` che accetta due array come parametri.
Ogni array è composto da uno o più numeri tra 0 e 9.
La funzione deve interpretare ogni array come un numero e restituire la somma di quei due numeri.

```javascript
twoSum([1, 2, 3], [0, 7]);
//=> 130

// [1, 2, 3] represents 123 and [0, 7] represents 7.
// 123 + 7 = 130
```

## 2. Determina se un numero è palindromo

Un altro gioco sul sito è un piccolo quiz chiamato "Lucky Numbers".
Un utente può inserire un numero e poi vede se il numero appartiene a una qualche sequenza o schema segreto.
La sequenza o lo schema dei "lucky numbers" cambia ogni mese e ogni utente ha solo un numero limitato di tentativi per indovinarlo.

I numeri fortunati di questo mese devono essere numeri palindromi.
I numeri palindromi restano uguali quando si invertono le cifre.

Implementa la nuova funzione `luckyNumber` che accetta un numero come parametro.
La funzione deve restituire `true` se il numero è palindromo e `false` in caso contrario.
Il numero di input sarà sempre un numero intero positivo.

```javascript
luckyNumber(1441);
//=>  true

luckyNumber(123);
//=> false
```

## 3. Genera un messaggio di errore per input non validi dell'utente

In vari punti del sito ci sono campi di input dove gli utenti possono inserire numeri e fare clic su un pulsante per attivare qualche azione.
Kojo vuole migliorare l'esperienza utente del suo sito.
Vuole mostrare un messaggio di errore nel caso in cui l'utente faccia clic sul pulsante ma il campo contenga un valore di input non valido.

Ecco qualche informazione in più su come viene fornito il valore di un campo di input.

- Se l'utente digita qualcosa in un campo, il valore associato è sempre una stringa, anche se ha digitato solo numeri.
- Se l'utente digita qualcosa ma poi lo cancella, la variabile sarà una stringa vuota.
- Prima ancora che l'utente inizi a digitare, la variabile può essere `undefined` o `null`.

Scrivi una funzione `errorMessage` che accetta l'input dell'utente come parametro.
Se l'utente non ha fornito alcun input, `errorMessage` deve restituire `'Required field'`.
Se l'input non rappresenta un numero diverso da zero (secondo le regole di conversione di JavaScript), deve essere restituito `'Must be a number besides 0'`.
In tutti gli altri casi puoi assumere che l'input sia valido: il valore restituito deve essere una stringa vuota.

```javascript
errorMessage('123');
// => ''

errorMessage('');
// => 'Required field'

errorMessage('abc');
// => 'Must be a number besides 0'
```
