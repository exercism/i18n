# Appendice alle istruzioni

## Suggerimenti

Questo è il primo esercizio in cui i test richiedono di lanciare un'[`Exception`][exception-docs].
Le `Exception` vengono in genere lanciate per indicare che un programma ha incontrato un input o uno stato imprevisti.

I test in tutta la traccia verificheranno che le eccezioni che lanci siano:

1. istanze di un tipo Java specificato;
2. (facoltativamente) inizializzate con un messaggio specificato.

[exception-docs]: https://docs.oracle.com/javase/8/docs/api/java/lang/Exception.html
