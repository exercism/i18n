# Installare Python

Se Python non è già disponibile sul tuo sistema, nella sezione [Installazione e utilizzo di Python][using python] della documentazione ufficiale trovi istruzioni dettagliate per ogni piattaforma.
Real Python offre anche una [guida utile][helpful guide] all'installazione su varie piattaforme, tra cui iOS e Android.

Infine, questi post di Brett Cannon, [A quick-and-dirty guide][quick-and-dirty] e [Why you should use `python -m pip`][python-m-pip], offrono consigli molto utili su come gestire le installazioni e i pacchetti di Python.

**Nota per gli utenti MacOS:**  prima di MacOS Monterey (12.3), `Python 2.7` era preinstallato con il sistema operativo.
Usare `Python 2.7` con Exercism o con la maggior parte degli altri programmi non è supportato.
Ti conviene invece installare [Python 3][Python-three downloads] con uno dei metodi descritti di seguito.
A partire da MacOS Monterey (12.3), nessuna versione di Python viene più preinstallata con MacOS.

Alcuni link rapidi alla documentazione, per sistema operativo:

-  [Windows][windows] Inoltre, questo articolo di Microsoft su come [installare Python su Windows][python-on-windows] è utile.
-  [Sistemi Unix e Linux][unix-and-linux] (_funzionano in gran parte anche per MacOS_)
-  [MacOS][macos]

   Ti consigliamo anche di dare un'occhiata ad alcuni dei metodi descritti nell'articolo di Real Python [Installare Python][installing-python] o negli articoli di Brett Cannon linkati sopra.

Attualmente i test e gli strumenti di Exercism supportano `3.10` - `3.13.5` (_test_) e [`Python 3.13.5`][313-new-features] (_strumenti_).
Le eccezioni a questo supporto sono indicate dove si presentano.
La maggior parte degli esercizi funziona con `Python 3.6+`, o anche con versioni precedenti.
Ma non garantiamo il supporto per le versioni non elencate in [Versioni Python attive][active-python-releases].

Consulta la [documentazione di Python 3.13.x][3.13 docs] per sapere cosa è attualmente supportato.
