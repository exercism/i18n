# Informazioni

Elixir rappresenta i valori vero e falso con il tipo booleano. Esistono solo due valori: `true` e `false`. Questi valori possono essere combinati con gli operatori booleani ([`and/2`][strict-and], [`or/2`][strict-or], [`not/1`][strict-not]):

```elixir
true_variable = true and true
false_variable = true and false

true_variable = false or true
false_variable = false or false

true_variable = not false
false_variable = not true
```

Gli operatori [`and/2`][strict-and], [`or/2`][strict-or] e [`not/1`][strict-not] sono strettamente booleani, il che significa che richiedono che il loro _primo_ argomento sia un booleano. Esistono anche operatori booleani equivalenti che funzionano con qualsiasi tipo di argomento: [`&&/2`][and], [`||/2`][or] e [`!/1`][not].

Gli operatori booleani usano la _valutazione a cortocircuito_, il che significa che l'espressione a destra dell'operatore viene valutata solo se necessario.

Ogni operatore ha una precedenza diversa: `not/1` viene valutato prima di `and/2` e `or/2`. Le parentesi possono essere usate per valutare una parte dell'espressione prima delle altre:

```elixir
not true and false
# => false

not (true and false)
# => true
```

Quando si scrive una funzione che restituisce un valore booleano, è [idiomatico terminare il nome della funzione][naming] con un `?`. La stessa convenzione può essere usata per le variabili che memorizzano valori booleani.

```elixir
def either_true?(a?, b?) do
  a? or b?
end
```
