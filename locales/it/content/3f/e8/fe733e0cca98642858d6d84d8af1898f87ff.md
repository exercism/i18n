# Suggerimenti

## 1. Descrivere numeri semplici

- usa `fmt.Sprintf` per formattare

## 2. Descrivere una scatola numerica

- ottieni il risultato dal metodo `Number()`
- usa `fmt.Sprintf` per formattare

## 3. Implementare un metodo che estrae il numero da una scatola numerica elaborata

- usa un'asserzione di tipo per verificare se si tratta di un `FancyNumber`
- ottieni la `string` dal metodo `Value()`
- usa `strconv.Atoi` per convertire la `string` in un `int` (possiamo scartare l'errore, dato che vogliamo 0 se non può essere convertito in un `int`)

## 4. Descrivere una scatola numerica elaborata

- usa `ExtractFancyNumber` per ottenere il valore `int`
- converti l'`int` in un `float64`
- usa `fmt.Sprintf` per formattare

## 5. Implementare `DescribeAnything`, che li usa tutti

- usa le asserzioni di tipo (ad esempio `i.(someType)`) oppure un type switch (`switch v := i.(type)`)
- ricorda di convertire `int` in un `float64`
