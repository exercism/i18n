# Introduzione

## Funzioni anonime

In Elixir le funzioni sono trattate come cittadini di prima classe. Questo significa che:

- Le funzioni con nome e quelle anonime possono essere assegnate a variabili.
- Le funzioni con nome e quelle anonime possono essere passate in giro come dati, come argomenti e valori restituiti.
- Le funzioni anonime possono essere create dinamicamente.

Le funzioni anonime, a differenza delle funzioni con nome, non hanno un riferimento statico disponibile: sono disponibili solo se assegnate a una variabile o chiamate immediatamente.

Potremmo usare le funzioni anonime per:

- Nascondere i dati usando lo scope lessicale (noto anche come closure).
- Creare dinamicamente funzioni a runtime.

Le funzioni anonime iniziano con la parola riservata `fn`, gli argomenti sono separati dal corpo della funzione con il token `->`, e terminano con un `end`. Come per le funzioni con nome, l'ultima espressione della funzione viene _restituita implicitamente_ alla funzione chiamante.

Per chiamare un riferimento a una funzione, devi usare un `.` tra la variabile di riferimento e la lista di argomenti:

```elixir
function_variable = fn param ->
  param + 1
end

function_variable.(1)
# => 2
```

Puoi anche usare la notazione di cattura abbreviata per renderlo più conciso:

```elixir
variable = &(&1 + 1)

variable.(1)
# => 2
```

## Manipolazione dei bit

Elixir supporta molte funzioni per lavorare con i bit, che si trovano nel _modulo Bitwise_.

- `band/2`: AND bit a bit
- `bsl/2`: scorrimento a sinistra bit a bit
- `bsr/2`: scorrimento a destra bit a bit
- `bxor/2`: XOR bit a bit
- `bor/2`: OR bit a bit
- `bnot/1`: NOT bit a bit

Ecco un esempio di come usare una funzione bit a bit:

```elixir
Bitwise.bsl(1, 3)
# => 8
```

Tutte le funzioni bit a bit funzionano solo su numeri interi.

Se usi Elixir versione 1.9 o inferiore, dovrai chiamare `require Bitwise` all'inizio della definizione del modulo per poter usare il modulo _Bitwise_.
