# Introduzione

## Classi

Il principale costrutto orientato agli oggetti in Java è la _classe_, che è una combinazione di dati (_campi_) e comportamento (_metodi_).
I campi e i metodi di una classe sono noti come i suoi _membri_.

L'accesso ai membri può essere controllato tramite i modificatori di accesso, i due più comuni dei quali sono:

- `public`: il membro è accessibile da qualsiasi codice (nessuna restrizione).
- `private`: il membro è accessibile solo dal codice nella stessa classe.

Puoi pensare a una classe come a un modello per creare istanze di quella classe.
Per creare un'istanza di una classe (nota anche come _oggetto_), si usa la parola chiave `new`:

```java
class Car {
}

// Create two car instances
Car myCar = new Car();
Car yourCar = new Car();
```

I campi hanno un tipo e un nome (definito in camelCase) e possono essere definiti ovunque in una classe (per convenzione scritta in PascalCase):

```java
class Car {
    // Accessible by anyone
    public int weight;

    // Only accessible by code in this class
    private String color;
}
```

Si può assegnare facoltativamente un valore iniziale a un campo.
Se un campo _non_ specifica un valore iniziale, viene impostato al valore predefinito del suo tipo.
I valori dei campi di un'istanza possono essere letti e aggiornati usando la notazione con il punto.

```java
class Car {
    // Will be set to specified value
    public int weight = 2500;

    // Will be set to default value (0)
    public int year;
}

Car newCar = new Car();
newCar.weight; // => 2500
newCar.year;   // => 0

// Update value of the field
newCar.year = 2018;
```

I campi privati vengono solitamente aggiornati come effetto collaterale della chiamata a un metodo.
Tali metodi di solito non restituiscono alcun valore, nel qual caso il tipo restituito dovrebbe essere `void`:

```java
class CarImporter {
    private int carsImported;

    public void importCars(int numberOfCars)
    {
        // Update private field from public method
        carsImported = carsImported + numberOfCars;
    }
}
```
