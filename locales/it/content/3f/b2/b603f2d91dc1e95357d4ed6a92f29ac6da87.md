# Istruzioni aggiuntive

## Suggerimenti

Per completare questo esercizio devi implementare la funzione `slices`,
che prende un *text* e restituisce le sottosequenze di cifre di una
dimensione specificata:

Se è la prima volta che risolvi questo esercizio, ti consigliamo di
attenerti alla firma fornita:

```haskell
slices :: Int -> String -> [[Int]]
```

In seguito, potrebbe essere una buona idea tornare su questo problema e
sperimentare con altri tipi di dati e librerie:

- `ByteString`, dal pacchetto *bytestring*.
- `Sequence`, dal pacchetto *containers*.
- `Text`, dal pacchetto *text*.
- `Vector`, dal pacchetto *vector*.

La suite di test è stata progettata di proposito per accettare quasi
qualsiasi firma di tipo che abbia senso, quindi ti incoraggiamo a trovare
quella che ritieni migliore.
