# Appendice alle istruzioni

## Istruzioni specifiche del track

Il tuo compito è implementare un record `circularBuffer` con i seguenti metodi

- `clear()`: svuota il buffer.
- `write(item)`: aggiunge al buffer l'elemento indicato. Se il buffer è pieno, deve lanciare `Error("Cannot write to full buffer.")`.
- `read()`: rimuove dal buffer l'elemento più vecchio e lo restituisce. Se il buffer è vuoto, deve lanciare `Error("Cannot read from an empty buffer.")`.
- `overwrite(item)`: se il buffer è pieno, sovrascrive `item` al posto dell'elemento più vecchio. Se il buffer non è pieno, si comporta come `write`.
