# Istruzioni

In questo esercizio aiuterai due innamorati del liceo a professare il loro amore sui social media, generando un riquadro ASCII con le loro iniziali:

```
❤-------------------❤
|  J. K.  +  M. B.  |
❤-------------------❤
```

## 1. Ottenere la prima lettera del nome

Implementa la funzione `HighSchoolSweetheart.first_letter/1`. Dovrebbe prendere un nome e restituirne la prima lettera. Dovrebbe anche eliminare dal nome gli spazi bianchi superflui.

```elixir
HighSchoolSweetheart.first_letter("Jane")
# => "J"
```

## 2. Formattare la prima lettera come iniziale

Implementa la funzione `HighSchoolSweetheart.initial/1`. Dovrebbe prendere un nome e restituirne la prima lettera, in maiuscolo, seguita da un punto. Assicurati di riutilizzare `HighSchoolSweetheart.first_letter/1`, che hai definito nel passaggio precedente.

```elixir
HighSchoolSweetheart.initial("Robert")
# => "R."
```

## 3. Suddividere il nome completo in nome e cognome

Implementa la funzione `HighSchoolSweetheart.initials/1`. Dovrebbe prendere un nome completo, formato da un nome e un cognome separati da uno spazio, e restituire le iniziali. Assicurati di riutilizzare `HighSchoolSweetheart.initial/1`, che hai definito nel passaggio precedente.

```elixir
HighSchoolSweetheart.initials("Lance Green")
# => "L. G."
```

## 4. Inserire le iniziali all'interno del riquadro ASCII

Implementa la funzione `HighSchoolSweetheart.pair/2`. Dovrebbe prendere due nomi completi e restituire le iniziali all'interno di un riquadro ASCII. Non devi disegnare il riquadro da solo: usa quello incluso nel commento del codice. Assicurati di riutilizzare `HighSchoolSweetheart.initials/1`, che hai definito nel passaggio precedente.

```elixir
HighSchoolSweetheart.pair("Blake Miller", "Riley Lewis")
# => """
# ❤-------------------❤
# |  B. M.  +  R. L.  |
# ❤-------------------❤
# """
```
