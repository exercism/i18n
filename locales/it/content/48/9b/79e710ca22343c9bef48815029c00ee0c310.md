# Introduzione

## Funzioni freccia

Oltre alle dichiarazioni di funzione e alle espressioni di funzione, JavaScript ha anche un'altra sintassi molto concisa per definire una funzione.
Queste funzioni si chiamano _funzioni freccia_.

Ecco un confronto tra una dichiarazione di funzione e una funzione freccia.

```javascript
function addUpTwoNumbers(num1, num2) {
  return num1 + num2;
}
// function keyword removed and => added
const addUpTwoNumbers = (num1, num2) => {
  return num1 + num2;
};
```

Se il corpo della funzione contiene solo un'istruzione return, come nell'esempio sopra, si possono omettere le `{}` e la parola chiave `return`.
Se c'è un solo parametro, si possono omettere anche le parentesi tonde (`()`).

<!-- prettier-ignore-start -->
```javascript
const addUpTwoNumbers = (num1, num2) => num1 + num2;
const square = num => num * num;
```
<!-- prettier-ignore-end -->

Le funzioni freccia si usano spesso per definire brevi funzioni di callback direttamente nella chiamata della funzione.

<!-- prettier-ignore-start -->
```javascript
applyToSquare(number => number * number);
```
<!-- prettier-ignore-end -->

## Analisi degli array

Gli [array][arrays-concept] hanno metodi integrati per analizzare il contenuto dell'array.
La maggior parte di questi metodi accetta come argomento una funzione che restituisce true o false.
Una funzione di questo tipo si chiama [`predicate`][predicate_in_programming].

Questi metodi integrati sono pensati per essere usati _al posto di un ciclo `for`_ o del metodo integrato `forEach`:

Esempio di analisi con un ciclo for:

```javascript
const numbers = [1, 'two', 3, 'four'];
for (var i = 0; i < numbers.length; i++) {
  if (numbers[i] === 'two') {
    return i;
  }
}
// => 1
```

Esempio di analisi con un metodo integrato:

```javascript
const numbers = [1, 'two', 3, 'four'];
numbers.indexOf('two');
// => 1
```

Qui sotto sono mostrati altri metodi integrati utili che puoi usare per analizzare un array.
Vedi [MDN][mdn-array-methods] per un elenco completo dei metodi degli array.

### `includes`

Il metodo `includes(value)` determina se un array contiene un certo valore.
Restituisce `true` quando il valore è presente, `false` in caso contrario.

```javascript
const numbers = [1, 'two', 3, 'four'];
numbers.includes(1);
// => true
numbers.includes('one');
// => false
```

### `every`

Il metodo `every(predicate)` accetta una funzione che è _un predicato_.
Verifica se tutti gli elementi dell'array restituiscono `true` quando vengono passati al predicato.
In altre parole: il metodo verifica che tutti i suoi elementi superino il test passato alla chiamata della funzione.
Restituisce `true` quando ogni elemento supera il test del predicato, `false` in caso contrario.

```javascript
const numbers = [1, 3, 5, 7, 9];
numbers.every((num) => num % 2 !== 0);
// => true
```

### `some`

Il metodo `some(predicate)` è uguale al metodo `every`, ma restituisce `true` se almeno un elemento dell'array supera il test del _predicato_.

```javascript
const numbers = [1, 3, 5, 7, 9];
numbers.some((num) => num % 2 !== 0);
// => true
```

### `find`

Il metodo `find(predicate)` restituisce il valore del primo elemento dell'array che supera il test di `predicate`.
Mentre `some()` restituisce `true` quando il test viene superato, `find()` restituisce il valore effettivo presente nell'array.
Il metodo restituisce `undefined` quando nessuno degli elementi dell'array supera il test del _predicato_.

```javascript
const numbers = [1, 3, 5, 7, 9];
numbers.find((num) => num < 5);
// => 1
```

### `findIndex`

Il metodo `findIndex(predicate)` è uguale al metodo `find()`, ma restituisce l'_indice_ (il primo) dell'elemento che supera il test del _predicato_ invece del `value`.
Il metodo restituisce `-1` quando nessuno degli elementi dell'array supera il test del _predicato_.

```javascript
const numbers = [1, 3, 5, 7, 9];
numbers.findIndex((num) => num > 7);
// => 4
numbers.findIndex((num) => num > 9);
// => -1
```
