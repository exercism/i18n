# Test

Installa le dipendenze.

```sh
dart pub get
```

Esegui i test.

```sh
dart test
```

Per un output più dettagliato di ogni singolo test, usa il reporter expanded.

```sh
dart test -r expanded
```

La maggior parte degli esercizi ha più test e, per impostazione predefinita, tutti tranne il primo vengono saltati.
Per affrontare i test uno alla volta, cambia `skip: true` in `skip: false` su ogni test man mano che procedi.

In alternativa, esegui tutti i test in una volta sola senza modificare il file.

```sh
dart test --run-skipped
```

Al momento della consegna, il test runner online esegue tutti i test, compresi quelli saltati.
