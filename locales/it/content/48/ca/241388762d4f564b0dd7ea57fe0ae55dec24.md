# Introduzione

ABAP supporta gli operatori aritmetici per eseguire calcoli con valori numerici.

```abap
DATA day_rate TYPE p LENGTH 8 DECIMALS 2.
day_rate = rate_per_hour * 8.
```

Gli operatori di base sono:

- `+` per l'addizione.
- `-` per la sottrazione.
- `*` per la moltiplicazione.
- `/` per la divisione.
- `MOD` per il resto di una divisione intera.

```abap
DATA full_months TYPE i.
full_months = floor( num_days / 22 ).

DATA remaining_days TYPE i.
remaining_days = num_days MOD 22.
```

ABAP valuta prima la moltiplicazione e la divisione, poi l'addizione e la sottrazione. Si possono usare le parentesi tonde per rendere esplicito l'ordine desiderato.

```abap
DATA discounted_rate TYPE p LENGTH 8 DECIMALS 2.
discounted_rate = monthly_rate * ( 1 - discount ).
```
