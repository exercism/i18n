# Introduzione

Elixir facilita le pratiche del **principio aperto-chiuso** permettendo alle funzioni di avere più clausole: così, invece di una logica di controllo estesa e codificata a mano, si possono scrivere funzioni mirate che aggiungono o rimuovono comportamenti con facilità.

Elixir offre le _clausole multiple di funzione_ e le _guardie_ per scrivere:

```elixir
def number(n) when n == 7 do
  "Awesome, that's my favorite"
end

def number(_n) do
  "That's not my favorite"
end
```

Al momento dell'esecuzione, Elixir verifica, dall'alto verso il basso del file sorgente, quale clausola di funzione chiamare.

Le variabili non utilizzate vanno precedute da un underscore.
