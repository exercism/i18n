# Introduzione

## Numeri

In C# esistono due tipi diversi di numeri:

- Interi: numeri senza cifre dopo il separatore decimale (numeri interi). Ad esempio `-6`, `0`, `1`, `25`, `976` e `500000`.
- Numeri in virgola mobile: numeri con zero o più cifre dopo il separatore decimale. Ad esempio `-2.4`, `0.1`, `3.14`, `16.984025` e `1024.0`.

I due tipi numerici più comuni in C# sono `int` e `double`. Un `int` è un intero a 32 bit e un `double` è un numero in virgola mobile a 64 bit.

L'aritmetica si esegue usando gli operatori aritmetici standard. I numeri si possono confrontare usando gli operatori di confronto numerico standard e gli operatori di uguaglianza (`==`) e disuguaglianza (`!=`).

In C# esistono due tipi di conversione numerica:

1. Conversioni implicite: non verrà perso alcun dato e non è richiesta alcuna sintassi aggiuntiva.
2. Conversioni esplicite: si potrebbero perdere dei dati ed è richiesta una sintassi aggiuntiva sotto forma di _cast_.

Poiché un `int` ha meno precisione di un `double`, convertire da un `int` a un `double` è sicuro ed è quindi una conversione implicita. Tuttavia, convertire da un `double` a un `int` potrebbe comportare la perdita di dati, quindi richiede una conversione esplicita.

```csharp
int softCool = 1358938113;
double notLost = 4.8151623;

// implicit cast: no loss of information
double macDebug = softCool;         // 1358938113.0

// explicit cast: possible loss of information 
int somethingLost = (int)notLost;   // 4
```

## Istruzioni if

In questo esercizio devi eseguire della logica in modo condizionale. Il modo più comune per farlo in C# è usare un'istruzione `if/else`:

```csharp
int x = 6;

if (x == 5)
{
    // Execute logic if x equals 5
}
else if (x > 7)
{
    // Execute logic if x greater than 7
}
else
{
    // Execute logic in all other cases
}
```

La condizione di un'istruzione `if` deve essere di tipo `bool`. C# non ha il concetto di valori _truthy_.
