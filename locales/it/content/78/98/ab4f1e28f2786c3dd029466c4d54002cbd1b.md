# Introduzione

Molti programmi hanno bisogno di valori (pseudo)casuali per simulare eventi del mondo reale.

Tra gli esempi comuni e familiari ci sono:

- Il lancio di una moneta: un valore casuale tra ('H', 'T').
- Il lancio di un dado: un numero intero casuale da 1 a 6.
- Mescolare un mazzo di carte: un ordinamento casuale di un array di carte.
- La creazione di alberi e cespugli in una simulazione grafica 3D.

Generare valori davvero casuali con un computer è una [sfida tecnica sorprendentemente difficile][why-randomness-is-hard], ed è per questo che esistono anche i generatori «pseudocasuali».

~~~exercism/advanced
[La specifica del linguaggio][spec] per JavaScript non impone l'implementazione della generazione di numeri casuali.
Tutti i principali browser e i runtime JavaScript implementano un PRNG (generatore di numeri pseudocasuali).
Poiché questi numeri non sono crittograficamente sicuri, non dovrebbero mai essere usati per qualcosa che richiede numeri davvero casuali, o almeno crittograficamente sicuri, come la generazione di certificati o password, o altre operazioni.

Esiste uno standard chiamato [Web Cryptography][rfc] che standardizza un'interfaccia per fare crittografia in JavaScript.
È implementato [dai browser][crypto-web] e anche da runtime come [Node.JS][crypto-node] e [Deno][crypto-deno].

Questo concetto non riguarda Web Crypto e si limiterà alla generazione di numeri pseudocasuali.

## Generare numeri casuali

In JavaScript, puoi generare numeri pseudocasuali usando la funzione [`Math.random()`][Math.random].
Restituirà un numero in virgola mobile pseudocasuale compreso tra 0 (incluso) e 1 (escluso).

Per ottenere un numero casuale tra _min_ (incluso) e _max_ (escluso), puoi usare una funzione simile a questa:

```javascript
function getRandomInRange(min, max) {
  return min + Math.random() * (max - min);
}
getRandomInRange(4, 10);
// => 5.72
```

<!-- prettier-ignore -->
~~~exercism/advanced
La maggior parte delle tecniche semplici per ottenere un intervallo di numeri a partire dal numero generato casualmente [introdurrà una distorsione][bias].
Ciò significa che alcuni numeri avranno più probabilità di uscire rispetto ad altri.
Usare la tecnica della moltiplicazione distribuisce la distorsione su tutto l'intervallo, quindi sarà meno evidente e nella maggior parte dei casi non sarà un grosso problema, ma è bene esserne consapevoli.

[bias]: https://adammil.net/blog/v134_Efficiently_generating_random_numbers_without_bias.html
~~~

## Generare numeri interi casuali

Per generare un numero intero casuale, puoi usare `Math.floor()` o `Math.ceil()` per trasformare un numero generato casualmente in un numero intero.
