# Istruzioni

In questo esercizio scriverai del codice per tenere traccia di un array di linguaggi di programmazione che vuoi imparare su Exercism.

Hai sei attività, che hanno tutte a che fare con gli array.

## 1. Crea un nuovo array

Per tenere traccia dei linguaggi che vuoi imparare, dovrai creare un nuovo array. Definisci il binding `newList`, che contiene un nuovo array vuoto.

```fsharp
newList
// => []
```

## 2. Definisci un array esistente

Al momento hai un foglio di carta con l'elenco dei linguaggi che vuoi imparare: F#, Clojure e Haskell. Definisci il binding `existingList` per rappresentare questo array.

```fsharp
existingList
// => ["F#"; "Clojure"; "Haskell"]
```

## 3. Aggiungi un nuovo linguaggio a un array

Mentre esplori Exercism e trovi linguaggi più interessanti, vuoi aggiungerli al tuo array. Implementa la funzione `addLanguage` per aggiungere un nuovo linguaggio all'inizio del tuo array.

```fsharp
addLanguage "TypeScript" ["JavaScript"; "CoffeeScript"]
// => ["TypeScript"; "JavaScript"; "CoffeeScript"]
```

## 4. Conta i linguaggi nell'array

Contare i linguaggi uno per uno è scomodo. Implementa la funzione `countLanguages` per contare quanti linguaggi ci sono nel tuo array.

```fsharp
countLanguages ["C#"; "Racket"; "Rust"; "Ruby"]
// => 4
```

## 5. Inverti l'array

A un certo punto ti accorgi che il tuo array è in realtà in ordine inverso! Implementa la funzione `reverseList` per invertire il tuo array.

```fsharp
reverseList ["Prolog"; "C"; "Idris"; "Assembly"]
// => ["Assembly"; "Idris"; "C"; "Prolog"]
```

## 6. Verifica se l'array è entusiasmante

Anche se ami tutti i linguaggi, F# occupa un posto speciale nel tuo cuore. Per questo, un array di linguaggi ti entusiasma davvero se:

- Il primo elemento dell'array è F#.
- Il secondo elemento dell'array è F# e l'array contiene due o tre linguaggi.

Implementa la funzione `excitingList` per verificare se un array di linguaggi è entusiasmante:

```fsharp
excitingList ["Nim"; "F#"]
// => true
```
