# Informazioni

L'assembly ARM64/AArch64 è la versione a 64 bit del set di istruzioni ARM.
Si basa sul set di istruzioni ARMv7, che a sua volta deriva in modo piuttosto libero dai set di istruzioni legacy ARM Classic.

Questo track consiste nel programmare in linguaggio assembly ARM64, assemblato ed eseguito su un simulatore multipiattaforma.
