# Appendice alle istruzioni

## Callable

In PHP esiste il concetto di [callable](https://www.php.net/manual/en/language.types.callable.php).

Questi possono assumere diverse forme, ma ci concentreremo sulle [funzioni anonime](https://www.php.net/manual/en/functions.anonymous.php).

È possibile creare una funzione anonima in una variabile e chiamarla con dei parametri:

```php
$double = function ($number) {
    return $number * 2;
};

$double(2); // returns 4
$double(4); // returns 8
```
