# Introduzione

Un modo comune di usare le unioni discriminate in F# è rappresentare un insieme fisso di costanti denominate, una struttura chiamata «enum» in altri linguaggi.

Normalmente, in un'unione discriminata di questo tipo, ogni caso può riferirsi esattamente a una sola di quelle costanti denominate.
Tuttavia, a volte è utile riferirsi a più di una costante.
Per farlo, si può annotare l'unione discriminata con l'attributo Flags.

Un'unione discriminata con l'attributo Flags può essere definita come segue (usando la notazione binaria per interi 0b):

```fsharp
[<Flags>]
type PhoneFeatures =
| Call = 0b00000001
| Text = 0b00000010
```

Un'istanza di `PhoneFeatures` con il valore `0b00000011` ha entrambi i flag `Call` e `Text` impostati.
