# Istruzioni

Converti un numero ottale, rappresentato come stringa (ad esempio '1735263'), nel suo equivalente decimale partendo dai principi di base (cioè no, non puoi usare librerie integrate o esterne per eseguire la conversione).

Implementa la conversione da ottale a decimale.
Data una stringa ottale in input, il programma dovrebbe produrre un output decimale.

## Nota

- Implementa la conversione da solo.
  Non usare qualcos'altro per eseguire la conversione al posto tuo.
- Tratta un input non valido come lo 0 ottale.

## Informazioni sul sistema ottale (base 8)

Il sistema decimale è un sistema in base 10.

Un numero come 233 in notazione in base 10 si può intendere
come una combinazione lineare di potenze di 10:

- La cifra più a destra viene moltiplicata per 10^0 = 1
- La cifra successiva viene moltiplicata per 10^1 = 10
- ...
- L'_n_-esima cifra viene moltiplicata per 10^_(n-1)_.
- Tutti questi valori vengono sommati.

Quindi:

```text
   233 # decimal
 = 2*10^2 + 3*10^1 + 3*10^0
 = 2*100  + 3*10   + 3*1
```

Il sistema ottale è simile, ma usa le potenze di 8 invece delle potenze di 10.

Quindi:

```text
   233 # octal
 = 2*8^2 + 3*8^1 + 3*8^0
 = 2*64  + 3*8   + 3*1
 = 128   + 24    + 3
 = 155
```
