# Introduzione

## Stringhe

Le stringhe in Gleam sono testo immutabile racchiuso tra virgolette doppie. Supportano i caratteri unicode e possono essere sviluppate su più righe.

```gleam
let greeting = "Hello, Joe! 📞"

let multi_line_string = "one
two
three"
```

Le stringhe si possono unire tra loro con l'operatore `<>`:

```gleam
let name = "Mike"
"Hello, " <> name <> "!"
// -> "Hello, Mike!"
```

Il modulo [`gleam/string`][stdlib] della libreria standard fornisce funzioni per lavorare con le stringhe.

Nelle espressioni case si può fare pattern matching sulle stringhe:

```gleam
pub fn on_an_excellent_adventure(name: String) -> Bool {
  case name {
    "Bill" -> True
    "Ted" -> True
    _ -> False
  }
}
```

Se vuoi fare pattern matching sull'inizio di una stringa e assegnare il resto a una variabile, puoi usare il pattern con l'operatore `<>`:

```gleam
pub fn profession(name: String) -> String {
  case name {
    "Dr " <> rest -> rest <> " is a doctor"
    _ -> "I'm not sure what " <> name <> " does"
  }
}
```

[stdlib]: https://hexdocs.pm/gleam_stdlib/gleam/string.html
