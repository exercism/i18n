# Appendice alle istruzioni

## Implementazione

Gli oggetti sono rappresentati da [record](https://lfe.gitbooks.io/reference-guide/content/16.html), definiti in `item.lfe`.
Usa `item-weight` per ottenere il peso e `item-value` per ottenere il valore.

```
;; Create an item with weight=5, value=50
(set item (make-item weight 5 value 50))

;; Get the weight. Returns 5.
(item-weight item)

;; Get the value. Returns 50.
(item-value item)
```
