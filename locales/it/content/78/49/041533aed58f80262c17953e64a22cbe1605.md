# Installazione

Per lavorare sugli esercizi, ti serviranno questi programmi:

1. [`OPAM`, il gestore di pacchetti per OCaml](https://opam.ocaml.org/)

   Vedi [Real World Ocaml, 2nd Ed.: Installation Instructions](https://dev.realworldocaml.org/install.html)
   per scoprire come installare e configurare `OPAM` sul tuo sistema operativo.

2. Il compilatore OCaml

   Per vedere un elenco delle versioni disponibili:

   ```bash
   opam switch
   ```

   Se hai già uno switch per OCaml 5.1, puoi caricarlo eseguendo `opam switch <switch-name>`, oppure creare un nuovo switch eseguendo:

   ```bash
   opam switch create exercism 5.4.0
   ```

   Il nome `exercism` qui è facoltativo, ma dare un nome ai propri switch è una buona pratica.

3. Installa le librerie standard estese e le librerie di test

   Esegui il comando seguente per installare le dipendenze richieste da questo track:

   ```bash
   opam install base core_kernel ounit qcheck
   ```

   Alcuni esercizi usano solo la libreria standard di OCaml, altri usano le librerie estese di Jane Street chiamate Base e Core_kernel.
   La libreria di test si chiama OUnit, e alcuni esercizi usano in più la libreria QCheck per i test basati sulle proprietà.
   Eseguendo il comando qui sopra installerai queste librerie.

4. Installa e usa una shell interattiva (facoltativo)

   Un riassunto di [Configurare e usare `utop`](https://dev.realworldocaml.org/install.html):

   ```bash
   opam install utop
   ```

   Crea un nuovo file chiamato `.ocamlinit` nella tua directory home e aggiungici le righe seguenti:

   ```ocaml
   #use "topfind";;
   #require "base";;
   open Base
   ```

5. Installa gli strumenti in VS Code (facoltativo)

   Se usi VS Code:
   - Installa il language server di OCaml da [qui](https://github.com/ocaml/ocaml-lsp).
   - Installa l'estensione OCaml per VS Code da [qui](https://marketplace.visualstudio.com/items?itemName=ocamllabs.ocaml-platform), oppure cerca `OCaml Platform` di Ocaml Labs.
