# Introduzione

ABAP ha diversi tipi numerici. In questo esercizio ne userai due:

- `i` per i valori interi, come un numero di giorni.
- `p` per i valori decimali packed, come una tariffa oraria o uno sconto.

```abap
DATA billable_days TYPE i VALUE 22.
DATA rate_per_hour TYPE p LENGTH 8 DECIMALS 2 VALUE '89.89'.
```

I numeri packed definiscono la loro lunghezza massima e il numero di cifre decimali. I letterali decimali vengono comunemente scritti come valori di testo e convertiti nel tipo decimale di destinazione dal compilatore oppure con `CONV`.

```abap
TYPES discount_rate TYPE p LENGTH 8 DECIMALS 6.

DATA discount TYPE discount_rate.
discount = CONV discount_rate( '0.15' ).
```

ABAP mette a disposizione funzioni numeriche integrate per l'arrotondamento. La funzione `floor` arrotonda per difetto al numero intero più vicino, mentre `ceil` arrotonda per eccesso al numero intero più vicino.

```abap
DATA full_months TYPE i.
full_months = floor( 70 / 22 ).

DATA rounded_cost TYPE i.
rounded_cost = ceil( '14527.2' ).
```
