# Introduzione

I cicli `for` sono il tipo di ciclo più complesso in PHP. Si comportano come i cicli `for` di `C`, `Java` e `JavaScript`. La loro forma di base è:

```php
for (expr1; expr2; expr3) {
  // statements
}
```

La prima espressione (_expr1_) viene valutata prima che il ciclo inizi. La seconda espressione (_expr2_) viene valutata prima di ogni iterazione: se il suo valore è _truthy_, le istruzioni vengono eseguite. Dopo l'esecuzione delle istruzioni, viene valutata la terza espressione (_expr3_).
