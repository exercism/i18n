# Introduzione

## Conversione di tipo

Go richiede una conversione esplicita tra tipi diversi.
La conversione tra tipi (nota anche come **type casting**) avviene tramite una funzione con il nome del tipo in cui convertire.
Ad esempio, per convertire un `int` in un `float64` devi fare quanto segue:

```go
var x int = 42 // x has type int
f := float64(x) // f has type float64 (ie. 42.0)
```

## Convertire tra tipi primitivi e stringhe

Esiste un pacchetto `strconv` per convertire tra tipi primitivi (come `int`) e `string`.

```go
import "strconv"

var intString string = "42"
var i, err = strconv.Atoi(intString)

var number int = 12
var s string = strconv.Itoa(number)
```

## Asserzioni di tipo

Le interfacce in Go possono introdurre ambiguità sul tipo sottostante.
Un'asserzione di tipo permette di estrarre il valore concreto sottostante di un valore di interfaccia usando questa sintassi: `interfaceVariable.(concreteType)`.

Ad esempio:

```go
var input any = 12
number := input.(int)
```

NOTA: questo causerà un panic se la variabile di interfaccia non contiene un valore del tipo concreto.

Possiamo verificare se un valore di interfaccia contiene un tipo concreto specifico sfruttando entrambi i valori restituiti dall'asserzione di tipo: il valore sottostante e un valore booleano che indica se l'asserzione è riuscita.
Ad esempio:

```go
str, ok := input.(string) // no panic if input is not a string
```

Se `input` contiene una `string`, allora `str` sarà il valore sottostante e `ok` sarà true.
Se `input` non contiene una `string`, allora `str` sarà il valore zero del tipo `string` (cioè `""`, la stringa vuota) e `ok` sarà false.
In nessun caso si verifica un panic.

## Switch di tipo

Uno **switch di tipo** può eseguire diverse asserzioni di tipo in serie.
Ha la stessa sintassi di un'asserzione di tipo (`interfaceVariable.(concreteType)`), ma `concreteType` viene sostituito con la parola chiave `type`.
Ecco un esempio:

```go
var i any = 12 // try: 12.3, true, int64(12), []int{}, map[string]int{}

switch v := i.(type) {
case int:
    fmt.Printf("the integer %d\n", v)
case string:
    fmt.Printf("the string %s\n", v)
default:
    fmt.Printf("type, %T, not handled explicitly: %#v\n", v, v)
}
```
