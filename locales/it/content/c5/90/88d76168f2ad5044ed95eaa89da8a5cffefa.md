# Istruzioni

Nella tua zona c'è una scuola con un'associazione studentesca molto attiva.
L'associazione studentesca è gestita da un presidente e ogni 2 anni
si tengono le elezioni per eleggere un nuovo presidente.

Quest'anno si è deciso che serviva un nuovo sistema digitale per contare i voti.
La scuola ha bisogno del tuo aiuto per costruire questo nuovo sistema.

## 1. Crea un contatore di voti

Una delle prime cose di cui il nuovo sistema di voto ha bisogno è un contatore di voti.
Questo contatore serve a tenere traccia dei voti che ha un particolare candidato.

Crea una funzione `NewVoteCounter` che accetta il numero di voti iniziali di un candidato e restituisce un puntatore a un `int`, inizializzato con il numero di voti iniziali dato.

```go
var initialVotes int
initialVotes = 2

var counter *int
counter = NewVoteCounter(initialVotes)
*counter == initialVotes // true
```

## 2. Ottieni il numero di voti da un contatore

Ora hai un modo per creare nuovi contatori! Ma ti accorgi che il nuovo sistema avrà bisogno anche di un modo per ottenere il numero di voti da un contatore.

Crea una funzione `VoteCount` che prende un contatore (`*int`) come argomento e restituisce il numero di voti nel contatore.
Se il contatore è `nil`, devi assumere che non abbia voti:

```go
var votes int
votes = 3

var voteCounter *int
voteCounter = &votes

VoteCount(voteCounter)
// => 3

var nilVoteCounter *int
VoteCount(nilVoteCounter)
// => 0
```

## 3. Incrementa i voti di un contatore

È finalmente il momento di contare i voti! Ora ti serve un modo per incrementare i voti in un contatore.

Crea una funzione `IncrementVoteCount` che prende un contatore (`*int`) come argomento e un numero di voti, e incrementa il contatore di quel numero di voti.
Puoi assumere che il puntatore passato non sarà mai `nil`.

```go
var votes int
votes = 3

var voteCounter *int
voteCounter = &votes

IncrementVoteCount(voteCounter, 2)

votes == 5          // true
*voteCounter == 5   // true
```

## 4. Crea i risultati delle elezioni

Con tutti i voti ormai contati, è il momento di preparare l'annuncio dei risultati per tutta la scuola.
Per farlo, ti accorgi che avere solo i contatori dei voti non basta.
Serve un modo per associare il numero di voti a un particolare candidato.

Crea una funzione `NewElectionResult` che riceve il nome di un candidato e il suo numero di voti e
restituisce un nuovo risultato elettorale.

```go
var result *ElectionResult
result = NewElectionResult("Peter", 3)

result.Name == "Peter"  // true
result.Votes == 3       // true
```

La struct del risultato elettorale è già stata creata per te ed è definita come:

```go
type ElectionResult struct {
    // Name of the candidate
    Name    string
    // Votes of votes the candidate had
    Votes   int
}
```

## 5. Annuncia i risultati

È il momento di annunciare il nuovo presidente alla scuola!
Il presidente sarà annunciato nei piccoli tabelloni digitali che la scuola ha a disposizione.
Il messaggio dovrebbe mostrare il nome del nuovo presidente e i voti che ha ottenuto, nel seguente formato: `<candidate_name> (<votes>)`.
Questo è un esempio di tale messaggio: `"Peter (51)"`.

Crea una funzione `DisplayResult` che riceve un `*ElectionResult` come argomento e restituisce una stringa con il messaggio da mostrare.

```go
var result *ElectionResult
result = &ElectionResult{
    Name: "John",
    Votes: 32,
}

DisplayResult(result)
// => John (32)
```

## 6. Riconteggio dei voti

Per assicurarsi che i risultati finali fossero accurati, i voti sono stati ricontati.
Nel riconteggio è emerso che il numero di voti di alcuni candidati era sbagliato di uno.

Crea una funzione `DecrementVotesOfCandidate` che riceve i risultati finali e il nome di un candidato per il quale devi decrementare il conteggio dei voti.
I risultati finali sono dati sotto forma di una `map[string]int`, dove le chiavi sono i nomi dei candidati e i valori sono il totale dei loro voti.

```go
var finalResults = map[string]int{
    "Mary":  10,
    "John":  51,
}

DecrementVotesOfCandidate(finalResults, "Mary")

finalResults["Mary"]
// => 9
```
