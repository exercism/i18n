# Informazioni

In Haxe, un **array** è una collezione di elementi (di solito) dello stesso tipo. Esistono tre modi per creare un array in Haxe: tramite un costruttore oppure tramite una sintassi di dichiarazione. In Haxe, il primo elemento di un array ha indice zero:

```haxe
var a = [1, 2, 3];
trace(a); // [1,2,3]

// Here the second element is called by index
trace(a[1]); // 2

// The actual first element's index is 0
trace(a[0]); // 1
```

Per creare un array usando un costruttore, devi passare il tipo degli elementi che verranno inclusi nell'array:

```haxe
var a:Array<Int> = [0, 1, 2, 3];
a[1] = "Hello"; // Error: the array a takes integers only
```

Dato che l'accesso agli array in Haxe è illimitato, cioè è garantito che non lanci un'eccezione, questo richiede ulteriori chiarimenti:

- Se si effettua un accesso in lettura su un indice inesistente, viene restituito un valore che dipende dal target.
- Se si effettua un accesso in scrittura con un indice positivo fuori dai limiti, `null` (o il valore predefinito per i tipi di base sui target statici) viene inserito in tutte le posizioni tra l'ultimo indice definito e quello appena scritto.
- Se si effettua un accesso in scrittura con un indice negativo, il risultato non è specificato.

Se vogliamo che un array contenga elementi di tipi diversi, aggiungiamo il tipo `Dynamic` all'indicatore di tipo:

```haxe
var a:Array<Dynamic> = [10, "Bob", true]
```

## Iterazione

Gli array si possono iterare con un ciclo `for`:

```haxe
var nums = [2, 3, 5];
var sum = 0;
for (num in nums) {
  sum += num;
}
trace(sum); // 10
```
