# Istruzioni

Sei un appassionato di birdwatching che tiene traccia di quanti uccelli hanno visitato il tuo giardino negli ultimi sette giorni.

Hai sei compiti, tutti legati al numero di uccelli che hanno visitato il tuo giardino.

## 1. Controlla quali erano i conteggi della settimana scorsa

Per poter fare dei confronti, tieni sempre a portata di mano una copia dei conteggi della settimana scorsa, che erano: 0, 2, 5, 3, 7, 8 e 4. Implementa il metodo `BirdWatcher.getLastWeek()` che restituisce i conteggi della settimana scorsa:

```java
BirdWatcher.getLastWeek();
// => [0, 2, 5, 3, 7, 8, 4]
```

## 2. Controlla quanti uccelli sono venuti oggi

Implementa il metodo `BirdWatcher.getToday()` per restituire quanti uccelli hanno visitato il tuo giardino oggi. I conteggi degli uccelli sono ordinati per giorno: il primo elemento è il conteggio del giorno più lontano, l'ultimo è il conteggio di oggi.

```java
int[] birdsPerDay = { 2, 5, 0, 7, 4, 1 };
BirdWatcher birdCount = new BirdWatcher(birdsPerDay);
birdCount.getToday();
// => 1
```

## 3. Incrementa il conteggio di oggi

Implementa il metodo `BirdWatcher.incrementTodaysCount()` per incrementare il conteggio di oggi:

```java
int[] birdsPerDay = { 2, 5, 0, 7, 4, 1 };
BirdWatcher birdCount = new BirdWatcher(birdsPerDay);
birdCount.incrementTodaysCount();
birdCount.getToday();
// => 2
```

## 4. Controlla se c'è stato un giorno senza uccelli in visita

Implementa il metodo `BirdWatcher.hasDayWithoutBirds()` che restituisce `true` se c'è stato un giorno in cui zero uccelli hanno visitato il giardino; altrimenti, restituisce `false`:

```java
int[] birdsPerDay = { 2, 5, 0, 7, 4, 1 };
BirdWatcher birdCount = new BirdWatcher(birdsPerDay);
birdCount.hasDayWithoutBirds();
// => true
```

## 5. Calcola il numero di uccelli in visita per i primi giorni indicati

Implementa il metodo `BirdWatcher.getCountForFirstDays()` che restituisce il numero di uccelli che hanno visitato il tuo giardino dall'inizio della settimana, ma limita il conteggio al numero di giorni specificato dall'inizio della settimana.

```java
int[] birdsPerDay = { 2, 5, 0, 7, 4, 1 };
BirdWatcher birdCount = new BirdWatcher(birdsPerDay);
birdCount.getCountForFirstDays(4);
// => 14
```

## 6. Calcola il numero di giorni intensi

Alcuni giorni sono più intensi di altri. Un giorno intenso è quello in cui cinque o più uccelli hanno visitato il tuo giardino.
Implementa il metodo `BirdWatcher.getBusyDays()` per restituire il numero di giorni intensi:

```java
int[] birdsPerDay = { 2, 5, 0, 7, 4, 1 };
BirdWatcher birdCount = new BirdWatcher(birdsPerDay);
birdCount.getBusyDays();
// => 2
```
