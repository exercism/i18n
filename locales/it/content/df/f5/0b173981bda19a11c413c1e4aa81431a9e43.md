# Introduzione

## Numeri

In Python esistono tre diversi tipi di numeri integrati: `ints`, `floats` e `complex`. In questo esercizio, però, avrai a che fare solo con `ints` e `floats`.

### ints

Gli `ints` sono numeri interi, ad esempio `1234`, `-10`, `20201278`.

In Python i numeri interi hanno [precisione arbitraria][arbitrary-precision]: il numero di cifre è limitato solo dalla memoria disponibile del sistema host.

### floats

I `floats` sono numeri che contengono un punto decimale, ad esempio `0.0`, `3.14`, `-9.01`.

I numeri in virgola mobile sono di solito implementati in Python usando un `double` in C (_15 cifre decimali di precisione_), ma la loro rappresentazione varia in base al sistema host e ad altri dettagli di implementazione. Questo può riservare qualche sorpresa quando si lavora con i float, ma è «abbastanza buono» per la maggior parte delle situazioni.

## Aritmetica

Python supporta pienamente l'aritmetica tra `ints` e `floats`. Quando vengono usati con gli operatori aritmetici binari (`+`, `-`, `*`, `/`, `//` e `%`), converte i numeri di tipo più ristretto per adattarli alle loro controparti di tipo più ampio.

Python considera gli `ints` più ristretti dei `floats`. Quindi, usare un float in un'espressione garantisce che anche il risultato sarà un float. Tuttavia, quando si esegue una divisione il risultato sarà sempre un float, anche se vengono usati solo numeri interi.

```python
# The int is widened to a float here, and a float type is returned.
>>> 3 + 4.0
7.0
>>> 3 * 4.0
12.0
>>> 3 - 2.0
1.0
# Division always returns a float.
>>> 6 / 2
3.0
>>> 7 / 4
1.75
# Calculating remainders.
>>> 7 % 4
3
>>> 2 % 4
2
>>> 12.75 % 3
0.75
```

Se serve un risultato intero, puoi usare `//` per troncare il risultato.

```python
>>> 6 // 2
3
>>> 7 // 4
1
```

Per convertire un float in un intero, puoi usare `int()`. Per convertire un intero in un float, puoi usare `float()`.

```python
>>> int(6 / 2)
3
>>> float(1 + 2)
3.0
```
