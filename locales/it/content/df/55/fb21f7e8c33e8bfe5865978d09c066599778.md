# Informazioni

I combinator trasformano gli schemi di riordino dello stack in parole con un nome, componibili tra loro. Quando hai scritto abbastanza Factor, smetti di pensare «devo fare `dup`, poi eseguire F, poi conservare l'originale» e scrivi semplicemente `[ F ] keep`.

| schema                                | spostamenti                    | combinator      |
|------------------------------------|-------------------------------|-----------------|
| applica F, conserva l'input           | `dup F swap`                  | `[ F ] keep`    |
| due funzioni su un input              | `dup F swap G`                | `[ F ] [ G ] bi`|
| tre funzioni su un input              | complicato                    | `[ F ] [ G ] [ H ] tri` |
| molte funzioni su un input            | molto complicato              | `{ Fs … } cleave`|
| opera sui valori *sotto* la cima      | `swap F swap`                 | `[ F ] dip`     |
| stessa operazione su due valori       | `swap F swap F`               | `[ F ] bi@`     |
| operazioni diverse su due valori      | `swap F swap G`               | `[ F ] [ G ] bi*`|

La famiglia con il prefisso `2` (`2bi`, `2dip`, `2tri`, `2dup`, `2drop`, `2nip`, `2swap`) fa lo stesso quando ogni operazione richiede *due* input; `3dup` e `4dup` estendono l'idioma di duplicazione a tre o quattro valori in cima allo stack.

Oltre alla famiglia cleave/dip/bi, [`kernel`][kernel] offre anche varianti di controllo del flusso che propagano `f` in modo pulito:

| parola     | effetto                                             |
|-------------|-----------------------------------------------------|
| `if*`       | il ramo vero vede il valore, quello falso no        |
| `?last`     | l'ultimo elemento di una sequenza, oppure `f` se è vuota |
| `pop*`      | variante di `pop` che scarta (modifica un vettore)  |
| `dupd`      | duplica il *secondo* dalla cima                     |
| `pick`      | copia il *terzo* dalla cima sulla cima              |
| `swapd`     | scambia il secondo e il terzo dalla cima            |
| `rotd`      | ruota i tre in fondo di uno stack profondo quattro  |
| `tuck`      | copia la cima sotto il secondo dalla cima           |
| `with`      | incorpora un valore fisso in una quotation per HOS  |
| `while`     | esegue un ciclo finché vale un predicato            |
| `until`     | esegue un ciclo finché un predicato non è vero      |

Scegliere il combinator giusto è di per sé un'abilità. La regola generale: quando il corpo di una definizione contiene più di una parola di riordino di fila, di solito esiste un combinator che esprime meglio l'intenzione.

[kernel]: https://docs.factorcode.org/content/vocab-kernel.html
