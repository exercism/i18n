# Introduzione

I caratteri e le stringhe costituiscono la base per la rappresentazione del testo in Elm.
Le stringhe si possono pensare come array di caratteri, e la maggior parte delle funzioni di `List` ha il proprio equivalente nel modulo `String`.

## Caratteri

Il tipo `Char` rappresenta un singolo carattere Unicode racchiuso tra virgolette singole, ad esempio `'a'`. 
Il modulo `Char` fornisce funzioni di predicato (`Char -> Bool`) per verificare le caratteristiche di un carattere: `isUpper`, `isLower`, `isAlpha` e `isAlphaNum`.
Il modulo fornisce anche funzioni per convertire un carattere, `toUpper`, `toLower`, `toLocaleUpper`, `toLocaleLower`, e per passare da e verso il suo valore numerico Unicode (`Int`) con `toCode` e `fromCode`.

## Stringhe

Il tipo `String` fornisce una rappresentazione integrata che consente di manipolare le stringhe in modo efficiente e può rappresentare qualsiasi sequenza di caratteri Unicode.
Le stringhe sono rappresentate con virgolette doppie: `"this is a string"`.
Le stringhe multi-riga sono rappresentate con tre virgolette doppie e possono contenere virgolette e ritorni a capo senza doverli precedere da escape.

```elm 
haiku = 
"""
    Code's strings entwine
    , In binary, thoughts combine
    , Logic's elegant line.
"""
```

## Manipolazione delle stringhe

`reverse : String -> String` inverte la stringa.
```elm 
reverse "Hello world." 
    --> ".dlrow olleH"
```

`repeat : Int -> String -> String` ripete una stringa n volte.
```elm 
repeat 2 "Hello world." 
    --> "Hello world.Hello world."
```

`replace : String -> String -> String -> String` sostituisce tutte le occorrenze di una data sottostringa.
```elm
replace "Hello" "Goodbye cruel" "Hello world." 
    --> "Goodbye cruel world."
```

`append : String -> String -> String` aggiunge una stringa in coda a un'altra.
Anche l'operatore `++` può essere usato a questo scopo.
```elm
append "butter" "fly" 
    --> "butterfly"
"butter" ++ "fly" 
    --> "butterfly"
```

`concat : List String -> String` concatena un array di stringhe in un'unica stringa.
```elm
concat ["never", "the", "less"] 
    --> "nevertheless"
```

`split : String -> String -> List String` divide una stringa in un array di stringhe in corrispondenza del separatore dato.
```elm
split ";" "cat;dog;cow" 
    --> ["cat", "dog", "cow"]
```

`join : String -> List String -> String` concatena un array di stringhe unendole con un separatore dato.
```elm
join "a" ["H", "w", "ii", "n"] 
    --> "Hawaiian"
```

`words : String -> List String` scompone una stringa in più stringhe, dividendo in corrispondenza di gruppi di spazi bianchi.
```elm
words "How are \t you? \n Good?" 
    --> ["How", "are", "you?", "Good?"]
```

`lines : String -> List String` scompone una stringa in righe, dividendo in corrispondenza dei ritorni a capo.
```elm
lines "How are you?\nGood?" 
    --> ["How are you?", "Good?"]
```

`cons : Char -> String -> String` aggiunge un carattere all'inizio di una stringa.
```elm
cons 'T' "he truth is out there" 
    --> "The truth is out there"
```

`uncons : String -> Maybe ( Char, String )` divide una stringa non vuota nella sua testa e nella sua coda.
Questo permette di fare pattern matching sulle stringhe esattamente come si farebbe con gli array.
Le stringhe vuote restituiscono `Nothing`.
```elm
uncons "abc" 
    --> Just ('a', "bc")
uncons ""
    --> Nothing
```

## Ottenere sottostringhe

`slice : Int -> Int -> String -> String` estrae una sottostringa dati un indice iniziale e uno finale.
Gli indici negativi vengono contati a partire dalla fine dell'array.
```elm
slice 0 6 "snakes on a plane!" 
    --> "snakes"
slice 0 -7 "snakes on a plane!"
    --> "snakes on a"
```

`left : Int -> String -> String` e `right : Int -> String -> String` estraggono n caratteri rispettivamente dal lato sinistro o dal lato destro della stringa.

```elm
left 2 "Mulder" 
    --> "Mu"
right 2 "Scully" 
    --> "ly"
```

`dropLeft : Int -> String -> String` e `dropRight : Int -> String -> String` eliminano n caratteri rispettivamente dal lato sinistro o dal lato destro di una stringa.
```elm
dropRight 6 "Hello world." 
    --> "Hello"
dropLeft 6 "Hello world." 
    --> "world"
```

## Verificare le caratteristiche di una stringa

`length : String -> Int` restituisce il numero di caratteri in una stringa.
```elm 
length "Hello world." 
    --> 12
```

`isEmpty : String -> Bool` stabilisce se una stringa è vuota. 
```elm 
isEmpty "Hello world." 
    --> False
```

`contains : String -> String -> Bool` verifica se la seconda stringa contiene la prima.
```elm
contains "the" "theory" 
    --> True
contains "THE" "theory" 
    --> False
```

`startsWith : String -> String -> Bool` e `endsWith : String -> String -> Bool` verificano se la seconda stringa inizia o termina con una data sottostringa.
```elm
startsWith "the" "theory" 
    --> True
endsWith "ory" "theory" 
    --> True
```

`indexes : String -> String -> List Int` restituisce un array con tutti gli indici iniziali di una sottostringa all'interno di un'altra stringa.
```elm
indexes "ss" "Mississippi"  
    --> [2, 5]
```

## Convertire le stringhe
`toInt : String -> Maybe Int` prova a convertire una stringa in `Just Int` e restituisce `Nothing` per le stringhe dal formato non corretto.
```elm
toInt "-42" 
    --> Just -42
toInt "3.1" 
    --> Nothing
toInt "two" 
    --> Nothing
```

`fromInt : Int -> String` converte un intero in una stringa.
```elm
fromInt -42 
    --> "-42"
```

`toFloat : String -> Maybe Float` prova a convertire una stringa in un numero in virgola mobile, fallendo sulle stringhe dal formato non corretto.
```elm
toFloat "-42" 
    --> Just -42.0
toFloat "3.1" 
    --> Just 3.1
toFloat "two" 
    --> Nothing
```

`fromFloat : Float -> String` converte un numero in virgola mobile in una stringa.
```elm
fromFloat 3.9 
    --> "3.9"
```

`toList : String -> List Char` e `fromList : List Char -> String` convertono rispettivamente una stringa in un array di caratteri e viceversa.
```elm 
toList "abc" 
    --> ['a', 'b', 'c']
fromList ['a', 'b', 'c'] 
    --> "abc"
```

`fromChar : Char -> String` converte un carattere in una stringa.
```elm
fromChar 'a' 
    --> "a"
```

## Formattare le stringhe

`toUpper : String -> String` e `toLower : String -> String` convertono le stringhe rispettivamente tutte in maiuscolo o tutte in minuscolo.
Utili per i confronti senza distinzione tra maiuscole e minuscole.
```elm
toUpper "skinner" 
    --> "SKINNER"
toLower "X-FILES" 
    --> "x-files"
```

`pad : Int -> Char -> String -> String` riempie una stringa su entrambi i lati con il `Char` fornito finché non raggiunge la lunghezza indicata.
```elm
pad 5 ' ' "11"  
    --> "  11 "
```
Allo stesso modo, `padLeft` e `padRight` riempiono una stringa su un lato finché non raggiunge una data lunghezza.

`trim : String -> String` rimuove gli spazi bianchi su entrambi i lati di una stringa.
```elm
trim "  hats  \n" 
    --> "hats"
```
`trimLeft` e `trimRight` rimuovono gli spazi bianchi su un lato di una stringa.

## Funzioni di ordine superiore

`map : (Char -> Char) -> String -> String` trasforma ogni carattere di una stringa con la funzione data.
Nota che la funzione fornita deve essere una mappatura da e verso `Char`.
```elm
map (\c -> if c == '/' then '.' else c) "a/b/c" 
    --> "a.b.c"
```

`filter : (Char -> Bool) -> String -> String` mantiene solo i caratteri che superano il test.
```elm
filter isDigit "R2-D2" 
    --> "22"
```

`foldl : (Char -> b -> b) -> b -> String -> b` riduce una stringa partendo da sinistra.
La funzione viene applicata con il primo carattere come primo parametro e un valore iniziale fornito come secondo parametro.
Il risultato della funzione deve essere dello stesso tipo del valore iniziale fornito e viene applicato a ogni carattere in sequenza.
```elm
foldl (\c acc -> Char.toCode c + acc) 0 "the sum of my unicode is " 
    --> 2260
```
`foldr` fa la stessa cosa, ma partendo dal lato destro della stringa.

`any : (Char -> Bool) -> String -> Bool` stabilisce se almeno un carattere restituisce `True` al predicato fornito.
```elm
any isDigit "R2-D2" 
    --> True
any isDigit "heart" 
    --> False
```
`all : (Char -> Bool) -> String -> Bool` stabilisce se tutti i caratteri di una stringa restituiscono `True` al predicato fornito.
```elm
all isDigit "R2-D2" 
    --> False
all isAlpha "heart" 
    --> True
```
