# Test


## Eseguire e testare le soluzioni


### Dalla riga di comando

Digita semplicemente `make chez` se usi ChezScheme oppure `make guile` se usi GNU Guile\.

### Da una REPL

* Inserisci `test.scm` al prompt della REPL\.
* Sviluppa la soluzione nel file di soluzione dell'esercizio (ad esempio, `hello-world.scm`), ricaricando man mano\.
* Esegui `(test)` per verificare la soluzione\.
