# Istruzioni

Sei un insegnante.
Alla fine dell'anno hai assegnato un voto numerico a ciascuno dei tuoi studenti.
Ora devi convertire quel voto in un voto in lettere e contare quanti studenti hanno ottenuto ciascun voto.

## 1. Converti un voto numerico in un voto in lettere

La funzione `letter_grade` prende in input un voto numerico e produce in output la lettera.
Usa questi intervalli:

| Lettera |      Voto |
| :-----: | --------: |
|   A     | 90% - 100% |
|   B     |  80% - 89% |
|   C     |  70% - 79% |
|   D     |  60% - 69% |
|   F     |   0% - 59% |

Esempio:

```jq
75 | letter_grade   # => "C"
```

## 2. Conta il numero di studenti per ogni voto in lettere

La funzione `count_letter_grades` prende un oggetto che mappa i nomi degli studenti ai loro voti.
L'output sarà un oggetto che mappa ogni voto in lettere al numero di studenti con quel voto.

Esempio:

```jq
{"Joe": 78, "Jane": 93, "Richard": 72} | count_letter_grades
# => {"A": 1, "B": 0, "C": 2, "D": 0, "F": 0}
```

Ci sono diversi modi per risolvere questo problema.
Usa il filtro `reduce` per esercitarti.
