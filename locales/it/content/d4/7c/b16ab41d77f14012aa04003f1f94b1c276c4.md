# Descrizione

In questo esercizio creerai un programma utile, così non dovrai ricordare i valori delle bande.
Il programma riceverà in input 1, 4 o 5 colori e restituirà il valore corretto in ohm.
Le bande di colore sono codificate come segue:

| Colore      | Valore |
|-------------|-------|
| Black       | 0     |
| Brown       | 1     |
| Red         | 2     |
| Orange      | 3     |
| Yellow      | 4     |
| Green       | 5     |
| Blue        | 6     |
| Violet      | 7     |
| Gray        | 8     |
| White       | 9     |
|-------------|-------|

In [`Resistor Color Trio`][resistor-color-trio-exercise] hai decodificato le prime tre bande di colore.
Per esempio: orange-orange-brown corrisponde al valore principale `330`.
In questo esercizio dovrai aggiungere anche la _tolleranza_.
La tolleranza è la quantità massima di cui un valore può essere al di sopra o al di sotto del valore principale.
Per esempio, se l'ultima banda è green, la tolleranza massima sarà `±0.5%`.

La banda di tolleranza avrà uno di questi valori:

| Colore | Tolleranza |
|--------|----------:|
| Grey   | ±0.05%    |
| Violet | ±0.10%    |
| Blue   | ±0.25%    |
| Green  | ±0.50%    |
| Brown  | ±1.00%    |
| Red    | ±2.00%    |
| Gold   | ±5.00%    |
| Silver | ±10.00%   |
|--------|-----------|

La resistenza a quattro bande è composta così:

| Banda_1  | Banda_2  | Banda_3     | Banda_4    |
| ------- | ------- | ---------- | --------- |
| Valore_1 | Valore_2 | Moltiplicatore | Tolleranza |

Esempi:

- orange-orange-brown-green sarebbe `330` ohm con una tolleranza di `±0.5%`.
- orange-orange-red-grey sarebbe `3300` ohm con una tolleranza di `±0.05%`.

La differenza tra una resistenza a quattro bande ed una a cinque bande è che quella a cinque bande ha una banda in più per indicare un valore più preciso.

| Banda_1  | Banda_2  | Banda_3  | Banda_4     | Banda_5    |
| ------- | ------- | ------- | ---------- | --------- |
| Valore_1 | Valore_2 | Valore_3 | Moltiplicatore | Tolleranza |

Esempi:

- orange-orange-orange-black-green sarebbe `333` ohm con una tolleranza di `±0.5%`.
- orange-red-orange-blue-violet sarebbe `323 million` ohm con una tolleranza di `±0.1%`.

Esistono anche resistenze ad una banda.
Le resistenze ad una banda hanno solo il colore black, con un valore di 0.

Il programma dovrà tradurre in un'etichetta una `list` di input con i colori delle bande di una resistenza:

«... ohms ±...%»

Quindi una `list` di input `["orange", "orange", "black", "green"]` dovrà restituire:

«33 ohms ±0.5%»

Quando ci sono migliaia di ohm, diciamo «kiloohms».
È simile a dire «chilometro» per 1000 metri e «chilogrammo» per 1000 grammi.

Quindi una `list` di input `["orange", "orange", "orange", "grey"]` dovrà restituire:

«33 kiloohms ±0.05%»

Quando ci sono milioni di ohm, diciamo «megaohms».

Quindi una `list` di input `["orange", "orange", "blue", "red"]` dovrà restituire:

«33 megaohms ±2%»
