# Appendice alle istruzioni

## Implementazione

Le funzioni di questo esercizio accettano un array contenente uno o più numeri, ognuno dei quali rappresenta un «punteggio di gioco».

I punteggi di gioco del giocatore si possono leggere in

| `scores`   |
|---|
| `scores[0]` |
| `scores[1]` |
| ... |
| `scores[scores_len - 1]` |

`personal_top_three()` deve scrivere i punteggi migliori del giocatore in

| `output`   |
|---|
| `output[0]` |
| ... |
