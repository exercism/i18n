# Suggerimenti

## Generale

- `<min-heap>`, `heap-push`, `heap-peek` e `heap-pop-all` si trovano tutti in
  [`heaps`][heaps]; `values` è in [`assocs`][assocs].
- Un heap memorizza ogni elemento come un *valore* con una *chiave*; la chiave è
  la priorità. `heap-push` li prende come `( value key heap -- )`.

## 1. Apri la coda

- `<min-heap>` costruisce un min-heap vuoto: la chiave più piccola viene servita
  per prima.

## 2. Aggiungi un cliente

- Il nome del cliente è il valore e la priorità è la chiave, che è esattamente
  l'ordine che `heap-push` vuole.
- `heap-push` consuma la coda. Usa `[ heap-push ] keep` per aggiungere il
  cliente e restituire comunque la coda.

## 3. Chi è il prossimo?

- `heap-peek` restituisce `value key` per l'elemento in testa senza rimuoverlo.
  A te serve solo il nome, quindi usa `drop` sulla chiave.

## 4. Servi tutti

- `heap-pop-all` svuota l'heap in una lista di associazioni di coppie
  `{ key value }`, già in ordine di priorità.
- `values` mantiene solo i valori, cioè i nomi.

[assocs]: https://docs.factorcode.org/content/vocab-assocs.html
