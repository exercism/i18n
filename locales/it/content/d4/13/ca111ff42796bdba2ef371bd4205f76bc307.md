# Appendice alle istruzioni

## Registri

| Registro | Utilizzo   | Tipo   | Scopo                        |
| -------- | ---------- | ------ | ---------------------------- |
| `$a0`    | input      | intero | valore dato                  |
| `$v0`    | output     | intero | differenza dei quadrati      |
| `$t0-9`  | temporaneo | qualsiasi | usato per la memoria temporanea |
