# Test

Per testare la soluzione, apri il terminale ed esegui

```
mason test
```

nella cartella dell'esercizio (quella che contiene il file `Mason.toml` e le cartelle `src/` e `test/`).

Se il messaggio di errore non ti sembra abbastanza informativo, puoi provare quanto segue per ottenerne uno più dettagliato.

```
mason test --show
```
