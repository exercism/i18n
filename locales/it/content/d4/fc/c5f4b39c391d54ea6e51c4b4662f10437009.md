# Suggerimenti

## 1. Inserisci una carta in cima alla pila

- Per aggiungere un elemento in fondo a un array puoi usare la [funzione `ArrayTrait::append`][append].

## 2. Rimuovi la carta in cima alla pila

- Puoi sempre convertire un array in uno span, quindi usare la [funzione `SpanTrait::pop_back`][pop-back] per rimuovere l'ultimo elemento di un array.

## 3. Inserisci una carta in fondo alla pila

- Non c'è modo di aggiungere un elemento all'inizio dell'array, ma una soluzione è creare un nuovo array con un solo elemento e aggiungere quello vecchio come span con [`ArrayTrait::append_span`][append-span].

## 4. Rimuovi una carta dal fondo della pila

- Per rimuovere il primo elemento di un array puoi usare la [funzione `ArrayTrait::pop_front`][pop-front].

## 5. Controlla la dimensione della pila

- Per ottenere la lunghezza di un array puoi usare la [funzione `ArrayTrait::len`][len].
