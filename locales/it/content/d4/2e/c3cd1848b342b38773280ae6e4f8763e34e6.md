# Istruzioni

Benvenuto nel mondo di *ChronoRealms*, una terra magica in cui potenti Timekeepers controllano il flusso del tempo.

In questo reame, i Timekeepers gestiscono i «TimeShards», unità speciali che si possono sommare, sottrarre, confrontare e anche verificare se sono uguali.

Il tuo compito è aiutare i Timekeepers implementando operatori personalizzati per manipolare questi TimeShards.

I Timekeepers hanno bisogno che tu crei una struct personalizzata `TimeShard` che supporti le seguenti operazioni:

1. **Sommare e sottrarre TimeShards**: i Timekeepers devono poter sommare e sottrarre i TimeShards per controllare la linea temporale.
2. **Confrontare i TimeShards**: a volte i TimeShards vanno confrontati per vedere quale è più grande, o se sono uguali.
3. **Verificare l'uguaglianza**: i Timekeepers devono verificare se due TimeShards sono identici nel valore.

La tua missione è implementare i seguenti trait per la struct `TimeShard`:

1. **Addizione (`Add`)**: consente di sommare due istanze di `TimeShard`.
2. **Sottrazione (`Sub`)**: consente di sottrarre un `TimeShard` da un altro.
3. **Uguaglianza (`PartialEq`)**: consente ai Timekeepers di verificare se due istanze di `TimeShard` sono uguali.
4. **Confronto (`PartialOrd`)**: consente di confrontare due istanze di `TimeShard` per vedere quale è maggiore o minore.

Un `TimeShard` sarà rappresentato da una struct che contiene un valore intero (`i32`).

Implementa i trait necessari per rendere più facile il lavoro dei Timekeepers.

```rust
let shard1 = TimeShard { value: 5 };
let shard2 = TimeShard { value: 3 };

// Adding TimeShards
let sum = shard1 + shard2; // TimeShard { value: 8 }

// Subtracting TimeShards
let difference = shard1 - shard2; // TimeShard { value: 2 }

// Checking equality
let are_equal = shard1 == shard2; // false

// Comparing TimeShards
let is_greater = shard1 > shard2; // true
```
