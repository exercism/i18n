# Istruzioni

Stai costruendo una piccola calcolatrice a Notazione Polacca Inversa (RPN).
Lo stato della calcolatrice è uno *stack di valori*, rappresentato come un
array di Factor, e un'*operazione* è una quotation che prende uno stack
di questo tipo e ne restituisce uno nuovo.

```factor
{ 3 4 }   ! the calculator's stack: 3 is below 4
[ ... ]   ! an operation that consumes some values and pushes a result
```

## 1. Implementare l'addizione

Definisci `add-op` in modo che estragga i due valori in cima allo stack,
inserisca la loro somma e restituisca il nuovo stack.

```factor
{ 3 4 } add-op .
! => { 7 }

{ 1 2 3 4 } add-op .
! => { 1 2 7 }
```

## 2. Implementare la moltiplicazione

Definisci `multiply-op` allo stesso modo, ma per la moltiplicazione.

```factor
{ 3 4 } multiply-op .
! => { 12 }
```

## 3. Applicare una singola operazione

Definisci `apply-op` in modo che prelevi dallo stack dati uno stack e
un'operazione (una quotation) e restituisca il nuovo stack della
calcolatrice.

```factor
{ 3 4 } [ add-op ] apply-op .
! => { 7 }
```

## 4. Valutare un programma

Definisci `evaluate` in modo che prenda uno stack iniziale e un array di
operazioni, applichi ogni operazione a turno e restituisca lo stack
finale.

```factor
{ 3 4 5 } { [ add-op ] [ multiply-op ] } evaluate .
! => { 27 }
```

## 5. Valutare per nome

Ora il programma è un array di *nomi di operatore* (stringhe) e la
calcolatrice cerca ogni nome in un assoc che mappa i nomi alle
operazioni.

Definisci `evaluate-named` in modo che prenda uno stack iniziale, un
assoc di operazioni con nome e un array di nomi, e restituisca lo stack
finale.

```factor
{ 3 4 5 } H{ { "+" [ add-op ] } { "*" [ multiply-op ] } } { "+" "*" }
evaluate-named .
! => { 27 }
```

## 6. Dividere in sicurezza

Una calcolatrice vera non deve produrre risultati senza senso in
silenzio quando le si chiede di dividere per zero. La classe di errore
`zero-divisor-error` è già definita. Implementa `divide-op` in modo
analogo a `add-op` e `multiply-op`, tranne per il fatto che fa `throw`
di un nuovo `zero-divisor-error` quando il divisore in cima allo stack
è `0`.

```factor
{ 12 4 } divide-op .
! => { 3 }

{ 1 5 6 2 } divide-op .
! => { 1 5 3 }

{ 5 0 } divide-op
! throws zero-divisor-error
```
