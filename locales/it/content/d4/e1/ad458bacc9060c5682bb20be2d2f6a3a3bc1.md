# Introduzione

In Cairo, il sovraccarico degli operatori ti permette di definire un comportamento personalizzato per gli operatori standard come `+`, `-`, `==`, `<`, ecc., quando lavori con tipi personalizzati.

Lo si fa implementando trait specifici per i tipi personalizzati.

## I trait principali per gli operatori

### `Add` e `Sub`

I trait `Add` e `Sub` ti permettono di definire come funzionano l'addizione (`+`) e la sottrazione (`-`) con un tipo personalizzato:

```rust
impl MyTypeAdd of Add<MyType> {
    fn add(lhs: MyType, rhs: MyType) -> MyType {
        // Define addition behavior
    }
}
```

### `PartialEq`

Il trait `PartialEq` abilita il confronto di uguaglianza (`==` e `!=`) tra istanze di un tipo personalizzato.

Spesso lo si può derivare automaticamente con `#[derive(PartialEq)]`.

### `PartialOrd`

Il trait `PartialOrd` permette le operazioni di confronto (`<`, `>`, `<=`, `>=`) tra istanze di un tipo personalizzato.

Richiede di implementare almeno il metodo `lt` (minore di):

```rust
impl MyTypePartialOrd of PartialOrd<MyType> {
    fn lt(lhs: MyType, rhs: MyType) -> bool {
        // Define "less than" behavior
    }
}
```
