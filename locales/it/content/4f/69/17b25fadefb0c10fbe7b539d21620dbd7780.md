# Istruzioni

Il tuo amico ti ha appena inviato un messaggio con un segreto importante.
Per non rendere facile agli altri leggerlo, il messaggio è stato cifrato eseguendo una serie di manipolazioni sui bit.
Dovrai scrivere le funzioni che aiutano a decifrare il messaggio.

## 1. Riporta indietro i bit

Il primo passo per decifrare il messaggio è annullare lo scorrimento fatto durante la cifratura, spostando i bit di nuovo verso destra.
Ci saranno altri passaggi del processo di decifratura che presuppongono l'inserimento di 0 dal lato sinistro.

Implementa la funzione `shift_back()`, che prende un valore e il numero di posizioni di cui scorrere ed esegue lo scorrimento.

```julia
shift_back(0b1001, 2) # => 0b0010
```

## 2. Imposta alcuni bit

Ora ci sono alcuni bit che devono essere impostati a 1.

Implementa la funzione `set_bits()`, che prende un valore e una maschera e restituisce il risultato dell'impostazione a 1 dei bit nel valore.
Un bit di `value` deve essere impostato a 1 dove anche il bit della `mask` è 1.
Tutti gli altri bit vanno lasciati invariati.

```julia
set_bits(0b0110, 0b0101) # => 0b0111
```

## 3. Inverti bit specifici

Alcuni bit vengono invertiti durante la cifratura.
Bisognerà invertirli di nuovo per decifrare il messaggio.

Implementa la funzione `flip_bits()`, che prende un valore e la maschera.
La maschera indica quali bit del valore invertire.
Se il bit è 1 nella `mask`, il bit viene invertito nel `value`.
Tutti gli altri bit vanno lasciati invariati.

```julia
flip_bits(0b1100, 0b0101) # => 0b1001
```

## 4. Azzera bit specifici

Infine, ci sono anche alcuni bit che una volta decifrati valgono sempre 0.

Implementa la funzione `clear_bits()`, che prende un valore e una maschera.
I bit nel `value` devono essere impostati a 0 dove il bit della maschera è 1.
Tutti gli altri bit vanno lasciati invariati.

```julia
clear_bits(0b0110, 0b0101) # => 0b0010
```
