# Debug

Per aiutare con il debug, ci sono diverse macro definite in un [file debug.mac][debug]. Possono essere chiamate con uno o più argomenti del tipo e della dimensione appropriati. Per esempio:

```x86asm
debugf32 xmm0, xmm1 ; prints the value of two 32-bit floating-point numbers
debugd16 ax, cx, dx ; prints the value of three signed 16-bit integers
debugx64 [rax]      ; prints the value of a 64-bit integer in hexadecimal format
debugs rel mem, rsi ; prints two NUL-terminated strings
debugu8_xmm xmm1    ; prints 16 packed 8-bit unsigned integers
debug_flag e        ; prints true if je would jump, and false otherwise
```

Per usare una qualsiasi di queste macro, `debug.mac` deve essere incluso all'inizio del file della soluzione:

```x86asm
%include "debug.mac"
```

Nota che `rsp` viene modificato temporaneamente da tutte le macro. Per fare il debug di un valore sullo stack, carica prima il valore, o il suo indirizzo, in un altro registro.

[debug]: https://github.com/exercism/x86-64-assembly/tree/main/templates/debug.mac
