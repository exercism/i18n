Mentre in Haxe è possibile concatenare manualmente le stringhe, Haxe supporta l'[interpolazione di stringhe][string-interpolation], che fornisce una sintassi più breve e più comoda:

```haxe
var x = 42;
//The following two statements are equivalent:

// manual concatenation
trace("the number is " + x);

// using interpolation
trace('the number is $x');
```

Come mostrato sopra, le stringhe interpolate sono racchiuse tra caratteri di virgolette singole (`'`), a differenza delle normali [stringhe][strings], e possono contenere identificatori speciali indicati dal simbolo del dollaro (`$`) che attivano l'interpolazione.

È possibile includere intere espressioni usando `${expr}`, dove `expr` è qualsiasi espressione Haxe valida:

```haxe
trace('the next number is ${x + 1}');
```

Per sopprimere l'interpolazione nel caso in cui si desideri un vero simbolo del dollaro, si può usare `$$`:

```haxe
trace('the price is $$42'); // outputs: the price is $42
```

Infine, nota che l'interpolazione di stringhe è una funzionalità del tempo di compilazione che non ha alcun impatto sulle prestazioni di runtime. Internamente, il compilatore Haxe genera il codice equivalente alla concatenazione manuale.

[string-interpolation]: https://haxe.org/manual/lf-string-interpolation.html
[strings]: https://haxe.org/manual/std-String.html
