# Istruzioni

In questo esercizio giocherai con un'auto radiocomandata, che finalmente hai risparmiato abbastanza soldi per comprare.

Le auto partono con la batteria completamente carica (100%).
Ogni volta che guidi l'auto con il radiocomando, percorre 20 metri e consuma l'uno percento della batteria.
Il soprannome dell'auto non è noto finché non viene creata.

L'auto radiocomandata ha un elegante display a LED che mostra due informazioni:

- La distanza totale percorsa, visualizzata come: `"<METERS> meters"`.
- La carica residua della batteria, visualizzata come: `"Battery at <PERCENTAGE>%"`.

Se la batteria è allo 0%, non puoi più guidare l'auto e il display della batteria mostrerà `"Battery empty"`.

## 1. Crea un'auto radiocomandata nuova di zecca

Implementa la funzione `new_remote_control_car/0` in modo che restituisca un oggetto auto radiocomandata nuovo di zecca:

```jq
new_remote_control_car
# => {
#      "battery_percentage": 100,
#      "distance_driven_in_meters": 0,
#      "nickname": null
#    }
```

## 2. Crea un'auto radiocomandata nuova di zecca con un soprannome

Implementa la funzione `new_remote_control_car/1` in modo che restituisca un oggetto auto radiocomandata nuovo di zecca con un soprannome fornito:

```jq
new_remote_control_car("Blue")
# => {
#      "battery_percentage": 100,
#      "distance_driven_in_meters": 0,
#      "nickname": "Blue"
#    }
```

## 3. Visualizza la distanza

Implementa la funzione `display_distance/0` che prende in input un oggetto auto e restituisce la stringa della distanza così come viene visualizzata sul display a LED:

```jq
new_remote_control_car | display_distance
# => "0 meters"
```

## 4. Visualizza la percentuale della batteria

Implementa la funzione `display_battery/0` che prende in input un oggetto auto e restituisce la stringa della percentuale della batteria così come viene visualizzata sul display a LED:

```jq
new_remote_control_car | display_battery
# => "Battery at 100%"
```

Se la batteria è allo 0%, il display della batteria mostrerà "Battery empty".

## 5. Guidare modifica la batteria e la distanza percorsa

Implementa la funzione `drive/0` che:

- prende in input un oggetto auto
- aumenta di 20 il numero di metri percorsi
- consuma l'1% della batteria
- restituisce l'oggetto auto modificato

```jq
new_remote_control_car("Red") | drive
# => {
#      "battery_percentage": 99,
#      "distance_driven_in_meters": 20,
#      "nickname": "Red"
#    }
```

## 6. Gestisci la guida con la batteria scarica

Aggiorna la funzione `drive/0` in modo che non aumenti la distanza percorsa né diminuisca la percentuale della batteria quando la batteria è scarica (allo 0%):

```jq
{
  battery_percentage: 0,
  distance_driven_in_meters: 2000,
  nickname: "Red"
} | drive
# => {
#      "battery_percentage": 0,
#      "distance_driven_in_meters": 2000,
#      "nickname": "Red"
#    }
```
