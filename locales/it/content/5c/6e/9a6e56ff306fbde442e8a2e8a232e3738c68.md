# Introduzione

Il fatto che un array sia anche una _collezione_ significa che, oltre ad accedere ai valori tramite l'indice, puoi iterare su _tutti_ i suoi valori usando un ciclo `foreach`:

```csharp
char[] vowels = new [] { 'a', 'e', 'i', 'o', 'u' };

foreach (char vowel in vowels)
{
    // Output the vowel
    System.Console.Write(vowel);
}

// => aeiou
```
