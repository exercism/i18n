# Istruzioni

In questo esercizio costruirai la gestione degli errori per una semplice calcolatrice di numeri interi.
Per semplificare le cose, i metodi per calcolare addizione, moltiplicazione e divisione sono già forniti.

L'obiettivo è avere una calcolatrice funzionante che restituisce una stringa con il seguente formato: `16 + 51 = 67`, quando riceve come argomenti `16`, `51` e `+`.

```java
CalculatorConundrum calculator = new CalculatorConundrum();

calculator.calculate(16, 51, "+");
// => returns "16 + 51 = 67"

calculator.calculate(32, 6, "*");
// => returns "32 * 6 = 192"

calculator.calculate(512, 4, "/");
// => returns "512 / 4 = 128"
```

## 1. Implementa il metodo calculate per supportare alcune operazioni di base

Il metodo principale da implementare in questa attività sarà il metodo `CalculatorConundrum.calculate()`.
Richiede tre argomenti.
I primi due argomenti, `operand1` e `operand2`, sono numeri interi su cui verrà eseguita un'operazione.
Il terzo argomento, `operation`, è di tipo String e per questo esercizio è necessario implementare le seguenti operazioni:

- addizione usando la stringa `+`
- moltiplicazione usando la stringa `*`
- divisione usando la stringa `/`

## 2. Gestisci le operazioni non valide

Aggiorna il metodo `CalculatorConundrum.calculate()` per gestire le operazioni non valide:

- Quando l'argomento `operation` è `null`, va lanciata un'`IllegalArgumentException` con il messaggio `Operation cannot be null`.
- Quando l'argomento `operation` è `""`, va lanciata un'`IllegalArgumentException` con il messaggio `Operation cannot be empty`.
- Quando l'argomento `operation` è un'operazione diversa da `+`, `*` o `/`, va lanciata un'`IllegalOperationException` con il messaggio `Operation '{operation}' does not exist`.

```java
calculator.calculate(10, 1, null);
// => throws IllegalArgumentException with message "Operation cannot be null"

calculator.calculate(10, 1, "");
// => throws IllegalArgumentException with message "Operation cannot be empty"

calculator.calculate(10, 1, "-");
// => throws IllegalOperationException with message "Operation '-' does not exist"
```

## 3. Gestisci l'eccezione lanciata quando si divide per zero

In Java, tentare di dividere per zero lancia un'`ArithmeticException`.
Aggiorna il metodo `CalculatorConundrum.calculate()` per intercettare questa eccezione e lanciare poi un'`IllegalOperationException` con il messaggio `Division by zero is not allowed` e l'`ArithmeticException` intercettata come causa.

```java
calculator.calculate(512, 0, "/");
// => throws IllegalOperationException with message "Division by zero is not allowed"
```
