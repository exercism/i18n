# Introduzione

## Result

Il tipo `Result` è la soluzione che il linguaggio Elm offre per segnalare gli errori e consente di riprendersi da essi. È in qualche modo simile al tipo `Maybe`, ma mentre `Maybe` può essere restituito da funzioni che potrebbero fallire, non dice nulla sul perché il fallimento sia avvenuto. `Result` include proprio questo contesto, cioè il motivo per cui qualcosa è fallito.

Il tipo `Result` è definito come segue:

```elm
type Result error value
  = Ok value
  | Err error
```

Questa è quella che nella terminologia di Elm si chiama definizione di «custom type».
L'`error` e il `value` in `OK value` e `Error error` rappresentano una variabile di tipo, cioè possono essere un tipo qualsiasi, come `Int`, `Bool` o `String`.
Di conseguenza, un `Result String Int` è una variabile che dovrebbe contenere un `Int` e, se c'è un errore, questo sarà rappresentato da una `String`.
Esiste un [modulo Result](https://package.elm-lang.org/packages/elm/core/latest/Result) con molte utili funzioni ausiliarie per il tipo Result.
