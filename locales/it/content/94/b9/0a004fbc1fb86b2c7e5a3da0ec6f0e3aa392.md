# Introduzione

I booleani in Cairo sono rappresentati dal tipo booleano predefinito `bool`, i cui valori possono essere `true` o `false`.

```rust
let speeding = true;   // Boolean variable 'speeding' set to 'true'
let has_error = false; // Boolean variable 'has_error' set to 'false' 
```

Cairo supporta tre operatori logici che possono ridurre le espressioni a valori booleani, restituendo `true` o `false`.

| Operatore    | Cosa significa                                 |
| ----------- | --------------------------------------------- |
| `&&` (and)  | È vero se entrambe le affermazioni sono vere.       |
| `\|\|` (or) | È vero se almeno una delle affermazioni è vera. |
| `!` (not)   | È vero solo se l'affermazione è falsa.    |
