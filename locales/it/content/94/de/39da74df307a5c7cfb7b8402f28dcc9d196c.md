# Istruzioni

In questo esercizio, implementerai la logica di missione per un nuovo gioco di ruolo che un amico sta sviluppando.

La protagonista del gioco è Annalyn, una ragazza coraggiosa con un cane fedele e feroce. Purtroppo, arriva la catastrofe: il suo migliore amico è stato rapito mentre cercava bacche nel bosco.

Annalyn proverà a trovare e liberare il suo migliore amico, con la possibilità di portare con sé il cane in questa missione.

Dopo aver seguito per un po' le tracce del suo migliore amico, trova l'accampamento in cui è tenuto prigioniero. Scopre che i rapitori sono due: un cavaliere possente e un arciere astuto.

Dopo aver trovato i rapitori, Annalyn valuta quali delle seguenti azioni può intraprendere:

- _Attacco rapido_: si può sferrare un attacco rapido se il cavaliere dorme, perché ci vuole tempo per indossare l'armatura e quindi sarà vulnerabile.
- _Spionaggio_: si può spiare il gruppo se almeno uno dei suoi membri è sveglio. Altrimenti, spiare è una perdita di tempo.
- _Segnalare al prigioniero_: si può mandare un segnale al prigioniero usando versi di uccelli se il prigioniero è sveglio e l'arciere dorme, perché gli arcieri sono addestrati ai segnali con i versi degli uccelli e potrebbero intercettare il messaggio.
- _Liberare il prigioniero_: Annalyn può provare a intrufolarsi nell'accampamento per liberare il prigioniero.
  È un'azione rischiosa e può riuscire solo in uno dei due modi seguenti:
  - Se Annalyn ha con sé il cane, può salvare il prigioniero se l'arciere dorme.
    Il cavaliere ha paura del cane e l'arciere non avrà il tempo di prepararsi prima che Annalyn e il prigioniero riescano a fuggire.
  - Se Annalyn non ha il cane, lei e il prigioniero devono essere molto furtivi!
    Annalyn può liberare il prigioniero se il prigioniero è sveglio e sia il cavaliere sia l'arciere dormono, ma se il prigioniero dorme non può essere salvato: il prigioniero si spaventerebbe per l'apparizione improvvisa di Annalyn e sveglierebbe il cavaliere e l'arciere.

Hai quattro compiti: implementare la logica per determinare se le azioni precedenti sono disponibili in base allo stato dei tre personaggi trovati nel bosco e alla presenza o meno del cane di Annalyn.

## 1. Verifica se si può sferrare un attacco rapido

Implementa il metodo `canFastAttack()`, che accetta un valore booleano che indica se il cavaliere è sveglio. Il metodo restituisce `true` se si può sferrare un attacco rapido in base allo stato del cavaliere. Altrimenti, restituisce `false`:

```haxe
var knightIsAwake = true;
canFastAttack(knightIsAwake);
// => false
```

## 2. Verifica se si può spiare il gruppo

Implementa il metodo `canSpy()`, che accetta tre valori booleani, che indicano rispettivamente se il cavaliere, l'arciere e il prigioniero sono svegli. Il metodo restituisce `true` se si può spiare il gruppo, in base allo stato dei tre personaggi. Altrimenti, restituisce `false`:

```haxe
var knightIsAwake = false;
var archerIsAwake = true;
var prisonerIsAwake = false;
canSpy(knightIsAwake, archerIsAwake, prisonerIsAwake);
// => true
```

## 3. Verifica se si può mandare un segnale al prigioniero

Implementa il metodo `canSignalPrisoner()`, che accetta due valori booleani, che indicano rispettivamente se l'arciere e il prigioniero sono svegli. Il metodo restituisce `true` se si può mandare un segnale al prigioniero, in base allo stato dei due personaggi. Altrimenti, restituisce `false`:

```haxe
var archerIsAwake = false;
var prisonerIsAwake = true;
canSignalPrisoner(archerIsAwake, prisonerIsAwake);
// => true
```

## 4. Verifica se si può liberare il prigioniero

Implementa il metodo `canFreePrisoner()`, che accetta quattro valori booleani. I primi tre parametri indicano rispettivamente se il cavaliere, l'arciere e il prigioniero sono svegli. L'ultimo parametro indica se il cane di Annalyn è presente. Il metodo restituisce `true` se si può liberare il prigioniero, in base allo stato dei tre personaggi e alla presenza del cane di Annalyn. Altrimenti, restituisce `false`:

```haxe
var knightIsAwake = false;
var archerIsAwake = true;
var prisonerIsAwake = false;
var petDogIsPresent = false;
canFreePrisoner(knightIsAwake, archerIsAwake, prisonerIsAwake, petDogIsPresent);
// => false
```
