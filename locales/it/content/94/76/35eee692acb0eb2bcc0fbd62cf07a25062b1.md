# Istruzioni

Sei un elfo che lavora nella divisione logistica di Babbo Natale e il capo ti ha affidato un paio di compiti per aggiornare il software del sistema.

## 1. Ottenere il nome del giocattolo

Il sistema deve essere in grado di ottenere il nome di un giocattolo dal database.
Il database è fatto di tuple di tipo `(name: String, quantity: Int)`.

Implementa la funzione `getName(_:)`, che prende un argomento contenente una tupla di tipo `(name: String, quantity: Int)`.

```swift
let toy = (name: "Doll", quantity: 10)
getName(toy)
// Returns "Doll"
```

## 2. Aggiungere un nuovo giocattolo al database

Il mercato dei giocattoli è un mercato rapido e in continuo cambiamento: ciò che è popolare cambia molto velocemente.
Per questo serve una funzione che crei un nuovo giocattolo.

Implementa la funzione `createToy(name:amount:)`, che prende un argomento `name` che contiene il nome del giocattolo e `amount` che contiene la quantità del giocattolo.

```swift
createToy(name: "Doll", amount: 10)
// Returns (name: "Doll", amount: 10)
```

## 3. Aggiornare la quantità di un giocattolo

Gli elfi nella bottega di Babbo Natale producono continuamente nuovi giocattoli e Babbo Natale deve tenere traccia della quantità di ogni giocattolo.
Per farlo, il sistema deve essere in grado di aggiornare la quantità di un giocattolo nel database.

Implementa la funzione `updateQuantity(_:toy:Amount:)`, che prende gli argomenti:
- `toys` che contiene un array di tuple di tipo `(name: String, quantity: Int)`.
- `toy` che contiene il nome del giocattolo da aggiornare.
- `amount` che contiene la nuova quantità del giocattolo.

Puoi presumere che il giocattolo sia già nel database e non devi verificarlo.

```swift
let toys = [(name: "Doll", quantity: 10), (name: "Car", quantity: 5), (name: "Train", quantity: 3)]
updateQuantity(toys, toy: "Doll", amount: 15)
// Returns [(name: "Doll", quantity: 15), (name: "Car", quantity: 5), (name: "Train", quantity: 3)]
```

## 4. Aggiungere una chiave di categoria a un giocattolo

Babbo Natale vuole poter categorizzare i giocattoli nel database.
In questo modo può trovarli facilmente quando deve fare una consegna e può ordinare i giocattoli nel database.

Tuttavia, quando il sistema è stato implementato per la prima volta, la chiave di categoria è stata dimenticata.
Ora il sistema deve essere in grado di aggiungere una chiave di categoria a un giocattolo nel database.

Implementa la funzione `addCategory(_:category:)`, che prende gli argomenti:
- `toys` che contiene un array di tuple di tipo `(name: String, quantity: Int)`.
- `category` che contiene la chiave di categoria da aggiungere ai giocattoli.

Puoi presumere che il giocattolo sia già nel database e non devi verificarlo.
Puoi anche presumere che nel giocattolo non ci sia già una chiave di categoria.

```swift
let toys = [(name: "Car", quantity: 5), (name: "Train", quantity: 3)]
addCategory(toys, category: "Vehicle")
// Returns [(name: "Car", quantity: 5, category: "Vehicle"), (name: "Train", quantity: 3, category: "Vehicle")]
```
