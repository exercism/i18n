# Segnaposto

## Ordinare le stringhe in Wren

Wren è ancora un linguaggio molto giovane: ci sono funzionalità, forse comuni in altri linguaggi, che non sono ancora state implementate. Una di queste è la possibilità di ordinare le stringhe.

Il metodo `sort` di List in Wren usa esplicitamente il confronto `<`.
`String` non implementa `<(_)`.

Una delle sfide di questo esercizio è implementare un modo per ordinare un array di stringhe.


## Riferimenti:

- [`sort(), sort(comparer)`][list-sort] nella List
- [l'implementazione di `sort` del modulo List][list-module]
