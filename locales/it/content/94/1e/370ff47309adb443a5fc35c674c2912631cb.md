# Spese elevate del database

## Descrizione del problema

ABC Corp ha bisogno che tu trovi il nome e il dipartimento dei dipendenti con voci di pagamento superiori a un determinato importo (ad esempio, `3000.00`).

Crea un record chiamato `HighPayment` per restituire i dati richiesti. La definizione del record è la seguente.

```ballerina
type HighPayment record {
    string name;
    string department;
    decimal amount;
    string reason;
};
```

Usa l'operazione `query` del client JDBC per ottenere i dati richiesti dal database.

> NOTA: ordina il risultato per `payment_id` in ordine crescente.

## Dettagli del database

Per questo problema, usa il database H2 fornito.

> Il file del database di esempio è `gofigure.mv.db` e il nome del database è `gofigure`. Si trova nella cartella `db`.

Nel database H2 di esempio sono già presenti le tabelle seguenti, con alcuni dati di esempio. I nomi delle colonne e i tipi di dati sono riportati di seguito.

**Nome tabella** : `Employee`

| **Colonne:**      | tipo |
| -----------       | ----------- |
| `employee_id`     | intero, chiave primaria con auto-incremento       |
| `name`            | stringa        |
| `city`            | stringa        |
| `department`      | stringa        |
| `age`             | intero        |

**Nome tabella**: `Payment`

| **Colonne:**      | tipo |
| -----------       | ----------- |
| `payment_id`      | intero, chiave primaria con auto-incremento       |
| `date`            | data        |
| `amount`          | numero in virgola mobile        |
| `employee_id`     | intero        |
| `reason`          | stringa        |

* Il file del database è `gofigure.mv.db`. Usa l'URL JDBC `jdbc:h2:file:/path/to/db/file`
* Nome utente: `root`
* Password: `root`

## Vincoli

* Usa il file del database H2 fornito nella cartella `db` per convalidare le query e l'esempio Ballerina
* Usa l'approccio dei parametri di dipendenza di Maven per aggiungere il driver del database H2 come dipendenza di piattaforma nel tuo Ballerina.toml

## Ambiente di test

* Puoi eseguire i test con `bal test`, che verranno eseguiti sul database di esempio fornito.
