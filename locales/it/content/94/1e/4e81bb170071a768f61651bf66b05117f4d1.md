# Introduzione

Una `str` in Python è una [sequenza immutabile][text sequence] di [punti di codice Unicode][unicode code points].
Queste possono includere lettere, segni diacritici, caratteri di posizionamento, numeri, simboli di valuta, emoji, punteggiatura, vari tipi di spazi, interruzioni di riga e altro ancora.

Le stringhe implementano tutte le [operazioni comuni sulle sequenze][common sequence operations] e possono essere iterate usando la sintassi `for item in <str>` o `for index, item in enumerate(<str>)`.
Possono essere concatenate usando `<str> + <other str>` o `<str>.join(<iterable>)`, divise con `<str>.split(<separator>)` e offrono diverse opzioni di formattazione e composizione.

Per lavorare ulteriormente con le stringhe, Python offre un ricco insieme di [metodi delle stringhe][str-methods] che possono aiutare con la ricerca, la pulizia, la trasformazione, la traduzione e molte altre operazioni.

Essendo _immutabile_, il valore in memoria di un oggetto `str` non cambia; i metodi che sembrano modificare una stringa restituiscono una nuova copia o istanza di quell'oggetto `str`.
