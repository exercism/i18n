# Istruzioni

Elena è la nuova responsabile qualità di una fabbrica di giornali.
Dato che è appena arrivata in azienda, ha deciso di esaminare alcuni processi della fabbrica per vedere cosa si potrebbe migliorare.

Ha scoperto che i tecnici fanno molti controlli di qualità a mano.

Vede una buona occasione per l'automazione e chiede a te, sviluppatore freelance, di scrivere un software per monitorare alcune delle macchine.

## 1. Monitora il livello di umidità della stanza

La tua prima missione è scrivere un software per monitorare il livello di umidità della sala di produzione.
C'è già un sensore collegato al software dell'azienda che restituisce periodicamente la percentuale di umidità della stanza.

Devi implementare nel software una funzione che generi un errore se la percentuale di umidità è troppo alta.
La funzione deve chiamarsi `check_humidity_level` e prendere la percentuale di umidità come parametro.

Devi interromperti con un errore (il messaggio non è importante) se la percentuale supera il 70%.
Altrimenti, emetti un messaggio che include "humidity test passed" e restituisci `TRUE` per confermare che la misurazione è buona.

```R
check_humidity_level(60)
#> humidity test passed
#> [1] TRUE

check_humidity_level(100)
#> Error in check_humidity_level(100) : pct_humidity <= 70 is not TRUE
```

## 2. Rileva il surriscaldamento

Elena è molto soddisfatta del tuo primo incarico e ti chiede di occuparti del monitoraggio della temperatura delle macchine.
Mentre chiacchieri con un tecnico, Greg, vieni a sapere che se la temperatura di una macchina supera i 500°C, i tecnici iniziano a preoccuparsi per il surriscaldamento.

La macchina è dotata di un sensore che misura la sua temperatura interna.
Devi sapere che il sensore è molto sensibile e spesso si rompe.
In questo caso, i tecnici dovranno sostituirlo.

Il tuo compito è implementare una funzione `report_overheating` che prende la temperatura come parametro e genera un errore se il sensore è rotto o se la macchina inizia a surriscaldarsi.

Sapendo che in seguito dovrai reagire in modo diverso a seconda dell'errore, ti serve un meccanismo per distinguere i due tipi di errore.

- Se il sensore è rotto, la temperatura sarà `NULL`.
  In questo caso, devi interromperti con un messaggio di errore che include "Sensor Broken" come parte della stringa.
- Quando il sensore funziona, se la temperatura supera i 600°C, devi interromperti con un messaggio che include la temperatura.
- Se la temperatura supera i 500°C ma non i 600°C, devi emettere un avviso che include la temperatura e restituire `FALSE`.
- Altrimenti va tutto bene, quindi emetti il messaggio `"temperature check passed: t °C"`, dove `t` è la temperatura, e restituisci `TRUE`.

```R
report_overheating(NULL)
#> Error in report_overheating(NULL) : Sensor Broken

report_overheating(800)
#> Error in report_overheating(800) : Overheating: 800 C

report_overheating(550)
#> [1] FALSE
#> Warning message:
#> In report_overheating(550) : Risk of overheating: 550 C

report_overheating(450)
#> temperature check passed: 450 °C
#> [1] TRUE
```


## 3. Monitora la macchina

Ora che la tua macchina sa rilevare gli errori e hai un errore personalizzato della macchina, aggiungi una funzione wrapper che possa riportare come sta andando tutto.
Oltre a restituire i log delle funzioni precedenti, questo wrapper dovrà anche aggiungere dei log a seconda del tipo o dei tipi di errore che si verificano.

- Controlla l'umidità e la temperatura.
- Se ci sono problemi, lascia semplicemente che `check_humidity_level()` e `report_overheating()` producano i loro log.
- Se va tutto bene, aggiungi un messaggio che include "All OK".

Implementa una funzione `monitor_the_machine()` che prende l'umidità e la temperatura come argomenti.

```R
# Working well
monitor_the_machine(53, 200)
#> humidity test passed
#> temperature check passed: 200 °C
#> All OK!

# High humidity
monitor_the_machine(90, 200)
#> Error in check_humidity_level(pct_humidity) : 
#>   pct_humidity <= 70 is not TRUE

# Faulty sensor
monitor_the_machine(53, NULL)
#> humidity test passed
#> Error in report_overheating(temperature) : Sensor Broken

# Mild overheating
monitor_the_machine(53, 550)
#> humidity test passed
#> Warning message:
#> In report_overheating(temperature) : Risk of overheating: 550 C

# Dangerous overheating: shutdown
monitor_the_machine(53, 650)
#> humidity test passed
#> Error in report_overheating(temperature) : Overheating: 650 C
```
