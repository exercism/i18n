# About

Lua usa due rappresentazioni per i numeri: numeri interi a 64 bit e numeri in virgola mobile a doppia precisione.

~~~exercism/note
Prima della versione 5.3, Lua rappresentava tutti i numeri usando il formato in virgola mobile a doppia precisione.
~~~

I numeri si possono scrivere con una parte decimale facoltativa, più un esponente decimale altrettanto facoltativo.
```lua
1               --> 1
0.2             --> 0.2
0.3e4           --> 3000.0
4.0e-3          --> 0.004
5.0e+20         --> 5e+20
```

Un numero con un punto decimale o un esponente è considerato un numero in virgola mobile, mentre senza viene trattato come un intero, ma entrambi hanno il tipo 'number'.
```lua
type(1)         --> number
type(2.0)       --> number
```

Per distinguere i numeri in virgola mobile dagli interi, si può usare la funzione `type` del modulo `math`.
```lua
math.type(1)    --> integer
math.type(2.0)  --> float
```

## Confronto

Interi e numeri in virgola mobile con lo stesso valore risultano uguali in un confronto:
```lua
1 == 1.0        --> true
-2 == -2.0      --> true
0.3e3 == 300    --> true
```

## Aritmetica

Lua supporta il solito insieme di operatori aritmetici: addizione, sottrazione, moltiplicazione, divisione e negazione. Inoltre supporta la divisione intera, il modulo e l'elevamento a potenza.

### Addizione, sottrazione, moltiplicazione e negazione

Se entrambi gli operandi sono interi, il risultato dell'operazione è un intero. Lo stesso vale per i numeri in virgola mobile.
```lua
1 + 2     --> 3
1.0 + 2.0 --> 3.0
```

Se un operando è un numero in virgola mobile, anche gli interi rimanenti vengono convertiti in numeri in virgola mobile e l'operazione produce un numero in virgola mobile.
```lua
1.0 + 2   --> 3.0
```

### Divisione

La divisione opera sempre su numeri in virgola mobile e dà come risultato un numero in virgola mobile.
```lua
1.0 / 2.0 --> 0.5
2 / 1     --> 2.0
```

Dividere per zero dà come risultato `inf` o `-inf`. Dividere zero per zero dà come risultato `-nan`.
```lua
1 / 0     --> inf
-1 / 0    --> -inf
0 / 0     --> -nan
```

### Divisione intera

Se serve un risultato intero, si può usare la divisione intera. La divisione intera arrotonda sempre il quoziente verso meno infinito, garantendo così un risultato intero per qualsiasi operando.

~~~exercism/note
Prima della versione 5.3, Lua non aveva un operatore aritmetico per la divisione intera.
~~~

```lua
3 // 2    --> 1
6 // 2    --> 3
```

La divisione intera segue le stesse regole degli operatori di addizione, sottrazione, moltiplicazione e negazione: se entrambi gli operandi sono interi, il risultato dell'operazione è un intero, altrimenti il risultato è un numero in virgola mobile.

```lua
3.0 // 2   --> 1.0
6.0 // 2.0 --> 3.0
```

Quando si divide per zero con la divisione intera, Lua genera un errore.
```lua
3 // 0     --> stdin:1: attempt to divide by zero
```

### Modulo

Il modulo si usa per ottenere il resto della divisione tra due operandi.
```lua
8 % 2      --> 0
13 % 9     --> 4
-13 % -9   --> -4
-13 % 9    --> 5
13 % -9    --> -5
0.3 % 0.2  --> 0.1
```

### Elevamento a potenza

Come la divisione, anche l'elevamento a potenza opera su numeri in virgola mobile e dà come risultato numeri in virgola mobile.
```lua
10 ^ 2    --> 100.0
```

## Precedenza

Tutte le operazioni vengono valutate secondo la [precedenza degli operatori](https://www.lua.org/manual/5.4/manual.html#3.4.8). Le parentesi si possono usare per cambiare la precedenza di un'espressione.

```lua
1 + 2 * 3   --> 7
(1 + 2) * 3 --> 9
```

## Arrotondamento

Il modulo `math` fornisce tre funzioni di arrotondamento: `floor` arrotonda «per difetto» (verso meno infinito), `ceil` arrotonda «per eccesso» (verso più infinito) e `modf` arrotonda verso zero.

### `math.floor`

`floor` arrotonda verso meno infinito.
```lua
math.floor(1.3)    --> 1
math.floor(-1.3)   --> -2
```

### `math.ceil`

`ceil` arrotonda verso più infinito.
```lua
math.ceil(1.3)    --> 2
math.ceil(-1.3)   --> -1
```

### `math.modf`

`modf` arrotonda verso zero. La funzione restituisce sia il valore arrotondato sia la parte frazionaria del numero, che è sempre un numero in virgola mobile.
```lua
math.modf(1.3)    --> 1    0.3
math.modf(-1.3)   --> -1   -0.3
```

## Conversione

Per convertire un intero in un numero in virgola mobile, basta aggiungergli `0.0`.
```lua
1 + 0.0         --> 1.0
```

Per convertire un numero in virgola mobile in un intero, si può applicare l'OR bit a bit con zero oppure usare la funzione `tointeger` del modulo `math`.
```lua
1.0 | 0              --> 1
math.tointeger(1.0)  --> 1
```

Se il numero non può essere convertito in un intero, l'operatore OR genera un errore e la funzione `tointeger` restituisce `nil`.
```lua
1.1 | 0              --> stdin:1: number has no integer representation
math.tointeger(1.1)  --> nil
```

## Esadecimale

Come molti altri linguaggi di programmazione, Lua supporta i numeri esadecimali anteponendo `0x`, ma a differenza di molti altri linguaggi supporta anche i numeri esadecimali in virgola mobile. Possono avere una parte frazionaria e un esponente binario, introdotto da 'p' o 'P'.
```lua
0xff            --> 255
0x0.2           --> 0.125
0x3p-1          --> 1.5
0xa.bp2         --> 42.75
```
