# Instructions

In questo esercizio scriverai un TreasureChest generico (e magico!) per custodire un tesoro.

## 1. Definisci il tipo personalizzato generico TreasureChest

Definisci un tipo personalizzato `TreasureChest` con una sola variante.

La variante deve avere un valore `String` associato, che verrà usato per memorizzare la password del forziere.

La variante deve avere anche un valore generico associato, che verrà usato per memorizzare il tesoro.
Questo valore è generico, così il tesoro può essere qualsiasi cosa.

## 2. Definisci il tipo UnlockResult

Definisci un tipo personalizzato `UnlockResult` con due varianti.

La prima variante deve essere `Unlocked` e deve contenere un valore generico, che verrà usato per memorizzare il tesoro.

La seconda variante deve essere `WrongPassword`, che non contiene alcun valore.

## 3. Definisci la funzione get_treasure

Questa funzione deve accettare due parametri

- un tipo personalizzato generico `TreasureChest`
- una `String` (per provare una password)

Questa funzione deve confrontare il tentativo di password fornito con la `String` contenuta nel `TreasureChest`.

La funzione deve restituire un `UnlockResult`.

Se le password corrispondono, restituisci `Unlocked` con il valore generico contenuto nel `TreasureChest` (il tesoro!)

Se le password non corrispondono, restituisci `WrongPassword`.
