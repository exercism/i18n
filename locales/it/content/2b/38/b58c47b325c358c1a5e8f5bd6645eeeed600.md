# Suggerimenti

## Generale

- Rivedi le funzioni disponibili nel [modulo `NaiveDateTime`][naive-date-time], nel [modulo `Date`][date] e nel [modulo `Time`][time].

## 1. Analizza i datetime memorizzati

- C'è una [funzione integrata][naive-date-time-from-iso8601] che analizza una stringa datetime ISO8601 e restituisce uno struct `NaiveDateTime`.

## 2. Determina se un libro è stato preso in prestito prima di mezzogiorno

- Puoi definire un letterale `Time` usando il [sigillo `~T`][time-sigil].
- C'è una [funzione integrata][naive-date-time-to-time] che trasforma uno struct `NaiveDateTime` in uno struct `Time`.
- C'è una [funzione integrata][time-compare] che controlla quale di due struct `Time` è maggiore.

## 3. Calcola la data di restituzione

- Un giorno ha `24 * 60 * 60` secondi.
- C'è una [funzione integrata][naive-date-time-add] che aggiunge un determinato numero di secondi a uno struct `NaiveDateTime`.
- C'è una [funzione integrata][naive-date-time-to-date] che trasforma uno struct `NaiveDateTime` in uno struct `Date`.

## 4. Determina quanto è stata in ritardo la restituzione del libro

- C'è una [funzione integrata][naive-date-time-to-date] che trasforma uno struct `NaiveDateTime` in uno struct `Date`.
- C'è una [funzione integrata][date-diff] che calcola la differenza in giorni tra due struct `Date`.

## 5. Determina se il libro è stato restituito di lunedì

- C'è una [funzione integrata][naive-date-time-to-date] che trasforma uno struct `NaiveDateTime` in uno struct `Date`.
- C'è una [funzione integrata][date-day-of-week] che restituisce il giorno della settimana per uno struct `Date` dato.

## 6. Calcola la penale per il ritardo

- Combina insieme tutte le funzioni che hai definito nei passaggi precedenti.
