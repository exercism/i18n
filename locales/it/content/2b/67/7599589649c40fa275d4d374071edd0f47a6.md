# Istruzioni

Elena, la nuova responsabile qualità di una fabbrica di giornali, ti chiede di
scrivere un piccolo programma per monitorare la sala di produzione.

## 1. Definisci un errore personalizzato

Definisci una classe di tuple di errore `machine-error` usando la parola di
parsing `ERROR:`. Non servono slot.

```factor
machine-error   ! throws a fresh machine-error
```

## 2. Controlla l'umidità

Definisci `check-humidity`. Prende dallo stack una lettura di umidità e, quando
la lettura è strettamente maggiore di `70`, con `throw` lancia la stringa
`"humidity too high"`. Negli altri casi non restituisce nulla.

```factor
50 check-humidity   ! returns nothing
80 check-humidity   ! throws "humidity too high"
```

## 3. Controlla la temperatura

Definisci `check-temperature`. Prende una lettura di temperatura e, quando la
lettura è strettamente maggiore di `500`, con `throw` lancia la stringa
`"temperature too high"`. Negli altri casi non restituisce nulla.

```factor
400 check-temperature   ! returns nothing
600 check-temperature   ! throws "temperature too high"
```

## 4. Monitora la macchina

Definisci `monitor` in modo che prelevi dallo stack un'umidità e una temperatura
ed esegua entrambi i controlli. Se uno dei due controlli lancia un errore,
`monitor` deve invece lanciare un nuovo `machine-error`. Se entrambi passano,
`monitor` non restituisce nulla.

```factor
50 400 monitor   ! returns nothing
80 400 monitor   ! throws a machine-error
50 600 monitor   ! throws a machine-error
```

## 5. Monitora un lotto di letture

Definisci `monitor-batch` in modo che prelevi un array di letture
`{ humidity temperature }` e restituisca quante di esse fallirebbero (cioè
quante farebbero lanciare un errore a `monitor`).

```factor
{ { 50 400 } { 80 400 } { 50 600 } { 60 200 } } monitor-batch .
! => 2
```
