# Istruzioni

Hai lavorato a un progetto che consente agli utenti di caricare file sul server per condividerli con altri utenti. Ti è stato chiesto di scrivere una funzione per verificare che un caricamento corrisponda al suo [tipo di media][mimetype]. Fai qualche ricerca e scopri che i primi byte di un file sono generalmente unici per quel tipo di file, una sorta di firma.

Usa la tabella seguente come riferimento:

| Tipo di file | Estensione comune | Tipo di media                | «firma» binaria                                  |
| ------------ | ----------------- | ---------------------------- | ------------------------------------------------ |
| ELF          | `"exe"`           | `"application/octet-stream"` | `0x7F, 0x45, 0x4C, 0x46`                         |
| BMP          | `"bmp"`           | `"image/bmp"`                | `0x42, 0x4D`                                     |
| PNG          | `"png"`           | `"image/png"`                | `0x89, 0x50, 0x4E, 0x47, 0x0D, 0x0A, 0x1A, 0x0A` |
| JPG          | `"jpg"`           | `"image/jpg"`                | `0xFF, 0xD8, 0xFF`                               |
| GIF          | `"gif"`           | `"image/gif"`                | `0x47, 0x49, 0x46`                               |

## 1. Data un'estensione, restituisci il tipo di media previsto

Implementa la funzione `type_from_extension/1`. Deve accettare un'estensione di file (stringa) e restituire il tipo di media (stringa) oppure nil se l'estensione non corrisponde a quelle previste.

```elixir
FileSniffer.type_from_extension("exe")
# => "application/octet-stream"

FileSniffer.type_from_extension("txt")
# => nil
```

## 2. Dato un file binario, restituisci il tipo di media previsto

Implementa la funzione `type_from_binary/1`. Deve accettare un file (binario) e restituire il tipo di media (stringa) oppure nil se la firma del file non corrisponde a quelle previste.

```elixir
file = File.read!("application.exe")
FileSniffer.type_from_binary(file)
# => "application/octet-stream"

file = File.read!("example.txt")
FileSniffer.type_from_binary(file)
# => nil
```

Non preoccuparti di leggere il file come binario. Dai per scontato che sia già stato fatto e che i test lo forniscano come argomento.

## 3. Data un'estensione e un file binario, verifica che il file corrisponda al tipo previsto

Implementa la funzione `verify/2`. Deve accettare un file (binario) e un'estensione (stringa) e restituire una tupla `:ok` o `:error`.

```elixir
file = File.read!("application.exe")

FileSniffer.verify(file, "exe")
# => {:ok, "application/octet-stream"}

FileSniffer.verify(file, "png")
# => {:error, "Warning, file format and file extension do not match."}
```

[mimetype]: https://en.wikipedia.org/wiki/Media_type
