# Installazione

L'unica cosa che ti serve per eseguire questi esercizi è avere installati [CommandBox CLI](https://commandbox.ortusbooks.com/getting-started-guide) e [Java 8](https://java.com/en/download/). CommandBox CLI è supportato su Mac, Linux e Windows. La guida all'installazione la trovi qui:

[https://commandbox.ortusbooks.com/setup/installation](https://commandbox.ortusbooks.com/setup/installation)

Se usi Homebrew su Mac, un esempio di configurazione di CommandBox CLI è il seguente:

```bash
brew install commandbox
```

Una volta installata la CLI, puoi giocare con la REPL:

```bash
box repl
```

Puoi eseguire direttamente le pagine .cfm:

```bash
box exec myTest.cfm
```

E puoi persino avviare un server web in qualsiasi directory del tuo disco rigido:

```bash
box server start
```

CommandBox ha una shell interattiva che puoi usare, con un completamento automatico con il tasto Tab migliorato, e che è anche più veloce. Per entrarci, basta eseguire il binario `box` senza argomenti.

```bash
box
```
