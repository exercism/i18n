# Istruzioni

In questo esercizio scriverai del codice per stampare i badge con il nome dei dipendenti di una fabbrica. 
Ogni dipendente ha un ID, un nome e il nome di un dipartimento. 
Le etichette dei badge dei dipendenti hanno questo formato: `"[id] - name - DEPARTMENT"`.

## 1. Stampa un badge per un dipendente

Implementa la funzione `print_name_badge`. Deve ricevere un ID, un nome e un dipartimento.
Deve restituire l'etichetta del badge, con il nome del dipartimento in maiuscolo.

```R
print_name_badge(67, "Katherine Williams", "Strategic Communication")
# => "[67] - Katherine Williams - STRATEGIC COMMUNICATION"
```

## 2. Stampa un badge per un nuovo dipendente

A causa di una stranezza del sistema informatico, i nuovi dipendenti a volte non hanno ancora un ID quando iniziano a lavorare in fabbrica. 
Dato che i badge sono obbligatori, riceveranno un badge temporaneo senza il prefisso dell'ID.

Estendi la funzione `print_name_badge`. Quando l'id manca, deve stampare un badge senza l'ID.

```R
print_name_badge(NA, "Robert Johnson", "Procurement")
# => "Robert Johnson - PROCUREMENT"
```

## 3. Stampa un badge per il proprietario

Anche il proprietario della fabbrica deve indossare un badge in ogni momento. 
Tuttavia, un proprietario non ha un dipartimento e non ne avrà mai: è al di sopra di tutti i dipartimenti. 
In questo caso, l'etichetta deve stampare `"OWNER"` al posto del nome del dipartimento.

Estendi la funzione `print_name_badge`. Quando il dipartimento è `NULL`, supponi che il badge appartenga al proprietario dell'azienda.

```R
print_name_badge(204, "Rachel Miller", NULL)
# => "[204] - Rachel Miller - OWNER"
```

Nota che è possibile che il proprietario sia anche un nuovo dipendente.

```R
print_name_badge(NA, "Rachel Miller", NULL)
# => "Rachel Miller - OWNER"
```

## 4. Calcola lo stipendio totale dei dipendenti senza ID

Come metrica approssimativa di quanto bene vengono assegnati gli ID, vuoi vedere lo stipendio complessivo dei dipendenti senza ID. 
Un valore alto significa che molti sono in attesa, o che il problema riguarda anche i dipendenti con più anzianità: entrambe le cose sono negative.

Implementa la funzione `salaries_no_id` che riceve un vettore di ID e un vettore corrispondente di stipendi, e restituisce la somma degli stipendi delle persone che non hanno ancora un ID. 
I due vettori hanno la stessa lunghezza.

```R
ids <- c(204, NA, 210, 352, NA, 263)
salaries <- c(23, 21, 47, 35, 17, 101) * 1000
salaries_no_id(ids, salaries)
# => 38,000
```
