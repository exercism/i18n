# Appendice alle istruzioni

Una possibile soluzione per questo esercizio è implementare una propria funzione di esponenziazione modulare.
Per saperne di più, consulta la [pagina seguente](https://en.wikipedia.org/wiki/Modular_exponentiation).

## Per ottenere punti bonus

Molte implementazioni non funzionano per l'intero dominio degli input.
Sono stati definiti dei test opzionali aggiuntivi che aiutano ad assicurarsi che tutti gli input validi producano risultati validi.

Per eseguire i test bonus, rimuovi il flag `#[ignore]` ed esegui i test con
la feature `big-primes`, in questo modo:

```bash
$ cargo test --features big-primes
```
