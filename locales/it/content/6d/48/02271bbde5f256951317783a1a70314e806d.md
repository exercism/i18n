# Installazione

## Installare .NET

Il track C# è basato sulla piattaforma [.NET](https://dotnet.microsoft.com/learn/dotnet/what-is-dotnet), che funziona su Windows, Linux e macOS.
Per compilare i progetti .NET puoi usare l'interfaccia a riga di comando (CLI) di .NET.
Questa CLI fa parte dell'SDK .NET, che puoi installare seguendo le [istruzioni di installazione](https://dotnet.microsoft.com/download/dotnet/8.0).
Nota: il track C# richiede la versione 9.0 o superiore dell'SDK.

Una volta completata l'installazione, puoi verificare che la CLI sia stata installata correttamente eseguendo questo comando in un terminale:

```bash
dotnet --version
```

Se l'output è una versione maggiore o uguale a `9.0.100`, l'SDK .NET è stato installato correttamente.

## Usare un IDE

Se vuoi un'esperienza di editing più completa, probabilmente ti serve un [IDE (ambiente di sviluppo integrato)](https://en.wikipedia.org/wiki/Integrated_development_environment).
Questi sono gli IDE più diffusi che supportano la compilazione dei progetti .NET:

- [Visual Studio 2022](https://www.visualstudio.com/downloads/)
- [Visual Studio Code](https://code.visualstudio.com/download) con l'[estensione C#](https://marketplace.visualstudio.com/items?itemName=ms-dotnettools.csharp)
- [Visual Studio for Mac](https://www.visualstudio.com/vs/visual-studio-mac/)
- [Project Rider](https://www.jetbrains.com/rider/download/)

Nota: poiché il formato dei progetti .NET è molto diverso da quello delle versioni precedenti, gli IDE più vecchi (come Visual Studio 2015) non sono supportati.
