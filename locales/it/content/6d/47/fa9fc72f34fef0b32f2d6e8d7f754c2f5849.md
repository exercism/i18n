# Installazione

Le soluzioni di questo track sono scritte in assembly RISC-V a 32 bit e vengono eseguite in emulazione, quindi non serve alcun hardware RISC-V.
Ogni esercizio include un Makefile che compila i test e li esegue.
Per usarlo, ti servono tre strumenti:

- [Zig][zig], che fornisce l'assembler RISC-V, il compilatore C e il linker tramite `zig cc`.
- [Make][make], che esegue la compilazione.
- `qemu-riscv32` di [QEMU][qemu], che esegue il programma risultante.

## macOS

Avvia una macchina virtuale Linux con una soluzione di virtualizzazione qualsiasi (ad esempio [Lima][lima]) e segui la sezione dedicata a una distribuzione Linux qui sotto.

## Windows

Usa [Windows Subsystem for Linux][wsl] e segui la sezione dedicata a una distribuzione Linux qui sotto.
In alternativa, configura una macchina virtuale Linux.

## Debian / Ubuntu

Installa Make e gli emulatori in modalità utente di QEMU:

```shell
sudo apt install make qemu-user
```

Poi installa Zig 0.15.2 o versione successiva come descritto in [Download diretto][zig-install].

## Fedora

Installa tutti e tre gli strumenti con:

```shell
sudo dnf install zig make qemu-user
```

## Arch Linux

Installa tutti e tre gli strumenti con:

```shell
sudo pacman -S zig make qemu-user
```

## openSUSE Tumbleweed

Installa tutti e tre gli strumenti con:

```shell
sudo zypper install zig make qemu-linux-user
```

## Verifica dell'installazione

Verifica che tutti e tre gli strumenti vengano trovati:

```shell
zig version
make --version
qemu-riscv32 --version
```

Poi scarica un esercizio con la CLI di Exercism e lancia i suoi test:

```shell
exercism download --track=risc-v --exercise=hello-world
cd ~/exercism/risc-v/hello-world/
make
```
