# Introduzione

## IO

Le funzioni per gestire l'input e l'output sono fornite dal modulo `IO`.

### Output

Per scrivere una stringa sullo standard output, usa `IO.puts`. `IO.puts` aggiunge sempre una nuova riga alla fine della stringa. Se non vuoi questo comportamento, usa invece `IO.write`. Entrambe le funzioni restituiscono l'atomo `:ok` se hanno successo.

```elixir
IO.puts("Hi!")
# > Hi!
# => :ok
```

`IO.puts` è utile per scrivere stringhe, ma non molto altro. Se ti serve uno strumento di debug che ti permetta di scrivere qualsiasi valore sullo standard output, usa invece `IO.inspect`. `IO.inspect` restituisce il valore che gli è stato passato, invariato, quindi può essere inserito in qualsiasi punto del codice. Accetta anche molte opzioni, ad esempio `:label`, che permettono di distinguerlo dalle altre chiamate a `IO.inspect`.

### Input

Per leggere una riga dallo standard input, usa `IO.gets`. `IO.gets` accetta un solo argomento: una stringa che stamperà come richiesta di input. `IO.gets` non aggiunge una nuova riga dopo la richiesta, quindi aggiungila tu se ti serve.

```elixir
IO.gets("What's your name?\n")
# > What's your name?
# < Mary
# => "Mary\n"
```
