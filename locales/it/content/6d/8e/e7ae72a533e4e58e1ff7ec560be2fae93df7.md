# Risorse

* [The Rust Programming Language](https://doc.rust-lang.org/book/) è un'ottima risorsa per iniziare con Rust e per approfondire funzionalità specifiche del linguaggio.
* [Rust by Example](https://doc.rust-lang.org/stable/rust-by-example/) ti mostra esempi delle cose più comuni che scriverai in Rust.
* La [Rust API Documentation](http://doc.rust-lang.org/std/) può essere usata per scoprire nuovi metodi e capire come funzionano.
* [Stack Overflow](http://stackoverflow.com/questions/tagged/rust) può essere usato per cercare il tuo problema e vedere se qualcuno ha già risposto. Puoi anche fare domande e rispondere a quelle degli altri.
* Il [Rust User Forum](http://users.rust-lang.org) è dedicato alle discussioni generali su Rust.
* [/r/rust](http://www.reddit.com/r/rust/) è il subreddit ufficiale di Rust.
* Il server ufficiale di [The Rust Programming Language](https://discord.gg/rust-lang) su [Discord](https://discordapp.com/) può essere usato per domande rapide e discussioni sul linguaggio.
