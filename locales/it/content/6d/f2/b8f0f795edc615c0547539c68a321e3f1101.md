# Apprendimento

Lean è sia un linguaggio di programmazione funzionale di uso generale, sia un assistente di dimostrazione.
Esistono numerose risorse per imparare Lean: alcune si concentrano sugli aspetti di programmazione, altre sul suo uso come dimostratore di teoremi.

Il libro [Functional Programming in Lean][functional-programming] è un'introduzione al paradigma della programmazione funzionale che usa Lean.
È pensato per chi programma e vuole imparare Lean, anche senza alcuna esperienza precedente con i linguaggi di programmazione funzionale.

Per uno sguardo più approfondito alla dimostrazione di teoremi in Lean, il libro [Theorem Proving in Lean 4][theorem-proving] è elencato tra le risorse ufficiali.

[The Lean Language Reference][lean-reference] è la fonte autorevole per informazioni dettagliate sul linguaggio.

La [Lean Community][community-resources] mette a disposizione molte altre risorse per imparare Lean.
