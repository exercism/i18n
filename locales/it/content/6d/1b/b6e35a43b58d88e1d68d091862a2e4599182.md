# non usare le funzioni sulle liste

Per favore, non usare nessun modulo esterno (come List, Enum o Stream)
nell'implementazione. Lo scopo di questo esercizio è che queste funzioni di base
le crei tu. Puoi usare le funzioni di base di Kernel (come `Kernel.+/2` per
sommare numeri), ma non usare le funzioni di Kernel per le liste come
`++`, `--`, `hd`, `tl`, `in`, `for` e `length`.
