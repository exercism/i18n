# Appendice alle istruzioni

## Costruisci il tuo DSL

In questo esercizio sei completamente libero di progettare il DSL per grafi dei tuoi sogni.

Forse ti piacerebbe creare un DSL basato su liste di tag e record, come questo:

```roc
my_graph =
    Graph.new([
        Title("My Graph"),
        Node("a", { color: Green }),
        Node("b", { color: Blue }),
        Edge("a", "b", { style: Dotted }),
    ])
```

O forse preferiresti un DSL basato su catene di chiamate di funzione, come questo:

```roc
my_graph =
    Graph.new
        .with_title("My Graph")
        .add_node("a", Attr.new.with_color(Green))
        ...
```

O magari hai in mente un piano del tutto diverso? Fai pure! I test richiedono solo di creare alcuni grafi specifici: il modo in cui li costruisci dipende completamente da te.

Detto questo, un DSL di solito è migliore se è chiaro, conciso e non troppo sorprendente (ad esempio, la funzione `minus` serve per sottrarre, non per costruire un arco tra due nodi, come in `node("a") - node("b")`).

Per raddoppiare il divertimento, puoi provare, se vuoi, a implementare una funzione `to_dot` che converte il tuo grafo nel formato DOT!
