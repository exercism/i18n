# Istruzioni

È il turno di notte giù alla banchina di Hull. La nave da carico
*Olwen* è ormeggiata di fianco, e una squadra di operai portuali
lavora al manifesto in parallelo. Ogni cassa deve essere pesata
prima di salire a bordo, e il comandante del porto tiene un unico
**conteggio del tonnellaggio** progressivo, che ogni sollevamento
aggiorna. Il problema: c'è una sola gru sulla banchina, quindi il
conteggio non può risultare incoerente se due operai portuali lo
aggiornano nello stesso momento.

Ogni cassa è un array di pesi degli oggetti. Il peso della cassa
è la somma di quegli oggetti.

## 1. Pesare una cassa

Definisci `weigh-crate` in modo che prenda una cassa e restituisca
il suo peso totale. È un semplice lavoro sequenziale: una cassa,
un numero in uscita.

```factor
{ 12 8 15 } weigh-crate .
! => 35
```

## 2. Pesare l'intero manifesto in parallelo

Definisci `weigh-all` in modo che prenda un array di casse e
restituisca l'array dei loro pesi, nello stesso ordine. Usa
`parallel-map` così il lavoro su ogni cassa avviene in modo
concorrente.

```factor
{ { 5 5 } { 10 } { 3 4 5 } } weigh-all .
! => { 10 10 12 }
```

## 3. Costruire una nuova gru

Definisci `<crane>` per costruire una nuova gru: una tupla con un
`<lock>` nuovo e un tonnellaggio di `0`. La gru è la risorsa
condivisa che i compiti successivi proteggeranno.

```factor
<crane> tonnage>> .
! => 0
```

## 4. Sollevare una cassa sul conteggio progressivo

Definisci `hoist-crate` in modo che prenda un `weight` e una
`crane` e aggiunga il peso al tonnellaggio della gru **sotto il
lock della gru**, così la lettura, la somma e la scrittura sono
atomiche rispetto ad altri operai portuali che sollevano nello
stesso momento.

```factor
<crane>
35 over hoist-crate
17 over hoist-crate
tonnage>> .
! => 52
```

## 5. Leggere il tonnellaggio progressivo

Definisci `crane-tonnage` per restituire il tonnellaggio attuale
della gru, anche questo sotto il lock, così la lettura non può
vedere un valore incoerente durante un sollevamento.

```factor
<crane>
35 over hoist-crate
crane-tonnage .
! => 35
```

## 6. Caricare la merce

Definisci `load-cargo` in modo che prenda un array di casse e una
gru e, **per ogni cassa, avvii un thread di un operaio portuale**
che pesa la cassa e solleva il peso sulla gru. La parola
restituisce solo quando tutti gli operai portuali hanno finito.
Usa `<promise>` e `?promise` per coordinare il join.

```factor
<crane> :> crane
{ { 5 5 } { 10 } { 3 4 5 } } crane load-cargo
crane crane-tonnage .
! => 32
```
