# Istruzioni

In questo esercizio lavorerai su alcune funzioni per gestire gli appuntamenti.
Il sistema memorizza tutto in stringhe formattate secondo lo standard ISO 8601, ma non è così che le persone usano il calendario.
Servono diverse funzioni per convertire tra i vari formati.

## 1. Crea un appuntamento

Crea un appuntamento tra `n` giorni da adesso, all'ora corrente.
La funzione prende `n` giorni e restituisce l'orario dell'appuntamento a `n` giorni da adesso.

```javascript
createAppointment(4, now);
// Given now is Sun Oct 05 2022 23:28:43 GMT+0600 (Bangladesh Standard Time)
// => Sun Oct 09 2022 23:28:43 GMT+0600 (Bangladesh Standard Time)
```

Se il secondo parametro `now` non viene usato, al suo posto va usata l'ora corrente.

## 2. Converti una data in un timestamp

Diversi strumenti funzionano solo con il formato ISO 8601, lo standard internazionale.
Scrivi la funzione `getAppointmentTimestamp` in modo che prenda una data e restituisca una stringa in quel formato.

```javascript
const appointment = new Date(Date.UTC(2010, 6, 16, 12, 42, 0, 0));

getAppointmentTimestamp(appointment);
// => '2010-07-16T12:42:00.000Z'
```

## 3. Ottieni i dettagli di un appuntamento

I timestamp sono difficili da leggere. Una funzione per ottenere i dettagli dell'appuntamento dovrebbe aiutare.
La funzione `getAppointmentDetails` prende un timestamp nel formato ISO 8601 e restituisce l'anno, il mese, la data, l'ora e i minuti.

```javascript
getAppointmentDetails('2022-04-24T08:15:00.000');
// => { year: 2022, month: 3, date: 24, hour: 8, minute: 15 }
```

## 4. Aggiorna un appuntamento con le opzioni indicate

La funzione riceverà come primo argomento l'orario dell'appuntamento e come secondo argomento un oggetto con alcune opzioni.
Devi aggiornare l'appuntamento in base alle opzioni presenti nell'oggetto e restituire la nuova data dell'appuntamento.
L'oggetto delle opzioni può contenere più opzioni.

```javascript
updateAppointment('2022-02-09T09:20:00.000', { month: 6 });
// => { year: 2022, month: 6, date: 9, hour: 10, minute: 20 }
```

## 5. Ottieni il tempo disponibile tra due appuntamenti

La funzione riceverà come argomenti due appuntamenti (timestamp).
Devi restituire la differenza tra questi due orari in secondi.

Dato che mezzo secondo non ha quasi significato, arrotonda il numero prima di restituirlo.

```javascript
timeBetween('2022-12-12T09:20:00.000', '2022-12-18T08:30:00.000');
// => 515400
```

## 6. Controlla se un appuntamento è valido oppure no

Infine, quando viene fissato un appuntamento, il sistema deve controllare se è valido.
In altre parole, l'appuntamento deve essere nel futuro, non nel passato.

Scrivi la funzione `isValid` che prende due argomenti, un timestamp dell'appuntamento (una stringa) e l'ora corrente come timestamp (una stringa), e restituisce `true` se l'appuntamento è nel futuro rispetto all'ora corrente.

```javascript
isValid('2022-02-11T23:00:00.000', '2022-02-08T23:00:00.000');
// => true
```
