# Informazioni

Le [guardie][guards] si usano come complemento al [pattern matching][exercism-pattern-matching]. Permettono di eseguire controlli più complessi. Si possono usare in [alcune, ma non tutte le situazioni][where-guards-can-be-used] in cui si può usare il pattern matching, per esempio nelle clausole di funzione o nelle clausole case.

```elixir
def empty?(list) when is_list(list) and length(list) == 0 do
  true
end
```

- Le guardie iniziano con la parola chiave `when`, seguita da un'espressione booleana.
- Le espressioni di guardia sono funzioni speciali che:
  - Devono essere pure e non modificare alcuno stato globale.
  - Devono restituire valori rigorosamente `true` o `false`.
- Un elenco delle guardie più comuni si trova nella [documentazione di Elixir][kernel-guards]. Ne fanno parte:
  - Controlli di tipo: [`is_integer/1`][guard-is-integer], [`is_list/1`][guard-is-list], [`is_nil/1`][guard-is-nil] ecc.
  - Operatori aritmetici: [`+/2`][guard-plus], [`-/2`][guard-minus] ecc.
  - Confronti: [`==/2`][guard-equals], [`>/2`][guard-greater], [`</2`][guard-less] ecc.
  - Operatori booleani: [`and/2`][guard-and], [`or/2`][guard-or], [`not/1`][guard-not]
  - Operatore di appartenenza: [`in/2`][guard-in]
- Puoi definire una guardia personalizzata con [`defguard`][defguard].

  - Secondo la [convenzione di denominazione][naming] di Elixir, i nomi delle guardie dovrebbero iniziare con `is_`.

    ```elixir
    defmodule HTTP do
      defguard is_success(code) when code >= 200 and code < 300

      def handle_response(code) when is_success(code) do
        :ok
      end
    end
    ```
