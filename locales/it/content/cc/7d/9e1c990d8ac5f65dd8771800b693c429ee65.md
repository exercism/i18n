# Appendice alle istruzioni

## Registri

| Registro | Utilizzo     | Tipo      | Descrizione                              |
| -------- | ------------ | --------- | ---------------------------------------- |
| `$a0`    | input        | indirizzo | stringa di input terminata da null       |
| `$a1`    | input/output | indirizzo | array di word con i conteggi finali dei nucleotidi |
| `$t0-9`  | temporaneo   | qualsiasi | per l'archiviazione temporanea           |
