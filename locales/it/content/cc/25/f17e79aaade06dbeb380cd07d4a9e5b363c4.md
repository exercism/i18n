# Istruzioni

Quell'auto radiocomandata che hai comprato di recente è diventata un hobby tutto nuovo. Hai organizzato gare di auto radiocomandate.

Stavi quasi finendo di scrivere un programma che avrebbe permesso di eseguire le simulazioni delle gare, quando il tuo gatto è saltato sulla tastiera e ha cancellato alcune righe di codice. Ora il programma non si compila più...

## 1. Correggi l'errore di compilazione `Race.__struct__/0 is undefined`

Aggiungi un alias in modo che il modulo `NeedForSpeed.Race` possa essere indicato con il nome più breve `Race`.

## 2. Correggi l'errore di compilazione `Car.__struct__/0 is undefined`

Aggiungi un alias in modo che il modulo `NeedForSpeed.RemoteControlCar` possa essere indicato con il nome più breve `Car`.

## 3. Correggi l'errore di compilazione `undefined function puts/1`

La funzione `puts/1` proviene dal modulo `IO`. Importala per poterla usare senza fare riferimento al modulo.

## 4. Correggi l'errore di compilazione `undefined function default_color/0`

Le funzioni `default_color/0`, `red/0`, `cyan/0` e `green/0` provengono tutte dal modulo `IO.ANSI`. Hai in programma di aggiungere il supporto per altri colori di auto, quindi vuoi importare l'intero modulo. Purtroppo, la funzione `color/1` del modulo `IO.ANSI` è in conflitto con una delle funzioni locali. Importa l'intero modulo `IO.ANSI` tranne quella funzione.
