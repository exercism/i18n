# Concetti dei numeri di Armstrong

> Un [numero di Armstrong](https://en.wikipedia.org/wiki/Narcissistic_number) è un numero uguale alla somma delle proprie cifre, ciascuna elevata alla potenza del numero di cifre.

## Soluzione di esempio

```rust
pub fn is_armstrong_number(num: u32) -> bool {
    let digits = format!("{}", num);
    digits
        .chars()
        .map(|c| c.to_digit(10).unwrap().pow(digits.len() as u32))
        .sum::<u32>()
    == num
}
```

## Concetti

- funzioni: indispensabili per verificare la soluzione e definire la logica
- suite di test: necessarie per verificare la soluzione
- interi: u32 per l'argomento e per le affermazioni di identità
- `&str`: necessario per contare la lunghezza del numero, dato che Rust è fortemente tipizzato
- `Option<T>`: necessario per accedere al valore effettivo di `char::to_digit`
- conversione di tipo: necessaria per applicare operazioni aritmetiche
- funzionalità degli iteratori:
  - turbofish per abilitare una soluzione con una singola espressione
  - `map` e `sum` per ridurre comodamente l'espressione a ciò che dobbiamo affermare
