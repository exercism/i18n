# Introduzione

PowerShell è un linguaggio di scripting di Microsoft a tipizzazione dinamica e implicita (supporta anche le variabili a tipizzazione forte), pensato soprattutto per l'automazione delle attività e la gestione della configurazione.

PowerShell supporta la programmazione imperativa, funzionale e orientata agli oggetti, e persino lo stile a pipeline.

PowerShell è stato costruito sulla piattaforma .NET ed è stato rilasciato per la prima volta nel 2006.
È incluso per impostazione predefinita in tutti i sistemi operativi Windows moderni e può essere installato su Mac e Linux.


## Variabili

Ci sono due modi comuni per definire una variabile in PowerShell.

Un nome di variabile in PowerShell deve iniziare con `$` e usare l'operatore di assegnazione `=` per legare il nome della variabile a un valore.

```powershell
> $intVar = 1
> $doubleVar = 2.0
> $stringVar = "Hello"

# Checking a variable type using the GetType() method
> Write-Host $doubleVar.GetType()
System.Double
```

Puoi anche specificare esplicitamente il tipo di una variabile, se vuoi imporre un [tipo][strong typed] specifico.
PowerShell farà del suo meglio per convertire il valore da un tipo a un altro, se possibile.

```powershell
# String represents a floating number can be converted to integer
> [int]$staticOne = "1.234"
> $staticOne
1

# String of letters can not be converted to double type
> [double]$staticTwo = "hello"
MetadataError: Cannot convert value "hello" to type "System.Double"
```


### Costanti

Le costanti in PowerShell sono variabili di sola lettura che non possono essere **rimosse** dopo essere state definite.
Questo ci porta al secondo modo di definire le variabili, usando il cmdlet `New-Variable`.

```powershell
> New-Variable -Name "MyConstant" -Value 100 -Option Constant
> $MyConstant
```

Per un modo più dettagliato e avanzato di creare una nuova variabile con varie opzioni, vedi il cmdlet [New-Variable][New-Variable].


## Funzioni

Le [funzioni][functions] in PowerShell si definiscono usando la parola chiave `function`.
Ogni funzione può avere zero o più [parametri][parameters] formali tra parentesi tonde (`()`), seguiti dal proprio [scope][scope], che inizia con `{` e termina con `}`.

```powershell
function Greeting {
    return "Hello!"
}
```

Le funzioni in PowerShell possono restituire valori esplicitamente tramite la parola chiave `return`, dopo essere state chiamate usando la sintassi `FuncName $Arg`.

```powershell
function AddTwoNumbers($NumOne, $NumTwo):
    $result = $NumOne + $NumTwo
    return $result

> AddTwoNumbers 10 20
30
```

Uno sguardo avanzato su come scrivere una definizione di funzione dettagliata e su come le funzioni possono restituire valori in modo implicito sarà trattato nel modulo del concetto `Functions`.


## Commenti

Il commento singolo in PowerShell inizia con un `#` e termina alla fine della riga.
Il blocco di commento in PowerShell inizia con `<#` e termina con `#>`.
Una dimostrazione avanzata del blocco di commento per creare Comment-Based Help sarà trattata nel modulo del concetto `Functions`.

```powershell
function Main() {
    #This is a comment
}
```
