# Introduzione

Le funzioni per gestire l'input e l'output sono fornite dal modulo `IO`.

## Output

Per scrivere una stringa sullo standard output, usa `IO.puts`. `IO.puts` aggiunge sempre una nuova riga alla fine della stringa. Se non vuoi questo comportamento, usa invece `IO.write`. Entrambe le funzioni restituiscono l'atomo `:ok` se riescono.

```elixir
IO.puts("Hi!")
# > Hi!
# => :ok
```

`IO.puts` è utile per scrivere stringhe, ma non molto altro. Se ti serve uno strumento per il debug che permetta di scrivere qualsiasi valore sullo standard output, usa invece `IO.inspect`. `IO.inspect` restituisce invariato il valore che gli è stato passato, quindi può essere inserito in qualsiasi punto del codice. Accetta anche molte opzioni, ad esempio `:label`, che permettono di distinguerlo dalle altre chiamate a `IO.inspect`.

## Input

Per leggere una riga dallo standard input, usa `IO.gets`. `IO.gets` accetta un solo argomento: una stringa che verrà stampata come richiesta per l'input. `IO.gets` non aggiunge una nuova riga dopo la richiesta. Aggiungila tu se ti serve.

```elixir
IO.gets("What's your name?\n")
# > What's your name?
# < Mary
# => "Mary\n"
```
