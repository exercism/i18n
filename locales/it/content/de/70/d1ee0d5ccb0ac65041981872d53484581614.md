# Suggerimenti

## Generale

- Usa il [tipo array (collegato)][list] integrato.

## 1. Definire una funzione che restituisca un array vuoto di linguaggi

- La funzione deve restituire `[]`.

## 2. Definire una funzione che aggiunga un linguaggio all'array

- Un elemento può essere aggiunto in testa a un array usando `:`.

## 3. Definire una funzione che rimuova un linguaggio dall'array

- Haskell [fornisce una funzione][tail] che restituisce un array con il primo elemento rimosso.

## 4. Definire una funzione che restituisca il primo elemento dell'array

- Haskell [fornisce una funzione][head] per ottenere il primo elemento da un array.

## 5. Definire una funzione che restituisca quanti linguaggi ci sono nell'array

- Haskell [fornisce una funzione][length] per contare la lunghezza di un array.

## 6. Definire una funzione che determini se l'array include un linguaggio funzionale

- La funzione deve restituire un valore booleano che indichi se `"Haskell"` è un elemento dell'array. 
  Haskell [fornisce una funzione][elem] per verificare l'appartenenza a un array.
