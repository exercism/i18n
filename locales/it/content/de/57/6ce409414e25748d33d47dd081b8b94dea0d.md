# Introduzione

I generici ti permettono di scrivere codice che funziona con più tipi senza duplicazioni.
Definisci i tipi generici usando le parentesi angolari (`<T>`), dove `T` è un segnaposto per
qualsiasi tipo.

```rust
fn largest_list<T>(l1: Array<T>, l2: Array<T>) -> Array<T> {
    if l1.len() > l2.len() {
        l1
    } else {
        l2
    }
}
```

Cairo richiede vincoli sui trait per specificare quali operazioni il tipo generico deve
supportare. Puoi aggiungere i vincoli usando la sintassi `+`:

```rust
fn process_data<T, +Drop<T>, +Copy<T>>(value: T) -> T {
    // Function body
}
```

Anche le struct possono essere generiche:

```rust
#[derive(Drop)]
struct Container<T> {
    value: T,
}
```

Anche i trait possono essere generici, il che permette loro di funzionare con tipi diversi:

```rust
trait Processor<T> {
    fn process(self: @T) -> ByteArray;
}

impl MyProcessor<T, +Drop<T>> of Processor<T> {
    fn process(self: @T) -> ByteArray {
        "processed"
    }
}
```

Le funzioni possono accettare parametri generici con vincoli sui trait, così da funzionare
con qualsiasi tipo che implementi il trait richiesto:

```rust
fn use_processor<T, +Processor<T>, +Drop<T>>(item: T) -> ByteArray {
    item.process()
}
```
