# Informazioni

Un `bit` è il valore più elementare dell'informatica.
La parola `bit` sta per «cifra binaria».
È un'unità di memorizzazione dei dati nell'ambiente di esecuzione, grande abbastanza da contenere un oggetto che può assumere uno di due valori.
Di conseguenza, ha un valore binario che può essere `1` oppure `0`.
Tutti gli altri tipi di dati sono composti da più `bits`.
Per esempio, un `byte` di solito è composto da otto `bits`.

## Come scrivere i valori dei bit

I `Bits` costituiscono un sistema di numerazione in base 2.
Ogni multiplo di `2` finisce in quella che consideriamo la posizione delle decine, delle centinaia, delle migliaia e così via, con la differenza che le «decine» sarebbero «due», le «centinaia» sarebbero «quattro», le «migliaia» sarebbero «otto» e così via.
Quindi, il valore decimale `2` corrisponderebbe al valore binario `10`, `4` a `100` e `8` a `1000`.
Come nei numeri decimali, i valori aumentano man mano che si procede da destra verso sinistra.
Possiamo pensare al valore decimale `5` come rappresentato da `101` in binario, con un `1` nella posizione delle «unità» e un `1` nella posizione dei «quattro».
Tuttavia, i letterali binari non fanno parte dello standard del linguaggio C.
Gli unici valori binari supportati dallo standard del linguaggio C sono un singolo `1` o `0`.
I letterali binari _sono_ supportati da alcune estensioni non standard dei compilatori, come il compilatore gnu, anteponendo al letterale `0b`.

```c
#include <stdio.h>

int main() {
    int binary_five = 0b101;
    printf("%d", binary_five);
    return 0;
}
```

È importante ricordare che questa notazione non è supportata da tutti i compilatori e potrebbe ostacolare la portabilità del codice tra compilatori diversi.

Un modo comune per scrivere i valori binari nel codice è usare la notazione esadecimale, che è un sistema di numerazione in base 16.
La notazione esadecimale del linguaggio C antepone al letterale `0x` o `0X`.
Poiché il valore decimale `16` è rappresentato come `1` nella posizione delle decine, il valore decimale `10` è rappresentato come `0xA` in esadecimale, `11` come `0xB`, `12` come `0xC`, `13` come `0xD`, `14` come `0xE` e `15` come `0xF`.
Quindi, per esempio, il valore decimale `42` si scriverebbe come `0x2A`: `2` per `16` (= `32`) più `10` (= `42`).

In binario, possiamo pensare a `42` come `00101010`: `32` più `8` più `2`.
Diremmo che il secondo, il quarto e il sesto bit da destra sono «impostati», cioè che sono `1` invece di `0`.
Il secondo bit è `2`, il quarto bit è `8` e il sesto bit è `32`.
Impostare quei tre bit definisce un valore di `42`.

## Maschere di bit

Una maschera di bit può essere qualsiasi valore usato per impostare singoli bit.
Per esempio, l'alfabeto inglese ha ventisei lettere.
Un valore di almeno ventisei bit, come un intero senza segno a 32 bit, potrebbe essere usato come maschera di bit per impostare una condizione `true` o `false` per ogni lettera dell'alfabeto inglese.
Qualsiasi valore con abbastanza bit per gestire un insieme richiesto di condizioni `true` o `false` può servire come maschera di bit.
L'impostazione e la lettura dei singoli bit avvengono tramite gli operatori bit a bit.

## Operatori bit a bit

Supponiamo di voler tenere traccia di quali lettere compaiono in una `string`.
Per il nostro esempio, useremo solo le ventisei lettere dell'alfabeto inglese.
La nostra maschera di bit sarà un intero senza segno a 32 bit.
Uno `0` rappresenterà il fatto che la lettera non compare.
Un `1` rappresenterà il fatto che la lettera compare una o più volte.
All'inizio, la rappresentazione in bit della nostra maschera sarà di 32 `0s` di fila: `00000000000000000000000000000000`.
La posizione più a destra sarà quella della `A`.
La seconda da sinistra sarà per la `B`, e così via.
Supponiamo di elaborare tutte le lettere della stringa in un ciclo, quindi vogliamo una sola riga di codice che funzioni per impostare qualsiasi lettera.

### Operatore di scorrimento a sinistra bit a bit: un modo per posizionare un bit

`<<` è l'operatore bit a bit per lo scorrimento a sinistra.

Se la nostra lettera è `A` non vogliamo scorrere a sinistra, ma se la nostra lettera è `B` vogliamo scorrere a sinistra di una posizione, e se la nostra lettera è `C` vogliamo scorrere a sinistra di due posizioni, e così via.
Anche se possiamo percepire i `chars` come lettere tipo `A` o `B`, un `char` è implementato in memoria come un tipo intero, quindi possiamo fare semplice aritmetica con un `char`.
Data una variabile chiamata `letter` che rappresenta il `char` che stiamo elaborando, possiamo scorrere a sinistra del numero di posizioni richiesto spostando `1` a sinistra della differenza tra `letter` e il `char` `A`, così: `1 << letter - 'A'`.
`A` - `A` fa `0`, quindi scatterebbe a sinistra di `0` posizioni se `letter` è `A`.
`B` - `A` fa `1`, quindi scatterebbe a sinistra di `1` posizione se `letter` è `B`, e così via.

### Operatore OR inclusivo bit a bit: un modo per impostare un bit

Una volta che sappiamo _dove_ vogliamo impostare un bit, possiamo effettivamente impostarlo usando l'operatore OR inclusivo bit a bit, che è `|`.
Il risultato dell'operatore `|` sarà `1` in ogni posizione in cui l'operando di sinistra o quello di destra ha un bit impostato.
Quindi, il risultato di `0010 | 0001` sarebbe `0011`.
(È importante ricordare che il valore è `11` in binario, ma è `3` in decimale.)
Per assegnare il risultato a un valore, l'operatore `|` può essere combinato con l'operatore di assegnazione per impostare i bit così: `|=`.
Per semplicità, l'esempio seguente non usa un ciclo, ma mostra come potremmo elaborare le lettere `ABA` in una maschera di bit.

```c
#include <stdio.h>
#include <stdint.h>

int main() {
    // it's important to initialize the mask to 0 so we don't get garbage values
    uint32_t mask = 0;
    char letter_A = 'A';
    char letter_B = 'B';
    char letter_A_again = 'A';
    mask |= 1 << letter_A - 'A';
    mask |= 1 << letter_B - 'A';
    mask |= 1 << letter_A_again - 'A';
    // prints 3
    printf("%d", mask);
}
```

Impostiamo la parte più a destra della nostra maschera a `0001` per la `A`, e poi impostiamo la maschera a `0011` per la `B`.
Impostare un'altra `A` non comporta alcun cambiamento nella maschera esistente.
Avremmo potuto evitare di impostare di nuovo il bit controllando se la `A` era già stata impostata.

### Operatore AND bit a bit: un modo per leggere un bit

`&` è l'operatore AND bit a bit.
Il risultato dell'operatore `&` sarà `1` in ogni posizione in cui sia l'operando di sinistra sia quello di destra hanno un bit impostato.
Quindi, il risultato di `0011 & 0001` sarebbe `0001`.
Possiamo vederlo in azione nell'esempio seguente.

```c
#include <stdio.h>
#include <stdint.h>

int main() {
    uint32_t mask = 0;
    char letter_A = 'A';
    char letter_B = 'B';
    char letter_A_again = 'A';
    mask |= 1 << letter_A - 'A';
    mask |= 1 << letter_B - 'A';
    // prints A already set
    if (mask & 1 << letter_A_again - 'A')
        printf("A already set\n");
    else
        mask |= 1 << letter_A_again - 'A';
    printf("%d", mask);
}
```

### Operatore OR esclusivo bit a bit: un modo per invertire un bit

`^` è l'operatore OR esclusivo bit a bit.
Un operatore OR _inclusivo_ implica che esista un operatore OR _esclusivo_ con un comportamento diverso.
Il risultato dell'operatore `^` sarà `1` in ogni posizione in cui _solo uno_ tra l'operando di sinistra e quello di destra ha un bit impostato.
Quindi, il risultato di `0001 ^ 0011` sarebbe `0010`.
Il bit più a destra non sarà impostato perché _entrambi_ gli operandi hanno `1` nella posizione più a destra.
L'operazione OR esclusivo a volte viene indicata come XOR.
Se il risultato di un valore su cui è stato applicato lo XOR viene a sua volta sottoposto a XOR, restituirà il valore originale.
Questo può essere usato per una crittografia molto semplice, in cui la stessa chiave serve sia per cifrare sia per decifrare i dati.
Per esempio

```c
#include <stdio.h>

int main() {
    char a = 'a';
    char b = 'b';
    char c = 'c';
    // we will use "a" for the "key"
    char first = a ^ 'a';
    char second = b ^ 'a';
    char third = c ^ 'a';
    // prints three "dots" for unprintable characters
    printf("%c %c %c\n", first, second, third);
    // prints the ascii values 0 3 2
    printf("%d %d %d\n", first, second, third);
    first = first ^ 'a';
    second = second ^ 'a';
    third = third ^ 'a';
    // prints a b c
    printf("%c %c %c\n", first, second, third);
    // prints the ascii values 97 98 99
    printf("%d %d %d\n", first, second, third);
}
```

### Operatore di scorrimento a destra bit a bit: un modo per dimezzare un valore

`>>` è l'operatore bit a bit per lo scorrimento a destra.
Di solito, per ogni posizione di cui i bit di un valore vengono spostati a destra, il risultato è il valore diviso per due.
Per esempio

```c
#include <stdio.h>

int main() {
    int number = 16;
    number >>= 2;
    // prints 4, or 16 / 2 = 8 / 2 = 4
    printf("%d\n", number);
}
```

Se il valore dell'operando di destra è negativo o è maggiore o uguale alla larghezza dell'operando di sinistra promosso, il comportamento non è definito.
Lo stesso vale per l'operatore di scorrimento a sinistra.
Quando si usa un intero con segno invece di un intero senza segno, anche la presenza del segno può entrare in gioco.
L'esempio seguente mostra il comportamento su un sistema quando si scorre troppo a sinistra o a destra per un intero con segno.

```c
#include <stdio.h>

int main() {
    int number = 16;
    number <<= 250;
    // prints 1073741824
    printf("%d\n", number);
    number <<= 1;
    // prints -2147483648
    printf("%d\n", number);
    number <<= 1;
    // prints 0
    printf("%d\n", number);
    // total shifts are now 256, done incrementally
    number <<= 4;
    // prints 0
    printf("%d\n", number);
    number = 16;
    // prints 16 when 256 total shifts done at once
    printf("%d\n", number << 256);
    // prints 0 when bits shifted right far enough
    printf("%d\n", number >> 5);    
    // still prints 0
    printf("%d\n", number >> 255);
    // prints 16 when shifted right far enough to "wrap around"
    printf("%d\n", number >> 256);
}
```

Poiché il comportamento non è definito, un sistema diverso potrebbe produrre risultati diversi.
Quando si spostano i bit, è importante capire i limiti del tipo di dati utilizzato.

## Campi di bit

Abbiamo visto come i bit raggruppati in un semplice tipo di dati possano essere indirizzati in base alla loro posizione.
I bit raggruppati in una `struct` possono essere indirizzati per nome.
Un tipo di dati così si chiama `bit field`.
Un caso d'uso dei `bit fields` può essere quando serve una raccolta di flag ON/OFF e si vuole ridurre al minimo l'uso della memoria.

```c
#include <stdio.h>

int main() {

    struct lights {
        unsigned int number_of_lights;
        unsigned int red   : 1;
        unsigned int green : 1;
        unsigned int blue  : 1;
    };
    struct lights lightboard = {3, 0, 0, 0};
     
    //  prints 000
    printf("%d", lightboard.red);
    printf("%d", lightboard.green);
    printf("%d\n", lightboard.blue);
    
    lightboard.green = 1;

    //  prints 010
    printf("%d", lightboard.red);
    printf("%d", lightboard.green);
    printf("%d\n", lightboard.blue);
    
    // prints 3
    printf("%d\n", lightboard.number_of_lights);
}
```

La sintassi `unsigned int variable_name : 1;` crea un campo di `1` bit all'interno di un `unsigned int` inserito nella struct.
Al posto di un `unsigned int` si potrebbe usare un `signed int`, oppure, da C99 in poi, si potrebbe usare un tipo `bool`.
Una struct che contiene campi di bit può contenere anche campi di altri tipi di dati, come `number_of_lights` nell'esempio precedente.
