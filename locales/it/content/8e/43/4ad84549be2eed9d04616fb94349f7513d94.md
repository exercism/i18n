# Test

Per eseguire i test, lancia il comando `bal test --offline` dalla directory dell'esercizio.

## Test saltati

All'inizio sarà abilitato solo il primo test.
Serve a incoraggiarti a risolvere l'esercizio un passo alla volta.
Quando il primo test passa, rimuovi la proprietà `enable: false` dal test successivo e lavora per far passare anche quello.
