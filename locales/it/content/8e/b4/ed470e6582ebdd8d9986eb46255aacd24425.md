# Istruzioni

Conta i rettangoli in un diagramma ASCII come quello qui sotto.

```text
   +--+
  ++  |
+-++--+
|  |  |
+--+--+
```

Il diagramma qui sopra contiene questi 6 rettangoli:

```text


+-----+
|     |
+-----+
```

```text
   +--+
   |  |
   |  |
   |  |
   +--+
```

```text
   +--+
   |  |
   +--+


```

```text


   +--+
   |  |
   +--+
```

```text


+--+
|  |
+--+
```

```text

  ++
  ++


```

Puoi dare per scontato che l'input sia sempre un rettangolo ben formato (cioè che la lunghezza di ogni riga sia uguale alla lunghezza della prima riga).
