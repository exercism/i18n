# Sovraccarico degli operatori

Il sovraccarico degli operatori è una funzionalità di alcuni linguaggi di programmazione che permette di ridefinire gli operatori standard, come l'addizione (`+`), la sottrazione (`-`), la moltiplicazione (`*`) e la divisione (`/`), perché funzionino con tipi definiti dall'utente.

Questo può rendere la sintassi del codice più intuitiva, permettendo di esprimere le operazioni sui tipi definiti dall'utente allo stesso modo delle operazioni sui tipi primitivi.

In Cairo, il sovraccarico degli operatori si ottiene implementando dei trait specifici.

Ogni operatore ha un trait associato, e sovraccaricare quell'operatore significa fornire un'implementazione di quel trait per un tipo personalizzato.
Tuttavia, è essenziale usare il sovraccarico degli operatori con giudizio.

Un uso scorretto può generare confusione e rendere il codice più difficile da mantenere, per esempio quando l'operatore che si sovraccarica non ha alcun significato semantico.

Consideriamo un esempio in cui bisogna combinare due `Potions`.

Le `Potions` hanno due campi dati, mana e health.

Combinare due `Potions` dovrebbe sommare i rispettivi campi.

```rust
struct Potion {
    health: felt252,
    mana: felt252,
}

impl PotionAdd of Add<Potion> {
    fn add(lhs: Potion, rhs: Potion) -> Potion {
        Potion { health: lhs.health + rhs.health, mana: lhs.mana + rhs.mana }
    }
}

fn main() {
    let health_potion: Potion = Potion { health: 100, mana: 0 };
    let mana_potion: Potion = Potion { health: 0, mana: 100 };
    let super_potion: Potion = health_potion + mana_potion;
    // Both potions were combined with the `+` operator.
    assert(super_potion.health == 100, '');
    assert(super_potion.mana == 100, '');
}
```

Nel codice qui sopra, implementiamo il trait `Add` per il tipo `Potion`.

La funzione add prende due argomenti: `lhs` e `rhs` (lato sinistro e lato destro).

Il corpo della funzione restituisce una nuova istanza di `Potion`, con i valori dei campi che sono una combinazione di `lhs` e `rhs`.

Come illustrato nell'esempio, sovraccaricare un operatore richiede di specificare il tipo concreto che si sta sovraccaricando.

Il trait generico sovraccaricato è `Add<T>`, e definiamo un'implementazione concreta per il tipo `Potion` con `Add<Potion>`.
