# Test

## Clojure CLI

Gli esercizi di Clojure su Exercism includono un file `deps.edn` con un alias `:test` per invocare [cognitect-labs test-runner](https://github.com/cognitect-labs/test-runner):

``` bash
$ clj -X:test
```

## Leiningen

Leiningen può essere usato anche per eseguire il test dell'esercizio, eseguendo il comando seguente dalla directory dell'esercizio:

```bash
lein test
```

## REPL

Per usare la REPL ed eseguire il test dell'esercizio, esegui il comando seguente dalla directory dell'esercizio:

```bash
$ clj
```

-oppure-

```bash
$ lein repl
```

Poi `require` il namespace di test dell'esercizio e il namespace di test di Clojure):

```clojure
;; replace <exercise> with the exercise's name
=> (require '<exercise>-test)
```

Poi chiama `run-tests` su `<exercise>-test`:

```clojure
;; replace <exercise> with the exercise's name
=> (clojure.test/run-tests '<exercise>-test)
```
