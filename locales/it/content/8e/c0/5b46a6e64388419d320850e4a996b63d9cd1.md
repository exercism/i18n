# Appendice alle istruzioni

## Implementazione

È possibile esaurire i nomi dei robot: una volta che ogni possibile nome di robot è stato assegnato, si dovrebbe restituire un errore.

## Test bonus

Una volta che `go test` passa, troverai nella suite di test un test chiamato `TestCollisions`, che viene saltato per impostazione predefinita perché può richiedere molto tempo.
Questo test crea nuovi robot finché non è più possibile assegnare nuovi nomi al robot.

Per far eseguire il test, rimuovi questa riga:

```go
t.Skip("skipping test as it can take a long time to run if solution is sub-optimal.")
```

Per far passare questo test dovrai assicurarti che il nome di un robot non sia già stato usato e che i nomi possano essere assegnati in modo efficiente.
