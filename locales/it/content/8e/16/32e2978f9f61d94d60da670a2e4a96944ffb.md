# Pacchetti

Sulla traccia F# sono supportati i seguenti pacchetti:

| Pacchetto      | Versione |
| --------------- | ------- |
| Aether          | 8.3.1   |
| BenchmarkDotNet | 0.12.1  |
| FParsec         | 1.1.1   |

```exercism/caution
Se il codice usa una combinazione pacchetto/versione non supportata, i test eseguiti sul sito web falliranno.
```
