# Introduzione

Swift ha una serie di istruzioni che possono essere usate per modificare il normale flusso di controllo dei cicli.
Sono note come istruzioni di trasferimento del controllo.
Hai già visto `return`; in questo concetto ne vedremo altre, tra cui `continue`, `break` e le etichette.

## Continue

A volte è necessario saltare in anticipo all'iterazione successiva di un ciclo, senza completare il resto delle istruzioni dell'iterazione corrente.
Per farlo si può usare la parola chiave `continue`.
Quando `continue` viene eseguito, il ciclo passa al controllo successivo per vedere se l'iterazione seguente può essere eseguita, cioè il `while` nei cicli while e repeat-while oppure il controllo che ci sia un altro elemento nella sequenza nei cicli for-in.

```swift
count = 1
while count < 6 {
  count += 1
  if count == 4 { continue }
  print(count)
}

// prints:
// 2
// 3
// 5
```

## Break

Break serve a uscire da un ciclo in anticipo.
Quando `break` viene eseguito, il ciclo termina immediatamente e il programma prosegue con la prima istruzione dopo il ciclo.

```swift
for fruit in ["banana", "grapes", "apple", "strawberry", "kiwi", "lemon"] {
  if !fruit.count.isMultiple(of: 2) { break }
  print(fruit)
}

// prints:
// banana
// grapes
```

## Etichette

Quando i cicli sono annidati, a volte può servire usare `break` o `continue` per uscire dai cicli esterni che contengono il ciclo in cui `break` o `continue` sono usati, oppure per riavviarli.
In casi come questi si possono usare le etichette per specificare il ciclo da terminare o da riavviare.
Un ciclo può essere etichettato mettendo un nome seguito da due punti prima del `while`, del `repeat` o del `for` che avvia il ciclo.

Per vedere l'effetto dell'uso delle etichette in questo modo, considera il seguente ciclo.

```swift
outerLoop: for fruit in ["banana", "grapes", "apple", "strawberry", "kiwi", "lemon"] {
  print("\n--- \(fruit) ---")
  for letter in fruit {
    guard letter != "n" else { break outerLoop }
    print(letter)
  }
}

// prints:
// --- banana ---
// b
// a
```

## Fallthrough

La parola chiave `fallthrough` serve a passare al caso successivo in un'istruzione switch.
Questo significa che il codice all'interno del caso successivo verrà eseguito senza controllare la sua condizione (o le sue condizioni).
Così l'istruzione switch si comporta come in altri linguaggi di programmazione, dove l'istruzione `break` non è necessaria per uscire dallo switch dopo che un caso è stato soddisfatto.
Puoi leggere di più su `fallthrough` nel [libro di Swift][fallthrough].

```swift
let value = 1
switch value {
case 1:
  print("One")
  fallthrough
case 2:
  print("Two")
}

// prints:
// One
// Two
```
