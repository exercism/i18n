# Appendice alle istruzioni

## Note di implementazione

`Range` deve restituire un array di tutte le terne pitagoriche con i lati nell'intervallo che va da `min` a `max`, estremi inclusi.

`Sum` deve restituire un array di tutte le terne pitagoriche in cui la somma `a+b+c` (il perimetro) è uguale a `p`.
I tre elementi di ogni terna restituita devono essere in ordine, `t[0] <= t[1] <= t[2]`, e l'array di terne deve essere in ordine lessicografico.
