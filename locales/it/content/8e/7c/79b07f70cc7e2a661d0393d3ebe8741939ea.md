# Introduzione

Haxe è un linguaggio a tipizzazione forte, ma il sistema di tipi può essere aggirato quando serve. Assegnare un valore a un nome si chiama definire una variabile. Una variabile può essere definita specificando esplicitamente il suo tipo, oppure lasciando che il compilatore Haxe deduca il tipo. Quindi, le due definizioni di variabile seguenti sono equivalenti:

```haxe
var explicitVariable:Int = 10; // Explicitly typed
var implicitVariable = 10; // Implicit typed
```

Per aggiornare una variabile si può usare l'operatore `=`:

```haxe
var number = 0; // Initial value
number = 1; // Updated value
```

Il compilatore genera un errore quando si prova ad assegnare un valore di tipo diverso da quello della variabile:

```haxe
var number = 1; // Variable number is of integer type
number = "Hello" // Error trying to assign a string to an integer variable
```

Una funzione che si trova all'interno di una classe si chiama _metodo_. I metodi possono avere zero o più parametri. Tutti i parametri devono avere un tipo specificato esplicitamente. Proprio come i parametri, il tipo restituito da un metodo non può essere dedotto e deve essere specificato. I valori vengono restituiti dai metodi usando la parola chiave `return`:

```haxe
function add(x:Int, y:Int):Int {
  return x + y;
}
```

Per chiamare un metodo si specificano il nome della classe e quello del metodo e si passano gli argomenti:

```haxe
var sum = add(1, 2) // sum = 3
```

In Haxe, lo scope è definito tra i caratteri `{` e `}`.

Haxe supporta due tipi di commenti. Quelli su riga singola sono preceduti da `//`, mentre i commenti su più righe vanno inseriti tra `/*` e `*/`.
