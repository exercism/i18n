# Istruzioni

In questo esercizio giocherai con un'auto radiocomandata, per cui hai finalmente risparmiato abbastanza soldi da poterla comprare.

Le auto partono con la batteria completamente carica (100%). Ogni volta che guidi l'auto con il radiocomando, percorre 20 metri e consuma l'uno per cento della batteria. Il soprannome dell'auto non è noto finché non viene creata.

L'auto radiocomandata ha un elegante display a LED che mostra due informazioni:

- La distanza totale percorsa, visualizzata come: `"<METERS> meters"`.
- La carica residua della batteria, visualizzata come: `"Battery at <PERCENTAGE>%"`.

Se la batteria è allo 0%, non puoi più guidare l'auto e il display della batteria mostrerà `"Battery empty"`.

## 1. Crea un'auto radiocomandata nuova di zecca

Implementa la funzione `RemoteControlCar.new/0` in modo che restituisca una struct di un'auto radiocomandata nuova di zecca:

```elixir
RemoteControlCar.new()
# => %RemoteControlCar{
#      battery_percentage: 100,
#      distance_driven_in_meters: 0,
#      nickname: "none"
#    }
```

Il soprannome è richiesto dalla struct: assicurati che un valore venga inizializzato nella funzione `new`, ma non nella struct.

## 2. Crea un'auto radiocomandata nuova di zecca con un soprannome

Implementa la funzione `RemoteControlCar.new/1` in modo che restituisca una struct di un'auto radiocomandata nuova di zecca con un soprannome fornito:

```elixir
RemoteControlCar.new("Blue")
# => %RemoteControlCar{
#      battery_percentage: 100,
#      distance_driven_in_meters: 0,
#      nickname: "Blue"
#    }
```

## 3. Visualizza la distanza

Implementa la funzione `RemoteControlCar.display_distance/1` in modo che restituisca la distanza così come viene visualizzata sul display a LED:

```elixir
car = RemoteControlCar.new()
RemoteControlCar.display_distance(car)
# => "0 meters"
```

Assicurati che la funzione accetti come argomento solo una struct `RemoteControlCar`.

## 4. Visualizza la percentuale della batteria

Implementa la funzione `RemoteControlCar.display_battery/1` in modo che restituisca la percentuale della batteria così come viene visualizzata sul display a LED:

```elixir
car = RemoteControlCar.new()
RemoteControlCar.display_battery(car)
# => "Battery at 100%"
```

Assicurati che la funzione accetti come argomento solo una struct `RemoteControlCar`. Se la batteria è allo 0%, il display della batteria mostrerà "Battery empty".

## 5. Guidare modifica la batteria e la distanza percorsa

Implementa la funzione `RemoteControlCar.drive/1` che:

- aggiorna di 20 il numero di metri percorsi
- consuma l'1% della batteria

```elixir
RemoteControlCar.new("Red")
|> RemoteControlCar.drive()

# => %RemoteControlCar{
#      battery_percentage: 99,
#      distance_driven_in_meters: 20,
#      nickname: "Red"
#    }
```

Assicurati che la funzione accetti come argomento solo una struct `RemoteControlCar`.

## 6. Gestisci la guida con la batteria scarica

Aggiorna la funzione `RemoteControlCar.drive/1` in modo che non aumenti la distanza percorsa né diminuisca la percentuale della batteria quando la batteria è scarica (allo 0%):

```elixir
%RemoteControlCar{
  battery_percentage: 0,
  distance_driven_in_meters: 1980,
  nickname: "Red"
}
|> RemoteControlCar.drive()

# => %RemoteControlCar{
#      battery_percentage: 0,
#      distance_driven_in_meters: 1980,
#      nickname: "Red"
#    }
```
