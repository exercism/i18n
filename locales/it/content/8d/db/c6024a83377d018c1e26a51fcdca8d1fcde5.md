# Istruzioni

Data una stringa di cifre, calcola il prodotto più grande per una sottostringa contigua di cifre di lunghezza n.

Ad esempio, per l'input `'1027839564'`, il prodotto più grande per una serie di 3 cifre è 270 (9 * 5 * 6), ed il prodotto più grande per una serie di 5 cifre è 7560 (7 * 8 * 3 * 9 * 5).

Tieni presente che queste serie devono occupare solo *posizioni adiacenti* nell'input; le cifre non devono essere *consecutive in senso numerico*.

Per l'input `'73167176531330624919225119674426574742355349194934'`, il prodotto più grande per una serie di 6 cifre è 23520.
