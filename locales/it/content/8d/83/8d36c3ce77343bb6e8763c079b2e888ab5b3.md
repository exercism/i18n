# Istruzioni

Sei un appassionato osservatore di uccelli che tiene traccia di quanti uccelli hanno visitato il tuo giardino in una determinata giornata.

Hai deciso di portare il tuo birdwatching a un livello superiore e di realizzare qualche strumento che ti aiuti a tenere traccia dei dati e a elaborarli.

Hai scelto di memorizzare i dati come un array di numeri interi.
Il primo numero dell'array è il numero di uccelli che hanno visitato il tuo giardino oggi, il secondo quelli di ieri, e così via.

```exercism/note
Nelle applicazioni reali, dovresti sempre usare i moduli core quando è possibile; per imparare la ricorsione, però, in questo esercizio non usare nessuna delle funzioni di `List`.
```

## 1. Verifica quanti uccelli hanno visitato il giardino oggi

Implementa la funzione `today`.
Dovrebbe ricevere in ingresso un array con i conteggi giornalieri degli uccelli e restituire il conteggio di oggi.
Se l'array è vuoto, dovrebbe restituire `Nothing`, altrimenti il conteggio viene racchiuso in un `Just`.

```elm
BirdCount.today [2, 5, 1]
    -- Just 2
```

## 2. Incrementa il conteggio di oggi

Implementa la funzione `incrementDayCount`.
Dovrebbe ricevere in ingresso un array con i conteggi giornalieri degli uccelli e incrementare di 1 il conteggio di oggi.
Se l'array è vuoto, restituisci `[1]`.

```elm
BirdCount.incrementDayCount [4, 0, 2]
    -- [5, 0, 2]
```

## 3. Verifica se c'è stato un giorno senza uccelli in visita

Implementa la funzione `hasDayWithoutBirds`.
Dovrebbe ricevere in ingresso un array con i conteggi giornalieri degli uccelli.
Dovrebbe restituire `True` se c'è stato almeno un giorno in cui nessun uccello ha visitato il giardino, e `False` altrimenti.

```elm
BirdCount.hasDayWithoutBirds [2, 0, 4]
    -- True

BirdCount.hasDayWithoutBirds [3, 8, 1, 5]
    -- False
```

## 4. Calcola il numero totale di uccelli in visita

Implementa la funzione `total`.
Dovrebbe ricevere in ingresso un array con i conteggi giornalieri degli uccelli e restituire il numero totale di uccelli che hanno visitato il tuo giardino da quando hai iniziato a raccogliere i dati.

```elm
BirdCount.total [4, 0, 9, 0, 5]
    -- 18
```

## 5. Calcola il numero di giornate intense

Alcune giornate sono più intense di altre.
Una giornata intensa è quella in cui cinque o più uccelli hanno visitato il tuo giardino.

Implementa la funzione `busyDays`.
Dovrebbe ricevere in ingresso un array con i conteggi giornalieri degli uccelli e restituire il numero di giornate intense.

```elm
BirdCount.busyDays [4, 5, 0, 0, 6]
    -- 2
```
