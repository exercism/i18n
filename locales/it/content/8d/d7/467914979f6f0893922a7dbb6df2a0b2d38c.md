# Informazioni

Haxe è fortemente tipizzato, ma il sistema di tipizzazione può essere aggirato quando necessario. Assegnare un valore a un nome è ciò che si chiama definire una variabile. Una variabile può essere definita specificandone esplicitamente il tipo, oppure lasciando che il compilatore Haxe inferisca il tipo usando la [parola chiave `var`](var). Pertanto, le seguenti due definizioni di variabile sono equivalenti:

```haxe
var explicitVariable:Int = 10; // Explicitly typed
var implicitVariable = 10; // Implicit typed
```

Aggiornare una variabile può essere fatto usando l'operatore `=`:

```haxe
var number = 0; // Initial value
number = 1; // Updated value
```

Il compilatore genererà un errore quando si prova ad assegnare un valore il cui tipo è diverso da quello della variabile:

```haxe
var number = 1; // Variable number is of integer type
number = "Hello" // Error trying to assign a string to an integer variable
```

In Haxe, il codice viene di solito scritto all'interno di una _funzione_, chiamata anche [_metodo_](method). Queste funzioni possono accettare parametri (argomenti) e restituire valori usando la parola chiave `return`. Le funzioni vengono chiamate usando la sintassi `()`. Tutte le funzioni devono avere un tipo di ritorno.

```haxe
function add(x:Int, y:Int):Int {
  return x + y;
}
```

Lo scope in Haxe è definito tra i caratteri `{` e `}`.

Haxe supporta due tipi di commenti. Quelli a riga singola sono preceduti da `//` e i commenti multilinea sono inseriti tra `/*` e `*/`.
