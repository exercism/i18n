# Installazione

## Installare Dart

Le istruzioni per installare l'SDK di Dart sono disponibili sul sito di Dart: [Ottieni Dart][get-dart]

## Plugin Dart per il tuo IDE o editor

Se usi un IDE o un editor, [aggiungi un plugin per Dart][editors] se ne esiste uno per l'editor che preferisci.

[get-dart]: https://dart.dev/get-dart
[editors]:  https://dart.dev/tools#editors
