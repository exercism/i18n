# Istruzioni

Gli endpoint HTTP sono migliori con il controllo dei tipi. Aggiungere un tipo Record a una richiesta POST garantirà che i dati corretti vengano inviati ogni volta.

## Obiettivi

- Modifica il codice fornito.
- Aggiungi gli attributi necessari a questo record per accettare due operandi e un operatore.
- Aggiungi una funzione di risorsa HTTP per accettare una richiesta POST sul percorso '/calc'
- La funzione deve accettare il tipo record Calculation come payload e restituire un oggetto JSON generico

### Accetta

```json
{ "operand1": 4, "operand2": 10.2, "operator": "+" }
```

### Restituisce

```json
{ "expression": "4+10.2", "result": 14.2 }
```
