# Test

Per eseguire i test dalla riga di comando, esegui il seguente comando dalla directory dell'esercizio:

```bash
java -jar /path/to/mars.jar nc runner.mips impl.mips
```

## Interfaccia grafica

Per eseguire i test tramite l'interfaccia grafica del simulatore MARS, inserisci la tua implementazione in fondo a `runner.mips` con l'istruzione `include`, togliendo il commento dall'ultima riga.
