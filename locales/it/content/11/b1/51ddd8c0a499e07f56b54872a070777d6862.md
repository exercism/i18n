# Appendice alle istruzioni

L'elevamento a potenza dei numeri complessi richiede una funzione esponenziale, una funzione seno e una funzione coseno, nessuna delle quali è disponibile in WebAssembly. Per fortuna, si può usare una [serie di Taylor](https://en.wikipedia.org/wiki/Taylor_series) per calcolarle. Dovresti avere almeno una precisione di `1/26!` per allinearti ai valori attesi.

## Funzione esponenziale

```
exp(x) ≃ 1 + x + x ^ 2 / 2! + x ^ 3 / 3! + x ^ 4 / 4! + ... + x ^ n / n!
```

## Funzione seno

```
sin(x) ≃ x - x ^ 3 / 3! + x ^ 5 / 5! - x ^ 7 / 7! + ... - x ^ n / n!
```

## Funzione coseno

```
cos(x) ≃ 1 - x ^ 2 / 2! + x ^ 4 / 4! - x ^ 6 / 6! + ... - x ^ n / n!
```
