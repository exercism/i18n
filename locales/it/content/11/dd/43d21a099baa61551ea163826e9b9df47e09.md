# Istruzioni

Gestisci un piccolo osservatorio meteo sulla riva della Vltava a Praga. A ogni
turno annoti le letture della temperatura in un registro di testo semplice, una
lettura per riga. Cinque piccole parole basteranno per tutta la contabilità di
un turno.

A ogni parola viene passato il percorso del file di registro.

## 1. Leggi tutte le letture

Definisci `read-readings` in modo che restituisca tutte le letture del registro
come array di stringhe, una per riga.

```factor
"weather.log" read-readings .
! => { "21.5" "19.0" "22.3" }
```

## 2. Trova la lettura più recente

Definisci `latest-reading` in modo che restituisca la lettura più recente, cioè
l'ultima riga del registro.

```factor
"weather.log" latest-reading .
! => "22.3"
```

## 3. Leggi il registro grezzo

Definisci `log-text` in modo che restituisca l'intero file di registro come
un'unica stringa, esattamente come è memorizzato.

```factor
"weather.log" log-text .
! => "21.5\n19.0\n22.3\n"
```

## 4. Registra una lettura

Definisci `record-reading` in modo che aggiunga una nuova lettura alla fine del
registro su una riga a sé, lasciando intatte le letture precedenti. Non
restituisce nulla.

```factor
"23.1" "weather.log" record-reading
"weather.log" log-text .
! => "21.5\n19.0\n22.3\n23.1\n"
```

## 5. Riscrivi il registro

Definisci `rewrite-log` in modo che sostituisca l'intero registro con un nuovo
array di letture, una per riga.

```factor
{ "10.0" "11.0" } "weather.log" rewrite-log
"weather.log" log-text .
! => "10.0\n11.0\n"
```
