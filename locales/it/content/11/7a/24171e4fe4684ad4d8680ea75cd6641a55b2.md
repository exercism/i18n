## Istruzioni

Ti hanno assunto in un centro di riciclaggio.
Per mancanza di spazio, tutti i prodotti finiscono sullo stesso nastro trasportatore, ma così materiali diversi si mescolano tra loro e diventano inutilizzabili.
Per risolvere il problema, il tuo compito è scrivere funzioni che identifichino il tipo di un prodotto.

### 1. Verifica se un valore è un booleano

Implementa la funzione `isBoolean`, che verifica se un valore è un booleano.

```javascript
isBoolean(true);
// => true

isBoolean(null);
// => false
```

### 2. Verifica se un valore è un numero

Implementa la funzione `isNumber`, che verifica se un valore è un `number` o un `bigint` _finito_, cioè se non è `NaN` né `Infinity`.

A volte il dispositivo che legge gli ID si guasta e legge un valore non numerico come `NaN` (Not a Number) o `Infinity`.
Anche la funzione deve saper gestire correttamente questo caso.

```javascript
isNumber(42);
// => true

isNumber('Hello, World!');
// => false

isNumber(42n);
// => true

isNumber(NaN);
// => false
```

### 3. Verifica se un valore è un oggetto

Implementa la funzione `isObject`, che verifica se il valore è un oggetto.
Sul nastro trasportatore, `null` non è nulla e non è considerato un oggetto.

```javascript
isObject({ greeting: 'Hello' });
// => true

isObject(25n);
// => false
```

### 4. Verifica se una stringa è numerica

Implementa la funzione `isNumericString`, che verifica se il valore è una stringa composta solo da cifre, oppure da un segno meno seguito da cifre, a indicare un numero negativo.
Vanno considerati solo i numeri interi: per questo controllo del robot di riciclaggio i decimali non sono considerati numerici.

```javascript
isNumericString(42);
// => false

isNumericString('42');
// => true

isNumericString('Hi!');
// => false
```

### 5. Verifica se un oggetto è elettronico

Implementa la funzione `isElectronic`, che verifica se un oggetto è un'istanza della classe `ElectronicDevice` fornita o di una delle sue classi figlie.

```javascript
class Duck {
  //...
}

class WashingMachine extends ElectronicDevice {
  //...
}

isElectronic(new Duck());
// => false

isElectronic(new WashingMachine());
// => true
```

### 6. Verifica se un valore è un array non vuoto

Implementa la funzione `isNonEmptyArray`, che verifica se un valore è un array non vuoto.

```javascript
isNonEmptyArray([1, 2, 3]);
// => true

isNonEmptyArray([]);
// => false
```

### 7. Verifica se un valore è un array vuoto

Implementa la funzione `isEmptyArray`, che verifica se un valore è un array vuoto.

```javascript
isEmptyArray([1, 2, 3]);
// => false

isEmptyArray([]);
// => true
```

### 8. Verifica se un oggetto ha una proprietà o un metodo `type`

Implementa la funzione `hasType`, che verifica se un oggetto ha una proprietà o un metodo `type`.

```javascript
class Keyboard(){
  type(){
    // ...
  }
}
hasType({ type:"car", color:"red" })
// => true

hasType({ color:"green" })
// => false

hasType(new Keyboard())
// => true
```

### 9. Lancia un errore se un oggetto non ha una proprietà o un metodo `id`

Implementa la funzione `assertHasId`, che lancia un `Error` se a un oggetto manca la proprietà `id`.

Se un oggetto ha la proprietà `id`, la funzione non deve restituire nulla.

```javascript
assertHasId({ id: 42, color: 'red' });
// => undefined

assertHasId({ color: 'green' });
// Error: "Object is missing the 'id' property"
```

### 10. Verifica se un oggetto ha una proprietà `id`

Implementa la funzione `hasIdProperty`, che verifica se un oggetto ha una proprietà `id`.

```javascript
class SimpleData {
  constructor() {
    this.number = '42';
    this.id = 'BC269327FE1D9B95';
  }
}

class StealingData extends SimpleData {}

class MethodData {
  constructor() {
    this.number = '42';
    this._id = 'BC269327FE1D9B95';
  }

  get id() {
    return this._id;
  }
}

hasIdProperty(new SimpleData());
// => true

hasIdProperty(new MethodData());
// => false

hasIdProperty(new StealingData());
// => false
```

### 11. Verifica se un oggetto ha una proprietà `type` definita

Implementa la funzione `hasDefinedType`, che verifica se un oggetto ha una proprietà `type` che non è `undefined`.

```javascript
hasDefinedType({ type: undefined, color: 'red' });
// => false

hasDefinedType({ type: 'car', color: 'green' });
// => true
```
