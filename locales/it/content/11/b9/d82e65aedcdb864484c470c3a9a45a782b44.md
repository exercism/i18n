# Istruzioni

Andrew, sviluppatore nella sua azienda, ha recentemente realizzato un piccolo generatore di query SQL da usare con uno strumento di migrazione dei database.
La sua prima implementazione, piuttosto ingenua, funzionava perfettamente con piccoli insiemi di dati.
Durante le grandi migrazioni in produzione, però, l'applicazione ha iniziato a consumare memoria in eccesso e faticava sotto carico elevato.
Dopo aver profilato l'applicazione, Andrew si è reso conto che la normale concatenazione di stringhe all'interno dei cicli costringeva Go a riallocare memoria di continuo.
Ora ha bisogno del tuo aiuto per riorganizzare lo strumento usando `strings.Builder` di Go, così che l'applicazione scali bene e gestisca grandi volumi di testo senza schiacciare l'heap di memoria.

## 1. Genera query SELECT

Implementa la funzione `BuildSelectQuery`.
Prende il nome di una tabella (`string`) e uno slice di nomi di colonna (`[]string`).
Deve restituire un'istruzione SQL `SELECT` completa, che termina con un punto e virgola.
Se lo slice delle colonne è vuoto o `nil`, la query deve usare il carattere jolly `*` per selezionare tutte le colonne.

```go
columns := []string{"id", "name", "email"}
BuildSelectQuery("users", columns)
// Function return: "SELECT id, name, email FROM users;"

BuildSelectQuery("orders", nil)
// Function return: "SELECT * FROM orders;"
```

## 2. Genera istruzioni INSERT multiple

Implementa la funzione `BuildBatchInserts`.
Prende il nome di una tabella (`string`) e uno slice bidimensionale che rappresenta le righe del database (`[][]ColumnValue`).
Ogni elemento di una riga associa un nome di colonna specifico al suo valore sotto forma di stringa.
La funzione deve restituire uno slice di singole stringhe SQL `INSERT`.
Il formato strutturato dello slice garantisce un ordine di output delle query prevedibile e stabile.
Se lo slice di righe in input è vuoto, restituisci uno slice di stringhe vuoto.
Se una singola riga è vuota, saltala.
I valori di tipo stringa nella clausola `VALUES` devono essere racchiusi tra apici singoli `'`.

```go
rows := [][]ColumnValue{
    {
        {Column: "title", Value: "Book"},
        {Column: "price", Value: "100"},
    },
    {
        {Column: "title", Value: "Magazine"},
        {Column: "price", Value: "15"},
    },
}

BuildBatchInserts("products", rows)
// Function returns string slice: [
//   "INSERT INTO products (title, price) VALUES ('Book', '100');",
//   "INSERT INTO products (title, price) VALUES ('Magazine', '15');"
// ]
```
