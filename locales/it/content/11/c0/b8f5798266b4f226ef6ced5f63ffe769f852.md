# Informazioni

## Iterazione sugli array

Un ciclo `for` permette di iterare su un array e ripetere il codice per ogni elemento:

```haxe
var fruitList = ["apple", "banana", "pear"];

for (fruit in fruitList) {
  trace(fruit);
}

// apple
// banana
// pear
```

Nell'esempio qui sopra, `fruit` è la variabile che contiene il valore di un singolo elemento dell'array `fruitList`. Il compilatore si assicura che si possa iterare su `fruitList`, altrimenti interrompe l'esecuzione.

## Iterazione su un intervallo

Puoi iterare sui numeri usando l'operatore di intervallo. L'operatore accetta due operandi di tipo `Int` e si scrive `min...max`. Il `min` è incluso e il `max` è escluso (`min` <= i e `max` > i)

```haxe
for (i in 0...10) {
  trace(i); // from 0 to 9
}
```

## Iterazione su coppie chiave-valore

È possibile iterare su collezioni di coppie chiave-valore. L'unica differenza nella sintassi è che, invece di una singola variabile, si usa un identificatore di variabile per la chiave, seguito da `=>`, seguito dall'identificatore di variabile per il valore:

```haxe
var map = [1 => 101, 2 => 202, 3 => 303];

for (k => v in map) {
  trace(key, value);
}

// 1, 101
// 2, 202
// 3, 303
```
