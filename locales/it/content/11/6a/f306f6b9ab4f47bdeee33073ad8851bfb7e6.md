# Informazioni

`TUPLE:` dichiara una classe con degli slot denominati. Factor genera automaticamente una parola costruttrice (il nome della classe con il suffisso `new`), un costruttore `boa` («per ordine di argomenti»), una sintassi letterale `T{ class … }` e una parola di accesso per ogni slot.

```factor
TUPLE: player
    { name initial: f }
    { level initial: 0 }
    { health initial: 100 } ;

player new .                                    ! T{ player }
3 100 "Merlin" player boa .                     ! by-order construction
T{ player { name "Merlin" } { health 50 } } .   ! literal syntax
```

Il sistema di accesso offerto da [`accessors`][accessors] mette a disposizione quattro varianti per slot: `name>>`, `>>name`, `change-name` e la coppia di mutazione `[ … ] change-name`. `>>name` e `change-name` mutano la tupla; se devi lasciare intatta quella originale, usa prima `clone`.

Le tuple supportano `=` tramite uguaglianza strutturale e vengono stampate mostrando i valori degli slot diversi da quelli predefiniti.

[accessors]: https://docs.factorcode.org/content/vocab-accessors.html
