# Suggerimenti

## 1. Definisci il tempo di cottura previsto in minuti

- Devi definire una [var][vars] usando [def].

## 2. Calcola il tempo di cottura rimanente in minuti

- Devi definire una [funzione][functions] con un solo parametro.
- Puoi usare la var definita in precedenza e farvi riferimento tramite il suo nome.
- Il risultato della valutazione dell'ultima espressione di una funzione viene restituito automaticamente dalla funzione; tutte le funzioni restituiscono questo valore.
- Puoi usare le funzioni di base per le [operazioni sui numeri][operators] per sottrarre valori.

## 3. Calcola il tempo di preparazione in minuti

- Devi definire una [funzione][functions] con un solo parametro.
- Puoi usare le funzioni di base per le [operazioni sui numeri][operators] per moltiplicare valori.

## 4. Calcola il tempo trascorso in minuti

- Devi definire una [funzione][functions] con due parametri.
- Puoi [chiamare][calling] una delle altre funzioni che hai definito in precedenza.
- Puoi usare le funzioni di base per le [operazioni sui numeri][operators] per sommare valori.
