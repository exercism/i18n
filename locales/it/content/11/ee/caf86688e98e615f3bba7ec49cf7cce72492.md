# Introduzione

In Cairo, il concetto di ownership si applica alle _variabili_ e definisce le regole che stabiliscono chi può usarle.
Ogni variabile dichiarata può essere usata una sola volta. Una volta usata, verrà distrutta o spostata, a seconda del tipo di utilizzo.

_Distruzione_ può avvenire in diversi modi:

- una variabile esce dallo scope (con o senza essere usata).
- una struct viene destrutturata.
- distruzione esplicita tramite `destruct()`

_Spostare_ un valore significa semplicemente passare quel valore a un'altra funzione.

Il linguaggio Cairo usa un sistema di tipi lineare, che sfrutta per garantire che tutto il codice sia dimostrabile (e verificabile) e per astrarre la memoria immutabile della Cairo VM.
