# Introduzione

La sintassi di destrutturazione degli array di JavaScript è un modo conciso per estrarre valori da un array ed assegnarli a variabili distinte.

In questo esempio, ogni valore nell'array `numberOfMoons` viene assegnato al suo pianeta corrispondente:

```javascript
const numberOfMoons = [0, 2, 14];
const [venus, mars, neptune] = numberOfMoons;

neptune;
// => 14
```
