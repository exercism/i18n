# Introduzione

In SQL, un'istruzione `SELECT` ti permette di recuperare i dati da un database.
Il risultato di un'istruzione `SELECT` è un insieme di risultati.
Un insieme di risultati contiene valori disposti in righe e colonne.
Ogni colonna è un particolare attributo dei dati.
Ogni riga contiene un valore per ogni colonna.

Un modo per pensarci è questo: un insieme di colonne rappresenta una struttura dati, dove ogni colonna rappresenta un campo della struttura dati ed ogni riga rappresenta un'istanza di quella struttura.

Con un'istruzione `SELECT` puoi specificare i dati che vuoi recuperare.
Puoi anche, se vuoi, trasformare, filtrare e/o modificare la forma dei dati in output.

## Le basi

L'anatomia di un'istruzione `SELECT` di base è la seguente:

```sql
SELECT <columns>
FROM <source>
WHERE <criteria>;
```

~~~~exercism/note
Le clausole `FROM` e `WHERE` sono facoltative.
Ad esempio, un'istruzione come `SELECT "Hello, world.";` è perfettamente valida.

Nota anche che gli a capo non sono obbligatori: qualsiasi spaziatura basta a separare le diverse clausole (cioè le parti) dell'istruzione `SELECT`.
~~~~

Subito dopo la parola chiave `SELECT` c'è un elenco delle colonne che vuoi nel risultato.
La clausola `FROM` identifica la sorgente dei dati, che di solito è una tabella del database.
La clausola `WHERE` filtra i dati in output in base a uno o più criteri.

## Filtrare i dati con la clausola WHERE

La clausola `WHERE` ti permette di filtrare i dati recuperati da un'istruzione `SELECT`.
Ad esempio, se vogliamo solo gli Appliances, possiamo fare così:

```sql
SELECT * FROM inventory
WHERE category = "Appliances";
```

Risultato:
```
upc           category    supplier        brand      product_name                 weight  stock
------------  ----------  --------------  ---------  ---------------------------  ------  -----
899001234556  Appliances  Culinary Depot  QuickBrew  Single-Serve Coffee Maker    4.2     18   
880012349876  Appliances  Culinary Depot  HeatWave   Compact Toaster Oven         7.5     14   
844110220987  Appliances  Culinary Depot  BlendPro   High-Speed Personal Blender  3.1     16   
```

Oppure magari vogliamo solo i dati in cui il weight è compreso tra 2.0 e 6.0:

```sql
SELECT * FROM inventory
WHERE weight BETWEEN 2.0 AND 6.0;
```

Risultato:
```
upc           category    supplier        brand      product_name                  weight  stock
------------  ----------  --------------  ---------  ----------------------------  ------  -----
899001234556  Appliances  Culinary Depot  QuickBrew  Single-Serve Coffee Maker     4.2     18   
823450987112  Cookware    KitchenCo       FreshKeep  12-Piece Glass Container Set  6       33   
899998877665  Cookware    KitchenCo       IronCraft  Cast-Iron Grill Pan           5.3     21   
844110220987  Appliances  Culinary Depot  BlendPro   High-Speed Personal Blender   3.1     16   
```
