# Introduzione

Ruby è un linguaggio dinamico [orientato agli oggetti][object-oriented-programming].
In Ruby tutto è un [oggetto][object].

In Ruby esistono due modi principali per assegnare oggetti a dei nomi: usare variabili oppure costanti.
Le variabili si scrivono sempre in [snake case][snake-case].
Nel corso della sua esistenza, una variabile può fare riferimento a oggetti diversi.
Per esempio, `my_first_variable` può essere definita e ridefinita molte volte usando l'operatore `=`:

```ruby
my_first_variable = 1
my_first_variable = "Some string"
my_first_variable = SomeComplexObject.new
```

Le costanti, invece, sono pensate per essere assegnate una sola volta.
Devono iniziare con una lettera maiuscola e di norma si scrivono tutte in maiuscolo, con le parole separate da underscore.

Per esempio:

```ruby
MY_FIRST_CONSTANT = 10

# Redefining not allowed
# MY_FIRST_CONSTANT = "Some String"
```

Ruby è organizzato in classi.
Le classi si definiscono usando la parola chiave `class`, seguita dal nome della classe.
Gli oggetti si creano in genere istanziando le classi con il metodo `.new`.

Per esempio:

```ruby
# Define the class
class Calculator
  #...
end

# Create an instance of it and assign it to a variable
my_first_calc = Calculator.new
```

Le unità di funzionalità sono incapsulate nei metodi, simili alle _funzioni_ di altri linguaggi.
Un metodo può essere definito facoltativamente con argomenti posizionali e/o argomenti con parole chiave, definiti e chiamati usando la sintassi `:`.
I metodi restituiscono implicitamente il risultato dell'ultima istruzione valutata, oppure possono restituire esplicitamente un oggetto tramite la parola chiave `return`.
I metodi si chiamano usando la sintassi `.`.

```ruby
class Calculator

  # Unnamed params
  def add(num1, num2)
    return num1 + num2 # Explicit return
  end

  # Named params
  def multiply(num1:, num2:)
    num1 * num2 # Implicit return
  end
end

calc = Calculator.new
calc.add(1, 3)
calc.multiply(num1: 2, num2: 5)
```
