# Introduzione

A volte, quando una funzione accetta molti argomenti, può essere difficile ricordare l'ordine in cui vanno passati. Per rendere più leggibile il codice, Gleam permette di etichettare gli argomenti con un nome.

Per etichettare un argomento, specifica il nome dell'etichetta prima del nome dell'argomento, separandoli con uno spazio.

```gleam
pub fn replace(
  in string: String,
  each target: String,
  with replacement: String
) -> String {
  // ...
}
```

Quando chiami una funzione con argomenti etichettati, gli argomenti possono essere passati in qualsiasi ordine. Queste chiamate a `replace` sono tutte equivalenti:

```gleam
replace(in: "🍔🍔🍔" each: "🍔", with: "🍕")

replace(each: "🍔", in: "🍔🍔🍔", with: "🍕")

replace(with: "🍕", each: "🍔", in: "🍔🍔🍔")
```

Le etichette sono sempre facoltative. Anche se una funzione ha argomenti etichettati, può comunque essere chiamata senza etichette.

```gleam
replace("🍔🍔🍔", "🍔", "🍕")
```
