# Imparare

Tcl è stato progettato con l'obiettivo di essere molto semplice ma potente.
Per questo motivo, imparare [la sintassi di base di Tcl][syntax] è abbastanza facile.

Per un tutorial pratico, vedi [Learn X in Y minutes: Tcl][X-in-Y].

Per un tutorial completo in più parti:
 - [Il tutorial di Tcl][tutorial] copre la versione 8.5 di Tcl (la versione stabile attuale è la 9.0)
 - Il supporto per la programmazione orientata agli oggetti è stato aggiunto al core di Tcl nella versione 8.6.
   Magicsplat offre un [tutorial approfondito sulla programmazione orientata agli oggetti][oo-tutorial] che lo tratta.
