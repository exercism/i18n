# Introduzione

Un parametro di un metodo può essere reso opzionale assegnandogli un valore predefinito. Quando si chiama un metodo con parametri opzionali, non è necessario passare un valore per questi parametri. Se non viene passato alcun valore per un parametro opzionale, verrà usato il suo valore predefinito.

I parametri opzionali _devono_ trovarsi alla fine dell'elenco dei parametri: non possono essere seguiti da parametri non opzionali.

```csharp
class Card
{
    static string NewYear(int year = 2020)
    {
        return $"Happy {year}!";
    }
}

Card.NewYear();     // => "Happy 2020!"
Card.NewYear(1999); // => "Happy 1999!"
```
