# Introduzione

I concetti di covarianza e controvarianza in PHP sono importanti, perché PHP impone che queste regole vengano rispettate quando si estendono classi o interfacce.

La covarianza preserva la relazione tra due tipi, mentre la controvarianza la inverte. In breve: quando estendi classi e sovrascrivi funzioni, puoi accettare tipi più o meno specifici per i parametri del metodo e puoi restituire dal metodo tipi più specifici o meno numerosi.

## Esempi

Considera la seguente classe:

```php
class Calculator 
{
    public function add(int $x, int $y): int 
    {
        return $x + $y;
    }
}
```

Se estendiamo la classe, possiamo accettare più tipi di parametro rispetto a quelli dichiarati in origine, ma non possiamo restituire nulla di diverso dai tipi restituiti originali.

```php
class Floatulator extends Calculator
{
    // This is valid
    public function add(int|float $x, int|float $y): int 
    {
        return (int)($x + $y);
    }
}
```

La seguente classe estesa non è valida, perché non è consentito restituire tipi aggiuntivi o più ampi:

```php
class BrokenCalculator extends Calculator 
{
    // This is invalid and will not compile
    public function add(int|float $x, int|float $y): int|float{
        return $x + $y;
    }
}
```
