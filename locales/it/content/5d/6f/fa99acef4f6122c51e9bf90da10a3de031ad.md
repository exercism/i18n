# Eseguire i test

## Scaricare un esercizio

Usa la [CLI di Exercism][cli] per scaricare l'esercizio su cui vuoi lavorare.

```sh
exercism download --track=dart --exercise=hello-world
```

Poi spostati nella directory dell'esercizio.

```sh
cd /path/to/exercism/dart/hello-world
```

## Installare le dipendenze

Prima di eseguire i test, scarica le dipendenze dell'esercizio.

```sh
dart pub get
```

## Eseguire i test

```sh
dart test
```

## Procedere con i test

La maggior parte degli esercizi ha diversi test, e per impostazione predefinita tutti tranne il primo sono saltati.

```dart
void main() {
  final twoFer = TwoFer();

  group('TwoFer', () {
    test('no name given', () {
      final result = twoFer.statement();
      expect(result, equals('One for you, one for me.'));
    }, skip: false);

    test('a name given', () {
      final result = twoFer.statement('Alice');
      expect(result, equals('One for Alice, one for me.'));
    }, skip: true);

    test('another name given', () {
      final result = twoFer.statement('Bob');
      expect(result, equals('One for Bob, one for me.'));
    }, skip: true);
  });
}
```

Per affrontare i test uno alla volta, cambia `skip: true` in `skip: false` su ciascun test man mano che procedi.
In alternativa, esegui tutti i test in una volta sola senza modificare il file.

```sh
dart test --run-skipped
```

Al momento dell'invio, il test runner online esegue tutti i test, compresi quelli saltati.

## Gestire l'errore «Could not find a command named frontend_server.dart.snapshot»

Supponi di avere un esercizio che hai già risolto e inviato, e di tornarci dopo un po' di tempo.
Potresti incontrare questo errore quando lo testi:

```sh
$ dart test
...
Could not find a command named "/path/to/frontend_server.dart.snapshot".
```

La [soluzione][solution] è eliminare il file `pubspec.lock`.
Poi esegui di nuovo il comando dart.
