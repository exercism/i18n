# Appendice alle istruzioni

# Input

Gli input per questo esercizio sono:

- `target`: una stringa (ad es. `'stone'`) sarà l'_argomento di sinistra_.
- `candidates`: un array di stringhe racchiuse in box (ad es. `'stone' ; 'tones' ; 'banana' ; 'tons' ; 'notes' ; 'Seton'`) sarà l'_argomento di destra_.

Il tuo verbo verrà chiamato così:

```j
  target     =. 'stone'
  candidates =. 'stone' ; 'tones' ; 'banana' ; 'tons' ; 'notes' ; 'Seton'
  
  subject findAnagrams candidates
```

## Output

Il tuo verbo dovrebbe restituire un _array_ di box che contengono le stringhe che sono anagrammi del target. Se non ci sono anagrammi, il risultato dovrebbe essere `empty`.
