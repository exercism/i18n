# Introduzione

I cicli servono a eseguire più volte la stessa logica.
I due tipi più comuni sono il `while loop` (iterazione indefinita) e il `for loop` (iterazione definita, o contata).
Esiste anche il ciclo `for each`, di cui parleremo in un concetto successivo.


## Sintassi generale

Il `for loop` è composto da un'intestazione e da un blocco di codice che contiene il corpo del ciclo racchiuso tra parentesi graffe.
L'intestazione è composta da 3 componenti separate da punti e virgola `;`: istruzione di inizializzazione, condizione e un'altra espressione.
Ognuna di queste può essere vuota.

```cpp
for (init-statement; condition; expression) {
  some_statement;
}
```

- La componente **init** è codice che viene eseguito una sola volta prima che il ciclo inizi.
- La componente **condition** deve essere un'espressione che restituisce un valore booleano e controlla quando il ciclo deve fermarsi.
Il codice all'interno del ciclo viene eseguito finché questa condizione è vera.
Non appena l'espressione diventa falsa, il ciclo non esegue più iterazioni.
- La componente **expression** è codice che viene eseguito alla fine di ogni iterazione.


Il `while loop` esegue il suo corpo finché la sua condizione è vera.
Lo snippet di codice qui sotto mostra come trasformare un ciclo for in un ciclo while.

```cpp
init-statement;
while(condition) {
    some_statement;
    expression;
}
```

## Intermezzo: incrementi e decrementi

Quando si lavora con i cicli, spesso è necessario aggiungere o sottrarre 1 a una variabile contatore.
L'operazione è così comune che esistono operatori appositi: `++` e `--`.

Esistono in una forma prefissa e in una forma postfissa.
La forma prefissa modifica la variabile prima che venga usata nell'istruzione, quella postfissa dopo.
Nella maggior parte dei casi probabilmente ti serve la forma prefissa.

```cpp
int a{3};
int b{--a};
// b is 2, a is now 2
int c{a++};
// c is 2, a is now 3
```

## Cicli for: un esempio

Di solito la componente init inizializza una variabile contatore, la condizione verifica se il ciclo deve continuare o fermarsi, mentre la componente post incrementa il contatore alla fine di ogni ripetizione.

```cpp
int sum{0};
for (int i{1}; i < 10; ++i) {
  sum += i;
}
```

Questo ciclo somma i numeri da `1` a `9` (incluso `9`).

## Break e continue

All'interno del corpo di un ciclo, puoi usare la parola chiave `break` per interrompere del tutto l'esecuzione del ciclo:

```cpp
int sum{2};
while(true) {
    sum *= 2;
    if (sum > 1000)
        break;
}
// sum is now 1024
```

Invece, la parola chiave `continue` interrompe solo l'esecuzione dell'iterazione corrente e passa a quella successiva:

```cpp
int equal_sum{0};
for (int i{1}; i < 7; ++i) {
  if  (i%2 == 1) {
    continue;
  }
  equal_sum += i;
}
// equal_sum is now 12
```
> Nota: di solito è più facile capire la logica di un ciclo quando l'uso di `break` e `continue` è ridotto al minimo o evitato del tutto.
