# Condizionali

Ruby ha quelle che vengono chiamate espressioni di controllo del flusso: servono a controllare il modo in cui il programma verrà eseguito e assumono un valore veritiero o falso.
Esistono operatori che si possono usare per creare valori veritieri o falsi, noti come [operatori di confronto][comparison-operators].

Ci sono due espressioni di controllo principali, usate per decidere quale codice verrà eseguito e quale no, cioè quale ramo verrà percorso.

Queste due sono: l'espressione `if` e l'espressione `unless`.

## Operatori di confronto

Gli [operatori di confronto][comparison-operators] si usano per confrontare valori e restituire un valore `true` o `false`.
Gli operatori seguenti richiedono due valori dello stesso tipo da confrontare.
Se i valori non sono dello stesso tipo, il compilatore genererà un errore.
Ecco un elenco degli operatori e un esempio di quando restituiscono un valore `true`:

| Metodo | Descrizione         | Esempio |
| ------ | ------------------- | ------- |
| <      | minore di           | 4 < 5   |
| <=     | minore o uguale a   | 4 <= 4  |
| >      | maggiore di         | 3 > 1   |
| >=     | maggiore o uguale a | 2 >= 2  |

Gli operatori di uguaglianza e disuguaglianza si possono usare per confrontare qualsiasi tipo di valore, a differenza degli operatori appena visti.
L'operatore `==` serve a verificare se due valori sono uguali, e questo include il controllo del tipo del valore.
L'operatore `!=` funziona allo stesso modo, ma restituisce `true` se i valori non sono uguali e `false` se sono uguali.
Ecco un elenco degli operatori di uguaglianza e disuguaglianza e un esempio di quando restituiscono un valore `true`:

| Metodo | Descrizione | Esempio |
| ------ | ----------- | ------- |
| ==     | uguale a    | 4 == 4  |
| !=     | diverso da  | 5 != 4  |

## Istruzione if

L'istruzione [`if`][if] serve a verificare se una data condizione è «veritiera» o «falsa».
Se la condizione è veritiera, il codice dentro l'istruzione if verrà eseguito.
Un'istruzione `if` termina con la parola chiave `end`.

```ruby
value = 1
if value == 1
  "1 is equal to 1"
end
# => "1 is equal to 1"

if value > 2
  "1 is greater than 2"
end
# => nil
```

## Istruzione unless

L'istruzione `unless` funziona in modo molto simile all'istruzione if, ma esegue il codice al suo interno se la condizione è falsa.

```ruby
value = 1
unless value == 1
  "1 is not equal to 1"
end
# => nil

unless value > 2
  "1 is not greater than 2"
end
# => "1 is not greater than 2"
```

## Istruzione else

L'istruzione `else` si può usare insieme all'istruzione if.
L'istruzione `else` viene eseguita se il ramo if non viene eseguito.

```ruby
value = 1
if value == 1
  "1 is equal to 1"
else
  "1 is not equal to 1"
end
# => "1 is equal to 1"

if value > 2
  "1 is greater than 2"
else
  "1 is not greater than 2"
end
# => "1 is not greater than 2"
```

## Istruzioni «if a cascata»

L'istruzione `elsif` si può usare insieme all'istruzione if.
L'istruzione `elsif` viene eseguita se il ramo if non viene eseguito e la condizione dell'istruzione elsif è veritiera.
Le istruzioni elsif si possono concatenare tra loro e verrà eseguita la prima condizione veritiera.
Alla fine dell'istruzione if può esserci anche un'istruzione else, che verrà eseguita se nessuna delle istruzioni precedenti è risultata vera.

```ruby
value = 1
if value == 0
  "1 is equal to 0"
elsif value > 2
  "1 is greater than 2"
else
  "1 is not equal to 0 and 1 is not greater than 2"
end
# => "1 is not equal to 0 and 1 is not greater than 2"
```
