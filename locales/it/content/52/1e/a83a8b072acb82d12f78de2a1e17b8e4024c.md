# Test

Esegui i test con `exercism test` o `eutest`. Tutti i test vengono eseguiti per impostazione predefinita.

## Saltare i test

Un buon modo per iniziare è trasformare in commento tutti i test tranne il primo in `t_<exercise>.e`.

```euphoria
test_equal("no name given", "One for you, one for me.", two_fer())
-- test_equal("a name given", "One for Alice, one for me.", two_fer("Alice"))
-- test_equal("another name given", "One for Bob, one for me.", two_fer("Bob"))
```

Procedi un test alla volta: togli il commento al test successivo quando quello corrente passa. Quando tutti i test passano, hai completato l'esercizio.
