# Istruzioni

Sei volontario al centro artistico del quartiere, dove sta prendendo forma un lungo mosaico di piastrelle di ceramica sopra l'ingresso principale. Il team di progettazione ha organizzato il lavoro **riga per riga**: ogni riga è un array di colori delle piastrelle, e l'intero mosaico è un array di righe.

Mentre i volontari tagliano, posizionano e riordinano le piastrelle, stai scrivendo piccole parole riutilizzabili per costruire, combinare e cercare i pezzi del disegno.

## 1. Una striscia di una sola piastrella

Definisci `tile-strip` in modo che prenda un colore e restituisca una riga di 1 elemento che contiene solo quel colore.

```factor
"sky-blue" tile-strip .
! => { "sky-blue" }
```

## 2. Una riga di tre piastrelle

Definisci `row-of-three` in modo che prenda tre colori dallo stack e restituisca una riga di 3 elementi.

```factor
"red" "white" "blue" row-of-three .
! => { "red" "white" "blue" }
```

## 3. Combina le righe in un elenco piatto di piastrelle

Il team di progettazione deve verificare i totali dei colori su tutte le righe del mosaico. Definisci `combine-rows` in modo che prenda un array di righe e restituisca un'unica sequenza con tutte le piastrelle in ordine.

```factor
{ { "red" "white" } { "blue" "red" } } combine-rows .
! => { "red" "white" "blue" "red" }
```

## 4. Specchia una riga

Per i pannelli simmetrici, il team specchia una riga prima di posizionare la copia sul lato opposto. Definisci `mirror-row` in modo che restituisca una riga in ordine inverso.

```factor
{ "red" "white" "blue" } mirror-row .
! => { "blue" "white" "red" }
```

## 5. Dov'è questo colore nella riga?

Definisci `tile-position` in modo che prenda una riga e un colore e restituisca l'indice (a base 0) della prima piastrella con quel colore nella riga. Se il colore non è presente, restituisci `f`.

```factor
{ "red" "white" "blue" } "white" tile-position .
! => 1

{ "red" "white" "blue" } "green" tile-position .
! => f
```

## 6. Questa riga contiene il colore?

Definisci `has-colour?` in modo che prenda una riga e un colore e restituisca `t` se il colore compare da qualche parte nella riga, altrimenti `f`.

```factor
{ "red" "white" "blue" } "white" has-colour? .
! => t

{ "red" "white" "blue" } "green" has-colour? .
! => f
```
