# Introduzione

## Cicli

I cicli servono a eseguire ripetutamente una certa logica.
I due tipi più comuni sono il `while loop` (ciclo indefinito) e il `for loop` (ciclo definito, o contato).
Esiste anche il ciclo `for each`, che incontreremo più avanti, in un altro concetto.

### Sintassi generale

Il `for loop` è composto da un'intestazione e da un blocco di codice che contiene il corpo del ciclo racchiuso tra parentesi graffe.
L'intestazione è composta da 3 componenti separate da punti e virgola `;`: l'istruzione di inizializzazione, la condizione e un'altra espressione.
Ognuna di queste può essere vuota.

```cpp
for (init_statement; condition; expression) {
  some_statement;
}
```

- La componente **init_statement** è codice che viene eseguito una sola volta, prima che il ciclo inizi.
- La componente **condition** deve essere un'espressione che valuta un valore `boolean` e controlla quando il ciclo deve fermarsi.
  Il codice all'interno del ciclo verrà eseguito finché questa condizione vale `true`.
  Non appena questa espressione vale `false`, il ciclo non eseguirà più altre iterazioni.
- La componente **expression** è codice che viene eseguito alla fine di ogni iterazione.

Il `while loop` esegue il suo corpo finché il controllo della **condition** vale `true`.
Il frammento di codice qui sotto mostra come trasformare un `for` in un `while loop`.

```cpp
init_statement;
while(condition) {
    some_statement;
    expression;
}
```

### Intermezzo: incrementi e decrementi

Quando si lavora con i cicli, spesso serve aggiungere o sottrarre 1 a una variabile contatore che tiene traccia delle iterazioni.
È così comune che le operazioni di incremento e decremento hanno operatori dedicati: `++` e `--`.

Esistono in una forma **prefissa** e in una **postfissa**.
La forma prefissa modifica la variabile prima del suo utilizzo nell'istruzione, quella postfissa dopo.
Nella maggior parte dei casi probabilmente ti serve la versione prefissa.

```cpp
int a{3};
int b{--a};
// b is 2, a is now 2
int c{a++};
// c is 2, a is now 3
```

### I cicli for: un esempio

La _componente init_ di solito inizializza una variabile contatore, la _condizione_ controlla se il ciclo deve continuare o fermarsi e la _componente post_ di solito incrementa il contatore alla fine di ogni ripetizione.

```cpp
int sum{0};
for (int i{1}; i < 10; ++i) {
  sum += i;
}
```

Questo ciclo somma i numeri da `1` a `9` (`9` incluso).

### break e continue

All'interno del corpo di un ciclo, puoi usare la parola chiave `break` per interrompere del tutto l'esecuzione del ciclo:

```cpp
int sum{2};
while(true) {
    sum *= 2;
    if (sum > 1000)
        break;
}
// sum is now 1024
```

Al contrario, la parola chiave `continue` interrompe solo l'esecuzione dell'iterazione corrente e passa a quella successiva:

```cpp
int equal_sum{0};
for (int i{1}; i < 7; ++i) {
  if  (i%2 == 1) {
    continue;
  }
  equal_sum += i;
}
// equal_sum is now 12
```

~~~~exercism/note
Di solito è più facile capire la logica del ciclo quando l'uso di `break` e `continue` è ridotto al minimo o evitato del tutto.
Entrambe le parole chiave saltano alcune sezioni del codice e spesso rendono più difficile seguire il flusso.
~~~~
