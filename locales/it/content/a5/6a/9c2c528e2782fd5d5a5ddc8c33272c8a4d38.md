# Introduzione

I caratteri in Factor sono numeri interi, ossia punti di codice Unicode, quindi gli operatori numerici `<`, `>` e `=` ti danno direttamente un ordinamento che distingue maiuscole e minuscole. Il vocabolario [`unicode`][unicode] aggiunge predicati che tengono conto di Unicode e la conversione di maiuscole e minuscole su singoli caratteri.

## Predicati sui caratteri

```
LETTER?  ( c -- ? )    ! uppercase letter
letter?  ( c -- ? )    ! lowercase letter
Letter?  ( c -- ? )    ! letter, either case
digit?   ( c -- ? )    ! decimal digit
digit>   ( c -- n )    ! the integer value of a digit char
blank?   ( c -- ? )    ! whitespace
```

```factor
USING: unicode ;

CHAR: A LETTER? .    ! => t
CHAR: a letter? .    ! => t
CHAR: 7 digit?  .    ! => t
CHAR: 7 digit>  .    ! => 7
```

## Conversione di maiuscole e minuscole

`ch>upper` e `ch>lower` cambiano il caso di un singolo carattere. Le versioni per stringa, `>upper` e `>lower`, le applicano a ogni carattere di una stringa.

```factor
CHAR: a ch>upper .   ! => 65   (which is CHAR: A)
"Hello" >upper .     ! => "HELLO"
```

`capitalize` porta tutta una stringa in minuscolo e poi mette in maiuscolo il suo primo carattere, cioè la maiuscola iniziale di una singola parola:

```factor
"hELLO" capitalize .   ! => "Hello"
```

## Letterali carattere

`CHAR: A` viene analizzato come il punto di codice intero di `A`. Per i caratteri con un nome, usa i nomi `space`, `tab`, `\n` e così via:

```factor
CHAR: A .        ! => 65
CHAR: space .    ! => 32
CHAR: \n .       ! => 10
```

## Simboli

Quando una parola deve restituire un'etichetta invece di un valore, ad esempio `yes`/`no`/`maybe` al posto di un booleano, dichiara ogni etichetta come un *simbolo*. Un simbolo è una parola che, quando viene chiamata, mette sé stessa sullo stack: due simboli risultano uguali solo quando hanno lo stesso nome.

```factor
USING: kernel ;

SYMBOLS: yes no maybe ;

yes .    ! => yes
yes yes = .    ! => t
yes no = .     ! => f
```

`SYMBOL: name` ne dichiara uno; `SYMBOLS: a b c ;` ne dichiara diversi.
