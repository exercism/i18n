# Appendice alle istruzioni

## Memoria riservata

Il buffer per la stringa di input usa i byte da 64 a 191 della memoria lineare.

## Formato dell'input

L'input arriva formattato come un'unica stringa di tre righe, con un'interruzione di riga alla fine di ciascuna. Le croci e i cerchi saranno sempre `X` e `O` maiuscoli.

Quindi la griglia

```
X··
OXO
XOX
```
viene codificata come

```
"X  \nOXO\nXOX\n"
```
