# Introduzione

JavaScript è un linguaggio dinamico, che supporta stili orientati agli oggetti, imperativi e dichiarativi (ad esempio la programmazione funzionale).

## Assegnazione (e riassegnazione)

In JavaScript ci sono alcuni modi principali per assegnare valori a dei nomi: usando variabili o costanti. Su Exercism, le variabili si scrivono sempre in [camelCase][wiki-camel-case]; le costanti si scrivono in [SCREAMING_SNAKE_CASE][wiki-snake-case]. Non esiste una guida ufficiale da seguire: aziende e organizzazioni diverse adottano stili diversi. _Sentiti libero di scrivere le variabili come preferisci_. Il vantaggio di scriverle come sono preparate negli esercizi è che verranno evidenziate in modo diverso nell'interfaccia web e nella maggior parte degli IDE.

In JavaScript, le variabili si possono definire usando la parola chiave [`const`][mdn-const], [`let`][mdn-let] o [`var`][mdn-var].

Una variabile può fare riferimento a valori diversi nel corso della sua esistenza quando si usa `let` o `var`. Per esempio, `myFirstVariable` può essere definita e ridefinita più volte usando l'operatore di assegnazione `=`:

```javascript
let myFirstVariable = 1;
myFirstVariable = 'Some string';
myFirstVariable = new SomeComplexClass();
```

A differenza di `let` e `var`, le variabili definite con `const` possono essere assegnate una sola volta. Questo si usa per definire le costanti in JavaScript.

```javascript
const MY_FIRST_CONSTANT = 10;

// Cannot be re-assigned.
MY_FIRST_CONSTANT = 20;
// => TypeError: Assignment to constant variable.
```

> 💡 In un esercizio di apprendimento successivo, esploreremo e spiegheremo la differenza tra l'assegnazione o l'associazione di una _costante_ e il _valore_ di una _costante_.

## Dichiarazioni di funzioni

In JavaScript, le unità di funzionalità sono incapsulate nelle _funzioni_: di solito le funzioni che stanno insieme vengono raggruppate nello stesso file. Queste funzioni possono accettare parametri (argomenti) e possono _restituire_ un valore usando la parola chiave `return`. Le funzioni si chiamano usando la sintassi `()`.

```javascript
function add(num1, num2) {
  return num1 + num2;
}

add(1, 3);
// => 4
```

> 💡 In JavaScript ci sono _molti_ modi diversi per dichiarare una funzione. Questi altri modi sono diversi dall'uso della parola chiave `function`. La traccia cerca di introdurli gradualmente, ma se li conosci già, sentiti libero di usare quello che preferisci. Nella maggior parte dei casi, usare l'uno o l'altro non è né meglio né peggio.

## Esporre ad altri file

Per rendere disponibile una `function`, una costante o una variabile in _altri file_, è necessario [esportarle][mdn-export] usando la parola chiave `export`. Un altro file può quindi [importarle][mdn-import] usando la parola chiave `import`. Questo è anche noto come sistema di moduli. Un ottimo esempio è come funzionano tutti i test. Ogni esercizio ha almeno un file, per esempio `lasagna.js`, che contiene l'_implementazione_. Inoltre, c'è almeno un altro file, per esempio `lasagna.spec.js`, che contiene i _test_. Questo file _importa_ le entità pubbliche (cioè esportate) per testare l'implementazione:

```javascript
// file.js
export const MY_VALUE = 10;

export function add(num1, num2) {
  return num1 + num2;
}

// file.spec.js
import { MY_VALUE, add } from './file';

add(MY_VALUE, 5);
// => 15
```
