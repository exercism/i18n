# Informazioni

Le funzioni per gestire input e output sono fornite dal [modulo `IO`][module-io].

- [`IO.puts/2`][io-puts] scrive una stringa sullo standard output, seguita da un carattere di nuova riga. Restituisce `:ok`.
- [`IO.write/2`][io-write] scrive una stringa sullo standard output, senza aggiungere un carattere di nuova riga. Restituisce `:ok`.
- [`IO.gets/2`][io-gets] legge una riga dallo standard input.
- [`IO.inspect/2`][io-inspect] scrive qualsiasi cosa sullo standard output e accetta opzioni utili come `:label`. Restituisce invariato il valore ricevuto. Utile per il debug.

## Il protocollo `String.Chars`

Se provi a passare a [`IO.puts/2`][io-puts] un valore che non riesce a stampare, vedrai un errore `Protocol.UndefinedError`.

```elixir
IO.puts({:ok, 7})
# ** (Protocol.UndefinedError) protocol String.Chars not implemented for {:ok, 7} of type Tuple
```

Quando succede, potresti voler usare [`IO.inspect/2`][io-inspect] al suo posto.

## `IO.inspect/2` per il debug

[`IO.inspect/2`][io-inspect] è perfetto per il debug: restituisce invariato il suo argomento, può stampare qualsiasi cosa e offre un'opzione `:label`.

```elixir
"HELLO\n"
|> String.trim()
|> IO.inspect(label: "step 1")
|> String.downcase()
|> IO.inspect(label: "step 2")

# > step 1: "HELLO"
# > step 2: "hello"
# => "hello"
```

## I dispositivi IO

Il primo argomento di tutte queste funzioni è un [dispositivo IO][io-devices], con il valore predefinito `:stdio` (standard input/output). Per scrivere sul dispositivo di errore standard, usa invece `:stderr`. Un dispositivo IO può anche essere un processo, per esempio uno creato chiamando [`File.open/2`][file-open], il che permetterebbe di scrivere su un file.
