# Appendice alle istruzioni

## Implementazione

Questo esercizio ti chiede di creare una struttura dati a lista concatenata che possa essere iterata.

1. Implementa la proprietà `Count`: non deve essere possibile cambiarne il valore dall'esterno
2. Implementa il metodo `Push(T value)`, che aggiunge un valore in testa alla lista.
3. Implementa il metodo `Pop()`, che rimuove e restituisce un valore dalla testa.
4. Aggiungi un costruttore che permetta l'inizializzazione con un singolo valore o con un iterabile
5. Implementa l'interfaccia `IEnumerable<T>`. Per maggiori informazioni, vedi [ienumerable].
6. Assicurati che il metodo `Reverse()` sia disponibile.

[ienumerable]: https://docs.microsoft.com/en-us/dotnet/api/system.collections.generic.ienumerable-1
