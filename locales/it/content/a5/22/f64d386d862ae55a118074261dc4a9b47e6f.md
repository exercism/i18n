# Test

## Installare il test runner della traccia GDScript di Exercism

Per usare il test runner, devi avere [Godot installato][installation] correttamente.

Per creare e testare gli script GDScript per Exercism, Godot viene eseguito in modalità "headless" dalla CLI.
Al momento queste istruzioni richiedono Linux e bash.

### Passaggio 1: installare l'infrastruttura del test runner

Per preparare l'ambiente per i test, clona [https://github.com/exercism/gdscript-test-runner][gdscript-test-runner] e sposta il suo contenuto in `/opt/test-runner/`:

```sh
git clone https://github.com/exercism/gdscript-test-runner.git
sudo mkdir -p /opt/
sudo mv gdscript-test-runner/ /opt/test-runner/
```

### Passaggio 2: scaricare lo script del test runner per il singolo esercizio

Se hai configurato lo strumento `exercism` e hai scaricato almeno un esercizio GDScript, dovrebbe essere stata creata una cartella `exercism/gdscript` per contenere gli esercizi.
Salva [il test runner][test-local-gdscript-solution] in questa cartella e rendi il file eseguibile, oppure crea direttamente un link a esso:

```sh
cd ~/exercism/gdscript # replace with your exercism/gdscript directory
ln /opt/test-runner/bin/test-local-gdscript-solution.sh
```

## Eseguire i test

Una volta completati i passaggi di installazione, puoi iniziare da qualsiasi cartella di esercizio (ad esempio `~/exercism/gdscript/two-fer`) ed eseguire lo script (che si trova un livello sopra, in `../`) per testare la soluzione locale di quell'esercizio:

```sh
../test-local-gdscript-solution.sh
```
