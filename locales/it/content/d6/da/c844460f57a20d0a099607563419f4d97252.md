# Introduzione

Una «quotation», cioè del codice tra parentesi quadre (`[ ]`), è a sua volta un valore in Factor, proprio come un numero o una stringa. Puoi memorizzarla in una variabile, metterla in un array, passarla a un'altra word e *chiamarla* più tardi.

## `call`

`call` (in [`kernel`][kernel]) esegue una quotation:

```factor
3 4 [ + ] call .
! => 7
```

Quando esegui `call` su una quotation in un contesto in cui Factor non riesce a dedurre l'effetto sullo stack, devi dichiarare l'effetto esplicitamente:

```
call( stack-effect ) ! e.g. call( a b -- c )
```

```factor
: apply-binary ( a b op -- c )
    call( a b -- c ) ;

5 3 [ - ] apply-binary .
! => 2
```

In questo modo si compila un controllo a runtime che verifica che la quotation abbia davvero l'effetto dichiarato.

## Le quotation nelle sequenze

Dato che le quotation sono valori, un array può contenere un misto di numeri e quotation:

```factor
{ 3 4 [ + ] }
```

Così «un programma» diventa una normale sequenza, e `each` diventa un modo naturale per eseguirne uno:

```
each ( seq quot -- )
```

```factor
{ [ 1 + ] [ 2 * ] } 5 swap [ call( x -- y ) ] each .
! 5 -> 6 -> 12
```

## Estrarre la parte finale di una sequenza

`head*` restituisce tutto tranne gli ultimi `n` elementi; `last2` restituisce gli ultimi due:

```
head* ( seq n -- headseq )
last2 ( seq -- penultimate last )
```

```factor
{ 1 2 3 4 5 } 2 head* .    ! => { 1 2 3 }
{ 1 2 3 4 5 } last2 .s
! => 4
! => 5
```

Insieme a `suffix`, è tutto ciò che ti serve per scrivere un'operazione sullo stack che «consuma i due elementi in cima e ne spinge uno come risultato».
