# Test

Prima di provare a eseguire i test, assicurati che la cartella dell'esercizio sia configurata correttamente seguendo i passaggi di installazione, cioè `corepack yarn install` e la configurazione dell'Editor SDK.

Esegui i test con:

```bash
$ corepack yarn test
```

Assicurati che il codice segua le best practice, come fanno gli altri utenti, con eslint, uno strumento che esegue l'analisi statica del codice.
Strumenti come questo fanno risparmiare tempo nel trovare errori di battitura o sciocchezze nel codice:

```bash
$ corepack yarn lint
```

Oppure fai entrambe le cose contemporaneamente:

```bash
$ corepack yarn test && corepack yarn lint
```

Il percorso TypeScript su Exercism non impone uno _stile_ di codice, quindi sei libero di scegliere tra punti e virgola, tabulazioni o spazi, e tutto ciò che sta nel mezzo.

## Creare il primo modulo

Di solito, i test di questo percorso caricano l'implementazione importandola come modulo: `import Bob from './bob';`.
Per farlo funzionare, devi esportare l'implementazione dal file in cui i test cercano il modulo, `bob.ts`:

```typescript
export class Bob {
  public hey(message: string) {
    // Your solution here
  }
}
```

Abbiamo fornito degli stub in ogni esercizio e ci abbiamo già inserito questo `export`.
