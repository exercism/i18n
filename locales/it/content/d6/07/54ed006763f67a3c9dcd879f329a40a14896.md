# Booleani

Crystal ha un tipo noto come [`Bool`][bools].
Rappresenta i valori `true` e `false`.

## Operatori logici

Crystal ha tre operatori logici (`!`, `||`, `&&`), che combinano i Bool e creano espressioni che producono valori diversi.

### And(`&&`)

L'operatore [_and_][and] in Crystal è rappresentato da `&&` e restituisce `true` se entrambi i valori sono `true`; altrimenti restituisce `false`.
Quando si usa l'operatore _and_, un Bool va messo a destra di `&&` ed un altro a sinistra.

```crystal
true && true
# => true

true && false
# => false
```

### Or(`||`)

L'operatore [_or_][or] in Crystal è rappresentato da `||` e restituisce `true` se **almeno uno** dei valori dati è `true`. 
Se entrambi i valori sono `false`, allora restituisce `false`.
Quando si usa l'operatore _or_, un Bool va messo a destra di `||` ed un altro a sinistra.

```crystal
true || true
# => true

true || false
# => true

false || false
# => false
```

### Not(`!`)

L'operatore _not_ in Crystal è rappresentato da `!` e restituisce `true` se il Bool dato è `false` e restituisce `false` se viene fornito `true`.
Quando si usa l'operatore _not_, un Bool va messo dopo l'operatore (`!`).

```crystal
!true
# => false

!false
# => true
```

## Usare le parentesi (`()`)

Quando lavori con i booleani, puoi usare le parentesi per decidere quali Bool valutare per primi.
Il risultato può cambiare a seconda di come vengono usate le parentesi.
In Crystal, ciò che è tra parentesi viene valutato per primo.

```crystal
true && false && false || true
# => true

true && false && (false || true)
# => false
```

Poiché ciò che è tra parentesi viene valutato per primo, nel seguente esempio l'operatore _not_ si applica all'espressione dentro le parentesi.

```crystal
!true && false
# => false

!(true && false)
# => true
```

~~~~exercism/note
Usa le parentesi solo quando influenzano il risultato; altrimenti vanno omesse.
~~~~
