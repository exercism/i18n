# Appendice alle istruzioni

## Istruzioni aggiuntive

Ti verrà fornita una tabella chiamata "isogram".
La prima colonna, "phrase", contiene del testo.
Devi stabilire se la frase è un isogramma.
Aggiorna la seconda colonna, "is_isogram", con un valore intero:

* 1 se la frase è un isogramma,
* 0 se non lo è.

~~~~exercism/note
Le operazioni di confronto di SQLite restituiscono valori booleani come numeri 0/1

```sh
$ sqlite3
sqlite> .mode table
sqlite> SELECT 1 < 2 AS "true", 1 > 2 AS "false";
+------+-------+
| true | false |
+------+-------+
| 1    | 0     |
+------+-------+
```
