# Istruzioni

In questo esercizio, scriverai del codice per aiutare un freelance a comunicare con un project manager.
Il tuo compito è fornire alcune funzioni di utilità per calcolare rapidamente tariffe giornaliere e mensili, opzionalmente con uno sconto specificato.

Stabiliamo prima alcune regole tra il freelance e il project manager:

- La tariffa giornaliera è 8 volte la tariffa oraria.
- Un mese ha 22 giorni fatturabili.

A volte, il freelance propone di applicare uno sconto sulla propria tariffa giornaliera (ad esempio per i clienti più fedeli o per i clienti senza scopo di lucro).

Gli sconti sono modellati come numeri frazionari che rappresentano percentuali, ad esempio `25.0` (25%).

## 1. Calcola la tariffa giornaliera data una tariffa oraria

Implementa una funzione chiamata `daily_rate` per calcolare la tariffa giornaliera data una tariffa oraria come parametro.
Il contratto definisce che un giorno ha 8 ore fatturabili.

```cpp
daily_rate(60)
// => 480.0
```

La tariffa giornaliera restituita deve essere di tipo `double`.

## 2. Calcola un prezzo scontato

Implementa una funzione `apply_discount` per calcolare il prezzo dopo uno sconto.
Deve accettare due parametri: il prezzo originale e la percentuale di sconto.

```cpp
apply_discount(150, 10)
// => 135.0
```

Il valore restituito deve essere sempre di tipo `double`, non arrotondato in alcun modo.

## 3. Calcola la tariffa mensile, data una tariffa oraria e uno sconto

Implementa una funzione `monthly_rate` per calcolare la tariffa mensile scontata.
Deve avere due parametri, una tariffa oraria e la percentuale di sconto.

```cpp
monthly_rate(77, 10.5)
// => 12130
```

La tariffa mensile restituita deve essere arrotondata per eccesso (prendi il valore ceiling) all'intero più vicino.

## 4. Calcola il numero di giorni lavorativi completi dato un budget, una tariffa oraria e uno sconto

Implementa una funzione `days_in_budget` che accetta un budget, una tariffa oraria e uno sconto, e calcola quanti giorni di lavoro completi copre.

```cpp
days_in_budget(20'000, 80, 11.0)
// => 35
```

Il numero di giorni restituito deve essere arrotondato per difetto (prendi il valore floor) all'intero più vicino.
