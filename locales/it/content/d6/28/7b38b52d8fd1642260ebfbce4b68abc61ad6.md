# Suggerimenti

## Generale

- Questo esercizio lavora con dati testuali e array. I valori `Text` di Unison possono essere scompattati in un array di `Char` e ricomposti di nuovo in `Text`. L'UCM supporta una funzionalità di «ricerca per tipo» che può essere utile per trovare le funzioni pertinenti.
- Prova a digitare `find : Text -> [Char]` nella riga di comando dell'UCM per vedere cosa compare. È il `:` a indicare che stiamo cercando per tipo invece che per nome. [Scopri di più sul comando `find`.](https://www.unison-lang.org/learn/ucm-commands/#find)
- Puoi anche consultare online le funzioni per il tipo `Text` e le funzioni per il tipo `List` su [Unison share.](https://share.unison-lang.org/@unison/code/latest/namespaces/public/base/latest)
