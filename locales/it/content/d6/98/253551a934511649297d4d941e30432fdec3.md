# Introduzione

Una [`function`][function] è un modo per suddividere il codice in compartimenti, così da poterla chiamare per nome da uno o più punti del programma.
Le funzioni servono a svolgere compiti specifici e ripetitivi.

In termini più formali: una funzione è un qualsiasi oggetto Python a cui si può applicare l'operazione di [`function call`][calls].
Una funzione può essere usata per [`return`][return] uno o più valori in seguito a una o più operazioni, oppure può essere usata per uno o più [`side effects`][side effects].
Se una funzione non specifica un valore restituito, restituirà comunque `None`.

Di seguito un esempio di funzione con un effetto collaterale:

```python
>>> def hello():
...     print("Hello")
...
>>> hello()
Hello

```

Nell'esempio qui sopra, la parola chiave [`def`][def] serve a segnalare l'inizio della definizione della funzione.
`hello` è il nome della funzione.
Le parentesi vuote indicano che alla funzione non viene passato alcun valore.
Il corpo della funzione è la singola istruzione `print("Hello")`.
Anche `print` è una funzione.
Il `"Hello"` tra le parentesi della funzione `print` è noto come [`argument`][arguments].
La funzione `print` usa l'argomento per sapere cosa stampare.
Nota che il corpo della funzione è indentato.
L'indentazione è importante perché Python si basa su di essa per sapere dove finisce quel blocco di codice.
Il corpo della funzione finisce alla fine del programma oppure subito prima della riga di codice successiva che _non_ è indentata.
Dato che `hello()` non specifica un valore di `return`, esegue il suo effetto collaterale, cioè chiama `print()`, e poi restituisce `None`.
Infine, chiamiamo la funzione usando il suo nome e le parentesi, il che segnala all'interprete Python che questo è un nome _chiamabile_.

Di seguito un esempio di funzione con un valore restituito:

```python
>>> def hello():
...     return "Hello"
... 
print(hello())
Hello

```

Il corpo di questa funzione è stato modificato: non più _chiamare_ `print`, ma _restituire_ la `string` "Hello".
Alla fine il codice stampa comunque `"Hello"`, ma l'effetto collaterale avviene nel _codice chiamante_ invece che nella funzione `hello`.
Se si omettono le parentesi quando si chiama la funzione `hello` (ad esempio `print(hello)`), `print` stamperebbe qualcosa come

```
<function hello at 0x0000026E18E93E20>
```

È importante ricordare che, anche se una funzione non accetta argomenti (_cioè non ha parametri_), per _chiamarla_ correttamente bisogna usare le parentesi vuote.
Questo è diverso da un linguaggio come Ruby, che non richiede parentesi vuote per chiamare una funzione senza argomenti.

Una funzione può definire zero o più [`parameters`][parameters]. Un parametro definisce quali argomenti la funzione accetta.

Di seguito un esempio di funzione che accetta un argomento:

```python
>>> def hello(name):
...     return f"Hello, {name}"
... 
>>> print(hello("Bob"))
Hello, Bob

```

Il parametro è definito come `name`.
`"Bob"` è l'argomento che il programma passa alla funzione `hello`.
La funzione _restituisce_ la `string` "Hello, Bob".

E se qualcuno chiama `hello` senza passare alcun argomento?
Il programma genera un errore:

```python
print(hello())
Traceback (most recent call last):

  Input In in <line: 1>
    print(hello())

TypeError: hello() missing 1 required positional argument: 'name'
```

Se non vogliamo che il programma vada in errore quando non c'è alcun argomento (_ma vogliamo permettere al codice chiamante di non fornirne uno_), possiamo definire un [argomento predefinito][default arguments].
Un argomento predefinito definisce quale valore usare se l'argomento manca quando la funzione viene chiamata.

Di seguito un esempio di funzione con un argomento predefinito:

```python
>>> def hello(name="you"):
...     return f"Hello, {name}"
... 
>>> print(hello())
Hello, you

```

Al parametro `name` viene assegnato l'argomento predefinito `"you"`, quindi il programma dà come output `Hello, you` se non gli viene passato un argomento `name`.

Per saperne di più sugli argomenti delle funzioni, consulta il concetto [argomenti delle funzioni][function arguments].
