# Informazioni

Il tipo primitivo `char` di Java è una rappresentazione a 16 bit di un singolo carattere Unicode.

~~~~exercism/note
Il tipo `char` si basa sulla [specifica Unicode originale][unicode-specification], che usava 16 bit per rappresentare i caratteri.
Questo basta a coprire la maggior parte delle lettere comuni e copre i caratteri nell'intervallo da 0x0000 a 0xFFFF.
Da allora la specifica ha esteso l'intervallo dei caratteri possibili fino a 0x01FFFF.

[unicode-specification]: https://www.unicode.org/versions/Unicode1.0.0/
~~~~

Più `char` possono comporre una stringa, come `"word"`, oppure i `char` possono essere elaborati singolarmente.
Un letterale `char` è racchiuso tra virgolette singole (ad es. `'A'`).

```java
char lowerA = 'a';
char upperB = 'B';
```

## Ottenere i `char` di una `String`

Il metodo `String.toCharArray` restituisce i caratteri di una stringa come array.
Come accennato in [array][concept-arrays], puoi usare un ciclo `for` per scorrere l'array.

```java
String text = "Hello";
char[] asArray = text.toCharArray();

for (char ch: asArray) {
    System.out.println(ch);
}

// Outputs:
// H
// e
// l
// l
// o
```

## La classe [Character][docs-character]

Ci sono molti metodi integrati della libreria per esaminare e manipolare i `char`.
Li puoi trovare come metodi statici della classe [`java.lang.Character`][docs-character].
Ecco alcuni esempi:

```java
Character.isWhitespace(' ');    // true
Character.isWhitespace('#');    // false

Character.isLetter('a');        // true
Character.isLetter('3');        // false

Character.isDigit('6');         // true
Character.isDigit('?');         // false
```

~~~~exercism/note
Alcuni metodi della classe Character hanno un overload che permette di accettare sia un `char` sia un `int`.
Per esempio, `isDigit` ne ha uno che accetta un [`char`][is-digit-char] e un altro un [`int`][is-digit-int].
Come accennato prima, il tipo `char` può rappresentare solo i caratteri nell'intervallo da 0x0000 a 0xFFFF.
L'`int`, invece, può rappresentare tutti i caratteri, da cui gli overload per `int`.

[is-digit-char]: https://docs.oracle.com/en/java/javase/21/docs/api/java.base/java/lang/Character.html#isDigit(char)
[is-digit-int]: https://docs.oracle.com/en/java/javase/21/docs/api/java.base/java/lang/Character.html#isDigit(int)
~~~~

## Aggiungere un `char` a una `String`

L'operatore `+` può essere usato per aggiungere un `char` a una `String`.

```java
'a' + " banana"     // => "a banana"
"banana " + 'a'     // => "banana a"
```

~~~~exercism/caution
Fai attenzione a _non_ usare `+` per unire due `char` insieme per formare una `String`!
Aggiungere due `char` in questo modo dà un `int`, _non_ una `String`!
Per esempio:

```java
'b' + 'c';
// => 197 (not the String "bc")
```

Questo perché Java promuove il `char` a un `int` (vedi [4.2 Primitive Types and Values ][jls-primitives] della [Java Language Specification][jls-main]).

[jls-main]: https://docs.oracle.com/javase/specs/jls/se21/html/
[jls-primitives]: https://docs.oracle.com/javase/specs/jls/se21/html/jls-4.html#jls-4.2
~~~~

Tuttavia, quando ci sono molti caratteri da aggiungere, può essere più efficiente usare invece uno [`StringBuilder`][docs-stringBuilder]:

```java
StringBuilder builder = new StringBuilder();
builder.append('a');
builder.append('b');
builder.append('c');

String builtString = builder.toString();
// => abc
```
