# Appendice alle istruzioni

## Parole

Definisci una tupla `linked-list-node`.

Definisci una tupla `linked-list` e fornisci un metodo `M: linked-list length` (da `sequences`). In questo modo i test possono chiamare `length` direttamente sulla lista.

- `<linked-list> ( -- linked-list )`: costruisci una lista vuota.
- `>linked-list ( seq -- linked-list )`: inserisci ogni elemento di `seq` in cima a una nuova lista, in ordine.
- `linked-list>array ( linked-list -- array )`: restituisci i valori, a partire dal valore in cima alla lista.
- `list-push ( linked-list value -- linked-list )`: inserisci un valore in cima.
- `list-pop ( linked-list -- linked-list value )`: rimuovi e restituisci il valore in cima.
- `list-peek ( linked-list -- value )`: restituisci il valore in cima senza rimuoverlo.
- `list-reverse ( linked-list -- linked-list )`: restituisci una lista con gli elementi in ordine inverso.

Lancia una classe di errore `list-empty` da `list-pop` e `list-peek` quando la lista è vuota.
