# Informazioni sulle funzioni anonime e le closure

PHP permette di dichiarare funzioni all'interno di altre funzioni. Queste funzioni non devono per forza avere un nome: possono essere assegnate a delle variabili o persino passate direttamente a un'altra funzione che richiede un parametro di tipo funzione.

```php
function onlyOdds(array $numbers): array
{
    return array_filter($numbers, function($num) {
        return $num % 2 === 1;
    });
}
```

La funzione definita e passata ad array_filter qui sopra è una funzione anonima. La funzione `array_filter` la usa per stabilire se un dato valore di un array sarà incluso nel risultato restituito da `array_filter`. Se la funzione restituisce `true` per un valore, quel valore sarà incluso nell'array risultato.

Le funzioni anonime possono anche essere usate per fare riferimento, dall'interno della funzione, a variabili che si trovano nello scope esterno alla funzione. Questo fenomeno è noto come lo scope della funzione che si «chiude» sulla variabile usata al suo interno, da cui il nome «closure». In alcuni linguaggi, tutte le variabili nello scope sono automaticamente utilizzabili all'interno della closure. In PHP, `$this`, che si riferisce all'oggetto corrente, è automaticamente disponibile all'interno della closure. Tutte le altre variabili devono essere referenziate esplicitamente usando la parola chiave `use`.

```php
function makeAdderFunction(int $number) {
    return function(int $x) use($number) {
        return $x + $number;
    }
}

$add5 = makeAdderFunction(5);
echo $add5(4); // echos 9
```

Nella funzione `makeAdderFunction` qui sopra, il valore `$number` che viene passato viene «chiuso» all'interno della funzione anonima definita internamente, che poi viene restituita. Così, ogni volta che quella funzione viene eseguita, conosce il valore di `$number` che le è stato passato. Se chiamassimo di nuovo questa funzione con un altro numero, otterremmo una funzione completamente diversa. Non cambierebbe i valori né il comportamento restituiti dalla prima chiamata alla funzione.
Se hai bisogno di chiudere su più di una variabile, puoi elencarle nella parola chiave `use` separandole con una virgola.

PHP ha anche una sintassi più breve per le funzioni, chiamata `arrow functions`. Queste funzioni devono essere piuttosto semplici. La loro forma di base è:

```php
fn(arguments) => expression
```

In questo stile di funzione, non hai bisogno di usare `use`. La funzione chiude e cattura automaticamente qualsiasi valore presente nello scope padre. L'espressione di queste arrow functions viene restituita automaticamente, senza bisogno di usare la parola chiave `return`. Questo ci permette di riscrivere la funzione `onlyOdds` qui sopra così:

```php
function onlyOdds(array $numbers): array
{
    return array_filter($numbers, fn($n) => $n % 2 == 1);
}
```

La funzione `makeAdderFunction` qui sopra potrebbe essere riscritta così:

```php
function makeAdderFunction(int $number) {
    return fn(int $x) => $x + $number;
}
```

**Nota:** se la funzione non può essere scritta come espressione, non è possibile usare la sintassi più breve delle arrow functions.

Le variabili vengono passate e usate all'interno delle funzioni anonime e delle closure per valore. Questo significa che se cambi il valore della variabile all'interno della funzione, il valore della variabile all'esterno non ne risentirà. Se hai bisogno che il valore venga modificato, puoi passarlo per riferimento.

```php
function positiveAverage(array $numbers): float
{
    $total = 0;
    $count = 0;
    return array_walk(
      $numbers,
      function($num) use (&$count, &$total) {
          $total += abs($num);
          $count++;
      }
    );
    return $total / $count;
}
```

Nell'esempio qui sopra `array_walk` itera su ogni elemento dell'array, inviando ciascun valore alla funzione definita nella chiamata. Mantiene un totale progressivo in `$total`, dove ogni valore aggiunto è il valore assoluto del numero. Tiene anche traccia di quanti numeri ci sono stati. Entrambi i valori sono usati nella closure per riferimento, come indica il `&` davanti a ciascuna variabile nella sezione `use`. Questo significa che le modifiche apportate alle variabili saranno ancora presenti quando `array_walk` termina, così la funzione può restituire la media dei valori assoluti dei numeri nell'array.

Le funzioni anonime e le closure possono offrire un modo comodo per definire una funzione che serve solo in un unico contesto, oppure per definire una funzione che restituisce una funzione dinamica basata su un insieme di parametri noti in un momento diverso da quello in cui la funzione viene effettivamente usata.
