# Informazioni

## Operatori aritmetici

JavaScript mette a disposizione 6 operatori diversi per eseguire le operazioni aritmetiche di base sui numeri.

- `+`: L'operatore di addizione serve a trovare la somma di numeri.

  ```javascript
  1 + 2; // => 3
  2.5 + 3.9; // => 6.5
  ```

- `-`: L'operatore di sottrazione serve a trovare la differenza tra due numeri

  ```javascript
  19 - 2; // => 17
  7.4 - 1.2; // => 6.2
  ```

- `*`: L'operatore di moltiplicazione serve a trovare il prodotto di due numeri

  ```javascript
  7 * 5; // => 35
  9.2 * 6.3; // => 57.959999999999994
  ```

- `/`: L'operatore di divisione serve a dividere due numeri.
  Dato che i numeri di JavaScript sono sempre numeri in virgola mobile, non esiste la divisione intera.

  ```javascript
  8 / 2; // => 4
  25 / 3; // => 8.333333333333334
  ```

- `%`: L'operatore modulo serve a trovare il resto di una divisione.

  ```javascript
  40 % 4; // => 0
  11 % 4; // => 3
  -11 % 4; // => -3
  ```

- `**`: L'operatore di esponenziazione serve a elevare un numero a una potenza.
  Equivale a usare [`Math.pow()`][mdn-math-pow]

  ```javascript
  4 ** 3; // => 64
  4 ** 1 / 2; // => 2
  ```

## Ordine delle operazioni

Quando si usano più operatori sulla stessa riga, JavaScript segue un ordine di precedenza, come mostrato in [questa tabella di precedenza][mdn-operator-precedence].
Per semplificare nel nostro contesto, JavaScript usa la regola PEDMAS (Parentesi, Esponenti, Divisione/Moltiplicazione, Addizione/Sottrazione) che abbiamo imparato alle scuole elementari.

<!-- prettier-ignore-start -->
```javascript
const result = 3 ** 3 + 9 * 4 / (3 - 1);
// => 3 ** 3 + 9 * 4/2
// => 27 + 9 * 4/2
// => 27 + 18
// => 45
```
<!-- prettier-ignore-end -->

## Operatori di assegnazione abbreviati

Gli operatori di assegnazione abbreviati sono un modo più breve per scrivere codice che esegue operazioni aritmetiche su una variabile e assegna il nuovo valore alla stessa variabile.
Ad esempio, consideriamo due variabili `x` e `y`.
Allora, `x += y` equivale a `x = x + y`.
Spesso si usa un numero al posto della variabile `y`.
Anche le altre 5 operazioni si possono svolgere in modo simile.

```javascript
let x = 5;
x += 25; // x is now 30

let y = 31;
y %= 3; // y is now 1
```
