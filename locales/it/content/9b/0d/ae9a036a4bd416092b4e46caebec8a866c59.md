# Istruzioni

L'ufficio oggetti smarriti della scuola conserva tutto in delle scatole, e quello che finisce in una scatola può essere qualsiasi cosa: un maglione, un numero di cose, un nome.

Scrivi una classe `LOST_BOX{T}`. Lo stub fornisce l'intestazione della classe.

## 1. Accettare qualcosa

`create` riceve l'oggetto e il nome di chi l'ha consegnato, e restituisce una scatola. Una scatola inizia come non reclamata.

```sather
box ::= #LOST_BOX{STR}("blue jumper", "Mia");
box.item
-- => "blue jumper"
box.handed_in_by
-- => "Mia"
box.claimed
-- => false
```

## 2. Reclamarla

`claim` segna la scatola come reclamata. Non restituisce nulla.

```sather
box.claim;
box.claimed
-- => true
```

## 3. È ancora in attesa?

`waiting` restituisce se la scatola non è stata reclamata.

```sather
box.waiting
-- => false
```

## 4. Scambiare il contenuto

`replace` riceve un nuovo oggetto, lo mette nella scatola e restituisce quello che c'era prima. L'oggetto che entra e l'oggetto che esce sono entrambi di tipo `T`.

```sather
old ::= box.replace("red jumper");
old
-- => "blue jumper"
box.item
-- => "red jumper"
```

## 5. Descriverla

`describe` restituisce una riga sulla scatola, come `"blue jumper, handed in by Mia"`.

Per inserire l'oggetto in una stringa, la classe deve sapere che un `T` può essere convertito in una. Vincola il parametro: scrivi l'intestazione della classe come `class LOST_BOX{T < $STR}`, e a quel punto `item.str` è consentito.

```sather
box.describe
-- => "blue jumper, handed in by Mia"
```
