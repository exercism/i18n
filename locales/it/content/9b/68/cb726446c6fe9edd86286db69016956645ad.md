## MacOS

Per prima cosa, installa Lua e [Luarocks][2] usando [Homebrew][1]:

```shell
$ brew install lua luarocks
```

Poi installa [Busted][3], il framework di test per Lua:

```shell
$ luarocks install --local busted
```

Aggiungi `~/.luarocks/bin` al `$PATH` di sistema

```shell
export PATH="$HOME/.luarocks/bin:$PATH"
```

Tieni presente che è solo temporaneo.
Per aggiungerlo in modo permanente al tuo `$PATH`, dovrai aggiungerlo al tuo `.bashrc`, `.zshrc` o `config.fish`, a seconda della shell che stai usando.

Poi esegui i test:

```shell
$ busted
```

## Windows 10: WSL

Per prima cosa devi abilitare [WSL (Windows Subsystem for Linux)][7] usando [PowerShell][8] (come amministratore):

```shell
PS> Enable-WindowsOptionalFeature -Online -FeatureName Microsoft-Windows-Subsystem-Linux
```

Questo richiede un riavvio.

Poi installa Ubuntu dal [Microsoft Store][9], **oppure** scaricalo e installalo usando PowerShell:

```shell
PS> curl.exe -L -o ubuntu1804.appx https://aka.ms/wsl-ubuntu-1804
PS> Add-AppxPackage .\ubuntu1804.appx; rm .\ubuntu1804.appx
PS> ubuntu1804
```

Poi aggiorna la lista dei pacchetti:

```shell
PS> wsl
$ sudo apt-get update
```

Ora sei pronto a installare [LuaRocks][2] e [Busted][3] seguendo le [istruzioni per Ubuntu](#ubuntu) qui sopra.

Fatto questo, puoi eseguire i test direttamente da qualsiasi riga di comando di Windows:

```cmd
C:\> wsl busted
```

## Windows 10: Docker

### Installare Gitbash

Questo passaggio è facoltativo. Potresti dover adattare leggermente i passaggi seguenti se preferisci usare la CLI nativa di Windows o un'altra CLI.

Scarica [qui][10].
Istruzioni di installazione [qui][11].

### Installare Docker

Segui le istruzioni per installare [Docker for Windows][12].
Una volta terminata l'installazione, puoi eseguire il comando seguente per verificare che sia stata installata correttamente.

```shell
$ docker --version
```

_Potresti incontrare un errore quando provi a eseguire Docker la prima volta._

`cannot enable hyper-v service`

_Se succede, puoi seguire queste istruzioni per [abilitare Hyper V][13]. Potresti dover disattivare l'impostazione, riavviare il computer e riattivarla dopo l'avvio._

### Installare busted

Una volta installati Gitbash e Docker, potrai installare un «container» di busted.

In Gitbash esegui quanto segue:

Scarica questo container Docker molto diffuso eseguendo quanto segue:

```shell
$ docker pull imega/busted
```

Crea una funzione così non dovrai digitare ogni volta il comando completo.
Aggiungi questo al tuo `.bashrc`:

```shell
dbusted() { docker run --rm -t -v "/$@":/data imega/busted; }
```

Ora, nella tua CLI, puoi spostarti nella directory in cui vuoi eseguire i test. Esegui quanto segue:

```shell
$ dbusted $PWD
```

Dovresti vedere l'output dei test di busted.
