# Appendice alle istruzioni

## Registri

| Registro | Utilizzo  | Tipo    | Descrizione                     |
| -------- | --------- | ------- | ------------------------------- |
| `$a0`    | input     | indirizzo | stringa di input terminata da null |
| `$v0`    | output    | intero  | punteggio di Scrabble           |
| `$t0-9`  | temporaneo | qualsiasi | per la memorizzazione temporanea |
