# Risorse

Ecco alcune risorse utili per conoscere meglio SQLite e migliorare le tue competenze:

- La [documentazione ufficiale di SQLite][sqlite-docs] offre guide complete, tutorial e riferimenti per SQLite.

- [SQLite Command-Line Shell][sqlite-shell]: documentazione della shell a riga di comando di SQLite, che ti permette di interagire con i database SQLite usando comandi SQL.

- [SQLite FAQ][sqlite-faq]: domande frequenti su SQLite, che coprono argomenti che vanno dall'installazione alla risoluzione dei problemi.

- [SQLite Forum][sqlite-forum]: il forum di SQLite serve a fare domande, segnalare bug, proporre miglioramenti, chiedere istruzioni e discutere software legato a SQLite.

- [SQLite Browser][sqlite-browser]: uno strumento visuale per creare, progettare e gestire database SQLite, che ti permette di consultare e modificare i file di database SQLite.

Esplora queste risorse per approfondire la tua conoscenza di SQLite e migliorare la tua padronanza di questo potente sistema di gestione di database.

[sqlite-shell]: https://www.sqlite.org/cli.html
