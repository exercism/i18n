# Istruzioni

Il club di poesia locale sta iniziando una nuova stagione. I poeti si uniscono al club e, ogni volta che due di loro scrivono una poesia insieme, entrano a far parte dello stesso *circolo di scrittura*. Il club vuole tenere traccia di chi condivide un circolo con chi, e ti è stato chiesto di scrivere le parole che lo gestiscono.

Un insieme disgiunto è la scelta perfetta: ogni poeta è un atomo, e un circolo di scrittura è un gruppo.

## 1. Apri il club

Definisci `new-club`, che prende una sequenza di poeti e restituisce un nuovo insieme disgiunto con ogni poeta registrato. Ogni poeta parte in un circolo di scrittura tutto suo.

```factor
{ "Keats" "Byron" "Dickinson" } new-club
! => a disjoint set holding the three poets
```

## 2. Registra una collaborazione

Definisci `collaborate`, che prende due poeti e un club. Unisce i circoli di scrittura dei due poeti e restituisce il club, così le collaborazioni si possono registrare una dopo l'altra.

```factor
{ "Keats" "Byron" "Dickinson" } new-club
"Keats" "Byron" rot collaborate
! => the club, with Keats and Byron now in one circle
```

## 3. Trova il circolo di un poeta

Definisci `circle-of`, che prende un poeta e un club e restituisce il rappresentante del circolo di scrittura di quel poeta. Due poeti che condividono un circolo riportano sempre lo stesso rappresentante.

```factor
{ "Keats" "Byron" "Dickinson" } new-club
"Dickinson" swap circle-of
! => "Dickinson"   (still in a circle of their own)
```

## 4. Condividono un circolo?

Definisci `same-circle?`, che prende due poeti e un club e restituisce `t` quando entrambi i poeti appartengono allo stesso circolo di scrittura e `f` altrimenti. Confronta i rappresentanti dei poeti invece di usare un test di equivalenza integrato.

```factor
{ "Keats" "Byron" "Dickinson" } new-club
"Keats" "Byron" rot collaborate
dup [ "Keats" "Byron" ] dip same-circle? .      ! => t
    [ "Keats" "Dickinson" ] dip same-circle? .  ! => f
```
