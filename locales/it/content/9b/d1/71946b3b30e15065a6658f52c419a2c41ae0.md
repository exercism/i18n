## Conosciamo «Hello, World!»

«Hello, World!» è probabilmente il programma più famoso al mondo.
Praticamente chiunque abbia imparato a programmare l'ha scritto almeno una volta.
La sua semplicità e il messaggio amichevole spesso rappresentano il primo passo nel meraviglioso mondo della programmazione.

Su Exercism ti viene fornita una funzione di nome `hello` che restituisce «Goodbye, Mars!».

```python
def hello():
    return 'Goodbye, Mars!'
```

Il tuo compito è modificarla perché restituisca invece «Hello, World!».

## L'approccio tradizionale

Per prima cosa abbiamo l'approccio più semplice, quello che Exercism spera che tu implementi.
Con un semplice cambio della stringa da «Goodbye, Mars!» a «Hello, World!», ora possiamo restituirla senza problemi!

```python
def hello() -> str:
    return 'Hello, World'
```

## Approcci alternativi

Risolverò questo esercizio usando tutti i metodi diversi che mi sono venuti in mente.

Per ragioni narrative, chiamerò questa semplice funzione «la macchina», una macchina il cui unico compito è restituire un saluto «Hello, World!».

Vediamo dove ci porta...!

### Il join

La macchina conosce già alcune delle parole, ma sembra non riuscire a... ah, ehm... metterle insieme.

```python
def hello() -> str:

    return ",".join(words)
```

### Il curry

Oh oh, alcune parti della macchina sono in manutenzione.
Ha dimenticato il messaggio di saluto e ora può accettarlo solo una parte alla volta.

```python

    def world(location: str) -> str:
        return f"{greet}, {location}!"
    return world
```

### La permutazione

È passato un forte temporale e la tua povera sfortunata macchina è stata colpita da un fulmine.
Si accende ancora, ma ora si comporta in modo strano.
Tutti i caratteri per comporre il messaggio di saluto ci sono ancora, ma non sono in ordine, e i danni alla scheda logica fanno sì che la macchina non riesca più a metterli nell'ordine giusto per il messaggio.
E, naturalmente, la macchinetta incredibilmente affidabile e *indistruttibile* che avevi costruito prima si è rivelata in realtà rubabile (sì, è sparita!).
Quindi decidi di lasciare che il tuo buon vecchio amico provi in tutti i modi possibili a rimescolare queste lettere fino a ottenere il messaggio corretto.
Dopotutto sono solo 13 caratteri e la macchina ha molta memoria. Dovrebbe essere veloce...

```python
from itertools import permutations

def hello() -> str:
    chars = ['H', 'e', 'l', 'l', 'o', ',', ' ', 'W', 'o', 'r', 'l', 'd', '!']

    all_permutations = permutations(chars)
    for perm in all_permutations:
        if ("".join(perm) == "Hello, World!"):
            return ''.join(perm)
```

### La ricerca

Hai deciso di aggiornare la macchina per permetterle di salutare in lingue diverse.
Ma il suo UNICO compito è dire «Hello, World!» in inglese, così, nella sua confusione, decide di scaricare un fantastiliardo di modi di dire «Hello, World!», ognuno con caratteri maiuscoli e posizioni leggermente diversi.
Questo ti ha lasciato confuso, senza sapere quale scegliere, ma almeno sono tutti in un certo ordine.
Devi dire alla macchina la formulazione corretta, così può trovare la frase e tornare normale (forse).

```python
        mid_val = combinations[mid]

        if mid_val == my_fav_phrase:
            return combinations[mid]

hello("Hello, World!")
```

### La classe

Decidi di sperimentare e modificare la macchina perché si comporti diversamente a seconda del pulsante premuto.
Avevi pensato di renderla un po' più informale, facendole dire «Hi», ma, essendo una persona *con classe*, decidi di usare sempre e solo il metodo `hello` e di coprire l'altro con del nastro adesivo.
Ti rendi conto di avere parecchio tempo da perdere per queste cose...

### La ricorsione

Per qualche motivo, hai deciso che sarebbe stato divertente se la macchina rallentasse un po' e rispondesse solo con 10 secondi di ritardo. Tuo fratello solleva ancora una volta la questione della logica dietro questa funzionalità, perché secondo lui sei l'unico a usare la macchina.

```python
import time

def hello(n=10):
    if n == 0:
        return "Hello, World!"
    else:
        time.sleep(1)
        return hello(n-1)
```

### La casualità

All'improvviso, un giorno ti stanchi di sentire sempre lo stesso saluto, così decidi di lasciarti salutare un'ultima volta e di mandare in pensione la macchina per sempre, senza toccarla mai più.
Poiché la macchina ti è stata accanto nella buona e nella cattiva sorte per molto tempo, decidi di lasciare questo ultimo incontro tra «amici» nelle mani del destino.
La accendi un'ultima volta e la lasci girare...

```python
import random

def hello():
    chars = list("Helo,Wrld!")
    greeting = ""
    while (greeting != "Hello, World!"):
        greeting = "".join(random.choices(chars, k=13))
    return greeting
```
