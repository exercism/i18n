# Mutabilità

Cairo, con il suo design orientato alla blockchain, implementa di default un modello di memoria immutabile.
Questo significa che, una volta scritto un valore in memoria, questo non può essere sovrascritto, ma solo letto.
Tuttavia, Cairo offre un meccanismo per creare variabili mutabili usando la parola chiave `mut`.
Quando una variabile è dichiarata mutabile e il suo valore viene modificato, il nuovo valore viene scritto in una nuova cella di memoria e la variabile viene aggiornata per puntare alla nuova cella.
Questo meccanismo garantisce flessibilità senza rinunciare ai vantaggi dell'immutabilità.

Nell'esempio qui sotto, `x` è dichiarata come variabile immutabile.
Se il valore di `x` viene modificato, il compilatore genererà un errore.

```rust
let x = 5;
x = 2; // Error: cannot assign twice to immutable variable
```

Possiamo dichiarare `x` come variabile mutabile usando la parola chiave `mut`.
Questo permette di modificare il valore di `x` dopo che è stata dichiarata.

```rust
let mut x = 5;
x = 10;
```

Alla fine, decidere se usare o meno la mutabilità sta a te e dipende da ciò che ritieni più chiaro in quella particolare situazione.

## Costanti

Come le variabili immutabili, le costanti sono valori legati a un nome che non possono cambiare, ma ci sono alcune differenze tra costanti e variabili:

- Le costanti si dichiarano usando la parola chiave `const`
- Non puoi usare `mut` con le costanti
- Il tipo del valore deve essere sempre specificato esplicitamente
- Le costanti si possono dichiarare solo nello scope globale
- Le costanti possono essere impostate solo su espressioni costanti, non sul risultato di un valore calcolato a runtime

```rust
struct AnyStruct {
    a: u256,
    b: u32
}

enum AnyEnum {
    A: felt252,
    B: (usize, u256)
}

const ONE_HOUR_IN_SECONDS: u32 = 3600;
const STRUCT_INSTANCE: AnyStruct = AnyStruct { a: 0, b: 1 };
const ENUM_INSTANCE: AnyEnum = AnyEnum::A('any enum');
const BOOL_FIXED_SIZE_ARRAY: [bool; 2] = [true, false];
```

È possibile usare la macro `consteval_int!` per creare una variabile `const` che è il risultato di un calcolo.

```rust
const ONE_HOUR_IN_SECONDS: u32 = consteval_int!(60 * 60);
```

## Shadowing

È possibile, e spesso idiomatico, riutilizzare il nome di una variabile man mano che un particolare valore viene trasformato, ridichiarandola più volte con `let`.
Questo è noto come _shadowing_.
Di fatto, la seconda variabile oscura la prima e si prende tutti gli usi del nome della variabile finché non viene a sua volta oscurata o finché lo scope non termina.

```rust
fn main() {
    let s: ByteArray = "my string";
    let s: ByteArray = s + " and a shadow";
    {
        let s: ByteArray = "a nested shadow";
        println!(s); // emits "a nested shadow"
    }
    println!(s); // emits "my string and a shadow"
}
```

Grazie allo shadowing, possiamo perfino cambiare il tipo della variabile riutilizzando lo stesso nome.

```rust
fn main() {
    let x: u64 = 2;
    println!("x is u64, value: {}", x);               // prints "x is u64, value: 2"
    let x: ByteArray = format!("fizz");               // converts x to a ByteArray, type annotation is required
    println!("x is now ByteArray, value: \"{}\"", x); // prints 'x is now ByteArray, value: "fizz"'
}
```
