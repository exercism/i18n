# Informazioni

Uno degli aspetti chiave quando si lavora con i numeri in C# è la distinzione tra i numeri interi (numeri senza cifre dopo il separatore decimale) e i numeri in virgola mobile (numeri con zero o più cifre dopo il separatore decimale).

I due tipi numerici più usati in C# sono `int` (un intero a 32 bit) e `double` (un numero in virgola mobile a 64 bit).

```csharp
int i = 123;
double d = 54.29;
```

Sia i numeri interi che quelli in virgola mobile possono usare il carattere `_` come _separatore di cifre_, cosa che può essere utile quando si definiscono numeri grandi:

```csharp
int largeInt = 1_000_000;
// => 1000000

double largeDouble = 9_876_543.21;
// => 9876543.21
```

L'aritmetica si basa sui normali [operatori aritmetici][arithmetic-operators] (`+`, `-`, `*`, ecc.). I numeri si possono confrontare usando i normali [operatori di confronto][comparison-operators] (`<`, `>=`, ecc.), l'operatore di [uguaglianza][equality-operators] (`==`) e l'operatore di [disuguaglianza][equality-operators] (`!=`).

```csharp
5 * 6;
// => 30

1.2 > 0.8
// => true

2 != 4
// => true
```

Quando si converte tra tipi numerici, esistono due tipi di conversioni numeriche:

1. Conversioni implicite: nessun dato viene perso e non serve sintassi aggiuntiva.
2. Conversioni esplicite: i dati potrebbero andare persi e serve sintassi aggiuntiva sotto forma di un _cast_.

Poiché un `int` ha meno precisione di un `double`, convertire da `int` a `double` è sicuro ed è quindi una conversione implicita. Invece, convertire da `double` a `int` potrebbe comportare la perdita di dati, quindi richiede una conversione esplicita.

```csharp
int i = 9;
double d = 2.66;

// Safe conversion, thus implicit conversion
double fromInt = i;

// Potentially unsafe conversion, thus explicit conversion
int fromDouble = (int)d;
```
