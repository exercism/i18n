# Le istruzioni case

```sather
   case zone
   when 0 then return 0;
   when 1, 2 then return 550;
   else return 920;
   end;
```

## Come avviene il confronto

Il valore dopo `case` viene confrontato con ogni valore `when` usando `=`, dall'alto verso il basso. Viene eseguita la prima corrispondenza, e solo quella. Le parti `when` rimanenti vengono saltate e l'esecuzione prosegue dopo `end`.

Si può usare qualsiasi tipo che supporti `=`: `INT`, `CHAR`, `STR`, `BOOL`.

## Il ramo else

Un `case` senza corrispondenza e senza `else` genera un errore fatale in fase di esecuzione. Scrivilo sempre. Quando i casi rimanenti non dovrebbero davvero verificarsi, dillo lì invece di ometterlo:

```sather
   else
      raise "unknown zone: " + zone;
   end;
```

`raise` arriverà più avanti; fino ad allora, restituire un valore predefinito sensato va bene.

## Quando preferire if

`case` confronta un valore con delle costanti. Qualsiasi altra cosa richiede `if`:

```sather
   -- ranges
   if age < 13 then ... elsif age < 16 then ... end;

   -- more than one value at a time
   if score >= 8 and sings then ... end;
```

Cercare di forzare un intervallo dentro un `case` produce qualcosa di più lungo e peggiore dell'`if` che sostituisce.

## Case come espressione

`case` è un'istruzione, non un'espressione, quindi questo non è Sather:

```sather
   -- wrong
   fare := case zone when 1 then 550 else 920 end;
```

Restituisci un valore dall'interno di ogni ramo, oppure assegnalo a una variabile all'interno di ogni ramo.
