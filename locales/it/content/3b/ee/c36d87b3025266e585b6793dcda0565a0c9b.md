# Istruzioni

Come aspirante maga, Elyse deve esercitarsi con le basi.

Ha una pila di carte che vuole manipolare.

Per rendere le cose un po' più semplici, usa solo le carte dall'1 al 10.

La pila di carte è rappresentata da un `Array`, con il fondo della pila all'inizio dell'array e la cima della pila alla fine.

## 1. Inserire una carta in cima alla pila

Implementa la funzione `insert_top` che restituisce una copia della pila con la nuova carta fornita aggiunta in cima alla pila.

```rust
let stack = array![5, 9, 7, 1];
insert_top(stack, 8);
// -> [5, 9, 7, 1, 8]
```

## 2. Rimuovere la carta in cima alla pila

Implementa la funzione `remove_top_card` che restituisce una copia della pila a cui è stata rimossa la carta in cima.

Se la pila fornita è vuota, va restituita la pila originale, invariata.

```rust
let stack = array![3, 2, 6, 4, 8];
remove_top_card(stack);
// -> [3, 2, 6, 4]
```

## 3. Inserire una carta in fondo alla pila

Implementa la funzione `insert_bottom` che restituisce una copia della pila con la nuova carta fornita aggiunta in fondo alla pila.

```rust
let stack = array![5, 9, 7, 1];
insert_bottom(stack, 8);
// -> [8, 5, 9, 7, 1]
```

## 4. Rimuovere una carta dal fondo della pila

Implementa la funzione `remove_bottom_card` che restituisce una copia della pila a cui è stata rimossa la carta in fondo.

Se la pila fornita è vuota, va restituita la pila originale, invariata.

```rust
let stack = array![8, 5, 9, 7, 1];
remove_bottom_card(stack);
// -> [5, 9, 7, 1]
```

## 5. Controllare la dimensione della pila

Implementa la funzione `check_size_of_stack` che controlla se la dimensione della pila è uguale a un dato `stack_size` oppure no.

```rust
let stack = array![3, 2, 6, 4, 8];
check_size_of_stack(stack, 4);
// -> false
```
