# Suggerimenti

## 1. Creare una nuova lista

- Per sapere come definire una lista vuota, dai un'occhiata a [questa pagina][create-and-initialize].

## 2. Definire una lista esistente

- Per sapere come definire e inizializzare una lista con più elementi, dai un'occhiata a [questa pagina][create-and-initialize].

## 3. Aggiungere una nuova lingua a una lista

- Esiste un [operatore integrato][cons] per aggiungere un elemento all'inizio di una lista.

## 4. Contare le lingue nella lista

- C'è una funzione nel modulo `List` per [contare gli elementi di una lista][length].

## 5. Invertire la lista

- C'è una funzione nel modulo `List` per [invertire una lista][reverse].

## 6. Verificare se la lista è entusiasmante

- Puoi usare il pattern matching con i pattern [cons][cons-pattern] e [list][list-pattern] per riconoscere strutture di lista specifiche.
