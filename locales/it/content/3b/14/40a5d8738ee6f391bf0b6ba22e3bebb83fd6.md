# Introduzione

L'oggetto [`Promise`][promise-docs] rappresenta il completamento (o il fallimento) futuro di un'operazione asincrona e il valore che ne risulta.

## Ciclo di vita di una promise

Una `Promise` ha tre stati:

1. pending
2. fulfilled
3. rejected

Quando viene creata, una promise è pending.
Ad un certo punto nel futuro può essere _risolta_ o _rifiutata_.
Una volta che una promise è stata risolta o rifiutata, non può più essere risolta né rifiutata di nuovo, e il suo stato non può cambiare.

In altre parole:

1. Quando è pending, una promise:
   - può passare allo stato fulfilled o a quello rejected.
2. Quando è fulfilled, una promise:
   - non deve passare a nessun altro stato.
   - deve avere un valore, che non deve cambiare.
3. Quando è rejected, una promise:
   - non deve passare a nessun altro stato.
   - deve avere un motivo, che non deve cambiare.

## Concatenazione delle promise

In JavaScript ci sono vari metodi per concatenare le promise.
Chiamare un metodo di concatenazione su una promise restituisce un'altra promise.
