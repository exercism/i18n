# Introduzione

## Stringhe

Ricorda che `jq` supporta gli stessi tipi di dati di JSON.
JSON descrive le **stringhe** come:

> Una stringa è una sequenza di zero o più caratteri Unicode, racchiusa tra virgolette doppie, che usa sequenze di escape con la barra rovesciata.

### Sequenze di escape

All'interno di una stringa, usa il carattere barra rovesciata per incorporare i caratteri «speciali»:

- `\"` una virgoletta letterale,
- `\\` una barra rovesciata letterale,
- caratteri di spaziatura `\n`, `\t`, `\r`, `\f`, `\b`
- caratteri unicode `\uAAAA` dove `A` è una cifra esadecimale

### Lunghezza di una stringa

Per trovare il numero di caratteri, usa la funzione `length`.

```sh
$ jq -cn --args  '$ARGS.positional[] | length' "Hello world!" "❄🌡🤧🤒🏥🕰😀"
12
7
```

### Sottostringhe

La notazione **slice** può essere usata per estrarre sottostringhe.
La sintassi è `.[i:j]`.
La sottostringa restituita ha lunghezza `j - i` e restituisce i caratteri dall'indice `i` (incluso) all'indice `j` (escluso).
Entrambi gli indici possono essere negativi, nel qual caso si contano a ritroso dalla fine della stringa.
Entrambi gli indici possono anche essere omessi, nel qual caso si riferiscono all'inizio o alla fine della stringa.
Gli indici partono da zero.

```jq
"abcdefghij"[3:6]   # => "def"
"abcdefghij"[3:]    # => "defghij"
"abcdefghij"[:-2]   # => "abcdefgh"
```

### Concatenazione

Usa `+` per unire le stringhe:

```jq
"Hello" + " " + "world!"
# => "Hello world!"
```

Usa `add` quando hai un array di stringhe:

```jq
["Hello", " ", "world!"] | add
# => "Hello world!"
```

### Dividere e unire

Per dividere si usa la funzione `split/1` o l'operatore `/`:

```jq
"Hello beautiful world!" | split(" ")   # => ["Hello", "beautiful", "world!"]
```

```jq
"Hello beautiful world!" / " "          # => ["Hello", "beautiful", "world!"]
```

L'inverso di `split/1` è `join/1`.

Spesso è necessario convertire una stringa in un array di caratteri.
Ci sono due modi per farlo:

1. dividere su una stringa vuota

   ```jq
   "Hi friend 😀" / ""   # => ["H","i"," ","f","r","i","e","n","d"," ","😀"]
   ```

1. `explode` in un array di _punti di codice_

   ```jq
   "Hi friend 😀" | explode   # => [72,105,32,102,114,105,101,110,100,32,128512]
   ```

   `implode` è l'inverso di `explode`.

### Trovare l'indice di una sottostringa

Usa la funzione `index/1`; l'indice parte da zero.

```jq
"hello" | index("el")'   # => 1
```

Se la sottostringa non è presente nella stringa, il risultato è `null`

```jq
"hello" | index("elk")   # => null
```

### Interpolazione di stringhe

All'interno di una stringa, la sequenza `\(expression)` incorpora il _risultato_ di quell'espressione [nella stringa][interpolate]:

```jq
"The current datetime is \(now | strflocaltime("%c"))"   # => "The current datetime is Wed Nov 16 17:06:33 2022"
```

### Conversione di maiuscole e minuscole

Usa le funzioni `ascii_downcase` e `ascii_upcase`.

### Espressioni regolari

`jq` ha un ricco supporto per le espressioni regolari: sarà l'argomento di una lezione successiva.

[interpolate]: https://jqlang.org/manual/#string-interpolation
