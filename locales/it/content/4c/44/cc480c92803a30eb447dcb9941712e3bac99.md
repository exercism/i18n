# Installazione

La distribuzione Racket può essere scaricata da https://download.racket-lang.org

Sono disponibili degli installer per

* Windows
* Linux
* macOS

Consulta la pagina [Getting Started](http://docs.racket-lang.org/getting-started/) di Racket per i materiali introduttivi.

La [Racket Guide](https://docs.racket-lang.org/guide/intro.html) ti introduce all'interazione con Racket.

Consulta [DrRacket: The Racket Programming Environment](https://docs.racket-lang.org/drracket/index.html) per una guida all'uso dell'IDE DrRacket.

Consulta [Command-Line Tools and Your Editor of Choice](https://docs.racket-lang.org/guide/other-editors.html) per un'introduzione agli strumenti a riga di comando di Racket e all'uso di altri editor.


## Informazioni sull'installer per Linux:
La build per Linux è abbastanza generica da funzionare sulla maggior parte delle distribuzioni, comprese quelle relativamente vecchie.

Dopo aver scaricato il file di installazione, eseguilo con
```
sh racket-8.10-x86_64-linux-cs.sh
```

Potresti dover anteporre `sudo` all'inizio del comando per installare in una posizione che richiede privilegi di amministratore.

**Attenzione: Racket potrebbe essere disponibile anche tramite il gestore di pacchetti della tua distribuzione, ma potrebbe essere più vecchio dell'ultima versione di Racket.**
Anche se potresti scegliere di farlo più avanti, come principiante avrai un'esperienza molto migliore se ti attieni alla versione attuale disponibile su https://download.racket-lang.org


## Informazioni sull'installer per macOS:

Se la tua macchina usa processori della serie M1 o M2, seleziona **Apple Silicon** nel menu a tendina della piattaforma prima di scaricare.
