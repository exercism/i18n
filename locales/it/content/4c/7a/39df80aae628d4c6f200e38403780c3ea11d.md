# Istruzioni

Hai appena iniziato a lavorare alla reception di una palestra di arrampicata.
I soci acquistano abbonamenti per un certo numero di mesi e registrano l'ingresso e l'uscita ogni volta che vengono.
Il responsabile ti ha chiesto di scrivere una funzione ausiliaria che risponda alle domande che i soci fanno più spesso.

## 1. Calcolare quando termina un abbonamento

Un abbonamento che inizia in una certa data termina nello stesso giorno del mese, il numero di mesi indicato più tardi.
Quando quel giorno non esiste nel mese di fine, l'abbonamento termina invece l'ultimo giorno di quel mese.

Implementa il metodo `FrontDesk.membershipEnd()` che riceve la data di inizio di un abbonamento e il suo numero di mesi e restituisce la data in cui termina:

```java
FrontDesk frontDesk = new FrontDesk();
frontDesk.membershipEnd(LocalDate.of(2024, 3, 10), 1);
// => LocalDate.of(2024, 4, 10)
frontDesk.membershipEnd(LocalDate.of(2025, 1, 31), 1);
// => LocalDate.of(2025, 2, 28)
```

## 2. Mostrare quanto dura un abbonamento

Sulla tessera dell'abbonamento, la palestra stampa quanto dura l'abbonamento in anni, mesi e giorni.

Implementa il metodo `FrontDesk.membershipLength()` che riceve la data di inizio e la data di fine di un abbonamento e restituisce la durata dell'abbonamento come `Period`:

```java
FrontDesk frontDesk = new FrontDesk();
frontDesk.membershipLength(LocalDate.of(2023, 3, 10), LocalDate.of(2024, 5, 25));
// => Period.of(1, 2, 15)
```

## 3. Contare i giorni che restano a un abbonamento

I soci chiedono spesso quanti giorni restano loro prima che l'abbonamento scada.

Implementa il metodo `FrontDesk.daysLeft()` che riceve la data di oggi e la data di fine di un abbonamento e restituisce il numero totale di giorni da oggi fino alla data di fine.
Quando la data di fine è oggi o è già passata, non restano giorni, quindi il metodo restituisce `0`:

```java
FrontDesk frontDesk = new FrontDesk();
frontDesk.daysLeft(LocalDate.of(2024, 1, 15), LocalDate.of(2024, 3, 20));
// => 65
frontDesk.daysLeft(LocalDate.of(2024, 4, 2), LocalDate.of(2024, 3, 20));
// => 0
```

## 4. Misurare una visita

La palestra è aperta giorno e notte, e il tornello registra la data e l'ora in cui un socio entra ed esce.

Implementa il metodo `FrontDesk.visitDuration()` che riceve la data e l'ora di ingresso e di uscita di una visita e restituisce quanto è durata la visita come `Duration`:

```java
FrontDesk frontDesk = new FrontDesk();
frontDesk.visitDuration(LocalDateTime.of(2024, 3, 10, 23, 30), LocalDateTime.of(2024, 3, 11, 1, 15));
// => Duration.ofMinutes(105)
```

## 5. Stampare una visita sullo scontrino

Lo scontrino mostra la durata di una visita in ore e minuti, come `1h 35m`.
I minuti sono sempre scritti con due cifre, gli eventuali secondi vengono omessi e le ore non sono limitate a un solo giorno.

Implementa il metodo `FrontDesk.formatVisit()` che riceve la durata di una visita e la restituisce in questo formato:

```java
FrontDesk frontDesk = new FrontDesk();
frontDesk.formatVisit(Duration.ofMinutes(95));
// => "1h 35m"
frontDesk.formatVisit(Duration.ofHours(2).plusMinutes(5));
// => "2h 05m"
frontDesk.formatVisit(Duration.ofHours(26).plusMinutes(10));
// => "26h 10m"
```
