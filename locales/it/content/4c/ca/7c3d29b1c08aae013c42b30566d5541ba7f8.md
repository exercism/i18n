# Informazioni

I [cons][hyper-conses] sono un tipo di dato di base in Common Lisp. Sono composti da una testa e da una coda (chiamate, per [ragioni storiche][history], `car` e `cdr`).
Non c'è alcuna restrizione sui tipi di dato della testa e della coda di un cons.

I cons si creano con la funzione [`cons`][hyper-cons], che prende due oggetti e restituisce un cons (a volte chiamato anche «cella cons»).

Si può accedere alle parti di un cons con le funzioni [`car`][hyper-car] e [`cdr`][hyper-cdr].

## Riferimento

```lisp
;; Testing for atoms
(atom 'foo)              ; => T
(atom '(bar baz))        ; => NIL

;; Testing for cons
(consp 'foo)             ; => NIL
(consp '(bar baz))       ; => T

;; First item of a cons
(car '(one two three))   ; => ONE
(first '(one two three)) ; => ONE

;; Rest of a cons
(cdr '(one two three))   ; => (TWO THREE)
(rest '(one two three))  ; => (TWO THREE)
```
