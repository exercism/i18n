# Istruzioni specifiche per SQLite

- La colonna **matrix** contiene l'input, un array di array di interi codificato in JSON.
- Le colonne **result** devono contenere l'output, cioè l'elenco dei punti di sella.
  L'output deve essere un array di oggetti codificato in JSON, dove ogni oggetto ha due chiavi: row e column.
  Ad esempio, `[{"row": 2, "column": 1}]`.
