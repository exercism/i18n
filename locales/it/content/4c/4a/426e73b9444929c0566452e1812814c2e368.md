# Non usare istruzioni if annidate

Prova a riscrivere le istruzioni if per evitare un annidamento profondo: può portare a codice più difficile da seguire. Considera i due frammenti di codice seguenti:

```csharp
void PrintName(Person p)
{
    if (p != null)
    {
        if (p.Name != null)
        {
            if (p.Age >= 21)
            {
                Console.WriteLine(p.Name);
            }
        }
    }
}
```

Confrontalo con il codice seguente:

```csharp
void PrintName(Person p)
{
  if (p == null || p.Name == null || p.Age < 21)
  {
      return;
  }

  Console.WriteLine(p.Name);
}
```

Il secondo esempio ha una struttura molto precisa: tutti i percorsi che gestiscono gli errori vengono trattati in blocchi indentati, mentre il «happy path» è sempre allineato più a sinistra. Così il codice si legge con molta facilità: si vede subito qual è il percorso più comune e senza errori all'interno del codice.
