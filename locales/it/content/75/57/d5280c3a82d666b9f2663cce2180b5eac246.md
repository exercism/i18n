# Introduzione

Un `Option` è un enum che serve a verificare la validità dei valori restituiti da una funzione. È definito così:

```haxe
enum Option<T> {
  Some(v:T);
  None;
}
```

Fa parte del pacchetto `haxe.ds`:

```haxe
import haxe.ds.Option;

class Main {
  static public function main() {
    var result = trySomething();

    switch (result) {
      case None:
        trace("Nothing");
      case Some(s):
        trace("Got: " + s);
    }
  }

  static public function trySomething():Option<String> {
    if (Math.random() > 0.5) {
      return None;
    } else {
      return Some("Success");
    }
  }
}
```
