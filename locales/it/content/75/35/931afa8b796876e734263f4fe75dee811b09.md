# Istruzioni

Dati due array qualsiasi `A` e `B`, stabilisci se:

- L'array `A` è uguale all'array `B`; oppure
- L'array `A` contiene l'array `B` (`A` è un sopraarray di `B`); oppure
- L'array `A` è contenuto nell'array `B` (`A` è un sottoarray di `B`); oppure
- Nessuna delle precedenti è vera, quindi gli array `A` e `B` sono diversi

Nello specifico, l'array `A` è uguale all'array `B` se entrambi gli array hanno gli stessi valori nello stesso ordine.
L'array `A` è un sopraarray di `B` se `A` contiene una sottosequenza di valori uguale a `B`.
L'array `A` è un sottoarray di `B` se `B` contiene una sottosequenza di valori uguale a `A`.

Esempi:

- Se `A = []` e `B = []` (entrambi gli array sono vuoti), allora `A` e `B` sono uguali
- Se `A = [1, 2, 3]` e `B = []`, allora `A` è un sopraarray di `B`
- Se `A = []` e `B = [1, 2, 3]`, allora `A` è un sottoarray di `B`
- Se `A = [1, 2, 3]` e `B = [1, 2, 3, 4, 5]`, allora `A` è un sottoarray di `B`
- Se `A = [3, 4, 5]` e `B = [1, 2, 3, 4, 5]`, allora `A` è un sottoarray di `B`
- Se `A = [3, 4]` e `B = [1, 2, 3, 4, 5]`, allora `A` è un sottoarray di `B`
- Se `A = [1, 2, 3]` e `B = [1, 2, 3]`, allora `A` e `B` sono uguali
- Se `A = [1, 2, 3, 4, 5]` e `B = [2, 3, 4]`, allora `A` è un sopraarray di `B`
- Se `A = [1, 2, 4]` e `B = [1, 2, 3, 4, 5]`, allora `A` e `B` sono diversi
- Se `A = [1, 2, 3]` e `B = [1, 3, 2]`, allora `A` e `B` sono diversi
