# Entry API

L'API entry è spesso il modo più idiomatico per manipolare il contenuto di una struttura di tipo mappa. Tuttavia, in modo insolito per Rust, non è stata formalizzata in un trait: è solo un insieme di tipi e metodi implementati sui tipi mappa della libreria standard.

Fondamentalmente, il metodo `map.entry()` fornisce un `enum`:

```rust
enum Entry {
    Occupied(_),
    Vacant(_),
}
```

L'utilità sta negli altri metodi implementati su quell'enum. Per esempio, se vuoi ottenere e potenzialmente modificare il valore di una determinata chiave, e il valore predefinito del tipo va bene, puoi semplicemente fare:

```rust
// `entry` has type `&mut Value` for the value type of the map
let entry = map.entry(key).or_default();
```

Per applicazioni come un contatore, questo semplifica molto la vita:

```rust
let counts: HashMap<_, usize> = HashMap::new();
for item in sequence {
    *counts.entry(item).or_default() += 1;
}
```

Se il valore predefinito del tipo non è adatto alla tua applicazione, puoi fornire un tuo valore predefinito costante con `or_insert`, oppure calcolarlo con `or_insert_with`.

In alcuni casi, potresti voler eseguire un calcolo su un valore esistente prima di eventuali inserimenti. In questi casi, `and_modify` lo permette. Tuttavia, questo utilizzo è piuttosto raro. `and_modify` si usa più comunemente per evitare la necessità di dereferenziare:

```rust
map.entry(key).and_modify(|v| *v += 1).or_default();
```

A volte è utile fare il match direttamente sull'entry. Questo è consentito:

```rust
match map.entry(key) {
    Entry::Occupied(occupied) => println!("removed from the map: {:?}", occupied.remove_entry()),
    Entry::Vacant(vacant) => println!("key not present in map: {:?}", vacant.key()),
}
```

Per maggiori informazioni, vedi [`std::collections::hash_map::Entry`](https://doc.rust-lang.org/std/collections/hash_map/enum.Entry.html) e [`std::collections::btree_map::Entry`](https://doc.rust-lang.org/std/collections/btree_map/enum.Entry.html).
