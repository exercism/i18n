# Istruzioni

Come quasi chiunque abbia un lavoro, Layla l'aliena Lisp a volte ha bisogno di preparare dei report per comunicare informazioni agli altri. Ti chiede se puoi aiutarla a formattare i dati che ha per questi report.

## 1. Formattare i valori trimestrali

La prima cosa di cui Layla ha bisogno è una funzione: `format-quarter-value` che prende due parametri: il trimestre di calendario e il valore, e li formatta per un report. Dovrebbe restituire una stringa.

```lisp
(format-quarter-value "last" 3.14) ; => "The value last quarter: 3.14"
(format-quarter-value "this" 0) ; => "The value this quarter: 0"
```

## 2. Il report dei due trimestri

Layla ti ringrazia per la funzione `format-quarter-value` e dice che sarà molto utile nella *prossima* funzione che serve.

Il prossimo report deve mostrare il trimestre e il valore di 2 trimestri stampati su due righe.

Inoltre l'output deve andare sullo stream fornito come primo argomento.

Per esempio: `(format-two-quarters t "last" 3.14 "this" 0)` produrrà quanto segue sullo standard output:

```

The value last quarter: 3.14
The value this quarter: 0

```

Nota le righe vuote che lo circondano.

## 3. Leggibile da umani e alieni Lisp

Layla si è dimenticata di dirti che agli alieni Lisp piace vedere i valori in un modo leggibile come dati Lisp. Quindi serve una nuova funzione che possa essere letta come dati Lisp (di nuovo sullo stream specificato):

```lisp
(format-two-quarters-for-reading nil "last" 3.14 "this" 0) ; =>

"(\"The value last quarter: 3.14\" \"The value this quarter: 0\")"
```
