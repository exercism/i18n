# Appendice alle istruzioni

## Parole

Implementa:

- `grep ( pattern flags files -- lines )`

`pattern` è la stringa da cercare, `flags` è un array di zero o più tra le
stringhe di flag `"-n"`, `"-l"`, `"-i"`, `"-v"` e `"-x"`, e `files` è un
array di uno o più nomi di file. Restituisci le righe corrispondenti (con gli
eventuali prefissi richiesti di nome del file e numero di riga) come array di
stringhe.

Quando è presente il flag `-l`, restituisci un array con i nomi dei file che
contengono almeno una corrispondenza.

## Leggere i file

Leggi le righe di un file con `file-lines`, passando una codifica:

```factor
USING: io.encodings.utf8 io.files ;

"iliad.txt" utf8 file-lines
! => { "Achilles sing, O Goddess! Peleus' son;" ... }
```

I tre file di prova (`iliad.txt`, `midsummer-night.txt` e
`paradise-lost.txt`) arrivano insieme all'esercizio nella directory di lavoro,
quindi basta leggerli per nome.
