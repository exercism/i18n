# Introduzione

Un metodo è una funzione con un argomento speciale, il _ricevitore_.
Il ricevitore compare nella propria lista di argomenti, tra la parola chiave `func` e il nome del metodo.

```go
func (receiver type) MethodName(parameters) (returnTypes) {

}
```

Puoi definire un metodo solo con un ricevitore il cui tipo è definito nello stesso pacchetto del metodo.

```go
type Person struct {
    Name string
}

func (p Person) Greetings() string {
	return fmt.Sprintf("Welcome %s!", p.Name)
}

s := Person{Name: "Bronson"}
fmt.Println(s.Greetings())
// Output: Welcome Bronson!
```

Esistono due tipi di ricevitore: i ricevitori di valore e i ricevitori di puntatore.

I metodi con un ricevitore di valore operano su una copia del valore che ricevono: qualsiasi modifica fatta al ricevitore all'interno del metodo non è visibile a chi lo chiama.

Puoi dichiarare metodi con ricevitori di puntatore per modificare il valore verso cui punta il ricevitore.
Per farlo, si antepone un `*` al nome del tipo: ad esempio, per il tipo `rect`, un ricevitore di puntatore si dichiara come `*rect`.
Anche queste modifiche sono visibili a chi chiama il metodo.

```go
type rect struct {
	width, height int
}
func (r *rect) squareIt() {
	r.height = r.width
}

r := rect{width: 10, height: 20}
fmt.Printf("Width: %d, Height: %d\n", r.width, r.height)
// Output: Width: 10, Height: 20

r.squareIt()
fmt.Printf("Width: %d, Height: %d\n", r.width, r.height)
// Output: Width: 10, Height: 10

```
