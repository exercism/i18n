# Istruzioni

Un anagramma è un riarrangiamento di lettere che forma una nuova parola.
Data una parola e un array di candidati, seleziona il sottoinsieme degli anagrammi della parola data.

Data la parola `"listen"` e un array di candidati come `"enlists" "google"
"inlets" "banana"`, il programma dovrebbe restituire un array che contiene
`"inlets"`.
