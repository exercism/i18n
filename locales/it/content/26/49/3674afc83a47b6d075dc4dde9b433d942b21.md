# Installazione

Questo track si affida ovunque a [Wren Console][wren-console] per fornire un runtime locale per Wren. Questo significa che diamo per scontato che ogni esecuzione di Wren sul tuo computer avverrà tramite [Wren Console][wren-console]. Per favore, non confonderlo con la <abbr title="Command Line Interface">CLI</abbr> ufficiale di Wren. In un mondo perfetto potresti usare quel runtime, ma al momento [ha](https://github.com/wren-lang/wren-cli/pull/74) [diversi](https://github.com/wren-lang/wren/pull/1006) [problemi](https://github.com/wren-lang/wren-cli/issues/108) [di varia natura](https://github.com/wren-lang/wren-cli/pull/105) che lo rendono una scelta tutt'altro che ottimale per imparare Wren con Exercism.

Wren Console è un fork di Wren CLI, risolve questi problemi e aggiunge funzionalità che rendono più fluida la tua esperienza di apprendimento. Non preoccuparti: le conoscenze e i concetti del linguaggio Wren che imparerai qui varranno ovunque tu voglia usare Wren in futuro.

## Panoramica dell'installazione

- Installa Git per il comando `git`
- Installa [Wren Console][wren-console] per il comando `wrenc`

### Installare Git

Ti servirà il binario `git` installato e disponibile nel tuo path. È così che Wren Package installa i pacchetti (come la suite di test che ti servirà per testare i tuoi esercizi, ecc.).

- **Windows**: il [download ufficiale di Git](https://git-scm.com/download/win) è un buon punto di partenza.
- **Linux**: il tuo gestore di pacchetti preferito dovrebbe fare al caso tuo.
- **Mac**: tutte le versioni recenti di Mac OS includono `git` già pronto all'uso.

Puoi verificare che Git sia installato con `git --version`:

```
$ git --version
git version 2.31.1
```

Non preoccuparti se la versione esatta non corrisponde: di solito non è poi così importante.


### Installare Wren Console

#### Windows

Con ogni probabilità vorrai [scaricare l'ultima release][releases] da GitHub. Dopodiché dovrai decomprimere l'archivio e copiare l'eseguibile `wrenc` nel tuo path.

È anche possibile [compilare dai sorgenti][build-from-source] usando Visual Studio.

#### Linux

Puoi [scaricare l'ultima release][releases] da GitHub oppure [compilare dai sorgenti][build-from-source].

```sh
wget -c https://github.com/joshgoebel/wren-console/releases/download/v0.3.1/wren-console-v0.3.1-linux.tar.gz
tar xzf wren-console-v0.3.1-linux.tar.gz
```

E assicurati che sia disponibile nel tuo `PATH`.

```sh
cp bin/wrenc /usr/local/bin/
```


#### Mac

L'installazione più semplice usa il tap e la formula [Homebrew][homebrew] di Exercism:

```
brew tap exercism/wren
brew install wren-console
```

In alternativa puoi [scaricare l'ultima release][releases] da GitHub e installarla manualmente come mostrato nelle istruzioni per Linux. Compilare dai sorgenti è comunque abbastanza semplice se hai familiarità con queste cose.

### Verificare l'installazione

Dopo che credi di aver installato correttamente il binario, è bene verificare che tutto funzioni.

1. Apri un _terminale_ (`Terminal`, `cmd`, `Powershell`, `bash`, ...)
2. Esegui `wrenc -v`

Dovresti vedere elencate sia la versione di `wrenc` sia quella di Wren:

```
wrenc v0.3.1 (wren v0.4.0)
```

**Nota**: è importante che tu apra una finestra di terminale _nuova_. Le finestre di terminale già aperte potrebbero non essere state aggiornate dopo il completamento dell'installazione. Questo significa che i terminali aperti non sanno che è stato installato un nuovo programma.

> _**Aiuto**_: `'wrenc' is not recognised`
>
> Probabilmente non hai messo `wrenc` nel tuo PATH... Su MacOS e Linux puoi modificare il tuo path aggiungendo quanto segue a `~/.bash_profile` oppure a `~/.zshrc`:
>
> ```bash
> export PATH=/path/to/your/wrenc/:$PATH
> ```
> **Non ho idea se tutto questo sia corretto.**
> Su Windows apri il menu Start e cerca "environment variables". Dovrai
> modificare la voce `PATH` e _aggiungere_ qui il percorso dei binari di `wrenc`.
> Di solito si trovano in `C:\Program Files\nodejs`. Se navighi fin qui con il
> tuo `File Explorer`, dovresti trovare `node.exe`, `npm.bat` e `npx.bat`.
>
> Chiudi tutti i terminali aperti e aprine uno nuovo.

## Requisiti degli esercizi

Segui [queste istruzioni][cli-walkthrough] per scaricare la CLI `exercism` per il tuo sistema operativo.

Una volta che la CLI è configurata, scarica il primo esercizio, `hello-world`:

```bash
$ exercism download --exercise=hello-world --track=wren
```

Ogni esercizio poi ha bisogno di alcuni pacchetti Wren per eseguire i test. Puoi installarli eseguendo questo comando nella directory dell'esercizio:

```bash
$ wrenc package.wren install
```
