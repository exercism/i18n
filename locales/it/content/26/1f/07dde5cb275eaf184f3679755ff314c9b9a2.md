# Informazioni

Le [espressioni `throw`][throw-expressions] sono un'alternativa alle istruzioni `throw` e in particolare possono accrescere la potenza dell'operatore ternario e di altre espressioni composte.

```csharp
string trimmed = str == null ? throw new ArgumentException() : str.Trim();
```

Se `str` è `null` nel codice qui sopra, viene lanciata un'eccezione.

[throw-expressions]: https://docs.microsoft.com/en-us/dotnet/csharp/language-reference/keywords/throw#the-throw-expression
