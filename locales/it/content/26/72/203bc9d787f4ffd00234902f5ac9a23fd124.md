# Informazioni

Un parametro di un metodo può essere reso opzionale assegnandogli un valore predefinito. Quando si chiama un metodo con parametri opzionali, chi chiama non è tenuto a passare un valore per essi. Se non viene passato alcun valore per un parametro opzionale, viene usato il suo valore predefinito.

I parametri opzionali devono trovarsi alla fine della lista dei parametri; non possono essere seguiti da parametri non opzionali.

```haxe
class Card {
  static function newYear(year = 2021):String {
    return "Happy " + year;
  }
}

Card.newYear(); // Happy 2020
Card.newYear(1990); // Happy 1990
```

Il parametro opzionale può essere impostato a `null` usando l'operatore `?` prima del nome della variabile:

```haxe
function newYear(?year:Int) {
  if (year != null)
    return "It's " + year;
  return "Year is null";
}

newYear(); // Year is null
```
