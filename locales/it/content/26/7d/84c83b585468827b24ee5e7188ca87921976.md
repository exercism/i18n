# Istruzioni

Un violino si accorda a orecchio rispetto a una nota di riferimento. Le corde sono molto distanti in altezza, e i numeri coinvolti non sono interi.

Tutti e cinque i compiti vanno nella classe `TUNING_THE_STRINGS`.

## 1. Un'ottava sopra

Una nota un'ottava più alta ha il doppio della frequenza.

```sather
TUNING_THE_STRINGS::octave_up(440.0d)
-- => 880.0d
```

## 2. Un'ottava sotto

Un'ottava più bassa è la metà.

```sather
TUNING_THE_STRINGS::octave_down(440.0d)
-- => 220.0d
```

## 3. A metà strada

Date due frequenze, restituisci quella esattamente a metà tra loro.

```sather
TUNING_THE_STRINGS::midpoint(440.0d, 442.0d)
-- => 441.0d
```

## 4. Quanto sono distanti?

Quando due note sono vicine ma non identiche, senti un battito una volta al secondo per ogni ciclo di differenza. Restituisci quanto sono distanti le frequenze. La risposta non è mai negativa, qualunque nota sia più alta.

```sather
TUNING_THE_STRINGS::beats_per_second(441.5d, 440.0d)
-- => 1.5d
```

## 5. Dividere la pratica

Dati un numero di minuti e un numero di musicisti, quanti minuti spettano a ciascuno? I minuti e i musicisti sono numeri interi, ma la risposta potrebbe non esserlo.

```sather
TUNING_THE_STRINGS::minutes_each(45, 2)
-- => 22.5d
```
