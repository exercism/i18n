# Istruzioni

Impara le basi delle tabelle interne di ABAP.

La tua classe ha una tabella interna chiamata `initial_data`. Ha tre colonne: `GROUP`, `NUMBER` e `DESCRIPTION`.

```abap
TYPES group TYPE c LENGTH 1.
TYPES: BEGIN OF initial_type,
         group       TYPE group,
         number      TYPE i,
         description TYPE string,
       END OF initial_type,
       initial_data TYPE STANDARD TABLE OF initial_type WITH EMPTY KEY.
```

## Passo 1

Il tuo primo compito è completare il metodo `fill_itab` ed inserire 6 record in questa tabella con i seguenti valori:

| GROUP | NUMBER | DESCRIPTION |
| --- | ----------- | ----------- |
| A | 10 | Group A-2 |
| B | 5 | Group B |
| A | 6 | Group A-1 |
| C | 22 | Group C-1 |
| A | 13 | Group A-3 |
| C | 500 | Group C-2 |

## Passo 2

Ora implementa il metodo `add_to_itab` per aggiungere un record alla fine della tabella interna con il seguente valore:

| GROUP | NUMBER | DESCRIPTION |
| --- | ----------- | ----------- |
| A | 19 | Group A-4 |

## Passo 3

Adesso ordina la tabella interna nel metodo `sort_itab` con la colonna `GROUP` in ordine alfabetico e la colonna `NUMBER` in ordine decrescente.

## Passo 4

Nel metodo `search_itab`, cerca nella tabella ordinata e restituisci l'indice del record che ha un valore di 6 nella colonna `NUMBER`.
