# Introduzione

Un dizionario (`dict`) in Python è una struttura dati che associa _chiavi_ [hashable][term-hashable] a _valori_ ed è noto in altri linguaggi di programmazione come [tabella hash][hashtable-wikipedia] ridimensionabile, hashmap o [array associativo][associative-array].
I dizionari sono l'unico [tipo di mappatura][mapping-types-dict] integrato di Python.


Le `keys` devono essere hashable e uniche all'interno del dizionario.
I tipi delle chiavi possono includere `number`s, `str`s o `tuple`s (di valori _immutabili_).
Non possono contenere strutture dati _mutabili_ come `list`s, `dict`s o `set`s.
A partire da Python 3.7, l'ordine delle chiavi di un `dict` è garantito essere quello in cui le voci vengono inserite.

Le `values` possono essere di qualsiasi tipo o struttura dati.
I valori possono anche annidarsi _arbitrariamente_, quindi possono includere liste di liste, sotto-dizionari e altre strutture dati personalizzate o composte.

Data una `key`, i dizionari possono recuperare un `value` in tempo costante (in media), _indipendentemente dal numero di voci_.
Rispetto alla ricerca di un valore all'interno di una `list` o di un `array` (_senza conoscere la posizione dell'`index`_), un `dict` usa molta più memoria, ma ha un recupero molto rapido.

I dizionari sono particolarmente utili in scenari in cui la collezione di elementi è grande e deve essere consultata e aggiornata di frequente.
