# Introduzione

Molti tipi di membri di struct e classi (i campi sono la principale eccezione) possono usare la sintassi dei membri con corpo di espressione. Definire un membro con un'espressione produce spesso codice più conciso e leggibile rispetto ai tradizionali blocchi/istruzioni.

I metodi e le proprietà di sola lettura sono tra i membri che si possono definire con un corpo di espressione.

```csharp
public int Times3(int input) => input * 3;

public int Interesting => 1729;
```
