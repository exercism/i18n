# I metodi dei dizionari in Python

La classe `dict` di Python mette a disposizione tanti [metodi][dict-methods] utili per lavorare con i dizionari.
Alcuni li abbiamo già incontrati nel concetto dedicato ai `dict`.
Qui ne vediamo altri, insieme ad alcune tecniche per iterare sui dizionari e modificarli.

## Usa `setdefault()` per un inserimento senza errori

Nel concetto sui dizionari abbiamo già visto che `.get(key, <default value>)` restituisce un `value` esistente, oppure il `default value` se una `key` non è presente nel dizionario, evitando così un `KeyError`.
Funziona bene quando preferisci evitare una gestione degli errori extra, ma non puoi dare per scontato che la `key` che cerchi sia presente.

Per un'operazione di inserimento altrettanto «sicura» (_senza KeyError_), esiste il metodo `.setdefault(key, <default value>)`.
`setdefault(key, <default value>)` restituisce il `value` se la `key` è presente nel dizionario.
Se la key **non** è presente, _inserisce_ la coppia (`key`, `default value`) e restituisce il `default value` da usare.

```python
>>> palette_I = {'Grassy Green': '#9bc400', 'Purple Mountains Majesty': '#8076a3', 'Misty Mountain Pink': '#f9c5bd'}

# Looking for the value associated with key "Rock Brown".
# The key does not exist, so it is added with the default value, and the value is returned.
>>> palette_I.setdefault('Rock Brown', '#694605')
'#694605'

# The (key, default value) pair has now been added to the dictionary.
>>> palette_I
{'Grassy Green': '#9bc400', 'Purple Mountains Majesty': '#8076a3', 'Misty Mountain Pink': '#f9c5bd', 'Rock Brown': '#694605'}
```

## Usa `fromkeys()` per popolare un dizionario da un iterabile

Per popolare rapidamente un dizionario con varie `keys` e valori predefiniti, il _metodo di classe_ [`fromkeys(iterable, <default value>)`][fromkeys] itera su un iterabile di `keys` e crea un nuovo `dict`.
Tutti i `values` vengono impostati al `default value` fornito:

```python
>>> new_dict = dict.fromkeys(['Grassy Green', 'Purple Mountains Majesty', 'Misty Mountain Pink'], 'fill in hex color here')

{'Grassy Green': 'fill in hex color here',
 'Purple Mountains Majesty': 'fill in hex color here',
 'Misty Mountain Pink': 'fill in hex color here'}
```

## Iterare sulle voci di un dizionario tramite le viste

I metodi `.keys()`, `.values()` e `.items()` restituiscono delle [_viste iterabili_][dict-views] di un dizionario.

Queste viste possono essere usate per scorrere facilmente le voci senza modificarle.
Le viste sono anche _dinamiche_: quando i dati sottostanti del dizionario cambiano, il `view object` associato riflette la modifica:

```python
>>> palette_I = {'Grassy Green': '#9bc400',
                 'Purple Mountains Majesty': '#8076a3',
                  'Misty Mountain Pink': '#f9c5bd'}

# Using .keys() returns a list of keys.
>>> palette_I.keys()
dict_keys(['Grassy Green', 'Purple Mountains Majesty', 'Misty Mountain Pink'])

# Using .values() returns a list of values.
>>> palette_I.values()
dict_values(['#9bc400', '#8076a3', '#f9c5bd'])

# Using .items() returns a list of (key, value) tuples.
>>> palette_I.items()
dict_items([('Grassy Green', '#9bc400'), ('Purple Mountains Majesty', '#8076a3'), ('Misty Mountain Pink', '#f9c5bd')])

# Views are dynamic.  Changing values in the dict changes all of the associated views.
>>> palette_I['Purple Mountains Majesty'] = (128, 118, 163)
>>> palette_I['Deep Red'] = '#932432'

>>> palette_I.values()
dict_values(['#9bc400', (128, 118, 163), '#f9c5bd', '#932432'])

>>> palette_I.keys()
dict_keys(['Grassy Green', 'Purple Mountains Majesty', 'Misty Mountain Pink', 'Deep Red'])

>>> palette_I.items()
dict_items([('Grassy Green', '#9bc400'), ('Purple Mountains Majesty', (128, 118, 163)), ('Misty Mountain Pink', '#f9c5bd'), ('Deep Red', '#932432')])
```

## Ancora su `.keys()`, `.values()` e `.items()`

In Python 3.7+, i `dict` conservano l'ordine in cui le voci vengono inserite, permettendo un'iterazione First-in, First-out (_`FIFO`_) quando usi `.keys()`, `.values()` o `.items()`.

In Python 3.8+, le viste sono anche _reversibili_.
Questo permette di iterare su keys, values o coppie (`key`, `value`) in ordine Last-in, First-out (`LIFO`) usando `reversed(<dict>.keys())`, `reversed(<dict>.values())` o `reversed(<dict>.items())`:

```python
>>> palette_II = {'Factory Stone Purple': '#7c677f', 'Green Treeline': '#478559', 'Purple baseline': '#161748'}

# Iterating in insertion order (First in, first out)
>>> for item in palette_II.items():
...     print(item)
...
('Factory Stone Purple', '#7c677f')
('Green Treeline', '#478559')
('Purple baseline', '#161748')


# Iterating in the reverse direction. (Last in, first out)
>>> for item in reversed(palette_II.items()):
...    print (item)
...
('Purple baseline', '#161748')
('Green Treeline', '#478559')
('Factory Stone Purple', '#7c677f')
```

## Ordinare un dizionario

I dizionari non hanno un metodo di ordinamento integrato.
Tuttavia, è possibile ordinare una _vista_ di un `dicts` usando la funzione integrata `sorted()` con `dict.items()`.
La vista ordinata può poi essere usata per creare un nuovo dizionario.
Come per l'iterazione, l'ordinamento predefinito avviene sulle `keys` del dizionario.

```python
# Default ordering for a dictionary is insertion order (First in, first out).
>>> color_palette = {'Grassy Green': '#9bc400', 
                    'Purple Mountains Majesty': '#8076a3', 
                    'Misty Mountain Pink': '#f9c5bd', 
                    'Factory Stone Purple': '#7c677f', 
                    'Green Treeline': '#478559', 
                    'Purple baseline': '#161748'}
 
 
# The default sort order for a dictionary uses the keys.
>>> sorted_palette = dict(sorted(color_palette.items()))
>>> sorted_palette
{'Factory Stone Purple': '#7c677f',
 'Grassy Green': '#9bc400',
 'Green Treeline': '#478559',
 'Misty Mountain Pink': '#f9c5bd',
 'Purple Mountains Majesty': '#8076a3',
 'Purple baseline': '#161748'}
```

## Combinare dizionari con `.update()`

`<dict_one>.update(<dict_two>)` può essere usato per _combinare_ due dizionari.
Questo metodo prende le coppie (`key`,`value`) di `<dict_two>` e le scrive in `<dict_one>`:

```python
>>> palette_I = {'Grassy Green': '#9bc400',
                 'Purple Mountains Majesty': '#8076a3',
                  'Misty Mountain Pink': '#f9c5bd'}
>>> palette_II = {'Factory Stone Purple': '#7c677f',
                  'Green Treeline': '#478559',
                  'Purple Baseline': '#161748'}

>>> palette_I.update(palette_II)

# Note that new items from palette_II are added.
>>> palette_I
{'Grassy Green': '#9bc400', 'Purple Mountains Majesty': '#8076a3', 'Misty Mountain Pink': '#f9c5bd', 'Factory Stone Purple': '#7c677f', 'Green Treeline': '#478559', 'Purple Baseline': '#161748'}
```

Dove le key dei due dizionari _si sovrappongono_, il `value` in `dict_one` viene _sovrascritto_ dal `value` corrispondente di `dict_two`:

```python
>>> palette_I =   {'Grassy Green': '#9bc400', 'Purple Mountains Majesty': '#8076a3', 'Misty Mountain Pink': '#f9c5bd', 
                   'Factory Stone Purple': '#7c677f', 'Green Treeline': '#478559', 'Purple baseline': '#161748'}
>>> palette_III = {'Grassy Green': (155, 196, 0), 'Purple Mountains Majesty': (128, 118, 163),
                   'Misty Mountain Pink': (249, 197, 189)}
>>> palette_I.update(palette_III)

# Overlapping values in palette_I are replaced with values from palette_III
>>> palette_I
{'Grassy Green': (155, 196, 0),
  'Purple Mountains Majesty': (128, 118, 163), 
  'Misty Mountain Pink': (249, 197, 189), 
  'Factory Stone Purple': '#7c677f', 
  'Green Treeline': '#478559', 'Purple baseline': '#161748'}
```

## Unire o aggiornare dizionari con gli operatori union (`|` e `|=`)

Python 3.9 introduce un modo diverso di unire i `dicts`: gli operatori `union`.
`dict_one | dict_two` crea un **nuovo dizionario**, formato dalle coppie (`key`, `value`) di `dict_one` e `dict_two`.
Quando i due dizionari condividono delle key, i valori di `dict_two` hanno la precedenza.

```python
>>> palette_I = {'Grassy Green': '#9bc400', 'Purple Mountains Majesty': '#8076a3', 'Misty Mountain Pink': '#f9c5bd'}
>>> palette_II = {'Factory Stone Purple': '#7c677f', 'Green Treeline': '#478559', 'Purple baseline': '#161748'}
>>> new_dict = palette_I | palette_II
>>> new_dict
...
{'Grassy Green': '#9bc400',
 'Purple Mountains Majesty': '#8076a3',
 'Misty Mountain Pink': '#f9c5bd',
 'Factory Stone Purple': '#7c677f',
 'Green Treeline': '#478559',
 'Purple baseline': '#161748'}
```

`dict_one |= other` si comporta in modo simile a `<dict_one>.update(<other>)`, ma in questo caso `other` può essere sia un `dicts` sia un iterabile di coppie (`key`, `value`):

```python
>>> palette_III = {'Grassy Green': (155, 196, 0),
                   'Purple Mountains Majesty': (128, 118, 163),
                   'Misty Mountain Pink': (249, 197, 189)}
>>> new_dict |= palette_III
>>> new_dict
...
{'Grassy Green': (155, 196, 0),
'Purple Mountains Majesty': (128, 118, 163),
'Misty Mountain Pink': (249, 197, 189),
'Factory Stone Purple': '#7c677f',
'Green Treeline': '#478559',
'Purple baseline': '#161748'}
```
