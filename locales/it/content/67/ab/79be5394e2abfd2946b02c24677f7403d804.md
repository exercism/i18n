# Informazioni

Elm è un linguaggio puramente funzionale, quindi non ci sono istruzioni, solo espressioni, e le funzioni sono sempre una singola espressione.

Questo favorisce funzioni piccole e semplici ed è generalmente una buona cosa, ma a volte le funzioni sono inevitabilmente più complesse e serve un modo per assicurarsi che possano essere scritte in modo elegante.

È qui che entrano in gioco le espressioni `let`. Hanno due parti: una sezione `let`, dove puoi creare tutte le definizioni che ti servono, e poi una sezione `in`, che è una singola espressione che può usare queste definizioni.

In termini informatici, `let` crea uno scope locale all'espressione in `in`.

L'espressione `let` è utile in alcune situazioni:

- Per semplificare le espressioni
- Per dare un nome ai risultati di espressioni intermedie
- Per spezzare un'espressione in parti più piccole se sta diventando grande

Puoi fare la maggior parte delle cose all'interno di un'espressione `let`, inclusa la destrutturazione, ma le seguenti cose non sono consentite:

- Tipi personalizzati
- Alias di tipo
- Shadowing dei nomi (non puoi ridefinire / riutilizzare un nome già nello scope)

## Semplificare le espressioni

Questa espressione somma i cubi di 3 numeri, ma è difficile da leggere, e sarebbe facile che il calcolo risultasse diverso per i diversi numeri.

```elm
(a * a * a) + (b * b * b) + (c * c * c)
```

Possiamo definire una funzione `cube` in un'espressione `let` per rendere il calcolo più semplice, più espressivo e più sicuro. Questa funzione potrebbe avere un'annotazione di tipo, ma nel codice Elm idiomatico è relativamente raro.

```elm
let
  cube x = x * x * x
in
  cube a + cube b + cube c
```

## Dare un nome ai risultati di espressioni intermedie

Questo codice definisce sideArea e topArea per rendere il calcolo più semplice e più espressivo.

```elm
cylinderArea : Float -> Float -> Float
cylinderArea radius height =
    let
        sideArea = 2 * pi * radius * height
        topArea = pi * radius ^2
    in
        sideArea + 2 * topArea
```

## Spezzare un'espressione grande

Questo codice crea uno schema iniziale per il [Game of Life](https://playgameoflife.com/) (un comune esercizio di esempio di programmazione).

Non è importante capire esattamente come funziona, ma dovrebbe essere evidente che sarebbe molto grande se scritto come un'unica espressione, senza `let`.

```elm
beginWithPattern : Size -> Padding -> Pattern -> GameOfLife
beginWithPattern minimumSize padding pattern =
    let
        size = calculateSize minimumSize padding pattern

        center = Size.center size

        centeredPattern = Pattern.centerAt center pattern

        dimensions = { width = size, height = size }

        deadCells = Matrix.create dimensions Dead
    in
    GameOfLife (bringPatternToLife deadCells centeredPattern)
```
