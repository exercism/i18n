# Come usare Markdown nel mentoring

Puoi usare Markdown nei tuoi commenti di mentoring su GitHub.
Questo ti permette di inserire frammenti di codice, aggiungere titoli, testo in grassetto, corsivo, elenchi e citare frasi precedenti.

Su Exercism permettiamo anche alcuni elementi del «Github-flavoured Markdown», in particolare l'evidenziazione della sintassi, le tabelle e il testo barrato.

Se non hai familiarità con Markdown o con le funzionalità aggiuntive di GitHub, ti consigliamo di leggere la [guida di GitHub a Markdown](https://guides.github.com/features/mastering-markdown/).
