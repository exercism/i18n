# Istruzioni

Converti un numero binario, rappresentato come stringa (ad esempio '101010'), nel suo equivalente decimale partendo dai principi di base.

Implementa la conversione da binario a decimale.
Data una stringa binaria in input, il tuo programma deve produrre un output decimale.
Il programma deve gestire anche gli input non validi.

## Nota

- Implementa la conversione da solo.
  Non far fare la conversione a qualcos'altro.

## Il sistema binario (base 2)

Il sistema decimale è un sistema in base 10.

Un numero come 23 in notazione in base 10 si può vedere come una combinazione lineare di potenze di 10:

- La cifra più a destra viene moltiplicata per 10^0 = 1
- La cifra successiva viene moltiplicata per 10^1 = 10
- ...
- L'ennesima cifra viene moltiplicata per 10^_(n-1)_.
- Tutti questi valori vengono sommati.

Quindi: `23 => 2*10^1 + 3*10^0 => 2*10 + 3*1 = 23 base 10`

Il sistema binario è simile, ma usa le potenze di 2 invece delle potenze di 10.

Quindi: `101 => 1*2^2 + 0*2^1 + 1*2^0 => 1*4 + 0*2 + 1*1 => 4 + 1 => 5 base 10`.
