# Test

## Esegui tutti i test

C'è uno script Raku con l'estensione `.rakutest` che verrà usato per testare la soluzione.
Puoi eseguire i test con il comando:

`prove6`

Prima di iniziare l'esercizio, l'output sarà probabilmente simile a questo:

```
# Failed test 'Say Hi!'
# at t/hello-world.rakutest line 6
# expected: "Hello, World!"
#  matcher: 'infix:<eq>'
#      got: "Goodbye, Mars!"
# You failed 1 test of 1
t/hello-world.rakutest ... Dubious, test returned 1
Failed 1/1 subtests
```

Dovrai modificare il modulo con l'estensione `.rakumod`, contenuto nella directory `lib/`, e scrivere una soluzione che superi i test.
Una volta superati i test, l'output del comando qui sopra sarà probabilmente simile a questo:

```
t/hello-world.rakutest ... ok
All tests successful.
```

## Fermarsi dopo il primo fallimento

Se hai impostato la variabile d'ambiente `RAKU_TEST_DIE_ON_FAIL`, il test
runner si fermerà dopo il primo errore. Per esempio:

In Linux / OS X:

```bash
export RAKU_TEST_DIE_ON_FAIL=1
# now all the follow up runs will stop at the first failure
prove6
# until we do
unset RAKU_TEST_DIE_ON_FAIL
# or you can use it for one run like this:
RAKU_TEST_DIE_ON_FAIL=1 prove6
```

Oppure in Windows:

```
SET RAKU_TEST_DIE_ON_FAIL=1
REM now all the follow up runs will stop at the first failure
prove6
REM until we do
set RAKU_TEST_DIE_ON_FAIL=
```

Per maggiori informazioni, vedi il
[capitolo sul testing della documentazione di Raku](https://docs.raku.org/language/testing.html).

## Risoluzione dei problemi

```
===SORRY!===
Could not find JSON::Fast
```

Tutti i moduli usati nel track Raku sono inclusi con Rakudo Star.
Se, quando provi a eseguire un test, ricevi un messaggio di errore come quello qui sopra, dovrai assicurarti di avere l'ultima distribuzione di Rakudo Star oppure installare il modulo da solo con un gestore di pacchetti.
Vedi la [documentazione di Raku sui moduli](https://docs.raku.org/language/modules#Looking_for_and_installing_modules.) per informazioni su come installare i moduli.
