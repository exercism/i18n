# Informazioni

In Haxe, una gerarchia di classi può essere definita usando l'_ereditarietà_, che consente a una classe derivata (`Car`) di ereditare il comportamento e i dati della sua classe genitore (`Vehicle`).

Nella classe genitore, puoi definire:

- metodi che possono essere sovrascritti
- metodi astratti che devono essere implementati dalle classi derivate

```haxe
abstract class Vehicle {
  public function new() {}

  // Can be overridden
  public function drive() {
    // ...
  }

  // Must be implemented
  public abstract function getSpeed():Int;
}

class Car extends Vehicle {
  public function new() {
    super(); // Runs the parent class' constructor
  }

  public override function drive() {
    // ...
  }

  public function getSpeed():Int {
    // ...
  }
}
```

Se la classe genitore ha un costruttore, usiamo `super()` per chiamarlo:

```haxe
abstract class Vehicle {
  var wheels:Int;

  public function new(wheels:Int) {
    this.wheels = wheels
  }
}

class Car extends Vehicle {
  var color:String;

  public function new(wheels:Int, color:String) {
    super(wheels);
    this.color = color;
  }
}

```
