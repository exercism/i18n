# Introduzione

Una `string` in Go è una sequenza immutabile di byte, che non devono per forza rappresentare caratteri.

Un letterale di tipo stringa si definisce tra doppi apici:

```go
const name = "Jane"
```

Le stringhe si possono concatenare con l'operatore `+`:

```go
"Jane" + " " + "Austen"
// => "Jane Austen"
```

Alcuni caratteri speciali devono essere preceduti da una barra rovesciata, come `\t` per una tabulazione e `\n` per un a capo all'interno delle stringhe.

```go
"How is the weather today?\nIt's sunny"  
// =>
// How is the weather today?
// It's sunny
```

Il pacchetto `strings` contiene molte funzioni utili per lavorare con le stringhe.
Per saperne di più sulle funzioni per le stringhe, dai un'occhiata alla [documentazione del pacchetto strings](https://pkg.go.dev/strings).
Ecco alcuni esempi:

```go
import "strings"

// strings.ToLower returns the string given as argument with all its characters lowercased
strings.ToLower("MaKEmeLoweRCase")
// => "makemelowercase"

// strings.Repeat returns a string with a substring given as argument repeated many times
strings.Repeat("Go", 3)
// => "GoGoGo"
```
