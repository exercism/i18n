# Istruzioni

Mentre lavori a _Instruments of Texas_, ti viene chiesto di occuparti di una calcolatrice sperimentale a notazione polacca inversa [RPN] scritta in Elixir. Il tuo team ha un problema: alcune operazioni generano errori e fanno crashare il processo. Ti è stato chiesto di scrivere una funzione che racchiuda la funzione di operazione, così che gli errori possano essere gestiti in modo più elegante con codice Elixir idiomatico.

## 1. Avvisa il team

Implementa la funzione `calculate!/2` in modo che chiami la funzione di operazione con lo stack come unico argomento. La funzione di operazione è definita altrove, ma sai che può concludersi con successo oppure sollevare un errore.

```elixir
stack = []
operation = fn _ -> :ok end
RPNCalculator.calculate!(stack, operation)
# => :ok

stack = []
operation = fn _ -> raise ArgumentError, "An error occurred" end
RPNCalculator.calculate!(stack, operation)
# => ** (ArgumentError) An error occurred
```

> I nomi di funzione che terminano con `!` avvertono i programmatori che quella funzione potrebbe sollevare un errore

## 2. Racchiudi l'errore

Facendo altre ricerche, noti che molte funzioni usano atomi e tuple per indicare successo o fallimento. Implementa `calculate/2` usando questa strategia.

```elixir
stack = []
operation = fn _ -> "operation completed" end
RPNCalculator.calculate(stack, operation)
# => {:ok, "operation completed"}

stack = []
operation = fn _ -> raise ArgumentError, "An error occurred" end
RPNCalculator.calculate(stack, operation)
# => :error
```

## 3. Inoltra il messaggio

Alcuni errori contengono informazioni importanti che i tuoi colleghi devono conoscere per garantire il corretto funzionamento del sistema. Implementa `calculate_verbose/2` per inoltrare il messaggio di errore. L'errore è una struct che ha un campo `:message`.

```elixir
stack = []
operation = fn _ -> "operation completed" end
RPNCalculator.calculate_verbose(stack, operation)
# => {:ok, "operation completed"}

stack = []
operation = fn _ -> raise ArgumentError, "An error occurred" end
RPNCalculator.calculate_verbose(stack, operation)
# => {:error, "An error occurred"}
```
