# Introduzione

A volte hai bisogno di vedere una sequenza come una serie di *pezzi* anziché
elemento per elemento. I vocabolari [`grouping`][grouping],
[`splitting`][splitting] e [`splitting.monotonic`][splitting.monotonic] ti
danno quattro modi per farlo.

## `group`: blocchi disgiunti di dimensione *n*

```
group ( seq n -- groups )
```

```factor
USING: grouping ;

{ 1 2 3 4 5 6 7 } 3 group .
! => { { 1 2 3 } { 4 5 6 } { 7 } }
```

Se la lunghezza della sequenza non è un multiplo di *n*, l'ultimo gruppo è
più corto di *n*.

## `clump`: finestra scorrevole sovrapposta di dimensione *n*

```
clump ( seq n -- clumps )
```

```factor
USING: grouping ;

{ 1 2 3 4 5 } 2 clump .
! => { { 1 2 } { 2 3 } { 3 4 } { 4 5 } }
```

Se la sequenza è più corta di *n*, il risultato è vuoto.

## `split-when`: spezza ovunque scatti un predicato

```
split-when ( seq quot: ( elt -- ? ) -- pieces )
```

```factor
USING: splitting ;

{ 1 2 0 3 4 0 5 } [ zero? ] split-when .
! => { { 1 2 } { 3 4 } { 5 } }
```

Ogni elemento riceve la propria chiamata al predicato; gli elementi veri
sono i *punti di interruzione* e non vengono mantenuti nel risultato.

## `monotonic-split`: spezza le serie dove fallisce un controllo sulla coppia adiacente

```
monotonic-split ( seq quot: ( a b -- ? ) -- pieces )
```

```factor
USING: splitting.monotonic ;

{ 1 1 2 2 2 3 } [ = ] monotonic-split .
! => { { 1 1 } { 2 2 2 } { 3 } }
```

Il predicato lavora su *coppie adiacenti*. Finché restituisce un valore vero,
la serie continua; quando restituisce `f`, inizia un nuovo pezzo. Con `[ = ]`
ottieni serie di elementi uguali; con `[ <= ]` ottieni serie non decrescenti;
e così via.

## Quando usare quale

- **`group`/`clump`**: conosci la *dimensione* che vuoi.
- **`split-when`**: sai che aspetto ha un *elemento di interruzione*.
- **`monotonic-split`**: sai cosa fa sì che due elementi adiacenti
  *appartengano ancora insieme*.
