# Suggerimenti

Il tuo codice dovrebbe contenere una funzione frequency :: Int -> [Text] -> Map Char Int che accetta un numero di worker da usare in parallelo e un array di testi, e restituisce la frequenza totale di ogni lettera nel testo.

## Benchmark

Scopri come cambiare il numero di worker influisce sulle prestazioni della soluzione eseguendo il benchmark. Per eseguirlo, usa `stack bench`. Sentiti libero di modificare `bench/Benchmark.hs` per esplorare le prestazioni della soluzione con input diversi.
