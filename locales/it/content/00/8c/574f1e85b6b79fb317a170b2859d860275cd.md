# Le basi

Un programma Sather è composto da **classi**. Una classe è una scatola con un nome che contiene routine. Una **routine** è un pezzo di lavoro con un nome che produce una risposta.

```sather
class GREETER is

   hello : STR is
      return "Hello!";
   end;

end; -- class GREETER
```

Leggiamo quel codice dall'alto:

- `class GREETER is` apre la scatola e le dà un nome. I nomi delle classi si scrivono in maiuscolo.
- `hello : STR is` avvia una routine chiamata `hello` che produce un `STR`, cioè un pezzo di testo chiamato *stringa*. Il `: STR` è una promessa sul tipo di risposta che verrà restituita.
- `return "Hello!";` restituisce la risposta. Il testo si scrive tra virgolette doppie.
- `end;` chiude la routine, e il secondo `end;` chiude la classe.

Tutto ciò che segue `--` in una riga è un **commento**. Sather lo ignora; è lì per le persone.

```sather
-- This line is for the reader, not the computer.
```

Per usare una routine da un'altra parte, scrivi il nome della classe, due volte i due punti e il nome della routine:

```sather
GREETER::hello        -- this is "Hello!"
```

All'interno della stessa classe puoi omettere il nome della classe:

```sather
class GREETER is

   hello : STR is
      return "Hello!";
   end;

   greeting_again : STR is
      return hello;      -- calls the routine just above
   end;

end; -- class GREETER
```

Una routine che non accetta argomenti si chiama senza parentesi: `hello`, non `hello()`.
