# Test

Per usare il test runner, devi avere [Godot installato][installation] correttamente.

## Eseguire i test

Il [test runner][] viene usato per caricare e testare le soluzioni.
Per eseguire il test runner, scaricalo in locale, poi avvialo con `godot`.
In futuro, il test runner verrà scaricato automaticamente insieme agli esercizi quando usi `exercism download`.

### Scaricare il test runner

Il seguente frammento di shell serve a scaricare il test runner.

```bash
exercism download --track gdscript --exercise hello-world
cd "$(exercism workspace)/gdscript"
curl --remote-name https://raw.githubusercontent.com/exercism/gdscript-test-runner/refs/heads/main/bin/test_runner.gd
```

### Eseguire il test runner

Il test runner si esegue usando `godot` in modalità headless (senza IDE).
`-s` o `--script` indica a Godot di eseguire lo script del test runner.
Il test runner si aspetta due argomenti: lo slug ed il percorso della cartella della soluzione.

```bash
godot --headless -s to/test_runner.gd -- <solution-slug> <path/to/solution>
```

Ad esempio,

```bash
godot --headless -s "$(exercism workspace)/gdscript/test_runner.gd" -- hello-world "$(exercism workspace)/gdscript/hello-world
```
