# Introduzione

Un modo comune per eseguire del codice in modo condizionale in JavaScript è l'istruzione `if`.
È composta dalla parola chiave `if`, da una condizione racchiusa tra parentesi tonde e da un blocco di codice racchiuso tra parentesi graffe.
Il blocco di codice verrà eseguito solo se la condizione restituisce `true`.

```javascript
if (condition) {
  // code that is executed if "condition" is true
}
```

Può essere usata da sola oppure combinata con la parola chiave `else`.

```javascript
if (condition) {
  // code that is executed if "condition" is true
} else {
  // code that is executed otherwise
}
```

Per annidare un'altra condizione nell'istruzione `else`, puoi usare `else if`.

```javascript
if (condition1) {
  // code that is executed if "condition1" is true
} else if (condition2) {
  // code that is executed if "condition2" is true
  // but "condition1" was false
} else {
  // code that is executed otherwise
}
```
