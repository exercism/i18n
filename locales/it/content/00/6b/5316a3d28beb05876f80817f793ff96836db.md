# Informazioni

In Elixir, le funzioni possono essere chiamate dinamicamente.

Tutti i nomi dei moduli sono atomi. Tutti i nomi dei moduli Elixir vengono automaticamente preceduti da `Elixir.` quando vengono compilati.

```elixir
is_atom(Enum)
# => true
Enum == Elixir.Enum
# => true
```

Elixir può risolvere la funzione da chiamare a runtime, usando il nome del modulo per effettuare una ricerca. La ricerca può essere fatta dinamicamente se il nome del modulo è legato a una variabile.

```elixir
defmodule MyModule do
  def message(), do: "My message"
end

atom = MyModule
atom.message()
# => "My message"
```
