# Introduzione

## Classi

Le classi sono un'unità di organizzazione del codice in PHP.
Il codice che rappresenta il comportamento di un elemento, o il comportamento di un processo, può essere raggruppato in una classe.
Le funzioni assegnate a una classe vengono chiamate `methods` per convenzione.

```php
<?php

class Door
{
    function lock()
    {
        // ...
    }

    function unlock()
    {
        // ...
    }
}
```

Le classi si istanziano con la parola chiave `new`: questo alloca la memoria per l'istanza della classe e chiama il metodo costruttore della classe.
Le classi istanziate possono essere assegnate a una variabile.
Per invocare i metodi di un'istanza di una classe, possiamo usare l'operatore di accesso `->`.

```php
<?php

$a_door = new Door();
$a_door->lock();
$a_door->unlock();
```

Una classe istanziata può riferirsi alla propria istanza usando la variabile speciale `$this`.
Le classi possono anche avere proprietà: queste si comportano come variabili legate all'istanza dell'oggetto classe.
A queste proprietà si può fare riferimento dall'interno o dall'esterno.

```php
<?php

class Car
{
    public $color;

    function __construct($color)
    {
        $this->color = $color;
    }

    function getColor()
    {
        return $this->color;
    }
}

$a_car = new Car("red");
$a_car->color; // => "red" by accessing the property
$a_car->getColor(); // => "red" by invoking the instance method
```
