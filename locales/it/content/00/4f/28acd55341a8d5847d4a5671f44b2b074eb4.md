# Istruzioni

Cerca nei file le righe che corrispondono a una stringa di ricerca e restituisci tutte le righe corrispondenti.

Il comando Unix [`grep`][grep] cerca nei file le righe che corrispondono a un'espressione regolare. Il tuo compito è implementare una versione semplificata del comando `grep`, che supporta la ricerca di stringhe fisse.

Il comando `grep` accetta tre argomenti:

1. La stringa da cercare.
2. Zero o più flag per personalizzare il comportamento del comando.
3. Uno o più file in cui cercare.

Poi legge il contenuto dei file specificati (nell'ordine indicato), trova le righe che contengono la stringa di ricerca e infine restituisce quelle righe nell'ordine in cui sono state trovate.
Quando cerca in più file, ogni riga corrispondente è preceduta dal nome del file e dai due punti (':').

## Flag

Il comando `grep` supporta i seguenti flag:

- `-n` Anteponi il numero di riga e i due punti (':') a ogni riga dell'output, mettendo il numero dopo il nome del file (se presente).
- `-l` Restituisci solo i nomi dei file che contengono almeno una riga corrispondente.
- `-i` Confronta ignorando la differenza tra maiuscole e minuscole.
- `-v` Inverti il programma: raccogli tutte le righe che non corrispondono.
- `-x` Cerca solo le righe in cui la stringa di ricerca corrisponde all'intera riga.

[grep]: https://pubs.opengroup.org/onlinepubs/9699919799/utilities/grep.html
