# Introduzione

Una *espressione regolare* (regex) è un piccolo schema che descrive come dovrebbe apparire un certo testo. Gli strumenti per le espressioni regolari di Factor si trovano nel vocabolario [`regexp`][regexp], e uno schema si scrive tra `R/ ` e `/`.

La maggior parte dei caratteri in uno schema rappresenta sé stessa. Alcuni elementi speciali indicano *tipi* di carattere o *quanti* aspettarsene:

```
\d        ! any digit 0–9
\s        ! any whitespace; \S means any non-whitespace
[A-Z]     ! any one capital letter
.         ! any single character

{4}       ! exactly 4 times       +   ! one or more
{2,5}     ! 2 to 5 times          *   ! zero or more
?         ! optional (0 or 1)
```

Quindi `R/ [A-Z]{2}-\d{4}/` significa «due maiuscole, un trattino, quattro cifre».

`matches?` verifica se una stringa *intera* corrisponde allo schema:

```
matches? ( string regexp -- ? )
```

```factor
USING: regexp ;

"NS-1024" R/ [A-Z]{2}-\d{4}/ matches? .   ! => t
"NS-10"   R/ [A-Z]{2}-\d{4}/ matches? .   ! => f
```

Altre parole guardano *dentro* una stringa: `all-matching-subseqs` restituisce tutte le corrispondenze, `count-matches` le conta, `re-contains?` indica se ce n'è almeno una, e `re-replace` sostituisce ogni corrispondenza con un nuovo testo:

```
all-matching-subseqs ( string regexp -- seq )
count-matches        ( string regexp -- n )
re-contains?         ( string regexp -- ? )
re-replace           ( string regexp replacement -- result )
```

```factor
USING: regexp ;

"seen NS-1024 then AB-0007" R/ [A-Z]{2}-\d{4}/ all-matching-subseqs .
! => { "NS-1024" "AB-0007" }

"user=alice pass=hunter2" R/ pass=\S+/ "pass=****" re-replace .
! => "user=alice pass=****"
```

[regexp]: https://docs.factorcode.org/content/vocab-regexp.html
