# Introduzione

Così come si può creare un puntatore a un `int` o a un altro tipo di dato di base, si può creare anche un puntatore a una funzione.
Un puntatore a funzione può essere usato per passare una funzione a un'altra funzione.
Una funzione che viene passata come valore di un parametro a un'altra funzione è detta funzione di prima classe.
Una funzione che accetta una o più funzioni come parametro, oppure che restituisce una funzione, è detta funzione di ordine superiore.

Nell'esempio seguente, `is_even` e `is_odd` sono funzioni di prima classe.
La funzione di ordine superiore è `test_number`.

```c
#include <stdio.h>
#include <stdbool.h>

bool is_even (int number) {
    return number & 1 != 1;
}

bool is_odd (int number) {
    return number & 1 == 1;
}

// this function takes any other function which takes a number and returns a bool
void test_number(bool (*func) (int), int number, char *text){
    printf(text, number, func(number)? "true": "false");
}

int main() {
    // prints Testing odd for 3 is true
    test_number(is_odd, 3,"Testing odd for %d is %s\n");
    // prints Testing even for 3 is false
    test_number(is_even, 3,"Testing even for %d is %s\n");
}
```
La firma della funzione `bool (*func) (int)` del primo argomento di `test_number` corrisponde alla firma delle funzioni passate.
Sia `is_even` che `is_odd` accettano un parametro `int` e restituiscono un `bool`.
In `(*func)`, `func` rappresenta il nome della funzione da usare.
Se si fosse usato `(*fn)`, la chiamata sarebbe avvenuta così: `printf(text, number, fn(number)? "true": "false");`.
Per soddisfare il parametro del puntatore a funzione, quando chiamiamo `test_number` passiamo il nome di una funzione che ha la firma attesa.
Vediamo quindi che il nome di una funzione punta all'indirizzo di quella funzione.
