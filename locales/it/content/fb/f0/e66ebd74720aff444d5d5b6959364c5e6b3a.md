# Appendice alle istruzioni

## Suggerimenti

Questo esercizio lavora con dati testuali. Per ragioni storiche, il tipo `String` di Haskell è sinonimo di `[Char]`, un array di caratteri. Per gestire i dati testuali in modo più efficiente, si può usare il tipo `Text`.

Come estensione opzionale di questo esercizio, puoi

- Leggere qualcosa sui [tipi di stringa](https://haskell-lang.org/tutorial/string-types) in Haskell.
- Aggiungere `- text` alle dipendenze in package.yaml.
- Importare `Data.Text` [nel modo seguente](https://hackernoon.com/4-steps-to-a-better-imports-list-in-haskell-43a3d868273c):

        import qualified Data.Text as T
        import           Data.Text (Text)

- Ora puoi scrivere ad esempio `transform :: Map Int Text -> Map Char Int` e riferirti ai combinatori di `Data.Text` come ad esempio `T.toLower`.
- Consulta la documentazione di [`Data.Text`](https://hackage.haskell.org/package/text/docs/Data-Text.html).

Questa parte è del tutto opzionale.
