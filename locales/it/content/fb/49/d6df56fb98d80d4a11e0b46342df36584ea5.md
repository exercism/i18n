# Approfondimento

L'istruzione `guard` di Swift serve a uscire in anticipo da una funzione quando non è soddisfatta una condizione necessaria perché l'elaborazione possa proseguire, ad esempio:

```swift
guard myValue = 0 else { return 0 }
let root = myValue.squareRoot()
```

Qui `guard` verifica se l'espressione booleana che segue la parola chiave `guard` è vera. Se lo è, l'elaborazione prosegue con il codice che segue l'istruzione guard (qui `let root = myValue.squareRoot()`). Altrimenti viene eseguito il codice della clausola else. A differenza di un'istruzione `if`, un'istruzione `guard` _deve_ avere una clausola else e, a differenza della clausola else di un if-else, la clausola else di un guard _deve_ uscire dallo scope dell'istruzione guard. Ovvero, deve usare un'istruzione di trasferimento del controllo come `return`, `continue` o `break`, oppure deve lanciare un errore o terminare il programma.

Un esempio d'uso è la funzione sinc, che è uguale a sin(x)/x, con sinc(0) definito pari a 1, così da evitare problemi con la divisione per 0. Questa funzione si può scrivere in Swift usando un `guard` nel modo seguente:

```swift
func sinc(_ x: Double) -> Double {
    guard x != 0 else { return 1 }
    return sin(x) / x
}

sinc(0)              // returns 1
sinc(Double.pi / 2)  // returns 0.6366197723675814
```
