# Introduzione

In Swift, non puoi accedere a una stringa usando un numero intero, come in `string[3]`.
Poiché le stringhe di Swift sono composte da caratteri Unicode di lunghezza variabile, per trovare un carattere bisogna scorrere i caratteri che lo precedono.

Per accedere al carattere in una posizione specifica, devi calcolare un indice di tipo `String.Index`.
Questi indici sono chiamati *indici opachi* perché la loro struttura interna è gestita da Swift, invece di essere manipolata direttamente come numeri interi grezzi:

```swift
let csv = "apple,pear,peach,orange,cherry,lime,gooseberry"
let index = csv.index(csv.startIndex, offsetBy: 21)
print(csv[index])
// Prints "g"

print(index)
// Prints internal representation: Index(_rawBits: ...)
```
