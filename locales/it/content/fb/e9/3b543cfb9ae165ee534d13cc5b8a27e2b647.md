# Istruzioni

Ti è venuta improvvisamente voglia di pancake.
Da persona moderna e incline alla tecnica, scrivi una lista della spesa per gli ingredienti dei pancake in formato JSON.
La struttura della lista è:

```json
{
  "name": "name of shopping list",
  "ingredients": [ ...list of ingredients... ],
  "optional ingredients": [ ...list of ingredients... ]
}
```

Un ingrediente è rappresentato da un oggetto JSON, come questo:

```json
{
  "item": "flour",
  "amount": {
    "quantity": 2,
    "unit": "cup"
  }
}
```

Un ingrediente ha una proprietà opzionale chiamata `"substitute"` che contiene una stringa con un altro elemento che può essere usato al suo posto.

Vediamo come possiamo esaminare la lista della spesa con `jq`

## 1. Estrai il nome della lista della spesa

Scrivi un'espressione che produca come output l'elemento "name" della lista della spesa.

## 2. Conta quanti ingredienti servono

Conta solo gli ingredienti «obbligatori». Non includere gli ingredienti opzionali.

## 3. Quanto zucchero?

Scrivi un'espressione che produca come output la quantità di zucchero.
Serve solo la parte numerica.

## 4. Mappa gli ingredienti che possono essere sostituiti

Alcuni ingredienti possono essere sostituiti (se non hai l'ingrediente X puoi usare Y).
Produci come output un oggetto JSON che associa l'ingrediente consigliato al suo sostituto.
Includi gli ingredienti opzionali nella mappatura.
