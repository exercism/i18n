# Basi della sintassi di Elm 1

## Costanti e funzioni

I programmi Elm sono composti da definizioni ed espressioni.
In Elm tutto è una definizione oppure un'espressione.

Un valore costante si definisce con `name = expression`.

```elm
five = 5

six = 3 + 3
```

Le funzioni si definiscono con `name parameters... = expression`,
dove i parametri sono separati soltanto da uno spazio.

```elm
add number1 number2 = number1 + number2
```

Anche chiamare una funzione è un'espressione e si fa
specificando il suo nome e passando gli argomenti per ciascun parametro della funzione,
separati da uno spazio, proprio come nella definizione di una funzione.

```elm
five = add 2 3
```

Le parentesi tonde si possono usare per specificare l'ordine di valutazione di un'espressione.

```elm
six = add 2 (1 * 4)

twelve = add 2 1 * 4
```

## Indentazione / spazi bianchi significativi

Elm non usa marcatori sintattici come parentesi graffe, parentesi tonde o punti e virgola per specificare i confini del codice. Usa invece spazi bianchi e indentazione.

- Le definizioni di modulo, di import e di funzioni di primo livello devono iniziare dalla colonna più a sinistra.
- Se un'espressione è suddivisa su più righe, il codice che fa parte di quell'espressione deve essere indentato sotto quell'espressione con almeno uno spazio.
- Le parti dell'espressione raggruppate insieme dovrebbero essere indentate con lo stesso numero di spazi.

```elm
-- A function split over multiple lines, so subsequent lines must be indented
add number1 number2 =
    number1 + number2
```

https://elmprogramming.com/indentation.html

## Moduli

Ogni file in Elm è un modulo e deve contenere un'istruzione `module` prima di tutto il resto del codice.
I nomi dei moduli devono corrispondere al nome del file, quindi il modulo `Calculator` deve trovarsi nel file Calculator.elm.
Qualsiasi cosa definita all'interno di un modulo ha uno scope privato al suo interno
e non è accessibile dall'esterno, a meno che non sia elencata in `exposing`.

```elm
-- Define the Calculator module, and expose the `add` function
module Calculator exposing (add)

six = 3 + 3

add number1 number2 = number1 + number2
```

```elm
-- Define the Calculator module, and expose everything within: `six` and `add`
module Calculator exposing (..)

six = 3 + 3

add number1 number2 = number1 + number2
```

https://elm-lang.org/docs/syntax#modules

## Commenti

Un commento è un testo all'interno del file Elm che non viene interpretato come codice.
Serve principalmente a essere letto da te e da altri programmatori.
Esiste una sintassi leggera per i commenti su una sola riga, basata sui doppi trattini.
I commenti su più righe sono possibili anche con la coppia `{-` e `-}`
di delimitatori di apertura e chiusura.

```elm
-- a single line comment
-- another single line comment

{- a multiline comment
   spawning multiple lines
-}
```
