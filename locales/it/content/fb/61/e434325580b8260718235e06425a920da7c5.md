# Condizionali superflui

I [condizionali][conditionals] sono usati inutilmente in questa soluzione.
Usare un [argomento predefinito][default argument] insieme a [str.format][str.format] oppure alle [f-strings][f-strings] (_note anche come «formatted string literals» o «stringhe interpolate»_) può rendere il codice più chiaro e meno prolisso.

Per maggiori dettagli, dai un'occhiata a questo post su [python default arguments][python default arguments].
Anche il post del blog [string formatting in python][string formatting in python] può essere un buon punto di partenza per conoscere le opzioni di formattazione delle stringhe di Python.
