# Istruzioni

In questo esercizio elaborerai delle righe di log.

Ogni riga di log è una stringa formattata così: `"[<LEVEL>]: <MESSAGE>"`.

Ci sono tre diversi livelli di log:

- `INFO`
- `WARNING`
- `ERROR`

Hai diversi compiti, ognuno dei quali riceverà una riga di log e ti chiederà di fare qualcosa con essa.

## 1. Recuperare la stringa che segue una sottostringa specifica

Guardando i log dell'ultimo mese, vedi che il messaggio di test si trova sempre dopo una sottostringa specifica. Dato che prevedi di dover estrarre il messaggio di test nel prossimo futuro, decidi di creare un metodo ausiliario che ti aiuti a farlo.

Implementa il metodo di estensione (_static_) `LogAnalysis.SubstringAfter()`, che riceve un delimitatore di tipo stringa e restituisce la sottostringa che segue il delimitatore.

```csharp
var log = "[INFO]: File Deleted.";
log.SubstringAfter(": "); // => returns "File Deleted."
```

## 2. Recuperare la stringa compresa tra due sottostringhe

Guardando più attentamente, vedi che il livello di log si trova sempre tra parentesi quadre (`[` e `]`). Dato che anche in questo caso prevedi di dover estrarre il livello di log nel prossimo futuro, decidi di creare un altro metodo ausiliario per questo.

Implementa il metodo di estensione (_static_) `LogAnalysis.SubstringBetween()` che riceve due delimitatori di tipo stringa e restituisce la sottostringa compresa tra i due delimitatori.

```csharp
var log = "[INFO]: File Deleted.";
log.SubstringBetween("[", "]"); // => returns "INFO"
```

## 3. Estrarre il messaggio da un log

Implementa il metodo di estensione (_static_) `LogAnalysis.Message()` per restituire il messaggio contenuto in un log.

```csharp
var log = "[ERROR]: Missing ; on line 20.";
log.Message(); // => returns "Missing ; on line 20."
```

## 4. Estrarre il livello di log da un log

Implementa il metodo di estensione (_static_) `LogAnalysis.LogLevel()` per restituire il livello di log di un log.

```csharp
var log = "[ERROR]: Missing ; on line 20.";
log.LogLevel(); // => returns "ERROR"
```
