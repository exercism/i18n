# Appendice alle istruzioni

## Configurazione

Segui le istruzioni di configurazione per TypeScript per installare le dipendenze necessarie:

[https://exercism.org/docs/tracks/typescript/installation](https://exercism.org/docs/tracks/typescript/installation)

## Requisiti

Installa le dipendenze dell'esercizio:

```bash
$ yarn install
```

## Far passare la suite di test

Esegui i test con:

```bash
$ yarn test
```

In molte suite di test, tutti i test tranne il primo vengono saltati.

Una volta che un test passa, puoi riattivare il successivo cambiando `xit` in `it`.

## Tutorial

Questa sezione è una guida passo passo per risolvere questo esercizio.

Questo esercizio ha due file:

- hello-world.ts
- hello-world.test.ts

Nel primo file scriverai il codice.
Nel secondo sono definiti i test.

I test verificheranno se il codice fa la cosa giusta.
Non devi essere in grado di scrivere una suite di test da zero,
ma aiuta a capire come è fatto un test e cosa fa.

Apri il file di test, hello-world.test.ts.
Dentro c'è un solo test:

```typescript
it('says hello world', () => {
  expect(hello()).toEqual('Hello, World!')
})
```

Ora esegui il test con il seguente comando dalla riga di comando:

```bash
$ yarn test
```

Il test fallisce. È normale, visto che non hai ancora scritto nessun codice.

Il messaggio di errore è simile a questo:

```
    × says hello world (5ms)

  ● Hello World › says hello world

    expect(received).toEqual(expected) // deep equality

    Expected: "Hello, World!"
    Received: "Goodbye, Mars!"

      4 |
      5 |   it('says hello world', () => {
    > 6 |     expect(hello()).toEqual('Hello, World!')
        |                     ^
      7 |   })
      8 |
      9 | })

      at Object.it (hello-world.test.ts:6:32)
```

E queste sono le righe di codice con probabili difetti nel file `hello-world.test.ts`:

la sesta riga:

```typescript
    expect(hello()).toEqual('Hello, World!')
                    ^
```

Quindi il problema è nella chiamata alla funzione `hello()`.
Vediamo che il test si aspetta `'Hello, World!'` come output, ma invece riceve `"Goodbye, Mars!"`.

Ora controlliamo questa funzione nel file `hello-worlds.ts`:

```typescript
export function hello(): string {
  return 'Goodbye, Mars!'
}
```

Ora vediamo che la funzione restituisce la stringa sbagliata, ed è questo il motivo del fallimento. Risolviamo cambiando il valore restituito:

```typescript
export function hello(): string {
  return 'Hello, World!'
}
```

Esegui di nuovo il test:

```bash
 PASS  ./hello-world.test.ts
  Hello World
    √ says hello world (4ms)
```

E il test passa!
