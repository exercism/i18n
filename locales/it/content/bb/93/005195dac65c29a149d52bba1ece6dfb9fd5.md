# Classi con stato

Finora ogni classe è stata una scatola di routine. Ognuna riceveva i suoi argomenti, calcolava una risposta e dimenticava tutto.

Una classe può invece **ricordare** le cose. Un tabellone segnapunti deve farlo: il punteggio ora dipende da ogni gol segnato da quando è iniziata la partita.

## Attributi

`attr` dà a una classe qualcosa da ricordare.

```sather
class SCOREBOARD is

   attr home_score : INT;
   attr away_score : INT;

end; -- class SCOREBOARD
```

Ogni `attr` diventa una routine che legge il valore e una che lo modifica:

```sather
   board.home_score            -- read it
   board.home_score := 4;      -- change it
```

Gli attributi dello stesso tipo possono condividere una dichiarazione, come possono fare gli argomenti:

```sather
   attr home_score, away_score : INT;
```

## Oggetti

Una classe con attributi è un modello per creare **oggetti**. Ogni oggetto ha le proprie copie degli attributi, quindi due tabelloni segnapunti mantengono due punteggi.

`new` crea un oggetto. Va dentro una routine chiamata `create`, che poi riempie l'oggetto e lo restituisce:

```sather
   create(home, away : STR) : SAME is
      board ::= new;
      board.home_team := home;
      board.away_team := away;
      return board;
   end;
```

`SAME` significa «questa classe». Scrivere `SCOREBOARD` lì direbbe la stessa cosa, ma `SAME` continua a funzionare se la classe viene rinominata.

## Creare un oggetto

`#` chiama `create`:

```sather
   board ::= #SCOREBOARD("Vixens", "Magpies");
```

Usi `#` fin da `rehearsal-script`: `#FSTR` è esattamente questo.

## Routine che modificano l'oggetto

All'interno della classe, un attributo si usa per nome, senza alcun oggetto davanti. Si riferisce all'oggetto su cui è stata chiamata la routine.

```sather
   home_goal is
      home_score := home_score + 1;
   end;
```

`home_goal` non dichiara alcun tipo restituito, perché non risponde nulla: modifica invece l'oggetto. Chiamala come istruzione:

```sather
   board.home_goal;
```

## Gli attributi partono vuoti

Un attributo che nessuno ha impostato vale zero per un `INT`, `false` per un `BOOL` e il vuoto per una stringa o un oggetto. Quindi un nuovo tabellone segnapunti segna 0 a 0 senza che nulla debba dirlo.
