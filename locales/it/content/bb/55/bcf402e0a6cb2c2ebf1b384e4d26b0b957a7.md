# Istruzioni

Questo esercizio riguarda il parsing dei file di log.

Dopo una recente revisione di sicurezza, ti è stato chiesto di ripulire i file di log archiviati dell'organizzazione.

Tutte le stringhe passate ai metodi sono garantite non nulle e senza spazi iniziali o finali.

## 1. Individua le righe di log corrotte

Ti serve un'idea di quante righe di log nel tuo archivio non siano conformi agli standard attuali. Ritieni che un semplice test riveli se una riga di log è valida. Per essere considerata valida, una riga deve iniziare con una delle seguenti stringhe:

- [TRC]
- [DBG]
- [INF]
- [WRN]
- [ERR]
- [FTL]

Implementa il metodo `LogParser.IsValidLine()` in modo che restituisca `false` se una stringa non è valida, altrimenti `true`.

```csharp
var lp = new LogParser();
lp.IsValidLine("[ERR] A good error here");
// => true
lp.IsValidLine("Any old [ERR] text");
// => false
lp.IsValidLine("[BOB] Any old text");
// => false
```

## 2. Dividi la riga di log

Un nuovo team si è unito all'organizzazione e scopri che i suoi file di log usano uno strano separatore per i «campi». Invece di qualcosa di sensato come i due punti ":" usano una stringa come "<--->" o "<=>" (perché è più carino), in realtà qualsiasi stringa che abbia come primo carattere "<" e come ultimo carattere ">" e in mezzo una qualsiasi combinazione dei seguenti caratteri: "^", "\*", "=" e "-".

Implementa il metodo `LogParser.SplitLogLine()` che prende una riga e restituisce un array di stringhe, ognuna delle quali contiene un campo.

```csharp
var lp = new LogParser();
lp.SplitLogLine("Section 1<===>Section 2<^-^>Section 3");
// => {"Section 1", "Section 2", "Section 3"}
```

## 3. Conta il numero di righe che contengono una password tra virgolette

Il team ha bisogno di sapere quali password compaiono in testi tra virgolette, così da poterle esaminare manualmente.

Implementa il metodo `LogParser.CountQuotedPasswords()` per avere un'indicazione della probabile portata dell'attività manuale.

Individua le righe di log in cui la stringa letterale "password", che può essere in qualsiasi combinazione di maiuscole e minuscole, è racchiusa tra virgolette.
Dovresti considerare la possibilità che ci sia contenuto aggiuntivo tra le virgolette, prima e dopo "password".

Le righe passate alla routine possono essere valide oppure no, secondo la definizione del punto 1. Le elaboriamo allo stesso modo, che siano valide o meno.

```csharp
string lines =
    "[INF] passWord " + Environment.NewLine + // contains 'password' but not surrounded by quotation marks
    "\"passWord\"" + Environment.NewLine + // count this one
    "[INF] User saw error message \"Unexpected Error\" on page load." + Environment.NewLine + //does not contain 'password'
    "[INF] \"The secret password was added by the user\""; // count this one

var lp = new LogParser();
lp.CountQuotedPasswords(lines);
// => 2
```

## 4. Rimuovi gli artefatti dal log

Hai scoperto che un'elaborazione a monte dei log ha sparso il testo "end-of-line" seguito da un numero di riga (senza spazio in mezzo) in tutti i log.

Implementa il metodo `LogParser.RemoveEndOfLineText()` che prende una stringa, rimuove il testo "end-of-line" e restituisce una stringa «pulita».

Le righe che non contengono il testo end-of-line devono essere restituite invariate.

Rimuovi solo la stringa end-of-line. Non cercare di sistemare gli spazi.

```csharp
var lp = new LogParser();
lp.RemoveEndOfLineText("[INF] end-of-line23033 Network Failure end-of-line27");
// => "[INF]  Network Failure "
```

## 5. Elenca le righe con password estremamente deboli, così che i colpevoli possano essere puniti

Prima di eliminare le password dal file, dobbiamo elencare tutti i casi in cui le password iniziano con il testo "password".

Implementa il metodo `LogParser.ListLinesWithPasswords()` per stampare la password incriminata seguita dalla riga completa.

Le righe con password tra virgolette sono già state rimosse, e tu elabori le righe indipendentemente dal fatto che siano valide (secondo il punto 1).

Le righe che contengono una password incriminata devono essere restituite con il prefisso "<password>: ".

Le righe che non contengono una password incriminata devono essere restituite con il prefisso "--------: ".

```csharp
var lp = new LogParser();
lp.ListLinesWithPasswords(new string[] {"my passwordsecret is great"});
// => "passwordsecret: my passwordsecret is great"
lp.ListLinesWithPasswords(new string[] {"my password secret"});
// => {"--------: my password secret"}

```
