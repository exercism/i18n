# Informazioni

I tipi C# possono essere definiti all'interno dello scope di una classe o di uno struct. Il tipo contenitore fornisce una sorta di spazio dei nomi. L'accesso al tipo avviene tramite il tipo contenitore con la sintassi del punto.

```csharp
class Outer
{
    public interface IInner {}
    public enum EInner {}
    public class CInner {}
    public struct SInner {}
}

var outer = new Outer();
var inner = new Outer.CInner();
```

## Livelli di accesso

I livelli di accesso possono essere applicati ai tipi annidati. Ad esempio, se una classe è `private`, non può essere vista al di fuori dello scope del tipo contenitore e, naturalmente, le istanze non possono essere viste o usate al di fuori dello scope.

I membri privati della classe esterna sono nello scope di tutti i membri della classe annidata, ma solo i membri non privati della classe annidata sono nello scope dei membri della classe esterna. Per accedere ai membri della classe esterna, la classe annidata deve ricevere un'istanza della classe esterna.

Lo vediamo nell'esempio seguente:

```csharp
class Outer
{
    public class InnerImpl
    {
        private Outer outer;

        public int Interesting = 42;

        public InnerImpl(Outer outer, int interesting)
        {
            this.outer = outer;
            Interesting = interesting;
        }

    }

    public InnerImpl Inner;
    public Outer()
    {
        Inner = new InnerImpl(this, 42);
    }
}

var outer = new Outer();
outer.Inner.Interesting
// => 42
var inner = new Outer.InnerImpl(outer, 1729);
outer.Inner.Interesting
// => 1729
```

## Impedire l'istanziazione indipendente

Esiste un pattern per impedire che un tipo istanziabile venga creato al di fuori del tipo contenitore. Si espone un'interfaccia pubblica ma si mantiene privata la classe che la implementa.

```csharp
class Outer
{
    public interface IInner
    {
        void DoSomething();
    }

    private class InnerImpl : IInner
    {
        private Outer outer;
        public InnerImpl(Outer outer)
        {
            this.outer = outer;
        }
        public void DoSomething()
        {
            outer.DoSomethingElse();
        }
    }

    public IInner Inner;

    public Outer()
    {
        Inner = new InnerImpl(this);
    }
    private void DoSomethingElse()
    {
    }
}

var outer = new Outer();
outer.Inner.DoSomething();

// NOT var inner = new Outer.Inner(outer);
```

## Nota per sviluppatori Java

Le classi annidate di C# sono un incrocio tra le classi annidate statiche e le classi interne di Java. In C# i membri privati della classe esterna sono nello scope dei membri della classe annidata, ma non esiste una sintassi speciale per istanziarle e collegarle a un'istanza della classe esterna. Devi usare una qualche variante del pattern illustrato negli esempi sopra.

C# ha sì classi annidate statiche, ma queste sono semplicemente classi racchiuse con comportamento statico.
