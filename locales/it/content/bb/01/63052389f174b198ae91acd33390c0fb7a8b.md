# Introduzione

## Espressioni case

In Gleam un'espressione `case` può essere usata per eseguire del codice in modo condizionale. Con un'espressione case un valore può essere confrontato con uno o più _pattern_. Un esempio di tale pattern è il _pattern letterale_, che confronta un valore con un valore letterale (ad esempio `1` o `"hello"`).

Le espressioni case si scrivono con la parola chiave `case`:

```gleam
pub fn describe(number: Int) -> String {
  case number {
    0 -> "Zero"
    1 -> "One"
  }
}
```

Anche se questo può sembrare simile alle istruzioni `switch` di altri linguaggi, il pattern matching dà il meglio di sé quando si usano anche altri pattern. Uno di questi pattern è il _pattern variabile_, che permette di assegnare un valore a una variabile. In questo esempio, alla variabile `i` verrà assegnato il valore di `number` se non è `0`:

```gleam
pub fn describe(number: Int) -> String {
  case number {
    0 -> "Zero"
    i -> "Non zero"
  }
}
```

In alcuni casi potresti voler aggiungere una condizione ulteriore a un pattern. Questa è nota come _guardia_ (clausola) e si può aggiungere usando la parola chiave `if`:

```gleam
pub fn describe(number: Int) -> String {
  case number {
    0 -> "Zero"
    i if i < 0 -> "Negative number"
  }
}
```

Per motivi di prestazioni, nelle guardie sono ammessi solo gli operatori matematici e booleani di base: non è possibile usare altre funzioni nelle guardie.

Nell'esempio sopra, non tutti gli input possibili avranno un pattern corrispondente. Il compilatore lo rileva e segnala un errore. Questo si chiama _controllo di esaustività_. Per risolvere l'avviso, bisogna gestire tutti i casi. Per questo si può usare il _pattern jolly_, che è un pattern che corrisponde a qualsiasi valore:

```gleam
pub fn describe(number: Int) -> String {
  case number {
    0 -> "Zero"
    i if i < 0 -> "Negative number"
    _ -> "Positive number"
  }
}

// No compiler error
```

In una stessa clausola si possono confrontare più pattern, usando `|` per separarli. A una clausola si può aggiungere una sola guardia:

```gleam
pub fn describe(number: Int) -> String {
  let yell = True
  case number {
    0 -> "Zero"
    3 | 5 -> "One of the first odd prime numbers"
    2 | 4 | 6 | 8 if !yell -> "One of the even numbers less than 10"
    i if i % 2 == 0 && yell -> "[Yelling] I'm telling you! It's a even nunber"
    i if i < 0 -> "Negative number"
    _ -> "Positive number"
  }
}
// No compiler error
```

Le espressioni case confrontano un valore con ciascun pattern dall'alto verso il basso, finché non trovano un pattern corrispondente ed eseguono la logica associata a quel pattern. L'ordine dei pattern è importante!
