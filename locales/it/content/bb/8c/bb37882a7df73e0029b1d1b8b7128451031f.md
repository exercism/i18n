# Suggerimenti

## Generale

- Potrebbe esserti utile avere un elenco di tutte le [operazioni aritmetiche][arithmetic-operations] in PHP.

## 1. Una proporzione di impasto

- Puoi risolvere questo compito usando gli operatori aritmetici di base per l'addizione e la moltiplicazione.

## 2. Una spruzzata di salsa

- Per ottenere un numero intero di barattoli, dovrai arrotondare per eccesso.
- PHP mette a disposizione delle [funzioni numeriche][numeric-functions] che possono aiutarti.

## 3. Un po' di formaggio, per favore

- Puoi elevare un numero al cubo usando l'[operatore di elevamento a potenza][arithmetic-operations].
- Per ottenere un numero intero di pizze, dovrai arrotondare per difetto.
- PHP mette a disposizione delle [funzioni numeriche][numeric-functions] che possono aiutarti.
- PHP ha una [costante integrata][pi-constant] per pi greco (π).

## 4. Una giusta spartizione

- Usa l'[operatore modulo][arithmetic-operations] (`%`) per ottenere il resto della divisione.

[arithmetic-operations]: https://www.php.net/manual/en/language.operators.arithmetic.php
[pi-constant]: https://www.php.net/manual/en/function.pi.php
