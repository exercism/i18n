# Istruzioni

Il tuo team di design sta passando dalle trasformazioni CSS a Factor per una parte del suo lavoro di layout. Per tenere felice il resto del team, costruirai piccole trasformazioni riutilizzabili sotto forma di quotation che prendono un punto 2D e restituiscono un punto 2D.

Un punto è un array di 2 elementi `{ x y }`.

## 1. Trasla le coordinate

Definisci `translate-2d` in modo che prelevi due valori `dx` e `dy` dallo stack e restituisca una quotation che trasla un punto di `(dx, dy)`.

```factor
{ 4 8 } 2 0 translate-2d call( p -- p' ) .
! => { 6 8 }
```

## 2. Scala le coordinate

Definisci `scale-2d` allo stesso modo, restituendo una quotation che scala un punto di `(sx, sy)`.

```factor
{ 6 -3 } 2 2 scale-2d call( p -- p' ) .
! => { 12 -6 }
```

## 3. Componi due trasformazioni

Definisci `compose-transformations` in modo che prelevi due quotation di trasformazione `f` e `g` e restituisca un'unica quotation che applica prima `f` e poi `g`.

```factor
{ 0 1 } 2 0 translate-2d 2 2 scale-2d compose-transformations
call( p -- p' ) .
! => { 4 2 }
```

## 4. Applica una trasformazione

Definisci `apply-transformation` in modo che prelevi dallo stack un punto e una quotation di trasformazione e restituisca il punto trasformato.

```factor
{ 4 8 } 2 0 translate-2d apply-transformation .
! => { 6 8 }
```

## 5. Trasforma più punti in una sola volta

Definisci `transform-points` in modo che prelevi un array di punti e una quotation di trasformazione, e restituisca l'array dei punti trasformati.

```factor
{ { 0 0 } { 1 1 } { 2 2 } } 1 0 translate-2d transform-points .
! => { { 1 0 } { 2 1 } { 3 2 } }
```
