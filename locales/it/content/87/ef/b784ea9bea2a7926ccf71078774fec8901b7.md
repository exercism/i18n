# Istruzioni

In questo esercizio elaboreremo le righe di log.

Ogni riga di log è una stringa formattata come segue: `"[<LEVEL>]: <MESSAGE>"`.

Ci sono tre diversi livelli di log:

- `INFO`
- `WARNING`
- `ERROR`

Hai tre attività: ognuna prende una riga di log e ti chiede di fare qualcosa con essa.

## 1. Ottenere il messaggio da una riga di log

Implementa il metodo (_statico_) `LogLine.Message()` per restituire il messaggio di una riga di log:

```csharp
LogLine.Message("[ERROR]: Invalid operation")
// => "Invalid operation"
```

Gli spazi bianchi all'inizio o alla fine devono essere rimossi:

```csharp
LogLine.Message("[WARNING]:  Disk almost full\r\n")
// => "Disk almost full"
```

## 2. Ottenere il livello di log da una riga di log

Implementa il metodo (_statico_) `LogLine.LogLevel()` per restituire il livello di log di una riga di log, che deve essere restituito in minuscolo:

```csharp
LogLine.LogLevel("[ERROR]: Invalid operation")
// => "error"
```

## 3. Riformattare una riga di log

Implementa il metodo (_statico_) `LogLine.Reformat()` che riformatta la riga di log, mettendo prima il messaggio e poi il livello di log tra parentesi:

```csharp
LogLine.Reformat("[INFO]: Operation completed")
// => "Operation completed (info)"
```
