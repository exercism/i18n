# Appendice alle istruzioni

## Parole

`find-fewest-coins ( coins target -- result )` restituisce un array di tagli di monete la cui somma è `target`. `coins` è un insieme hash (ad esempio `HS{ 1 5 10 25 }`); per lavorarci, usa le parole del vocabolario `sets` (`members`, `in?`, …).

Quando nessuna combinazione di `coins` può formare `target`, lancia un errore `cannot-make-change`.
