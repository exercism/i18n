# Introduzione

Una `List` è molto simile a un `Array`. Ci sono però differenze importanti che non vorrai perderti:

1. Una lista non può essere indicizzata con le parentesi quadre (`[]`), cioè `[0]`.
2. Una lista non può essere inizializzata.
3. Non esistono le list comprehension.
4. Una lista può modificare liberamente i suoi elementi mentre si itera su di essi.

`List` fa parte del pacchetto `haxe.ds`, quindi ogni volta che vuoi usare le liste devi importarne il pacchetto:

```haxe
import haxe.ds.List;

class Main {
  static function main() {
    var myList = List<Int>();

    for (i in 0...5) {
      myList.add(i);
    }

    trace(myList); // {0, 1, 2, 3, 4}
  }
}
```
