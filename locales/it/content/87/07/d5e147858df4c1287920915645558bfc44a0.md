# Introduzione

Questo è potenzialmente un argomento _vasto_!
Si potrebbe scriverci un libro intero, e diverse persone l'hanno fatto (cerca «unicode book» su Amazon per vedere qualche esempio).

## Una storia molto breve

Gestire i caratteri nei computer era molto più semplice nei decenni passati, quando i programmatori davano per scontato che l'inglese fosse l'unica lingua importante.
Quindi: 26 lettere, maiuscole e minuscole, 10 cifre, alcuni segni di punteggiatura, più un codice (0x07) per far suonare un campanello, e il tutto stava in 7 bit: il set di caratteri [ASCII][wiki-ascii].

Naturalmente, la gente ha iniziato a chiedersi che ne fosse di à, ä e Ł, poi altre persone hanno iniziato a chiedersi di ऄ, ஹ e ญ, e i giovani volevano le emoji 😱.
Cosa fare?

Per farla breve, molte persone intelligenti e pazienti hanno dovuto far parte di commissioni per anni, per definire i dettagli del set di caratteri [Unicode][web-unicode] e di codifiche come [UTF-8][wiki-utf-8], e moltissimo software ha avuto bisogno di una riscrittura _molto_ complicata.
Inoltre, sono stati introdotti molti nuovi bug.

Per evitare che _tutto_ si rompa, il design di Unicode/UTF-8 garantisce che i primi 127 codici siano identici ad ASCII _(persino il campanello)_.

## I caratteri in Kotlin

I linguaggi progettati dopo il 2005 circa hanno l'enorme vantaggio che esisteva già uno standard Unicode ragionevolmente stabile.

Kotlin (pubblicato per la prima volta nel 2011) ha potuto dare per scontato che gli utenti avrebbero usato una varietà di lingue (umane) e che avrebbero avuto bisogno di Unicode per esprimerle.

I letterali di tipo carattere si scrivono tra apici singoli, e sono distinti dalle stringhe, che si scrivono tra virgolette doppie.
Per chi arriva dal mondo C/C++ è probabilmente ovvio, ma può confondere chi programma in Python e JavaScript.

```kotlin
val a = 'a'
a::class.qualifiedName  // => kotlin.Char
a.code  // => 97

val jha = 'झ'  // Devanagari alphabet
jha.code  // => 2333

val heart = '❤'  // heart emoji
heart.code  // => 10084

Char.MAX_VALUE.code  // => 65535 (64k, the largest code point allowed)
```

Convertire tra `Char` e `Int` è semplice:

```kotlin
a.code  // => 97  (a.toInt() is deprecated)
Char(97) // => 'a'
```

Il compilatore consente _alcune_ forme di aritmetica intera sui `Char`:

```kotlin
'a' + 5       // => 'f'
'c' - 'a'   // => 2
'c' + 'a'   // => error!

'f' + ('A' - 'a')  // => 'F' (same as 'f'.uppercase()

'f'.dec() // => 'e' (decrement)
'f'.inc() // => 'g' (increment)
```

## Alcune funzioni per `Char`

Come sempre, ci sono davvero [troppe funzioni][ref-char-lib] di cui parlare qui, quindi questa è solo una selezione.

- Per gli alfabeti appropriati, cambia maiuscole e minuscole con [`uppercase()`][ref-uppercase] e [`lowercase()`][ref-lowercase].
- Verifica maiuscole e minuscole con [`isUpperCase()`][ref-isuppercase] e [`isLowerCase()`][ref-islowercase].
- Verifica il tipo di carattere con:
    - [`isLetter()`][ref-isletter], copre molti alfabeti
    - [`isDigit()`][ref-isdigit], nell'intervallo 0..9
    - `isLetterOrDigit()`, combina le due precedenti
    - [`isWhitespace()`][ref-iswhitespace], qualsiasi carattere di spaziatura

```kotlin
'झ'.isLetter()      // => true
'A'.isLowerCase()   // => false
'4'.isDigit()       // => true
'\t'.isWhitespace() // => true  (tab character)
```

## Conversioni tra liste di Char e stringhe

Per passare da una String a una lista di `Char`, possiamo usare `toList()`.

Per passare da una lista di `Char` a una String c'è la funzione [`joinToString()`][ref-jointostring], che accetta come argomento un separatore (spesso la stringa vuota).

```kotlin
val kt = "kotlin".toList()  // => [k, o, t, l, i, n]
kt.joinToString("")   // => "kotlin"
kt.joinToString("_")  // => "k_o_t_l_i_n"
```

Nota che `joinToString()` opera su una List o su un Array.
Per fare il _cast_ di un singolo `Char` in una stringa di un solo carattere, usa `toString()`.

```kotlin
'a'.toString() // => "a"
```

Per verificare se un carattere è presente in una `String`, oppure in una lista o in un array di `Char`, abbiamo `in`, che corrisponde alla funzione [`contains()`][ref-contains].

```kotlin
val clist = "kotlin".toList()  // => [k, o, t, l, i, n]
't' in clist     // => true
't' in "kotlin"  // => true
```
