# Informazioni sulle stringhe

Una [`string`][ref-string] in Kotlin è una sequenza immutabile di caratteri Unicode.

[`Immutable`][wiki-immutable] significa che qualsiasi operazione su una stringa deve restituire una nuova stringa: la stringa originale non può mai cambiare.

[`Unicode`][wiki-unicode] significa che è possibile rappresentare la maggior parte dei sistemi di scrittura del mondo, ma (a differenza di linguaggi più vecchi come il C) non esiste una corrispondenza 1:1 tra caratteri e byte.
Ne parleremo più in dettaglio nel concetto [`Chars`][concept-chars].

Una stringa è racchiusa tra virgolette doppie `" "`.

Alcuni caratteri richiedono una sequenza di escape: `\\`, più i soliti caratteri non stampabili come `\t` (tabulazione) e `\n` (a capo).

```kotlin
val s = "Escape backslash \\."
// Escape backslash \.
```

Le stringhe su più righe sono racchiuse tra 3 virgolette doppie e possono contenere testo arbitrario (senza bisogno di sequenze di escape).

```kotlin
val multi = """I'm a
    multi-line
    string with special characters \ \t """
//I'm a
//    multi-line
//    string with special characters  \ \t 
```

Usa [trimIndent][trimIndent-doc] per rimuovere l'indentazione comune dalle righe.
È utile per formattare la stringa:

```kotlin
val multi = """
    I'm a
      multi-line
    string""".trimIndent()

//I'm a
//  multi-line
//string
```

In alternativa, [trimMargin][trimMargin-doc] permette di specificare un delimitatore.
Ogni riga della `String` inizia quindi dopo il delimitatore.
Il delimitatore predefinito è `|`, ma puoi specificarne uno diverso come parametro.
Ad esempio:

```kotlin
val multi = """
    |I'm a
    |  multi-line
    |string""".trimMargin()

//I'm a
//  multi-line
//string

val multi2 = """
    start>I'm a
    start>  multi-line
    start>string""".trimMargin("start>")

//I'm a
//  multi-line
//string
```

Le stringhe si possono concatenare con `+`, ma è meglio limitarsi a casi brevi e semplici.
Esistono altre opzioni, spesso migliori.

## Stringhe interpolate

[`Templates`][ref-templates] si riferisce a quella che altri linguaggi chiamano «interpolazione».

Se una stringa contiene un simbolo del dollaro `$` seguito da un identificatore, oppure contiene parentesi graffe (`{expression}`) attorno a un'espressione, questi vengono sostituiti rispettivamente dal valore o dal risultato dell'espressione.

```kotlin
val x = 42
val st = "x is $x, x squared is {x * x}"
// x is 42, x squared is 1764
```

## Formattazione delle stringhe

Solo sulla piattaforma JVM, `String.format()` consente una formattazione più precisa rispetto alle stringhe interpolate, con una [sintassi][web-formats] simile a quella delle funzioni [`printf`][wiki-printf] (_molto vecchie!_).

```kotlin
String.format("%s %.3f", "π ≈", 3.14159)
//π ≈ 3.142
```

## Funzioni sulle stringhe

Kotlin mette a disposizione _molte_ [`functions`][ref-string-functions] per manipolare le stringhe.

Per lo più si tratta di [`extensions functions`][ref-extensions] e non di membri della classe `String`, anche se questo ha poca influenza su come le usiamo.

~~~~exercism/note
Le piuttosto complesse pagine di [documentazione][ref-string-functions] di Kotlin nascondono le funzioni di estensione nella vista predefinita.
Al momento in cui scriviamo, i contenuti più preziosi sono nascosti in una scheda chiamata `Members & Extensions`.
Fai clic per espandere questa sezione e vedere tutti i membri e le estensioni disponibili nella classe `String`.

[ref-string-functions]: https://kotlinlang.org/api/core/kotlin-stdlib/kotlin/-string/
~~~~

L'esempio seguente mostra solo una piccola selezione di ciò che è disponibile:

```kotlin
val str = "Hello World!"

str.length              // => 12 (a property, not a function)
str.elementAt(6)        // => W
str.elementAtOrNull(20) // => null (index out of range)
str.substring(6, 11)    // => "World"
str.substringAfter(" ") // => "World!"

str.lowercase()         // => "hello world!"
str.uppercase()         // => "HELLO WORLD!"

str.startsWith("Hel")   // => true
str.endsWith("xyz")     // => false
str.indexOf("0")        // => 4

str.toCharArray()       // => [H, e, l, l, o,  , W, o, r, l, d, !]
"42".toInt() + 1        // => 43  (parsing; see also toFloat)

"Howdy!  ".trim()       // => "Howdy"
```

## Costruire una stringa

A volte una stringa lunga va costruita per fasi, ad esempio all'interno di un ciclo.

Concatenare le stringhe con `+` diventa presto poco elegante e poco efficiente: l'immutabilità implica una _grande_ quantità di copie.

Kotlin offre vari modi più efficienti per combinare più stringhe:

- Le stringhe interpolate, descritte sopra.
- [`joinToString()][ref-jointostring], di cui parleremo nel concetto [Lists][concept-lists].
- [`StringBuilder`][ref-stringbuilder] di Java, che non è considerato particolarmente idiomatico in Kotlin.
- [`buildString()`][ref-buildstring] di Kotlin, che avvolge `StringBuilder` in una sintassi più concisa e idiomatica.
Accetta la logica di costruzione della stringa come argomento lambda, di cui parleremo in un concetto successivo.

In sostanza, uno `StringBuilder` è una struttura simile a un array, con molti metodi comodi.
Questa è una piccola selezione:

- [`append()`][ref-sb-append] per aggiungere in fondo.
- [`insert()`][ref-sb-insert] per aggiungere in una posizione specificata.
- [`deleteAt()`][ref-sb-deleteat] e [`deleteRange()`][ref-sb-deleterange] per rimuovere da una o più posizioni specificate.
- `toString()` per convertire in una stringa normale alla fine: concatena tutto in un'unica operazione efficiente.

```kotlin
// Available, not recommended
val sb = StringBuilder()
sb.append("Hello ")
sb.append("World!")
sb.toString()
//Hello World!
```

Un esempio con `buildString()`, che usa una sintassi di concetti successivi:

```kotlin
val countDown = buildString {
    for (i in 5 downTo 1) {
        append(i)
        append("_")
    }
}
// countDown is "5_4_3_2_1_"
```
