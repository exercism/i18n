# Istruzioni

È un'altra notte di gran lavoro allo scalo di smistamento di Anversa. Sei tu il responsabile dello smistamento di turno: i carri merci in arrivo vanno raggruppati in treni in partenza, gli accoppiamenti ispezionati, i percorsi divisi agli scambi e i carichi identici accorpati per la fatturazione.

Ogni *carro* è una stringa che indica ciò che trasporta: `"coal"`, `"timber"`, `"crates"`, ecc.

## 1. Accoppia i carri in treni

Definisci `couple` in modo che prenda un array di carri e una lunghezza `n`, e restituisca treni non sovrapposti di `n` carri ciascuno. L'ultimo treno può essere più corto se il conteggio non si divide in parti uguali.

```factor
{ "coal" "coal" "coke" "ore" "ore" "timber" "timber" } 3 couple .
! => { { "coal" "coal" "coke" } { "ore" "ore" "timber" } { "timber" } }
```

## 2. Dai un'occhiata agli accoppiamenti

Definisci `peek-couplings` in modo che prenda un array di carri e restituisca ogni coppia adiacente, così l'ispettore può esaminare ogni accoppiamento.

```factor
{ "coal" "ore" "timber" "crates" } peek-couplings .
! => { { "coal" "ore" } { "ore" "timber" } { "timber" "crates" } }
```

## 3. Dividi la catena agli scambi

Definisci `split-at-junctions` in modo che prenda un array di carri e un array di `junctions` (carri che segnano un punto di separazione), e restituisca i tratti tra i carri di scambio. I carri di scambio stessi non vengono conservati.

```factor
{ "coal" "coal" "switch" "ore" "switch" "timber" }
{ "switch" } split-at-junctions .
! => { { "coal" "coal" } { "ore" } { "timber" } }
```

## 4. Accorpa il carico identico

Definisci `coalesce-cargo` in modo che prenda un array di carri e raggruppi in sequenze i carri *consecutivi* che trasportano lo stesso carico.

```factor
{ "coal" "coal" "ore" "ore" "ore" "timber" "coal" } coalesce-cargo .
! => { { "coal" "coal" } { "ore" "ore" "ore" } { "timber" } { "coal" } }
```
