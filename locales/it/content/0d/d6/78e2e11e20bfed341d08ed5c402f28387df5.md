# Istruzioni

Il direttore di scena vuole che il copione delle prove venga trascritto, e diverse sue parti si costruiscono ripetendo o unendo elementi tra loro.

Tutti e quattro i compiti vanno nella classe `REHEARSAL_SCRIPT`.

## 1. Ripeti un segnale

Dato un segnale e un numero, restituisci il segnale ripetuto quel numero di volte, senza nulla in mezzo.

```sather
REHEARSAL_SCRIPT::repeat_cue("Ha", 3)
-- => "HaHaHa"
```

Ripetere qualcosa zero volte dà la stringa vuota.

## 2. Le iniziali del cast

Data la lista del cast, restituisci la prima lettera di ogni nome, una di seguito all'altra.

```sather
REHEARSAL_SCRIPT::initials(|"Mia", "Ana", "Ben"|)
-- => "MAB"
```

## 3. Numera le battute

Date le battute di una scena, numerala a partire da uno, ognuna su una riga separata.

```sather
REHEARSAL_SCRIPT::numbered_lines(|"Enter", "Exit"|)
-- => "1. Enter\n2. Exit"
```

C'è un a capo *tra* le battute e nessuno dopo l'ultima. Una scena senza battute è la stringa vuota.

## 4. Urla una battuta

Restituisci una battuta con ogni lettera trasformata in maiuscolo.

```sather
REHEARSAL_SCRIPT::shout("quiet please")
-- => "QUIET PLEASE"
```
