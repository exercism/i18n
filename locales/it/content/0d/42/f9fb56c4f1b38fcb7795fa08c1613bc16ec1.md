# Informazioni

Le classi sono un elemento costitutivo fondamentale dei programmi Swift.
Ti permettono di raggruppare proprietà (dati) e metodi (funzioni) correlati in unità di funzionalità autonome.

### Definire le classi

Per definire una classe, usa la parola chiave `class` seguita dal nome della classe, con la definizione racchiusa tra parentesi graffe:

```swift
class GameCharacter {
    var characterClass: String?
    var name: String?
    var active = false
    let id = makeRandomID()
}
```

Il corpo di una classe può contenere proprietà memorizzate, che si definiscono e si comportano come normali costanti (`let`) o variabili (`var`).

### Istanze

La definizione di una classe funge da modello: definisce un nuovo tipo e descrive come sono fatti i suoi valori, ma non crea da sola alcuna istanza.

Per creare un'*istanza* di una classe, chiama il suo inizializzatore scrivendo il nome della classe seguito da una coppia di parentesi tonde:

```swift
let someCharacter = GameCharacter()
```

Questo crea una nuova istanza le cui proprietà vengono inizializzate con i valori predefiniti specificati nella definizione della classe.
Per le proprietà opzionali prive di un valore predefinito esplicito (come `name`), Swift assegna loro `nil` come valore predefinito.

### Accedere alle proprietà

Si accede alle proprietà di un'istanza usando la *notazione con punto*: scrivi il nome dell'istanza, un punto (`.`), e il nome della proprietà.
La notazione con punto funziona anche per le proprietà annidate.

Puoi usare la notazione con punto per leggere i valori e, se la proprietà è mutabile (`var`), per assegnare nuovi valori:

```swift
someCharacter.name
// => nil

someCharacter.name = "Luther"
someCharacter.name
// => "Luther"

someCharacter.id = "new id"
// Error: Cannot assign to property: 'id' is a 'let' constant
```

### I metodi

Oltre alle proprietà, le classi possono definire i *metodi*: funzioni associate alla classe.

Definisci i metodi all'interno del corpo della classe usando la normale sintassi `func`.
Se un metodo modifica una proprietà, quella proprietà deve essere dichiarata con `var`:

```swift
class GameCharacter {
    var characterClass: String?
    var name: String?
    var active = false
    let id: String = makeRandomID()

    func takesDamage(_ damage: Double) {
        if damage > 100 {
            active = false
        }
    }

    func sayName() -> String {
        return "My name is \(name ?? "no one"), my class is \(characterClass ?? "undetermined")"
    }
}
```

Chiama i metodi su un'istanza usando la notazione con punto, proprio come le proprietà:

```swift
var myChar = GameCharacter()
myChar.active = true
myChar.takesDamage(200)
myChar.active
// => false
```

### Self

Ogni istanza di una classe ha una proprietà implicita chiamata `self`, che si riferisce all'istanza stessa.
Sebbene venga spesso omesso quando ci si riferisce a proprietà o metodi, `self` è comunemente usato per distinguere i nomi delle proprietà dai nomi dei parametri dei metodi quando hanno lo stesso nome.
