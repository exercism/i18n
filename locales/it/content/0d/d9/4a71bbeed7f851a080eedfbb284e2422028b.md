# Istruzioni

Ti hanno assunto come specialista di espressioni regolari in un'azienda che sta sviluppando un Chatbot.

Il progetto è in una fase di sviluppo molto iniziale, quindi la tua missione è usare le espressioni regolari per migliorare la capacità del chatbot di capire e generare linguaggio naturale.

## Controlla che il comando sia valido

Oltre a essere intelligente, il Chatbot è anche un assistente leale.

Per chiedere qualcosa al chatbot, l'utente deve dire la parola «Chatbot» come prima cosa del comando.

Non importa se la parola chiave è in MAIUSCOLO o in minuscolo. L'aspetto importante qui è la posizione della parola.

Implementa la funzione `isValidCommand()` che aiuta il Chatbot a riconoscere quando l'utente sta impartendo un comando.

```javascript
isValidCommand("Chatbot, play a song from the 80's.";
// => True
isValidCommand("Hey Chatbot, where is the closest pharmacy?";
// => False
isValidCommand("CHATBOT, do you have a solution for this challenge?";
// => True
```

## Rimuovi le emoji criptate

Il Chatbot fa fatica a capire come gli esseri umani usano le emoji per esprimere le proprie emozioni.

Quando il chatbot riceve i messaggi degli utenti, ogni emoji è rappresentata come «_emoji_» seguita dal suo numero _id_.

Implementa il metodo `removeEmoji()` in modo che prenda una stringa e rimuova la codifica di tutte le emoji presenti nel messaggio.

Le righe che non contengono il testo delle emoji devono essere restituite senza modifiche.

Rimuovi solo la stringa dell'emoji. Non cercare di sistemare gli spazi bianchi.

Per questa sfida in particolare, usa la sintassi del costruttore per creare l'espressione regolare.

```javascript
removeEmoji("I love playing videogames emoji3465 it's one of my hobbies");
// => "I love playing videogames  it's one of my hobbies"
```

## Controlla che il numero di telefono sia valido

Dato che le funzionalità del chatbot si scaricano su un'app mobile, ci si aspetta che l'utente scriva un numero di telefono durante la conversazione.

Il problema è che il chatbot sa leggere e validare solo un numero con un formato specifico.

Se il numero è valido (corrisponde alla sequenza di caratteri specificata dall'**espressione regolare**), il chatbot risponde con un messaggio che ringrazia l'utente e conferma il numero. Se il numero non è valido, la funzione informa l'utente che il numero di telefono non è valido.

Il formato atteso è: (+##) ###-###-###

```javascript
checkPhoneNumber('(+34) 659-771-594');
// => "Thanks! You can now download me to your phone."
checkPhoneNumber('659-771-594');
// => "Oops, it seems like I can't reach out to 659-771-594"
```

## Ottieni il link di un sito web

Il Chatbot è un software davvero curioso. Anche se può cercare su internet informazioni su un argomento specifico, gli piace chiedere agli utenti siti web interessanti o URL da cui andare a trovare le informazioni che servono.

Esempio di conversazione:

- **Chatbot**: Ciao username, vorrei imparare a programmare in JavaScript, conosci qualche sito interessante dove potrei imparare?
- **Utente**: Ho imparato molto da [exercism.org](http://exercism.org)

Implementa la funzione `getURL()` che riesce a restituire un array con solo il link di ciascun sito web. Scrivere una regex in grado di riconoscere qualsiasi URL sarebbe molto complicato, ma al Chatbot basta leggere URL semplici. Per questo esercizio, un URL è una qualsiasi sequenza di parole separate da `"."`.

```javascript
getURL(
  'I learned a lot from exercism.org and developer.mozilla.org, but I found ts39.es very boring!',
);
// => ["exercism.org", "developer.mozilla.org", "ts39.es"];
```

## Saluta l'utente

Per memorizzare i dati di tutte le persone con cui ha conversato, il chatbot riesce a ricavare il nome completo dal profilo dell'utente in questo formato: **«smith, john»**.

In questo modo, vogliamo che il nostro chatbot sia davvero educato e faccia una buona impressione.

Scrivi la funzione `niceToMeetYou()` che prende una stringa con il nome completo dell'utente e restituisce la stringa **«Nice to meet you, John Smith»**

A scopo di apprendimento, implementa la funzione usando un **metodo di sostituzione** delle espressioni regolari.

```javascript
let str = 'Smith, John';

niceToMeetYou(str);
// => "Nice to meet you, John Smith"
```
