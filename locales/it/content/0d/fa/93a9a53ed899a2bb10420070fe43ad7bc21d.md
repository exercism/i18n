# Introduzione

## Array

In C#, le strutture dati che possono contenere zero o più elementi sono note come _collezioni_. Un **array** è una collezione che ha una dimensione e una lunghezza fisse e i cui elementi devono essere tutti dello stesso tipo. Gli elementi si possono assegnare a un array o recuperare da esso usando un indice. Gli array in C# sono indicizzati da zero: l'indice del primo elemento è sempre zero.

```csharp
// Declare array with explicit size (size is 2)
int[] twoInts = new int[2];

// Assign second element by index
twoInts[1] = 8;

// Retrieve the second element by index
twoInts[1] == 8; // => true
```

Gli array si possono anche definire con una notazione abbreviata che permette di creare l'array e assegnargli il suo valore contemporaneamente. Dato che ora il compilatore sa quanti elementi avrà l'array, si può omettere la lunghezza:

```csharp
// Three equivalent ways to declare and initialize an array (size is 3)
int[] threeIntsV1 = new int[] { 4, 9, 7 };
int[] threeIntsV2 = new[] { 4, 9, 7 };
int[] threeIntsV3 = { 4, 9, 7 };
```

Si può operare sugli array chiamando i metodi o le proprietà di un'istanza di array, oppure usando i metodi statici definiti nella classe `Array`.

## Cicli for

Un ciclo `for` permette di eseguire più volte lo stesso codice finché non si verifica una condizione.

```csharp
for (int i = 0; i < 5; i++)
{
    System.Console.Write(i);
}

// => 01234
```

Un ciclo `for` è composto da quattro parti:

1. L'inizializzatore: viene eseguito una volta prima di entrare nel ciclo. Di solito serve a definire le variabili usate all'interno del ciclo.
2. La condizione: viene eseguita prima di ogni iterazione del ciclo. Il ciclo continua a essere eseguito finché il suo valore è `true`.
3. L'iteratore: viene eseguito dopo ogni iterazione del ciclo. Di solito serve a modificare (spesso incrementare o decrementare) le variabili del ciclo.
4. Il corpo: il codice che viene eseguito a ogni iterazione del ciclo.

## Cicli foreach

Il fatto che un array sia anche una _collezione_ significa che, oltre ad accedere ai valori tramite indice, puoi iterare su _tutti_ i suoi valori usando un ciclo `foreach`:

```csharp
char[] vowels = new [] { 'a', 'e', 'i', 'o', 'u' };

foreach (char vowel in vowels)
{
    // Output the vowel
    System.Console.Write(vowel);
}

// => aeiou
```
