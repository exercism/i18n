# Introduzione

## Numeri

ABAP ha diversi tipi numerici. In questo esercizio ne userai due:

- `i` per i valori interi, come un numero di giorni.
- `p` per i valori decimali packed, come una tariffa oraria o uno sconto.

```abap
DATA billable_days TYPE i VALUE 22.
DATA rate_per_hour TYPE p LENGTH 8 DECIMALS 2 VALUE '89.89'.
```

I numeri packed definiscono la loro lunghezza massima e il numero di cifre decimali.
Di solito i letterali decimali si scrivono come valori di testo, poi il compilatore li converte nel tipo decimale di destinazione, oppure lo fai tu con `CONV`.

```abap
TYPES discount_rate TYPE p LENGTH 8 DECIMALS 6.

DATA discount TYPE discount_rate.
discount = CONV discount_rate( '0.15' ).
```

### Arrotondamento

ABAP mette a disposizione funzioni numeriche integrate per l'arrotondamento.
La funzione `floor` arrotonda per difetto al numero intero più vicino, mentre `ceil` arrotonda per eccesso al numero intero più vicino.

```abap
DATA full_months TYPE i.
full_months = floor( 70 / 22 ).

DATA rounded_cost TYPE i.
rounded_cost = ceil( '14527.2' ).
```

## Operatori aritmetici

ABAP supporta gli operatori aritmetici per i calcoli con valori numerici.

```abap
DATA day_rate TYPE p LENGTH 8 DECIMALS 2.
day_rate = rate_per_hour * 8.
```

Gli operatori di base sono:

- `+` per l'addizione.
- `-` per la sottrazione.
- `*` per la moltiplicazione.
- `/` per la divisione.
- `MOD` per il resto di una divisione intera.

```abap
DATA remaining_days TYPE i.
remaining_days = num_days MOD 22.
```

ABAP valuta la moltiplicazione e la divisione prima dell'addizione e della sottrazione.
Le parentesi permettono di rendere esplicito l'ordine desiderato.

```abap
DATA discounted_rate TYPE p LENGTH 8 DECIMALS 2.
discounted_rate = monthly_rate * ( 1 - discount ).
```
