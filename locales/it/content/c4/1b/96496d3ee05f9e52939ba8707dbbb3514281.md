# Appendice alle istruzioni

## Registri

| Registro | Utilizzo     | Tipo    | Descrizione                                          |
| -------- | ------------ | ------- | ---------------------------------------------------- |
| `$a0`    | input        | intero  | numero di cifre di input                             |
| `$a1`    | input        | intero  | base per le cifre di input                           |
| `$a2`    | input        | intero  | base per le cifre di output                          |
| `$a3`    | input/output | indirizzo | array sovrascrivibile di parole contenenti le cifre |
| `$v0`    | output       | intero  | numero di cifre di output, -1 se l'input non è valido |
| `$t0-9`  | temporaneo   | qualsiasi | usato per l'archiviazione temporanea                |
