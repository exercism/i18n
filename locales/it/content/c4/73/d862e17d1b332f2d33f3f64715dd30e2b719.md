# Approfondimento

Quando i tipi non possono essere convertiti con un cast implicito, devi usare un [operatore di cast][cast-operator] esplicito. L'operatore di cast non è altro che il tipo di destinazione tra parentesi tonde, davanti al valore che vuoi convertire:

```csharp

int i = 7;
byte b = (byte)i; // Explicit cast from int to byte
```

Usare un cast esplicito è potenzialmente pericoloso. I due errori più comuni sono:

- Eseguire il cast verso un tipo incompatibile. In questo caso viene generata un'eccezione in fase di esecuzione.
- Eseguire il cast verso un valore numerico non abbastanza «ampio». Questo può causare un conflitto di segno o, nel caso degli interi, la generazione di un'eccezione di overflow.

Nota: un'espressione di tipo `int` può essere convertita esplicitamente in `char`. Questo può produrre un `char` non valido.

[cast-operator]: https://docs.microsoft.com/en-us/dotnet/csharp/language-reference/operators/type-testing-and-cast#cast-expression
