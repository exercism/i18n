# Introduzione

## Numeri in virgola mobile

Un numero in virgola mobile è un numero con zero o più cifre dopo il separatore decimale. Alcuni esempi sono `-2.4`, `0.1`, `3.14`, `16.984025` e `1024.0`.

Tipi diversi di numeri in virgola mobile possono memorizzare un numero diverso di cifre dopo il separatore decimale: questa caratteristica si chiama precisione.

C# ha tre tipi in virgola mobile:

- `float`: 4 byte (precisione di circa 6-9 cifre). Si scrive `2.45f`.
- `double`: 8 byte (precisione di circa 15-17 cifre). È il tipo più comune. Si scrive `2.45` o `2.45d`.
- `decimal`: 16 byte (precisione di 28-29 cifre). Si usa normalmente quando si lavora con dati monetari, perché la sua precisione riduce il rischio di errori di arrotondamento. Si scrive `2.45m`.

Come si può vedere, ogni tipo può memorizzare un numero diverso di cifre. Per esempio, se provi a memorizzare PI in un `float`, verranno memorizzate solo le prime 6 cifre decimali (con l'ultima cifra memorizzata arrotondata).

## I cicli while

In questo esercizio potresti voler usare un ciclo. Ci sono diversi modi per scrivere cicli in C#, ma il ciclo `while` è il più adatto qui:

```csharp
int x = 23;

while (x > 10)
{
    // Execute logic if x > 10
    x = x - 2;
}
```

## I cicli do while

Se il codice in un ciclo deve essere eseguito almeno una volta, puoi usare un ciclo `do`/`while`:

```csharp
int x = 23;

do
{
    // Execute body, repeating only if x > 10
    x = x - 2;
} while (x > 10);
```
