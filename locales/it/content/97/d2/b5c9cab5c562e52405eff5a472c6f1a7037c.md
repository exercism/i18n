# Istruzioni

In questo esercizio organizzerai gare tra vari tipi di auto radiocomandate. Ogni auto ha le proprie caratteristiche di velocità e di consumo della batteria.

Le auto partono con la batteria completamente carica (100%). Ogni volta che guidi l'auto con il radiocomando, questa percorre un numero di metri pari alla sua velocità e la percentuale di batteria rimanente diminuisce in base al suo consumo.

Se la batteria di un'auto scende sotto la sua percentuale di consumo, non puoi più guidarla.

Ogni pista ha la sua lunghezza. Le auto vengono messe alla prova verificando se riescono a completare la pista senza esaurire la batteria.

## 1. Crea un'auto radiocomandata

Definisci un array `car` con i seguenti elementi:

- speed
- battery_drain
- battery
- distance_traveled

Per creare un'auto radiocomandata, definisci una funzione `new_car` che prende come parametri la velocità dell'auto in metri e la percentuale di consumo della batteria, e restituisce un array `car`.

Per un'auto nuova, la batteria è al 100% e la distanza percorsa è zero.

```R
speed <- 5
battery_drain <- 2
car <- new_car(speed, battery_drain)
str(car)
#> List of 4
#>  $ speed             : num 5
#>  $ battery_drain     : num 2
#>  $ battery           : num 100
#>  $ distance_traveled : num 0
```

## 2. Crea una pista

Definisci un altro array chiamato `track` con il singolo elemento `track_length`.
Per creare una pista, definisci una funzione `new_track` che prende la distanza della pista in metri:

```R
track_length <- 800
track <- new_track(track_length)
str(track)
#> List of 1
#>  $ track_length: num 800
```

## 3. Controlla se la batteria è scarica

Implementa la funzione `battery_drained()` che indica se la batteria è scarica.
Una batteria è considerata scarica quando non c'è abbastanza carica per muoversi un'altra volta.

```R
speed <- 5;
battery_drain <- 2;
car <- new_car(speed, battery_drain);
car <- drive(car);

battery_drained(car);
#> [1] FALSE
```

## 4. Guida l'auto

Implementa la funzione `drive` che aggiorna il numero di metri percorsi in base alla velocità dell'auto e riduce la batteria in base al consumo della stessa.
Se non c'è abbastanza batteria per guidare un'altra volta, l'auto non si muove.

```R
speed <- 5
battery_drain <- 2
car <- new_car(speed, battery_drain)
car <- drive(car)
str(car)
#> List of 4
#>  $ speed             : num 5
#>  $ battery_drain     : num 2
#>  $ battery           : num 98
#>  $ distance_traveled : num 5
```

## 5. Controlla se un'auto radiocomandata può completare una gara

Per completare una gara, un'auto deve riuscire a percorrere tutta la lunghezza della pista. Questo significa non esaurire la batteria prima di aver tagliato il traguardo.

Implementa la funzione `can_finish` che prende un `car` e un `track` come parametri e restituisce `TRUE` se l'auto può completare la gara; altrimenti restituisce `FALSE`.

Supponi di essere sulla linea di partenza della gara e di accendere il motore dell'auto per partire. Tieni presente che la batteria dell'auto potrebbe non essere completamente carica all'inizio della gara.

```R
speed <- 5
battery_drain <- 5
car <- new_car(speed, battery_drain)

name <- "track1"
track_length <- 100
track <- new_track(track_length)

can_finish(car, track)
#> [1] TRUE

# partial battery charge
car$battery <- 50
can_finish(car, track)
#> [1] FALSE
```

## 6. Memorizza se l'auto può completare una pista con la batteria carica

Hai creato diverse piste di lunghezze diverse e devi memorizzare se l'auto può completarle quando è completamente carica.

Implementa la funzione `store_track` che prende un'auto, una pista e il nome di una pista, e restituisce un'auto aggiornata con un elemento in più.
Questo elemento deve avere il `name` della pista, e il valore deve essere un sotto-array con il `track_length` e se l'auto può `complete`-arla.

L'auto passata come argomento potrebbe non essere completamente carica, quindi assicurati di reimpostare la batteria e la distanza percorsa prima di usarla.

```R
speed <- 5
battery_drain <- 5
car <- new_car(speed, battery_drain)
car$battery <- 50

name <- "track1"
track_length <- 100
track <- new_track(track_length)

track1 <- store_track(car, track, "Imola")
str(track1)
#> List of 5
#>  $ speed             : num 5
#>  $ battery_drain     : num 5
#>  $ battery           : num 100
#>  $ distance_traveled : num 0
#>  $ Imola             :List of 2
#>   ..$ track_length: num 100
#>   ..$ complete    : logi TRUE
```
