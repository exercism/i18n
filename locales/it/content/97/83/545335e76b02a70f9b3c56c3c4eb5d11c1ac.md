# Istruzioni

In questo esercizio scriverai del codice per aiutarti a prepararti all'acquisto di un veicolo.

Ci sono tre compiti: uno per determinare se ti serve una patente, uno per aiutarti a scegliere tra due veicoli e uno per stimare il prezzo accettabile di un veicolo usato.

## 1. Determina se ti servirà la patente di guida

Alcuni tipi di veicolo richiedono una patente di guida per essere guidati.
Assumi che solo i tipi `"car"` e `"truck"` richiedano una patente, tutti gli altri si possono guidare senza.

Implementa la funzione `needs_license(kind)` che prende il tipo di veicolo come stringa e restituisce un booleano che indica se ti serve una patente per quel tipo di veicolo.

```cpp
needs_license("car")
// => true

needs_license("bike")
// => false

needs_license("truck")
// => true
```

## 2. Scegli tra due potenziali veicoli da comprare

Valuti le opzioni tra i veicoli disponibili.
Riesci a restringerle a due, ma ti serve aiuto per prendere la decisione finale.
Per questo, implementa la funzione `choose_vehicle(option1, option2)` che prende due veicoli come argomenti e restituisce una decisione che include l'opzione che viene prima in ordine lessicografico.

```cpp
choose_vehicle("Wuling Hongguang", "Toyota Corolla")
// => "Toyota Corolla is clearly the better choice."

choose_vehicle("Volkswagen Beetle", "Volkswagen Golf")
// => "Volkswagen Beetle is clearly the better choice."
```

La stringa restituita dovrebbe seguire lo schema `"<CHOSEN_VEHICLE> is clearly the better choice."`, dove `<CHOSEN_VEHICLE>` è l'opzione scelta tra gli argomenti passati.

## 3. Calcola una stima del prezzo di un veicolo usato

Ora che hai preso una decisione, vuoi assicurarti di ottenere un prezzo equo dal concessionario.
Dato che ti interessa comprare un veicolo usato, il prezzo dipende da quanto è vecchio il veicolo.
Per una stima approssimativa, assumi che se il veicolo ha meno di 3 anni costi l'80% del prezzo originale che aveva quando era nuovo di zecca.
Se ha almeno 10 anni, costa il 50%.
Se il veicolo ha almeno 3 anni ma meno di 10, costa il 70% del prezzo originale.

Implementa la funzione `calculate_resell_price(original_price, age)` che applica questa logica usando `if`, `else if` e `else` (ci sono altri modi, se vuoi esercitarti).
Prende il prezzo originale e l'età del veicolo come argomenti e restituisce il prezzo stimato dal concessionario.

```cpp
calculate_resell_price(1000, 1)
// => 800

calculate_resell_price(1000, 5)
// => 700

calculate_resell_price(1000.0, 15)
// => 500
```

> Nota: il valore restituito è di tipo `double`.
