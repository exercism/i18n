# Appendice alle istruzioni

## Informazioni specifiche di Arturo

In questo esercizio ti verrà chiesto di restituire le età usando una [grandezza fisica][physical-quantities] con un'unità personalizzata che rappresenta la durata di un singolo anno su quel pianeta.
In Arturo, una quantità è composta da un valore numerico e da una [unità di misura][unit-of-measurement] associata.

```arturo
length: 10`m
units length ; `m
scalar length ; 10

10`m * 10`m ; 100 m²
```

~~~~exercism/caution
L'unità `yr integrata di Arturo corrisponde a 31556952 secondi.
Quindi dovrai definire e usare una tua unità di anno, in termini del numero di secondi a cui si fa riferimento prima nelle istruzioni.
~~~~

Le quantità possono essere [convertite][convert] in un'altra unità compatibile.
```arturo
convert 1`m `ft ; 1250/381 ft
convert 100`m2 `ft2 ; 156250000/145161 ft²

property `m  ; length
property `m2 ; area

convert 1`m `m2 ; conversion error results
```

~~~~exercism/note
A causa dei limiti di precisione dei numeri in virgola mobile, a volte Arturo memorizza lo scalare come numero razionale.
La [funzione `to`][to] può essere usata per ottenere invece il valore come numero in virgola mobile approssimativo.

```arturo
length: convert 1`m `ft ; 1250/381 ft
to :floating length ; 3.280839895013123
```

[to]: https://arturo-lang.io/documentation/library/types/to/
~~~~

Arturo ci permette anche di [specificare][specify] unità personalizzate per le quantità.

```arturo
specify 'nauMile 1.151`mi
property `nauMile length
specify 'lea 3.00579`nauMile
property `lea ; length
depth: 20000`lea
convert depth `km ; 111355.7993425152 km
```
