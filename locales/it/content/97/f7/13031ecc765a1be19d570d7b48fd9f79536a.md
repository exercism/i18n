# Test

Per eseguire il test tramite DrRacket, è sufficiente aprire il file di test e fare clic sul pulsante "Run" in alto a destra.

Per eseguire il test dalla riga di comando, esegui il test dalla directory dell'esercizio con il comando seguente:

```
raco test <exercise>-test.rkt
```

dove `<exercise>` va sostituito con lo slug dell'esercizio.
