# Introduzione

Oltre alle classi di caratteri e ai quantificatori, le espressioni regolari possono descrivere *struttura* e *contesto*. Queste funzionalità vivono nello stesso vocabolario [`regexp`][regexp] e nello stesso letterale `R/ /`.

Le parentesi tonde `( )` raggruppano parte di un pattern, così un quantificatore o un `|` («questo o quello») si applica all'intero gruppo; un `?` dopo un gruppo lo rende opzionale:

```factor
USING: regexp ;

"abab"    R/ (ab)+/ matches? .             ! => t
"$100"    R/ \$\d+(\.\d{2})?/ matches? .   ! => t   (optional group)
```

Le ancore fissano un pattern a una posizione: `^` (inizio), `$` (fine) e `\b` (un confine di parola).

Un *lookaround* verifica la corrispondenza in base a ciò che circonda un punto, senza consumarlo:

```
(?=...)    ! lookahead — ... must follow
(?!...)    ! negative lookahead — ... must not follow
(?<=...)   ! lookbehind — ... must come before
```

```factor
USING: regexp ;

"spent $100 and $25" R/ (?<=\$)\d+/ all-matching-subseqs .
! => { "100" "25" }

"up 5% then 12%" R/ \d+(?=%)/ all-matching-subseqs .
! => { "5" "12" }
```

Una lettera di opzione dopo la `/` di chiusura cambia l'intero pattern; `i` lo rende insensibile alle maiuscole:

```factor
USING: regexp ;

"REFUND" R/ refund/i matches? .   ! => t
```

Factor usa il lookaround al posto dei gruppi di cattura: non ha estrazione dei gruppi di cattura, back-reference né quantificatori lazy.

[regexp]: https://docs.factorcode.org/content/vocab-regexp.html
