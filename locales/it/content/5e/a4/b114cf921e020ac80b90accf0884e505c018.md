# Riferimento su Rust

## Concetti

Gli esercizi sui concetti di Rust insegnano i concetti, dalle basi fino alla padronanza del linguaggio. Sono classificati ed elencati di seguito.

I concetti di Exercism esistono per servire chi impara in modo pratico, e per questo differiscono dalle idee astratte. Questo documento definisce cosa significano questi concetti in Rust. Abbiamo aggiunto qui sotto un raggruppamento visivo per aiutare i maintainer del track a creare un documento di riferimento efficace. Tali raggruppamenti _non_ costituiscono divisioni pedagogiche. Quindi non farvi riferimento mentre insegni.

Le caselle di controllo indicano se i concetti sono già insegnati nell'elenco di mappatura degli esercizi.

## Mappatura degli esercizi sui concetti

L'ideale sarebbe avere un singolo esercizio sul concetto per ognuno dei concetti elencati sopra,
che insegni esattamente un concetto e richieda solo i suoi prerequisiti,
ma farlo non è del tutto pratico. Per esempio, sarebbe difficile progettare un esercizio
che insegni cosa sono le funzioni senza richiedere alcuna conoscenza dei tipi primitivi; allo stesso modo,
sarebbe difficile insegnare i tipi primitivi, con una suite di test, senza alcuna conoscenza delle funzioni.

Gli esercizi in questa tabella dovrebbero formare un DAG che alla fine coprirà tutti i concetti elencati sopra.

| esercizio                | prerequisiti                                 | insegna                                                  | narrazione                                                                       |
| ------------------------ | -------------------------------------------- | -------------------------------------------------------- | -------------------------------------------------------------------------------- |
| `hello-world`            | -                                            | funzioni, suite di test                                  | restituisci il letterale `&str` `"hello world"`                                  |
| `compiled-calculator`    | `hello-world`                                | interi, assegnazione di variabili                        | esegui una serie di operazioni matematiche e restituisci implicitamente il risultato |
| `conditionals`           | `hello-world`                                | condizionali                                             | dovrebbe strutturarsi come `if` / `else if` / `else` a 3 rami; return implicito  |
| `slices`                 | `hello-world`, `compiled-calculator`         | slice                                                    | estrai uno slice da un parametro che è uno slice di interi                       |
| `loops`                  | `slices`                                     | iterazione di base su uno slice                          | idealmente con un return anticipato, così da renderlo complicato da esprimere come iteratore |
| `iterator-use`           | `slices`                                     | uso degli iteratori, `collect`                           |                                                                                  |
| `integer-sizes`          | `compiled-calculator`                        | interi diversi da `i32`, casting                         | comunque tutti con segno                                                        |
| `unsigned-ints`          | `integer-sizes`                              | interi senza segno                                       |                                                                                  |
| `indexing`               | `integer-sizes`, `slices`                    | indicizzazione, `usize`                                  |                                                                                  |
| `floats`                 | `compiled-calculator`                        | numeri in virgola mobile                                 | probabilmente lo stesso esercizio del calcolatore compilato, con risultati non interi |
| `bools`                  | `compiled-calculator`                        | booleani, operatori booleani                             |                                                                                  |
| `char`                   | `compiled-calculator`                        | tipo di dato `char`                                      | dovrebbe includere qualche esempio di caratteri wide                            |
| `str-use`                | `char`, `slices`                             | `&str`                                                   | nota: immutabile!                                                                |
| `string-use`             | `str-use`                                    | `String`                                                 | nota: posseduto, mutabile                                                        |
| `format-macro`           | `string-use`                                 | macro `format!`                                          |                                                                                  |
| `str-vs-string`          | `str-use`, `string-use`                      | combinare, convertire, costi, ecc.                       |                                                                                  |
| `generics-basics`        | `integer-sizes`, `floats`                    | usare trait esterni come vincoli, generici di base       | probabilmente sempre il calcolatore compilato, solo generico                     |
| `structs`                | `string-use`, `unsigned-ints`, `floats`      | creare e usare una struct per gestire i dati             | `Person` ha nome, altezza e quantità di scarpe possedute                         |
| `implicit-return`        | `compiled-calculator`                        | scope, espressioni, return implicito                     |                                                                                  |
| `explicit-return`        | `implicit-return`, `conditionals`            | istruzione `return` esplicita                            |                                                                                  |
| `methods`                | `structs`, `explicit-return`                 | blocchi `impl`, metodi                                   |                                                                                  |
| `tuples`                 | `structs`                                    | tuple                                                    | insegna come struct anonime; insegna la sintassi `.0`                            |
| `tuple-structs`          | `tuples`, `structs`                          | tuple struct (tuple con nome)                            |                                                                                  |
| `basic-enums`            | `unsigned-ints`                              | enum di base (senza campi), `match`                      |                                                                                  |
| `enums`                  | `basic-enums`, `tuple-structs`               | sintassi delle tuple per le varianti degli enum          |                                                                                  |
| `option`                 | `enums`                                      | `Option<T>`                                              |                                                                                  |
| `result`                 | `enums`                                      | `Result<T, E>`                                           |                                                                                  |
| `mutability`             | `compiled-calculator`                        | immutabilità per impostazione predefinita; mutabilità esplicita |                                                                          |
| `let-expressions`        | `loops`, `option`, `result`                  | `if let`, `while let`                                    | probabilmente dipenderà solo da `option` o da `result`, a seconda dell'implementazione |
| `vectors`                | `slices`                                     | `Vec<T>`                                                 |                                                                                  |
| `hashmaps`               | `vectors`                                    | `Hashmap<K, V>`                                          |                                                                                  |
| `entry-api`              | `hashmaps`                                   | Entry API                                                |                                                                                  |
| `hashsets`               | `hashmaps`                                   | `HashSet<K>`                                             |                                                                                  |
| `btreemaps`              | `hashmaps`                                   | `BTreeMap<K, V>`                                         |                                                                                  |
| `deriving-traits`        | `structs`                                    | `PartialEq`, `PartialOrd`, `Debug`, `Display`, `Default` |                                                                                  |
| `implementing-traits`    | `deriving-traits`                            | implementare manualmente un trait                        | probabilmente implementa `Iterator`                                              |
| `collection-conversions` | `vectors`, `hashsets`, `implementing-traits` | `FromIterator`, `IntoIterator`                           |                                                                                  |
