# Informazioni

[`fold`][fold] è un [adattatore di iteratore che consuma][consuming iterator adaptor], che applica una funzione a ogni elemento dell'iterazione, accumulando il risultato in un nuovo valore.

Ogni iterazione di `fold` prende due argomenti. Il primo è un valore iniziale per l'accumulatore. Il secondo è una closure che a sua volta prende due argomenti: l'accumulatore e un elemento. Il valore restituito dalla closure è il valore successivo dell'accumulatore.
Una volta che l'iteratore si esaurisce, viene restituito il valore finale dell'accumulatore.

`fold` può essere usato quando si desidera trasformare una collezione in un unico valore. Ad esempio, se si desidera la somma di tutti i numeri pari

```rust
pub fn main() {
    let even_sum = (1..=10).fold(0, |acc, num| if num % 2 == 0 { acc + num } else { acc });
    println!("{even_sum:?}");
}
```

Stampa `30`.

Quello che si può fare con `fold` spesso può essere fatto con un'altra funzione o con più funzioni. Per l'esempio sopra, usare [`filter`][filter] su `(1..=10)` e poi [`sum`][sum] sarebbe meno verboso e darebbe lo stesso risultato, così

```rust
(0..=10).filter(|n| *n % 2 == 0).sum()
```

Altre funzioni usate più comunemente di `fold` includono [`product`][product] e [`collect`][collect].

Un accumulatore può essere usato per valori diversi da quelli numerici. Ad esempio

```rust
pub fn giant_grunts(initial: char) -> String {
    ["Bee", "Fee", "Gee", "Fi", "Hi", "Fo", "Mo", "Fum", "Tum"].iter().fold(
        String::new(),
        |acc, grunt| if grunt.starts_with(initial) { acc + grunt } else { acc },
    )
}

pub fn main() {
    let song = giant_grunts('F');
    println!("{song:?}");
}
```

Stampa `FeeFiFoFum`
