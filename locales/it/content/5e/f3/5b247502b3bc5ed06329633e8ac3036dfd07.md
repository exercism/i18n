# Informazioni

Un'[istruzione switch][switch] confronta un valore con più pattern corrispondenti possibili.
È un'alternativa più pulita e leggibile rispetto a una catena di più istruzioni `if-else`.

Un'istruzione `switch` inizia con la parola chiave `switch`, seguita dal valore da verificare.
Ogni possibile corrispondenza è introdotta dalla parola chiave `case`.
La parola chiave `default` definisce un caso di riserva che viene eseguito se nessuno dei casi espliciti corrisponde.
Come le catene `if-else`, un'istruzione `switch` esegue solo il blocco di codice associato al primo caso corrispondente.

```swift
switch value {
case 1:
    print("One")
case 2:
    print("Two")
default:
    print("Other")
}
```

Considera la seguente catena `if-else`:

```swift
if str == "apple" {
    print("Let's bake an apple crumble")
} else if str == "lemon" {
    print("Let's bake a lemon meringue pie!")
} else if str == "peach" {
    print("Let's bake a peach pie!")
} else {
    print("Let's buy ice cream.")
}
```

Lo stesso codice si può scrivere in modo più chiaro con un'istruzione `switch`:

```swift
switch str {
case "apple":
    print("Let's bake an apple crumble")
case "lemon":
    print("Let's bake a lemon meringue pie!")
case "peach":
    print("Let's bake a peach pie!")
default:
    print("Let's buy ice cream.")
}
```

## Binding dei valori e clausole where

Un caso di `switch` può associare i valori corrispondenti a costanti o variabili temporanee, da usare nel corpo di quel caso.
I casi possono anche includere una clausola `where` per verificare condizioni booleane aggiuntive prima della corrispondenza:

```swift
let x = 1337
switch sumOfDivisors(of: x) {
case let total where total == x:
    print(total, "is a perfect number")
default:
    print(x, "is not a perfect number")
}
```
