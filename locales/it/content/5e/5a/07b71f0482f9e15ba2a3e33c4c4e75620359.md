# Introduzione

`when` è la parola chiave per filtrare le eccezioni. Va inserita dopo
l'istruzione catch e può accettare un'espressione booleana che contenga qualsiasi
valore sia nello scope in quel momento. Se l'espressione restituisce true, viene eseguito il blocco associato a quella istruzione `catch`, altrimenti si passa a controllare la successiva istruzione `catch`, se c'è.

```csharp
try
{
    // do stuff
}
catch (Exception ex) when (ex.Message != "")
{
    // output the message when it is not empty
}
catch (Exception ex)
{
    // show stack trace or something.
}
```
