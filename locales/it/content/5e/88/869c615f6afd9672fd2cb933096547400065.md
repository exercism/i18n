# Istruzioni

Sei un appassionato osservatore di uccelli che tiene un conteggio giornaliero degli uccelli che visitano il tuo giardino. I conteggi sono memorizzati in un array, con il giorno più vecchio per primo.

## 1. Il conteggio di oggi

Definisci `today` in modo che prenda dallo stack l'array dei conteggi giornalieri e restituisca il conteggio di oggi.

```factor
{ 2 5 0 7 4 1 } today .
! => 1
```

## 2. Incrementa il conteggio di oggi

Definisci `increment-todays-count` in modo che restituisca un nuovo array con il conteggio di oggi aumentato di uno. L'array originale non deve essere modificato.

```factor
{ 2 5 0 7 4 1 } increment-todays-count .
! => { 2 5 0 7 4 2 }
```

## 3. C'è stato un giorno senza uccelli?

Definisci `has-day-without-birds?` in modo che restituisca `t` se almeno un giorno ha registrato zero uccelli, altrimenti `f`.

```factor
{ 2 5 0 7 4 1 } has-day-without-birds? .
! => t

{ 2 5 1 } has-day-without-birds? .
! => f
```

## 4. Somma i primi giorni

Definisci `count-for-first-days` in modo che prenda un array di conteggi e un numero `n`, e restituisca la somma dei primi `n` conteggi.

```factor
{ 2 5 0 7 4 1 } 4 count-for-first-days .
! => 14
```

## 5. Conta i giorni intensi

Un giorno intenso è un giorno con cinque o più uccelli. Definisci `busy-days` in modo che restituisca il numero di giorni intensi nell'array.

```factor
{ 2 5 0 7 4 1 } busy-days .
! => 2
```

## 6. Riempi i giorni mancanti

Se non hai osservato in ogni giorno di un periodo di `n` giorni, riempi con `0` i giorni mancanti in coda. Definisci `pad-missing-days` in modo che prenda un array di conteggi e una lunghezza obiettivo `n`, e restituisca un array di lunghezza almeno `n` le cui posizioni extra sono `0`. I conteggi esistenti devono essere preservati invariati; se l'input è già lungo almeno `n`, restituiscilo invariato.

```factor
{ 2 5 0 } 7 pad-missing-days .
! => { 2 5 0 0 0 0 0 }

{ 4 1 6 8 } 3 pad-missing-days .
! => { 4 1 6 8 }
```
