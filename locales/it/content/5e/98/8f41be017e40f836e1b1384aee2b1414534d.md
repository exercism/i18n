# Test sul track MoonScript

Testare sul track MoonScript è esattamente come [testare sul track Lua][lua-tests].
Da una directory di un esercizio, digita:

```console
$ busted
```

## Test in sospeso

Questo track segue la metodologia [Test-Driven Development][tdd] di Exercism.
Ti viene fornita una suite di test completa, ma solo il primo test è «attivo».

Per abilitare i test, cambia il comando di un test da `pending` a `it`.

Se ti piace eseguire sempre tutti i test, puoi usare uno strumento a riga di comando per cambiarli tutti in una volta.
Ecco un esempio che usa perl (che è installato praticamente ovunque):

```console
$ perl -i -pe 's/^\s+\Kpending\b/it/' two_fer_spec.moon
```

Quando lavori nell'editor online, il test runner eseguirà automaticamente tutti i test.

## Usare LuaRocks

Lua di per sé è un linguaggio molto piccolo.
[LuaRocks][luarocks] è il gestore di pacchetti per i moduli Lua.

Sei libero di usare qualsiasi modulo nelle soluzioni, ma non tutti saranno disponibili nel test runner online.
Il test runner mette a disposizione questi:

**Già disponibili come dipendenze di `busted`**

* [penlight][penlight-home]
* [dkjson][dkjson-home]

**Già disponibili come dipendenze di MoonScript**

* [LPeg][lpeg-home]
* [LuaFileSystem][lfs-home]

**Data e ora**

* [date][date-home]
* [lua-tz][lua-tz-home]
* [luatz][luatz-home]
