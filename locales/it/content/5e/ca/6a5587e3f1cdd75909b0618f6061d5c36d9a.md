# Eseguire i test

Scegli il tuo sistema operativo:

- [Windows](#windows)
- [macOS](#macos)
- [Linux](#linux)

## Windows

1. Apri il Command Prompt.
2. Scarica il primo esercizio:

   ```batchfile
   C:\Users\JohnDoe>exercism download --exercise hello-world --track java
   ```

3. Entra nella cartella dell'esercizio:

   ```batchfile
   C:\Users\JohnDoe>cd C:\Users\JohnDoe\exercism\java\hello-world
   ```

4. Esegui i test:

   ```batchfile
   C:\Users\JohnDoe>gradlew.bat test
   ```

   _(Non preoccuparti se all'inizio i test falliscono: è così che si comincia ogni esercizio.)_

5. Risolvi l'esercizio. Trova e segui la guida `instructions.append.md` ([visualizzala su GitHub][hello-world-tutorial]).

Buona fortuna! Divertiti!

## macOS

1. Nella finestra del terminale, scarica il primo esercizio:

   ```sh
   exercism download --exercise hello-world --track java
   ```

2. Entra nella cartella dell'esercizio:

   ```sh
   cd /Users/johndoe/exercism/java/hello-world
   ```

3. Esegui i test:

   ```sh
   ./gradlew test
   ```

   _(Non preoccuparti se all'inizio i test falliscono: è così che si comincia ogni esercizio.)_

4. Risolvi l'esercizio. Trova e segui la guida `instructions.append.md` ([visualizzala su GitHub][hello-world-tutorial]).

Buona fortuna! Divertiti!

## Linux

1. Nella finestra del terminale, scarica il primo esercizio:

   ```sh
   exercism download --exercise hello-world --track java
   ```

2. Entra nella cartella dell'esercizio:

   ```sh
   cd /home/johndoe/exercism/java/hello-world
   ```

3. Esegui i test:

   ```sh
   ./gradlew test
   ```

   _(Non preoccuparti se all'inizio i test falliscono: è così che si comincia ogni esercizio.)_

   Se ricevi il seguente errore:

   ```sh
   ./gradlew: Permission denied
   ```

   Allora al file manca il permesso di esecuzione. Per risolvere, esegui:

   ```sh
   chmod +x ./gradlew
   ```

   E ora dovresti riuscire a eseguire il comando precedente.

4. Risolvi l'esercizio. Trova e segui la guida `instructions.append.md` ([visualizzala su GitHub][hello-world-tutorial]).

Buona fortuna! Divertiti!
