# Introduzione

Esistono fondamentalmente due tipi di cicli:

1. Ripetere finché una condizione non è soddisfatta.
2. Iterare sugli elementi di una collezione.

Entrambi sono possibili in R, anche se il primo potrebbe essere più comune.

## `while` e `repeat`

Per problemi aperti, in cui non si sa in anticipo quante volte ripetere il ciclo, R ha il ciclo `while` con una condizione e il ciclo `repeat` senza condizione (equivalente a `while (TRUE)`).

La forma di base è piuttosto semplice:

```R
while (condition) {
  do_something()
}
```

In questo caso, il programma continuerà a ripetere il ciclo finché `condition` non è più `TRUE`.

Sono disponibili due modi per uscire anticipatamente dal ciclo:

- Un `break` fa uscire dal ciclo, con l'esecuzione che prosegue dalla riga successiva alla parentesi graffa `}` di chiusura del ciclo.
- Un `return(x)` interrompe l'esecuzione della funzione corrente, restituendo al chiamante il valore restituito `x`.

Con queste opzioni disponibili, a volte può essere comodo creare un ciclo «infinito» con `repeat { ... }` e poi affidarsi alla ricerca di una condizione di arresto all'interno del corpo del ciclo per attivare un `break` o un `return`.

Queste tre varianti sono equivalenti e terminano tutte con `x == 0.4444...`

```R
x <- 12
while (x > 1) {
  x <- x / 3
}

x <- 12
while (TRUE) {
  x <- x/3
  if (x <= 1) break
}

x <- 12
# no boolean clause 
repeat { 
  x <- x/3
  if (x <= 1) break
}
```

## Iterare su un vettore

In R spesso non è necessario.
Come discusso in altri concetti, molte funzioni operano su interi vettori.

Tuttavia, a volte i cicli espliciti sono inevitabili.
Questo è particolarmente vero quando:

- Il corpo del ciclo ha effetti collaterali, come la stampa o l'I/O su file.
- Il ciclo continua finché non si raggiunge un certo criterio, dopo un numero imprevedibile di iterazioni.

La condizione del ciclo deve essere racchiusa tra parentesi tonde.
Come per i corpi delle funzioni, le parentesi graffe sono facoltative (ma spesso presenti) per i corpi di ciclo su una sola riga.

```R
words <- c("This", "is", "a", "loop")
for (w in words) { print(w) } # the braces are optional here
#> [1] "This"
#> [1] "is"
#> [1] "a"
#> [1] "loop"
```

Se l'iterazione corrente non soddisfa una certa condizione, è possibile passare subito all'iterazione successiva con un `next`:

```R
for (n in 1:10) {
    if (is_useless(n)) next
     
    # we decided this iteration could be useful
    do_something_slow(n)
}
```

Se serve l'indice numerico, usa `seq_along()`.

```R
v <- LETTERS[1:3]
v
#> [1] "A" "B" "C"

for (i in seq_along(v)) { print(sprintf("%s%i", v[i], i)) }
#> [1] "A1"
#> [1] "B2"
#> [1] "C3"
```

Usare `i in 1:length(v)` _non_ è consigliato, perché può causare problemi quando `length(v)` è zero.
L'intervallo `1:0` è equivalente a `c(1, 0)`, quindi il corpo del ciclo verrà eseguito e probabilmente fallirà.
La funzione `seq_along()` è progettata per gestire correttamente questo caso.
