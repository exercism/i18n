# Informazioni

Le [espressioni switch][switch-expressions] si comportano in modo simile alle [istruzioni switch][switch-statements] trattate in [concept:csharp/switch-statements](). Supportano una sorta di tabella decisionale che associa le condizioni di input ad azioni o valori.

Al centro dell'espressione switch c'è il _pattern matching_. Nell'esercizio di programmazione abbiamo confrontato i valori con i pattern `const`. In questo caso gli input dello `switch` sono un'_espressione di intervallo_ che viene confrontata con valori `const` e con i valori usati dalle _guardie di caso_.

I casi (detti anche _bracci dello switch_) vengono valutati nell'ordine in cui sono scritti: il processo si interrompe e il valore associato viene restituito non appena si trova una corrispondenza.

Il caso `_`, che è l'ultimo della lista, è utile per assicurarsi che la corrispondenza sia esaustiva ed evitare possibili errori in fase di esecuzione.

```csharp
double xx = 42d;

string interesting = xx switch
{
    0 => "I suppose zero is interesting",
    3.14 when DateTime.Now.Day == 14 && DateTime.Now.Month == 3 => "Mmm pie!",
    3.14 => "π",
    42 => "a bit of a cliché",
    1729 => "only if you are a pure mathematician",
    _ => "not interesting"
};

// => interesting == "a bit of a cliché"
```

Un «braccio» dello `switch` viene selezionato quando il pattern corrisponde alla variabile di intervallo e qualsiasi guardia di caso restituisce true.

Le espressioni switch supportano anche i [pattern di tipo][pattern-matching] e la corrispondenza ricorsiva.
