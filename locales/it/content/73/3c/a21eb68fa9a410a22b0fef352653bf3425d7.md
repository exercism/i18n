# Test

Puoi usare l'editor online sul sito di Exercism per risolvere gli esercizi.
Oppure scarica gli esercizi sul tuo computer, risolvili in locale e poi inviali a Exercism.
Il resto di questo documento parla di come lavorare in locale.

## Exercism CLI

Ti servirà lo strumento da riga di comando `exercism` per scaricare e inviare gli esercizi.
Vedi [la documentazione della CLI di Exercism][exercism-cli] per le istruzioni su come scaricarla e configurarla.

Per scaricare un esercizio, fai così:

```bash
exercism download --track 8th --exercise hello-world
```

E spostati nella directory dell'esercizio:

```bash
cd /path/to/your/exercism_workspace/8th/hello-world
```

oppure, se usi Windows:

```cmd
cd \path\to\your\exercism_workspace\8th\hello-world
```

Tieni presente che puoi ottenere il tuo workspace di Exercism con il comando `exercism configure`.

## Eseguire i test in locale

Per eseguire i test di un esercizio, devi trovarti nella directory corretta dell'esercizio.
Poi avvia i test con questo comando:

```bash
8th -f test.8th
```

## Test saltati

Risolvere un esercizio significa far passare tutti i suoi test.
Per impostazione predefinita, quando esegui i test viene eseguito un solo test (il primo).
È una scelta intenzionale: ti permette di concentrarti solo sul far passare quel singolo test.
Una volta che passa, puoi abilitare il test successivo spostando la riga `SKIP-REST-OF-TESTS` sotto di esso.

### Eseguire anche i test saltati

Per eseguire tutti i test, compresi quelli dopo la parola `SKIP-REST-OF-TESTS`, puoi impostare la variabile d'ambiente `RUN_ALL_TESTS` al valore `true`.
Un modo per impostarla solo per la durata dell'esecuzione dei test è questo (macOS e Linux):

```bash
RUN_ALL_TESTS=true 8th -f test.8th
```

## Invia la soluzione

Per caricare la soluzione sul sito di Exercism usando lo strumento exercism:

```bash
exercism submit
```

Tieni presente che puoi caricare il tuo codice anche se non passa tutti i test.
È utile se sei bloccato e ti serve l'aiuto di un mentore.
