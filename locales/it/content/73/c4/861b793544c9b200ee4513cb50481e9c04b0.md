# Introduzione

Quando il cast implicito tra i tipi non è possibile, devi usare un operatore di cast esplicito.
L'operatore di cast non è altro che il tipo di destinazione tra parentesi, davanti al valore su cui vuoi fare il cast:

```csharp

int i = 7;
byte b = (byte)i; // Explicit cast from int to byte
```
