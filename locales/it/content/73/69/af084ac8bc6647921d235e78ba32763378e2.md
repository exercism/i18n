# Istruzioni

Lavori come amministratore di sistema per una grande azienda a Monaco di Baviera, in Germania. Una delle tue responsabilità è gestire gli account email.

Hai sentito le lamentele di alcune persone che dicono di non riuscire a scrivere email al signor Müller. Ti rendi presto conto che gran parte dell'azienda usa un vecchio client di posta che non riconosce `müller@firma.de` come un indirizzo email valido, a causa del carattere non ASCII.

Dire alle persone di rinunciare al loro vecchio client di posta preferito è una battaglia persa, quindi decidi di creare degli alias ripuliti per tutti gli account email.

## 1. Ripulisci i nomi utente esistenti rimuovendo tutto tranne le lettere minuscole

Implementa la funzione `sanitize/1`. Deve accettare un nome utente come charlist e restituire il nome utente con tutti i caratteri rimossi tranne le lettere minuscole.

```elixir
Username.sanitize(~c"schmidt1985")
# => ~c"schmidt"
```

## 2. Consenti gli underscore

Estendi la funzione `sanitize/1`. Non deve rimuovere gli underscore dal nome utente.

```elixir
Username.sanitize(~c"mark_fischer$$$")
# => ~c"mark_fischer"
```

## 3. Sostituisci i caratteri tedeschi

Nell'alfabeto tedesco ci sono 4 caratteri non ASCII, e tutti hanno dei sostituti ASCII comunemente riconosciuti.

| Carattere tedesco | Sostituto ASCII |
| ----------------- | --------------- |
| ä                | ae               |
| ö                | oe               |
| ü                | ue               |
| ß                | ss               |

Estendi la funzione `sanitize/1`. Deve sostituire i caratteri tedeschi secondo la tabella. Puoi presumere tranquillamente che tutti i nomi utente siano già in minuscolo.

```elixir
Username.sanitize(~c"cäcilie_weiß")
# => ~c"caecilie_weiss"
```
