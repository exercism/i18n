# Test

Spostati nella directory che contiene il file `${slug}_test.sql` appropriato, dove `${slug}` è il nome dell'esercizio, con i trattini al posto degli spazi e tutto in minuscolo (ad esempio `hello-world_test.sql` per l'esercizio `Hello World`).

```bash
sqlite3 -bail < ${slug}_test.sql
```

Puoi usare istruzioni `SELECT` per fare debug.
L'output verrà inoltrato a `user_output.md` e mostrato nell'editor web se i test falliscono.

Puoi trovare maggiori informazioni nella [documentazione del track sqlite sui test](https://exercism.org/docs/tracks/sqlite/tests).
