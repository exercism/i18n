# Istruzioni

In questo esercizio scriverai del codice per aiutare un'azienda di insegne a creare messaggi personalizzati per le sue insegne.

## 1. Crea un'insegna per un'occasione

Implementa il metodo `build_sign( )` che accetta una stringa come parametro `occasion` e una stringa che contiene il nome di una persona come parametro `name`. I due parametri verranno incorporati in una stringa interpolata per dare in output il messaggio sull'insegna.

```abap
build_sign( occasion = 'Birthday' 
            name     = 'Rob').
" => "Happy Birthday Rob!"
```

## 2. Crea un'insegna di compleanno

Implementa il metodo `build_birthday_sign( )` che accetta un'età e, in base all'età, determina parte del messaggio sull'insegna. Se l'età è 50 o più, l'insegna includerà la parola _mature_, altrimenti includerà la parola _young_.

```abap
build_birthday_sign( 45 ).
" => "Happy Birthday! What a young fellow you are."
```

## 3. Crea un'insegna di laurea

Implementa il metodo `graduation_for( )` che accetta un nome come parametro stringa e un anno come parametro numerico e usa stringhe interpolate per creare una frase per un'insegna che usa un carattere di nuova riga per separare le due righe del messaggio.

```abap
graduation_for( name = 'Hannah' 
                year = 2022 ).
" => "Congratulations Hannah!\nClass of 2022"
```

## 4. Calcola il costo di un'insegna

Implementa la funzione `cost_of( sign currency )` che accetta una stringa che contiene il contenuto dell'insegna e una stringa che rappresenta la valuta. L'insegna ha un prezzo base di 20 nella valuta indicata. Inoltre ogni lettera costa 2. (Gli spazi bianchi sono inclusi nel calcolo.) La frase restituita include il costo per creare l'insegna, scritto con due cifre decimali, seguito dalla stringa della valuta.

```abap
costOf( sign     = 'Happy Birthday Rob!'
        currency = 'euros');
// => "Your sign costs 58.00 euros."
```
