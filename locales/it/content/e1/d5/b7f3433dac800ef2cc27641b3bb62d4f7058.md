# Introduzione

I namespace sono un modo importante per organizzare il codice.
Due funzioni potrebbero avere un conflitto di nomi, che si può risolvere mettendole in namespace diversi.
I namespace possono essere annidati, il che può aiutare a strutturare grandi basi di codice.
Si accede ai namespace tramite l'operatore di risoluzione dello scope `::`.

L'esempio seguente mostra l'uso di due diverse funzioni `foo`.
Vengono usate insieme anteponendo i rispettivi namespace.

```cpp
namespace my_ns {
    int foo() {
        return 44;
    }
    namespace my_inner_ns {
        int baz() {
            return 90;
        }
    }
}
namespace my_other_ns {
    int foo() {
        return -2;
    }
}

int myresult{my_ns::foo() + my_other_ns::foo() * my_ns::my_inner_ns::baz()};
```
