# Suggerimenti

## Generale

- Leggi qualcosa sulla ricorsione nella [guida introduttiva ufficiale][getting-started-recursion].
- Leggi qualcosa sulla ricorsione su [elixirschool.com][elixir-school-recursion].
- Usa funzioni con più clausole e il pattern matching.
- Prova a suddividere un problema in un caso base e un caso ricorsivo. Per esempio, supponiamo che tu voglia contare quanti biscotti ci sono nel barattolo dei biscotti con un approccio ricorsivo. Un caso base è un barattolo vuoto: contiene zero biscotti. Se il barattolo non è vuoto, allora il numero di biscotti nel barattolo è uguale a un biscotto più il numero di biscotti nel barattolo dopo aver tolto un biscotto.

## 1. Controlla quanti uccelli hanno fatto visita oggi

- Questo compito non richiede la ricorsione.
- Si può accedere al primo elemento di un array tramite il [pattern matching][getting-started-pattern-matching].

## 2. Incrementa il conteggio di oggi

- Questo compito non richiede la ricorsione.
- Si può accedere al primo elemento di un array tramite il [pattern matching][getting-started-pattern-matching].

## 3. Controlla se c'è stato un giorno senza uccelli in visita

- Usa la ricorsione per iterare sugli elementi dell'array finché non trovi un giorno senza uccelli in visita.
- Il caso base è un array vuoto.

## 4. Calcola il numero totale di uccelli in visita

- Usa la ricorsione per iterare su ogni elemento dell'array.
- Il caso base è un array vuoto.

## 5. Calcola il numero di giorni intensi

- Usa la ricorsione per iterare su ogni elemento dell'array.
- Il caso base è un array vuoto.
- Una funzione può avere più di un caso ricorsivo.
- Usa un [guard][kernel-equal-or-greater-than] per una delle clausole della funzione.
