# Informazioni

Un [ciclo while][while-loops] è un'istruzione di controllo del flusso che permette di eseguire del codice finché una certa condizione è vera.
Swift mette a disposizione due tipi di ciclo while: il ciclo while e il ciclo repeat-while.
La condizione del ciclo while viene valutata prima dell'esecuzione del corpo del ciclo; se la condizione è falsa, il corpo del ciclo non verrà eseguito affatto.
I cicli while in Swift hanno la seguente struttura:

```swift
while <#condition#> {
  <#code#>
}
```

Qui il ciclo verrà eseguito finché count è maggiore di 0, e stamperà così i numeri 2, 1 e «Liftoff!».

```swift
var count = 2
while count > 0 {
  print("\(count)…")
  count -= 1
}
print("Liftoff!")

// prints:
// 2…
// 1…
// Liftoff!
```

Un [ciclo repeat-while][while-loops] è simile a un ciclo while, ma la condizione viene valutata dopo l'esecuzione del corpo del ciclo.
Questo significa che il corpo del ciclo verrà eseguito sempre almeno una volta, anche se la condizione è falsa.
I cicli repeat-while in Swift hanno la seguente struttura:

```swift
repeat {
  <#code#>
} while <#condition#>
```

Qui il ciclo verrà eseguito una sola volta, dato che la condizione è falsa.
Trattandosi di un ciclo repeat-while, il corpo del ciclo verrà eseguito una volta prima che la condizione venga valutata.

```swift
var count = 2
repeat {
  print("\(count)…")
} while count < 0
print("Liftoff!")
```
