# Introduzione

Factor è un linguaggio *concatenativo*: ogni parola legge i propri input da uno **stack dei dati** condiviso e vi rimette i propri output. Non c'è altro modo per passare i valori in giro.

Scrivere un letterale lo spinge in cima allo stack; il codice si legge da sinistra a destra:

```factor
1 2 3    ! stack (bottom → top): 1 2 3
```

Una dichiarazione di *effetto sullo stack* documenta il contratto di una parola:

```factor
: restow ( a b -- b a ) swap ;
```

`( a b -- b a )` dice che la parola estrae due valori e ne lascia due dietro nell'ordine inverso. I nomi sono documentazione: solo il *numero* di input e output viene controllato dal compilatore, e la cima dello stack è il nome a destra.

Le comuni **parole di riordino** di `kernel` riorganizzano la cima dello stack:

```
dup  ( x   -- x x   )
drop ( x   --       )
swap ( x y -- y x   )
over ( x y -- x y x )
nip  ( x y -- y     )
rot  ( x y z -- y z x )
```

Le parole si definiscono con `:` e terminano con `;`; il compilatore rifiuta una definizione il cui corpo non corrisponde all'effetto dichiarato.
