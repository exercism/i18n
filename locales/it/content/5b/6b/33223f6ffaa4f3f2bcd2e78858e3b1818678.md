# Introduzione

PowerShell è un linguaggio di scripting dinamico e a tipizzazione implicita (_ma che supporta anche le [variabili a tipizzazione forte][strong typed]_) di Microsoft, incentrato soprattutto sull'automazione delle attività e sulla gestione della configurazione.

PowerShell supporta la programmazione imperativa, funzionale, orientata agli oggetti e persino lo stile a pipeline.

PowerShell è stato costruito sulla piattaforma .NET e rilasciato per la prima volta nel 2006.
È incluso di default in tutti i moderni sistemi operativi Windows e può anche essere installato su Mac e Linux.


## Variabili

Ci sono due modi comuni per definire una variabile in PowerShell.

I nomi delle variabili in PowerShell devono iniziare con un `$` e usano l'operatore di assegnazione `=` per associare il nome della variabile a un valore.

```powershell
> $intVar = 1
> $doubleVar = 2.0
> $stringVar = "Hello"

# Checking a variable type using the GetType() method
> Write-Host $doubleVar.GetType()
System.Double
```

Puoi anche specificare esplicitamente il tipo di una variabile, se vuoi imporre o richiedere che il valore sia di un certo tipo.
PowerShell farà del suo meglio per convertire il valore da un tipo a un altro, quando possibile.

```powershell
# String represents a floating number can be converted to integer
> [int]$staticOne = "1.234"
> $staticOne
1

# String of letters can not be converted to double type
> [double]$staticTwo = "hello"
MetadataError: Cannot convert value "hello" to type "System.Double"
```


### Costanti

Le costanti in PowerShell sono variabili che non possono essere né **modificate** né **rimosse** dopo la definizione.
Questo ci porta al secondo modo di definire le variabili: usare il cmdlet `New-Variable`.

```powershell
> New-Variable -Name "MyConstant" -Value 100 -Option Constant
> $MyConstant
```

Per modi più dettagliati e avanzati di creare una nuova variabile, leggi [New-Variable][New-Variable].


## Funzioni

Le [Funzioni][functions] in PowerShell si definiscono con la parola chiave `function`.
Ogni funzione può avere zero o più parametri formali tra parentesi tonde (`()`), seguiti dallo scope della funzione che inizia con `{` e termina con `}`.

```powershell
function Greeting {
    return "Hello!"
}
```

Le funzioni in PowerShell possono restituire valori esplicitamente tramite la parola chiave `return`, dopo essere state chiamate con la sintassi `FuncName $Arg`.

```powershell
function AddTwoNumbers($NumOne, $NumTwo):
    $result = $NumOne + $NumTwo
    return $result

> AddTwoNumbers 10 20
30
```

Uno sguardo avanzato su come scrivere una definizione di funzione dettagliata e su come le funzioni possono restituire valori in modo implicito sarà trattato nel modulo del concetto `Functions`.


## Commenti

I commenti singoli in PowerShell iniziano con un `#` e terminano a fine riga.
I blocchi di commento in PowerShell iniziano con `<#` e terminano con `#>`.
Una dimostrazione avanzata dei blocchi di commento per creare la Comment-Based Help sarà trattata nel modulo del concetto `Functions`.

```powershell
function Main() {
    #This is a comment
    <#
    And this is a comment block
    that can span multiple lines
    #>
}
```
