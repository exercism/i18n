# Suggerimenti

## Generale

- Leggi qualcosa sul [pattern matching][pattern-matching] nella guida ufficiale.
- Dai un'occhiata a questo cheat sheet sul [destructuring][destructuring].
- Il pattern matching per i record è [spiegato qui][records-pattern-matching] più in dettaglio.

## 1. Individuare i commenti vuoti

- Puoi usare `(a, b)` direttamente nell'argomento della funzione se l'argomento è una coppia.
- Puoi sostituire i valori che ricevi ma non usi con il wildcard `_`.
- Per controllare se una stringa è vuota, consulta la [documentazione di `String`][string-docs].

## 2. Contare il numero di commenti del creatore

- Puoi destrutturare un tipo personalizzato con un'unica variante `type Box = Box AB` direttamente in un argomento della funzione, così: `(Box ab)`.
- Puoi fare pattern matching sul campo `a` di un record `{a : A, b : B}` usando: `{ a }`.
- Puoi usare entrambe le tecniche precedenti contemporaneamente per i tipi personalizzati che contengono un record.
- Non puoi fare direttamente pattern matching sulla coppia `ab` di un record `{ ab : (A, B) }`. Devi prima fare pattern matching su `{ ab }`, poi usare `( a, b) = ab` in un binding `let`.
- Per trovare il numero di elementi che soddisfano una condizione in un array, usa le [funzioni di `List`][list-docs].
- Puoi destrutturare le coppie direttamente negli argomenti delle funzioni anonime.

## 3. Individuare i ticket assegnati al Dev Team

- Come nell'attività 2, puoi fare pattern matching sui campi rilevanti di un record «incapsulato» nell'argomento della funzione.
- Puoi usare il pattern matching in modo ricorsivo per fare pattern matching su un valore annidato come `Just (Box "42")`.
- Puoi usare il wildcard `_` per fare pattern matching su qualsiasi cosa in un'istruzione `case`.

## 4. Assegnare i ticket ai dipendenti IT

- Come nelle attività 2 e 3, puoi fare pattern matching sui campi rilevanti di un record «incapsulato» nell'argomento della funzione.
- Inoltre, puoi usare la parola chiave `as` per fare pattern matching su un campo e associare anche l'intero record: `(Box ({ a } as ab))`.
- Puoi fare pattern matching sui valori di un tipo personalizzato con l'istruzione `case`.
- Usa il costruttore di tipo `Ticket` per restituire un ticket.
- Usa la [sintassi di aggiornamento dei record][record-update] per modificare i record.
