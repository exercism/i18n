# Istruzioni

In questo esercizio scriverai un TreasureChest generico (e anche magico!), per custodire un po' di tesoro.

## 1. Definisci il tipo personalizzato generico TreasureChest

Definisci un tipo personalizzato `TreasureChest` con una sola variante.

La variante deve avere un valore `String` associato, che servirà a memorizzare la password del forziere.

La variante deve avere anche un valore generico associato, che servirà a memorizzare il tesoro.
Questo valore è generico, così il tesoro può essere qualsiasi cosa.

## 2. Definisci la funzione getTreasure

Questa funzione deve accettare due parametri

- una `String` (per provare una password)
- un tipo personalizzato generico `TreasureChest`

Questa funzione deve confrontare il tentativo di password fornito con la `String` contenuta nel `TreasureChest`.

La funzione deve restituire un `Maybe`.

Se le password corrispondono, restituisci `Just` con il valore generico contenuto nel `TreasureChest` (il tesoro!).

Se le password non corrispondono, restituisci `Nothing`.

## 3. Definisci la funzione multiplyTreasure

Questa funzione (di ordine superiore) deve accettare due parametri

- una funzione moltiplicatrice che accetta un parametro generico e restituisce un array dello stesso tipo generico
- un tipo personalizzato generico `TreasureChest`, anch'esso con lo stesso tipo generico

Questa funzione deve chiamare la funzione moltiplicatrice passandole il tesoro contenuto nel forziere.

La funzione deve restituire un nuovo TreasureChest, con la stessa password dell'originale e con il tesoro moltiplicato (il valore restituito).
