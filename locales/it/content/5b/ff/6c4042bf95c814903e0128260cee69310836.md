# Introduzione

## Costanti e funzioni

Un valore costante si definisce con `name = expression`,
dove in Elm tutto, tranne le definizioni, è un'espressione.

```elm
five = 5

six = 3 + 3
```

Le funzioni si definiscono con `name parameters... = expression`,
ed i parametri sono separati solo da uno spazio.

```elm
add number1 number2 = number1 + number2
```

Anche chiamare una funzione è un'espressione: si specifica il nome della funzione
e si passano gli argomenti per ognuno dei suoi parametri,
separati da uno spazio, proprio come nella definizione della funzione.

```elm
five = add 2 3
```

Le parentesi si possono usare per specificare l'ordine di valutazione di un'espressione.

```elm
six = add 2 (1 * 4)

twelve = add 2 1 * 4
```

## Indentazione / spazi bianchi significativi

Elm non usa marcatori sintattici come parentesi graffe, parentesi tonde o punti e virgola per delimitare il codice. Usa invece gli spazi bianchi e l'indentazione.

- Le definizioni di moduli, import e funzioni di primo livello devono iniziare dalla colonna più a sinistra.
- Se un'espressione è suddivisa su più righe, il codice che fa parte di quell'espressione deve essere indentato sotto di essa con almeno uno spazio.
- Le parti dell'espressione che formano un gruppo dovrebbero essere indentate con lo stesso numero di spazi.

```elm
-- A function split over multiple lines, so subsequent lines must be indented
add number1 number2 =
    number1 + number2
```

https://elmprogramming.com/indentation.html

## Moduli

Ogni file in Elm è un modulo e deve contenere un'istruzione `module` prima di qualsiasi altro codice.
Il nome di un modulo deve corrispondere a quello del suo file, quindi il modulo `Calculator` deve trovarsi nel file Calculator.elm.
Tutto ciò che viene definito all'interno di un modulo ha uno scope privato
e non è accessibile dall'esterno, a meno che non sia elencato in `exposing`.

```elm
-- Define the Calculator module, and expose the `add` function
module Calculator exposing (add)

six = 3 + 3

add number1 number2 = number1 + number2
```

```elm
-- Define the Calculator module, and expose everything within: `six` and `add`
module Calculator exposing (..)

six = 3 + 3

add number1 number2 = number1 + number2
```

https://elm-lang.org/docs/syntax#modules

## Commenti

Un commento è un testo all'interno del file Elm che non viene interpretato come codice.
È pensato principalmente per essere letto da te e dagli altri programmatori.
Esiste una sintassi leggera per i commenti su una sola riga, basata sul doppio trattino.
I commenti su più righe sono possibili grazie alla coppia di delimitatori
di apertura e chiusura `{-` e `-}`.

```elm
-- a single line comment
-- another single line comment

{- a multiline comment
   spawning multiple lines
-}
```
