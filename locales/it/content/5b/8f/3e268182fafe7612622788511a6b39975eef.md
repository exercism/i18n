# Istruzioni

In questo esercizio simulerai un sistema informatico basato su finestre.
Creerai alcune finestre che possono essere spostate e ridimensionate.
L'immagine che segue è rappresentativa dei valori con cui lavorerai qui sotto.

```text
 ╔════════════════════════════════════════════════════════════╗
 ║                                                            ║
 ║        position::$y,_                                      ║
 ║        position::$x  \                                     ║
 ║                       \<---- size::$width ---->            ║
 ║                 ^      *──────────────────────┐            ║
 ║                 |      │        title         │            ║
 ║                 |      ├──────────────────────┤            ║
 ║                 |      │                      │            ║
 ║          size::$height │                      │            ║
 ║                 |      │       contents       │            ║
 ║                 |      │                      │            ║
 ║                 |      │                      │            ║
 ║                 v      └──────────────────────┘            ║
 ║                                                            ║
 ║                                                            ║
 ╚════════════════════════════════════════════════════════════╝
```

## 1. Definisci le proprietà della finestra del programma

Usando lo scaffold di classe fornito, fornisci le proprietà per i valori `y`, `x`, `height` e `width`.

```php
<?php

$window = new ProgramWindow();
$window->y; // => null
$window->x; // => null
$window->height; // => null
$window->width; // => null
```

## 2. Definisci i valori iniziali della finestra del programma

Definisci un costruttore per `ProgramWindow`.
Non deve accettare argomenti, ma durante l'esecuzione del costruttore imposta i valori predefiniti delle sue proprietà.
Deve impostare i valori iniziali di `y` e `x` a `0`.
Deve impostare `height` e `width` iniziali a una dimensione dello schermo di `600x800`.

```php
<?php

$window = new ProgramWindow();
$window->y; // => 0 
$window->x; // => 0
$window->height; // => 600
$window->width; // => 800
```

## 3. Definisci una funzione per ridimensionare la finestra

Definisci una nuova classe in `Size.php` per una classe Size.
Deve accettare argomenti del costruttore per impostare le proprietà `height` e `width`.
Inoltre `ProgramWindow` richiede una funzione di ridimensionamento, che riceve l'istanza dell'oggetto `Size` e aggiorna le proprie proprietà.

```php
<?php 

$window = new ProgramWindow();
$size = new Size(764, 1080);
$window->resize($size)

$window->height;
// => 764
$window->width;
// => 1080
```

## 4. Definisci una funzione per spostare la finestra

Definisci una nuova classe in `Position.php` per una classe Position.
Deve accettare argomenti del costruttore per impostare le proprietà `y` e `x`.
Inoltre `ProgramWindow` richiede una funzione di spostamento, che riceve l'istanza dell'oggetto `Position` e aggiorna le proprie proprietà.

```php
<?php 

$window = new ProgramWindow();
$position = new Position(80, 313);
$window->move($position)

$window->y;
// => 80
$window->x;
// => 313
```
