# Informazioni

In Haxe, una `class` è la struttura dati principale, che incapsula dati (campi) e comportamento (metodi). I campi e i metodi sono anche chiamati membri di una classe.

L'accesso ai membri può essere limitato usando i [modificatori di accesso][visibility], che sono:

- `public`: il membro è accessibile da qualsiasi punto.
- `private`: il membro è accessibile solo dalla stessa classe.

Le classi possono essere viste come modelli per creare istanze. Per creare un'[istanza][class-instance], usa semplicemente la parola chiave `new`:

```haxe
class Car {
  public function new() {}
}

var myCar = new Car();
var yourCar = new Car();
```

Per definire un campo, usa un modificatore di accesso seguito dal nome della variabile e dal tipo:

```haxe
class Car {
  public var weight:Int; // Accessable by anyone

  private var color:String; // Accessable only within this class
}
```

Puoi anche impostare un valore iniziale quando definisci un campo. Se un campo non specifica un valore iniziale, assumerà il valore `null`. Puoi accedere a un campo usando la notazione con il punto:

```haxe
class Car {
  public var weight:Int = 2500; // Weight will be set to 2500
  public var year:Int; // year will be null

  public function new() {}
}

var newCar = new Car();
newCar.weight; // 2500
newCar.year; // null

// Update value of field
newCar.year = 2020;
```
