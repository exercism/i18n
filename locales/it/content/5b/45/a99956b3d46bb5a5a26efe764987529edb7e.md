# Introduzione

Factor modella date e orari con il vocabolario [`calendar`][calendar]. Un punto nel tempo è un `timestamp`; un intervallo di tempo è un `duration`.

## Costruire una data

`<date>` (in [`calendar`][calendar]) costruisce un `timestamp` a mezzanotte del giorno indicato:

```
<date> ( year month day -- timestamp )
```

```factor
USING: calendar ;

1904 11 16 <date> .
! a timestamp at midnight on 1904-11-16
```

`>date<` scompone un timestamp di nuovo nelle sue parti:

```
>date< ( timestamp -- year month day )
```

```factor
1904 11 16 <date> >date< .   ! => 16   (with 1904 and 11 below it)
```

## Esaminare una data

`day-of-week` restituisce il giorno della settimana come numero intero, da `0` per domenica a `6` per sabato. `day-names` (in [`calendar.english`][english]) è la lista di nomi corrispondente, quindi `day-names nth` trasforma il numero in una parola:

```factor
USING: calendar calendar.english sequences ;

2024 1 8 <date> day-of-week .          ! => 1
day-names .   ! { "Sunday" "Monday" ... "Saturday" } — Sunday first
```

`leap-year?` accetta un anno (o un timestamp) e `days-in-month` restituisce la durata del mese di un timestamp, tenendo già conto degli anni bisestili:

```
leap-year?    ( obj -- ? )
days-in-month ( timestamp -- n )
```

```factor
2024 leap-year? .                ! => t
2024 2 1 <date> days-in-month .  ! => 29
```

## Aritmetica con le date

Parole come `days`, `weeks` e `hours` costruiscono un `duration`, e `time+` sposta un timestamp di quella durata:

```
days  ( x -- duration )
time+ ( timestamp duration -- timestamp )
```

```factor
2024 2 28 <date> 1 days time+ >date< .
! => 29   (2024-02-29, with 2024 and 2 below it)
```

L'aritmetica funziona correttamente anche attraverso i confini di mese e anno, e due timestamp che indicano lo stesso istante risultano uguali con `=`.

## Orari del giorno

`<timestamp>` costruisce un timestamp completo, fino al secondo. Il suo ultimo argomento è lo scostamento da UTC; `instant` (un `duration` pari a zero) mantiene il timestamp in UTC:

```
<timestamp> ( year month day hour minute second gmt-offset -- timestamp )
```

```factor
USING: calendar ;

1969 7 21 2 56 15 instant <timestamp> .
! a timestamp at 02:56:15 on 1969-07-21
```

`>time<` è la controparte di `>date<`: scompone un timestamp in ora, minuti e secondi:

```
>time< ( timestamp -- hour minute second )
```

```factor
1969 7 21 2 56 15 instant <timestamp> >time< .   ! => 15   (with 2 and 56 below it)
```

`seconds` e `minutes` costruiscono un `duration` proprio come `days`, `weeks` e `hours`, quindi ognuna di esse può essere passata a `time+`:

```
seconds ( x -- duration )
minutes ( x -- duration )
```

I singoli campi di un timestamp si leggono con gli accessor `year>>`, `month>>`, `day>>`, `hour>>`, `minute>>` e `second>>`:

```factor
1969 7 21 2 56 15 instant <timestamp> hour>> .   ! => 2
```
