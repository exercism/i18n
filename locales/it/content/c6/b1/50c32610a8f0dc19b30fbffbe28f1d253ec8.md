# Introduzione

In JavaScript, le _stringhe interpolate_ permettono di incorporare espressioni all'interno delle stringhe; questa tecnica è nota anche come interpolazione di stringhe.
Questa funzionalità estende le capacità dell'oggetto globale [`String`][string-reference] integrato.

In JavaScript puoi creare stringhe interpolate racchiudendo il testo tra backtick.
Non solo permettono al testo di includere a capo e altri caratteri speciali: puoi anche incorporare variabili e altre espressioni.

```javascript
const num1 = 1;
const num2 = 2;

`Adding ${num1} and ${num2} gives ${num1 + num2}.`;
// => Adding 1 and 2 gives 3.
```

Nell'esempio qui sopra, i backtick (<code>\`\`</code>) servono a rappresentare una stringa interpolata. Il `${...}` è il segnaposto usato per la sostituzione.
Qualsiasi tipo non stringa viene convertito _implicitamente_ in stringa.
Questo argomento è trattato nel concetto [conversione di tipo][type-conversion-concept].
Con le stringhe interpolate puoi usare tutti i tipi di espressione.

```javascript
const track = 'JavaScript';

`This track on exercism.org is ${track.toUpperCase()}.`;
// => This track on exercism.org is JAVASCRIPT.
```

Quando hai bisogno di formattare una stringa su più righe:

```javascript
`This is an example of using template
strings to accomplish multiple
lines`;
```

Grazie alle possibilità di sostituzione disponibili, puoi anche introdurre della logica nel processo per determinare quale debba essere la stringa di output.

Un esempio è l'incorporamento di un [operatore ternario][ternary-operator].
Questo operatore è una forma abbreviata per scrivere un'istruzione `if/else`.
La sintassi è `condition ? consequent-expression : alternative-expression`.
Se la condizione è truthy, viene restituito l'operando a sinistra dei due punti.
Altrimenti, il risultato dell'espressione ternaria è l'operando a destra dei due punti.

```javascript
const grade = 95;

`You have ${grade > 90 ? 'passed' : 'failed'} the exam.`;
// => You have passed the exam.
```
