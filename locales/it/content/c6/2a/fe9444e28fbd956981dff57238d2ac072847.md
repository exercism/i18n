# Introduzione

## Metodi di estensione

I metodi di estensione consentono di aggiungere metodi ai tipi esistenti senza creare un nuovo tipo derivato, ricompilare o modificare in altro modo il tipo originale. Sono definiti come metodi statici, ma vengono chiamati usando la sintassi dei metodi di istanza. Il loro primo parametro è preceduto dal modificatore `this` e specifica su quale tipo opera il metodo; i metodi di estensione vengono portati nello scope a livello di namespace.

```csharp
public static int WordCount(this string str)
{
    return str.Split().Length;
}

"Hello World".WordCount();
// => 2
```
