# Introduzione

Swift offre funzionalità ricche nella sua libreria standard, ma puoi accedere a molte funzionalità aggiuntive importando librerie e framework esterni.
Questi moduli possono arrivare direttamente dal progetto Swift (come [Swift Argument Parser][argument-parser]), dai framework delle piattaforme Apple (come [Foundation][apple-foundation] ed il [Network Framework][network-framework]), oppure da librerie open source di terze parti (come [SwiftyBeaver][swifty-beaver]).

I moduli principali come Foundation, una delle librerie più usate in Swift, sono inclusi nella toolchain di Swift.
Le librerie di terze parti devono essere aggiunte alla configurazione del progetto (per esempio, usando Swift Package Manager) prima di poterle importare.

Per importare un modulo, scrivi la parola chiave `import` seguita dal nome del modulo:

```swift
import Foundation
```

Importare un modulo rende disponibili al codice i suoi tipi, metodi e funzioni.
Per esempio, importare Foundation estende `String` con utili metodi di utilità come `components(separatedBy:)`.

Per convenzione, le istruzioni `import` si collocano all'inizio di un file Swift, così le dipendenze sono subito visibili a chiunque legga il codice.

[argument-parser]: https://apple.github.io/swift-argument-parser/documentation/argumentparser/
[network-framework]: https://developer.apple.com/documentation/network
[swifty-beaver]: https://github.com/SwiftyBeaver/SwiftyBeaver
[apple-foundation]: https://developer.apple.com/documentation/foundation
