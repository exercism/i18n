# Informazioni

Una keyword list è una lista di [tuple][exercism-tuples] `{key, value}`. Ci sono due modi per scrivere una keyword list:

```elixir
# concise
[month: "April", year: 2018]

# explicit
[{:month, "April"}, {:year, 2018}]
```

## Le chiavi devono essere atomi

Non tutte le liste di tuple da due elementi sono keyword list. Le chiavi devono essere atomi:

```elixir
Keyword.keyword?([{"month", "April"}])
# => false
```

Se vuoi usare nella chiave caratteri diversi da lettere, numeri e `_`, devi racchiuderla tra virgolette. Tuttavia questo non la trasforma in una stringa: è comunque un atomo.

[//]: # (elixir-formatter-disable-next-block)

```elixir
Keyword.keyword?(["day of week": "Monday"])
# => true
```

## Le chiavi possono ripetersi

Le chiavi in una keyword list possono ripetersi, e le [coppie chiave-valore sono ordinate][keyword-duplicate-keys-and-ordering]. Quando provi a ottenere un singolo valore associato a una determinata chiave, ottieni il primo valore, mentre eventuali altri valori sotto la stessa chiave vengono ignorati silenziosamente.

```elixir
list = [month: "April", month: "May"]

Keyword.get_values(list, :month)
# => ["April", "May"]

Keyword.get(list, :month)
# => "April"
```

Le keyword list supportano anche il [_comportamento Access_][access-behaviour].

```elixir
list[:month]
# => "April"
```

## Le keyword list come opzioni

Le caratteristiche delle keyword list le hanno rese il meccanismo predefinito per passare opzioni alle funzioni in Elixir.

Quando hai imparato `if`, hai visto una sintassi speciale più breve:

```elixir
if age >= 16, do: "beer", else: "no beer"
```

Può sembrare che `if` accetti due argomenti, ma la coppia `do:` ed `else:` è in realtà un unico argomento, una keyword list. Lo stesso codice si potrebbe scrivere così:

[//]: # (elixir-formatter-disable-next-block)

```elixir
if age >= 16, [do: "beer", else: "no beer"]
# or
if age >= 16, [{:do, "beer"}, {:else, "no beer"}]
```

L'uso delle keyword list come opzioni delle funzioni è così comune che Elixir ti permette di [saltare le parentesi quadre quando la keyword list è l'ultimo argomento][keyword-call-syntax] passato a una funzione.

Dato che nella sintassi di Elixir le tuple, le liste, le mappe e altre strutture sono trattate come le chiamate di funzione, questa proprietà vale anche per loro.

```elixir
[1, 2, three: 3]
# => [1, 2, {:three, 3}]
```

## Pattern matching

Per fare pattern matching su una keyword list usando la sintassi concisa, dovresti specificare tutte le chiavi nell'ordine corretto. Questo rende il pattern matching una scelta improbabile per lavorare con le keyword list. Usa invece il modulo [`Keyword`][keyword] o il [_comportamento Access_][access-behaviour].

```elixir
[month: month] = [month: "April", year: 2018]
# => ** (MatchError) no match of right hand side value: [month: "April", year: 2018]

[year: year, month: month] = [month: "April", year: 2018]
# => ** (MatchError) no match of right hand side value: [month: "April", year: 2018]
```

## Keyword list e mappe a confronto

|                  | Keyword list                  | Mappa                               |
| ---------------- | ----------------------------- | ----------------------------------- |
| Tipo di chiave   | Atomi                         | Qualsiasi, si possono mescolare in una stessa mappa |
| Chiavi duplicate | Sì                            | No                                  |
| Chiavi ordinate  | Sì                            | No                                  |
| Accesso          | `list[:key]`, `Keyword.get/2` | `map.key`, `map[:key]`, `Map.get/2` |
| Tempo di accesso | Lineare                       | Logaritmico                         |
| Pattern matching | Non molto utile               | Utile                               |

Un tempo di accesso più rapido, un tipo di chiave flessibile e un pattern matching utile rendono le mappe la scelta predefinita nella maggior parte dei casi.

Usa le keyword list quando non hai molti dati, ma ti servono chiavi duplicate o chiavi in un ordine specifico.
