# Istruzioni

L'azienda per cui lavori sta per lanciare il suo nuovissimo smartphone, chiamato **Smarty 5**: presenta un sistema di fotocamere completamente nuovo, un nuovo design e un processore rivoluzionario che gira su un nuovo sistema operativo chiamato **smartyOS**.

Il nuovo processore è abbastanza potente da gestire password più sicure che mai, e l'azienda ha deciso di sfruttarlo a proprio vantaggio.
Ti hanno chiesto di implementare per il telefono un sistema di blocco tramite password, che permetta all'utente di impostare una password e poi di verificare se una password data è corretta.

~~~~exercism/caution
Il sistema di password trattato in questo esercizio non è sicuro ed è usato solo a scopo didattico.
**NON** dovrebbe essere usato in nessuna applicazione reale.
~~~~

## 1. Impostare una password

Il telefono permette agli utenti di usare diversi tipi di password, da una semplice password numerica a una password alfanumerica più sicura, e persino una password che memorizza l'impronta digitale dell'utente.

Questi diversi tipi di password usano tipi diversi: la password numerica usa un `Int32`, la password alfanumerica usa una `String`, e la password con impronta digitale usa un `Float64`.

Implementa la classe `PasswordLock` con un inizializzatore che accetta come argomento uno qualsiasi dei tre tipi di password e lo memorizza in una variabile di istanza chiamata `@password`.

```crystal
password_lock = PasswordLock.new(1234)
# => #<PasswordLock:0x7f8e1b8c0b80 @password=1234>
```

## 2. Crittografare la password

L'azienda ha deciso di crittografare la password in modo che non sia memorizzata in chiaro, e ti ha chiesto di implementare un metodo per crittografarla.

Ogni tipo di password ha il suo modo unico di essere crittografato:

- Password `Int32`: la password viene divisa per due e arrotondata all'intero più vicino.
- Password `String`: la password viene invertita.
- Password `Float64`: la password viene moltiplicata per quattro.

Implementa un metodo di istanza chiamato `encrypt` che non accetta argomenti e modifica la variabile di istanza `@password` in modo che sia crittografata.

```crystal
password_lock = PasswordLock.new(1234)
# => #<PasswordLock:0x7f8e1b8c0b80 @password=1234>

password_lock.encrypt
# => #<PasswordLock:0x7f8e1b8c0b80 @password=617>
```

## 3. Verificare se una password è corretta

L'azienda ti ha anche chiesto di implementare un metodo che verifica se una password data è corretta.

Vogliono che il metodo restituisca `nil` se la password non è corretta e `"Unlocked"` se la password è corretta.

Implementa un metodo di istanza chiamato `unlock?` che accetta come argomento la password da verificare.
Il metodo deve restituire `nil` se la password non è corretta e `"Unlocked"` se la password è corretta.

```crystal
password_lock = PasswordLock.new(1234)
password_lock.encrypt
password_lock.unlock?(1234)
# => "Unlocked"
```
