# Introduzione

## Le basi

C# è un linguaggio a tipizzazione statica, il che significa che tutto ha un tipo in fase di compilazione. Assegnare un valore a un nome si chiama definire una variabile. Una variabile può essere definita specificando esplicitamente il suo tipo oppure lasciando che il compilatore C# inferisca il suo tipo in base al valore assegnato (nota come _inferenza di tipo_). Pertanto, le due definizioni di variabile seguenti sono equivalenti:

```csharp
int explicitVar = 10; // Explicitly typed
var implicitVar = 10; // Implicitly typed
```

L'aggiornamento del valore di una variabile si effettua tramite l'operatore `=`. Una volta definita una variabile, il suo tipo non può mai cambiare.

```csharp
var count = 1; // Assign initial value
count = 2;     // Update to new value

// Compiler error when assigning different type
// count = false;
```

C# è un [linguaggio orientato agli oggetti][object-oriented-programming] e richiede che tutte le funzioni siano definite in una _classe_. La parola chiave `class` si usa per definire una classe. Gli oggetti (o _istanze_) vengono creati usando la parola chiave `new`.

```csharp
class Calculator
{
    // ...
}

var calculator = new Calculator();
```

Una funzione all'interno di una classe è detta _metodo_. Ogni metodo può avere zero o più parametri. Tutti i parametri devono essere tipizzati esplicitamente; non c'è inferenza di tipo per i parametri. Allo stesso modo, anche il tipo restituito deve essere reso esplicito. I valori vengono restituiti dai metodi usando la parola chiave `return`. Per consentire a codice in altri file di chiamare un metodo, è necessario aggiungere il modificatore di accesso `public`.

```csharp
class Calculator
{
    public int Add(int x, int y)
    {
        return x + y;
    }
}
```

I metodi vengono chiamati usando la sintassi con il punto (`.`) su un'istanza, specificando il nome del metodo da chiamare e passando argomenti per ciascuno dei parametri del metodo. Gli argomenti possono specificare facoltativamente il nome del parametro corrispondente.

```csharp
var calculator = new Calculator();
var sum_v1 = calculator.Add(1, 2);
var sum_v2 = calculator.Add(x: 1, y: 2);
```

Lo scope in C# è definito tra i caratteri `{` e `}`.

C# supporta due tipi di commenti. I commenti a riga singola sono preceduti da `//` e i commenti multilinea sono inseriti tra `/*` e `*/`.
