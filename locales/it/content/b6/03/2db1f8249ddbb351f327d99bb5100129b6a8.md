# Appendice alle istruzioni

## Registri

| Registro | Uso          | Tipo    | Descrizione                       |
| -------- | ------------ | ------- | --------------------------------- |
| `$a0`    | input        | indirizzo | stringa di cifre terminata da null |
| `$a1`    | input        | intero  | lunghezza                         |
| `$v0`    | output       | intero  | prodotto della serie più grande   |
| `$t0-9`  | temporaneo   | qualsiasi | per memorizzazione temporanea   |
