# Workflow di sincronizzazione delle etichette

Il workflow di sincronizzazione delle etichette sincronizza le [etichette di GitHub](https://docs.github.com/en/issues/using-labels-and-milestones-to-track-work/managing-labels) di un repository con il contenuto del file `.github/labels.yml`.
Ogni volta che il file `.github/labels.yml` cambia, il workflow di sincronizzazione delle etichette aggiorna automaticamente le etichette del repository.

## Personalizzare le etichette

Le etichette definite in `.github/labels.yml` si presentano in due forme:

- Etichette condivise: sono le etichette usate da _tutti_ i repository di Exercism e sono definite nel [repo org-wide-files](https://github.com/exercism/org-wide-files/blob/main/global-files/.github/labels.yml)
- Etichette specifiche della track: sono definite in un file `.appends/.github/labels.yml`

Per aggiungere etichette specifiche della track, devi aggiungerle al file `.appends/.github/labels.yml` (vedi [questo esempio](https://github.com/exercism/python/blob/main/.appends/.github/labels.yml)).
Una volta unite le modifiche a `main`, verrà aperta automaticamente una pull request per modificare il file `.github/labels.yml`.
Dopo aver unito quella PR, le etichette verranno aggiornate automaticamente (vedi la descrizione sopra).

```exercism/caution
Non modificare mai manualmente il file `.github/labels.yml`: le modifiche verranno sovrascritte la prossima volta che le etichette vengono sincronizzate.
```

## Fonte

Il workflow è definito nel file `.github/workflows/sync-labels.yml`.
