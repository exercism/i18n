# Operatori di confronto

PHP ha dieci operatori di confronto integrati:

| Nome  | Esempio    | Risultato                                             |
| ----- | ---------- | -------------------------------------------------- |
| Uguale | `$a == $b` | true se `$a` è uguale a `$b` dopo il type juggling. |
| Identico | `$a === $b` | true se `$a` è uguale a `$b` ed è dello stesso tipo. |
| Non uguale | `$a != $b` | true se `$a` non è uguale a `$b` dopo il type juggling. |
| Non uguale | `$a <> $b` | true se `$a` non è uguale a `$b` dopo il type juggling. |
| Non identico | `$a !== $b` | true se `$a` non è uguale a `$b` o non è dello stesso tipo. |
| Minore di | `$a < $b` | true se `$a` è strettamente minore di `$b`. |
| Maggiore di | `$a > $b` | true se `$a` è strettamente maggiore di `$b`. |
| Minore o uguale a | `$a <= $b` | true se `$a` è minore o uguale a `$b`. |
| Maggiore o uguale a | `$a >= $b` | true se `$a` è maggiore o uguale a `$b`. |
| Spaceship | `$a <=> $b` | restituisce un intero minore, uguale o maggiore di `0` quando `$a`. |

PHP ha definizioni distinte che differenziano tra `equal` e `identical`.
A volte `identical` è anche indicato come `strictly equal`.

```php
<?php

// Comparisons between integer and numeric string values
1 == "1"; // => true, equal
1 === "1"; // => false, not identical

// Comparisons between integers and floating point values
1 == 1.0; // => true
1 === 1.0; // => false

// Comparisons between object instances
new stdClass() == new stdClass(); // => true, properties are equal
new stdClass() === new stdClass(); // => false, references are not identical
```
