# evitare le istruzioni print

Prova a rimuovere dal codice istruzioni come `System.out.println()`.
I test dell'esercizio richiedono che la soluzione _restituisca_ i valori dai metodi invece di stamparli.

Di solito istruzioni come queste vengono aggiunte per aiutare a fare il debug del codice.
Tuttavia, un approccio migliore è eseguire il debug del codice mentre si eseguono uno o più test unitari.
Questo ha il vantaggio aggiuntivo di poter concentrarsi sul debug di un caso di test specifico.

Ecco alcuni link che spiegano come eseguire il debug del codice Java mentre si eseguono i test unitari in vari IDE:

- [Eseguire e fare il debug dei test Java in Visual Studio Code](https://code.visualstudio.com/docs/java/java-testing#_rundebug-test-cases)
- [Eseguire il debug dei test in IntelliJ IDEA](https://www.jetbrains.com/help/idea/performing-tests.html#RedebugFailedTests)
