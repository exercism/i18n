# Istruzioni

Elaine sta lavorando a un nuovo gioco per bambini con animali e bacchette magiche.
È il momento di scrivere funzioni per lanciare un dado, generare l'energia casuale di una bacchetta e mescolare una slice.

## 1. Lancia un dado

Implementa una funzione `RollADie`.

Sarà il tradizionale dado a venti facce, con numeri da 1 a 20.

```go
d := RollADie() // d will be assigned a random int, 1 <= d <= 20
```

## 2. Genera l'energia della bacchetta

Implementa una funzione `GenerateWandEnergy`.
L'energia della bacchetta deve essere un numero in virgola mobile casuale maggiore o uguale a 0.0 e minore di 12.0.

```go
f := GenerateWandEnergy()  // f will be assigned a random float64, 0.0 <= f < 12.0
```

## 3. Mescola una slice

Il gioco presenta otto animali diversi:

- ant
- beaver
- cat
- dog
- elephant
- fox
- giraffe
- hedgehog

Scrivi una funzione `ShuffleAnimals` che restituisce una slice con gli otto animali in ordine casuale.
