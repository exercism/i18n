# Convertire direttamente il codepoint in una stringa

Il modo più semplice per convertire il codepoint di un carattere nella stringa che lo rappresenta è usare la forma speciale `<<>>`. Non serve passare da una charlist come passaggio intermedio.

```elixir
# instead of:
to_string([?A])
# => "A"

# use:
<<?A>>
# => "A"
```
