# Informazioni

Le [classi](https://docs.microsoft.com/en-us/dotnet/fsharp/language-reference/classes) sono il costrutto principale per fare programmazione orientata agli oggetti in F#.

Una classe in F# è composta dai suoi campi e metodi. I campi e i metodi di una classe sono noti come i suoi _membri_.

Le classi in F# si definiscono usando la parola chiave `type`. I metodi si definiscono usando la parola chiave `member` e sono sempre pubblici. Per definire i campi (privati), si possono usare le associazioni `let`.

```fsharp
type Shoe() =
    let size = 8

    member this.Describe() = $"This is a size {size} shoe"
```

Le classi sono modelli per creare oggetti. Per creare un'istanza di una classe, chiama il nome della classe come una funzione. Un'istanza di una classe è anche nota come _oggetto_.

Si può accedere ai membri di un oggetto usando la notazione puntata.

```fsharp
let myShoe = Shoe()
myShoe.Describe()
// => "This is a size 8 shoe"
```
