# Introduzione

In Go un'applicazione è organizzata in pacchetti.
Un pacchetto è una raccolta di file sorgente che si trovano nella stessa cartella.
Tutti i file sorgente in una cartella devono avere lo stesso nome di pacchetto all'inizio del file.
Per convenzione, i pacchetti prendono il nome della cartella in cui si trovano.

```go
package greeting
```

Go fornisce un'ampia libreria standard di pacchetti che puoi usare nel tuo programma con la parola chiave `import`.
I pacchetti della libreria standard si importano usando il loro nome.

```go
package greeting

import "fmt"
```

Un pacchetto importato viene poi indicato con il nome del pacchetto:

```go
world := "World"
fmt.Sprintf("Hello %s", world)
```

Go stabilisce se un elemento può essere chiamato dal codice di altri pacchetti in base a come è dichiarato.
Per rendere una funzione, un tipo, una variabile, una costante o un campo di una struct visibili dall'esterno (noti come _esportati_), il nome deve iniziare con una lettera maiuscola.
È analogo a come funzionano altri linguaggi di programmazione, come Java, che usano modificatori di accesso come `public` e `private`.

```go
package greeting

// Hello is a public function (callable from other packages).
func Hello(name string) string {
    return "Hello " + name
}

// hello is a private function (not callable from other packages).
func hello(name string) string {
    return "Hello " + name
}
```
