# Introduzione

## Filtro delle eccezioni

`when` è la parola chiave per filtrare le eccezioni. Si mette dopo l'istruzione `catch` e può accettare un'espressione booleana che contenga qualsiasi valore sia nello scope in quel momento. Se l'espressione restituisce true, allora viene eseguito il blocco associato a quell'istruzione `catch`; altrimenti si passa a controllare l'istruzione `catch` successiva, se c'è.

```csharp
try
{
    // do stuff
}
catch (Exception ex) when (ex.Message != "")
{
    // output the message when it is not empty
}
catch (Exception ex)
{
    // show stack trace or something.
}
```

## Eccezioni definite dall'utente

Un'eccezione definita dall'utente è una classe qualsiasi definita nel tuo codice che deriva da `System.Exception`. È soggetta a tutte le regole dell'ereditarietà tra classi, ma in più il compilatore e il runtime del linguaggio trattano queste classi in modo speciale, permettendo di lanciare e catturare le loro istanze al di fuori del normale flusso di controllo, come abbiamo visto nell'esercizio `exceptions`.

Le eccezioni definite dall'utente servono spesso a trasportare informazioni aggiuntive, come un messaggio e altri dati rilevanti, da rendere disponibili alle routine che le catturano.
