# Installazione

## Installa Node.js

**Utenti Windows e OS X**: installa [Node.js][node] [tramite il gestore di pacchetti][node-download].

**Utenti Linux**: installa [Node.js][node] seguendo le istruzioni per la tua distribuzione sul [gestore di pacchetti di Node.js][linstall].

## Installa `jasmine-node` e `coffeescript`

Per la maggior parte degli utenti basterà eseguire il comando seguente:

```bash
$ npm install -g jasmine-node coffeescript
```

A seconda della tua configurazione, potresti aver bisogno dei privilegi di super user per installare globalmente un modulo `npm`.
È il tuo caso se hai usato il programma di installazione ufficiale indicato sopra.
Se NPM ti dà un errore dicendo che non hai i permessi di accesso, aggiungi `sudo` al comando qui sopra:

```bash
$ sudo npm install -g jasmine-node coffeescript
```

Se hai usato il programma di installazione ufficiale, il tuo `PATH` dovrebbe essere stato configurato automaticamente. Ma se la tua shell ha difficoltà a trovare i moduli installati globalmente, o se hai compilato Node.js dai sorgenti.
Allora aggiorna il tuo `PATH` per includere i binari di `npm` aggiungendo quanto segue a `~/.bash_profile` oppure `~/.zshrc`:

```bash
$ export PATH=/usr/local/share/npm/bin:$PATH
```
