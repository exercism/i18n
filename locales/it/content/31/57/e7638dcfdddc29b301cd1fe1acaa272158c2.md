# Suggerimenti

## Generali

- Leggi qualcosa sulla [ricorsione dal creatore di Elm][recursion].
- Usa il pattern matching con le espressioni `case`.
- Prova a suddividere un problema in un caso base e un caso ricorsivo. Ad esempio, supponiamo di voler contare quanti biscotti ci sono nel barattolo dei biscotti con un approccio ricorsivo. Il caso base è un barattolo vuoto: contiene zero biscotti. Se il barattolo non è vuoto, allora il numero di biscotti al suo interno è uguale a un biscotto più il numero di biscotti nel barattolo dopo averne rimosso uno.

## 1. Controlla quanti uccelli sono passati oggi

- Questo compito non richiede la ricorsione.
- Per accedere al primo elemento di una lista si può usare il pattern matching con un'espressione `case`.
- Ricordati di racchiudere il risultato in `Just` quando restituisci un valore.

## 2. Incrementa il conteggio di oggi

- Questo compito non richiede la ricorsione.
- Per accedere al primo elemento di una lista si può usare il pattern matching con un'espressione `case`.
- Usa l'[operatore `::`][list-cons] per scomporre e ricomporre la nuova lista.

## 3. Controlla se c'è stato un giorno senza uccelli di passaggio

- Usa la ricorsione per iterare sugli elementi della lista finché non trovi un giorno senza uccelli di passaggio.
- I casi base sono una lista vuota o un giorno senza uccelli.
- Usa il pattern matching per verificare la presenza di `0` nella lista.

## 4. Calcola il numero totale di uccelli di passaggio

- Usa la ricorsione per iterare su ogni elemento della lista.
- Il caso base è una lista vuota.
- Usa l'operatore `+` per aggiungere l'elemento corrente al totale del resto.

## 5. Calcola il numero di giornate piene

- Usa la ricorsione per iterare su ogni elemento della lista.
- Il caso base è una lista vuota.
- Usa un'espressione `if` per controllare se il giorno corrente è pieno (5 uccelli o più).
- Aggiungi 1 al conteggio delle giornate piene nel resto della lista quando trovi una giornata piena.
