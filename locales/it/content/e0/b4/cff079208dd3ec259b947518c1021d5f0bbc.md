# Introduzione

In Java, il letterale `null` viene usato per indicare l'assenza di un valore.

I tipi di dati primitivi in Java hanno tutti un valore predefinito e quindi non possono mai essere `null`. Per convenzione, iniziano con una lettera minuscola, ad esempio `int`.

I tipi di riferimento contengono l'indirizzo di memoria di un oggetto e possono avere come valore `null`. In genere iniziano con una lettera maiuscola, ad esempio `String`.

Se si prova ad assegnare a una variabile primitiva un valore `null`, si ottiene un errore in fase di compilazione, dato che la variabile contiene sempre un valore primitivo del tipo assegnato.

```java
//Throws compile time error stating the required type is int, but null was provided
int number = null;
```

Se si assegna a una variabile di riferimento un valore `null`, non si ottiene alcun errore in fase di compilazione, dato che le variabili di riferimento possono essere `null`.

```java
//No error will occur as the String variable str is nullable
String str = null;
```
