# Istruzioni

In questo esercizio controllerai i permessi degli account utente su un forum internet. Il forum supporta tre diversi permessi:

- Read
- Write
- Delete

Ci sono tre tipi di account, ognuno con permessi predefiniti diversi:

- Guests: possono leggere i post.
- Users: possono leggere e scrivere i post.
- Moderators: possono leggere, scrivere ed eliminare i post, hanno tutti i permessi.

A volte i singoli permessi possono essere modificati: è possibile, per esempio, concedere a un account ospite anche il permesso di scrivere i post, oppure revocare tutti i permessi di un account, che si ritroverebbe così senza alcun permesso.

## 1. Ottenere i permessi predefiniti per un tipo di account

Per prima cosa, definisci un enum `AccountType` per rappresentare i tre tipi di account: `Guest`, `User` e `Moderator`.

Poi definisci un enum `Permission` per rappresentare i tre tipi di permesso, `Read`, `Write` e `Delete`, più altri due: `All`, per avere tutti i permessi, e `None`, per non averne nessuno.

Infine implementa il metodo (_static_) `Permissions.Default()` per restituire i permessi predefiniti di un tipo di account specifico:

```csharp
Permissions.Default(AccountType.Guest)
// => Permission.Read
```

## 2. Concedere un permesso

Implementa il metodo (_static_) `Permissions.Grant()` che concede (aggiunge) un permesso:

```csharp
Permissions.Grant(current: Permission.None, grant: Permission.Read)
// => Permission.Read
```

## 3. Revocare un permesso

Implementa il metodo (_static_) `Permissions.Revoke()` che revoca (rimuove) un permesso:

```csharp
Permissions.Revoke(current: Permission.Read, revoke: Permission.Read)
// => Permission.None
```

## 4. Verificare un permesso

Implementa il metodo (_static_) `Permissions.Check()` che prende i permessi attuali dell'account e verifica se l'account è autorizzato per un dato permesso:

```csharp
Permissions.Check(current: Permission.Write, check: Permission.Read)
// => false
```
