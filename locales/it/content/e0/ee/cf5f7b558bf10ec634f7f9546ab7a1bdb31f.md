# Introduzione

## L'interfaccia come insieme di metodi

Nella sua forma più semplice, un **tipo interfaccia** è un insieme di firme di metodi.
Ecco un esempio di definizione di interfaccia che include due metodi, `Add` e `Value`:

```go
type Counter interface {
    Add(increment int)
    Value() int
}
```

I nomi dei parametri come `increment` si possono omettere dalla definizione dell'interfaccia, ma spesso aumentano la leggibilità.

In Go, i nomi delle interfacce non contengono la parola `Interface` o `I`.
Spesso invece terminano con `er`, ad esempio `Reader` o `Stringer`.

## Implementare un'interfaccia

Qualsiasi tipo che definisce i metodi dell'interfaccia la implementa automaticamente, anche se in modo implicito.
In Go non esiste la parola chiave `implements`.

Il tipo seguente implementa l'interfaccia `Counter` che abbiamo visto sopra.

```go
type Stats struct {
    value int
    // ...
}

func (s Stats) Add(v int) {
    s.value += v
}

func (s Stats) Value() int {
    return s.value
}

func (s Stats) SomeOtherMethod() {
    // The type can have additional methods not mentioned in the interface.
}
```

Ai fini dell'implementazione dell'interfaccia, non importa se il metodo ha un receiver di valore o un receiver di puntatore.
(Rivedi i [concetti sui metodi][concept-methods] se hai dei dubbi in merito.)

> Un valore di tipo interfaccia può contenere qualsiasi valore che implementi quei metodi. [^1]

Questo significa che ora `Stats` può essere usato in tutti i punti in cui ci si aspetta l'interfaccia `Counter`.

```go
func SetUpAnalytics(counter Counter) {
    // ...
}

stats := Stats{}
SetUpAnalytics(stats)
// works because Stats implements Counter
```

Poiché le interfacce si implementano in modo implicito, un tipo può implementarne facilmente più di una.
Gli basta avere definiti tutti i metodi necessari.

## L'interfaccia vuota

In Go esiste un tipo interfaccia davvero speciale, il **tipo interfaccia vuota**, che non contiene alcun metodo.
L'interfaccia vuota si scrive così: `interface{}`.
`any` è un alias di `interface{}` ed è quello usato più di frequente.

Dato che l'interfaccia vuota non ha metodi, ogni tipo la implementa in modo implicito.
Questo è utile per definire una funzione che possa accettare qualsiasi valore in modo generico.
In quel caso, il parametro della funzione usa il tipo interfaccia vuota.
