# Introduzione

Un ciclo `for` permette di eseguire ripetutamente del codice finché non si verifica una condizione.

```csharp
for (int i = 0; i < 5; i++)
{
    System.Console.Write(i);
}

// => 01234
```

Un ciclo `for` è composto da quattro parti:

1. L'inizializzazione: viene eseguita una sola volta prima di entrare nel ciclo. Di solito serve a definire le variabili usate all'interno del ciclo.
2. La condizione: viene eseguita prima di ogni iterazione del ciclo. Il ciclo continua a essere eseguito finché questa è `true`.
3. L'iteratore: viene eseguito dopo ogni iterazione del ciclo. Di solito serve a modificare (spesso incrementare o diminuire) la variabile o le variabili del ciclo.
4. Il corpo: il codice che viene eseguito a ogni iterazione del ciclo.
