## 1. Verifica la criticità

- Gli operatori di confronto ([confronti][comparisons review]) e le operazioni booleane ([concept:python/bools]()) si possono combinare e usare con le condizionali.
- Le espressioni condizionali devono avere come risultato `True` o `False`.
- `else` si può usare per un blocco di codice che viene eseguito quando tutti i test condizionali restituiscono `False`.

  ```python
     >>> item = 'blue'
     >>> item_2 = 'green'
     
     >>>  if len(item) >= 3 and len(item_2) < 5:
            print('Both pass the test!')
          elif len(item) >= 3 or len(item_2) < 5:
            print('One passes the test!')
          else:
            print('None pass the test!')
    ...
    One passes the test!
  ```

## 2. Determina l'intervallo di potenza in output

- Gli operatori di confronto si possono combinare e usare con le condizionali.
- Si può usare un numero qualsiasi di istruzioni `elif` come «rami» decisionali.
- Ogni «ramo» può avere un `return` separato, anche se gli strumenti di linting potrebbero considerarlo una «cattiva pratica».
- Se il linter si lamenta, valuta di assegnare l'output di un ramo a una variabile comune e poi di restituirla con `return`.
