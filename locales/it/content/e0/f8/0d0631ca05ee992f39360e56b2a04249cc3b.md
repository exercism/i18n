# Esempio

```riscvasm
.equ FRAME_SIZE, 16

.text
.global is_triple
```

Le righe che iniziano con un punto sono _direttive_: istruzioni per l'assembler, non per il processore.
`.equ` assegna il nome `FRAME_SIZE` al numero 16.
`.text` indica che quello che segue è codice.
`.global` rende l'etichetta `is_triple` visibile all'esterno di questo file, così che altro codice possa chiamarla.
Potresti anche vedere `.globl`, che significa la stessa cosa.

```riscvasm
/* bool is_triple(unsigned a, unsigned b, unsigned c); */
is_triple:
```

`is_triple` controlla se `a² + b² = c²`, restituendo 1 in tal caso e 0 altrimenti.
Per esempio, `(6, 8, 10)` dà 1, perché `36 + 64 = 100`.
L'etichetta `is_triple` indica dove inizia la funzione.
Viene chiamata con `a`, `b` e `c` nei registri `a0`, `a1` e `a2`.

```riscvasm
        addi    sp, sp, -FRAME_SIZE
        sw      ra, 12(sp)      /* save the return address */
        sw      a1, 8(sp)       /* save b */
        sw      a2, 4(sp)       /* save c */
```

Il registro `ra` contiene l'_indirizzo di ritorno_, il punto a cui tornare nel chiamante quando abbiamo finito.
Ogni `call` sovrascrive `ra`, quindi prima lo salviamo sullo _stack_.
Lo stack cresce verso il basso, verso indirizzi più piccoli, quindi sottrarre 16 dal puntatore dello stack `sp` ci riserva 16 byte.
(`sp` deve essere sempre un multiplo di 16.)
Salviamo anche `b` e `c`, perché una funzione che chiamiamo può modificare i registri `a`.

```riscvasm
        call    square          /* a0 = a * a */
        sw      a0, 0(sp)       /* save a * a */
```

`a` è già in `a0`, dove `square` si aspetta il suo input.
`call` imposta `ra` all'istruzione successiva e salta a `square`, che restituisce il suo risultato in `a0`.

```riscvasm
        lw      a0, 8(sp)       /* a0 = b */
        call    square          /* a0 = b * b */
        lw      t0, 0(sp)       /* t0 = a * a */
        add     t0, t0, a0      /* t0 = a * a + b * b */
        sw      t0, 0(sp)       /* save a * a + b * b */
```

Ricariciamo `b` dallo stack, lo eleviamo al quadrato e lo sommiamo ad `a * a`.

```riscvasm
        lw      a0, 4(sp)       /* a0 = c */
        call    square          /* a0 = c * c */
        lw      t0, 0(sp)       /* t0 = a * a + b * b */
        sub     a0, t0, a0      /* a0 = a * a + b * b - c * c */
        seqz    a0, a0          /* a0 = 1 if that is zero, otherwise 0 */
```

La differenza è zero esattamente quando `a² + b² = c²`.
`seqz` («set if equal to zero») trasforma il risultato in 1 o 0.

```riscvasm
        lw      ra, 12(sp)      /* restore the return address */
        addi    sp, sp, FRAME_SIZE
        ret
```

Ripristiniamo `ra` e restituiamo i 16 byte dello stack.
`ret` salta poi all'indirizzo contenuto in `ra`, tornando al chiamante.

```riscvasm
/* unsigned square(unsigned n); */
square:
        mul     a0, a0, a0      /* n * n */
        ret
```

`square` non chiama nessun'altra funzione, quindi `ra` rimane intatto e non c'è niente da salvare.
Non è contrassegnata come `.global`, perché solo `is_triple` la usa.
