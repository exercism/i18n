# Note sulle parentesi

Tcl è un [linguaggio molto semplice](https://tcl.tk/man/tcl8.6/TclCmd/Tcl.htm),
ma il modo in cui l'interprete analizza il codice presenta un paio di casi limite insidiosi.

## Parentesi graffe

Le parentesi graffe in Tcl sono semplicemente un modo per quotare un blocco di testo: quel testo può essere interpretato come codice o come dati. All'interno delle parentesi graffe possono comparire parentesi graffe annidate, ma le parentesi graffe annidate devono essere bilanciate. Il manuale di Tcl dice questo:

> Le parentesi graffe si annidano all'interno della parola: per ogni parentesi graffa aperta aggiuntiva deve esserci una parentesi graffa chiusa aggiuntiva (tuttavia, se una parentesi graffa aperta o chiusa all'interno della parola è _quotata con un backslash_, allora non viene contata nel trovare la parentesi graffa chiusa corrispondente).

La formulazione qui è piuttosto specifica: se vuoi avere un carattere di parentesi graffa aperta o chiusa non abbinata, deve essere quotato con un backslash. Quindi non fare così:
```tcl
proc isOpenBrace {char} {
    return [expr {$char eq "{"}]
    # ......................^ will not work
}
```
Devi fare così
```tcl
proc isOpenBrace {char} {
    return [expr {$char eq "\{"}]
    # ......................^^ will work
}
```

Questo può essere problematico per come Tcl analizza i commenti, che è diverso dalla maggior parte dei linguaggi. C'è un'ulteriore discussione sul [wiki di
Tcl](https://wiki.tcl-lang.org/page/Why+can+I+not+place+unmatched+braces+in+Tcl+comments).

## Parentesi quadre

Allo stesso modo, dato che Tcl usa le parentesi per la [sostituzione dei
comandi.](https://tcl.tk/man/tcl8.6/TclCmd/Tcl.htm#M11), anche all'interno delle stringhe racchiuse tra virgolette doppie devi fare attenzione a come effettuare l'escape delle parentesi quadre aperte.

## Parentesi tonde

Ad eccezione delle [variabili di array
associativo](https://tcl.tk/man/tcl8.6/TclCmd/Tcl.htm#M12), le parentesi tonde sono semplicemente caratteri ordinari.
