# Informazioni

I [parametri variadici][variadic-parameters] consentono a una funzione di accettare zero o più valori di un tipo specificato per un singolo parametro.
Definisci un parametro variadico aggiungendo tre punti (`...`) all'annotazione di tipo del parametro.

All'interno del corpo della funzione, Swift rende questi valori disponibili come un array del tipo specificato:

```swift
import Foundation

func geometricMean(_ numbers: Double...) -> Double {
    var total = 1.0
    for number in numbers {
        total *= number
    }
    return pow(total, 1.0 / Double(numbers.count))
}

let result = geometricMean(1, 2, 3, 4, 5)
// result is 2.605171084697352
```

~~~~exercism/note
Se una funzione include parametri aggiuntivi dopo un parametro variadico, il primo parametro che segue il parametro variadico **deve** avere un'etichetta dell'argomento esplicita, così Swift sa dove termina l'elenco degli argomenti variadici.
~~~~
