# Appendice alle istruzioni

## Indicizzazione a base zero

Ricorda che, mentre di solito si conta con un'indicizzazione a base 1 (cioè «il sesto numero primo è 13»), molti linguaggi di programmazione, incluso Rust, usano un'indicizzazione a base zero (cioè `primes[5] == 13`). Usa l'indicizzazione a base zero nell'implementazione.
