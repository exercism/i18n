# Introduzione

Un'interfaccia è un tipo che contiene membri che definiscono un gruppo di funzionalità correlate. Tiene separate le modalità d'uso di una classe dall'implementazione, permettendo più implementazioni diverse o il supporto di comportamenti generici come la formattazione, il confronto o la conversione.

La sintassi di un'interfaccia è simile a quella di una classe o di una struct, con la differenza che i metodi e le proprietà appaiono solo come firma e non viene fornito alcun corpo.

```csharp
public interface ILanguage
{
    string LanguageName { get; set; }
    string Speak();
}

public class ItalianTaveller : ILanguage, ICloneable
{
    public string LanguageName { get; set; } =  "Italiano";

    public string Speak()
    {
        return "Ciao mondo";
    }

    public object Clone()
    {
        ItalianTaveller it = new ItalianTaveller();
        it.LanguageName = this.LanguageName;
        return it;
    }
}
```

Tutte le operazioni definite dall'interfaccia devono essere implementate.

Le interfacce possono contenere, tra gli altri membri, metodi e proprietà di istanza
