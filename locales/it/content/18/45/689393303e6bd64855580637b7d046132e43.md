# Debug in locale

Quando esegui i test della track Bash con [Bats](https://github.com/bats-core/bats-core), Bats cattura sia STDOUT che STDERR per le affermazioni sull'output.

```exercism/caution
Funziona in locale con `bats`, ma **non** nell'editor online di Exercism.
```

Se vuoi stampare output di debug senza influire sul risultato del test, scrivilo sul descrittore di file (fd) 3.

```bash
echo 'debug message' >&3
```

Bats mostra l'output scritto su fd 3 durante l'esecuzione dei test, ma non lo include nelle affermazioni come `assert_output`.

Esempio di esecuzione:

```none
$ bats hello_world.bats
hello_world.bats
 ✓ Say Hi!
debug message
1 test, 0 failures
```

È utile quando esegui i test in locale.
