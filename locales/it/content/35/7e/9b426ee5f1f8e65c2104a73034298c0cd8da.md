# Integrazioni di Babashka con gli editor di testo

## nREPL

### Emacs: [CIDER](https://cider.mx/)

È il progetto che ha dato il via a tutto quanto: il suo ecosistema [Orchard](https://metaredux.com/posts/2018/11/09/ciders-orchard-the-heart.html) alimenta molti degli altri plug-in.

1. Installa [Emacs](https://www.gnu.org/software/emacs/download.html) per la tua piattaforma.

2. Scegli una distribuzione Emacs già esistente ([Prelude](https://prelude.emacsredux.com/), [Spacemacs](https://www.spacemacs.org/) e [Doom Emacs](https://github.com/hlissner/doom-emacs) sono tutte ottime) oppure aggiungi questo al tuo `init.el`:

```elisp
(unless (package-installed-p 'cider)
  (package-install 'cider))
  
(add-hook 'clojure-mode-hook #'cider-mode)
```

Riassunto dalla [documentazione di CIDER](https://docs.cider.mx/cider/platforms/babashka.html):

Avvia il server nREPL dalla directory del progetto:

```bash
$ bb --nrepl-server
```

Crea o apri un file Clojure qualsiasi (`.clj`) con `C-x C-f` e connettiti con `C-c C-x c j` (cider-connect-clj).

Le [scorciatoie di base di CIDER](https://docs.cider.mx/cider/usage/cider_mode.html#key-reference):

* `cider-load-buffer`: `C-c C-k`
* `cider-eval-last-sexp`: `C-x C-e` oppure `C-c C-e`
* `cider-eval-defun-at-point`: `C-M-x` oppure `C-c C-c`

### VSCode: [Calva](https://github.com/BetterThanTomorrow/calva)

1. Installa [VSCode](https://code.visualstudio.com/).

2. Installa [Calva](https://marketplace.visualstudio.com/items?itemName=betterthantomorrow.calva).

Al momento Calva considera il codice sorgente come inserito nel contesto di una cartella, cioè di un progetto Clojure. Un buon modo per crearne uno è con [clj-new](https://github.com/seancorfield/clj-new):

```bash
$ clj -A:new lib myorg/bbtest
Generating a project called bbtest based on the 'lib' template.
The lib template is intended for library projects, not applications.
```
3. Avvia il server nREPL dalla directory del progetto:

```bash
$ cd bbtest
bbtest$ bb --nrepl-server 1667
Started nREPL server at localhost:1667
For more info visit https://github.com/borkdude/babashka/blob/master/doc/repl.md#nrepl.
```

Apri la cartella del progetto in VSCode (Ctrl+K Ctrl+O) oppure da un altro terminale:

```bash
$ cd bbtest
bbtest$ code .
```

4. In VSCode, esegui il comando di Calva `Connect to a running REPL` (ctrl+alt+c ctrl+alt+c). Quando richiesto, scegli il progetto `Generic` e inserisci `localhost:1667`.

Comandi REPL:

* `Load Current File and Dependencies` ctrl+alt+c enter
* `Evaluate Current Form Inline` ctrl+alt+c e
* `Evaluate Current Top Level Form (defun)` ctrl+alt+c space

### IntelliJ: [Cursive](https://cursive-ide.com/)

1. Scarica IntelliJ [qui](https://www.jetbrains.com/idea/download/index.html).
2. Installa Cursive seguendo la [guida utente](https://cursive-ide.com/userguide/) e [configura le dipendenze](https://cursive-ide.com/userguide/deps.html).
3. Consulta [Cursive: lavorare con Babashka](https://cursive-ide.com/userguide/babashka.html) per maggiori informazioni.

## Socket REPL

### Atom: [chlorine](https://github.com/mauricioszabo/atom-chlorine)

1. Installa [atom](https://flight-manual.atom.io/getting-started/sections/installing-atom/)

2. Installa il pacchetto `chlorine`

3. Avvia il socket REPL:

 ```
$ bb --socket-repl 1666
Babashka socket REPL started at localhost:1666
 ```

4. Apri la Command Palette di Atom (ctrl+shift+p) ed esegui il comando `Connect Clojure Socket REPL` con `localhost` `1666`

5. Modifica le scorciatoie da tastiera in keymap.cson tramite il menu `Edit`, `Keymap...`:

```
'atom-text-editor[data-grammar="source clojure"]':
  'ctrl-; y':       'chlorine:connect-clojure-socket-repl'
  'ctrl-; e':       'chlorine:disconnect'
  'ctrl-; k':       'chlorine:clear-console'
  'ctrl-shift-enter':       'chlorine:load-file'
  'ctrl-enter':       'chlorine:evaluate-block'
  'shift-enter':       'chlorine:evaluate-top-block'
  'ctrl-; i':       'chlorine:inspect-block'
  'ctrl-; I':       'chlorine:inspect-top-block'
  'ctrl-; s':       'chlorine:evaluate-selection'
  'ctrl-; c':       'chlorine:break-evaluation'
  'ctrl-; S':       'chlorine:source-for-var'
  'ctrl-; d':       'chlorine:doc-for-var'
  'ctrl-; x':       'chlorine:run-tests-in-ns'
  'ctrl-; t':       'chlorine:run-test-for-var'
```

### Emacs: [inf-clojure](https://github.com/clojure-emacs/inf-clojure)

Per Emacs, installa [inf-clojure](https://github.com/clojure-emacs/inf-clojure) aggiungendo questo al tuo `init.el`:

```
(unless (package-installed-p 'inf-clojure)
  (package-refresh-contents)
  (package-install 'inf-clojure))

(add-hook 'clojure-mode-hook #'inf-clojure-minor-mode)
```

Avvia il socket REPL come sopra e in Emacs esegui `M-x inf-clojure-connect` (C-c M-c).

Valuta le form con C-c C-e. Per un elenco di tutti i comandi disponibili in inf-clojure-mode (ovvero la REPL) e inf-clojure-minor-mode puoi invocare C-h f RET inf-clojure-mode e C-h f RET inf-clojure-minor-mode oppure sfogliare semplicemente i relativi menu.

### Vim: [vim-iced](https://github.com/liquidz/vim-iced)

Scarica l'[appimage di Neovim](https://github.com/neovim/neovim/releases/download/v0.4.3/nvim.appimage) e assegnagli l'alias `vim`.

* Installa [vim-plug](https://github.com/junegunn/vim-plug):

```
$ curl -fLo ~/.local/share/nvim/site/autoload/plug.vim --create-dirs \
    https://raw.githubusercontent.com/junegunn/vim-plug/master/plug.vim
```

Crea `~/.config/nvim/init.vim`:

```
call plug#begin('~/.vim/plugged')

Plug 'liuchengxu/vim-clap'
Plug 'guns/vim-sexp',    {'for': 'clojure'}
Plug 'liquidz/vim-iced', {'for': 'clojure'}

call plug#end()

" Enable vim-iced's default key mapping
" This is recommended for newbies
let g:iced_enable_default_key_mappings = v:true
```

Apri Neovim ed esegui il comando `:PlugInstall`.

Aggiungi il comando `iced` al $PATH:

`$ export PATH=$PATH:~/.vim/plugged/vim-iced/bin`

* Avvia il server socket REPL, apri il file sorgente ed esegui `:IcedConnectSocketRepl 1666`.

Comandi REPL predefiniti (il valore predefinito di `<Leader>` è `\`):

- `<Leader>ei`: Valuta l'elemento interno
- `<Leader>ee`: Valuta la lista esterna
- `<Leader>et`: Valuta la lista esterna di primo livello
