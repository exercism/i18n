# Introduzione

In questo esercizio esamineremo alcuni dettagli dei parametri dei metodi e del loro uso in C#.

I parametri trasmettono informazioni da un metodo chiamante a un metodo chiamato.

- Il comportamento dei parametri può essere modificato con l'uso di modificatori come `ref` e `out`.

- Un parametro con il modificatore `out` riporta un valore dal metodo chiamato al chiamante. Il parametro può essere passato al metodo chiamato senza essere inizializzato e in ogni caso, all'interno del metodo chiamato, viene trattato come se, all'ingresso, non fosse stato inizializzato. Il modo più semplice per capire il comportamento e le regole dei modificatori dei parametri è attraverso esempi (vedi sotto) ed i messaggi del compilatore.

```csharp
void Foo(out int val)
{
    val = 42;
}
void Bar(int val)
{
    val = 42;
}

int importantValue = 1729;
Foo(out importantValue);
var result = importantValue == 42;
// => true

importantValue = 1729;
Bar(importantValue);
result = importantValue == 1729;
// => true
```

- I parametri `out` devono ricevere un'assegnazione all'interno del metodo chiamato.

- Un parametro con il modificatore `ref` passa un valore a un metodo chiamato. Al termine del metodo, il chiamante troverà in quel parametro tutte le modifiche apportate dal metodo chiamato.

```csharp
void Foo(ref int val)
{
    val *= 7;
}

int importantValue = 6;
Foo(ref importantValue);
return importantValue;
// => 42
```

- I parametri `ref` devono essere variabili, poiché il metodo chiamato opererà direttamente sul parametro così come lo vede il chiamante.
- I modificatori `out` e `ref` sono richiesti sia nella firma del metodo chiamato sia nel punto di chiamata.
