# gofmt non usato

Esegui `gofmt` sulla soluzione: aiuta a formattare il codice in Go.

La formattazione del codice in Go è molto importante per la comunità.
La maggior parte degli IDE può essere configurata per formattare automaticamente il codice a ogni salvataggio. Per esempio:

- Visual Studio Code ha un [ottimo supporto per Go](https://code.visualstudio.com/docs/languages/go)
- Anche Vim ha una [fantastica estensione per Go](https://github.com/fatih/vim-go)
- [Jetbrains Goland](https://www.jetbrains.com/go/) è un IDE completo per Go

Per eseguire `gofmt` manualmente:

```bash
# will only show the differences
gofmt -d filename.go

# will apply the changes
gofmt -w filename.go
```

```git
%{gofmt}
```
