# Introduzione

Quando una quotation deve *ricordare* dei valori dal suo contesto, quello che altri linguaggi chiamano *closure*, Factor usa due strumenti: il word `curry` e la sintassi *fry* `'[ ]`.

## `curry`: catturare un valore

`curry` (in [`kernel`][kernel]) prende un valore e una quotation e restituisce una nuova quotation con quel valore già incorporato:

```
curry ( value quot -- newquot )
```

```factor
3 [ + ] curry .
! => [ 3 + ]

10 3 [ + ] curry call .
! => 13
```

Applica `curry` due volte per catturare due valori:

```factor
2 3 [ + + ] curry curry .
! => [ 2 3 + + ]
```

## `compose`: unire due quotation

`compose` (in [`kernel`][kernel]) incolla due quotation insieme:

```
compose ( quot1 quot2 -- quot )
```

```factor
[ 1 + ] [ 2 * ] compose .
! => [ 1 + 2 * ]

5 [ 1 + ] [ 2 * ] compose call .
! => 12
```

## Le quotation fry: catturare più valori

Quando le catture sono più di una o due, le chiamate a `curry` incatenate diventano difficili da leggere. *Fry* usa `'[ … ]` con uno o più segnaposto `_`; ogni `_` viene sostituito da un valore preso dallo stack dei dati, in ordine:

```factor
2 3 '[ _ _ + + ] .
! => [ 2 3 + + ]
```

Sia `curry` sia fry *consumano* i loro valori dallo stack nel momento in cui la closure viene costruita. La riga qui sopra non lascia nulla sullo stack ed è un sostituto diretto di `[ + + ] curry curry`.

I segnaposto vengono riempiti da sinistra a destra con i valori dello stack dal basso verso l'alto: `2 3 '[ _ _ ]` è `[ 2 3 ]`, non `[ 3 2 ]`.

Fry riesce anche a entrare *dentro* le quotation annidate, il che ti permette di posizionare i valori catturati esattamente dove vuoi:

```factor
2 '[ [ _ > ] filter ] { 1 2 3 4 5 } swap call( s -- s ) .
! => { 3 4 5 }
```

Il `_` si trova dentro la `[ … ]` interna, ma fry lo riempie comunque.

## `call` con un effetto dichiarato

Quando alla fine esegui una quotation memorizzata, dichiara il suo effetto sullo stack su `call`, così il compilatore può controllare i tipi:

```factor
{ 3 4 5 } [ first2 + ] call( p -- n ) .
! => 7

{ 3 4 5 } [ first ] call( p -- n ) .
! => 3
```

## Aritmetica vettoriale

Il vocabolario [`math.vectors`][math.vectors] combina due sequenze della stessa lunghezza elemento per elemento. `v+` e `v*` le sommano o le moltiplicano; `vmax` e `vmin` mantengono il maggiore o il minore di ogni componente. Ognuna restituisce un array di 2 elementi:

```factor
{ 1 1 } { 3 4 } v+ .    ! => { 4 5 }
{ 2 5 } { 3 -1 } v* .   ! => { 6 -5 }
{ 1 9 } { 4 4 } vmax .  ! => { 4 9 }
{ 1 9 } { 4 4 } vmin .  ! => { 1 4 }
```
