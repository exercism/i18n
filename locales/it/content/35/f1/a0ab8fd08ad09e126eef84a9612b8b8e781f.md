# Introduzione

## Comprensioni di liste

Le comprensioni permettono di trasformare gli _Enumerables_ in modo semplice e dichiarativo.

Per dichiarare una comprensione molto semplice, possiamo usare la parola chiave `for`, seguita da un _generatore_ e da un _blocco do_ che crea i nuovi valori a partire dai valori enumerati.

```elixir
for n <- [0, 1, 2, 3], do: n + 1
# => [1, 2, 3, 4]
```

Le comprensioni possono anche avere dei _filtri_. I valori che non superano il filtro vengono rimossi dalla lista finale:

```elixir
for n <- [0, 1, 2, 3], n > 1, do: n + 1
# => [3, 4]
```

Possiamo dichiarare comprensioni più complesse su più righe:

```elixir
for {atom, number} <- [a: 1, b: 2, c: 3, d: 4],
    rem(number, 2) == 0 do
  atom
end

# => [:b, :d]
```

Si può creare un _prodotto cartesiano_ usando più generatori. Questo significa che ogni valore generato dal primo generatore verrà abbinato una volta a ciascun valore generato dal secondo generatore:

```elixir
for x <- [0, 1],
    y <- [0, 1] do
  {x, y}
end

# => [{0, 0}, {0, 1}, {1, 0}, {1, 1}]
```
