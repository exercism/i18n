# Istruzioni

Lavori in una boutique di moda online.
Ti viene l'idea di una funzionalità del sito dove vengono suggeriti degli abbinamenti all'utente.
Ci interessano gli abbinamenti potenziali, i loro prezzi e l'eliminazione delle opzioni che stonano.

~~~~exercism/note
Anche se ci possono essere modi diversi per risolvere i problemi seguenti, tutti si possono risolvere con una comprensione.
~~~~

## 1. Crea un capo di abbigliamento


Implementa `clothingitem()` in modo che prenda due `Tuple`, uno di `categories` e l'altro delle rispettive `qualities`.
La funzione deve restituire un `Dict` con le `categories` come chiavi e le `qualities` come valori.

```julia-repl
julia> categories = ("item_name", "price", "color", "base_color");

julia> qualities = ("Descriptive Name", 99.00, "Ochre Red", "red");

julia> clothingitem(categories, qualities)
Dict{String, Any} with 4 entries:
  "price"      => 99.0
  "item_name"  => "Descriptive Name"
  "base_color" => "red"
  "color"      => "Ochre Red"
```

La funzione deve essere in grado di gestire qualsiasi numero di `categories`.

## 2. Suggerisci le combinazioni

Implementa `get_combinations()` in modo che prenda una `Tuple` di capi superiori e una `Tuple` di capi inferiori.
La funzione deve restituire il `cartesian product` delle tuple come array bidimensionale (cioè una `Matrix`).
Ogni voce è una combinazione `(top, bottom)` sotto forma di `Tuple`.
I capi superiori cambiano scendendo lungo le righe, quelli inferiori lungo le colonne.

```julia-repl
julia> tops = (
        Dict("item_name" => "Dress shirt"),
        Dict("item_name" => "Casual shirt")
        );

julia> bottoms = (
        Dict("item_name" => "Jeans"),
        Dict("item_name" => "Dress trousers")
       );

julia> get_combinations(tops, bottoms)
2×2 Matrix{Tuple{Dict{String, String}, Dict{String, String}}}:
 (Dict("item_name"=>"Dress shirt"), Dict("item_name"=>"Jeans"))   (Dict("item_name"=>"Dress shirt"), Dict("item_name"=>"Dress trousers"))
 (Dict("item_name"=>"Casual shirt"), Dict("item_name"=>"Jeans"))  (Dict("item_name"=>"Casual shirt"), Dict("item_name"=>"Dress trousers"))
```

## 3. Somma i prezzi degli abbinamenti

Ogni capo di abbigliamento ha un campo `price` associato, quindi può essere utile poter confrontare il prezzo totale di un abbinamento.
Implementa `get_prices()`, che prende un array di combinazioni di capi.
La funzione deve restituire un array della stessa forma, con i prezzi degli abbinamenti nelle rispettive posizioni.

```julia-repl
julia> tops = (
        Dict("item_name" => "Dress shirt", "base_color" => "blue", "price" => 35),
        Dict("item_name" => "Casual shirt", "base_color" => "black", "price" => 20)
       );

julia> bottoms = (
        Dict("item_name" => "Jeans", "base_color" => "blue", "price" => 30),
        Dict("item_name" => "Dress trousers", "base_color" => "black", "price" => 75)
       );

julia> combomatrix = get_combinations(tops, bottoms);

julia> get_prices(combomatrix)
2×2 Matrix{Int}::
 65  110
 50   95

julia> filteredmatrix = filter_clashing(combomatrix)
1-element Vector{Tuple{Dict{String, Any}, Dict{String, Any}}}:
 (Dict("price" => 20, "item_name" => "Casual shirt", "base_color" => "black"), Dict("price" => 30, "item_name" => "Jeans", "base_color" => "blue"))

julia> get_prices(filteredmatrix)
1-element Vector{Int}:
 50
```

## 4. Filtra gli abbinamenti che stonano

Ogni capo di abbigliamento ha un campo `base_color`.
Usa questo campo per rimuovere tutte le combinazioni in cui il capo superiore e quello inferiore hanno lo stesso colore di base.
Implementa `filter_clashing()` in modo che prenda un array di combinazioni di capi.
Restituisci un array monodimensionale (cioè un `Vector`) delle combinazioni corrispondenti.

```julia-repl
julia> tops = (
        Dict("item_name" => "Dress shirt", "base_color" => "blue", "price" => 35),
        Dict("item_name" => "Casual shirt", "base_color" => "black", "price" => 20)
       );

julia> bottoms = (
        Dict("item_name" => "Jeans", "base_color" => "blue", "price" => 30),
        Dict("item_name" => "Dress trousers", "base_color" => "black", "price" => 75)
       );

julia> combos = get_combinations(tops, bottoms);

julia> filter_clashing(combos)
1-element Vector{Tuple{Dict{String, Any}, Dict{String, Any}}}:
 (Dict("price" => 20, "item_name" => "Casual shirt", "base_color" => "black"), Dict("price" => 30, "item_name" => "Jeans", "base_color" => "blue"))
```
