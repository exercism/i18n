# Informazioni

In Factor i caratteri sono *interi*, cioè punti di codice Unicode, quindi i normali operatori numerici `<`, `>`, `=` forniscono già un ordinamento sensibile alle maiuscole e alle minuscole. Il vocabolario [`unicode`][unicode] aggiunge in più predicati che tengono conto di Unicode e la conversione di maiuscole e minuscole per singoli caratteri.

## Predicati

```
LETTER?  ( c -- ? )    ! uppercase letter
letter?  ( c -- ? )    ! lowercase letter
Letter?  ( c -- ? )    ! letter, either case
digit?   ( c -- ? )    ! decimal digit
digit>   ( c -- n )    ! the integer value of a digit char
blank?   ( c -- ? )    ! whitespace
alpha?   ( c -- ? )    ! letter or decimal digit
```

```factor
USING: unicode ;

CHAR: A LETTER? .    ! => t
CHAR: a letter? .    ! => t
CHAR: 7 digit?  .    ! => t
CHAR: \n blank? .    ! => t
```

## Conversione tra maiuscole e minuscole

```
ch>upper  ( c -- c' )
ch>lower  ( c -- c' )
ch>title  ( c -- c' )
```

Le versioni per stringhe `>upper`, `>lower` e `>title` le applicano a ogni carattere di una stringa.

```factor
CHAR: a ch>upper .   ! => 65   (which is CHAR: A)
"Hello" >upper .     ! => "HELLO"
```
