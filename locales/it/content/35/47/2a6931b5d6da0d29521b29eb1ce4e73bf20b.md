# Introduzione

Il concetto [`Basics`][basics] ha introdotto due modi per definire una funzione.

Il più generale, la forma multilinea:

```julia
function muladd(x, y, z)
    x * y + z
end
```

La forma «di assegnazione», o «a riga singola», per le definizioni brevi:
```julia
muladd(x, y, z) = x * y + z
```

In una terza forma, ancora più breve, si può creare una funzione corta e monouso senza darle un nome:

```julia-repl
julia> map(x -> 2x, 1:3)
4-element Vector{Int64}:
 2
 4
 6

julia> map((x, y) -> x * y, 1:3, 4:6)
3-element Vector{Int64}:
  4
 10
 18
```

In questo caso, `x -> 2x` è una «funzione anonima».
Equivale a quella che in altri linguaggi si chiama «funzione lambda».

Nota che con più argomenti servono le parentesi, come in `(x, y) -> x * y`.

Le funzioni anonime sono comuni nel codice Julia, soprattutto quando vengono combinate con funzioni di ordine superiore come `map()` e `filter()` (che vedremo più in dettaglio in un concetto successivo).

```julia-repl
julia> map(x -> x^4, [1, 2, 3])
3-element Vector{Int64}:
  1
 16
 81
```

## Argomenti delle funzioni

Finora nel percorso abbiamo visto solo funzioni con un numero preciso di argomenti, che richiedono che ogni chiamata li fornisca tutti, nell'ordine corretto.
Sarebbe limitante e scomodo, quindi ci sono diverse altre opzioni.

### Argomenti opzionali

Come molti linguaggi, Julia permette alle definizioni di funzione di specificare valori predefiniti per singoli argomenti.

La chiamata può quindi fornire un valore per quell'argomento, oppure ometterlo e affidarsi al valore predefinito.

```julia-repl
julia> f(x, y=10) = x * y
f (generic function with 2 methods)

julia> f(2, 3)
6

julia> f(2)
20
```

Tutti gli argomenti _senza_ un valore predefinito devono venire prima degli argomenti _con_ un valore predefinito, il che significa che `f(x=2, y)` non sarebbe valido.

### Argomenti keyword

Tutti gli esempi visti finora usano gli `positional arguments`, in cui i valori forniti in una chiamata devono corrispondere all'ordine degli argomenti corrispondenti nella definizione della funzione.

Come molti linguaggi, Julia permette anche gli `keyword arguments`.
Le chiamate di funzione devono specificare il nome dell'argomento, ma più argomenti keyword si possono specificare in qualsiasi ordine.

Una caratteristica distintiva di Julia è che gli argomenti keyword (se presenti) nella definizione della funzione devono essere preceduti da un punto e virgola `;`, per separarli dagli argomenti posizionali.
Una chiamata di funzione può usare `;` o `,` tra l'ultimo argomento posizionale e il primo argomento keyword.

```julia-repl
julia> b(x; y) = x + y
b (generic function with 1 method)

julia> b(2, y=3)
5

# keyword is required when calling
julia> b(2, 3)
ERROR: MethodError: no method matching b(::Int64, ::Int64)
The function `b` exists, but no method is defined for this combination of argument types.
```

I valori predefiniti si possono specificare facoltativamente, esattamente come per gli argomenti posizionali.

È comune ritrovarsi con una sintassi come `myarg=myarg` dentro una chiamata di funzione, quando una variabile con lo stesso nome del parametro è stata calcolata prima.
In questa situazione è ammessa una sintassi abbreviata:

```julia-repl
julia> width = 4.0
4.0

julia> height = √ width
2.0

julia> area(; width, height) = width * height
area (generic function with 1 method)

# repetition
julia> area(; width=width, height=height)
8.0

# shorthand form
julia> area(; width, height)
8.0
```

### Splat e slurp

Questi sono i nomi standard di un aspetto utile della sintassi di Julia, se te lo stavi chiedendo.
Entrambi si riferiscono all'operatore `...`.

#### Splat

Lo splat si usa nelle _chiamate_ di funzione, per espandere le collezioni nei singoli valori richiesti dalla funzione.

Forse è più facile mostrarlo che spiegarlo:

```julia-repl
julia> fxyz(x, y, z) = x * y * z
fxyz (generic function with 1 method)

julia> xyz = [2, 3, 4]
3-element Vector{Int64}:
 2
 3
 4

# Using the vector directly in a function call is invalid
julia> fxyz(xyz)
ERROR: MethodError: no method matching fxyz(::Vector{Int64})
The function `fxyz` exists, but no method is defined for this combination of argument types.

# splatting converts the vector to 3 numbers, used as positional arguments
julia> fxyz(xyz...)
24
```

Alcune «chiamate di funzione» sono nascoste dallo zucchero sintattico, quindi lo splat si può usare anche in modi meno ovvi.

Per esempio, l'assegnazione multipla usa internamente una funzione costruttrice di tuple:

```julia-repl
julia> first, rest... = [1, 2, 3, 4]
4-element Vector{Int64}:
 1
 2
 3
 4

julia> first
1

julia> rest
3-element Vector{Int64}:
 2
 3
 4
```

Anche gli argomenti keyword si possono fornire tramite splat, di solito usando una `named tuple`. 
Anche un `Dict` funziona, ma le chiavi devono essere simboli (le stringhe non funzionano).

```julia-repl
# function with 3 keyword arguments
julia> fabc(; a, b, c) = a + b + c
fabc (generic function with 1 method)

# named tuple
julia> abc_nt = (a=2, b=3, c=4)
(a = 2, b = 3, c = 4)

# there are no positional arguments, so need to use ; before kw argument
julia> fabc(;abc_nt...)
9

# Dict
julia> abc_dict = Dict(:a=>2, :b=>3, :c=>4)
Dict{Symbol, Int64} with 3 entries:
  :a => 2
  :b => 3
  :c => 4

julia> fabc(;abc_dict...)
9
```

#### Slurp

Lo slurp si usa nella _definizione_ della funzione, per impacchettare un numero arbitrario di singoli valori in una collezione.

```julia-repl
julia> f_more(i, j, more...) = i + j + sum(more)
f_more (generic function with 1 method)

julia> f_more(1, 3, 5, 7, 9, 11)
36
```

Il nome dell'argomento raccolto dallo slurp (in questo caso `more`) non è significativo.
Il tipo di questa variabile è scelto dal compilatore, ma per gli argomenti posizionali è probabilmente `tuple` o qualcosa di simile.

Anche gli argomenti keyword si possono raccogliere con lo slurp, ottenendo un `Dict` (o simile).

```julia-repl
julia> f_kwslurp(x, y; switches...) = :mult in keys(switches) ? x * y : x + y
f_kwslurp (generic function with 1 method)

julia> f_kwslurp(5, 6; mult=true)
30

julia> f_kwslurp(5, 6)
11
```

Nella chiamata si può usare qualsiasi argomento keyword.
È la definizione della funzione a decidere a quali keyword rispondere e quali ignorare.
