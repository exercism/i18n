# Uso delle specifiche di tipo

[comment]: # (Questo avviso viene mostrato quando la soluzione non ha una specifica di tipo)

Includi le [specifiche di tipo](https://elixir-lang.org/getting-started/typespecs-and-behaviours.html#types-and-specs) (`@spec`) per comunicare il contratto tra gli input e l'output di una funzione.

- Elixir è un linguaggio tipizzato dinamicamente: i controlli di tipo avvengono solo a runtime. Usare le specifiche di tipo permette a linter ed analisi statica come [`Dialyxir`](https://hexdocs.pm/dialyxir/readme.html) (basato su [`Dialyzer`](http://erlang.org/doc/man/dialyzer.html) di Erlang) di valutare il codice alla ricerca di comportamenti indesiderati.
- Puoi trovare un [elenco completo](https://hexdocs.pm/elixir/typespecs.html#basic-types) di tutti i tipi predefiniti nella [documentazione del linguaggio](https://hexdocs.pm/elixir/typespecs.html#content)
- i tipi si possono specificare con o senza parentesi tonde: `atom()` vs `atom`
  - lo stile di Exercism per Elixir è specificare senza parentesi.

```elixir
# Example 1
@spec add_one(int) :: int
def add_one(n) when is_integer(n) do
  n + 1
end

# Example 2
@spec hello(String.t) :: String.t
def hello(what \\ "world") when is_binary(what) do
  "Hello, #{what}"
end
```
