# Operatore ternario

L'operatore ternario fornisce una sintassi alternativa per eseguire un confronto `if..else..` e restituire un valore.

## Sintassi

PHP fornisce un'istruzione if in cui un'azione può essere valutata in base alla «veridicità» di una condizione.

```php
if ($condition) {
  $value = 1;
} else {
  $value = 2
}
```

In alternativa, l'operatore ternario può rappresentare la stessa operazione:

```php
$value = $condition
  ? 1  // True branch
  : 2; // False branch
```

La sintassi del confronto è breve, rappresentata da `(condition) ? (evaluate if true) : (evaluate if false);`.
