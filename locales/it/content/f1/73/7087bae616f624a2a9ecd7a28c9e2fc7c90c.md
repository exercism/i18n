# Istruzioni

C'era una volta una città frenetica chiamata Cyberspace.
Cyberspace era una metropoli digitale, con milioni di abitanti che si connettevano e disconnettevano ogni giorno.
Per tenere traccia di tutti questi utenti, Cyberspace aveva un file speciale chiamato /etc/passwd.

Il file /etc/passwd era come un elenco telefonico per la città.
Elencava ogni utente che aveva un account sul sistema, insieme ad alcune informazioni importanti su ciascun utente:

| n   | campo |
| --- | --- |
| 1   | nome utente |
| 2   | password ("x" indica che la password effettiva è memorizzata altrove, per motivi di sicurezza) |
| 3   | UID, un ID numerico univoco dell'utente |
| 4   | GID, un ID numerico univoco del gruppo (tipicamente uguale all'UID) |
| 5   | informazioni sull'utente (tipicamente il nome completo dell'utente, ma può includere altre informazioni) |
| 6   | directory home |
| 7   | shell di login |

I campi sono separati da un carattere due punti.
Questa è una voce tipica:

```none
glennj:x:1010:1010:Glenn Jackman:/home/glennj:/usr/local/bin/fish
```

Il file era gestito da un team di amministratori di sistema, responsabili di creare nuovi account, aggiornare quelli esistenti e rimuovere quelli vecchi.
Gli amministratori di sistema erano i custodi di Cyberspace. Facevano in modo che solo gli utenti autorizzati potessero accedere al sistema.

Un giorno, un nuovo amministratore di sistema di nome Alex fu assunto per unirsi al team.
Alex era entusiasta di accettare il lavoro. Imparò rapidamente tutti i segreti del file /etc/passwd.
Imparò come aggiungere nuovi utenti al sistema, come aggiornare le informazioni degli utenti e come rimuovere quelli vecchi.

Mentre Alex lavorava al file /etc/passwd, notò qualcosa di strano.
Alcuni utenti avevano directory home strane o insolite.
Alcuni utenti avevano la directory home impostata su /dev/null, mentre altri l'avevano impostata su percorsi strani che non esistevano.

Alex si rese conto che quegli utenti non erano persone reali, ma account falsi creati dagli hacker.
Gli hacker avevano trovato il modo di sfruttare una vulnerabilità del sistema ed avevano creato questi account falsi per accedere a Cyberspace.

Alex sapeva che doveva agire.
Usò awk per analizzare il file /etc/passwd e scrisse uno script per identificare tutti gli account falsi.
Poi lavorò con il resto del team per rimuovere questi account e correggere la vulnerabilità che aveva permesso agli hacker di crearli.

Grazie all'uso di awk da parte di Alex, il team riuscì a identificare e rimuovere gli account falsi ed a rendere Cyberspace un posto più sicuro per tutti.
Gli amministratori di sistema continuarono a gestire il file /etc/passwd, mantenendolo aggiornato e sicuro, ed assicurandosi che solo gli utenti autorizzati potessero accedere al sistema.

Ora tocca a te essere un amministratore di sistema come Alex.

## 1. Elenca i nomi utente

Scrivi un programma awk che stampi il primo campo separato da due punti per ogni riga del file passwd.

## 2. Stampa i numeri di riga

Scrivi un comando awk che stampi il numero di riga di ogni record nel file di input.
Stampa solo il numero di riga, non altre informazioni.

## 3. Stampa i record con directory home non valide

A Cyberspace, una directory home «valida» inizia con `/home` o `/root`.
Stampa i record del file di input con directory home **non valide**.

## 4. Stampa gli utenti validi che usano bash

Stampa i record in cui la directory home è valida **e** la shell di login è `bash`.
