# Informazioni

[Java](https://go.java/index.html) è tra i linguaggi di programmazione più diffusi, grazie alla sua versatilità e alla sua compatibilità.
È ampiamente utilizzato per lo sviluppo software, per le applicazioni mobile e per realizzare sistemi più grandi.

Java è nato nel 1995 ed è mantenuto da [Oracle](https://www.oracle.com/index.html).
Nonostante non sia giovane come alcuni dei linguaggi più recenti, Java è ancora molto popolare.
È stato progettato per essere veloce, sicuro, affidabile, adatto ai principianti e altamente portabile.
Questa portabilità esiste perché Java viene eseguito su una [Java Virtual Machine, o JVM](https://en.wikipedia.org/wiki/Java_virtual_machine) compatibile con più piattaforme.
Anche le app Android vengono sviluppate con Java, dato che il [sistema operativo Android](<https://en.wikipedia.org/wiki/Android_(operating_system)>) funziona in un ambiente basato su Java.

La comunità Java è enorme!
GitHub, per esempio, ha oltre 1,5 milioni di progetti Java.
Vale anche la pena ricordare che Java ha la seconda comunità più grande su [StackOverflow](https://stackoverflow.com/questions/tagged/java)!
Questo è importante, perché più è grande la comunità di un linguaggio di programmazione, più è probabile che tu riceva supporto.

Java ha anche un insieme potente e ben progettato di [API, cioè le interfacce di programmazione delle applicazioni](https://docs.oracle.com/en/java/javase/11/docs/api/index.html), integrate nel linguaggio, che si possono usare per varie attività: connettersi a un database, fare networking, gestire l'I/O, analizzare file XML, usare utilità e molto altro.

Dai laptop ai data center, dalle console per videogiochi ai supercomputer scientifici, dai telefoni cellulari a Internet, [Java è ovunque](https://en.wikipedia.org/wiki/Write_once,_run_anywhere)!
