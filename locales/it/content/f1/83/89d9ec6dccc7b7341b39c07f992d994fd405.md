# Istruzioni

Una banca molto impegnata serve i clienti in attesa in base alla *priorità*, non nell'ordine in cui sono arrivati. Ogni cliente riceve un numero di priorità quando prende un biglietto, e il cassiere serve sempre per primo il numero più basso (`1` è il più urgente). Un min-heap è la coda d'attesa perfetta.

## 1. Apri la coda

Definisci `new-queue`, che non prende nulla e restituisce una coda a priorità nuova e vuota.

```factor
new-queue
! => an empty priority queue
```

## 2. Aggiungi un cliente

Definisci `join-queue`, che prende il nome di un cliente, un numero di priorità e una coda. Aggiunge il cliente alla coda e restituisce la coda, così i clienti si possono aggiungere uno dopo l'altro.

```factor
new-queue "alice" 5 rot join-queue "bob" 2 rot join-queue
! => the queue, now holding alice (5) and bob (2)
```

## 3. Chi è il prossimo?

Definisci `next-name`, che prende una coda e restituisce il nome del cliente che dovrebbe essere servito per prossimo, quello con il numero di priorità più basso, *senza* rimuoverlo.

```factor
new-queue "alice" 5 rot join-queue "bob" 2 rot join-queue next-name .
! => "bob"
```

## 4. Servi tutti

Definisci `serve-all`, che prende una coda e restituisce i nomi di tutti i clienti in attesa, nell'ordine in cui verrebbero serviti.

```factor
new-queue "alice" 5 rot join-queue "bob" 2 rot join-queue
"carol" 9 rot join-queue serve-all .
! => { "bob" "alice" "carol" }
```
