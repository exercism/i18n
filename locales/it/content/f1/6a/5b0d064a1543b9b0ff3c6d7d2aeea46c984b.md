# Introduzione

In C++, puoi confrontare i valori usando gli operatori di confronto.

| Confronto         | Operatore |
| ------------------| --------- |
| uguale            | `==`      |
| diverso           | `!=`      |
| minore            | `<`       |
| minore o uguale   | `<=`      |
| maggiore          | `>`       |
| maggiore o uguale | `>=`      |

Il risultato di questi confronti è sempre un valore booleano:

```cpp
int a{3};

bool eq1 = a != 4; // true

bool eq2 = a > 5;  // false
```

Gli operatori `==` e `!=` verificano rispettivamente se un valore è uguale o no a un altro.
Ecco alcuni esempi comuni:

```cpp
bool eq3 = 2 == 3; // false, integer comparison

bool eq4 = 2.1 != 2.2; // true, float comparison

bool eq5 = "hello" == "hello"; // true, string comparison
```

Gli altri operatori verificano se un valore è maggiore (`>`), maggiore o uguale (`>=`), minore (`<`) o minore o uguale (`<=`) a un altro valore.
Questo tipo di confronto è disponibile per i numeri e per le stringhe.
Quando si confrontano le stringhe, si segue l'ordine alfabetico (noto anche come ordine lessicografico).

```cpp
bool eq6 = 2 > 3; // false, integer comparison

bool eq7 = 1.2 < 1.3; // true, float comparison

bool eq8 = "Hello" < "World"; // true, string comparison
```
