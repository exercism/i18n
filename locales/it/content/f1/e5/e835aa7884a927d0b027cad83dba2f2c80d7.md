# preferisci estrarre la costante di livello superiore

Prova a estrarre la costante nello scope di livello superiore:

```javascript
const %{name} = %{value}

// the rest of your code below it
export %{method.signature}
```

Solo le funzioni, le classi e le costanti che sono `export`ate sono visibili e accessibili dall'esterno.
Queste costanti possono restare nello stesso file senza essere esposte ad altro codice.
Inoltre, estrarre le costanti fa risparmiare memoria, evitando allocazioni ripetute all'interno delle funzioni quando le stesse costanti vengono riutilizzate.
