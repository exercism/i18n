# Introduzione

## Confronto

### Confrontare i numeri

In `jq` i numeri si possono confrontare usando i seguenti operatori relazionali e di uguaglianza.

| Confronto             | Operatore |
| ---------------------- | -------- |
| Maggiore di            | `a > b`  |
| Maggiore o uguale a    | `a >= b` |
| Minore di              | `a < b`  |
| Minore o uguale a      | `a <= b` |
| Uguale a               | `a == b` |
| Diverso da             | `a != b` |

Il risultato del confronto è sempre un valore booleano, quindi `true` o `false`.

```jq
1 < 3,      # => true
2 != 2,     # => false
1 == 1.0    # => true
            # All numbers are floating-points, so this is different syntax
            # for the exact same value.
```

### Confrontare le stringhe

Gli operatori di confronto precedenti possono essere usati anche per confrontare le stringhe.
In tal caso, si applica un ordine lessicografico.
L'ordinamento è _in base al valore del punto di codice Unicode_.

```jq
"Apple" > "Pear",   # => false
"a" < "above",      # => true
"a" == "A"          # => false
```

Devi fare attenzione quando confronti due variabili che sembrano contenere valori numerici ma sono di tipo stringa.
A causa dell'ordine lessicografico, il risultato non sarà lo stesso che confrontare valori di tipo numero.

```jq
10 < 2,     # => false
"10" < "2"  # => true (because "1" comes before "2")
```

### Uguaglianza «rigorosa»

L'operatore `==` di `jq` è simile a `===` di JavaScript, nel senso che le cose che «sembrano» uguali, ma sono di tipi diversi, non sono uguali.

```jq
"3" == 3    # => false
            # the value on the left has type string,
            # the value on the right has type number.
```

### Confrontare gli array

Due array sono uguali se tutti gli elementi corrispondenti sono uguali.

```jq
[1, 2, 3] == [1, 2, 3]      # => true
[1, 2, 3] == [1, 3, 2]      # => false, different order
[1, 2, 3] == [1, 2, "3"]    # => false, different types
```

### Confrontare gli oggetti

Due oggetti sono uguali se hanno le stesse coppie chiave-valore.

```jq
{name: "Joe", age: 42} == {age: 42, name: "Joe"}                # => true
{name: "Joe", age: 42} == {age: 42, name: "Jane"}               # => false
{name: "Joe", age: 42} == {age: "42", name: "Joe"}              # => false
{name: "Joe", age: 42} == {age: 42, name: "Joe", height: 175}   # => false

# comparisons will drill down as deeply as required
{a: {b: {c: [1, 2]}}} == {a: {b: {c: [1, 2]}}}                  # => true
{a: {b: {c: [1, 2]}}} == {a: {b: {c: [1, 2, 3]}}}               # => false
```

## Condizionali

### Espressione if

L'**espressione condizionale** di `jq` è `if A then B else C end`.

`if-then-else` è un filtro come tutte le funzioni predefinite di `jq`: prende un input e produce un output.

Se l'espressione `A` produce un valore «veritiero», allora il filtro `if` valuta `B`.
Altrimenti valuta `C`.
L'input del filtro `if` verrà passato a `B` o `C`.

```jq
42 | if . < 50 then "small" else "big" end      # => "small"
```

```jq
5 | if . % 2 == 0 then . / 2 else . * 4 end     # => 20
```

~~~~exercism/note
La clausola `else` è **opzionale**; le due istruzioni seguenti sono equivalenti.

```jq
if A then B else . end
if A then B end
```
~~~~

### Istruzioni if annidate

Si possono aggiungere altre condizioni con `elif`.

```jq
42 | if . < 33 then "small"
     elif . < 66 then "medium"
     else "big"
     end
# => "medium"
```

Usa tutte le clausole `elif` che ti servono.

### Veridicità

Gli unici valori «falsi» in `jq` sono: `false` e `null`.
Tutto il resto è «vero», persino il numero zero e la stringa vuota, l'array vuoto e l'oggetto vuoto.

### Operatori booleani

Gli **operatori booleani** `and` e `or` possono essere usati per costruire query complesse.

```jq
42 | if . < 33 or . > 66 then "big or small"
     else "medium"
     end
```

Per negare, usa `not`. Questo è un **filtro**, non un operatore.

```jq
42 | if (. < 33 or . > 66 | not) then "medium"
     else "big or small"
     end
```

### Operatore alternativo

L'**operatore alternativo** ti permette di specificare un valore «predefinito» se un'espressione è falsa o null.

```jq
A // B

# This is identical to
if A then A else B end
```

Per dimostrarlo

```jq
[3, 5, 18] | add / 2       # => 13
[]         | add / 2       # => error: null (null) and number (2) cannot be divided
[]         | add // 0 / 2  # => 0
```
