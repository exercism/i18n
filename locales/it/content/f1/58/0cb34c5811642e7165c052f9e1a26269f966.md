### Introduzione

Benvenuto al primo esercizio del track Java!

Questo documento è una guida passo passo per risolvere questo esercizio.
Le istruzioni funzionano allo stesso modo su Windows, macOS e Linux.

Anche se hai già familiarità con le basi di Java, seguire questa guida può esserti utile: ti aiuterà a capire l'output dello strumento che usiamo per compilare e testare il codice, Gradle, e ti farà conoscere alcuni schemi comuni a tutti gli esercizi di questo track.

### Struttura dell'esercizio

Quando scarichi un nuovo esercizio Java, ricevi:

- __uno o più file di test__ (sempre).
Si trovano nella directory `src/test/java` e definiscono una serie di test che la soluzione deve superare prima di poter dichiarare con sicurezza che funziona.
- __uno o più file di partenza__ (all'inizio).
Se presenti, si trovano nella directory `src/main/java` e definiscono gli scheletri delle classi che ti serviranno per risolvere il problema.

### Passaggio 1: Correggere la soluzione

Sia lavorando in locale sia usando l'editor online, dovresti trovare il seguente codice:

```java
String getGreeting() {
    return "Goodbye, Mars!";
}
```

L'obiettivo è modificare il codice fornito in modo che produca il testo `"Hello, World!"` invece di `"Goodbye, Mars!"`.

### Passaggio 2: Eseguire i test

Dopo aver apportato le correzioni e implementato la soluzione, esegui di nuovo i test.
Puoi eseguire i test usando l'editor online oppure in locale sul tuo computer:

- Per eseguire i test nell'editor online, premi "Esegui i test".
- Per eseguire i test in locale, dai un'occhiata a [Testare sul track Java][Testing locally on the java track]. Se i test falliscono, non c'è problema! Guarda cosa ti dice il messaggio di errore, modifica il codice e prova di nuovo. Quando i test passano, passa al passaggio successivo.

### Passaggio 3: Inviare la prima iterazione

Con una soluzione funzionante che abbiamo esaminato, siamo pronti a inviarla su exercism.org.
Puoi inviare la soluzione usando l'editor online oppure in locale con la [CLI di Exercism][Working Locally]:

- Per inviare l'esercizio in locale, prima [installa la CLI di Exercism][Working Locally] se non l'hai già fatto, poi invia i file della soluzione, ad esempio:

  ```sh
  exercism submit <file location>
  ```

- Sostituisci `<file location>` con il percorso relativo del file `Greeter.java`, quindi se stai lavorando in `C:\exercism\java\hello-world` il comando sarà

  ```sh
  exercism submit .\src\main\java\Greeter.java
  ```

- Se vuoi usare l'editor online per inviare la soluzione, ti basta premere il pulsante "Invia"!

Per saperne di più su come inviare una soluzione in locale:

- [Inviare in locale][Working Locally]

### Diventa un mentore

Il cuore di Exercism sono le conversazioni sulle pratiche di programmazione.
Fare pratica è sicuramente divertente, ma è confrontandoti con gli altri, sui loro tentativi come su quelli che fai tu, che ottieni un feedback.
Quel feedback può aiutarti a capire cosa stai facendo bene e dove potresti migliorare.

Alcune soluzioni inviate saranno quasi identiche a quella che hai scritto, altre saranno completamente diverse.
Vedere entrambi i tipi può essere istruttivo e interessante.

I mentori esaminano le soluzioni inviate per il track di cui hanno scelto di essere mentori, per aiutare gli utenti a imparare il più possibile.

Per saperne di più sul mentoring, consulta la [documentazione di Exercism][Mentoring].
