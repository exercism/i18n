# Introduzione

A differenza di molti altri linguaggi, in JavaScript ci sono due entità diverse che rappresentano l'assenza di un valore (significativo).
Si tratta di `null` e `undefined`.

## Null

Il valore primitivo `null` viene usato come «valore vuoto» intenzionale per variabili di qualsiasi tipo.

```javascript
let name = null;
// name is intentionally set to "empty" because it is not
// available
```

Puoi verificare se una variabile è null usando l'[operatore di uguaglianza stretta][mdn-strict-equality] `===`.

```javascript
let name = null;

name === null;
// => true
```

## Undefined

> Una variabile a cui non è stato assegnato un valore è di tipo `undefined`.[^1]

Questo significa che, mentre `null` rappresenta un valore vuoto (ma pur sempre un valore), `undefined` rappresenta l'assenza totale di un valore. 🤯

`undefined` compare in contesti diversi.

- Se una variabile viene dichiarata senza un valore (inizializzazione), è `undefined`.

  ```js
  let name;
  console.log(name); // => undefined
  ```

- Se provi ad accedere a un valore per una chiave inesistente in un oggetto, ottieni `undefined`.

  ```js
  let obj = {
    name: 'John',
  };
  console.log(obj.age); // => undefined
  ```

- Se una funzione non restituisce un valore, il risultato è `undefined`.

  ```js
  function printName(name) {
    'My name is ' + name;
  }
  console.log(printName('John')); // => undefined
  ```

- Se non viene passato un argomento a una funzione, questo è `undefined`, a meno che quell'argomento non abbia un valore predefinito.

  ```js
  function printName(name) {
    return name;
  }
  console.log(printName()); // => undefined
  ```

Puoi verificare se una variabile è undefined usando l'operatore di uguaglianza stretta `===`.

```javascript
let name;

name === undefined;
// => true
```

## Optional Chaining

Se provi a recuperare un valore annidato in un oggetto ma la chiave genitore non esiste, JavaScript genera un errore.
Per evitare facilmente questo problema, l'optional chaining è stato aggiunto alla specifica del linguaggio nel 2020.
Con l'operatore di optional chaining `?.` puoi fare in modo che JavaScript provi ad accedere alla chiave annidata solo se il genitore non era `null` o `undefined`.
Altrimenti viene restituito `undefined`.

```javascript
const obj = {
  address: {
    street: 'Trincomalee Highway',
    city: 'Batticaloa',
  },
};

obj.address.zipCode;
// => undefined

obj.residence.street;
// => TypeError: Cannot read property 'street' of undefined

obj.residence?.street;
// => undefined
```

## Nullish Coalescing

Ci sono situazioni in cui vuoi applicare un valore predefinito nel caso in cui una variabile sia null o undefined (ma solo in quel caso).
Per risolvere questo, nel 2020 è stato introdotto l'operatore di nullish coalescing `??`.
Restituisce l'operando a destra solo quando l'operando a sinistra è `null` o `undefined`.
In caso contrario, viene restituito l'operando a sinistra.

```javascript
let amount = null;
amount = amount ?? 1;
// => 1

amount = 0;
amount = amount ?? 1;
// => 0
```
