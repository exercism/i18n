# Introduzione

## I numeri

Lua usa due rappresentazioni per i numeri: numeri interi a 64 bit e numeri in virgola mobile a doppia precisione. Supporta il consueto insieme di operatori aritmetici: addizione, sottrazione, moltiplicazione, divisione e negazione. Inoltre supporta la divisione intera, il modulo e l'elevamento a potenza.

| Operatore | Esempio             |
| --------- | ------------------- |
| `+`       | `1 + 2 --> 3`       |
| `-`       | `2 - 1 --> 1`       |
| `*`       | `2 * 2 --> 4`       |
| `/`       | `4 / 2 --> 2.0`     |
| `//`      | `11 // 3 --> 3`     |
| `%`       | `11 % 3 --> 2`      |
| `^`       | `10 ^ 2 --> 100.0`  |
| `-`       | `-(2 * 2) --> -4`   |
