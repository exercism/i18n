# Suggerimenti

## Generale

- Leggi la documentazione di [MapSet][mapset]
- Anche la documentazione di [Enum][enum] potrebbe esserti utile

## 1. Inizia una collezione

- [Questa è la funzione `MapSet` più adatta][new] per risolvere il compito

## 2. Fai crescere la collezione

- Usa [questa funzione `MapSet`][put] per aggiungere carte alla tua collezione
- Usa [quella funzione `MapSet`][member] per controllare se hai una carta specifica nella tua collezione

## 3. Inizia a scambiare

- Per controllare se puoi scambiare una carta, usa [questa funzione `MapSet`][member]
- Per aggiornare la tua collezione, usa [questa funzione `MapSet`][delete] e [quella][put]

## 4. Ce ne può essere solo una per tipo

- Un `MapSet` ha la proprietà di contenere solo valori unici
- Usa [questa funzione `MapSet`][new] per creare un set e [quella][to_list] per riconvertirlo in una lista
- I `MapSet` non hanno un concetto di ordine: dovresti usare [questa funzione `Enum`][sort] per ordinare le carte, anche se i test passano senza

## 5. Le carte che non hanno

- Usa [questa funzione `MapSet`][difference] per controllare le differenze tra le collezioni
- Usa [quella funzione `MapSet`][size] per ottenere il numero di carte in una collezione

## 6. Le carte che hanno tutte

- [Questa funzione `Enum`][reduce] ti sarà utile per scorrere tutte le collezioni
- Usa il pattern matching sulla lista per distinguere le liste vuote da quelle non vuote
- [Questa funzione `MapSet`][intersection] ti aiuterà a tenere le carte in comune
- [Questa funzione `MapSet`][to_list] può creare una lista
- I `MapSet` non hanno un concetto di ordine: dovresti usare [questa funzione `Enum`][sort] per ordinare le carte, anche se i test passano senza

## 7. Tutte le carte

- [Questa funzione `Enum`][reduce] ti sarà utile per scorrere tutte le collezioni
- Usa [questa funzione `MapSet`][new_empty] come accumulatore
- [Questa funzione `MapSet`][union] ti aiuterà ad accumulare tutte le carte
- [Questa funzione `MapSet`][size] conterà quante carte hai

## 8. Shiny per la vittoria

- Usa [questa funzione `MapSet`][split_with] per separare la tua collezione
- Usa [questa funzione `String`][starts_with] per individuare le carte shiny
- [Questa funzione `MapSet`][to_list] può creare una lista
- I `MapSet` non hanno un concetto di ordine: dovresti usare [questa funzione `Enum`][sort] per ordinare le carte, anche se i test passano senza
