# Istruzioni

In **Chrono Realms**, i Time Keepers hanno spesso a che fare non solo con alberi di linee temporali, ma con le **Chrono Chains**: sequenze di **TimeNode** collegati tra loro, ognuno dei quali rappresenta un momento specifico nel tempo.
Una **Chrono Chain** è un percorso lineare di momenti sequenziali, in cui ogni **TimeNode** si collega al successivo.
Queste **Chrono Chains** sono utili quando si viaggia attraverso una serie di eventi specifici: permettono ai Time Keepers di seguire un'unica linea temporale.

Tuttavia, per gestire **Chrono Chains** potenzialmente lunghe, i Time Keepers usano gli **Smart Pointers (Box<T>)** per gestire e attraversare in sicurezza queste liste di momenti, senza causare inutili duplicazioni di memoria o overflow.
Ogni **TimeNode** contiene un riferimento al nodo successivo, formando una struttura ricorsiva.

Il tuo compito, come apprendista, è implementare una **Chrono Chain** come struttura di lista ricorsiva usando i puntatori intelligenti.

In questo esercizio dovrai:

1. Creare un enum ricorsivo `ChronoChain`, che rappresenta una lista di momenti.
2. Usare il puntatore intelligente `Box<T>` per memorizzare i nodi ricorsivi.
3. Implementare una funzione che crea una `ChronoChain` a partire da un array di valori `u32`.
4. Implementare una funzione che attraversa la `ChronoChain` e somma i valori memorizzati nella lista.

## 1. Definire l'enum ricorsivo `ChronoChain`

Crea un enum ricorsivo `ChronoChain` con due varianti:

- `End`: rappresenta la fine della lista.
- `Link`: contiene un valore `u32` e un riferimento racchiuso in un box al nodo successivo della catena.

## 2. Creare una funzione che costruisce una ChronoChain

Scrivi una funzione `ChronoChain::build` che prende un array di valori `u32` e restituisce una `ChronoChain`, collegando i valori in sequenza tramite puntatori intelligenti.

## 3. Implementare la funzione di somma

Scrivi una funzione `ChronoChain::sum` che attraversa ricorsivamente la `ChronoChain` e somma i valori di tutti i nodi.

## Esempio di utilizzo

```rust
fn main() {
    // Create a ChronoChain from an array of values
    let chrono_chain = ChronoChain::build(array![10, 20, 30]);

    // Sum the values in the ChronoChain
    let total_sum = chrono_chain.sum();

    println!("Total Time Power: {}", total_sum);
}
```
