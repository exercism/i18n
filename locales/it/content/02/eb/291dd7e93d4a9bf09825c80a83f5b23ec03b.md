# Concetti di Anno bisestile

Preferisco la prima soluzione di esempio, perché la sua concisione segue quello che ho visto nel Rust idiomatico. Evita anche l'aggiunta del concetto di closure presente nella soluzione canonica.

## Concetti estratti

### Generali

- Logica booleana
  - booleano
- Espressioni
  - le funzioni di Rust restituiscono espressioni in modo implicito
- Aritmetica
  - operatore modulo

### Tipi

- interi senza segno: `u64`
- booleani: `bool`

## Esercizio di esempio 1

la soluzione di ["desi-belokonska"](https://exercism.org/tracks/rust/exercises/leap/solutions/01d024321b6a491690321844aedf8b09)

```rust
pub fn is_leap_year(year: u64) -> bool {
  year % 400 == 0 || year % 4 == 0 && year % 100 != 0
}
```

## Esercizio di esempio 2

[Canonica](https://github.com/exercism/rust/blob/master/exercises/leap/example.rs)

```rust
pub fn is_leap_year(year: u64) -> bool {
    let has_factor = |n| year % n == 0;
    has_factor(4) && (!has_factor(100) || has_factor(400))
}
```
