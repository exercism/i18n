# Introduzione

Con un ciclo while puoi eseguire del codice ripetutamente finché una certa condizione è soddisfatta.
Si scrive con la parola chiave `while`, seguita da una condizione tra parentesi tonde e da un blocco di codice tra parentesi graffe che contiene il _corpo_ del ciclo.

```javascript
while (condition) {
  // code that is executed repeatedly as long as the condition is true
}
```

JavaScript ha anche un ciclo do-while.
Qui la condizione viene controllata dopo che il corpo del ciclo è stato eseguito.
Questo è utile quando la condizione dipende dal risultato del codice nel corpo.

```javascript
do {
  // The code here will always be executed once and then
  // repeatedly while the condition is true.
} while (condition);
```

All'interno del corpo di un ciclo puoi usare la parola chiave `break` per interrompere del tutto l'esecuzione del ciclo.
Al contrario, la parola chiave `continue` interrompe solo l'esecuzione dell'iterazione corrente e prosegue con quella successiva.
Con `continue` puoi spesso evitare di racchiudere grandi parti del corpo del ciclo in un'istruzione if.

```javascript
let i = 0;

while (i < 100) {
  i = i + 2;

  if (i % 3 === 0) {
    continue;
  }

  // The code here will only be executed when i was not divisible
  // by 3 in the check above.
}
```
