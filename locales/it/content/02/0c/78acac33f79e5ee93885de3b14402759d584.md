# Manipolazione di bit

Crystal ha operatori bitwise per manipolare [`Int`][ints] a livello binario.

## Operatori di shift

Crystal ha [operatori di shift][shift] per spostare i bit verso sinistra (`<<`) o verso destra (`>>`).

### Shift a sinistra (`<<`)

L'operatore di shift a sinistra (`<<`) sposta i bit verso sinistra.
Il valore da spostare è specificato a sinistra e il numero di posizioni di cui spostarlo è a destra.

```crystal
0b0010 << 1
# => 0b0100

0b0010 << 2
# => 0b1000
```

Se il numero è negativo, lo spostamento avverrà invece verso destra.

```crystal
0b0010 << -1
# => 0b0001
```

### Shift a destra (`>>`)

L'operatore di shift a destra (`>>`) sposta i bit verso destra.
Come per l'operatore di shift a sinistra, il valore da spostare è specificato a sinistra e il numero di posizioni di cui spostarlo è a destra.

```crystal
0b0100 >> 1
# => 0b0010

0b0100 >> 2
# => 0b0001
```

Ed analogamente, l'operatore sposterà verso sinistra se il numero è negativo.

```crystal
0b0100 >> -1
# => 0b1000
```

## Operatori binari

Crystal ha 3 [operatori binari][binary] (`&`, `|`, `^`) ed un operatore `~` per eseguire operazioni bitwise.

### AND bitwise (`&`)

L'operatore binario AND (`&`) esegue un AND bitwise su due valori.
Confronta ogni bit del primo valore con il bit nella stessa posizione del secondo valore.
Il bit risultante è impostato a 1 se entrambi i bit sono 1.
Altrimenti, è impostato a 0.

```crystal
0b0011 & 0b1010
# => 0b0010
```

### OR bitwise (`|`)

L'operatore binario OR (`|`) esegue un OR bitwise su due valori.
Anche in questo caso, confronta ogni bit del primo valore con il bit nella stessa posizione del secondo valore.
Se almeno uno dei due bit è 1, il bit risultante è impostato a 1.
Altrimenti, è impostato a 0.

```crystal
0b0011 | 0b1010
# => 0b1011
```

### XOR bitwise (`^`)

L'operatore binario XOR (`^`) esegue un XOR bitwise.
Come gli operatori AND e OR bitwise, confronta ogni bit del primo valore con il bit nella stessa posizione del secondo valore.
Se _solo uno_ dei due è 1, il bit risultante è 1.
Altrimenti, è 0.

```crystal
0b0011 ^ 0b1010
# => 0b1001
```

### NOT bitwise (`~`)

Infine, l'operatore NOT bitwise (`~`) inverte ciascun bit del valore.
A differenza degli altri operatori binari, questo è un operatore unario, che opera solo sul valore a destra.

```crystal
~0b1110_0010
# => 0b0001_1101
```
