# Introduzione

Gli array e le liste contengono una collezione ordinata di scalari.
A parte l'uso dei riferimenti (che tratteremo in un concetto separato), questo significa che gli array e le liste sono sempre piatti, cioè non possono contenere altri array o altre liste.

Nella maggior parte dei casi, le liste sono racchiuse tra parentesi tonde `()` e i loro elementi sono separati da virgole `,`.

Di solito si popola una variabile array assegnandole una lista, ad esempio `my @names = ('Alice', 'Bob', 'Charlie');`.

Si può accedere agli elementi di un array o di una lista specificando gli indici tramite un pedice, ad esempio `('Alice', 'Bob', 'Charlie')[1] # 'Bob'`.

Gli indici in Perl partono da `0`.
Gli indici negativi contano a partire dalla fine dell'array o della lista, ad esempio `('Alice', 'Bob', 'Charlie')[-1] # 'Charlie'`.

## Funzioni

Ci sono molte funzioni pensate per operare su array e liste: tra le più utili ci sono [grep][grep], per ottenere una nuova lista di elementi filtrati che soddisfano una condizione, [map][map], per trasformare gli elementi in una nuova lista di valori, e [sort][sort], per ottenere una nuova lista di elementi riordinati.

Tra le funzioni per manipolare gli array ci sono [push][push] per aggiungere elementi in fondo, [pop][pop] per rimuovere l'ultimo elemento, [shift][shift] per rimuovere il primo elemento, [unshift][unshift] per aggiungere elementi in testa, e [splice][splice] per modifiche più complesse.

Anche iterare su array e liste con un'istruzione [for(each)][perlsynforeach] sarà qualcosa che incontrerai spesso.

## Variazione del sigil

Quando accedi agli elementi di un array, il sigil usato determina il risultato.
Il pedice `[]` alla fine del nome della variabile è quello che dice a Perl che stai accedendo a un array con quel nome.

```perl
my @names = ('Alice', 'Bob', 'Charlie');

$names[0]; # 'Alice'      <- A scalar
@names[0]; # ('Alice')    <- A slice (with only one index, this probably isn't what you want. There will be a warning.)
%names[0]; # (0, 'Alice') <- A key/index + value slice

$names[1, 2]; # 'Charlie'                <- A scalar (via unsupported syntax for an ancient feature. Probably not what you want. There will be a warning.)
@names[1, 2]; # ('Bob', 'Charlie')       <- A slice
%names[1, 2]; # (1, 'Bob', 2, 'Charlie') <- A key/index + value slice
```

Anche se è consentito, per leggibilità è consigliabile non far condividere lo stesso nome a variabili di tipo diverso.

## Array e liste

Array e liste hanno molte somiglianze e in molti contesti si possono usare in modo intercambiabile, ma non sono la stessa cosa.
Una lista è una collezione fissa e immutabile di scalari.
Un array è una collezione variabile di scalari, in cui il contenuto e la dimensione dell'array stesso possono cambiare.

In alcuni contesti si comportano in modo diverso.
Un array usato in contesto scalare ti dà la dimensione dell'array.
Una lista usata in contesto scalare ti dà l'ultimo elemento della lista e, potenzialmente, anche qualche avviso sul fatto che il resto del suo contenuto viene usato in contesto void.

```perl
my @names = ('Alice', 'Bob', 'Charlie');

scalar @names; # 3
scalar ('Alice', 'Bob', 'Charlie'); # 'Charlie' (and some warnings).
```
