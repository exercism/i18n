# Batch di pagamenti nel database

## Descrizione del problema

Devi inserire un batch di dati di pagamento nella tabella `Payment`. Il tuo compito è leggere i dati di pagamento dal file JSON di input fornito e usare l'operazione `batchExecute` del client JDBC per inserire i dati di pagamento nella tabella `Payment`. Il file di input di esempio è `payments.json`.

Il contenuto del file JSON di input si basa sul seguente schema JSON.

```json
{
  "type": "array",
  "items": [
    {
      "type": "object",
      "properties": {
        "employee_id": {
          "type": "integer"
        },
        "amount": {
          "type": "number"
        },
        "reason": {
          "type": "string"
        },
        "date": {
          "type": "string"
        }
      },
      "required": [
        "employee_id",
        "amount",
        "reason",
        "date"
      ]
    }
  ]
}

```

Devi restituire come output gli ID di pagamento generati automaticamente per i dati di pagamento inseriti nel batch, senza eseguire un'altra query sul database.

Puoi presumere che gli `employee_id` indicati nel file `payments.json` siano validi e già presenti nella tabella `Employee`.

## Dettagli del database

Per questo problema, usa il database H2 fornito.

> Il file del database di esempio è `gofigure.mv.db` e il nome del database è `gofigure`. Si trova all'interno della cartella `db`.

Le seguenti tabelle sono già presenti nel database H2 di esempio con alcuni dati di esempio. I nomi delle colonne e i tipi di dati sono riportati di seguito.

**Nome della tabella**: `Employee`

| **Colonne:**      | tipo |
| -----------       | ----------- |
| `employee_id`     | intero, chiave primaria con auto-incremento       |
| `name`            | stringa        |
| `city`            | stringa        |
| `department`      | stringa        |
| `age`             | intero        |

**Nome della tabella**: `Payment`

| **Colonne:**      | tipo |
| -----------       | ----------- |
| `payment_id`      | intero, chiave primaria con auto-incremento       |
| `date`            | data        |
| `amount`          | decimale        |
| `employee_id`     | intero        |
| `reason`          | stringa        |

* Il file del database è `gofigure.mv.db`. Usa l'URL JDBC `jdbc:h2:file:/path/to/db/file`
* Nome utente: `root`
* Password: `root`

## Vincoli

* Usa il file del database H2 fornito nella cartella `db` per validare le query e l'esempio Ballerina
* Usa l'approccio dei parametri di dipendenza Maven per aggiungere il driver del database H2 come dipendenza di piattaforma nel tuo Ballerina.toml
* Devi trovare gli ID di pagamento generati automaticamente senza eseguire un'altra query sul database.

## Ambiente di test

* Puoi eseguire i test con `bal test`, che li eseguirà sul database di esempio fornito.

## Esempi

### Esempio 1

**Input:** dbFilePath: `"/path/to/file/gofigure"`, paymentFilePath: `"/path/to/file/payments.json"`

Dati di esempio del file `payments.json`:

```json
[{
        "employee_id": 4,
        "amount": 12500.50,
        "reason": "Fuel for the month January",
        "date": "2022-02-03"
    },
    {
        "employee_id": 1,
        "amount": 10500.50,
        "reason": "Medical Expenses for the month January",
        "date": "2022-02-04"
    },
    {
        "employee_id": 4,
        "amount": 500.50,
        "reason": "Fuel for the month February",
        "date": "2022-03-03"
    }
]

```

**Output:** `[1,2,3]`

## Suggerimenti

* Usa il modulo [ballerinax/java.jdbc](https://central.ballerina.io/ballerinax/java.jdbc) per lavorare con il database
* Consulta la sezione [Prerequisiti](https://lib.ballerina.io/ballerinax/java.jdbc/latest) per i passaggi necessari ad aggiungere il driver JDBC come dipendenza
* Usa [io:fileReadJson](https://lib.ballerina.io/ballerina/io/latest/functions#fileReadJson) per leggere il file JSON di input
* Converti i valori JSON in tipi specifici dell'applicazione per lavorare con i dati in modo type-safe. Consulta l'esempio [Conversione in un tipo definito dall'utente](https://ballerina.io/learn/by-example/convert-from-json-to-user-defined-type/)
* Usa [sql:ParameterizedQuery](https://lib.ballerina.io/ballerina/sql/latest#ParameterizedQuery) e il metodo remoto [batchExecute](https://lib.ballerina.io/ballerinax/java.jdbc/latest#Client-batchExecute) per lavorare con il database
* Consulta l'esempio [esecuzione in batch](https://ballerina.io/learn/by-example/mysql-batch-execute-operation/)
