# Suggerimenti

## Generale

- Il namespace `clojure.string` contiene molte utili [funzioni di manipolazione delle stringhe][string-ns].

## 1. Ottieni il messaggio da una riga di log

- Puoi usare la funzione [`split`][split] per dividere una stringa in base a un'espressione regolare.
- Puoi usare la funzione [`trim`][trim] per rimuovere gli spazi bianchi all'inizio e alla fine di una stringa.

## 2. Ottieni il livello di log da una riga di log

- Una `string` può essere convertita in minuscolo con [`lower-case`][lower-case].

## 3. Riformatta una riga di log

- Puoi usare la funzione [`str`][str] per concatenare le stringhe.

[split]: https://clojuredocs.org/clojure.string/split
[str]: https://clojuredocs.org/clojure.core/str
[string-ns]: https://clojuredocs.org/clojure.string
[trim]: https://clojuredocs.org/clojure.string/trim
