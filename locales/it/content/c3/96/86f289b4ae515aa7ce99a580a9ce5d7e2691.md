# Istruzioni

Converti un numero, rappresentato come una sequenza di cifre in una base, in qualsiasi altra base.

Implementa la conversione di base in generale. Dato un numero in base **a**,
rappresentato come una sequenza di cifre, convertilo in base **b**.

## Nota

- Prova a implementare la conversione da solo.
  Non usare qualcos'altro per eseguire la conversione al posto tuo.

## Sulla [notazione posizionale](https://en.wikipedia.org/wiki/Positional_notation)

Nella notazione posizionale, un numero in base **b** può essere inteso come una combinazione
lineare di potenze di **b**.

Il numero 42, *in base 10*, significa:

(4 * 10^1) + (2 * 10^0)

Il numero 101010, *in base 2*, significa:

(1 * 2^5) + (0 * 2^4) + (1 * 2^3) + (0 * 2^2) + (1 * 2^1) + (0 * 2^0)

Il numero 1120, *in base 3*, significa:

(1 * 3^3) + (1 * 3^2) + (2 * 3^1) + (0 * 3^0)
