# Introduzione

La classe Lambda è una raccolta di metodi funzionali per usare la programmazione in stile funzionale con Haxe. Ci permette di operare su un intero Iterable in una volta sola. Spesso è preferibile rispetto alle routine con cicli, perché è meno soggetta a errori e più facile da leggere. Per comodità, la classe Array e la classe List contengono alcuni dei metodi più usati della classe Lambda.

Alcune delle funzioni della classe `Lambda` includono:

- `Lambda.array`, `Lambda.list` Converte un Iterable in Array o List. Restituisce sempre una nuova istanza.
- `Lambda.count` Conta il numero di elementi. Se l'Iterable è un Array o una List, è più veloce usare la sua proprietà length.
- `Lambda.has` Determina se l'elemento specificato è presente nell'Iterable.
- `Lambda.indexOf` Trova l'indice dell'elemento specificato.
- `Lambda.find` Trova il primo elemento che soddisfa la funzione di ricerca data.
- `Lambda.concat` Unisce due Iterable, restituendo una nuova List.
- `Lambda.filter` Trova gli elementi che soddisfano un criterio, restituendo una nuova List.

Un esempio che mostra alcune funzioni:

```haxe
using Lambda;

class Main {
  static function main() {
    var words = ["boat", "dog", "phone", "cat", "food"];

    var isThreeLetters = function(word) return word.length == 3;

    trace(words.filter(isThreeLetters)); // [dog,cat]
  }
}
```
