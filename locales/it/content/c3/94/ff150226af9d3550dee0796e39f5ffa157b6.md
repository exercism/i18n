# Suggerimenti

## Generale

- Ci sono tre [operatori booleani][boolean-operators] per lavorare con valori booleani scalari.
- Più operatori si possono combinare in un'unica espressione.

## 1. Verifica se è possibile sferrare un attacco rapido

- L'operatore logico NOT (`!`) può essere posto prima di un'espressione per negarne il valore.

## 2. Verifica se si può spiare il gruppo

- Gli operatori booleani si usano tipicamente per valutare se due o più espressioni sono `TRUE` o no`!`

## 3. Verifica se si può mandare un segnale al prigioniero

- Gli operatori booleani vengono eseguiti nell'ordine della loro precedenza (dalla più alta alla più bassa): `!`, `&&`, `||`.
- In generale, si consiglia di usare le parentesi per rendere più chiara la tua intenzione.

## 4. Verifica se si può liberare il prigioniero

- Gli operatori booleani vengono eseguiti nell'ordine della loro precedenza (dalla più alta alla più bassa): `!`, `&&`, `||`.
- In generale, si consiglia di usare le parentesi per rendere più chiara la tua intenzione.
