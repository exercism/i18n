# Installazione

## Installare la Clojure CLI
Clojure fornisce strumenti a riga di comando che si possono usare per avviare un REPL di Clojure, usare le librerie di Clojure e Java e avviare programmi Clojure.

Se devi installare Java, ti consigliamo [Adoptium Temurin 17](https://adoptium.net/).

### Linux
Assicurati che siano installate le seguenti dipendenze: `bash`, `curl`, `rlwrap` e `Java`. 
Puoi installare Clojure in uno di questi 2 modi:

1. LinuxBrew: richiede [Homebrew](https://brew.sh/)

```bash
brew install clojure/tools/clojure
```

2. Script di installazione

```bash
curl -O https://download.clojure.org/install/linux-install-1.11.1.1347.sh
chmod +x linux-install-1.11.1.1347.sh
sudo ./linux-install-1.11.1.1347.sh
```

### Homebrew per Mac OS X
Installa gli strumenti a riga di comando con brew dal tap [clojure/tools](https://github.com/clojure/homebrew-tools):

```bash
brew install clojure/tools/clojure
```

#### Java

Va bene qualsiasi distribuzione di Java. Se serve, puoi installare Temurin con brew:

```bash
brew tap homebrew/cask-versions
brew install --cask temurin17
```

### Windows

Clojure su Windows è migliorato molto di recente. In passato consigliavamo di usare WSL2, che funziona benissimo, ma ora c'è un installer PowerShell. Al momento Clojure su Windows è in fase alpha: per i problemi noti, vedi [clj-on-windows](https://github.com/clojure/tools.deps.alpha/wiki/clj-on-Windows#known-issues).

Assicurati che Java sia installato e che la variabile d'ambiente `JAVA_HOME` sia impostata, poi esegui:

```powershell
iwr -useb download.clojure.org/install/win-install-1.11.1.1165.ps1 | iex
```

Un altro modo per installare Clojure su Windows è con il gestore di pacchetti [Scoop](https://scoop.sh/). Per installare scoop, apri PowerShell ed esegui questi 2 comandi, uno dopo l'altro:

 ```sh
 iwr -useb get.scoop.sh | iex
Set-ExecutionPolicy RemoteSigned -Scope CurrentUser -Force
```

Per installare Clojure con Scoop devi prima aggiungere due bucket importanti:

```sh
# if you don't have git version control system installed
# it is required for adding new external buckets to your scoop installer
# you can skip this step otherwise
scoop install git

# add scoop bucket for Java 
scoop bucket add java

# add scoop bucket for clojure build
scoop bucket add scoop-clojure https://github.com/littleli/scoop-clojure
```

Ora siamo pronti a installare Java e Clojure eseguendo i seguenti comandi:

```sh
# install Java runtime and compiler
scoop install adoptopenjdk-lts-hotspot

# install official clojure tools
scoop install clojure

# update to the newest version
scoop update clojure
```

Dopo aver eseguito correttamente i passaggi precedenti, dovresti riuscire ad avviare Clojure con il comando seguente:

```sh
clj
```

## Installare Leiningen (opzionale)

Anche se non è più necessario, continuiamo a supportare il completo strumento di gestione dei progetti [Leiningen](https://leiningen.org/). Offre tante attività utili, come test comodi, build e un REPL migliorato.

1. Scarica lo [script lein](https://raw.githubusercontent.com/technomancy/leiningen/stable/bin/lein) o [lein.bat](https://raw.githubusercontent.com/technomancy/leiningen/stable/bin/lein.bat) (Windows)
2. Mettilo nel tuo `$PATH`, dove la tua shell può trovarlo (ad es. `/usr/local/bin/`)
3. Rendilo eseguibile (`sudo chmod a+x /usr/local/bin/lein`)
4. Esegui `lein`.
