# Introduzione

L'attributo Flags consente di rappresentare i valori definiti in un'unione discriminata come posizioni di bit (cioè flag).
Come flag, tali valori possono essere combinati, rendendo così possibile rappresentare più condizioni booleane in un unico valore.

```fsharp
[<Flags>]
type PhoneFeatures =
| Call = 1
| Text = 2
```

```fsharp
[<Flags>]
type PhoneFeaturesBinary =
| Call = 0b00000001
| Text = 0b00000010
```

Impostare un flag si può fare con l'operatore OR bit per bit (`|||`); rimuovere un flag si può fare con una combinazione dell'operatore AND bit per bit (`&&&`) e dell'operatore di negazione bit per bit (`~~~`).
Per controllare lo stato di un flag si può usare l'operatore AND bit per bit, ma si può anche usare il metodo `HasFlag()`.

```fsharp
let features = PhoneFeatures.Call

// Set the Text flag
let moreFeatures = features ||| PhoneFeatures.Text

moreFeatures.HasFlag(PhoneFeatures.Call) // => true
moreFeatures.HasFlag(PhoneFeatures.Text) // => true
```
