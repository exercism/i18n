# Introduzione

Il tipo `char` di F# è un valore a 16 bit che rappresenta la più piccola componente indirizzabile del testo; è immutabile per impostazione predefinita.

I `char` si possono definire come letterali con gli apici singoli:

```fsharp
let ch = 'A'
// => val ch: char = 'A'
```

Le stringhe sono una sequenza di char.

Un singolo `char` si può estrarre da una stringa con l'indicizzazione (che parte da zero):

```fsharp
"Exercism"[4] //  =>  'c'
```

Iterando su una stringa si ottiene un `char` a ogni passo.

Il prossimo esempio usa una funzione di ordine superiore e una funzione anonima, per comodità.
Ne parleremo come si deve più avanti nel programma del corso, ma per ora basti sapere che sono essenzialmente un modo conciso per scrivere un ciclo sui caratteri di una stringa.

```fsharp
Seq.map (fun c -> c, int c) "F#"  //  =>  [('F', 70); ('#', 35)]
```

Come mostrato sopra, un `char` può essere convertito nel suo valore `int`.
Questo funziona anche (*almeno in alcuni casi*) per altre scritture:

```fsharp
Seq.map (fun c -> c, int c) "東京"  //  =>  [('東', 26481); ('京', 20140)]
```

Quando si confrontano i caratteri, viene usato l'Int16 sottostante:

```fsharp
'A' < 'D'  // =>  true
```

Inoltre, un `int` può essere convertito in `char`:

```fsharp
char 77  // => 'M'
```

La libreria `System.Char` contiene l'insieme completo dei metodi che ci si aspetta da un linguaggio .NET, come le conversioni in maiuscolo e in minuscolo:

```fsharp
'a' |> System.Char.ToUpper  // =>  'A'

'Q' |> System.Char.ToLower  // =>  'q'
```
