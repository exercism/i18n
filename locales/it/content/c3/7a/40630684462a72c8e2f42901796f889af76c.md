# Istruzioni

Scriverai del codice per gestire un array di linguaggi di programmazione da imparare. Questi saranno contenuti in un array chiamato `@LanguageList::Languages`.

## 1. Aggiungi un linguaggio all'array @Languages

Modifica la subroutine `LanguageList::add_language`, che prende il nome di un linguaggio come argomento, per aggiungere il linguaggio in fondo all'array `@LanguageList::Languages`.

## 2. Rimuovi un linguaggio dall'array @Languages

Modifica la subroutine `LanguageList::remove_language` per rimuovere l'ultimo linguaggio dall'array `@LanguageList::Languages`.

## 3. Recupera il primo linguaggio dall'array @Languages

Modifica la subroutine `LanguageList::first_language` per restituire il primo linguaggio dell'array `@LanguageList::Languages`.

## 4. Recupera l'ultimo linguaggio dall'array @Languages

Modifica la subroutine `LanguageList::last_language` per restituire l'ultimo linguaggio dell'array `@LanguageList::Languages`.

## 5. Recupera una porzione di linguaggi dall'array @Languages

Modifica la subroutine `LanguageList::get_languages`, che prende un array di numeri per gli elementi desiderati, per restituire una porzione dell'array `@LanguageList::Languages`.

## 6. Verifica se un linguaggio è presente nell'array @Languages

Modifica la subroutine `LanguageList::has_language`, che prende il nome di un linguaggio come argomento, per restituire un valore vero o falso che indica se il linguaggio è presente nell'array `@LanguageList::Languages`.
