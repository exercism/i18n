# Test

## Eseguire i test

1. Scarica un esercizio:

    ```bash
    $ exercism download -track=kotlin --exercise=hello-world
    ```

2. Spostati nella directory dell'esercizio:

    ```bash
    $ cd <path_to_exercise_directory>
    ```

3. Esegui i test:

    ```bash
    $ ./gradlew test
    ```

Nella maggior parte degli esercizi, per impostazione predefinita viene eseguito solo il primo test.  
Gli altri test sono annotati con `@Ignore` per saltarli.  
Man mano che risolvi ogni test, rimuovi `@Ignore` dal test successivo per andare avanti.

È una pratica comune nello sviluppo guidato dai test (o TDD, in breve).
Serve a garantire che si lavori a un problema alla volta.
