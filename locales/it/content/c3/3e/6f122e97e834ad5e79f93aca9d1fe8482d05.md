# Segnaposto

## Consigli su `jq`

Questo esercizio consiste nel prendere un oggetto di input e trasformarlo in un nuovo oggetto.
Un paio di funzioni integrate che possono aiutare:

- [`to_entries`][x_entries]
  - questa funzione prende un oggetto come input
  - restituisce un _array_: ogni elemento dell'array è un oggetto `{"key": "K", "value": V}`
    - ogni `K` è una chiave dell'oggetto di input
    - ogni `V` è il valore corrispondente di `K`.
- [`from_entries`][x_entries]
  - l'operazione inversa
  - prende un array di oggetti `{"key": K, "value": V}` e costruisce un oggetto

Un esempio:

```sh
jq -n '
    {
        "username": "glennj",
        "tracks": ["bash", "awk", "jq"],
        "reputation": 123
    }
    | to_entries
'
```

produce

```json
[
  {
    "key": "username",
    "value": "glennj"
  },
  {
    "key": "tracks",
    "value": ["bash", "awk", "jq"]
  },
  {
    "key": "reputation",
    "value": 123
  }
]
```

[x_entries]: https://jqlang.org/manual/#to_entries-from_entries-with_entries
