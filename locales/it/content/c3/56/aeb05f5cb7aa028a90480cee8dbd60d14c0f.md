# Test

## In breve

- Vai nella directory del problema (ad es. `~/Exercism/hello-world`).
- Avvia una sessione `jconsole` in un terminale.
- Carica il file della soluzione (ad es. `load 'hello-world.ijs'`).
- Carica il framework di unit test digitando `load  'general/unittest'`.
- Testa la soluzione digitando `unittest 'test.ijs'`.
<br></br>
- In alternativa, puoi eseguire i test su una sola riga, così: `jconsole -js "load 'hello-world.ijs'" "echo unittest 'test.ijs'" "exit 0"`.

## La sessione con jconsole

L'impostazione dei test del track è pensata per essere il più semplice possibile.
Se stai lavorando a un esercizio, diciamo `hamming.ijs`, ecco come dovrebbe procedere il lavoro.
Modifica `hamming.ijs` scrivendo la soluzione.
Costruiscila in modo interattivo, iniziando a digitare.

```j
NB. your j terminal binary may be ijconsole (eg. on Debian)
jconsole 'hamming.ijs' NB. start a J console session with definitions loaded hamming.ijs
```

Poi, dall'interno della console J, ricarica digitando

```j
load 'hamming.ijs'
```

Il passo successivo è caricare il framework di unit test digitando

```j
load 'general/unittest'
```

Per eseguire i test, dopo aver caricato la soluzione, digita

```j
unittest 'test.ijs'
```

E poi osserva i risultati.

## Riga di comando

Puoi eseguire i test con un comando su una sola riga nel terminale, usando l'opzione -js:

```j
jconsole  -js "load 'hamming.ijs'" "echo unittest 'test.ijs'" "exit 0"
```
dove ogni argomento rappresenta un comando che verrà eseguito in sequenza.
