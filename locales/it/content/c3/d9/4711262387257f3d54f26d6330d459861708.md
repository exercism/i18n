# Array

Un **array** contiene una riga di valori, tutti dello stesso tipo, in ordine.

Il tipo si scrive `ARRAY{T}`, dove `T` è ciò che contiene. Un array di stringhe è `ARRAY{STR}`; un array di numeri interi è `ARRAY{INT}`.

```sather
   row : ARRAY{STR} := |"Mia", "Ana", "Ben"|;
```

I valori tra i due segni `|` sono il **letterale di array**. Sather ricava la dimensione dal numero di valori.

## Estrarre un valore

Le parentesi quadre indicano la posizione:

```sather
row[0]      -- "Mia"
row[1]      -- "Ana"
row[2]      -- "Ben"
```

Il conteggio parte da **zero**, non da uno. Quindi il primo valore è a `0`, e l'ultimo in una riga di tre è a `2`.

## Quanti?

`.size` è il numero di valori che l'array contiene.

```sather
row.size    -- 3
```

Siccome il conteggio parte da zero, l'ultima posizione è sempre `.size - 1`:

```sather
row[row.size - 1]     -- "Ben"
```

Chiedere una posizione che non esiste, come `row[3]` o `row[-1]`, è un errore che Sather non rileverà al posto tuo: conviene scrivere `.size - 1` invece di contare i valori a occhio.

## Percorrere un array

Un array e un ciclo vanno insieme. Fai avanzare una variabile attraverso le posizioni e usala per raggiungere ogni valore:

```sather
   total ::= 0;
   i ::= 0;
   loop
      until!(i >= scores.size);
      total := total + scores[i];
      i := i + 1;
   end;
```
