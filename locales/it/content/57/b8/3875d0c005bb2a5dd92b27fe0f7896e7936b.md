# Appendice alle istruzioni

## Suggerimenti

Haskell supporta molti tipi di array. Questo esercizio usa gli array immutabili, boxed e non-strict di `Data.Array`. Per saperne di più sull'uso di questi array, puoi consultare:

- [A Gentle Introduction to Haskell: Arrays][1]
- La documentazione di [`Data.Array`][2]

Come estensione facoltativa di questo esercizio, prova a far funzionare la funzione `find` con array dai limiti arbitrari, ad esempio array in cui il primo indice non è necessariamente 0.

[1]: https://www.haskell.org/tutorial/arrays.html
[2]: https://hackage.haskell.org/package/array/docs/Data-Array.html
