# Appendice alle istruzioni

## Registri

| Registro | Uso       | Tipo      | Descrizione                           |
| -------- | --------- | --------- | ------------------------------------- |
| `$a0`    | input     | indirizzo | array di parole dei libri             |
| `$a1`    | input     | intero    | numero di libri                       |
| `$v0`    | output    | intero    | prezzo, in centesimi                  |
| `$t0-9`  | temporaneo | qualsiasi | utilizzato per memoria temporanea     |
