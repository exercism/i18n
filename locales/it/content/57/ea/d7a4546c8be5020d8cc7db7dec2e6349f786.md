# Introduzione

`OpenStruct` ti permette di creare facilmente un oggetto da un `Hash`. 
Invece di dover accedere usando le chiavi di `Hash`, `OpenStruct` ci permette di usare metodi per accedere e impostare i valori.


```ruby
attributes = { name: "Jeremy Walker", age: 21, location: "Nomadic" }
person = OpenStruct.new(attributes)

person.name
#=> Jeremy Walker

person.location
#=> Nomadic

# Update the age
person.age = 35

# It sets correctly
person.age
#=> 35
```

Un vantaggio di questo approccio è che possiamo sfruttare una scorciatoia quando usiamo la sintassi con i blocchi. 
Quando un blocco chiama un singolo metodo, puoi sostituire il blocco con `&:` seguito dal nome del metodo. 
Per esempio, queste due righe sono sinonime:

```ruby
people.sum { |person| person.age }
people.sum(&:age)
```

## Libreria standard

Tutte le classi che hai visto negli esercizi precedenti facevano parte della libreria core di Ruby.

OpenStruct fa parte della libreria standard di Ruby (spesso abbreviata in «stdlib»): una raccolta di classi per lavorare con cose come date, JSON e networking.
Fornisce anche alcune funzionalità utili per rendere il codice più facile da usare.

Quando usi classi che non provengono dalla libreria core (codice in file diversi, classi della stdlib o dipendenze esterne), dobbiamo importarle usando il metodo `require` prima di poterle usare.
Per esempio:

```ruby
require 'ostruct'

person = OpenStruct.new(name: "Jeremy Walker")
# ...
```
