# Installare Java

Oltre alla CLI di Exercism e al tuo editor di testo preferito, per esercitarti con gli esercizi Java di Exercism ti serve il **Java Development Kit** (JDK). Il JDK include sia un Java Runtime _sia_ gli strumenti di sviluppo (in particolare, il compilatore Java).

Oggi esistono molte varianti del JDK, alcune delle quali open source. Qui su Exercism consigliamo di usare [Eclipse Temurin di Adoptium][adoptium].

## Versioni di Java supportate

Il track Java di Exercism supporta Java 25 LTS e versioni precedenti.

## Installare Eclipse Temurin

Per installare Eclipse Temurin sul tuo sistema, vai alle loro ottime [istruzioni di installazione][adoptium-installation-guide]. Qui troverai le istruzioni per installare il JDK con il tuo gestore di pacchetti preferito, insieme ai link per scaricare gli installer per tutti i principali sistemi operativi.

## IDE per Java

Esistono molti IDE gratuiti per Java. Ecco alcune scelte popolari:

- [IntelliJ IDEA Community Edition][intellij-idea]
- [Eclipse][eclipse]
- [Visual Studio Code con l'estensione Java][vscode-java]

## Prossimi passi

Ora sei pronto per iniziare con il track Java di Exercism!

Per iniziare, consulta "[Eseguire i test][exercism-java-tests-docs]".
