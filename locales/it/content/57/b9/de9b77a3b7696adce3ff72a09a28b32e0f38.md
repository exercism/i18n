# Appendice alle istruzioni

## Formato dell'output

Genera il diamante come una stringa con terminatore nullo, con un carattere di nuova riga alla fine di ogni riga.

Un esempio di output sarebbe `"  A  \n B B \nC   C\n B B \n  A  \n"`

## Registri

| Registro | Utilizzo     | Tipo    | Descrizione                            |
| -------- | ------------ | ------- | -------------------------------------- |
| `$a0`    | input        | byte    | lettera                                |
| `$a1`    | input/output | indirizzo | stringa risultato con terminatore nullo |
| `$t0-9`  | temporaneo   | qualsiasi | per l'archiviazione temporanea         |
