# Introduzione

## Data e ora

Il pacchetto `java.time`, introdotto in Java 8, contiene diverse classi per lavorare con date e orari.

### `LocalDate`

La classe `java.time.LocalDate` rappresenta una data senza fuso orario nel [sistema di calendario ISO-8601][iso-8601], come `2007-12-03`:

```java
LocalDate date = LocalDate.of(2007, 12, 3);
```

Le date si possono confrontare con altre date:

```java
LocalDate date1 = LocalDate.of(2007, 12, 3);
LocalDate date2 = LocalDate.of(2007, 12, 4);

date1.isBefore(date2);
// => true

date1.isAfter(date2);
// => false
```

Un'istanza di `LocalDate` ha dei getter per recuperarne le componenti temporali:

```java
LocalDate date = LocalDate.of(2007, 12, 3);

date.getDayOfMonth();
// => 3
```

Un'istanza di `LocalDate` ha dei metodi per aggiungervi unità di tempo:

```exercism/note
Questi metodi restituiscono una _nuova_ istanza di `LocalDate` e non aggiornano quella esistente, dato che la classe `LocalDate` è immutabile.
```

```java
LocalDate date = LocalDate.of(2007, 12, 3);

date.plusDays(3);
// => 2007-12-06
```

### `LocalDateTime`

La classe `java.time.LocalDateTime` rappresenta una data e un'ora senza fuso orario nel [sistema di calendario ISO-8601][iso-8601], come `2007-12-03T10:15:30`:

```java
LocalDateTime datetime = LocalDateTime.of(2007, 12, 3, 10, 15, 30);
```

Puoi convertire un'istanza di `LocalDate` in un `LocalDateTime`:

```java
LocalDate date = LocalDate.of(2007, 12, 3);
LocalDateTime datetime = date.atTime(10, 15, 30);
datetime.toString();
// => "2007-12-03T10:15:30"
```

### Formattare le date e gli orari

Sia `LocalDate` che `LocalDateTime` usano la notazione standard [ISO-8601][iso-8601] quando convertono da e verso una `String`.

```java
LocalDateTime datetime = LocalDateTime.of(2007, 12, 3, 10, 15, 30);
LocalDateTime parsed = LocalDateTime.parse("2007-12-03T10:15:30");

datetime.isEqual(parsed);
// => true
```

Non è possibile parsare un `LocalDate` o un `LocalDateTime` da una `String` come questa usando un formato diverso.
Per formattare le date con un formato personalizzato, invece, devi usare `java.time.format.DateTimeFormatter`:

```java
DateTimeFormatter parser = DateTimeFormatter.ofPattern("dd/MM/yyyy");
LocalDate date = LocalDate.parse("03/12/2007", parser);

DateTimeFormatter printer = DateTimeFormatter.ofPattern("MMMM d, yyyy");
printer.format(date);
// => "December 3, 2007"
```

Puoi anche specificare una locale quando crei il formato personalizzato, per formattare e parsare date di regioni diverse:

```java
DateTimeFormatter.ofPattern("MMMM d, yyyy", Locale.FRENCH).format(date);
// => décembre 3, 2007

DateTimeFormatter.ofPattern("MMMM d, yyyy", Locale.of("pt")).format(date);
// => dezembro 3, 2007
```

[iso-8601]: https://en.wikipedia.org/wiki/ISO_8601
