# Istruzioni

Boris è un grande appassionato di modellismo ferroviario e ha deciso di condividere la sua passione con il mondo avviando una newsletter. Comincerà inviando il primo numero della newsletter ad amici e conoscenti che condividono questo hobby. I loro indirizzi email sono salvati in un file di testo.

Suggerimento: usa il modulo [simplifile](https://hexdocs.pm/simplifile/simplifile.html) per le operazioni sui file.

## 1. Leggi gli indirizzi email da un file

Implementa la funzione `read_emails`. Prende una stringa con il percorso di un file di testo che contiene indirizzi email separati da caratteri di nuova riga e restituisce un array con gli indirizzi email presenti nel file.

```gleam
read_emails("/home/my_user/documents/model_train_friends_emails.txt")
// -> Ok(["rick@example.com", "choochoo42@example.com", "anna@example.com"])
```

## 2. Crea un file di log per la scrittura

Inviare un'email è un'operazione che può fallire per molte ragioni imprevedibili, come un errore di battitura nell'indirizzo email o problemi temporanei di rete. Per poter ritentare l'invio delle email a tutti gli amici senza mandarne di duplicate, devi registrare gli indirizzi email che hanno già ricevuto il messaggio. Per farlo, ti serve un file di log.

Implementa la funzione `create_log_file`. Prende il percorso di un file e crea un nuovo file vuoto in quella posizione.

```gleam
create_log_file("/home/my_user/documents/newsletter_issue1_log.txt")
// -> Ok(Nil)
```

## 3. Registra un'email inviata

Implementa la funzione `log_sent_email`. Prende il percorso di un file di log e una stringa con l'indirizzo email. Scrive l'indirizzo email nel file, seguito da un carattere di nuova riga.

```gleam
log_sent_email(
  "/home/my_user/documents/newsletter_issue1_log.txt",
  "joe@example.com",
)
// -> Ok(Nil)
```

## 4. Invia la newsletter

Ora che hai tutti i mattoni della procedura di invio delle email, devi combinarli insieme in un'unica funzione.

Implementa la funzione `send_newsletter`. Prende il percorso del file con gli indirizzi email, il percorso di un file di log e una funzione anonima che invia un'email a un dato indirizzo email.

Dovrebbe leggere tutti gli indirizzi email dal file indicato e provare a inviare un'email a ciascuno di essi. Se la funzione anonima che invia l'email restituisce un valore `Ok`, scrivi l'indirizzo email nel file di log. Assicurati di farlo appena l'email è stata inviata.

```gleam
send_newsletter(
  "model_train_friends_emails.txt",
  "newsletter_issue1_log.txt",
  send_email,
)
// -> Ok(Nil)
```
