# Introduzione

Il tipo `Result` è la soluzione che il linguaggio Elm offre per segnalare gli errori e permetterne il recupero. È in parte simile al tipo `Maybe`, ma mentre `Maybe` può essere restituito da funzioni che potrebbero fallire, non dice nulla sul perché il fallimento sia avvenuto. `Result` include proprio questo contesto, cioè il motivo per cui qualcosa è fallito.

Il tipo `Result` è definito così:

```elm
type Result error value
  = Ok value
  | Err error
```

Nella terminologia di Elm, questa è quella che si chiama una definizione di «custom type». L'`error` e il `value` in `OK value` e `Error error` rappresentano una variabile di tipo, il che significa che può essere un tipo qualsiasi, come `Int`, `Bool` o `String`. Di conseguenza, un `Result String Int` è una variabile che ci si aspetta contenga un `Int` e, in caso di errore, questo sarà rappresentato da una `String`. Esiste un [modulo Result](https://package.elm-lang.org/packages/elm/core/latest/Result) con tante funzioni ausiliarie utili per lavorare con `Result`.
