# Informazioni

Quando si modellano dati che possono assumere solo un insieme ben preciso di stati possibili, come i giorni della settimana, i punti cardinali o i pulsanti di un controller, i tipi di base come `Int` o `String` presentano grossi svantaggi.
Con gli interi o le stringhe, il codice deve controllare di continuo la presenza di valori non validi (come un codice di stato `999` o un refuso come `"leftt"`), e per chi legge non è facile capire che cosa rappresentano i numeri.

Swift risolve questo problema con le [_Enumerazioni_][enumerations] (spesso abbreviate in *enum*).
Un enum definisce un tipo comune per un gruppo di valori correlati tra loro e identificati da un nome. Poiché il compilatore conosce in anticipo tutti i casi possibili, può verificare che il codice sia accurato e completo già in fase di compilazione.
Gli enum possono anche avere metodi, inizializzatori e proprietà calcolate.

## Definire gli enum

Per definire un enum si usa la parola chiave `enum` seguita dal nome del tipo, con i casi elencati tra parentesi graffe (`{}`).
Per convenzione Swift, il nome del tipo usa `UpperCamelCase`, mentre ogni caso usa `lowerCamelCase`:

```swift
enum NESButton {
    case up
    case down
    case left
    case right
    case a
    case b
    case select
    case start
}
```

Puoi anche definire più casi su una sola riga, separati da virgole:

```swift
enum NESButton {
    case up, down, left, right, a, b, select, start
}
```

Per fare riferimento a un caso di un enum, scrivi il nome del tipo dell'enum, un punto (`.`) e il nome del caso. Quando il tipo è noto o il compilatore riesce a dedurlo, puoi omettere il nome del tipo e usare la sintassi abbreviata con il punto:

```swift
var lastPressed = NESButton.up

// Swift infers the type, so you can omit the type name:
lastPressed = .down

let konamiCode: [NESButton] = [.up, .up, .down, .down, .left, .right, .left, .right, .b, .a]
```

## Enum e istruzioni switch

Gli enum si integrano perfettamente con le [istruzioni `switch`][enums-and-switches].
Poiché un `switch` in Swift deve essere esaustivo, il compilatore fa in modo che ogni caso possibile venga gestito:

```swift
lastPressed = .left
switch lastPressed {
case .up: print("You pressed the UP button")
case .down: print("You pressed the DOWN button")
case .left: print("You pressed the LEFT button")
case .right: print("You pressed the RIGHT button")
case .a: print("You pressed the A button")
case .b: print("You pressed the B button")
case .select: print("You pressed the SELECT button")
case .start: print("You pressed the START button")
}
// Prints "You pressed the LEFT button"
```

Se dimentichi un caso e non fornisci una clausola `default`, il compilatore segnala un errore:

```swift
switch lastPressed {
case .up, .down, .left, .right:
    print("You pressed a direction button.")
}
// Error: Switch must be exhaustive
```

Elencare tutti i casi in modo esplicito è spesso preferibile all'uso di `default`. In questo modo, se in futuro aggiungi un nuovo caso, il compilatore ti avviserà subito di aggiornare tutte le istruzioni `switch` che gestiscono quell'enum.

## Metodi e inizializzatori

Gli enum possono definire metodi e inizializzatori personalizzati proprio come le classi e le strutture. All'interno di un metodo di un enum, `self` fa riferimento al valore del caso corrente:

```swift
enum Coin {
    case heads
    case tails

    init(_ value: Int) {
        if value.isMultiple(of: 2) {
            self = .heads
        } else {
            self = .tails
        }
    }

    func flip() -> Coin {
        switch self {
        case .heads: return .tails
        case .tails: return .heads
        }
    }
}

let tails = Coin(13)     // .tails
let heads = Coin(0)      // .heads
let flipped = heads.flip() // .tails
```

## Valori grezzi

I casi di un enum possono essere precompilati con valori predefiniti chiamati [_valori grezzi_][raw-values].
Tutti i valori grezzi di un enum devono avere lo stesso tipo (come `Int`, `String` o `Character`):

```swift
enum NESButton: Character {
    case up = "⬆️"
    case down = "⬇️"
    case left = "⬅️"
    case right = "➡️"
    case a = "🅰️"
    case b = "🅱️"
    case select = "✅"
    case start = "🚦"
}

print(NESButton.left.rawValue) // Prints "⬅️"
```

Puoi inizializzare un enum a partire da un valore grezzo usando `init(rawValue:)`. Poiché potrebbe essere fornito un valore grezzo non valido, questo inizializzatore restituisce un optional:

```swift
let upButton = NESButton(rawValue: "⬆️") // Optional(NESButton.up)
let invalid = NESButton(rawValue: "🙄")  // nil
```

Swift può assegnare automaticamente i valori grezzi per gli enum `String` e `Int`:

- Per gli enum `String`, il valore grezzo di ogni caso corrisponde per impostazione predefinita al nome del caso.
- Per gli enum `Int`, i valori grezzi partono da `0` e aumentano di 1, salvo diversa indicazione.

```swift
enum Planet: Int {
    case mercury = 1, venus, earth, mars
}

print(Planet.earth.rawValue) // Prints 3
```

## Valori associati

I casi di un enum possono anche memorizzare, accanto a ciascun caso, valori personalizzati di tipi diversi, noti come [_valori associati_][associated-values]:

```swift
enum Suit: Character {
    case diamonds = "♦️", clubs = "♣️", hearts = "♥️", spades = "♠️"
}

enum Card {
    case ace(Suit)
    case king(Suit)
    case queen(Suit)
    case jack(Suit)
    case number(Suit, Int)

    func description() -> String {
        switch self {
        case .ace(let suit): return "A\(suit.rawValue)"
        case .king(let suit): return "K\(suit.rawValue)"
        case .queen(let suit): return "Q\(suit.rawValue)"
        case .jack(let suit): return "J\(suit.rawValue)"
        case let .number(suit, value): return "\(value)\(suit.rawValue)"
        }
    }
}

let aceOfSpades = Card.ace(.spades)
let twoOfHearts = Card.number(.hearts, 2)

print(aceOfSpades.description()) // Prints "A♠️"
print(twoOfHearts.description()) // Prints "2♥️"
```

Un enum può usare valori grezzi o valori associati, ma non entrambi.

## Enumerazioni ricorsive

Un'[enumerazione ricorsiva][recursive-enumerations] è un enum che ha un'altra istanza dell'enum stesso come valore associato di uno o più casi.
Per abilitare la ricorsione, contrassegna il caso (o l'intero enum) con la parola chiave `indirect`:

```swift
enum BinaryTree {
    case leaf(value: Int)
    indirect case node(left: BinaryTree, value: Int, right: BinaryTree)
}

let tree: BinaryTree = .node(
    left: .leaf(value: 1),
    value: 3,
    right: .node(left: .leaf(value: 5), value: 6, right: .leaf(value: 9))
)
```
