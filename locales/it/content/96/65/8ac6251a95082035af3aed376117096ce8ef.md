# Istruzioni

In questo esercizio scriverai del codice per aiutarti a prepararti all'acquisto di un veicolo.

Hai tre compiti: determinare se ti serve la patente, scegliere tra due veicoli e stimare il prezzo accettabile di un veicolo usato.

## 1. Determina se ti servirà la patente di guida

Alcuni tipi di veicolo richiedono la patente di guida per essere guidati.
Supponi che solo i tipi `"car"` e `"truck"` richiedano la patente: tutto il resto si può guidare senza.

Implementa la funzione `NeedsLicense(kind)`, che prende il tipo di veicolo e restituisce un booleano che indica se per quel tipo di veicolo serve la patente.

```go
needLicense := NeedsLicense("car")
// => true

needLicense = NeedsLicense("bike")
// => false

needLicense = NeedsLicense("truck")
// => true
```

## 2. Scegli tra due veicoli che potresti acquistare

Valuti le opzioni di veicoli disponibili.
Riesci a restringerle a due, ma ti serve una mano per prendere la decisione finale.
Per questo, implementa la funzione `ChooseVehicle(option1, option2)`, che prende due veicoli come argomenti e restituisce una decisione che include l'opzione che viene prima in ordine lessicografico.

```go
vehicle := ChooseVehicle("Wuling Hongguang", "Toyota Corolla")
// => "Toyota Corolla is clearly the better choice."

ChooseVehicle("Volkswagen Beetle", "Volkswagen Golf")
// => "Volkswagen Beetle is clearly the better choice."
```

## 3. Calcola una stima del prezzo di un veicolo usato

Ora che hai preso una decisione, vuoi assicurarti di ottenere un prezzo equo dal concessionario.
Dato che ti interessa acquistare un veicolo usato, il prezzo dipende da quanto è vecchio il veicolo.
Per una stima approssimativa, supponi che se il veicolo ha meno di 3 anni, costi l'80% del prezzo originale che aveva quando era nuovo di zecca.
Se ha almeno 10 anni, costa il 50%.
Se il veicolo ha almeno 3 anni ma meno di 10, costa il 70% del prezzo originale.

Implementa la funzione `CalculateResellPrice(originalPrice, age)`, che applica questa logica usando `if`, `else if` e `else` (ci sono altri modi, se vuoi esercitarti).
Prende il prezzo originale e l'età del veicolo come argomenti e restituisce il prezzo stimato dal concessionario.

```go
CalculateResellPrice(1000, 1)
// => 800

CalculateResellPrice(1000, 5)
// => 700

CalculateResellPrice(1000, 15)
// => 500
```

**Nota**: il valore restituito è un `float64`.
