# Istruzioni

Il nostromo tiene ogni giorno un briefing di guardia sul ponte: un saluto fisso, l'appello dell'equipaggio in servizio, poi un congedo finale. Scomporrai il briefing in piccole righe con un nome e le comporrai.

Per questo esercizio modificherai **due file**:

- `bosuns-briefing/helpers/helpers.factor`: piccoli pezzi riutilizzabili. Vocabolario: `bosuns-briefing.helpers`.
- `bosuns-briefing/bosuns-briefing.factor`: il file principale che compone le funzioni ausiliarie. Vocabolario: `bosuns-briefing`.

## 1. Saluto

In `helpers.factor`, definisci `greeting` in modo che restituisca la stringa di apertura fissa `"All hands, attention!"`.

```factor
greeting .
! => "All hands, attention!"
```

## 2. Riga dell'equipaggio

In `helpers.factor`, definisci `crew-line` in modo che prenda una stringa con un nome e restituisca quel nome preceduto da `"  - "` (due spazi, un trattino, uno spazio).

```factor
"Lopez" crew-line .
! => "  - Lopez"
```

## 3. Congedo

In `helpers.factor`, definisci `closing` in modo che restituisca la stringa di congedo fissa `"Carry on."`.

```factor
closing .
! => "Carry on."
```

## 4. Elenco

In `bosuns-briefing.factor`, definisci `roster` in modo che prenda un array di nomi dell'equipaggio e restituisca un'unica stringa su più righe con ogni nome formattato da `crew-line`, uniti da ritorni a capo.

```factor
{ "Lopez" "Mwangi" } roster .
! => "  - Lopez\n  - Mwangi"

{ } roster .
! => ""
```

## 5. Briefing

In `bosuns-briefing.factor`, definisci `briefing` in modo che prenda un array di nomi dell'equipaggio e restituisca il briefing completo come un'unica stringa: il saluto sulla prima riga, l'elenco sulle righe successive e il congedo sull'ultima riga. Usa le funzioni ausiliarie e `roster`.

```factor
{ "Lopez" "Mwangi" } briefing .
! => "All hands, attention!\n  - Lopez\n  - Mwangi\nCarry on."

{ } briefing .
! => "All hands, attention!\n\nCarry on."
```
