# Informazioni

In C#, il [letterale `null`][null-keyword] viene usato per indicare l'assenza di un valore. Un tipo _nullable_ è un tipo che ammette valori `null`.

Prima di C# 8.0, i tipi di riferimento erano sempre nullable e i tipi di valore no. Un [tipo di valore può comunque essere reso nullable][nullable-value-types] aggiungendo un punto interrogativo (`?`).

```csharp
string nullableReferenceType = "hello";
nullableReferenceType = null; // Valid as type is nullable

int nonNullableValueType = 5;
nonNullableValueType = null; // Compile error as type is not nullable

int? nullableValueType = 5; // Define nullable value type
nullableValueType = null;   // Valid as type is nullable
```

Accedere a un membro di una variabile il cui valore è `null` viene compilato senza errori, ma a runtime comporta la generazione di una `NullReferenceException`:

```csharp
string sentence = "What a nice day!";

// Throws NullReferenceException at runtime
sentence.Length;
```

Per ovviare a questo tipo comune di errore, C# 8 consente di [attivare una funzionalità][nullable-csharp-8] che rende i [tipi di riferimento non nullable per impostazione predefinita][nullable-reference-types]:

```csharp
string nonNullableReferenceType = "book";
nonNullableReferenceType = null; // Compile warning (no error!)

string? nullableReferenceType = "movie";
nullableReferenceType = null; // Valid as type is nullable
```

Per [lavorare in modo sicuro con i valori nullable][nullable-types-tutorial], conviene verificare se sono `null` prima di usarli:

```csharp
string NormalizedName(string? name)
{
    if (name == null)
    {
        return "UNKNOWN";
    }
    else
    {
        // Value is not null at this point, so no compile warning
        // and no runtime NullReferenceException being thrown
        return name.ToUpper();
    }
}

NormalizedName(null); // => "UNKNOWN"
NormalizedName("Elisabeth"); // => "ELISABETH"
```

L'[operatore `??`][null-coalescing-operator] consente di restituire un valore predefinito quando il valore è `null`:

```csharp
string? name1 = "John";
name1 ?? "Paul"; // => "John"

string? name2 = null;
name2 ?? "George"; // => "George"
```

L'[operatore `?.`][null-conditional-operator] consente di chiamare i membri in modo sicuro su un valore che potrebbe essere `null`:

```csharp
string? fruit = "apple";
fruit?.Length; // => 5

string? vegetable = null;
vegetable?.Length; // => null
```

Se il compilatore ritiene che un valore potrebbe essere `null` ma tu sei certo che non lo sarà, l'[operatore `!.`][null-forgiving-operator] può essere usato per sopprimere l'avviso. Usa però questo operatore solo come ultima risorsa.

```csharp
void PrintName(string? name)
{
    // Assume that the IsValid() method only return true
    // when its argument is not null
    if (IsValid(name))
    {
        // No compile warning
        Console.WriteLine(name!.Length);
    }
}
```
