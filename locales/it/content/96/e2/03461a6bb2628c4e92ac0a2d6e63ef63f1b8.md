# Appendice alle istruzioni

## Informazioni sull'ability `Stream`

`Stream` è un'ability di Unison che si usa per emettere valori.

Potresti usare l'ability `Stream` se hai una funzione che deve produrre valori come effetto secondario mentre viene chiamata. Per esempio, questa funzione restituisce l'ultimo valore dell'array, ma emette un totale progressivo man mano che ogni elemento viene esaminato:

```
emitRunningTotal : '{Stream Nat} Nat
emitRunningTotal = 'let
  use Nat +
  List.foldLeft (
    acc a -> let
      runningTotal = acc + a
      Stream.emit runningTotal
      a
    ) 0 [1,2,3,4,5]
```

Possiamo materializzare lo Stream come una List, accanto al valore restituito dalla funzione che lo produce, con un gestore di ability:

```
> Stream.toListWithResult! emitRunningTotal
  ⧩
  ([1, 3, 5, 7, 9], 5)
```
