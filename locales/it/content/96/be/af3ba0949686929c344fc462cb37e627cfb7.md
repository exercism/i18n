# Aggiungi un nuovo track

Il primissimo passo per aggiungere un nuovo track per un linguaggio a Exercism è:

- [Richiedi un nuovo track per un linguaggio](/docs/building/tracks/new/request-new)

Una volta completato questo passo, i passi successivi sono:

- [Entra nella nostra community](/docs/building/tracks/new/join-our-community)
- [Seleziona la variante del linguaggio di programmazione](/docs/building/tracks/new/select-programming-language-variant) (se applicabile)
- [Seleziona il framework di test](/docs/building/tracks/new/select-testing-framework)
- [Aggiungi il primo esercizio](/docs/building/tracks/new/add-first-exercise)
- [Configura l'integrazione continua](/docs/building/tracks/new/setup-continuous-integration)
- [Aggiungi gli esercizi iniziali](/docs/building/tracks/new/add-initial-exercises)
- [Crea il test runner](/docs/building/tracks/new/build-test-runner)
- [Configura gli strumenti](/docs/building/tracks/new/configure-tooling)
- [Preparati al lancio](/docs/building/tracks/new/prepare-for-launch)
- [Collauda il track](/docs/building/tracks/new/test-track)
- [Trova i maintainer](/docs/building/tracks/new/find-maintainers)
- [Lancia!](/docs/building/tracks/new/launch)
- [Abilita l'evidenziazione della sintassi](/docs/building/tracks/new/syntax-highlighting)
- [Implementa strumenti aggiuntivi](/docs/building/tracks/new/implement-tooling)
- [Preparati ai contributi open source da parte di sconosciuti](/docs/building/tracks/new/prepare-for-contributions)
