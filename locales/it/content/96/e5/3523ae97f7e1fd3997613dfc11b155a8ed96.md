# istruzione if non necessaria

Invece di creare un blocco `if (...) {}`, sfrutta direttamente il valore booleano che si può restituire dal controllo del valore del parametro.

Per esempio, il seguente codice:

```javascript
if (param === true) {
  return true;
}
```

può diventare:

```javascript
return param === true;
```
