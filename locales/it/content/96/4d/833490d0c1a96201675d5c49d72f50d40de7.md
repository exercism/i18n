# Suggerimenti

## Generali

- Gli array in Swift usano indici che partono da zero. Il primo indice di un array è `0`.

## 1. Recupera una carta dalla pila

- Per ottenere l'`n`-esimo elemento di una slice, [usa un subscript][array-access].
- Un array inizia sempre con l'indice `0`

## 2. Scambia una carta nella pila

- Per impostare l'`n`-esimo elemento di un array, [usa un subscript][array-access] e assegnagli un nuovo valore.
- Un array inizia sempre con l'indice `0`

## 3. Inserisci una carta in cima alla pila

- C'è un [metodo dell'array][array-append-docs] per aggiungere un nuovo valore alla fine dell'array.

## 4. Rimuovi una carta dalla pila

- C'è un [metodo dell'array][array-removeat-docs] che si può usare per rimuovere elementi a un indice specificato.

## 5. Rimuovi la carta in cima alla pila

- C'è un [metodo dell'array][array-removelast-docs] per rimuovere l'ultimo elemento dall'array.

## 6. Inserisci una carta in fondo alla pila

- C'è un [metodo dell'array][array-insert-docs] per aggiungere un nuovo valore a un indice specificato dell'array.
- Un array inizia sempre con l'indice `0`

## 7. Rimuovi una carta dal fondo della pila

- C'è un [metodo dell'array][array-removefirst-docs] per rimuovere il primo elemento dall'array.

## 8. Verifica la dimensione della pila

- Gli array hanno una [proprietà][array-count-docs] per ottenere la loro lunghezza.

## 9. Conta il numero di carte pari nella pila

- Puoi scorrere gli elementi di un array usando un [ciclo for-in][for-in-loops].
- I tipi interi in Swift hanno il metodo [`isMultiple(of:)`][int-ismultiple-docs] per verificare se sono multipli di un altro intero.
