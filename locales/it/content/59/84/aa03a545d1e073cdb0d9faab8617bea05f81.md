# Suggerimenti

## Generale

- Ricordati di fare riferimento alla tabella nelle istruzioni.

## 1. Data un'estensione, restituisci il tipo di media previsto

- Usa il [pattern matching][pattern-matching] per restituire il tipo di media corretto.
- Puoi usare [più clausole di funzione][mfc].

## 2. Dato un file binario, restituisci il tipo di media previsto

- Usa la [forma speciale binaria][special-forms] che hai a disposizione per scrivere un letterale binario.
- Usa il [pattern matching][binary-matching] per confrontare i primi byte del file binario.

## 3. Data un'estensione e un file binario, verifica che il file corrisponda al tipo previsto

- Riutilizza le funzioni che hai creato per le parti 1 e 2.
- Confronta il valore restituito da ciascuna funzione, poi restituisci il valore appropriato.
  - Puoi usare la [macro condizionale `if`][if] per le condizioni binarie.
