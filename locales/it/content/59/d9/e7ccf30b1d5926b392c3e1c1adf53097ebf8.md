# Istruzioni

In questo esercizio giocherai a un gioco di ruolo chiamato "Wizard and Warriors", che ti permette di interpretare un Wizard o un Warrior.

Ci sono regole diverse per i Warrior e i Wizard per determinare quanti punti di danno infliggono.

Per un Warrior, le regole sono queste:

- Infligge 6 punti di danno se il personaggio che sta attaccando non è vulnerabile
- Infligge 10 punti di danno se il personaggio che sta attaccando è vulnerabile

Per un Wizard, le regole sono queste:

- Infligge 12 punti di danno se il Wizard ha preparato un incantesimo in anticipo
- Infligge 3 punti di danno se il Wizard non ha preparato un incantesimo in anticipo

In generale, i personaggi non sono mai vulnerabili. Tuttavia, i Wizard _sono_ vulnerabili se non hanno preparato un incantesimo.

Hai sei compiti che lavorano con i personaggi Warrior e Wizard.

## 1. Descrivi un personaggio

Sovrascrivi il metodo `ToString()` della classe `Character` per restituire una descrizione del personaggio, formattata come `"Character is a <CHARACTER_TYPE>"`.

```csharp
var warrior = new Warrior();
warrior.ToString();
// => "Character is a Warrior"
```

## 2. Rendi i personaggi non vulnerabili per impostazione predefinita

Assicurati che il metodo `Character.Vulnerable()` restituisca sempre `false`.

```csharp
var warrior = new Warrior();
warrior.Vulnerable();
// => false
```

## 3. Permetti ai Wizard di preparare un incantesimo

Implementa il metodo `Wizard.PrepareSpell()` per permettere a un Wizard di preparare un incantesimo in anticipo.

```csharp
var wizard = new Wizard();
wizard.PrepareSpell();
```

## 4. Rendi i Wizard vulnerabili quando non hanno preparato un incantesimo

Assicurati che il metodo `Vulnerable()` restituisca `true` se il wizard non ha preparato un incantesimo; altrimenti, restituisci `false`.

```csharp
var wizard = new Wizard();
wizard.Vulnerable();
// => true
```

## 5. Calcola i punti di danno per un Wizard

Implementa il metodo `Wizard.DamagePoints()` per restituire i punti di danno inflitti: 12 punti di danno quando è stato preparato un incantesimo, 3 punti di danno quando non lo è.

```csharp
var wizard = new Wizard();
var warrior = new Warrior();

wizard.PrepareSpell();
wizard.DamagePoints(warrior);
// => 12
```

## 6. Calcola i punti di danno per un Warrior

Implementa il metodo `Warrior.DamagePoints()` per restituire i punti di danno inflitti: 10 punti di danno quando l'obiettivo è vulnerabile, 6 punti di danno quando non lo è.

```csharp
var warrior = new Warrior();
var wizard = new Wizard();

warrior.DamagePoints(wizard);
// => 10
```
