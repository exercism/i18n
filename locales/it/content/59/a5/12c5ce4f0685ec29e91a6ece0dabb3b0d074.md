# Introduzione

Un'[istruzione switch][switch] confronta un valore con più pattern corrispondenti possibili.
Offre un'alternativa più pulita e leggibile rispetto al concatenare più istruzioni `if-else`.

Un'istruzione `switch` inizia con la parola chiave `switch`, seguita dal valore da testare.
Ogni corrispondenza possibile viene introdotta con la parola chiave `case`.
La parola chiave `default` definisce un caso di riserva che viene eseguito se nessuno dei casi espliciti corrisponde.
Come le catene di `if-else`, un'istruzione `switch` esegue solo il blocco di codice associato al primo caso corrispondente.

```swift
switch value {
case 1:
    print("One")
case 2:
    print("Two")
default:
    print("Other")
}
```

Considera la seguente catena di `if-else`:

```swift
if str == "apple" {
    print("Let's bake an apple crumble")
} else if str == "lemon" {
    print("Let's bake a lemon meringue pie!")
} else if str == "peach" {
    print("Let's bake a peach pie!")
} else {
    print("Let's buy ice cream.")
}
```

Si può scrivere in modo più chiaro con un'istruzione `switch`:

```swift
switch str {
case "apple":
    print("Let's bake an apple crumble")
case "lemon":
    print("Let's bake a lemon meringue pie!")
case "peach":
    print("Let's bake a peach pie!")
default:
    print("Let's buy ice cream.")
}
```
