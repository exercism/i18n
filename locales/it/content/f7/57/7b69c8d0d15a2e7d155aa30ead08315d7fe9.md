# Istruzioni

Gestisci una boutique di moda online. Ogni articolo del tuo
inventario è un array di 2 elementi `{ name price }`, e l'intero
inventario è un array di articoli.

Un prezzo mancante è registrato come `f`.

## 1. Ordina l'inventario per prezzo

Definisci `sort-by-price` in modo che restituisca un nuovo array con
gli articoli ordinati per prezzo, in ordine crescente.

```factor
{ { "Maxi Brown Dress" 65 } { "Red Skirt" 50 } { "Bamboo Socks Cats" 20 } }
sort-by-price .
! => { { "Bamboo Socks Cats" 20 } { "Red Skirt" 50 } { "Maxi Brown Dress" 65 } }
```

## 2. Trova gli articoli senza prezzo

Definisci `with-missing-price` in modo che restituisca un array con i
soli articoli il cui prezzo è `f`.

```factor
{ { "Black T-shirt" 40 } { "Denim Pants" f } { "Orange T-shirt" 40 } }
with-missing-price .
! => { { "Denim Pants" f } }
```

## 3. Conta gli articoli costosi

Definisci `expensive-items` in modo che prenda un inventario e una
soglia di prezzo, e restituisca quanti articoli costano strettamente
più della soglia.

```factor
{ { "Skirt" 50 } { "Coat" 120 } { "Hat" 25 } { "Dress" 80 } }
50 expensive-items .
! => 2

{ { "Skirt" 50 } { "Coat" 120 } { "Hat" 25 } { "Dress" 80 } }
0 expensive-items .
! => 4
```

## 4. Trova l'articolo meno caro

Definisci `cheapest-item` in modo che restituisca l'articolo con il
prezzo più basso. Gli articoli senza prezzo (`f`) non compariranno
nell'input.

```factor
{ { "Skirt" 50 } { "Coat" 120 } { "Hat" 25 } } cheapest-item .
! => { "Hat" 25 }
```

## 5. Somma tutti i prezzi

Definisci `total-price` in modo che restituisca la somma di tutti i
prezzi. Gli articoli senza prezzo (`f`) non compariranno nell'input.

```factor
{ { "Skirt" 50 } { "Coat" 120 } { "Hat" 25 } } total-price .
! => 195
```

## 6. Formatta un articolo come cartellino del prezzo

Definisci `format-price-tag` in modo che restituisca una stringa nella
forma `"name: $price"` per un articolo. Gli articoli senza prezzo (`f`)
non compariranno qui.

```factor
{ "Skirt" 50 } format-price-tag .
! => "Skirt: $50"
```
