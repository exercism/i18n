# Introduzione

A volte un pezzo di stato deve essere condiviso tra diverse word senza passarlo ogni volta attraverso i loro stack effect.

Le *variabili dinamiche* di Factor, dichiarate con `SYMBOL:`, danno a ogni word accesso a un valore memorizzato in un namespace.

```factor
USING: namespaces ;

SYMBOL: counter

0 counter set-global
counter [ 1 + ] change-global
counter get-global .       ! => 1
```

`set-global` e `get-global` operano sul namespace globale.
`set` e `get` operano sullo scope dinamico *corrente* e si usano di norma all'interno di un blocco `with-variable`, quando vuoi un binding limitato allo scope invece di uno valido per tutto il processo.

`SYMBOLS: a b c ;` dichiara diversi symbol in una sola volta.
