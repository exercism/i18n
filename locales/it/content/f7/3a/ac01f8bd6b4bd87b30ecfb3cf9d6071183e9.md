# Introduzione

Il [tipo `enum`](https://docs.microsoft.com/en-us/dotnet/csharp/language-reference/builtin-types/enum) di C# rappresenta un insieme fisso di costanti denominate (un'enumerazione).

Normalmente, un membro di un `enum` può riferirsi esattamente a una sola di queste costanti denominate. A volte però è utile potersi riferire a più di una costante. Per farlo, si può annotare l'`enum` con l'[attributo `Flags`](https://docs.microsoft.com/en-us/dotnet/api/system.flagsattribute)

Un enum di flag può essere definito come segue (usando la notazione binaria per i numeri interi `0b`):

```csharp
[Flags]
enum PhoneFeatures
{
    Call = 0b00000001,
    Text = 0b00000010
}
```

Un'istanza di `PhoneFeatures` il cui valore è `0b00000011` ha impostati sia il flag `Call` _sia_ il flag `Text`.

Per impostazione predefinita, per i valori dei membri dell'enum si usa il tipo `int`. Si può usare un tipo intero diverso specificando il tipo nella dichiarazione dell'enum:

```csharp
[Flags]
enum PhoneFeatures : byte
{
    Call = 0b00000001,
    Text = 0b00000010
}
```
