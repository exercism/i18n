# Suggerimenti

## Generale

- Una [mappa][maps] è una struttura dati associativa di coppie chiave-valore.
- Elixir offre [molte funzioni utili del modulo Map nella libreria standard][map-module].

## 1. Definisci una nuova mappa dei punteggi migliori

- Dovrebbe restituire una [mappa][maps] vuota.
- Le funzioni del [modulo Map][map-module] o le forme letterali possono essere utili.

## 2. Aggiungi giocatori alla mappa dei punteggi migliori

- La mappa risultante dovrebbe essere restituita.
- Il [modulo Map][map-module] contiene funzioni utili per manipolare le mappe. [Una di queste][map-put] inserisce un valore in una mappa sotto una chiave data.

## 3. Rimuovi giocatori dalla mappa dei punteggi

- La mappa risultante dovrebbe essere restituita.
- Il [modulo Map][map-module] contiene funzioni utili per manipolare le mappe. [Una di queste][map-delete] elimina una chiave da una mappa.

## 4. Azzera il punteggio di un giocatore

- La mappa risultante dovrebbe essere restituita con il punteggio del giocatore riportato a un valore iniziale.
- Il [modulo Map][map-module] contiene funzioni utili per manipolare le mappe. [Una di queste][map-put] inserisce un valore in una mappa sotto una chiave data.

## 5. Aggiorna il punteggio di un giocatore

- La mappa risultante dovrebbe essere restituita con il punteggio aggiornato del giocatore.
- Il [modulo Map][map-module] contiene funzioni utili per manipolare le mappe. [Una di queste][map-update] aggiorna un valore in una mappa sotto una chiave data.

## 6. Ottieni un array di giocatori

- Il [modulo Map][map-module] contiene funzioni utili per manipolare le mappe. [Una di queste][map-keys] restituisce un array con tutte le chiavi di una mappa.
