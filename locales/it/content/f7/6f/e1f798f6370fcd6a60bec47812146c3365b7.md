# Test

Per eseguire i test, segui questi passaggi:

- Vai nella directory del problema (ad esempio `~/Exercism/hello-world`).
- Avvia una sessione `jconsole` (ad esempio digitando `jconsole` o `ijconsole`) in un terminale.
- Carica il file della soluzione (ad esempio `load 'hello-world.ijs'`)
- Carica il framework degli unit test digitando `load  'general/unittest'`
- Esegui i test sulla soluzione digitando `unittest 'test.ijs'`.
<br></br>
- In alternativa, è possibile eseguire i test in una sola riga, così: `jconsole -js "load 'hello-world.ijs'" "echo unittest 'test.ijs'" "exit 0"`.

## Test saltati

All'inizio sarà abilitato solo il test iniziale.
L'approccio ti incoraggia a risolvere l'esercizio passo dopo passo.
Ogni test include, sopra la propria definizione, un nome che termina in _'\_ignore'_.
Per eseguire il test, cambia il suo valore in 0.

### Esempio:

```
    leap_test_02_ignore=: 1 NB. Change this value to 0 to run this test
    test_leap_test_02  =: monad define
    ...                     NB. test definitions
    )
```
