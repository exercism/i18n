# Informazioni

Il [pacchetto `strings`](https://pkg.go.dev/strings) fornisce funzioni per lavorare con le stringhe.
Qui sotto ci sono alcune delle funzioni del pacchetto; dai un'occhiata alla documentazione per vedere le altre!

| Ruolo                     | Funzione                                            | Scopo                                                                   |
| ------------------------- | --------------------------------------------------- | ----------------------------------------------------------------------- |
| Conversione tra maiuscole e minuscole | [ToLower](https://pkg.go.dev/strings#ToLower)       | Converte una stringa in minuscolo                                       |
| Conversione tra maiuscole e minuscole | [ToUpper](https://pkg.go.dev/strings#ToUpper)       | Converte una stringa in maiuscolo                                       |
| Ricerca                   | [Contains](https://pkg.go.dev/strings#Contains)     | Verifica se una stringa contiene una sottostringa specifica             |
| Ricerca                   | [Count](https://pkg.go.dev/strings#Count)           | Conta le occorrenze non sovrapposte di una sottostringa                 |
| Ricerca                   | [HasPrefix](https://pkg.go.dev/strings#HasPrefix)   | Verifica se una stringa inizia con una sottostringa specifica           |
| Ricerca                   | [HasSuffix](https://pkg.go.dev/strings#HasSuffix)   | Verifica se una stringa termina con una sottostringa specifica          |
| Ricerca                   | [Index](https://pkg.go.dev/strings#Index)           | Restituisce l'indice della prima occorrenza di una sottostringa, oppure -1 |
| Modifica                  | [Replace](https://pkg.go.dev/strings#Replace)       | Sostituisce fino a n occorrenze di una sottostringa                     |
| Modifica                  | [ReplaceAll](https://pkg.go.dev/strings#ReplaceAll) | Sostituisce tutte le occorrenze di una sottostringa                     |
| Modifica                  | [TrimSpace](https://pkg.go.dev/strings#TrimSpace)   | Rimuove gli spazi bianchi all'inizio e alla fine                        |
| Divisione e unione        | [Fields](https://pkg.go.dev/strings#Fields)         | Divide una stringa in parole in base agli spazi bianchi                 |
| Divisione e unione        | [FieldsSeq](https://pkg.go.dev/strings#FieldsSeq)   | Restituisce una parola alla volta                                       |
| Divisione e unione        | [Join](https://pkg.go.dev/strings#Join)             | Unisce un array di stringhe con un separatore                           |
| Divisione e unione        | [Split](https://pkg.go.dev/strings#Split)           | Divide una stringa in parti in base a un separatore                     |
| Divisione e unione        | [SplitSeq](https://pkg.go.dev/strings#SplitSeq)     | Restituisce una parte alla volta                                        |

```go
import (
    "fmt"
    "strings"
)

// Case conversion
strings.ToLower("Gopher")              // "gopher"
strings.ToUpper("Gopher")              // "GOPHER"

// Searching
strings.Contains("Apple", "le")        // true
strings.Index("Apple", "le")           // 3
strings.Index("Apple", "xyz")          // -1
strings.Count("test", "t")             // 2
strings.HasPrefix("Gopher", "Go")      // true
strings.HasSuffix("Gopher", "er")      // true

// Modifying
strings.TrimSpace("  hello  ")         // "hello"
strings.Replace("aabbcc", "b", "x", 1) // "aaxbcc"
strings.ReplaceAll("aabbcc", "b", "x") // "aaxxcc"

// Splitting or Joining
strings.Fields("  a b\tc  ")               // []string{"a", "b", "c"}
strings.Split("a,b,c", ",")                // []string{"a", "b", "c"}
strings.Join([]string{"a", "b", "c"}, ",") // "a,b,c"

// You do not need to worry about this range syntax yet.
// It is covered later in the range iteration concept.
for word := range strings.FieldsSeq("  a b\tc  ") {
    fmt.Println(word)
}
// Output:
// a
// b
// c

for part := range strings.SplitSeq("a,b,c", ",") {
    fmt.Println(part)
}
// Output:
// a
// b
// c
```
