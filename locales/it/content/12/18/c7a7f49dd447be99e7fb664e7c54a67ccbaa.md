# I condizionali

Un **condizionale** sceglie tra due possibili azioni a seconda che qualcosa sia vero.

```sather
   verdict(score : INT) : STR is
      if score >= 5 then
         return "Recalled";
      else
         return "Thank you";
      end;
   end;
```

Leggiamolo: `if`, poi una domanda che risponde `true` o `false`, poi `then`. Le righe dopo `then` vengono eseguite quando la risposta è vera, quelle dopo `else` quando è falsa. `end;` chiude tutto il blocco.

## Più di due strade

`elsif` aggiunge un'altra domanda, posta solo quando le precedenti sono risultate false.

```sather
   verdict(score : INT) : STR is
      if score >= 8 then
         return "Cast";
      elsif score >= 5 then
         return "Recalled";
      else
         return "Thank you";
      end;
   end;
```

L'ordine conta. Un punteggio di `9` viene intercettato dalla prima domanda e non raggiunge mai la seconda, anche se `9 >= 5` è a sua volta vero. Scrivere le condizioni nell'ordine sbagliato è il modo più comune per sbagliare.

Si scrive `elsif`, non `elseif` e nemmeno `else if`.

## Omettere l'else

`else` si può omettere quando in quel caso non c'è nulla da fare.

```sather
   if late then
      apologise;
   end;
```

Una routine che deve restituire qualcosa ha bisogno che ogni percorso restituisca un valore, quindi in questo esercizio ogni `if` mantiene il suo `else`.
