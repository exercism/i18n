# Il tipo tupla

Una tupla è un tipo di dato composto versatile ed efficiente in Cairo: ti permette di raggruppare più valori di tipi diversi in un'unica entità.
Le tuple hanno una lunghezza fissa: una volta dichiarate, la loro dimensione non può cambiare.

## Creare le tuple

Per creare una tupla, scrivi un elenco di valori separati da virgole all'interno di parentesi tonde (`()`).
Ogni posizione della tupla ha un tipo specifico, e questi tipi possono essere diversi tra loro.

```rust
fn main() {
    let tup: (u32, u64, bool) = (10, 20, true);
}
```

Una tupla può contenere più valori di tipi di dato diversi, comprese altre tuple.
Per esempio:

```rust
fn main() {
    let nested_tup: ((i32, u64), (u8, bool)) = ((10, 3), (5, false));
}
```

Qui la variabile `nested_tup` è una tupla che contiene due tuple: le tuple possono quindi avere altre tuple come elementi.

## Destrutturare le tuple

Per accedere ai singoli valori all'interno di una tupla, puoi usare il pattern matching per destrutturarla.
In questo modo la tupla viene scomposta nelle sue parti.

```rust
fn main() {
    let tup = (500, 6, true);

    let (x, y, z) = tup;

    println!("x is: {x}"); // prints "x is: 500"
    println!("y is: {y}"); // prints "x is: 6"
    println!("z is: {z}"); // prints "z is: true"
}
```

## Dichiarare e destrutturare contemporaneamente

Puoi anche dichiarare e destrutturare una tupla contemporaneamente.

```rust
fn main() {
    let (x, y): (felt252, felt252) = (2, 3);
}
```

## Il tipo unit `()`

Il tipo unit è un tipo speciale in Cairo che ha un solo valore: `()`.
È rappresentato da una tupla senza elementi.
La dimensione del tipo unit è sempre zero, ed è garantito che non esista nel codice compilato.

In Cairo ogni espressione restituisce un valore: quando un'espressione non restituisce nulla, restituisce implicitamente `()`.
Questo è utile per le funzioni che devono restituire un valore ma non hanno un valore significativo da restituire.

## Dichiarazione di un tipo tupla con nome

Una tupla con nome ti permette di creare un alias di tipo più descrittivo per una tupla, migliorando la leggibilità del codice.

```rust
type Point = (u32, u32);

fn main() {
    let point: Point = (10, 8);
    println!("{point:?}"); // prints "(10, 8)"
}
```

In questo esempio, `Point` è un tipo tupla con nome che rappresenta una coppia di interi senza segno a 32 bit, e rende il codice più espressivo.
