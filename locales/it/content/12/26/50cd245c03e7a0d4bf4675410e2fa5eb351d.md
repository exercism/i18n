# Concatenazione di stringhe

La concatenazione di stringhe è del tutto valida in Ruby, ma un modo più comune per comporre una stringa è con l'[interpolazione di stringhe](http://ruby-for-beginners.rubymonstas.org/bonus/string_interpolation.html). Per esempio:

```ruby
# Rather than:
"One for " + %{name_variable} + ", one for me"

# Consider:
"One for #{%{name_variable}}, one for me."
```
