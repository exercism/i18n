# Informazioni

Su [concept:csharp/enumerables]() si può iterare usando un [ciclo `foreach`][foreach-statement]:

```csharp
char[] vowels = new [] { 'a', 'e', 'i', 'o', 'u' };

foreach (char vowel in vowels)
{
    // Output the vowel
    System.Console.Write(vowel);
}

// => aeiou
```

Un ciclo `foreach` è formato da tre parti:

1. La dichiarazione: definisci la variabile che conterrà il valore iterato. Questa variabile può essere usata (solo) all'interno del ciclo.
2. L'oggetto iterabile: l'oggetto sul quale è possibile iterare.
3. Il corpo del ciclo.

## Confronto tra cicli for e foreach

In generale, però, un ciclo `foreach` è preferibile a un ciclo `for` per i seguenti motivi:

- Un ciclo `foreach` garantisce di iterare su _tutti_ i valori. Con un ciclo `for`, è facile saltare degli elementi, per esempio a causa di un errore off-by-one.
- Un ciclo `foreach` è più _dichiarativo_: il codice esprime _cosa_ si vuole ottenere, mentre un ciclo `for` esprime _come_ ottenerlo.
- Un ciclo `foreach` è a prova di errore, mentre con i cicli `for` è facile incappare in un errore off-by-one.
- Un ciclo `foreach` funziona con tutti i tipi di collezione, comprese quelle che non supportano l'uso di un indicizzatore per accedere agli elementi.

Per garantire che un ciclo `foreach` iteri su _tutti_ i valori, il compilatore non permette di modificare una collezione all'interno di un ciclo `foreach`:

```csharp
char[] vowels = new [] { 'a', 'e', 'i', 'o', 'u' };

foreach (char vowel in vowels)
{
    // This would result in a compiler error
    // vowel = 'Y';
}
```

Un ciclo `for` ha però alcuni vantaggi rispetto a un ciclo `foreach`:

- Puoi iniziare o fermarti all'indice che vuoi.
- Puoi usare la condizione di terminazione (booleana) che preferisci.
- Puoi saltare degli elementi personalizzando l'incremento della variabile del ciclo.
- Puoi elaborare le collezioni dall'ultimo al primo elemento contando all'indietro.
- Puoi usare i cicli `for` in situazioni che non coinvolgono collezioni.

Argomenti correlati:

- Tieni presente che C# supporta gli [array multidimensionali][multi-dimensional-arrays] come `int[,] arr = new int[10, 5]`, che possono essere molto utili.
- Tieni anche presente che puoi istanziare oggetti di tipo [`System.Array`][system-array-object] con `Array.CreateInstance`. Tali oggetti sono di scarsa utilità, soprattutto per l'interoperabilità con il codice VB.NET. Non sono intercambiabili con gli array standard (`T[]`). Possono avere un limite inferiore diverso da zero.
