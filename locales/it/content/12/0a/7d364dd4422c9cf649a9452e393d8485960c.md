# Appendice alle istruzioni

## Registri

| Registro | Utilizzo     | Tipo      | Descrizione                              |
| -------- | ------------ | --------- | ---------------------------------------- |
| `$a0`    | input        | intero    | limite                                   |
| `$a1`    | input/output | indirizzo | array di destinazione per i numeri primi |
| `$v0`    | output       | intero    | numero di numeri primi                   |
| `$t0-9`  | temporaneo   | qualsiasi | usato come memoria temporanea            |
