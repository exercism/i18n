# Usa `||` invece di if-else

Quando vuoi cambiare un valore che vale `nil` o un qualsiasi altro valore falsy, usa l'operatore `||` invece di un'istruzione if-else.
È più idiomatico, più conciso e anche più performante.

L'operatore `||` restituisce il valore a sinistra dell'operatore se è truthy, altrimenti restituisce il valore a destra.

Per esempio:

```crystal
# Rather than:
value.nil? ? "default" : value

# Consider:
value || "default"
```
