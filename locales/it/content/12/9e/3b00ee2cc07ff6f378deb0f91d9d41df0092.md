# Introduzione

Una `String` in Java è un oggetto che rappresenta testo immutabile sotto forma di sequenza di caratteri Unicode (lettere, cifre, segni di punteggiatura, ecc.).
Per definire un'istanza di `String` si usano le virgolette doppie:

```java
String fruit = "Apple";
```

Le stringhe si manipolano chiamando i metodi della stringa.
Una volta costruita una stringa, il suo valore non può mai cambiare.
I metodi che sembrano modificare una stringa in realtà restituiscono una nuova stringa.
La classe `String` fornisce alcuni metodi _statici_ per trasformare le stringhe.
