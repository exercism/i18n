# Introduzione

Questo esercizio ti insegnerà i mattoni fondamentali di Ruby.
Copre molti argomenti, ma non preoccuparti se ti sembra troppo: approfondiremo ogni cosa molto più nel dettaglio man mano che proseguiamo lungo il percorso.

Una delle cose fondamentali da capire su Ruby è che è un [linguaggio orientato agli oggetti][object-oriented-programming] e che **in Ruby tutto è un [oggetto][object]**. Numeri, stringhe, array: sono tutti oggetti.

## Variabili e costanti

Di solito usiamo gli oggetti assegnando loro dei nomi, tramite variabili o costanti.

Le variabili si scrivono sempre in [snake case][snake-case].
Una variabile può fare riferimento a oggetti diversi nel corso della sua esistenza.
Ad esempio, `my_first_variable` può essere definita e ridefinita molte volte usando l'operatore `=`:

```ruby
my_first_variable = 1
my_first_variable = "Some string"
my_first_variable = SomeComplexObject.new
```

Le costanti, invece, sono pensate per essere assegnate una sola volta.
Devono iniziare con la lettera maiuscola e di norma si scrivono tutte in maiuscolo, con le parole separate da underscore.
Ad esempio:

```ruby
MY_FIRST_CONSTANT = 10

# Redefining not allowed
# MY_FIRST_CONSTANT = "Some String"
```

## Classi

Ruby è organizzato in classi.
Le classi si definiscono usando la parola chiave `class` seguita dal nome della classe.
Gli oggetti vengono generalmente creati istanziando le classi con il metodo `.new`.
Ad esempio:

```ruby
# Define the class
class Calculator
  #...
end

# Create an instance of it and assign it to a variable
my_first_calc = Calculator.new
```

## Metodi

Le unità di funzionalità vengono incapsulate nei metodi, simili alle _funzioni_ di altri linguaggi.

Un metodo può essere definito con argomenti posizionali, con argomenti keyword (che si definiscono e si chiamano usando la sintassi `:`) oppure senza alcun argomento.

I metodi restituiscono implicitamente il risultato dell'ultima istruzione valutata, oppure possono restituire esplicitamente un oggetto tramite la parola chiave `return`.

```ruby
class Calculator

  # Positional arguments
  def add(num1, num2)
    return num1 + num2 # Explicit return
  end

  # Keyword arguments
  def multiply(num1:, num2:)
    num1 * num2 # Implicit return
  end
end
```

I metodi si chiamano usando la sintassi `.`:

```ruby
calc = Calculator.new
calc.add(1, 3)
calc.multiply(num1: 2, num2: 5)
```
