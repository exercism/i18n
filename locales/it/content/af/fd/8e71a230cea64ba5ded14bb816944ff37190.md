# Informazioni

Il modulo `Time` si usa per mostrare date e orari in un formato leggibile.
Anche se tecnicamente è possibile manipolare le date e gli orari con `Time`, esistono pacchetti della comunità di Elm molto più adatti allo scopo, come [`justinmimbs/date`][date] o [`CoderDennis/elm-time-format`][elm-time-format].

## Posix

Le date e gli orari sono rappresentati dal tipo opaco `Posix`, che avvolge il tempo epoch di Unix, cioè il numero di millisecondi trascorsi dalla mezzanotte UTC del 1º gennaio 1970.
Un `Posix` è un valore non ambiguo che non varia tra i fusi orari, quindi è una buona scelta per tenere traccia del tempo.
In un'applicazione Elm, i valori `Posix` vengono di norma forniti da fonti esterne, come il browser.

È possibile trasformare un `Posix` in un numero di millisecondi e viceversa con le seguenti funzioni:

```elm
posixToMillis : Posix -> Int
millisToPosix : Int -> Posix
```

## Fusi orari

Nella vita di tutti i giorni non leggiamo i `Posix`, preferiamo l'ora locale, che dipende da dove ci troviamo sulla Terra e dalle regole locali sull'ora legale.
In Elm, queste informazioni sono codificate nel tipo opaco `Zone`, di norma fornito dal browser.

Esiste un `Zone` speciale sempre accessibile:

```elm
utc : Zone
```

## Orari leggibili

Con un `Posix` e una `Zone` abbiamo informazioni sufficienti per mostrare l'ora locale a qualsiasi livello di dettaglio.
Ecco un elenco delle funzioni che si possono usare a questo scopo:

```elm
toYear : Zone -> Posix -> Int
toMonth : Zone -> Posix -> Month
toDay : Zone -> Posix -> Int
toWeekday : Zone -> Posix -> Weekday
toHour : Zone -> Posix -> Int
toMinute : Zone -> Posix -> Int
toSecond : Zone -> Posix -> Int
toMillis : Zone -> Posix -> Int
```

Avrai notato altri due tipi personalizzati di `Time`:

```elm
type Month = Jan | Feb | Mar | Apr | May | Jun | Jul | Aug | Sep | Oct | Nov | Dec
type Weekday = Mon | Tue | Wed | Thu | Fri | Sat | Sun
```

Spetta agli utenti convertire questi tipi personalizzati in valori leggibili.
