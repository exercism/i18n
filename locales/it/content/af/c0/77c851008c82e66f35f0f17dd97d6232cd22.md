# Introduzione

Questa è una _grande_ materia!
È possibile scrivere un lungo libro al riguardo, e diverse persone l'hanno fatto (cerca su Amazon "unicode book" per vedere alcuni esempi).

## Una brevissima storia

Gestire i caratteri nei computer era molto più semplice nei decenni passati, quando i programmatori presumevano che l'inglese fosse l'unica lingua importante.
Quindi: 26 lettere, maiuscole e minuscole, 10 cifre, diversi segni di punteggiatura, più un codice (0x07) per far suonare un campanello, e tutto stava in 7 bit: il set di caratteri ASCII.

Naturalmente, le persone hanno iniziato a chiedersi: e per à, ä e Ł? Poi altre persone hanno iniziato a chiedere di ऄ, ஹ e ญ, e i giovani volevano le emoji 😱.
Cosa fare?

Per farla breve, molte persone intelligenti e pazienti hanno dovuto far parte di comitati per anni, elaborando i dettagli del set di caratteri Unicode, e di codifiche come UTF-8, e molto software ha avuto bisogno di una riscrittura _molto_ complicata.
Inoltre, sono stati introdotti molti nuovi bug.

Per evitare che _tutto_ si rompa, il design di Unicode/UTF-8 garantisce che i primi 127 codici siano identici ad ASCII _(persino il campanello)_.

## I caratteri in Julia

I linguaggi progettati dopo il 2005 circa hanno il grande vantaggio che uno standard Unicode ragionevolmente stabile esisteva già.

Julia (rilasciato per la prima volta nel 2012) ha potuto presupporre che tutto sarebbe stato Unicode: caratteri, stringhe, nomi di variabili e funzioni, operatori matematici...

Citando il manuale, «Julia rende semplice ed efficiente la gestione del semplice testo ASCII, e gestire Unicode è il più semplice ed efficiente possibile».
Nota il «possibile», è una parte importante dell'affermazione.

***I letterali carattere si scrivono tra apici singoli, e sono distinti dalle stringhe scritte tra virgolette doppie.***

Questo è ovvio per chi viene dal mondo C/C++, ma potenzialmente confuso per i programmatori Python e Javascript.

```julia-repl
julia> a = 'a'  # Roman alphabet
'a': ASCII/Unicode U+0061 (category Ll: Letter, lowercase)

julia> typeof(a)
Char

julia> jha = 'झ'  # Devanagari alphabet
'झ': Unicode U+091D (category Lo: Letter, other)

julia> typeof(jha)
Char

julia> '❤'  # heart emoji
'❤': Unicode U+2764 (category So: Symbol, other)
```

Dagli esempi possiamo vedere che il tipo è `Char`, e Julia ha ulteriori informazioni sulla categoria del carattere.

Guardando più da vicino, sembra che questi caratteri possano essere rappresentati da 4 cifre esadecimali.
Il set di caratteri completo richiede fino a 6 cifre esadecimali.

Questi numeri sono chiamati «code point», e attualmente vanno da U+0000 a U+10FFFF.
Vengono visualizzati nella REPL, ma all'interno del codice usa `codepoints()` per ottenerli.

Convertire tra `Char` e `Int` è semplice:

```julia-repl
julia> Int('a')
97

julia> Char(97)
'a': ASCII/Unicode U+0061 (category Ll: Letter, lowercase)
```

Il compilatore permette _alcune_ forme di aritmetica intera sui `Char`:

```julia-repl
julia> 'b' - 'a'  # interval, in alphabetic order
1

julia> 'b' + 'a'
ERROR: MethodError: no method matching +(::Char, ::Char)

julia> 'a' + 5
'f': ASCII/Unicode U+0066 (category Ll: Letter, lowercase)

julia> 'f' + ('A' - 'a')  # same as `uppercase('f')`
'F': ASCII/Unicode U+0046 (category Lu: Letter, uppercase)
```

## Funzioni per i caratteri

Molte funzioni per la gestione delle stringhe possono funzionare anche con input di tipo `Char`.

- Per gli alfabeti appropriati, cambia maiuscole/minuscole con `uppercase()` e `lowercase()`.
- Verifica maiuscole/minuscole con `isuppercase()` e `islowercase()`.
- Verifica il tipo di carattere con:
  - `isletter()` copre molti alfabeti
  - `isdigit()`, verifica per i caratteri strettamente 0:9
  - `isnumeric()`, più ampio di `isdigit`, quindi `true` per ¾ e vari script non europei
  - `isxdigit()`, cifre esadecimali
  - `isascii()`, carattere pre-Unicode
  - `ispunct()`, punteggiatura
  - `isspace()`, qualsiasi carattere di spazio
  - `isprint()`, caratteri stampabili (l'opposto è `iscntrl()`)

```julia
islowercase('A')  # false
uppercase('γ')  # 'Γ': Unicode U+0393 (category Lu: Letter, uppercase)
ispunct('@')  # true
isdigit('A')  # false
isxdigit('A')  # true
```

## Conversioni tra vettori di Char e stringhe

Per convertire una stringa in un vettore di Char, possiamo usare `collect()`.

Per convertire un vettore di Char in una stringa, c'è il costruttore `String()`.

```julia-repl
julia> s = "abcde"
"abcde"

julia> cv = collect(s)
5-element Vector{Char}:
 'a': ASCII/Unicode U+0061 (category Ll: Letter, lowercase)
 'b': ASCII/Unicode U+0062 (category Ll: Letter, lowercase)
 'c': ASCII/Unicode U+0063 (category Ll: Letter, lowercase)
 'd': ASCII/Unicode U+0064 (category Ll: Letter, lowercase)
 'e': ASCII/Unicode U+0065 (category Ll: Letter, lowercase)

julia> String(cv)
"abcde"
```

Questo funziona con qualsiasi carattere, non solo ASCII.

```julia-repl
julia> collect("❤,😱")
3-element Vector{Char}:
 '❤': Unicode U+2764 (category So: Symbol, other)
 ',': ASCII/Unicode U+002C (category Po: Punctuation, other)
 '😱': Unicode U+1F631 (category So: Symbol, other)
```

Nota che il costruttore `String()` opera su un Vector.
Per _eseguire il cast_ di un singolo `Char` in una stringa di 1 carattere, la funzione è `string()`, con la `s` minuscola.

```julia-repl
julia> string('a')
"a"
```

## Memorizzazione

Tutto ciò che abbiamo visto finora nel documento sembra relativamente semplice, quindi non c'è davvero molto di cui preoccuparsi?

Purtroppo, questo è troppo ottimistico!

Una complicazione deriva dalla necessità di «fino a» 6 cifre esadecimali per code point.
Questo significa che caratteri diversi richiedono quantità diverse di spazio in memoria quando codificati in UTF-8.

Un byte può memorizzare solo numeri (senza segno) fino a 255, due cifre esadecimali, quindi UTF-8 usa un numero variabile di byte (da 1 a 4) per memorizzare un `Char`.
Questi sono chiamati «code unit», e la funzione `ncodeunits()` restituirà il numero necessario per un dato carattere.

```julia-repl
julia> codepoint(jha)  # jha 'झ' is defined in an earlier example
0x0000091d

julia> ncodeunits(jha)
3

julia> ncodeunits('a')  # ASCII character
1

julia> ncodeunits('😱')  # emoji
4
```

Inoltre, non tutto ciò che può essere visualizzato sullo schermo ha il proprio code point unico.
Alcuni caratteri visivamente distinti sono considerati derivati da altri, quindi Unicode li tratta come un carattere genitore più un modificatore.
