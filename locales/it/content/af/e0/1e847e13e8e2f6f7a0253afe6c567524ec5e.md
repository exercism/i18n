# Approfondimento

I due tipi principali di proprietà sono

1. le proprietà implementate automaticamente, in cui gli accessor `get` e `set` non hanno un corpo.
   Possono essere inizializzate esplicitamente oppure no. Per esempio:
   ```csharp
   public int MyProperty {get; set;} = 42;
   ```
2. quelle in cui gli accessor valutano espressioni ed eseguono istruzioni. Il codice può
   essere semplice come restituire o assegnare un campo sottostante. Per esempio:
   ```csharp
   private int myField;
   public int MyProperty
   {
     get { return myField; }
     set { myField = value; }
   }
   ```

C'è una notevole sovrapposizione di comportamento e di capacità tra proprietà e metodi.
Quando non sono implementate automaticamente, le proprietà possono contenere qualsiasi
istruzione o espressione che possa comparire all'interno dello scope della classe. Nel
caso più comune vengono spesso descritte come un incapsulamento di un campo sottostante.
Anche se il più delle volte è ovvio se codificare un comportamento come proprietà o come metodo in un caso
specifico, spesso è una questione di valutazione da parte di chi scrive il codice, in particolare per quanto
riguarda la quantità di codice da eseguire all'interno degli accessor. La validazione in un accessor `set` e un semplice calcolo o una formattazione in un
accessor `get` sono casi comuni:

```csharp
private float fraction;
public float Percentage
{
  get { return fraction * 100; }
  set
  {
    if (value < 0 || value > 100)
    {
      throw new ArgumentException("Percentage must be between 0 and 100");
    }
    fraction = value / 100;
  }
}
```

Come per gli altri membri della classe, anche le proprietà possono avere livelli di accesso.
Il più delle volte le proprietà avranno un livello di accesso non privato, in linea con
il loro scopo essenziale. A volte uno degli accessor avrà
un livello di accesso diverso da quello della proprietà. Nel caso di `TareWeight`,
con il vincolo di «sicurezza» piuttosto artificioso, c'era l'opportunità
di avere una proprietà pubblica con un getter privato. Questo significa che il codice esterno
alla classe può impostare il valore della proprietà, ma solo il codice interno alla classe
può leggerlo (get).

```csharp
public int ConfidentialValueUsedInternally {private get; set; }
```

Sono supportati anche accessor `set` non pubblici, ma un caso più comune è quello in cui
l'accessor `set` può essere omesso del tutto. Forse perché
il valore della proprietà viene impostato nel costruttore della classe.

```csharp
class MyClass
{
  public MyClass( int importantValue)
  {
    ConstructedValue = importantValue;
  }
  public int ConstructedValue {get;}
}
```

Questo esercizio ha trattato l'uso di base delle proprietà. Troverai argomenti più avanzati
in altri esercizi:

- proprietà con corpo di espressione, accessor get e set (trattate nei Membri con corpo di espressione)
- proprietà sulle interfacce (trattate nelle Interfacce)
- proprietà/proprietà astratte sulle classi astratte (trattate nell'Ereditarietà)
- uso della parola chiave `readonly` con le proprietà (trattato nell'Immutabilità)
- proprietà statiche (trattate nei Membri statici)
- indicizzatori (trattati negli Indicizzatori)
