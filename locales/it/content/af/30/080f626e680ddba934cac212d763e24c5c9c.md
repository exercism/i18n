# Informazioni

Oltre alle classi di caratteri e ai quantificatori, le espressioni regolari possono descrivere la *struttura* e il *contesto* di un testo. Queste funzionalità fanno parte dello stesso vocabolario [`regexp`][regexp] e si scrivono con il letterale `R/ /`.

## Raggruppamento e alternanza

Le parentesi tonde `( )` raggruppano una parte di un pattern, così un quantificatore o un `|` («questo o quello») si applica all'intero gruppo. Un `?` dopo un gruppo lo rende opzionale:

```factor
USING: regexp ;

"abab"    R/ (ab)+/ matches? .             ! => t
"cat"     R/ cat|dog/ matches? .           ! => t
"$100.50" R/ \$\d+(\.\d{2})?/ matches? .   ! => t
"$100"    R/ \$\d+(\.\d{2})?/ matches? .   ! => t   (group optional)
```

## Ancore

```
^    ! start of the string
$    ! end of the string
\b   ! a word boundary
```

Un *confine di parola* (`\b`) è il punto in cui un carattere di parola (una lettera, una cifra o un underscore) incontra un carattere che non lo è, comprese le estremità della stringa. Quindi `\bcat\b` trova `cat` solo quando compare da solo:

```factor
USING: regexp ;

"cat nap" R/ \bcat\b/ re-contains? .   ! => t
"scatter" R/ \bcat\b/ re-contains? .   ! => f
```

## Lookaround

Un *lookaround* verifica cosa viene subito prima o subito dopo un punto senza includere quei caratteri nella corrispondenza: è a larghezza zero:

```
(?=...)    ! lookahead
(?!...)    ! negative lookahead
(?<=...)   ! lookbehind
```

```factor
USING: regexp ;

"spent $100 and $25" R/ (?<=\$)\d+/ all-matching-subseqs .
! => { "100" "25" }

"up 5% then 12%" R/ \d+(?=%)/ all-matching-subseqs .
! => { "5" "12" }
```

## Opzioni

Una lettera di opzione dopo la `/` di chiusura cambia l'intero pattern. La `i` disattiva la distinzione tra maiuscole e minuscole:

```factor
USING: regexp ;

"REFUND" R/ refund/i matches? .   ! => t
```

## Trasformare ogni corrispondenza

`map-matches` esegue una quotation su ogni corrispondenza e raccoglie i risultati; `each-match` fa lo stesso, ma solo per gli effetti collaterali. Entrambe passano alla quotation l'indice `start` della corrispondenza, l'indice `end` e l'intera stringa, così `subseq` recupera il testo trovato:

```
map-matches ( string regexp quot: ( start end string -- obj ) -- seq )
each-match  ( string regexp quot: ( start end string --     ) --     )
```

```factor
USING: math regexp sequences ;

"a1 b22 c333" R/ \d+/ [ subseq length ] map-matches .
! => { 1 2 3 }
```

## Cosa non supporta Factor

Il motore delle espressioni regolari di Factor non ha l'**estrazione dei gruppi di cattura** (un gruppo `( )` struttura il pattern, ma non puoi rileggere il testo con cui ha trovato corrispondenza), né i **back-reference** (`\1`), né i quantificatori **lazy/non-greedy** (`*?`, `+?`). Il lookaround è il sostituto idiomatico dei gruppi di cattura: trova la parte che ti interessa, riconosciuta dal contesto che la circonda.
