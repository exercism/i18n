# Appendice alle istruzioni

## Messaggi delle eccezioni

A volte è necessario [sollevare un'eccezione](https://docs.python.org/3/tutorial/errors.html#raising-exceptions). Quando lo fai, dovresti sempre includere un **messaggio di errore significativo** per indicare quale sia l'origine dell'errore. Questo rende il codice più leggibile ed aiuta notevolmente il debug. Nei casi in cui sai che l'origine dell'errore sarà di un certo tipo, puoi scegliere di sollevare uno dei [tipi di errore predefiniti](https://docs.python.org/3/library/exceptions.html#base-classes), ma dovresti comunque includere un messaggio significativo.

Questo esercizio in particolare richiede che tu usi la [istruzione raise](https://docs.python.org/3/reference/simple_stmts.html#the-raise-statement) per «lanciare» un `ValueError` per diverse basi di input e di output. I test passeranno solo se usi `raise` per l'`exception` e ci alleghi un messaggio significativo.

Per sollevare un `ValueError` con un messaggio, scrivi il messaggio come argomento del tipo `exception`:

```python
# for input.
raise ValueError("input base must be >= 2")

# another example for input.
raise ValueError("all digits must satisfy 0 <= d < input base")

# or, for output.
raise ValueError("output base must be >= 2")
```
