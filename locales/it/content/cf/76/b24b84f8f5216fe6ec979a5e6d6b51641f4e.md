# Installazione

## Requisiti del percorso PowerShell

Il percorso PowerShell di Exercism richiede che sul tuo sistema siano installati:

- PowerShell o Windows PowerShell Core
- il modulo del framework di test e mock Pester

(PS: il supporto per PowerShell è limitato alle correzioni critiche. PowerShell Core è mantenuto con costanza e offre un supporto multipiattaforma maggiore)

### Installare PowerShell

PowerShell è preinstallato su tutti i sistemi operativi Windows a partire da Windows 7 SP1.

Puoi trovare la versione più recente di PowerShell e le istruzioni di installazione per tutte le piattaforme (Linux, macOS e Windows) [qui][installation].

Sono disponibili anche il codice sorgente e l'installazione manuale di [PowerShell][source-code].

### Installare e aggiornare il framework Pester

[Pester][pester] è il framework di test per PowerShell.
Dalla versione 4.0.9 è compatibile con PowerShell Core su Windows, Linux e MacOS (con alcune limitazioni)

È preinstallato su Windows 10, ma ti consigliamo di aggiornarlo eseguendo il seguente comando PowerShell:

```PowerShell
Install-Module -Name Pester -Force -SkipPublisherCheck
```

Per gli aggiornamenti successivi, esegui:

```PowerShell
Update-Module -Name Pester
```

Se necessario, trovi ulteriori istruzioni per l'installazione su: [https://github.com/pester/Pester/wiki/Installation-and-Update]()

## Usare un IDE

Se desideri un'esperienza di editing più completa, probabilmente vorrai usare un IDE.
Questi sono gli IDE più diffusi che supportano la creazione di progetti PowerShell:

### Tutte le piattaforme

- [PowerShell ISE (Integrated Scripting Environment)][ise], IDE grafico integrato che viene fornito con PowerShell (solo Windows).
  Per avviare PowerShell ISE, digita `powershell_ise.exe` in una console PowerShell.
- [Visual Studio Code][vsc] con l'[estensione PowerShell][vsc-extension].
  Visual Studio Code ti permetterà anche di eseguire i test e di fare il debug del codice.
- [Sublime Text 3][sublime] con il [pacchetto PowerShell][sublime-package].
