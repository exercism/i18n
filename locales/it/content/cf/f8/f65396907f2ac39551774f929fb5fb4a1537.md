# Introduzione

In questo esercizio dovrai eseguire la logica in modo condizionale. Il modo più comune per farlo in C# è usare un'istruzione `if/else`:

```csharp
int x = 6;

if (x == 5)
{
    // Execute logic if x equals 5
}
else if (x > 7)
{
    // Execute logic if x greater than 7
}
else
{
    // Execute logic in all other cases
}
```

La condizione di un'istruzione `if` deve essere di tipo `bool`. In C# non esiste il concetto di valori _truthy_.
