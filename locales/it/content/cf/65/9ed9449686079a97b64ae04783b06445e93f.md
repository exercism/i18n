# Suggerimenti

## Generale

- Leggi i capitoli su [charlist][getting-started-charlists], [Unicode e code point][getting-started-code-points] e [`case`][getting-started-case] nella guida ufficiale Getting Started.
- Leggi i capitoli su [charlist][elixirschool-charlists] e [`case`][elixirschool-case] su elixirschool.com.

## 1. Ripulisci i nomi utente esistenti rimuovendo tutto tranne le lettere minuscole

- Usa la ricorsione per iterare su una charlist.
- C'è una [funzione integrata][kernel-case] che permette di confrontare un dato valore con molti pattern.
- Esiste una [sintassi speciale][syntax-reference-code-points] per ottenere il code point di un carattere. Si può usare nelle guardie.
- Le charlist sono liste di code point, e i code point, essendo numeri, si possono [confrontare][kernel-greater-than] tra loro.
- Le lettere latine minuscole hanno tutte [code point consecutivi][unicode-character-reference], in ordine alfabetico.
- C'è una [funzione integrata][kernel-concat-list] che permette di concatenare due liste.

## 2. Consenti gli underscore

- Esiste una [sintassi speciale][syntax-reference-code-points] per ottenere il code point di un carattere. Si può usare nelle guardie e funziona anche con i caratteri di punteggiatura.
- C'è una [funzione integrata][kernel-concat-list] che permette di concatenare due liste.

## 3. Sostituisci i caratteri tedeschi

- Esiste una [sintassi speciale][syntax-reference-code-points] per ottenere il code point di un carattere. Si può usare nelle guardie e funziona anche con le lettere non ASCII.
- C'è una [funzione integrata][kernel-concat-list] che permette di concatenare due liste.
