# Introduzione

## Istruzioni switch

Wikipedia descrive un'istruzione `switch` come «un tipo di meccanismo di controllo di selezione che permette al valore di una variabile o di un'espressione di modificare il flusso di controllo del programma».

Il meccanismo coinvolge le seguenti parole chiave: `switch`, `case`, `break` e `default`.

Nella loro forma più semplice, verificano un'espressione primitiva o una stringa e prendono una decisione in base al suo valore. Per esempio:

```csharp
string direction = GetDirection();
switch (direction)
{
    case "left":
        GoLeft();
        break;
    case "right":
        GoRight();
        break;
    default:
        MarkTime();
        break;
}
```

Nella loro forma più sofisticata, introducono il down casting `case <Type> <variable>:` e le guardie (`when`).

```csharp
Animal animal = GetAnimal();

switch (animal)
{
    case Dog canine:
    case Coyote canine:
        canine.Bark();
        break;
    case Cat cat when cat.HasOnly8Lives():
        cat.IsCareful();
        cat.Meow();
        break;
    case Cat cat:
        cat.Meow();
        break;
}
```
