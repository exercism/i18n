# Metodi delle stringhe

`String` ha diversi metodi che si possono usare per manipolare le stringhe.  
Questi metodi si chiamano sulla stringa stessa e spesso vengono concatenati per eseguire più operazioni su una stringa.

Di seguito trovi un elenco di alcuni dei metodi più comuni.
Consulta la [documentazione dell'API di `String`][string-api] per un elenco completo dei metodi.

## String#upcase & String#downcase

Il metodo [`upcase`][upcase] restituisce una nuova stringa con tutti i caratteri convertiti in maiuscolo.

```crystal
"hello".upcase
# => "HELLO"
```

Il metodo [`downcase`][downcase] restituisce una nuova stringa con tutti i caratteri convertiti in minuscolo.

```crystal
"HELLO".downcase
# => "hello"
```

## String#capitalize & String#camelcase & String#underscore & String#titleize

Diversi metodi possono fare conversioni di maiuscole e minuscole più specifiche.
Possono essere utili quando si converte una stringa in un formato specifico.
Ecco un elenco di alcuni dei metodi più comuni:

| Metodo                            | Descrizione                                                                                                        | Esempio                                              |
| --------------------------------- | ------------------------------------------------------------------------------------------------------------------ | ---------------------------------------------------- |
| [`String#capitalize`][capitalize] | Converte la prima lettera in maiuscolo e il resto in minuscolo                                                     | `"hEllO" # => "Hello"`                               |
| [`String#camelcase`][camel-case]  | Converte gli underscore in camelcase                                                                               | `"eiffel_tower" # => "EiffelTower"`                  |
| `String#camelcase(lower: true)`   | Come String#camelcase, ma lascia il primo carattere in minuscolo                                                   | `"empire_state_building" # => "empireStateBuilding"` |
| [`String#underscore`][underscore] | Converte tutti i caratteri in minuscolo e inserisce un underscore tra una lettera minuscola e una maiuscola        | `"PartyInTheUSA" # => "party_in_the_usa"`            |
| [`String#titleize`][titleize]     | Mette in maiuscolo la prima lettera di ogni parola e in minuscolo il resto                                         | `"the great gatsBY" # => "The Great Gatsby"`         |

## String#sub & String#gsub

Crystal ha dei metodi per sostituire parti di una stringa.
Sono [`sub`][sub] (_sostituzione_) e [`gsub`][gsub] (_sostituzione globale_).

Questi metodi possono accettare una stringa, un char o una regex come primo argomento e una stringa o un char come secondo argomento.
Il primo argomento è la parte della stringa che verrà sostituita, e il secondo argomento è la sostituzione.
`Char` e le regex verranno spiegati nei concetti successivi.

Il metodo `sub` sostituisce la prima occorrenza del primo argomento con il secondo argomento.

```crystal
"hello".sub("l", "r")
# => "herlo"
```

Il metodo `gsub` funziona come `sub`, ma sostituisce tutte le occorrenze del primo argomento con il secondo argomento.

```crystal
"hello".gsub("l", "r")
# => "herro"
```

## String#chomp & String#strip

Chomp e strip si possono usare per rimuovere caratteri indesiderati da una stringa.

Il metodo [`chomp`][chomp] rimuove di default gli ultimi caratteri `\r`, `\n` o `\r\n` da una stringa.
Se il metodo viene chiamato con un argomento, rimuove il valore indicato dalla fine della stringa, se è presente.

```crystal
"hello\n".chomp
# => "hello"

"hello".chomp("llo")
# => "he"
```

Di default, il metodo [`strip`][strip] rimuove tutti gli spazi bianchi dall'inizio e dalla fine di una stringa.
Se il metodo viene chiamato con un argomento, rimuove quell'argomento dall'inizio e dalla fine della stringa, se è presente.

```crystal
" hello ".strip
# => "hello"
```

## String#reverse

Puoi usare il metodo [`reverse`][reverse] per invertire una stringa.
Questo metodo restituisce una nuova stringa con i caratteri in ordine inverso.

```crystal
"hello".reverse
# => "olleh"
```

## String#index

Il metodo [`index`][index] si può usare per trovare l'indice di un carattere in una stringa.
Il metodo `index` accetta una `String`, un `Char` o una regex come argomento.
Può accettare un secondo argomento opzionale per specificare l'indice da cui iniziare la ricerca.
Il metodo `index` restituisce l'indice della prima occorrenza dell'argomento.

```crystal
"hello".index("l")
# => 2

"hello".index("l", 3)
# => 3
```

## String#delete_at

Puoi usare il metodo [`delete_at`][delete_at] per rimuovere un carattere da una stringa.
Il metodo `delete_at` accetta un indice come argomento e rimuove il carattere a quell'indice.

```crystal
"hello".delete_at(0)
# => "ello"

"hello".delete_at(3)
# => "helo"
```

## String#insert

Il metodo [`insert`][insert] si può usare per inserire una stringa a un indice specifico.
Il metodo `insert` accetta un indice come primo argomento e una stringa come secondo argomento.
Il metodo `insert` restituisce una nuova stringa con il secondo argomento inserito all'indice indicato.

```crystal
"hello".insert(0, "h")
# => "hhello"

"hello".insert(3, "l")
# => "helllo"
```
