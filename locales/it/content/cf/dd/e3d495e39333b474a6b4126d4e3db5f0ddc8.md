# Introduzione

## Costruttori

Per creare un'istanza di una _classe_ si chiama il suo _costruttore_ tramite l'operatore `new`. Un costruttore è un tipo speciale di metodo il cui scopo è inizializzare un'istanza appena creata. I costruttori sembrano metodi normali, ma senza tipo restituito e con un nome che coincide con quello della classe.

```csharp
class Library
{
    private int books;

    public Library()
    {
        // Initialize the books field
        this.books = 10;
    }
}

// This will call the constructor
var library = new Library();
```

Come i metodi normali, i costruttori possono avere parametri. Di solito i parametri del costruttore vengono salvati in campi (privati) per essere usati più tardi, oppure servono per un calcolo una tantum. Gli argomenti si possono passare ai costruttori proprio come si passano gli argomenti ai metodi normali.

```csharp
class Building
{
    private int numberOfStories;
    private int totalHeight;

    public Building(int numberOfStories, double storyHeight)
    {
        this.numberOfStories = numberOfStories;
        this.totalHeight = numberOfStories * storyHeight;
    }
}

// Call a constructor with two arguments
var largeBuilding = new Building(55, 6.2)
```
