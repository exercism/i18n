# Istruzioni

Stai creando un semplice gioco online in cui un amico può indovinare un numero segreto. Vuoi dare un po' di feedback, ma senza rivelare la risposta con un tentativo. Devi ideare una funzione che fornisca risposte diverse a seconda di come il tentativo si rapporta al numero segreto.

| Condizione                                                       | Risposta       |
| ---------------------------------------------------------------- | -------------- |
| Quando il tentativo coincide con il numero segreto               | "Correct"      |
| Quando il tentativo è uno in più o uno in meno del numero segreto | "So close"     |
| Quando il tentativo è maggiore del numero segreto                | "Too high"     |
| Quando il tentativo è minore del numero segreto                  | "Too low"      |
| Quando non viene fatto alcun tentativo                           | "Make a guess" |

Tutti i tentativi e i numeri segreti sono numeri interi.

## 1. Genera la risposta quando il tentativo coincide con il numero segreto

Implementa la funzione `compare/2`, che accetta due argomenti, `secret_number` e `guess`, entrambi numeri interi.

```elixir
GuessingGame.compare(5, 5)
# => "Correct"
```

## 2. Genera la risposta quando il tentativo è maggiore del numero segreto

Modifica la funzione `compare` in modo che risponda ai tentativi più alti del numero segreto.

```elixir
GuessingGame.compare(5, 8)
# => "Too high"
```

## 3. Genera la risposta quando il tentativo è minore del numero segreto

Modifica la funzione `compare` in modo che risponda ai tentativi più bassi del numero segreto.

```elixir
GuessingGame.compare(5, 2)
# => "Too low"
```

## 4. Genera le risposte quando il tentativo è uno in più o uno in meno del numero segreto

Modifica la funzione `compare` in modo che risponda ai tentativi vicini al numero segreto.

```elixir
GuessingGame.compare(5, 6)
# => "So close"
GuessingGame.compare(5, 4)
# => "So close"
```

## 5. Genera la risposta quando non c'è alcun tentativo

Modifica la funzione `compare` in modo che risponda all'assenza di un tentativo.

```elixir
GuessingGame.compare(5)
# => "Make a guess"

GuessingGame.compare(5, :no_guess)
# => "Make a guess"
```
