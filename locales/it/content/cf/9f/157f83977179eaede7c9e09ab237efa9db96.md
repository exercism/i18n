# Istruzioni

La tua nostalgia per le carte Blorkemon™️ non accenna a diminuire, hai perfino ricominciato a collezionarle e stai convincendo i tuoi amici a unirsi a te.

In questo esercizio, una collezione di carte è rappresentata da un `MapSet`, dato che le carte duplicate non contano quando l'obiettivo è ottenere tutte le carte esistenti.

## 1. Inizia una collezione

Vuoi davvero che i tuoi amici entrino nella tua follia per i Blorkemon™️, e il modo migliore è dare il via alla loro collezione regalando loro una carta.

Implementa `GottaSnatchEmAll.new_collection`, che trasforma una carta in una collezione.

```elixir
GottaSnatchEmAll.new_collection("Newthree")
# => MapSet.new(["Newthree"])
```

## 2. Fai crescere la collezione

Una volta che hai una collezione, questa prende vita propria e deve crescere.

Implementa `GottaSnatchEmAll.add_card`, che prende una carta e una collezione e restituisce una tupla con due valori: un booleano che indica se la carta era già nella collezione, e la collezione con la carta aggiunta.

```elixir
GottaSnatchEmAll.add_card("Scientuna", MapSet.new(["Newthree"]))
# => {false, MapSet.new(["Newthree", "Scientuna"])}
```

## 3. Inizia a scambiare

Ora che i tuoi amici sono di nuovo pazzi per i Blorkemon™️, puoi approfittarne per far crescere la tua collezione scambiando carte.

Non tutti gli scambi valgono la pena, né sono sempre possibili.
Non puoi scambiare una carta che non hai, e non dovresti scambiare una carta con una che possiedi già.

Implementa `GottaSnatchEmAll.trade_card`, che prende due carte da scambiare (la tua e la loro) e la tua collezione attuale.
Il valore restituito è una tupla di due valori: un booleano che indica se lo scambio è possibile e vale la pena, e la collezione che ti ritroveresti facendolo (anche se in realtà non è possibile).

```elixir
GottaSnatchEmAll.trade_card("Scientuna", "Newthree", MapSet.new(["Scientuna"]))
# => {true, MapSet.new(["Newthree"])}
```

## 4. Ce ne può essere solo una per tipo

Trovi una vecchia scorta di carte a un mercatino delle pulci.
Devi ordinare le carte ed eliminare i duplicati per confrontare la lista con la tua collezione.

Implementa `GottaSnatchEmAll.remove_duplicates`, che ordina una lista di carte e restituisce una lista di carte uniche e ordinate.

```elixir
GottaSnatchEmAll.remove_duplicates(["Newthree", "Newthree", "Newthree", "Scientuna"])
# => ["Newthree", "Scientuna"]
```

## 5. Le carte che non hanno

È il momento di essere soddisfatto della tua collezione.

Implementa `GottaSnatchEmAll.extra_cards`, che prende la tua collezione ed un'altra collezione e restituisce il numero di carte che l'altra collezione non ha.

```elixir
GottaSnatchEmAll.extra_cards(MapSet.new(["Scientuna"]), MapSet.new(["Newthree", "Scientuna"]))
# => 0
```

## 6. Le carte che hanno tutti

Tu ed i tuoi amici appassionati di Blorkemon™️ vi riunite e vi chiedete quali carte siano le più comuni.

Implementa `GottaSnatchEmAll.boring_cards`, che prende una lista di collezioni e restituisce una lista ordinata delle carte che tutte le collezioni hanno.

```elixir
GottaSnatchEmAll.boring_cards([MapSet.new(["Scientuna"]), MapSet.new(["Newthree", "Scientuna"])])
# => ["Scientuna"]
```

## 7. Tutte le carte

Tu ed i tuoi amici possedete collettivamente tutte le carte Blorkemon™️?

Implementa `GottaSnatchEmAll.total_cards`, che prende una lista di collezioni e restituisce il numero totale di carte diverse presenti in tutte le collezioni.

```elixir
GottaSnatchEmAll.total_cards([MapSet.new(["Scientuna"]), MapSet.new(["Newthree", "Scientuna"])])
# => 2
```

## 8. Le carte luccicanti per vincere

Tuo nipote verrà presto a trovarti e ti va di fargli una bella impressione.
Ai bambini piacciono le cose luccicanti, no?
Le carte Blorkemon™️ possono essere luccicanti!

Implementa `GottaSnatchEmAll.split_shiny_cards`, che prende una collezione e restituisce una tupla con due liste di carte ordinate: una con tutte le carte che iniziano con `"Shiny"` ed una con le altre carte.

```elixir
GottaSnatchEmAll.split_shiny_cards(MapSet.new(["Newthree", "Scientuna", "Shiny Scientuna"]))
# => {["Shiny Scientuna"], ["Newthree", "Scientuna"]}
```
