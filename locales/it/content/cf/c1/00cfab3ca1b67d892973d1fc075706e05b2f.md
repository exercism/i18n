# Introduzione

## Funzioni con più clausole

Elixir favorisce le pratiche del **principio Open-Closed** permettendo alle funzioni di avere più clausole: invece di una logica di controllo dispersiva e codificata a mano, si possono scrivere funzioni mirate che aggiungono o rimuovono comportamenti con facilità.

Elixir offre le _clausole multiple di funzione_ e le _guardie_ per scrivere:

```elixir
def number(n) when n == 7 do
  "Awesome, that's my favorite"
end

def number(_n) do
  "That's not my favorite"
end
```

In fase di esecuzione, Elixir verifica, dall'alto verso il basso del file sorgente, quale clausola di funzione chiamare.

Le variabili non utilizzate vanno precedute da un underscore.

## Guardie

Le guardie impediscono a Elixir di chiamare una funzione in base a come le funzioni di guardia valutano gli argomenti. Le guardie iniziano con la parola chiave `when`, seguita da un'espressione booleana. Le funzioni di guardia sono funzioni speciali che:

- Devono essere pure e non modificare alcuno stato globale.
- Devono restituire valori strettamente `true` o `false`.

Un elenco delle guardie più comuni si trova nella [documentazione di Elixir][kernel-guards]. Include controlli di tipo, aritmetica di base, confronti e operatori strettamente booleani.

## Argomenti predefiniti

Le funzioni possono dichiarare valori predefiniti per uno o più argomenti. Consideriamo questa funzione:

```elixir
def number(n \\ 13), do: "That's not my favorite"
```

Al momento della compilazione, Elixir crea una definizione di funzione per `number/0` (nessun argomento) e per `number/1` (un argomento).

Se più di un argomento ha valori predefiniti, questi vengono applicati alla funzione da sinistra a destra per coprire gli argomenti mancanti.

Se la funzione ha più di una clausola, gli argomenti predefiniti vanno definiti in un'intestazione di funzione (una funzione senza corpo) prima delle clausole della funzione:

```elixir
def number(n \\ 13)
def number(n) when n < 10, do: "Dream bigger!"
def number(n) when n > 100, do: "Not that big..."
```
