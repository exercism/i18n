# Introduzione

Una funzione ti permette di raggruppare il codice in un'unità riutilizzabile.
È composta dalla parola chiave `func`, dal nome della funzione e da un elenco separato da virgole di zero o più parametri e tipi tra parentesi tonde.

## Parametri di una funzione

Tutti i parametri devono avere un tipo esplicito: non c'è inferenza di tipo per i parametri.
Non ci sono valori predefiniti per i parametri, quindi tutti i parametri di una funzione sono obbligatori.

```go
import "fmt"

// No parameters
func PrintHello() {
    fmt.Println("Hello")
}

// One parameter
func PrintHelloName(name string) {
  fmt.Println("Hello " + name)
}
```

I parametri dello stesso tipo possono essere dichiarati insieme, seguiti da un'unica dichiarazione di tipo.

```go
import "fmt"

func PrintGreetingName(greeting, name string) {
  fmt.Println(greeting + " " + name)
}
```

## Parametri e argomenti

Vediamo rapidamente due termini che vengono spesso confusi tra loro: `parameters` e `arguments`.
I parametri di una funzione sono i nomi definiti nella firma della funzione, come `greeting` e `name` nella funzione `PrintGreetingName` qui sopra.
Gli argomenti di una funzione sono i valori concreti passati ai parametri della funzione quando la chiamiamo.
Per esempio, nell'esempio qui sotto, `"Hello"` e `"Katrina"` sono gli argomenti passati ai parametri `greeting` e `name`:

```go
PrintGreetingName("Hello", "Katrina")
```

## Valori restituiti

Ai parametri della funzione seguono zero o più valori restituiti, che devono anch'essi avere un tipo esplicito.
I valori restituiti singoli si lasciano senza parentesi, mentre più valori restituiti vengono racchiusi tra parentesi.
I valori vengono restituiti al codice chiamante dalle funzioni usando la parola chiave `return`.
In una funzione possono esserci più istruzioni `return`.
L'esecuzione della funzione termina non appena incontra una di queste istruzioni `return`.
Se una funzione deve restituire più valori, questi sono separati da virgole.

```go
func Hello(name string) string {
  return "Hello " + name
}

func HelloAndGoodbye(name string) (string, string) {
  return "Hello " + name, "Goodbye " + name
}
```

## Chiamare le funzioni

Per chiamare una funzione basta indicare il nome della funzione e passare un argomento per ciascuno dei suoi parametri tra parentesi.

```go
import "fmt"

// No parameters, no return value
func PrintHello() {
    fmt.Println("Hello")
}
// Called like this:
PrintHello()

// One parameter, one return value
func Hello(name string) string {
  return "Hello " + name
}
// Called like this:
greeting := Hello("Dave")

// Multiple parameters, multiple return values
func SumAndMultiply(a, b int) (int, int) {
    return a+b, a*b
}
// Called like this:
aplusb, atimesb := SumAndMultiply(a, b)
```

## Valori restituiti con nome e «naked return»

Oltre ai parametri, si può scegliere di dare un nome anche ai valori restituiti.
Se si usano valori restituiti con nome, un'istruzione `return` senza argomenti restituirà quei valori.
Questo è noto come «naked return».

```go
func SumAndMultiplyThenMinus(a, b, c int) (sum, mult int) {
    sum, mult = a+b, a*b
    sum -= c
    mult -= c
    return
}
```
