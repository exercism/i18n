# Introduzione

Uno degli obiettivi principali di Julia è poter eseguire calcoli su dati numerici in modo rapido ed efficiente.
_Molti_ dati numerici.

Di solito i dati vengono memorizzati in array (o in qualche tipo correlato), quindi si può ben dire che gli array sono al cuore del linguaggio Julia.

Gli array possono avere dimensioni arbitrarie (limitate solo dalla memoria disponibile nell'hardware) e possono avere un numero arbitrario di dimensioni.

Questo concetto introduttivo si concentra sulle basi degli array monodimensionali, che vengono chiamati Vector.

## Creare i Vector

In Julia, un Vector è una sequenza ordinata di valori a cui si può accedere tramite un indice numerico.

Il modo più semplice per creare un Vector è elencare i valori tra parentesi quadre:

```julia-repl
julia> num_vec = [1, 4, 9]
3-element Vector{Int64}:
 1
 4
 9

julia> str_vec = ["arrays", "are", "important"]
3-element Vector{String}:
 "arrays"
 "are"
 "important"
```

Il tipo di un Vector coincide con il tipo dei suoi elementi.

_Quindi i Vector devono essere omogenei (tutti gli elementi dello stesso tipo)?_

A un certo livello, sì, ed è consigliabile puntarci se vuoi ottenere le prestazioni migliori.
Tuttavia, Julia può aggirare questo limite (quando necessario) usando il tipo `Any`:

```julia-repl
julia> mixed_vector = [1, "str", 'c']
3-element Vector{Any}:
 1
  "str"
  'c': ASCII/Unicode U+0063 (category Ll: Letter, lowercase)
```

Quando si crea un Vector vuoto, Julia usa per impostazione predefinita il tipo di elemento `Any`, ma lo si può definire in modo più specifico annotando l'array vuoto con il tipo di elemento desiderato.

```julia-repl
julia> empty_vec = []
Any[]

julia> empty_int_vec = Int64[]
Int64[]
```

# Indicizzazione

Leggi e ricorda questa regola:

- ***Per impostazione predefinita, l'indicizzazione in Julia inizia da 1, non da 0***.

Questo è familiare a chiunque abbia usato altri linguaggi di data science (R, Matlab, Fortran...), ma può sembrare scioccante agli informatici con un background in linguaggi simili al C.

A parte questo, gli indici funzionano come potresti immaginare: basta metterli tra parentesi quadre:

```julia
squares = [0, 1, 4, 9, 16]
squares[1]  # 0
squares[3]  # 4
squares[begin]  # 0 ("begin" is synonym for 1)
squares[end]  # 16 ("end" is synonym for length(squares))
```

Nota la comodità di indicizzare con `end` (molto utile) e con `begin` (che probabilmente non lo è).

Chi programma in Python potrebbe chiedersi come funzionano gli indici negativi.
In realtà no: non fanno parte di Julia e sollevano un `BoundsError`, come qualsiasi indice minore di 1 o maggiore di `length(squares)`.

## Operazioni sui Vector

I Vector in Julia sono _mutabili_: possiamo modificare il contenuto delle singole celle.

```julia-repl
julia> vals = [1, 3, 5, 7]
4-element Vector{Int64}:
 1
 3
 5
 7

julia> vals[2] = 4  # reassign the value of this element
4

# Only the value at position 2 changes:
julia> vals
4-element Vector{Int64}:
 1
 4
 5
 7
```

Esistono molte funzioni per manipolare i vettori, anche se la documentazione di Julia le generalizza a «collezioni» anziché a Vector.

Nota che, per convenzione, le funzioni che modificano il proprio input hanno un `!` nel nome.
Il compilatore non lo impone, ma nel mondo Julia è una convenzione molto _forte_.

Queste sono alcune delle funzioni più utili:

- Per aggiungere valori in fondo al vettore, usa `push!()`.
- Per rimuovere l'ultimo valore, usa `pop!()`.
- Per agire sull'inizio del vettore, le funzioni corrispondenti sono `pushfirst!()` e `popfirst!()`.
- Per inserire o rimuovere un elemento in una posizione qualsiasi, ci sono `insert!()` e `deleteat!()`.

```julia-repl
julia> vals = [1, 3]
2-element Vector{Int64}:
 1
 3

julia> push!(vals, 5, 6)  # can add multiple values
4-element Vector{Int64}:
 1
 3
 5
 6

julia> pop!(vals)  # mutates vals, return popped value
6

julia> vals
3-element Vector{Int64}:
 1
 3
 5
```
