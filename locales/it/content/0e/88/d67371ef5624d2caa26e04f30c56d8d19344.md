# Suggerimenti

Usare i numeri complessi per le rotazioni in 2D può rendere il codice molto più pulito e numericamente più preciso.

## 1. Costruire un numero complesso a partire dalle coordinate cartesiane

- Il metodo integrato [`complex(x, y)`][complex] è più efficiente che assegnare `x + im*y`.
- Dai un'occhiata all'introduzione per un ripasso.

## 2. Costruire un numero complesso a partire dalle coordinate polari

- Ci sono alcuni modi equivalenti per farlo (ad esempio `exp`, `cis`, `cispi`).
- Consulta l'introduzione e le istruzioni per un ulteriore ripasso.

## 3. Eseguire la rotazione di un vettore in 2D

- La [formula di Eulero][euler] è un'ottima alleata qui: potresti usare la funzione `euler`.
- Esistono metodi per ottenere la parte [reale][real] e la parte [immaginaria][imaginary] di un numero complesso, oppure entrambe!

## 4. Eseguire uno spostamento radiale

- La funzione `euler` può essere utile, oppure no...
- Il metodo integrato [`angle`][angle] può essere usato per trovare rapidamente un argomento a partire da un numero complesso.
- Il metodo [`abs`][abs] può essere usato per trovare il modulo di un numero complesso.

## 5. Trovare la canzone desiderata

- Questa è una buona occasione per comporre le funzioni `rotate` e `rdisplace`.
