# Informazioni

Un [ciclo `for`][for-statement] permette di eseguire ripetutamente del codice in un ciclo finché non viene soddisfatta una condizione.

```csharp
for (int i = 0; i < 5; i++)
{
    System.Console.Write(i);
}

// => 01234
```

Un ciclo `for` è composto da quattro parti:

1. L'inizializzatore: viene eseguito una sola volta prima di entrare nel ciclo. Di solito serve a definire le variabili usate all'interno del ciclo.
2. La condizione: viene eseguita prima di ogni iterazione del ciclo. Il ciclo continua a essere eseguito finché il suo valore è `true`.
3. L'iteratore: viene eseguito dopo ogni iterazione del ciclo. Di solito serve a modificare (spesso incrementare o decrementare) le variabili del ciclo.
4. Il corpo: il codice che viene eseguito a ogni iterazione del ciclo.

## Cicli for e foreach

In generale i [concept:csharp/foreach-loops]() sono preferibili ai cicli `for` per i seguenti motivi:

- Un ciclo `foreach` ha la garanzia di iterare su _tutti_ i valori. Con un ciclo `for`, è facile saltare degli elementi, per esempio a causa di un errore off-by-one.
- Un ciclo `foreach` è più _dichiarativo_: il codice comunica _cosa_ vuoi che faccia, invece di un ciclo `for` che comunica _come_ vuoi farlo.
- Un ciclo `foreach` è a prova di errore, mentre con i cicli `for` è facile commettere un errore off-by-one.
- Un ciclo `foreach` funziona con tutti i tipi di collezione, compresi quelli che non supportano l'uso di un indicizzatore per accedere agli elementi.

Per garantire che un ciclo `foreach` iteri su _tutti_ i valori, il compilatore non permette di modificare una collezione all'interno di un ciclo `foreach`:

```csharp
char[] vowels = new [] { 'a', 'e', 'i', 'o', 'u' };

foreach (char vowel in vowels)
{
    // This would result in a compiler error
    // vowel = 'Y';
}
```

Un ciclo `for` ha però alcuni vantaggi rispetto a un ciclo `foreach`:

- Puoi iniziare o fermarti all'indice che vuoi.
- Puoi usare qualsiasi condizione di terminazione (booleana) desideri.
- Puoi saltare degli elementi personalizzando l'incremento della variabile del ciclo.
- Puoi elaborare le collezioni dall'ultimo al primo elemento contando alla rovescia.
- Puoi usare i cicli `for` in scenari che non coinvolgono collezioni.
