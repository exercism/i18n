# Introduzione

I singoli caratteri di una `String` sono accessibili usando il metodo di indicizzazione che si usa con gli array.
Tuttavia, gli [indici][string-indices] utilizzati per le stringhe _non_ sono numeri interi e non possono essere usati direttamente.
Vanno invece calcolati a partire da un altro indice noto, come `startIndex`, che punta alla posizione del primo carattere di una stringa non vuota, usando i metodi disponibili nelle librerie [`String`][string-docs] e [`NSString`][nsstring-docs] (quando il modulo `Foundation` è importato, le stringhe in Swift hanno accesso a tutte le proprietà e i metodi di NSString).

Ad esempio, data la stringa seguente:

```swift
let csv = "apple,pear,peach,orange,cherry,lime,goosberry"
```

Non si può scrivere `csv[21]` per ottenere la «g» in «orange»: bisogna invece calcolare un valore di tipo `String.Index` e fornire quell'indice.
Nota che questi indici non sono pensati per essere comprensibili agli esseri umani da soli.
Sono quelli che vengono chiamati _indici opachi_, dato che non c'è bisogno di sapere cosa contengono.

```swift
let index = csv.index(csv.startIndex, offsetBy: 21)
csv[index]
// "g"
print(index)
// prints Index(_rawBits: 1376513)
```

Nota, però, che se l'offset non è un indice valido, cioè se restituirebbe l'indice prima di `startIndex` o dopo `endIndex`, l'operazione solleverà un errore, facendo crashare il programma.
Per evitare questo problema, si può specificare un indice limite.
In questo caso viene restituito un indice opzionale, che sarà nil per gli indici altrimenti non validi.

```swift
let tooFar = csv.index(csv.startIndex, offsetBy: 200)
// error: Execution was interrupted, reason: EXC_BAD_INSTRUCTION (code=EXC_I386_INVOP, subcode=0x0).
let tooFarButSafe = csv.index(csv.startIndex, offsetBy: 200, limitedBy: csv.endIndex)
// nil
```

Inoltre, gli indici non possono essere condivisi tra stringhe.
Ad esempio, usare l'`index` della «g» in «orange» calcolato sopra per indicizzare la stringa `fam = "This is my family: 👨‍👩‍👦‍👦, this is our dog: 🐶, this is our cat: 🐱!"`, cioè `fam[index]`, farà crashare il programma.

Ci sono molte ragioni per tutto questo, ma in sostanza si riducono tutte a «Unicode è complicato».

In generale, se hai bisogno di accedere in modo casuale ai singoli caratteri, probabilmente dovresti usare un'altra struttura dati, come `Array<Character>`.

## Alcuni metodi utili

Swift ha i metodi `first` e `last` per ottenere il primo e l'ultimo carattere di una stringa.
Questi metodi restituiscono un carattere opzionale, quindi se la stringa è vuota restituiranno nil.

```swift
let str = "Hello, world!"
print(str.first) // Prints Optional("H")
print(str.last)  // Prints Optional("!")
```

Puoi anche usare i metodi `prefix` e `suffix` per ottenere una sottostringa di una stringa.
Questi metodi accettano un numero intero come argomento e restituiscono una sottostringa contenente i primi o gli ultimi n caratteri della stringa.

```swift
let str = "Hello, world!"
print(str.prefix(5)) // Prints "Hello"
print(str.suffix(6)) // Prints "world!"
```
