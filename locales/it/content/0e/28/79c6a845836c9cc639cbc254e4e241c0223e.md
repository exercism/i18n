# Introduzione

I namespace sono un modo per raggruppare codice correlato ed evitare conflitti di nomi, e sono presenti praticamente in ogni base di codice, tranne quelle più banali.

La sintassi è la seguente:

```csharp
namespace MyNameSpace
{
    public class MyClass {}

    public class OtherClass {}
}
```

I tipi racchiusi nei namespace, al di fuori dello scope del namespace, si indicano anteponendo al nome del tipo la sintassi con il punto. In alternativa, e più comunemente, puoi inserire una direttiva `using` in cima al file (o all'interno di un namespace) e usare il tipo senza il prefisso. All'interno dello stesso namespace non è necessario qualificare i nomi dei tipi.

```csharp
namespace MySpace
{
    public class MyClass {}

    public class Foo
    {
        public void Bar()
        {
            var baz = new MyClass();
        }
    }
}

public class Qux
{
    public void Box()
    {
        var nux = new MySpace.MyClass();
    }
}

namespace OtherSpace
{
    using MySpace;

    public class Tix
    {
        public void Jeg()
        {
            var lor = new MyClass();
        }
    }
}
```

Puoi dare un alias a un namespace con la sintassi `using MyAlias = MySpace;` e successivamente usare l'alias ovunque si possa usare il namespace.
