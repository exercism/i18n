# Introduzione

Un `Map` serve a memorizzare coppie di **chiave** e **valore**. I `Maps` si inizializzano proprio come un array, ma usano l'operatore `=>` del letterale di map. Si può anche definire esplicitamente il tipo delle chiavi e dei valori, oppure lasciare che i tipi vengano inferiti. Le chiavi devono essere uniche, altrimenti viene lanciato un errore.

```haxe
var map1:Map<Int, String> = [1 => "one", 2 => "two", 3 => "three"];

var map2 = ["one" => 1, "two" => 2, "three" => 3];

var map3 = [1 => "cat", 1 => "dog"]; // Error: Duplicate Key

var map4 = ["h" => "Hello", "b" => "Bye"];
trace(map4["h"]); // Hello
```

Un `Map` può essere iterato con un ciclo `for`. Puoi iterare sui valori oppure sulle chiavi:

```haxe
for (value in map) {
  // ...
}

for (key in map.keys()) {
  // ...
}
```
