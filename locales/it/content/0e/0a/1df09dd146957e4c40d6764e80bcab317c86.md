# Introduzione

Una *tupla* raggruppa diversi valori con un nome in un unico oggetto: quello che altri linguaggi chiamano record, struct o classe. Ogni classe di tupla ha un insieme fisso di slot con un nome, e Factor genera automaticamente i getter e i setter corrispondenti.

## Definire una tupla

```factor
TUPLE: point
    { x initial: 0 }
    { y initial: 0 } ;
```

Ogni slot si dichiara con `{ name initial: default-value }`. Senza una clausola `initial:` il valore predefinito è `f`.

## Costruire una tupla

Il costruttore più semplice è `new`:

```factor
point new .
! => T{ point }
```

`boa` («by order of arguments») riempie gli slot nell'ordine in cui sono dichiarati, prendendo i valori dalla pila dei dati:

```factor
3 4 point boa .
! => T{ point { x 3 } { y 4 } }
```

La sintassi letterale `T{ class { slot value } … }` permette di costruire una tupla impostandone solo una parte degli slot, e si stampa allo stesso modo:

```factor
T{ point { x 3 } } .
! => T{ point { x 3 } }
```

Quando il valore di uno slot coincide con il suo valore predefinito, la stampa lo omette.

## Leggere uno slot

Factor genera un getter `slot>>` per ogni slot. I getter si trovano in [`accessors`][accessors]:

```factor
T{ point { x 3 } { y 4 } } x>> .
! => 3
```

## Aggiornare uno slot

I setter si scrivono `>>slot` e *mutano* la tupla sul posto:

```factor
T{ point { x 3 } { y 4 } } 10 >>x .
! => T{ point { x 10 } { y 4 } }
```

Per lasciare intatto l'originale, fai prima un `clone`:

```factor
: shifted ( pt -- pt' )
    clone 10 >>x ;
```

`change-slot` prende una quotation che trasforma il valore attuale in quello nuovo:

```factor
: shift-x ( pt dx -- pt )
    [ + ] curry change-x ;
```

Anche `change-x` muta la tupla, quindi fai un `clone` prima di chiamarla se vuoi conservare l'originale.
