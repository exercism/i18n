# Type juggling

Il type juggling è noto anche come coercizione dei tipi.
Si ha type juggling quando due valori di tipi diversi vengono convertiti allo stesso tipo per eseguire un'operazione.

```php
$baskets = 5 // int
$apples_per_basket = "3" // string
$baskets * $apples_per_basket
# => 15
```

Questo può avvenire in modo implicito (vedi l'esempio qui sopra), oppure in modo esplicito con il cast dei tipi in stile `C`:

```php
$apples_per_basket = "3" // string
$my_number = (int) $apples_per_basket // cast string to int
# => 3 // int
```

I tipi ammessi per il cast manuale sono: `bool`, `int`, `float`, `string`, `array`, `object`.
Il più delle volte il cast dei tipi si usa per trasformare un numero intero (`int`) in un numero in virgola mobile (`float`) o viceversa.
