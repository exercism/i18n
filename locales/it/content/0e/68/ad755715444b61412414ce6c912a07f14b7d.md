# Introduzione

Gli operatori ternari permettono di definire condizioni if all'interno di espressioni invece che in blocchi di istruzioni. Questo richiama gli approcci della programmazione funzionale e spesso può rendere il codice più espressivo e meno soggetto a errori.

L'operatore ternario combina 3 espressioni: una condizione seguita da un'espressione che viene valutata e restituita se la condizione è vera (la parte `if`, introdotta da `?`) e un'espressione che viene valutata e restituita se la condizione è falsa (la parte `else`, introdotta da `:`).

```csharp
int a = 3, b = 4;
int max = a > b ? a : b;
// => 4
```
