# Informazioni

Un numero in virgola mobile è un numero con zero o più cifre dopo il separatore decimale.
Alcuni esempi sono `4.0`, `0.1`, `3.14`, `-6.4`, `16.984025` e `1024.0`.
In Ruby, i numeri in virgola mobile sono implementati tramite la classe [Float][Float].

Trovi una breve introduzione ai numeri in virgola mobile su [0.30000000000000004.com][0.30000000000000004.com].

La [pagina Float Toy][evanw.github.io-float-toy] offre una bella spiegazione grafica di come i bit di un numero in virgola mobile vengono convertiti in un valore effettivo in virgola mobile.

Per eseguire ripetutamente una logica, si possono usare i cicli.
In questo esempio il ciclo `while` è utile perché continua a ripetere _mentre_ una condizione assume un valore considerato vero (cioè non `false` né `nil`).
Ruby implementa un ciclo simile al ciclo `while`.
Si chiama ciclo `until`, e probabilmente hai già capito cosa fa.
Continua a ripetere il ciclo _finché_ una condizione booleana non è `true`.
In alcuni linguaggi, per far eseguire un pezzo di codice un numero illimitato di volte, si usano costrutti come `while true`.
In Ruby, per questo scopo esiste il ciclo `loop`.
Anche se il ciclo `loop` non dipende da una singola condizione, si può interrompere usando la parola chiave `return` o `break`.

Il metodo `#years_before_desired_balance` dell'esercizio precedente si sarebbe potuto scrivere usando uno qualsiasi dei tre cicli menzionati:

## `while`

```ruby
def self.years_before_desired_balance(current_balance, desired_balance)
  years = 0
  while current_balance < desired_balance
    current_balance = annual_balance_update(current_balance)
    years += 1
  end
  years
end
```

## `until`

```ruby
def self.years_before_desired_balance(current_balance, desired_balance)
  years = 0
  until current_balance >= desired_balance
    current_balance = annual_balance_update(current_balance)
    years += 1
  end
  years
end
```

## `loop`

```ruby
def self.years_before_desired_balance(current_balance, desired_balance)
  years = 0
  loop do
    current_balance = annual_balance_update(current_balance)
    years += 1
    return years if current_balance >= desired_balance
  end
end
```

Come avrai probabilmente notato, Ruby non ha un operatore di incremento (`i++`) come altri linguaggi.
Al suo posto, si possono usare costrutti come `i += 1` (equivalenti a `i = i + 1`).
