# Introduzione

In C#, una proprietà è un membro di una classe che fornisce l'accesso ai dati contenuti nella classe stessa.
Il codice chiamante può impostare o recuperare (get) questi dati. Le proprietà possono essere auto-implementate oppure avere un campo di supporto. Comprendono una funzione di accesso set e/o una funzione di accesso get.
In altri linguaggi, un «mutator» è più o meno equivalente a una funzione di accesso set e un «accessor» è più o meno equivalente a una funzione di accesso get, anche se la sintassi è strutturata in modo del tutto diverso.

Quando si imposta una proprietà, il valore di input può essere validato, formattato o altrimenti elaborato. In effetti, si può eseguire qualsiasi operazione programmatica accessibile al codice della classe.

Allo stesso modo, quando si recupera una proprietà i dati possono essere calcolati o formattati e, anche in questo caso, si può eseguire qualsiasi operazione programmatica disponibile per la classe.

Le proprietà hanno modificatori di accesso (`public`, `private` ecc.) come qualsiasi altro membro della classe, ma la funzione di accesso set può avere un livello di accesso indipendente da quella get (recupero) e viceversa. Una proprietà non deve necessariamente avere entrambe le funzioni di accesso: può averne solo una (get oppure set).

La sintassi di base per esprimere le proprietà può assumere due forme:

## Proprietà supportate da un campo o da un'espressione:

```csharp
private int myField;
public int MyProperty
{
    get { return myField; }
    set { myField = value; }
}
```

## Proprietà auto-implementate

```
public int MyProperty { get; private set; } = 42;
```

L'inizializzazione è facoltativa.
