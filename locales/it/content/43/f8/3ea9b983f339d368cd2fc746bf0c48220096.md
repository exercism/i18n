## Nuovi concetti di AWK

Consulta le [istruzioni dell'esercizio `matrix`][ex-matrix] per ripassare alcune interessanti funzionalità del linguaggio GNU awk.

### Chiamata dinamica di funzioni

Le funzioni awk non sono oggetti di prima classe: non si possono passare in giro come accade in altri linguaggi.
Tuttavia, una variabile può contenere il _nome_ di una funzione (una stringa), e la funzione viene chiamata con una notazione speciale, `@varname(args)`.
Un esempio:

```awk
function greet(name) {
    print "Hello, " name
}
BEGIN {
    greet("John")       # => "Hello, John"

    f = "greet"
    f("Bill")           # => error
    @f("Bill")          # => "Hello, Bill"
}
```
Questo meccanismo è descritto in [Chiamate indirette di funzioni][indirect].
Si tratta di un'estensione di `gawk`.
