# Puntatori intelligenti

I puntatori intelligenti in Cairo sono uno strumento potente che offre una gestione della memoria sicura ed efficiente.

Un puntatore intelligente è una struttura dati che si comporta come un puntatore normale, ma con funzionalità di sicurezza aggiuntive per evitare i problemi più comuni nella gestione della memoria, come dereferenziare un puntatore nullo o accedere a memoria non inizializzata.

## Che cos'è un puntatore intelligente?

In generale, un puntatore è una variabile che memorizza un indirizzo di memoria e in genere punta a un valore memorizzato in quella posizione.

Tuttavia, i puntatori grezzi possono essere pericolosi: se il puntatore non punta a memoria valida o viene dereferenziato in modo scorretto, può causare crash o comportamenti imprevedibili.

I puntatori intelligenti risolvono questo problema applicando regole rigide alla gestione della memoria, assicurando che vi si acceda in modo sicuro e controllato.

Cairo, come molti linguaggi moderni tra cui Rust, usa i puntatori intelligenti per impedire accessi non sicuri alla memoria.

Un puntatore intelligente in Cairo non si limita a memorizzare un indirizzo di memoria: tiene anche traccia della proprietà e garantisce la sicurezza della memoria.

## I tipi di puntatori intelligenti in Cairo

Cairo mette a disposizione diversi tipi di puntatori intelligenti, tra cui `Box<T>` e `Nullable<T>`, ognuno con uno scopo diverso.

Vediamo più da vicino come funzionano questi tipi e quando potresti usarli.

### `Box<T>`

Il tipo `Box<T>` è il principale puntatore intelligente in Cairo.

Ti permette di memorizzare dati in un segmento di memoria speciale chiamato «boxed segment». Un `Box<T>` è un puntatore che punta a questo segmento e, quando crei un box, riservi spazio per i dati proprio lì.

I box sono ideali nelle situazioni in cui:

- devi memorizzare un valore di un tipo la cui dimensione non può essere determinata in fase di compilazione.
- hai una grande quantità di dati e vuoi trasferirne la proprietà senza copiarli.

Usando un box, puoi memorizzare strutture dati di grandi dimensioni in modo più efficiente.

Quando passi un `Box<T>` a una funzione, viene passato solo il puntatore: si evita così di copiare tutti i dati, con un miglioramento delle prestazioni, soprattutto con strutture di grandi dimensioni.

### `Nullable<T>`

Il tipo `Nullable<T>` è un altro importante puntatore intelligente in Cairo.

Può puntare a un valore valido di tipo `T` oppure essere `null` se non c'è alcun valore.

Questo tipo è utile quando devi memorizzare valori che non sempre esistono, come in un dizionario che può contenere elementi opzionali.

In Cairo, `Nullable<T>` si usa di solito nei dizionari per gestire i casi in cui non è possibile applicare un valore predefinito.

Ti permette di memorizzare valori in modo condizionale, il che rende più semplice gestire in sicurezza l'assenza di dati.

## La sicurezza della memoria con i puntatori intelligenti

Uno dei principali vantaggi dei puntatori intelligenti è che aiutano a garantire la sicurezza della memoria.

Gestendo le regole di proprietà e di accesso, Cairo previene problemi comuni come la dereferenziazione di puntatori nulli o pendenti.

I puntatori intelligenti tengono traccia di quando i dati non servono più e possono deallocare automaticamente la memoria quando esce dallo scope, riducendo il rischio di perdite di memoria.

### Esempio: usare un `Box<T>` per i tipi ricorsivi

Una sfida comune in molti linguaggi di programmazione è gestire i tipi ricorsivi.

I tipi ricorsivi sono tipi che contengono riferimenti a se stessi.

Senza una gestione adeguata della memoria, definire un tipo ricorsivo può portare a problemi come la ricorsione infinita.

In Cairo, `Box<T>` permette di definire i tipi ricorsivi in modo sicuro.

Per esempio, puoi usare `Box<T>` per implementare un albero binario, in cui ogni nodo contiene un riferimento a un altro nodo.

Memorizzando i riferimenti nei box, Cairo garantisce che l'uso della memoria sia finito e il compilatore può determinare la dimensione di memoria richiesta per la struttura.

```rust
use core::box::{BoxTrait};

#[derive(Copy, Drop)]
enum BinaryTree {
    Leaf: u32,
    Node: (u32, Box<BinaryTree>, Box<BinaryTree>),
}

fn main() {
    let leaf1 = BinaryTree::Leaf(1);
    let leaf2 = BinaryTree::Leaf(2);
    let node = BinaryTree::Node((3, BoxTrait::new(leaf1), BoxTrait::new(leaf2)));
    println!("{:?}", node);
}
```

### I vantaggi in termini di prestazioni dei puntatori intelligenti

I puntatori intelligenti migliorano anche le prestazioni dei programmi che scrivi.

Quando usi `Box<T>`, viene passato in giro solo il puntatore ai dati, invece di copiare l'intera struttura dati.

È particolarmente utile quando si lavora con grandi quantità di dati, perché riduce in modo significativo il sovraccarico delle operazioni di memoria.

Nell'esempio seguente, i dati vengono passati per riferimento usando un `Box<T>` per evitare il costo della copia dell'intera struttura:

```rust
#[derive(Drop)]
struct Cart {
    paid: bool,
    items: u256,
    buyer: ByteArray,
}

fn pass_data(cart: Cart) {
    println!("{} is shopping today and bought {} items", cart.buyer, cart.items);
}

fn pass_pointer(cart: Box<Cart>) {
    let cart = cart.unbox();
    println!("{} is shopping today and bought {} items", cart.buyer, cart.items);
}

fn main() {
    let new_cart = Cart { paid: true, items: 1, buyer: "John" };
    pass_data(new_cart);

    let new_box = BoxTrait::new(Cart { paid: false, items: 3, buyer: "Jane" });
    pass_pointer(new_box);
}
```

In questo esempio, `pass_pointer` riceve un `Box<Cart>` invece di un `Cart`, riducendo la quantità di memoria copiata durante la chiamata alla funzione.
