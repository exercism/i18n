# Istruzioni

Una scuola locale vicino a te ha un'associazione studentesca molto attiva.
L'associazione studentesca è gestita da un presidente e ogni 2 anni si tengono le elezioni per eleggerne uno nuovo.
Per le elezioni di quest'anno si è deciso che serviva un nuovo sistema digitale per contare i voti.

La scuola ha bisogno del tuo aiuto per costruire questo nuovo sistema.

## 1. Crea un contatore di voti

Una delle prime cose di cui il nuovo sistema di voto ha bisogno è un contatore di voti.
Questo contatore serve a tenere traccia dei voti di un particolare candidato.

Crea una funzione `new_vote_counter` che accetta il numero di voti iniziali di un candidato e restituisce un'istantanea di una struct `VoteCounter`, inizializzata con il numero di voti iniziali indicato.

```rust
let initial_votes: u32 = 2;
let counter: @VoteCounter = new_vote_counter(initial_votes);
// @VoteCounter {
//     value: 2,
// }
```

## 2. Ottieni il numero di voti da un contatore

Ora hai un modo per creare nuovi contatori!
Ma adesso ti accorgi che il nuovo sistema avrà bisogno anche di un modo per ottenere il numero di voti da un contatore.

Crea una funzione `vote_count` che prende un contatore (`@VoteCounter`) come argomento e restituisce il numero di voti presenti nel contatore.

```rust
let initial_votes: u32 = 3;
let vote_counter: @VoteCounter = new_vote_counter(initial_votes);

let count = vote_count(vote_counter);
// => 3
```

## 3. Incrementa i voti di un contatore

È finalmente arrivato il momento di contare i voti!
Ora ti serve un modo per incrementare i voti in un contatore.

Crea una funzione `increment_vote_count` che prende come argomenti un contatore (`@VoteCounter`) e un numero di voti, e incrementa il contatore di quel numero di voti.

```rust
let votes: u32 = 3;
let vote_counter: @VoteCounter = new_vote_counter(initial_votes);
let vote_counter: VoteCounter = increment_vote_count(vote_counter, 2);

let count = vote_count(@vote_counter);
// => 5
```

## 4. Crea i risultati delle elezioni

Ora che tutti i voti sono stati contati, è il momento di preparare l'annuncio dei risultati per tutta la scuola.
Per farlo, ti accorgi che avere solo dei contatori per i voti non basta.
Serve un modo per associare il numero di voti a un particolare candidato.

Crea una funzione `new_election_result` che riceve il nome di un candidato e il suo numero di voti e restituisce un nuovo risultato elettorale.

```rust
let result: ElectionResult = new_election_result("Peter", 3);
// ElectionResult {
//     name: "Peter",
//     votes: @VoteCounter {
//         value: 3,
//     },
// }
```

La struct del risultato elettorale è già stata creata per te ed è definita così:

```rust
struct ElectionResult {
    name: ByteArray,
    counter: @VoteCounter,
}
```

## 5. Annuncia i risultati

È il momento di annunciare il nuovo presidente alla scuola!
Il nuovo presidente sarà annunciato nei piccoli tabelloni digitali di cui la scuola dispone.

Il messaggio deve mostrare il nome del nuovo presidente e i voti che ha ottenuto, nel formato seguente: `<candidate_name> (<votes>)`.
Questo è un esempio di tale messaggio: `"Peter (51)"`.

Crea una funzione `display_result` che riceve un `@ElectionResult` come argomento e restituisce un `ByteArray` con il messaggio da mostrare.

```rust
let result = ElectionResult {
    name: "John",
    votes: @VoteCounter {
        value: 32,
    },
};

let msg = display_result(@result);
// => "John (32)"
```

## 6. Riconteggio dei voti

Per assicurarsi che i risultati finali fossero accurati, i voti sono stati ricontati.
Durante il riconteggio si è scoperto che il numero di voti di alcuni candidati era sbagliato di uno.

Crea una funzione `decrement_votes_of_candidate` che riceve i risultati finali e il nome di un candidato di cui devi decrementare il numero di voti.
I risultati finali sono forniti sotto forma di un `Felt252Dict<u32>`, dove le chiavi sono i nomi dei candidati e i valori sono il totale dei loro voti.

```rust
let mut final_results: Felt252Dict<u32> = Default::default();
final_results.insert('Mary', 10);
final_results.insert('John', 51);

decrement_votes_of_candidate(ref final_results, 'Mary');

let decremented_votes = final_results.get('Mary');
// => 9
```
