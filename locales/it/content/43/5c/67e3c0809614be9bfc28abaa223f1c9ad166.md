# Installazione

## Installare Godot Engine

Il track GDScript è costruito su [Godot Engine][godot-engine], che funziona su Windows, Linux, macOS e Android.
Per il momento, il test runner per [lavorare in locale][working-locally] richiede Linux.
Questo track richiede Godot versione 4.0 o superiore.

Dopo aver completato l'installazione, puoi verificare che la CLI sia stata installata correttamente eseguendo questo comando in un terminale:

```bash
godot --version
```

## Installare il test runner del track GDScript di Exercism

Per usare il test runner, dovrai avere [Godot installato][installation] correttamente.

Per compilare e testare gli script GDScript per Exercism, Godot verrà eseguito in modalità "headless" dalla CLI.
Al momento queste istruzioni richiedono Linux e bash.

### Passo 1: installare l'infrastruttura complessiva del test runner

Per preparare l'ambiente ai test, clona [https://github.com/exercism/gdscript-test-runner][gdscript-test-runner] e sposta il suo contenuto in `/opt/test-runner/`:

```sh
git clone https://github.com/exercism/gdscript-test-runner.git
sudo mv gdscript-test-runner/ /opt/test-runner/
```

### Passo 2: scaricare lo script del test runner per il singolo esercizio

Supponendo che tu abbia configurato lo strumento `exercism` e scaricato almeno un esercizio GDScript, questo dovrebbe aver creato una cartella `gdscript` nella tua area di lavoro (come mostra l'esecuzione di `exercism configure`) per contenere gli esercizi.
Salva [il test runner][test-local-gdscript-solution] in questa cartella e rendi il file eseguibile.

## Eseguire i test

Una volta completati i passaggi di installazione, puoi partire da qualsiasi cartella di esercizio (ad esempio `~/exercism/gdscript/two-fer`) ed eseguire lo script (che si trova un livello sopra, in `../`) per testare la soluzione locale di quell'esercizio:

```sh
../test-local-gdscript-solution.sh
```

[gdscript-test-runner]: https://github.com/exercism/gdscript-test-runner

## Usare un IDE

Per avere l'evidenziazione della sintassi GDScript in un editor come [Visual Studio Code][vscode], dovrai installare un'estensione come [godot-tools][godot-tools] e avere un server di debug in esecuzione.
Godot avvia questo server di debug automaticamente ogni volta che un progetto è aperto nel suo editor e lo mantiene in esecuzione finché il progetto, o Godot stesso, non viene chiuso.
