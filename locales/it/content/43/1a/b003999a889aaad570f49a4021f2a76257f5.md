# Test

Se hai il binario di 8th nel tuo PATH, digita il comando:

```bash
8th -f test.8th
```

Se il binario di 8th non è nel PATH, in Windows digita

```cmd
\path\to\8th -f test.8th
```

Linux o macOS:

```bash
/path/to/8th -f test.8th
```

## Test nella REPL

Avvia 8th, caricando test-words.8th:

```sh
8th -f test-words.8th
```

Questo avvierà una sessione CLI in cui, dopo aver scritto del codice nel file della soluzione, potrai caricarlo nella REPL.
Ad esempio, per l'esercizio «Conteggio parole», digiteresti:

```8th
"word-count.8th" f:include
```

E puoi eseguire i test con

```sh
"word-count-tests.8th" f:include
```

Oppure puoi copiare e incollare un singolo test da quel file o inserirne uno tuo.

## Test saltati

Risolvere un esercizio significa far passare tutti i suoi test.
Per impostazione predefinita, quando esegui i test viene eseguito un solo test (il primo).
È intenzionale: ti permette di concentrarti solo sul far passare quel singolo test.
Una volta che passa, puoi abilitare il test successivo spostando la parola `SKIP-REST-OF-TESTS` dopo di esso.

## Ignorare i test saltati

Per eseguire tutti i test, compresi quelli dopo la parola `SKIP-REST-OF-TESTS`, puoi impostare la variabile d'ambiente `RUN_ALL_TESTS` al valore `true`.
Un modo per impostarla solo per la durata dell'esecuzione dei test è (macOS e Linux):

```bash
RUN_ALL_TESTS=true 8th -f test.8th
```
