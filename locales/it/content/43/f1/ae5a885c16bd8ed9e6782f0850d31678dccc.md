# Istruzioni

In questo esercizio, implementerai un modo per tenere traccia dei punteggi più alti del gioco più popolare della tua sala giochi.

Hai 7 funzioni da implementare, tutte legate alla restituzione e alla manipolazione di un dizionario di dati sui punteggi.

## 1. Definire un nuovo dizionario dei punteggi

Crea una funzione `newScoreBoard()` che non accetta parametri e restituisce un nuovo dizionario dei punteggi, che usa valori di tipo `String` per le chiavi e valori di tipo `Int` come valori.

## 2. Aggiungere giocatori al dizionario dei punteggi

Per aggiungere un giocatore al dizionario dei punteggi, definisci `addPlayer(_:_:_:)`, una funzione che accetta 3 parametri:

- Il primo parametro è il dizionario dei punteggi. 
    Deve essere un parametro in-out.
- Il secondo parametro è il nome di un giocatore, come stringa.
- Il terzo parametro è il punteggio, come numero intero. 
    Il parametro è opzionale: implementa il terzo parametro con un valore predefinito di 0.

```swift
var highScores = newScoreBoard()
addPlayer(&highScores, "Dave Thomas")
// Returns ["Dave Thomas": 0]
addPlayer(&highScores, "José Valim", 486_373)
// Returns ["Dave Thomas": 0, "José Valim": 486_373]
```

## 3. Rimuovere giocatori dal dizionario dei punteggi

Per rimuovere un giocatore dal dizionario dei punteggi, definisci `removePlayer(_:_:)`, che accetta 2 parametri:

- Il primo parametro è il dizionario dei punteggi. 
    Deve essere un parametro in-out.
- Il secondo parametro è il nome del giocatore, come stringa.

Questa funzione deve rimuovere il giocatore dal dizionario se è presente, altrimenti non deve fare nulla.

```swift
var highScores = ["Dave Thomas": 0, "José Valim": 486_373]
removePlayer(&highScores, "Dave Thomas")
// Returns ["José Valim": 486_373]
removePlayer(&highScores, "Rose Fanaras")
// Returns ["José Valim": 486_373]
```

## 4. Azzerare il punteggio di un giocatore

Per azzerare il punteggio di un giocatore, definisci `resetPlayer(_:_:)`, che accetta 2 parametri:

- Il primo parametro è il dizionario dei punteggi.
    Deve essere un parametro in-out.
- Il secondo parametro è il nome del giocatore, come stringa, il cui punteggio vuoi azzerare.

La funzione imposta a 0 il punteggio del giocatore. 
Se il giocatore non è nel dizionario, non deve succedere nulla.

```swift
var highScores = ["Dave Thomas": 486_373, "José Valim": 10]
resetScore(&highScores, "Dave Thomas")
// Returns ["Dave Thomas": 0, "José Valim": 10]
```

## 5. Aggiornare il punteggio di un giocatore

Per aggiornare il punteggio di un giocatore aggiungendolo al punteggio precedente, definisci `updateScore`, che accetta 3 parametri:

- Il primo parametro è il dizionario dei punteggi. Deve essere un parametro in-out.
- Il secondo parametro è il nome del giocatore, come stringa, il cui punteggio vuoi aggiornare.
- Il terzo parametro è il punteggio che vuoi **aggiungere** al punteggio più alto memorizzato.

```swift
var highScores = ["Dave Thomas": 0, "José Valim": 486_373]
addPlayer(&highScores, "Freyja Ćirić", 12_771_008)
updateScore(&highScores, "Freyja Ćirić", 73)
// Returns ["Dave Thomas": 0, "José Valim": 486_373, "Freyja Ćirić": 12_771_081]
```

## 6. Ottenere un elenco di giocatori con i punteggi ordinati per nome

Definisci la funzione `orderByPlayers`, che accetta 1 parametro:

- Il primo parametro è il dizionario dei punteggi.

La funzione restituisce un array di tuple `(String, Int)` che sono i giocatori e i loro punteggi più alti, ordinati in ordine crescente per nome del giocatore.

```swift
var highScores = ["Dave Thomas": 0, "José Valim": 486_373, "Freyja Ćirić": 12_771_091]
orderByPlayers(highScores)
// Returns [("Dave Thomas", 0), ("Freyja Ćirić", 12_771_091), ("José Valim", 486_373)]
```

## 7. Ottenere un elenco di giocatori ordinati per punteggio in ordine decrescente

Per ottenere un elenco di giocatori ordinati per punteggio in ordine decrescente, definisci `orderByScores`, che accetta 1 parametro:

- Il primo parametro è il dizionario dei punteggi.

La funzione restituisce un array di tuple `(String, Int)` che sono i giocatori e i loro punteggi più alti, ordinati in ordine decrescente per punteggio del giocatore.

```swift
var highScores = ["Dave Thomas": 0, "José Valim": 486_373, "Freyja Ćirić": 12_771_091]
orderByScores(highScores)
// Returns [("Freyja Ćirić", 12_771_091), ("José Valim", 486_373), ("Dave Thomas", 0)]
```
