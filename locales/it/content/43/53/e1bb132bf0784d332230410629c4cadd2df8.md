# Istruzioni

Stampa i numeri da 1 a n con le seguenti regole:

1. Quando il numero è un multiplo di 3, stampa "Fizz"
2. Quando il numero è un multiplo di 5, stampa "Buzz"
3. Quando il numero è un multiplo sia di 3 sia di 5, stampa "Fizz Buzz"
4. Quando il numero non è un multiplo di 3 né di 5, stampa il numero

L'output dovrebbe essere un vettore di stringhe, ad esempio: "1" "2" "Fizz" "4" "Buzz" ...
