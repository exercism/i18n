# Appendice alle istruzioni

## Registri

| Registro | Utilizzo     | Tipo      | Descrizione                        |
| -------- | ------------ | --------- | ---------------------------------- |
| `$a0`    | input        | indirizzo | stringa del nome terminata da null |
| `$a1`    | input        | intero    | numero                             |
| `$a2`    | input/output | indirizzo | stringa del risultato terminata da null |
| `$t0-9`  | temporaneo   | qualsiasi | per l'archiviazione temporanea     |
