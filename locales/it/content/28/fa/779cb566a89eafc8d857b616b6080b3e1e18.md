# Introduzione

In Ruby, gli **array** sono collezioni ordinate di qualsiasi oggetto, indicizzate tramite numeri interi.
L'indicizzazione degli array inizia da `0`.
Un indice negativo è considerato relativo alla fine dell'array, cioè un indice `-1` indica l'ultimo elemento dell'array, `-2` il penultimo, e così via.
Gli array di Ruby includono il [modulo Enumerable][enumerable-module], che aggiunge diversi metodi di attraversamento e di ricerca, oltre alla possibilità di ordinare.

## Creare un array

- Un array in Ruby può contenere oggetti di tipi diversi.

```ruby
array = [1, "two", 3.0] #=> [1, "two", 3.0]
```

## Assegnazione degli elementi

Gli elementi sono accessibili o modificabili tramite gli indici.
È possibile accedere a sotto-array specificando un indice di partenza e una dimensione.

```ruby
a = ["", "", "", "", ""]

a[4] = "hello"  #=> [nil, nil, nil, nil, "hello"]
a[0, 3] = [ 'a', 'b', 'c' ] #=> ["a", "b", "c", nil, "hello"]
```

- Gli indici negativi contano a ritroso dalla fine dell'array.

```ruby
a = ['a', 'b']

a[-1] = "Z"
a #=> ["a", "Z"]
```

## Riferimento agli elementi

- Gli elementi di un array possono essere recuperati tramite il metodo #[].
- Restituisce l'elemento all'indice indicato, oppure un sotto-array che parte dall'indice di partenza e continua per length elementi.

```ruby
a = [ "a", "b", "c", "d", "e" ]

a[2]    #=> "c"
a[6]    #=> nil
a[1, 2] #=> [ "b", "c" ]
```

- Gli indici negativi contano a ritroso dalla fine dell'array (-1 è l'ultimo elemento)

```ruby
a = [ "a", "b", "c", "d", "e" ]

a[-2]    #=> "d"
a[-3, 3] #=> [ "c", "d", "e" ]
```

## Ottenere informazioni su un array

Gli array tengono traccia della propria lunghezza in ogni momento.
Per sapere quanti elementi contiene un array, usa length, count o size.

```ruby
browsers = ['Chrome', 'Firefox', 'Safari', 'Opera', 'IE']
browsers.length #=> 5
browsers.count  #=> 5
browsers.size   #=> 5
```

## Aggiungere elementi a un array

Gli elementi possono essere aggiunti in fondo a un array usando `push` oppure `<<`:

```ruby
arr = [1, 2, 3, 4]
arr.push(5) #=> [1, 2, 3, 4, 5]
arr << 6    #=> [1, 2, 3, 4, 5, 6]
```

## Rimuovere elementi da un array

Il metodo pop rimuove l'ultimo elemento di un array e lo restituisce:

```ruby
arr = [1, 2, 3, 4, 5, 6]
arr.pop #=> 6
arr     #=> [1, 2, 3, 4, 5]
```
