# Istruzioni

In questo esercizio, giocherai a un gioco di ruolo chiamato _Wizards and Warriors_. Per giocare ti serve un metodo per lanciare i dadi adatto a qualsiasi evenienza, per determinare vari esiti. Sarà il tradizionale dado a 18 facce con i numeri da 1 a 18. I giocatori dovranno anche generare una forza dell'incantesimo casuale.

## 1. Consentire a un giocatore di _Wizards and Warriors_ di lanciare un dado

Implementa un metodo `RollDie()` sulla classe `Player`.

```csharp
var player = new Player();
player.RollDie();
// => >= 1 <= 18
```

## 2. I giocatori hanno bisogno della loro forza. Fornisci un modo per generare la forza dell'incantesimo

Implementa un metodo `GenerateSpellStrength()` sulla classe `Player`.
La forza dell'incantesimo è compresa tra 0.0 e 100.0, escluso quest'ultimo.

Nota che la forza dell'incantesimo deve essere un numero in virgola mobile (non un numero intero) per ridurre la possibilità di un pareggio quando si confrontano le forze di due avversari.

```csharp
var player = new Player();
player.GenerateSpellStrength();
// => >= 0.0 < 100.0
```
