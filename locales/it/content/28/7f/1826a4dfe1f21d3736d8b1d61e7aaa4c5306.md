# Informazioni

I booleani in Kotlin sono rappresentati dal tipo `Boolean`, i cui valori possono essere `true` o `false`.

Kotlin supporta tre [operatori booleani][reference] predefiniti: `!` (negazione, ovvero NOT), `&&` (congiunzione pigra, ovvero AND) e `||` (disgiunzione pigra, ovvero OR). Gli operatori `&&` e `||` usano la _valutazione a cortocircuito_, il che significa che il lato destro dell'operatore viene valutato solo quando serve.

```kotlin
true || false // => true
true && false // => false
```

I tre operatori booleani hanno ciascuno una diversa [_precedenza degli operatori_][precedence]. Di conseguenza, vengono valutati in questo ordine: prima `!`, poi `&&` e infine `||`. Se vuoi «aggirare» queste regole, puoi racchiudere un'espressione booleana tra parentesi tonde (`()`), dato che le parentesi hanno una precedenza degli operatori ancora più alta.

```kotlin
!true && false   // => false
!(true && false) // => true
```

[reference]: https://kotlinlang.org/docs/reference/basic-types.html#booleans
[precedence]: https://kotlinlang.org/docs/reference/grammar.html#expressions
