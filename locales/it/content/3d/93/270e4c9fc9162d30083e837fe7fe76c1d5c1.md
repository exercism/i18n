# Istruzioni

Sei un appassionato osservatore di uccelli che tiene traccia di quanti uccelli hanno visitato il tuo giardino negli ultimi sette giorni.

Hai cinque attività, che riguardano tutte il numero di uccelli che hanno visitato il tuo giardino.

## 1. Controlla quali erano i conteggi della settimana scorsa

Per fare confronti, tieni sempre a portata di mano una copia dei conteggi della settimana scorsa, che erano: 0, 2, 5, 3, 7, 8 e 4. Implementa il metodo `BirdCount.last_week` che restituisce i conteggi della settimana scorsa:

```ruby
BirdCount.last_week
# => [0, 2, 5, 3, 7, 8, 4]
```

## 2. Controlla quanti uccelli hanno visitato ieri il tuo giardino

Implementa il metodo `BirdCount#yesterday` perché restituisca quanti uccelli hanno visitato il tuo giardino ieri. I conteggi degli uccelli sono ordinati per giorno: il primo elemento è il conteggio del giorno meno recente, l'ultimo è il conteggio di oggi.

```ruby
birds_per_day = [2, 5, 0, 7, 4, 1]
bird_count = BirdCount.new(birds_per_day)
bird_count.yesterday
# => 4
```

## 3. Calcola il numero totale di uccelli in visita

Implementa il metodo `BirdCount#total` perché restituisca il numero totale di uccelli che hanno visitato il tuo giardino:

```ruby
birds_per_day = [2, 5, 0, 7, 4, 1]
bird_count = BirdCount.new(birds_per_day)
bird_count.total
# => 19
```

## 4. Calcola il numero di giorni intensi

Alcuni giorni sono più intensi di altri. Un giorno intenso è quello in cui cinque o più uccelli hanno visitato il tuo giardino.
Implementa il metodo `BirdCount#busy_days` perché restituisca il numero di giorni intensi:

```ruby
birds_per_day = [2, 5, 0, 7, 4, 1]
bird_count = BirdCount.new(birds_per_day)
bird_count.busy_days
# => 2
```

## 5. Controlla se c'è stato un giorno senza uccelli in visita

Implementa il metodo `BirdCount#day_without_birds?` che restituisce `true` se c'è stato un giorno in cui zero uccelli hanno visitato il giardino; altrimenti restituisce `false`:

```ruby
birds_per_day = [2, 5, 0, 7, 4, 1]
bird_count = BirdCount.new(birds_per_day)
bird_count.day_without_birds?
# => true
```
