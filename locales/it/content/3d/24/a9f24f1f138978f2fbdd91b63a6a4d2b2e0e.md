# Introduzione

## Le basi

In F#, assegnare un valore a un nome si chiama _associazione_. Le associazioni sono immutabili, il che le rende simili alle costanti di altri linguaggi. Poiché F# è un linguaggio tipizzato staticamente, ogni associazione ha un tipo in fase di compilazione.

Le associazioni si definiscono con la parola chiave `let`. Per la maggior parte delle associazioni specificare il tipo è facoltativo, perché di solito l'_inferenza dei tipi_ di F# riesce a dedurre il tipo dal loro valore. Un'associazione si presenta così:

```fsharp
// Automatically inferred type
let fingers = 10
```

Anche le funzioni sono normali associazioni, ma con uno o più parametri. Una funzione restituisce automaticamente la sua ultima espressione. L'inferenza dei tipi funziona anche per la maggior parte delle funzioni: analizza con quali valori la funzione viene chiamata e quale valore restituisce.

```fsharp
// Automatically inferred types for parameters and return type
let add x y = x + y
```

Per chiamare una funzione si specifica il suo nome e si passano gli argomenti per ciascuno dei suoi parametri.

```fsharp
let five = add 2 3
```

Se il tipo di un'associazione non può essere dedotto, il compilatore segnala un errore. Per risolvere, aggiungi un'annotazione di tipo esplicita all'associazione.

```fsharp
// Explicit type annotation
let fingers: int = 10

// Explicit type annotation (also for parameters)
let add (x: int) (y: int): int = x + y
```

In F#, le associazioni si possono usare solo _dopo_ averle definite. Usare un'associazione prima di averla definita provoca un errore di compilazione.

```fsharp
// Compile error as the add binding has not yet been defined
// let seven = add 3 4

let add x y = x + y
```

F# usa la spaziatura significativa per definire lo scope. Questo significa che lo scope è definito indentando il codice con degli spazi, rispetto alla riga che definisce l'associazione. La convenzione predefinita è usare quattro spazi per l'indentazione:

```fsharp
let toes =
    let left = 5
    let right = 5
    left + right

let multiplyPlusTwo x y =
    let product = x * y
    product + 2

// Trying to access the left, right or product bindings
// here would result in a compile error
```

Le associazioni di F# (comprese le funzioni) sono di solito organizzate in moduli. Un modulo raggruppa funzionalità correlate e si definisce con la parola chiave `module`. La definizione del modulo deve precedere le sue associazioni:

```fsharp
module Calculator

let pi = 3.14

let add x y = x + y
```

F# supporta due tipi di commenti. I commenti su una sola riga sono preceduti da `//`, mentre i commenti su più righe si inseriscono tra `(*` e `*)`.
