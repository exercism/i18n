# Introduzione


## Booleani

PowerShell ha il tipo [`bool`][booleans] per rappresentare i valori vero e falso.
In questo tipo ci sono solo due valori: `True` e `False`.
Puoi assegnare questi valori alle variabili con il prefisso `$`:

```powershell
> $TrueVar  = $true
> $FalseVar = $FALSE
#Case senstitivity doesn't matter here
```

Possiamo usare gli [operatori logici][logical-operators] come `-and`, `-or` e `-not` per combinare e valutare espressioni booleane.

```powershell
> $TrueVar  = $true -and $true
> $FalseVar = $true -and $false

> $TrueVar  = $true -or $false
> $FalseVar = $false -or $false

> $TrueVar  = -not $false
> $FalseVar = -not $true
```


## Guida basata sui commenti

[`Comment-based help`][comment-based help] in PowerShell serve a fornire informazioni dettagliate su funzioni e script scritti nei commenti.
Usa speciali parole chiave dei commenti di guida per specificare gli argomenti in evidenza, ad esempio `.SYNOPSIS`, `.EXAMPLE` o `.NOTES`.

```powershell
function ExampleFunction($Arg) {
    <#
    .DESCRIPTION
    A detailed description of the function or script. This keyword can be used only once in each topic.

    .PARAMETER Arg
    The description of a parameter, it must be follow with the parameter name.
    #>
}
```

Puoi visualizzare le informazioni della guida basata sui commenti usando il cmdlet `Get-Help`.

```powershell
> Get-Help -Name "ExampleFunction"
```
