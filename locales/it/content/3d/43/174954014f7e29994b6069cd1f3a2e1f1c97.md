# Imparare

Vim è già dotato di un'ottima documentazione integrata. L'interfaccia alla documentazione è il comando `:help`.

Per un'introduzione, vedi `:h user-manual`.

Quasi tutte le installazioni di Vim includono anche un tutorial interattivo:

```
$ vimtutor
```

Vim ha decenni di vita ed è ancora popolare. Sul web troverai tantissime risorse, alcune migliori di altre. Quelle buone sono elencate [qui](https://exercism.org/docs/tracks/vimscript/resources).
