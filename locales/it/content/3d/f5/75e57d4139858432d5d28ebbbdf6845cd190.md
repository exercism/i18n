# Introduzione

Haxe supporta la riflessione a runtime di tipi e campi. Per usare correttamente la riflessione, è necessario capire quali tipi di operazioni sono supportate e quali no. Data la natura dinamica della riflessione, questo non è sempre determinabile in fase di compilazione.

L'API di riflessione è composta da due classi:

- `Reflect`: un'API leggera che funziona al meglio con le strutture anonime, con un supporto limitato per le classi.
- `Type`: un'API più robusta per lavorare con classi ed enum.

Per il seguente esempio, useremo il target JavaScript:

```haxe
class Main {
  public static function main() {
    trace(Type.resolveClass("Main"));
  }
}

// This outputs
// class Test { static main() { console.log("Test.hx:3:",$hxClasses["Test"]); } }
```
