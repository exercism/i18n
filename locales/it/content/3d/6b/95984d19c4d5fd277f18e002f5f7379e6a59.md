# Appendice alle istruzioni

## Pacchetti Tcl

Questo è il primo esercizio a includere un pacchetto già scritto.
Nota la presenza del file `pkgIndex.tcl` e l'inclusione della directory corrente nella variabile `auto_path`.
Queste permettono al comando `package require` di trovare il file sorgente del pacchetto.

Questo non è un pacchetto particolarmente ben scritto: è solo del codice preso in prestito da varie fonti.
La chiamata `interp alias` serve a nascondere i difetti e a rendere più facile usare il pacchetto permutations.

Riferimenti:
* [`auto_path`](http://www.tcl-lang.org/man/tcl8.6/TclCmd/tclvars.htm)
* [`package`](http://www.tcl-lang.org/man/tcl8.6/TclCmd/package.htm)
* [`pkg_mkIndex`](http://www.tcl-lang.org/man/tcl8.6/TclCmd/pkgMkIndex.htm)
