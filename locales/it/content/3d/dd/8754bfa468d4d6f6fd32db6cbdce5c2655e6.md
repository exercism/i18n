# Istruzioni

Il taccuino di un detective si riempie mentre un caso va avanti e si svuota di nuovo quando delle piste vengono escluse.

Tutti e cinque i compiti vanno nella classe `CASE_NOTES`.

## 1. Apri un caso

Restituisci un taccuino nuovo e vuoto.

```sather
notes ::= CASE_NOTES::new_case;
notes.size
-- => 0
```

## 2. Annota un indizio

Aggiungi un indizio in fondo al taccuino. Non restituisce nulla: modifica il taccuino che riceve.

```sather
CASE_NOTES::add_clue(notes, "muddy boots");
notes.size
-- => 1
```

## 3. Quanti indizi?

```sather
CASE_NOTES::clue_count(notes)
-- => 1
```

## 4. Escludine uno

Prendi l'indizio che si trova in una certa posizione e rimuovilo dal taccuino. Tutti quelli che vengono dopo risalgono. Anche in questo caso non restituisce nulla.

```sather
CASE_NOTES::rule_out(notes, 0);
```

## 5. Rileggi il caso

Restituisci tutti gli indizi del taccuino, uniti con `"; "`. Un taccuino vuoto dà come risultato la stringa vuota.

```sather
CASE_NOTES::summary(notes)
-- => "muddy boots; broken window"
```
