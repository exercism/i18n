# Test

## clojure.test

Babashka viene distribuito insieme a clojure.test. Quando sei pronto a lavorare su un esercizio e hai creato un file in cui inserire la soluzione (come `bob.clj`), puoi eseguire i test usando `clojure.test/run-tests` [come descritto qui](http://clojure.github.io/clojure/clojure.test-api.html#clojure.test/run-tests).


Il REPL ti permette di eseguire il codice facilmente e di ricevere un feedback immediato. Puoi anche usarlo per eseguire i test. Si consiglia di usare `rlwrap` per abilitare la modifica della riga e la cronologia dei comandi con le frecce su e giù. Per testare un esercizio, spostati nella sua directory e apri un socket REPL aggiungendo le directory `src` e `test` al classpath:
``` bash
/bob $ rlwrap bb --classpath src:test socket-repl 1666
```

Per prima cosa, fai il `require` del namespace di test:
``` clojure
=> (require 'bob-test)
nil
```

Poi chiama `run-tests` su `bob-test`:
``` clojure
=> (clojure.test/run-tests 'bob-test)

Testing bob-test

Ran 25 tests containing 25 assertions.
0 failures, 0 errors.
{:test 25, :pass 25, :fail 0, :error 0, :type :summary}
```

Per creare uno script che esegue i test:

``` clojure
#!/usr/bin/env bb

(require '[clojure.test :as t]
         '[babashka.classpath :as cp])

(cp/add-classpath "src:test")                        

(require 'bob-test)                  

(def test-results
  (t/run-tests 'bob-test))           

(def failures-and-errors
  (let [{:keys [:fail :error]} test-results]
    (+ fail error)))                                 

(System/exit failures-and-errors)
```
