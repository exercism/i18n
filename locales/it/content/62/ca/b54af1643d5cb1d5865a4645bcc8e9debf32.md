# Introduzione

## With

La [forma speciale with][with] permette di concentrarsi sul «happy path» di una serie di passaggi che potrebbero fallire e di gestire i fallimenti in un secondo momento.

```elixir
with {:ok, id} <- get_id(username),
     {:ok, avatar} <- fetch_avatar(id),
     {:ok, image_type} <- check_valid_image_type(avatar) do
  {:ok, image_type, avatar}
else
  :not_found ->
    {:error, "invalid username"}

  {:error, "not an image"} ->
    {:error, "avatar associated to #{username} is not an image"}

  err ->
    err
end
```

A ogni passo, se una clausola corrisponde, la catena continua finché non viene eseguito il blocco `do`. Se una corrispondenza fallisce, la catena si ferma e viene restituita la clausola che non corrisponde. Hai la possibilità di usare un blocco `else` per intercettare le corrispondenze fallite e modificare il valore restituito.

[with]: https://hexdocs.pm/elixir/Kernel.SpecialForms.html#with/1
