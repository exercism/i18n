# Istruzioni

In questo esercizio implementerai una serie parziale di routine di utilità per aiutare uno sviluppatore a ripulire i nomi degli identificatori.
Nelle 5 attività costruirai gradualmente la routine `Clean`.
Un identificatore valido è composto da zero o più lettere e caratteri di sottolineatura.
In tutti i casi, è garantito che la stringa di input non sia nulla.
Se alla funzione `Clean` viene passata una stringa vuota, deve essere restituita una stringa vuota.
Nota che chi chiama dovrebbe evitare di chiamare la routine `Clean` con un identificatore vuoto, dato che tali identificatori sono inefficaci.

## 1. Sostituisci tutti gli spazi incontrati con caratteri di sottolineatura

Implementa il metodo (_static_) `Identifier.Clean()` per sostituire tutti gli spazi con caratteri di sottolineatura.
Questo vale anche per gli spazi iniziali e finali.

```csharp
Identifier.Clean("my   Id");
// => "my___Id"
```

## 2. Sostituisci i caratteri di controllo con la stringa maiuscola "CTRL"

Modifica il metodo (_static_) `Identifier.Clean()` per sostituire i caratteri di controllo con la stringa maiuscola `"CTRL"`.

```csharp
Identifier.Clean("my\0Id");
// => "myCTRLId",
```

## 3. Converti il kebab-case in camelCase

Modifica il metodo (_static_) `Identifier.Clean()` per convertire il kebab-case in camelCase.

```csharp
Identifier.Clean("à-ḃç");
// => "àḂç"
```

## 4. Ometti i caratteri che non sono lettere

Modifica il metodo (_static_) `Identifier.Clean()` per omettere tutti i caratteri che non sono lettere.

```csharp
Identifier.Clean("1😀2😀3😀");
// => ""
```

## 5. Ometti le lettere greche minuscole

Modifica il metodo (_static_) `Identifier.Clean()` per omettere tutte le lettere greche nell'intervallo da 'α' a 'ω'.

```csharp
Identifier.Clean("MyΟβιεγτFinder");
// => "MyΟFinder"
```
