# PowerShell

Automatizza tutto!
Scrivi script su qualsiasi sistema operativo per gestire file, processi, un data center o servizi cloud.
Esplora in modo interattivo dati strutturati come JSON, XML e CSV; lavora con qualsiasi interfaccia di gestione, dalle API web e CIM alle applicazioni a riga di comando.

# Informazioni su PowerShell

Linguaggio di scripting, shell e framework di gestione della configurazione .NET, open source e multipiattaforma, PowerShell aiuta i professionisti IT e gli utenti esperti a controllare e automatizzare praticamente qualsiasi cosa.

PowerShell si basa sul .NET Framework e trasforma il classico concetto di pipe di Unix, estendendolo dal semplice passaggio di flussi di testo o binari al supporto del passaggio di istanze di oggetti che includono informazioni sul tipo (ad esempio date e orari) e stati complessi con i loro dati strutturati.
Dove in una shell tradizionale potresti usare l'elaborazione del testo per estrarre informazioni specifiche dall'output di un comando, in PowerShell hai accesso a proprietà e metodi (compresi i modi per ispezionare gli oggetti e determinare quali proprietà e metodi sono disponibili).
Puoi lavorare con file CSV, convertire JSON in tabelle hash, navigare documenti XML e molto altro: questo rende facilmente componibili molte attività che con l'analisi del testo sarebbero difficili o poco pratiche.

PowerShell è estensibile.
Non solo tramite strumenti a riga di comando autonomi, come sono estensibili altre shell, ma tramite script, funzioni e cmdlet distribuiti in moduli che si integrano pienamente con il sistema di aiuto di PowerShell, l'editor a riga di comando con evidenziazione della sintassi, l'individuazione automatica dei parametri e il completamento tramite tab.
Puoi persino estendere la semplice sintassi esplorabile proprietà + contenuto del file system ad archivi dati come il registro di Windows e l'archivio dei certificati, SQL Server e persino Azure!

PowerShell include molte funzionalità aggiuntive:

- «Cmdlet» integrati per le comuni attività di amministrazione del sistema, come gestire file, servizi, processi e persino il registro di sistema, i log eventi e il Common Information Model (CIM), le richieste web e altro ancora.
- Compatibilità con script e strumenti a riga di comando esistenti.
- Interfacce estensibili e moduli e comandi facilmente individuabili.
- Accesso completo al .NET Framework ed estensibilità tramite assembly .NET da NuGet.
- Una ricca cronologia dei comandi con informazioni sul successo e sulla durata dell'esecuzione di un comando.
- Potenti capacità di manipolazione degli oggetti. Gli oggetti possono essere manipolati direttamente, serializzati e persino inviati ad altri strumenti o database.

La documentazione dettagliata su PowerShell, il linguaggio, i concetti fondamentali e le funzionalità è disponibile insieme ai programmi di installazione all'indirizzo https://docs.microsoft.com/en-us/powershell.
