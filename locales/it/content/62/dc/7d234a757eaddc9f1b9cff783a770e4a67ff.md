# Introduzione

## Casualità

Un'istanza della classe `java.util.Random` può essere usata per generare numeri casuali in Java.

### Numeri interi casuali

Un numero intero casuale può essere generato usando il metodo `nextInt()`.
Questo genera un valore nell'intervallo da `Integer.MIN_VALUE` a `Integer.MAX_VALUE`.

```java
Random random = new Random();

random.nextInt();
// => -1169335537
```

Per limitare l'intervallo dei valori generati, usa `nextInt(int)`.
Questo genera un valore nell'intervallo da `0` (incluso) al limite superiore indicato (escluso).

Per esempio, questo genera un numero casuale da `0` a `9`.

```java
Random random = new Random();

random.nextInt(10);
// => 6
```

E questo genera un numero casuale da `10` a `19`.

```java
Random random = new Random();

10 + random.nextInt(10);
// => 11
```

### Numeri in virgola mobile casuali

Un numero in virgola mobile casuale può essere generato usando il metodo `nextDouble()`.
Questo genera un valore nell'intervallo da `0.0` a `1.0`.

```java
Random random = new Random();

random.nextDouble();
// => 0.19250004204021398
```

E questo genera un numero casuale da `100.0` a `200.0`.

```java
Random random = new Random();

100.0 + 100.0 * random.nextDouble();
// => 111.31849856260328
```
