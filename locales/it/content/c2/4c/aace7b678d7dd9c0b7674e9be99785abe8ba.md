# Introduzione

Elixir è un linguaggio tipizzato dinamicamente, il che significa che non fornisce controlli dei tipi in fase di compilazione. Tuttavia, le specifiche di tipo possono essere usate come una forma di documentazione.

Una specifica di tipo può essere aggiunta a una funzione usando l'attributo di modulo `@spec` subito prima della definizione della funzione. A `@spec` seguono il nome della funzione e un elenco dei tipi di tutti i suoi argomenti, tra parentesi tonde, separati da virgole. Il tipo del valore restituito è separato dagli argomenti della funzione con un doppio due punti `::`.

```elixir
@spec longer_than?(String.t(), non_neg_integer()) :: boolean()
def longer_than?(string, length), do: String.length(string) > length
```

## Tipi

I tipi più comunemente usati includono:

- booleani: `boolean()`
- stringhe: `String.t()`
- numeri: `integer()`, `non_neg_integer()`, `pos_integer()`, `float()`
- liste: `list()`
- un valore di qualsiasi tipo: `any()`

Alcuni tipi possono anche essere parametrizzati, per esempio `list(integer)` è una lista di interi.

Anche i valori letterali possono essere usati come tipi.

Un'unione di tipi può essere scritta usando la barra verticale `|`. Per esempio, `integer() | :error` significa un intero oppure il valore letterale atomo `:error`.

Un elenco completo di tutti i tipi si trova nella sezione "Typespecs" della documentazione ufficiale.

## Dare un nome agli argomenti

Gli argomenti nella specifica di tipo possono anche avere un nome, cosa utile per distinguere più argomenti dello stesso tipo. Il nome dell'argomento, seguito da un doppio due punti, va prima del tipo dell'argomento.

```elixir
@spec to_hex({hue :: integer, saturation :: integer, lightness :: integer}) :: String.t()
```

## Tipi personalizzati

Le specifiche di tipo non si limitano ai tipi predefiniti. I tipi personalizzati possono essere definiti usando l'attributo di modulo `@type`. La definizione di un tipo personalizzato inizia con il nome del tipo, seguito da un doppio due punti e poi dal tipo stesso.

```elixir
@type color :: {hue :: integer, saturation :: integer, lightness :: integer}

@spec to_hex(color()) :: String.t()
```

Un tipo personalizzato può essere usato dallo stesso modulo in cui è definito, oppure da un altro modulo.
