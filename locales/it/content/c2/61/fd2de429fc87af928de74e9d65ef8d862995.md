# Test

Fai in modo che il primo test venga compilato, collegato e superato seguendo le [tre regole dello sviluppo guidato dai test][3-tdd-rules].

Il makefile incluso può essere usato per creare ed eseguire i test con il task `test`.

```console
$ make test
```

Crea solo le funzioni che ti servono per risolvere gli errori del compilatore e fai fallire il test.
Poi scrivi solo il codice sufficiente a far passare il test.
Quando hai finito, passa al test successivo.

Man mano che procedi con i test, prenditi il tempo di riorganizzare la tua implementazione per renderla più leggibile ed espressiva, poi passa al test successivo.

Prova a usare le funzionalità standard del C99 invece di scrivere a mano i tuoi algoritmi o strumenti di basso livello.

## Controllare le perdite di memoria

Il makefile include anche una build che controlla alcuni errori comuni riguardo alle perdite di memoria e agli accessi agli array fuori dai limiti.
Per eseguire questi controlli, usa il comando seguente dalla riga di comando:

```console
$ make memcheck
```
