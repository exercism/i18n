# Introduzione

Per iniziare il viaggio nel C++, partiamo dalle variabili, dalle chiamate di funzione e dai commenti.

## Commenti

I commenti esistono in due varianti: su una sola riga e su più righe.
Tutto ciò che segue `//` sulla stessa riga viene ignorato dal compilatore.
I commenti su più righe sono anche noti come commenti in stile C.
Sono delimitati da `/*` e `*/`.
Anche tutto ciò che si trova tra questi due viene ignorato.

## Variabili

Il C++ è un linguaggio tipizzato.
Tutti i tipi devono essere noti in fase di compilazione e, in genere, devi dichiararli esplicitamente.
Il tipo di una variabile non può cambiare.
Una variabile intera con il nome `years` si può dichiarare così:

```cpp
int years;
```

È buona pratica inizializzare le variabili al momento della dichiarazione.
Il C++ offre diversi meccanismi per farlo.
La versione con le parentesi graffe è più in linea con il C++ moderno, ma anche la versione con il segno di uguale è molto comune.

```cpp
int tomatoes{80};
int potatoes = 40;
```

~~~~exercism/caution
Il C++ permette di usare variabili non inizializzate.
Finché la variabile non viene impostata di proposito, il suo valore è indefinito e può contenere qualsiasi cosa.
Per evitare errori di uso prima dell'assegnazione e comportamenti indefiniti è consigliabile **inizializzare sempre**.
Il comportamento indefinito può far crashare il programma nel momento peggiore, dopo che fino a poco prima funzionava senza problemi.
Non lo si ripeterà mai abbastanza: evita il comportamento indefinito a ogni costo.
~~~~

## Operazioni aritmetiche

Gli operatori aritmetici come `*`, `+` o `-` possono far parte di un'espressione come `3 * 2` o `tomatoes + potatoes`.

## Aggiornare le variabili

Puoi riassegnare le variabili, purché mantengano il loro tipo:

```cpp
tomatoes = tomatoes - 5; // tomatoes is now 75
potatoes = (32 * 2) + 11; // potatoes is now 75 as well
```

## Funzioni

Le funzioni hanno un nome, un tipo restituito e un elenco di parametri (eventualmente vuoto).
Un esempio di funzione chiamata `always_fortyseven` che restituirebbe sempre 47 è questo:

```cpp
int always_fortyseven() {
    return 47;
}
```

Ecco `vip_fee`, che ha un parametro:
```cpp
int vip_fee(int standard_fee) {
    /*
    vip_fee calculates the vip fee based on the standard_fee.
    */
    int vip_multi{3};
    return standard_fee * vip_multi;
}
```

Oppure `total_fee`, una funzione con tre parametri e una chiamata a un'altra funzione.

```cpp
int total_fee(int vips, int adults, int kids) {
    /*
    total_fee calculates the total price for a group of VIP and adult guests with kids.
    Kids get a flat discount on the standard fee.
    VIP guest fees are calculated by calling vip_fee.
    */
    int standard_fee{30};
    int kids_discount{15};

    int kids_total_fee = kids  * (standard_fee - kids_discount);
    int vips_total_fee = vips * vip_fee(standard_fee);
    int adult_total_fee = adults * standard_fee;

    return vips_total_fee + adult_total_fee + kids_total_fee;
}
```

In C++, le funzioni non restituiscono il valore dell'ultima istruzione come in altri linguaggi.
La parola chiave `return` è necessaria perché il codice venga compilato.

### Spazi bianchi

Gli spazi bianchi servono a formattare il codice sorgente e comprendono spazi, tabulazioni e ritorni a capo.
Poiché il compilatore ignora gli spazi bianchi superflui, puoi usarli per strutturare il codice.
Un uso intelligente degli spazi bianchi può migliorare la leggibilità del codice.
Esistono diversi standard di formattazione, ma sono tutti convenzionali e non imposti dal compilatore.

```cpp
// Formatting makes it easier to find bugs

int eggs_yolks =  3;
int      yeast = 15;

int flour=500;int sugar=200;// compact, but difficult to read
```
