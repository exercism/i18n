# Installazione

Useremo *PolyML* come implementazione di Standard ML.

Se usi Windows, puoi scaricare un installer da [https://github.com/polyml/polyml/releases](https://github.com/polyml/polyml/releases).
Le istruzioni generali per Linux/OS X/Free BSD le trovi su [https://github.com/polyml/polyml#readme](https://github.com/polyml/polyml#readme).

Se vuoi installarlo dai sorgenti, la procedura è piuttosto semplice:

```sh
$ git clone https://github.com/polyml/polyml.git
$ cd polyml
$ ./configure
```

Se vuoi installarlo in una posizione personalizzata, per esempio `$HOME/.local`:

```sh
$ ./configure --prefix=$HOME/.local
```

Ultimo passaggio:

```sh
$ make compiler
$ make install
```

Verifica che l'installazione sia andata a buon fine:

```sh
$ poly
```

Se vedi l'interprete, sei pronto!
In caso contrario, probabilmente dovrai aggiungere `$HOME/.local/bin` (o `<you prefix>/bin`) al tuo `$PATH`.
