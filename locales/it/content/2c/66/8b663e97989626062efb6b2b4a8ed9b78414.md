# Istruzioni

Stai sviluppando un sistema per aiutare lo staff del sito web di un club di calcio a redigere i resoconti delle partite.
I dati vengono ricevuti da varie fonti e convogliati in un unico flusso dopo essere stati ripuliti.

## 1. Restituisci le descrizioni dei giocatori in base al loro numero di maglia

La squadra gioca sempre e solo con il modulo 4-3-3 e non ha mai accettato la modifica del 1965 alle regole che consente le sostituzioni, figuriamoci le rose allargate.

Le descrizioni dei giocatori sono le seguenti:

```text
1 -> "goalie"
2 -> "left back"
3 & 4 "center back"
5 -> "right back"
6, 7, & 8 -> "midfielder"
9 -> "left wing"
10 -> "striker"
11 -> "right wing"
```

Implementa il metodo statico `FootballMatchReports.onField()` per restituire la descrizione di un giocatore in base al suo numero di maglia.

```java
FootballMatchReports.onField(10);
// => "striker"
```

## 2. Restituisci "invalid" se il numero di maglia non fa parte dell'elenco ufficiale

Modifica il metodo `FootballMatchReports.onField()` in modo che restituisca 'invalid' quando viene elaborato un numero di maglia fuori dall'intervallo 1-11.

```java
FootballMatchReports.onField(13);
// => "invalid"
```
