# Appendice alle istruzioni

## Istruzioni specifiche del track

Il tuo compito è scrivere una funzione `nucleotideCounts` che prende in input una stringa e restituisce in output un array associativo che conta quante volte è presente ciascun nucleotide.
Se la stringa è una sequenza non valida, la funzione deve lanciare un `IllegalArgumentError` con il messaggio `Invalid nucleotide in strand`.
