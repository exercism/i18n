# Istruzioni

In questo esercizio, implementerai alcune regole del classico gioco Pac-Man.

Hai quattro regole da implementare, tutte legate agli stati del gioco.

## 1. Definisci se Pac-Man mangia un fantasma

Implementa una funzione che riceve come input se Pac-Man ha una pillola energetica attiva e se Pac-Man sta toccando un fantasma, e restituisce un valore booleano che indica se Pac-Man è in grado di mangiare il fantasma. La funzione deve restituire `true` solo se Pac-Man ha una pillola energetica attiva e sta toccando un fantasma.

```lua
rules.eat_ghost(false, true)
-- => false
```

## 2. Definisci se Pac-Man segna punti

Implementa una funzione che riceve come input se Pac-Man sta toccando una pillola energetica e se Pac-Man sta toccando un pallino, e restituisce un valore booleano che indica se Pac-Man ha segnato punti. La funzione deve restituire `true` se Pac-Man sta toccando una pillola energetica o un pallino.

```lua
rules.score(true, true)
-- => true
```

## 3. Definisci se Pac-Man perde

Implementa una funzione che riceve come input se Pac-Man ha una pillola energetica attiva e se Pac-Man sta toccando un fantasma, e restituisce un valore booleano che indica se Pac-Man perde. La funzione deve restituire `true` se Pac-Man sta toccando un fantasma e non ha una pillola energetica attiva.

```lua
rules.lose(false, true)
-- => true
```

## 4. Definisci se Pac-Man vince

Implementa una funzione che riceve come input se Pac-Man ha mangiato tutti i pallini, se Pac-Man ha una pillola energetica attiva e se Pac-Man sta toccando un fantasma, e restituisce un valore booleano che indica se Pac-Man vince. La funzione deve restituire `true` se Pac-Man ha mangiato tutti i pallini e non ha perso in base agli argomenti definiti nella parte 3.

```lua
rules.win(false, true, false)
-- => false
```
