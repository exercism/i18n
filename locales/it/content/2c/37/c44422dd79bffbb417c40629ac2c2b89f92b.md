# Suggerimenti

## Generali

- Le [tuple](https://docs.microsoft.com/en-us/dotnet/fsharp/language-reference/tuples) sono raggruppamenti immutabili di valori senza nome ma ordinati, possibilmente di tipi diversi.
- Gli elementi all'interno delle tuple si possono [ottenere](https://docs.microsoft.com/en-us/dotnet/fsharp/language-reference/tuples#obtaining-individual-values) tramite pattern matching, decostruzione della tupla o funzioni ausiliarie.

## 1. Estrarre le coordinate

- Ricorda: le tuple consentono l'accesso tramite funzioni ausiliarie o decostruzione.
- Consulta il [parsing](https://docs.microsoft.com/en-us/dotnet/api/system.int32.parse?view=net-5.0) per ottenere un numero da una stringa.

## 2. Formattare le coordinate

- Consulta gli [esempi](https://docs.microsoft.com/en-us/dotnet/fsharp/language-reference/tuples#examples) per maggiori dettagli sulla creazione delle tuple.
- Consulta lo [slicing delle stringhe](https://docs.microsoft.com/en-us/dotnet/fsharp/language-reference/strings#string-indexing-and-slicing) per maggiori dettagli sulle stringhe.

## 3. Abbinare le coordinate

- Quali operatori si potrebbero usare qui per [verificare l'appartenenza](https://docs.microsoft.com/en-us/dotnet/fsharp/language-reference/strings#string-indexing-and-slicing)?
- Potresti riutilizzare la funzione `convertCoordinate()`?

## 4. Combinare i record abbinati
