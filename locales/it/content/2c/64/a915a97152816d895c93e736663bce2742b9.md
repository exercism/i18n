# Introduzione

Un'estensione statica permette di pseudo-estendere i tipi esistenti senza modificarne il codice sorgente. Questo si ottiene utilizzando l'istruzione `using`. Le estensioni statiche possono essere uno strumento potente: permettono di ampliare i tipi senza modificarli davvero.

```haxe
using Main.IntExtender;

class Main {
  public static function main() {
    trace(2.triple()); // 6
  }
}

class IntExtender {
  public static function triple(i:Int):Int {
    return i * 3;
  }
}
```
