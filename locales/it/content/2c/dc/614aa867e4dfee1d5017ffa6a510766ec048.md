# Risorse

## Informazioni generali

* [La documentazione del linguaggio Unison](https://www.unison-lang.org/learn/fundamentals/values-and-functions/terms/) è un ottimo punto di partenza per imparare i concetti fondamentali di Unison
* [Unison Share](https://share.unison-lang.org/) è il repository dove ospitiamo le librerie pubbliche e il codice
* Puoi sempre fare domande nel [Discord di Unison](https://unison-lang.org/discord)
* [Il blog di Unison](https://www.unison-lang.org/blog/) contiene aggiornamenti sul linguaggio e argomenti speciali
* Un articolo sull'uso della [funzionalità Remote di Unison per implementare una libreria simile a Spark](https://www.unison-lang.org/articles/distributed-datasets/)
