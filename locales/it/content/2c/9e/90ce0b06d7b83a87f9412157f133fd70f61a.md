# Istruzioni case

Quando un valore viene confrontato con una lista di possibilità, una catena di
`elsif` ripete sempre la stessa cosa:

```sather
   if zone = 0 then
      return 0;
   elsif zone = 1 then
      return 550;
   elsif zone = 2 then
      return 370;
   else
      return 920;
   end;
```

`case` lo dice una volta sola:

```sather
   case zone
   when 0 then return 0;
   when 1 then return 550;
   when 2 then return 370;
   else return 920;
   end;
```

Il valore va dopo `case`. Ogni `when` fornisce un valore con cui confrontarlo, e viene eseguito il primo che corrisponde.

## Più valori in un solo when

Un `when` può elencare più valori, separati da virgole:

```sather
   case day
   when "Sat", "Sun" then return "Weekend";
   when "Mon", "Tue", "Wed", "Thu", "Fri" then return "Weekday";
   else return "Unknown";
   end;
```

Funziona con numeri interi, caratteri e stringhe: qualsiasi cosa che possa essere confrontata con `=`.

## L'else non è opzionale

**Un `case` che non corrisponde a nulla e non ha un `else` è un errore che blocca il programma nel momento in cui si verifica.**

È diverso da `if`, dove omettere l'`else` significa semplicemente che non succede nulla. È diverso anche dalla maggior parte dei linguaggi, dove un `case` senza corrispondenze non fa nulla, in silenzio.

Quindi ogni `case` ha bisogno di un `else`, anche quando sei sicuro che le parti `when` coprano già tutti i valori. Più avanti viene aggiunta una quarta zona, il `case` non viene aggiornato di conseguenza, e il programma si blocca sul primo passeggero che la usa.

## Viene eseguito un solo when

Quando un `when` corrisponde, vengono eseguite le istruzioni dopo il suo `then` e il `case` è concluso: il programma prosegue dopo l'`end`. Le parti `when` che stanno sotto non vengono mai esaminate, quindi non devi scrivere nulla per impedire che venga eseguita anche la successiva.
