# Attività

Le attività sono issue di GitHub su cui vorremmo che le persone dessero una mano, dalla correzione di bozze alla creazione di esercizi sui concetti.
Sono presentate sul sito e rimandano alle rispettive issue su GitHub.
Ogni attività è contrassegnata con una o più proprietà, che vengono ricavate dalle etichette della issue.
L'utente può quindi filtrare le attività in base alle loro proprietà.

## Tag

Perché una issue venga considerata un'attività, deve essere etichettata con una o più etichette specifiche per le attività.
I maintainer possono così scegliere di far comparire come attività solo alcune issue.

Ogni etichetta di attività è definita come `x:<type>/<value>` e sono supportati cinque tipi di attività:

- `action`
- `knowledge`
- `module`
- `size`
- `type`

### Tag action

Le etichette `x:action/<value>` descrivono il tipo di lavoro a cui il contributore si dedicherà quando lavora sulla issue.

| Tag                  | Descrizione                            |
| -------------------- | -------------------------------------- |
| `x:action/create`    | Lavorare su qualcosa da zero           |
| `x:action/fix`       | Correggere una issue                   |
| `x:action/improve`   | Migliorare funzionalità o contenuti esistenti |
| `x:action/proofread` | Correzione di bozze                    |
| `x:action/sync`      | Sincronizzare i contenuti con la loro versione più recente |

### Tag knowledge

Le etichette `x:knowledge/<value>` descrivono quanta conoscenza di Exercism è richiesta al contributore.

| Tag                        | Descrizione                                |
| -------------------------- | ------------------------------------------ |
| `x:knowledge/none`         | Non è richiesta alcuna conoscenza di Exercism |
| `x:knowledge/elementary`   | È richiesta poca conoscenza di Exercism    |
| `x:knowledge/intermediate` | È richiesta una discreta conoscenza di Exercism |
| `x:knowledge/advanced`     | È richiesta una conoscenza approfondita di Exercism |

### Tag module

Le etichette `x:module/<value>` indicano su quale parte di Exercism lavorerà il contributore.

| Tag                          | Descrizione                 |
| ---------------------------- | --------------------------- |
| `x:module/analyzer`          | Lavorare sugli analyzer     |
| `x:module/concept`           | Lavorare sui concetti       |
| `x:module/concept-exercise`  | Lavorare sugli esercizi sui concetti |
| `x:module/generator`         | Lavorare sui generatori di esercizi |
| `x:module/practice-exercise` | Lavorare sugli esercizi di pratica |
| `x:module/representer`       | Lavorare sui representer    |
| `x:module/test-runner`       | Lavorare sui test runner    |

### Tag size

Le etichette `x:size/<value>` descrivono la quantità di lavoro prevista per un contributore.

| Tag              | Descrizione            |
| ---------------- | ---------------------- |
| `x:size/tiny`    | Quantità minima di lavoro |
| `x:size/small`   | Quantità ridotta di lavoro |
| `x:size/medium`  | Quantità media di lavoro |
| `x:size/large`   | Quantità elevata di lavoro |
| `x:size/massive` | Quantità enorme di lavoro |

### Tag type

Le etichette `x:type/<value>` descrivono il tipo di lavoro a cui il contributore si dedicherà.

| Tag              | Descrizione                                                                                                                                                                                                    |
| ---------------- | -------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| `x:type/ci`      | Lavorare sull'integrazione continua (ad esempio i workflow di GitHub Actions)                                                                                                                                  |
| `x:type/coding`  | Scrivere codice che non fa parte dei contenuti rivolti agli studenti. Di norma si tratta di attività legate agli strumenti di produzione (ad esempio i test runner), agli strumenti interni (i generatori) o a librerie che Exercism mantiene. |
| `x:type/content` | Lavorare sui contenuti (ad esempio esercizi, concetti)                                                                                                                                                         |
| `x:type/docker`  | Lavorare sui Dockerfile                                                                                                                                                                                        |
| `x:type/docs`    | Lavorare sulla documentazione                                                                                                                                                                                  |

## Tag claimed e unclaimed

Per nascondere un'attività perché qualcuno ci sta già lavorando, una issue può aggiungere l'etichetta `x:status/claimed`.
