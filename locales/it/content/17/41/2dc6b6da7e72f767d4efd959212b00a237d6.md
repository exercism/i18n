# Istruzioni

Stai lavorando all'implementazione di un sistema di monitoraggio della salute. Come parte di questo, devi tenere traccia delle statistiche di salute degli utenti.

Inizierai con alcune funzioni abbozzate in un blocco `impl` e con la seguente definizione di struct:

```rust
pub struct User {
    name: String,
    age: u32,
    weight: f32,
}
```

Il tuo obiettivo è implementare i metodi abbozzati sullo `struct` `User` definito nel blocco `impl`.

Per esempio, il metodo `new` dovrebbe restituire un'istanza dello `struct` `User` con i valori specificati di nome, età e peso.

```rust
let mut bob = User::new(String::from("Bob"), 32, 155.2);
// Returns: a User with name "Bob", age 32, and weight 155.2
```

Il metodo `weight` dovrebbe restituire il peso dello `User`.

```rust
bob.weight();
// Returns: 155.2
```

Il metodo `set_age` dovrebbe impostare l'età dello `User`.

```rust
bob.set_age(33);
// Updates Bob's age to 33; happy birthday Bob!
```
