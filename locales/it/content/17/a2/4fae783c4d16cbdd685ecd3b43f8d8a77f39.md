# Istruzioni

Impara ad aggregare e raggruppare i dati all'interno di una tabella interna ABAP.


Alla classe verrà fornita una tabella interna chiamata `initial_numbers`.  Ha due colonne: `GROUP` e `NUMBER`.

```abap
TYPES: BEGIN OF initial_numbers_type,
        group  TYPE group,
        number TYPE i,
       END OF initial_numbers_type,
       initial_numbers TYPE STANDARD TABLE OF initial_numbers_type WITH EMPTY KEY.
```

I dati di questa tabella sono divisi in tre gruppi: A, B e C.  Ogni gruppo contiene più record.

| GROUP | NUMBER |
| --- | ----------- |
| A | 10 |
| B | 5 |
| A | 6 |
| C | 22 |
| A | 13 |
| C | 500 |

Il tuo compito è restituire una tabella interna con un record per ogni gruppo. Questo record deve contenere il numero di record della tabella originale per ogni gruppo (`COUNT`), la somma di tutti i valori di `NUMBER` del gruppo (`SUM`), il valore minimo del gruppo (`MIN`), il valore massimo del gruppo (`MAX`) e la media di tutti i valori del gruppo (`AVERAGE`).  

La tabella restituita attesa ha la seguente definizione:

```abap
TYPES: BEGIN OF aggregated_data_type,
        group   TYPE group,
        count   TYPE i,
        sum     TYPE i,
        min     TYPE i,
        max     TYPE i,
        average TYPE f,
       END OF aggregated_data_type,
       aggregated_data TYPE STANDARD TABLE OF aggregated_data_Type WITH EMPTY KEY.
```
