# Introduzione

La ricorsione è un modo per ripetere del codice all'interno di una funzione facendo sì che la funzione chiami se stessa.
Può essere vista come un altro modo per eseguire un ciclo o per iterare.
Come nei cicli, si usa un'espressione booleana o un test `True`/`False` per determinare quando fermare l'esecuzione ricorsiva.
_A differenza_ dei cicli, la ricorsione senza una condizione di terminazione in Python non può andare avanti all'infinito.
I valori usati in ogni chiamata di funzione vengono collocati in un [frame][stack-frame] tutto loro sullo [stack dell'interprete][what-is-the-call-stack] Python.
Se il numero totale di chiamate di funzione occupa più spazio di quanto lo stack possa contenerne, si verificherà un errore.

```python
def print_increment(step, max_value):
    if step > max_value:
        return
    print(f'The step is {step}')
    print_increment(step + 1, max_value)


def main():
    print_increment(1, 2)
    print("After recursion")

if __name__ == "__main__":
    main()

```

Questo stamperà

```
The step is 1
The step is 2
After recursion
```

Ci sono situazioni che risultano più leggibili e/o più facili da ragionare quando si esprimono con la ricorsione invece che con un ciclo.
