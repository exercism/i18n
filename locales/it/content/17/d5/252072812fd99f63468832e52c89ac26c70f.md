# Appendice alle istruzioni

## Implementazione

Puoi usare le funzionalità principali del linguaggio per costruire e decostruire gli array tramite la destrutturazione, e puoi usare il letterale di array `[]`, ma non devi usare nessuna funzione di `Array.prototype`.

Per poter testare la soluzione, assicurati che `forEach` sia implementato.

```typescript
const list = List.create(1, 2)
list.forEach((item) => console.log(item))
// =>
//    1
//    2
```
