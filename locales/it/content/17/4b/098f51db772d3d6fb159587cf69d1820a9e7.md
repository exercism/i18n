# Introduzione

La funzione `switch()` può essere un sostituto conciso per una lunga serie di controlli `if` ... `else if`.
La variabile su cui si effettua lo switch è quasi sempre una stringa e, in questo caso, puoi omettere le virgolette dal selettore.

```R
star <- function(type) {
  switch(type,
    M = , # will "fall through" if no value given
    K = "red dwarf",
    G = "Earth-like",
    "bigger star" # only correct for O,B,A,F
  )
}

> star("M")
[1] "red dwarf"
```

Nota che le opzioni passano a quella successiva solo se il valore viene lasciato vuoto, come per `M` nell'esempio qui sopra.
Non c'è bisogno di includere istruzioni `break`, come avviene in altri linguaggi.

Quando si effettua lo switch su tipi `character`, il valore finale è quello predefinito, come qui.
Con i tipi integer, invece, non si può indicare alcun valore predefinito.

## Le funzioni in `dplyr`

Lo `switch` di R base è piuttosto limitato: esegue solo una corrispondenza esatta con un singolo input.
Sembrava ragionevole quando R è stato rilasciato per la prima volta nel 1993, ma per l'uso moderno ha bisogno di miglioramenti.

~~~~exercism/note
Come accennato nel concetto [`Conditionals`][concept-conditionals], la raccolta di pacchetti `tidyverse` è pensata per integrare (e talvolta sostituire) le funzionalità di R base senza compromettere la retrocompatibilità.

Il pacchetto `dplyr` può essere portato nello scope aggiungendo `library(dplyr)` (per il singolo pacchetto) oppure `library(tidyverse)` (per l'intera raccolta) in cima al codice.

[concept-conditionals]: https://exercism.org/tracks/r/concepts/conditionals
~~~~

La libreria `dplyr` fornisce due funzioni aggiuntive legate a `switch`.

### Le funzioni `recode_values` e `replace_values`

Queste due funzioni correlate consentono una mappatura vettorizzata, simile a uno switch, dai vecchi valori ai nuovi valori.

La differenza principale tra loro è che `recode_values()` crea un vettore completamente nuovo, mentre `replace_values()` consente aggiornamenti parziali di un vettore esistente.

La corrispondenza è ancora esatta, ma:

- Le opzioni a sinistra possono essere vettori e l'input corrisponde se corrisponde uno qualsiasi dei suoi elementi.
- Le opzioni a sinistra e i risultati a destra si collegano con una tilde `~` invece che con `=`.
- In tutti i casi si può specificare un valore predefinito.

```R
library(dplyr)

x <- c("a", "b", "a", "d", "b", NA, "c", "e", "z")
recode_values(
  x,
  "a" ~ 1,
  "b" ~ 2,
  "c" ~ 3,
  c("d", "e") ~ 4, # either "d' or "e" will match
  NA ~ 0,          # matches missing values
  default = 100   # note the different syntax for the default
)
#> [1]   1   2   1   4   2   0   3   4 100
```

### La funzione `case_when`

`case_when` porta la sintassi di `case_match` un passo più avanti, consentendo qualsiasi espressione logica a sinistra della `~`.

Il vettore di input (`x` nell'esempio qui sotto) non viene passato come argomento: deve solo essere già definito.

```R
x <- 1:10
case_when(
  x < 3 ~ "low",
  between(x, 3, 5) ~ "mid",
  between(x, 6, 8) ~ "high",
  .default = "what?"
)
#>  [1] "low"   "low"   "mid"   "mid"   "mid"   "high"  "high"  "high"  "what?" "what?"
```

Anche la funzione `between()` fa parte di `dplyr`.
