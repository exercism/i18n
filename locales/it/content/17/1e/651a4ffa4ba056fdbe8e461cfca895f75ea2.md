# Introduzione

Una `string` in C++ è un oggetto mutabile che rappresenta del testo come una sequenza di caratteri (lettere, cifre, punteggiatura, ecc.).
Le stringhe si manipolano chiamando i metodi della stringa.

## La libreria delle stringhe

In C++, il tipo stringa e le funzioni associate vanno inclusi dalla libreria delle stringhe prima di poterli usare.
Per farlo, aggiungi `#include <string>` in cima al file.
Diventeranno così disponibili nel namespace `std`.
Il nome completo del tipo stringa è `std::string`.
Il letterale stringa usa il carattere delle virgolette doppie: `"`.

```cpp
#include <string>
std::string w_berry_quote{"A well-made sentence, I think, is a thing of beauty."};
```

## Operazioni comuni sulle stringhe

Puoi usare l'operatore `+` per concatenare le stringhe:

```cpp
std::string original_title{"The School of Rock"};
std::string sequel_indicator{"Electric Boogaloo"};
std::string next_movie_title = original_title + " 2: " + sequel_indicator;
```

Per usare la libreria delle stringhe, devi sapere che è possibile chiamare una funzione che appartiene a un oggetto.
Queste si chiamano funzioni membro.
Più avanti nel programma, imparerai di più sulle funzioni membro ed il concetto di classe a esse collegato.

```cpp
std::string qualification{"awesome"};
// 1st argument: from the index to the end of the string:
std::string who_is_awesome = qualification.substr(5);
// => "me"

// 2nd optional argument for the length:
std::string material{"haunted books"};
std::string ghost = material.substr(8, 3);
// => "boo"
```


Anche la funzione `find` è molto utile.
Viene chiamata come funzione membro sulla stringa ed accetta una stringa come argomento.
`find` restituisce la posizione, con indice che parte da zero, della _prima_ occorrenza nella stringa.

```cpp
std::string new_release{"apple released a new app!"};
new_release.find("app");
// => 0
new_release.find("e");
// => 4
```

C'è anche la funzione `std::to_string`, che si può usare per convertire numeri interi e valori in virgola mobile in una stringa.

```cpp
int num{92};
double exponent{0.92e2};
std::string msg{ std::to_string(num) + " can also be written as " + std::to_string(exponent)};
// => 92 can also be written as 92.0000000
```
