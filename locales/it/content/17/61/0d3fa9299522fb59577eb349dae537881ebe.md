# Istruzioni specifiche per SQLite

Le colonne **list_one** e **list_two** contengono un array di numeri interi codificato in JSON.

Esempio:

```json
[1, 2, 3]
```

## Schema della tabella

```sql
CREATE TABLE sublist (
    list_one TEXT NOT NULL,     -- json array
    list_two TEXT NOT NULL,     -- json array
    result   TEXT
);
```
