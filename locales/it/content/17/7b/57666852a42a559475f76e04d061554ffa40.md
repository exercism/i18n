# Istruzioni

La tua azienda è stata ingaggiata per generare record CSV a partire dall'input dell'utente.

Ci serve un builder per un record CSV secondo lo standard definito nella [RFC 4180](https://tools.ietf.org/html/rfc4180).

Anche se esiste una specifica formale, alla tua azienda serve implementare solo le funzionalità seguenti:
- creare un nuovo builder di record
- aggiungere un singolo campo al record
- serializzare il record con l'escape di base

Per escape di base si intende:

- I campi che contengono interruzioni di riga, virgolette doppie e virgole vanno racchiusi tra virgolette doppie.

- Se per racchiudere i campi si usano le virgolette doppie, allora una virgoletta doppia che compare all'interno di un campo deve essere sottoposta a escape facendola precedere da un'altra virgoletta doppia.


## 1. Crea un nuovo builder

Per creare un nuovo builder dovrai implementare il metodo `new`.

```rust
let mut builder = CsvRecordBuilder::new();
```

## 2. Aggiungi i singoli campi al record

Per aggiungere campi al tuo builder di record dovrai implementare il metodo `add`.
`add` prende come argomento delle slice di stringa immutabili, `&str`.

```rust
builder.add("ant");
builder.add("ba\"t");
builder.add("cat");
```


## 3. Serializza il record con l'escape di base

Dovrai implementare il metodo `build`.
`build` consuma il builder e restituisce un record CSV.
```rust
let record = builder.build();
// Note that from now on we cannot use `builder`
assert_eq!(&record, r#"ant,"ba""t",cat"#);
```
