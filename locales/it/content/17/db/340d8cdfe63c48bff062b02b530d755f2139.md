# Informazioni

Common Lisp mette a disposizione del programmatore diversi condizionali, che si possono classificare in base al numero di «rami» che supportano.

Inoltre, a differenza di molti altri linguaggi di programmazione, in Common Lisp tutti i condizionali sono _espressioni_, non istruzioni.
Questo significa che ogni condizionale Lisp si valuta in un valore e può essere usato al posto di un parametro concreto.

Un esempio:

```lisp
;; Doubles x when it's even
(* x (if (evenp x) 2 1))
```

## Condizionali a un ramo

I condizionali `when` e `unless` valutano del codice solo quando il test fornito è vero o falso, rispettivamente; in caso contrario si valutano in `nil`.

La sezione dopo l'espressione di test può contenere più di un'espressione.

```lisp
(when (= 2 2) "All is well")      ; => "All is well"
(unless (= 2 2) "Time to panic!") ; => NIL
```

## Il condizionale a due rami

Il condizionale `if` valuta la prima espressione del corpo quando il test è vero, la seconda altrimenti.

```lisp
(if (= 2 2) 'how-honest 'you-liar) ; => HOW-HONEST
```

Nota che sia la clausola then sia la clausola else possono contenere una sola espressione.

## Condizionali a molti rami

Il «super-condizionale» di Lisp è `cond`, che può avere un numero infinito di rami.
Ogni ramo ha una condizione di test e un'espressione di corpo racchiuse da una coppia extra di parentesi.
Se tutti i test risultano falsi, viene restituito `nil`.

```lisp
(cond ((= 0 2) 'nope)
      ((= 1 2) 'try-again)
      ((= 2 2) 'quite-true)
      ((= 3 2) 'too-far)
      (t 'something-else))
; => QUITE-TRUE
```

Nota che non c'è limite al numero di espressioni dopo l'espressione di test.


Se vuoi semplicemente verificare un valore rispetto a diversi rami, puoi usare l'espressione `case`, più pulita.
Se nessuno dei casi corrisponde, viene restituito `nil`.
Sia `t` sia `otherwise` possono essere usati come casi di default:

```lisp
(case 'elder-beast
  (cat "Meow")
  (bird "Chirp")
  (dog "Bark")
  (otherwise "???"))
; => "???"
```

Nota che, come in `cond`, non c'è limite al numero di espressioni dopo l'espressione di test.

## I condizionali nascosti

Le operazioni booleane `and` e `or` in Common Lisp sono macro con cortocircuito che si possono usare per ridurre la duplicazione di alcune espressioni condizionali.

La macro `and` restituisce immediatamente `nil` se incontra un solo valore falso, altrimenti restituisce l'ultimo valore vero:

```lisp
(and 42 "Magic" :cool) ; => :COOL
(and () "Magic" :cool) ; => NIL
```

La macro `or` restituisce il primo valore vero che incontra, oppure `nil` se non c'erano valori veri:

```lisp
(or () 42 nil)  ; => 42
(or () NIL nil) ; => NIL
```

## Sono esausto...

Come accennato in precedenza, quando nessuno dei rami di un'istruzione `case` corrisponde e non c'è una clausola `otherwise`, viene restituito `nil`.
A volte, però, la mancata corrispondenza con qualsiasi ramo dovrebbe essere trattata come un errore: ed è qui che entra in gioco `ecase` (per una corrispondenza **esaustiva**).

Si usa esattamente come `case`, ma segnala un errore invece di restituire `nil` quando non c'è corrispondenza.

```lisp
(case 'elder-beast
  (cat "Meow")
  (bird "Chirp")
  (dog "Bark"))
; => NIL

(ecase 'elder-beast
  (cat "Meow")
  (bird "Chirp")
  (dog "Bark"))
; => ERROR: ELDER-BEAST fell through ECASE expression. Wanted one of (CAT BIRD DOG).
```
