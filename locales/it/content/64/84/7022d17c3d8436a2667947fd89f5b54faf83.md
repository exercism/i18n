# Classi astratte

Uno spettacolo circense è una lista di numeri. Giocoleria, trapezio e acrobazie
sono cose diverse e ognuna funziona a modo suo, ma chi costruisce la scaletta
ha bisogno solo di due informazioni su ciascuna: come si chiama e quanto dura.

Una **classe astratta** descrive esattamente questo, e niente di più.

```sather
abstract class $ACT is
   name : STR;
   minutes : INT;
end; -- abstract class $ACT
```

Il suo nome inizia con `$`. Elenca routine senza corpo: solo le firme, ognuna
che termina con il punto e virgola. Da essa non si può creare nulla: non c'è
`create` né `new`.

## Conformità

Una classe reale promette di essere un `$ACT` nominandolo dopo `<`:

```sather
class JUGGLING < $ACT is

   create : SAME is return new; end;

   name : STR is return "Juggling"; end;

   minutes : INT is return 5; end;

end; -- class JUGGLING
```

`<` si legge «è un». La classe deve fornire ogni routine elencata dalla classe
astratta, con gli stessi argomenti e lo stesso tipo restituito. Ometterne una è
un errore di compilazione, non una sorpresa a runtime.

Una classe può aggiungere tutto quello che vuole. `TRAPEZE` può avere
un'altezza che nessun altro numero possiede; alla classe astratta questo non
interessa, né lo sa.

## Usare il tipo

`$ACT` è un tipo, quindi si può usare per dichiarare qualsiasi cosa:

```sather
   acts : ARRAY{$ACT} := |#JUGGLING, #TRAPEZE(4), #TUMBLING|;
```

Quell'array contiene contemporaneamente oggetti di tre classi diverse, cosa che
un `ARRAY{JUGGLING}` non potrebbe fare.

## Dispatch

```sather
   loop
      total := total + acts.elt!.minutes;
   end;
```

`acts.elt!` è un `$ACT`. Quale `minutes` venga eseguito si decide quando la riga
viene eseguita, da ciò che l'oggetto è realmente: `JUGGLING::minutes` per la
giocoleria, `TRAPEZE::minutes` per il trapezio. Questa scelta si chiama
**dispatch**.

La routine che fa la somma non chiede mai che tipo di numero ha davanti.
Aggiungere un quarto tipo di numero significa scrivere una nuova classe e non
cambiare nient'altro: è proprio questo il motivo per farlo in questo modo.
