# Istruzioni

Il tuo compito è convertire le descrizioni della data di consegna in date di consegna _effettive_, in base a quando è iniziata la riunione.

Esistono due tipi di descrizioni della data di consegna:

1. Fisse: un insieme predefinito di parole.
2. Variabili: parole che hanno una componente variabile, ma seguono un insieme predefinito di schemi.

## Descrizioni fisse della data di consegna

Ci sono tre descrizioni fisse della data di consegna:

- `"NOW"`
- `"ASAP"` (As Soon As Possible)
- `"EOW"` (End Of Week)

La tabella seguente mostra come tradurle:

| Descrizione | Inizio della riunione        | Data di consegna                    |
| ----------- | ---------------------------- | ----------------------------------- |
| `"NOW"`     | -                            | Due ore dopo l'inizio della riunione |
| `"ASAP"`    | Prima delle 13:00            | Oggi alle 17:00                     |
| `"ASAP"`    | Alle 13:00 o dopo            | Domani alle 13:00                   |
| `"EOW"`     | Lunedì, martedì o mercoledì  | Venerdì alle 17:00                  |
| `"EOW"`     | Giovedì o venerdì            | Domenica alle 20:00                 |

## Descrizioni variabili della data di consegna

Ci sono due schemi di descrizione variabile della data di consegna:

- `"<N>M"` (N-esimo mese)
- `"Q<N>"` (N-esimo trimestre)

| Descrizione | Inizio della riunione            | Data di consegna                                             |
| ----------- | -------------------------------- | ------------------------------------------------------------ |
| `"<N>M"`    | Prima dell'N-esimo mese          | Alle 8:00 del _primo_ giorno lavorativo dell'N-esimo mese di quest'anno  |
| `"<N>M"`    | Dall'N-esimo mese in poi         | Alle 8:00 del _primo_ giorno lavorativo dell'N-esimo mese dell'anno prossimo |
| `"Q<N>"`    | Prima o durante l'N-esimo trimestre | Alle 8:00 dell'_ultimo_ giorno lavorativo dell'N-esimo trimestre di quest'anno |
| `"Q<N>"`    | Dopo l'N-esimo trimestre         | Alle 8:00 dell'_ultimo_ giorno lavorativo dell'N-esimo trimestre dell'anno prossimo |

~~~~exercism/note
Un giorno lavorativo è un lunedì, un martedì, un mercoledì, un giovedì o un venerdì.

Un anno ha quattro trimestri, ciascuno con tre mesi:
1. gennaio/febbraio/marzo
2. aprile/maggio/giugno
3. luglio/agosto/settembre
4. ottobre/novembre/dicembre.
~~~~
