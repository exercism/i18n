# File legacy

```exercism/note
Se lo vedi su Elixir o Elm dopo aver iniziato a usare la v3, molto probabilmente è perché quei track hanno cambiato la struttura dei loro file.
Vedi le sezioni in fondo a questo documento per capire come gestire questo cambiamento.
```

## Cosa sono i file legacy?

Se usi l'editor online di Exercism, a volte potresti imbatterti in un avviso sui file legacy.
Ci sono due motivi per cui potresti vederlo.

### File caricati in modo errato tramite la CLI

Quando usi la CLI, puoi caricare i file che vuoi.
L'editor online, però, ti permette di modificare solo i file che conosce.
Quindi, se carichi un file che l'editor non conosce, non ti lascerà modificarlo e ti mostrerà un avviso, nel caso tu voglia eliminarlo.

### File dovuti a cambiamenti negli esercizi

A volte la struttura degli esercizi cambia.
I file possono essere rinominati, oppure può cambiare l'intera struttura di un esercizio.
Anche se cerchiamo di evitarlo, a volte è pragmaticamente la decisione giusta.
Per esempio, un track può cambiare il suo sistema di build, come ha fatto Elixir passando dai file `exs` ai file `ex`.
Oppure può cambiare la normale struttura di directory di un linguaggio, come è successo con Elm quando hanno spostato tutto in sottodirectory.

In queste situazioni non possiamo spostare i file al posto tuo automaticamente, quindi c'è un po' di lavoro manuale da fare.
Nell'editor vedrai il vecchio file della soluzione (o i vecchi file), con un banner legacy, e lo stub del nuovo file della soluzione.
Copia il tuo lavoro dal vecchio file a quello nuovo e sistema il codice che c'è da cambiare.
Quando i test passano, puoi eliminare il tuo vecchio file della soluzione e dimenticare che tutto questo sia mai successo 🙂

## Eliminare i file legacy

Quando elimini un file legacy, questo **non** ha alcun effetto sulle iterazioni precedenti.
Quel file continuerà a esistere in quelle iterazioni.
Eliminare un file lo rimuove semplicemente dalla **prossima** iterazione che invii tramite l'editor.

## Cambiamenti nella struttura dei track

### Elixir

Nel luglio 2019, Elixir ha cambiato la struttura dei suoi esercizi, passando dall'uso di script Elixir (file `*.exs`) a un [progetto Mix](https://elixir-lang.org/getting-started/mix-otp/introduction-to-mix.html) completo per ogni esercizio.
Per usare le funzionalità della v3, copia la tua soluzione nel file stub che si trova in `lib/<exercise_stub>.ex`.
Non devi spostare il file di test: la versione aggiornata sarà già presente nella posizione corretta.
