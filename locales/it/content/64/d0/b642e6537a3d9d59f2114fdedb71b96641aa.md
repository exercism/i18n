# Appendice alle istruzioni

## Formato dell'output

L'output è la sequenza di proteine sotto forma di stringa terminata da null, con un carattere di nuova riga dopo ogni proteina.

Un esempio di output sarebbe `"Methionine\nPhenylalanine\nSerine\n"`

Se l'input non è valido, l'output è una stringa vuota.

## Registri

| Registro | Utilizzo     | Tipo    | Descrizione                    |
| -------- | ------------ | ------- | ------------------------------ |
| `$a0`    | input        | address | stringa di input terminata da null  |
| `$a1`    | input/output | address | stringa di output terminata da null |
| `$t0-9`  | temporary    | any     | usati per l'archiviazione temporanea |
