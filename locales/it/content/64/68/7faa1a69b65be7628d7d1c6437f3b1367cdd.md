# Appendice alle istruzioni

## Implementazione

Definisci un unico func Go, Cost, che calcola il costo di una data lista di libri in base agli sconti definiti.

Usa la seguente firma per func Cost:

```go
func Cost(books []int) int
```

Cost restituirà il costo totale (dopo gli sconti) in centesimi.
Per esempio, per un singolo libro il costo è di 800 centesimi, pari a 8,00 $.
Per questo esercizio bastano solo calcoli tra numeri interi.
