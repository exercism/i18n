# Introduzione

## Tempo

Il concetto di _tempo_ viene trattato in .NET tramite la struttura `DateTime`. Esistono routine per convertire tra ora locale e UTC. Le operazioni aritmetiche possono essere eseguite con l'aiuto di `TimeSpan`.

## Fuso orario

La classe `TimeZoneInfo` fornisce routine per gestire le differenze tra fusi orari. La classe `TimeZoneInfo` contiene anche metodi che facilitano la gestione dell'ora legale.

La classe `CultureInfo` supporta formati di data e ora dipendenti dalle impostazioni locali.

Per supportare la programmazione multipiattaforma, la classe `RuntimeInformation` consente di rilevare su quale sistema operativo è in esecuzione il codice: Linux, Windows o OSX.
