# Introduzione

## Casualità

In Elixir, per scegliere un elemento casuale da una struttura dati enumerabile (ad esempio una lista o un intervallo), usiamo `Enum.random`. Questa funzione sceglie un singolo elemento, e ogni elemento ha la stessa probabilità di essere scelto.

Elixir non ha funzioni proprie per scegliere un numero in virgola mobile casuale. Per farlo, dobbiamo usare Erlang direttamente.

## Le librerie di Erlang

Il codice Elixir viene eseguito nella macchina virtuale BEAM. BEAM fa parte dell'Erlang Run-Time System. Ispirato a Erlang e condividendone l'ambiente di esecuzione, Elixir offre un'ottima interoperabilità con le librerie di Erlang. Questo significa che chi sviluppa in Elixir può usare le librerie di Erlang dal proprio codice Elixir. Anzi, nella comunità Elixir è scoraggiato scrivere librerie Elixir per funzionalità che le librerie di Erlang forniscono già.

Di conseguenza, alcune funzionalità, come le operazioni matematiche o le funzioni per i timer, in Elixir sono disponibili solo tramite Erlang.

La libreria standard di Erlang è disponibile per l'uso nel nostro codice Elixir senza alcun passaggio aggiuntivo.

Le funzioni di Erlang si chiamano allo stesso modo in cui chiamiamo le funzioni di Elixir, con una piccola differenza. I nomi dei moduli Erlang sono atomi in `snake_case`. Per esempio, per chiamare la funzione `pi/0` di Erlang dal modulo `math`, si scrive:

```elixir
:math.pi()
# => 3.141592653589793
```

Le funzioni di Erlang più usate che non hanno un equivalente in Elixir sono:

- `:timer.sleep/1`, che sospende un processo per il numero di millisecondi indicato.
- `:rand.uniform/0`, che genera un numero in virgola mobile casuale `x`, dove `0.0 <= x < 1.0`.
- `:io_lib.format/2`, che offre la formattazione di stringhe in stile C (usando sequenze di controllo). Con questa funzione, per esempio, potremmo stampare un numero intero in qualsiasi base tra 2 e 36 oppure formattare un numero in virgola mobile con la precisione desiderata. Da notare che questa funzione, come molte funzioni di Erlang, restituisce una charlist.
- Il modulo `math`, che fornisce funzioni matematiche come `sin/1`, `cos/1`, `log2/1`, `log10/1`, `pow/2` e altre ancora.

Per scoprire la libreria standard di Erlang, esplora il [Manuale di riferimento di STDLIB][erl-stdlib-ref].

[erl-stdlib-ref]: https://www.erlang.org/doc/apps/stdlib/index.html
