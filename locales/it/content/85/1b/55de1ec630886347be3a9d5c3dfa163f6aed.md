# Introduzione

## Tipi di funzione

Se rimuoviamo tutti i nomi ed etichette da una firma di funzione Swift, otteniamo il tipo della funzione.

```swift
func shoppingList(item: String, quantity: Int) -> String {
  "You need to buy \(quantity) \(item)."
}
// shoppingList: (String, Int) -> String

func repeater(_ phrase: String, times: Int) -> String {
  var result = ""
  for _ in 1...times {
    result += phrase
  }
  return result
}
// repeater: (String, Int) -> String

func printString(line: String) {
  print(line)
}
// printString: (String) -> ()
```

Nota che i tipi delle prime due funzioni sono gli stessi, `(String, Int) -> String`, anche se le due firme sono diverse e le due funzioni funzionano in modo molto diverso. Entrambe prendono una `String` e un `Int` come input e restituiscono una `String`. E, come si può vedere dal tipo della terza funzione, anche se il corpo della funzione non sembra restituire nulla, in realtà restituisce implicitamente `()`, l'unico valore di tipo `Void`.

Questi tipi di funzione possono essere usati allo stesso modo di qualsiasi altro tipo in Swift; per esempio, si possono usare nella dichiarazione di variabili o costanti. E poiché in Swift le funzioni sono valori, a queste costanti/variabili si possono assegnare funzioni già esistenti:

```swift
var stringAndIntToString: (String, Int) -> String

stringAndIntToString = shoppingList
stringAndIntToString("carrots", 3)
// => "You need to buy 3 carrots."
```

Come per le altre variabili/costanti, il valore che assegni deve essere del tipo corretto:

```swift
stringAndIntToString = printShoppingList
// Error: Cannot assign value of type '(String) -> ()' to type '(String, Int) -> String'
```

## Tipi di funzione come tipi di parametro

Poiché i tipi di funzione possono essere usati ovunque si possa usare un altro tipo, ne consegue che possono essere usati come tipi di parametro, passati ad altre funzioni e chiamati dall'interno di quelle funzioni.

```swift
func apply3(to str: String, function f: (String, Int) -> String) -> String {
  f(str,3)
}
// apply3: ([String], (String, Int) -> String) -> [String]

apply3(to: "eggs", function: shoppingList)
// => "You need to buy 3 eggs."

apply3(to: "eggs", function: repeater)
// => "eggseggseggs"
```

## Tipi di funzione come tipi restituiti

Allo stesso modo, i tipi di funzione possono essere usati come tipi restituiti dalle funzioni. In altre parole, si possono scrivere funzioni che creano e restituiscono altre funzioni. Quando si creano queste funzioni, la funzione restituita può usare gli altri parametri passati alla funzione o le variabili locali create dentro la funzione contenitrice.

```swift
func makeAdder(base: Int) -> (Int) -> Int {
  func adder(_ i: Int) -> Int {
    base + i
  }
  return adder
}
// makeAdder: (Int) -> (Int) -> Int

let add10 = makeAdder(base: 10)
// add10: (Int) -> Int

let subtract20 = makeAdder(base: -20)
// subtract20: (Int) -> Int

add10(5)
// => 15

subtract20(5)
// => -15
```
