# Informazioni

Le charlist si creano usando il Sigil `~c`.

```elixir
~c"hello"
```

~~~~exercism/note
Nota che nelle versioni più vecchie di Elixir, le charlist sono rappresentate come `'hello'` con virgolette singole.
~~~~

Una charlist è un array di numeri interi. I numeri interi rappresentano i valori Unicode di un dato carattere, noti anche come punti di codice.

```elixir
[65, 66, 67]
# => ~c"ABC"
```

## Le charlist _sono_ array

```elixir
~c"" === []
# => true

is_list(~c"hello")
# => true
```

Dato che le charlist sono array, puoi lavorarci proprio come con qualsiasi altro array: usando la ricorsione e il pattern matching, oppure usando il modulo [`List`][list].

```elixir
[first_letter | _] = ~c"cat"
first_letter
# => 99

List.first(~c"hello")
# => 104
List.pop_at(~c"hello", 0)
# => {104, ~c"ello"}

```

Puoi concatenare due array insieme usando [`++`][kernel-concat-list].

```elixir
~c"hi" ++ ~c"!"
# => ~c"hi!"
```

Più è lungo il primo array, più lenta è la concatenazione, quindi evita di aggiungere ripetutamente elementi in coda ad array di lunghezza arbitraria.

## Stampabilità

Se un array di numeri interi contiene solo numeri interi che sono punti di codice di caratteri stampabili, verrà visualizzato come charlist. Anche se è stato definito usando la sintassi `[]`.

```elixir
~c"ABC"
# => ~c"ABC"

[65, 66, 67]
# => ~c"ABC"
```

Se un array di numeri interi contiene anche solo un punto di codice di un carattere non stampabile (ad esempio `0-6`, `14-26`, `28-31`), verrà visualizzato come array. Anche se è stato definito usando la sintassi `~c""`.

```elixir
~c"ABC\0"
# => [65, 66, 67, 0]

[65, 66, 67, 0]
# => [65, 66, 67, 0]
```

La stampabilità può essere verificata con [`List.ascii_printable?`][list-ascii-printable].

```elixir
List.ascii_printable?([65, 66, 67])
# => true
List.ascii_printable?([65, 66, 67, 0])
# => false
```

Tieni presente che questi sono due modi diversi di _visualizzare_ gli stessi dati. I valori sono strettamente uguali.

```elixir
~c"ABC" === [65, 66, 67]
# => true
```

Quando stampi un array con [`IO.inspect`][io-inspect], puoi usare l'opzione [`:charlists`][inspect-opts] per controllare come vengono stampati gli array.

```elixir
IO.inspect(~c"ABC", charlists: :as_charlists)
# => prints ~c"ABC"

IO.inspect(~c"ABC", charlists: :as_lists)
# => prints [65, 66, 67]
```

## Punti di codice

Puoi anteporre `?` a un carattere per ottenere il suo punto di codice.

```elixir
?A
# => 65

[?:, ?)]
# => ~c":)"
```

## Charlist e stringhe

Le charlist e le stringhe composte dagli stessi caratteri non sono considerate uguali.

```elixir
~c"hello" == "hello"
false
```

Ogni valore in una charlist è il [punto di codice Unicode di un carattere][unicode-table], mentre in una stringa i punti di codice sono codificati come [UTF-8][utf8].

```elixir
IO.inspect(~c"tschüss", charlists: :as_lists)
# => prints [116, 115, 99, 104, 252, 115, 115]

IO.inspect("tschüss", binaries: :as_binaries)
# => prints <<116, 115, 99, 104, 195, 188, 115, 115>>
```

Nota come `ü`, punto di codice `252`, è codificato in UTF-8 come `195` e `188`.

**In pratica, le charlist sono usate raramente**. Il loro caso d'uso principale è l'interfacciamento con Erlang, in particolare quando si usano librerie più vecchie che non accettano binari come argomenti.

Quando lavori con Elixir, **usa le stringhe per memorizzare il testo**. Il modulo `String` offre un'ampia scelta di funzioni per elaborare il testo, funzioni non disponibili per le charlist.

Le charlist possono essere convertite in stringhe con [`to_string`][kernel-to-string].

```elixir
to_string(~c"hello")
# => "hello"
```
