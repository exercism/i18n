# Appendice alle istruzioni

## Registri

| Registro | Utilizzo     | Tipo    | Descrizione                              |
| -------- | ------------ | ------- | ---------------------------------------- |
| `$a0`    | input        | indirizzo | primo colore come stringa terminata da null |
| `$a1`    | input        | indirizzo | secondo colore come stringa terminata da null |
| `$a2`    | input        | indirizzo | terzo colore come stringa terminata da null |
| `$a3`    | input/output | indirizzo | stringa di output terminata da null      |
| `$t0-9`  | temporaneo   | qualsiasi | usato per l'archiviazione temporanea     |
