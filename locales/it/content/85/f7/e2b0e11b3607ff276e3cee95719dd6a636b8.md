# Test

## Eseguire i test

Per eseguire i test, esegui il comando seguente:

```bash
dotnet test
```

## Risolvere l'esercizio

Risolvere un esercizio significa far passare tutti i suoi test. Per impostazione predefinita, quando esegui i test viene eseguito un solo test (il primo). È intenzionale: ti permette di concentrarti solo sul far passare quel singolo test. Una volta che passa, puoi abilitare il test successivo rimuovendo `Skip = "Remove this Skip property to run this test"` dall'attributo `[<Fact>]` o `[<Theory>]` del test. Quando tutti i test saranno abilitati e la tua implementazione li farà passare tutti, avrai risolto l'esercizio!

Per aiutarti a iniziare, ogni esercizio include un file di implementazione stub. Puoi usare questo file come punto di partenza per costruire la soluzione. Sentiti libero di rimuoverlo o modificarlo se ritieni che sia la cosa giusta da fare.

## Usare i pacchetti

Puoi risolvere la maggior parte degli esercizi senza usare pacchetti esterni. Tuttavia, per gli esercizi in cui vuoi davvero usare un pacchetto esterno, puoi aggiungerlo al progetto eseguendo il comando seguente:

```bash
dotnet add package [package-name]
```
