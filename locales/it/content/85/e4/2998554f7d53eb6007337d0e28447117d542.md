# Istruzioni

Lavori alla postazione di sicurezza di una stazione di ricerca. Il personale porta dei *badge* i cui codici seguono un formato rigido, il registro degli accessi è pieno di quei codici mescolati a testo normale, e il registro va ripulito prima di poterlo condividere. Le espressioni regolari sono lo strumento giusto per ognuno di questi compiti.

Un codice badge valido è formato da **due lettere maiuscole, un trattino, poi quattro cifre**, ad esempio `NS-1024`.

## 1. Controlla un codice badge

Definisci `valid-badge?`, che prende una stringa badge e restituisce `t` quando l'*intera* stringa è un codice badge valido e `f` altrimenti.

```factor
"NS-1024" valid-badge? .   ! => t
"NS-10"   valid-badge? .   ! => f
```

## 2. Estrai tutti i codici da una riga di registro

Definisci `badge-codes`, che prende una riga del registro degli accessi e restituisce una sequenza di tutti i codici badge che vi compaiono, in ordine.

```factor
"seen NS-1024 then AB-0007 today" badge-codes .
! => { "NS-1024" "AB-0007" }
```

## 3. Conta le cifre di un codice

Definisci `digit-count`, che prende una stringa e restituisce quante cifre contiene.

```factor
"NS-1024" digit-count .   ! => 4
```

## 4. Oscura le password

A volte le righe di registro annotano una password come `pass=` seguito dal segreto (una qualsiasi sequenza di caratteri diversi dallo spazio). Definisci `redact`, che prende una riga e la restituisce con ogni password di questo tipo sostituita da `pass=****`.

```factor
"user=alice pass=hunter2 ok" redact .
! => "user=alice pass=**** ok"
```
