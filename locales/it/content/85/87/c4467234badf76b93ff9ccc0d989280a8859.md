# Introduzione

Un *disposable* è qualsiasi cosa che occupi una risorsa del sistema operativo, come un file aperto, un socket o un lucchetto basato su una tabella hash, e che vada liberata quando hai finito di usarla. Il vocabolario [`destructors`][destructors] di Factor incapsula tutto questo in un piccolo framework, così la pulizia avviene anche quando un'eccezione risale lo stack.

```factor
USING: destructors io.files io.encodings.utf8 ;

"log.txt" utf8 <file-writer> [
    "hello, world" write
] with-disposal
! file is closed even if write throws
```

`with-disposal ( disposable quot -- )` esegue la quotation con la risorsa e la libera all'uscita. Se le risorse sono più di una, apri uno scope con `with-destructors` e registra ciascuna con `&dispose` (libera all'uscita normale *e* in caso di errore) oppure `|dispose` (libera solo in caso di errore).

Una classe entra a far parte del framework estendendo `disposable` e implementando la parola generica `dispose*`: il framework la chiama una volta sola per oggetto. La parola pubblica usata da chi chiama è `dispose`.

[destructors]: https://docs.factorcode.org/content/vocab-destructors.html
