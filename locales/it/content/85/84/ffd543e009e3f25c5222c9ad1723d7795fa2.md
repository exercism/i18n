# Eseguire i test

Per eseguire la suite di test, esegui il seguente comando:

```bash
stack test
```

#### Se ricevi un messaggio di errore come questo...

```
No .cabal file found in directory
```

oppure

```
RedownloadInvalidResponse Request {
...
}
 "/home/username/.stack/build-plan/lts-xx.yy.yaml" (Response {responseStatus = Status {statusCode = 404, statusMessage = "Not Found"},
```

Probabilmente stai usando una versione vecchia di stack e devi aggiornarla. Prova a eseguire:

```bash
stack upgrade
```

Oppure consulta altre opzioni per l'aggiornamento nella [documentazione di Stack](https://docs.haskellstack.org/en/stable/install_and_upgrade/#upgrade).

#### Altrimenti, se ricevi un messaggio di errore come questo...

```
No compiler found, expected minor version match with...
Try running "stack setup" to install the correct GHC...
```

Fai semplicemente come dice e scaricherà e installerà la versione corretta del compilatore:

```bash
stack setup
```

# Eseguire *GHCi*

Se vuoi giocare con la soluzione in GHCi, esegui semplicemente il comando:

```bash
stack ghci
```
