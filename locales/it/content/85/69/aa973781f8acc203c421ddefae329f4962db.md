# Introduzione

## Numeri

In Java ci sono due tipi diversi di numeri:

- Interi: numeri senza cifre dopo il separatore decimale (numeri interi).
  Alcuni esempi sono `-6`, `0`, `1`, `25`, `976` e `-500000`.
- Numeri in virgola mobile: numeri con zero o più cifre dopo il separatore decimale.
  Alcuni esempi sono `-20.4`, `0.1`, `2.72`, `16.984025` e `1024.0`.

I due tipi numerici più comuni in Java sono `int` e `double`.
Un `int` è un intero a 32 bit, mentre un `double` è un numero in virgola mobile a 64 bit.

Le operazioni aritmetiche si eseguono con i normali operatori aritmetici.
I numeri si possono confrontare con i normali operatori di confronto numerico (ad es. `5 > 4` e `4 <= 5`) e con gli operatori di uguaglianza (`==`) e disuguaglianza (`!=`).

Java ha due tipi di conversione numerica:

1. Conversioni implicite: non si perde nessun dato e non serve alcuna sintassi aggiuntiva.
2. Conversioni esplicite: si potrebbero perdere dei dati e serve una sintassi aggiuntiva, sotto forma di _cast_.

Poiché un `int` ha meno precisione di un `double`, convertire da `int` a `double` è sicuro ed è quindi una conversione implicita.
Al contrario, convertire da `double` a `int` potrebbe significare perdere dei dati, quindi richiede una conversione esplicita.

## Istruzioni if-else

### L'istruzione _if-then_

L'istruzione di controllo del flusso più semplice in Java è l'istruzione _if-then_.
Questa istruzione serve a eseguire una sezione di codice solo se una particolare condizione è `true`.
Un'istruzione _if-then_ si definisce usando la clausola `if`:

```java
class Car {
    void drive() {
        // the "if" clause: the car needs to have fuel left to drive
        if (fuel > 0) {
            // the "then" clause: the car drives, consuming fuel
            fuel--;
        }
    }
}
```

Nell'esempio qui sopra, se l'auto è senza carburante, chiamare il metodo `Car.drive` non farà nulla.

### L'istruzione _if-then-else_

L'istruzione _if-then-else_ fornisce un percorso di esecuzione alternativo per quando la condizione nella clausola `if` si valuta come `false`.
Questo percorso di esecuzione alternativo segue una clausola `if` e si definisce usando la clausola `else`:

```java
class Car {
    void drive() {
        if (fuel > 0) {
            fuel--;
        } else {
            stop();
        }
    }
}
```

Nell'esempio qui sopra, se l'auto è senza carburante, chiamare il metodo `Car.drive` chiamerà un altro metodo per fermare l'auto.

L'istruzione _if-then-else_ supporta anche più condizioni usando la clausola `else if`:

```java
class Car {
    void drive() {
        if (fuel > 5) {
            fuel--;
        } else if (fuel > 0) {
            turnOnFuelLight();
            fuel--;
        } else {
            stop();
        }
    }
}
```

Nell'esempio qui sopra, guidare l'auto quando il carburante è minore o uguale a `5` farà muovere l'auto, ma accenderà la spia del carburante.
Quando il carburante arriva a `0`, l'auto smetterà di muoversi.
