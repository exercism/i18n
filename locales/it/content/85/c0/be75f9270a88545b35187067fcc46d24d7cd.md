Ma le cose sono un po' disorganizzate: le coordinate di Azara sembrano formattate e ordinate in modo diverso da quelle di Rui, e devono continuare a passare da una lista all'altra per capire quali tesori vanno con quali luoghi.
Essendo programmatori Julia in erba, si sono rivolti a te per un aiuto nello scrivere un piccolo programma (in realtà un insieme di funzioni) per organizzare meglio le informazioni della loro caccia.

## 1. Estrai le coordinate

Implementa la funzione `get_cooordinate()` che prende una coppia `(treasure, coordinate)` dalla lista di Azara e restituisce solo la coordinata della mappa estratta.

```julia-repl
julia> get_cooordinate( ("Scrimshaw Whale's Tooth", "2A") )
"2A"
```

## 2. Formatta le coordinate

Implementa la funzione `convert_coordinate()` che prende una coordinata nel formato «2A» e restituisce una tupla nel formato `('2', 'A')`.

```julia-repl
julia> convert_coordinate("2A")
('2', 'A')
```

## 3. Abbina le coordinate

Implementa la funzione `compare_records()` che prende una coppia `(treasure, coordinate)` e un record `(location, coordinate, quadrant)` e confronta le coordinate di ciascuno.
Restituisci **`true`** se le coordinate «corrispondono», e restituisci **`false`** se non corrispondono.
Riformatta le coordinate come serve per un confronto accurato.

```julia-repl
julia> compare_records(("Brass Spyglass", "4B"), ("Seaside Cottages", ('1', 'C'), "blue"))
false

julia> compare_records(("Model Ship in Large Bottle", "8A"), ("Harbor Managers Office", ('8', 'A'), "purple"))
true
```

## 4. Combina i record abbinati

Implementa la funzione `create_record()` che prende una coppia `(treasure, coordinate)` dalla lista di Azara e un record `(location, coordinate, quadrant)` dalla lista di Rui e restituisce `(coordinate, location, quadrant, treasure)` **se le coordinate corrispondono**.

Se le coordinate _non_ corrispondono, restituisci una tupla vuota.
Riformatta le coordinate come serve per un confronto accurato.

```julia-repl
julia> create_record(("Brass Spyglass", "4B"), ("Abandoned Lighthouse", ('4', 'B'), "Blue"))
("4B", "Abandoned Lighthouse", "Blue", "Brass Spyglass")

julia> create_record(("Brass Spyglass", "4B"), ("Seaside Cottages", ('1', 'C'), "Blue"))
()
```
