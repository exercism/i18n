# Introduzione

Un'espressione switch può far corrispondere un valore a uno dei casi di un insieme di pattern e restituire il valore associato oppure eseguire l'azione associata. L'associazione è indicata dal simbolo `=>`. Inoltre, ogni pattern può avere una guardia del caso opzionale, introdotta dalla parola chiave `when`. L'espressione della guardia del caso deve avere valore true perché quel «braccio» dello switch venga selezionato. I casi (detti anche _bracci dello switch_) vengono valutati nell'ordine in cui sono scritti: il processo si interrompe non appena viene trovata una corrispondenza e viene restituito il valore associato.

```csharp
double xx = 42d;

string interesting = xx switch
{
    0 => "I suppose zero is interesting",
    3.14 when DateTime.Now.Day == 14 && DateTime.Now.Month == 3 => "Mmm pie!",
    3.14 => "π",
    42 => "a bit of a cliché",
    1729 => "only if you are a pure mathematician",
    _ => "not interesting"
};

// => interesting == "a bit of a cliché"
```
