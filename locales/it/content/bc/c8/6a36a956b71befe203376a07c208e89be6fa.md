# Introduzione

Unison rappresenta i valori vero e falso con il tipo `Boolean`. Esistono solo due valori: `true` e `false`.

```unison
trueVariable = true
falseVariable = false
```

Possiamo valutare le espressioni booleane con gli operatori «and», rappresentato da `&&`; «or», rappresentato da `||`; e «not», rappresentato da `not`.

```unison
trueVariable = true && true
falseVariable = true && false

trueVariable = false || true
falseVariable = false || false

trueVariable = not false
falseVariable = not true
```

Le espressioni booleane di Unison ammettono la valutazione a corto circuito: se il primo argomento di un'espressione `&&` è `false`, non c'è motivo di continuare a valutare il secondo argomento. Allo stesso modo, se il primo argomento di un'espressione `||` è `true`, l'espressione restituirà subito `true`.

```unison
> false && (base.bug "oh no")
  ⧩
  false
```

```unison
> true || (base.bug "oh no")
  ⧩
  true
```
