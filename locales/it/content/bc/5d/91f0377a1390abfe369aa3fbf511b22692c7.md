# Stringhe

Una **stringa** è un pezzo di testo. In Sather il tipo che la rappresenta è `STR`, e una stringa si scrive tra virgolette doppie.

```sather
   composer : STR is
      return "Sibelius";
   end;
```

## Unire le stringhe

`+` unisce due stringhe una di seguito all'altra.

```sather
"Jean" + " " + "Sibelius"      -- "Jean Sibelius"
```

Tra loro non viene messo nulla, quindi lo spazio va chiesto esplicitamente. Se lo dimentichi, ottieni `"JeanSibelius"`.

## Quanto è lunga?

`.size` indica quanti caratteri contiene una stringa. È un numero intero, quindi il suo tipo è `INT`.

```sather
"Sibelius".size      -- 8
```

Dopo `.size` non ci sono parentesi, proprio come una routine che non prende argomenti.

## Prendere una parte

`.head(n)` sono i primi `n` caratteri. `.tail(n)` sono gli ultimi `n`.

```sather
"Sibelius".head(3)   -- "Sib"
"Sibelius".tail(4)   -- "lius"
```

`head` conta dall'inizio, `tail` conta dalla fine. Entrambi lasciano intatta la stringa originale e ne restituiscono una nuova.
