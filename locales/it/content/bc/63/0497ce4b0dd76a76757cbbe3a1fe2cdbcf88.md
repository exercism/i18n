# Appendice alle istruzioni

## Implementazione

La lista deve anche implementare la seguente interfaccia:

- `delete` (elimina la prima occorrenza di un valore specificato)
- `count` (conta il numero di elementi nella lista)

**NOTA**: _Non_ usare una libreria per implementare questo esercizio. _Non_ usare un array di appoggio per implementare questo esercizio.
