# Informazioni

In Elixir ci sono due tipi diversi di numeri: i numeri interi e i numeri in virgola mobile.

I numeri interi non hanno una parte decimale.

```elixir
integer = 3
# => 3
```

Nel modulo [`Integer`][integer] troverai alcune funzioni utili per lavorare con i numeri interi.

```elixir
Integer.digits(123)
# => [1, 2, 3]
```

I numeri interi grandi (ma anche i numeri in virgola mobile) di solito si formattano separando ogni 3 cifre in gruppi con un trattino basso.

```elixir
1_000_000
# => 1000000
```

La dimensione massima dei numeri in Elixir è limitata solo dalla memoria disponibile sul sistema, perché Elixir usa l'[aritmetica a precisione arbitraria][arbitrary-precision-arithmetic].

Elixir supporta anche notazioni abbreviate per inserire [numeri interi binari, ottali ed esadecimali][integers-in-other-bases].

```elixir
0b0100
# => 4

0o555
# => 365

0xFF
# => 255
```

## Confronto

I numeri interi e i numeri in virgola mobile possono essere considerati uguali ([`==`][kernel-equal]) se hanno lo stesso valore. Tuttavia, essendo di tipi diversi, non sono mai strettamente uguali ([`===`][kernel-strictly-equal]).

```elixir
1 == 1.0
# => true

1 === 1.0
# => false
```
