# Introduzione

Una tupla è un raggruppamento _immutabile_ di valori senza nome ma ordinati.
Le tuple possono contenere qualsiasi tipo di dato (o più tipi di dati), comprese altre tuple.

Le tuple si definiscono come valori separati da virgole tra i caratteri `(` e `)`: `(<element_1>, ... , <element_n>)`.

```fsharp
("one", 2) // Tuple pair (2 values)
("one", 2, true) // Tuple triplet (3 values)
```

Solo le tuple con la stessa lunghezza e gli stessi tipi (nello stesso ordine) possono essere confrontate.
Le tuple hanno un'uguaglianza strutturale: sono uguali _solo_ se tutti i loro valori sono uguali.

```fsharp
(1, 2) = (1, 2) // Same length, same types, same values, same order
// => true

(1, 2) = (2, 1) // Same length, same types, same values, different order
// => false

(1, 2) = (1, "2") // Same length, different types
// compiler error

(1, 2) = (1, 2, 3) // Different length
// compiler error
```

Ci sono tre modi per estrarre i valori da una tupla:

- Le funzioni `fst` e `snd`
- La destrutturazione della tupla
- Il pattern matching

```fsharp
let person = ("Jordan", 170)

// Option 1: fst/snd
let name1 = fst person
let length2 = snd person

// Option 2: deconstruction
let (name2, length2) = person
// => name2 = "Jordan"
// => length2 = 170

// Option 3: pattern matching
match person with
| name3, length3 -> printf "%s: %d" name3 length3
```
