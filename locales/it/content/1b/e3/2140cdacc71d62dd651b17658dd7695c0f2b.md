# I condizionali

Crystal ha quelle che vengono chiamate espressioni di controllo: servono a controllare il modo in cui il programma verrà eseguito e accettano un valore veritiero o falso.
Ci sono operatori che possono essere usati per creare valori veritieri o falsi, questi sono noti come [operatori di uguaglianza e confronto][equality-and-comparison].

Ci sono due espressioni di controllo principali, usate per controllare quale codice verrà eseguito e quale no.
In altre parole, quale determinato ramo verrà eseguito.

Queste due sono: l'espressione `if` e l'espressione `unless`.

## Operatori di confronto

Gli operatori di confronto servono a confrontare valori e restituiscono un valore `true` o `false`.
Questi operatori richiedono che vengano confrontati due valori dello stesso tipo.
Se i valori non sono dello stesso tipo, il compilatore genererà un errore.
Ecco un elenco degli operatori di confronto e un esempio di quando restituiscono un valore `true`:

| Metodo | Descrizione           | Esempio |
| ------ | --------------------- | ------- |
| <      | minore di             | 4 < 5   |
| <=     | minore o uguale a     | 4 <= 4  |
| >      | maggiore di           | 3 > 1   |
| >=     | maggiore o uguale a   | 2 >= 2  |

## Operatori di uguaglianza

Gli operatori di uguaglianza sono simili agli operatori di confronto, ma servono a verificare se due valori sono uguali o no.

L'operatore `==` verifica se due valori sono uguali, incluso il tipo del valore.
Se i valori sono uguali restituisce `true`, altrimenti restituisce `false`.
L'operatore `==` può confrontare qualsiasi tipo di valore con qualsiasi altro tipo di valore.
L'operatore `!=` funziona allo stesso modo, ma restituisce `true` se i valori non sono uguali e `false` se lo sono.

## L'operatore spaceship

L'operatore spaceship è un operatore di confronto particolare, il cui nome deriva dal suo aspetto.
È particolare nel senso che non restituisce un valore veritiero o falso, ma un numero.
Si scrive `<=>` e si usa per confrontare due valori.
Restituisce `1` se il valore di sinistra è maggiore di quello di destra, `-1` se il valore di sinistra è minore di quello di destra, e `0` se i valori sono uguali.

```crystal
1 <=> 2 # => -1
2 <=> 2 # => 0
3 <=> 2 # => 1
```

## L'istruzione if

L'istruzione [`if`][if] serve a verificare se una determinata condizione è veritiera o falsa.
Se la condizione è veritiera, il codice dentro l'istruzione if verrà eseguito.
Un'istruzione `if` termina con la parola chiave `end`.

```crystal
if 1 == 1
  puts "1 is equal to 1"
end
# => 1 is equal to 1

if 1 > 2
  puts "1 is greater than 2"
end
# => no output
```

## L'istruzione unless

L'istruzione [`unless`][unless] funziona in modo molto simile all'istruzione `if`, ma esegue il codice al suo interno se la condizione è falsa.

```crystal
unless 1 == 1
  puts "1 is not equal to 1"
end
# => no output

unless 1 > 2
  puts "1 is not greater than 2"
end
# => 1 is not greater than 2
```

## L'istruzione else

L'istruzione `else` può essere usata insieme alle istruzioni `if` e `unless`.
L'istruzione `else` viene eseguita se il ramo `if` o il ramo `unless` non viene eseguito.

~~~~exercism/warning
Anche se un ramo `else` può essere usato insieme a `unless,` farlo è sconsigliato perché danneggia la leggibilità.
Al suo posto, si consiglia di usare `if !condition` con un ramo else.
~~~~

```crystal
if 1 == 1
  puts "1 is equal to 1"
else
  puts "1 is not equal to 1"
end
# => 1 is equal to 1

unless 1 < 2
  puts "1 is not greater than 2"
else
  puts "1 is greater than 2"
end
# => 1 is greater than 2
```

## Le istruzioni "if a cascata"

L'istruzione `elsif` può essere usata insieme all'istruzione if.
L'istruzione `elsif` viene eseguita se il ramo if non viene eseguito e la condizione dell'istruzione `elsif` è veritiera.
Le istruzioni `elsif` possono essere concatenate tra loro e verrà eseguita la prima condizione veritiera.
Alla fine dell'istruzione if può esserci anche un'istruzione else, che verrà eseguita se nessuna delle istruzioni precedenti è risultata vera.

```crystal
if 1 != 1
  puts "1 is not equal to 1"
elsif 1 > 2
  puts "1 is greater than 2"
else
  puts "1 is not equal to 1 and 1 is not greater than 2"
end
# => 1 is not equal to 1 and 1 is not greater than 2
```

## L'operatore ternario

Crystal ha un operatore ternario, un'istruzione if-else su una sola riga: `condition ? expression_if_truthy : expression_if_falsey`

```crystal
1 == 1 ? puts("1 is equal to 1") : puts("1 is not equal to 1")
# => 1 is equal to 1
```

## if e unless come suffisso

Le istruzioni if e unless possono anche essere usate come [suffisso][if-as-suffix], il che è utile quando vuoi eseguire una singola riga di codice se una condizione è vera.
Si fa mettendo l'istruzione if o unless dopo il codice che vuoi eseguire.

```crystal
puts "1 is equal to 1" if 1 == 1
# => 1 is equal to 1

puts "1 is not equal to 1" unless 1 == 1
# => no output
```

## I tipi con i condizionali

Quando a una variabile vengono assegnati tipi diversi, la variabile porterà entrambi i tipi.
Questo perché il compilatore non sa quale ramo verrà eseguito.
Questa assegnazione multipla, nota anche come union, verrà spiegata nei concetti successivi.
Lo si può vedere nell'esempio seguente:

```crystal
if 1 == 1
  a = 1
else
  a = "1"
end

typeof(a) # => Int32 | String
```
