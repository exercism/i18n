# Appendice alle istruzioni

## Informazioni su Enum

L'istruzione enum permette di creare un insieme di etichette fortemente tipizzato.
Puoi usare quell'enumerazione nel codice senza dover analizzare o controllare eventuali errori di ortografia.

Le enumerazioni sono rappresentate internamente come numeri interi con un valore iniziale pari a zero.
Per impostazione predefinita, PowerShell assegna alla prima etichetta della lista il valore zero e alle etichette rimanenti assegna numeri interi consecutivi.

Esempio:
```pwsh
Enum Fruits {
    APPLE       #default internal value 0
    ORANGE      #default internal value 1
    MANGO       #default internal value 2
}

$myFavFruit = [Fruits]::APPLE
Write-host $myFavFruit => APPLE
``````

Per saperne di più su Enum in PowerShell, dai un'occhiata al [modulo Enum.](https://learn.microsoft.com/en-us/powershell/module/microsoft.powershell.core/about/about_enum)
