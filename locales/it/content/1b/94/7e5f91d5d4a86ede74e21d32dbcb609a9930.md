# Nessun letterale intero

Elixir ha una [sintassi speciale](https://elixir-lang.org/getting-started/binaries-strings-and-char-lists.html#unicode-and-code-points) per scrivere numeri interi che corrispondono ai [Code Point Unicode](https://en.wikipedia.org/wiki/Code_point): puoi usare un `?` davanti al letterale carattere per rivelarne il code point.

Per esempio,

```elixir
?a === 97
?\s === 32
?ß === 223
?互 === 20114
```

Quando si manipolano i code point, questa notazione è molto più leggibile dei numeri e va sempre preferita.
