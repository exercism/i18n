# Strumenti per chi contribuisce

Chi studia ha bisogno solo degli strumenti elencati in [INSTALLATION.md](INSTALLATION.md).
Chi contribuisce ne ha bisogno di qualcun altro, perché gli script del track li usano:

- `git`, per clonare il repository e aprire pull request.
- `jq`, usato da `bin/verify-exercises` e `bin/add-practice-exercise`.
- `curl`, usato da `bin/fetch-configlet`.
- Python 3.11 o successivo, per il generatore di test.
- `clang-format`, che il generatore di test esegue sui file che scrive.
- `pre-commit`, che esegue i controlli del repository prima di ogni commit.

Installali con il comando per la tua distribuzione, poi segui i passaggi nella sezione "Configurare il repository".

## Debian / Ubuntu

```shell
sudo apt install git jq curl clang-format pre-commit
```

## Fedora

```shell
sudo dnf install git jq curl pre-commit clang-tools-extra diffutils
```

## Arch Linux

```shell
sudo pacman -S git jq curl pre-commit clang diffutils
```

## openSUSE Tumbleweed

```shell
sudo zypper install git jq curl python3-pre-commit clang-tools diffutils
```

## Configurare il repository

Dalla radice del repository:

```shell
bin/fetch-configlet
bin/configlet info
pre-commit install
pre-commit run --all-files
```
