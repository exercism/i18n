# Suggerimenti

## 1. Crea un nuovo array

- Puoi creare un array vuoto con la sintassi `[]`.

## 2. Definisci un array esistente

- Puoi creare array con più elementi con la sintassi `["a", "b", "c"]`.

## 3. Aggiungi un nuovo linguaggio a un array

- La sintassi di espansione (`[x, ..list]`) permette di aggiungere un elemento all'inizio di un array.

## 4. Conta i linguaggi nell'array

- Nel modulo `gleam/list` c'è una funzione per [contare gli elementi di un array][length].

## 5. Inverti l'array

- Nel modulo `gleam/list` c'è una funzione per [invertire un array][reverse].

## 6. Controlla se l'array è entusiasmante

- Puoi usare il pattern matching, con i pattern di array e di espansione, per riconoscere strutture di array specifiche.

[reverse]: https://hexdocs.pm/gleam_stdlib/gleam/list.html#reverse
[length]: https://hexdocs.pm/gleam_stdlib/gleam/list.html#length
