# Aiuto

Dove cercare aiuto per le domande su AWK:

* [Il tag `awk` su Stack Overflow][so].
* dai un'occhiata alla sezione "Resources" della [pagina informativa del tag `awk` su Stack Overflow][so-info].
* apri una issue nel repository Github [exercism/awk][github].
* IRC: `irc://irc.liberachat.net/#awk`, `irc://irc.liberachat.net/#exercism`
    * vedi [Libera.chat][libera] se non conosci IRC.
