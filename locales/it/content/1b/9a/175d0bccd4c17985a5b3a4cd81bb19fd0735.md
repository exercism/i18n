# Istruzioni

Implementa un sistema reattivo di base.

La programmazione reattiva è un paradigma di programmazione che si concentra su come i valori vengono calcolati in relazione gli uni agli altri, così che una modifica a un valore si propaghi automaticamente agli altri, come in un foglio di calcolo.

Implementa un sistema reattivo di base con celle con valori impostabili (le celle di input) e celle con valori calcolati in termini di altre celle (le celle di calcolo).
Implementa gli aggiornamenti in modo che, quando un valore di input cambia, i valori si propaghino fino a raggiungere un nuovo stato stabile del sistema.

Inoltre, le celle di calcolo dovrebbero permettere di registrare callback di notifica dei cambiamenti.
Chiama le callback di una cella quando il valore della cella, in un nuovo stato stabile, è cambiato rispetto allo stato stabile precedente.
