# Test

Scegli il sistema operativo che stai usando:

* [Windows](##windows)
* [macOS](##macos)
* [Linux](##linux)

# Eseguire i test

## Windows

1. Apri il Command Prompt.

2. Scarica il primo esercizio:

    ```batchfile
     C:\Users\USERNAME> exercism download --exercise hello-world --track cobol
    ```

3. Entra nella cartella dell'esercizio:

    ```batchfile
     C:\Users\USERNAME> cd C:\Users\USERNAME\exercism\cobol\hello-world
    ```
   
4. Esegui i test:

    ```batchfile
     C:\Users\USERNAME\exercism\cobol\hello-world> test.ps1
    ```
    *(Non preoccuparti se i test falliscono la prima volta che li esegui: è così che inizi ogni esercizio.)*

5. Risolvi l'esercizio. 
    Leggi `instructions.md` e guarda come risolvere l'esercizio ([visualizza su GitHub](https://github.com/exercism/cobol/blob/main/exercises/practice/hello-world/.docs/instructions.md)).


In bocca al lupo, divertiti e benvenuto alla traccia COBOL!

----

## macOS

1. Apri una finestra del Terminal.

2. Scarica il primo esercizio:

    ```
     $ exercism download --exercise hello-world --track cobol
    ```

3. Entra nella cartella dell'esercizio:

    ```
     $ cd /Users/USERNAME/exercism/cobol/hello-world
    ```

4. Esegui i test:

    ```
     $ bash test.sh
    ```
    *(Non preoccuparti se i test falliscono la prima volta che li esegui: è così che inizi ogni esercizio.)*

    Suggerimento: se ricevi un messaggio che dice che manca `basename`, puoi usare [brew](https://brew.sh/) per installare coreutils. (`brew install coreutils`)

5. Risolvi l'esercizio. 

    Leggi `instructions.md` e guarda come risolvere l'esercizio ([visualizza su GitHub](https://github.com/exercism/cobol/blob/main/exercises/practice/hello-world/.docs/instructions.md)).


In bocca al lupo, divertiti e benvenuto alla traccia COBOL!
