# Appendice alle istruzioni

## Implementazione

~~~~exercism/note

Potresti voler chiamare (o forse no!) la funzione `permutations(a, t)` da [Combinatorics.jl][combinatorics] nella soluzione.

[combinatorics]: https://juliamath.github.io/Combinatorics.jl/stable/api/#Combinatorics.permutations-Tuple{Any,%20Integer}
~~~~

- Se lavori nell'editor online, puoi chiamare `permutations(a ,t)` liberamente, dato che è già nel namespace. Puoi vedere il codice sorgente nella scheda `permutations.jl`.
- Se lavori in locale, aggiungi `include("permutations.jl")` in cima al file della soluzione per accedere a una versione di `permutations(a, t)` che si trova lì.

~~~~exercism/caution

Se usi `Combinatorics.jl` `v1.0.3` in locale, `permutations(a, t)` è *molto* lenta sui test di grandi dimensioni.
Usa il file fornito `permutations.jl`, aggiorna a `Combinatorics.jl` `v≥1.1.0` oppure esegui il «downgrade» a `v1.0.2`.

~~~~
