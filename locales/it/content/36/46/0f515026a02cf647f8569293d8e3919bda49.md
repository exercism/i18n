# Informazioni

ABAP ha diversi tipi numerici. I più comuni per i piccoli esercizi introduttivi sono `i` per i valori interi e `p` per i valori decimali packed.

Usa `i` quando un valore deve essere un numero intero, come il conteggio dei giorni. Usa un tipo decimale quando un valore può contenere cifre frazionarie, come una tariffa oraria.

```abap
DATA hours_per_day TYPE i VALUE 8.
DATA rate_per_hour TYPE p LENGTH 8 DECIMALS 2 VALUE '89.89'.

DATA day_rate TYPE p LENGTH 8 DECIMALS 2.
day_rate = hours_per_day * rate_per_hour.
```

I numeri packed si usano spesso nelle applicazioni gestionali quando serve un numero fisso di cifre decimali. ABAP ha anche numeri decimali in virgola mobile (`decfloat16` e `decfloat34`) e numeri binari in virgola mobile (`f`). I numeri binari in virgola mobile possono essere utili per i calcoli scientifici, ma non sono una buona scelta predefinita per esempi di tipo monetario, perché molte frazioni decimali non possono essere rappresentate esattamente.
