# Appendice alle istruzioni

## Formato dell'output

Scrivi la sequenza di azioni come stringa terminata da null, usando una virgola e uno spazio come separatori.

## Registri

| Registro | Uso          | Tipo    | Descrizione                          |
| -------- | ------------ | ------- | ------------------------------------ |
| `$a0`    | input        | intero  | numero compreso tra 1 e 31           |
| `$a1`    | input/output | indirizzo | stringa di output terminata da null |
| `$t0-9`  | temporaneo   | qualsiasi | usato per l'archiviazione temporanea |
