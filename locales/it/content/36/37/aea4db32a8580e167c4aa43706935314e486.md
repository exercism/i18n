# Introduzione

Se i tipi dei parametri possono essere inferiti, Swift permette anche di omettere i nomi dei parametri e la parola chiave `in` dalla definizione della closure. Al posto dei parametri si può usare una speciale sintassi abbreviata, in cui `$0` si riferisce al primo parametro, `$1` al secondo, e così via.

```swift
let mean: (Double, Double) -> Double = { $0 + $1 / 2.0 }

["apple", "ball", "carrot"].sorted(by: { $0.count < $1.count })
```
