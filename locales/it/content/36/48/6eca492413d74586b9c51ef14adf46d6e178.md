# Informazioni

Il tipo `Maybe` è la soluzione nel linguaggio Elm per i valori opzionali.
È quindi presente nelle firme di tipo di un gran numero di funzioni principali di Elm e capirlo è cruciale.

## Definizione e variabile di tipo

Il tipo `Maybe` è definito come segue:

```elm
type Maybe a = Nothing | Just a
```

Questa è nota come definizione di «tipo personalizzato» nella terminologia di Elm.
I tipi personalizzati vengono introdotti in dettaglio in un altro concetto di questo percorso, ma non ci serviranno per capire specificamente `Maybe`.
La `a` in `Maybe a` e `Just a` rappresenta una variabile di tipo, cioè può essere qualsiasi tipo, come `Int`, `Bool` o `String`.
Di conseguenza, un `Maybe String` è una variabile che contiene opzionalmente una `String`, mentre un `Maybe Int` conterrebbe opzionalmente un `Int`.

```elm
name : Maybe String
name = Just "Matthieu"

age : Maybe Int
age = Just 29
```

La barra verticale `|` nella definizione del tipo `Maybe` significa «oppure».
Indica che un valore di questo tipo può essere `Nothing` oppure `Just` qualcosa di tipo `a`.
Quindi immagina che il nome e l'età non fossero stati compilati da quella persona: avremmo quanto segue.

```elm
name : Maybe String
name = Nothing

age : Maybe Int
age = Nothing
```

## Leggere il contenuto di un valore Maybe

Leggere il contenuto di un valore `Maybe` si fa tramite il «pattern matching».
Il pattern matching viene introdotto in modo più dettagliato in un altro concetto, quindi ci concentriamo solo su come funziona il pattern matching applicato a un `Maybe`.

```elm
-- This function returns "Hello, <name>!" if the name was provided.
-- Otherwise, it just says "Hello, World!".
sayHello : Maybe String -> String
sayHello maybeName =
    case maybeName of
        Nothing -> "Hello, World!"
        Just someName -> "Hello, " ++ someName ++ "!"

sayHello (Just "Matthieu")
    --> "Hello, Matthieu!"

sayHello Nothing
    --> "Hello, World!"
```

Ogni volta che usi un valore `Maybe`, il compilatore di Elm controllerà che il tuo codice gestisca tutte le possibilità, così non potrai mai fare pattern matching su un `Maybe` gestendo solo il caso in cui c'è un `Just someValue`.
All'inizio può sembrare fastidioso, ma è uno dei più grandi punti di forza del linguaggio Elm.
Questo preverrà centinaia di bug e renderà la riorganizzazione guidata dal compilatore un'esperienza senza timori e gratificante.

## Altre funzioni per manipolare `Maybe`

Nel modulo `Maybe` ci sono anche diverse funzioni utili per manipolare i tipi `Maybe`.

```elm
sayHelloAgain : Maybe String -> String
sayHelloAgain name = "Hello, " ++ Maybe.withDefault "World" name ++ "!"

capitalizeName : Maybe String -> Maybe String
capitalizeName name = Maybe.map String.toUpper name

capitalizeName matthieu
    --> Just "MATTHIEU"

capitalizeName anon
    --> Nothing
```
