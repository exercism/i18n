# Test

## Eseguire i test

Per eseguire i test, esegui il comando seguente:

```bash
call {slug}Test.bat
```

## Risolvere l'esercizio

Risolvere un esercizio significa far passare tutti i suoi test.
Quando tutti i test saranno passati, avrai risolto l'esercizio!

Per aiutarti a iniziare, ogni esercizio include un file di implementazione stub.
Puoi usare questo file come punto di partenza per costruire la soluzione.
Sentiti libero di rimuovere o modificare questo file se pensi che sia la cosa giusta da fare.
