# Informazioni

Quando scriviamo funzioni in Haskell, possiamo usare il [pattern matching][pattern-matching]. Il pattern matching è una funzionalità molto potente di Haskell che ti permette di far corrispondere i costruttori di dati e associare variabili ai valori al loro interno. Come suggerisce il nome, quello che facciamo è far corrispondere i valori ai pattern e, se il valore corrisponde al pattern, possiamo associare variabili ai valori all'interno del pattern. Il pattern matching si basa principalmente su questi concetti: riconoscere valori, associare variabili e scomporre valori.

~~~~exercism/note
Il pattern matching in linguaggi come Elixir è un po' diverso dal pattern matching in Haskell. Elixir, per esempio, permette di usare più volte lo stesso nome di associazione in un pattern, mentre Haskell no.
~~~~


Prendiamo questa funzione come esempio:

```haskell
lucky :: Int -> String
lucky 7 = "Lucky number seven!"
lucky x = "Sorry, you're out of luck, pal!"
```

Qui abbiamo una funzione `lucky` che prende un `Int` e restituisce una `String`. Abbiamo definito due pattern per la funzione: uno che corrisponde al numero `7` e uno che corrisponde a qualsiasi altro numero. Il nome può essere qualsiasi cosa (purché segua le convenzioni di denominazione di Haskell), ma qui usiamo `x`. Se il numero è `7`, la funzione restituirà `"Lucky number seven!"`, altrimenti restituirà `"Sorry, you're out of luck, pal!"`. È importante notare che i pattern vengono controllati dall'alto verso il basso, quindi se avessimo scambiato l'ordine dei pattern, la funzione restituirebbe sempre `"Lucky number seven!"`.

## Pattern con le liste

Un pattern molto comune è far corrispondere le liste, cioè prendere la testa e la coda della lista. Questo dipende dal fatto che le liste sono liste concatenate. Ecco un esempio di funzione che restituisce la testa e la coda di una lista:

```haskell
headAndTail :: [Int] -> (Int, [Int])
headAndTail [] = error "Can't call head on an empty list"
headAndTail (x:xs) = (x, xs)
```

Qui abbiamo due pattern: uno che corrisponde a una lista vuota e uno che corrisponde a una lista con almeno un elemento. Questo perché se la lista è vuota dobbiamo avere un caso per quella situazione, altrimenti otterremmo un errore a runtime. Se la lista non è vuota, possiamo far corrispondere la testa della lista a `x` e la coda a `xs`. Questo si fa usando l'operatore `:` (cons), che serve ad anteporre un elemento a una lista. Ma nel pattern matching ci permette di scomporre una lista nella sua testa e nella sua coda, facendo in un certo senso l'opposto.

`xs` è un nome comune per la coda di una lista, evidenzia che si tratta di una lista; ma se lavorassi con una lista annidata, potresti usare `xss` per evidenziare che è una lista di liste.

## Pattern con le tuple

Come per le liste, possiamo far corrispondere anche le tuple. Ecco un esempio di funzione che prende una tupla e restituisce il primo e il secondo elemento:

```haskell
sumTuple :: (Int, Int) -> Int
sumTuple (x, y) = x + y
```

Qui abbiamo un pattern che corrisponde a una tupla con due elementi: il primo elemento è associato a `x` e il secondo a `y`.

## Pattern jolly

A volte non ci interessa il valore di una variabile, vogliamo solo far corrispondere il pattern. Qui entra in gioco il pattern jolly, indicato da un underscore `_`.

Ecco un esempio di funzione che restituisce il primo elemento di una lista:

```haskell
head' :: [Int] -> Int
head' [] = error "Can't call head on an empty list"
head' (x:_) = x
```

Qui diciamo che non ci serve la coda della lista, quindi usiamo il pattern jolly per ignorarla.

## Pattern di tipo

Possiamo anche far corrispondere i tipi, e questo si fa usando il costruttore di quel tipo. Possiamo anche estrarre valori dal tipo, come abbiamo fatto con le tuple.

```haskell
data AccountType = Guest | User String 

greet :: AccountType -> String
greet Guest = "Welcome, guest!"
greet (User name) = "Welcome, " ++ name ++ "!"
```

Nel primo pattern facciamo corrispondere il costruttore `Guest`, nel secondo il costruttore `User` e associamo il valore al suo interno a `name`.
