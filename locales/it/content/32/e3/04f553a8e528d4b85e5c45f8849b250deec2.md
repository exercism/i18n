# Appendice alle istruzioni

## Messaggi delle eccezioni

A volte è necessario [sollevare un'eccezione](https://docs.python.org/3/tutorial/errors.html#raising-exceptions). Quando lo fai, dovresti includere sempre un **messaggio di errore significativo** per indicare quale sia l'origine dell'errore. Rende il codice più leggibile e aiuta molto nel debug. Quando sai che l'origine dell'errore sarà di un certo tipo, puoi scegliere di sollevare uno dei [tipi di errore predefiniti](https://docs.python.org/3/library/exceptions.html#base-classes), ma dovresti comunque includere un messaggio significativo.

Questo esercizio richiede in particolare di usare la [istruzione raise](https://docs.python.org/3/reference/simple_stmts.html#the-raise-statement) per «lanciare» un `ValueError` quando l'argomento passato non è un letterale binario valido. I test passeranno solo se esegui il `raise` dell'`exception` ed ci includi un messaggio.

Per sollevare un `ValueError` con un messaggio, scrivi il messaggio come argomento del tipo `exception`:

```python
# example when the argument passed is not a valid binary literal
raise ValueError("Invalid binary literal: " + digits)
```
