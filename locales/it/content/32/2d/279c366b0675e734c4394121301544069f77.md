# Introduzione

A volte non serve il costo aggiuntivo di creare un oggetto con uno stato.
In questi casi, si può usare un `module`.

Un modulo è molto simile a una classe (in realtà, `Module` è un antenato di `Class` nella gerarchia degli oggetti); la differenza principale è che, invece di usare metodi di istanza, usiamo metodi di classe.
I metodi di classe iniziano con `self.` e vengono chiamati direttamente su un modulo.

Per esempio:

```ruby
module Speaker
  def self.echo(something)
    "#{something} ... #{something}"
  end
end

Speaker.echo("Hello")   #=> "Hello ... Hello"
```
