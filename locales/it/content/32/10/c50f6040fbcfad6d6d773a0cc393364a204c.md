# Informazioni

Le tuple si usano comunemente per raggruppare informazioni in modo informale. Un pattern comune in Elixir è raggruppare i valori restituiti da una funzione insieme a uno stato.

```elixir
File.read("hello.txt")
# => {:ok, "World"}

File.read("invalid.txt")
# => {:error, :enoent}
```

- I letterali di tupla si scrivono tra parentesi graffe, `{}`.
- Le tuple possono contenere dati di qualsiasi tipo in memoria contigua, che viene allocata quando la tupla viene creata.
- Le tuple permettono un accesso in lettura in tempo costante.
- Quando si manipola una tupla, invece di modificare quella esistente, se ne crea una nuova.
- Le caratteristiche prestazionali delle tuple le rendono ideali per conservare insieme informazioni correlate, ma non per conservare collezioni di elementi da iterare o che potrebbero crescere o ridursi. In quest'ultimo caso, [un array è più adatto][getting-started-lists-or-tuples].
- I moduli [`Kernel`][kernel-module] e [`Tuple`][tuple-module] offrono funzioni utili per lavorare con le tuple.
