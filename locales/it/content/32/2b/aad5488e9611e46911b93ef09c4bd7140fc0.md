# Appendice alle istruzioni

L'elevamento a potenza di numeri razionali con un numero reale richiede di calcolare un numero elevato a un esponente non intero, una funzionalità che non è disponibile in modo nativo in WebAssembly.

Tuttavia, puoi anche esprimere `x ^ y` come `x ^ y = exp(y * ln(x))`.

E per fortuna si possono usare serie diverse per calcolare l'esponenziale e il logaritmo naturale.

## Funzione esponenziale

La soluzione migliore per l'esponenziale è una [serie di Taylor](https://en.wikipedia.org/wiki/Taylor_series):

```
exp(x) ≃ 1 + x + x ^ 2 / 2! + x ^ 3 / 3! + x ^ 4 / 4! + ... + x ^ n / n!
```

## Funzione logaritmo (per x positivo)

Ci sono diversi modi per calcolare in modo efficiente un logaritmo naturale. Uno di questi è una serie basata su una [tangente iperbolica inversa](https://en.wikipedia.org/wiki/Logarithm#Inverse_hyperbolic_tangent):

```
ln(x) / 2 ≃ y + y ^ 3 / 3 + y ^ 5 / 5 + ... + y ^ n / n where y = (x - 1) / (x + 1)
```

C'è anche un'altra serie di Taylor per calcolare il logaritmo naturale:

```
ln(x) = (x - 1) - (x - 1) ^ 2 / 2 + (x  - 1) ^ 3 / 3 - (x - 1) ^ 4 / 4 ... + (x - 1) ^ n / n
```

È accurata solo per `x` compreso tra 0 e 2. Tuttavia possiamo anche usare `ln(x) = - ln(1 / x)`

## Elevamento a potenza con esponente intero

Per l'elevamento a potenza con esponente intero, è meglio usare la moltiplicazione ed un ciclo oppure la ricorsione, sia per motivi di prestazioni sia di precisione. Per prestazioni ancora migliori, si può usare il [metodo di Horner](https://en.wikipedia.org/wiki/Horner%27s_method) per ridurre il numero di moltiplicazioni.
