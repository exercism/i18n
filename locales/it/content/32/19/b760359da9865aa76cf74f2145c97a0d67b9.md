# Introduzione

Una `list` in R è una collezione ordinata di elementi, che differisce dai `vectors` per alcuni aspetti:

- Gli elementi possono essere di tipi diversi (ad esempio mescolare `numeric` con `character`).
- Gli elementi possono essere strutture complesse (ad esempio vettori, altre liste, ecc.).
- Esiste una sintassi diversa per accedere agli elementi.

Le analogie con altri linguaggi sono imprecise.
Una `list` di R è in qualche modo simile a un dizionario Python, ma è ordinata e accessibile tramite indice numerico.
È in qualche modo simile a una `struct` di C, tranne per il fatto che la `list` può essere facilmente estesa a runtime.

## Creazione di liste

Dare nomi (spesso chiamati «tag») agli elementi è più comune con le liste che con i vettori:

```R
list(x = 5.3, y = 4.2, color = "blue")
$x
#> [1] 5.3

$y
#> [1] 4.2

$color
#> [1] "blue"
```

Tuttavia, i tag sono opzionali e R userà semplicemente i numeri di indice:

```R
list(5.3, 4.2, "blue")
#> [[1]]
#> [1] 5.3

#> [[2]]
#> [1] 4.2

#> [[3]]
#> [1] "blue"
```

## Accesso agli elementi di una lista

Ci sono tre modi per farlo, ognuno utile in contesti diversi.

### 1. Con la notazione `$tag`

Molto comune se i nomi dei tag sono noti in anticipo.

```R
point <- list(x = 5.3, y = 4.2, color = "blue")
point$x
#> [1] 5.3
point$color
#> [1] "blue"
```

### 2. Con la notazione `[[tag]]`

Questo ha il vantaggio che il nome del tag può essere scelto a runtime.
Nota le doppie parentesi quadre.

```R
want <- "y"
point[[want]] # same as point$y
#> [1] 4.2
```

### 3. Con l'indice di posizione

Funziona sia che la lista abbia dei tag, sia che non ne abbia.
Anche qui, le parentesi sono doppie.

```R
point[[3]] # same as point$color
#> [1] "blue"
```

## Aggiungere ed eliminare elementi

Semplice: assegnare un valore a un elemento lo modifica se esiste, oppure lo inserisce se è nuovo.

```R
point$color <- "red"
point$trust <- TRUE
str(point)
#> List of 4
#>  $ x    : num 5.3
#>  $ y    : num 4.2
#>  $ color: chr "red"
#>  $ trust: logi TRUE
```

Per eliminarlo, assegna `NULL` all'elemento indesiderato.

```R
point$trust <- NULL
str(point)
#> List of 3
#>  $ x    : num 5.3
#>  $ y    : num 4.2
#>  $ color: chr "red"
```
