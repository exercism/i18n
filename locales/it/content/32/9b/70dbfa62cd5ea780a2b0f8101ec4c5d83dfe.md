# Introduzione

Oltre all'istruzione if, JavaScript ha anche l'istruzione switch per eseguire della logica in modo condizionale.
Si usa quando una singola variabile deve essere confrontata con più varianti.
Il confronto avviene verificando l'uguaglianza stretta (`===`), vedi [il concetto di confronto][concept-comparison].
Per una variabile `x`, l'istruzione switch in JavaScript ha la seguente sintassi.

<!-- prettier-ignore-start -->
```javascript
switch (x) {
  case option1:
    // code that is executed when "x === option1" is true
    break;
  case option2:
    // code that is executed when "x === option2" is true
    break;
  default:
    // code that is executed when x does not equal any of the options
}
```
<!-- prettier-ignore-end -->

Il caso `default` è opzionale e si usa quando vuoi eseguire del codice se nessuna delle altre opzioni corrisponde alla variabile.

Le istruzioni `break` qui sopra sono necessarie perché, per impostazione predefinita, in JavaScript tutti i casi sono «fallthrough».
Questo significa che, senza alcuna istruzione `break`, verrebbe eseguito tutto il codice dei casi che seguono la prima opzione corrispondente, anche se `x` non corrispondeva a quelle opzioni.
Questo comportamento di «fallthrough» predefinito è una trappola comune quando si usa `switch` in JavaScript.
All'interno di una funzione, si può anche usare `return` al posto di `break` per evitare questo problema.
