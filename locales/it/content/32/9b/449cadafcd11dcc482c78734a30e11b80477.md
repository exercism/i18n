# Suggerimenti

## Generali

- Leggi le [comprensioni][elixir-comprehensions] nella guida Getting Started.
- Leggi le [liste][elixir-lists] nella guida Getting Started.
- Leggi le [mappe][elixir-maps] nella guida Getting Started.
- Leggi le [keyword list][elixir-kwlists] nella guida Getting Started.

## 1. Suggerisci una combinazione

- Nella comprensione di liste, usa due _generatori_ per creare il prodotto cartesiano.

## 2. Escludi gli abbinamenti che stonano

- Puoi usare il _pattern matching_ per destrutturare all'interno del _generatore_ e associare i campi a una variabile.
- Usa un'_espressione di filtro_ per restituire false quando i colori di base coincidono.

## 3. Filtra per prezzo della combinazione

- Ci sono diverse [funzioni delle keyword list][kw-module] che puoi usare per recuperare le opzioni da una keyword list.
- Usa un'_espressione di filtro_ per restituire false quando il prezzo combinato è maggiore del prezzo massimo.
