# Introduzione

## Caratteri

### I char

Il tipo primitivo `char` di Java è una rappresentazione a 16 bit di un singolo carattere.
Più `char` possono comporre una stringa, come `"word"`, oppure i `char` possono essere elaborati singolarmente.
Un letterale `char` è racchiuso tra virgolette singole (ad esempio `'A'`).

```java
char lowerA = 'a';
char upperB = 'B';
```

### Ottenere i `char` di una `String`

Il metodo `String.toCharArray` restituisce i char di una String come array.
Come accennato negli array, puoi usare un ciclo `for` per iterare sull'array.

```java
String text = "Hello";
char[] asArray = text.toCharArray();

for (char ch: asArray) {
    System.out.println(ch);
}

// Outputs:
// H
// e
// l
// l
// o
```

### La classe Character

Ci sono molti metodi di libreria integrati per ispezionare e manipolare i `char`.
Puoi trovarli come metodi statici della classe `java.lang.Character`.
Ecco alcuni esempi:

```java
Character.isWhitespace(' ');    // true
Character.isWhitespace('#');    // false

Character.isLetter('a');        // true
Character.isLetter('3');        // false

Character.isDigit('6');         // true
Character.isDigit('?');         // false
```

### Aggiungere un `char` a una `String`

L'operatore `+` può essere usato per aggiungere un `char` a una `String`.

```java
'a' + " banana"     // => "a banana"
"banana " + 'a'     // => "banana a"
```

~~~~exercism/caution
Fai attenzione a _non_ usare `+` per unire due `char` insieme per formare una `String`!
Aggiungere due `char` in questo modo dà un `int`, _non_ una `String`!
Per esempio:

```java
'b' + 'c';
// => 197 (not the String "bc")
```

Questo perché Java promuove il `char` ad un `int` (vedi [4.2 Primitive Types and Values ][jls-primitives] della [Java Language Specification][jls-main]).

[jls-main]: https://docs.oracle.com/javase/specs/jls/se21/html/
[jls-primitives]: https://docs.oracle.com/javase/specs/jls/se21/html/jls-4.html#jls-4.2
~~~~

Tuttavia, quando ci sono molti caratteri da aggiungere, può essere più efficiente usare uno `StringBuilder`:

```java
StringBuilder builder = new StringBuilder();
builder.append('a');
builder.append('b');
builder.append('c');

String builtString = builder.toString();
// => abc
```
