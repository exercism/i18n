# Usa la ricorsione in coda

Lo scopo di questo esercizio è insegnare la ricorsione in coda. Risolvilo senza usare funzioni ricorsive che non siano in coda.

Funzioni ricorsive in coda trovate nella soluzione: %{tail_call_recursive_functions}. Altre funzioni ricorsive trovate nella soluzione: %{non_tail_call_recursive_functions}.

Ricorda: la ricorsione in coda si ha quando l'_ultima_ espressione valutata dalla funzione è una chiamata a se stessa.

```elixir
# this is tail call recursion,
# the last expression is a call to `do_encode`
defp do_encode([n | rest], acc) do
  do_encode(rest, <<acc::bitstring, encode_nucleotide(n)::4>>)
end

# this is not tail call recursion,
# the last expression is a call to `<<>>`
def encode([head | tail]) do
  <<encode_nucleotide(head)::4, encode(tail)::bitstring>>
end
```
