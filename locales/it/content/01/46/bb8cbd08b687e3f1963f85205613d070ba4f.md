# Introduzione

I condizionali sono istruzioni che eseguono codice diverso a seconda che una condizione sia `true` o `false`.

Un'istruzione `if` esegue il suo corpo solo quando la sua condizione è `true`.
Go non ha il concetto di valori «truthy» o «falsy», quindi la condizione deve essere di tipo `bool`.
Espressioni come `if mySlice { ... }` o `if 1 { ... }` sono errori di compilazione.

```go
func describe(val string) string {
    if val == "val" {
        return "was val"
    }
    return "was not val"
}
```

Usa `else if` per verificare condizioni aggiuntive e `else` come ripiego se nessuna corrisponde.
Le condizioni vengono valutate dall'alto verso il basso e verrà eseguito solo il primo ramo la cui condizione è vera.

```go
number := 0
result := "This number is "

if number > 0 {
    result += "positive"
} else if number < 0 {
    result += "negative"
} else {
    result += "zero"
}
```

Un'istruzione `if` può anche includere una breve istruzione di inizializzazione.
Le variabili dichiarate in questo modo sono nello scope solo all'interno dell'intera catena `if`/`else`.

```go
num := 7
if v := 2 * num; v > 10 {
    fmt.Println(v)
} else {
    fmt.Println(num)
}
// Output: 14
```
