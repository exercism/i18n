# Introduzione

## Le stringhe

Una `string` in F# è un oggetto che rappresenta testo immutabile come sequenza di caratteri Unicode (lettere, cifre, segni di punteggiatura, ecc.) e si definisce così:

```fsharp
let fruit = "Apple"
```

Le stringhe si manipolano chiamando i metodi della stringa oppure usando le funzioni del modulo `String`. Una volta costruita, una stringa non può più cambiare valore. Qualsiasi metodo o funzione che sembri modificare una stringa in realtà restituisce una nuova stringa.

Le stringhe si possono concatenare o formattare in diversi modi.
* Puoi usare l'operatore `+` per la concatenazione:
```fsharp
let sentence = "Apple" + " is a type of fruit."
```
* Puoi usare la funzione `sprintf` per formattare il testo, dove hai dei segnaposto in un testo di formato (`%s` per una `string`) e fornisci i valori come argomenti:
```fsharp
let sentence = sprintf "%s is a type of %s." "Apple" "fruit"
```
