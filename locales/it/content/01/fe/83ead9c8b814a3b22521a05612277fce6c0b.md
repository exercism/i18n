# Funzioni

Le funzioni sono fondamentali in Cairo.

Per convenzione, Cairo usa lo **snake case** per i nomi di funzioni e variabili: le parole sono in minuscolo e separate da underscore.

Ecco un esempio:

```rust
fn another_function() {
    println!("Another function.");
}

fn main() {
    println!("Hello, world!");
    another_function();
}
```

Le funzioni si definiscono con `fn`, seguito da un nome, da una coppia di parentesi per i parametri (se ce ne sono) e da un corpo racchiuso tra parentesi graffe.

Puoi chiamare una funzione scrivendo il suo nome seguito da una coppia di parentesi tonde (`()`).

L'ordine delle funzioni non ha importanza, purché siano nello scope.

## Parametri

Le funzioni possono accettare dei **parametri**, cioè variabili definite nella firma della funzione.

Quando chiami la funzione, fornisci gli **argomenti**, cioè i valori passati a questi parametri.

```rust
fn main() {
    another_function(5);
}

fn another_function(x: felt252) {
    println!("The value of x is: {}", x);
}
```

Qui, `x` è un parametro di tipo `felt252`.

Chiamata con `5`, la funzione stampa «The value of x is: 5».

Più parametri sono separati da virgole:

```rust
fn main() {
    print_labeled_measurement(5, "h");
}

fn print_labeled_measurement(value: u128, unit_label: ByteArray) {
    println!("The measurement is: {value}{unit_label}");
}
```

Questo stampa: `The measurement is: 5h`.

## Istruzioni ed espressioni

Le funzioni in Cairo sono composte da **istruzioni** ed **espressioni**:

- Le **istruzioni** compiono azioni ma non restituiscono valori.
Per esempio, `let x = 3;` è un'istruzione.
- Le **espressioni** producono un valore.
Per esempio, `5 + 6` produce `11`.

Anche i blocchi racchiusi tra parentesi graffe sono espressioni, e il loro valore finale viene restituito:

```rust
fn main() {
    let y = {
        let x = 3;
        x + 1
    };
    println!("The value of y is: {}", y);
}
```

Qui, a `y` viene assegnato il valore `4`.

## Valori restituiti

Le funzioni possono restituire valori usando la sintassi `->` per specificare il tipo restituito.

Per impostazione predefinita, una funzione restituisce il valore della sua espressione finale:

```rust
fn five() -> u32 {
    5
}

fn main() {
    let x = five();
    println!("The value of x is: {}", x);
}
```

Questo stampa: `The value of x is: 5`.

Per casi più complessi:

```rust
fn plus_one(x: u32) -> u32 {
    x + 1
}

fn main() {
    let x = plus_one(5);
    println!("The value of x is: {}", x);
}
```

Questo stampa: `The value of x is: 6`.

Fai attenzione a non aggiungere un punto e virgola alla fine dell'espressione finale: trasformerebbe l'espressione in un'istruzione, facendo sì che la funzione restituisca `()` (tipo unit) invece del valore atteso.
