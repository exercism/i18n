# Appendice alle istruzioni

## Formato dell'output

Produci il testo della canzone come una stringa terminata da null.

## Registri

| Registro | Utilizzo     | Tipo      | Descrizione                          |
| -------- | ------------ | --------- | ------------------------------------ |
| `$a0`    | input        | intero    | verso iniziale                       |
| `$a1`    | input        | intero    | verso finale                         |
| `$a2`    | input/output | indirizzo | stringa di output terminata da null  |
| `$t0-9`  | temporaneo   | qualsiasi | per la memorizzazione temporanea     |
