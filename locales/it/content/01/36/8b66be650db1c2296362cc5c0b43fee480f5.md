# Debug

Puoi usare [Debug.log](https://package.elm-lang.org/packages/elm/core/latest/Debug#log) per allegare messaggi ai test che falliscono, così:

```elm
hoursToSeconds : Int -> Int
hoursToSeconds hours =
    let
        secondsInOneHour =
            Debug.log "secondsInOneHour" (60 * 60)
    in
    hours * secondsInOneHour
```

Su un test che fallisce, il log allegato sarà `secondsInOneHour: 3600`.

C'è una sola accortezza: le costanti di primo livello vengono valutate una sola volta prima che i test inizino a essere eseguiti, quindi i test non possono catturare i loro messaggi di log. Per esempio:

```elm
secondsInOneHour : Int
secondsInOneHour =
    Debug.log "secondsInOneHour" (60 * 60)
```

non produrrà alcun log durante i test, perché la variabile JavaScript associata a `secondsInOneHour` è già stata valutata al valore 3600.
