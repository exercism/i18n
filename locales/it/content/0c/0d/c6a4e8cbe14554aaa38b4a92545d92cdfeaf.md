# Debug

Quando un test fallisce, viene mostrato un messaggio che descrive cosa è andato storto e per quale input. Puoi anche sfruttare il fatto che viene mostrato anche qualsiasi [output della console][dotnetperls.com-console-vbnet]. Per scrivere sulla console puoi usare:

```vbnet
Console.WriteLine("Debug message");
```

[dotnetperls.com-console-vbnet]: https://www.dotnetperls.com/console-vbnet
