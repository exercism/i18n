# non modificare le firme fornite

Come accennato nelle istruzioni, non devi modificare le firme di `makeChest` e `makeTreasureChest`.
Devono rimanere esattamente queste:

```elm
makeChest : String -> treasure -> Chest treasure {}

makeTreasureChest : Chest treasure { conditions | securePassword : (), uniqueTreasure : () } -> TreasureChest treasure
```
