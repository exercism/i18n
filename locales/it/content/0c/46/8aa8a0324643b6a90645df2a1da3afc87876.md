# Istruzioni

Gestisci un cinema esclusivo.
Per assistere a un film, le persone devono acquistare un abbonamento annuale, poi possono assistere ai film gratuitamente.

Il tuo cinema tiene un registro degli ingressi.
Vuoi usare quel registro per tenere traccia di quali soci hanno usato il loro abbonamento annuale questo mese.
Vuoi anche ottenere informazioni sulle fasce d'età dei tuoi clienti.
Ti rendi conto che puoi usare gli insiemi per raggiungere questi obiettivi.

## Gli insiemi

Un insieme è il tipo di dato perfetto per memorizzare questo tipo di dati.

Un insieme è un tipo di dato usato per memorizzare valori distinti e univoci, senza un ordine particolare.
Distinto e univoco significa che un elemento o è nell'insieme o non lo è: a differenza di quanto accade con un array, non può trovarsi nell'insieme più volte.
Gli insiemi in genere non sono ordinati: se elenchi gli elementi di un insieme, l'ordine che ottieni può essere diverso da quello in cui sono stati aggiunti, o persino diverso da quello che hai ottenuto nell'elenco precedente!

Una proprietà fondamentale degli insiemi è la verifica di appartenenza: la capacità di controllare se un insieme contiene un elemento.
La verifica di appartenenza è alla base di quasi tutti gli usi di un insieme.

Go non fornisce un tipo di dato insieme integrato nel linguaggio.
È comune usare una `map[<type>]struct{}` o una `map[<type>]bool` al posto di un insieme; come un insieme, una `map` permette di aggiungere elementi distinti e univoci e supporta la verifica di appartenenza.

## 1. Un posto dove memorizzare le informazioni sui partecipanti

Per tenere traccia delle presenze e delle fasce d'età, vuoi usare un insieme.

Non vuoi scrivere insiemi separati per i nomi e per le età: invece, puoi usare un insieme generico per entrambi.
Definisci un tipo `Set` come `map[T comparable]struct{}` per memorizzare i partecipanti.
Scrivi una funzione `NewSet[T comparable]()` che restituisce un `Set[T]` vuoto.

```go
names := NewSet[string]()
```

## 2. Tenere traccia dei partecipanti

Adesso è tutto pronto per registrare le informazioni sui partecipanti.

Scrivi un metodo `Add[T]()` che aggiunge un elemento all'insieme.

```go
names := NewSet[string]()
names.Add("Alice")
```

## 3. Controllare i partecipanti

Ora che hai un insieme di partecipanti, puoi controllare se determinati soci e determinate fasce d'età si sono presentati.
Scrivi un metodo `Contains[T](element)` che restituisce se un socio o una fascia d'età è nel `Set`.

```
names := NewSet[string]()
names.Add("Alice")
names.Contains("Alice")
// => true
names.Contains("Bob")
// => false
```

## 4. Confrontare i partecipanti

È passato un altro mese e hai un nuovo `Set` di fasce d'età.
Il tuo responsabile marketing vuole sapere se le nuove uscite di questo mese hanno cambiato le fasce d'età che si presentano.
Scrivi un metodo `Equals[T](other)` che determina se due insiemi hanno gli stessi elementi.

```go
agesOne := NewSet[int]()
names.Add(25)

agesTwo := NewSet[int]()
names.Add(25)

agesOne.Equals(agesTwo)
// => true

agesThree := NewSet[int]()
names.Add(35)

agesOne.Equals(agesThree)
// => false
```
