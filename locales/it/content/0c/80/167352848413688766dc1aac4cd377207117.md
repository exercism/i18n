# Informazioni

La ricorsione è un modo per ripetere del codice all'interno di una funzione, facendo sì che la funzione chiami se stessa.
È un altro modo per eseguire un ciclo, cioè per iterare. Come nei cicli, la funzione dovrebbe verificare un'espressione booleana per sapere quando fermarsi.
A differenza dei cicli, però, una ricorsione che non finisce mai non continua all'infinito.
I valori usati in ogni chiamata di funzione possono essere collocati in uno stack frame dedicato.
Se il numero di chiamate di funzione occupa più spazio di quanto ne abbia lo stack, si ottiene un errore di stack overflow.

```c
int printIncrement (int i, int maxValue){
    if (i > maxValue) return i;
    printf("The number is %i\n", i++);
    printIncrement(i, maxValue);
}

int main() {
    printIncrement(1, 2);
    printf("After recursion");
    return 0;
}
```

Questo stamperà

```
The number is 1
The number is 2
After recursion
```

Ci sono situazioni che, espresse con la ricorsione, risultano più leggibili e/o più facili da seguire rispetto a quando le si esprime con un ciclo.


## Chiamata di coda

Una chiamata di coda si ha quando l'ultima istruzione di una funzione chiama soltanto se stessa, nient'altro.

La chiamata di coda è una forma particolare di ricorsione che può permettere al compilatore di ottimizzare la ricorsione trasformandola in un ciclo nel codice compilato.
Così si ottiene il meglio dei due mondi: la leggibilità della ricorsione con le prestazioni di un ciclo.
La compilazione della ricorsione in un ciclo si chiama `tail call elimination` o `tail call optimization.`

Quando una chiamata di coda viene compilata in un ciclo, non viene creato un nuovo stack frame per ogni chiamata di funzione.
All'indirizzo della funzione chiamata originariamente vengono passati i valori aggiornati, risparmiando così spazio sullo stack e migliorando le prestazioni.

Questo esempio non è una chiamata di coda, perché la funzione somma 1 al risultato della chiamata a se stessa

```c
int printIncrement (int i, int maxValue){
    if (i > maxValue) return 1;
    printf("The number is %i\n", i++);
    return 1 + printIncrement(i, maxValue);
}

int main() {
    int j = printIncrement(1, 2);
    printf("j is %i after recursion", j);
    return 0;
}
```

Questo stamperà

```
The number is 1
The number is 2
j is 3 after recursion
```

Per riorganizzarlo in una chiamata di coda, rendi `j` un parametro di `printIncrement`

```c
int printIncrement (int i, int maxValue, int j){
    if (i > maxValue) return j;
    printf("The number is %i\n", i++);
    return printIncrement(i, maxValue, ++j);
}

int main() {
    int j = printIncrement(1, 2, 1);
    printf("j is %i after recursion", j);
    return 0;
}
```

Potresti scoprire che una chiamata di coda è più facile da seguire di una chiamata ricorsiva che non è una chiamata di coda.
Tuttavia, di solito i compilatori non garantiscono che tutte le chiamate di coda vengano ottimizzate.
Quando si usa la ricorsione, è sempre importante assicurarsi che le iterazioni non siano così tante da provocare un overflow dello stack.
