# Informazioni

L'[operatore condizionale ternario][ternary-operator] è una forma abbreviata e concisa di un'espressione `if-else`.
Valuta una condizione e restituisce uno dei due valori, a seconda che quella condizione sia `true` o `false`.

L'operatore usa tre parti: `condition ? trueExpression : falseExpression`.
Se `condition` vale `true`, viene valutata e restituita `trueExpression`; altrimenti, viene valutata e restituita `falseExpression`.

L'operatore ternario è ideale per scelte semplici, su una sola riga:

```swift
let showFahrenheit = true
let temperatureInCelsius = 30

let temperature = showFahrenheit ? temperatureInCelsius * 9 / 5 + 32 : temperatureInCelsius
print(temperature)
// Prints 86
```

L'esempio qui sopra è l'equivalente compatto di:

```swift
let showFahrenheit = true
let temperatureInCelsius = 30

let temperature = if showFahrenheit {
    temperatureInCelsius * 9 / 5 + 32
} else {
    temperatureInCelsius
}
```

[ternary-operator]: https://docs.swift.org/swift-book/LanguageGuide/BasicOperators.html#ID71
