# Insegne personalizzate

## Storia

In questo esercizio scriverai del codice per aiutare un'azienda di insegne a creare messaggi personalizzati per le sue insegne.

## Attività

Questi sono esempi di attività che si adattano alla storia di un cliente che progetta un'insegna personalizzata:

- Creare una serie di stringhe utili
- Creare una serie di caratteri utili
- Combinare frasi per comporre messaggi
- Costruire un'insegna di laurea
- Calcolare il costo di un'insegna
