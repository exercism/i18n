# Informazioni

Oltre a `cond`, Elixir fornisce anche la macro [`if/2`][getting-started-if], utile quando devi verificare una sola condizione.

[`if/2`][kernel-if] accetta una condizione e due opzioni. Restituisce la prima opzione se la condizione è _truthy_ e la seconda se la condizione è _falsy_.

```elixir
age = 15

if age >= 16 do
  "You are allowed to drink beer in Germany."
else
  "No beer for you!"
end

# => "No beer for you!"
```

Se la seconda opzione non viene fornita, viene restituito `nil`.

```elixir
age = 15

if age >= 16 do
  "You are allowed to drink beer in Germany."
end

# => nil
```

È anche possibile scrivere un'espressione `if` su una sola riga. Nota la virgola dopo la condizione.

```elixir
if age >= 16, do: "beer", else: "no beer"
```

Questa sintassi è utile per espressioni molto brevi, ma è da evitare se l'espressione non entra in una sola riga.

## _Truthy_ e _falsy_

In Elixir, tutti i tipi di dato restituiscono un valore _truthy_ o _falsy_ quando vengono incontrati in un contesto booleano (come un'espressione `if`). Tutti i dati sono considerati _truthy_ **tranne** `false` e `nil`. In particolare, le stringhe vuote, il numero intero `0` e gli array vuoti sono tutti considerati _truthy_ in Elixir. Sotto questo aspetto, [Elixir è simile a Ruby ma diverso da JavaScript, Python o PHP][falsy-various-langs].

```elixir
truthy? = fn x -> if x, do: "truthy", else: "falsy" end

truthy?.(true)
# => "truthy"
truthy?.(0)
# => "truthy"
truthy?.([])
# => "truthy"

truthy?.(false)
# => "falsy"
truthy?.(nil)
# => "falsy"
```

[`&&/2`][kernel-and], [`||/2`][kernel-or] e [`!/1`][kernel-not] sono operatori booleani _truthy_ che funzionano con qualsiasi valore e che completano gli operatori booleani _strict_ [`and/2`][kernel-boolean-and], [`or/2`][kernel-boolean-or] e [`not/1`][kernel-boolean-not].

```elixir
0 and true
# => ** (BadBooleanError) expected a boolean on left-side of "and", got: 0

0 && true
# => true
```
