# Istruzioni

Tori è una giornalista climatica e vuole scrivere un articolo sul meteo in diverse città. Ha dei dati sul meteo in diverse città e vuole classificarle in base alla loro temperatura, ma alcune temperature sono in Fahrenheit e altre in Celsius. Ha bisogno del tuo aiuto per convertire le temperature nella stessa unità e classificarle.

## 1. Converti i Fahrenheit in Celsius

Definisci la funzione `fahrenheit_to_celsius` che prende una temperatura in Fahrenheit come argomento e restituisce la temperatura in Celsius.

Per convertire i Fahrenheit in Celsius, sottrai 32 dal valore in Fahrenheit e poi dividi il risultato per 1.8.

```gleam
fahrenheit_to_celsius(72.5)
// -> 22.5
```

## 2. Confronta due temperature

Definisci la funzione `compare_temperature` che prende due temperature e restituisce un valore `Order` che indica se la prima temperatura è minore, uguale o maggiore della seconda.

```gleam
compare_temperature(Celsius(30.5), Fahrenheit(82.1))
// -> Gt
```

## 3. Ordina le città per temperatura

Definisci la funzione `sort_cities_by_temperature` che prende un array di città e le restituisce dalla più fredda alla più calda.

```gleam
sort_cities_by_temperature([
  City(name: "London", temperature: Celsius(30.5)),
  City(name: "Paris", temperature: Fahrenheit(82.1))
])
// -> [
//   City(name: "Paris", temperature: Fahrenheit(82.1)),
//   City(name: "London", temperature: Celsius(30.5)))
// ]
```
