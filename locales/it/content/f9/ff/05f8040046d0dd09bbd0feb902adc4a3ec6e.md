# Informazioni

Un'espressione booleana è una domanda posta a uno o più valori, a cui si può rispondere con `true` o `false`.
Un'espressione vera restituisce `1`; un'espressione falsa restituisce `0`.
Inoltre, i numeri hanno un valore di verità. Lo zero è `false`; un valore diverso da zero è `true`.

Il vecchio codice C usa direttamente il tipo `int` per i valori booleani, oppure il programmatore può aver definito costanti come `TRUE` e `FALSE` per associare `1` e `0` a una rappresentazione booleana.

Con la versione C99 è stato aggiunto il tipo `_Bool`.
Il file di intestazione `stdbool.h` definisce tre nuovi simboli booleani: `bool`; `true` e `false`.
`true` corrisponde a `1`; `false` corrisponde a `0`; e `bool` corrisponde a `_Bool`.
Quindi ora, invece di usare direttamente gli `int` o di inventarsi le proprie mappature booleane, i programmatori possono includere `stdbool.h` e ottenere automaticamente i simboli booleani nel proprio codice.

## Operatori di confronto

C supporta sei operatori di confronto: `==` (uguale), `!=` (diverso da), `>` (maggiore di), `<` (minore di), `>=`(maggiore o uguale a), `<=` (minore o uguale a).
Questi operatori confrontano le relazioni tra i valori e le risolvono in valori booleani.

```c
0 == 0 // true. Although 0 is false, 0 equals 0 is true.
0 != 0 // false
1 > 0 // true
1 < 0 // false
1 >= 0 // true
1 <= 0 // false
```

## Operatori booleani

C supporta tre operatori booleani: `||` (o), `&&` (e) e `!` (non).

`!` si usa con un solo operando.
Inverte il valore booleano dell'operando.
Per esempio, `0` è `false`, ma `!0` è `true`.

`||` e `&&` si usano con due operandi.
L'operando di destra viene valutato solo quando l'operando di sinistra non determina già il risultato dell'espressione.
Vale a dire, `||` valuta il suo operando di destra solo quando il suo operando di sinistra vale `false`.
`&&` valuta il suo operando di destra solo quando il suo operando di sinistra vale `true`.


## Valutazione a cortocircuito

Il fatto di non valutare tutti gli operandi è noto come «cortocircuito».
Il cortocircuito è un modo conciso e potente per gestire certe situazioni.
Per esempio, un idioma comune consiste nel verificare che un puntatore non sia `NULL` e (&&), se non è `NULL`, dereferenziarlo, evitando così di dereferenziare un puntatore `NULL`.
Ma il cortocircuito può anche portare a bug.
A volte un programmatore dimentica che l'operando di destra di `||` o `&&` potrebbe non essere sempre valutato.
Se l'operando di destra è un'espressione con un effetto collaterale che ci si aspetta avvenga sempre, allora si avrà un bug a seconda del valore booleano dell'operando di sinistra.


## Restituire un'espressione booleana

Il risultato di un'espressione booleana può essere restituito direttamente.
Per esempio, questa istruzione `if`

```c
if (count > 0)
    return true;
else
    return false;
end
```

potrebbe essere sostituita da

```c
return count > 0;
```
