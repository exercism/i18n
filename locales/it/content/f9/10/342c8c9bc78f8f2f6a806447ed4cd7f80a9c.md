# Introduzione

Una *quotation* è un pezzo di codice racchiuso tra parentesi quadre (`[ ]`). È un valore: puoi inserirla nello stack, passarla a un'altra word oppure memorizzarla in un array.

```factor
[ 1 + ] .          ! => [ 1 + ]
5 [ 1 + ] call .   ! => 6
```

La maggior parte delle word di ordine superiore prende una quotation come secondo argomento:

```factor
{ 1 2 3 } [ sq ] map .    ! => { 1 4 9 }
{ 1 2 3 } [ even? ] filter .  ! => { 2 }
```

Il corpo di una quotation è normale codice Factor: gli stessi operatori ed effetti sullo stack che usi ovunque altro.

Quando costruisci codice a partire dai dati, concatenando frammenti o associando token a operazioni, il risultato è una sequenza: passala attraverso `>quotation` per renderla chiamabile:

```factor
{ [ 1 ] [ 2 + ] [ 3 * ] } concat >quotation call .   ! => 9
```
