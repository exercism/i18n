# Approfondimento

In Go, le stringhe sono immutabili.
Concatenare le stringhe con `+` all'interno di un ciclo causa allocazioni frequenti e copia i dati più volte.
Il pacchetto [`strings`](https://pkg.go.dev/strings) fornisce [`Builder`](https://pkg.go.dev/strings#Builder) per ridurre al minimo il sovraccarico di memoria componendo le stringhe in modo efficiente.

## Costruire le stringhe

Il valore zero di un `strings.Builder` è pronto all'uso, senza bisogno di inizializzazione o allocazione esplicita.
Puoi aggiungere nuovi dati al builder usando metodi di scrittura specifici.
Ogni metodo di scrittura restituisce un valore di errore per rispettare le interfacce standard di Go, ma è garantito che sia sempre `nil` e nel codice di tutti i giorni viene di solito ignorato.

I metodi più usati sono:

- `WriteString(s string) (int, error)`: aggiunge una stringa al buffer.
- `WriteRune(r rune) (int, error)`: aggiunge la codifica UTF-8 di una rune.
- `WriteByte(c byte) error`: aggiunge un singolo byte.

```go
var sb strings.Builder

sb.WriteString("Hello")
var r rune = ' '
sb.WriteRune(r)
var b byte = '.'
sb.WriteByte(b)
```

## Recuperare e azzerare

Quando hai finito di comporre il testo, puoi estrarre il contenuto accumulato come una normale stringa Go chiamando il metodo `String()`.
Chiamare `String()` è un'operazione molto economica, perché restituisce direttamente la slice di byte sottostante come stringa, senza copiare i dati accumulati.

Se devi riutilizzare la stessa istanza del `Builder` per comporre una nuova stringa (per esempio all'interno di un ciclo), puoi chiamare il metodo `Reset()`.
Questo svuota il buffer interno: puoi ricominciare da capo e costruire la stringa successiva, mantenendo la capacità di memoria già allocata.

```go
var sb strings.Builder

sb.WriteString("Task One")
fmt.Println(sb.String()) // Output: Task One

// Clear the buffer for resource reuse
sb.Reset()

sb.WriteString("Task Two")
fmt.Println(sb.String()) // Output: Task Two
```
