# Introduzione

## Operatori di confronto

R ha una serie di operatori uguali a quelli di molti altri linguaggi:

```R
1 == 2 # FALSE
1 != 2 # TRUE
1 < 2 # TRUE
1 > 2 # FALSE
1 <= 2 # TRUE
1 >= 2 # FALSE
```

## Diramazioni

La forma base di un if-else è questa:

```R
if (x > 10) {
    y <- "big"
} else if (x > 2) {
    y <- "medium"
} else {
    y <- "tiny"
}
```

In questo caso, sono necessarie sia le parentesi tonde (`()`) attorno al booleano, sia le parentesi graffe (`{}`) attorno all'istruzione.
Una semplice istruzione `if` si può abbreviare:

```R
if (x == 0) return("success")
```
