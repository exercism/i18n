# Informazioni

Il valore `null` viene usato per indicare l'_assenza_ di un valore. Un tipo **nullable** è un tipo che consente a una variabile di assumere il valore `null`. Per rendere nullable qualsiasi tipo, lo racchiudiamo in `Null<T>`:

```haxe
var a:Int = null; // Error
var b:Null<Int> = null; // Allowed
```

Per controllare se un valore è al momento `null`, basta usare un'espressione `if`:

```haxe
var a:Null<Int> = 10;

if (a != null) {
  trace("a is not null"); // a is not null
}
```
