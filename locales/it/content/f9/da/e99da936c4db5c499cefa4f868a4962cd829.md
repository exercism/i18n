# Introduzione

Questo esercizio riprende la pila dei dati e la notazione degli effetti sulla pila che hai incontrato in [Cargo Shuffle][cargo-shuffle]. Qui scriverai parole che combinano valori booleani.

## Parole di riordino

Le parole di riordino più comuni si trovano in [`kernel`][kernel]:

```
dup    ( x -- x x )
dupd   ( x y -- x x y )
drop   ( x -- )
swap   ( x y -- y x )
swapd  ( x y z -- y x z )
over   ( x y -- x y x )
pick   ( x y z -- x y z x )
rot    ( x y z -- y z x )
-rot   ( x y z -- z x y )
rotd   ( w x y z -- w y z x )
spin   ( x y z -- z y x )
nip    ( x y -- y )
tuck   ( x y -- y x y )

2dup   ( x y -- x y x y )
3dup   ( x y z -- x y z x y z )
4dup   ( w x y z -- w x y z w x y z )
2drop  ( x y -- )
3drop  ( x y z -- )
4drop  ( w x y z -- )
2nip   ( x y z -- z )
2swap  ( x y z w -- z w x y )
```

## Booleani

I due letterali booleani sono `t` e `f`. `f` è l'unico valore che Factor considera falso: tutto il resto, inclusi `0` e le collezioni vuote, è considerato vero.

```factor
t .    ! => t
f .    ! => f
```

## Parole booleane

Queste tre parole booleane dal vocabolario `kernel`:

```
and ( x y -- ? )    ! true when both inputs are truthy
or  ( x y -- ? )    ! true when either input is truthy
not ( x   -- ? )    ! inverts its argument
```

```factor
t t and .    ! => t
t f and .    ! => f
f t or .     ! => t
t not .      ! => f
```

Il `?` in ogni output è la convenzione della notazione degli effetti sulla pila per «un booleano».

Ti servirà `swap` per uno dei compiti qui sotto.
