# Suggerimenti

## 1. Calcola il prezzo di una pizza

- Imposta una funzione ricorsiva che restituisce il prezzo di un'opzione extra aggiunto al prezzo della pizza senza quel condimento extra.
- Se viene generato l'errore `Maximum call stack size exceeded`, controlla di non aver dimenticato il caso base.
- Se ricevi un `Memory Allocation Error`, controlla se stai duplicando l'array di condimenti in input invece di mutarlo.

## 2. Calcola il prezzo totale di un ordine

- Usando `pizzaPrice`, calcola il prezzo di ogni pizza nell'array e aggiungilo a un totale.
- Se viene generato l'errore `Maximum call stack size exceeded` e più di un test fallisce, controlla di non aver dimenticato il caso base. Se fallisce un solo test, prova a implementarlo con un ciclo!
- Se ricevi un `Memory Allocation Error`, controlla se stai duplicando l'array di input invece di mutarlo.
