# Istruzioni

Il giorno che hai aspettato tanto è finalmente arrivato: ora sei il fiero proprietario di una bellissima fattoria sulle Alpi.

Continui a non sopportare di svegliarti molto presto la mattina per dare da mangiare alle mucche.
Dato che sei un ottimo ingegnere, costruisci un distributore di mangime, il `FEED-M-ALL`.

L'ultima cosa che serve per completare il progetto è un pezzo di codice che calcoli la quantità di foraggio che ogni mucca dovrebbe ricevere.
È importante che ogni mucca ne riceva la stessa quantità: bisogna evitare i conflitti.
Le mucche sono molto sensibili.

Per fortuna, non devi ricavare da solo tutte le formule per calcolare le quantità di foraggio.
Usi una misteriosa libreria esterna che hai trovato su internet.
Dovrebbe dare come risultato le mucche più felici.
La libreria espone un tipo che soddisfa la seguente interfaccia.
Ti affiderai a questa nel codice che scriverai.

```go
type FodderCalculator interface {
	FodderAmount(int) (float64, error)
	FatteningFactor() (float64, error)
}
```

Man mano che lavori al codice, migliorerai la gestione degli errori per renderla più robusta e più facile da analizzare in seguito, quando la userai nella tua vita quotidiana in fattoria.

## 1. Dividi il cibo in parti uguali

Per prima cosa, ti concentri sullo scrivere il codice necessario a calcolare la quantità di foraggio per ogni mucca.

Implementa una funzione `DivideFood` che accetta come argomenti un `FodderCalculator` e un numero di mucche come intero.
*Per questo compito, puoi assumere che il numero di mucche passato sia sempre maggiore di zero.*
La funzione dovrebbe restituire la quantità di cibo per mucca come `float64`, oppure un errore se se ne verifica uno.

Per fare il calcolo, devi prima recuperare la quantità totale di foraggio per tutte le mucche.
Lo si fa chiamando il metodo `FodderAmount` e passando il numero di mucche.
Inoltre, ti serve un fattore per cui moltiplicare questa quantità.
Ottieni questo fattore chiamando il metodo `FatteningFactor`.
Con questi due valori e il numero di mucche, puoi ora calcolare la quantità di cibo per mucca (come `float64`).
È questo che la funzione `DivideFood` dovrebbe restituire.

Se uno dei metodi che chiami restituisce un errore, l'esecuzione dovrebbe fermarsi e quell'errore dovrebbe essere restituito (così com'è) dalla funzione `DivideFood`.

```go
// For this example, we assume FodderAmount returns 50
// and FatteningFactor returns 1.5.
DivideFood(fodderCalculator, 5)
// => 15 <nil>

// Now assuming FodderAmount returns an error with message "something went wrong".
DivideFood(fodderCalculator, 5)
// => 0 "something went wrong"
```

## 2. Controlla il numero di mucche

Mentre lavoravi al primo compito, ti sei reso conto che la libreria esterna che usi non è di così alta qualità come pensavi.
Per esempio, non riesce a gestire correttamente input non validi.
Vuoi aggirare questo limite aggiungendo un controllo sul valore di input direttamente nel codice.

Scrivi una funzione `ValidateInputAndDivideFood` che ha la stessa firma di `DivideFood` qui sopra.

- Se il numero di mucche passato è maggiore di 0, la funzione dovrebbe chiamare `DivideFood` e restituire i risultati di quella chiamata.
- Se il numero di mucche è 0 o meno, la funzione dovrebbe restituire un errore con messaggio `"invalid number of cows"`.

```go
ValidateInputAndDivideFood(fodderCalculator, 5)
// => 15 <nil>

ValidateInputAndDivideFood(fodderCalculator, -2)
// => 0 "invalid number of cows"
```

## 3. Migliora la gestione degli errori

Controllare il numero di mucche prima di passarlo era una buona mossa, ma non sei del tutto soddisfatto del messaggio di errore poco specifico.
Decidi di fare meglio creando un tipo di errore personalizzato chiamato `InvalidCowsError`.

L'errore personalizzato dovrebbe contenere il numero di mucche (`int`) e un messaggio personalizzato (`string`), e il metodo `Error` dovrebbe serializzare i dati nel seguente formato:

```txt
{number of cows} cows are invalid: {custom message}
```

Ora che hai il tuo errore personalizzato, implementa una funzione `ValidateNumberOfCows` che accetta il numero di mucche come intero e restituisce un errore (oppure nil).

- Se il numero di mucche è minore di 0, la funzione restituisce un `InvalidCowsError` con il messaggio personalizzato impostato su `"there are no negative cows"`.
- Se il numero di mucche è 0, la funzione restituisce un `InvalidCowsError` con il messaggio personalizzato impostato su `"no cows don't need food"`.
- Altrimenti, la funzione restituisce `nil` per indicare che la validazione è andata a buon fine.

```go
err := ValidateNumberOfCows(-5)
err.Error()
// => "-5 cows are invalid: there are no negative cows"
```

Dopo il duro lavoro per impostare questa funzione di validazione, ti accorgi che è già sera e lasci la scrivania per goderti il tramonto sulle montagne.
Rimandi a un altro giorno il compito di aggiungere davvero la nuova funzione di validazione al codice.
