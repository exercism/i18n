# Istruzioni

In questo esercizio scriverai un po' di logica per un videogioco che un amico sta sviluppando.
La protagonista del gioco è Annalyn, una ragazza coraggiosa con un cane feroce e fedele.
Purtroppo arriva la catastrofe: la sua migliore amica viene rapita mentre cerca bacche nel bosco.
Annalyn cercherà di trovare e liberare la sua amica, con la possibilità di portare con sé il cane in questa missione.

Alla fine Annalyn trova il campo in cui è imprigionata la sua amica e scopre che i rapitori sono due: un cavaliere possente e un astuto arciere.

Al giocatore vengono proposte alcune opzioni su cosa fare in seguito.
Per ognuna delle quattro opzioni possibili devi scrivere una funzione che dice al gioco se mostrare o meno quell'opzione.

## 1. Verifica se l'opzione "Attacco rapido" deve essere mostrata

Se il cavaliere sta dormendo, Annalyn potrà sferrare un attacco rapido nel campo prima che lui si svegli per bene e indossi l'armatura.

Implementa una funzione chiamata `can_do_fast_attack` che prende un valore booleano che indica se il cavaliere è sveglio.
Questa funzione restituisce `true` se l'azione "Attacco rapido" è disponibile in base allo stato del personaggio. Altrimenti restituisce `false`:

```julia-repl
julia> knight_awake = true

julia> can_do_fast_attack(knight_awake)
false
```

## 2. Verifica se l'opzione "Spia" deve essere mostrata

Si può spiare il gruppo se almeno uno di loro è sveglio. Altrimenti spiare è una perdita di tempo.

Implementa una funzione chiamata `can_spy` che prende tre valori booleani, che indicano rispettivamente se il cavaliere, l'arciere e la prigioniera sono svegli.
La funzione restituisce `true` se l'azione "Spia" è disponibile in base allo stato dei personaggi.
Altrimenti restituisce `false`:

```julia-repl
# Output suppressed from the next 3 lines
julia> knight_awake = false
julia> archer_awake = true
julia> prisoner_awake = false

julia> can_spy(knight_awake, archer_awake, prisoner_awake)
true
```

## 3. Verifica se l'opzione "Segnala alla prigioniera" deve essere mostrata

Si può segnalare alla prigioniera usando versi di uccelli se la prigioniera è sveglia e l'arciere sta dormendo.
Se l'arciere è sveglio, invece, non la si può segnalare in sicurezza, perché anche l'arciere è addestrato ai segnali con i versi degli uccelli.

Implementa una funzione chiamata `can_signal_prisoner` che prende due valori booleani, che indicano rispettivamente se l'arciere e la prigioniera sono svegli.
La funzione restituisce `true` se l'azione "Segnala alla prigioniera" è disponibile in base allo stato dei personaggi.
Altrimenti restituisce `false`:

```julia-repl
julia> archer_awake = false
julia> prisoner_awake = true

julia> can_signal_prisoner(archer_awake, prisoner_awake)
true
```

## 4. Verifica se l'opzione "Libera la prigioniera" deve essere mostrata

Annalyn può provare a intrufolarsi nel campo per liberare la sua amica. È una cosa rischiosa e può riuscire solo in uno di due modi:

- Se Annalyn ha con sé il cane, può salvare la prigioniera se l'arciere dorme.
  Il cavaliere ha paura del cane e l'arciere non avrà il tempo di prepararsi prima che Annalyn e la sua amica riescano a scappare.

- Se Annalyn non ha il cane, allora lei e la prigioniera devono essere molto furtive!
  Annalyn può liberare la prigioniera se è sveglia e il cavaliere e l'arciere stanno entrambi dormendo, ma se la prigioniera dorme non può essere salvata: si spaventerebbe per l'apparizione improvvisa di Annalyn e sveglierebbe il cavaliere e l'arciere.

Implementa una funzione chiamata `can_free_prisoner` che prende quattro valori booleani.
I primi tre parametri indicano rispettivamente se il cavaliere, l'arciere e la prigioniera sono svegli.
L'ultimo parametro indica se il cane di Annalyn è presente.
La funzione restituisce `true` se l'azione "Libera la prigioniera" è disponibile in base allo stato dei personaggi. Altrimenti restituisce `false`:

```julia-repl
julia> knight_awake = false
julia> archer_awake = true
julia> prisoner_awake = false
julia> dog_present = false

julia> can_free_prisoner(knight_awake, archer_awake, prisoner_awake, dog_present)
false
```
