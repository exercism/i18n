# Suggerimenti

## Generale

- Non dimenticare di esportare le tre subroutine pubbliche.
  Elencale nell'array `@EXPORT_OK`.

## 1. Verifica se una data è nel passato

- Per analizzare le stringhe di data, sappi che le stringhe sono fornite nel formato ISO 8601.
  Usa la variabile di package `$STRPTIME_FORMAT`.
- I metodi `Time::Piece->strptime` e `DateTime::Tiny->from_string` ti saranno utili.

## 2. Verifica se una data è nel pomeriggio

- «Pomeriggio» inizia a mezzogiorno e finisce prima delle 18:00.

## 3. Analizza una data ottenendo una stringa che descrive un appuntamento

- Usa `mm/dd/yyyy` per il formato della data di output.
  Ad esempio: 12/31/2021
- Il formato dell'ora di output usa l'ora nell'intervallo 0-12, senza zero iniziale né spazio, con l'indicatore am/pm in maiuscolo.
  Ad esempio: 7:59 PM
- Se usi il modulo Time::Piece, il metodo `strftime` è quello adatto.
