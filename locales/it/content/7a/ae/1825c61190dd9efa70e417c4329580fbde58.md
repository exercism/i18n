# Test

Per eseguire la suite di test:
```bash
tclsh exercise.test
```

## Test saltati

Risolvere un esercizio significa far passare tutti i suoi test. Per impostazione predefinita, quando esegui i test ne viene eseguito uno solo, il primo. È voluto: così puoi concentrarti solo sul far passare quel test. Una volta che passa, puoi abilitare il test successivo trasformando in commento o rimuovendo il comando `skip` che lo precede.

In alternativa, per eseguire tutti i test anche se sono saltati:
```bash
RUN_ALL=1 tclsh exercise.test
```
