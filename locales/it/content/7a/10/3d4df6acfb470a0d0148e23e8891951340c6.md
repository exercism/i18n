# Istruzioni

Il tuo amico Chandler ha in programma di visitare paesi esotici in tutto il mondo. Purtroppo, Chandler non è bravo in matematica. È piuttosto preoccupato di essere truffato dagli uffici di cambio durante il viaggio, e vuole che tu gli costruisca un calcolatore di valuta. Ecco le sue specifiche per l'app:

## 1. Stima il valore dopo il cambio

Crea la funzione `exchange_money()`, che prende 2 parametri:

1. `budget` : la somma di denaro che intendi cambiare.
2. `exchange_rate` : la quantità di valuta nazionale pari a un'unità di valuta estera.

Questa funzione deve restituire il valore della valuta cambiata.

**Nota:** Se la tua valuta è USD e vuoi cambiare USD in EUR con un tasso di cambio di `1.20`, allora `1.20 USD == 1 EUR`.

```python
>>> exchange_money(127.5, 1.2)
106.25
```

## 2. Calcola la valuta rimasta dopo un cambio

Crea la funzione `get_change()`, che prende 2 parametri:

1. `budget` : la somma di denaro prima del cambio.
2. `exchanging_value` : la somma di denaro che viene *presa* dal budget per essere cambiata.

Questa funzione deve restituire la somma di denaro che *rimane* del budget.

```python
>>> get_change(127.5, 120)
7.5
```

## 3. Calcola il valore delle banconote

Crea la funzione `get_value_of_bills()`, che prende 2 parametri:

1. `denomination` : il valore di una singola banconota.
2. `number_of_bills` : il numero totale di banconote.

Questo ufficio di cambio tratta solo contanti in determinati tagli.
Il totale che ricevi deve essere divisibile per il valore di una «banconota» o unità, il che può lasciare una frazione o un resto.
La funzione deve restituire solo il valore totale delle banconote (_escludendo le frazioni_) che l'ufficio restituirebbe.
Purtroppo, l'ufficio può tenersi il resto come bonus aggiuntivo.

```python
>>> get_value_of_bills(5, 128)
640
```

## 4. Calcola il numero di banconote

Crea la funzione `get_number_of_bills()`, che prende `amount` e `denomination`.

Questa funzione deve restituire il _numero di banconote_ che puoi ricevere con l'_amount_ indicato.
In altre parole: quante _banconote intere_ stanno nella somma iniziale?
Ricorda: puoi ricevere solo _banconote intere_, non frazioni di banconota, quindi ricordati di dividere di conseguenza.
In pratica, stai arrotondando _per difetto_ alla banconota intera più vicina.

```python
>>> get_number_of_bills(127.5, 5)
25
```

## 5. Calcola il resto dopo il cambio in banconote

Crea la funzione `get_leftover_of_bills()`, che prende `amount` e `denomination`.

Questa funzione deve restituire l'_importo avanzato_ che non può essere restituito partendo dalla somma iniziale, data la denominazione delle banconote.
È molto importante sapere esattamente quanto può tenersi l'ufficio.

```python
>>> get_leftover_of_bills(127.5, 20)
7.5
```

## 6. Calcola il valore dopo il cambio

Crea la funzione `exchangeable_value()`, che prende `budget`, `exchange_rate`, `spread` e `denomination`.

Il parametro `spread` è la *percentuale trattenuta* come commissione di cambio, scritta come numero intero.
Va convertita in decimale dividendola per 100.
Se `1.00 EUR == 1.20 USD` e lo *spread* è `10`, il tasso di cambio effettivo sarà: `1.00 EUR == 1.32 USD`, perché il 10% di 1.20 è 0.12 e questa commissione aggiuntiva viene sommata al cambio.

Questa funzione deve restituire il valore massimo della nuova valuta dopo aver calcolato il *tasso di cambio* più lo *spread*.
Ricorda che la *denominazione* della valuta è un numero intero e non può essere suddivisa.

**Nota:** Il valore restituito deve essere di tipo `int`.

```python
>>> exchangeable_value(127.25, 1.20, 10, 20)
80
>>> exchangeable_value(127.25, 1.20, 10, 5)
95
```
