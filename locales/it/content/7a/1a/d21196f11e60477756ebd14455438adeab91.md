# Suggerimenti

## Generali

- Se ti serve, torna a rivedere il [concetto di oggetti][concept-class-basics] per ripassare le basi.
- Leggi con attenzione le istruzioni sul posizionamento dei parametri `x`, `y`, `width` e `height`. È facile confonderli.

## 1. Definire una classe ProgramWindow

- Ricorda di usare la [sintassi delle classi][php-class] per questo compito.
- Definisci le [proprietà][php-properties] aggiungendole alla dichiarazione della classe.

## 2. Definire una funzione costruttore per la classe ProgramWindow

- Controlla che la tua funzione costruttore non accetti argomenti.
- Controlla che ogni proprietà sia impostata sul valore intero previsto.

## 3. Aggiungere un metodo per ridimensionare la finestra

- Ricorda di usare una nuova [classe][php-class] nel file `Size.php` per questo compito.
  - Per convenzione, i file di solito contengono una sola classe.
- Il costruttore di `Size` dovrebbe accettare argomenti per i valori iniziali delle [proprietà][php-properties] della classe.
- Crea un metodo `resize` dell'oggetto `ProgramWindow` per applicare la modifica usando un'istanza di `Size`.

## 4. Aggiungere un metodo per spostare la finestra

- Ricorda di usare una nuova [classe][php-class] nel file `Position.php` per questo compito.
  - Per convenzione, i file di solito contengono una sola classe.
- Il costruttore di `Position` dovrebbe accettare argomenti per i valori iniziali delle [proprietà][php-properties] della classe.
- Crea un metodo `move` dell'oggetto `ProgramWindow` per applicare la modifica usando un'istanza di `Position`.
