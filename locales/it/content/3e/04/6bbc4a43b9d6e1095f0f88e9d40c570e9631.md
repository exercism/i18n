# Istruzioni

Elyse, futura maga, continua il suo allenamento. Le verranno date diverse pile di carte con cui eseguire i suoi trucchi.
Per semplificare un po' le cose, usa solo le carte da 1 a 10.

In questo esercizio, usa i metodi integrati per analizzare il contenuto di un array.

## 1. Trova la posizione di una carta

Elyse vuole conoscere la posizione (l'indice) di una carta nella pila.

```javascript
const card = 2;
getCardPosition([9, 7, 3, 2], card);
// => 3
```

## 2. Determina se una carta è presente

Elyse vuole determinare se una carta è presente nella pila, in altre parole se la pila contiene una determinata `number`.

```javascript
const card = 3;
doesStackIncludeCard([2, 3, 4, 5], card);
// => true
```

## 3. Determina se ogni carta è pari

Elyse vuole sapere se ogni carta è pari, in altre parole se ogni numero nella pila è un `number` pari.

```javascript
isEachCardEven([2, 4, 6, 7]);
// => false
```

## 4. Verifica se la pila contiene una carta con un valore dispari

Elyse vuole sapere se c'è un numero dispari nella pila.

```javascript
doesStackIncludeOddCard([3, 2, 6, 4, 8]);
// => true
```

## 5. Ottieni la prima carta dispari dalla pila

Elyse vuole sapere il valore della prima carta dispari.

```javascript
getFirstOddCard([4, 2, 8, 7, 9]);
// => 7
```

## 6. Determina la posizione della prima carta pari

Elyse vuole sapere la posizione della prima carta pari.

```javascript
getFirstEvenCardPosition([5, 2, 3, 1]);
// => 1
```
