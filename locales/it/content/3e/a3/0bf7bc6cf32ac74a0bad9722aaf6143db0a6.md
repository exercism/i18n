# Introduzione agli array

Bash mette a disposizione due tipi di parametri: i valori «scalari» e gli array.
Un valore scalare può essere una stringa o un numero: rappresenta una singola «cosa».

Il più delle volte i valori scalari bastano a contenere i tuoi dati.
A volte però ti serve memorizzare un elenco di valori scalari.
In questo caso userai un _array_.

Esistono due tipi di array:

* Gli array con indice numerico associano una chiave intera a un valore stringa.
  (Altri linguaggi potrebbero chiamarlo «lista» o «sequenza».)
* Gli array associativi associano una chiave stringa a un valore stringa.
  (Altri linguaggi potrebbero chiamarlo «mappa» o «dizionario».)

Le prime sezioni di questo documento tratteranno gli array con indice numerico (d'ora in poi chiamati semplicemente «array»).
I dettagli sugli array associativi arriveranno alla fine.

~~~~exercism/caution
Gli array di Bash possono memorizzare _solo_ valori scalari.
Non è possibile creare un array bidimensionale (un array di array).
~~~~

## Dichiarare e inizializzare una variabile array

Puoi inizializzare un array assegnando a una variabile un elenco di elementi racchiuso tra parentesi (eventualmente vuoto).

```bash
myarray=("one" "two" "three")
```

Come per qualsiasi assegnazione di variabile, non ci devono essere spazi attorno al segno di uguale.

Nota che non ci sono virgole a separare gli elementi: è un elenco di stringhe separato da spazi.

In realtà, la quantità di spazi all'interno delle parentesi è del tutto arbitraria.
Sono ammessi anche i ritorni a capo: usane quanti vuoi per migliorare la leggibilità.

```bash
myarray=(
    "first element"
    "second element"
    "this is the last element"
)
```

Assegnare in questo modo un elenco di stringhe a una variabile array memorizzerà la prima stringa all'indice zero, la successiva all'indice uno, quella dopo all'indice due, e così via.

È possibile inizializzare un «array sparso» specificando gli indici che ti servono.

```bash
raindrops=([3]="Pling" [5]="Plang [7]="Plong")
```

~~~~exercism/note
Per ribadire: gli indici degli array partono da zero.
Questo frammento stampa «true»:

```bash
myarray=("one" "two" "three")
[[ "${myarray[0]}" == "one" ]] && echo true || echo false
```
~~~~

Puoi usare il comando `declare` (o `local` all'interno di una funzione) per specificare che una variabile conterrà un array.

```bash
declare -a myarray
```

È più idiomatico limitarsi ad assegnare una lista tra parentesi (magari vuota) per inizializzare la variabile.

## Accedere agli elementi di un array

Come hai visto nella nota qui sopra, la sintassi per accedere a un elemento di un array è `${myarray[$index]}`.
L'indice va indicato tra parentesi quadre.
Le parentesi graffe sono obbligatorie.

~~~~exercism/note
Per gli array con indice numerico, l'indice è un'espressione aritmetica.
Il manuale di Bash [afferma][arithmetic]:

> All'interno di un'espressione aritmetica, le variabili della shell possono anche essere referenziate per nome senza usare la sintassi di espansione dei parametri.

Questo significa che il `$` non è necessario per l'espansione «semplice» delle variabili.
Puoi accedere agli elementi così, il che è un po' più facile da leggere:

```bash
i=5
echo "${myarray[i]}"
# ..............^
```

[arithmetic]: https://www.gnu.org/software/bash/manual/bash.html#Shell-Arithmetic
~~~~

Se l'indice indicato non esiste nell'array, il risultato dell'espansione è una stringa vuota.

## Assegnare a un array

Per assegnare a una particolare voce dell'array, usa questa sintassi:

```bash
myarray[10]="hello"
```

Per _aggiungere_ in coda a un array, usa l'operatore di assegnazione con concatenazione `+=` e le parentesi:

```bash
myarray+=("new element 1" "new element 2")
```

## Iterare su un array

Di solito ti servirà iterare sui _valori_ di un array.
Usa un ciclo for (quello che hai visto nel concetto [Looping][looping]):

```bash
myarray=("one" "two" "three")
for value in "${myarray[@]}"; do
    echo "$value"
done
```

Nota la sintassi speciale per espandere l'array: `"${myarray[@]}"`
Questa forma di espansione dei parametri sostituisce i valori dell'array come parole separate.
È in qualche modo equivalente a:

```bash
for value in "${myarray[0]}" "${myarray[1]}" ... "${myarray[n]}"
```

La forma `"${myarray[@]}"` funziona con gli array sparsi, espandendo solo i valori definiti.

Questa espansione speciale, in cui l'indice è una chiocciola (`@`), è speciale solo all'interno delle virgolette doppie.

#### Altre espansioni speciali dei parametri

Ecco un altro paio di sintassi speciali che ci servono per iterare su un array.
Sono descritte nel manuale alla voce [Shell Parameter Expansion][man-expn].

Per trovare la _lunghezza_ di un array, usa `${#myarray[@]}`, con un `#` davanti al nome.
La «lunghezza» di un array è il numero di elementi che contiene.

Per estrarre l'elenco degli _indici_ di un array, usa `"${!myarray[@]}"`, con un `!` davanti al nome e l'espansione tra virgolette doppie.
Per gli array con indice numerico, gli indici vengono espansi in ordine numerico.

### Iterare sugli indici di un array

A volte ti servono sia l'indice sia il valore.
Ci sono un paio di modi per farlo.

1. Quando sai che gli indici formano una sequenza ininterrotta, puoi usare un ciclo for _aritmetico_.

   ```bash
   for ((i = 0; i < ${#myarray[@]}; i++)); do
       echo "$i -> ${myarray[i]}"
   done
   ```

   Nota la sintassi `${#myarray[@]}`, con il carattere `#` davanti al nome dell'array.
   Dato che gli array usano l'indicizzazione a base zero, l'ultimo indice dell'array è uno in meno della lunghezza dell'array.

2. Quando l'array è sparso, puoi usare questa forma:

   ```bash
   for index in "${!raindrops[@]}"; do
       echo "$index -> ${raindrops[index]}"
   done
   ```

   Nota la sintassi `${!myarray[@]}`, con il carattere `!` davanti al nome dell'array.

## Ispezionare un array

Se vuoi esaminare il contenuto di un array, usa il comando `declare` con l'opzione `-p`:

```bash
a=("the 'first' element"
   second
   third
   'the "last" element')
declare -p a
```

Questo stampa il contenuto con la quotatura canonica della shell.

```bash
declare -a a=([0]="the 'first' element" [1]="second" [2]="third" [3]="the \"last\" element")
```

## Array associativi

Per ribadire, gli array associativi usano stringhe come indici, non numeri.
Tutto quanto scritto sopra vale anche per gli array associativi, con qualche piccola differenza.
In genere usiamo il termine «chiave» invece di «indice»: gli array associativi associano chiavi a valori.

### Dichiarare un array associativo

A differenza degli array, gli array associativi **devono** essere dichiarati.
Usa l'opzione `-A` di `declare` (o di `local` all'interno di una funzione):

```bash
declare -A mymap

myfunc() {
    local -A my_local_map
    # ...
}
```

### Inizializzare un array associativo

Le coppie chiave-valore vengono specificate all'interno dell'elenco tra parentesi:

```bash
mymap=([first]=foo [second]=bar [third]=baz)
declare -p mymap
```

Questo stampa:

```
declare -A mymap=([second]="bar" [first]="foo" [third]="baz")
```

~~~~exercism/note
Tieni presente che gli array associativi **non hanno un ordine**.
~~~~

La dichiarazione e l'inizializzazione possono avvenire in una sola riga.

```bash
declare -A mymap=([first]=foo [second]=bar [third]=baz)
```

Nelle versioni recenti di Bash, l'inizializzazione può usare un elenco `(key value key value ...)`.

```bash
declare -A mymap=(first foo second bar third baz)
```

### Accedere ai valori

Per accedere agli elementi si usa la stessa sintassi di prima: `${mymap[$key]}`.

Le chiavi degli array associativi non vengono valutate in un contesto aritmetico.
È richiesta la solita sintassi di espansione dei parametri.

### Assegnare a un array associativo

L'assegnazione usa la stessa sintassi di prima:

```bash
mymap[$key]="$value"
```

### Iterare

Puoi usare un ciclo `for value in "${mymap[@]}"` per iterare.
Di solito però vuoi avere anche la chiave insieme al valore.

Usa la sintassi `"${!mymap[@]}"` che abbiamo visto sopra.

```bash
for key in "${!mymap[@]}"; do
    echo "$key -> ${mymap[$key]}"
done
```

Questo stampa

```
second -> bar
first -> foo
third -> baz
```

Per rimarcarlo, non c'è alcun ordine nelle chiavi.
