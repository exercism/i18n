# Introduzione

Un'interfaccia può essere vista come la firma di una classe, perché ne descrive i campi pubblici. Una classe _implements_ un'`interface` con la parola chiave `implments`.

La sua sintassi è molto simile a quella di una classe, con la differenza che i metodi appaiono come firme senza corpo:

```haxe
interface Language {
  private var languageName:String;

  public function speak():String;
}

class FrenchSpeaker implements Language {
  var languageName = "French";

  public function speak():String {
    return "Bonjour!";
  }
}
```

I campi implementati da un'interfaccia **devono** sempre usare lo stesso modificatore di visibilità. Per esempio, se la variabile `a` è `public` in un'interfaccia, anche la sua implementazione deve essere `public`.
