# Istruzioni

In questo esercizio lavorerai a un sistema di pianificazione degli appuntamenti per un salone di bellezza.

Ci sono tre attività, tutte legate alle date degli appuntamenti.

## 1. Verifica se un appuntamento è già passato

Implementa la subroutine `appointment_has_passed`, che prende una stringa di data e verifica se l'appuntamento è avvenuto nel passato:

```perl
appointment_has_passed("2019-07-25T13:45:00")
// => true
```

Le stringhe di data verranno passate nel formato ISO 8601 datetime: `YYYY-mm-ddTHH:MM:SS`

Dovrai implementare la subroutine privata `_parse_datetime`.
Ti suggeriamo un paio di moduli:

- [Time::Piece][time-piece] è un modulo del core di Perl.
- [DateTime::Tiny][datetime-tiny] è disponibile su CPAN.

## 2. Verifica se l'appuntamento è nel pomeriggio

Implementa la funzione `is_afternoon_appointment`, che prende una stringa di data e verifica se l'appuntamento è nel pomeriggio (>= 12:00 e < 18:00):

```perl
is_afternoon_appointment("2019-07-25T13:45:00")
// => true
```

## 3. Descrivi l'ora e la data dell'appuntamento

Implementa la funzione `describe_appointment`, che prende una stringa di data e restituisce una descrizione di quella data e di quell'ora:

```perl
describe_appointment("2019-07-25T13:45:00")
// => "You have an appointment on 07/25/2019 1:45 PM"
```

Nota che l'ora è nell'intervallo 0-12 e non ha né uno zero iniziale né uno spazio.

[time-piece]: https://perldoc.perl.org/Time::Piece
[datetime-tiny]: https://metacpan.org/pod/DateTime::Tiny
