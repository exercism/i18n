# Test

Se hai scaricato un esercizio con lo strumento CLI, dovresti vedere un file Uiua che porta il nome dell'esercizio e un file `tests.ua`.
Questo file contiene tutti i casi di test, che corrispondono a quelli eseguiti dal test runner quando carichi la tua soluzione.
Sentiti libero di aggiungere altri casi di test per fare esperimenti.
Tuttavia, modificare i test non influisce sul processo del test runner online.

## Test in locale

Per eseguire i test di un esercizio, apri un terminale nella directory dell'esercizio ed esegui il comando `uiua test tests.ua`.

Ad esempio, l'output di un esercizio `hello-world` non modificato potrebbe essere simile a questo:

```bash
$ uiua test tests.ua
Error: Goodbye, Mars!
  at tests.ua:3:1
3 | ⍤⤙≍ "Hello, World!" Hello
    ─
Test failed
```

La riga `Error` mostra l'output effettivo del tuo codice.
Il numero di riga indica la posizione del risultato atteso in `tests.ua`.
Una soluzione corretta produce:

```bash
$ uiua test tests.ua
Test passed
```
