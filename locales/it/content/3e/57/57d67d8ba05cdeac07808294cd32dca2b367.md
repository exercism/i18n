# Introduzione

Un **word** è il nome che Factor dà a una funzione. Partendo dallo stack dei dati visto in `basics`, questo concetto riguarda la definizione dei propri word: fare aritmetica, dare un nome a valori fissi e comporre word a partire da altri word.

Una definizione inizia con `:`, indica un effetto sullo stack, poi il corpo, poi `;`. Il compilatore controlla che il corpo corrisponda all'effetto dichiarato:

```factor
: square ( x -- x*x ) dup * ;

4 square .    ! => 16
```

I word aritmetici per i numeri interi `+`, `-`, `*` estraggono due numeri dallo stack e impilano il risultato. Si trovano nel vocabolario `math`, quindi un file che li usa deve avere `math` nella riga `USING:`. La cima dello stack è l'operando di destra:

```factor
2 3 + .    ! => 5
8 3 - .    ! => 5    (8 - 3, not 3 - 8)
2 3 * .    ! => 6
```

`CONSTANT:` dà un nome a un valore fisso. Una costante è a sua volta un word: chiamarla ne impila il valore:

```factor
CONSTANT: pi 3

pi pi * .    ! => 9
```

Il corpo di un word può chiamare qualsiasi word già nello scope, compresi quelli definiti prima nello stesso file:

```factor
: double    ( x -- 2x ) 2 * ;
: quadruple ( x -- 4x ) double double ;

5 quadruple .    ! => 20
```

Un `?` finale negli output è la convenzione per indicare «un booleano», e sia i word che le costanti usano `lowercase-kebab-case`.
