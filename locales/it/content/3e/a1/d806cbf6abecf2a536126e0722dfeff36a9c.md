# Introduzione

Una `string` in C# è un oggetto che rappresenta testo immutabile sotto forma di una sequenza di caratteri Unicode (lettere, cifre, punteggiatura, ecc.). Per definire un'istanza di `string` si usano le virgolette doppie:

```csharp
string fruit = "Apple";
```

Le stringhe si manipolano chiamando i metodi della stringa. Una volta che una stringa è stata costruita, il suo valore non può più cambiare. Qualsiasi metodo che sembri modificare una stringa in realtà restituisce una nuova stringa.

Più stringhe si possono concatenare (sommare) tra loro. Il modo più semplice per farlo è usare l'operatore `+`.

```csharp
string name = "Jane";
"Hello " + name + "!";
// => "Hello Jane!"
```

Per qualsiasi formattazione di stringa più complessa di una semplice concatenazione, è preferibile l'interpolazione di stringhe. Per usare l'interpolazione in una stringa, anteponi ad essa il simbolo del dollaro (`$`). Poi puoi usare le parentesi graffe (`{}`) per accedere a qualsiasi variabile all'interno della stringa.

```csharp
string name = "Jane";
$"Hello {name}!";
// => "Hello Jane!"
```
