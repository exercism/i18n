# Appendice alle istruzioni

## Registri

| Registro | Utilizzo   | Tipo      | Descrizione                                                                             |
| -------- | ---------- | --------- | --------------------------------------------------------------------------------------- |
| `$a0`    | input      | intero    | lato a                                                                                  |
| `$a1`    | input      | intero    | lato b                                                                                  |
| `$a2`    | input      | intero    | lato c                                                                                  |
| `$v0`    | output     | intero    | tipo di triangolo (`0` = scaleno, `1` = isoscele, `2` = equilatero, `3` = non valido)    |
| `$t0-9`  | temporaneo | qualsiasi | usato per la memorizzazione temporanea                                                  |
