# Introduzione

Cairo non ha un tipo nativo per le stringhe, ma offre due modi per gestirle: stringhe corte con virgolette singole e `ByteArray` con virgolette doppie.

Una stringa corta è una stringa ASCII in cui ogni carattere è codificato su un byte.

Il tipo che Cairo usa per le stringhe corte per impostazione predefinita è `felt252`, il che rende la loro lunghezza massima di soli 31 caratteri.

```rust
// below are different ways to write the same value
let name: felt252 = 'Jane';     // short string format
let name: felt252 = 0x4a616e65; // byte format
let name: felt252 = 1247899237; // decimal format
```

Tecnicamente, qualsiasi tipo intero più piccolo di `felt252` può essere rappresentato usando il formato stringa corta.

```rust
// all of the below are equal u8 values, they are just written using different formats!
let lowercase_a_in_ascii: u8 = 'a';  // short string format
let lowercase_a_in_ascii: u8 = 0x61; // byte format
let lowercase_a_in_ascii: u8 = 97;   // decimal format
```

Per stringhe più lunghe di 31 caratteri, Cairo fornisce `ByteArray`, che ha una lunghezza illimitata.

```rust
let long_string: ByteArray = "this is a string which has more than 31 characters";
```

I ByteArray possono essere concatenati tramite l'operatore `+`:

```rust
"Jane" + " " + "Austen"
// => "Jane Austen"
```

Alcuni caratteri speciali devono essere preceduti da una barra rovesciata, come `\t` per una tabulazione e `\n` per una nuova riga nelle stringhe.

```rust
"How is the weather today?\nIt's sunny"  
// =>
// How is the weather today?
// It's sunny
```

Puoi persino accedere ai singoli byte all'interno di un ByteArray usando il suo indice.

Fai attenzione però: il tipo del byte restituito è `u8` e non `ByteArray`!

```rust
let hello: ByteArray = "Hello World!";
let exclamation_mark: u8 = hello[11];
// => 33
```

La libreria principale fornisce molti metodi e operatori utili per lavorare con i ByteArray.

Per maggiori informazioni sui metodi di ByteArray, consulta la [documentazione di ByteArrayTrait][docs].

Ecco alcuni esempi:

```rust
let name: felt252 = 'Jane';
let mut greeting: ByteArray = "Welcome ";

// append_word appends a single word of a given number of bytes to the end of the ByteArray 
greeting.append_word(name, 4);
// => "Welcome Jane"

// rev returns a ByteArray with the all characters reversed
let rev_greeting = greeting.rev();
// => "enaJ emocleW"
```
