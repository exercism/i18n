Elixir ha convenzioni di denominazione precise, tra cui quella per dare un nome alle [funzioni che restituiscono un valore booleano](https://hexdocs.pm/elixir/naming-conventions.html#trailing-question-mark-foo):

> Le funzioni che restituiscono un valore booleano hanno un punto interrogativo finale nel nome.

```elixir
# this is the expected name of functions that return a boolean

%{expected}

# this is the current name

%{actual}
```

Tieni presente che le guardie, alcune funzioni integrate e le macro che restituiscono valori booleani e sono valide nelle guardie seguono un'altra convenzione e hanno il prefisso `is_` nel nome (`def is_integer`, `defguard is_foo`, `defmacro is_foo`). Le due convenzioni non vanno mescolate.
