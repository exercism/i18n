# Appendice alle istruzioni

## Suggerimenti

Devi implementare la funzione `recite`, che restituisce il testo di «The Twelve Days of Christmas». Puoi usare la firma fornita se hai dubbi sui tipi, ma non lasciare che limiti la tua creatività.

Questo esercizio lavora con dati testuali. Per ragioni storiche, il tipo `String` di Haskell è sinonimo di `[Char]`, una lista di caratteri. Per gestire i dati testuali in modo più efficiente si può usare il tipo `Text`.

Come estensione facoltativa di questo esercizio, puoi

- leggere qualcosa sui [tipi di stringa](https://haskell-lang.org/tutorial/string-types) in Haskell.
- aggiungere `- text` alla tua lista di dipendenze in package.yaml.
- importare `Data.Text` [nel modo seguente](https://hackernoon.com/4-steps-to-a-better-imports-list-in-haskell-43a3d868273c):

```haskell
import qualified Data.Text as T
import           Data.Text (Text)
```

- scrivere ad es. `recite :: Int -> Int -> [Text]` e riferirti ai combinatori di `Data.Text` come ad es. `T.pack`.
- consultare la documentazione di [`Data.Text`](https://hackage.haskell.org/package/text/docs/Data-Text.html).
- sostituire tutte le occorrenze di `String` con `Text` in TwelveDays.hs, cioè:

```haskell
recite :: Int -> Int -> [Text]
```

Questa parte è del tutto facoltativa.
