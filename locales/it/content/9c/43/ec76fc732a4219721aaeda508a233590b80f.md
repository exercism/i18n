# Introduzione

Gli array sono il principale tipo di sequenza a lunghezza fissa di Factor, scritto `{ … }`: puoi cambiare gli elementi ma non la lunghezza. I vocabolari `arrays` e `sequences` insieme ti danno piccoli costruttori che prendono valori dallo stack, più operazioni comuni per unire, invertire e cercare elementi.

```factor
USING: arrays sequences ;

42 1array .                ! => { 42 }
"a" "b" "c" 3array .       ! => { "a" "b" "c" }
{ { 1 2 } { 3 4 } } concat .   ! => { 1 2 3 4 }
{ 1 2 3 } reverse .            ! => { 3 2 1 }
```
