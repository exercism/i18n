# Introduzione

In Go, ogni variabile ha un valore.
Dichiarare una variabile senza assegnarne uno la imposta al valore zero del suo tipo.

I tipi di base, tra cui `bool`, i tipi numerici e `string`, hanno ciascuno un valore zero fisso:

| Tipo                   | Valore zero |
| ---------------------- | ----------- |
| bool                   | `false`     |
| int, int8, int64, ecc. | `0`         |
| float32, float64       | `0`         |
| complex64, complex128  | `0+0i`      |
| string                 | `""`        |

I puntatori, le funzioni, le interfacce, gli slice, i canali e le mappe hanno un valore zero pari a `nil`.

Gli array e le struct non sono mai `nil`, perché contengono i dati direttamente, non un riferimento a essi.
Ogni elemento di un array e ogni campo di una struct vengono inizializzati al valore zero del proprio tipo.
Per esempio, `var a [3]int` crea l'array `[0, 0, 0]`.

## Dichiarare i valori zero

Usa `var` per una dichiarazione:

```go
var myBool bool   // false
var mySlice []int // nil
```

Usa un literal composito `T{}` per le struct:

```go
type Person struct {
    Name string
    Age  int
}

myPerson := Person{} // Person{Name: "", Age: 0}
```
