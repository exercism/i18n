# Introduzione

## Istruzioni switch

Come un'istruzione _if/else_, un'istruzione `switch` ti permette di cambiare il flusso del programma eseguendo del codice in modo condizionale.
La differenza è che un'istruzione `switch` può confrontare il valore di un'espressione primitiva o di una stringa solo con valori costanti predefiniti.

Alcune parole chiave sono utili quando si usa un'istruzione switch.

- `switch`: questa parola chiave ti permette di dichiarare la struttura dello switch.
  È seguita dall'espressione o dalla variabile che cambierà il risultato.
- `case`: userai questa parola chiave per dichiarare le diverse possibilità per il risultato.
- `break`: la parola chiave `break` è molto utile per interrompere l'esecuzione dello switch alla fine del flusso desiderato.
  Se la dimentichi, il programma continuerà e potrà portare a risultati inaspettati.
- `default`: come dice il nome, usala come risultato predefinito quando nessun altro case corrisponde al risultato della tua espressione.

Nella loro forma più semplice, verificano un'espressione primitiva o una stringa e prendono una decisione in base al suo valore.
Per esempio:

```java
String direction = getDirection();
switch (direction) {
    case "left":
        goLeft();
        break;
    case "right":
        goRight();
        break;
    default:
        // otherwise
        markTime();
        break;
}
```
