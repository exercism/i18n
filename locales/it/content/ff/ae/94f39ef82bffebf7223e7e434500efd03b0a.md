# Informazioni

I [cicli repeat-while][repeat-loops] sono simili ai cicli `while`, ma con una differenza fondamentale: il controllo della condizione avviene *dopo* che il corpo del ciclo è stato eseguito, non prima.
Di conseguenza, un ciclo `repeat-while` eseguirà il proprio blocco di codice almeno una volta.

```swift
repeat {
    print("This runs at least once")
} while false

print("Loop done")

// Prints:
// This runs at least once
// Loop done
```

[repeat-loops]: https://docs.swift.org/swift-book/LanguageGuide/ControlFlow.html#ID126
