# Apprendimento

* [The Rust Programming Language](https://doc.rust-lang.org/book/) è un'ottima risorsa per iniziare con Rust e per approfondire funzionalità specifiche del linguaggio.
* [Rust by Example](https://doc.rust-lang.org/stable/rust-by-example/) ti mostra esempi delle cose più comuni che scriverai in Rust.
* [Into_rust()](http://intorust.com/) «Screencast per imparare Rust».
* [Rustlings](https://github.com/carols10cents/rustlings) «Piccoli esercizi per abituarti a leggere e scrivere codice Rust».
* Il [Rust User Forum](http://users.rust-lang.org) risponde a domande di tutti i livelli
