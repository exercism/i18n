# Informazioni

Una `Map` serve a memorizzare coppie di **chiave** e **valore**. Le `Maps` si inizializzano proprio come un array, ma usano l'operatore `=>` dei letterali di mappa. Si possono anche definire esplicitamente i tipi di chiave e valore, oppure lasciare che i tipi vengano inferiti. Le chiavi devono essere uniche, altrimenti viene generato un errore.

```haxe
var map1:Map<Int, String> = [1 => "one", 2 => "two", 3 => "three"];

var map2 = ["one" => 1, "two" => 2, "three" => 3];

var map3 = [1 => "cat", 1 => "dog"]; // Error: Duplicate Key

var map4 = ["h" => "Hello", "b" => "Bye"];
trace(map4["h"]); // Hello
```

Una `Map` si può iterare con un ciclo `for`. Puoi iterare sui valori oppure sulle chiavi:

```haxe
for (value in map) {
  // ...
}

for (key in map.keys()) {
  // ...
}
```

Dietro le quinte, una `Map` è un tipo astratto. Al momento della compilazione viene convertita in uno tra diversi tipi specializzati, a seconda del tipo della chiave:

- `String`: `haxe.ds.StringMap`
- `Int`: `haxe.ds.IntMap`
- `EnumValue`: `haxe.ds.EnumValueMap`
- `{}`: `haxe.ds.ObjectMap`

Il tipo `Map` non esiste a runtime ed è stato sostituito con uno degli oggetti qui sopra.
