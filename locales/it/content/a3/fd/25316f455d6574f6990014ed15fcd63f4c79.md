# Introduzione

Il codice Elixir viene eseguito nella macchina virtuale BEAM. BEAM fa parte dell'Erlang Run-Time System. Poiché si ispira ad Erlang e ne condivide l'ambiente di esecuzione, Elixir offre un'ottima interoperabilità con le librerie Erlang. Questo significa che gli sviluppatori Elixir possono usare le librerie Erlang dal proprio codice Elixir. Anzi, nella comunità Elixir scrivere librerie Elixir per funzionalità già offerte dalle librerie Erlang è sconsigliato.

Di conseguenza, alcune funzionalità, come le operazioni matematiche o le funzioni per i timer, in Elixir sono disponibili solo tramite Erlang.

La libreria standard di Erlang è disponibile nel nostro codice Elixir senza che serva alcun passaggio aggiuntivo.

Le funzioni Erlang si chiamano allo stesso modo delle funzioni Elixir, con una piccola differenza. I nomi dei moduli Erlang sono atomi in `snake_case`. Per esempio, per chiamare la funzione Erlang `pi/0` dal modulo `math`, si scriverebbe così:

```elixir
:math.pi()
# => 3.141592653589793
```

Le funzioni Erlang più usate che non hanno un equivalente in Elixir sono:

- `:timer.sleep/1`, che sospende un processo per il numero di millisecondi indicato.
- `:rand.uniform/0`, che genera un numero in virgola mobile casuale `x`, dove `0.0 <= x < 1.0`.
- `:io_lib.format/2`, che offre una formattazione di stringhe in stile C (con sequenze di controllo). Con questa funzione potremmo, per esempio, stampare un numero intero in una base qualsiasi tra 2 e 36, oppure formattare un numero in virgola mobile con la precisione desiderata. Tieni presente che questa funzione, come molte funzioni Erlang, restituisce una charlist.
- Il modulo `math`, che fornisce funzioni matematiche come `sin/1`, `cos/1`, `log2/1`, `log10/1`, `pow/2` e molto altro.

Per scoprire la libreria standard di Erlang, esplora lo [STDLIB Reference Manual][erl-stdlib-ref].

[erl-stdlib-ref]: https://www.erlang.org/doc/apps/stdlib/index.html
