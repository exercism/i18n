# uso dei return nudi

La comunità di Go consiglia di evitare i *return nudi* (o *bare return*) in circostanze normali, perché di solito rendono il codice più difficile da leggere.
Per maggiori dettagli, consulta la [guida ufficiale di Go alla revisione del codice](https://github.com/golang/go/wiki/CodeReviewComments#naked-returns).
Esiste una [proposta](https://github.com/golang/go/issues/21291) per rimuovere del tutto i return nudi in Go 2.
