# Introduzione

Un ciclo `for` permette di iterare su un array e ripetere il codice per ogni elemento:

```haxe
var fruitList = ["apple", "banana", "pear"];

for (fruit in fruitList) {
  trace(fruit);
}

// apple
// banana
// pear
```

Nell'esempio qui sopra, `fruit` è la variabile che contiene il valore di un singolo elemento dell'array `fruitList`. Il compilatore verifica che si possa iterare su `fruitList`, altrimenti ferma l'esecuzione.

Puoi iterare sui numeri usando l'operatore range. L'operatore prende due operandi di tipo `Int` e si scrive `min...max`:

```haxe
for (i in 0...10) {
  trace(i); // from 0 to 9
}
```
