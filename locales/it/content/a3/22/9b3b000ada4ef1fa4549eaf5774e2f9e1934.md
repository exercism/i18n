# Introduzione

## Importare

Swift offre molte funzionalità nella sua libreria standard, ma puoi accedere a molte funzionalità aggiuntive importando librerie e framework esterni.
Questi moduli possono arrivare direttamente dal progetto Swift (come [Swift Argument Parser][argument-parser]), dai framework delle piattaforme Apple (come [Foundation][apple-foundation] e il [Network Framework][network-framework]) oppure da librerie open source di terze parti (come [SwiftyBeaver][swifty-beaver]).

I moduli principali, come Foundation, una delle librerie più usate in Swift, sono inclusi nella toolchain di Swift.
Le librerie di terze parti devono invece essere aggiunte alla configurazione del progetto (per esempio, usando Swift Package Manager) prima di poterle importare.

Per importare un modulo si scrive la parola chiave `import` seguita dal nome del modulo.
Quindi puoi importare Foundation aggiungendo le righe seguenti al programma.

```swift
import Foundation
```

Importare un modulo rende disponibili al codice i tipi, i metodi e le funzioni che contiene.
Per esempio, importare Foundation estende `String` con utili metodi di utilità come `components(separatedBy:)`.

Per convenzione, le istruzioni `import` si mettono all'inizio di un file Swift, così le dipendenze sono subito visibili a chi legge il codice.

## Indicizzazione delle stringhe

Ai singoli caratteri di una `String` si accede con lo stesso metodo di indicizzazione usato per gli array.
Tuttavia, gli [indici][string-indices] usati per le stringhe _non_ sono numeri interi e non si possono usare direttamente.
Vanno invece calcolati a partire da un altro indice noto, come `startIndex`, che punta alla posizione del primo carattere di una stringa non vuota, usando i metodi disponibili nelle librerie [`String`][string-docs] e [`NSString`][nsstring-docs] (quando il modulo `Foundation` è importato, le stringhe in Swift hanno accesso a tutte le proprietà e i metodi di NSString).

Per esempio, data la seguente stringa:

```swift
let csv = "apple,pear,peach,orange,cherry,lime,goosberry"
```

Non si può scrivere `csv[21]` per ottenere la «g» di «orange»: bisogna invece calcolare un valore di tipo `String.Index` e usare quell'indice.
Nota che questi indici non sono pensati per essere letti direttamente da una persona.
Sono quelli che si chiamano _indici opachi_, perché non è necessario sapere cosa contengono.

```swift
let index = csv.index(csv.startIndex, offsetBy: 21)
csv[index]
// "g"
print(index)
// prints Index(_rawBits: 1376513)
```

Nota però che se l'offset non è un indice valido, cioè se restituirebbe un indice prima di `startIndex` o dopo `endIndex`, l'operazione genera un errore e fa andare in crash il programma.
Per evitare questo problema, si può specificare un indice limite.
In questo caso si ottiene un indice opzionale, che vale nil per gli indici altrimenti non validi.

```swift
let tooFar = csv.index(csv.startIndex, offsetBy: 200)
// error: Execution was interrupted, reason: EXC_BAD_INSTRUCTION (code=EXC_I386_INVOP, subcode=0x0).
let tooFarButSafe = csv.index(csv.startIndex, offsetBy: 200, limitedBy: csv.endIndex)
// nil
```

Inoltre, gli indici non si possono condividere tra stringhe diverse.
Per esempio, se usi l'`index` della «g» di «orange» calcolato sopra per indicizzare la stringa `fam = "This is my family: 👨‍👩‍👦‍👦, this is our dog: 🐶, this is our cat: 🐱!"`, cioè `fam[index]`, il programma andrà in crash.

Ci sono molte ragioni dietro tutto questo, ma in sostanza si riducono tutte a una: «Unicode è complicato».

In generale, se ti serve un accesso casuale ai singoli caratteri, probabilmente ti conviene usare un'altra struttura dati, come `Array<Character>`.

### Alcuni metodi utili

Swift ha i metodi `first` e `last` per ottenere il primo e l'ultimo carattere di una stringa.
Questi metodi restituiscono un carattere opzionale, quindi se la stringa è vuota restituiscono nil.

```swift
let str = "Hello, world!"
print(str.first) // Prints Optional("H")
print(str.last)  // Prints Optional("!")
```

Puoi anche usare i metodi `prefix` e `suffix` per ottenere una sottostringa di una stringa.
Questi metodi accettano un numero intero come argomento e restituiscono una sottostringa con i primi o gli ultimi n caratteri della stringa.

```swift
let str = "Hello, world!"
print(str.prefix(5)) // Prints "Hello"
print(str.suffix(6)) // Prints "world!"
```

## Metodi delle stringhe

Lavorare con il testo è un compito comune nella programmazione.
Swift, insieme al framework Foundation, offre molti metodi e proprietà comodi per esaminare, trasformare e manipolare le stringhe.

## Dividere le stringhe con `components(separatedBy:)`

Per dividere una stringa in un array di sottostringhe in base a un delimitatore, usa `components(separatedBy:)` (richiede di importare Foundation):

```swift
import Foundation

let sentence = "Hello, world!"
let words = sentence.components(separatedBy: " ")
print(words) // Prints ["Hello,", "world!"]
```

## Controllare prefissi e suffissi con `hasPrefix(_:)` e `hasSuffix(_:)`

Per controllare se una stringa inizia o finisce con una determinata sequenza di caratteri, usa `hasPrefix(_:)` e `hasSuffix(_:)`:

```swift
let greeting = "Hello, world!"
print(greeting.hasPrefix("Hello"))  // Prints true
print(greeting.hasSuffix("world!")) // Prints true
```

## Cambiare maiuscole e minuscole

Puoi trasformare maiuscole e minuscole di una stringa con questi metodi e proprietà standard:

- `lowercased()`: restituisce una copia della stringa in minuscolo.
- `uppercased()`: restituisce una copia della stringa in maiuscolo.
- `capitalized`: restituisce una copia in cui la prima lettera di ogni parola è maiuscola (da Foundation).

```swift
let greeting = "hello, world!"
print(greeting.lowercased())  // Prints "hello, world!"
print(greeting.uppercased())  // Prints "HELLO, WORLD!"
print(greeting.capitalized)   // Prints "Hello, World!"
```

## Sostituire sottostringhe con `replacingOccurrences(of:with:)`

Per sostituire tutte le occorrenze di una sottostringa con un'altra stringa, usa `replacingOccurrences(of:with:)` (da Foundation):

```swift
let greeting = "Hello, world!"
let updated = greeting.replacingOccurrences(of: "world", with: "Swift")
print(updated) // Prints "Hello, Swift!"
```

## Unire le stringhe con `joined(separator:)`

Il metodo `joined(separator:)` appartiene alle collezioni di stringhe, come `[String]`.
Unisce gli elementi in un'unica stringa usando un separatore:

```swift
let words = ["Hello", "world"]
let sentence = words.joined(separator: ", ")
print(sentence) // Prints "Hello, world"
```
