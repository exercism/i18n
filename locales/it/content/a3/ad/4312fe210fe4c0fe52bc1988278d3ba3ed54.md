# Introduzione

La classe `TimeZoneInfo` fornisce le routine per gestire le differenze tra i fusi orari. La classe `TimeZoneInfo` contiene anche metodi che semplificano la gestione dell'ora legale.

La classe `CultureInfo` supporta formati di data e ora dipendenti dalle impostazioni locali.

Per supportare la scrittura di codice multipiattaforma, la classe `RuntimeInformation` permette di rilevare il sistema operativo su cui il codice è in esecuzione: Linux, Windows o OSX.
