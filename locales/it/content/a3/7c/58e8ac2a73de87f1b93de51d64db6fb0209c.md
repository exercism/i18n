# Introduzione

## Stringhe

Le stringhe in Elixir sono delimitate da doppi apici e sono codificate in UTF-8:

```elixir
"Hi!"
```

Le stringhe possono essere concatenate usando l'operatore `<>/2`:

```elixir
"Welcome to" <> " " <> "New York"
# => "Welcome to New York"
```

Le stringhe in Elixir supportano l'interpolazione usando la sintassi `#{}`:

```elixir
"6 * 7 = #{6 * 7}"
# => "6 * 7 = 42"
```

Per inserire un carattere di nuova riga in una stringa, usa il codice di escape `\n`:

```elixir
"1\n2\n3\n"
```

Per lavorare comodamente con testi che contengono molti caratteri di nuova riga, usa invece la sintassi heredoc con tripli doppi apici:

```elixir
"""
1
2
3
"""
```

Elixir mette a disposizione molte funzioni per lavorare con le stringhe nel modulo `String`.

## Operatore pipe

L'operatore `|>` si chiama operatore pipe. Può essere usato per concatenare tra loro più chiamate di funzione, in modo che il valore restituito dalla chiamata precedente venga passato come primo argomento alla chiamata successiva.

```elixir
"hello"
|> String.upcase()
|> Kernel.<>("?!")

# => "HELLO?!"
```
