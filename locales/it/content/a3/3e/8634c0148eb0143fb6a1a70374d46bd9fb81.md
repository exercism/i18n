# Binario, ottale ed esadecimale

Il binario, l'ottale e l'esadecimale (_noto anche come hex_) sono diversi [sistemi di numerazione][numeral-systems], con basi diverse.
Il binario è in base 2, l'ottale in base 8 e l'esadecimale in base 16.
In Crystal, i normali numeri interi sono in base 10.
Il binario, l'ottale e l'esadecimale sono tutte rappresentazioni di numeri interi.
Questo significa che rappresentano numeri positivi e negativi (_incluso lo zero_) senza frazioni o decimali e supportano tutte le operazioni che possiamo fare con i numeri interi.

## Binario

Il [binario][binary] è un sistema di numerazione in base 2, che usa solo le cifre 0 e 1.
Rappresenta comunemente gli stati 0 («off») e 1 («on») del flusso elettrico attraverso transistor e interruttori nei computer, così come le cariche positive e negative nei supporti di memorizzazione magnetica.
Il binario può rappresentare tutti i numeri interi che si usano in base 10.

Uno stralcio del sistema in base 2 è questo, anche se continua all'infinito e non si ferma a 128:

| 128      | 64       | 32       | 16       | 8        | 4        | 2        | 1        |
| -------- | -------- | -------- | -------- | -------- | -------- | -------- | -------- |
| 2 \*\* 7 | 2 \*\* 6 | 2 \*\* 5 | 2 \*\* 4 | 2 \*\* 3 | 2 \*\* 2 | 2 \*\* 1 | 2 \*\* 0 |

Quindi, se vogliamo rappresentare il numero 6, in binario sarebbe: 110

| Place value   | 4   | 2   | 1   |
| ------------- | --- | --- | --- |
| Binary number | 1   | 1   | 0   |

E l'operazione sarebbe: `4 + 2 + 0 = 6`

Un altro esempio: 19

| Place value   | 16  | 8   | 4   | 2   | 1   |
| ------------- | --- | --- | --- | --- | --- |
| Binary number | 1   | 0   | 0   | 1   | 1   |

Il numero binario sarebbe: 10011
E l'operazione sarebbe: `16 + 0 + 0 + 2 + 1 = 19`

## Il binario in Crystal

In Crystal, possiamo rappresentare i letterali binari usando il prefisso `0b`.
Se scriviamo `0b10011`, Crystal lo interpreterà come numero binario e lo convertirà in base 10.

```crystal
0b10011
# => 19

typeof(0b10011)
# => Int32
```

Se scrivi un numero con il prefisso `0b` che non è nel sistema binario, verrà generato un errore di compilazione.

```crystal
0b10211
# => Error: unexpected token: "211"
```

### Operazioni con i numeri binari

Dato che i numeri binari sono numeri interi, possiamo eseguire su di essi tutte le operazioni che possiamo fare con i numeri interi.

```crystal
0b10011 + 0b10011
# => 38

0b10011 * 0b10011
# => 361

0b10011 / 3
# => 6.333333333333333
```

### Convertire da e verso la rappresentazione binaria

Crystal convertirà automaticamente un letterale binario in `Int32`.
Per convertire un `Int32` in una rappresentazione binaria, usa il metodo [`<int>.to_s(base)`][to_s] con l'argomento base impostato a 2.
Il metodo restituirà una rappresentazione sotto forma di stringa del numero binario:

```crystal
19.to_s(2)
# => "10011"
```

Per convertire la rappresentazione di un binario sotto forma di stringa in un numero intero, possiamo usare il metodo [`<int>.to_i(base)`][to_i], passando la base (2) come argomento:

```crystal
"10011".to_i(2)
# => 19
```

Indicare la base sbagliata (_o una rappresentazione binaria non valida_) genererà un `ArgumentError`:

```crystal
"011021".to_i(2)
# => Invalid Int32: "011021" (ArgumentError)
```

### Metodi per il binario

Esistono alcuni metodi che si possono usare sui numeri interi per ottenere informazioni sulla rappresentazione binaria del numero.

[`<int>.bit_length`][bit_length] restituirà il numero di bit necessari per rappresentare il numero:

```crystal
19.bit_length
# => 5
```

[`<int>.bit(index)`][bit] restituirà il bit all'indice indicato, partendo da destra (_bit meno significativo_):

```crystal
19.bit(0)
# => 1

0b10011.bit(1)
# => 1
```

## Ottale

L'[ottale][octal] è un sistema di numerazione in base 8.
Usa le cifre 0, 1, 2, 3, 4, 5, 6 e 7.

In Crystal, possiamo rappresentare i numeri ottali usando il prefisso `0o`.
Come per il binario, Crystal converte automaticamente una rappresentazione ottale in un `Int32`.

```crystal
0o123
# => 83
```

Scrivere un numero con il prefisso `0o` che non è nel sistema ottale genererà un errore di compilazione.

### Convertire da e verso la rappresentazione ottale

Come per il binario, possiamo usare il metodo [`<int>.to_s(base)`][to_s] per convertire un `Int32` in una rappresentazione ottale.
E possiamo usare il metodo [`<int>.to_i(base)`][to_s] per convertire una rappresentazione ottale in un `Int32`.

```crystal
83.to_s(8)
# => "123"

"123".to_i(8)
# => 83
```

Come per il binario, indicare la base sbagliata genererà un `ArgumentError`.

## Esadecimale

L'[esadecimale][hexadecimal] è un sistema di numerazione in base 16.
Usa le cifre da 0 a 9 e le lettere A, B, C, D, E e F.
A è 10, B è 11, C è 12, D è 13, E è 14 e F è 15.

Possiamo rappresentare i numeri esadecimali in Crystal usando il prefisso `0x`.
Come per il binario e l'ottale, Crystal convertirà automaticamente i letterali esadecimali in `Int32`.

```crystal
#=> 0x123
291
```
 
Scrivere un numero non esadecimale con il prefisso `0x` genererà un errore di compilazione.

###  Convertire da e verso la rappresentazione esadecimale

Come per il binario, possiamo usare il metodo [`<int>.to_s(base)`][to_i] per convertire un `Int32` in una rappresentazione esadecimale.
E possiamo usare il metodo [`<int>.to_i(base)`][to_s] per convertire una rappresentazione esadecimale in un `Int32`.

```crystal
291.to_s(16)
# => "123"

"123".to_i(16)
# => 291
```

Come per il binario e l'ottale, indicare la base sbagliata genererà un `ArgumentError`.

## Precisione

Quando convertiamo un numero in una rappresentazione sotto forma di stringa, possiamo specificare la precisione del numero.
Ovvero il numero **minimo** di cifre usate per rappresentare il numero.
Se il numero ha meno cifre della precisione, alla rappresentazione sotto forma di stringa verranno aggiunti degli zeri iniziali.
Per farlo, si passa l'argomento `precision` al metodo [`<int>.to_s(<base>, precision: <value>)`][to_s].

```crystal
291.to_s(16, precision: 5)
# => "00123"

543.to_s(precision: 2)
# => "543"
```
