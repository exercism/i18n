# Istruzioni

In questo esercizio, implementerai le meccaniche di un gioco di ruolo.
Il personaggio di un giocatore è rappresentato dal seguente tipo:

```fsharp
type Player = {
    Name: string option
    Level: int
    Health: int
    Mana: int option
}
```

In questo gioco, i giocatori devono raggiungere il livello 10 prima di sbloccare una riserva di mana, così da poter iniziare a lanciare incantesimi.
Lavorerai su due funzionalità di questo gioco: la meccanica di rianimazione e la meccanica di lancio degli incantesimi.

## 1. Presentati

Scrivi il contenuto della funzione `introduce`.
Nota che il campo `Name` del record `Player` è un'`Option`.
I giocatori furtivi potrebbero voler nascondere il proprio nome lasciandolo impostato a `None`: questi giocatori si presenteranno come `"Mighty Magician"`.
Altrimenti, presentati semplicemente con il tuo nome.

```fsharp
introduce { Name = None; Level = 2; Health = 8; Mana = None }
    --> "Mighty Magician"

introduce { Name = Some "Merlin"; Level = 2; Health = 8; Mana = None }
    --> "Merlin"
```

## 2. Implementa la meccanica di rianimazione

La funzione `revive` deve verificare che il personaggio del giocatore sia effettivamente morto (la sua salute ha raggiunto 0).
Se lo è, deve restituire una nuova istanza di `Player` con 100 di salute.
Altrimenti, se il personaggio del giocatore non è morto, la funzione `revive` restituisce `None`.

Se il livello del giocatore è pari o superiore a 10, deve essere rianimato anche con 100 di mana.
Se il livello del giocatore è inferiore a 10, il suo mana deve essere `None`.
La funzione `revive` deve preservare il livello del giocatore.

```fsharp
let deadPlayer = { Name = None; Level = 2; Health = 0; Mana = None }

revive deadPlayer
    --> Some { Name = None; Level = 2; Health = 100; Mana = None }
```

Se il metodo `revive` viene chiamato su un giocatore con salute pari o superiore a 1, la funzione deve restituire `None`.

```fsharp
let alivePlayer = { Name = None; Level = 2; Health = 42; Mana = None }

revive alivePlayer
    --> None
```

## 3. Implementa la meccanica di lancio degli incantesimi

La funzione `castSpell` prende come argomenti un `int`, che indica quanto mana costa l'incantesimo, e un `Player`.
Restituisce il giocatore aggiornato e la quantità di danno che l'incantesimo lanciato infligge.
Un lancio riuscito infligge un danno pari al doppio del costo in mana dell'incantesimo.
Tuttavia, se il giocatore non ha mana a sufficienza, non succede nulla: il giocatore resta invariato e non viene inflitto alcun danno.
Se il giocatore non ha nemmeno una riserva di mana, il tentativo di lanciare l'incantesimo deve ridurre la sua salute del costo in mana dell'incantesimo e non infligge alcun danno.

```fsharp
let wizard = { Name = None; Level = 18; Health = 123; Mana = Some 30 }

let updatedWizard, damage = castSpell 14 wizard

updatedWizard.Mana --> Some 16
damage             --> 28
```
