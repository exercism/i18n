# Introduzione

## Tipi struct

Abbiamo già visto i tipi struct; riassumendo, uno `struct` è una sequenza di elementi con un nome, chiamati _campi_, ognuno dei quali ha un nome e un tipo.
Il nome di un campo deve essere univoco all'interno dello struct.
Gli struct si possono paragonare alle _classi_ del paradigma della programmazione orientata agli oggetti.

Crei un nuovo struct usando le parole chiave `type` e `struct`, poi definisci esplicitamente il nome e il tipo dei campi, come mostrato nell'esempio qui sotto.

```go
type StructName struct{
    field1 fieldType1
    field2 fieldType2
}
```

## Tipi non struct

È anche possibile definire tipi non struct da usare come alias per le dichiarazioni di un tipo predefinito.

```go
type Name string
func SayHello(n Name) {
  fmt.Printf("Hello %s\n", n)
}
n := Name("Fred")
SayHello(n)
// Output: Hello Fred
```

Puoi anche definire tipi non struct composti da array e mappe.

```go
type Names []string
func SayHello(n Names) {
  for _, name := range n {
    fmt.Printf("Hello %s\n", name)
  }
}
n := Names([]string{"Fred", "Bill"})
SayHello(n)
// Output:
// Hello Fred
// Hello Bill
```
