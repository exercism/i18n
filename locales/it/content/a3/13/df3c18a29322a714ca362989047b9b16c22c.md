# Funzioni

In JavaScript, le funzioni sono _oggetti di prima classe_: questo significa che possono essere assegnate a variabili e proprietà, passate ad altre funzioni e restituite da funzioni. Possono avere proprietà e metodi, proprio come qualsiasi altro _oggetto_.

## Input: passare gli argomenti

Le funzioni JavaScript ti permettono di passare argomenti quando vengono chiamate. Gli argomenti vengono sempre [passati per valore](https://dev.to/xpbytes/javascript-ruby-and-c-are-not-call-by-reference-23f7). In altre parole, se una funzione riassegna un parametro al suo interno, il valore non cambierà all'esterno della funzione. Questo non significa che gli oggetti passati non possano essere modificati.

> [!TIP]
> Quando si passa un oggetto, il riferimento a quell'oggetto viene passato per valore. Questo fa _sembrare_ che il passaggio degli oggetti funzioni diversamente, ma non è così.

Un esempio di funzione che prende due argomenti e li moltiplica è:

```javascript
function multiply(a, b) {
  return a * b;
}

multiply(2, 3);
// => 6
```

## Output: valore restituito

JavaScript può restituire un singolo valore da una funzione usando la parola chiave `return`, seguita da un'espressione. Quando una funzione non restituisce nulla, il valore restituito è `undefined`.

Un esempio di funzione che restituisce un valore è:

```javascript
function multiply(a, b) {
  return a * b;
}

multiply(2, 3);
// => 6
```

## Definire le funzioni

In JavaScript esistono quattro tipi di funzioni:

1. Le funzioni normali, che possono restituire qualsiasi cosa e vengono sempre eseguite fino alla fine;
2. Le funzioni asincrone, che restituiscono sempre una `Promise` e possono essere messe in pausa e riprese con l'operatore `await`;
3. Le funzioni generatrici, che restituiscono sempre un oggetto `Generator` e possono essere messe in pausa e riprese con l'operatore `yield`;
4. Le funzioni generatrici asincrone, che restituiscono sempre un oggetto `AsyncGenerator` e possono essere messe in pausa e riprese con _entrambi_ gli operatori `yield` e `await`.

Per ciascuno di questi quattro tipi, ci sono tre modi per definirle:

1. usando una dichiarazione
2. usando un'espressione
3. usando il costruttore

Infine, esiste una sintassi speciale per definire le _funzioni arrow e i metodi_.
