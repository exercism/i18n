# Informazioni

[Clojure](http://clojure.org) è un linguaggio di programmazione dinamico che punta alla macchina virtuale Java (JVM).
Progettato come linguaggio di uso generale, Clojure combina l'accessibilità di un linguaggio di scripting con un'infrastruttura solida per la programmazione multithread.

Clojure è prevalentemente un linguaggio di programmazione funzionale e offre un ricco insieme di [strutture dati](http://clojure.org/data_structures) immutabili e persistenti.

Clojure è open source, e le informazioni su come contribuire al linguaggio [si trovano qui](http://clojure.org/contributing).

Rich Hickey, il creatore di Clojure, voleva un Lisp moderno per la programmazione funzionale, in simbiosi con la consolidata piattaforma Java e pensato per la concorrenza; così nacque Clojure.

Ecco un paio di citazioni che esemplificano gli obiettivi di Clojure:

* *«Il buon design non consiste nel fare grandi piani, ma nel saper scomporre le cose.»*
* *«Programmare non vuol dire digitare... vuol dire pensare.»*
