# Informazioni

Un'[istruzione switch][switch] ti permette di confrontare un valore con più valori corrispondenti possibili.
Ti consente di scrivere codice più conciso rispetto all'uso di più istruzioni `else-if`.
Un'istruzione switch inizia con la parola chiave `switch`, seguita dal valore da confrontare.
Successivamente puoi definire i casi usando la parola chiave `case`, seguita dal valore con cui confrontare.
La parola chiave `default` serve a definire il caso predefinito, quando nessuno dei casi corrisponde.
Come le istruzioni `else-if`, le istruzioni `switch` eseguono solo il blocco di codice associato al primo caso corrispondente.

```swift
switch value {
case 1:
    print("One")
case 2:
    print("Two")
default:
    print("Other")
}
```

Considera il seguente esempio:

```swift
if str == "apple" {
    print("Let's bake an apple crumble")
} else if str == "lemon" {
    print("Let's bake a lemon meringue pie!")
} else if str == "peach" {
    print("Let's bake a peach pie!")
} else {
    print("Let's buy ice cream.")
}
```

Si potrebbe invece scrivere così:

```swift
switch str {
case "apple":
    print("Let's bake an apple crumble")
case "lemon":
    print("Let's bake a lemon meringue pie!")
case "peach":
    print("Let's bake a peach pie!")
default:
    print("Let's buy ice cream.")
}
```
