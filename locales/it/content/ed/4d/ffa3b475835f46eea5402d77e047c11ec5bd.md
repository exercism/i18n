# Istruzioni

Il tuo gruppo d'archi tiene un recital e qualcuno deve scrivere il programma.

Tutte e cinque le attività vanno nella classe `PROGRAMME_NOTES`.

## 1. Dai un nome al brano e a chi l'ha scritto

Metti prima il brano, poi ` by `, poi il compositore.

```sather
PROGRAMME_NOTES::full_title("Nocturne", "Chopin")
-- => "Nocturne by Chopin"
```

## 2. Misura una riga

La stampante deve sapere quanto è lunga una riga.

```sather
PROGRAMME_NOTES::title_length("Nocturne")
-- => 8
```

## 3. Le prime lettere

Dato un titolo e un numero, restituisci altrettante lettere dall'inizio.

```sather
PROGRAMME_NOTES::opening_letters("Nocturne", 3)
-- => "Noc"
```

## 4. Le ultime lettere

Lo stesso, contando dalla fine.

```sather
PROGRAMME_NOTES::closing_letters("Nocturne", 4)
-- => "urne"
```

## 5. Accorcia un titolo lungo

I titoli che non entrano vengono tagliati alle loro prime sei lettere, seguite da tre punti.

```sather
PROGRAMME_NOTES::short_title("Nocturne in E flat")
-- => "Noctur..."
```
