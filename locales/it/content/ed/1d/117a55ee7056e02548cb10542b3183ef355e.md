# Introduzione

In Elixir le funzioni sono trattate come cittadini di prima classe. Questo significa che:

- Le funzioni con nome e quelle anonime possono essere assegnate a variabili.
- Le funzioni con nome e quelle anonime possono essere passate in giro come dati, come argomenti e come valori restituiti.
- Le funzioni anonime possono essere create dinamicamente.

Le funzioni anonime, a differenza di quelle con nome, non hanno un riferimento statico disponibile: sono disponibili solo se vengono assegnate a una variabile o chiamate immediatamente.

Possiamo usare le funzioni anonime per:

- Nascondere dati usando lo scope lessicale (chiamato anche closure).
- Creare funzioni dinamicamente a runtime.

Le funzioni anonime iniziano con la parola riservata `fn`, gli argomenti sono separati dal corpo della funzione con il token `->`, e terminano con un `end`. Come per le funzioni con nome, l'ultima espressione della funzione viene _restituita implicitamente_ alla funzione chiamante.

Per chiamare un riferimento a una funzione, devi usare un `.` tra la variabile di riferimento e l'elenco degli argomenti:

```elixir
function_variable = fn param ->
  param + 1
end

function_variable.(1)
# => 2
```

Puoi anche usare la notazione abbreviata di cattura per rendere il tutto più conciso:

```elixir
variable = &(&1 + 1)

variable.(1)
# => 2
```
