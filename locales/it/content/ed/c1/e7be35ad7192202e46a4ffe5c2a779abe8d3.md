# Introduzione

Tutto il codice Common Lisp è fatto di S-Expressions (Symbolic Expressions). Per brevità vengono chiamate sexpr. Ogni sexpr è un atom oppure un cons. Quando le S-Expressions vengono valutate, restituiscono automaticamente un valore che prende il posto dell'espressione. Quando scrivi le tue funzioni (usando `defun`), l'ultimo valore all'interno del corpo della `defun` viene restituito automaticamente:

```lisp
;; Defining a new function
(defun gimme-foo () 'foo)
;; Calling the function as an S-Expression
(gimme-foo) ; => FOO
```
