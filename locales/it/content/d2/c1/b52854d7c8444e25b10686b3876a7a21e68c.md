# Introduzione

## Numeri interi

I numeri interi sono numeri senza parte frazionaria che appartengono all'insieme `{..., -2, -1, 0, 1, 2, ...}`.
I valori massimo e minimo di un numero intero sono determinati dal sistema su cui gira PHP.
In genere, sulla maggior parte dei sistemi moderni, il numero intero è un valore a 64 bit, il che significa che può rappresentare da `-9_223_372_036_854_775_808` a `9_223_372_036_854_775_807` inclusi.

```php
<?php

$a = 1234;
$a = 1_234_567;
```

Puoi scrivere valori letterali interi in basi diverse dalla base 10 usando un prefisso di base:

```php
<?php

$a = 0123; // octal number (equivalent to 83 decimal)
$a = 0o123; // octal number (as of PHP 8.1.0)
$a = 0x1A; // hexadecimal number (equivalent to 26 decimal)
$a = 0b11111111; // binary number (equivalent to 255 decimal)
```

> Tratto dalla [documentazione][syntax] di PHP

## Numeri in virgola mobile

I numeri in virgola mobile sono usati in PHP per rappresentare un sottoinsieme dei numeri reali.
Iniziano con una o più cifre separate da un separatore decimale.

```php
<?php

$a = 1.234; 
$b = 1.2e3; 
$c = 7E-10;
$d = 1_234.567; // as of PHP 7.4.0
```

### Errori comuni

Non tutti i numeri e le operazioni aritmetiche possono essere eseguiti con i numeri in virgola mobile.
Usare i numeri in virgola mobile per rappresentare dollari e centesimi può portare a errori di arrotondamento.

```php
<?php

$result = 0.1 + 0.2; // => 0.30000000000000004
```

## Operatori aritmetici

PHP mette a disposizione diversi operatori per eseguire operazioni aritmetiche. PHP segue l'ordine di operazioni matematico standard per i suoi operatori aritmetici. Gli operatori forniti da PHP sono:

* Identità (+)
* Negazione (-)
* Addizione (+)
* Sottrazione (-)
* Moltiplicazione (*)
* Divisione (/)
* Modulo (%)
* Esponenziazione (**)

```php
$moles = +'10';
$aLotOfMoles = 6.022 * 10**23 * $moles;
```
