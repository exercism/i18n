# Operatore ternario

L'operatore ternario offre una sintassi alternativa per eseguire un confronto `if..else..` e restituire un valore.

## Sintassi

PHP offre un'istruzione if in cui un'azione può essere valutata in base alla «truthiness» di una condizione.

```php
if ($condition) {
  $value = 1;
} else {
  $value = 2
}
```

In alternativa, l'operatore ternario può rappresentare la stessa operazione:

```php
$value = $condition
  ? 1  // True branch
  : 2; // False branch
```

La sintassi del confronto è breve, rappresentata da `(condition) ? (evaluate if true) : (evaluate if false);`.

## Vantaggi

Il vantaggio più evidente dell'uso di un operatore ternario è la brevità: l'espressione condizionale si scrive in meno spazio rispetto a un'istruzione `if..else..`. Ma ce ne sono diversi altri:

- È un'espressione che può essere usata all'interno di un'altra espressione
- Favorisce la valutazione pigra di ciascun ramo.

  ```php
  function expensiveCalculation(): int
  {
    // An expensive calculation is performed
    $answerToEverything = 42;
    return $answerToEverything;
  }

  $needExactAnswer = false;
  $estimatedAnswer = 40;
  $answer = $needExactAnswer ? expensiveCalculation() : $estimatedAnswer;
  ```

  In questo esempio, se la risposta esatta non è necessaria, il calcolo costoso non viene eseguito.

## Svantaggi

Gli operatori ternari hanno diversi svantaggi, quindi è importante valutarne l'uso:

- Un operatore ternario può essere più difficile da leggere, perché richiede di interpretare dei simboli invece di usare delle parole chiave.
- Un operatore ternario può portare inavvertitamente a dei bug, perché in PHP è associativo a sinistra, al contrario della maggior parte dei linguaggi contemporanei (ad es. C, Java, JavaScript).
- L'espressione valutata nei rami true e false deve restituire un valore.

## Ancora più breve

La sintassi ternaria può essere ulteriormente abbreviata in `(condition) ?: (evaluate if falsey)`.
Un possibile uso è fornire un valore di riserva all'interno di un'espressione:

```php
$fruit = null;
eat($fruit ?: 'apple');
```

Questo è anche talvolta noto come _operatore Elvis_ (`?:`).
