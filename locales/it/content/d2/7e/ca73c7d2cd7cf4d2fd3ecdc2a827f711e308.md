# Calcolatrice da cucina

## Storia

La storia facilita l'esplorazione delle [tuple][type-tuple] in un linguaggio.

La premessa di base è che spesso gli ingredienti da cucina si misurano in modi oscuri e richiedono conversioni diverse a seconda delle quantità o degli strumenti a disposizione.

Le tuple servono a fornire [duck typing][concept-duck-typing] alla componente numerica della misurazione.

Qui quindi si esplora la conversione di base dei valori usando numeri in virgola mobile.

### Conversioni

| Da                 | A       |
| ------------------ | ------- |
| 1 mL               | 1mL     |
| 1 tazza            | 240mL   |
| 1 oncia liquida (US) | 29.57mL |
| 1 cucchiaino       | 5 mL    |
| 1 cucchiaio        | 15 mL   |

## Attività

Questo dovrebbe guidare gli studenti a usare:

- Le tuple
- Le tuple come informazioni raggruppate
- Ottenere valori da una tupla usando l'indice degli elementi
- Ottenere valori da una tupla usando il pattern matching
- Creare nuove tuple
