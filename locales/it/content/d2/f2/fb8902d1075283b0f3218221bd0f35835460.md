# Informazioni

Gleam ha funzioni di prima classe: le funzioni sono valori normali che possono essere assegnati a delle variabili, passati come argomenti e restituiti da altre funzioni.

Una funzione con nome definita in un modulo può essere riferita tramite il suo nome.

```gleam
pub fn main() {
  // Assign the function to a variable
  let f = add_one
  
  // Invoke the function
  f(1) // -> 2
  f(2) // -> 3
}

fn add_one(x) {
  x + 1
}
```

Gleam ha anche le funzioni anonime, che si definiscono all'interno di altre funzioni.

```gleam
// Define the function
let f = fn(x) { x + 1 }

// Invoke the function
f(1) // -> 2
f(2) // -> 3
```

Il tipo di una funzione si scrive usando una sintassi simile a quella delle funzioni anonime. Il tipo di una funzione che prende un `Int` ed un `Float` e restituisce un `Int` si scrive così:

```gleam
fn(Int, Float) -> Int
```

Le funzioni anonime possono riferirsi a variabili che erano nello scope quando sono state definite, rendendole delle _closure_.

```gleam
let secret_number = 42

// This function always returns 42
fn() { secret_number }
```

La sintassi di _cattura della funzione_ offre una comoda scorciatoia per creare funzioni anonime che passano un singolo argomento a una funzione. Queste due espressioni sono equivalenti:

```gleam
// Anonymous function syntax
let f = fn(x) { my_function(1, 2, x) }

// Function capture syntax
let f = my_function(1, 2, _)
```
