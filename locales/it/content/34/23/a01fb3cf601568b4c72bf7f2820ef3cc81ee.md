# Test

## Eseguire i test

Il track Haxe si basa sul framework di test [Buddy](https://github.com/ciscoheat/buddy).
Puoi installarlo con il comando seguente:

```bash
haxelib install buddy
```

Per eseguire i test, lancia questo comando:

```bash
haxe test.hxml
```

Nel file di test, ogni blocco `describe` contrassegna una sezione di test dell'esercizio, e ogni test è un blocco `it` o `xit`.
I blocchi `it` vengono eseguiti quando lanci i test, mentre i blocchi `xit` sono test in sospeso.
Quando invii una soluzione, il test runner di Exercism eseguirà tutti i blocchi `it` o `xit`.
In locale, invece, per impostazione predefinita viene eseguito solo il primo test.
Per eseguire gli altri test, trasforma i blocchi `xit` corrispondenti in blocchi `it` e rilancia `haxe test.hxml`.


Inoltre, alcuni esercizi potrebbero richiedere l'installazione di librerie aggiuntive tramite haxelib.
In quel caso, troverai una nota nelle istruzioni dell'esercizio.

## Risolvere l'esercizio

Risolvere un esercizio significa far passare tutti i suoi test.
Per aiutarti a iniziare, ogni esercizio include un file di implementazione stub.
Puoi usare questo file come punto di partenza per costruire la soluzione.
Sentiti libero di rimuovere o modificare questo file se ritieni che sia la cosa giusta da fare.
Prova a concentrarti su un test alla volta mentre lavori verso la soluzione.
