# Istruzioni

Continui a lavorare sul sistema di gestione del magazzino che hai costruito in precedenza.
Dopo aver scoperto `OpenStruct` e le scorciatoie di blocco, hai deciso di riorganizzare un po' il codice.
Invece di memorizzare gli articoli come hash, metterai a frutto le tue nuove competenze.

## 1. Consenti il recupero degli articoli

Vuoi continuare a recuperare l'elenco degli articoli in magazzino, ma questa volta devono essere oggetti su cui poter chiamare dei metodi.

```ruby
inventory = BoutiqueInventory.new([
  {price: 65.00, name: "Maxi Brown Dress", quantity_by_size: {s: 3, m: 7, l: 8, xl: 4}},
  {price: 50.00, name: "Red Short Skirt", quantity_by_size: {}},
  {price: 29.99, name: "Black Short Skirt", quantity_by_size: {s: 1, xl: 4}},
  {price: 20.00, name: "Bamboo Socks Cats", quantity_by_size: {s: 7, m: 2}}
])

inventory.items.first.name
# => "Maxi Brown Dress"

inventory.items.first.price
# => 65

inventory.items.size
# => 4
```

## 2. Riorganizza `item_names`

Riorganizza `item_names` in modo che usi la nuova scorciatoia di blocco che hai imparato, invece degli hash.
Come promemoria, il metodo deve restituire:

```ruby
BoutiqueInventory.new([
  {price: 65.00, name: "Maxi Brown Dress", quantity_by_size: {s: 3, m: 7, l: 8, xl: 4}},
  {price: 50.00, name: "Red Short Skirt", quantity_by_size: {}},
  {price: 29.99, name: "Black Short Skirt", quantity_by_size: {s: 1, xl: 4}},
  {price: 20.00, name: "Bamboo Socks Cats", quantity_by_size: {s: 7, m: 2}}
]).item_names

# => ["Bamboo Socks Cats", "Black Short Skirt", "Maxi Brown Dress", "Red Short Skirt"]
```

## 3. Riorganizza `total_stock`

Riorganizza `total_stock` in modo che usi il metodo di OpenStruct, invece di fare riferimento a un hash.
Come promemoria, il metodo deve restituire:

```ruby
BoutiqueInventory.new([
  {price: 65.00, name: "Maxi Brown Dress", quantity_by_size: {s: 3, m: 7, l: 8, xl: 4}},
  {price: 50.00, name: "Red Short Skirt", quantity_by_size: {}},
  {price: 29.99, name: "Black Short Skirt", quantity_by_size: {s: 1, xl: 4}},
  {price: 20.00, name: "Bamboo Socks Cats", quantity_by_size: {s: 7, m: 2}}
]).total_stock

# => 36
```
