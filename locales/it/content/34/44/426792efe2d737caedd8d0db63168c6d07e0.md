# Introduzione

## Nil

In Gleam, `Nil` è un tipo con un unico valore, chiamato anch'esso `Nil`. È simile a `void` di altri linguaggi: si usa quando una funzione non ha un valore più adatto da restituire.

```gleam
io.println("Hello, Joe!")
// -> Nil
```

I valori in Gleam non sono «nil-able» o «nullable» come in alcuni altri linguaggi. Un valore può essere `Nil` solo se il suo tipo è `Nil`, e un valore di qualsiasi altro tipo non può mai essere `Nil`.

## IO

Come la maggior parte dei linguaggi di programmazione, Gleam ha gli «effetti collaterali»: le funzioni possono leggere e cambiare lo stato del mondo, oltre a restituire un valore.

Il modulo `gleam/io` della libreria standard di Gleam fornisce funzioni per stampare stringhe sulla console.

```gleam
io.println("Hello, Joe!")
// Hello, Joe!
// -> Nil
```

Altri pacchetti possono fornire altre funzioni di IO, come `simplifile`, un pacchetto che fornisce funzioni per leggere e scrivere file.

```gleam
simplifile.read("favourite-colour.txt")
// -> Ok("Pink\n")
```
