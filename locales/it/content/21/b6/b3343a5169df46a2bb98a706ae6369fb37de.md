Come aspirante maga, Elyse deve esercitarsi con le basi.
Ha un mazzo di carte che vuole manipolare.

Per rendere le cose un po' più semplici, usa solo le carte dall'1 al 10.

## 1. Recuperare una carta dal mazzo

Restituisci la carta in posizione `idx` del mazzo dato.

```julia-repl
julia> idx = 2;

julia> card([1, 3, 4, 1], idx)
3
```

## 2. Scambiare una carta nel mazzo

Scambia la carta in posizione `idx` con la nuova carta fornita e restituisci il mazzo aggiornato.
Nota che questo modificherà (cambierà) il vettore di input e va bene così.

```julia-repl
julia> idx = 2; new_card = 6;

julia> replace_card!([1, 3, 4, 1], idx => new_card)
[1, 6, 4, 1]
```

## 3. Inserire una carta in cima al mazzo

Inserisci una nuova carta in cima al mazzo e restituisci il mazzo.

```julia-repl
julia> new_card = 8;

julia> insert_card_at_top!([1, 3, 4, 1], new_card)
[1, 3, 4, 1, 8]
```

## 4. Rimuovere una carta dal mazzo

Rimuovi la carta in posizione `idx` dal mazzo e restituisci il mazzo.

```julia-repl
julia> idx = 2;

julia> remove_card!([1, 3, 4, 1], idx)
[1, 4, 1]
```

## 5. Rimuovere la carta in cima al mazzo

Rimuovi la carta in cima al mazzo e restituisci il mazzo.

```julia-repl
julia> remove_card_from_top!([1, 3, 4, 1])
[1, 3, 4]
```

## 6. Inserire una carta in fondo al mazzo

Inserisci una nuova carta in fondo al mazzo e restituisci il mazzo.

```julia-repl
julia> new_card = 8;

julia> insert_card_at_bottom!([1, 3, 4, 1], new_card)
[8, 1, 3, 4, 1]
```

## 7. Rimuovere una carta dal fondo del mazzo

Rimuovi la carta in fondo al mazzo e restituisci il mazzo.

```julia-repl
julia> remove_card_at_bottom!([1, 3, 4, 1])
[3, 4, 1]
```

## 8. Verificare la dimensione del mazzo

Verifica se la dimensione del mazzo è uguale a un dato `deck_size` oppure no.

```julia-repl
julia> deck_size = 4;

julia> check_deck_size([1, 3, 4, 1], deck_size)
true

julia> check_deck_size([1, 3, 4, 1, 5], deck_size)
false
```
