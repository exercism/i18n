# Introduzione

## Applicazioni web

Elm è un linguaggio delizioso per costruire applicazioni web affidabili.
Ha messaggi di errore amichevoli, ottime prestazioni, asset di piccole dimensioni e nessuna eccezione a runtime.

Probabilmente la parte più famosa e più copiata di Elm è The Elm Architecture, un semplice pattern per strutturare le applicazioni web: è così che vengono scritte tutte le applicazioni web in Elm.

L'idea centrale è che il codice è costruito attorno a un `Model` dello stato dell'applicazione, a un modo per fare `update` del modello e a un modo per fare `view` del modello.

Il `Model` contiene lo stato dell'applicazione: tutti i dati di cui l'applicazione ha bisogno.
Se immagini un'applicazione semplice con una casella di testo e un testo che ne mostra il contenuto invertito, il modello sarà simile a quello qui sotto.
Puoi anche vedere questo esempio nella [Guida di Elm][elm-guide-text-fields].

```elm
type alias Model =
  { text : String
  }
```

`update` è una funzione che viene chiamata con un `Msg` quando c'è un cambiamento (ad esempio quando l'utente clicca un pulsante).
Prende il `Msg` e il `Model` attuale e restituisce un nuovo `Model`.

```elm
type Msg
  = TextChanged String

update : Msg -> Model -> Model
update msg model =
  case msg of
    TextChanged newText ->
      { model | text = newText }
```

`view` è una funzione che restituisce l'HTML da mostrare all'utente nel browser.
Prende il `Model` attuale e restituisce un `Html Msg` (il tipo che Elm usa per rappresentare l'HTML).

```elm
view : Model -> Html Msg
view model =
  Html.div []
    [ Html.input
      [ Html.Attributes.placeholder "Text to reverse"
      , Html.Attributes.value model.text
      , Html.Events.onInput TextChanged
      ]
      []
    , Html.div [] [ Html.text (String.reverse model.text) ]
    ]
```
