# Istruzioni

Sei di nuovo in cucina, a rifinire la ricetta delle lasagne da
[Le deliziose lasagne di Leah][lasagna]. Le attività di questo esercizio
ti chiederanno di gestire più input contemporaneamente: ed è proprio in
questi casi che le *variabili locali*, cioè i binding con nome di Factor,
si rivelano preziose.

## 1. Determina lo stato di cottura

Definisci `cooking-status` in modo che prelevi una lettura del timer
dallo stack e restituisca una stringa di stato.

- `0` → `"Lasagna is done."`
- `f` (il timer non è mai stato impostato) → `"You forgot to set the timer."`
- qualsiasi altro numero → `"Not done, please wait."`

```factor
12 cooking-status .   ! => "Not done, please wait."
0 cooking-status .    ! => "Lasagna is done."
f cooking-status .    ! => "You forgot to set the timer."
```

## 2. Stima il tempo di preparazione

Definisci `preparation-time` in modo che prenda un array di nomi di
strato e un numero medio di minuti per strato, e restituisca il tempo
di preparazione totale.

```factor
{ "sauce" "noodles" "sauce" "meat" "mozzarella" "noodles" } 3 preparation-time .
! => 18
```

## 3. Calcola le quantità di noodles e sugo necessarie

Definisci `quantities` in modo che prenda un array di nomi di strato e
restituisca *due* valori: i grammi di noodles necessari (50 g per ogni
strato di noodles) e i litri di sugo necessari (`1/5` di litro per ogni
strato di sugo).

```factor
{ "sauce" "noodles" "sauce" "meat" "mozzarella" "noodles" } quantities .s
! => 100
! => 2/5
```

## 4. Aggiungi l'ingrediente segreto

Una persona amica ti manda un elenco di ingredienti: l'*ultimo*
elemento è il suo ingrediente segreto. Definisci `add-secret-ingredient`
in modo che prenda il suo elenco e il tuo e restituisca il tuo elenco
con l'ingrediente segreto aggiunto in fondo.

```factor
{ "noodles" "sauce" "mozzarella" "kampot pepper" }
{ "noodles" "meat" "sauce" "mozzarella" }
add-secret-ingredient .
! => { "noodles" "meat" "sauce" "mozzarella" "kampot pepper" }
```

## 5. Ridimensiona la ricetta

La ricetta del libro di cucina produce due porzioni. Definisci
`scale-recipe` in modo che prenda una ricetta (una hashtable che associa
il nome di un ingrediente alla sua quantità) e un numero di porzioni
obiettivo, e restituisca una nuova ricetta scalata di conseguenza.

```factor
H{ { "noodles" 200 } { "sauce" 1/2 } { "mozzarella" 1 } { "meat" 100 } }
4 scale-recipe .
! => H{ { "noodles" 400 } { "sauce" 1 } { "mozzarella" 2 } { "meat" 200 } }
```
