# Appendice alle istruzioni

## Parole

`convert ( rows -- str )` prende la griglia come un array di stringhe,
una stringa per riga, e restituisce le cifre riconosciute come un'unica
stringa. Più righe di celle vengono unite nell'output con
virgole (`,`).

## Errori

Lancia una di queste stringhe (esattamente come sono scritte) per input malformati:

- `"Number of input lines is not a multiple of four"`
- `"Number of input columns is not a multiple of three"`
