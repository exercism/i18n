# Dizionari

I dizionari in Cairo sono archivi chiave-valore simili a mappe o tabelle hash di altri linguaggi.

Tuttavia, hanno alcune caratteristiche uniche dovute al modello di memoria immutabile di Cairo.

## Concetto fondamentale

Il tipo `Felt252Dict<T>` fornisce la funzionalità di dizionario in Cairo, con `felt252` come tipo delle chiavi e qualsiasi tipo supportato `T` come tipo dei valori.

```rust
use core::dict::Felt252Dict;

fn main() {
    let mut balances: Felt252Dict<u64> = Default::default();
    balances.insert('Alice', 100);
    let balance = balances.get('Alice'); // Returns 100
}
```

## Caratteristiche importanti

A differenza dei dizionari di altri linguaggi, i dizionari di Cairo hanno alcune proprietà speciali:

1. Le chiavi devono essere valori `felt252`.
2. Tutte le chiavi iniziano implicitamente con un valore pari a zero.
3. Non è possibile eliminare voci: è possibile solo aggiornare i valori.
4. I valori devono implementare il trait `Felt252DictValue`.

## Nota sulle prestazioni

A causa del modello di memoria immutabile di Cairo, le operazioni sui dizionari hanno complessità $O(n)$, dove $n$ è il numero di operazioni eseguite sul dizionario.

Ogni operazione crea una nuova voce che registra la modifica.

## Lavorare con tipi complessi

Per i tipi che non implementano `Felt252DictValue` (come gli array o le struct), puoi racchiuderli in `Nullable<T>`:

```rust
let mut dict: Felt252Dict<Nullable<Span<felt252>>> = Default::default();
dict.insert(0, NullableTrait::new(array![1, 2, 3].span()));
```

## Gestione della memoria

I dizionari implementano il trait `Destruct`: vengono automaticamente «schiacciati» (validati e ottimizzati) quando escono dallo scope.

Questo fa parte del sistema di dimostrazione di Cairo e avviene dietro le quinte.

Ricorda: anche se i dizionari possono sembrare meno efficienti rispetto ad altri linguaggi, sono progettati così per funzionare con il modello di memoria unico di Cairo e con i requisiti del suo sistema di dimostrazione.
