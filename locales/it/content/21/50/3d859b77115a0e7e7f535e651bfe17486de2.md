# Introduzione

### Le inclusioni

In generale, in programmazione non vuoi reinventare la ruota.
Per molti algoritmi standard, probabilmente c'è già qualcuno che ha fatto il lavoro per te.

### La direttiva include

Per includere il contenuto di altri file, C++ usa la direttiva `include`.
Queste inclusioni vanno dichiarate in cima al file.
Durante la compilazione, la riga con la direttiva viene sostituita dal contenuto del rispettivo file.
Dopo le inclusioni, i namespace restano quelli del file originale.

### La libreria standard

La libreria standard offre molte funzioni, algoritmi e strutture dati comuni.
La libreria standard usa il namespace `std`.

Un esempio è la libreria numerica del C, `cmath`: fornisce molte operazioni matematiche comuni.

```cpp
#include <cmath>

int cube_me(int a) {
    // raise `a` to the third power
    return std::pow(a, 3);
}
```

~~~~exercism/note
Le librerie standard si includono con le parentesi angolari (`<>`) al posto delle virgolette doppie (`"`).
La differenza sta in dove il compilatore cerca i rispettivi file.
Con le parentesi angolari, la ricerca nel progetto corrente viene saltata e si parte direttamente dalle directory di inclusione del sistema.
Se vuoi includere file locali, usa le virgolette doppie: `#include "myfile"`
~~~~

## Stringhe

In C++ una `string` è un oggetto mutabile che rappresenta il testo come una sequenza di caratteri (lettere, cifre, punteggiatura, ecc.).
Le stringhe si manipolano chiamando i metodi della stringa.

### La libreria delle stringhe

In C++, il tipo stringa e le funzioni associate devono essere inclusi dalla libreria delle stringhe prima di poterli usare.
Puoi farlo aggiungendo `#include <string>` in cima al file.
A quel punto popoleranno il namespace `std`.
Il nome completo del tipo stringa è `std::string`.
Il letterale stringa usa il carattere delle virgolette doppie: `"`.

```cpp
#include <string>
std::string w_berry_quote{"A well-made sentence, I think, is a thing of beauty."};
```

### Operazioni comuni sulle stringhe

Puoi usare l'operatore `+` per concatenare le stringhe:

```cpp
std::string original_title{"The School of Rock"};
std::string sequel_indicator{"Electric Boogaloo"};
std::string next_movie_title = original_title + " 2: " + sequel_indicator;
```

Per usare la libreria delle stringhe, devi sapere che è possibile chiamare una funzione che appartiene a un oggetto.
Queste si chiamano funzioni membro.
Più avanti nel programma del corso imparerai di più sulle funzioni membro e sul concetto di classe a esse collegato.

```cpp
std::string qualification{"awesome"};
// 1st argument: from the index to the end of the string:
std::string who_is_awesome = qualification.substr(5);
// => "me"

// 2nd optional argument for the length:
std::string material{"haunted books"};
std::string ghost = material.substr(8, 3);
// => "boo"
```

Anche la funzione `find` è molto utile.
Si chiama come funzione membro sulla stringa e prende una stringa come argomento.
`find` restituisce la posizione, con indice che parte da zero, della _prima_ occorrenza nella stringa.

```cpp
std::string new_release{"apple released a new app!"};
new_release.find("app");
// => 0
new_release.find("e");
// => 4
```
