# Introduzione

Una `Tuple` è molto simile a un `Vector` (un `array` monodimensionale) sotto molti aspetti. Ci sono però alcune differenze importanti.

- Le tuple si scrivono tra parentesi tonde (`( )`) invece che tra parentesi quadre (`[ ]`), anche se le parentesi si possono omettere quando il significato è inequivocabile.
- Le tuple non devono essere omogenee: il tipo di ogni elemento viene memorizzato in modo indipendente.
- Le tuple sono immutabili.

L'immutabilità consente al compilatore di ottimizzare meglio il codice e rende le tuple più performanti degli array, quindi conviene preferirle quando la mutabilità non è necessaria.

```julia-repl
julia> t = (3, 5.2, "xyz")
(3, 5.2, "xyz")

# Non-homogeneous:
julia> dump(t)
Tuple{Int64, Float64, String}
  1: Int64 3
  2: Float64 5.2
  3: String "xyz"

julia> t[2]
5.2

# Immutable:
julia> t[2] = 7.3
ERROR: MethodError: no method matching setindex!(::Tuple{Int64, Float64, String})
```

Esiste anche un costruttore `Tuple()`, che trasforma qualsiasi collezione iterabile in una tupla. Cosa utile, tratta una stringa come una collezione iterabile di caratteri.

```julia-repl
julia> Tuple("Julia")
('J', 'u', 'l', 'i', 'a')
```

Per qualsiasi tupla è possibile accedere agli elementi tramite l'indice oppure iterarli con un ciclo.

Qualsiasi tupla puramente numerica può anche essere usata in funzioni matematiche come `sum()`, esattamente come gli array.

## Spacchettamento

Si può spacchettare una tupla nei singoli elementi usando l'assegnazione multipla.
Per gli elementi che non servono, usa il trattino basso `_` come variabile fittizia.

```julia-repl
julia> tup = (1, "Julia", true)
(1, "Julia", true)

julia> num, name, _ = tup
(1, "Julia", true)

julia> uppercase(name), 2num
("JULIA", 2)
```

Chi programma in Python conoscerà molto bene questa sintassi di assegnazione multipla.

## Tuple con nome

Una `Tuple` contiene solo valori.
Un `NamedTuple` associa a ogni valore un nome.

Ai singoli campi si può poi accedere con la notazione «punto»:

```jullia-repl
julia> nt = (a = 1, b = 7.3)
(a = 1, b = 7.3)

julia> dump(nt)
@NamedTuple{a::Int64, b::Float64}
  a: Int64 1
  b: Float64 7.3

julia> nt.b
7.3
```

Il nome è memorizzato internamente come `Symbol` (un tipo immutabile, e il nome è preceduto dai due punti `:`), quindi è disponibile una sintassi alternativa:

```julia-repl
julia> nt[:b]
7.3
```

È facile ottenere separatamente i nomi (chiamati anche «chiavi») oppure i valori:

```julia-repl
julia> nt
(a = 1, b = 7.3)

julia> keys(nt)
(:a, :b)

julia> values(nt)
(1, 7.3)
```

Tieni presente che iterando su una tupla con nome si ottengono solo i _valori_, mentre i _nomi_ vengono ignorati.

Le tuple, con o senza nome, sono un modo molto comune per trasferire dati strutturati da e verso le funzioni.
In questo caso l'immutabilità è un vantaggio, perché garantisce la sicurezza dei dati e consente ottimizzazioni del compilatore più aggressive.
