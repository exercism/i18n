# Introduzione

Gleam può girare sulla macchina virtuale Erlang (BEAM) oppure sui runtime JavaScript. Esistono molti altri linguaggi che usano questi runtime, e spesso è utile poter chiamare da Gleam del codice scritto in questi linguaggi.

La funzionalità delle «funzioni esterne» di Gleam permette di importare in Gleam funzioni scritte in altri linguaggi e di chiamarle senza alcun overhead a runtime.

Se il tuo progetto Gleam gira sulla macchina virtuale Erlang e vuoi chiamare la funzione `reverse` dal modulo `lists` di Erlang, puoi farlo aggiungendo l'attributo `@external` all'intestazione di una funzione Gleam, così:

```gleam
@external(erlang, "lists", "reverse")
pub fn reverse_list(x: List(a)) -> List(a)
```

A questo punto la puoi chiamare come una normale funzione Gleam:

```gleam
let reversed = reverse_list([1, 2, 3])
// -> [3, 2, 1]
```

Se provi a compilare questo codice per i runtime JavaScript, la compilazione fallirà con un messaggio di errore, perché non esiste un'implementazione per JavaScript. Si può specificare un'altra implementazione per i runtime JavaScript, così:

```gleam
@external(erlang, "lists", "reverse")
@external(javascript, "./my_module.mjs", "reverse")
pub fn reverse_list(x: List(a)) -> List(a)
```

È anche possibile scrivere un'implementazione in Gleam che verrà usata quando non esiste un'implementazione esterna per il target di compilazione corrente:

```gleam
@external(erlang, "lists", "reverse")
pub fn reverse_list(x: List(a)) -> List(a) {
  tail_recursive_reverse(x, [])
}

fn tail_recursive_reverse(list, reversed) {
  case list {
    [] -> reversed
    [x, ..xs] -> tail_recursive_reverse(xs, [x, ..reversed])
  }
}
```
