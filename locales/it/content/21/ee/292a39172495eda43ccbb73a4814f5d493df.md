# Istruzioni

Astrid, un'alchimista intraprendente, sta cercando di standardizzare le unità magiche di misura che raccoglie da regni diversi.
Alcuni regni usano misure con segno (che possono essere negative), mentre altri usano misure senza segno (che sono sempre positive).
In più, Astrid ha due tipi personalizzati per certi ingredienti rari, e le serve un modo per convertire facilmente tra questi tipi.

La tua missione è aiutare Astrid a convertire tra interi con segno e senza segno, e a creare conversioni personalizzate per i suoi tipi di ingredienti speciali usando i trait `Into` e `TryInto` di Cairo.

## 1. Convertire le unità magiche tra valori con segno e senza segno

Astrid ha misure che a volte hanno valori positivi o negativi (interi con segno), ma per alcune attività deve assicurarsi che i valori siano sempre positivi (interi senza segno).

Aiuta Astrid scrivendo una funzione che converte:

1. Un intero con segno (`i32`) in un intero senza segno (`u16`).
2. Un intero senza segno (`u16`) in un intero con segno (`i32`).

```rust
let signed_value: i32 = -42;
match convert_signed_to_unsigned(signed_value) {
    Option::Some(v) => println!("Converted to unsigned: {}", v),
    Option::None => println!("Failed to convert: {}", signed_value),
} // prints "Failed to convert: -42"

let unsigned_value: u16 = 42;
let signed_value: i32 = convert_unsigned_to_signed(unsigned_value);
println!("Converted to signed: {}", signed_value); // prints "Converted to signed: 42"
```

## 2. Conversione dei tipi di ingredienti personalizzati

Astrid lavora con due ingredienti rari, **Essence** e **Elixir**, rappresentati da tipi personalizzati.
Vuole poter convertire **Essence** in **Elixir**, ma non il contrario.

Aiuta Astrid creando due tipi personalizzati, `Essence` e `Elixir`, e implementando il trait `Into` per convertire da `Essence` a `Elixir`.

Scrivi una funzione che accetta un `Essence` e lo converte in un `Elixir` usando `.into()`.

```rust
#[derive(Drop)]
struct Essence {
    potency: u16,
}

#[derive(Drop)]
struct Elixir {
    strength: u16,
}

fn convert_essence_to_elixir(essence: Essence) -> Elixir {
    // Convert the Essence to Elixir using the Into trait.
    essence.into()
}

fn main() {
    let essence = Essence { potency: 100 };
    let elixir: Elixir = convert_essence_to_elixir(essence);
    println!("Elixir strength: {}", elixir.strength); // Elixir strength: 100
}
```
