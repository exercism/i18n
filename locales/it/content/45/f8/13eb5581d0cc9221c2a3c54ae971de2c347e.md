# Test

## Configurazione

Segui le [istruzioni di configurazione per JavaScript][docs-exercism-javascript] per installare le dipendenze necessarie.

## Requisiti

Installa le dipendenze dell'esercizio:

```shell
corepack pnpm install
```

Se `corepack` segnala che non è abilitato, puoi abilitarlo eseguendo:

```bash
corepack enable pnpm
```

## Far passare la suite di test

Tutti gli esercizi includono una suite di test che ti aiuta a verificare la soluzione prima di inviarla.
Puoi eseguire questi test aprendo un prompt dei comandi nella cartella dell'esercizio ed eseguendo:

```bash
corepack pnpm test
```

In alcune suite di test, tutti i test tranne il primo sono stati saltati.

Quando un test passa, puoi abilitare il successivo cambiando `xtest` in `test`.

## Scrivere test personalizzati

Se vuoi scrivere altri test personalizzati, crea un nuovo file `custom.spec.js` e invialo insieme alla soluzione:

```shell
exercism submit numbers.js custom.spec.js
```

[docs-exercism-javascript]: https://exercism.org/docs/tracks/javascript/installation
