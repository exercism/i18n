# Dichiarazione di tipo

PHP è un linguaggio _dinamicamente tipizzato_, il che significa che una variabile può contenere qualsiasi tipo di informazione.
PHP consente una dichiarazione di tipo forte _opzionale_ per le proprietà della classe, gli argomenti delle funzioni e i valori restituiti dalle funzioni.
Le dichiarazioni di tipo forti in PHP forniscono asserzioni di tipo in fase di esecuzione; tuttavia, PHP tenterà di forzare i tipi scalari in modo che corrispondano alla dichiarazione, se possibile.
Il comportamento di coercizione può essere disabilitato usando la dichiarazione `strict_types` all'inizio del file.

```php
<?php
declare(strict_types=1);
```

Inoltre, le funzioni possono restituire un tipo di ritorno `void` per indicare che non deve essere restituito alcun valore dalla funzione.

```php
<?php
declare(strict_types=1);

class Driver
{
    string $serial_number;

    function setSerialNumber(string $number): void
    {
        $this->serial_number = $number;
    }

    function getSerialNumber(): string
    {
        return $this->serial_number; 
    }
}

$driver = new Driver(); 
$driver->setSerialNumber(1234);
// => This will throw a TypeError with strict_types=1
```

## Unioni di tipo

Se un argomento di funzione, un valore restituito o una proprietà di classe può assumere più di un tipo, si può dichiarare un'unione di tipi.

```php
<?php

class IdentityCard
{
    private int|float $id = 0;

    public function assign(int|float $id): void
    {
        $this->id = intval($id);
    }
}

$card = new IdentityCard();
$card->assign(5.0);
```

## Tipi misti

Quando lavoriamo con il codice, potremmo non riuscire a specificare un tipo.
A partire da PHP 8.0, viene fornito un tipo di scappatoia chiamato `mixed`.
Mixed equivale a un'unione di tipi di `object|resource|array|string|float|int|bool|null`.
