# Istruzioni

Dati due array, determina se il primo array è contenuto nel secondo, se il secondo array è contenuto nel primo, se entrambi gli array sono contenuti l'uno nell'altro o se nessuna di queste condizioni è vera.

In particolare, un array A è un sottoarray dell'array B se, eliminando 0 o più elementi dall'inizio di B e 0 o più elementi dalla fine di B, si ottiene un array completamente uguale ad A.

Esempi:

 * A = [1, 2, 3], B = [1, 2, 3, 4, 5], A è un sottoarray di B
 * A = [3, 4, 5], B = [1, 2, 3, 4, 5], A è un sottoarray di B
 * A = [3, 4], B = [1, 2, 3, 4, 5], A è un sottoarray di B
 * A = [1, 2, 3], B = [1, 2, 3], A è uguale a B
 * A = [1, 2, 3, 4, 5], B = [2, 3, 4], A è un sovraarray di B
 * A = [1, 2, 4], B = [1, 2, 3, 4, 5], A non è né un sovraarray né un sottoarray di B, e non è uguale a B
