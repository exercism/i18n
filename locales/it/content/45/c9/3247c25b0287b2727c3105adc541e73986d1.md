# Introduzione

## Pacchetti

In Go un'applicazione è organizzata in pacchetti.
Un pacchetto è una raccolta di file sorgente che si trovano nella stessa cartella.
Tutti i file sorgente di una cartella devono avere lo stesso nome di pacchetto in cima al file.
Per convenzione, i pacchetti prendono il nome della cartella in cui si trovano.

```go
package greeting
```

Go fornisce un'ampia libreria standard di pacchetti, che puoi usare con la parola chiave `import`.
I pacchetti della libreria standard si importano usando il loro nome.

```go
package greeting

import "fmt"
```

A un pacchetto importato ci si riferisce poi con il nome del pacchetto:

```go
world := "World"
fmt.Sprintf("Hello %s", world)
```

Go stabilisce se un elemento può essere chiamato dal codice di altri pacchetti in base a come è dichiarato.
Per rendere una funzione, un tipo, una variabile, una costante o un campo di una struct visibile dall'esterno (noto come _exported_), il nome deve iniziare con una lettera maiuscola.

```go
package greeting

// Hello is a public function (callable from other packages).
func Hello(name string) string {
    return "Hello " + name
}

// hello is a private function (not callable from other packages).
func hello(name string) string {
    return "Hello " + name
}
```

## Formattazione delle stringhe

Go fornisce un pacchetto integrato chiamato `fmt` (il pacchetto di formattazione), che offre varie funzioni per manipolare il formato dell'input e dell'output.
La funzione più usata è `Sprintf`, che usa verbi come `%s` per interpolare valori in una stringa e restituisce quella stringa.

```go
import "fmt"

food := "taco"
fmt.Sprintf("Bring me a %s", food)
// Returns: Bring me a taco
```

In Go, i numeri in virgola mobile si formattano comodamente con i verbi di `Sprintf`: `%g` (rappresentazione compatta), `%e` (esponente) o `%f` (senza esponente).
Tutti e tre i verbi permettono di controllare la larghezza del campo e la posizione numerica.

```go
import "fmt"

number := 4.3242
fmt.Sprintf("%.2f", number)
// Returns: 4.32
```

Puoi trovare un elenco completo dei verbi disponibili nella [documentazione del pacchetto format][fmt-docs].

`fmt` contiene altre funzioni per lavorare con le stringhe, come `Println`, che si limita a stampare sulla console gli argomenti che riceve, e `Printf`, che formatta l'input allo stesso modo di `Sprintf` prima di stamparlo.

[fmt-docs]: https://pkg.go.dev/fmt
