# Informazioni

In Elixir, per scegliere un elemento casuale da una struttura dati enumerabile (ad esempio un array o un intervallo), usiamo [`Enum.random/1`][enum-random]. Questa funzione sceglie un singolo elemento, dove ogni elemento ha la stessa probabilità di essere scelto. Scegliere un singolo valore casuale da un intervallo viene eseguito in tempo costante, senza attraversare l'intero intervallo.

## Numeri interi e lettere casuali

- Scegliere un numero intero casuale
  ```elixir
  Enum.random(1..10)
  # => 7
  ```
- Scegliere una lettera casuale come stringa
  ```elixir
  <<Enum.random(?A..?Z)>>
  # => "K"
  ```
- Scegliere una lettera casuale come charlist
  ```elixir
  [Enum.random(?A..?Z)]
  # => ~c"J"
  ```

Per scegliere più di un elemento da una struttura dati enumerabile, usa [`Enum.take_random/2`][enum-take-random]. Per ordinare una struttura dati enumerabile in ordine casuale, usa [`Enum.shuffle/1`][enum-shuffle].

## Numeri in virgola mobile casuali

Elixir non ha funzioni proprie per scegliere un numero in virgola mobile casuale. Per farlo, dobbiamo usare il modulo [`rand`][erl-rand] di Erlang, che è anche quello che `Enum.random` usa sotto il cofano.

- Scegliere un numero in virgola mobile casuale (maggiore o uguale a 0.0 e minore di 1.0):

  ```elixir
  :rand.uniform()
  # => 0.275329955448815
  ```

- Scegliere un numero in virgola mobile casuale (maggiore o uguale a `a` e minore di `b`):
  ```elixir
  a = 13
  b = 20
  :rand.uniform() * (b - a) + a
  # => 18.96815556890448
  ```

## Distribuzione normale

Tutte le funzioni menzionate sopra scelgono un valore casuale, dove ogni valore possibile ha la stessa probabilità di essere scelto. Questa si chiama _distribuzione uniforme_. Il modulo `rand` offre anche le funzioni [`normal/0`][erl-rand-normal-0] e [`normal/2`][erl-rand-normal-2], che scelgono un numero in virgola mobile casuale con una [distribuzione normale][normal-distribution].

## Seme

È importante capire che i valori «casuali» sono generati da un [generatore di numeri _pseudo_ casuali][prng]. Un PRNG è un algoritmo che, dato un valore iniziale chiamato _seme_, genera una sequenza di numeri che sembra casuale, ma non è affatto casuale.

Questo fatto può essere utile per il debug. Puoi forzare il generatore di numeri pseudo-casuali di Erlang (e quindi di Elixir) a produrre gli stessi valori della sequenza reimpostando il suo seme con [`:rand.seed/2`][rand-seed-2]. Il primo argomento è uno specifico algoritmo PRNG, e il secondo una tupla di tre numeri interi: il seme.

```elixir
:rand.seed(:exsss, {1, 2, 3})
Enum.take_random(100..999, 3)
# => [680, 127, 622]

:rand.seed(:exsss, {1, 2, 3})
Enum.take_random(100..999, 3)
# => [680, 127, 622]
```

## Crittografia

I valori casuali restituiti da `Enum.random` e dal modulo `rand` di Erlang non sono [crittograficamente sicuri][cryptographically-secure-rng]. Non usarli per generare chiavi crittografiche, password o nonce. Per questo caso d'uso, esiste [`:crypto.strong_rand_bytes/1`][erl-crypto-strong-rand-bytes] di Erlang.
