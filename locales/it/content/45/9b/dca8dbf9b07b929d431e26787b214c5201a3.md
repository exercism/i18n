# Test

Il track Factor usa **Factor 0.101**. Ogni esercizio viene fornito con un vocabolario `exercism-tools` incluso che definisce le parole di parsing `STOP-HERE` e `TASK:` più un runner per i test. Dalla directory dell'esercizio, esegui:

```
factor -roots=. -run=exercism-tools <exercise>
```

Ad esempio, per l'esercizio `hello-world`:

```
factor -roots=. -run=exercism-tools hello-world
```

Il runner esce con stato 0 quando tutti i test passano, e con un valore diverso da zero con output diagnostico quando un test fallisce.

## Test saltati

Risolvere un esercizio significa far passare tutti i suoi test.
Per impostazione predefinita, quando esegui i test viene eseguito un solo test (il primo).
Questo è intenzionale, perché ti permette di concentrarti solo sul far passare quel singolo test.

Il meccanismo è la riga `STOP-HERE` nel file di test: al momento del parsing dice a Factor di ignorare tutto ciò che sta sotto, così il runner vede solo i test sopra. Una volta che il tuo primo test passa, puoi abilitare più test in due modi:

- **Elimina la riga `STOP-HERE`** per abilitare tutti i test rimanenti in una volta.
- **Sposta la riga `STOP-HERE` più in basso** per abilitare i test uno alla volta, o un task alla volta. Gli esercizi concept raggruppano i test sotto i marcatori `TASK:`. Spostare `STOP-HERE` appena prima del prossimo `TASK:` è un passo naturale.

Quando tutti i test sono stati abilitati e la tua implementazione li fa passare tutti, avrai risolto l'esercizio!
