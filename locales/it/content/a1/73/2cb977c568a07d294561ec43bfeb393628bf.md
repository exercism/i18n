# Test

## Eseguire i test

Esegui la specifica dei test con:

```bash
$ gradle test
```

## Abilitare altri test

Una volta che il codice supera tutti i test attivi, abilita un altro test rimuovendo l'`@Ignore` che precede il prossimo test che ti interessa. Fallo eliminando la riga `@Ignore` oppure trasformala in commento aggiungendo due barre all'inizio della riga.

```Groovy
//@Ignore
def 'outputs "Hello, Alice!" when given the name "Alice"'() {
    expect: hello.hello('Alice') == 'Hello, Alice!'
}
```
