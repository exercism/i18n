# Appendice alle istruzioni

## Esempio di input

```j
  INPUTS=: 2 ; 1 0 0 1 0 1 ; 10
```

Questo significa che gli input sono:
```
  0{INPUTS NB. is the input base.
  1{INPUTS NB. is the digits.
  2{INPUTS NB. is the output base.
```
## Gestione degli input non validi

Se uno qualsiasi dei valori di input non è valido, il verbo dovrebbe restituire un `empty` (ad esempio, `0$0` o `''`).

### Esempi

- Se la _base di input_ è minore di 2:
    ```j
      '' -: rebase 10 ; 0 0 0 0 ; 1
    ```

- Se la _base di output_ è minore di 2:
    ```j
      '' -: rebase 1 ; 0 0 0 0 ; _7
    ```

- Se le _cifre_ contengono valori maggiori o uguali alla base di input:
    ```j
      '' -: rebase 10 ; 1 0 2 0 ; 2
    ```
