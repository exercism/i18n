# Istruzioni

Stai gestendo un sistema composto da alcune applicazioni che producono molti log. Vuoi scrivere un piccolo programma che aggreghi quei log e assegni loro un'etichetta in base al livello di gravità. Tutte le applicazioni del tuo sistema usano gli stessi codici di log, ma alcune applicazioni legacy non supportano tutti i codici.

| Codice del log        | Etichetta del log | Supportato nelle applicazioni legacy? |
|-----------------------| --------- | ------------------------- |
| 0                     | trace     | no                        |
| 1                     | debug     | sì                       |
| 2                     | info      | sì                       |
| 3                     | warning   | sì                       |
| 4                     | error     | sì                       |
| 5                     | fatal     | no                        |
| altro / non supportato | unknown   | -                         |

## 1. Determina l'etichetta del log

Implementa la funzione `LogLevel.to_label/2`. Dovrebbe accettare un codice intero e un flag booleano che indica se il log proviene da un'applicazione legacy, e restituire l'etichetta di una riga di log come atomo.

I codici di log non specificati nella tabella dovrebbero restituire l'etichetta _unknown_. Anche i codici di log indicati nella tabella come non supportati nelle applicazioni legacy dovrebbero restituire l'etichetta _unknown_ se il log proviene da un'applicazione legacy.

```elixir
LogLevel.to_label(0, false)
# => :trace

LogLevel.to_label(0, true)
# => :unknown
```

## 2. Invia un avviso

Qualcuno deve essere avvisato quando succedono cose inaspettate.

Implementa la funzione `LogLevel.alert_recipient/2` per determinare a chi deve essere inviato l'avviso. La funzione dovrebbe accettare un codice intero e un flag booleano che indica se il log proviene da un'applicazione legacy, e restituire il nome del destinatario come atomo.

Usa la funzione `LogLevel.to_label/2` dell'attività precedente. Se l'etichetta del log è _error_ o _fatal_, invia l'avviso al team _ops_. Se ricevi un log con etichetta _unknown_ da un sistema legacy, invia l'avviso al team _dev1_, mentre le altre etichette _unknown_ vanno inviate al team _dev2_. Tutte le altre etichette di log possono essere tranquillamente ignorate restituendo _false_.

```elixir
LogLevel.alert_recipient(-1, true)
# => :dev1

LogLevel.alert_recipient(0, false)
# => false
```
