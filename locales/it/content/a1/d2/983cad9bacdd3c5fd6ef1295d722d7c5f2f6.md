# Introduzione

## Definire le variabili

Definire una variabile significa assegnare un valore a un nome. In Scala esistono due tipi di variabili: val e var.

Un `val` è immutabile, quindi il suo valore non può più essere modificato dopo la prima assegnazione:

```scala
val numberTen = 10

numberTen = 11
// --> raises a compile error "reassignment to val"
```

Un `var`, al contrario, può essere riassegnato a un nuovo valore dello stesso tipo:

```scala
var someNumber = 10

someNumber = 11
// now someNumber has been reassigned
```

Scala è un linguaggio a tipizzazione statica: tutto ha un tipo in fase di compilazione. Una variabile si può definire specificandone esplicitamente il tipo, oppure lasciando che il compilatore Scala ne deduca il tipo in base al valore assegnato (questa operazione è nota come inferenza di tipo). Quindi, le due definizioni di variabile seguenti sono equivalenti:

```scala
val explicitNumber: Int = 10; // Explicitly typed
val implicitNumber = 10; // Implicitly typed
```

Una volta definita, il tipo di una variabile non può mai cambiare.

```scala
var count = 1; // Assigning an initial value of type Int
count = 2;     // Updating to new value is possible, because it is defined as var

count = false;
// --> raises a compile error "type mismatch"
```

## Definire i metodi all'interno delle classi

Scala è un _linguaggio orientato agli oggetti_ e richiede che tutti i metodi siano definiti all'interno di una _classe_. La parola chiave `class` si usa per definire una classe.

```scala
class Calculator {
  // ...
}
```

All'interno di una classe, i metodi si definiscono iniziando con la parola chiave `def` seguita da un nome. Ogni metodo può avere zero o più parametri, elencati separati da virgole all'interno di parentesi tonde. Tutti i parametri devono avere un tipo esplicito: per i parametri non esiste l'inferenza di tipo. Dopo l'elenco dei parametri, viene definito il tipo restituito dal metodo, separato da un altro due punti.

La definizione del metodo è seguita dal segno `=` che introduce il corpo del metodo. Nell'esempio seguente il corpo del metodo è composto da due istruzioni, racchiuse tra parentesi graffe.

Il metodo restituirà il valore dell'ultima espressione: in questo caso, il metodo `add` restituisce il valore della variabile `sum`:

```scala
class Calculator {
  // long form
  def add(x: Int, y: Int): Int = {
    val sum = x + y
    sum
  }
}
```

Ci sono alcuni accorgimenti che si possono applicare per accorciare quel metodo e migliorarne la leggibilità:

- dato che si accede alla variabile `sum` una sola volta per restituirne il valore, si può omettere
- i metodi composti da una sola istruzione non hanno bisogno di parentesi graffe
- il tipo restituito dal metodo si può inferire allo stesso modo dei tipi delle variabili

Si arriva così al seguente metodo su una sola riga, con la stessa funzionalità:

```scala
class Calculator {
  // shortened form
  def add(x: Int, y: Int) = x + y
}
```

## Creare istanze di classi e chiamare metodi

Per chiamare un metodo, prima si crea un'istanza di una classe, poi si chiama il metodo su quell'istanza passando degli argomenti:

```scala
val calculator = new Calculator()
val sum = calculator.add(5, 7)
// sum is of type Int with assigned value of 12
```

## Commentare

Scala supporta due tipi di commenti: i commenti su una sola riga e i commenti su più righe:

```scala
// this is a single line comment

/*
This comment spans across
multiple lines.
*/
```
