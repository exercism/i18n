# Test

## Eseguire i test

Una volta completati i [passaggi di installazione][test-installation-steps], puoi partire da qualsiasi directory di esercizio (ad esempio `~/exercism/gdscript/two-fer`) ed eseguire lo script (che si trova un livello più in alto, in `../`) per testare la soluzione locale a quell'esercizio:

```sh
../test-local-gdscript-solution.sh
```

## Risolvere un esercizio

Risolvere un esercizio significa far passare tutti i suoi test.

Per aiutarti a iniziare, ogni esercizio include un file GDScript con lo stesso nome dell'esercizio (ad esempio `exercism/gdscript/two-fer/two_fer.gd`).
Puoi usare questo file come punto di partenza per costruire la soluzione.
Sentiti libero di modificarlo come serve, ma i test si aspettano che i nomi delle funzioni restino quelli forniti in origine.

[test-installation-steps]: https://exercism.org/docs/tracks/gdscript/tests
