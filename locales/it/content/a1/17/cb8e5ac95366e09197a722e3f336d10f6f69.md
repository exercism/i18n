# Istruzioni

Aiuterai due fidanzatini del liceo a dichiarare il loro amore sui social media generando un cuore unicode con le loro iniziali:

```
❤ J.  +  M. ❤
```

## 1. Pulisci il nome

Definisci `cleanupname` che prende un nome dallo stack. Sostituisci ogni `-` con uno spazio, poi rimuovi gli spazi bianchi all'inizio e alla fine.

```factor
"Jane-Ann" cleanupname .
! => "Jane Ann"
```

## 2. Ottieni la prima lettera del nome

Definisci `firstletter` che prende un nome. Riutilizza `cleanupname` del compito precedente, poi prendi il primo carattere del risultato e restituiscilo come stringa di un solo carattere.

```factor
"Jane" firstletter .
! => "J"
```

## 3. Formatta la prima lettera come iniziale

Definisci `initial` che prende un nome. Riutilizza `firstletter` del compito precedente, converti il risultato in maiuscolo, poi aggiungi un `.`.

```factor
"Robert" initial .
! => "R."
```

## 4. Metti le iniziali dentro il cuore

Definisci `couple` che prende due nomi dallo stack. Riutilizza `initial` del compito precedente su ciascun nome, poi componi il risultato:

```factor
"Blake Miller" "Riley Lewis" couple .
! => "❤ B.  +  R. ❤"
```
