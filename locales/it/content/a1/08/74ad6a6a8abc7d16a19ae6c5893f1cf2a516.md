# Appendice alle istruzioni

Sovrascrivi la stringa del numero di telefono fornita.
Se il numero di telefono non è valido, sostituiscilo con una stringa vuota.

## Registri

| Registro | Utilizzo     | Tipo    | Descrizione                            |
| -------- | ------------ | ------- | -------------------------------------- |
| `$a0`    | input/output | indirizzo | numero di telefono come stringa terminata da null |
| `$t0-9`  | temporaneo   | qualsiasi | usato come memoria temporanea          |
