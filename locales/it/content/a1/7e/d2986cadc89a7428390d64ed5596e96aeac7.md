# Test

Usiamo [PonyTest](https://stdlib.ponylang.io/pony_test--index/) della libreria standard per scrivere i test che verificano la soluzione. Per testare la soluzione, compila ed esegui il codice.

Per esempio, la sessione per "Hello World" potrebbe essere simile a questa:

```text
[red@apophenia:~/exercism/pony/hello-world]$ ponyc
Generating
 Reachability
 Selector painting
 Data prototypes
 Data types
 Function prototypes
 Functions
 Descriptors
Optimising
Writing ./hello-world.o
Linking ./hello-world

[red@apophenia:~/exercism/pony/hello-world]$ ./hello-world 
1 test started, 0 complete: hello-world/HelloWorld started
1 test started, 1 complete: hello-world/HelloWorld complete
---- Passed: hello-world/HelloWorld
----
---- 1 test ran.
---- Passed: 1
```
