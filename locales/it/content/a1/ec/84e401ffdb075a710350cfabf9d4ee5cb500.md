# Introduzione

La libreria standard di Gleam implementa un tipo `Queue` nel modulo `gleam/queue`. È simile al tipo `List`, ma con alcune differenze importanti:

- Il tipo `Queue` non ha una sintassi letterale che possa essere usata per costruire code o eseguire il pattern matching su di esse.
- Gli elementi possono essere aggiunti e rimossi in modo efficiente sia all'inizio che alla fine del tipo `Queue`, mentre il tipo `List` può aggiungere e rimuovere elementi in modo efficiente solo dall'inizio.

Il più delle volte vorrai usare il tipo `List`, ma quando hai bisogno di poter aggiungere e rimuovere dalla fine di una collezione, il tipo `Queue` è una buona scelta.

Le code possono essere create usando le funzioni `queue.new` e `queue.from_list`:

```gleam
let empty = queue.new()
let one_to_four = queue.from_list([1, 2, 3, 4])
```

Gli elementi possono essere aggiunti alla coda usando le funzioni `queue.push_front` e `queue.push_back`:

```gleam
let one_to_four = queue.from_list([1, 2, 3, 4])
let one_to_five = queue.push_back(one_to_four, 5)
let zero_to_five = queue.push_front(one_to_five, 0)
```

Gli elementi possono essere rimossi dalla coda usando le funzioni `queue.pop_front` e `queue.pop_back`:

```gleam
let one_to_four = queue.from_list([1, 2, 3, 4])

queue.pop_back(one_to_four)
// -> Ok(#(4, queue.from_list([1, 2, 3])))

queue.pop_front(one_to_four)
// -> Ok(#(1, queue.from_list([2, 3, 4])))

queue.pop_front(queue.new())
// -> Error(Nil)
```

Una coda può essere convertita in un array usando la funzione `queue.to_list`:

```gleam
let one_to_four = queue.from_list([1, 2, 3, 4])
queue.to_list(one_to_four)
// -> [1, 2, 3, 4]
```

## Uguaglianza delle code

A causa di come sono implementate le code, due code con gli stessi elementi nello stesso ordine potrebbero non essere uguali secondo l'operatore `==`, che confronta i valori in modo strutturale. Ad esempio:

```gleam
let empty = queue.new()
let a = queue.push_front(empty, 1)
let b = queue.push_back(empty, 1)
a == b
// -> False
```

Se hai bisogno di confrontare due code per verificarne l'uguaglianza, puoi usare la funzione `queue.is_logically_equal`.

```gleam
queue.is_logically_equal(a, b, fn(x, y) { x == y })))
// -> True
```
