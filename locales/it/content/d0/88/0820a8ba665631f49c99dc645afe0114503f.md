# Istruzioni

In questo esercizio scriverai del codice per aiutare un freelancer a comunicare con un project manager, fornendo alcune utility per calcolare rapidamente le tariffe giornaliere e mensili, facoltativamente con uno sconto.

Per prima cosa stabiliamo alcune regole tra il freelancer e il project manager:

La tariffa giornaliera è 8 volte la tariffa oraria.
Un mese ha 22 giorni fatturabili.
Il freelancer si offre di applicare uno sconto se il project manager sceglie di farsi fatturare su base mensile: può tornare utile quando il project manager deve lavorare con un budget preciso.

Gli sconti sono rappresentati come numeri decimali che esprimono una percentuale, ad esempio 25.0 (25%).

## 1. Calcola la tariffa giornaliera a partire da una tariffa oraria

Implementa una funzione che calcoli la tariffa giornaliera a partire da una tariffa oraria:

```gleam
freelancer_rates.daily_rate(60)
# => 480.0
```

La tariffa giornaliera restituita dovrebbe essere un numero in virgola mobile.

## 2. Calcola un prezzo scontato

Implementa una funzione che calcoli il prezzo dopo l'applicazione di uno sconto.

```gleam
freelancer_rates.apply_discount(150, 10)
# => 135.0
```

Il valore restituito dovrebbe essere sempre un numero in virgola mobile, non arrotondato in alcun modo.

## 3. Calcola la tariffa mensile a partire da una tariffa oraria e uno sconto

Implementa una funzione che calcoli la tariffa mensile e applichi uno sconto:

```gleam
freelancer_rates.monthly_rate(77, 10.5)
# => 12130
```

La tariffa mensile restituita dovrebbe essere arrotondata per eccesso (prendi il valore intero superiore) al numero intero più vicino.

## 4. Calcola il numero di giornate lavorative a partire da un budget, una tariffa oraria e uno sconto

Implementa una funzione che riceve un budget, una tariffa oraria e uno sconto, e calcola a quante giornate di lavoro corrispondono.

```gleam
freelancer_rates.days_in_budget(20000, 80, 11.0)
# => 35
```

Il numero di giorni restituito dovrebbe essere arrotondato per difetto (prendi il valore intero inferiore) a una cifra decimale.
