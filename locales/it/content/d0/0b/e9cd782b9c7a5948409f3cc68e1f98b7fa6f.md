# Installazione

## Mac

Installa con Homebrew usando `brew install swi-prolog`.
In alternativa, scarica il sorgente per la tua macchina dal [sito web di SWI Prolog](http://www.swi-prolog.org/download/devel).

## Windows

Scarica il sorgente per la tua macchina dal [sito web di SWI Prolog](http://www.swi-prolog.org/download/devel).

## Linux

Segui le istruzioni per la tua distribuzione da [qui](http://www.swi-prolog.org/build/unix.html).
