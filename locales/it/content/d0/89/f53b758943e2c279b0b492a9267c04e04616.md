# Espressione match

Un'espressione match valuta un valore e una condizione per restituire un'espressione da valutare. Proprio come un operatore ternario, se la condizione non corrisponde, l'espressione restituita non viene valutata. Per verificare la corrispondenza di una condizione, viene eseguito un controllo di identità [uguaglianza stretta, o `===`].

```php
<?php
$some_value = 42;

$return_value = match($some_value) {
    0 => 'number is 0',
    1 => 'number is 1',
    default => 'number is something else'
}
```

Per eseguire un controllo di uguaglianza [`==`], puoi riorganizzare la condizione:

```php
<?php
$some_value = 42;

$return_value = match(true) {
    $some_value < 100 => 'number is less than 100',
    $some_value > 100 => 'number is greater than 100',
    $some_value == 100 => 'number is 100',
}
```

In un'espressione match, se nessuna condizione corrisponde, viene generato un `UnhandledMatchError`.
