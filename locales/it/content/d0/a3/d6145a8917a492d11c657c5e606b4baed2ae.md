# Istruzioni specifiche per SQLite

Questo esercizio richiede di impostare la colonna `result` della tabella `etl` al valore corretto, in base all'oggetto JSON che si trova nella colonna `input`. Le chiavi dell'oggetto result devono essere ordinate alfabeticamente.

## Schema della tabella

```sql
CREATE TABLE "etl" ("input" TEXT, "result" TEXT);
```
