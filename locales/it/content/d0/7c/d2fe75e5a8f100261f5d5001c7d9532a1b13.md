# Introduzione

`Nil` in Gleam è un tipo con un unico valore, anch'esso chiamato `Nil`. È simile a `void` in altri linguaggi: si usa quando una funzione non ha un valore più adatto da restituire.

```gleam
io.println("Hello, Joe!")
// -> Nil
```

I valori in Gleam non sono «nil-able» o «nullable», come accade in altri linguaggi. Un valore può essere `Nil` solo se il suo tipo è `Nil`, e un valore di qualsiasi altro tipo non può mai essere `Nil`.
