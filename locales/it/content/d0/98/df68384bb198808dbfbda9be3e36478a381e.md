# Suggerimenti

## Generali

- [The Cairo Book - Type Conversions][tcb-conversions]
- [The Cairo Book - Custom Type Conversion][tcb-ctc]

## 1. Convertire un valore con segno in uno senza segno

- Controlla se il valore con segno è negativo: in tal caso, restituisci `Option::None`
- Controlla se il valore con segno supera `u16::MAX` (65535): in tal caso, restituisci `Option::None`
- Per i valori validi, fai il cast usando `.try_into()` o una conversione diretta
- Ricorda che `u16` può contenere valori da 0 a 65535

## 2. Convertire un valore senza segno in uno con segno

- Dato che `u16::MAX` (65535) sta comodamente in `i32`, questa conversione riesce sempre
- Usa `.into()` per una conversione sicura da `u16` a `i32`

## 3. Conversione di tipi personalizzati

- Implementa il trait `Into` con la sintassi: `impl IntoImplName of Into<SourceType, TargetType>`
- Nel metodo `into`, crea una nuova istanza del tipo di destinazione
- Mappa il campo `potency` di `Essence` sul campo `strength` di `Elixir`
- Una volta implementato il trait, puoi usare `.into()` sulle istanze di `Essence`

## 4. Usare il trait Into

- Dopo aver implementato il trait `Into`, chiama `.into()` sul parametro `Essence`
- Il compilatore userà automaticamente l'implementazione del trait
- L'annotazione del tipo di ritorno aiuta Cairo a capire quale conversione usare
