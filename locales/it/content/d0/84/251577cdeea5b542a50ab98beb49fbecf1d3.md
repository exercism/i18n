# Informazioni

## Valori restituiti multipli

In Swift, le funzioni possono [restituire più valori][multiple-return-values] restituendo una tupla:

```swift
func reverseAndLength(_ str: String) -> (reverse: String, length: Int) {
    return (reverse: String(str.reversed()), length: str.count)
}

let result = reverseAndLength("Hello")
print(result.reverse) // Prints "olleH"
print(result.length)  // Prints 5
```

## Omettere la parola chiave return

Quando il corpo di una funzione è composto da una sola espressione, puoi [omettere la parola chiave `return`][implicit-returns]:

```swift
func reverseAndLength(_ str: String) -> (reverse: String, length: Int) {
    (reverse: String(str.reversed()), length: str.count)
}
```

Questa sintassi di restituzione implicita si applica a tutte le funzioni che restituiscono un valore, non solo a quelle che restituiscono tuple.
