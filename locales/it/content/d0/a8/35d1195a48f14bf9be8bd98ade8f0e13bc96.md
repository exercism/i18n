# Test

Per eseguire i test, esegui il comando seguente:

```bash
make
```

## Test saltati

Risolvere un esercizio significa far passare tutti i suoi test.
Per impostazione predefinita, quando esegui i test viene eseguito un solo test (il primo).
È una scelta intenzionale: ti permette di concentrarti solo sul far passare quel test.
Una volta che passa, puoi abilitare il test successivo rimuovendo la riga `TEST_IGNORE()`.
Quando tutti i test sono abilitati e l'implementazione li fa passare tutti, hai risolto l'esercizio!
