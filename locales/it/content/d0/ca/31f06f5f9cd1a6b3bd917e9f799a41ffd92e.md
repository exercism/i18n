# Appendice alle istruzioni

## Registri

| Registro | Utilizzo     | Tipo      | Descrizione                      |
| -------- | ------------ | --------- | -------------------------------- |
| `$a0`    | input        | intero    | numero della casella nell'intervallo 1..64 |
| `$v0`    | output       | intero    | i 32 bit bassi dell'output       |
| `$v1`    | output       | intero    | i 32 bit alti dell'output        |
| `$t0-9`  | temporaneo   | qualsiasi | per la memorizzazione temporanea |
