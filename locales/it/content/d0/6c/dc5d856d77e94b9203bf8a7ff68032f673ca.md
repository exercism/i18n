# Segnaposto

## Come risolvere con bash

`bash` non ha modi integrati per **analizzare** stringhe di data e ora.
Questo esercizio richiede di chiamare un'utilità esterna.

* L'opzione `-d` del comando GNU `date` può analizzare [un'ampia varietà di formati][gnu-date].
* Per gli utenti Mac, vedi il [comando `date` di BSD][bsd-date] e la sua opzione `-f`.
* Perl è ampiamente disponibile e il suo [modulo `Time::Piece`][time-piece] può essere usato per analizzare i timestamp.

bash può **formattare** le date senza strumenti esterni.
Dato un valore di tempo intero (secondi dall'epoca), [il formattatore `%()T` di `printf`][bash-printf] può applicare una formattazione in stile «strftime».

```bash
epoch=1234567890

printf '%(%Y-%m-%d %H:%M:%S)T\n' "$epoch"
# ==> 2009-02-13 18:31:30

# bash uses the `TZ` environment variable for the timezone.

TZ=Asia/Kolkata printf '%(%Y-%m-%d %H:%M:%S)T\n' "$epoch"
# ==> 2009-02-14 05:01:30
```

[bsd-date]: https://manpage.me/index.cgi?apropos=0&q=date&sektion=0&manpath=FreeBSD+12-CURRENT+and+Ports&arch=default&format=html
