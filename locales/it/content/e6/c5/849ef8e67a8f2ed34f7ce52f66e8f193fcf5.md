# Installazione

## Avvio rapido

``` shellsession
$ bash <(curl -s https://raw.githubusercontent.com/borkdude/babashka/master/install)
```

Per impostazione predefinita, l'installazione avviene in `/usr/local/bin`. Per cambiarla, indica il nome della directory:

``` shellsession
$ bash <(curl -s https://raw.githubusercontent.com/borkdude/babashka/master/install) /tmp
```

## Brew

I binari per Linux e macOS sono forniti tramite brew.

Installa:

    brew install borkdude/brew/babashka

Aggiorna:

    brew upgrade babashka

## Arch (Linux)

`babashka` è [disponibile](https://aur.archlinux.org/packages/babashka-bin/) nell'[Arch User Repository](https://aur.archlinux.org). Si può installare usando il tuo helper [AUR](https://aur.archlinux.org) preferito, come
[yay](https://github.com/Jguer/yay), [yaourt](https://github.com/archlinuxfr/yaourt), [apacman](https://github.com/oshazard/apacman) e [pacaur](https://github.com/rmarquis/pacaur). Ecco un esempio con `yay`:

    yay -S babashka-bin

## Windows

Su Windows puoi installare usando [scoop](https://scoop.sh/) ed il bucket
[scoop-clojure](https://github.com/littleli/scoop-clojure).

## Download

Puoi anche scaricare un binario da
[Github](https://github.com/borkdude/babashka/releases). Per Linux è disponibile un
binario statico che si può usare su Alpine.
