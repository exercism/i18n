# Introduzione

Gli array in C# sono collezioni di valori primitivi o di istanze di struct o di classi. Sono implementati nella libreria di classi di base come `List<T>`, dove `T` è il tipo dell'elemento nell'array. L'API espone un ricco insieme di metodi per creare e manipolare gli array.

Gli elementi si possono aggiungere e rimuovere dagli array. Crescono e si riducono quando serve.

```csharp
var listOfStrings = new List<string>();
```
