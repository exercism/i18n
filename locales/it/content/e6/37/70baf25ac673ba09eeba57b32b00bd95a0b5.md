# Introduzione

Quando una quotation deve *ricordare* dei valori dal contesto in cui si trova,
Factor offre due strumenti: `curry`/`compose` da [`kernel`][kernel]
e la sintassi fry `'[ … ]` di [`fry`][fry].

`curry` fissa un valore in testa a una quotation:

```
curry ( value quot -- newquot )
```

```factor
3 [ + ] curry .          ! => [ 3 + ]
10 3 [ + ] curry call .  ! => 13
```

`compose` incolla insieme due quotation:

```factor
[ 1 + ] [ 2 * ] compose .       ! => [ 1 + 2 * ]
5 [ 1 + ] [ 2 * ] compose call . ! => 12
```

Per più di una o due catture, fry è più pulito. Ogni segnaposto `_`
viene riempito, in ordine, con un valore preso dallo stack:

```factor
2 3 '[ _ _ + + ] .    ! => [ 2 3 + + ]
```

Fry riesce a entrare anche dentro quotation annidate.

[kernel]: https://docs.factorcode.org/content/vocab-kernel.html
[fry]: https://docs.factorcode.org/content/vocab-fry.html
