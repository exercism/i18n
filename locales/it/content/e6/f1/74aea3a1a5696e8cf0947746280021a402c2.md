# Istruzioni

In questo esercizio implementerai la logica della missione per un nuovo gioco di ruolo che un amico sta sviluppando.

La protagonista del gioco è Annalyn, una ragazza coraggiosa con un cane feroce e fedele al suo fianco. Purtroppo arriva la catastrofe: il suo migliore amico è stato rapito mentre cercava bacche nella foresta.

Annalyn proverà a trovare e liberare il suo migliore amico, con la possibilità di portare con sé il cane in questa missione.

Dopo aver seguito per un po' le tracce del suo migliore amico, trova il campo in cui è imprigionato. Si scopre che i rapitori sono due: un cavaliere possente ed un arciere astuto.

Una volta trovati i rapitori, Annalyn valuta quali delle seguenti azioni può intraprendere:

- _Attacco rapido_: si può sferrare un attacco rapido se il cavaliere sta dormendo, perché gli serve tempo per indossare l'armatura, quindi sarà vulnerabile.
- _Spionaggio_: si può spiare il gruppo se almeno uno di loro è sveglio. Altrimenti, spiare è una perdita di tempo.
- _Segnalare al prigioniero_: si può segnalare al prigioniero usando versi di uccelli se il prigioniero è sveglio e l'arciere sta dormendo, perché gli arcieri sono addestrati ai richiami degli uccelli, quindi potrebbero intercettare il messaggio.
- _Liberare il prigioniero_: Annalyn può provare a intrufolarsi nell'accampamento per liberare il prigioniero.
  È un'impresa rischiosa e può riuscire solo in uno dei due modi seguenti:
  - Se Annalyn ha con sé il suo cane, può liberare il prigioniero se l'arciere dorme.
    Il cavaliere ha paura del cane e l'arciere non farà in tempo a prepararsi prima che Annalyn e il prigioniero riescano a fuggire.
  - Se Annalyn non ha il cane, lei e il prigioniero devono essere molto furtivi!
    Annalyn può liberare il prigioniero se il prigioniero è sveglio e il cavaliere e l'arciere dormono entrambi, ma se il prigioniero dorme non si può salvarlo: si spaventerebbe per l'apparizione improvvisa di Annalyn e sveglierebbe il cavaliere e l'arciere.

Hai quattro compiti: implementare la logica per determinare se le azioni sopra descritte sono disponibili in base allo stato dei tre personaggi che si trovano nella foresta ed alla presenza o meno del cane di Annalyn.

## 1. Verifica se si può sferrare un attacco rapido

Implementa il metodo `can_fast_attack()` che riceve un valore booleano che indica se il cavaliere è sveglio. Il metodo restituisce `TRUE` se è possibile sferrare un attacco rapido in base allo stato del cavaliere. Altrimenti restituisce `FALSE`:

```R
knight_is_awake <- TRUE
can_fast_attack(knight_is_awake)
# => FALSE
```

## 2. Verifica se si può spiare il gruppo

Implementa il metodo `can_spy()` che riceve tre valori booleani, che indicano rispettivamente se il cavaliere, l'arciere e il prigioniero sono svegli. Il metodo restituisce `TRUE` se è possibile spiare il gruppo, in base allo stato dei tre personaggi. Altrimenti restituisce `FALSE`:

```R
knight_is_awake <- FALSE
archer_is_awake <- TRUE
prisoner_is_awake <- FALSE
can_spy(knight_is_awake, archer_is_awake, prisoner_is_awake)
# => TRUE
```

## 3. Verifica se si può segnalare al prigioniero

Implementa il metodo `can_signal_prisoner()` che riceve due valori booleani, che indicano rispettivamente se l'arciere e il prigioniero sono svegli. Il metodo restituisce `TRUE` se è possibile segnalare al prigioniero, in base allo stato dei due personaggi. Altrimenti restituisce `FALSE`:

```R
archer_is_awake <- FALSE
prisoner_is_awake <- TRUE
can_signal_prisoner(archer_is_awake, prisoner_is_awake)
# => TRUE
```

## 4. Verifica se si può liberare il prigioniero

Implementa il metodo `can_free_prisoner()` che riceve quattro valori booleani. I primi tre parametri indicano rispettivamente se il cavaliere, l'arciere e il prigioniero sono svegli. L'ultimo parametro indica se il cane di Annalyn è presente. Il metodo restituisce `TRUE` se è possibile liberare il prigioniero in base allo stato dei tre personaggi e alla presenza del cane di Annalyn. Altrimenti restituisce `FALSE`:

```R
knight_is_awake <- FALSE
archer_is_awake <- TRUE
prisoner_is_awake <- FALSE
pet_dog_is_present <- FALSE
can_free_prisoner(knight_is_awake, archer_is_awake, prisoner_is_awake, pet_dog_is_present)
# => FALSE
```
