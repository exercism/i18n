# Array

A Cairo, un array è una struttura dati che permette di memorizzare una raccolta di elementi dello stesso tipo.
Gli array in Cairo hanno opzioni di modifica limitate.
Puoi solo aggiungere elementi alla fine di un array e rimuovere elementi dall'inizio.
Gli array sono, di fatto, code i cui valori non possono essere modificati.

## Costruzione di un array

Gli array si costruiscono principalmente usando il trait `ArrayTrait`, in uno dei 4 modi seguenti per costruire un array di elementi `[1, 2]`:

```rust
// 1. Passing the type to the `ArrayTrait`
let mut arr_type_in_trait = ArrayTrait::<felt252>::new();
arr_type_in_trait.append(1);
arr_type_in_trait.append(2);

// 2. Setting the type on the variable itself
let mut arr_explicit_type: Array<felt252> = ArrayTrait::new();
arr_explicit_type.append(1);
arr_explicit_type.append(2);

// 3. Using the `array!` macro
let mut arr_from_macro: Array<felt252> = array![1, 2]; // assign values in-line

// 4. Allowing the compiler to infer the type from the type of values being assigned to it
let mut arr_implicit_type = ArrayTrait::new(); // compiler "knows" this is a `felt252` array
arr_implicit_type.append(1);
arr_implicit_type.append(2);
```

> Ogni chiamata a `append()` mette un nuovo numero alla fine dell'array.

## Rimuovere elementi da un array

L'unico modo per rimuovere elementi da un array in Cairo è dall'inizio.
Questa operazione è resa possibile dal metodo `pop_front()`, che restituisce un `Option` con dentro l'elemento rimosso, che si può estrarre, oppure `Option::None` se l'array è vuoto.

```rust
fn main() {
    let mut a = array![10, 1, 2];
    let first_value = a.pop_front().unwrap(); // `unwrap()` is used to get the value from `Option`
    println!("The first value is {}", first_value); // prints "The first value is 10"
}
```

## Accedere ai valori di un array

Per accedere agli elementi di un array, puoi usare i metodi `get()` e `at()` dell'array, che restituiscono tipi diversi.
Un equivalente di `arr.at(index)` è l'operatore di indicizzazione `arr[index]`.

### Usare il metodo get()

Il metodo `get()` è come cercare un elemento in una lista tramite il suo numero.
Ecco come funziona:

- `arr.get(index)` ti permette di recuperare un elemento in una posizione specifica (l'indice) dell'array.
- Restituisce `Option::Some(value)` se l'elemento all'indice indicato esiste, oppure `Option::None` se l'indice è fuori dai limiti.

Questo metodo è ideale quando vuoi gestire casi in cui l'indice potrebbe non essere valido senza far andare in crash il programma.

```rust
fn main() {
    let arr: Array<u32> = array![1, 2, 3];

    let index = 1;

    match arr.get(index) {
        Option::Some(value) => { println!("Element at index {}: {}", index, value.unbox()); },
        Option::None => { println!("Index {} is out of bounds!", index); }
    }
}
```

### Usare il metodo at()

Il metodo `at()` ti dà direttamente uno snapshot dell'elemento a un indice specifico, usando l'operazione `unbox()` per estrarre dal box il valore memorizzato.
Una scorciatoia per questo metodo è usare l'operatore di indicizzazione `arr[index]`.
Se provi ad accedere a un indice che non esiste (fuori dai limiti), il programma andrà in panic con un errore.

```rust
fn main() {
    let a: Array<u32> = array![5, 8];

    println!("First: {}", *a.at(0)); // prints "First: 5"
    println!("Second: {}", a[1]); // prints "Second: 8"
    println!("Third: {}", a[2]); // panics with 'Index out of bounds'
}
```

## Metodi relativi alla dimensione

Per determinare il numero di elementi di un array, usa il metodo `len()`.
Il valore restituito è di tipo `usize`.

Se vuoi verificare se un array è vuoto, puoi usare il metodo `is_empty()`, che restituisce `true` se l'array è vuoto e `false` altrimenti.

## `Span`

`Span` è una struct che rappresenta uno snapshot di un `Array`.
È progettato per fornire un accesso sicuro e controllato agli elementi di un array senza modificare l'array originale.
`Span` è particolarmente utile per garantire l'integrità dei dati ed evitare problemi di borrowing quando si passano array tra funzioni o quando si eseguono operazioni di sola lettura.

> Tutti i metodi forniti da `Array` si possono usare anche con `Span`, tranne il metodo `append()`.

Per creare uno `Span` di un `Array`, chiama il metodo `span()`:

```rust
let my_array: Array<u32> = array![1, 2, 3];
let my_span: Span<u32> = my_array.span();
```

## Il tipo `Array` a dimensione fissa

I valori di un array a dimensione fissa si scrivono come un elenco separato da virgole tra parentesi quadre.
Il tipo dell'array si scrive usando le parentesi quadre con il tipo di ogni elemento, un punto e virgola, e poi il numero di elementi dell'array.

```rust
let arr: [u64; 5] = [1, 2, 3, 4, 5];
```

> Nota: solo gli array a dimensione fissa possono essere usati come costanti

Si può accedere agli elementi di un array a dimensione fissa sia destrutturando l'array sia convertendolo in uno `Span`, che supporta l'indicizzazione.

```rust
fn main() {
    let arr = [1, 2, 3, 4, 5]; // implicit `felt252` array type

    // Accessing elements of a fixed-size array by deconstruction
    let [a, b, c, _, _] = arr;
    println!("c: {}", c); // c: 3
    
    // Accessing elements of a fixed-size array by index
    let my_span = arr.span();
    println!("my_span[2]: {}", my_span[2]); // my_span[2]: 3
}
```
