# Introduzione

[I range][range] rappresentano un intervallo tra due valori.
I range sono comunemente usati con tipi come `Int`, `String` e `Character` per iterare su sequenze, estrarre porzioni di collezioni o controllare se un valore rientra nei limiti.

Swift mette a disposizione due operatori range principali:

- **Operatore range chiuso (`...`)**: include sia il valore iniziale sia quello finale (`1...5` include 1, 2, 3, 4 e 5).
- **Operatore range semiaperto (`..<`)**: include il valore iniziale ma esclude quello finale (`1..<5` include 1, 2, 3 e 4).

```swift
let closed = 1...5
let halfOpen = 1..<5
```

~~~~exercism/note
Quando chiami un metodo direttamente su un range letterale, racchiudi l'espressione del range tra parentesi, così il compilatore valuta prima il range:

```swift
(1...5).contains(3) // Returns true
// 1...5.contains(3) // Error: value of type 'Int' has no member 'contains'
```
~~~~

## Convertire un range in un Array

Puoi convertire un range di numeri in un `Array` usando l'inizializzatore `Array(_:)`:

```swift
let range = 1...5
let numbers = Array(range)
// numbers is [1, 2, 3, 4, 5]
```

## Ritagliare un array con i range

Puoi usare i range per ritagliare porzioni di un array:

```swift
let array = [10, 20, 30, 40, 50]
let slice = array[1...3]
// slice contains [20, 30, 40]
```

## Proprietà e metodi dei range

Tra le operazioni più comuni sui range ci sono:

| Membro                  | Descrizione                                                | Esempio                              |
| ----------------------- | ---------------------------------------------------------- | ------------------------------------ |
| `count`                 | Restituisce il numero di elementi nel range                | `(1...5).count` restituisce `5`          |
| [`contains(_:)`][contains] | Restituisce `true` se il range include il valore specificato | `(1...5).contains(3)` restituisce `true` |

## Range a una sola estremità

Swift supporta anche i range a una sola estremità (parziali), in cui si omette il valore iniziale o quello finale:

- `array[2...]`: dall'indice 2 alla fine della collezione.
- `array[...2]`: dall'inizio della collezione fino all'indice 2 incluso.
- `array[..<2]`: dall'inizio della collezione fino all'indice 2 escluso.

## Range di stringhe e caratteri

I range si possono creare anche tra caratteri o stringhe che conformano a `Comparable`:

```swift
let letters = "a"..."z"
print(letters.contains("m")) // Prints true
print(letters.contains("A")) // Prints false
```
