# Introduzione

## Numeri

Dal [manuale][man-types]

> jq supporta lo stesso insieme di tipi di dato di JSON: numeri, stringhe, booleani, array, oggetti (che nel gergo JSON sono hash con sole chiavi di tipo stringa) e "null".

Concentriamoci sui **numeri**.

### Numeri e operatori numerici

Tutti i numeri, che siano interi o no, sono numeri in virgola mobile a doppia precisione IEEE754.
Questo ci limita a 53 bit di precisione.

Con i numeri puoi usare i soliti operatori:

- aritmetica: `+`, `-`, `*`, `/`, `%`
- confronto: `==`, `!=`, `<`, `<=`, `>=`, `>`
- le [funzioni matematiche][man-math] standard

  Per le funzioni con un solo input, passa il valore alla funzione con una pipe

  ```sh
  $ jq -n '(1 | atan) * 4'
  3.141592653589793
  ```

  Per le funzioni con due input, la funzione ignora l'input e si aspetta gli
  input come parametri (ricorda che i parametri sono separati da punti e virgola)

  ```sh
  $ jq -n 'pow(2; 10)'
  1024
  ```

  Il punto e virgola è il separatore degli argomenti di una funzione, non la virgola.

### Altre espressioni `jq`

Per risolvere l'esercizio, dovrai conoscere le espressioni condizionali.

#### Espressioni condizionali

`jq` usa un'[espressione `if-then-else`][if-then-else] per le **espressioni condizionali**.
Essendo un'_espressione_, si inserisce in una pipeline.

La sintassi è: `if CONDITION then TRUE_EXPR else FALSE_EXPR end`.

La clausola `else` è facoltativa.

```jq
42 | if . < 33 then "small" else "larger" end
# => "larger"
```

Per ulteriori condizioni si usa `elif`

```jq
42 | if . < 33 then "small"
     elif . < 67 then "medium"
     else "large"
     end
# => "medium"
```
