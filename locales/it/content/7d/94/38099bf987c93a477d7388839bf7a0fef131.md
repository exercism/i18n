# Istruzioni

In questo esercizio dovrai implementare alcuni metodi per manipolare un array di linguaggi di programmazione.

## 1. Definire un metodo che restituisca un array di linguaggi vuoto

Definisci il metodo `LanguageList.list`, che non accetta argomenti e restituisce un array vuoto di tipo `Array(String)`.

```crystal
LanguageList.list()
# => []
```

## 2. Definire un metodo per aggiungere un linguaggio all'array

Definisci il metodo `LanguageList.add`, che accetta 2 argomenti (un _array di linguaggi_ e una stringa letterale che rappresenta un _linguaggio_).
Il metodo deve restituire l'array con il nuovo linguaggio aggiunto alla fine.

```crystal
language_list = LanguageList.list()
# => []
language_list = LanguageList.add(language_list, "Crystal")
# => ["Crystal"]
language_list = LanguageList.add(language_list, "Ruby")
# => ["Crystal", "Ruby"]
```

## 3. Definire un metodo per rimuovere un linguaggio dall'array

Definisci il metodo `LanguageList.remove`, che accetta 1 argomento (un _array di linguaggi_).
Il metodo deve restituire l'array senza l'ultimo elemento.
Dai per scontato che l'array contenga sempre almeno un elemento.

```crystal
language_list = LanguageList.list()
# => []
language_list = LanguageList.add(language_list, "Crystal")
# => ["Crystal"]
language_list = LanguageList.add(language_list, "Ruby")
# => ["Crystal", "Ruby"]
language_list = LanguageList.remove(language_list)
# => ["Crystal"]
```

## 4. Definire un metodo che restituisca l'n-esimo elemento dell'array

Definisci la funzione `LanguageList.at`, che accetta 2 argomenti (un _array di linguaggi_ e un indice).
Il metodo deve restituire il linguaggio che si trova all'indice n dell'array.
Dai per scontato che all'indice indicato ci sia sempre un linguaggio.

```crystal
language_list = LanguageList.new()
# => []
language_list = LanguageList.add(language_list, "Crystal")
# => ["Crystal"]
language_list = LanguageList.add(language_list, "Ruby")
# => ["Crystal", "Ruby"]
LanguageList.at(language_list, 1)
# => "Ruby"
```

## 5. Definire un metodo per analizzare una stringa di linguaggi

Definisci il metodo `LanguageList.parse`, che accetta 1 argomento (una stringa letterale di linguaggi separati da una virgola).
Il metodo deve restituire un array di linguaggi.

```crystal
LanguageList.parse("Crystal, Ruby")
# => ["Crystal", "Ruby"]
```
