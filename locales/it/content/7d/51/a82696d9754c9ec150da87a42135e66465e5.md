# Introduzione

Per impostazione predefinita, le variabili sono limitate allo scope in cui vengono definite. Se vengono definite in un file al di fuori di una funzione o di una classe, sono limitate allo scope del file. Se vengono definite all'interno di una funzione o di una classe, sono limitate allo scope della funzione o della classe.

```php
<?php

$file_scoped = "I am file scoped";

function example(): void
{
  $function_scoped = "I am function scoped!";
}
```

Inoltre, le variabili possono essere dichiarate con uno scope specifico, `global` o `static`.
