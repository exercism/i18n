# Introduzione

## Overload degli operatori

I principali operatori aritmetici e di confronto possono essere adattati per essere usati dalle tue classi e dalle tue struct. Questo si chiama _overload degli operatori_.

La maggior parte degli operatori ha questa forma:

```csharp
static <return type> operator <operator symbols>(<parameters>);
```

Gli operatori di cast hanno questa forma:

```csharp
static (explicit|implicit) operator <cast-to-type>(<cast-from-type> <parameter name>);
```

Gli operatori si comportano allo stesso modo dei metodi statici. Il simbolo di un operatore prende il posto dell'identificatore di un metodo; gli operatori hanno parametri ed un tipo restituito. Le regole di tipo per i parametri e per il tipo restituito seguono l'intuito: puoi contare sul compilatore per ottenere indicazioni dettagliate.
