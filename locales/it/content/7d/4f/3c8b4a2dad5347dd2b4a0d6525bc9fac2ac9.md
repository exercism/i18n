# Introduzione

Le eccezioni sono una forma di gestione degli errori.
Si chiamano eccezioni perché compaiono di solito quando si ha a che fare con un evento inatteso.

In qualsiasi punto del nostro codice, possiamo «raise» un'eccezione.
Lo facciamo usando il metodo `raise`, passando un oggetto: di norma un oggetto Exception, anche se possiamo usare anche delle stringhe semplici.
Per esempio, negli stub degli esercizi vedrai che usiamo `RuntimeError`, che è integrata, per dire a Ruby che un metodo non è stato implementato.
Puoi anche usare la sintassi abbreviata `raise(ExceptionObject, params)`.
Se la classe dell'eccezione viene omessa, per impostazione predefinita viene usata `RuntimeError`.
Per esempio:

```ruby
# These are equivalent
raise RuntimeError.new("Please implement this method")
raise RuntimeError, "Please implement this method"
raise "Please implement this method"
```

Quando Ruby lo incontra, fa risalire l'errore fino alla cima del programma e poi esce.
Per esempio, se provi a dividere qualcosa per zero, vedrai qualcosa di simile a questo:
```ruby
5/0

#=> Traceback (most recent call last):
#=> ...
#=> ZeroDivisionError (divided by 0)
```
