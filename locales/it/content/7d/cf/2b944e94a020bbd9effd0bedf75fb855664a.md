# Informazioni

Una quotation, scritta tra `[ ]`, è l'equivalente in Factor di una funzione anonima o di un blocco di codice. È un valore di prima classe che puoi impilare, memorizzare o passare in giro, e che viene eseguito solo quando qualcosa la *chiama*.

```factor
[ 1 + ]              ! a quotation, sitting on the stack
5 [ 1 + ] call .     ! => 6
```

Le quotation sono sequenze di parole, e Factor le usa ovunque un comportamento debba essere rimandato o parametrizzato:

- i rami di `if` / `when` / `unless` / `cond`
- il predicato di `filter`, `count`, `any?`, `all?`
- la trasformazione di `map`, `each`, `reduce`
- il corpo di `times`, `while`, `loop`

Di solito l'effetto sullo stack di una quotation si può dedurre. Quando non è possibile, in genere quando la quotation viene memorizzata e richiamata più tardi con `call`, dichiara l'effetto in modo esplicito: `call( a b -- c )`.

## Combinare le quotation

```
compose ( quot1 quot2 -- compound )
curry   ( value quot  -- curried )
```

`compose` concatena due quotation una in coda all'altra, in una nuova quotation che esegue prima la prima e poi la seconda. `curry` antepone un valore fisso e restituisce una quotation che impilerà quel valore prima di chiamare l'originale. Entrambi producono quotation ordinarie che puoi chiamare con `call`, memorizzare o passare ai combinator.

```factor
USING: kernel math ;

3 [ 2 * ] [ 1 + ] compose call .   ! 3 2 * 1 + => 7
5 [ 1 + ] curry call .             ! 5 1 +     => 6
```
