# Istruzioni

Traduci le sequenze di RNA in proteine.

L'RNA può essere suddiviso in sequenze di tre nucleotidi chiamate codoni, e poi tradotto in un polipeptide in questo modo:

RNA: `"AUGUUUUCU"` => si traduce in

Codoni: `"AUG", "UUU", "UCU"`
=> che diventano un polipeptide con la seguente sequenza =>

Proteina: `"Methionine", "Phenylalanine", "Serine"`

Ci sono 64 codoni che a loro volta corrispondono a 20 amminoacidi; tuttavia, in questo esercizio non è importante conoscere tutte le sequenze di codoni e gli amminoacidi risultanti.
Se funziona per un codone, il programma dovrebbe funzionare per tutti.
Sentiti comunque libero di ampliare l'elenco nella suite di test per includerli tutti.

Ci sono anche tre codoni di terminazione (detti anche codoni «STOP»); se il ribosoma incontra uno di questi codoni, la traduzione si interrompe e la proteina viene terminata.

Tutti i codoni successivi vengono ignorati, in questo modo:

RNA: `"AUGUUUUCUUAAAUG"` =>

Codoni: `"AUG", "UUU", "UCU", "UAA", "AUG"` =>

Proteina: `"Methionine", "Phenylalanine", "Serine"`

Nota che il codone di stop `"UAA"` termina la traduzione e la metionina finale non viene tradotta nella sequenza proteica.

Di seguito sono riportati i codoni e gli amminoacidi risultanti necessari per l'esercizio.

| Codone             | Proteina      |
| :----------------- | :------------ |
| AUG                | Methionine    |
| UUU, UUC           | Phenylalanine |
| UUA, UUG           | Leucine       |
| UCU, UCC, UCA, UCG | Serine        |
| UAU, UAC           | Tyrosine      |
| UGU, UGC           | Cysteine      |
| UGG                | Tryptophan    |
| UAA, UAG, UGA      | STOP          |
