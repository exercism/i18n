# Appendice alle istruzioni

## Formato del giardino

Il giardino è rappresentato come una stringa terminata da null, con un carattere di nuova riga alla fine di ogni riga.

Un esempio potrebbe essere `"   \n * \n   \n"`

## Registri

| Registro | Utilizzo     | Tipo    | Descrizione                       |
| -------- | ------------ | ------- | --------------------------------- |
| `$a0`    | input        | indirizzo | stringa di input terminata da null  |
| `$a1`    | input/output | indirizzo | stringa di output terminata da null |
| `$t0-9`  | temporaneo   | qualsiasi | per l'archiviazione temporanea      |
