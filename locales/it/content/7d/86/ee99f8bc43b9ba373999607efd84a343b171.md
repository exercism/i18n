# Test

Digita semplicemente `make chez` se usi ChezScheme o `make guile` se usi GNU Guile.

## Usare il REPL

- Inserisci `test.scm` al prompt del REPL.
- Sviluppa la soluzione nel file di soluzione dell'esercizio (ad esempio, `hello-world.scm`), ricaricando man mano che procedi.
- Esegui `(test)` per verificare la soluzione.
