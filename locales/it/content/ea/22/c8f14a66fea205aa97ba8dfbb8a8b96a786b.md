# Introduzione

## Istruzioni condizionali

Le istruzioni condizionali servono a prendere decisioni: possono eseguire effetti collaterali o controllare il flusso di esecuzione di un programma.
Le istruzioni condizionali includono `if`, `if/else`, `switch` e `ternary`.

Le istruzioni condizionali servono a porre domande su un valore o su una relazione tra valori.
La domanda si risolve in una risposta booleana, ma l'istruzione `if` stessa può restituire qualsiasi valore oppure può semplicemente eseguire un effetto collaterale.

## Istruzioni if

L'istruzione `if` più semplice valuta un'espressione ed esegue una riga.
L'espressione da valutare è sempre racchiusa tra parentesi tonde.

Può eseguire un effetto collaterale

```c
if (count > 10)
    printf("count is greater than 10");
```

oppure può cambiare il flusso di esecuzione


```c
if (count > 10)
    return sum;
```

Se un'istruzione `if` esegue più di una riga, deve racchiudere le righe tra parentesi graffe

```c
if (count > 10) {
    printf("count is greater than 10");
    return sum;
}
```

Alcuni team di sviluppo potrebbero stabilire che le istruzioni `if` debbano usare sempre le parentesi graffe, anche per una sola riga.


## If ed else

Un'istruzione `if` può essere abbinata a un `else`

```c
if (number % 2 == 0)
    return "even";
else
    return "odd";
```

## If, else if


`else` può essere abbinato a un altro `if` per creare quella che viene chiamata una `if-else-if ladder`.

```c
if (number == 0)
    return "zero";
else if (number < 0)
    return "negative";
else if (number < 10)
    return "single digit";   
else if (number % 2 == 0)
    return "even";
else
    return "odd";
```

## Switch


A volte una `if-else-if ladder` può essere rappresentata meglio da uno `switch`.
Come `if`, l'espressione da valutare va sempre messa tra parentesi.

```c
switch (number) {
    case -1:
        return "negative one";
    case 0:
        return "zero";
    case 1:
        return "positive one";
    case 10:
        return "positive ten";
    case -10:
        return "negative ten";
    default:
        return "don't care";
}
```

Il caso `default` viene eseguito se il valore da valutare non corrisponde a nessuno dei casi precedenti.

Se un caso di `switch` non restituisce un valore, di solito si inserisce un `break` per terminare ogni caso; altrimenti la logica «passa» al caso successivo.
A volte il passaggio al caso successivo è intenzionale

```c
switch (number) {
    case 0:
        msg = "zero"; break;
    case 1:
        msg = "one"; break;
    case 2: case 3: case 4:
        msg = "more than one and less than five"; break;
    default:
        msg = "don't care";
}
```

Quando il passaggio al caso successivo avviene in modo non intenzionale, è un bug.

```c
switch (number) {
    case 0:
        msg = "zero"; // bug! fallthrough of 0 will set msg to "one"
    case 1:
        msg = "one"; break; 
    case 2: case 3: case 4:
        msg = "more than one and less than five"; break;
    default:
        msg = "don't care";
}
```

Uno `switch` può essere vantaggioso quando si confronta con valori specifici invece che con un intervallo di valori.
Può essere più veloce di una `if-else-if ladder` perché il compilatore potrebbe riuscire a ottimizzare l'istruzione `switch` in modi che non può applicare a una scala.
Uno `switch` a volte può risultare più leggibile di una scala.

## Operatore ternario (detto anche condizionale)

L'operatore ternario è un'istruzione condizionale in tre parti che viene spesso usata per impostare un valore.
L'espressione da valutare si trova prima del punto interrogativo e non deve essere racchiusa tra parentesi.
Il valore restituito se la condizione è vera si trova prima dei due punti, mentre il valore restituito se è falsa si trova dopo i due punti.
Si può restituire sia un valore letterale sia una variabile.

```c
int i = j > 5 ? 5: j;
```

Gli operatori ternari possono essere annidati per ridurre il disordine sintattico.

```c
// the below could also be 
i = j > 5 ? j :k > 5 ? k: 10;
// but that may not be quite as readable

i = j > 5 ? j
    :k > 5 ? k
    :10;

// which is the same as
if (j > 5) i = j;
else if (k > 5) i = k;
else i = 10;
```
