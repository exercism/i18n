# Boutique di moda

## Storia

Stai gestendo una boutique di moda online. Il Black Friday è alle porte, quindi devi fare l'inventario per assicurarti di essere pronto.

Un singolo articolo dell'inventario è rappresentato da una mappa/dizionario, e l'intero inventario è una lista/array di tali mappe/dizionari.

```elixir
%{
  name: "White Shirt",
  price: 40,
  quantity_by_size: %{s: 3, m: 7, l: 8, xl: 4}
}
```

## Attività

- Ordina gli articoli per prezzo
- Trova tutti gli articoli a cui manca il prezzo
- Incrementa la quantità di un articolo
- Calcola la quantità totale di un articolo
