# Appendice alle istruzioni

## Struttura del progetto

Gli esercizi di Clojure in Exercism supportano i due strumenti più comuni per la gestione delle dipendenze e per i test, [leiningen][leiningen] e la [Clojure CLI][clojure-cli].

Nella directory `test` troverai un file di test chiamato `hello_world_test.clj`.
Scrivi il codice in `src/hello_world.clj`. Dovrebbe usare il namespace `hello-world` in modo che i test lo trovino.

### Eseguire i test con la Clojure CLI

```
$ clj -X:test
```

### Eseguire i test con Leiningen

```
$ lein test

lein test hello-world-test

Ran 3 tests containing 3 assertions.
0 failures, 0 errors.
```

Poi invia l'esercizio con:

```
$ exercism submit src/hello_world.clj
```

Per istruzioni più dettagliate e risorse di apprendimento, consulta la [pagina del linguaggio Clojure di Exercism][exercism-clojure].

[leiningen]: https://leiningen.org
[clojure-cli]: https://clojure.org/guides/deps_and_cli
[exercism-clojure]: https://exercism.org/tracks/clojure
