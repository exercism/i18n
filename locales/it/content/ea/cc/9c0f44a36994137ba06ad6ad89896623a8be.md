# Istruzioni

Mecha Munch™, un'azienda di automazione per la spesa, ti ha appena assunto per lavorare sulla sua app per gli ordini.
Il tuo team ha il compito di costruire un MVP (_[prodotto minimo funzionante][mvp]_) che gestisce tutte le attività di base del carrello della spesa, permettendo agli utenti di aggiungere, rimuovere e ordinare i loro ordini di generi alimentari.
Per fortuna, un altro team si occupa di tutto ciò che riguarda il denaro e il check-out!

## 1. Aggiungi articoli al carrello dell'utente

L'MVP dovrebbe permettere all'utente di aggiungere articoli al proprio carrello.
Può trattarsi di un singolo articolo o di più articoli contemporaneamente.
Poiché si tratta di un MVP, la quantità di un articolo è indicata dalle _ripetizioni_.
Se un utente vuole aggiungere 2 arance, 'Oranges' comparirà due volte nell'iterabile di input.
Se l'utente ha già l'articolo nel carrello, la quantità nel carrello va aumentata di 1.
Se l'articolo è _nuovo_ per il carrello, va aggiunto con una quantità di 1.

Definisci la funzione `add_items!(<cart>, <items>)` che prende come argomenti un dizionario del carrello e un iterabile di articoli da aggiungere.
Dovrebbe restituire il dizionario del carrello aggiornato per l'utente.

```julia-repl
julia> additems!(Dict("Banana" => 3, "Apple" => 2, "Orange" => 1),
                 ("Apple", "Apple", "Orange", "Apple", "Banana"))
Dict{String, Int64} with 3 entries:
  "Apple"  => 5
  "Orange" => 2
  "Banana" => 4

julia> additems!(Dict("Banana" => 3, "Apple" => 2, "Orange" => 1),
                 ["Banana", "Orange", "Blueberries", "Banana"])
Dict{String, Int64} with 4 entries:
  "Blueberries" => 1
  "Apple"       => 2
  "Orange"      => 2
  "Banana"      => 5
```

## 2. Aggiorna la sezione "idee" delle ricette

L'app ha una sezione "idee" piena di ricette finite di varie cucine.
L'utente può selezionare una qualsiasi di queste ricette e far aggiungere automaticamente tutti i suoi ingredienti al proprio carrello.
Il project manager ti ha chiesto di creare un modo per modificare queste ricette della sezione "idee", dato che il team di contenuti continua a cambiare ingredienti e quantità.

Definisci la funzione `update_recipes!(<ideas>, <updates>)` che prende come argomenti un dizionario "idee" e un dizionario di aggiornamenti alle ricette.

## 3. Invia il carrello dell'utente al negozio per l'evasione

L'app deve inviare il carrello di un utente al negozio per l'evasione.
Tuttavia, i commessi del negozio devono sapere dove si trova ogni articolo, usando un codice di corsia univoco.
Il "carrello di evasione" va ordinato in base ai codici di corsia degli articoli, per aiutare i commessi a essere più efficienti.

Definisci la funzione `send_to_store(<cart>, <aislecodes>)` che prende come argomenti il carrello di un utente e un dizionario con i numeri di corsia del negozio.
La funzione dovrebbe restituire un "carrello di evasione" che ha una coppia `aislecode => quantity` per ogni articolo ordinato dal cliente.
Gli articoli devono comparire nell'ordine dei loro codici di corsia.

```julia-repl
julia> cart = Dict("Orange" => 1, "Milk" => 2, "Banana" => 3, "Apple" => 2, "Chocolate" => 2);

julia> aislecodes = Dict("Orange" => 2.4, "Milk" => 3.3, "Banana" => 2.6, "Apple" => 2.2, "Chocolate" => 5.7);

julia> send_to_store(cart, aislecodes)
5-element Vector{Pair{Float64, Int64}}:
 2.2 => 2
 2.4 => 1
 2.6 => 3
 3.3 => 2
 5.7 => 2
```

## 4. Aggiorna l'inventario del negozio in base a ciò che un utente ha ordinato

L'app non può semplicemente registrare ordini dei clienti all'infinito.
Prima o poi, al negozio finiranno vari prodotti.
Quindi l'MVP dell'app deve aggiornare l'inventario del negozio ogni volta che un utente invia il proprio ordine al negozio.
Altrimenti, i clienti ordineranno prodotti che in realtà non sono disponibili.

Definisci la funzione `update_store_inventory!(<inventory>, <cart>)` che prende un `cart` e un `inventory`.
La funzione dovrebbe ridurre le quantità dell'inventario del negozio del numero «ordinato» nel carrello e poi restituire un dizionario degli articoli esauriti (cioè quelli che hanno raggiunto `0`).

```julia-repl
julia> inventory = Dict("Banana" => 15, "Apple" => 12, "Orange" => 1, "Milk" => 4);

julia> cart = Dict("Orange" => 1, "Milk" => 2, "Banana" => 3, "Apple" => 2);

julia> update_store_inventory!(inventory, cart)
Dict{String, Int64} with 1 entry:
  "Orange" => 0

julia> inventory
Dict{String, Int64} with 4 entries:
  "Milk"   => 2
  "Apple"  => 10
  "Orange" => 0
  "Banana" => 12
```

## 5. Riordina gli articoli esauriti

Oltre ad aggiornare l'inventario, l'app può aiutare a rifornirlo.
L'MVP dovrebbe essere in grado di preparare un mini-ordine degli articoli esauriti dopo l'ordine di un cliente.
Così sarà più semplice avviare un ordine più grande.
Inoltre, a volte ci sono articoli in promozione a tempo limitato che non sono nella lista delle scorte.
Se si esauriscono prima della fine del periodo promozionale, significa che hanno avuto successo e possono essere aggiunti alla lista delle scorte.

Definisci la funzione `reorder!(<outofstock>, <stock>)` che prende `outofstock` e `stock`.
Il dizionario `stock` contiene gli articoli standard e le rispettive quantità di riordino.
Il dizionario `outofstock` è il risultato di `update_store_inventory!`, cioè un dizionario di articoli con quantità zero.
Le quantità in `outofstock` vanno aggiornate con quelle in `stock` e restituite.
Inoltre, qualsiasi articolo presente in `outofstock` ma non in `stock` va aggiunto a `stock` con una quantità predefinita di `100`.

```julia-repl
julia> inventory = Dict("Banana" => 15, "Apple" => 12, "Orange" => 1, "Milk" => 4, "Chocolate" => 2);

julia> cart = Dict("Orange" => 1, "Milk" => 2, "Banana" => 3, "Apple" => 2, "Chocolate" => 2);

julia> stock = Dict("Banana" => 150, "Apple" => 120, "Orange" => 120, "Milk" => 45);

julia> outofstock = update_store_inventory!(inventory, cart)
Dict{String, Int64} with 1 entry:
  "Orange"    => 0
  "Chocolate" => 0

julia> reorder!(outofstock, stock)
Dict{String, Int64} with 1 entry:
  "Orange"    => 120
  "Chocolate" => 100

julia> stock 
Dict{String, Int64} with 5 entries:
  "Milk"      => 45
  "Apple"     => 120
  "Chocolate" => 100
  "Orange"    => 120
  "Banana"    => 150
```
