# Approfondimento

In Common Lisp i parametri con nome si chiamano parametri keyword.

I parametri keyword sono indicati dalla parola chiave di lambda list `&key` in una lambda list.
I parametri keyword non sono obbligatori, possono avere un valore predefinito e possono anche specificare un «parametro supplied-p», che sarà «true» o «false» a seconda che per il parametro sia stato fornito o meno un argomento.

```lisp
(defun keyword-parameter (&key (arg -1) arg)
(keyword-parameter)         ; => -1
(keyword-parameter :arg 13) ; => 13
```

Negli argomenti di una funzione, i parametri keyword vengono specificati tramite il loro «nome keyword», che per impostazione predefinita è la versione simbolo keyword del nome del parametro (cioè il parametro keyword `name` ha come nome keyword `:name`).
È possibile specificare un altro nome per il parametro keyword usando una lista composta dal nome keyword e dal nome del parametro al posto del solo nome del parametro:

```lisp
(defun other-keyword-name (&key ((other-name arg))) (list arg))
(other-keyword-name 'other-name 5) ; => (5)
```

Sebbene più tipi di parametri si possano combinare con altri tipi di parametri (parametri opzionali e parametri keyword), questo può essere problematico e va fatto con attenzione.
Consulta la sezione ["Mixing Different Parameter Types"][pcl-function] di Practical Common Lisp.
