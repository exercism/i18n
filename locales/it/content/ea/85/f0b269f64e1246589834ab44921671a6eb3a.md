# Introduzione

Oltre alle dichiarazioni di funzione e alle espressioni di funzione, JavaScript ha anche un'altra sintassi molto concisa per definire una funzione.
Queste funzioni si chiamano _funzioni freccia_.

In questo concetto, ci concentreremo sulla sintassi usata per scrivere una funzione freccia.
Esistono differenze nel modo in cui funziona una funzione freccia, come il binding di _this_, che vedremo in altri concetti.

Ecco un confronto tra una dichiarazione di funzione e una funzione freccia.

```javascript
function addUpTwoNumbers(num1, num2) {
  return num1 + num2;
}

// function keyword removed and => added
const addUpTwoNumbers = (num1, num2) => {
  return num1 + num2;
};
```

Qui sopra puoi vedere che la sintassi della funzione freccia:

1. elimina la parola chiave `function`
2. dichiara l'identificatore `addUpTwoNumbers` come `const`
3. aggiunge una freccia spessa `=>`

Se il corpo della funzione contiene solo un'istruzione return, come nell'esempio qui sopra, si possono omettere le parentesi graffe `{}` e la parola chiave `return`.

<!-- prettier-ignore-start -->
```javascript
const addUpTwoNumbers = (num1, num2) => { return num1 + num2 };

// can be shortened to
const addUpTwoNumbers = (num1, num2) => num1 + num2;
// braces {} and return removed
```
<!-- prettier-ignore-end -->

Nel caso particolare in cui una funzione freccia restituisce solo un oggetto, servono le parentesi intorno all'oggetto per poter omettere l'istruzione return.

```javascript
// explicit return of object
const addUpTwoNumbers = (num1, num2) => {
  return {
    num1,
    num2,
  };
};

// implicit return of object
const addUpTwoNumbers = (num1, num2) => ({ num1, num2 });
```

L'uso delle parentesi intorno ai parametri dipende dal numero di parametri.

<!-- prettier-ignore-start -->
```javascript
// one parameter does not need parenthesis
const square = num => num * num;

// two or more parameters need to be wrapped in parenthesis
const addUpTwoNumbers = (num1, num2) => num1 + num2;
```
<!-- prettier-ignore-end -->
