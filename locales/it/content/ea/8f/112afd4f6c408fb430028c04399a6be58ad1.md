# Introduzione

Se vuoi costruire qualcosa usando un Raspberry Pi, probabilmente userai delle _resistenze_.
Come negli esercizi precedenti [`Resistor Color Duo`][resistor-color-duo-exercise] e [`Resistor Color Trio`][resistor-color-trio-exercise], convertirai le bande colorate delle resistenze in etichette leggibili da una persona.

- Ogni resistenza ha un valore di resistenza.
- Le resistenze sono piccole, così piccole che se ci stampassi sopra il valore di resistenza sarebbe difficile leggerlo.
  Per aggirare questo problema, i produttori stampano sulle resistenze delle bande colorate che ne indicano il valore di resistenza.
- Ogni banda rappresenta una cifra di un numero.
  Per esempio, se stampassero una banda brown (valore 1) seguita da una banda green (valore 5), corrisponderebbe al numero 15.
