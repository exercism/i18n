# Introduzione

## Costanti

Il modificatore `const` può essere applicato (e in genere dovrebbe esserlo) a qualsiasi campo il cui valore sia noto in fase di compilazione e non cambi durante la vita del programma.

```csharp
private const int num = 1729;
public const string title = "Grand" + " Master";
```

Il modificatore `readonly` può essere applicato (e in genere dovrebbe esserlo) a qualsiasi campo che non possa essere reso `const`, il cui valore non cambi durante la vita del programma e che venga impostato tramite un inizializzatore inline oppure durante l'istanziazione (dal costruttore o da un metodo chiamato dal costruttore).

```csharp
private readonly int num;
private readonly System.Random rand = new System.Random();

public MyClass(int num)
{
    this.num = num;
}
```

## Copia difensiva

Nelle situazioni sensibili alla sicurezza (o anche semplicemente in una grande base di codice, dove gli sviluppatori hanno priorità e obiettivi diversi) dovresti evitare di permettere che l'API pubblica di una classe venga aggirata accettando e memorizzando parametri mutabili di un metodo oppure esponendo un membro mutabile di una classe tramite un valore restituito o come parametro `out`.

## Collezioni readonly

Mentre il modificatore `readonly` impedisce che il valore o il riferimento contenuto in un campo venga sovrascritto, non offre alcuna protezione per i membri di un tipo di riferimento.

```csharp
readonly List<int> ints = new List<int>();

void Foo()
{
    ints.Add(1);    // ok
    ints = new List<int>(); // fails to compile
}
```

Per assicurarti che tutti i membri di un tipo di riferimento siano protetti, puoi rendere i campi `readonly` e definire proprietà automatiche senza una funzione di accesso `set`.

La Base Class Library (BCL) fornisce alcune versioni readonly delle collezioni, pensate per bloccare l'aggiornamento dei membri di una collezione. Si presentano sotto forma di wrapper:

- `ReadOnlyDictionary<T>` espone un `Dictionary<T>` in sola lettura.
- `ReadOnlyCollection<T>` espone una `List<T>` in sola lettura.
