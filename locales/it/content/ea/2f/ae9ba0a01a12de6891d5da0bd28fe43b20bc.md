# Istruzioni

In questo esercizio scriverai il codice per stampare i badge con il nome dei dipendenti della fabbrica.

## 1. Stampa un badge per un dipendente

I dipendenti hanno un ID, un nome e il nome del reparto. Le etichette dei badge dei dipendenti hanno il seguente formato: `"[id] - name - DEPARTMENT"`.
Implementa il metodo `Badge.print()` in modo che restituisca l'etichetta del badge di un dipendente:

```java
Badge badge = new Badge();
badge.print(734, "Ernest Johnny Payne", "Strategic Communication");
// => "[734] - Ernest Johnny Payne - STRATEGIC COMMUNICATION"
```

Nota che il reparto va scritto in maiuscolo sull'etichetta.

## 2. Stampa un badge per un nuovo dipendente

A causa di una stranezza del sistema informatico, ogni tanto i nuovi dipendenti non hanno ancora un ID quando iniziano a lavorare in fabbrica.
Dato che il badge è obbligatorio, riceveranno un badge temporaneo senza il prefisso dell'ID. Modifica il metodo `Badge.print()` per gestire i nuovi dipendenti che non hanno ancora un ID:

```java
Badge badge = new Badge();
Badge.print(null, "Jane Johnson", "Procurement");
// => "Jane Johnson - PROCUREMENT"
```

## 3. Stampa un badge per il proprietario

Anche il proprietario della fabbrica deve indossare un badge in ogni momento.
Il proprietario, però, non ha un reparto. In questo caso, l'etichetta deve stampare `"OWNER"` al posto del nome del reparto.
Modifica il metodo `Badge.print()` per stampare l'etichetta del proprietario:

```java
Badge badge = new Badge();
badge.print(254, "Charlotte Hale", null);
// => "[254] - Charlotte Hale - OWNER"
```

Nota che il proprietario può essere anche un nuovo dipendente:

```java
Badge badge = new Badge();
badge.print(null, "Charlotte Hale", null);
// => "Charlotte Hale - OWNER"
```
