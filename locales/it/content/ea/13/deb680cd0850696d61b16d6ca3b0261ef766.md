# Introduzione

[Go](https://golang.org) è un linguaggio di programmazione compilato e a tipizzazione statica.
In questo esercizio introdurremo tre caratteristiche principali del linguaggio: i package, le funzioni e le variabili.

## I package

Le applicazioni Go sono organizzate in package.
Un package è un insieme di file sorgente che si trovano nella stessa directory.
Tutti i file sorgente in una directory devono condividere lo stesso nome di package.
Quando si importa un package, è possibile usare o accedere solo alle entità (funzioni, tipi, variabili, costanti) il cui nome inizia con una lettera maiuscola.
Lo stile di denominazione consigliato in Go prevede che gli identificatori siano scritti in `camelCase`, tranne quelli che devono essere accessibili da altri package, che dovrebbero usare `PascalCase`.

```go
package lasagna
```

## Le variabili

Go è a tipizzazione statica, il che significa che tutte le variabili [devono avere un tipo definito](https://en.wikipedia.org/wiki/Type_system) in fase di compilazione.

Le variabili si possono definire specificando esplicitamente un tipo:

```go
var explicit int // Explicitly typed
```

Puoi anche usare un valore di inizializzazione: il compilatore assegnerà alla variabile un tipo corrispondente a quello del valore.

```go
implicit := 10   // Implicitly typed as an int
```

Una volta dichiarata, a una variabile si possono assegnare dei valori usando l'operatore `=`.
Una volta dichiarata, il tipo di una variabile non può mai cambiare.

```go
count := 1 // Assign initial value
count = 2  // Update to new value

count = false // This throws a compiler error due to assigning a non `int` type
```

## Le costanti

Le costanti contengono un dato proprio come le variabili, ma il loro valore non può cambiare durante l'esecuzione del programma.

Le costanti si definiscono con la parola chiave `const` e possono essere numeri, caratteri, stringhe o valori booleani:

```go
const Age = 21 // Defines a numeric constant 'Age' with the value of 21
```

## Le funzioni

Le funzioni Go accettano zero o più parametri.
I parametri devono avere un tipo esplicito: non c'è inferenza di tipo.

I valori vengono restituiti dalle funzioni usando la parola chiave `return`.

Una funzione si chiama specificando il suo nome e passando un argomento per ciascuno dei suoi parametri.

Nota che Go supporta due tipi di commenti.
I commenti su una sola riga sono preceduti da `//`, mentre i commenti su più righe si inseriscono tra `/*` e `*/`.

```go
package greeting

// Hello is a public function.
func Hello (name string) string {
    return hi(name)
}

// hi is a private function.
func hi (name string) string {
    return "hi " + name
}
```
