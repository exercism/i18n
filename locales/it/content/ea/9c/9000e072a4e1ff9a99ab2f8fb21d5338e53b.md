# Introduzione

In Python, [un enum](https://docs.python.org/3/library/enum.html) è un insieme di nomi associati a valori `literal`, o `constant`, univoci. Gli enum si definiscono ereditando una classe `Enum`. I tipi enum integrati sono disponibili nel modulo `enum` e la classe `Enum` si può importare con `from enum import Enum`.

```python
class Color(Enum):
    RED = 1
    GREEN = 2
```

Nota che i valori dei membri di un enum possono essere di qualsiasi tipo di dato, come str, tuple, float e così via.

```python
class Color(Enum):
    RED = 'red'
    GREEN = 'green'
```

Quando si assegna lo stesso valore a due membri di un enum, il membro assegnato per secondo diventa un alias di quello già formato. Non è consentito usare lo stesso nome per due membri di un enum.

```python
class Color(Enum):
    RED = 1
    GREEN = 2
    ALIAS_OF_RED = 1

Color.ALIAS_OF_RED
#=> <Color.RED: 1>

Color.ALIAS_OF_RED.value
#=> 1
```

Si può iterare sui membri dell'enum con la sintassi standard `for member in`:

```python
for member in Color:
    print((member.name, member.value))
#=> (RED, 1)
#=> (GREEN, 2)
```

I membri di un enum si possono confrontare con [`is` (_operatore di identità_)](https://www.w3schools.com/python/ref_keyword_is.asp) oppure `is not`. Anche `==` e `!=` (_operatori di uguaglianza_) funzionano allo stesso modo.

```python
a = Color.RED

a is Color.RED
#=> True

a == Color.RED
#=> True
```

Per accedere a un membro dell'enum a partire da un dato valore, si può usare `EnumName(value)`:

```python
g = Color(2)

g is Color.GREEN
#=> True

g
#=> <Color.GREEN: 2>
```
