# Introduzione

## Variabili di istanza

Gli oggetti possono mantenere il proprio stato impostando delle _variabili di istanza_.
Queste variabili vivono all'interno di un oggetto e normalmente servono a memorizzare uno stato interno.

Le variabili di istanza iniziano sempre con una `@`.
Puoi creare una nuova variabile di istanza assegnando una variabile che inizia con una `@`.
Per esempio:

```ruby
class Repeater
  def hear(something)
    # Save what's been heard into a new instance variable called @heard
    @heard = something
  end

  def repeat
    # Return the value of the instance variable
    @heard
  end
end

repeater = Repeater.new
repeater.hear("Hello, friend!")
print repeater.repeat # Prints "Hello, friend!"
```

Di solito gli oggetti impostano il proprio stato iniziale in un metodo `initialize`, che viene chiamato automaticamente quando si chiama `new` su una classe.

```ruby
class Airplane
  def initialize
    @wings = 2
  end

  def wings
    @wings
  end
end

plane = Airplane.new
plane.wings # returns 2
```

Il metodo `initialize` può anche accettare argomenti, così che ogni istanza possa partire con uno stato personalizzato:

```ruby
class Suitcase
  def initialize(locked)
    @locked = locked
  end
end
```

È buona pratica considerare le variabili di istanza come private rispetto a letture e scritture esterne.
Al loro posto, definiamo dei metodi per leggerne e impostarne i valori.
Per esempio:

```ruby
class Suitcase
  def initialize
    @locked = false
  end

  def locked? # Query methods should be named with a trailing `?`
    @locked
  end

  def lock! # Methods which mutate state should have trailing `!`
    @locked = true
  end
end

suitcase = Suitcase.new
suitcase.locked? # false
suitcase.lock!
suitcase.locked? # true
```

## Nil

[Nil][nil-dictionary] è una parola inglese che significa «niente» o «zero».
In Ruby, `nil` viene usato per esprimere l'_assenza_ di un oggetto.
In altri linguaggi di programmazione, valori come `null` o `none` possono svolgere un ruolo simile.

```ruby
# I do not have a favorite color
favorite_color = nil
```

Ruby assegna a qualsiasi variabile di istanza il valore predefinito `nil` quando viene incontrata per la prima volta, finché non le viene assegnato un valore diverso.

```ruby
print @favourite_color # prints nil
@favourite_color = "blue"
print @favourite_color # prints "blue"
```
