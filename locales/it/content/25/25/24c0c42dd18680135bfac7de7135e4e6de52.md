# Eseguire i test

Per compilare ed eseguire i test, esegui quanto segue nella directory dell'esercizio:
```bash
$ ponyc
$ ./exercise-name
```

(Sostituisci `exercise-name` con il nome della directory dell'esercizio)

Il binario compilato esegue i test nel suo Main actor: basta eseguire il binario e controllare se i test sono passati. Pony controlla tutto il codice in fase di compilazione, quindi potresti scoprire che i test non si compilano finché non scrivi il codice richiesto. Puoi trasformare in commento i test che non si compilano facendo iniziare ogni riga con `//`. Poi, quando sei pronto a lavorare su quel test, puoi togliere il commento.
