# Appendice alle istruzioni

## Letterali per le date di nascita con `from_quote`

La funzione `DateOfBirth.from_quote` analizza una stringa nel formato `"YYYY-MM-DD"` e la trasforma in un `DateOfBirth`.
Questo permette di scrivere codice come il seguente:

```roc
birthdate : DateOfBirth
birthdate = "2019-01-20"
```

Questo codice chiama implicitamente `DateOfBirth.from_quote("2019-01-20")` al momento della compilazione. Eseguire codice al momento della compilazione con questo approccio (o con gli altri metodi descritti qui sotto) può potenzialmente velocizzare il programma, perché non deve gestire il parsing e la validazione dei dati a runtime. Inoltre, garantisce che i dati non validi (come un formato di data errato) vengano rifiutati al momento della compilazione invece che a runtime, rendendo l'app più robusta. Infine, rende il codice bello e leggibile. Per esempio, ecco uno dei test di questo esercizio:

```roc
# multiple birthdates with one shared birthday
expect {
	shared_birthday(["1966-07-29", "1977-02-12", "2001-07-29", "1980-11-10"])
}
```

Tuttavia, chi legge questo codice potrebbe pensare che la funzione `shared_birthday` accetti una `List(Str)`, quando in realtà accetta una `List(DateOfBirth)`. Questo può portare a confusione ed errori. Per questo motivo, potresti preferire il formato un po' più lungo ma più esplicito: `"2019-01-20".DateOfBirth`, che chiama anch'esso `from_quote` al momento della compilazione.

Nei tuoi programmi potresti preferire fornire un costruttore comodo, come questo:

```roc
DateOfBirth := { year : I64, month : U8, day : U8 }.{
    from_ymd : I64, U8, U8 -> Try(DateOfBirth, [InvalidMonth, InvalidDay])
    from_ymd = |year, month, day| ...
}
```

Puoi anche chiamare questo costruttore al momento della compilazione, in questo modo:

```roc
Ok(birthdate) = DateOfBirth.from_ymd(2019, 1, 20)
```

Nota: collocare questa definizione al livello superiore la fa eseguire al momento della compilazione (dato che la funzione è pura e gli input sono noti al momento della compilazione). All'interno di una funzione, puoi usare lo stesso costruttore a runtime.
