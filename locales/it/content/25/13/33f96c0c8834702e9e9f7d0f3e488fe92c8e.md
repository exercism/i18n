# Istruzioni

In questo esercizio genererai bollettini meteorologici per una stazione di notizie locale.

## Genera i bollettini meteorologici

Inizierai con alcune funzioni stub e con il seguente enum:

```rust
#[derive(Drop, Clone, PartialEq, Debug)]
pub enum WeatherCondition {
    Sunny,
    Rainy,
    Cloudy,
    Stormy
}
```

Dovrai formattare un bollettino meteorologico come `"Today is <CONDITION> with a temperature of <TEMPERATURE> degrees Celsius."`.
Dovrai implementare la funzione che restituisce le condizioni meteorologiche corrette.

Ad esempio, lo snippet qui sotto mostra l'output atteso della funzione `get_weather_report` per una giornata «piovosa».

```rust
get_weather_report(WeatherCondition::Rainy, "25")
// Returns: "Today is RAINY with a temperature of 25 degrees Celsius."
```

E per una giornata «soleggiata»:

```rust
get_weather_report(WeatherCondition::Sunny, "30")
// Returns: "Today is SUNNY with a temperature of 30 degrees Celsius."
```
