# Informazioni

Una [tupla](https://docs.microsoft.com/en-us/dotnet/fsharp/language-reference/tuples) è un raggruppamento _immutabile_ di valori senza nome ma ordinati.
Le tuple possono contenere qualsiasi tipo di dato, o anche più di uno, comprese altre tuple.

Le tuple si definiscono come valori separati da virgole tra i caratteri `(` e `)`: `(<element_1>, ... , <element_n>)`.

```fsharp
("one", 2) // Tuple pair (2 values)
("one", 2, true) // Tuple triplet (3 values)
```

Si possono confrontare solo tuple con la stessa lunghezza e gli stessi tipi (nello stesso ordine).
Le tuple hanno uguaglianza strutturale, il che significa che sono uguali _solo_ se tutti i loro valori sono uguali.

```fsharp
(1, 2) = (1, 2) // Same length, same types, same values, same order
// => true

(1, 2) = (2, 1) // Same length, same types, same values, different order
// => false

(1, 2) = (1, "2") // Same length, different types
// compiler error

(1, 2) = (1, 2, 3) // Different length
// compiler error
```

Ci sono [tre modi per estrarre i valori da una tupla](https://docs.microsoft.com/en-us/dotnet/fsharp/language-reference/tuples#obtaining-individual-values):

- Le funzioni `fst` e `snd`
- La decostruzione della tupla
- Il pattern matching

```fsharp
let person = ("Jordan", 170)

// Option 1: fst/snd
let name1 = fst person
let length1 = snd person

// Option 2: deconstruction
let (name2, length2) = person

// Option 3: pattern matching
match person with
| name3, length3 -> printf "%s: %d" name3 length3
```

~~~~exercism/note
Tecnicamente, puoi accedere al valore di una tupla usando le sue proprietà `.Item1`, `.Item2`, ... ma questo è sconsigliato e produce un avviso del compilatore.
~~~~

## Punti chiave sulle tuple

Ecco alcune cose importanti da sapere sulle tuple:

- Una particolare istanza di un tipo tupla è un singolo oggetto, simile, per esempio, ad un array di due elementi in C#. Quando la usi con una funzione, conta come un singolo parametro. L'unica eccezione è quando chiami codice non F# con più parametri: in quel caso passi una tupla ed i suoi valori vengono estratti automaticamente nel valore del parametro corrispondente.
- Ai tipi tupla non si possono dare nomi espliciti. Il «nome» del tipo tupla è determinato dalla combinazione dei tipi che vengono moltiplicati tra loro.
- La virgola è il simbolo cruciale che definisce le tuple, non le parentesi. Puoi definire le tuple senza parentesi, anche se a volte può risultare confuso. In F#, se vedi una virgola, probabilmente fa parte di una tupla.
- Le tuple possono essere usate come argomenti di una funzione e come valore restituito da una funzione.
