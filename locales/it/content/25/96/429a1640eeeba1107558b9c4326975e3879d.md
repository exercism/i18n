# Informazioni

Quando una funzione accetta un'altra funzione (o una closure) come parametro, la closure passata è detta *non-escaping* per impostazione predefinita.
Si dice che una closure *escape* da una funzione quando viene chiamata dopo che la funzione stessa è già terminata.

Questa situazione si verifica spesso quando:

- Una closure viene memorizzata in una variabile esterna o in una proprietà.
- Una closure viene eseguita in modo asincrono dopo che un'operazione è terminata.
- Una closure viene restituita dalla funzione per essere chiamata più tardi.

Considera il seguente esempio:

```swift
func emptyKitchen(_ order: String) -> String {
    "Sorry, we're all out of \(order)."
}

func prepare(order: String, kitchen: (String) -> String) -> (String) -> String {
    func newKitchen(_ newOrder: String) -> String {
        if newOrder == order {
            return "One \(order) coming up!"
        } else {
            return kitchen(newOrder)
        }
    }
    return newKitchen
}
```

In questo codice, `prepare` accetta una funzione di nome `kitchen`, costruisce una nuova funzione `newKitchen` che chiama `kitchen` e restituisce `newKitchen`.
Se provi a compilare questo codice, ottieni un errore: `Escaping local function captures non-escaping parameter 'kitchen'`.

Poiché `newKitchen` sopravvive a `prepare`, la closure `kitchen` esegue l'escape.
Per permetterlo, contrassegna il tipo del parametro con l'attributo `@escaping`.

```swift
func prepare(order: String, kitchen: @escaping (String) -> String) -> (String) -> String {
    func newKitchen(_ newOrder: String) -> String {
        if newOrder == order {
            return "One \(order) coming up!"
        } else {
            return kitchen(newOrder)
        }
    }
    return newKitchen
}

let restaurant = prepare(
    order: "sandwich",
    kitchen: prepare(
        order: "chicken",
        kitchen: prepare(order: "steak", kitchen: emptyKitchen)
    )
)

print(restaurant("pork chop"))
// Prints "Sorry, we're all out of pork chop."

print(restaurant("chicken"))
// Prints "One chicken coming up!"
```

L'attributo `@escaping` informa il compilatore Swift che la closure sopravvivrà alla chiamata immediata della funzione, permettendo a Swift di gestire correttamente la memoria ed i riferimenti catturati.
