# Introduzione

## Gli array

Gli array in PHP sono mappe ordinate.
Una mappa è una struttura dati che associa una chiave a un valore.
Gli array sono versatili e possono essere trattati come un array lineare (come in `C` o `Java`), una lista [vector], una tabella hash, un dizionario, una collezione, uno stack o una coda.

Una chiave è opzionale, ma se specificata deve essere un `int` o una `string`.
Quando una chiave non viene fornita, PHP usa per impostazione predefinita chiavi intere in ordine crescente, a partire da `0`.

```php
$no_keys = ["my", "first", "array"];
$integer_keys = [0 => "my", 1 => "first", 2 => "array"];

$no_keys == $integer_keys // => equal returns true
$no_keys === $integer_keys // => strictly equal returns true
```

Un array può memorizzare valori di tutti i tipi.
Ogni valore può avere un tipo diverso.

### Usare gli array

Gli array si possono dichiarare come letterale (scritto nel codice, come sopra) oppure creare e manipolare tramite funzioni.
Per accedere ai valori, assegnarli e aggiungerli si usa l'operatore di indice:

```php
$prime_numbers = [2, 3, 5, 6];

$prime_numbers[3] = 7; // replace 6 with 7

$prime_numbers[] = 11; // array now contains [2, 3, 5, 7, 11]
```

## Argomenti di lunghezza variabile

Gli argomenti di una funzione possono essere specificati in modo che accetti un numero qualsiasi di argomenti:

```php
<?php

function actOnItems(...$items) {
  // $items is an array containing 0 or more values
  // used to call the function.
}

actOnItems(1, 2, 3, 4); // $items => [1, 2, 3, 4]
```
