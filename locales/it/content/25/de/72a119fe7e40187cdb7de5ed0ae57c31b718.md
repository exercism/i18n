# Appendice alle istruzioni

## Registri

| Registro | Utilizzo   | Tipo      | Descrizione                        |
| -------- | ---------- | --------- | ---------------------------------- |
| `$a0`    | input      | intero    | x                                  |
| `$a1`    | input      | intero    | y                                  |
| `$v0`    | output     | intero    | punti guadagnati                   |
| `$t0-9`  | temporaneo | qualsiasi | usato per la memorizzazione temporanea |
