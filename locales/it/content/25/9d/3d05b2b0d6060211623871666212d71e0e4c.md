# Istruzioni

Stai tenendo un conteggio giornaliero di quanti uccelli visitano il tuo giardino. I dati sono memorizzati in un array di numeri interi, con **il conteggio di oggi per primo**.

## 1. Il conteggio di oggi

Definisci `today` in modo che prenda dallo stack un array di conteggi giornalieri e restituisca il conteggio di oggi, oppure `f` se l'array è vuoto.

```factor
{ 2 5 1 } today .
! => 2

{ } today .
! => f
```

## 2. Incrementa il conteggio di oggi

Definisci `increment-day-count` in modo che restituisca un nuovo array con il conteggio di oggi aumentato di uno. Se l'input è vuoto, restituisci `{ 1 }`.

```factor
{ 4 0 2 } increment-day-count .
! => { 5 0 2 }

{ } increment-day-count .
! => { 1 }
```

## 3. C'è stato un giorno senza uccelli?

Definisci `has-day-without-birds?` in modo che restituisca `t` se almeno un giorno ha registrato zero uccelli, altrimenti `f`.

**Usa la ricorsione** invece di `any?` o di altre parole di ordine superiore per le sequenze.

```factor
{ 2 0 4 } has-day-without-birds? .   ! => t
{ 3 8 1 5 } has-day-without-birds? . ! => f
```

## 4. Uccelli totali da quando hai iniziato

Definisci `total` in modo che restituisca la somma di tutti i conteggi.

**Usa la ricorsione** invece di `sum`.

```factor
{ 4 0 9 0 5 } total .
! => 18
```

## 5. Giorni intensi

Un giorno intenso è un giorno con cinque o più uccelli. Definisci `busy-days` in modo che restituisca il numero di giorni intensi.

**Usa la ricorsione** invece di `count`.

```factor
{ 4 5 0 0 6 } busy-days .
! => 2
```
