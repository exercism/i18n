# Istruzioni

Lavori con un team di sviluppo web per mantenere un sito web per una squadra di basket locale. Il team di sviluppo web ha meno familiarità con Elixir e chiede una funzione per estrarre dati da una serie di mappe annidate, per facilitare lo sviluppo rapido.

## 1. Estrai i dati da una struttura di mappe annidate

Implementa la funzione `extract_from_path/2` in modo che accetti due argomenti:

- `data`: una struttura di mappe annidate con i dati sulla squadra di basket.
- `path`: una stringa composta da chiavi delimitate da punti per ottenere il valore associato all'ultima chiave.

Se il valore o la chiave non esiste in qualsiasi punto del percorso, va restituito `nil`

```elixir
data = %{
  "team_mascot" => %{
    "animal" => "bear",
    "actor" => %{
      "first_name" => "Noel"
    }
  }
}

BasketballWebsite.extract_from_path(data, "team_mascot.animal")
# => "bear"
BasketballWebsite.extract_from_path(data, "team_mascot.colors")
# => nil
```

Usa l'_Access Behaviour_ quando implementi questa funzione.

Non usare nessuna funzione dei moduli `Map` o `Kernel` per lavorare con la struttura di mappe annidate.

## 2. Riorganizza usando le funzioni incluse

Un collega che revisiona il codice ti parla di una funzione del modulo `Kernel` che fa qualcosa di molto simile a quella appena implementata.

Implementa `get_in_path/2` per usare questa funzione del modulo `Kernel`.

Gli argomenti attesi sono gli stessi della parte 1.

```elixir
BasketballWebsite.get_in_path(data, "team_mascot.actor.first_name")
# => "Noel"
```
