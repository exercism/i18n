## Eseguire i test

1. Vai alla radice della directory del tuo esercizio PHP, che si trova in `<EXERCISM_WORKSPACE>/php`.
   Per trovare il workspace di Exercism, esegui

   ```shell
   exercism workspace
   ```

2. Installa [PHPUnit] se non ce l'hai già.
3. Esegui i test con:

   ```shell
   phpunit test_file.php
   ```

   Per esempio, per eseguire i test dell'esercizio Hello World, esegui:

   ```shell
   phpunit HelloWorldTest.php
   ```

[PHPUnit]: https://exercism.org/docs/tracks/php/installation#h-via-php-archive-phar
