# Istruzioni

Stai aiutando con un censimento degli uccelli. Ogni giorno qualcuno si siede in un capanno e conta quello che passa in volo, e i conteggi della giornata tornano indietro sotto forma di array.

Tutte e cinque le attività vanno nella classe `BIRD_SURVEY`.

## 1. Il totale

Somma il conteggio di ogni giornata.

```sather
BIRD_SURVEY::total_seen(|3, 0, 7|)
-- => 10
```

Un censimento senza alcuna giornata conta zero uccelli.

## 2. La giornata migliore

Restituisci il conteggio più grande. Se non ci sono giornate, la risposta è zero.

```sather
BIRD_SURVEY::busiest_day(|3, 0, 7|)
-- => 7
```

## 3. Le giornate intense

Quante giornate hanno avuto un conteggio superiore a un certo numero?

```sather
BIRD_SURVEY::days_over(|3, 0, 7|, 2)
-- => 2
```

Superiore significa superiore: un conteggio esattamente pari a 2 non vale.

## 4. I capanni da controllare

Il primo giorno del censimento controlli un capanno, il secondo due, e così via. Quanti controlli dei capanni sono in tutto?

```sather
BIRD_SURVEY::hides_to_check(4)
-- => 10
```

Cioè 1 + 2 + 3 + 4.

## 5. La prima giornata intensa

Qual è stata la prima giornata con un conteggio superiore a un certo numero? Le giornate sono numerate a partire da zero, come le posizioni di un array. Se nessuna giornata è stata così intensa, la risposta è `-1`.

```sather
BIRD_SURVEY::first_busy_day(|3, 0, 7|, 5)
-- => 2
BIRD_SURVEY::first_busy_day(|3, 0, 7|, 9)
-- => -1
```
