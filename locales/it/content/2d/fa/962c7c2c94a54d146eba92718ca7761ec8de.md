# Nessun export con nome

Non è stato trovato [`export %{export.name}`](https://developer.mozilla.org/en-US/docs/Web/JavaScript/Reference/Statements/export).
Senza di esso, i test non passeranno.

Assicurati che `%{export.name}` esista e aggiungi `export` davanti ad esso:
```javascript
// exporting a "const"
export const %{export.name} = /*...*/

// exporting a named function declaration
export function %{export.name}() { /* ... */ }
```
