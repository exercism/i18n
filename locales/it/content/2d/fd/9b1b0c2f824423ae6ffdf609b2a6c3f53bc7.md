# Istruzioni

Stai lavorando a un gioco destinato a un sistema embedded a basso consumo e devi scrivere alcune funzioni di utilità che verranno usate da altre parti del gioco.

## 1. Calcolare il quoziente e il resto di una divisione

Il quoziente è l'output di una divisione.

```rust
fn divmod(dividend: i16, divisor: i16) -> (i16, i16)
```

Esempio:

```rust
assert_eq!(divmod(10, 3), (3, 1));
```

## 2. Scegliere gli elementi in posizione pari da un iteratore

A detta del tuo capo, servirà ad abilitare un'ottimizzazione del buffer dello schermo.

Gli iteratori sono elementi che espongono i metodi definiti dal [trait `Iterator`](https://doc.rust-lang.org/std/iter/trait.Iterator.html). Quella documentazione è piuttosto ampia, perché offrono molti metodi; ecco le proprietà più rilevanti:

- Un iteratore è un flusso di elementi di lunghezza arbitraria
- Hanno un [metodo `enumerate`](https://doc.rust-lang.org/std/iter/trait.Iterator.html#method.enumerate) che restituisce una tupla `(i, val)` per ogni valore
- Hanno un [metodo `filter`](https://doc.rust-lang.org/std/iter/trait.Iterator.html#method.filter) che usa una chiusura per determinare se produrre un elemento dell'iteratore
- Hanno un [metodo `map`](https://doc.rust-lang.org/std/iter/trait.Iterator.html#method.map) che usa una chiusura per modificare gli elementi dell'iteratore

Poiché la tua funzione può essere eseguita su qualsiasi tipo di iteratore, usa `impl` per indicare che si tratta di un'istanza di un trait invece che di un semplice elemento. Allo stesso modo, la sintassi `<Item=T>` significa semplicemente che non importa che tipo di elemento produca l'iteratore; la tua funzione può produrre gli elementi pari di qualsiasi iteratore.

```rust
fn evens<T>(iter: impl Iterator<Item=T>) -> impl Iterator<Item=T>
```

Esempi:

```rust
let mut even_ints = evens(0_u8..);
assert_eq!(even_ints.next(), Some(0));
assert_eq!(even_ints.next(), Some(2));
assert_eq!(even_ints.next(), Some(4));
assert_eq!(even_ints.next(), Some(6));
```

```rust
let mut evens_from_odds = evens(1_i16..);
assert_eq!(evens_from_odds.next(), Some(1));
assert_eq!(evens_from_odds.next(), Some(3));
assert_eq!(evens_from_odds.next(), Some(5));
assert_eq!(evens_from_odds.next(), Some(7));
```

## 3. Calcolare la distanza di Manhattan di una posizione dall'origine

Per comodità di mappatura, hai una struct tupla `Position`:

```rust
struct Position(i16, i16);
```

Devi implementare un metodo `manhattan` su `Position` che restituisce la [distanza di Manhattan](https://en.wikipedia.org/wiki/Taxicab_geometry) di quella posizione dall'origine (`Position(0, 0)`).

```rust
impl Position {
    fn manhattan(&self) -> i16
}
```

Esempio:

```rust
assert_eq!(Position(3, 4).manhattan(), 7);
```
