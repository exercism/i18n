# Informazioni

Swift fornisce istruzioni di trasferimento del controllo per modificare il flusso di esecuzione dei cicli e delle istruzioni switch.
Oltre a `return`, Swift include `continue`, `break`, le etichette dei cicli e `fallthrough`.

## Continue

L'istruzione `continue` indica a un ciclo di interrompere l'esecuzione dell'iterazione corrente e di iniziare subito quella successiva.
In un ciclo `while` o `repeat-while`, salta direttamente al controllo della condizione.
In un ciclo `for-in`, passa all'elemento successivo della sequenza.

```swift
var count = 1
while count < 6 {
    count += 1
    if count == 4 {
        continue
    }
    print(count)
}

// Prints:
// 2
// 3
// 5
// 6
```

## Break

L'istruzione `break` esce immediatamente da un intero ciclo o da un'istruzione switch.
L'esecuzione riprende dalla prima riga di codice dopo il ciclo o l'istruzione switch.

```swift
for fruit in ["banana", "grapes", "apple", "strawberry", "kiwi", "lemon"] {
    if !fruit.count.isMultiple(of: 2) {
        break
    }
    print(fruit)
}

// Prints:
// banana
// grapes
```

## Istruzioni etichettate

Nei cicli annidati, potresti volere che `break` o `continue` agiscano su un ciclo esterno invece che sul ciclo più interno.
Puoi etichettare un ciclo anteponendogli un nome e due punti (`labelName:`).
Puoi quindi passare quell'etichetta a `break` o `continue`:

```swift
outerLoop: for fruit in ["banana", "grapes", "apple", "strawberry", "kiwi", "lemon"] {
    print("\n--- \(fruit) ---")
    for letter in fruit {
        guard letter != "n" else {
            break outerLoop
        }
        print(letter)
    }
}

// Prints:
// --- banana ---
// b
// a
```

## Fallthrough

In Swift, le istruzioni `switch` non passano al caso successivo per impostazione predefinita; l'esecuzione si ferma automaticamente alla fine del caso corrispondente.
Se vuoi esplicitamente che l'esecuzione continui nel caso successivo senza valutarne il pattern, usa la parola chiave `fallthrough`:

```swift
let value = 1
switch value {
case 1:
    print("One")
    fallthrough
case 2:
    print("Two")
default:
    break
}

// Prints:
// One
// Two
```
