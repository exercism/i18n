# Introduzione

## Booleani

Il tipo booleano in Lua ha i due tradizionali valori booleani: `true` e `false`. Questi valori si possono assegnare a una variabile, combinare con gli operatori logici (`and`, `or`, `not`) e usare nei test condizionali (ad esempio nelle strutture di controllo).

```lua
local is_true = true
local is_false = false

true and true  --> true
true and false --> false
false or true  --> true
false or false --> false
not false      --> true
not true       --> false

-- prints 0
if is_true == true then
  print(0)
else
  print(1)
end
```

I test condizionali e gli operatori logici considerano falsi sia il valore booleano `false` sia `nil`, e veri tutti gli altri valori.
```lua
1 and 2          --> 2
nil and 2        --> nil
false and 2      --> false
1 or 2           --> 1
false or 'hello' --> "hello"
nil or false     --> false
```

Sia `and` che `or` usano la *valutazione a corto circuito*: valutano il secondo operando solo quando è necessario. Tutte le operazioni vengono valutate secondo la [precedenza degli operatori](https://www.lua.org/manual/5.4/manual.html#3.4.8), in cui `not` viene valutato prima di `and` e `or`.
