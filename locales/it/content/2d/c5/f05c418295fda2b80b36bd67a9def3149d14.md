# Appendice alle istruzioni

## Suggerimenti

Se l'argomento è minore di `1`, restituisci [`NONE`](https://smlfamily.github.io/Basis/option.html#SIG:OPTION.option:TY:SPEC).

Alcuni di questi concetti potrebbero essere utili:

- [Valutazione pigra](https://en.wikipedia.org/wiki/Lazy_evaluation)
- Setacciamento (per esempio il [crivello di Eratostene](https://en.wikipedia.org/wiki/Sieve_of_Eratosthenes)
- Primalità tramite [divisione per tentativi](https://en.wikipedia.org/wiki/Trial_division)
