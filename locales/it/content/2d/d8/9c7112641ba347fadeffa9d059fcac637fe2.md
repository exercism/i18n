# Appendice alle istruzioni

## Implementazione

Definisci
`type Classification`
per contenere i valori di classificazione dei numeri naturali.
Puoi scegliere qualsiasi rappresentazione per questo tipo.

Definisci tre costanti Classification chiamate

```text
	ClassificationDeficient
	ClassificationPerfect
	ClassificationAbundant
```

Implementa una funzione chiamata Classify che accetta
un input di tipo int64 e restituisce una Classification e un valore di errore.

Crea un errore chiamato ErrOnlyPositive
che viene restituito quando l'input non è un numero intero positivo.
