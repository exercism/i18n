# Agenzia di web design

## Storia

La tua agenzia di design ha lavorato principalmente con le trasformazioni CSS per costruire pagine web. Dopo qualche discussione, avete deciso di iniziare a usare JavaScript per eseguire alcuni calcoli in modo dinamico. Alcuni dei tuoi colleghi hanno meno esperienza con JavaScript, così decidi di usare una closure per creare trasformazioni riutilizzabili per coppie di coordinate `{x, y}`.

## Attività

- Crea una funzione i cui argomenti sono usati come closure in una funzione restituita.

  - Una funzione per una traslazione 2D, dove la funzione esterna specifica di quanto traslare, e la funzione restituita accetta una coordinata x, y e restituisce le coordinate traslate.
  - Una funzione per una scalatura 2D, dove la funzione esterna specifica di quanto scalare, e la funzione restituita accetta una coordinata x, y e restituisce le coordinate traslate.
  - Una funzione che restituisce una funzione che ne compone due, di fatto una funzione per `g(f(x))`

- Crea una funzione che memoizza un'altra funzione.
