# Introduzione

## Charlist

Le charlist si creano usando il sigil `~c`.

```elixir
~c"hello"
```

~~~~exercism/note
Nota che nelle versioni più vecchie di Elixir le charlist sono rappresentate come `'hello'` con le virgolette singole.
~~~~

Anche se sembrano molto simili alle stringhe, questi due tipi di dati sono piuttosto diversi tra loro. Una charlist è un array di interi. Gli interi rappresentano i valori Unicode di un dato carattere, noti anche come punti di codice.

```elixir
[65, 66, 67]
# => ~c"ABC"
```

Puoi anteporre `?` a un carattere per ottenerne il punto di codice.

```elixir
?A
# => 65

[?:, ?)]
# => ~c":)"
```

Dato che le charlist sono array, puoi lavorarci proprio come con qualsiasi altro array, usando ricorsione e pattern matching.

```elixir
[first_letter | _] = ~c"cat"
first_letter
# => 99
```

Puoi concatenare due array usando `++`.

```elixir
~c"hi" ++ ~c"!"
# => ~c"hi!"
```

Più lungo è il primo array, più lenta è la concatenazione, quindi evita di aggiungere ripetutamente elementi in coda ad array di lunghezza arbitraria.

## Case

`case` è una struttura di controllo che ci permette di confrontare un dato valore con molti pattern. Le clausole di un'espressione `case` vengono valutate dall'alto verso il basso, finché non si trova una corrispondenza.

```elixir
age = 15

case age do
  0 -> ~c"infant"
  age when age < 4 -> ~c"baby"
  age when age < 13 -> ~c"child"
  age when age < 18 -> ~c"teenager"
  _ -> ~c"adult"
end

# => ~c"teenager"
```
