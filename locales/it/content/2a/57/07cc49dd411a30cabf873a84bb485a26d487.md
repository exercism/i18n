# Visibilità

Quando si usano le classi per organizzare il codice, la visibilità di proprietà, metodi e costanti può favorire astrazioni e responsabilità appropriate.
La visibilità di proprietà, metodi e costanti è definita dall'uso delle parole chiave `public`, `private` o `protected` al momento della loro dichiarazione.
La visibilità è sempre riferita a un uso esterno della proprietà, del metodo o della costante della classe.
Ovvero, se una proprietà è dichiarata `public`, è osservabile e utilizzabile dalle chiamate esterne.
Le proprietà, i metodi e le costanti `private` non sono osservabili né utilizzabili dalle chiamate esterne.

```php
<?php

class SecretDocument
{
    private $encryption_key;

    public $title;

    public function __construct($encryption_key, $title)
    {
        $this->encryption_key = $encryption_key;
        $this->title = $title;
    }
}

$document = new SecretDocument('secret_password', 'Secret Plans');
$title = $document->title; // => succeeds
$key = $document->encryption_key; // => fails
```

Le proprietà, i metodi e le costanti `protected` sono osservabili solo da se stesse e dalle classi figlie (tramite ereditarietà).

```php
<?php

class Shape
{
    protected $color = "blue";
}

class Square extends Shape
{
    public function getColor()
    {
        return $this->color;
    }
}

$square = new Square();
$color = $square->getColor(); // => succeeds
```
