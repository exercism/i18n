# Introduzione

I numeri in virgola mobile sono numeri con una o più cifre dopo il separatore decimale. Usano il formato a virgola mobile a doppia precisione a 64 bit.

```elixir
float = 3.45
# => 3.45
```

## Lavorare con i numeri

Nei moduli [`Integer`][integer-functions] e [`Float`][float-functions] puoi trovare alcune funzioni utili per lavorare con questi tipi. Gli operatori aritmetici di base sono definiti nel modulo [`Kernel`][kernel-arithmetic-operators].

## Conversione

I numeri interi e i numeri in virgola mobile possono essere combinati insieme in un'unica espressione aritmetica. Usare un numero in virgola mobile in un'espressione garantisce che anche il risultato sarà un numero in virgola mobile.

```elixir
2 * 3
# => 6

2 * 3.0
# => 6.0
```

Tuttavia, quando si esegue una divisione, il risultato sarà sempre un numero in virgola mobile, anche se si usano solo numeri interi.

```elixir
6 / 2
# => 3.0
```

Per convertire un numero in virgola mobile in un numero intero, puoi scartare la parte decimale con [`trunc/1`][trunc-1].
