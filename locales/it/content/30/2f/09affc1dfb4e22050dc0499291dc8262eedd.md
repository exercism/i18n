# Informazioni

`assocs` è un [protocollo][assoc-protocol], non un singolo tipo di dato. Le tabelle hash (`H{ }`), le liste di associazioni (sequenze di coppie `{ key value }`) e le mappe ad albero lo implementano tutte, e la maggior parte delle parole che operano sugli assoc è intercambiabile tra loro.

```factor
USING: assocs ;

H{ } clone "coal" over inc-at
"coal" over inc-at
"wood" over inc-at      ! => H{ { "coal" 2 } { "wood" 1 } }
```

La superficie completa è ampia, con iterazione ordinata, mappatura e filtraggio. Gran parte del lavoro a livello di esercizio, però, riguarda un piccolo insieme:

| parola      | effetto                                       |
|-------------|-----------------------------------------------|
| `at`        | `( key assoc -- value/f )`                    |
| `at*`       | `( key assoc -- value ? )` distingue f come valore da un valore mancante |
| `key?`      | `( key assoc -- ? )`                          |
| `set-at`    | `( value key assoc -- )`, muta                |
| `change-at` | `( key assoc quot -- )`, dove `quot` è `( old -- new )` |
| `inc-at`    | `( key assoc -- )`, `+1`, inserendo `1` se assente |
| `delete-at` | `( key assoc -- )`, muta                      |
| `>alist`    | `( assoc -- pairs )`                          |

`sort-keys` e `sort-values` (in `sorting`) ordinano un alist in base al campo scelto.

[assoc-protocol]: https://docs.factorcode.org/content/article-assocs-protocol.html
