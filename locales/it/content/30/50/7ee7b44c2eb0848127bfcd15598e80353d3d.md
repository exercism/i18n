# Appendice alle istruzioni

## Suggerimenti

Per completare questo esercizio devi implementare la funzione `score`, che prende una sequenza di *lanci* al bowling e restituisce il punteggio finale o l'errore appropriato:

```haskell
score :: [Int] -> Either BowlingError Int

data BowlingError = IncompleteGame
                  | InvalidRoll { rollIndex :: Int, rollValue :: Int }
                  deriving (Eq, Show)
```

Troverai queste definizioni già presenti, ma sta a te definire la funzione.

Tieni presente che la suite di test si aspetta che i lanci siano numerati a partire da zero.
