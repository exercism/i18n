# Test

Puoi eseguire i test forniti tramite DrRacket oppure dalla riga di comando.

Per eseguire i test tramite DrRacket, basta aprire il file di test e cliccare sul pulsante "Run" in alto a destra.

Per eseguire i test dalla riga di comando, basta eseguirli dalla cartella dell'esercizio. Ad esempio, se la suite di test si chiama `hello-world-test.rkt`, puoi eseguire il comando seguente:

```
raco test hello-world-test.rkt
```

che mostrerà quanto segue:

```
raco test: (submod "hello-world-test.rkt" test)
2 success(es) 0 failure(s) 0 error(s) 2 test(s) run
0
2 tests passed
```
