# Appendice alle istruzioni

## Formato del campo minato

Il campo minato è rappresentato come una stringa con terminatore nullo, con un carattere di nuova riga alla fine di ogni riga.

Un esempio è `"   \n * \n   \n"`

## Registri

| Registro | Uso          | Tipo    | Descrizione                   |
| -------- | ------------ | ------- | ----------------------------- |
| `$a0`    | input        | address | stringa di input con terminatore nullo  |
| `$a1`    | input/output | address | stringa di output con terminatore nullo |
| `$t0-9`  | temporaneo   | qualsiasi | per l'archiviazione temporanea         |
