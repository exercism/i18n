# Informazioni

Gli inizializzatori di oggetto sono un'alternativa ai costruttori. La sintassi è un elenco di coppie campo=valore separate da virgole, illustrato di seguito:

```csharp
public class Person
{
    public string Name;
    public string Address;
}

var person = new Person{Name="The President", Address = "Élysée Palace"};
```

Anche le collezioni possono essere inizializzate in questo modo. In genere, ciò si ottiene con elenchi separati da virgole, come mostrato qui:

```csharp
IList<Person> people = new List<Person>{ new Person(), new Person{Name="Joe Shmo"}};
```

Questo approccio (e questa sintassi) può essere usato con qualsiasi classe che implementa `IEnumerable` e ha un metodo `Add()`.

I campi possono essere elencati in qualsiasi ordine o omessi del tutto.

I dizionari usano la seguente sintassi:

```csharp
IDictionary<int, string> numbers = new Dictionary<int, string>{ [0] = "zero", [1] = "one"...};

// or

IDictionary<int, string> numbers = new Dictionary<int, string>{ {0, "zero" }, {1,  "one"}...};
```

I campi inizializzati devono essere accessibili al chiamante. In genere, questo significa che devono essere `public` o `internal`.

C'è una forte tendenza a promuovere l'immutabilità tra i progettisti del linguaggio e i principali professionisti, quindi la mutabilità degli oggetti inizializzati in questo modo è considerata uno svantaggio. Ci sono proposte per introdurre una clausola `init` nella prossima versione del linguaggio, C# 9, che potrebbe risolvere questo problema.

- La documentazione sugli [inizializzatori di oggetto][object-initializers] descrive come usarli.
- La documentazione sugli [inizializzatori di collezione][collection-initializers] offre un'anteprima di come gli inizializzatori possono essere usati con collezioni come dizionari e array.
