# Installazione

## Note sulla versione di Perl
Il track si rivolge all'ultima versione stabile di Perl.
È possibile usare versioni più vecchie di Perl, ma potrebbe essere necessario adattare i file stub forniti per garantirne la compatibilità.
Se non puoi usare la versione specificata nei file stub, ti consigliamo di sostituire `use v5.XX;` con il seguente codice:

```perl
use strict;
use warnings;
use feature qw<signatures>;
```

Se il file stub contiene `use experimental qw<class>;` e la versione di Perl che stai usando non lo supporta, puoi sostituirlo con `use Feature::Compat::Class;` oppure usare un sistema alternativo di programmazione orientata agli oggetti, ad esempio [Moo](https://metacpan.org/pod/Moo).

## Unix/Linux/Mac OSX
Probabilmente Perl è già installato, ma è possibile che non sia l'ultima versione.
Esegui `perl -v` per controllare quale versione hai.
Se vuoi usare una versione più recente, dai un'occhiata alla sezione "Altre opzioni".

Se usi Fedora/Red Hat/CentOS, alcuni moduli principali non sono inclusi con Perl.
Usa il comando `yum install perl-core` per installarli.

## Windows
[Strawberry Perl](http://strawberryperl.com/): un Perl per Windows completamente open source, identico al Perl di ogni altra piattaforma;
questo include l'uso dei moduli di CPAN, senza bisogno di pacchetti binari.

Puoi installarlo direttamente dal sito oppure usare il [gestore di pacchetti chocolatey](https://chocolatey.org/packages/StrawberryPerl).

## Altre opzioni
* [asdf](https://asdf-vm.com/):
  un gestore di versioni di strumenti che permette di installare più linguaggi, incluso Perl, disponibile come [plugin della community](https://github.com/asdf-vm/asdf-plugins).
* [perlbrew](https://perlbrew.pl/):
  uno strumento per gestire più installazioni di Perl nella tua directory `$HOME`.
  Sono universi Perl completamente isolati.
* [plenv](https://github.com/tokuhirom/plenv):
  installa i Perl nella tua home directory, ti permette di installare i moduli localmente e di passare a qualsiasi versione di Perl nella tua shell.
* [ActivePerl Community Edition](https://www.activestate.com/activeperl/downloads):
  una distribuzione Perl gratuita e pronta all'installazione per Windows, Linux e Mac OS X, pensata per sviluppatori della community o per progetti open source che non siano critici per il business o per la missione.

### Installare i moduli necessari
Se usi una versione di Perl precedente alla 5.40, dovrai installare il bundle di test `Test2::V0`.
Dovrai anche installare `Feature::Compat::Class` oppure un sistema alternativo di programmazione orientata agli oggetti per gli esercizi di programmazione orientata agli oggetti.
Segui le istruzioni seguenti per configurarlo (oppure usa pure il tuo installer di moduli preferito, se hai già familiarità con Perl):

#### local::lib
* Assicurati che la CLI di exercism sia già installata e configurata.
Eseguire `exercism workspace` dovrebbe mostrarti il percorso corretto.

* Scarica l'installer di moduli `cpm` e usalo per installare se stesso,
`local::lib`, `Test2::V0` e `Feature::Compat::Class` nella tua directory `exercism/perl5`:
```
# *nix
curl -sL --compressed https://git.io/cpm | \
  perl - install -L $(exercism workspace)/perl5 App::cpm local::lib Test2::V0 Feature::Compat::Class

# Microsoft PowerShell
(Invoke-WebRequest -UseBasicParsing 'https://git.io/cpm').Content |
  perl - install -L "$(exercism workspace)/perl5" App::cpm local::lib Test2::V0 Feature::Compat::Class
```

* Esegui `local::lib` per configurare il tuo ambiente in modo che usi i moduli che hai
installato in `exercism/perl5`:
```
# *nix
eval $(perl -I$(exercism workspace)/perl5/lib/perl5 -Mlocal::lib=$(exercism workspace)/perl5)

# Microsoft PowerShell
perl -I"$(exercism workspace)/perl5/lib/perl5"
  -M"local::lib=--shelltype=powershell,$(exercism workspace)/perl5" | Invoke-Expression
```

Le modifiche all'ambiente prodotte dal comando qui sopra non sono permanenti e andranno rieseguite se riavvii la shell.
Se vuoi che il tuo ambiente venga configurato automaticamente ogni volta, modifica il tuo `.bashrc` (o l'equivalente su \*nix) oppure il tuo `PowerShell_profile.ps1` in modo che includa il comando qui sopra.

La documentazione di local::lib si trova [qui](https://perldoc.perl.org/local::lib).

#### Pacchetti del sistema operativo
In alternativa, il gestore di pacchetti del tuo sistema operativo potrebbe avere un pacchetto Test2 Suite pronto da installare.
Tra le opzioni disponibili:

* Ubuntu: [libtest2-suite-perl](https://launchpad.net/ubuntu/+source/libtest2-suite-perl)
* Debian: [libtest2-suite-perl (via backports)](https://packages.debian.org/stretch-backports/libtest2-suite-perl)
* Arch: [perl-test2-suite](https://www.archlinux.org/packages/community/any/perl-test2-suite/)
