# Introduzione

In Clojure, associare un valore a un nome si chiama _var_. Le var di primo livello (globali) sono simili alle costanti di altri linguaggi, ma vengono spesso ridefinite per facilitare lo sviluppo dinamico.

Le var di primo livello si definiscono con `def`:

```clojure
(def fingers 10)
```

La macro `defn` si può usare per definire una funzione che accetta zero o più argomenti. Una funzione restituisce sempre il risultato dell'ultima espressione nel suo corpo.

```clojure
(defn add [x y]
  (+ x y))
```

Per chiamare una funzione basta indicarne il nome e passare un argomento per ciascuno dei suoi parametri.

```clojure
(def five (add 2 3))
```

In Clojure le funzioni e i valori si possono usare solo _dopo_ che sono stati definiti. Usarli prima che siano stati definiti provoca un errore di compilazione.

```clojure
;; Compile error as `add` has not yet been defined
(def seven (add 3 4))

(defn add [x y]
  (+ x y))
```

In Clojure gli spazi bianchi non hanno alcun significato, se non quello di formattazione.

Le funzioni e le var di Clojure sono organizzate in namespace. Un namespace raggruppa funzionalità correlate e si definisce con la macro `ns`:

```clojure
(ns calculator)

(def pi 3.14)

(defn add [x y]
  (+ x y))
```

Clojure supporta due tipi di commenti. I commenti su una sola riga sono preceduti da `;`, mentre la forma `comment` serve a impedire la valutazione di tutto ciò che si trova tra `(comment` e `)`.
