# Istruzioni

In questo esercizio lavorerai a un sistema di pianificazione degli appuntamenti per un salone di bellezza a New York che ha aperto il 15 settembre 2012.

Hai cinque attività, che avranno tutte a che fare con le date degli appuntamenti.
Gli orari sono in formato 24 ore (niente AM/PM).

## 1. Analizza la data dell'appuntamento composta da soli numeri

Implementa la funzione `schedule_appointment()` per analizzare una rappresentazione testuale della data di un appuntamento e convertirla nel formato `DateTime` corrispondente.

Nota che l'input segue l'ordine mese/giorno/anno in stile statunitense.

```julia-repl
julia> schedule_appointment("07/25/2023 13:45:00")
2023-07-25T13:45:00
```

## 2. Controlla se un appuntamento è già passato

Implementa la funzione `has_passed()` che prende una data di appuntamento e controlla se l'appuntamento si trova nel passato:

```julia-repl
julia> has_passed(DateTime(1999, 12, 31, 9, 0, 0))
true
```

## 3. Controlla se l'appuntamento è nel pomeriggio

Implementa la funzione `is_afternoon_appointment()` che prende una data di appuntamento e controlla se l'appuntamento è nel pomeriggio (>= 12:00 e < 18:00):

```julia-repl
julia> is_afternoon_appointment(DateTime(2023, 3, 29, 15, 0, 0))
true
```

## 4. Descrivi l'ora e la data dell'appuntamento

Implementa la funzione `description()` che prende una data di appuntamento e restituisce una descrizione di quella data e ora:

```julia-repl
julia> describe(DateTime(2023, 3, 29, 15, 0, 0))
"You have an appointment on Wednesday, March 29, 2023 at 15:00"
```

## 5. Restituisci la data dell'anniversario

Implementa la funzione `anniversary_date()` che restituisce la data dell'anniversario di quest'anno, cioè il 15 settembre:

```julia-repl
julia> anniversary_date()  # run during 2025
2025-09-15
```
