## Generale

- Per definire una stringa puoi usare le virgolette doppie `"`.
- Per concatenare le stringhe puoi usare l'operatore `+`.
- Puoi usare `#{}` per interpolare una stringa.

## 1. Dai il benvenuto a un nuovo ospite alla festa

- Una stringa può essere concatenata a un'altra stringa usando l'operatore `+`.

## 2. Dai il benvenuto a un nuovo ospite il cui compleanno è oggi

- Per convertire un numero in una stringa puoi usare il metodo `to_s`.

## 3. Dai le indicazioni

- Per arrotondare un numero puoi usare il metodo `round`.
- Per ottenere un carattere in una stringa puoi usare il metodo `[]`, che accetta un numero intero che è un indice.
