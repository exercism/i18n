# Descrizione

Le funzioni possono dichiarare dei [valori predefiniti][default-arguments] per uno o più argomenti.

```elixir
def number(n \\ 13), do: "That's not my favorite"
```

- Quando compila l'esempio qui sopra, Elixir crea una definizione di funzione per `number/0` (nessun argomento) e per `number/1` (un argomento).
- Se più di un argomento ha un valore predefinito, i valori predefiniti vengono applicati alla funzione da sinistra a destra per coprire gli argomenti mancanti.
- Se la funzione ha più clausole, è necessario scrivere un'[intestazione di funzione][function-header] per i valori predefiniti.
- Qualsiasi espressione può essere usata come valore predefinito.
- Le funzioni anonime non possono avere argomenti con valori predefiniti.

```elixir
def guess(number \\ 5)
def guess(number) when number != 5, do: false
def guess(number) when number == 5, do: true

guess()
# => true
```
