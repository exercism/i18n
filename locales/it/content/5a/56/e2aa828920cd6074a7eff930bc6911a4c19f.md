# Istruzioni

Mary è una grande fan della serie TV _Star Trek: The Next Generation_. Spesso gioca a giochi di ruolo con carta e penna, in cui lei e i suoi amici fingono di essere l'equipaggio della _Starship Enterprise_. Il personaggio di Mary è il Capitano Picard, il che significa che deve tenere il diario del capitano. Ama la parte creativa del gioco, ma non sopporta di dover generare dati casuali sul momento.

Aiuta Mary creando dei generatori casuali per i dati che compaiono più spesso nel diario del capitano.

## 1. Genera un pianeta casuale

La _Starship Enterprise_ incontra molti pianeti nei suoi viaggi. I pianeti dell'universo di Star Trek sono divisi in categorie in base alle loro proprietà. Per esempio, la Terra è un pianeta di classe M. Tutte le classi planetarie possibili sono: D, H, J, K, L, M, N, R, T e Y.

Implementa la funzione `random_planet_class/0`. Dovrebbe restituire una delle classi planetarie a caso.

```elixir
CaptainsLog.random_planet_class()
# => "K"
```

## 2. Genera un numero di registrazione casuale per un'astronave

L'Enterprise (numero di registrazione NCC-1701) non è l'unica astronave in circolazione! Quando si incontra con un'altra astronave, Mary deve registrare nel diario il numero di registrazione di quell'astronave.

I numeri di registrazione iniziano con il prefisso "NCC-" e poi usano un numero da 1000 a 9999 (inclusi).

Implementa la funzione `random_ship_registry_number/0` che restituisce un numero di registrazione di un'astronave a caso.

```elixir
CaptainsLog.random_ship_registry_number()
# => "NCC-1947"
```

## 3. Genera una data stellare casuale

A cosa serve un diario se non include le date?

Una data stellare è un numero in virgola mobile. Le avventure della _Starship Enterprise_ della prima stagione di _The Next Generation_ si svolgono tra le date stellari 41000.0 e 42000.0. Il «4» sta per il XXIV secolo, il «1» per la prima stagione.

Implementa la funzione `random_stardate/0` che restituisce un numero in virgola mobile tra 41000.0 (incluso) e 42000.0 (escluso).

L'implementazione dovrebbe usare una funzione Erlang.

```elixir
CaptainsLog.random_stardate()
# => 41458.15721310934
```

## 4. Formatta la data stellare

Nel diario del capitano, le date stellari vengono di solito arrotondate a una sola cifra decimale.

Implementa la funzione `format_stardate/1` che prende un numero in virgola mobile e restituisce una stringa con il numero arrotondato a una sola cifra decimale.

L'implementazione dovrebbe usare una funzione Erlang.

```elixir
CaptainsLog.format_stardate(41458.15721310934)
# => "41458.2"
```
