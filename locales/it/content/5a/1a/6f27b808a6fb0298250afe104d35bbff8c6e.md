# Clonare la track ABAP

## Prerequisiti

1. Sistema ABAP versione 7.4 o superiore
2. abapGit v1.115.0 o superiore
3. Autorizzazioni per implementare pacchetti, programmi e classi ABAP

## Installare abapGit

La track ABAP con tutti gli esercizi è implementata come repository abapGit. Per clonare la track sul tuo sistema, devi prima installare abapGit.

1. Vai su [https://github.com/abapGit/abapGit](https://github.com/abapGit/abapGit)
2. Scarica il file `zabapgit_standalone.prog.abap`
3. Crea il programma `zabapgit_standalone` nel tuo sistema
4. Carica il codice sorgente da `zabapgit_standalone.prog.abap` nel programma `zabapgit_standalone`
5. Attiva il programma

## Installare la track ABAP di Exercism

### Repository online

Usa questo metodo se il tuo sistema è connesso a Internet e ha accesso a GitHub.com (approccio consigliato).

1. Avvia abapGit

![Repository online di abapGit](https://github.com/exercism/abap/blob/main/docs/clone_01.png?raw=true)

2. Nella "Repository Overview", seleziona "New Online"
3. Inserisci i seguenti valori
- URL: `https://github.com/exercism/abap`
- Package: `$exer`
- Display Name: `Exercism - ABAP Track`

Nota: se il nome del pacchetto è troppo lungo, come `$exercism`, riceverai un errore quando provi a importare il repository. Mantieni il nome corto come indicato sopra.

![Repository online di abapGit](https://github.com/exercism/abap/blob/main/docs/clone_02.png?raw=true)

4. Seleziona "Create Online Repository". Dovresti vedere un elenco di oggetti con stato "A":

![Repository online di abapGit](https://github.com/exercism/abap/blob/main/docs/clone_03.png?raw=true)

5. Seleziona "Pull" per clonare tutti gli oggetti sul tuo sistema. Al termine, dovresti vedere tutti gli oggetti con lo stato vuoto

![Repository online di abapGit](https://github.com/exercism/abap/blob/main/docs/clone_04.png?raw=true)

### Repository offline

Usa questo metodo se il tuo sistema *non* è connesso a Internet.

1. Vai su [https://github.com/exercism/abap](https://github.com/exercism/abap)
2. Scarica il file ZIP del repository

![Repository offline di abapGit](https://github.com/exercism/abap/blob/main/docs/clone_10.png?raw=true)

3. Avvia abapGit
4. Nella "Repository Overview", seleziona "New Offline"
5. Inserisci i seguenti valori
- Repository Name: `Exercism - ABAP Track`
- Package: `$exer`

![Repository offline di abapGit](https://github.com/exercism/abap/blob/main/docs/clone_11.png?raw=true)

6. Seleziona "Create Offline Repository"

![Repository offline di abapGit](https://github.com/exercism/abap/blob/main/docs/clone_12.png?raw=true)

7. Seleziona "Import ZIP" e scegli il file ZIP scaricato. Dovresti vedere un elenco di oggetti con stato "A":

![Repository offline di abapGit](https://github.com/exercism/abap/blob/main/docs/clone_13.png?raw=true)

8. Seleziona "Pull ZIP" per clonare tutti gli oggetti sul tuo sistema. Al termine, dovresti vedere tutti gli oggetti con lo stato vuoto

![Repository offline di abapGit](https://github.com/exercism/abap/blob/main/docs/clone_14.png?raw=true)

## Disinstallare la track ABAP di Exercism

Puoi rimuovere tutti gli oggetti dal tuo sistema in questo modo:

1. Avvia abapGit
2. Vai al repository `Execism - ABAP Track`
3. Seleziona "Advanced > Uninstall"
4. Conferma l'eliminazione di tutti gli oggetti e del repository

## Risoluzione dei problemi

- In caso di problemi di connessione, controlla [SSL Setup](https://docs.abapgit.org/user-guide/setup/ssl-setup.html)
- In caso di errore `Package $EXERCISM_DIFFERENCE-OF-SQUARES exceeds ABAP 30-characters name limit`, usa un nome di pacchetto più corto come `$exer`.
- Alcuni file mostreranno delle differenze dopo il pull nel tuo sistema ABAP. Le differenze legate ai caratteri di fine file o ai byte-order-mark possono essere ignorate.
