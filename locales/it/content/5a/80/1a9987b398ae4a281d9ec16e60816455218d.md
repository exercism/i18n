# Introduzione

Elixir mette a disposizione molte funzioni per lavorare con i bit, presenti nel _modulo Bitwise_.

- `band/2`: AND bit a bit
- `bsl/2`: scorrimento a sinistra bit a bit
- `bsr/2`: scorrimento a destra bit a bit
- `bxor/2`: XOR bit a bit
- `bor/2`: OR bit a bit
- `bnot/1`: NOT bit a bit

Ecco un esempio di come usare una funzione bit a bit:

```elixir
Bitwise.bsl(1, 3)
# => 8
```

Tutte le funzioni bit a bit funzionano solo su numeri interi.

Se usi Elixir versione 1.9 o precedente, dovrai chiamare `require Bitwise` all'inizio della definizione del modulo per poter usare il modulo _Bitwise_.
