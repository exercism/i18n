# Informazioni

Le funzioni per lavorare con i file sono fornite dal modulo [`File`][file].

Per leggere un intero file, usa [`File.read/1`][file-read]. Per scrivere su un file, usa [`File.write/2`][file-write].

Il modulo fornisce anche funzioni per copiare, rimuovere, rinominare i file e così via. I loro nomi sono simili a quelli delle equivalenti UNIX, per esempio:

- [`File.cp/3`][file-cp]: copia un file.
- [`File.rm/1`][file-rm]: elimina un file.
- [`File.rename/2`][file-rename]: rinomina e/o sposta un file.
- [`File.mkdir/1`][file-mkdir]: crea una directory.
- [`File.cwd/0`][file-cwd]: ottieni la directory di lavoro corrente.

Tutte le funzioni menzionate del modulo `File` hanno anche una variante con `!` che solleva un errore invece di restituire una tupla di errore (ad esempio [`File.read!/1`][file-read-bang]). Usa quella variante se non hai intenzione di gestire errori come file mancanti o permessi insufficienti.

```elixir
File.read("does_not_exist")
# => {:error, :enoent}

File.read!("does_not_exist")
# => ** (File.Error) could not read file "does_not_exist": no such file or directory
#        (elixir 1.10.4) lib/file.ex:353: File.read!/1
```

## File e processi

Ogni volta che si scrive su un file con [`File.write/2`][file-write], viene aperto un descrittore di file e viene generato un nuovo [processo][exercism-processes] Elixir. Per questo motivo, conviene evitare di scrivere su un file in un ciclo usando [`File.write/2`][file-write].

Invece, un file può essere aperto usando [`File.open/2`][file-open]. Il secondo argomento di [`File.open/2`][file-open] è un array di modalità, che ti permette di specificare se vuoi aprire il file in lettura o in scrittura.

Le modalità più usate sono:

- `:read`: apre in lettura, il file deve esistere
- `:write`: apre in scrittura, il file viene creato se non esiste, il contenuto esistente viene sovrascritto
- `:append`: apre in scrittura, il file viene creato se non esiste, il contenuto esistente viene conservato

Per conoscere tutte le modalità disponibili, consulta la documentazione di [`File.open/2`][file-open].

[`File.open/2`][file-open] restituisce il PID di un processo che gestisce il file. Per leggere e scrivere sul file, usa le funzioni del modulo [`IO`][io] e passa questo PID come [dispositivo IO][io-io-devices].

Quando hai finito di lavorare con il file, chiudilo con [`File.close/1`][file-close].

```elixir
file = File.open!("README.txt", [:write])
# => #PID<0.157.0>

IO.puts(file, "# README")
# => :ok

File.close(file)
# => :ok
```

## Streaming dei file

Leggere un file con [`File.read/1`][file-read] carica l'intero file in memoria tutto in una volta. Questo può essere un problema quando si lavora con file davvero grandi. Per gestirli in modo efficiente, puoi usare [`File.open/2`][file-open] e [`IO.read/2`][io-read] per leggere il file riga per riga, oppure puoi ricorrere allo streaming con [`File.stream/3`][file-stream]. Lo stream implementa sia il protocollo [`Enumerable`][enumerable] sia il [`Collectable`][collectable], quindi può essere usato sia per leggere sia per scrivere.

```elixir
File.stream!("file.txt")
|> Stream.map(&(&1 <> "!"))
|> Stream.into(File.stream!("new_file.txt"))
|> Stream.run()
```

## Percorsi

Tutte le funzioni che lavorano sui file richiedono un percorso di file. I percorsi possono essere assoluti o relativi alla directory corrente. Per manipolare i percorsi, usa le funzioni del modulo [`Path`][path]. Per garantire la compatibilità tra piattaforme, usa [`Path.join/1`][path-join] per costruire i percorsi: sceglierà il separatore adatto alla piattaforma.

```elixir
Path.expand(Path.join(["~", "documents", "important.txt"]))
"/home/user/documents/important.txt"
```
