# Istruzioni specifiche per SQLite

* La colonna **digits** contiene una lista di numeri interi codificata in JSON.
  Esempio:
  ```json
  [1,0,1,0,1,0]
  ```
* La colonna **result** dovrebbe contenere dati codificati in JSON: un oggetto con le cifre come numeri interi oppure una descrizione degli eventuali errori.
  Esempi:
  ```json
  {"digits":[1,0,1,0,1,0]}
  ```
  oppure
  ```json
  {"error":"some error description"}
  ```

## Schema della tabella

```sql
CREATE TABLE IF NOT EXISTS "all-your-base" (
  input_base  INTEGER NOT NULL,
  digits      TEXT    NOT NULL, -- json array
  output_base INTEGER NOT NULL,
  result      TEXT              -- json object
);
```
