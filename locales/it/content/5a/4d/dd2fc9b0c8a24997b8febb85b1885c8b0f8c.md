# Introduzione

Un blocco è un insieme di istruzioni e dichiarazioni raggruppate in un'unica unità sintattica.
I blocchi sono spesso, ma non sempre, definiti all'interno di parentesi graffe.
I blocchi possono essere annidati all'interno di funzioni e all'interno di altri blocchi.

Una funzione si comporta in modo simile a un blocco.
Un identificatore di una variabile definita in una funzione non può essere visto all'esterno della funzione, proprio come un identificatore di una variabile definita in un blocco non può essere visto all'esterno del blocco.
Due variabili in due funzioni possono avere lo stesso nome, dato che le due funzioni non si vedono a vicenda, proprio come due variabili in due blocchi possono avere lo stesso nome, dato che i due blocchi non si vedono a vicenda.
Ma funzioni e blocchi non sono identici.
Una funzione non può essere annidata all'interno di un'altra funzione, ma un blocco può essere annidato all'interno di un altro blocco.

Nell'esempio seguente, `number` è definito all'interno della funzione `main`.
`flag` è definito all'interno del blocco `if`, che è annidato all'interno della funzione `main`.
Le variabili definite all'interno di un blocco sono valide solo all'interno di quel blocco.
Quindi, provare a compilare il codice produce un errore di compilazione.

```c
#include <stdio.h>

int main() {

  int number = 1;

  if (number == 1) {
      int flag = 1;
      printf("%d", flag);
  }

  // this line generates a compilation error
  // error: 'flag' undeclared (first use in this function)
  printf("%d", flag);
    
}
```

Il messaggio di errore può confondere, dato che `flag` _viene_ usato prima nella funzione.
Tuttavia, `flag` è definito all'interno di un blocco dentro la funzione.
Il blocco interno può «vedere» la variabile `number` nella sua funzione esterna, ma la funzione esterna non può «vedere» la variabile `flag` definita all'interno del suo blocco interno.
Una volta che l'esecuzione esce dal blocco, la variabile `flag` viene distrutta automaticamente e non è più disponibile per il programma.
La funzione `main` stessa vede l'identificatore `flag` per la prima volta nell'ultima istruzione `printf`.
Se l'ultima istruzione `printf` viene rimossa, il programma verrà compilato e stamperà `1` quando viene eseguito.
Questo perché la variabile `flag` è valida nel blocco che contiene la prima istruzione `printf`.

A partire da `C99`, anche le istruzioni `if`, `for`, `while` e `do` su una sola riga sono considerate blocchi.
Nell'esempio seguente, anche se `i` non è definito all'interno di parentesi graffe, esiste solo nel blocco definito dall'istruzione `for` e non è visibile alla funzione `main` esterna.

```c
#include <stdio.h>

int main() {

    for (int i = 0, j = 11; i < j; i+=2)
        printf("%d", i);

    // this line generates a compilation error
    // error: 'i' undeclared (first use in this function)
    printf("%d", i);
    
}
```

Se l'ultima istruzione `printf` viene rimossa, il programma verrà compilato e stamperà `0 2 4 6 8 10 ` quando viene eseguito.
Alcuni linguaggi, come Go e Rust, stabiliscono esplicitamente che le istruzioni condizionali e quelle di ciclo su una sola riga costituiscono un blocco.
Richiedono che tali istruzioni su una sola riga siano comunque racchiuse tra parentesi graffe.
