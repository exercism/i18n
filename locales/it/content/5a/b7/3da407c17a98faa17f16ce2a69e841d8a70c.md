# Char

`Char` è un tipo di dato in Crystal che rappresenta un punto di codice [Unicode][unicode] a 32 bit.
Le loro dimensioni li rendono efficienti in termini di memoria e conferiscono loro proprietà specifiche che le stringhe non hanno.
Si creano usando virgolette singole (`'`) e consentono di inserirvi un solo punto di codice Unicode.

```crystal
'a' # => 'a'
'a'.class # => Char
```

È abbastanza comune lavorare con i Char quando si lavora con le stringhe in Crystal, dato che parecchi metodi della classe String restituiscono Char o accettano Char come argomenti.
Per esempio, il metodo [`String#[]`][index] restituisce un Char, oppure il metodo [`String#chars`][chars] restituisce una collezione di Char.

## Incremento / decremento

Poiché un Char è un punto Unicode a 32 bit, supporta l'incremento e il decremento: questo fa sì che, se hai `'a'`, puoi ottenere `'b'` aggiungendo uno.

```crystal
'a' + 5
# => 'f'

'z' - 25
# => 'a'
```

Esiste anche un metodo chiamato [`Char#succ`][succ], che restituisce il Char successivo nella tabella Unicode, e [`Char#pred`][pred], che restituisce il Char precedente nella tabella Unicode.

```crystal
'a'.succ
# => 'b'

'z'.pred
# => 'y'
```

## Concatenazione

Poiché un Char serve solo a rappresentare un punto Unicode a 32 bit, due Char non si possono concatenare.
Di conseguenza, i Char si possono concatenare solo con le stringhe.

```Crystal
'a' + "bc"
# => "abc"

'a' + 'b'
# => error: expected argument #1 to 'Char#+' to be Int or String, not Char
```

## Metodi delle proprietà

Crystal ha alcuni metodi per ottenere informazioni su un carattere, come ad esempio se è un numero o una lettera, oppure se è maiuscolo o minuscolo.
Ecco un elenco di alcuni metodi; per un elenco completo, consulta la [Char API][char-api]:

| Metodo                           | Descrizione                                          |
| -------------------------------- | ---------------------------------------------------- |
| [`Char#number?`][number]         | Restituisce `true` se il Char è un numero            |
| [`Char#letter?`][letter]         | Restituisce `true` se il Char è una lettera          |
| [`Char#lowercase?`][lowercase]   | Restituisce `true` se il Char è minuscolo            |
| [`Char#uppercase?`][uppercase]   | Restituisce `true` se il Char è maiuscolo            |
| [`Char#ascii?`][ascii]           | Restituisce `true` se il Char è un carattere ASCII   |
| [`Char#whitespace?`][whitespace] | Restituisce `true` se il Char è un carattere di spazio |

## Conversione

### Conversione tra punti di codice e Char

Poiché un Char è un punto Unicode a 32 bit, puoi convertire tra Char e punti di codice (Int).
Questo si può fare usando il metodo [`Char#ord`][ord], che restituisce il punto di codice del Char, oppure il metodo [`Int#chr`][chr], che restituisce il Char corrispondente al punto di codice.

```crystal
'a'.ord
# => 97

97.chr
# => 'a'
```

### Conversione tra tipi

Come per gli altri tipi di dato, anche i Char hanno alcuni metodi per convertire tra tipi.
Il più comune è il metodo `Char#to_s`, che converte il Char in una stringa. Tuttavia esiste anche il metodo `Char#to_i`, che converte il Char in un Int, e il metodo `Char#to_f`, che converte il Char in un Float.

```crystal
'a'.to_s
# => "a"

'4'.to_i
# => 4

'a'.to_i
# => Error: Invalid integer: a (ArgumentError)
```

## Sequenze di escape

Come per le stringhe, ci sono alcuni caratteri che non si possono scrivere direttamente e, per scriverli, devi usare una sequenza di escape.
Puoi usare il carattere `\` per scrivere una sequenza di escape seguita dal carattere che vuoi rappresentare.

Questi sono i caratteri speciali in Crystal:

| Valore   | Descrizione                   |
| -------- | ----------------------------- |
| `\a`     | Avviso                        |
| `\b`     | Backspace                     |
| `\e`     | Escape                        |
| `\f`     | Avanzamento modulo            |
| `\n`     | Avanzamento riga o nuova riga |
| `\r`     | Ritorno carrello              |
| `\t`     | Tabulazione orizzontale       |
| `\v`     | Tabulazione verticale         |
| `\\`     | Barra rovesciata              |
| `\'`     | Virgoletta singola            |
| `\"`     | Virgoletta doppia             |
| `\377`   | Carattere ASCII ottale        |
| `\xFF`   | Carattere ASCII esadecimale   |
| `\uFFFF` | Carattere Unicode esadecimale |
