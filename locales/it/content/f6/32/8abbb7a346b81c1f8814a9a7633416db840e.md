# Appendice alle istruzioni

## Aggiungere metodi alla classe Array

Questo esercizio si concentra sull'aggiunta di metodi alla classe `Array` in Crystal.
Per farlo, dovrai definire una classe con il nome `Array(T)` e inserire i metodi al suo interno.

```crystal
class Array(T)
  # your solution here
end
```

La classe Array è una classe [generica][generic], ed è anche [indicizzabile][indexable] e [enumerabile][enumerable].
Il codice sorgente della classe `Array` si trova [qui][array].

[array]: https://github.com/crystal-lang/crystal/blob/7aa5cdd86/src/array.cr#L48
[generic]: https://crystal-lang.org/docs/syntax_and_semantics/generics.html
[indexable]: https://crystal-lang.org/api/Indexable.html
[enumerable]: https://crystal-lang.org/api/Enumerable.html
