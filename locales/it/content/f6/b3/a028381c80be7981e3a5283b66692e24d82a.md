# Suggerimenti

## Generali

- Gli indici di `Vector` partono da `1`.
- I mazzi di carte non contengono carte duplicate.

## 1. Stabilire se una carta è presente

- In Base c'è un metodo [`in`/`∈`](https://docs.julialang.org/en/v1/base/collections/#Base.in) per stabilire se una collezione contiene un valore.

## 2. Trovare la posizione di una carta

- In Base c'è un metodo [`findfirst`](https://docs.julialang.org/en/v1/base/arrays/#Base.findfirst-Tuple{Function,%20Any}) per trovare la posizione del primo elemento di una collezione che soddisfa un dato predicato.
- `==(x)` può essere usato come predicato per trovare gli elementi uguali a `x` nei metodi che accettano funzioni predicato.

## 3. Stabilire se ogni carta è pari

- In Base c'è un metodo [`all`](https://docs.julialang.org/en/v1/base/collections/#Base.all-Tuple{AbstractArray,%20Any}) che restituisce `true` se tutti gli elementi di una collezione soddisfano un dato predicato.
- [`iseven`](https://docs.julialang.org/en/v1/base/numbers/#Base.iseven) è una funzione predicato.

## 4. Verificare se il mazzo contiene una carta di valore dispari

- In Base c'è un metodo [`any`](https://docs.julialang.org/en/v1/base/collections/#Base.any-Tuple{AbstractArray,%20Any}) che restituisce `true` se almeno un elemento di una collezione soddisfa un dato predicato.
- [`isodd`](https://docs.julialang.org/en/v1/base/numbers/#Base.isodd) è una funzione predicato.

## 5. Stabilire la posizione della prima carta pari

- In Base c'è un metodo [`findfirst`](https://docs.julialang.org/en/v1/base/arrays/#Base.findfirst-Tuple{Function,%20Any}) per trovare la posizione del primo elemento di una collezione che soddisfa un dato predicato.
- [`iseven`](https://docs.julialang.org/en/v1/base/numbers/#Base.iseven) è una funzione predicato.

## 6. Ottenere la prima carta dispari dal mazzo

- Puoi recuperare l'`n`-esimo valore di un array `v` con `v[n]`.
- In Base c'è un metodo [`findfirst`](https://docs.julialang.org/en/v1/base/arrays/#Base.findfirst-Tuple{Function,%20Any}) per trovare la posizione del primo elemento di una collezione che soddisfa un dato predicato.
- Se nessun elemento della collezione data soddisfa il predicato passato a `findfirst`, `findfirst` restituisce `nothing`.
- Ripassa come funziona `nothing` in Julia: [concept:julia/nothingness](../../../../concepts/nothingness/about.md)
- Ripassa come funzionano i condizionali in Julia: [concept:julia/conditionals](../../../../concepts/conditionals/about.md)
