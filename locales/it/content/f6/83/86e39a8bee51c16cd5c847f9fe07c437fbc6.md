# Introduzione

## Numeri

Molti linguaggi di programmazione hanno tipi numerici specifici per rappresentare diversi tipi di numeri, ma JavaScript ne ha solo due:

- `number`: un tipo di dato numerico nel formato in virgola mobile a 64 bit a doppia precisione (IEEE 754).
  Alcuni esempi sono `-6`, `-2.4`, `0`, `0.1`, `1`, `3.14`, `16.984025`, `25`, `976`, `1024.0` e `500000`.
- `bigint`: un tipo di dato numerico che può rappresentare i _numeri interi_ nel formato a precisione arbitraria.
  Alcuni esempi sono `-12n`, `0n`, `4n` e `9007199254740991n`.

Se hai bisogno di precisione arbitraria o lavori con numeri estremamente grandi, usa il tipo `bigint`.
Altrimenti, il tipo `number` è probabilmente l'opzione migliore.

### Arrotondamento

Esiste un oggetto globale integrato chiamato `Math` che fornisce varie [funzioni di arrotondamento][ref-math-object-rounding].
Ad esempio, puoi arrotondare per difetto (`floor`) o per eccesso (`ceil`) i numeri decimali al numero intero più vicino.

```javascript
Math.floor(234.34); // => 234
Math.ceil(234.34); // => 235
```

## Operatori aritmetici

JavaScript fornisce 6 operatori diversi per eseguire operazioni aritmetiche di base sui numeri.

- `+`: l'operatore di addizione serve a calcolare la somma di numeri.
- `-`: l'operatore di sottrazione serve a calcolare la differenza tra due numeri
- `*`: l'operatore di moltiplicazione serve a calcolare il prodotto di due numeri.
- `/`: l'operatore di divisione serve a dividere due numeri.

```javascript
2 - 1.5; //=> 0.5
19 / 2; //=> 9.5
```

- `%`: l'operatore modulo serve a calcolare il resto di una divisione.

  ```javascript
  40 % 4; // => 0
  -11 % 4; // => -3
  ```

- `**`: l'operatore di esponenziazione serve a elevare un numero a una potenza.

  ```javascript
  4 ** 3; // => 64
  4 ** 1 / 2; // => 2
  ```

### Ordine delle operazioni

Quando usi più operatori su una riga, JavaScript segue un ordine di precedenza, come mostrato in [questa tabella di precedenza][mdn-operator-precedence].
Per semplificare nel nostro contesto, JavaScript usa la regola PEDMAS (parentesi, esponenti, divisione/moltiplicazione, addizione/sottrazione) che abbiamo imparato nelle lezioni di matematica delle elementari.

<!-- prettier-ignore-start -->
```javascript
const result = 3 ** 3 + 9 * 4 / (3 - 1);
// => 3 ** 3 + 9 * 4/2
// => 27 + 9 * 4/2
// => 27 + 18
// => 45
```
<!-- prettier-ignore-end -->

### Operatori di assegnazione abbreviata

Gli operatori di assegnazione abbreviata sono un modo più breve di scrivere codice che esegue operazioni aritmetiche su una variabile e assegna il nuovo valore alla stessa variabile.
Ad esempio, considera due variabili `x` e `y`.
Allora, `x += y` equivale a `x = x + y`.
Spesso si usa un numero al posto di una variabile `y`.
Le altre 5 operazioni si possono eseguire in modo simile.

```javascript
let x = 5;
x += 25; // x is now 30

let y = 31;
y %= 3; // y is now 1
```
