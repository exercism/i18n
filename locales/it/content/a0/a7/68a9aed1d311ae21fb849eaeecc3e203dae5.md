# Suggerimenti

## 1. Dividere una stringa in singole righe

- Swift ha un [metodo][nsstring-components-docs] per dividere una stringa in un array di stringhe usando un delimitatore fornito.

## 2. Porta anteriore

- La guardia reciterà una poesia e dovrai dividere la poesia in singole righe: per farlo puoi usare una funzione già esistente.
- Puoi usare un ciclo for per iterare sulle righe della poesia.
- Puoi usare la proprietà `first` di una stringa per ottenere il primo carattere di una stringa.
- Per memorizzare il primo carattere di ogni riga, puoi usare un array di caratteri o una stringa.

## 3. Porta posteriore

- La guardia reciterà una poesia e dovrai dividere la poesia in singole righe: per farlo puoi usare una funzione già esistente.
- Puoi usare un ciclo for per iterare sulle righe della poesia.
- Puoi usare la proprietà `last` di una stringa per ottenere l'ultimo carattere di una stringa.
- Per memorizzare l'ultimo carattere di ogni riga, puoi usare un array di caratteri o una stringa.

## 4. Stanza segreta

- La guardia reciterà una poesia e dovrai dividere la poesia in singole righe: per farlo puoi usare una funzione già esistente.
- Puoi usare un ciclo for che itera sulla lunghezza delle righe della poesia.
- Swift ha un [metodo][indexing] per ottenere il carattere a un indice specifico in una stringa.
- Swift ha un [metodo][uppercased] per convertire una stringa in maiuscolo.
