# Informazioni

`when` è la parola chiave che si usa per filtrare le eccezioni. Va inserita dopo l'istruzione `catch` e può accettare un'espressione booleana che contiene qualsiasi valore sia nello scope in quel momento. Non devono essere per forza membri dell'eccezione stessa. Se il tipo dell'eccezione corrisponde e l'espressione è vera, allora viene eseguito il blocco associato a quella istruzione `catch`. Altrimenti si passa a controllare la successiva istruzione `catch`, se c'è.

```csharp
try
{
    // do stuff
}
catch (Exception ex) when (ex.Message != "")
{
    // output the message when it is not empty
}
catch (Exception ex)
{
    // show stack trace or something.
}
```
