# Debug

Quando un test fallisce, viene mostrato un messaggio che descrive cosa è andato storto e per quale input. Puoi anche sfruttare il fatto che verrà mostrato anche l'output della console. Puoi scrivere nell'output della console usando:

```crystal
puts "Debug message"
```

oppure

```crystal
p "Debug message"
```

`puts` converte il valore in una stringa e lo stampa nell'output della console.
`p` stampa il valore nell'output della console senza convertirlo in una stringa.
