# Introduzione

Molti linguaggi hanno un modo, come `null` o `none`, per indicare un valore inesistente.
Poiché R è progettato per gestire grandi quantità di dati (spesso disordinati), ha diverse forme di nulla.

L'obiettivo generale è segnalare i valori mancanti o sospetti man mano che li si incontra, per poi proseguire senza sollevare un'eccezione.

## NULL

Se un valore non esiste davvero, è rappresentato da `NULL`. Questa è probabilmente la forma più vicina a quella che userebbero C o Python.

```R
v <- c() # zero-length vector
v
#> NULL
is.null(v)
#> [1] TRUE
```

In molti contesti, i valori `NULL` vengono semplicemente ignorati:

```R
c(2, 3, NULL, 5)
#> [1] 2 3 5
```

## NA

Per le situazioni in cui un valore esiste ma non sappiamo quale sia, si usa `NA`. Per esempio, quando si contano i veicoli che percorrono una strada, gli osservatori umani potrebbero ammalarsi o i sensori automatici rompersi, ma il traffico continua a scorrere.

```R
v <- c(1, 2, NA, 4, 5)
v
#> [1]  1  2 NA 4  5
is.na(v) # test for data gaps
#> [1] FALSE FALSE  TRUE FALSE FALSE
```

Quindi `NA` è un segnaposto che avverte le persone che devono decidere come gestirlo.

## NaN

Abbreviazione di «Not a Number», `NaN` segnala un problema di calcolo nelle situazioni in cui ci si aspettava un numero.

```R
n <- c(0, 2, 4)
d <- c(0, 1, 2)
n / d
#> [1] NaN   2   2  # 0/0 is mathematically undefined
is.nan(n / d)
#> [1]  TRUE FALSE FALSE
```

Questa non è l'unica possibilità per i calcoli «non validi».
Dividere per zero restituirà `Inf` o `-Inf` per un numeratore diverso da zero, senza sollevare un errore.

```R
1 / 0
#> [1] Inf
```

## Vettori vuoti

Forse sorprendentemente, R non ha un modo standard per verificare se un vettore è vuoto.

Anche generare un vettore vuoto non è del tutto ovvio.
In una sezione precedente abbiamo visto che `c()` senza argomenti restituisce `NULL`, non un vettore.

```R
is.vector(c())
#> [1] FALSE
```

Funzioni come `logical()` o `integer()` prendono un argomento che specifica la lunghezza desiderata, che può essere zero.

```R
z <- logical(0)
is.vector(z)
#> [1] TRUE
length(z)
#> [1] 0
```

Possiamo anche generare un vettore e poi rimuoverne ogni elemento, come descritto nel [concetto Vettori][concept-vectors].
Il risultato è un vettore di lunghezza 0 del tipo appropriato.

```R
v <- 5
v[-1]  # delete the first element
#> numeric(0)
```

[concept-vectors]: https://exercism.org/tracks/r/concepts/vectors
