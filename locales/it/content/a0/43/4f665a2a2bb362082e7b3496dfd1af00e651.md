# Introduzione

In Haxe, un **array** è una raccolta di elementi (di solito) dello stesso tipo. Ci sono tre modi per creare un array in Haxe: tramite un costruttore o tramite una sintassi di dichiarazione. In Haxe, il primo elemento di un array ha indice zero:

```haxe
var a = [1, 2, 3];
trace(a); // [1,2,3]

// Here the second element is called by index
trace(a[1]); // 2

// The actual first element's index is 0
trace(a[0]); // 1
```

Per creare un array usando un costruttore, devi passare il tipo degli elementi che verranno inclusi nell'array:

```haxe
var a:Array<Int> = [0, 1, 2, 3];
a[1] = "Hello"; // Error: the array a takes integers only
```

Se vogliamo che un array contenga elementi di più tipi, aggiungiamo il tipo `Dynamic` all'indicatore di tipo:

```haxe
var a:Array<Dynamic> = [10, "Bob", true]
```
