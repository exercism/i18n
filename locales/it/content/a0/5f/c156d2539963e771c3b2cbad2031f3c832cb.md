# Introduzione

## I moduli

I moduli sono un modo per raggruppare codice correlato, per evitare conflitti di nomi, e in generale sono presenti in tutte le basi di codice tranne le più banali.

La sintassi è la seguente:

```rust
mod my_module {
    pub struct MyStruct {}

    pub struct OtherClass {}
}
```

Al di fuori dello scope del modulo, i tipi racchiusi nei moduli si indicano anteponendo al nome del tipo la sintassi del doppio due punti `::`.
In alternativa, e più comunemente, puoi mettere una direttiva `use` all'inizio del file (o all'interno di un modulo), e poi i tipi si possono usare senza il prefisso.
All'interno dello stesso modulo non c'è bisogno di qualificare i nomi dei tipi.

```rust
mod my_module {
    #[derive(Drop)]
    pub struct MyStruct {}

    pub struct Foo {}

    #[generate_trait]
    pub impl FooImpl of FooTrait {
        fn bar() {
            let baz = MyStruct {};
        }
    }
}

#[derive(Drop)]
pub struct Qux {}

#[generate_trait]
impl QuxImpl of QuxTrait {
    fn box() {
        let nux = my_module::MyStruct {};
    }
}

mod other_module {
    use super::my_module::*;

    #[derive(Drop)]
    pub struct Tix {}

    #[generate_trait]
    pub impl TixImpl of TixTrait {
        fn jeg() {
            let lor = MyStruct {};
        }
    }
}
```

Puoi assegnare un alias a un modulo o a un tipo con la sintassi `use core::array::ArrayTrait as Arr;` e poi usare l'alias ovunque si possa usare il modulo o il tipo.
