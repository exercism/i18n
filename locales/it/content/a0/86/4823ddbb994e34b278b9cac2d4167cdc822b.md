# Appendice alle istruzioni

## Lavorare con le date in Prolog

Il supporto integrato di Prolog per le date è [piuttosto rudimentale][built-in-dates-support].
Un modo molto più comodo per lavorare con le date è il [pacchetto date_time][date_time-package].

### Installare il pacchetto date_time

Se la versione di Swipl che hai installato è abbastanza aggiornata, puoi installare il pacchetto eseguendo:

```bash
swipl pack install date_time
```

Se non funziona, puoi eseguire:

```shell
swipl -g 'pack_install(date_time)'
```

~~~~exercism/note
Se usi l'editor online, non devi installare nulla manualmente.
~~~~

### Usare il pacchetto date_time

Aggiungi il seguente codice all'inizio del file della soluzione per usare il pacchetto `date_time`:

```prolog
:- use_module(library(date_time)).
```

~~~~exercism/note
Suggerimento: il [codice sorgente del pacchetto date_time][https://www.swi-prolog.org/pack/file_details/date_time/prolog/date_time.pl?show=src] è ben documentato e può esserti di grande aiuto!
~~~~
