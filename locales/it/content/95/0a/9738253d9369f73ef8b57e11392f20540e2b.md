# Introduzione

Gli errori capitano. In Elixir, anche se spesso si dice «let it crash», ci sono momenti in cui dobbiamo fare rescue della chiamata di funzione a uno stato noto e valido per soddisfare un contratto software. In alcuni linguaggi, gli errori vengono usati come metodo di controllo del flusso, ma in Elixir questo schema è sconsigliato. Spesso possiamo riconoscere le funzioni che potrebbero sollevare un errore semplicemente dal loro nome: le funzioni che sollevano errori hanno un `!` alla fine del nome. Questo rispetto alle funzioni che restituiscono `{:ok, value}` o `:error`. Guarda questi esempi dalla libreria:

```elixir
Map.fetch(%{a: 1}, :b)
# => :error
Map.fetch!(%{a: 1}, :b)
# => raises KeyError
```
