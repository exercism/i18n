# Informazioni

La definizione di una collezione include di solito un segnaposto tra parentesi angolari (`<>`), spesso `T` per convenzione. Una collezione di questo tipo viene chiamata tipo generico. Questo permette a chi usa la collezione di specificare il tipo di elementi da memorizzare al suo interno. Nel codice di esempio qui sopra stiamo istanziando un array di stringhe.

Per rendere **generica** una classe o una funzione si usa l'attributo `@:generic`. In questo modo il compilatore identifica la classe o la funzione come generica:

```haxe
@:generic
class MyValue<T> {
  public var value:T;

  public function new(value:T) {
    this.value = value;
  }
}

var a = MyValue<String>("Hello");
trace(a.value); // Hello
```
