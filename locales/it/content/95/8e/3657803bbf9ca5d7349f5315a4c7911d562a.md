# Introduzione

In Go, puoi iterare su uno `slice` usando `for` e un indice, oppure puoi usare `range`.
`range` ti permette anche di iterare su una `map`.

Ogni iterazione restituisce due valori: l'indice o la chiave, e una copia dell'elemento in quella posizione.

## Iterare su uno slice

Facile come bere un bicchier d'acqua: i cicli su uno slice sono ordinati come ci si aspetta.

```go
xi := []int{10, 20, 30}
for i, x := range xi {
  fmt.Println(i, x)
}
// outputs:
// 0, 10
// 1, 20
// 2, 30
```

## Iterare su una map

Iterare su una map presenta un nuovo problema.
Ora l'ordine è casuale.

```go
hash := map[int]int{9: 10, 99: 20, 999: 30}
for k, v := range hash {
  fmt.Println(k, v)
}
// outputs, for example:
// 99 20
// 999 30
// 9 10
```

~~~~exercism/note
Può sembrare che l'output qui sopra sia errato: ci si aspetterebbe che la prima coppia chiave/valore della dichiarazione della map, `9 10`, sia la prima a essere stampata, e non l'ultima.
Tuttavia, le map sono per natura prive di ordine: non esiste una prima né un'ultima coppia chiave/valore.
Per questo, quando si iterano le voci di una map, l'ordine in cui le voci vengono visitate è casuale e non segue alcuno schema preciso.
Ciò significa che l'output qui sopra è possibile, ma potrebbe differire da quello che ottieni se provi a eseguirlo tu.
Per saperne di più, consulta [Go Language Spec: range clause](https://go.dev/ref/spec#RangeClause).
~~~~

## Iterazione con chiave o valore omessi

In Go, una variabile non utilizzata genera un errore in fase di compilazione.
A volte ti serve solo il valore, come nel primo esempio:

```go
xi := []int{10, 20, 30}
for i, x := range xi {
  fmt.Println(x)
}
// Go build failed: i declared but not used
```

Puoi sostituire `i` con `_`, cosa che indica al compilatore che non usiamo quel valore:

```go
xi := []int{10, 20, 30}
for _, x := range xi {
  fmt.Println(x)
}
// outputs:
// 10
// 20
// 30
```

Se vuoi stampare solo l'indice, puoi sostituire `x` con `_`,
oppure omettere del tutto la dichiarazione:

```go
xi := []int{10, 20, 30}
// for i, _ := range xi {
for i := range xi {
  fmt.Println(i)
}
// outputs:
// 0
// 1
// 2
```

## Definire i tipi

Una definizione di tipo crea un nuovo tipo con un nome, distinto da ogni altro tipo, anche da uno con lo stesso tipo sottostante.

```go
type File []bool
```

`File` qui si riferisce a una singola colonna verticale su una scacchiera, comunemente etichettata da A a H.
Ogni casella di questa colonna è rappresentata da un valore booleano che indica se è occupata o no.
Ora che `File` è definito, possiamo usarlo all'interno di altre definizioni:

```go
type Chessboard map[string]File

board := Chessboard{
    "A": File{true, false, true},
    "B": File{false, true, false},
}
```

`Chessboard` mappa gli identificatori delle colonne su valori `File`.
Ogni `File` è uno slice di booleani che rappresenta le caselle di una colonna della scacchiera.
Senza queste definizioni di tipo, `board` sarebbe una `map[string][]bool`, il che renderebbe più difficile capire cosa stiamo rappresentando.
