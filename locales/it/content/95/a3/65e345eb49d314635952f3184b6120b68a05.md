# Introduzione

## Le eccezioni

In C#, le eccezioni forniscono un modo strutturato, uniforme e type-safe di gestire le condizioni di errore che si verificano durante l'esecuzione. Una gestione corretta delle eccezioni e degli errori è importante per evitare che l'applicazione vada in crash.

In C#, tutte le eccezioni hanno la classe `System.Exception` come tipo di base. Questa contiene proprietà importanti, come `Message`, che racchiude una descrizione leggibile del motivo per cui l'eccezione è stata lanciata.

Per segnalare che si è verificato un errore in una certa parte del codice, è necessario creare un nuovo oggetto eccezione e poi lanciarlo, usando la parola chiave `throw`:

```csharp
using System;
static int Square(int number)
{
    if (number >= 46341)
    {
        throw new ArgumentException($"Argument {number} cannot be higher than 46340 as its' square doesn't fit into int type.");
    }
    return number * number;
}
```

Quando viene lanciata un'eccezione, il runtime ha il compito di trovare un pezzo di codice responsabile della sua gestione. Se non viene trovato un gestore adeguato, il runtime mostra il messaggio di eccezione non gestita e interrompe l'esecuzione del programma.

Per creare un gestore per un'eccezione, C# usa l'istruzione try-catch, composta da un blocco `try` e da una o più clausole `catch`. Il blocco `try` deve contenere e proteggere il codice che potrebbe causare il lancio dell'eccezione. Le clausole `catch` devono contenere il codice che gestisce il comportamento del programma dopo che si è verificato l'errore. È importante notare che l'ordine delle eccezioni è rilevante dopo il blocco `try`: quando sono elencate più eccezioni, viene eseguita la prima clausola `catch` che corrisponde.

```csharp
try
{
   if (number == 42)
   {
       throw new ArgumentException("The number cannot be equal to 42.", "number");
   }

   if (number < 0)
   {
      throw new ArgumentOutOfRangeException("number", "The number cannot be negative.");
   }

    // Process number ...
}
catch (ArgumentOutOfRangeException e)
{
    Console.WriteLine($"Number is out of range: {e.Message}.");
}
catch (ArgumentException)
{
    Console.WriteLine("Invalid number.");
}
```
