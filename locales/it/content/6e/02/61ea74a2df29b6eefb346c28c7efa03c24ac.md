# Introduzione

In Common Lisp una funzione può avere alcuni argomenti opzionali.
Questi vengono indicati nella lambda list con la parola chiave `&optional`.
Se non viene specificato, un parametro viene legato al valore `nil`.
Se ci sono più parametri opzionali, vengono legati in ordine.
Per i parametri opzionali si possono specificare dei valori predefiniti.
Infine, per ogni parametro opzionale si può specificare un simbolo che verrà legato a vero o falso a seconda che il chiamante della funzione abbia fornito o meno quel parametro (questo è il cosiddetto «parametro supplied-p»).

```lisp
(defun optional-parameters (&optional x (y 'default) (z nil z-supplied-p))
  (list x y (if z-supplied-p (list :z-was-supplied z)
                             (list :z-was-not-supplied z))))

(optional-parameters)          ; => (NIL DEFAULT (:Z-WAS-NOT-SUPPLIED NIL))
(optional-parameters 5 nil 10) ; => (5 NIL (:Z-WAS-SUPPLIED 10))
```
