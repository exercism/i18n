# Istruzioni

In questo esercizio implementerai un insieme parziale di routine di utilità per aiutare uno sviluppatore a ripulire i nomi degli identificatori.

Nelle 6 attività costruirai gradualmente le funzioni `transform`, per convertire singoli caratteri, e `clean`, per convertire stringhe.

Un identificatore valido è composto da zero o più lettere, underscore, trattini, punti interrogativi ed emoji.

Se alla funzione `clean` viene passata una stringa vuota, deve essere restituita una stringa vuota.

## 1. Sostituire ogni trattino incontrato con un underscore

Implementa la funzione `transform` per sostituire ogni trattino con un underscore.

```fsharp
transform '-'  // => "_"
```

## 2. Rimuovere tutti gli spazi bianchi

Rimuovi tutti i caratteri di spazio bianco.
Sono compresi anche gli spazi bianchi iniziali e finali.

```fsharp
transform ' '  // => ""
```

## 3. Convertire camelCase in kebab-case

Modifica la funzione `transform` per convertire camelCase in kebab-case

```fsharp
transform 'D'  // => "-d"
```

## 4. Omettere i caratteri che sono cifre

Modifica la funzione `transform` per omettere i caratteri numerici.

```fsharp
transform '7'  // => ""
```

## 5. Sostituire le lettere greche minuscole con punti interrogativi

Modifica la funzione `transform` per sostituire le lettere greche nell'intervallo da 'α' a 'ω'.

```fsharp
transform 'β' // => "?"
```

## 6. Combinare queste operazioni per agire su una stringa

Implementa la funzione `clean` per applicare queste operazioni a un'intera stringa.

I caratteri che non rientrano nelle regole devono passare inalterati.

```fsharp
clean "  a2b Cd-ω😀  " //  => "ab-cd_?😀"
```

## Costruire una stringa a partire da caratteri

Questo argomento sarà trattato in dettaglio più avanti nel percorso.

Per ora, può essere utile sapere che esiste una [funzione di ordine superiore][higher-order-function] chiamata [`String.collect`][string-collect] che converte una collezione di `char` in una stringa, usando una funzione che fornisci.

```fsharp
let transform ch = $"{ch}_"
String.collect transform "abc"  // =>  "a_b_c_"
```
