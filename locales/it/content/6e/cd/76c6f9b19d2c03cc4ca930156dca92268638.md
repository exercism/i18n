# Introduzione

Spesso vogliamo scrivere codice che possa prendere percorsi diversi in base a una condizione. In Elixir ci sono molti modi per farlo, ma uno dei più semplici è usare `cond/1`.

Nella sua forma più semplice, `cond` segue il primo percorso che ha come risultato `true`, con uno o più rami:

```elixir
cond do
  x > 10 -> :this_might_be_the_way
  y < 7 -> :or_that_might_be_the_way
  true -> :this_is_the_default_way
end
```

Se nessun percorso ha come risultato `true`, il runtime genera un errore.
