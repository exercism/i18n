# Introduzione

In JavaScript, i valori possono essere di tipi diversi. Il tipo di una variabile si può cambiare con una _conversione di tipo_ esplicita.
Oltre a questo, JavaScript esegue anche una _coercizione di tipo_ (conversione implicita di tipo) quando il contesto lo richiede.

## Conversione di tipo

A differenza di molti altri linguaggi, JavaScript non ha un costrutto per eseguire il cast verso un tipo (diverso), ma si possono usare alcune funzioni ausiliarie predefinite.
In particolare, `Boolean`, `Number` e `String` si possono usare come funzioni per convertire un valore nel tipo corrispondente.

### Conversione in un valore booleano (valori truthy e falsy)

Con `Boolean(value)` puoi convertire qualsiasi valore in un valore booleano.
Esiste un insieme fisso di valori, i cosiddetti valori _falsy_, che si convertono in `false`.
Soprattutto, `false`, `0`, la stringa vuota, `null`, `undefined` e `NaN` sono falsy.

Per tutti gli altri valori, `Boolean` restituisce `true`.
Questi valori si chiamano _truthy_.

```javascript
Boolean(-1);
// => true

Boolean(0);
// => false

Boolean(' ');
// => true

Boolean('');
// => false
```

Nota che, per le regole descritte, `'0'`, `'false'`, `[]` e `{}` sono **truthy** in JavaScript.

### Conversione in un numero

`Number(value)` si può usare per convertire un valore in un numero.
Gli spazi bianchi all'inizio e alla fine di una stringa vengono ignorati e una stringa vuota viene convertita in `0`.
Se provi a convertire un valore non primitivo o una stringa che non rappresenta un numero, il risultato è `NaN` ([Not-A-Number][mdn-nan]).

```javascript
Number('  -12.34  ');
// => -12.34

Number('1,2');
// => NaN

Number('');
// => 0

Number({ num: 123 });
// => NaN
```

### Conversione in una stringa

Con `String(value)` puoi convertire un valore in una stringa.
Per i valori primitivi, il risultato è quello che ti aspetti.

```javascript
String(12.34);
// => '12.34'

String(false);
// => 'false'

String(null);
// => 'null'

String(undefined);
// => 'undefined'
```

Per gli array, la funzione `String` applica la conversione a stringa a ogni elemento e unisce i risultati con una virgola.
Puoi anche applicare il [metodo `join`][mdn-join] direttamente, ad esempio per personalizzare il separatore.
Nota che in questi casi `null` e `undefined` vengono convertiti in una stringa vuota.

```javascript
String([42, null, true, 'abc']);
// => '42,,true,abc'
```

Per gli oggetti, per impostazione predefinita `String` restituisce un testo poco utile.

```javascript
String({ key: 'value' });
// => '[object Object]'
```

## Coercizione di tipo

In alcuni contesti, JavaScript converte automaticamente un valore in un altro tipo di dato prima di valutare un'istruzione.
Questa conversione implicita si chiama _coercizione di tipo_.

### Contesto booleano

Quando un valore non booleano viene usato in un contesto booleano, JavaScript applica le stesse regole della funzione `Boolean` per convertirlo implicitamente.

La coercizione a valore booleano si verifica comunemente nei casi seguenti:

- la condizione di un'[istruzione if][concept-conditionals]
- il primo operando dell'[operatore ternario][mdn-ternary] `?`
- l'operando dell'operatore logico NOT `!`
- gli operandi degli operatori logici AND `&&` e OR `||` (il risultato dell'espressione è uno degli operandi, non necessariamente un valore booleano)

```javascript
const num = 0;
if (num) {
  // this block is NOT executed because 0 is falsy
}
```

### Contesto delle stringhe

Se l'operatore di addizione `+` viene usato con valori primitivi e un operando è una stringa, anche l'altro subirà una coercizione a stringa.
La logica di conversione è la stessa della funzione `String`.
Successivamente, le due stringhe vengono concatenate.

```javascript
let name;
'hello ' + name;
// => 'hello undefined'
```

### Contesto numerico

Molti operatori applicano una coercizione numerica agli operandi (se necessario) secondo la logica della funzione `Number` spiegata sopra.

- Operatori aritmetici: `+` (se non è coinvolta alcuna stringa), `-`, `*`, `/`, `%`, `**`
- Operatori più e meno unari: `+`, `-`
- Operatori relazionali (per operandi non stringa): `>`, `>=`, `<`, `<=`
- Operatori bit a bit: `|`, `&`, `^`, `~`

Per maggiori dettagli su uno qualsiasi di questi operatori, consulta l'[elenco degli operatori di MDN][mdn-operators].

Per evitare errori, è buona pratica chiamare sempre `Number` esplicitamente prima di applicare questi operatori.
