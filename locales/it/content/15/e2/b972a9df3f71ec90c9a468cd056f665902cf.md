# Metodi degli array

Gli array sono una struttura dati comune con cui lavorare.
Per questo motivo esiste una raccolta di metodi che si possono usare per gestirli.
Tra questi ci sono l'ordinamento, l'inversione, l'inserimento e molti altri.

Alcuni di questi metodi sono distruttivi, cioè modificano l'array originale.
Altri non sono distruttivi, cioè restituiscono un nuovo array e non modificano quello originale.

Ecco alcuni dei metodi più comuni che si possono usare quando si lavora con gli array:

## insert

Quando inserisci un elemento in un array, puoi usare il metodo [`insert`][insert], che accetta come argomenti un indice e un elemento.
L'elemento verrà inserito all'indice specificato e il resto dell'array verrà spostato a destra.
Se l'indice è fuori dai limiti, viene generato un `IndexError`.

```crystal
numbers = [1, 2, 3]
numbers.insert(1, 4)
numbers # => [1, 4, 2, 3]

numbers.insert(5, 5) # => Error: Index out of bounds (IndexError)
```

## delete

Quando vuoi eliminare un elemento specifico da un array, puoi usare il metodo [`delete`][delete], che accetta un elemento come argomento.
Il metodo restituisce l'elemento rimosso.
Se l'elemento non esiste nell'array, viene restituito `nil`.

```crystal
numbers = [1, 2, 3]
numbers.delete(2) # => 2
numbers           # => [1, 3]
```

## first & last

Quando vuoi ottenere il primo o l'ultimo elemento di un array, puoi usare i metodi [`first`][first] e [`last`][last].
Questi metodi accettano un argomento opzionale che specifica quanti elementi restituire.
Possono migliorare la leggibilità rispetto all'uso dell'indice `0` o `-1`, o di un intervallo.
Se l'array è vuoto, viene generato un `Enumerable::EmptyError`.

```crystal
numbers = [1, 2, 3]
numbers.first # => 1
numbers.last  # => 3

numbers.first(2) # => [1, 2]
numbers.last(2)  # => [2, 3]

empty_array = [] of Int32
empty_array.last # => Error: Empty enumerable (Enumerable::EmptyError)
```

## reverse

Quando vuoi invertire un array, puoi usare il metodo [`reverse`][reverse], che restituisce un nuovo array con gli elementi in ordine inverso.
È importante notare che `reverse` restituisce un nuovo array e non modifica quello originale.
Se vuoi modificare l'array originale, aggiungi un `!` alla fine del nome del metodo.

```crystal
numbers = [1, 2, 3]
numbers.reverse # => [3, 2, 1]
numbers         # => [1, 2, 3]

numbers.reverse! # => [3, 2, 1]
numbers          # => [3, 2, 1]
```

## flatten & compact & transpose & uniq

I seguenti metodi sono utili per operazioni come rendere un array monodimensionale, rimuovere gli elementi `nil`, rimuovere i duplicati o trasporre un array di array.
Come `reverse`, questi metodi restituiscono un nuovo array e non modificano quello originale.

| Metodo | Descrizione | Esempio |
| ------ | ----------- | ------- |
| [`flatten`][flatten] | Restituisce un nuovo array che è un appiattimento monodimensionale di questo array (in modo ricorsivo). In pratica, per ogni elemento dell'array, estrae i suoi elementi nel nuovo array. | `[[1, 2], [3, 4]].flatten # => [1, 2, 3, 4]` |
| [`compact`][compact] | Restituisce una copia di sé stesso con tutti gli elementi nil rimossi. | `[1, nil, 2, nil, 3].compact # => [1, 2, 3]` |
| [`transpose`][transpose] | Presuppone che sé stesso sia un array di array e [traspone][transpose] le righe e le colonne. | `[[1, 2], [3, 4]].transpose # => [[1, 3], [2, 4]]` |
| [`uniq`][uniq] | Restituisce un nuovo array rimuovendo i valori duplicati in sé stesso. | `[1, 2, 1, 3, 1].uniq # => [1, 2, 3]` |

## Concat(`+`)

Il metodo di append (`<<`) è utile quando vuoi aggiungere oggetti a un array.
Tuttavia, quando combini due array, puoi usare l'operatore [`+`][concat], che restituisce un nuovo array con gli elementi di entrambi gli array.

```crystal
[1, 2] + [3, 4] # => [1, 2, 3, 4]
```

Se fai un append di un array a un altro array, l'array verrà aggiunto come un singolo elemento.

```crystal
[1, 2] << [3, 4] # => [1, 2, [3, 4]]
```

## empty?

Quando vuoi verificare se un array è vuoto, puoi usare il metodo [`empty?`][empty?], che restituisce `true` se l'array è vuoto e `false` in caso contrario.
Questo migliora la leggibilità rispetto al confronto della lunghezza dell'array con `0`.

```crystal
[].empty? # => true
[1, 2, 3].empty? # => false
```

## index

Quando vuoi ottenere l'indice di un elemento in un array, puoi usare il metodo [`index`][index], che accetta un elemento come argomento.
Se l'elemento non esiste nell'array, viene restituito `nil`.

```crystal
numbers = [1, 2, 3]
numbers.index(2) # => 1
```

## size

Quando vuoi sapere quanti elementi ci sono in un array, puoi usare il metodo [`size`][size].

```crystal
numbers = [1, 2, 3]
numbers.size # => 3
```

## count

Quando vuoi contare quante volte un elemento è presente in un array, puoi usare il metodo [`count`][count].

```crystal
fruits = ["apple", "banana", "apple"]
fruits.count("apple")      # => 2
fruits.count("banana")     # => 1
fruits.count("watermelon") # => 0
```

## sort

Quando vuoi ordinare un array, puoi usare il metodo [`sort`][sort], che restituisce un nuovo array con gli elementi ordinati.
Come `reverse`, questo metodo restituisce un nuovo array e non modifica quello originale.

```crystal
numbers = [3, 2, 1]
numbers.sort # => [1, 2, 3]
numbers      # => [3, 2, 1]

numbers.sort! # => [1, 2, 3]
numbers       # => [1, 2, 3]
```
