# Introduzione

Il modulo [`fractions`][fractions] ci permette di creare e usare i [`rational numbers`][rational]: frazioni con un numeratore intero diviso per un denominatore intero.
Per esempio, possiamo memorizzare `2/3` come frazione esatta invece del valore `float` approssimato `0.6666...`.

A differenza dei numeri `int`, `float` e `complex`, le frazioni non hanno una forma letterale.
Tuttavia, il costruttore delle frazioni è piuttosto flessibile.

Nel caso più evidente, può accettare due numeri interi come argomenti.
I fattori comuni vengono rimossi automaticamente, riducendo la frazione alla sua «forma ridotta» (_i numeri interi più piccoli che rappresentano accuratamente la frazione_):

```python
>>> from fractions import Fraction

>>> f1 = Fraction(2, 3) # 2/3
>>> f1
Fraction(2, 3)

>>> f2 = Fraction(6, 9)
>>> f2
Fraction(2, 3)  # automatically simplified

>>> f1 == f2
True
```

Il costruttore delle frazioni può anche analizzare una rappresentazione sotto forma di stringa:

```python
>>> f3 = Fraction('2/3')
>>> f3
Fraction(2, 3)
```

Le frazioni possono anche lavorare con parametri `float`, ma questo può creare problemi per via della natura approssimata con cui il valore decimale viene rappresentato internamente in binario.
Per saperne di più su questo problema di rappresentazione, vedi il sito [0.30000000000000004][0.30000000000000004] e [Floating Point Arithmetic: Issues and Limitations ][fp-issues] nella documentazione di Python.

Per un risultato più affidabile quando si usano numeri in virgola mobile con le frazioni, c'è il metodo `<fraction>.limit_denominator()`.


## Aritmetica con le frazioni

I soliti [`arithmetic operators`][operators] `+ - * / **` funzionano con le frazioni, come con gli altri tipi numerici.

Numeri interi e altre `Fraction` possono comparire nell'espressione e dare come risultato una `Fraction`.
Includere un `float` nell'espressione produce un `float` come risultato, con una conseguente (possibile) perdita di precisione:

```python
>>> Fraction(2, 3) + Fraction(1, 4) # addition
Fraction(11, 12)

>>> Fraction(2, 3) * Fraction(6, 5) # multiply fractions
Fraction(4, 5)

>>> Fraction(2, 3) * 6 / 5 # fraction with integers
Fraction(4, 5)

>>> Fraction(2, 3) * 1.2  # fraction with float -> float
0.7999999999999999

>>> Fraction(2, 3) ** 2  # exponentiation with integer
Fraction(4, 9)
```

Anche varie funzioni numeriche standard di Python danno il risultato che ti aspetteresti lavorando con i tipi `int` e `float`:

```python
>>> round(Fraction(11, 3))
4

>>> from math import floor, ceil
>>> floor(Fraction(11, 3))
3
>>> ceil(Fraction(11, 3))
4

>>> float(Fraction(11, 3))
3.6666666666666665
```
