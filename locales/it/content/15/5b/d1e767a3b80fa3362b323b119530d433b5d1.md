# Introduzione

Ricorda dal concetto Fondamenti che un programma AWK è composto da **coppie pattern-azione**.

```awk
pattern1 { action1 }
pattern2 { action2 }
...
```

## Cosa intendiamo con «pattern»?

Il «pattern» è una qualsiasi espressione AWK.
La verità del risultato dell'espressione determina se l'azione viene eseguita.

## Il pattern vuoto

Il pattern può essere omesso.
In questo caso, l'azione viene eseguita per ogni record.

Possiamo stampare tutti i nomi utente nel file passwd.

```sh
awk -F: '{print $1}' /etc/passwd
```

## Espressioni regolari

AWK può confrontare le stringhe con espressioni regolari per ottenere un risultato booleano.

Usa l'operatore di corrispondenza con espressioni regolari `~` per far corrispondere un campo specifico.
Questo operatore accetta una stringa come operando di sinistra e un'espressione regolare come operando di destra.
Un valore letterale di espressione regolare è racchiuso tra barre `/`.

Per trovare gli utenti nel file passwd che accedono con bash:

```sh
awk -F: '$7 ~ /bash/ {print $1}' /etc/passwd
```

`!~` è l'operatore «espressione regolare che **non** corrisponde».

Per far corrispondere un'espressione regolare al record corrente, puoi scrivere `$0 ~ /regex/`.
È così comune che esiste una scorciatoia: puoi omettere `$0` e `~` e scrivere semplicemente `/regex/`

```sh
awk '/regex/' data.txt
```

Confronta quel one-liner AWK con il comando grep equivalente

```sh
grep 'regex' data.txt
```

## Espressioni

Le espressioni AWK (aritmetiche, logiche o di altro tipo) possono essere usate come pattern.

Per estrarre tutti gli utenti con UID 1000 o superiore:

```sh
awk -F: '$3 >= 1000' /etc/passwd
```

Ricorda che i valori falsi di AWK sono il numero zero e la stringa vuota, mentre tutti gli altri numeri o stringhe sono veri.
Qualsiasi espressione che restituisce un numero o una stringa può essere usata come pattern.

## Funzioni

Qualsiasi funzione [integrata][builtins] o [definita dall'utente][user-defined] può essere usata in un'espressione, e quindi nel pattern.
Un paio di esempi:

```awk
length($1) {print "first field is not empty"}
```
```awk
toupper(substr($1, 1, 1)) ~ /[AEIOU]/ {print "starts with a vowel"}
```

## Pattern costanti

Un idioma AWK comune è:

```sh
{
    xyz()   # some code that transforms each record
}
1
```

`1` è un pattern vero senza un'azione associata.
Questo significa «stampa il record corrente».
