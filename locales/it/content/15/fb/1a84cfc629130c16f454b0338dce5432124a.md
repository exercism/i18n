# Informazioni

Un [`Array`][array] in Elm è una collezione immutabile e veloce di zero o più valori dello stesso tipo.
Poiché gli array sono immutabili, una volta che un array è stato costruito, il suo valore non può più cambiare.
Non esiste una sintassi letterale per gli array (come invece c'è per le liste), quindi si usa la sintassi Array.fromList.
Per esempio, un `Array` che contiene "a", "b" e "c" di solito viene mostrato come `Array.fromList ["a", "b", "c"]`.
Lo vedrai nell'output della console, nel debugger e in altri posti simili.

A differenza di `List`, che è un [import predefinito][default-imports], il modulo `Array` deve essere importato esplicitamente, usando `import Array` o qualcosa di simile.

Le annotazioni di tipo per gli array si possono definire come segue

```elm
Array String --> an array of String
Array Int --> an array of Int
```

Gli array si possono definire come segue:

```elm
import Array exposing (Array)

empty : Array Char
empty = Array.empty

singleValue = Array.fromList [ 5 ] --> Array Int

repeatSingleValue = Array.repeat 2 5 --> Array.fromList [ 5, 5 ]

initialiseFromIndex = Array.initialise 3 (\index -> index * 2) --> Array.fromList [ 0, 2, 4 ]

initialisefromList = Array.fromList [ "a", "b", "c" ] --> Array.fromList [ "a", "b", "c" ]
```

Gli elementi si aggiungono a un Array usando `Array.push`:

```elm
twoToFour = Array.fromList [ 2, 3, 4 ]
oneToFour = Array.push 1 twoToFour --> Array.fromList [ 1, 2, 3, 4 ]
```

Gli array si concatenano usando `Array.append`:

```elm
sixSeven = Array.fromList [ 6, 7 ]
eightNine = Array.fromList [ 8, 9 ]
Array.append sixSeven eightNine --> Array.fromList [ 6, 7, 8, 9 ]
```

Un elemento di un Array si recupera usando `Array.get`:

```elm
sixSeven = Array.fromList [ 6, 7 ]
Array.get 0 sixSeven --> Just 6
```

Un elemento di un Array si imposta usando `Array.set`:

```elm
sixSeven = Array.fromList [ 6, 7 ]
Array.set 1 8 sixSeven --> Array.fromList [ 6, 8 ]
```

Gli array si manipolano con le funzioni definite nel [modulo `Array`][array-module].

```elm
oneTwo = Array.fromList [ 1, 2 ]
Array.length oneTwo --> 2
```

Qualsiasi funzione o operatore che sembra modificare un `Array` (come aggiungere un elemento) in realtà restituisce un nuovo `Array`.
Di solito però le prestazioni non sono un problema, dato che l'implementazione di `Array` evita allocazioni e copie superflue.

[array-module]: https://package.elm-lang.org/packages/elm/core/latest/Array
