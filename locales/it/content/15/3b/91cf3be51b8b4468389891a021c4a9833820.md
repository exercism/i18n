# Introduzione

Python ha tre diversi tipi di numeri predefiniti: interi ([`int`][int]), in virgola mobile ([`float`][float]) e complessi ([`complex`][complex]).
Le frazioni ([`fractions.Fraction`][fractions]) e i decimali ([`decimal.Decimal`][decimals]) sono disponibili anch'essi, importandoli dalla libreria standard.

Anche i numeri interi, compresi i numeri esadecimali ([_`hex()`_][hex]), ottali ([_`oct()`_][oct]) e binari ([_`bin()`_][bin]) **senza** cifre decimali, sono identificati come `ints`:

```python
# Ints are whole numbers.
>>> 1234
1234
>>> type(1234)
<class 'int'>

>>> -12
-12
```

I numeri che contengono un punto decimale (con o senza parte frazionaria) sono identificati come `floats`:

```python
>>> 3.45
3.45
>>> type(3.45)
<class 'float'>
```

## Aritmetica

Python supporta pienamente l'aritmetica tra questi diversi tipi di numero e converte i numeri più ristretti per allinearli ai loro omologhi meno ristretti quando si usano gli operatori aritmetici binari (`+`, `-`, `*`, `/`, `//` e `%`).

### Addizione e sottrazione

Gli operatori di addizione e sottrazione si comportano come nella matematica normale.
Se uno o più operandi è un `float`, anche gli `int` rimanenti verranno convertiti in `float`:

```python
>>> 5 - 3
2
# The int is widened to a float here, and a float is returned.
>>> 3 + 4.0
7.0
```

### Moltiplicazione

Come per l'addizione e la sottrazione, la moltiplicazione converte i numeri più ristretti per allinearli ai loro omologhi meno ristretti:

```python
>>> 3 * 2
6

>>> 3 * 2.0
6.0
```

### Divisione

La divisione restituisce sempre un `float`, anche se il risultato è un numero intero:

```python
>>> 6/5
1.2

>>> 6/2
3.0
```

### Divisione con arrotondamento per difetto

Se serve un risultato di tipo `int`, puoi usare la divisione con arrotondamento per difetto per troncare il risultato.
La divisione con arrotondamento per difetto si esegue con l'operatore `//`:

```python
>>> 6//5
1

>>> 6//2
3
```

### Modulo

L'operatore modulo (`%`) restituisce il resto della divisione dei due operandi:

```python
# The result of % is zero here, because dividing 8 by 2 leaves no remainder
>>> 8 % 2
0

# The result of % is 2 here, because 3 only goes into 5 once, with 2 leftover
>>> 5 % 3
2
```

Un altro modo per vedere 5 % 3:

```python
>>> whole_part = int(5/3)
1

>>> decimal_part = 5/3 - whole_part
0.6666666666666667

>>> whole_remainder = decimal_part * 3
2.0
```

## Arrotondamento

Python fornisce una funzione predefinita [`round(number, <decimal_places>)`][round] per arrotondare un numero in virgola mobile a un dato numero di cifre decimali.
Se non viene specificato il numero di cifre decimali, il numero viene arrotondato all'intero più vicino e viene restituito un `int`:

```python
>>> round(3.1415926535, 2)
3.14

>>> round(3.1415926535)
3
```

## Priorità e parentesi

Python ti permette di usare le parentesi per raggruppare le espressioni.
È utile quando vuoi modificare l'ordine predefinito delle operazioni.

```python
>>> 2 + 3 * 4
14

>>> (2 + 3) * 4
20
```

Python segue la regola [PEMDAS][pemdas] per la precedenza degli operatori.
Questo significa che i calcoli all'interno delle `()` hanno la priorità più alta, seguiti da `**`, poi `*`, `/`, `//`, `%`, `+` e `-`:

```python
>>> 2 + 3 - 4 * 4
-11

>>> (2 + 3 - 4) * 4
4

# In the following example, the `**` operator has the highest priority, then `*`, then `+`
# Meaning we first do 4 ** 4, then 3 * 64, then 2 + 192
>>> 2 + 3 * 4 ** 4
770
```

## Precisione e rappresentazione

In Python i numeri interi hanno [precisione arbitraria][arbitrary-precision]: il numero di cifre è limitato solo dalla memoria disponibile del sistema che li ospita.

I numeri in virgola mobile sono di solito implementati usando un `double` in C (_15 cifre decimali di precisione_), ma la loro rappresentazione varia in base al sistema che li ospita.
I numeri complessi hanno una parte `real` e una parte `imaginary`, entrambe rappresentate da numeri in virgola mobile.

Per una trattazione più dettagliata dei problemi e dei limiti dell'aritmetica in virgola mobile tra i vari linguaggi di programmazione, dai un'occhiata a [0.30000000000000004.com][0.30000000000000004.com] e a [The Python Tutorial][floating point math].
