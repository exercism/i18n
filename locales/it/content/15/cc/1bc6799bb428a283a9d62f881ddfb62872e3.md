# Istruzioni

In questo esercizio scriverai del codice per tenere traccia dei prefissi telefonici internazionali tramite un dizionario dei prefissi telefonici internazionali.

Il dizionario usa un numero intero per le chiavi (il prefisso telefonico) e una stringa (il nome del paese) per i valori.

Ci sono 9 attività che coinvolgono la classe statica `DialingCodes`.

## 1. Crea un nuovo dizionario

Implementa il metodo (statico) `DialingCodes.GetEmptyDictionary()` che restituisce un dizionario vuoto.

```csharp
DialingCodes.GetEmptyDictionary();
// => empty dictionary
```

## 2. Crea un dizionario pre-popolato

Esiste un dizionario pre-popolato che contiene i seguenti 3 prefissi telefonici: "United States of America", che ha il prefisso 1, "Brazil", che ha il prefisso 55, e "India", che ha il prefisso 91. Implementa il metodo (statico) `DialingCodes.GetExistingDictionary()` in modo che restituisca il dizionario pre-popolato:

```csharp
DialingCodes.GetExistingDictionary();
// => 1 => "United States of America", 55 => "Brazil", 91 => "India"
```

## 3. Aggiungi un paese a un dizionario vuoto

Implementa il metodo (statico) `DialingCodes.AddCountryToEmptyDictionary()` che crea un dizionario e vi aggiunge un prefisso telefonico e il nome del paese associato.

```csharp
DialingCodes.AddCountryToEmptyDictionary(44, "United Kingdom");
// => 44 => "United Kingdom"
```

## 4. Aggiungi un paese a un dizionario esistente

Implementa il metodo (statico) `DialingCodes.AddCountryToExistingDictionary()` che aggiunge un prefisso telefonico e il nome del paese associato a un dizionario non vuoto.

```csharp
DialingCodes.AddCountryToExistingDictionary(DialingCodes.GetExistingDictionary(),
  44, "United Kingdom");
// => 1 => "United States of America", 44 => "United Kingdom", 55 => "Brazil", 91 => "India"
```

## 5. Trova il nome del paese corrispondente a un prefisso telefonico

Implementa il metodo (statico) `DialingCodes.GetCountryNameFromDictionary()` che prende un prefisso telefonico e restituisce il nome del paese corrispondente. Se il prefisso telefonico non è contenuto nel dizionario, viene restituita una stringa vuota.

```csharp
DialingCodes.GetCountryNameFromDictionary(
  DialingCodes.GetExistingDictionary(), 55);
// => "Brazil"

DialingCodes.GetCountryNameFromDictionary(
  DialingCodes.GetExistingDictionary(), 999);
// => string.Empty
```

## 6. Verifica che un paese esista nel dizionario

Implementa il metodo (statico) `DialingCodes.CheckCodeExists()` per verificare se un prefisso telefonico esiste nel dizionario.

```csharp
DialingCodes.CheckCodeExists(DialingCodes.GetExistingDictionary(), 55);
// => true
```

## 7. Aggiorna il nome di un paese

Implementa il metodo (statico) `DialingCodes.UpdateDictionary()` che prende un prefisso telefonico e sostituisce il nome del paese corrispondente nel dizionario con il nome del paese passato come parametro. Se il prefisso telefonico non esiste nel dizionario, il dizionario rimane invariato.

```csharp
DialingCodes.UpdateDictionary(
  DialingCodes.GetExistingDictionary(), 1, "Les États-Unis");
// => 1 => "Les États-Unis", 55 => "Brazil", 91 => "India"

DialingCodes.UpdateDictionary(
  DialingCodes.GetExistingDictionary(), 999, "Newlands");
// 1 => "United States of America", 55 => "Brazil", 91 => "India"
```

## 8. Rimuovi un paese dal dizionario

Implementa il metodo (statico) `DialingCodes.RemoveCountryFromDictionary()` che prende un prefisso telefonico e rimuove dal dizionario la voce corrispondente, prefisso telefonico + nome del paese.

```csharp
DialingCodes.RemoveCountryFromDictionary(
  DialingCodes.GetExistingDictionary(), 91);
// => 1 => "United States of America", 55 => "Brazil"
```

## 9. Trova il paese con il nome più lungo

Implementa il metodo (statico) `DialingCodes.FindLongestCountryName()` che restituisce il nome del paese con il nome più lungo memorizzato nel dizionario.

```csharp
DialingCodes.FindLongestCountryName(
  DialingCodes.GetExistingDictionary());
// => "United States of America"
```
