# Normalizzazioni del representer

Il [representer JavaScript][github-javascript-representer] applica le seguenti normalizzazioni:

## Rimuovere i commenti

Tutti i commenti vengono rimossi.
I seguenti esempi sono equivalenti:

### Esempio con commenti

```javascript
/**
 * Returns the string literal 'hi there' just to say hello
 * @return [String]
 */
function hello(/* nothing*/) {
  // just return it
  return 'hi there';
}
```

### Esempio senza commenti

```javascript
function hello() {
  return 'hi there';
}
```

## Normalizzare gli spazi bianchi

Quando il codice viene rappresentato, ciò che conta è l'_ordine_, non la sua posizione fisica.
Questo significa che gli spazi bianchi vengono normalizzati.
I seguenti esempi sono equivalenti:

### Esempio con indentazione di due spazi

```javascript
function hello() {
  return 'hello world';
}
```

### Esempio con indentazione di quattro spazi

```javascript
function hello() {
  return 'hello world';
}
```

### Esempio con un'indentazione particolare

```javascript
function hello() {
  return 'hello world';
}
```

## Normalizzare gli identificatori

Gli identificatori vengono normalizzati a un valore segnaposto.

### Prima

```javascript
const MY_CONSTANT = 42;

function answer(multiplier, addition = 1) {
  return MY_CONSTANT * multiplier + addition;
}
```

### Dopo

```javascript
const PLACEHOLDER_1 = 42;

function PLACEHOLDER_2(PLACEHOLDER_3, PLACEHOLDER_4 = 1) {
  return PLACEHOLDER_1 * PLACEHOLDER_3 + PLACEHOLDER_4;
}
```
