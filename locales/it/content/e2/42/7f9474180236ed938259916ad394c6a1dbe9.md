# Appendice alle istruzioni

La direzione verso cui è rivolto il robot sarà espressa con uno dei seguenti numeri:

- North = 0
- East = 1
- South = 2
- West = 3

Quando l'input non è valido, restituisci una direzione di -1 (gli altri valori verranno ignorati).

## Memoria riservata

Il buffer per la stringa di input usa i byte da 64 a 319 della memoria lineare.

La stringa di input può essere modificata, se lo desideri.
