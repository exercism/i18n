# Informazioni

Gli hash sono un tipo di dato di Perl che contiene una collezione non ordinata di chiavi di tipo stringa abbinate a valori scalari.

Di solito una variabile hash viene popolata assegnandole una lista, ad esempio `my %scores = (Alice => 10, Bob => 15, Charlie => 20);`.

Gli elementi di una lista si separano normalmente con virgole, ma capita spesso di vedere quella che viene chiamata «virgola grassa» `=>` per separare chiavi e valori in una lista.
Il suo comportamento è quasi identico a quello di una virgola, ma in più ha il vantaggio di interpretare l'elemento alla sua sinistra come una stringa.

Un hash si può popolare anche assegnando direttamente alle singole chiavi, ad esempio `$scores{Alice} = 10;`.

I valori di un hash si possono leggere specificando le chiavi tramite un pedice, ad esempio `$scores{Bob} # 15`.

Le chiavi di un hash sono uniche.
Se la stessa chiave viene indicata più volte, viene mantenuto solo l'ultimo valore assegnato.

## Funzioni

Tra le funzioni per lavorare con gli hash ci sono [keys][keys] e [values][values], che recuperano le rispettive parti di un hash sotto forma di lista.
Le liste restituite dalle funzioni [keys][keys] e [values][values] possono essere utili per funzioni sulle liste come [grep][grep], [map][map] e [sort][sort], oltre che per i cicli [for][for].

Altre funzioni sugli hash sono [exists][exists], che controlla se una chiave esiste in un hash (anche se il suo valore è `undef`), e [delete][delete], che rimuove una chiave da un hash.

## Variazione dei sigil

Quando si leggono i valori di un hash, è il sigil indicato a determinare il risultato.
Il pedice `{}` alla fine del nome della variabile è ciò che dice a Perl che stai accedendo a un hash con quel nome.

```perl
my %names = (Alice => 10, Bob => 15, Charlie => 20);

$names{Alice}; # 10            <- A scalar
@names{Alice}; # (10)          <- A slice (with only one key, this probably isn't what you want. There will be a warning.)
%names{Alice}; # ('Alice', 10) <- A key/index + value slice

$names{'Bob', 'Charlie'}; #                            <- An error (disabled syntax for an ancient feature.)
@names{'Bob', 'Charlie'}; # (15, 20)                   <- A slice
%names{'Bob', 'Charlie'}; # ('Bob', 15, 'Charlie', 20) <- A key/index + value slice
```

Anche se è consentito, per motivi di leggibilità è meglio non far condividere lo stesso nome a variabili di tipo diverso.
