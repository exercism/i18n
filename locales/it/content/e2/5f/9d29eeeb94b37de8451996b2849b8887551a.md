# Debug

Tutto l'output dello script Red è visibile nella console, quando esegui tutti i test. Puoi usare `print` per stampare quello che vuoi, per esempio i valori delle parole:

```red
print ["x =" x]
```

Inoltre, la funzione `probe` è molto utile. Quando viene valutata, valuta il suo input, stampa il risultato in un modo che ne riflette il tipo e lo restituisce. Quindi nella maggior parte dei casi è «trasparente» e puoi inserirla all'interno delle espressioni:

```red
x: 10
y: probe x + 5
```

A volte la funzione chiamata `type?` (sì, ha un punto interrogativo nel nome!) può essere utile per controllare il tipo di un valore:

```red
print ["x type:" type? x]
```

Ci sono anche alcune tecniche di debug più avanzate, [elencate sul Wiki di Red](https://github.com/red/red/wiki/%5BDOC%5D-Debugging).
