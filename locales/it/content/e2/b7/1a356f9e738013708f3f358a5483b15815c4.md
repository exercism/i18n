# Suggerimenti

## Generale

- Gli slice in Go hanno indici che partono da zero.
  Il primo indice di uno slice è `0`.
- La funzione predefinita [`append`][append-builtin] è [`variadic`][variadic-gobyexample]
- Puoi aggiungere gli elementi di uno slice a un altro slice usando la notazione con i tre punti:

```go
a := []int{1, 3}
b := []int{4, 2, 6}
c := append(a, b...)
fmt.Println(c)
// Output: [1 3 4 2 6]
```

## 1. Creare uno slice con determinate carte

- Per creare uno slice precompilato con alcuni dati, usa la notazione letterale dello slice: `s := []T{x1, x2, ..., xn}`.

## 2. Recuperare una carta da uno stack

- Per ottenere l'`n`-esimo elemento di uno slice [usa un indice][go-slices].
- Per verificare se un elemento esiste in uno slice, usa una condizione e confronta l'indice con la [lunghezza dello slice][len-builtin].

## 3. Scambiare una carta nello stack

- Per impostare l'`n`-esimo elemento di uno slice [usa un indice][go-slices] e assegnagli un nuovo valore.
- Per aggiungere un nuovo elemento alla fine di uno slice, usa la funzione `append`.

## 4. Aggiungere carte in cima allo stack

- Aggiungere elementi all'inizio di uno slice si può fare aggiungendo gli elementi dello slice originale allo slice passato come argomento `value`.

## 5. Rimuovere una carta dallo stack

- Rimuovere un elemento da uno slice si può fare aggiungendo la parte dopo `index` alla parte prima di index.
