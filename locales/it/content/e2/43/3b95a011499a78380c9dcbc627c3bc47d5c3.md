# Nil

Crystal ha un tipo chiamato [`Nil`][nil], che può avere un solo valore: `nil`.
Serve a rappresentare l'assenza di un valore ed è simile a `null` o `None` in altri linguaggi.

I valori di tipo Nil possono essere restituiti da vari metodi, ad esempio [`String#[]?`][string-index], che restituisce `nil` se l'indice è fuori dai limiti.

```crystal
"foo"[10]? # => nil
```

Crystal ha quello che è noto come **CONTROLLI SUI RIFERIMENTI NULLI**, il che significa che tutti i tipi non possono essere `nil` per impostazione predefinita.
Questo significa che non puoi assegnare `nil` a una variabile a meno che non la dichiari esplicitamente di tipo `Nil`.
Di conseguenza, il compilatore controllerà automaticamente i riferimenti nulli.

## Valore falsey

Si possono adottare diversi approcci per gestire i valori `nil`.
`nil` è un valore [falsey][truthy-falsey], così come `false`.
Questo significa che nelle istruzioni e in altri contesti in cui ci si aspetta un valore falsey o truthy, verrà trattato allo stesso modo di `false`.

```crystal
if nil
  puts "nil is truthy"
else
  puts "nil is falsey"
end

# => nil is falsey
```

Questo significa che il ramo truthy non verrà eseguito se una variabile che può essere `nil` ha un valore `nil`.

```crystal
foo = "boo"[2]? # It is possible that foo is nil
if foo
  p foo.class # => Char
end
```

## Controllo di nil

Crystal ha un metodo che può essere usato per controllare se un valore è `nil`.
Si chiama [`nil?`][nil?] ed è disponibile su tutti gli oggetti.

```crystal
foo = "boo"[2]?
if foo.nil?
  puts "foo is nil"
else
  puts "foo is not nil"
end
```

Questo è un po' diverso quando si usa direttamente il valore in un'istruzione if, perché negli ultimi esempi sia `false` che `nil` sarebbero stati trattati come falsi.
Qui solo `nil` viene trattato come falsey, dato che se fosse stato `false` non sarebbe stato `nil`, e quindi sarebbe stato truthy.

## Operatore or

Il modo più semplice per gestire i valori `nil` è assicurarsi che non diventino mai `nil` fin dall'inizio.
L'operatore or ([`||`][or]) viene spesso usato quando si ha a che fare con `Bools`, ma, se lo si capisce bene, può essere usato anche per gestire i valori `nil`.
L'operatore or controlla se il primo valore è truthy; in caso contrario, viene usato il secondo valore.
Si può usare per far sì che, se il valore è `nil`, venga considerato falsey e quindi venga usato il secondo valore.

```crystal
"foo"[10]? || "bar" # => "bar"
```
