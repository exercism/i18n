# Appendice alle istruzioni

## Formato dell'output

Ogni nazionalità è indicata con una singola lettera. (`E` = `Englishman`, `J` = `Japanese`, `N` = `Norwegian`, `S` = `Spaniard`, `U` = `Ukrainian`)

## Registri

| Registro | Utilizzo  | Tipo    | Descrizione                  |
| -------- | --------- | ------- | ---------------------------- |
| `$v0`    | output    | byte    | nazionalità di chi beve l'acqua |
| `$v1`    | output    | byte    | nazionalità del proprietario della zebra |
| `$t0-9`  | temporaneo | qualsiasi | per l'archiviazione temporanea |
