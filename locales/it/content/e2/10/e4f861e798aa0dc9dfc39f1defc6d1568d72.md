# Introduzione

Le [strutture][structs-and-classes] (comunemente chiamate *struct*) sono uno degli elementi costitutivi principali dei programmi Swift.
Le struct ti permettono di creare tipi personalizzati che raggruppano proprietà (dati) e metodi (comportamento) correlati.
Infatti, anche i tipi standard di Swift, tra cui `Int`, `Double`, `Bool`, `String`, `Array` e `Dictionary`, sono tutti implementati come struct.

## Definire le struct

Per definire una struct si usa la parola chiave `struct`, seguita dal nome del tipo e da parentesi graffe che ne contengono la definizione.
Per convenzione di Swift, i nomi delle struct usano `UpperCamelCase`:

```swift
struct CharacterStats {
    var health = 0.0
    var speed = 0
    var strength = 0
}
```

## Creare istanze

La definizione di una struct è uno schema.
Per creare un'*istanza* di una struct, chiama il suo inizializzatore scrivendo il nome del tipo seguito da una coppia di parentesi tonde:

```swift
var someStats = CharacterStats()
```

In questo modo si crea un'istanza popolata con i valori predefiniti delle proprietà presenti nella definizione.

Swift genera inoltre automaticamente un **inizializzatore membro per membro** per le struct, che ti permette di inizializzare le proprietà per nome:

```swift
let customStats = CharacterStats(health: 100.0, speed: 6, strength: 18)
```

## Accedere alle proprietà e modificarle

Puoi accedere alle proprietà di un'istanza e modificarle usando la *notazione con il punto*:

```swift
var stats = CharacterStats()

print(stats.health) // Prints 0.0

stats.health = 87.3
print(stats.health) // Prints 87.3
```

Poiché le struct sono tipi valore, per modificare le proprietà di un'istanza è necessario che l'istanza stessa sia dichiarata con `var`.
Se l'istanza è dichiarata con `let`, tutte le sue proprietà diventano immutabili.
