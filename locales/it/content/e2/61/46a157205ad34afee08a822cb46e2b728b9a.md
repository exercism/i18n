# Istruzioni

In questo esercizio sei un grande appassionato di sport e hai appena scoperto una passione per il basket NBA.
Dato che sei nuovo al basket NBA, ti stai addentrando nella storia della NBA, tenendo traccia di squadre, allenatori, le loro statistiche di vittorie e sconfitte e confrontandole tra loro.

Siccome non hai ancora una squadra del cuore, svilupperai anche un algoritmo per capire se tifare per una squadra in particolare.
Hai sette attività per aiutarti a sviluppare il tuo algoritmo proprietario _tifa-per-una-squadra_.

## 1. Definisci il modello

Definisci l'alias di tipo `Coach` per un record con i due campi seguenti, nell'ordine indicato:

- `name`: il nome dell'allenatore, di tipo `String`.
- `formerPlayer`: indica se l'allenatore era un ex giocatore, di tipo `Bool`.

Definisci l'alias di tipo `Stats` per un record con i due campi seguenti, nell'ordine indicato:

- `wins`: il numero di vittorie, di tipo `Int`.
- `losses`: il numero di sconfitte, di tipo `Int`.

Definisci l'alias di tipo `Team` per un record con i tre campi seguenti, nell'ordine indicato:

- `name`: il nome della squadra, di tipo `String`.
- `coach`: l'allenatore della squadra, di tipo `Coach`.
- `stats`: le statistiche della squadra, di tipo `Stats`.

## 2. Crea una squadra

Vuoi interfacciarti con del codice di terze parti che ha il concetto di squadra, ma che chiama il tuo codice con i parametri in un ordine diverso. Aggiungi una funzione `createTeam` con la seguente firma `String -> Stats -> Coach -> Team`.

## 3. Sostituisci l'allenatore

I proprietari delle squadre NBA sono impazienti, e hai scoperto che i cattivi risultati della squadra portavano spesso alla sostituzione dell'allenatore.
Implementa la funzione `replaceCoach` che prende come parametri il nuovo allenatore e la squadra, e restituisce la squadra con il nuovo allenatore:

```elm
let
    coach = { name = "Larry Bird", formerPlayer = True }
    stats = { wins = 58, losses =  24 }
    team = { name = "Indiana Pacers", coach = coach, stats =  stats }
    newCoach = { name = "Isiah Thomas", formerPlayer = True }
in
replaceCoach newCoach team
--> { name = "Indiana Pacers"
--  , coach = { name = "Isiah Thomas", formerPlayer = True }
--  , stats = { wins = 58, losses = 24 } }
```

## 4. Controlla se dovresti tifare per una squadra

In futuro hai in programma di ideare un algoritmo complicato per decidere se tifare o no per una squadra, ma per questo primo tentativo hai deciso che dovresti tifare per qualsiasi squadra che ha più vittorie che sconfitte.

Vuoi che questa funzione sia riutilizzabile in altri contesti, quindi usa un record estensibile nella firma del tipo per accettare qualsiasi record che abbia i campi rilevanti.
Per mantenere la funzione il più concisa possibile, vuoi usare il pattern matching per ottenere `stats` dal parametro della funzione.
Implementa la funzione `rootForTeam` che prende una squadra e restituisce `True` se dovresti tifare per quella squadra, altrimenti restituisce `False`.

```elm
let
    spursCoach = { name = "Gregg Popovich", formerPlayer =  False }
    spursStats = { wins = 56, losses = 26 }
    spursTeam = { name = "San Antonio Spurs", coach = spursCoach, stats = spursStats }
in
rootForTeam spursTeam
--> True
```
