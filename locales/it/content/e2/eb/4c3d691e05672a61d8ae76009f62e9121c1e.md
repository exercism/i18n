# Introduzione

## Type juggling

Il type juggling è anche noto come coercizione di tipo.
Il type juggling si verifica quando due valori di tipi diversi vengono forzati allo stesso tipo per eseguire un'operazione.

```php
$baskets = 5 // int
$apples_per_basket = "3" // string
$baskets * $apples_per_basket
# => 15
```

Questo può avvenire in modo implicito (vedi l'esempio sopra) oppure in modo esplicito con il cast di tipo in stile `C`:

```php
$apples_per_basket = "3" // string
$my_number = (int) $apples_per_basket // cast string to int
# => 3 // int
```

I tipi consentiti per il cast di tipo manuale sono: `bool`, `int`, `float`, `string`, `array`, `object`.
Più comunemente, il cast di tipo viene usato per convertire un numero intero (`int`) in un numero in virgola mobile (`float`) o viceversa.
