# Istruzioni

Sei un appassionato osservatore di uccelli che tiene traccia di quanti uccelli hanno visitato il tuo giardino in un giorno qualsiasi.

Hai deciso di portare l'osservazione degli uccelli a un nuovo livello e di implementare alcuni strumenti che ti aiuteranno a tenere traccia dei dati e a elaborarli.

Hai scelto di memorizzare i dati come un array di numeri interi. Il primo numero dell'array è il numero di uccelli che hanno visitato il tuo giardino oggi, il secondo quello di ieri, e così via.

## 1. Controlla quanti uccelli hanno visitato oggi

Implementa la funzione `BirdCount.today/1`. Dovrebbe ricevere un array di conteggi giornalieri di uccelli e restituire il conteggio di oggi. Se l'array è vuoto, dovrebbe restituire `nil`.

```elixir
BirdCount.today([2, 5, 1])
# => 2
```

## 2. Incrementa il conteggio di oggi

Implementa la funzione `BirdCount.increment_day_count/1`. Dovrebbe ricevere un array di conteggi giornalieri di uccelli e incrementare il conteggio di oggi di 1. Se l'array è vuoto, restituisci `[1]`.

```elixir
BirdCount.increment_day_count([4, 0, 2])
# => [5, 0, 2]
```

## 3. Controlla se c'è stato un giorno senza uccelli in visita

Implementa la funzione `BirdCount.has_day_without_birds?/1`. Dovrebbe ricevere un array di conteggi giornalieri di uccelli. Dovrebbe restituire `true` se c'è stato almeno un giorno in cui nessun uccello ha visitato il giardino, e `false` altrimenti.

```elixir
BirdCount.has_day_without_birds?([2, 0, 4])
# => true

BirdCount.has_day_without_birds?([3, 8, 1, 5])
# => false
```

## 4. Calcola il numero totale di uccelli in visita

Implementa la funzione `BirdCount.total/1`. Dovrebbe ricevere un array di conteggi giornalieri di uccelli e restituire il numero totale di uccelli che hanno visitato il tuo giardino da quando hai iniziato a raccogliere i dati.

```elixir
BirdCount.total([4, 0, 9, 0, 5])
# => 18
```

## 5. Calcola il numero di giorni intensi

Alcuni giorni sono più intensi di altri. Un giorno intenso è quello in cui cinque o più uccelli hanno visitato il tuo giardino.

Implementa la funzione `BirdCount.busy_days/1`. Dovrebbe ricevere un array di conteggi giornalieri di uccelli e restituire il numero di giorni intensi.

```elixir
BirdCount.busy_days([4, 5, 0, 0, 6])
# => 2
```
