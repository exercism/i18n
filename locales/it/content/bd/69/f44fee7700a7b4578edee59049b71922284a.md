# Istruzioni

In questo esercizio, aiuterai due innamorati del liceo a dichiarare il loro amore sui social media, generando un cuore unicode con le loro iniziali:

```
❤ J.  +  M. ❤
```

## 1. Pulisci il nome

Implementa il metodo `cleanupname`.
Deve prendere un nome e rimuovere tutti i caratteri `-`, sostituendoli con uno spazio.
Deve anche rimuovere gli spazi bianchi all'inizio e alla fine del nome.

```julia-repl
julia> cleanupname("Jane-Ann")
"Jane Ann"
```

## 2. Ottieni la prima lettera del nome

Implementa il metodo `firstletter`.
Deve prendere un nome e restituire la sua prima lettera come stringa.
Assicurati di riutilizzare `cleanupname`, che hai definito nel passo precedente, e di comporla con altre funzioni.

```julia-repl
julia> firstletter("Jane")
"J"
```

## 3. Formatta la prima lettera come iniziale

Implementa il metodo `initial`.
Deve prendere un nome e restituire la sua prima lettera, in maiuscolo, seguita da un punto.
Assicurati di riutilizzare `firstletter`, che hai definito nel passo precedente.

```julia-repl
initial("Robert")
"R."
```

## 4. Metti le iniziali dentro il cuore

Implementa il metodo `couple`.
Deve prendere due nomi e restituire le iniziali con intorno i cuori emoji.
Assicurati di riutilizzare `initial`, che hai definito nel passo precedente.

```julia-repl
couple("Blake Miller", "Riley Lewis")
"❤ B.  +  R. ❤"
```
