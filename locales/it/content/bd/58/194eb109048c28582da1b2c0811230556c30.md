# Introduzione

Una _stringa_ è il tipo di dati di JavaScript che serve a memorizzare dati testuali.

## Creare una stringa

Si crea una stringa racchiudendo il testo tra virgolette singole o virgolette doppie.
Su Exercism si usano le virgolette singole.

<!-- prettier-ignore-start -->
```javascript
'Hello, World!'
"Hello, World!"
```
<!-- prettier-ignore-end -->

## Le stringhe come array di caratteri

Una stringa può essere trattata come un array di caratteri, dove il primo carattere ha indice `0`.
Puoi accedere a un singolo carattere della stringa usando le parentesi quadre (`[]`) e l'indice della lettera che vuoi recuperare.

```javascript
'cat'[1];
// => 'a'
```

Puoi determinare il numero di caratteri di una stringa accedendo alla proprietà `length`.

```javascript
'cat'.length;
// => 3
```

## Concatenazione e metodi

Il modo più semplice per concatenare le stringhe è usare l'operatore di addizione `+`.

```javascript
'I like' + ' ' + 'cats.';
// => "I like cats."
```

Le stringhe offrono molti metodi ausiliari: per un elenco completo, vedi [i documenti MDN sui metodi delle stringhe][mdn-string-methods].
Il seguente elenco mostra alcuni metodi ausiliari di uso comune.

- [`toUpperCase`][mdn-to-upper-case] e [`toLowerCase`][mdn-to-lower-case]: trasformano tutti i caratteri in maiuscolo o in minuscolo
- [`trim`][mdn-trim]: rimuove gli spazi bianchi all'inizio e alla fine
- [`includes`][mdn-includes], [`startsWith`][mdn-starts-with] e [`endsWith`][mdn-ends-with]: determinano se un'altra stringa fa parte della stringa data
- [`slice`][mdn-slice]: estrae una sezione della stringa

Le stringhe sono immutabili in JavaScript. Quindi una «modifica», ad esempio tramite alcuni dei metodi qui sopra, crea sempre una nuova stringa.
