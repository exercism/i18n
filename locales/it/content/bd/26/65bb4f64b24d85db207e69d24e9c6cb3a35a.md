# Debug

Quando un test fallisce, viene mostrato un messaggio che descrive cosa è andato storto e per quale input.
Puoi ispezionare valori arbitrari nel tuo programma passandoli al metodo `debug` (disponibile in `exercism/test_runner`).
Questo catturerà i valori e ti mostrerà l'output.


```gleam
import exercism/test_runner.{ debug }

let value: String = "test"
debug("The value is " <> value)
```
