# Introduzione

Un [array][list] è una collezione mutabile di elementi in _sequenza_.
Si tratta di una struttura dati estremamente flessibile e utile, che molti metodi e operazioni `built-in` di Python producono come output.
Gli array possono contenere riferimenti a qualsiasi tipo di dato (o a più tipi), compresi altri array o strutture dati come le tuple, i set o i dict.
Il contenuto si può iterare usando il costrutto `for item in <list>`.
Se servono anche gli indici, si può usare `for index, item in enumerate(<list>)`.
Agli elementi di un `list` si può accedere con un numero `0-based index` da sinistra, oppure con un numero `-1-based index` da destra.
Gli array si possono copiare interamente o in parte usando la _notazione di slicing_ o `<list>.copy()`.
