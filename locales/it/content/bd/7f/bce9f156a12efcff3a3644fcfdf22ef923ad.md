# CLI

Puoi eseguire i test aprendo un prompt dei comandi nella cartella dell'esercizio e poi lanciando il [comando `stack test`][docs-stack-test]. Se il codice compila, questo comando ti mostrerà quali test sono passati e quali sono falliti: quando un test fallisce, prova a farlo passare ed esegui di nuovo i test.

Una volta che tutti i test passano, puoi inviare la soluzione aprendo un prompt dei comandi nella cartella dell'esercizio e lanciando il [comando `exercism submit`][docs-exercism-cli].

[docs-stack-test]: https://docs.haskellstack.org/en/stable/build_command/
[docs-exercism-cli]: https://exercism.io/cli
