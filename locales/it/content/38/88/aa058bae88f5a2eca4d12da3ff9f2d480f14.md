# Informazioni

Swift fornisce un tipo integrato chiamato [`Bool`][bools] per rappresentare i valori di verità: `true` e `false`.

## Operatori logici

Swift fornisce tre [operatori logici][logical-operators] (`!`, `&&` e `||`) per combinare e valutare espressioni booleane.

### L'operatore AND logico (`&&`)

L'[operatore _and_][and] (`&&`) restituisce `true` solo se entrambi gli operandi sono `true`.
Se uno dei due operandi è `false`, restituisce `false`.
Metti un'espressione o un valore booleano su ciascun lato del simbolo `&&`:

```swift
true && true  // true
true && false // false
```

### L'operatore OR logico (`||`)

L'[operatore _or_][or] (`||`) restituisce `true` se **almeno uno** degli operandi è `true`.
Restituisce `false` solo quando entrambi gli operandi sono `false`.
Metti un'espressione o un valore booleano su ciascun lato del simbolo `||`:

```swift
true || true   // true
true || false  // true
false || false // false
```

### L'operatore NOT logico (`!`)

L'[operatore _not_][not] (`!`) inverte un valore booleano.
Restituisce `true` se il valore è `false`, e `false` se il valore è `true`.
Metti l'operatore `!` subito prima del valore o dell'espressione:

```swift
!true  // false
!false // true
```

## Usare le parentesi (`()`)

Puoi usare le [parentesi][explicit-parentheses] per raggruppare le espressioni e controllare l'ordine di valutazione.
In Swift, le espressioni tra parentesi vengono valutate per prime:

```swift
true && false && false || true   // true
true && false && (false || true) // false
```

Il raggruppamento con le parentesi determina anche come l'operatore NOT si applica alle espressioni complesse:

```swift
!true && false   // false (evaluates (!true) first, then false && false)
!(true && false) // true  (evaluates (true && false) first to false, then !false)
```

~~~~exercism/note
Usa le parentesi quando devi chiarire l'ordine di valutazione o rendere più leggibili le condizioni complesse.
Evita di aggiungere parentesi inutili quando la precedenza predefinita è già chiara.
~~~~
