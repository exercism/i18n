# Introduzione

Quando Elixir individua la funzione da chiamare, usa il nome del modulo per eseguire una ricerca. La ricerca può essere fatta dinamicamente se il nome del modulo è associato a una variabile.

```elixir
defmodule MyModule do
  def message(), do: "My message"
end

atom = MyModule
atom.message()
# => "My message"
```

Internamente, il nome di un modulo è un atomo. Tutti gli atomi dei moduli Elixir hanno automaticamente il prefisso `Elixir.`

```elixir
is_atom(Enum)
# => true
Enum == Elixir.Enum
# => true
```
