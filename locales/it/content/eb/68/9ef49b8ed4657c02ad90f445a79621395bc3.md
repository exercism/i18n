# Informazioni

In Factor, la maggior parte delle iterazioni si esprime con i combinatori (`each`, `map`, `reduce`), ma la ricorsione esplicita ha ancora il suo posto: quando la ricorsione non ha la forma di una lista, quando il caso base non è banale, o quando sei tu a implementare un combinatore.

```factor
: total ( seq -- sum )
    [ 0 ] [ unclip swap total + ] if-empty ;

: gcd ( a b -- g )
    dup zero? [ drop ] [ tuck mod gcd ] if ;
```

Alcune cose da sapere:

- Le definizioni `:` semplici possono ricorrere senza alcuna sintassi speciale. Il compilatore inferisce gli effetti sullo stack attraverso la chiamata ricorsiva.
- `loop ( quot -- )` ti permette di iterare una quotation che restituisce un booleano: continua finché il valore è vero.
- Le chiamate in coda vengono compilate in salti, quindi le word profondamente ricorsive non fanno esplodere lo stack.

La coppia `unclip` / `if-empty` è la forma standard della ricorsione sulle sequenze; `cond` è la forma standard per la selezione tra più casi.
