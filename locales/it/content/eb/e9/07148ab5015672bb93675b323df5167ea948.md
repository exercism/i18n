# Test

Per testare la soluzione, basta **eseguire lo script di test**. Puoi farlo da Red Console usando la funzione `do` insieme al percorso dello script di test, in questo modo:

```red
do %exercism/red/hello-world/hello-world-test.red
```

Oppure basta aggiungerlo come argomento al binario Red nel terminale del sistema:

```shell
red exercism/red/hello-world/hello-world-test.red
```

Inizialmente, sarà abilitato solo il primo test del file di test. Lo scopo è incoraggiarti a risolvere gli esercizi uno alla volta. Una volta che il primo test passa, cambia il secondo *argomento* della funzione `test-init` all'inizio del file di test e rieseguilo. Questo valore indica il numero di test abilitati: se lo cambi da `1` a `2`, abiliterai il secondo test. Puoi anche rimuovere il refinement `\limit` della funzione `test-init` e il secondo argomento, per eseguire tutti i test senza saltarne nessuno.
