# Appendice alle istruzioni

## Registri

| Registro | Utilizzo     | Tipo      | Descrizione                                      |
| -------- | ------------ | --------- | ------------------------------------------------ |
| `$a0`    | input        | intero    | numero di monete in input                        |
| `$a1`    | input        | intero    | obiettivo                                        |
| `$a2`    | input/output | indirizzo | array sovrascrivibile di word di monete          |
| `$v0`    | output       | intero    | numero di monete in output, -1 se l'input non è valido |
| `$t0-9`  | temporaneo   | qualsiasi | usato come memoria temporanea                    |
