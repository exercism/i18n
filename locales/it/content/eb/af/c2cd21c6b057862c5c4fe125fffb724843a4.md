# Indice delle rune usato con i byte

Iterare su `runes` e usare l'indice per ottenere singoli `bytes` è sicuro in questo caso,
perché l'input è composto interamente da caratteri ASCII.
Per vedere cosa succede quando si usano caratteri non ASCII, aggiungi questo caso di test:

```go
{
	s1:          "aüa",
	s2:          "aÃa",
	want:        1,
	expectError: false,
}
```
