# Appendice alle istruzioni

## Registri

| Registro | Uso          | Tipo    | Descrizione                                  |
| -------- | ------------ | ------- | -------------------------------------------- |
| `$a0`    | input        | indirizzo | stringa del nome terminata da null, oppure un puntatore nullo |
| `$a1`    | input/output | indirizzo | stringa del risultato terminata da null                |
| `$t0-9`  | temporaneo   | qualsiasi | per l'archiviazione temporanea                        |
