# Istruzioni

In questo esercizio, implementerai un modo per tenere traccia dei punteggi più alti del gioco più popolare della tua sala giochi.

Devi implementare 5 funzioni, per lo più legate alla manipolazione di un oggetto che contiene i punteggi più alti.

## 1. Creare un nuovo tabellone dei punteggi più alti

Crea una funzione `createScoreBoard` che crea un oggetto che funge da tabellone dei punteggi più alti.
Le chiavi di questo oggetto saranno i nomi dei giocatori, i valori saranno i loro punteggi.
Per motivi di test, vuoi includere direttamente una voce nell'oggetto.
Questa voce iniziale deve consistere in `The Best Ever` come nome del giocatore e `1000000` come punteggio.

```javascript
createScoreBoard();
// returns an object with one initial entry
```

## 2. Aggiungere giocatori a un tabellone dei punteggi

Per aggiungere un giocatore al tabellone dei punteggi più alti, definisci la funzione `addPlayer`.
Accetta 3 parametri:

- Il primo parametro è un oggetto tabellone dei punteggi esistente.
- Il secondo parametro è il nome di un giocatore, come stringa.
- Il terzo parametro è il punteggio, come numero.

La funzione restituisce lo stesso oggetto tabellone dei punteggi che le è stato passato, dopo aver aggiunto il nuovo giocatore.

```javascript
addPlayer({ 'Dave Thomas': 0 }, 'José Valim', 486373);
// => {'Dave Thomas': 0, 'José Valim': 486373}
```

## 3. Rimuovere giocatori da un tabellone dei punteggi

Se i giocatori violano le regole della sala giochi, vengono rimossi manualmente dal tabellone dei punteggi più alti.
Definisci `removePlayer`, che accetta 2 parametri:

- Il primo parametro è un oggetto tabellone dei punteggi esistente.
- Il secondo parametro è il nome del giocatore, come stringa.

Questa funzione deve rimuovere dal tabellone la voce relativa al giocatore indicato e restituire poi il tabellone.
Se il giocatore non era presente sul tabellone, non deve succedere nulla al tabellone.
Va restituito così com'è.

```javascript
removePlayer({ 'Dave Thomas': 0 }, 'Dave Thomas');
// => {}

removePlayer({ 'Dave Thomas': 0 }, 'Rose Fanaras');
// => { 'Dave Thomas': 0 }
```

## 4. Aumentare il punteggio di un giocatore

Se un giocatore termina un'altra partita alla sala giochi, una certa quantità di punti verrà aggiunta al punteggio precedente sul tabellone.
Implementa `updateScore`, che accetta 3 parametri:

- Il primo parametro è un oggetto tabellone dei punteggi esistente.
- Il secondo parametro è il nome del giocatore il cui punteggio deve essere aumentato.
- Il terzo parametro è il punteggio che vuoi **aggiungere** al punteggio più alto memorizzato.

La funzione deve restituire il tabellone dei punteggi dopo che l'aggiornamento è stato eseguito.

```javascript
updateScore({ 'Freyja Ćirić': 12771008 }, 'Freyja Ćirić', 73);
// => {"Freyja Ćirić", 12771081}
```

## 5. Applicare i punti bonus del lunedì

La sala giochi tiene un tabellone dei punteggi separato il lunedì.
Alla fine della giornata, ogni giocatore su quel tabellone riceve 100 punti aggiuntivi.

Implementa la funzione `applyMondayBonus`, che accetta un tabellone dei punteggi.
La funzione aggiunge i punti bonus per ogni giocatore elencato su quel tabellone.
Poi, il tabellone viene restituito.

```javascript
const scoreBoard = {
  'Dave Thomas': 44,
  'Freyja Ćirić': 539,
  'José Valim': 265,
};

applyMondayBonus(scoreBoard);
// => { 'Dave Thomas': 144, 'Freyja Ćirić': 639, 'José Valim': 365 }
```
