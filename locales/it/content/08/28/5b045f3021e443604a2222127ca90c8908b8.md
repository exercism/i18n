# Informazioni

In Go possiamo confrontare i valori usando gli operatori di uguaglianza e di ordinamento.
Ne abbiamo 6:

| Confronto       | Operatore |
| --------------- | --------- |
| uguale          | `==`      |
| diverso         | `!=`      |
| minore          | `<`       |
| minore o uguale | `<=`      |
| maggiore        | `>`       |
| maggiore o uguale | `>=`    |

Il risultato di un confronto è sempre un valore booleano:

```go
a := 3

a != 4 // true
a > 5  // false
```

## Operatori di uguaglianza

Gli operatori di uguaglianza `==` e `!=` verificano rispettivamente se un valore è uguale a un altro oppure no.
Possiamo usare gli operatori di uguaglianza sulla maggior parte dei tipi in Go.
Ecco alcuni esempi comuni:

```go
2 == 3 // false, integer comparison

2.1 != 2.2 // true, float comparison 

"hello" == "hello" // true, string comparison

'a' != 'b' // true, rune/byte comparison
```

## Operatori di ordinamento

Gli operatori di ordinamento verificano se un valore è maggiore di (`>`), maggiore o uguale a (`>=`), minore di (`<`) o minore o uguale a (`<=`) un altro valore.
Questo tipo di confronto è disponibile per numeri, byte, rune e stringhe.
Quando si confrontano le stringhe, si segue l'ordine alfabetico (noto anche come ordine lessicografico).

```go
2 > 3 // false, integer comparison

1.2 < 1.3 // true, float comparison

'a' > 'b' // false, rune/byte comparison

"Hello" < "World" // true, string comparison
```
