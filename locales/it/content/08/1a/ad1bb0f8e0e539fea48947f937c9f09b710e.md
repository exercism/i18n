# Istruzioni

In questo esercizio simulerai un sistema informatico basato su finestre.
Creerai alcune finestre che si possono spostare e ridimensionare e che mostrano il loro contenuto.
L'immagine seguente è rappresentativa dei valori con cui lavorerai qui sotto.

       |          ║          position.y  \                                     ║
       |          ║                       \<----- size.width ----->            ║
       |          ║                 ^      *──────────────────────┐            ║

## 1. Definisci una struct Size

Definisci una struct di nome `Size` con due proprietà `Int`, `width` e `height`, che memorizzano rispettivamente la larghezza e l'altezza attuali della finestra.
La larghezza e l'altezza iniziali devono essere rispettivamente 80 e 60.
Includi un metodo `resize(newWidth:newHeight:)` che accetta come parametri la nuova larghezza e la nuova altezza e modifica le proprietà per riflettere le nuove dimensioni.

```swift
let size1080x764 = Size(width: 1080, height: 764)
// Returns Size
var size1200x800 = size1080x764
// Returns Size
size1200x800.resize(newWidth: 1200, newHeight: 800)
size1200x800.height
// Returns 800
```

## 2. Definisci una struct Position

Definisci una struct di nome `Position` con due proprietà `Int`, `x` e `y`, che memorizzano rispettivamente la posizione orizzontale e verticale attuali dell'angolo in alto a sinistra della finestra.
I valori iniziali di x e y devono essere entrambi 0. La posizione (0, 0) è l'angolo in alto a sinistra dello schermo: i valori di `x` aumentano man mano che ci si sposta verso destra e i valori di `y` aumentano man mano che ci si sposta verso il basso.

Includi un metodo `moveTo(newX:newY:)` che accetta come parametri la nuova x e la nuova y e modifica le proprietà per riflettere la nuova posizione.

```swift
var point = Position(x: 10, y: 20)
// Returns Position
point.moveTo(newX: 100, newY: -100)
point.y
// Returns -100
```

## 3. Definisci una classe Window

Definisci una classe Window con le seguenti proprietà:

- `title` : `String`, il valore iniziale è "New Window"
- `screenSize` : `Size`, valore costante con `width` = 800 e `height` = 600
- `size` : `Size`, il valore iniziale è quello predefinito della struct `Size`
- `position` : `Position`, il valore iniziale è quello predefinito della struct `Position`
- `contents` : `String?`, il valore iniziale è `nil`

Definisci anche un inizializzatore vuoto per la classe.

```swift
let window = Window()
window.title
// Returns "New Window"
```

## 4. Aggiungi un metodo per ridimensionare le finestre

- `resize(to:)` : `(Size) -> ()`. Questo metodo accetta come input una struct `Size` e prova a ridimensionare la finestra alle dimensioni specificate. Tuttavia, le nuove dimensioni non possono superare certi limiti. 
- L'altezza o la larghezza minime consentite sono 1.
  Altezze o larghezze richieste inferiori a 1 vengono ridotte a 1.
- L'altezza e la larghezza massime dipendono dalla posizione attuale della finestra: i bordi della finestra non possono oltrepassare i bordi dello schermo. 
  I valori superiori a questi limiti vengono ridotti alla dimensione massima possibile.
  Ad esempio, se la posizione della finestra è `x` = 400, `y` = 300 e viene richiesto un ridimensionamento a `height` = 400, `width` = 300, la finestra verrà ridimensionata a `height` = 300, `width` = 300, perché lo schermo non è abbastanza grande nella direzione `y` per soddisfare completamente la richiesta.

## 5. Aggiungi un metodo per spostare le finestre

- `move(to:)` : `(Position) -> ()`. È simile a `resize(to:)`, ma questo metodo regola la _posizione_ della finestra al valore richiesto, non le dimensioni. Come per `resize`, la nuova posizione non può superare certi limiti.
- La posizione minima è 0 sia per `x` che per `y`.
- La posizione massima in entrambe le direzioni dipende dalle dimensioni attuali della finestra: i bordi non possono oltrepassare i bordi dello schermo.
       I valori superiori a questi limiti vengono ridotti alla dimensione massima possibile. Ad esempio, se le dimensioni della finestra sono `x` = 250, `y` = 100 e viene richiesto uno spostamento a `x` = 600, `y` = 200, la finestra verrà spostata a `x` = 550, `y` = 200, perché lo schermo non è abbastanza grande nella direzione `x` per soddisfare completamente la richiesta.

## 6. Aggiungi metodi per aggiornare il testo della finestra e mostrare le informazioni sulla finestra

- `update(title:)` : `(String) -> ()`. Questo metodo imposta la proprietà `title` al valore della stringa passata.
- `update(text:)` : `(String?) -> ()`. Questo metodo imposta la proprietà `contents` al valore della stringa opzionale passata.
- `display()` : `() -> String`. Questo metodo restituisce una stringa che descrive lo stato attuale della finestra. Ad esempio, se la finestra ha il `title` "My First Window" con posizione: x = 10, y = 100; dimensioni: width = 200, height = 150; e contents: "I 😍 my window", dovrebbe restituire la stringa: `"My First Window\nPosition: (10, 100), Size: (200 x 150)\nI 😍 my window\n"`. Se `contents` è nil, l'ultima riga dovrebbe essere "[This window intentionally left blank]"

## 7. Crea un inizializzatore per la classe Window

Il sistema a finestre dovrebbe avere un inizializzatore che permetta di creare la finestra con input personalizzati.
Crea un **altro** inizializzatore per la classe `Window`.
L'inizializzatore dovrebbe accettare i seguenti parametri: `title`, `contents` e due parametri opzionali, `size` e `position`.
I parametri `size` e `position` dovrebbero avere come valori predefiniti quelli predefiniti delle struct `Size` e `Position`.

```swift
let window = Window(title: "My First Window", contents: "I 😍 my window")
window.display()
// Returns "My First Window\nPosition: (0, 0), Size: (80 x 60)\nI 😍 my window\n"

let window2 = Window(title: "My Second Window", contents: "I 😍 my window", size: Size(width: 200, height: 150), position: Position(x: 10, y: 100))
window2.display()
// Returns "My Second Window\nPosition: (10, 100), Size: (200 x 150)\nI 😍 my window\n"
```
