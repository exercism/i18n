# Introduzione

Il flusso di controllo in Cairo ti permette di controllare il percorso di esecuzione dei tuoi programmi in base a condizioni e ripetizioni.

## Esecuzione condizionale

Usa le espressioni `if` per eseguire del codice in base a delle condizioni:

```rust
let number = 42;
if number > 0 {
    println!("Positive number");
} else if number < 0 {
    println!("Negative number");  
} else {
    println!("Zero");
}
```

`if` è un'espressione, quindi può restituire dei valori:

```rust
let result = if condition { 5 } else { 10 };
```

## Cicli

Usa `loop` per ripetere del codice.
Un ciclo viene eseguito all'infinito, a meno che tu non lo fermi; usa `break` per uscire dal ciclo quando una condizione è soddisfatta.

```rust
let mut counter = 0;
loop {
    if counter == 5 {
        break;
    }
    println!("Counter: {}", counter);
    counter += 1;
}
```

I cicli possono restituire dei valori usando `break`:

```rust
let result = loop {
    counter += 1;
    if counter == 10 {
        break counter * 2; // Returns 20
    }
};
```

Usa `continue` per passare all'iterazione successiva:

```rust
let mut i = 0;
loop {
    i += 1;
    if i % 2 == 0 {
        continue; // Skip even numbers
    }
    if i > 10 {
        break;
    }
    println!("{}", i); // Only prints odd numbers
}
```
