# Approfondimento sulle nozioni di base

Il concetto Nozioni di base ha introdotto [Go](https://golang.org) come linguaggio di programmazione compilato e a tipizzazione statica.
Il linguaggio viene spesso chiamato Golang per via del suo precedente nome di dominio, golang.org, ma il nome corretto è Go.

Il concetto Nozioni di base introduce tre caratteristiche principali del linguaggio: pacchetti, funzioni e variabili.

## Pacchetti

Le applicazioni Go sono organizzate in pacchetti.
Un pacchetto è un insieme di file sorgente che si trovano nella stessa directory.
Tutti i file sorgente in una directory devono condividere lo stesso nome di pacchetto.
Per convenzione, il nome del pacchetto è l'ultima directory del percorso di importazione.
Ad esempio, i file del [pacchetto "math/rand"](https://golang.org/src/math/rand/) iniziano con l'istruzione `package rand`.
Quando si importa un pacchetto, è possibile usare o accedere solo alle entità (funzioni, tipi, variabili, costanti) i cui nomi iniziano con una lettera maiuscola.
Lo stile consigliato per i nomi in Go è usare `camelCase` per gli identificatori, tranne quelli che devono essere accessibili tra pacchetti, per i quali si usa `PascalCase`.

```go
package lasagna
```

## Variabili

Go è a tipizzazione statica: tutte le variabili [devono avere un tipo definito](https://en.wikipedia.org/wiki/Type_system) al momento della compilazione.

Le variabili si possono definire specificando esplicitamente un tipo:

```go
var explicit int // Explicitly typed
```

Puoi anche usare un inizializzatore, e il compilatore assegnerà alla variabile il tipo corrispondente a quello dell'inizializzatore.

```go
implicit := 10   // Implicitly typed as an int
```

Una volta dichiarata, a una variabile si possono assegnare valori usando l'operatore `=`.
Una volta dichiarata, il tipo di una variabile non può mai cambiare.

```go
count := 1 // Assign initial value
count = 2  // Update to new value

count = false // This throws a compiler error due to assigning a non `int` type
```

## Costanti

Le costanti contengono un dato proprio come le variabili, ma il loro valore non può cambiare durante l'esecuzione del programma.

Le costanti si definiscono con la parola chiave `const` e possono essere numeri, caratteri, stringhe o valori booleani:

```go
const Age = 21 // Defines a numeric constant 'Age' with the value of 21
```

## Funzioni

Le funzioni Go accettano zero o più parametri.
I parametri devono avere un tipo esplicito: non c'è inferenza di tipo.

I valori vengono restituiti dalle funzioni usando la parola chiave `return`.

Una funzione si chiama specificando il nome della funzione e passando un argomento per ciascuno dei suoi parametri.

Tieni presente che Go supporta due tipi di commenti.
I commenti su una sola riga sono preceduti da `//`, mentre i commenti su più righe si inseriscono tra `/*` e `*/`.

```go
package greeting

// Hello is a public function.
func Hello (name string) string {
    return hi(name)
}

// hi is a private function.
func hi (name string) string {
    return "hi " + name
}
```
