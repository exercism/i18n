# Installazione


## Ottenere GHCup

Il modo consigliato per installare gli strumenti di Haskell è tramite [GHCup][ghcup].

Con GHCup puoi gestire i compilatori installati, i gestori di progetti e pacchetti e il language server.


## Installare Stack

Per svolgere gli esercizi di Exercism ti serve solo Stack.

Per installare Stack, esegui il comando o lo script di installazione di GHCup.
Segui le impostazioni predefinite, ma specifica che vuoi installare anche Stack.

Hai saltato per sbaglio l'installazione di Stack?
Non preoccuparti: esegui semplicemente `ghcup install stack` in un secondo momento.

GHCup installerà

- **Un compilatore** (GHC: il Glasgow Haskell Compiler)

  A rigor di termini non ti serve per Exercism, ma torna utile quando vuoi giocare con [GHCi][ghc-guide-ghci] al di fuori delle directory degli esercizi.

- **Cabal**

  Un gestore di progetti e pacchetti.
  Per Exercism non ti serve.

- **Stack**

  Il gestore di progetti e pacchetti che userai per Exercism.
  Si assicurerà che tu abbia il compilatore e le librerie giusti per ogni singolo progetto (esercizio).

Per verificare che l'installazione sia andata a buon fine, esegui uno dei due comandi

- `ghcup list`: se ha successo, vedrai un lungo elenco di versioni degli strumenti, con Stack contrassegnato come installato
- `stack --version`: se ha successo, vedrai `Version 2.7.5, Git revision ...`


## Ottenere la versione giusta di GHC

Stack scaricherà e installerà GHC automaticamente quando serve.
Puoi avviare l'installazione e verificarla eseguendo i comandi seguenti in un terminale:

```bash
# Note: it only makes sense to run Stack
# inside projects, so navigate into an
# exercise directory first!
exercism download --exercise=hello-world --track=haskell
cd ~/Exercism/haskell/hello-world
stack ghc -- --version
```

Se l'output è qualcosa come

```
The Glorious Glasgow Haskell Compilation System, version 8.8.4
```

allora GHC è installato correttamente.


## Configurare l'editor per lavorare con Haskell

Il supporto per Haskell è fornito dall'Haskell Language Server (HLS).
Il supporto per il linguaggio non è obbligatorio, ma è vivamente consigliato.


### Visual Studio Code (consigliato)

Ti basta installare l'[estensione Haskell per Visual Studio Code][vscode-haskell].
Userà GHCup per installare HLS automaticamente, dopodiché sarà tutto pronto.

**Nota:** con esercizi appena scaricati, HLS potrebbe avere problemi ad avviarsi.
In questo caso, esegui `stack test` e riavvia il language server.


### Altri editor

Consulta la [documentazione di HLS sulla configurazione dell'editor][hls-editor-config].
Potrebbe essere necessario installare HLS manualmente.
In tal caso, esegui `ghcup install hls`.
