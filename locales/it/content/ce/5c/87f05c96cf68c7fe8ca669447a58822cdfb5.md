# Introduzione

Il sistema di errori di Factor è composto da tre parti: `throw` (in [`kernel`][kernel]) solleva un errore, `recover` (in [`continuations`][continuations]) ne intercetta uno, ed `ERROR:` definisce una classe di errore tipizzata come tuple.

```factor
! "file not found" throw          (raises a string as the error)

[ "boom" throw ] [ drop "caught" ] recover .
! => "caught"
```

`recover ( try recovery -- )` esegue la *quotation* try; se questa solleva un errore, l'errore viene impilato e viene eseguita la *quotation* recovery.

`ERROR:` dichiara sia la classe *sia* una parola costruttrice che solleva una nuova istanza:

```factor
! DOCTEST: SKIP
ERROR: not-found path ;

"/missing" not-found
! throws T{ not-found { path "/missing" } }
```

[continuations]: https://docs.factorcode.org/content/vocab-continuations.html
