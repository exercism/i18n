# Introduzione

In Haxe, `String` è un oggetto che rappresenta testo immutabile come una sequenza di caratteri Unicode (lettere, cifre, punteggiatura, ecc.). Per definire un'istanza di `String` si usano le virgolette doppie:

```haxe
var fruit:String = "Apple";
```

Le stringhe si manipolano chiamando i metodi della stringa. Una volta creata una stringa, il suo valore non può mai cambiare. Tutti i metodi che sembrano modificare una stringa in realtà restituiscono una nuova stringa.

Più stringhe si possono concatenare (sommare) tra loro. Il modo più semplice per farlo è usare l'operatore `+`.

```haxe
var name:String = "Jane";
trace("Hello " + name + "!");
// => "Hello Jane!"
```

Per qualsiasi formattazione di stringhe più complessa di una semplice concatenazione, è preferibile l'interpolazione di stringhe. Per usare l'interpolazione in una stringa, racchiudila tra virgolette singole (`'`). Poi usa il simbolo del dollaro (`$`) per attivare l'interpolazione:

```haxe
var name:String = "Jane";
trace('Hello $name!');
// => "Hello Jane!"
```
