# Suggerimenti

## 1. Analizzare la data dell'appuntamento

- La classe `LocalDateTime` ha un metodo per [analizzare][localdatetime-parse] una `String` in un `LocalDateTime`.
- Usa un [`DateTimeFormatter`][datetimeformatter-docs] con un pattern personalizzato per analizzare un formato di data e ora non standard.

## 2. Verificare se un appuntamento è già passato

- Le istanze di `LocalDateTime` hanno dei [metodi][localdatetime-methods] per confrontarle con altri `LocalDateTime`.
- C'è un [metodo][localdatetime-methods] per ottenere la data e l'ora corrente.

## 3. Verificare se l'appuntamento è nel pomeriggio

- Per accedere alla parte relativa all'ora di un'istanza di `LocalDateTime` puoi usare uno dei suoi [metodi][localdatetime-methods].

## 4. Descrivere l'ora e la data dell'appuntamento

- Usa un [`DateTimeFormatter`][datetimeformatter-docs] con un pattern personalizzato per formattare il `LocalDateTime`.
- I test vengono eseguiti come se girassero su una macchina negli Stati Uniti, quindi assicurati che il formatter [usi la locale corretta][datetimeformatter-ofpattern-with-locale].

## 5. Restituire la data dell'anniversario

- La classe `LocalDate` ha un [metodo][localdate-methods] per ottenere la data corrente.
- Per accedere all'anno di un'istanza di `LocalDate` puoi usare uno dei suoi [metodi][localdate-methods].
