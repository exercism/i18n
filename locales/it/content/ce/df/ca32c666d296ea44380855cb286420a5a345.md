# API di Exercism

## Descrizione

Molti track di linguaggi su Exercism usano lo strumento a riga di comando `exercism` per recuperare e inviare esercizi, che interagisce con `exercism.io` tramite un'API REST. Il track del linguaggio Pharo Smalltalk, invece, usa la stessa API REST per portare gli esercizi dentro e fuori dall'immagine Pharo senza l'uso di strumenti intermedi. Questo documento descrive in dettaglio l'API di Exercism, concentrandosi su come viene usata dal track del linguaggio Pharo Smalltalk. È pensato per i maintainer degli strumenti di Pharo Smalltalk.

## Header

Tutti gli endpoint richiedono che gli header della richiesta siano impostati sui seguenti valori:

```
Authorization: Bearer <token>
```

Il valore `<token>` è il token di autenticazione della CLI dell'utente, disponibile all'indirizzo `https://exercism.io/my/settings`.

## Recuperare gli esercizi

```
Content-Type: application/json
```

`GET api.exercism.io/v1/solutions/latest?exercise_id=<slug>&track_id<language> HTTP/1.1`

Nell'URL qui sopra, `<slug>` è il nome dell'esercizio, ad esempio `hello-world`, e `<language>` è il track del linguaggio, ad esempio `pharo-smalltalk`.

### Risposta

#### 200

Una richiesta riuscita invierà una risposta contenente un payload JSON. All'interno del JSON ci saranno le informazioni sull'esercizio e un URL da cui scaricare i file dell'esercizio.

```json
"solution":{
	"id":"<id-string>",
	"url":"https://exercism.io/my/solutions/<id-string>",
	"team":null,
	"user":{
		"handle":"<exercism-user-name>",
		"is_requester":true
		},
		"exercise":{
			"id":"isogram",
			"instructions_url":"https://exercism.io/my/solutions/<id-string>",
			"auto_approve":false,
			"track":{
				"id":"pharo-smalltalk",
				"language":"Pharo"
				}
			},
			"file_download_base_url":"https://api.exercism.io/v1/solutions/<id-string>/files/",
			"files":[
				"IsogramTest.class.st",
				"README.md"
				],
			"iteration":null
		}
	}
```

#### 400

Il nome del track del linguaggio è ambiguo, oppure i file dell'esercizio inviati non sono cambiati.

#### 403

La soluzione non è sbloccata per l'utente, oppure l'utente non è iscritto al track del linguaggio.

#### 404

Impossibile trovare il track del linguaggio o l'esercizio.

## Inviare gli esercizi

```
Content-Type: application/octet-stream
```

`PATCH api.exercism.io//v1/solutions/<some-kind-of-token-or-hash> HTTP/1.1`

### Risposta

#### 201

Invio riuscito.

#### 400

Un file inviato è troppo grande (oltre un megabyte), oppure la soluzione è un duplicato.

#### 403

L'utente non può accedere alla soluzione. L'ID utente della soluzione e l'ID dell'utente attuale non corrispondono.

#### 404

Impossibile trovare l'ID della soluzione.
