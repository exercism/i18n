# Usa le guardie

[comment]: # (Questo errore viene generato quando la soluzione non usa affatto le guardie)

Usa le [guardie](https://hexdocs.pm/elixir/master/guards.html) per impedire a `two_fer/1` di eseguire codice con input non binari.

> Ricorda che in Elixir le [stringhe](https://elixir-lang.org/getting-started/binaries-strings-and-char-lists.html) sono considerate [dati binari](https://elixir-lang.org/getting-started/binaries-strings-and-char-lists.html).

```elixir
# Consider this function with a guard:
def hello(what) when is_binary(what) do
  "Hello, #{what}!"
end
```

> Questa guardia si può provare in `iex`

```shell
iex> hello("world")
"Hello, world!"
iex> hello(123)
** (FunctionClauseError) no function clause matching in hello/1

    The following arguments were given to hello/1:

        # 1
        123
```
