# Appendice alle istruzioni

## Note specifiche per l'esercizio in Rust

La versione in Rust è leggermente diversa rispetto alle altre versioni di questo esercizio in altri linguaggi. Invece di chiederti di restituire errori per valori fuori intervallo, usiamo il sistema di tipi forte di Rust per limitare l'input. È molto più facile fare in modo che una funzione gestisca tutti gli input validi, invece di chiedere a chi usa il tuo modulo di gestire gli errori.

### Estensione

Aggiungi la capacità di convertire fino al valore massimo di u64: `18_446_744_073_709_551_615`.

Per capire quale output dovrebbe avere, guarda l'ultimo caso di test.
