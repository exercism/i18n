# Introduzione

Destreggiarsi con lo stack va bene per parole brevi. Quando una
parola ha diversi input e devi riferirti a essi per nome, Factor
offre i *locals*: associazioni con nome introdotte da `::` (per le
definizioni di parole) o da `[| | ]` (per le lambda inline), entrambe
provenienti da [`locals`][locals].

```factor
USING: locals ;

:: hypotenuse ( a b -- c )
    a a *
    b b *
    + sqrt ;
```

All'interno di una quotation, `[| inputs | body ]` è una lambda i cui
input hanno un nome:

```factor
USING: assocs locals ;

H{ { "a" 1 } { "b" 2 } }
[| key value | key value 10 * ] assoc-map .
! => H{ { "a" 10 } { "b" 20 } }
```

[locals]: https://docs.factorcode.org/content/vocab-locals.html
