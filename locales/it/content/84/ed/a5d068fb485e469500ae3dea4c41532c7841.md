# Appendice alle istruzioni

## Formato dell'input

Ogni domino è memorizzato in un unico byte, con la metà sinistra nel [nibble] alto e la metà destra nel [nibble] basso. Ad esempio, le pietre `[2|1]`, `[2|3]` e `[1|3]` sono rappresentate dai byte `0x21 0x23 0x13`.

## Registri

| Registro | Utilizzo  | Tipo    | Descrizione                                        |
| -------- | --------- | ------- | -------------------------------------------------- |
| `$a0`    | input     | indirizzo | array di byte delle pietre                        |
| `$a1`    | input     | intero  | numero di pietre                                   |
| `$v0`    | output    | booleano | i domino possono concatenarsi (`0` = `false`, `1` = `true`) |
| `$t0-9`  | temporaneo | qualsiasi | usato per l'archiviazione temporanea              |


[nibble]: https://en.wikipedia.org/wiki/Nibble
