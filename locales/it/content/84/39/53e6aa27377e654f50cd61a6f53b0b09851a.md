# Istruzioni

In questo esercizio, aiuterai due fidanzatini del liceo a dichiarare il loro amore sui social media generando un cuore ASCII con le loro iniziali:

```
❤ J.  +  M. ❤
```

## 1. Pulisci il nome

Implementa il metodo `HighSchoolSweetheart.clean_up_name`.
Dovrebbe prendere un nome, rimuovere tutti i caratteri `-` e sostituirli con uno spazio.
Dovrebbe anche rimuovere gli spazi bianchi all'inizio e alla fine del nome.

```crystal
HighSchoolSweetheart.clean_up_name("Jane-Ann")
# => "Jane Ann"
```

## 2. Ottieni la prima lettera del nome

Implementa il metodo `HighSchoolSweetheart.first_letter`.
Dovrebbe prendere un nome e restituirne la prima lettera.
Assicurati di riutilizzare `HighSchoolSweetheart.clean_up_name`, che hai definito nel passaggio precedente.

```crystal
HighSchoolSweetheart.first_letter("Jane")
# => "J"
```

## 3. Formatta la prima lettera come iniziale

Implementa il metodo `HighSchoolSweetheart.initial`.
Dovrebbe prendere un nome e restituirne la prima lettera, in maiuscolo, seguita da un punto.
Assicurati di riutilizzare `HighSchoolSweetheart.first_letter`, che hai definito nel passaggio precedente.

```crystal
HighSchoolSweetheart.initial("Robert")
# => "R."
```

## 4. Metti le iniziali dentro il cuore

Implementa il metodo `HighSchoolSweetheart.pair`.
Dovrebbe prendere due nomi e restituire le iniziali circondate dai cuori emoji.
Assicurati di riutilizzare `HighSchoolSweetheart.initial`, che hai definito nel passaggio precedente.

```crystal
HighSchoolSweetheart.pair("Blake Miller", "Riley Lewis")
# => "❤ B.  +  R. ❤"
```
