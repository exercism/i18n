# Test

Puoi usare l'editor online sul sito di Exercism per risolvere gli esercizi.
Oppure scarica gli esercizi sul tuo computer, risolvili in locale e poi inviali a Exercism.

Se vuoi lavorare in locale, ti serve il programma [`bats`][bats].
Per le istruzioni di installazione, consulta la pagina [Test sulla traccia Bash][test-bash].

Il codice verrà testato sul test runner jq di Exercism usando [`jq` versione **1.8**][jq].

[bats]: https://github.com/bats-core/bats-core
[test-bash]: https://exercism.org/docs/tracks/bash/tests
[jq]: https://jqlang.org/manual/
