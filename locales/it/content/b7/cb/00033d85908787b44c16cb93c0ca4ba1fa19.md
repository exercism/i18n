# Introduzione

Il concetto [Coppie e dizionari][pairs-dicts] ha illustrato le basi del tipo dizionario di Julia.

Dato che i `Dict` sono un tipo di collezione importante e molto usato, esistono anche molte funzioni per manipolarli.

## Ottenere le voci

Il modo più semplice per recuperare una voce è tramite la chiave (come in molti linguaggi).
Chiedere una chiave inesistente, però, dà un `KeyError`.

```julia-repl
julia> d = Dict(i => ('a':'c')[i] for i in 1:3)
Dict{Int64, Char} with 3 entries:
  2 => 'b'
  3 => 'c'
  1 => 'a'

julia> d[2]
'b': ASCII/Unicode U+0062 (category Ll: Letter, lowercase)

# missing key
julia> d[4]
ERROR: KeyError: key 4 not found
```

Potremmo verificare l'esistenza della chiave prima di provare a recuperarla (con qualcosa come `haskey(d, 4)` o `4 ∈ keys(d)`), ma può essere utile ottenere direttamente un valore predefinito per le chiavi mancanti.

Per questo abbiamo la funzione `get()` e la sua variante mutante `get!()`.
La differenza sta nel fatto che la chiave «mancante» venga aggiunta o meno al `Dict`.

```julia-repl
julia> get(d, 4, '!')
'!': ASCII/Unicode U+0021 (category Po: Punctuation, other)

# get() leaves Dict unchanged
julia> d
Dict{Int64, Char} with 3 entries:
  2 => 'b'
  3 => 'c'
  1 => 'a'

julia> get!(d, 4, '!')
'!': ASCII/Unicode U+0021 (category Po: Punctuation, other)

# get!() adds new key to Dict
julia> d
Dict{Int64, Char} with 4 entries:
  4 => '!'
  2 => 'b'
  3 => 'c'
  1 => 'a'
```

Nel concetto precedente abbiamo visto che `delete!()` rimuove una voce tramite la chiave.
Questo si può combinare con il recupero del valore usando la funzione `pop!()`.

```julia-repl
julia> d
Dict{Int64, Char} with 4 entries:
  4 => '!'
  2 => 'b'
  3 => 'c'
  1 => 'a'

# popped value is returned
julia> pop!(d, 3)
'c': ASCII/Unicode U+0063 (category Ll: Letter, lowercase)

# Dict is shrunk
julia> d
Dict{Int64, Char} with 3 entries:
  4 => '!'
  2 => 'b'
  1 => 'a'
```

## Iterazione

Iterare su un `Dict` restituisce di default coppie `key => value`.
Le componenti sono accessibili con la solita nomenclatura `.first` e `.second`.

```julia-repl
# d is from the previous example
julia> [(kv.first, kv.second) for kv in d]
3-element Vector{Tuple{Int64, Char}}:
 (4, '!')
 (2, 'b')
 (1, 'a')
```

Spesso vogliamo usare solo le chiavi o solo i valori, e farlo è facile.

```juliajulia> [k for k in keys(d)]
julia> [k for k in keys(d)]
3-element Vector{Int64}:
 4
 2
 1

julia> [v for v in values(d)]
3-element Vector{Char}:
 '!': ASCII/Unicode U+0021 (category Po: Punctuation, other)
 'b': ASCII/Unicode U+0062 (category Ll: Letter, lowercase)
 'a': ASCII/Unicode U+0061 (category Ll: Letter, lowercase)
```

## Unione

Combinare due `Dict` può essere utile, ma dobbiamo essere chiari su cosa intendiamo fare con le chiavi presenti in più di un input.

Le funzioni `merge()` e `merge!()` combinano un numero arbitrario di `Dict` forniti, procedendo da sinistra a destra.

I valori delle chiavi già esistenti vengono semplicemente sovrascritti, quindi «vince» il `Dict` più a destra.

```julia-repl
julia> d3 = Dict("color" => "red", "shape" => "circle")
Dict{String, String} with 2 entries:
  "shape" => "circle"
  "color" => "red"

julia> d4 = Dict("color" => "blue", "coords" => (3, 2))
Dict{String, Any} with 2 entries:
  "color"  => "blue"
  "coords" => (3, 2)

# color from d3 is lost
julia> merge(d3, d4)
Dict{String, Any} with 3 entries:
  "shape"  => "circle"
  "color"  => "blue"
  "coords" => (3, 2)
```

Le funzioni `mergewith()` e `mergewith!()` ci permettono di passare una funzione come primo argomento, per definire come unire le chiavi ripetute.
L'addizione è un semplice esempio.

```julia-repl
julia> d5 = Dict("color" => "red", "area" => 3)
Dict{String, Any} with 2 entries:
  "area"  => 3
  "color" => "red"

julia> d6 = Dict("shape" => "circle", "area" => 5)
Dict{String, Any} with 2 entries:
  "shape" => "circle"
  "area"  => 5

# area values are added, not overwritten
julia> mergewith(+, d5, d6)
Dict{String, Any} with 3 entries:
  "shape" => "circle"
  "area"  => 8
  "color" => "red"
```

Concatenare due vettori è un'altra operazione molto usata quando si uniscono i dizionari.
Per questo, Julia usa la funzione `vcat()`, per i motivi spiegati nel concetto [`Multi Dimensional Arrays`][multidim].

```julia-repl
julia> d7 = Dict("vals" => [1, 2, 3])
Dict{String, Vector{Int64}} with 1 entry:
  "vals" => [1, 2, 3]

julia> d8 = Dict("vals" => [4, 5])
Dict{String, Vector{Int64}} with 1 entry:
  "vals" => [4, 5]

julia> mergewith(vcat, d7, d8)
Dict{String, Vector{Int64}} with 1 entry:
  "vals" => [1, 2, 3, 4, 5]
```

Nota che le funzioni `mergewith` sono un buon esempio di [funzioni di ordine superiore][hof] in azione.

Per più [`Set`][sets], la funzione di unione corrispondente è `union`.
