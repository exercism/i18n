# Istruzioni

Gestisci una boutique di moda online. I tuoi grandi saldi annuali stanno per iniziare, quindi devi fare il punto sull'inventario per assicurarti che sia tutto pronto.

Un singolo articolo dell'inventario è rappresentato da una mappa, e l'intero inventario è un array di mappe di questo tipo.

```elixir
%{
  name: "White Shirt",
  price: 40,
  quantity_by_size: %{s: 3, m: 7, l: 8, xl: 4}
}
```

## 1. Ordina gli articoli per prezzo

Implementa la funzione `sort_by_price/1`. Deve prendere l'inventario e restituirlo ordinato per prezzo dell'articolo, in ordine crescente.

```elixir
BoutiqueInventory.sort_by_price([
  %{price: 65, name: "Maxi Brown Dress", quantity_by_size: %{}},
  %{price: 50, name: "Red Short Skirt", quantity_by_size: %{}},
  %{price: 50, name: "Black Short Skirt", quantity_by_size: %{}},
  %{price: 20, name: "Bamboo Socks Cats", quantity_by_size: %{}}
])

# => [
#      %{price: 20, name: "Bamboo Socks Cats", quantity_by_size: %{}},
#      %{price: 50, name: "Red Short Skirt", quantity_by_size: %{}},
#      %{price: 50, name: "Black Short Skirt", quantity_by_size: %{}},
#      %{price: 65, name: "Maxi Brown Dress", price: 65, quantity_by_size: %{}}
#    ]
```

## 2. Trova tutti gli articoli a cui manca il prezzo

Dopo aver ordinato l'inventario per prezzo, hai notato di aver commesso un errore mentre facevi l'inventario e di aver dimenticato di inserire il prezzo di alcuni articoli.

Implementa la funzione `with_missing_price/1`. Deve prendere l'inventario e restituire un array di articoli che non hanno un prezzo.

```elixir
BoutiqueInventory.with_missing_price([
  %{price: 40, name: "Black T-shirt", quantity_by_size: %{}},
  %{price: nil, name: "Denim Pants", quantity_by_size: %{}},
  %{price: nil, name: "Denim Skirt", quantity_by_size: %{}},
  %{price: 40, name: "Orange T-shirt", quantity_by_size: %{}}
])

# => [
#      %{price: nil, name: "Denim Pants", quantity_by_size: %{}},
#      %{price: nil, name: "Denim Skirt", quantity_by_size: %{}}
#    ]
```

## 3. Aggiorna i nomi degli articoli

Hai notato che alcuni nomi di articoli contengono una parola che non vuoi più usare. Ora devi aggiornare tutti i nomi degli articoli che contengono quella parola.

Implementa la funzione `update_names/3`. Deve prendere l'inventario, la vecchia parola che vuoi rimuovere e una nuova parola da usare al suo posto. Deve restituire un array di articoli con i nomi aggiornati.

```elixir
BoutiqueInventory.update_names(
  [
    %{price: 40, name: "Black T-shirt", quantity_by_size: %{}},
    %{price: 70, name: "Denim Pants", quantity_by_size: %{}},
    %{price: 65, name: "Denim Skirt", quantity_by_size: %{}},
    %{price: 40, name: "Orange T-shirt", quantity_by_size: %{}}
  ],
  "T-shirt",
  "Tee"
)

# => [
#      %{price: 40, name: "Black Tee", quantity_by_size: %{}},
#      %{price: 70, name: "Denim Pants", quantity_by_size: %{}},
#      %{price: 65, name: "Denim Skirt", quantity_by_size: %{}},
#      %{price: 40, name: "Orange Tee", quantity_by_size: %{}}
#    ]
```


## 4. Incrementa la quantità dell'articolo

Alcuni articoli vendevano particolarmente bene, quindi ne hai ordinati altri, in tutte le taglie.

Implementa la funzione `increase_quantity/2`. Deve prendere un singolo articolo e un numero `n`, e restituire quell'articolo con la quantità di ogni taglia aumentata di `n`.

```elixir
BoutiqueInventory.increase_quantity(
  %{
    name: "Polka Dot Skirt",
    price: 68,
    quantity_by_size: %{s: 3, m: 5, l: 3, xl: 4}
  },
  6
)

# => %{
#      name: "Polka Dot Skirt",
#      price: 68,
#      quantity_by_size: %{l: 9, m: 11, s: 9, xl: 10}
#    }
```

## 5. Calcola la quantità totale dell'articolo

Per sapere quanto spazio ti serve in magazzino, devi sapere quanti pezzi hai in totale per ogni articolo.

Implementa la funzione `total_quantity/1`. Deve prendere un singolo articolo e restituire quanti pezzi hai in totale, in qualsiasi taglia.

```elixir
BoutiqueInventory.total_quantity(%{
  name: "Red Shirt",
  price: 62,
  quantity_by_size: %{s: 3, m: 6, l: 5, xl: 2}
})

# => 16
```
