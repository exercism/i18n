# Introduzione

In Haxe, le eccezioni sono un modo sicuro per gestire gli errori che si verificano durante l'esecuzione del codice. Tutte le eccezioni dovrebbero contenere un messaggio che descrive l'errore. Possiamo _lanciare_ eccezioni usando la parola chiave `throw`:

```haxe
public function main(num:Int) {
  if (num < 10) {
    throw "Argument num cannot be greater than 10";
  }
  // ...
}
```

Quando viene lanciata un'eccezione, il codice cerca una parte assegnata a gestire l'errore. Se non ne trova una, visualizzerà il messaggio di errore e interromperà anche l'esecuzione del programma.

Per gestire le eccezioni in Haxe, usiamo il blocco `try-catch`. Questa istruzione a blocco è composta da un blocco `try` e da uno o più blocchi `catch`. Il blocco `try` _prova_ a eseguire un pezzo di codice, mentre il blocco `catch` attende nel caso venga lanciata un'eccezione per _catturarla_, così che l'esecuzione non venga fermata. Quando il blocco `catch` cattura un'eccezione, esegue anche tutto ciò che è al suo interno:

```haxe
try {
  if (num < 10) {
    throw "Argument num cannot be greater than 10";
  }
} catch (e) {
  // All exceptions will be caught here
  trace(e.message); // Argument num cannot be greater than 10
}
```

Il tipo dell'argomento del blocco `catch` va omesso.
