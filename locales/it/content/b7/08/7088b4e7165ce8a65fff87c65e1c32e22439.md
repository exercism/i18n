# Introduzione

Swift offre una variazione della sua sintassi quando si gestiscono le closure, nota come trailing closure. Le trailing closure si presentano quando l'ultimo parametro nella lista dei parametri di una funzione ha un tipo di funzione. In questo caso, se si passa una closure, la closure può essere scritta _dopo_ la parentesi tonda di chiusura e l'etichetta dell'argomento viene omessa. Nota che se c'è un solo parametro per la funzione, le parentesi tonde (`()`) possono essere omesse del tutto.

```swift
func fetchURL(_ urlString: String,
              uponReceipt handleResult: (String) -> ()
             )  -> () {
  if let url = URL(string: urlString), let htmlString = fetch(url) {
    handleResult(htmlString)
  }
}

fetchURL("https://www.swift.org") { print($0) }
// prints the fetched html string

["apple", "ball", "carrot"].sorted { $0.count < $1.count }
```
