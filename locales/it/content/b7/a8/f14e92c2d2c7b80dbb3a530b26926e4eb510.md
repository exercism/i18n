# Stampa

La stampa in Cairo ti permette di mostrare messaggi e valori sulla console, il che rende più semplice fare debug dei programmi o comunicare informazioni durante l'esecuzione.

Il sistema di stampa è versatile e semplice al tempo stesso: mette a disposizione gli strumenti per formattare e stampare dati di vario tipo.

## Le basi della stampa

Cairo mette a disposizione due macro principali per stampare testo sulla console:

- **`println!`**: stampa l'output su una nuova riga.
- **`print!`**: stampa l'output sulla stessa riga, senza aggiungere una nuova riga.

Entrambe le macro accettano un `ByteArray` come primo argomento: può essere una semplice stringa oppure una stringa formattata con dei segnaposto per i valori.

```rust
// Printing a simple message
println!("Hello, Cairo!");

// Printing with values
let x = 10;
let y = 20;
println!("Values: x = {}, y = {}", x, y);
```

Nell'esempio qui sopra:

- i segnaposto `{}` vengono sostituiti dai valori di `x` e `y`.
- `println!` fa sì che l'output termini con una nuova riga.

## Formattare le stringhe

A volte può servirti creare una stringa formattata senza stamparla subito.

La macro `format!` ti permette di farlo.

Funziona in modo simile a `println!`, ma restituisce un `ByteArray` invece di inviare l'output alla console.

```rust
let s1: ByteArray = "tic";
let s2: ByteArray = "tac";
let s3: ByteArray = "toe";

// Create a formatted string
let result = format!("{s1}-{s2}-{s3}");

println!("{}", result); // Output: tic-tac-toe
```

In questo esempio:

- `format!` combina `s1`, `s2` e `s3` in un'unica stringa, separandoli con dei trattini (`-`).
- La stringa risultante può essere riutilizzata o stampata più tardi.

## Stampare tipi di dati personalizzati

Per impostazione predefinita, Cairo può stampare solo i tipi di base, come interi e stringhe.

Se provi a stampare un tipo personalizzato, ad esempio una struct, ottieni un errore, a meno che il tipo non implementi i trait `Display` o `Debug`.

### Usare `Display` per una formattazione personalizzata

Il trait `Display` ti permette di definire come deve essere stampato un tipo personalizzato.

Ecco un esempio:

```rust
use core::fmt::{Display, Formatter, Error};

struct Point {
    x: u8,
    y: u8,
}

impl PointDisplay of Display<Point> {
    fn fmt(self: @Point, ref f: Formatter) -> Result<(), Error> {
        write!(f, "Point({}, {})", *self.x, *self.y)
    }
}

let p = Point { x: 3, y: 4 };
println!("{}", p); // Output: Point(3, 4)
```

In questo esempio:

- La funzione `fmt` definisce come la struct `Point` viene convertita in una stringa stampabile.
- La macro `write!` aggiunge la stringa formattata al `Formatter`.

### Fare debug con `Debug`

Per fare debug, Cairo mette a disposizione il trait `Debug`.

Per la maggior parte dei tipi puoi derivarlo automaticamente, il che rende veloce e semplice stampare i dettagli interni delle tue struct.

```rust
#[derive(Debug)]
struct Point {
    x: u8,
    y: u8,
}

let p = Point { x: 3, y: 4 };
println!("{:?}", p); // Output: Point { x: 3, y: 4 }
```

In questo esempio:

- `#[derive(Debug)]` genera automaticamente l'implementazione del trait `Debug`.
- Il segnaposto `{:?}` indica a `println!` di usare il trait `Debug` per la formattazione.

## Stampare in esadecimale

Cairo permette di stampare gli interi in formato esadecimale usando il segnaposto `{:x}`.

```rust
let value: u32 = 255;
println!("{:x}", value); // Output: ff
```

È particolarmente utile quando si lavora con rappresentazioni dei dati di basso livello.
