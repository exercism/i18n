# Appendice
## Bonus

Preserva i cluster di grafemi, cioè

```julia
myreverse("hi 👋🏾") == "👋🏾 ih"
myreverse("as⃝df̅") == "f̅ds⃝a"
```

Probabilmente troverai utile la libreria standard `Unicode` per questo compito bonus.

Per abilitare il test dei grafemi, aggiungi `const TEST_GRAPHEMES = true` allo scope globale del file.
