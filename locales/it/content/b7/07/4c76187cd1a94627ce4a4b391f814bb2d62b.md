# Test

Nella directory `t/` c'è uno script Perl con estensione `.t`, che verrà usato per testare la soluzione.
Puoi eseguire i test con il comando:

```bash
`prove`
```

La documentazione sulle affermazioni usate nei file di test si trova in [Test2::Manual::Testing::Introduction][test2-manual].

[test2-manual]: https://metacpan.org/pod/Test2::Manual::Testing::Introduction
