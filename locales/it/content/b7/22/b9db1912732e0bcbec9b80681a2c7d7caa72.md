# Introduzione

## Cicli for

Un'istruzione `for` ripete un blocco di codice.
La sua prima riga controlla quante volte il blocco viene ripetuto:

```go
for init; condition; post {
    // loop body
}
```

- L'istruzione **init** viene eseguita una sola volta prima della prima iterazione. Spesso si usa per dichiarare e inizializzare una variabile contatore usata dal ciclo.
- La **condition** è un'espressione booleana valutata prima di ogni iterazione. Il ciclo si ferma quando questa diventa `false`.
- L'istruzione **post** viene eseguita dopo ogni iterazione completata. Può servire ad aggiornare un contatore.

Non racchiudere `init; condition; post` tra parentesi tonde.
Le parentesi graffe (`{ }`) attorno al corpo del ciclo, invece, sono sempre obbligatorie.

Questo ciclo fa partire `i` da `1`, stampa il valore corrente di `i`, lo incrementa per l'iterazione successiva e si ferma quando `i` raggiunge `10`:

```go
for i := 1; i < 10; i++ {
    fmt.Println(i)
}
```
