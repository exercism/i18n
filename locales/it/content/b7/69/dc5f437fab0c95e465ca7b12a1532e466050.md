# Introduzione

## Copie e riferimenti

Con le conoscenze che abbiamo ora, aggiornare una variabile con l'aiuto di una funzione è un po' macchinoso.
Ogni argomento di una funzione viene trattato come una copia e non modifica il valore originale.
A seconda della dimensione del tuo tipo, questo può avere conseguenze serie sulle prestazioni del tuo codice.

```cpp
int adjust_salary(int base, int kids) {
    return base + kids * 500;
}
int now_a_mother_of_twins{2500};
adjust_salary(now_a_mother_of_twins, 2);

// now_a_mother_of_twins is still 2500
now_a_mother_of_twins = adjust_salary(now_a_mother_of_twins, 2);
// now_a_mother_of_twins is now 3500
```

`References` si possono considerare degli alias: le modifiche apportate hanno effetto sulla variabile originale.
`References` si scrivono con una **e commerciale** (`&`) nella dichiarazione del tipo.

```cpp
int balance{1000};
int& budget{balance};
int pro_computer_wheels{699};
budget -= pro_computer_wheels;
// budget is now 301;
// balance is also 301;
```
Riassegnare (cioè cambiare il collegamento di un `reference`) non è possibile.
Non puoi avere un `reference` non inizializzato.
`References` devono essere inizializzati con una variabile esistente.

```cpp
int main_acc{1'000'000};
int side_acc{-20};
int& savings{main_acc};
// => main_acc and savings are 1'000'000

// try to reseat savings to use main account
savings = side_acc;
// savings and main_acc are now -20
// as this uses the **value** of side_acc
savings += 20;
// savings and main_acc are now 0, side_acc is stil -20

int& future_budget;
// => compiler error, reference must be bound!
```

## `void`

Con la potenza dei `references` potresti non avere affatto bisogno di restituire un valore da una funzione.
In questo scenario `void` si usa come tipo restituito.

```cpp
void increase_power(int& level) {
    level += 500;
}
int goku{8700};
increase_power(goku);
// goku's power level?
// It's over 9000!
```
