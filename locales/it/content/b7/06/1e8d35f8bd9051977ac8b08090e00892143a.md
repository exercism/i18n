# Getter e setter

I getter e i setter sono metodi che permettono di leggere e scrivere il valore di una proprietà di un oggetto.
Crystal ha le macro, che rendono semplice definire getter e setter per una proprietà.
Le macro sono un modo per generare codice in fase di compilazione; ne parleremo più avanti, nel concetto delle macro.

In Ruby questi metodi si definiscono usando i metodi `attr_reader`, `attr_writer` e `attr_accessor` e in superficie sono molto simili all'implementazione di Crystal.
Crystal li ha definiti come macro `getter`, `setter` e `property`.

## Getter

`getter` è una macro che definisce un metodo che restituisce il valore di una variabile di istanza.
Questo significa che non devi più scrivere `@` davanti alla variabile di istanza quando vuoi accedervi (nei metodi, escluso initialize); puoi invece chiamare il metodo definito dalla macro `getter`.

La macro `getter` può accettare più variabili di istanza separandole con virgole.

```crystal
# This:
class Person
  @name : String
  @age : Int32

  def name
    @name
  end

  def age
    @age
  end
end

# Is the same as this:
class Person
  @name : String
  @age : Int32

  getter name, :age
end
```

Come puoi vedere, usare `getter` riduce la quantità di codice da scrivere e lo rende più facile da leggere.
Inoltre, Ruby e Crystal differiscono perché Crystal accetta sia il nome della variabile sia il simbolo come argomenti della macro `getter`.
I simboli saranno trattati più avanti, nel concetto dei simboli.

## Setter

`setter` è una macro che definisce un metodo che imposta il valore di una variabile di istanza.
Questa macro non si incontra spesso: al suo posto si usa di solito la macro `property`.
I metodi creati avranno una forma simile a `name_of_method=`; è il `=` che permette di impostare la proprietà.

Questa definizione di metodo è un po' particolare, perché l'argomento che il metodo riceve sta dopo il segno `=`.
Diversi altri metodi speciali di Crystal usano questa sintassi, come il metodo `+`.

Come per la macro `getter`, quando vuoi aggiornare il valore di una variabile di istanza dopo aver definito un setter, puoi chiamare il metodo definito dalla macro `setter`.

```crystal
# This:
class Person
  @name : String
  @age : Int32

  def name=(name : String)
    @name = name
  end

  def age=(age : Int32)
    @age = age
  end
end

# Is the same as this:
class Person
  @name : String
  @age : Int32

  setter name, :age
end
```

## Property

`property` è una macro che definisce sia un getter sia un setter per una variabile di istanza.

```crystal
class Person
  @name : String
  @age : Int32

  property name, :age
end
```
