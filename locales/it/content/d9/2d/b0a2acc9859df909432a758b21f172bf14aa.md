# Introduzione

In PHP, una variabile può essere chiamata come una funzione applicandole delle parentesi [`()`]. Quando PHP tenta di chiamare la funzione, cercherà una funzione con lo stesso nome del valore della variabile.

```php
function foo(): string
{
    return "foo() invoked";
}

$func = 'foo';
$func(); // This calls foo()
```
