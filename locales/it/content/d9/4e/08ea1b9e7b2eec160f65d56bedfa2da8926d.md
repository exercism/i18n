# Introduzione

Un vettore è un array monodimensionale.
Può contenere elementi di tipi diversi.

## Creare i vettori

I vettori possono essere creati tramite la funzione `vector` o usando la sua forma di lettura `#()`

```lisp
(vector 1 t "foo" 'b) ; => #(1 T "foo" B)
#(2 nil "bar" a)      ; => #(2 NIL "bar" A)
```

Dato che sono array, possono anche essere creati con `make-array`:

```lisp
(make-array 3 :initial-element 'x)        ; => #(X X X)
(make-array 3 :initial-contents '(a b c)) ; => #(A B C)
```

## Il predicato dei vettori

Per controllare se un oggetto è un vettore, basta usare il predicato `vectorp`.

## Accedere agli elementi

Per accedere agli elementi di un vettore usa `aref`. Gli indici partono da zero:

```lisp
(aref #(1 2 3) 1) ; => 2
(aref #(a b c) 0) ; => A
```
