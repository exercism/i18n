# Installazione

Per fare gli esercizi ti serve [Vim](http://www.vim.org):

- [macOS](#macos)
- [Ubuntu / Debian](#ubuntu--debian)
- [Windows](#windows)
- [Sorgente](#source)

## macOS

Il sistema operativo include Vim di default, ma è una versione irrimediabilmente obsoleta.

Probabilmente usi [MacPorts](https://www.macports.org) o [Homebrew](https://brew.sh) per installare il software.

Homebrew:

```
$ brew update
$ brew install vim
```

MacPorts:

```
$ sudo port install vim +huge
```

Se preferisci un'interfaccia grafica, dai un'occhiata a [MacVim](https://macvim-dev.github.io/macvim).

## Ubuntu / Debian

Installa la versione completa di Vim con il supporto all'interfaccia grafica (`gvim`):

```
$ sudo apt-get update
$ sudo apt-get install vim-gtk
```

## Windows

Con [Chocolatey](https://chocolatey.org):

```
C:\> choco install vim
```

Oppure scaricalo e installalo direttamente da [qui](http://www.vim.org/download.php#pc).

## Sorgente

Se vuoi compilare da solo l'ultima versione di Vim, dai un'occhiata al [repository ufficiale su GitHub](https://github.com/vim/vim).
