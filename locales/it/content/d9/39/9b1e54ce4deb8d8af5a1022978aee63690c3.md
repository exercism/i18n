# Informazioni

## Gli include

Per includere il contenuto di altri file, C++ usa la direttiva `include`.
Queste inclusioni vanno indicate all'inizio del file.
Durante la compilazione, la riga con la direttiva viene sostituita dal contenuto del rispettivo file.
Dopo le inclusioni, i namespace restano come nel file originale.

## La libreria standard

La libreria standard offre molte funzioni, algoritmi e strutture dati comuni.
La libreria standard usa il namespace `std`.

Un esempio è la libreria numerica del C, `cmath`.
Fornisce molte operazioni matematiche comuni.

```cpp
#include <cmath>

int cube_me(int a) {
    // raise `a` to the third power
    return std::pow(a, 3);
}
```

~~~~exercism/note
Le librerie standard si includono con le parentesi angolari (`<>`) invece che con le virgolette doppie (`"`).
La differenza sta nella posizione in cui il compilatore cerca i rispettivi file.
Con la versione tra parentesi angolari, la ricerca nel progetto corrente viene saltata: il compilatore parte direttamente dalle directory di include del sistema.
Se vuoi includere file locali, devi usare le virgolette doppie: `#include "myfile"`
~~~~
