# Introduzione ai tipi generici

Un **tipo generico** è una classe o un'interfaccia generica parametrizzata sui tipi.
Questo permette al compilatore di garantire la sicurezza dei tipi sulla classe o sull'interfaccia.

Considera questa interfaccia `Container` non generica:

```java
class Container {
    private Object object;

    public void set(Object object) { this.object = object; }
    public Object get() { return object; }
}
```

Dato che accetta e restituisce tipi Object, funziona con qualsiasi tipo non primitivo.
Tuttavia questo ha un costo, perché del codice potrebbe chiamare `get` aspettandosi degli `Integer`, mentre altro codice chiama `set` aggiungendo delle `String`, e il risultato è un'eccezione a runtime.

Una **classe generica** e un'**interfaccia generica** hanno il seguente formato:

```java
class ClassName<T1, T2, ..., Tn> { ... }
interface InterfaceName<T1, T2, ..., Tn> { ... }
```

La sezione dei parametri di tipo, delimitata da parentesi angolari (`<>`) e posta dopo il nome della classe o dell'interfaccia, specifica i parametri di tipo (detti anche variabili di tipo) `T1`, `T2`, ..., e `Tn`.
Possiamo usarli all'interno del corpo della classe o dell'interfaccia per ottenere la sicurezza dei tipi offerta dai generici.

Ecco la versione generica di `Container`:

```java
class Container<E> {
    private E object;

    public void set(E object) { this.object = object; }
    public E get() { return object; }
}
```

Quando la creiamo, dobbiamo dichiarare quale tipo contiene e il compilatore farà rispettare questo vincolo:

```java
// empty <> can infer from context
Container<String> stringContainer = new Container<>();
// compiler knows this is a String, so it is allowed
stringContainer.set("Some string");
// no cast needed, compiler knows it is a String
String result = stringContainer.get();
// this causes a compiler error:
stringContainer.set(42);
```
