# Suggerimenti

## 1. Classifica i clienti

- Usare [`every()`][ref-every] con una funzione anonima può essere comodo.

## 2. Dai un nome ai clienti

- Elaborare due input in parallelo: pensa a [`map2()`][ref-map2] come possibile approccio.

## 3. Separa i clienti enfatici

- I compiti precedenti ti aiuteranno.
- Quali clienti vuoi [`keep`][ref-keep] nella lista di output?

## 4. Converti le valutazioni in binarie

- Ci sono diversi modi per risolvere questo problema, ma [`if_else()`][ref-if_else] della libreria `dplyr` potrebbe essere il più semplice. Ne abbiamo parlato nel [concetto Switch][concept-switch].
- All'interno di `purrr`, un'altra possibilità è [`map_int()`][ref-map_int].

## 5. Media delle valutazioni nel tempo

- È una media cumulativa, un indizio sul nome di una funzione utile.
- Una media è una somma divisa per una lunghezza, quindi potremmo implementarla usando le funzioni di `purrr`.
  - Nell'introduzione abbiamo visto come accumulare una somma.
  - Potremmo usare [`map2_dbl()`][ref-map2] per dividere le somme per le lunghezze.
