# Introduzione

Una *parola generica* dichiara un'operazione che può avere implementazioni diverse a seconda della classe del suo argomento. I metodi si aggiungono con `M:`.

```factor
USING: kernel math ;

GENERIC: area ( shape -- n )

TUPLE: square side ;
TUPLE: circle radius ;

M: square area side>> dup * ;
M: circle area radius>> dup * 3.14159 * ;
```

```factor
T{ square { side 4 } } area .    ! => 16
T{ circle { radius 2 } } area .  ! => 12.56636
```

`GENERIC:` dichiara la parola e il suo effetto sullo stack. `M:` definisce un metodo su una classe specifica: Factor fa il dispatch sulla classe dell'argomento in cima allo stack a runtime.

Puoi chiedere alla parola generica per quali classi ha dei metodi, e aggiungere o rimuovere metodi in un secondo momento. Non esiste una sintassi speciale per l'ereditarietà: qualsiasi classe tuple è automaticamente idonea a ricevere metodi.
