# Introduzione

## L'interfaccia come insieme di metodi

Nella sua forma più semplice, un **tipo interfaccia** è un insieme di firme di metodi.
Ecco un esempio di definizione di interfaccia che include due metodi `Add` e `Value`:

```go
type Counter interface {
    Add(increment int)
    Value() int
}
```

I nomi dei parametri come `increment` possono essere omessi dalla definizione dell'interfaccia, ma spesso ne aumentano la leggibilità.

I nomi delle interfacce in Go non contengono la parola `Interface` o `I`.
Spesso invece terminano con `er`, ad esempio `Reader`, `Stringer`.

## Implementare un'interfaccia

Qualsiasi tipo che definisce i metodi dell'interfaccia «implementa» automaticamente e in modo implicito l'interfaccia.
In Go non esiste la parola chiave `implements`.

Il tipo seguente implementa l'interfaccia `Counter` che abbiamo visto sopra.

```go
type Stats struct {
    value int
    // ...
}

func (s Stats) Add(v int) {
    s.value += v
}

func (s Stats) Value() int {
    return s.value
}

func (s Stats) SomeOtherMethod() {
    // The type can have additional methods not mentioned in the interface.
}
```

Per implementare l'interfaccia, non importa se il metodo ha un receiver di valore o di puntatore.
(Torna ai [concetti sui metodi][concept-methods] se hai qualche dubbio in merito.)

> Un valore di tipo interfaccia può contenere qualsiasi valore che implementi quei metodi. ((Go Tour: Interfaces)[go-tour-interfaces])

Questo significa che ora `Stats` può essere usato in tutti i punti in cui ci si aspetta l'interfaccia `Counter`.

```go
func SetUpAnalytics(counter Counter) {
    // ...
}

stats := Stats{}
SetUpAnalytics(stats)
// works because Stats implements Counter
```

Poiché le interfacce vengono implementate in modo implicito, un tipo può facilmente implementare più interfacce.
Basta che abbia definiti tutti i metodi necessari.

## Interfaccia vuota

In Go esiste un tipo di interfaccia molto speciale, il tipo **interfaccia vuota**, che non contiene alcun metodo.
L'interfaccia vuota si scrive così: `interface{}`.
In Go 1.18 o versioni successive si può usare anche `any`.
È stato definito come alias.

Dato che l'interfaccia vuota non ha metodi, ogni tipo la implementa in modo implicito.
Questo è utile per definire una funzione che possa accettare genericamente qualsiasi valore.
In quel caso, il parametro della funzione usa il tipo interfaccia vuota.
