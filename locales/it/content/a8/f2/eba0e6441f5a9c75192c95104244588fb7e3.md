# Introduzione

In Clojure un `vector` è una collezione sequenziale, indicizzata e immutabile di zero o più valori. Questo significa che, una volta creato, un vector non può più essere modificato. Le funzioni che operano sui vector restituiscono un nuovo vector, mentre il vector originale rimane invariato. I valori in un vector possono essere di tipi eterogenei. I vector si possono definire così:

```clojure
(def empty [])
(def single-value [5])
(def single-value-alternative (vector 5))
(def three-values [1 "a" "b"])
```

Gli elementi si possono recuperare da un vector tramite un indice. I vector di Clojure sono basati sullo zero, cioè l'indice del primo elemento è sempre zero:

```clojure
(def numbers [2 3 5])
;; Read value from vector
(get numbers 2)
;;=> 5
;; Update value in vector
(assoc numbers 2 9)
;;=> [2 3 9]
```

Il vector originale rimane invariato:

```clojure
numbers
;;=> [2 3 5]
```

Per ricordare il valore aggiornato, dobbiamo passarlo avanti oppure catturarlo in un var:

```clojure
(def updated-numbers
  (assoc numbers 2 9))
(get updated-numbers 2)
;;=> 9
```
