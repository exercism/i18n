# senza rescue

Non usare le eccezioni per controllare il flusso.
Prova a risolvere questo esercizio senza usare `rescue`.

Se stai usando una funzione della libreria standard il cui nome termina con un `!` (che solleva errori), cerca una funzione equivalente senza il `!` (spesso restituisce `{:ok, result}` o `{:error, message}`).

Nota: se vedi questo commento automatico sulla soluzione, altri commenti automatici potrebbero non essere accurati.
Risolvi prima questo problema!

```elixir
# preferred: for example `case`

case Date.new(1999, 13, 1) do
  {:ok, date} -> date
  {:error, _} -> nil
end

# discouraged: rescuing exceptions

try do
  Date.new!(1999, 13, 1)
rescue
  ArgumentError ->
    nil
end
```
