# Aiuto

Per ottenere aiuto se hai dei problemi, puoi usare una delle seguenti risorse:

- [CF SCript Cheatsheet](http://www.petefreitag.com/cheatsheets/coldfusion/cfscript/)
- [CFML Slack](https://cfml-slack.herokuapp.com/)
- [Community Resource Page](http://carehart.org/cf411/)
- [Lucee Server Discourse Forum](https://dev.lucee.org/)
- [Twitter](https://twitter.com/search?q=coldfusion&src=typd)
- [/r/coldfusion](https://www.reddit.com/r/coldfusion/) è il subreddit di ColdFusion.
- [StackOverflow](http://stackoverflow.com/questions/tagged/coldfusion) può essere usato per cercare il tuo problema e vedere se è già stato risolto. Puoi anche fare e rispondere a domande.
