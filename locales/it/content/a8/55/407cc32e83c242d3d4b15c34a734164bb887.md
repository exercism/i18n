# Informazioni

Le costanti sono valori definiti al momento della compilazione e non possono essere riassegnati.
Usa la parola chiave `const` per dichiarare una singola costante:

```go
const greeting = "hello"
```

È possibile dichiarare più costanti all'interno di un blocco.
All'interno di un blocco, una costante senza un valore esplicito ripete l'espressione precedente:

```go
const (
    greeting    = "hello"
    buffSize    = 4096
    chunkSize   // 4096
)
```

Di solito le costanti si dichiarano a livello di pacchetto, ma è possibile dichiararle anche dentro una funzione.

## Costanti tipizzate e non tipizzate

Dichiarare una costante senza specificarne il tipo la rende non tipizzata.
Una costante non tipizzata non ha un tipo fisso: è il suo valore a determinare con quali tipi è compatibile.
Finché il valore sottostante è compatibile, il compilatore la convertirà al tipo richiesto a ogni utilizzo:

```go
const numA = 2

math.Sqrt(numA)  // numA is treated as float64 here
var numB int = numA  // numA is treated as int here
```

Una costante tipizzata fissa il tipo al momento della dichiarazione:

```go
const num int = 2

math.Sqrt(num)  // compile error because a float is expected
```

## Cosa può essere una costante

Le costanti possono contenere solo valori booleani, numeri, stringhe e rune.
Poiché i valori vengono impostati al momento della compilazione, il risultato di una chiamata a funzione non può essere usato per una costante.

```go
const s = math.Sqrt(4)  // compile error because the value isn't known at compile time
```

## Iota

All'interno di un blocco di costanti, `iota` rappresenta la posizione di una costante nel blocco:

```go
const (
    Sunday    = iota // 0
    Monday           // 1
    Tuesday          // 2
    Wednesday        // 3
)
```

Ogni costante dopo la prima eredita la stessa espressione, con `iota` che si incrementa di uno.

`iota` funziona anche nelle espressioni.

```go
const (
    _  = iota             // position 0: value discarded
    KB = 1 << (10 * iota) // position 1: 1 << 10 = 1024
    MB                    // position 2: 1 << 20 = 1048576
    GB                    // position 3: 1 << 30 = 1073741824
)
```
