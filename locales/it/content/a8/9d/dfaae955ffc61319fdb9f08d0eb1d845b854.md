# Istruzioni

Stai sviluppando il nuovo gioco di grande successo **Wings Quest**.
Nel gioco sei un uccello che si muove e raccoglie semi.
Il giocatore vince raccogliendo tutti i semi.
Se il giocatore entra in contatto con un'aquila, perde tutti i suoi semi e perde la partita.
C'è un'eccezione a questa regola: il giocatore può avere un power-up attivo che lo fa volare più in alto degli altri uccelli.

Il tuo obiettivo è scrivere alcune regole che verranno usate nel gioco.

## 1. Definire se l'uccello ottiene punti bonus

Nel gioco, l'uccello ottiene punti bonus se tocca un'aquila mentre ha un power-up.

Definisci la funzione `bonusPoints(powerUpActive:touchingEagle:)` che prende due argomenti: `powerUpActive`, che indica se l'uccello ha un power-up attivo, e l'argomento `touchingEagle`, che indica se l'uccello sta toccando un'aquila.
La funzione deve restituire `true` solo se l'uccello ha un power-up attivo e sta toccando un'aquila, e `false` in caso contrario.

```Swift
bonusPoints(powerUpActive: false, touchingEagle: true)
// Returns false
```

## 2. Definire se l'uccello segna punti

Nel gioco, il giocatore ottiene punti quando raccoglie un seme o un power-up.

Definisci la funzione `score(touchingPowerUp:touchingSeed:)` che prende due argomenti: `touchingPowerUp`, che indica se l'uccello sta toccando un power-up, e l'argomento `touchingSeed`, che indica se l'uccello sta toccando un seme.
La funzione deve restituire `true` se l'uccello sta toccando un power-up o un seme, e restituire `false` in caso contrario.

```Swift
score(touchingPowerUp: true, touchingSeed: true)
// Returns true
```

## 3. Definire se l'uccello perde

Definisci la funzione `lose(powerUpActive:touchingEagle:)` che prende due argomenti: `powerUpActive`, che indica se l'uccello ha un power-up attivo, e l'argomento `touchingEagle`, che indica se l'uccello sta toccando un'aquila.
La funzione deve restituire `true` se il personaggio sta toccando un'aquila e non ha un power-up attivo, e restituire `false` in caso contrario.

```Swift
lose(powerUpActive: false, touchingEagle: true)
// Returns true
```

## 4. Definire se l'uccello vince

Definisci la funzione `win(hasPickedUpAllSeeds:powerUpActive:touchingEagle:)` che prende gli argomenti:

- `hasPickedUpAllSeeds` se l'uccello ha raccolto tutti i semi.
- `powerUpActive` se l'uccello ha un power-up attivo.
- `touchingEagle` se l'uccello sta toccando un'aquila.

La funzione deve restituire `true` se l'uccello ha raccolto tutti i semi e non ha perso in base agli argomenti definiti nella parte 3, e restituire `false` in caso contrario.

```Swift
win(hasPickedUpAllSeeds: false, powerUpActive: true, touchingEagle: false)
// Returns false
```
