# Istruzioni

In questo esercizio scriverai del codice per aiutare un freelancer a comunicare con un project manager.
Il tuo compito è fornire alcune funzioni di utilità per calcolare rapidamente le tariffe giornaliere e mensili, facoltativamente con uno sconto dato.

Stabiliamo innanzitutto alcune regole tra il freelancer ed il project manager:

- La tariffa giornaliera è 8 volte la tariffa oraria.
- Un mese ha 22 giorni fatturabili.

A volte il freelancer propone di applicare uno sconto sulla propria tariffa giornaliera (per esempio per i clienti più fedeli o per i clienti senza scopo di lucro).

Gli sconti sono rappresentati come numeri frazionari che esprimono percentuali, per esempio `25.0` (25%).

~~~~exercism/note
Questi sono i suffissi delle istruzioni in virgola mobile:

| Suffisso | Dimensione dell'operando |
|--------|--------------|
| `ss`   | 32 bit       |
| `sd`   | 64 bit       |

Queste sono alcune delle istruzioni menzionate in questo concetto:

| Istruzione       | Descrizione                                                  |
|-------------------------|--------------------------------------------------------|
| movss/movsd a, b        | copia b in a                                          |
| addss/addsd a, b        | a = a + b                                              |
| subss/subsd a, b        | a = a - b                                              |
| mulss/mulsd a, b        | a = a * b                                              |
| divss/divsd a, b        | a = a / b                                              |
| cvtsi2ss/cvtsi2sd a, b  | converte l'intero b nel numero in virgola mobile a                 |
| roundss/roundsd a, b, c | arrotonda il numero in virgola mobile b secondo c e lo memorizza in a |
| cvtss2si/cvtsd2si a, b  | converte il numero in virgola mobile b nell'intero a                 |
| comiss/comisd a, b      | fa un confronto tra a e b, solleva un'eccezione se `NaN` |
| ucomiss/ucomisd a, b    | fa un confronto tra a e b, imposta `PF` se `NaN` |

Questi sono i numeri di controllo dell'arrotondamento in `roundss` e `roundsd`:

| Numero | Modalità         |
|:-------|:-------------|
| 0      | Al più vicino      |
| 1      | Per difetto (down) |
| 2      | Per eccesso (up)    |
| 3      | Troncamento     |
~~~~

## 1. Calcola la tariffa giornaliera data una tariffa oraria

Implementa una funzione chiamata `daily_rate` per calcolare la tariffa giornaliera data come parametro una tariffa oraria, come numero in virgola mobile a 64 bit.
Il contratto stabilisce che un giorno ha 8 ore fatturabili.

```c
daily_rate(60)
// => 480.0
```

La tariffa giornaliera restituita deve essere un numero in virgola mobile a 64 bit.

## 2. Calcola un prezzo scontato

Implementa una funzione `apply_discount` per calcolare il prezzo dopo uno sconto.
Deve accettare due parametri: il prezzo originale e la percentuale di sconto, entrambi come numeri in virgola mobile a 64 bit.

```c
apply_discount(150.0, 10.0)
// => 135.0
```

Il valore restituito deve essere sempre un numero in virgola mobile a 64 bit.

## 3. Calcola la tariffa mensile, data una tariffa oraria e uno sconto

Implementa una funzione `monthly_rate` per calcolare la tariffa mensile scontata.
Prende due parametri, una tariffa oraria e lo sconto in percentuale, entrambi come numeri in virgola mobile a 64 bit.

```c
monthly_rate(77.0, 10.5)
// => 12130
```

La tariffa mensile restituita deve essere arrotondata per eccesso all'intero a 64 bit più vicino.

## 4. Calcola il numero di giornate lavorative complete dati un budget, una tariffa oraria ed uno sconto

Implementa una funzione `days_in_budget` che prende come parametri:

1. Un budget, come intero senza segno a 64 bit.
2. Una tariffa oraria, come numero in virgola mobile a 64 bit.
3. Uno sconto in percentuale, come numero in virgola mobile a 64 bit.

Questa funzione deve restituire il numero di giornate lavorative complete coperte dal budget.

```c
days_in_budget(20000, 80, 11.0)
// => 35
```

Il numero di giorni restituito deve essere arrotondato per difetto all'intero a 32 bit più vicino.
