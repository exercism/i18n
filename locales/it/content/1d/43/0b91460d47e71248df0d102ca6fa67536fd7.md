# Suggerimenti

## Generali

- Leggi la sezione sulla composizione di funzioni nel [manuale][function-composition-manual].
- Dai un'occhiata ai [metodi disponibili per le _stringhe_][string-methods].

## 1. Ripulisci il nome

- Esiste un [metodo integrato][string-replace] per sostituire tutte le occorrenze di una sottostringa in una stringa.
- Esiste un [metodo integrato][string-strip] per rimuovere gli spazi bianchi all'inizio e alla fine di una stringa.

## 2. Ottieni la prima lettera del nome

- Per ottenere un carattere specifico da una stringa, puoi usare l'[indicizzazione][string-indexing].
- Il modo più pulito per scriverlo è usare l'operatore di composizione `∘`.

## 3. Formatta la prima lettera come iniziale

- Esiste un [metodo integrato][string-uppercase] per convertire tutti i caratteri di una stringa nella loro variante maiuscola.

## 4. Inserisci le iniziali dentro il cuore

- Puoi usare caratteri unicode nelle stringhe in questo modo: `'\u<id>'`, dove, nel caso dell'emoji cuore, l'id è `2764`.
- Puoi farlo con la [concatenazione][string-concatenation] o l'[interpolazione][string-interpolation].
