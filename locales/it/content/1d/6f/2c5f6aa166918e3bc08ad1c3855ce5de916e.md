# Installare Emacs

Dato che Emacs Lisp (elisp) è il linguaggio di estensione di Emacs, per prima cosa dovrai installare [GNU Emacs](http://www.gnu.org/software/emacs/).

Ti consigliamo di procurarti l'ultima versione di Emacs, ma per gli esercizi va considerata come implementazione di riferimento la 28.1 o superiore.
Se hai già installato Emacs, puoi controllare la versione con `M-x emacs-version RET`.

## Su OS X
Il modo più semplice è visitare [Emacs For Mac OS X](http://emacsformacosx.com/) e scaricare il dmg, che installerà GNU Emacs come applicazione OS X pacchettizzata.

Esistono alternative, come Aquamacs (sconsigliato) o l'installazione tramite [Homebrew](https://formulae.brew.sh/formula/emacs), se preferisci.

## Su Linux
Su alcune distribuzioni Emacs è già installato, dato che fa parte di GNU.

### Ubuntu
Il modo attualmente consigliato per installare l'ultima versione di Emacs è tramite [snap](https://snapcraft.io/emacs):

```
sudo snap install emacs --classic
```

Se non vuoi usare snap, puoi installare Emacs anche tramite snap, ma la versione disponibile nei repository di Ubuntu è spesso obsoleta.
Se vuoi installare una versione più recente di Emacs tramite apt, dovrai usare un [PPA](https://launchpad.net/ubuntu/+ppas?name_filter=emacs) oppure [compilarlo dai sorgenti](https://www.emacswiki.org/emacs/BuildingEmacs).

Se non ti interessa installare l'ultima versione, dovrebbe bastare:

```
sudo apt-get install emacs
```

### Arch
Arch di solito distribuisce l'ultima versione di Emacs, quindi esegui:

```
sudo pacman -S emacs
```

e dovresti essere a posto.

### Altre distribuzioni
Controlla con la tua distribuzione quale versione è disponibile e usa il tuo gestore di pacchetti o compila dai sorgenti, a seconda dei casi.

### Windows
Per installare Emacs su Windows, vai al [mirror FTP](https://ftpmirror.gnu.org/emacs/windows) più vicino, scarica l'installer (=emacs-XX.X-installer.exe=) e avvialo.
Se vuoi usare Emacs senza installarlo, puoi scaricare il file con il pattern =emacs-XX.x.zip=, scompattarlo e avviare `bin\runemacs.exe`.

Se usi [MSYS2](https://www.msys2.org/) puoi installare la build a 64 bit di Emacs con

```
pacman -S mingw-w64-x86_64-emacs
```

oppure la build a 32 bit con

```
pacman -S mingw-w64-i686-emacs
```
