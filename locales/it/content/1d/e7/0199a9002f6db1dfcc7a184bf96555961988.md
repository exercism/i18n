# Informazioni

## Istruzioni condizionali

Le istruzioni condizionali sono istruzioni decisionali che possono eseguire effetti collaterali oppure controllare il flusso di esecuzione di un programma.
Tra le istruzioni condizionali ci sono `if`, `if/else`, `switch` e `ternary`.

Le istruzioni condizionali servono a fare domande su un valore o su una relazione tra valori.
La domanda si valuta in una risposta booleana, ma l'istruzione `if` stessa può restituire un valore qualsiasi, oppure può semplicemente eseguire un effetto collaterale.

## Istruzioni if

L'istruzione `if` più semplice valuta un'espressione ed esegue una sola riga.
L'espressione che viene valutata è sempre racchiusa tra parentesi.

Può eseguire un effetto collaterale

```c
if (count > 10)
    printf("count is greater than 10");
```

oppure può cambiare il flusso di esecuzione


```c
if (count > 10)
    return sum;
```

Se un'istruzione `if` esegue più di una riga, deve racchiudere le righe tra parentesi graffe

```c
if (count > 10) {
    printf("count is greater than 10");
    return sum;
}
```

Alcuni team di sviluppo possono stabilire come regola che le istruzioni `if` usino sempre le parentesi graffe, anche per una sola riga.


## If else

Un'istruzione `if` può essere abbinata a un `else`

```c
if (number % 2 == 0)
    return "even";
else
    return "odd";
```

## If else if


`else` può essere abbinato a un altro `if` per creare quella che viene chiamata `if-else-if ladder`.

```c
if (number == 0)
    return "zero";
else if (number < 0)
    return "negative";
else if (number < 10)
    return "single digit";   
else if (number % 2 == 0)
    return "even";
else
    return "odd";
```

## Switch


A volte una `if-else-if ladder` può essere rappresentata meglio da uno `switch`.
Come per `if`, l'espressione che viene valutata è sempre messa tra parentesi.

```c
switch (number) {
    case -1:
        return "negative one";
    case 0:
        return "zero";
    case 1:
        return "positive one";
    case 10:
        return "positive ten";
    case -10:
        return "negative ten";
    default:
        return "don't care";
}
```

Il caso `default` viene eseguito se il valore in esame non corrisponde a nessuno dei casi precedenti.

Se un caso di `switch` non restituisce un valore, di solito si inserisce un `break` per terminare ogni caso; altrimenti la logica «cade» nel caso successivo.
A volte il fallthrough viene usato intenzionalmente

```c
switch (number) {
    case 0:
        msg = "zero"; break;
    case 1:
        msg = "one"; break;
    case 2: case 3: case 4:
        msg = "more than one and less than five"; break;
    default:
        msg = "don't care";
}
```

Quando il fallthrough avviene in modo non intenzionale, è un bug.

```c
switch (number) {
    case 0:
        msg = "zero"; // bug! fallthrough of 0 will set msg to "one"
    case 1:
        msg = "one"; break; 
    case 2: case 3: case 4:
        msg = "more than one and less than five"; break;
    default:
        msg = "don't care";
}
```

Uno switch può essere vantaggioso quando si verifica rispetto a valori specifici anziché a un intervallo di valori.
Può essere più veloce di una `if-else-if ladder` perché il compilatore può ottimizzare l'istruzione `switch` in modi che non può applicare a una scala.
A volte uno switch può risultare più leggibile di una scala.

## Operatore ternario (detto anche condizionale)

L'operatore ternario è un'istruzione condizionale in tre parti, spesso usata per assegnare un valore.
L'espressione da valutare precede il punto interrogativo e non deve necessariamente trovarsi tra parentesi.
Il valore restituito quando la condizione è vera precede i due punti, quello restituito quando è falsa li segue.
Si può restituire sia un valore letterale sia una variabile.

```c
int i = j > 5 ? 5: j;
```

Gli operatori ternari possono essere annidati per ridurre il disordine sintattico.

```c
// the below could also be 
i = j > 5 ? j :k > 5 ? k: 10;
// but that may not be quite as readable

i = j > 5 ? j
    :k > 5 ? k
    :10;

// which is the same as
if (j > 5) i = j;
else if (k > 5) i = k;
else i = 10;
```

## Confronti condizionali tra numeri in virgola mobile

Poiché i numeri in virgola mobile sono implementati in un certo modo, una semplice operazione matematica può produrre un errore di arrotondamento che può far sì che un test di uguaglianza non restituisca il risultato atteso.

```c
    a = 1.345f;
    b = 1.123f;
    c = a + b;
    // c may equal something like 2.4679999352
    if (c == 2.468)
        return "I won the lottery!";
```

Un valore di tolleranza, chiamato `epsilon`, può essere usato per determinare un intervallo entro cui un valore può ricadere pur essendo considerato uguale a un altro.
Alcune piattaforme hanno costanti predefinite per gli epsilon di float e double.
Consulta la documentazione del tuo compilatore per saperne di più.
Calcolare l'epsilon può essere complicato e può variare da piattaforma a piattaforma, persino tra singole macchine.
Ecco un programma di esempio che usa un semplice confronto.

```c
#include <stdio.h>
#include <math.h>
#include <stdbool.h>

const double MY_EPSILON = .002;

bool same(double x, double y)
{
    return fabs(x - y) < MY_EPSILON;
}

int main()
{
    // Same should return true if the difference is less than MY_EPSILON
    printf("%s\n", same(1.1, 1.099) ? "true" : "false"); // prints true
    printf("%s\n", same(1.1, 1.098) ? "true" : "false"); // prints false
    return 0;
}
```

Fai attenzione quando confronti `float` o `double` per verificarne l'uguaglianza!
