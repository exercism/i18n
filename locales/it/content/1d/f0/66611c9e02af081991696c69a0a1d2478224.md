# Appendice alle istruzioni

## Output

In questo esercizio implementerai un verbo che genera il triangolo di Pascal fino a un numero di righe dato. L'output del verbo può essere formattato in uno dei due modi seguenti:

  1. Come un array di liste boxed, in cui ogni lista rappresenta una riga del triangolo di Pascal.
  1. Come una tabella, in cui i numeri sono allineati a destra e gli zeri riempiono gli spazi vuoti a sinistra.

### Output di esempio

Ecco due output validi per `pascal 3`:

  - Come un array di liste boxed:
```j
  (1 ; 1 1 ; 1 2 1) -: pascal 3          NB. This test will pass
```
  - Come una tabella con riempimento:
```j
  (3 3$1 0 0 1 1 0 1 2 1) -: pascal 3   NB. This test also passes
```
