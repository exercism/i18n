# Informazioni

La cosa più importante da ricordare sulle stringhe di Java è che sono oggetti immutabili che rappresentano del testo come una sequenza di caratteri Unicode (lettere, cifre, punteggiatura e così via).
Per definire un'istanza di `String` si usano le virgolette doppie:

```java
String fruit = "Apple";
```

Per manipolare una stringa si possono usare i metodi della classe [`String`][string-class].
Poiché i valori di tipo stringa non possono mai cambiare dopo essere stati definiti, tutti i metodi di manipolazione delle stringhe restituiscono una nuova stringa.

Una stringa è delimitata da virgolette doppie (`"`).
Alcuni caratteri speciali richiedono l'escape tramite la barra rovesciata (`\`).
I caratteri che richiedono l'escape in Java:

- `"`
- `\`

```java
String escaped = "c:\\test.txt";
// => c:\test.txt
```

Infine, ci sono molti modi per concatenare una stringa.
Il più semplice è l'operatore `+`:

```java
String name = "Jane";
"Hello " + name + "!";
// => "Hello Jane!"
```

Per qualsiasi formattazione di stringa più complessa di una semplice concatenazione, è preferibile il metodo `String.format`.

```java
String name = "Jane";
String.format("Hello %s!",name);
// => "Hello Jane!"
```

Altre possibilità sono:

- usare la [classe `StringBuilder`][string-builder]
- usare il [metodo `String.concat`][string-concat]
