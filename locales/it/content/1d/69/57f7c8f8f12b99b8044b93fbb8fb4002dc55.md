# Informazioni

Il pattern matching è il processo di diramazione in base alla corrispondenza di un valore con determinati pattern, anche profondi. In Haxe, il **pattern matching** si fa usando l'espressione `switch` e le singole espressioni `case`.

Considera questa struttura dati:

```haxe
enum Tree<T> {
  Leaf(v:T);
  Node(l:Tree<T>, r:Tree<T>);
}
```

- I pattern vengono sempre confrontati dall'alto verso il basso.
- Viene eseguita l'espressione del pattern più in alto che corrisponde al valore di input.
- Un pattern `_` corrisponde a qualsiasi cosa, quindi `case _:` equivale a `default:`

## Pattern matching sugli enum

Gli enum si possono confrontare in base al loro costruttore in modo naturale:

```haxe
var myTree = Node(Leaf("foo"), Node(Leaf("bar"), Leaf("foobar")));

var match = switch (myTree) {
  // Matches any Leaf
  case Leaf(_):
    "0";

  // Matches any Node that has r = Leaf
  case Node(_, Leaf(_)):
    "1";

  // Matches any Node that has
  // r = another Node which has
  // l = Leaf("bar")
  case Node(_, Node(Leaf("bar", _))):
    "2";

  // Matches anything
  case _:
    "3";
}

trace(match); // 2
```
