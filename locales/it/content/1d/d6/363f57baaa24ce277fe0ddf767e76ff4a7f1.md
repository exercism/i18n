# Suggerimenti

## 1. Leggere gli indirizzi email da un file

- La [funzione `simplifile.read`][file-read] può essere usata per leggere il contenuto di un file.

## 2. Creare un file di log per la scrittura

- La [funzione `simplifile.create_file`][file-create] può essere usata per creare un file vuoto.

## 3. Registrare un'email inviata

- La [funzione `simplifile.append`][file-append] può essere usata per aggiungere testo a un file.

## 5. Inviare la newsletter

- Tutte le operazioni necessarie sui file sono già state implementate nei passaggi precedenti.
- La [funzione `result.try`][result-try] e la [funzione `list.try_each`][list-try-each] possono essere usate per lavorare con il tipo `Result`.
