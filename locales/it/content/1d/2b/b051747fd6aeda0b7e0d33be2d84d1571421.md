# Appendice alle istruzioni

## Formato dell'output

Restituisci il testo della canzone come stringa terminata da null.

## Registri

| Registro | Uso          | Tipo    | Descrizione                    |
| -------- | ------------ | ------- | ------------------------------ |
| `$a0`    | input        | intero  | bottiglie iniziali             |
| `$a1`    | input        | intero  | bottiglie da togliere          |
| `$a2`    | input/output | indirizzo | stringa di output terminata da null |
| `$t0-9`  | temporaneo   | qualsiasi | per la memorizzazione temporanea |
