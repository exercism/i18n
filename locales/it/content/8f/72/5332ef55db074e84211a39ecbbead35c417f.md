## Istruzioni

Il tuo compito è generare i labirinti perfetti per Mickey e Minerva: quelli con una sola soluzione e senza sezioni isolate. 
Ecco cosa devi sapere:

- Il labirinto ha una forma rettangolare con un'apertura all'inizio e alla fine.
- Il labirinto ha stanze e passaggi, che si intersecano ad angolo retto.
- Il programma dovrebbe accettare due parametri: rows e columns. Il labirinto deve avere una dimensione compresa tra 5 e 100 celle.
- Un labirinto largo `x` colonne e alto `y` righe dovrebbe essere largo `2x + 1` caratteri e alto `2y + 1` caratteri.
- Se non viene fornito alcun seed, genera un labirinto casuale. Se lo stesso seed viene fornito più volte, il labirinto risultante dovrebbe essere sempre lo stesso.
- Usa i [caratteri di disegno a riquadri][Box-drawing] per disegnare i muri e un simbolo a freccia (⇨) per l'ingresso a sinistra e l'uscita a destra.

È il momento di creare dei labirinti perfetti per questi topi avventurosi!

### Esempi

1. Il piccolo labirinto quadrato 5x5 celle (o 11x11 caratteri)
```text
	┌───────┬─┐
	│       │ │
	│ ┌─┬── │ │
	│ │ │   │ ⇨
	│ │ │ ──┤ │
	⇨ │ │   │ │
	┌─┤ └── │ │
	│ │     │ │
	│ │ ────┘ │
	│         │
	└─────────┘
```
2. Il labirinto rettangolare 6x18 celle
```text
	┌───────────┬─────────┬───────────┬─┐
	│           │         │           │ │
	│ ┌───────┐ │ ┌─┐ ──┐ └───┐ ┌───┐ │ │
	│ │       │ │ │ │   │     │ │   │   ⇨
	│ └─┐ ┌─┐ │ │ │ ├── ├───┐ │ │ ──┼── │
	│   │ │ │   │   │   │   │ │ │   │   │
	└── │ │ ├───┴───┤ ┌─┘ ┌─┘ │ ├── │ ──┤
	⇨   │   │       │ │   │   │ │   │   │
	┌─┬─┴─┐ └─┐ ┌─┐ │ └─┐ │ ┌─┘ │ ──┴─┐ │
	│ │   │   │ │ │ │   │   │   │     │ │
	│ │ │ └── │ │ │ └── │ ──┘ ┌─┘ ──┐ │ │
	│   │       │       │     │     │   │
	└───┴───────┴───────┴─────┴─────┴───┘
```
