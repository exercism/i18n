# Istruzioni

È San Valentino. Il tuo partner ha alcune idee per delle attività e ti
chiede di valutarle: `yes`, `no` o `maybe`.

Le attività sono rappresentate come array di 2 elementi `{ tag value }`,
dove `tag` è uno tra `board-game`, `chill`, `movie`, `restaurant`
o `walk`.

| attività                      | forma                          |
| ----------------------------- | ------------------------------ |
| Fare un gioco da tavolo       | `{ board-game f }`             |
| Rilassarsi                    | `{ chill f }`                  |
| Guardare un film di `genre`   | `{ movie genre }`              |
| Mangiare in un locale di cucina `cuisine` | `{ restaurant cuisine }` |
| Camminare per `km` chilometri | `{ walk km }`                  |

Il genere è uno tra `crime`, `horror`, `romance`, `thriller`. La
cucina è `korean` oppure `turkish`.

## 1. Valuta la cucina

Definisci `rate-restaurant` in modo che prenda una cucina dallo stack e
restituisca la tua valutazione:

- `korean` → `yes`
- `turkish` → `maybe`

```factor
korean rate-restaurant .   ! => yes
turkish rate-restaurant .  ! => maybe
```

## 2. Valuta il genere del film

Definisci `rate-movie` in modo che prenda un genere e restituisca:

- `romance` → `yes`
- qualsiasi altra cosa → `no`

```factor
romance rate-movie .   ! => yes
horror rate-movie .    ! => no
```

## 3. Valuta la camminata

Definisci `rate-walk` in modo che prenda un numero di chilometri e
restituisca:

- più di `11` → `yes`
- più di `6`, fino a `11` → `maybe`
- altrimenti → `no`

```factor
12 rate-walk .   ! => yes
8 rate-walk .    ! => maybe
3 rate-walk .    ! => no
```

## 4. Valuta l'attività

Definisci `rate-activity` in modo che prenda dallo stack un'attività
`{ tag value }` e restituisca la tua valutazione. Riutilizza le funzioni
ausiliarie qui sopra:

- `board-game`, `chill` → sempre `no`
- `movie` → demanda a `rate-movie`
- `restaurant` → demanda a `rate-restaurant`
- `walk` → demanda a `rate-walk`

```factor
{ restaurant turkish } rate-activity .   ! => maybe
{ movie horror } rate-activity .         ! => no
{ walk 12 } rate-activity .              ! => yes
{ board-game f } rate-activity .         ! => no
```

## 5. Conta le valutazioni

Definisci `approval-counts` in modo che prenda un array di attività e
restituisca un array di 3 elementi `{ yes-count maybe-count no-count }`
con quante attività sono state valutate in ciascun modo.

```factor
{ { restaurant korean } { restaurant turkish } { walk 3 } { movie romance } }
approval-counts .
! => { 2 1 1 }
```
