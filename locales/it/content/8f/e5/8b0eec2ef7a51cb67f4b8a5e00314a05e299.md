# Inserimento dei dipendenti nel database

## Descrizione del problema

ABC Corp intende tenere in un database tutte le informazioni sui pagamenti in contanti di piccolo importo ai dipendenti. Stai aiutando il reparto finanziario di ABC Corp a implementarlo. Dato che ABC Corp sta ampliando le proprie attività, aggiungere nuovi dipendenti al sistema è un'esigenza frequente, a causa delle nuove assunzioni.

Il tuo compito è aggiungere alla tabella `Employee` del database i dettagli del nuovo dipendente forniti e restituire il valore della colonna `employee_id` generata automaticamente, senza eseguire un'altra query al database per trovarlo. Se durante l'esecuzione si verifica un errore, va restituito `-1`.

## Dettagli del database

Per questo problema usa il database H2 fornito.

> Il file del database di esempio è `gofigure.mv.db` e il nome del database è `gofigure`. Si trova nella cartella `db`.

Nel database H2 di esempio sono già presenti le seguenti tabelle, con alcuni dati di esempio. I nomi delle colonne e i tipi di dati sono riportati di seguito.

**Nome tabella**: `Employee`

| **Colonne:**      | tipo |
| -----------       | ----------- |
| `employee_id`     | intero, chiave primaria con incremento automatico       |
| `name`            | stringa        |
| `city`            | stringa        |
| `department`      | stringa        |
| `age`             | intero        |

**Nome tabella**: `Payment`

| **Colonne:**      | tipo |
| -----------       | ----------- |
| `payment_id`      | intero, chiave primaria con incremento automatico       |
| `date`            | data        |
| `amount`          | numero decimale        |
| `employee_id`     | intero        |
| `reason`          | stringa        |

* Il file del database è `gofigure.mv.db`. Usa come URL JDBC `jdbc:h2:file:/path/to/db/file`
* Nome utente: `root`
* Password: `root`

## Vincoli

* Usa il file del database H2 fornito nella cartella `db` per convalidare le query e l'esempio Ballerina
* Usa l'approccio dei parametri di dipendenza di Maven per aggiungere il driver del database H2 come dipendenza di piattaforma nel file Ballerina.toml
* Non eseguire un'altra query al database per trovare l'id generato automaticamente


## Ambiente di test

* Puoi eseguire i test con `bal test`: verranno eseguiti sul database di esempio fornito.

## Esempi

### Esempio 1

**Input** : dbFilePath: `"./db/gofigure"`, name : `“John Doe”`, city: `“Omaha”`, department : `“Sales”`, age: `24`

**Output** : `4`

### Esempio 2

**Input** : dbFilePath: `"./db/invalidDB"`, name : `“John"`, city: `"Colombo"`, department : `"HR"`, age: `25`
