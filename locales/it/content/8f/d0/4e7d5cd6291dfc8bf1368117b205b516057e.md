# Operatore di risoluzione dello scope

L'operatore di risoluzione dello scope (`::`) ci permette di fare riferimento a una classe per accedere alle sue costanti, alle proprietà statiche o ai metodi statici.

```php
class MyClass
{
  public const MY_VALUE = 1;
}

// MyClass::class => "MyClass"
// MyClass::MY_VALUE => 1
```

## Usare `self` e `static` con l'operatore di risoluzione dello scope

A volte può servire che un oggetto faccia riferimento al proprio scope. Per rendere possibile tutto questo, la parola chiave `self` permette a una classe di fare riferimento al proprio scope. Usare la parola chiave `self` scollega la classe dal suo stesso nome, il che rende più facile mantenere il codice nel tempo.

```php
class MyClass
{
  public const MY_VALUE = 1;

  public function getMyValue(): int
  {
    return self::MY_VALUE;
  }
}

// (new MyClass)->getMyValue() => 1
```

Usa la parola chiave `static` con l'operatore di risoluzione dello scope per «late bind» del riferimento alla classe discendente corrente.

```php
// Update MyClass:
class MyClass
{
  public const MY_VALUE = 1;

  public function getMyValue(): int
  {
    return static::MY_VALUE;
  }
}
```

## Usare `parent` con l'operatore di risoluzione dello scope

La parola chiave `parent` serve a fare riferimento a costanti, proprietà o metodi della classe padre. Di solito viene usata per chiamare il costruttore della classe padre quando si istanzia un oggetto:

```php
class ChildClass extends ParentClass
{
  public function __construct(): void
  {
    parent::__construct();
  }
}
```

## Avvertenze

### Visibilità di costanti, proprietà e metodi

L'operatore di risoluzione dello scope segue comunque le regole stabilite dai modificatori di visibilità `public`, `private` e `protected`.
