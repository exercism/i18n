# Introduzione

Ogni istanza di una struct o di una classe ha una proprietà implicita chiamata `self`, che fa riferimento all'istanza stessa.
L'uso più comune di `self` è distinguere tra una proprietà di istanza e un parametro che ha lo stesso nome:

```swift
struct Position {
    var x = 0

    mutating func move(x: Int) {
        // Here, 'self.x' refers to the struct's property,
        // while 'x' refers to the parameter passed to the method.
        self.x = x
    }
}
```

I tipi Swift forniscono anche una parola chiave `Self` con l'iniziale maiuscola, che si riferisce al *tipo* dell'istanza, non all'istanza stessa.
