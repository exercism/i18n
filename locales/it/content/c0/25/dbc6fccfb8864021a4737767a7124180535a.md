# Test

## Clojure CLI

Gli esercizi di Clojure su Exercism includono un file `deps.edn` con un alias `:test` per invocare il [cognitect-labs test-runner](https://github.com/cognitect-labs/test-runner):

``` bash
$ clj -X:test
```

Questo esaminerà la cartella `test` del progetto alla ricerca di tutti i test definiti con `clojure.test` e li eseguirà.

## Leiningen

Per eseguire i test di un esercizio con Leiningen, basta lanciare:

``` bash
$ lein test

lein test bob-test

Ran 14 tests containing 14 assertions.
0 failures, 0 errors.
```
