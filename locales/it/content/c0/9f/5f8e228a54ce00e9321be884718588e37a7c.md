# Istruzioni

Il lavoro sul progetto dell'auto radiocomandata continua. La larghezza di banda nel sistema di telemetria scarseggia e ti è stato chiesto di implementare un protocollo di messaggi per comunicare i dati di telemetria.

I dati vengono trasmessi in un buffer (un array di byte). Quando si inviano numeri interi, la dimensione del buffer viene ridotta applicando il protocollo descritto di seguito.

Ogni valore dovrebbe essere rappresentato con il tipo intero più piccolo possibile (i tipi `byte` e `sbyte` non sono inclusi, perché il risparmio sarebbe trascurabile):

| Da                         | A                         | Tipo     |
| -------------------------- | ------------------------- | -------- |
| 4_294_967_296              | 9_223_372_036_854_775_807 | `long`   |
| 2_147_483_648              | 4_294_967_295             | `uint`   |
| 65_536                     | 2_147_483_647             | `int`    |
| 0                          | 65_535                    | `ushort` |
| -32_768                    | -1                        | `short`  |
| -2_147_483_648             | -32_769                   | `int`    |
| -9_223_372_036_854_775_808 | -2_147_483_649            | `long`   |

Il valore dovrebbe essere convertito nel numero di byte appropriato per il tipo assegnato. Il buffer completo comprende un byte che indica il numero di byte aggiuntivi nel buffer (_byte di prefisso_), seguito dai byte che contengono il numero intero (_byte di payload_).

Alcuni tipi usano lo stesso numero di byte (ad esempio i tipi `uint` e `int`). Normalmente avrebbero lo stesso _byte di prefisso_, ma questo renderebbe problematica la decodifica. Per ovviare a questo, il protocollo introduce un piccolo trucco: per i tipi con segno, il valore del loro _byte di prefisso_ è `256` meno il numero di byte aggiuntivi nel buffer.

Nella comunicazione verranno inviati solo il byte di prefisso e il numero di byte successivi indicati dal prefisso. Internamente viene usato un buffer di 9 byte (con gli zeri finali, se necessario), sia dalle routine di invio che da quelle di ricezione.

## 1. Codificare un valore intero pronto per l'invio

Implementa il metodo statico `TelemetryBuffer.ToBuffer()` per codificare un buffer prendendo il parametro passato al metodo.

```csharp
// Type: ushort, bytes: 2, signed: no, prefix byte: 2
TelemetryBuffer.ToBuffer(5)
// => {0x2, 0x5, 0x0, 0x0, 0x0, 0x0, 0x0, 0x0, 0x0 };

// Type: int, bytes: 4, signed: yes, prefix byte: 256 - 4
TelemetryBuffer.ToBuffer(Int32.MaxValue)
// => {0xfc, 0xff, 0xff, 0xff, 0x7f, 0x0, 0x0, 0x0, 0x0 };
```

## 2. Decodificare un buffer ricevuto

Implementa il metodo statico `TelemetryBuffer.FromBuffer()` per decodificare il buffer ricevuto e restituire il valore sotto forma di `long`.

```csharp
TelemetryBuffer.FromBuffer(new byte[] {0xfc, 0xff, 0xff, 0xff, 0x7f, 0x0, 0x0, 0x0, 0x0 })
// => 2147483647
```

Se il byte di prefisso ha un valore inatteso, allora dovrebbe essere restituito `0`.
