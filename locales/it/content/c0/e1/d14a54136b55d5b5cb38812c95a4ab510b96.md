# Istruzioni

Dato un testo di input, produci come output la sua trasposizione.

Detto in parole povere, la trasposta di una matrice:

```text
ABC
DEF
```

è data da:

```text
AD
BE
CF
```

Le righe diventano colonne e le colonne diventano righe. Vedi <https://en.wikipedia.org/wiki/Transpose>.

Se l'input ha righe di lunghezza diversa, si procede così:

- Riempi a sinistra con degli spazi.
- Non riempire a destra.

Quindi, trasponendo questa matrice:

```text
ABC
DE
```

si ottiene:

```text
AD
BE
C
```

E trasponendo:

```text
AB
DEF
```

si ottiene:

```text
AD
BE
 F
```

In generale, tutti i caratteri dell'input devono essere presenti anche nell'output trasposto. Ciò significa che se una colonna del testo di input contiene solo spazi nelle sue righe più in basso, la riga corrispondente dell'output deve contenere quegli spazi nelle sue colonne più a destra.
