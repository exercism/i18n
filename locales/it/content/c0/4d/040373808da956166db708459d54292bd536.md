# Introduzione

Oltre all'istruzione `if`, esiste anche l'istruzione `switch` per eseguire del codice in modo condizionale. Si usa quando una singola variabile va confrontata con più varianti. Per una variabile x, l'istruzione `switch` in Haxe ha la seguente sintassi.

```haxe
var a = 2;

switch (a) {
  case 0:
    trace("a is 0");
  case 1:
    trace("a is 1");
  case 2:
    trace("a is 2");
  default:
    trace("a is something else");
}

// a is 2
```

Il caso `default` viene eseguito quando nessun altro caso corrisponde.
