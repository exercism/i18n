# Introduzione

Un file non è altro che uno stream con un nome su disco. Il vocabulary [`io.files`][io.files] ti offre due modi per lavorarci: word di comodo che leggono o scrivono l'intero file con una sola chiamata, e word che aprono uno stream, per quando vuoi leggere o scrivere in modo incrementale.

Ogni word che tocca un file richiede un **encoding**: lo schema che trasforma i byte in caratteri e viceversa. Per il testo, si tratta quasi sempre di [`utf8`][utf8] da `io.encodings.utf8`.

## Leggere un intero file

```
file-contents   ( path encoding -- str )
file-lines      ( path encoding -- seq )
```

`file-contents` restituisce l'intero file come un'unica stringa; `file-lines` restituisce un array delle sue righe, con i caratteri di fine riga rimossi.

```factor
USING: io.encodings.utf8 io.files prettyprint ;

"sunny\ncloudy\n" "forecast.txt" utf8 set-file-contents

"forecast.txt" utf8 file-contents .
! => "sunny\ncloudy\n"

"forecast.txt" utf8 file-lines .
! => { "sunny" "cloudy" }
```

## Scrivere un intero file

```
set-file-contents   ( str path encoding -- )
set-file-lines      ( seq path encoding -- )
```

Entrambe **sostituiscono** il contenuto del file (creandolo se necessario). `set-file-contents` scrive una stringa così com'è; `set-file-lines` scrive ogni elemento di una sequenza sulla propria riga, aggiungendo i fine riga per te.

```factor
USING: io.encodings.utf8 io.files prettyprint ;

{ "sunny" "cloudy" } "forecast.txt" utf8 set-file-lines
"forecast.txt" utf8 file-contents .
! => "sunny\ncloudy\n"
```

## Aggiungere contenuto a un file

Per aggiungere a un file senza cancellare ciò che c'è già, aprirlo con un combinatore `with-…` e scrivere sullo stream ambientale all'interno della quotation:

```
with-file-appender   ( path encoding quot -- )
with-file-reader     ( path encoding quot -- )
with-file-writer     ( path encoding quot -- )
```

```factor
USING: io io.encodings.utf8 io.files prettyprint ;

"sunny\ncloudy\n" "forecast.txt" utf8 set-file-contents
"forecast.txt" utf8 [ "rainy" print ] with-file-appender
"forecast.txt" utf8 file-contents .
! => "sunny\ncloudy\nrainy\n"
```

Come ogni combinatore `with-…`, questi sono destructor scope: l'handle del file viene chiuso quando la quotation termina, anche se questa solleva un'eccezione.
