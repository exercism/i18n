# Istruzioni

Leslie, l'alieno del Lisp, deve fare la spesa. Avere una lista della spesa è molto importante. Bisogna aggiungerci delle cose e toglierne delle altre.

Naturalmente, per un alieno del Lisp non bastano certo carta e penna. «List» è già buona parte della parola «Lisp»! Ci devono pur essere delle funzioni scritte per aiutare a tenere traccia della spesa.

Puoi aiutare Leslie a tenere traccia della lista della spesa?

## 1. Creare una nuova lista

Prima di tutto, Leslie deve creare una lista vuota. Una funzione chiamata `new-list` sarebbe perfetta per questo.

```lisp
(new-list) ; => ()
```

Oh no... Leslie ha già in mente qualche cosa, quindi serve una funzione che prenda tre elementi (per fortuna Leslie crea liste di soli tre elementi. Né più, né meno!) e che crei una nuova lista della spesa con quelle cose. Scrivi una funzione, `list-of-things`, che prende tre elementi e restituisce una lista che li contiene.

```lisp
(list-of-things 'bread 'milk 'butter) ; => '(bread milk butter)
```

## 2. Aggiungere cose alla lista.

Prima di andare al negozio, Leslie guarda nella dispensa per vedere cosa serve. Aiuta Leslie scrivendo la funzione `add-to-list`, che aggiunge un elemento all'inizio di una lista.

```lisp
(add-to-list 'butter '(bread)) ; => '(butter bread)
```

## 3. Quali sono le prossime cose sulla lista?

Mentre fa la spesa, Leslie vuole sapere cosa cercare dopo. A Leslie piace anche sbirciare avanti nella lista per vedere il secondo, il terzo o addirittura il ventitreesimo elemento (il suo numero fortunato).

- `first-thing` restituirà il primo elemento della lista
- `second-thing` restituirà il secondo elemento
- `third-thing` restituirà il terzo elemento
- `twenty-third-thing` restituirà il ventitreesimo elemento

```lisp
(first-thing '(bread butter milk)) ; => 'bread
(second-thing '(bread butter milk)) ; => 'butter
(third-thing '(bread butter milk)) ; => 'milk
```

## 4. Rimuovere una cosa dalla lista

Leslie vuole trovare il primo elemento della lista e rimuoverlo dallo scaffale. Aiuta Leslie scrivendo una funzione `remove-first-item`, che restituisce una lista con tutto tranne il primo elemento della lista di input.

```lisp
(remove-first-item '(bread butter milk)) ; => '(butter milk)
```

## 5. Liste più grandi a partire da liste più piccole

Leslie ha capito di aver fatto per sbaglio due liste della spesa, non una! Scrivi una funzione, `list-append`, che restituisce una lista con gli elementi della prima lista seguiti da quelli della seconda.

```lisp
(list-append '(bread salt) '(butter milk)) ; => '(bread salt butter milk)
```

## 6. Quanto è ancora lunga?

Leslie comincia a preoccuparsi che questa spesa richiederà parecchio tempo. Ma quante cose ci sono su questa lista? Scrivi una funzione `just-how-long` che dica quanto è lunga la lista.

```lisp
(just-how-long '(bread milk butter salt)) ; => 4
```
