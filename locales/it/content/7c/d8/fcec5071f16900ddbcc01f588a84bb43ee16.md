# Istruzioni

In questo esercizio scriverai ancora un po' di codice per preparare e cucinare la tua splendida lasagna, tratta dal tuo ricettario preferito.

Hai cinque attività.
La prima riguarda la cottura vera e propria, le altre quattro riguardano la preparazione perfetta.

## 1. Stabilire se la lasagna è pronta

Quando hai una lasagna nel forno, vuoi sapere se puoi già tirarla fuori oppure no.
Per essere sicuro che la lasagna non bruci nel forno, di solito imposti un timer.
A volte però te ne dimentichi.

Scrivi una funzione `cookingStatus` che accetta come parametro il tempo rimanente sul timer, in minuti.
La funzione ha tre possibili risultati.

- Se il timer mostra `0`, dovrebbe restituire `'Lasagna is done.'`.
- Se il timer mostra qualsiasi altro numero, il risultato dovrebbe essere `'Not done, please wait.'`.
- Se la funzione viene chiamata senza un valore per il timer, il risultato dovrebbe essere `'You forgot to set the timer.'`.

Il timer non mostrerà mai un valore inferiore a 0.

```javascript
cookingStatus(12);
// => 'Not done, please wait.'

cookingStatus();
// => 'You forgot to set the timer.'
```

## 2. Stimare il tempo di preparazione

Per la prossima lasagna che preparerai, vuoi essere sicuro di riservare abbastanza tempo per goderti la cucina.
Hai già fatto un piano con tutti gli strati che avrà la tua lasagna.
Ora vuoi stimare quanto tempo richiederà la preparazione, in base a quel piano.

Implementa una funzione `preparationTime` che accetta un array di strati e il tempo medio di preparazione per strato, in minuti.
La funzione dovrebbe restituire la stima del tempo totale di preparazione in base al numero di strati.
Se la funzione viene chiamata senza indicare il tempo medio di preparazione, si dovrebbe assumere `2` minuti.

```javascript
const layers = ['sauce', 'noodles', 'sauce', 'meat', 'mozzarella', 'noodles'];
preparationTime(layers, 3);
// => 18

preparationTime(layers);
// => 12
```

## 3. Calcolare le quantità di sfoglie e sugo necessarie

Oltre a riservare il tempo, vuoi anche essere sicuro di avere abbastanza sugo e sfoglie per cucinare la lasagna dei tuoi sogni.
Per ogni strato di sfoglie della tua lasagna ti serviranno 50 grammi di sfoglie.
Per ogni strato di sugo ti serviranno 0,2 litri di sugo.

Definisci la funzione `quantities` che prende un array di strati come parametro.
La funzione determinerà poi la quantità di sfoglie e sugo necessaria per preparare il tuo pasto.
Il risultato dovrebbe essere restituito come un oggetto con le chiavi `noodles` e `sauce`.

```javascript
quantities(['sauce', 'noodles', 'sauce', 'meat', 'mozzarella', 'noodles']);
// => { noodles: 100, sauce: 0.4 }
```

## 4. Aggiungere l'ingrediente segreto

Un po' di tempo fa hai fatto visita a un amico e hai mangiato la lasagna da lui.
Era fantastica e aveva qualcosa di speciale.
L'amico ti ha mandato la lista degli ingredienti e ti ha detto che l'ultimo elemento della lista è l'«ingrediente segreto» che ha reso il pasto così speciale.
Ora vuoi aggiungere anche tu quell'ingrediente segreto alla tua ricetta.

Scrivi una funzione `addSecretIngredient` che accetta due array di ingredienti come parametri.
Il primo parametro è la lista che ti ha mandato il tuo amico, il secondo è la lista di ingredienti della tua ricetta.
La funzione dovrebbe aggiungere l'ultimo elemento della lista del tuo amico in fondo alla tua lista.
L'array che rappresenta la tua ricetta dovrebbe essere modificato direttamente e la funzione non dovrebbe restituire nulla.
Il primo argomento, però, non dovrebbe essere modificato.

```javascript
const friendsList = ['noodles', 'sauce', 'mozzarella', 'kampot pepper'];
const myList = ['noodles', 'meat', 'sauce', 'mozzarella'];

addSecretIngredient(friendsList, myList);
// => undefined

console.log(myList);
// => ['noodles', 'meat', 'sauce', 'mozzarella', 'kampot pepper']
```

## 5. Ridimensionare la ricetta

Le quantità elencate nel tuo ricettario bastano solo per due porzioni.
Dato che la prossima volta vuoi cucinare per più persone, vuoi calcolare le quantità per numeri diversi di porzioni.

Implementa una funzione `scaleRecipe` che prende due parametri.

- Un oggetto ricetta che contiene le quantità necessarie per 2 porzioni.
  Il formato dell'oggetto si vede nell'esempio qui sotto.
- Il numero di porzioni che vuoi cucinare.

La funzione dovrebbe restituire un oggetto ricetta con le quantità necessarie per il numero di porzioni desiderato.
Vuoi però mantenere la ricetta originale.
Questo significa che, in questa attività, l'argomento ricetta non dovrebbe essere modificato.

```javascript
const recipe = {
  noodles: 200,
  sauce: 0.5,
  mozzarella: 1,
  meat: 100,
};

scaleRecipe(recipe, 4);
// =>
// {
//   noodles: 400,
//   sauce: 1,
//   mozzarella: 2,
//   meat: 200,
// };

console.log(recipe);
// =>
// {
//   noodles: 200,
//   sauce: 0.5,
//   mozzarella: 1,
//   meat: 100,
// };
```
