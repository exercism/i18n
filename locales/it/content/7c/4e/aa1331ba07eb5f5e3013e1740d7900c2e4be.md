# Informazioni

C# è un linguaggio a tipizzazione statica, il che significa che ogni cosa ha un tipo in fase di compilazione. Scegliere un nome per una [variabile][variable] si chiama definire una variabile. Una volta definita una variabile, impostare o aggiornare un valore si chiama assegnazione di variabile. Una variabile può essere definita specificando esplicitamente il suo tipo oppure usando la [parola chiave `var`][var] per far dedurre al compilatore C# il tipo in base al valore assegnato. L'uso di `var` è noto come _inferenza di tipo_.

```csharp
int explicitVar = 10; // Explicitly typed
var implicitVar = 10; // Implicitly typed
```

Il valore di una variabile può essere assegnato e aggiornato usando l'[operatore `=`][assignment]. Una volta definita, il tipo di una variabile non può mai cambiare.

```csharp
var count = 1; // Assign initial value
count = 2;     // Update to new value

// Compiler error when assigning different type
// count = false;
```

C# è un linguaggio orientato agli oggetti e richiede che tutte le [funzioni][function] siano definite all'interno di una _classe_, che a sua volta si definisce usando la [parola chiave `class`][classes]. Gli oggetti (o _istanze_) si creano usando la parola chiave `new`.

```csharp
class Calculator
{
    // ...
}

var calculator = new Calculator();
```

Una funzione all'interno di una classe si chiama _metodo_. Ogni [metodo][methods] può avere zero o più parametri. Tutti i parametri devono avere un tipo esplicito: per i parametri non esiste l'inferenza di tipo. Allo stesso modo, anche il tipo restituito deve essere esplicitato. I valori vengono restituiti dai metodi usando la [parola chiave `return`][return]. Per consentire a codice in altri file di chiamare un metodo, occorre aggiungere il modificatore di accesso `public`.

```csharp
class Calculator
{
    public int Add(int x, int y)
    {
        return x + y;
    }
}
```

I metodi si chiamano usando la sintassi con il punto (`.`) su un'istanza, specificando il nome del metodo da chiamare e passando gli argomenti per ciascuno dei parametri del metodo. Gli argomenti possono specificare facoltativamente il nome del parametro corrispondente.

```csharp
var calculator = new Calculator();
var sum_v1 = calculator.Add(1, 2);
var sum_v2 = calculator.Add(x: 1, y: 2);
```

Se il metodo da chiamare è definito nella stessa classe del metodo che lo chiama, il nome della classe può essere omesso.

Se un metodo non usa alcuno _stato_ dell'oggetto, può essere reso _static_ usando il modificatore `static`. Anche i metodi statici si chiamano con la sintassi del punto (`.`), ma si chiamano sulla classe stessa anziché su un'istanza della classe.

Se una classe ha solo metodi statici, anche lei può essere resa statica usando il modificatore `static`. Questo esprime l'intenzione della classe.

```csharp
static class Calculator
{
    public static int Multiply(int x, int y)
    {
        return x * y;
    }
}

Calculator.Multiply(2, 4); // => 8
```

In C#, lo scope è definito tra i caratteri `{` e `}`.

C# supporta due tipi di [commenti][comments]. I commenti su una sola riga sono preceduti da `//`, mentre i commenti su più righe si inseriscono tra `/*` e `*/`.

I valori interi sono definiti come una o più cifre (consecutive) e supportano i [comuni operatori matematici][operators].

Il nome di una variabile [deve seguire alcune regole][identifier-names], come iniziare con una lettera o un underscore, e [dovrebbe seguire le convenzioni di denominazione di C#][naming-guidelines]. Se il nome di una variabile entra in conflitto con una [parola chiave riservata di C#][csharp-keywords], bisogna farlo precedere da `@`. L'uso di questa notazione non è raccomandato, ma si può incontrare in casi eccezionali, per esempio: `var @this`, `var @class` o `var @var`.

Ci sono un paio di concetti talmente fondamentali per un linguaggio della famiglia C come C# che compaiono naturalmente in quasi ogni frammento di codice non banale. Sono la [mutazione][mutation] e lo [scope][scope]. La mutazione è l'idea che il valore di una variabile possa cambiare nel corso della vita di un programma. Lo scope è l'idea che il valore associato a un nome (di un elemento del programma) sia accessibile solo all'interno dell'«area» di codice in cui è definito. Le principali aree di codice in C# sono _classe/struct_ e _funzione_ (in genere metodi), ma possono includere anche il corpo dei cicli e di altri costrutti.
