# Informazioni

## Gli optional

Swift usa gli [_optional_][optionals] per permettere ai programmatori di rappresentare la possibile assenza di un valore.
Un optional è un tipo che può contenere un valore oppure essere [`nil`][nil], che rappresenta l'assenza di un valore.
Usare un optional richiede che il programma controlli se un valore esiste davvero prima di usarlo, dopo averne fatto l'unwrapping.

Qualsiasi tipo può essere trasformato in un optional aggiungendo un `?` alla fine del nome del tipo.
Quindi un intero optional avrebbe il tipo `Int?` e una stringa optional avrebbe il tipo `String?`.
Definire costanti o variabili di tipo optional e assegnare loro dei valori funziona allo stesso modo che per i valori di tipo non optional.

```swift
let x: Int? = 42
var y: String? = "Hello"
y = "Goodbye"
```

Puoi assegnare l'assenza di un valore a una variabile di tipo optional assegnandole il valore speciale `nil`.
`nil` si può usare con tutti i tipi optional, ma i `nil` assegnati a due tipi optional diversi non hanno lo stesso tipo e non possono essere scambiati né tantomeno confrontati.

```swift
let intOpt: Int? = nil
let stringOpt: String? = nil

intOpt = stringOpt
// Compiler error: Cannot assign value of type 'String?' to type 'Int?'

intOpt == stringOpt
// Compiler error: Binary operator '==' cannot be applied to operands of type 'Int?' and 'String?'
```

Nota anche che, anche se `nil` può essere assegnato a qualsiasi tipo optional, non può essere assegnato a un tipo non optional (anche se in realtà non contiene `nil`).
E a un metodo che si aspetta un tipo non optional non si può passare un tipo optional senza prima farne l'unwrapping.

```swift
var x: Int = 42
var y: Int? = 42

y = x
// Works fine
x = y
// error: value of optional type 'Int?' must be unwrapped to a value of type 'Int'
x + y
// error: value of optional type 'Int?' must be unwrapped to a value of type 'Int'
```

## Usare gli optional

Poiché i tipi optional non sono gli stessi tipi dei loro tipi di base, i due tipi non possono essere usati allo stesso modo.
Per esempio, `Int("123") + 1` provoca un errore del compilatore: «Value of optional type 'Int?' must be unwrapped to a value of type 'Int'».
Questo perché `Int("123")` restituisce un tipo optional `Int?`, non un tipo `Int`: se la stringa non può essere convertita in un intero, il risultato sarà `nil`.
Per accedere all'`Int` risultante dalla conversione bisogna prima farne l'unwrapping.

In Swift, il modo più comune per farlo è usare i costrutti `if-let` e `guard-let` dell'[_optional binding_][optional-binding].
Questi verificano se il valore è `nil` e, se un valore esiste, seguono un percorso di codice in cui il valore ottenuto dall'unwrapping viene associato a un nome fornito; se invece viene trovato `nil`, seguono un percorso diverso.

```swift
if let safeNum = Int("123") {
	let sum = safeNum + 1
	…
} else {
  // code for the case where nil was found -- may be left out
}
```

Vale la pena notare che la variabile `safeNum` ha il tipo `Int` e non `Int?`.
Nell'esempio seguente, `num` è di tipo `Int?` e `safeNum` è di tipo `Int`.

```swift
let num = Int("123")
if let safeNum = num {
  // num is of type Int
}
```

Questo _optional binding_ è importante perché fa l'unwrapping (ovvero «rimuove») del tipo optional dal valore, permettendo di usarlo come valore non optional.
Se ti limitassi a controllare se il valore è `nil`, il valore sarebbe comunque di tipo optional:

```swift
let num = Int("123")
if num != nil {
  // num is of type Int?
}
```

L'opzione `guard-let` si può usare anche nei casi in cui si vuole un ritorno anticipato:

```swift
guard let num = Int("123") else { return nil }
let sum = num + 1
…
```

## Confrontare gli optional

Nota che, anche se il tipo di base di una coppia di optional può essere confrontato usando gli operatori di confronto standard, gli optional stessi non possono essere confrontati.
Si può solo verificare se sono uguali.
Due optional sono uguali se sono entrambi `nil` oppure se i valori che racchiudono sono uguali nei rispettivi tipi di base.

Tuttavia, si può scrivere del codice per eseguire un confronto personalizzato tra due valori optional.
Quello che segue è un esempio di istruzione `switch` che restituisce `true` solo se entrambi i valori optional non sono `nil` e il primo valore è minore del secondo.
Per farlo usa l'_optional pattern_ `varName?`, che corrisponde solo agli optional non `nil` e associa al nome `varName` il valore contenuto nell'optional.

```swift
switch (optionalA, optionalB) {
case let (valA?, valB?): return valA < valB
default: return false
}
```
