# Introduzione

Le variabili dichiarate con la parola chiave `final` invece di `var` possono ricevere un valore una sola volta.

```haxe
final a = "hello";
var b = "world";
trace(a, b); // hello, world
b = "haxe";
trace(a, b); // hello, haxe

// The following line would cause a compilation error:
// a = "bye";
```
