# Suggerimenti

## Generale

- Nella libreria standard sono disponibili diverse funzioni per le espressioni booleane. Dai un'occhiata al namespace `Boolean` su [Unison share](https://share.unison-lang.org/@unison/code/latest/namespaces/public/base/latest/;/types/Boolean).
- L'ability Each ti permette di operare su un array di elementi come se fosse un unico elemento, applicando la funzione desiderata a «each» elemento. Può anche essere usata per creare combinazioni di elementi, chiamando Each su due array diversi.
- Dai un'occhiata alla [funzione `guard` di `Each`](https://share.unison-lang.org/@unison/code/latest/namespaces/public/base/latest/;/types/abilities/Each). Può essere utile quando vuoi restituire qualcosa in modo condizionato dall'ability `Each`.
- Data la quantità di combinazioni uniche possibili per questo problema, potresti incontrare problemi di complessità spaziale o temporale. Esistono parecchi meccanismi per ottimizzare la ricerca. Dai un'occhiata agli algoritmi di [backtracking](https://www.geeksforgeeks.org/backtracking-algorithms/) o di [branch and bound](https://www.geeksforgeeks.org/branch-and-bound-algorithm/?ref=lbp).
