# Installazione

## Versione di destinazione

I test di questo track usano l'immagine Docker `alpine:3.24.1` che, a settembre 2026, utilizza `sqlite3 version 3.53.4`.
Ci impegniamo a garantire che gli strumenti forniti da questo track funzionino sull'ultima versione LTS di Ubuntu.
Anche se potresti avere installato versioni più recenti, tieni presente che alcune funzionalità potrebbero non funzionare con il nostro test runner.
Puoi confrontare le funzionalità nella [cronologia delle versioni di SQLite][version-history].

## Windows

Per installare SQLite su Windows, segui questi passaggi:

1. Scarica i binari Windows precompilati dalla [pagina di download ufficiale][sqlite-download].
2. Estrai il file ZIP scaricato in una cartella a tua scelta.
   Per esempio, `C:\Program Files\sqlite3`.
3. Aggiungi la cartella che contiene `sqlite3.exe` alla variabile d'ambiente PATH del sistema.
   La procedura è un po' diversa per ogni versione di Windows, ma le informazioni dovrebbero essere facili da trovare.
   Per esempio, le [istruzioni per Windows 11][windows-11-install] e quelle per [Windows 10][windows-10-install].

## macOS

Su macOS, SQLite è preinstallato.
Se però ti serve una versione più recente, puoi usare [Homebrew][homebrew]:

```bash
brew install sqlite
```

## Ubuntu / Debian

Su Ubuntu e sui sistemi basati su Debian, puoi installare SQLite usando apt:

```bash
sudo apt install sqlite3
```

## CentOS / Fedora / RHEL

Su CentOS, Fedora e sui sistemi basati su Red Hat, puoi installare SQLite usando yum o dnf:

```bash
sudo yum install sqlite3
# OR
sudo dnf install sqlite3
```

## Arch Linux

Su Arch Linux, puoi installare SQLite usando pacman:

```bash
sudo pacman -S sqlite
```

## Altre modalità di installazione e versioni precedenti

Consulta la [pagina di download di SQLite][sqlite-download] per maggiori informazioni e metodi di installazione alternativi.
La sezione `Build Product Names and Info` contiene il modello di denominazione per le diverse versioni di SQLite, quindi dovresti riuscire a cercare la versione che ti interessa con il tuo motore di ricerca preferito.
