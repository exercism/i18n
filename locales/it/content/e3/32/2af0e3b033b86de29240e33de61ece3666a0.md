# Cicli

Python ha due costrutti di ciclo.
I cicli `while` per l'iterazione _indefinita_ (non contata) e i cicli `for` per l'iterazione _definita_ (contata).
Le parole chiave `break`, `continue` e `else` aiutano a personalizzare il comportamento dei cicli.
`range()` e `enumerate()` aiutano con il conteggio e l'indicizzazione nei cicli.

## While

I cicli [`while`][while statement] continuano a essere eseguiti finché l'`loop expression`, o «test», viene valutata come `True` in un [`boolean context`][truth value testing], e terminano quando viene valutata come `False`:

```python
# Lists are considered "truthy" in a boolean context if they
# contain one or more values, and "falsy" if they are empty.

>>> placeholders = ["spam", "ham", "eggs", "green_spam", "green_ham", "green_eggs"]

>>> while placeholders:
...     print(placeholders.pop(0))
...
'spam'
'ham'
'eggs'
'green_spam'
'green_ham'
'green_eggs'
```

## For

Il `loop` di base [`for`][for statement] in Python si descrive meglio come un _`for each`_ che scorre i valori di qualsiasi [oggetto iterabile][iterable], e termina quando la chiamata a [`next()`][next built-in] non restituisce più valori (_sollevando una [`StopIteration`][stopiteration]_).

```python
>>> word_list = ["bird", "chicken", "barrel", "bongo"]

>>> for word in word_list:
...    if word.startswith("b"):
...        print(f"{word.title()} starts with a B.")
...    else:
...        print(f"{word.title()} doesn't start with a B.")
...
'Bird starts with a B.'
'Chicken doesn\'t start with a B.'
'Barrel starts with a B.'
'Bongo starts with a B.'
```


## L'oggetto sequenza `range()`

Quando non viene fornito uno specifico `iterable`, si usa la sequenza speciale [`range()`][range] come contatore del ciclo.
`range()` richiede un `int` prima del quale fermare (`stop`) la sequenza, e può accettare facoltativamente i parametri `start` e `step`.
Se non viene fornito alcun numero `start`, la sequenza inizierà da 0.
Gli oggetti `range()` sono **lazy** (_i valori vengono generati su richiesta_), supportano tutte le [operazioni comuni sulle sequenze][common sequence operations] e occupano una quantità di memoria fissa, per quanto lunga sia la sequenza specificata.
Curiosamente, `range()` [_non è un iteratore_][range is not an iterator], e può essere usato in molti contesti che non sono cicli, dove serve una sequenza di numeri.


```python
# Here we use range to produce some numbers, rather than creating a list of them in memory.
# The values will start with 1 and stop *before* 7.

>>> for number in range(1, 7):
...    if number % 2 == 0:
...       print(f"{number} is even.")
...    else:
...       print(f"{number} is odd.")
'1 is odd.'
'2 is even.'
'3 is odd.'
'4 is even.'
'5 is odd.'
'6 is even.'

# range() can also take a *step* parameter.
# Here we use range to produce only the "odd" numbers, starting with 3 and stopping *before* 15.

>>> for number in range(3, 15, 2):
...    if number % 2 == 0:
...       print(f"{number} is even.")
...    else:
...       print(f"{number} is odd.")
...
'3 is odd.'
'5 is odd.'
'7 is odd.'
'9 is odd.'
'11 is odd.'
'13 is odd.'
```


## Valori e indici con `enumerate()`

Se servono sia i valori sia gli indici, la funzione integrata [`enumerate(<iterable>)`][enumerate] restituisce un [`iterator`][iterator] su coppie (`index`, `value`):

```python
>>> word_list = ["bird", "chicken", "barrel", "apple"]

# *index* and *word* are the loop variables.
# Loop variables can be any valid python name.

>>> for index, word in enumerate(word_list):
...    if word.startswith("b"):
...        print(f"{word.title()} (at index {index}) starts with a B.")
...    else:
...        print(f"{word.title()} (at index {index}) doesn't start with a B.")
...
'Bird (at index 0) starts with a B.'
'Chicken (at index 1) doesn\'t start with a B.'
'Barrel (at index 2) starts with a B.'
'Apple (at index 3) doesn\'t start with a B.'


# The same method can be used as a "lookup" for pairing items between two lists.
# Of course, if the lengths or indexes don't line up, this doesn't work.

>>> word_list = ["cat", "chicken", "barrel", "apple", "spinach"]
>>> category_list = ["mammal", "bird", "thing", "fruit", "vegetable"]

>>> for index, word in enumerate(word_list):
...    print(f"{word.title()} is in category: {category_list[index]}.")
...
'Cat is in category: mammal.'
'Chicken is in category: bird.'
'Barrel is in category: thing.'
'Apple is in category: fruit.'
'Spinach is in category: vegetable.'
```

La funzione `enumerate(<iterable>)` può anche essere impostata per far iniziare il conteggio degli indici da un numero diverso:


```python
# Here, the index count will start at 1.
>>> for position, word in enumerate(word_list, start=1):
...    if word.startswith("b"):
...        print(f"{word.title()} (at position {position}) starts with a B.")
...    else:
...        print(f"{word.title()} (at position {position}) doesn't start with a B.")
...
'Bird (at position 1) starts with a B.'
'Chicken (at position 2) doesn\'t start with a B.'
'Barrel (at position 3) starts with a B.'
'Apple (at position 4) doesn\'t start with a B.'
```


## Modificare il comportamento di un ciclo

La parola chiave [`continue`][continue statement] può essere usata per saltare avanti all'iterazione successiva:

```python
>>> word_list = ["bird", "chicken", "barrel", "bongo", "sliver", "apple", "bear"]
...
... # This will skip *bird*, at index 0
... for index, word in enumerate(word_list):
...     if index == 0:
...         continue
...     if word.startswith("b"):
...         print(f"{word.title()} (at index {index}) starts with a b.")
...
'Barrel (at index 2) starts with a b.'
'Bongo (at index 3) starts with a b.'
'Bear (at index 6) starts with a b.'
```


La parola chiave [`break`][break statement] (_come in molti linguaggi della famiglia del C_) può essere usata per interrompere l'iterazione e «uscire» dal `loop` più interno che la racchiude:

```python
>>>  word_list = ["bird", "chicken", "barrel", "bongo", "sliver", "apple"]

>>> for index, word in enumerate(word_list):
...    if word.startswith("b"):
...        print(f"{word.title()} (at index {index}) starts with a B.")
...    elif word == "sliver":
...        break
...    else:
...        print(f"{word.title()} doesn't start with a B.")
... print("loop broken.")
...
'Bird (at index 0) starts with a B.'
'Chicken doesn\'t start with a B.'
'Barrel (at index 2) starts with a B.'
'Bongo (at index 3) starts with a B.'
'loop broken.'
```


La [clausola `else`][loop else] del ciclo è esclusiva di Python e può essere usata per azioni di «conclusione» o «chiusura» quando l'iterazione è stata esaurita.
Le istruzioni che seguono la parola chiave `else` non vengono eseguite se l'iterazione termina tramite `break`:


```python
>>> word_list = ["bird", "chicken", "barrel", "bongo", "sliver", "apple"]

# Using enumerate to get both an index and a value.

>>> for index, word in enumerate(word_list):
...    word = word.title()
...    if word.startswith("B"):
...        print(f"{word} (at index {index}) starts with a B.")
...
... # This executes once *StopIteration* is raised and 
... # There are no more items to iterate through.
... # Note the indentation, which lines up with the for keyword.
... else:
...    print(f"Found the above b-words, out of {len(word_list)} words in the word list.")
...
'Bird (at index 0) starts with a B.'
'Barrel (at index 2) starts with a B.'
'Bongo (at index 3) starts with a B.'
'Found the above b-words, out of 6 words in the word list.'


# Terminating a loop via *break* will bypass the loop *else* clause

>>> for index, word in enumerate(word_list):
...    word = word.title()
...    if word.startswith("B"):
...       print(f"{word} (at index {index}) starts with a B.")
...    if word.startswith("S"):
...        print("Found an S, stopping iteration.")
...        break

... # This statement does not run, because a *break* was triggered.
... else:
...    print(f"Found the above b-words, out of {len(word_list)} words in the word list.")
...
'Bird (at index 0) starts with a B.'
'Barrel (at index 2) starts with a B.'
'Bongo (at index 3) starts with a B.'
'Found an S, stopping iteration.'
```
