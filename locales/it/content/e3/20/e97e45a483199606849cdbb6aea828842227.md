# Introduzione

Le classi in Kotlin servono a incapsulare dati e comportamento.
Una classe si dichiara con la parola chiave `class`.
Per esempio:

```kotlin
class Car
```

Per creare un'istanza della classe, la si chiama.

```kotlin
val instance = Car()
```

## Proprietà

Negli esempi qui sopra, la classe `Car` è stata dichiarata senza alcuna proprietà.
Le proprietà della classe si possono dichiarare nel corpo, tra `{}`, usando `var` per le proprietà mutabili e `val` per quelle immutabili.
Per esempio:

```kotlin
class Car {
    // color is mutable
    var color = "red"

    // year is immutable
    val year = 2025
}
```

In alternativa, le proprietà si possono definire in un costruttore che le riceve.

## Costruttori

Kotlin ha due tipi di costruttori: il costruttore primario e i costruttori secondari.
Il costruttore primario si dichiara sulla stessa riga della dichiarazione della classe.
Per esempio:

```kotlin
class Car constructor(var color : String = "red", val year : Int = 2025) {
    // ...
}
```

La parola chiave `constructor` si può omettere se non ci sono annotazioni e non ci sono modificatori di visibilità:

```kotlin
class Car(var color : String = "red", val year : Int = 2025) {
    // ...
}
```

~~~~exercism/note
Kotlin permette di definire la classe con un corpo se contiene solo proprietà, senza bisogno delle parentesi graffe (`{}`):

```kotlin
class Car (var color : String = "red", val year : Int = 2025)
```
~~~~

Una classe può avere un solo costruttore primario.
I costruttori secondari sono costruttori aggiuntivi, che si possono dichiarare nel corpo della classe con la parola chiave `constructor`.
Per esempio:

```kotlin
class Car constructor(var color : String = "red", val year : Int = 2025) {

    // This constructor allows the year to be provided as a String
    constructor(color : String = "red", yearText : String) : this(color, yearText.toIntOrNull() ?: 0)
}
```

I costruttori secondari devono chiamare il costruttore primario usando `this`.

## Blocchi di inizializzazione

Il costruttore primario imposta le proprietà della classe.
Se durante la creazione dell'oggetto serve fare altro, si possono usare i blocchi `init` per eseguire azioni aggiuntive.

```kotlin
class Car constructor(var color: String = "red", val year : Int = 2025) {
    init {
        println("Car is ${color}, made in ${year}")
    }
}
```

## Funzioni

Le funzioni si possono definire nel corpo della classe.
Per esempio:

```kotlin
class Car (var color : String = "red", val year : Int = 2025) {
    fun repaint(newColor : String) {
        color = newColor
    }
}
```

## Visibilità

Le proprietà e le funzioni possono essere `private`, `public`, `internal` o `protected`.

- `private`: accessibile solo dall'interno della classe
- `protected`: accessibile dagli elementi interni alla classe e dalle sue sottoclassi
- `internal`: accessibile dagli elementi dello stesso modulo
- `public`: accessibile da altri componenti che usano la classe

Per esempio:

```kotlin
class Car {
    private val color: String
    public val year: Int
    internal val model: String
    protected val brand: String

    private fun drive() {
        // ...
    }

    internal fun start() {
        // ...
    }

    protected fun stop() {
        // ...
    }

    public fun make() {
        // ...
    }
}
```
