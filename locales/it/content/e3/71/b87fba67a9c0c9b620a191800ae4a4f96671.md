# Suggerimenti

## Generale

- Leggi come usare le librerie di Erlang nella [guida ufficiale per iniziare][getting-started-erlang-libraries], e in particolare come [formattare le stringhe][getting-started-formatted-text-output].

## 1. Genera un pianeta casuale

- Usa l'attributo del modulo fornito con una lista di lettere che rappresentano le classi planetarie.
- Esiste una [funzione integrata][enum-random] per scegliere un elemento da una lista in modo casuale.

## 2. Genera un numero di registrazione casuale per un'astronave

- Esiste una [funzione integrata][enum-random] per scegliere un elemento da un intervallo in modo casuale.

## 3. Genera una data stellare casuale

- Non esiste una funzione di Elixir che restituisca un numero in virgola mobile casuale.
- Esiste una [funzione Erlang integrata][erl-rand-uniform] che restituisce un numero in virgola mobile x dove `0.0 <= x < 1.0`.
- Se `x` appartiene a un intervallo `0.0 <= x < 1.0`, ma ti serve un numero di un intervallo diverso `a <= x < b`, puoi spostare l'intervallo di x moltiplicandolo per l'ampiezza dell'intervallo (`b - a`) e aggiungendo l'inizio dell'intervallo (`a`). Cioè: `x * (b - a) + a`.

## 4. Formatta la data stellare

- Non esiste una funzione di Elixir in grado di formattare, in un solo passaggio, un numero in virgola mobile come stringa con una data precisione.
- Esiste una [funzione Erlang integrata][erl-io-lib-format] che accetta una stringa di formato e una lista di dati e restituisce una charlist.
- Esiste una [funzione integrata][to-string] che converte una charlist in una stringa.
- La stringa di formato di quella funzione contiene sequenze di controllo.
- Una sequenza di controllo inizia con `~` e ha il pattern `~F.P.PadModC`, dove `F` indica l'ampiezza dell'output, `P` indica la precisione, `Pad` indica il carattere di riempimento, `Mod` indica il modificatore della sequenza di controllo e `C` è il tipo della sequenza di controllo.
- Per formattare un numero in virgola mobile con la precisione desiderata è sufficiente una sequenza di controllo con il pattern `~.PC`.
- Il tipo di sequenza di controllo per i numeri in virgola mobile è `f`.
- La stringa di formato esatta che ti serve è `~.1f`.
