# Introduzione

«La combinatoria» è la matematica del contare e dell'elencare i modi in cui una collezione di elementi può essere scelta o disposta. Il vocabolario [`math.combinatorics`][math.combinatorics] di Factor copre le due domande di base:

- **Combinazioni**: selezioni in cui l'ordine *non* conta.
- **Permutazioni**: disposizioni in cui l'ordine *conta*.

A ciascuna domanda corrispondono una parola di *conteggio*, che restituisce un numero, e una parola di *elencazione*, che restituisce le selezioni vere e proprie, più una variante `each-` in streaming che chiama una quotation con ciascuna di esse:

```
nCk              ( n k -- m )              ! count of k-combinations
nPk              ( n k -- m )              ! count of k-permutations
all-combinations ( seq k -- combinations )
all-permutations ( seq -- permutations )
each-combination ( seq k quot -- )
each-permutation ( seq quot -- )
```

```factor
USING: math.combinatorics prettyprint ;

5 2 nCk .                        ! => 10
{ 1 2 3 } 2 all-combinations .   ! => { { 1 2 } { 1 3 } { 2 3 } }
{ 1 2 } all-permutations .       ! => { { 1 2 } { 2 1 } }
```
