# Struct

Gli struct raccolgono un insieme fisso ed eterogeneo di dati in un'unica unità. Gli struct in Rust hanno queste proprietà:

- Ogni tipo struct ha un nome specifico.
- Ogni membro di uno struct si chiama **campo**.
- Ogni campo di uno struct ha un nome specifico.
- La visibilità è gestita a livello di campo: ogni campo può essere indipendentemente pubblico, privato o altro[^1].

# Panoramica sugli struct

Gli struct si definiscono con la parola chiave `struct`, seguita dal nome del tipo che lo struct descrive.
Il nome può poi essere seguito da parentesi graffe (per uno struct standard), da parentesi tonde (per una tuple struct) o da un punto e virgola (per una unit struct).

```rust
struct Item {}
```

Altri tipi vengono poi inseriti nel corpo dello struct come _campi_ dello struct, ognuno con il proprio tipo:

```rust
struct Item {
    name: String,
    weight: f32,
    worth: u32,
}
```

Infine, si possono definire dei metodi sugli struct all'interno di un blocco `impl`:

```rust
impl Item {
    // initializes and returns a new instance of our Item struct
    fn new() -> Self {
        todo!()
    }
}
```

# Varianti degli struct

Gli struct esistono in tre varianti: struct con campi nominati (struct standard), tuple struct e unit struct.

Gli struct sono molto simili alle **tuple**. In effetti, l'unica differenza tra struct e tuple riguarda ciò che è anonimo. La forma generale è questa:

- Gli struct hanno un nome e hanno campi nominati:

  ```rust
  struct Foo {
      bar: Bar,
      bat: Bat,
  }
  ```

  Si accede ai campi tramite il nome:

  ```rust
  let bar = foo.bar;
  ```

- Le tuple struct hanno un nome e hanno campi anonimi:

  ```rust
  Foo(Bar, Bat)
  ```

  Si accede ai campi tramite destrutturazione o tramite indice numerico:

  ```rust
  // unpacking
  let (bar, bat) = foo;
  ```

  ```rust
  // numeric index
  let bar = foo.0;
  let bat = foo.1;
  ```

- Le tuple sono anonime e hanno campi anonimi:

  ```rust
  (Bar, Bat)
  ```

  Come nelle tuple struct, si accede ai campi tramite destrutturazione o tramite indice numerico.

- Gli struct anonimi sono, come suggerisce il nome, anonimi, ma con campi nominati. Potresti conoscerli da altri linguaggi, come Go o Java. In Rust non esistono: l'approccio idiomatico è usare una tupla.

# Tipi a dimensione zero

Gli struct possono avere tutti i campi necessari, o anche solo pochi. Di conseguenza, è legale che uno struct abbia zero campi. Uno struct con zero campi si chiama **tipo a dimensione zero** e riceve una gestione speciale da parte del compilatore: i tipi a dimensione zero (spesso abbreviati in **ZST**) non occupano mai spazio nello stack o nello heap, anche quando potresti aspettarti il contrario. Per esempio, `Box<T>` non alloca memoria nello heap se `T` è uno ZST.

Quando scrivi uno ZST, puoi usare la sintassi degli struct standard o delle tuple struct:

```rust
// declaration
struct Foo {}
// instantiation
let foo = Foo {}
```

```rust
// declaration
struct Foo();
// instantiation
let foo = Foo();
```

Esiste anche una forma abbreviata per gli ZST:

```rust
// declaration
struct Foo;
// instantiation
let foo = Foo;
```

Di solito, quando si scrive uno ZST, si preferisce la forma abbreviata, perché non si possono mescolare gli stili: qualunque stile sia stato usato per dichiarare uno ZST[^2] è lo stesso stile richiesto per istanziarlo.

Dopo tutta questa discussione sulla sintassi degli ZST, parliamo del perché potresti mai volerne uno. Uno ZST non può contenere dati, ma è ottimo per implementare dei trait.

[^2]: Questo è un caso particolare di una regola generale: qualunque stile sia stato usato per dichiarare un tipo struct è lo stesso stile richiesto per istanziarlo.
