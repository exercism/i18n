# Introduzione

I `Complex numbers` non sono complicati.
Hanno solo bisogno di un nome meno allarmante.


Sono così utili, soprattutto in ingegneria e nelle scienze, che Python include [`complex`][complex] come tipo numerico standard, accanto agli interi ([`int`s][ints]) e ai numeri in virgola mobile ([`float`s][floats]).


Un valore `complex` in Python è essenzialmente una coppia di numeri in virgola mobile:

```python
>>> my_complex = 5.443+6.77j
(5.443+6.77j)
```

Queste sono chiamate le parti «reale» e «immaginaria».
Potresti aver sentito dire che «`i` (o `j`) è la radice quadrata di -1».
Per ora, tutto ciò significa che la parte immaginaria _per definizione_ soddisfa l'uguaglianza `1j * 1j == -1`.
È un'idea semplice, ma porta a conseguenze matematiche interessanti.

In Python, la parte «immaginaria» è indicata con `j` (_non `i` come vedresti nei libri di matematica_), e
la `j` deve seguire immediatamente un numero, per evitare che Python la veda come nome di variabile:


```python
>>> j
Traceback (most recent call last):
  File "<stdin>", line 1, in <module>
NameError: name 'j' is not defined

>>> 1j
1j

>>> type(1j)
<class 'complex'>
```


Ci sono due modi comuni per creare numeri complessi.

1) Il costruttore [`complex(real, imag)`][complex] accetta due parametri di tipo `float`:

    ```python
    >>> z1 = complex(1.5, 2.0)
    >>> z1
    (1.5+2j)
    ```

    Il costruttore può anche analizzare una stringa in input.
    Ha la strana limitazione di fallire se la stringa contiene spazi.

    ```python
    >>> complex('4+2j')
    (4+2j)
    
    >>> complex('4 + 2j')
    Traceback (most recent call last):
      File "<stdin>", line 1, in <module>
    ValueError: complex() arg is a malformed string
    ```


2) Il numero complesso può essere specificato come letterale `<real part> + <complex part>j`, oppure semplicemente `<complex part>j` se la parte reale è zero:


    ```python
    >>> z2 = 2.0 + 1.5j
    >>> z2
    (2+1.5j)
    ```
    Il risultato finale è identico a usare il costruttore `complex()`.


## Aritmetica

La maggior parte degli [`operators`][operators] usati con i float e gli interi funziona anche con i numeri complessi.

La divisione intera _**non**_ è possibile con i numeri complessi, quindi gli operatori `//` e `%` e la funzione `divmod()` falliranno per il tipo numero complesso.

Spiegare le regole per la moltiplicazione e la divisione dei numeri complessi esula dallo scopo di questo concetto (_e difficilmente dovrai eseguire quelle operazioni «a mano» molto spesso_).

Qualsiasi introduzione [matematica][math-complex] o di [ingegneria elettrica][engineering-complex] ai numeri complessi coprirà questi scenari, se vorrai approfondire l'argomento.

La libreria standard di Python ha un modulo [`math`][math-module] pieno di funzionalità utili per lavorare con i numeri reali, e il modulo [`cmath`][cmath] è il suo equivalente per lavorare con i numeri complessi.
