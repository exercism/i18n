# Informazioni

Ruby viene fornito con una libreria standard (spesso abbreviata in «stdlib»): una raccolta di classi per lavorare con cose come date, json e networking.
Fornisce anche alcune funzionalità utili che rendono il codice più semplice da gestire.

`OpenStruct` fa parte della libreria standard e permette di creare facilmente un oggetto a partire da un `Hash`.
Invece di dover accedere tramite le chiavi di un `Hash`, `OpenStruct` permette di usare dei metodi per leggere e impostare i valori.

Quando usi classi della libreria standard, o di qualsiasi altra libreria, devi richiedere quella classe usando il metodo `require`.

```ruby
require 'ostruct'

attributes = { name: "Jeremy Walker", age: 21, location: "Nomadic" }
person = OpenStruct.new(attributes)

person.name
#=> Jeremy Walker

person.location
#=> Nomadic

# Update the age
person.age = 35

# It sets correctly
person.age
#=> 35
```

Un vantaggio in più è che puoi sfruttare una scorciatoia quando usi la sintassi con i blocchi.
Quando un blocco chiama un solo metodo, puoi sostituire il blocco con `&:` seguito dal nome del metodo.
Per esempio, queste due righe sono equivalenti:

```ruby
people.sum { |person| person.age }
people.sum(&:age)
```
