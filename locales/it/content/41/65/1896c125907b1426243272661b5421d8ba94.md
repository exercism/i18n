# Suggerimenti

## Generale

- Leggi di [`alias` e `import`][getting-started] nella guida Getting Started.
- Leggi di [composizione dei moduli][elixir-school-module-composition] su elixirschool.com.

## 1. Correggi l'errore di compilazione `Race.__struct__/0 is undefined`

- Un alias si può creare con la forma speciale [`alias`][alias].

## 2. Correggi l'errore di compilazione `Car.__struct__/0 is undefined`

- Un alias si può creare con la forma speciale [`alias`][alias].
- La forma speciale `alias` accetta un'opzione `:as`.

## 3. Correggi l'errore di compilazione `undefined function puts/1`

- Le funzioni si possono importare con la forma speciale [`import`][import].
- La forma speciale [`import`][import] accetta un'opzione `:only`. Il suo valore deve essere una keyword list con i nomi delle funzioni come chiavi e le arità delle funzioni come valori.

## 4. Correggi l'errore di compilazione `undefined function default_color/0`

- Le funzioni si possono importare con la forma speciale [`import`][import].
- La forma speciale [`import`][import] accetta un'opzione `:except`. Il suo valore deve essere una keyword list con i nomi delle funzioni come chiavi e le arità delle funzioni come valori.
