# Installazione

Per prima cosa, assicurati di avere Erlang installato, seguendo le istruzioni della pagina di installazione di [Erlang][1] più adatte al tuo sistema.
[1]: /languages/erlang

## Homebrew per Mac OS X

Aggiorna Homebrew all'ultima versione:

```bash
$ brew update
```

Installa LFE:

```bash
$ brew install lfe
```

## Installazione dal codice sorgente

Installa i "developer tools" o gli "essential build packages" del tuo sistema, `git` e `erl` di Erlang.

Per esempio, su Ubuntu 18.04:

```bash
$ sudo apt-get install build-essential git erlang erlang-base-hipe
```

Successivamente puoi scaricare e compilare LFE nel modo seguente:

```bash
$ git clone https://github.com/lfe/lfe.git
$ cd lfe
$ make
$ make install
```

Una volta compilato LFE, puoi avviare la REPL (sessione interattiva) eseguendo il binario ``lfe``:

```bash
$ ./bin/lfe
```
