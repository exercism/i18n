# Installazione

Ti serve [NodeJS LTS](https://nodejs.org/en).

> 💡 Questa traccia probabilmente funziona con versioni stabili più vecchie, oltre che con la versione «current».
> Tuttavia, [per scelta progettuale](https://github.com/nodejs/release#release-schedule), le versioni dispari non sono mai stabili.
> Assicurati sempre di installare una versione pari di NodeJS.

Installa [Yarn 4+](https://yarnpkg.com/getting-started/install) usando `corepack` di Node.JS:

```shell
corepack enable yarn
```

## Verificare l'installazione

In genere devi aprire un nuovo terminale per poter usare i binari che hai appena installato.

```shell
$ node -v
v20.15.0

$ corepack -v
0.28.1

$ corepack yarn -v
v4.3.1
```

_Nota: è probabile che le tue versioni siano diverse da queste._

## Installazione degli esercizi

**Ogni esercizio** ha bisogno di alcuni strumenti per eseguire i test:

Si possono installare eseguendo questo comando all'interno della directory di ogni esercizio:

```bash
$ corepack yarn install
```

A seconda dell'editor, l'[Editor SDK](https://yarnpkg.com/getting-started/editor-sdks) deve essere installato in ogni esercizio per funzionare con le installazioni Plug'n'Play.
Al momento in cui scriviamo sono supportati i seguenti:

- [CoC nvim](https://yarnpkg.com/getting-started/editor-sdks#coc-nvim)
- [Emacs](https://yarnpkg.com/getting-started/editor-sdks#emacs)
- [Neovim Native LSP](https://yarnpkg.com/getting-started/editor-sdks#neovim-native-lsp)
- [VSCode](https://yarnpkg.com/getting-started/editor-sdks#vscode)
