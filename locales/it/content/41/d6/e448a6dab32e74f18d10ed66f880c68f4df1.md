# Informazioni

La libreria standard di Elixir offre 4 moduli diversi per lavorare con date e orari, ognuno con la propria struct.

- Il [modulo `Date`][date]. Una struct `Date` può essere creata con il [sigil `~D`][sigil-d].
    ```elixir
    ~D[2021-01-01]
    ```

- Il [modulo `Time`][time]. Una struct `Time` può essere creata con il [sigil `~T`][sigil-t].
    ```elixir
    ~T[12:00:00]
    ```

- Il [modulo `NaiveDateTime`][naivedatetime] per datetime senza fuso orario. Una struct `NaiveDateTime` può essere creata con il [sigil `~N`][sigil-n].
    ```elixir
    ~N[2021-01-01 12:00:00]
    ```

- Il [modulo `DateTime`][datetime] per datetime con un fuso orario. Usare questo modulo per fusi orari diversi da UTC richiede una dipendenza esterna, un database dei fusi orari. Una struct `DateTime` può essere rappresentata con il [sigil `~U`][sigil-u], ma è meglio crearla usando le funzioni di `DateTime`.
    ```elixir
    DateTime.new!(~D[2021-01-01], ~T[12:00:00], "Etc/UTC")
    # => ~U[2021-01-01 12:00:00Z]
    ```

## Confronti

Per confrontare date o orari tra loro, cerca una funzione `compare` o `diff` nel modulo corrispondente. Gli operatori di confronto come `==`, `>` e `<` _sembrano_ funzionare, ma non eseguono un confronto semantico corretto per quelle struct.

```elixir
Date.compare(~D[2020-11-30], ~D[2020-12-01])
# => :lt

Time.diff(~T[13:45:00], ~T[13:46:30])
# => -90
```

## Spostamenti

Date, orari e datetime possono essere spostati avanti e indietro nel tempo usando la funzione `add/2` del modulo corrispondente.

```elixir
# add 4 days
Date.add(~D[2021-01-01], 4)
# => ~D[2021-01-05]

# subtract 1 second
Time.add(~T[12:00:00], -1)
# => ~T[11:59:59.000000]

# add 4 days and 30 seconds
NaiveDateTime.add(~N[2021-01-01 12:00:00], 4 * 24 * 60 * 60 + 30)
# => ~N[2021-01-05 12:00:30]
```

## Conversioni

Una struct `NaiveDateTime` può essere scomposta in una struct `Date` e una struct `Time` usando [`NaiveDateTime.to_date/1`][naivedatetime-to-date] e [`NaiveDateTime.to_time/1`][naivedatetime-to-time]. L'operazione inversa si può ottenere con [`NaiveDateTime.new!/2`][naivedatetime-new].

```elixir
NaiveDateTime.to_date(~N[2021-01-01 12:00:00])
# => ~D[2021-01-01]

NaiveDateTime.to_time(~N[2021-01-01 12:00:00])
# => ~T[12:00:00]

NaiveDateTime.new!(~D[2021-01-01], ~T[12:00:00])
# => ~N[2021-01-01 12:00:00]
```
