# Aiuto

Se hai problemi, puoi rivolgerti a una di queste risorse per ottenere aiuto:

- [Sito web di CoffeeScript](http://coffeescript.org)
- [/r/coffeescript](https://www.reddit.com/r/coffeescript) è il subreddit di CoffeeScript.
- [StackOverflow](http://stackoverflow.com/questions/tagged/coffeescript) può essere usato per cercare il tuo problema e vedere se è già stato risolto. Puoi anche fare domande e rispondere a quelle degli altri.
