# Appendice alle istruzioni
## Istruzioni specifiche per Arturo

A differenza della maggior parte degli esercizi di Arturo, la suite di test non importerà direttamente `src/grep.art`.
La soluzione verrà invece eseguita come script Arturo autonomo, ricevendo una serie di argomenti dalla riga di comando.
Puoi usare `arg`[arg] o `args`[args] per accedere a questi argomenti della riga di comando, che contengono zero o più flag, un pattern di ricerca e uno o più nomi di file.
Questi file vengono creati e popolati dalla suite di test in fase di esecuzione.
La soluzione dovrà leggere il file richiesto e scrivere l'output previsto sullo standard output.

[arg]: https://arturo-lang.io/documentation/library/system/arg
[args]: https://arturo-lang.io/documentation/library/system/args
