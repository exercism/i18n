# Introduzione

L'_operatore ternario_ è un'alternativa leggera e compatta alle semplici istruzioni _if/else_. Di solito si usa nelle istruzioni return (ma non solo): basta una sola riga per prendere la decisione, restituendo il valore a sinistra se l'espressione è `true` e quello a destra se è `false`, così:

```java
boolean expr = 0 != 200;

// Ternary statement
int value = expr ? 22 : 33;
// => 22
```

Molte espressioni _if/else_ semplici si possono semplificare usando gli _operatori ternari_.
