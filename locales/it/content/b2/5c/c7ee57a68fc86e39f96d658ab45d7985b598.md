# Test

Gli esercizi usano tutti il framework [Pester][pester] per il mocking e i test.
Tutti i test saranno in un file chiamato `[Exercise].tests.ps1`, come da standard del framework Pester.
Se ti trovi nella directory giusta (quella che contiene `[Exercise].ps1` e `[Exercise].tests.ps1`).
Puoi eseguire i test da PowerShell chiamando:

``` PowerShell
Invoke-Pester
```

In questo modo verranno eseguiti tutti i file `.tests.ps1` che trova nella directory.

Se usi una shell diversa da PowerShell, puoi eseguire i test chiamando:

``` PowerShell
pwsh -Command "Invoke-Pester"
```

## Eseguire i test in Visual Studio Code

Devi assicurarti di avere installato [l'estensione PowerShell][extension] in Visual Studio Code.

Puoi eseguire i test in Visual Studio Code in un paio di modi:

- Eseguendo lo script `.Tests.ps1` dal menu Debug. Le scorciatoie da tastiera sono: `F5` o `Shift + F5`
- Dall'interno dell'editor, facendo clic sul link "Run Tests" sopra la parola chiave `Describe` nel codice dei test stesso
- Configurando un Task per eseguire il framework Pester

[pester]: https://github.com/pester/Pester
[extension]: https://marketplace.visualstudio.com/items?itemName=ms-vscode.PowerShell
