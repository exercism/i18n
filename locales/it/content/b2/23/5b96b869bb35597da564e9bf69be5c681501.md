# Appendice alle istruzioni

## Istruzioni specifiche del track

Questo esercizio si concentra sull'aggiunta di metodi alla struttura `Array` di Swift.
Il modo più semplice è usare le [estensioni][extensions].

```swift
extension Array {
  // Write your code for the 'Strain' exercise in this file.
}
```

La documentazione di `Array` si trova [qui][array].

[array]: https://developer.apple.com/documentation/swift/array
[extensions]: https://docs.swift.org/swift-book/documentation/the-swift-programming-language/extensions/
