# Appendice alle istruzioni

Ogni riga della griglia è rappresentata da una parola.

Per esempio:

```
    0 1 0
    1 0 0
    1 1 0
```

è rappresentata come

```
0x2
0x4
0x6
```

La griglia ha al massimo 32 colonne.

## Registri

| Registro | Utilizzo     | Tipo    | Descrizione                        |
| -------- | ------------ | ------- | ---------------------------------- |
| `$a0`    | input        | intero  | numero di righe                    |
| `$a1`    | input        | intero  | numero di colonne                  |
| `$a2`    | input        | indirizzo | griglia per la generazione attuale |
| `$a3`    | input/output | indirizzo | griglia per la generazione successiva |
| `$t0-9`  | temporaneo   | qualsiasi | usato per l'archiviazione temporanea |
