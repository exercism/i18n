# Istruzioni

In questo esercizio analizzerai numeri di telefono.

Ti viene chiesto di implementare 2 funzionalità.

I numeri di telefono passati alle routine sono garantiti nel formato NNN-NNN-NNNN, ad esempio 212-515-9876, e non nulli.

## 1. Analizza un numero di telefono

La tua analisi dovrebbe restituire 3 informazioni:

1. Un'indicazione se il numero ha un prefisso di New York, cioè 212 come prime 3 cifre
2. Un'indicazione se il numero è fasullo, avendo 555 come prefisso nelle posizioni da 5 a 7 (numerando da 1)
3. Le ultime 4 cifre del numero.

Implementa il metodo (statico) `PhoneNumber.Analyze()` per produrre le informazioni sul numero di telefono.

```csharp
PhoneNumber.Analyze("631-555-1234");
// => (false, true, "1234")
```

## 2. Rileva se un numero di telefono ha un prefisso fasullo (555)

Implementa il metodo (statico) `PhoneNumber.IsFake()` per rilevare se il numero di telefono è fasullo utilizzando le informazioni sul numero di telefono prodotte nell'attività 1.

```csharp
PhoneNumber.IsFake(PhoneNumbers.Analyze("631-555-1234"));
// => true
```
