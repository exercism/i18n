# Appendice alle istruzioni

## Formato dell'output

Produci in output le piante dello studente come stringa terminata da null, usando una virgola e uno spazio come separatori.

## Registri

| Registro | Utilizzo     | Tipo      | Descrizione                            |
| -------- | ------------ | --------- | -------------------------------------- |
| `$a0`    | input        | indirizzo | diagramma del giardino                 |
| `$a1`    | input        | indirizzo | nome dello studente                    |
| `$a2`    | input/output | indirizzo | stringa di output terminata da null    |
| `$t0-9`  | temporaneo   | qualsiasi | usato per la memorizzazione temporanea |
