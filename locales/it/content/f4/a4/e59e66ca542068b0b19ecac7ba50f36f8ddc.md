# Destrutturazione

La destrutturazione è il processo che scompone gli elementi nelle loro parti componenti, associando ogni parte a una variabile più piccola.

## Destrutturazione delle tuple

Destrutturare le tuple è semplice: basta assegnare un nuovo nome di variabile a ciascun campo della tupla:

```rust
let (first, second) = (1, 2);
```

## Destrutturazione delle tuple struct

Destrutturare le tuple struct è identico alla destrutturazione delle tuple, ma con l'aggiunta del nome della struct:

```rust
struct TupleStruct(&'static str, i32);
let my_tuple_struct = TupleStruct("foo", 123);
let TupleStruct(foo, num) = my_tuple_struct;
```

## Destrutturazione delle struct

Destrutturare le struct è simile alla destrutturazione delle tuple struct. Basta usare i nomi dei campi:

```rust
struct ArabianNights {
    name: String,
    stories: usize,
}
let teller = ArabianNights { name: "Scheherazade".into(), stories: 1001 };
{
    let ArabianNights { name, stories } = teller;
    println!("{name} told {stories} stories");
}
```

## Destrutturazione parziale

L'operatore `..` può essere usato per ignorare alcuni campi durante la destrutturazione:

```rust
let ArabianNights { name, .. } = teller;
println!("{name} survived by her wits");
```

## Destrutturazione condizionale

La destrutturazione di struct e tuple è infallibile. Tuttavia, anche gli enum possono essere destrutturati, usando i costrutti del linguaggio `if let`, `while let` e `match`.

```rust
if let Some(foo) = foo {
    println!("{foo:?}");
}
```
