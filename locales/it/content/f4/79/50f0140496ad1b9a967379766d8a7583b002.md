# Istruzioni

In questo esercizio creerai un programma utile per non dover ricordare i valori delle fasce.
Il programma prenderà in input 1, 4 o 5 colori e restituirà il valore corretto in ohm.
Le fasce colorate sono codificate come segue:

| Colore | Valore |
| ------ | ------ |
| Black  | 0      |
| Brown  | 1      |
| Red    | 2      |
| Orange | 3      |
| Yellow | 4      |
| Green  | 5      |
| Blue   | 6      |
| Violet | 7      |
| Gray   | 8      |
| White  | 9      |

In [`Resistor Color Trio`][resistor-color-trio-exercise] hai decodificato le prime tre fasce colorate.
Ad esempio: orange-orange-brown corrisponde al valore principale `330`.
In questo esercizio dovrai aggiungere anche la _tolleranza_.
La tolleranza è lo scostamento massimo, in eccesso o in difetto, rispetto al valore principale.
Ad esempio, se l'ultima fascia è green, la tolleranza massima sarà `±0.5%`.

La fascia della tolleranza avrà uno di questi valori:

| Colore | Tolleranza |
| ------ | --------: |
| Grey   |    ±0.05% |
| Violet |    ±0.10% |
| Blue   |    ±0.25% |
| Green  |    ±0.50% |
| Brown  |    ±1.00% |
| Red    |    ±2.00% |
| Gold   |    ±5.00% |
| Silver |   ±10.00% |

Il resistore a quattro fasce è composto così:

| Fascia 1 | Fascia 2 | Fascia 3   | Fascia 4  |
| -------- | -------- | ---------- | --------- |
| Valore 1 | Valore 2 | Moltiplicatore | Tolleranza |

Esempi:

- orange-orange-brown-green corrisponderebbe a `330` ohm con una tolleranza di `±0.5%`.
- orange-orange-red-grey corrisponderebbe a `3300` ohm con una tolleranza di `±0.05%`.

La differenza tra un resistore a quattro fasce e uno a cinque fasce è che quello a cinque fasce ha una fascia in più per indicare un valore più preciso.

| Fascia 1 | Fascia 2 | Fascia 3 | Fascia 4   | Fascia 5  |
| -------- | -------- | -------- | ---------- | --------- |
| Valore 1 | Valore 2 | Valore 3 | Moltiplicatore | Tolleranza |

Esempi:

- orange-orange-orange-black-green corrisponderebbe a `333` ohm con una tolleranza di `±0.5%`.
- orange-red-orange-blue-violet corrisponderebbe a `323 million` ohm con una tolleranza di `±0.1%`.

Esistono anche resistori a una sola fascia.
I resistori a una sola fascia hanno solo il colore black con valore 0.

Il tuo programma deve tradurre una `list` di colori delle fasce, fornita in input, in un'etichetta:

"... ohms ±...%"

Quindi una `list` di input `["orange", "orange", "black", "green"]` deve restituire:

"33 ohms ±0.5%"

Quando ci sono migliaia di ohm, diciamo «kiloohms».
È simile a dire «chilometro» per 1000 metri e «chilogrammo» per 1000 grammi.

Quindi una `list` di input `["orange", "orange", "orange", "grey"]` deve restituire:

"33 kiloohms ±0.05%"

Quando ci sono milioni di ohm, diciamo «megaohms».

Quindi una `list` di input `["orange", "orange", "blue", "red"]` deve restituire:

"33 megaohms ±2%"
