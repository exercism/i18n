# Introduzione

Una *tupla* è il tipo record/struct/classe di Factor. Ogni classe di tupla
ha un insieme fisso di slot con nome, e Factor ne genera automaticamente i
getter e i setter.

```factor
TUPLE: point
    { x initial: 0 }
    { y initial: 0 } ;

T{ point { x 3 } { y 4 } } x>> .   ! => 3
3 4 point boa .                    ! => T{ point { x 3 } { y 4 } }
point new .                        ! => T{ point }
```

`boa` («by order of arguments») riempie gli slot prendendoli dallo stack,
nell'ordine di dichiarazione. `new` costruisce un'istanza con ogni slot al
valore `initial:` dichiarato (o `f` se non ne ha uno).

Il getter di ogni slot è `slot>>` e il setter è `>>slot`: il setter
*modifica* lo slot, quindi fai prima un `clone` se ti serve un aggiornamento
non distruttivo:

```factor
T{ point { x 3 } { y 4 } } clone 10 >>x .
! => T{ point { x 10 } { y 4 } }
```

I valori predefiniti degli slot si indicano con `{ name initial: value }`;
senza `initial:` il valore predefinito è `f`.
