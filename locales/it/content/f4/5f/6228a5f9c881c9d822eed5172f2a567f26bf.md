# Introduzione

Gli array associativi di Factor, gli hashtable ed affini, condividono un [protocollo][assoc-protocol] comune che arriva da [`assocs`]. Il letterale hashtable è `H{ }`:

```factor
H{ { "coal" 1 } { "wood" 2 } } .

"coal" H{ { "coal" 1 } { "wood" 2 } } at .   ! => 1
"gold" H{ { "coal" 1 } { "wood" 2 } } at .   ! => f
```

Operazioni comuni:

```
at        ( key assoc -- value/f )
key?      ( key assoc -- ? )
set-at    ( value key assoc -- )
delete-at ( key assoc -- )
inc-at    ( key assoc -- )
change-at ( key assoc quot -- )
keys      ( assoc -- keys )
values    ( assoc -- values )
>alist    ( assoc -- alist )
```

Gli hashtable sono *mutabili*: fai il `clone` di un letterale `H{ }` prima di modificarlo, così il letterale non viene condiviso tra le chiamate.

[assoc-protocol]: https://docs.factorcode.org/content/article-assocs-protocol.html
