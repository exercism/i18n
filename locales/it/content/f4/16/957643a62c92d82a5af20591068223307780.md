# Imparare Visual Basic

## Siti web

Visual Basic si è evoluto notevolmente nel corso degli anni e molti tutorial di terze parti fanno riferimento a strumenti obsoleti o a funzionalità obsolete.
La [documentazione ufficiale di Visual Basic](https://learn.microsoft.com/en-us/dotnet/visual-basic/) è il luogo più aggiornato e affidabile da cui iniziare il tuo percorso.

## L'ecosistema .NET

Visual Basic viene eseguito sul runtime .NET e condivide molte funzionalità di base con C# e F#.
Pertanto, capire come funziona .NET ti renderà uno sviluppatore VB più preparato.

- [Che cos'è .NET?](https://learn.microsoft.com/en-us/dotnet/core/introduction)
- [Il glossario .NET](https://learn.microsoft.com/en-us/dotnet/standard/glossary)
- [Il Common Type System (CTS)](https://learn.microsoft.com/en-us/dotnet/standard/base-types/common-type-system)
