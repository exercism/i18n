# Appendice alle istruzioni

## Formato dell'output

Produci una stringa con terminatore null, usando una virgola e uno spazio come separatori.

Un esempio di output sarebbe `"491, 914, 142"`

Se l'input non è valido, produci una stringa vuota.

## Registri

| Registro | Utilizzo     | Tipo    | Descrizione                          |
| -------- | ------------ | ------- | ------------------------------------ |
| `$a0`    | input        | indirizzo | stringa della serie con terminatore null |
| `$a1`    | input        | intero  | lunghezza della slice                |
| `$a2`    | input/output | indirizzo | stringa di output con terminatore null |
| `$t0-9`  | temporaneo   | qualsiasi | usato come memoria temporanea        |
