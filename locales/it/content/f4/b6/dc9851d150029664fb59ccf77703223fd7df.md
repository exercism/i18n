# formato kernel

Oltre al metodo `format`, un modo comune per creare stringhe in Ruby è usare l'[interpolazione di stringhe](http://ruby-for-beginners.rubymonstas.org/bonus/string_interpolation.html). Ad esempio:

```ruby
# Rather than:
format("One for %%s, one for me.", %{name_variable})

# Consider:
"One for #{%{name_variable}}, one for me."
```
