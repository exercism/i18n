# Istruzioni

Nessuno sale sul trapezio al circo finché i controlli di sicurezza non sono superati.
Stai mettendo per iscritto i controlli, così le stesse regole valgono per tutti.

Tutti e cinque i compiti vanno nella classe `SAFETY_CHECK`.

## 1. Il materassino è pronto?

Il materassino è pronto solo quando è sia steso che pulito.

```sather
SAFETY_CHECK::mat_ready(true, false)
-- => false
```

## 2. C'è qualcosa su cui atterrare?

Ci deve essere un materassino sotto, oppure una rete sotto. Va bene uno dei due,
e va bene anche averli entrambi.

```sather
SAFETY_CHECK::something_below(false, true)
-- => true
```

## 3. Chi ha ancora bisogno del briefing?

Chiunque non abbia ricevuto il briefing ne ha bisogno.

```sather
SAFETY_CHECK::needs_briefing(false)
-- => true
```

## 4. Questo artista ha l'età giusta?

Il trapezio è per gli artisti dai 13 anni in su.

```sather
SAFETY_CHECK::old_enough(13)
-- => true
```

## 5. Mettiamo tutto insieme

Un artista è idoneo al trapezio quando ha l'età giusta, ha ricevuto il briefing
e il materassino è pronto.

```sather
SAFETY_CHECK::cleared(14, true, true, true)
-- => true
```

I quattro argomenti sono l'età, se ha ricevuto il briefing, se il materassino è
steso e se il materassino è pulito.
