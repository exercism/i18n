# Istruzioni

Come maga in erba, Elyse deve analizzare il suo mazzo in tanti modi diversi.
Per semplificare, usa solo carte con valori da 1 a 10.

## 1. Determina quante carte di un certo tipo ci sono nel mazzo

Elyse vuole sapere quante carte di un tipo particolare ha nel suo mazzo.

Scrivi una funzione `cardTypeCheck` che prende due parametri: un array di carte (il mazzo di Elyse) e il tipo di carta da contare.

<!--prettier-ignore -->
~~~exercism/note
La funzione dovrebbe usare `forEach` e restituire il numero di carte del tipo indicato presenti nel mazzo.
~~~

```javascript
const cardType = 3;
cardTypeCheck([1, 2, 3, 4], cardType);
// => 1
```

## 2. Determina quante carte pari o dispari ci sono

Per un altro trucco, Elyse deve sapere quante carte pari o dispari ci sono nel suo mazzo.

Implementa una funzione `determineOddEvenCards` che prende due parametri: un array di carte (il mazzo di Elyse) e un booleano (true equivale a «pari» e false equivale a «dispari»).

Questa funzione dovrebbe restituire un unico numero: il numero di carte pari o dispari presenti nel mazzo (a seconda del valore del secondo argomento).

<!--prettier-ignore -->
~~~exercism/note
Per fare pratica, stavolta usa un ciclo `for...of` nell'implementazione della funzione.
~~~

```javascript
determineOddEvenCards([1, 2, 3, 1, 5, 6], true);
// => 2

determineOddEvenCards([1, 2, 3, 1, 5, 6], false);
// => 4
```
