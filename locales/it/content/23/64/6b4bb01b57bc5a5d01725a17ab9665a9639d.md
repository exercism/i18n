# Informazioni

Un [`Attribute`][attribute-concept] di C# offre un modo per decorare una dichiarazione e associarvi dei metadati: una classe, un metodo, un enum, un campo, una proprietà o qualsiasi altra [dichiarazione supportata][attribute-targets].

Puoi applicare [un attributo][attribute] a una dichiarazione aggiungendolo tra parentesi quadre (`[]`) prima della dichiarazione; l'esempio seguente usa sia un `ClassAttribute` sia un `FieldAttribute`:

```csharp
[Class]
public class MyClass
{
    [Field] public int myField;
}
```

I metadati dichiarativi si limitano ad associare al codice informazioni strutturate aggiuntive e non ne modificano il comportamento. Tuttavia, altre parti del codice usano questi metadati per cambiare il comportamento della loro destinazione, oppure per aggiungere, modificare, rimuovere o limitare alcune delle sue funzionalità.

Esistono diversi attributi predefiniti, tra cui: `Flags`, `Obsolete`, `Conditional`. Nota che il nome completo dell'[attributo `Flags`][flags-attribute] è `FlagsAttribute`, ma il suffisso «Attribute» può essere omesso quando lo si usa nell'attributo.

I quattro attributi predefiniti seguenti sono usati regolarmente:

- `[Flags]`: predefinito nello spazio dei nomi System. Indica che l'enum supporta sia le operazioni bit a bit sia il metodo `Enum.HasFlag()`; inoltre `ToString` visualizza tutti i flag: [vedi l'esempio][flags-example].
- `[Obsolete]`: predefinito nello spazio dei nomi System. Consente di aggiungere un messaggio sul perché il codice è obsoleto; può essere usato per visualizzare avvisi o errori del compilatore.
- `[Conditional]`: predefinito nello spazio dei nomi System.Diagnostics. Consente di rimuovere alcune chiamate di metodo in fase di compilazione per scopi di debug (diagnostica).
- `[CallerMemberName]`: predefinito nello spazio dei nomi System.Runtime.CompilerServices. Consente a un metodo di ottenere informazioni sul proprio chiamante.
