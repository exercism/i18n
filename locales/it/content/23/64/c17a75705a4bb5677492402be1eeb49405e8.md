# Informazioni

`jq` è uno strumento per analizzare e trasformare dati JSON.
`jq` è come `sed` per i dati JSON: puoi usarlo per affettare, filtrare, mappare e trasformare dati strutturati con la stessa facilità con cui `sed`, `awk`, `grep` e simili ti lasciano giocare con il testo.

`jq` è un linguaggio di programmazione funzionale a tipizzazione dinamica.
Tutti i valori sono immutabili.

I programmi `jq` sono composti da pipeline di «filtri»: ogni filtro prende in input un singolo elemento, lo elabora e produce in output zero o più elementi trasformati.
Un «filtro» può anche essere chiamato «espressione».

Gli output di un'espressione possono essere passati a un'altra tramite l'operatore `|`.
`expressionA | expressionB` applica `expressionA` a un input, poi `expressionB` viene eseguita ripetutamente per ciascuno degli output di `expressionA`.

L'input di un'espressione può essere indicato esplicitamente con `.`.
Un'espressione che aggiunge `1` al suo input si scrive così: `. + 1` (oppure `1 + .`).

## `jq` (il programma) contro `jq` (il linguaggio)

`jq` è un programma che puoi installare come pacchetto su diversi sistemi operativi, oppure compilare dai sorgenti (è scritto in C).
Ha diverse utili [opzioni da riga di comando][cli-options] ed è piuttosto veloce.

Il programma `jq` implementa anche un _linguaggio_ che permette manipolazioni arbitrariamente complesse dei dati di input.

Questo track di Exercism si concentrerà sul linguaggio.
Vedrai l'uso del programma `jq` nei test.

## JSON

Da [json.org][json]:

> JSON (JavaScript Object Notation) è un formato leggero per lo scambio di dati.
> È facile da leggere e scrivere per gli esseri umani.
> È facile da analizzare e generare per le macchine.
> Si basa su un sottoinsieme dello standard del linguaggio di programmazione JavaScript ECMA-262, 3ª edizione, dicembre 1999.
> JSON è un formato testuale completamente indipendente dal linguaggio, ma usa convenzioni familiari ai programmatori della famiglia di linguaggi C, tra cui C, C++, C#, Java, JavaScript, Perl, Python e molti altri.
> Queste proprietà rendono JSON un ideale linguaggio per lo scambio di dati.

Questo track riguarda `jq`, non JSON.
Daremo per scontato che tu abbia familiarità con la [sintassi e i tipi di dati JSON][wiki-json].
