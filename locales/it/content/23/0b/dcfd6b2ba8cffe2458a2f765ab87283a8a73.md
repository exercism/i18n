# A proposito delle liste

Le **liste** sono la collezione che rappresenta sequenze ordinate in Java.
A differenza degli array, una [`List`](https://docs.oracle.com/en/java/javase/11/docs/api/java.base/java/util/List.html) può crescere di dimensione per contenere qualsiasi numero di elementi.
Una delle implementazioni standard è `ArrayList`, che si basa su un array di dimensione variabile.
Un'altra implementazione standard è la classe `LinkedList`, che si basa su una lista doppiamente collegata.

Le `List` possono essere vuote o contenere qualsiasi numero di elementi (anche duplicati).
Le `List` sono un'**interfaccia generica**: il tipo indica quali oggetti possono contenere.
Per esempio:

```java
List<String> emptyListOfStrings = List.of();
List<Integer> singleInteger = List.of(1);
List<Boolean> threeBooleans = List.of(true, false, true);
List<Object> listWithMultipleTypes = List.of("hello", 1, true);
```

Le `List` hanno vari metodi utili per aggiungere, rimuovere, ottenere un elemento e verificare che sia presente:

```java
List<Character> vowels = new ArrayList<>(List.of('a', 'e', 'i', 'o', 'i', 'e', 'a'));
int startingSize = vowels.size(); // 7
vowels.add('u'); // vowels is now ['a', 'e', 'i', 'o', 'i', 'e', 'a', 'u']
char a = vowels.get(0); // 'a'
boolean hadI = vowels.remove('i'); // true and vowels is now ['a', 'e', 'o', 'i', 'e', 'a', 'u']
boolean hasI = vowels.contains('i'); // true (still have one more left)
```

Anche la classe [`Collections`](https://docs.oracle.com/en/java/javase/11/docs/api/java.base/java/util/Collections.html) offre alcune utilità per lavorare con collezioni come `List`:

```java
List<Integer> numbers = new ArrayList<>(List.of(1, 5, 3, 2, 4));
Collections.sort(numbers); // [1, 2, 3, 4, 5]
Collections.reverse(numbers); // [5, 4, 3, 2, 1]
Collections.fill(numbers, 42); // [42, 42, 42, 42, 42]
List<Integer> fiveNines = Collections.nCopies(5, 9); // [9, 9, 9, 9, 9]
```
