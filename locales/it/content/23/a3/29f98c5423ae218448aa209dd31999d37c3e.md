# Verifica dei pagamenti nel database

## Descrizione del problema

ABC Corp ha bisogno che tu carichi tutti i dati dal database SQL in una [tabella Ballerina](https://ballerina.io/learn/by-example/table-syntax/) per un'ulteriore elaborazione. Poi devi trovare i nomi dei dipendenti che hanno pagamenti superiori a un importo dato (ad esempio, 3000.00) interrogando la tabella Ballerina caricata.

**Passo 1:**

Crea una tabella Ballerina con le seguenti colonne.

`payment_id` - intero

`amount` - numero in virgola mobile

`employee_name` - stringa

**Passo 2:**

Popola la tabella Ballerina di cui sopra caricando in essa il corrispondente set di dati completo presente nel database H2. Usa `payment_id` come chiave primaria della tabella.

**Passo 3**

Interroga la tabella Ballerina con le espressioni di query di Ballerina per trovare i nomi dei dipendenti che hanno pagamenti superiori all'importo dato. Ordina il risultato per nome del dipendente in ordine crescente. Rimuovi i nomi duplicati dal risultato prima di restituirlo.

> NOTA: è obbligatorio usare una tabella Ballerina per implementare la soluzione.

## Dettagli del database

Usa il database H2 fornito per questo problema.

> Il file del database di esempio è `gofigure.mv.db` e il nome del database è `gofigure`. Si trova nella cartella `db`.

Le seguenti tabelle sono già presenti nel database H2 di esempio con alcuni dati di esempio. I nomi delle colonne e i tipi di dati sono riportati di seguito.

**Nome della tabella**: `Employee`

| **Colonne:**      | tipo |
| -----------       | ----------- |
| `employee_id`     | intero, chiave primaria con incremento automatico       |
| `name`            | stringa        |
| `city`            | stringa        |
| `department`      | stringa        |
| `age`             | intero        |

**Nome della tabella**: `Payment`

| **Colonne:**      | tipo |
| -----------       | ----------- |
| `payment_id`      | intero, chiave primaria con incremento automatico       |
| `date`            | data        |
| `amount`          | numero in virgola mobile        |
| `employee_id`     | intero        |
| `reason`          | stringa        |

* Il file del database è `gofigure.mv.db`. Usa l'URL JDBC `jdbc:h2:file:/path/to/db/file`
* Nome utente: `root`
* Password: `root`

## Vincoli
