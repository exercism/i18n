# Introduzione

## Valori booleani

Gleam rappresenta i valori vero e falso con il tipo `Bool`. Esistono solo due valori: `True` e `False`. Questi valori possono essere associati a una variabile:

```gleam
let true_variable = True
let false_variable = False
```

Gli operatori `&&`, `||` e `!` possono essere usati per manipolare i valori booleani:

```gleam
True && True  // -> True
True && False // -> False

False || True  // -> True
False || False // -> False

!False // -> True
!True  // -> False
```

Gli operatori `&&` e `||` usano la valutazione a corto circuito: l'espressione a destra dell'operatore viene valutata solo se serve.

Ogni operatore ha una precedenza diversa: `!` viene valutato prima di `&&` e `||`. Le parentesi graffe possono essere usate per valutare una parte dell'espressione prima delle altre:

```gleam
!True && False   // -> False
!{True && False} // -> True
```
