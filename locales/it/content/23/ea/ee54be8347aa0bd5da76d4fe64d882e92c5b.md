# Introduzione

[Gli array][arrays-concept] hanno metodi integrati per analizzare il contenuto dell'array.
La maggior parte di questi metodi accetta come argomento una funzione che restituisce true o false.
Una funzione di questo tipo è chiamata [`predicate`][predicate_in_programming].

I metodi integrati sono pensati per essere usati _al posto di un ciclo `for`_ o del metodo integrato `forEach`:

Esempio di analisi usando un ciclo for:

```javascript
const numbers = [1, 'two', 3, 'four'];
for (var i = 0; i < numbers.length; i++) {
  if (numbers[i] === 'two') {
    return i;
  }
}
// => 1
```

Esempio di analisi usando un metodo integrato:

```javascript
const numbers = [1, 'two', 3, 'four'];
numbers.indexOf('two');
// => 1
```

Di seguito sono mostrati altri metodi integrati utili disponibili per analizzare un array. Consulta [MDN][mdn-array-methods] per un elenco completo dei metodi degli array.

## `includes`

> Il metodo includes() determina se un array include un certo valore tra le sue voci, restituendo true o false a seconda dei casi. [^1]

```javascript
const numbers = [1, 'two', 3, 'four'];
numbers.includes(1);
// => true
numbers.includes('one');
// => false
```

## `every`

> Il metodo every() verifica se tutti gli elementi dell'array superano il test implementato dalla funzione fornita. Restituisce un valore booleano. [^2]

```javascript
const numbers = [1, 3, 5, 7, 9];
numbers.every((num) => num % 2 !== 0);
// => true
```

## `some`

> Il metodo some() verifica se almeno un elemento dell'array supera il test implementato dalla funzione fornita. [^3]

```javascript
const numbers = [1, 3, 5, 7, 9];
numbers.some((num) => num % 2 !== 0);
// => true
```

## `find`

> Il metodo find() restituisce il valore del primo elemento nell'array fornito che soddisfa la funzione di test fornita. Se nessun valore soddisfa la funzione di test, viene restituito undefined. [^4]

```javascript
const numbers = [1, 3, 5, 7, 9];
numbers.find((num) => num < 5);
// => 1
```

## `findIndex`

> Il metodo findIndex() restituisce l'indice del primo elemento nell'array che soddisfa la funzione di test fornita. In caso contrario, restituisce -1, indicando che nessun elemento ha superato il test. [^5]

```javascript
const numbers = [1, 3, 5, 7, 9];
numbers.findIndex((num) => num > 7);
// => 4
numbers.findIndex((num) => num > 9);
// => -1
```
