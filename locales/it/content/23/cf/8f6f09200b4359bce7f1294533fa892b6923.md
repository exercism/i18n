# I test

Per ogni esercizio c'è una configurazione iniziale da fare una sola volta, che può richiedere qualche minuto:

```
npm install
```

Apri due shell: nella prima avvia il processo di build.

```
npm start
```

Nella seconda avvia l'esecuzione dei test.

```
npm test
```

Mentre modifichi il codice, i due processi continueranno a ricostruire e rieseguire i test.
