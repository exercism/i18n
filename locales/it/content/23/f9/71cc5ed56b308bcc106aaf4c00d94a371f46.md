# Istruzioni

Un tuo amico ha un vecchio negozio all'ingrosso chiamato **Gross Store**.
Il nome deriva dalla quantità degli articoli che il negozio vende: è tutto in [unità gross][gross-unit].
Il tuo amico ti ha chiesto di implementare un sistema di punto vendita (POS) per il suo negozio.
**Per prima cosa, vuoi costruirne un prototipo.**
**Nel prototipo, il sistema registrerà solo la quantità.**
Il tuo amico ti ha dato un elenco di unità di misura per aiutarti:

| Unità              | Valore |
| ------------------ | ------ |
| quarter_of_a_dozen | 3      |
| half_of_a_dozen    | 6      |
| dozen              | 12     |
| small_gross        | 120    |
| gross              | 144    |
| great_gross        | 1728   |

## 1. Memorizza l'unità di misura nel programma

Per poter usare l'unità di misura, devi memorizzarla nel programma.

```go
units := Units()
fmt.Println(units)
// Output: map[...] with entries like ("dozen": 12)
```

## 2. Crea un nuovo conto per il cliente

Devi implementare una funzione che crei un nuovo conto (vuoto) per il cliente.

```go
bill := NewBill()
fmt.Println(bill)
// Output: map[]
```

## 3. Aggiungi un articolo al conto del cliente

Per implementarlo, dovrai:

- Restituire `false` se `unit` non è presente nella mappa `units`.
- Altrimenti, aggiungere l'articolo al `bill` del cliente, indicizzato con il nome dell'articolo, e restituire `true`.
- Se l'articolo è già presente nel conto, aumentarne la quantità del valore corrispondente all'`unit` fornita.

```go
bill := NewBill()
units := Units()
ok := AddItem(bill, units, "carrot", "dozen")
fmt.Println(ok)
// Output: true (since dozen is a valid unit)
```

> Nota che il valore restituito è di tipo `bool`.

## 4. Rimuovi un articolo dal conto del cliente

Per implementarlo, dovrai:

- Restituire `false` se l'articolo fornito **non** è presente nel conto
- Restituire `false` se `unit` non è presente nella mappa `units`.
- Restituire `false` se la nuova quantità sarebbe inferiore a 0.
- Se la nuova quantità è 0, rimuovere completamente l'articolo dal `bill` e restituire `true`.
- Altrimenti, ridurre la quantità dell'articolo e restituire `true`.

```go
bill := NewBill()
units := Units()
ok := RemoveItem(bill, units, "carrot", "dozen")
fmt.Println(ok)
// Output: false (because there are no carrots in the bill)
```

> Nota che il valore restituito è di tipo `bool`.

## 5. Restituisci la quantità di un articolo specifico presente nel conto del cliente

Per implementarlo, dovrai:

- Restituire `0` e `false` se `item` non è presente nel conto.
- Altrimenti, restituire la quantità dell'articolo nel `bill` e `true`.

```go
bill := map[string]int{"carrot": 12, "grapes": 3}
qty, ok := GetItem(bill, "carrot")
fmt.Println(qty)
// Output: 12
fmt.Println(ok)
// Output: true
```

> Nota che i valori restituiti sono di tipo `int` e `bool`.

[gross-unit]: https://en.wikipedia.org/wiki/Gross_(unit)
