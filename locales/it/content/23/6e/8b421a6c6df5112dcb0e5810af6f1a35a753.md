# Informazioni

[`Rational numbers`][rational] sono frazioni con un numeratore intero diviso per un denominatore intero.

Per esempio, possiamo memorizzare `2//3` come frazione esatta invece del valore approssimato `Float64` `0.6666...`

Il vantaggio è che (tranne nel caso estremo di [integer overflow][integer-overflow]) un numero razionale resta esatto, evitando gli errori di arrotondamento che spesso sono inevitabili con i numeri in virgola mobile.

Alcuni dettagli aggiuntivi si trovano nella [pagina del manuale][julia-rational] di Julia.

I numeri razionali sono un tipo numerico piuttosto semplice e funzionano più o meno come ti aspetteresti.
Dato che sono un tipo standard in Julia fin dalle prime versioni, la maggior parte delle funzioni li accetta come input allo stesso modo degli interi e dei numeri in virgola mobile.

## Creare i numeri razionali

Crearli è semplice come usare `//` tra due interi.

```julia-repl
julia> 3//4
3//4

julia> a = 3; b = 4;

julia> a//b
3//4
```

I fattori comuni vengono rimossi automaticamente, riducendo la frazione ai suoi [«minimi termini»][lowest-terms]: gli interi più piccoli che rappresentano accuratamente la frazione, con un denominatore non negativo.

```julia-repl
julia> 5//15
1//3

julia> 5//-15
-1//3
```

I risultati infiniti sono accettati, ma non [`NaN`][NaN].

```julia-repl
julia> 1//0
1//0

julia> float(1//0)
Inf

julia> 0//0
ERROR: ArgumentError: invalid rational: zero(Int64)//zero(Int64)
```

## Aritmetica con i numeri razionali

I soliti [`arithmetic operators`][operators] `+ - * / ^ %` funzionano con i razionali, essenzialmente come con gli altri tipi numerici.

Si possono includere numeri interi e altri `Rational`, ottenendo come risultato un `Rational`.
Includere un `float` nell'espressione produce un output `float`, con una conseguente (possibile) perdita di precisione.

Se si desidera un `float`, basta usare la funzione `float()` per convertire un razionale.
È del tutto normale usare i numeri razionali per preservare la precisione durante un calcolo lungo, per poi convertire in un numero in virgola mobile alla fine.

```julia-repl
julia> 3//4 + 1//3  # addition
13//12

julia> 3//4 * 1//3  # multiplication
1//4

julia> 3//4 / 1//3  # division
9//4

julia> 3//4 ^ 2  # exponentiation
3//16

julia> 3//4 + 5  # rational and int => rational
23//4

julia> 3//4 + 5.3  # rational and float => float
6.05

julia> float(3//4)  # casting
0.75
```

I razionali e i [numeri complessi][complex] si possono anche combinare.
I numeri complessi sono trattati in un [concetto separato][complex-concept].

## Altre operazioni

In Julia, i numeri razionali sono semplicemente numeri.
Di solito il compilatore converte i tipi quando serve.

Tuttavia, tieni presente che i confronti funzionano per le frazioni con una rappresentazione decimale finita:

```julia-repl
julia> 3//4 == 0.75
true

julia> 3//4 < 0.74
false
```

Negli altri casi, invece, per i confronti un `Rational` va convertito in un `Float`:

```julia-repl
julia> 1//3 == 1/3
false

julia> float(1//3) == 1/3
true
```

Le funzioni matematiche accettano i razionali come input, ma possono restituire un risultato in virgola mobile:

```julia-repl
julia> sqrt(9//16)
0.75
```
