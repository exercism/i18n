# Introduzione

## Valori predefiniti dei parametri

I [valori predefiniti dei parametri][default-parameter-values] si possono indicare per qualsiasi parametro di una funzione assegnando un valore al parametro nell'elenco dei parametri, subito dopo l'annotazione di tipo. Quando un valore predefinito è specificato per un parametro, chi chiama la funzione può omettere quel parametro: al suo posto verrà usato il valore predefinito.

```swift
func greeting(name: String = "guest", duration: Int = 2) -> String {
  "Welcome, \(name). Enjoy your \(duration) night stay."
}

greeting(name: "Bobo", duration: 7)
// Returns "Welcome, Bobo. Enjoy your 7 night stay."
greeting(duration: 3)
// Returns "Welcome, guest. Enjoy your 3 night stay."
greeting(name: "Wynona")
// Returns "Welcome, Wynona. Enjoy your 2 night stay."
greeting()
// Returns "Welcome, guest. Enjoy your 2 night stay."
```

## Parametri variadici

I [_parametri variadici_][variadic-parameters] in Swift permettono di passare zero o più valori dello stesso tipo a un singolo parametro di una funzione. Per indicarlo, si aggiunge `...` all'annotazione di tipo del parametro.

Questi valori vengono raggruppati automaticamente in un array i cui elementi hanno lo stesso tipo del parametro variadico.

```swift
func geometricMean(_ numbers: Double...) -> Double {
  var total = 1.0
  for number in numbers {
      total *= number
  }
  return pow(total, 1.0 / Double(numbers.count))
}

geometricMean(1, 2, 3, 4, 5)
// => 2.605171084697352
```

Tieni presente che, quando si usano i parametri variadici, Swift ha una limitazione.
Se nella definizione una funzione ha dei parametri che seguono il parametro variadico, il primo parametro dopo il variadico _deve_ avere un'etichetta dell'argomento.

## Parametri in-out

All'interno del corpo di una funzione, i parametri sono trattati come costanti, non come variabili: provare a modificarne il valore genera un errore in fase di compilazione.
Se una funzione vuole modificare il valore di un parametro, deve usare un [_parametro in-out_][in-out-parameters] per rendere esplicita questa mutabilità.

Per usare i parametri in-out, chi programma deve tenere presenti tre cose:

1. La definizione della funzione deve contrassegnare esplicitamente i parametri in-out scrivendo la parola chiave `inout` tra i `:` e il nome del tipo nell'annotazione di tipo del parametro.
2. Il valore passato al parametro in-out deve essere dichiarato come variabile, non come costante. Allo stesso modo, non può essere un valore letterale.
3. Il nome della variabile deve essere preceduto da un `&` nella chiamata alla funzione, per indicare esplicitamente che è modificabile.

Quando si fa così, la funzione crea una copia interna del parametro in-out, la modifica come indicato nel corpo della funzione e poi ricopia il valore modificato nella variabile passata, quando la funzione termina.

```swift
func updateVersion(_ record: inout (version: Int, title: String)) {
  record.version += 1
}

var dbRecord = (version: 2, title: "Exercism")
updateVersion(&dbRecord)

// dbRecord is now (3, "Exercism")
```

~~~~exercism/warning
Ci sono un paio di regole extra di cui tenere conto per quanto riguarda i parametri in-out.

1. All'interno di una funzione con parametri in-out, non è consentito fare riferimento alla variabile passata come parametro in-out.
2. La stessa variabile non può essere passata come più parametri in-out nella stessa funzione.
   Per esempio, `inoutFunc(&mutVar, &mutVar)` genera un errore del compilatore.
~~~~

## Funzioni annidate

In Swift, puoi definire [funzioni dentro altre funzioni][nested-functions].
Queste sono note come **funzioni annidate**.

Le funzioni annidate si usano comunemente come funzioni ausiliarie private che svolgono compiti specifici per la funzione che le contiene, senza appesantire lo scope esterno:

```swift
func makeNumber(_ number: Int) -> Int {
    func double(_ x: Int) -> Int {
        x * 2
    }

    func increment(_ x: Int) -> Int {
        x + 1
    }

    return number.isMultiple(of: 2) ? increment(double(number)) : double(number)
}

print(makeNumber(3)) // Prints 6
print(makeNumber(4)) // Prints 9
```

Le funzioni annidate si comportano come funzioni standard, ma la loro visibilità è limitata al corpo della funzione che le contiene.
