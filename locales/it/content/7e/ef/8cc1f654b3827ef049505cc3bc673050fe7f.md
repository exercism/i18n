# Introduzione

R non ha un tipo di dato Set separato: usa invece diverse funzioni per eseguire operazioni simili sui vettori.

L'operatore `%in%` verifica l'appartenenza a un insieme.

```R
2 %in% 1:10 # TRUE
12 %in% 1:10 # FALSE
```

Tra le funzioni rilevanti ci sono `unique` (per rimuovere i duplicati), oltre a `union()`, `intersect()`, `setdiff()` e `setequal()` per operare su coppie di insiemi.

```R
> set_1 <- c("a", "b", "c", "b", "a")
> unique(set_1) # deduplicate
[1] "a" "b" "c"

> set_2 <- c('a', "c", "d")
> union(set_1, set_2) # values in either set
[1] "a" "b" "c" "d"

> intersect(set_1, set_2) # values in both sets
[1] "a" "c"

> setdiff(set_1, set_2) # values in set_1 but not set_2
[1] "b"

> setdiff(set_2, set_1) # values in set_2 but not set_1
[1] "d"

setequal(set_1, c("c", "b", "a", "b")) # are elements the same after deduplication?
[1] TRUE
```

In ogni caso, `set_1` e `set_2` restano invariati.
