# Istruzioni

Sei un appassionato osservatore di uccelli che tiene traccia di quanti uccelli hanno visitato il tuo giardino negli ultimi sette giorni.

Hai sei attività, tutte legate al numero di uccelli che hanno visitato il tuo giardino.

## 1. Controlla quanti uccelli sono venuti oggi

Implementa la funzione `today()` in modo che restituisca quanti uccelli hanno visitato il tuo giardino oggi. I conteggi degli uccelli sono ordinati per giorno: il primo elemento è il conteggio del giorno più lontano, l'ultimo è il conteggio di oggi.

```R
birds_per_day <- c(2, 5, 0, 7, 4, 1)
today(birds_per_day)
# => 1
```

## 2. Incrementa il conteggio di oggi

Implementa la funzione `increment_todays_count()` per incrementare il conteggio di oggi:

```R
birds_per_day <- c(2, 5, 0, 7, 4, 1)
increment_todays_count(birds_per_day)
# => c(2, 5, 0, 7, 4, 2)
```

## 3. Controlla se c'è stato un giorno senza uccelli in visita

Implementa la funzione `has_day_without_birds()` che restituisce `TRUE` se c'è stato un giorno in cui zero uccelli hanno visitato il giardino; altrimenti restituisce `FALSE`:

```R
birds_per_day <- c(2, 5, 0, 7, 4, 1)
has_day_without_birds(birds_per_day)
# => true
```

## 4. Calcola il numero di uccelli in visita nei primi giorni specificati

Implementa la funzione `count_for_first_days()` che restituisce il numero di uccelli che hanno visitato il tuo giardino dall'inizio della settimana, ma limita il conteggio al numero di giorni specificato dall'inizio della settimana.

```R
birds_per_day <- c(2, 5, 0, 7, 4, 1)
count_for_first_days(birds_per_day, 4)
# => 14
```

## 5. Calcola il numero di giorni intensi

Alcuni giorni sono più intensi di altri. Un giorno intenso è un giorno in cui cinque o più uccelli hanno visitato il tuo giardino.
Implementa la funzione `busy_days()` in modo che restituisca il numero di giorni intensi:

```R
birds_per_day <- c(2, 5, 0, 7, 4, 1)
busy_days(birds_per_day)
# => 2
```

## 6. Calcola il totale progressivo delle visite degli uccelli nell'ultima settimana

Sei curioso di sapere quanti uccelli in totale sono venuti finora questa settimana.
Calcola i totali cumulativi per ogni giorno.

```R
running_total(c(7, 6, 5, 4, 3, 2, 1))
#> [1]  7 13 18 22 25 27 28
```

## 7. Ordina i nomi dei giorni in base a quanto sono intensi

Supponi che le visite degli uccelli siano influenzate dal traffico stradale nelle vicinanze, che è diverso nei fine settimana rispetto ai giorni feriali.

Ordina le abbreviazioni dei giorni in ordine _decrescente_ rispetto a quanti uccelli sono venuti.

```R
day_names <- c("Mon", "Tue", "Wed", "Thu", "Fri", "Sat", "Sun")
birds_per_day <- c(5, 2, 4, 6, 0, 9, 8)
busy_days_of_week(birds_per_day, day_names)
#> [1] "Sat" "Sun" "Thu" "Mon" "Wed" "Tue" "Fri"
```
