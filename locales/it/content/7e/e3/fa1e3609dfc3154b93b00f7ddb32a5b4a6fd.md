# Istruzioni

Elyse, aspirante maga, continua il suo addestramento. Le verranno dati diversi mazzi di carte che le servono per eseguire i suoi trucchi.
Per rendere le cose un po' più semplici, usa solo le carte da 1 a 10.

In questo esercizio, usa i metodi integrati per analizzare il contenuto di un vettore.

## 1. Determina se una carta è presente

Elyse vuole determinare se una carta è presente nel mazzo, in altre parole se il mazzo contiene un numero specifico.

```R
card = 3;
does_stack_include_card(c(2, 3, 4, 5), card);
# => TRUE
```

## 2. Trova la posizione di una carta

Elyse vuole conoscere la posizione (indice) di una carta nel mazzo. 
Se la carta non è nel mazzo, restituisci `-1`.

```R
card = 2;
get_card_position(c(9, 7, 3, 2), card);
# => 4
```

## 3. Determina se ogni carta è pari

Elyse vuole sapere se ogni carta è pari, in altre parole se ogni numero nel mazzo è un numero pari.

```R
is_each_card_even(c(2, 4, 6, 7));
# => FALSE
```

## 4. Controlla se il mazzo contiene una carta di valore dispari

Elyse vuole sapere se c'è un numero dispari nel mazzo.

```R
does_stack_include_odd_card(c(3, 2, 6, 4, 8));
# => TRUE
```

## 5. Prendi la prima carta dispari dal mazzo

Elyse vuole conoscere il valore della prima carta dispari.  
Se non c'è nessuna carta dispari nel mazzo, restituisci `-1`.

```R
get_first_odd_card(c(4, 2, 8, 7, 9));
# => 7
```

## 6. Determina la posizione della prima carta pari

Elyse vuole conoscere la posizione della prima carta pari.
Se non c'è nessuna carta pari nel mazzo, restituisci `-1`.

```R
get_first_even_card_position(c(5, 2, 3, 1));
# => 2
```
