# Introduzione ai cicli for-each

Il [ciclo for-each](https://docs.oracle.com/javase/tutorial/java/nutsandbolts/for.html) fornisce un meccanismo per eseguire un blocco di codice per ogni elemento di una collezione.
Alcune documentazioni (ad esempio quella di Oracle) li chiamano enhanced for loop.

Ecco la sintassi generale:

```java
for(declaration: collection) {
    body;
}
```

La `declaration` dichiara la variabile usata per contenere i valori assegnati dalla collezione.

La `collection` è un array o una collezione che contiene i valori che verranno assegnati alla variabile del ciclo.

Il `body` contiene le istruzioni che verranno eseguite una volta per ogni valore della collezione.

Per esempio:

```java
char[] vowels = {'a', 'e', 'i', 'o', 'u'};

for(char vowel: vowels) {
    System.out.println(vowel);
}
```

che produce il seguente output:

```text
a
e
i
o
u
```

In generale, un ciclo `for-each` è preferibile a un ciclo `for` per i seguenti motivi:

- Un ciclo `for-each` garantisce di iterare su _tutti_ i valori.
- Un ciclo `for-each` è più _dichiarativo_: il codice comunica _cosa_ sta facendo, invece di _come_ lo sta facendo.
- Un ciclo `for-each` è a prova di errore, mentre con i cicli `for` è facile commettere un errore off-by-one (pensa all'uso di `<` invece di `<=`).
- Un ciclo `for-each` funziona con tutti i tipi di collezione, comprese quelle che non supportano l'uso di un indice per accedere agli elementi (ad esempio un `Set`).
