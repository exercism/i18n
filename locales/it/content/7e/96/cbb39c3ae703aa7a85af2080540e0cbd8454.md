# Introduzione

## Array e vector

C++ offre diversi contenitori per memorizzare in modo ordinato elementi dello stesso tipo.
C'è `std::array` per contenitori di dimensione fissa e `std::vector`, che ha capacità di ridimensionamento dinamico.

### Costruzione

Quando dichiari un array o un vector devi specificare il tipo degli elementi che il contenitore conterrà.
Gli array richiedono anche una dimensione.
Guarda questi esempi per vedere l'inizializzazione dei due tipi di contenitore:

```cpp
#include <array>
#include <string>

// std::array<element_type, size> variable_name {list of elements}
std::array<std::string, 3> indie_rock {"yeah", "yeah", "yeah"};
// indie_rock contains the elements "yeah" three times
```

I vector di solito richiedono più spazio, perché allocano memoria per crescere ulteriormente.
Non devi specificare una dimensione:

```cpp
#include <vector>

// std::vector<element_type> variable_name {list of elements}
std::vector<int> countdown {3, 2, 1};
// countdown contains the elements 3, 2 and 1
```

> Nota: non hai ancora bisogno di conoscere la meccanica esatta che sta dietro al concetto di template: avrà un suo concetto più in basso nell'albero del percorso.

### Accesso agli elementi

Vector e array condividono le stesse funzioni per accedere ai loro elementi.
Puoi usare le funzioni membro `front` e `back` per ottenere il primo e l'ultimo elemento del contenitore.
Ci sono anche `at` e l'operatore `[]` per accedere a elementi specifici.

```cpp
countdown[0];
// => 3
countdown.at(2);
// => 1
countdown[1] = 4;
// countdown now contains 3, 4 and 1
indie_rock.back() = "yeahs";
// indie_rock is now "yeah", "yeah", "yeahs"
```

> Nota: se scegli una posizione che non rientra nell'intervallo del contenitore, `[]` potrebbe portare a un comportamento indefinito.
> La funzione `at` lancerebbe un'eccezione, il che a lungo termine potrebbe renderti la vita più semplice.

### Modificatori di vector

Dato che un `vector` non ha dimensione fissa, è possibile aggiungere o rimuovere elementi.
Due funzioni comuni a questo scopo sono `emplace_back` e `pop_back`.

```cpp
std::vector<std::string> witches {"Holly", "Alyssa", "Shannen"};
witches.pop_back();
// Shannen is no longer with the witches
witches.emplace_back("Rose");
// Rose has joined the team
```

### Capacità

Puoi verificare se i contenitori sono vuoti con la funzione membro `empty`.
Se vuoi conoscere il numero di elementi, puoi usare `size`.
