# Normalizzazioni del representer

Il [representer di Elixir][representer] applica diverse normalizzazioni.
Per i dettagli, fai riferimento al codice o ai [dati di test][test-data].

## Rimuovere commenti e doc

Tutti i commenti, i doc, i moduledoc e i typedoc vengono rimossi.

### Prima

```elixir
defmodule Fake do
  @moduledoc """
  Fake module to demonstrate stuff
  """

  @doc "Not much to see here"
  def foo do
    # TODO: return bar
    nil
  end
end
```

### Dopo

```elixir
defmodule Fake do
  def foo do
    nil
  end
end
```

## Ordinare l'ordine degli import

Le istruzioni import all'inizio dei moduli o delle funzioni vengono ordinate così: `alias`, `use`, `require`, `import`.

### Prima

```elixir
defmodule Fake do
  import D
  alias A.U.V
  use B
  alias A.{T, S}
  require C

  def foo do
    import Z
    alias X
    use Y
  end

  import NotTouched
  alias NotTouched
end
```

### Dopo

```elixir
defmodule Fake do
  alias A.{S, T}
  alias A.U.V
  use B
  require C
  import D

  def foo do
    alias X
    use Y
    import Z
  end

  import NotTouched
  alias NotTouched
end
```

## Formattare il codice

Il codice viene formattato usando [mix code][mix-code], forzando i blocchi `do` `end`.
Tutte le funzioni nelle pipe vengono scritte con le parentesi, i tipi senza.

### Prima

[//]: # (elixir-formatter-disable-next-block)

```elixir
defmodule    Fake   do
        @type foo() :: integer() | atom
def foo, do:    nil |> bar
end
```

### Dopo

```elixir
defmodule Fake do
  @type foo() :: integer | atom
  def foo do
    nil |> bar()
  end
end
```

## Normalizzare gli identificatori

Gli identificatori vengono normalizzati in un valore segnaposto.
Alcune variabili speciali e attributi di modulo (`_`, `@spec`, `__MODULE__`, ecc.) non vengono sostituiti.
Le chiavi delle mappe, delle struct e delle keyword list non vengono normalizzate.

### Prima

```elixir
defmodule Fake do
  alias Fake, as: SuperFake
  @my_constant 42

  @impl true
  def foo(bar) when is_integer(bar) do
    bar + @my_constant
  end

  def foo(%{a: a} = bar) do
    %{bar | a: a + @my_constant}
  end

  def foo(_), do: nil
end
```

### Dopo

```elixir
defmodule Placeholder_1 do
  alias Placeholder_1, as: Placeholder_2
  @placeholder_6 42
  @impl true
  def placeholder_4(placeholder_5) when is_integer(placeholder_5) do
    placeholder_5 + @placeholder_6
  end

  def placeholder_4(%{a: placeholder_7} = placeholder_5) do
    %{placeholder_5 | a: placeholder_7 + @placeholder_6}
  end

  def placeholder_4(_) do
    nil
  end
end
```

## Ordinare le chiavi nelle mappe e nelle struct

Le chiavi nelle mappe e nelle struct vengono ordinate.
Le chiavi nelle keyword list non vengono ordinate.

### Prima

```elixir
defmodule Fake do
  def foo do
    %MyStruct{z: 3, y: 2, x: 1}
    m = %{c: 3, a: 1, b: 2}
    %{m | b: 20, a: 10}
    [b: 2, a: 1]
  end
end
```

### Dopo

```elixir
defmodule Fake do
  def foo do
    %MyStruct{x: 1, y: 2, z: 3}
    placeholder_3 = %{a: 1, b: 2, c: 3}
    %{placeholder_3 | a: 10, b: 20}
    [b: 2, a: 1]
  end
end
```
