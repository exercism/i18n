# Il debug in `jq`

`jq` include un comodo filtro [`debug`][debug].
Usalo mentre sviluppi le soluzioni degli esercizi per ispezionare i dati che al momento si trovano nella pipeline di jq.
Per maggiori dettagli, consulta la [documentazione sul debug][debugging].

[debug]: https://jqlang.org/manual/#debug
[debugging]: https://exercism.org/docs/tracks/jq/debugging
