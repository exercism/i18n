# non usare il metodo main

Prova a rimuovere il metodo `main` dal codice.
I test dell'esercizio non richiedono che la soluzione abbia un metodo `main`. Averne uno rende il codice un po' più difficile da leggere.

Di solito, un metodo `main` viene aggiunto per facilitare il debug del codice.
Tuttavia, un approccio migliore è fare il debug del codice mentre si eseguono uno o più test unitari. In più, puoi concentrarti sul debug di un caso di test specifico.

Ecco alcuni link che spiegano come fare il debug del codice Java mentre si eseguono test unitari in vari IDE:

- [Eseguire e fare il debug dei test Java in Visual Studio Code](https://code.visualstudio.com/docs/java/java-testing#_rundebug-test-cases)
- [Fare il debug dei test in IntelliJ IDEA](https://www.jetbrains.com/help/idea/performing-tests.html#RedebugFailedTests)
