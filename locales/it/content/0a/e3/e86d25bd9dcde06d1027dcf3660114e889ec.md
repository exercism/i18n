# Istruzioni

In questo esercizio implementerai la logica di missione per un nuovo gioco di ruolo che un amico sta sviluppando. Il personaggio principale del gioco è Annalyn, una ragazza coraggiosa con un cane feroce e fedele. Purtroppo arriva la catastrofe: la sua migliore amica è stata rapita mentre cercava bacche nel bosco. Annalyn cercherà di trovare e liberare la sua migliore amica, portando eventualmente con sé il cane in questa missione.

Dopo aver seguito per un po' le tracce della sua migliore amica, trova l'accampamento in cui è tenuta prigioniera. Si scopre che i rapitori sono due: un cavaliere possente e un arciere astuto.

Dopo aver trovato i rapitori, Annalyn valuta quale delle seguenti azioni può intraprendere:

- Attacco rapido: è possibile sferrare un attacco rapido se il cavaliere dorme, perché impiega del tempo a indossare l'armatura, quindi sarà vulnerabile.
- Spionaggio: si può spiare il gruppo se almeno uno di loro è sveglio. Altrimenti, spiare è una perdita di tempo.
- Segnalare al prigioniero: si può segnalare al prigioniero usando versi di uccelli se il prigioniero è sveglio e l'arciere dorme, perché gli arcieri sono addestrati al linguaggio degli uccelli e potrebbero intercettare il messaggio.
- _Liberare il prigioniero_: Annalyn può provare a intrufolarsi nell'accampamento per liberare il prigioniero.
  È un'operazione rischiosa e può riuscire solo in uno dei due modi seguenti:
  - Se Annalyn ha il cane con sé, può salvare il prigioniero se l'arciere dorme.
    Il cavaliere ha paura del cane e l'arciere non avrà il tempo di prepararsi prima che Annalyn e il prigioniero riescano a fuggire.
  - Se Annalyn non ha il cane, allora lei e il prigioniero devono essere molto furtivi!
    Annalyn può liberare il prigioniero se il prigioniero è sveglio e sia il cavaliere sia l'arciere dormono; ma se il prigioniero dorme non può essere salvato: si spaventerebbe per l'apparizione improvvisa di Annalyn e sveglierebbe il cavaliere e l'arciere.

Hai quattro compiti: implementare la logica che determina se le azioni precedenti sono disponibili in base allo stato dei tre personaggi presenti nel bosco e alla presenza o meno del cane di Annalyn.

## 1. Verifica se l'azione «Attacco rapido» è possibile

Implementa una funzione chiamata `canExecuteFastAttack` che riceve un valore booleano che indica se il cavaliere è sveglio. La funzione restituisce `true` se l'azione «Attacco rapido» è disponibile in base allo stato del personaggio. Altrimenti, restituisce `false`:

```purescript
knightIsAwake :: Boolean
knightIsAwake = true

canExecuteFastAttack knightIsAwake
-- => false
```

## 2. Verifica se l'azione «Spionaggio» è possibile

Implementa una funzione chiamata `canSpy` che riceve tre valori booleani, che indicano rispettivamente se il cavaliere, l'arciere e il prigioniero sono svegli. La funzione restituisce `true` se l'azione «Spionaggio» è disponibile in base allo stato dei personaggi. Altrimenti, restituisce `false`:

```purescript
knightIsAwake :: Boolean
knightIsAwake = true

archerIsAwake :: Boolean
archerIsAwake = true

prisonerIsAwake :: Boolean
prisonerIsAwake = true

canSpy knightIsAwake archerIsAwake prisonerIsAwake
-- => true
```

## 3. Verifica se l'azione «Segnalare al prigioniero» è possibile

Implementa una funzione chiamata `canSignalPrisoner` che riceve due valori booleani, che indicano rispettivamente se l'arciere e il prigioniero sono svegli. La funzione restituisce `true` se l'azione «Segnalare al prigioniero» è disponibile in base allo stato dei personaggi. Altrimenti, restituisce `false`:

```purescript
archerIsAwake :: Boolean
archerIsAwake = false

prisonerIsAwake :: Boolean
prisonerIsAwake = true

canSignalPrisoner archerIsAwake prisonerIsAwake -- => true
```

## 4. Verifica se l'azione «Liberare il prigioniero» è possibile

Implementa una funzione chiamata `canFreePrisoner` che riceve quattro valori booleani. I primi tre parametri indicano rispettivamente se il cavaliere, l'arciere e il prigioniero sono svegli. L'ultimo parametro indica se il cane di Annalyn è presente. La funzione restituisce `true` se l'azione «Liberare il prigioniero» è disponibile in base allo stato dei personaggi e alla presenza del cane di Annalyn. Altrimenti, restituisce `false`:

```purescript
knightIsAwake :: Boolean
knightIsAwake = true

archerIsAwake :: Boolean
archerIsAwake = false

prisonerIsAwake :: Boolean
prisonerIsAwake = true

petDogIsPresent :: Boolean
petDogIsPresent = true

canFreePrisoner knightIsAwake archerIsAwake prisonerIsAwake petDogIsPresent
-- => false
```
