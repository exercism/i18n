L'obiettivo di questo esercizio è migliorare l'esercizio Controllo della password.
Dato che è probabile che una data password violi più di una regola alla volta, un controllo della password utile dovrebbe comunicare all'utente tutte le regole violate, invece di limitarsi alla prima che capita di scoprire.
Il controllo della password migliorato dovrebbe indicare in una sola volta tutte le regole violate da una data password.

Le regole per questo controllo della password sono le stesse dell'esercizio precedente Controllo della password:

- Deve contenere almeno 12 caratteri
- Deve contenere almeno una lettera maiuscola
- Deve contenere almeno una lettera minuscola
- Deve contenere almeno una cifra
- Deve contenere almeno un simbolo nell'insieme !@#$%^&\*

## 1. Modifica l'unione discriminata `PasswordError` per permettere di trattare i singoli valori come flag

## 2. Implementa la funzione `checkPassword`

La funzione `checkPassword` verifica la password data rispetto alle regole menzionate sopra.
La funzione deve restituire un valore `Result`: `Ok` quando la password soddisfa tutte le regole, un valore `Error` quando ne viola una o più.
Se la password data viola più regole, il valore `PasswordError` deve rappresentare tutte le regole violate.

```fsharp
checkPassword "abcdefghijk5"
// => Error (PasswordError.MissingUppercaseLetter ||| PasswordError.MissingSymbol)
```

## 3. Implement the ``getStatusPhrases` function

La funzione `getStatusPhrases` restituisce un insieme di stringhe, ognuna contenente una frase leggibile che corrisponde a uno degli errori nel risultato restituito da `checkPassword`.

```fsharp
getStatusPhrases (Error PasswordError.MissingDigit ||| PasswordError.LessThan12Characters)
// => List ["12 characters"; "digit"]
```
