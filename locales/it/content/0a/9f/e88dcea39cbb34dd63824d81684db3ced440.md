# Introduzione

## Basi 1

### Costanti e funzioni

Un valore costante si definisce con `name = expression`: in Elm, tutto ciò che non è una definizione è un'espressione.

```elm
five = 5

six = 3 + 3
```

Le funzioni si definiscono con `name parameters... = expression`, con i parametri separati soltanto da uno spazio.

```elm
add number1 number2 = number1 + number2
```

Anche chiamare una funzione è un'espressione, e si fa specificando il nome della funzione e passando un argomento per ciascuno dei suoi parametri, separati da uno spazio, proprio come nella definizione di una funzione.

```elm
five = add 2 3
```

Le parentesi tonde (`()`) possono essere usate per specificare l'ordine di valutazione di un'espressione.

```elm
six = add 2 (1 * 4)

twelve = add 2 1 * 4
```

### Indentazione / spazi significativi

Elm non usa marcatori sintattici come parentesi graffe, parentesi tonde o punti e virgola per delimitare il codice. Usa invece gli spazi e le indentazioni.

- Le definizioni di moduli, gli import e le funzioni di primo livello devono iniziare dalla colonna più a sinistra.
- Se un'espressione è divisa su più righe, il codice che fa parte di quell'espressione deve essere indentato sotto l'espressione con almeno uno spazio.
- Le parti dell'espressione raggruppate insieme dovrebbero essere indentate con lo stesso numero di spazi.

```elm
-- A function split over multiple lines, so subsequent lines must be indented
add number1 number2 =
    number1 + number2
```

https://elmprogramming.com/indentation.html

### Moduli

Ogni file in Elm è un modulo, e deve contenere un'istruzione `module` prima di ogni altro codice.
I nomi dei moduli devono corrispondere al nome del file, quindi il modulo `Calculator` deve trovarsi nel file Calculator.elm.
Tutto ciò che è definito all'interno di un modulo ha uno scope privato rispetto ad esso e non è accessibile dall'esterno del modulo, a meno che non sia elencato in `exposing`.

```elm
-- Define the Calculator module, and expose the `add` function
module Calculator exposing (add)

six = 3 + 3

add number1 number2 = number1 + number2
```

```elm
-- Define the Calculator module, and expose everything within: `six` and `add`
module Calculator exposing (..)

six = 3 + 3

add number1 number2 = number1 + number2
```

https://elm-lang.org/docs/syntax#modules

### Commenti

Un commento è del testo all'interno del file Elm che non viene interpretato come codice.
Serve soprattutto a essere letto da te e da altri programmatori.
Esiste una sintassi leggera per i commenti su una sola riga, basata sui doppi trattini.
I commenti multilinea sono possibili anche con la coppia `{-` e `-}` di delimitatori di apertura e chiusura.

```elm
-- a single line comment
-- another single line comment

{- a multiline comment
   spawning multiple lines
-}
```

Esiste una [guida di stile](https://elm-lang.org/docs/style-guide), e [elm-format](https://github.com/avh4/elm-format) può essere usato per formattare il codice automaticamente.
