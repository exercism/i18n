# Ordine delle annotazioni di funzione

Per convenzione, le annotazioni di funzione `@doc` dovrebbero precedere le annotazioni di funzione `@spec`, e le annotazioni di funzione `@spec` dovrebbero venire direttamente prima della funzione. Se la funzione ha più clausole, le annotazioni di funzione dovrebbero andare prima della prima clausola.

Esempio:

```elixir
@doc """
This function counts the number elements in a list
"""
@spec count(list(any())) :: integer()
def count([]), do: 0
def count([h | t]), do: 1 + count(t)
```
