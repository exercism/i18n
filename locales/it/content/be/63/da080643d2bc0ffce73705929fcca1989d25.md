# Informazioni

Una `List` è molto simile a un [`Array`][array]. Tuttavia, ci sono differenze importanti che non vuoi perderti:

1. Una `List` non può essere indicizzata usando le parentesi quadre, cioè `[0]`.
2. Una `List` non può essere inizializzata.
3. Non esistono le list comprehension.
4. Una `List` può modificare liberamente gli elementi mentre si itera su di essa.

`List` fa parte del pacchetto `haxe.ds`, quindi ogni volta che vuoi usare le liste devi importare il suo pacchetto:

```haxe
import haxe.ds.List;

class Main {
  static function main() {
    var myList = List<Int>();

    for (i in 0...5) {
      myList.add(i);
    }

    trace(myList); // {0, 1, 2, 3, 4}
  }
}
```

[array]: https://haxe.org/manual/std-Array.html
