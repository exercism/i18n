# https://www.php.net/manual/en/language.basic-syntax.phptags.php"Operatore di risoluzione dello scope

L'operatore di risoluzione dello scope (`::`) ci permette di fare riferimento a una classe per accedere alle sue costanti, alle proprietà statiche o ai metodi statici.

```php
class MyClass
{
  public const MY_VALUE = 1;
}

// MyClass::class => "MyClass"
// MyClass::MY_VALUE => 1
```

## Usare `self` e `static` con l'operatore di risoluzione dello scope

Può essere necessario che un oggetto faccia riferimento al proprio scope. Per facilitarlo, la parola chiave `self` permette a una classe di fare riferimento al proprio scope. Usare la parola chiave `self` scollega la classe dal suo stesso nome, il che rende più facile mantenere il codice nel tempo.

```php
class MyClass
{
  public const MY_VALUE = 1;

  public function getMyValue(): int
  {
    return self::MY_VALUE;
  }
}

// (new MyClass)->getMyValue() => 1
```

Tuttavia, `self` è legato lessicalmente alla classe in cui appare.

```php
class MyOtherClass extends MyClass
{
  public const MY_VALUE = 99;
}

// (new MyOtherClass)->getMyValue() => 1
```

Valutare `MyOtherClass::getMyValue` restituisce comunque `1` invece di `99`. Per aggirare il problema, usa la parola chiave `static` con l'operatore di risoluzione dello scope per fare il «late binding» del riferimento alla classe discendente corrente.

```php
// Update MyClass:
class MyClass
{
  public const MY_VALUE = 1;

  public function getMyValue(): int
  {
    return static::MY_VALUE;
  }
}
```

## Usare `parent` con l'operatore di risoluzione dello scope

Può esserci la necessità di fare riferimento specificamente a una costante, a una proprietà o a un metodo disponibile dallo scope genitore:

```php
class MyClass
{
  public function getMaximum(): int
  {
    return 5;
  }
}

class AnotherClass extends MyClass
{
  public function getMaximum(): int
  {
    return parent::getMaximum() * 2;
  }
}

// (new AnotherClass())->getMaximum() => 10
```

Nella programmazione orientata agli oggetti, `parent` viene usato più comunemente per chiamare il costruttore del genitore quando si istanzia un oggetto:

```php
class ChildClass extends ParentClass
{
  public function __construct(): void
  {
    parent::__construct();
  }
}
```

## Avvertenze

### Visibilità di costanti, proprietà e metodi

L'operatore di risoluzione dello scope segue comunque le regole stabilite dai modificatori di visibilità `public`, `private` e `protected`.
