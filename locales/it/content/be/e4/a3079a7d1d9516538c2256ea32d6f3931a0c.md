## Feedback, issue e pull request

Il repository [exercism/haskell](https://github.com/exercism/haskell) su GitHub è il punto di riferimento per tutti gli esercizi di Haskell.

Se hai un feedback su un esercizio, o vuoi aiutare a implementarne uno nuovo, vai lì e apri una issue. Faremo del nostro meglio per aiutarti!
