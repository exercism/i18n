# Informazioni

Un'*espressione regolare* (regex) è un piccolo pattern che descrive la forma di un testo. Gli strumenti per le regex di Factor si trovano nel vocabolario [`regexp`][regexp], e un pattern si scrive come un letterale tra `R/ ` e `/`.

Nella maggior parte dei casi, i caratteri di un pattern corrispondono a se stessi. La potenza espressiva arriva dalle classi di caratteri e dai quantificatori:

```
\d        ! a digit 0–9            \s   ! whitespace
\D        ! any non-digit          \S   ! non-whitespace
[A-Z]     ! one capital letter     .    ! any one character
[^0-9]    ! any char except a digit

{4}       ! exactly 4              +    ! one or more
{2,5}     ! between 2 and 5        *    ! zero or more
?         ! optional               |    ! either side (alternation)
```

Quindi `R/ [A-Z]{2}-\d{4}/` corrisponde a «due lettere maiuscole, un trattino, quattro cifre».

## Corrispondenza dell'intera stringa o ricerca

`matches?` ha successo solo quando l'*intera* stringa corrisponde al pattern. Le altre parole cercano *all'interno* di una stringa:

```
matches?             ( string regexp -- ? )
re-contains?         ( string regexp -- ? )
count-matches        ( string regexp -- n )
all-matching-subseqs ( string regexp -- seq )
first-match          ( string regexp -- slice/f )
re-split             ( string regexp -- seq )
re-replace           ( string regexp replacement -- result )
```

```factor
USING: regexp ;

"NS-1024" R/ [A-Z]{2}-\d{4}/ matches? .         ! => t
"id NS-1024 ok" R/ [A-Z]{2}-\d{4}/ matches? .   ! => f   (extra text)
"id NS-1024 ok" R/ [A-Z]{2}-\d{4}/ re-contains? .   ! => t

"a1b2c3" R/ \d/ count-matches .   ! => 3
"a1b2c3" R/ \d/ re-replace .      ! NOTE: see re-replace below
```

## Le slice

`first-match` e `re-split` restituiscono oggetti `slice`: viste leggere sulla stringa originale, non stringhe nuove. Converti una slice con `>string` quando ti serve una stringa a sé stante (per esempio per confrontarla con un letterale stringa). `all-matching-subseqs` restituisce già delle stringhe.

## Sostituire

`re-replace` sostituisce ogni corrispondenza con una stringa di sostituzione e restituisce il risultato:

```factor
USING: regexp ;

"user=alice pass=hunter2" R/ pass=\S+/ "pass=****" re-replace .
! => "user=alice pass=****"
```

## Costruire un pattern a runtime

`R/ /` viene analizzato quando il file viene caricato. Per costruire un pattern a partire da una stringa calcolata a runtime, usa `<regexp>`:

```
<regexp> ( string -- regexp )
```
