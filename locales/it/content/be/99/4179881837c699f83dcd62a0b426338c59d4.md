# Installazione

Cairo si può installare semplicemente scaricando Scarb. Scarb raggruppa il compilatore Cairo e il language server di Cairo in un unico pacchetto facile da installare, così puoi iniziare subito a scrivere codice Cairo. Scarb è anche il gestore di pacchetti di Cairo.

Per ottenere le istruzioni di installazione consigliate per la tua piattaforma, vai sul [sito ufficiale di Cairo](https://www.cairo-lang.org/tutorials/getting-started-with-cairo/).

Per sistema operativo:

- Linux/MacOS
    1. Installa [asdf](https://asdf-vm.com/guide/getting-started.html)
    2. Installa [scarb](https://docs.swmansion.com/scarb/download#install-via-asdf)
    3. Verifica l'installazione in una nuova sessione del terminale `scarb --version`
- Windows
    1. Installa [scarb](https://docs.swmansion.com/scarb/download#windows)
    2. Verifica l'installazione in una nuova sessione del terminale `scarb --version`

Avere la toolchain installata non è tutto! Il supporto IDE è un enorme vantaggio in termini di produttività, che la maggior parte degli sviluppatori ormai dà per scontato.
Se usi Visual Studio Code, ti consigliamo di installare l'[estensione Cairo](https://marketplace.visualstudio.com/items?itemName=starkware.cairo1), che offre evidenziazione della sintassi, completamento del codice e altre funzionalità utili!
