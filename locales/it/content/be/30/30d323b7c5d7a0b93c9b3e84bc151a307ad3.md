# Informazioni

Disponibili a partire da `PHP 8.0.0`, le **dichiarazioni di tipo unione** accettano valori di più tipi diversi, anziché di un solo tipo. Le definizioni di tipo unione si creano usando il carattere pipe (`|`) per separare i tipi.

```php
function add(int|float $a, int|float $b): int|float
{
    return $a + $b;
}
```

## Sfumature

- I tipi `null` possono essere dichiarati _nullable_ usando `?Type` oppure `Type1|Type2|null`.
- Dichiarare tipi duplicati o ridondanti comporta un errore in fase di compilazione.
- `void` non può essere usato come parte di una dichiarazione di tipo unione.
