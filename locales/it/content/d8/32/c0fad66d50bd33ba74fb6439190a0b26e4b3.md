# Istruzioni

In questo esercizio giochi a un gioco di ruolo in cui diversi tipi di combattenti possono scontrarsi tra loro.
Il gioco ha regole diverse per ogni tipo di combattente.
Ci concentreremo su due tipi specifici: Wizards e Warriors.

Per un Warrior, queste sono le regole:

- Un Warrior non è mai vulnerabile.
- Un Warrior infligge `6` punti di danno se il combattente che sta attaccando non è vulnerabile.
- Un Warrior infligge `10` punti di danno se il combattente che sta attaccando è vulnerabile.

Per un Wizard, queste sono le regole:

- Un Wizard può preparare un incantesimo in anticipo.
- Un Wizard è vulnerabile a meno che non abbia preparato un incantesimo in anticipo.
- Un Wizard infligge `12` punti di danno se ha preparato un incantesimo in anticipo.
- Un Wizard infligge `3` punti di danno se non ha preparato un incantesimo in anticipo.

## 1. Crea la classe Warrior

Crea una nuova classe chiamata `Warrior`.
Questa classe deve ereditare dalla classe `Fighter` esistente.

## 2. Descrivi un Warrior

Aggiorna la classe `Warrior` in modo che il suo metodo `toString()` descriva che tipo di combattente è.
Il metodo deve restituire la stringa `"Fighter is a Warrior"`.

```java
Warrior warrior = new Warrior();
warrior.toString();
// => "Fighter is a Warrior"
```

## 3. Rendi i Warrior invulnerabili

Aggiorna la classe `Warrior` in modo che il suo metodo `isVulnerable()` restituisca sempre `false`.

```java
Warrior warrior = new Warrior();
warrior.isVulnerable();
// => false
```

## 4. Calcola i punti di danno per un Warrior

Aggiorna la classe `Warrior` in modo che il suo metodo `getDamagePoints(Fighter)` calcoli il danno inflitto da un Warrior secondo le regole qui sopra.

```java
Warrior warrior = new Warrior();
Wizard wizard = new Wizard();

warrior.getDamagePoints(wizard);
// => 10
```

## 5. Crea la classe Wizard

Crea un'altra nuova classe chiamata `Wizard`.
Anche questa classe deve ereditare dalla classe `Fighter` esistente.

## 6. Descrivi un Wizard

Aggiorna la classe `Wizard` in modo che il suo metodo `toString()` descriva che tipo di combattente è.
Il metodo deve restituire la stringa `"Fighter is a Wizard"`.

```java
Wizard wizard = new Wizard();
wizard.toString();
// => "Fighter is a Wizard"
```

## 7. Permetti ai Wizard di preparare un incantesimo e rendili vulnerabili quando non ne hanno preparato uno

Aggiorna la classe `Wizard` per aggiungere un metodo chiamato `prepareSpell()`.
La classe deve ricordare quando questo metodo viene chiamato e assicurarsi che il suo metodo `isVulnerable()` restituisca `false` solo quando un incantesimo è preparato.

```java
Wizard wizard = new Wizard();
wizard.prepareSpell();
wizard.isVulnerable();
// => false
```

## 8. Calcola i punti di danno per un Wizard

Aggiorna la classe `Wizard` in modo che il suo metodo `getDamagePoints(Fighter)` calcoli il danno inflitto da un Wizard secondo le regole qui sopra.

```java
Wizard wizard = new Wizard();
Warrior warrior = new Warrior();

wizard.prepareSpell();
wizard.getDamagePoints(warrior);
// => 12
```
