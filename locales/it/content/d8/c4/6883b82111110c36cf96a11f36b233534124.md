# Appendice alle istruzioni

## Formato dell'output

Restituisci le piante dello studente come stringa, usando una virgola ed uno spazio come separatori.

## Memoria riservata

Il buffer per la stringa del diagramma usa i byte 1024-2047 della memoria lineare.
Il buffer per la stringa dello studente usa i byte 2048-3071 della memoria lineare.

Le stringhe di input possono essere modificate sul posto, se lo si desidera.
