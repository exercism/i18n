# Introduzione

Common Lisp fornisce diverse espressioni condizionali, la cui differenza principale sta nel numero di rami che supportano.

- `when` e `unless` permettono un solo ramo:

```lisp
(when (= 2 2) "All is well")      ; => "All is well"
(unless (= 2 2) "Time to panic!") ; => NIL
```

La sezione dopo l'espressione di test può contenere più di un'espressione.

- `if` fornisce il classico costrutto if-then-else:

```lisp
(if (= 2 2) 'how-honest 'you-liar) ; => HOW-HONEST
```

Nota che sia la clausola then sia quella else possono contenere una sola espressione.

- `cond` permette di avere più rami senza annidare espressioni `if`:

```lisp
(cond ((= 0 2) 'nope)
      ((= 1 2) 'try-again)
      ((= 2 2) 'quite-true)
      ((= 3 2) 'too-far)
      (t 'something-else))
; => QUITE-TRUE
```

Nota che non c'è limite al numero di espressioni dopo l'espressione di test.

- `case` fornisce un classico costrutto in stile «switch»: confronta un singolo valore con diversi rami:

```lisp
(case 'elder-beast
  (cat "Meow")
  (bird "Chirp")
  (dog "Bark")
  (otherwise "???"))
; => "???"
```

Nota che, come per `cond`, non c'è limite al numero di espressioni dopo l'espressione di test.
