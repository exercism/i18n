# Suggerimenti

## Generale

- Gli indirizzi in memoria su x86-64 sono numeri a 64 bit (8 byte).
- Usa `rel` per formare indirizzi relativi validi in memoria.

## 1. Ottenere il valore RGB di un colore

- Gli indirizzi in memoria su x86-64 sono numeri a 64 bit (8 byte).
- Usa `rel` per formare indirizzi relativi validi in memoria.
- Per accedere ai contenuti memorizzati in un indirizzo di memoria, devi dereferenziarlo usando `[]`.
- Gli interi a 32 bit (4 byte) vengono restituiti in `eax`.

## 2. Aggiungere il colore di base

- Gli indirizzi in memoria su x86-64 sono numeri a 64 bit (8 byte).
- Usa `rel` per formare indirizzi relativi validi in memoria.
- Le variabili inizializzate sono definite nella _section .data_.
- Una variabile deve essere dichiarata `global` per essere visibile agli altri file sorgente.
- Puoi riutilizzare la funzione `get_color_value` già implementata.

## 3. Definire le costanti per i colori primari

- Gli indirizzi in memoria su x86-64 sono numeri a 64 bit (8 byte).
- Usa `rel` per formare indirizzi relativi validi in memoria.
- Le costanti inizializzate sono definite nella _section .rodata_.
- Una costante deve essere dichiarata `global` per essere visibile agli altri file sorgente.

## 4. Combinare i colori

- Gli indirizzi in memoria su x86-64 sono numeri a 64 bit (8 byte).
- Usa `rel` per formare indirizzi relativi validi in memoria.
- Per accedere ai contenuti memorizzati in un indirizzo di memoria, devi dereferenziarlo usando `[]`.
- Una funzione o un dato esterno deve essere dichiarato `extern` nella sezione corrispondente.
- Una funzione esterna può modificare qualsiasi registro tu stia usando, quindi devi salvare le variabili in memoria prima di chiamarla.
- `combining_function` prende il valore a 32 bit (non l'indirizzo) del colore di base in `rdi` e il valore a 32 bit (non l'indirizzo) del colore secondario in `rsi`.
