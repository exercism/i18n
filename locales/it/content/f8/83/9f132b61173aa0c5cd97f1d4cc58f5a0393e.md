# Introduzione

## Argomenti etichettati

A volte, quando una funzione accetta molti argomenti, può essere difficile ricordare l'ordine in cui vanno passati. Per facilitare la lettura, Gleam permette di etichettare gli argomenti con un nome.

Per etichettare un argomento, specifica il nome dell'etichetta prima del nome dell'argomento, separandoli con uno spazio.

```gleam
pub fn replace(
  in string: String,
  each target: String,
  with replacement: String
) -> String {
  // ...
}
```

Quando chiami una funzione con argomenti etichettati, puoi passare gli argomenti in qualsiasi ordine. Ognuna di queste chiamate a `replace` è equivalente:

```gleam
replace(in: "🍔🍔🍔", each: "🍔", with: "🍕")

replace(each: "🍔", in: "🍔🍔🍔", with: "🍕")

replace(with: "🍕", each: "🍔", in: "🍔🍔🍔")
```

Le etichette sono sempre facoltative. Anche se una funzione ha argomenti etichettati, puoi comunque chiamarla senza etichette.

```gleam
replace("🍔🍔🍔", "🍔", "🍕")
```
