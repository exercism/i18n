# Introduzione

I [dizionari][dictionaries] sono uno dei tipi di collezione principali di Swift.
Un dizionario memorizza associazioni non ordinate tra chiavi uniche e i valori corrispondenti.
Tutte le chiavi di un dizionario devono essere dello stesso tipo, ed anche tutti i valori devono condividere lo stesso tipo.

I literal dei dizionari si scrivono come coppie `key: value` separate da virgole e racchiuse tra parentesi quadre:

```swift
var addresses: Dictionary<String, String> = [
    "The Munsters": "1313 Mockingbird Lane",
    "The Simpsons": "742 Evergreen Terrace",
    "Buffy Summers": "1630 Revello Drive"
]

var sequences: [String: [Int]] = [
    "Euler's totient": [1, 1, 2, 2, 4, 2, 6, 4],
    "Lazy caterer": [1, 2, 4, 7, 11, 16, 22, 29, 37],
    "Carmichael": [561, 1105, 1729, 2465, 2821, 6601, 8911, 10585, 15841]
]

let constants = [
    "pi": 3.14159,
    "e": 2.71828,
    "phi": 1.618033,
    "avogadro": 6.02214076e23
]
```

I tipi dei dizionari si possono scrivere esplicitamente in due modi: `Dictionary<Key, Value>` oppure la sintassi abbreviata `[Key: Value]`.

Per creare un dizionario vuoto, specifica esplicitamente i tipi delle chiavi e dei valori:

```swift
var emptyDict1: [Int: Int] = [:]
var emptyDict2 = [Character: String]()
var emptyDict3 = Dictionary<Int, Double>()
```

## Accesso ai valori

Puoi accedere ai valori usando la notazione subscript: metti la chiave tra parentesi quadre dopo il nome del dizionario.
Poiché una chiave potrebbe non esistere nel dizionario, l'accesso tramite subscript restituisce un *optional* (`Value?`).
Se la chiave è presente, Swift restituisce il valore incapsulato; in caso contrario, restituisce `nil`:

```swift
let munster: String? = addresses["The Munsters"]
// Returns Optional("1313 Mockingbird Lane")

let carmichael = sequences["Carmichael"]
// Returns Optional([561, 1105, 1729, 2465, 2821, 6601, 8911, 10585, 15841])

let planck = constants["planck"]
// Returns nil
```

Per evitare di lavorare con gli optional, puoi fornire un valore predefinito usando il parametro `default`:

```swift
let e: Double = constants["e", default: 0]
// Returns 2.71828

let hoagie: [Int] = sequences["Hoagie", default: []]
// Returns []

let betty = addresses["Betty Cooper", default: "Address unknown"]
// Returns "Address unknown"
```

## Modificare i dizionari

Per i dizionari mutabili dichiarati con `var`, puoi aggiungere o aggiornare coppie chiave-valore tramite assegnazione con subscript:

```swift
sequences["Euler's totient"]?.append(contentsOf: [6, 4])
// sequences["Euler's totient"] is now [1, 1, 2, 2, 4, 2, 6, 4, 6, 4]

addresses["Betty Cooper"] = "111 Queens Ave."
addresses["Betty Cooper", default: "Address unknown"]
// Returns "111 Queens Ave."

constants["Gelfond's"] = 23.140692
// Compiler error: Cannot assign through subscript: 'constants' is a 'let' constant
```

## Iterare su un dizionario

Puoi iterare su ogni coppia chiave-valore di un dizionario usando un ciclo `for-in`.
Ogni elemento viene fornito come una tupla `(key, value)`:

```swift
for (name, address) in addresses {
    print("\(name) lives at \(address)")
}
```

## Ordinare i dizionari

Poiché i dizionari non sono ordinati, ordinarli produce un array di coppie chiave-valore.
Puoi passare una closure al metodo `sorted(by:)` che confronta due tuple `(key, value)` e restituisce `true` se la prima tupla deve comparire prima della seconda:

```swift
func sortByNameLengthThenValue(_ lhs: (key: String, value: Double), _ rhs: (key: String, value: Double)) -> Bool {
    let left = lhs.value + Double(lhs.key.count)
    let right = rhs.value + Double(rhs.key.count)
    return left < right
}

let sortedConstants = constants.sorted(by: sortByNameLengthThenValue)
```
