# Istruzioni

Come aspirante maga, Elyse deve esercitarsi con le basi. Ha un mazzo di carte che vuole manipolare.

Per rendere le cose un po' più semplici, usa solo le carte da 1 a 10, così il suo mazzo di carte può essere rappresentato da un vettore di numeri. La posizione di una certa carta corrisponde all'indice nel vettore.

## 1. Recupera una carta da un mazzo

Per pescare una carta, restituisci la carta all'indice `position` dal mazzo dato.

```R
stack <- c(1, 2, 4, 1)
position <- 3
get_item(stack, position)
# => 4
```

## 2. Scambia una carta nel mazzo

Con un po' di destrezza, scambia la carta all'indice `position` con la carta sostitutiva fornita.
Restituisci il mazzo modificato.

```R
stack <- c(1, 2, 4, 1)
position <- 3
replacement_card <- 6
set_item(stack, position, replacement_card)
# => c(1, 2, 6, 1)
```

## 3. Inserisci una carta in cima al mazzo

Fai apparire una carta inserendo una nuova carta in cima al mazzo.
Restituisci il mazzo modificato.

```R
stack <- c(5, 9, 7, 1)
new_card <- 8
insert_item_at_top(stack, new_card)
# => c(5, 9, 7, 1, 8)
```

## 4. Rimuovi una carta dal mazzo

Fai sparire una carta rimuovendo la carta alla `position` data dal mazzo.
Restituisci il mazzo modificato.

```R
stack <- c(3, 2, 6, 4, 8)
position <- 3
remove_item(stack, position)
# => c(3, 2, 4, 8)
```

## 5. Controlla la dimensione del mazzo

Controlla se la dimensione del mazzo è uguale a `stack_size` oppure no.

```R
stack <- c(3, 2, 6, 4, 8)
stack_size <- 4
check_size_of_stack(stack, stack_size)
# => FALSE
```

## 6. Rimuovi la carta in cima al mazzo

Fai sparire una carta rimuovendo la carta in cima al mazzo.
Restituisci il mazzo modificato.

```R
stack <- c(3, 2, 6, 4, 8)
remove_item_from_top(stack)
# => c(3, 2, 6, 4)
```

## 7. Inserisci una carta in fondo al mazzo

Fai apparire una carta inserendo una nuova carta in fondo al mazzo.
Restituisci il mazzo modificato.

```R
stack <- c(5, 9, 7, 1)
new_card <- 8
insert_item_at_bottom(stack, new_card)
# => c(8, 5, 9, 7, 1)
```

## 8. Rimuovi una carta dal fondo del mazzo

Fai sparire una carta rimuovendo la carta in fondo al mazzo.
Restituisci il mazzo modificato.

```R
stack <- c(8, 5, 9, 7, 1)
remove_item_at_bottom(stack)
# => c(5, 9, 7, 1)
```
