# Introduzione

JavaScript è un linguaggio dinamico, che supporta gli stili orientato agli oggetti, imperativo e dichiarativo (ad esempio la programmazione funzionale).

## Variabili

In JavaScript ci sono alcuni modi principali per assegnare dei valori a dei nomi: usando variabili o costanti.
Su Exercism, le variabili si scrivono sempre in [camelCase][wiki-camel-case]; le costanti si scrivono in [SCREAMING_SNAKE_CASE][wiki-snake-case].
Non esiste una guida ufficiale da seguire, e aziende e organizzazioni diverse hanno guide di stile diverse.
_Sentiti libero di scrivere le variabili come preferisci_.
Il vantaggio di scriverle nel modo in cui sono preparati gli esercizi è che verranno evidenziate in modo diverso nell'interfaccia web e nella maggior parte degli IDE.

In JavaScript, le variabili si possono definire usando la parola chiave [`const`][mdn-const], [`let`][mdn-let] o [`var`][mdn-var].

Una variabile può fare riferimento a valori diversi nel corso della sua esistenza quando si usa `let` o `var`.
Ad esempio, `myFirstVariable` si può definire e ridefinire più volte usando l'operatore di assegnazione `=`:

```javascript
let myFirstVariable = 1;
myFirstVariable = 'Some string';
myFirstVariable = new SomeComplexClass();
```

A differenza di `let` e `var`, le variabili definite con `const` si possono assegnare una sola volta.
Questo si usa per definire le costanti in JavaScript.

```javascript
const MY_FIRST_CONSTANT = 10;

// Can not be re-assigned.
MY_FIRST_CONSTANT = 20;
// => TypeError: Assignment to constant variable.
```

## Dichiarazioni di funzioni

In JavaScript, le unità di funzionalità sono incapsulate nelle _funzioni_; di solito, le funzioni che stanno insieme vengono raggruppate nello stesso file.
Queste funzioni hanno dei parametri (così possono ricevere degli argomenti) e possono _restituire_ un valore usando la parola chiave `return`.
Le funzioni si chiamano usando la sintassi `()`.

```javascript
function add(num1, num2) {
  return num1 + num2;
}

add(1, 3);
// => 4
```

In questo esempio, il nome della funzione è `add`.
Ha due parametri, `num1` e `num2`.
Restituisce un valore: il risultato dell'espressione `num1 + num2`

Poi la funzione `add` viene _chiamata_ con due argomenti: `1` e `3`.
Il risultato della funzione, il valore restituito, è `4`.

```exercism/note
💡 In JavaScript ci sono _molti_ modi diversi per dichiarare una funzione.
Alcuni di questi altri modi sono diversi dall'usare la parola chiave `function`.
Il track cerca di introdurli gradualmente, ma se li conosci già, sentiti libero di usarne uno qualsiasi.
Nella maggior parte dei casi, usare l'uno o l'altro non è meglio né peggio.
```

## Esporre ad altri file

Per rendere una `function`, una costante o una variabile disponibile in _altri file_, queste devono essere [esportate][mdn-export] usando la parola chiave `export`.
Un altro file può quindi [importarle][mdn-import] usando la parola chiave `import`.
Questo è anche noto come sistema di moduli.

Un ottimo esempio è come funzionano tutti i test.
Ogni esercizio ha almeno un file, ad esempio `lasagna.js`, che contiene l'_implementazione_.
L'_implementazione_ viene esportata dal file, rendendola disponibile per l'importazione in un altro file.
Inoltre c'è almeno un altro file, ad esempio `lasagna.spec.js`, che contiene i _test_.
Questo file `import`a le entità pubbliche (cioè quelle `export`ate) per poter testare l'implementazione:

```javascript
// file.js
export const MY_VALUE = 10;

export function add(num1, num2) {
  return num1 + num2;
}

// file.spec.js
import { MY_VALUE, add } from './file';

add(MY_VALUE, 5);
// => 15
```
