# Istruzioni specifiche per SQLite

* La colonna **candidates** contiene una lista di stringhe codificata in JSON.
  Esempio:
  ```json
  ["stone","tones","banana","tons","notes","Seton"]
  ```
* Anche la colonna **result** deve contenere una lista di stringhe codificata in JSON.

## Schema della tabella

```sql
CREATE TABLE anagram (
  subject    TEXT NOT NULL,
  candidates TEXT NOT NULL,     -- json array of strings
  result     TEXT               -- json array of strings
);
```
