# Concetti di Luhn

Luhn è un algoritmo di validazione che combina affermazioni testuali e numeriche. Le soluzioni in Rust prediligono approcci funzionali.

## Generale

### Tipi primitivi

- `&str` e `char`
  - gli studenti devono cogliere la differenza tra un singolo `char` e una `&str` per escludere o includere correttamente parti dell'input fornito
- numeri interi
  - capire i numeri interi è importante per eseguire la validazione numerica richiesta
- booleani
  - fondamentali per le affermazioni di identità e per i confronti finali

### Funzionalità degli iteratori

- concatenamento
  - qui è importante capire le catene di iteratori per risolvere il problema in modo ordinato.
- `map`, `filter`, turbofish ed eventualmente `fold`
  - combinare map e filter fornisce un modello di progettazione fondamentale per problemi di validazione come questo. Le soluzioni con `fold` vantano anche maggiore brevità.
  - in alcune soluzioni il turbofish serve a dire a Rust quale tipo si sta creando da un'espressione concatenata

## Soluzione di esempio 1

la [soluzione](https://exercism.org/tracks/rust/exercises/luhn/solutions/7038c269a4af4f5b95ca35a99c5c3b4d) di york

```rust
pub fn is_valid(code: &str) -> bool {
    code.chars()
        .filter(|c| !c.is_ascii_whitespace())
        .rev()
        .try_fold((0, 0), |(num_count, sum), c| {
            c.to_digit(10).map(|x| {
                let double = x * (num_count % 2 + 1);
                let double = if double > 9 { double - 9 } else { double };
                (num_count + 1, sum + double)
            })
        })
        .map_or(false, |(num_count, sum)| num_count >= 2 && sum % 10 == 0)
}
```

## Soluzione di esempio 2

Canonica

```rust
pub fn is_valid(candidate: &str) -> bool {
    if candidate.chars().filter(|c| c.is_ascii_digit()).take(2).count() <= 1
        || candidate.chars().any(|c| !c.is_ascii_digit() && c != ' ')
    {
        return false;
    }

    candidate
        .chars()
        .filter_map(|c| c.to_digit(10))
        .rev()
        .enumerate()
        .map(|(index, digit)| if index % 2 == 0 { digit } else { digit * 2 })
        .map(|digit| if digit > 9 { digit - 9 } else { digit })
        .sum::<u32>()
        % 10
        == 0
}
```
