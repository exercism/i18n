# Informazioni

## Funzioni

In Gleam le funzioni si definiscono usando la sintassi `pub fn`.

```gleam
pub fn add(x: Int, y: Int) -> Int {
  x + y
}
```

Questa funzione prende due argomenti, entrambi di tipo `Int`, e restituisce un valore di tipo `Int`. In Gleam non esiste la parola chiave `return`: il valore dell'ultima espressione in una funzione viene sempre _restituito implicitamente_.

Le annotazioni di tipo per gli argomenti e per il tipo restituito sono opzionali, e Gleam eseguirà sempre un controllo completo dei tipi sul codice. Di solito i programmatori Gleam aggiungono annotazioni di tipo alle proprie funzioni per chiarezza, ma puoi ometterle se preferisci.

```gleam
pub fn add(x, y) {
  x + y
}
```

Una funzione si può chiamare usando la sintassi `function_name(argument1, argument2)`.

```gleam
pub fn double(x: Int) -> Int {
  // Call the add function defined above
  add(x, x)
}
```

## Variabili

In Gleam le variabili si definiscono usando la sintassi `let name = expression`.

```gleam
pub fn main() {
  let count = 1
}
```

Le variabili possono essere dichiarate con annotazioni di tipo. Come per gli argomenti di una funzione, queste sono opzionali, anche se la maggior parte dei programmatori Gleam omette le annotazioni di tipo per le variabili.

```gleam
pub fn main() {
  let count: Int = 1
}
```

## Stringhe letterali

In Gleam le stringhe si scrivono usando le virgolette doppie.

```gleam
pub fn greeting() {
  "Hello, world!"
}
```

## Commenti nel codice

I commenti possono essere usati per lasciare note ad altri sviluppatori che leggono il codice sorgente. In Gleam i commenti sono singole righe precedute da `//`.

```gleam
pub fn main() {
  // This is a comment
  let x = 1
}
```
