# Informazioni

Un ciclo `do-while` è un'alternativa a un ciclo `while`, con l'unica differenza che un `do-while` viene eseguito almeno una volta:

```haxe
var i = 0;

do {
  trace("Hello");
} while (i < 10);
```

I casi in cui serve un ciclo `do-while` sono molto rari, perciò al suo posto si usa il normale `while`.
