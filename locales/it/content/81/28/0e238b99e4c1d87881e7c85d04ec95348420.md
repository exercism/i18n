# Informazioni

In Rust, i metodi sono funzioni definite per una struct (o un `enum` o un oggetto `trait`).
Questo cambia il modo in cui vengono chiamati: invece di `frobnicate(foo)`, un metodo si chiama con `foo.frobnicate()`.

I metodi sono simili alle funzioni: si dichiarano con la parola chiave `fn`, hanno un nome e possono avere parametri e valori restituiti.

A differenza delle funzioni, il primo parametro di un metodo è sempre `self` (o una sua variante), che rappresenta l'istanza della struct su cui il metodo viene chiamato (maggiori dettagli più avanti).

Creiamo un `enum` per le case di Hogwarts e una `struct` che descrive i campi `age` e `house` di un mago:

```rust
#[derive(Debug)]
enum House {
    Gryffindor,
    Hufflepuff,
    Ravenclaw,
    Slytherin,
}

struct Wizard {
    age: u32,
    house: House,
}
```

## Definire i metodi

Per definire i metodi per la struct `Wizard`, iniziamo un blocco `impl` (abbreviazione di implementazione) per `Wizard`.

```rust
impl Wizard { }
```

Tutto ciò che si trova all'interno di questo blocco `impl` sarà associato al tipo `Wizard`.
Nota che a una struct è consentito avere più blocchi `impl`.

### Usare `self`

Un metodo deve avere come primo parametro un parametro chiamato `self` di tipo `Self`.
Il tipo `Self` è un alias per il tipo a cui si riferisce il blocco `impl`.
Nel nostro esempio, `Self` rappresenta `Wizard`.

Per comodità, Rust ci permette di abbreviare tutto questo usando solo il nome `self` al posto del primo parametro.
I tipi comuni di `self` per i metodi includono:

- `self`: abbrevia `self: Self`. La firma `self` da sola consuma l'istanza.
- `&self`: abbrevia `self: &Self`. Prende in prestito l'istanza in modo immutabile.
- `&mut self`: abbrevia `self: &mut Self`. Prende in prestito l'istanza in modo mutabile.

In codice più avanzato potresti anche vedere firme come `self: Pin<&self>`, `self: Rc<Self>`, ecc.
Questo, però, esula dallo scopo di questo tutorial.

### Definire un metodo con `&self`

Se vogliamo implementare un metodo `info` per mostrare le informazioni di base del mago,
potremmo definire questo metodo dentro un blocco `impl` per `Wizard`:

```rust
impl Wizard {
    fn info(&self) {
        println!(
            "A wizard of age {} who studies in House {:?} at Hogwarts",
            self.age,
            self.house,
        );
    }
}
```

Nota che nella firma di `info`, prendiamo in prestito l'istanza in modo immutabile con `&self`.
Così possiamo leggere i campi `age` e `house` di un'istanza di `Wizard` senza modificarli.
Se avessimo usato un `self` che consuma l'istanza invece di prenderla in prestito, l'istanza non sarebbe più accessibile dopo la chiamata al metodo.

Con il metodo `info` implementato, potremmo stampare le informazioni di base di un mago:

```rust
let harry = Wizard { age: 11, house: House::Gryffindor };
harry.info();
// => A wizard of age 11 who studies in House Gryffindor at Hogwarts
```

### Definire un metodo con `&mut self`

Se vogliamo implementare un metodo che modifica i campi di un'istanza di una struct,
prendiamo in prestito l'istanza in modo mutabile con `&mut self` nella firma del metodo.

Diciamo che vogliamo stabilire una nuova regola a Hogwarts per permettere agli studenti di cambiare casa.
Potremmo implementare un metodo `switch_house` come segue:

```rust
impl Wizard {
    fn switch_house(&mut self, new_house: House) {
        self.house = new_house;
    }
}
```

Ora possiamo cambiare casa a un mago che studia a Hogwarts:

```rust
// Note that the variable must be mutable
let mut cedric = Wizard {age: 14, house: House::Hufflepuff};
cedric.info();
// => A wizard of age 14 who studies in House Hufflepuff at Hogwarts
cedric.switch_house(House::Slytherin);
cedric.info()
// => A wizard of age 14 who studies in House Slytherin at Hogwarts
```

## Più blocchi «impl»

In Rust, ogni elemento può avere più blocchi `impl`.
Quindi possiamo raggruppare tutti i metodi nello stesso blocco `impl` oppure avere più blocchi `impl` per gruppi diversi di metodi.
Entrambi gli approcci sono sintatticamente validi, ma l'organizzazione tipica di un progetto usa un singolo blocco `impl` per ogni insieme univoco di vincoli `where` a livello di `impl`.

## Funzioni associate

È possibile definire funzioni all'interno di un blocco `impl` che non contengono un parametro `self`.
Poiché mancano del parametro `self`, non sono metodi.
Tuttavia, sono comunque associate al tipo implementato e si chiamano nominando quel tipo.
Per questo motivo vengono chiamate funzioni associate (o funzioni associate al tipo).

Hai già visto alcune funzioni associate, come `String::from()`:

```rust
let some_string = String::from("This is an associated function but not a method");
```

I costruttori sono spesso implementati come funzioni associate.
Creiamo una funzione `new` associata al tipo `Wizard`:

```rust
impl Wizard {
    fn new(age: u32, house: House) -> Self {
        Self {
            age,
            house,
        }
    }
}
```

Nota che possiamo usare `Self` al posto di `Wizard` per indicare il tipo che sarà restituito dalla funzione.
Non è obbligatorio usare l'alias di tipo `Self` in questo modo, ma può semplificare l'implementazione per tipi con nomi complicati o prolissi.
Ora possiamo eseguire quanto segue:

```rust
let myrtle = Wizard::new(14, House::Ravenclaw);

myrtle.info();
// => A wizard of age 14 who studies in House Ravenclaw at Hogwarts
```
