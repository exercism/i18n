# Uso di strings.TrimSpace per rimuovere gli spazi

Non c'è bisogno di ripulire il codice, per esempio usando `strings.TrimSpace`.

Per tutti gli esercizi di Exercism puoi presumere che il codice faccia parte di una libreria interna. Ai margini dell'applicazione c'è codice che si occupa di ripulire l'input nel punto in cui entra nel sistema.
