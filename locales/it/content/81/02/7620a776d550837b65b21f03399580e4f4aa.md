# Istruzioni

Sei un appassionato osservatore di uccelli che tiene traccia di quanti uccelli hanno visitato il tuo giardino negli ultimi sette giorni.

Hai sei compiti, tutti legati al numero di uccelli che hanno visitato il tuo giardino.

## 1. Controlla quali erano i conteggi della settimana scorsa

Per fare confronti, tieni sempre a portata di mano una copia dei conteggi della settimana scorsa, che erano: 0, 2, 5, 3, 7, 8 e 4. Implementa il metodo (_static_) `BirdCount.LastWeek()` che restituisce i conteggi della settimana scorsa:

```csharp
BirdCount.LastWeek();
// => [0, 2, 5, 3, 7, 8, 4]
```

## 2. Controlla quanti uccelli hanno fatto visita oggi

Implementa il metodo `BirdCount.Today()` in modo che restituisca quanti uccelli hanno visitato il tuo giardino oggi. I conteggi degli uccelli sono ordinati per giorno: il primo elemento è il conteggio del giorno più lontano, l'ultimo è il conteggio di oggi.

```csharp
int[] birdsPerDay = { 2, 5, 0, 7, 4, 1 };
var birdCount = new BirdCount(birdsPerDay);
birdCount.Today();
// => 1
```

## 3. Incrementa il conteggio di oggi

Implementa il metodo `BirdCount.IncrementTodaysCount()` che incrementa il conteggio di oggi:

```csharp
int[] birdsPerDay = { 2, 5, 0, 7, 4, 1 };
var birdCount = new BirdCount(birdsPerDay);
birdCount.IncrementTodaysCount();
birdCount.Today();
// => 2
```

## 4. Controlla se c'è stato un giorno senza uccelli in visita

Implementa il metodo `BirdCount.HasDayWithoutBirds()` che restituisce `true` se c'è stato un giorno in cui zero uccelli hanno visitato il giardino; altrimenti restituisce `false`:

```csharp
int[] birdsPerDay = { 2, 5, 0, 7, 4, 1 };
var birdCount = new BirdCount(birdsPerDay);
birdCount.HasDayWithoutBirds();
// => true
```

## 5. Calcola il numero di uccelli in visita per i primi giorni indicati

Implementa il metodo `BirdCount.CountForFirstDays()` che restituisce il numero di uccelli che hanno visitato il tuo giardino dall'inizio della settimana, ma limita il conteggio al numero di giorni specificato a partire dall'inizio della settimana.

```csharp
int[] birdsPerDay = { 2, 5, 0, 7, 4, 1 };
var birdCount = new BirdCount(birdsPerDay);
birdCount.CountForFirstDays(4);
// => 14
```

## 6. Calcola il numero di giorni intensi

Alcuni giorni sono più intensi di altri. Un giorno intenso è un giorno in cui cinque o più uccelli hanno visitato il tuo giardino.
Implementa il metodo `BirdCount.BusyDays()` che restituisce il numero di giorni intensi:

```csharp
int[] birdsPerDay = { 2, 5, 0, 7, 4, 1 };
var birdCount = new BirdCount(birdsPerDay);
birdCount.BusyDays();
// => 2
```
