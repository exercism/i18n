# Appendice alle istruzioni

## Registri

| Registro | Utilizzo     | Tipo    | Descrizione                    |
| -------- | ------------ | ------- | ------------------------------ |
| `$a0`    | input        | intero  | numero di righe del triangolo  |
| `$a1`    | input/output | indirizzo | array di word                |
| `$v0`    | output       | intero  | numero di word di output       |
| `$t0-9`  | temporaneo   | qualsiasi | per l'archiviazione temporanea |
