# Istruzioni

Il tuo compito è capire se una frase è un pangramma.

Un pangramma è una frase che usa ogni lettera dell'alfabeto almeno una volta.
Non fa distinzione tra maiuscole e minuscole, quindi non importa se una lettera è minuscola (ad esempio `k`) o maiuscola (ad esempio `K`).

Per questo esercizio, una frase è un pangramma se contiene tutte e 26 le lettere dell'alfabeto inglese.
