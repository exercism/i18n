# Suggerimenti

## Generale

- [Errori irreversibili][unrecoverable]: invoca un panic con un messaggio di errore.
- [La macro `panic!`][panic-excl-macro]: invoca un panic con un messaggio di errore di tipo `ByteArray`.
- [La macro `assert!`][assert]: invoca un panic se una condizione è `false`.
- [L'enum Result][result]: come usare l'enum `Result`.

## 2. Gestire le operazioni illegali

- Qui devi [restituire un errore][result].

## 3. Gestire il caso in cui non viene fornita alcuna operazione

- Qui devi [invocare un panic][panic-excl-macro] con un messaggio di tipo `ByteArray` per gestire le stringhe vuote delle operazioni.

## 4. Gestire gli errori nella divisione per zero

- Qui devi invocare un panic per gestire la divisione per zero.
