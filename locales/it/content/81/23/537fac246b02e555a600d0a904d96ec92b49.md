# Informazioni

Dato che tutti i tipi di dati standard di Clojure sono immutabili, il linguaggio offre *tipi di riferimento* che consentono una mutazione controllata. I più semplici e più comunemente usati tra questi sono chiamati atomi.

Gli atomi si creano con la funzione `atom`, che accetta un valore iniziale:

```clojure
(def players (atom ()))
```

Il valore attuale dell'atomo si ottiene con `deref` o con la notazione abbreviata `@`:

```clojure
@players
;;=> ()
```

Il valore attuale dell'atomo `players` può essere modificato usando `swap!`, che aggiorna il valore applicando una funzione:

```clojure
(swap! players conj :player1)
;;=> (:player1)
```

La funzione `reset!` sostituisce il valore di un atomo indipendentemente dal suo valore attuale:

```clojure
(reset! players ())
```
