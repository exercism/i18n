# import ANSI with :except

Le istruzioni menzionano che «stai pensando di aggiungere il supporto per altri colori delle auto, quindi vuoi importare l'intero modulo», tranne la funzione `color` che è in conflitto. Per farlo, usa l'opzione `:except` così:

```elixir
import IO.ANSI, except: [color: 1]
```
