# Introduzione

## Tipi opachi

I tipi opachi in Gleam sono tipi personalizzati in cui solo il modulo che definisce il tipo può costruire o eseguire il pattern matching sui valori di quel tipo. Sono utili per creare tipi che dovrebbero essere usati solo in un modo specifico.

I tipi opachi si definiscono usando la parola chiave `opaque`.

```gleam
pub opaque type PositiveInt {
  PositiveInt(inner: Int)
}
```

Questo tipo `PositiveInt` è pensato per le situazioni in cui serve un intero, ma che sia zero o maggiore. Un normale `Int` di Gleam non potrebbe essere usato, perché può anche essere negativo.

Il modulo che definisce questo tipo può definire una funzione per ottenere il valore intero interno ed una funzione per creare il tipo `PositiveInt`, che restituirà un errore se il valore non è positivo.

```gleam
pub fn from_int(i: Int) -> Result(PositiveInt, String) {
  case i {
    _ if i < 0 -> Error("Value must be positive")
    _ -> Ok(PositiveInt(i))
  }
}

pub fn to_int(i: PositiveInt) -> Int {
  i.inner
}
```

Con questa API gli altri moduli non possono costruire un `PositiveInt` con un valore negativo, quindi qualsiasi funzione che accetta un `PositiveInt` può essere certa che il valore sia positivo.
