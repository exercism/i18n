# Informazioni

## Uguaglianza

I tipi di Elm si possono verificare per «essere uguali» con l'[operatore di uguaglianza][equality-operator] `(==)`.
L'operatore di disuguaglianza è `(/=)` (*non* `!=` come in molti linguaggi).

```elm
1 == 2
    --> False

1 /= 2
    --> True
```

Entrambi i valori confrontati devono essere dello stesso tipo.
L'operatore di uguaglianza funziona su valori letterali, tuple, record e tipi personalizzati.
L'operatore verifica l'uguaglianza strutturale: valori uguali hanno contenuto e struttura profonda uguali, indipendentemente dall'annotazione di tipo o dalla posizione in memoria.

```elm
(1, 2) == (2, 1)
    --> False

type alias MyRecord = { myInt : Int, myStrings : List String }
a : MyRecord
a = MyRecord (1 + 1) ["hello world"]

type alias MyOtherRecord = { myInt : Int, myStrings : List String }
myStrings =  (String.join " " ["hello", "world"]) :: []
b : MyOtherRecord
b = { myInt = 2, myStrings = myStrings}

a == b
    --> True
```

Tieni presente che *non dovresti mai* confrontare le funzioni: il programma andrebbe in crash in fase di esecuzione.
Trovi maggiori informazioni su questo limite [qui][equality-operator].

## Confronti

Gli [operatori di confronto][comparison-operators] `(<)`, `(<=)`, `(>)`, `(>=)` e le funzioni `min`, `max`, `compare` funzionano sui tipi `comparable`.
Il tipo `comparable` è un tipo speciale che raggruppa tutti i tipi incorporati che si possono confrontare: numeri, caratteri, stringhe, array di elementi confrontabili e tuple di elementi confrontabili.
I caratteri vengono confrontati in base ai loro [code point Unicode][unicode-codepoint].

```elm
1 < 1 + 1
    --> True

'x' < 'X'
    --> False

'互' < '🙏'
    --> True
```

I tipi simili a sequenze (stringhe, array e tuple) vengono confrontati in [ordine lessicografico][lexicographic-order].
In breve, gli elementi di una sequenza vengono confrontati a coppie, in ordine, finché non si trova un elemento più piccolo o non termina una delle sequenze.

```elm
"abc" < "abz"
    --> True

"abc" < "abcd"
    --> True

"abc" < "b"
    --> True

min [1 , 2, 9000] [10]
    --> [1 , 2, 9000]

min (1, "hello") (3, "bye")
    --> (1, "hello")

min (1, ['a', 'b']) (1, ['A', 'B'])
    --> (1, ['A', 'B'])
```

I valori di altri tipi, come i record o i tipi personalizzati, non si possono confrontare direttamente.

Alcuni tipi incorporati richiedono che il loro contenuto sia `comparable`, come le chiavi di `Set` o `Dict`, perché la loro struttura si basa su un ordinamento interno.
Questo significa che i tipi personalizzati non si possono memorizzare in un `Set`, anche se esistono alternative della community: [`AnySet`][any-set], [`AnyDict`][any-dict], [`Sort`][sort] e altre.

Gli array di valori `comparable` si possono ordinare con `List.sort`, e gli array di valori che si possono mappare in valori confrontabili si possono ordinare con `List.sortBy`.
Se ti serve un ordinamento gerarchico (ordina per una proprietà, poi risolvi i pareggi con un'altra), puoi usare tuple o array con `List.sortBy` (tra le altre [alternative][sort-by]), dato che tuple e array vengono ordinati in ordine lessicografico.


```elm
List.sort ["hi", "hello", "bye", "goodbye"]
    --> ["bye", "goodbye", "hello", "hi"]

List.sortBy String.length ["hi", "hello", "bye", "goodbye"]
    --> ["hi", "bye", "hello", "goodbye"]

-- sort by length, then alphabetically
List.sortBy (\str -> (String.length str, str)) ["hi", "mum", "hello", "sis", "bye", "dad"]
    --> ["hi", "bye", "dad", "mum", "sis", "hello"]
```

La funzione `compare` prende due valori `comparable` e restituisce un `Order`.
Un `Order` è un tipo che verifica con una sola operazione se un valore è maggiore (`GT`), uguale (`EQ`) o minore (`LT`) di un altro.

```elm
compare 1 2
    --> LT

compare "" ""
    --> EQ

compare [12] []
    --> GT
```

Si possono costruire funzioni di confronto per tipi arbitrari e usarle, per esempio, per ordinare con `List.sortWith`:

```elm
type Color = Red | Green | Blue

compareColors : Color -> Color -> Order
compareColors a b =
  case (a, b) of
    (Red, Red) -> EQ
    (Red, _) -> LT
    (_, Red) -> GT
    (Green, Green) -> EQ
    (Green, _) -> LT
    (_, Green) -> GT
    (Blue, Blue) -> EQ

List.sortWith compareColors [Blue, Red, Green, Green, Blue]
    --> [Red, Green, Green, Blue, Blue]
```
