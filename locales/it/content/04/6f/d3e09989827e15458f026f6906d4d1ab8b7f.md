# Istruzioni

Converti un numero binario, rappresentato come stringa (ad esempio '101010'), nel suo equivalente decimale usando i principi di base.

Implementa la conversione da binario a decimale. Data una stringa di input binaria, il programma deve produrre un output decimale. Il programma deve gestire input non validi.

## Nota

- Implementa la conversione da solo.
  Non usare qualcos'altro per eseguire la conversione al posto tuo.

## Il sistema binario (base 2)

Il sistema decimale è un sistema in base 10.

Un numero come 23 in notazione in base 10 si può interpretare come una combinazione lineare delle potenze di 10:

- La cifra più a destra viene moltiplicata per 10^0 = 1
- La cifra successiva viene moltiplicata per 10^1 = 10
- ...
- La cifra *n*-esima viene moltiplicata per 10^*(n-1)*.
- Tutti questi valori vengono sommati.

Quindi: `23 => 2*10^1 + 3*10^0 => 2*10 + 3*1 = 23 base 10`

Il sistema binario è simile, ma usa le potenze di 2 invece delle potenze di 10.

Quindi: `101 => 1*2^2 + 0*2^1 + 1*2^0 => 1*4 + 0*2 + 1*1 => 4 + 1 => 5 base 10`.
