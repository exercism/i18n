# Generatori di test

Il track C# usa un [generatore di test](https://exercism.org/docs/building/tooling/test-generators) per generare automaticamente i test degli esercizi di pratica.
Sfrutta il fatto che la maggior parte degli esercizi definiti nel [repository problem-specifications](https://github.com/exercism/problem-specifications/) ha anche un file `canonical-data.json`, che contiene input e output di test standardizzati che si possono usare per implementare l'esercizio.

## Passaggi

Per generare i test di un esercizio di pratica, il generatore di test:

1. Legge i casi di test dell'esercizio dal suo file `canonical-data.json`
2. Usa il file `tests.toml` per omettere i casi di test esclusi
3. Renderizza i casi di test usando il template del generatore dell'esercizio
4. Formatta il template renderizzato usando Roslyn
5. Scrive il template formattato nel file di test dell'esercizio

### Passaggio 1: leggere il file `canonical-data.json`

Il generatore di test analizza i casi di test dal file `canonical-data.json` dell'esercizio usando il [namespace System.Text.Json](https://learn.microsoft.com/en-us/dotnet/api/system.text.json).

Dato che alcuni dati canonici usano l'annidamento, il caso di test analizzato include un campo `path` aggiuntivo che contiene le proprietà `description` di eventuali elementi padre, oltre alla proprietà `description` del caso di test stesso.

### Passaggio 2: omettere i test esclusi dal file `tests.toml`

Ogni esercizio ha un file `tests.toml`, in cui i singoli test possono essere esclusi o disabilitati.
Il generatore di test rimuove tutti i casi di test contrassegnati come esclusi (`include = false`).

### Passaggio 3: renderizzare i casi di test

I casi di test (potenzialmente trasformati) vengono poi passati al file `.meta/Generator.tpl`, che definisce come renderizzare i test in base a quei casi di test.

### Passaggio 4: formattare il template renderizzato usando Roslyn

Il template renderizzato viene poi formattato usando [Roslyn](https://github.com/dotnet/roslyn).
Questo offre i seguenti vantaggi:

- Gli esercizi sono formattati in modo coerente
- Non devi preoccuparti troppo degli spazi bianchi e dell'allineamento quando scrivi i template

### Passaggio 5: scrivere il template renderizzato nel file di test dell'esercizio

Infine, l'output del template renderizzato viene scritto nel file di test dell'esercizio.

## Template

I template vengono renderizzati usando la [libreria Scriban](https://github.com/scriban/scriban/).

## Interfaccia a riga di comando

Il generatore di test può essere eseguito in due modi:

1. `bin/update-tests.ps1`: aggiorna i test di tutti gli esercizi che hanno un template di generatore
2. `bin/update-tests.ps1 -e <slug>`: aggiorna i test dell'esercizio specificato, se ha un template di generatore
