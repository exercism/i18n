# Nessun argomento predefinito utilizzato

Nella definizione della funzione di questa soluzione non viene usato alcun [argomento predefinito][default argument].
Gli [argomenti predefiniti in Python][default arguments in python] possono aiutare a prevenire situazioni in cui una funzione viene chiamata senza un argomento previsto, o in cui non c'è alcun argomento disponibile da passare.

`Default arguments` può anche aiutare a evitare codice condizionale o controlli non necessari all'interno di una funzione.

Questa soluzione può essere migliorata facendo uso di un `default argument` in combinazione con [str.format][str.format] oppure con le [f-strings][f-strings] (_note anche come «formatted string literals» o «stringhe interpolate»_).

[String Formatting in Python][string formatting in python] di Real Python può essere un buon punto di partenza per conoscere le opzioni di formattazione delle stringhe di Python.
