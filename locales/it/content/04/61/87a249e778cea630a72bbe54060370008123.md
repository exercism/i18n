# Istruzione switch

L'istruzione `switch` permette di realizzare una struttura di controllo condizionale `if..elseif..else`.

```php
function getMessage(string $letter): string
{
  switch ($letter) {
    case 'a':
      $message = 'First letter of the english alphabet';
      break;
    case 'z':
      $message = 'Last letter of the english alphabet';
      break;
    case 'l':
    default:
      $message = 'A letter, neither the first nor the last of the alphabet';
  }
  return $message;
}

// getMessage('a') => 'First letter of the english alphabet'
// getMessage('z') => 'Last letter of the english alphabet'
// getMessage('l') => 'A letter, neither the first nor the last of the alphabet'
// getMessage('k') => 'A letter, neither the first nor the last of the alphabet'
```

Una caratteristica peculiare delle istruzioni `switch` è il comportamento «fall-through» di ogni `case`.
Nota nell'esempio la posizione specifica delle istruzioni `break`.
Senza un'istruzione `break`, ogni `case` viene eseguito dall'inizio del primo `case` finché non viene valutata un'istruzione `break`.
L'ordine delle istruzioni `case` all'interno di uno `switch` è importante, perché viene valutato solo fino al primo case corrispondente.

> Un avviso: il comportamento «fall-through» facilita la condivisione di codice tra casi simili, ma può anche essere fonte di comportamenti indesiderati e di bug se ci si dimentica dell'istruzione `break`.

Ogni `case` esegue un confronto non stretto (loose):

```php
function matches($value): string
{
  switch ($value) {
    case false:
      return 'matches false';
    case true:
      return 'matches true';
  }
}

// matches([]) => 'matches false'
// matches(0) => 'matches false'
// matches(null) => 'matches false'
// matches('') => 'matches false'

// matches([1]) => 'matches true'
// matches(1) => 'matches true'
// matches('a') => 'matches true'
```

## Il pattern switch senza break

Supponiamo che la funzione di esempio precedente venga riscritta:

```php
function getMessage(string $letter): string
{
  switch ($letter) {
    case 'a':
      return 'First letter of the english alphabet';
    case 'z':
      return 'Last letter of the english alphabet';
    case 'l':
    default:
      return 'A letter, neither the first nor the last of the alphabet';
  }
}

// getMessage('a') => 'First letter of the english alphabet'
// getMessage('z') => 'Last letter of the english alphabet'
// getMessage('l') => 'A letter, neither the first nor the last of the alphabet'
// getMessage('k') => 'A letter, neither the first nor the last of the alphabet'
```

Il comportamento della funzione resta lo stesso, ma restituire direttamente dall'istruzione switch evita la possibile dimenticanza dell'istruzione `break`.

## Il pattern switch con espressioni condizionali

Un altro modo di usare l'istruzione switch è confrontare ogni case tramite un'espressione:

```php
function compareSum(int $sum): string
{
  switch (true) {
    case $sum < 10:
      return 'Less than 10';
    case $sum > 10:
      return 'More than 10';
    default:
      return 'Sum is 10';
  }
}
```

Questo offre una certa flessibilità per scrivere espressioni più varie e comporre funzioni nel valutare quale ramo `case` eseguire.
