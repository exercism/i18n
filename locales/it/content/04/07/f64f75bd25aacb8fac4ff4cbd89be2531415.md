# Ignorami

## Input

Lo script riceverà il puzzle alfametico come un'unica stringa tramite lo standard input (stdin). La stringa del puzzle segue il formato `WORD1 + WORD2 + ... == RESULT`.

Per esempio:

```text
SEND + MORE == MONEY
```

## Output

Se il puzzle ha una soluzione, stampa una sola riga composta da coppie `LETTER=DIGIT` separate da spazi, ordinate alfabeticamente per lettera.

Per l'esempio qui sopra, l'output dovrebbe essere:

```text
D=7 E=5 M=1 N=6 O=0 R=8 S=9 Y=2
```

Se il puzzle ha più soluzioni valide, va bene stamparne una qualsiasi.

Se il puzzle non ha soluzione, non stampare nulla (una riga vuota).
