# Istruzioni

In questo esercizio implementerai un modo per tenere traccia dei punteggi più alti del gioco più popolare della tua sala giochi.

## 1. Definisci una nuova mappa dei punteggi più alti

Per creare una nuova mappa dei punteggi più alti, definisci la funzione `HighScore.new/0`, che non accetta argomenti e restituisce una nuova mappa vuota dei punteggi.

```elixir
HighScore.new()
# => %{}
```

## 2. Aggiungi giocatori alla mappa dei punteggi

Per aggiungere un giocatore alla mappa dei punteggi, definisci `HighScore.add_player/3`, una funzione che accetta 3 argomenti:

- Il primo argomento è la mappa dei punteggi.
- Il secondo argomento è il nome di un giocatore, come stringa.
- Il terzo argomento è il punteggio, come numero intero. L'argomento è opzionale: implementa il terzo argomento con un valore predefinito di 0.

Memorizza il punteggio iniziale predefinito in un attributo del modulo. Servirà di nuovo.

```elixir
score_map = HighScore.new()
# => %{}
score_map = HighScore.add_player(score_map, "Dave Thomas")
# => %{"Dave Thomas" => 0}
score_map = HighScore.add_player(score_map, "José Valim", 486_373)
# => %{"Dave Thomas" => 0, "José Valim"=> 486_373}
```

## 3. Rimuovi giocatori dalla mappa dei punteggi

Per rimuovere un giocatore dalla mappa dei punteggi, definisci `HighScore.remove_player/2`, che accetta 2 argomenti:

- Il primo argomento è la mappa dei punteggi.
- Il secondo argomento è il nome del giocatore, come stringa.

```elixir
score_map = HighScore.new()
# => %{}
score_map = HighScore.add_player(score_map, "Dave Thomas")
# => %{"Dave Thomas" => 0}
score_map = HighScore.remove_player(score_map, "Dave Thomas")
# => %{}
```

## 4. Reimposta il punteggio di un giocatore

Per reimpostare il punteggio di un giocatore, definisci `HighScore.reset_score/2`, che accetta 2 argomenti:

- Il primo argomento è la mappa dei punteggi.
- Il secondo argomento è il nome del giocatore, come stringa, di cui vuoi reimpostare il punteggio.

La funzione deve funzionare anche se il giocatore non ha un punteggio.

```elixir
score_map = HighScore.new()
# => %{}
score_map = HighScore.add_player(score_map, "José Valim", 486_373)
# => %{"José Valim"=> 486_373}
score_map = HighScore.reset_score(score_map, "José Valim")
# => %{"José Valim"=> 0}
```

## 5. Aggiorna il punteggio di un giocatore

Per aggiornare il punteggio di un giocatore aggiungendo al punteggio precedente, definisci `HighScore.update_score/3`, che accetta 3 argomenti:

- Il primo argomento è la mappa dei punteggi.
- Il secondo argomento è il nome del giocatore, come stringa, di cui vuoi aggiornare il punteggio.
- Il terzo argomento è il punteggio che vuoi **aggiungere** al punteggio più alto memorizzato.

La funzione deve funzionare anche se il giocatore non ha un punteggio precedente: in quel caso, presupponi che il punteggio precedente sia 0.

```elixir
score_map = HighScore.new()
# => %{}
score_map = HighScore.add_player(score_map, "José Valim", 486_373)
# => %{"José Valim"=> 486_373}
score_map = HighScore.update_score(score_map, "José Valim", 5)
# => %{"José Valim"=> 486_378}
```

## 6. Ottieni una lista di giocatori

Per ottenere una lista di giocatori, definisci `HighScore.get_players/1`, che accetta 1 argomento:

- Il primo argomento è la mappa dei punteggi.

```elixir
score_map = HighScore.new()
# => %{}
score_map = HighScore.add_player(score_map, "Dave Thomas", 2_374)
# => %{"Dave Thomas" => 2_374}
score_map = HighScore.add_player(score_map, "José Valim", 486_373)
# => %{"Dave Thomas" => 2_374, "José Valim"=> 486_373}
HighScore.get_players(score_map)
# => ["Dave Thomas", "José Valim"]
```
