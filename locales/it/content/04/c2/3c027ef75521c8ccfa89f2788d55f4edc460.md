# Introduzione

## Operatori di confronto

R ha una serie di operatori uguali a quelli di molti altri linguaggi:

```R
1 == 2 # FALSE
1 != 2 # TRUE
1 < 2 # TRUE
1 > 2 # FALSE
1 <= 2 # TRUE
1 >= 2 # FALSE
```

## Ramificazione

La forma base di un if-else è:

```R
if (x > 10) {
    y <- "big"
} else if (x > 2) {
    y <- "medium"
} else {
    y <- "tiny"
}
```

In questo caso sono necessarie sia le parentesi tonde (`()`) attorno al valore booleano, sia le parentesi graffe (`{}`) attorno al corpo.

Una semplice istruzione `if` può essere abbreviata:

```R
if (x == 0) return("success")
```
