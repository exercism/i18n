# Numeri

`INT` contiene un numero intero. In questo Sather occupa esattamente 32 bit, quindi conta da -2147483648 a 2147483647.

```sather
   goals : INT is
      return 42;
   end;
```

## Argomenti

Una routine accetta argomenti tra parentesi, ognuno con un tipo:

```sather
   total(first : INT, second : INT) : INT is
      return first + second;
   end;
```

Gli argomenti che condividono un tipo possono condividere la dichiarazione, che è lo stile abituale:

```sather
   total(first, second : INT) : INT is
```

## Aritmetica

| Operatore | Significato |
| --- | --- |
| `+` | addizione |
| `-` | sottrazione e negazione |
| `*` | moltiplicazione |
| `/` | divisione, scartando il resto |
| `%` | il resto di quella divisione |

`/` tra due `INT` non produce mai una frazione:

```sather
7 / 2      -- 3
7 % 2      -- 1
```

Se vuoi una frazione ti serve `FLTD`, che vedremo più avanti.

La moltiplicazione e la divisione hanno la precedenza rispetto all'addizione e alla sottrazione, come nell'aritmetica ordinaria. Le parentesi raggruppano quando ti serve qualcosa di diverso:

```sather
2 + 3 * 4        -- 14
(2 + 3) * 4      -- 20
```

## Routine utili su INT

```sather
7.max(3)     -- 7
7.min(3)     -- 3
(-7).abs     -- 7
7.str        -- "7", the number written as text
```

`.str` è il modo in cui un numero diventa parte di una frase, una volta che hai conosciuto le stringhe.
