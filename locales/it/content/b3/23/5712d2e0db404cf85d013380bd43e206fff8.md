# Introduzione

## Uguaglianza

In Elm puoi verificare se due valori sono «uguali» con l'operatore di uguaglianza `(==)`.
L'operatore di disuguaglianza è `(/=)` (*non* `!=` come in molti altri linguaggi).
L'operatore di uguaglianza funziona con i valori letterali, le tuple, i record e i tipi personalizzati.

```elm
1 == 2
    --> False

1 /= 2
    --> True

(1, 2) == (2, 1)
    --> False

type alias MyRecord = { myInt : Int, myStrings : List String }
a : MyRecord
a = MyRecord (1 + 1) ["hello world"]

type alias MyOtherRecord = { myInt : Int, myStrings : List String }
myStrings =  (String.join " " ["hello", "world"]) :: []
b : MyOtherRecord
b = { myInt = 2, myStrings = myStrings}

a == b
    --> True
```

Tieni presente che *non dovresti mai* confrontare le funzioni: farà crashare il programma in fase di esecuzione.

## Confronti

Gli operatori di confronto `(<)`, `(<=)`, `(>)`, `(>=)` e le funzioni `min`, `max`, `compare` funzionano sui tipi `comparable`.
Il tipo `comparable` è un tipo speciale che raggruppa tutti i tipi predefiniti che possono essere confrontati: numeri, caratteri, stringhe, liste di elementi confrontabili e tuple di elementi confrontabili.

```elm
1 < 1 + 1
    --> True

'x' < 'X'
    --> False

"abc" < "abz"
    --> True

"abc" < "abcd"
    --> True

"abc" < "b"
    --> True

min [1 , 2, 9000] [10]
    --> [1 , 2, 9000]

min (1, "hello") (3, "bye")
    --> (1, "hello")
```

I valori di altri tipi, come i record o i tipi personalizzati, non possono essere confrontati direttamente.

Alcuni tipi predefiniti richiedono che il loro contenuto sia `comparable`, come le chiavi di `Set` o `Dict`, dato che la loro struttura si basa su un ordinamento interno.

Le liste di valori `comparable` possono essere ordinate con `List.sort`, e le liste di valori che possono essere mappati su valori confrontabili possono essere ordinate con `List.sortBy`.
Se ti serve un ordinamento gerarchico (ordina in base a una proprietà e risolvi i pareggi con un'altra), puoi usare anche tuple o liste con `List.sortBy`, dato che tuple e liste vengono ordinate in ordine lessicografico.


```elm
List.sort ["hi", "hello", "bye", "goodbye"]
    --> ["bye", "goodbye", "hello", "hi"]

List.sortBy String.length ["hi", "hello", "bye", "goodbye"]
    --> ["hi", "bye", "hello", "goodbye"]

-- sort by length, then alphabetically
List.sortBy (\str -> (String.length str, str)) ["hi", "mum", "hello", "sis", "bye", "dad"]
    --> ["hi", "bye", "dad", "mum", "sis", "hello"]
```

La funzione `compare` prende due valori `comparable` e restituisce un `Order`.
Un `Order` è un tipo che verifica in un'unica operazione se un valore è maggiore (`GT`), uguale (`EQ`) o minore (`LT`) di un altro.

```elm
compare 1 2
    --> LT

compare "" ""
    --> EQ

compare [12] []
    --> GT
```

Puoi costruire funzioni di confronto per tipi arbitrari e usarle, per esempio, per ordinarli con `List.sortWith`:

```elm
type Color = Red | Green | Blue

compareColors : Color -> Color -> Order
compareColors a b =
  case (a, b) of
    (Red, Red) -> EQ
    (Red, _) -> LT
    (_, Red) -> GT
    (Green, Green) -> EQ
    (Green, _) -> LT
    (_, Green) -> GT
    (Blue, Blue) -> EQ

List.sortWith compareColors [Blue, Red, Green, Green, Blue]
    --> [Red, Green, Green, Blue, Blue]
```
