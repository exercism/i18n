# Informazioni

Una **word** è il nome che Factor dà a una funzione. In `basics` hai incontrato lo stack di dati e le shuffle words; qui definisci le tue word che calcolano a partire dai loro input.

```factor
: square ( x -- x*x ) dup * ;
: hello  ( -- )       "Hello, world!" print ;
: max3   ( a b c -- max ) max max ;
```

Una definizione è composta da `:`, un effetto sullo stack, il corpo e infine `;`. I nomi dentro `( … -- … )` servono a chi legge; quello che il compilatore controlla è il *numero* di input e output. Una discrepanza è un errore in fase di compilazione: questo intercetta una classe di bug che, in un linguaggio a tipizzazione dinamica senza questo tipo di dichiarazione, sarebbero errori in fase di esecuzione.

Le word di aritmetica intera `+`, `-`, `*` provengono dal vocabolario `math` e ognuna consuma due numeri dalla cima dello stack. La cima dello stack è l'operando di destra, quindi `8 3 -` calcola `8 - 3`.

`CONSTANT:` definisce un nome per un valore fisso; chiamare quel nome impila il valore, esattamente come qualsiasi altra word. Metti le costanti all'inizio del file, prima di qualsiasi word che le usi.

Il corpo di una word può chiamare qualsiasi word già nello scope: definizioni precedenti nello stesso file, word provenienti dai vocabolari importati e le costanti che hai dichiarato. Comporre word piccole e con un unico scopo è il modo normale per costruire un programma.

Per convenzione:

- Le word e le costanti usano `lowercase-kebab-case`.
- I predicati terminano con `?` e producono un booleano (`even?`, `empty?`).
- Le word che modificano il loro input hanno spesso lo stesso nome della versione che non lo modifica, e si distinguono solo dal contesto.
