# Informazioni

Lo scope di un valore, cioè l'ambito di visibilità, riguarda il punto del programma in cui è possibile accedere a quel valore.

## I quattro tipi di scope: blocco, funzione, prototipo di funzione, file

### Scope di blocco

Un valore con scope di blocco è accessibile solo dall'interno del blocco in cui è definito.
Per saperne di più sui blocchi, vedi il [concetto di blocco](../blocks/introduction.md#Introduction).

### Scope di funzione

Lo scope di funzione è un tipo speciale di scope che si applica alle etichette usate con le istruzioni `goto`.
Due etichette con lo stesso nome non possono essere usate nella stessa funzione, anche se sono definite in blocchi separati all'interno della funzione.

### Scope del prototipo di funzione

Lo scope del prototipo di funzione è un altro tipo speciale di scope che si applica solo ai parametri indicati all'interno del prototipo (detto anche dichiarazione, tenendo presente che non tutte le dichiarazioni sono prototipi).
Il nome di un parametro è di solito facoltativo in una dichiarazione di funzione.
Lo scope di un nome è rilevante solo all'interno della dichiarazione.
Nell'esempio seguente, l'identificatore `len` viene definito e poi ripreso più avanti nella dichiarazione di funzione.

```c
#include <stdio.h>

// len is defined and then referred to
void my_func(int len, int numbers[len]);

int main() {
    int numbers[2];
    numbers[0] = 1;
    numbers[1] = 2;
    my_func(2, numbers);
}

void my_func(int length, int numbers[length]) {
    // prints numbers should have 2 elements
    printf("numbers should have %d elements", length);
}
```

Nota che all'interno di una dichiarazione i nomi devono coincidere quando si fa riferimento alla stessa variabile.
Se `my_func` fosse dichiarata come `void my_func(int len, int numbers[length]);`, verrebbe generato un errore di compilazione simile a

```
/tmp/scn62kKPEZ.c:4:35: error: 'length' undeclared here (not in a function)
    3 | void my_func(int len, int numbers[length]);
      |                                   ^~~~~~
/tmp/scn62kKPEZ.c: In function 'main':
/tmp/scn62kKPEZ.c:10:16: error: type of formal parameter 2 is incomplete
   10 |     my_func(2, numbers);
```

Una definizione di funzione non deve usare per un parametro lo stesso nome usato nella dichiarazione della funzione.
Nell'esempio precedente, nella dichiarazione è stato usato `len` e nella definizione `length`: questo dimostra che lo scope dell'identificatore `len` era limitato alla dichiarazione della funzione.

### Scope di file

Un valore con scope di file è accessibile da qualsiasi punto del file.
Un valore del genere è definito al di fuori di una funzione.
