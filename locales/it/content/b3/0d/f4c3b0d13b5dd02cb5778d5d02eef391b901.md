# Cicli while e until

Un ciclo è una struttura di controllo che permette di eseguire ripetutamente del codice in base a una determinata condizione.

## Cicli while

Un ciclo while è una struttura di controllo che permette di eseguire ripetutamente del codice in base a una determinata condizione.
Il codice all'interno di un ciclo while continua a essere eseguito finché la condizione è veritiera.
I cicli while sono spesso usati quando il numero di iterazioni non è noto in anticipo; possono essere usati in qualsiasi situazione in cui serve un ciclo.

La condizione viene valutata prima che il codice all'interno del ciclo venga eseguito, il che significa che se la condizione è falsa, il codice all'interno del ciclo non verrà mai eseguito.

```crystal
i = 0
while i < 3
  puts i
  i += 1
end

# Output:
# 0
# 1
# 2
```

Quando vuoi iterare su una stringa, puoi usare un ciclo sulla lunghezza della stringa.

```crystal
str = "Hello"
i = 0
while i < str.size
  puts str[i]
  i += 1
end

# Output:
# H
# e
# l
# l
# o
```

## Cicli until

I cicli until funzionano come i cicli while, con la differenza che il codice all'interno del ciclo continua a essere eseguito finché la condizione non è veritiera.
È come la differenza tra `if` e `unless`.

```crystal
i = 0
until i == 3
  puts i
  i += 1
end
```

### Cicli infiniti

Un errore comune con i cicli while è entrare in un «ciclo infinito», che non termina mai.
Un ciclo infinito può essere causato da una condizione che _non_ restituisce mai un valore veritiero o falso.
Spesso è dovuto a un errore del programmatore; per esempio, dimenticare di incrementare la variabile del ciclo.
A volte, però, un ciclo infinito è il modo più chiaro per implementare la logica del programma.
Oppure è essenziale avere un ciclo infinito; per esempio, un server HTTP attende una connessione in entrata, la gestisce e poi attende la connessione successiva.

## Break

La parola chiave `break` può essere usata per uscire anticipatamente da un ciclo.
Questo può essere comodo quando vuoi uscire da un ciclo in anticipo in determinate condizioni.

```crystal
i = 0
while i <= 3
  puts i
  i += 1
  if i == 2
    break
  end
end

# Output:
# 0
# 1
```

## Next

La parola chiave `next` può essere usata per saltare all'iterazione successiva di un ciclo.
Questo può essere comodo quando vuoi saltare iterazioni specifiche di un ciclo.

```crystal
i = 0
while i <= 3
  i += 1
  if i == 2
    next
  end
  puts i
end

# Output:
# 1
# 3
```

## Tipi nei cicli

Il tipo della variabile può essere diverso durante i cicli.
Nell'esempio seguente, il tipo di `a` è `Int32 | String` perché può essere `Int32` o `String` nella prima parte del ciclo.
La variabile `a` avrà il tipo `Int32 | String` solo nella prima parte del ciclo, dato che quando il ciclo inizia contiene `Int32`, e nella seconda iterazione contiene una `String`.
Questo sistema a tipi multipli sarà spiegato in dettaglio più avanti.
Ma poiché siamo sicuri che la seconda parte del ciclo conterrà solo `String`, il tipo di `a` è `String` nella seconda parte del ciclo.
A runtime, non conterrà mai simultaneamente `Int32` e `String`.

```crystal
i = 0
a = 4
while i < 3
  p typeof(a)
  # => Int32 | String
  a = "4"
  p typeof(a)
  # => String
  i += 1
end
```

# Return

In Crystal, l'ultima espressione in un metodo restituisce il suo valore.
Tuttavia, a volte è necessario restituire un valore prima dell'ultima espressione.
Per questo, puoi usare la parola chiave `return`, che restituirà il valore dell'espressione seguente.
Il codice scritto dopo una parola chiave `return` non verrà eseguito.

```crystal
def speed_limit(road_number)
    if road_number == 1
        return 50
        puts "This will not be executed"
    elsif road_number == 2
        return 80
        puts "This will not be executed"
    end
    100
end

p speed_limit(1) # => 50
p speed_limit(2) # => 80
p speed_limit(3) # => 100
```

~~~~exercism/note
La parola chiave `return` dovrebbe essere omessa quando l'ultima espressione in un metodo è il valore che dovrebbe essere restituito.
~~~~
