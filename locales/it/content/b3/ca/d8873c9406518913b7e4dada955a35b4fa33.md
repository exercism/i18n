# Introduzione

In Common Lisp, come in altri linguaggi, un array è un insieme di elementi a cui si accede tramite indici interi.
I tipi degli elementi possono essere eterogenei.
L'array può essere multidimensionale, non solo a una dimensione.

## Creazione

`make-array` permette di creare array.
Ha molte opzioni, ma le sue forme più semplici permettono di creare array a N dimensioni con tutti gli elementi inizializzati a un singolo valore, oppure con l'array inizializzato ai valori di un'altra sequenza (come una lista). 
Il suo primo argomento è una lista che indica la dimensione di ciascuna dimensione.

```lisp
(make-array '(4) :initial-element 3)    ; => #(3 3 3 3)
(make-array '(2 2) :initial-element 'x) ; => #2A((X X) (X X))
```

(Nota come gli array a N dimensioni vengono stampati con il numero di dimensioni.)

Gli array possono anche essere creati usando lo stesso formato con cui vengono stampati: 

```lisp
#(x y z)         ; => #(X Y Z)
#2A((1 2) (3 4)) ; => #2A((1 2) (3 4))
```

## Accesso agli elementi

Per accedere agli elementi di un vector usa `aref`, gli indici partono da zero. 
Il numero di indici forniti deve corrispondere al rango dell'array.

```lisp
(aref #2A((1 2 3) (3 4 5)) 
       1 0)           ; => 3
(aref #3A(((a b) (c d)) 
           ((e f) (g h)) 
           ((t u) (v w))) 
       2 0 1)         ; => U
(aref #2A((1) (2)) 0) ; => ERROR (because not enough indexes provided)
```
