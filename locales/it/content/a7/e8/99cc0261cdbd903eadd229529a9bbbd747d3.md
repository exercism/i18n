# Introduzione

## Ereditarietà

L'ereditarietà è un concetto fondamentale nella programmazione orientata agli oggetti (OOP).
Rappresenta una relazione IS-A.
In programmazione significa esattamente quello che significa in inglese: ereditare caratteristiche dal genitore (in programmazione le caratteristiche sono normalmente funzioni e variabili).

Considera una classe, `Animal`, come mostrato qui:

```java
//Creating an Animal class with bark() as a member function.
public class Animal {

    public void bark() {
        System.out.println("This is an animal");
    }

}
```

`Animal` è una classe genitore, perché le proprietà di questa classe possono essere estese a tutti gli animali in generale.

Considera un animale di nome `Lion`, con una classe come questa:

```java
//Lion class is a child class of Animal.
public class Lion extends Animal {

    @Override
    public void bark() {
        System.out.println("Lion here!!");
    }

}
```

~~~~exercism/note
L'annotazione `Override` serve a indicare che un metodo di una sottoclasse sta sovrascrivendo un metodo della sua superclasse.
Non è strettamente necessaria, ma usarla è una buona pratica.
~~~~

Ora, ogni volta che scriviamo:

```java
Animal animal = new Lion(); //creating instance of Animal, of type Lion
animal.bark();
```

Nota: stiamo inizializzando la classe `Animal` con `Lion`.
L'output sarà così:

```java
Lion here!!
```

Secondo la programmazione orientata agli oggetti esistono molti tipi di ereditarietà, ma Java ne supporta solo alcuni (multi-livello e gerarchica).
Per saperne di più, leggi [questo][java-inheritance].
