# Istruzioni

Lucy, l'aliena Lisp, ama i numeri e alcuni li trova «magnifici».

Ti chiede di aiutarla a scrivere delle funzioni per rendere i numeri ancora più magnifici.

Quello che secondo Lucy rende magnifico un numero può cambiare, quindi le funzioni dovranno essere flessibili.

## 1. Rendi magnifico

Per trasformare un array di numeri in un array di numeri più magnifici dovrai scrivere una funzione `make-magnificent-maybe` che prende una funzione da applicare ai numeri e un array di numeri.
Deve restituire un array di numeri ancora più magnifici (secondo la funzione fornita).

```lisp
(make-magnificent-maybe #'square '(1 2 3)) ; => (1 4 9)
(make-magnificent-maybe #'1+ '(1 2 3))     ; => (2 3 4)
```

## 2. Solo i migliori

Dopo aver reso (si spera) i numeri più magnifici, Lucy vuole vedere solo i numeri che sono davvero magnifici.

Sa per certo che 1 non è *mai* magnifico, quindi dovrai semplicemente eliminarlo.

Ma a parte questo, Lucy a volte cambia idea, quindi anche stavolta ti darà una funzione che ti dirà se un numero è magnifico oppure no.

Dovrai scrivere una funzione `only-the-best` che prende una funzione e un array di numeri e restituisce solo i numeri migliori (escluso `1` e i numeri per cui la funzione restituisce vero).

```lisp
(only-the-best #'evenp '(1 2 3 4 5)) ; => (3 5)
(only-the-best #'oddp '(1 3 5))    ; => ()
```
