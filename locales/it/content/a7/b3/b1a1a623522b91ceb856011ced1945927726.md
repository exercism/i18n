# Informazioni

JavaScript ha un operatore di incremento e uno di decremento.
Modificano una variabile sul posto.
`++` aggiunge uno a un numero, `--` sottrae uno da un numero.

```javascript
let i = 3;
i++;
// i is now 4

let j = 0;
j--;
// j is now -1
```

L'esempio sopra mostra l'operatore di incremento/decremento postfisso.
In questo caso l'operatore è posto dopo la variabile e il valore restituito dall'espressione è il valore della variabile _prima_ dell'incremento/decremento.

```javascript
let a = 3;
let b = a++;
// a = 4
// b = 3
```

C'è anche la variante prefissa, in cui l'operatore è posto prima della variabile.
In questo caso il valore restituito è il valore della variabile _dopo_ l'incremento o il decremento.

```javascript
let a = 3;
let b = ++a;
// a = 4
// b = 4
```
