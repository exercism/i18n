# Import

La [forma speciale `import`][import] ti permette di usare funzioni e macro di un modulo esterno senza usare il nome del modulo.

Importare un intero modulo esterno potrebbe creare conflitti con le funzioni locali esistenti. Per evitarlo, hai a disposizione due opzioni: `:except` e `:only`. Entrambe si aspettano una lista di keyword, in cui la chiave è il nome della funzione e il valore è l'arità della funzione.

```elixir
defmodule Square do
  import Integer, only: [pow: 2]

  def area(a), do: pow(a, 2)
end
```

Di solito le import si aggiungono all'inizio della definizione del modulo, ma possono essere aggiunte in qualsiasi punto. Hanno scope lessicale: un'import aggiunta all'interno di una definizione di funzione non sarà disponibile in un'altra funzione.

Le import non usate causano avvisi del compilatore.

[import]: https://hexdocs.pm/elixir/Kernel.SpecialForms.html#import/2
