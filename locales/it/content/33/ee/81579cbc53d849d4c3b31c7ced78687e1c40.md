# Istruzioni

In questo esercizio scriverai del codice per tenere traccia di un array di linguaggi di programmazione che vuoi imparare su Exercism.

Dovrai svolgere nove attività, che riguarderanno tutte la gestione degli array.

## 1. Crea un nuovo array

Per tenere traccia dei linguaggi che vuoi imparare, dovrai creare un nuovo array.

Implementa il metodo statico `Languages.NewList()` che restituisce un nuovo array vuoto.

```csharp
Languages.NewList()
// => empty list
```

## 2. Definisci un array esistente

Al momento hai un foglio di carta su cui sono elencati i linguaggi che vuoi imparare: C#, Clojure ed Elm.

Implementa il metodo statico `Languages.GetExistingLanguages()` per restituire l'array.

```csharp
Languages.GetExistingLanguages();
// => {"C#", "Clojure", "Elm"}
```

## 3. Aggiungi un nuovo linguaggio a un array

Mentre esplori Exercism e trovi linguaggi più interessanti, vorrai aggiungerli all'array.

Implementa la funzione statica `Languages.AddLanguage()` per aggiungere un nuovo linguaggio in fondo all'array.

```csharp
Languages.AddLanguage(Languages.GetExistingLanguages(), "VBA");
// => {"C#", "Clojure", "Elm", "VBA"}
```

## 4. Conta i linguaggi nell'array

Contare i linguaggi uno per uno è scomodo.

Implementa il metodo statico `Languages.CountLanguages()` per contare il numero di linguaggi nell'array.

```csharp
Languages.CountLanguages(Languages.GetExistingLanguages())
// => 3
```

## 5. Verifica se un linguaggio è nell'array

Implementa il metodo statico `Languages.HasLanguage()` per verificare se un linguaggio è presente.

```csharp
Languages.HasLanguage(Languages.GetExistingLanguages(), "Elm")
// => true
```

## 6. Inverti l'array

A un certo punto ti accorgi che l'array è in realtà ordinato al contrario!

Implementa il metodo statico `Languages.ReverseList()` per invertire l'array.

```csharp
Languages.ReverseList(Languages.GetExistingLanguages())
// => {"Elm", "Clojure", "C#"}
```

## 7. Verifica se l'array è entusiasmante

Anche se ami tutti i linguaggi, C# ha un posto speciale nel tuo cuore. Per questo, un array di linguaggi ti entusiasma davvero se una delle seguenti condizioni è vera:

- Il primo elemento dell'array è C#.
- Il secondo elemento dell'array è C# e l'array contiene due o tre linguaggi.

Implementa il metodo statico `Languages.IsExciting()` per verificare se un array di linguaggi è entusiasmante:

```csharp
Languages.IsExciting(Languages.GetExistingLanguages())
// => true
```

## 8.Rimuovi un linguaggio

Implementa il metodo statico `Languages.RemoveLanguage()` per rimuovere un linguaggio specificato dall'array.

```csharp
Languages.RemoveLanguage(Languages.GetExistingLanguages(), "Clojure")
// => { "C#", "Elm" }
```

## 9. Verifica se tutti i linguaggi nell'array sono unici

Implementa il metodo statico `Languages.IsUnique()` per verificare se uno dei linguaggi è ripetuto nell'array.

L'array di linguaggi (cioè il parametro) è garantito non vuoto quando questo metodo viene chiamato, e non importa se l'array viene modificato.

```csharp
Languages.IsUnique(Languages.GetExistingLanguages())
// => true
```
