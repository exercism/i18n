# Appendice alle istruzioni

## Operatori sui numeri complessi

Le funzioni aritmetiche supportano le normali chiamate di funzione, il dispatch statico (ovvero la sintassi di chiamata di metodo) e gli operatori:

| Chiamata di funzione | Chiamata di metodo | Operatore |
| --- | --- | --- |
| `plus(z1, z2)` | `z1.plus(z2)` | `z1 + z2` |
| `minus(z1, z2)` | `z1.minus(z2)` | `z1 - z2` |
| `times(z1, z2)` | `z1.times(z2)` | `z1 * z2` |
| `div_by(z1, z2)` | `z1.div_by(z2)` | `z1 / z2` |
