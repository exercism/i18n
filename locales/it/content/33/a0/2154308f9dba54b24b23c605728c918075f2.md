# Introduzione

## Liste

Una lista in Gleam è una collezione immutabile di zero o più valori. I valori di una lista devono avere tutti lo stesso tipo. Dato che le liste sono immutabili, una volta costruita una lista il suo valore non può più cambiare. Qualsiasi funzione o operatore che sembri modificare una lista (come aggiungere un elemento) in realtà restituisce una nuova lista.

Le liste si possono definire così:

```gleam
let empty = []
let singleValue = [5]
let threeValues = ["a", "b", "c"]
```

Il modo più comune per aggiungere un elemento a una lista è la sintassi spread:

```gleam
let two_to_four = [2, 3, 4]
let one_to_four = [1, ..two_to_four]
// -> [1, 2, 3, 4]
```

Il modulo [`gleam/list`](https://hexdocs.pm/gleam_stdlib/gleam/list.html) nella libreria standard di Gleam contiene molte funzioni utili per lavorare con le liste. Questo modulo è usatissimo nel codice Gleam, quindi è bene conoscerlo.

I pattern delle liste si possono usare nelle espressioni case per confrontare le liste e assegnare a delle variabili i valori che contengono:

```gleam
pub fn describe(list: List(String)) -> String {
  case list {
    [] -> "Empty list"
    [x] -> "List with one item: " <> x
    [x, y] -> "List with two items: " <> x <> " and " <> y
    _ -> "List with three or more items"
  }
}
```

Oltre a confrontare liste di lunghezza esatta, la sintassi spread si può usare per confrontare liste con almeno una certa lunghezza:

```gleam
pub fn describe(list: List(String)) -> String {
  case list {
    [_, _, ..] -> "List with at least two items"
    [_] -> "List with one item"
    [] -> "Empty list"
  }
}
```

La sintassi spread si può usare anche per assegnare a una variabile il resto della lista:

```gleam
pub fn remove_first_item(list: List(String)) -> List(String) {
  case list {
    // Return the list without the first item
    [_, ..rest] -> rest

    // There's no first item to remove, return an empty list
    _ -> []
  }
}
```

Le espressioni case dovrebbero avere un pattern per ogni possibile valore del tipo su cui si sta facendo il confronto, quindi spesso si usa un pattern di scarto finale (`_`) per gestire i valori rimanenti.
