# Test

Per scaricare un esercizio, ad esempio `hello-world`, apri un terminale ed esegui:

```bash
exercism download --track roc --exercise hello-world
```

Poi vai nella directory dell'esercizio e modifica il codice per risolvere l'esercizio. Ad esempio:

```bash
cd {your Exercism folder}/roc/hello-world
edit HelloWorld.roc
```

Ogni esercizio è accompagnato da una suite di test. Puoi eseguire i test con il comando `roc test`, ad esempio:

```
roc test hello-world-test.roc
```

Se hai risolto l'esercizio, dovresti vedere 0 test falliti, ad esempio:

```
All (5) tests passed in 123.4 ms.
```

Se invece il codice contiene errori, appariranno così:

```
── EXPECT FAILED in hello-world-test.roc ───────────────────────────────────────

This expectation failed:

6│  expect hello == "Hello, World!"
    ^^^^^^^^^^^^^^^^^^^^^^^^^^^^^^^


1 failed and 0 passed in 123.4 ms.
```

Questo dovrebbe aiutarti a correggere il codice. Quando il codice funziona, puoi inviarlo con il comando `exercism submit` (per maggiori dettagli, vedi `HELP.md` nella directory dell'esercizio).
