# Istruzioni aggiuntive

## Implementazione

In questo esercizio implementerai una procedura che serve ad allocare la stringa che restituisce. Deallocare la stringa è responsabilità di chi chiama la procedura.

```odin
// The procedure will be called like that:
formatted := format("Gianna", 4)
// ...
// and eventually the caller will delete the string
delete(formatted)
```
