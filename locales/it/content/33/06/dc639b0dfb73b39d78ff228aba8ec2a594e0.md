# Informazioni

Un [`list`][lists] in F# è una collezione immutabile di zero o più valori. I valori in un array devono avere tutti lo stesso tipo. Dato che gli array sono immutabili, una volta costruito un array il suo valore non può più cambiare. Gli array in F# hanno una _testa_ (il primo elemento) e una _coda_ (tutto ciò che segue il primo elemento). La coda di un array è essa stessa un array.

Gli array si possono definire così:

```fsharp
let empty = []
let emptyAlternative = List.empty

let singleValue = [5]
let singleValueAlternative = List.singleton 5

let threeValues = ["a"; "b"; "c"]
```

Il modo più comune per aggiungere un elemento a un array è tramite l'operatore `::` (cons):

```fsharp
let twoToFour = [2; 3; 4]
let oneToFour = 1 :: twoToFour
// => [1; 2; 3; 4]
```

Gli array si possono concatenare usando l'operatore `@` oppure `List.append`:

```fsharp
[6; 7] @ [8; 9]           // => [6; 7; 8; 9]
List.append [6; 7] [8; 9] // => [6; 7; 8; 9]
```

Gli array si manipolano con funzioni e operatori definiti nel [modulo `List`][list-module]. Alcune di queste funzioni sono disponibili anche come [proprietà][list-properties] di un'istanza di `list`:

```fsharp
List.length [7; 8] // => 2
[7; 8].Length      // => 2
```

Qui non c'è un'opzione giusta o sbagliata. In generale, le funzioni del modulo `List` si integrano meglio con l'inferenza di tipo, mentre le proprietà permettono un codice più conciso.

Qualsiasi funzione o operatore che sembri modificare un array (per esempio aggiungendo un elemento) in realtà restituisce un nuovo array. Le prestazioni di solito non sono un problema, dato che l'implementazione degli array evita allocazioni e copie inutili.

Dato che gli array sono implementati come liste concatenate singolarmente, anteporre un elemento (usando l'operatore `::`) è molto veloce, mentre accedere a un elemento tramite indice può essere relativamente lento.

Gli array si possono anche elaborare usando il pattern matching tramite i pattern [_list_][list-pattern] e [_cons_][cons-pattern]:

```fsharp
let describe list =
    match list with
    | [] -> "Empty list"
    | [ 1 ] -> "Singleton list with 1"
    | head::tail -> sprintf "Non-empty list with head: %d" head

describe []        // => "Empty list"
describe [1]       // => "Singleton list with 1"
describe [5; 7; 9] // => "Non-empty with head: 5"
```

[list-module]: https://fsharp.github.io/fsharp-core-docs/reference/fsharp-collections-listmodule.html
[list-properties]: https://docs.microsoft.com/en-us/dotnet/fsharp/language-reference/lists#properties
[cons-pattern]: https://docs.microsoft.com/en-us/dotnet/fsharp/language-reference/pattern-matching#cons-pattern

Puoi anche _scartare_ un valore durante il pattern matching; quando _non_ ti interessa un valore in un caso specifico (cioè non hai intenzione di _usare_ quel valore) puoi usare un underscore (`'_'`) per indicarlo:

```fsharp
let describe list =
    match list with
    | [] -> "Empty list"
    | [x] -> "List with one item"
    | [_; y] -> "List with two items (first item ignored)"
    | _ -> "List with many items (all items ignored)"

describe []        // => "Empty list"
describe [1]       // => "List with one item"
describe [5; 7]     // => "List with two items (first item ignored)"
describe [5; 7; 9] // => "List with many items (all items ignored)"
```

Il singolo `'_'` dovrebbe sempre venire per _ultimo_ durante il pattern matching: ogni valore che _non_ corrisponde a nessuno degli altri casi verrà gestito da questo caso.
