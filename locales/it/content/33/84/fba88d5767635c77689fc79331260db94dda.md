# Istruzioni

È la finale di stagione al circolo locale. Gestisci la
classifica sulla linea d'arrivo: i corridori arrivano in ordine, le corsie
hanno bisogno di etichette e il registro ufficiale va annotato prima
della prossima batteria.

I nomi dei corridori arrivano sotto forma di array, in ordine di arrivo:
il nome in posizione 0 è il vincitore, quello in posizione 1 è il secondo
classificato, e così via.

## 1. Assegna i pettorali

Definisci `assign-bibs` in modo che prenda un array di nomi dei corridori e
restituisca un array di coppie `{ position name }`, con la posizione per prima.

```factor
{ "Bolt" "Comet" "Spirit" } assign-bibs .
! => { { 0 "Bolt" } { 1 "Comet" } { 2 "Spirit" } }
```

## 2. Etichette delle corsie

Definisci `lane-labels` in modo che prenda un array di nomi dei corridori e
restituisca stringhe come `"Lane 0: Bolt"`.

```factor
{ "Bolt" "Comet" } lane-labels .
! => { "Lane 0: Bolt" "Lane 1: Comet" }
```

## 3. Contrassegna i corridori

Definisci `tag-racers` in modo che prenda un array di nomi dei corridori *e*
una stringa di tag, restituendo etichette nella forma `"<tag>/<index>:
<name>"`. Lo stesso tag è incorporato in ogni etichetta.

```factor
{ "Bolt" "Comet" } "Green" tag-racers .
! => { "Green/0: Bolt" "Green/1: Comet" }
```

## 4. Registra gli arrivi

Definisci `record-finishes` in modo che prenda un array di nomi dei corridori e
un registro (un vector). Per ogni corridore, aggiungi una stringa nella forma
`"<index>: <name>"` al registro, sul posto. Non restituisce nulla.

```factor
V{ } clone   ! a fresh empty ledger
{ "Bolt" "Comet" } over record-finishes
.
! => V{ "0: Bolt" "1: Comet" }
```

## 5. Campanelle dei giri

Definisci `lap-bells` in modo che prenda un numero `laps` e restituisca una
stringa composta da `"ding "` ripetuto `laps` volte.

```factor
0 lap-bells .   ! => ""
3 lap-bells .   ! => "ding ding ding "
```
