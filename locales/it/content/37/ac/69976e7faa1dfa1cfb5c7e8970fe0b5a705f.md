# Informazioni

Rust implementa un array di caratteri in due modi: [`str`][str] e [`String`][String].

`str`, noto anche come «string slice», di solito si usa con un riferimento, cioè come `&str`.

Per capire perché, può aiutare capire perché la riga di codice seguente non viene compilata

```rust
const MY_CONST: str = *"Hello, World!";

// the size for values of type `str` cannot be known at compilation time
// the trait `Sized` is not implemented for `str`
```

Anche se la lunghezza del letterale «Hello, World!» può essere nota al momento della compilazione, in quanto `str` è una sequenza di dimensione sconosciuta.
Ma come _riferimento_ a un letterale (`&str`), ha un «fat pointer», che contiene l'indirizzo e la lunghezza del letterale in memoria.
I fat pointer hanno una dimensione nota, quindi questa riga verrà compilata

```rust
const MY_CONST: &str = "Hello, World!";
```

Un binding mutabile a una string slice può avere il valore sostituito, ma non modificato sul posto.

Esempio

```rust
let mut my_str = "Hello, World!";
my_str = "Hi!";
let mut my_string = String::from("Hello");
my_string.push_str(", World!"); // there is no equivalent function to modify &str
```

È meno restrittivo usare `&str` invece di `&String` quando si definisce il parametro di una funzione: il codice seguente, infatti, non verrà compilato

```rust
pub fn main() {
    let my_str: &str = "Hello, World!";
    say_hi(my_str);
}

fn say_hi(phrase: &String) {
    println!("{phrase:?}");
}

// mismatched types
// expected reference `&String`
// found reference `&str`
```

Un `&str` non subisce una [coercizione][coercion] verso un `&String`. Questo codice invece verrà compilato

```rust
pub fn main() {
    let my_string = String::from("Hello, World!");
    say_hi(&my_string)
}

fn say_hi(phrase: &str) {
    println!("{phrase:?}");
}
```

Un `&String` subisce una coercizione verso un `&str`. Quindi usare `&str` come tipo di parametro sarà spesso più utile.

[str]: https://doc.rust-lang.org/std/primitive.str.html
[String]: https://doc.rust-lang.org/std/string/struct.String.html
[coercion]: https://doc.rust-lang.org/reference/type-coercions.html
