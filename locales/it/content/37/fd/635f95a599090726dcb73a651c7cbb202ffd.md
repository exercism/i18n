# Appendice alle istruzioni

## Stampa dell'albero

Questo esercizio include alcuni metodi di classe predefiniti che aiutano a stampare l'albero in un formato chiaro e leggibile.
Il loro scopo principale è facilitare il debug e offrire maggiore chiarezza.
Se implementi correttamente il resto della classe, dovrebbero stampare l'albero per te.

```powershell
.Example
$tree = [BinarySearchTree]::new(@(50, 76, 1, 34, 89, 44, 25, 6, 26, 100, 13))
$tree.ToString()

Return:
@"
50
├──L:1
│   └──R:34
│       ├──L:25
│       │   ├──L:6
│       │   │   └──R:13    
│       │   └──R:26        
│       └──R:44
└──R:76
    └──R:89
        └──R:100
"@
```
