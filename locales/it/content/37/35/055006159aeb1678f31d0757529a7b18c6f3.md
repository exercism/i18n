# Informazioni

Le [tuple][tuple] si usano comunemente per raggruppare informazioni: a differenza degli array, hanno una dimensione fissa e possono contenere tipi di dati diversi.
Le tuple si creano con le parentesi tonde (`()`) e servono spesso a restituire più valori da una funzione.

```haskell
tuple = (1, "abc", False)
```

Questo può esserti utile, per esempio, quando vuoi memorizzare una coordinata in uno spazio bidimensionale: sai che la tupla avrà sempre due elementi, le coordinate x e y.

```haskell
coordinate = (3, 4)
```

## Accesso agli elementi

Spesso lavori con tuple brevi e puoi accedere agli elementi usando le funzioni `fst` e `snd`.

```haskell
x = fst coordinate
-- x = 3
y = snd coordinate
-- y = 4
```

[tuple]: https://hackage.haskell.org/package/base/docs/Data-Tuple.html
