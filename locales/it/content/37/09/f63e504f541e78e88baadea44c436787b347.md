# Stringhe

Crystal ha un tipo noto come [`String`][strings], usato per rappresentare il testo.
Le stringhe di Crystal sono sequenze di caratteri Unicode.
Le stringhe sono immutabili, il che significa che non possono essere modificate una volta create.
Questo significa che ogni volta che modifichi una stringa viene creata una nuova stringa; quindi, la stringa originale non viene modificata.

Per definire una stringa si usano le virgolette doppie `"`.

```crystal
"Hello World"
```

## Concatenazione

Per concatenare due stringhe, usa l'operatore `+`.
L'operatore `+` restituisce una nuova stringa che combina le due stringhe.

```crystal
hello = "Hello"
hello + " World"
# => "Hello World"
```

## Conversione tra stringhe e numeri

Il metodo `to_i` converte una stringa in un numero intero.
In alternativa, si può usare il metodo `to_f` per restituire un numero in virgola mobile.
Se la stringa non può essere convertita in un numero, viene sollevato un `ArgumentError`.

```crystal
"1".to_i
# => 1

"1.0".to_f
# => 1.0

"Hello".to_i
# => ArgumentError: Invalid integer: Hello
```

Un numero intero o un numero in virgola mobile può essere convertito in una stringa usando il metodo `to_s`.

```crystal
1.to_s
# => "1"

1.0.to_s
# => "1.0"
```

## Interpolazione

L'interpolazione è un modo comodo per combinare stringhe e incorporare espressioni nelle stringhe.
Per interpolare una stringa, puoi usare il carattere `#` seguito da parentesi graffe `{}` con l'espressione all'interno delle parentesi.

```crystal
name = "World"
"Hello #{name}!"
# => "Hello World!"
```

Crystal convertirà automaticamente il risultato dell'espressione in una stringa.

```crystal
"Hello #{1 + 1}!"
# => "Hello 2!"
```

## Dimensione

Quando hai bisogno di conoscere il numero di caratteri in una stringa, puoi usare il metodo `size`, che restituisce la lunghezza della stringa come numero intero.
La dimensione di una stringa è una proprietà memorizzata della stringa, quindi non deve calcolare la dimensione ogni volta che chiami il metodo, il che lo rende molto veloce.

```crystal
"Hello World".size
# => 11
```

## Indicizzazione

L'indicizzazione serve quando vuoi ottenere un carattere specifico da una stringa.
Per ottenere un carattere da una `String` puoi usare la familiare notazione con parentesi quadre.

~~~~exercism/note
`[]` è implementato come metodo di istanza di String, dove l'indice è l'argomento del metodo.
~~~~

Il primo carattere di una stringa si trova all'indice 0.

```crystal
"Hello World"[0]
# => 'H'

"Hello World"[6]
# => 'W'
```

Per ottenere un carattere dalla fine di una stringa, puoi prendere la lunghezza della stringa meno uno per ottenere l'indice dell'ultimo carattere, e per ottenere il penultimo carattere, puoi prendere la lunghezza della stringa meno due, e così via.
C'è una scorciatoia per questo, e cioè usare semplicemente un indice negativo, dove l'ultimo carattere è all'indice -1, il penultimo carattere è all'indice -2, e così via.

```crystal
name = "Hello World"
name[name.size - 1]
# => 'd'

name[-1]
# => 'd'
```

### Test di sottostringa

Crystal supporta la verifica se una stringa contiene una sottostringa usando l'indicizzazione.
La stessa notazione con parentesi lo fa, ma invece di un indice, viene data una sottostringa.
Se la sottostringa viene trovata nella stringa, allora viene restituita la sottostringa, altrimenti viene sollevato un `NilAssertionError`.

```crystal
"Hello World"["Hello"]
# => "Hello"

"Hello World"["Goodbye"]
# => NilAssertionError
```

Se vuoi un valore `Bool` per indicare se la sottostringa è stata trovata, allora puoi usare il metodo `includes?`.

```crystal
"Hello World".includes?("Hello")
# => true

"Hello World".includes?("Goodbye")
# => false
```

## Sequenze di escape

Alcuni caratteri non possono essere scritti direttamente in una stringa, invece devi usare una sequenza di escape.
Ad esempio, se vuoi usare le virgolette doppie in una stringa, devi fare l'escape delle virgolette doppie.
Puoi usare il carattere `\` per scrivere una sequenza di escape seguita dal carattere che vuoi fare escape.

Questi sono i caratteri speciali in Crystal:

| Valore   | Descrizione                   |
| -------- | ----------------------------- |
| `\a`     | Avviso                        |
| `\b`     | Backspace                     |
| `\e`     | Escape                        |
| `\f`     | Avanzamento modulo            |
| `\n`     | Avanzamento riga o nuova riga |
| `\r`     | Ritorno carrello              |
| `\t`     | Tabulazione orizzontale       |
| `\v`     | Tabulazione verticale         |
| `\\`     | Barra rovesciata              |
| `\'`     | Virgoletta singola            |
| `\"`     | Virgoletta doppia             |
| `\377`   | Carattere ASCII ottale        |
| `\xFF`   | Carattere ASCII esadecimale   |
| `\uFFFF` | Carattere Unicode esadecimale |

```crystal
puts "Hello \"World\""
# => Hello "World"

puts "Hello \nWorld"
# => Hello
# => World
```

## Stringhe multilinea

Per scrivere una stringa multilinea, usi la stessa sintassi di una stringa a riga singola ma vai a capo per ogni riga che vuoi nella stringa.

```crystal
"Hello
World"
# => "Hello\nWorld"
```

## Unicode

[Unicode][unicode] è uno standard per codificare, rappresentare e elaborare testo in diversi sistemi di scrittura.
Unicode supporta oltre 100.000 caratteri, incluse lettere, punteggiatura, simboli ed emoji.

Poiché Crystal usa Unicode per le stringhe, puoi, ad esempio, inserire emoji nelle stringhe.

```crystal
"Hello 🌍"
# => "Hello 🌍"
```

A volte, vuoi usare un carattere che non è disponibile, ad esempio, nel tuo editor o nel tuo sistema.
In tal caso, puoi usare la sequenza di escape Unicode per scrivere il carattere.

```crystal
"\u{1F310}"
# => "🌐"
```
