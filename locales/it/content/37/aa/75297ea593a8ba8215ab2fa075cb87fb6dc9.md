# Istruzioni

Il tuo compito è determinare cosa dirai mentre regali il biscotto in più.

Se al tuo amico piacciono i biscotti e si chiama Do-yun, allora dirai:

```text
One for Do-yun, one for me.
```

Se al tuo amico non piacciono i biscotti, dai il biscotto alla prossima persona in fila alla panetteria.
Dato che non conosci il suo nome, dirai _you_ al suo posto.

```text
One for you, one for me.
```

Ecco alcuni esempi:

| Nome   | Dialogo                     |
| :----- | :-------------------------- |
| Alice  | One for Alice, one for me.  |
| Bohdan | One for Bohdan, one for me. |
|        | One for you, one for me.    |
| Zaphod | One for Zaphod, one for me. |
