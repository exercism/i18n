# Introduzione

Ogni file sorgente Factor dichiara un *vocabolario* con `IN:` e
importa tutti gli altri che usa con `USING:`.

```factor
USING: kernel sequences ;
IN: my-vocab

: shout ( str -- str ) "!" append ;
```

La struttura delle directory segue il nome puntato del vocabolario:

- il vocabolario `my-vocab` si trova in `my-vocab/my-vocab.factor`
- il vocabolario `my-vocab.helpers` si trova in `my-vocab/helpers/helpers.factor`

Il caricatore dei vocabolari di Factor segue le dichiarazioni `USING:`
in modo transitivo: quando un file che richiedi importa un altro vocabolario,
quel vocabolario viene caricato automaticamente.

Spesso conviene suddividere una routine di grandi dimensioni tra due
vocabolari: un vocabolario ausiliario con piccole parole riutilizzabili, e
un vocabolario principale che le importa e compone il risultato.
