# Istruzioni

Salve, agente Double-Null0111.

La tua missione, se deciderai di accettarla, è scrivere un paio di strumenti che ti aiutino a infiltrarti nel quartier generale di UMBRA (United Minions Being Really Awful) e a recuperare i piani del loro ultimo piano davvero atroce.
Per portare a termine questa missione ti serviranno tre strumenti.

## 1. Genera un numero identificativo

Ogni sgherro ha un identificatore unico che cambia ogni giorno e dipende dal numero di segreti che custodisce e dal numero di ore che dorme.
Dovrai scrivere una funzione che prende il giorno (come `Int`) e crea una funzione generatrice di identificatori per quel giorno.
La funzione generatrice di identificatori prende due parametri:

1. il numero di segreti custoditi
2. il numero di ore in cui lo sgherro dorme

L'identificatore si calcola così:

1. moltiplica il numero di segreti custoditi per il numero di ore che dorme
2. aggiungi il giorno (rappresentato come `Int`) al risultato

```kotlin
val idGenerator = makeIdGenerator(4)
idGenerator(3, 6)
// => 22

idGenerator(11, 5)
//  => 59
```

## 2. Proteggi con una password segreta i piani segreti recuperati

Una volta ottenuti i piani segreti, dovrai proteggerli, così che solo chi conosce la password possa recuperarli.
Per farlo, dovrai implementare la funzione `protectSecret(secret: String, password: String) : (String) -> String`.
Questa funzione restituirà un'altra funzione che prende in input delle possibili stringhe password.
Se la password inserita è corretta, la nuova funzione restituisce il segreto nascosto; se invece la password è sbagliata, la funzione restituisce "Sorry. No hidden secrets here."

```kotlin
val secretFunction = protectSecret("Steal the world's supply of french fries!", "5up3r53cr37")

secretFunction("Open sesame")
// Returns "Sorry. No hidden secrets here."

secretFunction("5up3r53cr37")
// Returns "Steal the world's supply of french fries!"
```

## 3. Trova la password segreta

La base di UMBRA ha diverse stanze sorvegliate da una guardia giurata che ti chiederà la password segreta.
La password segreta dipende dal numero della stanza.
Purtroppo conosciamo solo metà dell'algoritmo per calcolare la password.
L'altra metà si può scoprire chiedendola a uno degli sgherri.

Implementa la funzione `getPassword`, che prende quanto segue e restituisce la password:

1. il numero della stanza
2. la funzione dello sgherro e restituisce la password segreta

La password segreta si ottiene chiamando la funzione dello sgherro con un'altra funzione che rappresenta l'algoritmo che conosciamo.
La nostra parte dell'algoritmo:

1. prende due numeri e li somma
2. moltiplica il risultato per l'id della stanza

```kotlin
val minionFunction = { yourFunc : (Int, Int) -> Int ->
    "Password=${yourFunc(1, 3)}"
}

getPassword(5, minionFunction)
// Returns "Password=20"
```
