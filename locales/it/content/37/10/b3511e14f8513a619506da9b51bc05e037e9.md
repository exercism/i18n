# Introduzione

Go non ha un concetto di vuoto, null o undefined per i valori delle variabili.
Le variabili dichiarate senza un valore iniziale esplicito assumono il valore zero del proprio tipo.

Il valore zero dei tipi primitivi, come i booleani, i tipi numerici e le stringhe, è rispettivamente `false`, `0` e `""`.

L'identificatore `nil`, che significa zero, è il valore zero per i tipi più complessi, come puntatori, funzioni, interfacce, slice, canali e mappe.

La tabella seguente riporta il valore zero per i tipi di Go.

| Tipo      | Valore zero |
| --------- | ----------- |
| booleano  | `false`     |
| numerico  | `0`         |
| stringa   | `""`        |
| puntatore | `nil`       |
| funzione  | `nil`       |
| interfaccia | `nil`     |
| slice     | `nil`       |
| canale    | `nil`       |
| mappa     | `nil`       |

Forse avrai notato che i tipi struct non compaiono nella tabella qui sopra.
Il motivo è che il valore zero di un tipo struct dipende dai suoi campi.
Uno struct viene impostato al suo valore zero quando tutti i suoi campi sono impostati al rispettivo valore zero.
