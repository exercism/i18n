# Introduzione

In programmazione, è essenziale gestire gli errori con eleganza, per evitare che situazioni impreviste facciano andare in crash il programma o lo portino a comportarsi in modo imprevedibile.
Cairo mette a disposizione due meccanismi principali per la gestione degli errori:

1. **Errori non recuperabili** con `panic`, che arrestano immediatamente il programma.
2. **Errori recuperabili** con `Result`, che permettono al programma di gestire gli errori e di reagire ad essi.

## Errori non recuperabili con `panic`

A volte un programma incontra un errore talmente grave da non poter proseguire.
In questi casi Cairo usa la funzione `panic` per interrompere immediatamente l'esecuzione.
È utile quando un errore, ad esempio il tentativo di accedere a un indice fuori dai limiti, rende impossibile per il programma continuare in modo sensato.
La funzione `panic` accetta un messaggio di tipo `ByteArray` che descrive il motivo dell'errore.

Per esempio, in Cairo:

```rust
fn main() {
    let data = array![1, 2];
    panic("An unrecoverable error has occurred!");
}
```

Questo esempio mostra un panic forzato, che arresta immediatamente il programma con un messaggio.

### La macro `assert!`

La macro `assert!` è uno strumento utile per imporre condizioni specifiche nel codice.
Se la condizione in `assert!` viene valutata come `false`, il programma andrà in panic con un messaggio di errore di tipo `ByteArray`.
Spesso viene usata per verificare le ipotesi durante lo sviluppo e per assicurarsi che i valori soddisfino determinati criteri.

Per esempio:

```rust
fn main() {
    let x = 5;
    assert!(x > 0, "x must be greater than zero");
}
```

Se `x` non è maggiore di zero, il programma andrà in panic con il messaggio `"x must be greater than zero"`. `assert!` è utile per controllare invarianti e precondizioni senza scrivere a mano il codice di gestione degli errori.

## Errori recuperabili con `Result`

Non tutti gli errori devono arrestare il programma.
Alcuni possono essere gestiti con eleganza, così che il programma possa proseguire.
L'enum `Result` di Cairo rappresenta questi errori recuperabili e ha due varianti:

- `Result::Ok` indica un successo.
- `Result::Err` rappresenta un errore.

Usando `Result`, una funzione può restituire un valore di successo oppure un errore, lasciando alla funzione chiamante decidere cosa fare dopo.

```rust
fn divide(a: u32, b: u32) -> Result<u32, ByteArray> {
    if b == 0 {
        Result::Err("Error: Division by zero")
    } else {
        Result::Ok(a / b)
    }
}
```

In questo esempio, se `b` è zero viene restituito un errore; altrimenti viene restituito il risultato della divisione.
