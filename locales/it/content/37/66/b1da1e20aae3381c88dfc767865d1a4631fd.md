# Appendice alle istruzioni

## Istruzioni specifiche della traccia

Le funzioni devono restituire il prodotto, l'offset e la lunghezza dell'array dei fattori.
I fattori sono semplicemente scritti in memoria come coppie di i32:

```
Return value:
[u32 $product] [u32 $factorsOffset] [u32 $factorsLength]

Memory at $factorsOffset
[u32 firstFactor] [u32 firstCofactor] [u32 secondFactor] [u32 secondCofactor] ...
```

Per il più grande prodotto palindromo a una cifra, apparirebbe così:

```
Return value
0009 0000 0004

Memory at offset 0
0001 0009 0003 0003
```
