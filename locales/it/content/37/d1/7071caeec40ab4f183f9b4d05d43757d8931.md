# Informazioni

In Haxe, un tipo astratto è un tipo che a run-time è un tipo diverso. È una funzionalità a tempo di compilazione che definisce tipi «sopra» tipi concreti per modificarne o estenderne il comportamento:

```haxe
abstract AbstractInt(Int) {
    inline public function new(i:Int) {
        this = i;
    }
}
```

Qui dichiariamo il tipo `AbstractInt` usando la parola chiave `abstract`. La sua sintassi è molto simile a quella di `class`. E proprio come le classi, i tipi astratti possono avere metodi. Possono anche essere istanziati e usati proprio come le classi:

```haxe
class Main {
    static public function main() {
        var a = new AbstractInt(12);
        trace(a); // 12
    }
}
```

Come accennato sopra, i tipi astratti sono una funzionalità a tempo di compilazione. Compilare l'esempio precedente in JavaScript produce quanto segue:

```javascript
var a = 12;
console.log(a)
```

Il tipo astratto `AbstractInt` scompare completamente dall'output. Questo perché il costruttore di `Abstract` è [incorporato][inline], come vedremo più avanti.

[inline]: https://haxe.org/manual/class-field-inline.html
