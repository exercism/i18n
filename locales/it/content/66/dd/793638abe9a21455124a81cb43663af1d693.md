# Informazioni

Objective-C è un sottile strato sopra il C ed è un «strict superset» del C: questo significa che è possibile compilare qualsiasi programma C con un compilatore Objective-C e includere liberamente codice C all'interno di una classe Objective-C.
Objective-C deriva da Smalltalk la sua sintassi per gli oggetti.
Tutta la sintassi per le operazioni non orientate agli oggetti (comprese le variabili primitive, il preprocessing, le espressioni, le dichiarazioni di funzioni e le chiamate di funzione) è identica a quella del C, mentre la sintassi per le funzionalità orientate agli oggetti è un'implementazione della messaggistica in stile Smalltalk.

Puoi trovare maggiori informazioni sul linguaggio e sulla sua storia [qui](https://en.wikipedia.org/wiki/Objective-C).
