# Informazioni

Le classi principali di `java.time`, come `LocalDate` e `LocalDateTime`, forniscono metodi di base per aggiungere o sottrarre unità di tempo. Le regolazioni di data più complesse richiedono però spesso una logica più sofisticata (per esempio, trovare il «secondo martedì del mese» o l'«ultimo giorno dell'anno»).

Il package `java.time.temporal` fornisce a questo scopo l'interfaccia funzionale [`TemporalAdjuster`][temporaladjuster-docs].
Rappresenta una strategia per regolare un oggetto temporale (come un `LocalDate`).
La classe di utilità [`TemporalAdjusters`][temporaladjusters-docs] (nota la «s» finale del plurale) contiene metodi factory statici che forniscono molte implementazioni comuni e predefinite di regolatori.

## Usare TemporalAdjusters

Gli oggetti temporali come `LocalDate` e `LocalDateTime` hanno un metodo `with()` che accetta un `TemporalAdjuster`.
Questo metodo restituisce un *nuovo* oggetto temporale a cui è stata applicata la regolazione.

```exercism/note
Usare `with(TemporalAdjuster)` restituisce una _nuova_ istanza e non aggiorna quella esistente, dato che tutte le classi temporali di `java.time` sono immutabili.
```

```java
import java.time.LocalDate;
import java.time.Month;
import java.time.DayOfWeek;
import java.time.temporal.TemporalAdjusters;

LocalDate date = LocalDate.of(2024, Month.AUGUST, 15); // 2024-08-15 (a Thursday)

// Use a predefined adjuster from TemporalAdjusters
LocalDate firstDayOfNextMonth = date.with(TemporalAdjusters.firstDayOfNextMonth());
// => 2024-09-01

LocalDate nextSunday = date.with(TemporalAdjusters.next(DayOfWeek.SUNDAY));
// => 2024-08-18
```

## Regolatori predefiniti comuni

La classe `TemporalAdjusters` fornisce molti metodi statici utili.
Ecco alcuni esempi comuni:

### Trovare l'ennesimo giorno della settimana

Il regolatore `dayOfWeekInMonth(int ordinal, DayOfWeek dayOfWeek)` trova l'ennesima occorrenza di un giorno specifico della settimana all'interno del mese.

```java
LocalDate date = LocalDate.of(2024, Month.AUGUST, 15); // 2024-08-15

// Find the second Tuesday of August 2024
LocalDate secondTuesday = date.with(TemporalAdjusters.dayOfWeekInMonth(2, DayOfWeek.TUESDAY));
// => 2024-08-13

// Find the fourth Friday of August 2024
LocalDate fourthFriday = date.with(TemporalAdjusters.dayOfWeekInMonth(4, DayOfWeek.FRIDAY));
// => 2024-08-23
```

### Trovare il primo o l'ultimo giorno della settimana nel mese

I regolatori `firstInMonth(DayOfWeek dayOfWeek)` e `lastInMonth(DayOfWeek dayOfWeek)` trovano la prima o l'ultima occorrenza di un giorno della settimana all'interno del mese.

```java
LocalDate date = LocalDate.of(2024, Month.AUGUST, 15); // 2024-08-15

// Find the first Sunday of August 2024
LocalDate firstSunday = date.with(TemporalAdjusters.firstInMonth(DayOfWeek.SUNDAY));
// => 2024-08-04

// Find the last Monday of August 2024
LocalDate lastMonday = date.with(TemporalAdjusters.lastInMonth(DayOfWeek.MONDAY));
// => 2024-08-26
```

### Trovare il primo o l'ultimo giorno del mese o dell'anno

Regolatori più semplici trovano il primo o l'ultimo giorno del mese o dell'anno corrente.

```java
LocalDate date = LocalDate.of(2024, Month.AUGUST, 15); // 2024-08-15

LocalDate firstDay = date.with(TemporalAdjusters.firstDayOfMonth());
// => 2024-08-01

LocalDate lastDay = date.with(TemporalAdjusters.lastDayOfMonth());
// => 2024-08-31

LocalDate lastDayOfYear = date.with(TemporalAdjusters.lastDayOfYear());
// => 2024-12-31
```

### Regolazioni relative (successivo/precedente)

Regolatori come `next()`, `previous()`, `nextOrSame()` e `previousOrSame()` trovano l'occorrenza successiva o precedente di un dato giorno della settimana, rispetto alla data corrente.

- `next()`/`previous()`: escludono la data corrente se corrisponde.
- `nextOrSame()`/`previousOrSame()`: includono la data corrente se corrisponde.

```java
LocalDate thursday = LocalDate.of(2024, Month.AUGUST, 15); // A Thursday

// Find the next Sunday (exclusive)
LocalDate nextSunday = thursday.with(TemporalAdjusters.next(DayOfWeek.SUNDAY));
// => 2024-08-18

// Find the next Thursday (exclusive)
LocalDate nextThursday = thursday.with(TemporalAdjusters.next(DayOfWeek.THURSDAY));
// => 2024-08-22

// Find the next Thursday (inclusive) - returns the same date
LocalDate nextOrSameThursday = thursday.with(TemporalAdjusters.nextOrSame(DayOfWeek.THURSDAY));
// => 2024-08-15

// Find the previous Monday (exclusive)
LocalDate previousMonday = thursday.with(TemporalAdjusters.previous(DayOfWeek.MONDAY));
// => 2024-08-12
```

## Regolatori personalizzati

Poiché `TemporalAdjuster` è una [`@FunctionalInterface`][functionalinterface-docs], puoi creare regolatori personalizzati usando espressioni lambda per la logica non coperta dai metodi predefiniti.
L'interfaccia richiede l'implementazione di un unico metodo: `Temporal adjustInto(Temporal temporal)`.

```java
// Example: An adjuster that finds the next workday (Mon-Fri), skipping weekends.
TemporalAdjuster nextWorkday = temporal -> {
    LocalDate result = (LocalDate) temporal; // Assuming input is LocalDate
    do {
        result = result.plusDays(1);
    } while (result.getDayOfWeek() == DayOfWeek.SATURDAY || result.getDayOfWeek() == DayOfWeek.SUNDAY);
    return result;
};

LocalDate friday = LocalDate.of(2024, Month.AUGUST, 16);
LocalDate nextWorkdayDate = friday.with(nextWorkday);
// => 2024-08-19 (Monday)

LocalDate sunday = LocalDate.of(2024, Month.AUGUST, 18);
LocalDate nextWorkdayFromSunday = sunday.with(nextWorkday);
// => 2024-08-19 (Monday)
```

I regolatori personalizzati sono potenti, ma quelli predefiniti nella classe `TemporalAdjusters` coprono una vasta gamma di casi d'uso comuni.
