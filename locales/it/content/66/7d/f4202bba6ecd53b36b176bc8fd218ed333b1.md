# Istruzioni

Stai gestendo il tabellone di una partita di netball. A differenza di tutto quello che hai visto finora, un tabellone deve ricordare quello che è successo.

La classe `SCOREBOARD` deve avere quanto segue. Lo stub ti fornisce la classe e le dichiarazioni dei suoi due attributi: aggiungi il resto.

## 1. Preparare il tabellone

`create` prende il nome della squadra di casa e quello della squadra ospite, e restituisce un tabellone con entrambi i punteggi a zero.

```sather
board ::= #SCOREBOARD("Vixens", "Magpies");
board.home_score
-- => 0
```

## 2. Segnare un goal

`home_goal` aggiunge uno al punteggio di casa, e `away_goal` aggiunge uno al punteggio ospite. Nessuno dei due restituisce nulla.

```sather
board.home_goal;
board.home_score
-- => 1
```

## 3. Leggere il tabellone

`summary` restituisce il tabellone così come verrebbe scritto: la squadra di casa, il suo punteggio, un trattino, il punteggio ospite, poi la squadra ospite.

```sather
board.summary
-- => "Vixens 1 - 0 Magpies"
```

Gli spazi sono esattamente quelli mostrati, e il trattino è un singolo `-`.

## 4. Chi sta vincendo?

`leader` restituisce il nome della squadra in vantaggio, oppure `"Draw"` quando i punteggi sono in parità.

```sather
board.leader
-- => "Vixens"
```

## 5. Di quanto è avanti?

`margin` restituisce quanti goal separano le squadre. Non è mai negativo, chiunque sia in vantaggio.

```sather
board.margin
-- => 1
```
