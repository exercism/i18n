# Istruzioni

Nei panni di una futura maga, Elyse deve esercitarsi con le basi. Ha un mazzo di carte che vuole manipolare.

Per rendere le cose un po' più semplici, usa solo le carte da 1 a 10.

## 1. Recuperare una carta da un mazzo

Implementa la funzione `getCard` che restituisce la carta alla posizione `index` del mazzo dato. Se l'indice non è presente nel mazzo, restituisci Nothing.

```elm
getCard 2 ( Array.fromList [ 1, 2, 4, 1 ] )
    --> Just 4
getCard 6 ( Array.fromList [ 1, 2, 4, 1 ] )
    --> Nothing
```

## 2. Cambiare una carta nel mazzo

Implementa la funzione `setCard` che restituisce un mazzo con la carta alla posizione `index` sostituita con la nuova carta fornita.
Se l'`index` non è presente nel mazzo, restituisci il mazzo originale.

```elm
setCard 2 6 ( Array.fromList [ 1, 2, 4, 1 ] )
    --> Array.fromList [ 1, 2, 6, 1 ]
setCard 6 6 ( Array.fromList [ 1, 2, 4, 1 ] )
    --> Array.fromList [ 1, 2, 4, 1 ]
```

## 3. Aggiungere una carta al mazzo

Implementa la funzione `addCard` che restituisce un mazzo con la nuova carta aggiunta.

```elm
addCard 8 ( Array.fromList [ 5, 9, 7, 1 ] )
    --> Array.fromList [ 5, 9, 7, 1, 8 ]
```

## 4. Rimuovere una carta dal mazzo

Implementa la funzione `removeCard` che restituisce un mazzo con la carta alla posizione `index` rimossa.
Se l'`index` indicato non è un indice valido nel mazzo, restituisci il mazzo originale.

```elm
removeCard 2 ( Array.fromList [ 3, 2, 6, 4, 8 ] )
    --> Array.fromList [ 3, 2, 4, 8 ]
removeCard 2 ( Array.fromList [ 3, 2 ] )
    --> Array.fromList [ 3, 2 ]
```

## 5. Contare il numero di carte pari nel mazzo

Implementa la funzione `evenCardCount` che conta il numero di carte pari nel mazzo.

```elm
evenCardCount (Array.fromList [ 3, 8, 4, 5, 1, 6, 10 ] )
    --> 4
```
