# Introduzione

## Le basi

Per informazioni più dettagliate su questi argomenti, visita la [pagina del concetto][exercism-concept].

### Sintassi generale

Il tag di apertura PHP `<?php` segna l'inizio del codice PHP.
Tutte le istruzioni devono terminare con un `;` per separare le istruzioni.

```php
<?php

$message = "Success!"; // Statement correctly ends with `;`
$message = "I fail." // PHP Parse error: syntax error, [...]
```

Per facilitare la lettura, tutti gli esempi di codice omettono il tag di apertura PHP `<?php`.

### I commenti

I commenti su una sola riga iniziano con `//`.

```php
// Single line comment
```

### Valori e variabili

Con l'operatore di assegnazione `=`, un valore può essere assegnato a una variabile.
I nomi delle variabili devono iniziare con il simbolo del dollaro `$` e seguire le [convenzioni di denominazione][exercism-concept-naming-conventions].

```php
$count = 1; // Assign value of 1

// Strings can be created by enclosing the characters
// within single `'` quotes or double `"` quotes.
$message = "Success!";
```

### Funzioni e metodi

Valori e variabili possono essere passati alle funzioni.
Gli argomenti di una funzione diventano nuove variabili che contengono i valori passati.
Le funzioni possono restituire qualsiasi valore usando la parola chiave `return`.

```php
function window_height($height)
{
    return $height + 10;
}

window_height(100);
// => 110
```

Le funzioni all'interno delle classi e delle loro istanze si chiamano metodi.
Per chiamare un metodo, il nome è preceduto dall'istanza e da `->`.
I metodi hanno accesso alla variabile speciale `$this`, che fa riferimento all'istanza corrente.

```php
<?php

class Calculator {
    public function sub($x, $y)
    {
        return $this->add($x, -$y); // Calls the method add() of the current instance
    }

    public function add($x, $y)
    {
        return $x + $y;
    }
}

$calculator = new Calculator(); // Creates a new instance of Calculator class
$calculator->sub(3, 1); // Calls the method sub() of the instance stored in $calculator
// => 2
```
