# Informazioni

Z3 è un linguaggio di soddisfacibilità modulo teorie (SMT), che si usa per verificare se equazioni o formule sono soddisfacibili, cioè se hanno una possibile soluzione.

Z3 si incontra soprattutto nella verifica del software, nella risoluzione di vincoli, nei problemi geometrici, nella sicurezza e in altre applicazioni che traggono vantaggio da calcoli matematici rapidi.

Z3 è stato creato dal gruppo Research in Software Engineering (RiSE) di Microsoft Research e, dal 2015, è diventato un linguaggio open source. Il repository GitHub open source di Z3 si trova su https://github.com/Z3Prover/z3.
