# Tipi di numeri

Crystal ha diversi tipi di numeri per vari scopi.
Per esempio, alcuni tipi sono più veloci ma hanno un intervallo di valori possibili più piccolo rispetto ad altri.
Altri hanno un intervallo di valori possibili più ampio ma sono più lenti.

In Crystal esistono sia tipi interi con segno che tipi interi senza segno.
I tipi interi con segno possono essere positivi o negativi.
I tipi interi senza segno possono essere solo positivi.

## Tipi interi con segno

Questi sono i [tipi interi con segno][int] in Crystal:

| Type     | Size (bits) | Range                                                                                                       |
| -------- | ----------- | ----------------------------------------------------------------------------------------------------------- |
| `Int8`   | 8           | -128 to 127                                                                                                 |
| `Int16`  | 16          | -32_768 to 32_767                                                                                           |
| `Int32`  | 32          | -2_147_483_648 to 2_147_483_647                                                                             |
| `Int64`  | 64          | -9_223_372_036_854_775_808 to 9_223_372_036_854_775_807                                                     |
| `Int128` | 128         | -170_141_183_460_469_231_731_687_303_715_884_105_728 to 170_141_183_460_469_231_731_687_303_715_884_105_727 |

I tipi più piccoli usano meno memoria e sono più veloci di quelli più grandi, ma hanno un intervallo di valori possibili più piccolo.

Quando sai che i valori rientreranno in un certo intervallo, la cosa migliore è usare il tipo più piccolo possibile per risparmiare memoria e migliorare le prestazioni.

Il tipo intero predefinito è `Int32`.
Per dichiarare un intero con un tipo specifico, puoi usare il nome del tipo come suffisso aggiungendo `<number>_I <bit>`.

```crystal
1_i8.class
# => Int8
```

Puoi usare il metodo `to_i<bit>` per convertire tra tipi interi diversi.
Il metodo `to_i` converte al tipo intero predefinito, `Int32`.

```crystal
1_i8.to_i16.class
# => Int16

2_i16.to_i.class
# => Int32
```

## Tipi interi senza segno

Questi sono i [tipi interi senza segno][uint] in Crystal:

`UInt8`, `UInt16`, `UInt32`, `UInt64`, `UInt128`

L'unica differenza tra interi con segno e interi senza segno è che quelli senza segno possono essere solo positivi.
Per dichiarare un intero senza segno con un tipo specifico, puoi usare il nome del tipo come suffisso aggiungendo `<number>_u<bit>`.
Puoi usare il metodo `to_u<bit>` per convertire tra tipi interi senza segno diversi.
Il metodo `to_u` converte al tipo intero senza segno predefinito, `UInt32`.

```crystal
1_u8.to_u16.class
# => UInt16
```

## Tipi in virgola mobile

Questi sono i tipi in virgola mobile in Crystal:

| Type      | Size (bits) | Range                |
| --------- | ----------- | -------------------- |
| `Float32` | 32          | 1.2E-38 to 3.4E+38   |
| `Float64` | 64          | 2.3E-308 to 1.7E+308 |

Esistono due [tipi in virgola mobile][float] diversi, uno è più preciso dell'altro.

Il tipo in virgola mobile predefinito è `Float64`.

Puoi usare il metodo `to_f<bit>` per convertire tra tipi in virgola mobile diversi.
Il metodo `to_f` converte al tipo in virgola mobile predefinito, `Float64`.

[float]: https://crystal-lang.org/api/latest/Float.html
[int]: https://crystal-lang.org/api/latest/Int.html
[uint]: https://crystal-lang.org/api/latest/UInt32.html
