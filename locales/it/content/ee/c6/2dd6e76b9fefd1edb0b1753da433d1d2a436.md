# Cicli for

L'iterazione è un concetto fondamentale della programmazione: ti permette di eseguire un blocco di codice più volte.
In Swift esistono due tipi di cicli: i [cicli `for-in`][for-loops] e i cicli `while`.
In questo capitolo vedremo come funzionano i cicli `for-in`.

I cicli for ti permettono di iterare su una sequenza di valori, prendendo ogni elemento a turno e assegnandolo a una variabile che scegli tu.
Swift ti permette di iterare su una varietà di sequenze, come intervalli, array e stringhe (e altri tipi che vedremo più avanti).
Quando ogni elemento della sequenza è stato iterato, il ciclo termina.

I cicli for si dichiarano usando la parola chiave `for`, seguita dal nome di una variabile, dalla parola chiave `in` e da una sequenza di valori su cui iterare.
La variabile dichiarata nel ciclo `for-in` è immutabile: non puoi cambiarne il valore all'interno del ciclo.
Ecco un esempio di ciclo `for-in` che itera su un array di numeri:

```swift
let numbers = [3, 10, 7, 11]

for number in numbers {
  print(number)
}
print("Done with numbers")

// prints:
// 3
// 10
// 7
// 11
// Done with numbers
```

~~~~exercism/note
La variabile `number` è dichiarata nel ciclo `for-in` ed è disponibile solo all'interno dello scope del ciclo.

```swift
let numbers = [3, 10, 7, 11]

for number in numbers {
    number + 1
}
number + 1
// Error: Use of unresolved identifier 'number'
```
~~~~

## Iterare su un intervallo

Puoi anche iterare su un intervallo di numeri usando un ciclo `for-in`.
Questo ti permette di eseguire un blocco di codice un numero specifico di volte: per esempio, l'intervallo `1...5` itererà sui numeri 1, 2, 3, 4 e 5, quindi il ciclo verrà eseguito 5 volte.
A volte potresti voler iterare sugli indici di una struttura dati come un array: in quel caso puoi usare un intervallo `0..<array.count`.

```swift
let numbers = [3, 10, 7, 11]

for i in 0..<numbers.count {
  print(numbers[i])
}

// prints:
// 3
// 10
// 7
// 11
```

## Iterare su una stringa

Puoi anche iterare su una stringa usando un ciclo `for-in`.
Questo ti permette di iterare su ogni carattere della stringa; nota in particolare che il tipo dichiarato nel ciclo è `Character`.

```swift
let message = "Hello!"

for character in message {
  print(character)
}

// prints:
// H
// e
// l
// l
// o
// !
```

## Variabili inutilizzate

Se non ti serve il valore della variabile nel ciclo, puoi usare un underscore `_` per ignorarlo.

```swift
let numbers = [3, 10, 7, 11]

for _ in numbers {
  print("Hello!")
}
```

## stride

Swift mette a disposizione anche una funzione `stride` che ti permette di creare una sequenza su un intervallo con un passo specifico.
Su questa sequenza puoi poi iterare con un ciclo `for-in`.
`stride` ha due forme: [`stride(from:to:by:)`][stride-to] e [`stride(from:through:by:)`][stride-through]. La prima è esclusiva, la seconda è inclusiva.

```swift
for i in stride(from: 0, to: 10, by: 2) {
  print(i)
}

// prints:
// 0
// 2
// 4
// 6
// 8
```

Nota che il parametro `to` è esclusivo, quindi il ciclo itera fino al numero che precede il parametro `to`; il parametro `through` invece è inclusivo, quindi in questo caso includerebbe anche il `10`.

[stride-to]: https://developer.apple.com/documentation/swift/stride(from:to:by:)
[stride-through]: https://developer.apple.com/documentation/swift/stride(from:through:by:)
[for-loops]: https://docs.swift.org/swift-book/documentation/the-swift-programming-language/controlflow/#For-In-Loops
