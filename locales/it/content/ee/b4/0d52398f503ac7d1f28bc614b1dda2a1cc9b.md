# Suggerimenti

## 1. Aggiungi una lingua all'array @Languages

- Vuoi modificare l'array `@Languages` per aggiungere una nuova lingua alla fine.

## 2. Rimuovi una lingua dall'array @Languages

- Vuoi modificare l'array `@Languages` per rimuovere l'ultima lingua.

## 3. Recupera la prima lingua dall'array @Languages

- Vuoi restituire il primo elemento dell'array `@Languages` usando `return`.

## 4. Recupera l'ultima lingua dall'array @Languages

- Vuoi restituire l'ultimo elemento dell'array `@Languages` usando `return`.

## 5. Recupera una fetta di lingue dall'array @Languages

- Vuoi una fetta dell'array `@Languages`.
- Ricorda che gli indici partono da 0. L'elemento `1` è l'indice `0`.

## 6. Verifica se una lingua esiste nell'array @Languages

- Vuoi restituire un valore vero, ad esempio `1`, o falso, ad esempio `0`, se la lingua indicata si trova nell'array `@Languages`.
