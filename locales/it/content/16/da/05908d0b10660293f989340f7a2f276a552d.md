# Formato delle stringhe

Oltre al metodo `String#%%`, un modo comune per creare stringhe in Ruby è usare l'[interpolazione di stringhe](http://ruby-for-beginners.rubymonstas.org/bonus/string_interpolation.html). Per esempio:

```ruby
# Rather than:
"One for %%s, one for me." %% %{name_variable}

# Consider:
"One for #{%{name_variable}}, one for me."
```
