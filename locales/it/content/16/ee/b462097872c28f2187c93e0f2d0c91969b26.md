# Introduzione

In Go, una `struct` è una sequenza di elementi con un nome, chiamati _campi_, e ogni campo ha un nome e un tipo.
Il nome di un campo deve essere univoco all'interno della struct.
Le struct si possono paragonare alle _classi_ del paradigma della programmazione orientata agli oggetti.

## Definire una struct

Per creare una nuova struct si usano le parole chiave `type` e `struct`, definendo esplicitamente il nome e il tipo dei campi.
Ad esempio, qui definiamo la struct `Shape`, che contiene il nome di una forma e la sua dimensione:

```go
type Shape struct {
    name string
    size int
}
```

I nomi dei campi nelle struct seguono la convenzione di Go: i campi il cui nome inizia con una lettera minuscola sono visibili solo al codice dello stesso package, mentre quelli il cui nome inizia con una lettera maiuscola sono visibili anche negli altri package.

## Creare istanze di una struct

Una volta definita la `struct`, per creare una nuova istanza devi definire i campi usando il loro nome, in qualsiasi ordine:

```go
s := Shape {
    name: "Square",
    size: 25,
}
```

Per leggere o modificare i campi di un'istanza, usa la notazione `.`:

```go
// Update the name and the size
s.name = "Circle"
s.size = 35
fmt.Printf("name: %s size: %d\n", s.name, s.size)
// Output: name: Circle size: 35
```

I campi a cui non viene assegnato un valore iniziale avranno il loro valore zero.
Ad esempio:

```go
s := Shape{name: "Circle"}
fmt.Printf("name: %s size: %d\n", s.name, s.size)
// Output: name: Circle size: 0
```

Puoi creare un'istanza di una `struct` senza usare i nomi dei campi, a patto di definire i campi _in ordine_:

```go
s := Shape {
	"Oval",
	20,
}
```

Tuttavia, questa sintassi è considerata _codice fragile_, perché può rompersi quando si aggiunge un campo, soprattutto se il nuovo campo è di un tipo diverso.
Nell'esempio seguente aggiungiamo un campo in più a `Shape`:

```go
type Shape struct {
	name        string
	description string // new field 'description' added
	size        int
}

s := Shape{
    "Circle",
    20,
}
// Since the second field of the struct is now a string and not an int,
// the compiler will throw an error when compiling the program:
// Output: cannot use 20 (type untyped int) as type string in field value
// Output: too few values in Shape{...}
```

## Funzioni «New»

A volte può essere utile avere delle funzioni che ci aiutano a creare istanze di una struct.
Per convenzione, queste funzioni di solito si chiamano `New` o hanno un nome che inizia con `New`, ma dato che sono normali funzioni, puoi dare loro il nome che preferisci.
Potrebbero ricordarti i costruttori di altri linguaggi, ma in Go sono normali funzioni.

Nell'esempio seguente, una di queste funzioni `New` viene usata per creare una nuova istanza di `Shape` e impostare automaticamente un valore predefinito per la `size` della forma:

```go
func NewShape(name string) Shape {
	return Shape{
		name: name,
		size: 100, //default-value for size is 100
	}
}

NewShape("Triangle")
// => Shape { name: "Triangle", size: 100 }

```

Usare le funzioni `New` può avere i seguenti vantaggi:

* la validazione dei valori forniti
* la gestione dei valori predefiniti
* dato che le funzioni `New` sono spesso dichiarate nello stesso package delle struct che inizializzano, possono inizializzare anche i campi privati della struct
