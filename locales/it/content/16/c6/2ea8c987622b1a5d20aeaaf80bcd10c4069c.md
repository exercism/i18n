# Introduzione

In Clojure esistono alcune strutture fondamentali per il [controllo di flusso](https://clojure.org/guides/learn/flow). `if` è l'espressione condizionale più importante: è formata da una condizione, un «then» e un «else» opzionale. `if` valuta solo il ramo selezionato dalla condizione.

```clojure
(if (even? 2) "even" "odd")
```

`cond` è una serie di test ed espressioni. Ogni test viene valutato in ordine e, per il primo test che risulta vero, l'espressione corrispondente viene valutata e restituita.

```clojure
(cond (= x 5) "Expression to evaluate when x equals 5"
      (> x 7) "Expression to evaluate when x is greater than 7"
      :else   "Expression to evaluate in all other cases")
```
