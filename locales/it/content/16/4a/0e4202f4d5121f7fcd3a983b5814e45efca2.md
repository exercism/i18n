# Introduzione

Molti programmi hanno bisogno di valori (_apparentemente_) casuali per simulare eventi del mondo reale.

Tra gli esempi comuni e familiari ci sono:
- Il lancio di una moneta: un valore casuale da `('Heads', 'Tails')`.
- Il lancio di un dado: un numero intero casuale da 1 a 6.
- Mescolare un mazzo di carte: un ordine casuale di un array di carte.
- La creazione di alberi e cespugli in una simulazione grafica 3D.

Generare valori _davvero_ casuali con un computer è una [sfida tecnica sorprendentemente difficile][truly-random], perciò potresti vedere questi risultati chiamati «pseudocasuali».

In pratica, una libreria ben progettata come il modulo [`random`][random] della libreria standard di Python è veloce, flessibile e produce risultati più che sufficienti per la maggior parte delle applicazioni di modellazione, simulazione e giochi.

In questa breve introduzione mostriamo le quattro funzioni più usate del modulo.
Ti invitiamo a esplorare la documentazione completa di [`random`][random], perché ci sono molti strumenti e opzioni.

Prima di poter usare gli strumenti del modulo `random`, devi prima importarlo:

```python
>>> import random

# Choose random integer from a range
>>> random.randrange(1000)
360

>>> random.randrange(-1, 500)
228

>>> random.randrange(-10, 11, 2)
-8

# Choose random integer between two values (inclusive)
>>> random.randint(5, 25)
22

```

Per evitare di digitare il nome del modulo, puoi importare funzioni specifiche per nome:

```python
>>> from random import choice, choices

# Using choice() to pick Heads or Tails 10 times
>>> tosses = []
... for side in range(10):
...    tosses.append(choice(['H', 'T']))    

>>> print(tosses)
['H', 'H', 'H', 'H', 'H', 'H', 'H', 'T', 'T', 'H']


# Using choices() to pick Heads or Tails 8 times
>>> picks = []
... picks.extend(choices(['H', 'T'], k=8))
... print(picks)
['T', 'H', 'H', 'T', 'H', 'H', 'T', 'T']
```



## `randrange()` e `randint()`

Come mostrato nel primo esempio qui sopra, la funzione `randrange()` ha tre forme:

1. `randrange(stop)` restituisce un numero intero `n` tale che `0 <= n < stop`
2. `randrange(start, stop)` restituisce un numero intero `n` tale che `start <= n < stop`
3. `randrange(start, stop, step)` restituisce un numero intero `n` tale che `start <= n < stop`
    e `n` appartiene alla sequenza `start, start + step, start + 2*step...`

Nel caso più comune, in cui `step == 1`, `randint(a, b)` può essere più comodo e leggibile.
I possibili risultati di `randint()` _includono_ il limite superiore, quindi `randint(a, b)` equivale a usare `randrange(a, b+1)`.



## `choice()` e `choices()`

Queste due funzioni presuppongono che tu parta da una [sequenza][sequence-types] o da un altro contenitore.
Di solito si tratta di un `list`, oppure, con alcune limitazioni, di un `tuple` o di un `set` (_un `tuple` è immutabile e un `set` non è ordinato_).

La funzione `choice()` restituisce un elemento scelto a caso da una sequenza data, mentre `choices()` restituisce un numero specificato di elementi (`k`) scelti a caso da una sequenza data.
Negli esempi mostrati sopra abbiamo ipotizzato una moneta equa, con uguale probabilità di testa o croce, ma si possono specificare anche dei pesi.

Per esempio, se un sacchetto contiene 10 palline rosse e 15 palline verdi e vogliamo estrarne una a caso:


```python
>>> random.choices(['red', 'green'], [10, 15])
['red']
```
