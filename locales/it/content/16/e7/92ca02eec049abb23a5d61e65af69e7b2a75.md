# Introduzione

Il modulo `gleam/order` della libreria standard di Gleam contiene il tipo `Order`, che serve a confrontare i valori.

La definizione di `Order` è questa:

```gleam
pub type Order {
  Gt
  Eq
  Lt
}
```

Il tipo ha tre varianti, ciascuna delle quali rappresenta la relazione tra un valore e un altro valore:

- `Gt` - il valore è _più grande_ dell'altro valore.
- `Eq` - il valore è _uguale_ all'altro valore.
- `Lt` - il valore è _più piccolo_ dell'altro valore.

Se un tipo di dato può essere confrontato in base alla grandezza, è comune che il modulo definisca una funzione `compare` che restituisce un valore di tipo `Order`. Per esempio, `gleam/float` e `gleam/int` definiscono funzioni `compare` che operano rispettivamente sui numeri in virgola mobile e sugli interi.

```gleam
int.compare(1, 2)
// -> Lt

int.compare(2, 2)
// -> Eq

float.compare(1.0, 2.0)
// -> Lt
```

Le funzioni di ordinamento come `list.sort` di solito accettano una funzione che restituisce un valore di tipo `Order`, così chi la chiama può definire come ordinare l'array.

```gleam
list.sort([3, 7, 3, 1], by: int.compare)
// -> [1, 3, 3, 7]
```
