# Istruzioni

Salve, agente Doppio-Zero0111.

La sua missione, se deciderà di accettarla, è scrivere un paio di strumenti per aiutarla a infiltrarsi nel quartier generale dell'UMBRA (Unione Minacce Bastarde Realmente Atroci) e recuperare i piani del loro ultimo, atroce piano. Per portare a termine questa missione le serviranno due strumenti.

## 1. Proteggere i piani segreti recuperati con una password

Una volta entrata in possesso dei piani segreti, dovrà proteggerli in modo che solo chi conosce la password possa recuperarli.

Per farlo, dovrà implementare la funzione `protectSecret(_ secret: String, withPassword password: String) -> (String) -> String`.
Questa funzione restituirà un'altra funzione che accetta come input delle possibili stringhe di password.
Se la password inserita è corretta, la nuova funzione restituisce il segreto nascosto; se invece la password non è corretta, la funzione restituisce "Sorry. No hidden secrets here."

```swift
let secretFunction = protectSecret("Steal the world's supply of french fries!", withPassword: "5up3r53cr37")

secretFunction("Open sesame")
// Returns "Sorry. No hidden secrets here."

secretFunction("5up3r53cr37")
// Returns "Steal the world's supply of french fries!"
```

## 2. Generare una combinazione per aprire la loro cassaforte

Abbiamo scoperto che l'UMBRA basa tutte le combinazioni delle sue casseforti sul numero della stanza in cui si trovano.
Le combinazioni delle casseforti si generano applicando ripetutamente una funzione speciale al numero della stanza.
Quindi il primo numero della combinazione deriverà dall'applicazione della funzione al numero della stanza, il secondo dall'applicazione della funzione al primo numero, e il terzo dall'applicazione della funzione al secondo numero.

Tuttavia, l'UMBRA cambia regolarmente la funzione usata per generare le combinazioni, quindi il tuo strumento dovrà accettare sia un numero di stanza sia la funzione appropriata per generare la combinazione.

Implementa la funzione `generateCombination(forRoom room: Int, usingFunction f: (Int) -> Int) -> (Int, Int, Int)` per generare la combinazione che ti servirà.

```swift
func makeCombo(_ x: Int) -> Int {
  (x * 13) % 256
}

generateCombination(forRoom: 227, usingFunction: makeCombo)
// Returns (135, 219, 31)
```
