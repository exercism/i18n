# Suggerimenti

## 1. Genera un pianeta casuale

- Java non fornisce una funzione per scegliere a caso un elemento da una collezione.
- Ricorda che puoi recuperare un elemento da un array tramite il suo indice, che è un numero intero.

## 2. Genera un numero di registrazione casuale per un'astronave

- La classe `java.util.Random` fornisce un metodo per generare un `int` casuale compreso tra 0 e un valore massimo dato.

## 3. Genera una data stellare casuale

- Il metodo della classe `java.util.Random` per generare un `double` casuale restituisce sempre un numero compreso tra `0.0` e `1.0`.
