# Appendice alle istruzioni

## Parole

`smallest` e `largest` restituiscono ciascuno **due** valori sullo stack: il valore palindromo (oppure `f` se non ne esiste alcuno nell'intervallo) e un array di coppie di fattori.

- `smallest ( mn mx -- value factors )`
- `largest  ( mn mx -- value factors )`

Ogni coppia in `factors` è un array di 2 elementi `{ a b }`. Lancia la stringa `"min must be <= max"` se `mn > mx`.
