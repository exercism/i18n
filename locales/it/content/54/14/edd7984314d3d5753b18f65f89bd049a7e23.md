# Introduzione

In Julia, una `String` è una sequenza finita e immutabile di caratteri [Unicode](https://en.wikipedia.org/wiki/Unicode), con codifica [UTF-8](https://en.wikipedia.org/wiki/UTF-8).

Un letterale `String` è una sequenza di caratteri racchiusa tra virgolette doppie:

```julia-repl
julia> "Christopher"
"Christopher"
```

Le stringhe si possono concatenare con l'operatore `*`:

```julia-repl
julia> "Christopher" * " " * "Paolini"
"Christopher Paolini"
```

~~~~exercism/advanced
Se sei curioso di sapere perché Julia usa `*` invece di `+` per concatenare le stringhe, dai un'occhiata al [Julia Manual](https://docs.julialang.org/en/v1/manual/strings/#man-concatenation).
~~~~

Alcuni caratteri speciali vanno preceduti da una barra rovesciata:

```julia-repl
julia> println("\t or spaces?")
         or spaces?
```

Di default, Julia include molte funzioni utili per lavorare con le stringhe:

```julia-repl
julia> lowercase("TEST")
"test"

julia> titlecase("TEST")
"Test"
```
