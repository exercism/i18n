# Informazioni

I numeri in virgola mobile sono numeri con una o più cifre dopo il separatore decimale.

```gleam
let float = 3.45
// -> 3.45
```

Anche i numeri in virgola mobile hanno il proprio insieme di operatori.

```gleam
1.0 +. 1.4 // -> 2.4
5.0 -. 1.5 // -> 3.5
5.0 /. 2.0 // -> 2.5
3.0 *. 3.1 // -> 9.3

2.0 >. 1.0  // -> True
2.0 <. 1.0  // -> False
2.0 >=. 1.0 // -> True
2.0 <=. 1.0 // -> False
```

Si possono aggiungere anche gli underscore ai numeri in virgola mobile per maggiore chiarezza.

```gleam
1_000_000.0 // One million
```

Si può usare anche la notazione scientifica con i numeri in virgola mobile:

```gleam
1.01e3 // -> 1010
15.1e-3 // -> 0.0151
```
