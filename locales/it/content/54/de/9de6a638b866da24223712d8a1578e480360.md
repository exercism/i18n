# Istruzioni

Da appassionato di scacchi, ti piacerebbe scrivere la tua versione del gioco. Sì, online ci sono già tante implementazioni di scacchi, ma la tua sarà unica!

Ma prima di dare libero sfogo alla fantasia, devi occuparti delle basi. Iniziamo generando la scacchiera.

Ogni casella della scacchiera è identificata da una coppia lettera-numero. Le colonne verticali di caselle, chiamate file, sono contrassegnate dalla A alla H. Le righe orizzontali di caselle, chiamate rank, sono numerate da 1 a 8.

## 1. Definisci l'intervallo dei rank

Implementa la funzione `rank_range()`. Deve restituire un intervallo di numeri interi, da 1 a 8.

```julia-repl
julia> rank_range()
# output omitted
```

## 2. Definisci l'intervallo dei file

Implementa la funzione `file_range()`. 
Deve restituire un intervallo di caratteri, dalla lettera maiuscola A alla lettera maiuscola H.

```julia-repl
julia> file_range()
# output omitted
```

## 3. Trasforma l'intervallo dei rank in un array di rank

Implementa la funzione `ranks()`. Deve restituire un array di numeri interi, da 1 a 8. 
Non scrivere l'array a mano: generalo dall'intervallo restituito dalla funzione `rank_range()`.

```julia-repl
julia> ranks()
[1, 2, 3, 4, 5, 6, 7, 8]
```

## 4. Trasforma l'intervallo dei file in un array di file

Implementa la funzione `files`. Deve restituire un array di caratteri, da 'A' a 'H'. 
Non scrivere l'array a mano: generalo dall'intervallo restituito dalla funzione `file_range()`.

```julia-repl
julia> files()
['A', 'B', 'C', 'D', 'E', 'F', 'G', 'H']
```
