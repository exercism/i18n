# Informazioni

Mentre il modificatore `readonly` impedisce che il valore o il riferimento in un campo venga sovrascritto, non offre alcuna protezione per i membri di un tipo di riferimento.

```csharp
readonly List<int> ints = new List<int>();

void Foo()
{
    ints.Add(1);    // ok
    ints = new List<int>(); // fails to compile
}
```

Per garantire che tutti i membri di un tipo di riferimento siano protetti, i campi possono essere resi `readonly` e le proprietà automatiche possono essere definite senza una funzione di accesso `set`.

La libreria di classi di base (BCL) fornisce alcune versioni di sola lettura delle collezioni quando c'è la necessità di impedire che i membri di una collezione vengano aggiornati. Questi si presentano sotto forma di wrapper:

- [`ReadOnlyDictionary<T>`][ReadOnlyDictionary]
- [`ReadOnlyCollection<T>`][ReadOnlyCollection]

[ReadOnlyDictionary]: https://docs.microsoft.com/en-us/dotnet/api/system.collections.objectmodel.readonlydictionary-2
[ReadOnlyCollection]: https://docs.microsoft.com/en-us/dotnet/api/system.collections.objectmodel.readonlycollection-1
