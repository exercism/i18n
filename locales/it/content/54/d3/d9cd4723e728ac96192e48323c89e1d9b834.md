# Approfondimento

In Gleam un'espressione `case` si può usare per eseguire del codice in modo condizionale. Con un'espressione `case` un valore può essere confrontato con uno o più «pattern». Un esempio di tale pattern è il «pattern letterale», che confronta un valore con un valore letterale (ad esempio `1` o `"hello"`).

Le espressioni `case` si scrivono con la parola chiave `case`:

```gleam
pub fn describe(number: Int) -> String {
  case number {
    0 -> "Zero"
    1 -> "One"
  }
}
```

Anche se all'apparenza può sembrare un'istruzione `switch` di altri linguaggi, il pattern matching dà il meglio di sé quando si usano anche altri pattern. Uno di questi è il «pattern variabile», che permette di assegnare un valore a una variabile. In questo esempio, alla variabile `i` verrà assegnato il valore di `number` se questo non è `0`:

```gleam
pub fn describe(number: Int) -> String {
  case number {
    0 -> "Zero"
    i -> "Non zero"
  }
}
```

In alcuni casi potresti voler aggiungere una condizione ulteriore a un pattern. Questa è nota come «guardia» (clausola) e si può aggiungere usando la parola chiave `if`:

```gleam
pub fn describe(number: Int) -> String {
  case number {
    0 -> "Zero"
    i if i < 0 -> "Negative number"
  }
}
```

Per motivi di prestazioni, nelle guardie sono ammessi solo gli operatori matematici e booleani di base: non è possibile usare altre funzioni.

Nell'esempio qui sopra, non tutti i possibili input hanno un pattern corrispondente. Il compilatore se ne accorge e produce un errore. Questa si chiama «verifica di esaustività». Per risolvere l'avviso, bisogna gestire tutti i casi. A questo scopo si può usare il «pattern jolly», che corrisponde a qualsiasi valore:

```gleam
pub fn describe(number: Int) -> String {
  case number {
    0 -> "Zero"
    i if i < 0 -> "Negative number"
    _ -> "Positive number"
  }
}

// No compiler error
```

Le espressioni `case` confrontano un valore con ogni pattern, dall'alto verso il basso, finché non trovano un pattern corrispondente ed eseguono la logica associata a quel pattern. L'ordine dei pattern conta!
