# Introduzione

## Operatori di confronto

Gli operatori di confronto sono simili a quelli di molti altri linguaggi.

Per l'uguaglianza, gli operatori sono `==` (uguale) e `!=` (diverso).

```Kotlin
val txt = "abc"
txt == "abc" // => true
txt != "abc" // => false
```

Anche gli operatori maggiore/minore sono convenzionali.

```Kotlin
1 < 3 // => true
3 > 3 // => false
3 <= 3 // => true
4 >= 3 // => true
```

## Diramazioni con `if`

Questa è la forma completa di un'espressione `if`:

```Kotlin
if (conditional1) {
//    something...
} else if (conditional2) {
//    something...
} else {
//    something...
}
```

- Le parentesi tonde `()` attorno a ogni condizione sono obbligatorie.
- Una condizione deve dare come risultato un valore booleano, `true` o `false`.
  Kotlin non ha il concetto di «truthy» e «falsy» che si trova in alcuni linguaggi.
- Le parentesi graffe `{}` sono facoltative se c'è una sola espressione.
- Sia `else if` che `else` sono facoltativi, e possono esserci più blocchi `else if`.

L'espressione `if` può anche essere usata per «scegliere» un valore:

```Kotlin
val number = 100000
val description = if (number > 100) "number is over 100" else "number is less than 100"
// => description = "number is over 100"
```

## Alternative?

Per scelta deliberata, Kotlin _non_ ha l'operatore ternario `? :` che si trova in Java.
Si preferisce una forma concisa di `if ... else`:

```Kotlin
return if (isOK) goodValue else badValue
```
