# Istruzioni

Sei di nuovo al lavoro sul sistema ORM (Object Relationship Mapping) introdotto in [exercise:csharp/object-relational-mapping]().

L'analisi sull'utilizzo del nostro ORM mostra che il 95% delle transazioni viene eseguito all'interno di un unico metodo chiamante, e si è deciso che sarebbe più appropriato avere un unico metodo ORM che aprisse, scrivesse e confermasse una transazione.

Il database ha i seguenti metodi di istanza:

- `Database.BeginTransaction()` avvia una transazione sul database.
- `Database.Write(string data)` scrive i dati sul database all'interno della transazione. Se riceve dati non validi viene lanciata un'eccezione. Un tentativo di chiamare questo metodo senza che sia stato chiamato `BeginTransaction()` provoca il lancio di un'eccezione. Se ha successo, lo stato interno del database passa a `DataWritten`.
- `Database.EndTransaction()` conferma la transazione sul database. Può lanciare un'eccezione se non riesce a chiudere la transazione o se `Database.BeginTransaction()` non era stato chiamato.
- Una chiamata a `Database.Dispose()` ripulisce il database se durante una transazione viene lanciata un'eccezione. Questo porta lo stato del database a `Closed`.

## 1. Scrivi sul database

Implementa il metodo `Orm.Write()` per avviare una transazione sul database, scrivere i dati ricevuti e confermare la transazione. Tutte le eccezioni, compresa `InvalidOperationException`, devono poter essere propagate al chiamante senza registrarle in un log né intervenire in alcun altro modo.

```csharp
Database db = new Database();
Orm orm = new Orm(db);
orm.Write("good write");
// => database has an internal state of State.Closed
orm.Write("bad write");
// => an exception is thrown but database is left with an internal state of State.Closed
orm.Write("bad commit");
// => an exception is thrown but database is left with an internal state of State.Closed
```

## 2. Scrivi sul database e restituisci al chiamante un'indicazione sull'esito della scrittura

Sono passati alcuni mesi da quando è stato introdotto `Orm.Write()` e nel team c'è divisione. Molti sviluppatori vorrebbero che l'_ORM_ gestisse gli errori quando viene lanciata un'eccezione e restituisse semplicemente al chiamante un'indicazione di successo.

Implementa il metodo `Orm.WriteSafely()` per avviare una transazione sul database, scrivere i dati ricevuti e confermare la transazione (come sopra). Dovrebbe restituire `true` se la _scrittura_ è andata a buon fine, altrimenti `false`. Non cercare di registrare l'eccezione in un log.

```csharp
Database db = new Database();
Orm orm = new Orm(db);
orm.WriteSafely("good write");
// => true
orm.WriteSafely("bad write");
// => false
orm.WriteSafely("bad commit");
// => false
```
