# Istruzioni

In questo esercizio aiuterai a gestire le attività quotidiane di una piccola panetteria usando i costrutti di controllo di Cairo.

## 1. Calcola il totale dell'ordine

Implementa `calculate_total`, che calcola il costo di un ordine in base al tipo di dolce e alla quantità:

- Croissant: 3 monete ciascuno
- Muffin: 2 monete ciascuno  
- Cookie: 1 moneta ciascuno

```rust
calculate_total(Pastry::Croissant, 4) // Returns: 12 (4 * 3)
calculate_total(Pastry::Cookie, 10)   // Returns: 10 (10 * 1)
```

## 2. Applica gli sconti sulla quantità

Implementa `apply_discount`, che applica gli sconti in base al totale dell'ordine.
Applica lo sconto percentuale al totale, poi arrotonda per difetto alla moneta intera più vicina (floor).

- Ordini ≥ 20 monete: sconto del 10%
- Ordini ≥ 10 monete: sconto del 5%
- Ordini < 10 monete: nessuno sconto

```rust
apply_discount(25) // Returns: 22
apply_discount(15) // Returns: 14
apply_discount(8)  // Returns: 8
```

## 3. Crea il programma di cottura

Implementa `baking_schedule`, che crea un piano di cottura giornaliero.
La panetteria cuoce in lotti di 5 ordini all'ora:

```rust
baking_schedule(18) // Returns: [5, 5, 5, 3] (3 full batches + 3 remaining)
baking_schedule(10) // Returns: [5, 5] (2 full batches)
baking_schedule(3)  // Returns: [3] (1 partial batch)
```

Usa i costrutti di controllo appropriati (`if`/`else`, `loop`) per risolvere ogni problema in modo efficiente.
