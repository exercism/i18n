# Appendice alle istruzioni

## Responsabilità di Roc e dell'host

Nel codice Roc di solito ci concentriamo sulla logica di business, mentre la piattaforma gestisce la concorrenza e lo stato condiviso.
Quindi, in questo esercizio devi solo implementare le operazioni sul conto in `BankAccount.roc`, senza doverti preoccupare della concorrenza.
I conti partono chiusi, una nuova apertura azzera il saldo, e i depositi e i prelievi devono essere positivi.

## Demo opzionale del server

Il file `bank-account-demo.roc` incluso mostra come si può usare l'implementazione in un piccolo servizio web.
Puoi leggerlo nell'editor, ma è indipendente dai test e non fa parte della soluzione.

Per eseguire la demo, devi [installare Roc](https://www.roc-lang.org/install/) sulla tua macchina, installare l'[Exercism CLI](https://exercism.org/cli-walkthrough), e poi eseguire questo comando in un terminale:

```sh
exercism download --exercise=bank-account --track=roc
```

Poi implementa `BankAccount.roc` e provalo con il seguente comando (cambia il percorso di download stampato dalla CLI se è diverso dal percorso qui sotto):

```sh
cd ~/Exercism/roc/bank-account
roc test bank-account-test.roc
```

Quando tutti i test passano, puoi avviare il server della demo con il seguente comando:

```sh
roc bank-account-demo.roc
```

Il server usa la [piattaforma basic-webserver](https://github.com/roc-lang/basic-webserver) e il suo supporto SQLite integrato (Roc scarica la piattaforma alla prima esecuzione).
Non serve un server di database separato.
Il server ascolta su `http://127.0.0.1:8000` e crea `bank-account-demo.db` nella directory corrente (imposta `DB_PATH` per usare un file di database diverso).
Ferma il server con Ctrl-C.
I dati sopravvivono ai riavvii.

In un altro terminale, puoi chiamare il servizio web usando `curl` (su Windows, usa sempre `curl.exe` per evitare l'alias `curl` di PowerShell).
Per esempio, ecco come aprire il conto #123, depositare 50, prelevare 10 e controllare il saldo:

```sh
curl -X POST http://127.0.0.1:8000/accounts/123/open
curl -X POST http://127.0.0.1:8000/accounts/123/deposit/50
curl -X POST http://127.0.0.1:8000/accounts/123/withdraw/10
curl http://127.0.0.1:8000/accounts/123/balance
```

Il saldo è `40`.
Gli ID dei conti e gli importi devono essere interi senza segno.
Le operazioni di aggiornamento restituiscono `OK` in caso di successo o un errore dell'implementazione del conto in caso di fallimento.
Per chiudere il conto #123:

```sh
curl -X POST http://127.0.0.1:8000/accounts/123/close
```

Per provare richieste concorrenti su Linux/macOS, usa un ID di conto nuovo e invia 100 depositi da otto client:

```sh
curl -X POST http://127.0.0.1:8000/accounts/456/open
seq 100 | xargs -P 8 -I '{}' curl --fail --silent --show-error -X POST http://127.0.0.1:8000/accounts/456/deposit/1
curl http://127.0.0.1:8000/accounts/456/balance
```

Su Windows, usa [PowerShell 7+](https://learn.microsoft.com/powershell/scripting/install/installing-powershell-on-windows) per l'esempio in parallelo:

```powershell
curl.exe -X POST http://127.0.0.1:8000/accounts/456/open
1..100 | ForEach-Object -Parallel { curl.exe --fail --silent --show-error -X POST http://127.0.0.1:8000/accounts/456/deposit/1 } -ThrottleLimit 8
curl.exe http://127.0.0.1:8000/accounts/456/balance
```

Tutti i depositi dovrebbero andare a buon fine e il saldo dovrebbe essere `100`.

## Come la demo gestisce la concorrenza

Ogni richiesta legge il conto, chiama le funzioni Roc e salva il risultato all'interno di una transazione `Immediate` di SQLite.
Le operazioni fallite vengono annullate senza modificare il conto.
SQLite consente un solo scrittore alla volta, il che impedisce alle richieste concorrenti di sovrascrivere gli aggiornamenti l'una dell'altra (anche tra conti diversi).

Nota: l'esercizio usa `U64`, ma la demo memorizza i saldi come interi SQLite e rifiuta gli aggiornamenti che superano il valore massimo di `I64` (`9223372036854775807`).

Per un esempio di esecuzione di calcoli indipendenti in parallelo, prova l'esercizio [Frequenza delle lettere in parallelo](https://exercism.org/tracks/roc/exercises/parallel-letter-frequency).
