# Approfondimento

Quando scriviamo funzioni in Elixir, possiamo usare uno [stile assertivo][assertive-style] con il [pattern matching][pattern-match-doc]:

```elixir
def read_file() do
  {:ok, contents} = File.read("hello.txt")
  contents
end
```

- Il pattern matching si esegue in modo esplicito con l'operatore di match, [`=/2`][match-op].

  - La corrispondenza riesce quando la _forma_ dei dati sul lato sinistro dell'operatore corrisponde a quella dei dati sul lato destro.
  - Quando la corrispondenza riesce, le variabili a sinistra vengono legate ai valori a destra.
  - Usare un underscore, `_`, ci permette di ignorare i valori in quelle posizioni.

    ```elixir
    {:ok, number, _} = {:ok, 5, [4.5, 6.3]}
    number
    # => 5 is bound to this variable
    ```

  - [L'operatore pin `^`][getting-started-pin-operator] permette di evitare di rilegare una variabile e di fare invece pattern matching sul suo valore esistente.

    ```elixir
    number = 10
    {:ok, ^number, _} = {:ok, 5, [4.5, 6.3]}
    # => ** (MatchError) no match of right hand side value: {:ok, 5, [4.5, 6.3]}
    ```

- Il pattern matching può avvenire anche nella testa di una clausola di funzione, così che solo gli argomenti che corrispondono al pattern chiamino la funzione.
- È possibile legare variabili in un pattern match di una clausola di funzione.

  ```elixir
  defmodule Example do
    def named_function(:a = atom_variable) do
      {atom_variable, 1}
    end
  end

  Example.named_function(:a)
  # => {:a, 1}
  # The first function clause matches, so it is invoked

  Example.named_function(:b)
  # => ** (FunctionClauseError) no function clause matching in Example.named_function/1
  ```
