# Istruzioni

In questo esercizio, dovrai tradurre alcune regole del classico gioco Pac-Man in funzioni Gleam.

Hai quattro regole da tradurre, tutte legate agli stati di gioco.

> Non preoccuparti di come vengono ricavati gli argomenti, concentrati solo sul combinarli per restituire il risultato desiderato.

## 1. Definisci se Pac-Man mangia un fantasma

Definisci la funzione `eat_ghost` che accetta due argomenti (_se Pac-Man ha una pillola energetica attiva_ e _se Pac-Man sta toccando un fantasma_) e restituisce un valore booleano se Pac-Man è in grado di mangiare il fantasma. La funzione deve restituire `True` solo se Pac-Man ha una pillola energetica attiva e sta toccando un fantasma.

```gleam
eat_ghost(False, True)
// -> False
```

## 2. Definisci se Pac-Man fa punti

Definisci la funzione `score` che accetta due argomenti (_se Pac-Man sta toccando una pillola energetica_ e _se Pac-Man sta toccando un pallino_) e restituisce un valore booleano se Pac-Man ha fatto punti. La funzione deve restituire `True` se Pac-Man sta toccando una pillola energetica o un pallino.

```gleam
score(True, True)
// -> True
```

## 3. Definisci se Pac-Man perde

Definisci la funzione `lose` che accetta due argomenti (_se Pac-Man ha una pillola energetica attiva_ e _se Pac-Man sta toccando un fantasma_) e restituisce un valore booleano se Pac-Man perde. La funzione deve restituire `True` se Pac-Man sta toccando un fantasma e non ha una pillola energetica attiva.

```gleam
lose(False, True)
// -> True
```

## 4. Definisci se Pac-Man vince

Definisci la funzione `win` che accetta tre argomenti (_se Pac-Man ha mangiato tutti i pallini_, _se Pac-Man ha una pillola energetica attiva_ e _se Pac-Man sta toccando un fantasma_) e restituisce un valore booleano se Pac-Man vince. La funzione deve restituire `True` se Pac-Man ha mangiato tutti i pallini e non ha perso in base agli argomenti definiti nella parte 3.

```gleam
win(False, True, False)
// -> False
```
