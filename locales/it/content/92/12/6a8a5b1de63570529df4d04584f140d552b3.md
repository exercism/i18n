# Appendice alle istruzioni

## Lo stub

`src/TreeBuilding.hs` contiene già una soluzione funzionante che supera tutti i test.
È lenta e difficile da leggere; il tuo compito è migliorarla senza far fallire i test.

`buildTree` restituisce `Nothing` quando i record non formano un albero valido.

## Cambiare la rappresentazione

I test non usano mai direttamente i costruttori di `Tree`.
Invece, costruiscono gli alberi attesi con la funzione

```haskell
node :: Int -> [Tree] -> Tree
```

dove `node i children` è il nodo con id `i` e i figli indicati, in ordine crescente di id.

Questo significa che sei libero di cambiare il modo in cui `Tree` è rappresentato, per esempio in questo modo:

```haskell
import qualified Data.Tree as T

type Tree = T.Tree Int

node :: Int -> [Tree] -> Tree
node = T.Node
```

purché `Tree` abbia ancora le istanze `Eq` e `Show` e `node` mantenga il suo significato.
Se usi una libreria come `containers`, ricordati di aggiungerla alle `dependencies` in `package.yaml`.
