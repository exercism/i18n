# Introduzione

## Set

Un [`Set`][set-docs] è una collezione non ordinata che, a differenza di `List`, ha la garanzia di non contenere valori duplicati.

Il parametro di tipo generico dell'interfaccia `Set` indica il tipo degli elementi contenuti nel `Set`:

```java
Set<Integer> ints = Set.of(1, 2, 3);
Set<String> strings = Set.of("alpha", "beta", "gamma");
Set<Object> mixed = Set.of(1, false, "foo");
```

Nota che il metodo `Set.of()` crea un'istanza di `Set` [_non modificabile_][unmodifiable-set-docs].
Se provi a chiamare metodi come `add` e `remove` su questa istanza, otterrai un'eccezione in fase di esecuzione.

Per creare un `Set` modificabile, devi istanziare una classe che implementa l'interfaccia `Set`.
La classe integrata più usata che implementa questa interfaccia è la classe [`HashSet`][hashset-docs].

```java
Set<Integer> ints = new HashSet<>();
```

L'interfaccia `Set` estende le interfacce [`Collection`][collection-docs] e [`Iterable`][iterable-docs], e quindi condivide molti metodi con altri tipi di collezioni.
Una differenza notevole rispetto all'interfaccia `Collection`, però, è che metodi come `add` e `remove` restituiscono un `boolean` (invece di `void`) che indica se l'elemento era contenuto nel set nel momento in cui è stato chiamato il metodo:

```java
Set<Integer> set = new HashSet<>();
set.add(1);
// => true
set.add(2);
// => true
set.add(1);
// => false
set.size();
// => 2
set.contains(1);
// => true
set.contains(3);
// => false
set.remove(3);
// => false
set.remove(2);
// => true
set.size();
// => 1
```
