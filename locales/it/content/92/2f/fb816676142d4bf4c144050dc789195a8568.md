# Il tipo booleano

In Cairo, il tipo booleano è essenziale per le operazioni logiche e le istruzioni condizionali. In Cairo, i booleani hanno la dimensione di una `felt252`: un uso efficiente dello spazio, senza rinunciare alla semplicità della logica vero/falso.

Il tipo booleano in Cairo si specifica con la parola chiave `bool`. Questo permette di dichiarare e manipolare variabili booleane all'interno del linguaggio. Vediamo un esempio:

```rust
fn main() {
    let t = true;
    let f: bool = false; // with explicit type annotation
}
```

In questo esempio vengono dichiarate due variabili booleane. Alla variabile `t` viene assegnato il valore `true` ed è dichiarata implicitamente come tipo booleano, mentre la variabile `f` è annotata esplicitamente con il tipo `bool` e riceve il valore `false`.

Un aspetto importante da tenere presente è che, quando si dichiara una variabile booleana in Cairo, è obbligatorio usare come valore il letterale `true` o `false`. Questo significa che i letterali interi, come `0` o `1`, non possono sostituire `false` o `true`. Il rispetto rigoroso di questa regola garantisce la sicurezza dei tipi e previene potenziali errori logici nello sviluppo di smart contract.

## Gli operatori booleani in Cairo

- `||` (OR logico): restituisce `true` se almeno uno degli operandi è `true`.
- `&&` (AND logico): restituisce `true` se entrambi gli operandi sono `true`.
- `!` (NOT logico): restituisce il valore booleano opposto dell'operando.

## Codice di esempio

Il frammento di codice seguente mostra come usare i tipi booleani in Cairo. Vediamo la dichiarazione di variabili booleane, l'assegnazione di espressioni booleane e l'uso delle asserzioni per verificare la correttezza della logica booleana:

```rust
fn main() {
    // Declaration of Boolean variables
    let t: bool = true;
    let f: bool = false;

    // Boolean expression evaluation
    let true_expr = 5 == 5; // true
    let false_expr = 7 == 5; // false

    // Using Boolean operators
    let or_expr = t || f; // true || false => true
    let and_expr = t && f; // true && false => false
    let not_expr = !f; // !false => true

    // Assertions to verify the correctness
    assert(t == true_expr, 'this should be true'); // t == true
    assert(f == false_expr, 'this should be false'); // f == false
    assert(or_expr == true, 'this should be true for OR'); // true
    assert(and_expr == false, 'this should be false for AND'); // false
    assert(not_expr == true, 'this should be true for NOT'); // true
}
```
