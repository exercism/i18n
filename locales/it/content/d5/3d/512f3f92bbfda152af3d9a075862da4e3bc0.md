# Eseguire i test dalla riga di comando

Esegui i test con:

```bash
scarb cairo-test
```

Tutti i test tranne il primo sono stati ignorati. Dopo essere riuscito a far
passare il primo test, apri il file sorgente dei test che si trova nella cartella
`tests` e rimuovi il flag `#[ignore]` dal test successivo, poi fai passare di nuovo
i test. Ogni test è una funzione con sopra il flag `#[test]`.
Continua, finché non li superi tutti.

Se vuoi eseguire _tutti_ i test senza modificare il file sorgente dei test, usa:

```bash
scarb cairo-test --include-ignored
```

Per eseguire un test specifico, che sia ignorato o no, per esempio `some_test`, puoi usare:

```bash
scarb cairo-test -f some_test
```

Per saperne di più sui test di Cairo, consulta la [documentazione dei test][cairo-tests] online.

[cairo-tests]: https://book.cairo-lang.org/ch10-01-how-to-write-tests.html
