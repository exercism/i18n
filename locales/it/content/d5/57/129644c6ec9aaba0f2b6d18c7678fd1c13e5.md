# Istruzioni

In questo esercizio lavorerai a un pianificatore di appuntamenti per un salone di bellezza a New York, aperto il 15 settembre 2012.

Ci sono cinque compiti, che riguardano tutti le date degli appuntamenti. Le date e gli orari useranno uno dei tre formati seguenti:

- `"7/25/2019 13:45:00"`
- `"July 25, 2019 13:45:00"`
- `"Thursday, July 25, 2019 13:45:00:00"`

~~~~exercism/caution
I test imposteranno automaticamente la cultura su `en-US`: non devi impostarla né specificarla da solo.
~~~~

## 1. Analizzare la data di un appuntamento

Implementa la funzione `schedule`, che sa analizzare una rappresentazione testuale di una data di appuntamento nel formato `DateTime` corrispondente:

```fsharp
schedule "7/25/2019 13:45:00"
// => DateTime(2019, 7, 25, 13, 45, 0)
```

## 2. Controllare se un appuntamento è già passato

Implementa la funzione `hasPassed`, che prende una data di appuntamento e controlla se l'appuntamento è nel passato:

```fsharp
hasPassed (DateTime(1999, 12, 31, 9, 0, 0))
// => true
```

## 3. Controllare se un appuntamento è nel pomeriggio

Implementa la funzione `isAfternoonAppointment`, che prende una data di appuntamento e controlla se l'appuntamento è nel pomeriggio (>= 12:00 e < 18:00):

```fsharp
isAfternoonAppointment (DateTime(2019, 03, 29, 15, 0, 0))
// => true
```

## 4. Descrivere l'ora e la data dell'appuntamento

Implementa la funzione `description`, che prende una data di appuntamento e restituisce una descrizione di quella data e di quell'ora:

```fsharp
description (DateTime(2019, 03, 29, 15, 0, 0))
// => "You have an appointment on 3/29/2019 3:00:00 PM."
```

## 5. Restituire la data dell'anniversario

Implementa la funzione `anniversaryDate`, che restituisce la data dell'anniversario di quest'anno, cioè il 15 settembre:

```fsharp
anniversaryDate()
// => DateTime(2019, 9, 15, 0, 0, 0)
```
