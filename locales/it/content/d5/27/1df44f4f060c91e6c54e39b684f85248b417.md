# Informazioni

In F#, tutto ciò che ha un tipo e può essere definito è noto come _valore_. Questo include i valori booleani, gli interi e le liste, ma anche le funzioni. I valori interi sono definiti come una o più cifre (consecutive) e supportano i [operatori matematici predefiniti][operators].

Assegnare un valore a un nome si chiama _associazione_. Le [associazioni][bindings] sono immutabili, il che le rende simili alle costanti di altri linguaggi. Le associazioni si definiscono con la parola chiave `let`.

Poiché F# è un linguaggio a tipizzazione statica, ogni associazione ha un tipo. Specificare il tipo di un'associazione è facoltativo per la maggior parte delle associazioni, perché l'_inferenza di tipo_ di F# riesce di solito a dedurlo in base al valore.

```fsharp
// Automatically inferred type
let fingers = 10
```

Anche le [funzioni][functions] sono normali associazioni, ma con uno o più parametri. Una funzione restituisce automaticamente la sua ultima espressione. L'inferenza di tipo funziona anche per la maggior parte delle funzioni: analizza con quali valori la funzione viene chiamata e quale valore restituisce.

```fsharp
// Automatically inferred types for parameters and return type
let add x y = x + y
```

Per chiamare una funzione, scrivi il suo nome e passa un argomento per ognuno dei parametri della funzione.

```fsharp
let five = add 2 3
```

Se il tipo di un'associazione non può essere dedotto, il compilatore segnalerà un errore. Per risolvere, specifica esplicitamente il tipo dell'associazione.

```fsharp
// Explicit type annotation
let fingers: int = 10

// Explicit type annotation (also for parameters)
let add (x: int) (y: int): int = x + y
```

In F#, le associazioni si possono usare solo _dopo_ essere state definite. Usare un'associazione prima di definirla produce un errore di compilazione.

```fsharp
// Compile error as the add binding has not yet been defined
// let seven = add 3 + 4

let add x y = x + y
```

Gli spazi bianchi sono significativi: servono a definire lo scope, indentando il codice con spazi rispetto alla riga che definisce l'associazione. Per convenzione, si usano quattro spazi per l'indentazione.

```fsharp
let toes =
    let left = 5
    let right = 5
    left + right

let multiplyPlusTwo x y =
    let product = x * y
    product + 2

// Trying to access the left, right or product bindings
// here would result in a compile error
```

Le associazioni di F# (comprese le funzioni) sono di solito organizzate in moduli. Un modulo raggruppa funzionalità correlate e si definisce con la parola chiave `module`. La definizione del modulo deve precedere le sue associazioni:

```fsharp
module Calculator

let pi = 3.14

let add x y = x + y
```

F# supporta due tipi di [commenti][comments]. I commenti su una sola riga sono preceduti da `//`, mentre i commenti multilinea si inseriscono tra `(*` e `*)`.
