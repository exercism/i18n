# Informazioni

C è un linguaggio a tipizzazione statica: questo significa che ogni cosa ha un tipo al momento della compilazione.
Scegliere un nome per una [variabile][variable] e stabilirne il tipo si chiama dichiarare una variabile.

Una variabile si dichiara specificando esplicitamente il suo tipo.
Un nome di variabile [deve seguire alcune regole][name-rules], come iniziare con una lettera o con un underscore.
Alcuni nomi non si possono usare perché sono riservati [per le parole chiave][reserved-keywords] o [per altri identificatori][reserved-identifiers].

Impostare o aggiornare una variabile si fa con l'assegnazione.
Assegnare il valore definisce la variabile.
Definire la variabile è anche detto inizializzazione.

```c
int foo;      // Declare an integer named var
foo = 10;     // Define the variable

int bar = 15; // Both can also be done in a single statement
```

Il valore di una variabile può essere assegnato e aggiornato usando l'[operatore di assegnazione semplice `=`][assignment-operator].
Una volta definita, il tipo di una variabile non può mai cambiare.

```c
int foo = 10; // Assign initial value
foo = 25;     // Update to new value

foo = false;  // Compiler error when assigning value of a different type
```

C è un linguaggio [imperativo][imperative] e [procedurale][procedural].
Ogni calcolo viene eseguito come parte di una serie di [istruzioni][statements] che fanno parte di una [funzione][function] o di più funzioni.

Ogni funzione può avere zero o più [parametri][parameters].
Quando si definisce una funzione, sia tutti i parametri sia il valore restituito devono avere un tipo esplicito.
I valori vengono restituiti dalle funzioni usando la [parola chiave `return`][return-keyword].
Per impostazione predefinita le funzioni hanno una [classe di memorizzazione][storage_class] esterna, il che significa che la funzione esiste per tutta la durata del programma e può essere visibile all'esterno del file.
Per evitarlo si può aggiungere la parola chiave `static`, che specifica la visibilità interna.

```c
static int add(int x, int y) {
  return x + y;
}
```

Nell'esempio precedente, le variabili `x` e `y` si possono usare solo all'interno della funzione: hanno cioè uno scope di funzione.
Lo [scope][scope], ovvero l'ambito di visibilità, è l'idea che il valore associato a un nome (di un elemento del programma) sia accessibile solo all'interno dell'«area» di codice in cui è definito.
Le principali aree di codice in C sono:

- file
- funzione
- blocco (come all'interno dei cicli e di altri costrutti)

Le funzioni si chiamano specificando il nome della funzione e passando gli argomenti per ciascuno dei parametri della funzione.

```c
int sum = add(1, 2);
```

C supporta due tipi di [commenti][comments].
I commenti su una sola riga sono preceduti da `//` (da C99 in poi), mentre i commenti su più righe si inseriscono tra `/*` e `*/`.
