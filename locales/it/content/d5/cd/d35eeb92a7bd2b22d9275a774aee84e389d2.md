# Suggerimenti

## 1. Analizza la data dell'appuntamento in formato numerico

- Il costruttore avrà bisogno di un [DateFormat][dateformat] adeguato.

## 2. Verifica se un appuntamento è già passato

- Il confronto con il DateTime attuale è sintatticamente simile a qualsiasi confronto numerico.

## 3. Verifica se l'appuntamento è nel pomeriggio

- Pensa a quale parte del DateTime è utile: _non_ la data, e i minuti contano?
- Leggi le istruzioni per verificare se gli estremi sono inclusi o esclusi nel confronto tra orari (matematicamente, si tratta di un intervallo semiaperto).

## 4. Descrivi l'ora e la data dell'appuntamento

- Il metodo `Dates.format()` è pensato proprio per questo.
- Includi la parte `Dates.` per sicurezza (_ci scusiamo, potrebbe essere un bug di Julia_).
- Anche qui ti serve un [DateFormat][dateformat].

## 5. Restituisci la data dell'anniversario

- Qual è l'anno corrente?
- Costruisci una `Date` per il 15 settembre di quest'anno.
