# Suggerimenti

## 1. Presentati

La funzione `introduce` deve «estrarre» il valore contenuto in `player.Name`.
Prova a usare la [funzione `Options.defaultValue`][defaultvalue] per convertire `player.Name` nel suo valore «incapsulato» quando è `Some`, o nel valore predefinito richiesto quando è `None`.

## 2. Implementare la meccanica di rianimazione

La funzione `revive` deve restituire `Some <player>` oppure `None`, dove `<player>` è un record `Player`, eventualmente con alcuni campi modificati.

## 3. Implementare la meccanica di lancio degli incantesimi

Prova a usare un'espressione match per coprire sia il caso `Some` sia il caso `None`, come nell'esempio seguente:

```fsharp
let exists (x: int option) =
    match x with
    | Some n -> true
    | None -> false
```

[defaultvalue]: https://learn.microsoft.com/en-us/dotnet/fsharp/language-reference/options#converting-options-with-default-values
