# Istruzioni

In questo esercizio, avrai il compito di scrivere il software per un dispositivo di cifratura che funziona eseguendo trasformazioni sui dati. Serve un modo per creare in modo flessibile funzioni complicate, combinando insieme funzioni più semplici.

Per ogni compito, restituisci una funzione anonima che può essere chiamata dallo scope chiamante.

Tutte le funzioni devono aspettarsi argomenti interi. In Elixir, i numeri interi sono adatti anche per eseguire operazioni bit a bit.

## 1. Crea un addizionatore

Implementa `Secrets.secret_add/1`. Deve restituire una funzione che accetta un argomento e gli aggiunge l'argomento passato a `secret_add`.

```elixir
adder = Secrets.secret_add(3)
adder.(2)
# => 5
```

## 2. Crea un sottrattore

Implementa `Secrets.secret_subtract/1`. Deve restituire una funzione che accetta un argomento e sottrae da quell'argomento il segreto passato a `secret_subtract`.

```elixir
subtractor = Secrets.secret_subtract(2)
subtractor.(3)
# => 1
```

## 3. Crea un moltiplicatore

Implementa `Secrets.secret_multiply/1`. Deve restituire una funzione che accetta un argomento e lo moltiplica per il segreto passato a `secret_multiply`.

```elixir
multiplier = Secrets.secret_multiply(7)
multiplier.(3)
# => 21
```

## 4. Crea un divisore

Implementa `Secrets.secret_divide/1`. Deve restituire una funzione che accetta un argomento e lo divide per il segreto passato a `secret_divide`.

```elixir
divider = Secrets.secret_divide(3)
divider.(32)
# => 10
```

Usa la divisione intera, così l'output è compatibile con l'input atteso dalle altre funzioni.

## 5. Crea una funzione «and»

Implementa `Secrets.secret_and/1`. Deve restituire una funzione che accetta un argomento e su di esso e sul segreto passato a `secret_and` esegue un'operazione bit a bit _and_.

```elixir
ander = Secrets.secret_and(1)
ander.(2)
# => 0
```

## 6. Crea una funzione «xor»

Implementa `Secrets.secret_xor/1`. Deve restituire una funzione che accetta un argomento e su di esso e sul segreto passato a `secret_xor` esegue un'operazione bit a bit _xor_.

```elixir
xorer = Secrets.secret_xor(1)
xorer.(3)
# => 2
```

## 7. Crea un combinatore di funzioni

Implementa `Secrets.secret_combine/2`. Deve restituire una funzione che accetta un argomento e gli applica, nell'ordine, le due funzioni passate a `secret_combine`.

```elixir
add_one = Secrets.secret_add(1)
multiply_by_2 = Secrets.secret_multiply(2)
combined = Secrets.secret_combine(add_one, multiply_by_2)

combined.(3)
# => 8
```
