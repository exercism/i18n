# Istruzioni

In questo esercizio modellerai una bilancia che usa i chilogrammi come unità.

Ci sono 6 compiti, ognuno dei quali richiede di implementare una o più proprietà:

## 1. Consenti alla bilancia di avere una precisione

Per venire incontro a esigenze diverse, consentiamo di personalizzare ogni bilancia con una precisione (il numero di cifre dopo il separatore decimale).
Implementa la classe `WeighingMachine` in modo che abbia una proprietà `Precision` di sola lettura, impostata sull'argomento `precision` del costruttore:

```csharp
var wm = new WeighingMachine(precision: 3);

//  => wm.Precision == 3
```

## 2. Consenti di impostare il peso sulla bilancia

Implementa la proprietà `WeighingMachine.Weight` in modo da poter leggere _e_ impostare il peso:

```csharp
var wm = new WeighingMachine(precision: 3);
wm.Weight = 60.5;

//  => wm.Weight == 60.5
```

## 3. Assicurati che un peso di input negativo venga rifiutato

È chiaro che nessuno può avere un peso negativo.
Aggiungi una validazione alla proprietà `WeighingMachine.Weight` in modo che lanci un'eccezione `ArgumentOutOfRangeException` quando si prova a impostarla su un peso negativo:

```csharp
var wm = new WeighingMachine(precision: 3);
wm.Weight = -10; // Throws an ArgumentOutOfRangeException
```

## 4. Consenti di applicare una regolazione della tara alla bilancia

La regolazione della tara può essere un valore qualsiasi (anche negativo, o un valore che rende negativo il peso visualizzato).
Implementa la proprietà `WeighingMachine.TareAdjustment` in modo da poter impostare la regolazione della tara:

```csharp
var wm = new WeighingMachine(precision: 3);
wm.TareAdjustment = -10.6;

// => wm.TareAdjustment == -10.6
```

## 5. Assicurati che la bilancia abbia una regolazione della tara predefinita

Dopo alcuni test approfonditi, sembra che, a causa di un problema di fabbricazione, tutte le bilance tendano a sovrastimare il peso di `5`.
Modifica la proprietà `WeighingMachine.TareAdjustment` in modo che il suo valore predefinito sia `5`.

```csharp
var wm = new WeighingMachine(precision: 3);

// => wm.TareAdjustment == 5.0
```

## 6. Consenti di recuperare il peso

Implementa la proprietà `WeighingMachine.DisplayWeight`, che deve restituire una stringa con il peso dopo la regolazione della tara, con la precisione corretta applicata e l'unità aggiunta.
Nota che:
``` display-weight = input-weight - tare-adjustment ```

```csharp
var wm = new WeighingMachine(precision: 3);
wm.Weight = 60.567;
wm.TareAdjustment = 10;

// => wm.DisplayWeight == "50.567 kg"
```
