# Introduzione

I booleani in Rust sono rappresentati dal tipo `bool`, i cui valori possono essere `true` o `false`.

Rust supporta sei operatori di confronto: `==` (uguale), `!=` (diverso), `>` (maggiore di), `<` (minore di), `>=`
(maggiore o uguale a), `<=` (minore o uguale a). Si possono usare per valutare la relazione tra valori non booleani,
ottenendo un valore booleano.

```rust
1 > 0 // true
1 < 0 // false
1 == 0 // false
1 != 0 // true
1 >= 0 // true
1 <= 0 // false
```

A differenza di alcuni altri linguaggi, `0` non è `false` e un valore diverso da zero non è `true`.

Rust supporta due operatori booleani: `||` (o), `&&` (e). Vengono valutati solo quando l'operando di sinistra non
determina già il risultato dell'espressione. Ovvero, `||` valuta il suo operando di destra solo quando l'operando di
sinistra vale `false`, e `&&` solo quando vale `true`.
