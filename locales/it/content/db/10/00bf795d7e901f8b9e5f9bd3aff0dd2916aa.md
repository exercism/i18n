# Suggerimenti

## Generale

- Leggi la pagina sugli [errori][getting-started-errors] nella guida di Introduzione.
- Leggi la pagina su [IO][getting-started-io] nella guida di Introduzione.

## 1. Apri un file

- Usa il _dynamic dispatch_ per chiamare la funzione open. Rivedi lo snippet di codice dell'introduzione.

## 2. Prova a scrivere nel file

- Usa il costrutto try-rescue.
- Nel modulo `IO` c'è una [funzione][io-write] che permette di scrivere su un dispositivo IO.
- Puoi usare il blocco `rescue` per fare pattern matching sull'errore e restituire la tupla dell'errore.
- Puoi usare il blocco `else` per fare pattern matching sul valore restituito da una scrittura riuscita.

## 3. Chiudi il file

- Puoi usare il blocco `after` per eseguire una funzione indipendentemente dal fatto che il blocco `try` vada a buon fine o venga gestito con `rescue`.
