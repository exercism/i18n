# Istruzioni

Sei stato tentato a tornare a Hyperia (con la sua alta inflazione) per una tariffa giornaliera da capogiro.

La Banca Centrale sta valutando di introdurre il dollaro statunitense come seconda valuta, quindi tutti i sistemi contabili devono essere adattati per gestire più valute.

Ti è stato chiesto di implementare l'oggetto che rappresenta un importo in valuta.

## 1. Consentire di verificare l'uguaglianza dell'importo in valuta

Modifica la struct `CurrencyAmount` in modo che gestisca l'uguaglianza. Se le due struct di importo in valuta non hanno la stessa valuta ("USD" o "HD"), deve essere lanciata un'istanza di `ArgumentException`.

```csharp
CurrencyAmount amountA = new CurrencyAmount(55, "HD");
CurrencyAmount amountB = new CurrencyAmount(55, "HD");
CurrencyAmount amountC = new CurrencyAmount(55, "USD");
amountA == amountB
// => true
amountA != amountB
// => false
amountA == amountC
// => ArgumentException
amountA != amountC
// => ArgumentException
```

## 2. Confrontare gli importi in valuta

Modifica la struct `CurrencyAmount` in modo che gestisca i confronti (solo `>` e `<`). Se le due struct di importo in valuta non hanno la stessa valuta ("USD" o "HD"), deve essere lanciata un'istanza di `ArgumentException`.

```csharp
CurrencyAmount amountA = new CurrencyAmount(55, "HD");
amountA > new CurrencyAmount(50, "HD")
// => true
amountA < new CurrencyAmount(50, "HD")
// => false
amountA > new CurrencyAmount(50, "USD")
// => ArgumentException
```

## 3. Sommare e sottrarre importi in valuta

Modifica la struct `CurrencyAmount` in modo che gestisca l'addizione e la sottrazione aritmetica (solo `+` e `-`). Se le due struct di importo in valuta non hanno la stessa valuta ("USD" o "HD"), deve essere lanciata un'istanza di `ArgumentException`.

```csharp
CurrencyAmount amountA = new CurrencyAmount(55, "HD");
CurrencyAmount amountB = new CurrencyAmount(100, "HD");
CurrencyAmount amountC = new CurrencyAmount(55, "USD");
amountA + amountB
// => {155, HD}
amountB - amountA
// => {45, HD}
amountA + amountC
// => ArgumentException
```

## 4. Moltiplicare e dividere importi in valuta

Modifica la struct `CurrencyAmount` in modo che gestisca la moltiplicazione e la divisione aritmetica (solo `*` e `/`).

```csharp
CurrencyAmount amountA = new CurrencyAmount(10, "HD");
amountA * 2m
// => {20, HD}
amountA / 2m
// => {5, HD}
```

## 5. Convertire l'importo in valuta in un double

Modifica la struct `CurrencyAmount` in modo che un'istanza possa essere convertita esplicitamente in un `double`.

```csharp
CurrencyAmount amountA = new CurrencyAmount(55.5m, "HD");
(double)amountA
// => 55.5d
```

## 6. Convertire l'importo in valuta in un decimal

Modifica la struct `CurrencyAmount` in modo che un'istanza possa essere convertita implicitamente in un `decimal`.

```csharp
CurrencyAmount amountA = new CurrencyAmount(55.5m, "HD");
decimal d = amountA;
// => d == 55.5m
```
