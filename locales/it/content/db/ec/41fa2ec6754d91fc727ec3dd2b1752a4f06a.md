# Dichiarazione di tipo

In PHP, le dichiarazioni di tipo forniscono asserzioni di tipo in fase di esecuzione per gli argomenti delle funzioni, i valori restituiti e le proprietà delle classi.
Nelle funzioni, si può aggiungere un tipo di ritorno `void` per indicare che la funzione non restituisce alcun valore.
I tipi dichiarati servono anche come asserzioni in fase di esecuzione sul fatto che le funzioni restituiscano una risposta con un tipo ragionevole.

```php
<?php

class Driver
{
    private int $serial_number;

    public function setSerialNumber(int $number): void
    {
        $this->serial_number = $number;
    }

    public function getSerialNumber(): int
    {
        return $this->serial_number; 
    }
}

$driver = new Driver();
$driver->setSerialNumber("Version 1b"); // This will throw a TypeError
```

## Unioni di tipo

Se un argomento di una funzione, un valore restituito o una proprietà di una classe possono essere di più di un tipo, si può dichiarare un'unione di tipo.

```php
<?php

class IdentityCard
{
    private int|null $id = null;

    public function assign(int|float $id): void
    {
        $this->id = intval($id);
    }
}

$card = new IdentityCard();
$card->assign(5.0);
```

## Tipi misti

Quando si lavora con il codice, può capitare di non riuscire a specificare un tipo.
A partire da PHP 8.0, è disponibile un tipo di ripiego chiamato `mixed`.
`mixed` equivale a un'unione di tipo di `object|resource|array|string|float|int|bool|null`.
