# Informazioni

[I bitstring][bitstring] permettono ai programmatori di lavorare efficacemente con i dati binari.

- Puoi costruire i bitstring in modo elegante usando la [forma speciale `<<>>`][bitstring-form].

  ```elixir
  <<0b101::3>> == <<5::3>> and <<5::3>> == <<5::size(3)>>
  # => true

  first = <<0b110::3>>
  second = <<0b001::3>>
  combined = <<first::bitstring, second::bitstring>>
  # => <<49::size(6)>>
  ```

- Puoi eseguire il matching con la forma `<<>>` e sfruttare quel match per [scomporre ulteriormente i dati binari][bitstring-matching].

  ```elixir
  <<data_size::32, count::size(data_size)>> = <<8::32, 3::8>>
  # => <<0, 0, 0, 8, 3>>
  data_size
  # => 8
  count
  # => 3
  ```

- Puoi eseguire il matching sul resto del bitstring usando `::bitstring`.

  ```elixir
  <<_::32, remainder::bitstring>> = <<8::32, 3::8>>
  # => <<0, 0, 0, 8, 3>>
  remainder
  # => <<3>>
  ```

- Il *tipo* dei dati binari è un tipo specifico di bitstring in cui il numero di bit è divisibile per 8.
  - Tutti i binari sono bitstring, ma non tutti i bitstring sono binari.
- Elixir offre dello zucchero sintattico per lavorare con i [valori letterali interi][integer-literal] in forme diverse:
  - `0b1000001 = ?A = 65`
