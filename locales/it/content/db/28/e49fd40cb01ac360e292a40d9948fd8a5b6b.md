# Introduzione

## Array

La libreria core di Cairo implementa un tipo `Array`.

È simile ai tipi array che si trovano di solito negli altri linguaggi di programmazione, ma con alcune differenze fondamentali:

- Gli elementi possono essere aggiunti in modo efficiente solo in fondo al tipo `Array`, e possono essere rimossi in modo efficiente solo dalla parte iniziale.
- È impossibile impostare manualmente un elemento usando l'indice dell'array.

Gli array possono essere creati con la funzione `ArrayTrait::new` ed anche con la macro `array!`:

```rust
let empty: Array<u32> = ArrayTrait::new();
let one_to_four = array![1, 2, 3, 4];
```

Gli elementi possono essere aggiunti all'array con la funzione `ArrayTrait::append`:

```rust
let mut num_array = array![1, 2, 3, 4];
num_array.append(5);
// -> [1, 2, 3, 4, 5]
```

Gli elementi possono essere rimossi dall'array con la funzione `ArrayTrait::pop_front`:

```rust
let mut one_to_four = array![1, 2, 3, 4];

one_to_four.pop_front();
// -> [2, 3, 4]
```

Cairo introduce anche un tipo `Span` che si comporta come una «istantanea» dell'`Array`.

Ogni `Array` può essere convertito in uno `Span` con la funzione `ToSpanTrait::span`:

```rust
let one_to_four = array![1, 2, 3, 4];
let one_to_four_span = one_to_four.span();
// -> [1, 2, 3, 4]
```

Convertire un array in uno `Span` è molto efficiente: `Span` è solo una struttura dati che permette a Cairo di «vedere» una sezione dell'array, non la modifica in alcun modo.

Convertendo un array in uno `Span`, Cairo permette di eseguire più operazioni di quante ne sarebbero consentite direttamente su `Array`, come rimuovere un elemento dall'inizio dello span.

```rust
let one_to_four = array![1, 2, 3, 4];
let mut one_to_four_span = one_to_four.span();
one_to_four_span.pop_back();
// -> [2, 3, 4]
```

Nota che abbiamo dovuto rendere `one_to_four_span` mutabile con la parola chiave `mut` per chiamare `pop_back`, che modifica lo span accorciando la sezione dell'array che lo span sta «vedendo».
