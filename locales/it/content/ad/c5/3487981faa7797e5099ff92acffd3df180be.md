# Istruzioni

Il tuo compito è determinare cosa dirai quando regalerai il biscotto in più.

Se conosci il nome della persona (ad esempio se si chiama Do-yun), dirai:

```text
One for Do-yun, one for me.
```

Se non conosci il nome della persona, dirai invece _you_.

```text
One for you, one for me.
```

Ecco alcuni esempi:

| Nome   | Dialogo                     |
| :----- | :-------------------------- |
| Alice  | One for Alice, one for me.  |
| Bohdan | One for Bohdan, one for me. |
|        | One for you, one for me.    |
| Zaphod | One for Zaphod, one for me. |
