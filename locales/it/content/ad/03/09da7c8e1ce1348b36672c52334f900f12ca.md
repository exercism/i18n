# Istruzioni

Lilly adora cucinare.
Vuole organizzare una festa a base di pizza con i suoi amici.
Per sfruttare al meglio i suoi ingredienti, deve sapere quanto di ciascun ingrediente le serve prima di iniziare.

Per risolvere il problema, Lilly ha abbozzato un programma per automatizzare parte della pianificazione, ma ha bisogno del tuo aiuto per finirlo.
Vuoi aiutare Lilly a organizzare una festa a base di pizza dalle proporzioni perfette?

## 1. Il rapporto dell'impasto

Lilly adora le pizze sottili e croccanti, con una crosta più sottile.
L'impasto necessario per la parte centrale è di almeno 200g, ma ogni persona a cui la pizza è destinata ne richiede altri 20g.

`grams = pizzas * ((persons * 20) + 200)`

Lilly ha bisogno di una funzione che:

- Prende il numero di pizze
- Prende il numero di persone che ogni pizza servirà
- E restituisce l'impasto necessario, arrotondato al grammo più vicino.

Ad esempio, per fare 4 pizze che sfamano 8 persone:

```php
<?php

$pizza_pi = new PizzaPi();
$pizza_pi->calculateDoughRequirement(4, 8);
// => 1440
```

## 2. Una spruzzata di salsa

Lilly è meticolosa quando stende la salsa, ma le dimensioni delle sue pizze possono variare.
Per esperienza sa che servono 125mL di salsa per pizza.
Lilly ha bisogno di una funzione che calcoli quante lattine di salsa comprare.

`cans of sauce = pizzas * sauce per pizza / sauce can volume`

Ad esempio, dato che Lilly deve fare 8 pizze e ogni lattina è da 250mL:

```php
<?php

$pizza_pi = new PizzaPi();
$pizza_pi->calculateSauceRequirement(8, 250);
// => 4
```

## 3. Un po' di formaggio, per favore

Il formaggio si trova in cubi perfetti ed è venduto in base alle dimensioni.

La formula che Lily usa non è quella per l'area della pizza, perché _non_ vuole che il formaggio copra tutta la superficie.
Ha deciso di usare la formula seguente per determinare quante pizze di un certo diametro (`diameter`) si possono fare con un cubo di formaggio di un certo lato (`cheese_dimension`):

`pizzas = (cheese_dimension³) / (thickness * PI * diameter)`

Crea una funzione che:

- Prende la misura del lato di un cubo di formaggio
- Prende lo spessore desiderato dello strato di formaggio
- Prende il diametro della pizza
- E usa la formula di Lilly per restituire il numero di pizze che si possono fare, arrotondando per difetto.

Ad esempio, con un cubo di formaggio di 25x25x25cm, uno strato di formaggio spesso 0.5cm e pizze di 30cm di diametro:

```php
<?php

$pizza_pi = new PizzaPi();
$pizza_pi->calculateCheeseCubeCoverage(25, 0.5, 30);
// => 331
```

## 4. Una divisione equa

Infine, Lilly vuole che le sue pizze si dividano in 8 fette ciascuna e siano distribuite in modo equo tra i suoi amici.

Crea una funzione che:

- Prende un numero di pizze e un numero di amici
- e restituisce il numero di fette che avanzeranno se ogni persona prende lo stesso numero di fette.

Ad esempio:

```php
<?php

$pizza_pi = new PizzaPi();
$pizza_pi->calculateLeftOverSlices(2, 4);
// => 0
$pizza_pi->calculateLeftOverSlices(4, 3);
// => 2
```
