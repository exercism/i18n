# Introduzione

## Funzioni matematiche

Le radici quadrate, gli angoli e le curve di crescita sono difficili da calcolare con i soli `+`, `-`, `*` e `/`. Il vocabolario [`math.functions`][math.functions] contiene parole che le calcolano per te, e [`math.constants`][math.constants] contiene π. Come ogni altra parola, ognuna prende i propri input dallo stack e vi lascia la propria risposta.

## Radici quadrate

```
sqrt ( x -- y )
```

```factor
USING: kernel math math.constants math.functions math.libm prettyprint ;

9 sqrt .     ! => 3.0
2 sqrt .     ! => 1.4142135623730951
```

Una scala lunga 5 metri, con il piede a 3 metri dal muro, raggiunge i 4 metri di altezza sul muro:

```factor
5 sq 3 sq - sqrt .   ! => 4.0
```

## Pi

`pi` (da `math.constants`) mette π sullo stack, il numero di volte che il diametro di un cerchio entra nella sua circonferenza:

```factor
: wheel-edge ( diameter -- edge ) pi * ;

2 wheel-edge .   ! => 6.283185307179586
```

## Gli angoli sono in radianti

```
sin ( x -- y )
cos ( x -- y )
tan ( x -- y )
```

`sin`, `cos` e `tan` accettano un angolo, ma non in gradi. Usano i **radianti**, dove mezzo giro è π invece di 180. Passare loro dei gradi non è un errore: restituiscono silenziosamente la risposta sbagliata.

`deg>rad` converte i gradi in radianti, e `rad>deg` fa il contrario. Equivalgono a moltiplicare per π e dividere per 180, o viceversa:

```
deg>rad ( x -- y )
rad>deg ( x -- y )
```

```factor
30 deg>rad .       ! => 0.5235987755982988
30 pi * 180 / .    ! => 0.5235987755982988
pi rad>deg .       ! => 180.0
```

Converti i gradi in radianti prima di chiamare `sin`:

```factor
: ramp-rise ( length degrees -- rise ) deg>rad sin * ;

10 30 ramp-rise .   ! => 4.999999999999999
```

Una rampa lunga 10 metri a 30 gradi sale di 5 metri. La risposta viene stampata come `4.999999999999999` perché le funzioni matematiche restituiscono il numero in virgola mobile più vicino, non il valore esatto. Senza la conversione, `30 sin` tratta 30 come radianti (quasi cinque giri completi) e la rampa «salirebbe» di `-9.88` metri.

## Trovare un angolo

`fatan2` fa il percorso inverso: dati la distanza verticale e quella orizzontale, restituisce l'angolo in radianti. Vive in [`math.libm`][math.libm]. La distanza *verticale* va messa sullo stack per prima, poi quella *orizzontale*:

```
fatan2 ( y x -- radians )
```

```factor
1.0 1.0 fatan2 .              ! => 0.7853981633974483
1.0 1.0 fatan2 rad>deg .      ! => 45.0
-1.0 -1.0 fatan2 rad>deg .    ! => -135.0
0.0 -1.0 fatan2 rad>deg .     ! => 180.0
```

L'angolo è misurato a partire dalla direzione *orizzontale* positiva. `fatan2` guarda i segni di entrambe le distanze, quindi può restituire un valore compreso tra −180 e 180 gradi.

## Potenze di dieci: 10^ e log10

`10^` eleva 10 a una potenza:

```factor
5 10^ .     ! => 100000
2 10^ .     ! => 100
0.5 10^ .   ! => 3.1622776601683795
```

`log10` fa il percorso inverso. Risponde alla domanda: «10 elevato a quale potenza dà questo numero?» Quella risposta è il **logaritmo** del numero:

```factor
100000 log10 .   ! => 5.0
100 log10 .      ! => 2.0
1 log10 .        ! => 0.0
0.001 log10 .    ! => -3.0
```

## e^ e log

`e^` e `log` sono la stessa coppia, con *e* (circa 2,718) al posto di 10. `e^` eleva *e* a una potenza, e `log` risponde alla domanda: «*e* elevato a quale potenza dà questo numero?»

```
e^  ( x -- y )
log ( x -- y )
```

I matematici usano *e* per qualsiasi cosa che cresca o si riduca della stessa frazione a ogni passo. Il denaro che genera interessi è un esempio, e una tazza di tè che si raffredda è un altro:

```factor
! 80 degrees hotter than the room, the gap shrinking by 5% a minute
: tea-gap ( minutes -- gap ) -0.05 * e^ 80 * ;

0 tea-gap .    ! => 80.0
10 tea-gap .   ! => 48.52245277701067
```

`log` annulla `e^`. Questo risponde alla domanda inversa: quanti minuti passano prima che la differenza scenda a 40 gradi?

```factor
80 40 / log 0.05 / .   ! => 13.862943611198904
```
