# Introduzione

I booleani in C++ sono rappresentati dal tipo `bool`.
Un `bool` può essere `true` oppure `false`.

## Operatori logici

C++ supporta tre operatori booleani: `!` (NOT), `&&` (AND) e `||` (OR).
Puoi anche usare le versioni alternative `not`, `and` e `or`.

```cpp
true || false // => true
true && false // => false
!true // => false
not false // => true
```

## Precedenza

I tre operatori booleani hanno ciascuno una diversa _precedenza degli operatori_.
Di conseguenza, vengono valutati in questo ordine: prima `!`, poi `&&` ed infine `||`.
Se vuoi forzare un ordine diverso, puoi racchiudere un'espressione booleana tra parentesi tonde (`()`), ovvero tra parentesi, dato che queste hanno una precedenza ancora più alta.

```cpp
!true && false   // => false
!(true and false) // => true
```

## Conversione

Se usi `true` o `false` in un punto dove ci si aspetta un numero, verranno convertiti rispettivamente in `1` e `0`.
Se usi un numero in un'operazione booleana, tutto tranne `0` viene trattato come `true`, anche i valori negativi.

```cpp
!true && 0.0   // => false
true + true + false // => 2
```
