# Eseguire i test

Scegli il tuo sistema operativo:

- [Windows](#windows)
- [macOS](#macos)
- [Linux](#linux)

## Windows

1. Apri un Command Prompt.
2. Scarica il primo esercizio:

   ```batchfile
   C:\Users\JohnDoe>exercism download --exercise hello-world --track java
   ```

3. Spostati nella cartella dell'esercizio:

   ```batchfile
   C:\Users\JohnDoe>cd C:\Users\JohnDoe\exercism\java\hello-world
   ```

4. Esegui i test:

   ```batchfile
   C:\Users\JohnDoe>gradlew.bat test
   ```

   _(Non preoccuparti se i test falliscono all'inizio: è così che si comincia ogni esercizio.)_

5. Risolvi l'esercizio. Trova la guida `instructions.append.md` e seguila ([visualizza su GitHub](https://github.com/exercism/java/blob/main/exercises/practice/hello-world/.docs/instructions.append.md#tutorial)).

Buona fortuna! Divertiti!

## macOS

1. Nella finestra del terminale, scarica il primo esercizio:

   ```sh
   exercism download --exercise hello-world --track java
   ```

2. Spostati nella cartella dell'esercizio:

   ```sh
   cd /Users/johndoe/exercism/java/hello-world
   ```

3. Esegui i test:

   ```sh
   ./gradlew test
   ```

   _(Non preoccuparti se i test falliscono all'inizio: è così che si comincia ogni esercizio.)_

4. Risolvi l'esercizio. Trova la guida `instructions.append.md` e seguila ([visualizza su GitHub](https://github.com/exercism/java/blob/main/exercises/practice/hello-world/.docs/instructions.append.md#tutorial)).

Buona fortuna! Divertiti!
