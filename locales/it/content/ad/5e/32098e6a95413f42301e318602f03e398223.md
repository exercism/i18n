# Introduzione

Il concetto [`Basics`][basics] ha introdotto due modi per definire una funzione.

Il più generale è la forma su più righe:

```julia
function muladd(x, y, z)
    x * y + z
end
```

La forma «di assegnazione», o «a riga singola», per le definizioni brevi:
```julia
muladd(x, y, z) = x * y + z
```

In una terza forma, ancora più breve, si può creare una funzione breve, usata una sola volta, senza darle un nome:

```julia-repl
julia> map(x -> 2x, 1:3)
4-element Vector{Int64}:
 2
 4
 6

julia> map((x, y) -> x * y, 1:3, 4:6)
3-element Vector{Int64}:
  4
 10
 18
```

In questo caso, `x -> 2x` è una «funzione anonima».
È l'equivalente di quella che altri linguaggi chiamano «funzione lambda».

Tieni presente che con più argomenti servono le parentesi, come in `(x, y) -> x * y`.

Le funzioni anonime sono comuni nel codice Julia, soprattutto se combinate con funzioni di ordine superiore come `map()` e `filter()`.

## Argomenti di una funzione

Finora, nel programma, abbiamo visto solo funzioni con un numero preciso di argomenti, che richiedono che la chiamata ne fornisca tutti, nell'ordine corretto.
Sarebbe limitante e scomodo, così esistono diverse altre opzioni.

### Argomenti opzionali

Come molti linguaggi, Julia consente alle definizioni di funzione di indicare valori predefiniti per i singoli argomenti.

La chiamata alla funzione può quindi fornire un valore per quell'argomento, oppure ometterlo e affidarsi al valore predefinito.

```julia-repl
julia> f(x, y=10) = x * y
f (generic function with 2 methods)

julia> f(2, 3)
6

julia> f(2)
20
```

Tutti gli argomenti _senza_ valori predefiniti devono venire prima di quelli _con_ valori predefiniti, il che significa che `f(x=2, y)` non sarebbe valido.

### Argomenti con parola chiave

Tutti gli esempi visti finora usano `positional arguments`, in cui i valori forniti in una chiamata di funzione devono rispettare l'ordine degli argomenti corrispondenti nella definizione della funzione.

Come molti linguaggi, Julia permette anche `keyword arguments`.
Le chiamate alla funzione devono specificare il nome dell'argomento, ma più argomenti con parola chiave si possono poi indicare in qualsiasi ordine.

Una caratteristica distintiva di Julia è che gli argomenti con parola chiave (se presenti) nella definizione della funzione devono essere preceduti da un punto e virgola `;` per separarli dagli eventuali argomenti posizionali.
Una chiamata alla funzione può usare `;` oppure `,` tra l'ultimo argomento posizionale e il primo argomento con parola chiave.

```julia-repl
julia> b(x; y) = x + y
b (generic function with 1 method)

julia> b(2, y=3)
5

# keyword is required when calling
julia> b(2, 3)
ERROR: MethodError: no method matching b(::Int64, ::Int64)
The function `b` exists, but no method is defined for this combination of argument types.
```

I valori predefiniti si possono specificare facoltativamente, esattamente come per gli argomenti posizionali.

È comune ritrovarsi con una sintassi come `myarg=myarg` dentro una chiamata di funzione, quando una variabile con lo stesso nome del parametro è stata calcolata in anticipo.
In questa situazione è ammessa una sintassi abbreviata:

```julia-repl
julia> width = 4.0
4.0

julia> height = √ width
2.0

julia> area(; width, height) = width * height
area (generic function with 1 method)

# repetition
julia> area(; width=width, height=height)
8.0

# shorthand form
julia> area(; width, height)
8.0
```

### Splat e slurp

Questi sono i nomi standard di un aspetto utile della sintassi di Julia, nel caso te lo stessi chiedendo.
Entrambi si riferiscono all'operatore `...`.

#### Splat

Lo splat si usa nelle _chiamate_ di funzione, per espandere una collezione nei singoli valori richiesti dalla funzione.

Forse è più facile da mostrare che da spiegare:

```julia-repl
julia> fxyz(x, y, z) = x * y * z
fxyz (generic function with 1 method)

julia> xyz = [2, 3, 4]
3-element Vector{Int64}:
 2
 3
 4

# Using the vector directly in a function call is invalid
julia> fxyz(xyz)
ERROR: MethodError: no method matching fxyz(::Vector{Int64})
The function `fxyz` exists, but no method is defined for this combination of argument types.

# splatting converts the vector to 3 numbers, used as positional arguments
julia> fxyz(xyz...)
24
```

Alcune «chiamate di funzione» sono nascoste dallo zucchero sintattico, quindi lo splat si può usare anche in modi meno evidenti.

Per esempio, l'assegnazione multipla usa internamente una funzione costruttrice di tuple:

```julia-repl
julia> first, rest... = [1, 2, 3, 4]
4-element Vector{Int64}:
 1
 2
 3
 4

julia> first
1

julia> rest
3-element Vector{Int64}:
 2
 3
 4
```

Anche gli argomenti con parola chiave si possono fornire con lo splat, tipicamente usando una `named tuple`.
Funziona anche un `Dict`, ma le chiavi devono essere simboli (le stringhe non funzionano).

```julia-repl
# function with 3 keyword arguments
julia> fabc(; a, b, c) = a + b + c
fabc (generic function with 1 method)

# named tuple
julia> abc_nt = (a=2, b=3, c=4)
(a = 2, b = 3, c = 4)

# there are no positional arguments, so need to use ; before kw argument
julia> fabc(;abc_nt...)
9

# Dict
julia> abc_dict = Dict(:a=>2, :b=>3, :c=>4)
Dict{Symbol, Int64} with 3 entries:
  :a => 2
  :b => 3
  :c => 4

julia> fabc(;abc_dict...)
9
```

#### Slurp

Lo slurp si usa nella _definizione_ di una funzione, per impacchettare in una collezione un numero arbitrario di valori singoli.

```julia-repl
julia> f_more(i, j, more...) = i + j + sum(more)
f_more (generic function with 1 method)

julia> f_more(1, 3, 5, 7, 9, 11)
36
```

Il nome dell'argomento raccolto dallo slurp (in questo caso `more`) non ha importanza.
Il tipo di questa variabile è scelto dal compilatore, ma per gli argomenti posizionali è probabilmente `tuple` o qualcosa di simile.

Anche gli argomenti con parola chiave si possono raccogliere con lo slurp, ottenendo un `Dict` (o simile).

```julia-repl
julia> f_kwslurp(x, y; switches...) = :mult in keys(switches) ? x * y : x + y
f_kwslurp (generic function with 1 method)

julia> f_kwslurp(5, 6; mult=true)
30

julia> f_kwslurp(5, 6)
11
```

Nella chiamata si può usare qualsiasi argomento con parola chiave.
Sta alla definizione della funzione decidere a quali parole chiave rispondere e quali ignorare.
