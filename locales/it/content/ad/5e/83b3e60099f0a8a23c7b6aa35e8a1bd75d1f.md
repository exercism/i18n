# Introduzione

## Tipi personalizzati

I tipi personalizzati sono il modo in cui si definiscono nuovi tipi di dati in Gleam. Possono avere più _varianti_, ognuna con il proprio nome.

```gleam
pub type Season {
  Spring
  Summer
  Autumn
  Winter
}
```

Ogni caso di un tipo personalizzato può contenere facoltativamente dei dati, e casi diversi possono avere tipi di dati diversi. Quando una variante contiene dati, viene chiamata _record_.

```gleam
pub type Number {
  SomeInt(Int)
  SomeFloat(Float)
  Invalid
}
```

Per creare un valore per un caso specifico puoi fare riferimento al suo nome se non contiene dati aggiuntivi (`Spring`), oppure chiamarlo come una funzione se ne contiene (`SomeInt(2)`).

```gleam
let spring = Spring
let integerTwo = SomeInt(2)
```

I tipi personalizzati, come tutto il resto in Gleam, hanno _uguaglianza strutturale_, il che significa che due valori della stessa variante e con gli stessi dati sono equivalenti.

```gleam
Spring == Spring // -> True
Spring == Autumn // -> False
SomeInt(2) == SomeInt(2) // -> True
SomeInt(2) == SomeFloat(2.0) // -> False
```

Le varianti dei tipi personalizzati possono essere sottoposte a pattern matching usando espressioni case.

```gleam
import gleam/int
import gleam/float

pub fn describe(flexible_number: Number) -> String {
  case flexible_number {
    SomeFloat(f) -> "Float: " <> float.to_string(f)
    SomeInt(i) -> "Int: " <> int.to_string(i)
    Invalid -> "Neither a float nor an int"
  }
}
```
