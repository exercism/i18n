# Installazione

## Cosa serve

Gli strumenti di base necessari per sviluppare in Common Lisp sono:

- Un'«implementazione» di Lisp, che ti permette di compilare ed eseguire il codice, oltre a fornire una REPL.
- Un editor di testo con funzionalità per il codice Lisp.
- (Utile da avere) Il riferimento più usato per il linguaggio Common Lisp, il ["Common Lisp Hyperspec"][hyperspec].

## Roswell

[Roswell][roswell] è un comando per installare e gestire le implementazioni di Common Lisp, con molte funzionalità che rendono semplice sviluppare e distribuire applicazioni Lisp.
Lo usiamo per semplificare i passaggi di installazione e di test.

### Installare Roswell

Consulta la [Guida all'installazione][ros-inst] e segui le istruzioni per la tua piattaforma.
Per la maggior parte degli utenti, quanto segue sarà sufficiente:

* Per MacOS e Linux, [Homebrew][brew] lo rende semplice:
  ```sh
  brew install roswell
  ```
* Per Windows, usa [Scoop][scoop]:
  ```powershell
  scoop install roswell
  ```

La prima volta che usi Roswell, scaricherà e installerà SBCL e Quicklisp.
Basta eseguire questo:
```sh
ros help
```

Entra nella REPL con
```sh
ros run
```

## Configurare l'editor di testo

Chi è alle prime armi con Common Lisp, in particolare chi ha già esperienza con Emacs, può iniziare in modo rapido e semplice installando [Portacle, l'ambiente Common Lisp portatile][portacle].
È gratuito e ricco di funzionalità, funziona su tutte le piattaforme più comuni e arriva già preconfigurato e pronto all'uso. Fornisce:

- Un'implementazione di Lisp: SBCL, che include Quicklisp e ASDF.
- Un editor di testo: Emacs

... con tanti componenti aggiuntivi per scrivere codice Lisp:
- SLIME, la «Superior Lisp Interaction Mode for Emacs», trasforma Emacs in un IDE per Common Lisp
- ParEdit, che semplifica il lavoro con le parentesi.

Tutto arriva già configurato e pronto all'uso. Per installare Portacle, scaricalo dalla [pagina principale][portacle].

Nota: all'inizio Emacs (l'editor di testo) può disorientare, se non ci sei abituato. Per fortuna online ci sono molte guide introduttive a Emacs e SLIME.

## Avvio tradizionale

Se preferisci installare separatamente gli strumenti necessari, dovrai installare e configurare:

- un editor di testo che supporti Lisp: [Emacs][emacs] con il pacchetto [Slime][slime] o [Sly][sly] è una scelta comune, ma vanno bene anche [VIM][vim] con [SLIMV][slimv], [Atom][atom] con [SLIMA][slima] oppure [VSCode][vscode] con un [plugin per Common Lisp][vscode-plugin].
- un'implementazione di Common Lisp: [SBCL][sbcl] è una scelta "sicura" che funziona su Linux, MacOS e Windows. Dato che il linguaggio si basa su uno standard, funzioneranno anche altre [implementazioni conformi][awesome-cl-implementations].
- [Quicklisp][quicklisp] per la gestione delle librerie. Dopo averlo scaricato, segui le [istruzioni][quicklisp-install] per assicurarti che sia integrato correttamente con la tua implementazione di Common Lisp.
