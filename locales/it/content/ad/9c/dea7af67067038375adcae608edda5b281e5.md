# Introduzione

Quando ti serve una sequenza di `n` valori in cui ognuno dipende dal
suo indice, Factor ti mette a disposizione `<iota>`, una sequenza virtuale
degli interi `0, 1, …, n-1`, e `map`:

```factor
USING: math sequences ;

5 <iota> [ 2 * ] map .   ! => { 0 2 4 6 8 }
```

`<iota>` non alloca gli interi in anticipo; `map` li percorre in ordine,
applicando la quotation a ciascuno.

Se il risultato per ogni posizione è un codice di carattere, `>string` trasforma
il risultato in una stringa: il modo naturale per comporre una riga di
caratteri a partire da decisioni basate sull'indice:

```factor
USING: strings ;

5 <iota> [ CHAR: a + ] map >string .   ! => "abcde"
```

[strings]: https://docs.factorcode.org/content/article-strings.html
