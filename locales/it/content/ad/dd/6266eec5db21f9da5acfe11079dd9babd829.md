# Introduzione

## Struct

Gli struct sono un'estensione costruita sopra le [mappe][exercism-maps] e forniscono controlli in fase di compilazione e valori predefiniti. Uno struct prende il nome dal modulo in cui è definito. Per definire uno struct si usa il costrutto `defstruct`. Di solito questo costrutto segue subito la definizione del modulo. `defstruct` accetta sia un elenco di atomi (per valori predefiniti `nil`) sia una lista di parole chiave (per valori predefiniti specificati). I campi senza valore predefinito devono precedere i campi con un valore predefinito.

```elixir
defmodule Plane do
  defstruct [:engine, wings: 2]
end

plane = %Plane{}
# => %Plane{engine: nil, wings: 2}
```

### Accesso ai campi e aggiornamento

Dato che gli struct sono costruiti sulle mappe, possiamo usare gran parte delle funzioni per le mappe per leggere e modificare i valori. Il _Access Behaviour_ **non** è implementato per gli struct. Per accedere ai campi di uno struct, si consiglia invece di usare l'_operatore di accesso statico_ `.`.

- per leggere o recuperare i valori dei campi:

  ```elixir
  plane = %Plane{}
  plane.engine
  # => nil
  Map.fetch(plane, :wings)
  # => {:ok, 2}
  ```

- per aggiornare i valori dei campi

  ```elixir
  plane = %Plane{}
  %{plane | wings: 4}
  # => %Plane{engine: nil, wings: 4}
  ```

### Pattern matching

Gli struct si possono usare nel pattern matching con o senza il nome dello struct.

```elixir
plane = %Plane{}
%Plane{wings: wings} = plane
%{wings: wings} = plane
```

Includendo il nome dello struct nel pattern, puoi assicurarti che sia il lato sinistro sia quello destro siano struct dello stesso tipo.

```elixir
defmodule Helicopter do
  defstruct [:engine, rotors: 1]
end

%Plane{} = %Helicopter{}
# => (MatchError) no match of right hand side value: %Helicopter{engine: nil, rotors: 1}
```

### Imporre l'inizializzazione dei valori dei campi

Possiamo usare l'attributo di modulo `@enforce_keys` con un elenco delle chiavi dei campi per assicurarci che i valori siano inizializzati al momento della creazione dello struct. Se una chiave non compare nell'elenco, il suo valore sarà `nil`, come si vede nell'esempio qui sopra. Se una chiave obbligatoria non viene inizializzata, viene generato un errore.

```elixir
defmodule User do
  @enforce_keys [:username]
  defstruct [:username]
end

%User{}
# => (ArgumentError) the following keys must also be given when building struct User: [:username]
```
