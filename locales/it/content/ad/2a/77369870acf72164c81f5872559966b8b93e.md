# Introduzione

## Alias di tipo

In Gleam, un alias di tipo può essere usato per dare un nome comodo a un tipo esistente che altrimenti sarebbe scomodo da scrivere.

```gleam
pub type Headers =
  List(#(String, String))

pub fn html_headers() -> Headers {
  [
    #("content-type", "text/html"),
    #("x-frame-options", "DENY"),
  ]
}
```

Se viene scritto con `pub type`, l'alias può essere usato anche al di fuori del modulo in cui è definito. Se `pub` viene omesso, l'alias è privato e non può essere usato in altri moduli.
