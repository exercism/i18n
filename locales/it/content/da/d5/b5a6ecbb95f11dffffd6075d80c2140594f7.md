# Istruzioni

La macchina base Take-A-Number vendeva davvero bene, ma alcuni utenti si lamentavano della mancanza di funzionalità avanzate rispetto agli altri modelli disponibili sul mercato.

Il produttore ha ascoltato il feedback degli utenti e ha deciso di lanciare un modello deluxe con più funzionalità, ed ancora una volta ti è stato affidato il compito di scrivere il software per questa macchina.

Le nuove funzionalità aggiunte al modello deluxe includono:
- Tenere traccia dei numeri attualmente in coda.
- Impostare il numero minimo e massimo. Questo permetterà di usare più macchine Take-A-Number deluxe per mettere in coda i clienti verso reparti diversi della stessa struttura, e distinguere i reparti in base all'intervallo di numeri.
- Permettere a certi numeri di saltare la coda per offrire un servizio prioritario alle donne incinte e agli anziani.
- Spegnimento automatico per evitare di lasciare accidentalmente la macchina accesa per tutto il fine settimana e sprecare energia.

La logica di business della macchina è già stata implementata dal tuo collega e si trova nel modulo `TakeANumberDeluxe.State`. Ora il tuo compito è incapsularla in un `GenServer`.

## 1. Avvia la macchina

Usa il behaviour `GenServer` nel modulo `TakeANumberDeluxe`.

Implementa la funzione `start_link/1` e il callback `GenServer` necessario.

L'argomento passato a `start_link/1` è una keyword list. Contiene le chiavi `:min_number` e `:max_number`. I valori sotto quelle chiavi devono essere passati alla funzione `TakeANumberDeluxe.State.new/2`.

Se `TakeANumberDeluxe.State.new/2` restituisce una tupla `{:ok, state}`, la macchina deve avviarsi, usando lo stato restituito come proprio stato. Se invece restituisce una tupla `{:error, error}`, la macchina deve fermarsi, dando l'errore restituito come motivo dell'arresto.

```elixir
TakeANumberDeluxe.start_link(min_number: 1, max_number: 9)
# => {:ok, #PID<0.174.0>}

TakeANumberDeluxe.start_link(min_number: 9, max_number: 1)
# => {:error, :invalid_configuration}
```

Potresti aver notato che la funzione `TakeANumberDeluxe.State.new/2` accetta anche un terzo argomento opzionale, `auto_shutdown_timeout`. Lo useremo nell'ultimo passo di questo esercizio.

## 2. Riporta lo stato della macchina

Implementa la funzione `report_state/1` e il callback `GenServer` necessario. La macchina deve rispondere al chiamante con il suo stato attuale.

```elixir
{:ok, machine} = TakeANumberDeluxe.start_link(min_number: 1, max_number: 10)
TakeANumberDeluxe.report_state(machine)
# => %TakeANumberDeluxe.State{
#      max_number: 10,
#      min_number: 1,
#      queue: %TakeANumberDeluxe.Queue{in: [], out: []},
#      auto_shutdown_timeout: :infinity,
#    }
```

## 3. Metti in coda nuovi numeri

Implementa la funzione `queue_new_number/1` e il callback `GenServer` necessario.

Deve chiamare la funzione `TakeANumberDeluxe.State.queue_new_number/1` con lo stato attuale della macchina.

Se `TakeANumberDeluxe.State.queue_new_number/1` restituisce una tupla `{:ok, new_number, new_state}`, la macchina deve rispondere al chiamante con il nuovo numero e impostare il nuovo stato come proprio stato. Se invece restituisce una tupla `{:error, error}`, la macchina deve rispondere al chiamante con l'errore e non cambiare il proprio stato.

```elixir
{:ok, machine} = TakeANumberDeluxe.start_link(min_number: 1, max_number: 2)
TakeANumberDeluxe.queue_new_number(machine)
# => {:ok, 1}

TakeANumberDeluxe.queue_new_number(machine)
# => {:ok, 2}

TakeANumberDeluxe.queue_new_number(machine)
# => {:error, :all_possible_numbers_are_in_use}
```

## 4. Servi il prossimo numero in coda

Implementa la funzione `serve_next_queued_number/2` e il callback `GenServer` necessario.

Deve chiamare la funzione `TakeANumberDeluxe.State.serve_next_queued_number/2` con lo stato attuale della macchina ed il suo secondo argomento opzionale, `priority_number`.

Se `TakeANumberDeluxe.State.serve_next_queued_number/2` restituisce una tupla `{:ok, next_number, new_state}`, la macchina deve rispondere al chiamante con il prossimo numero e impostare il nuovo stato come proprio stato. Se invece restituisce una tupla `{:error, error}`, la macchina deve rispondere al chiamante con l'errore e non cambiare il proprio stato.

```elixir
{:ok, machine} = TakeANumberDeluxe.start_link(min_number: 1, max_number: 10)
TakeANumberDeluxe.queue_new_number(machine)
# => {:ok, 1}

TakeANumberDeluxe.serve_next_queued_number(machine)
# => {:ok, 1}

TakeANumberDeluxe.serve_next_queued_number(machine)
# => {:error, :empty_queue}
```

## 5. Reimposta lo stato

Implementa la funzione `reset_state/1` e il callback `GenServer` necessario.

Deve chiamare la funzione `TakeANumberDeluxe.State.new/2` per creare un nuovo stato usando `min_number` e `max_number` dello stato attuale. La macchina deve impostare il nuovo stato come proprio stato. Non deve rispondere al chiamante.

```elixir
{:ok, machine} = TakeANumberDeluxe.start_link(min_number: 1, max_number: 10)

TakeANumberDeluxe.reset_state(machine)
# => :ok
```

## 6. Implementa lo spegnimento automatico

Modifica l'avvio della macchina. Deve leggere il valore sotto la chiave `:auto_shutdown_timeout` nella keyword list passata come `init_arg` e passarlo come terzo argomento a `TakeANumberDeluxe.State.new/3`. Usa il valore predefinito `:infinity` se `:auto_shutdown_timeout` non è stato fornito.

Modifica la reimpostazione dello stato della macchina in modo che passi `auto_shutdown_timeout` anche a `TakeANumberDeluxe.State.new/3`.

Modifica i valori restituiti da tutti i callback implementati (`init/1` e tutti i callback `handle_*`) per impostare un timeout. Usa il valore sotto la chiave `:auto_shutdown_timeout` nello stato attuale della macchina. Non aggiungere il timeout al valore restituito `{:stop, reason}` di `init/1`: i timeout si applicano solo dopo che il server ha avviato il suo ciclo di ricezione.

Implementa un callback `GenServer` per gestire il messaggio `:timeout` che verrà inviato alla macchina se non riceve altri messaggi entro il timeout indicato. Deve terminare il processo con motivo `:normal`.

Assicurati anche di gestire eventuali messaggi imprevisti ignorandoli.

```elixir
{:ok, machine} =
  TakeANumberDeluxe.start_link(
    min_number: 1,
    max_number: 10,
    auto_shutdown_timeout: :timer.hours(2)
  )

# after 3 hours...

TakeANumberDeluxe.queue_new_number(machine)
# => ** (exit) exited in: GenServer.call(#PID<0.171.0>, :queue_new_number, 5000)
#        ** (EXIT) no process: the process is not alive or there's no process currently associated with the given name, possibly because its application isn't started
#       (elixir 1.13.0) lib/gen_server.ex:1030: GenServer.call/3
```
