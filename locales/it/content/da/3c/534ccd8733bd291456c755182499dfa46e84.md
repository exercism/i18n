# Introduzione

Una funzione in Cairo ti permette di raggruppare il codice in un'unità riutilizzabile, rendendo i tuoi programmi più modulari e più facili da capire.
In Cairo, una funzione è composta dalla parola chiave `fn`, seguita dal nome della funzione, da un elenco di parametri tra parentesi e da un blocco di codice che definisce cosa fa la funzione.

## Parametri di una funzione

In Cairo, tutti i parametri di una funzione devono avere un tipo esplicito.
A differenza di altri linguaggi, Cairo non deduce i tipi e non esistono valori predefiniti per i parametri: tutti i parametri sono obbligatori.

```rust
// Function with no parameters
fn print_hello() {
    // Function body
}

// Function with two parameters
fn print_greeting_name(greeting: ByteArray, name: ByteArray) {
    // Function body
}
```

## Differenza tra parametri e argomenti

È importante distinguere tra `parameters` e `arguments`:

- I **parametri** sono i nomi delle variabili usati nella definizione della funzione, come `greeting` e `name` nella funzione `print_greeting_name`.
- Gli **argomenti** sono i valori effettivi passati alla funzione quando viene chiamata.

```rust
// Calling the function with arguments
print_greeting_name(123, 456)
```

## Istruzioni ed espressioni

Il corpo di una funzione è composto da una serie di istruzioni che, facoltativamente, terminano con un'espressione.

- Le istruzioni sono comandi che compiono un'azione e non restituiscono un valore.
- Le espressioni producono un valore risultante.

Creare una variabile e assegnarle un valore con la parola chiave `let` è un'istruzione.

```rust
let y = 6;
```

Ma il `6` nell'istruzione qui sopra è un'espressione che ha come valore `6`.

Chiamare una funzione è un'espressione, perché ha sempre un valore: il valore restituito esplicitamente dalla funzione, se indicato, oppure il tipo «unit» `()` in caso contrario.

## Valori restituiti

Le funzioni in Cairo possono restituire valori al codice che le chiama.
I valori restituiti si elencano dopo i parametri, separati da una freccia `->`.
In Cairo, il valore restituito da una funzione coincide con il valore dell'ultima espressione nel blocco che forma il corpo della funzione.
Puoi uscire anticipatamente da una funzione usando la parola chiave `return` e indicando un valore.

```rust
// Function returning the last (and only) expression
fn hello(name: ByteArray) -> ByteArray {
    "Hello " + name
}

// Function returning using the `return` keyword
fn double_if_even(value: u32) -> u32 {
    if value % 2 == 0 {
        return value * 2;
    }
    return value;
}
```

## Chiamare una funzione

Per chiamare una funzione in Cairo, basta usare il nome della funzione seguito dagli argomenti tra parentesi.

```rust
// Calling a function with no parameters
print_hello()

// Calling a function with one parameter
let greeting = hello("John")

// Calling a function with multiple parameters
print_greeting_name("Howdy", "Joel")
```
