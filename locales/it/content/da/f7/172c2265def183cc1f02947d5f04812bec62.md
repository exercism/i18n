# Informazioni

Il `<iota>` di Factor produce una sequenza *virtuale* degli interi
`0, 1, …, n-1`. Percorrerla con `map` dà una sequenza tabulata
in cui ogni elemento è una funzione della sua posizione:

```factor
USING: math sequences ;

5 <iota> [ sq ] map .         ! => { 0 1 4 9 16 }
8 <iota> [ 1 + ] map .        ! => { 1 2 3 4 5 6 7 8 }
```

Due elementi permettono di trasformare una sequenza di codici
interi in una stringa:

| parola    | ruolo                                                            |
|-----------|------------------------------------------------------------------|
| `CHAR:`   | letterale risolto in fase di analisi che inserisce nello stack il code point di un carattere |
| `>string` | converte una sequenza di code point in una stringa               |

Combinati, formano la forma idiomatica standard per costruire una
riga di caratteri indicizzati per posizione:

```factor
USING: kernel math sequences strings ;

10 <iota> [ 2 mod zero? [ CHAR: O ] [ CHAR: . ] if ] map >string .
! => "O.O.O.O.O."
```

Scegliere il carattere con `if` (o `?`) all'interno della quotation
mantiene la decisione per ciascuna posizione vicina all'indice da cui dipende.
