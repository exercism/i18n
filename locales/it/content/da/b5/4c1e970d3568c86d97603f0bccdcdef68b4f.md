# Break, Continue

Quando si usa una struttura di controllo che esegue cicli o iterazioni, le parole chiave `break` e `continue` possono aiutare a controllare il flusso di un programma.
La parola chiave `break` interrompe il contesto del ciclo e passa allo scope esterno, terminando così il ciclo.
La parola chiave `continue` salta il resto dell'iterazione corrente e riavvia il contesto del ciclo dall'inizio dell'iterazione successiva.
Per quanto poco comune, è possibile indicare un numero insieme alla parola chiave per controllare quanti contesti interrompere o quanti saltare per passare all'iterazione successiva.

```php
<?php
$i = 1;
while ($i <= 10) {

    if ($i <= 5) {
        i += 1;
        continue;
    }
    break;
}
```

Nell'esempio precedente, `continue` viene eseguito cinque (5) volte, ma alla sesta (6) iterazione viene eseguito `break`, facendo uscire il codice dal ciclo.
