# Risorse

## Risorse di apprendimento consigliate

ClojureScript è un dialetto di Clojure progettato con cura. Le conoscenze di Clojure (il linguaggio, non la piattaforma host, ovvero la JVM) si possono usare anche in ClojureScript.

- [ClojureScript API](http://cljs.github.io/api/), documentazione ufficiale dell'API.
- [Clojurescript Cheat-Sheet](https://clojure.org/api/cheatsheet), un cheat sheet ufficiale.
- [Learn Clojurescript Syntax in 15 minutes](https://github.com/shaunlebron/ClojureScript-Syntax-in-15-minutes), un repository GitHub per insegnarti la sintassi del linguaggio.
