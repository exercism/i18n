# Informazioni

Un [ciclo while][while-loops] è un'istruzione di controllo di flusso che permette di eseguire del codice finché una certa condizione è vera.
Swift mette a disposizione due tipi di ciclo while: il ciclo while e il ciclo repeat-while.
La condizione del ciclo while viene valutata prima che il corpo del ciclo venga eseguito; se la condizione è falsa, il corpo del ciclo non verrà eseguito affatto.
I cicli while in Swift hanno la seguente struttura:

```swift
while <#condition#> {
  <#code#>
}
```

Qui il ciclo verrà eseguito finché count è maggiore di 0, e stamperà quindi i numeri 2, 1 e «Liftoff!».

```swift
var count = 2
while count > 0 {
  print("\(count)…")
  count -= 1
}
print("Liftoff!")

// prints:
// 2…
// 1…
// Liftoff!
```

Un [ciclo repeat-while][while-loops] è simile a un ciclo while, ma la condizione viene valutata dopo che il corpo del ciclo è stato eseguito.
Questo significa che il corpo del ciclo verrà eseguito sempre almeno una volta, anche se la condizione è falsa.
I cicli repeat-while in Swift hanno la seguente struttura:

```swift
repeat {
  <#code#>
} while <#condition#>
```

Qui il ciclo verrà eseguito una sola volta, dato che la condizione è falsa.
Trattandosi di un ciclo repeat-while, il corpo del ciclo verrà eseguito una volta prima che la condizione venga valutata.

```swift
var count = 2
repeat {
  print("\(count)…")
} while count < 0
print("Liftoff!")
```

## Cicli con optional binding

Una variante comune dei cicli while in Swift è il ciclo while con optional binding.
Questi cicli si ripetono fintanto che la chiamata a una qualche funzione che produce un valore opzionale restituisce un valore diverso da `nil`.
Quel valore (non opzionale) viene poi associato a un nome a tua scelta e può essere usato nel corpo del ciclo.

```swift
var arr = [1,2]
while let count = arr.popLast() {
  print("\(count)…")
}
print("Liftoff!")

// prints:
// 2…
// 1…
// Liftoff!
```
