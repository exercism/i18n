# Appendice alle istruzioni

## Implementazione

Se l'ultimo elemento dell'array è un `object` invece di una `string`, conterrà un qualificatore che modifica la riga finale del proverbio.

```javascript
proverb('nail', 'shoe', { qualifier: 'horseshoe' });
// => For want of a nail the shoe was lost.
//    And all for the want of a horseshoe nail.
```
