# Approfondimento

In Rust i booleani sono rappresentati dal tipo `bool`, i cui valori possono essere `true` oppure `false`.

Rust supporta un solo [operatore di negazione booleana][negation operators]: `!` (NOT).

Rust supporta sei [operatori di confronto][comparison operators]: `==` (uguale), `!=` (diverso), `>` (maggiore di), `<` (minore di), `>=`
(maggiore o uguale a), `<=` (minore o uguale a). Si possono usare per valutare la relazione tra valori non booleani, producendo un valore
booleano.

```rust
1 > 0 // true
1 < 0 // false
1 == 0 // false
1 != 0 // true
1 >= 0 // true
1 <= 0 // false
```

A differenza di altri linguaggi, `0` non è `false` ed un valore diverso da zero non è `true`.

Rust supporta tre [operatori binari logici][logical binary operators]: `&` (AND logico), `|` (OR logico), `^` (XOR logico).

Rust supporta due [operatori booleani][lazy boolean operators]: `||` (OR), `&&` (AND). Si differenziano da `|` e `&` perché l'operando di destra
viene valutato solo quando l'operando di sinistra non determina già il risultato dell'espressione. In altre parole, `||` valuta
il suo operando di destra solo quando l'operando di sinistra è `false`, e `&&` solo quando è `true`.

```rust
true || false // == true; the right-hand side was not evaluated
true && false // == false
```
