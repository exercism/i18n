# Resto

In matematica, il **resto** è la quantità che «avanza» dopo aver eseguito un calcolo.
Per esempio, il resto di `5 / 3` è `2`.

Molti linguaggi di programmazione usano il simbolo di percentuale (`%`) come operatore per calcolare il resto.
Per esempio:
```javascript
5 % 3 == 2
```

Spesso il resto si può calcolare sia sui numeri interi sia sui numeri in virgola mobile.
Per esempio,
```javascript
5.3 % 3 == 2.3
```

Quando si lavora con numeri negativi, il risultato ha sempre lo stesso segno del dividendo (il numero che si trova a sinistra e che viene diviso).
Per esempio:
```javascript
-5 % 3 == -2
5 % -3 == 2
-5 % -3 == -2
```

Alcuni linguaggi (come Python) usano l'operatore `%` per calcolare il modulo, non il resto.
In questo modo i numeri negativi vengono trattati diversamente.
Puoi saperne di più [su Wikipedia](https://en.wikipedia.org/wiki/Modulo).
