# Introduzione

## Condizionali: if

### Operatori logici

Java supporta i tre operatori logici `&&` (AND), `||` (OR) e `!` (NOT).

### L'istruzione if

Il tipo alla base di qualsiasi operazione condizionale è il tipo `boolean`, che può avere il valore `true` o `false`. Spesso i condizionali si usano come meccanismi di controllo del flusso per verificare diverse condizioni. Per verificare un caso particolare si può usare un'istruzione `if`, che esegue il suo codice se la condizione sottostante è `true`, in questo modo:

```java
int val;

if(val == 9) {
    // conditional code
}
```

Quando i casi sono più di uno, più istruzioni `if` possono essere concatenate tra loro usando le istruzioni `else if` ed `else`.

```java
if(val == 10) {
    // conditional code
} else if(val == 17) {
    // conditional code
} else {
    // executes when val is different from 10 and 17
}
```

### L'istruzione switch

Java fornisce anche un'istruzione `switch` per gli scenari con più opzioni.

```java
int val;

// switch statement on variable content
switch(val) {
    case 1:
        // conditional code
        break;
    case 2: case 3: case 4:
        // conditional code
        break;
    default:
        // if all cases fail
        break;
}
```
