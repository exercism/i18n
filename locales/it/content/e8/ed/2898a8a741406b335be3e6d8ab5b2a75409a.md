# Introduzione

Le istruzioni condizionali di Factor scelgono tra le **quotation**, cioè frammenti di
codice scritti tra parentesi quadre, `[ ... ]`. Scrivere `[ ... ]` mette il codice sullo
stack come valore invece di eseguirlo: poi l'istruzione condizionale decide quale
quotation eseguire. (Le quotation sono trattate in modo completo in un esercizio
successivo.)

`if` (in [`kernel`][kernel]) è l'istruzione condizionale di base di Factor. Prende un
valore booleano e due quotation: esegue la prima se il booleano è vero, altrimenti la
seconda.

```
if ( ? then-quot else-quot -- )
```

```factor
: abs ( x -- y ) dup 0 < [ neg ] [ ] if ;
```

`when` esegue la sua quotation solo quando il booleano è vero, `unless` solo quando è
falso. Per le diramazioni multiple c'è `cond` (in [`combinators`][combinators]):

```factor
USING: combinators ;

: classify ( n -- s )
    {
        { [ dup 0 <  ] [ drop "negative" ] }
        { [ dup 0 =  ] [ drop "zero"     ] }
        [ drop "positive" ]
    } cond ;
```

[combinators]: https://docs.factorcode.org/content/vocab-combinators.html
