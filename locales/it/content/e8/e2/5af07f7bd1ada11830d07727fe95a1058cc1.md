# Istruzioni

In questo esercizio devi implementare alcune funzioni per manipolare un array di linguaggi di programmazione.

## 1. Definisci una funzione che restituisce un array di linguaggi vuoto

Definisci la funzione `new/0` che non prende argomenti e restituisce un array vuoto.

```elixir
LanguageList.new()
# => []
```

## 2. Definisci una funzione che aggiunge un linguaggio all'array

Definisci la funzione `add/2` che prende 2 argomenti (un _array di linguaggi_ e una stringa letterale di un _linguaggio_). Deve restituire l'array risultante, con il nuovo linguaggio anteposto all'array dato.

```elixir
language_list = LanguageList.new()
# => []
language_list = LanguageList.add(language_list, "Clojure")
# => ["Clojure"]
language_list = LanguageList.add(language_list, "Haskell")
# => ["Haskell", "Clojure"]
```

## 3. Definisci una funzione che rimuove un linguaggio dall'array

Definisci la funzione `remove/1` che prende 1 argomento (un _array di linguaggi_). Deve restituire l'array senza il primo elemento. Supponi che l'array abbia sempre almeno un elemento.

```elixir
language_list = LanguageList.new()
# => []
language_list = LanguageList.add(language_list, "Clojure")
# => ["Clojure"]
language_list = LanguageList.add(language_list, "Haskell")
# => ["Haskell", "Clojure"]
language_list = LanguageList.remove(language_list)
# => ["Clojure"]
```

## 4. Definisci una funzione che restituisce il primo elemento dell'array

Definisci la funzione `first/1` che prende 1 argomento (un _array di linguaggi_). Deve restituire il primo linguaggio nell'array. Supponi che l'array abbia sempre almeno un elemento.

```elixir
language_list = LanguageList.new()
# => []
language_list = LanguageList.add(language_list, "Elm")
# => ["Elm"]
language_list = LanguageList.add(language_list, "Prolog")
# => ["Prolog", "Elm"]
LanguageList.first(language_list)
# => "Prolog"
```

## 5. Definisci una funzione che restituisce quanti linguaggi ci sono nell'array

Definisci la funzione `count/1` che prende 1 argomento (un _array di linguaggi_). Deve restituire il numero di linguaggi nell'array.

```elixir
language_list = LanguageList.new()
# => []
language_list = LanguageList.add(language_list, "Elm")
# => ["Elm"]
language_list = LanguageList.add(language_list, "Prolog")
# => ["Prolog", "Elm"]
LanguageList.count(language_list)
# => 2
```

## 6. Definisci una funzione che determina se l'array include un linguaggio funzionale

Definisci la funzione `functional_list?/1` che prende 1 argomento (un _array di linguaggi_). Deve restituire un valore booleano. Deve restituire true se _«Elixir»_ è uno dei linguaggi nell'array.

```elixir
language_list = LanguageList.new()
# => []
language_list = LanguageList.add(language_list, "Elixir")
# => ["Elixir"]
LanguageList.functional_list?(language_list)
# => true
```
