# Introduzione

## Agent

Il modulo `Agent` fornisce un'astrazione per avviare [processi e il ciclo _receive-send_][exercism-processes]. Da qui in avanti chiameremo «processi agente» i processi avviati tramite il modulo `Agent`. Un processo agente può essere scelto per rappresentare uno stato condiviso centrale.

Per avviare un processo agente, `Agent` mette a disposizione la funzione `start/2`. La funzione che passi a `start` quando avvii il processo agente restituisce lo stato iniziale del processo:

```elixir
# Start an agent process with an initial value of an empty list
{:ok, agent_pid} = Agent.start(fn -> [] end)
```

Proprio come `Map` o `List`, `Agent` fornisce molte funzioni per lavorare con i processi agente.

È prassi comune organizzare e incapsulare tutte le funzionalità legate ad `Agent` in un modulo dedicato al dominio che stiamo modellando.

[exercism-processes]: https://exercism.org/tracks/elixir/concepts/processes
