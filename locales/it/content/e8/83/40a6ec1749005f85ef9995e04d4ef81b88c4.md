# Appendice alle istruzioni

## Registri

| Registro | Utilizzo  | Tipo    | Descrizione                                  |
| -------- | --------- | ------- | -------------------------------------------- |
| `$a0`    | input     | indirizzo | stringa di caratteri ottali terminata da null |
| `$v0`    | output    | numero intero | valore decimale della stringa di input    |
| `$t0-9`  | temporaneo | qualsiasi | usato come memoria temporanea                 |
