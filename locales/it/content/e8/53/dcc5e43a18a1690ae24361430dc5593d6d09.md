# Appendice alle istruzioni

## Implementazione

Alcuni editor eliminano gli spazi bianchi.
Se fai affidamento sugli spazi bianchi in coda a una stringa multilinea, usa invece un formato che non dipenda dagli spazi in coda, oppure modifica le impostazioni del tuo editor.

[Una guida rapida per le stringhe multilinea in Ruby](https://commandercoriander.net/blog/2014/11/09/a-multiline-string-cheatsheet-for-ruby/)
