# Introduzione

## Try/Rescue/Else/After

Usare `try..rescue` è un costrutto potente per intercettare gli errori quando si verificano. Intercettare gli errori permette alle funzioni di restituire valori definiti quando è necessario. Il costrutto `try..rescue` ci offre anche due funzionalità aggiuntive di cui possiamo avvalerci:

- il blocco `else`
  - Quando il blocco try ha successo, il risultato viene messo in corrispondenza con questo blocco.
- il blocco `after`
  - Che il blocco try abbia successo o sollevi un'eccezione, il codice nel blocco `after` viene sempre eseguito, purché in quel momento il programma sia in esecuzione.
  - Il risultato del blocco `after` non viene restituito allo scope chiamante.

```elixir
try do
  :a
rescue
  _ -> :error
else
  :a -> :success
after
  :some_action
end

# => :success
```

## Dynamic Dispatch

Quando Elixir risolve la funzione da chiamare, usa il nome del Module per eseguire una ricerca. La ricerca può essere eseguita dinamicamente se il nome del Module è associato a una variabile.

```elixir
defmodule MyModule do
  def message(), do: "My message"
end

atom = MyModule
atom.message()
# => "My message"
```

Internamente, il nome di un Module è un atomo. Tutti gli atomi dei moduli Elixir hanno automaticamente il prefisso `Elixir.`

```elixir
is_atom(Enum)
# => true
Enum == Elixir.Enum
# => true
```
