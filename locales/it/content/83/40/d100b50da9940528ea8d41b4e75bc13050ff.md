# Test

Per eseguire i test, esegui il comando `v test .` dall'interno della directory dell'esercizio.

Se vuoi vedere tutti i test che sono stati eseguiti insieme alle statistiche sulla velocità, usa `v -stats test .`

Per ulteriori informazioni sui test in V, consulta [la documentazione](https://github.com/vlang/v/blob/master/doc/docs.md#testing).
