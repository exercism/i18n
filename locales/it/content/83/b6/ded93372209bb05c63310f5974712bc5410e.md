# Appendice alle istruzioni

## Parole

Definisci una tupla `school` per contenere il registro: come memorizzare gli studenti al suo interno dipende da te. Poi implementa le parole elencate di seguito.

- `<school> ( -- school )`: costruisce una scuola vuota.
- `add-student ( school name grade -- ? )`: aggiungi `name` a
  `grade`. Restituisci `t` in caso di successo, oppure `f` se `name`
  è già presente (in questa o in qualsiasi altra classe); in tal caso
  il registro resta invariato.
- `roster ( school -- names )`: tutti gli studenti, ordinati per classe
  e poi alfabeticamente per nome.
- `grade ( school n -- names )`: gli studenti della classe `n`,
  ordinati alfabeticamente per nome.
