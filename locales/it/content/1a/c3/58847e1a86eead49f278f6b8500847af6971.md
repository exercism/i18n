# Suggerimenti

## Generale

- `MACRO:` si trova in [`macros`][macros]. I pezzi di base si trovano in
  `kernel` (`dup`, `curry`), `sequences` (`append`, `concat`,
  `<repetition>`, `map`) e `quotations` (`>quotation`).
- Il corpo di una macro deve lasciare **una sola quotation** sullo stack. Se il
  corpo produce un array di codice, termina con `>quotation`.
- Per verificare il tuo ragionamento, esegui le parole del corpo su un letterale
  nel listener e guarda la quotation che ottieni: dovrebbe essere
  il codice lineare della riga «compila in» del compito.

## 1. Due volte

- Ricevi `[ A ]` e vuoi `[ A A ]`. Fai una copia e uniscile:
  `dup append`.

## 2. N ripetizioni

- Ricevi `[ A ] n` e vuoi `n` copie unite insieme.
- `<repetition>` costruisce le copie, ma il suo effetto è
  `( length elt -- repetition )`: il conteggio deve stare in cima, quindi prima
  `swap`.
- Poi appiattisci e converti: `swap <repetition> concat >quotation`.

  ```factor
  ! stack: [ 1 + ] 3
  swap <repetition>     ! 3 copies of [ 1 + ]
  concat >quotation     ! => [ 1 + 1 + 1 + ]
  ```

## 3. Comporre molte

- Ricevi già l'array di quotation; ti serve solo appiattirlo in una sola.
  `concat >quotation` è l'intero corpo.

## 4. Iterazione srotolata

Ricevi una sequenza e una quotation, per esempio `{ 10 20 30 } [ + ]`,
e vuoi `[ 10 + 20 + 30 + ]`. Costruiscilo in tre mosse.

**Un elemento.** Incorporare un elemento nella quotation è esattamente
ciò che fa `curry`:

```factor
10 [ + ] curry .   ! => [ 10 + ]
```

**Ogni elemento.** Vuoi applicare `map` su tutta la sequenza, ma
`map` passa alla quotation di mappatura un solo input (l'elemento),
mentre ogni volta ti serve anche `[ + ]` a disposizione. Quindi incorpora
prima `[ + ]` nella quotation di mappatura, sempre con `curry`:

```factor
! stack: { 10 20 30 } [ + ]
[ curry ] curry    ! => { 10 20 30 } [ [ + ] curry ]
map                ! runs  10 [ + ] curry,  20 [ + ] curry, …
                   ! => { [ 10 + ] [ 20 + ] [ 30 + ] }
```

`[ curry ] curry` si legge come «metti sullo stack la piccola quotation
`[ curry ]`, poi incorpora `[ + ]` al suo interno con curry», ottenendo
`[ [ + ] curry ]`. Applicando `map` su un elemento `e` si esegue
`e [ + ] curry`, che è `[ e + ]`.

**Uniscile.** Stesso finale degli altri compiti:

```factor
concat >quotation  ! => [ 10 + 20 + 30 + ]
```

- Il corpo completo: `[ curry ] curry map concat >quotation`.
