# Introduzione

Factor ha due valori booleani: `t` (vero) e `f` (falso). Ovunque serva
una risposta «sì/no», le parole ne impilano uno sullo stack.

Gli operatori booleani si trovano in [`kernel`][kernel]:

```
and ( a b -- ? )
or  ( a b -- ? )
not ( a -- ? )
```

```factor
t f and .   ! => f
t f or .    ! => t
f not .     ! => t
```

`f` è anche l'unico valore *falsy* di Factor. Ogni altro valore (stringhe
vuote, zero, array vuoti) viene considerato *truthy*.

[kernel]: https://docs.factorcode.org/content/vocab-kernel.html
