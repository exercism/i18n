# Il debug

Per facilitare il debug, puoi sfruttare il fatto che tutto l'output della console viene catturato e mostrato nella finestra dei risultati dei test.
Puoi mandare in output qualsiasi valore passandolo a `@show`.

`@show` mostra un'espressione e il suo risultato, restituendo quest'ultimo.

```julia
@show uppercase("hello") # HELLO will be shown as debug output
```

```julia-repl
julia> function f(a, b)
           @show a b
           return (@show a^b) / 1000
       end
f (generic function with 1 method)

julia> f(3, 5)
a = 3
b = 5
a ^ b = 243
0.243
```

Puoi anche usare [`println`](https://docs.julialang.org/en/v1/base/io-network/#Base.println) o qualsiasi altro metodo che scrive l'output su [`stdout`](https://en.wikipedia.org/wiki/Standard_streams#Standard_output_(stdout)).
