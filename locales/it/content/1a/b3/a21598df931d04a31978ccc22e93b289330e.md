# Test

  ## Panoramica rapida

  1. Apporta le modifiche nel file `<myFileName>.u`
  2. Salva il file `<myFileName>.u`
  3. Se il file supera il controllo dei tipi, esegui i comandi `add` o `update` di UCM
    * Se il file non supera il controllo dei tipi, modifica il codice nel file `<myFileName>.u` finché non compila. Ricorda di eseguire `update` sulle funzioni dopo le modifiche!
  4. Esegui il comando `load <myFileName>.test.u` nella CLI di UCM per portare i test nello scope ed eseguirli

  ## Passo per passo

  Se stai lavorando a un problema di Exercism dalla riga di comando, molto probabilmente implementerai la soluzione nella directory che prende il nome dall'esercizio indicato. Ad esempio, se l'esercizio è `hello-world`, dovresti aprire `ucm` dalla riga di comando dopo aver eseguito `cd` in `~/exercism/unison/hello-world`. Apporta le modifiche all'implementazione nel file `hello.u` e, quando sei soddisfatto dell'implementazione, digita il comando `add` o `update` nella CLI di Unison codebase manager (UCM) per aggiungere al codebase il lavoro svolto nel file.

  Il file che contiene i test di ogni esercizio ha il suffisso `.test.u`. Ti conviene usare il comando `load` di UCM per portare i test nello scope ed eseguirli. Il comando `load` prende un percorso di file come argomento. Ecco come potrebbe apparire per l'esercizio hello world:

  ```
  .> load hello.test.u
  ```

  Dovresti vedere un messaggio di UCM sui termini che sono stati portati nello scope e, cosa importante, il risultato dell'esecuzione del test:

  ```

    ⍟ These new definitions are ok to `add`:

      hello.test : Test.Test
      tests      : [Result]

  Now evaluating any watch expressions (lines starting with
  `>`)... Ctrl+C cancels.


    6 | test> tests = runAll [hello.test]

    🚫 FAILED
  ```

  Supponiamo che i test non siano passati la prima volta. Torna a modificare il file `myExercise.u` e, dopo aver salvato, puoi eseguire `update`

  ```
  I found and typechecked these definitions in ~/Exercism/unison/hello-world/hello.u. If you do an
  `add` or `update`, here's how your codebase would change:

    ⍟ These names already exist. You can `update` them to your new definition:

      hello : Text

  .> update

  ⍟ I've updated these names to your new definition:

    hello : Text
  ```

  Ora possiamo ricaricare i test per vedere se qualcosa è cambiato!

  ```
  .> load hello.test.u
    Now evaluating any watch expressions (lines starting with `>`)... Ctrl+C cancels.


    6 | test> tests = runAll [hello.test]

    ✅ Passed : Passed 1 tests.
  ```
