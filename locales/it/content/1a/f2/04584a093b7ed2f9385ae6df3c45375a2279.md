# Istruzioni

In questo esercizio scriverai codice per tenere traccia di un array di linguaggi di programmazione che vuoi imparare su Exercism.
Hai sei attività, che avranno tutte a che fare con gli array.

## 1. Creare un nuovo array

Per tenere traccia dei linguaggi che vuoi imparare, dovrai creare un nuovo array.
Definisci la costante `newList` che contiene un nuovo array vuoto.

```elm
newList
    --> []
```

## 2. Definire un array esistente

Al momento hai un foglio di carta che elenca i linguaggi che vuoi imparare: Elm, Clojure e Haskell.
Definisci la costante `existingList` per rappresentare questo array.

```elm
existingList
    --> [ "Elm", "Clojure", "Haskell" ]
```

## 3. Aggiungere un nuovo linguaggio a un array

Mentre esplori Exercism e trovi linguaggi più interessanti, vuoi aggiungerli all'array.
Implementa la funzione `addLanguage` per aggiungere un nuovo linguaggio all'inizio dell'array.

```elm
addLanguage "TypeScript" [ "JavaScript", "CoffeeScript" ]
    --> [ "TypeScript", "JavaScript", "CoffeeScript" ]
```

## 4. Contare i linguaggi nell'array

Contare i linguaggi manualmente è scomodo.
Implementa la funzione `countLanguages` per contare il numero di linguaggi nell'array.

```elm
countLanguages [ "C#", "Racket", "Rust", "Ruby" ]
    --> 4
```

## 5. Invertire l'array

A un certo punto, ti rendi conto che l'array è in realtà ordinato al contrario!
Implementa la funzione `reverseList` per invertire l'array.

```elm
reverseList [ "Prolog", "C", "Idris", "Assembly" ]
    --> [ "Assembly", "Idris", "C", "Prolog" ]
```

## 6. Verificare se l'array è entusiasmante

Anche se ami tutti i linguaggi, Elm ha un posto speciale nel tuo cuore.
Perciò, un array di linguaggi ti entusiasma davvero se:

- Il primo elemento dell'array è Elm.
- Oppure il secondo elemento dell'array è Elm e l'array contiene al massimo tre linguaggi.

Implementa la funzione `excitingList` per verificare se un array di linguaggi è entusiasmante:

```elm
excitingList [ "Nim", "Elm" ]
    --> True
```
