# Introduzione
## Switch

Un'[istruzione switch][switch] ti permette di confrontare un valore con diversi possibili valori corrispondenti.
Ti consente di scrivere codice più conciso rispetto all'uso di più istruzioni `else-if`.
Un'istruzione switch inizia con la parola chiave `switch`, seguita dal valore da confrontare.
Poi puoi definire i casi usando la parola chiave `case`, seguita dal valore con cui confrontare.
La parola chiave `default` serve a definire il caso predefinito quando nessuno dei casi corrisponde.
Come le istruzioni `else-if`, le istruzioni `switch` eseguono solo il blocco di codice associato al primo caso che corrisponde.

```swift
switch value {
case 1:
    print("One")
case 2:
    print("Two")
default:
    print("Other")
}
```

Considera il seguente esempio:

```swift
if str == "apple" {
    print("Let's bake an apple crumble")
} else if str == "lemon" {
    print("Let's bake a lemon meringue pie!")
} else if str == "peach" {
    print("Let's bake a peach pie!")
} else {
    print("Let's buy ice cream.")
}
```

In alternativa, si potrebbe scrivere così:

```swift
switch str {
case "apple":
    print("Let's bake an apple crumble")
case "lemon":
    print("Let's bake a lemon meringue pie!")
case "peach":
    print("Let's bake a peach pie!")
default:
    print("Let's buy ice cream.")
}
```

## Cicli while

Un [ciclo while][while-loops] è un'istruzione di controllo del flusso che permette di eseguire del codice finché una certa condizione è vera.
Swift fornisce due tipi di cicli while: i cicli while e i cicli repeat-while.
La condizione di un ciclo while viene valutata prima che il corpo del ciclo venga eseguito; se la condizione è falsa, il corpo del ciclo non verrà eseguito affatto.
I cicli while in Swift hanno la seguente struttura:

```swift
while <#condition#> {
  <#code#>
}
```

Qui il ciclo verrà eseguito finché count è maggiore di 0, e stamperà quindi i numeri 2, 1 e «Liftoff!».

```swift
var count = 2
while count > 0 {
  print("\(count)…")
  count -= 1
}
print("Liftoff!")

// prints:
// 2…
// 1…
// Liftoff!
```

Un [ciclo repeat-while][while-loops] è simile a un ciclo while, ma la condizione viene valutata dopo che il corpo del ciclo è stato eseguito.
Questo significa che il corpo del ciclo verrà eseguito sempre almeno una volta, anche se la condizione è falsa.
I cicli repeat-while in Swift hanno la seguente struttura:

```swift
repeat {
  <#code#>
} while <#condition#>
```

Qui il ciclo verrà eseguito una sola volta, dato che la condizione è falsa.
Trattandosi di un ciclo repeat-while, il corpo del ciclo verrà eseguito una volta prima che la condizione venga valutata.

```swift
var count = 2
repeat {
  print("\(count)…")
} while count < 0
print("Liftoff!")
```

## Trasferimento del controllo

Swift ha una serie di istruzioni che possono essere usate per modificare il normale flusso di controllo dei cicli.
Queste sono note come istruzioni di trasferimento del controllo.
Hai già visto `return`; questo concetto ne introdurrà altre, tra cui `continue`, `break` e le etichette.
Non tratteremo `fallthrough` in questo concetto, ma puoi trovarne una descrizione nel [libro di Swift][fallthrough].

### Continue

A volte è necessario passare anticipatamente all'iterazione successiva di un ciclo, senza completare il resto delle istruzioni dell'iterazione corrente del ciclo.
La parola chiave `continue` può essere usata a questo scopo.
Quando viene eseguito `continue`, il ciclo salta al controllo successivo per verificare se l'iterazione seguente del ciclo può essere eseguita, cioè il `while` nei cicli while e repeat-while, oppure il controllo della presenza di un altro elemento nella sequenza nei cicli for-in.

```swift
count = 1
while count < 6 {
  count += 1
  if count == 4 { continue }
  print(count)
}

// prints:
// 2
// 3
// 5
```

### Break

`break` serve a uscire anticipatamente da un ciclo.
Quando viene eseguito `break`, il ciclo termina immediatamente e il programma prosegue con la prima istruzione dopo il ciclo.

```swift
for fruit in ["banana", "grapes", "apple", "strawberry", "kiwi", "lemon"] {
  if !fruit.count.isMultiple(of: 2) { break }
  print(fruit)
}

// prints:
// banana
// grapes
```

### Etichette

Quando i cicli sono annidati, a volte può servire usare `break` o `continue` per uscire o riavviare i cicli esterni che contengono il ciclo in cui `break` o `continue` vengono usati.
In casi come questi, le etichette possono essere usate per specificare il ciclo da uscire o da riavviare.
Un ciclo può essere etichettato mettendo un nome seguito da due punti prima del `while`, `repeat` o `for` che avvia il ciclo.

Per vedere l'effetto dell'uso delle etichette in questo modo, considera il seguente ciclo.

```swift
outerLoop: for fruit in ["banana", "grapes", "apple", "strawberry", "kiwi", "lemon"] {
  print("\n--- \(fruit) ---")
  for letter in fruit {
    guard letter != "n" else { break outerLoop }
    print(letter)
  }
}

// prints:
// --- banana ---
// b
// a
```
