# Informazioni

Per creare un'istanza di una _classe_ si chiama il suo [_costruttore_][constructors] tramite l'[operatore `new`][new]. Un costruttore è un tipo speciale di metodo il cui scopo è inizializzare un'istanza appena creata. I [costruttori assomigliano ai metodi normali][constructor-syntax], ma non hanno un tipo restituito e hanno un nome che coincide con quello della classe.

```csharp
class Library
{
    private books;

    public Library()
    {
        this.books = 10;
    }
}

// This will call the constructor
var library = new Library();
```

Come i metodi normali, i costruttori possono avere dei parametri. I parametri del costruttore di solito vengono memorizzati in [campi][fields] (privati) per poterli usare in seguito, oppure servono per un calcolo una tantum. Si possono passare argomenti ai costruttori proprio come si passano gli argomenti ai metodi normali.

```csharp
class Building
{
    private int numberOfStories;
    private int totalHeight;

    public Building(int numberOfStories, double storyHeight)
    {
        this.numberOfStories = numberOfStories;
        this.totalHeight = numberOfStories * storyHeight;
    }
}

// Call a constructor with two arguments
var largeBuilding = new Building(55, 6.2);
```

Specificare un costruttore è facoltativo. Se non viene specificato alcun costruttore, il compilatore genera un [costruttore senza parametri][parameterless-constructors]:

```csharp
class Elevator
{
}

// This will call the (empty) generated constructor
var elevator = new Elevator();
```

Se ai campi viene assegnato un valore iniziale, il compilatore produrrà codice in cui l'assegnazione avviene effettivamente all'interno del costruttore. Le seguenti dichiarazioni di classe sono quindi equivalenti (dal punto di vista del funzionamento):

```csharp
class UsingFieldInitialization
{
    private int players = 5;
}

class UsingConstructorInitialization
{
    private int players;

    public UsingConstructorInitialization()
    {
        players = 5;
    }
}
```
