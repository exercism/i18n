# non confrontare i valori booleani con true o false

Confrontare valori booleani con true o false è ridondante.
Usare `==` genera un valore booleano, quindi non serve confrontarlo con un altro valore booleano scritto esplicitamente.
Se vuoi invertire il valore booleano, usa l'operatore `!`.

```crystal
# Rather than:
some_bool == true
some_bool == false

# Consider:
some_bool
!some_bool
```
