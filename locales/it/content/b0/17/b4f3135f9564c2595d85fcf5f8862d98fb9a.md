# Informazioni

Go contiene tipi numerici di base che possono rappresentare insiemi di valori interi o in virgola mobile.
Esistono tipi diversi a seconda della dimensione del valore che ti serve e dell'architettura del computer su cui gira l'applicazione (ad es. a 32 bit e 64 bit).

Questo concetto si concentrerà su due tipi numerici:

- `int`: ad es. `0`, `255`, `2147483647`.
   Un intero con segno che occupa almeno 32 bit (intervallo di valori: da -2147483648 a 2147483647).
   Ma questo dipenderà dall'architettura del sistema.
   La maggior parte dei computer moderni è a 64 bit, quindi `int` sarà di 64 bit (intervallo di valori: da -9223372036854775808 a 9223372036854775807).

- `float64`: ad es. `0.0`, `3.14`.
   Contiene l'insieme di tutti i numeri in virgola mobile a 64 bit.

Per un elenco completo dei tipi numerici disponibili e per maggiori dettagli, vedi le seguenti risorse:

- [Dichiarazioni dei tipi predefiniti di Go][go-builtins]
- [Digital Ocean - Capire i tipi di dati in Go][do-understanding-types]
- [Arden Labs - Capire i tipi in Go][arden-understanding-types]

Go supporta il set standard di operatori aritmetici `+`, `-`, `*`, `/` e `%` (resto, non modulo).

In Go, assegnare un valore tra tipi diversi richiede una conversione esplicita.
Ad esempio, per convertire un `int` in un `float64` devi fare quanto segue:

```go
var x int = 42
f := float64(x)

fmt.Printf("x is of type: %s\n", reflect.TypeOf(x))
// Output: x is of type: int

fmt.Printf("f is of type: %s\n", reflect.TypeOf(f))
// Output: f is of type: float64
```

Per maggiori informazioni sulla conversione di tipo, vedi [A Tour of Go: conversioni di tipo][type-conversion]
