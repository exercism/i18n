# Istruzioni

In questo esercizio costruirai la gestione degli errori per una semplice calcolatrice.

L'obiettivo è avere una calcolatrice funzionante che restituisce una stringa con il seguente formato: `16 + 51 = 67`, quando riceve gli argomenti `16`, `51` e `+`.

```ruby
SimpleCalculator.calculate(16, 51, "+")
# => "16 + 51 = 67"
SimpleCalculator.calculate(32, 6, "*")
# => "32 * 6 = 192"
SimpleCalculator.calculate(512, 4, "/")
# => "512 / 4 = 128"
```

## 1. Gestire il codice che può sollevare errori all'interno del metodo `calculate`

Il metodo principale da implementare in questa attività sarà il metodo di classe `SimpleCalculator.calculate()`.
Accetta tre argomenti.
I primi due argomenti sono numeri sui quali verrà eseguita un'operazione.
Il terzo argomento è di tipo stringa e per questo esercizio è necessario implementare le seguenti operazioni:

- l'addizione usando la stringa `+`
- la moltiplicazione usando la stringa `*`
- la divisione usando la stringa `/`

## 2. Gestire le operazioni non valide

Aggiorna il metodo `SimpleCalculator.calculate()` in modo che sollevi un'eccezione `UnsupportedOperation` per i simboli di operazione sconosciuti.

```ruby
SimpleCalculator.calculate(1, 2, '-')
# => Raises an UnsupportedOperation
```

~~~~exercism/note
In questo esercizio, ci si aspetta che tu definisca l'eccezione `UnsupportedOperation` per uno scope specifico.
~~~~

## 3. Gestire argomenti non validi

Aggiorna il metodo `SimpleCalculator.calculate()` in modo che sollevi un'eccezione `ArgumentError` per i tipi di argomento non validi.

```ruby
SimpleCalculator.calculate(1, '2', '*')
# => Raises an ArgumentError
```

## 4. Gestire le eccezioni DivideByZero

Aggiorna il metodo `SimpleCalculator.calculate()` per gestire le eccezioni `ZeroDivisionError`.
Il codice di gestione dovrebbe restituire la stringa con il contenuto `Division by zero is not allowed.`.
Qualsiasi altra eccezione non deve essere gestita dal metodo `SimpleCalculator.calculate()`.

```ruby
SimpleCalculator.calculate(512, 0, "/")
# => returns "Division by zero is not allowed."
```
