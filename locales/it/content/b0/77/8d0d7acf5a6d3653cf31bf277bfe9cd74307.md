# Suggerimenti per l'esercizio Minesweeper in Bash

Questo esercizio sembra richiedere un array bidimensionale.
Bash offre solo [array][array] monodimensionali, indicizzati o associativi.

Gli array multidimensionali si possono simulare usando un array associativo: codifica gli indici in una stringa separata da virgole e usala come chiave dell'array.

```bash
# store this matrix:
#   a b
#   c d
declare -A array2d
array2d["0,0"]="a"
array2d["0,1"]="b"
array2d["1,0"]="c"
array2d["1,1"]="d"
```

[array]: https://www.gnu.org/software/bash/manual/bash.html#Arrays
