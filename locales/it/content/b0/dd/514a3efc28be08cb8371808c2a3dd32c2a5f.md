# Istruzioni

In questo esercizio, scriverai del codice per aiutarti a prepararti all'acquisto di un veicolo.

Hai tre attività: una per determinare se ti servirà una patente, una per aiutarti a scegliere tra due veicoli e una per stimare il prezzo accettabile per un veicolo usato.

## 1. Determina se ti servirà la patente di guida

Alcuni tipi di veicoli richiedono la patente di guida per essere guidati.
Supponi che solo i tipi `'car'` e `'truck'` richiedano una patente, tutto il resto si può guidare senza patente.

Implementa la funzione `needsLicense(kind)` che prende il tipo di veicolo e restituisce un valore booleano che indica se ti serve una patente per quel tipo di veicolo.

```javascript
needsLicense('car');
// => true

needsLicense('bike');
// => false
```

## 2. Scegli tra due potenziali veicoli da acquistare

Valuti le tue opzioni tra i veicoli disponibili.
Riesci a restringerle a due opzioni, ma ti serve aiuto per prendere la decisione finale.
Per farlo, implementa la funzione `chooseVehicle(option1, option2)` che prende due veicoli come argomenti e restituisce una decisione che include l'opzione che viene prima in ordine alfabetico.

```javascript
chooseVehicle('Wuling Hongguang', 'Toyota Corolla');
// =>  'Toyota Corolla is clearly the better choice.'

chooseVehicle('Volkswagen Beetle', 'Volkswagen Golf');
// =>  'Volkswagen Beetle is clearly the better choice.'
```

## 3. Calcola una stima per il prezzo di un veicolo usato

Ora che hai preso la decisione, vuoi assicurarti di ottenere un prezzo equo in concessionaria.
Dato che sei interessato ad acquistare un veicolo usato, il prezzo dipende da quanti anni ha il veicolo.
Per una stima approssimativa, supponi che se il veicolo ha meno di 3 anni, costi l'80% del prezzo originale che aveva quando era nuovo di zecca.
Se ha più di 10 anni, costa il 50%.
Se il veicolo ha almeno 3 anni ma non più di 10, costa il 70% del prezzo originale.

Implementa la funzione `calculateResellPrice(originalPrice, age)` che applica questa logica usando `if`, `else if` e `else` (ci sono altri modi se vuoi esercitarti).
Prende il prezzo originale e l'età del veicolo come argomenti e restituisce il prezzo stimato in concessionaria.

```javascript
calculateResellPrice(1000, 1);
// => 800

calculateResellPrice(1000, 5);
// => 700

calculateResellPrice(1000, 15);
// => 500
```
