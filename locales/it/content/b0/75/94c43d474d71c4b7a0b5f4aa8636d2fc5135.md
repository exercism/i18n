# Introduzione

## Cicli while

Con un ciclo while puoi eseguire del codice ripetutamente, finché una certa condizione è soddisfatta.
Si scrive con la parola chiave `while`, seguita da una condizione racchiusa tra parentesi tonde (`()`) e da un blocco di codice che contiene il _corpo_ del ciclo, racchiuso tra parentesi graffe (`{}`).

```javascript
while (condition) {
  // code that is executed repeatedly as long as the condition is true
}
```

JavaScript ha anche il ciclo do-while.
Qui la condizione viene controllata dopo che il corpo del ciclo è stato eseguito.
È utile quando la condizione dipende da valutazioni eseguite nel corpo.

```javascript
do {
  // The code here will always be executed once and then
  // repeatedly while the condition is true.
} while (condition);
```

All'interno del corpo di un ciclo puoi usare la parola chiave `break` per interrompere del tutto l'esecuzione del ciclo.
Al contrario, la parola chiave `continue` interrompe solo l'esecuzione dell'iterazione corrente e passa alla successiva.
Con `continue` puoi spesso evitare di racchiudere grandi parti del corpo del ciclo in un'istruzione if.

```javascript
let i = 0;

while (i < 100) {
  i = i + 2;

  if (i % 3 === 0) {
    continue;
  }

  // The code here will only be executed when i was not divisible
  // by 3 in the check above.
}
```

## Istruzioni switch

Oltre all'istruzione if, JavaScript ha anche l'istruzione switch per eseguire della logica in modo condizionale.
Si usa quando una singola variabile deve essere confrontata con più varianti.
Il confronto avviene verificando l'uguaglianza stretta (`===`), vedi [il confronto][concept-comparison].
Per una variabile `x`, l'istruzione switch in JavaScript ha la seguente sintassi.

<!-- prettier-ignore-start -->
```javascript
switch (x) {
  case option1:
    // code that is executed when "x === option1" is true
    break;
  case option2:
    // code that is executed when "x === option2" is true
    break;
  default:
    // code that is executed when x does not equal any of the options
}
```
<!-- prettier-ignore-end -->

Il caso `default` è opzionale e si usa quando vuoi eseguire del codice se nessuna delle altre opzioni corrisponde alla variabile.

Le istruzioni `break` qui sopra sono necessarie perché, per impostazione predefinita, in JavaScript tutti i casi sono «fallthrough».
Ciò significa che, senza un'istruzione `break`, verrebbe eseguito tutto il codice dei casi successivi alla prima opzione corrispondente, anche se `x` non corrispondeva a quelle opzioni.
Questo comportamento di «fallthrough» predefinito è una trappola comune quando si usa `switch` in JavaScript.
All'interno di una funzione si può anche usare `return` al posto di `break` per evitare questo problema.
