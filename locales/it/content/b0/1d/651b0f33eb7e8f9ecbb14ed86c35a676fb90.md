# Preferire una costante a livello superiore

Prova a estrarre il numero `GIGASECOND` in una costante:

```javascript
const %{name} = %{value}

// the rest of your code below it
export const gigasecond = (...)
```

Solo le funzioni, le classi e le costanti contrassegnate da `export` sono visibili e accessibili dall'esterno. Di solito ha senso dare un nome ai [numeri magici](https://en.wikipedia.org/wiki/Magic_number_%%28programming%%29), il che migliora la manutenibilità. Queste costanti possono vivere nello stesso file senza essere esposte ad altro codice.
