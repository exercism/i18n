# Appendice alle istruzioni

## Registri

| Registro | Uso          | Tipo    | Descrizione                             |
| -------- | ------------ | ------- | --------------------------------------- |
| `$a0`    | input        | indirizzo | stringa di domanda terminata da null  |
| `$v0`    | output       | intero  | risultato, 0 se la domanda non è valida |
| `$t0-9`  | temporaneo   | qualsiasi | per l'archiviazione temporanea        |
