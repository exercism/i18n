# Appendice alle istruzioni

## Il processo di IO

A differenza di altri esercizi, `grep` richiede di interagire con il «mondo esterno»: leggere file, gestire errori di sistema e stampare su `stdout`.

In Lean, l'interazione con il sistema avviene di solito nella monade [IO][io], che permette agli effetti collaterali di verificarsi in un ambiente circoscritto senza intaccare lo stato puro della maggior parte delle altre funzioni.

## Lettura degli argomenti

Lean permette di richiamare un file come script, o direttamente come script autonomo tramite `lean --run`, oppure con l'utilizzo di `lake`.

Un progetto Lean ha un solo punto di ingresso, una funzione chiamata `main`, che riceve una `List String` con tutti gli argomenti passati. Per simulare l'esecuzione di `Grep.lean` come eseguibile, in questo esercizio gli argomenti vengono passati allo stesso modo.

## Lettura dei file

Lean offre delle [funzioni][files] per manipolare i file nella monade `IO.FS`. Per esempio, `IO.FS.readFile` può essere usato per leggere il contenuto di un file in un dato percorso, come `String`.

## Scrittura dell'output

Invece di restituire un valore, questo esercizio richiede che i risultati vengano scritti sull'output standard o sull'errore standard. In Lean ci sono delle [funzioni][console] per questo scopo.

## Gestione degli errori di sistema

A differenza degli errori in `Except`, le eccezioni di `IO` sono effettivamente eccezioni a runtime. Puoi usare `try`/`catch` per gestirle:

```
try
    /- 
        code that may possibly raise an exception 
    -/
catch msg =>
    /-
        code that is executed only if an exception was thrown
    -/
```
