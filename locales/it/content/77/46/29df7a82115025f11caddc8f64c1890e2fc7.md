# Informazioni

Scrivi [ReScript][rescript-lang], rilascia JavaScript.
Costruito sul robusto sistema di tipi di OCaml e successore moderno di BuckleScript e ReasonML, ReScript offre il pattern matching esaustivo e garanzie a tempo di compilazione all'interno dell'ecosistema JavaScript.
La sua integrazione di prima classe con React lo rende una valida alternativa a TypeScript per gli sviluppatori che vogliono una vera sicurezza dei tipi, invece di JavaScript con annotazioni.
Niente `any`, niente `undefined` a sorpresa.

[rescript-lang]: https://rescript-lang.org
