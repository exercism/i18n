# Introduzione

## Funzioni

In Gleam le funzioni si definiscono con la sintassi `pub fn`.

```gleam
pub fn add(x: Int, y: Int) -> Int {
  x + y
}
```

Questa funzione accetta due argomenti, entrambi di tipo `Int`, e restituisce un valore di tipo `Int`. In Gleam non esiste la parola chiave `return`: il valore dell'ultima espressione di una funzione viene sempre _restituito in modo implicito_.

Le annotazioni di tipo per gli argomenti e il tipo restituito sono facoltative, e Gleam controllerà sempre i tipi del tuo codice in modo completo. Di solito chi programma in Gleam aggiunge le annotazioni di tipo alle proprie funzioni per chiarezza, ma puoi ometterle se preferisci.

```gleam
pub fn add(x, y) {
  x + y
}
```

Una funzione si può chiamare con la sintassi `function_name(argument1, argument2)`.

```gleam
pub fn double(x: Int) -> Int {
  // Call the add function defined above
  add(x, x)
}
```

## Variabili

In Gleam le variabili si definiscono con la sintassi `let name = expression`.

```gleam
pub fn main() {
  let count = 1
}
```

Le variabili si possono dichiarare con le annotazioni di tipo. Come per gli argomenti delle funzioni, sono facoltative, anche se la maggior parte di chi programma in Gleam omette le annotazioni di tipo per le variabili per brevità.

```gleam
pub fn main() {
  let count: Int = 1
}
```

## Stringhe letterali

In Gleam le stringhe si scrivono con le virgolette doppie.

```gleam
pub fn greeting() {
  "Hello, world!"
}
```

## Commenti nel codice

I commenti si possono usare per lasciare note ad altri sviluppatori che leggono il codice sorgente. In Gleam i commenti sono righe singole precedute da `//`.

```gleam
pub fn main() {
  // This is a comment
  let x = 1
}
```
