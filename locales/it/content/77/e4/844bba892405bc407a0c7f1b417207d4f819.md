# Introduzione

Le costanti in Gleam sono un modo per dare un nome ai valori. Si definiscono con la parola chiave `const`.

```gleam
pub const pi: Float = 3.14159

pub fn circle_area(radius: Float) -> Float {
  radius *. radius *. pi
}
```

Quando vengono definite con la parola chiave `pub`, le costanti di modulo sono accessibili anche dagli altri moduli; altrimenti sono accessibili solo dall'interno del modulo in cui sono definite.
