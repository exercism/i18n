# Appendice alle istruzioni

## Istruzioni specifiche del track

Devi definire due verbi chiamati `allergic_to` e `list`.

## Input

1. Il verbo `allergic_to` è **diadico**, dove:

    - **Argomento sinistro**: è una stringa che contiene il nome dell'allergene.
    - **Argomento destro**: è il punteggio ottenuto.

1. Il verbo `list` è **monadico**, dove:

    - L'unico argomento è il punteggio ottenuto.

I verbi verranno chiamati con questi argomenti, in questo modo:

```j
  'cats' allergic_to 255
  list 5
```

## Output

L'output del verbo `allergic_to` è un **booleano**.

L'output di `list` è un **array di box**.
