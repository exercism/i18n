# Riferimenti e istantanee

Quando passi una variabile a una funzione, la sua proprietà viene di solito trasferita, rendendo la variabile originale inutilizzabile: questo può essere un po' noioso quando si accede a uno stato più di una volta.
Cairo ha due funzionalità per passare un valore senza distruggerlo o spostarlo, chiamate `references` e `snapshots`.

## Istantanee

Le istantanee forniscono una vista immutabile di un valore in un certo momento, permettendoti di mantenere la proprietà di una variabile mentre accedi al suo stato.
Qualsiasi modifica alla variabile crea una nuova cella di memoria, lasciando invariata la vista dell'istantanea.

```rust
fn get_len(arr: @Array<u128>) -> u32 { // this parameter takes in a snapshot using `@` with the data-type
    arr.len()
}

fn foo(arr: Array<u128>) {
    arr.pop_front();
}

fn main() {
    let mut new_arr: Array<u128> = array![1, 2, 3, 4, 5, 6, 7, 8];
    let snapshot = @new_arr; // using `@` to create a snapshot of a variable
    let len = get_len(snapshot); // pass the snapshot as argument, retaining ownership
    foo(new_arr); // `new_arr` is still valid up until here and no further

    // let new_len = new_arr.len(); // this would throw an error if you uncommented the code because `new_arr` has been moved when it was passed into `foo()` above
}
```

## Operatore desnap

Per riconvertire un'istantanea in una variabile normale, puoi usare l'operatore desnap `*`, che è l'opposto dell'operatore `@`.
Solo i tipi che implementano il trait `Copy` possono subire il desnap.

```rust
#[derive(Drop)]
struct Rectangle {
    height: u64,
    width: u64,
}

fn main() {
    let rec = Rectangle { height: 3, width: 10 };
    let area = calculate_area(@rec);
    println!("Area: {}", area);
}

fn calculate_area(rec: @Rectangle) -> u64 {
    // We need to transform the snapshots back into values using the desnap operator `*`.
    // Here we use `*` to both multiply the height and width and to desnap the snapshots.
    *rec.height * *rec.width
}
```

## Riferimenti mutabili

I riferimenti mutabili ti permettono di passare valori mutabili a una funzione e di averli restituiti implicitamente, mantenendo la proprietà nel contesto chiamante.
Questo si può ottenere usando il modificatore `ref`, a condizione che la variabile sia dichiarata mutabile con la parola chiave `mut`.

```rust
fn foo(ref arr: Array<u128>) { // using `ref` marks the argument as a mutable reference
    arr.pop_front(); // modifies the state of arr
}

fn main() {
    let mut new_arr: Array<u128> = array![1, 2, 3, 4, 5, 6, 7, 8];

    foo(ref new_arr);  // use `ref` to pass a mutable reference to the function

    let new_len = new_arr.len();  // the current context retains ownership of `new_arr`, so we can still use it
}
```
