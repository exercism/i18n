# Introduzione

R non ha un tipo [insieme][wiki-set] separato: usa invece diverse funzioni per svolgere operazioni simili sui vettori.

L'operatore [`%in%`][ref-match] verifica l'appartenenza a un insieme.
Questo operatore infisso è un sinonimo della funzione `is.element()`.

```R
2 %in% 1:10 # TRUE
12 %in% 1:10 # FALSE
```

Tra le funzioni rilevanti ci sono:

- [`unique()`][ref-unique] per rimuovere i duplicati.
- [`union()`][ref-sets] per combinare gli insiemi (matematicamente, `A ∪ B`).
- [`intersect()`][ref-sets] per trovare gli elementi comuni a entrambi gli insiemi (`A ∩ B`).
- [`setdiff()`][ref-sets] per sottrarre un insieme da un altro (`A - B`).
- [`setequal`][ref-sets] per verificare l'uguaglianza tra insiemi, ignorando duplicati e ordinamento.

```R
> set_1 <- c("a", "b", "c", "b", "a")
> unique(set_1) # deduplicate
[1] "a" "b" "c"

> set_2 <- c('a', "c", "d")
> union(set_1, set_2) # values in either set
[1] "a" "b" "c" "d"

> intersect(set_1, set_2) # values in both sets
[1] "a" "c"

> setdiff(set_1, set_2) # values in set_1 but not set_2
[1] "b"

> setdiff(set_2, set_1) # values in set_2 but not set_1
[1] "d"

setequal(set_1, c("c", "b", "a", "b")) # are elements the same after deduplication?
[1] TRUE
```

In ogni caso, la funzione restituisce una copia e lascia invariati gli argomenti.

## Tabelle hash

Le operazioni sui vettori descritte sopra fanno parte di base R.
Sono utili per problemi piccoli, ma diventano lente quando gli insiemi sono grandi.

Vari pacchetti di terze parti implementano le [tabelle hash][wiki-hash], per migliorare le prestazioni in alcuni contesti.

Per esempio, il pacchetto [`hashtable`][ref-hashtable] fornisce implementazioni di `hashmap` e `hashset`, che scalano meglio.
Come la maggior parte dei pacchetti esterni, non è disponibile all'interno di Exercism, ma vale la pena approfondirlo per problemi del mondo reale.
