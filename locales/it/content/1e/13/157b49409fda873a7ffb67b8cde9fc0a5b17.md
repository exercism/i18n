`String` e `&str` sono due modi fondamentali per lavorare con dati testuali in Rust.

`String` è un vettore di byte `u8` posseduto e mutabile.
`&str` è un riferimento preso in prestito a una slice di String e quindi immutabile.

Puoi anche creare e modificare le `String` usando uno dei loro numerosi metodi, come `push`.
```rust
let mut a_string = String::from("hello");
a_string.push('!');
```

Puoi anche creare una `String` convertendo una `&str`:
```rust
let a_string = "hello".to_string();
```
