# Suggerimenti

## Generali

- Tutte le parole per la pulizia si trovano in [`destructors`][destructors].
- `:>` e `::` (locals) mantengono leggibili i corpi multi-pump: aggiungi `locals` a `USING:` se vuoi usarli.

## 1. Svuotare la sentina

- Una sola parola: `dispose`.

## 2. Routine di svuotamento

- Una sola parola: `with-disposal`. Aggiungi `inline` dopo il `;` di chiusura, così il compilatore riesce a vedere attraverso l'argomento quotation:
  `: pump-out ( pump quot -- ) with-disposal ; inline`.

## 3. Routine dell'intero turno

- Apri lo scope con `with-destructors`. All'interno, registra ogni
  pompa con `&dispose`, poi esegui `call` sulla quotation. Con i locals:
  `[ pump-a &dispose pump-b &dispose quot call ] with-destructors`.

## 4. Svuotamento rischioso

- Stessa forma del task 3, ma con `|dispose` (solo in caso di fallimento) su
  una singola pompa.

## 5. Un disposable personalizzato: la valvola

- `TUPLE: valve < disposable is-open ;` — `<` estende `disposable`,
  così la macchina del framework viene ereditata.
- `<valve>` usa `new-disposable` (non il semplice `new`) così la nuova
  valvola viene registrata presso il framework.
- `M: valve dispose*` è l'hook di pulizia. Restituire nulla sullo
  stack è importante: `>>is-open` lascia la tupla in cima, quindi
  termina con `drop`.

[destructors]: https://docs.factorcode.org/content/vocab-destructors.html
