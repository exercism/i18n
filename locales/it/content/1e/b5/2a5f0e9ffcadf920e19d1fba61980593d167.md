# Integrazione con l'editor

Il modo migliore per sviluppare in Clojure è con un REPL collegato all'editor. Sono disponibili plugin per gli editor e gli IDE più diffusi:

- Emacs: [CIDER](https://cider.mx)
- IntelliJ: [Cursive](https://cursive-ide.com)
- VSCode: [Calva](https://calva.io)
- Vim: [Conjure](https://github.com/Olical/conjure)

Per saperne di più, consulta la [documentazione ufficiale](https://clojure.org/guides/editors).
