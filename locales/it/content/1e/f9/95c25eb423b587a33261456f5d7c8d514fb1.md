# Informazioni

Scrivi codice che si legge come una normale frase in inglese.

Visual Basic gira sullo stesso runtime .NET di C# e F#.
Hai a disposizione LINQ, i generics e async/await, ma la sintassi è pensata per essere letta, non per essere decifrata.

Se conosci già C# o F#, il runtime e le librerie .NET ti saranno familiari.
Se conosci VB6, VBA o VBScript, quella sintassi familiare ora poggia sul collaudato runtime .NET.

Niente parentesi graffe da bilanciare, niente punti e virgola da rincorrere.
