# Informazioni

Swift mette a disposizione tre costrutti principali per i cicli:

- **Cicli `while`**: ripetono un blocco di codice finché una condizione specificata resta `true`. La condizione viene valutata prima di eseguire il corpo del ciclo.
- **Cicli `repeat-while`**: simili ai cicli `while`, ma la condizione viene valutata dopo aver eseguito il corpo del ciclo. Questo garantisce che il corpo venga eseguito almeno una volta.
- **Cicli `for-in`**: eseguono un blocco di codice una volta per ogni elemento di una sequenza o collezione (come un intervallo, un array o una stringa).
