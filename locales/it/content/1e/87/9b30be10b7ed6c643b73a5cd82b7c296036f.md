# Istruzioni

In questo esercizio organizzerai delle gare tra vari tipi di auto radiocomandate. Ogni auto ha le proprie caratteristiche di velocità e di consumo della batteria.

Le auto partono con la batteria completamente carica (100%). Ogni volta che guidi l'auto con il radiocomando, questa percorre tanti metri quanti ne indica la sua velocità e riduce la percentuale di batteria rimanente del suo consumo della batteria.

Se la batteria di un'auto è al di sotto della sua percentuale di consumo della batteria, non puoi più guidarla.

Ogni pista ha la sua distanza. Le auto vengono messe alla prova verificando se riescono a completare la pista senza esaurire la batteria.

Hai sei compiti, ognuno dei quali lavorerà con istanze di auto radiocomandate.

## 1. Creare un'auto radiocomandata

Consenti di creare un'auto radiocomandata definendo un costruttore per la classe `RemoteControlCar` che accetta come suoi due parametri la velocità dell'auto in metri e la percentuale di consumo della batteria (entrambi di tipo `int`):

```csharp
int speed = 5;
int batteryDrain = 2;
var car = new RemoteControlCar(speed, batteryDrain);
```

## 2. Creare una pista

Consenti di creare una pista definendo un costruttore per la classe `RaceTrack` che accetta come unico parametro la distanza della pista in metri (di tipo `int`):

```csharp
int distance = 800;
var raceTrack = new RaceTrack(distance);
```

## 3. Guidare l'auto

Implementa il metodo `RemoteControlCar.Drive()` che aggiorna il numero di metri percorsi in base alla velocità dell'auto. Implementa anche il metodo `RemoteControlCar.DistanceDriven()` per restituire il numero di metri percorsi dall'auto:

```csharp
int speed = 5;
int batteryDrain = 2;
var car = new RemoteControlCar(speed, batteryDrain);
car.Drive();

car.DistanceDriven();
// => 5
```

## 4. Verificare se la batteria è scarica

Aggiorna il metodo `RemoteControlCar.Drive()` in modo che scarichi la batteria in base al consumo della batteria dell'auto. Implementa anche il metodo `RemoteControlCar.BatteryDrained()` che indica se la batteria è scarica:

```csharp
int speed = 5;
int batteryDrain = 2;
var car = new RemoteControlCar(speed, batteryDrain);
car.Drive();

car.BatteryDrained();
// => false
```

## 5. Creare l'auto radiocomandata Nitro

L'auto radiocomandata più venduta è la Nitro, che ha una velocità massima impressionante di 50 metri con un consumo della batteria del 4%. Implementa il metodo (statico) `RemoteControlCar.Nitro()` per restituire questo tipo di auto:

```csharp
var car = RemoteControlCar.Nitro();
car.Drive();
car.DistanceDriven();
// => 50
```
## 6. Verificare se un'auto radiocomandata può completare una gara

Per completare una pista, un'auto deve essere in grado di percorrere la distanza della pista. Questo significa non esaurire la batteria prima di aver tagliato il traguardo. Implementa il metodo `RaceTrack.TryFinishTrack()` che accetta come parametro un'istanza di `RemoteControlCar` e restituisce `true` se l'auto può completare la pista; altrimenti, restituisci `false`:

```csharp
int speed = 5;
int batteryDrain = 2;
var car = new RemoteControlCar(speed, batteryDrain);

int distance = 100;
var raceTrack = new RaceTrack(distance);

raceTrack.TryFinishTrack(car);
// => true
```
