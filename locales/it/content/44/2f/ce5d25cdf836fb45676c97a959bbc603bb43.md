# Istruzioni

In questo esercizio scriverai del codice per elaborare un elenco di linguaggi di programmazione con cui hai in programma di fare pratica sulla piattaforma Exercism.

Hai sei attività.

## 1. Crea un nuovo array

Prima di poter aggiungere dei linguaggi, devi iniziare creando un nuovo array. Definisci una funzione che restituisce un array vuoto.

```clojure
(new-list)
;; => ()
```

## 2. Aggiungi un nuovo linguaggio all'array

Mentre esplori Exercism e trovi linguaggi che vuoi imparare, dovrai poterli aggiungere all'array. Definisci una funzione che aggiunge un nuovo linguaggio all'inizio dell'array.

```clojure
(add-language '("Clojurescript") "JavaScript")
;; => '("JavaScript" "Clojurescript")
```

## 3. Controlla l'ultimo linguaggio aggiunto

Vorrai controllare rapidamente quale linguaggio hai appena aggiunto. Definisci una funzione che restituisce il primo linguaggio dell'array.

```clojure
(first-language '("Haskell" "Python"))
;; => "Haskell"
```

## 4. Rimuovi il primo linguaggio dall'array

A volte cambierai idea su un linguaggio che hai appena aggiunto. Definisci una funzione che rimuove il primo linguaggio dall'array.

```clojure
(remove-language '("Common Lisp" "Racket" "Scheme"))
;; => '("Racket" "Scheme")
```

## 5. Conta i linguaggi nell'array

Contare i linguaggi uno per uno è scomodo. Definisci una funzione che conta il numero di linguaggi nell'array.

```clojure
(count-languages '("C#" "Racket" "Rust" "Ruby"))
;; => 4
```

## 6. Metti tutto insieme

Definisci una funzione `learning-list`, all'interno della quale userai alcune delle funzioni definite sopra.

- Crea un array vuoto
- Aggiungi 2 nuovi linguaggi di programmazione all'array.

  - "Clojure"
  - "Lisp"

- Rimuovi "Lisp" dall'array, dato che potresti non avere abbastanza tempo quest'anno ed è molto simile a Clojure.
- Aggiungi altri 2 linguaggi di programmazione all'array.

  - "Java"
  - "JavaScript"

- Restituisci il numero totale di linguaggi. Suggerimento: dovrebbe essere 3.

```clojure
(learning-list)
;; => 3
```
