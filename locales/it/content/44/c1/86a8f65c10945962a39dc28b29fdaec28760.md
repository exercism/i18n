# Introduzione

I booleani in Go sono rappresentati dal tipo booleano predefinito `bool`, i cui valori possono essere `true` o `false`.
È un tipo definito.

```go
var closed bool    // boolean variable 'closed' implicitly initialized with 'false'
speeding := true   // boolean variable 'speeding' initialized with 'true'
hasError := false  // boolean variable 'hasError' initialized with 'false' 
```

Go supporta tre operatori logici che possono ridurre le espressioni a valori booleani, restituendo `true` o `false`.

| Operatore    | Cosa significa                                 |
| ----------- | --------------------------------------------- |
| `&&` (and)  | È vero se entrambe le affermazioni sono vere.       |
| `\|\|` (or) | È vero se almeno un'affermazione è vera. |
| `!` (not)   | È vero solo se l'affermazione è falsa.    |
