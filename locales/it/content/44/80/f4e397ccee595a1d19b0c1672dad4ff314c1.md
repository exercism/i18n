# Installazione

Consulta [System/Installation][install-link] per le istruzioni su come configurare tutto sul tuo sistema.

~~~exercism/caution
Se hai installato il Java Development Kit (JDK), l'eseguibile `jconsole` potrebbe entrare in conflitto con la Java Console, che usa lo stesso nome.

Tra le possibili soluzioni:

- Rinominare l'eseguibile `jconsole` del linguaggio di programmazione J con un nome univoco (ad esempio `jconsole-jlang`).

- Modificare le variabili d'ambiente o il PATH del tuo sistema per dare priorità alla `jconsole` del linguaggio di programmazione J.

- **Per gli utenti Linux**, c'è uno script bash in `bin/install.sh` che crea un **collegamento simbolico** chiamato `ijconsole` nella directory `/usr/`. Puoi usare questo collegamento digitando `ijconsole` nel terminale.
~~~

Una volta installato J, apri una console J nel terminale e inserisci i seguenti comandi per installare il framework di unit test:

```j
  load 'pacman'
  'update' jpkg ''
  'install' jpkg 'general/unittest'
  exit 0
```
