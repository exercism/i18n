# Informazioni

Gli argomenti di una funzione possono essere definiti in modo che la funzione accetti un numero qualsiasi di argomenti:

```php
<?php

function actOnItems(...$items) {
  // $items is an array containing 0 or more values
  // used to call the function.
}

actOnItems(1, 2, 3, 4); // $items => [1, 2, 3, 4]
```

Se, oltre agli altri, specifichi un argomento di lunghezza variabile, questo deve essere l'ultimo argomento.

```php
<?php

function writeLines($file_handle, ...$lines)
{
    put_file_contents($file_handle, implode("\n", $lines));
}

writeLines('file.txt', "a", "b", "c");
```
