# Informazioni

In Clojure una `string` è una stringa Java, cioè un oggetto che rappresenta testo immutabile come una sequenza di caratteri Unicode (lettere, cifre, punteggiatura, ecc.) ed è definita come segue:

```clojure
(def fruit "Apple")
```

La libreria `clojure.string` fornisce molte funzioni standard per la manipolazione e l'elaborazione delle stringhe. Inoltre, tutti i soliti metodi Java per operare sulle stringhe sono disponibili tramite l'interoperabilità.
