# Istruzioni

Traduci le sequenze di RNA in proteine.

L'RNA può essere suddiviso in sequenze di tre nucleotidi chiamate codoni, che poi vengono tradotte in una proteina, in questo modo:

RNA: `"AUGUUUUCU"` => si traduce in

Codoni: `"AUG", "UUU", "UCU"`
=> che diventano una proteina con la seguente sequenza =>

Proteina: `"Methionine", "Phenylalanine", "Serine"`

Esistono 64 codoni che a loro volta corrispondono a 20 amminoacidi; in questo esercizio, però, non tutte le sequenze di codoni e gli amminoacidi risultanti sono importanti.
Se funziona per un codone, il programma dovrebbe funzionare per tutti.
Puoi comunque ampliare liberamente l'elenco nella suite di test per includerli tutti.

Ci sono anche tre codoni di terminazione (detti anche codoni 'STOP'); se uno di questi codoni viene incontrato (dal ribosoma), la traduzione termina e la proteina si interrompe.

Tutti i codoni successivi vengono ignorati, in questo modo:

RNA: `"AUGUUUUCUUAAAUG"` =>

Codoni: `"AUG", "UUU", "UCU", "UAA", "AUG"` =>

Proteina: `"Methionine", "Phenylalanine", "Serine"`

Nota che il codone di stop `"UAA"` interrompe la traduzione e la metionina finale non viene tradotta nella sequenza proteica.

Qui di seguito ci sono i codoni e gli amminoacidi risultanti necessari per l'esercizio.

| Codone             | Amminoacido   |
| :----------------- | :------------ |
| AUG                | Methionine    |
| UUU, UUC           | Phenylalanine |
| UUA, UUG           | Leucine       |
| UCU, UCC, UCA, UCG | Serine        |
| UAU, UAC           | Tyrosine      |
| UGU, UGC           | Cysteine      |
| UGG                | Tryptophan    |
| UAA, UAG, UGA      | STOP          |
