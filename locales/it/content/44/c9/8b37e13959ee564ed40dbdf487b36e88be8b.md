# Informazioni

Elixir usa i [_Behaviour_][behaviours] per offrire interfacce generiche comuni, consentendo al contempo implementazioni specifiche per ogni modulo che implementa il behaviour. Uno di questi behaviour è l'_Access Behaviour_.

L'_Access Behaviour_ fornisce un'interfaccia comune per recuperare dati basati su chiavi da una struttura dati. È implementato per le mappe e le liste di parole chiave.

Il modulo [`Access`][access] definisce i callback necessari per l'interfaccia. I moduli [`Map`][map] e [`Keyword`][keyword] implementano poi i callback richiesti [`fetch/2`][map-fetch], [`get_and_update/3`][map-get-and-update] e [`pop/2`][map-pop]

Per usare il behaviour, puoi far seguire una variabile associata da _parentesi quadre_ e poi usare la chiave per recuperare il valore associato a quella chiave. Le mappe supportano chiavi di qualsiasi tipo, mentre le liste di parole chiave solo chiavi di tipo atom.

```elixir
# Atom as key
my_map = %{key: "my value"}
my_map[:key]
# => "my value"

# String as key
another_map = %{"key" => "my value"}
another_map["key"]
# => "my value"
```

Se la chiave non esiste nella struttura dati, viene restituito `nil`. Questo può essere una fonte di comportamenti indesiderati, perché non viene sollevato un errore.

```elixir
my_map = %{key: "my value"}
my_map[:wrong_key][:other_wrong_key]
# => nil
```

Nota che `nil` stesso implementa l'Access Behaviour e restituisce sempre `nil` per qualsiasi chiave.

```elixir
nil[:key]
# => nil
```

Le struct non implementano l'Access Behaviour.
