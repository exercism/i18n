# Istruzioni

In questo esercizio lavorerai a un sistema di pianificazione degli appuntamenti per un salone di bellezza a New York, aperto il 15 settembre 2012.

Hai cinque attività, che riguarderanno tutte le date degli appuntamenti.
Gli orari sono nel formato a 24 ore (senza AM/PM).
Per semplificare il più possibile le questioni legate al fuso orario, supponi che tutto usi UTC.

## 1. Interpreta una data di appuntamento composta solo da numeri

Implementa la funzione `schedule_appointment()` per interpretare una rappresentazione testuale di una data di appuntamento nel formato `DateTime` corrispondente.

Nota che l'input è nell'ordine mese/giorno/anno in stile statunitense.

```julia-repl
julia> schedule_appointment("07/25/2023 13:45:00")
2023-07-25T13:45:00
```

## 2. Verifica se un appuntamento è già passato

Implementa la funzione `has_passed()` che prende in input una data di appuntamento e verifica se l'appuntamento è nel passato:

```julia-repl
julia> has_passed(DateTime(1999, 12, 31, 9, 0, 0))
true
```

## 3. Verifica se un appuntamento è nel pomeriggio

Implementa la funzione `is_afternoon_appointment()` che prende in input una data di appuntamento e verifica se l'appuntamento è nel pomeriggio (>= 12:00 e < 18:00):

```julia-repl
julia> is_afternoon_appointment(DateTime(2023, 3, 29, 15, 0, 0))
true
```

## 4. Verifica il giorno della settimana di un appuntamento

Implementa la funzione `day_of_week()` che restituisce il giorno della settimana _numerico_.
Il salone è chiuso la domenica, quindi il lunedì è il giorno 1 e il sabato è il giorno 6.

```R
# a Friday
day_of_week(make_datetime(2026, 06, 05, 12, 30, 00))
#> [1] 5
```

## 5. Riprogramma un appuntamento

Quando un cliente ha bisogno di riprogrammare un appuntamento, questo viene automaticamente spostato al venerdì successivo alla stessa ora del giorno (visto che è il giorno più tranquillo della settimana).

Implementa la funzione `reschedule()` che prende in input l'appuntamento originale (come stringa di testo nell'ordine mese/giorno/anno) e restituisce un appuntamento riprogrammato.

```R
# a Saturday
reschedule("06/13/2026 12:30:00")
#> [1] "2026-06-19 12:30:00 UTC"
```

Se l'appuntamento originale era da lunedì a giovedì, riprogrammalo al venerdì di _questa_ settimana.
Per gli appuntamenti di venerdì o sabato, riprogramma al venerdì della settimana _successiva_.
