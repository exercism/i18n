# Approfondimento

La capacità di qualcosa di essere definito in termini di se stesso si chiama ricorsione. In Gleam, la ricorsione si trova più comunemente nelle funzioni ricorsive, cioè funzioni che chiamano se stesse.

Una funzione ricorsiva deve avere almeno un _caso base_ e almeno un _caso ricorsivo_. Un _caso base_ restituisce un valore senza chiamare di nuovo la funzione. Un _caso ricorsivo_ chiama di nuovo la funzione, modificando l'input in modo che a un certo punto corrisponda al caso base.

```gleam
pub fn factorial(x: Int) -> Int {
  case x {
    // Base case
    1 -> 1

    // Recursive case
    _ -> x * factorial(x - 1)
  }
}
```

Gleam non ha una sintassi speciale per i cicli, quindi tutti i cicli si fanno con la ricorsione.

```gleam
pub fn list_length(list: List(String)) -> Int {
  case list {
    [] -> 0
    [_, ..rest] -> 1 + list_length(rest)
  }
}
```

Gleam supporta anche i tipi personalizzati ricorsivi. Un tipo personalizzato ricorsivo ha una o più varianti che, nei dati che contengono, fanno riferimento al tipo stesso.

```gleam
pub type RussianDoll {
  Child               // Base case
  Mother(RussianDoll) // Recursive case
}
```
```gleam
let very_big_doll = Mother(Mother(Mother(Child)))
let small_doll = Mother(Child)
```
