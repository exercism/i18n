# Test

## Eseguire i test in modo interattivo

Avvia la REPL dalla cartella in cui hai scaricato l'esercizio.

Puoi eseguire i test caricando il file di test nella REPL con `(load "exercise-test")` (sostituendo «exercise» con il nome appropriato). Poi valuta `(exercise-test:run-tests)` per eseguire tutti i test.

Se scrivi il codice direttamente nella REPL, basta valutare `(exercise-test:run-tests)`.

Se invece scrivi il codice nel file lisp dell'esercizio, caricalo con `(load "exercise")` e poi valuta `(exercise-test:run-tests)`.

## Eseguire i test dalla riga di comando

Puoi avviare i test con questa invocazione da riga di comando (di nuovo, sostituisci «exercise» con il nome appropriato in due punti)

```sh
ros run --load exercise-test.lisp --eval '(uiop:quit (if (exercise-test:run-tests) 0 1))'
```
