# Istruzioni

In questo esercizio scriverai un po' di codice per aiutarti a preparare una lasagna eccezionale, seguendo il tuo libro di ricette preferito.

Hai quattro compiti, tutti legati al tempo impiegato per cucinare la lasagna.

## 1. Definire il tempo di cottura previsto in minuti

Definisci una costante chiamata `$expected_minutes_in_oven`.
Secondo il libro di ricette, il tempo di cottura previsto in minuti è 40:

```sh
$ jq -n -f lasagna.jq
{
  "expected_minutes_in_oven": 40,
  ...
```

## 2. Calcolare il tempo di cottura rimanente in minuti

Questo valore prende come input i minuti effettivi in cui la lasagna è rimasta nel forno e restituisce quanti minuti deve ancora rimanere la lasagna nel forno, in base al tempo di cottura previsto in minuti del compito precedente.

```sh
$ echo '{"actual_minutes_in_oven": 18}' | jq -f lasagna.jq
{
  "expected_minutes_in_oven": 40,
  "remaining_minutes_in_oven": 22,
  ...
```

## 3. Calcolare il tempo di preparazione in minuti

Il tempo di preparazione è quanto ci vuole per preparare la lasagna prima di metterla nel forno.
Servono 2 minuti per preparare ogni strato.

```sh
$ echo '{"number_of_layers": 3}' | jq -f lasagna.jq
{
  ...
  "preparation_time": 6,
  ...
```

## 4. Calcolare il tempo di lavoro totale in minuti

Calcola quanti minuti in totale hai lavorato per cucinare la lasagna.
È la somma del tempo di preparazione in minuti e del tempo in minuti che la lasagna ha trascorso nel forno fino a questo momento.

```sh
$ echo '{"actual_minutes_in_oven": 10, "number_of_layers": 2}' | jq -f lasagna.jq
{
  ...
  "total_time": 14,
  ...
```
