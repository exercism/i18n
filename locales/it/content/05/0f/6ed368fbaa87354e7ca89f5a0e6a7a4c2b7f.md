# Introduzione

Le classi sono un elemento costitutivo fondamentale dei programmi Swift.
Permettono di raggruppare proprietà (dati) e metodi (funzioni) correlate in unità di funzionalità autonome.

### Definire le classi

Per definire una classe, usa la parola chiave `class` seguita dal nome della classe, con la definizione racchiusa tra parentesi graffe (`{}`):

```swift
class GameCharacter {
    var characterClass: String?
    var name: String?
    var active = false
    let id = makeRandomID()
}
```

Il corpo di una classe può contenere proprietà memorizzate, che vengono definite e si comportano come normali costanti (`let`) o variabili (`var`).

### Istanze

Una definizione di classe funge da modello: definisce un nuovo tipo e descrive come sono fatti i suoi valori, ma da sola non crea alcuna istanza.

Per creare un'*istanza* di una classe, chiama il suo inizializzatore scrivendo il nome della classe seguito da una coppia di parentesi tonde (`()`):

```swift
let someCharacter = GameCharacter()
```

Questa crea una nuova istanza le cui proprietà sono inizializzate con i valori predefiniti specificati nella definizione della classe.
Per le proprietà opzionali senza valori predefiniti espliciti (come `name`), Swift assegna loro `nil` come valore predefinito.

### Accedere alle proprietà

Accedi alle proprietà di un'istanza usando la *notazione con il punto*: scrivi il nome dell'istanza, un punto (`.`) e il nome della proprietà.
La notazione con il punto funziona anche per le proprietà annidate.

Puoi usare la notazione con il punto per leggere i valori e, se la proprietà è modificabile (`var`), assegnare nuovi valori:

```swift
someCharacter.name
// => nil

someCharacter.name = "Luther"
someCharacter.name
// => "Luther"

someCharacter.id = "new id"
// Error: Cannot assign to property: 'id' is a 'let' constant
```

### Metodi

Oltre alle proprietà, le classi possono definire dei *metodi*: funzioni associate alla classe.

Definisci i metodi all'interno del corpo della classe usando la solita sintassi `func`.
Se un metodo modifica una proprietà, quella proprietà deve essere dichiarata con `var`:

```swift
class GameCharacter {
    var characterClass: String?
    var name: String?
    var active = false
    let id: String = makeRandomID()

    func takesDamage(_ damage: Double) {
        if damage > 100 {
            active = false
        }
    }

    func sayName() -> String {
        return "My name is \(name ?? "no one"), my class is \(characterClass ?? "undetermined")"
    }
}
```

Chiama i metodi su un'istanza usando la notazione con il punto, proprio come le proprietà:

```swift
var myChar = GameCharacter()
myChar.active = true
myChar.takesDamage(200)
myChar.active
// => false
```

### Self

Ogni istanza di una classe ha una proprietà implicita chiamata `self`, che fa riferimento all'istanza stessa.
Anche se spesso viene omesso quando si fa riferimento a proprietà o metodi, `self` si usa comunemente per distinguere i nomi delle proprietà da quelli dei parametri dei metodi quando hanno lo stesso nome.
