# Appendice alle istruzioni

## Alcune note sulle stringhe di Arturo

Nei test vedrai una sintassi che potrebbe esserti nuova: stringhe su più righe racchiuse tra `{ braces }`.

### Riferimenti

* Il [tipo `:string`][string] nella documentazione di riferimento del linguaggio.
* La documentazione di [Basic Usage][usage] nel modulo Strings.

[string]: https://arturo-lang.io/documentation/language/#string
[usage]: https://arturo-lang.io/documentation/library/strings/#basic-usage

### I letterali stringa di Arturo

Arturo offre diversi modi per scrivere i letterali stringa:

1. Stringhe su una sola riga racchiuse tra virgolette doppie

    ```arturo
    greeting: "Hello, World!"

    print express greeting     ; => "Hello, World!"
    ```

1. Stringhe che terminano a fine riga usando una «smart quote» (`«`)

    ```arturo
    farewell: « Goodbye, Mars!

    print express farewell     ; => "Goodbye, Mars!"
    ```

   Queste risultano ben leggibili se hai una lista di stringhe brevi:

    ```arturo
    numberWords: [
        « one
        « two
        « three
        « four, and so on
    ]
 
    print express numberWords    ; => ["one" "two" "three" "four, and so on"]
    ```

1. Stringhe su più righe racchiuse tra parentesi graffe.
   L'indentazione «comune» verrà rimossa.
   I caratteri di nuova riga iniziali e finali vengono rimossi.

    ```arturo
    multiline: {
        First line
        Second line
            Third line keeps indentation
        Last line!


    }

    print express first multiline   ; => 'F'
    print express last multiline    ; => '!'
    lines: split.lines multiline
    print size lines                ; => 4
    print express lines\2           ; => "    Third line keeps indentation"
    ```

1. Le stringhe verbatim vengono conservate esattamente, compresi gli spazi bianchi iniziali e finali

    ```arturo
    code: {:
        greet: function [name][
            print ~"Hello, |name|~"

        greet "World""
    :}

    print ">" ++ code ++ "<"
    print express first code
        ; => prints a literal newline character between single quotes
    print express (split.lines code | get 1)
        ; => "    greet: function [name]["
    ```

1. Le stringhe in stile heredoc si trovano sotto una riga di 3 o più trattini, fino alla fine del file.
   Funzionano come la parola chiave `__DATA__` di Perl.
   Questo stile è utile in un modulo, dove potresti memorizzare la documentazione o il testo della licenza in una variabile alla fine del file.

    Se questo si trova in un file chiamato "mymodule.art"

    ```arturo
    myLicense:
    ---------
    This text has been placed in the public domain.
    Do with it what you will.
    ```

    Poi

    ```arturo
    import {mymodule}!
    print ~">|myLicense|<"  ; => >This text has been placed in the public domain.
                            ; => Do with it what you will.<
    ```
