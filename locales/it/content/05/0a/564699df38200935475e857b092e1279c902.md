# Suggerimenti

## 1. Generale

- Leggi qualcosa sui file nella guida ufficiale [Getting Started][getting-started-file].
- Leggi qualcosa sui file su [joyofelixir.com][joy-of-elixir-file].
- Dai un'occhiata alla [documentazione del modulo `File`][file].

## 1. Leggere gli indirizzi email da un file

- C'è una [funzione integrata][file-read] per leggere in una sola volta il contenuto di un file.

## 2. Aprire un file di log per la scrittura

- C'è una [funzione integrata][file-open] per aprire un file.
- Il secondo argomento di quella funzione è un array di modalità che permette di specificare che il file va aperto per la scrittura.

## 3. Registrare un'email inviata

- Le funzioni per leggere e scrivere su un file aperto con [`File.open!/1`][file-open] si trovano nel modulo [`IO`][io].
- C'è una [funzione integrata][io-puts] per scrivere una stringa in un file, seguita da un carattere di nuova riga.

## 4. Chiudere il file di log

- C'è una [funzione integrata][file-close] per chiudere un file.

## 5. Inviare la newsletter

- Tutte le operazioni necessarie sui file sono già state implementate nei passaggi precedenti.
- Prima di scrivere su un file, il file va aperto.
- Dopo che tutte le operazioni di scrittura su un file sono terminate, il file va chiuso.
