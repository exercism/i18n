# Introduzione

Un `bit` è il valore più piccolo dell'informatica.
La parola `bit` sta per «binary digit», cioè «cifra binaria».
È un'unità di memorizzazione dei dati nell'ambiente di esecuzione, abbastanza grande da contenere un oggetto che può assumere uno di due valori.
Di conseguenza, ha un valore binario pari a `1` oppure `0`.
Tutti gli altri tipi di dati sono composti da più `bits`.
Per esempio, un `byte` di solito è composto da otto `bits`.

## Maschere di bit

Una maschera di bit può essere qualsiasi valore usato per impostare singoli bit.
Per esempio, l'alfabeto inglese ha ventisei lettere.
Un valore di almeno ventisei bit, come un intero senza segno a 32 bit, potrebbe essere usato come maschera di bit per impostare una condizione `true` o `false` per ogni lettera inglese.
Qualsiasi valore con abbastanza bit da gestire un insieme richiesto di condizioni `true` o `false` può fungere da maschera di bit.
L'impostazione e la lettura dei singoli bit avvengono tramite gli operatori bitwise.

## Operatori bitwise

Diciamo che vogliamo tenere traccia di quali lettere compaiono in una `string`.
Per il nostro esempio useremo solo le ventisei lettere dell'alfabeto inglese.
La nostra maschera di bit sarà un intero senza segno a 32 bit.
Uno `0` indicherà che la lettera non compare.
Un `1` indicherà che la lettera compare una o più volte.
All'inizio, la rappresentazione binaria della nostra maschera di bit sarà una fila di 32 `0s`: `00000000000000000000000000000000`.
La posizione più a destra sarà per `A`.
La seconda da sinistra sarà per `B`, e così via.
Diciamo che elaboriamo tutte le lettere della stringa in un ciclo, quindi vogliamo una riga di codice che funzioni per impostare qualsiasi lettera.

### L'operatore bitwise di spostamento a sinistra: un modo per posizionare un bit

`<<` è l'operatore bitwise per lo spostamento a sinistra.

Se la nostra lettera è `A` non vogliamo spostare a sinistra, ma se la lettera è `B` vogliamo spostare a sinistra di una posizione, se è `C` di due posizioni, e così via.
Anche se possiamo percepire i `chars` come lettere tipo `A` o `B`, un `char` è implementato in memoria come un tipo intero, quindi possiamo fare semplici calcoli con un `char`.
Data una variabile chiamata `letter` che rappresenta il `char` che stiamo elaborando, possiamo spostare a sinistra del numero di posizioni necessarie spostando `1` a sinistra della differenza tra `letter` e il `char` `A`, così: `1 << letter - 'A'`.
`A` - `A` fa `0`, quindi sposterebbe a sinistra di `0` posizioni se `letter` è `A`.
`B` - `A` fa `1`, quindi sposterebbe a sinistra di `1` posizione se `letter` è `B`, e così via.

### L'operatore bitwise OR inclusivo: un modo per impostare un bit

Una volta che sappiamo _dove_ vogliamo impostare un bit, possiamo impostarlo davvero usando l'operatore bitwise OR inclusivo, che è `|`.
Il risultato dell'operatore `|` sarà `1` in ogni posizione in cui l'operando di sinistra o quello di destra ha il bit impostato.
Quindi, il risultato di `0010 | 0001` sarebbe `0011`.
(È importante ricordare che il valore è `11` in binario, ma è `3` in decimale.)
Per assegnare il risultato a un valore, l'operatore `|` può essere combinato con l'operatore di assegnazione per impostare i bit così: `|=`.
Per semplicità, l'esempio seguente non usa un ciclo, ma mostra come potremmo elaborare le lettere `ABA` in una maschera di bit.

```c
#include <stdio.h>
#include <stdint.h>

int main() {
    // it's important to initialize the mask to 0 so we don't get garbage values
    uint32_t mask = 0;
    char letter_A = 'A';
    char letter_B = 'B';
    char letter_A_again = 'A';
    mask |= 1 << letter_A - 'A';
    mask |= 1 << letter_B - 'A';
    mask |= 1 << letter_A_again - 'A';
    // prints 3
    printf("%d", mask);
}
```

Impostiamo la parte più a destra della nostra maschera a `0001` per `A`, poi impostiamo la maschera a `0011` per `B`.
Impostare un'altra `A` non produce alcun cambiamento nella maschera esistente.
Avremmo potuto evitare di impostare di nuovo il bit controllando se `A` era già stata impostata.

### L'operatore bitwise AND: un modo per leggere un bit

`&` è l'operatore bitwise AND.
Il risultato dell'operatore `&` sarà `1` in ogni posizione in cui sia l'operando di sinistra sia quello di destra ha il bit impostato.
Quindi, il risultato di `0011 & 0001` sarebbe `0001`.
Possiamo vederlo in azione nell'esempio seguente.

```c
#include <stdio.h>
#include <stdint.h>

int main() {
    uint32_t mask = 0;
    char letter_A = 'A';
    char letter_B = 'B';
    char letter_A_again = 'A';
    mask |= 1 << letter_A - 'A';
    mask |= 1 << letter_B - 'A';
    // prints A already set
    if (mask & 1 << letter_A_again - 'A')
        printf("A already set\n");
    else
        mask |= 1 << letter_A_again - 'A';
    printf("%d", mask);
}
```

### L'operatore bitwise OR esclusivo: un modo per invertire un bit

`^` è l'operatore bitwise OR esclusivo.
Un operatore OR _inclusivo_ implica che esista un operatore OR _esclusivo_ con un comportamento diverso.
Il risultato dell'operatore `^` sarà `1` in ogni posizione in cui _solo uno_ tra l'operando di sinistra e quello di destra ha il bit impostato.
Quindi, il risultato di `0001 ^ 0011` sarebbe `0010`.
Il bit più a destra non sarà impostato perché _entrambi_ gli operandi hanno `1` nella posizione più a destra.
L'operazione OR esclusivo a volte è indicata come XOR.
Se il risultato di un valore su cui è stato applicato lo XOR viene a sua volta sottoposto a XOR, restituirà il valore originale.
Questo può essere usato per una crittografia molto semplice, in cui la stessa chiave serve sia per cifrare sia per decifrare i dati.
Per esempio

```c
#include <stdio.h>

int main() {
    char a = 'a';
    char b = 'b';
    char c = 'c';
    // we will use "a" for the "key"
    char first = a ^ 'a';
    char second = b ^ 'a';
    char third = c ^ 'a';
    // prints three "dots" for unprintable characters
    printf("%c %c %c\n", first, second, third);
    // prints the ascii values 0 3 2
    printf("%d %d %d\n", first, second, third);
    first = first ^ 'a';
    second = second ^ 'a';
    third = third ^ 'a';
    // prints a b c
    printf("%c %c %c\n", first, second, third);
    // prints the ascii values 97 98 99
    printf("%d %d %d\n", first, second, third);
}
```

## Campi di bit

Abbiamo visto come i bit raggruppati in un semplice tipo di dati possano essere indirizzati in base alla loro posizione.
I bit raggruppati in una `struct` possono essere indirizzati per nome.
Un tipo di dati così si chiama `bit field`.
Un caso d'uso dei `bit fields` può essere quando serve una raccolta di flag ON/OFF e si vuole ridurre al minimo l'uso della memoria.

```c
#include <stdio.h>

int main() {

    struct lights {
        unsigned int number_of_lights;
        unsigned int red   : 1;
        unsigned int green : 1;
        unsigned int blue  : 1;
    };
    struct lights lightboard = {3, 0, 0, 0};
     
    //  prints 000
    printf("%d", lightboard.red);
    printf("%d", lightboard.green);
    printf("%d\n", lightboard.blue);
    
    lightboard.green = 1;

    //  prints 010
    printf("%d", lightboard.red);
    printf("%d", lightboard.green);
    printf("%d\n", lightboard.blue);
    
    // prints 3
    printf("%d\n", lightboard.number_of_lights);
}
```

La sintassi di `unsigned int variable_name : 1;` crea un campo di `1` bit all'interno di un `unsigned int` inserito nella struct.
Al posto di un `unsigned int` si potrebbe usare un `signed int` oppure, a partire da C99, un tipo `bool`.
Una struct che contiene campi di bit può anche contenere campi di altri tipi di dati, come `number_of_lights` nell'esempio sopra.
