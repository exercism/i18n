# Installazione

- macOS: esegui `brew install futhark`
- linux: esegui `brew install futhark`
- Windows: usa WSL oppure segui [le istruzioni specifiche per Windows][windows-specific-instructions]

Puoi trovare metodi di installazione alternativi nelle [istruzioni di installazione ufficiali][instructions].

[instructions]: https://futhark.readthedocs.io/en/stable/installation.html
[windows-specific-instructions]: https://futhark.readthedocs.io/en/stable/installation.html#windows-installation
