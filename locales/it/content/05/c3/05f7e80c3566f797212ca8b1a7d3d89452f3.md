# Introduzione

## Dichiarazione di tipo

Le dichiarazioni di tipo in PHP forniscono asserzioni di tipo in fase di esecuzione per gli argomenti delle funzioni, i valori restituiti e le proprietà di classe.
Nelle funzioni, si può aggiungere un tipo di ritorno `void` per indicare che la funzione non restituisce alcun valore.
I tipi dichiarati servono anche come asserzioni in fase di esecuzione sul fatto che le funzioni restituiscano una risposta tipizzata in modo ragionevole.

```php
<?php

class Driver
{
    private int $serial_number;

    public function setSerialNumber(int $number): void
    {
        $this->serial_number = $number;
    }

    public function getSerialNumber(): int
    {
        return $this->serial_number; 
    }
}

$driver = new Driver();
$driver->setSerialNumber("Version 1b"); // This will throw a TypeError
```

### Unione di tipi

Se un argomento di una funzione, un valore restituito o una proprietà di classe può avere più di un tipo, si può dichiarare un'unione di tipi.

```php
<?php

class IdentityCard
{
    private int|null $id = null;

    public function assign(int|float $id): void
    {
        $this->id = intval($id);
    }
}

$card = new IdentityCard();
$card->assign(5.0);
```

### Tipi misti

Quando lavoriamo con il codice, potremmo non riuscire a specificare un tipo.
A partire da PHP 8.0, viene fornito un tipo di ripiego chiamato `mixed`.
Mixed equivale a un'unione di tipi che comprende `object|resource|array|string|float|int|bool|null`.
