# Informazioni aggiuntive

## GNU awk e l'aritmetica a precisione arbitraria

Per impostazione predefinita, i numeri in `awk` sono rappresentati come numeri in virgola mobile a doppia precisione. Questo offre 53 bit di precisione (vedi la [Tabella 16.3][table-16.3] nel manuale). Purtroppo non bastano per completare questo esercizio (attenzione allo spoiler: un test richiede 63 bit di precisione).

Una «precisione insufficiente» si presenta così:
```sh
$ gawk 'BEGIN {
  n = 2 ^ 54
  if (n == n + 1)
    print "not enough precision"
  else
    print "OK"
}'
```
```none
not enough precision
```

GNU `awk` può usare numeri a precisione arbitraria, se le librerie necessarie sono state compilate all'interno dell'eseguibile `awk`. Controlla la versione di awk e cerca «GNU MPFR»:
```sh
$ gawk --version
GNU Awk 5.0.1, API: 2.0 (GNU MPFR 4.0.2, GNU MP 6.2.0)
...
```

Se è presente, abilita questa possibilità con l'opzione `-M`:
```sh
$ gawk -M 'BEGIN {
  n = 2 ^ 54
  if (n == n + 1)
    print "not enough precision"
  else
    print "OK"
}'
```
```none
OK
```

E se il mio `awk` non ha `-M`? Dovrai rivolgerti a un programma esterno in grado di fare aritmetica a precisione arbitraria, come `bc`. Guarda la sezione [Usare getline per leggere una variabile da una pipe][getline-pipe] per un esempio di come si fa.
