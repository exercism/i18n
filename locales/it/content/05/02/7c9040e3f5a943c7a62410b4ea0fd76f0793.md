# Istruzioni

In questo esercizio genererai messaggi di log semi-strutturati.

## 1. Emetti messaggi semi-strutturati

Partirai da alcune funzioni stub e dal seguente enum:

```rust
#[derive(Clone, PartialEq, Debug)]
pub enum LogLevel {
    Info,
    Warning,
    Error,
}
```

L'obiettivo è emettere un messaggio di log nel formato seguente: `"[<LEVEL>]: <MESSAGE>"`.
Dovrai implementare le funzioni che corrispondono ai livelli di log.

Per esempio, il frammento qui sotto mostra un output atteso per la funzione `log`.

```rust
log(LogLevel::Error, "Stack overflow")
// Returns: "[ERROR]: Stack overflow"
```

E per `info`:

```rust
info("Timezone changed")
// Returns: "[INFO]: Timezone changed"
```

Buon divertimento!

## 2. Ulteriore pratica facoltativa

In questa suite c'è un test controllato da una feature.
Le feature gate disabilitano completamente la compilazione per alcune sezioni del programma.
Verranno trattate più avanti.
Per ora sappi solo che c'è un test che viene compilato ed eseguito soltanto quando usi un'invocazione di test speciale:

```sh
cargo test --features add-a-variant
```

Questo test serve a mostrarti come aggiungere una variante all'enum.
