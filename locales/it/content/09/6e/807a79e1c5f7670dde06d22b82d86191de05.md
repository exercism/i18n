# non scrivere sulla console

Rimuovi le funzioni che scrivono sulla console, dato che i test non le richiedono e rendono il codice un po' più difficile da leggere.

Di solito queste istruzioni vengono aggiunte per aiutare a fare il debug del codice. Tuttavia, un approccio migliore è fare il debug del codice mentre si eseguono uno o più unit test. Questo ha il vantaggio aggiuntivo di potersi concentrare sul debug di uno specifico caso di test. Ecco alcuni link che spiegano come fare il debug del codice Scala mentre si eseguono gli unit test in vari IDE:

- [IntelliJ](https://www.jetbrains.com/help/idea/run-debug-and-test-scala.html)
- [Eclipse](http://scala-ide.org/docs/current-user-doc/features/scaladebugger/index.html)
