# Introduzione

## Package e moduli

### Importare

Un modulo viene di solito caricato con la parola chiave `use`.
Questa lo carica e ne chiama il metodo `import`, importando tutti i simboli esportati.

I simboli nell'array `@EXPORT` del package vengono importati per impostazione predefinita.
I simboli nell'array `@EXPORT_OK` del package devono invece essere importati esplicitamente.

### Esportare

Perché un simbolo possa essere importato, deve prima essere esportato.
Il modulo [Exporter][Exporter] è incluso in Perl ed è una delle opzioni più comode per esportare.

Definizione del modulo:
```perl
package Foo;

use Exporter ('import');
our @EXPORT_OK = ('bar');

sub bar { ... }
```

Utilizzo del modulo:
```perl
use Foo ('bar');

bar();
```

### Moduli core

Oltre a [Exporter][Exporter], Perl mette a disposizione una grande varietà di [moduli core][perl-core-modules].
Alcuni esempi utili per gli esercizi che potresti incontrare qui sono [List::Util][List::Util], [Time::Piece][Time::Piece] e [Math::BigRat][Math::BigRat].

### CPAN

Oltre ai moduli core, [CPAN][metacpan] offre migliaia di moduli aggiuntivi creati dalla comunità Perl, pronti da installare.
Il track Perl usa un [cpanfile][test-runner-cpanfile] per installare una selezione di moduli utilizzabili con il test runner Perl di Exercism.
