Però le cose sono un po' disordinate: le coordinate di Aazra sembrano formattate e ordinate diversamente da quelle di Rui, e devono continuare a passare da un array all'altro per capire quali tesori corrispondono a quali luoghi. Essendo dei giovani Gleamlins in erba, sono venuti da te per farsi aiutare a scrivere un piccolo programma (in realtà, un insieme di funzioni) per organizzare meglio le informazioni della loro caccia.

## 1. Convertire le posizioni

Implementa la funzione `place_location_to_treasure_location`, che prende la posizione di un luogo (ad esempio `#("C", 1)`) e la converte nella posizione di un tesoro (ad esempio `#(1, "C")`).

```gleam
place_location_to_treasure_location(#("C", 1))
// -> #(1, "C")
```

## 2. Confrontare le posizioni dei tesori e dei luoghi

Implementa la funzione `treasure_location_matches_place_location`, che prende la posizione di un luogo (ad esempio `#("C", 1)`) e restituisce `True` se corrisponde alla posizione di un tesoro (ad esempio `#(1, "C")`).

```gleam
treasure_location_matches_place_location(#("C", 1), #(1, "C"))
// -> True

treasure_location_matches_place_location(#("C", 1), #(2, "C"))
// -> False
```

## 3. Contare i tesori di un luogo

Implementa la funzione `count_place_treasures`, che prende un luogo (ad esempio `#("Aqua Lagoon (Island of Mystery)", #("F", 1))`) e l'array dei tesori, e restituisce il numero di tesori che si possono trovare lì.

```gleam
let place = #("Aqua Lagoon (Island of Mystery)", #("F", 1))

count_place_treasures(place, treasures)
// -> 2
```

## 4. Luoghi speciali

Implementa la funzione `special_case_swap_possible`, che prende un tesoro (ad esempio `#("Amethyst Octopus", #(1, "F"))`), un luogo (ad esempio `#("Seaside Cottages", #("C", 1))`) e un tesoro desiderato (ad esempio `#("Crystal Crab", #(6, "A"))`), e restituisce `True` per le seguenti combinazioni:

- Il Brass Spyglass si può scambiare con qualsiasi altro tesoro all'Abandoned Lighthouse.
- L'Amethyst Octopus si può scambiare con il Crystal Crab o con il Glass Starfish allo Stormy Breakwater.
- Il Vintage Pirate Hat si può scambiare con il Model Ship in Large Bottle o con l'Antique Glass Fishnet Float all'Harbor Managers Office.
