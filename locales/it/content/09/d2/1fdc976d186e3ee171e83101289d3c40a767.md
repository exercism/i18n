# Suggerimenti

## Generale

- Perché un nome possa avere più tipi diversi, devi usare un [tipo unione][union-type].
- Per poter usare una variabile di istanza in un'espressione di controllo [`if var.is_a?(Type)`][if-is-a], devi prima assegnarla a una variabile locale.

## 1. Impostare una password

- Devi definire una classe con il nome `PasswordLock`.
- Devi definire un metodo di inizializzazione che accetti come argomento una `String`, un `Int32` o un `Float64`.
- Devi definire una [variabile di istanza][instance-variable] `@password` che viene impostata sull'argomento passato al costruttore.

## 2. Cifrare la password

- Definisci un metodo di istanza chiamato `encrypt`.
- Il metodo deve modificare la [variabile di istanza][instance-variable] `@password` in modo che sia cifrata.
- Per fare in modo che un ramo specifico possa essere eseguito solo se la variabile è di un tipo specifico, devi usare il metodo [`is_a?`][is-a] in un'espressione di controllo.

## 3. Verificare se una password è corretta

- Puoi usare metodi già definiti per cifrare il tentativo di password fornito.
