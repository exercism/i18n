# Istruzioni aggiuntive
 
## Alcune note aggiuntive per l'implementazione in Swift

I test di questo esercizio si aspettano che tu implementi un paio di proprietà che restituiscono un valore di tipo `Int` oppure un [array][array] di tipo `[Int]`. Dai pure un'occhiata alla documentazione della classe Array per trovare metodi utili che potrebbero esserti utili nella soluzione.

I test finali verificano l'[immutabilità][immutability]. Nessuna delle proprietà che devi scrivere dovrebbe modificare i punteggi del gioco.

Se vuoi fare un po' di pratica in più, puoi implementare una funzione che aggiunge nuovi punteggi al gioco oppure gestire un array vuoto

[array]: https://developer.apple.com/documentation/swift/array
[immutability]: https://en.wikipedia.org/wiki/Immutable_object
