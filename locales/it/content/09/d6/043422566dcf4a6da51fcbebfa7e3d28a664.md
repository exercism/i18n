# Introduzione

Il vocabolario [`random`][random] di Factor fornisce una parola generica, `random`, che si adatta al suo argomento, più alcune funzioni ausiliarie per mescolare e campionare sequenze.

```factor
USING: random ;

6 random .                       ! a value from 0..5
{ "rock" "paper" "scissors" } random .   ! a random element
{ 1 2 3 4 5 } randomize .        ! the same cards, reordered
{ 1 2 3 4 5 } 2 sample .         ! two distinct elements
```

Applicato a un intero `n`, `random` restituisce un valore in `[0, n)`; applicato a una sequenza, restituisce un elemento casuale. `randomize` mescola sul posto, mentre `sample` estrae elementi distinti.

Per impostazione predefinita, attingono da un generatore globale il cui seme deriva dall'orologio di sistema. Per rendere i risultati riproducibili, installa un generatore con un seme usando `<mersenne-twister>` (da [`random.mersenne-twister`][mt]) e `with-random`:

```factor
USING: random random.mersenne-twister ;

42 <mersenne-twister> [ 6 random ] with-random .   ! same value every run
```

[random]: https://docs.factorcode.org/content/vocab-random.html
[mt]: https://docs.factorcode.org/content/vocab-random.mersenne-twister.html
