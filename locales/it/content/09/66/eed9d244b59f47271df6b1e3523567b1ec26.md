# Suggerimenti

## Generale

- La tupla `plot`, i simboli `registrations` e `next-id`, ed il simbolo `not-found` sono già dichiarati nel file dell'esercizio.
- Per lo stato a livello di modulo, usa `set-global`, `get-global` e `change-global`.

## 1. Apri il giardino ed elenca le sue registrazioni

- `V{ } clone` è il valore iniziale giusto per `registrations` (fai sempre `clone`, così il valore letterale non viene condiviso tra le chiamate).
- `1 next-id set-global` imposta il contatore.
- Per `list-registrations` basta un solo `registrations get-global`.

## 2. Registra un appezzamento

- Leggi prima `next-id`, poi `plot boa` per costruire l'appezzamento da `id` e `name`.
- Incrementa il contatore con `next-id [ 1 + ] change-global`.
- `push` (in [`sequences`][sequences]) aggiunge in coda a un vettore sul posto: perfetto per `registrations get-global`.

## 3. Rilascia un appezzamento

- Un `:: release ( id -- )` rende `id` disponibile all'interno del predicato del filtro.
- `[ id>> id = ] reject` mantiene ogni appezzamento il cui slot `id` *non* corrisponde all'`id` locale. Usalo come corpo di un `change-global`.

## 4. Ottieni un appezzamento registrato

- `find` restituisce `( index elt/f )`. `nip` scarta l'indice.
- `[ not-found ] unless*` sostituisce il simbolo quando non è stato trovato nulla.

[sequences]: https://docs.factorcode.org/content/vocab-sequences.html
