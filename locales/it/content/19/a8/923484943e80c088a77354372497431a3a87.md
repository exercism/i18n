# Introduzione

## Bit array

Lavorare con i dati binari può essere complicato, quindi Gleam fornisce un tipo `BitArray` e una sintassi di supporto per costruire dati binari e fare pattern matching su di essi.

I letterali di bit array si definiscono con la sintassi `<<>>`. Un letterale di bit array viene definito in segmenti. Ogni segmento ha un valore e un'annotazione, separati da un `:`. L'annotazione specifica quanti bit verranno usati per codificare il valore e può essere omessa del tutto, nel qual caso il valore predefinito è un intero a 8 bit.

```gleam
// This defines a bit array with three segments of a single bit each
<<0:1, 1:1, 0:1>>

// This defines a bit array with three segments of 8 bits each
<<0, 1, 0>>
```

Specificare il tipo come `:1` è una scorciatoia per scrivere `:size(1)`. Devi usare la sintassi più lunga se la dimensione in bit proviene da una variabile.

```gleam
let segment_size = 1
<<0:size(segment_size), 1:size(segment_size), 0:size(segment_size)>>
```

### Binario

Quando scriviamo letterali interi binari, possiamo scriverli direttamente in notazione in base 2 anteponendo `0b` al letterale. Tieni presente che verranno visualizzati come numeri decimali quando vengono stampati nei test o nel programma.

```gleam
<<0b1011:4>> == <<11:4>>
// -> True
```

### Troncamento

Se il valore del segmento supera la capacità del tipo del segmento, verrà troncato da sinistra.

```gleam
<<0b1011:3>> == <<0b0011:3>>
// -> True
```

### Aggiungere all'inizio e alla fine

Puoi aggiungere elementi sia all'inizio che alla fine di un bit array esistente usando la sintassi dei bit array. Per il bit array esistente va usata l'annotazione `:bits`.

```gleam
let value = <<0b110:3, 0b001:3>>
let new_value = <<0b011:3, value:bits, 0b000:3>>
// -> <<120, 8:size(4)>>
```

### Concatenazione

Possiamo concatenare bit array memorizzati in variabili usando la sintassi dei bit array. L'annotazione `:bits` va usata quando si concatenano due bit array di dimensioni variabili.

```gleam
let first = <<0b110:3>>
let second = <<0b001:3>>
let concatenated = <<first:bits, second:bits>>
// -> <<49:size(6)>>
```

### Pattern matching

Si può fare pattern matching anche per ottenere valori dal bit array. Devi conoscere il numero di bit di ogni segmento che vuoi catturare, con un'eccezione: l'annotazione `:bits` può essere usata per fare pattern matching su un bit array di dimensione sconosciuta, ma solo per l'ultimo segmento.

```gleam
let assert <<value:4, rest:bits>> = <<0b01101001:8>>
value == 0b0110
// -> True
```

### Ispezionare i bit array

~~~~exercism/note
I bit array potrebbero essere stampati in un formato diverso da quello usato per crearli. Questo crea spesso confusione quando si imparano i bit array.
~~~~

Per impostazione predefinita, i bit array vengono visualizzati in segmenti di 8 bit (un byte), anche se li hai creati con segmenti di dimensioni diverse.

```gleam
<<2011:11>>
// -> <<251, 3:size(3)>>
```

Se crei un bit array che rappresenta una stringa stampabile codificata in UTF-8, potrebbe essere visualizzato come stringa da funzioni come `io.debug`. Ciò è dovuto a un dettaglio implementativo di come Gleam rappresenta le stringhe al suo interno.

```gleam
<<>>
// -> ""

<<65, 66, 67>>
// -> "ABC"
```
