# Introduzione

Lo [Zen of Python][zen-of-python] afferma che dovrebbe esserci «un modo _ovvio_ per fare qualcosa in Python».
A partire da Python 3.6, l'[**interpolazione letterale delle stringhe**][string-interpolation] ([**`f-string`**][f-string]) è spesso il modo ovvio e preferito per formattare le stringhe:

```python
>>> adjective = "easy"
>>> f"This is an {adjective} way to format strings!"
'This is an easy way to format strings!'
```

Tuttavia, vista la lunga storia di Python e i diversi casi d'uso, non sorprende che ci siano **tre** altri modi comuni per formattare le stringhe in Python:

1. [`str.format()`][str-format] è versatile, molto potente e compatibile sia con [`gnu gettext`][gettext] sia con la maggior parte delle versioni di Python.
2. Se ciò che ti serve è semplicità, sicurezza e/o un'intensa internazionalizzazione, puoi usare [`string.Template()`][string-template] per ridurre i rischi quando bisogna gestire gli input e per racchiudere le stringhe di traduzione.
3. L'operatore `%` è generalmente considerato deprecato per il codice nuovo, anche se funziona ancora nel Python moderno.
  Andrebbe usato soprattutto per la compatibilità con codebase più vecchie.
  La formattazione con `%` può causare problemi nella visualizzazione di caratteri non ASCII e Unicode, e presenta più errori e meno funzionalità rispetto agli altri metodi.
  Se intendi usarla, controlla la documentazione della tua distribuzione specifica di Python per i dettagli sul supporto.

Se vuoi andare oltre, [tutto sulla formattazione][all-about-formatting] e [Buone pratiche per la formattazione delle stringhe in Python][formatting-best-practices] sono buoni punti di partenza.
