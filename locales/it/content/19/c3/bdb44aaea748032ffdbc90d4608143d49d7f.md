# Informazioni

In Swift, una `String` è una collezione ordinata di valori `Character` che rappresenta testo leggibile dalle persone. Le stringhe di Swift supportano pienamente i caratteri Unicode e le emoji.

Per creare una stringa, usa un letterale stringa e racchiudi il testo tra virgolette doppie (`"`). I caratteri speciali si scrivono con sequenze di escape: per esempio, `\n` rappresenta un carattere di nuova riga, e `\"` rappresenta una virgoletta doppia con escape all'interno di un letterale stringa.

Una stringa vuota si scrive con una coppia di virgolette doppie senza nulla in mezzo (`""`).

```swift
let hello = "Hello, World!"
let sausage = "Weißwurst is a tasty sausage."
var family = "This is my family: 👨‍👩‍👦‍👦, this is our dog: 🐶"
var empty = ""
```
