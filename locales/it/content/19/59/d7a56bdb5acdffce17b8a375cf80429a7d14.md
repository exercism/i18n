# Introduzione

Il modificatore `const` può essere applicato (e in genere dovrebbe esserlo) a qualsiasi campo il cui valore sia noto in fase di compilazione e non cambierà per tutta la durata del programma.

```csharp
private const int num = 1729;
public const string title = "Grand" + " Master";
```

Il modificatore `readonly` può essere applicato (e in genere dovrebbe esserlo) a qualsiasi campo che non possa essere reso `const` e il cui valore non cambierà per tutta la durata del programma, impostato da un inizializzatore inline o durante l'istanziazione (dal costruttore o da un metodo chiamato dal costruttore).

```csharp
private readonly int num;
private readonly System.Random rand = new System.Random();

public MyClass(int num)
{
    this.num = num;
}
```
