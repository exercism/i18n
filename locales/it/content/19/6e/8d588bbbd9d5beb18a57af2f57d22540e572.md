# Appendice alle istruzioni

## Registri

| Registro | Utilizzo  | Tipo    | Descrizione                          |
| -------- | --------- | ------- | ------------------------------------ |
| `$a0`    | input     | indirizzo | prima stringa con terminazione null  |
| `$a1`    | input     | indirizzo | seconda stringa con terminazione null |
| `$v0`    | output    | intero  | distanza di Hamming                  |
| `$t0-9`  | temporaneo | qualsiasi | per la memorizzazione temporanea     |
