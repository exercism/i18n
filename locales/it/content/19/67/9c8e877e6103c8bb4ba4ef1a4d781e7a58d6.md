# Appendice
## Bonus

Preserva i cluster di grafemi, cioè

```julia
myreverse("hi 👋🏾") == "👋🏾 ih"
myreverse("as⃝df̅") == "f̅ds⃝a"
```

Probabilmente troverai utile la libreria standard [`Unicode`][ref-unicode] per questo compito bonus.

Per abilitare il test dei grafemi, aggiungi `const TEST_GRAPHEMES = true` allo scope globale del file.

[ref-unicode]: https://docs.julialang.org/en/v1/stdlib/Unicode/
