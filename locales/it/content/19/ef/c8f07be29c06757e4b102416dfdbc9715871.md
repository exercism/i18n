# Istruzioni

In questo esercizio elaborerai righe di log.

Ogni riga di log è una stringa formattata così: `"[<LEVEL>]: <MESSAGE>"`.

Ci sono tre diversi livelli di log:

- `INFO`
- `WARNING`
- `ERROR`

Hai tre attività: ognuna prenderà una riga di log e ti chiederà di fare qualcosa con essa. Ci sono tanti modi per risolvere queste attività: scegli i metodi che preferisci tra gli esempi qui sopra e vedi cosa ti viene in mente.

## 1. Estrarre il messaggio da una riga di log

Implementa il metodo `LogLineParser#message` per restituire il messaggio di una riga di log:

```ruby
LogLineParser.new('[ERROR]: Invalid operation').message
# => "Invalid operation"
```

Eventuali spazi bianchi iniziali o finali devono essere rimossi:

```ruby
LogLineParser.new("[WARNING]:  Disk almost full\r\n").message
# => "Disk almost full"
```

## 2. Estrarre il livello di log da una riga di log

Implementa il metodo `LogLineParser#log_level` per restituire il livello di log di una riga di log, che deve essere restituito in minuscolo:

```ruby
LogLineParser.new('[ERROR]: Invalid operation').log_level
# => "error"
```

## 3. Riformattare una riga di log

Implementa il metodo `LogLineParser#reformat` che riformatta la riga di log, mettendo prima il messaggio e poi il livello di log tra parentesi:

```ruby
LogLineParser.new('[INFO]: Operation completed').reformat
# => "Operation completed (info)"
```
