# Test Runner

Un Test Runner è un software che esegue i test di un esercizio sul codice di uno studente.

I Test Runner ci offrono due vantaggi:

1. Permettono di programmare direttamente nel browser, dove lo studente può iterare su una soluzione vedendo se i test passano o falliscono.
2. Ci permettono di fornire ai mentori informazioni sul fatto che il codice di uno studente «funzioni» o no.

## Costruire un Test Runner

Se ti interessa costruire un Test Runner, dai un'occhiata alla [documentazione sui Test Runner](/docs/building/tooling/test-runners) per maggiori informazioni.
