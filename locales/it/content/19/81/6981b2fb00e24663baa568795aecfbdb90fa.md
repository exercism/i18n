# Introduzione

L'ereditarietà è un modo per creare relazioni genitore-figlio tra le classi.
La classe figlia (talvolta chiamata _sottoclasse_) ha accesso al comportamento e ai dati definiti dalla classe genitore (talvolta chiamata _superclasse_).

```javascript
class Pet {
  constructor(name) {
    this.name = name;
  }

  introduce() {
    console.log(`This is my pet, ${this.name}.`);
  }
}

class Dog extends Pet {}

const dog = new Dog('Otis');
dog.introduce();
// => This is my pet, Otis.
```

La parola chiave `extends` nella dichiarazione della classe figlia stabilisce una relazione con la classe genitore attraverso la [catena di prototipi][prototype-chain].

Gli oggetti creati dal costruttore della classe figlia hanno il prototipo della classe genitore nella loro catena di prototipi. Questo dà loro accesso a qualsiasi metodo o dato definito dalla classe genitore.

```javascript
const dog = new Dog('Otis');

Dog.prototype.isPrototypeOf(dog); // => true
Pet.prototype.isPrototypeOf(dog); // => true
Pet.prototype.isPrototypeOf(Dog.prototype); // => true

Pet.prototype.hasOwnProperty('introduce'); // => true
Dog.prototype.hasOwnProperty('introduce'); // => false
dog.hasOwnProperty('introduce'); // => false
```

[prototype-chain]: https://developer.mozilla.org/en-US/docs/Web/JavaScript/Inheritance_and_the_prototype_chain
