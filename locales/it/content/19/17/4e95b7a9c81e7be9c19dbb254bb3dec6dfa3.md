# Suggerimenti

## Generale

- Un [valore int][ints] può essere definito come una o più cifre consecutive.
- I letterali [stringa][string] sono una sequenza di caratteri racchiusa tra virgolette doppie.

## 1. Definisci il tempo di cottura previsto in minuti

- Devi definire una [funzione][functions] senza argomenti.
- Devi restituire un [int][ints].

## 2. Calcola il tempo di cottura rimanente in minuti

- Devi definire una [funzione][functions] con un solo argomento.
- Devi restituire un int da una funzione.
- L'argomento della funzione è un [int][ints].
- Puoi usare l'[operatore matematico per la sottrazione][ints] per sottrarre valori.

## 3. Calcola il tempo di preparazione in minuti

- Devi definire una [funzione][functions] con un solo argomento.
- Devi restituire un int da una funzione.
- L'argomento della funzione è un [int][ints].
- Puoi usare l'[operatore matematico per la moltiplicazione][ints] per moltiplicare valori.

## 4. Calcola il tempo di lavoro totale in minuti

- Devi definire una [funzione][functions] con due argomenti.
- Devi restituire un int da una funzione.
- L'argomento della funzione è un [int][ints].
- Puoi chiamare una delle altre funzioni che hai definito in precedenza.
- Puoi usare l'[operatore matematico per l'addizione][ints] per sommare valori.

## 5. Crea una notifica che la lasagna è pronta

- Devi definire una [funzione][functions] senza argomenti.
- Devi restituire una [stringa][string].

[functions]: https://gleam.run/book/tour/functions.html
[ints]: https://gleam.run/book/tour/ints-and-floats.html
[string]: https://gleam.run/book/tour/strings.html
