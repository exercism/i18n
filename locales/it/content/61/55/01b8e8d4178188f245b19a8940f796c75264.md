# Alias

La [forma speciale `alias`][alias] ti permette di abbreviare o cambiare il nome con cui fai riferimento a un modulo esterno. Un nome personalizzato può essere specificato con l'opzione `:as`.

```elixir
defmodule Square do
  alias Integer, as: I

  def area(a), do: I.pow(a, 2)
end
```

Quando viene usato senza argomenti, riduce il nome del modulo alla sua ultima parte, ad esempio

```elixir
alias MyApp.Account.User
# is the same as
alias MyApp.Account.User, as: User
```

Più alias possono essere raggruppati insieme con `{}`:

```elixir
alias MyApp.Account.{User, EmailValidation}
# is the same as
alias MyApp.Account.User
alias MyApp.Account.EmailValidation
```

Di solito gli alias vengono aggiunti all'inizio della definizione del modulo, ma possono essere aggiunti ovunque. Hanno scope lessicale, il che significa che un alias aggiunto all'interno di una definizione di funzione non sarà disponibile in un'altra funzione.

Gli alias non utilizzati causano avvisi del compilatore.

[alias]: https://hexdocs.pm/elixir/Kernel.SpecialForms.html#alias/2
