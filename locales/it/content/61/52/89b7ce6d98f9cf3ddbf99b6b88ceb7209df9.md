# Introduzione

## Attributi

Un [C# `Attribute`](https://docs.microsoft.com/en-us/dotnet/csharp/programming-guide/concepts/attributes/) fornisce un modo per decorare una dichiarazione e associarle dei metadati: una classe, un metodo, un enum, un campo, una proprietà o qualsiasi altra [dichiarazione supportata](https://docs.microsoft.com/en-us/dotnet/csharp/programming-guide/concepts/attributes/#attribute-targets).

Puoi applicare un attributo aggiungendolo sulla riga prima della dichiarazione, usando un `ClassAttribute` e un `FieldAttribute`:

```csharp
[Class]
class MyClass
{
    [Field]
    int myField;
}
```

Questi metadati dichiarativi associano al codice solo informazioni strutturate aggiuntive e non ne modificano il comportamento. Tuttavia, altre parti del codice usano questi metadati per cambiare il comportamento del loro target, oppure per aggiungere, modificare o rimuovere, o limitare alcune delle sue funzionalità.

Esistono molti [attributi predefiniti e riservati](https://docs.microsoft.com/en-us/dotnet/csharp/language-reference/attributes/general#conditional-attribute), per esempio: `Flags`, `Obsolete`, `Conditional` e `Experimental`. Ognuno ha un significato semantico specifico che si può cercare nella documentazione di C#. Tieni presente che il nome completo di un attributo come [`Flags`](https://docs.microsoft.com/en-us/dotnet/api/system.flagsattribute) ha la forma `<Name>Attribute` (ad esempio `FlagsAttribute`).

## Enum con flag

Il [tipo `enum` di C#](https://docs.microsoft.com/en-us/dotnet/csharp/language-reference/builtin-types/enum) rappresenta un insieme fisso di costanti denominate (un'enumerazione).

Normalmente, un membro di un `enum` può riferirsi a una sola di queste costanti denominate. A volte però è utile riferirsi a più di una costante. Per farlo, si può annotare l'`enum` con l'[attributo `Flags`](https://docs.microsoft.com/en-us/dotnet/api/system.flagsattribute).

Un enum con flag può essere definito come segue (usando la notazione binaria per gli interi `0b`):

```csharp
[Flags]
enum PhoneFeatures
{
    Call = 0b00000001,
    Text = 0b00000010
}
```

Un'istanza di `PhoneFeatures` con valore `0b00000011` ha impostati sia il flag `Call` _che_ il flag `Text`.

Per impostazione predefinita, per i valori dei membri di un enum viene usato il tipo `int`. Si può usare un tipo intero diverso specificando il tipo nella dichiarazione dell'enum:

```csharp
[Flags]
enum PhoneFeatures : byte
{
    Call = 0b00000001,
    Text = 0b00000010
}
```
