# Informazioni

MIPS è un'architettura del set di istruzioni di tipo RISC (computer con set di istruzioni ridotto), oggi usata soprattutto nelle console per videogiochi e nei router. È anche un'architettura popolare nei corsi introduttivi e nei libri di testo di architettura dei calcolatori, grazie alla sua semplicità rispetto a x86 e ARM. Qui usiamo il set di istruzioni a 32 bit; ne esiste anche uno a 64 bit.

Questo percorso prevede la programmazione in linguaggio assembly MIPS, il cui codice viene assemblato ed eseguito su un simulatore multipiattaforma.
