# Installazione

Il modo più semplice per installare Ceylon è semplicemente **non** installarlo.
Dovresti riuscire a risolvere la maggior parte degli esercizi usando il nostro [IDE web](http://try.ceylon-lang.org/).

Se però preferisci, puoi installare la distribuzione da riga di comando. Il modo più semplice per farlo è tramite [SDKMAN](http://sdkman.io/), quindi installa prima quello se non lo hai già, poi basta digitare `sdk install ceylon` nel terminale.

Anche chi usa OSX può installarlo tramite il [gestore di pacchetti Homebrew](http://mxcl.github.com/homebrew/).

Le istruzioni di installazione per le altre piattaforme, così come per l'IDE di Ceylon, un plugin per Eclipse, sono disponibili sul [sito ufficiale](http://ceylon-lang.org/download/).
