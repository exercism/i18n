# Istruzioni

Mary è una grande fan della serie TV _Star Trek: The Next Generation_.
Spesso gioca a giochi di ruolo cartacei, in cui lei e i suoi amici fingono di essere l'equipaggio della _Starship Enterprise_.
Il personaggio di Mary è il Capitano Picard, il che significa che deve tenere il diario di bordo del capitano.
Ama la parte creativa del gioco, ma non le piace generare dati casuali sul momento.

Aiuta Mary creando dei generatori casuali per i dati che compaiono abitualmente nel diario di bordo del capitano.

~~~~exercism/note
L'implementazione iniziale di questo esercizio accetta come argomento del costruttore un'istanza di `java.util.Random`.
Questo permette ai test dell'esercizio di passare un'istanza con un seed predefinito, il che rende prevedibili i risultati dei test.

Per questo motivo, ci si aspetta che tu usi l'istanza di `java.util.Random` fornita nell'implementazione.
~~~~

## 1. Genera un pianeta casuale

Nei suoi viaggi, la _Starship Enterprise_ incontra molti pianeti.
I pianeti dell'universo di Star Trek sono divisi in categorie in base alle loro proprietà.
Per esempio, la Terra è un pianeta di classe `M`.
Tutte le classi planetarie possibili sono: `D`, `H`, `J`, `K`, `L`, `M`, `N`, `R`, `T` e `Y`.

Implementa il metodo `randomPlanetClass()`.
Deve restituire una delle classi planetarie, scelta a caso.

```java
captainsLog.randomPlanetClass();
// => "K"
```

## 2. Genera un numero di registrazione casuale di un'astronave

L'Enterprise (numero di registrazione `NCC-1701`) non è l'unica astronave in circolazione!
Quando si incontra con un'altra astronave, Mary deve annotare il numero di registrazione di quell'astronave.

I numeri di registrazione iniziano con il prefisso "NCC-" e poi usano un numero da `1000` a `9999` (inclusi).

Implementa il metodo `randomShipRegistryNumber()` che restituisce un numero di registrazione casuale di un'astronave.

```java
captainsLog.randomShipRegistryNumber();
// => "NCC-1947"
```

## 3. Genera una data stellare casuale

A cosa serve un diario di bordo se non contiene le date?

Una data stellare è un numero in virgola mobile.
Le avventure della _Starship Enterprise_ della prima stagione di _The Next Generation_ si svolgono tra le date stellari `41000.0` e `42000.0`.
Il "4" sta per il XXIV secolo e il "1" per la prima stagione.

Implementa il metodo `randomStardate()` che restituisce un numero in virgola mobile compreso tra `41000.0` (incluso) e `42000.0` (escluso).

```java
captainsLog.randomStardate();
// => 41458.15721310934
```
