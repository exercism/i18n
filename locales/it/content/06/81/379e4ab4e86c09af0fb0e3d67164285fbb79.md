# Appendice alle istruzioni

## Implementazione

In questo esercizio vedrai un file `cases_test.go`.
Contiene i casi di test usati in `leap_test.go`.
Puoi per lo più ignorare questo file.

Tuttavia, se sei interessato... a volte generiamo i dati dei test da un [repository condiviso tra più linguaggi][problem-specifications-leap].
In quel repository gli esercizi possono avere un [file .json][problem-specifications-leap-json] che contiene dati di test comuni.
Alcuni dei nostri esercizi locali hanno un [programma intermedio][local-leap-gen] che prende il JSON della specifica del problema e lo trasforma in struct Go, che vengono poi passate al file `<exercise>_test.go`.
La trasformazione specifica per Go di quei dati si trova nel file `cases_test.go`.

[problem-specifications-leap]: https://github.com/exercism/problem-specifications/tree/master/exercises/leap
[problem-specifications-leap-json]: https://github.com/exercism/problem-specifications/blob/master/exercises/leap/canonical-data.json
[local-leap-gen]: https://github.com/exercism/go/blob/main/exercises/practice/leap/.meta/gen.go
