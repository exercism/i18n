# Introduzione

Le espressioni condizionali vengono usate per eseguire codice a seconda che una condizione sia **true** o **false**. Queste espressioni si scrivono così:

```haxe
if (condition) {
  expressions
};
```

L'output della condizione è di tipo `Bool`, quindi quando l'output è `true`, le espressioni vengono eseguite.

A volte, quando la condizione è effettivamente `false`, vogliamo che venga eseguito un altro pezzo di codice. È qui che entra in gioco l'espressione `else`. `else` esegue le espressioni quando la condizione iniziale è `false`. Ma cosa succede se vogliamo verificare la condizione per più possibilità? Allora usiamo `else if (condition)`. Ecco un esempio completo:

```haxe
var a = 10;

if (a == 2) {
  trace("a is 2");
} else if (a == 5) {
  trace("a is 5");
} else {
  trace("a is 10");
}

// a is 10
```
