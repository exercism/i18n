# Introduzione

In Swift, una `String` è una collezione ordinata di valori `Character` che rappresenta testo leggibile dalle persone. Le stringhe di Swift supportano completamente i caratteri Unicode e le emoji.

Per creare una stringa si usa un letterale di stringa, racchiudendo il testo tra virgolette doppie (`"`).
I caratteri speciali usano sequenze di escape: ad esempio, `\n` rappresenta un carattere di nuova riga, e `\"` rappresenta una virgoletta doppia con escape all'interno di un letterale di stringa.

Una stringa vuota si scrive come una coppia di virgolette doppie senza nulla tra loro (`""`).

```swift
let hello = "Hello, World!"
let sausage = "Weißwurst is a tasty sausage."
var family = "This is my family: 👨‍👩‍👦‍👦, this is our dog: 🐶"
var empty = ""
```
