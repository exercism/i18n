# Istruzioni

In questo esercizio scriverai un TreasureChest generico (e magico!) per conservare un po' di tesoro.

## 1. Definisci il tipo TreasureChest

Definisci un tipo parametrico `TreasureChest{T}` con due campi.

- Un campo `password` di tipo `String`, che servirà a memorizzare la password del forziere.
- Un campo `treasure` di tipo `T`, che servirà a memorizzare il tesoro.
Questo valore è generico, quindi il tesoro può essere qualsiasi cosa.

```julia-repl
julia> chest = TreasureChest{String}("password", "gold")
TreasureChest{String}("password", "gold")
```



## 2. Definisci la funzione get_treasure()

Questa funzione deve accettare due argomenti.

- Una `String` (per provare una password)
- Un tipo `TreasureChest`

Questa funzione deve confrontare il tentativo di password fornito con la `password` nel `TreasureChest`.

- Se le password corrispondono, restituisci il tesoro.
- Se le password non corrispondono, restituisci `nothing`.

```julia-repl
julia> get_treasure("password", chest)
"gold"

julia> get_treasure("wrong", chest)
# no output

julia> isnothing(get_treasure("wrong", chest))
true
```

## 3. Definisci la funzione multiply_treasure()

Questa funzione deve accettare due argomenti.

- Un moltiplicatore intero `n`.
- Un tipo `TreasureChest{T}`.

La funzione deve restituire un nuovo `TreasureChest{Vector{T}}`, con 
- La stessa password dell'originale
- Il tesoro moltiplicato come `Vector{T}` di lunghezza `n`, cioè il tesoro originale ripetuto `n` volte.

```julia-repl
julia> multiply_treasure(3, chest)
TreasureChest{Vector{String}}("password", ["gold", "gold", "gold"])
```
