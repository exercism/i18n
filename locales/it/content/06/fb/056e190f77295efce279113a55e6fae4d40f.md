# Appendice alle istruzioni

## Come è strutturato questo esercizio nel track di Python

I test di questo esercizio si aspettano che il tuo programma sia implementato come una [`class`][classes in python] `Garden` (_vedi anche [concept:python/classes]()_).
Se non hai familiarità con le classi in Python, questo [tutorial di Real Python][how-to-make-a-class] potrebbe essere un buon punto di partenza in più.

La tua `class` dovrebbe implementare un [`method`][methods] chiamato `plants`, che prende il nome di uno studente come argomento e restituisce la `list` dei nomi delle piante che appartengono a quello studente.


## I costruttori

La creazione del giardino di esempio:

```python
[window][window][window]
VRCGVVRVCGGCCGVRGCVCGCGV
VRCCCGCRRGVCGCRVVCVGCGCV
```

sarebbe, nei test, rappresentata come `Garden("VRCGVVRVCGGCCGVRGCVCGCGV\nVRCCCGCRRGVCGCRVVCVGCGCV")`.

Per far funzionare questa rappresentazione, la tua `class` dovrà implementare un [`__init__()`][init] [metodo speciale][special-methods].
Se non hai familiarità con `__init__()` o con i [_costruttori_][what-is-a-constructor], [oggetti classe e oggetti istanza][class vs instance objects in python] della documentazione di Python offre una spiegazione più dettagliata.


## I parametri predefiniti

In alcuni test, una `list` di studenti viene passata come argomento a `__init__()`.
Questa dovrebbe sostituire l'elenco di dodici studenti fornito nella descrizione del problema.
Entrambe queste istruzioni devono funzionare con il tuo metodo `__init__()`:


```Python
# Make a garden based on the default 12-student roster.
Garden("VRCGVVRVCGGCCGVRGCVCGCGV\nVRCCCGCRRGVCGCRVVCVGCGCV") 

# Make a garden based on a 2-student roster.
Garden("VRCC\nVCGG", students=["Valorie", "Raven"]) 
```

Un possibile approccio è rendere la `list` di studenti un [argomento predefinito][default argument values]; la documentazione di Python descrive in dettaglio i `default parameters` mentre spiega le [definizioni di funzione][function definitions].
