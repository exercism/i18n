# Introduzione

PHP mette a disposizione diversi operatori per eseguire operazioni aritmetiche. Per i suoi operatori aritmetici, PHP segue il consueto ordine delle operazioni matematiche. Gli operatori forniti da PHP sono:

* Identità (+)
* Negazione (-)
* Addizione (+)
* Sottrazione (-)
* Moltiplicazione (*)
* Divisione (/)
* Modulo (%)
* Esponenziazione (**)

```php
$moles = +'10';
$aLotOfMoles = 6.022 * 10**23 * $moles;
```
