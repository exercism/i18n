# Istruzioni

Scrivi una funzione che converta i numeri normali in [numeri ordinali](https://en.wikipedia.org/wiki/Ordinal_numeral). Per lo zero (0), restituisci semplicemente "0" come stringa.

I numeri ordinali descrivono la posizione di qualcosa all'interno di una lista.
È in questo contesto che useremo i numeri ordinali, nella forma scritta in inglese.

I numeri ordinali sono (almeno, in una delle loro forme):

```
1st 2nd 3rd 4th 5th... 9th 10th 11th 12th... 20th 21st 22nd 23rd 24th... etc.
```

Quindi, inserendo un numero normale, si ottiene il suo equivalente ordinale:

```
1 -> 1st
2 -> 2nd
3 -> 3rd
(and so on...)
```
