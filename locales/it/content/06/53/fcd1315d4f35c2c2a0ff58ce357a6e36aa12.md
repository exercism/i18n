# Istruzioni

Azara e Rui sono compagni di squadra che gareggiano in una caccia al tesoro a tema pirata.
Uno ha un elenco di tesori con le coordinate sulla mappa, l'altro un elenco di nomi di luoghi con le coordinate sulla mappa.
Hanno anche ricevuto delle mappe vuote con un punto di partenza contrassegnato da SEI QUI.

Ma le cose sono un po' disordinate: le coordinate di Azara sembrano formattate e ordinate diversamente da quelle di Rui, e devono continuare a passare da un elenco all'altro per capire quali tesori vanno con quali luoghi.
Da aspiranti programmatori di F#, si sono rivolti a te per scrivere un piccolo programma (in realtà un insieme di funzioni) che organizzi meglio le informazioni della loro caccia.

## 1. Estrarre le coordinate

Implementa la funzione `getCooordinate()` che prende una coppia `(treasure, coordinate)` dall'elenco di Azara e restituisce solo la coordinata sulla mappa estratta.

```fsharp
getCoordinate ("Scrimshaw Whale's Tooth", "2A")
// "2A"
```

## 2. Formattare le coordinate

Implementa la funzione `convertCoordinate()` che prende una coordinata nel formato «2A» e restituisce una tupla nel formato `(2, 'A')`.

```fsharp
convertCoordinate "2A"
// (2, 'A')
```

## 3. Confrontare le coordinate

Implementa la funzione `compareRecords()` che prende una coppia `(treasure, coordinate)` e un record `(location, coordinate, quadrant)` e confronta le coordinate di ciascuno.
Restituisci **`true`** se le coordinate «corrispondono» e **`false`** se non corrispondono.
Riformatta le coordinate come serve per un confronto accurato.

```fsharp
compareRecords ("Brass Spyglass", "4B") ("Seaside Cottages", (1, 'C'), "blue")
// false

compareRecords ("Model Ship in Large Bottle", "8A") ("Harbor Managers Office", (8, 'A'), "purple")
// true
```

## 4. Combinare i record corrispondenti

Implementa la funzione `createrecord()` che prende una coppia `(treasure, coordinate)` dall'elenco di Azara e un record `(location, coordinate, quadrant)` dall'elenco di Rui e restituisce `(coordinate, location, quadrant, treasure)` **se le coordinate corrispondono**.
Se le coordinate _non_ corrispondono, restituisci una tupla della stessa forma ma riempita con `""`.
Riformatta le coordinate come serve per un confronto accurato.

```fsharp
createRecord ("Brass Spyglass", "4B") ("Abandoned Lighthouse", (4, 'B'), "Blue")
// ("4B", "Abandoned Lighthouse", "Blue", "Brass Spyglass")

createRecord ("Brass Spyglass", "4B") ("Seaside Cottages", (1, 'C'), "Blue")
// ("", "", "", "")
```
