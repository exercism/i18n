# Test

Puoi implementare un esercizio nel tuo sistema SAP. Segui questi passaggi:

1. Crea un pacchetto SAP per tutti gli esercizi di Exercism nel tuo sistema (nome consigliato: `$EXERCISM`)
2. Crea un pacchetto SAP per ogni esercizio come sottopacchetto (nome consigliato: `$EXERCISM_<name-of-exercise>`, esempio: `$EXERCISM_HELLO-WORLD`)
3. Crea una classe ABAP corrispondente all'esercizio (esempio: `ZCL_HELLO_WORLD`)
4. Copia il codice template da Exercism alla classe
5. Mantieni le classi di test e copia il codice da Exercism alla classe di test

Ora puoi completare l'implementazione della classe ed eseguire il test unitario per vedere se la soluzione funziona correttamente.

Nota: questa configurazione dei pacchetti ti permetterà di eseguire il backup di tutto il tuo lavoro usando [abapGit](https://abapgit.org) creando un repository per il pacchetto `$EXERCISM`.

Per maggiori dettagli, consulta [Documentazione ABAP di Exercism](https://exercism.org/docs/tracks/abap).
