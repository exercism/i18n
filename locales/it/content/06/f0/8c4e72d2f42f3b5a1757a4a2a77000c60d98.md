# Introduzione

Le **espressioni regolari** (regex) sono sequenze di caratteri che specificano un pattern di ricerca all'interno di un testo.

Imparare la sintassi delle espressioni regolari va oltre lo scopo di questo argomento.
Ci concentreremo sulle espressioni che `jq` mette a disposizione per usare le regex.

## Le varianti delle regex

Strumenti diversi implementano versioni diverse delle espressioni regolari.
`jq` incorpora la libreria di regex [Oniguruma][oniguruma], in gran parte compatibile con le regex di Perl v5.8.

La sintassi specifica usata da `jq` si può [trovare nel repo GitHub di Oniguruma][onig-syntax].

<!-- prettier-ignore -->
~~~~exercism/caution
`jq` non ha una sintassi speciale per le espressioni regolari.
Vengono semplicemente espresse come stringhe.
Questo significa che ogni backslash presente nell'espressione regolare deve essere sottoposto a escape nella stringa.

Per esempio, la classe di caratteri delle cifre (`\d`) va scritta come `"\\d"`.
~~~~

<!-- prettier-ignore-end -->

## Le funzioni per le regex

Le espressioni regolari in `jq` sono limitate a [una serie di filtri][jq-regex-funcs].

### Corrispondenza semplice

Quando devi sapere se una stringa corrisponde a un pattern, usa il filtro `test`.

```jq
STRING | test(REGEX)
STRING | test(REGEX; FLAGS)
STRING | test([REGEX, FLAGS])
```

Questo filtro produce un risultato _booleano_.

```jq
"Hello World!" | test("W")    # => true
"Goodbye Mars" | test("W")    # => false
```

### Informazioni sulla corrispondenza

Quando devi estrarre la sottostringa che ha effettivamente corrisposto al pattern, usa il filtro `match`.

```jq
STRING | match(REGEX)
STRING | match(REGEX; FLAGS)
STRING | match([REGEX, FLAGS])
```

Questo filtro produce:

- nulla, se non c'è stata alcuna corrispondenza, oppure
- un oggetto contenente varie proprietà, se c'è stata una corrispondenza.

Questo esempio cerca due vocali consecutive identiche usando la sintassi di backreference, `\1`.

```jq
"Hello World!" | match("([aeiou])\\1")
# => empty

"Goodbye Mars" | match("([aeiou])\\1")
# => {
#      "offset": 1,
#      "length": 2,
#      "string": "oo",
#      "captures": [
#        {
#          "offset": 1,
#          "length": 1,
#          "string": "o",
#          "name": null
#        }
#      ]
#    }
```

Il filtro `match` restituisce un oggetto per _ogni_ corrispondenza.
Questo esempio mostra il flag `"g"` in azione per trovare tutte le vocali.

```jq
"Goodbye Mars" | match("[aeiou]"; "g")
# => { "offset": 1, "length": 1, "string": "o", "captures": [] }
#    { "offset": 2, "length": 1, "string": "o", "captures": [] }
#    { "offset": 6, "length": 1, "string": "e", "captures": [] }
#    { "offset": 9, "length": 1, "string": "a", "captures": [] }
```

### Le sottostringhe catturate

In modo simile al filtro `match`, il filtro `capture` restituisce un oggetto se c'è stata una corrispondenza.

```jq
STRING | capture(REGEX)
STRING | capture(REGEX; FLAGS)
STRING | capture([REGEX, FLAGS])
```

L'oggetto restituito è una mappa delle **catture con nome**.

```jq
"JIRAISSUE-1234" | capture("(?<project>\\w+)-(?<issue_num>\\d+)")
# => {
#      "project": "JIRAISSUE",
#      "issue_num": "1234"
#    }
```

### Solo le sottostringhe

Il filtro `scan` è simile a `match` con il flag `"g"`.

```jq
STRING | scan(REGEX)
STRING | scan(REGEX; FLAGS)
```

`scan` produrrà uno _stream_ di sottostringhe.

```jq
"Goodbye Mars" | scan("[aeiou]")
# => "o"
#    "o"
#    "e"
#    "a"
```

Usa il costruttore di array `[...]` per catturare le sottostringhe.

```jq
"Goodbye Mars" | [ scan("[aeiou]") ]
# => ["o", "o", "e", "a"]
```

### Suddividere una stringa

Se conosci le parti della stringa che vuoi **mantenere**, usa `match` o `scan`.
Se conosci le parti che vuoi **scartare**, usa `split`.

```jq
STRING | split(REGEX; FLAGS)
```

<!-- prettier-ignore -->
~~~~exercism/caution
Il filtro `split` a **un solo argomento** tratta il suo argomento come una **stringa fissa**.

Per usare una regex con `split`, **devi** fornire il secondo argomento; va bene usare una stringa vuota.
~~~~

<!-- prettier-ignore-end -->

Un esempio che suddivide una stringa su spazi bianchi arbitrari.

```jq
"first   second           third fourth" | split("\\s+"; "")
# => ["first", "second", "third", "fourth"]
```

### Sostituzioni

I filtri `sub` e `gsub` possono trasformare la stringa di input, sostituendo le porzioni corrispondenti dell'input con una stringa di sostituzione.

Per sostituire solo la prima corrispondenza, usa `sub`.
Per sostituire tutte le corrispondenze, usa `gsub`.

```jq
STRING | sub(REGEX; REPLACEMENT)
STRING | sub(REGEX; REPLACEMENT; FLAGS)
STRING | gsub(REGEX; REPLACEMENT)
STRING | gsub(REGEX; REPLACEMENT; FLAGS)
```

```jq
"Goodnight kittens. Goodnight mittens." | sub("night"; " morning")
# => "Good morning kittens. Goodnight mittens."

"Goodnight kittens. Goodnight mittens." | gsub("night"; " morning")
# => "Good morning kittens. Good morning mittens."
```

Il testo di sostituzione può fare riferimento alle sottostringhe corrispondenti; usa le catture con nome e l'[interpolazione di stringhe][jq-interp].

```jq
"Some 3-letter acronyms: gnu, csv, png"
| gsub( "\\b(?<tla>[[:alpha:]]{3})\\b";     # find words 3 letters long
        "\(.tla | ascii_upcase)" )          # upper-case the match
# => "Some 3-letter acronyms: GNU, CSV, PNG"
```

## I flag

In tutti i filtri precedenti, FLAGS è una stringa composta da zero o più dei flag supportati.

- `g`: ricerca globale (trova tutte le corrispondenze, non solo la prima)
- `i`: ricerca senza distinzione tra maiuscole e minuscole
- `m`: modalità multiriga ('.' corrisponderà ai caratteri di nuova riga)
- `n`: ignora le corrispondenze vuote
- `p`: sia la modalità s sia la modalità m sono abilitate
- `s`: modalità a riga singola ('^' -> '\A', '$' -> '\Z')
- `l`: trova le corrispondenze più lunghe possibili
- `x`: formato regex esteso (ignora gli spazi bianchi e i commenti)

Per esempio

```jq
"JIRAISSUE-1234" | capture("(?<project>\\w+)-(?<issue_num>\\d+)")

# or with Extended formatting

"JIRAISSUE-1234" | capture("
                     (?<project>   \\w+ )  # the Jira project
                     -                     # followed by a hyphen
                     (?<issue_num> \\d+ )  # followed by digits
                   "; "x")
```
