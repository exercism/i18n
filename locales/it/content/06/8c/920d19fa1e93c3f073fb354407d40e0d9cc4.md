# Introduzione

I tipi che implementano l'interfaccia `IEnumerable<T>` sono detti _enumerabili_. Tutti i tipi di collezione predefiniti implementano questa interfaccia.

Un tipo enumerabile può essere iterato usando un ciclo `foreach`:

```csharp
var primes = new[] { 2, 3, 5, 7 };
foreach (var prime in primes)
{
    Console.Write(prime);
}
// => 2357
```

Per implementare `IEnumerable<T>`, un tipo deve implementare un metodo: `IEnumerator<T> GetEnumerator()`. Come abbiamo visto, un tipo enumerabile delega a un tipo `IEnumerator<T>` l'iterazione effettiva su una collezione. Questa interfaccia ha una proprietà e tre metodi da implementare:

- `public T Current { get; }`: ottiene l'elemento corrente.
- `public bool MoveNext ();`: passa all'elemento successivo, restituendo `true` se il passaggio all'elemento successivo è riuscito, e `false` in caso contrario (non ci sono più elementi).
- `public void Reset ();`: reimposta l'enumeratore al suo stato iniziale (prima del primo elemento).
