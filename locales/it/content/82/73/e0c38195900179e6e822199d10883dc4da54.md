## Formattazione

Anche se a Common Lisp non importa l'indentazione e la disposizione del codice, né se usi spazi o tabulazioni, si tratta di un aspetto importante per le soluzioni inviate su exercism.
Il widget del codice di Exercism.org non gestisce bene la mescolanza di tabulazioni e spazi, quindi si consiglia di usare solo spazi per rendere il codice più leggibile ai revisori umani.
Controlla le impostazioni del tuo editor per capire come fare.
Qui di seguito trovi le istruzioni per gli editor più usati con Common Lisp.

### VIM

Usa i seguenti comandi per assicurarti che VIM usi solo spazi per l'indentazione:

```vimscript
:set tabstop=2
:set shiftwidth=2
:set expandtab
```

(oppure come riga singola `:set tabstop=2 shiftwidth=2 expandtab`). Puoi aggiungerlo al file `~/.vimrc` per usarlo sempre.

### Emacs

Emacs è molto adatto per modificare Common Lisp e ha molti potenti pacchetti aggiuntivi disponibili. L'unica cosa da fare con un Emacs appena installato per farlo funzionare bene con exercism.org è valutare il seguente codice:

`(setq-default indent-tabs-mode nil)`

Puoi inserirlo nel tuo `~/.emacs` (o `~/.emacs.d/init.el`) per averlo impostato ogni volta che Emacs viene avviato.

Un componente aggiuntivo consigliato per Emacs e Common Lisp è [SLIME][slime], che offre un'integrazione stretta con la REPL, rendendo molto semplice scrivere e testare il codice in modo iterativo.
