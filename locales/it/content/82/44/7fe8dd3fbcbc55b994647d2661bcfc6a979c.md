# Informazioni

Scala è un linguaggio di programmazione che cresce insieme a te: da piccoli script ad applicazioni multipiattaforma di grandi dimensioni.

Scala combina la programmazione orientata agli oggetti e quella funzionale in un unico linguaggio conciso e di alto livello. I tipi statici di Scala aiutano a evitare bug nelle applicazioni complesse, mentre i suoi runtime JVM, JavaScript e Native ti permettono di costruire sistemi ad alte prestazioni con un accesso facile a enormi ecosistemi di librerie.

* Caratteristiche
    * Interoperabilità con la JVM: Scala gira sulla JVM, quindi gli stack Java e Scala possono essere combinati per un'integrazione senza soluzione di continuità.
    * Interoperabilità con JS e Native: Scala può girare nel browser e su dispositivi nativi, grazie a [Scala.js](https://www.scala-js.org/) e [Scala Native](https://github.com/scala-native/scala-native)
    * Inferenza dei tipi: Scala è tipizzato staticamente. Tuttavia, Scala fornisce l'inferenza dei tipi per alleggerire il peso di un sistema di tipi avanzato.
    * Orientato agli oggetti: Scala è un linguaggio puramente orientato agli oggetti, nel senso che ogni valore è un oggetto. I tipi di dato ed i comportamenti degli oggetti sono descritti da classi e trait. Le astrazioni di classe si estendono tramite la creazione di sottoclassi e tramite un flessibile meccanismo di composizione basato sui mixin, che evita i problemi dell'ereditarietà multipla.
    * Funzionale: Scala è anche un linguaggio funzionale, nel senso che ogni funzione è un valore. Scala offre una sintassi leggera per definire funzioni anonime, supporta le funzioni di ordine superiore, permette di annidare le funzioni e supporta il currying. Le case class di Scala ed il suo supporto integrato per il pattern matching modellano i tipi algebrici usati in molti linguaggi di programmazione funzionale. Gli oggetti singleton offrono un modo comodo per raggruppare funzioni che non sono membri di una classe.
    * Concorrenza e distribuzione: usa operazioni data-parallel sulle collezioni, usa gli attori per concorrenza e distribuzione, oppure i future per la programmazione asincrona.
