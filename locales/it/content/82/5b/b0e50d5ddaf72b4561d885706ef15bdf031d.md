# Introduzione

In C#, le strutture dati che possono contenere zero o più elementi sono note come _collezioni_. Un **array** è una collezione che ha una dimensione (o lunghezza) fissa e i cui elementi devono essere tutti dello stesso tipo. Gli elementi possono essere assegnati a un array o recuperati da esso tramite un indice. Gli array in C# sono basati sullo zero, il che significa che l'indice del primo elemento è sempre zero:

```csharp
// Declare array with explicit size (size is 2)
int[] twoInts = new int[2];

// Assign second element by index
twoInts[1] = 8;

// Retrieve the second element by index
twoInts[1] == 8; // => true
```

Gli array si possono anche definire con una notazione abbreviata che permette sia di creare l'array sia di impostarne il valore. Dato che ora il compilatore è in grado di stabilire quanti elementi avrà l'array, la lunghezza può essere omessa:

```csharp
// Three equivalent ways to declare and initialize an array (size is 3)
int[] threeIntsV1 = new int[] { 4, 9, 7 };
int[] threeIntsV2 = new[] { 4, 9, 7 };
int[] threeIntsV3 = { 4, 9, 7 };
```

Gli array si possono manipolare chiamando i metodi o le proprietà di un'istanza di array, oppure usando i metodi statici definiti nella classe `Array`.
