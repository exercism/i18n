# Appendice alle istruzioni

## Implementazione

Ipotesi:

1. Lo zero è sempre rappresentato negli output come [0] anziché [].
2. In nessun altro caso sono presenti zeri iniziali negli output.
3. Gli zeri iniziali sono accettati negli input.
4. Una sequenza vuota di cifre di input è considerata zero, anziché un errore.

Gestisci i casi problematici restituendo un errore il cui metodo Error() restituisce uno dei seguenti messaggi:

- input base must be >= 2
- output base must be >= 2
- all digits must satisfy 0 <= d < input base
