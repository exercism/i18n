# Appendice alle istruzioni

## Registri

| Registro | Utilizzo | Tipo | Descrizione |
| -------- | --------- | ------- | ------------------------------------------------------ |
| `$a0` | input | indirizzo | primo colore come stringa terminata da null |
| `$a1` | input | indirizzo | secondo colore come stringa terminata da null |
| `$a2` | input | indirizzo | terzo colore come stringa terminata da null (possibilmente vuota) |
| `$v0` | output | intero | valore del resistore |
| `$t0-9` | temporaneo | qualsiasi | per memorizzazione temporanea |
