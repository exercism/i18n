# I vettori come stack

Uno stack è una struttura dati lineare ottimizzata per l'accesso da un'estremità. Una metafora adatta è una pila di fogli di carta infilzati su un'asta: i fogli nuovi si aggiungono sempre dalla stessa estremità, e si rimuovono nell'ordine inverso rispetto a quello in cui sono stati aggiunti. I fogli aggiunti per primi si rimuovono per ultimi, e quelli aggiunti per ultimi si rimuovono per primi.

La struttura dati `Vec` di Rust è adatta all'uso come stack. Il [metodo `push`](https://doc.rust-lang.org/std/vec/struct.Vec.html#method.push) aggiunge elementi alla fine del vettore. Il [metodo `pop`](https://doc.rust-lang.org/std/vec/struct.Vec.html#method.pop) rimuove l'ultimo elemento dal vettore. Sia `push` che `pop` richiedono solo un tempo ammortizzato `O(1)`.

## Esempio

In questo esempio, usiamo un vettore come stack per una semplice calcolatrice [RPN](https://en.wikipedia.org/wiki/Reverse_Polish_notation). Il codice sorgente completo è disponibile sul [playground](https://play.rust-lang.org/?version=stable&mode=debug&edition=2018&gist=b40514e282cb753d0c3272778f92d736).

```rust
#[derive(Default)]
pub struct RpnCalculator {
    stack: Vec<Value>,
}

impl RpnCalculator {
    pub fn evaluate(&mut self, argument: Argument) -> Result<(), Error> {
        match argument {
            Argument::Value(value) => self.stack.push(value),
            Argument::Operator(operator) => {
                let b = self.stack.pop().ok_or(Error::StackUnderflow)?;
                let a = self.stack.pop().ok_or(Error::StackUnderflow)?;
                let output = operator.execute()(a, b);
                self.stack.push(output);
            }
        }
        Ok(())
    }

    pub fn conclude(self) -> Result<Value, Error> {
        if self.stack.len() == 1 {
            Ok(self.stack[0])
        } else {
            Err(Error::IncompleteCalculation)
        }
    }
}
```
