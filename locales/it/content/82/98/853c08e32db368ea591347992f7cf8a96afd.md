# Istruzioni

Elyse, aspirante maga, deve esercitarsi con le basi. Ha un mazzo di
carte che vuole manipolare.

Per rendere le cose un po' più semplici usa solo le carte da 1 a 10, così
il suo mazzo di carte può essere rappresentato da un array di numeri. La posizione
di una certa carta corrisponde all'indice nell'array. Questo significa che la
posizione 0 si riferisce alla prima carta, la posizione 1 alla seconda
e così via.

<!-- prettier-ignore-start -->
~~~~exercism/note
Tutte le funzioni tranne due devono aggiornare l'array di carte e poi restituire l'array modificato: un modo di lavorare molto comune noto come pattern Builder, che permette di concatenare le funzioni una dietro l'altra in modo elegante.

Le due eccezioni sono `getItem`, che deve restituire la carta nella posizione indicata, e `checkSizeOfStack`, che deve restituire `true` se la dimensione indicata corrisponde.
~~~~
<!-- prettier-ignore-end -->

## 1. Recuperare una carta dal mazzo

Per pescare una carta, restituisci la carta all'indice `position` del
mazzo indicato.

```javascript
const position = 2;
getItem([1, 2, 4, 1], position);
// => 4
```

## 2. Scambiare una carta nel mazzo

Con un po' di giochi di prestigio, scambia la carta all'indice `position`
con la carta sostitutiva fornita.
Restituisci il mazzo aggiornato.

```javascript
const position = 2;
const replacementCard = 6;
setItem([1, 2, 4, 1], position, replacementCard);
// => [1, 2, 6, 1]
```

## 3. Inserire una carta in cima al mazzo

Fai apparire una carta inserendo una nuova carta in cima al mazzo.
Restituisci il mazzo aggiornato.

```javascript
const newCard = 8;
insertItemAtTop([5, 9, 7, 1], newCard);
// => [5, 9, 7, 1, 8]
```

## 4. Rimuovere una carta dal mazzo

Fai sparire una carta rimuovendo dal mazzo la carta nella `position` indicata.
Restituisci il mazzo aggiornato.

```javascript
const position = 2;
removeItem([3, 2, 6, 4, 8], position);
// => [3, 2, 4, 8]
```

## 5. Rimuovere la carta in cima al mazzo

Fai sparire una carta rimuovendo la carta in cima al mazzo.
Restituisci il mazzo aggiornato.

```javascript
removeItemFromTop([3, 2, 6, 4, 8]);
// => [3, 2, 6, 4]
```

## 6. Inserire una carta in fondo al mazzo

Fai apparire una carta inserendo una nuova carta in fondo al mazzo.
Restituisci il mazzo aggiornato.

```javascript
const newCard = 8;
insertItemAtBottom([5, 9, 7, 1], newCard);
// => [8, 5, 9, 7, 1]
```

## 7. Rimuovere una carta dal fondo del mazzo

Fai sparire una carta rimuovendo la carta in fondo al mazzo.
Restituisci il mazzo aggiornato.

```javascript
removeItemAtBottom([8, 5, 9, 7, 1]);
// => [5, 9, 7, 1]
```

## 8. Controllare la dimensione del mazzo

Controlla se la dimensione del mazzo è uguale a `stackSize` oppure no.

```javascript
const stackSize = 4;
checkSizeOfStack([3, 2, 6, 4, 8], stackSize);
// => false
```
