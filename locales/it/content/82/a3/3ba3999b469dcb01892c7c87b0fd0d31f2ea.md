# Classi immutabili

```sather
immutable class BEARING is
   readonly attr degrees : INT;
   create(d : INT) : SAME is
      b : SAME;
      return b.degrees(d);
   end;
end;
```

## Cosa cambia

| | classe ordinaria | classe immutabile |
| --- | --- | --- |
| assegnazione | condivide l'oggetto | copia il valore |
| può essere void | sì | no |
| writer di `attr` | `x.a := v` | `x := x.a(v)` |
| `new` | sì | no; `x : SAME` esiste già |

Un oggetto immutabile non può essere void, quindi `void(b)` è sempre falso e nessuna routine su di esso può fallire per mancanza di un oggetto. Questo elimina un'intera classe di errori, al prezzo di non poter mai dire «nessun rilevamento ancora».

## Dove vive il valore

Il valore è memorizzato dove si trova la variabile, dentro un altro oggetto o sullo stack, invece di essere raggiunto tramite un riferimento. Quindi un `ARRAY{BEARING}` contiene i rilevamenti stessi, non puntatori a essi: è più piccolo e più veloce da percorrere.

Il costo è la copia: passare un oggetto immutabile di grandi dimensioni lo copia ogni volta. Conviene tenerli piccoli.

## Le routine degli attributi

`readonly attr degrees : INT` fornisce due routine:

```sather
   b.degrees          -- read: INT
   b.degrees(90)      -- answer a new BEARING with degrees changed
```

La seconda esiste anche con `readonly`, perché non cambia nulla: costruisce un nuovo valore. Con un semplice `attr` è pubblica; con `private attr` no.

## is_eq e str

Nessuno dei due viene fornito. Scrivi `is_eq` per `=`, e `str` in modo che l'oggetto possa essere stampato e concatenato alle stringhe:

```sather
   is_eq(other : SAME) : BOOL is return degrees = other.degrees; end;
   str : STR is return degrees.str + " degrees"; end;
```

Scrivere `str` fa sì che la classe sia conforme a `$STR`: è ciò che permette a `+` e `#OUT` di accettarla.

## Le classi integrate

`INT`, `BOOL`, `CHAR`, `FLTD` e `TUP` sono tutte classi immutabili. Non hanno nulla di speciale: sono scritte in Sather nella libreria allo stesso modo, e si comportano come si comportano per le ragioni viste sopra.
