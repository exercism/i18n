# Istruzioni

In questo esercizio, elaborerai messaggi di log con sei livelli di gravità.

Ogni riga di log è una stringa formattata così: `"[<LVL>]: <MESSAGE>"`.

Questi sono i diversi livelli di log:

| LIVELLO   | LVL   |
| --------- | ----- |
| `Trace`   | `TRC` |
| `Debug`   | `DBG` |
| `Info`    | `INF` |
| `Warning` | `WRN` |
| `Error`   | `ERR` |
| `Fatal`   | `FTL` |

## 1. Analizzare il livello di log

Definisci un enum `LogLevel` con sei elementi che corrispondono ai livelli di log definiti sopra.
Poi definisci la funzione `parse_log_level`, che prende come parametro il messaggio di log e restituisce il membro dell'enum corrispondente al suo livello.

```python
parse_log_level("[INF]: File deleted")
#=> LogLevel.Info
```

## 2. Gestire un livello di log sconosciuto

Purtroppo, a volte alcuni messaggi di log compaiono con una gravità _sconosciuta_. Per gestire con eleganza questi messaggi di log «misteriosi» nella funzione `parse_log_level`, aggiungi un membro `Unknown` all'enum `LogLevel`, che viene restituito quando si analizza un livello di log sconosciuto:

```python
parse_log_level("[XYZ]: Overly specific, out of context message")
#=> LogLevel.Unknown
```

## 3. Convertire un messaggio di log nel formato breve

Il livello di log di una riga di log è piuttosto verboso. Per ridurre lo spazio su disco necessario a memorizzare i messaggi di log, è definito un formato breve: `"[<CODE_LEVEL>]:<MESSAGE>"`.

I codici dei livelli di log seguono una mappatura semplice:

| LIVELLO   | CODE |
| --------- | ---- |
| `Trace`   | `0`  |
| `Debug`   | `1`  |
| `Info`    | `4`  |
| `Warning` | `5`  |
| `Error`   | `6`  |
| `Fatal`   | `7`  |
| `Unknown` | `42` |

Definisci la funzione `convert_to_short_log()`, che prende due parametri:

1. Livello di log: il livello di log del messaggio inviato. Es.: `LogLevel.Error`.
2. Messaggio di log: il messaggio di tipo `str`.

```python
convert_to_short_log(LogLevel.Error, "Stack overflow")
# => "6:Stack overflow"
```

## 4. Creare un alias

Sembra che l'utente abbia creato dei log per `LogLevel.Warn` invece che per `LogLevel.Warning`. Crea un `alias` per `LogLevel.Warning` e restituisci il nuovo membro alias nella funzione `get_warn_alias`.

Puoi farlo nella stessa classe enum `LogLevel` già definita all'inizio del file. Entrambi i livelli dovrebbero puntare allo stesso valore: `"WRN"`.

```python
get_warn_alias()
#=> LogLevel.Warn

get_warn_alias() == LogLevel.Warning
#=> True
```

## 5. Tutti i nomi e i valori dei membri

Definisci la funzione `get_members()`.

Questa funzione dovrebbe restituire un array di tuple `(name, value)` contenenti tutti i membri dell'enum `LogLevel`.

```python
get_members()
#=> [('Trace', 'TRC'), ('Debug', 'DBG'), ('Info', 'INF'), ('Warning', 'WRN'),
# ('Error', 'ERR'), ('Fatal', 'FTL'), ('Unknown', 'UKN')]
```
