# Formattazione percentuale o "vecchio stile"

Questa soluzione usa la `%%-formatting` o la [formattazione vecchio stile][old-style formatting] per le stringhe.

Anche se la `%%-formatting` è un approccio del tutto valido, può creare problemi di rappresentazione o di leggibilità.
L'uso del metodo [str.format()][str.format()] o delle [f-strings][f-strings] (_note anche come «formatted string literals» o «interpolated strings»_) può offrire opzioni che migliorano la leggibilità e rendono più chiara la sostituzione delle variabili all'interno delle stringhe.

Il post del blog [Formattazione delle stringhe in Python][string formatting in python] è un buon punto di partenza per capire tutte le opzioni di formattazione delle stringhe di Python, e [Tecniche più recenti per la formattazione delle stringhe in Python][newer python string format techniques] offre anche qualche buon consiglio e qualche trucco per usare `str.format()` e le `f-strings`.
