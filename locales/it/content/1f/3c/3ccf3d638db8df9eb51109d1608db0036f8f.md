# Introduzione

In Python, `None` viene usato spesso per rappresentare l'assenza di un valore: un segnaposto per definire una variabile, un oggetto o un argomento `null` (vuoto).

Se hai sentito parlare o hai usato un tipo `NULL` o `nil` in un altro linguaggio di programmazione, allora questo uso di `None` in Python ti sarà familiare.
`None` ti aiuta a dichiarare variabili o argomenti di funzione per cui non hai ancora un valore.
In seguito potrai riassegnarli a valori specifici, quando serve:


```python
a = None
print(a)
#=> None

type(a)
#=> <class 'NoneType'>

# Adding a default argument with `None`
def add_to_todos(new_task, todo_list=None):
    if todo_list is None:
        todo_list = []  
    todo_list.append(new_task)
     
  return todo_list
```

`None` restituisce `False` quando viene usato in un controllo condizionale, quindi è utile per verificare la «presenza» o l'«assenza» di un valore, _qualsiasi_ valore: un pattern usato spesso quando una funzione o un processo potrebbe restituire un `error`, un `object` o un messaggio.

```python
a = None
if a: #<-- a will be evaluated to False when it is used in a conditional check.
    print("This will not be printed")
```
