# Risorse

## Creare il tuo primo modulo Coffee

Per creare un modulo che possa essere caricato con `Bob = require './bob'`, inserisci questo codice in `bob.coffee`:

```coffeescript
class Bob

module.exports = Bob
```

Puoi trovare maggiori informazioni sui moduli nella [documentazione di Node](http://nodejs.org/api/modules.html#modules_module_exports).

## Visual Studio su Windows

Se hai una versione a pagamento di Visual Studio, puoi scaricare una soluzione di Visual Studio già configurata per funzionare con CoffeeScript e con gli altri linguaggi supportati da Visual Studio.

![Solution Explorer](https://raw.githubusercontent.com/exercism/coffeescript/main/docs/img/SolutionExplorer.png)

1. Scarica da GitHub il [Exercism.io Visual Studio Template](https://github.com/rprouse/Exercism.VisualStudio) facendo clic sul pulsante Download Zip della pagina.
2. Estrai il template nella tua cartella degli esercizi, per esempio `C:\src\exercises`
2. Installa la [Exercism CLI](http://exercism.io/cli)
3. Apri un prompt dei comandi nella tua cartella degli esercizi
4. Aggiungi la tua chiave API a exercism `exercism configure --key=YOUR_API_KEY`
5. Configura la tua cartella dei sorgenti in exercism `exercism configure --dir=C:\src\exercises`
6. [Scarica il tuo primo esercizio](http://exercism.io/languages/coffeescript) `exercism fetch coffeescript`
7. Apri la soluzione Exercism in Visual Studio
8. Espandi il progetto Exercism.coffeescript
9. Fai clic su **Show All Files** in Solution Explorer (vedi sotto)
10. L'esercizio che hai appena scaricato apparirà in grigio. Fai clic con il pulsante destro del mouse sulla cartella e scegli **Include In Project**
11. Ora si scrive codice...

![Aggiungi file](https://raw.githubusercontent.com/exercism/coffeescript/main/docs/img/AddFiles.png)

Per lavorare con CoffeeScript in Visual Studio, dovresti installare l'estensione [Web Essentials](http://vswebessentials.com/). Renderà molto più semplice anche lavorare con Javascript.

Puoi eseguire i test unitari da una riga di comando di node.js usando il file batch nel progetto.

```bash
C:\Src\exercises\coffeescript> test example\bob_test.spec.coffee
.................

Finished in 0.02 seconds
17 tests, 17 assertions, 0 failures, 0 skipped
```

Se non vedi alcun output quando esegui i test, probabilmente non ti trovi in un prompt dei comandi di Node.js.
