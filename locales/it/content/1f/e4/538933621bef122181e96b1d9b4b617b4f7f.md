# Introduzione

## Dizionari

Un dizionario è una collezione di elementi in cui ogni elemento comprende una chiave e un valore, così che se si passa una chiave a un metodo del dizionario, viene restituito il valore associato. Ha lo stesso ruolo che hanno le mappe o gli array associativi in altri linguaggi.

Un dizionario può essere creato come segue:

```csharp
new Dictionary<int, string>();
// Empty dictionary
```

Oppure

```csharp
new Dictionary<int, string>
{
    [1] = "One",
    [2] = "Two"
};

// Or

new Dictionary<int, string>
{
    {1, "One"},
    {2, "Two"}
};
// 1 => "One", 2 => "Two"
```

Nota che i tipi delle chiavi e dei valori fanno parte della definizione del dizionario.

Una volta costruito, è possibile aggiungere o rimuovere voci da un dizionario usando i metodi predefiniti `Add` e `Remove`.

Per recuperare o aggiornare i valori in un dizionario, si usa l'indicizzazione tramite una chiave:

```csharp
var numbers = new Dictionary<int, string>
{
   {1, "One"},
   {2, "Two"}
};

// Set the value of the element with key 2 to "Deux"
numbers[2] = "Deux";

// Get the value of the element with key 2
numbers[2];
// => "Deux"
```

Puoi verificare se un valore esiste nel dizionario con:

```csharp
var dict = new Dictionary<string, string>{/*...*/};
dict.ContainsKey("some key that exists");
// => true
```

Quando si enumera un dizionario, si enumerano le sue coppie chiave/valore. I dizionari hanno anche proprietà che permettono di enumerare le chiavi o i valori.
