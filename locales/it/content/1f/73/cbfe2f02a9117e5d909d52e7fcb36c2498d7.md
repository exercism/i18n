# Informazioni

`while` e `until` (in [`kernel`][kernel]) sono combinatori di cicli basati su quotation, pensati per quando non conosci in anticipo il numero di iterazioni:

```
while ( pred: ( -- ? ) body: ( -- ) -- )
until ( pred: ( -- ? ) body: ( -- ) -- )
```

`while` va avanti finché `pred` lascia un valore truthy; `until` va avanti finché `pred` lascia `f`. Entrambi si fermano e ritornano quando il loro predicato si inverte.

```factor
USING: kernel math ;

! Halve down to 1
16 [ dup 1 > ] [ 2 / ] while .   ! => 1

! Double up to 100
1 [ dup 100 >= ] [ 2 * ] until .   ! => 128
```

Quando un solo valore che scorre sullo stack non basta come stato, per esempio una lista rimanente, un totale parziale e un contatore tutti insieme, il pattern più pulito è usare delle *locals* con nome, per maggiore chiarezza. Le locals verranno introdotte in modo più approfondito più avanti nel percorso; qui basta sapere che `:: word ( a b -- c )` dichiara gli input come locals con nome, e che `:> name!` aggiunge una local mutabile che il corpo può aggiornare con `value name!`.

```factor
USING: kernel locals math sequences ;

! Sum a sequence by hand
:: sum-by-hand ( seq -- total )
    seq :> rest!
    0 :> running!
    [ rest length 0 > ] [
        rest unclip [ rest! ] dip
        running + running!
    ] while
    running ;
```

[kernel]: https://docs.factorcode.org/content/vocab-kernel.html
