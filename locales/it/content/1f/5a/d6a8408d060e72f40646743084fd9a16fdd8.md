# Null

Null è un tipo di valore primitivo con un solo valore: `null`.
Null viene spesso usato per rappresentare il nulla.
È considerato «falsey», ma è distinto da `false` e dagli altri valori falsey.

```php
<?php

is_null(null); // => true
isset(null); // => false

null == true; // => false
null === true; // => false

null == false; // => true
null === false; // => false
```

## Lavorare con i valori null

In PHP, i valori null possono essere una causa comune di errore, poiché spesso vengono restituiti al posto di uno stato di errore o per rappresentare il nulla.
Spesso, prevenire gli errori richiede un «controllo del null» per assicurarsi che il valore non sia null prima di operare su di esso.

Ripetere il controllo del null può essere soggetto a errori, quindi PHP fornisce due operatori per lavorare con i valori null: l'operatore di accesso null-safe `?->` e l'operatore di coalescenza null `??`.
