# Informazioni

PHP è un linguaggio lato server adatto allo sviluppo web. L'acronimo è ricorsivo: sta per _PHP: Hypertext Preprocessor_.

Molto più versatile dello scripting CGI, PHP viene spesso usato per aggiungere interattività all'HTML semplice e per rafforzare i framework web.

Il linguaggio può essere utilizzato su qualsiasi sistema operativo. PHP è supportato dalla maggior parte dei server web più comuni e spesso viene gestito tramite un modulo interprete. Questo combina il codice web statico con inclusioni dinamiche.

PHP non è solo un framework per server web. È utile anche per lo scripting da riga di comando (parsing headless) e per sviluppare interfacce grafiche.

Dovresti imparare PHP perché:

- è un linguaggio open source
- è ben documentato e supportato
- è compatibile con la maggior parte dei server web più comuni
- è facile da imparare e da cui partire
- è altamente scalabile ed estensibile
