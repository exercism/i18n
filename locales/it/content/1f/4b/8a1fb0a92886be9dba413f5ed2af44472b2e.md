# Introduzione

Sei un grande appassionato di [geocaching](https://en.wikipedia.org/wiki/Geocaching), che unisce la tua passione per l'aria aperta a quella per risolvere enigmi.
Il sito locale di geocaching elenca le coordinate GPS di tutte le cache, ma _non_ supporta la creazione di un percorso efficiente per raccoglierle.
Guarda caso, sul tuo computer è già installato un software di pathfinding, che però usa un formato GPS diverso da quello del sito di geocaching.
Per inserire i dati nel software di pathfinding, dovrai analizzare i gradi e l'emisfero sia della latitudine che della longitudine di ogni coordinata GPS presente sul sito.
