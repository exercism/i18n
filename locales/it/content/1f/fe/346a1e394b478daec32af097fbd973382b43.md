# Suggerimenti

## Generale

- Consulta le [funzioni disponibili nel _modulo string_][string-module-functions] per scoprire quali operazioni sulle stringhe offre la libreria standard di Gleam.

## 1. Ottenere la prima lettera del nome

- C'è una [funzione][string-first] per ottenere il primo carattere di una stringa.
- Ci sono diverse [funzioni][string-trim] per rimuovere gli spazi bianchi iniziali, finali, o sia iniziali che finali da una stringa.

## 2. Formattare la prima lettera come iniziale

- C'è una [funzione][string-upcase] per convertire tutti i caratteri di una stringa nella loro variante maiuscola.
- L'operatore `<>` può essere usato per concatenare le stringhe.

## 3. Dividere il nome completo nel nome e nel cognome

- C'è una [funzione][string-split] che divide una stringa in corrispondenza degli spazi bianchi.
- I primi elementi di un array possono essere assegnati a delle variabili tramite il pattern matching sull'array.

## 4. Inserire le iniziali dentro il cuore

- L'operatore `<>` può essere usato per concatenare le stringhe.
