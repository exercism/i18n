# Le basi della sintassi di Haskell

## Costanti e funzioni

I programmi Haskell sono composti da definizioni ed espressioni.

Un valore costante si definisce con `name = expression`.

```haskell
five = 5

six = 3 + 3
```

Le funzioni si definiscono con `name parameters... = expression`, e i parametri sono separati solo da uno spazio.

```haskell
add number1 number2 = number1 + number2
```

Anche chiamare una funzione è un'espressione: si specifica il nome della funzione e si passano gli argomenti per ciascuno dei suoi parametri, separati da spazi, proprio come nelle definizioni di funzione.

```haskell
five = add 2 3
```

Le parentesi tonde (`()`) si possono usare per specificare l'ordine di valutazione di un'espressione.

```haskell
six = add 2 (1 * 4)

twelve = add 2 1 * 4
```

## Indentazione / spazi bianchi significativi

Haskell usa gli spazi bianchi e l'indentazione per specificare i confini del codice.
***Il codice che fa parte di un'espressione deve essere indentato più a destra rispetto all'inizio di quell'espressione.***

- Le definizioni di moduli, import e funzioni di primo livello devono iniziare dalla colonna più a sinistra.
- Se un'espressione è divisa su più righe, il codice che fa parte di quell'espressione deve essere indentato sotto quell'espressione con almeno uno spazio.
- Le parti dell'espressione raggruppate insieme devono essere indentate con lo stesso numero di spazi.

```haskell
-- A function split over multiple lines, so subsequent lines must be indented
add number1 number2 =
    number1 + number2
```

https://en.wikibooks.org/wiki/Haskell/Indentation

## Moduli

I moduli esportano funzioni.
Questo significa che puoi usare le funzioni che il modulo rende disponibili nella sua dichiarazione di esportazione.
Un modulo può anche definire funzioni solo per uso interno.
Per impostazione predefinita, le funzioni che non sono esportate esplicitamente non possono essere usate dall'esterno del modulo.

All'inizio di un modulo, ne specifichiamo il nome.
Se abbiamo un file chiamato Calculator.hs, allora dovremmo chiamare il nostro modulo Calculator.
Poi specifichiamo le funzioni che esporta e, dopo, possiamo iniziare a scrivere le funzioni.
Quindi iniziamo con questo.

```haskell
module Calculator ( add ) where
```

https://learnyouahaskell.github.io/modules#making-our-own-modules

## Commenti

Un commento è del testo all'interno del file Haskell che non viene interpretato come codice.
È pensato principalmente per essere letto da te e da altri programmatori.
C'è una sintassi leggera per i commenti su una sola riga, basata sul doppio trattino.
I commenti su più righe sono possibili anche con la coppia di delimitatori di apertura e chiusura `{-` e `-}`.

```haskell
-- a single line comment
-- another single line comment

{- a multiline comment
   spanning multiple lines
-}
```
