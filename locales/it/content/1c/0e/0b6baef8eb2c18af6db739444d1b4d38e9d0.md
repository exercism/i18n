# Informazioni

[Nil][nil-dictionary] è una parola inglese che significa «niente» o «zero». In Elixir, `nil` è un valore speciale che indica un'_assenza_ di valore.

```elixir
# I do not have a favorite color
favorite_color = nil
```

`nil` è un atomo, ma di solito si scrive `nil`, non `:nil`. Anche i valori booleani `true` e `false` sono atomi.

[//]: # (elixir-formatter-disable-next-block)

```elixir
nil === :nil
# => true

true === :true
# => true
```

Per verificare se il valore di una variabile è `nil`, puoi usare [`==`][kernel-equal], il pattern matching, oppure la [guardia `is_nil`][kernel-is-nil].

```elixir
def call(phone_number) do
  if phone_number == nil do
    :error
  end
end
```

```elixir
def call(phone_number) when is_nil(phone_number) do
  :error
end
```

```elixir
def call(nil) do
  :error
end
```
