# Introduzione

In Factor, combini le parole semplicemente scrivendole una dopo l'altra: l'ordine in cui le scrivi *è* il modo in cui si uniscono. (I programmatori la chiamano *composizione di funzioni*.) Il corpo di una parola è a sua volta una sequenza di parole: ognuna consuma alcuni valori dallo stack e vi inserisce il proprio risultato; la parola successiva riprende da dove si era fermata la precedente. Quindi definire

```factor
! DOCTEST: SKIP   (cleanupname is hypothetical here — the exercise's job)
: firstletter ( name -- letter ) cleanupname first 1string ;
```

è già *di per sé* la composizione di `cleanupname`, `first` e `1string`.

Questo esercizio introduce anche le **quotation**: un pezzo di codice che puoi memorizzare come valore ed eseguire più tardi, invece di eseguirlo sul momento.

## Quotation

Una quotation è un pezzo di codice racchiuso tra parentesi quadre. Non viene eseguita quando la scrivi. Resta sullo stack come valore:

```factor
[ 2 * ] .       ! => [ 2 * ]
```

`call` esegue una quotation:

```factor
3 [ 2 * ] call .    ! => 6
```

Scrivi una quotation quando devi passare del codice come dato: per eseguirlo più tardi, oppure per passarlo a un *combinator*, una parola che prende in input una quotation.

## `compose`

`compose ( quot1 quot2 -- combined )` incolla due quotation in una sola, eseguendole nell'ordine in cui sono scritte:

```factor
[ 2 * ] [ 1 + ] compose .    ! => [ 2 * 1 + ]
```

Di solito troverai che definire una piccola parola con `:` ... `;` si legge meglio di `compose`, ma `compose` è comodo quando devi costruire delle quotation al volo. Quando i blocchi di partenza non sono già delle quotation, `>quotation ( seq -- quot )` (da [`quotations`][quotations]) trasforma una sequenza di valori e riferimenti a parole in una quotation richiamabile:

```factor
USING: quotations sequences ;

{ [ 1 ] [ 2 + ] [ 3 * ] } concat >quotation call .   ! => 9
```

## Applicare una quotation a due input

`bi@ ( x y quot -- ... )` esegue la quotation su `x` e di nuovo su `y`, lasciando entrambi i risultati sullo stack:

```factor
3 4 [ 2 * ] bi@ .s
! => 6
! => 8
```

Il compito `couple` dell'esercizio prende due nomi; `bi@` è il modo naturale per applicare `initial` a ciascuno.

## Alcune parole per le stringhe

L'esercizio richiede una manciata di piccole parole per le stringhe, prese da tre vocabolari: [`sequences`][sequences], [`ascii`][ascii] e [`strings`][strings]:

- `replace ( seq old new -- new-seq )` (in `splitting`): sostituzione di sottostringhe.
- `[ blank? ] trim` (`trim` in `sequences`, `blank?` in `ascii`): elimina gli spazi bianchi all'inizio e alla fine.
- `1string ( char -- str )` (in `strings`): racchiude un singolo carattere in una stringa.
- `>upper ( str -- upper )` (in `ascii`): converte una stringa in maiuscolo.
- `append ( s1 s2 -- s )` (in `sequences`): concatena due stringhe.
- `prepend ( s1 s2 -- s )` (in `sequences`): concatena prima `s2` e poi `s1` (`append` con gli input nell'ordine opposto).
- `glue ( s1 s2 sep -- s )` (in `sequences`): concatena due stringhe con un separatore tra di esse.
- `surround ( seq pre post -- new )` (in `sequences`): avvolge una stringa con un prefisso e un suffisso.

I caratteri Unicode si possono scrivere come `\u{XXXX}` all'interno di una stringa, dove `XXXX` è il codepoint in esadecimale. Il cuore `\u{2764}` (❤) compare in questo esercizio.

## Output formattato

Quando `append`/`glue`/`surround` non sono abbastanza espressivi, [`formatting`][formatting] fornisce `sprintf`, in stile printf:

```
sprintf ( inputs... format-string -- str )
```

`%s` interpola una stringa, `%d` un intero, `%f` un numero in virgola mobile; i modificatori opzionali di larghezza, precisione e riempimento si mettono tra `%` e la lettera del tipo:

```factor
USING: formatting ;

"Alice" "Bob" "%s & %s" sprintf .   ! => "Alice & Bob"
3.14159 "%.2f" sprintf .             ! => "3.14"
42 "%05d" sprintf .                  ! => "00042"
```

Per convertire numeri e stringhe in entrambe le direzioni, [`math.parser`][math.parser] mette a disposizione `number>string` e `string>number`:

```factor
USING: math.parser ;

42 number>string .       ! => "42"
"3.14" string>number .   ! => 3.14
```
