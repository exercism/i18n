# Introduzione

La maggior parte dei programmi ha dipendenze da alcune librerie. Gestirle a mano può essere faticoso. Per fortuna, l'ecosistema Rust include `cargo` di serie! `cargo` può gestire le dipendenze di un progetto.

In Rust, capita spesso di sentire chiamare i pacchetti esterni "crate". Un crate è un'unità di compilazione in Rust. Un crate può essere compilato in un binario o in una libreria.

Il più delle volte, aggiungere una dipendenza esterna è semplice come aggiungere una riga al tuo file `Cargo.toml`.

In questo esercizio, le dipendenze [`enum-iterator`](https://docs.rs/enum-iterator/1.2.0/enum_iterator/) e [`int-enum`](https://docs.rs/int-enum/0.5.0/int_enum/) sono state aggiunte per te.
