# Istruzioni

Sei un appassionato birdwatcher che tiene traccia di quanti uccelli hanno visitato il tuo giardino negli ultimi sette giorni.

Hai cinque attività, tutte relative al numero di uccelli che hanno visitato il tuo giardino.

## 1. Controlla quali erano i conteggi della scorsa settimana

Memorizzi i tuoi conteggi degli uccelli in formato JSON.
Un array "main" memorizza array di conteggi settimanali.
Ogni conteggio settimanale è un array di sette numeri interi, un numero per ogni giorno della settimana.
Aggiungi sempre le nuove settimane in fondo all'array "main".
Implementa il filtro che restituisce i conteggi della scorsa settimana.

```sh
$ cat bird-counting-data.json
[
  ...,
  [0, 2, 5, 3, 7, 8, 4],
  [4, 5, 9, 10, 9, 4, 3]
]

$ jq -f bird-count.jq < bird-counting-data.json
{
  "last_week": [0, 2, 5, 3, 7, 8, 4],
  ...
```

## 2. Controlla quanti uccelli hanno visitato ieri

Implementa il filtro per restituire quanti uccelli hanno visitato il tuo giardino ieri.
I conteggi degli uccelli sono ordinati per giorno: il primo elemento è il conteggio del giorno più vecchio, mentre l'ultimo è il conteggio di oggi.

```jq
$ jq -f bird-count.jq < bird-counting-data.json
{
  ...
  "yesterday": 4,
  ...
```

## 3. Calcola il numero totale di uccelli in visita

Implementa il filtro per restituire il numero totale di uccelli che hanno visitato il tuo giardino questa settimana.

```jq
$ jq -f bird-count.jq < bird-counting-data.json
{
  ...
  "total": 44,
  ...
```

## 4. Calcola il numero di giorni intensi

Alcuni giorni sono più intensi di altri.
Un giorno intenso è quello in cui cinque o più uccelli hanno visitato il tuo giardino.
Implementa il filtro per restituire il numero di giorni intensi questa settimana.

```jq
$ jq -f bird-count.jq < bird-counting-data.json
{
  ...
  "busy_days": 4,
  ...
```

## 5. Controlla se c'è stato un giorno senza uccelli in visita

Implementa il filtro che restituisce `true` se c'è stato un giorno questa settimana in cui zero uccelli hanno visitato il giardino; altrimenti, restituisci `false`.

```jq
$ jq -f bird-count.jq < bird-counting-data.json
{
  ...
  "has_day_without_birds": false
}
```
