# Appendice alle istruzioni

## Bonus

Prova la tua funzione con questa stringa: `uüu` e guarda cosa succede.
Prova a scrivere una funzione che inverta correttamente questa stringa.
Suggerimento: i cluster di grafemi

Per eseguire il test bonus, rimuovi il flag di ignore (`#[ignore]`) dall'ultimo test ed esegui i test con:

```bash
cargo test --features grapheme
```

Per il compito bonus ti serviranno librerie esterne (un `crate`, nel gergo di Rust).
Un buon posto dove cercarle è [crates.io](https://crates.io/), il repository ufficiale dei crate.
Ricorda che il nostro test runner supporta solo un insieme limitato di crate.
L'elenco completo è in [questo file](https://github.com/exercism/rust-test-runner/blob/main/local-registry/Cargo.toml) nella sezione `[dependencies]`.

[Consulta la documentazione](https://doc.rust-lang.org/cargo/guide/dependencies.html) per istruzioni su come usare crate esterne nei tuoi progetti.
