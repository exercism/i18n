# Introduzione

Il tipo `char` di F# è un valore a 16 bit che rappresenta la più piccola componente indirizzabile del testo, immutabile per impostazione predefinita.

I `char` possono essere definiti come letterali con virgolette singole:

```fsharp
let ch = 'A'
// => val ch: char = 'A'
```

Le stringhe sono una sequenza di `char`.

Un singolo `char` può essere estratto da una stringa con l'indicizzazione (a partire da zero):

```fsharp
"Exercism"[4] //  =>  'c'
```

Iterare su una stringa restituisce un `char` a ogni passo.

Il prossimo esempio usa una funzione di ordine superiore e una funzione anonima, per comodità.
Verranno trattate adeguatamente più avanti nel programma, ma per ora sono un modo conciso per scrivere un ciclo sui caratteri di una stringa.

```fsharp
Seq.map (fun c -> c, int c) "F#"  //  =>  [('F', 70); ('#', 35)]
```

Come mostrato sopra, un `char` può essere convertito nel suo valore `int`.
Questo funziona anche (*almeno in alcuni casi*) per altri sistemi di scrittura:

```fsharp
Seq.map (fun c -> c, int c) "東京"  //  =>  [('東', 26481); ('京', 20140)]
```

L'Int16 sottostante viene usato quando si confrontano i caratteri:

```fsharp
'A' < 'D'  // =>  true
```

Inoltre, un `int` può essere convertito in `char`:

```fsharp
char 77  // => 'M'
```

La libreria `System.Char` contiene l'insieme completo di metodi previsti per un linguaggio .NET, come le conversioni maiuscolo/minuscolo:

```fsharp
'a' |> System.Char.ToUpper  // =>  'A'

'Q' |> System.Char.ToLower  // =>  'q'
```
