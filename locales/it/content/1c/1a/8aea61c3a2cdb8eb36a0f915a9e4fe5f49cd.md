# Istruzioni

Una terna pitagorica è un insieme di tre numeri naturali, {a, b, c}, per cui

```text
a² + b² = c²
```

e tale che

```text
a < b < c
```

Per esempio,

```text
3² + 4² = 5².
```

Dato un numero intero N in input, trova tutte le terne pitagoriche per cui `a + b + c = N`.

Per esempio, con N = 1000 esiste esattamente una terna pitagorica per cui `a + b + c = 1000`: `{200, 375, 425}`.
