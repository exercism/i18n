# Appendice alle istruzioni

## Aspetta, è impossibile!

Implementare queste operazioni sulle liste senza usare _alcuna_ funzione integrata è praticamente impossibile in Roc, perché serve un modo per aggiungere elementi in coda o in testa a una lista.
In altri linguaggi potresti usare operatori come `:` in Haskell o `+=` in Python, ma in Roc devi usare le [funzioni di `List`](https://www.roc-lang.org/builtins/main/#Builtin.List).

Quindi per questo esercizio puoi usare `List.append` (ma evita di usare qualsiasi altra funzione integrata).

Molti linguaggi di programmazione funzionale usano le liste concatenate come tipo di collezione principale.
In una lista concatenata è efficiente aggiungere un elemento in testa o estrarre il primo elemento, quindi in quei linguaggi implementeresti le operazioni sulle liste con `List.prepend`.
In Roc, invece, una `List` è un array (un blocco contiguo di byte).
Gli array hanno proprietà diverse dalle liste concatenate, come la capacità di accedere in modo efficiente agli elementi tramite indice e di aggiungere nuovi elementi in coda.
Per questo motivo, in Roc usiamo spesso `List.append` e raramente `List.prepend`.

## Denominazione

Roc usa nomi leggermente diversi da quelli elencati nelle istruzioni generali:

- `concat` invece di `append`
- `join` invece di `concatenate`
- `len` invece di `length`
- `fold` invece di `foldl`
- `fold_rev` invece di `foldr`

Tuttavia, i seguenti nomi di funzione sono standard in Roc:
- `filter`
- `map`
- `reverse`

## Suggerimento

Prova a usare:

```roc
match list {
    [] => ...
    [first, .. as rest] => ...
}
```

oppure

```roc
match list {
    [] => ...
    [.. as rest, last] => ...
}
```
