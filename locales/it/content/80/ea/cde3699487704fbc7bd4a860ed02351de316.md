# Introduzione

`Rational numbers` sono frazioni con un numeratore intero diviso per un denominatore intero.

Ad esempio, possiamo memorizzare `2//3` come frazione esatta invece del valore approssimato `Float64` `0.6666...`

Il vantaggio è che (tranne nel caso estremo di *overflow di interi*) un numero razionale rimane esatto, evitando gli errori di arrotondamento spesso inevitabili con i numeri in virgola mobile.

I numeri razionali sono un tipo numerico piuttosto semplice e sono pensati per funzionare proprio come ti aspetteresti.
Poiché sono un tipo standard in Julia fin dalle prime versioni, la maggior parte delle funzioni li accetta come input allo stesso modo degli interi e dei numeri in virgola mobile.

## Creazione di numeri razionali

La creazione è semplice come usare `//` tra due interi.

```julia-repl
julia> 3//4
3//4

julia> a = 3; b = 4;

julia> a//b
3//4
```

I fattori comuni vengono rimossi automaticamente, convertendo la frazione ai suoi «minimi termini»: i più piccoli interi che rappresentano accuratamente la frazione, con denominatore non negativo.

```julia-repl
julia> 5//15
1//3

julia> 5//-15
-1//3
```

## Aritmetica con i numeri razionali

I soliti `arithmetic operators` `+ - * / ^ %` funzionano con i razionali, essenzialmente come con gli altri tipi numerici.

Gli interi e altri `Rational` possono essere inclusi e danno come risultato un `Rational`.
Includere un `float` nell'espressione produce un output `float`, con una conseguente (possibile) perdita di precisione.

Se desideri un `float`, usa semplicemente la funzione `float()` per convertire un razionale.
È del tutto normale usare numeri razionali per preservare la precisione durante un calcolo lungo, per poi convertire in un numero in virgola mobile alla fine.

```julia-repl
julia> 3//4 + 1//3  # addition
13//12

julia> 3//4 * 1//3  # multiplication
1//4

julia> 3//4 / 1//3  # division
9//4

julia> 3//4 ^ 2  # exponentiation
3//16

julia> 3//4 + 5  # rational and int => rational
23//4

julia> 3//4 + 5.3  # rational and float => float
6.05

julia> float(3//4)  # casting
0.75
```

## Altre operazioni

In Julia, i numeri razionali sono semplicemente numeri.
Di solito il compilatore converte i tipi secondo necessità.

Tuttavia, fai attenzione: i confronti funzionano per frazioni con una rappresentazione decimale finita:

```julia-repl
julia> 3//4 == 0.75
true

julia> 3//4 < 0.74
false
```

Negli altri casi, però, un `Rational` va convertito in un `Float` per i confronti:

```julia-repl
julia> 1//3 == 1/3
false

julia> float(1//3) == 1/3
true
```

Le funzioni matematiche accettano numeri razionali come input, ma possono restituire un risultato in virgola mobile:

```julia-repl
julia> sqrt(9//16)
0.75
```
