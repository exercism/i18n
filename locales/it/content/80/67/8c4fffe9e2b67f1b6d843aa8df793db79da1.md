# Introduzione

## I booleani in R

I valori vero o falso sono rappresentati dal tipo `logical`.
Contiene solo due valori: `TRUE` e `FALSE`.

```R
TRUE
#> [1] TRUE
FALSE
#> [1] FALSE
typeof(TRUE)
#> [1] "logical"
```

## Operatori booleani

In R ci sono cinque operatori booleani, ma solo tre sono rilevanti a questo punto del sillabo.
Gli altri due saranno importanti quando lavorerai con i vettori, argomento trattato in diversi concetti successivi.

`&&` è l'operatore booleano «and».
Si valuta in `TRUE` se le espressioni su *entrambi* i lati di `&&` sono `TRUE`.

```R
TRUE && TRUE
#> [1] TRUE
TRUE && FALSE
#> [1] FALSE
```

`||` è l'operatore booleano «or».
Si valuta in `TRUE` se un'espressione su *uno dei due* lati di `||` è `TRUE`.

```R
TRUE || TRUE
#> [1] TRUE
FALSE || TRUE
#> [1] TRUE
```

`!` è l'operatore booleano «not».
Scambia i valori `TRUE` e `FALSE`.

```R
!TRUE
#> [1] FALSE
!FALSE
#> [1] TRUE
```

Per espressioni più lunghe e complicate, è meglio usare le parentesi per chiarire la tua intenzione.

```R
(TRUE || FALSE) && (FALSE && TRUE)
#> [1] FALSE
```
