# Caratteri

Un `CHAR` è un singolo carattere, scritto tra apici singoli.

```sather
   c : CHAR := 'M';
```

## Caratteri speciali

Alcuni caratteri non si possono digitare direttamente e si scrivono con una barra rovesciata:

| Scritto | È |
| --- | --- |
| `'\n'` | una nuova riga |
| `'\t'` | una tabulazione |
| `'\''` | un apice |
| `'\\'` | una barra rovesciata |

## Domande

```sather
'M'.is_alpha      -- true
'7'.is_digit      -- true
'M'.is_upper      -- true
' '.is_space      -- true
'M'.is_alphanum   -- true, a letter or a digit
```

## Maiuscole e minuscole

`.upper` e `.lower` cambiano il caso di una lettera e lasciano invariato tutto il resto, quindi puoi applicarli senza rischi a un carattere che non hai verificato.

## Numeri

```sather
'a'.int           -- 97
97.char           -- 'a'
```

`.int` e `.char` sono l'uno l'esatto inverso dell'altro. Sulla numerazione, i fatti utili sono questi: da `'a'` a `'z'` i valori sono consecutivi, da `'A'` a `'Z'` sono consecutivi e da `'0'` a `'9'` sono consecutivi. Quindi:

```sather
   c.int - 'a'.int          -- how far c is along the alphabet
   ('a'.int + n).char       -- the letter n places along
   d.int - '0'.int          -- the value of a digit character
```

## Ripartire da capo

Un disco cifrante gira oltre la `z` e torna alla `a`. `%` fa esattamente questo:

```sather
   ('a'.int + (c.int - 'a'.int + places) % 26).char
```

Il `%` di Sather non restituisce mai un risultato negativo quando il lato destro è positivo, quindi funziona sia per girare il disco in avanti sia all'indietro.

## Caratteri e stringhe

Una `STR` è una sequenza di byte, e un `CHAR` è un byte solo. Per un testo in inglese un byte è una lettera, quindi `"Marlowe".size` vale 7 e `"Marlowe"[0]` è `'M'`. Per un testo con accenti o con un altro alfabeto, una lettera può occupare più byte, e nessuna delle due cose vale più.
