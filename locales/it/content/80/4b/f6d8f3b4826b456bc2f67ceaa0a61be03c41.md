# Suggerimenti

## 1. Sostituisci gli spazi con gli underscore

- [Questo tutorial][chars-tutorial] è utile.
- Puoi recuperare i `char` da una stringa usando il metodo [charAt][char-at].
- Dovresti usare uno [`StringBuilder`][string-builder] per costruire la stringa di output.
- Consulta la documentazione di [Character][chars-docs] per trovare un metodo che rilevi gli spazi bianchi. Ricorda che è un metodo statico.
- I letterali `char` sono racchiusi tra virgolette singole.

## 2. Converti il kebab-case in camel-case

- Consulta la documentazione di [Character][chars-docs] per trovare un metodo che converta un carattere in maiuscolo. Ricorda che è un metodo statico.

## 3. Converti il leetspeak in testo normale

- Consulta la documentazione di [Character][chars-docs] per trovare un metodo che rilevi quando un carattere è una cifra. Ricorda che è un metodo statico.

## 4. Ometti i caratteri che non sono lettere

- Consulta la documentazione di [Character][chars-docs] per trovare un metodo che rilevi quando un carattere è una lettera. Ricorda che è un metodo statico.
