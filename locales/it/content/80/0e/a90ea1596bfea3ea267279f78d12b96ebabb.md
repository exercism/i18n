# Test

Per eseguire i test, installa prima il pacchetto `z3-solver`:

```
pip install z3-solver
```

A questo punto puoi eseguire i test con il comando seguente, dalla directory dell'esercizio:

```
python <snake_case_exercise>_test.py
```

dove `<snake_case_exercise>` va sostituito con il nome dell'esercizio.
