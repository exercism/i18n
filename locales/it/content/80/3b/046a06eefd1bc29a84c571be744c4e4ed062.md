# Appendice alle istruzioni

## Note sull'implementazione

La definizione dell'interfaccia Cipher si trova in `cipher.go`.

Le tue implementazioni devono essere conformi all'interfaccia Cipher.

```go
type Cipher interface {
    Encode(string) string
    Decode(string) string
}
```

Ci si aspetta che `Encode` ignori tutti i caratteri della stringa che non siano A-Za-z: non saranno rappresentati nell'output.
Anche l'output sarà normalizzato in minuscolo.

Le funzioni usate per ottenere i cifrari sono:

```go
func NewCaesar() Cipher { }

func NewShift(distance int) Cipher { }

func NewVigenere(key string) Cipher { }
```

L'argomento di `NewShift` deve essere compreso tra 1 e 25 oppure tra -1 e -25.
Lo zero non è ammesso.
Per argomenti non validi, `NewShift` restituisce nil.

L'argomento di `NewVigenere` deve essere composto solo da lettere minuscole da a a z.
I valori composti interamente dalla lettera 'a' non sono ammessi.
Per argomenti non validi, `NewVigenere` restituisce `nil`.
