# Introduzione

## Operatori ternari

L'_operatore ternario_ è un'alternativa leggera e compatta alle semplici istruzioni _if/else_.
Di solito si usa nelle istruzioni di return (ma non solo): basta una sola riga per prendere la decisione, restituendo il valore di sinistra se l'espressione è `true` e il valore di destra se è `false`, come segue:

```java
boolean expr = 0 != 200;

// Ternary statement
int value = expr ? 22 : 33;
// => 22
```

Molte espressioni _if/else_ semplici possono essere semplificate usando gli _operatori ternari_.
