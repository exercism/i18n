# Introduzione

## Le basi

### Variabili

Elixir è un linguaggio a tipizzazione dinamica: il tipo di una variabile viene controllato solo a runtime. Con l'operatore di corrispondenza `=`, possiamo associare un valore di qualsiasi tipo a un nome di variabile:

```elixir
# Bound an integer value of 1
count = 1
# You may re-bind variables
count = 2

# You may re-bind any type to a variable
count = false

# Strings can be created by enclosing characters within double quotes
message = "Success!"
```

### Moduli

Elixir è un [linguaggio di programmazione funzionale][functional-programming] e richiede che tutte le funzioni con nome siano definite all'interno di un _modulo_. La parola chiave `defmodule` serve a definire un modulo. Tutti i moduli sono disponibili per tutti gli altri moduli a runtime e non richiedono un _modificatore di accesso_ per essere visibili alle altre parti del programma. Un _modulo_ è analogo a una _classe_ in altri linguaggi di programmazione.

```elixir
defmodule Calculator do
  # ...
end
```

### Funzioni con nome

Le _funzioni con nome_ devono essere definite all'interno di un modulo. La parola chiave `def` serve a definire una funzione con nome _pubblica_.

Ogni funzione può avere zero o più argomenti. Il valore dell'ultima espressione di una funzione viene sempre _restituito in modo implicito_.

```elixir
defmodule Calculator do
  def add(x, y) do
    x + y
  end
end
```

Chiamare una funzione significa specificarne il modulo e il nome e passare gli argomenti corrispondenti.

```elixir
sum = Calculator.add(1, 2)
# => 3
```

La parola chiave `defp` può essere usata al posto di `def` per definire una funzione _privata_. Le funzioni private possono essere usate solo all'interno dello stesso modulo che le ha definite.

Quando si chiama una funzione all'interno dello stesso modulo in cui è definita, si può omettere il nome del modulo.

Puoi anche scrivere funzioni brevi con una sintassi su una sola riga (nota la virgola `,` e i due punti `:` attorno alla parola chiave `do`).

```elixir
defmodule Calculator do
  def subtract(x, y) do
    private_subtract(x, y)
  end

  defp private_subtract(x, y), do: x - y
end

difference = Calculator.subtract(7, 2)
# => 5

difference = Calculator.private_subtract(7, 2)
# => ** (UndefinedFunctionError) function Calculator.private_subtract/2 is undefined or private
#       Calculator.private_subtract(7, 2)
```

### L'arità delle funzioni

È comune riferirsi alle funzioni indicandone l'_arità_. L'_arità_ di una funzione è il numero di argomenti che accetta.

```elixir
# add/3 because this function has three arguments, thus an arity of 3
def add(x, y, z) do
  x + y + z
end
```

### Convenzioni di denominazione

I nomi dei moduli dovrebbero usare `PascalCase`. Un nome di modulo deve iniziare con una lettera maiuscola `A-Z` e può contenere lettere `a-zA-Z`, numeri `0-9` e underscore `_`.

I nomi delle variabili e delle funzioni dovrebbero usare `snake_case`. Un nome di variabile o di funzione deve iniziare con una lettera minuscola `a-z` o un underscore `_`, può contenere lettere `a-zA-Z`, numeri `0-9` e underscore `_`, e può terminare con un punto interrogativo `?` o un punto esclamativo `!`.

### La libreria standard

Elixir ha una libreria standard molto ricca e ben documentata. La documentazione è disponibile online su [hexdocs.pm/elixir][docs]. Salva questo link da qualche parte: ti servirà spesso!

La maggior parte dei tipi di dati predefiniti ha un modulo corrispondente che offre funzioni per lavorare con quel tipo di dati: ad esempio, c'è il modulo `Integer` per gli interi, il modulo `String` per le stringhe, il modulo `List` per gli array e così via.

Un modulo degno di nota è il modulo `Kernel`. Fornisce le capacità di base su cui è costruito il resto della libreria standard, come gli operatori aritmetici, le macro di controllo del flusso e molto altro. Le funzioni del modulo `Kernel` vengono importate automaticamente, quindi puoi usarle senza il prefisso `Kernel.`.

### I commenti nel codice

I commenti possono essere usati per lasciare note ad altri sviluppatori che leggono il codice sorgente. I commenti su una sola riga in Elixir sono preceduti da `#`.
