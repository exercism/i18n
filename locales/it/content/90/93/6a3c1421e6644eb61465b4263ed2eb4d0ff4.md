# Informazioni

Un [record][records] è una raccolta di campi (che possono essere di tipi diversi) che appartengono insieme. Per [definire un record][define] si usa la parola chiave `type`. I campi di un record sono definiti tra i caratteri `{` e `}`, ed ogni campo ha un nome _ed_ un tipo.

```fsharp
type Address =
    { Street: string
      HouseNumber: int }
```

Per [creare un record][create], specifica i nomi dei campi e assegna loro un valore tra i caratteri `{` e `}`. Quando si crea un record, a tutti i suoi campi deve essere assegnato un valore. I campi possono essere specificati in qualsiasi ordine, non devono corrispondere all'ordine della definizione del tipo di record. Per accedere ai valori dei campi di un'istanza di record si usa la notazione con il punto.

```fsharp
let oldAddress: Address =
    { Street = "Main Street"
      HouseNumber = 17 }

oldAddress.Street      // => "Main Street"
oldAddress.HouseNumber // 17
```

Quando si definisce o crea un record, ogni campo deve trovarsi su una riga separata oppure essere separato da punto e virgola (`;`) quando si trova su una singola riga:

```fsharp
type Address = { Street: string; HouseNumber: int }

let oldAddress: Address = { Street = "Main Street"; HouseNumber = 17 }
```

Se i nomi dei campi di un record sono univoci, le annotazioni di tipo sono facoltative perché il compilatore sarà in grado di dedurre il tipo automaticamente. Se la combinazione dei nomi dei campi _non_ è univoca, puoi aiutare il compilatore a scegliere il record corretto usando un tipo esplicito per il binding del record oppure anteponendo il tipo del record a uno o più campi:

```fsharp
type Boat = { Weight: int; Length: int }
type Car = { Weight: int; Length: int }

// Let compiler infer type. As there are multiple matching record types,
// the last matching type is used (Car)
let typeEqualsLastMatch = { Weight = 5000; Length = 15 }

// Use type annotation on binding to force type to Boat
let typeAnnotation: Boat = { Weight = 5000; Length = 15 }

// Use fully qualified name for field to force type to Boat
let fullyQualifiedField = { Boat.Weight = 5000; Length = 15}
```

Poiché i record sono immutabili, una volta che un record è stato costruito i suoi valori di campo non possono mai cambiare. Se vuoi modificare i valori di un record, la parola chiave `with` ti permette di [creare una copia di un record esistente, ma con nuovi valori per uno o più campi][create].

```fsharp
// Copy the old address but change the house number
let newAddress = { oldAddress with HouseNumber = 86 }
newAddress.Street      // => "Main Street"
newAddress.HouseNumber // => 86
```

I record hanno [_uguaglianza strutturale_][equality], il che significa che due istanze dello stesso record con valori identici sono equivalenti:

```fsharp
let address1 = { Street = "Main Street"; HouseNumber = 17 }
let address2 = { Street = "Main Street"; HouseNumber = 17 }
let address3 = { Street = "Broadway"; HouseNumber = 17 }

address1 = address2 // => true
address1 = address3 // => false
```

Oltre a poter usare la notazione con il punto per accedere ai campi di un record, i record possono anche essere _destrutturati_ nei binding e nel pattern matching usando il [pattern record][record-patterns]:

```fsharp
let myAddress = { Street = "Broadway"; HouseNumber = 123 }
let { Street = myStreet; HouseNumber = myHouseNumber } = myAddress

match myAddress with
| { HouseNumber = 1 } -> printfn "First house"
| { HouseNumber = houseNumber; Street = street } -> printfn "House number %d on %s" houseNumber street
// => "House number 123 on Broadway
```
