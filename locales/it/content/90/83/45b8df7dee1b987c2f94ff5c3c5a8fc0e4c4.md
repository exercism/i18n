# Istruzioni

Questo esercizio ha due obiettivi:

1. Implementa una funzione `promisify` che trasforma una funzione che usa il «pattern callback» in una funzione che restituisce una `Promise`. Guarda l'esempio qui sotto.

```javascript
function fetchProduct(productId, function(error, data) {
    if (error) {
        // Handle the error
    } else {
        // Make something with your data
    }
})

const fetchProductAsPromise = promisify(fetchProduct);

// Now you got a function `fetchProductAsPromise`
// that returns a promise
fetchProductAsPromise(productId)
    .then((data) => {})
    .catch((error) => {});
```

2. Reimplementa i seguenti metodi integrati di `Promise` (senza usarli)

- `all`: prende un array di promesse e si risolve quando _tutte_ sono state risolte, oppure si rifiuta quando _una_ di esse viene rifiutata.
- `allSettled`: prende un array di promesse e si risolve quando _tutte_ si risolvono o si rifiutano.
- `race`: prende un array di promesse e si risolve o si rifiuta con il valore della _prima_ promessa che si risolve o si rifiuta.
- `any`: prende un array di promesse e si risolve quando _una_ di esse si risolve, oppure si rifiuta quando _tutte_ si rifiutano.
