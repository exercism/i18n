# Istruzioni

Implementa un valutatore per un sottoinsieme molto semplice di Forth.

[Forth][forth] è un linguaggio di programmazione basato sullo stack.
Implementa un valutatore molto semplice per un piccolo sottoinsieme di Forth.

Il valutatore deve supportare le seguenti parole:

- `+`, `-`, `*`, `/` (aritmetica intera)
- `DUP`, `DROP`, `SWAP`, `OVER` (manipolazione dello stack)

Puoi usare una tupla come stack, così eviti i codici operativi legati allo stack di fift e asm.

Per mantenere le cose semplici, l'unico tipo di dato che devi supportare sono gli interi con segno di almeno 16 bit.

Per la sintassi, usa le seguenti regole: un numero è una sequenza di una o più cifre (ASCII), una parola è una sequenza di una o più lettere, cifre, simboli o segni di punteggiatura che non è un numero.
(Probabilmente Forth usa regole leggermente diverse, ma queste ci si avvicinano abbastanza.)
