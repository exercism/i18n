# Introduzione

Un `array` in F# è una collezione mutabile di zero o più valori con una lunghezza fissa. Questo significa che una volta creato un array, la sua dimensione non può cambiare, ma i suoi valori sì. I valori in un array devono avere tutti lo stesso tipo. Gli array possono essere definiti come segue:

```fsharp
let empty = [| |]
let emptyAlternative = Array.empty

let singleValue = [| 5 |]
let singleValueAlternative = Array.singleton 5

let threeValues = [| "a"; "b"; "c" |]
```

Gli elementi possono essere assegnati a un array o recuperati da esso tramite un indice. Gli array di F# sono basati sullo zero, cioè l'indice del primo elemento è sempre zero:

```fsharp
let numbers = [| 2; 3; 5 |]

// Update value in array
numbers[2] <- 9

// Read value from array
numbers[2]
// => 9
```

Gli array si possono manipolare con le funzioni e gli operatori definiti nel modulo `Array`, oppure manualmente usando il pattern matching con il pattern _array_:

```fsharp
let describe array =
    match array with
    | [| |] -> "Empty"
    | [| 1; 2; three |] -> sprintf "1, 2, %d" three
    | _ -> "Other"

describe [| |]         // => "Empty"
describe [| 1; 2; 4 |] // => "1, 2, 4"
describe [| 5; 7; 9 |] // => "Other"
```

Puoi anche _scartare_ un valore durante il pattern matching; quando un valore _non_ ti interessa in un caso specifico (cioè non lo _userai_), puoi usare un underscore (`'_'`) per indicarlo:

```fsharp
let describe array =
    match array with
    | [| |] -> "Empty array"
    | [| x |] -> "Array with one item"
    | [| _; y |] -> "Array with two items (first item ignored)"
    | _ -> "Array with many items (all items ignored)"

describe [| |]          // => "Empty array"
describe [| 1 |]        // => "Array with one item"
describe [| 5; 7 |]     // => "Array with two items (first item ignored)"
describe [| 5; 7; 9 |]  // => "Array with many items (all items ignored)"
```

Il singolo `'_'` dovrebbe sempre venire per _ultimo_ nel pattern matching: ogni valore che _non_ corrisponde a nessuno degli altri casi verrà gestito da questo caso.
