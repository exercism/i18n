# Introduzione

In Go, le stringhe sono immutabili.
Concatenare stringhe con `+` all'interno di un ciclo provoca allocazioni frequenti e copie ripetute dei dati.
Il [pacchetto `strings`](https://pkg.go.dev/strings) fornisce [`Builder`](https://pkg.go.dev/strings#Builder) per ridurre al minimo il sovraccarico di memoria assemblando le stringhe in modo efficiente.

## Costruire stringhe

Il valore zero di un `strings.Builder` è subito pronto all'uso, senza alcuna inizializzazione o allocazione esplicita.
Puoi inserire nuovi dati nel builder usando metodi di scrittura specifici.
Ogni metodo di scrittura restituisce un valore di errore per soddisfare le interfacce standard di Go, ma è garantito che sia sempre `nil` e in genere viene ignorato nel codice quotidiano.

I metodi più usati sono:

- `WriteString(s string) (int, error)`: aggiunge una stringa al buffer.
- `WriteRune(r rune) (int, error)`: aggiunge la codifica UTF-8 di una rune.
- `WriteByte(c byte) error`: aggiunge un singolo byte.

```go
var sb strings.Builder

sb.WriteString("Hello")
var r rune = ' '
sb.WriteRune(r)
var b byte = '.'
sb.WriteByte(b)
```

## Recuperare e azzerare

Quando hai finito di assemblare il testo, puoi estrarre il contenuto accumulato come stringa Go standard chiamando il metodo `String()`.
Chiamare `String()` è un'operazione molto economica, perché restituisce direttamente la slice di byte sottostante come stringa, senza copiare i dati accumulati.

Se devi riutilizzare la stessa istanza del builder per assemblare una nuova stringa (per esempio, all'interno di un ciclo), puoi chiamare il metodo `Reset()`.
Svuota il buffer interno, così puoi ricominciare e costruire la stringa successiva, preservando dietro le quinte la capacità di memoria già allocata.

```go
var sb strings.Builder

sb.WriteString("Task One")
fmt.Println(sb.String()) // Output: Task One

// Clear the buffer for resource reuse
sb.Reset()

sb.WriteString("Task Two")
fmt.Println(sb.String()) // Output: Task Two
```
