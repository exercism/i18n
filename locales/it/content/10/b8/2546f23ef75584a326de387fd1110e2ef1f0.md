# Istruzioni

In questo esercizio scriverai codice per gestire un dizionario di prefissi telefonici internazionali usando una `Map`.

Il dizionario permette di cercare il nome di un paese (il valore della mappa, come `String`) tramite il prefisso telefonico internazionale (la chiave della mappa, come `Integer`).

## 1. Restituisci i prefissi in una mappa

Implementa il metodo `getCodes` che non accetta parametri e restituisce una mappa che associa i prefissi telefonici ai paesi attualmente presenti nel dizionario.

```java
DialingCodes dialingCodes = new DialingCodes();
dialingCodes.getCodes();
// => empty map 
```

## 2. Aggiungi voci al dizionario

Il dizionario deve essere popolato.
Implementa il metodo `setDialingCode` che accetta un prefisso telefonico ed il paese corrispondente, ed aggiunge il prefisso ed il paese.
Se il prefisso è già nella mappa, aggiorna la mappa con il prefisso ed il paese forniti.

```java
DialingCodes dialingCodes = new DialingCodes();
dialingCodes.setDialingCode(679, "Unknown");
// => { 679 => "Unknown" }

dialingCodes.setDialingCode(679, "Fiji");
// => { 679 => "Fiji" }
```

## 3. Trova il paese di un prefisso telefonico

Implementa il metodo `getCountry` che accetta un prefisso telefonico e restituisce il nome del paese associato a quel prefisso.

```java
DialingCodes dialingCodes = new DialingCodes();
dialingCodes.setDialingCode(55, "Brazil");
dialingCodes.getCountry(55);
// => "Brazil"
```

## 4. Non permettere duplicati

Quando aggiungi un prefisso, bisogna fare attenzione a non aggiungere due volte lo stesso prefisso o lo stesso paese.
Quando succede, si può presumere che la prima voce inserita sia quella giusta.
Implementa il metodo `addNewDialingCode` che aggiunge una voce per il prefisso telefonico ed il paese indicati.
A differenza di `setDialingCode`, però, non fa nulla se il prefisso o il paese sono già nella mappa.

```java
DialingCodes dialingCodes = new DialingCodes();
dialingCodes.addNewDialingCode(32, "Belgium");
dialingCodes.addNewDialingCode(379, "Vatican City");
// => { 32 => "Belgium", 379 => "Vatican City" }


dialingCodes.addNewDialingCode(32, "Other");
dialingCodes.addNewDialingCode(39, "Vatican City");
// => { 32 => "Belgium", 379 => "Vatican City" }
```

## 5. Trova il prefisso telefonico di un paese

È raro, ma si possono commettere errori.
Per correggere l'errore, dobbiamo sapere a quale prefisso telefonico il paese è attualmente associato.
Per scoprire quale prefisso deve essere corretto, implementa il metodo `findDialingCode` che accetta un paese e restituisce il prefisso telefonico di quel paese.
Restituisci `null` se il paese _non_ è nella mappa.

```java
DialingCodes dialingCodes = new DialingCodes();
dialingCodes.addDialingCode(44, "UK");
dialingCodes.findDialingCode("UK");
// => 44

dialingCodes.findDialingCode("Unlisted");
// => null
```

## 6. Aggiorna il prefisso telefonico di un paese

Ora che sappiamo quale prefisso deve essere corretto, procediamo ad aggiornarlo.
Implementa il metodo `updateCountryDialingCode` che accetta il nuovo prefisso telefonico del paese ed il nome del paese, e aggiorna di conseguenza.
Non fare nulla se il paese _non_ è nella mappa (questo metodo serve solo ad aiutare a correggere gli errori).

```java
DialingCodes dialingCodes = new DialingCodes();
dialingCodes.addDialingCode(88, "Japan");
// => { 88 => "Japan" }

dialingCodes.updateCountryDialingCode(81, "Japan");
// => { 81 => "Japan" }

dialingCodes.updateCountryDialingCode(32, "Mars");
// => { 81 => "Japan"}
```
