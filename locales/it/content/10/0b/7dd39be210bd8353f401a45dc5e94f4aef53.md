# Test

## Dalla riga di comando

Basta digitare `p test`. Si presume che il percorso dei binari di phix sia stato dichiarato nella variabile d'ambiente PATH.

Per i dettagli sul framework di test normalmente utilizzato, vedi [Test unitari][unit-testing].

## Modificare i file test.exw

All'inizio del tuo percorso è una pratica incoraggiata. Inserisci un `--` prima di tutti i test, tranne il primo o i primi due. Salva il file di test. Scrivi il codice per risolvere il primo test o i primi due. Poi abilita progressivamente altri test finché non riesci a superarli tutti.

[unit-testing]: http://phix.x10.mx/docs/html/unit_test.htm
