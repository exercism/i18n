# Case

[Case][case] (spesso chiamato switch in altri linguaggi) è una forma di espressione di controllo simile a if-else. Case permette di concatenare più istruzioni if-else-if e può risultare più leggibile pur offrendo comunque il controllo di flusso.

Un case è definito dalla parola chiave `case` seguita da un'espressione facoltativa. Poi, per ogni caso, si usa la parola chiave `when` seguita da un'espressione che viene confrontata con l'espressione del case. La parola chiave `when` non deve essere indentata rispetto alla parola chiave `case`. Dopo la parola chiave `when` c'è il codice che deve essere eseguito se l'espressione del case corrisponde all'espressione del when. Case permette di usare un'istruzione `else` facoltativa, che viene eseguita se nessun altro caso corrisponde.

L'espressione del case viene valutata e poi confrontata con ciascuna espressione del when. Il confronto avviene tramite l'operatore di uguaglianza del case (`===`).

```ruby
value = 1
case value
when 1
  "One"
when 2
  "Two"
else
  "Other"
end

# This is the same as:
value = 1
if 1 === value
  "One"
elsif 2 === value
  "Two"
else
  "Other"
end
```

## L'operatore di uguaglianza del case (`===`)

L'operatore di uguaglianza del case (`===`) è un po' diverso dall'operatore di uguaglianza (`==`).
Questo operatore controlla se il lato destro è un membro dell'insieme descritto dal lato sinistro.
Questo significa che la posizione di ciascun operando conta davvero.
Il funzionamento dipende dal tipo del lato sinistro: per esempio, un `Range` controlla se il lato destro è compreso nell'intervallo, mentre un `Object` controlla se il lato destro è un'istanza di `Object`.

```ruby
(1..3) == 1  # => false
(1..3) === 1 # => true

String == "foo"  # => false
String === "foo" # => true
```

## Il case con più espressioni

Il case permette di far corrispondere più espressioni in un unico caso, separando ogni valore possibile con una virgola.
Il codice viene eseguito se una qualsiasi delle espressioni corrisponde.
Questo può essere utile quando vuoi che un singolo caso abbia più valori possibili.

```ruby
case var
when 1, 2
  "One or two"
else
  "Other"
end
```

## Il case con gli intervalli

Il case può anche controllare se un valore è compreso in un intervallo.
Per farlo, si usa un intervallo come espressione del when.

```ruby
case var
when 1..3
  puts "One to three"
else
  puts "Other"
end
```

## Il case senza espressione

Quando non c'è bisogno di un'espressione del case, è possibile ometterla.
In questo modo, ogni espressione del when viene valutata in base alla sua veridicità, ed il case si comporta come una serie di istruzioni if-else-if.

```ruby
case
when 1 == 1
  "One is equal to one"
when 1 > 2
  "One is greater than two"
else
  "Other"
end
```

## Il when su una sola riga

Ruby permette di scrivere istruzioni case su una sola riga.
Puoi usarle quando hai una semplice istruzione su una sola riga.
L'istruzione when su una sola riga si scrive come `when <expression> then <statement>`.
E quando viene usata nell'istruzione else, si scrive come `else <statement>`.

```ruby
case var
when 1 then "One"
when 2 then "Two"
else "Other"
end
```

## Il case con i tipi

Il case permette di far corrispondere i tipi.
Questo è utile quando si vuole un comportamento diverso a seconda del tipo di una variabile.

```ruby
case var
when Integer
  "Integer"
when String
  "String"
else
  "Other"
end
```
