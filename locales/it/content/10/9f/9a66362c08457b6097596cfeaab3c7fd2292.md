# Introduzione

Le funzioni ricorsive sono funzioni che chiamano se stesse.

Una funzione ricorsiva deve avere almeno un _caso base_ e almeno un _caso ricorsivo_.

Un _caso base_ restituisce un valore senza richiamare la funzione.
Un _caso ricorsivo_ richiama la funzione, modificando l'input in modo che a un certo punto corrisponda al caso base.

In Elm, le funzioni ricorsive vengono in genere definite usando il pattern matching con espressioni `case` o più clausole di funzione.

```elm
count : List a -> Int
count list =
    case list of
        [] ->
            0  -- base case

        _ :: tail ->
            1 + count tail  -- recursive case
```

## Cicli tramite la ricorsione

A causa dell'immutabilità, i cicli in Elm si scrivono diversamente dai linguaggi imperativi.
Per esempio, i cicli spesso hanno questo aspetto:

```c
for(i = 0; i < array.length; i++) {
  // do something with array[i]
}
```

In un linguaggio funzionale come Elm, non è possibile mutare le variabili.
Quindi i cicli vanno implementati con la ricorsione.

L'equivalente di un ciclo `for` in Elm sarebbe questo:

```elm
loop : List a -> (a -> b) -> List b
loop list f =
    case list of
        [] ->
            []

        head :: tail ->
            f head :: loop tail f
```

Nella pratica, in Elm si itera su array e altre strutture dati usando per lo più funzioni dal modulo `List`, come `List.map`, `List.filter` e `List.foldl`.
Sotto il cofano, queste funzioni sono implementate tramite la ricorsione.
