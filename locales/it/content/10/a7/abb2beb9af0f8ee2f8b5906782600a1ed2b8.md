# Introduzione

C# è un linguaggio a tipizzazione statica, il che significa che tutto ha un tipo in fase di compilazione. Assegnare un valore a un nome si chiama definire una variabile. Una variabile può essere definita specificando esplicitamente il suo tipo oppure lasciando che il compilatore C# inferisca il tipo in base al valore assegnato (la cosiddetta _inferenza dei tipi_). Pertanto, le due definizioni di variabile seguenti sono equivalenti:

```csharp
int explicitVar = 10; // Explicitly typed
var implicitVar = 10; // Implicitly typed
```

Aggiornare il valore di una variabile avviene tramite l'operatore `=`. Una volta definita, il tipo di una variabile non può mai cambiare.

```csharp
var count = 1; // Assign initial value
count = 2;     // Update to new value

// Compiler error when assigning different type
// count = false;
```

C# è un [linguaggio orientato agli oggetti][object-oriented-programming] e richiede che tutte le funzioni siano definite in una _classe_. La parola chiave `class` si usa per definire una classe. Gli oggetti (o _istanze_) si creano usando la parola chiave `new`.

```csharp
class Calculator
{
    // ...
}

var calculator = new Calculator();
```

Una funzione all'interno di una classe si chiama _metodo_. Ogni metodo può avere zero o più parametri. Tutti i parametri devono avere un tipo esplicito: non c'è inferenza dei tipi per i parametri. Allo stesso modo, anche il tipo restituito deve essere esplicito. I valori vengono restituiti dai metodi usando la parola chiave `return`. Per permettere che il codice in altri file chiami un metodo, bisogna aggiungere il modificatore di accesso `public`.

```csharp
class Calculator
{
    public int Add(int x, int y)
    {
        return x + y;
    }
}
```

I metodi si chiamano usando la sintassi con il punto (`.`) su un'istanza, specificando il nome del metodo da chiamare e passando gli argomenti per ciascuno dei suoi parametri. Gli argomenti possono specificare facoltativamente il nome del parametro corrispondente.

```csharp
var calculator = new Calculator();
var sum_v1 = calculator.Add(1, 2);
var sum_v2 = calculator.Add(x: 1, y: 2);
```

Lo scope in C# è definito tra i caratteri `{` e `}`.

C# supporta due tipi di commenti. I commenti su una sola riga sono preceduti da `//`, mentre i commenti su più righe si inseriscono tra `/*` e `*/`.
