# Introduzione

Un [`list`][list] è una raccolta mutabile di elementi in _sequenza_.
 Come la maggior parte delle raccolte (_vedi i tipi integrati [`tuple`][tuple], [`dict`][dict] e [`set`][set]_), gli array possono contenere riferimenti a qualsiasi tipo di dati (o a più tipi), compresi gli altri array.
 Gli array possono essere copiati in tutto o in parte tramite la [notazione di slicing][slice notation] oppure usando `<list>.copy()`.
 Come qualsiasi [sequenza][sequence type], gli elementi all'interno di `lists` sono referenziati tramite un numero `0-based index` partendo da sinistra, o un numero `-1-based index` partendo da destra.

Gli array supportano sia le operazioni di sequenza [comuni][common sequence operations] sia quelle [mutabili][mutable sequence operations], come `min(<list>)`/`max(<list>)`, `<list>.index()`, `<list>.append()` e `<list>.reverse()`.
 Gli elementi all'interno di un `list` possono essere iterati usando il costrutto `for item in <list>`.
 `for index, item in enumerate(<list>)` può essere usato quando servono sia l'indice sia il valore dell'elemento.

Python fornisce anche molti utili [metodi degli array][list-methods] per lavorare con gli array.
 Una selezione di questi `list methods` è trattata di seguito.


Nota che quando manipoli un `list` con un `list-method`, **modifichi l'array** che è stato passato.
 Se non vuoi mutare il `list` originale, dovrai almeno farne una `shallow copy` tramite slicing o `<list>.copy()`.


## Aggiungere elementi

Per aggiungere un elemento alla fine, o al «lato destro», di un array esistente, usa `<list>.append(<item>)`:

```python
>>> numbers = [1, 2, 3]
>>> numbers.append(9)

>>> numbers
[1, 2, 3, 9]
```

Invece di _accodare_, `<list>.insert()` ti permette di aggiungere l'elemento a un _indice specifico_ dell'array.
 Richiede 2 parametri:

1. lo `<index>` in cui vuoi che venga inserito l'elemento.
2. lo `<item>` da inserire.

**Nota**: se l'`index` fornito è 0, l'elemento verrà aggiunto all'inizio («lato sinistro») del `list`.
 Se l'`index` fornito è maggiore dell'`index` finale del `list`, l'elemento verrà aggiunto nell'ultima posizione, l'equivalente di usare `<list>.append(<item>)`.


```python
>>> numbers = [1, 2, 3]
>>> numbers.insert(0, -2)

>>> numbers
[-2, 1, 2, 3]

>>> numbers.insert(1, 0)

>>> numbers
[-2, 0, 1, 2, 3]
```


`<list>.extend(<item>)` può essere usato per combinare un array esistente con gli elementi di un altro iterabile (per esempio un `set`, `tuple`, `str` o `list`).
  L'iterabile viene _scompattato_ e gli elementi vengono aggiunti in ordine (_in questo caso, usare `<list>.append(<item>)` aggiungerebbe l'intero iterabile come **un singolo elemento**._).


```python
>>> numbers = [1, 2, 3]
>>> other_numbers = [5, 6, 7]

>>> numbers.extend(other_numbers)

>>> numbers
[1, 2, 3, 5, 6, 7]

>>> numbers.extend([8, 9])

>>> numbers
[1, 2, 3, 5, 6, 7, 8, 9]

>>> numbers.append([8,9])

>>> numbers
[1, 2, 3, 5, 6, 7, 8, 9, [8, 9]]
```


## Rimuovere elementi

Per eliminare un elemento da un array usa `<list>.remove(<item>)`, passando come argomento l'elemento da rimuovere.
 `<list>.remove(<item>)` solleva un `ValueError` se l'elemento non è presente nel `list`.


```python
>>> numbers = [1, 2, 3]
>>> numbers.remove(2)

>>> numbers
[1, 3]

# Trying to remove a value that is not in the list throws a ValueError
>>> numbers.remove(0)
ValueError: list.remove(x): x not in list
```


In alternativa, usare il metodo `<list>.pop(<index>)` rimuove **e** `return` un elemento, rendendolo disponibile per l'uso.


`<list>.pop(<index>)` accetta un parametro opzionale: l'`index` dell'elemento da rimuovere e restituire.
 Se l'argomento (opzionale) `index` non è specificato, verranno rimossi e restituiti l'ultimo elemento del `list`.
 Se l'`index` specificato è maggiore dell'`index` dell'ultimo elemento, viene sollevato un `IndexError`.


```python
>>> numbers = [1, 2, 3]

>>> numbers.pop(0)
1

>>> numbers
[2, 3]

>>> numbers.pop()
3

>>> numbers
[2]

>>> numbers.pop(1)
Traceback (most recent call last):
  File "<stdin>", line 1, in <module>
IndexError: pop index out of range
```

Tutti gli elementi possono essere rimossi da un `list` con `list.clear()`. Non accetta alcun parametro.

```python
>>> numbers = [1, 2, 3]
>>> numbers.clear()

>>> numbers
[]
```

## Invertire e riordinare

Il metodo `<list>.reverse()` inverte l'ordine degli elementi **sul posto**.


```python
>>> numbers = [1, 2, 3]
>>> numbers.reverse()

>>> numbers
[3, 2, 1]
```


Un array può essere riordinato _**sul posto**_ con l'aiuto di [`<list>.sort()`][sort].
 L'ordinamento predefinito è _crescente_ da sinistra.
 La documentazione di Python offre [ulteriori suggerimenti e tecniche per l'ordinamento][sorting how to].

~~~~exercism/note
 Dal 2002 al 2022, Python usava internamente un algoritmo chiamato [`Timsort`][timsort] per ordinare gli array, ma da `Python 3.11` in poi è passato a [`Powersort`][powersort].

[powersort]: https://www.wild-inter.net/publications/munro-wild-2018
[timsort]: https://en.wikipedia.org/wiki/Timsort
~~~~


```python
>>> names = ["Tony", "Natasha", "Thor", "Bruce"]

# The default sort order is *ascending*.
>>> names.sort()

>>> names
["Bruce", "Natasha", "Thor", "Tony"]
```

Se vuoi un ordine _decrescente_, passa l'argomento `reverse=True`:

```python
>>> names = ["Tony", "Natasha", "Thor", "Bruce"]
>>> names.sort(reverse=True)

>>> names
["Tony", "Thor", "Natasha", "Bruce"]
```

Nei casi in cui non vuoi mutare l'array originale, puoi usare la funzione integrata [`sorted(<iterable>)`][sorted] per ottenere una **copia** ordinata.


```python
>>> names = ["Tony", "Natasha", "Thor", "Bruce"]

>>> sorted(names)
['Bruce', 'Natasha', 'Thor', 'Tony']
```


## Occorrenze di un elemento in un array

Il numero di occorrenze di un elemento in un array può essere calcolato con l'aiuto di `list.count(<item>)`.
 Prende come argomento l'`item` da contare e restituisce il numero totale di volte in cui quell'elemento compare nel `list`.


```python
>>> items = [1, 4, 7, 8, 2, 9, 2, 1, 1, 0, 4, 3]

>>> items.count(1)
3
```

## Trovare l'indice degli elementi

`<list>.index(<item>)` restituisce il numero `index` della _prima occorrenza_ di un elemento passato.
 Se non ci sono occorrenze, viene sollevato un `ValueError`.
 Se non serve la posizione esatta di un elemento, l'operatore integrato `in` è più efficiente per verificare se un array contiene un dato valore.


L'indicizzazione parte da zero a sinistra, quindi la posizione del «primo» elemento è `0`.
L'indicizzazione funziona anche da destra, iniziando da `-1`.


```python
>>> items = [7, 4, 1, 0, 2, 5]

>>> items.index(4)
1

>>> items.index(10)
ValueError: 10 is not in list
```

Si possono anche fornire gli indici `start` e `end` per restringere la ricerca a una sezione specifica del `list`:

```python
>>> names = ["Tina", "Leo", "Thomas", "Tina", "Emily", "Justin"]

>>> names.index("Tina")
0

>>> names.index("Tina", 2, 5)
3
```
