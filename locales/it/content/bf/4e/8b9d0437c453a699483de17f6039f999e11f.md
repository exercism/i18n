# Introduzione

In Python, [un `enum`][enum-docs] è un insieme di nomi associati a valori `literal` o `constant` univoci.
`Enums` si definiscono ereditando da una classe `Enum` o creandone una sottoclasse.
I tipi `enum` integrati sono disponibili nel modulo `enum` e la classe `Enum` può essere importata con `from enum import Enum`.


```python
from enum import Enum

class Color(Enum):
    RED = 1
    GREEN = 2
```

Nota che i valori dei membri di un `enum` possono essere di qualsiasi tipo di dato, come `str`, `tuple`, `float`, ecc.

```python
class Color(Enum):
    RED = 'red'
    GREEN = 'green'
```

Quando si assegna lo stesso valore a due membri di un `enum`, il membro assegnato per secondo diventa un alias del primo. Non è consentito usare lo stesso nome per due membri diversi di un `enum`.

```python
class Color(Enum):
    RED = 1
    GREEN = 2
    ALIAS_OF_RED = 1

Color.ALIAS_OF_RED
#=> <Color.RED: 1>

Color.ALIAS_OF_RED.value
#=> 1
```

Si può iterare sui membri di un `enum` con la sintassi standard `for member in`:

```python
for member in Color:
    print((member.name, member.value))
#=> (RED, 1)
#=> (GREEN, 2)
```

I membri di `Enum` possono essere confrontati usando [`is` (_operatore di identità_)][identity-keyword] o `is not`. Anche `==` o `!=` (_operatori di uguaglianza_) funzionano allo stesso modo:

```python
a = Color.RED

a is Color.RED
#=> True

a == Color.RED
#=> True
```

Per accedere a un membro di un `enum` per un dato valore, si può usare `<EnumName>(<value>)`:

```python
g = Color(2)

g is Color.GREEN
#=> True

g
#=> <Color.GREEN: 2>
```
