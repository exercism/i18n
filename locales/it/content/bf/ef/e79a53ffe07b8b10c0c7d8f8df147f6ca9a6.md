# Istruzioni

In questo esercizio scriverai codice per aiutare un freelance a comunicare con un project manager, fornendo alcune utilità per calcolare rapidamente le tariffe giornaliere e mensili, eventualmente con uno sconto specificato.

Stabiliamo prima alcune regole tra il freelance e il project manager:

- La tariffa giornaliera è 8 volte la tariffa oraria.
- Un mese ha 22 giorni fatturabili.

A volte il freelance propone di applicare uno sconto sulla propria tariffa giornaliera (per esempio per i clienti più fedeli o per i clienti senza scopo di lucro).

Gli sconti sono modellati come numeri frazionari che rappresentano percentuali, per esempio `25.0` (25%).

## 1. Calcola la tariffa giornaliera data una tariffa oraria

Implementa una funzione per calcolare la tariffa giornaliera data una tariffa oraria:

```elixir
FreelancerRates.daily_rate(60)
# => 480.0
```

La tariffa giornaliera restituita deve essere un numero in virgola mobile.

## 2. Calcola un prezzo scontato

Implementa una funzione per calcolare il prezzo dopo uno sconto.

```elixir
FreelancerRates.apply_discount(150, 10)
# => 135.0
```

Il valore restituito deve essere sempre un numero in virgola mobile, senza alcun arrotondamento.

## 3. Calcola la tariffa mensile, data una tariffa oraria e uno sconto

Implementa una funzione per calcolare la tariffa mensile e applicare uno sconto:

```elixir
FreelancerRates.monthly_rate(77, 10.5)
# => 12130
```

La tariffa mensile restituita deve essere arrotondata per eccesso (prendi il ceiling) all'intero più vicino.

## 4. Calcola il numero di giornate lavorative dati un budget, una tariffa oraria e uno sconto

Implementa una funzione che prende in ingresso un budget, una tariffa oraria e uno sconto, e calcola a quante giornate di lavoro corrispondono.

```elixir
FreelancerRates.days_in_budget(20000, 80, 11.0)
# => 35.1
```

Il numero di giornate restituito deve essere arrotondato per difetto (prendi il floor) a una cifra decimale.
