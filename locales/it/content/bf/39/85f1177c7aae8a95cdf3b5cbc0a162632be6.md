# CLI

## Configurazione

Il modo più semplice per installare Purescript è tramite Node.js e NPM.

Se non hai già Node.js installato sul computer, puoi scaricarlo dal [sito di Node.js][nodejs-website]. Quando Node.js è pronto all'uso, digita questo comando nel terminale per installare il compilatore PureScript e Spago, il gestore di pacchetti e strumento di build.

```shell
npm install -g purescript spago
```

Trovi maggiori informazioni nel [repository di PureScript][purescript-repository].

## Requisiti

Installa le dipendenze dell'esercizio:

```shell
spago install
spago build
```

## Come far passare la suite di test

Esegui i test con:

```shell
spago test
```

Nelle suite di test, tutti i test tranne il primo sono disattivati. Così puoi risolvere l'esercizio un passo alla volta.

Quando un test passa, puoi attivare il successivo sostituendo `xit` con `it`.

## Inviare la soluzione

Quando nessun test è più disattivato e passano tutti, puoi inviare la soluzione con:

```shell
exercism submit src/<NAME>.purs
```

## Scrivere test personalizzati

Se vuoi scrivere test aggiuntivi e personalizzati, crea un nuovo file `test/Custom.purs` e invialo insieme alla soluzione:

```shell
exercism submit src/<NAME>.purs test/Custom.purs
```
