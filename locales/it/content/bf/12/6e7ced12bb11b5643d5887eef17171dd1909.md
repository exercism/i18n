# Istruzioni

Come aspirante maga, Elyse deve esercitarsi sulle basi. Ha un mazzo di carte che vuole manipolare.

Per rendere le cose un po' più semplici, usa solo le carte dall'1 al 10.

Il mazzo di carte è rappresentato da una `queue`, con il fondo del mazzo all'inizio della coda e la cima del mazzo alla fine.

## 1. Inserisci una carta in cima al mazzo

Implementa la funzione `insert_top` che restituisce una copia del mazzo con la nuova carta fornita aggiunta in cima.

```gleam
insert_top(queue.from_list([5, 9, 7, 1]), 8)
// -> queue.from_list([5, 9, 7, 1, 8])
```

## 2. Rimuovi la carta in cima al mazzo

Implementa la funzione `remove_top_card` che restituisce una copia del mazzo a cui è stata rimossa la carta in cima. Se il mazzo dato è vuoto, va restituito il mazzo originale, invariato.

```gleam
remove_top_card(queue.from_list([3, 2, 6, 4, 8]))
// -> queue.from_list([3, 2, 6, 4])
```

## 3. Inserisci una carta in fondo al mazzo

Implementa la funzione `insert_bottom` che restituisce una copia del mazzo con la nuova carta fornita aggiunta in fondo.

```gleam
insert_bottom(queue.from_list([5, 9, 7, 1]), 8)
// -> queue.from_list([8, 5, 9, 7, 1])
```

## 4. Rimuovi una carta dal fondo del mazzo

Implementa la funzione `remove_bottom_card` che restituisce una copia del mazzo a cui è stata rimossa la carta in fondo. Se il mazzo dato è vuoto, va restituito il mazzo originale, invariato.

```gleam
remove_bottom_card(queue.from_list([8, 5, 9, 7, 1]))
// -> queue.from_list([5, 9, 7, 1])
```

## 5. Controlla la dimensione del mazzo

Implementa la funzione `check_size_of_stack` che controlla se la dimensione del mazzo è uguale a un dato `stack_size` oppure no.

```gleam
check_size_of_stack(queue.from_list([3, 2, 6, 4, 8]), 4)
// -> False
```
