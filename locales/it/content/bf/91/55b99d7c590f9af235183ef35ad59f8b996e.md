# Eseguire i test

Gli esercizi scaricati con il [client da riga di comando di Exercism](https://exercism.io/cli) arrivano con almeno tre file: un file `readme.md`, un file `.dpr` e un file `.pas`. Il file `.dpr` è il file di progetto Delphi, mentre il file `.pas` contiene il codice che esegue i test. Carica il progetto Delphi facendo doppio clic sul file `.dpr` oppure aprendo il progetto direttamente da Delphi. Dovrai creare un nuovo file `.pas` che conterrà il codice della soluzione su cui verranno eseguiti i test. Fai riferimento al file `readme.md` per le istruzioni su come compilare ed eseguire il codice.

Tutti i test sono stati ignorati tranne il primo, su cui puoi iniziare a lavorare. Per continuare, trasforma in commento l'attributo `[Ignore]` del test e potrai iniziare a lavorarci.

Assicurati che [DUnitX](https://github.com/VSoftTechnologies/DUnitX) sia installato, se non lo hai già installato con la configurazione descritta sopra.
