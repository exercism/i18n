# Informazioni

Per impostazione predefinita, le variabili sono limitate allo scope in cui sono definite. Se sono definite in un file, al di fuori di una funzione o di una classe, sono limitate allo scope del file. Se sono definite in una funzione o in una classe, sono limitate allo scope della funzione o della classe.

```php
<?php

$file_scoped = "I am file scoped";

function example(): void
{
  $function_scoped = "I am function scoped!";
}
```

## Scope globale

Usare la parola chiave `global` prima dell'assegnazione di una variabile crea una variabile con scope globale. Questo schema è spesso sconsigliato, perché crea [codice strettamente accoppiato](<https://en.wikipedia.org/wiki/Coupling_(computer_programming)#Disadvantages_of_tight_coupling>).

```php
function example(): void
{
  global $hello = "World!";
}

echo $hello; // #=> "World!"
```

## Scope statico

Usare la parola chiave `static` prima dell'assegnazione o della dichiarazione di una variabile ne preserva lo scope, ma il suo valore viene conservato tra i vari scope di esecuzione.

```php
function counter(): int
{
  static $count = 0;
  $count += 1;
  return $count;
}
```

In questo esempio, la variabile `$count` viene inizializzata a 0 _solo alla prima chiamata della funzione_. A ogni chiamata successiva, il valore viene trasferito alla chiamata seguente. Quindi ogni invocazione della funzione restituisce come risposta un intero sempre più grande.
