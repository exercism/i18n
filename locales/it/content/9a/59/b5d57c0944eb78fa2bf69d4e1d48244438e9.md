# Istruzioni

Sei un appassionato di birdwatching che tiene traccia di quanti uccelli hanno visitato il tuo giardino negli ultimi sette giorni.

Hai sei attività, tutte riguardanti il numero di uccelli che hanno visitato il tuo giardino.

## 1. Controlla quali erano i conteggi della settimana scorsa

Per motivi di confronto, tieni sempre a portata di mano una copia dei conteggi della settimana scorsa, che erano: 0, 2, 5, 3, 7, 8 e 4. Definisci il binding `lastWeek` che contiene i conteggi della settimana scorsa:

```fsharp
lastWeek
// => [| 0; 2; 5; 3; 7; 8; 4 |]
```

## 2. Controlla quanti uccelli hanno visitato ieri

Implementa la funzione `yesterday` per restituire quanti uccelli hanno visitato il tuo giardino ieri. I conteggi degli uccelli sono ordinati per giorno: il primo elemento è il conteggio del giorno più vecchio, e l'ultimo è il conteggio di oggi.

```fsharp
yesterday [| 3; 5; 0; 7; 4; 1 |]
// => 4
```

## 3. Calcola il numero totale di uccelli che hanno visitato

Implementa la funzione `total` per restituire il numero totale di uccelli che hanno visitato il tuo giardino:

```fsharp
total [| 3; 5; 0; 7; 4; 1 |]
// => 20
```

## 4. Controlla se c'è stato un giorno senza uccelli in visita

Implementa la funzione `dayWithoutBirds` che restituisce `true` se c'è stato un giorno in cui zero uccelli hanno visitato il giardino; altrimenti, restituisce `false`:

```fsharp
dayWithoutBirds [| 3; 5; 0; 7; 4; 1 |]
// => true
```

## 5. Incrementa il conteggio di oggi

Implementa la funzione `incrementTodaysCount` per incrementare il conteggio di oggi e restituire i conteggi aggiornati:

```fsharp
let birdCount = [| 3; 5; 0; 7; 4; 1 |]
incrementTodaysCount birdCount
// => [| 3; 5; 0; 7; 4; 2 |]
```

## 6. Controlla se la settimana è insolita

Nel corso dell'ultimo anno, hai scoperto che alcune settimane hanno gli stessi schemi insoliti:
- In ogni giorno pari della settimana, non c'erano uccelli
- In ogni giorno pari della settimana, sono stati avvistati esattamente 10 uccelli
- In ogni giorno dispari della settimana, sono stati avvistati esattamente 5 uccelli

Implementa la funzione `unusualWeek` che restituisce `true` se lo schema del conteggio degli uccelli di questa settimana corrisponde a uno degli schemi insoliti:

```fsharp
unusualWeek [| 1; 0; 5; 0; 12; 0; 2 |]
// => true

unusualWeek [| 5; 0; 5; 12; 5; 3; 5|]
// => true
```

(Nota che la parità del giorno è indicizzata a 1, non a 0: il primo elemento dell'array corrisponde a un giorno dispari)
