# Appendice alle istruzioni

## Suggerimenti

Questo esercizio lavora con dati testuali. Per ragioni storiche, in Haskell il tipo `String` è sinonimo di `[Char]`, una lista di caratteri. Per gestire i dati testuali in modo più efficiente, si può usare il tipo `Text`.

Come estensione facoltativa di questo esercizio, puoi

- Leggere qualcosa sui [tipi di stringa](https://haskell-lang.org/tutorial/string-types) in Haskell.
- Aggiungere `- text` all'elenco delle dipendenze in package.yaml.
- Importare `Data.Text` [nel modo seguente](https://hackernoon.com/4-steps-to-a-better-imports-list-in-haskell-43a3d868273c):

        import qualified Data.Text as T
        import           Data.Text (Text)

- Ora puoi scrivere per esempio `abbreviate :: Text -> Text` e riferirti ai combinatori di `Data.Text` come per esempio `T.filter`.
- Consultare la documentazione di [`Data.Text`](https://hackage.haskell.org/package/text/docs/Data-Text.html).

Questa parte è del tutto facoltativa.
