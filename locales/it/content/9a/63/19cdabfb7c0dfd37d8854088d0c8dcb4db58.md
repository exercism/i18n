# Informazioni

Un parametro di un metodo può essere reso opzionale assegnandogli un valore predefinito. Quando un parametro è opzionale, chi chiama il metodo non è tenuto a fornire un argomento per quel parametro; in tal caso verrà usato il valore predefinito. I [parametri opzionali][optional-arguments] _devono_ trovarsi alla fine dell'elenco dei parametri: non possono essere seguiti da parametri non opzionali. Se un metodo ha più parametri opzionali, puoi specificarne solo alcuni usando gli [argomenti denominati][named-arguments].

```csharp
class Card
{
    static string NewYear(int year = 2020, string sender = "me")
    {
        return $"Happy {year} from {sender}!";
    }
}

Card.NewYear();     // => "Happy 2020 from me!"
Card.NewYear(1999); // => "Happy 1999 from me!"
Card.NewYear(sender: "mom"); // => "Happy 2020 from mom!"
```

Il valore di un parametro opzionale deve essere uno dei seguenti:

- Un'espressione costante (ad esempio `"hi"`, `2`, `DayOfWeek.Friday`, `null`, ecc.)
- Un'espressione `new` di un tipo valore
- Un'espressione `default` di un tipo valore

[named-arguments]: https://docs.microsoft.com/en-us/dotnet/csharp/programming-guide/classes-and-structs/named-and-optional-arguments#named-arguments
