# Appendice alle istruzioni

## Memoria riservata

Il buffer per la stringa di input usa i byte 64-191 della memoria lineare.


## Formato dell'output

La serie di numeri è prevista come un unico array continuo di numeri u8; in fase di deserializzazione verrà suddiviso in base alla lunghezza:

```js
slice("123456", 3) => UInt8Array[1, 2, 3,   2, 3, 4,   3, 4, 5,   4, 5, 6]
// will be split into          [[1, 2, 3], [2, 3, 4], [3, 4, 5], [4, 5, 6]]
```
