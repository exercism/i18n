# Informazioni

## Cicli for

Un'istruzione `for` ripete un blocco di codice.
La sua prima riga controlla quante volte il blocco viene ripetuto:

```go
for init; condition; post {
    // loop body
}
```

- L'istruzione **init** viene eseguita una sola volta, prima della prima iterazione. Di solito qui si dichiara e si inizializza una variabile contatore usata dal ciclo.
- La **condition** è un'espressione booleana valutata prima di ogni iterazione. Il ciclo si ferma quando questa assume il valore `false`.
- L'istruzione **post** viene eseguita dopo ogni iterazione completata. Può essere usata per aggiornare un contatore.

Non racchiudere `init; condition; post` tra parentesi.
Le parentesi graffe (`{ }`) che racchiudono il corpo del ciclo, invece, sono sempre obbligatorie.

Questo ciclo fa partire `i` da `1`, stampa il valore corrente di `i`, lo incrementa per l'iterazione successiva e si ferma quando `i` raggiunge `10`:

```go
for i := 1; i < 10; i++ {
    fmt.Println(i)
}
```

## Altre forme di ciclo

### Ciclo con sola condizione

Le istruzioni init e post possono essere omesse.
Un'istruzione `for` con sola condizione svolge lo stesso compito di un ciclo `while` in altri linguaggi.
Go non ha una parola chiave `while`.

```go
sum := 1
for sum < 1000 {
    sum += sum
}
fmt.Println(sum)
// Output: 1024
```

### Ciclo infinito

Un'istruzione `for` può essere scritta senza condizione:

```go
for {
    // loop body
}
```

Questo ciclo non termina da solo.
L'esecuzione deve uscire dal ciclo in modo esplicito, per esempio con `break` o `return`.

## Controllo dei cicli

### Break e continue

In questo ciclo, `break` esce dal ciclo:

```go
for n := 0; n <= 5; n++ {
    if n == 3 {
        break
    }
    fmt.Println(n)
}
// Output:
// 0
// 1
// 2
```

`continue` salta il resto del corpo del ciclo corrente e inizia l'iterazione successiva:

```go
for n := 0; n <= 5; n++ {
    if n % 2 == 0 {
        continue
    }
    fmt.Println(n)
}
// Output:
// 1
// 3
// 5
```

### Break e continue con etichetta

Con i cicli annidati, un `break` o un `continue` senza etichetta si applica al ciclo più interno.
Per etichettare un ciclo esterno, metti un identificatore seguito da due punti sulla riga immediatamente sopra il ciclo.
Poi scrivi l'etichetta del ciclo dopo `break` o `continue` per indicare che l'azione si riferisce a quel ciclo:

```go
OuterLoop:
for i := 0; i < 10; i++ {
    for j := 0; j < 10; j++ {
        if i + j == 10 {
            break OuterLoop
        }
    }
}
```
