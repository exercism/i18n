# Istruzioni

Una scuola locale vicino a te ha un'associazione studentesca molto attiva.
L'associazione studentesca è gestita da un presidente e ogni 2 anni si tengono le elezioni per eleggere un nuovo presidente.

Per le elezioni di quest'anno è stato deciso che serviva un nuovo sistema digitale per contare i voti. La scuola ha bisogno del tuo aiuto per costruire questo nuovo sistema.

## 1. Ottenere il numero di voti da un `ElectionResult`

Il nuovo sistema avrà bisogno di un modo per ottenere il numero di voti da un contatore.

La struct del risultato elettorale è già stata creata per te ed è definita così:

```cpp
struct ElectionResult {
    // Name of the candidate
    std::string name{};
    // Number of votes the candidate has
    int votes{};
};
```

Dato che tutti i membri della `struct` sono pubblici, non devi scrivere un `constructor` per inizializzare un oggetto `ElectionResult`.
Puoi invece usare un `initializer list`:

```cpp
ElectionResult hamilton{"Alex", 1804};
// => the hamilton object was initialized with the name "Alex" and 1804 votes.
```

Crea una funzione `vote_count` che prende come argomento un riferimento a un `ElectionResult` e restituisce il numero di voti contenuti nell'`ElectionResult`.

```cpp
vote_count(hamilton);
// => 1804
```

## 2. Incrementare i voti di un `ElectionResult`

È finalmente il momento di elaborare i voti!
Ora ti serve un modo per incrementare i voti in un `ElectionResult`.

Crea una funzione `void` `increment_vote_count` che prende come argomenti un riferimento a un `ElectionResult` e un numero di voti, e incrementa l'`ElectionResult` di quel numero di voti.

```cpp
ElectionResult burr{"Aaron " 1801};

increment_vote_count(burr, 3);

vote_count(burr);
// => 1804
```

## 3. Conteggio dei voti e presidenza

La scuola ha consegnato i voti ed è ora di controllare i risultati per scoprire il vincitore.

Crea una funzione `determine_result` che riceve un riferimento a un conteggio finale e restituisce un riferimento all'`ElectionResult` del nuovo presidente.
Dovrebbe anche cambiare il nome del vincitore anteponendogli «President».
Il conteggio finale è fornito sotto forma di un `reference` a `std::vector<ElectionResult>`, un vettore con gli `ElectionResults` di tutti i candidati partecipanti.

```cpp
ElectionResult sanchez{"Pedro", 471};
ElectionResult wheatley{"Summer", 340};
std::vector<ElectionResult> final_count{sanchez, wheatley};

ElectionResult& winner = determine_result(final_count);

winner.name;
// => "President Pedro"
```

Per semplificare, puoi dare per scontate le seguenti cose:
- Il `vector` ha almeno un elemento.
- Non ci saranno pareggi per il primo posto.
