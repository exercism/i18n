# Introduzione

Il tipo `Option` è il meccanismo del linguaggio F# per gestire valori che possono esistere o meno.
Fornisce un'alternativa sicura rispetto ai tipi all'uso di `null`, comune in altri linguaggi per gestire tali valori.
È usato in molte funzioni della libreria standard di F#, quindi capirlo è essenziale per usare efficacemente la libreria standard di F#.

## Utilizzo

Il tipo `Option` è un tipo generico (che ha un tipo sottostante).  
I valori di `Option` sono `Some value`, che rappresenta un valore specifico, oppure `None`, che rappresenta l'assenza di valore.

La funzione seguente mostra come creare un valore `Option`:

```fsharp
let keepIfPositive (a: int) : int option = if a > 0 then Some a else None
```

~~~~exercism/note
`T option` è la sintassi postfissa equivalente a `Option<T>`; le due forme sintattiche possono essere usate in modo intercambiabile.
Tuttavia, secondo la Guida di stile di F#, la notazione postfissa è preferita per i tipi Option (vedi [sezione della Guida di stile di F# su formattazione dei tipi e annotazioni di tipo](https://learn.microsoft.com/en-us/dotnet/fsharp/style-guide/formatting#for-types-prefer-prefix-syntax-for-generics-foot-with-some-specific-exceptions)). 
~~~~

## Leggere il contenuto di un valore Option

Il modo idiomatico per leggere un valore `Option` è tramite pattern matching, come mostrato nell'esempio seguente:

```fsharp
// Returns "Hello, <name>!" if the name is provided; otherwise returns "Hello, you!"
let sayHello (optionalName: string option): string = 
    match optionalName with
    | Some name -> "Hello, " + name + "!"
    | None -> "Hello, you!"

sayHello (Some "Matthieu")
// --> "Hello, Matthieu!"

sayHello None
// --> "Hello, you!"
```

## Estrarre il valore dalle Option con valori predefiniti

I valori `Option` possono essere «estratti» (convertiti nel tipo che contengono) fornendo valori predefiniti con la funzione `Option.defaultValue`.
Questo è particolarmente utile quando vuoi assicurarti che il valore non sia `None`.
Per esempio:

```fsharp
Option.defaultValue "" (Some "F#")
// --> "F#"

Option.defaultValue 0 None
// --> 0
```
