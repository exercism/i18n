# Suggerimenti

## Generali

- [Il tutorial di Python][the python tutorial] può essere un'ottima introduzione.
- [PEP 8][pep8] è la guida di stile per il codice Python.
- [PEP 257][PEP257] descrive in dettaglio le convenzioni per le docstring di Python.
- [I numeri][numbers] in Python possono essere interi, numeri in virgola mobile o complessi.


## 1. Definire il tempo di cottura previsto in minuti

- Devi [dare un nome][naming] a una [costante][constants] e [assegnarle][assignment] un valore [intero][numbers].
  Questa costante dovrebbe essere la prima cosa dopo la docstring, che si trova all'inizio del file.
  Ricorda di rimuovere il commento #TODO dopo aver definito la costante.

## 2. Calcolare il tempo di cottura rimanente in minuti

- Devi definire una [funzione][defining functions] con un solo parametro che rappresenta il tempo trascorso finora.
- Usa l'[operatore matematico per la sottrazione][numbers] per sottrarre i valori.
- Questa funzione dovrebbe [restituire un valore][return].

## 3. Calcolare il tempo di preparazione in minuti

- Devi definire una [funzione][defining functions] con un solo parametro che rappresenta il numero di strati.
- Usa l'[operatore matematico per la moltiplicazione][numbers] per moltiplicare i valori.
- Puoi definire una _costante_ PREPARATION_TIME per il tempo in minuti per strato, invece di usare un [«numero magico»][magic-numbers] nel codice.
- Questa funzione dovrebbe [restituire un valore][return].

## 4. Calcolare il tempo di cottura totale trascorso (preparazione + cottura) in minuti

- Devi definire una [funzione][defining functions] con due parametri.
- Ricorda: puoi sempre _chiamare_ una funzione che hai definito in precedenza.
- Puoi usare l'[operatore matematico per l'addizione][python as a calculator] per sommare i valori.
- Questa funzione dovrebbe [restituire un valore][return].

## 5. Aggiornare la ricetta con delle note

- [Commentare][comments] e [documentare][docstrings] chiaramente il codice secondo [PEP257][pep257] è sempre consigliato.
- Alcuni esempi di docstring in stile Google si trovano nella documentazione di Sphinx per il [modulo napoleon][napoleon].
