# Istruzioni

In questo esercizio implementerai un modo per tenere traccia dei punteggi più alti del gioco più popolare della tua sala giochi locale.

Devi implementare 6 funzioni, per lo più legate alla manipolazione di un oggetto che contiene i punteggi più alti.

## 1. Crea una nuova classifica dei punteggi più alti

Scrivi una funzione `create_score_board` che crea un oggetto che funge da classifica dei punteggi più alti.
Le chiavi di questo oggetto saranno i nomi dei giocatori, i valori saranno i loro punteggi.
Per i test, vuoi includere direttamente una voce nell'oggetto.
Questa voce iniziale deve consistere di `"The Best Ever"` come nome del giocatore e `1000000` come punteggio.

```jq
create_score_board
# returns an object with one initial entry
```

## 2. Aggiungi giocatori a una classifica

Per aggiungere un giocatore alla classifica dei punteggi più alti, implementa la funzione `add_player`.
Prende in input una classifica e richiede due parametri: il nome del giocatore e il suo punteggio.
La funzione dà in output l'oggetto classifica con il nuovo giocatore aggiunto.

```jq
{"José Valim", 486373}
| add_player("Dave Thomas"; 0)
# => {"Dave Thomas": 0, "José Valim": 486373} -- in some order
```

Se il giocatore è già presente nella classifica, dai in output la classifica invariata.

## 3. Rimuovi giocatori da una classifica

Se i giocatori violano le regole della sala giochi, vengono rimossi manualmente dalla classifica dei punteggi più alti.
Implementa `remove_player`, che prende in input una classifica e un parametro: il nome del giocatore da rimuovere.
Questa funzione deve rimuovere la voce del giocatore indicato dalla classifica e dare in output la nuova classifica.
Se il giocatore non era presente nella classifica, non deve succedere nulla alla classifica: deve essere restituita così com'è.

```q
{"Dave Thomas": 0} | remove_player("Dave Thomas")
# => {}

{"Dave Thomas": 0} | remove_player("Rose Fanaras")
# => {"Dave Thomas": 0}
```

## 4. Aumenta il punteggio di un giocatore

Se un giocatore termina un'altra partita alla sala giochi, una certa quantità di punti verrà aggiunta al punteggio precedente nella classifica.
Implementa `update_score`, che prende in input una classifica e richiede due parametri: il nome del giocatore e la quantità di punteggio da aggiungere.
La funzione deve restituire la classifica dopo l'aggiornamento.

```jq
{"Freyja Ćirić": 12771000} | update_score("Freyja Ćirić"; 73)
# => {"Freyja Ćirić": 12771073}
```

Questa funzione deve aggiungere il giocatore alla classifica se non era già presente.

## 5. Applica i punti bonus del lunedì

La sala giochi tiene una classifica separata il lunedì.
Alla fine della giornata, ogni giocatore su quella classifica riceve 100 punti aggiuntivi.

Implementa la funzione `apply_monday_bonus`.
La funzione aggiunge i punti bonus a ogni giocatore elencato in quella classifica.

```jq
{
  "Dave Thomas": 44,
  "Freyja Ćirić": 539,
  "José Valim": 265
}
| apply_monday_bonus
# => {"Dave Thomas": 144, "Freyja Ćirić": 639, "José Valim": 365}
```

## 6. Trova il punteggio totale

Sala giochi diverse competono tra loro per determinare chi ha i giocatori migliori.
La sala giochi con il punteggio totale più alto vince l'onore.

Scrivi una funzione `total_score`.
Prende in input una classifica e dà in output la somma dei punteggi di tutti i giocatori.

```jq
{
  "Dave Thomas": 44,
  "Freyja Ćirić": 539,
  "José Valim": 265
}
| total_score
# => 848
```
