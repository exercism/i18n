# Informazioni

Per eseguire ripetutamente la stessa logica si possono usare i cicli. Se il codice di un ciclo deve essere eseguito almeno una volta, si può usare un ciclo `do`/`while`:

```csharp
int x = 0;

do
{
    x = GetX();
    // do something with x
}
while (x != 0);
```

Questo tipo di ciclo si usa meno spesso di un ciclo `while`, ma in alcuni casi il codice che ne risulta è più naturale da leggere.
