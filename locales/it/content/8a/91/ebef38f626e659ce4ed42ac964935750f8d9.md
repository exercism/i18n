# Introduzione

Questo esercizio si basa sull'aritmetica con i numeri interi di
[Le lasagne deliziose di Leah][lasagna]. Qui lavorerai con i numeri in
virgola mobile e sceglierai la parola giusta per la divisione.

## Numeri interi e numeri in virgola mobile

Factor distingue i numeri interi (`1`, `42`, `1_000_000`) dai numeri in
virgola mobile (`1.0`, `3.14`, `6.02e23`). Se mescoli un numero intero e
un numero in virgola mobile in un unico calcolo, il risultato sarà un
numero in virgola mobile:

```factor
2 3 + .      ! => 5
2 3.0 + .    ! => 5.0
```

Puoi inserire degli underscore all'interno di un numero per raggruppare
le cifre, come in `1_000_000`, e Factor li ignora semplicemente.

## Le parole per la divisione

Factor ha parole separate per la divisione. Vivono tutte nel vocabolario
[`math`][math].

```
/    ( x y -- x/y )    ! exact: ratio for two integers, float if either is a float
/f   ( x y -- f   )    ! always a float
/i   ( x y -- q   )    ! integer division (truncates toward zero)
mod  ( x y -- r   )    ! remainder
/mod ( x y -- q r )    ! quotient and remainder together
```

```factor
1 2 / .        ! => 1/2     (a proper ratio)
16 3 / .       ! => 5+1/3   (an improper ratio, printed as a mixed numeral)
16 3 /f .      ! => 5.333333333333333
16 3 /i .      ! => 5      (truncated)
16 3 mod .     ! => 1
16 3 /mod .s   ! quotient and remainder in one pass
! => 5
! => 1
16.0 3 / .     ! => 5.333333333333333
```

`/` produce un `ratio` (il tipo razionale esatto di Factor) per due
numeri interi, oppure un `float` se almeno uno degli input è un numero in
virgola mobile. `/f` forza un risultato in virgola mobile anche per due
numeri interi. `/i` tronca sempre verso zero.

## Verifiche

Predicati sui numeri da [`math`][math], [`math.functions`][math.functions]
e [`math.primes`][math.primes]:

```
zero?    ( x       -- ? )
even?    ( x       -- ? )
odd?     ( x       -- ? )
prime?   ( x       -- ? )
divisor? ( m n     -- ? )    ! true when n divides m
integer? ( x       -- ? )    ! true for ints (fixnum or bignum)
float?   ( x       -- ? )    ! true for floats
number?  ( x       -- ? )    ! true for any numeric kind
```

```factor
0 zero? .            ! => t
0.0 zero? .          ! => t
3 zero? .            ! => f

4 even? .            ! => t
7 even? .            ! => f
7 odd? .             ! => t

7 prime? .           ! => t
9 prime? .           ! => f

15 5 divisor? .      ! => t   (5 divides 15)
15 4 divisor? .      ! => f
```

## Da numero in virgola mobile a numero intero

`floor`, `ceiling` e `round` del vocabolario
[`math.functions`][math.functions] restituiscono tutti un numero in
virgola mobile (`3.0`, non `3`). Per ottenere un vero numero intero,
concatena `>integer`:

```factor
3.7 floor >integer .       ! => 3
3.2 ceiling >integer .     ! => 4
```

## Potenze e valore assoluto

`sq`, `^` e `abs` (in [`math.functions`][math.functions]) calcolano
quadrati, potenze arbitrarie e valori assoluti:

```
sq  ( x   -- x*x )
^   ( x y -- x^y )
abs ( x   -- |x| )
```

```factor
5 sq .          ! => 25
2 10 ^ .        ! => 1024
2 0.5 ^ .       ! => 1.4142135623730951
-7 abs .        ! => 7
3 abs .         ! => 3
```

## Minimo e massimo

`min ( x y -- z )` e `max ( x y -- z )` (in
[`math.order`][math.order]) restituiscono il minore o il maggiore di due
numeri:

```factor
3 7 min .       ! => 3
3 7 max .       ! => 7
```

L'uso più comune è il *clamping*: fissare un valore ad un limite
inferiore con `max` (ad esempio, `0 max` mantiene un valore non negativo)
o ad un limite superiore con `min`.

## Predicati di ordinamento

`math.order` fornisce anche `before?`, `after?`, `before=?`,
`after=?`, predicati di confronto che funzionano su qualsiasi tipo
ordinabile, come numeri, stringhe e caratteri:

```
before?  ( obj1 obj2 -- ? )   ! obj1 <  obj2
before=? ( obj1 obj2 -- ? )   ! obj1 <= obj2
after?   ( obj1 obj2 -- ? )   ! obj1 >  obj2
after=?  ( obj1 obj2 -- ? )   ! obj1 >= obj2
```

Usali al posto di `<`/`<=` quando i valori potrebbero essere stringhe:
gli operatori aritmetici non fanno dispatch sulle stringhe.
