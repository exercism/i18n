# Test

Ogni esercizio contiene un file di test.
Esegui i test con il programma `bats`.

```bash
bats hello_world.bats
```

Se hai bisogno di stampare output di debug mentre esegui i test in locale, vedi [Debug in locale][debugging].

Bisogna installare `bats`.
Consulta la pagina [Test sul track Bash][tests] per le istruzioni su come installare `bats` sul tuo sistema.

[tests]: https://exercism.org/docs/tracks/bash/tests
[debugging]: https://exercism.org/docs/tracks/bash/debugging

## Aiuto per le funzioni assert

I test usano funzioni della libreria [bats-assert][bats-assert].
Lì trovi aiuto per le varie funzioni `assert*`.

[bats-assert]: https://github.com/bats-core/bats-assert

## Test saltati

Risolvere un esercizio significa far passare tutti i suoi test.
Per impostazione predefinita, quando esegui i test ne viene eseguito solo uno, il primo.
È intenzionale: così puoi concentrarti solo sul far passare quel test.
Una volta che passa, puoi abilitare il test successivo trasformando in commento o rimuovendo l'annotazione successiva:

```bash
[[ $BATS_RUN_SKIPPED == true ]] || skip
```

## Eseguire anche i test saltati

Per eseguire tutti i test, compresi quelli con l'annotazione `skip`, puoi usare:

```bash
BATS_RUN_SKIPPED=true bats exercise_name.bats
```

Può essere comodo usare una funzione wrapper per scrivere meno:

```bash
bats() {
    BATS_RUN_SKIPPED=true command bats *.bats
}
```

Poi esegui i test semplicemente con:

```bash
bats
```
