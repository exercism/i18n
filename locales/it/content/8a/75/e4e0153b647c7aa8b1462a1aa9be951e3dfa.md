# Informazioni

I condizionali di Factor prendono tutti delle **quotations** come rami: codice scritto tra parentesi quadre, `[ ... ]`, che viene impilato come valore invece di essere eseguito finché il condizionale non lo seleziona. (Le quotations stesse saranno trattate in modo completo in un esercizio successivo.)

I tre di base sono in `kernel`:

```
if      ( ? then-quot else-quot -- )
when    ( ? quot -- )
unless  ( ? quot -- )
```

Due varianti con asterisco trattano il booleano come un valore di cui vale la pena servirsi quando è truthy: la coppia canonica «value-or-`f`»:

```
if*     ( ? true false -- )    ! truthy: true called WITH value
unless* ( ? false      -- )    ! falsy: false runs and pushes default
```

```factor
: abs   ( x -- y ) dup 0 < [ neg ] [ ] if ;
: shout ( s -- )   dup empty? [ drop ] [ >upper print ] if ;
```

Per più di due rami, `cond` (in `combinators`) percorre un array di coppie `{ predicate body }` ed esegue il corpo del primo predicato che si attiva. Il modello convenzionale usa `dup` in ogni predicato in modo che l'input sopravviva, e il corpo si apre con un `drop` per scartarlo prima di impilare il risultato:

```factor
{
    { [ dup 0 <  ] [ drop "negative" ] }
    { [ dup 0 =  ] [ drop "zero"     ] }
    [ drop "positive" ]
} cond
```

Una voce finale senza predicato è il ramo predefinito.
