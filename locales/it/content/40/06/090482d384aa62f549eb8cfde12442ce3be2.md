# Istruzioni

Il tuo compito è fornire e mantenere parti del sistema informatico di un parco divertimenti.
In particolare, sei responsabile del programma che gestisce i visitatori e i biglietti.

Per prima cosa, creerai un nuovo visitatore nel sistema.
Poi fornirai una funzione per revocare un biglietto.
Nei compiti 3 e 4 lavorerai sul sistema di tracciamento dei biglietti che aiuta a prevenire le contraffazioni.
Infine, aiuterai ad adattare il sistema ai nuovi requisiti legali.

## 1. Crea un nuovo visitatore

Quando i visitatori arrivano al parco divertimenti per la prima volta, devono registrarsi inserendo il proprio nome e la propria età in un terminale e accettando i termini e le condizioni.
Naturalmente, devono anche comprare un biglietto.
Ogni biglietto ha un identificatore come `H32AZ123`.

Scrivi una funzione `createVisitor` che accetta tre argomenti.

- Il nome del visitatore.
- L'età del visitatore.
- L'identificatore del biglietto che il visitatore ha comprato.

La funzione deve restituire un oggetto che contiene queste informazioni.
Le chiavi dell'oggetto devono chiamarsi `name`, `age` e `ticketId`.

```javascript
createVisitor('Verena Nardi', 45, 'H32AZ123');
// => { name: 'Verena Nardi', age: 45, ticketId: 'H32AZ123' }
```

## 2. Revoca il biglietto

Quando le persone lasciano il parco divertimenti, il loro biglietto viene revocato.
Se tornano, devono comprarne uno nuovo.
Per far risparmiare un po' di tempo ai visitatori abituali, devono registrarsi una sola volta e le informazioni sul visitatore vengono conservate per le visite successive.

Ciò significa che quando un visitatore lascia il parco, va invalidato solo il suo biglietto, mentre il resto dell'oggetto visitatore deve rimanere uguale.
Implementa la funzione `revokeTicket` che accetta un oggetto visitatore, imposta l'identificatore del biglietto su `null` e infine restituisce l'oggetto.

```javascript
const visitor = {
  name: 'Verena Nardi',
  age: 45,
  ticketId: 'H32AZ123',
};

revokeTicket(visitor);
// => { name: 'Verena Nardi', age: 45, ticketId: null }
```

## 3. Determina lo stato del biglietto

Per prevenire le contraffazioni, gli identificatori dei biglietti sono univoci.
Una volta stampato un biglietto, il suo identificatore viene aggiunto come chiave in un oggetto nel sistema, in modo da poterlo tracciare.

Prima che il biglietto venga venduto a un visitatore, viene memorizzato con il valore `null` nell'oggetto di tracciamento dei biglietti.
Quando viene venduto a un visitatore, come valore viene assegnato il nome del visitatore.
Quando i dipendenti hanno dubbi sulla validità di un biglietto, devono controllarne lo stato nel sistema.

Implementa una funzione `ticketStatus` che accetta l'oggetto di tracciamento e un identificatore di biglietto come argomenti.
Deve restituire uno dei seguenti risultati.

- `'unknown ticket id'` se l'identificatore non è stato trovato nell'oggetto di tracciamento
- `'not sold'` se il biglietto è stato stampato ma non venduto
- `'sold to {name}'` dove `{name}` è il nome del visitatore se il biglietto è stato venduto

```javascript
const tickets = {
  '0H2AZ123': null,
  '23LA9T41': 'Verena Nardi',
};

ticketStatus(tickets, 'RE90VAW7');
// => 'unknown ticket id'

ticketStatus(tickets, '0H2AZ123');
// => 'not sold'

ticketStatus(tickets, '23LA9T41');
// => 'sold to Verena Nardi'
```

## 4. Migliora la risposta dello stato del biglietto

Dopo un po', ricevi un riscontro dai dipendenti: vogliono che lo stato del biglietto sia più facile da capire a colpo d'occhio.
Vogliono vedere soltanto il nome del visitatore oppure che il biglietto non è valido.

Scrivi una funzione `simpleTicketStatus` che accetta gli stessi argomenti di `ticketStatus` nel compito 3.
Questa funzione restituisce solo uno tra due risultati diversi.

- il nome del visitatore se il biglietto è stato venduto
- `'invalid ticket !!!'` se il biglietto non è ancora stato venduto o l'identificatore non è stato trovato nell'oggetto di tracciamento

```javascript
const tickets = {
  '0H2AZ123': null,
  '23LA9T41': 'Verena Nardi',
};

simpleTicketStatus(tickets, '23LA9T41');
// => 'Verena Nardi'

simpleTicketStatus(tickets, '0H2AZ123');
// => 'invalid ticket !!!'

simpleTicketStatus(tickets, 'RE90VAW7');
// => 'invalid ticket !!!'
```

## 5. Determina la versione dei termini e condizioni

A causa dei nuovi requisiti legali, gli oggetti visitatore appena creati ora contengono anche informazioni dettagliate sulle «Condizioni generali di contratto» (GTC) che l'utente ha accettato.
Qui sotto puoi vedere un esempio del nuovo oggetto visitatore.

Ora i cassieri del parco divertimenti devono controllare se un visitatore deve firmare una nuova versione delle GTC.
Per questo, implementa una funzione `gtcVersion` che accetta un oggetto visitatore come argomento e restituisce la versione delle GTC, se disponibile.
Se le informazioni sulla versione non sono disponibili, non va restituito nulla.

```javascript
const visitorNew = {
  name: 'Verena Nardi',
  age: 45,
  ticketId: 'H32AZ123',
  gtc: {
    signed: true,
    version: '2.1',
  },
};

gtcVersion(visitorNew);
// => '2.1'

const visitorOld = {
  name: 'Verena Nardi',
  age: 45,
  ticketId: 'H32AZ123',
};

gtcVersion(visitorOld);
// => undefined
```
