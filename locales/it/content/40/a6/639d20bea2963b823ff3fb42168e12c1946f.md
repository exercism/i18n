# Appendice alle istruzioni

## Come è strutturato questo esercizio nella traccia Python

I test di questo esercizio si aspettano che tu crei una [`class`][classes] Matrix (_vedi anche [concept:python/classes]()_).
Questo è diverso dall'_usare_ un oggetto Matrix di una libreria di terze parti come [Numpy][numpy-matrix], che non è supportato.
 _Non preoccuparti, non è complicato come pensi!_
 Per altri punti di partenza e dettagli su `classes` e le strutture dati, dai un'occhiata alle risorse qui sotto:


-   [**Un primo sguardo alle classi**](https://docs.python.org/3/tutorial/classes.html#a-first-look-at-classes) dalla documentazione di Python 3. 
-   [**Come definire una classe in Python**](https://realpython.com/python3-object-oriented-programming/#how-to-define-a-class-in-python) dal sito di Real Python.  
-   [**Strutture dati in Python**](https://docs.python.org/3/tutorial/datastructures.html) dalla documentazione di Python 3.
