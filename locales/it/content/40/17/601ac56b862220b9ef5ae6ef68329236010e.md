# Approfondimento

Il tipo `Option` è un enum fornito dalla libreria standard. È utile per esprimere un valore che potrebbe non esistere. Anche se può sembrare simile a `null` o `nil`, è qualcosa di molto diverso e speciale.

`Option<T>` contiene altri tipi e ha due varianti: `Some(T)` e `None`.

Per esempio, `Option<u32>` contiene il tipo `u32`.

## Utilizzo

### Usare il `T` all'interno di `Option<T>`

Ci sono diversi modi idiomatici per usare il valore che potrebbe essere presente in un `Option`:

- `if let Some(t) = optional { ... }`.

    L'idioma `if let` estrae il valore da un `Option<T>` e lo associa alla variabile `t`. In questo modo puoi usarlo direttamente in quello scope di blocco.

- `match optional { Some(t) => {...}, None => {...}}`

    L'operatore `match` ti permette anche di estrarre e gestire i casi `None` in una sola istruzione o espressione. È un'alternativa a una catena di istruzioni if ed else. Usare `match` può aumentare la leggibilità di alcune sezioni di codice.
- `optional.map(|t| ...)`
   `Option::map` aggiorna un Option sul posto, potenzialmente con un nuovo tipo, usando la funzione fornita.

   **Nota**: opera sul valore contenuto, se presente. L'associazione diventa un `Option<U>`, dove la closure fornita è `FnOnce(T) -> U`.
- `optional.unwrap()`.
   Fare l'unwrap di un `Option<T>` estrae `T`, ma va in panic se `T` non è presente. In alcuni casi è la scelta più rapida.

   **Importante**: fare l'unwrap può facilitare lo sviluppo nel breve periodo o nel codice di test, ma introduce la possibilità di panic a runtime. È meglio evitarlo quando possibile.

- `optional.expect("Unexpected None found! Aborting program.)`.
   Il metodo `expect` su `Option<T>` è molto simile a `unwrap()`, ma se il valore è `None` va in panic usando il messaggio fornito.

## Esempi

Quando un valore esiste in un `Option<u32>`:

```rust
let has_something: Option<u32> = Some(100);
assert_eq!(has_something.unwrap(), 100);
```

Quando un valore *non* esiste in un `Option<u32>`:

```rust
let has_nothing: Option<u32> = None;
assert_eq!(has_nothing, None);
```
