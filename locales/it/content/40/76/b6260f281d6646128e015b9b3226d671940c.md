# Test

Prima di provare a eseguire i test, assicurati che la cartella dell'esercizio sia configurata correttamente seguendo i passaggi di installazione, cioè `corepack yarn install` e la configurazione dell'Editor SDK.

Esegui i test con:

```bash
$ corepack yarn test
```

## Test saltati

Nelle suite di test, tutti i test tranne il primo sono saltati.

Una volta che un test passa, puoi abilitare il successivo cambiando `xit` in `it`.
Inoltre, i test possono essere raggruppati usando `xdescribe`.
Abilita il gruppo cambiandolo in `describe`.
Infine, alcuni esercizi possono avere test opzionali `it.skip`.
Rimuovi `.skip` per eseguire il test opzionale.
