# Istruzioni

Due violinisti stanno provando un duetto. Ogni parte è un array che contiene il
numero di note di ogni battuta, e le parti non hanno sempre la stessa lunghezza.

Tutte e quattro le attività vanno nella classe `DUET_PRACTICE`.

## 1. Quante battute suonano insieme?

Suonano insieme finché entrambe le parti hanno ancora una battuta.

```sather
DUET_PRACTICE::bars_together(|4, 4, 8, 8|, |4, 4|)
-- => 2
```

## 2. Quante battute coincidono?

Conta le battute in cui entrambe le parti hanno lo stesso numero di note. Possono
coincidere solo le battute che hanno entrambe.

```sather
DUET_PRACTICE::in_unison(|4, 4, 8|, |4, 2, 8|)
-- => 2
```

## 3. Chi è più impegnato?

Conta le battute in cui la prima parte ha più note della seconda.

```sather
DUET_PRACTICE::louder_bars(|4, 8, 2|, |4, 2, 8|)
-- => 1
```

## 4. Pesa le battute

Le battute più avanti sono più difficili, quindi una battuta conta tanto quanto
la sua posizione: la prima battuta conta una volta, la seconda due volte, la
terza tre volte. Moltiplica le note di ogni battuta per il suo numero e somma
tutto.

```sather
DUET_PRACTICE::weighted_total(|4, 4, 8|)
-- => 36
```

Cioè 1×4 + 2×4 + 3×8. Le battute si numerano a partire da uno, non da zero.
