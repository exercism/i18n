# Informazioni

I tipi che implementano l'interfaccia [`IEnumerable<T>`][IEnumerable] sono detti _enumerable_.
Tutti i tipi di collezione predefiniti implementano questa interfaccia.

Un tipo enumerable può essere iterato con un ciclo `foreach`:

```csharp
var primes = new[] { 2, 3, 5, 7 };
foreach (var prime in primes)
{
    Console.Write(prime);
}
// => 2357
```

Per implementare `IEnumerable<T>`, un tipo deve implementare un solo metodo: `IEnumerator<T> GetEnumerator()`.
Come si è visto, un enumerable delega l'iterazione effettiva su una collezione a un tipo `IEnumerator<T>`.
Questa interfaccia ha una proprietà e tre metodi da implementare:

- `public T Current { get; }`: ottenere l'elemento corrente.
- `public bool MoveNext ();`: passare all'elemento successivo, restituendo `true` se lo spostamento verso l'elemento successivo è riuscito, e `false` in caso contrario (non ci sono altri elementi).
- `public void Reset ();`: riportare l'enumeratore al suo stato iniziale (prima del primo elemento).

[IEnumerable]: https://docs.microsoft.com/en-us/dotnet/api/system.collections.generic.ienumerable-1
