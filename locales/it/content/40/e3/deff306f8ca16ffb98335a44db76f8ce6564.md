# Introduzione

La maggior parte dei dati in Factor si trova nelle *sequenze*. Gli array (`{ … }`), i vettori (`V{ … }`) e le stringhe condividono tutti lo stesso [protocollo][sequence-protocol] di [`sequences`][sequences].

```factor
{ 1 2 3 } length .    ! => 3
{ 1 2 3 } first .     ! => 1
{ 1 2 3 } last .      ! => 3
{ 1 2 3 4 5 } 3 head .! => { 1 2 3 }
```

Le aggregazioni (`sum`, `count`, `any?`, `all?`) e i predicati come `empty?` e `member?` funzionano allo stesso modo su ogni tipo di sequenza. Per costruire nuove sequenze senza mutazione: `prefix`, `suffix`, `append`, `unclip`, `unclip-last`.

`>array`, `>vector`, e `>string` (in [`arrays`][arrays] e nei vocabolari corrispondenti) convertono tra i tipi di sequenza quando da un'operazione generica ti serve ottenere un tipo concreto specifico.

[arrays]: https://docs.factorcode.org/content/vocab-arrays.html

[sequences]: https://docs.factorcode.org/content/vocab-sequences.html
[sequence-protocol]: https://docs.factorcode.org/content/article-sequence-protocol.html
