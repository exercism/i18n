# Installazione

## Quale versione scegliere?

Ti consigliamo di usare una release stabile di PHP con supporto attivo.
Al momento sono **PHP 8.2, 8.3 e 8.4**.
I dettagli sulle release attuali e sulle loro tempistiche si trovano nella [documentazione ufficiale di PHP](https://www.php.net/supported-versions.php).

## Installare PHP

La maggior parte dei gestori di pacchetti per Linux / macOS fornisce pacchetti precompilati.
PHP può essere scaricato e compilato dai sorgenti, disponibili su [php.net/downloads.php](https://php.net/downloads.php) o [windows.php.net/download](https://windows.php.net/download).

~~~~exercism/note
Per completare gli esercizi non serve un web server come nginx o Apache HTTP server.
~~~~

### Linux

Distribuzioni diverse usano metodi diversi.
Dovresti poter eseguire

```shell
yum install php
```

oppure

```shell
apt-get install php
```

a seconda del tuo gestore di pacchetti.

Per ulteriori istruzioni, leggi il manuale PHP su [Installazione su sistemi Unix](https://www.php.net/manual/en/install.unix.php).

### macOS

PHP è spesso incluso in macOS, ma quasi sempre in una versione obsoleta.
Ti consigliamo di installare PHP tramite [Homebrew](https://brew.sh/).
Puoi installare Homebrew seguendo le istruzioni [sulla loro home page](https://brew.sh/#install).

Per verificare l'installazione, prova il comando seguente: al momento in cui scriviamo dovrebbe restituire Homebrew `4.5.x`.

```shell
brew --version 
```

Installa PHP con Homebrew

```shell
brew install php@8.4
```

Questo dovrebbe mostrare la versione di PHP appena installata, almeno la versione `8.2.0`.

```shell
php -v
```

Per ulteriori istruzioni, leggi il manuale su [Installazione su macOS](https://www.php.net/manual/en/install.macosx.php).

### Windows

I binari ufficiali di PHP per Windows si possono scaricare da [windows.php.net/download](https://windows.php.net/download).

Esistono stack precompilati, tra cui [WAMP](https://www.wampserver.com/en/) (Windows, Apache, MySQL, PHP) e [XAMPP](https://www.apachefriends.org/de/index.html).

Per ulteriori istruzioni, leggi il manuale su [Installazione su sistemi Windows](https://www.php.net/manual/en/install.windows.php).

### Docker

Se preferisci le soluzioni basate su container, puoi scaricare l'[immagine ufficiale di PHP da Docker Hub](https://hub.docker.com/_/php).
Ti servirà anche [Docker](https://docs.docker.com/engine/install/).

### Altro

Se vuoi usare un sistema operativo diverso, consulta le istruzioni su [php.net/manual/en/install](https://www.php.net/manual/en/install.php).

## Installare PHPUnit

~~~~exercism/note
PHPUnit 12 non è ancora supportato!
~~~~

### Tramite PHP Archive (PHAR)

Il modo più semplice per usare PHPUnit negli esercizi di Exercism è scaricare una distribuzione pacchettizzata come PHP Archive (PHAR), che è anche il modo consigliato per usare PHPUnit.
Salva il PHAR nella stessa posizione in cui hai salvato la CLI `exercism`, così puoi eseguire PHPUnit da qualsiasi cartella.

Puoi scaricare una release dei pacchetti PHPUnit come archivio PHP:

```shell
wget -O phpunit.phar https://phar.phpunit.de/phpunit-11.phar
```

Rendi eseguibile il file scaricato:

```shell
chmod +x phpunit.phar
```

Spostalo nella stessa posizione in cui hai spostato la CLI `exercism`, dando al comando il nome `phpunit`:

```shell
mv phpunit.phar ~/bin/phpunit
```

Ora puoi eseguire `phpunit` da qualsiasi posizione, come mostrato nella [documentazione sui test del track PHP](https://exercism.org/docs/tracks/php/tests):

```shell
phpunit --version
```

L'output dovrebbe essere simile a questo:

```text
PHPUnit 11.5.45 by Sebastian Bergmann and contributors.
```

Puoi anche seguire le [istruzioni ufficiali per installare PHPUnit](https://docs.phpunit.de/en/11.5/installation.html#installing-phpunit) per installare PHPUnit.

### Tramite Composer

PHPUnit versione 11 può anche essere installato tramite [Composer](https://getcomposer.org).

#### Installare Composer

Installa [Composer](https://getcomposer.org) seguendo le [istruzioni di installazione](https://getcomposer.org/doc/00-intro.md) del sistema operativo del tuo dispositivo. Ti consigliamo di installarlo a livello globale per semplicità.

#### Aggiungere PHPUnit come strumento globale

Usa il comando seguente:

```shell
composer global require phpunit/phpunit ^11.5
```

Assicurati di installare la versione 11.5 o successiva.
