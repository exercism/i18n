# Introduzione

Poiché tutti i tipi di dati standard di Clojure sono immutabili, il linguaggio offre dei *tipi di riferimento* che consentono una mutazione controllata. I più semplici e i più usati di questi sono chiamati Atom.

Gli Atom vengono creati con la funzione `atom`, che accetta un valore iniziale:

```clojure
(def players (atom ()))
```

Il valore corrente dell'Atom viene dereferenziato con `deref` o con la scorciatoia `@`:

```clojure
@players
;;=> ()
```

Il valore corrente dell'Atom `players` può essere modificato usando `swap!`, che aggiorna il valore applicando una funzione:

```clojure
(swap! players conj :player1)
;;=> (:player1)
```

La funzione `reset!` sostituisce il valore di un Atom senza tenere conto del suo valore corrente:

```clojure
(reset! players ())
```
