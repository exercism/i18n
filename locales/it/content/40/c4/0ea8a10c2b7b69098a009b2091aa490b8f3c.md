# Introduzione

Un [operatore di confronto][comparisons] in Python (_chiamato anche operatore relazionale di Python_) osserva i _valori_ di due [operandi][operand] e restituisce un valore booleano `True` o `False` a seconda che la condizione `comparison` sia soddisfatta o meno.

La tabella seguente mostra gli operatori di confronto più comuni in Python:

| Operatore | Operazione                     | Descrizione                                                                                 |
| --------- | ------------------------------ | ------------------------------------------------------------------------------------------- |
| `>`       | «maggiore di»                  | `a > b` è `True` se il valore di `a` è **strettamente** maggiore di quello di `b`           |
| `<`       | «minore di»                    | `a < b` è `True` se il valore di `a` è **strettamente** minore di quello di `b`             |
| `==`      | «uguale a»                     | `a == b` è `True` se il valore di `a` è **strettamente** uguale a quello di `b`             |
| `>=`      | «maggiore o uguale a»          | `a >= b` è `True` se `a > b` OPPURE `a == b` come valore                                    |
| `<=`      | «minore o uguale a»            | `a <= b` è `True` se `a < b` oppure `a == b` come valore                                    |
| `!=`      | «diverso da»                   | `a != b` è `True` se `a == b` è `False`                                                     |
| `is`      | «identità»                     | `a is b` è `True` se **_e soltanto se_** `a` e `b` sono lo stesso _oggetto_                 |
| `is not`  | «identità negata»              | `a is not b` è `True` se **_e soltanto se_** `a` e `b` **non** sono lo stesso _oggetto_     |
| `in`      | «test di appartenenza»         | `a in b` è `True` se `a` è membro, sottoinsieme o elemento di `b`                           |
| `not in`  | «test di appartenenza negato»  | `a not in b` è `True` se `a` non è membro, sottoinsieme o elemento di `b`                   |

Hanno tutti la stessa priorità (_più alta di quella delle [operazioni booleane][boolean operations], ma più bassa di quella delle operazioni aritmetiche o bit a bit_).

## Confronto tra tipi di dati diversi

Gli oggetti di tipo diverso (_tranne i tipi numerici_) non risultano mai uguali per impostazione predefinita.
Anche istanze non identiche di una `class` _**non**_ risultano uguali, a meno che la `class` non definisca metodi speciali che personalizzano il comportamento di confronto predefinito di `object`.

I tipi numerici sono (per la maggior parte) un'eccezione a questa regola di corrispondenza tra tipi.
Un `integer` **può** essere considerato uguale a un `float` (_o un [`octal`][octal] uguale a un [`hexadecimal`][hex]_), purché i tipi possano essere convertiti implicitamente per il confronto.

Per gli altri tipi numerici ([complessi][complex numbers], [decimali][decimal numbers], [frazioni][rational numbers]), gli operatori di confronto sono definiti dove hanno «senso» (_dove la conversione implicita non cambia il risultato_), ma generano un `TypeError` se gli oggetti sottostanti non possono essere convertiti accuratamente per il confronto.

## Confronto dell'identità degli oggetti

Gli operatori `is` e `is not` verificano l'[_identità_][object identity] di un oggetto, in contrapposizione al suo _valore_.
L'identità di un oggetto non cambia mai dopo la creazione e si può ricavare usando la funzione [`id()`][id function].

`<apple> is <orange>` restituisce `True` se _**e soltanto se**_ `id(<apple>)` == `id(<orange>)`.
`<apple> is not <orange>` produce l'inverso.

## Confronti di appartenenza

Gli operatori `in` e `not in` verificano l'_appartenenza_.
`<fish> in <soup>` restituisce `True` se `<fish>` è un membro di `<soup>` (_se `<fish>` è un sottoinsieme di `<soup>` o è contenuto in `<soup>`_), altrimenti restituisce `False`.
`<fish> not in <soup>` restituisce la negazione, ovvero l'_opposto_ di `<fish> in <soup>`.

Per i tipi stringa e bytes, `<name> in <fullname>` è `True` _**se e soltanto se**_ `<name>` è una sottostringa di `<fullname>`.
