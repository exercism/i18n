# Introduzione

In Python, una `str` è una [sequenza immutabile][text sequence] di [punti di codice Unicode][unicode code points].
Questi possono includere lettere, segni diacritici, caratteri di posizionamento, numeri, simboli di valuta, emoji, punteggiatura, spazi e caratteri di fine riga, e altro ancora.

Le stringhe implementano tutte le [operazioni comuni sulle sequenze][common sequence operations] e possono essere iterate usando la sintassi `for item in <string>` o `for index, item in enumerate(<string>)`.

Le stringhe si possono concatenare con `<str> + <other str>` o `<str>.join(<iterable>)` e dividere con `<str>.split(<separator>)`.
Offrono anche diverse altre opzioni di formattazione, composizione e creazione di template.

Essendo immutabile, il valore di un oggetto `str` in memoria non cambia; i metodi che sembrano modificare una stringa restituiscono una nuova copia o una nuova istanza di `str`.

Per un'analisi approfondita di quali informazioni codifica una stringa (o, _«come fa un computer a sapere come tradurre zeri e uno in lettere?»_), [questo post del blog è tuttora di grande aiuto][joel-on-text].
La documentazione di Python fornisce anche un [HOWTO su Unicode][unicode how-to] molto dettagliato che illustra il supporto di Python per la specifica Unicode nei moduli `str`, `bytes` e `re`, alcune considerazioni sulle locale e alcuni problemi comuni di codifica e conversione.
