# Informazioni
I tipi numerici predefiniti in C++ si possono dividere in numeri interi e numeri in virgola mobile.
I numeri interi sono numeri senza parte decimale, come `0`, `691` o `-2`.
I numeri in virgola mobile sono numeri con una parte decimale, come `6.02214076`, `0.1` o `-1.616`.

## Numeri interi
L'esempio seguente mostra la dichiarazione e l'inizializzazione di quattro variabili diverse

```cpp
int m_morales{9241};              // base 10: 0-9
int a_apaec{0x24CD};              // base 16: 0-9 and A-F
int m_gargan{0b10010000011001};   // base  2: 0-1
int b_reilly{022031};             // base  8: 0-7
                                  // Leading with a 0 not the letter o.
```

Quando assegni un valore a una variabile `int`, puoi farlo direttamente con un letterale.
Un letterale è un numero scritto fisso nel codice, come `9241`.
Esistono letterali interi diversi per le varie basi di rappresentazione.
I letterali interi decimali sono i più comuni e usano le cifre da `0` a `9`.
Aggiungendo un prefisso speciale, come `0x`, è possibile usare altre basi.
L'esempio sopra mostra il numero `9421` nelle sue quattro rappresentazioni e prefissi.
Tutte le variabili sono inizializzate allo stesso valore.

Per maggiori dettagli sui diversi sistemi di rappresentazione, dai un'occhiata a [un piccolo tutorial][cpp_numerical_bases].

Puoi usare un apostrofo per separare le cifre e rendere il numero più leggibile.
`9'241` è uguale a `0b0100'100'0001'1001` o a `92'4'1`.

## Numeri in virgola mobile

I letterali in virgola mobile si presentano in due forme.
Oltre alla forma intuitiva `0.0024`, è possibile usare la sua notazione scientifica `2.4e-3`.
Il tipo in virgola mobile più comune è `double`.

## Aritmetica

C++ supporta `+`, `-`, `*`, `/`, `(` e `)` e `%` per formare espressioni.
Il risultato dell'operazione tra due numeri interi è anch'esso un numero intero.
`5 / 2` restituisce `2`.
Quando uno dei tipi coinvolti è un tipo in virgola mobile, anche il risultato sarà in virgola mobile.
`5.0 / 2` e `5 / 2.0` restituiscono `2.5`.
`%` è l'operatore modulo e restituisce il resto di una divisione intera: `5%3` è `2`.

## Operatore di assegnazione

L'operatore di assegnazione assegna a una variabile un letterale.
L'assegnazione avviene sempre da destra verso sinistra, mai al contrario.

```cpp
int length = 5;
int width = 2;
length = width;
```

Qui il valore intero `5` viene assegnato alla variabile `length`.
Poi il valore intero `2` viene assegnato alla variabile `width`.
Infine il valore di `width` viene copiato nella variabile `length` e il valore precedente `5` va perso.
Tieni anche presente che stiamo assegnando il valore di `width` a `length` solo nel momento dell'operazione di assegnazione.
Di conseguenza, se il valore di `width` cambia in un momento successivo, ciò non influenzerà il valore assunto da `length`.

L'operatore di assegnazione può essere combinato con gli altri operatori (aritmetici e bit a bit), noti come operatori di `compound assignment`: `+=`, `-=`, `*=`, `/=`, `%=`.
Questi operatori modificano il valore corrente di una variabile eseguendo su di esso un'operazione.

```cpp
// we start with 0 people
int people{};
// we need 0 eggs
int eggs{};
// two people joined:
people += 2;
// people is now 2
// let's add 3 eggs per person
eggs += 3 * people;
// eggs is now 6
```

Le variabili `people` ed `eggs` sono inizializzate a `0`.
Poi aggiungiamo il valore intero `2` al valore esistente `0` della variabile `people` e lo riassegniamo a `people`.
Ora `people` diventa `2`.
In seguito aggiungiamo `3` uova per ogni persona, che in totale fanno `6` uova.
Ora aggiungiamo questo `6` al valore esistente `0` della variabile `eggs` e lo riassegniamo a `eggs`.
Ora `eggs` sarà `6`.
L'espressione equivalente sarebbe `people = people + 2` ed `eggs = eggs + (3 * people)`.

## Casting

Il casting è la conversione da un tipo a un altro.
Se serve un `double`, al suo posto si può usare un `int`.
L'esempio `5.0 / 2` visto sopra viene gestito con un cast implicito di `2` in `2.0`.
Un `double` convertito in un `int` potrebbe perdere informazioni.
È buona pratica rendere espliciti questi cast verso un altro tipo T tramite `static_cast<T>`.
Il vecchio cast in stile C tramite `(T)` è sconsigliato nel C++ moderno, ma vale comunque la pena conoscerlo.

```cpp
double pi{3.14};
int about_2_times_pi_cpp{static_cast<int>(pi) * 2};
// Old C-style cast:
int about_2_times_pi_c{(int)pi * 2};
```

## Precisione e rappresentazione

I numeri in C++ non possono essere arbitrariamente grandi.
`int`, per esempio, è rappresentato da 32 bit.
Questo basta per un insieme di `2^32` numeri, all'incirca 4 miliardi.
Includendo `0`, questo fissa i valori più grande e più piccolo di `int` a `-2^31` e `2^31 - 1`.

I numeri in virgola mobile sono di solito implementati con una precisione di 15 cifre decimali, ma la loro rappresentazione varia in base al sistema host.
