# Informazioni

Un file è uno stream con un nome su disco. Il vocabolario [`io.files`][io.files] offre due modi per lavorarci: parole di comodo che leggono o scrivono tutto il file con una sola chiamata, e funzioni di apertura degli stream (i combinatori `with-…`) per leggere o scrivere in modo incrementale. Entrambi si basano sullo stesso [protocollo degli stream][stream-protocol] degli stream in memoria del concetto `io-streams`: un `<file-reader>` e uno `<string-reader>` rispondono alle stesse parole.

Ogni parola che opera sui file richiede una **codifica**, lo schema che mappa i byte in caratteri e viceversa. Per il testo si tratta quasi sempre di [`utf8`][utf8] da `io.encodings.utf8`; per lavorare sui dati binari si usa `latin1` o una codifica `<byte-array>`.

## Lettura dell'intero file

```
file-contents   ( path encoding -- str )
file-lines      ( path encoding -- seq )
```

`file-contents` restituisce l'intero file come un'unica stringa. `file-lines` restituisce le sue righe sotto forma di array, con i terminatori di riga rimossi: comodo quando ogni riga è un record.

```factor
USING: io.encodings.utf8 io.files ;

"forecast.txt" utf8 file-contents   ! => "sunny\ncloudy\n"
"forecast.txt" utf8 file-lines      ! => { "sunny" "cloudy" }
```

## Scrittura dell'intero file

```
set-file-contents   ( str path encoding -- )
set-file-lines      ( seq path encoding -- )
```

Entrambe **sostituiscono** il file, creandolo se non esiste.
`set-file-contents` scrive una stringa così com'è; `set-file-lines` scrive ogni
elemento di una sequenza su una riga a sé, aggiungendo i ritorni a capo.

```factor
{ "sunny" "cloudy" } "forecast.txt" utf8 set-file-lines
! forecast.txt now holds "sunny\ncloudy\n"
```

## Stream con scope

Quando vuoi aggiungere qualcosa a un file, o leggere e scrivere pezzo per pezzo, aprilo con un combinatore `with-…` e usa le parole dello stream corrente all'interno della quotation:

```
with-file-reader     ( path encoding quot -- )
with-file-writer     ( path encoding quot -- )
with-file-appender   ( path encoding quot -- )
```

```factor
USING: io io.encodings.utf8 io.files ;

"log.txt" utf8 [ "another line" print ] with-file-appender
```

`with-file-writer` tronca prima il file; `with-file-appender` conserva il contenuto esistente e scrive in coda. Ciascuno è uno scope con distruzione automatica: l'handle del file viene chiuso quando la quotation termina, anche se lancia un'eccezione. È la stessa garanzia offerta dai combinatori di `boatswains-bilge`, qui specializzata ai file.

## Tutto il file o stream con scope?

Ricorri a `file-contents` / `file-lines` / `set-file-contents` / `set-file-lines` quando il file è abbastanza piccolo da stare in memoria e vuoi il tutto in una volta sola. Ricorri alle funzioni di apertura `with-…` quando devi aggiungere in coda, trasmettere un file grande una riga alla volta con `readln`, o alternare letture e scritture: in tutti i casi in cui tenere l'intero file in memoria sarebbe uno spreco o un errore.
