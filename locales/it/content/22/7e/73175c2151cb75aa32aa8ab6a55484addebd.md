# Istruzioni

Implementa la logica del gioco dell'impiccato usando la programmazione funzionale reattiva.

[L'impiccato][hangman] è un semplice gioco in cui si indovinano le parole.

[La programmazione funzionale reattiva][frp] è un modo per scrivere programmi interattivi.
Si differenzia dalla prospettiva usuale: invece di dire «quando si preme il pulsante, incrementa il contatore», scrivi «il valore del contatore è la somma del numero di volte in cui si preme il pulsante».

Implementa la logica di base dell'impiccato usando la programmazione funzionale reattiva.
Per farlo dovrai installare una libreria di programmazione funzionale reattiva: sarà descritto nei file specifici della lingua dell'esercizio.

[hangman]: https://en.wikipedia.org/wiki/Hangman_%28game%29
[frp]: https://en.wikipedia.org/wiki/Functional_reactive_programming
