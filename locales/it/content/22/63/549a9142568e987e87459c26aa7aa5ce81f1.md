# Introduzione

Un `vector` in Clojure è una collezione sequenziale, indicizzata ed immutabile di zero o più valori. Questo significa che, una volta creato, un vector non può più essere modificato. Le funzioni che operano sui vector restituiscono un nuovo vector, mentre quello originale resta invariato. I valori contenuti in un vector possono essere di tipi eterogenei. I vector si possono definire così:

```clojure
(def empty [])
(def single-value [5])
```

Gli elementi di un vector si possono recuperare tramite un indice. I vector di Clojure sono indicizzati a partire da zero, il che significa che l'indice del primo elemento è sempre zero:

```clojure
(def numbers [2 3 5])
;; Read value from vector
(get numbers 2)
;;=> 5
;; Update value in vector
(assoc numbers 2 9)
;;=> [2 3 9]
```

Il vector originale resta invariato:

```clojure
numbers
;;=> [2 3 5]
```

Per tenere traccia del valore aggiornato, dobbiamo passarlo avanti oppure catturarlo in una var:

```clojure
(def updated-numbers
  (assoc numbers 2 9))
(get updated-numbers 2)
;;=> 9
```
