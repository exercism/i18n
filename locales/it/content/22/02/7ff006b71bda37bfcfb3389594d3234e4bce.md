# Informazioni

In Gleam, un array è una collezione immutabile di zero o più valori. I valori in un array devono avere tutti lo stesso tipo. Dato che gli array sono immutabili, una volta che un array è stato costruito il suo valore non può più cambiare. Qualsiasi funzione o operatore che sembri modificare un array, per esempio aggiungendo un elemento, in realtà restituirà un nuovo array.

Gli array si possono definire così:

```gleam
let empty = []
let singleValue = [5]
let threeValues = ["a", "b", "c"]
```

Il modo più comune per aggiungere un elemento a un array è anteporlo usando la sintassi spread:

```gleam
let two_to_four = [2, 3, 4]
let one_to_four = [1, ..two_to_four]
// -> [1, 2, 3, 4]
```

Il modulo [`gleam/list`](https://hexdocs.pm/gleam_stdlib/gleam/list.html) della libreria standard di Gleam contiene molte funzioni utili per lavorare con gli array. Questo modulo è usatissimo nel codice Gleam, quindi è bene conoscerlo.

I pattern degli array si possono usare nelle espressioni case per eseguire il pattern matching su un array e assegnare a delle variabili i valori che contiene:

```gleam
pub fn describe(list: List(String)) -> String {
  case list {
    [] -> "Empty list"
    [x] -> "List with one item: " <> x
    [x, y] -> "List with two items: " <> x <> " and " <> y
    _ -> "List with three or more items"
  }
}
```

Oltre a eseguire il pattern matching su array di lunghezza esatta, la sintassi spread si può usare per farlo su array di almeno una certa lunghezza:

```gleam
pub fn describe(list: List(String)) -> String {
  case list {
    [_, _, ..] -> "List with at least two items"
    [_] -> "List with one item"
    [] -> "Empty list"
  }
}
```

La sintassi spread si può usare anche per assegnare a una variabile il resto dell'array:

```gleam
pub fn remove_first_item(list: List(String)) -> List(String) {
  case list {
    // Return the list without the first item
    [_, ..rest] -> rest

    // There's no first item to remove, return an empty list
    _ -> []
  }
}
```

Le espressioni case dovrebbero avere un pattern per ogni possibile valore del tipo su cui si esegue il pattern matching, quindi spesso si usa un pattern di scarto finale (`_`) per gestire tutti i valori rimanenti.
