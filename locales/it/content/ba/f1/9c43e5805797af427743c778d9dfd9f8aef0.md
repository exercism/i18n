# Istruzioni

Stai chiamando i segnali per lo spettacolo della tua scuola. Il direttore di scena
vuole che le battute standard siano messe per iscritto, così che chiunque possa
gestire la consolle.

Hai quattro attività, tutte nella classe `STAGE_DIRECTIONS`.

## 1. Annuncia l'inizio

Restituisci la battuta che apre lo spettacolo.

```sather
STAGE_DIRECTIONS::opening_line
-- => "The curtain rises."
```

## 2. Annuncia l'intervallo

Restituisci la battuta che si chiama all'intervallo.

```sather
STAGE_DIRECTIONS::interval_line
-- => "Interval. Fifteen minutes."
```

## 3. Annuncia la fine

Restituisci la battuta che chiude lo spettacolo.

```sather
STAGE_DIRECTIONS::closing_line
-- => "The curtain falls."
```

## 4. Chiama il segnale finale

Il segnale finale è la stessa battuta di quella che chiude lo spettacolo. Invece
di scrivere di nuovo il testo, chiama la routine che hai già scritto.

```sather
STAGE_DIRECTIONS::final_cue
-- => "The curtain falls."
```
