# Suggerimenti

## 1. Creare una nuova lista

- Common Lisp ha una [funzione dal nome piuttosto descrittivo][hyper-list] per creare una _LISTA_.

## 2. Aggiungere elementi alla lista.

- Per aggiungere qualcosa all'inizio di una lista, l'idioma è *CONS*truire una nuova lista con l'elemento come `car` e la lista come `cdr`. Nell'Hyperspec si trova una [pagina][hyper-cons] che descrive questa funzione.

## 3. Qual è il prossimo elemento (o gli elementi) della lista?

- Common Lisp ha una funzione generica per ottenere un elemento [da qualsiasi indice di una lista][hyper-nth].
- Ha anche [diversi ausiliari][hyper-first-tenth] per accedere agli indici inferiori a 11.
- Gli indici delle liste partono da zero.

## 4. Rimuovere un elemento dalla lista

- Un modo idiomatico per rimuovere il primo elemento di una lista è usare una funzione che sa separare il `cdr` della lista dal `car` della lista. Nell'Hyperspec si trova una [pagina][hyper-rest] che descrive una delle funzioni che fanno questo.

## 5. Liste più grandi a partire da liste più piccole

- Common Lisp ha una funzione [appositamente pensata per aggiungere una lista davanti a un'altra][hyper-append].

## 6. Quanto è più lunga?

- Common Lisp ha una funzione [dal nome ovvio][hyper-length] per ottenere la lunghezza di una lista.
