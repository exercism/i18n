# Eseguire i test

Per eseguire i test di un esercizio, entra nella cartella con `cd` ed esegui quanto segue:

```bash 
box task run TestRunner
# Or start up a test watcher that will rerun when files change
box task run TestRunner --:watcher
```

I test si basano su una libreria chiamata TestBox, che supporta gli stili di test xUnit e BDD. Tutte le suite di test saranno scritte nello [stile BDD](https://testbox.ortusbooks.com/content/primers/bdd/specs.html), che usa le closure per definire le specifiche dei test. Non devi preoccuparti di installare TestBox: ci penserà il test runner della CLI. Devi solo essere connesso a internet la prima volta che lo esegui. Per saperne di più:

[https://testbox.ortusbooks.com](https://testbox.ortusbooks.com)
