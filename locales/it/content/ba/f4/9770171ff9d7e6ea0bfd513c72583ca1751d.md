# Suggerimenti

## 1. Stampa un badge per un dipendente

- L'[interpolazione di stringhe][string-interpolation] può essere usata per formattare il badge in modo conciso.
- Esiste un [metodo integrato per convertire una stringa in maiuscolo][toupper].

## 2. Stampa un badge per un nuovo dipendente

- Controlla se l'ID è `null` prima di usarlo.
- [Questo tutorial spiega in dettaglio come lavorare con i tipi di valore nullable][nullable-types-tutorial].

## 3. Stampa un badge per il proprietario

- Controlla se il reparto è `null` prima di usarlo.
- [Questo tutorial spiega in dettaglio come lavorare con i tipi di riferimento nullable][nullable-reference-types-tutorial].
- L'[operatore condizionale null][null-conditional-operator] permette di semplificare la chiamata a un membro di un valore nullable.
- L'[operatore di coalescenza null][null-coalescing-operator] permette di restituire più facilmente un valore diverso quando un valore nullable è `null`.
