# Introduzione

## Operatore pipe

L'operatore `|>` è chiamato operatore pipe. Può essere usato per concatenare le chiamate di funzione in modo che il valore restituito dalla chiamata di funzione precedente venga passato alla chiamata successiva.

```gleam
"hello"
|> string.uppercase
|> string.append("?!")
// -> "HELLO?!"
```

Il codice qui sopra equivale al seguente:

```gleam
string.append(string.uppercase("hello"), "?!")
```

L'operatore pipe passerà il valore come primo argomento della chiamata di funzione, oppure come unico argomento di una nuova chiamata, scegliendo quello che avrebbe il tipo corretto.

```gleam
100
|> function_that_takes_two_arguments(1)

// Is equivalent to
function_that_takes_two_arguments(100, 1)
```

```gleam
100
|> function_that_returns_a_function(1)

// Is equivalent to
function_that_returns_a_function(1)(100)
```

A volte vogliamo passare il valore in un'altra posizione; in questo caso si può usare il segnaposto `_` per indicare dove inserire il valore.

```gleam
100
|> some_function(1, _, 2)
```
