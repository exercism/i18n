# Introduzione

## Struct

In C#, gli `struct` sono strettamente legati alle `class`. Hanno stato e comportamento. Hanno costruttori che accettano argomenti. Le istanze possono essere assegnate, confrontate per uguaglianza e memorizzate in collezioni.

```csharp
enum Unit
{
    Kg,
    Lb
}
struct Weight
{
    private double count;
    private Unit unit;

    public Weight(double count, Unit unit)
    {
        this.count = count;
        this.unit = unit;
    }

    public override string ToString()
    {
        return count.ToString() + unit.ToString();
    }
}

new Weight(77.5, Unit.Kg).ToString();
// => "77.6Kg"
```
