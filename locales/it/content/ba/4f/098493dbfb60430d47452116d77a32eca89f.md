# Introduzione

In Python, le istruzioni [`if`][if statement], `elif` (_contrazione di «else and if»_) e `else` servono per [controllare il flusso][control flow tools] di esecuzione e prendere decisioni in un programma.
A differenza di molti altri linguaggi di programmazione, le versioni di Python 3.9 e precedenti non offrono un'istruzione formale di tipo case-switch, ma usano più istruzioni `elif` per ottenere uno scopo simile.

Python 3.10 introduce una variante dell'istruzione case-switch chiamata `pattern matching`, che sarà trattata separatamente in un altro concetto.

Le istruzioni condizionali usano espressioni che devono dare come risultato `True` o `False`: o restituendo direttamente un `bool`, o valutando [«truthy» o «falsy»][truth value testing].


```python
x = 10
y = 5

# The comparison '>' returns the bool 'True',
# so the statement is printed.
if x > y:
    print("x is greater than y")
...
>>> x is greater than y
```

Quando è abbinato a `if`, un blocco di codice `else` opzionale viene eseguito quando la condizione `if` originale assume il valore `False`:

```python
x = 5
y = 10

# The comparison '>' here returns the bool False,
# so the 'else' block is executed instead of the 'if' block.
if x > y:
    print("x is greater than y")
else:
    print("y is greater than x")
...
>>> y is greater than x
```

`elif` permette più valutazioni e più rami.

```python
x = 5
y = 10
z = 20

# The elif statement allows for the checking of more conditions.
if x > y > z:
    print("x is greater than y and z")
elif y > x > z:
    print("y is greater than x and z")
else:
    print("z is greater than x and y")
...
>>> z is greater than x and y
```

Le [operazioni booleane][boolean operations] e i [confronti][comparisons] possono essere combinati con i condizionali per eseguire verifiche più complesse:

```python
>>> def classic_fizzbuzz(number):
...     if number % 3 == 0 and number % 5 == 0:
...         say = 'FizzBuzz!'
...     elif number % 5 == 0:
...         say = 'Buzz!'
...     elif number % 3 == 0:
...         say = 'Fizz!'
...     else:
...         say = str(number)
...     return say

>>> classic_fizzbuzz(15)
'FizzBuzz!'

>>> classic_fizzbuzz(13)
'13'
```
