# Installazione

Exercism ti permette di programmare e testare il codice ABAP direttamente nel tuo browser. Non è necessaria alcuna installazione aggiuntiva. Se però preferisci programmare e testare sul tuo sistema, puoi procurarti un sistema ABAP di prova.

Naturalmente, il tuo datore di lavoro potrebbe già usare SAP. Verifica con il tuo reparto IT se e come puoi ottenere l'accesso a una sandbox di sviluppo ABAP.

## Quale versione scegliere?

Ti consigliamo di usare una release attuale della piattaforma ABAP con supporto attivo. Al momento si tratta di **ABAP 7.5 e versioni successive**. I dettagli sulle release attuali e sulle relative tempistiche sono disponibili su [SAP Developer Center](hhttps://developers.sap.com/tutorials/mission-get-started-with-abap-development-on-premise).

## Cosa installare?

Ti consigliamo di usare la versione più recente di [ABAP Cloud Developer Trial](https://hub.docker.com/r/sapse/abap-cloud-developer-trial). Si basa su ABAP 7.58. Puoi installare il sistema SAP ABAP come immagine Docker oppure ospitato nella SAP Cloud Appliance Library. Inoltre, devi installare SAP GUI per Windows o per Java, a seconda del tuo sistema operativo locale. Puoi scaricare SAP GUI da [qui](https://www.sap.com/products/try-sap/trials-downloads.html?search=sap+gui).

Per maggiori dettagli, vedi questo blog della [SAP Community](https://community.sap.com/t5/technology-blog-posts-by-sap/abap-cloud-developer-trial-2023-available-now/ba-p/14057183).
