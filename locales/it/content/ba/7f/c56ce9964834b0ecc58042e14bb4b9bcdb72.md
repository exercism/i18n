# Introduzione

Molti linguaggi hanno un modo, come `null` o `none`, per indicare un valore inesistente.
Poiché R è progettato per gestire grandi quantità di dati (spesso disordinati), ha diverse forme di «nulla».

L'obiettivo generale è segnalare i valori mancanti o sospetti man mano che si incontrano, poi continuare senza sollevare un'eccezione.

## NULL

Se un valore davvero non esiste, viene rappresentato da `NULL`. È probabilmente la cosa più vicina a ciò che farebbero C o Python.

```R
v <- c() # zero-length vector
v
#> NULL
is.null(v)
#> [1] TRUE
```

In molti contesti, i valori `NULL` vengono semplicemente ignorati:

```R
c(2, 3, NULL, 5)
#> [1] 2 3 5
```

## NA

Nei casi in cui un valore esiste ma non sappiamo quale sia, si usa `NA`. Per esempio, quando si contano i veicoli in transito su una strada, gli osservatori umani potrebbero ammalarsi o i sensori automatici guastarsi, ma il traffico continua a scorrere.

```R
v <- c(1, 2, NA, 4, 5)
v
#> [1]  1  2 NA 4  5
is.na(v) # test for data gaps
#> [1] FALSE FALSE  TRUE FALSE FALSE
```

Quindi `NA` è un segnaposto, che avverte le persone che devono decidere come gestirlo.

## Vettori vuoti

Forse sorprendentemente, R non ha un modo standard per verificare il vuoto, anche se alcuni pacchetti di terze parti implementano funzioni proprie come `is.empty()`.

Persino generare un vettore vuoto non è del tutto ovvio.
In una sezione precedente abbiamo visto che `c()` senza argomenti restituisce `NULL`, non un vettore.

```R
is.vector(c())
#> [1] FALSE
```

Funzioni come `logical()` o `integer()` accettano un argomento che specifica la lunghezza desiderata, che può essere zero.

```R
z <- logical(0)
is.vector(z)
#> [1] TRUE
length(z)
#> [1] 0
```

Possiamo anche generare un vettore e poi rimuovere ogni elemento, come descritto nel [concetto Vectors][concept-vectors].
Il risultato è un vettore di lunghezza 0 del tipo appropriato.

```R
v <- 5
v[-1]  # delete the first element
#> numeric(0)
```

[concept-vectors]: https://exercism.org/tracks/r/concepts/vectors
