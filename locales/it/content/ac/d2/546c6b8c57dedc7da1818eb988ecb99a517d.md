# Introduzione

Una *riduzione* combina gli elementi di una sequenza in un unico valore (o in una sequenza derivata di valori progressivi). Il riduttore generico di Factor è `reduce`; `math.statistics` aggiunge una famiglia di operazioni cumulative, cioè somme, prodotti, minimi e massimi progressivi, per quando ti serve ogni risultato intermedio e non solo l'ultimo.

```factor
USING: math math.statistics sequences ;

{ 2 5 1 3 } 0 [ + ] reduce .         ! => 11

{ 2 5 1 3 } cum-sum .                ! => { 2 7 8 11 }
{ 2 5 1 3 } cum-product .            ! => { 2 10 10 30 }
{ 2 5 1 3 } cum-min .                ! => { 2 2 1 1 }
{ 2 5 1 3 } cum-max .                ! => { 2 5 5 5 }
```

[math.statistics]: https://docs.factorcode.org/content/vocab-math.statistics.html
