# Introduzione

Capire i riferimenti è un elemento fondamentale per usare Perl in modo efficace.
Poiché i riferimenti sono scalari, e gli array e gli hash possono contenere solo scalari, i riferimenti sono la chiave per annidare queste strutture dati.

I riferimenti possono essere creati per variabili e sottoprogrammi esistenti usando l'operatore backslash `\`:

* `\$scalar` per creare un riferimento a scalare (può essere qualsiasi scalare, ad esempio `\1`, non solo una variabile).
* `\@array` per creare un riferimento a un array.
* `\%hash` per creare un riferimento a un hash.
* `\&sub` per creare un riferimento a codice.

Puoi anche creare ciò che è noto come riferimento anonimo per array, hash e sottoprogrammi:

* `['Alice', 'Bob', 'Charlie']` per creare un riferimento anonimo ad array.
* `{foo => 'a', bar => 'b', baz => 'c'}` per creare un riferimento anonimo a un hash.
* `sub { return 1 }` per creare un riferimento anonimo a codice.

ATTENZIONE: le parentesi graffe in Perl possono essere ambigue in certi contesti. Se non ottieni il riferimento hash che ti aspetti, aggiungi un più iniziale per disambiguarlo, ad esempio `+{}`. Vedi [Parentesi graffe][perlrefcurlybrackets] per maggiori informazioni.

Puoi accedere ai riferimenti usando l'operatore freccia `->`:

* `$ref->[0]` per accedere a un elemento all'interno di un riferimento ad array.
* `$ref->{foo}` per accedere a un valore all'interno di un riferimento a un hash.
* `$ref->($arg)` per chiamare un sottoprogramma tramite un riferimento a codice.

Si può accedere ai dati all'interno di strutture dati complesse, come array multidimensionali e hash annidati, concatenando i pedici, ad esempio `$ref->{foo}[0]{bar}` (equivale a `$ref->{foo}->[0]->{bar}`).

Se vuoi dereferenziare un intero array o hash, puoi usare l'operatore freccia seguito da `@*` o `%*` rispettivamente, ad esempio `$ref->@*` o `$ref->%*`.
Puoi anche ottenere slice di un riferimento ad array o hash sostituendo il `*` con un pedice, ad esempio `$ref->@[0..2]` o `$ref->@{'Foo', 'Bar'}`.
Per le slice, la varianza del sigillo vale qui come per le variabili array e hash.

[perlrefcurlybrackets]: https://perldoc.perl.org/perlref#Curly-Brackets
