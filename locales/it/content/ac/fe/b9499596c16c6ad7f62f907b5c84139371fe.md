# Istruzioni

Stai lavorando all'implementazione di un sistema di monitoraggio della salute.
Come parte di questo lavoro, devi tenere traccia delle statistiche sulla salute degli utenti.

Inizierai con alcune funzioni non ancora implementate in un blocco `impl`, oltre alla seguente definizione di struct:

```rust
pub struct User {
    name: String,
    age: u32,
    weight: u32,
}
```

L'obiettivo è implementare i metodi non ancora implementati dello `struct` `User` definito nel blocco `impl`.

Per esempio, il metodo `new` deve restituire un'istanza dello `struct` `User` con i valori specificati di nome, età e peso.

```rust
let mut bob = User::new("Bob", 32, 72);
// Returns: a User with name "Bob", age 32, and weight 72
```

Il metodo `weight` deve restituire il peso dello `User`.

```rust
bob.weight();
// Returns: 72
```

Il metodo `set_age` deve impostare l'età dello `User`.

```rust
bob.set_age(33);
// Updates Bob's age to 33; happy birthday Bob!
```
