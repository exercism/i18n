# Istruzioni

In questo esercizio elaborerai delle righe di log.

Ogni riga di log è una stringa formattata come segue: `"[<LVL>]: <MESSAGE>"`.

Questi sono i diversi livelli di log:

- `TRC` (trace)
- `DBG` (debug)
- `INF` (info)
- `WRN` (warning)
- `ERR` (error)
- `FTL` (fatal)

Hai tre attività, ognuna delle quali deve essere completata per fornire la funzionalità necessaria.

## 1. Crea l'enum LogLevel

Definisci un enum `LogLevel` con sei casi corrispondenti ai livelli di log sopra elencati, più un caso unknown per i livelli con livello di log mancante o non standard.

- `trace`
- `debug`
- `info`
- `warning`
- `error`
- `fatal`
- `unknown`

## 2. Analizza il livello di log

Poi, implementa l'inizializzatore di `LogLevel` per analizzare il livello di log di una riga di log:

```swift
LogLevel("[INF]: File deleted")
// Returns LogLevel.info
LogLevel("Something went wrong!")
// Returns LogLevel.unknown
```

## 3. Converti la riga di log nel formato breve

Il livello di log di una riga di log è piuttosto verboso.
Per ridurre lo spazio su disco necessario per memorizzare le righe di log, è stato sviluppato un formato breve: `"<ENCODED_LEVEL>:<MESSAGE>"`.

Il livello di log codificato è una semplice mappatura da un livello di log a un numero:

- `trace` - `0`
- `debug` - `1`
- `info` - `4`
- `warning` - `5`
- `error` - `6`
- `fatal` - `7`
- `unknown` - `42`

Implementa il metodo `shortFormat(message: String) -> String` che può restituire il formato abbreviato della riga di log come `String`:

```swift
let overflow = LogLevel.error
overflow.shortFormat(message: "Stack overflow")
// Returns "6:Stack overflow"
```
