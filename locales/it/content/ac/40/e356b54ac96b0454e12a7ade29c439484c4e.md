# Istruzioni

Il tuo amico ti ha appena inviato un messaggio con un importante segreto.
Non volendo renderlo facile da leggere agli altri, il messaggio è stato cifrato usando una serie di manipolazioni a livello di bit.
Dovrai scrivere un programma che ti aiuti a decifrare il messaggio.

## 1. Sposta i bit indietro

Il primo passo per decifrare il messaggio è annullare lo scorrimento fatto durante la cifratura, spostando i bit di nuovo verso sinistra.
Il numero di posizioni di cui spostarli può variare da un messaggio all'altro.

Implementa il metodo `Secrets.shift_back`, che prende un valore e il numero di posizioni di cui spostarlo verso sinistra.

```crystal
Secrets.shift_back(0b0001, 2)
# => 0b0100
```

## 2. Applica una maschera di bit

Il passo successivo è applicare una maschera di bit per estrarre il valore di alcuni bit.
La maschera si applica eseguendo un AND bit a bit tra il valore e la maschera.

Implementa il metodo `Secrets.apply_mask`, che prende un valore e gli applica una maschera.

```crystal
Secrets.apply_mask(0b0110, 0b0101)
# => 0b0100
```

## 3. Imposta alcuni bit

Lo scorrimento dei bit verso sinistra ha aggiunto dei nuovi bit a 0.
Alcuni di questi nuovi bit devono essere impostati a 1.
L'OR bit a bit è utile per impostare alcuni bit a 1 preservando tutti gli altri.

Implementa il metodo `Secrets.set_bits`, che prende due valori ed esegue un OR bit a bit.

```crystal
Secrets.set_bits(0b0110, 0b0101)
# => 0b111
```

## 4. Inverti lo XOR

Una parte del processo di cifratura applica uno XOR con un valore concordato.
Per risalire al valore originale, basta applicare di nuovo lo XOR tra il valore cifrato e il valore concordato.
Tuttavia, per un malinteso, il tuo amico ha invertito i bit del valore concordato (cioè ha applicato un NOT bit a bit al valore concordato) prima di applicare lo XOR.

Implementa il metodo `Secrets.reverse_xor`, che prende il valore cifrato e il valore concordato e calcola il valore originale.

```crystal
Secrets.reverse_xor(0b1100, 0b0101)
# => 0b(0110)
```
