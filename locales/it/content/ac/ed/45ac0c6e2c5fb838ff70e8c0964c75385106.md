# Risolvere gli esercizi

Il modo principale con cui Exercism ti aiuta a imparare è risolvere gli esercizi.

Ci sono due modi per risolvere gli esercizi su Exercism:

1. [Online, con l'editor del sito nel browser](/docs/using/solving-exercises/using-the-online-editor)
2. [Sulla tua macchina locale, tramite la CLI](/docs/using/solving-exercises/working-locally)

## Quale opzione scegliere?

Usare l'editor online o la CLI comporta compromessi diversi:

|            | Editor online                          | CLI                                          |
| ---------- | -------------------------------------- | -------------------------------------------- |
| Installazione | No                                  | Sì (ad es. l'SDK)                            |
| Modifica    | Browser                                | L'editor che preferisci                      |
| Test       | Esegui i test sul sito                 | Esegui i test in locale                      |
| Debug      | Supporto limitato (solo per alcuni track) | Supporto completo (dipende dal tuo ambiente) |

In generale, l'editor online è ideale per iniziare nuovi track, mentre l'approccio basato sulla CLI è ottimo se vuoi usare il tuo ambiente di programmazione personale.
