Elixir ha convenzioni di denominazione specifiche, che comprendono anche come chiamare le [funzioni che restituiscono un booleano](https://hexdocs.pm/elixir/naming-conventions.html#trailing-question-mark-foo) ed i [controlli che restituiscono un booleano e sono validi nelle clausole di guardia](https://hexdocs.pm/elixir/naming-conventions.html#is_-prefix-is_foo):

> Le funzioni che restituiscono un booleano si chiamano con un punto interrogativo finale.

> I controlli di tipo e gli altri controlli booleani ammessi nelle clausole di guardia si chiamano con il prefisso `is_`.

Le macro si possono usare in entrambi i contesti, quindi la notazione varia a seconda del caso, ma le due convenzioni di denominazione non vanno mescolate.

```elixir
# this is the expected name of macros that return booleans

%{option1}

# this is the expected name of macros that return booleans and are valid in guard clauses

%{option2}

# this is the current name

%{actual}
```
