# Suggerimenti

## Generale

- Leggi la sezione sulle [struct][getting-started-structs] nella guida Getting Started.
- Leggi la documentazione di [`defstruct`][docs-defstruct].
- Guarda [Elixir Casts - #106: Intro to Structs][elixir-casts].

## 1. Crea un'auto radiocomandata nuova di zecca

- Puoi usare l'attributo di modulo `@enforce_keys` per specificare i valori obbligatori. Deve essere definito prima di chiamare `defstruct`.
- Il campo `nickname` non deve avere un valore predefinito.
- La funzione `new/0` deve inizializzare `nickname` con il valore `"none"`.

## 2. Crea un'auto radiocomandata nuova di zecca con un soprannome

- Usa [`multiple-function-clauses`][multiple-fn-clauses] per riutilizzare il nome della funzione ma accettare argomenti diversi.
- Valuta un [`default-argument`][default-arg] per la funzione.

## 3. Mostra la distanza

- Per le funzioni che accettano solo un tipo specifico di struct, assicurati di eseguire un pattern matching per controllare l'argomento.
- Usa l'_operatore di accesso statico_ per ottenere i valori dei campi.

## 4. Mostra la percentuale della batteria

- Per le funzioni che accettano solo un tipo specifico di struct, assicurati di eseguire un pattern matching per controllare l'argomento.
- Usa l'_operatore di accesso statico_ per ottenere i valori dei campi.

## 5. Guidare modifica la batteria e la distanza percorsa

- Per le funzioni che accettano solo un tipo specifico di struct, assicurati di eseguire un pattern matching per controllare l'argomento.
- Usa l'_operatore di accesso statico_ per ottenere i valori dei campi.
- Rileggi l'introduzione per aggiornare le struct.

## 6. Gestisci la guida con la batteria scarica

- Se la batteria è scarica, la funzione deve restituire la struct invariata.
