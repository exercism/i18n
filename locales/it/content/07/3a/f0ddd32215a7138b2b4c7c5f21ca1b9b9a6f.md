# Informazioni

Esistono sostanzialmente due tipi di cicli:

1. Ripetere finché una condizione non è soddisfatta.
2. Iterare sugli elementi di una collezione.

Entrambi sono [possibili in R][web-loops], anche se il primo è probabilmente il più comune.

## `while` e `repeat`

Per problemi aperti, in cui non si sa in anticipo quante volte si ripeterà il ciclo, R ha il ciclo [`while`][ref-control] con una condizione e il ciclo [`repeat`][ref-control] senza condizione (equivalente a `while (TRUE)`).

La forma di base è piuttosto semplice:

```R
while (condition) {
  do_something()
}
```

In questo caso, il programma continuerà a ripetere il ciclo finché `condition` non è più `TRUE`.

Sono disponibili due modi per uscire anticipatamente dal ciclo:

- Un `break` fa uscire dal ciclo: l'esecuzione prosegue dalla riga successiva alla parentesi graffa di chiusura del ciclo `}`.
- Un `return(x)` interrompe l'esecuzione della funzione corrente, passando al chiamante il valore restituito `x`.

Con queste opzioni a disposizione, a volte può essere comodo creare un ciclo «infinito» con `repeat { ... }` e poi affidarsi a una condizione di arresto individuata all'interno del corpo del ciclo per attivare un `break` o un `return`.

Queste tre varianti sono equivalenti e terminano tutte con `x == 0.4444...`

```R
x <- 12
while (x > 1) {
  x <- x / 3
}

x <- 12
while (TRUE) {
  x <- x/3
  if (x <= 1) break
}

x <- 12
# no boolean clause 
repeat { 
  x <- x/3
  if (x <= 1) break
}
```

## Iterare su un vettore (o un'altra collezione)

In R, spesso non è necessario.
Come spiegato in altri concetti, molte funzioni operano su interi vettori.

Tuttavia, a volte i cicli espliciti sono inevitabili.
Questo vale soprattutto quando:

- Il corpo del ciclo ha effetti collaterali, come la stampa o l'I/O su file.
- Il ciclo continua finché non si raggiunge un certo criterio, dopo un numero imprevedibile di iterazioni.

La condizione del ciclo deve essere tra parentesi tonde.
Come per i corpi delle funzioni, le parentesi graffe sono facoltative (ma spesso presenti) per i corpi di ciclo su una sola riga.

```R
words <- c("This", "is", "a", "loop")
for (w in words) { print(w) } # the braces are optional here
#> [1] "This"
#> [1] "is"
#> [1] "a"
#> [1] "loop"
```

Se l'iterazione corrente non soddisfa una certa condizione, è possibile saltare subito all'iterazione successiva con un `next`:

```R
for (n in 1:5) {
  if (n %% 2 == 0) next
  print(n)
}
#> [1] 1
#> [1] 3
#> [1] 5
```

Se serve l'indice numerico, usa [`seq_along()`][ref-seq_along].

```R
v <- LETTERS[1:3]
v
#> [1] "A" "B" "C"

for (i in seq_along(v)) { print(sprintf("%s%i", v[i], i)) }
#> [1] "A1"
#> [1] "B2"
#> [1] "C3"
```

Usare `i in 1:length(v)` _non_ è consigliato, perché può causare problemi quando `length(v)` è zero.
L'intervallo `1:0` equivale a `c(1, 0)`, quindi il corpo del ciclo verrà eseguito e probabilmente fallirà.
La funzione `seq_along()` è pensata per gestire correttamente questo caso.
