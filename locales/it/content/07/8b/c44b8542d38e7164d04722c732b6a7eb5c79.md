# Testare gli esercizi

Segui i passaggi qui sotto per sviluppare una soluzione per un esercizio e testarla in locale.

## Scaricare l'esercizio

Apri un Command Prompt ed esegui il comando qui sotto, indicando il nome dell'esercizio che preferisci, per scaricarlo.

```sh
exercism download --track ballerina --exercise <exercise-name>
```

## Sviluppare la soluzione

1. Esegui il comando qui sotto per spostarti nella directory dell'esercizio appena scaricato.

     >**Suggerimento:** Il percorso della directory nel comando qui sotto dipende dal tuo sistema operativo e dall'area di lavoro di Exercism che hai configurato. Puoi scoprire il percorso della tua area di lavoro eseguendo il comando `exercism configure`.

     ```sh
     cd ~/exercism/ballerina/hello-world/
     ```

2. Segui le istruzioni fornite e sviluppa una soluzione per l'esercizio.

## Testare la soluzione

Alcuni esercizi Ballerina hanno un solo test, mentre altri ne hanno più di uno. I test si trovano nel rispettivo file di test della directory `/tests`, dentro la directory principale dell'esercizio.

### Testare un esercizio con un solo test

Esegui il comando qui sotto per eseguire il test dell'esercizio.

Per impostazione predefinita, è abilitato solo il primo test. È una scelta intenzionale: ti permette di concentrarti solo sul far passare quel test.
     
```sh
bal test
```

### Testare un esercizio con più test

Segui i passaggi qui sotto per testare un esercizio con più test.

1. Una volta che il primo test passa, abilita il test successivo rimuovendo la proprietà `enable: false` dell'annotazione `@test:Config`.

     ```ballerina
     @test:Config {
       enable: false
     }
     function nextTestCase() {
     }
     ``` 

2.  Esegui il comando qui sotto per eseguire il test abilitato.

   ```sh
     bal test
   ```

3. Ripeti i due passaggi precedenti per abilitare i test rimanenti.

Hai completato l'esercizio con successo abilitando tutti i test e assicurandoti che l'implementazione li superi tutti.
