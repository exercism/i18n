# Istruzioni

Determina se un dato insieme di tre tessere del domino può essere disposto in modo da formare una catena di domino corretta (i punti su una metà di una tessera corrispondono ai punti sulla metà vicina di una tessera adiacente) e se i punti sulle metà delle tessere che non hanno un vicino (la prima e l'ultima tessera) corrispondono tra loro. Alcuni casi di test possono usare tessere duplicate in una soluzione a catena. Restituisci `True` se è possibile disporre una catena di domino corretta e `False` altrimenti.

```text
For example, given: [(2,1),(2,3),(1,3)]
    True

For example, given: [(1,2),(4,1),(2,3)]
    False
```
