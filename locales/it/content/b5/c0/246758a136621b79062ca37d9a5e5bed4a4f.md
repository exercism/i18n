# Introduzione

In Common Lisp, la lista degli argomenti di una funzione è nota come [«lambda list»][lambda-list].
Una lambda list può avere argomenti di tipi diversi.
Questi tipi diversi si indicano con l'uso delle [«lambda list keyword»][lambda-list-keyword], che iniziano tutte con `&`.
I tipi più comuni sono gli argomenti optional, keyword e rest.
Ogni parametro nella lambda list che segue una particolare lambda list keyword sarà di quel tipo.
Una lambda list keyword può essere usata una sola volta in una lambda list.

Le lambda list si usano anche in altri costrutti, di cui parleremo più avanti, come il destructuring e le macro.
