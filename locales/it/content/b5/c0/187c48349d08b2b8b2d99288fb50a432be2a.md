# Istruzioni

Il tuo compito sarà prendere un array di marcatori di una partita e contare quanti gol ha segnato ogni giocatore.

`PlayerName` è un alias di tipo per `String`, per rendere il codice più leggibile e per distinguere questo uso di `String` da altri usi di `String`.

## 1. Aggrega i marcatori

Per prima cosa, implementa `updateGoalCountForPlayer` per inizializzare o incrementare il conteggio dei gol di un giocatore.
Poi implementa la funzione `aggregateScorers` per contare quanti gol ha segnato ogni giocatore, usando `updateGoalCountForPlayer`.
Questa funzione prende una `List PlayerName` (i nomi dei giocatori che hanno segnato i gol, che può contenere nomi di giocatori duplicati) e restituisce un `Dict PlayerName Int` contenente tutti i giocatori dell'array insieme al numero di gol che hanno segnato.

```elm
aggregateScorers [ "Betty", "Cedd", "Betty" ]
--> Dict.fromList [ ( "Betty", 2 ), ( "Cedd", 1 ) ]
```

## 2. Rimuovi i giocatori irrilevanti

Implementa la funzione `removeInsignificantPlayers` per filtrare tutti i giocatori che hanno segnato meno gol della soglia.

```elm
removeInsignificantPlayers 2 (Dict.fromList [ ( "Betty", 2 ), ( "Cedd", 1 ) ] )
--> Dict.fromList [ ( "Betty", 2 ) ]
```

## 3. Azzera il conteggio dei gol di un giocatore

Implementa la funzione `resetPlayerGoalCount` per riportare a zero i gol segnati da un giocatore.

```elm
resetPlayerGoalCount "Cedd" (Dict.fromList [ ( "Betty", 2 ), ( "Cedd", 1 ) ] )
--> Dict.fromList [ ( "Betty", 2 ), ( "Cedd", 0 ) ]
```

## 4. Formatta il conteggio dei gol di un singolo giocatore

Implementa la funzione `formatPlayer` per formattare come stringa il conteggio dei gol di un singolo giocatore. Se il giocatore non esiste nel dict, presumi che il suo conteggio dei gol sia zero.

```elm
formatPlayer "Betty" (Dict.fromList [ ( "Betty", 2 ), ( "Cedd", 1 ) ] )
--> "Betty: 2"
```

## 5. Formatta il conteggio dei gol di tutti i giocatori

Implementa la funzione `formatPlayers` per formattare come stringa il conteggio dei gol di tutti i giocatori. I giocatori devono essere ordinati per nome.

```elm
formatPlayers (Dict.fromList [ ( "Betty", 2 ), ( "Cedd", 1 ) ] )
--> "Betty: 2, Cedd: 1"
```

## 6. Combina le partite

Implementa la funzione `combineGames`, contando il numero totale di gol che ogni giocatore ha segnato in entrambe le partite.

```elm
combine Games
  (Dict.fromList [ ( "Betty", 2 ), ( "Cedd", 1 ) ] )
  (Dict.fromList [ ( "Betty", 2 ), ( "Mario", 3 ) ] )
--> Dict.fromList [ ( "Betty", 4 ), ( "Cedd", 1 ), ( "Mario", 3 ) ]
```
