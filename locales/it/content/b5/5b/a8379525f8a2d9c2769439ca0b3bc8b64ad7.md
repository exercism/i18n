# Informazioni

Haxe supporta la riflessione a runtime su tipi e campi. Per usare correttamente la riflessione, è necessario capire quali tipi di operazioni sono supportate e quali no. Data la natura dinamica della riflessione, non è sempre possibile determinarlo a tempo di compilazione.

L'API di riflessione è composta da due classi:

- `Reflect`: Un'API leggera che funziona meglio con le strutture anonime, con un supporto limitato per le classi.
- `Type`: Un'API più robusta per lavorare con classi ed enum.

I metodi disponibili sono descritti in dettaglio nell'API di [Reflect][reflect] e [Type][type].

Per il seguente esempio, utilizzeremo il target JavaScript:

```haxe
class Main {
  public static function main() {
    trace(Type.resolveClass("Main"));
  }
}

// This outputs
// class Test { static main() { console.log("Test.hx:3:",$hxClasses["Test"]); } }
```

[reflect]: https://api.haxe.org/Reflect.html
[type]: https://api.haxe.org/Type.html
