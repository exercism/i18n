# Introduzione

## Array

JSON definisce un **array** come:

> Un array è una raccolta ordinata di valori.
> Un array inizia con la parentesi quadra sinistra `[` e finisce con la parentesi quadra destra `]`.
> I valori sono separati dalla virgola `,`.

Gli array possono contenere zero o più valori JSON di _qualsiasi tipo_.
Gli elementi di un array non devono essere tutti dello stesso tipo.

### Creare array

Usa le parentesi quadre per raccogliere gli elementi in un array.

```jq
[1, 2, 3]
```

Gli elementi di uno _stream_ possono essere raccolti in un array racchiudendoli tra parentesi quadre.

```jq
range(5)     # => a stream of 5 numbers
[range(5)]   # => the array [0, 1, 2, 3, 4]
```

### Dimensione

La funzione `length` restituisce il numero di elementi di un array.

### Indicizzazione e sezioni

L'indicizzazione degli array parte da zero.

Recupera un elemento da un array con un'espressione tra parentesi quadre:
`.[2]` ottiene il terzo elemento.

Gli indici negativi contano all'indietro dalla fine dell'array:
`.[-1]` ottiene l'ultimo elemento; `.[-2]` è il penultimo.

Una **sezione** (slice) è una sotto-sequenza dell'array.
`.[10:15]` restituisce 5 elementi a partire dall'indice 10; l'indice finale _non è incluso_.

Ci sono alcune funzioni di comodo:

- `first` ottiene il primo elemento.
- `last` ottiene l'ultimo elemento.
- `nth(n)` ottiene l'elemento all'indice `n`.

### Iterazione

`jq` fornisce molte funzioni per coprire le funzionalità di iterazione più comuni:

- `map(expr)` restituisce un nuovo array in cui l'`expr` viene applicato a ciascun elemento, uno alla volta.

  ```jq
  [1, 2, 3] | map(. * 10)    # => [10, 20, 30]

  ```

- `select(expr)` è una funzione che applica l'`expr` a un _singolo valore_;
  se il risultato dell'espressione è vero, allora il valore viene restituito;
  se il risultato è falso, _non viene restituito nulla_: non `null`, proprio nulla.

  Per applicarlo a un array, combinalo con `map`.

  ```jq
  [range(10)] | map(select(. % 2 == 0))    # => [0, 2, 4, 6, 8]
  ```

  In alternativa, applica `select` a uno _stream_ e raccogli i risultati.

  ```jq
  [range(10) | select(. % 2 == 0)]    # => [0, 2, 4, 6, 8]
  ```

- `any(condition)` e `all(condition)` restituiscono un valore booleano che indica se uno o tutti gli elementi dell'array superano la condizione.

  ```jq
  [1, 2, 3, 4] | any(. > 4)    # false
  [1, 2, 3, 4] | any(. >= 4)   # true

  [1, 2, 3, 4] | all(. >= 4)   # false
  [1, 2, 3, 4] | all(. <= 4)   # true
  ```
