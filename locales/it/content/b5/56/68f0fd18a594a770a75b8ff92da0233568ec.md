# Introduzione

Gli inizializzatori di oggetto sono un'alternativa ai costruttori. La sintassi è illustrata qui sotto. Fornisci un elenco di coppie nome-valore separate da virgole, con nome e valore divisi da `=`, all'interno di parentesi graffe:

```csharp
public class Person
{
    public string Name;
    public string Address;
}

var person = new Person{Name="The President", Address = "Élysée Palace"};
```

Anche le collezioni possono essere inizializzate in questo modo. In genere, questo si ottiene con elenchi separati da virgole, come mostrato qui:

```csharp
IList<Person> people = new List<Person>{ new Person(), new Person{Name="Joe Shmo"}};
```

I dizionari usano la seguente sintassi:

```csharp
IDictionary<int, string> numbers = new Dictionary<int, string>{ [0] = "zero", [1] = "one"...};

// or

IDictionary<int, string> numbers = new Dictionary<int, string>{ {0, "zero" }, {1,  "one"}...};
```
