# Introduzione

## Oggetti

Un **oggetto** JSON è, per usare la terminologia di altri linguaggi, un «hash», una «map» o un «dictionary».

JSON definisce un _oggetto_ come:

> Un oggetto è un insieme non ordinato di coppie **nome**/**valore**.
> Un oggetto inizia con la parentesi graffa aperta `{` e termina con la parentesi graffa chiusa `}`.
> Ogni _nome_ è seguito dai due punti (`:`) e le coppie _nome/valore_ sono separate da una virgola (`,`).

Il _nome_ **deve essere una stringa**.
Un altro termine per _nome_ è _chiave_.

Il _valore_ può essere di qualsiasi tipo JSON.
_Valori_ diversi nello stesso oggetto possono essere di tipi diversi, come in questo esempio.

<!-- prettier-ignore -->
```json
{
  "name": "Jane",
  "age": 42,
  "pets": ["cat", "fish"],
  "address": {"street": "123 Main St", "city": "Springfield"}
}
```

<!-- prettier-ignore-end -->

Tieni presente che **non deve** esserci una virgola dopo l'_ultima_ coppia chiave-valore.

### Creare oggetti

Usa le parentesi graffe per raccogliere le coppie nome/valore.
Anche se i nomi devono essere stringhe, non è necessario metterli tra virgolette se sono **_identifier-like_** (composti da caratteri alfanumerici e underscore, e non iniziano con una cifra).

```jq
{name: "Jane", age: 42}
```

È valido usare chiavi che non sono _identifier-like_.
Basta metterle tra virgolette.

```jq
{"first name": "Jane", "last name": "Lopez", age: 42}
```

Se il nome è il risultato di un'espressione, l'espressione **deve** essere tra parentesi.

```sh
$ echo "Jane" | jq -Rc '{.: 42}'
# verbose error message ...

$ echo "Jane" | jq -Rc '{(.): 42}'
{"Jane":42}
```

### Indicizzazione

I valori si recuperano da un oggetto con la **notazione con il punto**.

```jq
{name: "Jane", age: 42} | .age    # => 42
```

Se non puoi fare riferimento alla chiave come a un identificatore, usa la **notazione con le parentesi**.

```jq
"name" as $key | {name: "Jane", age: 42} | .$key    # => error
"name" as $key | {name: "Jane", age: 42} | .[$key]  # => "Jane"
```

### Aggiungere o modificare coppie chiave-valore

Per aggiungere una nuova coppia chiave-valore a un array, o per aggiornare il valore di una chiave esistente, usa l'operatore di assegnazione `=`, con un'espressione di indice sul lato sinistro.

```jq
{name: "Jane", age: 42} | .sport = "tennis" | .age = 21
# => {
#      "name": "Jane",
#      "age": 21,
#      "sport": "tennis"
#    }
```

L'operatore `+` _fonde_ gli oggetti.

```jq
{Richard: 54} + {Jane: 42}
# => {
#      "Richard": 54,
#      "Jane": 42
#    }
```

### Rimuovere una chiave

Usa la funzione `del` per rimuovere una chiave.
Restituisce l'oggetto aggiornato.

```jq
{name: "Jane", age: 42} | del(.age)   # => {"name": "Jane"}
```

Il parametro di `del` è un'**espressione di indice** (che usa la notazione con il punto o con le parentesi) che si risolve in una chiave dell'oggetto.
`jq` la chiama **espressione di percorso**.
Non basta fornire una semplice stringa.

```jq
{name: "Jane", age: 42} | del(name)        # error: name/0 is not defined
{name: "Jane", age: 42} | del("name")      # error: Invalid path expression with result "name"
{name: "Jane", age: 42} | del(.name)       # OK
{name: "Jane", age: 42} | del(.["name"])   # OK
```

### Appartenenza

- Per verificare se l'oggetto ha una chiave, usa la funzione `has`.

  ```jq
  {name: "Jane", age: 42} as $example
  |
    ($example | has("name")),    # => true
    ($example | has("sport"))    # => false
  ```

- Verifica se una chiave è presente in un oggetto con `in`.

  ```jq
  {name: "Jane", age: 42} as $example
  |
    ("name"  | in($example)),    # => true
    ("sport" | in($example))     # => false
  ```

### Elencare tutte le chiavi

Usa la funzione `keys` per produrre un elenco di tutte le chiavi.

```jq
{name: "Jane", age: 42} | keys   # => ["age", "name"]
```

Nota che `keys` _ordina_ le chiavi.
Per recuperare le chiavi nell'ordine originale, usa `keys_unsorted`.

Non esiste una funzione equivalente per elencare tutti i _valori_.
Tuttavia il filtro `.[]` produce i valori dell'oggetto come _stream_, e quello stream può essere catturato con il costruttore di array `[...]`.

```jq
[{first: "Jane", last: "Lopez", status: "awesome!"} | .[]]
# => ["Jane", "Lopez", "awesome!"]
```

### Iterare

- La funzione `map_values(filter)` applica il filtro a ogni _valore_ dell'oggetto.

  ```jq
  {first: "Jane", last: "Lopez", status: "awesome!"}
  | map_values(ascii_upcase)
  # => {"first": "JANE", "last": "LOPEZ", "status": "AWESOME!"}
  ```

- Per iterare su un oggetto, dobbiamo prima convertirlo in un array di oggetti chiave-valore.
  La funzione `to_entries` fa questo.

  ```jq
  {name: "Jane", age: 42} | to_entries'
  # => [
  #      {
  #        "key": "name",
  #        "value": "Jane"
  #      },
  #      {
  #        "key": "age",
  #        "value": 42
  #      }
  #    ]
  ```

  A questo punto, possiamo usare le funzioni di iterazione degli array, come `map`.

- La funzione `from_entries` è l'inverso: converte un array di oggetti chiave-valore in un oggetto.

  ```jq
  [
    {"key":"name", "value":"Jane"},
    {"key":"age", "value":42}
  ] | from_entries                  # =>{"name": "Jane", "age": 42}
  ```

- Per applicare un filtro a _ogni_ coppia chiave-valore di un oggetto, usa la funzione `with_entries(filter)`.

  Per esempio, dato un oggetto che associa un nome a un'età, le chiavi e i valori possono essere scambiati come segue.

  ```jq
  {"Jane": 42, "Richard": 54}
  | with_entries({key: (.value | tostring), value: .key})
  ```

  produce

  ```json
  {
    "42": "Jane",
    "54": "Richard"
  }
  ```

  `with_entries(filter)` equivale a

  ```jq
  to_entries | map(filter) | from_entries
  ```
