# Informazioni

Come le proprietà, che memorizzano dati nelle tue struct e classi, puoi anche definire _metodi_ che memorizzano funzioni nella tua struct o classe.

I metodi si definiscono allo stesso modo di una funzione normale, solo all'interno del corpo della struct o della classe. Nota che se una funzione cambia il valore di una proprietà in una struct, deve essere preceduta dalla parola chiave `mutating`. Inoltre, se una proprietà può essere modificata da un metodo, quella proprietà deve essere definita usando `var` anziché `let`, proprio come le variabili normali.

```swift
struct CharacterStats {
  var health = 0.0
  var speed = 0
  var strength = 0

  mutating func takeHit(_ damage: Double) {
    health = max(0.0, health - damage)
  }
  func canLift(_ weight: Int) -> Bool {
    weight < strength * 100
  }
}

class GameCharacter {
  var stats = CharacterStats()
  var characterClass: String?
  var name: String?
  var active = false
  let id: String = makeRandomID()

  func takesDamage(_ damage: Double) {
    stats.takeHit(damage)
    if stats.health <= 0 {
      active = false
    }
  }
  func sayName() -> String {
    return "My name is \(name ?? "no one"), my class is \(characterClass ?? "undetermined")"
  }
  func lift(_ weight: Int) -> String {
    if stats.canLift(weight) {
      return "No problem!"
    } else {
      return "Ooof! No way."
    }
  }
}
```

Questi metodi si possono chiamare usando la notazione puntata, proprio come le proprietà.

```swift
var myChar = GameCharacter()
myChar.stats = CharacterStats(health: 72.8, speed: 19, strength: 6)
myChar.name = "Shadowfly"
myChar.characterClass = "spy"
myChar.active = true

myChar.active
// => true
myChar.sayName()
// => "My name is Shadowfly, my class is spy"
myChar.lift(750)
// => "Ooof! No way."
myChar.takesDamage(80)
myChar.active
// => false
```
