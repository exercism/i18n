# Appendice alle istruzioni

## Usare il parallelismo

L'obiettivo di questo esercizio è fare pratica con il parallelismo in Emacs Lisp.

In Emacs Lisp puoi ottenere questo risultato usando gli [`asynchronous processes`](https://www.gnu.org/software/emacs/manual/html_node/elisp/Asynchronous-Processes.html#:~:text=An%20asynchronous%20process%20is%20controlled,%2Dtype%20(see%20below)).

Puoi anche dare un'occhiata alla documentazione di [`batch mode`](https://www.gnu.org/software/emacs/manual/html_node/elisp/Batch-Mode.html), [`sentinels`](https://www.gnu.org/software/emacs/manual/html_node/elisp/Sentinels.html) e [`receiving output from processes`](https://www.gnu.org/software/emacs/manual/html_node/elisp/Output-from-Processes.html).
