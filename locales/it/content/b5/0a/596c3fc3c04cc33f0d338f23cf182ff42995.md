# Test

Per eseguire i test, lancia il comando seguente nella directory dell'esercizio:

```shell
make
```

## Test saltati

Risolvere un esercizio significa far passare tutti i suoi test.
Per impostazione predefinita, quando esegui i test viene eseguito un solo test, il primo.
È intenzionale: così puoi concentrarti solo sul far passare quel test.
Una volta che passa, puoi abilitare il test successivo rimuovendo la riga `TEST_IGNORE();`.
Quando tutti i test sono abilitati e la soluzione li fa passare tutti, avrai risolto l'esercizio!
