# Introduzione

Per poter confrontare un oggetto con un altro, questo deve implementare l'interfaccia `IComparable<T>`.
Questa interfaccia ha un unico metodo che deve essere implementato: `int CompareTo(T other)`.

Il metodo `CompareTo` può restituire tre possibili valori:

- Valore minore di zero: l'oggetto corrente è minore dell'altro oggetto.
- Valore maggiore di zero: l'oggetto corrente è maggiore dell'altro oggetto.
- Valore uguale a zero: l'oggetto corrente è uguale all'altro oggetto.
