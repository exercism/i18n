# Istruzioni

Il progetto dell'auto radiocomandata che hai avviato nell'esercizio `classes` è andato bene (congratulazioni!) e, grazie a una serie di recenti accordi di sponsorizzazione, ci sono soldi nel budget per dei miglioramenti.

Parte del budget viene utilizzata per fornire un po' di telemetria.

Per tenere buoni gli sponsor, è stato installato un pannello sull'auto per mostrare i nomi degli sponsor mentre percorre la pista.

Noterai che l'introduzione di queste nuove tecnologie sofisticate ha ridotto drasticamente la durata della batteria dell'auto.

## 1. Abilita l'auto radiocomandata a mostrare i nomi degli sponsor

Implementa `SetSponsors()` in modo che accetti uno o più nomi di sponsor e li memorizzi sull'auto.

Nota che l'argomento del metodo `SetSponsors()` è garantito non nullo.

Implementa `DisplaySponsor()` per mostrare lo sponsor selezionato. Il primo sponsor passato ha un `sponsorNum` di 0, il secondo di 1 e così via.

```csharp
var car = RemoteControlCar.Buy();
car.SetSponsors("Exercism", "Walker Industries", "Acme Co.");
var sp2 = car.DisplaySponsor(sponsorNum: 1);
// => "Walker Industries"
```

## 2. Ottieni i dati di telemetria dell'auto

Implementa il metodo `RemoteControlCar.GetTelemetryData()`.

`GetTelemetryData()` deve rendere disponibili, tramite parametri `out`, la percentuale della batteria e la distanza percorsa in metri.

`GetTelemetryData()` deve restituire `false` se l'argomento serialNum è minore del valore ricevuto in precedenza. (C'è qualche problema con il coinvolgimento di più nodi di telemetria). In questo caso `serialNum` verrà impostato al valore più alto tra i `serialNum` precedenti e sia la percentuale della batteria sia i metri percorsi verranno impostati a `-1`. Se la chiamata ha successo, `serialNum` rimane invariato.

```csharp
var car = RemoteControlCar.Buy();
car.Drive();
car.Drive();
int serialNum = 4;
car.GetTelemetryData(ref serialNum, out int batteryPercentage, out int distanceDrivenInMeters);
// => true, 4L, 80, 4

serialNum = 1;
car.GetTelemetryData(ref serialNum, out batteryPercentage, out distanceDrivenInMeters);
// => false, 4L, -1, -1
```

## 3. Aggiungi funzionalità in modo che il sistema di telemetria possa ottenere il consumo della batteria per metro

Implementa il metodo `TelemetryClient.GetBatteryUsagePerMeter()`.

Questo chiamerà `RemoteControlCar.GetTelemetryData()`. Se `GetTelemetryData()` restituisce `false` o l'auto non è stata guidata, allora questa routine dovrebbe restituire "no data". Se `GetTelemetryData()` restituisce `true`, allora dovrebbe essere restituito un messaggio nella forma seguente: "usage-per-meter=BATTERY-USAGE-PER-METER". Dove il calcolo è (100 - percentuale attuale della batteria) diviso per la distanza percorsa finora in metri.

```csharp
var car = RemoteControlCar.Buy();
car.Drive();
car.Drive();
var tc = new TelemetryClient(car);
int serialNum = 4;
tc.GetBatteryUsagePerMeter(serialNum);
// => "usage-per-meter=5"

serialNum = 1;
tc.GetBatteryUsagePerMeter(serialNum);
// => "no data"
```
