# Istruzioni

In questo esercizio elaborerai delle righe di log.

Ogni riga di log è una stringa formattata così: `"[<LVL>]: <MESSAGE>"`.

Questi sono i diversi livelli di log:

- `TRC` (trace)
- `DBG` (debug)
- `INF` (info)
- `WRN` (warning)
- `ERR` (error)
- `FTL` (fatal)

Hai tre attività.

## 1. Analizza il livello di log

Definisci un enum `LogLevel` che ha sei elementi corrispondenti ai livelli di log sopra elencati.

- `Trace`
- `Debug`
- `Info`
- `Warning`
- `Error`
- `Fatal`

Poi, implementa il metodo (_static_) `LogLine.ParseLogLevel()` per analizzare il livello di log di una riga di log:

```csharp
LogLine.ParseLogLevel("[INF]: File deleted")
// => LogLevel.Info
```

## 2. Gestisci i livelli di log sconosciuti

Purtroppo, a volte alcune righe di log hanno un livello di log sconosciuto. Per gestire in modo controllato queste righe di log, aggiungi un elemento `Unknown` all'enum `LogLevel`, che deve essere restituito quando si analizza un livello di log sconosciuto:

```csharp
LogLine.ParseLogLevel("[XYZ]: Overly specific, out of context message")
// => LogLevel.Unknown
```

## 3. Converti una riga di log in formato breve

Il livello di log di una riga di log è piuttosto verboso. Per ridurre lo spazio su disco necessario per memorizzare le righe di log, è stato sviluppato un formato breve: `"[<ENCODED_LEVEL>]:<MESSAGE>"`.

Il livello di log codificato è una semplice mappatura da un livello di log a un numero:

- `Unknown` - `0`
- `Trace` - `1`
- `Debug` - `2`
- `Info` - `4`
- `Warning` - `5`
- `Error` - `6`
- `Fatal` - `42`

Implementa il metodo (_static_) `LogLine.OutputForShortLog()` che può restituire la riga di log in formato breve:

```csharp
LogLine.OutputForShortLog(LogLevel.Error, "Stack overflow")
// => "6:Stack overflow"
```
