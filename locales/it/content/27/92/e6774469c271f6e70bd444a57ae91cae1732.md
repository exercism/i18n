# Introduzione

Le mappe in Elixir sono la struttura dati per memorizzare informazioni in coppie chiave-valore. In altri linguaggi sono anche note come array associativi (PHP), hash (Perl 5, Raku) o dizionari (Python).

Le chiavi e i valori possono essere di qualsiasi tipo di dato, ma se la chiave è un atomo possiamo usare una sintassi abbreviata. Le mappe non garantiscono l'ordine delle loro voci quando vengono consultate o restituite.

## Forme letterali

Una mappa vuota si dichiara semplicemente con `%{}`. Se vogliamo aggiungere elementi a una mappa letterale, possiamo usare due forme:

```elixir
# If the key is an atom:
%{atom_key: 1}

# If the key is a different type:
%{1 => :atom_value}

# You can even mix these if the atom form comes second:
%{"first_form" => :a, atom_form: :b}
```

Anche se non esiste un formato canonico, scegli un modo coerente per rappresentare le coppie chiave-valore letterali.

## Funzioni del modulo Map

Elixir fornisce molte funzioni per lavorare con le mappe nel _modulo Map_. Alcune funzioni del _modulo Map_ richiedono che si passi loro una funzione _anonima_ che aiuti con la trasformazione della mappa.
