# Introduzione

Una tupla è un contenitore ordinato di valori. Come tutti i tipi di dato di Gleam, le tuple sono immutabili. Ogni elemento di una tupla può avere un tipo diverso dagli altri, e può persino essere un'altra tupla.

Le tuple si definiscono come valori separati da virgole tra `#(` e `)`: `#(1, 2.0, "Three")`.

```gleam
#("one", 2)      // Tuple pair (2 values)
#("one", 2, 3.0) // Tuple triplet (3 values)
```

Le tuple con la stessa lunghezza e gli stessi tipi (nello stesso ordine) si possono confrontare per uguaglianza.

```gleam
#(1, 2) == #(1, 2) // Same length, same types, same values, same order
// -> True

#(1, 2) == #(2, 1) // Same length, same types, same values, different order
// -> False

#(1, 2) == #(1, "2") // Same length, different types
// Compile error!

#(1, 2) == #(1, 2, 3) // Different length
// Compile error!
```

Ci sono tre modi per ottenere i valori contenuti in una tupla:

- Indicizzazione.
- Pattern matching con `let`.
- Pattern matching con `case`.

```gleam
let person = #("Jordan", 52)

// Option 1: Indexing
person.0 // -> "Jordan"
person.1 // -> 52

// Option 2: let
let #(name2, length2) = person
// -> name2 = "Jordan"
// -> length2 = 52

// Option 3: case
case person {
  #(name3, length3) -> {
    name3   // -> "Jordan"
    length3 // -> 52
  }
}
```

L'indicizzazione delle tuple si può usare nelle guardie delle espressioni `case`.

```gleam
pub fn is_18(person) {
  case person {
    _ if person.1 >= 18 -> True
    _ -> False
  }
}
```
