# Introduzione

La capacità di definire qualcosa in termini di se stesso si chiama ricorsione. In F#, la ricorsione si incontra più spesso nelle funzioni ricorsive, cioè funzioni che chiamano se stesse.

Una funzione ricorsiva deve avere almeno un _caso base_ e almeno un _caso ricorsivo_. Un _caso base_ restituisce un valore senza chiamare di nuovo la funzione. Un _caso ricorsivo_ chiama di nuovo la funzione, modificando l'input in modo che a un certo punto corrisponda al caso base.

Le funzioni ricorsive si definiscono come le funzioni normali, ma con il modificatore `rec`. Senza questo modificatore, una funzione _non_ può chiamare se stessa, e qualsiasi tentativo in tal senso produce un errore di compilazione. La ricorsione va quindi attivata esplicitamente.

```fsharp
let rec factorial x =
    // Base case
    if x = 1 then
        1
    // Recursive case
    else
        x * factorial (x - 1)
```

F# supporta anche i tipi ricorsivi tramite i tipi unione discriminata. In un tipo unione discriminata ricorsivo, uno o più casi fanno riferimento al tipo unione discriminata stesso nei loro dati. Come le funzioni ricorsive, i tipi ricorsivi devono avere un caso base. A differenza delle funzioni ricorsive, i tipi ricorsivi non usano la parola chiave `rec`.

```fsharp
type RussianDoll =
    | Doll                 // Base case
    | Layer of RussianDoll // Recursive case
```
