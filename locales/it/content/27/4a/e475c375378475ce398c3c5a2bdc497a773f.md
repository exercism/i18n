# Introduzione

In Go, `map` è un tipo di dato integrato che associa chiavi a valori.
In altri linguaggi di programmazione, potresti conoscere il concetto di `map` come dizionario, tabella hash, archivio chiave/valore o array associativo.

A livello sintattico, `map` si presenta così:

```go
map[KeyType]ElementType
```

È anche importante sapere che ogni chiave è unica: assegnare due volte la stessa chiave sovrascriverà il valore della chiave corrispondente.

Per creare una mappa, puoi fare così:

```go
  // With map literal
  foo := map[string]int{}
```

oppure

```go
  // or with make function
  foo := make(map[string]int)
```

Ecco alcune operazioni che puoi fare con una mappa:

```go
  // Add a value in a map with the `=` operator:
  foo["bar"] = 42
  // Here we update the element of `bar`
  foo["bar"] = 73
  // To retrieve a map value, you can use
  baz := foo["bar"]
  // To delete an item from a map, you can use
  delete(foo, "bar")
```

Se provi a recuperare il valore di una chiave che non esiste nella mappa, otterrai il valore zero del tipo di valore.
Questo può confonderti, soprattutto se il valore predefinito del tuo `ElementType` (per esempio, 0 per un int) è un valore valido.
Per verificare se una chiave esiste nella mappa, puoi usare

```go
  value, exists := foo["baz"]
  // If the key "baz" does not exist,
  // value: 0; exists: false
```
