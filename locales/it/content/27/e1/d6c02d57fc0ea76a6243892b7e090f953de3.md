# Introduzione

Una `string` in F# è un oggetto che rappresenta testo immutabile come sequenza di caratteri Unicode (lettere, cifre, punteggiatura e così via) e si definisce così:

```fsharp
let fruit = "Apple"
```

Le stringhe si manipolano chiamando i metodi della stringa oppure usando le funzioni del modulo `String`. Una volta costruita, una stringa non può più cambiare valore. Qualsiasi metodo o funzione che sembri modificarla in realtà ne restituisce una nuova.

Le stringhe si possono concatenare o formattare in diversi modi.
* Puoi usare l'operatore `+` per concatenare:
```fsharp
let sentence = "Apple" + " is a type of fruit."
```
* Puoi usare la funzione `sprintf` per formattare il testo: nel testo di formato ci sono dei segnaposto (`%s` per una `string`) e fornisci i valori come argomenti:
```fsharp
let sentence = sprintf "%s is a type of %s." "Apple" "fruit"
```
