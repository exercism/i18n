# Introduzione

Nel concetto `Vectors` abbiamo visto che un vettore può essere usato in un'espressione condizionale, dando un vettore logico.
A sua volta, questo può essere usato in funzioni come `all()` e `any()`.

```R
v <- c(4, 7, 10)
v >= 6
#> [1] FALSE  TRUE  TRUE
all(v > 6)
#> [1] FALSE    # not all elements match this condition
any(v > 6)
#> [1] TRUE     # at least one element matches
```

La tecnica è molto più potente di così.

## Sottoinsiemi di vettori

Si possono estrarre elementi selezionati di un vettore con un numero indice o con un vettore di indici:

```R
v <- 5:10
v
#> [1]  5  6  7  8  9 10
v[3] 
#> [1] 7
v[c(2, 4)]
#> [1] 6 8
```

In alternativa, usa un vettore logico per filtrare il vettore originale, ottenendo un sottoinsieme di elementi corrispondenti a un valore `TRUE`:

```R
v <- 1:3
bools <- c(FALSE, TRUE, TRUE)
v[bools]
#> [1] 2 3
```

Da lì è un piccolo passo generare il vettore booleano con un'espressione condizionale:

```R
bools <- v >= 2
bools
#> [1] FALSE  TRUE  TRUE

v[bools]
#> [1] 2 3

# simpler form
v[v >= 2]
#> [1] 2 3
```

## Trovare gli indici

La funzione `which()` prende un argomento booleano e restituisce un vettore di indici che danno `TRUE`.

```R
v
#> [1] 2 7 9

v[v > 5]  # returns values
#> [1]  7  9

which(v > 5) # returns indices
#> [1] 2 3
```

## Verificare se un elemento esiste

Le sezioni precedenti riguardavano la ricerca di elementi che soddisfano un certo criterio.

Se ti serve solo sapere se il vettore contiene un elemento specifico, si usa l'operatore `%in%`.

```R
3 %in% 1:5
#> [1] TRUE
7 %in% 1:5
#> [1] FALSE
```

È funzionalmente equivalente al codice seguente, ma molto più comodo:

```R
v <- 1:5
length(v[v == 3]) > 0
#> [1] TRUE
```
