# Istruzioni

Ellen sta creando un gioco in cui il giocatore deve combattere contro gli alieni.
Ha appena imparato la programmazione orientata agli oggetti (OOP) e non vede l'ora di sfruttare quello che l'uso delle `classes` potrebbe offrire al suo programma.

Con grande gioia di Ellen, ti sei offerto di aiutarla e lei ti ha affidato il compito di programmare gli alieni che il giocatore deve combattere.


## 1. Crea la classe `Alien`

Definisci la classe `Alien` con un costruttore che accetta due parametri `int`, `x` e `y`, e li assegna alle variabili membro `x_coordinate` e `y_coordinate`.
Inoltre ogni alieno partirà con un livello di salute di `3`, quindi anche la variabile membro `health` va inizializzata.

`health` deve essere una variabile membro privata.
Per permettere alle altre parti del programma di leggere le informazioni sulla salute, Ellen vuole un metodo `public` `get_health()` che restituisce un `int`.

```cpp
Alien alien{2, 0};
alien.x_coordinate;
// => 2
alien.y_coordinate;
// => 0
alien.get_health();
// => 3
```

Ora ogni alieno deve poter tenere traccia al proprio interno della propria posizione e della propria salute.

## 2. La funzione `hit`

Ellen vorrebbe che la `class` Alien avesse un metodo `hit` che, quando viene chiamato, decrementa di `1` la salute di un oggetto alieno.
Così può semplicemente chiamare `some_alien_instance.hit()` invece di dover cambiare a mano la salute di un alieno.
Assicurati che i punti salute non scendano sotto zero.
La funzione deve restituire `true`.
Ellen vuole introdurre gli scudi più avanti, e in quel caso la funzione restituirebbe `false` se lo scudo è attivo.

```cpp
Alien alien {0, 0};
alien.get_health();
// => 3 (Initial health value)

alien.hit(); // Decrements health by 1 point.
alien.get_health();
// => 2
```

## 3. La funzione `is_alive`

Ti rendi conto che, se la salute continua a diminuire, a un certo punto arriverà probabilmente a `0`.
Sarebbe una buona idea aggiungere un metodo `is_alive` che Ellen possa chiamare al volo per controllare se l'alieno è... beh... vivo. 😉
`some_alien_instance.is_alive()` deve restituire un booleano.

```cpp
alien.get_health();
// => 1
alien.is_alive();
// => true
alien.hit();
alien.get_health();
// => 0
alien.is_alive();
// => false
```

## 4. La funzione `teleport`

Nel gioco di Ellen gli alieni possono teletrasportarsi!
Dovrai scrivere un metodo `teleport` che accetta i valori `x_new` e `y_new` e modifica di conseguenza le coordinate dell'alieno.
Per ora la funzione deve restituire `true`.
Ellen vuole aggiungere bombe che bloccano il teletrasporto nei livelli successivi, e in quel caso la funzione restituirebbe `false` per i tentativi di teletrasporto falliti.

```cpp
alien.teleport(5, -4);
alien.x_coordinate;
// => 5
alien.y_coordinate;
// => -4
```

## 5. La funzione `collision_detection`

Se gli alieni possono essere colpiti da qualcosa, allora devono poter rilevare quando una collisione del genere può verificarsi.
Ellen ha bisogno di sapere se due alieni occupano le stesse coordinate.
La funzione `collision_detection()` accetta come argomento un altro oggetto alieno e restituisce un `bool`.

```cpp
Alien lrrr {3, 6};
Alien ndnd {-2, 12};
lrrr.collision_detection(ndnd);
// => false
ndnd.teleport(3, 6);
ndnd.collision_detection(lrrr);
// => true
```
