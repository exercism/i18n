# Introduzione

Le tuple sono un modo leggero per raggruppare un insieme fisso di dati di tipi arbitrari.
Le tuple possono avere un numero arbitrario di elementi.
Puoi accedere agli elementi tramite la destrutturazione.

```rust
fn main() {
    let tup: (u32, u64, bool) = (10, 20, true);
}

fn main() {
    let (x, y, z) = (500, 6, true);

    if y == 6 {
        println!("y is 6!");
    }
}
