# Normalizzazioni del representer

Il [representer per F#][representer] applica le seguenti normalizzazioni:

## Rimozione dei commenti

Tutti i commenti vengono rimossi.

### Prima

```fsharp
module Fake

(* Block comment
   on multiple lines *)

let message = "Hi" (* Block comment after code *)

// Double-slash comment on single line
let reply = "Yo" // Double-slash comment after code

/// <summary>This function adds two numbers</summary>
/// <param name="x">The first number</param>
/// <param name="y">The second number</param>
/// <returns>The first number added to the second number</param>
let add x y = x + y
```

### Dopo

```fsharp
module Fake

let message = "Hi"

let reply = "Yo"

let add x y = x + y
```

## Rimozione delle dichiarazioni di import

Tutte le dichiarazioni di import vengono rimosse.

### Prima

```fsharp
module Fake

open System
open System.IO

let message = "Hi"
```

### Dopo

```fsharp
module Fake

let message = "Hi"
```

## Formattazione del codice

Il codice viene formattato usando la [libreria fantomas][fantomas].
Questa formattazione segue la guida di stile di F#.
L'elenco completo delle trasformazioni applicate da fantomas si trova [qui][fantomas-formatting].

### Prima

```fsharp
module Fake

let  add ( birthDate  :  DateTime)  =
    birthDate.Add (    2.0)

type Volume =
| Liter of float
| USPint of float
| ImperialPint of float
```

### Dopo

```fsharp
module Fake

let add (birthDate: DateTime) =
    birthDate.Add(2.0)

type Volume =
    | Liter of float
    | USPint of float
    | ImperialPint of float
```

## Normalizzazione degli identificatori

Gli identificatori vengono normalizzati in un valore placeholder.

### Prima

```fsharp
module Fake

let foo x = x + 1
```

### Dopo

```fsharp
module PLACEHOLDER_1

let PLACEHOLDER_3 PLACEHOLDER_2 = PLACEHOLDER_2 + 1
```
