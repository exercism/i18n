# Istruzioni

Il dipartimento delle rivendicazioni della Isaac's Asteroid Exploration Co. ti ha incaricato di migliorare le prestazioni del suo sistema di rivendicazione dei terreni.

Ogni volta che un asteroide è pronto per lo sfruttamento, gli speculatori sono invitati a rivendicare il proprio appezzamento di terreno.
Il terreno dell'asteroide è diviso in appezzamenti rettangolari che non si sovrappongono.
Le dimensioni variano, ma tutti hanno i lati paralleli agli assi coordinati.
Gli speculatori rivendicano uno degli appezzamenti specificandone le coordinate.

Il tuo obiettivo è sviluppare un sistema performante per gestire la corsa alla terra che in passato ha causato il crash del sito web.

L'unità di misura è 100 metri, ma può essere ignorata in queste attività.

## 1. Definisci un punto

Definisci una `struct` per contenere le coordinate `x` e `y`.
Sono numeri interi non negativi piuttosto piccoli, quindi usa il tipo `UInt16`.

```julia-repl
julia> Coord(7, 3)
Coord(0x0007, 0x0003)  # unsigned integers display in hex format by default
```

## 2. Definisci un Plot

Poiché tutti gli appezzamenti devono essere rettangolari, con lati orizzontali e verticali, per definirli bastano due angoli opposti.

Implementa la struct `Plot`, che nel suo costruttore prende due struct Coord.

`Plot` deve essere una struct con parole chiave, con i campi `bottom_left` e `top_right`.

```julia-repl
julia> plot = Plot(bottom_left=Coord(10, 1), top_right=Coord(20, 2))
Plot(Coord(0x000a, 0x0001), Coord(0x0014, 0x0002))

julia> plot.top_right
Coord(0x0014, 0x0002)
```

## 3. Verifica se la tua rivendicazione è già stata registrata

C'è concorrenza per queste rivendicazioni, quindi prima che la tua rivendicazione venga accettata verrà confrontata con le rivendicazioni già presenti nel registro.

Implementa la funzione `is_claim_staked()` per determinare se una rivendicazione è già stata fatta.

```julia-repl
julia> claim = Plot(bottom_left=Coord(10, 1), top_right=Coord(20, 2));
julia> register = Set{Plot}();
julia> is_claim_staked(claim, register)
false
```

## 4. Gli speculatori possono rivendicare specificando un appezzamento identificato dalle coordinate dei suoi angoli

Implementa la funzione mutating `stake_claim!()` per consentire la registrazione di una rivendicazione.

Se la stessa rivendicazione è già stata fatta, restituisci `false`.

Se una nuova rivendicazione è possibile, aggiungila al registro e restituisci `true`.

```julia_repl
julia> claim = Plot(bottom_left=Coord(10, 1), top_right=Coord(20, 2));
julia> register = Set{Plot}();
julia> stake_claim!(claim, register)
true
```

## 5. Trova la lunghezza del lato più lungo di un appezzamento.

Implementa la funzione `get_longest_side()` per ottenere il lato più lungo (orizzontale o verticale) di una rivendicazione.

```julia-repl
claim = Plot(bottom_left=Coord(10, 1), top_right=Coord(20, 2));

julia> get_longest_side(claim)
0x000a
```

## 6. Trova l'appezzamento rivendicato che ha il lato più lungo, a fini di ricerca

Implementa la funzione `get_claim_with_longest_side()` per esaminare tutte le rivendicazioni registrate e restituire quella o quelle con il lato più lungo.

```julia-repl
julia> plot1 = Plot(bottom_left=Coord(5, 3), top_right=Coord(10, 5));
julia> plot2 = Plot(bottom_left=Coord(0, 0), top_right=Coord(3, 3));
julia> register = Set{Plot}([plot1, plot2]);

julia> get_claim_with_longest_side(register)
Plot(Coord(0x0005, 0x0003), Coord(0x000a, 0x0005))
```

Restituisci uno o più Plot come `Set`, con un solo elemento se c'è un unico appezzamento più lungo, più elementi in caso di parità.
