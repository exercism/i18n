# Intervalli

Gli [intervalli][range] rappresentano un intervallo tra due valori.
I tipi più comuni che supportano gli intervalli sono `Int`, `Char` e `String`.
Si possono usare per molte cose: creare rapidamente una collezione, estrarre sottostringhe, verificare se un valore è compreso in un intervallo e iterare.
Si creano con l'operatore di intervallo `..` o `...` (inclusivo ed esclusivo, rispettivamente).

```crystal
1..5  # A range containing 1, 2, 3, 4, 5
1...5 # A range containing 1, 2, 3, 4
```

Il motivo per cui esistono due operatori di intervallo è poter creare intervalli che includono o escludono il valore finale. Questo è utile, per esempio, quando si lavora con indici che partono da zero.

Gli intervalli si possono creare anche con l'inizializzatore di `Range`.

```crystal
Range.new(1, 5) # A range containing 1, 2, 3, 4, 5
```

~~~~exercism/note
Quando crei un intervallo in Crystal con gli operatori `..` o `...` e vuoi chiamare un metodo sull'intervallo, devi racchiudere l'intervallo tra parentesi.
Altrimenti il metodo verrebbe chiamato sul secondo argomento dell'operatore di intervallo.

```crystal
(1..5).size # => 5
1..5.size # => Error: undefined method 'size' for Int32
```
~~~~

## Estrarre sottostringhe

Per estrarre una sottostringa da una stringa puoi usare l'operatore di intervallo, creando un intervallo con l'indice iniziale e quello finale della sottostringa.

```crystal
"Hello World"[0..4] # => "Hello"
"Hello World"[6..10] # => "World"
```

Puoi anche usare indici negativi per ottenere la sottostringa a partire dalla fine della stringa.

```crystal
"Hello World"[-5..-1] # => "World"
"Hello World"[6..-4] # => "Wo"
```

## Metodi degli intervalli

Gli intervalli hanno una serie di metodi con cui puoi lavorarci.
Per esempio, questi metodi permettono di ottenere la somma di tutti i valori dell'intervallo o di verificare se l'intervallo contiene un valore.

| Metodo                  | Descrizione                                                             | Esempio                         |
|-------------------------|-------------------------------------------------------------------------|---------------------------------|
| [`sum`][sum]            | Restituisce la somma di tutti i valori dell'intervallo                  | `(1..5).sum # => 15`            |
| [`size`][size]          | Restituisce la dimensione dell'intervallo                               | `(1..5).size # => 5`            |
| [`includes?`][indludes] | Restituisce `true` se l'intervallo contiene il valore indicato, altrimenti `false` | `(1..5).includes?(3) # => true` |

## Intervalli senza fine e senza inizio

Un intervallo può essere senza fine o senza inizio.
In un intervallo senza fine o senza inizio il valore iniziale o finale è `nil`, ma `nil` si può omettere quando definisci l'intervallo.

Usare intervalli senza inizio e senza fine è utile quando vuoi, per esempio, estrarre una sottostringa dall'inizio o fino alla fine.

```crystal
"Hello World"[0..] # => "Hello World"
"Hello World"[4..] # => "o World"
"Hello World"[..5] # => "Hello"
```

~~~~exercism/caution
Se non lo usi su una collezione, un intervallo senza fine può generare una sequenza senza fine, se non lo usi con cautela.
~~~~

## Intervalli di caratteri

I caratteri si possono usare negli intervalli e permettono di ottenere un intervallo di caratteri compresi tra due caratteri.
Per esempio, è comodo quando vuoi ottenere l'alfabeto.

```crystal
'a'..'z' # A range containing ['a', 'b', 'c', ..., 'z']
```

## Intervalli di stringhe

Anche le stringhe si possono usare negli intervalli, il che permette di ottenere un intervallo di stringhe comprese tra due stringhe.
Il comportamento però è un po' diverso da quello di `Char` quando in un intervallo di stringhe si usano più caratteri.
Con intervalli di stringhe più complessi il comportamento può diventare confuso, quindi fai attenzione.

```crystal
("aa".."az") # A range containing ["aa", "ab", "ac", ..., "az"]
```

## Oggetti personalizzati negli intervalli

~~~~exercism/advanced
Crystal ti permette di usare oggetti personalizzati negli intervalli.
Per farlo, l'oggetto deve implementare quanto segue:

- includere il modulo `Comparable`
- il metodo `succ`
- il metodo `<=>`

Questi metodi permettono all'intervallo di iterare sull'oggetto e di confrontare gli oggetti contenuti nell'intervallo.

```crystal
class Foo
  include Comparable(Foo)

  getter value

  def initialize(@value : Int32)
  end

  def succ
    Foo.new(value + 1)
  end

  def <=>(other : Foo)
 value <=> other.value
  end
end

Foo.new(1)..Foo.new(5)
# => #<Foo:0x7f3552bebe70 @value=1>, #<Foo:0x7f3552bebe50 @value=2>, #<Foo:0x7f3552bebe40 @value=3>, #<Foo:0x7f3552bebe30 @value=4>, #<Foo:0x7f3552bebe20 @value=5>
```
~~~~
