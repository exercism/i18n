# Introduzione

Un [`List`][lists] in Elm è una collezione immutabile di zero o più valori dello stesso tipo.

Gli array si possono definire come segue:

```elm
empty = []
singleValue = [ 5 ]
threeValues = [ "a", "b", "c" ]
```

Il modo più comune per aggiungere un elemento a un array è tramite l'operatore `::` (cons):

```elm
twoToFour = [ 2, 3, 4 ]
oneToFour = 1 :: twoToFour --> [ 1, 2, 3, 4 ]
```

Gli array si manipolano con funzioni e operatori definiti nel modulo [`List`][list-module] o con il [pattern matching][list-destructuring]

```elm
describe : List String -> String
describe list =
    case list of
        [] ->
            "Empty list"

        [ "hello" ] ->
            "Singleton list with: hello"

        x :: xs ->
            "Non-empty list with head: " ++ x

describe []                   --> "Empty list"
describe [ "hello" ]          --> "Singleton list with: hello"
describe [ "hello", "world" ] --> "Non-empty list with head: hello"
```
