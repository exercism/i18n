# Introduzione

## Stringhe

Una `String` in Java è un oggetto che rappresenta testo immutabile come sequenza di caratteri Unicode (lettere, cifre, punteggiatura, ecc.).
Per definire un'istanza di `String` si usano le doppie virgolette:

```java
String fruit = "Apple";
```

Le stringhe si manipolano chiamando i metodi della stringa.
Una volta che una stringa è stata costruita, il suo valore non può mai cambiare.
Qualsiasi metodo che sembri modificare una stringa in realtà restituisce una nuova stringa.
La classe `String` fornisce alcuni metodi _statici_ per trasformare le stringhe.
