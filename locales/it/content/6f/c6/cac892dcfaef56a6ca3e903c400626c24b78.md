# Suggerimenti

## 1. Creare la tabella dei punteggi più alti

- La tabella dei punteggi più alti deve essere una tabella hash.
- Puoi creare una tabella hash con `make-hash-table`.

## 2. Aggiungere un giocatore alla tabella

- Per aggiungere una coppia chiave/valore a una tabella hash usa `(setf (gethash key table) value)`

## 3. Impostare il punteggio di un giocatore

- Impostare il punteggio di un giocatore è quasi identico ad aggiungere il giocatore alla tabella.
- Per aggiungere una coppia chiave/valore a una tabella hash usa `(setf (gethash key table) value)`

## 4. Ottenere un punteggio dalla tabella

- Usa `gethash` per ottenere il valore di una chiave dalla tabella hash.
- `gethash` ha un terzo argomento opzionale, cioè il valore da usare se la chiave non viene trovata.

## 5. Rimuovere un giocatore dalla tabella

- Usa `remhash` per rimuovere una chiave dalla tabella.
