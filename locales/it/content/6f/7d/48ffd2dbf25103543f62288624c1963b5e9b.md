# Introduzione

Dal [manuale][man-types]

> jq supporta lo stesso insieme di tipi di dato di JSON: numeri, stringhe, booleani, array, oggetti (che nel gergo di JSON sono hash con sole chiavi di tipo stringa) e «null».

Concentriamoci sui **numeri**.

## Numeri e operatori numerici

Tutti i numeri, interi o no, sono numeri in virgola mobile a doppia precisione IEEE754.
Questo ci limita a 53 bit di precisione.

Con i numeri si possono usare i soliti operatori:

- aritmetici: `+`, `-`, `*`, `/`, `%`
- di confronto: `==`, `!=`, `<`, `<=`, `>=`, `>`
- le [funzioni matematiche][man-math] standard

  Per le funzioni a un input, passa il valore alla funzione tramite una pipe

  ```sh
  $ jq -n '(1 | atan) * 4'
  3.141592653589793
  ```

  Per le funzioni a due input, la funzione ignora l'input e si aspetta che gli input
  vengano passati come parametri (ricorda: i parametri si separano con il punto e virgola)

  ```sh
  $ jq -n 'pow(2; 10)'
  1024
  ```

  Il separatore degli argomenti di una funzione è il punto e virgola, non la virgola.

## Altre espressioni `jq`

Per risolvere l'esercizio, dovrai conoscere le espressioni condizionali.

### Espressioni condizionali

`jq` usa un'[espressione `if-then-else`][if-then-else] per le **espressioni condizionali**.
Essendo un'_espressione_, si inserisce in una pipeline.

La sintassi è: `if CONDITION then TRUE_EXPR else FALSE_EXPR end`.

La clausola `else` è opzionale.

```jq
42 | if . < 33 then "small" else "larger" end
# => "larger"
```

Per condizioni aggiuntive si usa `elif`

```jq
42 | if . < 33 then "small"
     elif . < 67 then "medium"
     else "large"
     end
# => "medium"
```
