# Suggerimenti

## Generale

- Leggi la documentazione sugli [insiemi][set]
- Potrebbe tornare utile anche la documentazione sugli [array][lists]

## 1. Inizia una collezione

- La funzione di `Set` più adatta è [`Set.singleton`][singleton]

## 2. Fai crescere la collezione

- Usa la [funzione `Set.insert`][insert]
- Usa la [funzione `Set.member`][member]

## 3. Inizia a scambiare

- Usa la [funzione `Set.member`][member]
- Usa la [funzione `Set.insert`][insert]
- Usa la [funzione `Set.remove`][remove]

## 4. Ce ne può essere solo uno per tipo

- Un `Set` ha la proprietà di contenere solo valori unici
- Usa la [funzione `Set.fromList`][fromList]
- Usa la [funzione `Set.toList`][toList]
- È garantito che `Set.toList` restituisca un array ordinato

## 5. Le carte che non hanno

- Usa la [funzione `Set.diff`][diff]
- Usa la [funzione `Set.size`][size]

## 6. Le carte che hanno tutti

- Usa le [funzioni `List.foldl` o `List.foldr`][fold]
- Usa il pattern matching sull'array per distinguere tra array vuoti e non vuoti
- Usa la [funzione `Set.intersect`][intersect]
- Usa la [funzione `Set.toList`][toList]
- È garantito che `Set.toList` restituisca un array ordinato

## 7. Tutte le carte

- Usa le [funzioni `List.foldl` o `List.foldr`][fold]
- Usa [`Set.empty`][empty] come accumulatore
- Usa la [funzione `Set.union`][union]
- Usa la [funzione `Set.size`][size]

## 8. Uno shiny per vincere

- Usa la [funzione `Set.partition`][partition]
- Usa la [funzione `String.startsWith`][startsWith]
- Usa la [funzione `Set.toList`][toList]
- È garantito che `Set.toList` restituisca un array ordinato
