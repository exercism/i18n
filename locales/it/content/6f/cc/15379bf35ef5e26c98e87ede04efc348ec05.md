# Introduzione

Di norma, una definizione di collezione include un segnaposto tra parentesi angolari, spesso T per convenzione. Una collezione di questo tipo si chiama tipo generico. Questo permette a chi usa la collezione di specificare che tipo di elementi memorizzare al suo interno. Nel codice di esempio qui sopra stiamo istanziando un array di stringhe.

Per rendere **generica** una classe o una funzione si usa l'attributo `@:generic`. Questo fa sì che il compilatore identifichi la classe o la funzione come generiche:

```haxe
@:generic
class MyValue<T> {
  public var value:T;

  public function new(value:T) {
    this.value = value;
  }
}

var a = MyValue<String>("Hello");
trace(a.value); // Hello
```
