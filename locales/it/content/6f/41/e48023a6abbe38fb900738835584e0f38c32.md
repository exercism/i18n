# Installazione

## Installare .NET

Il track F# si basa sulla piattaforma [.NET](https://dotnet.microsoft.com/learn/dotnet/what-is-dotnet), che funziona su Windows, Linux e macOS. Per compilare i progetti .NET puoi usare l'interfaccia a riga di comando (CLI) di .NET. Questa CLI fa parte dell'SDK .NET, che puoi installare seguendo le [istruzioni di installazione](https://dotnet.microsoft.com/download). Nota: il track F# richiede una versione dell'SDK pari o superiore alla 8.0.

Dopo aver completato l'installazione, puoi verificare se la CLI è stata installata correttamente eseguendo questo comando in un terminale:

```bash
dotnet --version
```

Se l'output è una versione maggiore o uguale a `8.0.100`, l'SDK .NET è stato installato correttamente.

## Usare un IDE

Se vuoi un'esperienza di editing più completa, probabilmente ti conviene usare un IDE. Questi sono gli IDE più diffusi che supportano la compilazione di progetti .NET:

- [Visual Studio 2022](https://www.visualstudio.com/downloads/)
- [Visual Studio Code](https://code.visualstudio.com/download) con l'[estensione Ionide-fsharp](https://marketplace.visualstudio.com/items?itemName=Ionide.Ionide-fsharp)
- [Visual Studio for Mac](https://www.visualstudio.com/vs/visual-studio-mac/)
- [Project Rider](https://www.jetbrains.com/rider/download/)

Nota: poiché il formato dei progetti .NET è molto diverso da quello delle versioni precedenti, gli IDE più vecchi (come Visual Studio 2015) non sono supportati.
