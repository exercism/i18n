# Introduzione

In JavaScript, un array è una struttura simile a una lista, senza lunghezza fissa, che può contenere qualsiasi tipo di valore primitivo o di oggetto, anche di tipi misti.

Per creare un array, aggiungi gli elementi tra parentesi quadre (`[]`).
Per leggere dall'array, metti l'indice tra parentesi quadre (`[]`) dopo l'identificatore.
Gli indici di un array partono da zero.

Ad esempio:

```javascript
const numbers = [1, 'two', 3, 'four'];
numbers[2];
// => 3
```

Per ottenere il numero di elementi contenuti in un array, usa la proprietà `length`:

```javascript
const numbers = [1, 'two', 3, 'four'];
numbers.length;
// => 4
```

Per modificare un elemento dell'array, assegni un valore in corrispondenza dell'indice:

```javascript
const numbers = [1, 'two', 3, 'four'];
numbers[0] = 'one';
numbers;
// => ['one', 'two', 3, 'four']
```

## Metodi

Alcuni dei [metodi][mdn-array] disponibili su ogni oggetto Array si possono usare per aggiungere o rimuovere elementi dall'array.
Ecco quelli da tenere presenti mentre lavori su questo esercizio:

### push

Un `value` può essere _aggiunto_ alla fine di un array usando `.push(value)`.
Il metodo restituisce la nuova lunghezza dell'array.

```javascript
const numbers = [1, 'two', 3, 'four'];
numbers.push(5); // => 5
numbers;
// => [1, 'two', 3, 'four', 5]
```

### pop

L'_ultimo_ `value` può essere _rimosso_ da un array usando `.pop()`.
Il metodo restituisce il valore rimosso.
La lunghezza dell'array diminuirà per effetto di questa modifica.

```javascript
const numbers = [1, 'two', 3, 'four'];
numbers.pop(); // => four
numbers;
// => [1, 'two', 3]
```

### shift

Il _primo_ `value` può essere _rimosso_ da un array usando `.shift()`.
Il metodo restituisce il valore rimosso.
La lunghezza dell'array diminuirà per effetto di questa modifica.

```javascript
const numbers = [1, 'two', 3, 'four'];
numbers.shift(); // => 1
numbers;
// => ['two', 3, 'four']
```

### unshift

Un `value` può essere _aggiunto_ all'inizio di un array usando `.unshift(value)`.
Il metodo restituisce la nuova lunghezza dell'array.

```javascript
const numbers = [1, 'two', 3, 'four'];
numbers.unshift('one'); // => 5
numbers;
// => ['one', 1, 'two', 3, 'four']
```

### splice

Un `value` in corrispondenza di uno `index` specifico può essere _rimosso_ da un array usando `.splice(index, 1)`.
Il metodo restituisce l'elemento o gli elementi rimossi.

```javascript
const numbers = [1, 'two', 3, 'four'];
numbers.splice(2, 1, 'one'); // => [3]
numbers;
// => [1, 'two', 'one', 'four']
```

~~~exercism/advanced
Questi metodi sono più potenti di quanto descritto:

- Sia `push` che `unshift` permettono di aggiungere più valori in una volta sola, passando altri argomenti.
  Non è necessario per completare questo esercizio.
- Splice può rimuovere più valori aumentando il secondo argomento.
  Non è necessario per completare questo esercizio.
- Splice può anche aggiungere più valori passandoli come argomenti dopo il `deleteCount`.
  Si può usare per sostituire valori o inserirne nel mezzo di un array (ad esempio rimuovendo 0 elementi).
  Non è necessario per completare questo esercizio.
~~~
