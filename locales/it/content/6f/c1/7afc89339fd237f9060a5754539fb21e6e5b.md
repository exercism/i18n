# Installazione

## Requisiti

* Una CPU x86 a 64 bit
* Un compilatore C moderno
* Lo strumento di build Make
* Il Netwide Assembler (NASM)

Tieni presente che questa traccia supporta solo la convenzione di chiamata dell'ABI System V AMD64. Chi usa Windows dovrà installare il Windows Subsystem for Linux (WSL) oppure configurare una macchina virtuale Linux.

## Linux

Installa il software richiesto usando il gestore di pacchetti del tuo sistema:

* Ubuntu, Debian: `$ sudo apt-get install gcc make nasm`
* Fedora: `$ sudo dnf install gcc make nasm`
* CentOS, RHEL: `$ sudo yum install gcc make nasm`
* Arch Linux: `$ sudo pacman -S gcc make nasm`
* OpenSUSE: `$ sudo zypper install gcc make nasm`

## macOS

Installa gli Xcode Command Line Tools:

```bash
$ xcode-select --install
```

Installa NASM con [Homebrew](http://brew.sh/):

```bash
$ brew install nasm
```

## Windows

Per installare WSL, consulta https://docs.microsoft.com/en-us/windows/wsl/install-win10.
