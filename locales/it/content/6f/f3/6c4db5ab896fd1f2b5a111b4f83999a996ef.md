# Introduzione

## Valori booleani

In Java i valori booleani sono rappresentati dal tipo `boolean`, i cui valori possono essere `true` oppure `false`.

Java supporta tre operatori booleani:  

- `!` (NOT): nega il valore booleano  
- `&&` (AND): prende due valori booleani e restituisce `true` se sono entrambi `true`
- `||` (OR): restituisce `true` se almeno uno dei due valori booleani è `true`

### Esempi

```java
!true // => false
!false // => true
true && false // => false
true && true // => true
false || false // => false
false || true // => true
```
