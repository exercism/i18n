# Installazione

## Windows (consigliato)

Stai usando un sistema operativo Windows?

Premi `Windows Key`, digita `cmd` e premi `enter`.

> Batch è già installato sul tuo sistema se il tuo sistema operativo è Windows.

Se usi un sistema operativo diverso, puoi installare Batch seguendo le istruzioni riportate di seguito.

## Mac OS

1. Gatekeeper non deve essere impostato per bloccare i pacchetti non firmati.
2. Apri l'applicazione Terminal.
3. Esegui il seguente comando per installare Batch:

```bash
brew install --cask --no-quarantine wine-stable
```

## Ubuntu

1. Se il tuo sistema è a 64 bit, abilita l'architettura a 32 bit (se non l'hai già fatto):

```bash
sudo dpkg --add-architecture i386
```

2. Aggiungi il repository WineHQ:

```bash
sudo mkdir -pm755 /etc/apt/keyrings
sudo wget -O /etc/apt/keyrings/winehq-archive.key https://dl.winehq.org/wine-builds/winehq.key
sudo apt update
```

3. Installa WineHQ:

```bash
sudo apt install --install-recommends winehq-stable
```

## Fedora

1. Abilita il repository Wine:

```bash
# Fedore 39
dnf config-manager --add-repo https://dl.winehq.org/wine-builds/fedora/39/winehq.repo

# Fedora 40
dnf config-manager --add-repo https://dl.winehq.org/wine-builds/fedora/40/winehq.repo
```

2. Installa WineHQ:

```bash
dnf install winehq-stable
```
