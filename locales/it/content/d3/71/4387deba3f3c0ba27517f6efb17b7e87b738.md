# Introduzione

Pyret ha due valori booleani primitivi distinti, `true` e `false`.
Questi due valori indicano se un'affermazione o una condizione è valida o meno.

```pyret
"a" == "a" # true
"a" == "b" # false
```

Pyret fornisce gli operatori `and` e `or` che possono combinare valori booleani.

L'operatore and restituisce true se entrambi i lati sono true e false in tutte le altre combinazioni.

```pyret
true and true # true
true and false # true
false and true # false
false and false # false
```

L'operatore or restituisce true se almeno un lato è true e false se entrambi i lati sono false.

```pyret
true or true # true
true or false # true
false or true # true
false or false # false
```

`not()` è una funzione integrata che inverte true in false o false in true.

```pyret
not(true) # false
not(false) # true
```
