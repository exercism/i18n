# Introduzione

## Le espressioni `use`

In Gleam è comune scrivere e usare funzioni di ordine superiore, cioè funzioni che accettano altre funzioni come argomenti. A volte, quando si usano molte funzioni di ordine superiore insieme, il codice può diventare difficile da leggere, con molti livelli di indentazione.

Per esempio, ecco una funzione che chiama diverse funzioni che restituiscono `Result(Int, Nil)` e somma i valori se tutte e quattro hanno successo.

```gleam
import gleam/result

pub fn main() -> Result(Int, Nil) {
  result.try(function1(), fn(a) {
    result.try(function2(), fn(b) {
      result.try(function3(), fn(c) {
        result.try(function4(), fn(d) {
          Ok(a + b + c + d)
        })
      })
    })
  })
}
```

Le espressioni `use` di Gleam ci permettono di scrivere questo codice senza l'indentazione, rendendolo spesso più facile da leggere.

```gleam
import gleam/result

pub fn main() -> Result(Int, Nil) {
  use a <- result.try(function1())
  use b <- result.try(function2())
  use c <- result.try(function3())
  use d <- result.try(function4())
  Ok(a + b + c + d)
}
```

Un'espressione `use` raccoglie tutte le istruzioni che seguono nel blocco e le passa come funzione di callback, come argomento finale, alla chiamata di funzione. Le variabili tra la parola chiave `use` e il simbolo `<-` sono i nomi degli argomenti che verranno passati alla funzione di callback.

```gleam
// This use expression
use a <- function(1, 2)
io.println("Hello!")
a

// Is equivalent to this normal function call
function(1, 2, fn(a) {
  io.println("Hello!")
  a
})
```

La funzione di callback può accettare un numero qualsiasi di argomenti, o anche nessuno.

```gleam
use a, b, c, d <- call_4_function()

use <- call_0_function()
```

Non ci sono requisiti speciali per creare una funzione che possa essere chiamata con un'espressione `use`, se non quello di accettare una funzione di callback come argomento finale.

```gleam
pub fn call_twice(function: fn() -> t) -> #(t, t) {
  let first = function()
  let second = function()
  #(first, second)
}
```

Le espressioni `use` di Gleam sono una funzionalità molto potente, che si può applicare a molti problemi, ma se usate troppo possono rendere il codice difficile da leggere. In genere è preferibile usare la normale sintassi di chiamata di funzione e ricorrere alle espressioni `use` solo quando rendono il codice più facile da leggere.
