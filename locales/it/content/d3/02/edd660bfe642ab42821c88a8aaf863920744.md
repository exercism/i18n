# Introduzione

I metodi possono avere un parametro varargs, che permette a chi chiama di specificare zero o più argomenti come se fossero parametri normali. Il metodo riceverà questi argomenti in un unico array.

Per trasformare un parametro in un parametro varargs, aggiungi la parola chiave `params` alla dichiarazione del parametro:

```csharp
public static void PrintNumbers(params int[] numbers)
{
    foreach (var number in numbers)
    {
        Console.Write(number)
    }
}

// No values for a varags parameter is allowed
PrintNumbers();

PrintNumbers(1);
// => 1

PrintNumbers(1, 2, 3);
// => 123
```
