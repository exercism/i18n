# Informazioni

Il tipo booleano in Lua ha i due valori booleani tradizionali: `true` e `false`. Questi valori possono essere assegnati a una variabile, combinati con gli operatori logici (`and`, `or`, `not`) e usati nei test condizionali (ad esempio nelle strutture di controllo).

```lua
local is_true = true
local is_false = false

true and true  --> true
true and false --> false
false or true  --> true
false or false --> false
not false      --> true
not true       --> false

-- prints 0
if is_true == true then
  print(0)
else
  print(1)
end
```

I test condizionali e gli operatori logici considerano sia il `false` booleano sia `nil` come falsi, e qualsiasi altro valore come vero.
```lua
1 and 2          --> 2
nil and 2        --> nil
false and 2      --> false
1 or 2           --> 1
false or 'hello' --> "hello"
nil or false     --> false
```

Sia `and` che `or` usano la *valutazione a cortocircuito*, il che significa che valutano il loro secondo operando solo quando necessario. Tutte le operazioni vengono valutate secondo la [precedenza degli operatori](https://www.lua.org/manual/5.4/manual.html#3.4.8), dove `not` viene valutato prima di `and` e `or`.

Dato che solo `false` e `nil` sono considerati falsi e tutto il resto è vero, un'espressione idiomatica comune in Lua è:
```lua
x = x or y
```

Questo è equivalente a:
```lua
if not x then
  x = y
end
```

È abbastanza comune usarlo nelle funzioni per assegnare un valore predefinito se un parametro non ha valore (è `nil`):
```lua
local function hello(name)
  name = name or "World"
  print("Hello " .. name)
end

hello()       --> "Hello World"
hello('Mars') --> "Hello Mars"
```
