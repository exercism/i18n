# Istruzioni

Mentre ti prepari a cuocere dei biscotti per i tuoi amici, ti rendi conto di dover convertire alcune delle misure usate nella ricetta. Conoscendo soltanto il sistema metrico decimale, devi trovare un modo per convertire le comuni misure di cucina statunitensi in millilitri (mL) per tua comodità.

Usa questa tabella di conversione per la soluzione:

| Unità da convertire | volume | in millilitri (mL) |
| --------------- | ------ | ------------------- |
| mL              | 1      | 1                   |
| tazza americana          | 1      | 240                 |
| oncia liquida americana  | 1      | 30                  |
| cucchiaino americano     | 1      | 5                   |
| cucchiaio americano   | 1      | 15                  |

Dato che sei un programmatore di talento in formazione, decidi di usare i millilitri come unità di transizione per facilitare la conversione da qualsiasi unità elencata a qualsiasi altra (anche a se stessa).

## 1. Ottenere la componente numerica da una coppia di volume

Implementa la funzione `KitchenCalculator.get_volume/1`. Data una tupla coppia di volume, deve restituire solo la componente numerica.

```elixir
KitchenCalculator.get_volume({:cup, 2.0})
# => 2.0
```

## 2. Convertire la coppia di volume in millilitri

Implementa la funzione `KitchenCalculator.to_milliliter/1`. Data una tupla coppia di volume, deve convertire il volume in millilitri usando la tabella di conversione.

Usa più clausole di funzione e il pattern matching per creare le funzioni per ogni unità. Gli atom usati per indicare ciascuna unità sono: `:cup`, `:fluid_ounce`, `:teaspoon`, `:tablespoon`, `:milliliter`. Restituisci il risultato della conversione racchiuso in una tupla.

```elixir
KitchenCalculator.to_milliliter({:cup, 2.5})
# => {:milliliter, 600.0}
```

## 3. Convertire una coppia di volume espressa in millilitri in un'altra unità

Implementa la funzione `KitchenCalculator.from_milliliter/2`. Data una tupla coppia di volume e l'unità desiderata, deve convertire il volume nell'unità desiderata usando la tabella di conversione.

Usa più clausole di funzione e il pattern matching per creare le funzioni per ogni unità. Gli atom usati per indicare ciascuna unità sono: `:cup`, `:fluid_ounce`, `:teaspoon`, `:tablespoon`, `:milliliter`

```elixir
KitchenCalculator.from_milliliter({:milliliter, 1320.0}, :cup)
# => {:cup, 5.5}
```

## 4. Convertire da qualsiasi unità a qualsiasi unità

Implementa la funzione `KitchenCalculator.convert/2`. Data una tupla coppia di volume e l'unità desiderata, deve convertire il volume dato nell'unità desiderata.

```elixir
KitchenCalculator.convert({:teaspoon, 9.0}, :tablespoon)
# => {:tablespoon, 3.0}
```
