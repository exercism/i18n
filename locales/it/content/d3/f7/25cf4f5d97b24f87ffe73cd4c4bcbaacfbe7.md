# Informazioni

ColdFusion (CFML) è un linguaggio di scripting per la JVM la cui sintassi è simile a quella di C o JavaScript. 
Viene compilato JIT in byte code che gira sulla JVM, ma è dinamico e debolmente tipizzato, rendendolo veloce e facile da sviluppare. 
CF è un linguaggio multi-paradigma, che supporta la OO classica e la programmazione funzionale.

CFML ha anche un linguaggio di templating basato su tag integrato che lo rende ideale per le applicazioni web. 
Viene eseguito in un container J2EE con molte librerie incluse che lo rendono molto produttivo senza dover installare molti pacchetti. 
CFML ha supporto nativo per file zip, generazione di PDF ed Excel, e-mail, FTP, HTTP, file system S3, librerie di sicurezza ESAPI, driver JDBC, JSON e API REST.  

CFML può anche sfruttare qualsiasi progetto Java inserendo i jar nel progetto e istanziando direttamente oggetti Java nel codice. 
Puoi saperne di più sulla sintassi di base e sui tipi di dati di prima classe in questa guida: [Modern ColdFusion (CFML) in 100 Minutes](https://modern-cfml.ortusbooks.com/)
