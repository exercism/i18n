# Introduzione

## Tipi annidati

I tipi di C# possono essere definiti all'interno dello scope di una classe o di uno struct. Il tipo che li contiene fornisce una sorta di namespace. Si accede al tipo tramite il tipo che lo contiene, con la sintassi del punto.

```csharp
class Outer
{
    public interface IInner {}
    public enum EInner {}
    public class CInner {}
    public struct SInner {}
}

var outer = new Outer();
var inner = new Outer.CInner();
```

Puoi impostare i livelli di accesso per i tipi annidati.

I membri privati del tipo esterno sono nello scope dei membri del tipo annidato, ma non viceversa.
