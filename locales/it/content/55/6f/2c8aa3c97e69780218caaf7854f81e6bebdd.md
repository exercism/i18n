# Array

Gli array in PHP sono mappe ordinate.
Una mappa è una struttura dati che associa una chiave a un valore.
Gli array sono versatili e possono essere trattati come un array lineare (come in `C` o `Java`), una lista [vettore], una tabella hash, un dizionario, una collezione, uno stack o una coda.

Una chiave è opzionale, ma se viene specificata deve essere di tipo `int` o `string`.
Quando non viene fornita una chiave, PHP utilizza per impostazione predefinita chiavi intere in ordine crescente, a partire da `0`.

```php
$no_keys = ["my", "first", "array"];
$integer_keys = [0 => "my", 1 => "first", 2 => "array"];

$no_keys == $integer_keys // => equal returns true
$no_keys === $integer_keys // => strictly equal returns true
```

Un array può memorizzare valori di tutti i tipi.
Ogni valore può avere un tipo diverso.

```php
$my_arr = [
  1,
  "second",
  new \DateTimeImmutable()
];
```

## Usare gli array

Gli array possono essere dichiarati come letterali (scritti nel codice, come fatto sopra) oppure creati e manipolati tramite funzioni.

```php
$my_empty_arr = [];

// or
$my_empty_arr = array(); // => []

// or
$letters = mb_str_split("Hello"); // => ["H", "e", "l", "l", "o"] 
```

Accedi, assegna e aggiungi valori usando l'operatore di indice:

```php
$prime_numbers = [2, 3, 5, 6];

$prime_numbers[3] = 7; // replace 6 with 7

$prime_numbers[] = 11; // array now contains [2, 3, 5, 7, 11]
```

Itera su un array usando foreach:

```php
$names = ["Ani", "Jack", "Rami"]

// Iterate just the values
foreach ($names as $name) {
  echo $name;
}

// Iterate keys and values
foreach ($names as $index => $name) {
  echo "$index => $name";
}
```
