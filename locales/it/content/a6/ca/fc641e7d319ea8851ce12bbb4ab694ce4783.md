# Introduzione

I simboli in Common Lisp sono valori speciali che possono puntare ad altri valori o, nel caso delle _parole chiave_, a se stessi.
Quando Lisp valuta i simboli, questi vengono sostituiti con i valori a cui puntano:

```lisp
foo  ; => <whatever-foo-points-to>
:foo ; => :FOO
```

Nota che le parole chiave sono indicate da due punti iniziali (`:`).

Il quoting, cioè l'aggiunta di `'` prima di un'espressione S, dice a Lisp di non valutare quell'espressione.
Con il quoting di `'foo` nel nostro esempio con `defun`, abbiamo evitato che Lisp tentasse di cercare (senza trovarlo) ciò a cui `FOO` doveva puntare, restituendo invece il valore `FOO` stesso.
Se `FOO` non è stato definito da nessuna parte nel nostro programma:

```lisp
foo  ; => <ERROR! Lisp doesn't know what foo points to!>
'foo ; => FOO
```

Per ora, puoi considerarlo semplicemente come un modo per restituire simboli da una funzione, ma torneremo sul quoting e ne approfondiremo le implicazioni nei prossimi esercizi sui concetti.
