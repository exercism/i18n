# Suggerimenti

Per tutte queste attività ti servirà il comando `print`:
```awk
{print "something", "something else"}
```

## 1. Elenca i nomi utente

* Usa [la variabile `FS`][var-fs] per definire il separatore di campo.

## 2. Stampa i numeri di riga

* Usa la [variabile predefinita `NR`][var-nr] per ottenere il numero di riga.

## 3. Stampa i record con directory home non valide.

* La directory home è il sesto campo.
* Usa la funzione `startsWith` fornita.
* Usa gli [operatori booleani][boolean-ops]: `&&`, `||`, `!`.

## 4. Stampa il numero di utenti validi che usano bash

* La shell di login è l'ultimo campo; puoi usare [la variabile `NF`][var-nf].
