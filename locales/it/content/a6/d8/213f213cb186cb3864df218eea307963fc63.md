# Introduzione

Una proprietà, in Haxe, è un membro di una classe che dà accesso ai dati contenuti in quella classe. Chi la usa può impostare o recuperare (leggere) i dati. Una proprietà è composta da un accessore set e/o da un accessore get.

Le proprietà hanno i modificatori di accesso (`public`, `private` e così via) esattamente come gli altri membri della classe. L'accessore set, però, può avere un livello di accesso indipendente da quello dell'accessore get, e viceversa. Una proprietà non deve per forza avere entrambi gli accessori: può averne anche uno solo, get o set.

L'accesso in lettura e l'accesso in scrittura si riflettono direttamente nella sintassi, come mostra l'esempio seguente:

```haxe
class Main {
  public var x(default, null):Int;
}
```

Sia `default` che `null` sono speciali **identificatori di accesso**. Gli identificatori di accesso determinano il comportamento quando il campo viene letto (primo identificatore) e quando il campo viene scritto (secondo identificatore). I valori accettati sono:

- `default`: consente il normale accesso al campo se il campo è pubblico.
- `null`: consente l'accesso solo dall'interno della classe in cui il campo è definito.
- `get/set`: l'accesso viene generato come chiamata a un metodo accessore (`get_x()`).
- `dynamic`: come `get/set`, ma l'esistenza di un metodo accessore non può essere verificata.
- `never`: non consente alcun tipo di accesso.

Ecco un esempio completo:

```haxe
class Main {
  public var x(default, set):Int;

  public function set_x(x:Int):Int {
    return this.x = x + 2;
  }

  public function main() {
    trace(x); // null
    x = 2;
    trace(x); // 4
  }
}
```
