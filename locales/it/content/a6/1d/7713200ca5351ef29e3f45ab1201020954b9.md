# Iterazione

In programmazione, l'[iterazione][iteration] è il processo di ripetizione di un blocco di codice più volte.
Si può ottenere usando concetti come i cicli while e until, oppure la ricorsione, cioè una funzione che chiama se stessa.

Spesso, però, vuoi iterare su una collezione di elementi, come un `Array`, un `Range` o una `String`.
In Crystal, sia la classe `Array` che la classe `Range` includono il modulo [`Enumerable`][enumerable], che fornisce diversi metodi per iterare sugli elementi.
La classe `String`, invece, ha un proprio insieme di metodi per iterare sui caratteri.

Crystal non ha nemmeno un'istruzione for come altri linguaggi.
Al suo posto, mette a disposizione diversi metodi per iterare.

## Iterare

Il modo più comune per iterare su una collezione è usare il metodo [`each`][each], che passa ogni elemento della collezione a un blocco.
Con un `Range` è semplice.

Supponiamo che tu voglia iterare da 1 a 3: puoi usare il metodo `each` per iterare sull'intervallo.

```crystal
(1..3).each do |n|
  puts n
end

# Output:
# 1
# 2
# 3
```

Ancora più semplice: se vuoi solo ripetere qualcosa un certo numero di volte, puoi usare il metodo [`times`][times], disponibile sulla classe `Int`.

```crystal
3.times do |n|
  puts n
end

# Output:
# 0
# 1
# 2
```

## Iterare su una `String`

Una `String` è una sequenza di caratteri e non appartiene al modulo `Enumerable`, quindi ha un proprio insieme di metodi per iterare sui caratteri.
Il modo più comune per iterare su una `String` è usare il metodo [`each_char`][each_char], che passa ogni carattere della `String` a un blocco.

~~~~exercism/note
Il metodo `each_char` passa al blocco un oggetto `Char`, non un oggetto `String`.
~~~~

```crystal
str = "hello"
str.each_char { |char| puts char }

# Output:
# h
# e
# l
# l
# o
```

Un altro modo per iterare su una `String` è usare il metodo [`each_line`][each_line].
Questo metodo si usa soprattutto quando si legge un file riga per riga.

```crystal
str = "hello\nworld"
str.each_line do |line|
  puts line
end

# Output:
# hello
# world
```

## Iterare su un oggetto che include il modulo `Enumerable`

Il modulo [`Enumerable`][enumerable] fornisce diversi metodi per iterare sugli elementi di una collezione.
Le collezioni che includono il modulo `Enumerable` sono `Array`, `Range`, `Hash`, `Set` e altre ancora; queste ultime saranno trattate nei concetti successivi.

Il modo più comune per iterare su un `Array` è usare il metodo [`each`][each], che passa ogni elemento dell'`Array` a un blocco.

```crystal
arr = [5, 2, 3]
arr.each do |element|
  puts element
end

# Output:
# 5
# 2
# 3
```

### Map

Il metodo [`map`][map] è un altro modo per iterare su un `Array`: restituisce un nuovo `Array` con i risultati dell'applicazione del blocco a ogni elemento.
È simile al metodo `each`, ma restituisce un nuovo `Array` con gli elementi trasformati.
La trasformazione è molto utile quando vuoi applicare una funzione a ogni elemento della collezione, un'operazione piuttosto comune.

```crystal
arr = [1, 2, 3]
new_arr = arr.map do |element|
  element * 2
end

new_arr
# => [2, 4, 6]
```

Con un flusso di controllo come `if` puoi anche filtrare quali elementi trasformare.

```crystal
arr = [1, 2, 3]
new_arr = arr.map do |element|
  if element.odd?
    element * 2
  else
    element
  end
end

new_arr
# => [2, 2, 6]
```

## Sintassi abbreviata

In Crystal esiste una sintassi abbreviata per iterare e applicare un metodo a ogni elemento di una collezione.
È utile quando la logica è semplice e serve solo trasformare gli elementi con un unico metodo.
Si usa la sintassi `&.` seguita dal nome del metodo.

```crystal
arr = [1, 2, 3]
arr.map(&.to_s)
# => ["1", "2", "3"]
```

### Con l'indice

A volte ti serve conoscere l'indice dell'elemento su cui stai iterando: per questo puoi usare il metodo [`each_with_index`][each_with_index] o [`map_with_index`][map_with_index].
Passano al blocco ogni elemento e il suo indice; il metodo accetta anche un argomento opzionale per specificare l'indice di partenza.

```crystal
arr = [1, 2, 3]
arr.each_with_index(4) do |element, index|
  puts "Element: #{element}, Index: #{index}"
end

# Output:
# Element: 1, Index: 4
# Element: 2, Index: 5
# Element: 3, Index: 6
```

Nota che il metodo [`each_char_with_index`][each_char_with_index] è disponibile anche per gli oggetti `String`.

### sum

Il metodo [`sum`][sum] restituisce la somma di tutti gli elementi della collezione; accetta anche un blocco opzionale per trasformare gli elementi prima di sommarli e un argomento opzionale per specificare il valore iniziale della somma.

```crystal
arr = [1, 2, 3]
arr.sum
# => 6

arr.sum(2) { |n| n * 2 }
# => 14
```

### reduce

[`reduce`][reduce], noto come fold in altri linguaggi, è un metodo che, dati un metodo di combinazione e un valore iniziale, combina tutti gli elementi della collezione.
Il metodo `reduce` ha un accumulatore che viene passato al blocco; l'accumulatore è il risultato dell'iterazione precedente.
Si tratta di un processo ricorsivo che combina tutti gli elementi della collezione.

```crystal
arr = [1, 2, 3]
arr.reduce(0) do |acc, n|
  acc + n
end
# => 6
```

`reduce` può sembrare simile a `sum`, ma è più flessibile, perché ti permette di specificare il valore iniziale dell'accumulatore e il metodo di combinazione.
`reduce` può essere usato per implementare `sum`, `count` e altri metodi.
