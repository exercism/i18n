# Eseguire i test dalla riga di comando

Roc viene fornito con i propri strumenti di test integrati: non serve installare nient'altro.

Per testare la soluzione di un esercizio, apri un terminale, vai nella directory dell'esercizio ed esegui `roc test <exercise-name>-test.roc`, per esempio `roc test hello-world-test.roc`, e assicurati che tutti i test passino. *Non* modificare `*-test.roc` stesso, ma solo gli altri file `*.roc`.
