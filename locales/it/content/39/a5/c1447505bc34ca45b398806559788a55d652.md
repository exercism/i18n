# Introduzione

Un `list` in R è una raccolta ordinata di elementi, che si differenzia dai `vectors` sotto alcuni aspetti:

- Gli elementi possono essere di tipi diversi (ad esempio mescolando `numeric` con `character`).
- Gli elementi possono essere strutture complesse (ad esempio vettori, altri array, ecc.).
- La sintassi per accedere agli elementi è un po' diversa.

Le analogie con altri linguaggi sono imprecise.
Un `list` in R è in qualche modo simile a un dizionario di Python, ma è ordinato e vi si può accedere tramite un indice numerico.
È in qualche modo simile a una `struct` del C, con la differenza che il `list` può essere esteso facilmente in fase di esecuzione.

## Creare array

Dare dei nomi (spesso chiamati «tag») agli elementi è più comune con gli array che con i vettori:

```R
list(x = 5.3, y = 4.2, color = "blue")
$x
#> [1] 5.3

$y
#> [1] 4.2

$color
#> [1] "blue"
```

Tuttavia, i tag sono facoltativi e in quel caso R usa semplicemente i numeri di indice:

```R
list(5.3, 4.2, "blue")
#> [[1]]
#> [1] 5.3

#> [[2]]
#> [1] 4.2

#> [[3]]
#> [1] "blue"
```

## Accedere agli elementi di un array

Ci sono tre modi per farlo, ognuno utile in contesti diversi.

### 1. Con la notazione `$tag`

Molto comune se i nomi dei tag sono noti in anticipo.

```R
point <- list(x = 5.3, y = 4.2, color = "blue")
point$x
#> [1] 5.3
point$color
#> [1] "blue"
```

### 2. Con la notazione `[[tag]]`

Ha il vantaggio che il nome del tag può essere scelto in fase di esecuzione.
Nota le doppie parentesi quadre.

```R
want <- "y"
point[[want]] # same as point$y
#> [1] 4.2
```

### 3. Con l'indice di posizione

Funziona indipendentemente dal fatto che l'array abbia dei tag.
Anche qui le parentesi sono doppie.

```R
point[[3]] # same as point$color
#> [1] "blue"
```

## Aggiungere ed eliminare elementi

Semplice: assegnare un valore a un elemento lo modifica se esiste già, oppure lo inserisce se è nuovo.

```R
point$color <- "red"
point[[trust]] <- TRUE
str(point)
#> List of 4
#>  $ x    : num 5.3
#>  $ y    : num 4.2
#>  $ color: chr "red"
#>  $ trust: logi TRUE
```

Per eliminare, assegna `NULL` all'elemento indesiderato.

```R
point$trust <- NULL
str(point)
#> List of 3
#>  $ x    : num 5.3
#>  $ y    : num 4.2
#>  $ color: chr "red"
```
