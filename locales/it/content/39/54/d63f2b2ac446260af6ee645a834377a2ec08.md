# Informazioni

PHP ha diverse strutture di controllo per i cicli integrate, come `while`. La forma di base di un'istruzione `while` è:

```php
while (expr) {
  // statements
}
```

Finché l'espressione (_expr_) viene valutata come un valore _truthy_, il ciclo itera sulle istruzioni al suo interno. Se l'espressione (_expr_) viene valutata come false prima della prima iterazione, le istruzioni non vengono mai eseguite.

In alternativa, puoi usare un ciclo `do-while`, che esegue le istruzioni del ciclo una volta prima di valutare l'espressione (_expr_).

```php
do {
  // statements
} while (expr);
```
