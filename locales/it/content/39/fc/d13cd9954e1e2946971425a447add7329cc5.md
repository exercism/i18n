# Introduzione

Gli errori sono utili per segnalare quando qualcosa non va o è inatteso in un programma o in una parte di codice.

Sono oggetti JavaScript.

La proprietà principale di questo oggetto è `message`:

```javascript
const error = new Error('Oops, something went wrong');

console.log(error.message);
// => "Oops, something went wrong"
```

Usando la sintassi `throw`, puoi lanciare un Error.

```javascript
throw new Error('Oops');
```

Quando viene lanciato un `Error`, l'esecuzione corrente si interrompe e riprende nel primo blocco catch dello stack di chiamate.

```javascript
try {
  throw new Error('Oops');
} catch (error) {
  console.log(error.message);
  // => "Oops"
}
```

Come con qualsiasi classe in JavaScript, le sottoclassi possono ereditare da `Error` per creare errori personalizzati usando la parola chiave `extends`.
La sintassi `instanceof` verifica se l'errore catturato è un'istanza di una particolare sottoclasse di `Error`.

```javascript
class CustomError extends Error {}

try {
  // ... Code that may throw an error
} catch (error) {
  if (error instanceof CustomError) {
    console.log('The error thrown is an instance of the CustomError');
  }
}
```
