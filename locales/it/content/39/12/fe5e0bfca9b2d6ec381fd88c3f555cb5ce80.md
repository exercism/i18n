# Test

## Eseguire i test

Per eseguire i test, esegui il seguente comando:

```bash
make
```

## Risolvere l'esercizio

Risolvere un esercizio significa far passare tutti i suoi test.
Per impostazione predefinita, quando esegui i test viene eseguito un solo test (il primo).
Questa scelta è intenzionale, perché ti permette di concentrarti solo sul far passare quel test.
Una volta che passa, puoi abilitare il test successivo rimuovendo la riga `TEST_IGNORE()`.
Quando tutti i test sono stati abilitati e l'implementazione li fa passare tutti, avrai risolto l'esercizio!
