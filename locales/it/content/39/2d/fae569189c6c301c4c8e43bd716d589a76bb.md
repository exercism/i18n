# Istruzioni

Un tuo amico ha un vecchio negozio all'ingrosso chiamato **Gross Store**.

Il nome deriva dalla quantità degli articoli che il negozio vende: è tutto in [unità grossa][gross-unit].

Il tuo amico ti ha chiesto di implementare un sistema di punto vendita (POS) per il suo negozio.

**Per prima cosa, vuoi costruirne un prototipo.**

**Nel tuo prototipo, il sistema registrerà solo la quantità.**

Il tuo amico ti ha dato un elenco di misure per aiutarti:

| Unità              | Valore |
| ------------------ | ------ |
| quarter_of_a_dozen | 3      |
| half_of_a_dozen    | 6      |
| dozen              | 12     |
| small_gross        | 120    |
| gross              | 144    |
| great_gross        | 1728   |

## 1. Memorizza l'unità di misura nel tuo programma

Per usare la misura, devi memorizzarla nel tuo programma.

```rust
let units = units();
// Felt252Dictionary with entries like { 'dozen': 12 }
```

## 2. Crea un nuovo conto per il cliente

Devi implementare una funzione che crea un nuovo conto (vuoto) per il cliente.

```rust
let bill = new_bill();
// Empty Felt252Dictionary
```

## 3. Aggiungi un articolo al conto del cliente

Per implementarlo, dovrai:

- Restituire `false` se l'`unit` fornito non è presente nella mappa `units`.
- Altrimenti aggiungere l'articolo al `bill` del cliente, indicizzato con il nome dell'articolo, poi restituire `true`.
- Se l'articolo è già presente nel conto, aumentare la sua quantità della quantità che corrisponde all'`unit` fornito.

```rust
let bill = new_bill();
let units = units();
let ok = add_item(bill, units, 'carrot', 'dozen');
println!(ok);
// Output: true (since dozen is a valid unit)
```

> Nota che il valore restituito è di tipo `bool`.

## 4. Rimuovi un articolo dal conto del cliente

Per implementarlo, dovrai:

- Restituire `false` se l'articolo fornito **non** è presente nel conto.
Un articolo si considera non presente nel conto se la sua quantità è 0.
- Restituire `false` se l'`unit` fornito non è presente nella mappa `units`.
- Restituire `false` se la nuova quantità sarebbe inferiore a 0.
- Se la nuova quantità è 0, l'articolo si considera rimosso dal `bill`, quindi puoi restituire `true`.
- Altrimenti, ridurre la quantità dell'articolo e restituire `true`.

```rust
let bill = new_bill();
let units = units();
let ok = remove_item(bill, units, 'carrot', 'dozen');
println!(ok);
// Output: false (because there are no carrots in the bill)
```

> Nota che il valore restituito è di tipo `bool`.

## 5. Restituisci la quantità di un articolo specifico presente nel conto del cliente

```rust
let mut bill: Felt252Dict<u32> = Default::default();
bill.insert('carrot', 12);
bill.insert('grapes', 3);
let qty = get_item(bill, 'carrot');
println!(qty);
// Output: 12
```

> Nota che il valore restituito è di tipo `u32`.

[gross-unit]: https://en.wikipedia.org/wiki/Gross_(unit)
