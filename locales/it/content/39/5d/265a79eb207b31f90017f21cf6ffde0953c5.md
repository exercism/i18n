# Introduzione

Un array in Gleam è una collezione immutabile di zero o più valori. Tutti i valori in un array devono avere lo stesso tipo. Dato che gli array sono immutabili, una volta che un array è stato costruito il suo valore non può più cambiare. Qualsiasi funzione o operatore che sembra modificare un array (ad esempio aggiungendo un elemento) in realtà restituisce un nuovo array.

Gli array si possono definire così:

```gleam
let empty = []
let singleValue = [5]
let threeValues = ["a", "b", "c"]
```

Il modo più comune per aggiungere un elemento a un array è la sintassi spread:

```gleam
let two_to_four = [2, 3, 4]
let one_to_four = [1, ..two_to_four]
// -> [1, 2, 3, 4]
```

Il modulo [`gleam/list`](https://hexdocs.pm/gleam_stdlib/gleam/list.html) della libreria standard di Gleam contiene molte funzioni utili per lavorare con gli array. Questo modulo è usatissimo nel codice Gleam, quindi è bene conoscerlo.

I pattern delle liste possono essere usati nelle espressioni case per fare match sugli array e assegnare i valori contenuti a delle variabili:

```gleam
pub fn describe(list: List(String)) -> String {
  case list {
    [] -> "Empty list"
    [x] -> "List with one item: " <> x
    [x, y] -> "List with two items: " <> x <> " and " <> y
    _ -> "List with three or more items"
  }
}
```

Oltre a fare match su array di lunghezza esatta, la sintassi spread può essere usata per fare match su array di almeno una certa lunghezza:

```gleam
pub fn describe(list: List(String)) -> String {
  case list {
    [_, _, ..] -> "List with at least two items"
    [_] -> "List with one item"
    [] -> "Empty list"
  }
}
```

La sintassi spread può essere usata anche per assegnare il resto dell'array a una variabile:

```gleam
pub fn remove_first_item(list: List(String)) -> List(String) {
  case list {
    // Return the list without the first item
    [_, ..rest] -> rest

    // There's no first item to remove, return an empty list
    _ -> []
  }
}
```

Le espressioni case dovrebbero avere un pattern per ogni possibile valore del tipo su cui si fa match, quindi spesso si usa un pattern di scarto finale (`_`) per gestire i valori rimanenti.
