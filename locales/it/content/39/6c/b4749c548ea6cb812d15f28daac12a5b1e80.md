# Appendice alle istruzioni

## Funzioni e test

Ti viene fornita una definizione di partenza per la funzione `SayHi`.

```delphi
function SayHi : string;
begin
  result := 'Goodbye, Mars!';
end;
```

Il test runner prende questa funzione, la esegue e confronta il valore che [restituisce][returns] con il valore che si aspetta.
Usa questa definizione di funzione di partenza come base per la soluzione.

[returns]: https://www.freepascal.org/docs-html/3.2.2/ref/refse94.html
