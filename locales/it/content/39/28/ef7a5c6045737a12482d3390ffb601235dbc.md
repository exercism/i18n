# Numeri

`INT` è il tipo di Sather per i numeri interi: `0`, `7`, `-3`. Una routine
che restituisce un numero intero lo dichiara dopo i due punti, proprio come
una routine che restituisce del testo dice `STR`.

```sather
   goals : INT is
      return 42;
   end;
```

Le routine possono accettare **argomenti**: valori che vengono passati quando
la routine viene chiamata. Ogni argomento ha un nome e un tipo, tra parentesi
tonde (`()`) dopo il nome della routine:

```sather
   total(first : INT, second : INT) : INT is
      return first + second;
   end;
```

Quando due argomenti hanno lo stesso tipo, puoi nominarli insieme:

```sather
   total(first, second : INT) : INT is
```

Per chiamarla, metti i valori tra parentesi:

```sather
SCORES::total(3, 4)     -- this is 7
```

I cinque operatori aritmetici sono `+`, `-`, `*`, `/` e `%`.

La `/` tra due `INT` è la **divisione intera**: scarta il resto invece di
dare una frazione.

```sather
7 / 2      -- 3, not 3.5
```

Il `%` dà il resto di quella divisione.

```sather
7 % 2      -- 1
```

Le due cose vanno insieme: `7` è `3` volte `2` con `1` che avanza.
