# Introduzione

## Alias

Per condividere codice tra moduli Elixir diversi all'interno dello stesso progetto, devi fare riferimento al modulo esterno con il suo nome completo. Ma cosa succede se quel nome è troppo lungo o poco chiaro?

La forma speciale `alias` ti permette di abbreviare o cambiare il nome con cui fai riferimento a un modulo esterno. Se usata senza argomenti, riduce il nome del modulo al suo ultimo segmento, ad esempio `MyApp.Logger.Settings` diventa `Settings`. Puoi specificare un nome personalizzato con l'opzione `:as`.

Di solito gli alias si aggiungono all'inizio della definizione del modulo.

```elixir
defmodule Square do
  alias Integer, as: I

  def area(a), do: I.pow(a, 2)
end
```

## Import

La forma speciale `import` ti permette di usare le funzioni di un modulo esterno senza usare il nome del modulo.

Importare un intero modulo esterno potrebbe creare conflitti con le funzioni locali esistenti. Per evitarlo, sono disponibili due opzioni: `:except` e `:only`. Entrambe richiedono una keyword list, in cui la chiave è il nome della funzione e il valore è l'arità della funzione.

Di solito gli import si aggiungono all'inizio della definizione del modulo.

```elixir
defmodule Square do
  import Integer, only: [pow: 2]

  def area(a), do: pow(a, 2)
end
```
