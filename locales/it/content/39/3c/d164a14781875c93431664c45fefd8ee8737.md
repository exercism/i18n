# Tuple

Le tuple in Elm possono contenere due o tre valori, e ogni valore può avere qualsiasi tipo.
In Elm, le tuple si usano per lo più per tipi transitori semplici.
Per questo motivo le tuple hanno un massimo di 3 valori e, come ulteriore incoraggiamento, le funzioni di utilità sono fornite solo per 2 valori.
Per dati più complessi, è meglio passare ai record.
Un uso comune è quando devi restituire più di un valore da una funzione.
I campi di una tupla non hanno nome: vi si accede tramite la destrutturazione o per posizione.

Puoi leggere una [breve introduzione alle tuple][tuples-concise].
C'è anche una [introduzione più approfondita][tuples-in-depth], e la [documentazione API del modulo Tuple][tuple-core] contiene esempi di codice e documentazione dettagliata.

## Dichiarazione

I tipi per le tuple si creano con le parentesi e i tipi dei loro elementi sono separati da virgole.

```elm
type alias IntStringTuple = (Int, String)
```

### Creazione

Le tuple si creano con le parentesi e i loro elementi sono separati da virgole.

```elm
aTuple : IntStringTuple
aTuple = (123, "elements can be of differing types")
```

Puoi anche usare `Tuple.pair` per creare una tupla con due valori.

```elm
anotherTuple : (String, String)
anotherTuple = Tuple.pair "this time it's" "two strings"
    --> ("this time it's", "two strings")
```

### Accesso

Esistono anche funzioni per accedere ai valori di una tupla per posizione: `Tuple.first` e `Tuple.second`.

```elm
Tuple.first aTuple
    --> 123

Tuple.second aTuple
    --> "elements can be of differing types"
```

Le tuple possono essere _destrutturate_ nei binding usando il pattern matching sulle tuple.
La destrutturazione si può fare nelle espressioni let, nelle definizioni di funzione e nelle espressioni case.

```elm
repeatString : (Int, String) -> Bool
repeatString aTuple =
let
    (aNumber, aString) = aTuple
in
    String.repeat aNumber aString

repeatStringAgain : (Int, String) -> Bool
repeatStringAgain (aNumber, aString) = String.repeat aNumber aString
```

Il pattern matching in un'espressione case ti permette anche di fare corrispondere il contenuto dei valori:

```elm
has123 : (Int, String, Bool) -> Bool
has123 aTuple =
    case aTuple of
        (123, _, _) ->
            True
        (_, "123", _) ->
            True
        (_, _, True) ->
            True
        _ ->
            False
```
