# Test

Per usare il test runner, devi avere [Godot installato][installation] correttamente.

## Eseguire i test

Il [test runner][] viene usato per caricare e testare le soluzioni.
Per eseguire il test runner, scaricalo in locale, poi avvialo con `godot`.
In futuro, il test runner verrà scaricato automaticamente insieme agli esercizi quando usi `exercism download`.

```bash
godot --headless -s /path/to/test_runner.gd -- <solution-slug> <path/to/solution>
```
