# Test

## Eseguire i test in modo interattivo

Avvia la tua implementazione di Common Lisp nella directory dell'esercizio su cui stai lavorando (oppure cambia la directory corrente di un'implementazione di Common Lisp già in esecuzione, portandola in quella directory).
Con roswell, puoi farlo con `ros run`.

(Tutti gli esempi qui presuppongono un esercizio chiamato `exercise-name`: adatta come serve.)

Carica il file di test nella tua implementazione Lisp in esecuzione, per esempio `(load "exercise-name-test")`.
(Questo caricherà anche il file della soluzione.)
Dopo che il file di test è stato caricato, puoi eseguire i test valutando `(exercise-name-test:run-tests)` nella REPL.

Mentre apporti modifiche alla soluzione che stai scrivendo, usa le funzionalità del tuo editor per caricare le modifiche oppure valuta `(load "exercise-name")` per caricare il file della soluzione.

Ricordati di valutare `(exercise-name-test:run-tests)` per rieseguire i test dopo aver caricato la soluzione aggiornata.

## Eseguire i test dalla riga di comando

Puoi lanciare i test con questo comando da riga di comando (di nuovo, sostituisci "exercise" con il nome appropriato in due punti)

```sh
ros run --load exercise-test.lisp --eval '(uiop:quit (if (exercise-test:run-tests) 0 1))'
```

Quel comando è piuttosto macchinoso.
Un contributore ha scritto alcune note su [come renderlo più facile da invocare](https://glennj.github.io/exercism/cli).
