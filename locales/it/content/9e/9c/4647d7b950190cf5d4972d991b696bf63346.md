# Istruzioni

Jen lavora nella stanza di smistamento di una grande fabbrica.
La stanza di smistamento deve elaborare tutto ciò che vi entra categorizzandolo con un'etichetta.
Jen è responsabile delle cose che sono state pre-categorizzate come numeri e ha bisogno di un programma che la aiuti con lo smistamento.

La maggior parte dei valori primitivi dovrebbe ricevere etichette semplici.
Per i numeri, vuole stringhe che dicano `"This is the number 2.0"` (se il numero era 2).
Jen vuole lo stesso output per interi e numeri in virgola mobile.

Ci sono alcune interfacce `Box` che vanno scartate per ottenerne il contenuto.
Per un `NumberBox`, vuole stringhe che dicano `"This is a box containing the number 3.0"` (se il metodo `Number()` restituisce 3).
Per un `FancyNumberBox`, vuole stringhe che dicano `"This is a fancy box containing the number 4.0"`, ma solo se il tipo è un `FancyNumber`.

Qualsiasi cosa inaspettata dovrebbe dire `"Return to sender"`, così Jen può rispedirla da dove è venuta.

## 1. Descrivi i numeri semplici

Jen vuole che i numeri restituiscano stringhe come `"This is the number 2.0"` (inclusa una cifra dopo il punto decimale):

```go
fmt.Println(DescribeNumber(-12.345))
// Output: This is the number -12.3
```

## 2. Descrivi una scatola di numeri

Jen vuole che le scatole di numeri restituiscano stringhe come `"This is a box containing the number 2.0"` (di nuovo, inclusa una cifra dopo il punto decimale):

```go
fmt.Println(DescribeNumberBox(numberBoxContaining{12}))
// Output: This is a box containing the number 12.0
```

## 3. Implementa un metodo che estrae il numero da una scatola di numeri fancy

Jen ha bisogno di una funzione ausiliaria per estrarre il numero da un `FancyNumberBox`.
Se il `FancyNumberBox` è un `FancyNumber`, estrai il suo valore e convertilo da `string` a `int`.
Qualsiasi altro tipo di `FancyNumberBox` dovrebbe restituire 0.

```go
fmt.Println(ExtractFancyNumber(FancyNumber{"10"}))
// Output: 10
fmt.Println(ExtractFancyNumber(AnotherFancyNumber{"4"}))
// Output: 0
```

## 4. Descrivi una scatola di numeri fancy

Se il `FancyNumberBox` è un `FancyNumber`, Jen vuole stringhe che dicano `"This is a fancy box containing the number 4.0"`.
Qualsiasi altro tipo di `FancyNumberBox` dovrebbe dire `"This is a fancy box containing the number 0.0"`.

```go
fmt.Println(DescribeFancyNumberBox(FancyNumber{"10"}))
// Output: This is a fancy box containing the number 10.0
fmt.Println(DescribeFancyNumberBox(AnotherFancyNumber{"4"}))
// Output: This is a fancy box containing the number 0.0
```

NOTA: dobbiamo usare la funzione `ExtractFancyNumber`!

## 5. Implementa `DescribeAnything` che le usa tutte

Questa è la funzione principale di cui Jen ha bisogno, che accetta qualsiasi input.
`DescribeAnything` dovrebbe delegare alle altre funzioni in base al tipo del valore passato.
Più precisamente:

- `int` e `float64` dovrebbero entrambi delegare a `DescribeNumber`
- `NumberBox` dovrebbe delegare a `DescribeNumberBox`
- `FancyNumberBox` dovrebbe delegare a `DescribeFancyNumberBox`
- qualsiasi altra cosa dovrebbe dare come risultato `"Return to sender"`

```go
fmt.Println(DescribeAnything(numberBoxContaining{12.345}))
// Output: This is a box containing the number 12.3
fmt.Println(DescribeAnything("some string"))
// Output: Return to sender
```
