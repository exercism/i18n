# Scrivere il codice

Scrivi il codice in `<exercise_name>.zig`.
Alcuni esercizi includono firme già scritte per costrutti specifici di Zig, come [costanti][constants], [funzioni][functions], [import][imports], [struct][structs] e [potenzialmente molti altri][et-cetera]!

Queste firme già scritte servono ad aiutarti a completare gli esercizi, offrendoti un punto di partenza chiaro.
Tuttavia, non è necessario partire da queste firme.
Soprattutto perché qualsiasi codice scritto che superi i test è una soluzione perfettamente accettabile.

## Eseguire i test

Per eseguire i test, basta lanciare il seguente comando:

```bash
zig test test_exercise_name.zig
```

sostituendo `exercise_name` con il nome dell'esercizio.
Il comando qui sopra va eseguito nella directory principale dell'esercizio, dato che il file dei test dovrebbe trovarsi proprio lì.
Inoltre, tutti i test di un esercizio sono abilitati per impostazione predefinita e nessun test può essere saltato.

Dato che tutti i test hanno queste caratteristiche, se vuoi affrontarli uno alla volta devi [trasformare in commento][comments] quelli che non passano.
Trasformare un test in un commento è semplice: basta far iniziare ogni riga con `//`.
Altrimenti, quando sei sicuro che la soluzione possa superare i test, puoi togliere il commento da quei test per vedere se passano.
