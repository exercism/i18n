# Informazioni

Un *heap* è una collezione che sa sempre qual è il suo elemento più piccolo (o più grande) e ti permette di rimuoverlo rapidamente: è l'implementazione naturale di una *coda con priorità*. Gli heap vivono nel vocabolario [`heaps`][heaps].

`<min-heap>` costruisce un heap vuoto da cui esce per primo l'elemento con la chiave più piccola; `<max-heap>` restituisce per primo quello con la chiave più grande. Ogni elemento è un *valore* memorizzato sotto una *chiave*, e la chiave è la priorità in base alla quale Factor ordina:

```
<min-heap> ( -- min-heap )
<max-heap> ( -- max-heap )
heap-push  ( value key heap -- )
heap-push-all ( assoc heap -- )
```

```factor
USING: heaps ;

<min-heap>
"alice" 5 pick heap-push
"bob"   2 pick heap-push
```

Un heap è *mutabile*: `heap-push` e `heap-pop` lo modificano sul posto.

```
heap-peek    ( heap -- value key )
heap-pop     ( heap -- value key )
heap-pop-all ( heap -- alist )
heap-empty?  ( heap -- ? )
heap-size    ( heap -- n )
```

`heap-peek` legge l'elemento in testa senza rimuoverlo; `heap-pop` lo rimuove e lo restituisce; `heap-pop-all` svuota l'heap in una lista di associazioni di coppie `{ key value }` in ordine di priorità.

```factor
USING: assocs heaps kernel prettyprint ;

<min-heap>
"alice" 5 pick heap-push
"bob"   2 pick heap-push
"carol" 9 pick heap-push
dup heap-pop .           ! => 2 "bob"   (removed; value then key)
heap-pop-all values .    ! => { "alice" "carol" }
```

L'inserimento costa `O(log n)` e la lettura dell'elemento in testa costa `O(1)`, quindi ripetere «prendi l'elemento più urgente, poi aggiungine altri» resta veloce anche per una coda grande. L'implementazione è un heap binario memorizzato in un array ridimensionabile; la chiave può essere qualsiasi valore ordinabile (numeri, stringhe, …).

[heaps]: https://docs.factorcode.org/content/vocab-heaps.html
