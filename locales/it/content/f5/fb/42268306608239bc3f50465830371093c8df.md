# Introduzione

## Ricorsione

La capacità di qualcosa di essere definito in termini di sé stesso si chiama ricorsione. In Gleam, la ricorsione si incontra più spesso nelle funzioni ricorsive, ovvero le funzioni che chiamano sé stesse.

Una funzione ricorsiva deve avere almeno un _caso base_ e almeno un _caso ricorsivo_. Un _caso base_ restituisce un valore senza chiamare di nuovo la funzione. Un _caso ricorsivo_ chiama di nuovo la funzione, modificando l'input in modo che a un certo punto corrisponda al caso base.

```gleam
pub fn factorial(x: Int) -> Int {
  case x {
    // Base case
    1 -> 1

    // Recursive case
    _ -> x * factorial(x - 1)
  }
}
```

Gleam non ha una sintassi speciale per i cicli, quindi ogni ciclo si realizza con la ricorsione.

```gleam
pub fn list_length(list: List(String)) -> Int {
  case list {
    [] -> 0
    [_, ..rest] -> 1 + list_length(rest)
  }
}
```

Gleam supporta anche i tipi personalizzati ricorsivi. Un tipo personalizzato ricorsivo ha una o più varianti che fanno riferimento a sé stesso nei dati che contengono.

```gleam
pub type RussianDoll {
  Child               // Base case
  Mother(RussianDoll) // Recursive case
}
```
```gleam
let very_big_doll = Mother(Mother(Mother(Child)))
let small_doll = Mother(Child)
```
