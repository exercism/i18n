# Test

Ogni esercizio contiene un file di test.
Esegui i test usando il programma `bats`.

```bash
bats test-hello-world.bats
```

`bats` dovrà essere installato.
Consulta la pagina [Test sul track Bash][bash] per le istruzioni su come installare `bats` sul tuo sistema.

### bats è implementato in bash

Il file bats è uno script bash, con alcune funzioni speciali riconosciute dal comando `bats`.
Vedrai alcuni test che assomigliano a

```sh
jq -f some-exercise.jq <<< "{some,json,here}"
```

Quella sintassi `<<<` è una [Here String][here-string] di bash.
Invia la stringa a destra nello standard input del programma a sinistra.
È ([all'incirca][so]) equivalente a

```sh
echo "{some,json,here}" | jq -f some-exercise.jq
```

## Aiuto per le funzioni assert

I test usano funzioni della libreria [bats-assert][bats-assert].
Lì puoi trovare aiuto per le varie funzioni `assert*`.

## Test saltati

Risolvere un esercizio significa far passare tutti i suoi test.
Per impostazione predefinita, quando esegui i test viene eseguito un solo test (il primo).
È una scelta intenzionale: ti permette di concentrarti solo sul far passare quel singolo test.
Una volta che passa, puoi abilitare il test successivo trasformando in commento o rimuovendo le

    [[ $BATS_RUN_SKIPPED == true ]] || skip

annotazioni che precedono gli altri test.

## Disattivare i salti

Per eseguire tutti i test, compresi quelli con l'annotazione `skip`, puoi eseguire:

```bash
BATS_RUN_SKIPPED=true bats test-some-exercise.bats
```

Può essere comodo usare una funzione wrapper per risparmiare sulla digitazione: in `bash` puoi fare così:

```bash
bats() {
    BATS_RUN_SKIPPED=true command bats *.bats
}
```

Poi esegui i test semplicemente con:

```bash
bats
```

## Fare debug in `jq`

`jq` include un comodo filtro [`debug`][debug].
Usalo mentre sviluppi le soluzioni degli esercizi per ispezionare i dati che al momento si trovano nella pipeline di jq.
Consulta la [documentazione sul debug][debugging] per maggiori dettagli.
