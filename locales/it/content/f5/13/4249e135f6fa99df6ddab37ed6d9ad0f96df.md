# Introduzione

In Common Lisp una funzione non solo può restituire un valore, ma può restituirne diversi.
Per esempio `floor`, che arrotonda verso lo zero, restituisce due valori: il primo è il valore arrotondato, il secondo è il resto.

```lisp
(floor 3.5) ; => 3
            ;    0.5
```
(Mostreremo i valori restituiti su righe separate nell'output.)

## Restituire più valori

Se vuoi che una funzione restituisca più valori, usi l'accessor `values`:

```lisp
(defun three-numbers () (values 1 2 3))
(three-numbers) ; => 1
                ;    2
                ;    3
```

## Gestire più valori

Se ti interessa solo il primo valore, non devi fare nulla di speciale: ci pensa il linguaggio.

```lisp
(+ (values 1 2 3) (values 10 20 30)) ; => 11
```

Tuttavia, se vuoi accedere a quegli altri valori, dovrai usare diverse funzioni.
Le due macro principali sono `multiple-value-list` e `multiple-value-bind`.
Si usano per racchiudere qualcosa che restituisce più valori e catturarli tutti.
La prima crea una lista con tutti i valori.
La seconda ti permette di associare delle variabili ai singoli valori.

```lisp
(multiple-value-list (values 1 2 3))                   ; => (1 2 3)
(multiple-value-bind (a b c) (values 1 2 3) 
   (+ a b c)) ; => 6
```

Un'altra funzione utile è `nth-value`
