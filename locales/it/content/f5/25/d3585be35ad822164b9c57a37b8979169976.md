# Istruzioni

In questo esercizio implementerai un programma che determina lo stato di una partita a [tic-tac-toe][].
(_Forse conosci questo gioco anche con i nomi «tris» o «filetto»._)

Si gioca su una griglia 3×3.
I giocatori, a turno, collocano delle `X` e delle `O` sulla griglia.
La partita termina quando un giocatore vince allineando tre simboli in una riga, in una colonna o lungo una diagonale della griglia, oppure quando l'intera griglia è piena.

In questo esercizio assumeremo che inizi `X`.

Il tuo compito è determinare in quale stato si trova una data partita.

Ci sono 3 stati possibili per una partita:

- La partita è **ongoing**.
- La partita è terminata in una **draw**.
- La partita è terminata in una **win**.

Se la griglia data non è valida, lancia un errore appropriato.

Una griglia è non valida se soddisfa le seguenti condizioni:

- La griglia data non può essere raggiunta se le mosse vengono giocate nell'ordine corretto (ricorda che inizia `X`).
- Si è continuato a giocare dopo che la partita era già terminata.

## Esempi

### Partita in corso

```text
   |   |
 X |   |
___|___|___
   |   |
   | X | O
___|___|___
   |   |
 O | X |
   |   |
```

### Pareggio

```text
   |   |
 X | O | X
___|___|___
   |   |
 X | X | O
___|___|___
   |   |
 O | X | O
   |   |
```

### Vittoria

```text
   |   |
 X | X | X
___|___|___
   |   |
   | O | O
___|___|___
   |   |
   |   |
   |   |
```

### Non valida

#### Ordine dei turni errato

```text
   |   |
 O | O | X
___|___|___
   |   |
   |   |
___|___|___
   |   |
   |   |
   |   |
```

#### Gioco proseguito dopo la vittoria

```text
   |   |
 X | X | X
___|___|___
   |   |
 O | O | O
___|___|___
   |   |
   |   |
   |   |
```
