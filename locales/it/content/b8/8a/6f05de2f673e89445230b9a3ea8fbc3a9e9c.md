# Informazioni

Gli [intervalli][range] rappresentano un insieme di valori compresi tra due estremi.
Gli intervalli si usano comunemente con tipi come `Int`, `String` e `Character` per iterare su sequenze, estrarre porzioni di collezioni o verificare se un valore rientra nei limiti.

Swift mette a disposizione due operatori principali per gli intervalli:

- **Operatore di intervallo chiuso (`...`)**: include sia il valore iniziale sia quello finale (`1...5` include 1, 2, 3, 4 e 5).
- **Operatore di intervallo semiaperto (`..<`)**: include il valore iniziale ma esclude quello finale (`1..<5` include 1, 2, 3 e 4).

```swift
let closed = 1...5
let halfOpen = 1..<5
```

~~~~exercism/note
Quando chiami un metodo direttamente su un intervallo scritto come letterale, racchiudi l'espressione tra parentesi tonde, così il compilatore valuta prima l'intervallo:

```swift
(1...5).contains(3) // Returns true
// 1...5.contains(3) // Error: value of type 'Int' has no member 'contains'
```
~~~~

## Convertire un intervallo in un array

Puoi convertire un intervallo di numeri in un `Array` usando l'inizializzatore `Array(_:)`:

```swift
let range = 1...5
let numbers = Array(range)
// numbers is [1, 2, 3, 4, 5]
```

## Estrarre una porzione di un array con gli intervalli

Puoi usare gli intervalli per estrarre porzioni di un array:

```swift
let array = [10, 20, 30, 40, 50]
let slice = array[1...3]
// slice contains [20, 30, 40]
```

## Proprietà e metodi degli intervalli

Tra le operazioni più comuni sugli intervalli ci sono:

| Membro                  | Descrizione                                                | Esempio                              |
| ----------------------- | ---------------------------------------------------------- | ------------------------------------ |
| `count`                 | Restituisce il numero di elementi nell'intervallo           | `(1...5).count` restituisce `5`      |
| [`contains(_:)`][contains] | Restituisce `true` se l'intervallo include il valore indicato | `(1...5).contains(3)` restituisce `true` |

## Intervalli unilaterali

Swift supporta anche gli intervalli unilaterali (parziali), in cui si omette il valore iniziale o quello finale:

- `array[2...]`: dall'indice 2 fino alla fine della collezione.
- `array[...2]`: dall'inizio della collezione fino all'indice 2 compreso.
- `array[..<2]`: dall'inizio della collezione fino all'indice 2 (escluso).

## Intervalli di stringhe e caratteri

Puoi creare intervalli anche tra caratteri o stringhe che conformano a `Comparable`:

```swift
let letters = "a"..."z"
print(letters.contains("m")) // Prints true
print(letters.contains("A")) // Prints false
```
