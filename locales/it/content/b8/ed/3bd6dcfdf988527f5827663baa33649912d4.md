# Informazioni

A volte non hai bisogno del costo aggiuntivo di creare un oggetto con uno stato.
In questi casi, puoi usare un `module`.

Un modulo è molto simile a una classe (in effetti, nella gerarchia degli oggetti `Module` è il genitore di `Classes`): la differenza principale è che, invece di usare metodi di istanza, usiamo metodi di classe.
I metodi di classe iniziano con `self.` e vengono chiamati direttamente su un modulo.

Per esempio:

```ruby
module Speaker
  def self.echo(something)
    "#{something} ... #{something}"
  end
end

Speaker.echo("Hello")   #=> "Hello ... Hello"
```
