# Introduzione agli array

In Java, gli array sono un modo per memorizzare più valori dello stesso tipo in un'unica struttura.
A differenza di altre strutture dati, gli array hanno una dimensione fissa una volta creati.
Gli elementi possono essere assegnati a un array o recuperati da esso tramite un indice.
Gli array in Java usano l'indicizzazione a partire da zero: l'indice del primo elemento è 0, quello del secondo elemento è 1, e così via.

Ecco la sintassi standard per inizializzare un array:

```java
type[] variableName = new type[size];
```

Il `type` è il tipo degli elementi nell'array, che può essere un tipo primitivo (ad esempio `int`) o una classe (ad esempio `String`).

Il `size` è il numero di elementi che questo array conterrà (e che non può essere modificato in seguito).
Dopo la creazione dell'array, gli elementi vengono inizializzati ai loro valori predefiniti (tipicamente `0`, `false` o `null`).

```java
// Declare array with explicit size (size is 2)
int[] twoInts = new int[2];
```

Gli array possono anche essere definiti usando una notazione abbreviata che consente sia di creare l'array sia di impostarne i valori:

```java
// Two equivalent ways to declare and initialize an array (size is 3)
int[] threeIntsV1 = new int[] { 4, 9, 7 };
int[] threeIntsV2 = { 4, 9, 7 };
```

Dato che ora il compilatore può capire quanti elementi avrà l'array, la lunghezza può essere omessa.

Gli elementi dell'array possono essere assegnati e recuperati usando una notazione con indice tra parentesi quadre:

```java
// Assign second element by index
twoInts[1] = 8;

// Retrieve the second element by index and assign to the int element
int secondElement = twoInts[1];
```

Accedere a un indice che è al di fuori degli indici validi per l'array genera un'`IndexOutOfBoundsException`.

Gli array si possono manipolare chiamando i metodi o le proprietà di un'istanza di array, oppure usando i metodi statici definiti nella classe `Arrays` (tipicamente usati solo nel codice generico).
La proprietà `length` contiene la lunghezza di un array.
Vi si può accedere così:

```java
int arrayLength = someArray.length;
```

Java fornisce anche un'utile classe di utilità [`java.util.Arrays`](https://docs.oracle.com/en/java/javase/11/docs/api/java.base/java/util/Arrays.html) che ha molti metodi utili relativi agli array (ad esempio `Arrays.equals`).

Java supporta anche gli [array multidimensionali](https://www.programiz.com/java-programming/multidimensional-array) come `int[][] arr = new int[3][4];`, che possono essere molto utili.

Il fatto che un array sia anche una _collezione_ significa che, oltre ad accedere ai valori tramite indice, puoi iterare su _tutti_ i suoi valori usando un ciclo `for-each`:

```java
char[] vowels = { 'a', 'e', 'i', 'o', 'u' };

for(char vowel: vowels) {
    // Output the vowel
    System.out.print(vowel);
}

// => aeiou
```

Se vuoi avere più controllo su quali valori iterare, puoi usare un ciclo `for`:

```java
char[] vowels = { 'a', 'e', 'i', 'o', 'u' };

for (int i = 0; i < 3; i++) {
    // Output the vowel
    System.out.print(vowels[i]);
}

// => aei
```
