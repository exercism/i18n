# Approfondimento

## Concetti chiave

- Le liste sono collezioni.
- Le liste si possono creare usando [`list`][list] oppure un apostrofo.
- Clojure proverà a valutare le liste, trattando il primo elemento come una funzione.
- Funzioni principali:
  - [`first`][first] restituisce il primo elemento della lista.
  - [`rest`][rest] restituisce una lista con tutti gli elementi tranne il primo.
  - [`count`][count] restituisce il numero di elementi della lista.
  - [`conj`][conj] aggiunge uno o più elementi all'inizio della lista.

[list]: https://clojuredocs.org/clojure.core/list
[first]: https://clojuredocs.org/clojure.core/first
[rest]: https://clojuredocs.org/clojure.core/rest
[count]: https://clojuredocs.org/clojure.core/count
[conj]: https://clojuredocs.org/clojure.core/conj
