# Introduzione

Una `string` in Clojure è una stringa Java, cioè un oggetto che rappresenta testo immutabile sotto forma di una sequenza di caratteri Unicode (lettere, cifre, punteggiatura, ecc.) ed è definita come segue:

```clojure
(def fruit "Apple")
```

La libreria `clojure.string` fornisce molte funzioni standard per la manipolazione e l'elaborazione delle stringhe. Inoltre, tramite interop sono disponibili tutti i normali metodi Java per lavorare con le stringhe.
