# Intervalli

Gli [intervalli][range] rappresentano l'insieme dei valori compresi tra due estremi.
I tipi più comuni che supportano gli intervalli sono `Int`, `Char` e `String`.
Si possono usare per molte cose, come creare rapidamente una collezione, estrarre sottostringhe, controllare se un valore è compreso in un intervallo e iterare.
Si creano con l'operatore di intervallo `..` o `...` (rispettivamente inclusivo ed esclusivo).

```crystal
1..5  # A range containing 1, 2, 3, 4, 5
1...5 # A range containing 1, 2, 3, 4
```

Il motivo per cui esistono due operatori di intervallo è poter creare intervalli che includono o escludono il valore finale: una cosa utile, per esempio, quando si lavora con indici che partono da zero.

Gli intervalli si possono anche creare usando l'inizializzatore `Range`.

```crystal
Range.new(1, 5) # A range containing 1, 2, 3, 4, 5
```

~~~~exercism/note
Quando crei un intervallo in Crystal con gli operatori `..` o `...` e vuoi chiamare un metodo su quell'intervallo, devi racchiuderlo tra parentesi.
Altrimenti il metodo verrà chiamato sul secondo argomento dell'operatore di intervallo.

```crystal
(1..5).size # => 5
1..5.size # => Error: undefined method 'size' for Int32
```
~~~~

## Ottenere sottostringhe

Quando vuoi estrarre una parte di una stringa, puoi usare l'operatore di intervallo per ottenere una sottostringa.
Basta creare un intervallo con l'indice iniziale e quello finale della sottostringa.

```crystal
"Hello World"[0..4] # => "Hello"
"Hello World"[6..10] # => "World"
```

Puoi anche usare indici negativi per ottenere la sottostringa dalla fine della stringa.

```crystal
"Hello World"[-5..-1] # => "World"
"Hello World"[6..-4] # => "Wo"
```

## Metodi degli intervalli

Gli intervalli hanno una serie di metodi con cui lavorare.
Per esempio, questi metodi permettono di ottenere la somma di tutti i valori dell'intervallo o di verificare se l'intervallo include un valore.

| Metodo                  | Descrizione                                                             | Esempio                         |
|-------------------------|-------------------------------------------------------------------------|---------------------------------|
| [`sum`][sum]            | Restituisce la somma di tutti i valori dell'intervallo                  | `(1..5).sum # => 15`            |
| [`size`][size]          | Restituisce la dimensione dell'intervallo                               | `(1..5).size # => 5`            |
| [`includes?`][indludes] | Restituisce `true` se l'intervallo include il valore dato, altrimenti `false` | `(1..5).includes?(3) # => true` |

## Intervalli senza fine e senza inizio

Un intervallo può essere senza fine e senza inizio.
In un intervallo senza fine o senza inizio il valore iniziale o quello finale è `nil`, ma `nil` può essere omesso quando si definisce l'intervallo.

Usare intervalli senza inizio e senza fine è utile quando vuoi, per esempio, estrarre una parte di stringa dall'inizio o fino alla fine.

```crystal
"Hello World"[0..] # => "Hello World"
"Hello World"[4..] # => "o World"
"Hello World"[..5] # => "Hello"
```

~~~~exercism/caution
Se non viene usato su una collezione, un intervallo senza fine può generare una sequenza infinita, se non lo si usa con cautela.
~~~~

## Intervalli di Char

I caratteri si possono usare negli intervalli e permettono di ottenere un intervallo di caratteri compreso tra due caratteri.
Per esempio, può essere comodo quando vuoi ottenere l'alfabeto.

```crystal
'a'..'z' # A range containing ['a', 'b', 'c', ..., 'z']
```

## Intervalli di stringhe

Anche le stringhe si possono usare negli intervalli, il che permette di ottenere un intervallo di stringhe tra due stringhe.
Il comportamento però è un po' diverso da quello di `Char` quando in un intervallo di stringhe si usano più caratteri.
Con gli intervalli di stringhe più complessi il comportamento può diventare confuso, quindi fai attenzione.

```crystal
("aa".."az") # A range containing ["aa", "ab", "ac", ..., "az"]
```
