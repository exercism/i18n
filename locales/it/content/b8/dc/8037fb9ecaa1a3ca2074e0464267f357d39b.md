# Classi con stato

```sather
class SCOREBOARD is

   attr home_team, away_team : STR;
   attr home_score, away_score : INT;

   create(home, away : STR) : SAME is
      board ::= new;
      board.home_team := home;
      board.away_team := away;
      return board;
   end;

   home_goal is home_score := home_score + 1; end;

end; -- class SCOREBOARD
```

## attr, readonly attr, private attr

| Scritto | Lettura dall'esterno | Modifica dall'esterno |
| --- | --- | --- |
| `attr x : INT` | sì | sì |
| `readonly attr x : INT` | sì | no |
| `private attr x : INT` | no | no |

`readonly` è quello da preferire per impostazione predefinita. Permette a chiunque
di vedere il punteggio e impone che ogni modifica passi da `home_goal`, dove
risiedono le regole del punteggio.

## create e new

`new` crea un oggetto di questa classe con tutti gli attributi vuoti. Può essere
usato solo all'interno della classe.

`create` è una routine ordinaria con un nome concordato: `#C(args)` è esattamente
`C::create(args)`. Una classe può averne diverse, distinte dai loro argomenti,
e una classe che non ne ha nessuna semplicemente non può essere creata con `#`.

## SAME

`SAME` sta per la classe in cui è scritto. In `create` è il tipo di ritorno;
serve anche in un argomento, ed è ciò che fa sì che una routine ereditata parli
della classe che eredita anziché di quella da cui proviene.

## Routine senza tipo di ritorno

```sather
   home_goal is
      home_score := home_score + 1;
   end;
```

Nessun `:` e nessun tipo. Una routine così viene chiamata come istruzione e non
può comparire in un'espressione. È il segno che lo scopo della chiamata è il
cambiamento che essa produce.

## self

All'interno di una routine, `self` è l'oggetto su cui è stata chiamata. Si scrive
raramente, perché un attributo o una routine nominati da soli indicano già quelli
di `self`. È necessario quando l'oggetto deve essere passato o restituito:

```sather
   with_goal : SAME is
      home_score := home_score + 1;
      return self;
   end;
```

`self`, `new`, `void`, `result`, `value` e `out` sono tutte parole che Sather si è
riservato, e nessuna di esse può essere usata come nome.

## Riferimento, non valore

Un oggetto si raggiunge tramite un riferimento. Due nomi per lo stesso tabellone
vedono lo stesso punteggio:

```sather
   a ::= #SCOREBOARD("Vixens", "Magpies");
   b ::= a;         -- not a copy
   b.home_goal;
   a.home_score     -- 1
```

`immutable class`, più avanti, è il modo per ottenere l'altro comportamento.
