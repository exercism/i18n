# Introduzione

## Vero e falso

Gli stati logici vero e falso sono rappresentati con `true` e `false` in Ruby.
Questi possono essere usati come valori letterali a sé stanti, oppure come risultato di metodi logici o di confronto.

```ruby
happy = true
sad = false

true && false
# => false

1 < 2
# => true
```

## _Truthy_ e _falsey_

Quando si valutano oggetti in istruzioni `if` o in altri contesti booleani, tutti gli oggetti risultano _truthy_ **tranne** `false` e `nil`.

## Flusso di controllo

Le valutazioni _truthy_ e _falsey_ sono utili nel contesto del flusso di controllo.
Come nei linguaggi procedurali, Ruby ha un costrutto `if`...`else`, ma può essere più comune usare `if` come istruzione «di guardia» per modificare la valutazione di un'espressione.

```ruby
def falsey
  nil || false
end

def truthy
  not falsey
end

if truthy
  # this block is evaluated
end

if falsey
  # this block is not evaluated
else
  # this block is evaluated
end

1 + 1 if truthy
# this will evaluate and return 2

2 + 2 if falsey
# the numbers are not added because of the modifier, nil is returned
```

Ruby mette a disposizione `unless` per rendere il codice più leggibile.
Ad esempio, invece di `eat_desert if not too_full`, possiamo anche scrivere `eat_desert unless too_full`.

```ruby
3 + 3 unless truthy
# the numbers are not added because of the modifier, nil is returned

4 + 4 unless falsey
# this will evaluate and return 8
```
