# Appendice alle istruzioni

## Suggerimenti

Il modulo Sgf dovrebbe esportare un modulo parseSgf con la seguente firma:

```haskell
parseSgf :: Text -> Maybe (Tree (Map Text [Text]))
```

Potresti trovare utile copiare le seguenti definizioni di SgfTree
e SgfNode:

```haskell
-- | A tree of nodes.
type SgfTree = Tree SgfNode

-- | A node is a property list, each key can only occur once.
-- Keys may have multiple values associated with them.
type SgfNode = Map Text [Text]
```

La libreria parsec fa parte della Haskell Platform: usala a tuo vantaggio.
