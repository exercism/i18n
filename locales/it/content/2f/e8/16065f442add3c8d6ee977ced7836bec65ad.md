# Suggerimenti

## Generale

- Leggi il [comportamento `Access`][access-behaviour] nella documentazione.

## 1. Estrarre i dati da una struttura di mappe annidate

- Per prima cosa, tokenizza la stringa del percorso per portarla a uno stato utilizzabile. Puoi usare le [funzioni del modulo `String`][string-module].
- Scrivi una funzione ricorsiva che attraversi la struttura di mappe annidate per recuperare il valore oppure restituire `nil`.

## 2. Riorganizzare usando le funzioni incluse

- Dai un'occhiata alle varie [funzioni del modulo `Kernel`][kernel-module] per trovarne una che possa accorciare o semplificare il tuo approccio.

[kernel-module]: https://hexdocs.pm/elixir/Kernel.html#functions
[string-module]: https://hexdocs.pm/elixir/String.html#functions
[access-behaviour]: https://hexdocs.pm/elixir/Access.html
