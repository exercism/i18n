## Argomenti opzionali

```julia-repl
julia> f(a, b=1) = a + b
f (generic function with 2 methods)
```

equivale a

```julia-repl
julia> f(a, b) = a + b
f (generic function with 1 method)

julia> f(a) = f(a, 1)
f (generic function with 2 methods)
```

Nella risposta della REPL puoi vedere che la prima definizione definisce due metodi contemporaneamente.
