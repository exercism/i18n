# Appendice alle istruzioni

## Registri

| Registro | Utilizzo  | Tipo    | Descrizione                                            |
| -------- | --------- | ------- | ------------------------------------------------------ |
| `$a0`    | input     | indirizzo | stringa di input terminata da null                   |
| `$v0`    | output    | booleano | validità della stringa di input (`0` = `false`, `1` = `true`) |
| `$t0-9`  | temporaneo | qualsiasi | usato per l'archiviazione temporanea                 |
