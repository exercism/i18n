# Test Runner

Un Test Runner è un programma che esegue i test di un esercizio sul codice di uno studente.

I Test Runner ci offrono due vantaggi:

1. Consentono di scrivere codice direttamente nel browser, dove uno studente può iterare su una soluzione e vedere se i test passano o falliscono.
2. Ci permettono di fornire ai mentori informazioni sul fatto che il codice di uno studente «funzioni» oppure no.

## Contribuire ai Test Runner

Ogni linguaggio ha il proprio Test Runner, scritto in quel linguaggio.
Il sito web fa da orchestratore tra i Test Runner e le soluzioni inviate dagli studenti.

Ogni Test Runner si trova nell'organizzazione GitHub di Exercism, in un repository chiamato `<track_slug>-test-runner` (ad esempio [`exercism/ruby-test-runner`](https://github.com/exercism/ruby-test-runner)).
Puoi dare un'occhiata ai Test Runner esistenti [qui](https://github.com/search?q=topic%3Aexercism-test-runner&type=repositories).

Se vuoi dare una mano con un Test Runner già esistente, apri una issue nel suo repository e chiedi se c'è un punto in cui puoi essere d'aiuto.
Se invece vuoi creare un Test Runner per un linguaggio che al momento non ne ha uno, segui le istruzioni per [creare un Test Runner](/docs/building/tooling/test-runners/creating-from-scratch).
