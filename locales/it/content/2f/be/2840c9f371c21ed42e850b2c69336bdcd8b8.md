# Introduzione

## Stringhe

In C#, una `string` è un oggetto che rappresenta testo immutabile come sequenza di caratteri Unicode (lettere, cifre, punteggiatura, ecc.). Le virgolette doppie si usano per definire un'istanza di `string`:

```csharp
string fruit = "Apple";
```

### Metodi

Le stringhe si manipolano chiamando i [metodi integrati][docs-string-methods] della stringa.
Per esempio, per rimuovere gli spazi bianchi da una stringa, puoi usare il [metodo Trim][tutorial-docs.microsoft.com-trim-white-space] così:

```csharp
string name = " Jane "
name.Trim()
// => "Jane"
```

Una volta costruita, una stringa non può più cambiare valore.
Qualsiasi metodo che sembri modificare una stringa in realtà restituisce una nuova stringa.

### Concatenazione

Più stringhe si possono concatenare (sommare) tra loro. Il modo più semplice per farlo è usare l'operatore `+`.

```csharp
string name = "Jane";
"Hello " + name + "!";
// => "Hello Jane!"
```

### Formattazione

Per qualsiasi formattazione di stringhe più complessa di una semplice concatenazione, è preferibile l'interpolazione di stringhe. Per usare l'interpolazione in una stringa, mettile davanti il simbolo del dollaro (`$`). Poi puoi usare le parentesi graffe (`{}`) per accedere a qualsiasi variabile dentro la stringa.

```csharp
string name = "Jane";
$"Hello {name}!";
// => "Hello Jane!"
```
