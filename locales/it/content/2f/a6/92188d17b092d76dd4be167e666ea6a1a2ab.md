# Introduzione

C è un linguaggio a tipizzazione statica, il che significa che tutto ha un tipo in fase di compilazione.
Scegliere un nome per una variabile e impostarne il tipo si chiama dichiarare una variabile.

Una variabile viene dichiarata specificando esplicitamente il suo tipo.
Il nome di una variabile deve iniziare con una lettera o un underscore.
Alcuni nomi non possono essere usati perché sono riservati [per le parole chiave][reserved-keywords] o [per altri identificatori][reserved-identifiers].

Impostare o aggiornare la variabile avviene tramite l'assegnazione di una variabile.
Impostare il valore definisce quella variabile.
Definire la variabile è anche noto come inizializzazione.

```c
int foo;      // Declare an integer named var
foo = 10;     // Define the variable

int bar = 15; // Both can also be done in a single statement
```

Il valore di una variabile può essere assegnato e aggiornato usando l'operatore di assegnazione semplice `=`.
Una volta definita, il tipo di una variabile non può mai cambiare.

```c
int foo = 10; // Assign initial value
foo = 25;     // Update to new value

foo = false;  // Compiler error when assigning value of a different type
```

C è un linguaggio procedurale imperativo.
Tutto il calcolo viene svolto come parte di una serie di istruzioni che fanno parte di una funzione o di più funzioni.

Ogni funzione può avere zero o più parametri.
Quando si definisce una funzione, tutti i parametri e il valore restituito devono avere un tipo esplicito.
I valori vengono restituiti dalle funzioni usando la parola chiave `return`.
Per impostazione predefinita, le funzioni hanno classe di memorizzazione esterna, il che significa che esistono per tutta la durata del programma e possono essere visibili dall'esterno del file.
Per evitarlo, si può aggiungere la parola chiave `static` per specificare la visibilità interna.

```c
static int add(int x, int y) {
  return x + y;
}
```

Nell'esempio precedente, le variabili `x` e `y` possono essere usate solo all'interno della funzione, cioè hanno uno scope di funzione.
Lo scope è l'idea che il valore associato a un nome (di un elemento del programma) sia accessibile solo all'interno dell'«area» di codice in cui è definito.
Le principali aree di codice in C sono:

- file
- funzione
- blocco (come all'interno di cicli e altri costrutti)

Le funzioni si chiamano specificando il nome della funzione e passando un argomento per ciascuno dei parametri della funzione.

```c
int sum = add(1, 2);
```

C supporta due tipi di commenti.
I commenti su una sola riga sono preceduti da `//` (da C99) e i commenti su più righe sono inseriti tra `/*` e `*/`.
