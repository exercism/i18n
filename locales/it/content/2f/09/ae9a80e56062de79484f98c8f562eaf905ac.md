# Informazioni

Il principale costrutto orientato agli oggetti in C# è la _classe_, che è una combinazione di dati ([_campi_][fields]) e comportamento ([_metodi_][methods]). I campi e i metodi di una classe sono noti come i suoi _membri_.

L'accesso ai membri può essere limitato tramite i modificatori di accesso, i due più comuni dei quali sono:

- [`public`][public]: il membro può essere accessibile da qualsiasi codice (nessuna restrizione).
- [`private`][private]: il membro può essere accessibile solo dal codice nella stessa classe.

Di solito si specifica un modificatore di accesso per tutti i membri. Se non viene specificato alcun modificatore di accesso, per impostazione predefinita sarà `private`.

Il raggruppamento di dati e comportamento correlati descritto sopra, insieme alla limitazione dell'accesso ai membri, è noto come [incapsulamento][encapsulation], uno dei concetti fondamentali della programmazione orientata agli oggetti.

La combinazione dei valori dei campi di un oggetto in un dato momento è nota come lo [stato][object-state] dell'oggetto, cioè le informazioni che descrivono la situazione attuale dell'oggetto.

Puoi pensare a una classe come a un modello per creare istanze di quella classe. Per [creare un'istanza di una classe][creating-objects] (chiamata anche _oggetto_), si usa la parola chiave [`new`][new]:

```csharp
class Car
{
}

// Create two car instances
var myCar = new Car();
var yourCar = new Car();
```

I [campi][fields] hanno un tipo e possono essere definiti ovunque all'interno di una classe.
I campi pubblici sono definiti in [PascalCase][pascal-case] e i campi privati in [camelCase][camel-case], con un underscore `_` come prefisso:

```csharp
class Car
{
    // Accessible by anyone
    public int Weight;

    // Only accessible by code in this class
    private string _color;
}
```

Si può assegnare facoltativamente un valore iniziale a un campo. Se un campo _non_ specifica un valore iniziale, verrà impostato al [valore predefinito][default-values] del suo tipo. I valori dei campi di un'istanza possono essere letti e aggiornati usando la notazione con il punto.

```csharp
class Car
{
    // Will be set to specified value
    public int Weight = 2500;

    // Will be set to default value (0)
    public int Year;
}

var newCar = new Car();
newCar.Weight; // => 2500
newCar.Year;   // => 0

// Update value of the field
newCar.Year = 2018;
```

I campi privati di solito vengono aggiornati come effetto collaterale della chiamata di un metodo. Tali metodi di solito non restituiscono alcun valore, nel qual caso il tipo restituito dovrebbe essere [`void`][void]:

```csharp
class CarImporter
{
    private int _carsImported;

    public void ImportCars(int numberOfCars)
    {
        // Update private field
        _carsImported = _carsImported + numberOfCars;
    }
}
```

Nota che non è consuetudine usare campi pubblici nelle classi C#. Si usano o campi privati o altri tipi di membri di cui parleremo negli esercizi successivi.

All'interno di una classe, la parola chiave [`this`][this] fa riferimento alla classe corrente. Questo è particolarmente utile se un parametro ha lo stesso nome di un campo:

```csharp
class CarImporter
{
    private int carsImported;

    public void SetImportedCars(int carsImported)
    {
        // Update private field from public method
        this.carsImported = carsImported;
    }
}
```

La struttura di classi e metodi offre un modo naturale per limitare la visibilità di elementi del programma come campi e metodi ed evitare il noto [problema dello stato globale][so-global-state-problem]. I campi pubblici, i metodi e gli altri membri devono essere qualificati con il nome dell'oggetto, `object.field` o `object.method()` (il nome della classe nel caso dei membri statici), per essere visibili al codice esterno alla classe. Le variabili e i parametri dichiarati all'interno di un metodo sono visibili solo all'interno di quel metodo.

Una cosa a cui prestare attenzione con questo approccio è che, se il nome di un campo e il nome di una variabile o di un parametro in un metodo coincidono, il codice all'interno del metodo ignorerà il nome del campo, e questo potrebbe non essere ciò che desideri. In generale, dovresti evitarlo quando possibile, anche se è un modello comune nei costruttori. Se è appropriato che il nome del campo e quello della variabile siano uguali, qualifica il nome del campo con la parola chiave `this` all'interno del metodo.

Questi [modificatori di accesso][access-modifiers] possono essere usati per limitare ulteriormente la visibilità.
