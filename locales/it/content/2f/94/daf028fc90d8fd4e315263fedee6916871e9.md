# Appendice alle istruzioni

## Formato della griglia

La griglia è rappresentata come una stringa con terminatore nullo, con un carattere di nuova riga alla fine di ogni riga.

Un esempio sarebbe `"X  \n XO\nOX \n"`.

## Registri

| Registro | Utilizzo     | Tipo    | Descrizione                                                             |
| -------- | ------------ | ------- | ----------------------------------------------------------------------- |
| `$a0`    | input        | indirizzo | stringa di input con terminatore nullo                                |
| `$v0`    | output       | intero  | stato della partita (`1` = `ongoing`, `2` = `draw`, `3` = `win`, `-1` = `error`) |
| `$t0-9`  | temporaneo   | qualsiasi | per l'archiviazione temporanea                                        |
