# Introduzione

Le keyword list sono una struttura dati chiave-valore.

```elixir
[month: "April", year: 2018]
```

Le keyword list sono liste di [tuple][exercism-tuples] `{key, value}` e si possono anche scrivere così, ma la sintassi più breve è quella più usata.

```elixir
[month: "April"] == [{:month, "April"}]
# => true
```

Le chiavi di una keyword list devono essere [atomi][exercism-atoms], ma i valori possono essere qualsiasi cosa. Ogni chiave può essere usata più di una volta. Le coppie chiave-valore di una keyword list sono ordinate.

Puoi lavorare con le keyword list usando gli stessi approcci delle liste, oppure usare il modulo `Keyword`.

[exercism-tuples]: https://exercism.org/tracks/elixir/concepts/tuples
[exercism-atoms]: https://exercism.org/tracks/elixir/concepts/atoms
