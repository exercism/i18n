# Installazione

## Installare tclsh

L'unico strumento che ti serve è l'interprete TCL, `tclsh`.

Per Windows, il posto migliore dove procurarti Tcl è [il programma di installazione di Tcl di Magicsplat][magicsplat].

Su MacOS e sui sistemi operativi di tipo Unix, `tclsh` sarà già installato.
Di solito la versione installata sarà la 8.6.*qualcosa*.
Per installare l'attuale versione stabile 9.0:
 - su MacOS, usa [Homebrew][brew].
 - su Linux, controlla il tuo gestore di pacchetti.
 - oppure [scarica il codice sorgente][download] e [compilalo][build].

Per risolvere gli esercizi usando l'interfaccia web di Exercism, il test runner (a febbraio 2023) usa Tcl versione 8.7a4.

## Usare la shell interattiva di tclsh

È comune avviare una sessione interattiva di [`tclsh`][tclsh] per provare i comandi mentre scrivi il codice.
Tuttavia, tclsh offre solo un interprete REPL molto essenziale, senza editing della riga di comando né cronologia dei comandi.
Per un'esperienza migliore, esiste un programma chiamato `rlwrap` che aggiunge la funzionalità readline:

```bash
rlwrap tclsh
```

Per installare rlwrap:
 - su MacOS, usa [Homebrew][brew].
 - su Linux, controlla il tuo gestore di pacchetti.
 - oppure [scarica il codice sorgente][rlwrap-download] e [compilalo][rlwrap-build].

È così comodo che vorrai usarlo sempre: aggiungi questo al tuo ~/.bashrc

```bash
command -v rlwrap && alias tclsh='rlwrap tclsh'
```

## Quale versione usare?

La versione stabile attuale è la 9.0.
Come indicato sopra, la versione 8.6 è ancora ampiamente diffusa.

Puoi verificare quale versione di `tclsh` hai installato eseguendo il comando seguente:

```bash
echo 'puts [info patchlevel]' | tclsh
```
