# Informazioni

- Pony è un linguaggio a tipizzazione statica. Questo significa che devi definire
  in anticipo i tipi dei dati nei tuoi programmi. Se dici a Pony che la variabile
  `x` è un intero, non puoi assegnarle una stringa.
- È il sistema dei tipi di Pony che rende possibili le garanzie di Pony.
  - Se il tuo programma compila, non andrà in crash.
  - Non ci sarà mai un'eccezione non gestita.
  - `null` non esiste, quindi il tuo programma non proverà mai a
    dereferenziare `null`.
  - Non ci sarà mai una data race.
  - Non ci sarà mai un deadlock.
  - Il tuo codice sarà sempre sicuro rispetto alle capability (protezione dagli
    attacchi alla catena di approvvigionamento.
- Pony non ti permette di eseguire il cast dei tipi. Ogni cambio di tipo deve
  avvenire tramite una funzione che crea una nuova istanza del nuovo tipo.
- Il sistema dei tipi di Pony è diverso da quello di quasi tutti gli altri
  linguaggi, quindi lo affronteremo un pezzetto alla volta.

## Primitives

- I primitive sono la forma più semplice di organizzazione del codice in Pony.
  - Puoi pensarli come un contenitore, o un namespace per le funzioni.
  - Non hanno campi (per quello ci sono le classi).
  - Si definiscono con la parola chiave `primitive`.

## Funzioni

- Le funzioni si definiscono con la parola chiave `fun`.
  - Le funzioni devono trovarsi dentro un `primitive` (o una `class` o un
    `actor`, ma ne parleremo più avanti).
  - Le funzioni possono avere argomenti in input e un valore restituito. Tutto
    deve avere un tipo.
  - Se definisci un tipo restituito, la tua funzione *deve* restituire un valore
    di quel tipo. Pony non ha il concetto di Null.

```pony
primitive Greeter
  // A Function that takes a String, and returns a different String
  fun hello(name: String): String =>
    "Hello " + name + "!"
```

## Commenti

I commenti possono servire a lasciare note, promemoria o semplicemente a
rimuovere temporaneamente del codice dal sorgente. Come hai già visto sopra, i
commenti su una sola riga usano `//`. I commenti su più righe usano lo stile C:
`/*` e `*/`.

## Variabili

- Le variabili iniziano sempre con una lettera minuscola
  - Le dichiareremo usando `var`. (`let` e `embed` arriveranno più avanti).
  - Se Pony riesce a determinare il tipo della variabile, lo farà al posto tuo.
  - Il tipo della variabile viene controllato in fase di compilazione e non può
    mai cambiare.
  - Quando inizi con Pony, ti consigliamo di essere esplicito con il tipo.

```pony
var name: "Bob"
var bettername: String = "Bobby"
```
