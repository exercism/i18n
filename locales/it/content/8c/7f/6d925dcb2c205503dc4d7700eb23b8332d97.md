# Introduzione

`call` (in [`kernel`][kernel]) esegue una quotation. Quando non è possibile dedurne lo stack effect, di solito perché arriva da un'altra parte, dichiara esplicitamente l'effetto su `call`:

```
call( stack-effect ) ! e.g. call( a b -- c )
```

```factor
3 4 [ + ] call .                 ! => 7
3 4 [ + ] call( a b -- c ) .     ! => 7

: apply-binary ( a b op -- c )
    call( a b -- c ) ;

5 3 [ - ] apply-binary .         ! => 2
```

Dato che le quotation sono valori, un array può contenere un misto di numeri e quotation, il che rende «un programma» soltanto un'altra sequenza:

```factor
{ [ 1 + ] [ 2 * ] } 5 swap [ call( x -- y ) ] each .   ! 5 -> 6 -> 12
```

[kernel]: https://docs.factorcode.org/content/vocab-kernel.html
