# Appendice alle istruzioni

## Deprecazione di `String.lowercase`

A seconda della versione di OCaml che hai installato, l'uso di `String.lowercase` è malvisto.
Dalla versione 4.03.0, `String.lowercase` è deprecata a favore di `String.lowercase_ascii`.
Quindi, invece di scrivere

```ocaml
String.lowercase "Hello, World!"
```

usa

```ocaml
String.lowercase_ascii "Hello, World!"
```

Consulta la [documentazione di String][string] per altre funzioni utili.

[string]: http://caml.inria.fr/pub/docs/manual-ocaml/libref/String.html
