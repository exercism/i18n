# Installazione

## Installa il runtime di R
Visita la [pagina iniziale di CRAN](https://cran.r-project.org/). Lì troverai i link per il download di Linux, Mac OSX e Windows. Scarica ed esegui il programma di installazione per il tuo sistema operativo.

## Installa l'IDE RStudio (consigliato)
RStudio è un ambiente di sviluppo integrato (IDE) multipiattaforma molto diffuso per programmare in R (e supporta anche altri linguaggi come Python, JavaScript e Markdown). Usare RStudio renderà più semplice scrivere le soluzioni di codice ed eseguire i test.

Scarica e installa la [versione stabile attuale di RStudio](https://www.rstudio.com/products/rstudio/download/). Oppure, in alternativa, scarica la [versione di anteprima](https://www.rstudio.com/products/rstudio/download/preview/) di una release futura.

## Installa l'estensione di Visual Studio Code per R (alternativa)
L'estensione R per Visual Studio Code supporta l'evidenziazione estesa della sintassi, il completamento automatico del codice, il linting, la formattazione, l'interazione con i terminali R, la visualizzazione di dati, grafici, variabili del workspace e pagine di aiuto, la gestione dei pacchetti e il lavoro con i documenti R Markdown.

Scarica e installa la [versione attuale dell'estensione R](https://code.visualstudio.com/docs/languages/r)

## Installa i pacchetti R per eseguire i test
Il test runner per le specifiche è la libreria [`testthat`](https://github.com/hadley/testthat) di Hadley Wickham, una scelta popolare tra chi scrive pacchetti R.

Per installare questa libreria, digita quanto segue nella console di RStudio (o ovunque tu stia usando R).

```{R}
install.packages("testthat")
```

Anche se è improbabile che tu debba _installare_ dei pacchetti per risolvere gli esercizi di Exercism, potresti voler usare un pacchetto di utilità generico come [`tidyverse`](https://github.com/tidyverse/tidyverse), adatto al tuo stile di programmazione. Per installare e caricare un pacchetto come `tidyverse`:

```{R}
install.packages("tidyverse")
library(tidyverse)
```
