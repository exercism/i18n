# Informazioni

Un template è una stringa o un file che serve a produrre qualsiasi tipo di output sotto forma di stringa, a seconda dell'input.

```haxe
var sample = "My name is ::name::";
var template = new haxe.Template(sample);
var myName = {name: "Joe"};
var output = template.execute(myName);

trace(output); // My name is Joe
```

Tra le altre cose, puoi usare anche le condizioni per eseguire dei controlli all'interno dei template:

```haxe
var sample = "::if isAwake:: I'm awake ::else:: Zzzzz ::end::";
var template = new haxe.Template(sample);
var awake = {isAwake: false};
var output = template.execute(awake);

trace(output); // Zzzzz
```
