# Istruzioni aggiuntive

## Istruzioni specifiche della track

Nell'esercizio "Yacht" creerai un verbo che calcola il punteggio per un singolo lancio di cinque dadi nel gioco Yacht, in base alla categoria scelta.

Per questo esercizio, il verbo riceverà due argomenti:

- **Argomento sinistro**: una stringa che rappresenta la categoria di punteggio da applicare al lancio dei dadi.
- **Argomento destro**: un array di numeri interi che rappresenta i cinque dadi lanciati.

Definisci il verbo in modo che gestisca questi input nel modo seguente:

```j
  category =. 'Full House'
  dice     =. 1 3 3 3 5
  
  category scoreYacht dice
```
