# Insiemi

Un [insieme][type-set] è una collezione _mutabile_ e _non ordinata_ di oggetti [_hashable_][hashable].
Gli elementi di un insieme devono essere distinti: non sono ammessi duplicati.
Possono contenere più tipi di dati diversi e persino strutture annidate come una `tuple` di `tuples`, purché tutti gli elementi siano _hashable_.
Gli insiemi esistono anche in una versione immutabile: i [`frozensets`][type-frozenset].

Gli insiemi sono usati più comunemente per rimuovere rapidamente i duplicati da altre strutture dati o raggruppamenti di elementi.
Si usano anche per confronti efficienti quando non serve mantenere una sequenza né tenere traccia dei duplicati.

Come altri tipi di collezione (_dizionari, liste, tuple_), i `sets` supportano:
- L'iterazione tramite `for item in <set>`
- La verifica di appartenenza tramite `in` e `not in`,
- Il calcolo della lunghezza tramite `len()`, e
- Le copie superficiali tramite `copy()`

I `sets` non supportano:
- Nessun tipo di indicizzazione
- Nessun ordinamento tramite sorting o inserimento
- Lo slicing
- La concatenazione tramite `+`


Verificare l'appartenenza a un `set` ha complessità temporale costante (in media), mentre verificare l'appartenenza a una `list` o a una `string` ha una complessità che cresce all'aumentare della lunghezza dei dati.
Anche metodi come `<set>.union()`, `<set>.intersection()` o `<set>.difference()` hanno complessità temporale costante (in media).


## Letterali di insieme

Un `set` può essere scritto direttamente come _letterale di insieme_, con parentesi graffe `{}` e virgole tra gli elementi.
I duplicati vengono omessi silenziosamente:

```python
>>> one_element = {'➕'}
{'➕'}

>>> multiple_elements = {'➕', '🔻', '🔹', '🔆'}
{'➕', '🔻', '🔹', '🔆'}

>>> multiple_duplicates =  {'Hello!', 'Hello!', 'Hello!', 
                            '¡Hola!','Привіт!', 'こんにちは！', 
                            '¡Hola!','Привіт!', 'こんにちは！'}
{'こんにちは！', '¡Hola!', 'Hello!', 'Привіт!'}
```

I letterali di insieme usano le stesse parentesi graffe dei letterali `dict`, il che significa che per creare un `set` vuoto devi usare `set()`.


## Il costruttore di insiemi

`set()` (_il costruttore della classe `set`_) può essere usato con qualsiasi `iterable` passato come argomento.
Gli elementi dell'`iterable` vengono percorsi e aggiunti al `set` uno per uno.
L'ordine degli elementi non viene preservato e i duplicati vengono omessi silenziosamente:

```python
# To create an empty set, the constructor must be used.
>>> no_elements = set()
set()

# The tuple is unpacked & each element is added.  
# Duplicates are removed.
>>> elements_from_tuple = set(("Parrot", "Bird", 
                               334782, "Bird", "Parrot"))
{334782, 'Bird', 'Parrot'}

# The list is unpacked & each element is added.
# Duplicates are removed.
>>> elements_from_list = set([2, 3, 2, 3, 3, 3, 5, 
                              7, 11, 7, 11, 13, 13])
{2, 3, 5, 7, 11, 13}
```

### Insidie nella creazione degli insiemi

A causa del suo comportamento di «unpacking», usare `set()` con una stringa può sorprendere:

```python
# String elements (Unicode code points) are 
# iterated through and added *individually*.
>>> elements_string = set("Timbuktu")
{'T', 'b', 'i', 'k', 'm', 't', 'u'}

# Unicode separators and positioning code points 
# are also added *individually*.
>>> multiple_code_points_string = set('अभ्यास')
{'अ', 'भ', 'य', 'स', 'ा', '्'}
```

Gli insiemi possono contenere tipi di dati diversi e tipi di dati _annidati_, ma tutti gli elementi di un `set` devono essere _hashable_:

```python
# Attempting to use a list for a set member throws a TypeError
>>> lists_as_elements = {['🌈','💦'], 
                        ['☁️','⭐️','🌍'], 
                        ['⛵️', '🚲', '🚀']}

Traceback (most recent call last):
  File "<stdin>", line 1, in <module>
TypeError: unhashable type: 'list'


# Standard sets are mutable, so they cannot be hashed.
>>> sets_as_elements = {{'🌈','💦'}, 
                        {'☁️','⭐️','🌍'}, 
                        {'⛵️', '🚲', '🚀'}}

Traceback (most recent call last):
  File "<stdin>", line 1, in <module>
TypeError: unhashable type: 'set'
```


## Lavorare con gli insiemi

Gli insiemi hanno metodi che in genere imitano le [operazioni matematiche sugli insiemi][mathematical-sets].
La maggior parte (_non tutti_) di questi metodi ha un equivalente come [operatore][operator].
I metodi in genere accettano qualsiasi `iterable` come argomento, mentre gli operatori richiedono che entrambi i lati dell'operazione siano `sets` o `frozensets`.


### Insiemi disgiunti

Il metodo `<set>.isdisjoint(<other_collection>)` serve a verificare se gli elementi di un `set` si sovrappongono in qualche modo agli elementi di un altro `set`.
Il metodo accetta qualsiasi `iterable` o `set` come argomento.
Restituisce `True` se i due insiemi **non hanno elementi in comune**, `False` se ci sono elementi **condivisi**.
Non esiste un operatore equivalente:


```python
# Both mammals and additional_animals are lists.
>>> mammals = ['squirrel','dog','cat','cow', 'tiger', 'elephant']
>>> additional_animals = ['pangolin', 'panda', 'parrot', 
                          'lemur', 'tiger', 'pangolin']

# Animals is a dict.
>>> animals = {'chicken': 'white',
               'sparrow': 'grey',
               'eagle': 'brown and white',
               'albatross': 'grey and white',
               'crow': 'black',
               'elephant': 'grey', 
               'dog': 'rust',
               'cow': 'black and white',
               'tiger': 'orange and black',
               'cat': 'grey',
               'squirrel': 'black'}
               
# Birds is a set.
>>> birds = {'crow','sparrow','eagle','chicken', 'albatross'}

# Mammals and birds don't share any elements.
>>> birds.isdisjoint(mammals)
True

# There are also no shared elements between 
# additional_animals and birds.
>>> birds.isdisjoint(additional_animals)
True

# Animals and mammals have shared elements.
# **Note** The first object needs to be a set or converted to a set
# since .isdisjoint() is a set method.
>>> set(animals).isdisjoint(mammals)
False
```


### Sottoinsiemi e sovrainsiemi

`<set>.issubset(<other_collection>)` serve a verificare se ogni elemento di `<set>` è presente anche in `<other_collection>`.
La forma con operatore è `<set> <= <other_set>`:


```python
# Both mammals and additional_animals are lists.
>>> mammals = ['squirrel','dog','cat','cow', 'tiger', 'elephant']
>>> additional_animals = ['pangolin', 'panda', 'parrot', 
                          'lemur', 'tiger', 'pangolin']

# Animals is a dict.
>>> animals = {'chicken': 'white',
               'sparrow': 'grey',
               'eagle': 'brown and white',
               'albatross': 'grey and white',
               'crow': 'black',
               'elephant': 'grey', 
               'dog': 'rust',
               'cow': 'black and white',
               'tiger': 'orange and black',
               'cat': 'grey',
               'squirrel': 'black'}

# Birds is a set.
>>> birds = {'crow','sparrow','eagle','chicken', 'albatross'}

# Set methods will take any iterable as an argument.
# All members of birds are also members of animals.
>>> birds.issubset(animals)
True

# All members of mammals also appear in animals.
# **Note** The first object needs to be a set or converted to a set
# since .issubset() is a set method.
>>> set(mammals).issubset(animals)
True

# Both objects need to be sets to use a set operator
>>> birds <= set(mammals)
False

# A set is always a loose subset of itself.
>>> set(additional_animals) <= set(additional_animals)
True
```

`<set>.issuperset(<other_collection>)` è l'inverso di `.issubset()`.
Serve a verificare se ogni elemento di `<other_collection>` è presente anche in `<set>`.
La forma con operatore è `<set> >= <other_set>`:


```python
# All members of mammals also appear in animals.
# **Note** The first object needs to be a set or converted to a set
# since .issuperset() is a set method.
>>> set(animals).issuperset(mammals)
True

# All members of animals do not show up as members of birds.
>>> birds.issuperset(animals)
False

# Both objects need to be sets to use a set operator
>>> birds >= set(mammals)
False

# A set is always a loose superset of itself.
>>> set(animals) >= set(animals)
True
```


### Intersezioni tra insiemi

`<set>.intersection(*<other iterables>)` restituisce un nuovo `set` con gli elementi in comune tra il `set` originale e tutti gli `<others>` (_in altre parole, il `set` in cui tutto si [interseca][intersection]_).
La versione con operatore di questo metodo è `<set> & <other set> & <other set 2> & ... <other set n>`:


```python
>>> perennials = {'Annatto','Asafetida','Asparagus','Azalea',
                 'Winter Savory', 'Broccoli','Curry Leaf','Fennel', 
                 'Kaffir Lime','Kale','Lavender','Mint','Oranges',
                 'Oregano', 'Tarragon', 'Wild Bergamot'}

>>> annuals = {'Corn', 'Zucchini', 'Sweet Peas', 'Marjoram', 
              'Summer Squash', 'Okra','Shallots', 'Basil', 
              'Cilantro', 'Cumin', 'Sunflower', 'Chervil', 
              'Summer Savory'}

>>> herbs = ['Annatto','Asafetida','Basil','Chervil','Cilantro',
            'Curry Leaf','Fennel','Kaffir Lime','Lavender',
            'Marjoram','Mint','Oregano','Summer Savory', 
            'Tarragon','Wild Bergamot','Wild Celery',
            'Winter Savory']


# Methods will take any iterable as an argument.
>>> perennial_herbs = perennials.intersection(herbs)
{'Annatto', 'Asafetida', 'Curry Leaf', 'Fennel', 'Kaffir Lime',
 'Lavender', 'Mint', 'Oregano', 'Wild Bergamot','Winter Savory'}

# Operators require both groups be sets.
>>> annuals & set(herbs)
 {'Basil', 'Chervil', 'Marjoram', 'Cilantro'}
```


### Unioni tra insiemi

`<set>.union(*<other iterables>)` restituisce un nuovo `set` con gli elementi di `<set>` e di tutti gli `<other iterables>`.
La forma con operatore di questo metodo è `<set> | <other set 1> | <other set 2> | ... | <other set n>`:


```python
>>> perennials = {'Asparagus', 'Broccoli', 'Sweet Potato', 'Kale'}
>>> annuals = {'Corn', 'Zucchini', 'Sweet Peas', 'Summer Squash'}
>>> more_perennials = ['Radicchio', 'Rhubarb', 
                      'Spinach', 'Watercress']

# Methods will take any iterable as an argument.
>>> perennials.union(more_perennials)
{'Asparagus','Broccoli','Kale','Radicchio','Rhubarb',
'Spinach','Sweet Potato','Watercress'}

# Operators require sets.
>>> set(more_perennials) | perennials
{'Asparagus',
 'Broccoli',
 'Kale',
 'Radicchio',
 'Rhubarb',
 'Spinach',
 'Sweet Potato',
 'Watercress'}
```


### Differenze tra insiemi

`<set>.difference(*<other iterables>)` restituisce un nuovo `set` con gli elementi del `<set>` originale che non sono presenti in `<others>`.
La versione con operatore di questo metodo è `<set> - <other set 1> - <other set 2> - ...<other set n>`.

```python
>>> berries_and_veggies = {'Asparagus', 
                          'Broccoli', 
                          'Watercress', 
                          'Goji Berries', 
                          'Goose Berries', 
                          'Ramps', 
                          'Walking Onions', 
                          'Blackberries', 
                          'Strawberries', 
                          'Rhubarb', 
                          'Kale', 
                          'Artichokes', 
                          'Currants'}

>>> veggies = ('Asparagus', 'Broccoli', 'Watercress', 'Ramps',
               'Walking Onions', 'Rhubarb', 'Kale', 'Artichokes')

# Methods will take any iterable as an argument.
>>> berries = berries_and_veggies.difference(veggies)
{'Blackberries','Currants','Goji Berries',
 'Goose Berries', 'Strawberries'}

# Operators require sets.
>>> berries_and_veggies - berries
{'Artichokes','Asparagus','Broccoli','Kale',
'Ramps','Rhubarb','Walking Onions','Watercress'}
```


# Differenza simmetrica tra insiemi

`<set>.symmetric_difference(<other iterable>)` restituisce un nuovo `set` che contiene gli elementi presenti in `<set>` O in `<other>`, **ma non in entrambi**.
La versione con operatore di questo metodo è `<set> ^ <other set>`:


```python
>>> plants_1 = {'🌲','🍈','🌵', '🥑','🌴', '🥭'}
>>> plants_2 = ('🌸','🌴', '🌺', '🌲', '🌻', '🌵')


# Methods will take any iterable as an argument.
>>> fruit_and_flowers = plants_1.symmetric_difference(plants_2)
>>> fruit_and_flowers
{'🌸', '🌺', '🍈', '🥑', '🥭','🌻' }


# Operators require both groups be sets.
>>> fruit_and_flowers ^ plants_1
{'🌲',  '🌸', '🌴', '🌵','🌺', '🌻'}

>>> fruit_and_flowers ^ set(plants_2)
{'🥭', '🌴', '🌵', '🍈', '🌲', '🥑'}
```

~~~~exercism/note

La differenza simmetrica di più di due insiemi produce un `set` che include sia gli elementi unici di ciascun `set` SIA gli elementi condivisi tra più di due insiemi della serie (_dettagli nell'articolo di Wikipedia sulla [differenza simmetrica][symmetric_difference]_).  

Per ottenere solo gli elementi unici di ciascun `sets` della serie, le intersezioni tra tutte le combinazioni di 2 insiemi devono essere aggregate in un passaggio separato e poi rimosse:  


```python
>>> one = {'black pepper','breadcrumbs','celeriac','chickpea flour',
           'flour','lemon','parsley','salt','soy sauce',
           'sunflower oil','water'}

>>> two = {'black pepper','cornstarch','garlic','ginger',
           'lemon juice','lemon zest','salt','soy sauce','sugar',
           'tofu','vegetable oil','vegetable stock','water'}

>>> three = {'black pepper','garlic','lemon juice','mixed herbs',
             'nutritional yeast', 'olive oil','salt','silken tofu',
             'smoked tofu','soy sauce','spaghetti','turmeric'}

>>> four = {'barley malt','bell pepper','cashews','flour',
            'fresh basil','garlic','garlic powder', 'honey',
            'mushrooms','nutritional yeast','olive oil','oregano',
            'red onion', 'red pepper flakes','rosemary','salt',
            'sugar','tomatoes','water','yeast'}

>>> intersections = (one & two | one & three | one & four | 
                     two & three | two & four | three & four)
...
{'black pepper','flour','garlic','lemon juice','nutritional yeast', 
'olive oil','salt','soy sauce', 'sugar','water'}

# The ^ operation will include some of the items in intersections, 
# which means it is not a "clean" symmetric difference - there
# are overlapping members.
>>> (one ^ two ^ three ^ four) & intersections
{'black pepper', 'garlic', 'soy sauce', 'water'}

# Overlapping members need to be removed in a separate step
# when there are more than two sets that need symmetric difference.
>>> (one ^ two ^ three ^ four) - intersections
...
{'barley malt','bell pepper','breadcrumbs', 'cashews','celeriac',
  'chickpea flour','cornstarch','fresh basil', 'garlic powder',
  'ginger','honey','lemon','lemon zest','mixed herbs','mushrooms',
  'oregano','parsley','red onion','red pepper flakes','rosemary',
  'silken tofu','smoked tofu','spaghetti','sunflower oil', 'tofu', 
  'tomatoes','turmeric','vegetable oil','vegetable stock','yeast'}
```
