# Istruzioni

In questo esercizio dovrai implementare alcune funzioni per manipolare un array di linguaggi di programmazione.

## 1. Definisci una funzione che restituisce un array di linguaggi vuoto

Definisci la funzione `new` che non prende argomenti e restituisce un array vuoto.

```haskell
new
-- -> []
```

## 2. Definisci una funzione che aggiunge un linguaggio all'array

Definisci la funzione `add/2` che prende 2 argomenti (un _array di linguaggi_ e una stringa letterale che rappresenta un _linguaggio_).
Deve restituire l'array risultante, con il nuovo linguaggio inserito in testa a quello dato.

```haskell
add new "Clojure"
-- -> ["Clojure"]
add ["Clojure"] "Haskell"
-- -> ["Haskell", "Clojure"]
```

## 3. Definisci una funzione che rimuove un linguaggio dall'array

Definisci la funzione `remove` che prende 1 argomento (un _array di linguaggi_).
Deve restituire l'array senza il primo elemento. Supponi che l'array abbia sempre almeno un elemento.

```haskell
remove ["Haskell", "Clojure", "Erlang"]
-- -> ["Clojure", "Erlang"]
```

## 4. Definisci una funzione che restituisce il primo elemento dell'array

Definisci la funzione `first` che prende 1 argomento (un _array di linguaggi_).
Deve restituire il primo linguaggio presente nell'array.
Supponi che l'array abbia sempre almeno un elemento.

```haskell
first ["Elixir", "Haskell", "Clojure", "Prolog"]
-- -> "Elixir"
```

## 5. Definisci una funzione che restituisce quanti linguaggi ci sono nell'array

Definisci la funzione `count` che prende 1 argomento (un _array di linguaggi_). 
Deve restituire il numero di linguaggi presenti nell'array.

```haskell
count ["Prolog", "Elm"]
-- -> 2
```

## 6. Definisci una funzione che determina se l'array contiene un linguaggio funzionale

Definisci la funzione `isFunctionalList` che prende 1 argomento (un _array di linguaggi_). 
Deve restituire un valore booleano. 
Deve restituire `True` se _"Haskell"_ è uno dei linguaggi presenti nell'array.

```haskell
isFunctionalList ["Haskell"]
-- -> True
```
