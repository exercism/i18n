# Introduzione

## L'espressione if

L'**espressione condizionale** di `jq` è `if A then B else C end`.

`if-then-else` è un filtro come tutti i filtri integrati di `jq`: prende un input e produce un output.

Se l'espressione `A` produce un valore «veritiero», il filtro `if` valuta `B`.
Altrimenti valuta `C`.
L'input del filtro `if` verrà passato a `B` o a `C`.

```jq
42 | if . < 50 then "small" else "big" end      # => "small"
```

```jq
5 | if . % 2 == 0 then . / 2 else . * 4 end     # => 20
```

~~~~exercism/note
La clausola `else` è **facoltativa**; le due istruzioni seguenti sono equivalenti.

```jq
if A then B else . end
if A then B end
```
~~~~

## Istruzioni if annidate

Si possono aggiungere altre condizioni con `elif`.

```jq
42 | if . < 33 then "small"
     elif . < 66 then "medium"
     else "big"
     end
# => "medium"
```

Usa tutte le clausole `elif` che ti servono.

## Valori veri e falsi

Gli unici valori «falsi» in `jq` sono: `false` e `null`.
Tutto il resto è «vero», persino il numero zero, la stringa vuota, l'array vuoto e l'oggetto vuoto.

## Operatori booleani

Gli **operatori booleani** `and` e `or` si possono usare per costruire query complesse.

```jq
42 | if . < 33 or . > 66 then "big or small"
     else "medium"
     end
```

Per negare, usa `not`. Questo è un **filtro**, non un operatore.

```jq
42 | if (. < 33 or . > 66 | not) then "medium"
     else "big or small"
     end
```

## Operatore alternativo

L'**operatore alternativo** ti permette di specificare un valore «predefinito» se un'espressione è falsa o null.

```jq
A // B

# This is identical to
if A then A else B end
```

Per dimostrarlo

```jq
[3, 5, 18] | add / 2       # => 13
[]         | add / 2       # => error: null (null) and number (2) cannot be divided
[]         | add // 0 / 2  # => 0
```
