# Appendice alle istruzioni

## Registri

| Registro | Utilizzo   | Tipo    | Descrizione                     |
| -------- | ---------- | ------- | ------------------------------- |
| `$a0`    | input      | indirizzo | array dei pesi degli oggetti   |
| `$a1`    | input      | indirizzo | array dei valori degli oggetti |
| `$a2`    | input      | intero  | numero di oggetti               |
| `$a3`    | input      | intero  | peso massimo                    |
| `$v0`    | output     | intero  | valore massimo                  |
| `$t0-9`  | temporaneo | qualsiasi | usato come memoria temporanea  |
