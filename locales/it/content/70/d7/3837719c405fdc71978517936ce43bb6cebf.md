# Array

`ARRAY{T}` è una sequenza fissa di valori di tipo `T`.

```sather
   row : ARRAY{STR} := |"Mia", "Ana", "Ben"|;
   sizes : ARRAY{INT} := |3, 1, 2|;
```

## Le parentesi graffe

`ARRAY{STR}` si legge «array di `STR`». Tra le parentesi graffe c'è un **parametro di tipo**: `ARRAY` da solo non è un tipo, perché un array deve pur essere un array di qualcosa. Gran parte della libreria di Sather è costruita in questo modo, e scrivere da soli una classe del genere verrà dopo.

## Le posizioni

```sather
row[0]                 -- the first
row[row.size - 1]      -- the last
row.size               -- how many
```

Le posizioni vanno da `0` a `.size - 1`. Un array conosce la propria dimensione e non la cambia mai: a un `ARRAY` non si può aggiungere nulla in coda.

## Crearne uno senza un letterale

`#ARRAY{INT}(n)` crea un array di `n` valori, tutti uguali a zero:

```sather
   counts ::= #ARRAY{INT}(5);      -- five noughts
   counts[0] := 7;
```

Assegnare un valore a una posizione usa le stesse parentesi quadre a sinistra di `:=`.

## Fuori intervallo

Leggere o scrivere una posizione che non esiste non viene controllato in una normale compilazione. Non fermerà il programma con un messaggio utile: leggerà o scriverà qualunque cosa capiti di trovare subito dopo in memoria. Due abitudini lo evitano: usa `.size - 1` invece di un numero contato a occhio, e chiudi i cicli con `until!(i >= a.size)` invece che con un valore letterale.

## Stamparne uno

`.str` restituisce il contenuto tra parentesi graffe, cosa comoda mentre si sta mettendo a punto qualcosa:

```sather
   #OUT + row.str;      -- {Mia,Ana,Ben}
```
