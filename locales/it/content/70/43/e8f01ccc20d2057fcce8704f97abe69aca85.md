# Test

La maggior parte dei test verifica che, assegnando a [result] o passando un valore a [exit], restituisci il valore atteso.

Alcuni test verificano che [raise] l'eccezione attesa.

## Eseguire i test

Per eseguire i test è necessaria l'utility `make`.

Dalla directory dell'esercizio, digita in una console o in un terminale:

```sh
make
```

Se non hai nemmeno toccato il file della soluzione dell'esercizio, vedrai un messaggio simile a:

```
Please implement your solution.
```

Quindi rimuovi questa riga prima di iniziare a scrivere la soluzione.

Per impostazione predefinita viene eseguito solo il primo test.

```text
TAP version 14
1..10
ok 1 - ...
```

Per eseguire tutti i test, digita:

```sh
make test=all
```

```text
TAP version 14
1..10
ok 1 - empty_sentence
ok 2 - perfect_lower_case
ok 3 - only_lower_case
ok 4 - missing_the_letter_x
ok 5 - missing_the_letter_h
ok 6 - with_underscores
ok 7 - with_numbers
ok 8 - missing_letters_replaced_by_numbers
ok 9 - mixed_case_and_punctuation
ok 10 - am_and_AM_are_26_different_characters_but_not_a_pangram
```

Quando tutti i test passano, hai finito l'esercizio e puoi inviare la soluzione.

È possibile scegliere un singolo test da eseguire passando il numero corrispondente, ad esempio:

```sh
make test=2
```

eseguirebbe solo il secondo test.
