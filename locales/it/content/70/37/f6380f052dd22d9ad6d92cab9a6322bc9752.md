# Namespace

Un metodo importante per organizzare il codice è l'uso dei namespace.
Le classi e i moduli forniscono namespace.
Due metodi potrebbero avere una collisione di nomi. Si può risolvere mettendoli in namespace diversi.
I namespace possono essere annidati, il che può aiutare a strutturare codebase di grandi dimensioni.
Si accede ai namespace tramite l'operatore di risoluzione dello scope `::`.

L'esempio seguente mostra l'uso di due metodi `foo` diversi.
Vengono usati insieme anteponendo i rispettivi namespace.

```ruby
class MyNamespace
  def self.foo
    44
  end

  class MyInnerNamespace
    def self.baz
      90
    end
  end
end

class MyOtherNamespace
  def self.foo
    -2
  end
end

p MyNamespace::foo + MyOtherNamespace::foo * MyNamespace::MyInnerNamespace::baz  # => -136
```

Tieni presente che i namespace vengono interpretati in base a dove si trova il codice in esecuzione.
Per fare riferimento a qualcosa nel namespace *root*, cioè al di fuori di tutti i namespace definiti, inizia con `::`.

Per esempio:

```ruby
class Example
  def self.example
    5
  end
end

class MyNamespace

  class Example
    def self.example
      10
    end
  end

  def self.call_example
    p Example::example  # => 10
    p ::Example::example  # => 5
  end
end
```
