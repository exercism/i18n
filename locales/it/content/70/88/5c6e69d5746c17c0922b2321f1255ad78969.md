# Aiuto

Se hai difficoltà, per ottenere aiuto puoi usare una di queste risorse:

- La [Groovy Language Documentation](http://docs.groovy-lang.org/docs/latest/html/documentation/)
- La voce [Groovy Community](http://www.groovy-lang.org/community.html) della Groovy Language Documentation
- [/r/groovy](https://www.reddit.com/r/groovy) è il subreddit di Groovy.
- Puoi usare [StackOverflow](http://stackoverflow.com/questions/tagged/groovy) per cercare il tuo problema e vedere se è già stato risolto. Puoi anche fare domande e rispondere.
