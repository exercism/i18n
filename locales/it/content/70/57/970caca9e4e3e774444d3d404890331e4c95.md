# Apprendimento

Odin è un linguaggio di programmazione di sistema.
Come in C, chi programma deve gestire la memoria manualmente.
Tuttavia è un linguaggio piuttosto semplice.

Le seguenti risorse possono aiutarti a imparare Odin:

Per un primo assaggio del linguaggio:

* Guarda [Introduction to Odin][video], presentato dal creatore di Odin.
* Leggi l'articolo [Introduction to Odin][intro], scritto dall'autore di «Understanding the Odin Programming Language».
* Studia il [file demo][demo], che mostra in codice i concetti di Odin.

Per approfondire:

* La [panoramica del linguaggio Odin][overview].
* La documentazione per i [pacchetti ufficiali][packages].
* Il libro «Understanding the Odin Programming Language» (a pagamento).
* La raccolta ufficiale di «Odin Examples».
