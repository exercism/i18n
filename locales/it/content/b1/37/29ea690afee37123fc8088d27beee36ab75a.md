# Classi generiche

Hai usato `ARRAY{STR}`, `FMAP{STR,INT}` e `FSET{STR}` fin dall'inizio.
Le parentesi graffe hanno sempre contenuto un tipo. Adesso scrivi una classe
con parentesi graffe tutte sue.

## Il problema

L'ufficio oggetti smarriti ha bisogno di una scatola che contenga una cosa sola
e ricordi chi l'ha consegnata. Una scatola per un maglione:

```sather
class JUMPER_BOX is
   attr item : JUMPER;
   ...
end;
```

e poi di nuovo la stessa classe per una borraccia, e ancora per un telefono.
Tre copie che differiscono per una parola.

## Il parametro di tipo

```sather
class LOST_BOX{T} is

   attr item : T;

   create(thing : T) : SAME is
      box ::= new;
      box.item := thing;
      return box;
   end;

end; -- class LOST_BOX{T}
```

`{T}` dopo il nome della classe è un **parametro di tipo**. `T` non è un
tipo: è un segnaposto per qualunque tipo venga fornito quando si usa la
classe. All'interno della classe, `T` si usa esattamente come si userebbe
qualsiasi nome di tipo.

## Come si usa

Fornisci il tipo tra parentesi graffe:

```sather
   jumper ::= #LOST_BOX{STR}("blue jumper");
   count ::= #LOST_BOX{INT}(3);

   jumper.item      -- "blue jumper", a STR
   count.item       -- 3, an INT
```

`LOST_BOX{STR}` e `LOST_BOX{INT}` sono due tipi diversi. Mettere l'uno dove
serve l'altro è un errore che il compilatore intercetta, esattamente come se
avessi scritto le due classi a mano: ed è proprio quello che succede, in
effetti. Sather costruisce una classe separata a partire dallo schema, per
ogni tipo effettivamente usato.

Quindi non c'è alcun costo in fase di esecuzione, né alcuna perdita di
informazioni sul tipo: `jumper.item` è davvero una `STR`, non qualcosa che
vada controllato o convertito.

## Più di uno

Una classe può accettare più parametri, separati da virgole. `FMAP{K,T}` è
l'esempio che già conosci.

```sather
class LABELLED{L,T} is
   attr label : L;
   attr item : T;
   ...
end;
```

## Come si chiamano

Per convenzione si usano singole lettere maiuscole: `T` per una cosa, `K` per
una chiave, `E` per un elemento. La libreria le usa ovunque.
