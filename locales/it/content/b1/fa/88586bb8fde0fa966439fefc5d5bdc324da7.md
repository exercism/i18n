# concatenazione di stringhe

La concatenazione di stringhe è perfettamente valida in Crystal, ma un modo più comune per comporre una stringa è [l'interpolazione di stringhe][interpolation].
Per esempio:

```crystal
# Rather than:
"One for " + name_variable + ", one for me"

# Consider:
"One for #{name_variable}, one for me."
```

[interpolation]: https://crystal-lang.org/reference/latest/syntax_and_semantics/literals/string.html#interpolation
