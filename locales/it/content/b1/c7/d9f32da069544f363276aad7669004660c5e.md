# Suggerimenti

## Generale

- Tutte le parole per leggere e scrivere si trovano in [`io.files`][io.files]; la codifica `utf8` che accettano tutte proviene da [`io.encodings.utf8`][utf8].

## 1. Leggi ogni lettura

- `file-lines` restituisce un array di righe con i caratteri di nuova riga rimossi.

## 2. Trova la lettura più recente

- Leggi le righe con `file-lines`, poi prendi l'ultima con `last` (da `sequences`).

## 3. Leggi il log grezzo

- `file-contents` restituisce il file come un'unica stringa, caratteri di nuova riga inclusi.

## 4. Registra una lettura

- Apri il file in modalità append e passa la lettura a `print` all'interno della quotation: `with-file-appender ( path encoding quot -- )`. La lettura viene usata dentro la quotation mentre il path viene consumato prima, quindi le variabili locali di `::` mantengono il corpo leggibile: `:: record-reading ( reading path -- ) path utf8 [ reading print ] with-file-appender ;`.

## 5. Riscrivi il log

- `set-file-lines` scrive ogni elemento di una sequenza su una riga separata, aggiungendo i caratteri di nuova riga al posto tuo.

[utf8]: https://docs.factorcode.org/content/vocab-io.encodings.utf8.html
