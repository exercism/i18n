# Appendice alle istruzioni

## Parole

- `tick ( matrix cols -- matrix' )` — avanza la griglia di una
  generazione e restituisce la nuova griglia.

Ogni riga della griglia è rappresentata da un numero intero a 64 bit; `cols` è
il numero di colonne (al massimo 64). Per esempio,

```
    0 1 0
    1 0 0
    1 1 0
```

è rappresentata come

```
0b010
0b100
0b110
```
