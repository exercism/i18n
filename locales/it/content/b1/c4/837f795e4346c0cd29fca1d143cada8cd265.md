# Introduzione

## Interi

In Gleam ci sono due tipi diversi di numeri: gli interi e i numeri in virgola mobile.

Gli interi sono numeri senza parte decimale.

```gleam
let integer = 3
// -> 3
```

Gleam ha diversi operatori che funzionano con gli interi.

```gleam
1 + 1 // -> 2
5 - 1 // -> 4
5 / 2 // -> 2
3 * 3 // -> 9
5 % 2 // -> 1

2 > 1  // -> True
2 < 1  // -> False
2 >= 1 // -> True
2 <= 1 // -> False
```

## Numeri in virgola mobile

I numeri in virgola mobile hanno una o più cifre dopo il separatore decimale.

```gleam
let float = 3.45
// -> 3.45
```

Anche i numeri in virgola mobile hanno il proprio insieme di operatori.

```gleam
1.0 +. 1.4 // -> 2.4
5.0 -. 1.5 // -> 3.5
5.0 /. 2.0 // -> 2.5
3.0 *. 3.1 // -> 9.3

2.0 >. 1.0  // -> True
2.0 <. 1.0  // -> False
2.0 >=. 1.0 // -> True
2.0 <=. 1.0 // -> False
```

## Moduli

### Moduli

Il codice Gleam è organizzato in moduli, e ogni file è un modulo Gleam.

Finora abbiamo scritto funzioni con la sintassi `pub fn`, che definisce una funzione disponibile pubblicamente per gli altri moduli. Le funzioni definite con `fn` sono visibili solo all'interno del modulo in cui sono definite e non possono essere usate da altri moduli.

```gleam
// This function is public
pub fn add(x, y) {
  x + y
}

// This function is private
fn subtract(x, y) {
  x - y
}
```

I moduli Gleam hanno un nome, che deriva dal loro percorso file all'interno della directory `src` o `test`.

Per esempio, un modulo definito in `src\geometry\rectangle.gleam` (su Windows) o `src/geometry/rectangle.gleam` (su sistemi operativi simili a UNIX) si chiamerebbe `geometry/rectangle`.

### Importare funzioni da altri moduli

Per accedere alle funzioni definite in altri moduli si usano gli import.
Quando si importa un modulo, tutte le funzioni che esso espone diventano accessibili.
Ma come accedervi dipende da come si importa il modulo.

Gli import qualificati sono quelli predefiniti: per accedere a una funzione di un modulo così importato (per esempio la funzione `map` del modulo `gleam/list`) si antepone il nome del modulo (`list.map`).

```gleam
// Import the int module
import gleam/int

pub fn run(x: Int) -> String {
  // Use the to_string function from the int module
  int.to_string(x)
}
```

Per impostazione predefinita, il nome usato per riferirsi al modulo è l'ultima parte del nome del modulo, in questo caso `int`, ma lo si può cambiare usando la parola chiave `as`.

```gleam
// Import the int module and refer to it as i
import gleam/int as i

pub fn run(x: Int) -> String {
  i.to_string(x)
}
```

Gli import non qualificati consentono di accedere direttamente alle funzioni esposte da quel modulo, senza anteporre nulla.

```gleam
// Import the to_string function from the int module
import gleam/int.{to_string}

pub fn run(x: Int) -> String {
  to_string(x)
}
```

Gli import qualificati sono preferibili perché rendono più chiaro al lettore da dove viene una funzione ed evitano conflitti di nomi.


### Libreria standard

Gleam ha una libreria standard ricca e ben documentata. La documentazione è disponibile online su [hexdocs.pm/gleam_stdlib][docs]. Salva questo link da qualche parte: ti servirà spesso!

La maggior parte dei tipi di dati integrati ha un modulo corrispondente che offre funzioni per lavorare con quel tipo di dati. Per esempio, c'è il modulo `gleam/int` per gli interi, il modulo `gleam/string` per le stringhe, il modulo `gleam/list` per gli array e così via.

[docs]: https://hexdocs.pm/gleam_stdlib/
