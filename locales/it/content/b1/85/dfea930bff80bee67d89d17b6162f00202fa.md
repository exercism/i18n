# Appendice alle istruzioni

## Registri

| Registro | Utilizzo   | Tipo      | Descrizione                                                  |
| -------- | ---------- | --------- | ------------------------------------------------------------ |
| `$a0`    | input      | indirizzo | stringa di caratteri esadecimali terminata da null           |
| `$v0`    | output     | intero    | valore decimale della stringa di input                       |
| `$t0-9`  | temporaneo | qualsiasi | usato per l'archiviazione temporanea                         |
