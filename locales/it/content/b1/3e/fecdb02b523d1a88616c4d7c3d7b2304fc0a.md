# Introduzione

Lavorare con i dati binari è un concetto importante in qualsiasi linguaggio, ed Elixir offre una sintassi elegante per scrivere, confrontare e costruire dati binari.

In Elixir, i dati binari prendono il nome di tipo bitstring. Il _tipo_ di dati binari (da non confondere con i dati binari in generale) è una forma specifica di bitstring, di cui parleremo in un esercizio successivo.

I letterali bitstring si definiscono usando la forma speciale bitstring `<<>>`. Un letterale bitstring si definisce per segmenti. Ogni segmento ha un valore e un tipo, separati dall'operatore `::`. Il tipo specifica quanti bit verranno usati per codificare il valore. Il tipo può essere omesso del tutto; in tal caso si usa per impostazione predefinita un valore intero a 8 bit.

```elixir
# This defines a bitstring with three segments of a single bit each
<<0::1, 1::1, 0::1>>
```

Specificare il tipo come `::1` è una scorciatoia per scrivere `::size(1)`. Se la dimensione in bit proviene da una variabile, devi usare la sintassi più lunga.

## Binario

Quando scriviamo letterali interi binari, possiamo scriverli direttamente in notazione in base 2 facendo precedere il letterale da `0b`. Tieni presente che in ogni caso verranno mostrati come numeri decimali quando compaiono nei risultati dei test o quando usi iex.

```elixir
<<0b1011::4>> == <<11::4>>
# => true
```

## Troncamento

Se il valore del segmento supera la capacità del tipo del segmento, viene troncato da sinistra.

```elixir
<<0b1011::3>> == <<0b0011::3>>
# => true
```

## Aggiungere all'inizio e alla fine

Puoi aggiungere sia all'inizio sia alla fine di una bitstring esistente usando la forma speciale. Se la bitstring esistente è di dimensione sconosciuta, devi usare il tipo `::bitstring`.

```elixir
value = <<0b110::3, 0b001::3>>
new_value = <<0b011::3, value::bitstring, 0b000::3>>
# => <<120, 8::size(4)>>
```

## Concatenazione

Possiamo concatenare bitstring memorizzate in variabili usando la forma speciale. Il tipo `::bitstring` va usato quando si concatenano due bitstring di dimensione sconosciuta.

```elixir
first = <<0b110::3>>
second = <<0b001::3>>
concatenated = <<first::bitstring, second::bitstring>>
# => <<49::size(6)>>
```

## Pattern matching

Puoi usare il pattern matching anche per ottenere valori dalla forma speciale. Devi conoscere il numero di bit di ogni frammento che vuoi catturare, con un'eccezione: il tipo `::bitstring` può essere usato per fare pattern matching su una bitstring di dimensione sconosciuta, ma solo per l'ultimo frammento.

```elixir
<<value::4, rest::bitstring>> = <<0b01101001::8>>
value == 0b0110
# => true
```

## Ispezionare le bitstring

~~~~exercism/note
Le bitstring potrebbero essere stampate (dal test runner o in iex) in un
formato diverso da quello usato per crearle. Questo causa spesso
confusione quando si imparano le bitstring.
~~~~

Per impostazione predefinita, le bitstring vengono mostrate in frammenti di 8 bit (un byte), anche se le hai create con frammenti di dimensione diversa.

```elixir
<<2011::11>>
# => <<251, 3::size(3)>>
```

Se crei una bitstring che rappresenta una stringa codificata in UTF-8 stampabile, viene mostrata come stringa.

```elixir
<<>>
# => ""

<<65, 66, 67>>
# => "ABC"
```
