# Suggerimenti

## Generale

- Non preoccuparti di come vengono derivati gli argomenti: concentrati solo sul combinarli per restituire il risultato voluto.
- Unison ha [regole specifiche per la precedenza degli operatori][operator-precedence]: ricorda di usare le parentesi se devi ordinare diversamente l'applicazione delle funzioni

## 1. Definisci se Pac-Man può mangiare un fantasma

- Devi definire una funzione con 2 argomenti. Il primo argomento è un valore [booleano][boolean], se pac-man ha una power pellet attiva. Il secondo argomento è un valore [booleano][boolean], se pac-man sta toccando un fantasma.
- La funzione deve restituire un valore [booleano][boolean].
- Puoi usare l'operatore [booleano][boolean] `&&` per combinare gli argomenti ed ottenere un risultato.

## 2. Definisci se Pac-Man segna

- Devi definire una funzione con 2 argomenti. Il primo argomento è un valore [booleano][boolean], se pac-man sta toccando una power pellet. Il secondo argomento è un valore [booleano][boolean], se pac-man sta toccando un punto.
- La funzione deve restituire un valore [booleano][boolean].
- Puoi usare l'operatore [booleano][boolean] `||` per combinare gli argomenti ed ottenere un risultato.

## 3. Definisci se Pac-Man perde

- Devi definire una funzione con 2 argomenti. Il primo argomento è un valore [booleano][boolean], se pac-man ha una power pellet attiva. Il secondo argomento è un valore [booleano][boolean], se pac-man sta toccando un fantasma.
- La funzione deve restituire un valore [booleano][boolean].
- Puoi usare gli operatori [booleani][boolean] `&&` e `not` per combinare gli argomenti ed ottenere un risultato.

## 4. Definisci se Pac-Man vince

- Devi definire una funzione con 3 argomenti. Il secondo argomento è un valore [booleano][boolean], se pac-man ha mangiato tutti i punti. Il primo argomento è un valore [booleano][boolean], se pac-man ha una power pellet attiva. Il secondo argomento è un valore [booleano][boolean], se pac-man sta toccando un fantasma.
- La funzione deve restituire un valore [booleano][boolean].
- Puoi usare gli operatori [booleani][boolean] `&&` e `not` per combinare gli argomenti ed i risultati delle funzioni chiamate.

[boolean]: https://elixir-lang.org/getting-started/basic-types.html#booleans
