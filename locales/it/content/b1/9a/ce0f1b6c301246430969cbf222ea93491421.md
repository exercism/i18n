# Informazioni

Le [stringhe][strings] in Haxe sono oggetti immutabili che rappresentano il testo come una sequenza di caratteri Unicode (lettere, cifre, punteggiatura e così via). Per definire un'istanza di `string` si usano le virgolette doppie:

```haxe
var fruit:String = "Apple";
```

Per manipolare una stringa si può chiamare uno dei suoi [metodi o proprietà][string-api]. Dato che il valore di una stringa non può mai cambiare dopo essere stato definito, tutti i metodi di manipolazione delle stringhe restituiscono una nuova stringa.

Una stringa è delimitata da virgolette doppie (`"`). Alcuni caratteri speciali richiedono una [sequenza di escape][escaping] usando il carattere barra rovesciata (`\`). Inoltre, le stringhe di Haxe sono multiriga e permettono di costruire facilmente stringhe letterali lunghe:

```haxe
var escaped:String = "c:\\test.txt";
var multiline:String = "
- apple
- pear
- banana";
```

Il modo più semplice per concatenare le stringhe è usare l'[operatore `+`][plus-operator].

```haxe
var name:String = "Jane";
trace("Hello " + name + "!");
// => "Hello Jane!"
```

Per una formattazione delle stringhe più complessa, è preferibile l'[interpolazione di stringhe][interpolation]. Per farlo, si racchiude la stringa tra virgolette singole (`'`) e si usa il simbolo del dollaro (`$`) per attivare l'interpolazione delle variabili. È anche possibile valutare intere espressioni usando `${expr}`, dove `expr` è una qualsiasi espressione Haxe valida:

```haxe
var name:String = "Jane";
trace('Hello $name!');
// => "Hello Jane!"
trace('HELLO ${name.toUpperCase()}!');
// => "HELLO JANE!"
```
