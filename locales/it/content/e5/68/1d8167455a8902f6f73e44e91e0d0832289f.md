# Test

Per ogni esempio, occorre seguire questi passaggi generali.

Per prima cosa, entra nella directory dell'esercizio su cui vuoi esercitarti, in questo caso `bob`.

```bash
$ cd </path/to/exercism>/lfe/bob
```

Poi esegui i test. Il target `test` di make dipende da `compile`, quindi eseguire `make test` assicura che il codice venga compilato e poi passa a eseguire i test.


```bash
$ make test
```

Congratulazioni! Hai dei test che falliscono!!!

Ora leggi `README.md` per scoprire cosa devi fare per far passare tutti i test.


Correggi il primo errore segnalato dal test ed esegui di nuovo i test.

```bash
$ make test
```

Continua a correggere il prossimo test che fallisce nel codice e a rieseguire i test finché non passano tutti.

Una volta che tutti i test passano, dai un'ultima occhiata al codice nella directory `src` per assicurarti che ti soddisfi e invia per la revisione.

Ricevi un feedback, rivedi la soluzione, invia di nuovo, prova l'esercizio successivo e ripeti il ciclo finché non raggiungi l'illuminazione su LFE.
