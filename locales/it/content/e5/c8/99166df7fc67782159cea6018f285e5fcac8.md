# Approfondimento

Il collegamento descrive da dove nel codice è possibile accedere a un identificatore.
I valori con scope di blocco, di funzione o di prototipo di funzione non hanno collegamento.
Questo significa che non è possibile accedervi dall'esterno del loro scope.
Per saperne di più sullo scope, consulta il [concetto di scope](../scope/introduction.md#Introduction).

## Collegamento esterno

Gli identificatori con scope di file hanno il collegamento esterno per impostazione predefinita.
Un identificatore con collegamento esterno può essere chiamato da qualsiasi file del programma.

## Collegamento interno

Un identificatore con scope di file può avere il collegamento interno usando lo specificatore `static`.
Un identificatore con collegamento interno può essere usato solo all'interno del suo file.

Per esempio

```c
int public_count = 0; // file scope, external linkage by default
static int private_count = 0;  // file scope, internal linkage 

// file scope, internal linkage
static void some_function()
{
    // code snipped
}

// file scope, external linkage by default
int main()
{
    // code snipped
}
```

Il collegamento statico non va confuso con la durata di memorizzazione statica.
Per saperne di più sulla durata di memorizzazione statica, consulta il [concetto di durata di memorizzazione](https://github.com/exercism/c/blob/main/concepts/storage-class-specifiers/about.md#static-the-storage-specifier-not-to-be-confused-with-the-static-linkage-type).

Se un valore, a differenza di una funzione, è dichiarato in un file di intestazione ma è definito nel file sorgente come identificatore `static` con scope di file e con un valore inizializzato, il suo valore inizializzato non sarà accessibile dall'esterno del suo file sorgente.
Potrebbe compilare, collegare ed eseguire senza errori, ma il valore sarà il valore zero per l'identificatore, anche se il valore è dichiarato con `extern`.
(Per saperne di più su `extern`, consulta il [concetto di `extern`](https://github.com/exercism/c/blob/main/concepts/storage-class-specifiers/about.md#extern-how-to-access-a-variable-in-another-translation-unit).)
Un identificatore con scope di file contrassegnato come `static` in un file sorgente non dovrebbe essere dichiarato nel suo file di intestazione.
