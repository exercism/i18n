# Introduzione

## Sintassi generale

Il ciclo for è una delle istruzioni più usate per eseguire più volte la stessa logica.
In Go è composto dalla parola chiave `for`, da un'intestazione e da un blocco di codice che contiene il corpo del ciclo racchiuso tra parentesi graffe.
L'intestazione è composta da 3 componenti separati da punto e virgola (`;`): init, condition e post.

```go
for init; condition; post {
  // loop body - code that is executed repeatedly as long as the condition is true
}
```

- La componente **init** è del codice che viene eseguito una sola volta prima che il ciclo inizi.
- La componente **condition** deve essere un'espressione che restituisce un valore booleano e stabilisce quando il ciclo deve fermarsi.
  Il codice all'interno del ciclo viene eseguito finché questa condizione è vera.
  Non appena l'espressione diventa falsa, il ciclo non esegue più nessuna iterazione.
- La componente **post** è del codice che viene eseguito alla fine di ogni iterazione.

**Nota:** a differenza di altri linguaggi, non ci sono parentesi tonde (`()`) attorno alle tre componenti dell'intestazione.
Anzi, inserirle è un errore di compilazione.
Le parentesi graffe (`{ }`) attorno al corpo del ciclo, invece, sono sempre obbligatorie.

## Cicli for: un esempio

Di solito la componente init inizializza una variabile contatore, la condizione controlla se il ciclo deve continuare o fermarsi e la componente post incrementa il contatore alla fine di ogni ripetizione.

```go
for i := 1; i < 10; i++ {
  fmt.Println(i)
}
```

Questo ciclo stampa i numeri da `1` a `9` (compreso `9`).
L'ampiezza del passo si definisce spesso con un'istruzione di incremento o decremento, come mostra l'esempio qui sopra.
