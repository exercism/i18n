# Appendice alle istruzioni

~~~~exercism/note

La descrizione sopra menziona [_insiemi matematici_][math-sets], ma anche che una terna pitagorica {a, b, c} _**deve**_ essere ordinata in modo che a < b < c (_ordine crescente_). 

Questo rende il [tipo `set`][python-sets] di Python inadatto a questo esercizio, perché è intrinsecamente _non ordinato_. 
Dovresti invece restituire una [`list`][python-list] di `list` (_ad esempio `[[a, b, c]]`_). 
Puoi generare le terne stesse nell'ordine che preferisci, dato che l'ordine della `list` che le contiene verrà ignorato nei test. 

[math-sets]: https://en.wikipedia.org/wiki/Set_(mathematics)
[python-sets]: https://docs.python.org/3/tutorial/datastructures.html#sets
[python-list]: https://docs.python.org/3/tutorial/datastructures.html#more-on-lists
