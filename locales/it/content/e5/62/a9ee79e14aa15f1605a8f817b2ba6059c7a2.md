# Introduzione

Un'*espressione regolare* (regex) è un piccolo pattern che descrive come dovrebbe apparire un testo. Invece di controllare tu stesso una stringa carattere per carattere, scrivi una volta sola la forma che vuoi e lasci che sia Factor a occuparsi della corrispondenza. Gli strumenti regex di Factor si trovano nel vocabolario [`regexp`][regexp].

## Scrivere un pattern

In Factor un'espressione regolare si scrive tra `R/ ` e `/`:

```factor
R/ cat/      ! the pattern that matches the letters c, a, t
```

La maggior parte dei caratteri in un pattern rappresenta semplicemente se stessa: `R/ cat/` corrisponde al testo `cat`. La vera potenza viene da alcuni elementi speciali che indicano *tipi* di caratteri o *quanti* ce ne sono.

### Classi di caratteri: «un carattere da un insieme»

```
\d        ! any digit, 0–9
\D        ! any NON-digit (the opposite of \d)
\s        ! any space, tab, or newline
\S        ! any NON-space character (the opposite of \s)
\w        ! a "word" character: a letter, a digit, or an underscore
\W        ! any NON-word character (the opposite of \w)
[A-Z]     ! any one capital letter A to Z
[a-z]     ! any one lowercase letter
[0-9]     ! any one digit (same as \d)
.         ! any single character at all
```

Una classe corrisponde esattamente a *un* carattere. `[A-Z]` corrisponde a `Q` ma non a `QQ`.

### Quantificatori: «quanti»

Metti uno di questi *dopo* un elemento per indicare quante volte può ripetersi:

```
{4}       ! exactly 4 times
{2,5}     ! between 2 and 5 times
+         ! one or more
*         ! zero or more
?         ! zero or one (optional)
```

Quindi `\d{4}` significa quattro cifre di seguito, e `[A-Z]+` significa una o più lettere maiuscole. Mettendo tutto insieme, `R/ [A-Z]+-\d+/` descrive «una o più maiuscole, un trattino, poi una o più cifre»: un testo come `SALE-2024`. Qui il `-` è un carattere normale: fuori da `[ ]` un trattino corrisponde semplicemente a un trattino (dentro una classe, come in `[A-Z]`, indica un intervallo).

## Far corrispondere un'intera stringa

`matches?` risponde alla domanda «questa *intera* stringa corrisponde al pattern?»: il pattern deve tenere conto di ogni carattere, dall'inizio alla fine:

```
matches? ( string regexp -- ? )
```

```factor
USING: regexp ;

"SALE-2024"     R/ [A-Z]+-\d+/ matches? .   ! => t
"GET SALE-2024" R/ [A-Z]+-\d+/ matches? .   ! => f   (extra text before)
"SALE-2024 NOW" R/ [A-Z]+-\d+/ matches? .   ! => f   (extra text after)
"sale-2024"     R/ [A-Z]+-\d+/ matches? .   ! => f   (lowercase letters)
```

Anche se `SALE-2024` si trova dentro `"GET SALE-2024"`, `matches?` restituisce comunque `f`: i caratteri in più fanno parte della stringa e non corrispondono al pattern. Quando ti interessa solo se il pattern compare *da qualche parte*, usa `re-contains?`: restituisce `t` esattamente dove `matches?` restituiva `f`:

```
re-contains? ( string regexp -- ? )
```

```factor
USING: regexp ;

"GET SALE-2024" R/ [A-Z]+-\d+/ matches? .      ! => f
"GET SALE-2024" R/ [A-Z]+-\d+/ re-contains? .  ! => t
```

## Trovare corrispondenze dentro un testo più lungo

`re-contains?` ti dice soltanto *se* il pattern è presente. Le parole che seguono guardano all'interno e riportano *cosa* ha trovato una corrispondenza: `all-matching-subseqs` restituisce ogni punto in cui il pattern corrisponde, sotto forma di una sequenza di stringhe, mentre `count-matches` si limita a contarle:

```
all-matching-subseqs ( string regexp -- seq )
count-matches        ( string regexp -- n )
```

```factor
USING: regexp ;

"3 cats, 12 dogs, 1 fish" R/ \d+/ all-matching-subseqs .
! => { "3" "12" "1" }            (every run of digits)

"the quick fox" R/ \S+/ all-matching-subseqs .
! => { "the" "quick" "fox" }     (every run of non-space characters)

"id_7!" R/ \w/ count-matches .   ! => 4   (i, d, _ and 7 count; ! does not)
```

## Sostituire le corrispondenze

`re-replace` sostituisce ogni corrispondenza con un testo di sostituzione e restituisce la nuova stringa:

```
re-replace ( string regexp replacement -- result )
```

```factor
USING: regexp ;

"page 7 of 12" R/ \d+/ "N" re-replace .
! => "page N of N"
```

Il vocabolario `regexp` ha altre parole che vale la pena conoscere: segui i link per i dettagli, [`first-match`][first-match] (solo la prima corrispondenza) e [`re-split`][re-split] (divide una stringa in ogni punto in cui il pattern corrisponde).
