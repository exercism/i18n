# Informazioni

In Go, le funzioni sono valori di prima classe.
Questo significa che con le funzioni puoi fare le stesse cose che puoi fare con tutti gli altri valori: assegnare funzioni a variabili, passarle come argomenti ad altre funzioni o persino restituire funzioni da altre funzioni.

Qui sotto creiamo due funzioni, `engGreeting` e `espGreeting`, e le assegniamo alla variabile `greeting`:

```go
import "fmt"

func engGreeting(name string) string {
	return fmt.Sprintf("Hello %s, nice to meet you!", name)
}

func espGreeting(name string) string {
	return fmt.Sprintf("¡Hola %s, mucho gusto!", name)
}

greeting := engGreeting			// greeting is a variable of type func(string) string
fmt.Println(greeting("Alice"))	// Hello Alice, nice to meet you!

greeting = espGreeting
fmt.Println(greeting("Alice")) 	// ¡Hola Alice, mucho gusto!
```

I valori di funzione offrono l'opportunità di parametrizzare le funzioni non solo con i dati, ma anche con il comportamento.
Nell'esempio seguente passiamo un comportamento alla funzione `dialog` tramite il parametro `greetingFunc`:

```go
func dialog(name string, greetingFunc func(string) string) {
	fmt.Println(greetingFunc(name))
	fmt.Println("I'm a dialog bot.")
}

func espGreeting(name string) string {
	return fmt.Sprintf("¡Hola %s, mucho gusto!", name)
}

greeting := espGreeting
dialog("Alice", greeting)
// Output:
// ¡Hola Alice, mucho gusto!
// I'm a dialog bot.
```

Il valore di una variabile non inizializzata di tipo funzione è `nil`.
Quindi, chiamare un valore di funzione `nil` causa un panic.

```go
var dutchGreeting func(string) string
dutchGreeting("Alice") // panic: call of nil function
```

I valori di funzione si possono confrontare con `nil`.
Questo può essere utile per evitare panic inutili del programma.

```go
var dutchGreeting func(string) string
if dutchGreeting != nil {
	dutchGreeting("Alice") // safe to call dutchGreeting
}
```

## Tipi di funzione

Usare i valori di funzione è possibile grazie ai tipi di funzione di Go.
Un tipo di funzione denota l'insieme di tutte le funzioni con la stessa sequenza di tipi di parametro e la stessa sequenza di tipi di risultato.
I tipi definiti dall'utente possono essere dichiarati a partire dai tipi di funzione.
Per esempio, la funzione `dialog` degli esempi precedenti può essere aggiornata come segue:

```go
type greetingFunc func(string) string

func dialog(name string, f greetingFunc) {
	fmt.Println(f(name))
	fmt.Println("I'm a dialog bot.")
}
```

## Funzioni anonime

Un altro strumento potente, reso possibile dal supporto alle funzioni di prima classe, sono le funzioni anonime.
Le funzioni anonime sono definite nel punto in cui vengono usate, senza un nome dopo la parola chiave `func`.
Queste funzioni hanno accesso alle variabili della funzione che le racchiude.

Per esempio:

```go
func fib() func() int {
	var n1, n2 int

	return func() int {
		if n1 == 0 && n2 == 0 {
			n1 = 1
		} else {
			n1, n2 = n2, n1 + n2
		}
		return n2
	}
}

next := fib()
for i := 0; i < N; i++ {
  fmt.Printf("F%d\t= %4d\n", i, next())
}
```

Una chiamata a `fib` dichiara le variabili `n1` e `n2` e restituisce una funzione anonima che, a sua volta, cambia i valori di queste variabili ogni volta che la funzione viene chiamata.
La chiamata N-esima della funzione anonima restituisce l'N-esimo numero della sequenza di Fibonacci a partire da 0. La funzione anonima interna ha accesso alle variabili locali (`n1` e `n2`) della funzione `fib` che la racchiude.
È un ottimo modo per far mantenere lo stato ai valori di funzione tra una chiamata e l'altra.
Diciamo che la funzione anonima è una closure delle variabili `n1` e `n2`.
[Le closure][closure] sono molto usate nella programmazione e potresti vedere altri linguaggi che le supportano.
