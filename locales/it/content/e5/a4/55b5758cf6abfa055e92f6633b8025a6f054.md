# Appendice alle istruzioni

## Registri

| Registro | Uso       | Tipo    | Descrizione                              |
| -------- | --------- | ------- | ---------------------------------------- |
| `$a0`    | input     | indirizzo | stringa di caratteri binari terminata da null |
| `$v0`    | output    | intero  | valore decimale della stringa di input   |
| `$t0-9`  | temporaneo | qualsiasi | usato come archivio temporaneo           |
