# Istruzioni

In questo esercizio, implementerai la logica della missione per un nuovo gioco di ruolo che sta sviluppando un tuo amico. La protagonista del gioco è Annalyn, una ragazza coraggiosa con un cane da compagnia feroce e fedele. Purtroppo arriva il disastro: la sua migliore amica è stata rapita mentre cercava bacche nel bosco. Annalyn cercherà di trovare e liberare la sua migliore amica, portando con sé il suo cane in questa missione, se vuole.

Dopo aver seguito per un po' le tracce della sua migliore amica, trova l'accampamento in cui è imprigionata. Si scopre che ci sono due rapitori: un possente cavaliere e un astuto arciere.

Ora che ha trovato i rapitori, Annalyn valuta quali delle seguenti azioni può intraprendere:

- Attacco rapido: si può sferrare un attacco rapido se il cavaliere sta dormendo: ci vuole tempo perché indossi l'armatura, quindi sarà vulnerabile.
- Spionaggio: si può spiare il gruppo se almeno uno di loro è sveglio. Altrimenti, spiare è una perdita di tempo.
- Segnalare al prigioniero: si può segnalare al prigioniero con versi di uccelli se il prigioniero è sveglio e l'arciere sta dormendo, dato che gli arcieri sono addestrati al linguaggio degli uccelli e potrebbero intercettare il messaggio.
- _Liberare il prigioniero_: Annalyn può provare a intrufolarsi nell'accampamento per liberare il prigioniero.
  È un'azione rischiosa e può riuscire solo in uno di due modi:
  - Se Annalyn ha con sé il suo cane, può salvare il prigioniero se l'arciere dorme.
    Il cavaliere ha paura del cane e l'arciere non avrà il tempo di prepararsi prima che Annalyn e il prigioniero riescano a fuggire.
  - Se Annalyn non ha il cane, allora lei e il prigioniero devono essere molto furtivi!
    Annalyn può liberare il prigioniero se il prigioniero è sveglio e sia il cavaliere sia l'arciere dormono, ma se il prigioniero dorme non può essere salvato: si spaventerebbe per l'improvvisa apparizione di Annalyn e sveglierebbe il cavaliere e l'arciere.

Hai quattro compiti: implementare la logica per determinare se le azioni sopra sono disponibili in base allo stato dei tre personaggi che si trovano nel bosco e alla presenza o meno del cane di Annalyn.

## 1. Verifica se è possibile sferrare un attacco rapido

Implementa il metodo `canFastAttack()` che accetta un valore booleano che indica se il cavaliere è sveglio. Il metodo restituisce `true` se è possibile sferrare un attacco rapido in base allo stato del cavaliere. Altrimenti, restituisce `false`:

```kotlin
val knightIsAwake = true

canFastAttack(knightIsAwake)
// => false
```

## 2. Verifica se è possibile spiare il gruppo

Implementa il metodo `canSpy()` che accetta tre valori booleani, che indicano rispettivamente se il cavaliere, l'arciere e il prigioniero sono svegli. Il metodo restituisce `true` se è possibile spiare il gruppo, in base allo stato dei tre personaggi. Altrimenti, restituisce `false`:

```kotlin
val knightIsAwake = false
val archerIsAwake = true
val prisonerIsAwake = false

canSpy(knightIsAwake, archerIsAwake, prisonerIsAwake)
// => true
```

## 3. Verifica se è possibile segnalare al prigioniero

Implementa il metodo `canSignalPrisoner()` che accetta due valori booleani, che indicano rispettivamente se l'arciere e il prigioniero sono svegli. Il metodo restituisce `true` se è possibile segnalare al prigioniero, in base allo stato dei due personaggi. Altrimenti, restituisce `false`:

```kotlin
val archerIsAwake = false
val prisonerIsAwake = true

canSignalPrisoner(archerIsAwake, prisonerIsAwake)
// => true
```

## 4. Verifica se è possibile liberare il prigioniero

Implementa il metodo `canFreePrisoner()` che accetta quattro valori booleani. I primi tre parametri indicano rispettivamente se il cavaliere, l'arciere e il prigioniero sono svegli. L'ultimo parametro indica se il cane di Annalyn è presente. Il metodo restituisce `true` se è possibile liberare il prigioniero in base allo stato dei tre personaggi e alla presenza del cane di Annalyn. Altrimenti, restituisce `false`:

```kotlin
val knightIsAwake = false
val archerIsAwake = true
val prisonerIsAwake = false
val petDogIsPresent = false

canFreePrisoner(knightIsAwake, archerIsAwake, prisonerIsAwake, petDogIsPresent)
// => false
```
