# Testare dalla riga di comando

Esegui i test con:

```bash
$ cargo test
```

Tutti i test tranne il primo sono stati ignorati. Dopo che il primo test
passa, apri il file sorgente dei test che si trova nella directory `tests`,
rimuovi il flag `#[ignore]` dal test successivo e fai passare di nuovo i
test. Ogni singolo test è una funzione con il flag `#[test]` sopra di essa.
Continua finché non passano tutti i test.

Se vuoi eseguire _solo i test ignorati_ senza modificare il file sorgente dei test, usa:

```bash
$ cargo test -- --ignored
```

Se usi Rust 1.51 o una versione successiva, puoi eseguire _tutti_ i test con

```bash
$ cargo test -- --include-ignored
```

Per eseguire un test specifico, ad esempio `some_test`, puoi usare:

```bash
$ cargo test some_test
```

Se il test specifico è ignorato, usa:

```bash
$ cargo test some_test -- --ignored
```

Per saperne di più sui test di Rust, consulta la [documentazione sui test][rust-tests] online.

[rust-tests]: https://doc.rust-lang.org/book/ch11-02-running-tests.html
