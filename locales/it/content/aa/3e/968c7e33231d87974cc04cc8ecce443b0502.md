# Appendice alle istruzioni

## Registri

| Registro | Utilizzo  | Tipo    | Descrizione                                                        |
| -------- | --------- | ------- | ------------------------------------------------------------------ |
| `$a0`    | input     | indirizzo | stringa di input terminata da null                              |
| `$v0`    | output    | booleano  | l'input ha parentesi corrispondenti (`0` = `false`, `1` = `true`) |
| `$t0-9`  | temporaneo | qualsiasi | usato come memoria temporanea                                    |
