# Suggerimenti

## Generale

- Il modulo `gleam/string` ha molte utili [funzioni per le stringhe][stdlib].

## 1. Ottieni il messaggio da una riga di log

- L'operatore `<>` può essere usato nel pattern matching per far corrispondere l'inizio di una stringa.
- Il modulo `gleam/string` ha una [funzione][trim] per rimuovere gli spazi bianchi che circondano una stringa.

## 2. Ottieni il livello di log da una riga di log

- Il modulo `gleam/string` ha una [funzione][lowercase] per convertire una stringa in minuscolo.

## 3. Riformatta una riga di log

- L'operatore `<>` può essere usato per unire le stringhe tra loro.
