# Informazioni

In C#, i booleani sono rappresentati dal tipo `bool`, i cui valori possono essere `true` o `false`.

C# supporta quattro [operatori booleani][operators]: `!` (NOT), `&&` (AND), `||` (OR) e `^` (XOR). Gli operatori `&&` e `||` usano la _valutazione a cortocircuito_, il che significa che il lato destro dell'operatore viene valutato solo quando serve.

```csharp
true || false // => true
true && false // => false
true ^ false  // => true
true ^ true   // => false
```

I tre operatori booleani hanno ciascuno una diversa [_precedenza degli operatori_][precedence]. Di conseguenza, vengono valutati in quest'ordine: prima `not`, poi `&&`, poi `^` e infine `||`. Se vuoi «aggirare» queste regole, puoi racchiudere un'espressione booleana tra parentesi (`()`), dato che le parentesi hanno una precedenza ancora più alta.

```csharp
!true && false   // => false
!(true && false) // => true
```
