# Test

Un esercizio scaricato include questi file per compilare e testare la soluzione:

```text
hello-world/
├── HelloWorld.vb          # Your solution
├── HelloWorldTests.vb     # The test suite
├── HelloWorld.vbproj      # Project and build configuration
└── packages.lock.json     # Resolved project dependencies
```

I nomi dei file variano da esercizio a esercizio.
Scrivi la soluzione nel primo file `.vb`.
Il secondo file, quello che termina con `Tests.vb`, è la [suite di test xUnit][xunit].
In genere lo modificherai solo per riabilitare i test successivi.
Non avrai bisogno di modificare nessuno degli ultimi due file.
Il file `.vbproj` contiene le impostazioni di compilazione del progetto e i riferimenti diretti ai pacchetti.
Il file `packages.lock.json` generato registra le versioni risolte dei pacchetti diretti e transitivi.

~~~exercism/note
I test descrivono il comportamento che una soluzione che passa deve soddisfare.
Possono aiutarti a chiarire dettagli che le istruzioni non coprono.
~~~

## Eseguire i test

Apri un terminale nella directory dell'esercizio ed esegui:

```bash
dotnet test
```

Il comando ripristina le dipendenze del progetto, compila il progetto ed esegue i test.
Puoi anche usare `dotnet watch test` per rieseguire i test ogni volta che un file sorgente cambia.

## Test saltati

Gli esercizi abilitano inizialmente solo il primo test, così puoi risolvere il resto un passo alla volta.
Apri il file che termina con `Tests.vb` per trovare i test.
Ogni test è una subroutine `Sub` contrassegnata da un attributo `<Fact>` di xUnit.
Un test viene saltato finché il suo attributo `<Fact>` ha un argomento `Skip`:

```vb
<Fact(Skip:="Remove this Skip property to run this test")>
Public Sub Lowercase_words()
    Assert.Equal("ROR", Abbreviate("Ruby on Rails"))
End Sub
```

Per abilitare il test, basta rimuovere l'argomento `Skip`:

```vb
<Fact>
Public Sub Lowercase_words()
    Assert.Equal("ROR", Abbreviate("Ruby on Rails"))
End Sub
```

Dopo che il test appena abilitato passa, ripeti la procedura con il test successivo saltato.
Quando tutti i test sono abilitati e passano, hai finito.
