# Introduzione

In Elixir, possiamo definire attributi di modulo da usare come costanti nelle nostre funzioni.

```elixir
defmodule Example do
  # Defines the attribute as the value 1
  @constant_number 1

  def example_value() do
    # Returns the value 1
    @constant_number
  end
end
```

Quando vengono usati per definire costanti di modulo, gli attributi possono essere qualsiasi espressione che può essere valutata in fase di compilazione. Dopo la compilazione, gli attributi di modulo non sono accessibili, poiché vengono espansi durante la compilazione, in modo simile alle macro definite in linguaggi come il C.
