# Informazioni

Le strutture condizionali sono istruzioni che eseguono codice diverso a seconda che una condizione sia `true` o `false`.

Un'istruzione [`if`][if_statement] esegue il suo corpo solo quando la sua condizione è `true`.
Go non ha il concetto di valori truthy o falsy, quindi la condizione deve essere di tipo `bool`.
Espressioni come `if mySlice { ... }` o `if 1 { ... }` sono errori di compilazione.

```go
func describe(val string) string {
    if val == "val" {
        return "was val"
    }
    return "was not val"
}
```

Usa `else if` per verificare condizioni aggiuntive, ed `else` come ripiego se nessuna corrisponde.
Le condizioni vengono valutate dall'alto verso il basso, e viene eseguito solo il primo ramo la cui condizione è vera.

```go
number := 0
result := "This number is "

if number > 0 {
    result += "positive"
} else if number < 0 {
    result += "negative"
} else {
    result += "zero"
}
```

In generale, Go preferisce uscire anticipatamente dal caso eccezionale ed evitare `else`.

```go
func getVal(connected bool) int {
    if !connected {
        return readLocalVal()
    }

    return readVal()
}
```

Un'istruzione `if` può anche includere una breve istruzione di inizializzazione.
Questo si usa comunemente per verificare un errore subito dopo una chiamata:

```go
num := 7
if v := 2 * num; v > 10 {
    fmt.Println(v)
} else {
    fmt.Println(num)
}
// Output: 14
```

Le variabili dichiarate nell'istruzione di inizializzazione sono visibili nello scope solo all'interno dell'intera catena `if`/`else`.
In particolare, Go non ha un operatore ternario, una scelta di progettazione deliberata per rendere il codice facile da scorrere.

Per saperne di più, vedi [Go by Example: If/Else][go_by_example_if].
