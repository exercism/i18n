# Approfondimento

ABAP supporta i consueti operatori aritmetici per i valori numerici:

- `+` somma i valori.
- `-` sottrae i valori.
- `*` moltiplica i valori.
- `/` divide i valori.
- `MOD` restituisce il resto di una divisione intera.

```abap
DATA total TYPE i.
total = 6 + 4 * 2.

DATA remaining_days TYPE i.
remaining_days = 70 MOD 22.
```

La moltiplicazione e la divisione vengono valutate prima dell'addizione e della sottrazione. Usa le parentesi quando un calcolo va raggruppato in modo esplicito.

```abap
DATA result TYPE i.
result = ( 6 + 4 ) * 2.
```
