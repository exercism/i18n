# Test

Per eseguire i test dell'esercizio con la CLI, esegui il seguente comando dalla directory dell'esercizio:

```bash
clojure -M:test
```

## REPL

Per eseguire i test dell'esercizio con il REPL, esegui il seguente comando dalla directory dell'esercizio:

```bash
$ clojure -m cljs.main -re node
```

Poi `require` il namespace di test dell'esercizio e il namespace di test di Clojure):

```clojure
;; replace <exercise> with the exercise's name
=> (require '<exercise>-test)
nil
;; and the test namespace
=> (require 'cljs.test)
```

Cambia il ns nel namespace di test:

```clojure
;; replace <exercise> with the exercise's name
=> (ns <exercise>-test)
nil
```

Poi chiama `run-tests`:

```clojure
=> (cljs.test/run-tests)
```
