# Appendice alle istruzioni

## Suggerimenti

Per completare questo esercizio devi implementare la funzione `anagramsFor`, che prende una *parola* e un gruppo di *parole* e restituisce quelle che sono anagrammi della *parola* data.

Devi restituire gli anagrammi nello stesso ordine in cui sono elencati nelle parole candidate.

Se è la prima volta che risolvi questo esercizio, ti consigliamo di attenerti alla firma fornita:

```haskell
anagramsFor :: String -> [String] -> [String]
```

Più avanti, potrebbe essere una buona idea riprendere questo problema e giocare con altri tipi di dati e librerie:

- `Text`, dal pacchetto *text*.
- `Sequence` e `Set`, dal pacchetto *containers*.
- `MultiSet`, dal pacchetto *multiset*

La suite di test è stata progettata intenzionalmente per accettare quasi qualsiasi firma di tipo abbia senso, quindi ti invitiamo a trovare quella che ritieni migliore.
