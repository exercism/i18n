# Informazioni

## Operatori di confronto

Gli [operatori di confronto][comparison-operators] confrontano due valori dello stesso tipo e restituiscono un valore `Bool` (`true` o `false`).
Se provi a confrontare valori di tipi diversi, il compilatore genera un errore.

Gli operatori di confronto standard in Swift sono:

| Operatore | Descrizione              | Esempio         |
| --------- | ------------------------ | --------------- |
| `==`      | Uguale a                 | `1 == 1` (true) |
| `!=`      | Diverso da               | `1 != 2` (true) |
| `<`       | Minore di                | `4 < 5`  (true) |
| `<=`      | Minore o uguale a        | `4 <= 4` (true) |
| `>`       | Maggiore di              | `3 > 1`  (true) |
| `>=`      | Maggiore o uguale a      | `2 >= 2` (true) |

## Istruzioni if ed else

Un'[istruzione condizionale][conditional-statement] esegue del codice a seconda che una condizione valuti a `true` o a `false`.
Il condizionale più comune è un'[istruzione if][if], che esegue un blocco di codice solo quando la sua condizione è `true`.
Per scrivere un'istruzione `if` usa la parola chiave `if`, seguita dalla condizione e dal blocco di codice racchiuso tra parentesi graffe:

```swift
let wheelCount = 4
if wheelCount == 4 {
    print("Your vehicle is a car")
}
// Prints "Your vehicle is a car"
```

Puoi abbinare `if` a una clausola `else` per eseguire del codice alternativo quando la condizione è `false`:

```swift
let precipitationInMM = 0.5
if precipitationInMM > 0.5 {
    print("You will need an umbrella")
} else {
    print("You will not need an umbrella")
}
// Prints "You will not need an umbrella"
```

Per verificare più condizioni in sequenza, concatena le istruzioni usando `else if`.
Un'istruzione `if` non richiede un ramo `else`, ma puoi includerne uno per gestire i casi in cui nessuna delle condizioni corrisponde:

```swift
let favoriteFruit = "Apple"

if favoriteFruit == "Banana" {
    print("Your favorite fruit is a banana")
} else if favoriteFruit == "Orange" {
    print("Your favorite fruit is an orange")
} else if favoriteFruit == "Apple" {
    print("Your favorite fruit is an apple")
} else {
    print("Your favorite fruit is not a banana, orange, or apple")
}
// Prints "Your favorite fruit is an apple"
```

## Espressioni if

Nello Swift moderno, le istruzioni `if` possono essere usate anche come espressioni che producono un valore.
Ogni ramo produce un valore, il che rende semplice assegnare i risultati in modo condizionale:

```swift
let cpuBits = 32
let architecture = if cpuBits == 64 {
    "x86_64"
} else {
    "x86_32"
}

print(architecture)
// Prints "x86_32"
```
