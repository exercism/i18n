# Installazione

## Opzioni di installazione

La versione attuale di Unison è disponibile per Mac OS X, Linux a 64 bit e Windows! Se stai provando Unison, speriamo che tu venga a parlarci nel forum di Exercism o nel [Discord di Unison](https://unison-lang.org/discord). Vieni a fare domande e a segnalarci i problemi che potresti incontrare! Vogliamo che il tuo primo approccio sia accogliente e positivo! 😊

Puoi scaricare Unison con [homebrew](https://brew.sh/), [Nix](https://github.com/ceedubs/unison-nix/#usage) oppure direttamente tramite i binari pacchettizzati. Tutte queste opzioni di download sono descritte nella [pagina delle istruzioni di installazione del nostro sito](https://www.unison-lang.org/learn/quickstart/#installation-options). Una volta installato l'UCM, torna qui!

### Opzione 1: usare Homebrew

Per prima cosa [installa homebrew](https://brew.sh/) se non l'hai già fatto.

Poi, dalla riga di comando, digita questi comandi:

```
brew tap unisonweb/unison
brew install unison-language
```

Questo installerà l'eseguibile del codebase manager di Unison, `ucm`. Se stai aggiornando da una versione precedente, ti basta fare

```
brew upgrade unison-language.
```

Nota: se a questo punto ti viene chiesto un nome utente e una password di GitHub, assicurati di aver scritto correttamente unisonweb/unison.

### Opzione 2: installazione manuale per utenti Mac e Linux

[I link per l'installazione manuale su Linux e Mac sono disponibili qui](https://www.unison-lang.org/learn/quickstart/#installation-options) nelle rispettive sezioni di download manuale per Linux e Mac.

Eseguirai nella tua shell un comando simile a questo, ma il link qui sopra contiene il binario più aggiornato:

```
mkdir unisonlanguage
curl -L https://github.com/unisonweb/unison/releases/download/release_VERSION_NAME/ucm-YOUR_PLATFORM.tar.gz --output unisonlanguage/ucm.tar.gz
tar -xzf unisonlanguage/ucm.tar.gz -C unisonlanguage
./unisonlanguage/ucm
```

### Opzione 3: installazione manuale per utenti Windows

1. Imposta come applicazione terminale predefinita "Windows Terminal" per ottenere i risultati migliori. Cerca "Terminal" nelle Impostazioni oppure segui [questa guida.](https://bit.ly/3IXwdlY)
2. Se non sei sicuro di averlo già, installa Git:
  * Con winget: `winget install --id Git.Git -e --source winget`
  * Se hai Windows 10 e non hai winget, puoi installarlo da [Microsoft Store](https://www.microsoft.com/en-us/p/app-installer/9nblggh4nns1), e poi eseguire il comando qui sopra.
3. [Scarica l'UCM dal link indicato qui](https://www.unison-lang.org/learn/quickstart/#installation-options) ed estrailo in una posizione a tua scelta.
4. Esegui `ucm.exe`

### Opzione 4: installazione con Nix
Vai su [https://github.com/ceedubs/unison-nix/#usage](https://github.com/ceedubs/unison-nix/#usage) e segui le istruzioni nel readme.

## Crea la tua codebase Unison

Esegui `ucm` per inizializzare una codebase Unison in `$HOME/.unison`. Qui Unison memorizzerà le definizioni delle funzioni, i tipi, i namespace e così via. Per impostazione predefinita, il Codebase Manager di Unison (abbreviato "UCM") inizierà a scaricare la libreria standard, chiamata `base`, che userai per scrivere il codice Unison. Potrebbe volerci un momento! 🕰

## Flusso di lavoro con Unison

Quando vuoi scrivere codice Unison, lanci il comando `ucm` per avviare il codebase manager. L'UCM osserverà quindi le modifiche a qualsiasi file con suffisso `.u` nella directory da cui è stato avviato. Per esempio, potresti implementare funzioni in un file chiamato `scratch.u` in una directory chiamata `~/exercism/unison/my-exercise/`. Dovresti fare `cd` in `~/exercism/unison/my-exercise/` ed eseguire `ucm`. Così sarai sicuro che l'UCM tenga sotto controllo il tuo file `scratch.u` per rilevare le modifiche.

Se non ti è chiaro quale directory stia tenendo sotto controllo `ucm` per le modifiche ai file, lo trovi stampato nella schermata di benvenuto all'avvio della CLI.

```
👀 I'm watching for changes to .u files under /Users/myUser/exercism/unison/my-exercise
```

[Qui trovi altri consigli sul flusso di lavoro!](https://exercism.org/docs/tracks/unison/workflow)

## Supporto degli editor

Puoi usare qualsiasi editor di testo per scrivere i tuoi file `.u`. Unison ha il [supporto LSP](https://github.com/unisonweb/unison/blob/trunk/docs/language-server.markdown), quindi il tuo IDE preferito può aiutarti con cose come i tipi al passaggio del mouse e il completamento automatico. Qui sotto trovi alcuni editor popolari con supporto per Unison:

### Vim

Usando [vim-plug](https://github.com/junegunn/vim-plug):

1. Installa [`vim-plug`](https://github.com/junegunn/vim-plug) se non l'hai già fatto.
2. Aggiungi quanto segue al tuo .vimrc: `Plug 'unisonweb/unison', { 'branch': 'trunk', 'rtp': 'editor-support/vim' }`
3. Esegui il comando vim `:PlugInstall`.

Per maggiori informazioni, esegui `:help unison` da vim oppure consulta la [documentazione di aiuto online](https://github.com/unisonweb/unison/blob/trunk/editor-support/vim/doc/unison.txt).

### Atom
Dalla console, esegui:

```
apm install unisonweb/atom-unison
```

### VS Code

1. Apri la vista delle estensioni cliccando sull'icona delle estensioni nella barra delle attività a lato di VS Code, oppure con ⇧⌘X.
2. Cerca "unison"
3. Installa l'[estensione Unison per VS Code](https://marketplace.visualstudio.com/items?itemName=unison-lang.unison)

### Emacs
Installa [`unison-mode`](https://github.com/dariooddenino/unison-mode-emacs).
