# Istruzioni

In questo esercizio scriverai del codice che ti aiuterà a prepararti all'acquisto di un veicolo.

Hai tre attività: una per determinare se ti servirà qualcosa che ti aiuti a scegliere tra due veicoli, una per determinare quale patente ti servirà e una per stimare il prezzo accettabile di un veicolo usato.

## 1. Stabilisci se puoi permetterti o meno le rate mensili di una determinata auto

I concessionari della tua città stanno tutti proponendo una promozione di cinque anni a interesse 0% di cui vorresti approfittare.
Ma non sei sicuro di poterti permettere le rate mensili dell'auto che vuoi.

La rata mensile è il prezzo totale dell'auto diviso per il numero di mesi del periodo di cinque anni.

Implementa la funzione `canIBuy(vehicle:price:monthlyBudget:)` che accetta i seguenti argomenti:
- `vehicle`: il nome del veicolo che vuoi acquistare.
- `price`: il prezzo del veicolo che vuoi acquistare.
- `monthlyBudget`: la somma di denaro che puoi permetterti di pagare ogni mese.

La funzione deve restituire il seguente messaggio in base alle seguenti condizioni:
- Se la rata mensile del veicolo è minore o uguale al budget mensile, restituisci il messaggio `"Yes! I'm getting a <vehicle>"`.
- Se la rata mensile del veicolo supera il tuo budget mensile fino al 10% (incluso), restituisci il messaggio `"I'll have to be frugal if I want a <vehicle>"`.
- Se la rata mensile del veicolo supera il tuo budget mensile di più del 10%, restituisci il messaggio `"Darn! No <vehicle> for me"`.

```swift
canIBuy(vehicle: "1974 Ford Pinto", price: 516.32, monthlyBudget: 100.00)
// returns "Yes! I'm getting a 1974 Ford Pinto"
canIBuy(vehicle: "2011 Bugatti Veyron", price: 2_250_880.00, monthlyBudget: 10000.00)
// returns "Darn! No 2011 Bugatti Veyron for me"
canIBuy(vehicle: "2020 Indian FTR 1200", price: 12_500, monthlyBudget: 200)
// returns "I'll have to be frugal if I want a 2020 Indian FTR 1200"
```

## 2. Determina il tipo di patente che ti servirà

Hai deciso di acquistare un veicolo usato e devi determinare quale tipo di patente ti servirà per guidarlo.

Implementa la funzione `licenseType(numberOfWheels:)` che accetta l'argomento `numberOfWheels`, cioè il numero di ruote del veicolo che vuoi acquistare.

La funzione deve restituire il seguente messaggio in base alle seguenti condizioni:
- Se il numero di ruote è 2 o 3, restituisci il messaggio `"You will need a motorcycle license for your vehicle"`.
- Se il numero di ruote è 4 o 6, restituisci il messaggio `"You will need an automobile license for your vehicle"`.
- Se il numero di ruote è 18, restituisci il messaggio `"You will need a commercial trucking license for your vehicle"`.
- Se il numero è qualsiasi altro numero, restituisci il messaggio `"We do not issue licenses for those types of vehicles"`.

```swift
licenseType(numberOfWheels: 2)
// returns "You will need a motorcycle license for your vehicle"
licenseType(numberOfWheels: 6)
// returns "You will need an automobile license for your vehicle"
licenseType(numberOfWheels: 18)
// returns "You will need a commercial trucking license for your vehicle"
licenseType(numberOfWheels: 0)
// returns "We do not issue licenses for those types of vehicles"
```

## 3. Calcola una stima del prezzo di un veicolo usato

Ora che hai preso la tua decisione, vuoi assicurarti di ottenere un prezzo equo dal concessionario.
Dato che vuoi acquistare un veicolo usato, il prezzo dipende da quanto è vecchio il veicolo.
Per una stima approssimativa, supponi che se il veicolo ha meno di 3 anni costi l'80% del prezzo originale che aveva quando era nuovo di zecca.
Se ha almeno 10 anni, costa il 50%.
Se il veicolo ha almeno 3 anni ma non più di 10, costa il 70% del prezzo originale.

Implementa la funzione `calculateResellPrice(originalPrice:yearsOld:)` che accetta gli argomenti `originalPrice`, che contiene il prezzo originale del veicolo, e `yearsOld`, che contiene l'età del veicolo in anni.
La funzione deve restituire il prezzo di rivendita del veicolo.

```swift
calculateResellPrice(originalPrice: 1000, yearsOld: 1)
// returns 800
calculateResellPrice(originalPrice: 1000, yearsOld: 5)
// returns 700
calculateResellPrice(originalPrice: 1000, yearsOld: 15)
// returns 500
```
