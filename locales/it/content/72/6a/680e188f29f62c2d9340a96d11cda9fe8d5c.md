# Eseguire i test

Per eseguire i test di un esercizio, lancia lo script `<exercise>.test` nella directory dell'esercizio:

```bash
tclsh <exercise>.test
```

Nella maggior parte degli esercizi, tutti i test tranne il primo saranno «saltati».
Questo ti permette, come sviluppatore, di praticare il Test-Driven Development: scrivere solo il codice necessario per superare i test uno alla volta.
Per annullare i comandi di salto, imposta la variabile d'ambiente `RUN_ALL` su un valore che Tcl considera vero \[1\] prima di eseguire la suite di test:

```bash
RUN_ALL=yes tclsh <exercise>.test
```

\[1\]: I valori vero/falso di Tcl sono documentati nella pagina man della funzione di libreria C [Tcl_GetBoolean][bool].

[bool]: https://www.tcl-lang.org/man/tcl8.6/TclLib/GetInt.htm
