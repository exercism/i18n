# Installare Swift

Swift è disponibile su macOS, Linux e Windows.
Il processo di installazione varia a seconda del sistema operativo che stai usando.
Un aspetto importante da notare per il supporto a Linux è che Swift è supportato (ufficialmente) solo sulle seguenti distribuzioni:
- Ubuntu
- Debian
- RedHat
- Fedora
- Amazon Linux

Se usi una distribuzione Linux diversa, dovrai trovare un modo per installare Swift da solo.

## Xcode (macOS)

Swift è incluso in Xcode, l'IDE di Apple per lo sviluppo su macOS e iOS.
Per il track di Exercism ti servirà avere installata la versione 16.0 o successiva di Xcode.
Xcode è disponibile gratuitamente sul [Mac App Store][xcode].
Versioni aggiuntive di Xcode (compresa la beta più recente) sono disponibili presso il [centro per sviluppatori di Apple][apple-developer-center].

## macOS & Linux

Per macOS e Linux esiste un gestore di installazione di Swift chiamato [swiftly][swiftly].
È uno strumento a riga di comando che ti permette di installare e gestire più versioni di Swift sul tuo sistema.
Il comando per installare swiftly su macOS si trova [qui][swiftly-macos], e [qui][swiftly-linux] per Linux.

Un altro metodo di installazione per macOS è [Homebrew][homebrew].
Per Linux, puoi installare usando il tarball dal [sito ufficiale di Swift][tarball].

## Windows

Il modo consigliato per installare Swift su Windows è usare l'[installer di WinGet][winget-windows].
È anche possibile installare Swift usando il gestore di pacchetti Scoop o procedendo con un'installazione manuale.
Per tutte le opzioni, vedi la pagina [Installare Swift per Windows][swift-windows].
