# Approfondimento

## Moduli

Il codice Gleam è organizzato in moduli, e ogni file è un modulo Gleam.

Finora abbiamo scritto funzioni con la sintassi `pub fn`, che definisce una funzione disponibile pubblicamente per gli altri moduli. Le funzioni definite con `fn` sono private rispetto al modulo in cui sono definite e non possono essere usate da altri moduli.

```gleam
// This function is public
pub fn add(x, y) {
  x + y
}

// This function is private
fn subtract(x, y) {
  x - y
}
```

I moduli Gleam hanno un nome, e il nome si basa sul loro percorso file all'interno della directory `src` o `test`.

Per esempio, un modulo definito in `src\geometry\rectangle.gleam` (su Windows) o `src/geometry/rectangle.gleam` (su sistemi operativi simili a UNIX) si chiamerebbe `geometry/rectangle`.

## Importare funzioni da altri moduli

Si accede alle funzioni definite in altri moduli tramite gli import. Quando si importa un modulo, tutte le funzioni che esso espone diventano accessibili. Ma il modo in cui vi si accede varia a seconda di come il modulo viene importato.

Gli import qualificati sono il comportamento predefinito: per accedere a una funzione all'interno di un tale modulo (per esempio la funzione `map` nel modulo `gleam/list`) si antepone il nome del modulo (`list.map`).

```gleam
// Import the int module
import gleam/int

pub fn run(x: Int) -> String {
  // Use the to_string function from the int module
  int.to_string(x)
}
```

Per impostazione predefinita il nome usato per riferirsi al modulo è l'ultima parte del nome del modulo, in questo caso `int`, ma lo si può cambiare usando la parola chiave `as`.

```gleam
// Import the int module and refer to it as i
import gleam/int as i

pub fn run(x: Int) -> String {
  i.to_string(x)
}
```

Gli import non qualificati consentono di accedere direttamente alle funzioni esposte in quel modulo, senza anteporre il nome del modulo.

```gleam
// Import the to_string function from the int module
import gleam/int.{to_string}

pub fn run(x: Int) -> String {
  to_string(x)
}
```

Gli import qualificati sono preferiti perché rendono più chiaro a chi legge da dove viene una funzione, e aiutano a evitare conflitti di nomi.
