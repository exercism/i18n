# Istruzioni.append

Chi apprezza una sfida più impegnativa può attivare i test bonus togliendo il commento da una riga in `rational-numbers.jl`.

Richiedono una conoscenza di Julia e del suo sistema dei tipi molto più avanzata.

Il file `runtests.jl` contiene alcuni link che potrebbero essere utili.

Il file `rational-numbers.jl` non contiene di proposito altre indicazioni per i test bonus: pensa con attenzione agli import, alle definizioni di tipo e alle funzioni aggiuntive.
