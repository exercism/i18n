# Introduzione

Unison rappresenta i valori vero e falso con il tipo `Boolean`. Esistono solo due valori: `true` e `false`.

```unison
trueVariable = true
falseVariable = false
```

Possiamo valutare le espressioni booleane usando gli operatori and, rappresentato con `&&`; or, rappresentato con `||`; e not, rappresentato con `not`.

```unison
trueVariable = true && true
falseVariable = true && false

trueVariable = false || true
falseVariable = false || false

trueVariable = not false
falseVariable = not true
```
