# Istruzioni

In questo esercizio implementerai una serie parziale di routine di utilità per aiutare uno sviluppatore a ripulire i nomi SqueakyClean.

Nelle 4 attività costruirai gradualmente il metodo `clean`.
Un nome SqueakyClean valido è composto da zero o più lettere e underscore.

In tutti i casi, la stringa di input è garantita non nulla. Tieni presente che il metodo `clean` deve considerare valida una stringa vuota.

## 1. Sostituisci con degli underscore tutti gli spazi incontrati

Implementa il metodo (_static_) `SqueakyClean.clean()` in modo che sostituisca qualsiasi spazio con un underscore. Questo vale anche per gli spazi iniziali e finali.

```java
SqueakyClean.clean("my   Id");
// => "my___Id"
```

## 2. Converti il kebab-case in camelCase

Modifica il metodo (_static_) `SqueakyClean.clean()` in modo che converta il kebab-case in camelCase.

```java
SqueakyClean.clean("a-bc");
// => "aBc"
```

## 3. Converti il leetspeak in testo normale

Modifica il metodo (_static_) `SqueakyClean.clean()` in modo che converta il [leetspeak][leet-speak] in testo normale.

Per semplicità, sostituiremo solo `4`, `3`, `0`, `1` e `7` rispettivamente con `a`, `e`, `o`, `l` e `t`.

```java
SqueakyClean.clean("H3ll0 W0rld");
// => "Hello_World"
SqueakyClean.clean("4 73s7");
// => "a_test"
```

## 4. Ometti i caratteri che non sono lettere

Modifica il metodo (_static_) `SqueakyClean.clean()` in modo che ometta tutti i caratteri che non sono lettere.

```java
SqueakyClean.clean("a$#.b");
// => "ab"
```

[leet-speak]: https://en.wikipedia.org/wiki/Leet
