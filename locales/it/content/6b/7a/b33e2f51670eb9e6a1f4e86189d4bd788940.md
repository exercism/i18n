# Test

Se hai scaricato un esercizio con lo strumento CLI, dovresti vedere un file Futhark che porta il nome dell'esercizio e un file `test.fut`.
Questo file contiene tutti i casi di test, gli stessi che vengono eseguiti dal test runner quando carichi la soluzione.
Puoi aggiungere liberamente altri casi di test per fare qualche esperimento.
Tuttavia, modificare i test non influisce sul test runner online.

## Test in locale

Per eseguire i test di un esercizio, apri un terminale nella directory dell'esercizio ed esegui il comando `futhark test test.fut` (oppure `exercism test`).

Per saperne di più sui test con Futhark, consulta la documentazione di [`futhark test`][test-command].
