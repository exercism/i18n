# Informazioni

In F#, i booleani sono rappresentati dal tipo `bool`, i cui valori possono essere `true` o `false`.

F# supporta tre [operatori booleani][operators]: `not` (NOT), `&&` (AND) e `||` (OR). Gli operatori `&&` e `||` usano la _valutazione a corto circuito_, il che significa che il lato destro dell'operatore viene valutato solo quando è necessario.

```fsharp
true || false // => true
true && false // => false
```

I tre operatori booleani hanno ciascuno una diversa [_precedenza degli operatori_][precedence]. Di conseguenza, vengono valutati in quest'ordine: prima `not`, poi `&&`, infine `||`. Se vuoi «aggirare» queste regole, puoi racchiudere un'espressione booleana tra parentesi tonde (`()`), dato che le parentesi hanno una precedenza degli operatori ancora più alta.

```fsharp
not true && false   // => false
not (true && false) // => true
```

[precedence]: https://docs.microsoft.com/en-us/dotnet/fsharp/language-reference/symbol-and-operator-reference/#operator-precedence
