# Istruzioni aggiuntive

## Suggerimenti

Devi implementare le funzioni `decode` e `encode`, che decodificano e codificano una `String` usando un cifrario affine.
Puoi usare la firma fornita se hai dubbi sui tipi, ma non lasciare che limiti la tua creatività.

Questo esercizio lavora con dati testuali.
Per ragioni storiche, il tipo `String` di Haskell è sinonimo di `[Char]`, una lista di caratteri.
Per gestire i dati testuali in modo più efficiente, si può usare il tipo `Text`.

Come estensione opzionale di questo esercizio, puoi

- aggiungere `- text` alla tua lista di dipendenze in package.yaml.
- importare `Data.Text` [in questo modo](https://hackernoon.com/4-steps-to-a-better-imports-list-in-haskell-43a3d868273c):

```haskell
import qualified Data.Text as T
import           Data.Text (Text)
```

- usare il tipo `Text`, ad esempio `decode :: Text -> Text`, e riferirti ai combinatori di `Data.Text` come ad esempio `T.pack`.
- consultare la documentazione di [`Data.Text`](https://hackage.haskell.org/package/text/docs/Data-Text.html).
- sostituire tutte le occorrenze di `String` con `Text` in Affine.hs, cioè:

```haskell
encode :: (Int, Int) -> Text -> Maybe Text
encode key plainText = ...

decode :: (Int, Int) -> Text -> Maybe Text
decode key cipherText = ...
```

Questa parte è del tutto opzionale.
