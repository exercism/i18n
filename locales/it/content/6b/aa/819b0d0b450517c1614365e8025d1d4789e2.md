# Informazioni

Tcl, pronunciato «tickle» e abbreviazione di Tool Command Language, è un linguaggio di programmazione dinamico e open source.

È stato progettato con l'obiettivo di essere molto semplice ma potente.
È così semplice che l'intera sintassi è descritta completamente in [appena 12 regole][rules].
Eppure è un linguaggio di programmazione completo di ogni funzionalità.

Tcl trasforma tutto in *comandi*, persino le assegnazioni di variabili, la definizione di procedure e il flusso di controllo.
Per questo assomiglia sia agli script di shell sia a Lisp.

Tcl supporta molteplici paradigmi di programmazione, tra cui gli stili orientato agli oggetti, imperativo e funzionale.
I casi d'uso più comuni di Tcl sono come runtime di scripting incorporati in applicazioni C e per la prototipazione di GUI con il toolkit grafico Tk.

Per iniziare con il linguaggio Tcl, ti consiglio di usare [il tutorial di Tcl][tutorial] mentre risolvi gli esercizi.
