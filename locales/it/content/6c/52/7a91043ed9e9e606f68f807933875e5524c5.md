# Introduzione

## Enum

Il tipo `enum` di C# rappresenta un insieme fisso di costanti denominate (un'enumerazione). Il suo scopo principale è fornire un modo sicuro rispetto ai tipi di interagire con costanti numeriche, limitando i valori disponibili a un insieme predefinito. Un enum semplice si può definire nel modo seguente:

```csharp
enum Season
{
    Spring,
    Summer,
    Autumn,
    Winter
}
```

Se non vengono definiti esplicitamente, ai membri dell'enum vengono assegnati automaticamente valori interi incrementali, con il primo valore uguale a zero. È anche possibile assegnare i valori esplicitamente:

```csharp
enum Answer
{
    Maybe = 1,
    Yes = 3,
    No = 5
}
```
