# Introduzione

Molti linguaggi di programmazione hanno tipi numerici specifici per rappresentare diversi tipi di numeri, ma JavaScript ne ha solo due:

- `number`: un tipo di dato numerico nel formato in virgola mobile a doppia precisione a 64 bit (IEEE 754).
  Alcuni esempi sono `-6`, `-2.4`, `0`, `0.1`, `1`, `3.14`, `16.984025`, `25`, `976`, `1024.0` e `500000`.
- `bigint`: un tipo di dato numerico che può rappresentare i _numeri interi_ nel formato a precisione arbitraria.
  Alcuni esempi sono `-12n`, `0n`, `4n` e `9007199254740991n`.

Se hai bisogno della [precisione arbitraria][ref-arbitrary-precision] o lavori con numeri estremamente grandi, usa il tipo `bigint`.
Altrimenti, il tipo `number` è probabilmente l'opzione migliore.

## Arrotondamento

Esiste un oggetto globale integrato chiamato `Math` che fornisce varie [funzioni di arrotondamento][ref-math-object-rounding]. Per esempio, puoi arrotondare per difetto (`floor`) o per eccesso (`ceil`) i numeri decimali al numero intero più vicino.

```javascript
Math.floor(234.34); // => 234
Math.ceil(234.34); // => 235
```

[ref-math-object-rounding]: https://javascript.info/number#rounding
[ref-arbitrary-precision]: https://en.wikipedia.org/wiki/Arbitrary-precision_arithmetic
