# return non necessario

Le buone pratiche di Scala indicano che è meglio evitare la parola chiave `return`. In Scala, il risultato dell'ultima espressione di una funzione viene restituito in modo implicito. Indicare `return` esplicitamente alla fine di una funzione può avere effetti collaterali indesiderati. [Say No To Return](https://blog.knoldus.com/scala-best-practices-say-no-to-return/).
