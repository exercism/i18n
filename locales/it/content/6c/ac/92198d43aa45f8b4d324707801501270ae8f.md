# Istruzioni

In questo esercizio scriverai del codice per stampare i badge con il nome dei dipendenti della fabbrica.

## 1. Stampa un badge per un dipendente

I dipendenti hanno un ID, un nome e il nome del reparto. Le etichette dei badge dei dipendenti hanno il seguente formato: `"[id] - name - DEPARTMENT"`. Implementa il metodo (_statico_) `Badge.Print()` in modo che restituisca l'etichetta del badge di un dipendente:

```csharp
Badge.Print(734, "Ernest Johnny Payne", "Strategic Communication");
// => "[734] - Ernest Johnny Payne - STRATEGIC COMMUNICATION"
```

Nota che nell'etichetta il reparto deve essere scritto in maiuscolo.

## 2. Stampa un badge per un nuovo dipendente

A causa di una stranezza del sistema informatico, capita che i nuovi dipendenti non abbiano ancora un ID quando iniziano a lavorare in fabbrica. Dato che i badge sono obbligatori, riceveranno un badge temporaneo senza il prefisso con l'ID. Modifica il metodo (_statico_) `Badge.Print()` in modo che supporti i nuovi dipendenti che non hanno ancora un ID:

```csharp
Badge.Print(id: null, "Jane Johnson", "Procurement");
// => "Jane Johnson - PROCUREMENT"
```

## 3. Stampa un badge per il proprietario

Anche il proprietario della fabbrica deve indossare un badge in ogni momento. Il proprietario, però, non ha un reparto. In questo caso, l'etichetta deve stampare `"OWNER"` al posto del nome del reparto. Modifica il metodo (_statico_) `Badge.Print()` in modo che stampi un'etichetta per il proprietario:

```csharp
Badge.Print(254, "Charlotte Hale", department: null);
// => "[254] - Charlotte Hale - OWNER"
```

Nota che il proprietario potrebbe anche essere un nuovo dipendente:

```csharp
Badge.Print(id: null, "Charlotte Hale", department: null);
// => "Charlotte Hale - OWNER"
```
