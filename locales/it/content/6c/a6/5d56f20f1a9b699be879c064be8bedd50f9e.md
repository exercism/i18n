# Istruzioni

Nel tuo laboratorio di ricerca sul DNA, hai sperimentato vari modi per comprimere i dati delle tue ricerche e risparmiare spazio di archiviazione. Un collega di squadra propone di convertire i dati del DNA in una rappresentazione binaria:

| Acido nucleico | Codice |
| -------------- | ------ |
| uno spazio     | `0000` |
| A              | `0001` |
| C              | `0010` |
| G              | `0100` |
| T              | `1000` |

Ci rifletti un po': potrebbe dimezzare i costi di archiviazione necessari, ma a scapito della leggibilità per gli esseri umani. Decidi di scrivere un modulo per codificare e decodificare i dati, così da valutare il risparmio.

## 1. Codificare un acido nucleico in un valore binario

Implementa `encode_nucleotide/1` in modo che accetti il code point dell'acido nucleico e restituisca il valore intero del codice codificato.

```elixir
DNA.encode_nucleotide(?A)
# => 1
# (which is equal to 0b0001)
```

## 2. Decodificare il valore binario nell'acido nucleico

Implementa `decode_nucleotide/1` in modo che accetti il valore intero del codice codificato e restituisca il code point dell'acido nucleico.

```elixir
DNA.decode_nucleotide(0b0001)
# => 65
# (which is equal to ?A)
```

## 3. Codificare una charlist di DNA

Implementa `encode/1` in modo che accetti una charlist che rappresenta acidi nucleici e spazi e restituisca un bitstring con i dati codificati.

```elixir
DNA.encode(~c"AC GT")
# => <<18, 4, 8::size(4)>>
```

## 4. Decodificare un bitstring di DNA

Implementa `decode/1` in modo che accetti un bitstring che rappresenta acidi nucleici e spazi e restituisca i dati decodificati come charlist.

```elixir
DNA.decode(<<132, 2, 1::size(4)>>)
# => ~c"TG CA"
```
