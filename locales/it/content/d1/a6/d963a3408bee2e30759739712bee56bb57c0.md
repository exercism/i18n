# Eseguire i test

Con `sbt` installato, puoi eseguire i test dalla riga di comando con:

```bash
$ sbt test
```

Tieni presente che eseguire `sbt test` ogni volta sarà lento, perché `sbt` viene reinizializzato a ogni invocazione.

`sbt` funziona come una shell: una volta avviato, puoi eseguire comandi al suo interno.

Per esempio, puoi usare `sbt` per rieseguire i test ogni volta che i file sorgente cambiano:
```bash
$ sbt
>~ test
```

Tieni conto che tutti i test sono stati disabilitati tranne il primo, su cui puoi iniziare a lavorare.
Per continuare, ti basta rimuovere la parola chiave `pending` dall'inizio di ogni caso di test.

Vai [qui](https://www.scala-sbt.org/) per saperne di più su `sbt`.


I test si possono eseguire anche all'interno dei seguenti IDE

* [Metals](https://scalameta.org/metals/docs/#running-tests)
* [IntelliJ IDEA con il plugin Scala](https://www.jetbrains.com/idea/)
