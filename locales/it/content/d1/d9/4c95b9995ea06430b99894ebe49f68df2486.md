# Installazione

Free Pascal Compiler versione 3.2.2 può essere installato direttamente dal gestore di pacchetti per un'ampia varietà di piattaforme e sistemi.
Se non è disponibile per il tuo sistema o la tua piattaforma, oppure se vuoi installare Free Pascal nella tua directory home, puoi procurarti i file binari da [Free Pascal - Download][fpc-download], scompattare il tarball, eseguire ```install.sh``` e aggiungere ```$HOME/fpc-3.2.2/bin``` alla variabile d'ambiente ```PATH```.

Per altre opzioni di installazione e/o una descrizione più dettagliata, visita la pagina [Installing the Free Pascal Compiler - Free Pascal wiki][fpc-install-wiki].

[fpc-download]: https://www.freepascal.org/download.html
[fpc-install-wiki]: https://wiki.freepascal.org/Installing_the_Free_Pascal_Compiler
