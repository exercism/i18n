# Appendice alle istruzioni

## Suggerimenti

Devi implementare la funzione `responseFor` che restituisce la risposta di Bob
per un dato input. Puoi usare la firma fornita se non sei sicuro
dei tipi, ma non lasciare che limiti la tua creatività:

```haskell
responseFor :: String -> String
```

Per risolvere questo esercizio puoi documentarti su:

- [Guardie][guards]

[guards]: https://www.futurelearn.com/courses/functional-programming-haskell/0/steps/27226

Questo esercizio lavora con dati testuali. Per ragioni storiche, il tipo
`String` di Haskell è sinonimo di `[Char]`, un array di caratteri. Per gestire
i dati testuali in modo più efficiente, si può usare il tipo `Text`.

Come estensione facoltativa di questo esercizio, puoi:

- Leggere qualcosa su [tipi di stringa](https://haskell-lang.org/tutorial/string-types) in Haskell.
- Aggiungere `- text` all'elenco delle dipendenze in package.yaml.
- Importare `Data.Text` nel [modo seguente](https://hackernoon.com/4-steps-to-a-better-imports-list-in-haskell-43a3d868273c):

    ```haskell
    import qualified Data.Text as T
    import           Data.Text (Text)
    ```

- Ora puoi scrivere ad esempio `responseFor :: Text -> Text` e fare riferimento ai combinatori di `Data.Text` come ad esempio `T.isSuffixOf`.
- Consultare la documentazione di [`Data.Text`](https://hackage.haskell.org/package/text/docs/Data-Text.html),
- Successivamente puoi sostituire tutte le occorrenze di `String` con `Text` in Bob.hs:

    ```haskell
    responseFor :: Text -> Text
    ```

Questa parte è del tutto facoltativa.
