# Introduzione

In Common Lisp una funzione può avere parametri con nome (detti «parametri keyword»).
Questi sono contrassegnati nella lambda list dalla keyword `&key`.
I parametri keyword non sono parametri obbligatori.
Come i parametri opzionali, possono ricevere valori predefiniti e simboli a cui legare il loro stato di «fornito oppure no».

Quando si chiama una funzione con parametri keyword, il nome del parametro viene usato come keyword davanti al valore del parametro.
Chi chiama la funzione può specificare i parametri keyword in qualsiasi ordine.

```lisp
(defun keyword-parameters (&key x (y 'default) (z nil z-supplied-p))
  (list x y (if z-supplied-p (list :z-was-supplied z)
                             (list :z-was-not-supplied z))))

(keyword-parameters)            ; => (NIL DEFAULT (:Z-WAS-NOT-SUPPLIED NIL))
(keyword-parameters :y 5)       ; => (NIL 5 (:Z-WAS-NOT-SUPPLIED NIL))
(keyword-parameters :z 10 :x 5) ; => (5 DEFAULT (:Z-WAS-SUPPLIED 10))
```

Bisogna fare attenzione quando si combinano parametri opzionali e parametri keyword, perché il nome della keyword e il suo argomento potrebbero essere consumati dai parametri opzionali:

```lisp
(defun could-be-confusing (&optional x y &key z) (list x y z))
(could-be-confusing :z 'huh?) ; => (:Z HUH? NIL)
```
