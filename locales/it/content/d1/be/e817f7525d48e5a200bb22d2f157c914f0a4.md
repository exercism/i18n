# Introduzione

Quando lavori con oggetti `java.time` come `LocalDate`, spesso hai bisogno di fare regolazioni complesse delle date, come trovare il «secondo martedì del mese».
Invece di calcolarlo a mano, puoi usare **`TemporalAdjusters`**.

La classe di utilità `java.time.temporal.TemporalAdjusters` (nota la «s» del plurale) fornisce metodi statici per molte regolazioni comuni delle date.
Queste regolazioni si applicano con il metodo `.with()` su un oggetto temporale (come `LocalDate`).

```exercism/note
Usare `with(TemporalAdjuster)` restituisce una _nuova_ istanza e non aggiorna quella esistente, perché gli oggetti `java.time` sono immutabili.
```

```java
import java.time.LocalDate;
import java.time.Month;
import java.time.DayOfWeek;
import java.time.temporal.TemporalAdjusters;

LocalDate date = LocalDate.of(2024, Month.AUGUST, 15); // 2024-08-15 (a Thursday)

// Use a predefined adjuster: find the last day of the month
LocalDate lastDay = date.with(TemporalAdjusters.lastDayOfMonth());
// => 2024-08-31
```

Ecco alcuni regolatori fondamentali, utili per i calcoli di pianificazione:

## Trovare l'ennesima occorrenza di un giorno della settimana

Usa `dayOfWeekInMonth(int ordinal, DayOfWeek dayOfWeek)` per trovare l'ennesima occorrenza di un giorno della settimana.

```java
// Find the second Tuesday of August 2024
LocalDate secondTuesday = date.with(TemporalAdjusters.dayOfWeekInMonth(2, DayOfWeek.TUESDAY));
// => 2024-08-13
```

## Trovare il primo o l'ultimo giorno della settimana nel mese

Usa `firstInMonth(DayOfWeek dayOfWeek)` oppure `lastInMonth(DayOfWeek dayOfWeek)`.

```java
// Find the last Monday of August 2024
LocalDate lastMonday = date.with(TemporalAdjusters.lastInMonth(DayOfWeek.MONDAY));
// => 2024-08-26
```

## Regolazioni relative (successiva/precedente)

Regolatori come `next()`, `previous()`, `nextOrSame()` e `previousOrSame()` trovano l'occorrenza successiva o precedente di un dato giorno della settimana, rispetto alla data attuale.

- `next()`/`previous()`: escludono la data attuale se corrisponde.
- `nextOrSame()`/`previousOrSame()`: includono la data attuale se corrisponde.

```java
LocalDate thursday = LocalDate.of(2024, Month.AUGUST, 15); // A Thursday

// Find the next Thursday (exclusive)
LocalDate nextThursday = thursday.with(TemporalAdjusters.next(DayOfWeek.THURSDAY));
// => 2024-08-22

// Find the next Thursday (inclusive) - returns the same date
LocalDate nextOrSameThursday = thursday.with(TemporalAdjusters.nextOrSame(DayOfWeek.THURSDAY));
// => 2024-08-15

// Find the previous Monday (exclusive)
LocalDate previousMonday = thursday.with(TemporalAdjusters.previous(DayOfWeek.MONDAY));
// => 2024-08-12
```

## Regolatori personalizzati

`TemporalAdjuster` è un'interfaccia funzionale, quindi puoi scrivere un regolatore tutto tuo come lambda che prende l'oggetto temporale da regolare e restituisce quello regolato.
Si applica con `.with()` esattamente come i regolatori predefiniti, e può usarli al suo interno.

```java
import java.time.temporal.TemporalAdjuster;

// An adjuster that moves a weekend date to the following Monday
TemporalAdjuster skipWeekend = temporal -> {
    DayOfWeek day = DayOfWeek.from(temporal);
    if (day == DayOfWeek.SATURDAY || day == DayOfWeek.SUNDAY) {
        return temporal.with(TemporalAdjusters.next(DayOfWeek.MONDAY));
    }
    return temporal;
};

LocalDate saturday = LocalDate.of(2024, Month.AUGUST, 17);
LocalDate monday = saturday.with(skipWeekend);
// => 2024-08-19
```

Usare questi regolatori della classe `TemporalAdjusters` può semplificare molto le attività di manipolazione delle date.
