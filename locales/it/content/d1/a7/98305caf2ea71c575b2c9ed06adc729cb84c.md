# Introduzione

Le liste sono un tipo integrato nel linguaggio Elixir. Sono considerate un tipo di base e si indicano con le parentesi quadre. Le liste possono essere vuote o contenere un numero qualsiasi di elementi di qualsiasi tipo. Per esempio:

```elixir
empty_list = []
one_item_list = [1]
two_item_list = [1, 2]
multiple_type_list = [1, :pi, 3.14, "four"]
```

Elixir implementa le liste come liste concatenate: ogni nodo memorizza due valori, il primo elemento e un'altra lista con tutti gli elementi rimanenti. Il primo elemento della lista è chiamato _testa_ e la lista degli elementi rimanenti è chiamata _coda_. Possiamo usare questa notazione nel codice:

```elixir
# [1] represented in [head | tail] notation
[1 | []]

# [1, 2, 3] represented in [head | tail] notation
[1 | [2 | [3 | []]]]
```

Possiamo usare la notazione _`[head | tail]`_ per anteporre elementi a una lista:

```elixir
# Suppose
list = [2, 1]

[3, 2, 1] == [3 | list]
# => true
```

Nel modulo `Kernel` ci sono diverse funzioni per lavorare con le liste, oltre all'intero modulo `List`.

```elixir
# Check if 1 is a member of the list
1 in [1, 2, 3, 4]
# => true
```
