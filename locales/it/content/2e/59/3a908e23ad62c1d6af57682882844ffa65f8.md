# Introduzione

Il modificatore `readonly` impedisce che il valore o il riferimento in un campo venga sovrascritto, ma non offre alcuna protezione per i membri di un tipo di riferimento.

```csharp
readonly List<int> ints = new List<int>();

void Foo()
{
    ints.Add(1);    // ok
    ints = new List<int>(); // fails to compile
}
```

Per garantire che tutti i membri di un tipo di riferimento siano protetti, si possono rendere i campi `readonly` e definire proprietà automatiche senza un accessor `set`.

La Base Class Library (BCL) fornisce alcune versioni di sola lettura delle collezioni, quando è necessario impedire che i membri di una collezione vengano aggiornati. Sono disponibili sotto forma di wrapper:

- `ReadOnlyDictionary<T>` espone un `Dictionary<T>` in sola lettura.
- `ReadOnlyCollection<T>` espone una `List<T>` in sola lettura.
