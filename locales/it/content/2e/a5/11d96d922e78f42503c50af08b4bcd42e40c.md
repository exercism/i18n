# Istruzioni

In questo esercizio scriverai del codice per tenere traccia di un array di linguaggi di programmazione che vuoi imparare su Exercism.

Hai sei attività e tutte quante avranno a che fare con gli array.

## 1. Crea un nuovo array

Per tenere traccia dei linguaggi che vuoi imparare, dovrai creare un nuovo array. Definisci la funzione `new_list`, che restituisce un nuovo array vuoto.

```gleam
new_list()
// -> []
```

## 2. Definisci un array esistente

Al momento hai un foglio di carta con l'elenco dei linguaggi che vuoi imparare: Gleam, Go e TypeScript. Definisci la funzione `existing_list` in modo che restituisca questo array.

```gleam
existing_list()
// -> ["Gleam", "Go", "TypeScript"]
```

## 3. Aggiungi un nuovo linguaggio a un array

Mentre esplori Exercism e trovi linguaggi sempre più interessanti, vorrai aggiungerli al tuo array. Implementa la funzione `add_language` per aggiungere un nuovo linguaggio all'inizio del tuo array.

```gleam
add_language(["OCaml", "Elixir"], "Scheme")
// -> ["Scheme", "OCaml", "Elixir"]
```

## 4. Conta i linguaggi nell'array

Contare i linguaggi uno per uno non è comodo. Implementa la funzione `count_languages` per contare quanti linguaggi ci sono nel tuo array.

```gleam
count_languages(["jq", "Elm", "Rust", "Kotlin"])
// -> 4
```

## 5. Inverti l'array

A un certo punto ti accorgi che il tuo array è in realtà ordinato al contrario! Implementa la funzione `reverse_list` per invertire il tuo array.

```gleam
reverse_list(["Python", "Julia", "Idris", "COBOL"])
// -> ["COBOL", "Idris", "Julia", "Python"]
```

## 6. Controlla se un array è entusiasmante

Anche se ami tutti i linguaggi, Gleam occupa un posto speciale nel tuo cuore. Per questo, un array di linguaggi ti entusiasma davvero se:

- Il primo elemento dell'array è Gleam.
- Il secondo elemento dell'array è Gleam e l'array contiene due o tre linguaggi.

Implementa la funzione `exciting_list` per controllare se un array di linguaggi è entusiasmante:

```gleam
exciting_list(["Lua", "Gleam"])
// -> True
```
