# Suggerimenti

## Generale

- [I dizionari nel libro di Cairo][book]
- [Il cheatsheet di Cairo][cheatsheet]

## 1. Memorizza l'unità di misura nel programma

- Per memorizzare le misure nel programma, puoi inserirle una per una in un dizionario

## 2. Crea un nuovo conto

- Per creare un nuovo conto, basta inizializzare un dizionario

## 3. Aggiungi un articolo al conto del cliente

- Per verificare se l'unità di misura indicata è corretta, puoi controllare se il dizionario delle misure restituisce un valore diverso da zero per una chiave

## 4. Rimuovi un articolo dal conto del cliente

- Per verificare se l'articolo indicato è nel conto del cliente, puoi controllare se il dizionario del conto restituisce un valore diverso da zero per una chiave

- Per verificare se l'unità di misura indicata è corretta, puoi controllare se il dizionario delle misure restituisce un valore diverso da zero per una chiave

## 5. Restituisci il numero di un articolo specifico presente nel conto del cliente

- Per verificare se l'articolo indicato è nel conto del cliente, basta recuperarlo dal dizionario
