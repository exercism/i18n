# Workflow di configlet

Il workflow configlet usa lo [strumento configlet](/docs/building/configlet) per verificare se i file (di configurazione) di un track sono strutturati correttamente, sia dal punto di vista sintattico che semantico.
Lo fa eseguendo [`configlet lint`](/docs/building/configlet/lint).

## Abilitare la verifica della formattazione dei file

I track possono usare [`configlet fmt`](/docs/building/configlet/format) per formattare i vari file di configurazione del track.
Lo stesso comando può anche servire a verificare se tutti i file di configurazione sono formattati correttamente.

Il workflow `configlet` supporta la verifica della corretta formattazione dei file di configurazione, ma è opzionale e disattivata per impostazione predefinita.
Per attivare la verifica della formattazione dei file di configurazione, segui questi passaggi:

1. Crea un file `.github/org-wide-files-config.toml` con il seguente contenuto

```toml
[configlet]
fmt = true
```

2. Dopo che questo file è stato unito in `main`, verrà aperta automaticamente una PR che modifica il workflow `configlet.yml` come segue:

```diff
  jobs:
    configlet:
      uses: exercism/github-actions/.github/workflows/configlet.yml@main
+     with:
+       fmt: true
```

3. Una volta unita questa PR, il workflow `configlet` verificherà anche la formattazione dei file di configurazione del track.

## Fonte

Il workflow è definito nel file `.github/workflows/configlet.yml`.
