# Introduzione

L'operatore `|>` è chiamato operatore pipe. Può essere usato per concatenare tra loro le chiamate di funzione, in modo che il valore restituito dalla chiamata di funzione precedente venga passato come primo argomento alla chiamata di funzione successiva.

```elixir
"hello"
|> String.upcase()
|> Kernel.<>("?!")

# => "HELLO?!"
```
