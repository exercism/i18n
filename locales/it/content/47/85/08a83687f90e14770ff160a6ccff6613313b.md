# Tuple

Le tuple sono un modo leggero per raggruppare insieme un insieme fisso di dati di tipi arbitrari. Una tupla non ha un nome particolare; dare un nome a una struttura dati la trasforma in una `struct`. I campi di una tupla non hanno nomi; vi si accede tramite destrutturazione o per posizione.

## Sintassi

Le tuple sono un elenco di campi racchiusi tra parentesi:

- `()` è il `unit type`, che è un [caso speciale](https://doc.rust-lang.org/std/primitive.unit.html)
- **(** _espressione_ **,)** è un'espressione di tupla a elemento singolo
- **(** _Tipo_ **,)** è un tipo di tupla a elemento singolo
- **(** _espressione_ **,** ... **)** è un'espressione di tupla generica
- **(** _Tipo_ **,** ... **)** è un tipo di tupla generico

### Creazione

Le tuple vengono sempre create con un'espressione di tupla:

```rust
// pointless but legal
let unit = ();
// single element
let single_element = ("note the comma",);
// two element
let two_element = (123, "elements can be of differing types");
```

Le tuple possono avere un numero arbitrario di elementi.

### Accesso tramite destrutturazione

È possibile accedere agli elementi di una tupla tramite destrutturazione. Questo significa semplicemente assegnare nomi di variabile ai singoli elementi della tupla, consumandola.

```rust
let (elem1, _elem2) = two_element;
assert_eq!(elem1, 123);
```

### Accesso per posizione

È anche possibile accedere agli elementi di una tupla tramite un indice numerico posizionale. L'indicizzazione, come sempre, inizia da 0.

```rust
let notation = single_element.0;
assert_eq!(notation, "note the comma");
```

## Struct tupla

Ti verrà anche chiesto di lavorare con le struct tupla. Come le struct normali, queste sono tipi con nome; a differenza delle struct normali, hanno campi anonimi. La loro sintassi è molto simile a quella delle tuple normali. È legale usare sia la destrutturazione che l'accesso posizionale.

```rust
struct TupleStruct(u8, i32);
let my_tuple_struct = TupleStruct(123, -321);
let borrowed_neg = &my_tuple_struct.1;
let TupleStruct(borrowed_byte, _) = &my_tuple_struct;
assert_eq!(borrowed_neg, &-321);
assert_eq!(borrowed_byte, &123);
```

### Visibilità dei campi

Tutti i campi delle tuple anonime sono sempre pubblici. Tuttavia, i campi delle struct tupla hanno una visibilità individuale che per impostazione predefinita è privata, proprio come i campi delle struct standard. Puoi rendere pubblici i campi con il modificatore `pub`, proprio come in una struct standard.

```rust
// fails due to private fields
mod tuple { pub struct TupleStruct(u8, i32); }
fn main() { let _my_tuple_struct = tuple::TupleStruct(123, -321); }
```

```rust
// succeeds: fields are public
mod tuple { pub struct TupleStruct(pub u8, pub i32); }
fn main() { let _my_tuple_struct = tuple::TupleStruct(123, -321); }
```
