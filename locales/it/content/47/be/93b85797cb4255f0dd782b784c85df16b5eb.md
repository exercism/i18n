# Uso dell'intestazione di funzione

[comment]: # (Questo errore viene generato quando la soluzione usa un'intestazione di funzione)

Un'intestazione di funzione (cioè la definizione di una funzione senza corpo) è necessaria solo per le funzioni con argomenti predefiniti che hanno più clausole.

```elixir
# necessary function header
def hello(what \\ "World")
def hello("Alice"), do: "Hello, darling!"
def hello(name), do: "Hello, #{name}!"
```

Per le funzioni con argomenti predefiniti che hanno una sola clausola, gli argomenti predefiniti si possono specificare direttamente in quella clausola.

```elixir
# preferred
def bye(name \\ "World"), do: "See you, #{name}!"

# not preferred - unnecessary function header
def bye(what \\ "World")
def bye(name), do: "See you, #{name}!"
```

La funzione `two_fer/1` richiede una sola clausola, quindi non serve un'intestazione di funzione.
