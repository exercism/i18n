# Aiuto

## Installazione di Rust

Consulta la [pagina di aiuto di exercism][help-page] per l'installazione di Rust e per le risorse di apprendimento.

## Inviare la soluzione

In genere conviene inviare tutti i file in cui hai implementato la soluzione (`src/lib.rs` nella maggior parte dei casi). Se usi crate esterni, valuta la possibilità di inviare anche il file `Cargo.toml`. Così il processo di revisione sarà più rapido e più chiaro.

## Feedback, problemi e pull request

Vai sul [forum](https://forum.exercism.org/c/programming/rust/) e crea un post per dare un feedback su un esercizio, oppure se vuoi contribuire a implementare nuovi esercizi.
I membri del team del track Rust saranno felici di aiutarti!

Il [repository del track][github] su GitHub è la casa di tutti gli esercizi di Rust.

Se vuoi saperne di più su Exercism, dai un'occhiata alla [guida alla contribuzione].

## Inviare soluzioni incomplete
È possibile inviare una soluzione incompleta, così puoi vedere come altri hanno completato l'esercizio.
