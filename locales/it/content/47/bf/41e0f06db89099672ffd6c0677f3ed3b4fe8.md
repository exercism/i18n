# Installazione

La versione attuale di elm è la 0.19.1.
Le istruzioni di installazione cambiano man mano che il linguaggio si evolve.
Per istruzioni di installazione aggiornate, vai alle
[istruzioni di installazione della guida di elm][elm-install].

[elm-install]: https://guide.elm-lang.org/install/elm.html

## Strumenti aggiuntivi

**elm-test**

Lo strumento usato per eseguire i test dalla riga di comando si chiama elm-test.
Al momento elm-test richiede Node.js e npm, quindi se non l'hai ancora fatto,
[installa prima Node.js e npm][npm-install].
Una volta installato npm, puoi installare elm-test con:

```shell
npm install --global elm-test@latest-0.19.1
```

Trovi maggiori informazioni sulla [pagina npm di elm-test][elm-test].

[npm-install]: https://www.npmjs.com/get-npm
[elm-test]: https://www.npmjs.com/package/elm-test

**elm-format**

La maggior parte dei programmatori elm usa elm-format per formattare il proprio codice elm.
È uno strumento di formattazione del codice che non richiede configurazione.
All'inizio può sembrare un po' frustrante se non sei abituato
agli strumenti di formattazione automatica, ma una volta che ci prendi la mano
ti chiederai come facevi a scrivere codice senza.
Si può installare anche con npm:

```shell
npm install --global elm-format@latest-0.19.1
```

Trovi maggiori informazioni sulla [pagina GitHub di elm-format][elm-format].

[elm-format]: https://github.com/avh4/elm-format

**Editor di testo**

Il supporto per Elm è buono almeno per [IntelliJ][intellij],
e per gli editor di testo compatibili con il [language server di elm][els],
come VS Code, Sublime Text o Vim.

[els]: https://github.com/elm-tooling/elm-language-server
[intellij]: https://github.com/klazuka/intellij-elm

## Errori di autorizzazione con npm

Potresti incontrare un errore di autorizzazione EACCESS con npm
quando installi elm-test o elm-format.
In tal caso, segui le istruzioni sul sito di npm.
[Risolvere gli errori di autorizzazione EACCES quando si installano pacchetti a livello globale][eaccess].

[eaccess]: https://docs.npmjs.com/resolving-eacces-permissions-errors-when-installing-packages-globally
