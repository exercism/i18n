# Introduzione

## Generici

### Introduzione

I generici sono una funzionalità del linguaggio che permette di riutilizzare il codice.
Per esempio, non dovrebbe importare quale tipo contiene un array per calcolarne la lunghezza.
Ecco perché la funzione `length` usa un parametro di tipo generico `a` nella sua firma di tipo.

```elm
length : List a -> Int
```

### Parametri nei tipi

Quando un tipo è generico rispetto a un altro tipo, usiamo un nome minuscolo per quest'altro tipo e lo chiamiamo parametro di tipo.
Esempi comuni sono i tipi personalizzati `List`, `Maybe` e `Result`.

```elm
-- Maybe is generic over the type a
type Maybe a
    = Nothing
    | Just a

someString : Maybe String
someString = Just "hello"

someInt : Maybe Int
someInt = Just 42
```

Un'osservazione importante sui nomi dei parametri di tipo è che possono essere lunghi più di un carattere.
L'unico vincolo è che devono essere nomi minuscoli.
Perciò, quando è utile, tendiamo a dare loro nomi descrittivi.

Un tipo può essere generico rispetto a più tipi diversi, e quindi avere più parametri di tipo.
In quel caso, ogni tipo indipendente riceve un nome minuscolo diverso.
Essere indipendenti non impedisce che diventino lo stesso tipo, permette soltanto che siano diversi.

```elm
-- Result is generic over the types error and value
type Result error value
    = Ok value
    | Err error
```

Anche gli alias di tipo record possono avere parametri di tipo, anche se è meno comune.

```elm
-- Event is generic over the type a
type alias Event a =
    { at : Time
    , data : a 
    }
```

### Parametri di tipo nelle funzioni

Dato che i tipi possono essere generici, possono esserlo anche le funzioni.
Si possono scrivere funzioni che gestiscono tipi generici, come `Maybe.withDefault`.

```elm
withDefault : a -> Maybe a -> a
withDefault default maybe =
    case maybe of
      Just value -> value
      Nothing -> default
```

Le funzioni che accettano altre funzioni come parametri si chiamano funzioni di ordine superiore, ed anche queste possono essere generiche.

```elm
map : (a -> b) -> Maybe a -> Maybe b
map function maybe =
  case maybe of
    Just value ->
      Just (function value)

    Nothing ->
      Nothing
```
