# Introduzione

Elixir rappresenta i valori true e false con il tipo booleano. Ci sono solo due valori: `true` e `false`. Questi valori possono essere legati a una variabile:

```elixir
true_variable = true
false_variable = false
```

Possiamo valutare espressioni strettamente booleane usando gli operatori `and/2`, `or/2` e `not/1`.

```elixir
true_variable = true and true
false_variable = true and false

true_variable = false or true
false_variable = false or false

true_variable = not false
false_variable = not true
```

Quando si scrive una funzione che restituisce un valore booleano, è idiomatico terminare il nome della funzione con un `?`. La stessa convenzione si può usare per le variabili che memorizzano valori booleani.

```elixir
def either_true?(a?, b?) do
  a? or b?
end
```
