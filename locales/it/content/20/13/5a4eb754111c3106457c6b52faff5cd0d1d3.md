# Introduzione

Quando hai diversi valori discreti possibili tra cui scegliere, `case` (in [`combinators`][combinators]) è più adatto di una catena di `if`.

## `case`

```
case ( obj assoc -- )
```

`case` prende il valore dalla cima dello stack e un *assoc* di clausole. Ogni clausola è `{ value [ body ] }`. Vince la prima clausola il cui valore `=` l'input: il suo corpo viene eseguito con il valore di input *già consumato*. Una voce finale che è solo `[ body ]` è quella predefinita: l'input è *ancora sullo stack* quando viene eseguita.

```factor
USING: combinators ;

: name-of ( n -- s )
    {
        { 1 [ "one" ] }
        { 2 [ "two" ] }
        [ drop "many" ]
    } case ;
```

L'uguaglianza è per `=`, quindi qualsiasi cosa che risulti uguale funziona come chiave: numeri, stringhe e simboli vanno tutti bene.

## `cond` per i rami con guardia

Quando la scelta dipende da un *predicato* invece che dall'uguaglianza (ad esempio `x > 11`), `cond` è lo strumento adatto. Hai già incontrato `cond` in [Cars, Assemble!][cars-assemble].

## I simboli

Un `SYMBOL:` dichiara una parola che mette sé stessa sullo stack, cioè un valore etichetta che si valuta da solo. `SYMBOLS:` ne dichiara diversi in una volta:

```factor
SYMBOLS: yes no maybe ;
```

Ora `yes` è un valore, confrontabile con `=`, che puoi usare come chiave di un `case`:

```factor
: invert ( ? -- ?' )
    { { yes [ no ] } { no [ yes ] } [ ] } case ;
```
