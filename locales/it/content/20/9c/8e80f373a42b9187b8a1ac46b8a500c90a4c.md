# Istruzioni

In questo esercizio elaborerai voci di log.

Ogni riga di log è una stringa formattata come segue: `"[<LEVEL>]: <MESSAGE>"`.

Ci sono tre livelli di log diversi:

- `INFO`
- `WARNING`
- `ERROR`

Hai tre compiti, ciascuno dei quali prenderà una riga di log e ti chiederà di fare qualcosa con essa. Ci sono molti modi per risolvere questi compiti: scegli le tecniche che preferisci tra gli esempi qui sopra e vedi cosa riesci a mettere insieme.

## 1. Ottieni il messaggio da una riga di log

Implementa la funzione `message` per restituire il messaggio di una riga di log:

```jq
"[ERROR]: Invalid operation" | message
# => "Invalid operation"
```

Eventuali spazi bianchi all'inizio o alla fine vanno rimossi:

```jq
"[WARNING]:  Disk almost full\r\n" | message
# => "Disk almost full"
```

## 2. Ottieni il livello di log da una riga di log

Implementa la funzione `log_level` per restituire il livello di log di una riga di log, che deve essere restituito in minuscolo:

```ruby
"[ERROR]: Invalid operation" | log_level
# => "error"
```

## 3. Riformatta una riga di log

Implementa la funzione `reformat` che riformatta la riga di log, mettendo prima il messaggio e poi il livello di log tra parentesi:

```ruby
"[INFO]: Operation completed" | reformat
# => "Operation completed (info)"
```
