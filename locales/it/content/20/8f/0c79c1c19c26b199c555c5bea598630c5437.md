# Promozione delle proprietà del costruttore

Nelle classi che dichiarano molte proprietà, dichiarare separatamente la classe, le sue proprietà e un costruttore che le imposta richiede di scrivere più volte le stesse cose.
Con la promozione delle proprietà del costruttore possiamo ridurre questa ripetizione.

```php
<?php

class Book
{
    private string $isbn;
    private string $doi;
    private string $title;

    public function __construct(string $isbn, string, $doi, string $title)
    {
        $this->isbn = $isbn;
        $this->doi = $doi;
        $this->title = $title;
    }
}

// Using constructor property promotion
class Book
{
    public function __construct(
        private string $isbn,
        private string $doi,
        private string $title
    ) {
    }
}
