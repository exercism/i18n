# Introduzione

PHP permette di definire funzioni all'interno di altre funzioni. Queste funzioni non hanno bisogno di un nome, ma possono essere assegnate a delle variabili o persino passate direttamente a un'altra funzione che richiede una funzione come parametro.

```php
function onlyOdds(array $numbers): array
{
    return array_filter($numbers, function($num) {
        return $num % 2 === 1;
    });
}
```
