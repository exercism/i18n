# Test

## Clojure CLI

Gli esercizi di Clojure su Exercism includono un file `deps.edn` con un alias `:test` per invocare [cognitect-labs test-runner](https://github.com/cognitect-labs/test-runner):

``` bash
clj -X:test
```

## Leiningen

Leiningen può essere usato anche per eseguire il test dell'esercizio, eseguendo il comando seguente dalla directory dell'esercizio:

```bash
lein test
```
