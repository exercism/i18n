# Istruzioni

La compagnia di danza si dispone in file, e tieni traccia di chi sta dove.

Tutti e cinque i compiti vanno nella classe `DANCE_FORMATION`.

## 1. Quanti nella fila?

```sather
DANCE_FORMATION::dancer_count(|"Mia", "Ana", "Ben"|)
-- => 3
```

## 2. Chi guida?

Il leader è chi sta per primo.

```sather
DANCE_FORMATION::leader(|"Mia", "Ana", "Ben"|)
-- => "Mia"
```

## 3. Chi è in fondo?

Il chiudifila è chi sta per ultimo, per quanto lunga sia la fila.

```sather
DANCE_FORMATION::back_marker(|"Mia", "Ana", "Ben"|)
-- => "Ben"
```

## 4. La formazione iniziale

La compagnia si dispone sempre nello stesso ordine all'inizio: Mia, Ana, Ben. Restituisci quella fila.

```sather
DANCE_FORMATION::opening_row
-- => an array holding "Mia", "Ana" and "Ben", in that order
```

Questa routine non accetta argomenti.

## 5. Conta i passi

Ogni ballerino ha un numero di passi da fare. Somma i passi.

```sather
DANCE_FORMATION::total_steps(|8, 16, 8|)
-- => 32
```

Una fila vuota vale zero passi.
