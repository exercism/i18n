# Istruzioni aggiuntive

## Istruzioni specifiche della traccia

### Formato del campo minato

Il campo minato è rappresentato come una stringa, con un carattere di nuova riga alla fine di ogni riga.

Un esempio sarebbe `"   \n * \n   \n"`

### Memoria riservata

Il buffer per la stringa di input usa i byte 64-319 della memoria lineare.

La stringa di input può essere modificata sul posto, se lo si desidera.
