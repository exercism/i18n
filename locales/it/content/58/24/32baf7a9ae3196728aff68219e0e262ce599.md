# Stringa

Il tipo di dati `String` è una serie lineare di caratteri codificati in UTF-8. È utile per memorizzare dati testuali.

## Creare una stringa

Una stringa può essere creata usando le funzioni associate `String::new()` o `String::from()`. Molti tipi hanno un metodo `to_string` per produrre una stringa, ad esempio a partire da un numero.

```rust
let my_string = String::from("The answer is");
let answer = 42.to_string();
println!("{my_string} {answer}");
```

### La macro `format!`

Poiché produrre una stringa grande a partire da una selezione di tipi di dati più piccoli è un'operazione comune, Rust ha anche una scorciatoia che omette i dettagli della chiamata a `to_string`: la macro `format!`. Per esempio, potremmo semplificare la costruzione della stringa composta qui sopra come segue:

```rust
let the_answer = format!("{} {}.", "The answer is", 42);
assert_eq!("The answer is 42.", the_answer);
```

## String slice

Le stringhe hanno una stretta relazione con gli string slice. Uno string slice è un riferimento immutabile a una regione di memoria di dimensione nota, che contiene una serie lineare di caratteri codificati in UTF-8. Qualsiasi stringa può essere convertita in uno string slice prendendola in prestito con l'operatore di dereferenziazione (`&`). Per convertire uno string slice in una stringa, vanno bene sia il metodo `to_string()` sia `String::from`.

Nel codice Rust, una stringa letterale è racchiusa tra doppi apici. Queste stringhe letterali sono sempre string slice, perché fanno riferimento a una regione di memoria immutabile all'interno dell'eseguibile del programma.

```rust
let string = String::from("string");
let slice = "string";
assert_eq!(slice, &string);
```

## Modificare una stringa

Per concatenare un singolo carattere a una stringa, usa il metodo `push`. Per concatenare uno string slice a una stringa, usa il metodo `push_str` o l'operatore `+`.

```rust
fn main() {
    // For demonstration purposes, we're not using `format!`
    let s1 = String::from("tic");
    let s2 = String::from("tac");
    let s3 = String::from("toe");

    let s = s1 + "-" + &s2 + "-" + &s3;
    println!("{s}");
}
```

## Accedere ai caratteri di una stringa

Poiché le stringhe Rust sono codificate in UTF-8, i singoli caratteri non hanno tutti la stessa dimensione. Perciò il tipo di dati `String` non fornisce un operatore di indicizzazione (`[]`). Per accedere a tutti i caratteri o a un carattere specifico di una stringa, si può usare il metodo `chars()`. Questo itera su ogni carattere della stringa, in sequenza.

```rust
let alphabet: String = ('a'..='z').collect();
for c in alphabet.chars() {
    println!("{c}");
}
let j = alphabet.chars().nth(9);
println!("{j:?}"); // prints Some('j')
```

La stringa è un tipo di dati ricco, con diversi metodi e macro costruiti attorno ad essa. Dai un'occhiata alla [documentazione della libreria standard](https://doc.rust-lang.org/std/string/struct.String.html) per tutti i metodi e le funzionalità offerte dalla stringa.
