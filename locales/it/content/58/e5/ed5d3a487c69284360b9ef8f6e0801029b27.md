Potresti voler inserire questi widget da solo nei documenti Markdown, per esempio alla fine di un documento per suggerire letture aggiuntive o esercizi validi da cui imparare qualcosa.

**Nota:** Puoi anche usare i link normali per il testo in linea, a cui verranno aggiunti i tooltip. Vedi [la documentazione sui link interni](/docs/building/markdown/internal-linking) per maggiori dettagli.

## Utilizzo

I widget si possono usare ovunque si possa usare Markdown, ad esempio nella documentazione, negli approcci e nelle discussioni tra studenti e mentori.

Vengono renderizzati usando il seguente formato:

```md
[<type>:<id>]()
```

Le parti `<type>` e `<id>` sono variabili e dipendono dal widget effettivamente usato.

Il riferimento del link, cioè il contenuto di `()`, viene ignorato dal sito. Puoi farli puntare dove vuoi, ai fini della manutenzione.

## Widget degli esercizi

Formato del link: `[exercise:<track-slug>/<exercise-slug>]()`

### Esempio

```markdown
Great job on solving this exercise! Some other exercises that you might also like to try:

- [exercise:fsharp/anagram]()
- [exercise:fsharp/isogram]()
```

## Widget dei concetti

Formato del link: `[concept:<track-slug>/<concept-slug>]()`

### Esempio

```markdown
There are three primary conditional statements that are used in Julia:

- [concept:julia/if-statements]()
- [concept:julia/ternary-operator]()
- [concept:julia/short-circuiting]()
```

## Widget degli approcci

Formato del link: `[approach:<track-slug>/<exercise-slug>/<approach-slug>]()`

### Esempio

```markdown
Here are some approaches you might want to checkout!

- [approach:csharp/two-fer/method-overloading]()
- [approach:csharp/two-fer/optional-parameter]()
```

## Widget degli articoli

Formato del link: `[article:<track-slug>/<exercise-slug>/<article-slug>]()`

### Esempio

```markdown
We have an article you might be interested in:

- [article:csharp/reverse-string/performance]()
```
