# Introduzione

I tipi esterni possono essere usati per fare riferimento a tipi di dati definiti in altri linguaggi, come Erlang o JavaScript.

Per definire una funzione esterna, dichiara un tipo ma non fornire alcun costruttore. Questo può poi essere usato allo stesso modo di qualsiasi altro tipo.

```gleam
pub type OrderedDictionary(element)
```
