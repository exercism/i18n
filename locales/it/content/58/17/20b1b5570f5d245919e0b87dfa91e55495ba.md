# parametro obbligatorio imprevisto

Il parametro \`${'parameter.name'}\` viene chiamato nei test sia con sia senza un valore, ma _non è contrassegnato come opzionale_, il che significa che i test non passeranno. Un parametro TypeScript può essere contrassegnato esplicitamente come opzionale usando un suffisso `?`:

```typescript
function(${'parameter.name'}?: ${'parameter.type'}) {
  //
}
```

In alternativa, gli si può assegnare un valore predefinito:

```typescript
function(${'parameter.name'}: ${'parameter.type'} = <default>) {
  //
}
```
