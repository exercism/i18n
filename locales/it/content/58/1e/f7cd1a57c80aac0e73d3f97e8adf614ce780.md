# Introduzione

In generale, non conviene reinventare la ruota quando si programma.
Per molti algoritmi standard, ci sarà qualcuno che potrebbe aver già fatto il lavoro al posto tuo.

## Inclusioni

Per includere il contenuto di altri file, C++ usa la direttiva `include`.
Queste inclusioni dovrebbero essere indicate all'inizio del file.
Durante la compilazione, la riga con la direttiva viene sostituita dal contenuto del file corrispondente.
I namespace vengono mantenuti come nel file originale dopo le inclusioni.

## La libreria standard

La libreria standard offre molte funzioni, algoritmi e strutture dati comuni.
La libreria standard usa il namespace `std`.

Un esempio è la libreria numerica del C `cmath`.
Fornisce molte operazioni matematiche comuni.

```cpp
#include <cmath>

int cube_me(int a) {
    // raise `a` to the third power
    return std::pow(a, 3);
}
```

~~~~exercism/note
Le librerie standard vengono incluse con parentesi angolari `<>` invece che con virgolette doppie `"`.
La differenza sta nel luogo in cui il compilatore cerca i rispettivi file.
La ricerca nel progetto corrente viene saltata per la versione con parentesi angolari, e inizia direttamente nelle directory di inclusione del sistema.
Se vuoi includere file locali, useresti le virgolette doppie: `#include "myfile"`
~~~~
