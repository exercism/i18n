# Introduzione

Un *insieme disgiunto* (una struttura union-find) mantiene una raccolta di valori
suddivisi in gruppi non sovrapposti e risponde rapidamente a una domanda:
questi due valori sono nello stesso gruppo? Si trova nel vocabolario
[`disjoint-sets`][disjoint-sets].

## Costruire un insieme disgiunto

`<disjoint-set>` costruisce una struttura vuota. I valori, cioè gli *atomi*,
vengono aggiunti con `add-atom` uno alla volta, oppure con `add-atoms` a partire
da una sequenza. Ogni atomo inizia in un gruppo a sé.

```
<disjoint-set> ( -- disjoint-set )
add-atom       ( atom disjoint-set -- )
add-atoms      ( seq disjoint-set -- )
```

```factor
USING: disjoint-sets ;

<disjoint-set>
{ 1 2 3 } over add-atoms   ! 1, 2 and 3 each in their own group
```

L'insieme disgiunto è *mutabile*: `add-atom`, `add-atoms` ed `equate` lo
modificano sul posto invece di restituirne uno nuovo. `keep` è comodo quando
vuoi riavere l'insieme disgiunto sullo stack dopo che una di queste parole lo ha
consumato.

## Unire i gruppi

`equate` unisce i due gruppi che contengono i suoi atomi. L'unione è transitiva:
se si esegue l'operazione equate tra due atomi, poi tra uno di essi e un terzo,
tutti e tre finiscono in un unico gruppo.

```
equate ( atom1 atom2 disjoint-set -- )
```

## Rappresentanti

Ogni gruppo ha un unico membro canonico, il suo *rappresentante*.
`representative` lo restituisce, e due atomi appartengono allo stesso gruppo
esattamente quando i loro rappresentanti sono uguali.

```
representative ( atom disjoint-set -- representative )
```

```factor
USING: disjoint-sets ;

<disjoint-set>
{ 1 2 3 } over add-atoms
1 2 pick equate
1 over representative .   ! => 1
2 over representative .   ! => 1   (same representative as 1)
3 over representative .   ! => 3   (still on its own)
```

Quale atomo un gruppo sceglie come rappresentante è un dettaglio interno: non
fare mai affidamento sul fatto che venga scelto un atomo particolare, ma solo sul
fatto che due atomi nello stesso gruppo abbiano lo stesso rappresentante.
