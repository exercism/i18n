# Suggerimenti

## Generale

- Usa il [tipo di array (concatenato)][list] integrato.

## 1. Definisci una funzione per restituire un array vuoto di linguaggi

- La funzione deve restituire `[]`.

## 2. Definisci una funzione per aggiungere un linguaggio all'array

- Un elemento può essere anteposto a un array usando `|`.

## 3. Definisci una funzione per rimuovere un linguaggio dall'array

- Elixir [fornisce una funzione][tl] per restituire un array con il primo elemento rimosso.

## 4. Definisci una funzione per restituire il primo elemento dell'array

- Elixir [fornisce una funzione][hd] per ottenere il primo elemento di un array.

## 5. Definisci una funzione per restituire quanti linguaggi ci sono nell'array

- Elixir [fornisce una funzione][length] per contare la lunghezza di un array.

## 6. Definisci una funzione per determinare se l'array include un linguaggio funzionale

- La funzione dovrebbe restituire un valore booleano che indichi se `"Elixir"` è un membro dell'array. Elixir [fornisce una funzione][in] per verificare l'appartenenza a un array.

[length]: https://hexdocs.pm/elixir/Kernel.html#length/1
[in]: https://hexdocs.pm/elixir/Kernel.html#in/2
