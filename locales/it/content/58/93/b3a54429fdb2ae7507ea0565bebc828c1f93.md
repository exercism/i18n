# Approfondimento

Le [guardie][guards] si usano come complemento al [pattern matching][exercism-pattern-matching], che tratteremo in un concetto successivo.
Le guardie ci permettono di avere implementazioni diverse di una funzione a seconda del valore dell'input e consentono controlli più complessi.

Un'istruzione di guardia è definita da una barra verticale `|` seguita da un'espressione booleana, e termina con un segno di uguale `=` e il corpo della funzione.
Per una singola funzione possono esserci più istruzioni di guardia.
Le istruzioni di guardia vengono valutate dall'alto verso il basso: la prima che dà come risultato `True` viene eseguita.
Un'istruzione di guardia ammette un'istruzione `otherwise`, che fa da caso generale per qualsiasi valore che non corrisponde alle istruzioni di guardia precedenti.

```haskell
isEven :: Int -> String
isEven n
    | even n = "n is even"
    | otherwise = "n is odd"
```

Possiamo anche definire una funzione e usarla all'interno dell'istruzione di guardia.

```haskell
isEven' :: Int -> Bool
isEven' n = even n

isEven :: Int -> String
isEven n
    | isEven' n = "n is even"
    | otherwise = "n is odd"
```
