# Suggerimenti

## 1. Controlla se un valore è un booleano

- Puoi usare `typeof` per trovare il tipo di un valore.
- `typeof` restituisce una stringa.

## 2. Controlla se un valore è un numero.

- Puoi usare `typeof` per trovare il tipo di un valore.
- `typeof` restituisce una stringa.
- Devi controllare `Infinity` e `NaN`.
- `NaN` non è mai uguale a se stesso, ma esiste una [funzione integrata][isNaN] per verificare se un valore è NaN.

## 3. Controlla se un valore è un oggetto

- Puoi usare `typeof` per trovare il tipo di un valore.
- `typeof` restituisce una stringa.
- Devi controllare `null`.

## 4. Controlla se una stringa è numerica

- Puoi usare `typeof` per trovare il tipo di un valore.
- `typeof` restituisce una stringa.
- Puoi iterare su una stringa per controllare se tutti i caratteri sono cifre.

## 5. Controlla se un oggetto è elettronico

- Puoi usare `instanceof` per controllare se un oggetto è un'istanza di una classe o di una delle sue sottoclassi.

## 6. Controlla se un valore è un array non vuoto

- Puoi usare `typeof` per trovare il tipo di un valore.
- `typeof` restituisce una stringa.
- Puoi controllare la lunghezza di un array per scoprire quanti elementi contiene.

## 7. Controlla se un valore è un array vuoto

- Puoi usare `typeof` per trovare il tipo di un valore.
- `typeof` restituisce una stringa.
- Puoi controllare la lunghezza di un array per scoprire quanti elementi contiene.

## 8. Controlla se un oggetto ha una proprietà o un metodo `type`

- Puoi usare l'operatore `in` per controllare se un oggetto ha una proprietà o un metodo.

## 9. Lancia un errore se un oggetto non ha la proprietà o il metodo `id`

- Puoi usare l'operatore `in` per controllare se un oggetto ha una proprietà o un metodo.
- Se manca la proprietà o il metodo `id`, la funzione deve lanciare un `Error`.

## 10. Controlla se un oggetto ha una proprietà `id`

- Per controllare se un oggetto ha una proprietà (non un metodo), puoi usare la funzione `Object.hasOwn()`.

## 11. Controlla se un oggetto ha una proprietà `type` definita

- Per controllare se un oggetto ha una proprietà (non un metodo), puoi usare la funzione `Object.hasOwn()`.
- Dovrai accedere alla proprietà `type` e controllare se è definita.

[isNaN]: https://developer.mozilla.org/en-US/docs/Web/JavaScript/Reference/Global_Objects/isNaN
