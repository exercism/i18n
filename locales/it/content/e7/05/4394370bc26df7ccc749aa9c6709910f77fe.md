# Introduzione

Un [array][list] è una collezione mutabile di elementi in _sequenza_.
 Gli array possono contenere riferimenti a uno o più tipi di dato, compresi altri array o strutture dati come [tuple][tuples], [set][sets] o [dict][dicts].
 Si può iterare sul contenuto usando il costrutto `for item in <list>`.
 Se insieme al contenuto servono anche gli indici, si può usare `for index, item in enumerate(<list>)`.
 Gli elementi all'interno di una `list` si possono ottenere tramite un indice `0-based index` da sinistra, oppure `-1-based index` da destra.
 Gli array si possono copiare del tutto o in parte usando la _slice notation_ oppure `<list>.copy()`.
 Python fornisce molti [metodi][list-methods] utili e comodi per lavorare con gli array.
