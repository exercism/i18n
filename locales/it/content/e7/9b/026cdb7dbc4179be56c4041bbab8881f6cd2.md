# Informazioni

L'attributo Flags consente di rappresentare i valori definiti in un'unione discriminata come posizioni di bit (ovvero flag).
In quanto flag, tali valori possono essere combinati, rendendo possibile rappresentare più condizioni booleane in un singolo valore.

```fsharp
[<Flags>]
type PhoneFeatures =
| Call = 1
| Text = 2
```

```fsharp
[<Flags>]
type PhoneFeaturesBinary =
| Call = 0b00000001
| Text = 0b00000010
```

Per impostare un flag si può usare l'operatore OR bit per bit (`|||`); per disattivare un flag si può usare una combinazione dell'operatore AND bit per bit (`&&&`) e dell'operatore di negazione bit per bit (`~~~`).
Sebbene lo stato di un flag possa essere controllato con l'operatore AND bit per bit, si può anche usare il metodo HasFlag().

```fsharp
let features = PhoneFeatures.Call

// Set the Text flag
let moreFeatures = features ||| PhoneFeatures.Text

moreFeatures.HasFlag(PhoneFeatures.Call) // => true
moreFeatures.HasFlag(PhoneFeatures.Text) // => true

// Unset the Call flag
let lessFeatures = features &&& ~~~PhoneFeatures.Call

lessFeatures.HasFlag(PhoneFeatures.Call) // => false
lessFeatures.HasFlag(PhoneFeatures.Text) // => true
```
