# Appendice alle istruzioni

## Memoria riservata

Il buffer per la stringa di input occupa i byte da 64 a 191 della memoria lineare.

## Array

WebAssembly non ha il concetto di array.
Per il test dei colori, restituisci un buffer di caratteri delimitato da virgole nel formato: `black,brown,red,orange,yellow,green,blue,violet,grey,white`

Dovrai poi costruire internamente un array di strutture usando offset e lunghezze per dare struttura a questo buffer.
