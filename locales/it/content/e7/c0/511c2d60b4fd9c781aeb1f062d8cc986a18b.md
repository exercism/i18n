# Exercism CLI

La [CLI di Exercism][cli] permette agli studenti di scaricare esercizi e inviare soluzioni al sito. Supporta anche il comando `exercism test`, che a sua volta lancia il comando specifico della traccia per eseguire i test.

## Aggiungere un nuovo linguaggio

I comandi di test specifici della traccia sono definiti in un [file di configurazione][test-configurations]. Puoi aggiungere il supporto per il tuo linguaggio inserendo una voce in quel [file di configurazione][test-configurations], dove la chiave è lo slug della traccia.

### Segnaposto del comando di test

Ci sono tre segnaposto che si possono usare nel comando specifico della traccia:

- `{{test_files}}`: un elenco separato da spazi dei file di test (come si trova nella chiave `.files.test` del file `.meta/config.json` dell'esercizio)
- `{{solution_files}}`: un elenco separato da spazi dei file di soluzione (come si trova nella chiave `.files.solution` del file `.meta/config.json` dell'esercizio)
- `{{slug}}`: lo slug dell'esercizio (come si trova nella chiave `slug` dell'esercizio nel file `config.json` alla radice della traccia)

Ecco una [pull request di esempio][example-pr] che aggiunge il supporto per il linguaggio Arturo.
