# nessun export con nome

Non è stato trovato alcun [export](https://developer.mozilla.org/en-US/docs/Web/JavaScript/Reference/Statements/export) chiamato `%{export.name}`. I test non passeranno senza.

Assicurati che `%{export.name}` esista e aggiungi `export` davanti:
```javascript
// exporting a "const"
export const %{export.name} = /*...*/

// exporting a named function declaration
export function %{export.name}() { /* ... */ }
```
