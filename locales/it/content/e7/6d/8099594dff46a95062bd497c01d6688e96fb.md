# Introduzione

## Pattern matching sui valori letterali

Sebbene le espressioni `if/else` possano essere usate per eseguire logica condizionale, Haskell ha anche un modo più potente per farlo: il [pattern matching][pattern-matching].
Con il pattern matching, un valore può essere verificato rispetto a uno o più _pattern_.
Un esempio di tale pattern è il _pattern costante_, che verifica un valore rispetto a una costante (ad esempio `1` o `"hello"`).

Quando definisci funzioni, puoi definire corpi di funzione separati per pattern diversi.
Questo porta a codice pulito, semplice e leggibile.
Puoi fare pattern matching su qualsiasi tipo di dato: numeri, caratteri, liste, tuple e così via.

Ad esempio, una funzione semplice che prende un numero intero (`Int`) e lo avvicina di _1_ a _0_ potrebbe essere espressa così:

```haskell
closerToZero :: Int -> Int
closerToZero 0 = 0
closerToZero 1 = 0
```

Il pattern matching dà il meglio di sé quando viene usato insieme ad altri pattern, ad esempio il _pattern variabile_:

```haskell
closerToZero :: Int -> Int
closerToZero 0 = 0
closerToZero n = n - 1
```

L'esempio sopra tratta allo stesso modo tutti gli input diversi da _0_ e produrrebbe risultati errati per i numeri negativi.
Questo può essere risolto usando pattern condizionali, noti come _guardie_, che vengono espressi con il simbolo `|`:

```haskell
closerToZero :: Int -> Int
closerToZero n
    | n < 0 = n + 1
    | n > 0 = n - 1
```

Negli esempi sopra, non tutti gli input possibili hanno un pattern corrispondente.
Il compilatore lo rileva e produce un avviso.
Questa è una funzionalità molto utile di Haskell che aiuta a garantire che tutti i percorsi possibili siano coperti, evitando errori a runtime.
È noto come _controllo di esaustività_.
Per risolvere l'avviso, devi gestire tutti i casi.
All'interno delle _guardie_ puoi usare l'espressione `otherwise` come zucchero sintattico per `True`, per intercettare tutti i pattern rimanenti.

```haskell
closerToZero :: Int -> Int
closerToZero n
    | n < 0 = n + 1
    | n > 0 = n - 1
    | otherwise = 0
```

Il pattern matching verifica un valore rispetto a ogni pattern dall'alto verso il basso, finché non trova un pattern corrispondente ed esegue la logica associata a quel pattern.
**L'ordine dei pattern è importante!**
