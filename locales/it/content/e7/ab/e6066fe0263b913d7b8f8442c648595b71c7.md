# Appendice alle istruzioni

## Suggerimenti

Per far passare il test, dovrai creare alcuni tipi su cui far lavorare il codice: ti serve un oggetto per `School` che contenga una sequenza di tipo `Student`, che sarà una tupla di `string` e `int` per contenere name e grade degli studenti.

Ecco un po' di codice per i tipi che potrebbe esserti utile per iniziare

```nim
type
  Student* = tuple[name: string, grade: int]
  School* = object
    students*: seq[Student]
```
