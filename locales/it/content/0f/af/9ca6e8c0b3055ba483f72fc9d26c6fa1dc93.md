# Suggerimenti

## 1. Stampa un badge per un dipendente

- Puoi usare l'[interpolazione di stringhe][string-interpolation] per creare le stringhe di descrizione.
- Esiste un [metodo integrato per convertire una stringa in maiuscolo][to-upper-case].

## 2. Stampa un badge per un nuovo dipendente

- Prima di usarlo, dovresti controllare se l'ID è `null`.
- Puoi usare gli [operatori di uguaglianza][equality-operators] per confrontare il valore con `null`.

## 3. Stampa un badge per il proprietario

- Prima di usarlo, dovresti controllare se il reparto è `null`.
- Puoi usare gli [operatori di uguaglianza][equality-operators] per confrontare il valore con `null`.
