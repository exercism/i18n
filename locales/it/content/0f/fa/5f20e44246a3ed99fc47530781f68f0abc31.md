# Introduzione

Un'espressione `if/elif/else` può essere usata per eseguire della logica in modo condizionale. F# ha anche un altro modo, più potente, per eseguire logica in modo condizionale: il pattern matching. Con il pattern matching, un valore può essere verificato rispetto a uno o più _pattern_. Un esempio di pattern è il _pattern costante_, che confronta un valore con una costante (ad esempio `1` o `"hello"`).

In F#, il pattern matching si realizza tramite la parola chiave `match`:

```fsharp
let describe number =
    match number with
    | 0 -> "Zero"
    | 1 -> "One"
```

Anche se può sembrare simile alle istruzioni `switch` di altri linguaggi, il pattern matching dà il meglio di sé quando si usano anche altri pattern. Uno di questi è il _pattern variabile_, che permette di catturare un valore:

```fsharp
match number with
| 0 -> "Zero"
| i -> sprintf "Non zero: %d" i
```

In alcuni casi, potresti voler aggiungere una condizione ulteriore a un pattern. Questa è nota come _guardia_ (clausola), e si può aggiungere usando la parola chiave `when`:

```fsharp
match number with
| 0 -> "Zero"
| i when i < 0 -> "Negative number"
```

Nell'esempio qui sopra, non tutti gli input possibili hanno un pattern corrispondente. Il compilatore lo rileva e produce un avviso. Questo è noto come _controllo di esaustività_. Per risolvere l'avviso, bisogna gestire tutti i casi. A questo scopo si può usare il _pattern jolly_, un pattern che corrisponde a qualsiasi valore:

```fsharp
match number with
| i when i < 0 -> "Negative number"
| _ -> "Positive number"

// No compiler warning
```

Il pattern matching verifica un valore rispetto a ogni pattern, dall'alto verso il basso, finché non trova un pattern corrispondente ed esegue la logica associata a quel pattern. L'ordine dei pattern è importante!
