La concatenazione di stringhe con l'operatore `+` è un approccio valido, ma può creare problemi di manutenzione e leggibilità.
Usare il metodo [str.format()][str.format()] o le [f-strings][f-strings] (_dette anche «stringhe letterali formattate» o «stringhe interpolate»_) può offrire opzioni che migliorano la manutenibilità e rendono più chiaro l'inserimento delle variabili all'interno delle stringhe.

Il post del blog [String Formatting in Python][string formatting in python] è un buon punto di partenza per capire tutte le opzioni di formattazione delle stringhe di Python, e [Newer Python String Format Techniques][newer python string format techniques] fornisce anche alcuni buoni consigli e trucchi per usare `str.format()` e le `f-strings`.
