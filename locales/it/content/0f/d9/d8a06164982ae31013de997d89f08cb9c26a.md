# Suggerimenti

## Generale

- Leggi la documentazione sugli [operatori di confronto][comparison-operators]
- Leggi la documentazione sull'[ordinamento degli array][list-sort]
- Ricorda come puoi [accedere ai record o applicare il pattern matching][records]

## 1. Confrontare i livelli di potenza

- Usa l'[operatore `(>)`][greater]

## 2. Trovare la potenza più alta

- Usa la [funzione `max`][max]

## 3. Ordinare le carte

- Usa la [funzione `List.sortBy`][sort-by]

## 4. Prima le carte più cool

- Usa le funzioni [`List.sortBy`][sort-by] o [`List.sortWith`][sort-with]
- Puoi usare le tuple per ordinamenti gerarchici

## 5. Potenza shiny

- Puoi definire esplicitamente un ordinamento oppure usare la [funzione `compare`][compare] con un valore specifico
- Puoi usare le tuple per ordinamenti gerarchici

## 6. Fai le tue puntate

- Usa `compareShinyPower` in `expectedWinner`
- Usa un `case` per [applicare il pattern matching sull'ordine][pattern-match]
