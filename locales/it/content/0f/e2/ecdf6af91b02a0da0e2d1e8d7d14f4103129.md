# Introduzione

Ricorda che un programma `jq` è una _pipeline di espressioni_.
**L'assegnazione di variabili** segue questa regola: un'_assegnazione di variabile_ è un'espressione che ha questa forma:

```jq
... | expr as $varname | ...
```

## Il filtro restituisce l'input

Come l'_espressione di identità_ `.`, l'output dell'_assegnazione di variabile_ è uguale al suo input.
Impostare il valore della variabile è un effetto collaterale.

Esempio: il `.` dopo l'assegnazione è uguale all'input iniziale.

```sh
$ jq -c -n '42 | (. * 2) as $double | [., $double]'
[42,84]
```

## Lo scope delle variabili

Lo scope di una variabile, cioè l'ambito (di visibilità), è «lessicale»: la variabile resterà nello scope per tutto il resto della pipeline.
Le variabili definite all'interno delle funzioni (arriveremo alle funzioni più avanti) sono «locali» alla funzione.

## Nomi delle variabili

La variabile deve iniziare con `$`.
Il resto del nome della variabile è un **identificatore**: inizia con una lettera o un underscore, seguito da lettere, numeri o underscore.

## Assegnazione destrutturante

Dal manuale:

> Più variabili possono essere dichiarate con un'unica espressione `as`, fornendo un pattern che _corrisponde alla struttura dell'input_ (questa tecnica è nota come «destrutturazione»).

Esempi:

```jq
[1, 2, 3] as [$a, $b, $c]
| [$a, $b, $c]     # => [1, 2, 3]
```

```jq
{"foo": "bar", "len": [10, 20]} as {foo: $f, len: [$h, $w]}
| [$f, $h, $w]     # => ["bar", 10, 20]
```

Far corrispondere il nome della variabile alla _chiave dell'oggetto_ offre una scorciatoia:

```jq
{"x": 4, "y": 7} as {$x, $y}
| [$x, $y]         # => [4, 7]
```

```jq
{"foo": "bar", "len": [10, 20]} as {$foo, $len}
| [$foo, $len]     # => ["bar", [10, 20]]
```

## Costanti

Come mostrato nell'esempio qui sopra, le variabili sono comode per memorizzare le costanti.
È meglio dare un nome alle costanti invece di far comparire «numeri magici» nel codice.

## Spesso le variabili non servono

Spesso è più leggibile omettere le variabili.

Consideriamo il calcolo della media di un array di numeri

```jq
[2, 4, 8, 7]
| add as $sum
| length as $len
| $sum / $len
```

rispetto a

```jq
[2, 4, 8, 7] | add / length
```

Questo mette in luce uno degli aspetti più potenti di `jq`: l'input di un filtro viene fornito ad _ogni_ sotto-espressione:

- l'array di input `[2,4,8,7]` viene passato ad `add` (che somma i numeri applicando l'operatore `+` a tutti gli elementi)
- _in parallelo_, `[2,4,8,7]` viene passato anche a `length`
- quando queste sotto-espressioni terminano, i loro risultati vengono divisi tra loro, restituendo il valore medio dei numeri dell'array di input.
