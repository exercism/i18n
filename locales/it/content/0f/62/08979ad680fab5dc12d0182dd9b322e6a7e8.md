# Appendice alle istruzioni

## Formato dell'input

Il parametro `board`, che rappresenta il tabellone di gioco, ha il formato di un array di stringhe.

```javascript
['  B  ', ' B B ', 'B W B', ' W W ', '  W  '];
```

Ogni carattere di una stringa rappresenta una cella.
I valori validi per una cella sono:

- ` ` uno spazio che corrisponde a una cella vuota
- `B` una cella di proprietà del giocatore nero
- `W` una cella di proprietà del giocatore bianco

## Formati dell'output

Ci si aspetta che la funzione `getTerritory` restituisca un oggetto con 2 proprietà:

- `owner` Il proprietario del territorio (`NONE`, `BLACK` o `WHITE`)
- `territory` Un array di coordinate che rappresenta ogni cella del territorio.

```javascript
{
    owner: 'BLACK',
    territory: [
        [0, 0],
        [0, 1],
        [1, 0],
    ],
}
```

Ci si aspetta che la funzione `getTerritories` restituisca un oggetto con 3 proprietà:

- `territoryBlack` Un array di coordinate che rappresenta i territori di proprietà del giocatore `BLACK`
- `territoryWhite` Un array di coordinate che rappresenta i territori di proprietà del giocatore `WHITE`
- `territoryNone` Un array di coordinate che rappresenta i territori che non appartengono a nessuno dei due giocatori

```javascript
{
    territoryBlack: [
        [0, 0],
        [0, 1],
    ],
    territoryWhite: [
        [3, 0],
        [3, 1],
    ],
    territoryNone: [],
}
```
