# Appendice alle istruzioni

## Note

Questo esercizio richiede di creare una struttura dati a lista concatenata che possa essere iterata.

1. Implementa la proprietà `Count`: non deve essere possibile modificarne il valore dall'esterno
2. Implementa il metodo `Push(T value)`, che aggiunge un valore in testa alla lista.
3. Implementa il metodo `Pop()`, che rimuove e restituisce un valore dalla testa.
4. Aggiungi un costruttore che permetta di inizializzare la lista con un solo valore o con un oggetto iterabile
5. Implementa l'interfaccia `IEnumerable<T>`. Per maggiori informazioni, vedi [questa pagina](https://docs.microsoft.com/en-us/dotnet/api/system.collections.generic.ienumerable-1).
6. Assicurati che il metodo `Reverse()` sia disponibile.
