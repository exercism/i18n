# Introduzione

Una funzione è un blocco di codice organizzato e riutilizzabile che serve a eseguire un'azione.
In JavaScript ci sono diversi modi per definire le funzioni.
Qui vedremo le _dichiarazioni di funzione_ e le _espressioni di funzione_.
Altre possibilità, come le [funzioni freccia][concept-arrow-functions], saranno trattate in altri concetti.

## Dichiarazione di funzione

Il modo standard per definire una funzione in JavaScript è la _dichiarazione di funzione_, chiamata anche _definizione di funzione_ o _istruzione di funzione_.

È composta dalla parola chiave `function`, dal nome della funzione e da un elenco di parametri separati da virgole tra parentesi tonde (`()`).
Segue il corpo della funzione (l'insieme di istruzioni che definisce cosa fa la funzione) racchiuso tra parentesi graffe (`{}`).

```javascript
function someName(param1, param2, param3) {
  // ...
}
```

In JavaScript, per chiamare una funzione si scrive il nome della funzione seguito da una coppia di parentesi che contengono gli argomenti.

```javascript
someName(arg1, arg2, arg3);
```

## Parametri

Quando lavori con i parametri all'interno del corpo della funzione, tieni presente i possibili effetti collaterali.

- I valori dei [tipi di dati primitivi][mdn-primitives] sono _immutabili_.
  Il valore originale non viene mai modificato da ciò che accade all'argomento nel corpo della funzione.
- Per tutti gli altri valori (oggetti, array, funzioni), una riassegnazione non modifica il valore originale.
  Se però modifichi un argomento di questo tipo (ad esempio aggiungi una chiave a un oggetto), modifichi anche il valore originale che è stato passato.

Per impostazione predefinita, in JavaScript tutti i parametri definiti nella dichiarazione di funzione sono opzionali.
Se fornisci meno argomenti di quanti sono i parametri, gli argomenti mancanti saranno `undefined` all'interno della funzione, vedi [Null e Undefined][concept-null-undefined].
In molti casi ha senso assegnare un valore predefinito più adatto di `undefined`.
Puoi farlo specificando i parametri predefiniti direttamente nella definizione della funzione.

```javascript
function someName(param1 = defaultValue1, param2 = defaultValue2) {
  // ...
}
```

## L'istruzione return

Un'istruzione `return` termina l'esecuzione della funzione e specifica un valore da restituire a chi ha chiamato la funzione. Una funzione può avere più istruzioni `return`.

```javascript
function checkNumber(num) {
  if (num === 0) {
    return 'You passed 0, please provide another number.';
  }

  return 'Thanks for passing such a nice number.';
}
```

Il valore restituito da una funzione può essere memorizzato in una variabile.

```javascript
function sum(x, y) {
  return x + y;
}

const total = sum(5, 10);
// => 15
```

Il risultato di una funzione che non restituisce alcun valore o che non ha un'istruzione `return` è `undefined`.
In JavaScript non esistono `return` impliciti.

```javascript
function nakedReturn(a) {
  a * 2;
  return;
}

nakedReturn(1);
// => undefined

function noReturn(a) {
  a * 2;
}

noReturn(1);
// => undefined
```

In JavaScript puoi restituire esattamente un solo valore.
Se vuoi passare più informazioni, devi prima combinarle in un'unica entità, di solito in un [oggetto][concept-objects] o in un [array][concept-arrays].

```javascript
function divide(a, b) {
  return {
    quotient: Math.floor(a / b),
    remainder: a % b,
  };
}
```

## Espressione di funzione

Una dichiarazione di funzione è un'istruzione a sé stante.
A volte però è utile definire una funzione come parte di un'altra espressione, ad esempio in un'assegnazione, come parametro di una funzione ([callback][concept-callbacks]) o come valore in un [oggetto][concept-objects].
Questo si può fare con un'espressione di funzione.
Ha la stessa sintassi di una dichiarazione di funzione, con la sola differenza che il nome della funzione può essere omesso per creare una _funzione anonima_.

```javascript
const someFunction = function (param) {
  // ...
};

someOtherFunction(function (param) {
  // ...
});

const obj = {
  someFunction: function (param) {
    // ...
  },
};
```
