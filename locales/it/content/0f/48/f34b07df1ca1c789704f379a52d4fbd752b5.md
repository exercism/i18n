# Installazione

## Quale awk ho?

Il track AWK di Exercism usa `gawk`, l'AWK di GNU.
Potresti già averlo; per verificare, esegui questo comando
```sh
awk --version
```

Se ottieni:

* qualcosa tipo `GNU Awk 5.1.0 ...`
    - Hai già GNU awk e puoi proseguire con gli esercizi.

* qualcosa tipo `awk version 20200816`
    - Questo è `nawk`, noto anche come BWK awk (da Brian Kernighan) o «one true awk».
    - È quello che viene fornito con MacOS e i sistemi BSD.
    - Leggi più avanti per le istruzioni di installazione.

* l'errore `awk: not an option: --version`
    - Probabilmente hai `mawk`.
    - Conferma con: `awk -W version`, che potrebbe restituire `mawk 1.3.4 20200120`.
    - mawk è un'implementazione di awk molto buona e veloce, ma non ha alcune delle funzionalità specifiche di gawk che useremo nel track.
    - Leggi più avanti per le istruzioni di installazione.

* l'errore `awk: unrecognized option: version` seguito da `BusyBox v1.35.0 ...`
    - Potresti usare Alpine Linux.
    - Leggi più avanti per le istruzioni di installazione.

* un errore "command not found"
    - Allora o il tuo PATH è configurato male o semplicemente non hai awk installato.
    - Leggi più avanti per le istruzioni di installazione.

### Linux

Dipende dal gestore di pacchetti della tua distribuzione. Tipicamente:
```sh
apt install gawk
yum install gawk
apk add gawk
# and so on
```
Potresti dover usare `sudo` per eseguire il comando appropriato.

### MacOS

[Homebrew][brew] è tuo amico. Segui il link per installarlo e poi esegui:
```sh
brew install gawk
```

### Windows

Per [WSL][wsl], vedi le istruzioni per Linux qui sopra.
Per cygwin, installa il pacchetto `gawk`.

### Compilare dai sorgenti

Per i coraggiosi, le istruzioni sono [disponibili nel manuale di `gawk`][build].
