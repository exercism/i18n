# Introduzione

JavaScript è un linguaggio dinamico, che supporta stili orientati agli oggetti, imperativi e dichiarativi (ad esempio la programmazione funzionale).

## (Ri)assegnazione

In JavaScript ci sono alcuni modi principali per assegnare valori ai nomi: usando variabili o costanti. Su Exercism, le variabili si scrivono sempre in [camelCase][wiki-camel-case]; le costanti in [SCREAMING_SNAKE_CASE][wiki-snake-case]. Non esiste una guida ufficiale da seguire e aziende e organizzazioni diverse hanno stili di scrittura diversi. _Sentiti libero di scrivere le variabili come preferisci_. Il vantaggio di scriverle come sono preparati gli esercizi è che verranno evidenziate in modo diverso nell'interfaccia web e nella maggior parte degli IDE.

Le variabili in JavaScript si possono definire usando la parola chiave [`const`][mdn-const], [`let`][mdn-let] o [`var`][mdn-var].

Una variabile può riferirsi a valori diversi nel corso della sua vita quando si usano `let` o `var`. Ad esempio, `myFirstVariable` può essere definita e ridefinita molte volte usando l'operatore di assegnazione `=`:

```javascript
let myFirstVariable = 1
myFirstVariable = 'Some string'
myFirstVariable = new SomeComplexClass()
```

A differenza di `let` e `var`, le variabili definite con `const` possono essere assegnate una sola volta. In JavaScript questo si usa per definire le costanti.

```javascript
const MY_FIRST_CONSTANT = 10

// Can not be re-assigned.
MY_FIRST_CONSTANT = 20
// => TypeError: Assignment to constant variable.
```

> 💡 In un esercizio di concetto successivo esploreremo e spiegheremo la differenza tra l'assegnazione (o il binding) di una _costante_ e il _valore_ di una costante.

## Dichiarazioni di funzione

In JavaScript, le unità di funzionalità sono incapsulate nelle _funzioni_; di solito le funzioni che stanno insieme vengono raggruppate nello stesso file. Queste funzioni possono ricevere parametri (argomenti) e possono _restituire_ un valore usando la parola chiave `return`. Le funzioni si chiamano usando la sintassi `()`.

```javascript
function add(num1, num2) {
  return num1 + num2
}

add(1, 3)
// => 4
```

> 💡 In JavaScript ci sono _molti_ modi diversi per dichiarare una funzione. Questi altri modi sono diversi dall'uso della parola chiave `function`. La track cerca di introdurli gradualmente, ma se li conosci già, sentiti libero di usarne uno qualsiasi. Nella maggior parte dei casi, usare l'uno o l'altro non è né meglio né peggio.

## Rendere disponibile ad altri file

Per rendere disponibile in _altri file_ una `function`, una costante o una variabile, bisogna [esportarle][mdn-export] usando la parola chiave `export`. Un altro file può quindi [importarle][mdn-import] usando la parola chiave `import`. Questo è anche noto come sistema di moduli. Un ottimo esempio è come funzionano tutti i test. Ogni esercizio ha almeno un file, ad esempio `lasagna.js`, che contiene l'_implementazione_. Inoltre c'è almeno un altro file, ad esempio `lasagna.spec.js`, che contiene i _test_. Questo file _importa_ le entità pubbliche (cioè esportate) per testare l'implementazione:

```javascript
// file.js
export const MY_VALUE = 10

export function add(num1, num2) {
  return num1 + num2
}

// file.spec.js
import { MY_VALUE, add } from './file'

add(MY_VALUE, 5)
// => 15
```
