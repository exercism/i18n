# Introduzione

In Common Lisp le stringhe sono [vettori][concept-vectors] di [caratteri][concept-characters]. Si scrivono come caratteri racchiusi tra doppi apici (per esempio "Hello World!").

Il predicato `stringp` restituisce vero solo se il valore dato è una stringa.

Le stringhe si possono dividere in sottostringhe con la funzione `subseq`, che prende in input la stringa, un indice di inizio e, facoltativamente, un indice di fine. Gli indici partono da zero.

```lisp
(subseq "Hello World" 1 5)   ; => "ello"
(subseq "skip to the end" 5) ; => "to the end"
```

Le stringhe si possono confrontare per uguaglianza con `string=`.
Se le maiuscole e le minuscole dei caratteri vanno ignorate, si può usare `string-equal`.

```lisp
(string= "macaroni" "macaroni")      ; => T
(string= "macaroni" "MACARONI")      ; => NIL
(string-equal "macaroni" "MACARONI") ; => T
```

Per convertire una stringa in maiuscolo o in minuscolo, o per capitalizzarla, si possono usare `string-upcase`, `string-downcase` e `string-capitalize`.

```lisp
(string-upcase "not too loud")                ; => "NOT TOO LOUD"
(string-downcase "YELL IT FROM THE ROOFTOPS") ; => "yell it from the rooftops"
(string-capitalize "practical COMMON LiSP")   ; => "Practical Common Lisp"
```
