# Informazioni

`reduce` è il fold generale di Factor: percorre una sequenza, facendo passare un accumulatore attraverso una quotation binaria che prende l'accumulatore corrente e l'elemento successivo e produce il nuovo accumulatore.

```
reduce ( seq init quot: ( prev elt -- next ) -- result )
```

```factor
USING: math sequences ;

{ 1 2 3 4 } 0 [ + ] reduce .         ! => 10
{ 1 2 3 4 } 1 [ * ] reduce .         ! => 24
```

Un valore iniziale personalizzato permette a `reduce` di esprimere fold che `sum` o `product` non riescono a esprimere. Per esempio, il valore più grande di una sequenza, con un valore predefinito se ogni elemento perde:

```factor
USING: math.order ;

{ 3 1 -4 5 -2 } 0 [ max ] reduce .   ! => 5
{ -3 -1 -4 }    0 [ max ] reduce .   ! => 0
```

Il valore iniziale `0` partecipa al confronto, quindi una sequenza tutta negativa produce comunque `0` invece del suo valore più piccolo.

## `produce`: l'unfold

Il duale di `reduce` è `produce` (in [`sequences`][sequences]): dove `reduce` *consuma* una sequenza, `produce` ne *genera* una. Una quotation di predicato verifica lo stato corrente; finché restituisce un valore vero, una quotation di corpo produce l'elemento successivo.

```
produce ( pred quot -- seq )
```

Usati insieme, `reduce` e `produce` formano la coppia fold/unfold di Factor.

## Riduzioni cumulative

La famiglia cumulativa in [`math.statistics`][math.statistics] restituisce una sequenza della stessa lunghezza dell'input, in cui ogni elemento è la riduzione del prefisso fino a quella posizione inclusa:

| word          | operazione progressiva |
|---------------|------------------------|
| `cum-sum`     | totale progressivo     |
| `cum-product` | prodotto progressivo   |
| `cum-min`     | minimo progressivo     |
| `cum-max`     | massimo progressivo    |

```factor
USING: math.statistics ;

{ 3 1 4 1 5 9 2 6 } cum-sum .         ! => { 3 4 8 9 14 23 25 31 }
{ 3 1 4 1 5 9 2 6 } cum-min .         ! => { 3 1 1 1 1 1 1 1 }
{ 3 1 4 1 5 9 2 6 } cum-max .         ! => { 3 3 4 4 5 9 9 9 }
```

Le riduzioni cumulative sono utili quando vuoi ispezionare *come* una quantità si è evoluta lungo la sequenza, non solo il suo valore finale. Anche concatenarle è utile: l'output di una cumulativa è a sua volta una sequenza, pronta per essere passata a un'altra.

[sequences]: https://docs.factorcode.org/content/vocab-sequences.html
