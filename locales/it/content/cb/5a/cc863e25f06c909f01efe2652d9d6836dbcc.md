# Istruzioni

Da appassionato di scacchi, vuoi scrivere la tua versione del gioco.
Sì, online esistono già tante implementazioni degli scacchi, ma la tua sarà unica!

Inizierai implementando una scacchiera.

La partita si giocherà su una scacchiera larga otto caselle e lunga otto caselle.
Le caselle sono identificate da una lettera ed un numero.

## 1. Definisci l'intervallo di rank e file

Il gioco dovrà memorizzare i rank della scacchiera.
I rank sono le righe della scacchiera e sono numerati da 1 a 8.

Il gioco dovrà anche memorizzare i file della scacchiera.
I file sono le colonne della scacchiera e sono identificati dalle lettere dalla A alla H.

Definisci le costanti `ranks` e `files` che memorizzano rispettivamente l'intervallo dei rank e dei file.

```swift
ranks
// Returns 1..8

files
// Returns "A".."H"
```

## 2. Controlla se una casella è valida

Il gioco dovrà controllare se una casella è valida.
Una casella è valida se il rank ed il file rientrano negli intervalli dei rank e dei file.

Definisci il metodo `isValidSquare(rank:file:)` che accetta gli argomenti `rank`, che contiene un `Int` con il rank, e `file`, che contiene una `String` con il file.
Il metodo deve restituire `true` se il rank ed il file rientrano nell'intervallo dei rank e dei file, altrimenti deve restituire `false`.

```swift
isValidSquare(rank: 1, file: "A")
// Returns true
```

## 3. Ottieni la riga

Il gioco memorizzerà tutte le caselle della scacchiera in un array monodimensionale.
Le caselle sono formate da una stringa composta da rank e file, ad esempio "1A", "8B", "4G", ecc.
Per ottenere la riga di una casella, il gioco dovrà calcolare l'indice della prima casella della riga.

Definisci il metodo `getRow(rank:)` che accetta l'argomento `rank`, che contiene un `Int` con il rank.
Il metodo deve restituire un array di stringhe che rappresentano le caselle della riga.

```swift
let board = ["1A", "1B", "1C", "1D", "1E", "1F", "1G", "1H", "2A", ..., "8H"]
getRow(board, rank: 1)
// Returns ["1A", "1B", "1C", "1D", "1E", "1F", "1G", "1H"]
```
