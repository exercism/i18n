# Istruzioni

In questo esercizio creerai alcune costanti da usare nel funzionamento di una banca.

Hai cinque attività:

## 1. Rappresenta il tasso di interesse fisso su un prestito

Crea la costante numerica non tipizzata `FixedInterestRate` con il valore del 5% (5/100), poi implementa la funzione `GetFixedInterestRate` che la restituisce:

```go
GetFixedInterestRate()
// => 0.05
```

## 2. Rappresenta il numero di giorni in un anno

Crea la costante `DaysPerYear` di tipo `int` con il valore 365, poi implementa la funzione `GetDaysPerYear` che la restituisce:

```go
GetDaysPerYear()
// => 365
```

## 3. Rappresenta i mesi dell'anno

In un blocco, usa l'enumeratore di Go per creare dodici costanti numeriche non tipizzate con i valori da 1 a 12 per i mesi dell'anno.
Assegna loro i nomi `Jan`, `Feb`, `Mar`, ecc., poi implementa la funzione `GetMonth` che restituisce il valore per un dato mese:

```go
GetMonth(Jan)
// => 1
```

## 4. Rappresenta un numero di conto

Crea la costante stringa non tipizzata `AccountNo` con il valore XF348IJ, poi implementa la funzione `GetAccountNumber` che la restituisce:

```go
GetAccountNumber()
// => "XF348IJ"
```
