# Evitare di restituire valori booleani letterali

Invece di restituire valori booleani letterali dopo una condizione, puoi restituire direttamente la condizione stessa.

Esempio:

```java
// instead of
if (someExpression) {
  return true;
} else {
  return false;
}

// ... return the expression directly
return someExpression;
```
