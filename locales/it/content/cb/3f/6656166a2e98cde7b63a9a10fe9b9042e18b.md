# Istruzioni

In questo esercizio giocherai con un'auto radiocomandata, che finalmente hai risparmiato abbastanza soldi per comprare.

Le auto partono con la batteria completamente carica (100%). Ogni volta che guidi l'auto con il radiocomando, percorre 20 metri e consuma l'uno per cento della batteria.

L'auto radiocomandata ha un sofisticato display a LED che mostra due informazioni:

- La distanza totale percorsa, mostrata come: `"Driven <METERS> meters"`.
- La carica residua della batteria, mostrata come: `"Battery at <PERCENTAGE>%"`.

Se la batteria è allo 0%, non puoi più guidare l'auto e il display della batteria mostrerà `"Battery empty"`.

Hai sei attività, ognuna delle quali lavorerà con istanze di auto radiocomandata.

## 1. Compra un'auto radiocomandata nuova di zecca

Implementa il metodo (_statico_) `JedliksToyCar.buy()` in modo che restituisca un'istanza nuova di zecca di auto radiocomandata:

```java
JedliksToyCar car = JedliksToyCar.buy();
```

## 2. Mostra la distanza percorsa

Implementa il metodo `JedliksToyCar.distanceDisplay()` in modo che restituisca la distanza così come viene mostrata sul display a LED:

```java
JedliksToyCar car = JedliksToyCar.buy();
car.distanceDisplay();
// => "Driven 0 meters"
```

## 3. Mostra la percentuale della batteria

Implementa il metodo `JedliksToyCar.batteryDisplay()` in modo che restituisca la percentuale della batteria così come viene mostrata sul display a LED:

```java
JedliksToyCar car = JedliksToyCar.buy();
car.batteryDisplay();
// => "Battery at 100%"
```

## 4. Aggiorna il numero di metri percorsi quando guidi

Implementa il metodo `JedliksToyCar.drive()` che aggiorna il numero di metri percorsi:

```java
JedliksToyCar car = JedliksToyCar.buy();
car.drive();
car.drive();
car.distanceDisplay();
// => "Driven 40 meters"
```

## 5. Aggiorna la percentuale della batteria quando guidi

Aggiorna il metodo `JedliksToyCar.drive()` in modo che aggiorni la percentuale della batteria:

```java
JedliksToyCar car = JedliksToyCar.buy();
car.drive();
car.drive();
car.batteryDisplay();
// => "Battery at 98%"
```

## 6. Impedisci di guidare quando la batteria è scarica

Aggiorna il metodo `JedliksToyCar.drive()` in modo che non aumenti la distanza percorsa né diminuisca la percentuale della batteria quando la batteria è scarica (allo 0%):

```java
JedliksToyCar car = JedliksToyCar.buy();

// Drain the battery
// ...

car.distanceDisplay();
// => "Driven 2000 meters"

car.batteryDisplay();
// => "Battery empty"
```
