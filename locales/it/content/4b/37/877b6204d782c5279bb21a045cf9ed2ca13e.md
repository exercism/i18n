# Introduzione

## I booleani in Julia

I valori vero o falso sono rappresentati dal tipo `Bool`.
Contiene solo due valori: `true` e `false`.

```julia-repl
julia> true
true

julia> false
false
```

## Operatori booleani

Ci sono tre operatori booleani in Julia.

`&&` è l'operatore booleano «and».
Restituisce `true` se le espressioni su *entrambi* i lati di `&&` sono `true`.

```julia-repl
julia> true && true
true

julia> true && false
false
```

`||` è l'operatore booleano «or».
Restituisce `true` se un'espressione su *uno dei due* lati di `||` è `true`.

```julia-repl
julia> true || true
true

julia> false || true
true
```

`!` è l'operatore booleano «not».
Scambia i valori `true` e `false`.

```julia-repl
julia> !true
false

julia> !false
true
```

Per espressioni più lunghe e complicate, è meglio usare le parentesi tonde per rendere chiara la tua intenzione.

```julia-repl
julia> (true || false) && (false && true)
false
```
