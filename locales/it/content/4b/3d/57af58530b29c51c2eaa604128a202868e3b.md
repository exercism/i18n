# Istruzioni

Inizializzerai dei buffer vuoti ed elencherai i primi cinque numeri, o elementi, della sequenza di Fibonacci.

La sequenza di Fibonacci è un insieme di numeri in cui l'elemento successivo è la somma dei due precedenti. Iniziamo la sequenza da uno. Quindi i primi due elementi sono 1 e 1.

## 1. Crea un buffer di `count` zeri.

Crea una funzione che crea un buffer di `count` zeri.

```rust
let my_buffer = create_buffer(5);
// [0, 0, 0, 0, 0]
```

## 2. Elenca i primi cinque elementi della sequenza di Fibonacci

Crea una funzione che restituisce i primi cinque numeri della sequenza di Fibonacci.
I suoi primi cinque elementi sono `1, 1, 2, 3, 5`

```rust
let first_five = fibonacci();
// [1, 1, 2, 3, 5]
```
