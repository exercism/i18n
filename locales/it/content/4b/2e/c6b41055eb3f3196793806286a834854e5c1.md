# Mettere in pausa i contributi della community

Alcuni repository non hanno le risorse per fare triage o revisionare issue e pull request degli utenti che non sono maintainer.
La pausa delle soluzioni della community
Se un repository ha abilitato questo workflow, commenterà automaticamente una issue o una pull request appena aperta se l'autore _non_ è membro dell'organizzazione GitHub di Exercism.
Il commento suggerirà all'utente di aprire prima un argomento sul forum di Exercism.

## Abilitare il workflow

Aggiungi nel tuo repository il file [.github/workflows/pause-community-contributions.yml](https://github.com/exercism/github-actions/blob/b5424c17f661f5529493258a1ad480013351aa9e/.github/workflows/pause-community-contributions.yml).

## Disabilitare il workflow

Rimuovi il file del workflow dal tuo repository.

## Fonte

Il workflow è definito nel file `.github/workflows/pause-community-contributions.yml`.
