# Informazioni

PHP mette a disposizione diversi operatori per eseguire operazioni aritmetiche. Per i suoi operatori aritmetici, PHP segue l'ordine delle operazioni matematiche standard. Gli operatori forniti da PHP sono:

* Identità (+)
* Negazione (-)
* Addizione (+)
* Sottrazione (-)
* Moltiplicazione (*)
* Divisione (/)
* Modulo (%)
* Esponenziazione (**)

Diamo un'occhiata a ognuno di essi e a come possono essere usati:

## Identità (+)

L'operatore di identità (+) lavora su un singolo valore (operatore unario). Restituisce il valore `float` o `int` della variabile.

```php
$value = '42';
$answer = +$value; // 42 (int)
```

## Negazione (-)

L'operatore di negazione lavora su un singolo valore (operatore unario) e restituisce l'opposto del valore numerico.

```php
$forward = 65;
$reverse = -$forward; // -65
```

## Addizione (+) e sottrazione (-)

L'operatore di addizione somma i due valori che si trovano ai suoi lati, mentre l'operatore di sottrazione sottrae il valore di destra da quello di sinistra.

```php
$apples = 5;
$yourApples = 0;

$apples = $apples - 2; // 3
$yourApples = $yourApples + 2; 2
```

## Divisione (/)

L'operatore di divisione dà il risultato della divisione del valore di sinistra per il valore di destra. Se il valore di destra è 0, provoca un errore `DivisionByZeroError`.

```php
$slicesOfPizza = 8;
$people = 4;
$slicesPerPerson = $slicesOfPizza / $people; // 2
```

## Moltiplicazione (*)

L'operatore di moltiplicazione restituisce il risultato della moltiplicazione tra il valore di sinistra e quello di destra.

```php
$tires = 4;
$priceOfTire = 250;
$totalCost = $tires * $priceOfTire; // 1000
```

## Modulo (%)

L'operatore modulo restituisce il resto della divisione del valore di sinistra per il valore di destra. Questo operatore è molto utile per determinare se un numero divide esattamente un altro, per stabilire se un valore è pari o dispari e molto altro ancora.

```php
$value = 3;
$isOdd = $value % 2;
if ($isOdd === 1) {
    echo 'Yes, it is odd!';
} else {
    echo 'It is even.';
}
```

## Esponenziazione (**)

L'operatore di esponenziazione serve a elevare il valore di sinistra alla potenza del valore di destra. Prima di PHP 5.6 bisognava usare la funzione `pow` per ottenere lo stesso risultato.

```php
$sideLength = 13;
$areaOfSquare = $sideLength ** 2; // 169
```

L'operatore di esponenziazione supporta numeri interi e numeri in virgola mobile su entrambi i lati, quindi puoi usarlo per calcolare radici quadrate (o altre radici) o valori esponenziali più complessi.

```php
$squareArea = 144;
$side = $squareArea ** .5; // 12
```

## Ordine delle operazioni

PHP segue l'ordine delle operazioni matematiche standard. Questo significa che, invece di eseguire le operazioni da sinistra a destra, ogni operatore ha una precedenza e le operazioni vengono risolte in base alla loro precedenza. L'ordine delle operazioni è:

* parentesi
* esponenziazione
* moltiplicazione, divisione
* addizione, sottrazione

La moltiplicazione e la divisione hanno lo stesso livello di precedenza. Allo stesso modo, l'addizione e la sottrazione hanno lo stesso livello di precedenza.

Questo significa che il valore qui sotto sarebbe 17 invece di 10, dato che la moltiplicazione ha una precedenza maggiore dell'addizione:

```php
$value = 2 + 3 * 5;
```

PHP fornisce anche diversi utili operatori di assegnazione che combinano gli operatori aritmetici con l'assegnazione, quando esegui un'operazione su una variabile e riassegni il risultato alla variabile stessa. Saranno trattati nel concetto `Assignment Operators`.
