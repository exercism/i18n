# Installazione

## Utenti Windows

Installa il [Windows Subsystem for Linux][wsl-link] e passa alla sezione successiva.

## Utenti Linux/Mac

### Installare con brew

Questo è il modo più semplice per installare Chapel.
Ti darà un'installazione di base funzionante, adatta per affrontare il track di Exercism.
Gli utenti più esperti potrebbero invece voler compilare Chapel dal codice sorgente (sezione successiva).

0. Se non l'hai ancora fatto, installa il gestore di pacchetti [brew][brew-link].
1. Per prima cosa, assicurati che brew sia aggiornato eseguendo `brew update`
2. Installa Chapel eseguendo `brew install chapel`
3. Verifica che l'installazione sia andata a buon fine eseguendo `chpl --version`

Questo installerà il compilatore Chapel (`chpl`), il gestore di pacchetti `mason`, che useremo per eseguire i test, e lo strumento di generazione della documentazione `chpldoc`. Quest'ultimo non serve per Exercism, ma è utile averlo se (anzi, quando :) ) vuoi sviluppare le tue librerie in Chapel.

### Compilare Chapel dal codice sorgente

Gli utenti più esperti potrebbero voler compilare Chapel dal codice sorgente da soli. Per farlo,

1. Installa i [prerequisiti][prereqs-link]
2. [Scarica][download-link] l'archivio dell'ultima versione di Chapel e scompattalo.
3. Per prima cosa, devi preparare l'installazione e configurare il punto in cui vuoi installare Chapel.
Puoi farlo eseguendo lo script `configure` fornito.
Eseguendo semplicemente

```
./configure
```

installerai binari, librerie e file condivisi in `/usr/local/`; puoi cambiare questa posizione usando l'opzione `--prefix`.
Per esempio, se vuoi installare Chapel in `~/.chapel` puoi fare

```
./configure --prefix=~/.chapel
```

4. Per installare il compilatore e gli strumenti, esegui

```
make
make mason
make chpldoc
make install
```

5. Assicurati che la cartella `/dir/for/install/bin` sia nella tua variabile `PATH`.

Per maggiori informazioni sui diversi modi di installare Chapel e lavorare dal codice sorgente, vedi la pagina [Compilare Chapel][building-link] nella documentazione.
