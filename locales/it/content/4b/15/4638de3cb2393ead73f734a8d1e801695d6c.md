# Informazioni sulla conversione di tipo

Go richiede una conversione esplicita tra tipi diversi.
Per esempio, questo causa un errore di compilazione:

```go
var x int = 42
var f float64 = x // compiler error x is an int not a float64
```

La conversione tra tipi (nota anche come **type casting**) si fa tramite una funzione che porta il nome del tipo in cui convertire.
Un valore `v` viene convertito nel tipo `T` usando `T(v)`.
Per esempio, per convertire un `int` in un `float64` devi fare così:

```go
var x int = 42 // x has type int
f := float64(x) // f has type float64 (ie. 42.0)
```

Lo stesso vale per qualsiasi tipo personalizzato:

```go
type Id int
var number int = 121 // number has type int
userId := Id(number) // userId now has type Id
```

## Convertire tra tipi primitivi e stringhe

Esiste un pacchetto `strconv` per convertire tra tipi primitivi (come `int`) e `string`.

```go
import "strconv"

var intString string = "42"
var i, err = strconv.Atoi(intString)

var number int = 12
var s string = strconv.Itoa(number)
```

ATTENZIONE: usare il metodo di casting standard non ha questo comportamento.
Per esempio:

```go
var num int = 65
str := string(num) // str is now "A" not "65"
```

Ecco alcuni degli altri metodi di conversione più comuni:

| Metodo      | Scopo                       |
| ----------- | --------------------------- |
| ParseBool   | Convertire `string` in `bool`  |
| FormatBool  | Convertire `bool` in `string`  |
| ParseFloat  | Convertire `string` in `float` |
| FormatFloat | Convertire `float` in `string` |
| ParseInt    | Convertire `string` in `int`   |
| FormatInt   | Convertire `int` in `string`   |
