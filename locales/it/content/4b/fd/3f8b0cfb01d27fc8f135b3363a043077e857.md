# Introduzione

## Vero e falso

Gli stati logici vero e falso sono rappresentati con `true` e `false` in Ruby.

```ruby
happy = true
sad = false
```

## Uguaglianza e confronto

Ruby ti permette di confrontare gli oggetti tra loro usando i normali simboli di uguaglianza:
- Usa `==` per verificare se due oggetti sono uguali
- Usa `>` per verificare se l'oggetto a sinistra è **maggiore di** quello a destra
- Usa `<` per verificare se l'oggetto a sinistra è **minore di** quello a destra.
- Usa `>=` o `<=` per verificare rispettivamente «maggiore o uguale a» e «minore o uguale a».

Puoi anche usare la logica booleana con i normali operatori:
- Usa `&&` o `and` per verificare se `x and y` sono veri
- Usa `||` o `or` per verificare se `x or y` è vero.
- Usa `!` o `not` per invertire l'uguaglianza, ad esempio `x != y` (x non è uguale a y)

Ecco alcuni esempi:
```ruby
# Is "true equal to false"? 
true == false # false

# Is "true not equal to false"
true != false # true

# Is 5 greater than 4?
5 > 4 # true

# Is 3 less than or equal to 2?
3 <= 2 # false
```
