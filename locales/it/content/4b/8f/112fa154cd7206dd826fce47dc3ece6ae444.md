# Informazioni

Le strutture dati che possono contenere zero o più elementi sono note come _collezioni_.
Un **array** in Ruby è una collezione che mantiene l'ordine in cui i suoi oggetti vengono aggiunti.
Gli array possono contenere qualsiasi oggetto.
Gli oggetti possono essere aggiunti a un array o recuperati da esso tramite un indice.
L'indicizzazione degli array in Ruby parte da zero, il che significa che l'indice del primo elemento è sempre zero:

```ruby
# Declare an array containing two values
two_ints = [1,2]

# Assign first and second element by index
two_ints[0] = 7
two_ints[1] = 8

# Retrieve the second element by index
two_ints[1] # => 8

# Check the length of the array
two_ints.size # => 2
```

In Ruby ci sono diversi modi per creare un array:

- Usare il costruttore letterale `[]` _(il più comune)_
- Chiamare esplicitamente `Array.new`
- Chiamare il metodo `Array()` di Kernel

Il metodo `Array.new` supporta due argomenti opzionali: la dimensione iniziale dell'array e un oggetto predefinito.

Quando vengono forniti una dimensione e un oggetto predefinito, l'array viene popolato con `size` copie dell'oggetto predefinito.

```ruby
a = Array.new(2, Hash.new)
# => [{}, {}]
```

Poiché tutti gli elementi dell'array memorizzano lo stesso hash, le modifiche a uno di essi influenzeranno tutti gli altri.

```ruby
a[0]['cat'] = 'feline'
a # => [{"cat"=>"feline"}, {"cat"=>"feline"}]

a[1]['cat'] = 'Felix'
a # => [{"cat"=>"Felix"}, {"cat"=>"Felix"}]
```

Se vuoi più copie, dovresti usare la versione con blocco, che usa il risultato di quel blocco ogni volta che un elemento dell'array deve essere inizializzato:

```ruby
a = Array.new(2) {Hash.new}
a[0]['cat'] = 'feline'
a # => [{"cat"=>"feline"}, {}]
```

Un'altra caratteristica degli array Ruby è che includono il modulo [Enumerable][enumerable-module], che aggiunge molti metodi utili per iterare, cercare, ordinare, filtrare, ecc. gli elementi di un array.
