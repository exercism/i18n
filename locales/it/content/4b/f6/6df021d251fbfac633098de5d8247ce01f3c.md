# Parametri variadici

I [_parametri variadici_][variadic-parameters] in Swift permettono di passare zero o più valori dello stesso tipo a un singolo parametro di una funzione.
Si indica aggiungendo `...` all'annotazione di tipo del parametro.

Questi valori vengono raggruppati automaticamente in un array con elementi dello stesso tipo del parametro variadico.

```swift
func geometricMean(_ numbers: Double...) -> Double {
  var total = 1.0
  for number in numbers {
      total *= number
  }
  return pow(total, 1.0 / Double(numbers.count))
}

geometricMean(1, 2, 3, 4, 5)
// Returns 2.605171084697352
```

Quando si usano i parametri variadici, Swift ha due limitazioni:

1. Swift permette alle funzioni di avere un solo parametro variadico. È stato deciso che questa restrizione sarà rimossa in una versione futura di Swift, ma al momento è ancora in vigore.
2. Se una funzione ha parametri che seguono il parametro variadico nella definizione, il primo parametro che segue il parametro variadico _deve_ avere un'etichetta di argomento.

[variadic-parameters]: https://docs.swift.org/swift-book/documentation/the-swift-programming-language/functions/#Variadic-Parameters
