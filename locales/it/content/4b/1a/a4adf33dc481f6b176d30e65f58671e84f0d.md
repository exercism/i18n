# Appendice alle istruzioni

## Aggiungere un metodo allo struct `Int`

In questo esercizio aggiungeremo dei metodi allo struct `Int` di Crystal.
Per farlo, dovrai definire uno struct con il nome `Int`.
Il metodo va inserito al suo interno.

```crystal
struct Int
  # your solution here
end
```

Il codice sorgente della classe `Int` si trova [qui][int].
