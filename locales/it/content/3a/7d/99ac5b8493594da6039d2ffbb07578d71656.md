# Appendice alle istruzioni

## Registri

| Registro | Uso        | Tipo      | Descrizione                                |
| -------- | ---------- | --------- | ------------------------------------------ |
| `$a0`    | input      | indirizzo | colore come stringa con terminazione null  |
| `$v0`    | output     | intero    | valore della resistenza                    |
| `$t0-9`  | temporaneo | qualsiasi | per l'archiviazione temporanea             |
