# Introduzione

In C++, i booleani sono rappresentati dal tipo `bool`.
Un `bool` è `true` oppure `false`.

## Operatori logici

C++ supporta tre operatori booleani: `!` (NOT), `&&` (AND) e `||` (OR).
Puoi anche usare le versioni alternative `not`, `and` e `or`.

```cpp
true || false // => true
true && false // => false
!true // => false
not false // => true
```

## Precedenza

I tre operatori booleani hanno ciascuno una diversa _precedenza tra operatori_.
Di conseguenza, vengono valutati in quest'ordine: prima `!`, poi `&&` e infine `||`.
Se vuoi forzare un ordine diverso, puoi racchiudere un'espressione booleana tra parentesi tonde (cioè `()`), dato che le parentesi hanno una precedenza tra operatori ancora più alta.

```cpp
!true && false   // => false
!(true and false) // => true
```

## Conversione

Se usi `true` o `false` in un punto in cui ci si aspetta un numero, verranno convertiti rispettivamente in `1` e `0`.
Se usi un numero in un'operazione booleana, tutto ciò che non è `0` viene considerato `true`, anche i valori negativi.

```cpp
!true && 0.0   // => false
true + true + false // => 2
```
