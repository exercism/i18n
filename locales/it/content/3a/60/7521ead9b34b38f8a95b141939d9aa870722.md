# Introduzione

## L'operatore ternario

Un condizionale ternario è un modo più breve per scrivere semplici istruzioni `if/else`.
Se un'istruzione `if/else` contiene solo due rami, uno per quando la condizione è vera e uno per quando è falsa, può essere riscritta come condizionale ternario.

I ternari usano una combinazione dei simboli `?` e `:` per separare un condizionale:

```ruby
condition ? true_branch : false_branch
```

Il codice a sinistra del `?` è la condizione, mentre il codice a destra contiene i due rami possibili, separati dal `:`.
Se la condizione è _vera_, viene eseguito il codice a _sinistra_ del `:`.
Se la condizione è _falsa_, viene eseguito il codice a _destra_ del `:`.

Ad esempio:

```ruby
if traffic_light == 'green'
  cross_the_road
else
  wait
end
```

può essere riscritto così:

```ruby
traffic_light == 'green' ? cross_the_road : wait
```
