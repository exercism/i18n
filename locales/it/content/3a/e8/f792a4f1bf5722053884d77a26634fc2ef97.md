# Approfondimento

Le [struct][getting-started] sono delle [mappe][maps] speciali con un insieme definito di chiavi.

- Le struct forniscono controlli in fase di compilazione e valori predefiniti.
- Una struct prende il nome dal modulo in cui è definita.
- Per definire una struct si usa il costrutto [`defstruct`][docs-defstruct].
  - Il costrutto di solito segue immediatamente la definizione del modulo.
- `defstruct` accetta una lista di [atomi][atom] (per valori predefiniti nil) oppure liste di keyword (per valori predefiniti specificati).
  - I campi senza valore predefinito devono precedere i campi con un valore predefinito.

```elixir
defmodule Plane do
  defstruct [:engine, wings: 2]
end

plane = %Plane{}
# => %Plane{engine: nil, wings: 2}
```

## Accesso ai campi e aggiornamento

- La maggior parte delle funzioni che lavorano con le [mappe][maps] funziona anche con le struct.
  - L'[_Access Behaviour_][access-behaviour] è un'eccezione e **non** è implementato per le struct.
- Si consiglia di usare l'_operatore di accesso statico_ `.` per accedere ai campi di una struct.

- Ottenere/recuperare i valori dei campi:

  ```elixir
  plane = %Plane{}
  plane.engine
  # => nil
  Map.fetch(plane, :wings)
  # => {:ok, 2}
  ```

- Aggiornare i valori dei campi

  ```elixir
  plane = %Plane{}
  %{plane | wings: 4}
  # => %Plane{engine: nil, wings: 4}
  ```

## Obbligare all'inizializzazione dei valori dei campi

- L'[attributo di modulo `@enforce_keys`][enforcing-keys] crea un controllo a runtime che i campi specificati devono essere inizializzati a un valore **non** `nil` quando viene creata la struct.
- `@enforce_keys` è seguito da una lista delle chiavi dei campi (che sono [atomi][atom]).
- Se una chiave obbligatoria non viene inizializzata, viene generato un errore.

```elixir
defmodule User do
  @enforce_keys [:username]
  defstruct [:username]
end

%User{}
# => (ArgumentError) the following keys must also be given when building struct User: [:username]
```
