# Introduzione

Pompe, valvole, tubi: qualsiasi cosa che occupi una risorsa del sistema operativo (un file aperto, una connessione di rete) deve essere *rilasciata* quando hai finito di usarla. Il vocabolario [`destructors`][destructors] di Factor le avvolge in un framework che garantisce la pulizia, anche quando un errore interrompe il codice a metà.

## La classe e il generico

Una classe entra a far parte del framework estendendo `disposable` e implementando il generico `dispose*`:

```factor
USING: accessors destructors kernel ;

TUPLE: pump < disposable opened ;

: <pump> ( -- pump )
    pump new-disposable t >>opened ;

M: pump dispose* f >>opened drop ;
```

`new-disposable ( class -- obj )` alloca la tupla *e* la registra presso il framework: un'eccezione tra l'allocazione e il successivo punto sicuro non può causare una perdita della risorsa. Il framework garantisce che `dispose*` venga eseguito **al massimo una volta** per oggetto: le chiamate ripetute a `dispose` non producono alcun effetto.

## I chiamanti esterni usano `dispose`

```
dispose          ( obj -- )                ! release; safe to call twice
with-disposal    ( disposable quot -- )    ! scope one resource
with-destructors ( quot -- )               ! open a registry scope
&dispose         ( obj -- obj )            ! dispose on normal *or* failure exit
|dispose         ( obj -- obj )            ! dispose only if the scope unwinds
```

`with-disposal` è la forma per una singola risorsa: mette sullo stack l'oggetto disposable per la quotation interna e lo rilascia all'uscita.

```factor
USING: destructors io ;

<pump> [
    "pumping" print
] with-disposal
! pump released on the way out — even if `print` had thrown
```

Per più di una risorsa, apri uno scope `with-destructors` e registra ogni acquisizione. `&dispose` (la e commerciale) significa «rilascia sempre all'uscita, in caso di successo o di errore». `|dispose` (la barra verticale) significa «rilascia **solo** in caso di errore»: è utile quando il percorso di successo passa la risorsa a un chiamante che se ne assumerà la proprietà.

```factor
[
    <pump> &dispose
    <pump> &dispose
    ! ... use the pumps ...
] with-destructors
! both pumps released
```

Per un semplice try/finally senza registro, [`cleanup`][cleanup] (in `continuations`) è la primitiva di livello inferiore, ma `with-destructors` è l'approccio idiomatico del Factor moderno.
