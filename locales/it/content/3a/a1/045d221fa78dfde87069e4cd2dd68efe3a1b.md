# Introduzione

## Confrontare i numeri

In `jq` i numeri si possono confrontare con i seguenti operatori relazionali e di uguaglianza.

| Confronto              | Operatore |
| ---------------------- | --------- |
| Maggiore di            | `a > b`   |
| Maggiore o uguale a    | `a >= b`  |
| Minore di              | `a < b`   |
| Minore o uguale a      | `a <= b`  |
| Uguale a               | `a == b`  |
| Diverso da             | `a != b`  |

Il risultato del confronto è sempre un valore booleano, quindi `true` o `false`.

```jq
1 < 3,      # => true
2 != 2,     # => false
1 == 1.0    # => true
            # All numbers are floating-points, so this is different syntax
            # for the exact same value.
```

## Confrontare le stringhe

Gli operatori di confronto visti sopra si possono usare anche per confrontare le stringhe.
In quel caso si applica un ordine alfabetico (lessicografico).
L'ordinamento è _per valore del code point Unicode_.

```jq
"Apple" > "Pear",   # => false
"a" < "above",      # => true
"a" == "A"          # => false
```

Devi fare attenzione quando confronti due variabili che sembrano contenere valori numerici ma sono di tipo stringa.
A causa dell'ordine alfabetico, il risultato non sarà lo stesso che confrontare valori di tipo number.

```jq
10 < 2,     # => false
"10" < "2"  # => true (because "1" comes before "2")
```

## Uguaglianza «rigorosa»

L'operatore `==` di `jq` è come `===` di JavaScript, nel senso che cose che «sembrano» uguali, ma sono di tipi diversi, non sono uguali.

```jq
"3" == 3    # => false
            # the value on the left has type string,
            # the value on the right has type number.
```

## Confrontare gli array

Due array sono uguali se tutti gli elementi corrispondenti sono uguali.

```jq
[1, 2, 3] == [1, 2, 3]      # => true
[1, 2, 3] == [1, 3, 2]      # => false, different order
[1, 2, 3] == [1, 2, "3"]    # => false, different types
```

## Confrontare gli oggetti

Due oggetti sono uguali se hanno le stesse coppie chiave-valore.

```jq
{name: "Joe", age: 42} == {age: 42, name: "Joe"}                # => true
{name: "Joe", age: 42} == {age: 42, name: "Jane"}               # => false
{name: "Joe", age: 42} == {age: "42", name: "Joe"}              # => false
{name: "Joe", age: 42} == {age: 42, name: "Joe", height: 175}   # => false

# comparisons will drill down as deeply as required
{a: {b: {c: [1, 2]}}} == {a: {b: {c: [1, 2]}}}                  # => true
{a: {b: {c: [1, 2]}}} == {a: {b: {c: [1, 2, 3]}}}               # => false
```
