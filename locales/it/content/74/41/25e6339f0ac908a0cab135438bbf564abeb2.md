# Istruzioni

In questo esercizio applicherai le [regole del gioco del Go](https://matmoore.github.io/learngo/). Le regole sono già scritte, devi solo applicarle per aggiornare la partita e gestire eventuali errori o violazioni delle regole.

La partita è rappresentata così:

```elm
type Player
    = Black
    | White


type alias Game =
    { whiteCapturedStones : Int
    , blackCapturedStones : Int
    , player : Player
    , error : String
    }
```

Nel gioco ci sono 4 regole:

- Ogni punto può avere una sola pietra (`oneStonePerPointRule`)
- Le pietre avversarie possono essere catturate! (`captureRule`)
- Non puoi posizionare una pietra dove catturerebbe se stessa (`libertyRule`)
- Non puoi usare lo stesso punto due volte (`koRule`)

## 1. Applica le regole

Scrivi il contenuto della funzione `applyRules`, che riceve un `Game` iniziale ed un insieme di regole e restituisce il nuovo `Game` dopo che le regole sono state applicate.

`oneStonePerPointRule`, `libertyRule` e `koRule` controllano le violazioni delle regole e possono restituire un errore, quindi hanno come tipo di ritorno `Result String Game`. Se una di queste regole fallisce, va restituita la partita originale, ma con il campo `error` aggiornato con l'errore corrispondente.

`captureRule` non controlla le violazioni e quindi non può fallire (anche se può restituire un `Game` modificato), perciò ha come tipo di ritorno `Game`.

Se tutte le regole sono rispettate, le modifiche al `Game` apportate dalle regole vanno mantenute ed il giocatore va cambiato. La funzione `changePlayer` è fornita per farlo.

```elm
applyRules : Game -> Rule -> NonValidatingRule -> Rule -> Rule -> Game
applyRules game oneStonePerPointRule captureRule libertyRule koRule =
--> If all rules pass, return a `Game` with all changes from the rules applied, and changePlayer
--> If any rule fails, return the original Game, but with the error field set
```
