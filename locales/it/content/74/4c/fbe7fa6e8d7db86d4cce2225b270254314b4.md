# Istruzioni

Un [numero di Armstrong][armstrong-number] è un numero uguale alla somma delle proprie cifre, ciascuna elevata alla potenza del numero di cifre.

Per esempio:

- 9 è un numero di Armstrong, perché `9 = 9^1 = 9`
- 10 *non* è un numero di Armstrong, perché `10 != 1^2 + 0^2 = 1`
- 153 è un numero di Armstrong, perché: `153 = 1^3 + 5^3 + 3^3 = 1 + 125 + 27 = 153`
- 154 *non* è un numero di Armstrong, perché: `154 != 1^3 + 5^3 + 4^3 = 1 + 125 + 64 = 190`

Scrivi del codice per stabilire se un numero è un numero di Armstrong.

[armstrong-number]: https://en.wikipedia.org/wiki/Narcissistic_number
