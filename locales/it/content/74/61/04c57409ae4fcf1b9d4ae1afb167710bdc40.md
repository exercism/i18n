# Introduzione

Una funzione di ordine superiore è una funzione che fa una delle due cose seguenti:

- Accetta una funzione come argomento
- Restituisce una funzione

Un argomento di funzione è un argomento come tutti gli altri, solo che puoi chiamarlo.

```fsharp
let double = fun x -> x * 2

let apply f x = f x

apply double 3
// => 6
```
