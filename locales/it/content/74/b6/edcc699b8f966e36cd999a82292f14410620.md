# Istruzioni

Sei un appassionato di birdwatching che tiene traccia di quanti uccelli hanno visitato il tuo giardino.
Di solito usi un conteggio su un quaderno per contare gli uccelli, ma per lavorare meglio con i tuoi dati hai digitalizzato i conteggi degli uccelli delle ultime settimane.

## 1. Determina il numero totale di uccelli che hai contato finora

Iniziamo ad analizzare i dati con una visione d'insieme.
Scopri quanti uccelli hai contato in totale da quando hai iniziato a tenere i tuoi registri.

Implementa una funzione `TotalBirdCount` che accetta uno slice di `int` contenente il conteggio degli uccelli per ogni giorno.
Deve restituire il numero totale di uccelli che hai contato.

```go
birdsPerDay := []int{2, 5, 0, 7, 4, 1, 3, 0, 2, 5, 0, 1, 3, 1}
TotalBirdCount(birdsPerDay)
// => 34
```

## 2. Calcola il numero di uccelli in visita in una settimana specifica

Ora che hai un'idea generale dei tuoi conteggi, vuoi fare un'analisi più dettagliata.

Implementa una funzione `BirdsInWeek` che accetta uno slice con i conteggi degli uccelli per giorno e un numero di settimana.

Restituisce il numero totale di uccelli che hai contato in quella determinata settimana.
Puoi assumere che le settimane siano sempre registrate per intero.

```go
birdsPerDay := []int{2, 5, 0, 7, 4, 1, 3, 0, 2, 5, 0, 1, 3, 1}
BirdsInWeek(birdsPerDay, 2)
// => 12
```

## 3. Correggi un errore di conteggio

Ti sei reso conto che per tutto il tempo in cui cercavi di tenere traccia degli uccelli, ce n'era uno nascosto in un angolo lontano del giardino.

Hai capito che questo uccello passava sempre un giorno sì e uno no nel tuo giardino.

Non sai esattamente dove fosse negli altri giorni, ma di sicuro non nel tuo giardino.

Il tuo intuito da birdwatcher ti dice anche che l'uccello era nel tuo giardino il primo giorno che hai registrato nel tuo array.

Date queste nuove informazioni, scrivi una funzione `FixBirdCountLog` che prende come argomento uno slice con gli uccelli contati per giorno e restituisce lo slice dopo aver corretto l'errore di conteggio.

```go
birdsPerDay := []int{2, 5, 0, 7, 4, 1}
FixBirdCountLog(birdsPerDay)
// => [3 5 1 7 5 1]
```
