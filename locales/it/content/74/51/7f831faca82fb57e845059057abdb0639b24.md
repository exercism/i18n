# Appendice alle istruzioni

## Registri

| Registro | Utilizzo     | Tipo      | Descrizione                                    |
| -------- | ------------ | --------- | ---------------------------------------------- |
| `$a0`    | input        | indirizzo | array di word con le capacità dei secchi       |
| `$a1`    | input        | intero    | secchio di partenza (1 o 2)                    |
| `$a2`    | input        | intero    | volume obiettivo                               |
| `$a3`    | input/output | indirizzo | array di word con il contenuto finale dei secchi |
| `$v0`    | output       | intero    | numero di azioni richieste, -1 se non è possibile |
| `$t0-9`  | temporaneo   | qualsiasi | usati per la memorizzazione temporanea         |
