# Introduzione

Lavorare con il testo è un compito comune nella programmazione.
Swift, insieme al framework Foundation, fornisce molti metodi e proprietà comodi per ispezionare, trasformare e manipolare le stringhe.

## Dividere le stringhe con `components(separatedBy:)`

Per dividere una stringa in un array di sottostringhe in base a un delimitatore, usa `components(separatedBy:)` (richiede di importare Foundation):

```swift
import Foundation

let sentence = "Hello, world!"
let words = sentence.components(separatedBy: " ")
print(words) // Prints ["Hello,", "world!"]
```

## Controllare prefissi e suffissi con `hasPrefix(_:)` e `hasSuffix(_:)`

Per controllare se una stringa inizia o termina con una sequenza specifica di caratteri, usa `hasPrefix(_:)` e `hasSuffix(_:)`:

```swift
let greeting = "Hello, world!"
print(greeting.hasPrefix("Hello"))  // Prints true
print(greeting.hasSuffix("world!")) // Prints true
```

## Cambiare maiuscole e minuscole

Puoi trasformare le maiuscole e le minuscole di una stringa usando questi metodi e proprietà standard:

- `lowercased()`: Restituisce una copia della stringa in minuscolo.
- `uppercased()`: Restituisce una copia della stringa in maiuscolo.
- `capitalized`: Restituisce una copia in cui la prima lettera di ogni parola è in maiuscolo (da Foundation).

```swift
let greeting = "hello, world!"
print(greeting.lowercased())  // Prints "hello, world!"
print(greeting.uppercased())  // Prints "HELLO, WORLD!"
print(greeting.capitalized)   // Prints "Hello, World!"
```

## Sostituire le sottostringhe con `replacingOccurrences(of:with:)`

Per sostituire tutte le occorrenze di una sottostringa di destinazione con un'altra stringa, usa `replacingOccurrences(of:with:)` (da Foundation):

```swift
let greeting = "Hello, world!"
let updated = greeting.replacingOccurrences(of: "world", with: "Swift")
print(updated) // Prints "Hello, Swift!"
```

## Unire le stringhe con `joined(separator:)`

Il metodo `joined(separator:)` appartiene alle collezioni di stringhe, come `[String]`.
Unisce gli elementi in un'unica stringa usando un separatore:

```swift
let words = ["Hello", "world"]
let sentence = words.joined(separator: ", ")
print(sentence) // Prints "Hello, world"
```
