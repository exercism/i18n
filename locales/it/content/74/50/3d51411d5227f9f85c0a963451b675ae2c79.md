# Informazioni

Le strutture dati che possono contenere zero o più elementi sono note come _collezioni_. Un **array** è una collezione che ha una dimensione/lunghezza fissa e i cui elementi devono essere tutti dello stesso tipo. Gli elementi possono essere assegnati a un array o recuperati da esso usando un indice. Gli array in C# hanno indici che partono da zero: l'indice del primo elemento è sempre zero.

```csharp
// Declare array with explicit size (size is 2)
int[] twoInts = new int[2];

// Assign second element by index
twoInts[1] = 8;

// Retrieve the second element by index
twoInts[1] == 8; // => true

// Check the length of the array
twoInts.Length == 2; // => true
```

Gli array possono anche essere definiti usando una notazione abbreviata, che permette sia di creare l'array sia di impostarne il valore. Dato che ora il compilatore può capire quanti elementi avrà l'array, si può omettere la lunghezza:

```csharp
// Three equivalent ways to declare and initialize an array (size is 3)
int[] threeIntsV1 = new int[] { 4, 9, 7 };
int[] threeIntsV2 = new[] { 4, 9, 7 };
int[] threeIntsV3 = { 4, 9, 7 };
```

Gli array si possono manipolare chiamando i [metodi][array-methods] o le [proprietà][array-properties] di un'istanza di array, oppure usando i metodi statici definiti nella [classe `Array`][array-class].

## Iterazione

Un array è anche una _collezione_, il che significa che puoi iterare su _tutti_ i suoi valori usando un [ciclo `foreach`][foreach-statement]:

```csharp
char[] vowels = new [] { 'a', 'e', 'i', 'o', 'u' };

foreach (char vowel in vowels)
{
    // Output the vowel
    System.Console.Write(vowel);
}

// => aeiou
```

Si può usare un [ciclo `for`][for-statement] per iterare su un array:

```csharp
char[] vowels = new [] { 'a', 'e', 'i', 'o', 'u' };

for (int i = 0; i < vowels.Length; i++)
{
    // Output the vowel
    System.Console.Write(vowels[i]);
}

// => aeiou
```

In generale, però, un ciclo `foreach` è preferibile a un ciclo `for` per i seguenti motivi:

- Un ciclo `foreach` ha la garanzia di iterare su _tutti_ i valori. Con un ciclo `for`, è facile saltare degli elementi, ad esempio a causa di un errore di off-by-one.
- Un ciclo `foreach` è più _dichiarativo_: il codice comunica _cosa_ vuoi che faccia, mentre un ciclo `for` comunica _come_ vuoi farlo.
- Un ciclo `foreach` è a prova di errore, mentre con i cicli `for` è facile commettere un errore di off-by-one.
- Un ciclo `foreach` funziona con tutti i tipi di collezione, compresi quelli che non supportano l'uso di un indicizzatore per accedere agli elementi.

Per garantire che un ciclo `foreach` iteri su _tutti_ i valori, il compilatore non permette di modificare una collezione all'interno di un ciclo `foreach`:

```csharp
char[] vowels = new [] { 'a', 'e', 'i', 'o', 'u' };

foreach (char vowel in vowels)
{
    // This would result in a compiler error
    // vowel = 'Y';
}
```

Un ciclo `for` ha comunque alcuni vantaggi rispetto a un ciclo `foreach`:

- Puoi iniziare o fermarti all'indice che vuoi.
- Puoi usare qualsiasi condizione di terminazione (booleana) tu voglia.
- Puoi saltare degli elementi personalizzando l'incremento della variabile del ciclo.
- Puoi elaborare le collezioni dall'ultimo al primo elemento contando all'indietro.
- Puoi usare i cicli `for` in contesti che non coinvolgono collezioni.

Argomenti correlati:

- Tieni presente che C# supporta gli [array multidimensionali][multi-dimensional-arrays] come `int[,] arr = new int[10, 5]`, che possono essere molto utili.
- Tieni anche presente che puoi creare istanze di oggetti di tipo [`System.Array`][system-array-object] con `Array.CreateInstance`. Tali oggetti sono di scarsa utilità, soprattutto per l'interoperabilità con il codice VB.NET. Non sono intercambiabili con gli array standard (`T[]`) e possono avere un limite inferiore diverso da zero.
