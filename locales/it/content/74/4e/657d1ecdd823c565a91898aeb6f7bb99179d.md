# Istruzioni

In questo esercizio, tradurrai alcune regole del classico gioco Pac-Man in funzioni C++.

Hai quattro regole da tradurre, tutte legate agli stati del gioco.

> Non preoccuparti di come vengono ricavati gli argomenti: concentrati solo sul combinarli per restituire il risultato previsto.

## 1. Definisci se Pac-Man mangia un fantasma

Definisci la funzione `can_eat_ghost`, che prende due argomenti (_se Pac-Man ha una pillola energetica attiva_ e _se Pac-Man sta toccando un fantasma_) e restituisce un valore booleano che indica se Pac-Man è in grado di mangiare il fantasma. La funzione dovrebbe restituire true solo se Pac-Man ha una pillola energetica attiva e sta toccando un fantasma.

```cpp
can_eat_ghost(false, true);
// => false
```

## 2. Definisci se Pac-Man segna punti

Definisci la funzione `scored`, che prende due argomenti (_se Pac-Man sta toccando una pillola energetica_ e _se Pac-Man sta toccando un puntino_) e restituisce un valore booleano che indica se Pac-Man ha segnato. La funzione dovrebbe restituire true se Pac-Man sta toccando una pillola energetica o un puntino.

```cpp
scored(true, true);
// => true
```

## 3. Definisci se Pac-Man perde

Definisci la funzione `lost`, che prende due argomenti (_se Pac-Man ha una pillola energetica attiva_ e _se Pac-Man sta toccando un fantasma_) e restituisce un valore booleano che indica se Pac-Man ha perso. La funzione dovrebbe restituire true se Pac-Man sta toccando un fantasma e non ha una pillola energetica attiva.

```cpp
lost(false, true);
// => true
```

## 4. Definisci se Pac-Man vince

Definisci la funzione `won`, che prende tre argomenti (_se Pac-Man ha mangiato tutti i puntini_, _se Pac-Man ha una pillola energetica attiva_ e _se Pac-Man sta toccando un fantasma_) e restituisce un valore booleano che indica se Pac-Man ha vinto. La funzione dovrebbe restituire true se Pac-Man ha mangiato tutti i puntini e non ha perso in base agli argomenti definiti nella parte 3.

```cpp
won(false, true, false);
// => false
```
