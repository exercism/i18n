# Introduzione

## Let

L'espressione `let` si usa per creare uno scope locale ed è utile in alcune situazioni:

- Per semplificare le espressioni
- Per dare un nome ai risultati delle espressioni intermedie
- Per suddividere un'espressione in parti più piccole quando diventa troppo grande

All'interno di un'espressione `let` puoi fare quasi tutto, incluso il destructuring (ne parleremo più in dettaglio negli esercizi successivi), ma non è possibile definire un nuovo Custom Type o un Type Alias.

```elm
let
  cube x = x * x * x
in
  cube a + cube b + cube c
```

```elm
beginWithPattern : Size -> Padding -> Pattern -> GameOfLife
beginWithPattern minimumSize padding pattern =
    let
        size = calculateSize minimumSize padding pattern

        center = Size.center size

        centeredPattern = Pattern.centerAt center pattern

        dimensions = { width = size, height = size }

        deadCells = Matrix.create dimensions Dead
    in
    GameOfLife (bringPatternToLife deadCells centeredPattern)
```
