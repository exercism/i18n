# Test

## Eseguire i test

Per eseguire i test, esegui il comando seguente:

```bash
dotnet test
```

Per eseguire i test automaticamente ogni volta che un file sorgente viene modificato, esegui il comando seguente:

```bash
dotnet watch test
```

## Risolvere l'esercizio

Risolvere un esercizio significa far passare tutti i suoi test. Per impostazione predefinita, quando esegui i test viene eseguito un solo test, il primo. È una scelta intenzionale: così puoi concentrarti solo sul far passare quel test. Quando passa, puoi abilitare il test successivo rimuovendo `Skip = "Remove this Skip property to run this test"` dall'attributo `[Fact]` o `[Theory]` del test. Quando tutti i test saranno abilitati e l'implementazione li farà passare tutti, avrai risolto l'esercizio!

Per aiutarti a iniziare, ogni esercizio include un file di implementazione stub. Puoi usare questo file come punto di partenza per costruire la soluzione. Sentiti libero di rimuovere o modificare questo file se ritieni che sia la cosa giusta da fare.

## Usare i pacchetti

Dovresti riuscire a risolvere la maggior parte degli esercizi senza usare pacchetti esterni. Tuttavia, per gli esercizi in cui vuoi davvero usare un pacchetto esterno, puoi aggiungerlo al progetto eseguendo il comando seguente:

```bash
dotnet add package [package-name]
```
