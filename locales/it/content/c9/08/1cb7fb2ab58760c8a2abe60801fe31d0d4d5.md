# Introduzione

Il ciclo for è una delle istruzioni più usate per eseguire ripetutamente una certa logica.
In JavaScript è composto dalla parola chiave `for`, da un'_intestazione_ racchiusa tra parentesi tonde e da un blocco di codice che contiene il _corpo_ del ciclo, racchiuso tra parentesi graffe.

```javascript
for (initialization; condition; step) {
  // code that is executed repeatedly as long as the condition is true
}
```

L'inizializzazione di solito imposta una variabile contatore, la condizione verifica se il ciclo deve continuare o fermarsi e il passo incrementa il contatore alla fine di ogni ripetizione.
Le singole parti dell'intestazione sono separate da punti e virgola.

```javascript
const list = ['a', 'b', 'c'];
for (let i = 0; i < list.length; i++) {
  // code that should be executed for each item list[i]
}
```
