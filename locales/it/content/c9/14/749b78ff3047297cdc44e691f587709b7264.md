# Risorse consigliate per l'apprendimento

Benvenuto nell'apprendimento di ColdFusion (CFML)! CFML è un linguaggio di scripting JVM dinamico e a tipizzazione debole. Ha due tipi di file diversi. I file `.cfm` (ColdFusion markup)_ sono puramente procedurali e usano la sintassi basata sui tag per generare HTML tramite template. Li useresti per le viste, se costruisci un sito web:

**index.cfm**

```xml
<cfoutput>
	<html>
		<h1>Welcome to my site, #FirstName# #LastName#!
	</html>
</cfoutput>
```

L'altro tipo di file è il `.cfc` (ColdFusion Component), ed è così che si dichiara una classe. I componenti si usano per la logica di business, i modelli e i controller. Di solito usano la sintassi script, che risulta simile a JavaScript.

**Car.cfc**

```js
component accessors=true {
	property name='make' type='string';
	property name='model' type='string';
	property name='year' type='number';

	function init() {
		return this;
	}
 
}
```
