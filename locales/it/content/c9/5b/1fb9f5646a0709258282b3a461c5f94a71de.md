# Appendice alle istruzioni

## Registri

| Registro | Utilizzo  | Tipo    | Descrizione                                      |
| -------- | --------- | ------- | ------------------------------------------------ |
| `$a0`    | input     | intero  | anno da verificare                               |
| `$v0`    | output    | booleano | l'input è un anno bisestile (`0` = `false`, `1` = `true`) |
| `$t0-9`  | temporaneo | qualsiasi | usato come archivio temporaneo                  |
