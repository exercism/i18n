# Informazioni

Common Lisp usa gli operatori aritmetici standard per la maggior parte delle operazioni, ma è in qualche modo unico nell'usare una «notazione prefissa» invece della più familiare «notazione infissa».

Più visivamente:

```lisp
;; Infix-notation (non-lisp languages)
1 + 2 + 3 + 4 + 5 ; => 15
;; Prefix-notation (lisp languages)
(+ 1 2 3 4 5)     ; => 15
```

Anche se la notazione prefissa trasforma alcune operazioni come `2 + 2` nella forma un po' inconsueta `(+ 2 2)`, rende molto più facile operare su più numeri alla volta.

## Operatori aritmetici con un solo argomento

Come piccola particolarità, gli operatori `-` e `/` hanno un significato speciale quando vengono applicati a un solo numero:

```lisp
;; A single number passed to `-` is simply negated
(- 4)   ; => -4
(- -32) ; => 32
;; A single number passed to `/` returns the reciprocal
(/ 8)   ; => 1/8
(/ 0.1) ; => 10.0
```

## Confrontare i numeri

Infine, potresti trovare utile confrontare numeri diversi usando funzioni come `=` (uguale), `/=` (non uguale) e `>=` (maggiore o uguale).
Quando questi confronti sono veri (come in `(= 1 1)`), restituiscono `T`, mentre quando non lo sono (come in `(> 0 1)`), restituiscono `NIL`.

## Predicati numerici

Il linguaggio include anche alcuni predicati utili come `zerop`, `evenp` e `oddp`, che verificano le condizioni ovvie.

## Riferimento

```lisp
;; Addition
(+ 1 2 3 4 5) ; => 15

;; Subtraction
(- 15 3 2)    ; => 10
(- 42)        ; => -42

;; Multiplication
(* 4 3 2 1)   ; => 24

;; Division
(/ 64 16 2)   ; => 2
(/ 5)         ; => 1/5

;; Exponentiation
(expt 2 8)    ; => 256

;; Square Root
(sqrt 25)     ; => 25

;; Modulo (Similar to remainder)
(mod 10 3)    ; => 1

;; Equality
(= 2 2)       ; => T
(= 3 5)       ; => NIL
```
