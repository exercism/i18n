# Liste

`LIST{T}` è una collezione ordinata che può crescere, appoggiata a un array che viene sostituito con uno più grande quando si riempie.

```sather
   notes ::= #LIST{STR};
   notes.append("muddy boots");
   notes[0]                     -- "muddy boots"
   notes[0] := "clean boots";
   notes.size
   notes.is_empty
   notes.has("clean boots")
   notes.remove_index(0);
```

## Array o lista?

| | `ARRAY{T}` | `LIST{T}` |
| --- | --- | --- |
| dimensione | fissa alla creazione | cambia |
| append | no | sì |
| remove | no | sì |
| indicizzazione | `a[i]` | `l[i]` |
| overhead | nessuno | una dimensione e dello spazio libero |

Usa un `ARRAY` quando la dimensione è nota e definitiva: una fila di ballerini, una settimana di conteggi. Usa un `LIST` quando le cose arrivano o se ne vanno.

## In place, non funzionale

`append`, `remove_index` e `[i] :=` modificano la lista stessa. Non serve riassegnare nulla, e una lista passata a una routine non è al sicuro da queste modifiche.

È l'opposto di `FMAP` e `FSET`, e vale la pena avere chiaro quale dei due si ha in mano. La regola pratica: la `F` all'inizio del nome indica che è funzionale, tutto il resto modifica sul posto.

Per distribuire una lista che nessuno possa rovinare, regalane una copia:

```sather
   return notes.copy;
```

## Il costo dell'append

Fare append costa poco in media. Quando l'array sottostante si riempie, se ne prende uno nuovo del doppio della dimensione e si copia tutto, quindi la maggior parte degli append non costa quasi nulla e quelli occasionali costano una copia. Su molti append, il costo medio si stabilizza su una costante per operazione: ecco perché si raddoppia invece di crescere di uno alla volta.

`remove_index` non costa poco: tutti gli elementi dopo la posizione rimossa scalano di una posizione. Rimuovere ripetutamente dall'inizio di una lista lunga è lento, e la cosa è facile da non notare.

## Routine utili

| Chiamata | Cosa fa |
| --- | --- |
| `l.append(x)` | aggiunge in fondo |
| `l.insert_before(i, x)` | aggiunge in una posizione |
| `l.remove_index(i)` | toglie una posizione |
| `l.has(x)` | c'è dentro? |
| `l.copy` | una copia indipendente |
| `l.str` | il contenuto, tra parentesi graffe |
| `l.elt!`, `l.ind!` | scorre i valori, o le posizioni |
