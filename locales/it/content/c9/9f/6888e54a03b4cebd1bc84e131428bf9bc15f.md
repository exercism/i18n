# Trasformazione JSON del carburante

## Descrizione del problema

Ogni dipendente di ABC Corp riceve un'indennità di carburante illimitata. I dipendenti devono inviare un record ogni volta che fanno rifornimento ai propri veicoli. Questi record vengono aggiunti allo stesso file JSON, per poi essere elaborati alla fine del mese.

Come membro del team di operazioni digitali, il tuo compito è leggere questo file JSON e scrivere i risultati in un altro file JSON. Il file di output deve contenere una voce per ogni dipendente con i seguenti dettagli:

- Numero del dipendente
- Numero di rifornimenti
- Costo totale del carburante
- Galloni totali
- Miglia totali accumulate

Ti vengono forniti due argomenti `string`.

1. Il percorso del file JSON di input.
1. Il percorso del file JSON di output.

Il file JSON di input contiene un array di oggetti JSON. Ogni oggetto JSON ha la seguente forma.


```json
{
    "type": "array",
    "items": {
        "type": "object",
        "properties": {
            "employeeId": {
                "type": "integer"
            },
            "odometerReading": {
                "type": "integer"
            },
            "gallons": {
                "type": "number"
            },
            "gasPrice": {
                "type": "number"
            }
        },
        "required": [
            "employeeId",
            "odometerReading",
            "gallons",
            "gasPrice"
        ]
    }
}
```

```ballerina
// Ballerina record type definition
type FillUpEntry record {|
    int employeeId;
    int odometerReading;
    decimal gallons;
    decimal gasPrice;
|};
```

Il tuo compito è trasformare l'input JSON nel seguente formato JSON e scrivere il contenuto nel percorso indicato. Il file di output deve contenere una voce per ogni dipendente, in ordine crescente per `employeeId`.

```json
{
    "type": "array",
    "items": {
        "type": "object",
        "properties": {
            "employeeId": {
                "type": "integer"
            },
            "gasFillUpCount": {
                "type": "integer"
            },
            "totalFuelCost": {
                "type": "number"
            },
            "totalGallons": {
                "type": "number"
            },
            "totalMilesAccrued": {
                "type": "integer"
            }
        },
        "required": [
            "employeeId",
            "gasFillUpCount",
            "totalFuelCost",
            "totalGallons",
            "totalMilesAccrued"
        ]
    }
 }
```

```ballerina
// Ballerina record type definition
type EmployeeFillUpSummary record {|
    int employeeId;
    int gasFillUpCount;
    decimal totalFuelCost;
    decimal totalGallons;
    int totalMilesAccrued;
|};
```

## Vincoli

- Numero di record di rifornimento `n` nel file JSON di input:  0 <= n <= 1000
- Numero di dipendenti dell'azienda: 97
- Il prezzo del carburante è per gallone
- Nessun record di rifornimento mancante

## Suggerimenti

- Usa il [modulo `ballerina/io`](https://lib.ballerina.io/ballerina/io/latest) per leggere e scrivere file JSON.
- Converti i valori JSON in tipi specifici dell'applicazione per lavorare con i dati in modo sicuro dal punto di vista dei tipi. Per informazioni, fai riferimento all'esempio [Esempio di conversione a un tipo definito dall'utente](https://ballerina.io/learn/by-example/convert-from-json-to-user-defined-type) in Ballerina By Examples (BBE).

```ballerina
   json jsonPayload = {id: "2", title: "Jeru", artist: "Gerry Mulligan", price: 17.99};

   // Using cloneWithType  
   Album album1 = check jsonPayload.cloneWithType();
   io:println(album1);
 
   // Using fromJsonWithType
   Album album2 = check jsonPayload.fromJsonWithType();
   io:println(album2);
```

- La [destrutturazione dei record](https://ballerina.io/learn/by-example/destructure-records-using-query) può essere utile per ridurre la verbosità del codice.

```ballerina
   Album {id, title, artist, price} = album1;
   io:println(id);
   io:println(title);
```

- Usa le funzioni con corpo a espressione per le funzioni con una sola espressione. Ad esempio, le funzioni che contengono solo l'istruzione di `return`.

```ballerina
   function cfr(int deaths, int cases) returns decimal => <decimal>deaths / <decimal>cases * 100;
```
