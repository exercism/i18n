# Installazione

Segui le istruzioni per il tuo sistema nella pagina di installazione su [golang.org](http://golang.org/doc/install).

## Versione di Go

Questa track usa Go 1.26.

Si potrebbe usare una versione precedente di Go modificando il file `go.mod` di ogni esercizio e cambiando la riga `go 1.26`. Tuttavia, i test usano funzionalità introdotte in Go 1.22 e, senza modifiche, non funzioneranno con una versione precedente.
