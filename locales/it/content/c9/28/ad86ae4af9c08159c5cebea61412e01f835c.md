## Importazione

Di solito un modulo si carica con la parola chiave `use`.
Questa lo carica e chiama su di esso il metodo `import`, importando tutti i simboli esportati.

I simboli presenti nell'array `@EXPORT` del package vengono importati per impostazione predefinita.
I simboli presenti nell'array `@EXPORT_OK` del package devono invece essere importati esplicitamente.

Prima di Perl `v5.37`, un modulo doveva terminare con un valore vero (di solito `1`) per indicare che il modulo era stato caricato correttamente.
Questo non è più necessario quando si usa la funzionalità [`module_true`][module_true].

## Esportazione

Perché un simbolo venga importato, deve prima essere esportato.
Il modulo [Exporter][Exporter] è incluso in Perl ed è una delle opzioni più comode per l'esportazione.

Definizione del modulo:
```perl
package Foo;

use Exporter ('import');
our @EXPORT_OK = ('bar');

sub bar { ... }
```

Uso del modulo:
```perl
use Foo ('bar');

bar();
```

## Pragma

Un pragma è un modulo che influenza qualche aspetto del comportamento di Perl.

I pragma [`strict`][strict] e [`warnings`][warnings] sono comunemente consigliati, rispettivamente per limitare costrutti non sicuri e per segnalare potenziali problemi.
Il pragma `strict` viene abilitato insieme a `use v5.12` o versioni successive.
Il pragma `warnings` viene abilitato insieme a `use v5.35` o versioni successive.

Il pragma [`feature`][feature] ti permette di abilitare funzionalità di Perl più recenti e sperimentali.
Quando alla parola chiave `use` viene data una versione specifica di Perl, questa abilita il feature bundle di quella versione.

## Moduli core

Oltre a [Exporter][Exporter], Perl ha a disposizione una grande varietà di [moduli core][perl-core-modules].
Alcuni esempi utili per gli esercizi che potresti incontrare qui includono [List::Util][List::Util], [Time::Piece][Time::Piece] e [Math::BigRat][Math::BigRat].

## CPAN

Oltre ai moduli core, [CPAN][metacpan] mette a disposizione per l'installazione migliaia di moduli aggiuntivi creati dalla comunità Perl.
Il track Perl usa un [cpanfile][test-runner-cpanfile] per installare una selezione di moduli che possono essere usati con il test runner Perl di Exercism.
