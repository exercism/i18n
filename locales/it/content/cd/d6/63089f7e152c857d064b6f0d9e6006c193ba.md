# Debug

Quando un test fallisce, viene mostrato un messaggio che descrive cosa è andato storto e per quale input. Puoi anche sfruttare il fatto che verrà mostrato anche tutto ciò che viene stampato su "standard out".
Puoi scrivere su "standard out" usando `println!`:

```rust
println!("Debug message");
```

Usa le parentesi graffe (`{}`) per stampare il valore di una variabile o di un'espressione:

```rust
let secret_number = 4321;
println!("My banking password is {}, which is better than {}.", secret_number, 1200 + 34);
```

Nota che non tutti i tipi possono essere stampati in questo modo, solo quelli che possono essere presentati agli utenti in modo inequivocabile.
Per esempio, gli array non possono essere stampati così, perché non è chiaro come un array dovrebbe essere mostrato agli utenti!
Per questi altri tipi, puoi dire alla macro `println!` di usare la _formattazione di debug_ con: `{:?}`.
Questa rappresentazione è pensata per essere vista solo dagli sviluppatori.
Un esempio:

```rust
let words = vec!["hello", "world"];
println!("words that are often combined: {:?}", words);
```

C'è persino la comoda macro `dbg!`, che si può usare per fare il debug di grandi espressioni sul posto, senza doverle smontare in dichiarazioni di variabili separate.

Supponiamo di avere la seguente espressione:

```rust
"hello world".split(' ').collect::<Vec<_>>().join("-")
```

Ora vorremmo vedere cosa restituisce la chiamata a `collect`.
Potremmo fare così:

```rust
let my_temporary_debug_variable = "hello world".split(' ').collect::<Vec<_>>();
println!("{:?}", my_temporary_debug_variable);
my_temporary_debug_variable.join("-")
```

Ma è noioso!
Non vogliamo riscrivere le nostre belle espressioni solo per poter fare il debug.
Diamo il benvenuto sul palco a: `dbg!`

```rust
dbg!(
    "hello world".split(' ').collect::<Vec<_>>()
).join("-")
```

Gli spazi servono solo per chiarezza.
Puoi racchiudere qualsiasi espressione in `dbg!()`, che stamperà quel valore (con la formattazione di debug).
Dopodiché puoi continuare a usare il valore in un'espressione più grande, come se `dbg!` non ci fosse nemmeno.

Buon debug!
