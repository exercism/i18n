# Appendice alle istruzioni

## Suggerimenti

Il valore restituito da `countWords` può essere qualsiasi tipo di tabella hash con chiavi di tipo `string` e valori di tipo `int`.

Le tabelle hash (note anche come «dictionaries» o «maps» in altri linguaggi di programmazione) sono implementate dal modulo `tables`: consulta la [documentazione][documentation].

Ad esempio, `countWords` potrebbe restituire `TableRef[string, int]`.

```nim
proc countWords*(sentence: string): TableRef[string, int] =
  ...
```

[documentation]: https://nim-lang.org/docs/tables.html
