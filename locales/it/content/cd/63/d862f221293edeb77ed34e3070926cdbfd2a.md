# preferisci estrarre la costante di livello superiore

Invece di definire la costante _all'interno_ della funzione, valuta di estrarla al livello superiore. Le costanti, le funzioni e le classi che non sono `export`ate non sono accessibili dall'esterno del file.

```javascript
const %{name} = %{value}

export const gigasecond = (...)
```
