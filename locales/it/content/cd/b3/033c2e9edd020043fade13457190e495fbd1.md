# Suggerimenti

## Generale

- Fai molta attenzione alla sintassi dei puntatori.
  Userai `*` (operatore di dereferenziazione) e `->` (accesso a un membro tramite puntatore).
- Assicurati di controllare i puntatori nulli (`nullptr`) dove serve, per evitare di accedere a memoria non valida.
- Puoi eseguire i test anche se il codice non è completo: una struttura abbozzata basta per vedere i risultati dei test.
- Tutte le funzioni usate dai test devono essere dichiarate nel file di intestazione.
- Se il programma va in crash o si comporta in modo inatteso, spesso è colpa della dereferenziazione di un puntatore nullo.
  Controlla bene di gestire `nullptr` nel modo giusto.
- Quando usi l'aritmetica dei puntatori, assicurati di restare entro i limiti dell'array dei sensori.
  Andare oltre la capacità dell'array può causare problemi di memoria.

## 1. Controlla la connessione dei sensori (`connection_check`)

- Il compito consiste principalmente nel verificare se un puntatore è nullo oppure no.
- Usa l'operatore di confronto `!=` per controllare se un puntatore è valido.
- Se non sei sicuro di star controllando il puntatore nel modo giusto, pensa a cosa rappresenta `nullptr` (l'assenza di un indirizzo di memoria valido).


## 2. Conta l'attività dei sensori (`activity_counter`)

- Devi iterare sull'array dei sensori.
  In C++, un array può essere trattato come un puntatore al suo primo elemento.
- Usa l'aritmetica dei puntatori (`sensor_array + i`) per accedere al sensore all'indice `i`.
- L'operatore `->` serve ad accedere a un membro della struct tramite un puntatore.

### Esempio

```cpp
int sum = (sensor_array + i)->activity; // Access activity using pointer arithmetic
```

## 3. Controllo dell'allarme (`alarm_control`)

- Per prima cosa, controlla se il puntatore è nullo prima di accedere al sensore.
- Usa l'operatore `->` per accedere al membro `activity` della struct `pillar_men_sensor`.
- Rifletti con attenzione su cosa deve succedere se il livello di attività del sensore è `0`.
  L'allarme deve scattare?

## 4. Controllo dei dati alla ricerca di anomalie con la funzione `uv_alarm`

- Usa l'operatore `&` per passare alla funzione `uv_light_heuristic` un puntatore all'array di dati del sensore.
- Assicurati di controllare correttamente che il puntatore non sia nullo prima di accedere ai dati del sensore.
- Confronta il risultato di `uv_light_heuristic` con il valore `activity` del sensore per stabilire se l'allarme deve scattare.
