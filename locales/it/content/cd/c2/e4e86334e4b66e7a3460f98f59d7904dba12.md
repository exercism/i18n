## 1. Cattura le informazioni necessarie per generare le card usando le regex

- `\p{L}` corrisponde a qualsiasi tipo di lettera di qualsiasi lingua.
- Puoi usare la seguente espressione per catturare le informazioni:
  ```julia
  re = r"""»(.*)«                     # title
           \ –\ (.*?)                 # name
           (?:\ \((.*?)\)|)           # optional pronouns
           (?:,\ from\ (.*?)|).       # optional organisation
           \ Start:\ (.*?),\          # start time
           (?:Q&A:\ (.*?),\ |)        # optional Q&A time
           End:\ (.*)                 # end time
        """x
  ```
