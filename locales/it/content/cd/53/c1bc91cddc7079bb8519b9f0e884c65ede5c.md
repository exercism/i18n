# Introduzione

In Kotlin, `when` è un'espressione condizionale che serve a scegliere tra diverse opzioni.
È simile a `switch` di Java e più flessibile di una catena di `if` ... `else if` ... `else`.

Come `if`, anche `when` può essere usato come un'espressione che produce un valore.

## Confrontare un valore

A `when` si passa tra parentesi il valore da confrontare.
Ogni ramo confronta quel valore finché uno non trova corrispondenza:

```kotlin
val animal = "chicken"
val type = when (animal) {
    "chicken" -> "bird"
    "poodle" -> "dog"
    else -> "unknown"
}
// type => "bird"
```

- Ogni ramo si scrive come `pattern -> result`.
- I rami vengono provati dall'alto verso il basso finché non si trova una corrispondenza.
  Viene eseguito solo il primo ramo.
- Usa `else` per qualsiasi valore non elencato sopra (simile all'`else` finale di una catena di `if`).

È simile al [pattern matching].
Il `pattern` può essere un valore da confrontare, oppure puoi usare `is` per confrontare in base al tipo:

```kotlin
fun typeText(subject: Any): String {
    return when(subject) {
        is Animal -> "Animal"
        is Fruit -> "Fruit"
        is String -> "Text"
        else -> "Unknown"
    }
}
```

oppure `in` per verificare se è contenuto in un intervallo, in una collezione, in una stringa o in qualsiasi altra cosa che abbia un metodo `contains`:

```kotlin
fun describe(number: Int, position: String) {
    // Range
    when(number) {
        in 1..10 -> println("From 1 to 10")
        in 11..20 -> println("From 11 to 20")
    }

    // Collection
    when(number) {
        in listOf(2, 4, 6) -> println("small even")
        in listOf(3, 5, 7) -> println("small odd")
    }

    // String
    when(position) {
        in "center middle" -> println("inner")
        in "left right boundary" -> println("outer")
    }
}
```

## Condizioni di guardia

Quando confronti un valore, puoi aggiungere altre condizioni in un `if` dopo il pattern.
Queste condizioni si chiamano condizioni di guardia.

```kotlin
val x = 5
val y = 10
val description = when (x) {
    5 if y % 2 == 0 -> "x is 5, y is even"
    else -> "other"
}
// description => "x is 5, y is even"
```

Si può usare anche `else if`.

```kotlin
val x = 7
val y = 10
val description = when (x) {
    5 if y % 2 == 0 -> "x is 5, y is even"
    else if y % 2 == 0 -> "y is an even number"
    else -> "other"
}
// description => "y is an even number"
```


## Confrontare condizioni

In alternativa, si può omettere il valore e mettere una condizione booleana su ogni ramo:

```kotlin
val x = 5
val y = 8
val description = when {
    x % 2 != 0 -> "x is odd"
    y % 2 == 0 -> "y is even"
    else -> "neither condition matched first"
}
// description => "x is odd"
```

Anche qui i rami vengono controllati dall'alto verso il basso e viene eseguito solo il primo ramo la cui condizione è `true`.

## Usare `when` come espressione

Quando usi `when` per il suo risultato (assegnato a una variabile, restituito da una funzione e così via), devi coprire tutti i casi possibili.

- Quando confronti con un valore, aggiungi `else` a meno che tutti i valori possibili siano già gestiti (per esempio, tutti i valori di un `Boolean` o di un `enum`).
- Quando confronti condizioni, un ramo `else` è obbligatorio, perché il compilatore non può sapere se le condizioni coprono tutti i casi.

```kotlin
fun label(n: Int): String = when (n) {
    0 -> "zero"
    1 -> "one"
    else -> "other"
}
```
