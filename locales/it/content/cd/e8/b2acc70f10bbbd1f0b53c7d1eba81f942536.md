# Istruzioni

In questo esercizio dovrai implementare alcune regole di [Pac-Man][Pac-Man], il classico gioco arcade degli anni '80.

Ci sono sei attività in tutto, quattro delle quali sono regole legate agli stati del gioco.

> _Non preoccuparti di come vengono ricavati gli argomenti nelle funzioni: concentrati solo sul combinarli per restituire il risultato voluto._


## 0. Definire uno stato dell'energia

Definisci una variabile chiamata `PowerOn` con un valore che rappresenti il fatto che l'energia è effettivamente attiva.

```powershell
> $PowerOn
True
```

## 1. Definire se Pac-Man mangia un fantasma

Definisci la funzione `EatGhost` che prende due parametri (_se Pac-Man ha una pillola energetica attiva_ e _se Pac-Man sta toccando un fantasma_) e restituisce un valore booleano che indica se Pac-Man è in grado di mangiare il fantasma.
La funzione deve restituire `True` solo se Pac-Man ha una pillola energetica attiva e sta toccando un fantasma.

```powershell
> EatGhost -ActivePower $false -TouchingGhost $true
False
```

## 2. Definire se Pac-Man segna punti

Definisci la funzione `Score` che prende due parametri (_se Pac-Man sta toccando una pillola energetica_ e _se Pac-Man sta toccando un punto_) e restituisce un valore booleano che indica se Pac-Man ha segnato.
La funzione deve restituire `True` se Pac-Man sta toccando una pillola energetica o un punto.

```powershell
> Score -TouchDot $true -TouchPowerPellet $true
4
```

## 3. Definire se Pac-Man perde

Definisci la funzione `Lose` che prende due parametri (_se Pac-Man ha una pillola energetica attiva_ e _se Pac-Man sta toccando un fantasma_) e restituisce un valore booleano che indica se Pac-Man perde.
La funzione deve restituire `True` se Pac-Man sta toccando un fantasma e non ha una pillola energetica attiva.

```powershell
> Lose -ActivePower $false -TouchingGhost $true
True
```

## 4. Definire se Pac-Man vince

Definisci la funzione `Win` che prende tre parametri (_se Pac-Man ha mangiato tutti i punti_, _se Pac-Man ha una pillola energetica attiva_ e _se Pac-Man sta toccando un fantasma_) e restituisce un valore booleano che indica se Pac-Man vince.
La funzione deve restituire `True` se Pac-Man ha mangiato tutti i punti e non ha perso in base ai parametri definiti nella parte 3.

```powershell
> Win -EatenAllDots $false -ActivePower $true -TouchingGhost $false
False
```

## 5. Scrivere la sinossi per la condizione di vittoria

Torna all'ultima funzione e aggiungi al blocco di commento una sezione `Synopsis` come breve descrizione di come vincere la partita.
La descrizione deve contenere almeno dieci caratteri.

```powershell
function MyFunc($Arg) {
    <#
    .DESCRIPTION
    This is a demonstration of the comment-based help with the description keyword.
    #>
}
```
