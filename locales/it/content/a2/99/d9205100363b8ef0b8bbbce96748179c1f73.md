# Test

Puoi eseguire i test lanciando il comando seguente nella directory dell'esercizio:

```bash
dub test
```

## Superare i test

Fai in modo che il primo test venga compilato, linkato e superato seguendo le [tre regole dello sviluppo guidato dai test](http://butunclebob.com/ArticleS.UncleBob.TheThreeRulesOfTdd). Crea solo la struttura necessaria, dichiarando namespace, funzioni, classi e così via, per risolvere gli errori di compilazione e far fallire il test. Poi scrivi solo il codice necessario per far passare il test. Una volta fatto, rimuovi il commento al test successivo spostando la riga seguente dopo il test successivo.

```D
static if (all_tests_enabled)
```

Questo potrebbe causare errori di compilazione, perché potrebbero essere usati nuovi costrutti che non hai ancora dichiarato o definito. Anche in questo caso, correggi gli errori di compilazione con il minimo indispensabile per ottenere un test che fallisce, poi modifica il codice con il minimo indispensabile per superare il test, riorganizza l'implementazione per renderla più leggibile ed espressiva, e infine passa al test successivo.

Prova a usare le funzionalità standard di D invece di scrivere a mano algoritmi o strumenti di basso livello.
