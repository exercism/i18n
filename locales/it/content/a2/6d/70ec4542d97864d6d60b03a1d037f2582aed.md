# Introduzione

## Stringhe

I caratteri e le stringhe costituiscono la base per la rappresentazione del testo in Elm.
Le stringhe si possono pensare come liste di caratteri e la maggior parte delle funzioni di `List` ha il suo equivalente nel modulo `String`.

### Caratteri

Il tipo `Char` rappresenta un singolo carattere unicode racchiuso tra virgolette singole, ad esempio `'a'`. 
Il modulo `Char` fornisce funzioni di predicato (`Char -> Bool`) per verificare le qualità di un carattere: `isUpper`, `isLower`, `isAlpha` e `isAlphaNum`
Il modulo fornisce anche funzioni per convertire un carattere in maiuscolo o in minuscolo (`toUpper`, `toLower`, `toLocaleUpper`, `toLocaleLower`), nonché da e verso il suo valore numerico unicode (`Int`) con `toCode` e `fromCode`.

### Stringhe

Il tipo `String` fornisce una rappresentazione integrata per manipolare le stringhe in modo efficiente e può rappresentare qualsiasi sequenza di caratteri unicode, ad esempio «questa è una stringa di Elm».
Le stringhe su più righe sono rappresentate con tre virgolette doppie e possono contenere virgolette e interruzioni di riga senza caratteri di escape.
```elm
"""
    This is a multiline string.
All line-breaks and whitespace,
are preserved. 
"""
```

### Funzioni per le stringhe

Il modulo `String` contiene tutte le funzioni riassunte nella tabella qui sotto.
Alcune delle funzioni più usate sono:

`cons : Char -> String -> String` aggiunge un carattere all'inizio di una stringa.
```elm
cons 'T' "he truth is out there" 
    --> "The truth is out there"
```

`(++): String -> String -> String` concatena due stringhe.
```elm
"butter" ++ "fly" 
    --> "butterfly"
```

`split : String -> String -> List String` divide una stringa in una lista di stringhe in corrispondenza del separatore indicato.
```elm
split ";" "cat;dog;cow" 
    --> ["cat", "dog", "cow"]
```

`join : String -> List String -> String` unisce una lista di stringhe con un dato separatore.
```elm
join "a" ["H", "w", "ii", "n"] 
    --> "Hawaiian"
```
`replace : String -> String -> String -> String` sostituisce tutte le occorrenze di una data sottostringa.
```elm
replace "Hello" "Goodbye cruel" "Hello world." 
    --> "Goodbye cruel world."
```

`length : String -> Int` restituisce il numero di caratteri di una stringa.
```elm 
length "Hello world." 
    --> 12
```

`toInt : String -> Maybe Int` prova a convertire una stringa in `Just Int` e restituisce `Nothing` per le stringhe con un formato non valido.
```elm
toInt "-42" 
    --> Just -42
```    

`contains : String -> String -> Bool` verifica se la seconda stringa contiene la prima.
```elm
contains "the" "theory" 
    --> True
```

`map : (Char -> Char) -> String -> String` applica una data funzione a ogni `Char` della stringa.
Nota che la funzione fornita deve essere una mappatura da e verso `Char`.
```elm
map (\c -> if c == '/' then '.' else c) "a/b/c" 
    --> "a.b.c"
```
