# Informazioni

PowerShell è un linguaggio di scripting di Microsoft, dinamico e a tipizzazione implicita (ma che supporta anche le [variabili fortemente tipizzate][strong typed]), incentrato soprattutto sull'automazione delle attività e sulla gestione della configurazione.

PowerShell supporta la programmazione imperativa, funzionale, orientata agli oggetti e persino quella basata sulle pipeline.

PowerShell è stato costruito sulla piattaforma .NET e rilasciato per la prima volta nel 2006.
È incluso di default in tutti i sistemi Windows moderni e può essere installato anche su Mac e Linux.


## Variabili

Ci sono due modi comuni per definire una variabile in PowerShell.

I nomi delle variabili in PowerShell devono iniziare con un `$` e si usa l'operatore di assegnazione `=` per associare il nome della variabile a un valore.

```powershell
> $intVar = 1
> $doubleVar = 2.0
> $stringVar = "Hello"

# Checking a variable type using the GetType() method
> Write-Host $doubleVar.GetType()
System.Double
```

Puoi anche specificare esplicitamente il tipo di una variabile, se vuoi imporre o richiedere che il valore sia di un certo tipo.
PowerShell farà del suo meglio per convertire il valore da un tipo a un altro, se possibile.

```powershell
# String represents a floating number can be converted to integer
> [int]$staticOne = "1.234"
> $staticOne
1

# String of letters can not be converted to double type
> [double]$staticTwo = "hello"
MetadataError: Cannot convert value "hello" to type "System.Double"
```

### Costanti

In PowerShell le costanti sono variabili che non possono essere **modificate** né **rimosse** dopo la definizione.
Questo ci porta al secondo modo di definire le variabili: usare il cmdlet `New-Variable`.

```powershell
> New-Variable -Name "MyConstant" -Value 100 -Option Constant
> $MyConstant
100
```


## Funzioni

Le funzioni in PowerShell si definiscono con la parola chiave `function`.
Ogni funzione può avere zero o più parametri formali tra parentesi tonde (`()`), seguiti dallo scope della funzione, che inizia con `{` e termina con `}`.

```powershell
function Greeting {
    return "Hello!"
}
```

Le funzioni in PowerShell possono restituire valori esplicitamente tramite la parola chiave `return`, dopo essere state chiamate con la sintassi `FuncName $Arg`.

```powershell
function AddTwoNumbers($NumOne, $NumTwo):
    $result = $NumOne + $NumTwo
    return $result

> AddTwoNumbers 10 20
30
```

## Commenti

In PowerShell i commenti singoli iniziano con un `#` e terminano a fine riga.
I blocchi di commento iniziano con `<#` e terminano con `#>`.

```powershell
function Main() {
    #This is a comment
    <#
    And this is a comment block
    that can span multiple lines
    #>
}
```
