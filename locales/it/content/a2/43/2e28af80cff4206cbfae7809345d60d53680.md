# Approfondimento

Gli errori sono utili per segnalare quando qualcosa non va o non è come previsto in un programma o in un frammento di codice.

Sono oggetti JavaScript.

La proprietà principale di questo oggetto è `message`:

```javascript
const error = new Error('Oops, something went wrong');

console.log(error.message);
// => "Oops, something went wrong"
```

Usando la sintassi `throw`, puoi lanciare un Error.

```javascript
throw new Error('Oops');
```

Quando un errore viene lanciato, l'esecuzione corrente si interrompe e riprende nel primo blocco catch del call stack.

```javascript
try {
  throw new Error('Oops');
} catch (error) {
  console.log(error.message);
  // => "Oops"
}
```

Come per qualsiasi classe in JavaScript, le sottoclassi possono ereditare da `Error` per creare errori personalizzati usando la parola chiave `extends`.
La sintassi `instanceof` controlla se l'errore catturato è un'istanza di una particolare sottoclasse di `Error`.

```javascript
class CustomError extends Error {}

try {
  // ... Code that may throw an error
} catch (error) {
  if (error instanceof CustomError) {
    console.log('The error thrown is an instance of the CustomError');
  }
}
```

## Tipi di errore

Oltre all'oggetto `Error`, esistono altri oggetti di errore predefiniti. Puoi saperne di più [qui][error-types].

## Errori personalizzati

Puoi anche definire un tuo [tipo di errore personalizzato][custom-error-type] creando una classe che estende uno dei tipi di errore predefiniti.

```javascript
class MyCustomError extends Error {}
```

## Lanciare valori che non sono errori

Anche se la sintassi `throw` viene di solito usata per lanciare un oggetto Error, JavaScript è flessibile e ti permette di lanciare una `string`, un `null` o qualsiasi tipo primitivo.

## Stack trace degli errori

Anche se non è standard in JavaScript, la maggior parte degli ambienti JavaScript implementa una proprietà [`stack`][error-stack] sugli oggetti Error, che ti permette di ottenere lo stack trace dell'errore lanciato.
