# Introduzione

Le tuple sono un modo leggero per raggruppare un insieme fisso di dati di tipo arbitrario.
Una tupla non ha un nome particolare; dare un nome a una struttura dati la trasforma in una `struct`.
I campi di una tupla non hanno nomi; vi si accede tramite destrutturazione o in base alla posizione.

## Creazione

Le tuple si creano sempre con un'espressione di tupla:

```rust
// pointless but legal
let unit = ();
// single element
let single_element = ("note the comma",);
// two element
let two_element = (123, "elements can be of differing types");
```

Le tuple possono avere un numero arbitrario di elementi.

## Accesso tramite destrutturazione

È possibile accedere agli elementi di una tupla tramite destrutturazione.
Questo significa semplicemente assegnare nomi di variabile ai singoli elementi della tupla, consumandola.

```rust
let (elem1, _elem2) = two_element;
assert_eq!(elem1, 123);
```
