# Introduzione

Il tipo `Result` permette a una funzione di restituire un unico valore che indica tutte le cose seguenti:
- Se l'operazione è riuscita o fallita
- In caso di successo, il valore risultante dell'operazione
- In caso di fallimento, il motivo del fallimento

## Utilizzo

Il tipo `Result` è un tipo generico che contiene due tipi sottostanti:
- Il tipo del valore risultante in caso di operazione riuscita
- Il tipo di errore in caso di fallimento

Il tipo `Result` è anche una [unione discriminata][discriminated-union] con i seguenti casi possibili:
* `Ok <value>` che rappresenta un risultato riuscito
* `Error <reason>` che rappresenta un fallimento

La seguente funzione mostra come creare un valore `Result`:

```fsharp
let validateName (name: string) : Result<string, string> = 
    match name with
    | null -> Error "Name not found."
    | "" -> Error "Name is empty."
    | _ -> Ok name
```

In questo esempio, il valore `Ok` è una stringa (il nome fornito) e anche il valore `Error` è una stringa (la causa dell'errore, in una forma leggibile).

## Leggere il contenuto di un valore `Result`

Considera la seguente definizione di tipo e la firma della funzione:

```
type FileOpenError = 
| NotFound
| AccessDenied
| FileLocked

let openFile (filename: string) : Result<int, FileOpenError> =
```

Il codice che chiama la funzione `openFile` può usare il pattern matching per gestire i casi di successo e di fallimento, come nell'esempio seguente:

```fsharp
match openFile(filename) with
| Ok handle -> doSomethingWithFile(handle)
| Error NotFound -> printfn $"Error: file {filename} was not found."
| Error AccessDenied -> printfn $"Error: you do not have permission to open the file {filename}."
| Error FileLocked -> printfn $"Error: file {filename} is already in use."
```
