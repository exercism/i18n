# Le basi della sintassi di Elm 2

## Esportare le funzioni

Abbiamo già parlato dell'esportazione delle funzioni nel primo concetto: ecco un breve ripasso.

Ogni file in Elm è un modulo e deve contenere un'istruzione `module` prima di qualsiasi altro codice.

I nomi dei moduli devono corrispondere al nome del file: il modulo `Calculator` deve stare nel file Calculator.elm, mentre il modulo `Parser.Utils` deve stare nel file Parser/Utils.elm.

Tutto ciò che viene definito all'interno di un modulo è visibile solo al suo interno e non può essere usato dall'esterno, a meno che non sia elencato in `exposing`.

```elm
-- Calculator.elm
-- Define the Calculator module, and expose the `add` function
module Calculator exposing (add)

six = 3 + 3

add number1 number2 = number1 + number2
```

```elm
-- Calculator.elm
-- Define the Calculator module, and expose everything within: `six` and `add`
module Calculator exposing (..)

six = 3 + 3

add number1 number2 = number1 + number2
```

https://elm-lang.org/docs/syntax#modules

## Importare funzioni da altri moduli

Per usare le funzioni definite in altri moduli si ricorre agli import.
Quando importiamo un modulo, tutte le funzioni che quel modulo ha esposto diventano accessibili.
Il modo in cui vi si accede, però, dipende da come il modulo viene importato.

Gli import qualificati sono quelli predefiniti: per usare una funzione di un modulo del genere (ad esempio la funzione `map` nel modulo `List`) basta anteporre il nome del modulo (`List.map`).

Gli import aperti danno accesso diretto alle funzioni esposte da quel modulo, senza prefisso. Si realizzano con la parola chiave `exposing`, in modo speculare a quella usata per le esportazioni. Puoi esporre tutte le funzioni disponibili (con `..`) oppure solo alcune (ad esempio `map`).

Puoi anche importare tipi e i loro costruttori da altri moduli: ne parleremo in un concetto successivo.

Gli import qualificati sono da preferire, perché rendono il codice più chiaro ed evitano conflitti di nomi.

```elm
-- qualified imports
import List                            -- List.map, List.foldl
import List as L                       -- L.map, L.foldl

-- open imports
import List exposing (..)              -- map, foldl, concat, ...
import List exposing ( map, foldl )    -- map, foldl, List.concat
```

https://elm-lang.org/docs/syntax#modules

## Le annotazioni di tipo

Le annotazioni di tipo si definiscono con `name : parameter types -> return type`, dove anche i tipi dei parametri sono separati da `->`.

```elm
add : Int -> Int -> Int
add number1 number2 = number1 + number2
```

Si possono usare le parentesi per definire i parametri di una funzione (che a loro volta seguono la stessa sintassi, da cui la necessità delle parentesi).

```elm
-- Transform every character in a string
map : (Char -> Char) -> String -> String
map charMapperFunction string =
    -- ...
```

https://elm-lang.org/docs/syntax#type-annotations

## I numeri

In Elm ci sono due tipi di numeri, definiti dai tipi `Int` e `Float`.
`Int` corrisponde all'insieme degli interi positivi e negativi.
`Float` corrisponde all'insieme dei numeri reali, limitato dalla precisione del computer.
Le operazioni definite sui numeri di solito funzionano su un tipo oppure sull'altro, senza mescolarli.
Esistono funzioni per convertire tra i due tipi: `toFloat` converte un `Int` in un `Float`, mentre `round`, `floor`, `ceiling` e `truncate` convertono un `Float` in un `Int` con semantiche diverse.

https://package.elm-lang.org/packages/elm/core/latest/Basics#Int

## Le operazioni sulle stringhe

Per rappresentare parole e frasi nel codice, Elm ha un tipo `String` nativo.
I valori letterali di tipo stringa si scrivono tra doppi apici, ad esempio `"Hello World!"`.
L'operatore di concatenazione di stringhe `++` e l'operatore di uguaglianza `==` sono disponibili di default.

```elm
hello : String -> String
hello subject = "Hello " ++ subject

hello "World!" --> "Hello World!"
```

La maggior parte delle altre funzioni per le stringhe si trova nel modulo `String`, che va importato.

https://package.elm-lang.org/packages/elm/core/latest/String
