# Istruzioni

In questo esercizio, dovrai tradurre alcune regole del classico gioco Pac-Man in funzioni Haskell.

Hai quattro regole da tradurre, tutte legate agli stati di gioco.

> Non preoccuparti di come vengono derivati gli argomenti: concentrati solo sul combinarli per restituire il risultato previsto.

## 1. Definisci se Pac-Man mangia un fantasma

Definisci la funzione `eatsGhost`, che accetta due argomenti (_se Pac-Man ha una pillola energetica attiva_ e _se Pac-Man sta toccando un fantasma_) e restituisce un valore `Bool` quando Pac-Man è in grado di mangiare il fantasma.
La funzione dovrebbe restituire `True` solo quando Pac-Man ha una pillola energetica attiva e sta toccando un fantasma.

```haskell
eatsGhost False True
-- -> False
```

## 2. Definisci se Pac-Man segna punti

Definisci la funzione `scores`, che accetta due argomenti (_se Pac-Man sta toccando una pillola energetica_ e _se Pac-Man sta toccando un pallino_) e restituisce un valore `Bool` se Pac-Man ha segnato punti.
La funzione dovrebbe restituire `True` quando Pac-Man sta toccando una pillola energetica o un pallino.

```haskell
scores True True
-- -> True
```

## 3. Definisci se Pac-Man perde

Definisci la funzione `loses`, che accetta due argomenti (_se Pac-Man ha una pillola energetica attiva_ e _se Pac-Man sta toccando un fantasma_) e restituisce un valore `Bool` se Pac-Man perde.
La funzione dovrebbe restituire `True` quando Pac-Man sta toccando un fantasma e non ha una pillola energetica attiva.

```haskell
loses False True
-- -> True
```

## 4. Definisci se Pac-Man vince

Definisci la funzione `wins`, che accetta tre argomenti (_se Pac-Man ha mangiato tutti i pallini_, _se Pac-Man ha una pillola energetica attiva_ e _se Pac-Man sta toccando un fantasma_) e restituisce un valore `Bool` se Pac-Man vince.
La funzione dovrebbe restituire `True` quando Pac-Man ha mangiato tutti i pallini _e_ non ha perso in base agli argomenti definiti nella parte 3.

```haskell
wins False True False
-- -> False
```
