# Booleani

Alcune domande hanno solo due risposte: sì o no. Il tipo di Sather per una risposta del genere è `BOOL`, e le due risposte si scrivono `true` e `false`.

```sather
   ready : BOOL is
      return true;
   end;
```

## Confrontare

Confrontare due numeri dà un `BOOL`.

| Operatore | Domanda |
| --- | --- |
| `=` | sono uguali? |
| `/=` | sono diversi? |
| `<` | quello di sinistra è più piccolo? |
| `<=` | più piccolo, o uguale? |
| `>` | quello di sinistra è più grande? |
| `>=` | più grande, o uguale? |

```sather
   old_enough(age : INT) : BOOL is
      return age >= 13;
   end;
```

Nota che `=` pone una domanda. Mettere un valore *dentro* qualcosa è `:=`, che hai già visto, e i due non sono la stessa cosa.

## Combinare

Tre operatori costruiscono domande più grandi a partire da quelle più piccole.

`and` è vero quando **entrambi** i lati sono veri.

```sather
harness_on and rope_checked
```

`or` è vero quando **almeno uno** dei due lati è vero, o entrambi.

```sather
mat_below or net_below
```

`~` capovolge una risposta: trasforma vero in falso e falso in vero.

```sather
~ready       -- true exactly when ready is false
```

`and` e `or` stanno tra due risposte; `~` sta davanti a una.
