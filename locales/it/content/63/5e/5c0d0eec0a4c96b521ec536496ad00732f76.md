# Istruzioni

Stai tenendo una guida da campo: una mappa dal nome di un animale all'habitat in cui vive.

Tutti e cinque i compiti vanno nella classe `FIELD_GUIDE`.

## 1. È presente nella guida?

```sather
FIELD_GUIDE::is_listed(guide, "emu")
-- => true
```

## 2. Dove vive?

Restituisci l'habitat registrato per un animale. Se la guida non ne ha mai sentito parlare, restituisci `"Unknown"`.

```sather
FIELD_GUIDE::habitat_of(guide, "emu")
-- => "grassland"
FIELD_GUIDE::habitat_of(guide, "moa")
-- => "Unknown"
```

## 3. Aggiungi una voce

Restituisci la guida con un animale in più. Se un animale è già elencato, il suo habitat viene sostituito.

```sather
FIELD_GUIDE::add_entry(guide, "wombat", "forest")
-- => the guide, now with wombat in it
```

Qualunque cosa restituisca è la guida da usare da quel momento in poi. Aggiungere a una guida completamente vuota funziona e dà una guida con un solo animale.

## 4. Quanti animali?

```sather
FIELD_GUIDE::entry_count(guide)
-- => 3
```

## 5. Quali habitat?

Restituisci l'insieme degli habitat menzionati nella guida. Più animali possono condividere un habitat, e questo deve comparire una sola volta.

```sather
FIELD_GUIDE::all_habitats(guide)
-- => a set holding "grassland" and "forest"
```
