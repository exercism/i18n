# Istruzioni

In questo esercizio aiuterai un crittografo a gestire e verificare un sistema di comunicazione sicuro.
Il sistema si basa fortemente sugli elementi di campo, in particolare sul tipo `felt252` di Cairo, per garantire che tutte le operazioni aritmetiche restino all'interno di un intervallo definito.

## 1. Calcola la somma di due messaggi

Due messaggi cifrati, ognuno rappresentato come un `felt252`, devono essere sommati per creare un messaggio combinato.
Tuttavia, a causa della cifratura, qualsiasi risultato che superi il valore massimo $P - 1$ deve essere riportato all'interno dell'intervallo usando il modulo $P$.

Implementa una funzione che prende in input due valori `felt252` e restituisce la loro somma, assicurandoti che il risultato resti nell'intervallo valido:

```rust
add_messages(3618502788666131213697322783095070105623107215331596699973092056135007822949, 987654321)
// => 123456789
```

> **Nota:** Il valore restituito deve essere un `felt252`.

## 2. Calcola la differenza tra due messaggi

A volte i messaggi devono essere sottratti per recuperare i dati originali.
Se il risultato della sottrazione è negativo, il sistema lo corregge automaticamente aggiungendo $P$ per riportarlo all'interno dell'intervallo di un valore `felt252` valido.

Implementa una funzione che prende in input due valori `felt252` e restituisce la loro differenza, assicurandoti che il risultato resti nell'intervallo valido:

```rust
subtract_messages(123456789, 987654321)
// => 3618502788666131213697322783095070105623107215331596699973092056135007822949
```

> **Nota:** Il valore restituito deve essere un `felt252`.

## 3. Calcola un prodotto valido di due messaggi

Per garantire l'integrità dei dati cifrati, il sistema crittografico moltiplica spesso due messaggi (`felt252`) per assicurarsi che il loro prodotto resti in un intervallo valido.
Il risultato deve essere calcolato modulo $P$ per garantire che rimanga nell'intervallo valido.

Implementa una funzione che prende in input due valori `felt252` e restituisce il loro prodotto, assicurandoti che il risultato resti nell'intervallo valido:

```rust
multiply_messages(382927772233671078546147897004315551461400594453673204174697055647611, 9449570)
// => 123456789
```

> **Nota:** Il valore restituito deve essere un `felt252`.
