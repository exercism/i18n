# Istruzioni

Il tuo amico ti ha appena mandato un messaggio con un segreto importante. Siccome non voleva renderlo facile da leggere per gli altri, il messaggio è stato cifrato con una serie di manipolazioni di bit. Dovrai scrivere le definizioni per decifrare il messaggio.

## 1. Sposta i bit indietro

Il primo passo per decifrare il messaggio è annullare lo spostamento fatto durante la cifratura, spostando i bit di nuovo verso destra. I passaggi successivi presuppongono che a sinistra vengano inseriti degli zeri.

Definisci `shift-back`, che prende un valore a 32 bit e una quantità, e restituisce il valore spostato a destra di quella quantità con riempimento di zeri.

```factor
0b1001 2 shift-back .
! => 0b0010
```

## 2. Imposta alcuni bit

Ora ci sono alcuni bit che devono essere impostati a 1.

Definisci `set-bits`, che prende un valore e una maschera. Ogni bit di `value` il cui bit corrispondente in `mask` è 1 deve essere impostato a 1; tutti gli altri bit restano invariati.

```factor
0b0110 0b0101 set-bits .
! => 0b0111
```

## 3. Inverti bit specifici

Alcuni bit vengono invertiti durante la cifratura. Per decifrare il messaggio andranno invertiti di nuovo.

Definisci `flip-bits`, che prende un valore e una maschera. Ogni bit di `value` il cui bit corrispondente in `mask` è 1 deve essere invertito; tutti gli altri bit restano invariati.

```factor
0b1100 0b0101 flip-bits .
! => 0b1001
```

## 4. Azzera bit specifici

Infine, ci sono anche alcuni bit che, dopo la decifratura, sono sempre 0.

Definisci `clear-bits`, che prende un valore e una maschera. Ogni bit di `value` il cui bit corrispondente in `mask` è 1 deve essere azzerato; tutti gli altri bit restano invariati.

```factor
0b0110 0b0101 clear-bits .
! => 0b0010
```
