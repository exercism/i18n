# Introduzione

Disponibili a partire da `PHP 8.0.0`, le **dichiarazioni di tipo unione** accettano valori di più tipi diversi, invece di un solo tipo. Le definizioni di tipo unione si creano usando la pipe (`|`) per separare i tipi.

```php
function add(int|float $a, int|float $b): int|float
{
    return $a + $b;
}
```

In modalità strict, PHP lancerà un `TypeError` se i parametri di input non sono né un `float` né un `int`. In modalità non strict, verrà lanciato un errore di tipo se i parametri di input non possono essere convertiti in un `float` o in un `int`.

Allo stesso modo, se la funzione non restituisce uno dei tipi dichiarati, PHP lancerà un `TypeError` in fase di esecuzione.
