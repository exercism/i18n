# Introduzione

## Mappe

Le mappe in Elixir sono la struttura dati per memorizzare informazioni in coppie chiave-valore. In altri linguaggi, queste potrebbero anche essere note come array associativi (PHP), hash (Perl 5, Raku) o dizionari (Python).

Chiavi e valori possono essere di qualsiasi tipo di dato, ma se la chiave è un atomo possiamo usare una sintassi abbreviata. Le mappe non garantiscono l'ordine delle loro voci quando vengono consultate o restituite.

### Forme letterali

Una mappa vuota si dichiara semplicemente con `%{}`. Se vogliamo aggiungere elementi a una mappa letterale, possiamo usare due forme:

```elixir
# If the key is an atom:
%{atom_key: 1}

# If the key is a different type:
%{1 => :atom_value}

# You can even mix these if the atom form comes second:
%{"first_form" => :a, atom_form: :b}
```

Anche se non esiste un formato canonico, scegli un modo coerente per rappresentare le coppie chiave-valore letterali.

### Funzioni del modulo Map

Elixir fornisce molte funzioni per lavorare con le mappe nel _modulo Map_. Alcune funzioni del _modulo Map_ richiedono che venga passata una funzione _anonima_ per assistere nella trasformazione della mappa.

## Attributi di modulo come costanti

In Elixir, possiamo definire attributi di modulo che possono essere usati come costanti nelle nostre funzioni.

```elixir
defmodule Example do
  # Defines the attribute as the value 1
  @constant_number 1

  def example_value() do
    # Returns the value 1
    @constant_number
  end
end
```

Quando vengono usati per definire costanti di modulo, gli attributi possono essere qualsiasi espressione che possa essere valutata al momento della compilazione. Dopo la compilazione, gli attributi di modulo non sono accessibili poiché vengono espansi durante la compilazione, in modo simile alle macro definite in linguaggi come C.
