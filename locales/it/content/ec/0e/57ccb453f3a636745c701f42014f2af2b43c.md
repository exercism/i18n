# Suggerimenti

## 1. Recuperare una carta da un mazzo

- Gli indici di `Vector` partono da `1`.
- Puoi recuperare l'`n`-esimo valore di un vettore `v` con `v[n]`.

## 2. Scambiare una carta nel mazzo

- Gli `Vector` sono mutabili: puoi modificarne il contenuto in qualsiasi momento.
- Il metodo prende un [Pair](https://docs.julialang.org/en/v1/base/collections/#Base.Pair) come argomento.
- Puoi accedere ai campi di una coppia `p` usando `p.first` e `p.second`.

## 3. Inserire una carta in cima al mazzo

- In Base c'è un metodo [`push!`](https://docs.julialang.org/en/v1/base/collections/#Base.push!) per aggiungere un nuovo valore alla fine di una collezione.

## 4. Rimuovere una carta dal mazzo

- In Base c'è un metodo [`deleteat!`](https://docs.julialang.org/en/v1/base/collections/#Base.deleteat!) per eliminare un elemento da un `Vector` a un dato indice.

## 5. Rimuovere la carta in cima al mazzo

- In Base c'è un metodo [`pop!`](https://docs.julialang.org/en/v1/base/collections/#Base.pop!) per rimuovere un elemento alla fine di una collezione.

## 6. Inserire una carta in fondo al mazzo

- In Base c'è un metodo [`pushfirst!`](https://docs.julialang.org/en/v1/base/collections/#Base.pushfirst!) per inserire un nuovo valore all'inizio di una collezione.

## 7. Rimuovere una carta dal fondo del mazzo

- In Base c'è un metodo [`popfirst!`](https://docs.julialang.org/en/v1/base/collections/#Base.popfirst!) per rimuovere un elemento all'inizio di una collezione.

## 8. Controllare la dimensione del mazzo

- In Base c'è un metodo [`length`](https://docs.julialang.org/en/v1/base/collections/#Base.length) per recuperare la lunghezza di una collezione.
