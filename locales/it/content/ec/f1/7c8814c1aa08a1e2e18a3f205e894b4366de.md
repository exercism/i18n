# Break e continue

Quando si usa una struttura di controllo ciclica o iterativa, le parole chiave `break` e `continue` possono aiutare a controllare il flusso di un programma.
La parola chiave `break` esce dal contesto del ciclo verso lo scope esterno, terminando così il ciclo.
La parola chiave `continue` salta il resto dell'iterazione corrente e fa ripartire il contesto del ciclo dall'inizio dell'iterazione successiva.
Sebbene sia poco comune, si può fornire un numero alla parola chiave per controllare da quanti contesti uscire o quante iterazioni saltare.

```php
<?php
$i = 1;
while ($i <= 10) {

    if ($i <= 5) {
        i += 1;
        continue;
    }
    break;
}
```

Nell'esempio precedente, `continue` viene eseguito cinque (5) volte, ma alla sesta (6) iterazione viene eseguito `break`, facendo uscire il codice dal ciclo.
