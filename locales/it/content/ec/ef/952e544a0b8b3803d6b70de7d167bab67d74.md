# Appendice alle istruzioni

## Formato di output

Restituisci l'età in centesimi di anno.

Ad esempio, 100 × 1.000.000.000 ÷ 31.557.600 ≈ 3.169, quindi qualcuno che ha 1.000.000.000 secondi di età ha `3169` centesimi di anno terrestre.

## Registri

| Registro | Utilizzo   | Tipo      | Descrizione                   |
| -------- | ---------- | --------- | ----------------------------- |
| `$a0`    | input      | intero    | pianeta (`0` = Mercurio, `1` = Venere, `2` = Terra, `3` = Marte, `4` = Giove, `5` = Saturno, `6` = Urano, `7` = Nettuno) |
| `$a1`    | input      | intero    | secondi                       |
| `$v0`    | output     | intero    | età in centesimi di anno      |
| `$t0-9`  | temporaneo | qualsiasi | usato per l'archiviazione temporanea |
