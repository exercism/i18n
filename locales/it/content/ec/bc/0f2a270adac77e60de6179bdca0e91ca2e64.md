# Introduzione

Un dizionario è una raccolta di elementi in cui ogni elemento comprende una chiave e un valore, così che se si passa una chiave a un metodo del dizionario viene restituito il valore associato. Svolge lo stesso ruolo delle mappe o degli array associativi in altri linguaggi.

Un dizionario può essere creato nel modo seguente:

```csharp
new Dictionary<int, string>();
// Empty dictionary
```

Oppure

```csharp
new Dictionary<int, string>
{
    [1] = "One",
    [2] = "Two"
};

// Or

new Dictionary<int, string>
{
    {1, "One"},
    {2, "Two"}
};
// 1 => "One", 2 => "Two"
```

Tieni presente che i tipi della chiave e del valore fanno parte della definizione del dizionario.

Una volta costruito, è possibile aggiungere o rimuovere voci da un dizionario usando i suoi metodi integrati `Add` e `Remove`.

Recuperare o aggiornare i valori in un dizionario avviene indicizzando il dizionario con una chiave:

```csharp
var numbers = new Dictionary<int, string>
{
   {1, "One"},
   {2, "Two"}
};

// Set the value of the element with key 2 to "Deux"
numbers[2] = "Deux";

// Get the value of the element with key 2
numbers[2];
// => "Deux"
```

Puoi verificare se un valore esiste nel dizionario con:

```csharp
var dict = new Dictionary<string, string>{/*...*/};
dict.ContainsKey("some key that exists");
// => true
```

Enumerare un dizionario significa scorrere le sue coppie chiave/valore. I dizionari hanno anche proprietà che consentono di enumerare le chiavi o i valori.
