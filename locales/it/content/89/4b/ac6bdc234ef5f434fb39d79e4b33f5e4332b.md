# Informazioni

Un *insieme disgiunto* (una struttura union-find) mantiene una collezione di valori suddivisi in gruppi che non si sovrappongono e risponde rapidamente a una domanda: questi due valori sono nello stesso gruppo? Vive nel vocabolario [`disjoint-sets`][disjoint-sets].

`<disjoint-set>` costruisce una struttura vuota. I valori, gli *atomi*, si aggiungono con `add-atom`, oppure in blocco con `add-atoms`; ognuno parte in un gruppo a sé:

```
<disjoint-set> ( -- disjoint-set )
add-atom       ( atom disjoint-set -- )
add-atoms      ( seq disjoint-set -- )
```

```factor
USING: disjoint-sets ;

<disjoint-set>
{ "a" "b" "c" "d" } over add-atoms   ! four singleton groups
```

`equate` unisce i gruppi che contengono due atomi. L'unione è transitiva: una volta chiamato `equate` su `a` e `b`, e poi su `b` e `c`, tutti e tre condividono un unico gruppo.

```
equate ( atom1 atom2 disjoint-set -- )
```

Ogni gruppo è identificato da un unico membro canonico, il suo *rappresentante*. `representative` lo restituisce, e due atomi appartengono allo stesso gruppo esattamente quando i loro rappresentanti sono uguali. `equiv?` esegue direttamente questa verifica:

```
representative ( atom disjoint-set -- representative )
equiv?         ( atom1 atom2 disjoint-set -- ? )
```

```factor
USING: disjoint-sets ;

<disjoint-set>
{ "a" "b" "c" "d" } over add-atoms
"a" "b" pick equate
"b" "c" pick equate
"a" "c" pick equiv? .          ! => t   (transitively connected)
"a" "d" pick equiv? .          ! => f
"a" over representative
"c" pick representative = .     ! => t   (same representative)
```

Quale atomo venga scelto come rappresentante di un gruppo è un dettaglio interno: può essere qualsiasi membro del gruppo, e può cambiare man mano che i gruppi si uniscono. Non affidarti mai al fatto che un particolare atomo sia il rappresentante, ma solo al fatto che due atomi dello stesso gruppo concordino.

`disjoint-set-members` restituisce ogni atomo che è stato aggiunto.

La struttura è *mutabile*: `equate` e `add-atom` modificano l'insieme disgiunto sul posto invece di restituirne uno nuovo. L'implementazione usa l'unione per rango con la compressione dei percorsi, quindi una lunga serie di chiamate a `equate` e `representative` ha un tempo effettivamente costante ciascuna.
