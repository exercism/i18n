# Introduzione

In JavaScript, un array è una struttura simile a una lista, senza lunghezza fissa, che può contenere qualsiasi tipo di primitivo o di oggetto, anche di tipi diversi.

Per creare un array, aggiungi gli elementi tra parentesi quadre `[]`.
Per leggere da un array, metti l'indice tra parentesi quadre `[]` dopo l'identificatore.
Gli indici di un array partono da zero.

Ad esempio:

```javascript
const numbers = [1, 'two', 3, 'four'];
numbers[2];
// => 3
```

Per ottenere il numero di elementi presenti in un array, usa la proprietà `length`:

```javascript
const numbers = [1, 'two', 3, 'four'];
numbers.length;
// => 4
```

Per modificare un elemento dell'array, assegna un valore all'indice:

```javascript
const numbers = [1, 'two', 3, 'four'];
numbers[0] = 'one';
numbers;
// => ['one', 'two', 3, 'four']
```

## Metodi

Alcuni dei [metodi][array_methods] disponibili su ogni oggetto Array si possono usare per aggiungere o rimuovere elementi da un array.

### push

> Il metodo `push()` aggiunge uno o più elementi in fondo a un array e restituisce la nuova lunghezza dell'array.[^1]

```javascript
const numbers = [1, 'two', 3, 'four'];
numbers.push(5); // => 5
numbers;
// => [1, 'two', 3, 'four', 5]
```

### pop

> Il metodo `pop()` rimuove l'ultimo elemento di un array e restituisce quell'elemento.
> Questo metodo modifica la lunghezza dell'array.[^2]

```javascript
const numbers = [1, 'two', 3, 'four'];
numbers.pop(); // => four
numbers;
// => [1, 'two', 3]
```

### shift

> Il metodo `shift()` rimuove il primo elemento di un array e restituisce l'elemento rimosso.
> Questo metodo modifica la lunghezza dell'array.[^3]

```javascript
const numbers = [1, 'two', 3, 'four'];
numbers.shift(); // => 1
numbers;
// => ['two', 3, 'four']
```

### unshift

> Il metodo unshift() aggiunge uno o più elementi all'inizio di un array e restituisce la nuova lunghezza dell'array.[^4]

```javascript
const numbers = [1, 'two', 3, 'four'];
numbers.unshift('one'); // => 5
numbers;
// => ['one', 1, 'two', 3, 'four']
```

### splice

> Il metodo splice() modifica il contenuto di un array rimuovendo o sostituendo elementi esistenti e/o aggiungendo nuovi elementi sul posto. Questo metodo restituisce un array contenente gli elementi eliminati.[^5]

```javascript
const numbers = [1, 'two', 3, 'four'];
numbers.splice(2, 1, 'one'); // => [3]
numbers;
// => [1, 'two', 'one', 'four']
```
