# Istruzioni

Da aspirante maga, Elyse deve fare pratica con le basi.
Ha una pila di carte che vuole manipolare.

Per semplificare un po' le cose, usa solo le carte da 1 a 10, così la sua pila di carte può essere rappresentata da un array di numeri.
La posizione di una determinata carta corrisponde all'indice nell'array.

## 1. Recuperare una carta da una pila

Per pescare una carta, restituisci la carta all'indice `position` dalla pila data.

```julia-repl
julia> stack = [1, 2, 4, 1];
julia> position = 3;
julia> get_item(stack, position)
4
```

## 2. Scambiare una carta nella pila

Esegui un gioco di prestigio e scambia la carta all'indice `position` con la carta sostitutiva fornita.
Restituisci la pila aggiornata.

```julia-repl
julia> stack = [1, 2, 4, 1];
julia> position = 3;
julia> replacement_card = 6;
julia> set_item!(stack, position, replacement_card)
[1, 2, 6, 1]
```

## 3. Inserire una carta in cima alla pila

Fai apparire una carta inserendo una nuova carta in cima alla pila.
Restituisci la pila aggiornata.

```julia-repl
julia> stack = [5, 9, 7, 1];
julia> new_card = 8;
julia> insert_item_at_top!(stack, new_card)
[5, 9, 7, 1, 8]
```

## 4. Rimuovere una carta dalla pila

Fai sparire una carta rimuovendo dalla pila la carta alla `position` indicata.
Restituisci la pila aggiornata.

```julia-repl
julia> stack = [3, 2, 6, 4, 8];
julia> position = 3;
julia> remove_item!(stack, position)
[3, 2, 4, 8]
```

## 5. Rimuovere la carta in cima alla pila

Fai sparire una carta rimuovendo la carta in cima alla pila.
Restituisci la pila aggiornata.

```julia-repl
julia> stack = [3, 2, 6, 4, 8];
julia> remove_item_from_top!(stack)
[3, 2, 6, 4]
```

## 6. Inserire una carta in fondo alla pila

Fai apparire una carta inserendo una nuova carta in fondo alla pila.
Restituisci la pila aggiornata.

```julia-repl
julia> stack = [5, 9, 7, 1];
julia> new_card = 8;
julia> insert_item_at_bottom!(stack, new_card)
[8, 5, 9, 7, 1]
```

## 7. Rimuovere una carta dal fondo della pila

Fai sparire una carta rimuovendo la carta in fondo alla pila.
Restituisci la pila aggiornata.

```julia-repl
julia> stack = [8, 5, 9, 7, 1];
julia> remove_item_at_bottom!(stack)
[5, 9, 7, 1]
```

## 8. Verificare la dimensione della pila

Controlla se la dimensione della pila è uguale a `stack_size` oppure no.

```julia-repl
julia> stack = [3, 2, 6, 4, 8];
julia> stack_size = 4;
julia> check_size_of_stack(stack, stack_size)
false
```
