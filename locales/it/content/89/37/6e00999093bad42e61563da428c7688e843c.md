# Informazioni

Le [closure][closures] in Swift sono blocchi di codice a sé stanti ai quali si possono passare dei parametri per attivarne il calcolo, e che possono restituire dei valori.
Le closure inoltre catturano i valori dal loro ambiente e li usano nei loro calcoli.
Poiché sono a sé stanti, possono essere passate da una parte all'altra di un programma come qualsiasi altro valore, oppure assegnate a costanti e variabili.

Le closure possono sembrare molto simili alle funzioni di Swift; in effetti lo sono, e per una buona ragione.
Le funzioni in Swift sono casi particolari di closure: devono avere un nome e si definiscono con una sintassi leggermente diversa.

Sebbene in Swift le funzioni siano tecnicamente delle closure, quando si parla di «closure» in Swift ci si riferisce alle [espressioni closure][closure-expressions].
Un'espressione closure si scrive con un elenco di parametri seguito da un tipo restituito e dalla parola chiave `in`, seguita dal corpo della closure, il tutto racchiuso tra parentesi graffe:

```swift
{ (a: Double, b: Double) -> Double in
  return (a + b) / 2.0
}
```

Questa definisce un'espressione closure di tipo `(Double, Double) -> Double` e può essere eseguita in modo simile a una funzione di questo tipo, applicandola a parametri del tipo appropriato:

```swift
{ (a: Double, b: Double) -> Double in
  return (a + b) / 2.0
}(10.0, 15.0)
// returns 12.5
```

Dato che non è molto comodo scrivere ogni volta l'intera espressione closure quando la si vuole eseguire, le closure possono essere assegnate a un nome, come qualsiasi altro valore in Swift.
A quel punto si possono chiamare applicando il nome ai parametri:

```swift
let mean = { (a: Double, b: Double) -> Double in
  (a + b) / 2.0
}

mean(13.0, 100.0)
// returns 56.5
```

Come si è visto sopra, le closure, proprio come le funzioni normali, possono omettere la parola chiave `return` se il corpo della closure è una singola espressione.

Molto spesso le closure si usano con le funzioni di ordine superiore, passandole come parametri oppure restituendole come risultati:

```swift
[11, 75, 3, 99, 53].contains(where: { (x: Int) -> Bool in x > 100 })
// returns false

["apple", "ball", "carrot"].sorted(by: { (s1: String, s2: String) -> Bool in s1.count < s2.count })
// returns ["ball", "apple", "carrot"]

func makeAdder(base: Int) -> (Int) -> Int {
  { (x: Int) -> Int in base + x }
}
```
