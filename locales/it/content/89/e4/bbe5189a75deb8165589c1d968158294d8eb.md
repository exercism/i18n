# Istruzioni

Il paese di Hyperia ha i suoi problemi. In particolare, l'inflazione è fuori controllo. Ti hanno fatto arrivare qui per assumere un incarico presso la banca centrale.

## 1. Stampa i tagli delle banconote

Per semplificare l'amministrazione interna, la banca centrale ha suddiviso ogni taglio in due parti: una _base_, che rimane relativamente invariata, e un _moltiplicatore_ (uguale per tutti i tagli) che può essere modificato ogni anno, ogni settimana o persino ogni giorno.

Al momento della stampa, i tagli riportati sulle banconote sono il prodotto di _base_ e _moltiplicatore_.

Quando questo sistema fu introdotto, la banconota di valore più basso aveva già un taglio di 10.000.000. La tabella sottostante mostra la situazione (per i primi 3 tagli) al momento dell'introduzione del sistema. Le cose sono peggiorate molto da allora: non cambia solo il moltiplicatore, ma anche la base.

| Base    | Moltiplicatore | Taglio       |
| ------- | ---------- | ------------ |
| 10.000  | 1.000      | 10.000.000   |
| 50.000  | 1.000      | 50.000.000   |
| 100.000 | 1.000      | 100.000.000  |
| ...     | 1.000      | ...          |

In sintesi, questo significa che _taglio_ = _base_ \* _moltiplicatore_.

Implementa il metodo `CentralBank.DisplayDenomination()`: riceve la base e il moltiplicatore e restituisce una stringa con il loro prodotto (base \* moltiplicatore). La stringa numerica restituita non deve essere formattata.

Se l'operazione di moltiplicazione provoca un overflow, allora va restituita la stringa `"*** Too Big ***"`.

```csharp
CentralBank.DisplayDenomination(10000L, 1000L);
// => "10000000"
CentralBank.DisplayDenomination(long.MaxValue / 2, 10000L);
// => "*** Too Big ***"
```

## 2. Mostra il PIL di Hyperia

Per registrare il PIL internamente, la banca centrale usa lo stesso approccio del moltiplicatore. Le statistiche vengono registrate in un taglio base e poi scalate usando il moltiplicatore.

Implementa il metodo `CentralBank.DisplayGDP()`: riceve il PIL di base e il moltiplicatore corrente e restituisce il PIL come stringa.

Se il PIL non può essere calcolato, viene restituito `"*** Too Big ***"`.

```csharp
CentralBank.DisplayGDP(555f, 10000f);
// => "5550000"
CentralBank.DisplayGDP(float.MaxValue / 2, 10000f);
// => "*** Too Big ***"
```

## 3. Mostra lo stipendio del capo economista

Il tuo capo in banca vuole assicurarsi che non ci siano problemi al momento delle buste paga.

Implementa il metodo `CentralBank.DisplayChiefEconomistSalary()`, che riceve uno stipendio espresso in unità base (come sopra) e un moltiplicatore e restituisce una stringa contenente il prodotto.

Se lo stipendio non può essere calcolato, viene restituito `"*** Much Too Big ***"`.

```csharp
CentralBank.DisplayChiefEconomistSalary(555000m, 10000m);
// => "5550000000"
CentralBank.DisplayChiefEconomistSalary(555000m, decimal.MaxValue / 2L);
// => "*** Much Too Big ***"
```
