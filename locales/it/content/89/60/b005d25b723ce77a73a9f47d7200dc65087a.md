# Introduzione

## I moduli

Finora tutti gli esercizi che hai visto hanno usato le classi.
A volte non abbiamo bisogno del sovraccarico di creare un oggetto con stato, quindi usiamo `module`.

Un modulo è molto simile a una classe (in effetti, `Module` è il genitore di `Class` nella gerarchia degli oggetti): la differenza principale è che invece dei metodi di istanza usiamo i metodi di classe.
I metodi di classe iniziano con `self.` e vengono chiamati direttamente su un modulo.

Per esempio:

```ruby
module Speaker
  def self.echo(something)
    "#{something} ... #{something}"
  end
end

Speaker.echo("Hello")   #=> "Hello ... Hello"
```

## I cicli

In Ruby ci sono diversi modi per scrivere dei cicli, ma dato che in generale tendiamo a usare l'enumerazione invece dei cicli, il ciclo che si incontra più spesso è forse il ciclo `while`:

```ruby
counter = 0

while counter < 5
  counter += 1
end
```

Puoi anche usare il suo fratello `until`

```ruby
counter = 0

until counter == 5
  counter += 1
end
```
