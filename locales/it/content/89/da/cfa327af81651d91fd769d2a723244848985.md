# Istruzioni

Prendi un array annidato e restituisci un unico array appiattito con tutti i valori tranne nil/null.

La sfida è prendere una struttura simile a un array, annidata a una profondità arbitraria, e produrre una struttura appiattita senza alcun valore nil/null.

Per esempio:

input: [1,[2,3,null,4],[null],5]

output: [1,2,3,4,5]
