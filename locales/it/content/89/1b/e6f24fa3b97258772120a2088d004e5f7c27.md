# Test

Dato che OCaml è un linguaggio compilato, devi compilare la soluzione e il codice dei test prima di poter eseguire i test.
Usiamo [`dune`](https://dune.build/) per la compilazione.
Ogni cartella contiene un file dune che specifica come eseguire la build e anche un Makefile che delega a dune.

Per compilare ed eseguire i test, basta digitare dalla cartella dell'esercizio:

```bash
make
```

## Creare il primo modulo OCaml

Per creare un modulo che possa essere usato con il test dell'esercizio `bob`, inserisci quanto segue in un file chiamato `bob.ml`:

```ocaml
open Base 

let response_for input = failwith "TODO"
```
