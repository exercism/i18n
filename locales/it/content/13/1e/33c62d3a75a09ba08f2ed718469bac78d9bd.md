# Installazione

Il track del linguaggio C richiede che tu abbia installato sul tuo sistema il seguente software:

* Un compilatore C moderno
* Lo strumento di compilazione Make

L'IDE Xcode di Apple combina il compilatore e il sistema di compilazione nativo in un unico IDE (ambiente di sviluppo integrato).
Gli ambienti Linux, invece, espongono di solito il compilatore e il sistema di compilazione nativo come strumenti separati a riga di comando.

## Linux

Gli utenti Linux avranno bisogno di gcc o clang come compilatore, mentre per la compilazione nativa servirà `make`.
Make è preinstallato sulla maggior parte dei sistemi Unix, ma è molto probabilmente disponibile tramite il gestore di pacchetti.
Sulle distribuzioni basate su Debian e Ubuntu, se non è già presente, puoi installare tutto il necessario con `sudo apt-get install build-essential`.

## MacOS

Gli utenti MacOS possono installare gcc o clang con [Homebrew][] tramite `brew install gcc` o `brew install llvm`.

## Windows

Agli utenti di Windows 10 consigliamo di usare il [Windows Subsystem for Linux][] e di seguire le istruzioni per Linux qui sopra.

Se usi una versione precedente di Windows o WSL Bash non è disponibile, puoi ricorrere a [MSYS][] o [mingw-w64][].

[Homebrew]: https://brew.sh
[Windows Subsystem for Linux]: https://docs.microsoft.com/en-gb/windows/wsl/about
[MSYS]: https://www.msys2.org
[mingw-w64]: http://mingw-w64.org
