# Istruzioni

Continuando il tema del gioco _wizards and warriors_, è il momento di aggiungere un metodo per lanciare i dadi adatto a qualsiasi evenienza. Sarà il tradizionale dado a 18 facce con i numeri da 1 a 18. I giocatori generano anche una forza dell'incantesimo.

## 1. Consentire a un giocatore di _wizards and warriors_ di lanciare un dado.

Implementa un metodo `RollDie()` sulla classe `Player`.

```csharp
var player = new Player();
player.RollDie();
// => >= 1 <= 18
```

## 2. I giocatori hanno bisogno della loro forza. Fornisci un modo per generare la forza dell'incantesimo

Implementa un metodo `GenerateSpellStrength()` sulla classe `Player`. La forza dell'incantesimo è compresa tra 0.0 e 100.0, escluso quest'ultimo.

Nota che la forza dell'incantesimo deve essere un numero reale (non un numero intero) per ridurre la possibilità di un pareggio quando si confrontano le forze di due avversari.

```csharp
var player = new Player();
player.GenerateSpellStrength();
// => >= 0.0 < 100.0
```
