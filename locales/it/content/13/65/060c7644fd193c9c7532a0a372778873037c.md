# Snippet Extractor

Il [Snippet Extractor][snippet-extractor] prende la soluzione inviata da uno studente e ne estrae le prime dieci righe di codice «interessanti».
Lo snippet estratto viene mostrato in diverse pagine del sito.

Per impostazione predefinita vengono mostrate le prime dieci righe, ignorando le righe vuote iniziali.
Queste prime dieci righe _potrebbero_ includere elementi come i commenti, che di solito non sono l'ideale da mostrare in uno snippet.

## Personalizzare l'estrazione degli snippet

Consigliamo a ogni track di [personalizzare l'estrazione degli snippet][snippet-extractor-customize], almeno per rimuovere i commenti dal codice sorgente.
Per personalizzare l'estrazione degli snippet, dovrai:

1. Aggiungere un file `lib/languages/<track_slug>.txt` che configura l'estrazione degli snippet.
   Questo file può usare la [modalità base][basic-mode] oppure la [modalità estesa][extended-mode].
   La maggior parte dei track usa la modalità estesa, perché offre maggiore flessibilità.
2. Aggiungere uno o più casi di test a una directory `tests/<track_slug>/<test_slug>`.
   Ogni directory di test dovrà contenere due file:

   1. `tests/<track_slug>/<test_slug>/code.<track_extension>`: il codice su cui eseguire il Snippet Extractor
   2. `tests/<track_slug>/<test_slug>/expected_snippet.<track_extension>`: lo snippet atteso

Guarda [questa pull request di esempio][example-pr] che personalizza l'estrazione degli snippet per il linguaggio Arturo.
