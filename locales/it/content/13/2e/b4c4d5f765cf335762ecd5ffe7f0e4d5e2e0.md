# Aiuto

## Eseguire i test

Il track Factor usa **Factor 0.101**. Dopo averlo
[installato](https://exercism.org/docs/tracks/factor/installation),
esegui dalla directory di questo esercizio:

```
factor -roots=. -run=exercism-tools <exercise>
```

Ad esempio, per `hello-world`:

```
factor -roots=. -run=exercism-tools hello-world
```

Ogni esercizio include un piccolo vocabolario `exercism-tools`
che guida l'esecuzione dei test. Il runner termina con stato 0
quando tutti i test passano, e con uno stato diverso da zero più
un output diagnostico se un test fallisce.

### Test saltati

Per impostazione predefinita, viene eseguito solo il primo test.
Il meccanismo è la riga `STOP-HERE` nel file di test: in fase di
analisi sintattica dice al lexer di Factor di ignorare tutto
quello che segue, così il runner vede solo i test che stanno
sopra. Una volta che il primo test passa, puoi abilitare altri
test in due modi:

- **Elimina la riga `STOP-HERE`** per abilitare tutti i test
  rimanenti in una volta.
- **Sposta la riga `STOP-HERE` più in basso** per abilitare i
  test uno alla volta, o un task alla volta. Gli esercizi
  concettuali raggruppano i loro test sotto i marcatori `TASK:`;
  spostare `STOP-HERE` appena prima del prossimo `TASK:` è un
  passo naturale.

Quando tutti i test passano, hai risolto l'esercizio.

## Inviare la soluzione

Dalla directory dell'esercizio:

```
exercism submit <exercise>/<exercise>.factor
```

Ad esempio:

```
exercism submit hello-world/hello-world.factor
```

Se il file `.meta/config.json` dell'esercizio elenca più di un
file di soluzione (alcuni esercizi concettuali dividono una
soluzione in più file all'interno di un sotto-vocabolario
ausiliario), passa a `exercism submit` ogni file che hai
modificato.

## Inviare soluzioni incomplete

Puoi inviare una soluzione anche se i test falliscono: in questo
modo puoi vedere come altri hanno affrontato l'esercizio e
chiedere il feedback di un mentore su quello che hai fatto
finora.

## Ottenere più aiuto

- La [categoria Factor sul forum di Exercism](https://forum.exercism.org/c/programming/factor/)
  è il posto migliore per domande e feedback specifici del track.
- Il [Discord di Exercism](https://exercism.org/r/discord) ha
  canali sia per l'aiuto generale sia per i singoli track.
- La documentazione ufficiale di Factor è ricercabile ed esaustiva. Due buoni punti di partenza:
  - Il [manuale di Factor](https://docs.factorcode.org/content/article-handbook.html),
    in stile riferimento, organizzato per vocabolario.
  - Il [ricettario di Factor](https://docs.factorcode.org/content/article-cookbook.html),
    con esempi brevi e idiomatici per argomento.
- Il [tutorial su Factor](https://andreaferretti.github.io/factor-tutorial/)
  di Andrea Ferretti è un'introduzione rapida e amichevole al
  linguaggio e all'ambiente di sviluppo.
