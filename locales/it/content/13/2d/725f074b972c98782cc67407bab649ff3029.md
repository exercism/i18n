# Introduzione

## Manipolazione dei bit

Java ha degli operatori per manipolare i bit di un `byte`, `short`, `int`, `long` o `char`.

### Operatori di shift

Usa `<<` per spostare i bit a sinistra e `>>` per spostarli a destra.

```java
// Shift two places to the left
0b0000_1011 << 2;
// # => 0b0010_1100

// Shift two places to the right
0b0000_1011 >> 2;
// # => 0b0000_0010
```

L'operatore `<<` inserisce sempre degli 0 sul lato destro.
L'operatore `>>`, invece, inserisce lo stesso bit del bit più a sinistra (1 se il numero è negativo, 0 se è positivo).

```java
// Shift 2 places to the right preserves the sign
// This is a negative value, whose binary representation is
// 1000_0000_0000_0000_0000_0000_0010_0110
int value = -0x7FFFFFDA;

// Shift two places to the right, preserving the sign bit
value >> 2;
// # => 1110_0000_0000_0000_0000_0000_0000_1001
```

Usa `>>>` quando, spostando a destra, devono essere inseriti degli 0.

```java
// Shift two places to the right, inserting 0s on the left
value >>> 2;
// # => 0010_0000_0000_0000_0000_0000_0000_1001
```

### Operazioni bit a bit

#### AND bit a bit

L'operatore AND bit a bit (`&`) prende due valori ed esegue un AND su ogni bit.
Confronta ogni bit del primo valore con il bit nella stessa posizione del secondo valore.
Se entrambi sono 1, il bit del risultato è 1.
Altrimenti, il bit del risultato è 0.

```java
0b0110_0101 & 0b0011_1100;
// # => 0b0010_0100
```

#### OR bit a bit

L'operatore OR bit a bit (`|`) prende due valori ed esegue un OR su ogni bit.
Confronta ogni bit del primo valore con il bit nella stessa posizione del secondo valore.
Se almeno uno dei due bit è 1, il bit del risultato è 1.
Altrimenti è 0.

```java
0b0110_0101 | 0b0011_1100;
// # => 0b0111_1101
```

#### XOR bit a bit

L'operatore XOR bit a bit (`^`) esegue un XOR bit a bit su due valori.
Come gli operatori AND bit a bit e OR bit a bit, confronta ogni bit del primo valore con il bit nella stessa posizione del secondo valore.
Se solo uno dei due è 1, il bit risultante è 1.
Altrimenti è 0.

```java
0b0110_0101 ^ 0b0011_1100;
// # => 0b0101_1001
```

#### NOT bit a bit(`~`)

Infine, l'operatore NOT bit a bit (`~`) inverte ogni bit.
A differenza degli operatori precedenti, questo è un operatore unario e agisce su un solo valore.

```java
~0b0110_0101;
// # => 0b1001_1010
```
