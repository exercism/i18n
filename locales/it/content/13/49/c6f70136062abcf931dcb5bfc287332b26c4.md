# Booleani

Haskell ha un tipo noto come [`Bool`][bools].
È un'enumerazione di `True` e `False`.

## Operatori logici

Haskell ha tre operatori logici (`not`, `||`, `&&`), che combinano i Bool e danno espressioni che producono valori diversi.

### E(`&&`)

L'[operatore _and_][and] in Haskell è rappresentato da `&&` e restituisce `True` se entrambi i valori sono `True`; altrimenti restituisce `False`.
Quando si usa l'operatore _and_, un Bool si mette a destra del `&&` e un altro a sinistra.

```haskell
True && True
-- -> True

True && False
-- -> False
```

### O(`||`)

L'[operatore _or_][or] in Haskell è rappresentato da `||` e restituisce `True` se **almeno uno** dei valori dati è `True`.
Se entrambi i valori sono `False`, restituisce `False`.
Quando si usa l'operatore _or_, un Bool va messo a destra del `||` e un altro a sinistra.

```haskell
True || True
-- -> True

True || False
-- -> True

False || False
-- -> False
```

### Non(`not`)

L'operatore _not_ in Haskell è rappresentato da `not` e restituisce `True` se il Bool dato è `False`, mentre restituisce `False` se riceve `True`.
Quando si usa l'operatore _not_, un Bool va messo dopo l'operatore (`not`).

```haskell
not True
-- -> False

not False
-- -> True
```

## Usare le parentesi(`()`)

Quando lavori con i booleani, puoi usare le parentesi per decidere quali Bool valutare per primi.
Il risultato può cambiare a seconda di come si usano le parentesi.
In Haskell, quello che sta tra parentesi viene valutato per primo.

```haskell
True && False && False || True
-- -> True

True && False && (False || True)
-- -> False
```

Dato che ciò che sta tra parentesi viene valutato per primo, nel prossimo esempio l'operatore _not_ si applicherà all'espressione dentro le parentesi.

```haskell
not True && False
-- -> False

not (True && False)
-- -> True
```

~~~~exercism/note
Usa le parentesi solo quando influenzano il risultato; altrimenti è meglio ometterle.
