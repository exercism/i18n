# Introduzione

## Tabelle hash

Le tabelle hash in Common Lisp sono strutture dati per memorizzare dati associativi.
Mappano chiavi (che possono essere qualsiasi oggetto) a valori (che possono essere qualsiasi oggetto).
Altri linguaggi possono riferirsi a questo concetto con i nomi «map», «dictionary» o «hash».

### Creare tabelle hash

Le tabelle hash si possono creare con la funzione `make-hash-table`.

`(make-hash-table) ; => #<HASH-TABLE :TEST EQL :COUNT 0 {10024AD2B3}>`

(Nota: la rappresentazione stampata di una tabella hash dipende dall'implementazione, quindi potrebbe apparire diversamente nella tua REPL.)

### Ottenere i valori tramite le chiavi

Per ottenere un valore a partire da una chiave della tabella hash si usa la funzione `gethash`:

```lisp
*h* ; => #<HASH-TABLE :TEST EQL :COUNT 3 {10024AD2B3}>`
(gethash :foo *h*) ; => :bar
                   ;    T
```

`gethash` restituisce [valori multipli][concept-multiple-values], che saranno spiegati in un altro concetto.

### Inserire valori

Per inserire un valore in una tabella hash si usa `setf` insieme a `gethash`, così:

`(setf (gethash :foo *hash-table*) :bar) : => :bar`

Questo modifica il valore della chiave `:foo` nella tabella hash `*hash-table*` impostandolo a `:bar`.
Restituisce il valore.

L'uso di `setf` sarà spiegato in un altro concetto.
