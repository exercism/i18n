# Appendice alle istruzioni

## Registri

| Registro | Utilizzo  | Tipo    | Descrizione                   |
| -------- | --------- | ------- | ----------------------------- |
| `$a0`    | input     | indirizzo | array dei fattori             |
| `$a1`    | input     | intero  | numero di fattori             |
| `$a2`    | input     | intero  | limite                        |
| `$v0`    | output    | intero  | somma dei multipli entro il limite |
| `$t0-9`  | temporaneo | qualsiasi | usato per memorizzazione temporanea    |
