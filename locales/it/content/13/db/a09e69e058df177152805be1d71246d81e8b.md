# Istruzioni

Il tuo club di netball deve calcolare la classifica dopo ogni giornata.

Tutte e quattro le attività vanno nella classe `NETBALL_LADDER`.

## 1. Punti in classifica

Una vittoria vale 4 punti e un pareggio 2. Una sconfitta non vale nulla.

```sather
NETBALL_LADDER::ladder_points(3, 1)
-- => 14
```

## 2. Differenza gol

I gol fatti meno i gol subiti. Può essere negativa.

```sather
NETBALL_LADDER::goal_difference(180, 205)
-- => -25
```

## 3. Quarti interi giocati

Un quarto dura 15 minuti. Dato un numero di minuti, quanti quarti interi sono?

```sather
NETBALL_LADDER::whole_quarters(38)
-- => 2
```

## 4. Minuti trascorsi nel quarto

Dato lo stesso numero di minuti, quanti minuti sono trascorsi nel quarto in corso?

```sather
NETBALL_LADDER::minutes_into_quarter(38)
-- => 8
```
