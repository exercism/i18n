# Suggerimenti

## Generale

- Prova a dividere un problema in un caso base e un caso ricorsivo
  Per esempio, diciamo che vuoi contare quanti biscotti ci sono nel barattolo dei biscotti con un approccio ricorsivo
  Un caso base è un barattolo vuoto: contiene zero biscotti.
  Se il barattolo non è vuoto, allora il numero di biscotti nel barattolo è uguale a un biscotto più il numero di biscotti nel barattolo dopo aver rimosso un biscotto.

## 1. Implementa una funzione che somma i numeri di un array

- La ricorsione consiste nell'iterare sugli elementi dell'array, aggiungendo ciascuno a un accumulatore.
- Il caso base è un array vuoto, la cui somma è uguale a zero.
- Il caso ricorsivo aggiunge il primo elemento alla somma del resto dell'array.
- Ripassa l'indicizzazione e lo slicing degli array da [il concetto di array][arrays-concept] per separare il primo elemento dell'array dal resto degli elementi.

## 2. Inverti un array

- La ricorsione consiste nell'iterare sugli elementi dell'array, aggiungendo ciascuno a un altro array in ordine inverso.
- Il caso base è un array vuoto.
- Ricorda che l'[operatore `+`][manual-addition] concatena quando viene applicato agli array.

## 3. Mappa un array

- La ricorsione consiste nell'iterare sugli elementi dell'array, aggiungendo a un array accumulatore il risultato dell'applicazione del filtro all'elemento.
- Per applicare il parametro filtro a un elemento, usa la solita sintassi con la pipe: `.element | filter`.
- Il caso base è un array vuoto.

[arrays-concept]: https://exercism.org/tracks/jq/concepts/arrays
[manual-addition]: https://jqlang.org/manual/#addition
