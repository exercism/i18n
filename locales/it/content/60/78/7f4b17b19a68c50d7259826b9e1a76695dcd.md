# Suggerimenti

## Generale

- Leggi la documentazione ufficiale degli [intervalli][range].

## 1. Definisci l'intervallo dei rank

- Esiste un [operatore speciale][range-creation-operator] per creare gli intervalli.

## 2. Definisci l'intervallo dei file

- Esiste un [operatore speciale][range-creation-operator] per creare gli intervalli.
- Esiste una [sintassi speciale][unicode-code-points] per scrivere il code point di un carattere senza conoscerne esplicitamente il valore.

## 3. Trasforma l'intervallo dei rank in un array di rank

- Gli intervalli implementano il protocollo `Enumerable`.
- Esiste una [funzione integrata][enum-to-list] per trasformare una struttura dati enumerabile in un array.

## 4. Trasforma l'intervallo dei file in un array di file

- Gli intervalli implementano il protocollo `Enumerable`.
- Esiste una [funzione integrata][enum-map] per trasformare una struttura dati enumerabile in un array modificandone gli elementi.
- La [forma speciale bitstring][bitstring-special-form] può essere usata per convertire un code point in una stringa.
