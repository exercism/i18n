# Introduzione

Quando un valore lascia il programma (su un cavo, in un file di log, attraverso un socket), deve essere *testo*. Tre idiomi di Factor ricorrono di continuo quando si impacchettano valori da trasmettere: il serializzatore `unparse`, le varianti slice, che permettono di vedere una sequenza senza copiarla, e i combinatori cleave a più input, che ti consentono di proiettare diversi campi dallo stack in un'unica espressione.

```factor
USING: combinators kernel prettyprint sequences strings ;

123 unparse .                          ! => "123"
"NS-1024" 2 head-slice >string .       ! => "NS"
1 2 [ + ] [ - ] 2bi . .
! => -1
! => 3
```

`unparse` è l'inverso del parser di Factor: `dup unparse parse` fa andata e ritorno. `head-slice` restituisce una *vista* (un oggetto `slice`) invece di allocare una sequenza nuova come fa `head`: torna utile quando devi soltanto guardare una regione. `2bi`, `3bi`, `2tri` e `3tri` estendono la famiglia cleave a due o tre input dello stack.
