# Informazioni

L'enumerazione è l'atto di scorrere una collezione (`Array`, `Hash`, ecc.) ed eseguire un'azione su ogni oggetto.

L'enumerazione è un concetto chiave in Ruby e viene usata per ordinare (`sort_by`), raggruppare (`group_by`), mappare (`map`), ridurre (`reduce`) e molto altro.
Molto spesso vedrai l'enumerazione come il modo idiomatico di iterare sulle collezioni invece di usare i cicli.

Una semplice enumerazione per stampare ogni parola di un array si presenta così:

```ruby
words = %w[the cat sat on the mat]
words.each do |word|
  puts word
end

# Output:
# the
# cat
# sat
# on
# the
# mat
```

In questo esempio, abbiamo chiamato il metodo `Array#each` e passato un _blocco_, che riceve un parametro (`word`) e lo stampa.

Possiamo anche concatenare i metodi enumerabili.
Per esempio, possiamo concatenare `.with_index` a `each` per stampare anche l'indice di un oggetto oltre al suo valore:

```ruby
words = %w[the cat sat on the mat]
list = words.map.with_index { |word, index| "#{index}. #{word}" }
puts list

# Output:
# 0. the
# 1. cat
# ...
# 5. mat
```

Enumerare oggetti `Hash` è esattamente lo stesso che enumerare oggetti `Array`, tranne che il blocco riceve due argomenti: la chiave e il valore:

```ruby
pet_names = {cat: "bob", horse: "caris", mouse: "arya"}
words.each { |animal, name| ... }

# The two arguments should be put in brackets when chaining
words.each.with_index { |(animal, name), index| ... }
```

I metodi descritti sopra fanno parte del [modulo `Enumerable`][enumerable-module], che è incluso in `Array`, `Hash` e altre classi che richiedono la capacità di enumerare.

[enumerable-module]: https://docs.ruby-lang.org/en/master/Enumerable.html
