# Introduzione

## Confronto

In Go i numeri si possono confrontare usando i seguenti operatori relazionali e di uguaglianza.

| Confronto         | Operatore |
| ------------------| --------- |
| uguale            | `==`      |
| non uguale        | `!=`      |
| minore            | `<`       |
| minore o uguale   | `<=`      |
| maggiore          | `>`       |
| maggiore o uguale | `>=`      |

Il risultato del confronto è sempre un valore booleano, quindi `true` oppure `false`.

```go
a := 3

a != 4 // true
a > 5  // false
```

Gli operatori di confronto visti sopra si possono usare anche per confrontare le stringhe.
In quel caso si applica un ordine lessicografico (da dizionario).
Per esempio:

```Go
	"apple" < "banana"  // true
	"apple" > "banana"  // false
```

## Istruzioni if

Le condizioni in Go sono simili a quelle di altri linguaggi.
Il tipo sottostante di qualsiasi operazione condizionale è il tipo `bool`, che può avere il valore `true` o `false`.
Le condizioni sono spesso usate come meccanismi di controllo del flusso per verificare varie situazioni.

Per verificare un caso particolare si può usare un'istruzione `if`, che esegue il suo codice se la condizione sottostante è `true`, in questo modo:

```go
var value string

if value == "val" {
    return "was val"
}
```

Quando i casi sono più di uno, si possono concatenare più istruzioni `if` usando le istruzioni `else if` ed `else`.

```go
var number int
result := "This number is "

if number > 0 {
    result += "positive"
} else if number < 0 {
    result += "negative"
} else {
    result += "zero"
}
```

Le istruzioni `if` possono anche includere una breve istruzione di inizializzazione, che può servire a inizializzare una o più variabili per l'istruzione `if`.
Per esempio:

```go
num := 7
if v := 2 * num; v > 10 {
    fmt.Println(v)
} else {
    fmt.Println(num)
}
// Output: 14
```

> Nota: le variabili create nell'istruzione di inizializzazione escono dallo scope dopo la fine dell'istruzione if.
