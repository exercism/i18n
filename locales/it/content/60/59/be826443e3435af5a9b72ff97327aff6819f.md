# Test

Se hai il binario phix nel path, digita il comando:

```bash
p test 
```

Questo eseguirà il file di test (test.exw).

Se il binario phix non è nel PATH, in Windows digita

```cmd
\path\to\p.exe test
```

Linux:

```bash
/path/to/p test
```

## Test saltati

Risolvere un esercizio significa far passare tutti i suoi test.
Per impostazione predefinita, tutti i test nel file test.exw vengono eseguiti.
Per saltare un test, anteponi due trattini (il marcatore standard dei commenti di Phix) all'inizio della riga.

Tieni presente che i test non rispettano alcun flag include=false in tests.toml: è responsabilità di chi scrive test.exw mantenerli manualmente in quel file, per rispecchiare la realtà a beneficio del sito di Exercism (ad esempio per raccogliere le statistiche della track). Nulla nella track stessa ne fa uso in alcun modo, incluso nello specifico il generatore di test e il test runner.
