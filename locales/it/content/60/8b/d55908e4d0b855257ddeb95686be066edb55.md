# Introduzione

Un [`Attribute` di C#](https://docs.microsoft.com/en-us/dotnet/csharp/programming-guide/concepts/attributes/) offre un modo per decorare una dichiarazione e associarle dei metadati: una classe, un metodo, un enum, un campo, una proprietà o qualsiasi altra [dichiarazione supportata](https://docs.microsoft.com/en-us/dotnet/csharp/programming-guide/concepts/attributes/#attribute-targets).

Puoi applicare un attributo aggiungendolo sulla riga precedente alla dichiarazione, con un `ClassAttribute` e un `FieldAttribute`:

```csharp
[Class]
class MyClass
{
    [Field]
    int myField;
}
```

Questi metadati dichiarativi si limitano ad associare al codice ulteriori informazioni strutturate e non ne modificano il comportamento. Tuttavia, altre parti del codice usano questi metadati per cambiare il comportamento del loro target, oppure per aggiungere, modificare, rimuovere o limitare alcune delle sue funzionalità.

Esistono molti [attributi predefiniti e riservati](https://docs.microsoft.com/en-us/dotnet/csharp/language-reference/attributes/general#conditional-attribute), per esempio: `Flags`, `Obsolete`, `Conditional`. Ognuno ha una funzione specifica che puoi cercare nella documentazione di C#. Nota che, per convenzione, il nome completo di un attributo come [`Flags`](https://docs.microsoft.com/en-us/dotnet/api/system.flagsattribute) è `FlagsAttribute`, ma il suffisso _Attribute_ può essere omesso quando lo si applica a una dichiarazione.
