# Suggerimenti

## Generale

- Le parole di lettura si trovano in [`io`][io]; i costruttori di
  stream di stringhe e `with-string-writer` si trovano in
  [`io.streams.string`][io.streams.string].
- Per l'attività che svuota il writer, le variabili locali (`::` e `:>`)
  mantengono il corpo leggibile quando devi accedere due volte allo
  stesso stream.

## 1. Ascoltare tutto

- Una sola parola: `stream-contents`.

## 2. Contare i messaggi

- `stream-lines` divide lo stream in un array di righe;
  `length` restituisce il conteggio.

## 3. Ripetere l'ultima chiamata

- Lo stesso `stream-lines` di prima, poi `last`, poi `>upper` (da
  `ascii`).

## 4. Trasmettere un messaggio

- `stream-write` scrive il messaggio, `stream-flush` lo spinge
  fuori. Il writer viene usato due volte, quindi ricorri alle
  variabili locali `::`:
  `:: broadcast ( message writer -- ) message writer stream-write
  writer stream-flush ;`.

## 5. Catturare l'output di una quotation

- Una sola parola: `with-string-writer`. Aggiungi `inline` dopo il
  `;` di chiusura, così il compilatore può vedere attraverso
  l'argomento quotation:
  `: capture ( quot -- captured ) with-string-writer ; inline`.
