# Parole chiave statiche di classe

Una classe è un'unità di organizzazione del codice in PHP, che spesso rappresenta un'istanza di una cosa/servizio/procedura.
Usando le parole chiave `static` e `self`, proprietà e metodi possono esistere in riferimento alla classe per tutte le istanze (o per nessuna istanza).

```php
<?php

class Book
{
    static $genre = 'Adventure';

    static function getGenre()
    {
        return self::$genre;
    }
}

// Usage
$genre = Book::$genre;
$genre = Book::getGenre();
```

## Limitazione

I metodi statici di classe possono chiamare solo altre proprietà statiche o metodi di classe della propria classe.

```php
<?php

class Book
{
    $name = 'Treasure Island';

    static function getName()
    {
        // This static method cannot access the instance variable
        return $this->name;
    }
}
```
