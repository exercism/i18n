# Test

Per eseguire i test dall'interno della directory dell'esercizio, esegui il comando:

```sh
odin test .
```

Mentre esegui i test, Odin può fare il «vet» del codice: può cercare cose come import e variabili inutilizzati. Esegui i test con:

```sh
odin test . -vet
```

Per ulteriori opzioni, vedi `odin test -help`.
