# Introduzione

Le parole più utili per le sequenze prendono una *quotation* come uno dei loro input e la usano per guidare l'operazione:

```
each   ( seq quot -- )
map    ( seq quot -- newseq )
filter ( seq quot -- newseq )
reject ( seq quot -- newseq )
count  ( seq quot -- n )
any?   ( seq quot -- ? )
all?   ( seq quot -- ? )
```

```factor
{ 1 2 3 4 5 } [ even? ] filter .   ! => { 2 4 }
{ 1 2 3 4 5 } [ sq ] map .         ! => { 1 4 9 16 25 }
{ 1 2 3 4 5 } [ 2 > ] count .      ! => 3
```

`map-sum` (anch'essa in `sequences`) applica una quotation lungo la sequenza e somma i risultati in un solo passaggio. Lo stesso schema guida `sort-by` (in [`sorting`][sorting]) e `minimum-by` / `maximum-by` (in `sequences`).

[sorting]: https://docs.factorcode.org/content/vocab-sorting.html
