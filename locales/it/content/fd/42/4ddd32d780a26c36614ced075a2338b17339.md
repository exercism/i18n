# Istruzioni

Sei un grande fan del [canale YouTube Numberphile](https://www.youtube.com/watch?v=PeUbRXnbmms) e hai appena visto un video interessante sulla _sequenza dei numeri di Lucas_. Vuoi creare questa sequenza usando Elixir.

Mentre progetti la funzione, vuoi sfruttare la _valutazione pigra_: così puoi generare tutti i numeri che vuoi, ma solo quando ti servono. Per questo decidi di usare uno stream.

## 1. Intercettare gli argomenti non validi

Aggiungi una guard clause per sollevare un errore se si prova a generare la sequenza con un valore non intero o con un intero minore di 1. Farlo come primo passo eviterà bug di ricorsione infinita nei passi successivi.

```elixir
LucasNumbers.generate("Hello World")
# => ** (ArgumentError) count must be specified as an integer >= 1
```

## 2. Generare i casi base

Sai che la sequenza ha due numeri iniziali che non seguono la stessa regola. Scrivi due clausole per i casi base che restituiscano questi numeri:

```elixir
LucasNumbers.generate(1)
# => [2]

LucasNumbers.generate(2)
# => [2, 1]
```

## 3. Creare il caso generalizzato

Per qualsiasi sequenza più lunga di 2, sai che devi sommare i due numeri precedenti per ottenere il numero successivo, e così via. Scrivi il caso generalizzato.

```elixir
LucasNumbers.generate(3)
# => [2, 1, 3]

LucasNumbers.generate(4)
# => [2, 1, 3, 4]
```
