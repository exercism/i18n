# Introduzione

Per definire una funzione globale in Common Lisp si usa l'espressione `defun`.
Questa espressione prende come primo argomento una lista di parametri (una lista vuota significa che la funzione non ha parametri).
Segue poi una stringa di documentazione facoltativa (vedi più avanti), quindi zero o più espressioni che costituiscono il «corpo» della funzione.

Le funzioni possono avere zero o più parametri.

```lisp
(defun no-args () (+ 1 1))

(defun add-one (x) (1+ x))

(defun add-nums (x y) (+ x y))
```

Per chiamare una funzione si valuta un'espressione che ha come primo elemento il simbolo che designa la funzione e come elementi rimanenti gli argomenti della funzione (se ce ne sono).

Il valore a cui si valuta una funzione è il valore dell'ultima espressione valutata nel corpo della funzione.
Tutte le funzioni si valutano in un valore.

```lisp
(add-nums 2 2) ;; => 4
```

Le funzioni possono anche avere, facoltativamente, una stringa di documentazione (detta anche «docstring»).
Se presente, va dopo la lista degli argomenti ma prima del corpo della funzione.
Alla stringa di documentazione si può accedere tramite `documentation`.

```lisp
(defun add-nums (x y) "Add X and Y together" (+ x y))

(documentation 'add-nums 'function) ;; => "Add X and Y together"

;; Note that if one provides a docstring but fails to provide a body
;; then the docstring is interpreted by Common Lisp as the body, not
;; the docstring
(defun no-body ())
(no-body) ;; => NIL

(defun mistake () "This is not a docstring")
(mistake) ;; => "This is not a docstring"
(documentation 'mistake 'function) ;; => NIL
```
