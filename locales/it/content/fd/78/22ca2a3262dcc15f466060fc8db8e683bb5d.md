# Introduzione

Swift ha una serie di istruzioni che possono essere usate per modificare il normale flusso di controllo dei cicli.
Sono note come istruzioni di trasferimento del controllo.
Hai già visto `return`; in questo concetto ne introdurremo altre, tra cui `continue`, `break` e le etichette.
Non tratteremo `fallthrough` in questo concetto, ma puoi leggere qualcosa a riguardo nel [libro di Swift][fallthrough].

## Continue

A volte è necessario passare subito all'iterazione successiva di un ciclo, senza completare le restanti istruzioni dell'iterazione corrente.
Per farlo si può usare la parola chiave `continue`.
Quando `continue` viene eseguito, il ciclo salta al controllo successivo per verificare se l'iterazione seguente può essere eseguita, cioè il `while` nei cicli while e repeat-while oppure il controllo che ci sia un altro elemento nella sequenza nei cicli for-in.

```swift
count = 1
while count < 6 {
  count += 1
  if count == 4 { continue }
  print(count)
}

// prints:
// 2
// 3
// 5
```

## Break

`break` si usa per uscire anticipatamente da un ciclo.
Quando `break` viene eseguito, il ciclo termina immediatamente e il programma prosegue con la prima istruzione dopo il ciclo.

```swift
for fruit in ["banana", "grapes", "apple", "strawberry", "kiwi", "lemon"] {
  if !fruit.count.isMultiple(of: 2) { break }
  print(fruit)
}

// prints:
// banana
// grapes
```

## Etichette

Quando i cicli sono annidati, può capitare di voler usare `break` o `continue` per uscire o riavviare i cicli esterni che contengono il ciclo in cui sono usati `break` o `continue`.
In casi come questi, si possono usare le etichette per specificare il ciclo da terminare o da riavviare.
Un ciclo può essere etichettato mettendo un nome seguito da due punti prima del `while`, del `repeat` o del `for` che lo avvia.

Per vedere l'effetto dell'uso delle etichette in questo modo, considera il seguente ciclo.

```swift
outerLoop: for fruit in ["banana", "grapes", "apple", "strawberry", "kiwi", "lemon"] {
  print("\n--- \(fruit) ---")
  for letter in fruit {
    guard letter != "n" else { break outerLoop }
    print(letter)
  }
}

// prints:
// --- banana ---
// b
// a
```
