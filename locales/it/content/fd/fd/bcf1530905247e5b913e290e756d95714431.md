# Introduzione

Un *heap* è una collezione che conosce sempre il suo elemento più piccolo e ti permette di rimuoverlo rapidamente: è l'implementazione naturale di una *coda con priorità*. Gli heap si trovano nel vocabolario [`heaps`][heaps].

`<min-heap>` costruisce un heap vuoto la cui chiave più piccola esce per prima; `<max-heap>` è l'immagine speculare. Ogni elemento è un *valore* associato a una *chiave*, e la chiave è la priorità:

```
<min-heap> ( -- min-heap )
heap-push  ( value key heap -- )
```

```factor
USING: heaps ;

<min-heap>
"alice" 5 pick heap-push
"bob"   2 pick heap-push
```

Un heap è *mutabile*: `heap-push` lo modifica sul posto. `heap-peek` restituisce il valore e la chiave in testa senza rimuoverli, `heap-pop` li rimuove e li restituisce, e `heap-pop-all` svuota l'heap in una lista di associazioni di coppie `{ key value }` in ordine di priorità:

```
heap-peek    ( heap -- value key )
heap-pop     ( heap -- value key )
heap-pop-all ( heap -- alist )
```

```factor
USING: heaps kernel prettyprint ;

<min-heap>
"alice" 5 pick heap-push
"bob"   2 pick heap-push
dup heap-peek drop .     ! => "bob"
heap-pop-all .           ! => { { 2 "bob" } { 5 "alice" } }
```

[heaps]: https://docs.factorcode.org/content/vocab-heaps.html
