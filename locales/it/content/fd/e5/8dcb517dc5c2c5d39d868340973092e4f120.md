# Introduzione

In Go, una costante è un valore semplice e immutabile assegnato a un nome con la parola chiave `const`:

```go
const myWebsite = "Exercism"
```

Tali costanti non sono tipizzate, ma ricevono un tipo predefinito basato sulla loro sintassi quando serve un tipo, ad esempio quando vengono passate a un metodo.
Le costanti tipizzate si possono creare aggiungendo esplicitamente un tipo:

```go
const myWebsite string = "Exercism"
```

Go non ha gli enum come alcuni altri linguaggi, ma ha un identificatore predeclarato chiamato `iota` per creare costanti enumerate.
Le costanti in un blocco vengono ripetute implicitamente:

```go
const (
    a = 9
    b
    c
    d = iota
    e
    f
    g
)
fmt.Print(a, b, c, d, e, f, g)
// Output: 9 9 9 3 4 5 6
```
