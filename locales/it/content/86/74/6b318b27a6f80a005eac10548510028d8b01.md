# Istruzioni

In questo esercizio lavorerai a un pianificatore di appuntamenti per un salone di bellezza di New York, aperto il 15 settembre 2012.

Hai quattro compiti, che riguarderanno tutti le date degli appuntamenti. Le date e gli orari useranno uno dei tre formati seguenti:

- `"7/25/2019 13:45:00"`
- `"July 25, 2019 13:45:00"`
- `"Thursday, July 25, 2019 13:45:00"`

I test imposteranno automaticamente la cultura su `en-US`: non devi impostare né specificare la cultura da solo.

## 1. Analizza la data dell'appuntamento

Implementa il metodo (_statico_) `Appointment.Schedule()` per analizzare una rappresentazione testuale di una data di appuntamento nel corrispondente formato `DateTime`:

```csharp
Appointment.Schedule("7/25/2019 13:45:00")
// => new DateTime(2019, 7, 25, 13, 45, 0)
```

## 2. Controlla se un appuntamento è già passato

Implementa il metodo (_statico_) `Appointment.HasPassed()`, che prende una data di appuntamento e controlla se l'appuntamento è avvenuto in un momento del passato:

```csharp
Appointment.HasPassed(new DateTime(1999, 12, 31, 9, 0, 0))
// => true
```

## 3. Controlla se l'appuntamento è nel pomeriggio

Implementa il metodo (_statico_) `Appointment.IsAfternoonAppointment()`, che prende una data di appuntamento e controlla se l'appuntamento è nel pomeriggio (>= 12:00 e < 18:00):

```csharp
Appointment.IsAfternoonAppointment(new DateTime(2019, 03, 29, 15, 0, 0))
// => true
```

## 4. Descrivi l'ora e la data dell'appuntamento

Implementa il metodo (_statico_) `Appointment.Description()`, che prende una data di appuntamento e restituisce una descrizione di quella data e di quell'ora:

```csharp
Appointment.Description(new DateTime(2019, 03, 29, 15, 0, 0))
// => "You have an appointment on 3/29/2019 3:00:00 PM."
```

## 5. Restituisci la data dell'anniversario

Implementa il metodo (_statico_) `Appointment.AnniversaryDate()`, che restituisce la data dell'anniversario di quest'anno, cioè il 15 settembre:

```csharp
Appointment.AnniversaryDate()
// => new DateTime(2019, 9, 15, 0, 0, 0)
```
