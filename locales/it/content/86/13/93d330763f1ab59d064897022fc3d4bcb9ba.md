# Introduzione

La maggior parte dei dati in Factor vive nelle *sequences*. Gli array, i vettori e le stringhe sono tutte sequences e condividono un insieme comune di parole dal vocabolario [`sequences`][sequences].

## Array letterali

Un array letterale usa `{ }` con spazi bianchi tra gli elementi:

```factor
{ 1 2 3 } .          ! => { 1 2 3 }
{ "a" "b" "c" } .    ! => { "a" "b" "c" }
```

Gli array hanno lunghezza fissa, quindi parole come `suffix` e `remove-nth`, che cambiano il numero di elementi, restituiscono una *nuova* sequence invece di far crescere quella originale.

## Lunghezza e indicizzazione

```
length   ( seq -- n   )
first    ( seq -- elt )
rest     ( seq -- tailseq )    ! everything but the first element
last     ( seq -- elt )
but-last ( seq -- headseq )    ! everything but the last element
nth      ( n seq -- elt )      ! 0-based
?nth     ( n seq -- elt/f )    ! 0-based; f when out of bounds
```

```factor
{ 10 20 30 } length .       ! => 3
{ 10 20 30 } first .        ! => 10
{ 10 20 30 } rest .         ! => { 20 30 }
{ 10 20 30 } last .         ! => 30
{ 10 20 30 } but-last .     ! => { 10 20 }
1 { 10 20 30 } nth .        ! => 20
```

`?nth` è la versione sicura rispetto ai limiti: puoi sondare una posizione senza prima controllare la lunghezza.

```factor
1 { 10 20 30 } ?nth .       ! => 20
9 { 10 20 30 } ?nth .       ! => f  (out of bounds, no error)
```

## Sezioni

```
head ( seq n -- headseq )    ! first n elements
tail ( seq n -- tailseq )    ! drop first n
```

```factor
{ 1 2 3 4 5 } 3 head .   ! => { 1 2 3 }
{ 1 2 3 4 5 } 3 tail .   ! => { 4 5 }
```

Entrambi sollevano un errore se `n` è più grande della sequence. Se `n` è troppo grande, `index-or-length` lo riduce fino alla lunghezza della sequence, così la sezione che segue non può uscire dai limiti:

```
index-or-length ( seq n -- seq n' )
```

```factor
{ 10 20 30 40 50 } 3 index-or-length head .   ! => { 10 20 30 }
{ 10 20 } 3 index-or-length head .            ! => { 10 20 }
```

Le varianti con l'asterisco `head*` e `tail*` contano dalla fine: `head*` elimina gli ultimi `n`, `tail*` mantiene gli ultimi `n`:

```
head* ( seq n -- headseq )   ! everything except the last n
tail* ( seq n -- tailseq )   ! the last n elements
```

```factor
{ 1 2 3 4 5 } 2 head* .   ! => { 1 2 3 }
{ 1 2 3 4 5 } 2 tail* .   ! => { 4 5 }
```

Per una sezione arbitraria tra due indici, `subseq` prende l'*inizio* (incluso) e la *fine* (esclusa):

```
subseq ( from to seq -- subseq )
```

```factor
1 4 { 10 20 30 40 50 } subseq .   ! => { 20 30 40 }
1 4 "hello" subseq .              ! => "ell"
```

Quando hai un *inizio e una lunghezza*, sommali per ottenere la fine:

```factor
2 dup 3 + "hello world" subseq .  ! => "llo"
```

(Questo è l'intervallo di indici `[2, 5)`, tre caratteri che partono dalla posizione 2.)

La domanda inversa, cioè *dove* compare una sottosequenza, trova risposta in `subseq-index`, che restituisce l'indice iniziale della prima corrispondenza, oppure `f` quando non ce n'è nessuna:

```
subseq-index ( seq subseq -- i/f )
```

```factor
"hello world" "o w" subseq-index .   ! => 4
"hello world" "xyz" subseq-index .   ! => f
```

## Riempimento

```
pad-head ( seq n elt -- padded )    ! prepend copies of elt
pad-tail ( seq n elt -- padded )    ! append copies of elt
```

Entrambi estendono `seq` finché la sua lunghezza non è almeno `n`. Se `seq` ha già quella lunghezza, viene restituito senza modifiche.

```factor
{ 2 5 0 } 6 0 pad-tail .   ! => { 2 5 0 0 0 0 }
{ 4 1 } 5 9 pad-head .     ! => { 9 9 9 4 1 }
```

## Le stesse parole funzionano sulle stringhe

Una stringa è una sequence di caratteri, quindi tutto quanto sopra funziona anche sulle stringhe: il risultato è semplicemente un'altra stringa invece di un array:

```factor
"hello" length .            ! => 5
"hello" 3 head .             ! => "hel"
"abc" 6 CHAR: . pad-tail .   ! => "abc..."
```

## Aggregazione

`sum` e `product` (in [`sequences`][sequences]) sommano o moltiplicano gli elementi di una sequence numerica:

```factor
{ 2 5 0 7 } sum .        ! => 14
{ 2 5 3 7 } product .    ! => 210
```

`count` esegue un predicato sulla sequence e restituisce quanti elementi lo hanno reso vero:

```
count ( seq quot -- n )
```

```factor
{ 2 5 0 7 4 1 } [ even? ] count .    ! => 3
```

## Predicati sull'intera sequence

```
any?   ( seq quot -- ? )
all?   ( seq quot -- ? )
empty? ( seq -- ? )
```

```factor
{ 2 5 0 7 } [ 4 > ] any? .      ! => t
{ 2 5 0 7 } [ 0 > ] all? .      ! => f
```

## Costruire una nuova sequence

`suffix` aggiunge un elemento in fondo a una sequence; `prefix` ne aggiunge uno in testa. `unclip` stacca il primo elemento e `unclip-last` stacca l'ultimo:

```
prefix      ( seq elt -- newseq )
suffix      ( seq elt -- newseq )
unclip      ( seq -- rest first )
unclip-last ( seq -- butlast last )
```

```factor
{ 7 9 } 3 prefix .             ! => { 3 7 9 }
{ 7 9 } 3 suffix .             ! => { 7 9 3 }
{ 4 0 9 } unclip .s
! => { 0 9 }
! => 4
```

Combinando `unclip-last` e `suffix` si ottiene un aggiornamento non distruttivo dell'ultimo elemento (e `unclip` + `prefix` fa lo stesso con il primo):

```factor
{ 10 20 30 } unclip-last 2 * suffix .
! => { 10 20 60 }
```

## Convertire tra tipi di sequence

`>array`, `>vector` e `>string` (in [`arrays`][arrays] e nei vocabolari corrispondenti) forzano una sequence verso un tipo concreto specifico. È utile quando un'operazione ha restituito una sezione o una sequence generica e ti serve di nuovo un array (o una stringa).

```factor
{ 1 2 3 } 1 tail >array .   ! => { 2 3 }
"hello" >array .            ! => { 104 101 108 108 111 }
{ 65 66 67 } >string .      ! => "ABC"
```
