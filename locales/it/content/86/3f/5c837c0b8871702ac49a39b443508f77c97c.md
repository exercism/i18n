# Introduzione

## Operatori di confronto

Gli [operatori di confronto][comparison-operators] confrontano due valori dello stesso tipo e restituiscono un valore `Bool` (`true` o `false`).
Se provi a confrontare valori di tipi diversi, il compilatore genera un errore.

Gli operatori di confronto standard in Swift sono:

| Operatore | Descrizione             | Esempio         |
| --------- | ----------------------- | --------------- |
| `==`      | Uguale a                | `1 == 1` (vero) |
| `!=`      | Diverso da              | `1 != 2` (vero) |
| `<`       | Minore di               | `4 < 5`  (vero) |
| `<=`      | Minore o uguale a       | `4 <= 4` (vero) |
| `>`       | Maggiore di             | `3 > 1`  (vero) |
| `>=`      | Maggiore o uguale a     | `2 >= 2` (vero) |

## Istruzioni if ed else

Una [istruzione condizionale][conditional-statement] esegue codice a seconda che una condizione sia `true` o `false`.
L'istruzione condizionale più comune è l'[istruzione if][if], che esegue un blocco di codice solo quando la sua condizione è `true`.
Per scrivere un'istruzione `if`, usa la parola chiave `if`, seguita dalla condizione e dal blocco di codice racchiuso tra parentesi graffe:

```swift
let wheelCount = 4
if wheelCount == 4 {
    print("Your vehicle is a car")
}
// Prints "Your vehicle is a car"
```

Puoi abbinare `if` a una clausola `else` per eseguire codice alternativo quando la condizione è `false`:

```swift
let precipitationInMM = 0.5
if precipitationInMM > 0.5 {
    print("You will need an umbrella")
} else {
    print("You will not need an umbrella")
}
// Prints "You will not need an umbrella"
```

Per verificare più condizioni in sequenza, concatena le istruzioni usando `else if`.
Un'istruzione `if` non richiede un ramo `else`, ma puoi includerne uno per gestire i casi in cui nessuna delle condizioni corrisponde:

```swift
let favoriteFruit = "Apple"

if favoriteFruit == "Banana" {
    print("Your favorite fruit is a banana")
} else if favoriteFruit == "Orange" {
    print("Your favorite fruit is an orange")
} else if favoriteFruit == "Apple" {
    print("Your favorite fruit is an apple")
} else {
    print("Your favorite fruit is not a banana, orange, or apple")
}
// Prints "Your favorite fruit is an apple"
```

## Espressioni if

Nel Swift moderno, le istruzioni `if` possono essere usate anche come espressioni che producono un valore.
Ogni ramo restituisce un valore, il che rende semplice assegnare i risultati in modo condizionale:

```swift
let cpuBits = 32
let architecture = if cpuBits == 64 {
    "x86_64"
} else {
    "x86_32"
}

print(architecture)
// Prints "x86_32"
```

## Operatore ternario

L'[operatore condizionale ternario][ternary-operator] è una scorciatoia concisa per un'espressione `if-else`.
Valuta una condizione e restituisce uno di due valori a seconda che quella condizione sia `true` o `false`.

L'operatore usa tre parti: `condition ? trueExpression : falseExpression`.
Se `condition` è `true`, viene valutata e restituita `trueExpression`; altrimenti, viene valutata e restituita `falseExpression`.

L'operatore ternario è ideale per scelte semplici, su una sola riga:

```swift
let showFahrenheit = true
let temperatureInCelsius = 30

let temperature = showFahrenheit ? temperatureInCelsius * 9 / 5 + 32 : temperatureInCelsius
print(temperature)
// Prints 86
```

L'esempio qui sopra è un equivalente compatto di:

```swift
let showFahrenheit = true
let temperatureInCelsius = 30

let temperature = if showFahrenheit {
    temperatureInCelsius * 9 / 5 + 32
} else {
    temperatureInCelsius
}
```
