# Istruzioni

Il salone di bellezza di New York che hai aiutato nell'esercizio Prenotazioni per la bellezza sta andando bene, e molti dei suoi clienti sono diventati abituali.
Invece di prenotare ogni visita separatamente, un cliente abituale ha un accordo fisso: «ogni secondo martedì», «l'ultimo venerdì del mese» e così via.
Il proprietario ti ha chiesto una funzione ausiliaria che calcoli le date di questi accordi, oltre alle date della routine mensile del salone.

## 1. Trova l'appuntamento fisso di un cliente abituale

Implementa il metodo `SalonCalendar.standingAppointment()` che accetta un anno, un mese, un'occorrenza (`1` per la prima, `2` per la seconda e così via) ed un giorno della settimana.
Restituisce la data di quell'occorrenza del giorno della settimana nel mese:

```java
SalonCalendar calendar = new SalonCalendar();
calendar.standingAppointment(2024, Month.AUGUST, 2, DayOfWeek.TUESDAY);
// => LocalDate.of(2024, 8, 13)
```

## 2. Trova l'appuntamento di fine mese di un cliente abituale

Alcuni clienti abituali preferiscono l'ultima occorrenza del loro giorno nel mese.
Implementa il metodo `SalonCalendar.lastAppointment()` che accetta un anno, un mese ed un giorno della settimana e restituisce la data dell'ultima occorrenza di quel giorno della settimana nel mese:

```java
SalonCalendar calendar = new SalonCalendar();
calendar.lastAppointment(2024, Month.AUGUST, DayOfWeek.FRIDAY);
// => LocalDate.of(2024, 8, 30)
```

## 3. Trova il prossimo giorno disponibile per un cliente senza appuntamento

Un cliente alla reception chiede «il prossimo sabato».
Se il giorno in cui lo chiede è già un sabato, intende proprio quel giorno.
Implementa il metodo `SalonCalendar.nextAvailable()` che accetta una data ed un giorno della settimana e restituisce la prima data uguale o successiva alla data indicata che cade in quel giorno della settimana:

```java
SalonCalendar calendar = new SalonCalendar();
calendar.nextAvailable(LocalDate.of(2024, 8, 15), DayOfWeek.SATURDAY);
// => LocalDate.of(2024, 8, 17)
calendar.nextAvailable(LocalDate.of(2024, 8, 17), DayOfWeek.SATURDAY);
// => LocalDate.of(2024, 8, 17)
```

## 4. Trova il giorno di chiusura dei conti

Il salone chiude i conti l'ultimo giorno di ogni mese.
Il salone, però, è chiuso nel fine settimana: quando l'ultimo giorno del mese cade di sabato o di domenica, i conti si chiudono il venerdì precedente.
Implementa il metodo `SalonCalendar.bookkeepingDay()` che accetta un anno ed un mese e restituisce il giorno di chiusura dei conti di quel mese:

```java
SalonCalendar calendar = new SalonCalendar();
calendar.bookkeepingDay(2024, Month.SEPTEMBER);
// => LocalDate.of(2024, 9, 30)
calendar.bookkeepingDay(2024, Month.AUGUST);
// => LocalDate.of(2024, 8, 30)
```

## 5. Riusa la regola del fine settimana per il giorno di paga

Il personale viene pagato il 15 di ogni mese, con la stessa regola del fine settimana: quando il 15 cade di sabato o di domenica, il giorno di paga è il venerdì precedente.
Invece di scrivere la regola una seconda volta, trasformala in un regolatore temporale riutilizzabile.

Implementa il metodo `SalonCalendar.precedingWorkday()` che restituisce un `TemporalAdjuster` che lascia invariato un giorno feriale e sposta un sabato o una domenica al venerdì precedente.
Poi implementa il metodo `SalonCalendar.payday()` che accetta un anno ed un mese, usando quel regolatore:

```java
SalonCalendar calendar = new SalonCalendar();
LocalDate.of(2024, 6, 15).with(calendar.precedingWorkday());
// => LocalDate.of(2024, 6, 14)
calendar.payday(2024, Month.JUNE);
// => LocalDate.of(2024, 6, 14)
calendar.payday(2024, Month.AUGUST);
// => LocalDate.of(2024, 8, 15)
```

Sentiti libero di tornare indietro ed usare il regolatore anche in `bookkeepingDay()`.
