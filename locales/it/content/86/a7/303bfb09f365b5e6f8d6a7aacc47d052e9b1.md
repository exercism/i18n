# Test

Per eseguire i test, assembla ed esegui il file del test runner per un dato esercizio, sia tramite l'interfaccia grafica del simulatore MARS, sia dalla riga di comando. Per eseguire dalla riga di comando,
specifica prima il file del test runner e poi l'implementazione, come segue:

    java -jar /path/to/mars.jar nc runner.mips impl.mips

Per eseguire nell'interfaccia grafica, `include` l'implementazione in fondo a "runner.mips"
togliendo il commento dall'ultima riga.

Il test runner terminerà con un messaggio "success" oppure si arresterà quando un test fallisce, con un messaggio che specifica l'input per cui quel test è fallito.
