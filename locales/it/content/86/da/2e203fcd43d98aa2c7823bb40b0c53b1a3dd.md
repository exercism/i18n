# Suggerimenti

## Generali

- Usa il tipo [array][array] integrato.

## 1. Definire un metodo che restituisce un array di linguaggi vuoto

- La funzione deve restituire un array vuoto con il tipo `Array(String)`.
- La sintassi per creare un array vuoto è `[]`.
  Il tipo può essere specificato usando `of String`.

## 2. Definire un metodo per aggiungere un linguaggio all'array

- Un elemento può essere aggiunto a un array usando `<<`.

## 3. Definire un metodo per rimuovere un linguaggio dall'array

- Crystal [fornisce un metodo][pop] per rimuovere l'ultimo elemento da un array.

## 4. Definire un metodo che restituisce l'ennesimo elemento dell'array

- Crystal [fornisce un metodo][index] per ottenere l'elemento a un indice specifico di un array.

## 5. Definire un metodo per analizzare una stringa di linguaggi

- Crystal [fornisce un metodo][split] per convertire una stringa in un array usando un delimitatore.
