# Aiuto

Red ha un sistema di aiuto integrato, disponibile nella console di Red. Ogni funzione integrata è documentata lì. Basta digitare `help` e seguire le istruzioni.

La [documentazione ufficiale](https://github.com/red/docs/blob/master/en/SUMMARY.adoc) di Red è ancora in fase di sviluppo, quindi probabilmente andrà integrata con altro materiale.

* Molte funzioni sono descritte nella pagina [Red By Example](https://www.red-by-example.org/).
* È disponibile anche la [Red Language Specification](https://github.com/meijeru/red.specs-public/blob/master/specs.adoc), molto ampia, sebbene non ufficiale.
* Il posto migliore per ottenere aiuto in fretta è il [canale di aiuto di Red su Gitter](https://gitter.im/red/help), dove puoi chattare con una comunità amichevole.
