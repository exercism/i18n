# Introduzione

L'istruzione `guard` in Swift serve a uscire anticipatamente dalle funzioni Swift quando non è soddisfatta una condizione necessaria per proseguire con l'elaborazione, ad esempio:

```swift
guard myValue >= 0 else { return 0 }
let root = myValue.squareRoot()
```

Qui, l'istruzione `guard` controlla se l'espressione booleana che segue la parola chiave `guard` viene valutata come vera. In caso affermativo, l'elaborazione prosegue con il codice che segue l'istruzione `guard` (qui `let root = myValue.squareRoot()`). In caso contrario, eseguirà il codice nella clausola else. A differenza di un'istruzione `if`, un'istruzione `guard` _deve_ avere una clausola else e, a differenza della clausola else di un if-else, la clausola else di un'istruzione `guard` _deve_ uscire dallo scope dell'istruzione `guard`. Ovvero, deve usare un'istruzione di trasferimento del controllo come `return`, `continue`, `break`, oppure deve lanciare un errore o terminare il programma.
