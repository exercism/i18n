# Suggerimenti

## Generale

- Per estrarre più argomenti dai parametri della funzione, puoi raggrupparli con `...<args>`.
- Per usare rest e spread, usa l'operatore `...`.

## 1. Crea un array con tutti i vagoni

- Più argomenti nei parametri della funzione si possono raggruppare con la [`...<args>` (sintassi spread)][spread-syntax].

## 2. Sposta i primi due elementi alla fine dell'array

- Puoi spacchettare una serie di parametri usando [un'assegnazione con destrutturazione (`...`)][destructuring-assignment].
  Questo ti permette di estrarre i primi due elementi di un `array` mantenendo intatto il resto.
- Per aggiungere un altro `array` a un `array` esistente, puoi usare l'operatore `...` per fare lo «spread» dell'`array`.

## 3. Aggiungi i valori mancanti

- Usando lo spacchettamento con l'operatore rest (`...`), puoi estrarre il primo elemento di un `array` mantenendo intatto il resto.
- Per aggiungere un altro `array` a un `array` esistente, puoi usare l'operatore `...` per fare lo «spread» dell'`array`.

## 4. Estendi le informazioni sul percorso

- Per aggiungere un altro `object` a un `object` esistente, puoi usare l'operatore `...` per fare lo «spread» dell'`object`.

## 5. Separa l'orario di arrivo dalle informazioni sul percorso

- Per estrarre un valore da un `object` mantenendo intatto il resto, puoi usare l'operatore rest (`...`).
