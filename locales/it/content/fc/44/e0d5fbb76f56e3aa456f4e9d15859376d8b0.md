# Informazioni

[Groovy](http://www.groovy-lang.org/) è il potente linguaggio dinamico a tipizzazione opzionale della Apache Foundation, che offre anche capacità di tipizzazione statica e compilazione statica.

Groovy punta a migliorare la produttività degli sviluppatori grazie a una sintassi concisa e facile da imparare.
Facilita lo scripting, la creazione di linguaggi specifici del dominio, la metaprogrammazione a runtime e a tempo di compilazione e la programmazione funzionale.

Consente di accedere all'intero ecosistema delle librerie Java e si integra perfettamente con le applicazioni Java.

Può essere usato come un semplice linguaggio di scripting o aggiunto a framework Java complessi. 
È alla base di tecnologie come: 
* Gradle, 
* Spock, 
* Ratpack, 
* Grails, 
* e lo scripting in Jenkins.

Inoltre, è divertente.
