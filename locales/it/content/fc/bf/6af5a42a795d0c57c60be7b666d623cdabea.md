# Char

`Char` è un tipo di dato in Crystal che rappresenta un punto di codice [Unicode][unicode] a 32 bit.
Le sue dimensioni lo rendono efficiente in termini di memoria e gli conferiscono proprietà specifiche che le stringhe non hanno.
Si crea usando virgolette singole (`'`) e consente di inserirvi un solo punto di codice Unicode.

```crystal
'a' # => 'a'
'a'.class # => Char
```

È piuttosto comune lavorare con i Char quando si lavora con le stringhe in Crystal, dato che parecchi metodi della classe String restituiscono Char o accettano Char come argomenti.
Per esempio, il metodo [`String#[]`][index] restituisce un Char, oppure il metodo [`String#chars`][chars] restituisce una collezione di Char.

## Incremento e decremento

Dato che un Char è un punto Unicode a 32 bit, supporta l'incremento e il decremento: questo fa sì che, se hai `'a'`, puoi ottenere `'b'` aggiungendo uno.

```crystal
'a' + 5
# => 'f'

'z' - 25
# => 'a'
```

Esiste anche un metodo chiamato [`Char#succ`][succ], che restituisce il carattere successivo nella tabella Unicode, e [`Char#pred`][pred], che restituisce il carattere precedente nella tabella Unicode.

```crystal
'a'.succ
# => 'b'

'z'.pred
# => 'y'
```

## Concatenazione

Dato che i Char servono solo a rappresentare un punto Unicode a 32 bit, due Char non possono essere concatenati.
Di conseguenza, i Char possono essere concatenati solo con le stringhe.

```Crystal
'a' + "bc"
# => "abc"

'a' + 'b'
# => error: expected argument #1 to 'Char#+' to be Int or String, not Char
```

## Metodi per le proprietà

Crystal ha alcuni metodi per ottenere informazioni su un carattere, come se è un numero o una lettera, oppure se è maiuscolo o minuscolo.
Ecco un elenco di alcuni dei metodi; per un elenco completo, consulta l'[API di Char][char-api]:

| Metodo                           | Descrizione                                          |
| -------------------------------- | ---------------------------------------------------- |
| [`Char#number?`][number]         | Restituisce `true` se il Char è un numero            |
| [`Char#letter?`][letter]         | Restituisce `true` se il Char è una lettera          |
| [`Char#lowercase?`][lowercase]   | Restituisce `true` se il Char è minuscolo            |
| [`Char#uppercase?`][uppercase]   | Restituisce `true` se il Char è maiuscolo            |
| [`Char#ascii?`][ascii]           | Restituisce `true` se il Char è un carattere ASCII   |
| [`Char#whitespace?`][whitespace] | Restituisce `true` se il Char è un carattere di spazio |

## Conversione

### Convertire tra punti di codice e Char

Dato che un Char è un punto Unicode a 32 bit, puoi convertire tra Char e punti di codice (Int).
Puoi farlo usando il metodo [`Char#ord`][ord], che restituisce il punto di codice del Char, oppure il metodo [`Int#chr`][chr], che restituisce il Char del punto di codice.

```crystal
'a'.ord
# => 97

97.chr
# => 'a'
```

### Convertire tra tipi

Come per gli altri tipi di dato, i Char hanno alcuni metodi per convertire tra tipi.
Il più comune è il metodo `Char#to_s`, che converte il Char in una stringa. Esiste però anche il metodo `Char#to_i`, che converte il Char in un Int, e il metodo `Char#to_f`, che converte il Char in un Float.

```crystal
'a'.to_s
# => "a"

'4'.to_i
# => 4

'a'.to_i
# => Error: Invalid integer: a (ArgumentError)
```
