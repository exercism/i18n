# Caratteri

Un **carattere** è una singola lettera, una cifra, uno spazio o un segno. In Sather, il tipo per un carattere è `CHAR`, e un carattere si scrive tra virgolette singole.

```sather
   initial : CHAR is
      return 'M';
   end;
```

Virgolette singole per un carattere, virgolette doppie per una stringa. `'M'` e `"M"` sono tipi diversi e non si possono scambiare.

## Caratteri da una stringa

Una stringa è una fila di caratteri, e le parentesi quadre ne raggiungono uno in base alla posizione, contando da zero, proprio come in un array.

```sather
"Marlowe"[0]      -- 'M'
"Marlowe"[3]      -- 'l'
```

## Chiedere informazioni su un carattere

| Chiamata | Risposta |
| --- | --- |
| `c.is_alpha` | È una lettera? |
| `c.is_digit` | È una delle cifre da `0`–`9`? |
| `c.is_upper` | È una maiuscola? |
| `c.is_lower` | È una minuscola? |

Ciascuna risponde `true` o `false`.

```sather
'M'.is_alpha      -- true
'7'.is_alpha      -- false
'7'.is_digit      -- true
```

## Cambiare maiuscole e minuscole

`.upper` restituisce la maiuscola di una lettera, e `.lower` la minuscola. Tutto ciò che non è una lettera viene restituito invariato.

```sather
'm'.upper         -- 'M'
'M'.lower         -- 'm'
'7'.upper         -- '7'
```

## I caratteri come numeri

Ogni carattere ha un numero. `.int` lo restituisce, e `.char` trasforma un numero di nuovo in un carattere.

```sather
'a'.int           -- 97
'b'.int           -- 98
98.char           -- 'b'
```

I numeri esatti contano raramente. Quello che conta è che le lettere da `a` a `z` siano in ordine e una accanto all'altra, così `'c'.int - 'a'.int` fa 2, cioè quanto `c` è avanti nell'alfabeto. È questo che fa funzionare una ruota cifrante.
