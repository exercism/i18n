# Tipi unione

Crystal permette che una variabile abbia più tipi.
Questo si chiama [tipo unione][union-type].
In Crystal è comune che il compilatore inferisca un tipo unione.

~~~~exercism/note
A runtime, un tipo unione è comunque un unico tipo, anche se è composto da più tipi.
Questo significa che se un tipo unione è formato da `String` e `Int32`, non sarà entrambi contemporaneamente.
Sarà invece uno `String` o un `Int32`.
~~~~

Un tipo unione si dichiara separando i tipi con una barra verticale (`|`).
Spesso vengono racchiusi tra parentesi tonde, ma non è obbligatorio.
Il tipo unione più comune è `(T | Nil)`, dove `T` è un tipo; compare nei metodi che possono restituire `Nil`.
In questo caso si dice anche che la variabile è **nilable**.

```crystal
foo : String = "Hello"
foo = nil # Error: type must be String, not (String | Nil)

foo : (String | Nil) = "Hello"
foo = nil
```

Non è limitato a due soli tipi: può contenerne quanti ne vuoi.

```crystal
foo : (String | Int32 | Nil | Float64) = "Hello"
foo = 1
foo = nil
foo = 1.0
```

## `typeof` vs `Object#class`

Ci sono due modi per ottenere il tipo di una variabile: usare [`typeof`][typeof] oppure [`Object#class`][Object#class].
La differenza è che `typeof` restituisce il tipo di una variabile in fase di compilazione, mentre `Object#class` restituisce il tipo a runtime.
Questo significa che, per esempio, se vuoi sapere se una variabile è un tipo unione, `Object#class` non può dirtelo: restituisce il tipo solo a runtime, e a runtime si tratta di un unico tipo.

```crystal
foo = 0 == 0 ? "a" : 1
typeof(foo) # => (String | Int32)
foo.class # => String
```

## Operazioni sui tipi unione

Poiché a runtime un tipo unione è un unico tipo, tutte le operazioni standard funzionano su di esso.
Ma in fase di compilazione il compilatore deve sapere di quale tipo si tratta.
Perciò, quando vuoi usare le operazioni specifiche di un tipo, devi impostare il codice in modo che possa essere solo uno dei tipi.

```crystal
foo : (String | Int32) = "Hello"
foo.downcase # Error: undefined method 'downcase' for (String | Int32)
```

Crystal ha però un metodo specifico per i tipi unione: il metodo `is_a?`, che accetta un tipo come argomento e restituisce un valore booleano.
Il metodo `nil?` è una scorciatoia per `is_a?(Nil)`.
Inserire il metodo `is_a?` in un'espressione di controllo indica al compilatore di quale tipo si tratta, garantendo così che sia proprio quel tipo.
E in un ramo else sarà garantito che non è quel tipo.

```crystal
foo : (String | Int32) = "Hello"
if foo.is_a?(String)
  typeof(foo)  # => String
  foo.downcase # => "hello"
end
```

Questo `is_a?` non si limita ad avere un singolo tipo come argomento: può ricevere anche un tipo unione.
Può anche essere combinato con `&&` per più tipi.

~~~~exercism/note
Il metodo `is_a?`, se usato insieme a un'espressione di controllo, non può essere chiamato su una variabile di istanza o una variabile di classe.
In quel caso bisogna prima assegnarle a una variabile locale.
~~~~

## as

Un modo per trasformare un tipo unione in un unico tipo è fare in modo che un ramo possa essere eseguito solo se il tipo è un tipo specifico.
Un altro approccio è usare il metodo [`as`][as].
Questo trasforma un tipo unione in un unico tipo eseguendo un controllo a runtime.
Se il tipo non è quello previsto, viene sollevata un'eccezione.

```crystal
foo : String | Int32 = "Hello"
foo.as(String).downcase # => "hello"

foo.as(Int32) # Error: can't cast String to Int32
```

~~~~exercism/caution
Questo approccio è pensato solo per quando sei sicuro che il tipo sia quello previsto, oppure per quando vuoi sollevare un'eccezione se non lo è.

Usarlo con una configurazione inadeguata può portare a comportamenti inattesi.
~~~~

## as?

[`as?`][as?] funziona in modo molto simile a `as`, ma restituisce `nil` invece di sollevare un'eccezione se il tipo non è quello previsto.
Questo significa che restituisce un tipo unione formato dal tipo previsto e da `Nil`.

```crystal
foo : (String | Int32) = "Hello"
foo.as?(String).downcase # => "hello"

foo.as?(Int32) # => nil
```

## Scorciatoia per i tipi nilable

Nilable significa che una variabile può essere un certo tipo oppure `Nil`.
Questo si può scrivere come `(T | Nil)`.
Ma dato che i tipi nilable sono piuttosto comuni, esiste una scorciatoia: `T?`.

```crystal
# This:
foo : (String | Nil) = "Hello"
foo = nil

# Is the same as:
foo : String? = "Hello"
foo = nil
```
