# Informazioni

L'assembly x86-64 è il linguaggio di programmazione per la versione a 64 bit del set di istruzioni x86. Si basa sul set di istruzioni originale dell'8086, del 1978.

Il linguaggio assembly è diverso dai linguaggi di alto livello come C# e Java. Non ci sono variabili, oggetti o cicli. Dovrai invece avere a che fare con registri, indirizzi di memoria e salti.

Imparare l'assembly può intimidire all'inizio, ma ti darà una comprensione migliore di come funziona il tuo computer. Potrebbe persino migliorare le tue capacità di programmazione nei linguaggi di alto livello.
