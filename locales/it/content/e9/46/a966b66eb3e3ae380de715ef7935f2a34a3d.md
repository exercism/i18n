# Informazioni

Il concetto di base di `try .. rescue` può essere esteso per supportare le clausole `else` e `after`:

- Il blocco `else`:
  - Dove avviene un pattern match sul risultato di successo del blocco `try`.
- Il blocco `after`:
  - Dove le funzioni vengono chiamate sia che il blocco `try` abbia successo sia che venga intercettato un errore, purché il programma sia in esecuzione.
  - Il risultato del blocco `after` non viene restituito allo scope chiamante.

```elixir
try do
  :a
rescue
  _ -> :error
else
  :a -> :success
after
  :some_action
end

# => :success
```
