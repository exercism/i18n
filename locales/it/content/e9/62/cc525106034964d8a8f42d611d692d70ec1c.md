# Eseguire i test di Ceylon

Prima di eseguire i test, devi compilare il codice con [`ceylon compile`](https://ceylon-lang.org/documentation/current/reference/tool/ceylon/subcommands/ceylon-compile.html).

I test si eseguono con il comando [`ceylon test`](https://ceylon-lang.org/documentation/reference/tool/ceylon/subcommands/ceylon-test.html).

`ceylon test` richiede il nome di un modulo su cui eseguire i test.
Nel track di Ceylon, ogni esercizio ha un solo modulo.

Quindi puoi eseguire i test con:

```bash
ceylon compile && ceylon test $(basename source/*)
```
