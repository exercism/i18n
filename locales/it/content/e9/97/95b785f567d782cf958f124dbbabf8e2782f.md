# Test

Per eseguire i test forniti, ti serve la gem Minitest. Apri una finestra del terminale ed esegui il comando seguente per installare minitest:

```
gem install minitest
```


Esegui i test dalla directory dell'esercizio con il comando seguente:

```
ruby <snake-case-exercise>_test.rb
```

Sostituisci `<snake-case-exercise>` con il nome dell'esercizio in snake_case.

## Output colorato

Puoi usare `require 'minitest/pride'` oppure eseguire il comando seguente per ottenere un output colorato:

```
ruby -r minitest/pride <snake-case-exercise>_test.rb
```
