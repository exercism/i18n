# Introduzione

Per le basi sugli argomenti di funzione, vedi il [concetto di funzione][function concept].

## Nomi dei parametri

I [nomi dei parametri][parameters], come i nomi delle variabili, devono iniziare con una lettera o un underscore e possono contenere lettere, underscore o numeri.
I nomi dei parametri non devono contenere spazi o punteggiatura.


## Argomenti posizionali

Gli argomenti posizionali sono valori passati a una funzione nello stesso ordine dei parametri a cui sono associati.
Facoltativamente, possono essere passati usando il nome del parametro:


```python
def concat(greeting, name):
    return f"{greeting}{name}"
 
# Passing data to the function by position.
print(concat("Hello, ", "Judy"))
#->  Hello, Judy

# Passing data to the function using the parameter name.
print(concat(name="Sally", greeting="Hello, "))
#-> Hello, Sally
```

La prima chiamata a concat passa gli argomenti per posizione.
La seconda chiamata a concat passa gli argomenti per _nome_, il che permette di cambiarne la posizione.

Nota che gli argomenti posizionali non possono seguire gli argomenti passati per nome (_detti anche [argomenti keyword][keyword-arguments]. Da **non** confondere con i parametri var-positional o con [**kwargs][kwargs]_).

Questo insieme di argomenti:

```python
>>> print(concat(greeting="Hello, ", "Zed"))
```

produrrà questo errore:

```
SyntaxError: positional argument follows keyword argument
```

## Valori predefiniti degli argomenti

I [valori predefiniti][default arguments] per uno o più argomenti possono essere indicati nella lista dei parametri.
Questo permette di chiamare la funzione con _meno_ argomenti, se necessario.
I valori predefiniti possono essere sovrascritti chiamando la funzione con nuovi argomenti al posto di quelli predefiniti:


```python
# Note the default arguments for both greeting and name.
def concat(greeting="Hello, ", name="you"):
    return f"{greeting}{name}"
 
# Function call overriding the defaults
print(concat(name="Jerry", greeting="Hello, "))
#-> Hello, Jerry

# Function call without arguments resulting in the defaults being used.
print(concat())
#-> Hello, you
```

## Argomenti keyword

Gli argomenti keyword usano il nome del parametro quando si passano argomenti a una funzione.
Facoltativamente, possono essere indicati per posizione:


```python
# Note the default arguments for both greeting and name.
def concat(greeting="Hello, ", name="you"):
    return f"{greeting}{name}"

# Function call using parameter names as argument keywords.
print(concat(name="Jerry", greeting="Hello, "))
#-> Hello, Jerry

# Function call with positional data as arguments.
print(concat("Hello, ", "Isaac"))
#-> Hello, Isaac
```
