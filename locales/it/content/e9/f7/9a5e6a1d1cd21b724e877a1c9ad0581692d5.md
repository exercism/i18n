# Istruzioni

Sei il telegrafista senza fili su un mercantile. Il segnale arriva
su una linea disturbata: rumori dei macchinari della nave, disturbi
atmosferici, ogni tanto chiacchiere in lingue straniere, frammisto
al Morse che stai cercando di ascoltare. Per catturare il messaggio
fai passare il filo attraverso un dispositivo a *tape* che elimina
tutto tranne i simboli Morse validi (`.`, `-` e lo spazio che separa
le lettere).

Il tuo compito è costruire la tape come stream di input
personalizzato in Factor.

## 1. Definire la tape

Definisci una tupla `tape` che estende `disposable` e contiene un solo
slot, `wire`, per lo stream di input sottostante.

```factor
TUPLE: tape < disposable wire ;
```

Poi scrivi il costruttore `<tape> ( wire -- tape )`. Usa
`new-disposable` (non `new`) così il framework dei distruttori
registra la tape, e memorizza lo stream sottostante nello slot
`wire`.

## 2. Aderire al mixin input-stream

Dichiara che `tape` è un `input-stream`:

```factor
INSTANCE: tape input-stream
```

In questo modo i combinatori predefiniti del protocollo vengono
indirizzati alla tua classe.

## 3. Leggere un simbolo Morse

Implementa `M: tape stream-read1 ( tape -- elt/f )`. Leggi i byte
dal wire sottostante finché non ne incontri uno tra `CHAR: .`,
`CHAR: -` o `CHAR: \s` (spazio). Restituisci quel byte. Se il wire
restituisce `f` (fine dello stream), restituisci `f` anche tu: la
tape ha finito.

```factor
"x.y -ab cz" <string-reader> <tape>
[ stream-read1 ] [ stream-read1 ] [ stream-read1 ] tri
! => CHAR: . CHAR: - CHAR: \s
```

## 4. Delegare il tipo di elemento

Implementa `M: tape stream-element-type ( tape -- type )`
delegando al wire: la tape non cambia il tipo di elementi che
vengono letti.

## 5. Fare pulizia

Implementa `M: tape dispose* ( tape -- )`. Il framework chiama il
tuo metodo esattamente una volta per ogni `dispose`: basta chiamare
`dispose` sul wire sottostante.

Con questi cinque pezzi a posto, la tape funziona come un normale
stream di input: `with-input-stream`, `stream-read` e tutte le
altre parole del protocollo vengono indirizzate automaticamente ai
tuoi metodi.
