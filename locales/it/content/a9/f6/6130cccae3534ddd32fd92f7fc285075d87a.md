# Informazioni

Elm è un linguaggio delizioso per costruire applicazioni web affidabili.
Ha messaggi di errore amichevoli, prestazioni eccezionali, asset leggeri e nessuna eccezione a runtime.

La parte probabilmente più famosa e più imitata di Elm è The Elm Architecture, un pattern semplice per strutturare le applicazioni web, ed è il modo in cui si scrivono tutte le applicazioni web in Elm.

L'idea centrale è che il codice è costruito attorno a un `Model` che rappresenta lo stato dell'applicazione, a un modo per aggiornare il modello con `update` e a un modo per visualizzarlo con `view`.

Il `Model` contiene lo stato dell'applicazione, cioè tutti i dati di cui l'applicazione ha bisogno.
Se immagini un'applicazione semplice con una casella di testo e un testo che ne mostra il contenuto al contrario, il modello sarà quello qui sotto.
Puoi vedere questo esempio anche nella [Elm Guide][elm-guide-text-fields].

```elm
type alias Model =
  { text : String
  }
```

`update` è una funzione che viene chiamata con un `Msg` quando qualcosa cambia (ad esempio quando l'utente clicca un pulsante).
Riceve il `Msg` e il `Model` attuale e restituisce un nuovo `Model`.

```elm
type Msg
  = TextChanged String

update : Msg -> Model -> Model
update msg model =
  case msg of
    TextChanged newText ->
      { model | text = newText }
```

`view` è una funzione che restituisce l'HTML da mostrare all'utente nel browser.
Riceve il `Model` attuale e restituisce un `Html Msg` (il tipo che Elm usa per rappresentare l'HTML).

```elm
view : Model -> Html Msg
view model =
  Html.div []
    [ Html.input
      [ Html.Attributes.placeholder "Text to reverse"
      , Html.Attributes.value model.text
      , Html.Events.onInput TextChanged
      ]
      []
    , Html.div [] [ Html.text (String.reverse model.text) ]
    ]
```
