# Appendice alle istruzioni

## Struttura del progetto

Gli esercizi di Clojure in exercism usano [leiningen](http://leiningen.org/) per configurare ed eseguire il codice e seguono la [struttura di directory standard di leiningen](https://github.com/technomancy/leiningen/blob/master/doc/TUTORIAL.md#directory-layout).

Nella directory `test` troverai un file di test chiamato `hello_world_test.clj`.
Scrivi il codice in `src/hello_world.clj`. Dovrebbe usare il namespace `hello-world` in modo che i test lo trovino.

## Eseguire i test

Esegui i test con il comando `lein test` e falli passare:

```
$ lein test

lein test hello-world-test

Ran 3 tests containing 3 assertions.
0 failures, 0 errors.
```

Poi invia l'esercizio con:

```
$ exercism submit src/hello_world.clj
```

Per istruzioni più dettagliate e risorse di apprendimento, consulta la [pagina del linguaggio Clojure di exercism](http://exercism.io/languages/clojure).
