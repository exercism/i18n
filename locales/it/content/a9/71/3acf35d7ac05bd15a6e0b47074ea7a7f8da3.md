# Introduzione

Una stringa in Factor è una sequenza di caratteri. La maggior parte delle word del vocabolario [`sequences`][sequences] funziona sulle stringhe, oltre alle word dedicate alla gestione delle stringhe in [`splitting`][splitting], [`ascii`][ascii] e simili.

## Stringhe letterali

Le stringhe si scrivono tra virgolette doppie. Sono supportate le solite sequenze di escape: `\n`, `\t`, `\r`, `\\`, `\"`:

```factor
"hello, world" .                 ! => "hello, world"
"first\nsecond" print            ! prints two lines
```

## Lunghezza e indicizzazione

Dato che una stringa è una sequenza, le word `length` e `nth` di [`sequences`][sequences] funzionano direttamente su di essa.

`length` restituisce il numero di caratteri:

```factor
"hello" length .    ! => 5
```

`nth` prende un indice con base 0 e la sequenza, e restituisce l'elemento in quella posizione. Per una stringa l'elemento è un *carattere*, cioè un code point (un numero intero), non una sottostringa di un solo carattere:

```factor
0 "hello" nth .     ! => 104   (CHAR: h)
4 "hello" nth .     ! => 111   (CHAR: o)
```

## Da un carattere a una stringa

Per trasformare un singolo code point in una stringa di un solo carattere, usa `1string ( char -- str )` dal vocabolario [`strings`][strings]. `CHAR:` è la forma, al momento del parsing, di un code point letterale:

```factor
CHAR: A 1string .                ! => "A"
0 "hello" nth 1string .          ! => "h"
```

## Suddivisione

Il vocabolario [`splitting`][splitting] taglia una stringa in pezzi.

`split1` taglia in corrispondenza della *prima* occorrenza di un separatore e restituisce entrambe le metà:

```
split1 ( seq subseq -- before after )
```

```factor
"foo: bar" ": " split1 .s
! => "foo"
! => "bar"
```

`split` taglia in corrispondenza di *uno qualsiasi* dei caratteri di un insieme di separatori, producendo anche pezzi vuoti:

```factor
"[ERROR]: Stack overflow" "[]" split .
! => { "" "ERROR" ": Stack overflow" }
```

`harvest` (in [`sequences`][sequences]) scarta i pezzi vuoti:

```factor
"[ERROR]: Stack overflow" "[]" split harvest .
! => { "ERROR" ": Stack overflow" }
```

## Estrarre un pezzo

Una volta che una stringa è divisa in un array di pezzi, `first`, `second`, `third` e `fourth` (in [`sequences`][sequences]) restituiscono il pezzo in quella posizione:

```factor
"apple,bee,carrot,duck" "," split first .    ! => "apple"
"apple,bee,carrot,duck" "," split second .   ! => "bee"
"apple,bee,carrot,duck" "," split third .    ! => "carrot"
"apple,bee,carrot,duck" "," split fourth .   ! => "duck"
```

Quando vuoi tutti i pezzi iniziali sullo stack in una volta sola, `first2` e `first3` ne estraggono due o tre in un solo passaggio:

```factor
"apple,bee,carrot,duck" "," split first2 .s
! => "apple"
! => "bee"

"apple,bee,carrot,duck" "," split first3 .s
! => "apple"
! => "bee"
! => "carrot"
```

Applicato direttamente a una stringa, `first` restituisce il primo **carattere** (un code point) invece di una sottostringa:

```factor
"hello" first .                         ! => 104   (CHAR: h)
```

## Rimozione degli spazi bianchi

`[ blank? ] trim` (da [`sequences`][sequences], con `blank?` dal vocabolario [`ascii`][ascii]) rimuove gli spazi bianchi all'inizio e alla fine:

```factor
"  Disk full \r\n" [ blank? ] trim .
! => "Disk full"
```

## Conversione di maiuscole e minuscole

`>lower` e `>upper` (da [`ascii`][ascii]) restituiscono una nuova stringa convertita in minuscolo o in maiuscolo:

```factor
"WARNING" >lower .    ! => "warning"
"hello" >upper .      ! => "HELLO"
```

## Unione

Due word di [`sequences`][sequences] assemblano le stringhe:

`surround` avvolge una stringa con un prefisso e un suffisso:

```
surround ( seq pre post -- new-seq )
```

```factor
"warning" "(" ")" surround .    ! => "(warning)"
```

`glue` unisce due stringhe con un separatore in mezzo:

```
glue ( s1 s2 sep -- s )
```

```factor
"Disk full" "(error)" " " glue .    ! => "Disk full (error)"
```
