# Suggerimenti

## Generale

- [Struct e classi][structs-and-classes] condividono una sintassi di definizione simile.

## 1. Definire una struct Size

- Le proprietà vanno definite come `var` se possono essere modificate.
- Alle proprietà height e width vanno assegnati i valori predefiniti 80 e 60, rispettivamente.
- I metodi di una struct vanno contrassegnati come `mutating` se modificano le proprietà della struct.

## 2. Definire una struct Position

- Le proprietà vanno definite come `var` se possono essere modificate.
- Alle proprietà x e y va assegnato il valore predefinito 0.
- I metodi di una struct vanno contrassegnati come `mutating` se modificano le proprietà della struct.

## 3. Definire una classe Window

- Le struct si possono inizializzare con valori di proprietà diversi usando gli [inizializzatori per membro][memberwise-initializers].
- Le proprietà costanti vanno definite con `let`.
- La proprietà `contents` deve essere opzionale, perché potrebbe non avere un valore.
- Devi definire un inizializzatore vuoto per la classe (`init() {}`).

## 4. Aggiungere un metodo per ridimensionare le finestre

- Il metodo deve accettare un parametro `to` di tipo `Size`.
- È possibile estrarre width e height dal parametro `to` usando la notazione puntata.

## 5. Aggiungere un metodo per spostare le finestre

- Il metodo deve accettare un parametro `to` di tipo `Position`.
- È possibile estrarre x e y dal parametro `to` usando la notazione puntata.

## 6. Aggiungere un metodo per impostare il contenuto di una finestra

- In Swift è possibile avere due metodi con lo stesso nome ma parametri diversi.
- Definisci un metodo con il parametro `title` che imposta la proprietà `title`.
- Definisci un metodo con il parametro `text` che imposta la proprietà `contents`.
- Definisci un metodo di visualizzazione che stampa il titolo e il contenuto della finestra.

## 7. Creare un inizializzatore per la classe Window

- La classe deve avere due inizializzatori: uno che non accetta parametri e uno che accetta parametri.
- Il nuovo inizializzatore deve avere i parametri `title` e `contents`, e deve anche ammettere i parametri opzionali `size` e `position`
    Se non viene fornito alcun parametro, si usano i valori predefiniti.
- I parametri opzionali si possono ottenere usando i [valori predefiniti dei parametri][default-parameters-vales].
