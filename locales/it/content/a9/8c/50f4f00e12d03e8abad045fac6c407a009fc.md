# Approfondimento

Un ciclo è un modo per eseguire ripetutamente, in gruppo, una o più istruzioni.
Ogni esecuzione di un gruppo di istruzioni si chiama iterazione.

## Ciclo while

Un ciclo `while` esegue un gruppo di istruzioni finché un'espressione booleana all'inizio del ciclo è vera.
Quando l'espressione booleana è falsa, il ciclo smette di essere eseguito e l'esecuzione prosegue con la riga di codice successiva al ciclo.

Se l'espressione booleana è falsa fin dall'inizio, il ciclo `while` non verrà eseguito affatto e l'esecuzione proseguirà con la riga di codice successiva al ciclo.

```c
int main() {
    int i = 0;
    while (i < 5) {
        printf("Number is %i\n", i++);
    }    
    return 0;
}
```

È importante che ci sia una condizione che ponga fine al ciclo; altrimenti si tratta di un ciclo infinito che bloccherà ogni progresso del codice.
Se nel codice qui sopra si togliesse il `++` da `i`, sarebbe un ciclo infinito.

## Ciclo do

In un ciclo `do` l'espressione booleana viene verificata in fondo al ciclo.
Un ciclo `do` viene eseguito almeno una volta, come nell'esempio seguente

```c
do {
    printf("Enter the Answer to the Ultimate Question of Life: ");
    scanf("%d", &answer);
} while (answer != 42); 
// Note that a semicolon is needed after the Boolean expression.
```

Con un ciclo `while` sarebbe più verboso

```c
printf(""Enter the Answer to the Ultimate Question of Life: ");
scanf("%d", &answer);
while (answer != 42) {
    printf(""Enter the Answer to the Ultimate Question of Life: ");
    scanf("%d", &answer);
}
```

## Ciclo for

Spesso un ciclo aggiorna una variabile e termina quando la variabile raggiunge un certo valore.
Un ciclo `for` è un modo per inizializzare, aggiornare e verificare una o più variabili in una sola riga, all'interno delle parentesi.
La prima sezione serve a inizializzare la variabile, la seconda a verificarla, la terza ad aggiornarne il valore.

```c
for (int i = 0; i < 5; i++) {
    printf("Number is %i\n", i);
}
```

È meno verboso dell'equivalente con il ciclo `while`, eppure resta leggibile.

Le sezioni di inizializzazione e di aggiornamento del ciclo `for` possono gestire più di una variabile, usando l'operatore virgola per separare le espressioni all'interno delle condizioni.

```c
    int i, j;
    for (i = 0, j = 5; i < 5 && j > 2; i++, j--) {
        printf("i is %i\n", i);
        printf("j is %i\n", j);
    }
    printf("After the loop");
```

Questo stamperà

```
i is 0
j is 5
i is 1
j is 4
i is 2
j is 3
After the loop
```

Nessuna delle sezioni del ciclo `for` deve essere per forza definita.
Un'espressione di verifica vuota restituisce vero, quindi un ciclo `for` può essere usato per definire un ciclo infinito in questo modo

```c
int i = 0;
for (;;) {
    printf("Number is %i\n", i++);
    if (i == 5) break;
}
```

È simile al ciclo `while` per il fatto che `i` viene inizializzata prima del ciclo ed incrementata al suo interno.
Inoltre, `i` viene verificata all'interno del ciclo ed il ciclo termina con l'istruzione `break`.

## Istruzione break

A volte un ciclo può aver bisogno di terminare in base a una condizione speciale che non viene verificata nella sua espressione booleana.
L'istruzione `break` termina il ciclo e l'esecuzione prosegue con la riga di codice successiva al ciclo.

```c
int i, j, k;
for (int i = 0, j = 5, k = 3; i < 5 && j > 2; i++, j--) {
    printf("i is %i\n", i);
    printf("j is %i\n", j);
    if (k == 3) break;
}
printf("After the loop");
```

Questo stamperà

```
i is 0
j is 5
After the loop
```

## Istruzione continue

A volte un ciclo può aver bisogno di iniziare l'iterazione successiva senza completare quella corrente.
L'istruzione `continue` interrompe l'esecuzione dell'iterazione corrente e riprende dall'inizio dell'iterazione successiva.

```c
int i, j;
for (int i = 0, j = 4; i < 4 && j > 0; i++, j--) {
    if (i == j) continue;
    printf("i is %i\n", i);
    printf("j is %i\n", j);
}
printf("After the loop");
```

Questo stamperà

```
i is 0
j is 4
i is 1
j is 3
i is 3
j is 1
After the loop
```

Non stampa i valori di `i` e `j` quando valgono entrambi `2`.
