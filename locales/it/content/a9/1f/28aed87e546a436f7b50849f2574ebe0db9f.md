# Debug

Quando un test fallisce o il codice non si compila, nella console verrà mostrato un errore. Se non ti è d'aiuto, puoi eseguire il comando [`stack ghci`][docs-stack-ghci] e accedere alla [REPL interattiva][docs-ghci]. Lì puoi provare le funzioni e sperimentare finché non capisci come correggere il codice.

[docs-stack-ghci]: https://docs.haskellstack.org/en/stable/ghci/
[docs-ghci]: https://downloads.haskell.org/~ghc/latest/docs/html/users_guide/ghci.html
