# Introduzione

L'operatore `|>` è chiamato operatore pipe. Può essere usato per concatenare tra loro le chiamate di funzione, in modo che il valore restituito dalla chiamata precedente venga passato a quella successiva.

```gleam
"hello"
|> string.uppercase
|> string.append("?!")
// -> "HELLO?!"
```

Il codice qui sopra è equivalente al seguente:

```gleam
string.append(string.uppercase("hello"), "?!")
```

L'operatore pipe passerà il valore come primo argomento della chiamata di funzione, oppure come unico argomento di una nuova chiamata, scegliendo l'opzione che dà il tipo corretto.

```gleam
100
|> function_that_takes_two_arguments(1)

// Is equivalent to
function_that_takes_two_arguments(100, 1)
```

```gleam
100
|> function_that_returns_a_function(1)

// Is equivalent to
function_that_returns_a_function(1)(100)
```

A volte vogliamo passare il valore in un'altra posizione: in questo caso possiamo usare il segnaposto `_` per indicare dove inserirlo.

```gleam
100
|> some_function(1, _, 2)
```
