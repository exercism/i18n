# Introduzione

La funzione `switch()` può essere un sostituto conciso per una lunga serie di test `if` ... `else if`.
La variabile su cui si esegue lo switch è molto spesso una stringa e, in quel caso, si possono omettere le virgolette nel selettore.

```R
star <- function(type) {
  switch(type,
    M = , # will "fall through" if no value given
    K = "red dwarf",
    G = "Earth-like",
    "bigger star" # only correct for O,B,A,F
  )
}

> star("M")
[1] "red dwarf"
```

Nota che le opzioni ricadono su quella successiva solo se il valore è lasciato vuoto, come per `M` nell'esempio qui sopra.
Non c'è bisogno di includere istruzioni `break`, come invece avviene in altri linguaggi.

Quando si fa lo switch su tipi `character`, il valore finale è un default, come in questo caso.
Con i tipi integer non è invece possibile specificare alcun default.

## Funzioni in `dplyr`

Lo `switch` di R base è piuttosto limitato: esegue solo una corrispondenza esatta con un singolo input.
Sembrava una scelta ragionevole quando R è stato pubblicato per la prima volta nel 1993, ma va migliorato per l'uso moderno.

~~~~exercism/note
Come accennato nel concetto [`Conditionals`][concept-conditionals], la raccolta di pacchetti `tidyverse` è progettata per integrare (e talvolta sostituire) le funzionalità di R base senza compromettere la compatibilità con le versioni precedenti.

Il pacchetto `dplyr` può essere portato nello scope aggiungendo all'inizio del codice `library(dplyr)` (per il singolo pacchetto) oppure `library(tidyverse)` (per l'intera raccolta).

La libreria `dplyr` fornisce due funzioni aggiuntive legate a `switch`.

### Le funzioni `recode_values` e `replace_values`

Queste due funzioni correlate permettono una mappatura vettorizzata, simile a uno switch, dai vecchi valori ai nuovi valori.

La differenza principale tra le due è che `recode_values()` crea un vettore completamente nuovo, mentre `replace_values()` permette aggiornamenti parziali di un vettore esistente.

La corrispondenza resta esatta, ma:

- Le opzioni a sinistra possono essere vettori, e l'input corrisponde se corrisponde almeno un elemento.
- Le opzioni a sinistra e i risultati a destra sono collegati con una tilde `~` invece che con `=`.
- In tutti i casi si può specificare un default.

```R
library(dplyr)

x <- c("a", "b", "a", "d", "b", NA, "c", "e", "z")
recode_values(
  x,
  "a" ~ 1,
  "b" ~ 2,
  "c" ~ 3,
  c("d", "e") ~ 4, # either "d' or "e" will match
  NA ~ 0,          # matches missing values
  default = 100   # note the different syntax for the default
)
#> [1]   1   2   1   4   2   0   3   4 100
```

### La funzione `case_when`

`case_when` porta la sintassi di `case_match` un passo avanti, permettendo qualsiasi espressione logica a sinistra della `~`.

Il vettore di input (`x` nell'esempio sotto) non viene passato come argomento: deve solo essere già definito.

```R
x <- 1:10
case_when(
  x < 3 ~ "low",
  between(x, 3, 5) ~ "mid",
  between(x, 6, 8) ~ "high",
  .default = "what?"
)
#>  [1] "low"   "low"   "mid"   "mid"   "mid"   "high"  "high"  "high"  "what?" "what?"
```

Anche la funzione `between()` fa parte di `dplyr`.
