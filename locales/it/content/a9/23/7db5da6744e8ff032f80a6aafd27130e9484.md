# Introduzione

## Array

In Ruby, gli **array** sono collezioni ordinate di qualsiasi oggetto, indicizzate tramite numeri interi.
L'indicizzazione degli array parte da `0`.
Un indice negativo viene considerato relativo alla fine dell'array: ad esempio, un indice di `-1` indica l'ultimo elemento dell'array, `-2` è il penultimo elemento dell'array e così via.

### Creazione di array

Gli array vengono normalmente creati usando la notazione `[]`.
Possono contenere oggetti di qualsiasi tipo.

```ruby
array = [1, "two", 3.0]
```

### Riferimento agli elementi

Gli elementi di un array possono essere recuperati tramite i loro indici usando il metodo `#[]`.
Questo restituisce l'elemento all'indice specificato, oppure restituisce un sottoarray che inizia dall'indice di partenza e continua per una lunghezza specificata.
Gli indici negativi vengono contati a ritroso a partire dalla fine dell'array.

```ruby
a = [ "a", "b", "c", "d", "e" ]

a[2]       #=> "c"
a[6]       #=> nil
a[1, 3]    #=> [ "b", "c", "d" ]

a[-1]      #=> "e"
a[-2]      #=> "d"
a[-3, 2]   #=> ["c", "d"]
```

### Metodi ausiliari

Ci sono molti metodi ausiliari utili sugli array.
Ecco alcuni dei più comuni:

```ruby
fibonacci = [0, 1, 1, 2, 3, 5, 8, 13]

fibonacci.size      #=> 8
fibonacci.sum       #=> 33
fibonacci.reverse   #=> [13, 8, 5, 3, 2, 1, 1, 0]
```

## Enumerazione

Invece di usare cicli per scorrere le collezioni, in Ruby usiamo l'enumerazione.

L'enumerazione è l'atto di scorrere una collezione (in questo caso un array) ed eseguire un'azione su ciascun oggetto. L'enumerazione è un concetto chiave in Ruby e viene usata per cose come ordinare, raggruppare, mappare, ridurre e molto altro.

Ecco come apparirebbe un'enumerazione per stampare ogni parola in un array:

```ruby
words = ["the", "cat", "sat"]
words.each do |word|
  puts word
end

# Output:
# the
# cat
# sat
```

In questo esempio, abbiamo chiamato il metodo `.each` sul nostro array e passato un _blocco_ che accetta un parametro (`word`) e lo stampa.

Approfondiremo i _blocchi_ molto più avanti nel percorso, ma per ora pensali come funzioni anonime che possono accettare zero o più argomenti.
Possono essere definiti usando la sintassi `do...end` (sopra) o la sintassi `{}` (sotto).

Ecco alcuni altri esempi di metodi degli array che usano blocchi:

```ruby
fibonacci = [0, 1, 1, 2, 3, 5, 8, 13]

fibonacci.count  { |number| number == 1 }   #=> 2
fibonacci.any?   { |number| number == 6 }   #=> false
fibonacci.select { |number| number.odd? }   #=> [1, 1, 3, 5, 13]
fibonacci.all?   { |number| number < 20 }   #=> true
fibonacci.map    { |number| number * 2  }   #=> [0, 2, 2, 4, 6, 10, 16, 26]
```
