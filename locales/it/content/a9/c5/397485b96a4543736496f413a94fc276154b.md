# Informazioni

I principali operatori aritmetici e di confronto possono essere adattati per essere usati dalle tue classi e dalle tue struct. Questo è noto come «sovraccarico degli operatori».

Questo [articolo][operator-overloading] è una trattazione approfondita della sintassi, nonché di quali operatori si possono sovraccaricare e quali no.

La maggior parte degli operatori ha la forma:

```csharp
static <return type> operaator <operator symbols>(<parameters>);
```

Gli [operatori di cast][ud-conversion-operators] hanno la forma:

```csharp
static (explicit|implicit) operator <cast-to-type>(<cast-from-type> <parameter name>);
```

Gli operatori si comportano allo stesso modo dei metodi statici.

- Il simbolo di un operatore prende il posto dell'identificatore di un metodo, e ha parametri e un tipo restituito. Le regole sui tipi per i parametri e per il tipo restituito seguono l'intuito, e puoi contare sul compilatore per avere indicazioni dettagliate.
- Nelle operazioni binarie il primo parametro riceve l'argomento di sinistra dell'operazione.
- Gli operatori hanno una firma composta da due parametri (nel caso delle operazioni binarie) e un tipo restituito, oppure da un solo parametro e un tipo restituito nel caso degli operatori unari.
- Per gli operatori binari, uno dei tipi dei parametri deve essere quello della classe dichiarante.
- Nel caso delle conversioni di tipo, il parametro o il tipo restituito deve essere il tipo della classe dichiarante.
- Per gli operatori di incremento e di decremento, il parametro e il tipo restituito devono essere quelli della classe dichiarante.

Esempi di sintassi:

```csharp
struct Point
{
    decimal x;
    decimal y;

    public static bool operator ==(Point pt, Point ptOther)
    {
        return pt.x == ptOther.x && pt.y == ptOther.y;
    }

    public static bool operator !=(Point pt, Point ptOther)
    {
        return !(pt == ptOther);
    }

    public static Point operator *(Point pt, decimal scale)
    {
        var ptNew = new Point();
        ptNew.x = pt.x * scale;
        ptNew.y = pt.y * scale;
        return ptNew;
    }

    public static implicit operator Point((decimal x, decimal y) xy)
    {
        var pt = new Point();
        pt.x = xy.x;
        pt.y = xy.y;
        return pt;
    }

    public static explicit operator (decimal x, decimal y)(Point pt)
    {
        return (pt.x, pt.y);
    }
}
```

Spesso è produttivo implementare un metodo [`Equals()`][equals] e chiamarlo dall'operatore `==`. Allo stesso modo, per i confronti puoi implementare l'interfaccia [`IComparable`][icomparable]. In entrambi i casi prendi due piccioni con poco più di una fava.

Nota che non puoi creare operatori a partire da simboli che non fanno parte dell'insieme standard degli operatori. Puoi usare solo simboli esistenti per quelle operazioni che la documentazione indica come sovraccaricabili. Gli operatori che si possono sovraccaricare sono elencati [qui][overloadable-operators].

Nota che l'ordine dei parametri è importante quando differiscono per tipo. Nel codice di esempio qui sopra `pt * 10m` è un'espressione valida, mentre `10m * pt` non verrà compilato.
