# Istruzioni

Mentre continui a lavorare presso _Instruments of Texas_, si stanno facendo progressi sull'implementazione in Elixir della calcolatrice RPN. Il tuo team vorrebbe poter sollevare errori più specifici di quelli generici forniti dalla libreria standard. Stai facendo qualche ricerca, ma hai deciso di implementare due nuovi errori che seguono l'_Exception Behaviour_.

## 1. Errore per la divisione per zero

Dividere un numero per zero produce un risultato indefinito: il team ha deciso che è meglio rappresentarlo con un errore.

Implementa il modulo `DivisionByZeroError` in modo che abbia il messaggio di errore: `"division by zero occurred"`

```elixir
raise DivisionByZeroError
# => ** (DivisionByZeroError) division by zero occurred
```

## 2. Errore quando si verifica uno stack underflow

Le calcolatrici RPN usano uno _stack_ per tenere traccia dei numeri prima che vengano utilizzati nei calcoli. Il team rappresenta questo _stack_ con un array di numeri (interi e in virgola mobile), ad esempio: `[3, 4.0]`. Ogni operazione richiede una quantità precisa di numeri sullo stack per poter eseguire il proprio calcolo. Quando sullo stack non ci sono abbastanza numeri, si parla di errore di stack underflow. Implementa l'eccezione `StackUnderflowError`, che fornisce un messaggio predefinito e un contesto aggiuntivo opzionale

```elixir
raise StackUnderflowError
# => ** (StackUnderflowError) stack underflow occurred

raise StackUnderflowError, "when dividing"
# => ** (StackUnderflowError) stack underflow occurred, context: when dividing
```

## 3. Scrivi una funzione di divisione

Implementa la funzione `divide/1`, che prende uno stack _(un array di due numeri)_ e:

- solleva _stack underflow_ quando lo stack non contiene abbastanza numeri
- solleva _division by zero_ quando il divisore è 0 (nota che lo stack di numeri è memorizzato in ordine inverso)
- esegue la divisione quando non viene sollevato alcun errore

```elixir
RPNCalculator.Exception.divide([])
# => ** (StackUnderflowError) stack underflow occurred, context: when dividing

RPNCalculator.Exception.divide([0, 100])
# => ** (DivisionByZeroError) division by zero occurred

RPNCalculator.Exception.divide([4, 16])
# => 4
```

> Nota che l'ordine dell'array è invertito!
