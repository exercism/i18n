# Informazioni

In Haxe, gli iteratori servono a iterare su un valore usando un ciclo `for`. Esistono due tipi di iteratori:

- `Iterator`, che itera su un valore.
- i dati `Iterable`, che rendono possibile iterare su un tipo di dato.

Entrambi questi concetti sono rappresentati da `Iterator<T>` e `Iterable<T>`:

```haxe
typedef Iterator<T> = {
  function hasNext():Bool;
  function next():T;
}

typedef Iterable<T> = {
  function iterator():Iterator<T>;
}
```

Qualsiasi classe che unifica con uno di questi tipi può essere iterata usando un ciclo `for`. Se una classe definisce i metodi `hasNext` e `next`, è considerata un iteratore; altrimenti, se definisce un metodo `iterator`, è considerata un tipo iterabile:

```haxe
class MyStringIterator {
  var str:String;
  var i:Int;

  public function new(str:String) {
    this.str = str;
    i = 0;
  }

  public function hasNext():Bool {
    return i < str.length;
  }

  public function next():String {
    return str.charAt(i++);
  }
}
```

Nell'esempio precedente, la classe `MyStringIterator` è considerata un iteratore poiché implementa entrambi i metodi `hasNext` e `next`, rendendola compatibile con `Iterator<String>`.

```haxe
class MyArrayWrap<T> {
  var arr:Array<T>;

  public function new(a:Array<T>) {
    this.a = a;
  }

  public function iterator() {
    return a.iterator();
  }
}
```

Qui, la classe `MyArrayWrap` è considerata un tipo di dato iterabile poiché è compatibile con `Iterable<Array<T>>`.
