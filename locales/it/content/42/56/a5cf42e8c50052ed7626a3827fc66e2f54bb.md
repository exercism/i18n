# Introduzione

## Valori predefiniti dei parametri

I [valori predefiniti dei parametri][default-parameter-values] possono essere assegnati a qualsiasi parametro di una funzione assegnando un valore al parametro nella lista dei parametri, subito dopo l'annotazione di tipo del parametro. Quando un parametro ha un valore predefinito, chi chiama la funzione può omettere quel parametro e al suo posto verrà usato il valore predefinito.

```swift
func greeting(name: String = "guest", duration: Int = 2) -> String {
  "Welcome, \(name). Enjoy your \(duration) night stay."
}

greeting(name: "Bobo", duration: 7)
// Returns "Welcome, Bobo. Enjoy your 7 night stay."
greeting(duration: 3)
// Returns "Welcome, guest. Enjoy your 3 night stay."
greeting(name: "Wynona")
// Returns "Welcome, Wynona. Enjoy your 2 night stay."
greeting()
// Returns "Welcome, guest. Enjoy your 2 night stay."
```

## Parametri variadici

I [parametri variadici][variadic-parameters] permettono a una funzione di accettare zero o più valori di un tipo specificato per un singolo parametro.
Si definisce un parametro variadico aggiungendo tre punti (`...`) all'annotazione di tipo del parametro.

All'interno del corpo della funzione, Swift rende questi valori disponibili come un array del tipo specificato:

```swift
import Foundation

func geometricMean(_ numbers: Double...) -> Double {
    var total = 1.0
    for number in numbers {
        total *= number
    }
    return pow(total, 1.0 / Double(numbers.count))
}

let result = geometricMean(1, 2, 3, 4, 5)
// result is 2.605171084697352
```

~~~~exercism/note
Se una funzione include altri parametri dopo un parametro variadico, il primo parametro che segue il parametro variadico **deve** avere un'etichetta di argomento esplicita, così Swift sa dove finisce la lista degli argomenti variadici.
~~~~


## Parametri in-out

All'interno del corpo di una funzione, i parametri sono trattati come costanti, non come variabili; se provi a modificarne il valore, ottieni un errore in fase di compilazione.
Se una funzione vuole modificare il valore di un parametro, deve usare un [_parametro in-out_][in-out-parameters] per rendere esplicita questa mutabilità.

Per usare i parametri in-out, chi programma deve fare attenzione a tre cose:

1. La definizione della funzione deve contrassegnare esplicitamente i parametri in-out scrivendo la parola chiave `inout` tra i `:` e il nome del tipo nell'annotazione di tipo del parametro.
2. Il valore passato al parametro in-out deve essere dichiarato come variabile, non come costante. Allo stesso modo, non può essere un letterale.
3. Il nome della variabile deve essere preceduto da un `&` nella chiamata alla funzione, contrassegnandola esplicitamente come modificabile.

Quando tutto questo è rispettato, la funzione crea una copia interna del parametro in-out, la modifica come indicato nel corpo della funzione e poi, quando la funzione restituisce, copia il valore modificato nella variabile che era stata passata.

```swift
func updateVersion(_ record: inout (version: Int, title: String)) {
  record.version += 1
}

var dbRecord = (version: 2, title: "Exercism")
updateVersion(&dbRecord)

// dbRecord is now (3, "Exercism")
```

~~~~exercism/warning
Ci sono un paio di regole aggiuntive da tenere presenti riguardo ai parametri in-out.

1  All'interno di una funzione con parametri in-out, non puoi fare riferimento alla variabile passata come parametro in-out.
2. La stessa variabile non può essere passata come più parametri in-out nella stessa funzione.
   Per esempio, `inoutFunc(&mutVar, &mutVar)` genera un errore del compilatore.
~~~~

## Funzioni annidate

In Swift, puoi definire [funzioni all'interno di altre funzioni][nested-functions].
Queste sono note come **funzioni annidate**.

Le funzioni annidate si usano comunemente come funzioni ausiliarie private, che svolgono compiti specifici per la funzione che le contiene senza ingombrare lo scope esterno:

```swift
func makeNumber(_ number: Int) -> Int {
    func double(_ x: Int) -> Int {
        x * 2
    }

    func increment(_ x: Int) -> Int {
        x + 1
    }

    return number.isMultiple(of: 2) ? increment(double(number)) : double(number)
}

print(makeNumber(3)) // Prints 6
print(makeNumber(4)) // Prints 9
```

Le funzioni annidate si comportano come le funzioni normali, ma la loro visibilità è limitata al corpo della funzione che le contiene.
