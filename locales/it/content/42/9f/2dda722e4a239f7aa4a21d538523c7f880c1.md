# Appendice alle istruzioni

## Registri

| Registro | Utilizzo   | Tipo     | Descrizione                                       |
| -------- | ---------- | -------- | ------------------------------------------------- |
| `$a0`    | input      | intero   | numero                                            |
| `$v0`    | output     | booleano | è un numero di Armstrong (`0` = `false`, `1` = `true`) |
| `$t0-9`  | temporaneo | qualsiasi | usato per la memoria temporanea                   |
