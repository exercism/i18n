# Test

Ogni esercizio fornisce gli unit test e una ricetta di build di Make.
L'implementazione la fornisci tu.

Ogni file di test va collegato all'implementazione per ottenere un eseguibile da console che esegue i test.
Eseguendo l'eseguibile dei test viene stampato un messaggio per ogni test che fallisce e, quando i test falliscono, viene riportato un codice di uscita diverso da zero.

Per svolgere un esercizio:
* Crea la build iniziale con Make
* Per ogni unit test:
  * Rimuovi la riga `TEST_IGNORE()`.
  * Risolvi gli eventuali errori di compilazione per far sì che il test fallisca.
  * Implementa lo stretto necessario per far passare il test.
  * Riorganizza l'implementazione per migliorarne la leggibilità, ridurre le duplicazioni e così via.
