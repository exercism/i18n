# Test

## Eseguire i test

Quando ti trovi nella directory di un esercizio, dovresti vedere due sottodirectory:

* `src` contiene la soluzione per l'esercizio
* `spec` contiene i test da eseguire per l'esercizio

Se ti trovi nella directory giusta (cioè quella che contiene `src` e `spec`), puoi eseguire i test per quell'esercizio con `crystal spec`:

```bash
$ pwd
/Users/johndoe/Code/exercism/crystal/hello-world

$ ls
GETTING_STARTED.md README.md          spec               src

$ crystal spec
```

Questo eseguirà tutti i file di test nella directory `spec`.

In ogni file di test, tutti i test tranne il primo sono stati saltati.

Quando riesci a far passare un test, puoi riattivare il successivo cambiando `pending` in `it`.

## Formattazione di Crystal

Prima di inviare, ti consigliamo di eseguire `crystal tool format` sulla soluzione.

Puoi formattare tutto nella directory corrente con:

```bash
$ crystal tool format ./
```

Oppure puoi formattare file specifici con:

```bash
$ crystal tool format ./<path>/<to>/<file>
```

## Inviare la soluzione

Assicurati di inviare il file sorgente nella directory `src` quando invii la soluzione:

```bash
$ exercism submit src/<exercise>.cr
```
