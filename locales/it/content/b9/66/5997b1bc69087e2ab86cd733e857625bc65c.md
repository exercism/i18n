# Test

## Configurazione

Segui le [istruzioni di configurazione per WebAssembly][docs-exercism-wasm] per installare le dipendenze necessarie.

## Requisiti

Installa le dipendenze dell'esercizio:

```shell
# Using npm
npm install

# Alternatively using yarn
yarn
```

## Far passare la suite di test

Tutti gli esercizi includono una suite di test che ti aiuta a validare la soluzione prima di inviarla.
Puoi eseguire questi test aprendo un terminale nella cartella dell'esercizio e lanciando:

```bash
# Using npm
npm test

# Alternatively using yarn
yarn test
```

In alcune suite di test, tutti i test tranne il primo sono stati saltati.

Quando riesci a far passare un test, puoi abilitare il successivo cambiando `xtest` in `test`.

## Scrivere test personalizzati

Se vuoi scrivere test aggiuntivi e personalizzati, crea un nuovo file `custom.spec.js` e invialo insieme alla soluzione:

```shell
exercism submit numbers.wat custom.spec.js
```

[docs-exercism-wasm]: https://exercism.org/docs/tracks/wasm/installation
