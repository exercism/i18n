# Informazioni

Un valore booleano rappresenta se una condizione è `true` o `false`.
In Go, il tipo `bool` può essere solo uno di questi due valori.

```go
isDoorLocked := true
hasKey := true
knowsCode := false
```

## Operatori logici

Gli operatori logici operano su uno o due valori booleani e producono un risultato booleano.

| Operatore | Nome | Comportamento                                  |
| -------- | ---- | ---------------------------------------------- |
| `!`      | NOT  | Restituisce l'opposto di un singolo valore booleano |
| `&&`     | AND  | Restituisce `true` solo quando entrambi i lati sono `true` |
| `\|\|`   | OR   | Restituisce `true` se almeno un lato è `true`           |

Usa `!` (NOT) quando ti serve l'opposto di un valore booleano:

```go
!isDoorLocked // false
```

Usa `&&` (AND) quando entrambe le condizioni devono essere `true`:

```go
canUnlockDoor := isDoorLocked && hasKey // true
```

Usa `||` (OR) quando almeno una condizione deve essere `true`:

```go
canOpenDoor := canUnlockDoor || knowsCode // true
```

Gli operatori logici vengono valutati in questo ordine: prima `!`, poi `&&`, poi `||`.
Usa le parentesi per raggruppare il codice e controllare quali operazioni vengono eseguite per prime:

```go
!true && false   // false because !true is evaluated first
!(true && false) // true because true && false is evaluated first
```
