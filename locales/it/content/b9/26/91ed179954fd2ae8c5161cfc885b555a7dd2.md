# Introduzione

I commenti ti permettono di lasciare note nel codice senza influire sul modo in cui viene eseguito.
I commenti su una sola riga iniziano con `//`, mentre quelli su più righe sono racchiusi tra `/*` e `*/`:

```go
// This is a single-line comment.

/*
This is a
multiline comment.
*/
```

I commenti hanno scopi diversi a seconda di dove compaiono.

## Commenti nel codice

I commenti nel codice spiegano perché qualcosa viene fatto, non che cosa viene fatto.
Usali quando il motivo dietro una decisione non è ovvio dal codice:

```go
results = results[1:] // skipping the header row
```

## Commenti di documentazione

I commenti di documentazione si trovano direttamente prima di una dichiarazione, senza una riga vuota che separi il commento dalla dichiarazione.
[`godoc`][godoc] li analizza per generare la documentazione del pacchetto.
Un commento di documentazione dovrebbe essere una frase completa che inizia con il nome dell'identificatore e termina con un punto.

I commenti di pacchetto iniziano con il nome del pacchetto:

```go
// Package kelvin provides tools to convert temperatures to and from Kelvin.
package kelvin
```

I commenti di funzione iniziano con il nome della funzione:

```go
// CelsiusFreezingTemp returns an integer value equal to the temperature at which water freezes in degrees Celsius.
func CelsiusFreezingTemp() int {
	return 0
}
```

[godoc]: https://go.dev/blog/godoc
