# Introduzione

## Durate e periodi

Classi come `LocalDate` e `LocalDateTime` descrivono un _punto_ nel tempo. Il pacchetto `java.time` contiene anche due classi che descrivono una _quantità_ di tempo:

- `java.time.Period` è una quantità di tempo in anni, mesi e giorni, come «2 mesi e 5 giorni».
- `java.time.Duration` è una quantità di tempo in ore, minuti, secondi, millisecondi e nanosecondi, come «1 ora e 30 minuti».

Un `Period` segue il calendario, quindi si usa con le date e con i valori di data e ora. Una `Duration` misura il tempo esatto, quindi si usa con gli orari e con i valori di data e ora, ma non con le date.

```exercism/note
Come le altre classi di `java.time`, `Period` e `Duration` sono immutabili.
I metodi che sembrano modificarli restituiscono invece una _nuova_ istanza.
```

### `Period`

Un `Period` si crea con uno dei suoi metodi statici di creazione:

```java
Period.ofDays(10);
// => P10D

Period.ofMonths(3);
// => P3M

Period.of(1, 2, 15);
// => P1Y2M15D
```

Il risultato di `toString()` usa la notazione [ISO-8601][iso-8601-durations]: `P` (per «period») seguito dal numero di anni (`Y`), di mesi (`M`) e di giorni (`D`).

Si può aggiungere o sottrarre un periodo a una data:

```java
LocalDate date = LocalDate.of(2024, 3, 10);

date.plus(Period.ofMonths(2));
// => 2024-05-10

date.minus(Period.ofDays(10));
// => 2024-02-29
```

Dato che i mesi hanno lunghezze diverse, aggiungere dei mesi può far finire su un giorno che non esiste. In quel caso il risultato viene spostato all'indietro fino all'ultimo giorno valido del mese:

```java
LocalDate.of(2025, 1, 31).plus(Period.ofMonths(1));
// => 2025-02-28
```

`Period.between()` restituisce il periodo da una data (inclusa) a un'altra (esclusa):

```java
LocalDate start = LocalDate.of(2023, 3, 10);
LocalDate end = LocalDate.of(2024, 5, 25);

Period period = Period.between(start, end);
// => P1Y2M15D

period.getYears();
// => 1
period.getMonths();
// => 2
period.getDays();
// => 15
```

### Contare le unità con `ChronoUnit`

Un `Period` tiene separati anni, mesi e giorni. Quindi `getDays()` restituisce solo la _parte_ dei giorni del periodo, non il numero totale di giorni. Per contare il numero totale di una singola unità tra due date, usa il metodo `between()` di [`java.time.temporal.ChronoUnit`][chronounit-docs]:

```java
LocalDate start = LocalDate.of(2024, 1, 15);
LocalDate end = LocalDate.of(2024, 3, 20);

Period.between(start, end);
// => P2M5D

Period.between(start, end).getDays();
// => 5

ChronoUnit.DAYS.between(start, end);
// => 65
```

Il risultato è negativo quando la seconda data precede la prima:

```java
ChronoUnit.DAYS.between(end, start);
// => -65
```

### `Duration`

Anche una `Duration` si crea con metodi statici di creazione:

```java
Duration.ofMinutes(90);
// => PT1H30M

Duration.ofHours(2).plusMinutes(15);
// => PT2H15M
```

Nella notazione ISO-8601, la `T` separa la parte relativa alla data da quella relativa all'ora: è per questo che le durate si scrivono come `PT...`.

Si può aggiungere o sottrarre una durata a un valore di data e ora:

```java
LocalDateTime start = LocalDateTime.of(2024, 3, 10, 22, 30);

start.plus(Duration.ofMinutes(90));
// => 2024-03-11T00:00
```

`Duration.between()` restituisce la quantità esatta di tempo tra due valori di data e ora:

```java
LocalDateTime checkIn = LocalDateTime.of(2024, 3, 10, 18, 5);
LocalDateTime checkOut = LocalDateTime.of(2024, 3, 10, 19, 40);

Duration.between(checkIn, checkOut);
// => PT1H35M
```

Una durata si può convertire in una singola unità con metodi come `toHours()`, `toMinutes()` e `toSeconds()`. Questi restituiscono la quantità _totale_ in quell'unità, arrotondata per difetto:

```java
Duration duration = Duration.ofMinutes(95);

duration.toHours();
// => 1
duration.toMinutes();
// => 95
```

Per scomporre una durata nelle sue parti, come su un orologio, usa invece i metodi `toXxxPart()`:

```java
Duration duration = Duration.ofMinutes(95);

duration.toHoursPart();
// => 1
duration.toMinutesPart();
// => 35
```
