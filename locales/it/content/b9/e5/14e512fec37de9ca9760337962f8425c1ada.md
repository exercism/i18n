## 1. Estrai le coordinate

Implementa la funzione `get_coordinate()` che prende una coppia `(treasure, coordinate)` dalla lista di Azara e restituisce solo la coordinata sulla mappa estratta.


```python
>>> get_coordinate(('Scrimshawed Whale Tooth', '2A'))
2A
```

## 2. Formatta le coordinate

Implementa la funzione `convert_coordinate()` che prende una coordinata nel formato «2A» e restituisce una tupla nel formato `("2", "A")`.


```python
>>> convert_coordinate("2A")
("2", "A")
```

## 3. Abbina le coordinate

Implementa la funzione `compare_records()` che prende una coppia `(treasure, coordinate)` e un record `(location, coordinate, quadrant)` e confronta le coordinate di ciascuno.
Restituisci **`True`** se le coordinate «corrispondono», e restituisci **`False`** se no.
Riformatta le coordinate come serve per un confronto accurato.


```python
>>> compare_records(('Brass Spyglass', '4B'), ('Seaside Cottages', ('1', 'C'), 'blue'))
False

>>> compare_records(('Model Ship in Large Bottle', '8A'), ('Harbor Managers Office', ('8', 'A'), 'purple'))
True
```

## 4. Combina i record abbinati

Implementa la funzione `create_record()` che prende una coppia `(treasure, coordinate)` dalla lista di Azara e un record `(location, coordinate, quadrant)` dalla lista di Rui e restituisce `(treasure, coordinate, location, coordinate, quadrant)` **se le coordinate corrispondono**.
Se le coordinate _non_ corrispondono, restituisci la stringa **"not a match"**.
Riformatta la coordinata come serve per un confronto accurato.


```python
>>> create_record(('Brass Spyglass', '4B'), ('Abandoned Lighthouse', ('4', 'B'), 'Blue'))
```
