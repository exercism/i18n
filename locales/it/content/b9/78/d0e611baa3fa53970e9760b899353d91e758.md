# Stringhe

`STR` contiene testo. Una stringa si scrive tra virgolette doppie.

```sather
   composer : STR is
      return "Sibelius";
   end;
```

Una `STR` non cambia mai una volta che esiste. Tutto ciò che segue risponde con una *nuova* stringa, invece di modificare quella su cui è stata interrogata.

## Concatenazione

```sather
"Jean" + " " + "Sibelius"      -- "Jean Sibelius"
```

`+` unisce anche un numero a una stringa: è così che un numero entra in una frase.

```sather
"Opus " + 27           -- "Opus 27"
```

## Lunghezza

```sather
"Sibelius".size        -- 8
"".size                -- 0
```

`.size` conta i caratteri, e la risposta è un `INT`.

## Parti

| Chiamata | Risposta |
| --- | --- |
| `"Sibelius".head(3)` | `"Sib"` |
| `"Sibelius".tail(4)` | `"lius"` |

Chiedere più di quanto c'è restituisce quello che c'è, invece di fallire.

## Confronto

`=` chiede se due stringhe sono lo stesso testo, e `/=` se differiscono.

```sather
"forte" = "forte"      -- true
"forte" = "Forte"      -- false
```

Le maiuscole contano. `.upper` e `.lower` danno una copia tutta in maiuscolo o tutta in minuscolo, che è il modo usuale per confrontare senza badarci.

```sather
"Forte".lower                    -- "forte"
"Forte".lower = "forte".lower    -- true
```

## Una parola sulla dimensione

Una `STR` è una riga di byte, e `.size` conta i byte. Per il testo in inglese è come contare le lettere. Per un testo con accenti o altri alfabeti non lo è, perché quelle lettere occupano più di un byte ciascuna.
