## Generale

Non implementare la struct `SimpleLinkedList` come wrapper attorno a un `Vec`. Alloca invece i nodi nell'heap.

Una possibile implementazione è questa:

```
pub struct SimpleLinkedList<T> {
    head: Option<Box<Node<T>>>,
}
```

Il campo `head` punta al primo elemento (Node) di questa lista concatenata.

Questa implementazione richiede anche una struct `Node` con i seguenti campi:

```
struct Node<T> {
    data: T,
    next: Option<Box<Node<T>>>,
}
```

`data` contiene i dati memorizzati, mentre `next` punta al nodo successivo (se esiste) oppure a None.

## Perché `Option<Box<Node<T>>>` e non solo `Option<Node<T>>`?

Provalo da solo. Otterrai il seguente errore.

```
| struct Node<T>
| ^^^^^^^^^^^^^^ recursive type has infinite size
...
|     next: Option<Node<T>>,
|     --------------------- recursive without indirection
```

Il problema è che in fase di compilazione la dimensione di next deve essere nota.
Dato che `next` è ricorsivo («un nodo ha un nodo che ha un nodo...»), il compilatore non sa quanta memoria deve allocare.
Al contrario, [Box](https://doc.rust-lang.org/std/boxed/) è un puntatore all'heap con una dimensione definita.
