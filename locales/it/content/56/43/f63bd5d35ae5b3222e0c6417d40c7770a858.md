# Introduzione

## Le stringhe

Le stringhe sono una serie di caratteri, racchiusi tra virgolette.
Sono supportate sia le virgolette singole che quelle doppie.

```php
<?php

$where = "Spain";
$what = 'rain';
```

### Espansione delle variabili nelle stringhe

Nelle stringhe racchiuse tra virgolette doppie, se si fa riferimento a una variabile che è nello scope, il suo valore viene inserito nella stringa.

```php
<?php

$answer = 42;
$expanded = "The answer to life, the universe, and everything is $answer"; 
```

### Supporto alla codifica dei caratteri

Storicamente, le funzioni per le stringhe in PHP supportavano solo i caratteri ASCII e non supportavano le moderne codifiche Unicode.
I caratteri ASCII occupano 1 byte ciascuno, mentre i caratteri Unicode possono essere lunghi da 1 a 4 byte.
Se hai bisogno di manipolare stringhe Unicode in modo sicuro, fai riferimento alle [versioni multibyte][multi-byte-fns] delle funzioni storiche.

```php
<?php

$byte_length = strlen('😃'); // => 4
$string_length = mb_strlen('😃'); // => 1
```

[multi-byte-fns]: https://www.php.net/manual/en/ref.mbstring.php
