# Introduzione

Go è tipizzato staticamente: ogni variabile ha un tipo noto al momento della compilazione.
Una volta dichiarata, il tipo di una variabile non può più cambiare.

## Creare una variabile

L'istruzione `var` può dichiarare il tipo di una nuova variabile, impostarne il valore, oppure fare entrambe le cose insieme:

```go
var total int     // Type explicitly declared, value implicitly set (see note on zero values below)
var count int = 1 // Type explicitly declared, value explicitly set
var sum = 100     // Type implictly declared, value explicitly set
```

All'interno di una funzione si può usare anche l'istruzione di assegnazione breve `:=`.

```go
count := 1 // Type implictly declared, value explicitly set
```

In Go una variabile ha sempre un valore.
Se non ne viene impostato uno al momento della dichiarazione, Go ne fornisce uno [chiamato valore zero][zero-values], in base al tipo della variabile.

```go
var total int     // 0
var name string   // ""
var ready bool    // false
```

## Aggiornare una variabile

All'interno di una funzione, l'operatore di assegnazione `=` può impostare un nuovo valore per una variabile esistente:

```go
count := 1
count = 2
```

Il nuovo valore deve avere lo stesso tipo della variabile:

```go
count := 1
count = false // compile error: a Boolean is not an int
```

[zero-values]: https://exercism.org/tracks/go/concepts/zero-values
