# Installa `testthat`

I test di questa traccia utilizzano il pacchetto `testthat`.

Per installare il pacchetto, apri R ed esegui:

`install.packages("testthat")`

Puoi verificare che il pacchetto sia installato correttamente eseguendo:

`library(testthat)`

# Eseguire i test

Ogni esercizio avrà uno script chiamato `test_<exercise-name>.R` (ad esempio `test_hello-world.R`).

Per eseguire i test di un esercizio, basta eseguire questo script R.

In RStudio, è sufficiente aprire lo script di test e fare clic su "Source" in alto a destra nel riquadro del codice. In questo modo, il comando `source` sulla prima riga dello script di test caricherà il codice della soluzione ed eseguirà la suite di test di `testthat` che segue.

Tieni però presente che il comando `source()` sulla prima riga dello script di test funziona solo se lo script della soluzione (`<exercise-name>.R`) si trova nella directory di lavoro. In caso contrario, dovrai:
- cambiare la directory di lavoro, ad esempio `setwd('exercism/r/hello-world/')`, oppure
- aggiornare la prima riga dello script di test, ad esempio `source('exercism/r/hello-world/hello-world.R')`

Se preferisci, puoi anche eseguire i test dalla riga di comando con `Rscript path_to_exercise_directory/test_<exercise-name>.R` (ad esempio `Rscript hello-world/test_hello-world.R`)

Un altro modo comodo per eseguire questi test è usare la [funzione `auto_test` di testthat](https://www.rdocumentation.org/packages/testthat/topics/auto_test). Dato che il codice e i test di Exercism si trovano nella stessa cartella, usa lo stesso percorso per entrambi i parametri `code_path` e `test_path`. Dopo aver eseguito `auto_test()`, i test dell'esercizio verranno eseguiti automaticamente ogni volta che aggiorni o salvi il codice R dell'esercizio. Questo può aiutare a iterare rapidamente mentre lavori alla soluzione.
