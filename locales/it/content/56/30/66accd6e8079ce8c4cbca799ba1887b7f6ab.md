# Appendice alle istruzioni

## `Print` non mette tra virgolette i valori stringa

In questo esercizio si manipolano punteggi numerici.
#[a: 1]` and `#[a: "1"]` non sono la stessa cosa:

```arturo
inspect #[a: 1]
; [ :dictionary
;        a  :        1 :integer
; ]

inspect #[a: "1"]
; [ :dictionary
;        a  :        1 :string
; ]
equal? #[a: "1"] #[a: 1]
; false
```

Una pratica di debug comune è quella di usare `print` sui valori.
Tuttavia, l'output non aggiunge virgolette attorno alle stringhe.
Quindi una stringa numerica come `"1"`, quando viene stampata, appare identica al numero intero `1`.

```arturo
print #[a: 1]
; [a:1]
print #[a: "1"]
; [a:1]
```
Nell'output dei test di questo esercizio potresti vedere un risultato come `:x: equal? [a:1 e:1 i:1 o:1 u:1] [a:1 e:1 i:1 o:1 u:1]`.
I due dizionari confrontati appaiono identici quando vengono stampati.
Tuttavia, il primo dizionario ha valori stringa numerici e il secondo ha valori interi, quindi non sono la stessa cosa.
Quando fai debug, puoi usare `inspect` per controllare il contenuto del dizionario.

## `Express` mette tra virgolette i valori stringa

`express` converte un valore in codice Arturo e restituisce una stringa con la rappresentazione di quel codice.
In quel risultato, ogni valore stringa viene messo tra virgolette.
Di conseguenza, `express "1"` restituirà `"1"`, non `1`.

```arturo
express #[name: "Octavius" age: 22]
; #[name: "Octavius" age: 22 ]
```
```arturo
express #[name: "Octavius" age: "22"]
; #[name: "Octavius" age: "22" ]
```
