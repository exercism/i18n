# Installazione

Per ottenere le istruzioni di installazione consigliate per la tua piattaforma,
vai sul [sito ufficiale di Rust][the official Rust website].

Avere la toolchain installata non è tutto!
Il supporto dell'IDE è un enorme aumento di produttività che la maggior parte degli sviluppatori ormai si aspetta.
Se usi Visual Studio Code, dai un'occhiata alla sua [documentazione per il supporto a Rust][vscode].
Ti consigliamo inoltre caldamente di abilitare [il linting con clippy][vscode-linting]!

[the official Rust website]: https://www.rust-lang.org/tools/install
[vscode]: https://code.visualstudio.com/docs/languages/rust
[vscode-linting]: https://code.visualstudio.com/docs/languages/rust#_linting
