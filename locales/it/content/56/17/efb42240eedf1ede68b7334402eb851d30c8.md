# Istruzioni

In questo esercizio applicherai le [regole del gioco del Go](https://matmoore.github.io/learngo/). Le regole sono già scritte: devi solo applicarle per aggiornare il Game e gestire eventuali errori o violazioni delle regole.

Il Game è rappresentato così:

```gleam
pub type Player {
  Black
  White
}


pub type Game {
  Game(
    white_captured_stones: Int,
    black_captured_stones: Int,
    player: Player,
    error: String,
  )
}
```

Il gioco prevede 4 regole:

- Ogni punto può contenere una sola pietra.
- Le pietre avversarie possono essere catturate.
- Non puoi posizionare una pietra dove catturerebbe se stessa.
- Non puoi usare lo stesso punto due volte.

## 1. Applicare le regole

Scrivi il contenuto della funzione `apply_rules`, che riceve un `Game` iniziale e un insieme di regole, e restituisce il nuovo `Game` dopo che le regole sono state applicate.

Tre di queste regole controllano eventuali violazioni e possono restituire un errore, quindi hanno come tipo di ritorno `Result(Game, String)`. Se una di queste regole fallisce, va restituito il Game originale, ma con il campo `error` aggiornato con l'errore corrispondente.

L'altra regola non controlla le violazioni e quindi non può fallire (anche se può restituire un `Game` modificato), perciò ha come tipo di ritorno `Game`.

Se tutte le regole passano, le modifiche apportate al `Game` vanno mantenute e il giocatore va cambiato.

```gleam
pub fn apply_rules(
  game: Game,
  rule1: fn(Game) -> Result(Game, String),
  rule2: fn(Game) -> Game,
  rule3: fn(Game) -> Result(Game, String),
  rule4: fn(Game) -> Result(Game, String),
) -> Game {
  // -> If all rules pass, return a `Game` with all changes from the rules applied, and change player
  // -> If any rule fails, return the original Game, but with the error field set
}
```
