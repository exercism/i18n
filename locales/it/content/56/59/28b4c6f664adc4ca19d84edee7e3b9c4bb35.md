# Parametri variadici

I [_parametri variadici_][variadic-parameters] in Swift consentono di passare zero o più valori dello stesso tipo a un singolo parametro di una funzione. Questo si indica aggiungendo `...` all'annotazione di tipo del parametro.

Questi valori verranno raggruppati automaticamente in un array con elementi dello stesso tipo del parametro variadico.

```swift
func geometricMean(_ numbers: Double...) -> Double {
  var total = 1.0
  for number in numbers {
      total *= number
  }
  return pow(total, 1.0 / Double(numbers.count))
}

geometricMean(1, 2, 3, 4, 5)
// => 2.605171084697352
```

Nota che, quando si usano parametri variadici, Swift ha una limitazione.
Se una funzione ha dei parametri che seguono il parametro variadico nella definizione, il primo parametro che segue il parametro variadico _deve_ avere un'etichetta dell'argomento.

[variadic-parameters]: https://docs.swift.org/swift-book/documentation/the-swift-programming-language/functions/#Variadic-Parameters
