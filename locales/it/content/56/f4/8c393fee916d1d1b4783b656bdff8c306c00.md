# Istruzioni

In questo esercizio scriverai codice per stampare badge con il nome per i dipendenti di una fabbrica. Ogni dipendente ha un ID, un nome e il nome del reparto. Le etichette dei badge dei dipendenti hanno il seguente formato: `"[id] - name - DEPARTMENT"`.

## 1. Stampa un badge per un dipendente

Implementa la funzione `NameBadge.print/3`. Deve ricevere un id, un nome e un reparto. Deve restituire l'etichetta del badge, con il nome del reparto in maiuscolo.

```elixir
NameBadge.print(67, "Katherine Williams", "Strategic Communication")
# => "[67] - Katherine Williams - STRATEGIC COMMUNICATION"
```

## 2. Stampa un badge per un nuovo dipendente

A causa di una stranezza del sistema informatico, a volte i nuovi dipendenti non hanno ancora un ID quando iniziano a lavorare in fabbrica. Dato che i badge sono obbligatori, riceveranno un badge temporaneo senza il prefisso con l'ID.

Estendi la funzione `NameBadge.print/3`. Quando l'id manca, deve stampare un badge senza l'ID.

```elixir
NameBadge.print(nil, "Robert Johnson", "Procurement")
# => "Robert Johnson - PROCUREMENT"
```

## 3. Stampa un badge per il proprietario

Persino il proprietario della fabbrica deve indossare un badge in ogni momento. Però il proprietario non ha un reparto. In questo caso, l'etichetta deve stampare `"OWNER"` al posto del nome del reparto.

Estendi la funzione `NameBadge.print/3`. Quando il reparto manca, presupponi che il badge appartenga al proprietario dell'azienda.

```elixir
NameBadge.print(204, "Rachel Miller", nil)
# => "[204] - Rachel Miller - OWNER"
```

Nota che è possibile che il proprietario sia anche un nuovo dipendente.

```elixir
NameBadge.print(nil, "Rachel Miller", nil)
# => "Rachel Miller - OWNER"
```
