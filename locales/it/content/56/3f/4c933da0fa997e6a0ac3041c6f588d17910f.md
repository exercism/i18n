# Installazione

Phix per le piattaforme Windows e Linux si può scaricare da [il sito ufficiale][Download].

Dopo l'installazione, la struttura delle directory dovrebbe corrispondere a quella indicata nella [documentazione][Installation].

Per verificare, esegui 'p -test'.

[Installation]: http://phix.x10.mx/docs/html/installation.htm
[Download]: http://phix.x10.mx/download.php
