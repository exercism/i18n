# Imparare

Se vuoi imparare Typescript, dai un'occhiata alle seguenti risorse.

- [TS Tutorial](https://www.typescriptlang.org/docs/handbook/release-notes/overview.html)
- [TS Playground](https://www.typescriptlang.org/play)

TypeScript è un superset di JS.
TypeScript offre tutte le funzionalità di JavaScript, più un livello aggiuntivo: il sistema di tipi di TypeScript.

- Il libro [Exploring ES6](https://leanpub.com/exploring-es6), di Axel Rauschmayer
- Il sito [ES6 Katas](https://jskatas.org/#bundle-es6-katas)
- Il compilatore [Babel](https://github.com/babel/babel)
