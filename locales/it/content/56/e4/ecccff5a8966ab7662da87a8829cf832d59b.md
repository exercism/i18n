# Introduzione

Un'espressione booleana è una domanda posta a uno o più valori, a cui si può rispondere con `true` o `false`.
Un'espressione vera restituisce `1`; un'espressione falsa restituisce `0`.
Inoltre, anche i numeri hanno valori di vero o falso. Zero è `false`; un valore diverso da zero è `true`.

Nel vecchio codice C, o si usava direttamente il tipo `int` per i valori booleani, oppure il programmatore poteva aver definito costanti come `TRUE` e `FALSE` per mappare `1` e `0` su una rappresentazione booleana.

Con la versione C99 è stato aggiunto il tipo `_Bool`.
Il file di intestazione `stdbool.h` definisce tre nuovi simboli booleani: `bool`; `true` e `false`.
`true` corrisponde a `1`; `false` corrisponde a `0`; e `bool` corrisponde a `_Bool`.
Ora quindi, invece di usare direttamente gli `int` o di creare da soli le proprie mappature booleane, i programmatori possono includere `stdbool.h` e ottenere automaticamente i simboli booleani nel loro codice.

## Operatori di confronto

C supporta sei operatori di confronto: `==` (uguale), `!=` (diverso), `>` (maggiore di), `<` (minore di), `>=` (maggiore o uguale a), `<=` (minore o uguale a).
Questi operatori confrontano le relazioni tra i valori e le risolvono in valori booleani.

```c
0 == 0 // true. Although 0 is false, 0 equals 0 is true.
0 != 0 // false
1 > 0 // true
1 < 0 // false
1 >= 0 // true
1 <= 0 // false
```

## Operatori booleani

C supporta tre operatori booleani: `||` (o), `&&` (e), e `!` (non).

`!` si usa con un solo operando.
Inverte il valore booleano dell'operando.
Per esempio, `0` è `false`, ma `!0` è `true`.

`||` e `&&` si usano con due operandi.
L'operando a destra viene valutato solo quando quello a sinistra non determina già il risultato dell'espressione.
Cioè, `||` valuta l'operando a destra solo quando l'operando a sinistra è `false`.
`&&` valuta l'operando a destra solo quando l'operando a sinistra è `true`.
