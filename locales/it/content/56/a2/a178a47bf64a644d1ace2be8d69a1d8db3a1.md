# Informazioni

In Haxe, le eccezioni sono un modo sicuro per gestire gli errori che si verificano durante l'esecuzione del codice. Tutte le eccezioni dovrebbero contenere un messaggio che descrive l'errore. Possiamo _lanciare_ le eccezioni usando la parola chiave `throw`:

```haxe
public function main(num:Int) {
  if (num < 10) {
    throw "Argument num cannot be greater than 10";
  }
  // ...
}
```

Quando viene lanciata un'eccezione, il codice cerca una parte assegnata a gestire l'errore. Se non ne trova una, mostrerà il messaggio di errore e interromperà anche l'esecuzione del programma.

Per gestire le eccezioni in Haxe, usiamo il blocco `try-catch`. Questa istruzione composta consiste in un blocco `try` e uno o più blocchi `catch`. Il blocco `try` _prova_ a eseguire una parte di codice, mentre il blocco `catch` attende nel caso venga lanciata un'eccezione per _catturarla_, così che l'esecuzione non venga interrotta. Quando il blocco `catch` cattura un'eccezione, esegue anche tutto ciò che è all'interno del blocco:

```haxe
try {
  if (num < 10) {
    throw "Argument num cannot be greater than 10";
  }
} catch (e) {
  // All exceptions will be caught here
  trace(e.message); // Argument num cannot be greater than 10
}
```

Il tipo dell'argomento del blocco `catch` va omesso.

È importante notare che le eccezioni dovrebbero essere usate nei casi in cui accade qualcosa di eccezionale, un errore che richiede una gestione speciale. Non dovrebbero essere usate per il flusso di controllo di un programma, poiché ciò è considerato una cattiva progettazione, che spesso porta a scarse prestazioni e manutenibilità.
