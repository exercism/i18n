# Informazioni

[Le liste][list] sono un tipo di dato di base in Haskell per contenere una collezione di valori.
Le liste sono _immutabili_, il che significa che non possono essere modificate.
Qualsiasi operazione che modifica una lista restituisce una nuova lista.
Nel Prelude ci sono diversi metodi che ti permettono di lavorare con le liste.

Le liste in Haskell sono implementate come [liste concatenate][linked-list-wiki], e non come array di posizioni di memoria contigue.
Di conseguenza, accedere a un elemento di una lista richiede un tempo lineare che dipende dalla lunghezza della lista.

Le liste si possono scrivere in forma letterale, con la notazione testa-coda (che usa l'operatore `cons` `:`), oppure con una combinazione delle due:

```haskell
-- Literal Form
[]
[1]
[1, 2, 3]

-- Head-tail Notation
[]
-- same as [1]
1 : []
-- same as [1, 2, 3]
1 : (2 : (3 : []))

-- Mixed
-- same as [1, 2, 3]
1 : [2, 3]
```

La notazione testa-coda si può usare per aggiungere elementi in coda a una lista.

```haskell
list = [2, 1]

[3, 2, 1] == 3 : list
-- -> True
```

Aggiungere elementi in coda a una lista durante un'iterazione è considerato un anti-pattern. 
Aggiungere un elemento in coda richiede di scorrere tutta la lista e inserirlo alla fine; quindi, aggiungere un nuovo elemento a ogni iterazione richiederebbe di scorrere tutta la lista a ogni iterazione.

Possiamo ottenere lo stesso risultato aggiungendo un elemento in testa alla lista invertita e poi invertendo il risultato. Aggiungere in testa è un'operazione veloce e richiede tempo costante.

```haskell
-- Appending to the end of a list (potentially slow)
[1, 2, 3] ++ [4] ++ [5] ++ [6]

-- Prepend to the start of a list (faster, due to the nature of linked lists)
6 : (5 : (4 : [3, 2, 1]))
-- then reverse!
```

Esistono diverse funzioni comuni del Prelude per le liste:

- [`head`][head] restituisce la _testa_ di una lista: il _primo_ elemento della lista.
- [`tail`][tail] restituisce la _coda_ della lista: la lista _senza_ il _primo_ elemento.
- [`length`][length] restituisce il numero di elementi della lista.
- [`elem`][elem] restituisce un valore booleano che indica se l'elemento è presente nella lista.

Esiste anche il [modulo `Data.List`][list].

## Tipi di lista

In Haskell, le liste sono **omogenee**.
Questo significa che tutti gli elementi di una lista hanno lo stesso tipo.
Se provi a mettere elementi di tipi diversi nella stessa lista, otterrai un errore di tipo.

```haskell
list = [1, "string"]
-- Error: No instance for (Num String) arising from the literal ‘1’
```

L'annotazione di tipo di una lista è `[a]`, dove a è il tipo contenuto nella lista, per esempio `String` o `Int`.

``` haskell
a :: [Int] 
a = [1, 2, 3]
```
