# Informazioni

Le [mappe][maps] sono una struttura dati che contiene coppie chiave-valore.

- Le chiavi possono essere di qualsiasi tipo, ma devono essere uniche.
- I valori possono essere di qualsiasi tipo, non devono essere unici.
- Le mappe non garantiscono l'ordine del loro contenuto, anche se sembra il contrario.
  - L'implementazione sottostante dà origine a questa falsa percezione:
    - Con dimensioni ridotte (<=32 voci), sono implementate come una [Keyword list][keyword-list] ordinata.
    - Con dimensioni maggiori (>32 voci), sono implementate come un [hash array mapped trie][hamt] &#91;[1][stackoverflow]&#93;.
- Le mappe si possono dichiarare con una forma letterale:

  ```elixir
  # An empty map
  %{}

  # A map with the atom key :a associated to the integer value 1
  %{a: 1}

  # A map with the string key "a" associated to the float value 2.0
  %{"a" => 2.0}

  # A map with the map key %{} with the list value [1 ,2, 3]
  %{%{} => [1, 2, 3]}

  # A map with keys of different types
  %{:a => 1, "b" => 2}
  ```

- Le mappe si possono anche istanziare usando [`Map.new`][map-new] del [modulo Map][map-module]. Può essere utile se hai già una collezione enumerabile da trasformare in una lista:

  ```elixir
  kw_list = [a: 1, b: 2]
  Map.new(kw_list)
  # => %{a: 1, b: 2}
  ```

- Ai valori di una mappa si può accedere in molti modi diversi:

  ```elixir
  my_map = %{key: "value"}

  # with a dot if the key is an atom
  my_map.key
  # => "value"

  # with [], a syntax provided by the Access behaviour
  my_map[:key]
  # => "value"

  # with pattern matching
  %{key: x} = my_map
  x
  # => "value"

  # with Map.get/2
  Map.get(my_map, :key)
  # => "value"
  ```

- Il [modulo Map][map-module], incluso nella libreria standard, ha molte funzioni utili per lavorare con le mappe.

  ```elixir
  Map.delete(%{a: 2, b: 3}, :a)
  # => %{b: 3}
  ```

- Le mappe implementano il protocollo [`Enumerable`][enumerable], il che permette di usare le funzioni del [modulo Enum][enum].
- Spesso le funzioni del [modulo Map][map-module] e del [modulo Enum][enum] richiedono come argomenti [funzioni anonime][anon-fn] o [riferimenti a funzioni catturate][captured-fn]

  ```elixir
  # Increment the value by one, if it is not found, update it with 0
  Map.update(%{a: 1}, :a, 0, &(&1 + 1))
  # => %{a: 2}

  # Sorting by a specific sub-value
  list = [{"A", 4}, {"B", 3}, {"C", 2}, {"D", 1}]
  Enum.sort_by(list, &Kernel.elem(&1, 1))
  # => [{"D", 1}, {"C", 2}, {"B", 3}, {"A", 4}]
  ```
