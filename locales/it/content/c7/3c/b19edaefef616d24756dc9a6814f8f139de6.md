## Tupla

[Le tuple][tuple] si usano comunemente per raggruppare informazioni: a differenza degli array hanno una dimensione fissa e possono contenere tipi di dati diversi.
Le tuple si creano usando una coppia di parentesi tonde (`()`) e sono spesso usate per restituire più valori da una funzione.

```haskell
tuple = (1, "abc", False)
```

Può essere utile, per esempio, quando vuoi memorizzare una coordinata in uno spazio bidimensionale: sai che la tupla avrà sempre due elementi, la coordinata x e la coordinata y.

```haskell
coordinate = (3, 4)
```

### Accedere agli elementi

Spesso ti capita di lavorare con tuple corte: puoi accedere agli elementi usando le funzioni `fst` e `snd`.

```haskell
x = fst coordinate
-- x = 3
y = snd coordinate
-- y = 4
```

## Pattern matching

Quando scriviamo funzioni in Haskell, possiamo adottare uno [stile assertivo][assertive-style] con il [pattern matching][pattern-match-doc]:
il pattern matching è una funzionalità molto potente di Haskell che permette di riconoscere i costruttori di dati e di associare le variabili ai valori al loro interno.
Come suggerisce il nome, quello che facciamo è confrontare i valori con i pattern: se il valore corrisponde al pattern, possiamo associare delle variabili ai valori al suo interno.
Il pattern matching si basa principalmente su questi concetti: riconoscere i valori, associare variabili e scomporre i valori.

Prendi per esempio questa funzione:

```haskell
lucky :: Int -> String
lucky 7 = "Lucky number seven!"
lucky x = "Sorry, you're out of luck, pal!"
```

Qui abbiamo una funzione `lucky` che prende un `Int` e restituisce una `String`.
Abbiamo definito due pattern per la funzione: uno che corrisponde al numero `7` e uno che corrisponde a qualsiasi altro numero. Il nome può essere qualsiasi cosa (purché rispetti le convenzioni di denominazione di Haskell), ma qui usiamo `x`.
Se il numero è `7`, la funzione restituirà `"Lucky number seven!"`, altrimenti restituirà `"Sorry, you're out of luck, pal!"`.
È importante notare che i pattern vengono controllati dall'alto verso il basso: se avessimo invertito l'ordine dei pattern, la funzione restituirebbe sempre `"Lucky number seven!"`.

### Pattern sugli array

Un pattern molto comune è quello sugli array: consiste nel prendere la testa e la coda dell'array.
Questo è dovuto al fatto che gli array sono, in sostanza, liste concatenate.
Ecco un esempio di funzione che restituisce la testa e la coda di un array:

```haskell
headAndTail :: [Int] -> (Int, [Int])
headAndTail [] = error "Can't call head on an empty list"
headAndTail (x:xs) = (x, xs)
```

Qui abbiamo due pattern: uno che corrisponde a un array vuoto e uno che corrisponde a un array con almeno un elemento.
Questo perché, se l'array è vuoto, dobbiamo prevedere un caso apposito, altrimenti otterremmo un errore a runtime.
Se l'array non è vuoto, possiamo far corrispondere la testa dell'array a `x` e la coda a `xs`.
Questo si fa con l'operatore `:` (cons), che serve ad anteporre un elemento a un array.
Nel pattern matching, però, ci permette di scomporre un array nella sua testa e nella sua coda, facendo in un certo senso l'opposto.

`xs` è un nome comune per la coda di un array: mette in evidenza che si tratta di un array. Se però lavori con un array annidato, puoi usare `xss` per evidenziare che è un array di array.

### Pattern sulle tuple

Come per gli array, possiamo applicare il pattern matching anche alle tuple.
Ecco un esempio di funzione che prende una tupla e restituisce il primo e il secondo elemento:

```haskell
sumTuple :: (Int, Int) -> Int
sumTuple (x, y) = x + y
```

Qui abbiamo un pattern che corrisponde a una tupla con due elementi: il primo elemento è associato a `x` e il secondo a `y`.

### Pattern jolly

A volte non ci interessa il valore di una variabile: vogliamo solo che il valore corrisponda al pattern.
È qui che entra in gioco il pattern jolly, indicato da un underscore (`_`).

Ecco un esempio di funzione che restituisce il primo elemento di un array:

```haskell
head' :: [Int] -> Int
head' [] = error "Can't call head on an empty list"
head' (x:_) = x
```

Qui diciamo che non ci serve la coda dell'array, quindi usiamo il pattern jolly per ignorarla.

### Pattern sui tipi

Possiamo anche fare pattern matching sui tipi, usando il costruttore di quel tipo.
Possiamo anche estrarre valori dal tipo, come abbiamo fatto con le tuple.

```haskell
data AccountType = Guest | User String 

greet :: AccountType -> String
greet Guest = "Welcome, guest!"
greet (User name) = "Welcome, " ++ name ++ "!"
```

Nel primo pattern riconosciamo il costruttore `Guest`, mentre nel secondo riconosciamo il costruttore `User` e associamo il valore al suo interno a `name`.
