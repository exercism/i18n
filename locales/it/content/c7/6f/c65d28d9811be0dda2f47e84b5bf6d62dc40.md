# Introduzione

[concept:csharp/resource-cleanup]() usa l'interfaccia `IDispose` per segnalare che la risorsa di un oggetto o un altro stato del programma doveva essere rilasciato o reimpostato quando l'oggetto non serviva più (e che affidarsi al garbage collector non avrebbe ottenuto questo risultato né offerto il livello di controllo richiesto) e che il metodo `IDisposable.Dispose()` era il posto naturale per queste operazioni di pulizia.

Esiste un altro costrutto, il blocco `using`, che permette, dal punto di vista di chi chiama, di raccogliere in un'unica istruzione tutta la gestione del ciclo di vita delle risorse.

```csharp
using (var file = new File("my_secrets"))
{
    file.WriteSecret("xxxxxxx");
}
```

Nell'esempio precedente, le risorse del file system associate a `file` vengono rilasciate al sistema operativo all'uscita dal blocco `using`.

Perché il pattern funzioni, la variabile nell'istruzione using deve essere un tipo di riferimento che implementa l'interfaccia `IDisposable` e deve rilasciare risorse o reimpostare lo stato del programma nel suo metodo `Dispose()`.

C# 8 introduce un affinamento del pattern. Un'istruzione using può essere collocata all'inizio di un blocco.

```csharp
using var drawingResource = some_provided_or_new_object;
try
{
    drawingResource.DrawSomething();
}
catch (Exception)
{
    throw;
}
```

Gli sviluppatori Java potrebbero riconoscere in questo un analogo del meccanismo di _gestione automatica delle risorse_ introdotto in Java 7.
