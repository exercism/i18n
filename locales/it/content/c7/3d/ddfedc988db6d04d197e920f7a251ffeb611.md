I blocchi di codice sono usati abbondantemente in Raku. Sono fondamentali per le funzioni, ma anche in strumenti come `grep` e `map`, come blocchi di istruzioni `if`, `for`, `while` e `given`, e persino negli indici degli array.

## Routine

[`Subs`][type/Sub] e [`Methods`][type/Method] sono tipi di [`Routines`][type/Routine] in Raku.

Una routine può essere interrotta in qualsiasi momento con un valore restituito usando la parola chiave [`return`][control-return], uno strumento utile per creare funzioni.
Se non viene specificato `return`, l'ultima istruzione della routine sarà il suo valore restituito implicito.

Una routine può avere una [`Signature`][language/signatures] tra parentesi prima del blocco di codice.

[`Routine`][type/Routine] è una sottoclasse di [`Block`][type/Block].

```raku
sub add ($x, $y --> Int) { return $x + $y }
say add(1, 2); # 3
```

I metodi saranno trattati in un concetto separato dedicato a classi e oggetti.

## Blocks

Un [`Block`][type/Block] è un oggetto di codice riutilizzabile, usato tipicamente per creare lambda.

L'ultima istruzione di un blocco è il suo valore restituito implicito.

Un blocco può avere una [`Signature`][language/signatures] preceduta da `->` prima del blocco di codice.

[`Block`][type/Block] è una sottoclasse di [`Code`][type/Code], che è la classe base suprema di tutti gli oggetti di codice in Raku.

```raku
my $add = -> $x, $y { $x + $y };
say $add(1, 2); # 3
```

## Signature

Una [`Signature`][language/signatures] è composta da zero o più [`Parameters`][type/Parameter], separati da virgole.

Alla fine di una signature, si può specificare un tipo di ritorno con una [freccia di tipo di ritorno][signatures-return-type-arrow] `-->`.

Una signature può essere usata per specificare gli argomenti che un `Block` accetterà.

In questo concetto manterremo le signature semplici, usando solo parametri posizionali con variabili con sigillo scalare, e un tipo di ritorno.
Approfondiremo questi aspetti in altri concetti.

## Multi-Dispatch

Raku permette di scrivere più routine con lo stesso nome ma con signature diverse usando la parola chiave `multi`.
Questa funzionalità è nota come [multi-dispatch][multi-dispatch].
Quando la routine viene chiamata per nome, l'ambiente di runtime determina il candidato adatto e lo chiama.

Ne parleremo più in dettaglio in un concetto sui tipi.

```raku
multi foo () { say 'No arguments given'}

multi foo ($bar) { say "One argument given: $bar" }
```

## WhateverCode

Quando una stella [`Whatever`][type/Whatever] `*` viene usata in combinazione con la maggior parte degli operatori, viene creato un oggetto [`WhateverCode`][type/WhateverCode].
Questo permette di creare blocchi con una sintassi più semplice.

```raku
# These will all give code blocks that increment a single argument by 1:
-> $x { $x  + 1 }; # Explicit signature
      { $^x + 1 }; # Signature via placeholder variable
      { $_  + 1 }; # Topic variable
          * + 1;   # WhateverCode
```
