# Informazioni

In un linguaggio puramente funzionale come Elm, una funzione chiamata con gli stessi argomenti deve restituire sempre lo stesso valore.
Quindi una funzione con la firma di tipo `rand : Int` può essere implementata solo come (`rand = 4`)[xkcd-random], il che non promette nulla di buono per la generazione di numeri interi casuali.

Come facciamo, allora, a generare valori casuali in Elm?
Dividiamo il problema in due parti: prima descriviamo il valore che vogliamo generare con un `Random.Generator a`, poi generiamo un valore.

Il primo modo per generare un valore è creare un `Random.Seed` tramite `initialSeed : Int -> Seed`.
Un `Seed` è un tipo opaco che contiene un numero intero e sa come trasformare quel numero in modo che il risultato sembri casuale (cioè pseudocasuale).
Una volta che hai un `Seed`, puoi usarlo per generare un valore con un `Generator a`.
Un `Generator a` è un tipo opaco che sa come usare il numero intero contenuto in un seed per creare un valore pseudocasuale di tipo `a`, oltre a un nuovo seed con un numero intero aggiornato.

Per generare un valore possiamo usare `step : Generator a -> Seed -> ( a, Seed )`, che restituisce un valore e un nuovo seed che possiamo usare per generare altri valori.

Usiamo queste funzioni per estrarre `n` valori casuali da un generatore:

```elm
generate : Int -> Generator a -> List a
generate n generator = generateValuesFromSeed n generator (Random.initialSeed 42)

generateValuesFromSeed : Int -> Generator a -> Seed -> List a
generateValuesFromSeed n generator seed =
    if n <= 0 then
        []
    else
        let ( value, nextSeed ) = Random.step generator seed
        in value :: generateValuesFromSeed (n - 1) generator nextSeed
```

Nota che tutte queste funzioni sono pure, quindi chiamarle due volte con gli stessi argomenti produrrà gli stessi valori.

```elm
generate 10 (Random.int 1 6)
    --> [4, 5, 3, 3, 5, 1, 2, 4, 6, 6]

generate 10 (Random.int 1 6)
    --> [4, 5, 3, 3, 5, 1, 2, 4, 6, 6]
```

Il secondo modo per generare un valore è usare `Random.generate : (a -> msg) -> Generator a -> Cmd msg`, ma è possibile solo all'interno di un'applicazione Elm.
In quel caso, il runtime di Elm può usare `step` ed anche risorse esterne non pure per generare i seed, e chiamare due volte la stessa funzione darà risultati diversi.

Da questo momento in poi ci concentreremo sui generatori.

Il modulo `Random` fornisce due generatori di base per creare numeri interi e numeri in virgola mobile all'interno di un intervallo specifico:

```elm
generate 5 (Random.int -5 5)
    --> [0, 3, -5, 5, 0]

generate 3 (Random.float 0 5)
    --> [1.61803, 3.14159, 2.71828]
```

Questi valori si possono combinare in tuple o in liste di valori:

```elm
generate 2 (Random.list 3 (Random.int 0 3))
    --> [[0, 3, 3], [1, 3, 2]]

generate 2 (Random.pair (Random.int 0 3) (Random.float 10 10.3))
    --> [(0, 10.23412), (2, 10.17094)]
```

Il pacchetto (`elm-community/random-extra`)[random-extra] fornisce molti altri generatori per varie strutture dati: stringhe, date, dizionari, array, insiemi e così via.

Possiamo creare generatori che restituiscono sempre un solo valore usando `Random.constant`:

```elm
generate 4 (Random.constant "hello")
    --> ["hello", "hello", "hello", "hello"]
```

Possiamo scegliere a caso tra elementi dati, con uguale probabilità, usando `Random.uniform`:

```elm
generate 5 (Random.uniform Red [Green, Blue])
    --> [Red, Blue, Blue, Green, Red]
```

`Random.uniform` prende due argomenti (`Red` e `[Green, Blue]`) per garantire che ci sia almeno un valore tra cui scegliere, dato che una singola lista potrebbe essere vuota.

Possiamo anche modificare le probabilità usando `Random.weighted`:

```elm
generate 5 (Random.weighted (80, Red) [(15, Green), (5, Blue)])
    --> [Red, Red, Green, Red, Red]
```

I valori non devono per forza sommare a 100: verranno comunque rinormalizzati.

Possiamo arrivare all'interno di un generatore con `Random.map`:

```elm
generate 3 (Random.int 1 6 |> Random.map (\n -> n * 10))
    --> [30, 60, 10]
```

Possiamo anche usare da `Random.map2` fino a `Random.map5` per combinare più generatori:

```elm
position =
    Random.map3
      (\x y z -> Position x y z)
      (Random.float -100 100)
      (Random.float -100 100)
      (Random.float -100 100)

generate 1 position
    --> [Position 33.788 -98.321 10.0845]
```

Per usi più complessi abbiamo `Random.andThen : (a -> Generator b) -> Generator a -> Generator b`, che può usare il valore generato da un generatore per crearne un altro:

```elm
bool = Random.uniform True [False]

failHalfOfTheTime : Generator a -> Generator (Maybe a)
failHalfOfTheTime generator =
    bool
        |> Random.andThen
            (\boolResult ->
                if boolResult then
                    Random.map Just generator

                else
                    Random.constant Nothing
            )

generate 6 (Random.int 0 1 |> failHalfOfTheTime)
    --> [Nothing, Just 1, Just 0, Nothing, Just 1, Nothing]
```

A volte è utile definire un generatore in modo ricorsivo su se stesso.
In quei casi potresti aver bisogno di `Random.lazy` per evitare che il compilatore espanda il generatore all'infinito.

```elm
type Peano
    = Zero
    | Next Peano


peano : Generator Peano
peano =
    Random.uniform (Random.constant Zero)
        [ Random.map Next (Random.lazy (\_ -> peano))
        ]
        |> Random.andThen identity

generate 12 peano
    --> [Zero, Next(Next(Zero)), Zero, Next(Zero), Zero, Zero, Next(Zero), Zero, Zero, Next(Zero), Next(Next(Next(Zero)))]
```

Questo esempio è un po' pesante, quindi analizziamolo passo per passo.

`Peano` è un tipo che rappresenta i numeri interi positivi: `Zero` è 0, `Next(Zero)` è 1, `Next(Next(Zero))` è 2 e così via.
Definiamo `peano` in modo che ci dia un numero `Peano` casuale.

Prima di tutto, nota che `Random.lazy` non aggiunge nulla alla logica: impedisce soltanto al compilatore di scrivere `peano` dentro `peano` all'infinito.

Usiamo `Random.uniform` per scegliere tra zero (con probabilità del 50%) e un altro numero `Peano` più uno (con probabilità del 50%).
Tuttavia, a differenza dell'esempio precedente, `Random.uniform` non sceglie tra valori (come `Zero`) ma tra generatori (come `Random.constant Zero`), dato che vogliamo usare `peano` stesso.
Questo significa che `Random.uniform` restituirà un valore di tipo `Generator (Generator Peano)`, che non è quello che ci serve.

Per «appiattire» il generatore, lo passiamo a `Random.andThen : (a -> Generator b) -> Generator a -> Generator b`, dove vogliamo che `b` sia `Peano`.
Dato che `Generator a` è `Generator (Generator Peano)`, `a` deve essere `Generator Peano`, e la funzione `(a -> Generator b)` deve essere di tipo `(Generator Peano -> Generator Peano)`.
Non vogliamo modificare nulla, quindi `identity` è la scelta giusta.

Infine, che tipo di numeri produrrà `peano`?
Sappiamo che produrrà 0 nel 50% dei casi, oppure un'altra iterazione di se stesso più uno nell'altro 50% dei casi.
Questo significa che i numeri saranno 0 (nel 50% dei casi), 1 (nel 25% dei casi), 2 (nel 12% dei casi), 3 (nel 6% dei casi) e così via.
`peano` può produrre numeri arbitrariamente grandi, ma con probabilità che diminuisce in modo esponenziale.
