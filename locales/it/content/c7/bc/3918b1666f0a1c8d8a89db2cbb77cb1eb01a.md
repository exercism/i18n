# Introduzione

In Java, il sovraccarico dei metodi è una funzionalità che consente a una classe di avere più di un metodo con lo stesso nome, se le loro liste di parametri sono diverse.
È legato al polimorfismo a tempo di compilazione (o statico).
Questo concetto è cruciale per creare metodi che svolgono compiti simili ma con input diversi.

## Perché sovraccaricare i metodi?

Il sovraccarico dei metodi aumenta la leggibilità del programma.
A metodi diversi si può dare lo stesso nome, ma con parametri diversi.
A seconda del numero o del tipo dei parametri, viene chiamato il metodo corrispondente.

## Come sovraccaricare i metodi?

La chiave del sovraccarico dei metodi è la firma di un metodo.
Due metodi sono considerati diversi se hanno firme diverse.
Ci sono due modi per sovraccaricare un metodo:

1. **Diverso numero di parametri**: i metodi possono avere lo stesso nome ma un numero diverso di parametri.

   ```java
   public class Display {

       public void show(int x) {
           System.out.println("Show with int: " + x);
       }

       public void show(int x, int y) {
           System.out.println("Show with two ints: " + x + ", " + y);
       }
   }
   ```

2. **Tipi di parametri diversi**: i metodi possono avere lo stesso nome e lo stesso numero di parametri, ma con
   tipi diversi.

   ```java
   public class Display {

       public void show(int x) {
           System.out.println("Show with int: " + x);
       }

       public void show(String s) {
           System.out.println("Show with String: " + s);
       }
   }
   ```

## Punti da ricordare

- I metodi sovraccaricati devono cambiare la lista degli argomenti.
- I metodi sovraccaricati possono anche cambiare il tipo di ritorno, ma cambiare soltanto il tipo di ritorno non costituisce
  sovraccarico dei metodi.
- I metodi possono essere sovraccaricati nella stessa classe o in una sottoclasse.

In questo concetto, esploreremo vari esempi e sfumature del sovraccarico dei metodi in Java.
