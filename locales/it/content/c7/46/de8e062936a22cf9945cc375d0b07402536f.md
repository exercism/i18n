## Editor

### Gratuiti/open source

- [VS Code](https://code.visualstudio.com)

  VS Code è un editor di codice open source. Trovi informazioni su come configurare TypeScript [qui](https://code.visualstudio.com/docs/languages/typescript). VS Code è un editor molto diffuso per TypeScript, perché Microsoft sviluppa sia VS Code sia TypeScript, quindi va d'accordo con il linguaggio. VS Code supporta TypeScript senza alcuna configurazione aggiuntiva. Anzi, VS Code è stato scritto proprio con TypeScript!

  Un problema comune con VS Code e TypeScript si presenta quando la versione dell'editor e quella del progetto sono diverse: in questo caso VS Code può mostrare un messaggio di errore che confonde. Le istruzioni su come gestire questo errore sono [qui](https://code.visualstudio.com/docs/typescript/typescript-compiling#_using-newer-typescript-versions)

### A pagamento

- [Sublime Text](https://www.sublimetext.com)

  Sublime Text è un editor di codice molto diffuso, che supporta la maggior parte dei linguaggi tramite plugin installabili. È gratuito da provare, ma ti verrà chiesto regolarmente di acquistare una licenza, che al momento costa \$70 USD.

- [WebStorm](https://www.jetbrains.com/webstorm/)

  WebStorm è un IDE (ambiente di sviluppo integrato) completo per JavaScript e TypeScript. Supporta TypeScript senza configurazione aggiuntiva e integra test, debug e analisi del codice. È gratuito da provare per 30 giorni, poi una licenza annuale costa \$129 USD per il primo anno.
