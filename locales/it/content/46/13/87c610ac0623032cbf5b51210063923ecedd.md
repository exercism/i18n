# Informazioni

Le funzioni **definite dall'utente** vengono create usando la parola chiave `function`. A questa devono poi seguire un nome di funzione e un elenco di argomenti.

```php
function alarm($hour, $minute, $second)
{
    return 'Alarm!';
}
```

Le funzioni possono essere chiamate in un file prima che vengano definite, poiché vengono sollevate in cima al loro scope.

## Denominazione

I nomi delle funzioni in PHP seguono le regole degli altri identificatori: devono iniziare con un trattino basso o una lettera, poi possono essere seguiti da un numero qualsiasi di lettere, numeri o trattini bassi.
