# Suggerimenti

## 1. Partire da zero

- Per creare un array puoi usare `make-array`.
- Le dimensioni di un array si specificano come una lista di argomenti di `make-array`.
- Per impostare tutti gli elementi a un valore iniziale usa il parametro keyword `:inital-element`.

## 2. Partire da un tabellone esistente

- Per impostare il contenuto iniziale di un array usa il parametro keyword `:initial-contents`.

## 3. La condizione di vittoria

- Puoi usare `aref` per ottenere il valore di una cella di un array.
- Puoi usare `eq` per determinare se due simboli sono uguali.
- Puoi usare `and` per combinare due espressioni `eq` e confrontare tre elementi.

## 4. In una riga

- Gli argomenti di `aref` (per un array bidimensionale) sono «row» e «column».

## 5. In una colonna

- Gli argomenti di `aref` (per un array bidimensionale) sono «row» e «column».
