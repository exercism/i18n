# Moduli e percorsi in Cairo

Cairo usa i **moduli** per organizzare il codice.

I moduli aiutano a strutturare i progetti e a controllare la visibilità di elementi come funzioni, struct e trait.

## Definire i moduli

I moduli si definiscono con `mod` e possono essere annidati:

```rust
mod front_of_house {
    pub mod hosting {
        pub fn add_to_waitlist() {}
    }
}
```

Funzioni, struct e trait sono **privati per impostazione predefinita**.

Usa `pub` per renderli accessibili all'esterno del loro modulo.

## Percorsi: assoluti e relativi

Per fare riferimento a un elemento in un altro modulo, puoi usare:

- **Percorsi assoluti** (che iniziano da `crate::`):

  ```rust
  crate::front_of_house::hosting::add_to_waitlist();
  ```

- **Percorsi relativi** (che iniziano dal modulo corrente):

  ```rust
  front_of_house::hosting::add_to_waitlist();
  ```

  Funziona se `front_of_house` si trova nello stesso modulo.

## Portare i moduli nello scope con `use`

Scrivere ripetutamente i percorsi completi è scomodo.

La parola chiave `use` permette riferimenti più brevi:

```rust
use crate::front_of_house::hosting;

pub fn eat_at_restaurant() {
    hosting::add_to_waitlist(); // Shorter path
}
```

`use` si applica **solo nello scope in cui compare**; se serve altrove, va ripetuto.

### Uso idiomatico di `use`

- Porta nello scope i **moduli**, non le funzioni:

  ```rust
  use crate::front_of_house::hosting; // ✅
  hosting::add_to_waitlist();
  ```

  Invece di:

  ```rust
  use crate::front_of_house::hosting::add_to_waitlist; // ❌
  add_to_waitlist();
  ```

- Per **trait, struct ed enum**, usa il percorso completo:

  ```rust
  use core::num::traits::BitSize;
  ```

### Alias con `as`

Rinomina le importazioni quando serve:

```rust
use core::array::ArrayTrait as Arr;

fn main() {
    let mut arr = Arr::new();
    arr.append(1);
}
```

### Importare più elementi

Invece di più istruzioni `use`, raggruppa le importazioni:

```rust
use shapes::{Square, Circle, Triangle};
```

## Riesportare con `pub use`

Per esporre un modulo in una struttura diversa, usa `pub use`:

```rust
pub use crate::front_of_house::hosting;
```

Ora il codice esterno può usare `restaurant::hosting::add_to_waitlist()` invece di `restaurant::front_of_house::hosting::add_to_waitlist()`.

## Usare pacchetti esterni con Scarb

Per aggiungere una dipendenza, aggiorna `Scarb.toml`:

```toml
[dependencies]
alexandria_math = { git = "https://github.com/keep-starknet-strange/alexandria.git" }
```

Usa `scarb add <package>` per aggiungere dipendenze e `scarb rm <package>` per rimuoverle.

## L'operatore glob (`*`)

Per importare tutto da un modulo:

```rust
use core::num::traits::*;
```

Da usare con cautela, perché può rendere il codice più difficile da leggere.
