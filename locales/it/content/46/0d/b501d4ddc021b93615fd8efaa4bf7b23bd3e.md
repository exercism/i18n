# Contatore delle righe di codice

Il contatore delle righe di codice (LoC) prende una soluzione e conta le sue righe di codice.

Per impostazione predefinita, vengono conteggiate solo le LoC dei file inviati dallo studente.
Se lo studente ha inviato un file di test, questo verrà ignorato.

Anche se funziona bene per la maggior parte delle soluzioni inviate, alcuni track potrebbero aver bisogno di ignorare file aggiuntivi.
Per questo, permettiamo di [personalizzare il contatore delle righe di codice per ogni track][lines-of-code-counter-customize].

## Implementazione

Usiamo la libreria [tokei][tokei] per fare il conteggio vero e proprio.
Dato che le pull request spesso non vengono unite rapidamente, abbiamo creato un nostro [fork][tokei-fork].
Questo ci permette di iterare più rapidamente e di aggiungere il supporto per qualsiasi linguaggio vogliamo.

## Linguaggi supportati

Puoi verificare se il tuo linguaggio è supportato fin da subito cercandolo nel file [languages.json][languages.json].

### Aggiungere un nuovo linguaggio

Se il tuo linguaggio **non** è supportato, puoi aggiungere il supporto in questo modo:

1. Aggiungi una voce per il tuo linguaggio al file [languages.json].
   Consulta la [documentazione sull'aggiunta di linguaggi][adding-language] per maggiori informazioni.
2. Aggiungi dei test per verificare che il conteggio funzioni correttamente per il tuo linguaggio.
   Consulta la [documentazione sull'aggiunta dei test][adding-tests] per maggiori informazioni.

Dopo aver fatto queste modifiche, apri una pull request nel [repository exercism/tokei][tokei-fork].
Qui c'è una [pull request di esempio][example-pr] che aggiunge il supporto per il linguaggio Arturo.
