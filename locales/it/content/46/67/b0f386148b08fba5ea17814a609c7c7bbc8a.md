# Appendice alle istruzioni

## Registri

| Registro | Utilizzo  | Tipo    | Descrizione                                                |
| -------- | --------- | ------- | ---------------------------------------------------------- |
| `$a0`    | input     | intero | categoria: `0` = choice, `1` = ones, `2` = twos, `3` = threes, `4` = fours, `5` = fives, `6` = sixes, `7` = little_straight, `8` = big_straight, `9` = full_house, `10` = four_of_a_kind, `11` = yacht |
| `$a2`    | input     | indirizzo | dadi (array di word)                                          |
| `$v0`    | output    | intero | punteggio risultante                                            |
| `$t0-9`  | temporaneo | qualsiasi     | usato per l'archiviazione temporanea                                 |
