# Introduzione

Un dizionario (`dict`) in Python è una struttura dati che associa _chiavi_ [hashable][term-hashable] a _valori_ ed è conosciuto in altri linguaggi di programmazione come [tabella hash][hashtable-wikipedia] ridimensionabile, hashmap o [array associativo][associative-array].
I dizionari sono l'unico [tipo di mapping][mapping-types-dict] integrato di Python.


Le `Keys` devono essere hashable e uniche all'interno del dizionario.
I tipi delle chiavi possono includere `numbers`, `str` o `tuples` (di valori _immutabili_).
Non possono contenere strutture dati _mutabili_ come `lists`, `dict`s o `set`s.
A partire da Python 3.7, l'ordine delle chiavi di un `dict` è garantito essere quello in cui le voci vengono inserite.

I `values` possono essere di qualsiasi tipo o struttura dati.
I valori possono anche annidarsi in modo _arbitrario_, quindi possono includere liste di liste, sotto-dizionari e altre strutture dati personalizzate o composte.

Data una `key`, i dizionari possono recuperare un `value` in tempo (in media) costante (_indipendentemente dal numero di voci_).
Rispetto alla ricerca di un valore all'interno di una `list` o di un `array` (_senza conoscere la posizione dell'`index`_), un `dict` usa molta più memoria, ma il recupero è molto rapido.
I dizionari sono particolarmente utili negli scenari in cui l'insieme di elementi è grande e deve essere consultato e aggiornato spesso.


## Costruzione di un dizionario

I dizionari possono essere creati in molti modi.
I due più diretti sono usare il costruttore `dict()` oppure dichiarare un _letterale_ `dict`.

### Il costruttore della classe `dict()`

`dict()` (_il costruttore della classe dizionario_) può essere usato con qualsiasi iterabile di coppie `key`, `value` oppure con una serie di _argomenti_ `<name>=<value>`:

```python
#Passing a list of key,value tuples.
>>> wombat = dict([('name', 'Wombat'),('speed', 23),('land_animal', True)])
{'name': 'Wombat', 'speed': 23, 'land_animal': True}


#Using key=value arguments.
>>> bear = dict(name="Black Bear", speed=40, land_animal=True)
{'name': 'Black Bear', 'speed': 40, 'land_animal': True}
```

### I letterali dei dizionari

Un `dict` può anche essere inserito direttamente come _letterale di dizionario_, usando parentesi graffe (`{}`) che racchiudono coppie `key : value`:

```python
>>> whale = {"name": "Blue Whale", "speed": 35, "land_animal": False}
{'name': 'Blue Whale', 'speed': 35, 'land_animal': False}
```

## Accedere ai valori di un dizionario

Puoi accedere a una voce di un dizionario usando una _chiave_ tra parentesi quadre (`[]`).
Se una `key` non esiste nel `dict`, viene sollevata una `KeyError`:

```python
>>> bear["speed"]
40

>>> bear["color"]
Traceback (most recent call last):
  File "<stdin>", line 1, in <module>
KeyError: 'color'
```

Accedere a una voce tramite il metodo `.get(<key>, <default value>)` può evitare la `KeyError`:

```python
>>> bear.get("color", 'not found')
'not found'
```

## Modificare o aggiungere valori in un dizionario

Puoi cambiare il `value` di una voce assegnandolo alla sua _chiave_:

```python
#Assigning the value "Grizzly Bear" to the name key.
>>> bear["name"] = "Grizzly Bear"
{'name': 'Grizzly Bear', 'speed': 40, 'land_animal': True}

>>> whale["speed"] = 25
{'name': 'Blue Whale', 'speed': 25, 'land_animal': False}
```

Nuove coppie `key`:`value` possono essere _aggiunte_ allo stesso modo:

```python
# Adding a new "color" key with a new "tawney" value.
>>> bear["color"] = 'tawney'
{'name': 'Grizzly Bear', 'speed': 40, 'land_animal': True, 'color': 'tawney'}

>>> whale["blowholes"] = 1
{'name': 'Blue Whale', 'speed': 25, 'land_animal': False, 'blowholes': 1}
```

## Rimuovere (con pop) le voci di un dizionario

Puoi usare il metodo `.pop(<key>)` per eliminare una voce di un dizionario.
`.pop()` rimuove la coppia (`key`, `value`) e restituisce il `value` perché venga usato.
Come `.get()`, `.pop(<key>)` accetta un secondo argomento (_`dict.pop(<key>, <default value>)`_) che sarà restituito se la `key` non viene trovata.
Questo evita che venga sollevata una `KeyError`:

```python
#Using .pop() removes both the key and value, returning the value.
>>> bear.pop("name")
'Grizzly Bear'


#The "name" key is now removed from the dictionary.
#Attempting .pop() a second time will throw a KeyError.
>>> bear.pop("name")
Traceback (most recent call last):
  File "<stdin>", line 1, in <module>
KeyError: 'name'


#Using a default argument with .pop() will prevent a KeyError from a missing key.
>>> bear.pop("name", "Unknown")
'Unknown'
```

## Iterare su un dizionario

Iterare su un dizionario con `for item in dict` o `while item` esamina per impostazione predefinita solo le _chiavi_.
Puoi accedere ai _valori_ nello stesso ciclo usando le _parentesi quadre_:

```python
>>> for key in bear:
>>>     print((key, bear[key])) #this forms a tuple of (key, value) and prints it.
('name', 'Black Bear')
('speed', 40)
('land_animal', True)
```

Puoi anche usare il metodo `.items()`, che restituisce automaticamente tuple (`key`, `value`):

```python
#dict.items() forms (key, value tuples) that can be unpacked and iterated over.
>>> for key, value in whale.items():
>>>     print(key, ":", value)
name : Blue Whale
speed : 25
land_animal : False
blowholes : 1
```

Allo stesso modo, il metodo `.keys()` restituirà le `keys` e il metodo `.values()` restituirà i `values`.
