# Introduzione

In Kotlin, una [`string`][ref-string] è una sequenza immutabile di caratteri Unicode.

[`Immutable`][wiki-immutable] significa che qualsiasi operazione su una stringa deve restituire una nuova stringa: la stringa originale non può mai cambiare.

[`Unicode`][wiki-unicode] significa che è possibile rappresentare la maggior parte dei sistemi di scrittura del mondo, ma (a differenza di linguaggi più vecchi come il C) non c'è una corrispondenza 1:1 tra caratteri e byte.

Una stringa è racchiusa tra doppi apici `" "`.

Alcuni caratteri richiedono un escape: `\\`, oltre ai soliti caratteri non stampabili come `\t` (tabulazione) e `\n` (nuova riga).

```kotlin
val s = "Escape backslash \\."
// Escape backslash \.
```

Le stringhe multi-riga sono racchiuse tra 3 doppi apici e possono contenere testo arbitrario (non serve fare escape).

```kotlin
val multi = """I'm a
    multi-line
    string with special characters \ \t """
//I'm a
//    multi-line
//    string with special characters  \ \t 
```

Usa [trimIndent][trimIndent-doc] per rimuovere l'indentazione comune dalle righe.
È utile per formattare la stringa:

```kotlin
val multi = """
    I'm a
      multi-line
    string""".trimIndent()

//I'm a
//  multi-line
//string
```

In alternativa, [trimMargin][trimMargin-doc] permette di specificare un delimitatore.
Ogni riga nella `String` inizia quindi dopo il delimitatore.
Il delimitatore predefinito è `|`, ma puoi specificarne uno diverso come parametro.
Per esempio:

```kotlin
val multi = """
    |I'm a
    |  multi-line
    |string""".trimMargin()

//I'm a
//  multi-line
//string

val multi2 = """
    start>I'm a
    start>  multi-line
    start>string""".trimMargin("start>")

//I'm a
//  multi-line
//string
```

Le stringhe possono essere concatenate con `+`, ma è meglio limitarsi a casi brevi e semplici.
Esistono altre opzioni, spesso migliori.

## Stringhe interpolate

Si tratta di quello che altri linguaggi chiamano «interpolazione».

Se una stringa contiene un simbolo del dollaro `$` seguito da un identificatore, oppure contiene parentesi graffe (`{expression}`) attorno a un'espressione, questi vengono sostituiti rispettivamente dal valore o dal risultato dell'espressione.

```kotlin
val x = 42
val st = "x is $x, x squared is {x * x}"
// x is 42, x squared is 1764
```

Le parentesi graffe `{ }` sono necessarie attorno alle espressioni quando l'analisi sarebbe altrimenti ambigua.

In generale, l'uso delle stringhe interpolate è un modo più efficiente e idiomatico di combinare le stringhe rispetto all'uso di `+`.

## Funzioni per le stringhe

Kotlin mette a disposizione _molte_ [`functions`][ref-string-functions] per manipolare le stringhe.

Per lo più, queste sono [`extensions functions`][ref-extensions] e non membri della classe `String`, anche se questo ha poca importanza su come le usiamo.

~~~~exercism/note
Le piuttosto complesse pagine della [documentazione][ref-string-functions] di Kotlin nascondono le funzioni di estensione nella vista predefinita.
Assicurati di fare clic su `Members & Extensions` per espandere questa sezione.

[ref-string-functions]: https://kotlinlang.org/api/core/kotlin-stdlib/kotlin/-string/
~~~~

Gli esempi seguenti mostrano solo una piccola selezione di ciò che è disponibile:

```kotlin
val str = "Hello World!"

str.length              // => 12 (a property, not a function)
str.elementAt(6)        // => W
str.elementAtOrNull(20) // => null (index out of range)
str.substring(6, 11)    // => "World"
str.substringAfter(" ") // => "World!"

str.lowercase()         // => "hello world!"
str.uppercase()         // => "HELLO WORLD!"

str.startsWith("Hel")   // => true
str.endsWith("xyz")     // => false
str.indexOf("0")        // => 4

str.toCharArray()       // => [H, e, l, l, o,  , W, o, r, l, d, !]
"42".toInt() + 1        // => 43  (parsing; see also toFloat)

"Howdy!  ".trim()       // => "Howdy"
```
