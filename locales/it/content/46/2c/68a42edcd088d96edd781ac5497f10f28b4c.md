# Istruzioni

In questo esercizio aiuterai due innamorati del liceo a dichiarare il loro amore sui social media, generando un cuore ASCII con le loro iniziali:

```
     ******       ******
   **      **   **      **
 **         ** **         **
**            *            **
**                         **
**     J. K.  +  M. B.     **
 **                       **
   **                   **
     **               **
       **           **
         **       **
           **   **
             ***
              *
```

## 1. Ottieni la prima lettera del nome

Implementa la funzione `first_letter`. Dovrebbe prendere un nome e restituirne la prima lettera. Dovrebbe anche eliminare dal nome gli spazi bianchi superflui.

```gleam
first_letter("Jane")
// -> "J"
```

## 2. Formatta la prima lettera come iniziale

Implementa la funzione `initial`. Dovrebbe prendere un nome e restituirne la prima lettera, in maiuscolo, seguita da un punto. Assicurati di riutilizzare `first_letter`, che hai definito nel passaggio precedente.

```gleam
initial("Robert")
// -> "R."
```

## 3. Suddividi il nome completo in nome e cognome

Implementa la funzione `initials`. Dovrebbe prendere un nome completo, composto da un nome e un cognome separati da uno spazio, e restituire le iniziali. Assicurati di riutilizzare `initial`, che hai definito nel passaggio precedente.

```gleam
initials("Lance Green")
// -> "L. G."
```

## 4. Metti le iniziali dentro il cuore

Implementa la funzione `pair`. Dovrebbe prendere due nomi completi e restituire le iniziali dentro un cuore ASCII. Assicurati di riutilizzare `initials`, che hai definito nel passaggio precedente.

```gleam
pair("Blake Miller", "Riley Lewis")
// -> "
//      ******       ******
//    **      **   **      **
//  **         ** **         **
// **            *            **
// **                         **
// **     B. M.  +  R. L.     **
//  **                       **
//    **                   **
//      **               **
//        **           **
//          **       **
//            **   **
//              ***
//               *
// "
```
