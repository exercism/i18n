# Istruzioni

Il mosaico del centro di arte comunitaria ha terminato l'installazione
il mese scorso, e ora Magpie Marg l'ha scoperto. Quasi ogni giorno
scambia una tessera o due con altre più luccicanti prese dal suo
**bottino** lì vicino, oppure sfila una tessera e sparisce per un'ora.

Sei tu il volontario che registra ogni cambiamento. Il mosaico stesso
è un **array a dimensione fissa**: uno slot per ogni posizione di
tessera, che contiene una stringa di colore oppure `f` per «mancante».
Il bottino di Magpie Marg è un **vettore** di tessere sciolte che ha
rubato.

## 1. Disponi una riga nuova

Definisci `fresh-mosaic` in modo che prenda una lunghezza `n` e
restituisca un array di `n` slot vuoti (ognuno `f`).

```factor
4 fresh-mosaic .
! => { f f f f }
```

## 2. Posiziona una tessera

Definisci `place-tile` in modo che prenda una riga, una posizione e un
colore, e aggiorni la riga sul posto in modo che la posizione indicata
contenga quel colore. La parola non restituisce nulla.

```factor
5 fresh-mosaic   ! { f f f f f }
dup 2 "ruby" place-tile
.
! => { f f "ruby" f f }
```

## 3. Stacca una tessera

Definisci `chip-tile` in modo che prenda una riga e una posizione, e
aggiorni la riga sul posto in modo che la posizione indicata torni a
essere `f`.

```factor
{ "ruby" "lapis" "jade" } 1 chip-tile .
! => { "ruby" f "jade" }
```

## 4. Ricolora una tessera

Definisci `recolour-tile` in modo che prenda una riga, una posizione e
una quotation con un solo argomento, e aggiorni la riga sul posto
applicando la quotation alla tessera in quella posizione.

```factor
{ "RUBY" "LAPIS" "JADE" } 1 [ >lower ] recolour-tile .
! => { "RUBY" "lapis" "JADE" }
```

## 5. Un'istantanea prima che Marg arrivi

Definisci `snapshot-mosaic` in modo che prenda una riga e restituisca
una copia indipendente che non sarà influenzata dalle successive
mutazioni dell'originale.

```factor
{ "ruby" "lapis" "jade" } dup snapshot-mosaic    ! two equal but independent copies
swap 0 "amber" place-tile                        ! mutate the first
.s
! => { "ruby" "lapis" "jade" }                   (the snapshot)
! => { "amber" "lapis" "jade" }                  (the mutated original)
```

## 6. Marg si intasca una tessera

Definisci `stash-tile` in modo che prenda il bottino di Marg (un
vettore) e un colore, e aggiunga il colore in fondo al bottino. Non
restituisce nulla.

```factor
V{ } clone   ! a fresh empty hoard
dup "ruby"  stash-tile
dup "lapis" stash-tile
.
! => V{ "ruby" "lapis" }
```

## 7. Marg restituisce una tessera

Definisci `return-tile` in modo che prenda il bottino di Marg e rimuova
e restituisca la tessera messa da parte più di recente (quella in
cima).

```factor
V{ "ruby" "lapis" "jade" } clone
dup return-tile .
! => "jade"
.
! => V{ "ruby" "lapis" }
```
