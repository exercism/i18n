# Informazioni

Swift è un linguaggio di programmazione compilato e multi-paradigma, progettato con tre obiettivi principali:

- **Sicurezza**: le funzionalità integrate del linguaggio aiutano a individuare e prevenire i bug prima che il codice venga eseguito in produzione.
- **Velocità**: prestazioni ottimizzate, paragonabili a quelle dei linguaggi basati su C.
- **Espressività**: una sintassi pulita e moderna, piacevole e facile da leggere e da scrivere.

Apple ha introdotto Swift nel 2014 come sostituto moderno di Objective-C, il linguaggio usato in precedenza per lo sviluppo su iOS e macOS.
Oggi Swift è open source e funziona su piattaforme Apple, Linux e Windows.

## Per iniziare

### Variabili

Puoi memorizzare dei valori e dare loro un nome definendo una [variabile][constants-variables].
Dopo aver definito una variabile, puoi usarne il nome per fare riferimento a quel valore in tutto il codice.
Le variabili sono _mutabili_: il loro valore può cambiare dopo la definizione.

Definisci una variabile con la parola chiave `var`:

```swift
var variableName = 10
```

Swift è un linguaggio a tipizzazione statica: ogni valore ha un tipo noto al momento della compilazione.
Puoi dichiarare esplicitamente un tipo con un'[annotazione di tipo][type annotations], oppure lasciare che il compilatore Swift [deduca il tipo][type-inferring] dal valore assegnato:

```swift
var explicitVar: Int = 10 // Explicitly typed
var implicitVar = 10      // Implicitly typed (inferred as Int)
```

Puoi aggiornare il valore di una variabile usando l'operatore di assegnazione (`=`):

~~~~exercism/note
Il tipo di una variabile non può cambiare dopo la dichiarazione.

```swift
variableName = 13 // Allowed: same type (Int)

// Compiler error: cannot assign a different type
variableName = "Hello, world!" // Cannot assign value of type 'String' to type 'Int'
```
~~~~

Puoi dichiarare una variabile senza valore iniziale specificandone il tipo, ma devi assegnarle un valore prima di usarla:

```swift
var someInt: Int

// This triggers a compiler error:
// print(someInt) // Variable 'someInt' used before being initialized

// Assign a value first
someInt = 169
print(someInt) // Prints 169
```

### Costanti

Anche le [costanti][constants-variables] associano un nome a un valore, ma il loro valore non può essere cambiato dopo l'assegnazione.
Sono _immutabili_.
Definisci una costante con la parola chiave `let`:

```swift
let constantName = 10          // Inferred constant
let explicitConstant: Int = 10 // Explicitly typed constant
```

### Operatori aritmetici

Swift mette a disposizione i consueti [operatori aritmetici][arithmetical-operators] per la matematica di base:

- Addizione: `+`
- Sottrazione: `-`
- Moltiplicazione: `*`

```swift
print(1 + 1) // Prints 2
print(2 - 1) // Prints 1
print(2 * 2) // Prints 4
```

### Funzioni

In Swift, le [funzioni][functions] sono blocchi di codice autonomi che svolgono un compito specifico.
Le funzioni possono ricevere input, restituire un valore ed essere passate ad altre funzioni come valori.
Definisci una funzione con la parola chiave `func`, seguita dal nome della funzione, da un elenco di parametri tra parentesi e da un tipo restituito opzionale:

```swift
func functionName(argumentLabel parameterName: ParameterType) -> ReturnType {
    // Function body
}
```

Le funzioni Swift usano le [etichette degli argomenti][argument-labels], che fanno leggere il codice come frasi naturali:

- **L'etichetta dell'argomento** si usa quando si chiama la funzione.
- **Il nome del parametro** si usa all'interno del corpo della funzione per accedere al valore.

Se specifichi un solo nome, Swift lo usa sia come etichetta dell'argomento sia come nome del parametro:

```swift
func greet(name: String) {
    print("Hello, \(name)!")
}

greet(name: "Alice")
```

Se non vuoi un'etichetta dell'argomento quando chiami la funzione, scrivi un trattino basso (`_`) prima del nome del parametro:

```swift
func square(_ number: Int) -> Int {
    return number * number
}

square(5) // Called without an argument label
```

Per impostazione predefinita, tutti i parametri di una funzione sono costanti (`let`): il loro valore non può essere modificato all'interno del corpo della funzione.

Per restituire un valore da una funzione, specifica il tipo restituito dopo `->` e usa la parola chiave `return`:

```swift
func addTen(to value: Int) -> Int {
    return value + 10
}

addTen(to: 10) // Returns 20
```

Quando una funzione non restituisce un valore, il suo tipo restituito è `Void` (equivalente a una tupla vuota, `()`).
In questi casi puoi omettere sia il tipo restituito `-> Void` sia l'istruzione `return`.

### Commenti

Swift supporta due forme di [commenti][comments]:

- **I commenti su una sola riga** iniziano con `//` e proseguono fino alla fine della riga.
- **I commenti su più righe** sono racchiusi tra `/*` e `*/`.

```swift
// This is a single-line comment

/* This is a comment
   that spans multiple lines */
```
