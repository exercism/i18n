# Istruzioni

In questo esercizio, giocherai a indovinare un numero con un amico. Le regole sono semplici: scegli in segreto un numero tra `1` e `100` e il tuo amico prova a indovinare quale numero hai scelto. Per aiutare il tuo amico, rispondi in modo diverso a seconda di quanto il tentativo si avvicina al numero che hai scelto (`42`). Queste sono le regole per le diverse risposte:

- Se il tentativo è `42`: "Correct"
- Se il tentativo è `41` o `43`: "So close"
- Se il tentativo è minore di `41`: "Too low"
- Se il tentativo è maggiore di `43`: "Too high"

Hai quattro attività per codificare le risposte ai tentativi.

## 1. Rispondi a un tentativo corretto

Implementa la funzione `reply` per rispondere a un tentativo corretto:

```gleam
reply(42)
// -> "Correct"
```

## 2. Rispondi a un tentativo vicino

Modifica la funzione `reply` per rispondere ai tentativi vicini:

```gleam
reply(41)
// -> "So close"
```

## 3. Rispondi ai tentativi troppo bassi

Modifica la funzione `reply` per rispondere ai tentativi troppo bassi:

```gleam
reply(25)
// -> "Too low"
```

## 4. Rispondi ai tentativi troppo alti

Modifica la funzione `reply` per rispondere ai tentativi troppo alti:

```gleam
reply(88)
// -> "Too high"
```
