# Istruzioni

In questo esercizio modelleremo una bilancia.

## 1. Creare uno stato iniziale per la bilancia

Quando viene inizializzata, la bilancia dovrebbe fare riferimento alle proprie impostazioni di fabbrica, che sono diverse a seconda di dove viene venduta.
Di conseguenza, la macchina dovrebbe poter essere inizializzata con una precisione e specificando se usa il sistema metrico o quello imperiale.

Implementa il metodo `WeighingMachine#initialize`, che accetta due argomenti: `precision`, che è un `Int32`, e `metric`, che è un `Bool`.
L'argomento `metric`, quando è `true`, indica che la macchina deve usare il sistema metrico, altrimenti deve usare il sistema imperiale.
Il metodo initialize dovrebbe anche impostare la variabile di istanza `@weight` a `0.0`.

```crystal
precision = 3
metric = true
vm = WeighingMachine.new(precision, metric)
```

## 2. Consentire alla bilancia di avere una precisione

Per soddisfare esigenze diverse, permettiamo di personalizzare ogni bilancia con una precisione (il numero di cifre dopo il separatore decimale).

Implementa il metodo getter `WeighingMachine#precision` in modo che restituisca la precisione della bilancia.

```crystal
precision = 3
metric = true
vm = WeighingMachine.new(precision, metric)
vm.precision
# => 3
```

## 3. Consentire di impostare il peso sulla bilancia

Implementa la proprietà `WeighingMachine#weight` per poter ottenere _e_ impostare il peso:

```crystal
precision = 3
metric = true
wm = WeighingMachine.new(precision, metric)
wm.weight = 60.5
wm.weight
# => 60.5

wm.weigh
# => 60.5
```

## 4. Consentire di passare tra unità metriche e imperiali sulla macchina

Implementa la proprietà `WeighingMachine#metric=` per consentire di impostare l'unità.
Dovrebbe accettare un valore booleano.

```crystal
precision = 3
metric = true
wm = WeighingMachine.new(precision, metric)
vm.weight = 60.5
wm.metric = false

vm.weigh
# => 133.377
```
