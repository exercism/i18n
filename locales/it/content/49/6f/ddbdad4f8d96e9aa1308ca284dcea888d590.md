# Informazioni

Factor concentra la casualità nel vocabolario [`random`][random] attorno a un'unica parola generica:

```
random ( obj -- elt )
```

La parola si comporta in modo diverso a seconda del suo argomento:

- un **intero** `n` produce un intero casuale in `[0, n)`;
- una **sequenza** produce un elemento casuale;
- anche gli assoc, gli hash-set e le tuple `uniform-distribution` sono supportati.

Su di essa si basano due funzioni ausiliarie per le sequenze:

```factor
USING: random ;

{ 1 2 3 4 5 } randomize .   ! shuffle in place (Fisher–Yates)
{ 1 2 3 4 5 } 3 sample .    ! 3 distinct elements; error if too many
```

`randomize` modifica la sequenza e la restituisce, quindi se hai bisogno di conservare l'ordine originale, usa prima `clone`.

## Da dove viene la casualità

`random` legge il generatore contenuto nella variabile dinamica `random-generator`. Per impostazione predefinita si tratta di un Mersenne Twister inizializzato con un seme preso dall'orologio di sistema, quindi ogni processo è diverso. Puoi installare un generatore diverso per la durata di una quotation:

```
<mersenne-twister> ( seed -- rnd )
with-random        ( rnd quot -- )
```

```factor
USING: random random.mersenne-twister ;

42 <mersenne-twister> [ { 1 2 3 } randomize ] with-random .
! => the same ordering on every run
```

Poiché `with-random` si limita a legare `random-generator` per l'estensione dinamica della quotation, una parola che la racchiude dovrebbe essere contrassegnata come `inline`, così che la quotation possa lasciare il suo risultato sullo stack per il chiamante.

Oltre a queste, `random` offre `random-bits`, `random-unit`, `uniform-random` e `normal-random` per altre distribuzioni, più `system-random-generator` e `secure-random-generator` per esigenze non riproducibili e crittografiche.

[random]: https://docs.factorcode.org/content/vocab-random.html
