# Introduzione

Quando il numero di iterazioni di un ciclo non è noto in anticipo, cioè quando bisogna «continua finché un predicato non diventa falso», Factor usa il combinator `while` di [`kernel`][kernel]:

```
while ( pred body -- )
```

Sia `pred` sia `body` sono quotation che operano sullo stack dei dati. `while` chiama `pred`; se questo lascia in cima un valore truthy, `while` esegue `body` e ripete; altrimenti si ferma. Lo stato che passa da un'iterazione all'altra vive sullo stack tra una chiamata e l'altra (oppure in variabili locali con nome, quando lo stato è composto da più di un elemento).

```factor
USING: kernel math ;

5 [ dup 0 > ] [ dup . 1 - ] while drop
! prints 5 4 3 2 1
```

`until` è la forma simmetrica: continua *finché* il predicato non diventa truthy.

[kernel]: https://docs.factorcode.org/content/vocab-kernel.html
