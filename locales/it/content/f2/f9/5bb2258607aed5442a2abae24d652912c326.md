# Appendice alle istruzioni

## Implementazione

Definisci una singola funzione Go, MakeChain, che accetta una slice di domino e cerca di costruire una catena valida di domino.

MakeChain deve avere la seguente firma:

```go
type Domino [2]int

func MakeChain(input []Domino) (chain []Domino, ok bool)
```

Il risultato `ok` di tipo bool indica se la lista di domino fornita in input può essere disposta in una catena valida.
Una lista di input vuota è considerata valida, e anche un singolo domino con i lati uguali è considerato valido.

Il risultato «chain» è una slice di zero o più domino disposti in un ordine che mostra la catena valida.
È accettabile (e previsto) che i domino in «input» possano dover essere ruotati affinché ogni lato corrisponda al domino adiacente nella catena.
Anche i domino all'inizio e alla fine della catena devono corrispondere al loro lato esterno.

Se la slice di domino fornita in input non può essere disposta in una catena valida
MakeChain può restituire nil per il risultato «chain», ma deve restituire false per il risultato `ok`.

Poiché possono esserci più di una disposizione valida della catena per una data lista di input, quando `ok` è true, il programma di test controllerà solo la validità della catena.
