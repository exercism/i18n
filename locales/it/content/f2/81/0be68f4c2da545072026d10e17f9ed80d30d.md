# Istruzioni

In questo esercizio organizzerai gare tra vari tipi di auto radiocomandate.
Ogni auto ha le proprie caratteristiche di velocità e di consumo della batteria.

Le auto partono con la batteria carica al 100%.
Ogni volta che guidi l'auto con il radiocomando,
questa percorre un numero di metri pari alla sua velocità e la percentuale di batteria rimanente diminuisce del suo consumo.

Se la batteria di un'auto è inferiore alla sua percentuale di consumo, non puoi più guidarla.

Ogni pista di gara ha una propria distanza.
Le auto vengono messe alla prova verificando se riescono a completare la pista senza esaurire la batteria.

## 1. Crea un'auto radiocomandata

Definisci una struct `Car` con i seguenti campi di tipo `int`:

- battery
- batteryDrain
- speed
- distance

Per creare un'auto radiocomandata, definisci una funzione `NewCar` che prende come parametri la velocità dell'auto in metri
e la percentuale di consumo della batteria (entrambi di tipo `int`) e restituisce un'istanza di `Car`:

```go
speed := 5
batteryDrain := 2
car := NewCar(speed, batteryDrain)
// => Car{speed: 5, batteryDrain: 2, battery:100, distance: 0}
```

## 2. Crea una pista di gara

Definisci un'altra struct chiamata `Track` con il campo `distance` di tipo intero.
Per creare una pista di gara, definisci una funzione `NewTrack` che prende come unico parametro la distanza della pista in metri (di tipo `int`):

```go
distance := 800
track := NewTrack(distance)
// => Track{distance: 800}
```

## 3. Guida l'auto

Implementa la funzione `Drive` che aggiorna il numero di metri percorsi in base alla velocità dell'auto e riduce la batteria in base al consumo.
Se la batteria non è sufficiente per un'altra guida, l'auto non si muove:

```go
speed := 5
batteryDrain := 2
car := NewCar(speed, batteryDrain)
car = Drive(car)
// => Car{speed: 5, batteryDrain: 2, battery: 98, distance: 5}
```

## 4. Verifica se un'auto radiocomandata può completare una gara

Per completare una gara, un'auto deve riuscire a percorrere la distanza della gara.
Questo significa non esaurire la batteria prima di aver tagliato il traguardo.
Implementa la funzione `CanFinish` che prende come parametri un'istanza di `Car` e una di `Track` e restituisce `true` se l'auto può completare la gara, altrimenti restituisce `false`.

Supponi di trovarti sulla linea di partenza della gara e di accendere il motore dell'auto per la gara.
Tieni presente che la batteria dell'auto potrebbe non essere necessariamente carica del tutto quando inizia la gara:

```go
speed := 5
batteryDrain := 2
car := NewCar(speed, batteryDrain)

distance := 100
track := NewTrack(distance)

CanFinish(car, track)
// => true
```
