# Introduzione

Il casting e la conversione di tipo sono due modi diversi di trasformare un'espressione da un tipo di dato a un altro.

Un'espressione può essere convertita in un altro tipo con l'operatore di cast `(<type>)`.

```csharp
long l = 1000L;
int i = (int)l;

object o = new Random();
Random r = (Random)o;
```

Se i tipi non sono compatibili, viene lanciata un'istanza di `InvalidCastException`. Nel caso dei numeri, questo indica che il tipo ricevente non può rappresentare il valore convertito. Nel caso delle classi, uno dei due tipi deve derivare dall'altro (lo stesso vale, banalmente, anche per le struct).

Un'alternativa al _casting_ è la _conversione di tipo_ tramite l'operatore `is`. Di solito si applica ai tipi di riferimento e ai tipi nullable.

```csharp
object o = new Random();
if (o is Random rand)
{
    int ii = rand.Next();
    // now, do something random
}
```

Se devi rilevare il tipo preciso di un oggetto, allora `is` potrebbe essere un po' troppo permissivo, perché restituirà true per una classe e per qualsiasi classe o interfaccia da cui essa derivi, direttamente o indirettamente. In questo caso la soluzione è `typeof` e `Object.GetType()`.

```csharp
object o = new List<int>();

o is ICollection<int> // true
o.GetType() == typeof(ICollection<int>) // false
o is List<int> // true
o.GetType() == typeof(List<int>) // true
```
