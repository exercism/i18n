# Informazioni

Una _stringa_ è il tipo di dato di JavaScript per memorizzare testo.
Non esiste un tipo di dato separato per un singolo carattere.

## Creare una stringa

Puoi creare una [stringa letterale][literal] racchiudendo il testo tra apici singoli o apici doppi.
Su Exercism si usano gli apici singoli.

<!-- prettier-ignore-start -->
```javascript
'Hello, World!'
"Hello, World!"
```
<!-- prettier-ignore-end -->

Alcuni caratteri speciali del testo devono essere preceduti da una barra rovesciata `\`; vedi le [sequenze di escape su MDN][mdn-escape-sequences].

<!-- prettier-ignore-start -->
```javascript
const text = 'I\'m having fun.\nWhat about you?';
console.log(text);
// => I'm having fun.
// => What about you?
```
<!-- prettier-ignore-end -->

Oltre agli apici singoli e doppi, puoi anche creare una stringa racchiudendo il testo tra backtick.
Questa sintassi permette di includere apici singoli o doppi e persino nuove righe senza dover fare l'escape.
Permette anche di incorporare espressioni; per maggiori dettagli, vedi [Stringhe interpolate][mdn-template-strings].

```javascript
`A multi-line string
with 'single quotes'
and "double quotes"`;
```

## Le stringhe come array di caratteri

Una stringa può essere trattata come un array di caratteri, dove il primo carattere ha indice `0`.
Puoi accedere a un singolo carattere della stringa usando le parentesi quadre e l'indice della lettera che vuoi recuperare.
In alternativa, esiste anche il metodo `charAt`.

```javascript
'cat'[1];
// => 'a'

'cat'.charAt(2);
// => 't'
```

Puoi determinare il numero di caratteri di una stringa accedendo alla proprietà `length`.

```javascript
'cat'.length;
// => 3
```

## Concatenazione e metodi

Il modo più semplice per concatenare le stringhe è usare l'operatore di addizione `+`.

```javascript
'I like' + ' ' + 'cats.';
// => "I like cats."
```

Le stringhe offrono molti metodi ausiliari; per un elenco completo, vedi la [documentazione MDN sui metodi delle stringhe][mdn-string-methods].
Qui di seguito trovi alcuni dei metodi ausiliari più comuni.

- [`toUpperCase`][mdn-to-upper-case] e [`toLowerCase`][mdn-to-lower-case]: trasformano tutti i caratteri in maiuscolo o in minuscolo
- [`trim`][mdn-trim]: rimuovono gli spazi bianchi all'inizio e alla fine
- [`includes`][mdn-includes], [`startsWith`][mdn-starts-with] e [`endsWith`][mdn-ends-with]: determinano se un'altra stringa fa parte della stringa data
- [`slice`][mdn-slice]: estraggono una sezione della stringa

## Le stringhe sono immutabili

L'applicazione dei metodi precedenti non modifica mai la stringa originale. Viene invece creata e restituita una nuova stringa.
In JavaScript, le stringhe (e gli altri tipi di dati primitivi) sono immutabili.
Questo significa anche che non puoi assegnare un carattere diverso a un certo indice usando la sintassi con le parentesi quadre mostrata sopra (come faresti con gli array).

```javascript
const str = 'cat';
str[1] = 'u'; // fails silently
console.log(str);
// => 'cat'
```
