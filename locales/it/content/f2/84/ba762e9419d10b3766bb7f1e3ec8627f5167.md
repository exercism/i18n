# preferire Number a parse

La famiglia `parseXXX` è _ottima_ per convertire un input in un numero quando non sai se l'input è un numero, ma quando lo sai è meglio usare la funzione più rigorosa [`Number(...)`](https://developer.mozilla.org/en-US/docs/Web/JavaScript/Reference/Global_Objects/Number#Convert_numeric_strings_and_null_to_numbers ).
