# Istruzioni

In questo esercizio implementerai alcune regole del [Blackjack][blackjack], come il modo in cui si gioca e si assegnano i punti.

**Nota**: In questo esercizio, _`A`_ indica l'asso, _`J`_ il fante, _`Q`_ la regina e _`K`_ il re.
I jolly vengono scartati.
Si presume l'uso di un [mazzo standard francese da 52 carte][standard_deck], ma nella maggior parte delle versioni si mescolano insieme più mazzi per giocare.

## 1. Calcola il valore di una carta

A Blackjack, sta a ogni singolo giocatore decidere se un asso valga 1 o 11 punti (_ne riparleremo più avanti_).
Le figure (`J`, `Q`, `K`) valgono 10 punti e qualsiasi altra carta vale il suo valore «pip» (_numerico_).

Definisci la funzione `value_of_card(<card>)` con parametro `card`.
La funzione deve restituire il _valore numerico_ della stringa della carta passata.
Poiché un asso può assumere più valori (1 **o** 11), per ora questa funzione deve fissare il valore di un asso a 1.
Più avanti implementerai una funzione che determina il valore di un asso, data una mano esistente.

```python
>>> value_of_card('K')
10

>>> value_of_card('4')
4

>>> value_of_card('A')
1
```

## 2. Determina quale carta ha il valore più alto

Definisci la funzione `higher_card(<card_one>, <card_two>)` con parametri `card_one` e `card_two`.
Ai fini del punteggio, il valore di `J`, `Q` o `K` è 10.
La funzione deve restituire quale carta ha il valore più alto ai fini del punteggio.
Se entrambe le carte hanno lo stesso valore, restituiscile entrambe.
Restituire entrambe le carte è possibile usando una virgola nell'istruzione `return`:

```python
# Using a comma in a return creates a Tuple.  Tuples will be covered in a later exercise.
>>> def returning_two_values(value_one, value_two):
        return value_one, value_two

>>> returning_two_values('K', '3')
('K', '3')
```

Un asso può assumere più valori, quindi per questo compito fisseremo le carte `A` a un valore di 1.

```python
>>> higher_card('K', '10')
('K', '10')

>>> higher_card('4', '6')
'6'

>>> higher_card('K', 'A')
'K'
```

## 3. Calcola il valore di un asso

Come accennato prima, un asso può valere _o_ 1 **o** 11 punti.
I giocatori cercano di avvicinarsi il più possibile a un punteggio di 21, senza _superare_ il 21 (_cioè «sballare»_).

Definisci la funzione `value_of_ace(<card_one>, <card_two>)` con parametri `card_one` e `card_two`, che sono una coppia di carte già presenti in mano _prima_ di ricevere un asso.
La funzione dovrà decidere se l'asso in arrivo avrà un valore di 1 o di 11 e restituire quel valore.
Ricorda: il valore della mano con l'asso deve essere il più alto possibile _senza_ superare il 21.

**Suggerimento**: se abbiamo già un asso in mano, il valore dell'asso in arrivo sarà 1.

```python
>>> value_of_ace('6', 'K')
1

>>> value_of_ace('7', '3')
11
```

## 4. Determina una mano «naturale» o «blackjack»

Se a un giocatore vengono distribuite un asso (`A`) e una carta da dieci (10, `K`, `Q` o `J`) come prime due carte, allora il giocatore ha un punteggio di 21.
Questa è nota come mano **blackjack**.


Definisci la funzione `is_blackjack(<card_one>, <card_two>)` con parametri `card_one` e `card_two`, che sono una coppia di carte.
Determina se la mano di due carte è un **blackjack** e restituisci il booleano `True` se lo è, `False` altrimenti.

**Nota**: Il _calcolo_ del punteggio può essere fatto in molti modi.
Ma, se possibile, vorremmo che controllassi se ci sono un asso e una carta da dieci **_nella_** mano (_o in una certa posizione_), invece di _sommare_ i valori della mano.

```python
>>> is_blackjack('A', 'K')
True

>>> is_blackjack('10', '9')
False
```

## 5. Dividere le coppie

Se le prime due carte di una mano hanno lo stesso valore (_ad esempio due sei oppure una `Q` ed un `K`_), un giocatore può scegliere di trattarle come due mani separate.
Questa operazione è nota come «dividere le coppie».

Definisci la funzione `can_split_pairs(<card_one>, <card_two>)` con parametri `card_one` e `card_two`, che sono una coppia di carte.
Determina se questa mano di due carte può essere divisa in due coppie.
Se la mano può essere divisa, restituisci il booleano `True`, altrimenti restituisci `False`

```python
>>> can_split_pairs('Q', 'K')
True

>>> can_split_pairs('10', 'A')
False
```

## 6. Raddoppiare la puntata

Quando le due carte distribuite inizialmente totalizzano 9, 10 o 11 punti, un giocatore può piazzare una puntata aggiuntiva pari a quella iniziale.
Questa operazione è nota come «raddoppiare la puntata».

Definisci la funzione `can_double_down(<card_one>, <card_two>)` con parametri `card_one` e `card_two`, che sono una coppia di carte.
Determina se la mano di due carte può essere «raddoppiata», e restituisci il booleano `True` se può esserlo, `False` altrimenti.

```python
>>> can_double_down('A', '9')
True

>>> can_double_down('10', '2')
False
```
