## Opzioni aggiuntive della riga di comando di jq

Nei test noterai delle opzioni aggiuntive per `jq`.

```sh
run jq -s -R -c -f minesweeper.jq << 'END_INPUT'
```

Quali sono?

- `-s`

  Questa è la modalità «slurp».
  Invece di gestire l'input come un flusso di oggetti JSON,
  tutto l'input verrà raccolto in un array.

  ```sh
  $ seq 5 | jq -c '.'
  1
  2
  3
  4
  5
  $ seq 5 | jq -s -c '.'
  [1,2,3,4,5]
  ```

- `-R`

  Potresti aver già visto `-r`, che produce stringhe «grezze» (senza virgolette).
  Questa opzione fa l'opposto.
  Ogni riga dell'input viene considerata una stringa.

  Due esempi:

  ```sh
  $ seq 5 | jq -R -c .
  "1"
  "2"
  "3"
  "4"
  "5"

  $ echo 42 | jq '. * 2'      # input is a JSON number
  84
  $ echo 42 | jq -R '. * 2'   # input is a JSON string
  "4242"
  ```

Quando metti insieme queste due opzioni, _non_ ottieni un array di stringhe:
ottieni tutto l'input come un'unica stringa, compresi i caratteri di nuova riga alla fine di ogni riga.

```sh
$ seq 5 | jq -s -R -c .
"1\n2\n3\n4\n5\n"
```

Gestire questa cosa fa parte della sfida di questo esercizio.
