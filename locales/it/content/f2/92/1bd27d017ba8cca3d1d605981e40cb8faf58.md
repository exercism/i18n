# Informazioni

Le istruzioni condizionali in C++ sono simili a quelle di altri linguaggi.
Il tipo sottostante di ogni operazione condizionale è il tipo `bool`, che può avere il valore `true` o `false`.
Le istruzioni condizionali sono spesso usate come meccanismi di controllo di flusso per verificare varie condizioni.

Si può usare un'istruzione `if`, che esegue il suo codice se la condizione sottostante è `true`, in questo modo:

```cpp
std::string value{"val"};

if (value == "val") {
    return "was val";
}
```

In scenari che coinvolgono più di un caso, molte istruzioni `if` possono essere concatenate tra loro usando le istruzioni `else if` ed `else`.

```cpp
int number{33};

if (number > 0) {
   return "positive";
} else if (number < 0) {
    return "negative";
} else {
   return "zero";
}
```

A partire da C++17, le istruzioni if possono anche includere una breve istruzione di inizializzazione che può essere usata per inizializzare una o più variabili per l'istruzione if.
Per esempio:

```cpp
int num{7};
if (int v{2 * num}; v > 10) {
    return v;
} else {
    return num;
}
// => 14
```

> Nota: le variabili create nell'inizializzazione non sono accessibili dopo la fine dell'istruzione if.
