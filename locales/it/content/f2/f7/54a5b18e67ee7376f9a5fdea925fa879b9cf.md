# Istruzioni

Sei un appassionato osservatore di uccelli che tiene traccia di quanti uccelli hanno visitato il tuo giardino.
Di solito usi delle tacche su un quaderno per contare gli uccelli, ma per lavorare meglio con i tuoi dati hai digitalizzato i conteggi degli uccelli delle ultime settimane.

## 1. Determina il numero totale di uccelli che hai contato finora

Iniziamo ad analizzare i dati con una panoramica generale.
Scopri quanti uccelli hai contato in totale da quando hai iniziato a tenere i tuoi registri.

Implementa una funzione `totalBirdCount` che accetta un array di `Int` che contiene il conteggio degli uccelli per ogni giorno.
Deve restituire il numero totale di uccelli che hai contato.

```swift
let birdsPerDay = [2, 5, 0, 7, 4, 1, 3, 0, 2, 5, 0, 1, 3, 1]
totalBirdCount(birdsPerDay)
// Returns 34
```

## 2. Calcola il numero di uccelli in visita in una settimana specifica

Ora che hai un'idea generale dei tuoi conteggi di uccelli, vuoi fare un'analisi più dettagliata.

Implementa una funzione `birdsInWeek` che accetta un array di conteggi degli uccelli per giorno e un numero di settimana.

Restituisce il numero totale di uccelli che hai contato in quella settimana specifica.
Puoi assumere che le settimane siano sempre registrate per intero.

```swift
let birdsPerDay = [2, 5, 0, 7, 4, 1, 3, 0, 2, 5, 0, 1, 3, 1]
birdsInWeek(birdsPerDay, weekNumber: 2)
// Returns 12
```

## 3. Correggi un errore di conteggio

Hai capito che, per tutto il tempo in cui cercavi di tenere traccia degli uccelli, c'era un uccello che si nascondeva in un angolo lontano del giardino.

Hai scoperto che questo uccello passava sempre un giorno sì e uno no nel tuo giardino.

Non sai esattamente dove fosse nei giorni in mezzo, ma sicuramente non nel tuo giardino.

La tua intuizione da osservatore di uccelli ti dice anche che l'uccello era nel tuo giardino il primo giorno che hai registrato nella tua lista.

Date queste nuove informazioni, scrivi una funzione `fixBirdCountLog` che prende come argomento un array di uccelli contati per giorno e restituisce l'array dopo aver corretto l'errore di conteggio.

```swift
var birdsPerDay = [2, 5, 0, 7, 4, 1]
fixBirdCountLog(birdsPerDay)
// Returns [3, 5, 1, 7, 5, 1]
```
