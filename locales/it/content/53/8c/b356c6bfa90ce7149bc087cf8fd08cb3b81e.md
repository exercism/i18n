# Installazione

## Installare la Clojure CLI

Clojure fornisce strumenti a riga di comando per: eseguire un REPL interattivo (Read-Eval-Print Loop), eseguire programmi Clojure, valutare espressioni Clojure.
Ti consigliamo di usare la Clojure CLI con gli esercizi. Per installare la [Clojure CLI](https://clojure.org/guides/deps_and_cli):

### Windows
Per le istruzioni di installazione su Windows, vedi: [Installazione della Clojure CLI](https://clojure.org/guides/getting_started#_installation_on_windows).

### Linux
Per le istruzioni di installazione sulla maggior parte delle piattaforme, vedi: [Installazione della Clojure CLI](https://clojure.org/guides/getting_started#_installation_on_linux).

### Homebrew per Mac OS X
Aggiorna Homebrew:

``` bash
$ brew update
```

Installa la Clojure CLI:
``` bash
$ brew install node clojure/tools/clojure
```

`Node` è necessario per l'ambiente node.

## Verificare l'installazione

Per verificare che l'installazione sia corretta, esegui `clojure --help`: se tutto è andato bene, ti mostra la versione.

```bash
$ clojure --help
Version: 1.10.1.547
...
```
