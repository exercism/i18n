# Suggerimenti

## 1. Genera query SELECT

- Ricorda che non serve inizializzare il builder con un costruttore o un valore letterale.
  Un semplice `var sb strings.Builder` è subito operativo.
- Assicurati di gestire il caso in cui la slice `columns` è vuota o `nil` aggiungendo il simbolo jolly `*`.
- Nota che qui non ti viene richiesto, né ci si aspetta, che tu gestisca i metacaratteri o la sanitizzazione SQL. Puoi aggiungere i nomi delle colonne direttamente con `sb.WriteString(col)`, senza problemi.

## 2. Genera istruzioni INSERT in batch

- Allocare un `strings.Builder` nuovo dentro un ciclo `for` annulla i vantaggi in termini di prestazioni.
  Invece, dichiara un unico builder *prima* che il ciclo inizi.
- All'inizio di ogni iterazione del ciclo, chiama il metodo `Reset()` sull'istanza del builder.
  In questo modo svuoti il buffer e puoi iniziare una nuova query mantenendo la capacità di memoria già allocata.
- Non dimenticare che i valori di tipo stringa nella clausola `VALUES` di SQL vanno racchiusi esplicitamente tra apici singoli `'`.
  Puoi usare `WriteByte('\'')` per aggiungerli in modo pulito.
- Proprio come per le query SELECT, non preoccuparti di fare l'escaping dei caratteri speciali né di prevenire le SQL injection all'interno dei valori delle colonne. Considera le stringhe di input sicure da usare direttamente.
