# Informazioni

Quando si scorre una sequenza, a volte il solo elemento non basta: serve anche la posizione. Le parole di iterazione *indicizzata* di Factor passano entrambe le cose alla quotation per elemento, con l'indice in cima alla pila. `times` è la parola correlata per l'iterazione contata senza una sequenza sottostante.

```factor
USING: io kernel math.parser sequences ;

! map-index: build a new sequence; quot sees ( elt index )
{ "alice" "bob" "carol" }
[ number>string ": " glue ] map-index .
! => { "alice: 0" "bob: 1" "carol: 2" }

! each-index: for side effect; quot sees ( elt index )
{ "alice" "bob" } [
    number>string ": " glue print
] each-index
! prints alice: 0
! prints bob: 1

! times: run a quotation N times
3 [ "tick " print ] times
```

| parola       | effetto                                                              |
|--------------|----------------------------------------------------------------------|
| `each-index` | `( seq quot: ( elt index -- ) -- )`                                  |
| `map-index`  | `( seq quot: ( elt index -- newelt ) -- newseq )`                    |
| `times`      | `( n quot: ( -- ) -- )`, ma vedi sotto                               |

Una sottigliezza su `times`: anche se la sua quotation è documentata come `( -- )`, la parola è `inline`, quindi una quotation con effetti bilanciati come `( str -- str )` funziona benissimo e porta la pila attraverso le iterazioni. Così ottieni un accumulatore contato senza alcuno stato mutabile:

```factor
USING: kernel sequences ;

"" 3 [ "clop " append ] times .    ! => "clop clop clop "
```

Lo stesso trucco funziona per `each-index` e `map-index`: l'effetto dichiarato per elemento è un *minimo*, non un massimo.
