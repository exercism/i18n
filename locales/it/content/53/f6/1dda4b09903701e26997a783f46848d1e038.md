# Test

Per eseguire i test, esegui il comando `sbt test` nella directory dell'esercizio.
Per maggiori informazioni, consulta la [pagina dei test](https://exercism.org/docs/tracks/scala/tests).

## Test saltati

Inizialmente sarà abilitato solo il primo test.
Lo scopo è incoraggiarti a risolvere l'esercizio un passo alla volta.
Quando il primo test passa, rimuovi la parola chiave `pending` dall'inizio del test successivo e continua a lavorare per farlo passare.
