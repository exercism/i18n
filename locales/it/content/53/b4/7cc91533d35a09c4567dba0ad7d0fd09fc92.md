# Intervalli

Gli [intervalli][range] rappresentano un intervallo tra due valori.
I tipi più comuni che supportano gli intervalli sono `Integer` e `String`.
Si possono usare per molte cose: creare rapidamente una collezione, estrarre porzioni di stringa, verificare se un valore è compreso in un intervallo e iterare.
Si creano con l'operatore di intervallo `..` o `...` (inclusivo ed esclusivo, rispettivamente).

```ruby
1..5  # => 1..5
1...5 # => 1...5

(1..5).to_a # => [1, 2, 3, 4, 5]
(1...5).to_a # => [1, 2, 3, 4]
```

Il motivo per cui esistono due operatori di intervallo è permettere di creare intervalli che includono o escludono il valore finale, il che può essere utile, per esempio, quando si lavora con indici che partono da zero.

Gli intervalli si possono anche creare usando l'inizializzatore di `Range`.

```ruby
Range.new(1, 5) # A range containing 1, 2, 3, 4, 5
```

~~~~exercism/note
Quando crei un intervallo in Ruby con gli operatori `..` o `...` e vuoi chiamare un metodo sull'intervallo, devi racchiudere l'intervallo tra parentesi.
Altrimenti il metodo verrebbe chiamato sul secondo argomento dell'operatore di intervallo.

```ruby
(1..5).sum # => 15
1..5.sum # => Error: undefined method `sum' for 5:Integer (NoMethodError)
```
~~~~

## Estrarre sottostringhe

Quando vuoi estrarre una porzione di una stringa, puoi usare l'operatore di intervallo per ottenere una sottostringa, cioè creando un intervallo con l'indice iniziale e quello finale della sottostringa.

```ruby
"Hello World"[0..4] # => "Hello"
"Hello World"[6..10] # => "World"
```

Puoi anche usare indici negativi per ottenere la sottostringa dalla fine della stringa.

```ruby
"Hello World"[-5..-1] # => "World"
"Hello World"[6..-4] # => "Wo"
```

## Metodi degli intervalli

Gli intervalli hanno una serie di metodi con cui puoi lavorare. Per esempio, questi metodi possono servire a ottenere la somma di tutti i valori dell'intervallo o a verificare se l'intervallo include un valore.

| Metodo                  | Descrizione                                                             | Esempio                         |
| ----------------------- | ----------------------------------------------------------------------- | ------------------------------- |
| [`sum`][sum]            | Restituisce la somma di tutti i valori dell'intervallo                  | `(1..5).sum # => 15`            |
| [`size`][size]          | Restituisce la dimensione dell'intervallo                               | `(1..5).size # => 5`            |
| [`include?`][indlude]   | Restituisce `true` se l'intervallo include il valore dato, altrimenti `false` | `(1..5).include?(3) # => true` |

## Intervalli senza fine e senza inizio

Un intervallo può essere senza fine o senza inizio.
Un intervallo senza fine o senza inizio ha il valore iniziale o finale pari a `nil`, ma quando definisci l'intervallo puoi omettere il `nil`.

Usare intervalli senza inizio e senza fine è utile quando vuoi, per esempio, estrarre una sottostringa dall'inizio o fino alla fine.

```ruby
"Hello World"[0..] # => "Hello World"
"Hello World"[4..] # => "o World"
"Hello World"[..5] # => "Hello"
```

~~~~exercism/caution
Se non lo usi su una collezione, l'intervallo senza fine può causare una sequenza infinita: usalo con cautela.
~~~~

## Intervalli di stringhe

Anche le stringhe si possono usare negli intervalli e permettono di ottenere un intervallo di stringhe compreso tra due stringhe.
Il comportamento può essere un po' inaspettato con certe stringhe, quindi usalo con cautela.

```ruby
"aa".."az".to_a # => ["aa", "ab", "ac", ..., "az"]
```
