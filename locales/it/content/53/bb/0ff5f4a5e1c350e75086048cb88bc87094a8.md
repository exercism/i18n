# Introduzione

## Variabili e assegnazione

R è un linguaggio a tipizzazione dinamica, quindi in generale non è necessario specificare il tipo di una variabile. L'operatore di assegnazione preferito è `<-` 

```R
x <- 42
avogadro <- 6.02e23
mystr <- "Hello, World!"
```

Usare `=` al posto di `<-` spesso funziona, ma non sempre, ed è sconsigliato perché è cattivo stile.
Se lavori in RStudio, puoi inserirlo con la scorciatoia da tastiera `Alt-minus`.

Gli operatori sono per lo più convenzionali, ma fai attenzione a `%/%` e `%%`:

```R
2 + 3   # 5
2 - 3   # -1
2 * 3   # 6
2 / 3   # 0.6666667
8 %/% 3 # 2 (integer division)
8 %% 3  # 2 (remainder)
2 ^ 3   # 8 (exponential)
```

In R, `#` inizia un commento su una sola riga.
Non esiste una sintassi separata per i commenti su più righe.

## Funzioni

Per definire una funzione:

```R
squareit <- function(x) {
    x * x
}
```

Le funzioni possono avere zero o più argomenti, separati da virgole.
Le parentesi tonde (`()`) sono necessarie con `function()`, anche se non ci sono parametri.

Si possono specificare valori predefiniti per gli argomenti di una funzione, ma questi devono venire dopo tutti gli argomenti senza valore predefinito, e per assegnare il valore predefinito si usa `=`, non `<-`.
Un esempio piuttosto inutile:

```R
squareit <- function(x = 42) {
    x * x
}

squareit()
#> [1] 1764
```

Le parentesi graffe (`{ }`) non sono strettamente necessarie per i corpi di funzione su una sola riga, ma includerle è considerato buono stile.

R restituisce automaticamente il valore finale di una funzione, come negli esempi qui sopra.

`return()` può essere usata in qualsiasi punto del corpo della funzione per rendere esplicito il valore restituito.

Chiamare una funzione è come in molti altri linguaggi:

```R
squareit(3)
#> [1] 9
```
