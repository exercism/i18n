# Appendice alle istruzioni

## Registri

| Registro | Utilizzo     | Tipo    | Descrizione                              |
| -------- | ------------ | ------- | ---------------------------------------- |
| `$a0`    | input        | intero  | numero naturale da fattorizzare          |
| `$a1`    | input/output | indirizzo | array di destinazione per i fattori primi |
| `$v0`    | output       | intero  | numero di fattori                        |
| `$t0-9`  | temporaneo   | qualsiasi | usato come memoria temporanea            |
