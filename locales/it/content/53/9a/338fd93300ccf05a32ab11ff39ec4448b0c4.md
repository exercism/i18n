# Test

Per eseguire i test di questo track, dovrai installare DUnitX. Per ulteriori informazioni, consulta le istruzioni per l'[installazione](http://www.exercism.org/docs/tracks/delphi/installation).

### Caricare gli esercizi in Delphi

Se Delphi è installato correttamente e i tipi di file `*.dpr` sono stati associati a Delphi, facendo doppio clic sul file `*.dpr` fornito si avvierà Delphi e si caricherà l'esercizio/progetto. `control + F9` è la scorciatoia da tastiera per compilare il progetto, oppure premendo `F9` si compila ed esegue il progetto.

In alternativa, puoi avviare Delphi e caricare il progetto dal menu a tendina `File`.
