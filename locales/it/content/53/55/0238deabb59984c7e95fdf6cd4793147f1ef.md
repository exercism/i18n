# Modulo

Usare le comparazioni con il modulo è perfettamente valido in Crystal, ma un modo più leggibile per confrontare il resto di una divisione è il metodo [`divisible_by?`][divisible_by].
O, ancora meglio, se vuoi verificare se un numero è dispari o pari, usa i metodi [`odd?`][odd?] e [`even?`][even?].

Ad esempio:

```crystal
# Rather than:
number %% 2 == 0

# Consider:
number.even?
```
