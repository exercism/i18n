# Informazioni

Puoi usare i [tipi di enumerazione][enumeration types] ogni volta che hai un insieme fisso di valori costanti. Usare un `enum` offre un modo type-safe di interagire con valori costanti. Un enum si definisce tramite la parola chiave `enum`. Un membro di un enum si indica anteponendogli il nome dell'enum e un punto (ad esempio `Status.Active`).

Ogni membro di un enum è un'associazione tra un nome e un valore `int`. Se il primo membro non ha un valore esplicito, il suo valore è impostato a `0`. Se per un membro di un enum non viene definito esplicitamente alcun valore, il suo valore viene automaticamente impostato al valore del membro precedente più `1`.

```csharp
enum Season
{
    Spring,     // Auto set 0
    Summer = 2, // Set the value 2
    Autumn,     // Auto set 3
    Winter = 7  // Set the value 7
}
```

Gli enum sono molto dichiarativi. Confronta le due chiamate di metodo seguenti:

```csharp
Users.WithStatus(1)
Users.WithStatus(Status.Active)
```

Per chi legge il codice, la seconda versione (con l'enum) sarà più facile da comprendere.

## Enum con tipo numerico

Sebbene il tipo numerico predefinito dei valori sia `int`, è possibile cambiarlo specificando esplicitamente qualsiasi altro tipo [numerico integrale][integral numeric].

Il seguente enum usa il tipo numerico `byte` per i suoi valori:

```csharp
enum Priority : byte
{
    Low = 0,
    Medium = 127,
    High = 255
}
```

## Convertire in un membro di un enum

Dovresti sempre considerare di usare un enum ogni volta che vuoi modellare qualcosa come un booleano. Oltre ai vantaggi di leggibilità appena citati, gli enum hanno un altro vantaggio rispetto ai booleani: a un enum si possono sempre aggiungere nuovi valori, mentre un valore booleano sarà sempre e solo `true` o `false`. Usare un enum è quindi una scelta più lungimirante.

```csharp
enum Status
{
    Inactive = 0,
    Active = 1
}

Status active = (Status) 1;
active == Status.Active; // True
```

Nota che, sebbene _si possa_ eseguire il cast di valori interi a un enum, farlo può portare a risultati inaspettati quando il valore intero non corrisponde ad alcun valore dell'enum:

```csharp
Status status = (Status) 2;
status == Status.Inactive; // False
status == Status.Active;   // False
```

## Fare il parsing di un enum

A volte è utile convertire una stringa in un membro di un enum in base al suo nome con [`Enum.Parse`][enum parse]:

```csharp
var input = "Inactive";
Status status = (Status)Enum.Parse(typeof(Status), input);
// Inactive
```

Per verificare se un nome o un valore esiste nell'enum, puoi usare [`Enum.TryParse`][enum tryparse] o [`Enum.IsDefined`][enum isdefined], entrambi restituiscono un booleano che indica se il membro dell'enum esiste:

```csharp
bool doesExist = Enum.IsDefined(typeof(Status), "Inexistent");
// False
```
