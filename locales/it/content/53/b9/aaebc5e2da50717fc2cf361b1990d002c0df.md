# Installazione

## Installa .NET 10

La track di Visual Basic usa .NET 10.
Per compilare ed eseguire i test degli esercizi in locale, installa [l'SDK di .NET 10 per il tuo sistema operativo][install-sdk]:
installa l'SDK, non solo il runtime.

## Verifica l'installazione

Apri un nuovo terminale ed esegui:

```bash
dotnet --version
```

Il comando dovrebbe produrre come output `10.0.0` o una versione successiva.

## Supporto per l'editor

Il solo SDK di .NET e un editor di testo essenziale bastano per completare gli esercizi.
Per funzionalità più avanzate come il completamento automatico del codice e il debug, potresti prendere in considerazione uno di questi editor:

- [Visual Studio 2026][visual-studio] su Windows
- [Visual Studio Code][visual-studio-code] su Windows, Linux o macOS
- [JetBrains Rider][rider] su Windows, Linux o macOS

[rider]: https://www.jetbrains.com/rider/
