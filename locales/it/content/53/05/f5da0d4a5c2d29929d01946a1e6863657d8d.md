# Test

Per testare la soluzione, basta eseguire:

```bash
make test
```

Questo eseguirà il file di test `<exercise-name>-test.ys`, che contiene tutti i test che dovrai superare perché la soluzione sia corretta.
Dovresti studiare il file di test per capire esattamente cosa deve fare la soluzione.

> Nota: la prima volta che esegui `make test`, verrà anche verificato che la versione corretta dell'interprete YAMLScript `ys` sia installata nel posto giusto.

Se esegui `make test` prima di modificare qualsiasi file, tutti i test falliranno.
Questo è il comportamento corretto e previsto.
Il normale processo di sviluppo di un esercizio consiste nel migliorare la soluzione in modo iterativo, eseguendo `make test` dopo ogni modifica, finché non passano tutti i test.

Se vuoi eseguire solo un test specifico (mentre ti concentri su quella parte della soluzione), puoi aggiungere questa coppia chiave/valore a quel test:

```yaml
  ONLY: true
```

Se vuoi saltare alcuni test (mentre lavori su altre parti della soluzione), puoi aggiungere questa coppia chiave/valore a quei test:

```yaml
  SKIP: true
```


## Prerequisiti per i test

Al momento YAMLScript funziona su MacOS e Linux.

Il tuo computer dovrà avere installati i seguenti comandi molto comuni:

* `bash`: Puoi eseguire i test con qualsiasi shell, ma `bash` deve essere disponibile.
* `make`: Devi usare GNU `make` per eseguire i test.
  In alcuni ambienti potrebbe avere un nome diverso da `make`.
  Possibilmente `gmake`.
* `prove`: Questo programma fa parte di qualsiasi installazione normale di Perl.
* `curl`: Serve per installare `ys` se non è già installato.

È molto probabile che tu abbia già installato tutti questi programmi.
