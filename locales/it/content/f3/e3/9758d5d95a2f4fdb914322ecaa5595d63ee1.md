# Parole chiave statiche di classe

In PHP, una classe è un'unità di organizzazione del codice e spesso rappresenta un'istanza di una cosa, un servizio o una procedura. Usando le parole chiave `static` e `self`, proprietà e metodi possono esistere in riferimento alla classe per tutte le istanze (o per nessuna istanza).

```php
<?php

class Book
{
    static $genre = 'Adventure';

    static function getGenre()
    {
        return self::$genre;
    }
}

// Usage
$genre = Book::$genre;
$genre = Book::getGenre();
```

## Limitazione

I metodi statici di una classe possono chiamare solo altre proprietà statiche o altri metodi statici della stessa classe.
