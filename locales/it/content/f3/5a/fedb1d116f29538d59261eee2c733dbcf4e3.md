# Informazioni

Rust implementa il tipo [char][char type] per rappresentare un singolo carattere. Un letterale `char` si scrive tra apici singoli, come `'a'`.
Ogni `char` occupa quattro byte e rappresenta un singolo [valore scalare Unicode][unicode scalar].

Tuttavia, un [`char`][character type] non è sempre quello che consideriamo una lettera. In alcune lingue, come l'hindi, si usano i [segni diacritici][diacritics],
simboli speciali che modificano il carattere a cui sono legati. Anche se in Rust il segno diacritico è un `char` a sé stante, quello che comunemente
consideriamo una lettera è il segno diacritico insieme al carattere che modifica.

Il termine per indicare un carattere e il suo segno diacritico è [cluster di grafemi][grapheme cluster]. Esistono crate esterni che si possono usare
per elaborare i cluster di grafemi, come [unicode-segmentation][unicode-segmentation].

Esempio

```rust
pub fn main() {
    let text = "ü"; // a "u" with a diacritic
    let text_vec: Vec<char> = text.chars().collect(); // this gets the chars in "ü"
    println!("{:?}", text_vec.len()); // this prints the number of chars in "ü"
    println!("{:?}", text_vec[0]); // this prints the first char in "ü"
    println!("{:?}", text_vec[1]); // this prints the second char in "ü"
}
```

stampa

```rust
2
'u'
'\u{308}'
```

`'\u{308}'` è un altro modo di scrivere un letterale `char`. `\u` indica che si tratta di un `char` unicode, dove `{308}` è il numero Unicode univoco
di quel carattere o segno diacritico.
