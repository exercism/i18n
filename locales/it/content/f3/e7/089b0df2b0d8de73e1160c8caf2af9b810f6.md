# Istruzioni

Un tuo amico ti ha appena inviato un messaggio con un segreto importante.
Per non rendere troppo facile leggerlo agli altri, il messaggio è stato cifrato eseguendo una serie di manipolazioni sui bit.
Dovrai scrivere i metodi che servono a decifrare il messaggio.

## 1. Sposta i bit indietro

Il primo passo per decifrare il messaggio consiste nell'annullare lo scorrimento fatto durante la cifratura, spostando di nuovo i bit verso destra.
Nei passaggi successivi del processo di decifratura si presume che vengano inseriti degli 0 dal lato sinistro.

Implementa il metodo `Secrets.shiftBack`, che accetta un valore e il numero di posizioni da spostare ed esegue lo scorrimento.

```java
Secrets.shiftBack(0b1001, 2);
# => 0b0010
```

## 2. Imposta alcuni bit

Ora ci sono alcuni bit che devono essere impostati a 1.

Implementa il metodo `Secrets.setBits`, che accetta un valore e una maschera e restituisce il risultato dell'impostazione a 1 dei bit di value.
Un bit di value va impostato a 1 dove anche il bit della maschera è 1.
Tutti gli altri bit devono restare invariati.

```java
Secrets.setBits(0b0110, 0b0101);
# => 0b0111
```

## 3. Inverti bit specifici

Durante la cifratura alcuni bit vengono invertiti.
Per decifrare il messaggio bisognerà invertirli di nuovo.

Implementa il metodo `Secrets.flipBits`, che accetta un valore e la maschera.
La maschera indica quali bit del valore invertire.
Se il bit è 1 nella maschera, il bit viene invertito nel valore.
Tutti gli altri bit restano invariati.

```java
Secrets.flipBits(0b1100, 0b0101);
# => 0b1001
```

## 4. Azzera bit specifici

Infine, ci sono anche alcuni bit che, una volta decifrati, valgono sempre 0.

Implementa il metodo `Secrets.clearBits`, che accetta un valore e una maschera.
I bit di `value` vanno impostati a 0 dove il bit della maschera è 1.
Tutti gli altri bit devono restare invariati.

```java
Secrets.clearBits(0b0110, 0b0101);
# => 0b0010
```
