# Suggerimenti

## 1. Crea un array vuoto

Creare un array vuoto è proprio come creare un array con degli elementi. Puoi farlo usando `list` oppure `quote` su un array vuoto.

## 2. Aggiungi un nuovo linguaggio all'array

Clojure ha una funzione del core che può [anteporre un elemento a un array](https://clojuredocs.org/clojure.core/cons).

## 3. Controlla l'ultimo linguaggio aggiunto

Come in altri Lisp, anche Clojure ha una funzione che [restituisce il primo elemento di un array](https://clojuredocs.org/clojure.core/first).

## 4. Rimuovi il primo linguaggio dall'array

Allo stesso modo, Clojure ha anche una funzione che [restituisce un array con il primo elemento rimosso](https://clojuredocs.org/clojure.core/rest).

## 5. Conta i linguaggi nell'array

Il [numero di elementi](https://clojuredocs.org/clojure.core/count) in un array si può restituire facilmente con una funzione del core di Clojure.

## 6. Metti tutto insieme

Ricorda che le chiamate di funzione possono essere annidate.
