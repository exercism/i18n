# Istruzioni

Karl vuole tenere traccia di un array di linguaggi da imparare sul sito di Exercism.
Karl deve poter aggiungere nuovi linguaggi, rimuoverne di vecchi e controllare se certi linguaggi sono nell'array.
Sarebbe davvero entusiasmante se Karl volesse imparare Java o Kotlin!

## 1. Definire una funzione che verifica se l'array dei linguaggi è vuoto

Karl deve sapere se il suo array di linguaggi diventa vuoto, così può andare a cercarne altri da imparare!
Definisci un metodo chiamato `isEmpty` che restituisce `true` se non ci sono linguaggi nell'array.

```java
if (languageList.isEmpty()) {
    findMoreLanguagesToLearn();
}
```

## 2. Definire una funzione che aggiunge un linguaggio all'array

Karl non vede l'ora di imparare Kotlin e Python!
Aiuta Karl a iniziare definendo un metodo chiamato `addLanguage` che prende il linguaggio che vuole imparare e lo aggiunge all'array.

```java
languageList.addLanguage("Kotlin");
languageList.addLanguage("Python");
```

## 3. Definire una funzione che rimuove un linguaggio dall'array

Karl ha deciso che al momento non vuole imparare Scala.
Aiuta Karl a rimuoverlo dall'array definendo un metodo chiamato `removeLanguage` che prende il linguaggio che sta rimuovendo e lo elimina dall'array.

```java
languageList.removeLanguage("Scala");
```

## 4. Definire una funzione che restituisce il primo elemento dell'array

Karl vuole ricordare il primo linguaggio che ha aggiunto all'array (che è ancora nell'array).
Definisci un metodo chiamato `firstLanguage` che restituisce il primo linguaggio dell'array.

```java
String kotlin = languageList.firstLanguage(); // "Kotlin"
```

## 5. Definire una funzione che restituisce quanti linguaggi ci sono nell'array

Karl deve sapere quanti linguaggi sta cercando di imparare.
Aiuta Karl a trovare la risposta definendo un metodo chiamato `count` che restituisce il numero di linguaggi nell'array.

```java
int two = languageList.count(); // 2
```

## 6. Definire una funzione che determina se un linguaggio è nell'array

Karl sta cercando di ricordare se voleva imparare Python o Ruby.
Definisci un metodo chiamato `containsLanguage` che prende il linguaggio su cui sta chiedendo, così Karl può scoprirlo!

```java
boolean learningPython = languageList.containsLanguage("Python"); // true
boolean learningRuby = languageList.containsLanguage("Ruby"); // false
```

## 7. Definire una funzione che determina se l'array è entusiasmante

Se Karl vuole imparare Java o Kotlin, è davvero entusiasmante!
Definisci un metodo chiamato `isExciting` che restituisce true se Karl vuole imparare Java o Kotlin.

```java
javaLanguageList.isExciting() // true
neitherKotlinNorJavaLanguageList.isExciting() // false
```
