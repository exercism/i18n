# Istruzioni

In questo esercizio, dovrai scrivere il software per un dispositivo di cifratura che funziona applicando trasformazioni ai dati. Ti servirà un modo per creare in modo flessibile funzioni complicate combinando insieme funzioni più semplici.

Per ogni attività, restituisci una funzione anonima che possa essere chiamata dallo scope chiamante.

## 1. Crea un sommatore

Implementa `secret_add`. Deve restituire una funzione che accetta un argomento e vi aggiunge l'argomento passato a `secret_add`.

```gleam
let adder = secret_add(2)
adder(2)
// -> 4
```

## 2. Crea un sottrattore

Implementa `secret_subtract`. Deve restituire una funzione che accetta un argomento e sottrae da quell'argomento il segreto passato a `secret_subtract`.

```gleam
let subtractor = secret_subtract(2)
subtractor(3)
// -> 1
```

## 3. Crea un moltiplicatore

Implementa `secret_multiply`. Deve restituire una funzione che accetta un argomento e lo moltiplica per il segreto passato a `secret_multiply`.

```gleam
let multiplier = secret_multiply(7)
multiplier(3)
// -> 21
```

## 4. Crea un divisore

Implementa `secret_divide`. Deve restituire una funzione che accetta un argomento e lo divide per il segreto passato a `secret_divide`.

```gleam
let divider = secret_divide(3)
divider(32)
// -> 10
```

## 5. Crea un combinatore di funzioni

Implementa `secret_combine`. Deve restituire una funzione che accetta un argomento e vi applica, nell'ordine, le due funzioni passate a `secret_combine`.

```gleam
let multiply = secret_multiply(7)
let divide = secret_divide(3)
let combined = secret_combine(multiply, divide)

combined(6)
// -> 14
```
