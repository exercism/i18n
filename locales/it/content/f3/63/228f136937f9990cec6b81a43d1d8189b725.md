# Istruzioni

In questo esercizio, implementerai la gestione degli errori per una semplice calcolatrice di numeri interi.
La calcolatrice dovrà supportare le operazioni di addizione, moltiplicazione e divisione, restituendo il risultato come stringa formattata.
Implementerai anche la gestione degli errori per le operazioni non valide e la divisione per zero.

L'obiettivo è avere una calcolatrice funzionante che restituisca una stringa nel formato seguente:

```rust
SimpleCalculator::calculate(16, 51, "+"); // => returns "16 + 51 = 67"

SimpleCalculator::calculate(32, 6, "*"); // => returns "32 * 6 = 192"

SimpleCalculator::calculate(512, 4, "/"); // => returns "512 / 4 = 128"
```

## 1. Implementa le operazioni della calcolatrice

La funzione principale di questa attività sarà `SimpleCalculator::calculate`, che accetta tre argomenti: due numeri interi e un `ByteArray` che rappresenta l'operazione.
Implementa le seguenti operazioni:

- **Addizione** con il simbolo `+`
- **Moltiplicazione** con il simbolo `*`
- **Divisione** con il simbolo `/`

## 2. Gestisci le operazioni non valide

Se il simbolo dell'operazione è diverso da `+`, `*` o `/`, la calcolatrice deve andare in panic oppure restituire un errore:

- Se l'operazione è una stringa vuota, va in panic con un messaggio di errore `ByteArray` `"Operation cannot be an empty string"`.
- Per qualsiasi altra operazione non valida, restituisci `Result::Err("Operation is out of range")`.

```rust
SimpleCalculator::calculate(100, 10, "-"); // => returns Result::Err("Operation is out of range")

SimpleCalculator::calculate(8, 2, ""); // => panics with "Operation cannot be an empty string"
```

## 3. Gestisci gli errori nella divisione per zero

Quando si tenta di dividere per `0`, la calcolatrice deve andare in panic con un messaggio di errore che indica che la divisione per zero non è consentita.
Il risultato restituito dovrà essere un valore `felt252` pari a `'Division by zero is not allowed'`.

```rust
SimpleCalculator::calculate(512, 0, "/"); // => panics with 'Division by zero is not allowed'
```
