# Segnaposto

## L'opzione `--argjson`

I test usano l'opzione `--argjson n 1` di `jq`.
Questo crea una variabile jq chiamata `$n` che contiene il valore _**numerico**_ `1`.

Confrontalo con l'opzione `--arg n 1`
che crea una variabile jq chiamata `$n` che contiene il valore _**stringa**_ `"1"`.

Nella soluzione, usa `$n` come input per ottenere l'ennesimo numero primo.

Vedi [Invocare jq][man-invoke] nel manuale.

[man-invoke]: https://jqlang.org/manual/#invoking-jq
