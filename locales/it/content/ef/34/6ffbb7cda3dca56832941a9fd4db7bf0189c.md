# Introduzione

## `Base.@kwdef`

La macro `Base.@kwdef` può essere usata per definire automaticamente costruttori che accettano argomenti keyword per la definizione di uno [struct][struct].
Permette anche di impostare valori predefiniti per i campi.

Per esempio, la seguente definizione

```julia
Base.@kwdef struct HumanStats
    birthyear::Int
    height::Int
    mass::Int
    bmi::Float64 = mass / (0.01 * height)^2
end
```

definisce tre costruttori in una volta sola

```julia-repl
julia> methods(HumanStats)
# 3 methods for type constructor:
[1] HumanStats(; birthyear, height, mass, bmi) [...]
[2] HumanStats(birthyear::Int64, height::Int64, mass::Int64, bmi::Float64) [...]
[3] HumanStats(birthyear, height, mass, bmi) [...]
```

compreso un costruttore basato su argomenti keyword

```julia-repl
julia> HumanStats(
           birthyear = 2002,
           height = 193,
           mass = 83
       )
HumanStats(2002, 193, 83, 22.28247738194314)
```

mentre la definizione standard

```julia
struct HumanStats
    birthyear::Int
    height::Int
    mass::Int
    bmi::Float64
end
```

ne definisce solo i due seguenti

```julia-repl
julia> methods(HumanStats)
# 2 methods for type constructor:
[1] HumanStats(birthyear::Int64, height::Int64, mass::Int64, bmi::Float64) [...]
[2] HumanStats(birthyear, height, mass, bmi) [...]
```

e richiederebbe di definire manualmente un costruttore basato su argomenti keyword.

### Quando usare `Base.@kwdef`?

I costruttori basati su argomenti keyword sono particolarmente utili per costruire struct che accettano un gran numero di argomenti, soprattutto quando il tipo o il valore degli argomenti non sono direttamente collegati al loro significato.

Considera la seguente definizione:

```julia
dirk = BasketballPlayer(1978, 1994, 2019, 213, 111, 42, 1998, [2011], 31560, 11489, 3651)
```

Non è chiaro cosa significhi ogni valore senza conoscere la definizione del tipo.
E anche conoscendo la definizione, probabilmente si dovrebbe controllare l'ordine più e più volte.

Quando però si usa un costruttore basato su argomenti keyword, il loro significato è immediatamente ovvio:

```julia
dirk = BasketballPlayer(
    birthyear = 1978,
    career_start = 1994,
    career_end = 2019,
    height = 213,
    weight = 111,
    number = 42,
    drafted = 1998,
    championships = [2011],
    points = 31560,
    rebounds = 11489,
    assists = 3651
)
```

~~~~exercism/caution
`Base.@kwdef` non è esportata e non è documentata nel manuale, quindi non fa parte della [API pubblica di Julia][public-api].
Questo significa che, tecnicamente, non è garantito che la sua interfaccia sia stabile e potrebbe cambiare tra aggiornamenti minori di Julia.

Tuttavia, la macro è ampiamente usata in tutto l'ecosistema ed è improbabile che venga modificata in modo da rompere la compatibilità.

Per maggiori informazioni, vedi:

- [«Che cosa fa `@kwdef`?»][discourse-kwdef]
- [Issue di Julia #32659 per aggiungere `@kwdef` al manuale][add-kwdef-to-manual]
- [Issue di Julia #33192 per esportare `@kwdef`][export-kwdef]

~~~~
