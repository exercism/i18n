# Istruzioni

Il tuo lavoro presso il negozio online di moda continua. Ti viene l'idea per una funzionalità del sito che suggerisca un outfit all'utente. Vuoi dare tanti suggerimenti, ma non vuoi darne di sbagliati, così decidi di usare una list comprehension: puoi _generare_ facilmente combinazioni di outfit e poi _filtrarle_ in base a qualche criterio.

I capi di abbigliamento sono memorizzati in una mappa:

```elixir
%{
  item_name: "Descriptive Name",
  price: 99.00,
  color: "Ochre Red",
  base_color: "red"
}
```

## 1. Suggerisci una combinazione

Implementa `get_combinations/3` in modo che prenda una lista di top, una lista di bottom e una keyword list di opzioni. Per ora, imposta le opzioni su una keyword list vuota come valore predefinito. La funzione dovrebbe restituire il prodotto cartesiano delle liste.

```elixir
tops = [
  %{item_name: "Dress shirt"},
  %{item_name: "Casual shirt"}
]

bottoms = [
  %{item_name: "Jeans"},
  %{item_name: "Dress trousers"}
]

BoutiqueSuggestions.get_combinations(tops, bottoms)
# => [
#      {%{item_name: "Dress shirt"}, %{item_name: "Jeans"}},
#      {%{item_name: "Dress shirt"}, %{item_name: "Dress trousers"}},
#      {%{item_name: "Casual shirt"}, %{item_name: "Jeans"}},
#      {%{item_name: "Casual shirt"}, %{item_name: "Dress trousers"}}
#    ]
```

## 2. Filtra gli outfit che non si abbinano

Ogni capo di abbigliamento ha un campo `:base_color`: usa questo campo per filtrare tutte le combinazioni in cui il top e il bottom hanno lo stesso colore di base.

```elixir
tops = [
  %{item_name: "Dress shirt", base_color: "blue"},
  %{item_name: "Casual shirt", base_color: "black"}
]

bottoms = [
  %{item_name: "Jeans", base_color: "blue"},
  %{item_name: "Dress trousers", base_color: "black"}
]

BoutiqueSuggestions.get_combinations(tops, bottoms)
# => [
#      {%{item_name: "Dress shirt", base_color: "blue"},
#       %{item_name: "Dress trousers", base_color: "black"}},
#      {%{item_name: "Casual shirt", base_color: "black"},
#       %{item_name: "Jeans", base_color: "blue"}}
#    ]
```

## 3. Filtra in base al prezzo della combinazione

Ogni capo di abbigliamento ha un campo `:price` associato. Vuoi dare tanti suggerimenti, ma vuoi anche poter offrire agli utenti la possibilità di scegliere un prezzo entro il proprio budget. Dalla keyword list di opzioni, usa `:maximum_price` per filtrare le combinazioni in cui il prezzo del top e del bottom supera il prezzo massimo.

Se non viene specificato maximum_price, il valore predefinito dovrebbe essere `100.00`

```elixir
tops = [
  %{item_name: "Dress shirt", base_color: "blue", price: 35},
  %{item_name: "Casual shirt", base_color: "black", price: 20}
]

bottoms = [
  %{item_name: "Jeans", base_color: "blue", price: 30},
  %{item_name: "Dress trousers", base_color: "black", price: 75}
]

BoutiqueSuggestions.get_combinations(tops, bottoms, maximum_price: 50)
# => [
#      {%{item_name: "Casual shirt", base_color: "black", price: 20},
#       %{item_name: "Jeans", base_color: "blue", price: 30}}
#    ]
```
