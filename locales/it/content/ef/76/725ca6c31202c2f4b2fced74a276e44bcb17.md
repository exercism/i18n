# Appendice alle istruzioni

## Istruzioni specifiche del track

In passato, Elm usava la programmazione reattiva funzionale, per poi specializzarsi nell'uso dell'Elm Architecture.

Risolvi questo esercizio come se stessi scrivendo un'app web che usa l'Elm Architecture.
L'output del programma dovrebbe essere HTML con la seguente struttura:

```html
<div>
  <dl>
    <dt>State</dt>
    <dd>Ongoing</dd>
    <dt>Word</dt>
    <dd>______</dd>
    <dt>Remaining failures</dt>
    <dd>5</dd>
  </dl>
</div>
```

dove `<dl>` è l'elemento lista di descrizione, `<dt>` l'elemento termine di descrizione e `<dd>` l'elemento dettagli di descrizione, tutti elementi HTML standard.

Se c'è un errore, l'output dovrebbe avere la seguente struttura:

```html
<div>
  <p>error message</p>
</div>
```
