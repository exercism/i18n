# Introduzione

## Confronti

In C++, puoi confrontare i valori usando gli operatori di confronto.

| Confronto         | Operatore |
| ------------------| --------- |
| uguale            | `==`      |
| diverso           | `!=`      |
| minore            | `<`       |
| minore o uguale   | `<=`      |
| maggiore          | `>`       |
| maggiore o uguale | `>=`      |

Il risultato di questi confronti è sempre un valore booleano:

```cpp
int a{3};

bool eq1 = a != 4; // true

bool eq2 = a > 5;  // false
```

Gli operatori `==` e `!=` verificano rispettivamente se un valore è uguale a un altro oppure no.
Ecco alcuni esempi comuni:

```cpp
bool eq3 = 2 == 3; // false, integer comparison

bool eq4 = 2.1 != 2.2; // true, float comparison

bool eq5 = "hello" == "hello"; // true, string comparison
```

Gli altri operatori verificano se un valore è maggiore (`>`), maggiore o uguale (`>=`), minore (`<`) o minore o uguale (`<=`) a un altro valore.
Questo tipo di confronto è disponibile per i numeri e per le stringhe.
Quando si confrontano le stringhe, si segue l'ordine alfabetico (noto anche come ordine lessicografico).

```cpp
bool eq6 = 2 > 3; // false, integer comparison

bool eq7 = 1.2 < 1.3; // true, float comparison

bool eq8 = "Hello" < "World"; // true, string comparison
```

## Istruzioni if

Le strutture condizionali in C++ sono simili a quelle di altri linguaggi.
Il tipo sottostante di qualsiasi operazione condizionale è il tipo `bool`, che può avere il valore `true` o `false`.
Le strutture condizionali sono spesso usate come meccanismi di controllo del flusso per verificare varie condizioni.

Si può usare un'istruzione `if`, che esegue il suo codice se la condizione sottostante è `true`, in questo modo:

```cpp
std::string value{"val"};

if (value == "val") {
    return "was val";
}
```

Quando i casi sono più di uno, si possono concatenare più istruzioni `if` usando le istruzioni `else if` ed `else`.

```cpp
int number{33};

if (number > 0) {
   return "positive";
} else if (number < 0) {
    return "negative";
} else {
   return "zero";
}
```

A partire da C++17, le istruzioni if possono anche includere una breve istruzione di inizializzazione, che si può usare per inizializzare una o più variabili per l'istruzione if.
Per esempio:

```cpp
int num{7};
if (int v{2 * num}; v > 10) {
    return v;
} else {
    return num;
}
// => 14
```

> Nota: le variabili create nell'inizializzazione non sono accessibili dopo la fine dell'istruzione if.
