# I Bool

Crystal ha un tipo noto come [`Bool`][bools].
Rappresenta i valori `true` e `false`.

## Operatori logici

Crystal ha tre operatori logici (`!`, `||`, `&&`), che combinano i Bool e creano espressioni che producono valori diversi.

### And (`&&`)

L'operatore [_and_][and] in Crystal è rappresentato da `&&` e restituisce `true` se entrambi i valori sono `true`, altrimenti restituisce `false`.
Quando usi l'operatore _and_, un Bool va messo a destra del `&&` e un altro a sinistra.

```crystal
true && true
# => true

true && false
# => false
```

### Or (`||`)

L'operatore [_or_][or] in Crystal è rappresentato da `||` e restituisce `true` se **almeno uno** dei valori dati è `true`. 
Se entrambi i valori sono `false`, restituisce `false`.
Quando usi l'operatore _or_, un Bool va messo a destra del `||` e un altro a sinistra.

```crystal
true || true
# => true

true || false
# => true

false || false
# => false
```

### Not (`!`)

L'operatore _not_ in Crystal è rappresentato da `!` e restituisce `true` se il Bool dato è `false`, e restituisce `false` se gli viene passato `true`.
Quando usi l'operatore _not_, un Bool va messo dopo l'operatore (`!`).

```crystal
!true
# => false

!false
# => true
```

## Usare le parentesi tonde (`()`)

Quando lavori con i booleani, puoi usare le parentesi per decidere quali Bool valutare per primi.
Il risultato può cambiare a seconda di come vengono usate le parentesi.
In Crystal, quello che è tra parentesi viene valutato per primo.

```crystal
true && false && false || true
# => true

true && false && (false || true)
# => false
```

Dato che quello che è tra parentesi viene valutato per primo, nell'esempio seguente l'operatore _not_ si applicherà all'espressione dentro le parentesi.

```crystal
!true && false
# => false

!(true && false)
# => true
```

~~~~exercism/note
Usa le parentesi solo quando influiscono sul risultato: altrimenti vanno omesse.
~~~~

## Truthy e falsey

In Crystal, i valori «falsey» sono: `false`, `nil` e i puntatori null; **tutto il resto** è «truthy».
Questi valori si possono usare con gli operatori logici menzionati sopra.

```crystal

true && nil
# => false

false && 4
# => false

true || nil
# => true
```

## Convenzioni di denominazione dei metodi con i booleani

In Crystal, è comune dare a un metodo che restituisce un valore truthy o falsey un nome che termina con un punto interrogativo (`?`).
Nella maggior parte dei casi questo metodo restituirà un valore Bool, ma non è detto.
Questo significa che il metodo si può usare dove ci si aspetta un valore truthy o falsey, per esempio come condizione per un'istruzione `if`:

```crystal
def exchange(value)
    if value.nil?
        value = 5
    end
    value
end

exchange(10)
# => 10

exchange(nil)
# => 5
```

I metodi con un punto interrogativo alla fine del nome che non restituiscono un valore Bool spesso restituiscono `nil`. `nil` è _simile a `None` o `null` di altri linguaggi_.
