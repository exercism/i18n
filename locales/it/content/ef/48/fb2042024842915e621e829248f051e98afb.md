## Coppie

Una `Pair` è una struttura dati che contiene esattamente due elementi, accessibili tramite i campi `first` e `second`.

Si possono costruire usando `x => y`:

```julia-repl
julia> p = 3 => true
3 => true

julia> p.first
3

julia> p.second
true
```

Gli elementi di una `Pair` possono essere di tipo diverso:

```julia-repl
julia> typeof(p)
Pair{Int64,Bool}
```

Le `Pair` hanno due usi comuni in Julia: i dizionari e le sostituzioni.

### Sostituzioni

Molti metodi di sostituzione accettano una `Pair` come argomento per rendere chiaro quale elemento viene sostituito.
Questo permette una sintassi come

```julia-repl
julia> replace!([1, 3, 4, 1], 4 => 0)
4-element Array{Int64,1}:
 1
 3
 0
 1
```

dove ogni `4` della collezione viene sostituito con `0`, invece della sintassi meno chiara

```julia
replace!([1, 3, 4, 1], 4, 0) # this method doesn't exist
```
