# Test

Per eseguire i test degli esercizi SQLite, segui questi passaggi:

1. Apri il terminale che preferisci.
2. Vai nella cartella che contiene il file `${slug}_test.sql` corrispondente, dove `${slug}` è il nome dell'esercizio, con i trattini al posto degli spazi e tutto in minuscolo.
3. Esegui il comando seguente: 
```bash
sqlite3 -bail < ${slug}_test.sql
```
  
Questo comando inizializza SQLite con un database vuoto, esegue i test specificati in `${slug}_test.sql` e infine esce.
`-bail` fa in modo che l'esecuzione del codice si interrompa in caso di codice non valido.

I risultati dei test verranno mostrati nella console sotto forma di tabella, con la descrizione di ogni test, il suo stato (ad esempio, «pass») e un messaggio se lo stato è «fail».

## Debug

Puoi usare le istruzioni `SELECT` per il debug.
L'output verrà inoltrato a `user_output.md` e mostrato nell'editor web se i test falliscono.

## Dettagli di esecuzione

Il file di test (`${slug}_test.sql`) è uno script piuttosto complesso.
Ecco una panoramica di quello che fa.

1. Prepara le tabelle leggendo `create_fixture.sql`.
   Crea le tabelle e poi le popola con i valori di `data.csv` per i dati validi e di `error_data.csv` per le voci che dovrebbero fallire.
   Durante i test vengono controllate solo queste tabelle; le modifiche alle altre tabelle vengono ignorate.
2. Esegue il codice della soluzione leggendo il file `${slug}.sql`.
3. Crea le tabelle che contengono i casi di test e i risultati.
4. Popola i risultati dei test in base ai dati nelle tabelle aggiornate dalla soluzione.
5. Mostra i risultati dei test (pass o fail e dettagli opzionali).
Questi file CSV contengono i dati necessari per testare vari scenari.
