# Informazioni

In Common Lisp tutto è un'espressione.
Un'espressione è una singola cosa (chiamata atomo) oppure una lista di cose (delimitate dalle parentesi tonde: `()`).

## Il quoting

Tutte le S-espressioni, come i simboli, possono essere quotate:

```lisp
;; This line is evaluated as code
(gimme-foo)  ; => FOO

;; This line is treated as data
'(gimme-foo) ; => (GIMME-FOO)
```

Questo quoting impedisce la valutazione di una S-espressione, trattandola invece come un dato.
Ecco un'ottima [risposta su Stack Overflow][so-quoting] che discute il quoting con un po' più di dettaglio.
