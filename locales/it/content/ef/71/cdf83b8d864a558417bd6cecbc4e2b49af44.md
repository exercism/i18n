# Debug

Poiché il test runner attuale utilizza [PonyTest](https://stdlib.ponylang.io/pony_test--index/), l'attore Main si trova in test.pony e non dovrebbe essere modificato come parte della soluzione.

Come è prassi nelle applicazioni Pony, non forniamo l'accesso a `Env` se non quando serve. Questo significa che in quasi tutti i casi non puoi fare debug in stile printf usando `env.out.print()`.

Tuttavia, Pony ha un modulo [debug](https://stdlib.ponylang.io/debug--index/) che permette ai programmi compilati con il flag `-d` di avere un accesso speciale a STDOUT e STDERR senza accedere a `Env`.

Se hai bisogno del debug in stile printf, dovresti usare questa funzionalità.

Esempio di debug:

```pony
use "debug"

actor Main
  new create(env: Env) =>
    MySolution.examplefn("First String", 42)

primitive MySolution
  fun examplefn(arg1: String, arg2: USize) =>
    Debug.out("arg1: " + arg1 + ", arg2: " + arg2.string() + " were provided to MySolution.examplefn()")
```
