# Informazioni

In Clojure, associare un valore a un nome si chiama [_var_][vars]. Le var di primo livello (globali) sono simili alle costanti di altri linguaggi, ma vengono ridefinite di frequente per favorire uno sviluppo dinamico.

Le var di primo livello si definiscono con [`def`][def]:

```clojure
(def fingers 10)
```

Puoi eseguire operazioni aritmetiche sui valori con le funzioni di base per le [operazioni sui numeri][operators].

La macro `defn` serve a definire una [funzione][functions] che accetta zero o più argomenti. Una funzione restituisce sempre il risultato dell'ultima espressione nel suo corpo.

```clojure
(defn add [x y]
  (+ x y))
```

Per chiamare una funzione si scrive il suo nome e si passano gli argomenti per ciascuno dei suoi parametri.

```clojure
(def five (add 2 3))
```

In Clojure, funzioni e valori si possono usare solo _dopo_ che sono stati definiti. Usarli prima che siano stati definiti provoca un errore di compilazione.

```clojure
;; Compile error as `add` has not yet been defined
(def seven (add 3 4))

(defn add [x y]
  (+ x y))
```

In Clojure, gli spazi bianchi non hanno altro significato che la formattazione.

Le funzioni e le var di Clojure sono organizzate in namespace. Un namespace raggruppa funzionalità correlate e si definisce con la macro `ns`:

```clojure
(ns calculator)

(def pi 3.14)

(defn add [x y]
  (+ x y))
```

Clojure supporta due tipi di commenti. I commenti su una sola riga sono preceduti da `;`, mentre la forma `comment` serve a impedire la valutazione di tutto ciò che si trova tra `(comment` e `)`.
