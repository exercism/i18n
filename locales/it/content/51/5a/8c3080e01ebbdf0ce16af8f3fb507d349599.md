# Introduzione

Il modulo `Agent` fornisce un'astrazione per generare [processi e il ciclo _receive-send_][exercism-processes]. Da qui in poi, chiameremo i processi avviati con il modulo `Agent` _«processi agente»_. Un _processo agente_ potrebbe essere scelto per rappresentare uno stato condiviso centrale.

Per avviare un _processo agente_, `Agent` fornisce la funzione `start/2`. La funzione fornita, quando si avvia il _processo agente_ con `start`, restituisce lo stato iniziale del processo:

```elixir
# Start an agent process with an initial value of an empty list
{:ok, agent_pid} = Agent.start(fn -> [] end)
```

Proprio come `Map` o `List`, `Agent` fornisce molte funzioni per lavorare con i _processi agente_.

È consuetudine organizzare e incapsulare tutte le funzionalità legate ad `Agent` in un modulo per il dominio che si sta modellando.

[exercism-processes]: https://exercism.org/tracks/elixir/concepts/processes
