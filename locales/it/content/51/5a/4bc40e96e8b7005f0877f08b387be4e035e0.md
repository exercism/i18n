# Istruzioni

In questo esercizio scriverai del codice per stampare i badge con il nome dei dipendenti di una fabbrica.

## 1. Stampa un badge per un dipendente

I dipendenti hanno un ID, un nome e il nome del reparto.
Le etichette dei badge dei dipendenti sono formattate come segue: `"[id] - name - DEPARTMENT"`.
Implementa il metodo `printBadge()` per restituire l'etichetta del badge di un dipendente:

```kotlin
printBadge(734, "Ernest Johnny Payne", "Strategic Communication")
// => "[734] - Ernest Johnny Payne - STRATEGIC COMMUNICATION"
```

~~~~exercism/note
Nota che sull'etichetta il reparto deve essere scritto in maiuscolo.
~~~~

## 2. Stampa un badge per un nuovo dipendente

A causa di una stranezza nel sistema informatico, a volte i nuovi dipendenti non hanno ancora un ID quando iniziano a lavorare in fabbrica.
Dato che i badge sono obbligatori, riceveranno un badge temporaneo senza il prefisso dell'ID.
Modifica il metodo `printBadge()` per supportare i nuovi dipendenti che non hanno ancora un ID:

```kotlin
printBadge(null, "Jane Johnson", "Procurement")
// => "Jane Johnson - PROCUREMENT"
```

## 3. Stampa un badge per il proprietario

Persino il proprietario della fabbrica deve indossare un badge in ogni momento.
Tuttavia, un proprietario non ha un reparto.
In questo caso, l'etichetta deve riportare `"OWNER"` al posto del nome del reparto.
Modifica il metodo `printBadge()` per stampare un'etichetta per il proprietario:

```kotlin
printBadge(254, "Charlotte Hale", null)
// => "[254] - Charlotte Hale - OWNER"
```

~~~~exercism/note
Nota che è possibile che il proprietario sia anche un nuovo dipendente:

```kotlin
printBadge(null, "Charlotte Hale", null)
// => "Charlotte Hale - OWNER"
```
~~~~
