# Introduzione

Un ciclo è un modo per chiamare ripetutamente una o più istruzioni, raggruppate insieme.
Ogni esecuzione di un gruppo di istruzioni si chiama iterazione.

## Ciclo while

Il ciclo `while` esegue un gruppo di istruzioni finché un'espressione booleana all'inizio del ciclo è vera.
Quando l'espressione booleana è falsa, il ciclo smette di essere eseguito e l'esecuzione prosegue con la riga di codice successiva al ciclo.

Se l'espressione booleana è falsa fin dall'inizio, il ciclo `while` non verrà eseguito affatto e l'esecuzione proseguirà con la riga di codice successiva al ciclo.

```c
int main() {
    int i = 0;
    while (i < 5) {
        printf("Number is %i\n", i++);
    }    
    return 0;
}
```

È importante che ci sia una condizione che ponga fine al ciclo; altrimenti si ha un ciclo infinito che blocca ogni avanzamento del codice.
Se nel codice qui sopra si togliesse il `++` da `i`, si avrebbe un ciclo infinito.

## Ciclo do

Nel ciclo `do`, l'espressione booleana viene valutata in fondo al ciclo.
Il ciclo `do` viene eseguito almeno una volta, come nell'esempio seguente

```c
do {
    printf("Enter the Answer to the Ultimate Question of Life: ");
    scanf("%d", &answer);
} while (answer != 42); 
// Note that a semicolon is needed after the Boolean expression.
```

Con un ciclo `while` lo stesso codice sarebbe più prolisso

```c
printf(""Enter the Answer to the Ultimate Question of Life: ");
scanf("%d", &answer);
while (answer != 42) {
    printf(""Enter the Answer to the Ultimate Question of Life: ");
    scanf("%d", &answer);
}
```

## Ciclo for

Spesso un ciclo aggiorna una variabile e termina quando la variabile raggiunge un certo valore.
Il ciclo `for` è un modo per inizializzare, aggiornare e verificare una o più variabili in una sola riga, all'interno delle parentesi.
La prima sezione serve a inizializzare la variabile, la seconda a verificarla e la terza ad aggiornarne il valore.

```c
for (int i = 0; i < 5; i++) {
    printf("Number is %i\n", i);
}
```

È meno prolisso dell'equivalente con il ciclo `while`, e resta comunque leggibile.
