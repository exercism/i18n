# Informazioni

Le sequenze di Factor esistono in due varianti quando devi *modificarle*:

- **Array** (`{ … }`) hanno una lunghezza fissa. Puoi cambiare ciò che si
  trova *in* ciascuna posizione con `set-nth` / `change-nth`, ma non
  puoi allungarli né accorciarli.
- **Vettori** (`V{ … }`) sono a lunghezza variabile. `push` aggiunge in
  fondo, `pop` rimuove e restituisce l'ultimo elemento.

```factor
USING: arrays kernel sequences ;

! Fixed-length: build a counter array of zeros, then bump one slot.
3 0 <array>            ! { 0 0 0 }
dup [ 1 + ] 1 rot change-nth
.                      ! { 0 1 0 }

! Variable-length: build a vector of names by pushing.
V{ } clone
"alice" over push
"bob" over push
dup pop drop           ! removes "bob"
.                      ! V{ "alice" }
```

| word            | effetto                                         |
|-----------------|------------------------------------------------|
| `<array>`       | `( n elt -- array )`: array di `n` copie di `elt` |
| `<vector>`      | `( n -- vector )`: vettore vuoto con capacità `n` |
| `V{ }`          | letterale di vettore vuoto                      |
| `set-nth`       | `( elt n seq -- )`: assegna l'elemento all'indice `n` |
| `change-nth`    | `( i seq quot -- )`: applica `quot` all'elemento in posizione `i` |
| `push`          | `( elt seq -- )`: aggiunge in fondo a un vettore |
| `suffix!`       | `( seq elt -- seq )`: aggiunge sul posto, restituisce il vettore |
| `pop`           | `( seq -- elt )`: rimuove e restituisce l'ultimo |
| `pop*`          | `( seq -- )`: rimuove l'ultimo, scartandolo     |
| `clone`         | `( obj -- copy )`: copia nuova e indipendente   |
| `new-sequence`  | `( n exemplar -- newseq )`: nuova sequenza della stessa classe di `exemplar` |
| `new-resizable` | `( n exemplar -- newseq )`: nuova variante ridimensionabile |

Quando modifichi una sequenza passata dal chiamante, la modifica è
visibile al chiamante: sta tenendo lo stesso oggetto. Se non è quello
che vuoi, usa prima `clone` per ottenere una copia indipendente.
