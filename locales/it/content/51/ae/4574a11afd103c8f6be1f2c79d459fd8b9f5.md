# Introduzione

## Nullabilità

In Java, il letterale `null` viene usato per indicare l'assenza di un valore.

I tipi di dati primitivi in Java hanno tutti un valore predefinito e quindi non possono mai essere `null`. Per convenzione, iniziano con una lettera minuscola, ad esempio `int`.

I tipi di riferimento contengono l'indirizzo di memoria di un oggetto e possono avere valore `null`. In genere iniziano con una lettera maiuscola, ad esempio `String`.

Tentare di assegnare a una variabile primitiva un valore `null` causerà un errore in fase di compilazione, poiché la variabile contiene sempre un valore primitivo del tipo assegnato.

```java
//Throws compile time error stating the required type is int, but null was provided
int number = null;
```

Assegnare a una variabile di riferimento un valore `null` non causerà un errore in fase di compilazione, poiché le variabili di riferimento possono essere `null`.

```java
//No error will occur as the String variable str is nullable
String str = null;
```
