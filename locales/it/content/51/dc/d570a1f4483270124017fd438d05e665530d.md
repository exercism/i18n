# Introduzione

Le charlist si creano usando il sigil `~c`.

```elixir
~c"hello"
```

~~~~exercism/note
Nota che nelle versioni precedenti di Elixir le charlist sono rappresentate come `'hello'`, con le virgolette singole.
~~~~

Anche se sembrano molto simili alle stringhe, i due tipi di dati sono piuttosto diversi tra loro. Una charlist è un array di numeri interi. I numeri interi rappresentano i valori Unicode di un dato carattere, noti anche come punti di codice.

```elixir
[65, 66, 67]
# => ~c"ABC"
```

Puoi anteporre `?` a un carattere per ottenerne il punto di codice.

```elixir
?A
# => 65

[?:, ?)]
# => ~c":)"
```

Dato che le charlist sono array, puoi lavorarci proprio come con qualsiasi altro array: con la ricorsione e il pattern matching.

```elixir
[first_letter | _] = ~c"cat"
first_letter
# => 99
```

Puoi concatenare due array usando `++`.

```elixir
~c"hi" ++ ~c"!"
# => ~c"hi!"
```

Più lungo è il primo array, più lenta è la concatenazione: evita quindi di aggiungere ripetutamente elementi in coda ad array di lunghezza arbitraria.
