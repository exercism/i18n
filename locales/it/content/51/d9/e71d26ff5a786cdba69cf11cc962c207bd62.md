# Istruzioni

Il tuo compito è risolvere un puzzle binario.
Ogni puzzle binario ha esattamente _una_ soluzione, che si trova applicando queste regole:

1. Ogni cella deve contenere uno zero o un uno.
2. Più di due cifre uguali non possono essere adiacenti. Quindi, se due celle adiacenti contengono la stessa cifra, le celle accanto a quelle cifre devono contenere l'altra cifra.
3. Ogni riga ed ogni colonna devono contenere lo stesso numero di zeri ed uni.
4. Ogni riga ed ogni colonna è unica.

Riceverai un puzzle incompleto sotto forma di righe di zeri ed uni, con dei segnaposto (`_`) per i valori sconosciuti.
L'obiettivo è definire le regole del puzzle binario, che permetteranno ai test di ricavare i valori dei segnaposto (non sei tu a farlo).
L'implementazione deve usare il [Constraint Logic Programming over Finite Domains (CLP(FD))](https://www.swi-prolog.org/man/clpfd.html) di Prolog, perfetto per questo tipo di attività.

````exercism/note
Per aiutarti a iniziare, il file stub include già la [libreria `clpfd`](https://www.swi-prolog.org/man/clpfd.html) tramite:

```prolog

```
````
