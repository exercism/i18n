# Introduzione

Gli oggetti possono conservare il proprio stato, cioè le informazioni che descrivono la situazione attuale dell'oggetto, impostando delle _variabili di istanza_, che si creano anteponendo `@` al nome di una variabile.

```ruby
@name = 2
```

Di solito gli oggetti impostano il proprio stato iniziale in un metodo `initialize`, che viene chiamato automaticamente quando si chiama `new` su una classe.

```ruby
class Airplane
  def initialize
    @wings = 2
  end
end
```

Il metodo `initialize` può anche accettare argomenti, così che ogni istanza possa partire con uno stato personalizzato:

```ruby
class Suitcase
  def initialize(locked)
    @locked = locked
  end
end
```

Considera le _variabili di istanza_ come private rispetto a letture e scritture esterne. Per leggere e impostare le variabili di istanza, si dovrebbero usare i _metodi di istanza_:

```ruby
class Suitcase
  #...

  def locked? # Query methods should be named with a trailing `?`
    @locked
  end

  def unlock! # Methods which mutate state should have trailing `!`
    @locked = false
  end
end
```
