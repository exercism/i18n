# Suggerimenti

## In generale

- Puoi usare la sintassi `0b00` per specificare un int in sintassi binaria anziché decimale.

## 1. Codificare l'acido nucleico in un valore binario

- Puoi fare pattern matching sul tipo nucleotide con un'espressione case.

## 2. Decodificare il valore binario nell'acido nucleico

- La sintassi binaria degli int si può usare nei pattern.
- Restituisci `Error(Nil)` se l'int non è un nucleotide valido.

## 3. Codificare un array di DNA

- Puoi usare la funzione `encode_nucleotide` per codificare un singolo nucleotide.

## 4. Decodificare un bit array di DNA

- La sintassi binaria degli int si può usare all'interno di un pattern di bit array.
- Restituisci `Error(Nil)` se il bit array rimanente non è abbastanza lungo da contenere
  un nucleotide.
