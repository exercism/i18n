# Introduzione

Un metodo è una funzione con uno speciale argomento _ricevitore_.
Il ricevitore compare nella propria lista di argomenti tra la parola chiave `func` e il nome del metodo.

```go
func (receiver type) MethodName(parameters) (returnTypes) {
}
```

Puoi definire un metodo solo con un ricevitore il cui tipo è definito nello stesso pacchetto del metodo.

```go
package person 

type Person struct {
	Name string
}

func (p Person) Greetings() string {
	return fmt.Sprintf("Welcome %s!", p.Name)
}
```

Il metodo sullo struct può essere chiamato tramite notazione puntata.

```go
p := Person{Name: "Bronson"}
fmt.Println(p.Greetings())
// Output: Welcome Bronson!
```

Nota come abbiamo chiamato il metodo `Greetings()` sull'istanza `p` di `Person`.
È esattamente come chiamare i metodi in un linguaggio di programmazione orientato agli oggetti.

Ricorda: un metodo è solo una funzione con un argomento ricevitore.
I metodi aiutano a evitare conflitti di denominazione: dato che un metodo è legato a un particolare tipo di ricevitore, puoi avere lo stesso nome di metodo su tipi diversi.

```go
import "math"

type rect struct {
	width, height int
}
func (r rect) area() int {
	return r.width * r.height
}

type circle struct {
	radius int
}
func (c circle) area() float64 {
	return math.Pow(float64(c.radius), 2) * math.Pi
}
```

Esistono due tipi di ricevitori: i ricevitori di valore e i ricevitori di puntatore.

Tutti i metodi che abbiamo visto finora hanno un ricevitore di valore, quindi ricevono una copia del valore passato al metodo: qualsiasi modifica fatta al ricevitore all'interno del metodo non è visibile a chi chiama.

Puoi dichiarare metodi con ricevitori di puntatore per modificare il valore a cui punta il ricevitore.
Questo si fa anteponendo un `*` al nome del tipo.
Per esempio, con il tipo `rect`, un ricevitore di puntatore verrebbe dichiarato come `*rect`.
Tali modifiche sono visibili anche a chi chiama il metodo.

```go
type rect struct {
	width, height int
}
func (r *rect) squareIt() {
	r.height = r.width
}

r := rect{width: 10, height: 20}
fmt.Printf("Width: %d, Height: %d\n", r.width, r.height)
// Output: Width: 10, Height: 20

r.squareIt()
fmt.Printf("Width: %d, Height: %d\n", r.width, r.height)
// Output: Width: 10, Height: 10
```
