# Introduzione

## Operatori di confronto

Gli operatori di confronto in Julia sono simili a quelli di molti altri linguaggi, anche se con qualche opzione in più per gli amanti della matematica.

Per l'uguaglianza, gli operatori sono `==` (uguale) e `!=` o `≠` (diverso).

```julia
txt = "abc"
txt == "abc"  # true
txt != "abc"  # false
txt ≠ "abc"  # false (synonym for !=)
```

Inoltre, abbiamo i vari operatori di maggiore/minore.

```julia
1 < 3  # true
3 > 3  # false
3 <= 3  # true
3 ≤ 3  # true (synonym for <=)
4 >= 3  # true
4 ≥ 3  # true (synonym for >=)
```

Come spesso accade con Julia, un editor appropriato rende facile usare i simboli matematici.
Digita `\ne`, `\le` o `\ge` e poi `TAB` per ottenere `≠`, `≤` o `≥`.

L'esempio precedente usa solo numeri, ma vedremo in altre parti del percorso che vari altri tipi hanno un ordinamento e si possono confrontare con maggiore/minore.

Gli operatori di confronto si possono concatenare, il che permette una sintassi chiara e concisa:

```julia
n = 3
1 ≤ n ≤ 5  # true (n "between" two limits)
```

L'esempio precedente è un sinonimo di `1 ≤ n && n ≤ 5`.

## Ramificazione con `if`

Questa è la forma completa di un'istruzione `if`:

```julia
if conditional1
    statements...
elseif conditional2
    statements...
else
    statements...
end
```

Non servono parentesi tonde (`()`) né parentesi graffe (`{}`), e l'indentazione serve «solo» a migliorare la leggibilità _(ma la leggibilità è molto importante!)_.

Sia `elseif` sia `else` sono opzionali, e ci possono essere più blocchi `elseif`.
Tuttavia `end` è obbligatorio.

È possibile annidare le istruzioni `if`, anche se per aiutare la leggibilità potresti voler usare con criterio parentesi, rientri e commenti.

La forma più breve di un'istruzione `if` sarebbe qualcosa del genere:

```julia
if n < 0
    n = 0
end
```

Come promemoria: solo le espressioni che restituiscono `true` o `false` si possono usare come condizioni.
Julia evita deliberatamente qualsiasi concetto di «truthiness», quindi i valori zero, le stringhe vuote e gli array vuoti _non_ sono equivalenti a `false`. 

## Operatore ternario

Una situazione semplice e comune è scegliere uno di due valori in base a una condizione.

Julia, come molti linguaggi, ha un operatore ternario per rendere tutto questo più conciso.

La sintassi è `conditional ? value_if_true : value_if_false`.

Quindi l'esempio precedente si potrebbe riscrivere:

```julia
n = n < 0 ? 0 : n
```

Le parentesi non sono richieste dal compilatore, ma possono migliorare la leggibilità.
