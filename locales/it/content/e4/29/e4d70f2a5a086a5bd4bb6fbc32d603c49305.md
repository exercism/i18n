# Introduzione

## Confronto

In JavaScript, i numeri si possono confrontare con i seguenti operatori relazionali e di uguaglianza.

| Confronto              | Operatore |
| ---------------------- | --------- |
| Maggiore di            | `a > b`   |
| Maggiore o uguale a    | `a >= b`  |
| Minore di              | `a < b`   |
| Minore o uguale a      | `a <= b`  |
| (Strettamente) uguale a | `a === b` |
| Non (strettamente) uguale a | `a !== b` |

Il risultato del confronto è sempre un valore booleano: `true` o `false`.

```javascript
1 < 3;
// => true

2 !== 2;
// => false

1 === 1.0;
// => true
// All numbers are floating-points, so this is different syntax for
// the exact same value.
```

In JavaScript, gli operatori di confronto visti sopra si possono usare anche per confrontare le stringhe.
In questo caso viene applicato un ordine alfabetico (lessicografico).
Puoi trovare un elenco dell'ordine esatto di tutti i caratteri [qui][utf-16-list].

```javascript
'Apple' > 'Pear';
// => false

'a' < 'above';
// => true

'a' === 'A';
// => false
```

## Condizionali

Un modo comune per eseguire del codice in modo condizionale in JavaScript è l'istruzione `if`.
È composta dalla parola chiave `if`, da una condizione racchiusa tra parentesi tonde e da un blocco di codice racchiuso tra parentesi graffe.
Il blocco di codice viene eseguito solo se la condizione è vera (`true`).

```javascript
if (condition) {
  // code that is executed if "condition" is true
}
```

Si può usare da sola oppure insieme alla parola chiave `else`.

```javascript
if (condition) {
  // code that is executed if "condition" is true
} else {
  // code that is executed otherwise
}
```

Per annidare un'altra condizione nell'istruzione `else`, puoi usare `else if`.

```javascript
if (condition1) {
  // code that is executed if "condition1" is true
} else if (condition2) {
  // code that is executed if "condition2" is true
  // but "condition1" was false
} else {
  // code that is executed otherwise
}
```
