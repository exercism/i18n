# Informazioni

I tipi personalizzati sono il modo in cui Gleam definisce nuovi tipi di dati. Possono avere più _varianti_, ognuna con il proprio nome.

```gleam
pub type Season {
  Spring
  Summer
  Autumn
  Winter
}
```

Ogni caso di un tipo personalizzato può contenere facoltativamente dei dati, e casi diversi possono avere tipi di dati diversi. Quando una variante contiene dei dati, viene chiamata _record_.

```gleam
pub type Number {
  SomeInt(Int)
  SomeFloat(Float)
  Invalid
}
```

Per creare un valore per un caso specifico, puoi riferirti al suo nome se non contiene dati aggiuntivi (`Spring`), oppure chiamarlo come una funzione se ne contiene (`SomeInt(2)`).

```gleam
let spring = Spring
let integer_two = SomeInt(2)
```

I tipi personalizzati, come tutto in Gleam, hanno l'_uguaglianza strutturale_: due valori della stessa variante e con gli stessi dati sono equivalenti.

```gleam
Spring == Spring // -> True
Spring == Autumn // -> False
SomeInt(2) == SomeInt(2) // -> True
SomeInt(2) == SomeFloat(2.0) // -> False
```

Si può fare pattern matching sulle varianti di un tipo personalizzato usando le espressioni case.

```gleam
import gleam/int
import gleam/float

pub fn describe(flexible_number: Number) -> String {
  case flexible_number {
    SomeFloat(f) -> "Float: " <> float.to_string(f)
    SomeInt(i) -> "Int: " <> int.to_string(i)
    Invalid -> "Neither a float nor an int"
  }
}
```
