## Unicode e i cluster di grafemi

Questo esercizio include test con stringhe Unicode che contengono cluster di grafemi.
Le funzioni integrate di Perl per l'elaborazione delle stringhe non bastano a gestire queste stringhe.
Ecco un paio di risorse che possono aiutarti:

* [Tratta le stringhe Unicode come cluster di grafemi][foy]
* [Estrai per grafema invece che per code point (regex)][christiansen]

[foy]: https://www.effectiveperlprogramming.com/2011/06/treat-unicode-strings-as-grapheme-clusters/
[christiansen]: https://www.perl.com/pub/2012/05/perlunicookbook-extract-by-grapheme-instead-of-codepoint-regex.html/
