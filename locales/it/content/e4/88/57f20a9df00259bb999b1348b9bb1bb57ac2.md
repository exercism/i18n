# Introduzione

In Python, una [tupla][tuple] è una collezione _immutabile_ di elementi in _sequenza_.
Come la maggior parte delle collezioni, le `tuples` possono contenere qualsiasi tipo di dato (o più tipi), comprese altre `tuples`.
Le tuple supportano tutte le [operazioni comuni sulle sequenze][common sequence operations], ma **non** supportano le [operazioni sulle sequenze mutabili][mutable sequence operations].

Gli elementi di una tupla si possono iterare usando il costrutto `for item in <tuple>`.
Se servono sia l'indice che il valore di un elemento, si può usare `for index, item in enumerate(<tuple>)`.
Come per qualsiasi sequenza, si può accedere agli elementi delle `tuples` tramite la _notazione con parentesi_, usando un numero `0-based index` da sinistra oppure un numero `-1-based index` da destra.
Le tuple si possono anche copiare interamente o in parte usando lo slicing (_`<tuple>[<start>:<stop>:<step>]`_).


## Costruzione di una tupla

Le tuple si possono creare in diversi modi: usando il costruttore della classe `tuple(<iterable>)` oppure la dichiarazione del letterale `tuple`.

### Usare il costruttore `tuple()` vuoto o con un _iterabile_:

```python
>>> no_elements = tuple()
()

# The constructor *requires* an iterable, so single elements must be passed in a list or another tuple.
>>> one_element = tuple([16])
(16,)
```

Le stringhe sono iterabili, quindi passare una singola `str` come argomento al costruttore `tuple()` può dare risultati sorprendenti:

```python
# String elements (characters) are iterated through and added to the tuple
>>> multiple_elements_string = tuple("Timbuktu")
('T', 'i', 'm', 'b', 'u', 'k', 't', 'u')
```

Quando si passa un singolo iterabile, i suoi elementi vengono aggiunti uno alla volta:

```python
>>> multiple_elements_list = tuple(["Parrot", "Bird", 334782])
("Parrot", "Bird", 334782)

>>> multiple_elements_set = tuple({2, 3, 5, 7, 11})
(2,3,5,7,11)
```

#### Dichiarare una tupla come _letterale_:

Dato che il costruttore `tuple(<iterable>)` accetta come argomenti solo _iterabili_ (o niente), è molto più semplice creare una tupla con un solo elemento usando il metodo del letterale.

```python
>>> no_elements = ()
()

>>> one_element = ("Guava",)
("Guava",)
```

Strutture di dati annidate possono essere incluse come elementi di una `tuple`, comprese altre `tuples`:

```python
>>> nested_data_structures = ({"fish": "gold", "monkey": "brown", "parrot" : "grey"}, ("fish", "mammal", "bird"))
({"fish": "gold", "monkey": "brown", "parrot" : "grey"}, ("fish", "mammal", "bird"))

>>> nested_data_structures_1 = (["fish", "gold", "monkey", "brown", "parrot", "grey"], ("fish", "mammal", "bird"))
(["fish", "gold", "monkey", "brown", "parrot", "grey"], ("fish", "mammal", "bird"))
```

## Concatenazione di tuple

Le tuple si possono concatenare con l'operatore più `+`, che spacchetta ogni `tuple` creando una nuova `tuple` combinata.

```python
>>> new_via_concatenate = ("George", 5) + ("cat", "Tabby")
("George", 5, "cat", "Tabby")

#likewise, using the multiplication operator * is the equivalent of using + n times
>>> first_group = ("cat", "dog", "elephant")

>>> multiplied_group = first_group * 3
('cat', 'dog', 'elephant', 'cat', 'dog', 'elephant', 'cat', 'dog', 'elephant')
```

## Accedere agli elementi di una tupla

Si può accedere agli elementi di una `tuple` tramite la _notazione con parentesi_, usando un numero `0-based index` da sinistra oppure un numero `-1-based index` da destra.

```python
student_info = ("Alyssa", "grade 3", "female", 8 )

#gender is at index 2 or index -2
>>> student_gender = student_info[2]
'female'

>>> student_gender = student_info[-2]
'female'

#name is at index 0 or index -4
>>> student_name = student_info[0]
Alyssa

>>> student_name = student_info[-4]
Alyssa
```

## Iterare sugli elementi di una tupla

Gli elementi dentro una `tuple` si possono _iterare_ in un ciclo usando la sintassi `for item in <tuple>`.
Se servono sia gli indici che i valori, si può usare `for index, item in enumerate(<tuple>)`.

```python
>>> student_info = ("Alyssa", "grade 3", "female", 8 )
>>> for item in student_info:
...   print(item)

...
Alyssa
grade 3
female
8

>>> for index, item in enumerate(student_info):
...  print("Index is: " + str(index) + ", value is: " + str(item) +".")

...
Index is: 0, value is: Alyssa.
Index is: 1, value is: grade 3.
Index is: 2, value is: female.
Index is: 3, value is: 8.
```

## Verificare l'appartenenza a una tupla

L'operatore `in` si può usare per verificare l'appartenenza a una `tuple`.

```python
>>> multiple_elements_list = tuple(["Parrot", "Bird", 334782])
("Parrot", "Bird", 334782)

>>> "Parrot" in multiple_elements_list
True
```
