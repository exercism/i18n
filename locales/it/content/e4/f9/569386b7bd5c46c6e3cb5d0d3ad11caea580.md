# Informazioni

`case` è il costrutto di selezione multipla di Factor basato sull'uguaglianza. È lo strumento giusto quando la scelta dipende dall'uguaglianza di un *singolo* valore con una tra diverse alternative, non quando ogni ramo richiede un test diverso (per quello, usa `cond`).

```factor
USING: combinators ;

SYMBOLS: yes no maybe ;

: invert ( ?/maybe -- ?'/maybe )
    {
        { yes [ no ] }
        { no  [ yes ] }
        [ ]            ! default: leave value alone
    } case ;
```

Alcune cose da tenere bene a mente:

- L'uguaglianza è `=`. Qualunque valore per cui `=` funzioni può fare da chiave: numeri, stringhe, caratteri, simboli e persino tuple.
- *I rami che corrispondono* vedono lo stack *senza* il valore di input. *I rami di default* invece lo vedono ancora in cima.
- Un `case` senza un ramo di default e senza alcuna clausola corrispondente genera un errore.

`case` viene compilato in una tabella di salto dove possibile, quindi non è solo zucchero sintattico per una catena di `if`: è anche veloce.
