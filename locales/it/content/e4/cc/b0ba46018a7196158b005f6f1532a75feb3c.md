# Istruzioni

In questo esercizio scriverai del codice per aiutare un'azienda di insegne a creare messaggi personalizzati per le sue insegne.

## 1. Crea un'insegna per un'occasione

Implementa la funzione `buildSign(occasion, name)` che accetta una stringa come parametro `occasion` e una stringa contenente il nome di qualcuno come parametro `name`.
I due parametri verranno inseriti in una stringa interpolata per produrre il messaggio sull'insegna.

```javascript
buildSign('Birthday', 'Rob');
// => "Happy Birthday Rob!"
```

## 2. Crea un'insegna di compleanno

Implementa la funzione `buildBirthdaySign(age)` che accetta un'età e, in base all'età, determinerà parte del messaggio sull'insegna.
Se l'età è 50 o più, l'insegna si riferirà all'utente come _mature_, altrimenti come _young_.
L'output esatto previsto è mostrato di seguito:

```javascript
buildBirthdaySign(50);
// => "Happy Birthday! What a mature fellow you are."

buildBirthdaySign(45);
// => "Happy Birthday! What a young fellow you are."
```

## 3. Crea un'insegna di laurea

Implementa la funzione `graduationFor(name, year)` che accetta un nome come parametro stringa e un anno come parametro numerico e usa l'interpolazione di stringhe per creare una frase per un'insegna che usa un carattere di nuova riga per separare le due righe del messaggio.

```javascript
graduationFor('Hannah', 2022);
/* => "Congratulations Hannah!
       Class of 2022"
*/
```

## 4. Calcola il costo di un'insegna

Implementa la funzione `costOf(sign, currency)` che prende una stringa che contiene il contenuto dell'insegna e una stringa che rappresenta la valuta.
L'insegna ha un prezzo base di 20 nella valuta indicata. Inoltre, ogni lettera costa 2. (Gli spazi bianchi sono inclusi nel calcolo.)
La frase restituita include il costo per creare l'insegna, scritto con due cifre dopo il separatore decimale, seguito dalla stringa della valuta.

```javascript
costOf('Happy Birthday Rob!', 'dollars');
// => "Your sign costs 58.00 dollars."
```
