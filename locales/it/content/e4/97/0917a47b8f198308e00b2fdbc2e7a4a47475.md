# Approfondimento

Haxe ha due tipi numerici: i numeri interi e i numeri in virgola mobile:

- `Int`: rappresenta un numero intero.
- `Float`: rappresenta un numero in virgola mobile a doppia precisione a 64 bit.

```haxe
var integer:Int = 10;
var floating:Float = 5.4;
```

Anche se ogni `Int` può essere usato dove ci si aspetta un `Float` (cioè `Int` **è assegnabile a** o **si unifica con** `Float`), non vale il contrario: assegnare un `Float` a un `Int` può causare una perdita di precisione e quindi non è consentito in modo implicito.

## Confronto

Due numeri sono uguali se hanno lo stesso valore.

```haxe
1 == 1; // true

1.2 == 1.2; // true

1 == 1.0; // true

0.2 + 0.1 == 0.3 // false
```

Per l'ultimo caso, vedi [0.30000000000000004.com][0.30000000000000004.com] per una breve spiegazione.
