# Risorse

## Moduli

Perl viene fornito con un insieme di moduli core che puoi trovare elencati su [perldoc](https://perldoc.perl.org/modules). Di norma potrai usare subito uno qualsiasi di questi moduli. (Alcune distribuzioni potrebbero richiedere di installare i moduli core separatamente).

[Awesome Perl](https://github.com/hachiojipm/awesome-perl) è una lista curata di moduli utili e rimanda anche a una selezione di altre liste di consigli.

Per Perl sono disponibili diversi programmi di installazione dei moduli, che ti permettono di installare un'ampia varietà di moduli disponibili su [CPAN](https://metacpan.org/).

### App::cpm
Un programma di installazione di moduli molto veloce e immediato.
Su [CPAN](https://metacpan.org/pod/App::cpm::Tutorial) è disponibile un tutorial.

Lo avrai già installato se hai seguito le istruzioni per `local::lib` nella [documentazione di installazione](https://exercism.org/tracks/perl5/installation).

Esegui semplicemente `cpm install` per installare i moduli richiesti da un `cpanfile`, e usa `--with-recommends` o `--with-suggested` per installare rispettivamente i moduli raccomandati o suggeriti.

Esegui `cpm install Module::Name` per installare localmente un modulo specifico, oppure `cpm install -g Module::Name` per installarlo a livello globale.

### App::cpanminus
Il programma di installazione di moduli più conosciuto e usato in assoluto.
Le istruzioni per l'installazione si trovano su [CPAN](https://metacpan.org/pod/App::cpanminus).

Esegui `cpanm -L local --installdeps .` per installare i moduli richiesti
da un `cpanfile`.
Esegui `cpanm -L local Module::Name` per installare localmente un modulo
specifico, oppure `cpanm Module::Name` per installarlo a livello globale.

## Stile del codice e linting

Se cerchi buoni consigli generali sulla scrittura di codice Perl,
[Perl Best Practices][PBP] di Damian Conway è un buon riferimento.

Per rendere più leggibile il tuo codice, puoi usare il modulo
[Perl::Tidy][PerlTidy].

Puoi quindi usare il programma di utilità `perltidy` fornito
per riformattare il tuo codice.

    # modify file in-place and save old version as some_script.pl.bak
    $ perltidy -b some_script.pl

`perltidy` ha *molte* opzioni di configurazione per accontentare ogni gusto. Sono
documentate [qui][perltidyDocs].

C'è anche [tidyview], un'interfaccia visuale che ti permette di
ritoccare le diverse opzioni e vedere subito il risultato.

Se vuoi far rispettare determinate pratiche di scrittura, c'è anche
[Perl::Critic][perlcritic]. Include le regole descritte nel
libro *Perl Best Practices* menzionato prima, ma esistono molti
plugin e può essere personalizzato per adattarsi a qualsiasi regola di scrittura
interna.

Per usarlo:

    $ perlcritic some_script.pl

Lo strumento ha davvero moltissime opzioni di configurazione: consulta la sua
[documentazione][perlcriticdocs] per tutti i dettagli.
