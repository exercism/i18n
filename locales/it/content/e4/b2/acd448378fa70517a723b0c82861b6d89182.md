# Introduzione

Kotlin è un linguaggio di programmazione **tipizzato staticamente** sviluppato da JetBrains. Questo significa che il tipo delle variabili viene definito in fase di compilazione.

## Variabili

Come in altri linguaggi di programmazione tipizzati staticamente, il tipo di ogni variabile va definito in fase di compilazione. Puoi evitare le dichiarazioni di tipo esplicite quando il compilatore riesce a dedurlo dal contesto.

Kotlin ha variabili immutabili (`val`) e mutabili (`var`). Il valore di una variabile immutabile non può essere cambiato dopo che le è stato assegnato il valore iniziale. Il più delle volte userai questo tipo di variabile.

```kotlin
val robotName = "HAL-9000"
userId = "T-1000"  // This will not compile
```

Il valore di una variabile mutabile può essere cambiato una o più volte:

```kotlin
var index = 12
print(index)  // 12

index = 100
print(index)  // 100
```

In Kotlin i punti e virgola sono facoltativi, tranne in alcuni casi speciali che vedremo più avanti.

## Funzioni

In Kotlin le funzioni si definiscono con la parola chiave `fun` e sono _cittadini di prima classe_ (non ha nulla a che fare con la programmazione orientata agli oggetti). Questo significa che puoi dichiararle direttamente nei file, le cosiddette `top-level functions` (ad esempio in Java puoi definire metodi solo dentro le classi, non nei file):

```kotlin
// This is content of the Hello.kt file

fun hello() {}
```

Le funzioni possono ricevere argomenti. Ogni argomento ha un nome e un tipo. A differenza delle variabili, il tipo degli argomenti non può essere dedotto. Le funzioni possono avere zero o più argomenti:

```kotlin
fun hello() {}

fun hello(name: String) {}

fun hello(name: String, age: Int) {}
```

Le funzioni in Kotlin possono restituire un valore oppure no:

```kotlin
fun min(a: Int, b: Int): Int

fun countBonuses(user: User): Bonuses

fun run() {}
```

Per restituire un valore da una funzione si usa la parola chiave `return`:

```kotlin
fun getName(): String {
    return "Alice"
}
```

Le funzioni possono avere parametri con valori predefiniti. Questi valori verranno usati se vengono omessi nel punto in cui si chiama la funzione:

```kotlin
fun ping(host: String = "localhost") {
    println("PING --> $host")
}

ping("exercism.io")  // PING --> exercism.io
ping()               // PING --> localhost
```

## Commenti

Usa `//` per definire un commento su una sola riga:

```kotlin
foo() // Everything after `//` will be ignored by compiler

// I will be ignored too
```

oppure `/*` e `*/` per definire commenti su più righe:

```kotlin
/*
   This this an example
   for a multiline comment
*/
```
