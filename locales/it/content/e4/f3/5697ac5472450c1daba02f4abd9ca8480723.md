# Introduzione

Quando ti serve una serie di `n` valori in cui ognuno dipende dalla
sua posizione, `<iota>` e `map` di Factor collaborano per fare il
lavoro senza scrivere un contatore del ciclo.

## `<iota>` e `map`

`<iota>` (in [`sequences`][sequences]) prende un numero intero non
negativo `n` e restituisce una sequenza *virtuale* dei numeri interi
`0, 1, …, n-1`. `map` poi la percorre, applicando la quotation a
ogni elemento:

```factor
USING: math sequences ;

5 <iota> [ 2 * ] map .   ! => { 0 2 4 6 8 }
```

La quotation riceve un solo numero intero, l'indice, e lascia sullo
stack il valore per quella posizione.

## Iterare e ripetere per conteggio

Quando ti servono solo gli *effetti collaterali* di visitare ogni
indice, non una nuova sequenza, `each-integer` (in [`math`][math])
esegue una quotation su `0, 1, …, n-1`:

```
each-integer ( n quot: ( i -- ) -- )
```

`replicate` (in [`sequences`][sequences]) chiama una quotation `n`
volte e raccoglie i risultati, ignorando l'indice. È comodo per
costruire `n` valori indipendenti:

```
replicate ( n quot: ( -- elt ) -- seq )
```

```factor
USING: sequences ;

3 [ { 0 0 } ] replicate .   ! => { { 0 0 } { 0 0 } { 0 0 } }
```

## Intervalli limitati

Quando l'intervallo degli indici non parte da `0`, o lo vuoi
inclusivo a entrambi gli estremi, il vocabolario [`ranges`][ranges]
fornisce dei letterali con notazione a parentesi. Le parentesi quadre
includono l'estremo; le parentesi tonde lo escludono.

```
[a..b]    ! a, a+1, …, b      (inclusive)
[a..b)    ! a, a+1, …, b-1    (half-open at the top)
```

```factor
USING: math ranges sequences ;

3 7 [a..b] [ 2 * ] map .   ! => { 6 8 10 12 14 }
3 7 [a..b) [ 2 * ] map .   ! => { 6 8 10 12 }
```

Alcune abbreviazioni comuni a un argomento:

```
[1..b]    ! 1, 2, …, b        (same as 1 b [a..b])
[1..b)    ! 1, 2, …, b-1      (same as 1 b [a..b))
[0..b)    ! 0, 1, …, b-1      (same as 0 b [a..b), and same as `b <iota>`)
```

```factor
6 [1..b] [ sq ] map .      ! => { 1 4 9 16 25 36 }
6 [1..b) [ sq ] map .      ! => { 1 4 9 16 25 }
4 [0..b) [ 1 + ] map .     ! => { 1 2 3 4 }
```

`<iota>` è la forma più comune; `[a..b]` e affini sono lo strumento
giusto quando l'intervallo parte da un punto diverso da `0` o ha
bisogno di un estremo superiore inclusivo.

## Estremi inferiori aperti e intervalli possibilmente vuoti

Le parentesi quadre *includono* un estremo; le parentesi tonde lo
*escludono*. Lo stesso trucco a sinistra dà `(a..b]` e `(a..b)`:

```
(a..b]    ! a+1, …, b              (lower open, upper inclusive)
(a..b)    ! a+1, …, b-1            (both open)
```

`0 n (a..b]` dà `{ 1 … n }` per `n > 0` e `{ }` per `n = 0`, la
forma naturale quando si itera su «ogni numero intero positivo fino
a `n` incluso».

## Intervalli decrescenti

Tutte e quattro le forme a parentesi, `[a..b]`, `[a..b)`, `(a..b]`,
`(a..b)`, contano *all'indietro* quando `a > b`, non verso un
risultato vuoto:

```factor
USING: ranges sequences ;

5 1 [a..b] >array .   ! => { 5 4 3 2 1 }
1 0 [a..b] >array .   ! => { 1 0 }   (not empty!)
```

## Costruire una stringa in base alla posizione

`map` produce qualunque forma restituisca la sua quotation. Se la
quotation lascia sullo stack un codice di carattere, `>string` (in
[`strings`][strings]) trasforma il risultato in una stringa:

```factor
USING: math sequences strings ;

4 <iota> [ 2 * CHAR: A + ] map >string .   ! => "ACEG"
```

`CHAR: A` viene interpretato come il numero intero `65`. Qui la
quotation raddoppia l'indice e aggiunge quella base, facendo cadere
il risultato su una lettera maiuscola ogni due. Qualunque aritmetica
applichi all'indice decide quale carattere finisce in quella
posizione.

## Scegliere in base alla posizione

Quando il carattere dipende da una *condizione* sull'indice, fai la
scelta dentro la quotation:

```factor
USING: kernel math sequences strings ;

5 <iota> [ 3 < [ CHAR: a ] [ CHAR: b ] if ] map >string .
! => "aaabb"
```

Le prime tre posizioni valutano `i 3 <` come `t`, quindi ottengono
`a`; le altre ottengono `b`. La stessa forma, `[ <test> [ <yes> ]
[ <no> ] if ]`, copre i test di parità con `even?` / `odd?` (in
[`math`][math]) e i test «ogni k-esima posizione» con `mod` e
`zero?`.
