# Introduzione

Gli array sono le sequenze a lunghezza fissa di Factor: puoi modificarne gli elementi, ma non la lunghezza. Sai già come scrivere un array letterale, `{ … }`, e come estrarne una porzione e aggregarlo. Questo esercizio tratterà la piccola cassetta degli attrezzi che serve quando costruisci array a partire da valori sullo stack e poi ne cerchi o riordini il contenuto.

## Costruire dallo stack

`1array`, `2array`, `3array` e `4array` (in [`arrays`][arrays]) prelevano 1, 2, 3 o 4 valori dalla cima dello stack e li raggruppano:

```
1array ( a       -- { a }       )
2array ( a b     -- { a b }     )
3array ( a b c   -- { a b c }   )
4array ( a b c d -- { a b c d } )
```

```factor
42 1array .                ! => { 42 }
3 4 2array .               ! => { 3 4 }
"x" "y" "z" 3array .       ! => { "x" "y" "z" }
1 2 3 4 4array .           ! => { 1 2 3 4 }
```

## Unire

`concat` (in [`sequences`][sequences]) prende una sequenza i cui elementi sono a loro volta sequenze e la appiattisce di un livello. `join` fa la stessa cosa inserendo un separatore tra ogni coppia:

```
concat ( seqs     -- seq )
join   ( seqs sep -- seq )
```

```factor
{ { 1 2 } { 3 4 } { 5 } } concat .
! => { 1 2 3 4 5 }

{ "alpha" "beta" "gamma" } ", " join .
! => "alpha, beta, gamma"
```

## Invertire

`reverse` restituisce una nuova sequenza con gli elementi in ordine inverso:

```
reverse ( seq -- newseq )
```

```factor
{ 1 2 3 4 } reverse .   ! => { 4 3 2 1 }
```

## È un array?

`array?` (in [`arrays`][arrays]) è il predicato di tipo. È vero per qualsiasi valore costruito con `<array>`, `1array`/`2array`/..., o con un array letterale `{ … }`, e falso per tutto il resto (compresi vettori, stringhe e altre sequenze):

```
array? ( obj -- ? )
```

```factor
{ 1 2 3 } array? .         ! => t
"hello" array? .           ! => f
V{ 1 2 3 } array? .        ! => f
```

## Cercare gli elementi

`index` restituisce la posizione del primo elemento uguale al valore di input, oppure `f` se non è presente. `member?` restituisce solo un valore booleano. Entrambi prendono **prima l'elemento** e **poi la sequenza**. `members` (in [`sets`][sets]) restituisce gli elementi *unici* di una sequenza, cioè l'operazione di deduplicazione, e `all-unique?` (anch'esso in `sets`) verifica se la sequenza è già priva di duplicati:

```
index       ( elt seq -- i/f )
member?     ( elt seq -- ? )
members     ( seq     -- uniques )
all-unique? ( seq     -- ? )
```

```factor
"b" { "a" "b" "c" } index .       ! => 1
"z" { "a" "b" "c" } index .       ! => f
"b" { "a" "b" "c" } member? .     ! => t
"z" { "a" "b" "c" } member? .     ! => f
{ 1 2 3 2 1 } members .           ! => { 1 2 3 }
{ 1 2 3 } all-unique? .           ! => t
{ 1 2 1 } all-unique? .           ! => f
```
