# Introduzione

Supponi di volere tutti i numeri interi non negativi fino a 1000.
Sarebbe assurdo doverli digitare uno per uno in un array.

Per questo abbiamo il tipo `range`:

```julia-repl
julia> 0:1000
0:1000

julia> typeof(0:1000)
UnitRange{Int64}
```

Gli intervalli sono molto comuni: non solo per risparmiarti di digitare, ma anche come tipi restituiti dalle funzioni.

Nota che gli intervalli _non_ sono vettori.
Sono solo un insieme di istruzioni per generare una sequenza (una valutazione «lazy», o un «iteratore»).

Se ti serve un intervallo sotto forma di vettore, usa la funzione `collect()` per convertirlo:

```julia-repl
julia> collect(0:5)
6-element Vector{Int64}:
 0
 1
 2
 3
 4
 5
```

Si può specificare il passo, in questo caso 0.3:

```julia-repl
julia>  collect(1.0:0.3:2.0)
4-element Vector{Float64}:
 1.0
 1.3
 1.6
 1.9
```

Quindi la sintassi è `start:stepsize:stop`.
Entrambi i limiti sono _inclusi_, come si vede nell'esempio con i numeri interi.
Se il passo non divide esattamente `stop - start`, l'ultimo elemento eviterà di superare `stop`.

## Intervalli di lettere

Negli intervalli si possono usare anche sequenze non numeriche.
L'esempio più semplice sono le lettere ASCII:

```julia-repl
julia> 'a':'d'
'a':1:'d'

julia> typeof('a':'d')
StepRange{Char, Int64}

julia> collect('a':'d')
4-element Vector{Char}:
 'a': ASCII/Unicode U+0061 (category Ll: Letter, lowercase)
 'b': ASCII/Unicode U+0062 (category Ll: Letter, lowercase)
 'c': ASCII/Unicode U+0063 (category Ll: Letter, lowercase)
 'd': ASCII/Unicode U+0064 (category Ll: Letter, lowercase)
```

Il tipo `Char` sarà trattato più in dettaglio in un altro concetto.
Per ora, trattali semplicemente come singoli caratteri tra virgolette singole.

## Funzioni e operatori per gli intervalli

Controlla i limiti di un intervallo con `first()` e `last()`.

```julia
 r = 1:10  # => 1:10
 first(r)  # => 1
 last(r)   # => 10
```

## Ancora sull'indicizzazione dei vettori

Gli intervalli di numeri interi e i vettori si possono usare nell'indicizzazione dei vettori:

```julia
nums = collect(10.0:50.0)
nums[3:2:7]  # gives [12.0, 14.0, 16.0]
nums[ [3, 5, 7] ] # also gives [12.0, 14.0, 16.0]
```
