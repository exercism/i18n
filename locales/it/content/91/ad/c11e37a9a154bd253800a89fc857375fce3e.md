# Informazioni

Un `SYMBOL:` non *contiene* un valore: è solo un nome. Il valore vive in un namespace e il nome è la chiave per raggiungerlo.

```factor
USING: namespaces ;

SYMBOL: history

V{ } clone history set-global
"first event" history get-global push
"second event" history get-global push
history get-global .
! => V{ "first event" "second event" }
```

Due scope:

- **globale**: si scrive e si legge con `set-global`, `get-global`, `change-global`. I valori persistono per tutta la durata del processo.
- **dinamico**: si scrive e si legge con `set`, `get`, `change`. I binding vivono per la durata di una forma `with-variable`, il che permette al codice esterno di «iniettare» un valore visto dal codice interno senza cambiare tutte le firme nel mezzo.

```factor
"verbose" log-level [
    log-level get .   ! => "verbose"
] with-variable
```

`SYMBOL:` e `SYMBOLS:` dichiarano i simboli al momento del caricamento del vocabolario, rendendoli riferimenti condivisibili tra i file.
