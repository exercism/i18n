# Istruzioni

Il tuo compito è analizzare le coordinate GPS.
Ogni coordinata è formattata usando la variante con emisferi espliciti del [formato gradi decimali](https://en.wikipedia.org/wiki/Decimal_degrees):

```text
<LATITUDE_DEGREES> <LATITUDE_HEMISPHERE>, <LONGITUDE_DEGREES> <LONGITUDE_HEMISPHERE>
```

Questi sono i valori ammessi per ogni singolo componente:

- `<LATITUDE_DEGREES>`: un numero in virgola mobile nell'intervallo 0..90 (estremi inclusi)
- `<LATITUDE_HEMISPHERE>`: `N` oppure `S`
- `<LONGITUDE_DEGREES>`: un numero in virgola mobile nell'intervallo 0..180 (estremi inclusi)
- `<LONGITUDE_HEMISPHERE>`: `E` oppure `W`

Ad esempio, `"48.8584 N, 2.2945 E"` viene analizzata in:

- `<LATITUDE_DEGREES>`: 48.8584
- `<LATITUDE_HEMISPHERE>`: N
- `<LONGITUDE_DEGREES>`: 2.2945
- `<LONGITUDE_HEMISPHERE>`: E

Ci sono 11 attività, nelle quali analizzerai le coordinate GPS in modo incrementale.
Userai il supporto [Definite Clause Grammar](https://en.wikipedia.org/wiki/Definite_clause_grammar) (DCG) di Prolog, progettato per analizzare testo strutturato.

````exercism/note
Per iniziare, il file stub include già la [libreria `dcg/basics`](https://www.swi-prolog.org/pldoc/doc/_SWI_/library/dcg/basics.pl) tramite:

```prolog
:- use_module(library(dcg/basics)).
```
````

## 1. Analizzare una virgola

Implementa la regola `comma` per analizzare una singola virgola (`","`):

```prolog
?- string_codes(",", Codes), phrase(comma, Codes).
```

## 2. Analizzare uno spazio

Implementa la regola `space` per analizzare un singolo spazio (`" "`):

```prolog
?- string_codes(" ", Codes), phrase(space, Codes).
```

## 3. Gestire tutti gli spazi bianchi (tranne le nuove righe)

Modifica la regola `space` per analizzare _tutti_ gli spazi bianchi, tranne le nuove righe:

```prolog
?- string_codes("\t", Codes), phrase(space, Codes).

?- string_codes("\n", Codes), phrase(space, Codes).
false.
```

## 4. Analizzare l'emisfero della latitudine

L'emisfero della latitudine può essere `"N"` oppure `"S"`, e va analizzato nell'atomo `north` o `south`.
Implementa la regola `latitude_hemisphere` per analizzare l'emisfero della latitudine:

```prolog
?- string_codes("N", Codes), phrase(latitude_hemisphere(Hemisphere), Codes).
Hemisphere = north.
```

## 5. Analizzare l'emisfero della longitudine

L'emisfero della longitudine può essere `"E"` oppure `"W"`, e va analizzato nell'atomo `east` o `west`.
Implementa la regola `longitude_hemisphere` per analizzare l'emisfero della longitudine:

```prolog
?- string_codes("E", Codes), phrase(longitude_hemisphere(Hemisphere), Codes).
Hemisphere = east.
```

## 6. Analizzare i gradi

I gradi di una longitudine o di una latitudine sono definiti come un numero in virgola mobile.
Implementa la regola `degrees` per analizzare i numeri in virgola mobile:

```prolog
?- string_codes("748.012", Codes), phrase(degrees(Degrees), Codes).
Degrees = 748.012.
```

## 7. Analizzare i gradi della latitudine

I gradi della latitudine non sono semplicemente numeri in virgola mobile, ma numeri in virgola mobile nell'intervallo 0..90 (estremi inclusi).
Implementa la regola `latitude_degrees` per analizzare i gradi della latitudine usando l'intervallo qui sopra:

```prolog
?- string_codes("48.745", Codes), phrase(latitude_degrees(Degrees), Codes).
Degrees = 48.745.

?- string_codes("117.844", Codes), phrase(latitude_degrees(Degrees), Codes).
false.
```

## 8. Analizzare i gradi della longitudine

I gradi della longitudine non sono semplicemente numeri in virgola mobile, ma numeri in virgola mobile nell'intervallo 0..180 (estremi inclusi).
Implementa la regola `longitude_degrees` per analizzare i gradi della longitudine usando l'intervallo qui sopra:

```prolog
?- string_codes("178.773", Codes), phrase(longitude_degrees(Degrees), Codes).
Degrees = 178.773.

?- string_codes("-22.523", Codes), phrase(longitude_degrees(Degrees), Codes).
false.
```

## 9. Analizzare la latitudine

Le latitudini hanno due parti: i loro gradi e l'emisfero, separati da uno spazio.
Implementa la regola `latitude` per analizzare una latitudine:

```prolog
?- string_codes("56.101 N", Codes), phrase(latitude(Degrees, Hemisphere), Codes).
Degrees = 56.101,
Hemisphere = north.
```

## 10. Analizzare la longitudine

Le latitudini hanno due parti: i loro gradi e l'emisfero, separati da uno spazio.
Implementa la regola `latitude` per analizzare una latitudine:

```prolog
?- string_codes("143.889 W", Codes), phrase(longitude(Degrees, Hemisphere), Codes).
Degrees = 143.889,
Hemisphere = west.
```

## 11. Analizzare una coordinata

Le coordinate hanno due parti: la loro latitudine e longitudine, separate da una virgola seguita da uno spazio.
Implementa la regola `coordinate` per analizzare sia la latitudine (gradi ed emisfero):

```prolog
?- string_codes("48.8584 N, 2.2945 E", Codes), phrase(coordinate(Latitude, LatitudeHemisphere, Longitude, LongitudeHemisphere), Codes).
Latitude = 48.8584,
LatitudeHemisphere = north,
Longitude = 2.2945,
LongitudeHemisphere = east.
```
