# Informazioni

I numeri in virgola mobile sono numeri frazionari o interi che includono un punto decimale (come `3.14`, `-1.7`, `99.99`, `2048.0`)

Il tipo float in Common Lisp è suddiviso in diversi sottotipi, ognuno con le proprie caratteristiche e la propria precisione: short-float, single-float, double-float e long-float.

Il sottotipo short-float di solito occupa la minor quantità di memoria e offre la precisione più bassa dei quattro. È adatto alle situazioni in cui l'uso della memoria è una preoccupazione, ma una precisione minore è accettabile.

Il sottotipo single-float offre un compromesso tra uso della memoria e precisione. Si usa comunemente per calcoli in virgola mobile di carattere generale.

Il sottotipo double-float offre una precisione maggiore rispetto a single-float ed è adatto alle applicazioni che richiedono calcoli più accurati, come i calcoli scientifici e le simulazioni numeriche.

Il sottotipo long-float offre la precisione più alta dei quattro, ma può richiedere più memoria rispetto agli altri. Di solito si usa per applicazioni specialistiche che richiedono calcoli estremamente accurati.

Questi sottotipi permettono a chi programma in Common Lisp di scegliere il livello di precisione e l'uso di memoria più adatti alle esigenze della propria applicazione.

In generale, se lavori solo con numeri interi, è meglio preferire gli interi: non subiscono la stessa perdita di precisione dei numeri in virgola mobile quando si fanno molti calcoli.

## Riferimento

```lisp
;; Rounding to the Nearest Whole Number
(round 3.14)  ; => 3
(round -3.14) ; => -3
(round 2.72)  ; => 3
(round -2.72) ; => -3

;; Rounding Towards Zero
(truncate 3.14)  ; => 3
(truncate -3.14) ; => -3
(truncate 2.72)  ; => 2
(truncate -2.72) ; => -2

;; Rounding Towards Negative Infinity
(floor 3.14)  ; => 3
(floor -3.14) ; => -4
(floor 2.72)  ; => 2
(floor -2.72) ; => -3

;; Rounding Towards Positive Infinity
(ceiling 3.14)  ; => 4
(ceiling -3.14) ; => -3
(ceiling 2.72)  ; => 3
(ceiling -2.72) ; => -2
```
