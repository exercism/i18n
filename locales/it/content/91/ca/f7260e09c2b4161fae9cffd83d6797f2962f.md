# Debug

Quando un test fallisce, viene mostrato un messaggio che descrive cosa è andato storto e per quale input.
Puoi anche sfruttare il fatto che verrà mostrato anche l'[output della console][fmt-println].
Puoi scrivere sulla console usando:

```go
import "fmt"
fmt.Println("Debug message")
```

[fmt-println]: https://pkg.go.dev/fmt#Println

Nota: quando esegui il debug con l'editor del browser, usando ad esempio `fmt.Print` non viene aggiunta una nuova riga dopo l'output, il che può provocare un bug in `go test --json` e dare come risultato un output dei test confuso.
