# Introduzione

## Operazioni bit a bit

Le operazioni bit a bit permettono di manipolare le singole cifre all'interno dei numeri binari.

Elm fornisce diversi operatori bit a bit nel suo [modulo Bitwise](https://package.elm-lang.org/packages/elm/core/latest/Bitwise)

### Operazioni di base

Modificare i singoli bit di un numero si chiama _mascheramento_.
Una _maschera_ è un numero in cui bit specifici sono stati impostati in un certo modo per manipolare un altro numero usando operatori bit a bit come `and`, `or` e `xor`.

#### and

`and` combina due numeri mantenendo solo i bit che sono `1` in entrambi.
È utile per verificare se un singolo bit è impostato.
Per esempio, per controllare se il quarto bit di un numero è impostato a `1`, esegui l'operazione `and` con una maschera di `01000` (`8` in decimale) e verifica se il risultato è diverso da zero:

```elm
Bitwise.and 13 8 --> 8
--  13 = 01101
--   8 = 01000
-- and = 01000 = 8
```

#### or

`or` combina due numeri impostando ogni bit a `1` se è `1` in uno o in entrambi i numeri.
È utile per impostare un bit specifico a `1`.
Per esempio, per impostare il secondo bit in `10101`, esegui l'operazione `or` con la maschera `00010`:

```elm
Bitwise.or 21 2 --> 23
-- 21 = 10101
--  2 = 00010
-- or = 10111 = 23
```

#### OR esclusivo (xor)

`xor` combina due numeri impostando ogni bit a `1` se è `1` in un numero ma `0` nell'altro.
È utile per invertire un bit nel suo valore opposto:

```elm
Bitwise.xor 20 5 --> 17
--  20 = 10100
--   5 = 00101
-- xor = 10001 = 17
```

#### Complemento

`complement` inverte ogni bit di un numero (`0` diventa `1`, `1` diventa `0`).

Nota che questo farà diventare negativi i numeri positivi, ed i numeri negativi positivi.
Questo perché i numeri negativi, in binario, sono rappresentati con `1` nella posizione più a sinistra.

```elm
Bitwise.complement 21 --> -22
--         21 = 00000000000000000000000000010101
-- complement = 11111111111111111111111111101010 = -22
```

#### Scorrimento dei bit

Gli operatori seguenti spostano i bit a sinistra o a destra di un numero specificato di posizioni, moltiplicando o dividendo di fatto per potenze di 2.

`shiftLeftBy` sposta i bit a sinistra, riempiendo con `0` dal lato destro.
Per esempio, per spostare `21` a sinistra di 3 posizioni:

```elm
Bitwise.shiftLeftBy 3 21 --> 168
--  21 = 10101
-- shiftLeftBy 3 = 10101000 = 168
```

Questo equivale a dire `21 * 2^3 = 21 * 2 * 2 * 2 = 168`

`shiftRightBy`: sposta i bit a destra:

```elm
Bitwise.shiftRightBy 2 21 --> 5
--  21 = 10101
-- shiftRightBy 2 = 00101 = 5
```

Spostare a destra di 2 posizioni equivale alla divisione intera per 4.

Nota che questa funzione duplica il valore che si trova nel bit più a sinistra.
Quindi i numeri negativi resteranno negativi:

```elm
Bitwise.shiftRightBy 3 -21 --> -3
--  -21 = 111...101011
-- shiftRightBy 3 = 111...11101 = -3
```

Se vuoi spostare a destra riempiendo con zeri, usa `shiftRightZfBy`:

```elm
Bitwise.shiftRightZfBy 3 -21 --> 536870909
--  -21 = 111...101011
-- shiftRightZfBy 3 = 00111...11101 = 536870909
```
