# Istruzioni

Elyse, aspirante maga, continua il suo allenamento.
Riceverà diversi mazzi di carte con cui dovrà eseguire i suoi trucchi.
Per semplificare un po' le cose, usa solo le carte da 1 a 10.
Di ogni carta ne ha una sola: nei suoi mazzi non ci sono duplicati.

In questo esercizio userai i metodi della libreria Base di Julia per analizzare il contenuto di un array.

## 1. Determina se una carta è presente

Elyse vuole determinare se una carta è presente nel mazzo, in altre parole se il mazzo contiene un numero specifico.

```julia-repl
julia> card = 3;

julia> has_card([2, 3, 4, 5], card)
true
```

## 2. Trova la posizione di una carta

Elyse vuole conoscere la posizione (l'indice) di una carta nel mazzo.
Se la carta non è nel mazzo, restituisci `nothing`.

```julia-repl
julia> card = 2;

julia> find_card([9, 7, 3, 2], card)
4
```

## 3. Determina se ogni carta è pari

Elyse vuole sapere se ogni carta è pari, in altre parole se ogni numero nel mazzo è pari.

```julia-repl
julia> all_cards_even([2, 4, 6, 7])
false
```

## 4. Controlla se il mazzo contiene una carta di valore dispari

Elyse vuole sapere se c'è un numero dispari nel mazzo.

```julia-repl
julia> any_odd_cards([3, 2, 6, 4, 8])
true
```

## 5. Determina la posizione della prima carta pari

Elyse vuole conoscere la posizione della prima carta pari.
Se nel mazzo non ci sono carte pari, restituisci `nothing`.

```julia-repl
julia> first_even_card_idx([5, 2, 3, 1])
2
```

## 6. Ottieni la prima carta dispari del mazzo

Elyse vuole conoscere il valore della prima carta dispari.
Se nel mazzo non ci sono carte dispari, restituisci `nothing`.

```julia-repl
julia> first_odd_card([4, 2, 8, 7, 9])
7
```
