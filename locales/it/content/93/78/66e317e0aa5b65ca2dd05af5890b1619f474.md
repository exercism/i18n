# Modulo

I confronti con l'operatore modulo sono perfettamente validi in Crystal, ma un modo più leggibile per confrontare il resto di una divisione è il metodo [`divisible_by?`][divisible_by].
Ad esempio:

```crystal
# Rather than:
number %% 2 == 0

# Consider:
number.divisible_by?(2)
```

[divisible_by]: https://crystal-lang.org/api/latest/Int.html#divisible_by%%3F%%28num%%29%%3ABool-instance-method
