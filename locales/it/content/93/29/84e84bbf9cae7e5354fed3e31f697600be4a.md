# Introduzione

## Liste

Una `list` in F# è una collezione immutabile di zero o più valori. I valori in una lista devono avere tutti lo stesso tipo. Poiché le liste sono immutabili, una volta costruita una lista, il suo valore non può mai cambiare. Qualsiasi funzione o operatore che sembri modificare una lista (ad esempio aggiungendo un elemento) in realtà restituisce una nuova lista.

Le liste si possono definire come segue:

```fsharp
let empty = []
let singleValue = [5]
let threeValues = ["a"; "b"; "c"]
```

Il modo più comune per aggiungere un elemento a una lista è tramite l'operatore `::` (cons):

```fsharp
let twoToFour = [2; 3; 4]
let oneToFour = 1 :: twoToFour
// => [1; 2; 3; 4]
```

Una lista in F# ha una _testa_ (il primo elemento) e una _coda_ (tutto ciò che viene dopo il primo elemento). La coda di una lista è essa stessa una lista.

Le liste si possono manipolare con funzioni e operatori definiti nel modulo `List`, oppure manualmente con il pattern matching, usando i pattern _list_ e _cons_:

```fsharp
let describe list =
    match list with
    | [] -> "Empty list"
    | head::tail -> sprintf "Non-empty list with head: %d" head

describe []        // => "Empty list"
describe [1]       // => "Non-empty with head: 1"
describe [5; 7; 9] // => "Non-empty with head: 5"
```

Puoi anche _scartare_ un valore durante il pattern matching; quando _non_ ti interessa un valore in un caso specifico (cioè non hai intenzione di _usare_ un valore), puoi usare un underscore (`'_'`) per indicarlo:

```fsharp
let describe list =
    match list with
    | [] -> "Empty list"
    | [x] -> "List with one item"
    | [_; y] -> "List with two items (first item ignored)"
    | _ -> "List with many items (all items ignored)"

describe []        // => "Empty list"
describe [1]       // => "List with one item"
describe [5; 7]     // => "List with two items (first item ignored)"
describe [5; 7; 9] // => "List with many items (all items ignored)"
```

Il singolo `'_'` dovrebbe sempre venire _per ultimo_ nel pattern matching: ogni valore che _non_ corrisponde a nessuno degli altri casi sarà gestito da questo caso.
