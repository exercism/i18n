# Informazioni

Perl è un linguaggio di programmazione creato da Larry Wall, rilasciato per la prima volta nel 1987.

## Pacchetti e moduli

Un pacchetto è una raccolta di codice, spesso contenuta in un file di modulo con lo stesso nome e l'estensione `.pm`.
Il modulo può poi essere importato in un altro file, in genere con la parola chiave `use`.

```perl
# Foo.pm
package Foo;

# Accessible with `Foo::bar` when module is used
# or just `bar` if the subroutine is exported.
sub bar () {
    return 1;
}
```

## Variabili

Esistono variabili scalari (`$foo`), array (`@bar`) e hash (`%baz`).
Per semplificare, qui verranno usate solo variabili scalari.
Un valore scalare può essere uno dei seguenti: una stringa, un numero, un booleano o un [riferimento][perlreftut] a qualcosa.
L'assenza di un valore è `undef`.


Le parole chiave `my` e `our` dichiarano una variabile nello scope lessicale, ad esempio `my $foo;`.
Con `our`, la variabile avrà anche un alias verso una variabile di pacchetto con lo stesso nome.
Esistono altri modi per dichiarare le variabili, che non tratteremo qui.

Puoi assegnare un valore a una variabile con l'operatore `=`, ad esempio `$foo = 1;`, operazione che può essere svolta nello stesso momento in cui dichiari la variabile, ad esempio `my $foo = 1;`.

```perl
package Foo;

sub baz () {
    our $bar = 1; # Sets both $bar and $Foo::bar as 1.
    return $bar;
}

$Foo::bar = 2; # $bar is not accessible here, but $Foo::bar is.

# Both of these will print 1.
say baz;
say $Foo::bar;
```

## Subroutine

La parola chiave `sub` dichiara una [subroutine][perlsub].
La parola chiave `return` esce dalla subroutine, restituendo i valori specificati, oppure una lista vuota se non viene fornito nulla.
Senza un `return` specificato, il valore restituito sarà determinato dal contesto (scalare, lista o void) della subroutine usata e dalla sua istruzione finale.

```perl
sub hello () {
    return 'Hello, World!';
}
```

Le versioni recenti di Perl permettono di specificare parametri formali in una [firma][perlsubsig].
La lista di parametri può contenere variabili scalari, array o hash.
Una lista di parametri vuota significa che la subroutine accetta zero argomenti.
Le versioni più vecchie di Perl richiedevano di recuperare gli argomenti dalla variabile speciale `@_`, cosa che non tratteremo qui.

## Commenti

I commenti in Perl iniziano con un `#` che non fa parte di una stringa e finiscono alla fine della riga.
