# Introduzione

Le struct sono un'estensione costruita sopra le [mappe][exercism-maps], che forniscono controlli in fase di compilazione e valori predefiniti. Una struct prende il nome dal modulo in cui è definita. Per definire una struct usa il costrutto `defstruct`. Di solito il costrutto segue immediatamente la definizione del modulo. `defstruct` accetta o una lista di atomi (per valori predefiniti `nil`) o una lista di keyword (per valori predefiniti specificati). I campi senza valore predefinito devono precedere i campi con un valore predefinito.

```elixir
defmodule Plane do
  defstruct [:engine, wings: 2]
end

plane = %Plane{}
# => %Plane{engine: nil, wings: 2}
```

## Accedere ai campi e aggiornarli

Dato che le struct sono costruite sulle mappe, possiamo usare la maggior parte delle funzioni per le mappe per ottenere e manipolare i valori. Il _Access Behaviour_ **non** è implementato per le struct. Si consiglia invece di usare l'_operatore di accesso statico_ `.` per accedere ai campi di una struct.

- ottenere/recuperare i valori dei campi:

  ```elixir
  plane = %Plane{}
  plane.engine
  # => nil
  Map.fetch(plane, :wings)
  # => {:ok, 2}
  ```

- aggiornare i valori dei campi

  ```elixir
  plane = %Plane{}
  %{plane | wings: 4}
  # => %Plane{engine: nil, wings: 4}
  ```

## Pattern matching

Le struct si possono usare nel pattern matching con o senza il nome della struct.

```elixir
plane = %Plane{}
%Plane{wings: wings} = plane
%{wings: wings} = plane
```

Includendo il nome della struct nel pattern, puoi assicurarti che sia il lato sinistro sia quello destro siano struct dello stesso tipo.

```elixir
defmodule Helicopter do
  defstruct [:engine, rotors: 1]
end

%Plane{} = %Helicopter{}
# => (MatchError) no match of right hand side value: %Helicopter{engine: nil, rotors: 1}
```

## Forzare l'inizializzazione dei valori dei campi

Possiamo usare l'attributo di modulo `@enforce_keys` con una lista delle chiavi dei campi per assicurarci che i valori siano inizializzati quando viene creata la struct. Se una chiave non è elencata, il suo valore sarà `nil`, come nell'esempio qui sopra. Se una chiave obbligatoria non viene inizializzata, viene sollevato un errore.

```elixir
defmodule User do
  @enforce_keys [:username]
  defstruct [:username]
end

%User{}
# => (ArgumentError) the following keys must also be given when building struct User: [:username]
```
