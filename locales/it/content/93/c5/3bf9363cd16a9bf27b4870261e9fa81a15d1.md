# Type Juggling

Il type juggling è noto anche come coercizione di tipo.
Si parla di type juggling quando due valori di tipo diverso vengono forzati allo stesso tipo per eseguire un'operazione.

```php
$baskets = 5 // int
$apples_per_basket = "3" // string
$baskets * $apples_per_basket
# => 15 // int
```

Quando l'espressione viene valutata, il valore della stringa viene convertito implicitamente in un `int` per soddisfare l'aspettativa dell'operatore `*`.
La decisione su quale tipo forzare spetta a PHP, in base alle regole dell'operazione, e queste regole variano molto.

La coercizione di tipo avviene anche quando si chiamano funzioni e metodi:

```php
strlen(12321);
# => 5
```

## Cast dei tipi

Invece di affidarci alla coercizione implicita, possiamo forzare esplicitamente un valore a essere valutato come un certo tipo usando il cast di tipo in stile `C`:

```php
$apples_per_basket = "3" // string
$my_number = (int) $apples_per_basket // cast string to int
# => 3 // int
```

Questo convertirà il valore al tipo specificato tra le parentesi tonde (`(...)`).
Tutti i tipi primitivi possono essere usati come tipo di destinazione: `bool`, `int`, `float`, `string`, `array`, `object`.

## Solo una conversione temporanea

Il type juggling o il cast **non cambiano** il tipo del valore memorizzato in una variabile.
Viene convertito solo l'input dell'operazione.

```php
$apples_per_basket = "3" // string
5 * $apples_per_basket
# $apples_per_basket => "3" // string

$my_number = (int) $apples_per_basket // cast string to int
# $apples_per_basket => "3" // string
```

## Perdita di informazioni

Quando un valore viene forzato a un altro tipo, il processo può comportare una perdita di informazioni:

```php
$exact_distance = 15.5
$rough_distance = (int) $exact_distance
// => 15

$is_distant = (bool) $exact_distance
// => true

$erroneous_distance = (float) $is_distant
// => 1.0
```

Affidarsi al cast, in modo esplicito o implicito, può causare errori in un sistema più ampio.

## Cast esplicito a `array` e `object`

I valori possono essere sottoposti a cast anche verso i tipi `array` e `object`.
Se un valore che non è un array né un oggetto viene convertito in un `array`, diventa un singolo elemento presente nell'array:

```php
$day_of_the_week = 'Monday';
(array) $day_of_the_week
// => array(1) {
//      [0]=>
//        string(6) "Monday"
//    }
```

Quando viene convertito in un `object`, il valore viene assegnato a una proprietà pubblica chiamata `scalar`:

```php
$car = "Honda"
(object) $car
// => object(stdClass)#1 (1) {
//      ["scalar"]=>
//        string(5) "Honda"
//    }
```

> `stdClass` è il tipo di una classe anonima integrata in PHP.
