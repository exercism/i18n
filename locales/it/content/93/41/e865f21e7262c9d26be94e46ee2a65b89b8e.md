# Test

Gli esercizi di Odin all'interno della directory del progetto Exercism si possono eseguire spostandoti nella directory dell'esercizio e lanciando `odin test .`.

```sh
cd "$(exercism workspace)"/odin/leap
odin test .
```

## Abilitare i controlli del linguaggio

Mentre esegui i test, Odin può fare il «vet» del tuo codice: può cercare cose come import e variabili non utilizzati.

Esegui i test con

```sh
odin test . -vet
```

Per ancora più controlli, aggiungi l'opzione `-strict-style`.

## Sviluppo guidato dai test (TDD)

`odin test` esegue ogni procedura che ha l'attributo `@(test)`.

Nella suite di test, noterai che ogni procedura di test ha questo attributo.
Questo significa che quando lanci i test, ogni procedura di test verrà eseguita.

In generale, Exercism promuove lo [Sviluppo guidato dai test][tdd], in cui:

- inizialmente, tutti i test tranne il primo sono configurati per essere saltati;
- scrivi giusto il codice necessario per superare il primo test;
- poi abiliti il test successivo e scrivi giusto il codice necessario per farlo passare;
- ripeti finché il codice non supera tutti i test.

Noi (i maintainer) non abbiamo trovato un modo programmatico ed elegante per eseguire un sottoinsieme dei test.
Il file di test è diventato semplicemente troppo ingestibile.
Per sviluppare seguendo il TDD, puoi modificare il file di test e trasformare in commento i test che non sei ancora pronto a eseguire, per poi togliere il commento uno alla volta mentre scrivi la soluzione.
