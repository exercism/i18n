# Suggerimenti

## 1. Stampa un badge per un dipendente

- Puoi usare una [stringa interpolata][string-template] per creare stringhe di descrizione.
- Esiste un [metodo integrato per convertire una stringa in maiuscolo][to-upper-case].

## 2. Stampa un badge per un nuovo dipendente

- Dovresti controllare se l'ID è `null` prima di usarlo.
- Puoi usare un [operatore di uguaglianza][kotlin-operators] per controllare se un valore è `null`.

## 3. Stampa un badge per il proprietario

- Puoi usare l'[operatore Elvis][elvis-operator] per usare un valore alternativo quando una variabile è `null`.
