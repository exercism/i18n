# Classi immutabili

Un `SCOREBOARD` è una cosa che cambia. Due nomi per un unico tabellone vedono lo
stesso punteggio, perché c'è un solo tabellone ed entrambi i nomi puntano ad esso.

Un rilevamento non è così. `350 degrees` non diventa qualcos'altro; semplicemente
*è*. I numeri si comportano così, e anche le stringhe, e lo stesso possono fare
le classi che scrivi tu.

## immutable

```sather
immutable class BEARING is

   readonly attr degrees : INT;

end; -- class BEARING
```

Due parole cambiano tutto. Un oggetto di una classe immutabile è un **valore**,
non una cosa a cui si punta:

- viene copiato quando viene assegnato o passato, quindi nessun altro può
  modificare la tua copia;
- non può mai essere void;
- e non si possono assegnare i suoi attributi.

## Cambiarne uno creandone un altro

Poiché `degrees := 90` non è consentito, `attr` offre qualcos'altro: una routine
che riceve il nuovo valore e restituisce **un nuovo oggetto** con quel valore
modificato.

```sather
   b ::= b.degrees(90);      -- not b.degrees := 90
```

L'originale resta intatto. L'idioma è tutto qui, ed è così che si scrive
`create`:

```sather
   create(d : INT) : SAME is
      b : SAME;                     -- starts with everything at nought
      return b.degrees(d);
   end;
```

Qui non c'è nessun `new`. Un oggetto immutabile esiste sempre, quindi `b : SAME`
è già un oggetto, con ogni attributo al suo valore vuoto.

Una routine che «cambia» un rilevamento, quindi, ne restituisce uno nuovo:

```sather
   turned(by : INT) : SAME is
      return #BEARING(degrees + by);
   end;
```

## Confronto

I valori si confrontano in base a ciò che contengono, non a quale oggetto siano;
ma devi indicare come farlo. Scrivi `is_eq`, e `=` lo userà:

```sather
   is_eq(other : SAME) : BOOL is
      return degrees = other.degrees;
   end;
```

Senza di esso, `=` su due rilevamenti non verrà compilato.

## Quale scegliere

Usa una classe immutabile quando la cosa non ha un'identità e nulla in essa può
cambiare in modo sensato: un rilevamento, un punto, una data, una lunghezza. Usa
una classe normale quando la cosa è un oggetto particolare a cui accadono delle
cose: un tabellone, un'imbracatura, un file.

Il criterio è se «lo stesso» significa «uguale» oppure «proprio lo stesso».
