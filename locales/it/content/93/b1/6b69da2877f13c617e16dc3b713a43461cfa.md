# Introduzione

## Funzioni callback

Le funzioni callback sono funzioni passate come argomenti. Questo schema di programmazione crea una sequenza di chiamate di funzione, sia nella programmazione sincrona sia in quella asincrona. Scrivere una funzione callback non è diverso dallo scrivere una funzione; tuttavia, la funzione callback deve corrispondere alla firma definita dalla funzione chiamante.

```javascript
const sideLength = 5;

// Caller function takes a callback function
function applySideLength(callback) {
  return callback(sideLength);
}

// Callback must expect the possible argument from the calling function
function areaOfSquare(side) {
  return side * side;
}

applySideLength(areaOfSquare); // => 25
```

Puoi anche scrivere le callback come espressione di funzione:

```javascript
applySideLength(function squarePerimeterLength(side) {
  return side * 4;
});
```
