# Introduzione

Il valore `null` viene usato per indicare l'_assenza_ di un valore. Un tipo **nullable** è un tipo che permette a una variabile di assumere il valore `null`. Per rendere nullable un tipo qualsiasi, lo racchiudiamo con `Null<T>`:

```haxe
var a:Int = null; // Error
var b:Null<Int> = null; // Allowed
```

Per controllare se un valore è attualmente `null`, basta usare un'espressione `if`:

```haxe
var a:Null<Int> = 10;

if (a != null) {
  trace("a is not null"); // a is not null
}
```
