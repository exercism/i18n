# Introduzione alle asserzioni di tipo

Le interfacce in Go possono introdurre ambiguità sul tipo sottostante.
Un'asserzione di tipo permette di estrarre il valore concreto sottostante da un valore di interfaccia usando questa sintassi: `interfaceVariable.(concreteType)`.

Per esempio:

```go
var input interface{} = 12
number := input.(int)
```

NOTA: questo provocherà un panic se la variabile di interfaccia non contiene un valore del tipo concreto.

Possiamo verificare se un valore di interfaccia contiene un tipo concreto specifico sfruttando entrambi i valori restituiti dall'asserzione di tipo: il valore sottostante ed un valore booleano che indica se l'asserzione è riuscita.
Per esempio:

```go
str, ok := input.(string) // no panic if input is not a string
```

Se `input` contiene una `string`, allora `str` sarà il valore sottostante ed `ok` sarà true.
Se `input` non contiene una `string`, allora `str` sarà il valore zero del tipo `string` (cioè `""`, la stringa vuota) e `ok` sarà false.
In nessun caso si verifica un panic.

## Type switch

Un **type switch** può eseguire diverse asserzioni di tipo in serie.
Ha la stessa sintassi di un'asserzione di tipo (`interfaceVariable.(concreteType)`), ma `concreteType` viene sostituito con la parola chiave `type`.
Ecco un esempio:

```go
var i interface{} = 12 // try: 12.3, true, int64(12), []int{}, map[string]int{}

switch v := i.(type) {
case int:
    fmt.Printf("the integer %d\n", v)
case string:
    fmt.Printf("the string %q\n", v)
default:
    fmt.Printf("type, %T, not handled explicitly: %#v\n", v, v)
}
```
