# Istruzioni

Scriverai un po' di codice per gestire un array di linguaggi di programmazione da imparare.

## 1. Aggiungi un linguaggio a un array

Modifica la subroutine `add-language`, che prende come argomenti un array di linguaggi ed il nome di un linguaggio, in modo che restituisca un array con il nuovo linguaggio aggiunto in fondo.

## 2. Rimuovi un linguaggio da un array

Modifica la subroutine `remove-language` in modo che rimuova l'ultimo linguaggio da un array dato.

## 3. Estrai il primo linguaggio da un array

Modifica la subroutine `first-language` in modo che restituisca il primo linguaggio di un array dato.

## 4. Estrai l'ultimo linguaggio da un array

Modifica la subroutine `last-language` in modo che restituisca l'ultimo linguaggio di un array dato.

## 5. Estrai una porzione di linguaggi da un array

Modifica la subroutine `get-languages`, che prende come argomenti un array di linguaggi ed un array di numeri che indicano gli elementi desiderati, in modo che restituisca una porzione dell'array dato.

## 6. Verifica se un linguaggio esiste in un array

Modifica la subroutine `has-language`, che prende come argomenti un array di linguaggi ed il nome di un linguaggio, in modo che restituisca `True` o `False` a indicare se il linguaggio esiste nell'array dato.
