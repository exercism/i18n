# Appendice alle istruzioni

## Definire un tipo induttivo

Questo esercizio si aspetta che il valore restituito sia un [tipo induttivo][inductive] `Classification` che devi definire.

Questo tipo deve avere un'istanza [BEq][beq], cioè deve ammettere un test di uguaglianza booleana, e un'istanza [Repr][repr], cioè i valori del tipo devono poter essere formattati per la visualizzazione.

Puoi fare riferimento a [questa pagina][instance] sulle dichiarazioni di istanza.
Lean può [generare automaticamente le istanze][deriving] per molte classi.

## Sottotipi

L'argomento della funzione `classify` è un [sottotipo][subtype] chiamato `Positive`:

```
def Positive := { x : Nat // x > 0 }
```

I sottotipi rappresentano gli elementi di un tipo particolare che soddisfano un predicato.
`Positive` rappresenta gli elementi di `Nat` che sono maggiori di `0`.

Ogni elemento di un sottotipo può essere pensato come una coppia formata da un valore del tipo sottostante e da una dimostrazione, nel senso matematico del termine, che questo valore soddisfa il predicato corrispondente.

I sottotipi impongono invarianti a livello di tipo, assicurando che i valori malformati non possano essere costruiti.
