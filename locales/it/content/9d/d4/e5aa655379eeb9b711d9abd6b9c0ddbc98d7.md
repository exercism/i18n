# Istruzioni

In questo esercizio, implementerai un modo per tenere traccia dei punteggi migliori del gioco più popolare della tua sala giochi locale.

## 1. Aggiungi i giocatori al tabellone dei punteggi migliori

Per aggiungere un giocatore al tabellone dei punteggi migliori, definisci due metodi `add_player!` che accettano i seguenti argomenti:

- Il primo argomento è il dizionario dei punteggi.
- Il secondo argomento è il nome di un giocatore, come stringa.
- Il terzo argomento è il punteggio, come numero intero.
  Questo argomento è facoltativo: se non viene indicato alcun valore, il punteggio deve essere impostato a 0.

```julia-repl
julia> scores = Dict{String, Int}()
Dict{String, Int64}()

julia> add_player!(scores, "Liselot", 486373)
Dict{String, Int64} with 1 entry:
  "Liselot" => 486373

julia> add_player!(scores, "Éimhín")
Dict{String, Int64} with 2 entries:
  "Liselot" => 486373
  "Éimhín"  => 0
```

## 2. Rimuovi i giocatori dal tabellone dei punteggi

Per rimuovere un giocatore dal tabellone dei punteggi migliori, definisci `remove_player!`, che accetta 2 argomenti:

- Il primo argomento è il dizionario dei punteggi.
- Il secondo argomento è il nome del giocatore, come stringa.

```julia-repl
julia> scores = Dict(
           "Liselot" => 486373,
           "Éimhín"  => 0,
       )
Dict{String, Int64} with 2 entries:
  "Liselot" => 486373
  "Éimhín"  => 0

julia> remove_player!(scores, "Liselot")
Dict{String, Int64} with 1 entry:
  "Éimhín" => 0
```

## 3. Aggiorna il punteggio di un giocatore

Per aggiornare il punteggio di un giocatore sostituendo quello precedente, definisci `update_score!`, che accetta 3 argomenti:

- Il primo argomento è il dizionario dei punteggi.
- Il secondo argomento è il nome del giocatore, come stringa, di cui vuoi aggiornare il punteggio.
- Il terzo argomento è il punteggio a cui vuoi impostare il punteggio migliore memorizzato.

```julia-repl
julia> scores = Dict(
           "Liselot" => 486373,
           "Éimhín"  => 0,
       )
Dict{String, Int64} with 2 entries:
  "Liselot" => 486373
  "Éimhín"  => 0

julia> update_score!(scores, "Éimhín", 89479) # TODO: Should this return the dict?
89479

julia> scores

  "Liselot" => 486373
  "Éimhín"  => 89479
```

## 4. Azzera il punteggio di un giocatore

Per azzerare il punteggio di un giocatore, definisci `reset_score!`, che accetta 2 argomenti:

- Il primo argomento è il dizionario dei punteggi.
- Il secondo argomento è il nome del giocatore, come stringa, di cui vuoi azzerare il punteggio.

```julia-repl
julia> scores = Dict(
```

## 5. Ottieni un elenco dei giocatori

Per ottenere un elenco dei giocatori, definisci `players`, che accetta 1 argomento:

- Il primo argomento è il dizionario dei punteggi.

```julia-repl
julia> scores = Dict(
           "Liselot" => 486373,
           "Éimhín"  => 0,
       )
Dict{String, Int64} with 2 entries:
  "Liselot" => 486373
  "Éimhín"  => 0

julia> players(scores)
2-element Vector{String}:
 "Liselot"
 "Éimhín"
```
