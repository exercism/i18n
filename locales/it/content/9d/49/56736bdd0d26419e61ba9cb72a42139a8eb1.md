# Suggerimenti

## 1. Recupera una carta dalla pila

- Gli indici di `Vector` partono da `1`.
- Puoi recuperare l'`n`esimo valore in un vettore `v` con `v[n]`.

## 2. Scambia una carta nella pila

- Gli `Vector` sono mutabili: puoi modificarne il contenuto in qualsiasi momento assegnando un nuovo valore.

## 3. Inserisci una carta in cima alla pila

- In Base esiste un metodo [`push!`][push] per aggiungere un nuovo valore alla fine di una collezione.

## 4. Rimuovi una carta dalla pila

- In Base esiste un metodo [`deleteat!`][deleteat] per eliminare un elemento da un `Vector` in corrispondenza di un dato indice.

## 5. Rimuovi la carta in cima alla pila

- In Base esiste un metodo [`pop!`][pop] per rimuovere un elemento alla fine di una collezione.

## 6. Inserisci una carta in fondo alla pila

- In Base esiste un metodo [`pushfirst!`][pushfirst] per inserire un nuovo valore all'inizio di una collezione.

## 7. Rimuovi una carta dal fondo della pila

- In Base esiste un metodo [`popfirst!`][popfirst] per rimuovere un elemento all'inizio di una collezione.

## 8. Controlla la dimensione della pila

- In Base esiste un metodo [`length`][length] per ottenere la lunghezza di una collezione.
