# Istruzioni

In questo esercizio scriverai del codice per aiutare un'azienda di insegne a creare messaggi personalizzati per le sue insegne.

## 1. Crea un insieme di stringhe utili

Definisci le seguenti stringhe costanti, che verranno usate per creare le insegne:

- `birthday`: contiene il valore "Birthday"
- `valentine`: contiene il valore "Valentine's Day"
- `anniversary`: contiene la stringa "Anniversary"

## 2. Crea un insieme di caratteri utili

Definisci i seguenti caratteri costanti, che verranno usati per creare le insegne:

- `space`: contiene il valore " " (un singolo spazio)
- `exclamation`: contiene il valore "!"

## 3. Combina le frasi per comporre i messaggi

Implementa la funzione `buildSign(for:name:)`, che prende l'argomento `for`, che contiene una delle tre stringhe definite nella prima attività, e l'argomento `name`, una stringa che contiene il nome della persona a cui è destinata l'insegna.
Usa la concatenazione per comporre il messaggio dell'insegna e ricorda di riutilizzare le costanti già definite.
La funzione deve restituire il messaggio dell'insegna come stringa.

```swift
buildSign(for: birthday, name: "Otto")
// returns "Happy Birthday Otto!"

buildSign(for: anniversary, name: "Valentina")
// returns "Happy Anniversary Valentina!"
```

## 4. Crea un'insegna di laurea

Implementa la funzione `graduationFor(name:year:)`, che prende l'argomento `name`, una stringa che contiene il nome della persona a cui è destinata l'insegna, e l'argomento `year`, un numero intero che contiene l'anno in cui la persona si laurea.
Usa le stringhe interpolate per comporre il messaggio dell'insegna.
La funzione deve restituire il messaggio dell'insegna come stringa.

```swift
graduationFor(name: "Padma", year: 2023)
// returns "Congratulations Padma!\nClass of 2023"
```

## 5. Calcola il costo di un'insegna

Implementa la funzione `costOf(sign:)`, che prende l'argomento `sign`, una stringa che contiene il messaggio dell'insegna.
L'insegna ha un prezzo base di 20 nella valuta data. Inoltre ogni lettera costa 2 (gli spazi bianchi sono inclusi nel calcolo).
La funzione deve restituire il costo dell'insegna come numero intero.

```swift
costOf(sign: "Happy Birthday Grandma!")
// returns 66
```
