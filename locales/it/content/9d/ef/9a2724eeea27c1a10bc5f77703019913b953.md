# Introduzione

## Casting

Il casting e la conversione di tipo sono due modi diversi di trasformare un'espressione da un tipo di dati a un altro.

Si può fare il cast di un'espressione verso un altro tipo con l'operatore di cast `(<type>)`.

```csharp
long l = 1000L;
int i = (int)l;

object o = new Random();
Random r = (Random)o;
```

Se i tipi non sono compatibili, viene lanciata un'istanza di `InvalidCastException`. Nel caso dei numeri, questo indica che il tipo ricevente non può rappresentare il valore convertito. Nel caso delle classi, uno dei tipi deve derivare dall'altro (cosa che vale, banalmente, anche per le struct).

Un'alternativa al _casting_ è la _conversione di tipo_ tramite l'operatore `is`. Questa viene in genere applicata ai tipi di riferimento e ai tipi nullable.

```csharp
object o = new Random();
if (o is Random rand)
{
    int ii = rand.Next();
    // now, do something random
}
```

Se devi rilevare il tipo preciso di un oggetto, `is` può essere un po' troppo permissivo, perché restituisce true per una classe e per qualunque classe o interfaccia da cui essa derivi, direttamente o indirettamente. In questo caso, la soluzione è `typeof` e `Object.GetType()`.

```csharp
object o = new List<int>();

o is ICollection<int> // true
o.GetType() == typeof(ICollection<int>) // false
o is List<int> // true
o.GetType() == typeof(List<int>) // true
```
