# Appendice alle istruzioni

L'output va disposto in [ordine per righe](https://en.wikipedia.org/wiki/Row-_and_column-major_order): tutte le parole nella prima riga, poi le parole nella seconda riga, e così via.

## Registri

| Registro | Utilizzo     | Tipo    | Descrizione                         |
| -------- | ------------ | ------- | ----------------------------------- |
| `$a0`    | input        | intero  | dimensione                          |
| `$a1`    | input/output | indirizzo | matrice di parole, in ordine per righe |
| `$v0`    | output       | intero  | numero di parole nella matrice      |
| `$t0-9`  | temporaneo   | qualsiasi | per la memorizzazione temporanea    |
