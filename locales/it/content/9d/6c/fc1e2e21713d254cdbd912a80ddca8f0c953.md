# Informazioni

Le [stringhe verbatim][verbatim-strings] consentono stringhe su più righe. Si introducono con una @. Si possono usare con l'interpolazione di stringhe. Basta aggiungere un "\$" prima delle virgolette di apertura.

```csharp
string str = @"
See no wretched
quotes everywhere
";
```

[verbatim-strings]: https://docs.microsoft.com/en-us/dotnet/csharp/programming-guide/strings/#regular-and-verbatim-string-literals
