# Test

Un REPL di Clojurescript ti permette di eseguire il codice facilmente e di ricevere un riscontro immediato, e può essere usato anche per eseguire i test.

## Leiningen

Per aprire un REPL usando la Clojure CLI, spostati nella directory che contiene l'esercizio ed esegui:
``` bash
$ clojure -m cljs.main -re node
```

Nota: Node deve essere installato sul tuo sistema.

Quando sei pronto a lavorare su un esercizio e hai creato un file per contenere la tua soluzione (ad esempio `bob.cljs`), puoi eseguire i test nel terminale con `$ clojure -A:test`.

Per prima cosa, usa `require` sul namespace di test:
``` clojure
=> (require 'bob-test)
nil
;; and the test namespace
=> (require 'cljs.test)
```

Cambia il namespace in quello di test:
```clojure
=> (ns bob-test)
nil
```

Poi chiama `run-tests` su `bob-test`:
``` clojure
=> (cljs.test/run-tests)

Testing bob-test

Ran 14 tests containing 14 assertions.
0 failures, 0 errors.
{:test 14, :pass 14, :fail 0, :error 0, :type :summary}
```

Per eseguire i test di un esercizio con la Clojure CLI, ti basta chiamare:
``` bash
$ clojure -M:test

Testing bob-tests

Ran 14 tests containing 14 assertions.
0 failures, 0 errors.
```
