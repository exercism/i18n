# Appendice alle istruzioni

## Approfondimento

Quando definisci i metodi per un Enumerable generico, è tipico chiamare [#to_enum][to_enum], nel caso in cui non venga passato alcun blocco.

Ecco un test aggiuntivo che potresti aggiungere:

```ruby
def test_accumulate_when_block_is_deferred
  skip
  accumulate_enumerator = [1, 2, 3].accumulate
  accumulated_result = accumulate_enumerator.map do |number|
    number * number
  end
  assert_equal [1, 4, 9], accumulated_result
end
```

[to_enum]: https://docs.ruby-lang.org/en/master/Object.html#method-i-to_enum
