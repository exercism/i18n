# Introduzione

La forma speciale `import` ti permette di usare funzioni di un modulo esterno senza usare il nome del modulo.

Importare un intero modulo esterno potrebbe creare conflitti con le funzioni locali esistenti. Per evitarlo, sono disponibili due opzioni: `:except` e `:only`. Entrambe richiedono una keyword list, in cui la chiave è il nome della funzione e il valore è l'arità della funzione.

Di solito gli import vengono aggiunti all'inizio della definizione del modulo.

```elixir
defmodule Square do
  import Integer, only: [pow: 2]

  def area(a), do: pow(a, 2)
end
```
