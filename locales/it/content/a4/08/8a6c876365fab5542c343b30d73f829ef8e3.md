# Enum

Gli enum sono un tipo di dato di Cairo usato per definire un insieme di varianti predefinite allo scopo di rendere il codice più leggibile e più sicuro.
In Cairo, le varianti di un `enum` possono essere dichiarate per contenere tipi di dato diversi (interi, struct, tuple, altri enum, ecc.).

Il frammento di codice seguente mostra come si potrebbero definire gli enum:

```rust
#[derive(Drop)]
enum Direction {
    North,
    East,
    South,
    West,
}
```

L'enum `Direction` dichiarato sopra è un enum semplice con quattro varianti: `North`, `East`, `South` e `West`.
La convenzione di denominazione è usare il PascalCase per le varianti degli enum.
Ogni variante rappresenta un valore distinto del tipo enum `Direction`.
Ogni variante di questo particolare esempio di enum non ha un valore associato e può essere istanziata con questa sintassi:

```rust
let direction = Direction::North;
```

Di seguito c'è lo stesso enum `Direction`, ma con varianti che hanno valori associati, che memorizzano il grado esatto della direzione:

```rust
#[derive(Drop)]
enum Direction {
    North: u128,
    East: u128,
    South: u128,
    West: u128,
}
```

Da questo esempio è evidente che ogni variante dell'enum `Direction` ha un valore associato di `u128`.
Questo tipo di enum può essere istanziato come segue:

```rust
let direction = Direction::North(10);
```

## Esempio di enum complesso con tipi personalizzati

Un enum può essere dichiarato con una combinazione di tipi di dato diversi come varianti.
Nell'esempio seguente, `Action` è un enum complesso che ha una raccolta di `Quit`, `Direction`, `SendMessage`, `ChangeAvatar` e `ProfileState` come varianti.

```rust
#[derive(Drop)]
struct Move {
    up: u32,
    down: u32,
    right: u32,
    left: u32,
}

#[derive(Drop)]
enum UserCommand {
    Login,
    UpdateProfile,
    Logout,
}

#[derive(Drop)]
enum Action {
    Quit, //  variant with no associated value
    Direction: Move, // variant with the `Move` struct associated value
    SendMessage: felt252, // a single felt252 variant
    ChangeAvatarColor: (u8, u8, u8), // variant with the tuple of three associated values
    ProfileState: UserCommand // variant with an enum associated value
}
```

## Implementazioni di trait per gli enum

In Cairo, i trait possono essere definiti e implementati su enum personalizzati.
Questo permette di definire metodi e attributi associati a un enum.
Di seguito c'è un esempio di questo, in cui definiamo un enum `Message` e implementiamo un trait `Processing` per esso:

```rust
#[derive(Drop)]
enum Message {
    Quit,
    Echo: felt252,
    Move: (u128, u128),
}

trait Processing {
    fn process(self: Message);
}

impl ProcessingImpl of Processing {
    fn process(self: Message) {
        match self {
            Message::Quit => { println!("quitting") },
            Message::Echo(value) => { println!("echoing {}", value) },
            Message::Move((x, y)) => { println!("moving from {} to {}", x, y) },
        }
    }
}
```

Ecco come si potrebbe usare il trait per elaborare un messaggio `Quit`:

```rust
let msg: Message = Message::Quit;
msg.process(); // prints "quitting"
```

In molte situazioni gli enum possono tornare utili, soprattutto se usati con il flusso `match` come nell'implementazione dei trait qui sopra.
Leggi di più sul flusso `match` in [The Cairo Book][match].
