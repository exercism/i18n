# Null

Null è un tipo di valore primitivo con un solo valore: `null`.
Null viene spesso usato per rappresentare il nulla.
È considerato «falsey», ma è distinto da `false` e dagli altri valori falsey.

```php
<?php

is_null(null); // => true
isset(null); // => false

null == true; // => false
null === true; // => false

null == false; // => true
null === false; // => false
```

## Lavorare con i valori null

In PHP, i valori null possono essere una causa comune di errore, perché spesso vengono restituiti al posto di uno stato di errore o per rappresentare il nulla.
Prevenire gli errori richiede spesso di fare un «null-checking» per assicurarsi che il valore non sia null prima di operare su di esso.

```php
<?php

$value = null;

$value->doSomething(); // throws an error as a null value is not an object instance.

if (!is_null($value)) {
    $value->doSomething(); // succeeds
}
```

Ripetere il null-checking può essere fonte di errori, quindi PHP fornisce due operatori per lavorare con i valori null: l'operatore di accesso null-safe `?->` e l'operatore di coalescenza null `??`.

```php
<?php

$value = null;
$result = $value?->doSomething(); // => return null rather than error
$result = $result ?? "default"; // => "default" is assigned to $result
```
