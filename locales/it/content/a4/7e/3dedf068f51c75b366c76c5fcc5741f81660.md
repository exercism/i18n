# Informazioni

[Il sovraccarico dei metodi][method-overloading] è un concetto chiave in Java: permette a una classe di avere più di un metodo con lo stesso nome, purché ogni metodo abbia una lista di parametri diversa.
Questa caratteristica è un aspetto fondamentale della programmazione orientata agli oggetti di Java e offre un modo per eseguire operazioni simili con tipi diversi o con un numero diverso di input.
Il sovraccarico dei metodi migliora la leggibilità e l'organizzazione del codice, perché permette a metodi che svolgono funzioni simili di condividere lo stesso nome.
È importante notare che il sovraccarico è determinato dalla firma del metodo, che comprende il nome del metodo e la lista dei parametri.

## Punti chiave

- **La firma è importante**: il tipo restituito non fa parte della firma del metodo, quindi cambiare solo il tipo restituito di un metodo non costituisce un sovraccarico.
- **Differenze nei parametri**: i metodi sovraccaricati devono differire nel numero o nel tipo dei parametri.
- **Utilizzo**: il sovraccarico viene spesso usato per offrire modi più intuitivi di usare un metodo con tipi di input diversi.

## Esempi di sovraccarico dei metodi

Considera una classe `Calculator` che sa sommare numeri.
Il sovraccarico permette di definire operazioni di addizione diverse:

```java
public class Calculator {

    public int add(int a, int b) {
        return a + b;
    }

    public double add(double a, double b) {
        return a + b;
    }

    public int add(int a, int b, int c) {
        return a + b + c;
    }
}
```

## Buone pratiche

- **Chiarezza**: i metodi sovraccaricati vanno usati in modo da rendere il codice più intuitivo.
  - Il comportamento dei metodi sovraccaricati deve essere correlato e coerente.
- **Evita l'ambiguità**: assicurati che ogni metodo sovraccaricato abbia uno scopo chiaro e che le differenze nelle liste dei parametri siano abbastanza significative da evitare confusione.
- **Documentazione**: documenta in modo adeguato ogni versione dei metodi sovraccaricati.
  - Una documentazione chiara aiuta gli altri sviluppatori a capire lo scopo e l'uso di ogni variante del metodo.
- **Tipi restituiti coerenti**: anche se in un metodo sovraccaricato i tipi restituiti possono variare, in genere è buona pratica mantenerli coerenti dove possibile, per evitare confusione.
- **Limita il sovraccarico**: evita di abusare del sovraccarico dei metodi.
  - Un sovraccarico eccessivo può rendere il codice più difficile da leggere e da mantenere.

## Conclusione

Il sovraccarico dei metodi è una funzionalità potente di Java che, se usata correttamente, può migliorare molto la leggibilità e la flessibilità del codice.
Permette ai metodi di essere più versatili e adattabili a contesti diversi, rendendo i programmi Java più modulari e più facili da mantenere.
