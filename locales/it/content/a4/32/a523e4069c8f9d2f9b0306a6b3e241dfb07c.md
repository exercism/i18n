# About

## Alias di tipo

In Gleam, un alias di tipo può essere usato per dare un nome comodo a un tipo già esistente che altrimenti sarebbe scomodo da scrivere.

```gleam
pub type Headers =
  List(#(String, String))

pub fn html_headers() -> Headers {
  [
    #("content-type", "text/html"),
    #("x-frame-options", "DENY"),
  ]
}
```

Quando lo si scrive con `pub type`, l'alias può essere usato anche fuori dal modulo in cui è definito. Se `pub` viene omesso, l'alias è privato e non può essere referenziato in altri moduli.
