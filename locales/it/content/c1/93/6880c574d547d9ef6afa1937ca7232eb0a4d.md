# Informazioni

Una [funzione di ordine superiore](https://docs.microsoft.com/en-us/dotnet/fsharp/introduction-to-functional-programming/first-class-functions) è una funzione che può fare una di queste due cose:

- prendere una funzione come argomento
- restituire una funzione

Un argomento di tipo funzione è semplicemente un argomento normale, con la differenza che puoi chiamarlo.

```fsharp
let double = fun x -> x * 2

let apply f x = f x

apply double 3
// => 6
```
