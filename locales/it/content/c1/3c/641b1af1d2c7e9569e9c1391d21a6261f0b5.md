# Segnaposto

## Valori ASCII

Questo esercizio richiede di convertire i caratteri ASCII da e verso il loro valore numerico. L'estensione [ordchr][ordchr] di GNU awk fornisce questa funzionalità. Per aggiungere le funzioni `ord()` e `chr()`, carica l'estensione `ordchr` aggiungendo una direttiva `@load` all'inizio del file:

```
@load "ordchr"
```

[ordchr]: https://www.gnu.org/software/gawk/manual/gawk.html#Extension-Sample-Ord
