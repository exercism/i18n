# Informazioni

## I tipi di funzione

Abbiamo già visto come si definiscono le firme delle funzioni: un nome di funzione seguito da un elenco di etichette di parametro separate da virgole, con i rispettivi tipi, poi `->` e il tipo dei valori restituiti dalla funzione.

Se si rimuovono tutti i nomi e le etichette da questa firma, quello che resta è il [tipo della funzione][function-types].

```swift
func shoppingList(item: String, quantity: Int) -> String {
  "You need to buy \(quantity) \(item)."
}
// shoppingList: (String, Int) -> String

func repeater(_ phrase: String, times: Int) -> String {
  var result = ""
  for _ in 1...times {
    result += phrase
  }
  return result
}
// repeater: (String, Int) -> String

func printString(line: String) {
  print(line)
}
// printString: (String) -> ()
```

Nota come i tipi delle prime due funzioni siano gli stessi, `(String, Int) -> String`, anche se le due funzioni funzionano in modo molto diverso. Entrambe prendono in input una `String` e un `Int` e restituiscono una `String`. E, come si vede dal tipo della terza funzione, anche se la funzione non sembra restituire nulla, in realtà restituisce `()`, l'unico valore di tipo `Void`. Da notare che `()` e `Void` sono interscambiabili come nomi di tipo, quindi il tipo di `printString` si potrebbe scrivere anche come `String) -> Void`.

Questi tipi si possono usare allo stesso modo di qualsiasi altro tipo in Swift; per esempio, si possono usare nella dichiarazione di variabili o costanti. E poiché in Swift le funzioni sono valori, a queste costanti/variabili si possono assegnare funzioni già esistenti:

```swift
var stringAndIntToString: (String, Int) -> String

stringAndIntToString = shoppingList
stringAndIntToString("carrots", 3)
// => "You need to buy 3 carrots."

stringAndIntToString = repeater
stringAndIntToString("carrots", 3)
// => "carrotscarrotscarrots"
```

Come per le altre variabili/costanti, il valore che assegni deve essere del tipo corretto:

```swift
stringAndIntToString = printShoppingList
// Error: Cannot assign value of type '(String) -> ()' to type '(String, Int) -> String'
```

## I tipi di funzione come tipi di parametro

Dal momento che i tipi di funzione si possono usare ovunque si possano usare altri tipi, ne consegue che [si possono usare come tipi di parametro][functions-as-parameters], oltre che passarli ad altre funzioni e chiamarli dall'interno di quelle funzioni.

```swift
func apply3(to str: String, function f: (String, Int) -> String) -> String {
  f(str,3)
}
// apply3: ([String], (String, Int) -> String) -> [String]

apply3(to: "eggs", function: shoppingList)
// => "You need to buy 3 eggs."

apply3(to: "eggs", function: repeater)
// => "eggseggseggs"

func apply(functions fs: [(String, Int) -> String],
           to string: String,
          ) -> [String] {
  var result = [String]()
  for f in fs {
    result.append(f(string, 3))
  }
  return result

}
// apply: ([(String, Int) -> String], String) -> [String]


apply(functions: [shoppingList, repeater], to: "carrots")
// => ["You need to buy 3 carrots.", "carrotscarrotscarrots"]
```

## I tipi di funzione come tipi restituiti

Allo stesso modo, [i tipi di funzione si possono usare come tipi restituiti][functions-as-returns] dalle funzioni. In altre parole, si possono scrivere funzioni che creano e restituiscono altre funzioni. Quando si creano queste funzioni, la funzione restituita può usare gli altri parametri passati alla funzione o le variabili locali create all'interno della funzione genitore.

```swift
func makeAdder(base: Int) -> (Int) -> Int {
  func adder(_ i: Int) -> Int {
    base + i
  }
  return adder
}
// makeAdder: (Int) -> (Int) -> Int

let add10 = makeAdder(base: 10)
// add10: (Int) -> Int

let subtract20 = makeAdder(base: -20)
// subtract10: (Int) -> Int

add10(5)
// => 15

subtract20(5)
// => -15
```

## Catturare i valori

Come si è visto con la funzione `makeAdder(base:)` qui sopra, le funzioni annidate riescono ad accedere ai parametri e alle variabili delle funzioni che le circondano. Inoltre, mantengono l'accesso a questi valori anche dopo che la funzione che le contiene termina. Questa azione di ottenere e mantenere l'accesso è nota come [_cattura_][capturing-values].

## Le funzioni di ordine superiore

Le funzioni che prendono funzioni come parametri e/o restituiscono funzioni sono note come funzioni di ordine superiore. Swift ha molte funzioni di ordine superiore nelle sue varie librerie. Per esempio, il metodo `sorted(by:)` disponibile sulle collezioni di Swift come `Array`, che per un array con elementi di tipo `T` prende una funzione di tipo `(T, T) -> Bool` che determina quale di due valori deve venire prima dell'altro in un Array ordinato, restituendo `true` se il valore di sinistra deve apparire per primo e `false` se deve apparire per primo quello di destra.

Un altro esempio è il metodo `contains(where:)` sulle collezioni, che per una collezione con elementi di tipo `T` prende una funzione di tipo `(T) -> Bool` che restituisce `true` se l'elemento soddisfa una certa proprietà e `false` altrimenti. A quel punto, `contains(where:)` restituisce `true` se almeno un elemento della collezione soddisfa questa proprietà.

```swift
func longer(_ strA: String, _ strB: String) -> Bool {
  strA.count > strB.count
}
// longer: (String, String) -> Bool

["apple", "ball", "carrot"].sorted(by: longer)
// => ["carrot", "apple", "ball"]

["apple", "ball", "carrot"].sorted(by: >)
// => ["carrot", "ball", "apple"]


func isBig(_ i: Int) -> Bool {
  i > 100
}
// isBig: (Int) -> Bool

func isVowel(_ char: Character) -> Bool {
  switch char.lowercased() {
  case "a", "e", "i", "o", "u": return true
  default: return false
  }
}
// isVowel: (Character) -> Bool

[1, 75, 3, 99].contains(where: isBig)
// => false

"Owl".contains(where: isVowel)
// => true

```
