# Informazioni

[Le tuple][tuples] raggruppano più valori in un unico valore composto.
A differenza degli array, i valori di una tupla non devono avere lo stesso tipo, e la dimensione di una tupla è fissa una volta creata.

Per creare una tupla, racchiudi tra parentesi dei valori separati da virgole:

```swift
let order = ("biscuits", 2.99, 3)
```

Puoi anche specificare esplicitamente le annotazioni di tipo:

```swift
let order: (String, Double, Int) = ("biscuits", 2.99, 3)
```

Per estrarre i singoli elementi da una tupla senza nome, usa la sintassi con indice a base zero (`.0`, `.1`, ecc.):

```swift
let item = order.0     // "biscuits"
let quantity = order.2 // 3
```

## Tuple con nome

Puoi dare un nome ai singoli elementi di una tupla quando la definisci:

```swift
let order = (item: "biscuits", price: 2.99, quantity: 3)
```

Dare un nome agli elementi rende il codice più leggibile e ti permette di accedere agli elementi usando la notazione con punto e le loro etichette:

```swift
let item = order.item         // "biscuits"
let quantity = order.quantity // 3
```

Puoi anche includere i nomi degli elementi nell'annotazione di tipo:

```swift
let order: (item: String, price: Double, quantity: Int) = (item: "biscuits", price: 2.99, quantity: 3)
```

## Modificare le tuple

Se una tupla è dichiarata come variabile (`var`), puoi aggiornarne gli elementi:

```swift
var order = ("biscuits", 2.99, 3)
order.0 = "cookies"
order.1 = 1.99
order.2 = 5

print(order)
// Prints ("cookies", 1.99, 5)
```

## Restituire più valori

Anche se le funzioni Swift possono restituire un solo valore, restituire una tupla ti permette di raggruppare e [restituire più valori][multiple-return-values] da una funzione:

```swift
func divide(_ dividend: Int, by divisor: Int) -> (quotient: Int, remainder: Int) {
    let quotient = dividend / divisor
    let remainder = dividend % divisor
    return (quotient, remainder)
}

let result = divide(14, by: 4)
print("Quotient: \(result.quotient), Remainder: \(result.remainder)")
// Prints "Quotient: 3, Remainder: 2"
```

## Scomposizione delle tuple

Puoi scomporre (o spacchettare) i valori di una tupla in costanti o variabili separate:

```swift
let order = ("biscuits", 2.99, 3)
let (item, price, quantity) = order

print(item) // Prints "biscuits"
```

La scomposizione delle tuple funziona anche direttamente nei cicli `for-in`:

```swift
let orders = [("biscuits", 2.99, 3), ("cookies", 1.99, 5)]

for (item, price, quantity) in orders {
    print("Item: \(item), Price: \(price), Quantity: \(quantity)")
}
```
