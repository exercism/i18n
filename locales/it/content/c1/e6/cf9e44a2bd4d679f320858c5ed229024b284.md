# Appendice alle istruzioni

## Formato dell'input

Ogni elenco di input è rappresentato da una stringa terminata da null, con un carattere di nuova riga alla fine di ogni input.

Un esempio sarebbe `"nail\nshoe\nhorse\nrider\nmessage\nbattle\nkingdom\n"`

## Registri

| Registro | Utilizzo     | Tipo    | Descrizione                                                    |
| -------- | ------------ | ------- | -------------------------------------------------------------- |
| `$a0`    | input        | indirizzo | stringa di input terminata da null, con un carattere di nuova riga dopo ogni input |
| `$a1`    | input/output | indirizzo | stringa di output terminata da null                            |
| `$t0-9`  | temporaneo   | qualsiasi | per la memorizzazione temporanea                               |
