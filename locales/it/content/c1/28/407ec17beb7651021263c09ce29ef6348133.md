# Introduzione

Il tipo unione discriminata rappresenta un numero fisso di casi denominati. Ogni valore di un'unione discriminata corrisponde esattamente a uno dei casi denominati.

Un'unione discriminata si definisce con la parola chiave `type`, con i casi separati dal carattere pipe (`|`):

```fsharp
type Season =
    | Spring
    | Summer
    | Autumn
    | Winter
```

Ogni caso di un'unione discriminata può avere facoltativamente dei dati associati, e casi diversi possono avere tipi di dati diversi. Se nessuno dei casi ha dati associati, l'unione discriminata è simile a quella che in altri linguaggi viene di solito chiamata _enumerazione_ (o _enum_).

```fsharp
type Number =
    | Integer of int
    | Float of float
    | Invalid
```

Per creare un valore per un caso specifico, si può fare riferimento al suo nome (ad esempio `Success`). Dato che i nomi dei casi sono solo funzioni costruttore, i dati associati si possono passare come un normale argomento di funzione. Se un'altra unione discriminata ha definito un caso con lo stesso nome, dovrai usarne il nome completo (ad esempio `Result.Success`).

```fsharp
let byName = Integer 2
let byFullName = Number.Invalid
```

Le unioni discriminate hanno _uguaglianza strutturale_: due valori per lo stesso caso e con gli stessi dati (facoltativi) sono equivalenti.

Anche se si possono usare espressioni `if/elif/else` per lavorare con le unioni discriminate, il modo consigliato per farlo è il pattern matching con l'_identifier pattern_:

```fsharp
let describe number =
    match number with
    | Integer i -> sprintf "Integer: %d" i
    | Float d  -> sprintf "Float: %f" d
    | Invalid   -> "Invalid"
```
