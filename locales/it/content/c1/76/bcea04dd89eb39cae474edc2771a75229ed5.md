# Appendice alle istruzioni

## Implementazione

In questo esercizio implementerai una procedura che ha il compito di allocare la stringa che restituisce. La deallocazione della stringa è responsabilità di chi chiama la procedura.

```odin
// The procedure will be called like that:
converted := convert(3)
// ...
// and eventually the caller will delete the string
delete(converted)
```
