# Istruzioni

In questo esercizio elaborerai delle righe di log.

Ogni riga di log è una stringa formattata così: `"[<LVL>]: <MESSAGE>"`.

Questi sono i diversi livelli di log:

- `TRC` (traccia)
- `DBG` (debug)
- `INF` (info)
- `WRN` (avviso)
- `ERR` (errore)
- `FTL` (fatale)

Hai tre attività.

## 1. Analizzare il livello di log

Definisci un enum `LogLevel` con sei elementi che corrispondono ai livelli di log visti sopra.

- `TRACE`
- `DEBUG`
- `INFO`
- `WARNING`
- `ERROR`
- `FATAL`

Poi implementa il metodo `LogLine.getLogLevel()`, che restituisce il livello di log analizzato di una riga di log:

```java
var logLine = new LogLine("[INF]: File deleted");
logLine.getLogLevel();
// => LogLevel.INFO
```

## 2. Gestire un livello di log sconosciuto

Purtroppo, ogni tanto alcune righe di log hanno un livello sconosciuto.
Per gestire senza problemi queste righe di log, aggiungi un elemento `UNKNOWN` all'enum `LogLevel`: deve essere restituito quando si analizza un livello di log sconosciuto:

```java
var logLine = new LogLine("[XYZ]: Overly specific, out of context message");
logLine.getLogLevel();
// => LogLevel.UNKNOWN
```

## 3. Convertire una riga di log nel formato breve

Il livello di log di una riga di log è piuttosto verboso.
Per ridurre lo spazio su disco necessario a memorizzare le righe di log, è stato ideato un formato breve: `"[<ENCODED_LEVEL>]:<MESSAGE>"`.

Il livello di log codificato è una semplice corrispondenza tra un livello di log e un numero:

- `UNKNOWN` - `0`
- `TRACE` - `1`
- `DEBUG` - `2`
- `INFO` - `4`
- `WARNING` - `5`
- `ERROR` - `6`
- `FATAL` - `42`

Implementa il metodo `LogLine.getOutputForShortLog()`, che restituisce la riga di log nel formato breve:

```java
var logLine = new LogLine("[ERR]: Stack Overflow");
logLine.getOutputForShortLog();
// => "6:Stack Overflow"
```
