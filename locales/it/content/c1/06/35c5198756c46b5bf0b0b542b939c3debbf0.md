# Appendice alle istruzioni

## Pacchetto di ordinamento

Questo esercizio richiede di ordinare un array, ma questa funzionalità non è inclusa nella libreria standard.
Potresti scrivere una libreria di ordinamento, ma un'opzione migliore è usare il [pacchetto sorts](https://github.com/diku-dk/sorts).

Puoi usare questo pacchetto nella soluzione eseguendo il comando seguente nella cartella della soluzione:

```shell
futhark pkg add github.com/diku-dk/sorts
futhark pkg sync
```

Poi importa gli [algoritmi di ordinamento che preferisci](https://github.com/diku-dk/sorts/tree/master/lib/github.com/diku-dk/sorts) con:

```futhark
import "lib/github.com/diku-dk/sorts/<sorting algorithm>"
```
