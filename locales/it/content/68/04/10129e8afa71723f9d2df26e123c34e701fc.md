# Introduzione

Gli enum in Cairo ti permettono di definire un tipo che può essere una tra diverse varianti con nome.

## Nozioni di base

Gli enum, abbreviazione di enumerazioni, limitano tutti i possibili valori di alcuni dati a un insieme predefinito. I possibili valori di un `enum` sono chiamati varianti:

```rust
#[derive(Drop)]
enum Direction {
    North,
    South,
    East,
    West,
}
```

Crea i valori dell'enum specificando la variante:

```rust
let my_direction = Direction::North;
let another_direction = Direction::West;
```

## Corrispondenza di pattern

Usa match per gestire le diverse varianti dell'enum:

```rust
match my_direction {
    Direction::North => println!("Going north!"),
    Direction::South => println!("Going south!"),
    Direction::East => println!("Going east!"),
    Direction::West => println!("Going west!"),
}
```

Ogni braccio del match gestisce una variante dell'enum.

## Enum con dati

Le varianti dell'enum possono contenere dati aggiuntivi:

```rust
struct Location {
    x: u32,
    y: u32,
}

enum Message {
    Text: ByteArray,
    Number: u32,
    Location: Location,
}
```

Esegui la corrispondenza di pattern per estrarre i dati:

```rust
match msg {
    Message::Text(content) => println!("Text: {}", content),
    Message::Number(val) => println!("Number: {}", val),
    Message::Location(Location { x, y }) => println!("Position: ({}, {})", x, y),
}
```
