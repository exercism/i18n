# Informazioni

Il codice Elixir viene eseguito sulla [macchina virtuale BEAM][beam]. BEAM fa parte del sistema di runtime di [Erlang][erlang]. Essendo ispirato a Erlang e condividendone l'ambiente di esecuzione, Elixir offre un'ottima interoperabilità con le librerie Erlang. Questo significa che gli sviluppatori Elixir possono usare le librerie Erlang all'interno del proprio codice Elixir. Anzi, nella comunità Elixir è scoraggiato scrivere librerie Elixir per funzionalità già fornite dalle librerie Erlang.

Di conseguenza, alcune funzionalità, come le operazioni matematiche o le funzioni per i timer, sono disponibili in Elixir solo tramite Erlang.

Questo stretto rapporto tra Elixir e Erlang significa che, per diventare uno sviluppatore Elixir esperto, potresti voler dedicare un po' di tempo a imparare la sintassi di base di Erlang.

## Come si usano

La libreria standard di Erlang è disponibile per l'uso nel nostro codice Elixir senza bisogno di passaggi aggiuntivi.

Le funzioni Erlang si possono chiamare nello stesso modo in cui chiamiamo le funzioni Elixir, con una piccola differenza. I nomi dei moduli Erlang sono atomi in `snake_case`. Ad esempio, per chiamare la funzione `pi/0` di Erlang dal modulo `math`, si scriverebbe:

```elixir
:math.pi()
# => 3.141592653589793
```

## I moduli Erlang più usati

I moduli Erlang più usati forniscono funzionalità che mancano nella libreria standard di Elixir. Sono:

- Il modulo `timer`, che fornisce funzioni come [`sleep/1`][erl-timer-sleep], [`send_after/2`][erl-timer-send-after] e [`send_interval/2`][erl-timer-send-interval].
- Il modulo `rand`, che fornisce funzioni come [`uniform/0`][erl-rand-uniform], [`normal/0`][erl-rand-normal] e [`seed/2`][erl-rand-seed-2].
- [`:io_lib.format/2`][erl-io-lib-format], che fornisce la formattazione di stringhe in stile C (usando sequenze di controllo).
- Il modulo `math`, che fornisce funzioni matematiche come [`sin/1`][erl-math-sin], [`cos/1`][erl-math-cos], [`log2/1`][erl-math-log2], [`log10/1`][erl-math-log10], [`pow/2`][erl-math-pow] e altre ancora.
- Il modulo [`queue`][erl-queue], che fornisce una struttura dati di tipo coda.
- Il modulo [`crypto`][erl-crypto], che fornisce funzioni crittografiche.
- Il modulo [`zip`][erl-zip], che fornisce funzioni per lavorare con gli archivi zip.
- Il modulo [`calendar`][erl-calendar], che fornisce funzioni per lavorare con date e orari, come [`iso_week_number/1`][erl-calendar-iso-week-number]. Per passare una struct `Date`, `Time` o `NaiveDateTime` a una delle funzioni Erlang, bisogna convertirla nel formato Erlang con una funzione `to_erl` del modulo corrispondente.

Per scoprire la libreria standard di Erlang, esplora il [manuale di riferimento STDLIB][erl-stdlib-ref].

L'interoperabilità di Elixir con le librerie Erlang non si limita alla libreria standard di Erlang. Qualsiasi libreria Erlang può essere usata nel codice Elixir.
