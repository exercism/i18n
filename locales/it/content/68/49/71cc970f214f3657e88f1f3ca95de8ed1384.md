# Appendice alle istruzioni

## Formato di input/output

Ogni insieme di parole è rappresentato come una stringa terminata da null, con un carattere di nuova riga alla fine di ogni parola.

Devi restituire gli anagrammi nello stesso ordine in cui sono elencati nelle parole candidate.

Un esempio sarebbe `"tones\nnotes\nSeton\n"`

## Registri

| Registro | Utilizzo     | Tipo    | Descrizione                                                    |
| -------- | ------------ | ------- | -------------------------------------------------------------- |
| `$a0`    | input        | indirizzo | stringa di destinazione terminata da null, senza nuova riga     |
| `$a1`    | input        | indirizzo | stringa delle parole candidate terminata da null, con una nuova riga dopo ogni parola |
| `$a2`    | input/output | indirizzo | stringa di output terminata da null, con una nuova riga dopo ogni parola |
| `$t0-9`  | temporaneo   | qualsiasi | per l'archiviazione temporanea                                  |
