# Introduzione

I *combinatori* sono parole di ordine superiore: catturano gli schemi più comuni di riordino dello stack e danno loro un nome. Ricorrere a loro significa scrivere molti meno `dup`, `swap`, `over`, `rot`.

```
keep   ( x quot: ( x -- y ) -- y x )         ! apply, preserve x
dip    ( x quot -- x )                        ! operate underneath
bi     ( x q1 q2 -- r1 r2 )                   ! two functions of one input
tri    ( x q1 q2 q3 -- r1 r2 r3 )             ! three functions of one input
cleave ( x { q1 q2 … } -- r1 r2 … )           ! n functions of one input
bi@    ( x y q -- r1 r2 )                     ! same function on two values
bi*    ( x y q1 q2 -- r1 r2 )                 ! different functions on two values
```

```factor
5 [ 2 * ] keep .s            ! 10  /  5
4 [ sq ] [ neg ] bi .s       ! 16  / -4
1 2 3 [ + ] dip .s           ! 3   /  3
3 4 [ sq ] bi@ .s            ! 9   / 16
```

`keep`, `dip`, `bi`, `bi@`, `bi*` si trovano in [`kernel`][kernel]; `cleave` e le varianti più lunghe si trovano in [`combinators`][combinators].
