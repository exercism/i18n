# Istruzioni

La tua azienda di design ha lavorato principalmente con trasformazioni CSS per costruire pagine web. Dopo qualche discussione, si è deciso di iniziare a usare Clojure per eseguire alcuni calcoli in modo dinamico. Alcuni dei tuoi colleghi hanno meno esperienza con Clojure, quindi decidi di usare una closure per creare trasformazioni riutilizzabili per coppie di coordinate `{x, y}`.

## 1. Traslare le coordinate

Implementa la funzione `translate2d` che restituisce una funzione che fa uso di una closure per eseguire una traslazione 2d ripetibile di una coppia di coordinate.

```clojure
(def move-coordinates-right-2px (translate2d 2 0))
(def result (move-coordinates-right-2px 4 8))
;; result => [6 8]
```

## 2. Scalare le coordinate

Implementa la funzione `scale2d` che restituisce una funzione che fa uso di una closure per eseguire una scalatura 2d ripetibile di una coppia di coordinate.

> Per questo esercizio, supponi che i valori di scalatura siano solo positivi.

```clojure
(def double-scale (scale2d 2 2))
(def result (double-scale 6 -3))
;; result => [12 -6]
```

## 3. Combinare le funzioni di trasformazione

Combina due funzioni di trasformazione per eseguire una trasformazione ripetibile. Questa operazione è spesso chiamata _composizione di funzioni_, dove il risultato della prima funzione _'f(x)'_ viene usato come input della seconda funzione _'g(x)'_.

```clojure
(def move-coordinates-right-2px (translate2d 2 0))
(def double-coordinates (scale2d 2 2))
(def composed-transformations 
  (compose-transform move-coordinates-right-2px 
                     double-coordinates))
(def result (composed-transformations 0 1))
;; result => [4 2]
```

## 4. Salvare i risultati delle funzioni

Implementa la funzione `memoize-transform`. Prende una funzione da _memoizzare_, poi restituisce una nuova funzione che ricorda gli input della funzione fornita, così che l'ultimo valore restituito possa essere «ricordato» e calcolato una sola volta se viene chiamata di nuovo con gli stessi argomenti.

> La memoizzazione è talvolta chiamata _programmazione dinamica_: permette di eseguire operazioni costose una sola volta, dato che il loro risultato viene ricordato.

```clojure
(def triple-scale (scale2d 3 3))
(def memoized-scale (memoize-transform triple-scale))

(memoized-scale 4 3)
;; => [12, 9], this is computed since it hasn't been computed before for the arguments

(memoized-scale 4 3)
;; => [12, 9], this is remembered, since it was computed already
```
