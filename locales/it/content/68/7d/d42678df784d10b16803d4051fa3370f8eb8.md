## 1. Import di libreria con prefisso

- Nota che lo script di test (test/pig_latin_test.dart) importa il file della soluzione con un prefisso:

  ```dart
  import 'package:pig_latin/pig_latin.dart' as pigLatin;
  ```
- Per saperne di più: [Specificare il prefisso di una libreria](https://dart.dev/guides/language/language-tour#specifying-a-library-prefix)
