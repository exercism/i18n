# Informazioni

`call` è la primitiva universale per «eseguire subito questa quotation». Quando il compilatore riesce a vedere la quotation letteralmente, può inferirne l'effetto; quando invece la quotation arriva da una variabile, da un array o da un parametro, devi dichiarare l'effetto:

```factor
: apply-binary ( a b op -- c )
    call( a b -- c ) ;

5 3 [ - ] apply-binary .   ! => 2
5 3 [ + ] apply-binary .   ! => 8
```

La dichiarazione `call( a b -- c )` viene compilata in un controllo a runtime che verifica se la quotation ha davvero l'effetto dichiarato: una discrepanza diventa un errore chiaro invece di uno stato dello stack corrotto.

Trattare le quotation come dati, spingerle sullo stack, inserirle negli array, restituirle dalle word, è una delle cose che rende il codice concatenativo così compatto. Un «programma» può essere una semplice sequenza, e `each` con `call` basta per interpretarla.
