# Introduzione

## L'istruzione _if-then_

L'istruzione di controllo del flusso più semplice in Java è l'istruzione _if-then_.
Questa istruzione serve a eseguire una sezione di codice solo se una determinata condizione è `true`.
Un'istruzione _if-then_ si definisce usando la clausola `if`:

```java
class Car {
    void drive() {
        // the "if" clause: the car needs to have fuel left to drive
        if (fuel > 0) {
            // the "then" clause: the car drives, consuming fuel
            fuel--;
        }
    }
}
```

Nell'esempio qui sopra, se l'auto è senza carburante, chiamare il metodo `Car.drive` non fa nulla.

## L'istruzione _if-then-else_

L'istruzione _if-then-else_ fornisce un percorso di esecuzione alternativo per quando la condizione nella clausola `if` risulta `false`.
Questo percorso di esecuzione alternativo segue una clausola `if` e si definisce usando la clausola `else`:

```java
class Car {
    void drive() {
        if (fuel > 0) {
            fuel--;
        } else {
            stop();
        }
    }
}
```

Nell'esempio qui sopra, se l'auto è senza carburante, chiamare il metodo `Car.drive` chiama un altro metodo per fermare l'auto.

L'istruzione _if-then-else_ supporta anche più condizioni, usando la clausola `else if`:

```java
class Car {
    void drive() {
        if (fuel > 5) {
            fuel--;
        } else if (fuel > 0) {
            turnOnFuelLight();
            fuel--;
        } else {
            stop();
        }
    }
}
```

Nell'esempio qui sopra, guidare l'auto quando il carburante è minore o uguale a `5` fa muovere l'auto, ma accende la spia del carburante.
Quando il carburante arriva a `0`, l'auto smette di muoversi.
