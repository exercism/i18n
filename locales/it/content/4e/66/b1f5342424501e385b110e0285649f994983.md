# Istruzioni

Ti occupi del toolkit di generazione di codice di una stazione di segnali.
Ogni macro è uno *stencil*: un piccolo template che il compilatore usa per
stampare codice specializzato in ogni punto di chiamata.

Scrivi solo le quattro macro. Il file di test definisce piccole
parole wrapper che *chiamano* le macro (una macro si può
osservare solo attraverso il codice che genera), poi controlla i
risultati a runtime dei wrapper. Lascia i wrapper come sono.

Per ogni attività, il corpo riceve gli input letterali del punto di chiamata
sullo stack e deve lasciare **una quotation**. Le righe «compila in»
mostrano il codice lineare che la quotation dovrebbe produrre.

## 1. Due volte

`twice` prende una quotation letterale e restituisce una quotation che
esegue l'originale due volte di seguito.

```factor
! : inc-twice ( x -- y ) [ 1 + ] twice ;
! body receives [ 1 + ]  ->  must build [ 1 + 1 + ]
5 inc-twice .   ! => 7
```

## 2. N ripetizioni

`repeat-quot` prende una quotation letterale e un conteggio letterale `n`,
e restituisce una quotation che esegue l'originale `n` volte di seguito.
`n = 0` restituisce la quotation vuota `[ ]`.

```factor
! : inc-thrice ( x -- y ) [ 1 + ] 3 repeat-quot ;
! body receives [ 1 + ] 3  ->  must build [ 1 + 1 + 1 + ]
5 inc-thrice .   ! => 8
```

## 3. Comporne molte

`compose-many` prende un array letterale di quotation e restituisce un'unica
quotation che esegue ciascuna a turno. Un array vuoto
restituisce la quotation vuota.

```factor
! : pipeline ( x -- y ) { [ 1 + ] [ 2 * ] [ 1 - ] } compose-many ;
! body receives { [ 1 + ] [ 2 * ] [ 1 - ] }  ->  must build [ 1 + 2 * 1 - ]
5 pipeline .   ! => 11
```

## 4. Iterazione srotolata

`each-literal` prende una sequenza letterale e una quotation. Restituisce
una quotation che, per ogni elemento della sequenza, impila
quell'elemento e poi esegue la quotation: un'iterazione che avviene
in fase di compilazione, quindi il codice generato è lineare.

```factor
! : sum-three ( -- n ) 0 { 10 20 30 } [ + ] each-literal ;
! body receives { 10 20 30 } [ + ]  ->  must build [ 10 + 20 + 30 + ]
sum-three .   ! => 60
```

Questa è la più strutturale delle quattro: sia la lunghezza della sequenza
*sia* i suoi valori danno forma al codice generato. I suggerimenti ti
guidano a costruirla un passo alla volta.
