# Informazioni

In Java, i booleani sono rappresentati dal tipo `boolean`, i cui valori possono essere `true` o `false`.

Java supporta tre [operatori booleani][operators]:

- `!` (NOT): nega il valore booleano
- `&&` (AND): prende due valori booleani e dà come risultato true se entrambi sono true
- `||` (OR): dà come risultato true se almeno uno dei due valori booleani è true

Gli operatori `&&` e `||` usano la _valutazione a corto circuito_: il membro destro dell'operatore viene valutato solo quando serve.

Sono anche noti come operatori condizionali o logici.
Nella documentazione, `!` viene a volte classificato come operazione bit a bit, ma ha la consueta semantica di _NOT_.

```java
true || false // => true
false || false // => false
false || true // => true
true && false // => false
true && true // => true
!true // => false
!false // => true
```

I tre operatori booleani hanno ciascuno una diversa [_precedenza degli operatori_][precedence].
Di conseguenza, vengono valutati in quest'ordine: prima `not`, poi `&&` e infine `||`.
Se vuoi «aggirare» queste regole, puoi racchiudere un'espressione booleana tra parentesi (`()`), perché le parentesi hanno una precedenza ancora più alta.

```java
!true && false   // => false
!(true && false) // => true
```
