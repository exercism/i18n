# Introduzione

## Interfacce

Un'interfaccia è un tipo che contiene membri che definiscono un gruppo di funzionalità correlate. Separa gli utilizzi di una classe dall'implementazione, permettendo più implementazioni diverse o il supporto di comportamenti generici come la formattazione, il confronto o la conversione.

La sintassi di un'interfaccia è simile a quella di una classe o di una struct, con la differenza che metodi e proprietà compaiono solo come firma e non viene fornito alcun corpo.

```csharp
public interface ILanguage
{
    string LanguageName { get; set; }
    string Speak();
}

public class ItalianTaveller : ILanguage, ICloneable
{
    public string LanguageName { get; set; } =  "Italiano";

    public string Speak()
    {
        return "Ciao mondo";
    }

    public object Clone()
    {
        ItalianTaveller it = new ItalianTaveller();
        it.LanguageName = this.LanguageName;
        return it;
    }
}
```

Tutte le operazioni definite dall'interfaccia devono essere implementate.

Le interfacce possono contenere, tra gli altri membri, metodi di istanza e proprietà

## Ordinamento

Per permettere a un oggetto di essere confrontato con un altro oggetto, deve implementare l'interfaccia `IComparable<T>`.
Questa interfaccia ha un unico metodo che deve essere implementato: `int CompareTo(T other)`.

Il metodo `CompareTo` può restituire tre valori diversi:

- Un valore minore di zero: l'oggetto corrente è minore dell'altro oggetto.
- Un valore maggiore di zero: l'oggetto corrente è maggiore dell'altro oggetto.
- Un valore uguale a zero: l'oggetto corrente è uguale all'altro oggetto.
