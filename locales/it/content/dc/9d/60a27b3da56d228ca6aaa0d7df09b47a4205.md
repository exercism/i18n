# Informazioni

A volte, quando una funzione accetta molti argomenti, può essere difficile ricordare l'ordine in cui vanno passati. Per migliorare la leggibilità, Gleam permette di etichettare gli argomenti con un nome.

Per etichettare un argomento, scrivi il nome dell'etichetta prima del nome dell'argomento, separati da uno spazio.

```gleam
pub fn replace(
  in string: String,
  each target: String,
  with replacement: String
) -> String {
  // ...
}
```

Quando chiami una funzione con argomenti etichettati, puoi passare gli argomenti in qualsiasi ordine. Ognuna di queste chiamate a `replace` è equivalente:

```gleam
replace(in: "🍔🍔🍔" each: "🍔", with: "🍕")

replace(each: "🍔", in: "🍔🍔🍔", with: "🍕")

replace(with: "🍕", each: "🍔", in: "🍔🍔🍔")
```

Le etichette sono sempre facoltative. Anche se una funzione ha argomenti etichettati, puoi comunque chiamarla senza etichette.

```gleam
replace("🍔🍔🍔", "🍔", "🍕")
```

Quando definisci una funzione con argomenti etichettati, tutti gli argomenti dopo il primo argomento etichettato devono essere etichettati a loro volta.

```gleam
// This function is valid
pub fn valid(
  x: Int,
  label1 y: Int,
  label2 z: Int
) -> Int {
  // ...
}

// This function is invalid
pub invalid(
  x: Int,
  label1 y: Int,
  z: Int
) -> Int {
  // ...
}
```
