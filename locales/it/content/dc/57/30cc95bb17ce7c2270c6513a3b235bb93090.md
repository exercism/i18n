# Introduzione

## Tipi generici

Una definizione di collezione include tipicamente un segnaposto tra parentesi angolari, spesso `T` per convenzione. Una tale collezione è detta tipo generico. Ciò permette a chi usa la collezione di specificare quale tipo di elementi memorizzare nella collezione. Nel codice di esempio qui sotto stiamo istanziando un array di stringhe.

## Array

Gli array in C# sono collezioni di valori primitivi o di istanze di struct o classi. Sono implementati nella libreria di classi di base come `List<T>`, dove `T` è il tipo dell'elemento nell'array. L'API espone una ricca serie di metodi per creare e manipolare array.

Gli elementi possono essere aggiunti e rimossi dagli array. Crescono e si riducono a seconda delle necessità.

```csharp
var listOfStrings = new List<string>();
```
