## Installare Z3

### Scaricare Python (se non è già installato)

La versione più recente di Python può essere scaricata da [qui.](https://python.org)

* Durante l'installazione, assicurati di selezionare la casella che aggiunge Python a PATH

### Scaricare Visual Studio (se non è già installato)

La versione più recente di Visual Studio può essere scaricata da [qui.](https://visualstudio.microsoft.com/downloads/?utm_medium=microsoft&utm_source=docs.microsoft.com&utm_campaign=inline+link&utm_content=download+vs2019)

* Durante l'installazione, seleziona il carico di lavoro **Python Development**
* Seleziona tutte le caselle di controllo dei pacchetti opzionali per lo sviluppo Python sul lato destro

Dopo l'installazione, apri Visual Studio e configura le preferenze iniziali.

### Installare i comandi Git

Le istruzioni per installare Git le trovi [qui.](https://git-scm.com/book/en/v2/Getting-Started-Installing-Git)

* Dovrai [aggiungere Git alle variabili di sistema](https://stackoverflow.com/questions/4492979/git-is-not-recognized-as-an-internal-or-external-command)

### Clonare Z3

Vai al [repository GitHub di Z3](https://github.com/Z3Prover/z3) per vedere il progetto.

Apri un terminale sul tuo computer e spostati nel punto in cui vuoi clonare il repository Z3 (es: C:\Z3).

Da quella posizione, esegui:

```bash
git clone https://github.com/z3Prover/z3.git
```

### Compilare Z3 su Windows usando Visual Studio Command Prompt

Apri **Developer Command Prompt for VS 2019** dal menu Start.

Spostati nella cartella in cui hai clonato il repository Z3 (es: C:\Z3).

Per le build a 32 bit, esegui:

```bash
python scripts/mk_make.py
```

Per una build a 64 bit, esegui:

```bash
python scripts/mk_make.py -x
```

poi esegui:

```bash
cd build
pip install z3-solver
```



Ora dovresti riuscire ad aprire Visual Studio ed eseguire Z3 con il suo binding Python.


Per fare una prova, puoi eseguire:
```python
from x3 import *
x = Real('x')
y = Real('y)
s = Solver()
s.add(x + y > 5, x > 1, y > 1)
print(s.check())
print(s.model())
```

Le ultime due righe dovrebbero produrre `sat` e `[y = 4, x = 2]`.
