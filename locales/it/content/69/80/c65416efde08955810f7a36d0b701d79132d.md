# Installazione

Per installare Reason ti serve il Node Package Manager (npm). Segui le istruzioni [qui](https://www.npmjs.com/get-npm).

Una volta che hai npm, installa Reason con:
```
npm install -g bs-platform
```

Reason si integra con diversi editor, vedi [qui](https://reasonml.github.io/docs/en/editor-plugins.html#officially-supported-editors).

Alcuni strumenti a riga di comando (tra cui un REPL che ti permette di valutare espressioni Reason in una shell) si trovano [qui](https://github.com/reasonml/reason-cli).
