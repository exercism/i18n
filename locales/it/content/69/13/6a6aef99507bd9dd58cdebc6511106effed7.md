# Istruzioni

In questo esercizio scriverai del codice per aiutare Larry the Lisp Alien ad analizzare e formattare le stringhe di log. Queste stringhe di log arrivano da vari sistemi e devono essere elaborate, così che i loro messaggi possano comparire su un pannello di monitoraggio informativo.

Le stringhe di log hanno la forma `"[<level>]: <message>"`. Il livello sarà uno dei seguenti valori: `info`, `warn` o `ohno`.

## 1. Estrai il messaggio

Definisci una funzione `log-message` che prende una stringa di log e restituisce il messaggio che contiene.

```lisp
(log-message "[ohno]: whoops!") ; => "whoops!"
```

## 2. Determina la gravità

Il livello della stringa di log ne determina la gravità.

- un livello `info` corrisponde a una gravità di `:everything-ok`
- un livello `warn` corrisponde a una gravità di `:getting-worried`
- un livello `ohno` corrisponde a una gravità di `:run-for-cover`

Definisci una funzione `log-severity` che prende una stringa di log e restituisce la gravità corretta.

```lisp
(log-severity "[warn]: might want to get that checked") ; => :getting-worried
```

## 3. Fare i conti con i capricci della realtà

Purtroppo a volte le stringhe di log non sono sempre formattate correttamente. In particolare, il livello del log potrebbe non essere tutto in minuscolo come indicato sopra. Modifica `log-severity` per gestire questa situazione.

```lisp
(log-severity "[WaRn]: string case system failing") ; => :getting-worried
```

## 4. Riformatta il messaggio di log in base alla gravità

A seconda della gravità, il messaggio deve essere modificato in modi diversi:

- una gravità di `:everything-ok` deve avere il messaggio trasformato tutto in minuscolo.
- una gravità di `:getting-worried` deve avere il messaggio trasformato con ogni parola che inizia con la maiuscola.
- una gravità di `:run-for-cover` deve avere il messaggio trasformato tutto in maiuscolo.

Definisci una funzione `log-format` che prende un messaggio di log e restituisce un messaggio formattato correttamente.

```lisp
(log-format "[ohno]: whoops!") ; => WHOOPS!
```
