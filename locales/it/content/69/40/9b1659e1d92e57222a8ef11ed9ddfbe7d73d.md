# Introduzione

Come le proprietà, che memorizzano dati all'interno delle struct e delle classi, puoi anche definire dei _metodi_ che memorizzano funzioni nella struct o nella classe.

I metodi si definiscono allo stesso modo di una funzione normale, solo all'interno del corpo della struct o della classe. Nota che se una funzione cambia il valore di una proprietà in una struct, deve essere preceduta dalla parola chiave `mutating`. Inoltre, se una proprietà può essere cambiata da un metodo, quella proprietà deve essere definita usando `var` invece di `let`, proprio come le variabili normali.

```swift
struct CharacterStats {
  var health = 0.0
  var speed = 0
  var strength = 0

  mutating func takeHit(_ damage: Double) {
    health = max(0.0, health - damage)
  }
  func canLift(_ weight: Int) -> Bool {
    weight < strength * 100
  }
}
```

Questi metodi possono essere chiamati usando la notazione puntata, proprio come le proprietà.

```swift
var stats = CharacterStats(health: 72.8, speed: 19, strength: 6)
stats.canLift(500)
// => true
```
