# Scrivere il codice

Scrivi il codice in `src/lib.rs`.
Gli esercizi includono un file stub in `src/lib.rs` che ti mostrerà le firme del codice che dovrai scrivere.

Per la maggior parte degli esercizi, è meglio scrivere tutto il codice nel file `src/lib.rs`.
Se vuoi dividere la soluzione in più file, consulta il [capitolo sui moduli][chapter-modules] del libro di Rust.

[chapter-modules]: https://doc.rust-lang.org/book/ch07-02-defining-modules-to-control-scope-and-privacy.html

## Eseguire i test

Per eseguire i test, tutto quello che devi fare è lanciare il comando seguente:

```bash
$ cargo test
```

Per impostazione predefinita è abilitato solo il primo test.
Quando sei pronto a far passare il test successivo, rimuovi il flag di ignore dal test successivo (`#[ignore]`).
Se preferisci, puoi anche rimuovere il flag da tutti i test in una volta sola.

Scrivi pure il minor numero di righe di codice possibile per far passare i test.
Gli errori dei test ti guideranno su cosa scrivere dopo.

Poiché Rust controlla tutto il codice in fase di compilazione, può capitare che i test non compilino finché non scrivi il codice richiesto.
Anche i test contrassegnati con `ignore` vengono controllati in fase di compilazione.
Puoi [trasformare in commento][comments] i test che non compilano iniziando ogni riga con `//`.
Poi, quando sei pronto a lavorare su quel test, puoi togliere i commenti.
Rust ha anche una macro speciale chiamata `todo!()`, che puoi usare sui rami di codice non ancora finiti per far compilare il programma.

[comments]: https://doc.rust-lang.org/book/ch03-04-comments.html

## Usare le librerie

Dovresti riuscire a risolvere la maggior parte degli esercizi senza usare librerie esterne.
Puoi comunque aggiungere librerie (la comunità di Rust le chiama **crates**) eseguendo `cargo add crate-name` nella directory di un esercizio.

I test automatici sul sito supportano solo un insieme predefinito di crate, che trovi [qui][local-registry] nella sezione `[dependencies]`.
Se vuoi che venga aggiunto il supporto per un crate specifico, apri pure una issue o una pull request.

[local-registry]: https://github.com/exercism/rust-test-runner/blob/main/local-registry/Cargo.toml
