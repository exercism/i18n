# Appendice alle istruzioni

## Parole

- `<bst> ( data-seq -- tree )`: costruisce un albero inserendo in ordine ogni elemento di `data-seq`.
- `sorted-data ( tree -- seq )`: restituisce gli elementi dell'albero in ordine crescente (visita in ordine).

## Gerarchia delle tuple

Un nodo in un albero binario di ricerca è *vuoto* oppure *contiene un dato più due sottoalberi*. Modellalo come una piccola gerarchia di ereditarietà:

```factor
TUPLE: bst ;
TUPLE: leaf < bst ;
TUPLE: branch < bst data left right ;
```

`bst` è il genitore astratto; `leaf` è il caso dell'albero vuoto; `branch` porta un valore e due figli `bst` (ognuno dei quali è a sua volta un `leaf` o un `branch`).

## Ordinamento

Confronta i dati con `before=?` (da `math.order`), che funziona sia con le stringhe sia con i numeri: i test usano dati di tipo stringa come `"1"`, `"2"`, `"3"`.
