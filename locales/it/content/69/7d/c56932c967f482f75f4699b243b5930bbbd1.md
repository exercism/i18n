# Flusso di controllo

Le espressioni `if` e i cicli controllano il flusso di esecuzione in Cairo:
`

- **Le espressioni `if`** eseguono il codice in modo condizionale, a seconda che una condizione venga valutata come `true`.
- **I cicli** (come `loop`, `while` e `for`) eseguono ripetutamente del codice finché una condizione specificata resta vera o finché non si verifica una condizione di uscita.

Questi costrutti sono fondamentali per implementare la logica e l'iterazione in Cairo.

## Espressioni `if`

Le espressioni `if` in Cairo permettono di controllare il flusso di esecuzione in base a una logica condizionale.
Seguono una struttura in cui il codice viene eseguito a seconda che una condizione booleana venga valutata come `true` o `false`.

```rust
fn main() {
    let temperature = 30;

    if temperature > 25 {
        println!("It's hot outside!");
    }
}
```

Questo esempio mostra un semplice blocco `if` in Cairo.
Il messaggio `"It's hot outside!"` viene stampato solo se la condizione `temperature > 25` viene valutata come `true`.
Se la condizione è `false`, non viene eseguito alcun codice e il programma prosegue.

```rust
fn main() {
    let number: u32 = 5;

    if number < 10 {
        println!("The number is less than 10.");
    } else {
        println!("The number is 10 or greater.");
    }
}
```

Eseguendo questo codice, nella console verrà stampato `"The number is less than 10."`.

### Gestire più condizioni con `else if`

Puoi usare più condizioni combinando `if` ed `else` in un'espressione `else if`.

```rust
fn main() {
    let score: u64 = 85;

    if score >= 90 {
        println!("Grade: A");
    } else if score >= 80 {
        println!("Grade: B");
    } else if score >= 70 {
        println!("Grade: C");
    } else {
        println!("Grade: F");
    }
}
```

Eseguendo questo codice, nella console verrà stampato `"Grade: B"`.

### Usare `if` in un'istruzione `let`

L'espressione `if` in Cairo può essere usata sul lato destro di un'istruzione `let` per assegnare il risultato a una variabile.

```rust
fn main() {
    let condition: bool = true;
    let number: felt252 = if condition {
        5
    } else {
        6
    };

    if number == 5 {
        println!("condition was true and number is {}", number);
    }
}
```

## Cicli

I cicli sono un costrutto fondamentale che permette di ripetere blocchi di codice, consentendo un'esecuzione efficiente e controllata delle attività.
I cicli possono iterare su una sequenza o eseguire codice ripetutamente in base a una condizione.
Cairo offre tre tipi principali di cicli:

- **loop**: un ciclo di base che viene eseguito all'infinito, a meno che non venga fermato esplicitamente con un'istruzione `break`.
- **while**: continua a essere eseguito finché una condizione specificata resta `true`.
  Si ferma quando la condizione diventa `false`.
- **for**: itera sugli elementi di una collezione, come gli array, eseguendo il codice per ogni elemento.

### Ripetere il codice con `loop`

La parola chiave `loop` dice a Cairo di eseguire un blocco di codice più e più volte, all'infinito, o finché non gli dici esplicitamente di fermarsi.

```rust
fn main() {
    loop {
        println!("again!");
    }
}
```

Eseguendo questo codice, `"again!"` verrà stampato nella console all'infinito, finché il programma non esaurisce il gas o non lo fermiamo manualmente.

> Nota: Cairo ci impedisce di eseguire un programma con cicli infiniti grazie a un contatore del gas.
> Il contatore del gas è un meccanismo che limita la quantità di calcolo che un programma può svolgere.
> Il gas è un'unità di misura che esprime il costo di calcolo di un'istruzione.
> Quando il contatore del gas arriva a zero, il programma si ferma.

Per uscire da un ciclo, inserisci la parola chiave `break` all'interno del ciclo per indicare al programma quando smettere di eseguirlo.

```rust
fn main() {
    let mut i: usize = 0;
    loop {
        if i > 10 {
            break;
        }
        println!("i = {}", i);
        i += 1;
    }
}
```

La parola chiave `continue` dice al programma di passare all'iterazione successiva del ciclo e di saltare il resto del codice in questa iterazione.

```rust
fn main() {
    let mut i: usize = 0;
    loop {
        if i > 10 {
            break;
        }
        if i == 5 {
            i += 1;
            continue;
        }
        println!("i = {}", i);
        i += 1;
    }
}
```

Eseguendo questo programma, il valore di `i` non verrà stampato quando è uguale a `5`.

#### Restituire valori da `loop`

Puoi restituire un valore da un `loop` usando la parola chiave `break` seguita dal valore che vuoi restituire.
In questo modo esci dal `loop` e passi un risultato al resto del codice.

```rust
fn main() {
    let mut counter = 0;

    let result = loop {
        if counter == 10 {
            break counter * 2;
        }
        counter += 1;
    };

    println!("The result is {}", result); // prints "The result is 20"
}
```

### Cicli condizionali con `while`

`while` esegue del codice finché una condizione è `true` ed esce quando la condizione diventa `false`.

```rust
fn main() {
    let mut number = 3;
    while number != 0 {
        println!("{}!", number);
        number -= 1;
    }
    println!("LIFTOFF!!!");
}
```

### Iterare su una collezione con `for`

`for` itera su ogni elemento di una collezione, eseguendo il codice per ogni elemento.

```rust
fn main() {
    let a = [10, 20, 30, 40, 50].span();
    for element in a {
        println!("the value is: {}", element);
    }
}
```
