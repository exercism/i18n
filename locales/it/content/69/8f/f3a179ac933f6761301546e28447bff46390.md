# Suggerimenti

Questo è un esercizio breve e semplice, quindi è meglio non complicarlo.

## 1. Definisci l'intervallo delle traverse

- Devi restituire un intervallo di numeri interi

## 2. Definisci l'intervallo delle colonne

- Devi restituire un intervallo di caratteri maiuscoli.
- I caratteri si scrivono tra virgolette singole, come `'W'`,

## 3. Trasforma l'intervallo delle traverse in un array di traverse

- In questo caso, la funzione [`collect()`][collect] è la tua amica.

## 4. Trasforma l'intervallo delle colonne in un array di colonne

- Vedi l'attività 3.

[collect]: https://docs.julialang.org/en/v1/base/collections/#Base.collect-Tuple{Any}
