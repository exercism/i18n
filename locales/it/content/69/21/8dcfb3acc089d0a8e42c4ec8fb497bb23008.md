# Introduzione

## Namespace

Un metodo importante per organizzare il codice è l'uso dei namespace.
Due funzioni potrebbero avere un conflitto di nomi: si può risolvere mettendole in namespace diversi.
Gli namespace possono essere annidati, il che può aiutare a strutturare grandi basi di codice.
L'accesso agli namespace avviene tramite l'operatore di risoluzione dello scope `::`.

L'esempio qui sotto mostra l'uso di due diverse funzioni `foo`.
Vengono usate insieme anteponendo i rispettivi namespace.

```cpp
namespace my_ns {
    int foo() {
        return 44;
    }
    namespace my_inner_ns {
        int baz() {
            return 90;
        }
    }
}
namespace my_other_ns {
    int foo() {
        return -2;
    }
}

int myresult{my_ns::foo() + my_other_ns::foo() * my_ns::my_inner_ns::baz()};
```
