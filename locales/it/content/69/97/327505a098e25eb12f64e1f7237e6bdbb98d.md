# Istruzioni

In questo esercizio, elaborerai le righe di un report di log.
Ogni riga di log è una stringa formattata così: `"[<LEVEL>]: <MESSAGE>"`.

Ci sono tre livelli di log diversi:

- `INFO`
- `WARNING`
- `ERROR`

Hai tre compiti, ognuno dei quali riceverà una riga di log e ti chiederà di fare qualcosa con essa.

## 1. Ottieni il messaggio da una riga di log

Implementa il metodo `log_line::message` per restituire il messaggio di una riga di log:

```cpp
log_line::message("[ERROR]: Invalid operation")
// => "Invalid operation"
```

## 2. Ottieni il livello di log da una riga di log

Implementa il metodo `log_line::log_level` per restituire il livello di log di una riga di log, che va restituito in maiuscolo:

```cpp
log_line::log_level("[ERROR]: Invalid operation")
// => "ERROR"
```

## 3. Riformatta una riga di log

Implementa il metodo `log_line::reformat` che riformatta la riga di log, mettendo prima il messaggio e poi il livello di log tra parentesi:

```cpp
log_line::reformat("[INFO]: Operation completed")
// => "Operation completed (INFO)"
```
