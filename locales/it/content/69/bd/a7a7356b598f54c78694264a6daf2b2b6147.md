# Informazioni

Gli [attributi di modulo][module-attr] si possono usare come delle [«costanti»][attr-as-const], che vengono valutate al momento della compilazione.

```elixir
defmodule Example do
  @number 2

  def number(), do: @number
end
```

Tuttavia, non si comportano esattamente come delle costanti, perché possono essere sovrascritti ridefinendoli nel modulo:

```elixir
defmodule Example do
  @standard_message "Hello, World!"
  @standard_message "Overwritten!"

  def message(), do: @standard_message
end
```

[module-attr]: https://hexdocs.pm/elixir/module-attributes.html
[attr-as-const]: https://hexdocs.pm/elixir/module-attributes.html#as-constants
