# Appendice alle istruzioni

## Suggerimenti

I test di questo esercizio sono diversi da quelli a cui sei abituato. Normalmente un test verifica se, dato un certo input, l'output corrisponde al valore atteso. Questo si chiama _test basato sui valori_. Questo esercizio, invece, usa i _test basati sulle proprietà_, in cui i test verificano se, per una serie di input, l'output possiede una proprietà specifica. Le due differenze principali che distinguono i test basati sulle proprietà da quelli basati sui valori sono:

1. Un test basato sulle proprietà non lavora con un unico valore di input, ma con molti.
1. Un test basato sulle proprietà verifica proprietà, non valori concreti.

Per questo esercizio, i test verificano tutti una proprietà della forma a rombo che il codice dovrebbe produrre. Inoltre, tutti i test verificano se la proprietà che testano vale per tutte le lettere di input valide (da 'A' a 'Z').

Per facilitare i test basati sulle proprietà, i test di questo esercizio si avvalgono dei pacchetti [FsCheck](https://www.nuget.org/packages/FsCheck) e [FsCheck.Xunit](https://packages.nuget.org/packages/FsCheck.Xunit/2.2.0). Per saperne di più su FsCheck, la documentazione del framework è disponibile [qui](https://fscheck.github.io/FsCheck/).

Se vuoi maggiori informazioni sui test basati sulle proprietà, consulta [questo articolo](http://www.erikschierboom.com/2016/02/22/property-based-testing/).
