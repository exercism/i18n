# Introduzione

Le funzioni in Kotlin sono cittadini di prima classe.
Questo significa che possono essere memorizzate in variabili, passate come argomenti e persino restituite da altre funzioni.
Per esempio, assegnando una funzione alla variabile `addOne`:

```kotlin
val addOne = fun (num : Int) : Int {
    return num + 1
}
```

Una funzione può anche restituire un'altra funzione:

```kotlin
fun makeAddOne() : (Int) -> Int {
    return fun(num : Int) : Int {
        return num + 1
    }
}

val addOne = makeAddOne()
```

Una volta assegnata, la funzione può essere chiamata tramite la variabile come se fosse una qualsiasi altra funzione:
```kotlin
addOne(3)
// => 4
```

## Dichiarare i tipi di funzione

Un tipo di variabile o di parametro può essere dichiarato usando la sintassi `(parameter types) -> return type`.
Per esempio, dichiarando una variabile:

```kotlin
val addOne : (Int) -> Int = fun (num : Int) : Int {
    return num + 1
}
```

E per un parametro di funzione:

```kotlin
fun perform(operation : (Int) -> Int) {
    operation(3)
}
```

## Espressioni lambda

Un'espressione lambda è un modo più breve per definire una funzione.
Sono scritte nella forma `{ parameters -> body }`.
L'espressione restituisce l'ultimo valore dell'ultima istruzione nel corpo.
Per esempio:

```kotlin
// Assigning to a variable
val addOne = { num : Int -> num +  1}

// In a function call
perform({ num : Int -> num + 1 })
```

Kotlin può inferire i tipi quando ci sono informazioni sufficienti.
Per esempio, gli esempi precedenti possono anche essere scritti come:

```kotlin
// Assigning to a variable
val addOne : (Int) -> Int = { num -> num + 1 }

// Or ...
val addOne  = { num : Int -> num + 1 }

// Using in a function
perform({ num -> num + 1 })
```

## `it` per lambda con un singolo parametro

Quando l'espressione ha un solo parametro, il parametro può essere omesso.
Kotlin renderà quindi disponibile nel corpo un parametro chiamato `it`.
Per esempio:

```kotlin
val addOne : (Int) -> Int = { it +  1 }
```

## Passare lambda in coda

Quando l'ultimo argomento di una funzione è una lambda, l'espressione lambda viene scritta direttamente _dopo_ le parentesi.
Per esempio:

```kotlin
// Function that takes a function as last argument
fun calculateFrom(from : Int, operation : (Int) -> Int) : Int {
    return operation(from)
}

// Call the calculateFrom function
calculateFrom(2) { it * 3 }
// => 6
```
