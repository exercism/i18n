# Suggerimenti

## Generale

- Leggi qualcosa sul modulo `Enum` nella [guida ufficiale per iniziare][getting-started-enum] o su [elixirschool.com][elixir-school-enum].
- Dai un'occhiata alla documentazione per l'[elenco completo delle funzioni del modulo `Enum`][enum-functions].

## 1. Ordina gli articoli per prezzo

- Esiste una [funzione integrata][enum-sort-by] per ordinare un enumerable usando una funzione di ordinamento.

## 2. Trova tutti gli articoli con prezzi mancanti

- Esiste una [funzione integrata][enum-filter] per filtrare un enumerable.

## 3. Aggiorna i nomi degli articoli

- Esiste una [funzione integrata][enum-map] per trasformare ogni elemento di un enumerable.
- Esiste una [funzione integrata][string-replace] che può sostituire tutte le occorrenze di una stringa con un'altra.

## 4. Incrementa la quantità dell'articolo

- Le mappe implementano il protocollo enumerable.
- Le funzioni di `Enum` convertono le mappe in una lista di tuple `{key, value}`.
- Ci sono due funzioni diverse che possono trasformare una lista di tuple `{key, value}` di nuovo in una mappa usando una funzione di trasformazione. [Una restituisce sempre una nuova mappa][map-new], mentre [l'altra ti permette di scegliere la struttura di raccolta][enum-into].

## 5. Calcola la quantità totale dell'articolo

- Le mappe implementano il protocollo enumerable.
- Le funzioni di `Enum` convertono le mappe in una lista di tuple `{key, value}`.
- Esiste una [funzione integrata][enum-reduce] per ridurre un enumerable a un singolo valore.
