# Introduzione

Le funzioni hanno per impostazione predefinita un collegamento esterno e possono essere chiamate da qualsiasi altro file del progetto.
Per ulteriori informazioni sul collegamento, vedi il [concetto di collegamento](../linkage/introduction.md#Introduction).
Una funzione `static` può essere chiamata solo all'interno del file sorgente in cui è definita.

Per esempio

```c
// file scope, internal linkage
// can only be called from within this file
static void some_function()
{
    // code snipped
}

// file scope, external linkage by default
// can be called from any other file in the project
int main()
{
    // code snipped
}
```
