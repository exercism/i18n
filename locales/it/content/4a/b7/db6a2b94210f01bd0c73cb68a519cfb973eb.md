# Introduzione

## Unioni discriminate

Il tipo unione discriminata rappresenta un numero fisso di casi denominati. Ogni valore di un'unione discriminata corrisponde esattamente a uno dei casi denominati.

Un'unione discriminata si definisce con la parola chiave `type`, con i casi separati dal carattere pipe (`|`):

```fsharp
type Season =
    | Spring
    | Summer
    | Autumn
    | Winter
```

Ogni caso di un'unione discriminata può avere facoltativamente dei dati associati, e casi diversi possono avere tipi di dati diversi. Se nessuno dei casi ha dei dati associati, l'unione discriminata è simile a quello che in altri linguaggi viene di solito chiamato _enumerazione_ (o _enum_).

```fsharp
type Number =
    | Integer of int
    | Float of float
    | Invalid
```

Per creare un valore per un caso specifico basta riferirsi al suo nome (ad es. `Success`). Dato che i nomi dei casi sono soltanto funzioni costruttore, i dati associati possono essere passati come un normale argomento di una funzione. Se un'altra unione discriminata ha definito un caso con lo stesso nome, dovrai usare il nome completo (ad es. `Result.Success`).

```fsharp
let byName = Integer 2
let byFullName = Number.Invalid
```

Le unioni discriminate hanno l'_uguaglianza strutturale_, il che significa che due valori dello stesso caso e con gli stessi dati (facoltativi) sono equivalenti.

Anche se è possibile usare espressioni `if/elif/else` per lavorare con le unioni discriminate, il modo consigliato per farlo è tramite i criteri di ricerca, usando il _criterio identificatore_:

```fsharp
let describe number =
    match number with
    | Integer i -> sprintf "Integer: %d" i
    | Float d  -> sprintf "Float: %f" d
    | Invalid   -> "Invalid"
```
