# Informazioni

Molti operatori possono anche essere usati come [assegnazioni composte][compound-assignment], che sono una notazione abbreviata in cui `x = op y` può essere scritto come `x op= y`:

```csharp
var features = PhoneFeatures.Call;
features |= PhoneFeatures.Text;
features &= ~PhoneFeatures.Call;
```
