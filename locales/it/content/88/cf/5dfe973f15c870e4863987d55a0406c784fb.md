# Risorse

## Apprendimento

- [Nim basics](https://narimiran.github.io/nim-basics/): per programmatori principianti.
- [Nim tutorial, part 1](https://nim-lang.org/docs/tut1.html): per chi ha già qualche esperienza di programmazione.
- [Learn X in Y minutes for Nim](https://learnxinyminutes.com/docs/nim/): una panoramica della sintassi.
- [Nim for Python programmers](https://github.com/nim-lang/Nim/wiki/Nim-for-Python-Programmers)
- [Nim for C programmers](https://github.com/nim-lang/Nim/wiki/Nim-for-C-programmers)
- [Nim in Action](https://www.manning.com/books/nim-in-action): disponibile come libro stampato o come eBook.

Per saperne di più, consulta la pagina ufficiale [Learn Nim](https://nim-lang.org/learn.html).
