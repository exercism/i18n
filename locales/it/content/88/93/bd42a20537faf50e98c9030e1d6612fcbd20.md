# Istruzioni

In questo esercizio lavorerai con i conti di risparmio. Ogni anno, il saldo del tuo conto di risparmio viene aggiornato in base al suo tasso di interesse. Il tasso di interesse che la tua banca ti offre dipende dalla quantità di denaro presente sul conto (il suo saldo):

- 3,213% per un saldo negativo (che comporta un interesse negativo).
- 0,5% per un saldo positivo inferiore a `1000` dollari.
- 1,621% per un saldo positivo maggiore o uguale a `1000` dollari e inferiore a `5000` dollari.
- 2,475% per un saldo positivo maggiore o uguale a `5000` dollari.

Ogni anno il governo ti permette di donare in beneficenza una percentuale del tuo denaro, esentasse. Dato che sei una brava persona, se alla fine dell'anno il tuo saldo risulta positivo prendi la percentuale esentasse e la raddoppi, arrotondando per difetto al dollaro intero più vicino. Non ti dispiace pagare le tasse sulla seconda metà della donazione.

Hai tre attività, ognuna delle quali riguarderà il tuo saldo e il suo tasso di interesse.

## 1. Calcola il tasso di interesse

Implementa la funzione `interestRate` per calcolare il tasso di interesse in base al saldo indicato:

```fsharp
interestRate 200.75m
// => 0.5f
```

Nota che il valore restituito è un `single`.

## 2. Calcola l'interesse

Implementa il metodo `interest` per calcolare l'interesse in base al saldo indicato:

```fsharp
interest 200.75m
// => 1.00375m
```

Nota che il valore restituito è un `decimal`.

## 3. Calcola l'aggiornamento annuale del saldo

Implementa la funzione `annualBalanceUpdate` per calcolare l'aggiornamento annuale del saldo, tenendo conto del tasso di interesse:

```fsharp
annualBalanceUpdate 200.75m
// => 201.75375m
```

Nota che il valore restituito è un `decimal`.

## 4. Calcola quanti soldi donare

Implementa la funzione `amountToDonate` per calcolare quanti soldi donare in beneficenza, in base al saldo e alla percentuale esentasse che il governo concede:

```fsharp
let balance = 550.5m
let taxFreePercentage = 2.5
amountToDonate balance taxFreePercentage
// => 27
```

Nota che il valore restituito è un `int`.
