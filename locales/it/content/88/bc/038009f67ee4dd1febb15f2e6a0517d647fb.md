# Ordinamento

Mettere le cose in ordine è così comune che la libreria lo fa per te.

```sather
   scores : ARRAY{INT} := |3, 1, 2|;
   scores.sort;              -- 1, 2, 3
```

`sort` funziona con qualsiasi cosa che sappia già confrontarsi: i numeri e le stringhe lo sanno fare, perché hanno un `is_lt`.

## Ordinare secondo una regola propria

La maggior parte degli ordinamenti non è quello predefinito. La classifica di netball non è in ordine alfabetico né per lunghezza del nome: è per punti, e poi per differenza reti per le squadre a pari punti. Non c'è modo che `ARRAY` lo indovini.

Quindi passi l'ordinamento dall'esterno, come routine vincolata:

```sather
   before(a, b : STR) : BOOL is
      return a.size < b.size;
   end;

   ...

   words.insertion_sort_by(bind(before(_, _)));
```

`insertion_sort_by` accetta un `ROUT{T,T}:BOOL`, cioè una routine che prende due degli elementi da ordinare e risponde se il primo va prima del secondo. La chiama tutte le volte che serve e mette l'array nell'ordine che le risposte implicano.

`understudy` serviva proprio a questo. La libreria sa come ordinare, ma non sa nulla della tua idea di ordine: la routine vincolata è il punto in cui le due cose si incontrano.

## Scrivere il confronto

La routine risponde **true quando il primo argomento viene prima**.

```sather
   -- shortest first
   return a.size < b.size;

   -- longest first: turn it round
   return a.size > b.size;
```

Per una regola fatta di più parti, affronta le parti in ordine di importanza:

```sather
   higher(a, b : TEAM) : BOOL is
      if a.points /= b.points then
         return a.points > b.points;      -- more points comes first
      end;
      return a.difference > b.difference; -- level: better difference wins
   end;
```

Il primo `if` decide ogni volta che i punti sono diversi. Solo quando sono uguali la seconda riga ha voce in capitolo. Scrivere prima il criterio di spareggio significherebbe che i punti non avrebbero mai contato.

## Ordinare modifica l'array

`insertion_sort_by` mette in ordine l'array stesso e non restituisce nulla:

```sather
   teams.insertion_sort_by(bind(higher(_, _)));   -- teams is now sorted
```

Se l'ordine originale conta, ordina una copia:

```sather
   ranked ::= teams.copy;
   ranked.insertion_sort_by(bind(higher(_, _)));
   return ranked;
```
