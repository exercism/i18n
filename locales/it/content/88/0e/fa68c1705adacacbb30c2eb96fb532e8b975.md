# Introduzione

## Espressioni regolari

Le espressioni regolari in Gleam seguono la specifica **PCRE** (**P**erl **C**ompatible **R**egular **E**xpressions), come in altri linguaggi diffusi come Java, JavaScript o Ruby.

Il modulo `gleam/regexp` del pacchetto `gleam_regexp` offre funzioni per lavorare con le espressioni regolari.

~~~~exercism/note
Questo esercizio presuppone che tu conosca già la sintassi delle espressioni regolari, comprese classi di caratteri, quantificatori, gruppi e catture.

Se hai bisogno di rinfrescare le tue conoscenze sulle espressioni regolari, dai un'occhiata a una di queste risorse: [Regular-Expressions.info](https://www.regular-expressions.info), [Rex Egg](https://www.rexegg.com/), [RegexOne](https://regexone.com/), [Regular Expressions 101](https://regex101.com/), [RegExr](https://regexr.com/).
~~~~

Il modo più comune per creare espressioni regolari è usare la funzione `regexp.from_string`.

```gleam
let assert Ok(re) = regexp.from_string("test")
```

Le funzioni di creazione delle espressioni regolari restituiscono un errore se la sintassi dell'espressione regolare non è valida, quindi qui è stato usato un let-assertion per assicurarsi che l'espressione regolare sia valida.

La funzione `regexp.check` può essere usata per verificare se un'espressione regolare corrisponde a una stringa.

```gleam
let assert Ok(re) = regexp.from_string("test")

regexp.check(re, "this is a test")
// -> True

regexp.check(re, "this is too")
// -> False
```


### Catture

Se vuoi catturare sottostringhe con un'espressione regolare, puoi usare la funzione `regexp.scan` per ottenere un array di corrispondenze.

```gleam
let assert Ok(re) = regexp.from_string("[oi]n a (\\w+)")
regexp.scan(with: re, content: "I am on a boat in a lake.")
// -> [
//   Match(
//     content: "on a boat",
//     submatches: [Some("boat")]
//   ),
//   Match(
//     content: "in a lake",
//     submatches: [Some("lake")]
//   )
// ]
```

### Modificatori

Il comportamento di un'espressione regolare può essere modificato creandola con la funzione `regexp.compile` e passando delle opzioni.

```gleam
let options = regexp.Options(case_insensitive: True, multi_line: False)
let assert Ok(re) = regexp.compile("[A-Z]", with: options)
regexp.check(re, "abc123")
// -> True
```
