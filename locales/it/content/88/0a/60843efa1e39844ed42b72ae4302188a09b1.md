# Introduzione

In Cairo, gli smart pointer sono strutture dati avanzate che garantiscono una gestione della memoria sicura ed efficiente, aggiungendo funzionalità di sicurezza ai puntatori normali e prevenendo problemi comuni come la dereferenziazione di puntatori nulli o l'accesso a memoria non inizializzata.

## Che cos'è uno smart pointer?

Uno smart pointer si comporta come un puntatore normale, ma tiene traccia della proprietà e garantisce un accesso sicuro alla memoria, prevenendo problemi come la dereferenziazione di puntatori nulli o penzolanti.

## Tipi di smart pointer

Cairo fornisce diversi tipi di smart pointer, come `Box<T>` e `Nullable<T>`:

- **`Box<T>`**: memorizza i dati in uno speciale segmento di memoria, ideale per dati di grandi dimensioni o di dimensione dinamica.
                Permette di trasferire la proprietà senza copiare i dati.
- **`Nullable<T>`**: punta a un valore valido di tipo `T` oppure a `null`, utile per gestire valori opzionali.

## Sicurezza della memoria

Gli smart pointer aiutano a prevenire accessi non sicuri alla memoria, garantendo che la memoria venga deallocata automaticamente quando non serve più, riducendo così il rischio di perdite di memoria.

### Esempio: usare `Box<T>` per i tipi ricorsivi

Gli smart pointer come `Box<T>` permettono di gestire in modo sicuro i tipi ricorsivi, come in un albero binario, allocando la memoria in modo efficiente ed evitando la ricorsione infinita.

```rust
use core::box::{BoxTrait};

#[derive(Copy, Drop)]
enum BinaryTree {
    Leaf: u32,
    Node: (u32, Box<BinaryTree>, Box<BinaryTree>),
}

fn main() {
    let leaf1 = BinaryTree::Leaf(1);
    let leaf2 = BinaryTree::Leaf(2);
    let node = BinaryTree::Node((3, BoxTrait::new(leaf1), BoxTrait::new(leaf2)));
    println!("{:?}", node);
}
```

## Vantaggi in termini di prestazioni

Gli smart pointer migliorano le prestazioni passando riferimenti ai dati invece di copiare grandi strutture, riducendo il sovraccarico di memoria.

```rust
// `Cart` is a large struct that contains a lot of information
fn pass_pointer(cart: Box<Cart>) {
    let cart = cart.unbox();
    println!("{} is shopping today and bought {} items", cart.buyer, cart.items);
}
```
