# Istruzioni

Il tuo amico, un artista in erba, ti ha contattato con un'idea per un progetto. Uniamo la sua creatività visiva alla tua competenza tecnica. È il momento di cimentarci con l'[arte generativa][generative-art]!

I vincoli aiutano la creatività e accorciano le scadenze: avete così deciso di limitare il vostro capolavoro a una sola forma, il cerchio. Però ci saranno molti cerchi. E potranno muoversi! Lo chiamerai... puntini danzanti.

Il tuo amico vorrà sicuramente ideare nuovi ed elaborati movimenti per i puntini, perciò inizierai a programmare creando un'architettura che ti permetterà di definire facilmente nuove animazioni in seguito.

## 1. Definire il comportamento dell'animazione

Ogni modulo di animazione deve implementare due callback: `init/1` e `handle_frame/3`. Definiscile nel modulo `Animation`.

Definisci la callback `init/1`. Deve accettare un argomento di tipo `opts` e restituire una tupla `{:ok, opts}` oppure una tupla `{:error, error}`. Le implementazioni di questa callback controlleranno se le opzioni date sono valide per questo particolare tipo di animazione.

Definisci la callback `handle_frame/3`. Deve accettare tre argomenti: il puntino, un numero di frame e le opzioni. Deve restituire sempre un puntino. Le implementazioni di questa callback modificheranno gli attributi del puntino in base al numero di frame corrente e alle opzioni dell'animazione.

## 2. Fornire un'implementazione predefinita della callback `init/1`

Il comportamento `Animation` dovrebbe essere facile da incorporare in altri moduli chiamando `use DancingDots.Animation`.

Per farlo, implementa la macro `__using__` nel modulo `Animation` in modo che imposti il modulo `Animation` come comportamento dell'altro modulo. Deve anche fornire un'implementazione predefinita della callback `init/1`. L'implementazione predefinita di `init/1` deve restituire le opzioni date invariate.

```elixir
defmodule MyCustomAnimation do
  use DancingDots.Animation
end

MyCustomAnimation.init(some_option: true)
# => {:ok, [some_option: true]}
```

## 3. Implementare l'animazione `Flicker`

Usa il comportamento `Animation` per implementare un'animazione a sfarfallio.

Deve usare la callback `init/1` predefinita perché non accetta opzioni.

Implementa la callback `handle_frame/3`, che gestisce un singolo frame. Se il numero di frame è un multiplo di quattro, la funzione deve restituire il puntino con metà della sua opacità originale. Negli altri frame, deve restituire il puntino invariato.

I frame si contano da `1`. Il puntino passato a `handle_frame/3` è sempre il puntino nel suo stato originale, non nello stato del frame precedente.

```elixir
dot = %DancingDots.Dot{x: 100, y: 100, radius: 24, opacity: 1}

DancingDots.Flicker.handle_frame(dot, 1, [])
# => %DancingDots.Dot{opacity: 1, radius: 24, x: 100, y: 100}

DancingDots.Flicker.handle_frame(dot, 4, [])
# => %DancingDots.Dot{opacity: 0.5, radius: 24, x: 100, y: 100}
```

## 4. Implementare l'animazione `Zoom`

Usa il comportamento `Animation` per implementare un'animazione di zoom.

Questa animazione accetta un'opzione: velocity. velocity può essere un numero qualsiasi. Se è negativa, il puntino viene rimpicciolito invece che ingrandito.

Implementa la callback `init/1`. Deve verificare che le opzioni passate siano una keyword list con una chiave `:velocity`. Il valore di velocity deve essere un numero. Se non è un numero, restituisci l'errore `"The :velocity option is required, and its value must be a number. Got: #{inspect(velocity)}"`.

Implementa la callback `handle_frame/3`. Deve restituire il puntino con il raggio aumentato di (il numero di frame corrente meno uno) per velocity.

I frame si contano da `1`. Il puntino passato a `handle_frame/3` è sempre il puntino nel suo stato originale, non nello stato del frame precedente.

```elixir
DancingDots.Zoom.init(velocity: nil)
# => {:error, "The :velocity option is required, and its value must be a number. Got: nil"}

dot = %DancingDots.Dot{x: 100, y: 100, radius: 24, opacity: 1}

DancingDots.Zoom.handle_frame(dot, 1, velocity: 10)
# => %DancingDots.Dot{radius: 24, opacity: 1, x: 100, y: 100}

DancingDots.Zoom.handle_frame(dot, 2, velocity: 10)
# => %DancingDots.Dot{radius: 34, opacity: 1, x: 100, y: 100}
```
