# Introduzione

Il principale costrutto orientato agli oggetti in C# è la _classe_, una combinazione di dati (_campi_) e comportamento (_metodi_). I campi e i metodi di una classe sono noti come i suoi _membri_.

L'accesso ai membri può essere limitato tramite i modificatori di accesso, i due più comuni dei quali sono:

- `public`: il membro è accessibile da qualsiasi codice (nessuna restrizione).
- `private`: il membro è accessibile solo dal codice della stessa classe.

Puoi pensare a una classe come a un modello per creare istanze di quella classe. Per creare un'istanza di una classe (nota anche come _oggetto_) si usa la parola chiave `new`:

```csharp
class Car
{
}

// Create two car instances
var myCar = new Car();
var yourCar = new Car();
```

I campi hanno un tipo e possono essere definiti ovunque all'interno di una classe.
I campi pubblici si definiscono in PascalCase, mentre i campi privati si definiscono in camelCase e hanno come prefisso un underscore `_`:

```csharp
class Car
{
    // Accessible by anyone
    public int Weight;

    // Only accessible by code in this class
    private string _color;
}
```

Si può assegnare facoltativamente un valore iniziale a un campo. Se un campo _non_ specifica un valore iniziale, gli verrà assegnato il valore predefinito del suo tipo. I valori dei campi di un'istanza si possono leggere e aggiornare usando la notazione con il punto.

```csharp
class Car
{
    // Will be set to specified value
    public int Weight = 2500;

    // Will be set to default value (0)
    public int Year;
}

var newCar = new Car();
newCar.Weight; // => 2500
newCar.Year;   // => 0

// Update value of the field
newCar.Year = 2018;
```

I campi privati vengono di solito aggiornati come effetto collaterale della chiamata a un metodo. Questi metodi di solito non restituiscono alcun valore; in tal caso il tipo restituito deve essere `void`:

```csharp
class CarImporter
{
    private int _carsImported;

    public void ImportCars(int numberOfCars)
    {
        // Update private field from public method
        _carsImported = _carsImported + numberOfCars;
    }
}
```
