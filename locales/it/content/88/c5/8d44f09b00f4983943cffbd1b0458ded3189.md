# Introduzione

In Factor i caratteri sono numeri interi, cioè punti di codice Unicode, quindi gli operatori numerici `<`, `>`, `=` danno direttamente un ordinamento che distingue maiuscole e minuscole. Il vocabolario [`unicode`][unicode] aggiunge predicati che tengono conto di Unicode e la conversione di maiuscole e minuscole per singoli caratteri.

## Predicati sui caratteri

```
LETTER?  ( c -- ? )    ! uppercase letter
letter?  ( c -- ? )    ! lowercase letter
Letter?  ( c -- ? )    ! letter, either case
digit?   ( c -- ? )    ! decimal digit
blank?   ( c -- ? )    ! whitespace
```

```factor
USING: unicode ;

CHAR: A LETTER? .    ! => t
CHAR: a letter? .    ! => t
CHAR: 7 digit?  .    ! => t
```

## Conversione tra maiuscole e minuscole

`ch>upper` e `ch>lower` trasformano un singolo carattere. Le varianti `>upper` e `>lower`, a livello di stringa, le applicano a ogni carattere di una stringa.

```factor
CHAR: a ch>upper .   ! => 65   (which is CHAR: A)
"Hello" >upper .     ! => "HELLO"
```
