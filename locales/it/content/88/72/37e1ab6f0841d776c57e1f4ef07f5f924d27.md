# Introduzione

Nel concetto `Types`, abbiamo imparato che:

- I tipi in Julia formano una gerarchia.
- Ogni tipo ha un supertipo.
- `Any` è in cima alla gerarchia ed è il suo stesso supertipo.
- I tipi _possono_ avere sottotipi, e quelli che ne hanno sono chiamati `abstract types`.
- I tipi senza sottotipi (i nodi foglia dell'albero) sono chiamati `concrete types`.
- I tipi indivisibili, come `Char` o `Int64`, sono chiamati `primitive types`.

Solo i tipi `primitive` seguono lo schema astratto-concreto nella sua forma semplice.

Un esempio di tipi che non sono primitivi sono le collezioni, come `Vector` o `Set`.

```julia-repl
julia> isprimitivetype(Int)
true

julia> isprimitivetype(Vector)
false
```

_Una collezione di cosa?_

Ogni `Vector` (o `Set`) è una collezione di elementi con un tipo uniforme, che può essere specificato con un _parametro_ tra parentesi graffe (`{ }`), oppure omesso, lasciando che sia l'inferenza di tipo a determinarlo.

```julia-repl
julia> v = [1, 2, 3]
3-element Vector{Int64}:
 1
 2
 3

julia> v8 = Vector{Int8}([2, 4, 6])
3-element Vector{Int8}:
 2
 4
 6
```

Questi `parametric types` sono una forma di `generic programming`, e molti linguaggi moderni hanno qualcosa di ampiamente equivalente, anche se con molte differenze nei dettagli.

## Tipi compositi parametrici

A volte vogliamo creare un tipo composito abbastanza flessibile (generico) da gestire tipi di campo diversi.

Possiamo ottenere questo risultato con un tipo fittizio nella definizione, di solito chiamato `T`.

```julia-repl
julia> struct Point{T}
               x::T
               y::T
       end

# high definition version

julia> real_point = Point(7.3, 4.2)
Point{Float64}(7.3, 4.2)

julia> typeof(real_point)
Point{Float64}

# low definition version

julia> int8point = Point{Int8}(17, 23)
Point{Int8}(17, 23)

julia> typeof(int8point)
Point{Int8}

julia> Point(Int8(17), Int8(23))
Point{Int8}(17, 23)
```

Naturalmente, questo approccio funziona anche con le collezioni nei campi:

```julia-repl
julia> struct Record{T}
           data::Vector{T}
           comment::String
       end

julia> rec = Record{Float64}([1.3, 5.2], "some data")
Record{Float64}([1.3, 5.2], "some data")

julia> rec.data
2-element Vector{Float64}:
 1.3
 5.2

julia> rec2 = Record{Int32}([3, 5], "more data")
Record{Int32}(Int32[3, 5], "more data")

julia> rec2.data
2-element Vector{Int32}:
 3
 5
```
