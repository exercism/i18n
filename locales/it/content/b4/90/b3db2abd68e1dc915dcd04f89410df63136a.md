# Introduzione

## Le proprietà

Una proprietà in C# è un membro di una classe che fornisce l'accesso ai dati contenuti in quella classe.
Chi la usa può impostare o recuperare (get) i dati. Le proprietà possono essere auto-implementate oppure avere un campo di supporto. Sono composte da una funzione di accesso set e/o da una funzione di accesso get.
In alcuni altri linguaggi un «mutator» è più o meno equivalente a una funzione di accesso set e un «accessor» è più o meno equivalente a una funzione di accesso get, anche se la composizione della sintassi è completamente diversa.

Quando si imposta una proprietà, il valore di input può essere convalidato, formattato o altrimenti manipolato; di fatto è possibile eseguire qualsiasi operazione programmatica accessibile al codice della classe.

Allo stesso modo, quando si recupera una proprietà, i dati possono essere calcolati o formattati e, ancora una volta, è possibile eseguire qualsiasi operazione programmatica a disposizione della classe.

Le proprietà hanno modificatori di accesso (`public`, `private` ecc.) allo stesso modo degli altri membri di una classe, ma la funzione di accesso set può avere un livello di accesso indipendente da quello della funzione di accesso di recupero (get), e viceversa. Una proprietà non deve per forza avere entrambe le funzioni di accesso: può averne una sola (get oppure set).

La sintassi di base per esprimere le proprietà può assumere due forme:

### Proprietà basate su campi o espressioni:

```csharp
private int myField;
public int MyProperty
{
    get { return myField; }
    set { myField = value; }
}
```

### Proprietà auto-implementate

```
public int MyProperty { get; private set; } = 42;
```

L'inizializzazione è facoltativa.
