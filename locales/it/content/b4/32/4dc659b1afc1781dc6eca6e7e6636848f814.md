# Istruzioni

La tua amica bibliotecaria ti ha chiesto di estendere il software della sua biblioteca per calcolare automaticamente le penali per il ritardo.
Il suo sistema attuale memorizza la data e l'ora esatte del prestito di un libro come stringa di data e ora [ISO8601](https://en.wikipedia.org/wiki/ISO_8601).
Gestisce una biblioteca locale in una piccola città del Ghana, che usa il fuso orario GMT (UTC +0), non usa l'ora legale e non deve preoccuparsi di altri fusi orari.

## 1. Analizzare le date e ore memorizzate

Implementa la funzione `LibraryFees.datetime_from_string/1`. Deve prendere come argomento una stringa di data e ora ISO8601 e restituire uno struct `NaiveDateTime`.

```elixir
LibraryFees.datetime_from_string("2021-01-01T13:30:45Z")
# => ~N[2021-01-01 13:30:45]
```

## 2. Determinare se un libro è stato preso in prestito prima di mezzogiorno

Se un libro viene preso in prestito prima di mezzogiorno, il lettore ha 28 giorni per restituirlo. Se viene preso in prestito a mezzogiorno o dopo, sono 29 giorni.

Implementa la funzione `LibraryFees.before_noon?/1`. Deve prendere uno struct `NaiveDateTime` e restituire un valore booleano.

```elixir
LibraryFees.before_noon?(~N[2021-01-12 08:23:03])
# => true
```

## 3. Calcolare la data di restituzione

In base alla data e ora del prestito, calcola la data di restituzione.

Implementa la funzione `LibraryFees.return_date/1`. Deve prendere uno struct `NaiveDateTime` e restituire uno struct `Date`, 28 o 29 giorni dopo.

```elixir
LibraryFees.return_date(~N[2020-11-28 15:55:33])
# => ~D[2020-12-27]
```

## 4. Determinare quanto in ritardo è avvenuta la restituzione del libro

La biblioteca applica una tariffa fissa per le restituzioni in ritardo. Per poter calcolare la penale, dobbiamo sapere quanti giorni dopo la data di restituzione il libro è stato effettivamente restituito.

Implementa la funzione `LibraryFees.days_late/2`. Deve prendere uno struct `Date`, la data di restituzione prevista, e uno struct `NaiveDateTime`, la data e ora della restituzione effettiva.

Se la data di restituzione effettiva cade in un giorno precedente o nello stesso giorno della data e ora di restituzione prevista, la funzione deve restituire 0. Altrimenti, deve restituire la differenza tra queste due date in giorni.

La biblioteca registra sia la data sia l'ora della restituzione effettiva del libro per fini statistici, ma non usa l'ora quando calcola le penali per il ritardo.

```elixir
LibraryFees.days_late(~D[2020-12-27], ~N[2021-01-03 09:23:36])
# => 7
```

## 5. Determinare se il libro è stato restituito di lunedì

La biblioteca ha un'offerta speciale per la restituzione dei libri di lunedì.

Implementa la funzione `LibraryFees.monday?/1`. Deve prendere uno struct `NaiveDateTime` e restituire un valore booleano.

```elixir
LibraryFees.monday?(~N[2021-01-03 13:30:45Z])
# => false
```

## 6. Calcolare la penale per il ritardo

Implementa la funzione `LibraryFees.calculate_late_fee/3`. Deve prendere tre argomenti: due stringhe di data e ora ISO8601, la data e ora del prestito e la data e ora della restituzione effettiva, e la penale per un giorno di ritardo. Deve restituire la penale totale in base a quanto in ritardo è avvenuta la restituzione effettiva del libro.

Includi l'offerta speciale del lunedì. Se restituisci il libro di lunedì, la penale è scontata del 50%, arrotondata per difetto.

```elixir
# Sunday, 7 days late
LibraryFees.calculate_late_fee("2020-11-28T15:55:33Z", "2021-01-03T13:30:45Z", 100)
# => 700

# one day later, Monday, 8 days late
LibraryFees.calculate_late_fee("2020-11-28T15:55:33Z", "2021-01-04T09:02:11Z", 100)
# => 400
```
