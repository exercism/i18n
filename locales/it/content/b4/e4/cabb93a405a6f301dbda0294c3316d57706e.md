# Introduzione

La maggior parte dei programmi ha delle dipendenze da alcune librerie. Gestirle a mano può essere complicato. Per fortuna, l'ecosistema Rust viene fornito di serie con `cargo`! `cargo` può gestire le dipendenze di un progetto.

In Rust sentirai spesso chiamare i pacchetti esterni «crates». Un crate è un'unità di compilazione in Rust. Un crate può essere compilato in un binario o in una libreria.

Il più delle volte, aggiungere una dipendenza esterna è semplice quanto aggiungere una riga al file `Cargo.toml`.
