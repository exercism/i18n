# Introduzione

AWK è un linguaggio molto piccolo e ha solo pochi tipi di dati di base.
In questa lezione esamineremo i numeri e le stringhe.

## Numeri

I numeri in AWK sono implementati come numeri in virgola mobile a doppia precisione.
Non c'è alcuna distinzione tra interi, numeri in virgola mobile e double.

AWK riconosce le costanti numeriche ottali (che iniziano con `0`) e le costanti numeriche esadecimali (che iniziano con `0x` o `0X`).

### Operazioni numeriche

Puoi usare i [normali operatori aritmetici][ops-arith] `+`, `-`, `*`, `/`, `%`.
L'operatore di elevamento a potenza è `^` (è specificato da POSIX), sebbene si possa usare anche `**`.
Esistono alcune [funzioni numeriche integrate][funcs-numeric], tra cui le funzioni trigonometriche, la generazione di numeri casuali e `int(x)` per troncare un numero all'intero più vicino tra _x_ e zero.

Non esistono _operatori_ bit a bit. 
gawk li implementa come funzioni.
Gli argomenti devono essere numeri non negativi.

| funzione            | operazione                                     |
| ------------------- | ---------------------------------------------- |
| `and(a, b [, ...])` | AND bit a bit degli argomenti                  |
| `or(a, b [, ...])`  | OR bit a bit degli argomenti                   |
| `xor(a, b [, ...])` | XOR bit a bit degli argomenti                  |
| `lshift(v, count)`  | il valore di _v_ spostato a sinistra di _count_ bit  |
| `rshift(v, count)`  | il valore di _v_ spostato a destra di _count_ bit |
| `compl(v, count)`   | complemento bit a bit di _v_                   |

## Stringhe

Le stringhe in AWK sono sequenze di caratteri.
Una costante stringa si specifica usando le virgolette doppie.

~~~~exercism/caution
GNU awk consente caratteri Unicode nelle stringhe: altre implementazioni di awk potrebbero non farlo.
Confrontando `gawk` con `mawk`, un altro popolare AWK:

```sh
$ echo "Hi friend 😀!" | gawk '{print length($3)}'
2
$ echo "Hi friend 😀!" | mawk '{print length($3)}'
5
```
~~~~

### Operazioni sulle stringhe

C'è una sola operazione sulle stringhe: la concatenazione.
La concatenazione non ha un operatore speciale;
basta mettere due stringhe una accanto all'altra per concatenarle:

```awk
BEGIN {
    hw = "Hello" "World"
    print hw
}
# => HelloWorld
```

~~~~exercism/note
`print` è un'**istruzione**, non una funzione.
`print` non richiede le parentesi.
~~~~

AWK ha una ricchezza di [funzioni per la manipolazione delle stringhe][funcs-string].
Le conosceremo in modo approfondito man mano che procediamo nel track.

## Conversione tra numeri e stringhe

Non esistono operatori espliciti per convertire tra numeri e stringhe.
AWK lo fa in modo implicito, in base al contesto del programma.
Questo rende molto semplice lavorare con i valori dei campi di input: in genere AWK fa semplicemente quello che vuoi che faccia.

* `print x + y` converte i valori delle variabili `x` e `y` in numeri grazie all'operazione numerica `+`.
* `print x y` converte i valori delle variabili `x` e `y` in stringhe grazie all'operazione di concatenazione.

Se vuoi essere esplicito, `0 + x` dà la rappresentazione numerica di _x_ e `"" x` dà la rappresentazione come stringa di _x_.

### Da stringhe a numeri

Il modo in cui AWK converte una stringa in un numero può confondere.
Un modo semplice per pensarci è questo: AWK legge i «caratteri numerici» dall'inizio di una stringa finché non trova un carattere «non numerico».
Alcuni esempi:

* `"2.5"` si converte nel numero `2.5`;
* `"1e3"` si converte nel numero `1000` (notazione scientifica);
* `"456abc"` si converte nel numero `456` (dato che `a` non è un «numerale», la conversione si ferma lì).
* `"abc789"` si converte nel numero `0` (non ci sono numeri all'**inizio** della stringa).

Tutti i dettagli sono [nel manuale][str-to-num].

## Determinare il tipo di una variabile

La [funzione `typeof(var)`][func-typeof] restituisce il tipo sotto forma di stringa.

```awk
BEGIN {
    x = "42"
    print x, typeof(x)
    x = x + 1           # type conversion
    print x, typeof(x)
}
```
produce
```none
42 string
43 number
```
