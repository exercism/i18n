# Istruzioni

Sei il commissario di bordo della nave e gestisci l'inventario della cambusa. L'inventario è una hashtable in cui ogni chiave è il nome di un articolo e il valore è la quantità disponibile.

## 1. Costruisci un inventario da una lista

Definisci `create-inventory` in modo che prenda una sequenza di nomi di articoli e restituisca una hashtable che associa ogni nome unico al suo conteggio.

```factor
{ "coal" "wood" "wood" "diamond" "diamond" "diamond" } create-inventory .
! => H{ { "coal" 1 } { "wood" 2 } { "diamond" 3 } }
```

## 2. Aggiungi altri articoli

Definisci `add-items` in modo che prenda un inventario e una sequenza di articoli e restituisca un nuovo inventario con i conteggi incrementati per ogni articolo elencato. L'inventario originale non deve essere modificato.

```factor
H{ { "coal" 1 } } { "wood" "iron" "coal" "wood" } add-items .
! => H{ { "coal" 2 } { "wood" 2 } { "iron" 1 } }
```

## 3. Decrementa i conteggi

Definisci `decrement-items` in modo che prenda un inventario e una sequenza di articoli e restituisca un nuovo inventario con i conteggi diminuiti di uno per ogni articolo elencato. I conteggi non devono mai scendere sotto zero e gli articoli non ancora presenti nell'inventario vanno lasciati fuori (non vengono inserite voci negative).

```factor
H{ { "coal" 3 } { "diamond" 1 } { "iron" 5 } }
{ "diamond" "coal" "iron" "iron" } decrement-items .
! => H{ { "coal" 2 } { "diamond" 0 } { "iron" 3 } }
```

## 4. Rimuovi completamente un articolo

Definisci `remove-item` in modo che prenda un inventario e un articolo e restituisca un nuovo inventario con quell'articolo rimosso. Se l'articolo non è presente, restituisci una copia invariata.

```factor
H{ { "coal" 2 } { "wood" 1 } { "diamond" 2 } } "coal" remove-item .
! => H{ { "wood" 1 } { "diamond" 2 } }
```

## 5. Elenca gli articoli disponibili

Definisci `list-inventory` in modo che prenda un inventario e restituisca un array di coppie `{ name quantity }` contenente solo gli articoli con quantità maggiore di zero, ordinati alfabeticamente per nome.

```factor
H{ { "coal" 7 } { "wood" 11 } { "diamond" 2 } { "iron" 7 } { "silver" 0 } }
list-inventory .
! => { { "coal" 7 } { "diamond" 2 } { "iron" 7 } { "wood" 11 } }
```
