# Informazioni

Un set è una collezione immutabile e non ordinata di valori unici. Tutti gli elementi di un set devono essere dello stesso tipo.

Il modulo `gleam/set` definisce il tipo `Set` e fornisce funzioni per lavorare con i set.

Puoi trasformare le liste in set e viceversa con `set.to_list` e `set.from_list`. L'ordine degli elementi di un set non è garantito.

```gleam
set.from_list([2, 3, 3, 3, 1, 1, 2])
// -> set.from_list([1, 2, 3])

set.to_list(set.from_list([2, 3, 3, 3, 1, 1, 2]))
// -> [1, 2, 3]
```

Puoi creare e popolare i set con `set.new`, `set.insert` e `set.delete`.

```gleam
set.new()
// -> set.from_list([])

let eighty_eight = set.from_list([88])

set.insert(eighty_eight, 88)
// -> set.from_list([88])

set.insert(eighty_eight, 89)
// -> set.from_list([88, 89])

set.delete(eighty_eight, 88)
// -> set.from_list([])

set.delete(eighty_eight, 89)
// -> set.from_list([88])
```

Puoi interrogare il contenuto di un set con le funzioni `set.contains` e `set.size`.

```gleam
set.contains(eighty_eight, 88)
// -> True

set.size(eighty_eight)
// -> 1
```

Puoi combinare i set con `set.union` e `set.intersect`.

```gleam
let a = set.from_list([1, 5, 10])
let b = set.from_list([1, 2, 3, 4, 5])

set.union(a, b)
// -> set.from_list([1, 2, 3, 4, 5, 10])

set.intersection(a, b)
// -> set.from_list([1, 5])
```

Puoi anche filtrare i set.

```gleam
let is_small = fn(n) { x <= 3 }

set.filter(b, is_small)
// -> set.from_list([1, 2, 3])
```
