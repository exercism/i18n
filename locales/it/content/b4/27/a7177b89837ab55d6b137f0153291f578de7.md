## Variabili

Le variabili sono nomi simbolici, che si riferiscono a valori o a contenitori.
I nomi delle variabili possono iniziare con o senza un carattere speciale chiamato [sigil][sigils], seguito da un identificatore.
Un sigil può anche essere seguito da un [twigil][twigils].

Variabili con sigil diversi contengono tipi diversi di strutture dati.

```raku
my $scalar; # Assigned value will be stored as-is
my @array;  # Assigned value will be coerced into an array
my %hash;   # Assigned value will be coerced into a hash
my &code;   # Assigned value must be a code object
```

I twigil che vedrai più comunemente sono `^` e `:`, che funzionano da scorciatoie per le firme dei blocchi di codice.
Il `^` è per i parametri posizionali.
Il `:` è per i parametri con nome.

```raku
{ $^a + $^b }; #`[same as] ->  $a,  $b { $a + $b }; # Called with (1, 2)
{ $:a + $:b }; #`[same as] -> :$a, :$b { $a + $b }; # Called with (a => 1, b => 2)
```

## Contenitori

I contenitori sono ciò che permette di modificare una variabile.

Le variabili dichiarate con `constant` e le variabili senza sigil (dichiarate con un `\` prima dell'identificatore) non hanno contenitori e si riferiscono direttamente ai valori.

```raku
my $foo = 1;
$foo = 2;

constant $bar = 3;
my \baz = 4;

# The following will fail
$bar = 5;
baz  = 6;
```

## Tipi

Le variabili possono essere dichiarate con un vincolo di tipo.
I vincoli di tipo possono anche avere coercizioni, passando un tipo accettato come argomento al tipo desiderato.

```raku
my Bool   $foo = True; # Booleans only.
my Bool() $bar = 0;    # Accepts type `Any`. Coerced to False.

my Str(Bool(Int)) $baz;
$baz = 1;   # "True"
$baz = "1"; # "1"
```

Usare i vincoli di tipo è un modo per sfruttare le routine multi-dispatch.

```raku
multi foo (Int $bar) { say 'Type of arg to $bar is Int!' }
multi foo (Str $bar) { say 'Type of arg to $bar is Str!' }
```

In Raku i tipi sono solo un altro tipo di oggetto.
Dichiarare una `class`, un `role` o un `enum` sono modi per creare i tuoi oggetti di tipo.
Per esempio, il tipo predefinito `Bool` è costruito con un enum: `enum Bool <False True>`.

Puoi anche creare vincoli di tipo semplici basati su altri tipi con la parola chiave `subset`.
Puoi limitare ulteriormente questo nuovo tipo usando una clausola `where`.
Una clausola `where` può essere usata anche in una firma.

```raku
subset PositiveInt of Int where * > 0;

sub is-even (PositiveInt $n where  %% 2) { say "$n is even!" }
```
