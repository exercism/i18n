# Informazioni sugli operatori aritmetici

## Operatori

Go supporta i seguenti operatori aritmetici:

| Operatore | Esempio        |
| -------- | -------------- |
| `+`      | `4 + 6 == 10`  |
| `-`      | `15 - 10 == 5` |
| `*`      | `2 * 3 == 6`   |
| `/`      | `13 / 3 == 4`  |
| `%`      | `13 % 3 == 1`  |

Nella divisione tra numeri interi, il resto viene scartato (ad esempio `5 / 2 == 2`).

L'operatore `+` concatena anche le stringhe: `"foo" + "bar" == "foobar"`.

## Aritmetica tra tipi diversi

Go non permette operazioni aritmetiche tra tipi numerici diversi:

```go
x := 42
n := 2.0
value := n * x // invalid operation: n * x (mismatched types float64 and int)
```

Gli operandi devono essere dello stesso tipo, il che a volte richiede una conversione esplicita:

```go
x := float64(42)
n := 2.0
value := n * x 
```

## Assegnazioni abbreviate

Ogni operatore ha una forma di assegnazione abbreviata che aggiorna la variabile sul posto:

```go
a := 1
a += 2 // same as a = a + 2 == 3

b := 2
b -= 2 // same as b = b - 2 == 0

c := 4
c *= 2 // same as c = c * 2 == 8

d := 8
d /= 2 // same as d = d / 2 == 4

e := 16
e %= 2 // same as e = e % 2 == 0
```

## Incremento e decremento

Quando vengono inserite dopo una variabile, le istruzioni di incremento (`++`) e decremento (`--`) aumentano o diminuiscono di 1 il valore numerico memorizzato nella variabile.
Inserirle prima di una variabile è un errore di sintassi.

```go
a := 10
a++ // same as a += 1, a == 11

b := 10
b-- // same as b -= 1, b == 9
```

Poiché sono istruzioni, non restituiscono un valore.
