# Suggerimenti

## Generale

- Non preoccuparti di come vengono ricavati gli argomenti: concentrati solo sul combinarli per restituire il risultato previsto.

## 1. Stabilire se pac-man può mangiare un fantasma

- La funzione deve restituire un valore [booleano][boolean].
- Puoi usare l'operatore [booleano][boolean] [`and/2`][boolean-and] per combinare gli argomenti e ottenere un risultato.

## 2. Stabilire se pac-man segna punti

- La funzione deve restituire un valore [booleano][boolean].
- Puoi usare l'operatore [booleano][boolean] [`or/2`][boolean-or] per combinare gli argomenti e ottenere un risultato.

## 3. Stabilire se pac-man perde

- La funzione deve restituire un valore [booleano][boolean].
- Puoi usare gli operatori [booleani][boolean] [`and/2`][boolean-and] ed [`not/1`][boolean-not] per combinare gli argomenti e ottenere un risultato.

## 4. Stabilire se pac-man vince

- La funzione deve restituire un valore [booleano][boolean].
- Puoi usare gli operatori [booleani][boolean] [`and/2`][boolean-and] ed [`not/1`][boolean-not] per combinare gli argomenti ed i risultati di una delle funzioni implementate in precedenza.

[boolean]: https://hexdocs.pm/elixir/basic-types.html#booleans-and-nil
[boolean-and]: https://hexdocs.pm/elixir/Kernel.html#and/2
[boolean-or]: https://hexdocs.pm/elixir/Kernel.html#or/2
[boolean-not]: https://hexdocs.pm/elixir/Kernel.html#not/1
