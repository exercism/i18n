# Introduzione

## Destrutturazione degli array

La sintassi di destrutturazione degli array di JavaScript è un modo conciso per estrarre valori da un array e assegnarli a variabili distinte.

In questo esempio, ogni valore dell'array `numberOfMoons` viene assegnato al suo pianeta corrispondente:

```javascript
const numberOfMoons = [0, 2, 14];
const [venus, mars, neptune] = numberOfMoons;

neptune;
// => 14
```

In breve:

- La sintassi permette di dare un nome agli elementi _posizionati_ di un array e anche di scambiare le variabili tramite riassegnazione.
- La sintassi di destrutturazione è disponibile all'interno dei parametri di una funzione e su qualsiasi iterabile.
- Lasciare una posizione senza nome (non scrivendo _nessun_ nome di variabile) ignora silenziosamente quella posizione.

## Destrutturazione degli oggetti

In JavaScript esiste anche la sintassi di destrutturazione per estrarre proprietà da un oggetto e assegnarle a variabili distinte.

In questo esempio, i simboli del tempo vengono estratti dall'oggetto `weather`:

```javascript
const weather = {
  sun: '☀️',
  sun_behind_small_cloud: '🌤️',
  sun_behind_cloud: '⛅',
  sun_behind_large_cloud: '🌥️',
  sun_behind_rain_cloud: '🌦️',
  cloud: '☁️',
  cloud_with_rain: '🌧️',
  cloud_with_snow: '🌨️',
  cloud_with_lightning: '🌩️',
  cloud_with_lightning_and_rain: '⛈️',
};

const { sun, cloud, cloud_with_lightning: thunder } = weather;

sun;
// => '☀️'

cloud;
// => '☁️'

thunder;
// => '🌩️'
```

In breve:

- La sintassi permette sia di estrarre le proprietà sia di estrarle e rinominarle.
- La sintassi di destrutturazione è disponibile all'interno dei parametri di una funzione.
