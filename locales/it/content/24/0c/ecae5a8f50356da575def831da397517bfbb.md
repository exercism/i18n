# Introduzione

I numeri interi non sono solo valori numerici: possiamo vederli anche come sequenze di bit. Il vocabolario [`math`][math] di Factor mette a disposizione le operazioni standard di basso livello su queste sequenze di bit, mentre il vocabolario [`math.bitwise`][bitwise] aggiunge qualche funzione ausiliaria per lavorare con valori a larghezza fissa.

## Scorrimento dei bit

`shift ( m n -- m' )` fa scorrere i bit di `m`. Un `n` *positivo* fa scorrere verso sinistra (moltiplicando per 2 a ogni passo); un `n` *negativo* fa scorrere verso destra (dividendo per 2 a ogni passo):

```factor
3 2 shift .     ! => 12   (3 << 2)
24 -3 shift .   ! => 3    (24 >> 3)
```

Per i numeri interi positivi, lo scorrimento a destra elimina i bit in fondo e riempie con zeri. Per i numeri interi *negativi*, lo `shift` di Factor è aritmetico: conserva il bit di segno e, concettualmente, riempie da sinistra con copie del bit di segno. (I numeri interi di Factor hanno precisione arbitraria, quindi «la sinistra» si estende quanto serve.)

## Logica bit a bit

Le quattro operazioni logiche di base sono:

```
bitor  ( x y -- z )   ! 1 in either operand
bitand ( x y -- z )   ! 1 in both operands
bitxor ( x y -- z )   ! 1 in exactly one operand
bitnot ( x   -- z )   ! flip every bit
bit?   ( x n -- ? )   ! true when bit at position n is set
```

```factor
0b1011 0b0010 bitor .    ! => 11  (0b1011)
0b1011 0b0010 bitand .   ! => 2   (0b0010)
0b1011 0b0010 bitxor .   ! => 9   (0b1001)
0b1011 bitnot .          ! => -12
0b1011 0 bit? .          ! => t   (low bit is set)
0b1011 2 bit? .          ! => f   (bit 2 is clear)
```

Il `bitnot` di `0b1011` è `-12` perché i numeri interi di Factor hanno precisione arbitraria: invertire i bit di `0b1011` significa, concettualmente, «tutti uno con i quattro bit più bassi diventati `0100`», che letto come bignum con segno vale `-12`.

## Trattare un valore come N bit

`bits ( x n -- y )` di `math.bitwise` maschera `x` sui suoi `n` bit più bassi. Questo è il modo in Factor per «reinterpretare un valore come numero intero senza segno a N bit»:

```factor
-1 8 bits .              ! => 255   (lowest 8 bits of -1 are all 1)
-2144333657 32 bits .    ! => 2150633639
```

Il secondo esempio è importante per questo esercizio. Se parti da un valore Int32 negativo in complemento a due e vuoi farlo scorrere a destra «logicamente» (riempiendo con zeri da sinistra) di `amount`, l'idioma di Factor è:

```
( value -- shifted )
32 bits  amount neg  shift
```

Esegui prima la maschera a 32 bit per passare all'interpretazione senza segno, poi applica lo shift. Dato che il valore mascherato non è negativo, `shift` si limita a eliminare i bit in fondo e a riempire con zeri.
