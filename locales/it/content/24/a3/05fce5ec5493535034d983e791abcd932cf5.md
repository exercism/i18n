# Introduzione

Trattandosi di un linguaggio funzionale, in Clojure le funzioni sono cittadini di prima classe. Questo significa che possono essere passate ad altre funzioni e generate da esse proprio come dei dati. Clojure in particolare offre un ricco insieme di funzioni di ordine superiore che derivano nuove funzioni a partire da quelle esistenti. Qui esploreremo quattro casi importanti: `partial`, `comp`, `memoize` e `juxt`. Queste funzioni che generano funzioni rientrano in una categoria più ampia di funzioni di ordine superiore, come `map`, `reduce`, `apply`, `complement`, tanto per citarne alcune, che operano su funzioni esistenti.

## partial

In generale, data una funzione esistente `my-function`, con parametri `p1, p2, ..., pN`, possiamo fissare alcuni dei suoi parametri `p1, p2, ..., pM` assegnando loro valori costanti `v1, v2, ..., vM`. Per farlo applichiamo `partial` nel modo seguente: `(partial my-function v1 v2 ... vM)`.

Il risultato è una nuova funzione che applica quella originale `my-function` fissando `p1=v1, p2=v2, ..., pM=vM`. La nostra nuova funzione prende come input i parametri rimanenti `pM+1, pM+2, ..., pN`, i cui valori non sono stati indicati quando abbiamo applicato `partial`:

```clojure
(def my-new-function 
  (partial my-function v1 v2 ... vM))
(my-new-function xM+1 xM+2 ... xN)
; => equivalent to (my-function v1 v2 ... vM xM+1 xM+2 ... xN)
```

Come semplice esempio, definiamo una funzione `inc-by-9` che aumenta di 9, una quantità fissa, qualunque valore le passiamo. Potremmo implementare una funzione del genere nel modo seguente:

```clojure
(def inc-by-9 (partial + 9))
(inc-by-9 5)
; => 14
```

Come secondo esempio, abbiamo una funzione `generic-greetings` che usa il nome della persona che vogliamo salutare insieme a un messaggio testuale iniziale e uno finale:

```clojure
(defn generic-greetings
  [initial-text final-text name]
  (println (str initial-text name final-text)))
```

E usiamo `partial` per usare sempre uno specifico messaggio di saluto:

```clojure
(def say-hello-and-how-are-you-doing 
  (partial generic-greetings "Hello " ", how are you doing?"))
(say-hello-and-how-are-you-doing "Mary")
; => Hello Mary, how are you doing?
```

## comp

`comp` può essere usato per creare una composizione di un numero qualsiasi di funzioni che vogliamo comporre. In generale, comporre `N` funzioni `f1, f2, ..., fN` significa applicare queste funzioni in ordine sequenziale, passando l'output della funzione precedente a quella successiva. In notazione matematica si esprime così:

```
f1 (f2 (... fN(x)))
```

In Clojure, questo equivale a fare:
```clojure
(f1 (f2 (... (fN x))))
```

Usando comp, possiamo creare una nuova funzione che esegue questa composizione al posto nostro:

```clojure
(def my-function-composition 
  (comp f1 f2 ... fN))
(my-function-composition x)
; equivalent to
(f1 (f2 (... (fN x))))
```

Come esempio, supponiamo di voler sommare una serie di numeri e poi moltiplicare il risultato per 6. Possiamo farlo nel modo seguente:


```clojure
(def six-times-result-sum 
  (comp (partial * 6) +))
(six-times-result-sum 3 2)
; = ((partial * 6) (+ 3 2))
; = (* 6 (+ 3 2))
; = 30
```

## memoize

`memoize` permette di riutilizzare risultati calcolati in precedenza e associati a un dato input. A parità di input, la funzione *memorizzata* restituisce lo stesso risultato senza doverlo ricalcolare. Sfrutta il fatto che le funzioni di `clojure` sono, per impostazione predefinita, *referenzialmente trasparenti*: a parità di input producono sempre lo stesso output, il che rende possibile riutilizzare con facilità i calcoli precedenti.

Per vedere come funziona, usiamo un caso sintetico in cui la funzione resta in attesa per due secondi prima di produrre l'output, così da poter confrontare facilmente il *tempo di calcolo* prima e dopo l'uso di `memoize`.

```clojure
(defn my-time-consuming-fn
    "Original, time-consuming function"
    [x]
    (Thread/sleep 2000)
    (* x 2)
)

; We measure the time it takes for the original function
(time (my-time-consuming-fn 3))
; => "Elapsed time: 2007.785622 msecs"
; => 6

; We define a memoized function
(def my-memoized-fn 
  (memoize my-time-consuming-fn) )

; We call the memoized function and measure its execution time. 
; The first execution actually runs the function, taking
; similar time as the original.
(time (my-memoized-fn 3))
; => "Elapsed time: 2001.364052 msecs"
; => 6

; Subsequent calls reuse the previous computation, taking less
; time. Time is further reduced in additional calls.
(time (my-memoized-fn 3))
; => "Elapsed time: 1.190291 msecs"
; => 6

(time (my-memoized-fn 3))
; => "Elapsed time: 0.043701 msecs"
; => 6

; Changing the input makes the function be executed, so that
; we observe a similar computation time as the original 
(time (my-memoized-fn 4))
; => "Elapsed time: 2000.29306 msecs"
; => 8

; Again, repeating the same input will make the 
; execution be skipped, and the associated output returned
(time (my-memoized-fn 4))
; => "Elapsed time: 0.043701 msecs"
; => 8
```

## juxt

`juxt` genera una funzione che applica, da sinistra a destra, le funzioni che le vengono passate. Il risultato è un vettore in cui i singoli risultati di ciascuna funzione sono le componenti del vettore:

```clojure
((juxt f g h) x) ; => [(f x) (g x) (h x)]
```

Come semplice esempio, generiamo una funzione che calcola il prodotto di x per fattori successivi, da 2 a 5:
```clojure
((juxt (partial * 2) (partial * 3) (partial * 4) (partial * 5)) 10) ; => [20 30 40 50]
```
