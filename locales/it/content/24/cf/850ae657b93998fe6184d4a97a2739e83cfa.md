# Introduzione

La memoria dinamica è implementata tramite funzioni di libreria che il programmatore usa per allocare e deallocare memoria a runtime.
Poiché è il programmatore a controllare l'allocazione e la deallocazione della memoria, la memoria dinamica è sicura quanto lo è il programmatore dagli errori umani.
Per questo motivo, la memoria dinamica è una delle principali fonti di bug di programmazione e uno dei principali bersagli degli attacchi informatici.

## malloc

`malloc` è una funzione dichiarata in `stdlib.h` che viene usata per allocare memoria dinamica.
Se l'allocazione ha successo, viene restituito un puntatore che punta all'indirizzo del primo byte della memoria allocata.
Se l'allocazione non ha successo, viene restituito `NULL`.
È prudente verificare che il risultato di `malloc` non sia `NULL` e gestire il fallimento in modo controllato.
Il puntatore restituito è di tipo `pointer-to-void`, che si può considerare all'incirca come un puntatore «generico» convertibile nel tipo specifico usato dalla memoria.
`malloc` ha un solo parametro: la dimensione in byte della memoria desiderata.
La dimensione totale per allocare un array è la dimensione del tipo di dato di ciascun elemento moltiplicata per il numero di elementi.
L'operatore `sizeof` è comunemente usato per ottenere la dimensione del tipo di dato di ciascun elemento.
L'esempio seguente lo dimostra

```c
#include <stdio.h>
#include <stdlib.h>

int * my_function(int count) {
    // pointer-to-void from malloc is converted to a pointer-to-int
    int * numbers = malloc(sizeof(int) * count);
    return numbers;
}

int main() {
    int * numbers = my_function(3);
    if (!numbers) return -1;
    // printed The size of numbers is 8 bytes (can vary by system)
    printf("The size of numbers is %zu bytes\n", sizeof(numbers));
    numbers[0] = 1;
    numbers[1] = 2;
    numbers[2] = 3;
    // prints The first element of the array is 1
    printf("The first element of the array is %d\n", numbers[0]);
    // prints The second element of the array is 2
    printf("The second element of the array is %d\n", numbers[1]);
    // prints The third element of the array is 3
    printf("The third element of the array is %d\n", numbers[2]);
    free(numbers);
    numbers = NULL;
}
```

È importante ricordare che la memoria appena allocata da `malloc` non è inizializzata, ma può contenere valori spazzatura.
Nota che `sizeof` del puntatore `numbers` non è il numero di elementi dell'array, né la quantità totale di memoria allocata.
La dimensione del puntatore restituito da `malloc` è la dimensione di qualsiasi puntatore su quel particolare sistema.
Il codice di esempio è stato eseguito su un sistema a 64 bit, quindi la dimensione del puntatore era di 8 byte (moltiplicati per 8 bit per byte = 64 bit).
Il tipo del puntatore è stato convertito implicitamente da pointer-to-void a pointer-to-int.
Avrebbe anche potuto essere convertito esplicitamente in questo modo: `int * numbers = (int *) malloc(sizeof(int) * count);`.
Se i valori verranno sicuramente scritti prima di essere letti, usare `malloc` può essere un modo efficiente di allocare memoria.
Ma se c'è la possibilità che i valori vengano letti prima di essere inizializzati, usare `malloc` è rischioso.
Un modo più sicuro di allocare memoria è usare `calloc`, che inizializza a zero la memoria appena allocata.

Nota negli esempi sopra che è stato usato `free(numbers)`.

## free

`free` è una funzione dichiarata in `stdlib.h` che viene usata per deallocare memoria allocata dinamicamente.
La memoria allocata dinamicamente resta occupata finché non viene rilasciata da `free`.
Alcuni sistemi operativi possono liberare automaticamente la memoria allocata dinamicamente quando il programma termina, ma è buona norma non contarci.
`free` ha un solo parametro: un puntatore alla memoria che è stata allocata dinamicamente.
Un puntatore che non viene impostato a `NULL` dopo essere stato liberato si chiama dangling pointer.
Un dangling pointer può riferirsi a memoria diversa da quella a cui era destinato.
Di conseguenza, un dangling pointer può portare a corruzione dei dati e alla sostituzione ed esecuzione di codice arbitrario.
Un puntatore a memoria allocata che non è stato azzerato impostandolo a `NULL` può essere usato per violare il programma.
È buona norma impostare un puntatore a `NULL` dopo averlo passato a `free`.

## calloc

`calloc` è una funzione dichiarata in `stdlib.h` che serve sia ad allocare memoria dinamica sia a inizializzare a zero la memoria appena allocata.
Se l'allocazione ha successo, viene restituito un puntatore che punta all'indirizzo del primo byte della memoria allocata.
Se l'allocazione non ha successo, viene restituito `NULL`.
È prudente verificare che il risultato di `calloc` non sia `NULL` e gestire il fallimento in modo controllato.
Il puntatore restituito è di tipo `pointer-to-void`, che si può considerare all'incirca come un puntatore «generico» convertibile nel tipo specifico usato dalla memoria.
`calloc` ha due parametri.
Il primo parametro indica quanti elementi del tipo di dato specificato allocare.
Il secondo parametro indica la dimensione del tipo di dato specificato da allocare.

Nell'esempio seguente tutte le istruzioni `printf` dovrebbero mostrare sempre `0`, poiché `calloc` garantisce di azzerare i valori appena allocati.

```c
#include <stdio.h>
#include <stdlib.h>

int * my_function(int count) {
    // allocates the amount of bytes in an int, multiplied by count
    int * numbers = calloc(count, sizeof(int));
    return numbers;
}

int main() {
    int * numbers = my_function(3);
    if (!numbers) return -1;
    // prints The first element of the array is 0
    printf("The first element of the array is %d\n", numbers[0]);
    // prints The second element of the array is 0
    printf("The second element of the array is %d\n", numbers[1]);
    // prints The third element of the array is 0
    printf("The third element of the array is %d\n", numbers[2]);
    free(numbers);
    numbers = NULL;
}
```

## realloc

`realloc` è una funzione dichiarata in `stdlib.h` che serve ad espandere o ridurre memoria già allocata.
Se la riallocazione ha successo, viene restituito un puntatore che punta all'indirizzo del primo byte della memoria riallocata.
Se la riallocazione non ha successo, viene restituito `NULL`.
È prudente verificare che il risultato di `realloc` non sia `NULL` e gestire il fallimento in modo controllato.
`realloc` ha due parametri.
Il primo parametro è un puntatore alla memoria esistente da riallocare.
Il secondo parametro indica la dimensione in byte della memoria riallocata.
I valori impostati prima che la memoria venga espansa vengono conservati.
È importante ricordare che la memoria aggiunta quando si espande la memoria non viene inizializzata a zero e i suoi valori potrebbero essere qualsiasi cosa.
Inoltre, anche la memoria rimossa quando si riduce la memoria non viene inizializzata e potrebbe conservare i valori.
L'esempio seguente mostra come espandere e ridurre un array

```c
#include <stdio.h>
#include <stdlib.h>

int * my_function(int count) {
    // allocates the amount of bytes in an int, multiplied by count
    int * numbers = calloc(count, sizeof(int));
    return numbers;
}

int * my_function_2 (int * ptr , int count) {
    // reallocates the memory to the size of an int multiplied by count
    int * numbers = realloc(ptr, sizeof(int) * count);
    // if realloc fails, exit the program
    if (!numbers) exit(-1);
    return numbers;
}

int main() {
    int * numbers = my_function(3);
    if (!numbers) return -1;
    numbers[0] = 1;
    numbers[1] = 2;
    numbers[2] = 3;
    // expand the size of the array
    numbers = my_function_2(numbers, 6);
    // prints The first element of the array is 1
    printf("The first element of the array is %d\n", numbers[0]);
    // prints The sixth element of the array is [whatever is there]
    // the additional memory is not initialized, so it could be
    // 0 or it could be 18728 or anything else
    printf("The sixth element of the array is %d\n", numbers[5]);
    numbers[5] = 6;
    // shrink the size of the array
    numbers = my_function_2(numbers, 3);
    // prints The sixth element of the array is [whatever is there]
    // the removed memory is not initialized, so it could be
    // 6 or it could be 43164 or anything else
    printf("The sixth element of the array is %d\n", numbers[5]);
}
```
