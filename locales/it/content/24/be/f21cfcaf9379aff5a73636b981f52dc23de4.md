# Numeri

Crystal ha un tipo, `Number`, che è il tipo base di tutti i tipi numerici.
All'interno del tipo Number ci sono due sottotipi principali: [`Int`][int] e [`Float`][float].

`Int` è l'abbreviazione di «integer» e rappresenta i numeri interi.
`Int` può essere sia negativo che positivo, senza punto decimale.

```crystal
1.class
# => Int32

-1.class
# => Int32
```

`Float` rappresenta i numeri con un punto decimale.
I `Float` possono essere sia negativi che positivi.

```crystal
10.5.class
# => Float64
```

## Convertire tra `Int` e `Float`

Usando i metodi «to_i» e «to_f», puoi convertire tra `Int` e `Float`.
Il numero viene arrotondato per difetto quando si converte da `Float` a `Int`.

```crystal
1.to_f
# => 1.0

1.0.to_i
# => 1

1.9.to_i
# => 1
```

## Operatori aritmetici

Puoi usare i [operatori aritmetici di base][math] su `Int` e `Float`.
Gli operatori sono `+`, `-`, `*`, `/` e `%`.
Quando usi questi operatori, puoi combinare liberamente `Int` e `Float`.

### Addizione, sottrazione e moltiplicazione

L'operatore `+` si usa per l'addizione, l'operatore `-` per la sottrazione e l'operatore `*` per la moltiplicazione.

| Operatore | Esempio        |
| -------- | -------------- |
| `+`      | `4 + 6 => 10`  |
| `-`      | `15 - 10 => 5` |
| `*`      | `2 * 3 => 6`   |

### Divisione

La divisione si usa per dividere i numeri.
L'operatore `/` si usa per la divisione.
Il risultato sarà sempre un Float.

```crystal
4 / 2
# => 2.0

4.0 / 2
# => 2.0
```

~~~~exercism/caution
In alcuni linguaggi di programmazione, quando si divide per zero, il risultato è un errore.

In Crystal, quando si divide per zero, il risultato è `Infinity` o `-Infinity`.
L'unica eccezione è la divisione di zero per zero, che dà come risultato `NaN` (Not a Number).
`Infinity` e `NaN` sono valori particolari del tipo `Float`.

```crystal
1 / 0
# => Infinity

-1 / 0
# => -Infinity

0 / 0
# => NaN
```
~~~~

## Divisione intera

La divisione intera si usa per dividere i numeri e ottenere la parte intera del risultato.
Il risultato viene sempre arrotondato per difetto a un Int.

```crystal
4.0 // 2
# => 2

4.5 // 2
# => 2
```

~~~~exercism/caution
Dividere per zero quando si usa la divisione intera dà un `DivisionByZeroError`.
Questo è diverso dalla divisione normale.
~~~~

### Modulo

L'operatore modulo si usa per ottenere il resto di una divisione.
L'operatore `%` si usa per il modulo.

```crystal
5 % 2
# => 1

5.0 % 2
# => 1.0

5 % 3
# => 2
```

~~~~exercism/caution
Dividere per zero quando si usa il modulo dà un DivisionByZeroError.
Questo è diverso dalla divisione normale.

```crystal
1 % 0
# Error: Unhandled exception: Division by 0 (DivisionByZeroError)
```
~~~~

## Elevamento a potenza

L'elevamento a potenza si usa per elevare un numero a una potenza.
L'operatore `**` si usa per l'elevamento a potenza.
Il risultato di un'operazione con un `Float` e un `Int` sarà un `Float`.

```crystal
2 ** 2
# => 4

2.0 ** 2
# => 4.0
```

## Arrotondamento

Il metodo `round` accetta un argomento opzionale: il numero di cifre decimali a cui arrotondare.
Il numero di cifre decimali predefinito è 0.

```crystal
1.0.round
# => 1

1.5.round
# => 2

1.234.round(2)
# => 1.23
```

### Arrotondare per eccesso e per difetto

Puoi anche arrotondare per eccesso o per difetto a un `Int` usando i metodi `ceil` e `floor`.
Il metodo `ceil` arrotonda per eccesso, mentre il metodo `floor` arrotonda per difetto.

```crystal
1.0.ceil
# => 1

1.2.ceil
# => 2

1.7.floor
# => 1
```

## Priorità e parentesi

Crystal permette di usare le parentesi tonde (`()`), che possono servire a raggruppare le espressioni.
Questo è utile quando vuoi cambiare l'ordine delle operazioni.

Quando usi più operatori aritmetici, l'ordine delle operazioni è lo stesso della matematica, noto anche come [PEMDAS][pemdas].
Segue l'ordine: parentesi (`()`), esponenti (`**`), moltiplicazione (`*`) e divisione (`/`), addizione (`+`) e sottrazione (`-`).

```crystal
2 + 3 - 4 * 4
# => -11

(2 + 3 - 4) * 4
# => 4
```
