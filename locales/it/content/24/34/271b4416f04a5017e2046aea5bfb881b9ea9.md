# Istruzioni

Larry è un Lisp Alien a cui piace scrivere codice per giocare. 
Oggi vuole scrivere qualche funzione che lo aiuti con un gioco molto simile al tris.

Come il tris, questo gioco si gioca su un tabellone, una griglia 3x3.

## 1. Partire da zero

Per prima cosa Larry ha bisogno di una funzione per creare un tabellone vuoto, `make-empty-board`.
Tutte le celle del tabellone devono essere `NIL`.

```lisp
(make-empty-board) ; => #2A((NIL NIL NIL) (NIL NIL NIL) (NIL NIL NIL))
```

## 2. Partire da un tabellone esistente

Poi Larry ha bisogno di una funzione per creare un tabellone da un array di righe. 
Per esempio:

```lisp
(make-board-from-list '((A B C) (D E F) (G H I))) ; => #2A((A B C) (D E F) (G H I))
```

## 3. Condizione di vittoria

Se c'è un caso in cui ci sono 3 simboli uguali in fila, allora quel giocatore ha vinto.
Larry avrà bisogno di una funzione, `all-the-same-p`, che, dato un array di 3 elementi, restituisce `T` se tutti gli elementi sono lo stesso simbolo.
(`eq` si può usare per determinare se due simboli sono uguali.)

```lisp
(all-the-same-p #(A A A)) ; => T
(all-the-same-p #(A B C)) ; => NIL
```

## 4. In una riga

Ora Larry ha bisogno di un modo per ottenere gli elementi di una riga.
La funzione `row` prende un tabellone e un numero di riga e deve restituire un array con gli elementi di quella riga.

```lisp
(row #2A((1 2 3) (4 5 6) (7 8 9)) 1) ; => #(4 5 6)
```

## 5. In una colonna

Infine Larry ha bisogno di un modo per ottenere gli elementi di una colonna.
La funzione `column` prende un tabellone e un numero di colonna e deve restituire un array con gli elementi di quella colonna.

```lisp
(column #2A((1 2 3) (4 5 6) (7 8 9)) 1) ; => #(2 5 8)
```
