# NuVoc

Il [NuVoc][nuvoc-link] è il riferimento definitivo per J.
È una panoramica estremamente concisa e densa di informazioni sulle primitive e sul linguaggio J.

# Rosetta Code

Molti compiti di Rosetta hanno soluzioni in `J`.
È una buona risorsa per trovare programmi in J da studiare.
[Qui](https://rosettacode.org/wiki/Sudoku#J) c'è un risolutore di sudoku di Roger Hui.
