# Introduzione

In JavaScript, le _stringhe interpolate_ permettono di incorporare espressioni all'interno delle stringhe; questa funzionalità è nota anche come interpolazione di stringhe.
Estende le potenzialità dell'oggetto globale [`String`][string-reference] integrato nel linguaggio.

Puoi creare stringhe interpolate in JavaScript racchiudendo il testo tra i backtick.
Non solo permettono al testo di includere nuove righe e altri caratteri speciali, ma consentono anche di incorporare variabili e altre espressioni.

```javascript
const num1 = 1;
const num2 = 2;

`Adding ${num1} and ${num2} gives ${num1 + num2}.`;
// => Adding 1 and 2 gives 3.
```

Nell'esempio qui sopra, i backtick (<code>\`\`</code>) servono a rappresentare una stringa interpolata. Il `${...}` è il segnaposto usato per la sostituzione.
Qualsiasi tipo non stringa viene convertito _implicitamente_ in stringa.
Questo argomento è trattato nel concetto [conversione di tipo][type-conversion-concept].
Con le stringhe interpolate si può usare qualsiasi tipo di espressione.

```javascript
const track = 'JavaScript';

`This track on exercism.org is ${track.toUpperCase()}.`;
// => This track on exercism.org is JAVASCRIPT.
```

Quando hai bisogno di formattare stringhe su più righe:

```javascript
`This is an example of using template
strings to accomplish multiple
lines`;

/* => This is an example of using template
     strings to accomplish multiple
     lines
*/
```

Se vuoi rappresentare un carattere di nuova riga all'interno di una stringa normale invece di usare una stringa interpolata (cioè senza backtick), puoi usare la sequenza di escape per la nuova riga `\n`:

```javascript
'This is an example of using the newline escape sequence!\nWithout backticks';

/* => This is an example of using the newline escape sequence!
      Without backticks
*/
```

Con le possibilità di sostituzione disponibili, puoi anche introdurre della logica nel processo per determinare quale debba essere la stringa di output.
Un modo per gestire la logica potrebbe essere usare l'[operatore ternario][ternary-operator].
Offre la stessa funzionalità condizionale `if/else` in un formato leggermente diverso.

Per inserire della logica nella sintassi delle stringhe interpolate:

```javascript
const grade = 95;

`You have ${grade > 90 ? 'passed' : 'failed'} the exam.`;
// => You have passed the exam.
```
