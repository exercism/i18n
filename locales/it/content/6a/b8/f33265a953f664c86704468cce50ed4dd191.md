# Usa `Keyword.get_values`

Le keyword list possono contenere più di un valore per una chiave, il che rende complicato recuperare tutti i valori di una chiave.
Il modulo `Keyword`, oltre a `Keyword.get` per ottenere un singolo valore, mette a disposizione anche `Keyword.get_values` per ottenere più valori.
Usa `Keyword.get_values` per filtrare i vini per colore.
