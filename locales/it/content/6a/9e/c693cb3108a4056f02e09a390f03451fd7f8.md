# Creare un test runner

Per prima cosa, grazie per il tuo interesse a creare un test runner!

Questi sono i passaggi per iniziare:

1. Controlla [la nostra lista di repository per un `...-test-runner` esistente](https://github.com/search?q=org%3Aexercism+test-runner&type=repositories) per assicurarti che non ne esista già uno.
2. Dai un'occhiata ai [contenuti di questa directory](/docs/building/tooling/test-runners) per assicurarti che l'idea di creare un test runner ti sia chiara.
3. Apri una nuova discussione sul [forum di Exercism][building-exercism] dicendoci per quale linguaggio vorresti creare un test runner.
4. Una volta creato per te un repository per il test runner, usa i documenti [l'interfaccia del test runner](/docs/building/tooling/test-runners/interface) e [Buone pratiche](/docs/building/tooling/best-practices) per guidare la tua implementazione.

Abbiamo una community incredibilmente amichevole e disponibile che sarà felice di aiutarti mentre lavori su questo!
Se rimani bloccato, apri una nuova discussione sul [forum di Exercism][building-exercism] o crea nuove issue su [exercism/exercism][exercism-repo], se necessario 🙂
