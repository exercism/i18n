# Istruzioni

In questo esercizio lavorerai ancora un po' sulle auto telecomandate.

È stata sviluppata un'auto sperimentale e la pista di prova deve essere adattata per gestire sia i modelli di produzione che quelli sperimentali. I due tipi di auto sono già stati costruiti e devi trovare un modo per gestirli entrambi sulla pista di prova.

Inoltre, le auto di produzione stanno iniziando ad avere un certo successo. Il capo del team vuole mantenere lo spirito competitivo pubblicando una classifica delle auto di produzione.

## 1. Permettere di guidare le auto sulla stessa pista di prova

Aggiungi un metodo all'interfaccia `IRemoteControlCar` per esporre le implementazioni di `Drive()` per i due tipi di auto.

```csharp
TestTrack.Race(new ProductionRemoteControlCar());
TestTrack.Race(new ExperimentalRemoteControlCar());
// this should execute without an exception being thrown
```

## 2. Permettere di confrontare la distanza percorsa dai diversi modelli sulla pista di prova

Aggiungi una proprietà all'interfaccia `IRemoteControlCar` per esporre le implementazioni della proprietà `DistanceTravelled` per i due tipi di auto.

```csharp
var prod = new ProductionRemoteControlCar();
TestTrack.Race(prod);
var exp = new ExperimentalRemoteControlCar();
TestTrack.Race(exp);
prod.DistanceTravelled
// => 10
exp.DistanceTravelled
// => 20
```

## 3. Permettere di classificare le auto di produzione

Implementa l'interfaccia `IComparable<T>` nella classe `ProductionRemoteControlCar`. L'ordine di ordinamento predefinito delle auto deve essere quello crescente di vittorie.

Implementa il metodo statico `TestTrack.GetRankedCars()` in modo che restituisca le auto passate ordinate in ordine crescente di numero di vittorie.

```csharp
var prc1 = new ProductionRemoteControlCar();
var prc2 = new ProductionRemoteControlCar();
prc1.NumberOfVictories = 3;
prc2.NumberOfVictories = 2;
var rankings = TestTrack.GetRankedCars(prc1, prc2);
// => rankings[1] == prc1
```
