# Appendice alle istruzioni

## Implementazione

Nel package twobucket, implementa una func Go, Solve, con la seguente firma:

```go
func Solve(sizeBucketOne,
	sizeBucketTwo, goalAmount int, startBucket string,
) (goalBucket string, numSteps, otherBucketLevel int, e error)
```

Solve restituisce quattro valori: il secchio obiettivo risultante ("one" o "two"), il numero di mosse/passi per raggiungere la quantità obiettivo, i litri rimasti nell'altro secchio e un valore di errore.
Restituisci un errore se un parametro non è valido o se non è possibile trovare una soluzione.
