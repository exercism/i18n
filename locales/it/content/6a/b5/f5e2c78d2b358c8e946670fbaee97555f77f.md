# Introduzione

## Espressioni regolari

Le espressioni regolari in Elixir seguono la specifica **PCRE** (**P**erl **C**ompatible **R**egular **E**xpressions), in modo simile ad altri linguaggi diffusi come Java, JavaScript o Ruby.

Il modulo `Regex` offre funzioni per lavorare con le espressioni regolari. Anche alcune funzioni del modulo `String` accettano espressioni regolari come argomenti.

~~~~exercism/note
Questo esercizio presuppone che tu conosca già la sintassi delle espressioni regolari, incluse classi di caratteri, quantificatori, gruppi e catture.

Se hai bisogno di rinfrescare le tue conoscenze sulle espressioni regolari, dai un'occhiata a una di queste risorse: [Regular-Expressions.info](https://www.regular-expressions.info), [Rex Egg](https://www.rexegg.com/), [RegexOne](https://regexone.com/), [Regular Expressions 101](https://regex101.com/), [RegExr](https://regexr.com/).

### Sigils

Il modo più comune per creare espressioni regolari è usare il sigil `~r`.

```elixir
~r/test/
```

Tieni presente che tutti i sigil di Elixir supportano [diversi tipi di delimitatori][sigils], non solo `/`.

### Corrispondenze

L'operatore `=~/2` può essere usato per eseguire una corrispondenza con un'espressione regolare che restituisce un risultato `boolean`. In alternativa, ci sono anche le funzioni `match?/2` sia nel modulo `Regex` sia nel modulo `String`.

```elixir
"this is a test" =~ ~r/test/
# => true

String.match?("Alice has 7 apples", ~r/\d{2}/)
# => false
```

### Cattura

Se un semplice controllo booleano non basta, usa la funzione `Regex.run/3` per ottenere un array con tutte le catture (o `nil` se non c'è stata alcuna corrispondenza). Il primo elemento dell'array restituito è sempre una corrispondenza dell'intera espressione regolare, mentre gli elementi successivi sono i gruppi trovati.

```elixir
Regex.run(~r/(\d) apples/, "Alice has 7 apples")
# => ["7 apples", "7"]
```

### Modificatori

Il comportamento di un'espressione regolare può essere modificato aggiungendo dei flag speciali. Quando usi un sigil per creare un'espressione regolare, aggiungi i modificatori dopo il secondo delimitatore.

I modificatori più comuni sono:
- `i`: rende la corrispondenza non sensibile alle maiuscole e alle minuscole.
- `u`: abilita pattern specifici di Unicode come `\p` e fa sì che classi di caratteri come `\w`, `\s` ecc. corrispondano anche ai caratteri Unicode.

```elixir
"this is a TEST" =~ ~r/test/i
# => true
```
