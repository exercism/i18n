# Cicli

In Rust, i cicli possono essere usati per eseguire ripetutamente un blocco di codice finché non gli dici di fermarsi o finché non si verifica una certa condizione.

La versione più elementare di un ciclo usa la parola chiave `loop`:

```rust
fn main() {
    loop {
        println!("again!");
    }
}
```

Il frammento di codice qui sopra crea un ciclo infinito. Per uscire da un ciclo, usa la parola chiave break:

```rust
fn main() {
    let mut count = 0;
    loop {
        println!("again!");
        count += 1;
        if count > 10 { break; }
    }
}
```

## Cicli con `for` e `while`

Oltre alla parola chiave `loop`, puoi anche creare cicli con `for` e `while`.

Un ciclo `for` serve a iterare sugli elementi di una collezione o di un iteratore.

```rust
fn main() {
    let a = [10, 20, 30, 40, 50];

    for x in a {
        println!("the value is: {x}");
    }
}
```

Anche i range sono iteratori: iterare su di essi con il ciclo `for` è quindi molto comodo:

```rust
fn main() {
    for x in 0..10 {
        println!("the value is: {x}");
    }
}
```

Un ciclo while ripete il codice finché non si verifica una condizione. Possiamo riscrivere l'esempio precedente usando un ciclo while, così:

```rust
fn main() {
    let a = [10, 20, 30, 40, 50];
    let mut index = 0;

    while index < 5 {
        println!("the value is: {}", a[index]);

        index += 1;
    }
}
```

Vedi [https://doc.rust-lang.org/book/ch03-05-control-flow.html#repetition-with-loops](repetition with loops) nel libro di Rust per maggiori informazioni sui cicli.
