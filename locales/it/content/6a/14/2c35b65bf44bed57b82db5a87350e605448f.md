# Le basi di match

L'operatore `match` confronta un valore con una serie di pattern e poi esegue del codice in base al pattern che corrisponde.

## Corrispondenza di valori letterali

Nella sua forma più elementare, `match` confronta un valore con diversi pattern possibili e sceglie il primo ramo che corrisponde. Viene scelto sempre e solo un ramo, e il controllo non «fluisce» mai verso un altro ramo. `match` è un'espressione che può produrre un valore.

```rust
enum TrollNumber {
    One,
    Two,
    Many,
    Lots,
}

fn estimated_value(troll_number: TrollNumber) -> u32 {
    match troll_number {
        TrollNumber::One => 1,
        TrollNumber::Two => 2,
        TrollNumber::Many => 10,
        TrollNumber::Lots => 100,
    }
}
```

## Esaustività

La corrispondenza è sempre esaustiva: Rust non compilerà un programma se un valore può sfuggire tra le maglie. A questo scopo, `_` è un carattere jolly che corrisponde a qualsiasi valore.

```rust
fn ordinal(n: u32) -> String {
    let ordinal = match n % 10 {
        1 => "st",
        2 => "nd",
        3 => "rd",
        _ => "th",
    };
    format!("{n}{ordinal}")
}
```

## La corrispondenza come flusso di controllo

Oltre a poter essere usato come espressione per produrre un valore, `match` può anche essere usato come istruzione, al solo scopo di controllare il flusso.

```rust
// pretend that we've already filtered the key events relevant to the space bar (we don't want a keylogger)
fn space_timer(&mut self, event: Event) {
    match event {
        Event::KeyDown => self.timer = Some(Instant::now()),
        Event::KeyUp => {
            let duration = Instant::now() - self.timer.take().expect("can't have KeyUp without KeyDown");
            self.durations.push(duration);
        }
        // we don't care about any other events; the empty scope is a no-op
        _ => {}
    }
}
```

## Corrispondenza di intervalli

I rami del `match` non devono per forza essere singoli valori: possono anche essere intervalli.

```rust
fn ascii_type(ch: u8) -> &'static str {
    match ch {
        0..=31 => "non-printable control code",
        32..=126 => "printable character",
        127 => "DEL",
        _ => "extended ASCII; region-specific",
    }
}
```

## Pattern alternativi

Un ramo del `match` può corrispondere a una tra diverse opzioni possibili usando il token `|` come separatore.

```rust
fn should_retry(error: std::io::Error) -> bool {
    use std::io::ErrorKind;

    match error.kind() {
        ErrorKind::TimedOut | ErrorKind::Interrupted => true,
        _ => false,
    }
}
```

## Corrispondenza strutturale e binding

La corrispondenza può produrre un binding valido all'interno di un determinato ramo del `match`. È particolarmente utile per estrarre i dati dagli enum che li trasportano nelle loro varianti.

```rust
/// Consume a result and proceed, logging any errors.
trait OrLog {
    fn or_log(self);
}

impl<E: std::fmt::Display> OrLog for Result<(), E> {
    fn or_log(self) {
        match self {
            // discard Ok results
            Ok(()) => {},
            // log errors
            Err(err) => println!("ERROR: {err}"),
        }
    }
}
```
