# Istruzioni

Stai aiutando tua sorella minore con i compiti di vocabolario inglese, che trova molto noiosi.
La sua classe sta imparando a creare nuove parole aggiungendo _prefissi_ e _suffissi_.
Data una serie di parole, l'insegnante cerca parole trasformate correttamente e scritte senza errori, aggiungendo il prefisso all'inizio o il suffisso alla fine.

Il compito ha quattro attività, ognuna con un insieme di testi o parole con cui lavorare.


## 1. Aggiungere un prefisso a una parola

Uno dei prefissi più comuni in inglese è `un`, che significa «not».
In questa attività, tua sorella deve creare parole negative, cioè parole che significano «not», aggiungendo `un`.

Implementa la funzione `add_prefix_un(<word>)` che prende `word` come parametro e restituisce una nuova parola con il prefisso `un`:


```python
>>> add_prefix_un("happy")
'unhappy'

>>> add_prefix_un("manageable")
'unmanageable'
```


## 2. Aggiungere prefissi a gruppi di parole

Ci sono altri quattro prefissi comuni che la classe di tua sorella sta studiando:
`en` (_che significa «mettere dentro» o «coprire con»_),
`pre` (_che significa «prima» o «avanti»_),
`auto` (_che significa «sé» o «stesso»_),
e `inter` (_che significa «tra» o «fra»_).

In questo esercizio, la classe crea gruppi di parole del vocabolario usando questi prefissi, così da poterle studiare insieme.
Ogni prefisso arriva in una lista con le parole comuni con cui viene usato.
Gli studenti devono applicare il prefisso e produrre una stringa che mostri il prefisso applicato a tutte le parole.

Implementa la funzione `make_word_groups(<vocab_words>)` che prende `vocab_words` come parametro nella seguente forma:
`[<prefix>, <word_1>, <word_2> .... <word_n>]`, e restituisce una stringa con il prefisso applicato a ogni parola, simile a:
`'<prefix> :: <prefix><word_1> :: <prefix><word_2> :: <prefix><word_n>'`.

Qui non serve creare un ciclo `for` o `while` per elaborare l'input.
Pensa con attenzione a quali metodi delle stringhe (e delimitatori) potresti usare invece.


```python
>>> make_word_groups(['en', 'close', 'joy', 'lighten'])
'en :: enclose :: enjoy :: enlighten'

>>> make_word_groups(['pre', 'serve', 'dispose', 'position'])
'pre :: preserve :: predispose :: preposition'

>> make_word_groups(['auto', 'didactic', 'graph', 'mate'])
'auto :: autodidactic :: autograph :: automate'

>>> make_word_groups(['inter', 'twine', 'connected', 'dependent'])
'inter :: intertwine :: interconnected :: interdependent'
```


## 3. Rimuovere un suffisso da una parola

`ness` è un suffisso comune che significa _«stato dell'essere»_.
In questa attività, tua sorella deve trovare la parola radice originale rimuovendo il suffisso `ness`.
Ma naturalmente ci sono fastidiose regole ortografiche: se la parola radice terminava originariamente con una consonante seguita da una «y», allora la «y» è stata cambiata in «i».
Rimuovere «ness» deve ripristinare la «y» in quelle parole radice. Per esempio, `happiness` --> `happi` --> `happy`.

Implementa la funzione `remove_suffix_ness(<word>)` che prende una `word` e restituisce la parola radice senza il suffisso `ness`.


```python
>>> remove_suffix_ness("heaviness")
'heavy'

>>> remove_suffix_ness("sadness")
'sad'
```

## 4. Estrarre e trasformare una parola

I suffissi sono spesso usati per cambiare la parte del discorso a cui una parola è assegnata.
Una pratica comune in inglese è il «verbing» o «verbifying», in cui un aggettivo _diventa_ un verbo aggiungendo un suffisso `en`.

In questo compito, tua sorella si eserciterà a fare il «verbing» delle parole, estraendo un aggettivo da una frase e trasformandolo in un verbo.
Per fortuna, tutte le parole da trasformare qui sono «regolari»: non richiedono cambiamenti ortografici per aggiungere il suffisso.

Implementa la funzione `adjective_to_verb(<sentence>, <index>)` che prende due parametri.
Una `sentence` che usa la parola del vocabolario, e l'`index` della parola, una volta che la frase è stata divisa.
La funzione deve restituire l'aggettivo estratto come verbo.


```python
>>> adjective_to_verb('I need to make that bright.', -1 )
'brighten'

>>> adjective_to_verb('It got dark as the sun set.', 2)
'darken'
```
