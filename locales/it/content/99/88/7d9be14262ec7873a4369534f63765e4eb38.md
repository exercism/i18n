# Suggerimenti

## 1. Stampa un badge per un dipendente

- Per costruire le stringhe in Base R, è utile la funzione [`sprintf`][ref-sprintf].
- Per un approccio Tidyverse, puoi usare [`str_glue`][ref-str_glue] della libreria `stringr`.

## 2. Stampa un badge per un nuovo dipendente

- Fai una diramazione in base a [`is.na`][ref-isna].

## 3. Stampa un badge per il proprietario

- Fai una diramazione in base a [`is.null`][ref-isnull].

## 4. Calcola lo stipendio totale dei dipendenti senza ID

- Puoi [filtrare][concept-vector-filtering] in base a [`is.na`][ref-isna] e poi usare [`sum`][ref-sum].
- Cosa restituisce `salaries[is.na(ids)]` se non ci sono dipendenti senza ID? Sarebbe utile verificarlo in una console R. Se R non è installato sul tuo computer, console online come [rdrr.io][web-rdrr] possono essere d'aiuto.
