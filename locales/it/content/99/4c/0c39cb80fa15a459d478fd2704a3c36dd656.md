# Introduzione

Python rappresenta i valori vero e falso con il tipo [`bool`][bools], che è una sottoclasse di `int`.
 In questo tipo ci sono solo due valori: `True` e `False`.
  Questi valori possono essere assegnati a una variabile:

```python
>>> true_variable = True
>>> false_variable = False
```

Possiamo valutare espressioni booleane usando gli operatori `and`, `or` e `not`:

```python
>>> true_variable = True and True
>>> false_variable = True and False

>>> true_variable = False or True
>>> false_variable = False or False

>>> true_variable = not False
>>> false_variable = not True
```

[bools]: https://docs.python.org/3/library/stdtypes.html#typebool
