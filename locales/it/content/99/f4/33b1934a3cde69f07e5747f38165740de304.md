# Introduzione

I letterali sono valori fissi usati direttamente nel codice.
Non richiedono alcun calcolo in fase di esecuzione.
Esistono in varie forme per rappresentare in modo efficiente tipi di dati diversi.
I letterali più frequenti sono di natura numerica, ma ci sono anche operatori letterali per tipi come date, orari e stringhe.
Un concetto successivo mostrerà come si possono usare gli operatori letterali definiti dall'utente.

## Letterali numerici

I letterali numerici includono le rappresentazioni decimale, ottale, esadecimale e binaria.
Queste basi sono già state trattate nel [concetto numbers][numbers-concept].

Tutte le rappresentazioni come `23`, `0x50f7ba11` e `0xba5eba11` vengono interpretate dal compilatore come `int`.
Il tipo `int` generico è con segno e ([a seconda del compilatore e del sistema][in-depth-integers]) ha spesso un intervallo da `-2'147'483'648` a `2'147'483'647`.
Nella maggior parte dei casi è sufficiente e non devi preoccuparti del tipo specifico.

Alcuni casi d'uso richiedono intervalli più ampi o un ingombro di memoria dei programmi molto ridotto.
Per essere espliciti, si può indicare direttamente il tipo intero specifico con il letterale numerico.

Quando i numeri negativi non servono, ma si vuole l'intervallo aggiuntivo, si usano i suffissi `u` o `U` per gli interi _senza segno_.
Per intervalli maggiori si possono usare `L` o anche `LL`, per i tipi long e long long.

~~~~exercism/caution
L'uso della `l` minuscola è permesso, ma si confonde facilmente con il numero `1` ed è quindi sconsigliato.
~~~~

```cpp
auto net_worth_christian_grey{2'500'000'000U}; // out of range for 32-bit integers
auto net_worth_carlisle_cullen{46'000'000'000LL}; // int and uint are not enough
```

I numeri in virgola mobile di solito vengono risolti come `double` durante la compilazione.
Questo è un buon caso predefinito e i casi d'uso con il tipo `float` più stretto sono meno frequenti dell'esempio senza segno qui sopra.

~~~~exercism/advanced
Lo [standard C++23][cpp23-literals] introduce un controllo più preciso con letterali come `f128` o `F16`.
Alcuni compilatori permettono l'uso di letterali propri.
GCC consente di usare `d` come letterale, ma ciò non è previsto dallo standard e può ostacolare la compatibilità multipiattaforma.

[cpp23-literals]: https://en.cppreference.com/w/cpp/language/floating_literal

~~~~

```cpp
auto light_year_in_m{9.46073e+15f}; // well in the range of float
auto earth_to_edge_comoving_distance_in_nm{4.32355e+32}; // needs double type for magnitude
auto eulers_number{2.718281828459045}; // needs double type for precision
```

## Letterali di caratteri e stringhe

Altri concetti hanno già usato letterali di carattere con virgolette singole, come `'}'` o `'@'`.

In C++ `char` è limitato ai primi 128 [codici di carattere ascii][ascii-code].
Per usare più caratteri ascii o caratteri ascii estesi come `‰` o anche caratteri unicode come `麗` e `ẞ`, servono altri tipi.
In un concetto precedente i letterali di stringa sono stati introdotti con le _virgolette doppie_: `"一体どういう意味ですか。C++です"`.
Il tipo effettivo di questa frase giapponese è `const char (&)[46]`, una stringa in stile C.

L'uso dei letterali di stringa non è attivato per impostazione predefinita.
Per usare il letterale _string_ `""s` o il letterale _string-view_ `""sv`, l'utente deve specificarne l'uso tramite il namespace corrispondente:

```cpp
#include <string>
#include <string_view>

using namespace std::literals;

auto green_light{"무궁화 꽃 이 피었 습니다"};
// green_light type is const char (&)[36]
auto umbrella{"달고나"s};
// umbrella type is std::basic_string<char>, the same as std::string
auto il_nam{"보는 것이 하는 것보다 더 재미있을 수가 없지"sv};
// il_nam type is std::basic_string_view<char>
```

Un _string_view_ si può vedere come un riferimento a una stringa costante.
