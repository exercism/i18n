# Installare Kotlin

Oltre alla CLI di Exercism e al tuo editor di testo preferito, per esercitarti con gli esercizi di Exercism in Kotlin ti servono

* il **Java Development Kit** (JDK): Kotlin compila in bytecode Java, quindi devi installare il JDK, che include sia un Java Runtime *sia* gli strumenti di sviluppo (in particolare il compilatore Java); e
* **Gradle**, uno strumento di build specifico per i progetti basati su JVM, che supporta Kotlin.

Scegli il tuo sistema operativo:

* [Windows](#h-windows)
* [macOS](#h-macos)
* [Linux](#h-linux)

... oppure ...
* se preferisci non usare un gestore di pacchetti, puoi [installare manualmente](#h-install-manually).

Facoltativamente, puoi anche usare un [IDE Java](#h-java-ides).

----

## Windows

Apri un prompt dei comandi come amministratore.  (Se hai bisogno di aiuto per aprire un prompt con privilegi amministrativi, vedi [aprire un prompt con privilegi elevati in Windows 8+](http://www.howtogeek.com/194041/how-to-open-the-command-prompt-as-administrator-in-windows-8.1/) (oppure [Windows 7](http://www.howtogeek.com/howto/windows-vista/run-a-command-as-administrator-from-the-windows-vista-run-box/)).

1. Se non hai ancora installato Chocolatey, fallo adesso:

      ```batchfile
        C:\Windows\system32> @powershell -NoProfile -ExecutionPolicy unrestricted -Command "iex ((new-object net.webclient).DownloadString('https://chocolatey.org/install.ps1'))" && SET PATH=%PATH%;%ALLUSERSPROFILE%\chocolatey\bin
      ```

2.  Installa il JDK:

       ```batchfile
        C:\Windows\system32> choco install openjdk11
        ...
        C:\Windows\system32> refreshenv
        ...
       ```

Ti consigliamo di chiudere il prompt dei comandi amministrativo e aprirne uno nuovo: non servono privilegi di amministratore per esercitarti con gli esercizi di Exercism.

Ora sei pronto per iniziare con il track Kotlin di Exercism!

Per iniziare, vedi «[Eseguire i test](https://exercism.org/docs/tracks/kotlin/tests)».

## macOS

Qui di seguito trovi le istruzioni per l'installazione con il metodo più comune, cioè Homebrew.  Se preferisci, puoi anche [installare su macOS senza Homebrew](#h-installing-on-macos-without-homebrew).

### Installazione

1. Se non hai ancora installato [Homebrew](http://brew.sh), fallo adesso:

      ```sh
        $ /usr/bin/ruby -e "$(curl -fsSL https://raw.githubusercontent.com/Homebrew/install/master/install)"
      ```

2. Aggiungi il [Homebrew Cask](https://caskroom.github.io/): così possiamo installare binari precompilati come il JDK.

      ```
        $ brew tap adoptopenjdk/openjdk
      ```

3.  Installa il JDK:

       ```
        $ brew install --cask adoptopenjdk11
       ```

Ora sei pronto per iniziare con il track Kotlin di Exercism!

Per iniziare, vedi «[Eseguire i test](https://exercism.org/docs/tracks/kotlin/tests)».

## Linux

Qui di seguito trovi le istruzioni per l'installazione con il gestore di pacchetti della tua distribuzione.  Se preferisci, puoi anche [installare su Linux senza un gestore di pacchetti](#h-installing-on-linux-without-a-package-manager).

* [Debian](#h-debian)
* [Altre distribuzioni Linux](#h-other-linux-distributions)

### Debian

Se usi Debian o una sua derivata (come Ubuntu o Linux Mint), usa APT:

*(verificato su: Ubuntu 14, 16 e 18)*

1. Installa il JDK:

      ```sh
        $ sudo apt-get update
        $ sudo apt-get install software-properties-common
        $ sudo add-apt-repository ppa:openjdk-r/ppa
        $ sudo apt-get update
        $ sudo apt-get install openjdk-11-jdk
      ```


Ora sei pronto per iniziare con il track Kotlin di Exercism!

Per iniziare, vedi «[Eseguire i test](https://exercism.org/docs/tracks/kotlin/tests)».

### Altre distribuzioni Linux

Ci sono molti modi per installare JDK 11, ma uno dei più semplici è usare SDKMAN, 
che ti permette di installare OpenJDK 11 senza problemi. Segui questi passaggi:

1. Installa SDKMAN:
    ```sh
    $ curl -s "https://get.sdkman.io" | bash
    ``` 
    (se non funziona, dai un'occhiata alle istruzioni che trovi qui: https://sdkman.io/install )
1. Installa openjdk11:
    ```
    $ sdk install java 11.0.2-open
    ``` 

Ora sei pronto per iniziare con il track Kotlin di Exercism!

Per iniziare, vedi «[Eseguire i test](https://exercism.org/docs/tracks/kotlin/tests)».

### Installare su Windows manualmente

*NOTA: queste istruzioni sono pensate per utenti Windows esperti.  Se non sai già impostare le variabili d'ambiente o non ti senti sicuro a gestire la struttura delle directory, ti consigliamo vivamente di usare l'installazione basata su Chocolatey, [qui sopra](#h-windows).*

1. Installa il JDK:
   1. Scarica "**OpenJDK 11 (LTS)**" da [AdoptOpenJDK](https://adoptopenjdk.net/releases.html?variant=openjdk11#x64_win) (scegli **"Install JDK"**).
   -  Esegui il programma di installazione, lasciando tutte le impostazioni predefinite.

Ora sei pronto per iniziare con il track Kotlin di Exercism!

Per iniziare, vedi «[Eseguire i test](https://exercism.org/docs/tracks/kotlin/tests)».

## IDE Java

Ci sono molti IDE Java disponibili.  I tre più popolari sono:

* [IntelliJ IDEA](https://www.jetbrains.com/idea/download/) (scarica l'edizione "Community")
  - creato dagli autori di Kotlin, questo IDE offre il miglior supporto per il linguaggio.
- [Eclipse](https://www.eclipse.org/downloads/)
- [NetBeans](https://netbeans.org/downloads/) (scarica il pacchetto "Java SE")

e ce ne sono [altri](https://en.wikibooks.org/wiki/Java_Programming/Java_IDEs).
