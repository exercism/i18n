# Introduzione

**Le closure** sono un pattern di programmazione [in Clojure][clojure-guide-closures] che permette di usare all'interno di una funzione le variabili di uno [scope lessicale][wiki-lexical-scope] esterno. Clojure supporta le closure in modo trasparente e spesso vengono usate senza sapere cosa siano.

```clojure
;; Top-level definitions are global-scope
(def dozen 12)

;; Functions create a new scope.
;; Referencing the outer variable here is a closure.
(fn [n] (* dozen n))
```

## Closure per conservare lo stato e passare i valori

Usare un atom permette di conservare parte dello stato:

```clojure
;; This function closure increments the counter's state
;; in the outer lexical context.
;; This way the counter can be shared between many calling contexts.

(def increment
  (let [counter (atom 0)]
    (fn [] (swap! counter inc))))
```

Ogni chiamata successiva a `increment` incrementa il suo contatore:

``` clojure
(increment)
;;=> 1
(increment)
;;=> 2
```
