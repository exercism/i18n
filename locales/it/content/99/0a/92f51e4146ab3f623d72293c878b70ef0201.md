# Usa l'interpolazione di stringhe

[comment]: # (This warning is raised when the solution doesn't use string interpolation)

Usa l'[interpolazione di stringhe](https://github.com/elixir-lang/elixir/blob/9cac52833e91b5ebac0d322b20e39605d8dafad9/lib/elixir/lib/string.ex#L20) per inserire il parametro `name` nella stringa di output.

- Quando possibile, nel percorso Elixir di Exercism si consiglia di usare l'interpolazione di stringhe invece della concatenazione di stringhe, per una maggiore leggibilità.

```elixir
def hello(what) do
  "Hello, #{what}"
end
```

- [Qualsiasi espressione Elixir](https://github.com/elixir-lang/elixir/blob/9cac52833e91b5ebac0d322b20e39605d8dafad9/lib/elixir/lib/string.ex#L30) può stare nella sintassi dell'interpolazione di stringhe

```elixir
def pluralize_apple(n) when n >= 1 do
  "apple#{if n > 1, do: "s"}"
end
```
