# Istruzioni

Un pirata sta pianificando una rotta attraverso una mappa di calette nascoste. La mappa è una hashtable con chiave il nome della caletta: ogni valore è un array delle calette che si possono raggiungere direttamente da quella.

## 1. Svuota la coda della marea

Definisci `tide-queue` in modo che prenda un array di elementi, inserisca ciascuno in un deque nuovo (in ordine), poi li estragga tutti di nuovo in un array che conserva l'ordine originale. Questa è la forma FIFO: inserisci in fondo, estrai dalla testa.

```factor
{ "alpha" "bravo" "charlie" } tide-queue .
! => { "alpha" "bravo" "charlie" }
```

## 2. Calette raggiungibili

Definisci `coves-reachable` in modo che prenda una caletta di partenza e una mappa, e restituisca un hash-set di ogni caletta raggiungibile da `start`, inclusa `start` stessa.

```factor
"Skull Bay" H{
    { "Skull Bay"   { "Hidden Cove" } }
    { "Hidden Cove" { "Reef Point"  } }
    { "Reef Point"  { } }
} coves-reachable .
! => HS{ "Skull Bay" "Hidden Cove" "Reef Point" }
```

Usa un `<dlist>` come frontiera per la BFS e un `HS{ }` per l'insieme delle calette visitate.

## 3. Conteggio dei salti

Definisci `hop-count` in modo che prenda una caletta di partenza, una caletta di destinazione e una mappa, e restituisca il numero minimo di salti tra le due, oppure `f` se la destinazione non è raggiungibile.

```factor
"Skull Bay" "Hidden Cove"
H{
    { "Skull Bay"   { "Hidden Cove" } }
    { "Hidden Cove" { } }
} hop-count .
! => 1
```

Porta ogni caletta insieme alla sua distanza dalla partenza nel deque (va bene un array di 2 elementi).

## 4. Conteggio dell'oro

Lo stub dichiara `gold-count` con `:`. Cambialo in `MEMO:` (non `:`) così il risultato per ogni caletta viene calcolato una sola volta e messo in cache. Cerca l'oro della caletta nella costante `gold-distribution` che l'esercizio fornisce. Una caletta che non compare nella distribuzione ha zero oro.

```factor
"Smuggler's Hollow" gold-count .   ! => 200
"Davy Jones' Locker" gold-count .  ! => 0
```

## 5. La rotta del tesoro

Definisci `treasure-route` in modo che prenda una caletta di partenza e una mappa, e restituisca la caletta raggiungibile con più oro. Usa `coves-reachable` del punto 2 e `gold-count` del punto 4.

```factor
"Skull Bay" some-chart treasure-route .
! => "Smuggler's Hollow"   (the richest reachable cove)
```

Il `gold-count` memoizzato rende gratuite le ricerche ripetute: è utile quando diverse parti dell'algoritmo consultano la stessa caletta.
