# Informazioni

JavaScript è un linguaggio di programmazione che permette di rendere dinamiche le pagine web. È un linguaggio interpretato, il che significa che non deve essere compilato: l'interprete (come un browser web) analizza il codice e lo trasforma in codice che la macchina può eseguire. Questo lo rende adatto a creare siti web dinamici che funzionano su qualsiasi browser, _su qualsiasi computer_!

JavaScript non si usa solo nel browser. I runtime di JavaScript, come [Node.js][web-nodejs] e [Deno][web-deno], ti permettono di scrivere, avviare e servire richieste su server web.
Altri framework, come [Electron][web-electron], usano JavaScript per scrivere _applicazioni multipiattaforma_ per Windows, Linux e macOS.
È possibile anche sviluppare app per dispositivi mobili, utilizzando [React Native][web-react-native], [Ionic][web-ionic] e vari altri strumenti; con [Expo][web-expo] ora puoi puntare ad Android, iOS e al web, tutti insieme.

ECMAScript è lo [standard][web-ecma] che definisce JavaScript.

> «ECMAScript è diventato uno dei linguaggi di programmazione di uso generale più diffusi al mondo.
> È noto soprattutto come il linguaggio incorporato nei browser web, ma è stato ampiamente adottato anche per applicazioni server ed embedded.»
> [ECMA International Language Specification][web-ecma-2019]

A partire dalla sesta edizione (conosciuta comunemente come ES2015 o ES6) nel 2015, ogni anno viene pubblicata una nuova edizione dello standard.
La sesta edizione è stata un aggiornamento importante che ha portato molti miglioramenti rispetto a ES5, tra cui le stringhe interpolate, la sintassi espressiva delle arrow function e una sintassi più pulita per definire le classi.

Ma poiché ogni anno arrivano in JavaScript nuova sintassi e nuove funzionalità, il supporto a queste novità è spesso incompleto nei [browser attuali][web-compat-browsers] e nell'[ultima versione di Node.js][web-compat-node].
Questo non significa che non possiamo usarle.
Strumenti come [Babel][web-babel] offrono la [transpilazione][wiki-transpilation] per la maggior parte delle funzionalità, permettendoci di _scrivere_ come se fossimo già nel futuro.

**Nota**: questo track supporta la sintassi ECMAScript più recente tramite Babel e il plugin [@babel/preset-env][web-babel-preset-env]; le nuove funzionalità sperimentali vengono abilitate a ogni aggiornamento di quel plugin, in sincronia con il rilascio delle specifiche.
Si adatta automaticamente all'installazione di Node.js _che hai in locale_.
Così non devi preoccuparti di cosa è supportato e cosa no.
