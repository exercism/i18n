# Informazioni

Le librerie di classi di base di .NET mettono a disposizione la classe [`Regex`][regex] per l'elaborazione delle espressioni regolari.

Consulta questo [articolo][regex-comparison] per un confronto tra C# e altre varianti delle espressioni regolari.

## Gruppi di cattura

Un aspetto da considerare è quello dei gruppi di cattura, che restituiscono le parti del testo che corrispondono alle varie parti del pattern dell'espressione regolare. Bisogna abituarsi all'approccio ai gruppi di cattura. Consulta questa [documentazione][capture].

Nota che, quando entrano in gioco i gruppi di cattura `(?<capture-name>pattern)`, c'è una gerarchia:

- in cui viene restituito un insieme di zero o più corrispondenze (una per ogni corrispondenza trovata nel testo);
- ogni corrispondenza contiene un certo numero di gruppi di cattura;
- ogni gruppo contiene un certo numero di catture.

Inoltre:

- `Match` deriva da `Group`
- `Group` deriva da `Capture`

Avvertenze:

- L'approccio più sicuro è usare le catture con nome.
- I gruppi di cattura in genere compaiono nella raccolta `Groups` nello stesso ordine in cui appaiono nel testo.
- `Groups[0]` sembra riferirsi all'intera corrispondenza.
- `Groups[<capture name>].Value` è quasi certamente ciò che ti interessa. Le singole catture (a parte `Caputures[0]`) sembrano pensate per scopi diagnostici, se sono presenti.

## Opzioni di Regex

Prendi confidenza con [`RegexOptions`][regex-options].

Oltre alle solite opzioni come `IgnoreCase`, ce ne sono per `MultiLine`, utile per elaborare più righe di testo in una sola volta, e per `IgnorePatternWhitespace`, che, se abbinata a stringhe verbatim, interpolazione di stringhe e commenti, può essere molto espressiva, come mostrato in questo esempio:

```csharp
const string PREAMBLE = "preamble";
const string PWTEXT = "pwtext";
const string PW = "pw";
const string SPACE = "space";
const string POSTAMBLE = "postamble";

var pattern = $@"
    ^
    (?<{PREAMBLE}>.*)          # any text
    (?<{PWTEXT}>password)      # the literal text - password
    (?<{SPACE}>\s+)
    (?<{PW}>\w*)               # the password itself
    (?<{POSTAMBLE}>.*)         # any text
    $
  ";

var rewrittenLine = $"{grps[PREAMBLE].Value}{grps[PWTEXT].Value}{grps[SPACE].Value}{mask}{grps[POSTAMBLE].Value}";
```

Un'altra opzione interessante è `RegexOptions.Compiled`, per le espressioni regolari [compilate][regex-compilation].
