# Appendice alle istruzioni

## Suggerimento

Una funzione con un *tipo restituito* può restituire solo dati di quel *tipo* e `null`. Tuttavia, chi chiama la funzione si aspetta un solo tipo di dato.

Esempio:
```dart
String hello(int a){
    if ( a == 0){
        return "a";
    } else {
        return null;
    }
}
```
Per rendere più chiaro che questa funzione può restituire anche `null` o più tipi di dato, usa `dynamic`.
```dart
dynamic hello(int a){
    if ( a == 0){
        return "a";
    } else {
        return null;
    }
}
