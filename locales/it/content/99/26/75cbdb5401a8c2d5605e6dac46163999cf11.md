# Risolvere gli esercizi in locale

Risolvere gli esercizi sulla tua macchina locale ti permette di scrivere tutto il codice in un ambiente che conosci bene.

## Installare la CLI

Per risolvere un esercizio sulla tua macchina locale, devi prima installare e configurare l'interfaccia a riga di comando di Exercism seguendo [queste istruzioni](https://exercism.org/cli-walkthrough).

### Configurazione

Devi indicare alla CLI chi sei, così possiamo scaricare le cose correttamente.
Puoi trovare il tuo token nella [pagina delle impostazioni](/settings/api_cli).
Poi puoi configurare la CLI con il comando seguente, sostituendo `<your-api-token>` con il valore che trovi nella pagina delle impostazioni:

```
exercism configure --token=<your-api-token>
```

## Scaricare l'esercizio

Una volta installata, puoi usare la CLI per scaricare l'esercizio sulla tua macchina locale con il comando seguente (sostituendo `<exercise-slug>` e `<track-slug>` con i valori corrispondenti:

```
exercism download --exercise=<exercise-slug> --track=<track-slug>
```

Non devi ricordare questa struttura di comando: la pagina dell'esercizio elenca il comando giusto per quell'esercizio.

Quando il comando di download è terminato, i file dell'esercizio verranno scaricati sulla tua macchina locale.

## Risolvere l'esercizio

L'obiettivo di ogni esercizio è creare un'implementazione che superi tutti i test.
Un'implementazione di questo tipo viene chiamata _soluzione_.

Per aiutarti, ogni esercizio contiene i seguenti file:

- README.md: le istruzioni che spiegano cosa ci si aspetta da te
- HELP.md: informazioni su come eseguire i test e su come ottenere aiuto quando sei bloccato
- HINTS.md (facoltativo): suggerimenti per aiutarti a risolvere l'esercizio
- File di test: contengono i test che verificano la correttezza della soluzione
- File stub: forniscono un punto di partenza per costruire l'implementazione

A seconda del track, potrebbero esserci altri file che gli strumenti del track richiedono per far funzionare i test.

## Inviare la soluzione

Una volta che la soluzione supera tutti i test, puoi inviarla con il comando seguente:

```
exercism submit <implementation_file_paths>
```

Questo comando carica la soluzione sul sito di Exercism e stampa l'URL della pagina della soluzione.

Anche in questo caso non devi ricordare il comando: il file `HELP.md` dell'esercizio elenca il comando corretto.

È possibile inviare una soluzione incompleta, il che ti permette di:

- Vedere come altri hanno completato l'esercizio
- Chiedere aiuto a un mentore

## Altre funzionalità della CLI

### Vedere tutti i comandi

Esegui il sottocomando help per ottenere l'elenco completo dei comandi disponibili.

```bash
exercism help
```

### Risoluzione dei problemi

Assicurati di avere la versione più recente.

Verifica quale versione stai usando:

```bash
exercism version
```

Confronta con l'ultima release e aggiorna se la tua versione non è la più recente.

Dopo l'aggiornamento, ricontrolla la versione. Se la versione non è cambiata, assicurati di eseguire il binario aggiornato.

```bash
which exercism
```

Se hai ancora problemi, apri una issue in exercism/cli su GitHub con l'output del comando troubleshoot.

```bash
exercism troubleshoot
```

Puoi aprire delle issue sul [nostro issue tracker](https://github.com/exercism/exercism/issues) e la community cercherà di aiutarti. **Assicurati di aver seguito la [procedura guidata interattiva](https://exercism.org/cli-walkthrough) prima di aprire qualsiasi issue.**
