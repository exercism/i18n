# Installazione

Usa il binario `full` per la tua piattaforma dalla [pagina delle release ufficiali][official-releases].
Al momento, il track punta alla release Arturo 0.10.0 Arizona Bark.

~~~~exercism/caution
Homebrew è un metodo di terze parti molto diffuso per installare software su piattaforme macOS e Linux.
Tuttavia, la sua recipe per Arturo punta alla build `mini`, che non è compatibile con questo track.
~~~~

Per ulteriore assistenza sull'installazione di Arturo, consulta il [Discord ufficiale di Arturo][discord].

## Eseguire codice Arturo

A questo punto, sei pronto per iniziare a scrivere codice Arturo!
Per accedere alla REPL di Arturo, esegui `arturo` dalla riga di comando.
Per eseguire uno script Arturo, esegui `arturo <file>` dalla riga di comando.

[official-releases]: https://arturo-lang.io/#download
[discord]: https://discord.gg/YdVK2CB
