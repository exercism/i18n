# Debug

Quando un test fallisce, viene visualizzato un messaggio che descrive cosa è andato storto e per quale input.
Puoi esaminare valori arbitrari del programma passandoli al metodo `debug`.
In questo modo i valori vengono catturati e l'output viene mostrato.

```ruby
debug "The value is #{value}."
debug "The input is #{input.inspect}"
```
