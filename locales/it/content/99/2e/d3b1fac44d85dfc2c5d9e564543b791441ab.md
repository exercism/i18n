# Appendice alle istruzioni

## Registri

| Registro | Uso          | Tipo    | Descrizione                     |
| -------- | ------------ | ------- | ------------------------------- |
| `$a0`    | input        | integer | N, somma dei lati del triangolo |
| `$a1`    | input/output | address | valori di a                     |
| `$a2`    | input/output | address | valori di b                     |
| `$a3`    | input/output | address | valori di c                     |
| `$v0`    | output       | integer | numero di terne                 |
| `$t0-9`  | temporaneo   | any     | per l'archiviazione temporanea  |
