# はじめに

## 数値

Pythonには、組み込みの数値が3種類あります。`ints`、`floats`、`complex`です。ただし、この演習では`ints`と`floats`だけを扱います。

### `ints`

`ints`は整数です。例：`1234`、`-10`、`20201278`。

Pythonの整数は[任意精度][arbitrary-precision]を持ちます。桁数は、ホストシステムで利用できるメモリによってのみ制限されます。

### `floats`

`floats`は小数点を含む数値です。例：`0.0`、`3.14`、`-9.01`。

浮動小数点数は、通常PythonではC言語の`double`を使って実装されています（*精度は小数点以下15桁*）。ただし、その表現はホストシステムやその他の実装の詳細によって変わります。このため、浮動小数点数を扱うときには驚くようなことが起こることもありますが、ほとんどの場面では「十分」と言えます。

## 算術

Pythonは、`ints`と`floats`の間の算術を完全にサポートしています。二項算術演算子（`+`、`-`、`*`、`/`、`//`、`%`）を使うと、より狭い型の数値は、より広い型の相手に合わせて変換されます。

Pythonは`ints`を`floats`より狭い型と見なします。そのため、式の中で浮動小数点数を使うと、結果も必ず浮動小数点数になります。ただし、割り算では整数だけを使っても、結果は必ず浮動小数点数になります。

```python
# The int is widened to a float here, and a float type is returned.
>>> 3 + 4.0
7.0
>>> 3 * 4.0
12.0
>>> 3 - 2.0
1.0
# Division always returns a float.
>>> 6 / 2
3.0
>>> 7 / 4
1.75
# Calculating remainders.
>>> 7 % 4
3
>>> 2 % 4
2
>>> 12.75 % 3
0.75
```

整数の結果が必要な場合は、`//`を使って結果を切り捨てることができます。

```python
>>> 6 // 2
3
>>> 7 // 4
1
```

浮動小数点数を整数に変換するには、`int()`を使います。整数を浮動小数点数に変換するには、`float()`を使います。

```python
>>> int(6 / 2)
3
>>> float(1 + 2)
3.0
```
