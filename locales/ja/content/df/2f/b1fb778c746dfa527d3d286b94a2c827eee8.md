# 説明

あなたは熱心なバードウォッチャーで、この7日間に庭に何羽の鳥が来たかを記録しています。

庭に来た鳥の数を扱うタスクが6つあります。

## 1. 先週の数を確認しましょう

比較のため、先週の数もいつも手元に控えてあります。先週の数は、0、2、5、3、7、8、4でした。先週の数を返す`BirdWatcher.getLastWeek()`メソッドを実装しましょう。

```java
BirdWatcher.getLastWeek();
// => [0, 2, 5, 3, 7, 8, 4]
```

## 2. 今日何羽の鳥が来たか確認しましょう

今日、庭に何羽の鳥が来たかを返す`BirdWatcher.getToday()`メソッドを実装しましょう。鳥の数は日の順に並んでいて、最初の要素が一番古い日の数、最後の要素が今日の数です。

```java
int[] birdsPerDay = { 2, 5, 0, 7, 4, 1 };
BirdWatcher birdCount = new BirdWatcher(birdsPerDay);
birdCount.getToday();
// => 1
```

## 3. 今日の数を増やしましょう

今日の数を増やす`BirdWatcher.incrementTodaysCount()`メソッドを実装しましょう。

```java
int[] birdsPerDay = { 2, 5, 0, 7, 4, 1 };
BirdWatcher birdCount = new BirdWatcher(birdsPerDay);
birdCount.incrementTodaysCount();
birdCount.getToday();
// => 2
```

## 4. 鳥が1羽も来なかった日があったか確認しましょう

庭に来た鳥が0羽だった日があれば`true`を返し、そうでなければ`false`を返す`BirdWatcher.hasDayWithoutBirds()`メソッドを実装しましょう。

```java
int[] birdsPerDay = { 2, 5, 0, 7, 4, 1 };
BirdWatcher birdCount = new BirdWatcher(birdsPerDay);
birdCount.hasDayWithoutBirds();
// => true
```

## 5. 最初の数日間に来た鳥の数を計算しましょう

週の初めから庭に来た鳥の数を返す`BirdWatcher.getCountForFirstDays()`メソッドを実装しましょう。ただし、数えるのは週の初めからの指定された日数分だけにします。

```java
int[] birdsPerDay = { 2, 5, 0, 7, 4, 1 };
BirdWatcher birdCount = new BirdWatcher(birdsPerDay);
birdCount.getCountForFirstDays(4);
// => 14
```

## 6. 忙しい日の数を計算しましょう

日によっては、他の日より忙しいこともあります。忙しい日とは、庭に5羽以上の鳥が来た日のことです。
忙しい日の数を返す`BirdWatcher.getBusyDays()`メソッドを実装しましょう。

```java
int[] birdsPerDay = { 2, 5, 0, 7, 4, 1 };
BirdWatcher birdCount = new BirdWatcher(birdsPerDay);
birdCount.getBusyDays();
// => 2
```
