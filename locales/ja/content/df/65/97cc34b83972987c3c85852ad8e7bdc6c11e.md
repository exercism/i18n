# 指示の補足

## WebAssembly固有の注意点

WebAssemblyのエクスポート`convert`の関数シグネチャは次のとおりです。

```wasm
(func (export "convert")
    (param $arrOffset i32)
    (param $arrLength i32)
    (param $inputBase i32)
    (param $outputBase i32)
    (result i32 i32 i32)
)
```

最初の2つの仮引数`$arrOffset`と`$arrLength`は、32ビット符号付き整数の配列の先頭オフセットと長さを表します。長さの仮引数は、バイト数ではなく、配列の要素数で表されます。この関数を呼び出す前に、呼び出し側はこの配列を、オフセット`$arrOffset`から始まるWebAssemblyの線形メモリに書き込みます。WebAssemblyの線形メモリは常にリトルエンディアンで表現されます。

したがって、呼び出し側は配列`[1,2]`を、次の8バイトの並びとしてエンコードすることになります。

```
| 64 | 65 | 66 | 67 | 68 | 69 | 70 | 71 |
| ---- arr[0] ----- | ---- arr[1] ----- |
,0x01,0x00,0x00,0x00,0x02,0x00,0x00,0x00,
```

仮引数`$inputBase`と`$outputBase`は、線形メモリとは関係ありません。

結果の型は`(i32 i32 i32)`です。最初の2つの値は、線形メモリ上にある出力の`offset`と`length`です。必要であれば、入力に使った線形メモリのアドレスを上書きしてもかまいません。3つ目の戻り値は、エラー処理に使うi32のステータスコードです。

3つ目の戻り値がエラー状態を表している場合、ユニットテストは最初の2つの戻り値は読み取りません。
