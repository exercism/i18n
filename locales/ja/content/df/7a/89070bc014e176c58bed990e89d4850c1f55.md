# 説明

ここでは先生の立場になって考えてみましょう。
1年の終わりに、生徒一人ひとりの成績を数値で付け終えたところです。
あとはこれをアルファベットの成績に変換し、それぞれの成績を取った生徒が何人いるかを数えるだけです。

## 1. 数値の成績をアルファベットの成績に変換する

`letter_grade`関数は、数値の成績を入力として受け取り、アルファベットの成績を出力します。
範囲は次のとおりです。

| 成績 |      点数 |
| :----: | ---------: |
|   A    | 90% - 100% |
|   B    |  80% - 89% |
|   C    |  70% - 79% |
|   D    |  60% - 69% |
|   F    |   0% - 59% |

例：

```jq
75 | letter_grade   # => "C"
```

## 2. アルファベットの成績ごとに生徒の人数を数える

`count_letter_grades`関数は、生徒の名前と成績を対応させたオブジェクトを受け取ります。
出力は、アルファベットの成績ごとに、その成績を取った生徒の人数を対応させたオブジェクトになります。

例：

```jq
{"Joe": 78, "Jane": 93, "Richard": 72} | count_letter_grades
# => {"A": 1, "B": 0, "C": 2, "D": 0, "F": 0}
```

これを解く方法はいくつかあります。
練習として、`reduce`フィルターを使ってみましょう。
