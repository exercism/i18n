# 説明

ここでの課題は、数値を対応する雨粒の音に変換することです。

与えられた数値が次の場合を考えます。

- 3で割り切れるなら、結果に "Pling" を追加します。
- 5で割り切れるなら、結果に "Plang" を追加します。
- 7で割り切れるなら、結果に "Plong" を追加します。
- 3、5、7のいずれでも**割り切れない**なら、結果はその数値を文字列にしたものとします。

## 例

- 28は7で割り切れますが、3でも5でも割り切れないので、結果は`"Plong"`になります。
- 30は3と5で割り切れますが、7では割り切れないので、結果は`"PlingPlang"`になります。
- 34は3、5、7のいずれでも割り切れないので、結果は`"34"`になります。

~~~~exercism/note
ある数が別の数で割り切れるかどうかを確かめるよくある方法は、[余り][remainder]または[剰余][modulo]を0と比べることです。
ほとんどのプログラミング言語には、どちらか一方（または両方）のための演算子や関数が用意されています。

[remainder]: https://exercism.org/docs/programming/operators/remainder
[modulo]: https://en.wikipedia.org/wiki/Modulo_operation
~~~~
