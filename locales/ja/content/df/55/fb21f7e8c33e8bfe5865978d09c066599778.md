# 概要

コンビネータは、スタックを入れ替えるパターンに名前を付け、組み合わせて使えるワードにしたものです。Factorをある程度書くようになると、「`dup`して、Fを実行して、元の値を残す」と考えるのはやめて、`[ F ] keep`と書くだけになります。

| パターン                            | 入れ替え                      | コンビネータ      |
|------------------------------------|-------------------------------|-----------------|
| Fを適用し、入力を残す              | `dup F swap`                  | `[ F ] keep`    |
| 1つの入力に2つの関数               | `dup F swap G`                | `[ F ] [ G ] bi`|
| 1つの入力に3つの関数               | 複雑                          | `[ F ] [ G ] [ H ] tri` |
| 1つの入力にたくさんの関数           | かなり複雑                    | `{ Fs … } cleave`|
| スタックの先頭より*下*にある値を操作する | `swap F swap`            | `[ F ] dip`     |
| 2つの値に同じ操作                  | `swap F swap F`               | `[ F ] bi@`     |
| 2つの値に別々の操作                | `swap F swap G`               | `[ F ] [ G ] bi*`|

`2`が付くファミリー（`2bi`、`2dip`、`2tri`、`2dup`、`2drop`、`2nip`、`2swap`）は、それぞれの操作が*2つ*の入力を必要とするときに同じはたらきをします。`3dup`と`4dup`は、この複製の書き方を、スタックの先頭から3つ、4つの値にまで広げたものです。

cleave / dip / biファミリーのほかにも、[`kernel`][kernel]には、`f`をきれいに伝えてくれる制御フローのバリエーションが用意されています。

| ワード      | 効果                                                |
|-------------|-----------------------------------------------------|
| `if*`       | `true`の分岐は値を見ることができ、`false`の分岐は見ることができません |
| `?last`     | シーケンスの最後の要素。空の場合は`f`               |
| `pop*`      | `pop`の値を捨てるバリエーション（ベクターを変更します） |
| `dupd`      | 上から*2番目*の値を複製します                       |
| `pick`      | 上から*3番目*の値を先頭にコピーします               |
| `swapd`     | 上から2番目と3番目の値を入れ替えます                |
| `rotd`      | 4つ積まれたスタックの下3つを回転させます            |
| `tuck`      | 先頭の値を上から2番目の下にコピーします             |
| `with`      | HOSのために固定値をクォーテーションに埋め込みます   |
| `while`     | 述語が成り立つ間ループします                        |
| `until`     | 述語が成り立つまでループします                      |

適切なコンビネータを選ぶこと自体がひとつのスキルです。一般的なルールはこうです。ある定義の本体で入れ替えワードが2つ以上続けて出てきたら、たいていはその意図をよりよく表すコンビネータがあります。

[kernel]: https://docs.factorcode.org/content/vocab-kernel.html
