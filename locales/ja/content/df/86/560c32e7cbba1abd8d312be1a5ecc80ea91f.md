# 説明

DNAの研究所で、研究データを保存するスペースを節約するために、データを圧縮するさまざまな方法に取り組んできました。チームメイトの一人が、DNAデータをバイナリ表現に変換することを提案します。

| 核酸 | コード |
| ------------ | ----- |
| Adenine      |  `00` |
| Cytosine     |  `01` |
| Guanine      |  `10` |
| Thymine      |  `11` |

これなら必要なデータ保存コストを減らせる可能性がありますが、その代わりに人間が読みにくくなります。そこで、データをエンコードしたりデコードしたりするモジュールを書いて、どれだけ節約できるか測ってみることにします。

## 1. 核酸をバイナリ値にエンコードする

`encode_nucleotide`を実装して、核酸を受け取り、エンコードされたコードの整数値を返すようにします。

```gleam
encode_nucleotide(Cytosine)
// -> 1
// (which is equal to 0b01)
```

## 2. バイナリ値を核酸にデコードする

`decode_nucleotide`を実装して、エンコードされたコードの整数値を受け取り、核酸を返すようにします。

```gleam
decode_nucleotide(0b01)
// -> Ok(Cytosine)
```

## 3. DNAのリストをエンコードする

`encode`を実装して、核酸のリストを受け取り、エンコードされたデータのビット配列を返すようにします。

```gleam
encode([Adenine, Cytosine, Guanine, Thymine])
// -> <<27>>
```

## 4. DNAのビット配列をデコードする

`decode`を実装して、核酸を表すビット配列を受け取り、デコードされたデータを核酸のリストとして返すようにします。

```gleam
decode(<<27>>)
// -> Ok([Adenine, Cytosine, Guanine, Thymine])
```
