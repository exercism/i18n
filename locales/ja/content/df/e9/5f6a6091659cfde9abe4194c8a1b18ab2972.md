# はじめに

Elmでテキストを表現するための基本となるのが、文字と文字列です。
文字列は文字のリストと考えることができ、ほとんどの`List`関数には`String`モジュールに対応するものがあります。

## 文字

`Char`型は、シングルクォートで囲んだ単一のUnicode文字（例：`'a'`）を表します。 
`Char`モジュールには、文字の性質を調べるための述語関数（`Char -> Bool`）が用意されています：`isUpper`、`isLower`、`isAlpha`、`isAlphaNum`。
このモジュールには、文字を変換する関数`toUpper`、`toLower`、`toLocaleUpper`、`toLocaleLower`のほか、`toCode`と`fromCode`で数値のUnicode値（`Int`）との相互変換を行う関数も用意されています。

## 文字列

`String`型は、文字列を効率よく操作するための組み込みの表現で、任意のUnicode文字の並びを表すことができます。
文字列はダブルクォートで囲んで表します：`"this is a string"`。
複数行の文字列は三重のダブルクォートで囲んで表し、エスケープしていないクォートや改行を含めることができます。

```elm 
haiku = 
"""
    Code's strings entwine
    , In binary, thoughts combine
    , Logic's elegant line.
"""
```

## 文字列の操作

`reverse : String -> String`は文字列を逆順にします。
```elm 
reverse "Hello world." 
    --> ".dlrow olleH"
```

`repeat : Int -> String -> String`は文字列をn回繰り返します。
```elm 
repeat 2 "Hello world." 
    --> "Hello world.Hello world."
```

`replace : String -> String -> String -> String`は、与えられた部分文字列をすべて置き換えます。
```elm
replace "Hello" "Goodbye cruel" "Hello world." 
    --> "Goodbye cruel world."
```

`append : String -> String -> String`は2つの文字列を連結します。
`++`演算子を使っても同じことができます。
```elm
append "butter" "fly" 
    --> "butterfly"
"butter" ++ "fly" 
    --> "butterfly"
```

`concat : List String -> String`は文字列のリストを1つの文字列に連結します。
```elm
concat ["never", "the", "less"] 
    --> "nevertheless"
```

`split : String -> String -> List String`は、与えられた区切り文字で文字列を文字列のリストに分割します。
```elm
split ";" "cat;dog;cow" 
    --> ["cat", "dog", "cow"]
```

`join : String -> List String -> String`は、文字列のリストを指定した区切り文字で連結します。
```elm
join "a" ["H", "w", "ii", "n"] 
    --> "Hawaiian"
```

`words : String -> List String`は、空白のまとまりで区切って文字列を文字列に分解します。
```elm
words "How are \t you? \n Good?" 
    --> ["How", "are", "you?", "Good?"]
```

`lines : String -> List String`は、改行で区切って文字列を行に分解します。
```elm
lines "How are you?\nGood?" 
    --> ["How are you?", "Good?"]
```

`cons : Char -> String -> String`は、文字列の先頭に文字を追加します。
```elm
cons 'T' "he truth is out there" 
    --> "The truth is out there"
```

`uncons : String -> Maybe ( Char, String )`は、空でない文字列を先頭と残りに分割します。
これにより、リストと同じように文字列に対してパターンマッチできます。
空の文字列は`Nothing`を返します。
```elm
uncons "abc" 
    --> Just ('a', "bc")
uncons ""
    --> Nothing
```

## 部分文字列の取得

`slice : Int -> Int -> String -> String`は、開始と終了のインデックスを指定して部分文字列を取り出します。
負のインデックスは、リストの末尾から数えます。
```elm
slice 0 6 "snakes on a plane!" 
    --> "snakes"
slice 0 -7 "snakes on a plane!"
    --> "snakes on a"
```

`left : Int -> String -> String`と`right : Int -> String -> String`は、それぞれ文字列の左または右からn文字を取り出します。

```elm
left 2 "Mulder" 
    --> "Mu"
right 2 "Scully" 
    --> "ly"
```

`dropLeft : Int -> String -> String`と`dropRight : Int -> String -> String`は、それぞれ文字列の左または右からn文字を取り除きます。
```elm
dropRight 6 "Hello world." 
    --> "Hello"
dropLeft 6 "Hello world." 
    --> "world"
```

## 文字列の性質を調べる

`length : String -> Int`は文字列の文字数を返します。
```elm 
length "Hello world." 
    --> 12
```

`isEmpty : String -> Bool`は、文字列が空かどうかを判定します。 
```elm 
isEmpty "Hello world." 
    --> False
```

`contains : String -> String -> Bool`は、2番目の文字列が1番目の文字列を含むかどうかを調べます。
```elm
contains "the" "theory" 
    --> True
contains "THE" "theory" 
    --> False
```

`startsWith : String -> String -> Bool`と`endsWith : String -> String -> Bool`は、2番目の文字列が指定した部分文字列で始まるか、終わるかどうかを調べます。
```elm
startsWith "the" "theory" 
    --> True
endsWith "ory" "theory" 
    --> True
```

`indexes : String -> String -> List Int`は、ある文字列の中に部分文字列が現れるすべての開始インデックスのリストを取得します。
```elm
indexes "ss" "Mississippi"  
    --> [2, 5]
```

## 文字列の変換
`toInt : String -> Maybe Int`は、文字列を`Just Int`に変換しようとし、形式が正しくない文字列には`Nothing`を返します。
```elm
toInt "-42" 
    --> Just -42
toInt "3.1" 
    --> Nothing
toInt "two" 
    --> Nothing
```

`fromInt : Int -> String`は、整数を文字列に変換します。
```elm
fromInt -42 
    --> "-42"
```

`toFloat : String -> Maybe Float`は、文字列を小数に変換しようとし、形式が正しくない文字列では失敗します。
```elm
toFloat "-42" 
    --> Just -42.0
toFloat "3.1" 
    --> Just 3.1
toFloat "two" 
    --> Nothing
```

`fromFloat : Float -> String`は、小数を文字列に変換します。
```elm
fromFloat 3.9 
    --> "3.9"
```

`toList : String -> List Char`と`fromList : List Char -> String`は、それぞれ文字列を文字のリストへ、またその逆に変換します。
```elm 
toList "abc" 
    --> ['a', 'b', 'c']
fromList ['a', 'b', 'c'] 
    --> "abc"
```

`fromChar : Char -> String`は、文字を文字列に変換します。
```elm
fromChar 'a' 
    --> "a"
```

## 文字列の書式設定

`toUpper : String -> String`と`toLower : String -> String`は、それぞれ文字列をすべて大文字またはすべて小文字に変換します。
大文字と小文字を区別しない比較に便利です。
```elm
toUpper "skinner" 
    --> "SKINNER"
toLower "X-FILES" 
    --> "x-files"
```

`pad : Int -> Char -> String -> String`は、指定した長さになるまで、与えられた`Char`で文字列の両側を埋めます。
```elm
pad 5 ' ' "11"  
    --> "  11 "
```
同様に、`padLeft`と`padRight`は、指定した長さになるまで文字列の片側を埋めます。

`trim : String -> String`は、文字列の両側の空白を取り除きます。
```elm
trim "  hats  \n" 
    --> "hats"
```
`trimLeft`と`trimRight`は、文字列の片側の空白を取り除きます。

## 高階関数

`map : (Char -> Char) -> String -> String`は、与えられた関数で文字列のすべての文字を変換します。
与える関数は`Char`から`Char`への写像でなければならないことに注意してください。
```elm
map (\c -> if c == '/' then '.' else c) "a/b/c" 
    --> "a.b.c"
```

`filter : (Char -> Bool) -> String -> String`は、テストを通過した文字だけを残します。
```elm
filter isDigit "R2-D2" 
    --> "22"
```

`foldl : (Char -> b -> b) -> b -> String -> b`は、文字列を左から畳み込みます。
この関数が適用されるとき、最初の文字が第1仮引数に、与えられた初期値が第2仮引数になります。
関数の結果は、与えられた初期値と同じ型でなければならず、各文字に順番に適用されます。
```elm
foldl (\c acc -> Char.toCode c + acc) 0 "the sum of my unicode is " 
    --> 2260
```
`foldr`は同じことをしますが、文字列の右側から始めます。

`any : (Char -> Bool) -> String -> Bool`は、与えられた述語に対して`True`を返す文字が1つでもあるかどうかを判定します。
```elm
any isDigit "R2-D2" 
    --> True
any isDigit "heart" 
    --> False
```
`all : (Char -> Bool) -> String -> Bool`は、文字列のすべての文字が与えられた述語に対して`True`を返すかどうかを判定します。
```elm
all isDigit "R2-D2" 
    --> False
all isAlpha "heart" 
    --> True
```
