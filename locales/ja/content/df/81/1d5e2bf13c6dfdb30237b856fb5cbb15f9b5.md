# 概要

Common Lisp Printerは、データをストリームに出力するための機能です。この機能でよく使われる関数の1つが`format`です。

`format`が取る必須仮引数は2つあります。書き込み先のストリームと制御文字列です。制御文字列の内容によって、それ以降の引数をどう使うかが決まります。

1つ目の仮引数には、`t`と`nil`という2つの特別な値があります。`t`は`*standard-output*`に束縛されたストリームを使うことを示し、`nil`は文字列を作って返すことを示します。ストリームの仮引数が`nil`でない限り、`format`は`nil`に評価されます。

制御文字列にはフォーマット指示子を含めることができます。フォーマット指示子は、`~`とそれに続く1文字で表します（その文字の大文字・小文字は区別しません）。フォーマット指示子は、引数を消費するかどうかと、その引数をどのようにストリームへフォーマットするかを定義します。

基本的で重要なフォーマット指示子は次のとおりです。

* `~A` - 「人間が読み取れる」形で、_美的に_フォーマットします。
* `~S` - 「機械が読み取れる」_標準_の形でフォーマットします。
* `~%` - 改行を出力します。
* `~&` - まだ行の先頭にいない場合に改行を出力します。
* `~~` - チルダを出力します。

例：

```lisp
(format nil "The list is: ~A~%" (list 1 2 3)) ; => "The list is: (1 2 3)
                                                   "
(format nil "(format t ~S)" "hello world")    ; => "(format t \"hello world\""
(format nil "~&fresh~&lines")                 ;=> "fresh
                                                   lines"
(format nil "directives start with a ~~")     ; => "directives start with a ~"
```
