# はじめに

## アトム

Elixirの`atom`型は、固定された定数を表します。アトムの値は、それ自身の名前そのものです。これにより、型安全な方法でデータを扱えます。アトムは次のように定義できます。

```elixir
# All atoms are preceded with a ':' then follow with alphanumeric snake-cased characters
variable = :an_atom
```

_アトム_は、内部的にはルックアップテーブル内の整数として表現されており、この値は自動的に設定されます。この内部の値を変更することはできません。

## Cond

条件によって分岐するコードを書きたいことがよくあります。Elixirではこれを行う方法がたくさんありますが、もっとも簡単な方法の1つは`cond/1`を使うことです。

もっとも単純な形では、`cond`は、1つ以上の分岐のうち、最初に`true`と評価されたパスをたどります。

```elixir
cond do
  x > 10 -> :this_might_be_the_way
  y < 7 -> :or_that_might_be_the_way
  true -> :this_is_the_default_way
end
```

どのパスも`true`と評価されなかった場合、ランタイムがエラーを発生させます。
