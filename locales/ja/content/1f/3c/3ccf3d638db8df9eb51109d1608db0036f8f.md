# はじめに

Pythonでは、値が存在しないことを表すために`None`がよく使われます。`null`（空）の変数やオブジェクト、引数を定義するときのプレースホルダーとして使うのです。

他のプログラミング言語で`NULL`や`nil`という型を聞いたり使ったりしたことがあれば、Pythonでのこの`None`の使い方には馴染みがあるでしょう。
`None`を使うと、まだ値が決まっていない変数や関数の引数を宣言できます。
これらはあとから、必要に応じて具体的な値を再代入できます。


```python
a = None
print(a)
#=> None

type(a)
#=> <class 'NoneType'>

# Adding a default argument with `None`
def add_to_todos(new_task, todo_list=None):
    if todo_list is None:
        todo_list = []  
    todo_list.append(new_task)
     
  return todo_list
```

`None`は条件式で使うと`False`と評価されるので、値（_どんな_値でも）の「存在」や「不在」を検証するのに役立ちます。関数や処理が`error`や`object`、メッセージを返すかもしれないときによく使われるパターンです。

```python
a = None
if a: #<-- a will be evaluated to False when it is used in a conditional check.
    print("This will not be printed")
```
