# null

`null`は、`null`という1つの値だけを持つプリミティブ型です。
`null`は、何もないことを表すのによく使われます。
「偽」とみなされますが、`false`や他の偽とみなされる値とは異なります。

```php
<?php

is_null(null); // => true
isset(null); // => false

null == true; // => false
null === true; // => false

null == false; // => true
null === false; // => false
```

## null値の扱い

PHPでは、`null`値がエラーの原因になることがよくあります。エラー状態の代わりに返されたり、何もないことを表すために返されたりするからです。
エラーが起きるのを防ぐには、値を操作する前にその値が`null`でないことを確かめる「nullチェック」がよく必要になります。

nullチェックを何度も繰り返すと間違いが起こりやすくなるため、PHPには`null`値を扱うための演算子が2つ用意されています。null安全アクセス演算子（`?->`）と、null合体演算子（`??`）です。
