プレイヤーは地図の中を巡りながら、宝を拾い集めていきます。
宝物と場所では位置の書き方をわざと変えてあり、そこがまた難しくなっています。
さらに、特別な場所もいくつかあります。そうした場所では、特定の宝物を別の宝物と交換でき、ゲームにひと味違った面白さを加えています。
このゲームを手伝う関数を書くのが、この演習の目的です。

## 1. 位置を変換する

Place Location（`('C', 1)`など）を受け取り、Treasure Location（`(1, 'C')`など）に変換する`placeLocationToTreasureLocation`関数を実装しましょう。

```elm
placeLocationToTreasureLocation ('C', 1)
--> (1,'C')
```

## 2. 宝物と場所の位置を比較する

`PlaceLocation`（`('C', 1)`など）を受け取り、`TreasureLocation`（`(1, 'C')`など）と一致する場合に`true`を返す`treasureLocationMatchesPlaceLocation`関数を実装しましょう。

```elm
treasureLocationMatchesPlaceLocation ('C', 1) (1, 'C')
--> true

treasureLocationMatchesPlaceLocation ('C', 1) (2, 'C')
--> false
```

## 3. 宝物の位置を数える

Place（`("Aqua Lagoon (Island of Mystery)", ('F', 1))`など）と宝物の配列を受け取り、そこに見つけられる宝物の数を返す`countPlaceTreasures`関数を実装しましょう。

```elm
place = ("Aqua Lagoon (Island of Mystery)", ('F', 1))

countPlaceTreasures place treasures =
--> 2
```

## 4. 特別な場所

Treasure（`("Amethyst Octopus", (1, 'F'))`など）とPlace（`("Seaside Cottages ", ('C', 1))`など）を受け取り、次の組み合わせに対して`true`を返す`specialCaseSwapPossible`関数を実装しましょう。

- Brass Spyglassは、Abandoned Lighthouseでは他のどの宝物とも交換できます
- Amethyst Octopusは、Stormy BreakwaterではCrystal CrabまたはGlass Starfishと交換できます
- Vintage Pirate Hatは、Harbor Managers OfficeではModel Ship in Large BottleまたはAntique Glass Fishnet Floatと交換できます

この関数は、`if`文ではなく、アドホックなタプルを使った`case`式として実装してみましょう（これはElmでよく使われる書き方です）。
