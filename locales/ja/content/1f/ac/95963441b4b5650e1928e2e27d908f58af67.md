# パーセント形式、または「旧式の」フォーマット

この解答では、文字列に対して`%%-formatting`または[旧式のフォーマット][old-style formatting]を使っています。

`%%-formatting`もまったく有効なやり方ですが、表現や可読性に問題が生じることがあります。
[str.format()][str.format()]メソッドや[f-strings][f-strings]_（別名「フォーマット済み文字列リテラル」または「補間文字列」）_を使うと、可読性を高め、文字列内での変数の置き換えをよりわかりやすくするオプションを利用できます。

ブログ記事[String Formatting in Python][string formatting in python]は、Pythonの文字列フォーマットのあらゆる選択肢を理解するための良い出発点です。[Newer Python String Format Techniques][newer python string format techniques]にも、`str.format()`と`f-strings`を使うための役立つコツやテクニックが紹介されています。
