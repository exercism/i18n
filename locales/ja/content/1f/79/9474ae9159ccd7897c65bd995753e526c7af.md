# はじめに

SQLでは、`SELECT`文を使ってデータベースからデータを取得できます。
`SELECT`文の結果は結果セットです。
結果セットには、行と列に並んだ値が含まれます。
各列は、データの特定の属性を表します。
各行には、すべての列に対応する値が入っています。

ひとつの見方として、列の集まりはデータ構造を表していて、各列がそのデータ構造のフィールド、各行がそのデータ構造のインスタンスだと考えることができます。

`SELECT`文では、取得したいデータを指定できます。
必要に応じて、出力データを変換したり、絞り込んだり、形を変更したりすることもできます。

## 基本

基本的な`SELECT`文の構成は、次のとおりです。

```sql
SELECT <columns>
FROM <source>
WHERE <criteria>;
```

~~~~exercism/note
`FROM`句と`WHERE`句は省略できます。
たとえば、`SELECT "Hello, world.";`のような文もまったく問題なく動作します。

また、改行は必須ではありません。`SELECT`文の各句（つまり各部分）は、空白で区切るだけでかまいません。
~~~~

`SELECT`キーワードの直後には、結果に含めたい列のリストを書きます。
`FROM`句はデータの取得元を指定します。通常はデータベース内のテーブルです。
`WHERE`句は、1つ以上の条件で出力データを絞り込みます。

## WHERE句でデータを絞り込む

`WHERE`句を使うと、`SELECT`文で取得したデータを絞り込めます。
たとえば、`Appliances`だけが必要な場合は、次のようにします。

```sql
SELECT * FROM inventory
WHERE category = "Appliances";
```

結果:
```
upc           category    supplier        brand      product_name                 weight  stock
------------  ----------  --------------  ---------  ---------------------------  ------  -----
899001234556  Appliances  Culinary Depot  QuickBrew  Single-Serve Coffee Maker    4.2     18   
880012349876  Appliances  Culinary Depot  HeatWave   Compact Toaster Oven         7.5     14   
844110220987  Appliances  Culinary Depot  BlendPro   High-Speed Personal Blender  3.1     16   
```

また、`weight`が2.0から6.0の間にあるデータだけが必要な場合もあります。

```sql
SELECT * FROM inventory
WHERE weight BETWEEN 2.0 AND 6.0;
```

結果:
```
upc           category    supplier        brand      product_name                  weight  stock
------------  ----------  --------------  ---------  ----------------------------  ------  -----
899001234556  Appliances  Culinary Depot  QuickBrew  Single-Serve Coffee Maker     4.2     18   
823450987112  Cookware    KitchenCo       FreshKeep  12-Piece Glass Container Set  6       33   
899998877665  Cookware    KitchenCo       IronCraft  Cast-Iron Grill Pan           5.3     21   
844110220987  Appliances  Culinary Depot  BlendPro   High-Speed Personal Blender   3.1     16   
```

`WHERE`句では、`=`や`BETWEEN...AND`に加えて、さまざまな式を利用できます。比較（`<`、`<=`、`>`、`>=`）、パターンマッチング（`LIKE`、`GLOB`、`REGEXP`、`MATCH`）、リスト内の値かどうかの確認（`IN`、`NOT IN`）などです。
詳細なドキュメントは[SQL言語の式](sql-expr)を参照してください。
