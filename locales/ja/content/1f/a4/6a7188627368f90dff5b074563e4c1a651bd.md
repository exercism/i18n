# Haskellの構文の基本

## 定数と関数

Haskellのプログラムは、定義と式からできています。

定数の値は`name = expression`で定義します。

```haskell
five = 5

six = 3 + 3
```

関数は`name parameters... = expression`で定義し、仮引数はスペースだけで区切ります。

```haskell
add number1 number2 = number1 + number2
```

関数の呼び出しも式であり、関数名を指定して、その関数の各仮引数に引数をスペースで区切って渡します。区切り方は関数定義の場合と同じです。

```haskell
five = add 2 3
```

括弧（`()`）を使うと、式を評価する順序を指定できます。

```haskell
six = add 2 (1 * 4)

twelve = add 2 1 * 4
```

## インデントと意味を持つ空白

Haskellは、空白とインデントを使ってコードの境界を指定します。
***ある式の一部であるコードは、その式の始まりよりもさらに内側にインデントする必要があります。***

- モジュール、インポート、トップレベルの関数定義は、一番左の列から始めなければなりません。
- 式が複数行に分かれるときは、その式の一部であるコードを、その式より少なくとも1つのスペース分深くインデントしなければなりません。
- まとまりになっている式の部分は、同じ数のスペースでインデントします。

```haskell
-- A function split over multiple lines, so subsequent lines must be indented
add number1 number2 =
    number1 + number2
```

https://en.wikibooks.org/wiki/Haskell/Indentation

## モジュール

モジュールは関数をエクスポートします。
つまり、そのモジュールがエクスポート宣言で公開している関数を使えるということです。
モジュールは、内部で使うためだけの関数を定義することもできます。
デフォルトでは、明示的にエクスポートされていない関数は、モジュールの外から使えません。

モジュールの先頭で、モジュール名を指定します。
Calculator.hsというファイルがあるなら、モジュール名はCalculatorにします。
次に、エクスポートする関数を指定し、そのあとで関数を書き始めます。
では、次のように書き始めましょう。

```haskell
module Calculator ( add ) where
```

https://learnyouahaskell.github.io/modules#making-our-own-modules

## コメント

コメントとは、Haskellのファイルの中にある、コードとして解釈されないテキストのことです。
主に、自分自身やほかのプログラマーが読むためのものです。
1行コメントには、2つのハイフンによる軽量な構文が用意されています。
複数行コメントは、開きと閉じの区切り文字である`{-`と`-}`のペアを使えば書くこともできます。

```haskell
-- a single line comment
-- another single line comment

{- a multiline comment
   spanning multiple lines
-}
```
