# 概要

`while`と`until`（[`kernel`][kernel]内）は、繰り返し回数が事前にわからないときに使う、クオーテーション駆動のループコンビネーターです：

```
while ( pred: ( -- ? ) body: ( -- ) -- )
until ( pred: ( -- ? ) body: ( -- ) -- )
```

`while`は、`pred`が真とみなされる値を残すかぎり繰り返し続けます。`until`は、`pred`が`f`を残すかぎり繰り返し続けます。どちらも、述語が反転したときに止まり、値を返します。

```factor
USING: kernel math ;

! Halve down to 1
16 [ dup 1 > ] [ 2 / ] while .   ! => 1

! Double up to 100
1 [ dup 100 >= ] [ 2 * ] until .   ! => 128
```

スタックを流れる1つの値だけでは状態として足りないことがあります。たとえば、残りのリスト、途中までの合計、カウンターを同時に扱いたい場合です。そんなときは、名前付きの*ローカル変数*を使うのがいちばんすっきりした書き方です。ローカル変数については、この後のカリキュラムで詳しく扱います。ここでは、`:: word ( a b -- c )`が入力を名前付きのローカル変数として宣言すること、そして`:> name!`が、本体から`value name!`で更新できる可変のローカル変数を追加することだけ知っておけば十分です。

```factor
USING: kernel locals math sequences ;

! Sum a sequence by hand
:: sum-by-hand ( seq -- total )
    seq :> rest!
    0 :> running!
    [ rest length 0 > ] [
        rest unclip [ rest! ] dip
        running + running!
    ] while
    running ;
```
