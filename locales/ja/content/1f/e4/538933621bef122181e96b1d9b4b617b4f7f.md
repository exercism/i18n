# はじめに

## 辞書

辞書は要素の集まりで、各要素はキーと値で構成されています。辞書のメソッドにキーを渡すと、それに対応する値が返されます。他のプログラミング言語におけるマップや連想配列と同じ役割を果たします。

辞書は次のようにして作成できます：

```csharp
new Dictionary<int, string>();
// Empty dictionary
```

または

```csharp
new Dictionary<int, string>
{
    [1] = "One",
    [2] = "Two"
};

// Or

new Dictionary<int, string>
{
    {1, "One"},
    {2, "Two"}
};
// 1 => "One", 2 => "Two"
```

キーと値の型が辞書の定義の一部であることに注意してください。

作成したあとは、辞書に組み込まれているメソッド`Add`と`Remove`を使って、要素を追加したり削除したりできます。

辞書の値を取得したり更新したりするには、キーを使って辞書にインデックスを付けます：

```csharp
var numbers = new Dictionary<int, string>
{
   {1, "One"},
   {2, "Two"}
};

// Set the value of the element with key 2 to "Deux"
numbers[2] = "Deux";

// Get the value of the element with key 2
numbers[2];
// => "Deux"
```

値が辞書に存在するかどうかは、次のようにして確認できます：

```csharp
var dict = new Dictionary<string, string>{/*...*/};
dict.ContainsKey("some key that exists");
// => true
```

辞書を列挙すると、そのキーと値のペアが列挙されます。辞書には、キーまたは値だけを列挙できるプロパティもあります。
