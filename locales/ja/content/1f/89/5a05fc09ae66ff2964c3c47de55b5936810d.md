# リソース

## はじめてのCoffeeモジュールを作る

`Bob = require './bob'`で読み込めるモジュールを作るには、次のコードを`bob.coffee`に書きます。

```coffeescript
class Bob

module.exports = Bob
```

モジュールについての詳しい情報は、[Nodeのドキュメント](http://nodejs.org/api/modules.html#modules_module_exports)にあります。

## WindowsでのVisual Studio

有料版のVisual Studioをお持ちなら、CoffeeScriptと、Visual Studioが対応しているその他の言語ですぐに使えるように設定済みのVisual Studioソリューションをダウンロードできます。

![Solution Explorer](https://raw.githubusercontent.com/exercism/coffeescript/main/docs/img/SolutionExplorer.png)

1. ページのDownload Zipボタンをクリックして、GitHubから[Exercism.io Visual Studio Template](https://github.com/rprouse/Exercism.VisualStudio)をダウンロードします。
2. テンプレートを、たとえば`C:\src\exercises`のような演習用ディレクトリに解凍します。
2. [Exercism CLI](http://exercism.io/cli)をインストールします
3. 演習用ディレクトリでコマンドプロンプトを開きます
4. exercismにAPIキーを追加します `exercism configure --key=YOUR_API_KEY`
5. exercismでソースディレクトリを設定します `exercism configure --dir=C:\src\exercises`
6. [はじめての演習をフェッチします](http://exercism.io/languages/coffeescript) `exercism fetch coffeescript`
7. Visual StudioでExercismソリューションを開きます
8. Exercism.coffeescriptプロジェクトを展開します
9. Solution Explorerで**Show All Files**をクリックします（下記参照）
10. いまフェッチした演習がグレー表示で現れます。フォルダーを右クリックして**Include In Project**を選びます
11. さあ、コーディングを始めましょう...

![ファイルの追加](https://raw.githubusercontent.com/exercism/coffeescript/main/docs/img/AddFiles.png)

Visual StudioでCoffeeScriptを扱うには、[Web Essentials](http://vswebessentials.com/)拡張機能をインストールすることをおすすめします。これを入れると、JavaScriptを扱うのもずっと楽になります。

プロジェクト内のバッチファイルを使えば、node.jsのコマンドラインからユニットテストを実行できます。

```bash
C:\Src\exercises\coffeescript> test example\bob_test.spec.coffee
.................

Finished in 0.02 seconds
17 tests, 17 assertions, 0 failures, 0 skipped
```

テストを実行しても何も出力されない場合は、Node.jsのコマンドプロンプトに入っていない可能性が高いです。
