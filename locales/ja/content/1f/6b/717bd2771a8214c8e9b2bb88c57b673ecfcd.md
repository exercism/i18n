# 指示

ルトンの図書館は、本から芸術作品まで幅広い蔵書を誇る大きな図書館です。この図書館には、文学を研究し、本をコンピューターシステムに登録する部門があります。

いくつかの業務は自動化を目指しており、そのお手伝いを頼まれています。登録手続きのフォームの自動化から、テキストの復号の補助まで、幅広い作業が含まれます。

## 1. タイトルの最初の文字を取得する

図書館の本はすぐに見つけられるように、タイトルの最初の文字で並べ替えられています。

`Library.first_letter`メソッドを実装してください。このメソッドは、本のタイトルが入った引数`title`を受け取ります。
メソッドはタイトルの最初の文字を返すようにしてください。

```Crystal
Library.first_letter("Mystery of the Crystal Skull")
# => 'M'
```

## 2. 著者のイニシャルを取得する

図書館には、さまざまな著者が書いた本がたくさんあります。
著者はイニシャルで呼ばれることが多いため、図書館は著者の名前と苗字を入力するとその著者のイニシャルを返すシステムを求めました。
イニシャルは`{first_letter_of_first_name}.{first_letter_of_last_name}`のように整形します。

`Library.initials`メソッドを実装してください。このメソッドは、著者の名前と苗字が入った`first_name`と`last_name`の2つの引数を受け取ります。
メソッドは著者のイニシャルを返すようにしてください。

```Crystal
Library.initials("William", "Shakespeare")
# => "W.S"
```

## 3. 文字を復号する

文学作品の中には暗号化されたものもあり、図書館には暗号化されたテキストがたくさんあります。
図書館は、特殊な暗号方式のための新しい復号システムを望んでいます。

この暗号方式は、文字をアルファベット順で1つ前の文字に置き換えることで成り立っています。
たとえば`a`は`z`に、`b`は`a`に、`c`は`b`に、といった具合です。

図書館は、大文字と小文字の両方を復号でき、元の文字と同じ大文字・小文字を保つことを望んでいます。

`Library.decrypt_character`メソッドを実装してください。このメソッドは、復号する文字が入った引数`character`を受け取ります。
メソッドは復号した文字を返すようにしてください。

```Crystal
Library.decrypt_character('a')
# => 'z'
```

## 4. テキストを復号する

図書館は、アルファベット順で1つ前の文字に置き換えるこの暗号方式で、テキスト全体を復号できるようにもしたいと考えています。

復号プログラムは文字だけを復号し、それ以外の文字はそのままにしておく必要があります。

`Library.decrypt_text`メソッドを実装してください。このメソッドは、復号するテキストが入った引数`text`を受け取ります。
メソッドは復号したテキストを返すようにしてください。

```Crystal
Library.decrypt_text("Ifmmp Xpsme!")
# => "Hello World!"
```
