# はじめに

Juliaの`String`は、[Unicode](https://en.wikipedia.org/wiki/Unicode)文字を[UTF-8](https://en.wikipedia.org/wiki/UTF-8)でエンコードした、変更できない有限の並びです。

`String`リテラルは、二重引用符で囲んだ文字の並びです。

```julia-repl
julia> "Christopher"
"Christopher"
```

文字列は`*`演算子で連結できます。

```julia-repl
julia> "Christopher" * " " * "Paolini"
"Christopher Paolini"
```

~~~~exercism/advanced
なぜJuliaが文字列の連結に`+`ではなく`*`を使うのか気になる方は、[Juliaのマニュアル](https://docs.julialang.org/en/v1/manual/strings/#man-concatenation)を覗いてみてください。
~~~~

特殊な文字の中には、前にバックスラッシュを付けてエスケープする必要があるものがあります。

```julia-repl
julia> println("\t or spaces?")
         or spaces?
```

Juliaには、文字列を操作するための便利な関数が標準でたくさん用意されています。

```julia-repl
julia> lowercase("TEST")
"test"

julia> titlecase("TEST")
"Test"
```
