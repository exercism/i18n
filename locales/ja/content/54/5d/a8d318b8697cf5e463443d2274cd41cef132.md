# はじめに

**浮動小数点数**とは、`-1.23`や`3.1415`のように、小数部分を持つことができる数値のことです。

このような数値をバイト列として表現するために、x86-64では**IEEE-754**規格が使われています。この規格で最もよく使われる形式は、単精度浮動小数点数と倍精度浮動小数点数です。x86-64はその両方をサポートしています。

単精度浮動小数点数は32ビット幅で、倍精度浮動小数点数は64ビット幅です。

## XMMレジスター

x86-64には、浮動小数点演算を行うための専用レジスターが16個あり、`xmm0`から`xmm15`という名前が付けられています。

これらのレジスターは少なくとも128ビット幅ですが、最近のプロセッサーでは256ビットや512ビットに拡張されています。ただし、実際には、ほとんどの浮動小数点数は必要な精度に応じて、最下位の32ビットまたは64ビットしか使いません。

## 数値の変換

数値の形式を相互に変換するための命令群として、`cvtxx2yy`があります。

`xx`と`yy`はどちらもリテラルではなく、プレースホルダーです。

- `xx`はソースオペランドの型を表すプレースホルダーです。
- `yy`はデスティネーションオペランドの型を表すプレースホルダーです。

このプレースホルダーはさまざまな形を取ることができ、その中には次のようなものがあります。

| プレースホルダー | 意味               |
| ----------- | --------------------- |
| `si`        | 符号付き整数        |
| `ss`        | 32ビット浮動小数点数 |
| `sd`        | 64ビット浮動小数点数 |

たとえば、次のようになります。

```x86asm
cvtsi2ss xmm0, eax ; converts a 32-bit signed integer to a single-precision floating-point
cvtsd2si rax, xmm1 ; converts a double-precision floating-point to a 64-bit signed integer
```

32ビット整数を64ビット浮動小数点数に変換したり、64ビット整数を32ビット浮動小数点数に変換したりすることもできます。同様に、32ビット浮動小数点数を64ビット整数に変換したり、64ビット浮動小数点数を32ビット整数に変換したりすることもできます。つまり、`cvtxx2yy`の2つのオペランドのサイズは、_同じである必要はありません_。

```x86asm
cvtsi2sd xmm0, eax ; converts a 32-bit signed integer to a double-precision floating-point
cvtsi2ss xmm0, rax ; converts a 64-bit signed integer to a single-precision floating-point
cvtss2si rax, xmm0 ; converts a single-precision floating-point to a 64-bit signed integer
cvtsd2si eax, xmm0 ; converts a double-precision floating-point to a 32-bit signed integer
```

浮動小数点数を整数として正確に表現できない場合、`cvtxx2si`は`mxcsr`という特別なレジスターの丸め制御に従って数値を丸めます。丸め方には、最近接への丸め、切り下げ、切り上げ、切り捨てがあります。関数に入った時点でのデフォルトは保証されていません。

なお、正確な結果は丸められず、したがって丸め制御の影響を受けません。たとえば、`42.0`は_常に_`42`に変換されます。

似た命令群として、`cvttxx2si`（`t`が1つ多い）という形式があり、こちらは常に結果を切り捨てます。

## 丸め

`roundxx`命令群は、ソースオペランドの浮動小数点数を丸めた浮動小数点数に変換し、デスティネーションオペランドに格納します。

ここでも`xx`はオペランドの型を表すプレースホルダーで、`ss`は単精度、`sd`は倍精度の浮動小数点数を意味します。

これらの命令は、第3オペランドとして定数を取ります。この数値が丸めモードを指定します。

| 数値 | モード         |
| :----- | :----------- |
| 0      | 最近接      |
| 1      | 切り下げ（下方向） |
| 2      | 切り上げ（上方向）    |
| 3      | 切り捨て     |

たとえば、次のようになります。

```x86asm
roundss xmm0, xmm1, 1 ; this rounds down (takes the floor) a 32-bit floating-point in xmm1 and stores it in xmm0
roundsd xmm2, xmm2, 2 ; this rounds up (takes the ceil) a 64-bit floating-point in xmm2 and stores it in xmm2
```

これらの命令は正確な結果を生成するので、`cvtxx2si`の前準備として使うことができます。

## 算術命令

浮動小数点数の操作の多くは、整数用の同等の命令とよく似た名前の命令を使いますが、末尾に必要なプレースホルダー（`ss`または`sd`）を付けます。これらの命令は、乗算や除算を行うものも含め、通常の意味を持つ2オペランド命令です。

```x86asm
addss xmm1, xmm2 ; xmm1 = xmm1 + xmm2 (all 32-bit floating-point)
mulsd xmm4, xmm5 ; xmm4 = xmm4 * xmm5 (all 64-bit floating-point)
divss xmm0, xmm3 ; xmm0 = xmm0 / xmm3 (all 32-bit floating-point)
```

## 移動

XMMレジスターから別のレジスターへ移動する命令は、`movss`または`movsd`です。

```x86asm
movss xmm1, xmm0 ; this copies a 32-bit floating-point from xmm0 to xmm1
movsd xmm6, xmm4 ; this copies a 64-bit floating-point from xmm4 to xmm6
```

即値（定数の符号付き整数）をxmmレジスターへ直接移動することは**できません**。この数値はまず汎用レジスターへ移動し、次に`cvtsi2xx`を使って変換する必要があります。

```x86asm
mov rax, 10        ; rax is a 64-bit integer with value 10
cvtsi2sd xmm0, rax ; xmm0 is a 64-bit floating-point with value 10.0
```

## 比較

2つの浮動小数点数を比較する命令には、2つのグループがあります。`comixx`と`ucomixx`という形式で、`xx`は`ss`または`sd`のいずれかです。どちらも`cmp`と同じ意味に従って、通常どおり`rflags`のフラグを設定します。

両者の違いは、2つの浮動小数点数の一方が`NaN`値を持つ場合、`ucomixx`は`parity flag (PF)`を設定するのに対し、`comixx`は例外を発生させる点です。

浮動小数点数の比較は_符号なし_で行われます。

```x86asm
ucomisd xmm0, xmm1
ja .greater         ; 'ja' must be used for "greater", not 'jg'
jb .lesser          ; 'jb' must be used for "lesser", not 'jl'
```

## 呼び出し規約

System V ABIでは、最初の8つの浮動小数点引数が、`xmm0`から`xmm7`の順に関数へ渡されます。浮動小数点値は、`xmm0`、必要に応じて`xmm1`で関数から返されます。

すべての`xmm`レジスターは自由に使うことができ、呼び出し側のために予約されているものはありません。

## メモリー

浮動小数点値は、同じサイズの整数と同じ意味に従ってメモリー内に定義できます。NASM（The Netwide Assembler、このトラックで使われているアセンブラー）では、浮動小数点値を指数表記で宣言することもできます。

```x86asm
section .data
    pi dq 3.141592653589793 ; this is a double-precision floating-point value
    exp_num dd 1.e5 ; this is a single precision floating-point value equal to 1 * 10⁵
    exp_num2 dd 1.e+5 ; this is a single precision floating-point value equal to 1 * 10⁵
    frac dq 1.e-10 ; this is a double precision floating-point value equal to 1 * 10⁻¹⁰, i.e., 0.0000000001
```
