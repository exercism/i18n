# ヒント

## 1. Alienクラスを作成する

- `object methods`には常に最初の仮引数として`self`が渡されることを覚えておきましょう。
- `__init__()`の_両側_にある二重アンダースコアを忘れないようにしましょう。
- インスタンス変数は、それを持つ`class`のインスタンス（_オブジェクト_）に固有のものです。
- クラス変数は、`class`のすべてのインスタンスで同じです。

## 2. `hit`メソッド

- `object methods`には常に最初の仮引数として`self`が渡されることを覚えておきましょう。
- Alienの体力が0を下回ることを許すか、下回らないようにするかを選べます。

## 3. `is_alive`メソッド

- `object methods`には常に最初の仮引数として`self`が渡されることを覚えておきましょう。
- `hit()`の実装のしかたによっては、0だけが「死んでいる」条件とは限りません。

## 4. `teleport`メソッド

- `object methods`には常に最初の仮引数として`self`が渡されることを覚えておきましょう。
- インスタンス属性は、`self.<attribute> = <new attribute value>`を使うことで、メソッドから更新できます。

## 5. `collision_detection`メソッド

- `object methods`には常に最初の仮引数として`self`が渡されることを覚えておきましょう。
- このメソッドは、何らかのプレースホルダーを使うのに絶好の場所に思えます…

## 6. Alienのカウンター

- クラス属性は、`class`のすべてのインスタンスで同じです。
- 理想的には、このカウンターは_新しいAlienが作られる_たびに増えるとよいでしょう。
- クラス属性は、_クラス名_を使ってインスタンスメソッドから変更できます：`Alien.<class attribute name>`。
- `__init__()`は_新しいオブジェクトを初期化する_ので、インスタンスメソッドとみなされます。

## 7. オブジェクトの作成

- `tuple`は_単一_の仮引数になります。
- Alienのコンストラクターは_2つの仮引数_を受け取ります。
- タプルの_中身_を展開すれば、2つの仮引数が得られます。
- 独立した関数は`class`の外側にあります。
