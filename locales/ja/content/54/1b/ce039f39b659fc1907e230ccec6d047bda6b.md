# 詳細

小数は、小数点以下の桁を持つ数値です。

```gleam
let float = 3.45
// -> 3.45
```

小数には、専用の演算子もあります。

```gleam
1.0 +. 1.4 // -> 2.4
5.0 -. 1.5 // -> 3.5
5.0 /. 2.0 // -> 2.5
3.0 *. 3.1 // -> 9.3

2.0 >. 1.0  // -> True
2.0 <. 1.0  // -> False
2.0 >=. 1.0 // -> True
2.0 <=. 1.0 // -> False
```

小数でも、読みやすくするためにアンダースコアを追加できます。

```gleam
1_000_000.0 // One million
```

小数では、指数表記も使えます。

```gleam
1.01e3 // -> 1010
15.1e-3 // -> 0.0151
```
