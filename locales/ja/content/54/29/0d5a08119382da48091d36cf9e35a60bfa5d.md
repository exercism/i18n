# はじめに

## 比較演算子

比較演算子は、多くの他のプログラミング言語とよく似ています。

等しいかどうかを比べる演算子は、`==`（等しい）と`!=`（等しくない）です。

```Kotlin
val txt = "abc"
txt == "abc" // => true
txt != "abc" // => false
```

大小を比べる演算子も、一般的なものと同じです。

```Kotlin
1 < 3 // => true
3 > 3 // => false
3 <= 3 // => true
4 >= 3 // => true
```

## `if`による分岐

`if`式の完全な形は、次のとおりです。

```Kotlin
if (conditional1) {
//    something...
} else if (conditional2) {
//    something...
} else {
//    something...
}
```

- それぞれの条件を囲む括弧（`()`）は必須です。
- 条件は、真偽値の`true`か`false`に評価される必要があります。
  Kotlinには、一部の言語にあるような「truthy」や「falsy」という考え方はありません。
- 式が1つだけなら、波括弧（`{}`）は省略できます。
- `else if`と`else`はどちらも省略でき、`else if`ブロックは複数書くこともできます。

`if`式は、値を「選ぶ」ためにも使えます。

```Kotlin
val number = 100000
val description = if (number > 100) "number is over 100" else "number is less than 100"
// => description = "number is over 100"
```

## 代わりの書き方は？

Kotlinはあえて、Javaにある三項演算子`? :`を持っていません。
むしろ、簡潔な`if ... else`の形が好まれます。

```Kotlin
return if (isOK) goodValue else badValue
```
