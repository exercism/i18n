# 概要

多くのプログラムでは、現実世界の出来事をシミュレーションするために、（一見すると）ランダムな値が必要になります。

よくある身近な例としては、次のようなものがあります。
- コイントス：`('Heads', 'Tails')`からランダムに選ばれる値。
- サイコロを振ること：1から6までのランダムな整数。
- トランプをシャッフルすること：カードのリストをランダムに並べ替えたもの。

コンピューターで真にランダムな値を生成するのは[驚くほど難しい技術的課題][truly-random]なので、こうした結果は「疑似乱数」と呼ばれることがあります。

実際には、Pythonの標準ライブラリにある[`random`][random]モジュールのような、よく設計されたライブラリは高速で柔軟であり、モデリングやシミュレーション、ゲームのほとんどの用途に十分な結果をもたらします。

このページの残りでは、`random`でよく使われる関数をいくつか紹介します。
ここで扱うものよりもはるかに多くの選択肢がありますので、`random`のドキュメント全体もぜひ読んでみてください。

## インポート

`random`モジュールの機能を使うには、まずインポートする必要があります。

```python
>>> import random

# Choose random integer from a range
>>> random.randrange(1000)
360

>>> random.randrange(-1, 500)
228

>>> random.randrange(-10, 11, 2)
-8

# Choose random integer between two values (inclusive)
>>> random.randint(5, 25)
22

```

モジュール名を毎回入力するのを避けるには、特定の関数を名前でインポートできます。

```python
>>> from random import choice, choices

# Using choice() to pick Heads or Tails 10 times
>>> tosses = []
... for side in range(10):
...    tosses.append(choice(['H', 'T']))    

>>> print(tosses)
['H', 'H', 'H', 'H', 'H', 'H', 'H', 'T', 'T', 'H']


# Using choices() to pick Heads or Tails 8 times
>>> picks = []
... picks.extend(choices(['H', 'T'], k=8))
... print(picks)
['T', 'H', 'H', 'T', 'H', 'H', 'T', 'T']
```


## ランダムな整数の生成

`randrange()`関数には3つの形式があり、`range(start, stop, step)`からランダムな値を選びます。
  1.  `randrange(stop)`は、`0 <= n < stop`となる整数`n`を返します。
  2.  `randrange(start, stop)`は、`start <= n < stop`となる整数`n`を返します。
  3.  `randrange(start, stop, step)`は、`start <= n < stop`であり、かつ`n`が`start, start + step, start + 2*step...`という数列に含まれるような整数`n`を返します。

`step == 1`というよくある場合には、`randint(a, b)`関数のほうが便利で読みやすいこともあります。
`randint()`の結果には上限も_含まれる_ため、`randint(a, b)`は`randrange(a, b+1)`を使うのと同じです。

```python
>>> import random

# Select one number at random from the range 0, 499
>>> random.randrange(500)
219

# Select 10 numbers at random between 0 and 9 two steps apart.
>>> numbers = []
... for integer in range(10):
...    numbers.append(random.randrange(0, 10, 2))

>>> print(numbers)
[2, 8, 4, 0, 4, 2, 6, 6, 8, 8]

# roll a die
>>> random.randint(1, 6)  
4
```



## シーケンスの操作

このセクションの関数は、何らかの[シーケンス][sequence-types]などのコンテナから始めることを前提としています。


通常は`list`ですが、いくつかの制約はあるものの`tuple`や`set`の場合もあります（_`tuple`はイミュータブルで、`set`は順序を持ちません_）。



### `choice()`と`choices()`

`choice()`関数は、与えられたシーケンスからランダムに選んだ1つの要素を返します。
最も単純なのは、コイントスのような場合です。

```python
# This will pick one of the two values in the list at random 5 separate times 
>>> [random.choice(['H', 'T']) for _ in range(5)]
['T', 'H', 'H', 'T', 'H']
```


`choices()`関数を使って、リストの長さをキーワード引数として指定すれば、ほぼ同じことができます。

```python
>>> random.choices(['H', 'T'], k=5)
['T', 'H', 'T', 'H', 'H']
```


上の例では、表と裏の確率が等しい公平なコインを仮定しましたが、重みを指定することもできます。
たとえば、袋の中に赤いボールが10個、緑のボールが15個入っていて、そこからランダムに1つ取り出したいとします。

```python
>>> random.choices(['red', 'green'], [10, 15])
['red']
```



### `sample()`

上の`choices()`の例は、統計学者が[「復元抽出」][sampling-with-replacement]と呼ぶものを想定しています。
それぞれの選択は、その後の選択の確率に**何の影響も与えず**、選ばれうるものの分布は毎回同じままです。


赤と緑のボールの例では、1つ選ぶたびにボールを袋に_戻し_、よく振ってから次を選びます。
これは、赤いボールを取り出したら_それを袋の外に出したままにする_場合とは対照的です。
ボールを戻さないということは、袋の中の赤いボールが減るということであり、次の選択で赤が出る可能性は_低く_なります。

この「非復元抽出」をシミュレーションするために、randomモジュールには`sample()`関数があります。
`sample()`の構文は`choices()`と似ていますが、`counts`というキーワード引数が追加されています。


```python
>>> random.sample(['red', 'green'], counts=[10, 15], k=10)
['green', 'green', 'green', 'green', 'green', 'red', 'red', 'red', 'red', 'green']
```

サンプルは選ばれた順に返されます。



### `shuffle()`

`choices()`と`sample()`はどちらも、`k > 1`のとき新しいリストを返します。
これに対して、`shuffle()`はリストの順序を_**その場で**_ランダムに並べ替え、元の順序は失われます。

```python
>>> my_list = [1, 2, 3, 4, 5]
>>> random.shuffle(my_list)
>>> my_list
[4, 1, 5, 2, 3]
```


## 分布の操作

ここまでは、どの結果も同じ確率で起こる場合に焦点を当ててきました。
たとえば、`random.randrange(100)`は0から99までのどの整数も同じ確率で返します。

現実世界の多くの状況は、これよりもはるかに複雑です。
そのため、統計学者は「現実世界」の結果を数学的に記述するために、さまざまな[`distributions`][probability-distribution]を考案してきました。



### 一様分布

整数の場合、すべての確率が等しいときには`randrange()`と`randint()`を使います。
これは[`uniform`][uniform-distribution]分布と呼ばれます。


`randrange()`と`randint()`には、浮動小数点数を扱う同等の関数があります。

__`random()`__は、`0.0 <= x < 1.0`となる`float`値`x`を返します。

__`uniform(a, b)`__は、`a <= x <= b`となる`x`を返します。

```python
>>> [round(random.random(), 3) for _ in range(5)]
[0.876, 0.084, 0.483, 0.22, 0.863]

>>> [round(random.uniform(2, 5), 3) for _ in range(5)]
[2.798, 2.539, 3.779, 3.363, 4.33]
```



### ガウス分布

「正規」分布、「ベル型」曲線とも呼ばれ、測定値の不正確さを表すごく一般的な方法です。

たとえば、勤め先の工場が、同じはずのボルトを1万本購入したとします。
それらを扱えるように工場のロボットを設定したいので、100本をサンプルとして重さを量ったところ、平均（`mean`）の重さが4.731gであることがわかりました。
これは、すべてがちょうど4.731gであることを意味する可能性はきわめて低いです。
値は4.627から4.794gの範囲にありながら、4.731gの周辺に集まっていることがわかるかもしれません。

これが[`Gaussian distribution`][gaussian-distribution]であり、平均で確率が最も高くなり、両側に対称に裾を引きます（これが「ベル型」と呼ばれるゆえんです）。
これをソフトウェアでシミュレーションするには、曲線の幅を指定する方法が必要です（_一般に、高価なボルトは安価なボルトよりも平均の周りに密集します！_）。

慣例として、これは[`standard deviation`][standard-deviation]で表します。値が小さいと鋭く狭い曲線に、大きいと低く広い曲線になります。
数学者はギリシャ文字が大好きなので、平均を表すのに`μ`（'mu'）、標準偏差を表すのに`σ`（'sigma'）を使います。
したがって、「95%の値がμの2σ以内にある」とか「ヒッグス粒子が5シグマの信頼度で検出された」といった記述を目にしたら、それは標準偏差に関するものです。

```python
>>> mu = 4.731
>>> sigma = 0.316
>>> [round(random.gauss(mu, sigma), 3) for _ in range(5)]
[4.72, 4.957, 4.64, 4.556, 4.968]
```
