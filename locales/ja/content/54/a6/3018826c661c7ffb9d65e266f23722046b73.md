# Bashシェルでの算術演算入門

Bashは算術演算ができますが、_整数のみ_です。
浮動小数点の計算が必要な場合は、外部のプログラム（[awk][awk]や[bc][bc]など）を呼び出す必要があります。

算術演算子は、マニュアルの[シェル算術][arithmetic]に（優先順位の順で）記載されています。

さらに、Bashが算術演算を行うのは特定の場所だけです（これらは算術の「コンテキスト」と呼ばれます）。

## 算術展開

算術展開は[コマンド置換][cmd-sub]に似ていますが、二重括弧（`(( ))`）を使います。

```bash
$(( expression ))
```

この構文は、式を評価した結果に展開されます。
結果を変数に格納するためによく使われます：

```bash
x=$(( 3 + 4 ))
```

~~~~exercism/note
括弧の中にどれだけ空白を入れるかは、自由です。
スタイルと読みやすさの問題です。

```bash
x=$(( 3 + 4 ))
y=$((5+6))
```

この記事の著者は、括弧の中で算術式がより見やすくなるように、空白を入れるのが好きです。
~~~~

## 算術条件式

算術条件式は、先頭の`$`を_付けずに_、二重括弧の中で実行します：

```bash
(( expression ))
```

これは結果には展開されません。
ただし、_終了ステータス_を生成します。

* 式の結果が**ゼロ以外**であれば、終了ステータスは0（成功）です。
* 式の結果が**ゼロ**であれば、終了ステータスは1（失敗）です。

~~~~exercism/note
`((`の中では、BashはC言語と同じ真偽の考え方を使います。つまり、ゼロは偽、ゼロ以外は真です。
**これは、Bashが終了ステータスを評価する方法とは逆です！**
~~~~

この構文は、主に2つの場所で使われます：

1. [`if`文][conditional-if]や[`while`ループ][looping-while]のコマンド部分として。

   ```bash
   if (( x == y - 1 )); then ...
   while (( y > 0 )); do ...
   ```

1. 変数の値を変更する単独のコマンドとして。

   ```bash
   (( x = x + 1 ))
   echo "new value for x is $x"
   ```

   ~~~~exercism/caution
   このように算術演算を`set -e`と組み合わせて使うときは、注意してください。
   式がゼロと評価されると、終了ステータスがゼロ以外になり、Bashは終了します。

   ```bash
   x=0
   (( x++ ))
   echo "you will see this"

   set -e
   x=0
   (( x++ ))
   echo "shell exits on the previous line; you won't see this"
   ```

   `++`演算子についてより詳しく知りたい場合は、[後置インクリメントと前置インクリメント][incr]の記事を参照してください。

   [incr]: https://thisvsthat.io/postincrement-vs-preincrement
   ~~~~


## 算術コンテキストが使われるその他の場所

算術コンテキストになる場所は、ほかにもいくつかあります：

* [算術`for`ループ][looping-for]です。

  ```bash
  for (( i = 0; i < 10; i++ )); do
      echo "$i"
  done
  ```

* 数値でインデックス付けされた配列のインデックス部分です。

  ```bash
  echo "The next element is ${array[x + 1]}"
  # ................................^^^^^
  ```

  配列について詳しくは、[配列][arrays]のコンセプトドキュメントを読んでください。

* `${var:offset:length}`展開のオフセット部分と長さ部分です。
* [`let`組み込みコマンド][let]です。
  * `let "expresson"`より`(( expression ))`が推奨されることに注意してください。
    算術条件式の構文とは異なり、`let`の式はファイル名展開と単語分割の対象となり、クォートが必要です。
* 変数に「整数属性」が付いている場合の変数代入です。

  ```bash
  # variable x does not have the integer attribute
  x="3 + 4"
  declare -p x      # => declare -- x="3 + 4"

  # variable y has the integer attribute
  declare -i y
  y="4 + 5"
  declare -p y      # => declare -i y="9"
  ```

  ~~~~exercism/note
  著者の意見では、`declare -i`の用途は限られています。
  その主な利点は、「裸の」算術（算術式の構文を使わないもの）を可能にすることです。
  これにより、コードを読む人が混乱するかもしれません。予期しない場所で算術式が評価されるからです。
  ~~~~

## 算術式で変数を使う

算術コンテキストの中には、読みやすさを高める側面があります。

```bash
height=10
width=20
area=$(( height * width ))
```

算術式の中の変数から`$`のドル記号が消えていることに気づきましたか？
Bashではそれができます。
これにより、式がずっと読みやすくなります。

マニュアルには、次のように書かれています。

> 式の中では、シェル変数はパラメーター展開の構文を使わずに、名前で参照することもできます。

配列の要素でも同じように動作します：

```bash
point1=(10 15)  # these are (x, y) coordinates
point2=(20 7)
distance_squared=$(( (point1[0] - point2[0])**2 + (point1[1] - point2[1])**2 ))
```

ただし、その他のパラメーター式は、それぞれ独自の構文を使う必要があります。
たとえば、文字列の長さを2倍にする場合は次のようになります：

```bash
s="hello world"
len=$(( ${#s} * 2 ))
```

位置パラメーターも同様です。
最初の2つの位置パラメーターが幅と高さを表す場合は、次のようになります：

```bash
area=$(( $1 * $2 ))
```
