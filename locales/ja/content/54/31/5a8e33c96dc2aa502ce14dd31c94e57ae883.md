# 概要

`readonly`修飾子は、フィールドの値や参照が上書きされるのを防ぎますが、参照型のメンバーについては何も保護してくれません。

```csharp
readonly List<int> ints = new List<int>();

void Foo()
{
    ints.Add(1);    // ok
    ints = new List<int>(); // fails to compile
}
```

参照型のメンバーをすべて保護したいときは、フィールドを`readonly`にして、`set`アクセサーのない自動プロパティを定義します。

Base Class Library（BCL）には、コレクションのメンバーが更新されないようにしたい場面に向けた、読み取り専用のコレクションがいくつか用意されています。それらはラッパーという形で提供されています。

- [`ReadOnlyDictionary<T>`][ReadOnlyDictionary]
- [`ReadOnlyCollection<T>`][ReadOnlyCollection]
