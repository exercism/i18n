# 学習

Pascalというプログラミング言語には長い歴史があり、オンラインのドキュメントの多くは初心者向けに書かれています。こうしたチュートリアルのほとんどはコンソールプログラムを扱うもので、画面に情報を出力したり、ユーザーの入力を読み取ったりします。たとえば、もっともよくある初心者向けチュートリアルの1つに、画面に'Hello World'を出力するプログラムがあります。

```pascal
program HelloWorld;
begin
  writeln('Hello World!');
end.
```

このプログラムをコンソールやターミナルから実行すると、画面に'Hello World'と出力されます。

Exercismでは、解答が正しいかどうかを確かめるために自動テストを使っています。そのため、**プログラム**ではなく**ユニット**を使う必要があります。主な違いは、ターミナルに何かを出力するのではなく、関数から値を返す必要があることです。

```pascal
writeln('Hello World!');
```

これが次のようになります。

```pascal
result := 'Hello World!'
```

writeやwritelnコマンドは、情報を表示したり、コマンドや計算などの出力をテキストとして取得したりするのに、今でも役立ちます。
