# テスト

テストを実行するには、次のコマンドを実行します。

```shell
corepack pnpm test
```

ほかのユーザーと同じように、ESLintを使って、コードを静的に解析し、ベストプラクティスやコーディングスタイルに沿ったコードを書くようにしましょう。ESLintは、コードを静的に解析してくれるツールです。こうしたツールは、JavaScriptのコードのタイプミスやうっかりミスを発見する時間を節約してくれることもあります。

```shell
corepack pnpm lint
```

Jestは「watch」モードで実行することもできます。このモードでは、コードやテストモジュールを保存すると、テストが自動的に再実行されます。

```shell
corepack pnpm watch
```

## skipテストを理解する

skipメソッドは、テストスイートに特定のテストを実行しないよう指示します。この関数は、`it.skip(name, fn)`や`xit(name, fn)`、`xtest(name, fn)`という別名でも使えます。

- なぜスキップされるのでしょうか？

一度に1つのテストに集中できるようにし、解答を育てながら1つずつ有効にしていくためです。

- どうやって有効にするのでしょうか？

`xtest`を`test`に変えます。

```javascript
test('title cased phrases', () => {
  expect(Acronyms.parse('Portable Network Graphics')).toEqual('PNG');
});
```

## 初めてのJavaScript 2015モジュールを作る

通常、このトラックのテストは、実装をJavaScriptモジュールとしてインポートして読み込みます：`import { Bob } from './bob.js';`。
参照されているファイル`bob.js`から実装をエクスポートするだけで大丈夫です。

```javascript
export function hey(message) {}
```

モジュールについての詳しい情報は、[Babelのドキュメント](https://babeljs.io/docs/learn-es2015/#modules)にあります。
始めやすくするために、ディレクトリには_スケルトン_のJavaScriptファイルが用意されています。
