# 概要

型を暗黙的にキャストできない場合は、明示的なキャスト[演算子][cast-operator]を使う必要があります。キャスト演算子とは、キャストしたい値の前に、キャスト先の型を括弧（`()`）で囲んで置くだけのものです。

```csharp

int i = 7;
byte b = (byte)i; // Explicit cast from int to byte
```

明示的なキャストを使うときには、危険が伴います。よくある間違いは次の2つです。

- 互換性のない型へキャストする。実行時に例外がスローされます。
- 「幅」が足りない数値へキャストする。整数の場合、符号の衝突を起こしたり、オーバーフローの例外がスローされたりすることがあります。

注意：`int`型の式は、明示的に`char`へキャストできます。その結果、有効でない`char`になることがあります。

[cast-operator]: https://docs.microsoft.com/en-us/dotnet/csharp/language-reference/operators/type-testing-and-cast#cast-expression
