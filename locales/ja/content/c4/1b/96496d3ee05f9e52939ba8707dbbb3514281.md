# 指示の補足

## レジスタ

| レジスタ | 用途         | 型      | 説明                                          |
| -------- | ------------ | ------- | -------------------------------------------- |
| `$a0`    | 入力         | 整数    | 入力の桁数                                   |
| `$a1`    | 入力         | 整数    | 入力の桁の基数                               |
| `$a2`    | 入力         | 整数    | 出力の桁の基数                               |
| `$a3`    | 入力/出力    | アドレス | 上書き可能な、桁を表すワードの配列            |
| `$v0`    | 出力         | 整数    | 出力の桁数（入力が無効なときは-1）            |
| `$t0-9`  | 一時         | 任意    | 一時的な保存に使う                           |
