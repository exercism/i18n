# はじめに

F#の`string`は、Unicode文字（英字、数字、記号など）の並びとして不変のテキストを表すオブジェクトで、次のように定義します：

```fsharp
let fruit = "Apple"
```

文字列は、文字列のメソッドを呼び出すか、`String`モジュールの関数を使うことで操作します。一度文字列を作成すると、その値を変更することはできません。文字列を変更するように見えるメソッドや関数も、実際には新しい文字列を返します。

文字列の連結や書式設定には、いくつかの方法があります。
* 連結には`+`演算子を使えます：
```fsharp
let sentence = "Apple" + " is a type of fruit."
```
* テキストの書式設定には`sprintf`関数を使えます。書式文字列の中にプレースホルダー（`string`の場合は`%s`）を置き、値を引数として渡します：
```fsharp
let sentence = sprintf "%s is a type of %s." "Apple" "fruit"
```
