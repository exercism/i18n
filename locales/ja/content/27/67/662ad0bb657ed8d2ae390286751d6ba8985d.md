# はじめに

何かを自分自身を使って定義できることを、再帰と呼びます。F#で再帰が最もよく現れるのは、再帰関数です。再帰関数とは、自分自身を呼び出す関数のことです。

再帰関数には、少なくとも1つの*ベースケース*と、少なくとも1つの*再帰ケース*が必要です。ベースケースは、関数を再び呼び出さずに値を返します。再帰ケースは、入力を変化させながら関数を再び呼び出し、いずれベースケースに一致するようにします。

再帰関数は通常の関数と同じように定義しますが、`rec`修飾子を付けます。この修飾子がないと、関数は自分自身を呼び出せません。呼び出そうとすると、コンパイルエラーになります。そのため、再帰を使うには明示的に指定する必要があります。

```fsharp
let rec factorial x =
    // Base case
    if x = 1 then
        1
    // Recursive case
    else
        x * factorial (x - 1)
```

F#は、判別共用体を使った再帰型もサポートしています。再帰的な判別共用体では、1つ以上のケースが、そのデータの中で判別共用体自身を参照します。再帰関数と同様に、再帰型にもベースケースが必要です。再帰関数とは異なり、再帰型では`rec`キーワードを使いません。

```fsharp
type RussianDoll =
    | Doll                 // Base case
    | Layer of RussianDoll // Recursive case
```
