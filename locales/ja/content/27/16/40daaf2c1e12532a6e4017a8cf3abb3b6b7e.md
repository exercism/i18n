# 概要

## はじめに

ジェネリクスとは、コードの再利用を可能にする言語の機能です。
たとえば、配列がどんな型の値を持つかは、その長さを計算するうえで問題になりません。
そのため、`length`関数は型シグネチャーでジェネリックな型パラメーター`a`を使っています。

```elm
length : List a -> Int
```

## 型のパラメーター

ある型が別の型に対してジェネリックであるとき、その別の型には小文字の名前を使い、それを型パラメーターと呼びます。
よくある例は、`List`、`Maybe`、`Result`というカスタム型です。

```elm
-- Maybe is generic over the type a
type Maybe a
    = Nothing
    | Just a

someString : Maybe String
someString = Just "hello"

someInt : Maybe Int
someInt = Just 42
```

型パラメーターの名前について大事なのは、複数の文字を使えるということです。
唯一の制約は、小文字の名前でなければならないことです。
そのため、役に立つときには、説明的な名前を付けるようにしています。

型は複数の別の型に対してジェネリックにでき、その場合は複数の型パラメーターを持ちます。
その場合、それぞれ独立した型に異なる小文字の名前を付けます。
独立しているからといって、同じ型になれないわけではありません。違う型になれるようにしているだけです。

```elm
-- Result is generic over the types error and value
type Result error value
    = Ok value
    | Err error
```

レコードの型エイリアスも型パラメーターを持てますが、あまり一般的ではありません。

```elm
-- Event is generic over the type a
type alias Event a =
    { at : Time
    , data : a 
    }
```

## 関数の型パラメーター

型がジェネリックにできるのですから、関数も同じです。
ジェネリックな型を扱う関数も書けます。たとえば、`Maybe.withDefault`などです。

```elm
withDefault : a -> Maybe a -> a
withDefault default maybe =
    case maybe of
      Just value -> value
      Nothing -> default
```

他の関数を入力として受け取る関数は高階関数と呼ばれ、これらもジェネリックにできます。

```elm
map : (a -> b) -> Maybe a -> Maybe b
map function maybe =
  case maybe of
    Just value ->
      Just (function value)

    Nothing ->
      Nothing
```
