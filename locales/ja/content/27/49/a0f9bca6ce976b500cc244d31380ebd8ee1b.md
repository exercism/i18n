# 説明

この演習では、ログ行を処理します。

各ログ行は、`"[<LVL>]: <MESSAGE>"`という形式の文字列です。

ログレベルには、次の種類があります：

- `TRC`（トレース）
- `DBG`（デバッグ）
- `INF`（情報）
- `WRN`（警告）
- `ERR`（エラー）
- `FTL`（致命的）

取り組むタスクは3つあります。

## 1. ログレベルを解析する

上のログレベルに対応する6つの要素を持つ`LogLevel`列挙型を定義します。

- `Trace`
- `Debug`
- `Info`
- `Warning`
- `Error`
- `Fatal`

次に、(_static_)な`LogLine.ParseLogLevel()`メソッドを実装して、ログ行のログレベルを解析します：

```csharp
LogLine.ParseLogLevel("[INF]: File deleted")
// => LogLevel.Info
```

## 2. 未知のログレベルに対応する

残念ながら、ときどき未知のログレベルを持つログ行があります。そうしたログ行をうまく処理するために、`LogLevel`列挙型に`Unknown`要素を追加し、未知のログレベルを解析したときにはこれが返されるようにします：

```csharp
LogLine.ParseLogLevel("[XYZ]: Overly specific, out of context message")
// => LogLevel.Unknown
```

## 3. ログ行を短い形式に変換する

ログ行のログレベルはかなり冗長です。ログ行を保存するために必要なディスク容量を減らすため、短い形式が考案されました：`"[<ENCODED_LEVEL>]:<MESSAGE>"`

エンコードされたログレベルは、ログレベルを数値に対応させただけの単純なものです：

- `Unknown` - `0`
- `Trace` - `1`
- `Debug` - `2`
- `Info` - `4`
- `Warning` - `5`
- `Error` - `6`
- `Fatal` - `42`

短縮されたログ行の形式を出力する(_static_)`LogLine.OutputForShortLog()`メソッドを実装します：

```csharp
LogLine.OutputForShortLog(LogLevel.Error, "Stack overflow")
// => "6:Stack overflow"
```
