# はじめに

Elixirのマップは、情報をキーと値のペアで保存するためのデータ構造です。他の言語では、連想配列（PHP）、ハッシュ（Perl 5、Raku）、辞書（Python）などとも呼ばれます。

キーと値にはどんなデータ型でも使えますが、キーがアトムの場合は省略記法を使えます。マップは、アクセスしたときや返したときにエントリの順序を保証しません。

## リテラル形式

空のマップは`%{}`で宣言するだけです。マップリテラルに項目を追加したい場合は、2つの形式を使えます:

```elixir
# If the key is an atom:
%{atom_key: 1}

# If the key is a different type:
%{1 => :atom_value}

# You can even mix these if the atom form comes second:
%{"first_form" => :a, atom_form: :b}
```

決まった形式はありませんが、キーと値のリテラルのペアを表す方法は一貫させましょう。

## マップモジュールの関数

Elixirは、マップを扱うための多くの関数を_Mapモジュール_に用意しています。_Mapモジュール_の関数の中には、マップの変換を助けるために、_無名関数_を渡す必要があるものもあります。
