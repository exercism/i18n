# はじめに

ループには基本的に2つの種類があります。

1. 条件を満たすまでループします。
2. コレクションの要素をループします。

どちらもJuliaで可能ですが、2つ目のほうがよく使われるかもしれません。

## `while`ループ

ループの回数が事前にわからない、終わりの決まっていない問題には、Juliaの`while`ループが適しています。

基本的な形はとてもシンプルです。

```julia
while condition
    do_something()
end
```

この場合、プログラムは`condition`が`true`でなくなるまでループを回り続けます。

ループを途中で抜ける方法は2つあります。

- `break`を使うとループを抜け、実行はループの`end`の次の行から続きます。
- `return x`を使うと現在の関数の実行が止まり、戻り値`x`が呼び出し元に返されます。

これらの方法があると、`while true ... end`で「無限」ループを作り、ループ本体の中で停止条件を見つけて`break`や`return`を実行する、という書き方が便利なこともあります。

## コレクションをループする

もっとも単純な例は、範囲をループすることです。

何かを10回行いたいときは、次のように書きます。

```julia
for n in 1:10
    do_something(n)
end
```

現在の繰り返しが何らかの条件を満たさない場合、`continue`を使ってすぐに次の繰り返しに進むことができます。

```julia
for n in 1:10
    if is_useless(n)
        continue
    end
    
    # we decided this iteration could be useful
    do_something_slow(n)
end
```

短い形では、`if`ブロックを`is_useless(n) && continue`に置き換えることもできます。

ほかにもさまざまな種類のコレクションをループできます。配列の要素、文字列の文字、辞書のキーなどです。

ここまでの例では範囲`1:10`をループしており、値がループのインデックスにもなっています。

より一般的には、値だけでなくインデックスが必要になることもあります。
そのためには`eachindex()`関数を使います。たとえば、`for i in eachindex(my_array) ... end`のように書きます。

## 内包表記

明示的なループを書くことは、多くの従来の言語に比べてJuliaではあまり一般的ではありません。より簡潔に書ける方法がいろいろあるからです。

特によくあるのは、別のコレクション（ベクトル、文字列、集合など、ほかにもたくさんあります）の要素から新しいベクトルを作りたいときです。

Pythonのリスト内包表記が好きな人なら、Juliaでも似た構文が使えると知ってうれしくなるでしょう。

要点は、ベクトルの中に非常にコンパクトなループを書くことです。

もっとも単純な構文は、`result = [f(x) for x in some_collection]`の形です。

従来のループで書くと、次のようになります。

```julia
result = []
for x in some_collection
    push!(result, f(x))
end
```

必要に応じて、末尾に条件を追加して、コレクション内の条件に合う要素だけを選ぶこともできます。

```julia-repl
# multiples of 3
julia> [n^2 for n in 1:10 if n%3 == 0]
3-element Vector{Int64}:
  9
 36
 81
```
