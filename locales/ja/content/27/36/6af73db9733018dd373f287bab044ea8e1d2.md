# はじめに

タプルは、値を順番に並べて持つコンテナです。Gleamの他のデータ型と同じく、タプルは不変です。タプルの各要素はそれぞれ違う型でもかまいません。要素が別のタプルであってもよいのです。

タプルは、`#(`と`)`の間にカンマで区切った値を並べて書きます：`#(1, 2.0, "Three")`。

```gleam
#("one", 2)      // Tuple pair (2 values)
#("one", 2, 3.0) // Tuple triplet (3 values)
```

長さと型が同じ（順番も同じ）タプルどうしは、同じかどうかを比較できます。

```gleam
#(1, 2) == #(1, 2) // Same length, same types, same values, same order
// -> True

#(1, 2) == #(2, 1) // Same length, same types, same values, different order
// -> False

#(1, 2) == #(1, "2") // Same length, different types
// Compile error!

#(1, 2) == #(1, 2, 3) // Different length
// Compile error!
```

タプルに入っている値を取り出す方法は、次の3つです。

- インデックス指定。
- `let`を使ったパターンマッチ。
- `case`を使ったパターンマッチ。

```gleam
let person = #("Jordan", 52)

// Option 1: Indexing
person.0 // -> "Jordan"
person.1 // -> 52

// Option 2: let
let #(name2, length2) = person
// -> name2 = "Jordan"
// -> length2 = 52

// Option 3: case
case person {
  #(name3, length3) -> {
    name3   // -> "Jordan"
    length3 // -> 52
  }
}
```

タプルのインデックス指定は、`case`式のガードでも使えます。

```gleam
pub fn is_18(person) {
  case person {
    _ if person.1 >= 18 -> True
    _ -> False
  }
}
```
