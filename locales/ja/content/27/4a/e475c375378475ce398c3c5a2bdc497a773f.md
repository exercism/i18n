# はじめに

Goでは、`map`はキーを値に対応付ける組み込みのデータ型です。
他のプログラミング言語では、`map`と同じ概念を辞書、ハッシュテーブル、キーと値のストア、連想配列といった名前で知っているかもしれません。

構文としては、`map`は次のように書きます。

```go
map[KeyType]ElementType
```

また、それぞれのキーは一意であることも押さえておきましょう。つまり、同じキーに2回代入すると、そのキーに対応する値が上書きされます。

マップを作るには、次のように書きます。

```go
  // With map literal
  foo := map[string]int{}
```

または

```go
  // or with make function
  foo := make(map[string]int)
```

`map`でできる操作をいくつか紹介します。

```go
  // Add a value in a map with the `=` operator:
  foo["bar"] = 42
  // Here we update the element of `bar`
  foo["bar"] = 73
  // To retrieve a map value, you can use
  baz := foo["bar"]
  // To delete an item from a map, you can use
  delete(foo, "bar")
```

`map`に存在しないキーの値を取得しようとすると、値の型のゼロ値が返ります。
`ElementType`のデフォルト値（たとえば`int`なら0）が有効な値である場合、これは特に混乱の元になります。
キーが`map`に存在するかどうかを確認するには、次のように書きます。

```go
  value, exists := foo["baz"]
  // If the key "baz" does not exist,
  // value: 0; exists: false
```
