# https://www.php.net/manual/en/language.basic-syntax.phptags.php"スコープ解決演算子

スコープ解決演算子（`::`）を使うと、クラスを参照して、そのクラス定数、静的プロパティ、静的メソッドにアクセスできます。

```php
class MyClass
{
  public const MY_VALUE = 1;
}

// MyClass::class => "MyClass"
// MyClass::MY_VALUE => 1
```

## スコープ解決演算子で`self`と`static`を使う

オブジェクトが自分自身のスコープを参照する必要がある場合があります。そのために、`self`キーワードを使うと、クラスが自分自身のスコープを参照できるようになります。`self`キーワードを使うと、クラスをそのクラス名から切り離せるため、コードを長く保守しやすくなります。

```php
class MyClass
{
  public const MY_VALUE = 1;

  public function getMyValue(): int
  {
    return self::MY_VALUE;
  }
}

// (new MyClass)->getMyValue() => 1
```

ただし、`self`は、それが書かれているクラスに字句的に束縛されます。

```php
class MyOtherClass extends MyClass
{
  public const MY_VALUE = 99;
}

// (new MyOtherClass)->getMyValue() => 1
```

`MyOtherClass::getMyValue`を評価しても、結果は`99`ではなく`1`のままです。これを回避するには、スコープ解決演算子と`static`キーワードを組み合わせて、参照を現在の子孫クラスに「遅延束縛」します。

```php
// Update MyClass:
class MyClass
{
  public const MY_VALUE = 1;

  public function getMyValue(): int
  {
    return static::MY_VALUE;
  }
}
```

## スコープ解決演算子で`parent`を使う

親スコープで利用できる定数、プロパティ、メソッドを明示的に参照したい場合があります。

```php
class MyClass
{
  public function getMaximum(): int
  {
    return 5;
  }
}

class AnotherClass extends MyClass
{
  public function getMaximum(): int
  {
    return parent::getMaximum() * 2;
  }
}

// (new AnotherClass())->getMaximum() => 10
```

オブジェクト指向プログラミングでは、オブジェクトをインスタンス化するときに、親のコンストラクターを呼び出すために`parent`を使うのが最も一般的です。

```php
class ChildClass extends ParentClass
{
  public function __construct(): void
  {
    parent::__construct();
  }
}
```

## 注意点

### 定数・プロパティ・メソッドの可視性

スコープ解決演算子も、`public`、`private`、`protected`という可視性修飾子が定める規則に従います。
