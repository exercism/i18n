# はじめに

Haxeでは、抽象型は実行時には別の型になる型です。これはコンパイル時の機能で、具象型の「上に」型を定義し、その振る舞いを変更したり拡張したりするためのものです。

```haxe
abstract AbstractInt(Int) {
    inline public function new(i:Int) {
        this = i;
    }
}
```

ここでは、`abstract`キーワードを使って`AbstractInt`型を宣言しています。その構文は`class`のものとよく似ています。そしてクラスと同じように、抽象型もメソッドを持つことができます。また、クラスと同じようにインスタンス化して使うこともできます。

```haxe
class Main {
    static public function main() {
        var a = new AbstractInt(12);
        trace(a); // 12
    }
}
```
