# 概要

`List`は、[`Array`][array]とよく似ています。ただし、見逃せない大きな違いがいくつかあります。

1. リストは角括弧（`[]`）でインデックスを指定できません。つまり、`[0]`とは書けません。
2. リストは初期化できません。
3. リスト内包表記はありません。
4. リストは、要素を繰り返し処理しながら自由に変更できます。

`List`は`haxe.ds`パッケージに含まれているので、リストを使うときは、そのパッケージをインポートする必要があります。

```haxe
import haxe.ds.List;

class Main {
  static function main() {
    var myList = List<Int>();

    for (i in 0...5) {
      myList.add(i);
    }

    trace(myList); // {0, 1, 2, 3, 4}
  }
}
```

[array]: https://haxe.org/manual/std-Array.html
