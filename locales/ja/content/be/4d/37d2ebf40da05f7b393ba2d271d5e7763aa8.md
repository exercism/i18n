# Instructions

この演習では、貯蓄口座を扱います。貯蓄口座の残高は、毎年、利率に基づいて更新されます。銀行が適用する利率は、口座に入っている金額（残高）によって決まります。

- 残高が0以上で`1000`ドル未満の場合は0.5%。
- `1000`ドル以上`5000`ドル未満の正の残高の場合は1.621%。
- `5000`ドル以上の正の残高の場合は2.475%。
- 残高が負の場合は3.213%（利子も負になります）。

ここには3つのタスクがあり、それぞれが残高とその利率を扱います。

## 1. 利率を計算する

指定された残高に基づいて利率を計算する`SavingsAccount.interest_rate`メソッドを実装しましょう。

```ruby
SavingsAccount.interest_rate(200.75)
#=> 0.5
```

戻り値が`Float`のインスタンスであることに注意してください。

## 2. 年間の残高更新を計算する

利率を考慮して、年間の残高更新を計算する`SavingsAccount.annual_balance_update`メソッドを実装しましょう。

```ruby
SavingsAccount.annual_balance_update(200.75)
#=> 201.75375
```

戻り値が`Float`のインスタンスであることに注意してください。

## 3. 目標の残高に到達するまでの年数を計算する

目標の残高に到達するために必要な最小年数を計算する`SavingsAccount.years_before_desired_balance`メソッドを実装しましょう。

```ruby
SavingsAccount.years_before_desired_balance(200.75, 214.88)
#=> 14
```

戻り値が`Integer`のインスタンスであることに注意してください。
