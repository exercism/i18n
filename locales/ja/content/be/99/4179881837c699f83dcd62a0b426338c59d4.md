# インストール

Cairoは、Scarbをダウンロードするだけでインストールできます。ScarbにはCairoコンパイラーとCairo言語サーバーがインストールしやすいパッケージとしてまとめられているので、すぐにCairoのコードを書き始められます。Scarbは、Cairoのパッケージマネージャーでもあります。

お使いのプラットフォームに合った推奨のインストール手順については、[Cairo公式サイト](https://www.cairo-lang.org/tutorials/getting-started-with-cairo/)を参照してください。

オペレーティングシステムごとの手順は次のとおりです。

- Linux/MacOS
    1. [asdf](https://asdf-vm.com/guide/getting-started.html)をインストールします
    2. [scarb](https://docs.swmansion.com/scarb/download#install-via-asdf)をインストールします
    3. 新しいターミナルセッションで、`scarb --version`を実行してインストールを確認します
- Windows
    1. [scarb](https://docs.swmansion.com/scarb/download#windows)をインストールします
    2. 新しいターミナルセッションで、`scarb --version`を実行してインストールを確認します

ツールチェーンをインストールすればそれで終わり、というわけではありません！　IDEのサポートは生産性を大きく高めてくれるもので、今ではほとんどのエンジニアが当たり前にあるものだと期待しています。Visual Studio Codeを使っている場合は、[Cairo拡張機能](https://marketplace.visualstudio.com/items?itemName=starkware.cairo1)をインストールするのがおすすめです。この拡張機能を使うと、シンタックスハイライトやコード補完など、便利な機能が利用できます！
