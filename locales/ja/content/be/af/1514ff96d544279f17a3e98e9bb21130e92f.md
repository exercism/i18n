# はじめに

高校時代、初めて代数を習ったときのことを覚えていますか？

たいていは連立方程式が与えられ、`x`と`y`について解くよう求められます。

```
4x - 3y = -2
2x + 7y = 16
```

2つの方程式に2つの未知数。少し代入すれば、すぐに`x = 1, y = 2`だとわかります。

先ほどの例の左辺をもう一度見てみましょう。
行列`[4 -3; 2 7]`に未知のベクトル`[x, y]`を掛けて、ベクトル`[-2, 16]`が得られる、という形に見えます。

線形代数の記法では**A** **x** = **b**です。行列には大文字、ベクトルには小文字を使うのが通例です。

## **A x = 0**と零空間

重要な特別なケースは、すべての方程式の右辺がゼロのときです。

```
4x - 3y = 0
2x + 7y = 0
```

上の例では、解は`x = y = 0`のときだけです。ふつう、これはあまり面白い話ではありません。

**A x = 0**の自明でない解が存在するのは、**A**の[行列式][wiki-determinant]がゼロのときだけです。

```julia-repl
julia> using LinearAlgebra

julia> A = [4 -3; 2 7]
2×2 Matrix{Int64}:
 4  -3
 2   7

julia> det(A)  # not zero!
34.0
```

では、代わりに次の方程式を考えてみましょう。

```
4x - 3y = 0
8x + 6y = 0
```

2番目の方程式は1番目の2倍にすぎず、新しい情報は何も加わりません。
`x = 0.75y`となる値はすべて解になります。

こうした`(x, y)`の値は、2次元空間の直線上に並びます。
解は無限にあり、それらはこの行列の[零空間][wiki-nullspace]を成します。

この場合、行列の行は[線形独立][indep]ではなく、行列の[階数][rank]は行数や列数より小さくなります。

```julia-repl
julia> A = [4 -3; 8 -6]
2×2 Matrix{Int64}:
 4  -3
 8  -6

julia> det(A)
0.0

julia> size(A)  # total number of rows and columns
(2, 2)

julia> rank(A)  # number of linearly-independent rows (or columns)
1

julia> nullspace(A)
2×1 Matrix{Float64}:
 -0.6
 -0.8

julia> nullspace(A) |> norm  # Julia returns unit vectors when possible
1.0
```

[`nullspace()`][ref-nullspace]関数は1つの点を返します。この点は単位ベクトルに[正規化][wiki-unit-vec]されるように選ばれますが、このベクトルのスカラー倍もすべて零空間に含まれます。

## **A x = b**を解く

では、1000個の未知数について1000本の方程式があるとしたら、どうでしょう？
ばかばかしいと思うなら、ワイヤレスのデジタルトランスデューサーが今では安価で多用途であることを思い出してください（ひずみ、風速、3軸の加速度、何でも測定できます）。
吊り橋のような現代の構造物を、1000個のトランスデューサーで監視するのは、まったく理にかなっています。
データの流れを解釈し、異常があれば警報を発する制御システムが必要です。

ここでも**A** **x** = **b**です。**A**（設計から得られる）と**b**（トランスデューサーによる測定値）はわかっていますが、**x**を求めたいのです。

これに慣れていない人なら、まず「両辺を**A**で割って」右辺に移すことを思いつくでしょう。

実際、**A**には逆行列があります（すべてではありませんが、ほとんどの正方行列にあります。[行列式][wiki-determinant]がゼロでないことが条件です）。そしてこの計算はうまくいきます（_遅いですが！_）。

```julia-repl
julia> A = [4 -3; 2 7]
2×2 Matrix{Int64}:
 4  -3
 2   7

julia> b = [-2, 16]
2-element Vector{Int64}:
 -2
 16

# the inverse matrix
julia> inv(A)
2×2 Matrix{Float64}:
  0.205882   0.0882353
 -0.0588235  0.117647

julia> inv(A) * b
2-element Vector{Float64}:
 0.9999999999999999
 2.0
```

残念ながら、逆行列の計算は小さな行列でも遅く、大きな行列では極めて遅くなります。
計算中に橋が崩落したら、たまったものではありません！

幸いなことに、もっと劇的に速いアルゴリズムがあります（ここでは[ガウス消去法][gaussian-elim]です）。

Juliaは（Matlabにならって）ソルバーにバックスラッシュを使うだけです（正確には「左除算」です）。

```julia-repl
julia> x = A \ b
2-element Vector{Float64}:
 1.0
 2.0
```

これは単純な例ですが、注意すべき点がいくつかあります。

- 係数は列をそろえる必要があるので、抜けている項には必要に応じてゼロを入れます。
- 方程式（つまり行列の行）は[線形独立][indep]である必要があります。行3が行1と行2の和にすぎないなら、新しい情報は加わらず、問題は不定になります。

[`rank()`][rank]コマンドを使うと、線形独立な行（または列）の数がわかります。これが未知変数の数と一致することを目指しましょう。

```julia-repl
julia> rank(A)
2
```

### 長方行列

十代になる前に、`N`個の未知数を解くには`N`本の連立方程式が必要だと習ったはずです。

数学のほとんどの事柄と同じように、現実はもう少し微妙です（前の節で触れた線形独立の話だけではありません）。

#### 行が「少なすぎる」場合

`N-1`本の方程式（行列`A`の行数）では、問題は不定です。
絶望して諦めるべきでしょうか？

それは状況によります！

`N-1`本の方程式にも、まだ多くの情報が含まれています。
幾何学的に言えば、解をN次元空間の_点_として定めるには`N`が必要ですが、`N-1`でも、解が_直線_上のどこかにあることはわかります。

そうすると解は無限にありますが、同時に_解を持たない_パラメータ空間も無限に広がります。

解の直線は、まともなエンジニアなら心配すべきパラメータ空間の領域を通っているでしょうか？
それとも、構造物を一般の立ち入り禁止にする正当な理由になる領域でしょうか（_吊り橋は強い横風で揺れやすいのです_）？
それを確かめるために、もう少し計算してみる価値はあるかもしれません！

```julia-repl
julia> A3 = [4 -3 1; 2 2 2; 3 -4 -3]
3×3 Matrix{Int64}:
 4  -3   1
 2   2   2
 3  -4  -3

julia> b3 = [1, 12, -14]
3-element Vector{Int64}:
   1
  12
 -14

# fully-determined solution
julia> A3 \ b3
3-element Vector{Float64}:
 1.0
 2.0
 3.0

# remove row 3 from A3 and B3
julia> A2 = A3[1:2, :]
2×3 Matrix{Int64}:
 4  -3  1
 2   2  2

julia> b2 = b3[1:2]
2-element Vector{Int64}:
  1
 12

# an under-determined solution
julia> z1 = A2 \ b2
3-element Vector{Float64}:
 1.594594594594594
 2.445945945945947
 1.9594594594594592
```

バックスラッシュのソルバーが解を出してくれました！
[非公式には][underdet]、これはノルムが最小の解（幾何学的には原点に最も近い解）だそうです。

他の解を求めるには、`A2`の[`nullspace`][ref-nullspace]が必要です。

元の解に零空間のスカラー倍を加えると、別の有効な解になります。

```julia-repl
# get the nummspace of A2
julia> N = nullspace(A2)
3×1 Matrix{Float64}:
 -0.46499055497527725
 -0.3487429162314578
  0.813733471206735

# add a random multiple of the nullspace to the earlier solution
julia> z = z1 + rand() * N
3×1 Matrix{Float64}:
 1.274331860650258
 2.205748895487695
 2.5199192438620472

# our random z is a valid solution, recovering b2 = [1, 12]
julia> A2 * z
2×1 Matrix{Float64}:
  0.9999999999999947
 12.0
```

同様に、`N-2`本の方程式では（無限の）解が平面に制約され、同じ原理が当てはまります。

#### 行が「多すぎる」場合

反対の状況は、未知数よりも方程式のほうが_多い_のに、なぜかそれでも線形独立である場合に起こります。

_現実のエンジニアリングでは、これはまったく普通のことで、むしろ良いことだとされています！_

トランスデューサーの精度には限りがあり、**b**ベクトルの精度にも限りがあり、計算にはノイズがつきものです。
そこで解は、ノイズを含むデータへの[最小二乗][least-squares]当てはめになります。

最も簡単なのは、行列の[`pseudoinverse`][pseudoinv]を使う方法で、Juliaでは[`pinv()`][pinv]関数として実装されています。

これは（正則な）正方行列の逆行列とほぼ同じように使えて、厳密な解ではなく、変数の最小二乗推定値を与えてくれます。

```julia-repl
# create 5-row A and b for 2 variables
julia> A5 = [4 -3; 2 7; -1 2; 1 -1; 3 1]
5×2 Matrix{Int64}:
  4  -3
  2   7
 -1   2
  1  -1
  3   1

julia> rank(A5)
2

# add some random-normal noise to b5
julia> b5n = [-2, 16, 3, -1, 5] + randn(5) * 0.1
5-element Vector{Float64}:
 -1.9337349223581917
 16.024913008059457
  3.0087646177373992
 -0.8675748721176717
  4.914568047308805

# solve to get x ≈ 1, y ≈ 2, using the pseudoinverse
julia> pinv(A5) * b5n
2-element Vector{Float64}:
 1.006117942769543
 1.9962973764508272
```

## 固有値と固有ベクトル

前の節では、**A** **x** = **b**の解について説明しました。これはおなじみの代数と同じです。

この節では、**A** **x** = λ **x**の解を扱います。ここでλはスカラーです。

これは線形代数に特有の概念ですが、幾何学的に解釈できます。

_適切な**x**とλに対して、正方行列**A**は、ゼロでないベクトル**x**の長さをλ倍に伸縮させ、向きは変えません（負のλなら逆向きになります）_。

ずいぶん特殊な話に聞こえますが、実は_ばかげているほど_役に立ちます！

***用語:*** λの有効な値は**A**の_固有値_で、対応する**x**の値は**A**の_固有ベクトル_です。
_残念ながら、途中で言語が入れ替わる言葉と付き合っていくしかありません。_

2×2行列の固有値と固有ベクトルの計算は、ふつう手計算で習いますが、コンピューターを使えばずっと簡単です（それでもかなり遅く、一般に`n×n`行列では`O(n^3)`で増えていきます）。

```julia-repl
julia> A = rand(-9:9, 2, 2)
2×2 Matrix{Int64}:
 9  5
 3  2

julia> F = eigen(A)
Eigen{Float64, Float64, Matrix{Float64}, Vector{Float64}}
values:
2-element Vector{Float64}:
  0.27984674554472466
 10.720153254455274
vectors:
2×2 Matrix{Float64}:
 -0.497417  0.945605
  0.867511  0.325317

# eigenvalues
julia> F.values
2-element Vector{Float64}:
  0.27984674554472466
 10.720153254455274

# each column is an eigenvector, normalized to a unit vector
julia> F.vectors
2×2 Matrix{Float64}:
 -0.497417  0.945605
  0.867511  0.325317
```

一般に、`n×n`行列には`n`個の固有値がありますが、その値がいつも_異なる_とは限りません。
これらは`n`次の多項式（[特性多項式][wiki-char-poly]と呼ばれます）の根だと考えてください。根は重複することもあり、実数値の行列でもしばしば複素数になります。

各固有ベクトルは1つの方向を表し、そのスカラー倍もすべて有効な固有ベクトルです。
その後の計算を楽にするため、Juliaは[ノルム][wiki-norm]が1の単位ベクトルを返します。

### 応用例

固有ベクトルがなぜ重要かを説明するのは、数行の短い段落ではなく、500ページの教科書の仕事です。
この話題は、現代の応用数学の_あまりに多く_に浸透しています。

大まかに言えば、固有ベクトルはデータセットの中で「最も重要な」軸（方向）を表します。
固有値は、各軸の「相対的な重要度」を示します（_入力の正規化に関するいくつかの仮定のもとで_）。

これが実際に_何を意味するか_は、応用によって変わります。

#### 主成分分析

典型的なデータサイエンスの問題では、100個以上の「特徴量」がデータの列として並んでいることがあります。
ほぼ避けられないことに、ノイズ、冗長性、望ましくない相関が含まれます。

次元を削減する必要があります。[PCA][wiki-PCA]は、この混沌に秩序をもたらす1つの方法です。

- データの[共分散行列][wiki-cov-matrix]を計算します。
- これで正方行列が得られたので、次に固有値と固有ベクトルを計算します。
- 固有ベクトルを、対応する固有値（より正確には絶対値`|λ|`）の降順に並べます。
- 上位`k`個の固有ベクトルが`principal components`（主成分）です。ここで`k`は元の特徴量の数よりずっと小さくなります。
- データセット全体をこの`k`本の軸に射影し、興味深いパターンを探し始めます。

この形のPCAは、創薬で分子の特性を改善しようとする医学研究者から、世論調査データから有権者の好みを理解しようとする政治運動家まで、じつに多様な人々に使われてきました。
おそらく、あなたに何かを売り込もうとするマーケティング集団も使っているでしょう。しかしどんな技術も、善にも悪にも使えます。

PCAは最小構成のJuliaには含まれていませんが、（Exercismの外では）[MultivariateStats][ref-multistats]パッケージに必要なものがそろっています。

#### 画像処理

PCAの考え方をもう一歩進めると、デジタル画像はピクセル値の行列にすぎず、その主成分を計算できます。

これは何十年も前から画像圧縮に使われており、PCAはファイルサイズを小さくするときに何を残すのが最も重要かの指針になります。

近年では、顔認識のような画像分類器にとってPCAは欠かせない要素になっています。
次に空港を歩くとき、[ビッグ・ブラザー][wiki-big-brother]はただ見ているだけでなく、見たものを理解するために線形代数も使っています！

#### 機械工学

もっと議論の少ない例では、機械部品の主軸は、その[慣性モーメントテンソル][wiki-I-tensor]***I***（少し違う名前の行列です）の固有ベクトルです。

車の各ホイールには、このテンソル***I***の非対角要素をゼロにするよう調整された、1つ以上のバランスウェイトが付いているでしょう。
町の整備士は、おそらく（航空機の設計者やロケット技師とは違い）計算を避けているでしょう。しかし「ぶれ」とは、テンソルの交差項を表す日常的な言葉にすぎません。この場合、それは乗り心地を悪くし、ベアリングの摩耗を増やします。
