# 概要

`PHP 8.0.0`から利用できる**共用体型宣言**は、単一の型ではなく、複数の異なる型の値を受け入れます。共用体型の定義では、型を区切るためにパイプ（`|`）を使います。

```php
function add(int|float $a, int|float $b): int|float
{
    return $a + $b;
}
```

## 注意点

- `null`型は、`?Type`を使う方法と`Type1|Type2|null`と書く方法のどちらでも、_null許容_として宣言できます。
- 重複した型や冗長な型を宣言すると、コンパイル時のエラーになります。
- `void`は共用体型宣言の一部として使うことはできません。
