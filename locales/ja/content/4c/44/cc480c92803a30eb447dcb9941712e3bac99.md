# インストール

Racketのディストリビューションは、https://download.racket-lang.orgからダウンロードできます。

インストーラーが用意されているプラットフォームは次のとおりです。

* Windows
* Linux
* macOS

導入の手引きについては、Racketの[Getting Started](http://docs.racket-lang.org/getting-started/)ページを参照してください。

[Racket Guide](https://docs.racket-lang.org/guide/intro.html)では、Racketを操作する方法を紹介しています。

DrRacket IDEの使い方については、[DrRacket: The Racket Programming Environment](https://docs.racket-lang.org/drracket/index.html)を参照してください。

Racketのコマンドラインツールとほかのエディターの使い方については、[Command-Line Tools and Your Editor of Choice](https://docs.racket-lang.org/guide/other-editors.html)を参照してください。


## Linux用インストーラーについて：
Linux版のビルドは汎用性が高いので、比較的古いディストリビューションを含め、ほとんどのディストリビューションで動作するはずです。

インストーラーファイルをダウンロードしたら、次のコマンドで実行します。
```
sh racket-8.10-x86_64-linux-cs.sh
```

管理者権限が必要な場所にインストールするには、コマンドの先頭に`sudo`を付ける必要があるかもしれません。

**注意：Racketはディストリビューションのパッケージマネージャーからも入手できる場合がありますが、最新のRacketバージョンより古いことがあります。**
後からそうすることもできますが、学習者としては、https://download.racket-lang.orgから入手できる最新のリリースを使うほうが、ずっと快適に学べます。


## macOS用インストーラーについて：

お使いのマシンがM1またはM2シリーズのプロセッサーを使用している場合は、ダウンロードする前に、プラットフォームのドロップダウンメニューで**Apple Silicon**を選択してください。
