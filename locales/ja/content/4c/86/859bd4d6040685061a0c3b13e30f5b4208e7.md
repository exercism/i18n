# ヒント

## 1. アイテムを使って新しい在庫を作成する

- `$items`配列リファレンスに含まれるアイテムをキー、その個数を値とするハッシュリファレンスを、`create_inventory`サブルーチンから`return`する必要があります。

## 2. アイテムを使って在庫に追加する

- `$items`配列リファレンスに含まれる分だけアイテムの個数を増やしたハッシュリファレンスを、`add_items`サブルーチンから`return`する必要があります。

## 3. 在庫からアイテムを取り除く

- `$items`配列リファレンスに含まれる分だけアイテムの個数を減らしたハッシュリファレンスを、`remove_items`サブルーチンから`return`する必要があります。
- アイテムの個数が`0`を下回ってはいけません。

## 4. 在庫からアイテムを完全に削除する

- アイテムを在庫から完全に削除したハッシュリファレンスを、`delete_item`サブルーチンから`return`する必要があります。
