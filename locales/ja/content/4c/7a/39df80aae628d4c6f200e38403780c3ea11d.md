# 説明

クライミングジムのフロントで働き始めたところです。メンバーは数か月分のメンバーシップを購入し、来るたびにチェックインとチェックアウトをします。マネージャーから、メンバーがよく尋ねる質問に答えるヘルパーを書いてほしいと頼まれました。

## 1. メンバーシップがいつ終わるかを計算する

ある日に始まったメンバーシップは、指定された月数だけ後の、同じ月日の日に終わります。その日が終了する月に存在しない場合は、その月の最終日に終わります。

メンバーシップの開始日と月数を受け取り、それが終わる日付を返す`FrontDesk.membershipEnd()`メソッドを実装しましょう。

```java
FrontDesk frontDesk = new FrontDesk();
frontDesk.membershipEnd(LocalDate.of(2024, 3, 10), 1);
// => LocalDate.of(2024, 4, 10)
frontDesk.membershipEnd(LocalDate.of(2025, 1, 31), 1);
// => LocalDate.of(2025, 2, 28)
```

## 2. メンバーシップがどれだけ続くかを表示する

メンバーシップカードには、メンバーシップが何年何か月何日続くかが印刷されます。

メンバーシップの開始日と終了日を受け取り、メンバーシップの長さを`Period`として返す`FrontDesk.membershipLength()`メソッドを実装しましょう。

```java
FrontDesk frontDesk = new FrontDesk();
frontDesk.membershipLength(LocalDate.of(2023, 3, 10), LocalDate.of(2024, 5, 25));
// => Period.of(1, 2, 15)
```

## 3. メンバーシップの残り日数を数える

メンバーはよく、メンバーシップが終わるまであと何日残っているかを尋ねます。

今日の日付とメンバーシップの終了日を受け取り、今日から終了日までの合計日数を返す`FrontDesk.daysLeft()`メソッドを実装しましょう。終了日が今日である場合や、すでに過ぎている場合は残り日数がないので、このメソッドは`0`を返します。

```java
FrontDesk frontDesk = new FrontDesk();
frontDesk.daysLeft(LocalDate.of(2024, 1, 15), LocalDate.of(2024, 3, 20));
// => 65
frontDesk.daysLeft(LocalDate.of(2024, 4, 2), LocalDate.of(2024, 3, 20));
// => 0
```

## 4. 滞在時間を測る

ジムは24時間営業していて、改札機がメンバーのチェックインとチェックアウトの日時を記録します。

ある滞在のチェックインとチェックアウトの日時を受け取り、その滞在がどれだけ続いたかを`Duration`として返す`FrontDesk.visitDuration()`メソッドを実装しましょう。

```java
FrontDesk frontDesk = new FrontDesk();
frontDesk.visitDuration(LocalDateTime.of(2024, 3, 10, 23, 30), LocalDateTime.of(2024, 3, 11, 1, 15));
// => Duration.ofMinutes(105)
```

## 5. レシートに滞在時間を印字する

レシートには、`1h 35m`のように滞在時間が時間と分で表示されます。分は常に2桁で書き、秒は省きます。また、時間は1日以内に限られません。

滞在時間を受け取り、この形式で返す`FrontDesk.formatVisit()`メソッドを実装しましょう。

```java
FrontDesk frontDesk = new FrontDesk();
frontDesk.formatVisit(Duration.ofMinutes(95));
// => "1h 35m"
frontDesk.formatVisit(Duration.ofHours(2).plusMinutes(5));
// => "2h 05m"
frontDesk.formatVisit(Duration.ofHours(26).plusMinutes(10));
// => "26h 10m"
```
