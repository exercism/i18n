# 概要

[cons][hyper-conses]は、Common Lispの基本的なデータ型です。consは、headとtailという2つの部分からできています（歴史的な理由から、それぞれ`car`と`cdr`と呼ばれています）。

consのheadとtailには、データ型の制限はありません。

consは、[`cons`][hyper-cons]関数で作ります。この関数は2つのオブジェクトを受け取り、評価結果はconsになります（「consセル」と呼ばれることもあります）。

consの各部分には、[`car`][hyper-car]関数と[`cdr`][hyper-cdr]関数でアクセスできます。

## リファレンス

```lisp
;; Testing for atoms
(atom 'foo)              ; => T
(atom '(bar baz))        ; => NIL

;; Testing for cons
(consp 'foo)             ; => NIL
(consp '(bar baz))       ; => T

;; First item of a cons
(car '(one two three))   ; => ONE
(first '(one two three)) ; => ONE

;; Rest of a cons
(cdr '(one two three))   ; => (TWO THREE)
(rest '(one two three))  ; => (TWO THREE)
```
