# はじめに

多くのプログラムでは、現実世界の出来事をシミュレーションするために（疑似）乱数の値が必要になります。

よくある身近な例を挙げます。

- コイン投げ: ('H', 'T') からランダムに選ばれる値。
- サイコロを振る: 1から6までのランダムな整数。
- トランプをシャッフルする: カードの配列をランダムに並べ替えたもの。
- 3次元グラフィックスのシミュレーションで木や茂みを生成すること。

コンピューターで真の乱数を生成するのは[驚くほど難しい技術的課題][why-randomness-is-hard]で、だからこそ「疑似乱数」生成器も存在します。

## 乱数を生成する

JavaScriptでは、[`Math.random()`][Math.random]関数を使って疑似乱数を生成できます。
これは、0以上1未満の疑似乱数の浮動小数点数を返します。

_min_以上_max_未満の乱数を得るには、次のような関数を使います。

```javascript
function getRandomInRange(min, max) {
  return min + Math.random() * (max - min);
}
getRandomInRange(4, 10);
// => 5.72
```

## ランダムな整数を生成する

ランダムな整数を生成するには、`Math.floor()`または`Math.ceil()`を使って、生成した乱数を整数に変換します。
