# インストール

Zigをインストールする方法はたくさんあり、言語が成熟するにつれてその数は着実に増えています。幸いなことに、よく使われるインストール方法はすべて[Zigのインストールページ][install-zig]にまとめられています。

## Zigのバージョン

Exercismでは、Zig 0.17.0（2026-10-01にリリース）を使っています。

演習によっては別のZigバージョンと互換性があるかもしれませんが、それは保証されていません。Zigはまだバージョン1.0に達しておらず、破壊的な変更もよくあります。

## その他のツール

### Zig fmt：整形されたコードを生成する

演習を解くときには、解答にどんなコードスタイルを使ってもかまいません。しかし、アプリケーションやライブラリを作るときのように、演習を解く以外の場面では、コードを一貫性があり読みやすいものにしておくのがたいていは良いことです。こうした考え方は、自分のプロジェクトを手伝いたいと思っている人たちがコードを読まなければならなくなる場合には、とくに重要になります。

この問題を解決するために、Zigコンパイラーには、コードを手軽に整形してくれる軽量な[リンター][linters]が組み込まれています。このコードフォーマッターは、[Zigのドキュメント][documentation]ですでに確立されている[スタイルガイド][style-guide]に従うことを目指しています。

Zigのネイティブフォーマッターの機能を確認するには、次のコマンドを使います。

```bash
zig fmt --help
```

### Zig Zen：コードを書くときの指針

どんな作業をするときでも、たとえコードを書くときでも、ちょっとした指針があると大きな助けになります。ありがたいことに、Zigコンパイラーには、良いZigコードを書くうえでの目標のいくつかを思い出させてくれる楽しいコマンドが組み込まれています。

こうした知恵の言葉を確かめるには、次のコマンドを使います。

```bash
zig zen
```

### Zig Language Server：Zigのための総合的なエディターサポート

このサードパーティ製のソフトウェアは、エディターの入力補完や、Zigコードのナビゲーションを強化する機能を提供していて、言語をより速く学ぶのに役立ちます。

最新の手順については、[ZLSのインストールガイド][install-zls]で確認してください。
