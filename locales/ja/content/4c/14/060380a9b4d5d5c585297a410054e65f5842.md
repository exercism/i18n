# はじめに

シーケンスをたどるときには、要素そのものだけでなく、その*位置*も必要になることがあります。[`sequences`][sequences]にある`*-index`ファミリーは、要素と位置の両方を、要素ごとのクォーテーションに渡してくれます。`times`は、回数を指定して繰り返すための近い仲間です。単に回数が欲しいだけで、シーケンスまでは要らないときに便利です。

## `each-index`と`map-index`：クォーテーションの中のインデックス

```
each-index ( seq quot: ( elt index -- )       -- )
map-index  ( seq quot: ( elt index -- newelt ) -- newseq )
```

クォーテーションが受け取るのは、インデックスの下にある要素です。`index`はスタックの**一番上**にあります。

```factor
USING: io kernel math.parser sequences ;

{ "alice" "bob" "carol" } [
    number>string ": " glue print
] each-index
! prints:
! alice: 0
! bob:   1
! carol: 2

{ 10 20 30 } [ + ] map-index .
! => { 10 21 32 }       (index added to each element)
```

`each-index`は、副作用のためにクォーテーションを実行し、何も返しません。`map-index`は、要素ごとの結果を集めて、入力と同じ種類の新しいシーケンスにまとめます。

## `times`：回数を指定した繰り返し

`times`は（[`math`][math]にあります）、クォーテーションを`n`回実行します。

```
times ( n quot: ( -- ) -- )
```

公開されている`( -- )`という形は*最小限*のものです。`times`は`inline`なので、`( str -- str )`のような、スタック効果の釣り合ったクォーテーションでも問題なく動き、スタックは繰り返しをまたいで引き継がれていきます。こうすると、可変の状態を一切使わずに、回数を数えるアキュムレーターが作れます。

```factor
USING: kernel sequences ;

"" 3 [ "clop " append ] times .    ! => "clop clop clop "
```

各繰り返しの本体は、その時点の文字列を受け取り、それに追加し、新しい文字列を次の繰り返しのためにスタックに残します。同じやり方は、`each-index`や`map-index`でアキュムレーターを引き継ぎたいときにも使えます。
