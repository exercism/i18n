# 入れ子の`if`文は避けましょう

入れ子が深くなるとコードが追いにくくなるので、`if`文を書き直して、深い入れ子を避けてみましょう。次の2つのコードを見てみましょう。

```csharp
void PrintName(Person p)
{
    if (p != null)
    {
        if (p.Name != null)
        {
            if (p.Age >= 21)
            {
                Console.WriteLine(p.Name);
            }
        }
    }
}
```

これを次のコードと比べてみましょう。

```csharp
void PrintName(Person p)
{
  if (p == null || p.Name == null || p.Age < 21)
  {
      return;
  }

  Console.WriteLine(p.Name);
}
```

2つ目の例には、はっきりとした構造があります。エラーに対処するパスはすべて、インデントされたブロックの中で処理され、一方で「ハッピーパス」は常に一番左に揃えられています。こうするととても読みやすくなり、コードの中で最も一般的で、エラーのないパスがすぐにわかります。
