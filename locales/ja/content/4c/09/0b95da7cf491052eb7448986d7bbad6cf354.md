# 説明

パーティー用ロボットが、大きなお祭りに向けてバンティングを吊るしています。バンティングの1本1本は、`n`枚の小さな旗を横一列に並べたものです。それぞれの旗の文字は、左端を`0`として数えたときに、その旗が列のどこにあるかで決まります。ロボットが以下の模様を組み立てるのを手伝いましょう。

## 1. アルファベットのバンティング

`alphabet-bunting`を定義して、スタックから負でない整数`n`を取り出し、アルファベットの小文字の最初の`n`文字からなる文字列を返すようにします。

```factor
5 alphabet-bunting .
! => "abcde"

0 alphabet-bunting .
! => ""
```

`n`は最大でも`26`だと想定してかまいません。

## 2. 数え上げのバンティング

`counting-bunting`を定義して、`n`を受け取り、位置`i`の旗が`i mod 10`を示す、`n`桁の文字列を返すようにします。

```factor
12 counting-bunting .
! => "012345678901"
```

## 3. しま模様のバンティング

`stripe-bunting`を定義して、2つの文字を交互に並べます。偶数番目の位置は`*`、奇数番目の位置は`-`にします。

```factor
6 stripe-bunting .
! => "*-*-*-"

1 stripe-bunting .
! => "*"
```

## 4. 目印のバンティング

5つおきの旗は特別な目印です。`marker-bunting`を定義して、位置`0`、`5`、`10`、…が`|`、それ以外が`.`になるようにします。

```factor
11 marker-bunting .
! => "|....|....|"
```

## 5. 谷のバンティング

ロボットは、中央のフックに留める、旗10枚の決まった大きさのバンティングを吊るします。左端の旗を位置`-5`として、`5`の手前まで数えたとき、それぞれの旗の文字は、中心からの距離を数字で書いたものです。

`valley-bunting`を定義して、入力を取らずに、その決まった文字列を返すようにします。

```factor
valley-bunting .
! => "5432101234"
```
