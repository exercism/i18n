# 説明

この演習では、在庫管理システムを扱います。

在庫はアイテム名ごとに整理し、利用できるアイテムの数を把握しておく必要があります。

在庫へのアイテムの追加も扱う必要があります。与えられた配列の中にアイテムが現れるたびに、在庫内のそのアイテムの数量を`1`増やします。また、要求されたときに数量を`1`減らして、在庫からアイテムを削除する処理も扱う必要があります。

最後に、与えられた在庫内のすべてのキーと値のペアを、`tuples`の`list`として返す関数を実装する必要があります。


## 1. 配列から在庫を作成する

アイテムの入力配列から「在庫」を作成する`create_inventory(<input list>)`関数を実装します。それぞれのアイテム名と対応する数量を組み合わせた`dict`を返すようにします。

```python
>>> create_inventory(["coal", "wood", "wood", "diamond", "diamond", "diamond"])
{"coal":1, "wood":2, "diamond":3}
```

## 2. 既存の辞書に配列からアイテムを追加する

渡された在庫にアイテムの配列を追加する`add_items(<inventory dict>, <item list>)`関数を実装します。

```python
>>> add_items({"coal":1}, ["wood", "iron", "coal", "wood"])
{"coal":2, "wood":2, "iron":1}
```

## 3. 在庫からアイテムを減らす

アイテムの`list`を受け取る`decrement_items(<inventory dict>, <items list>)`関数を実装します。そのアイテムが`list`に現れるたびに、アイテムの個数から`1`を減らします。

```python
>>> decrement_items({"coal":3, "diamond":1, "iron":5}, ["diamond", "coal", "iron", "iron"])
{"coal":2, "diamond":0, "iron":3}
```

在庫内のアイテムの個数は、0を下回らないようにします。入力の`list`にアイテムが現れる回数が、在庫にある個数を超えた場合、そのアイテムの数量は0のままにします。個数が0になったあとは、それ以上減らす要求は無視します。

```python
>>> decrement_items({"coal":2, "wood":1, "diamond":2}, ["coal", "coal", "wood", "wood", "diamond"])
{"coal":0, "wood":0, "diamond":1}
```

## 4. 在庫からエントリを完全に削除する

在庫からアイテムとその個数を完全に削除する`remove_item(<inventory dict>, <item>)`関数を実装します。

```python
>>> remove_item({"coal":2, "wood":1, "diamond":2}, "coal")
{"wood":1, "diamond":2}
```

在庫にそのアイテムが見つからない場合、関数は元の在庫をそのまま返します。

```python
>>> remove_item({"coal":2, "wood":1, "diamond":2}, "gold")
{"coal":2, "wood":1, "diamond":2}
```

## 5. 在庫の内容をすべて返す

在庫を受け取り、`(item, quantity)`タプルの配列を返す`list_inventory(<inventory dict>)`関数を実装します。この配列には、_利用可能_なアイテム（_数量が0より大きいもの_）だけを含めます。

```python
>>> list_inventory({"coal":7, "wood":11, "diamond":2, "iron":7, "silver":0})
[('coal', 7), ('diamond', 2), ('iron', 7), ('wood', 11)]
```
