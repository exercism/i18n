# はじめに

## 基本

Javaは静的型付け言語です。つまり、変数の型はコンパイル時にわかります。
名前に値を割り当てることを、変数の定義といいます。
変数は、型を明示的に指定して定義します。

```java
int explicitVar = 10;
```

変数の値の更新は、`=`演算子で行います。
ここで`=`は、数学的な等号を意味するものではありません。
単に変数に値を代入するだけです。
一度定義されたら、変数の型は決して変わりません。

```java
int count = 1; // Assign initial value
count = 2;     // Update to new value

// Compiler error when assigning a different type
// count = false;
```

Javaは[オブジェクト指向言語][object-oriented-programming]であり、すべての関数を_クラス_内で定義する必要があります。
`class`キーワードを使ってクラスを定義します。

```java
class Calculator {
    // ...
}
```

クラス内の関数は、_メソッド_と呼ばれます。
各メソッドは、0個以上の仮引数を持てます。
すべての仮引数は明示的に型を指定する必要があり、仮引数には型推論がありません。
同様に、戻り値の型も明示する必要があります。
メソッドから値を返すには、`return`キーワードを使います。
メソッドを他のクラスから呼び出せるようにするには、`public`アクセス修飾子を付ける必要があります。

```java
class Calculator {
    public int add(int x, int y) {
        return x + y;
    }
}
```

メソッドを呼び出すには、クラス名とメソッド名を指定し、各仮引数に対応する引数を渡します。

```java
int sum = new Calculator().add(1, 2);  // here the  "add" method has been called to perform the task of addition
```

Javaのスコープは、`{`と`}`の文字の間に定義されます。

Javaでは、2種類のコメントが書けます。
単一行コメントは`//`で始まり、複数行コメントは`/*`と`*/`の間に書きます。

[object-oriented-programming]: https://docs.oracle.com/javase/tutorial/java/javaOO/index.html
