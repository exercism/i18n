# 説明

この演習では、ロールプレイングゲームの仕組みを実装します。
プレイヤーのキャラクターは、次の型で表されます。

```elm
type alias Player =
    { name : Maybe String
    , level : Int
    , health : Int
    , mana : Maybe Int
    }
```

このゲームのプレイヤーは、レベル10に達しないとマナプールを解放できず、呪文を唱えられません。
ここでは、このゲームの2つの機能、蘇生の仕組みと呪文詠唱の仕組みに取り組みます。

## 1. 自己紹介をする

`introduce`関数の中身を書きましょう。
身を潜めているプレイヤーは名前を隠していることがあり、その場合は`"Mighty Magician"`として紹介されます。
それ以外の場合は、自分の名前をそのまま使って自己紹介します。

```elm
introduce { name = Nothing, level = 2, health = 8, mana = Nothing }
    --> "Mighty Magician"

introduce { name = Just "Merlin", level = 2, health = 8, mana = Nothing }
    --> "Merlin"
```

## 2. 蘇生の仕組みを実装する

`revive`関数は、プレイヤーのキャラクターが本当に死んでいるか（体力が0になっているか）を確認します。
死んでいる場合は、体力が100の新しい`Player`インスタンスを返します。
そうでなければ、つまりプレイヤーのキャラクターが死んでいない場合は、`revive`関数は`Nothing`を返します。

プレイヤーのレベルが10以上の場合、マナ100でも蘇生されます。
プレイヤーのレベルが10未満の場合、マナは`Nothing`になります。
`revive`関数は、プレイヤーのレベルを保つ必要があります。

```elm
deadPlayer = { name = Nothing, level = 2, health = 0, mana = Nothing }

revive deadPlayer
    --> Just { name = Nothing, level = 2, health = 100, mana = Nothing }
```

体力が1以上のプレイヤーに対して`revive`メソッドが呼び出された場合、関数は`Nothing`を返す必要があります。

```elm
alivePlayer = { name = Nothing, level = 2, health = 42, mana = Nothing }

revive alivePlayer
    --> Nothing
```

## 3. 呪文詠唱の仕組みを実装する

`castSpell`関数は、呪文にかかるマナの量を表す`Int`と、`Player`を引数に取ります。
更新されたプレイヤーと、唱えた呪文が与えるダメージ量を返します。
呪文の詠唱に成功すると、その呪文のマナコストの2倍のダメージを与えます。
ただし、プレイヤーのマナが足りない場合は、何も起こらず、プレイヤーは変化せず、ダメージも発生しません。
プレイヤーがマナプールすら持っていない場合、呪文を唱えようとすると、体力がその呪文のマナコスト分だけ減り、ダメージは与えません。

```elm
wizard = { name = Nothing, level = 18, health = 123, mana = Just 30 }

( updatedWizard, damage ) = castSpell 14 wizard

updatedWizard.mana --> Just 16
damage             --> 28
```
