# 指示

地域コミュニティの協会から、コミュニティガーデンの登録を管理するためのシンプルな登録アプリケーションを実装してほしいと頼まれました。`Plot`構造体はすでに用意されています。

## 1. 庭を開く

`CommunityGarden.start/1`関数を実装します。この関数は、*エージェントプロセス*に引き渡すオプションのキーワードリストを任意で受け取ります。庭の初期状態は、区画の空のコレクションを表すように初期化します。庭のpidを含む`:ok`タプルを返します。

```elixir
{:ok, pid} = CommunityGarden.start()
# => {:ok, #PID<0.112.0>}
```

## 2. 登録の一覧を表示する

`CommunityGarden.list_registrations/1`関数を実装します。この関数は、コミュニティガーデンの`pid`を受け取ります。登録済みの、保存されている区画のリストを返します。

```elixir
CommunityGarden.list_registrations(pid)
# => []
```

> この時点では、区画を登録する機能はまだ追加していないので、このリストは空になるはずです

## 3. 区画を人に登録する

`CommunityGarden.register/2`関数を実装します。この関数は、コミュニティガーデンの`pid`と、区画を登録する相手の名前を受け取ります。成功すると、区画のidと登録先の人が入った`Plot`構造体を返します。

idは連番で一意である必要があります。エージェントの状態にidカウンターを保持しておくとよいでしょう。

```elixir
CommunityGarden.register(pid, "Emma Balan")
# => %Plot{plot_id: 1, registered_to: "Emma Balan"}
CommunityGarden.list_registrations(pid)
# => [%Plot{plot_id: 1, registered_to: "Emma Balan"}]
```

## 4. 区画を解放する

`CommunityGarden.release/2`関数を実装します。この関数は、解放する区画の`pid`と`id`を受け取ります。成功すると`:ok`を返します。区画を解放してもidは再利用されず、一意の識別子としてのみ使われます。

```elixir
CommunityGarden.release(pid, 1)
# => :ok
CommunityGarden.list_registrations(pid)
# => []
```

## 5. 登録済みの区画を取得する

`CommunityGarden.get_registration/2`関数を実装します。この関数は、確認する区画の`pid`と`id`を受け取ります。区画が登録済みならその区画を返し、未登録なら`:not_found`を返します。

```elixir
CommunityGarden.get_registration(pid, 1)
# => %Plot{plot_id: 1, registered_to: "Emma Balan"}
CommunityGarden.get_registration(pid, 7)
# => {:not_found, "plot is unregistered"}
```
