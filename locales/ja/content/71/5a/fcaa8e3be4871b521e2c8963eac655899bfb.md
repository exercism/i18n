# ヒント

## 全般

- `<dlist>`は[`dlists`][dlists]にあり、push/popのワードは[`deques`][deques]にあります。
- `MEMO:`は[`memoize`][memoize]にあります。
- ローカル（`::`と`:>`）を使うと、BFSの本体が読みやすくなります。述語からも、本体と同じローカルが見えます。

## 1. 潮のキューを空にする

- まず`<dlist>`を用意し、`[ push-back ] each`で要素を詰めます。次に`until`ループ（述語は`[ deque-empty? ]`）で空にしていきます。先頭をpopして`V{ } clone`に入れ、最後に`>array`で配列に変換します。

## 2. 到達できる入り江

- パターンはこうです。`visited`には`HS{ } clone`、`frontier`には`<dlist>`を使い、`start`を訪問済みにしてfrontierにpushし、あとはfrontierが空になるまでループします。先頭をpopし、`at`でチャートから隣り合うマスを調べ、まだ見ていないマスがあれば、それぞれ`visited`にadjoinし、frontierにpush-backします。

## 3. ホップ数

- タスク2と同じ形ですが、デックが運ぶのは`{ cove distance }`のペアです。popしたペアのcoveがゴールと等しければ、その距離を答えとして記録し、止めます。可変ローカル（`f :> answer!`）を使い、`until`ループの条件を`frontier deque-empty? answer or`にします。

## 4. 金貨の数

- 宣言は1つだけです。`MEMO: gold-count ( cove -- n ) gold-distribution at 0 or ;`。`MEMO:`は先頭の`:`に取って代わり、それ以外は普通のワード定義です。キーがなければ`at`は`f`を返し、`0 or`が代わりに0を返します。

## 5. 宝物への経路

- `coves-reachable`はハッシュセットを返します。`members`（`sets`にあります）を使うと、シーケンスに変換できます。`[ [ gold-count ] keep 2array ] map`で`{ gold cove }`のペアの配列を作り、その配列を`sort`します（ペアは最初の要素の順に並びます）。あとは`last second`で、金貨が最も多いペアのcoveを取り出します。
