イベントを取り込むサービスを書くことになりました。各イベントには日付が紐づいていますが、サービスのエンドポイントには3種類の異なる形式が送られてきていることに気づきます。

- `"01/01/1970"`
- `"January 1, 1970"`
- `"Thursday, January 1, 1970"`

どれも似ている点があることがわかるので、組み合わせて使える正規表現パターンを書くことにします。

## 1. 日付から日、月、年をマッチさせる

`day`、`month`、`year`を実装して、実行すると`"01/01/1970"`（`dd/mm/yyyy`）の数値部分にマッチする文字列パターンを返すようにします。日と月は`1`または`01`（0で左詰め）のように現れることがあります。

エラーチェックは気にしなくて大丈夫です。常に有効な数値が渡されると考えてかまいません。

```clojure
(day "31")
;;=> "31"
(month "12")
;;=> "12"
(year "1970")
;;=> "1970"
```

## 2. 曜日と月をマッチさせる

`day-name`と`month-name`を実装して、実行すると、それぞれ曜日の名前と月の名前にマッチする文字列パターンを返すようにします。

```clojure
(day-name "Tuesday")
;;=> "Tuesday"
(month-name "June")
;;=> "June"
```

## 3. 日、月、年をキャプチャする

`capture-day`、`capture-month`、`capture-year`、`capture-day-name`、`capture-month-name`を実装して、それぞれの要素を`"day"`、`"month"`、`"year"`、`"day-name"`、`"month-name"`という名前に対応付けたマップを返すようにします。

```clojure
(capture-month-name "December")
;;=> {:month-name "December"}
```

## 4. キャプチャを組み合わせて日付全体をキャプチャする

`capture-numeric-date`、`capture-month-name-date`、`capture-day-month-name-date`を実装して、それぞれの日付形式を使って、パート3の要素をまとめたマップを返すようにします。

```clojure
(capture-numeric-date "01/01/1970")
;;=> {:day "01", :month "01", :year "1970"}
```
