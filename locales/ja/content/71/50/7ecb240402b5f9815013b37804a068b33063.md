# テスト

## テストの実行

演習のディレクトリに移動すると、次の2つのサブディレクトリがあります。

* `Sources/<Exercise>`には、その演習の解答が入っています
* `Tests/<Exercise>Tests`には、その演習で実行するテストが入っています

正しいディレクトリ（`Sources`と`Tests`があるディレクトリ）にいれば、`swift test`を実行するとその演習のテストを実行できます。

```bash
$ pwd
/Users/johndoe/Code/exercism/swift/hello-world

$ ls
HELP.md  Package.swift  README.md  Sources  Tests

$ swift test
```

テストが1つ通ったら、次のテストを有効にするために`@Test`文の`.enabled(if: RUNALL)`を削除します。あるいは、LinuxやmacOSでは環境変数`RUNALL`を`true`に設定すると、すべてのテストを実行できます。

```bash
$ export RUNALL=true
```

WindowsでPowerShellを使っている場合は、次のようにします。

```powershell
set RUNALL=true
```

## 解答の提出

Exercismに解答をアップロードするには、`Sources`と`Tests`ディレクトリがあるディレクトリにいる必要があります。

```bash
$ exercism submit 
```
