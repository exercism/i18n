# はじめに

Factorのエラー処理は、3つの部品からできています。`throw`（[`kernel`][kernel]にあります）はエラーを投げ、`recover`（[`continuations`][continuations]にあります）はそれを捕まえ、`ERROR:`はタプル型のエラークラスを定義します。

```factor
! "file not found" throw          (raises a string as the error)

[ "boom" throw ] [ drop "caught" ] recover .
! => "caught"
```

`recover ( try recovery -- )`は*try*クオーテーションを実行します。エラーを投げた場合は、そのエラーがスタックに積まれ、*recovery*クオーテーションが実行されます。

`ERROR:`はクラス*と*、新しいインスタンスを投げるコンストラクターワードの両方を宣言します。

```factor
! DOCTEST: SKIP
ERROR: not-found path ;

"/missing" not-found
! throws T{ not-found { path "/missing" } }
```

[kernel]: https://docs.factorcode.org/content/vocab-kernel.html
[continuations]: https://docs.factorcode.org/content/vocab-continuations.html
