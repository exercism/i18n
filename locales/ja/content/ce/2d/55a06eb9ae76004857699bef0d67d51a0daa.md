# ガードを使う

[comment]: # (このエラーは、解答でガードをまったく使っていないときに発生します)

`two_fer/1`がバイナリ以外の入力でコードを実行しないように、[ガード](https://hexdocs.pm/elixir/master/guards.html)を使いましょう。

> Elixirでは、[文字列](https://elixir-lang.org/getting-started/binaries-strings-and-char-lists.html)は[バイナリデータ](https://elixir-lang.org/getting-started/binaries-strings-and-char-lists.html)として扱われることを覚えておきましょう。

```elixir
# Consider this function with a guard:
def hello(what) when is_binary(what) do
  "Hello, #{what}!"
end
```

> このガードは`iex`で試すことができます。

```shell
iex> hello("world")
"Hello, world!"
iex> hello(123)
** (FunctionClauseError) no function clause matching in hello/1

    The following arguments were given to hello/1:

        # 1
        123
```
