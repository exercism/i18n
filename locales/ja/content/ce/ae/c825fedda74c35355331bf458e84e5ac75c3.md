# はじめに

短いワードなら、スタックをやりくりするだけで十分です。ワードに複数の入力があり、それらを名前で参照したいときは、Factorの*locals*が使えます。`::`（ワード定義用）または`[| | ]`（インラインラムダ用）で導入する名前付きの束縛で、どちらも[`locals`][locals]のものです。

```factor
USING: locals ;

:: hypotenuse ( a b -- c )
    a a *
    b b *
    + sqrt ;
```

クォーテーションの中では、`[| inputs | body ]`は入力に名前を付けたラムダになります。

```factor
USING: assocs locals ;

H{ { "a" 1 } { "b" 2 } }
[| key value | key value 10 * ] assoc-map .
! => H{ { "a" 10 } { "b" 20 } }
```

[locals]: https://docs.factorcode.org/content/vocab-locals.html
