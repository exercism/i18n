# 説明

サッカークラブのウェブサイトで、試合のレポートを作成するスタッフを支援するシステムを開発しています。
このシステムは、フィールドの内外を問わず試合のさまざまな側面を分析し、それらをイベントのストリームに変換できます。

## 1. 背番号に基づいて選手の説明を出力する

このチームは4-3-3のフォーメーションしか使わず、選手交代を認める1965年のルール変更にも同意していません。ましてや選手数の拡大など論外です。

選手の説明は次のとおりです。

```text
1 -> "goalie"
2 -> "left back"
3 & 4 -> "center back"
5 -> "right back"
6, 7 & 8 -> "midfielder"
9 -> "left wing"
10 -> "striker"
11 -> "right wing"
```

静的メソッド`PlayAnalyzer.AnalyzeOnField()`を実装して、背番号に基づいた選手の説明を出力しましょう。

```csharp
PlayAnalyzer.AnalyzeOnField(10);
// => "striker"
```

## 2. 未知の背番号を処理する

`PlayAnalyzer.AnalyzeOnField()`メソッドを変更して、1〜11の範囲外の背番号が処理されたときに`UNKNOWN`を報告するようにしましょう。

## 3. 対象をフィールド外の活動にも広げる

`PlayAnalyzer.AnalyzeOffField()`メソッドを実装して、フィールド周辺の活動や人物の説明を出力しましょう。
このメソッドはさまざまな型のデータを受け取り、それらを分析して、ジャーナリストの役に立つ適切なテキストに変換します。

まずは、スタジアムに関するデータを扱います。

- スタジアムに現在いるサポーターの数（任意の`int`）
- スタジアムのPAシステムで流されるアナウンス（任意の`string`）

未知の型のデータは処理しません。そのため、メソッドが別の型のデータを受け取った場合は、空の文字列を返します。

```csharp
PlayAnalyzer.AnalyzeOffField(5000);
// => "There are 5000 supporters at the match."

PlayAnalyzer.AnalyzeOffField("5 minutes to go!");
// => "5 minutes to go!"

PlayAnalyzer.AnalyzeOffField(0.5);
// => ""
```

## 4. 試合中の出来事を報告する

`PlayAnalyzer.AnalyzeOffField()`メソッドを変更して、試合中に起きる出来事の説明を出力しましょう。

出来事は`Incident`型の任意のサブクラスで、その出来事の説明を含みます。
負傷は特別な種類の出来事です。試合を中断させるため、別の扱いをする必要があります。

```csharp
PlayAnalyzer.AnalyzeOffField(new Foul());
// => "The referee deemed a foul."

PlayAnalyzer.AnalyzeOffField(new Injury(8));
// => "Oh no! Player 8 is injured. Medics are on the field."
```

## 5. クラブの監督について報告する

`PlayAnalyzer.AnalyzeOffField()`メソッドを変更して、試合に立ち会っているクラブの監督について言及しましょう。

監督は`Manager`型のインスタンスで、名前と、その監督が率いるクラブの名前を持ちます。
監督のクラブが不明な場合、`null`に設定されます。
監督のクラブがわからない場合は、説明に含めません。

```csharp
PlayAnalyzer.AnalyzeOffField(new Manager("José Mário dos Santos Mourinho Félix", null));
// => "José Mário dos Santos Mourinho Félix"

PlayAnalyzer.AnalyzeOffField(new Manager("Jürgen Klopp", "Liverpool"));
// => "Jürgen Klopp (Liverpool)"
```
