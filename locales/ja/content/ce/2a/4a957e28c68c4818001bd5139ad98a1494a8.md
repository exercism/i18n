# 真偽値

`bool`型（真偽値の略）が持つ値は、`true`と`false`の2つだけです。
コードの中で書く`true`と`false`というリテラル値は、大文字と小文字を区別しません。

```php
<?php

$value_is_true = true;
$value_is_false = false;
```

真偽値は、演算子の結果として論理式でよく使われ、そのあと制御構造の中で使われます。

## 論理演算子

論理演算子には、次のようなものがあります：

- `!$a`：`$a`が`true`でないときに`true`を返します
- `$a && $b`：`$a`と`$b`がどちらも`true`のときに`true`を返します
- `$a || $b`：`$a`または`$b`のどちらかが`true`のときに`true`を返します

~~~~exercism/caution
`and`演算子と`or`演算子があり、それぞれ`&&`と`||`を補完する関係にあります。
これらは`&&`や`||`と同じ動作をするわけではなく、予期しない結果を生むことがあるため、使用は推奨されません。
~~~~
