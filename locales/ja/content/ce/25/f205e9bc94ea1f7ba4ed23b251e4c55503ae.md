# 説明

通常の数値をローマ数字に変換する関数を書いてください。

ローマ人は賢い人々でした。彼らはヨーロッパの大半を征服し、何百年もの間その地を支配しました。コンクリートやまっすぐな道路、さらにはビキニまで発明したほどです。ただ、彼らが決して発見しなかったものがあります。それはゼロという数です。このため、彼らの功績を詳しく記録して年代を付けるのは少し難しくなりましたが、彼らが考え出した数の体系は今でも使われています。たとえば、BBCは番組の制作年をローマ数字で表しています。

ローマ人は I、V、X、L、C、D、M という文字で数を書きました。（これらの文字はまっすぐな線が多く、石板に刻むのに向いていることに注目してください。）

```text
 1  => I
10  => X
 7  => VII
```

およそ3000より大きい数を変換できる必要はありません。（ローマ人自身も、それ以上を使うことはほとんどありませんでした）

ウィキペディアにはこう書かれています。現代のローマ数字は…最も左の桁から始めて各桁を別々に表し、値がゼロの桁は飛ばして書きます。

実際の例として、1990を見てみましょう。

ローマ数字では1990はMCMXCです。

1000=M
900=CM
90=XC

2008はMMVIIIと書きます。

2000=MM
8=VIII
