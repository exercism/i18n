# Exercism API

## 説明

ほとんどのExercismの言語トラックでは、演習の取得と提出に`exercism`コマンドラインツールを使います。このツールはREST APIを介して`exercism.io`とやり取りします。一方、Pharo Smalltalkの言語トラックでは、代わりに同じREST APIを使い、仲介するツールを一切挟まずに、Pharoイメージへ演習を出し入れします。このドキュメントでは、Pharo Smalltalkの言語トラックでの使われ方に焦点を当てて、Exercism APIの詳細を説明します。Pharo Smalltalkのツールのメンテナーを対象としています。

## ヘッダー

すべてのエンドポイントでは、リクエストのヘッダーを次の値に設定する必要があります。

```
Authorization: Bearer <token>
```

`<token>`の値は、`https://exercism.io/my/settings`で確認できる、ユーザーのCLI認証トークンです。

## 演習の取得

```
Content-Type: application/json
```

`GET api.exercism.io/v1/solutions/latest?exercise_id=<slug>&track_id<language> HTTP/1.1`

上のURLでは、`<slug>`は演習の名前（例：`hello-world`）、`<language>`は言語トラック（例：`pharo-smalltalk`）です。

### レスポンス

#### 200

リクエストが成功すると、JSONペイロードを含むレスポンスが返ります。JSONの中には、演習に関する情報と、演習ファイルをダウンロードするためのURLが含まれています。

```json
"solution":{
	"id":"<id-string>",
	"url":"https://exercism.io/my/solutions/<id-string>",
	"team":null,
	"user":{
		"handle":"<exercism-user-name>",
		"is_requester":true
		},
		"exercise":{
			"id":"isogram",
			"instructions_url":"https://exercism.io/my/solutions/<id-string>",
			"auto_approve":false,
			"track":{
				"id":"pharo-smalltalk",
				"language":"Pharo"
				}
			},
			"file_download_base_url":"https://api.exercism.io/v1/solutions/<id-string>/files/",
			"files":[
				"IsogramTest.class.st",
				"README.md"
				],
			"iteration":null
		}
	}
```

#### 400

言語トラックの名前が曖昧であるか、提出された演習ファイルが変更されていません。

#### 403

解答のロックがユーザーに対して解除されていないか、言語トラックに参加していません。

#### 404

言語トラックまたは演習が見つかりませんでした。

## 演習の提出

```
Content-Type: application/octet-stream
```

`PATCH api.exercism.io//v1/solutions/<some-kind-of-token-or-hash> HTTP/1.1`

### レスポンス

#### 201

提出に成功しました。

#### 400

提出されたファイルが大きすぎる（1メガバイトを超えている）か、解答が重複しています。

#### 403

解答にユーザーがアクセスできません。解答のユーザーIDと現在のユーザーIDが一致していません。

#### 404

解答のIDが見つかりませんでした。
