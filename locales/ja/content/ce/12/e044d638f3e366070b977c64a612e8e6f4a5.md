# ヒント

## 1. ジュースを混ぜる時間

- 等しいかどうかの比較を連ねて値を選ぶなら、`cond`（[`combinators`][combinators]にあります）が最もすっきりした方法です。

## 2. ライムウェッジを補充する

- まだ必要なウェッジの数と、まだ手元にあるライムという2つの状態を扱う`while`ループが、ここでは自然な書き方です。これらを`::`と`:> name!`で宣言すると、本体が読みやすくなります。
- `unclip ( seq -- rest first )`は最初のライムを取り出し、そのまま`wedges-from-lime`に渡せます。

## 3. キューにある各注文を混ぜる時間を一覧にする

- [`sequences`][sequences]にある1つのワードが、この作業をすべてこなしてくれます。

## 4. シフトを終える

- 形はタスク2と同じです。シフトの残り時間と、まだ待っている注文という2つの状態で動く`while`ループを使います。どちらかが尽きたらすぐに止めます。

[sequences]: https://docs.factorcode.org/content/vocab-sequences.html
