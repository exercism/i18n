# 高階関数について

Kotlinでは、関数は第一級の存在です。
つまり、変数に代入したり、引数として渡したり、ほかの関数から返したりできるということです。
たとえば、次のように関数を変数`addOne`に代入できます。

```kotlin
val addOne = fun (num : Int) : Int {
    return num + 1
}
```

関数は、ほかの関数を返すこともできます。

```kotlin
fun makeAddOne() : (Int) -> Int {
    return fun(num : Int) : Int {
        return num + 1
    }
}
```

代入したあとは、その変数を通して、ただの関数と同じように呼び出せます。
```kotlin
addOne(3)
// => 4
```

## 関数型の宣言

変数や引数の型は、`(parameter types) -> return type`という構文で宣言できます。
たとえば、変数を宣言するには次のようにします。

```kotlin
val addOne : (Int) -> Int = fun (num : Int) : Int {
    return num + 1
}
```

関数の引数の場合は次のとおりです。

```kotlin
fun perform(operation : (Int) -> Int) {
    operation(3)
}
```

## ラムダ式

ラムダ式は、関数をより短く定義する方法です。
`{ parameters -> body }`の形で書きます。
式の値は、本体の最後の文の値になります。
たとえば、次のようになります。

```kotlin
// Assigning to a variable
val addOne = { num : Int -> num +  1}

// In a function call
perform({ num : Int -> num + 1 })
```

情報が十分にあれば、Kotlinが型を推論してくれます。
たとえば、先ほどの例は次のようにも書けます。

```kotlin
// Assigning to a variable
val addOne : (Int) -> Int = { num -> num + 1 }

// Or ...
val addOne  = { num : Int -> num + 1 }

// Using in a function
perform({ num -> num + 1 })
```

## 引数が1つだけのラムダ式と`it`

式の引数が1つだけのときは、その引数を省略できます。
するとKotlinは、`it`という引数を本体で使えるようにしてくれます。
たとえば、次のようになります。

```kotlin
val addOne : (Int) -> Int = { it +  1 }
```

## 末尾ラムダを渡す

関数の最後の引数がラムダのときは、ラムダ式を括弧の_直後_に書きます。
たとえば、次のようになります。

```kotlin
// Function that takes a function as last argument
fun calculateFrom(from : Int, operation : (Int) -> Int) : Int {
    return operation(from)
}

// Call the calculateFrom function
calculateFrom(2) { it * 3 }
// => 6
```
