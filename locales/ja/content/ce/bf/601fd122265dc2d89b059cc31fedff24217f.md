# はじめに

Haxeの`String`は、テキストをUnicode文字（文字、数字、記号など）の並びとして表す、変更できないオブジェクトです。`String`のインスタンスを定義するには、二重引用符を使います。

```haxe
var fruit:String = "Apple";
```

文字列は、そのメソッドを呼び出すことで操作します。一度文字列を作成すると、その値を変更することはできません。文字列を変更するように見えるメソッドも、実際には新しい文字列を返します。

複数の文字列は連結（加算）できます。最も簡単な方法は、`+`演算子を使うことです。

```haxe
var name:String = "Jane";
trace("Hello " + name + "!");
// => "Hello Jane!"
```

単純な連結よりも複雑な文字列の整形には、文字列補間が好まれます。文字列で補間を使うには、一重引用符（`'`）で囲みます。すると、ドル記号（`$`）を使って補間を開始できます。

```haxe
var name:String = "Jane";
trace('Hello $name!');
// => "Hello Jane!"
```
