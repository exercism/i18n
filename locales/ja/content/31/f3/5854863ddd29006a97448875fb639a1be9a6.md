# 説明

鉄道模型が大好きで、その情熱を世界と共有しようと、ニュースレターを始めることにしました。まずは、同じ趣味を持つ友人や知人に、ニュースレターの第1号を送るところから始めます。手元には、彼らのメールアドレスの一覧が書かれたテキストファイルがあります。

## 1. ファイルからメールアドレスを読み込む

`Newsletter.read_emails/1`関数を実装しましょう。ファイルパスを1つ受け取ります。ファイルは、メールアドレスが改行で区切られて並んでいるテキストファイルです。関数は、ファイルから読み込んだメールアドレスの配列を返します。

```elixir
Newsletter.read_emails("/home/my_user/documents/model_train_friends_emails.txt")
# => ["rick@example.com", "choochoo42@example.com", "anna@example.com"]
```

## 2. 書き込み用にログファイルを開く

メールの送信は、メールアドレスの打ち間違いや一時的なネットワークの問題など、予測できないさまざまな理由で失敗する可能性のある作業です。重複して送ることなく、友人全員へのメール送信をやり直せるようにするには、すでにメールを送ったアドレスを記録しておく必要があります。そのためにログファイルを使います。

`Newsletter.open_log/1`関数を実装しましょう。ファイルパスを1つ受け取り、書き込み用にファイルを開き、そのファイルを扱うプロセスのPIDを返します。

```elixir
Newsletter.open_log("/home/my_user/documents/newsletter_issue1_log.txt")
# => #PID<0.145.0>
```

## 3. 送信済みメールを記録する

`Newsletter.log_sent_email/2`関数を実装しましょう。ファイルを扱うプロセスのPIDと、メールアドレスが入った文字列を受け取ります。ファイルにメールアドレスを書き込み、その後に改行を加えます。

```elixir
Newsletter.log_sent_email(pid, "joe@example.com")
# => :ok
```

## 4. ログファイルを閉じる

`Newsletter.close_log/1`関数を実装しましょう。ファイルを扱うプロセスのPIDを受け取り、ファイルを閉じます。

```elixir
Newsletter.close_log(pid)
# => :ok
```

## 5. ニュースレターを送信する

メール送信の手順を組み立てる部品がそろったので、それらを1つの関数にまとめます。

`Newsletter.send_newsletter/3`関数を実装しましょう。メールアドレスが書かれたファイルのパス、ログファイルのパス、そして指定されたメールアドレスにメールを送る無名関数を受け取ります。指定されたファイルからすべてのメールアドレスを読み込み、そのすべてにメールを送ろうとします。メールを送る無名関数が`:ok`を返したら、そのメールアドレスをログファイルに書き込み、その後に改行を加えます。メールを送ったらすぐに行うようにしましょう。すべての送信が終わったら、ログファイルを閉じます。

```elixir
Newsletter.send_newsletter(
  "model_train_friends_emails.txt",
  "newsletter_issue1_log.txt",
  fn email -> :ok end
)

# => :ok
```
