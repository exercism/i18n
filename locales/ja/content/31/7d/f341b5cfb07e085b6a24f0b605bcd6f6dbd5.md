# インストール

## Node.jsのインストール

**WindowsとOS Xをお使いの方**：[Node.js][node]を[パッケージマネージャー経由で][node-download]インストールしてください。

**Linuxをお使いの方**：[Node.jsのパッケージマネージャー][linstall]でお使いのディストリビューション向けに案内されている手順に従って、[Node.js][node]をインストールしてください。

## `jasmine-node`と`coffeescript`のインストール

ほとんどの方にとっては、次のコマンドを実行するだけです。

```bash
$ npm install -g jasmine-node coffeescript
```

環境によっては、`npm`モジュールをグローバルにインストールするためにスーパーユーザー権限が必要になることがあります。上でリンクした公式インストーラーを使った場合はこれに当てはまります。アクセス権がないというエラーがNPMから返ってきたら、上のコマンドに`sudo`を付けてください。

```bash
$ sudo npm install -g jasmine-node coffeescript
```

公式インストーラーを使った場合は、`PATH`は自動で設定されているはずです。ただし、シェルがグローバルにインストールしたモジュールを見つけられない場合や、Node.jsをソースからビルドした場合は、`~/.bash_profile`または`~/.zshrc`に次を追加して、`PATH`に`npm`のバイナリを含めてください。

```bash
$ export PATH=/usr/local/share/npm/bin:$PATH
```
