# 概要

[クラス](https://docs.microsoft.com/en-us/dotnet/fsharp/language-reference/classes)は、F#でオブジェクト指向プログラミングを行うための主要な仕組みです。

F#のクラスは、フィールドとメソッドからできています。クラスのフィールドとメソッドは、まとめて_メンバー_と呼ばれます。

F#のクラスは、`type`キーワードを使って定義します。メソッドは`member`キーワードを使って定義し、常にpublicです。privateなフィールドを定義するには、`let`束縛を使うことができます。

```fsharp
type Shoe() =
    let size = 8

    member this.Describe() = $"This is a size {size} shoe"
```

クラスは、オブジェクトを作るためのテンプレートです。クラスのインスタンスを作るには、クラス名を関数のように呼び出します。クラスのインスタンスは、_オブジェクト_とも呼ばれます。

オブジェクトのメンバーには、ドット記法でアクセスできます。

```fsharp
let myShoe = Shoe()
myShoe.Describe()
// => "This is a size 8 shoe"
```
