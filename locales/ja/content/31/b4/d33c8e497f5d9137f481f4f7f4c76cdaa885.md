# はじめに

## 例外のフィルタリング

`when`は、例外をフィルタリングするためのキーワードです。catch文の後ろに置き、その時点でスコープにある任意の値を含む真偽値の式を取ることができます。式が真と評価されれば、その`catch`文に対応するブロックが実行され、そうでなければ、次に`catch`文があればそれが調べられます。

```csharp
try
{
    // do stuff
}
catch (Exception ex) when (ex.Message != "")
{
    // output the message when it is not empty
}
catch (Exception ex)
{
    // show stack trace or something.
}
```

## ユーザー定義例外

ユーザー定義例外とは、自分のコードで定義するクラスのうち、`System.Exception`から派生したものすべてを指します。クラス継承のルールにすべて従いますが、それに加えて、コンパイラーと言語ランタイムはこのようなクラスを特別に扱い、`exceptions`演習で説明するように、通常の制御フローを外れてそのインスタンスをスローしたりキャッチしたりできるようにします。

ユーザー定義例外は、メッセージやその他の関連データといった追加情報を運び、それをキャッチするルーチンから利用できるようにするためによく使われます。
