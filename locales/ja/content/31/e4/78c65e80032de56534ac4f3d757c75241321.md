# はじめに

Goでは、アプリケーションはパッケージという単位で整理されます。
パッケージとは、同じフォルダーにあるソースファイルをまとめたものです。
同じフォルダーにあるソースファイルは、すべてファイルの先頭で同じパッケージ名を宣言する必要があります。
慣習として、パッケージ名には、そのパッケージが置かれているフォルダーと同じ名前を付けます。

```go
package greeting
```

Goには、豊富な標準ライブラリのパッケージが用意されており、`import`キーワードを使うことで自分のプログラムから利用できます。
標準ライブラリのパッケージは、その名前を使ってインポートします。

```go
package greeting

import "fmt"
```

インポートしたパッケージは、パッケージ名で呼び出します。

```go
world := "World"
fmt.Sprintf("Hello %s", world)
```

Goでは、ある項目を他のパッケージのコードから呼び出せるかどうかは、その宣言の仕方で決まります。
関数、型、変数、定数、構造体のフィールドを外部から見えるようにする（これを_エクスポート_と呼びます）には、名前を大文字で始める必要があります。
これは、`public`や`private`といったアクセス修飾子を使うJavaのような他のプログラミング言語と似ています。

```go
package greeting

// Hello is a public function (callable from other packages).
func Hello(name string) string {
    return "Hello " + name
}

// hello is a private function (not callable from other packages).
func hello(name string) string {
    return "Hello " + name
}
```
