# 比較演算子

PHPには、組み込みの比較演算子が10個あります。

| 名前  | 例    | 結果                                             |
| ----- | ---------- | -------------------------------------------------- |
| 等しい | `$a == $b` | 型変換の後で`$a`と`$b`が等しければ`true`。 |
| 同一 | `$a === $b` | `$a`と`$b`が等しく、型も同じであれば`true`。 |
| 等しくない | `$a != $b` | 型変換の後で`$a`と`$b`が等しくなければ`true`。 |
| 等しくない | `$a <> $b` | 型変換の後で`$a`と`$b`が等しくなければ`true`。 |
| 同一でない | `$a !== $b` | `$a`と`$b`が等しくないか、型が同じでなければ`true`。 |
| より小さい | `$a < $b` | `$a`が`$b`より厳密に小さければ`true`。 |
| より大きい | `$a > $b` | `$a`が`$b`より厳密に大きければ`true`。 |
| 以下 | `$a <= $b` | `$a`が`$b`以下であれば`true`。 |
| 以上 | `$a >= $b` | `$a`が`$b`以上であれば`true`。 |
| 宇宙船演算子 | `$a <=> $b` | `$a`のとき、`0`iより小さい、等しい、または大きい整数を返します。 |

PHPには、`equal`と`identical`を区別する異なる定義があります。`identical`は`strictly equal`と呼ばれることもあります。

```php
<?php

// Comparisons between integer and numeric string values
1 == "1"; // => true, equal
1 === "1"; // => false, not identical

// Comparisons between integers and floating point values
1 == 1.0; // => true
1 === 1.0; // => false

// Comparisons between object instances
new stdClass() == new stdClass(); // => true, properties are equal
new stdClass() === new stdClass(); // => false, references are not identical
```
