# 説明

エレインは、動物と魔法の杖が登場する新しい子ども向けゲームに取り組んでいます。そろそろ、サイコロを振ったり、ランダムな杖のエネルギーを生成したり、スライスをシャッフルしたりする関数を書く番です。

## 1. サイコロを振る

`RollADie`関数を実装しましょう。

これは、1から20までの数字が付いた、昔ながらの二十面体のサイコロです。

```go
d := RollADie() // d will be assigned a random int, 1 <= d <= 20
```

## 2. 杖のエネルギーを生成する

`GenerateWandEnergy`関数を実装しましょう。
杖のエネルギーは、0.0以上12.0未満のランダムな小数にします。

```go
f := GenerateWandEnergy()  // f will be assigned a random float64, 0.0 <= f < 12.0
```

## 3. スライスをシャッフルする

このゲームには、8種類の動物が登場します。

- ant
- beaver
- cat
- dog
- elephant
- fox
- giraffe
- hedgehog

8種類の動物をランダムな順番に並べたスライスを返す`ShuffleAnimals`関数を書きましょう。
