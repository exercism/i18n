# Char

`Char`は、Crystalで32ビットの[Unicode][unicode]コードポイントを表すデータ型です。そのサイズのおかげでメモリ効率がよく、`String`にはない特有の性質も持っています。`Char`はシングルクォート（`'`）を使って作成し、中には1つのUnicodeコードポイントしか入れられません。

```crystal
'a' # => 'a'
'a'.class # => Char
```

Crystalで`String`を扱うとき、`Char`を扱う機会はよくあります。`String`クラスの多くのメソッドが`Char`を返したり、`Char`を引数に取ったりするからです。たとえば、[`String#[]`][index]メソッドは`Char`を返し、[`String#chars`][chars]メソッドは`Char`のコレクションを返します。

## インクリメントとデクリメント

`Char`は32ビットのUnicodeコードポイントなので、インクリメントとデクリメントができます。そのため、`'a'`に1を足せば`'b'`が得られます。

```crystal
'a' + 5
# => 'f'

'z' - 25
# => 'a'
```

また、Unicodeテーブルの次の`Char`を返す[`Char#succ`][succ]というメソッドと、前の`Char`を返す[`Char#pred`][pred]もあります。

```crystal
'a'.succ
# => 'b'

'z'.pred
# => 'y'
```

## 連結

`Char`は32ビットのUnicodeコードポイントを表すためだけのものなので、2つの`Char`を連結することはできません。そのため、`Char`は`String`としか連結できません。

```Crystal
'a' + "bc"
# => "abc"

'a' + 'b'
# => error: expected argument #1 to 'Char#+' to be Int or String, not Char
```

## 文字の性質を調べるメソッド

Crystalには、その文字が数字なのか文字なのか、大文字なのか小文字なのかといった、文字についての情報を得るためのメソッドがいくつかあります。以下はメソッドの一部です。完全なリストは[Char API][char-api]を参照してください。

| メソッド                         | 説明                                                 |
| -------------------------------- | ---------------------------------------------------- |
| [`Char#number?`][number]         | `Char`が数字であれば`true`を返します                 |
| [`Char#letter?`][letter]         | `Char`が文字であれば`true`を返します                 |
| [`Char#lowercase?`][lowercase]   | `Char`が小文字であれば`true`を返します               |
| [`Char#uppercase?`][uppercase]   | `Char`が大文字であれば`true`を返します               |
| [`Char#ascii?`][ascii]           | `Char`がASCII文字であれば`true`を返します            |
| [`Char#whitespace?`][whitespace] | `Char`が空白文字であれば`true`を返します             |

## 変換

### コードポイントと`Char`の相互変換

`Char`は32ビットのUnicodeコードポイントなので、`Char`とコードポイント（`Int`）の間で変換できます。これには、`Char`のコードポイントを返す[`Char#ord`][ord]メソッドや、コードポイントの`Char`を返す[`Int#chr`][chr]メソッドを使います。

```crystal
'a'.ord
# => 97

97.chr
# => 'a'
```

### 型の相互変換

他のデータ型と同様に、`Char`には型を変換するためのメソッドがいくつかあります。最もよく使われるのは、`Char`を`String`に変換する`Char#to_s`メソッドです。ほかにも、`Char`を`Int`に変換する`Char#to_i`メソッドや、`Char`を`Float`に変換する`Char#to_f`メソッドがあります。

```crystal
'a'.to_s
# => "a"

'4'.to_i
# => 4

'a'.to_i
# => Error: Invalid integer: a (ArgumentError)
```
