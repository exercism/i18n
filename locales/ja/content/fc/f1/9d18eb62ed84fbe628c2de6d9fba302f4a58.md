# 説明

ダンス一座が演じるどのルーティンも、同じウォームアップを土台にして、そこからそれぞれの道を進みます。

スタブには`WARM_UP`が用意されています。その下に、さらに3つのクラスを書きましょう。

## 1. ジャズのルーティン

`JAZZ_ROUTINE`は`WARM_UP`からすべてをそのまま受け継ぎ、何も付け加えません。

```sather
JAZZ_ROUTINE::counts
-- => 8
JAZZ_ROUTINE::describe
-- => "8 counts"
```

## 2. タップのルーティン

`TAP_ROUTINE`は`WARM_UP`から`counts`を受け継ぎますが、説明のしかたは独自です。includeから`describe`を外して、新しいものを書きましょう。

```sather
TAP_ROUTINE::counts
-- => 8
TAP_ROUTINE::describe
-- => "Tap: 8 counts"
```

## 3. フィナーレ

`FINALE`は`WARM_UP`から`counts`を`warm_up_counts`という名前で受け継ぎ、`describe`は外します。そして独自の`counts`（ウォームアップの2倍）と、独自の`describe`を持ちます。

```sather
FINALE::warm_up_counts
-- => 8
FINALE::counts
-- => 16
FINALE::describe
-- => "Finale: 16 counts"
```

ここからわかるのは、`FINALE::counts`は`WARM_UP::counts`とは別もので、両方とも同じクラスの中で違う名前で使えるということです。
