# 指示

チーズクラブを立ち上げます。このクラブでは、機械学習（ML）を使って、チーズ好きのお客様の履歴と好みに基づき、提供する新しいチーズを選びます。

新しく入会するメンバーには、最初のアンケートに回答してもらいます。これは、手始めに使う基本的なデータを集めるためです。
このアンケートを通じて、評価にニュアンスを欠いた、極端な評価をするお客様が一定数いることが分かりました。
こうした評価は、よりきめ細やかなアルゴリズムに取り返しのつかない偏りをもたらしかねないため、そうしたお客様のニーズに対応するための専用のアルゴリズムを別に用意しています。
そこで、そうしたお客様のデータを扱うための補助的な関数をいくつか用意してもらいます。

~~~~exercism/note
以下のタスクにはいくつもの解き方がありますが、どのタスクも2つ以下の高階関数で解くことができます。
~~~~

## 1. お客様を分類する

評価システムは5段階の星を基準にしており、単純に整数`1:5`で表します。
極端な評価をするお客様は`1`か`5`の評価しか付けません。そこで、あるお客様がこの行動を示すかどうかを知りたいのです。

`all_15()`を実装してください。これは評価のベクトルを受け取り、すべての評価が`1`か`5`であれば`true`を、そうでなければ`false`を返します。

```R
all_15(c(2, 3, 4, 4, 1))
#> [1] FALSE

all_15(c(1, 5, 5, 1, 5))
#> [1] TRUE
```

## 2. お客様に名前を付ける

お客様の名前（またはID）と、その評価を関連付ける必要があります。

`name_customers()`を実装してください。これは名前のベクトルと評価のリストを受け取り、それらをリストのリストにまとめます。

内側のリストの要素には、`name`と`rating`という名前を付けてください。

```R
names <- c("c1", "c2")
ratings <- list(c(2, 3, 5), c(1, 1, 5))
name_customers(names, ratings)
#> [[1]]
#> [[1]]$name
#> [1] "c1"

#> [[1]]$rating
#> [1] 2 3 5

#> [[2]]
#> [[2]]$name
#> [1] "c2"

#> [[2]]$rating
#> [1] 1 1 5
```

## 3. 極端な評価をするお客様を分ける

より極端な評価をするお客様を、それ以外のお客様から分ける必要があります。

`emphatics()`を実装してください。これはお客様と評価を受け取り、`1`か`5`の星評価しか使わないお客様だけに絞り込んだリストを返します。

```R
# names and ratings as in the task 2 example

emphatics(names, ratings)
#> [[1]]
#> [[1]]$name
#> [1] "c2"

#> [[1]]$rating
#> [1] 1 1 5
```

## 4. 評価を2値に変換する

極端な評価をするお客様は`1`と`5`の評価しか使いません。そのため、これらを`0`と`1`に変換しておくと、計算上都合が良くなります。

`to_binary()`を実装してください。これは極端な評価のベクトルを受け取り、2値の評価を返します。ここでは`1`が`0`に、`5`が`1`に変換されています。

```R
to_binary(c(1, 1, 5, 5, 1))
#> [1] 0 0 1 1 0
```

## 5. 時系列で平均評価を計算する

すべてのお客様（極端な評価をするお客様だけでなく）について、好みをより深く理解するにつれて、時間をかけて推薦を改善し続けたいと考えています。

`satisfactions()`を実装してください。これは評価のベクトルを受け取り、その時点までの累積平均評価のベクトルを返します。結果は小数点以下2桁に丸めてください。

数値がどんどん伸びて、お客様が幸せになりますように！

```R
satisfactions(c(1, 2, 2, 3))
#> [1] 1.00 1.50 1.67 2.00
```
