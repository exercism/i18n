# 文字

**文字**とは、1つの英字、数字、スペース、または記号のことです。Satherで文字1つを表す型は`CHAR`で、文字は一重引用符で囲んで書きます。

```sather
   initial : CHAR is
      return 'M';
   end;
```

1文字には一重引用符、文字列には二重引用符を使います。`'M'`と`"M"`は異なる型で、置き換えることはできません。

## 文字列から文字を取り出す

文字列は文字が並んだもので、角括弧を使うと、位置を指定して1つの文字を取り出せます。位置は0から数えます。配列と同じです。

```sather
"Marlowe"[0]      -- 'M'
"Marlowe"[3]      -- 'l'
```

## 文字について調べる

| 呼び出し | 答え |
| --- | --- |
| `c.is_alpha` | 英字かどうか |
| `c.is_digit` | `0`から`9`までのいずれかかどうか |
| `c.is_upper` | 大文字かどうか |
| `c.is_lower` | 小文字かどうか |

それぞれが`true`か`false`を返します。

```sather
'M'.is_alpha      -- true
'7'.is_alpha      -- false
'7'.is_digit      -- true
```

## 大文字と小文字を変える

`.upper`は英字を大文字にし、`.lower`は小文字にします。英字以外のものは、そのまま返されます。

```sather
'm'.upper         -- 'M'
'M'.lower         -- 'm'
'7'.upper         -- '7'
```

## 文字を数値として扱う

すべての文字には数値が対応しています。`.int`でその数値を取り出し、`.char`で数値を文字に戻します。

```sather
'a'.int           -- 97
'b'.int           -- 98
98.char           -- 'b'
```

正確な数値が問題になることはほとんどありません。大切なのは、`a`から`z`までの英字が順番に、しかも隣り合って並んでいることです。そのため`'c'.int - 'a'.int`は2になり、これは`c`がアルファベットの何番目にあるかを表します。これが暗号円盤を機能させる仕組みです。
