# はじめに

Swiftの`guard`文は、この先の処理を続けるために必要な条件が満たされていないときに、関数から早い段階でreturnするために使います。たとえば、次のとおりです。

```swift
guard myValue >= 0 else { return 0 }
let root = myValue.squareRoot()
```

ここでは、`guard`は、`guard`キーワードに続く真偽値の式が`true`と評価されるかどうかを確認します。`true`であれば、guard文に続くコード（ここでは`let root = myValue.squareRoot()`）の処理が続きます。そうでなければ、else節のコードが実行されます。`if`文とは異なり、`guard`文にはelse節が_必ず_必要です。また、if-elseのelse節とは違い、guardのelse節は、guard文のスコープから_必ず_抜けなければなりません。つまり、`return`、`continue`、`break`などの制御転送文を使うか、エラーをスローするか、プログラムを終了しなければなりません。
