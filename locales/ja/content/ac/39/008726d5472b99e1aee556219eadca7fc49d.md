# 指示

三角形が正三角形、二等辺三角形、不等辺三角形のどれであるかを判定します。

_正三角形_は、3つの辺の長さがすべて同じです。

_二等辺三角形_は、少なくとも2つの辺の長さが同じです。
（正確に2つの辺の長さが同じであると定義されることもありますが、この演習では少なくとも2つとします。）

_不等辺三角形_は、すべての辺の長さが異なります。

## 注意

図形がそもそも三角形であるためには、すべての辺の長さが0より大きい必要があり、さらに、どの2つの辺の長さの和も、残りの1つの辺の長さ以上でなければなりません。

式で表すと、次のようになります。

三角形の辺を`a`、`b`、`c`とします。
このとき、次の3つの式がすべて成り立つ必要があります。

```text
a + b ≥ c
b + c ≥ a
a + c ≥ b
```

[三角不等式][triangle-inequality]を参照してください。
