# 指示の補足

## レジスタ

| レジスタ | 用途         | 型      | 説明                       |
| -------- | ------------ | ------- | -------------------------- |
| `$a0`    | 入力         | 整数    | 与えられた数値             |
| `$a1`    | 入力/出力    | アドレス | ヌル終端された結果文字列   |
| `$t0-9`  | 一時的       | 任意    | 一時的な保存用             |
