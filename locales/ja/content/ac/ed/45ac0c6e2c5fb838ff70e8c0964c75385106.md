# 演習を解く

Exercismが学習をサポートする主な方法は、演習を解くことです。

Exercismで演習を解く方法は、次の2つです。

1. [ウェブサイトのブラウザー内エディターで解く（オンライン）](/docs/using/solving-exercises/using-the-online-editor)
2. [CLIを使って自分のパソコンで解く（ローカル）](/docs/using/solving-exercises/working-locally)

## どちらを選べばいいのでしょうか？

オンラインエディターを使う場合とCLIを使う場合では、それぞれメリットとデメリットがあります。

|            | オンラインエディター | CLI |
| ---------- | ---------------------- | ----------- |
| インストール | 不要 | 必要（SDKなど） |
| 編集 | ブラウザー | 使い慣れたエディター |
| テスト | ウェブサイト上でテストを実行 | ローカルでテストを実行 |
| デバッグ | 一部のトラックのみサポート | 環境に応じて完全にサポート |

一般的に、オンラインエディターは新しいトラックを始めるのに最適です。一方、CLIを使う方法は、自分に合ったコーディング環境で学びたい場合に向いています。
