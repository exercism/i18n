# 説明

健康モニタリングシステムの実装に取り組んでいます。
その一環として、ユーザーの健康統計を記録する必要があります。

まずは、`impl`ブロックにあるいくつかのスタブ関数と、次の構造体の定義から始めます。

```rust
pub struct User {
    name: String,
    age: u32,
    weight: u32,
}
```

目標は、`impl`ブロックで定義されている`User` `struct`のスタブメソッドを実装することです。

たとえば、`new`メソッドは、指定された名前、年齢、体重を持つ`User`構造体のインスタンスを返します。

```rust
let mut bob = User::new("Bob", 32, 72);
// Returns: a User with name "Bob", age 32, and weight 72
```

`weight`メソッドは`User`の体重を返します。

```rust
bob.weight();
// Returns: 72
```

`set_age`メソッドは`User`の年齢を設定します。

```rust
bob.set_age(33);
// Updates Bob's age to 33; happy birthday Bob!
```

楽しんで取り組んでください！
