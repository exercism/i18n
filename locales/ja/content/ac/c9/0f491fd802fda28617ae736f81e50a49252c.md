# はじめに

関数を使うと、コードを再利用できるひとつのまとまりにグループ化できます。
関数は、`func`キーワード、関数名、そして括弧（`()`）の中にカンマで区切って並べた0個以上の仮引数と型からなります。

## 関数の仮引数

仮引数はすべて明示的に型を指定する必要があり、仮引数の型推論はありません。
仮引数にデフォルト値はないため、関数の仮引数はすべて必須です。

```go
import "fmt"

// No parameters
func PrintHello() {
    fmt.Println("Hello")
}

// Two parameters
func PrintGreetingName(greeting string, name string) {
  fmt.Println(greeting + " " + name)
}
```

同じ型の仮引数はまとめて宣言でき、そのあとに型を一度だけ書きます。

```go
import "fmt"

func PrintGreetingName(greeting, name string) {
  fmt.Println(greeting + " " + name)
}
```

## 仮引数と実引数

よく混同されやすい2つの用語、`parameters`と`arguments`について、簡単に見ておきましょう。
関数の仮引数とは、関数のシグネチャで定義される名前のことです。たとえば、上の関数`PrintGreetingName`では`greeting`と`name`がそれにあたります。
関数の実引数とは、関数を呼び出すときに仮引数へ渡す具体的な値のことです。
たとえば、次の例では、`"Hello"`と`"Katrina"`が、`greeting`と`name`という仮引数に渡される実引数です。

```go
PrintGreetingName("Hello", "Katrina")
```

## 戻り値

関数の仮引数のあとには、0個以上の戻り値が続き、これらも明示的に型を指定する必要があります。
戻り値が1つのときはそのまま書き、複数あるときは括弧でくくります。
値は、`return`キーワードを使って関数から呼び出し元のコードへ返されます。
1つの関数の中に複数の`return`文を書くこともできます。
関数の実行は、それらの`return`文のいずれかに到達した時点で終わります。
関数から複数の値を返す場合は、カンマで区切ります。

```go
func Hello(name string) string {
  return "Hello " + name
}

func HelloAndGoodbye(name string) (string, string) {
  return "Hello " + name, "Goodbye " + name
}
```

## 関数の呼び出し

関数を呼び出すには、関数名を指定し、その関数の仮引数それぞれに対応する実引数を括弧の中に渡します。

```go
import "fmt"

// No parameters, no return value
func PrintHello() {
    fmt.Println("Hello")
}
// Called like this:
PrintHello()

// One parameter, one return value
func Hello(name string) string {
  return "Hello " + name
}
// Called like this:
greeting := Hello("Dave")

// Multiple parameters, multiple return values
func SumAndMultiply(a, b int) (int, int) {
    return a+b, a*b
}
// Called like this:
aplusb, atimesb := SumAndMultiply(a, b)
```

## 名前付き戻り値とnaked return

仮引数と同様に、戻り値にも名前を付けることができます。
名前付き戻り値を使うと、引数なしの`return`文がそれらの値を返します。
これはnaked returnと呼ばれます。

```go
func SumAndMultiplyThenMinus(a, b, c int) (sum, mult int) {
    sum, mult = a+b, a*b
    sum -= c
    mult -= c
    return
}
```

## 値渡しと参照渡し

値渡しと参照渡しという概念も、ここで整理しておきましょう。

まずは値渡しから見てみましょう。
次の例では、変数`val`を関数`MultiplyByTwo`に渡すとき、`val`のコピーを渡しています。
そのため、`newVal`は更新後の値`4`を持ちますが、元の変数`val`は依然として`2`のままです。
内部的には、Goは元の値のコピーを作り、関数によって変更されるのはこのコピー（つまり`v`）だけです。

```go
val := 2
func MultiplyByTwo(v int) int {
    v = v * 2
    return v
}
newVal := MultiplyByTwo(val)
// newval is 4, val is still 2 because only a copy of its value was passed into the function
```

厳密に言えば、Goではすべての実引数は値渡しです。つまり、関数に渡された値やデータのコピーが作られます。
しかし、関数に渡すデータのコピーを作らずに、関数の中でそのデータを変更したい場合は、`pointers`を実引数として使います。これが参照渡しです。

## ポインタ

参照渡しを実現するには、`pointer`を使います。
`pointer`を実引数として関数に渡すことで、データのコピーを操作するだけでなく、関数に渡された元のデータそのものを変更できます。

今のところは、ポインタ型は関数のシグネチャで型の前に付いた`*`で見分けられる、と知っておけば十分です。

```go
func HandlePointers(x, y *int) {
    // Some logic to handle integer values referenced by pointers x and y
}
```

`pointer`という概念がよくわからなくても、心配いりません。
シラバスの後半に、ポインタをマスターするための専用のセクションを用意しています。

## 例外

`slices`と`maps`は、上述のルールの例外であることに注意してください。
`slice`や`map`を実引数として関数に渡すとき、型に明示的な`*`がなくても、これらはポインタ型として扱われます。
つまり、スライスやマップを関数に渡してその元のデータを変更すると、その変更は元のスライスやマップにも反映されます。
