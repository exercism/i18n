# ヒント

## 全般

- 新しい変更可能なハッシュテーブルを作るには、`H{ } clone`が正しい方法です。`H{ }`リテラルは呼び出し間で共有される可能性があるためです。
- [`assocs`][assocs]の`inc-at`は、キーの値に1を加えます（キーがなければ1として挿入します）。

## 1. リストから在庫を組み立てる

- まず`H{ } clone`から始めて、各要素に`inc-at`を使います。fry引用`'[ _ inc-at ]`はハッシュテーブルを捕捉するので、そのまま`each`に渡せます。
- 繰り返しを`[ … ] keep`で包むと、ハッシュテーブルがスタックに残る値になります。

## 2. アイテムをさらに追加する

- 形はタスク1と同じですが、空の在庫からではなく、入力の在庫を`clone`したものから始めます。

## 3. カウントを減らす

- まず`key?`を使います。在庫にすでにあるアイテムだけが対象になります。
- `change-at`は引用`( old -- new )`を受け取ります。これに`[ 1 - 0 max ]`（`max`は[`math.order`][math.order]にあります）を組み合わせると、カウントが負になることはありません。

## 4. アイテムを完全に取り除く

- `delete-at`はハッシュテーブルを変更し、何も返しません。まず`clone`し、次に`delete-at`を実行し、そのクローンをスタックに残します。

## 5. 利用可能なアイテムを一覧にする

- `>alist`はハッシュテーブルをペアの並びに変換します。
- `[ second 0 > ] filter`は、在庫のあるアイテムだけを残します。
- `sort-keys`（[`sorting`][sorting]にあります）は、alistをキーで並べ替えます。

[math.order]: https://docs.factorcode.org/content/vocab-math.order.html
[sorting]: https://docs.factorcode.org/content/vocab-sorting.html
