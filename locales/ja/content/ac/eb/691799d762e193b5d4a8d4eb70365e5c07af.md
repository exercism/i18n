# 説明

Bobは金融アドバイザーで、人々が支出を管理するのを手伝っています。
Bobのクライアントは、分析してもらうために支出の記録をBobに送ります。
Bobは過去の期間の記録も持っているので、支出の変化を見ることができます。
Bobはカレンダーが好きではなく、日付の代わりに*Bob epoch*を使います。
Bob epochは、Bobのクライアントが活動を始めてから経過した日数です。

この演習では、Bobがクライアントの支出を管理・分析するのを助けるプログラムを作ります。

Bobは`Record`と`DaysPeriod`を扱います。

`Record`は支出の記録を表し、支出があった日、使った金額、支出のカテゴリーを含みます。

```go
// Record represents an expense record.
type Record struct {
	Day         int
	Amount      float64
	Category    string
}
```

`DaysPeriod`は日の範囲を表し、`From`の日から`To`の日までのすべての日を含みます。
範囲には両端の日も含まれます。

```go
// DaysPeriod represents a period of days.
type DaysPeriod struct {
	From int
	To   int
}

p := DaysPeriod{From: 1, To: 31}
// p represents all days from the day 1 to the day 31:
//  - days 1, 20, 16 and 31 are examples of days that are included
//    in the range of time specified by p
//  - days 50 and 40 are examples of days that are not included
//    in the range of time specified by p
```

## 1. 汎用的なレコードフィルターを実装する

Bobは毎日たくさんのレコードを扱いますが、Bobが行う分析によっては、そのすべてが興味深いものではありません。
Bobが基本的なレコードの絞り込みを行えるよう、手伝いましょう。

関数で与えられた条件に従ってレコードを絞り込む、汎用的な`Filter`関数を実装します。
このフィルター関数は、レコードのコレクションと条件を判定する関数を受け取り、コレクションの中でその条件を満たすレコードだけを返します。

```go
records := []Record{
  {Day: 1, Amount: 15, Category: "groceries"},
  {Day: 11, Amount: 300, Category: "utility-bills"},
  {Day: 12, Amount: 28, Category: "groceries"},
}

// Day1Records only returns true for records that are from day 1
func Day1Records(r Record) bool {
  return r.Day == 1
}

Filter(records, Day1Records)
// =>
// [
//   {Day: 1, Amount: 15, Category: "groceries"}
// ]
```

## 2. 一定の期間内のレコードを絞り込む

Bobは、ある期間内にあるレコードを絞り込む必要がよくあります。

そのようなフィルターを作れるようにする`ByDaysPeriod`関数を実装します。
この関数は`DaysPeriod`を受け取り、レコードを受け取って、そのレコードが引数で与えられた`DaysPeriod`で指定された期間内にあるかどうかを返す関数を返します。

```go
records := []Record{
  {Day: 1, Amount: 15, Category: "groceries"},
  {Day: 11, Amount: 300, Category: "utility-bills"},
  {Day: 12, Amount: 28, Category: "groceries"},
  {Day: 26, Amount: 300, Category: "university"},
  {Day: 28, Amount: 1300, Category: "rent"},
}

period := DaysPeriod{From: 1, To: 15}

Filter(records, ByDaysPeriod(period))
// =>
// [
//   {Day: 1, Amount: 15, Category: "groceries"},
//   {Day: 11, Amount: 300, Category: "utility-bills"},
//   {Day: 12, Amount: 28, Category: "groceries"},
// ]
```

## 3. カテゴリーでレコードを絞り込む

期間でレコードを絞り込むだけでなく、Bobはカテゴリーでもレコードを絞り込む必要があります。

そのようなフィルターを作れるようにする`ByCategory`関数を実装します。
この関数はカテゴリーを受け取り、レコードを受け取って、そのレコードのカテゴリーが引数で与えられたカテゴリーと同じかどうかを返す関数を返します。

```go
records := []Record{
  {Day: 1, Amount: 15, Category: "groceries"},
  {Day: 11, Amount: 300, Category: "utility-bills"},
  {Day: 12, Amount: 28, Category: "groceries"},
  {Day: 28, Amount: 1300, Category: "rent"},
}

Filter(records, ByCategory("groceries"))
// =>
// [
//   {Day: 1, Amount: 15, Category: "groceries"},
//   {Day: 12, Amount: 28, Category: "groceries"},
// ]
```

## 4. 期間内の支出の合計額を計算する

Bobは、ある期間内の支出の合計額も知りたいと思っています。

`TotalByPeriod`関数を実装して、その期間内の支出の合計を返すようにします。

```go
records := []Record{
  {Day: 15, Amount: 16, Category: "entertainment"},
  {Day: 32, Amount: 20, Category: "groceries"},
  {Day: 40, Amount: 30, Category: "entertainment"}
}

p1 := DaysPeriod{From: 1, To: 30}
p2 := DaysPeriod{From: 31, To: 60}

TotalByPeriod(records, p1)
// => 16

TotalByPeriod(records, p2)
// => 50
```

## 5. 期間内の、あるカテゴリーのレコードの支出合計を計算する

Bobがクライアントに出す最も複雑なレポートのために、Bobはカテゴリーと期間の両方で同時にレコードを絞り込む必要があります。
つまり、Bobはある期間内の、あるカテゴリーのレコードの支出合計を知りたいということです。

ある期間内の、あるカテゴリーの支出の合計額を返す`CategoryExpenses`関数を実装します。
また、この関数は、与えられたカテゴリーが支出の記録に存在しない場合と、指定された期間内にそのカテゴリーの支出がない場合を区別する必要があります。
そのカテゴリーがどのレコードのカテゴリーでもない場合（期間に関係なく）、この関数はエラーを返す必要があります。

```go
p1 := DaysPeriod{From: 1, To: 30}
p2 := DaysPeriod{From: 31, To: 60}

records := []Record{
  {Day: 1, Amount: 15, Category: "groceries"},
  {Day: 11, Amount: 300, Category: "utility-bills"},
  {Day: 12, Amount: 28, Category: "groceries"},
  {Day: 26, Amount: 300, Category: "university"},
  {Day: 28, Amount: 1300, Category: "rent"},
}

CategoryExpenses(records, p1, "entertainment")
// => 0, error(unknown category entertainment)

CategoryExpenses(records, p1, "rent")
// => 1300, nil

CategoryExpenses(records, p2, "rent")
// => 0, nil
```
