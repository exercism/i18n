# `_is`と疑問符を付けた`defmacro`

[comment]: # (3つのパラメータが必要です：)
[comment]: # (- actual: 学習者が使った誤った名前)
[comment]: # (- option1: 関数で使う場合の正しい名前)
[comment]: # (- option2: ガード節で使う場合の正しい名前)

Elixirには独自の命名規則があり、[真偽値を返す関数](https://hexdocs.pm/elixir/naming-conventions.html#trailing-question-mark-foo)や[真偽値を返しガード節で有効なチェック](https://hexdocs.pm/elixir/naming-conventions.html#is_-prefix-is_foo)の名前の付け方もこれに含まれます：

> 真偽値を返す関数は、末尾に疑問符を付けて命名します。

> ガード節で使える型チェックやその他の真偽値チェックは、`is_`を接頭辞として命名します。

マクロはどちらの文脈でも使えるため、表記は場合によって異なりますが、2つの命名規則を混在させてはいけません。

```elixir
# this is the expected name of macros that return booleans

%{option1}

# this is the expected name of macros that return booleans and are valid in guard clauses

%{option2}

# this is the current name

%{actual}
```
