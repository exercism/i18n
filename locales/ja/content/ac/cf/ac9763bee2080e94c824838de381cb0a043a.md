# はじめに

リファレンスを理解することは、Perlを効果的に使うための基本です。
リファレンスはスカラーであり、配列とハッシュはスカラーしか含められないため、これらのデータ構造を入れ子にするにはリファレンスが欠かせません。

リファレンスは、バックスラッシュ演算子`\`を使うと、既存の変数やサブルーチンに対して作成できます。

* `\$scalar`でスカラーリファレンスを作成します（変数だけでなく、`\1`のように任意のスカラーを使えます）。
* `\@array`で配列リファレンスを作成します。
* `\%hash`でハッシュリファレンスを作成します。
* `\&sub`でコードリファレンスを作成します。

配列、ハッシュ、サブルーチンに対しては、無名リファレンスと呼ばれるものも作成できます。

* `['Alice', 'Bob', 'Charlie']`で無名配列リファレンスを作成します。
* `{foo => 'a', bar => 'b', baz => 'c'}`で無名ハッシュリファレンスを作成します。
* `sub { return 1 }`で無名コードリファレンスを作成します。

注意：Perlの波括弧は、状況によっては曖昧になることがあります。期待したハッシュリファレンスにならないときは、先頭にプラスを付けて曖昧さをなくします（例：`+{}`）。詳しくは[波括弧][perlrefcurlybrackets]を参照してください。

リファレンスには、アロー演算子`->`を使ってアクセスできます。

* `$ref->[0]`で配列リファレンス内の要素にアクセスします。
* `$ref->{foo}`でハッシュリファレンス内の値にアクセスします。
* `$ref->($arg)`でコードリファレンス経由でサブルーチンを呼び出します。

多次元配列や入れ子のハッシュのような複雑なデータ構造内のデータには、添字を連ねることでアクセスできます（例：`$ref->{foo}[0]{bar}`。これは`$ref->{foo}->[0]->{bar}`と同じです）。

配列やハッシュ全体をデリファレンスしたい場合は、アロー演算子の後に、それぞれ`@*`または`%*`を付けます（例：`$ref->@*`や`$ref->%*`）。
また、`*`を添字に置き換えることで、配列やハッシュのリファレンスからスライスを取り出すこともできます（例：`$ref->@[0..2]`や`$ref->@{'Foo', 'Bar'}`）。
スライスの場合、配列変数やハッシュ変数と同じように、シジルの使い分けが適用されます。

[perlrefcurlybrackets]: https://perldoc.perl.org/perlref#Curly-Brackets
