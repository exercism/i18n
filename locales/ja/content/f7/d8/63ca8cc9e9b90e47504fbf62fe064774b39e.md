# ヒント

## 1. パックマンがゴーストを食べられるかを定義する

* 関数は真偽値を返す必要があります。
* 論理演算子`and`を使うと、引数を組み合わせて結果を得られます。

## 2. パックマンが得点するかを定義する

* 関数は真偽値を返す必要があります。
* 真偽値演算子`or`を使うと、引数を組み合わせて結果を得られます。

## 3. パックマンが負けるかを定義する

* 関数は真偽値を返す必要があります。
* 真偽値演算子`and`と`not`を使うと、引数を組み合わせて結果を得られます。

## 4. パックマンが勝つかを定義する

* 関数は真偽値を返す必要があります。
* 真偽値演算子`and`と`not`を使うと、引数と、以前に実装したいずれかの関数の結果を組み合わせることができます。
