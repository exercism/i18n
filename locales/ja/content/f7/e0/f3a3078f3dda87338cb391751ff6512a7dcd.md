# 説明

学生の試験を採点するティーチングアシスタントです。
成績を手作業で管理するのは、面倒なうえに間違えやすくなってきました。
そこで、クラスの成績を数えたり計算したりする関数をいくつか組み合わせて、作業をもう少し面白くしてみることにしました。

## 1. 点数を丸める

試験の問題では「部分点」を与えることはできますが、試験全体の点数は`int`でなければなりません。
そのため、クラスの点数を扱う前に、まず成績を一つひとつ見て、`float`の点数を`int`に変換する必要があります。
幸いなことに、Pythonには組み込みの[`round()`][round]関数があります。

`student_scores`の`list`を受け取る`round_scores(student_scores)`関数を作成しましょう。
この関数は、入力の`list`を_消費_し、すべての点数を`int`に変換した新しいリストを`return`する必要があります。
結果の`list`に含まれる点数の順序は重要ではありません。

```python
>>> student_scores = [90.33, 40.5, 55.44, 70.05, 30.55, 25.45, 80.45, 95.3, 38.7, 40.3]
>>> round_scores(student_scores)
...
[40, 39, 95, 80, 25, 31, 70, 55, 40, 90]
```

## 2. 合格点に届かない学生

試験を採点していると、思っていたほど成績が伸びていない学生がいることに気づきました。
しかし、気を取られて、その学生が_何人_いたのかを正確に記録するのを忘れてしまいました。

`student_scores`の`list`を受け取る`count_failed_students(student_scores)`関数を作成しましょう。
この関数は、合格点に達していない学生の数を数え、その数を整数として返す必要があります。
試験で合格するには、**40**より大きい点数が必要です。

```python
>>> count_failed_students(student_scores=[90,40,55,70,30,25,80,95,38,40])
5
```

## 3. 「ベスト」

担当している先生は、この試験で「ベスト」な成績を収めた学生のグループを見つけたいと考えています。
何をもって「ベスト」とするかは変動するので、現在のしきい値**以上**の点数を見つける必要があります。

`student_scores`（成績の`list`）と`threshold`（「最高点」のしきい値）を引数に取る`above_threshold(student_scores, threshold)`関数を作成しましょう。
この関数は、`threshold`に対して`>=`であるすべての点数の`list`を返す必要があります。

```python
>>> above_threshold(student_scores=[90,40,55,70,30,68,70,75,83,96], threshold=75)
[90,75,83,96]
```

## 4. アルファベット成績の計算

担当している先生は、数値の点数だけでなくアルファベットの成績も付けたいと考えています。
学生が試験で100点を取ることはほとんどないため、「アルファベット成績」の下限のしきい値は、達成された最高点をもとに計算し、最高点と不合格のしきい値である**<= 40**の間を均等に割り振ります。

試験の「最高点」を引数に取り、各「アメリカ式」の成績区分（`["D", "C", "B", "A"]`）の下限のしきい値の`list`を返す`letter_grades(highest)`関数を作成しましょう。


```python
"""Where the highest score is 100, and failing is <= 40.
       "F" <= 40
 41 <= "D" <= 55
 56 <= "C" <= 70
 71 <= "B" <= 85
 86 <= "A" <= 100
"""

>>> letter_grades(highest=100)
[41, 56, 71, 86]


"""Where the highest score is 88, and failing is <= 40.
       "F" <= 40
 41 <= "D" <= 52
 53 <= "C" <= 64
 65 <= "B" <= 76
 77 <= "A" <= 88
"""

>>> letter_grades(highest=88)
[41, 53, 65, 77]
```

## 5. 名前と点数の対応付け

試験の点数を降順に並べた配列と、その点数に合わせて降順に並べた学生名の配列があります。
各学生の名前と試験の点数を対応させ、クラス全体の順位を出力したいと考えています。

`student_scores`と`student_names`を引数に持つ`student_ranking(student_scores, student_names)`関数を作成しましょう。
student_namesの`list`に含まれる各学生の名前を、student_scoresの`list`の点数と対応させます。
それぞれの引数の`list`は、点数が高い学生から低い学生の順に並んでいるものとします。
この関数は、`<rank>. <student name>: <student score>`という形式の文字列の`list`を返す必要があります。

```python
>>> student_scores = [100, 99, 90, 84, 66, 53, 47]
>>> student_names =  ['Joci', 'Sara','Kora','Jan','John','Bern', 'Fred']
>>> student_ranking(student_scores, student_names)
...
['1. Joci: 100', '2. Sara: 99', '3. Kora: 90', '4. Jan: 84', '5. John: 66', '6. Bern: 53', '7. Fred: 47']
```

## 6. 「満点」

試験で「満点」の100点を取ることはまれですが、少なくとも1人の学生が達成したかどうかを知るのは興味深いことです。

`student_info`を引数に持つ`perfect_score(student_info)`関数を作成しましょう。
`student_info`は、各学生の名前と点数を含むリストからなる`list`です: `[["Charles", 90], ["Tony", 80]]`。
この関数は、試験で100点を取った学生の_最初の_`[<name>, <score>]`ペアを`return`する必要があります。

`student_info`の中に100点が見つからなかった場合は、空のリスト`[]`を返す必要があります。

```python
>>> perfect_score(student_info=[["Charles", 90], ["Tony", 80], ["Alex", 100]])
["Alex", 100]

>>> perfect_score(student_info=[["Charles", 90], ["Tony", 80]])
[]
```

[round]: https://docs.python.org/3/library/functions.html#round
