# 説明

オンラインのファッションブティックを経営しています。在庫の各商品は2要素の配列`{ name price }`で、在庫全体は商品の配列です。

価格がない場合は`f`として記録されます。

## 1. 在庫を価格で並べ替える

`sort-by-price`を定義し、商品を価格の昇順に並べ替えた新しい配列を返すようにします。

```factor
{ { "Maxi Brown Dress" 65 } { "Red Skirt" 50 } { "Bamboo Socks Cats" 20 } }
sort-by-price .
! => { { "Bamboo Socks Cats" 20 } { "Red Skirt" 50 } { "Maxi Brown Dress" 65 } }
```

## 2. 価格が設定されていない商品を探す

`with-missing-price`を定義し、価格が`f`の商品だけを含む配列を返すようにします。

```factor
{ { "Black T-shirt" 40 } { "Denim Pants" f } { "Orange T-shirt" 40 } }
with-missing-price .
! => { { "Denim Pants" f } }
```

## 3. 高価な商品を数える

`expensive-items`を定義し、在庫と価格のしきい値を受け取って、しきい値を厳密に超える価格の商品がいくつあるかを返すようにします。

```factor
{ { "Skirt" 50 } { "Coat" 120 } { "Hat" 25 } { "Dress" 80 } }
50 expensive-items .
! => 2

{ { "Skirt" 50 } { "Coat" 120 } { "Hat" 25 } { "Dress" 80 } }
0 expensive-items .
! => 4
```

## 4. 最も安い商品を探す

`cheapest-item`を定義し、最も価格の低い商品を返すようにします。価格がない（`f`）商品は入力に現れません。

```factor
{ { "Skirt" 50 } { "Coat" 120 } { "Hat" 25 } } cheapest-item .
! => { "Hat" 25 }
```

## 5. すべての価格を合計する

`total-price`を定義し、すべての価格の合計を返すようにします。価格がない（`f`）商品は入力に現れません。

```factor
{ { "Skirt" 50 } { "Coat" 120 } { "Hat" 25 } } total-price .
! => 195
```

## 6. 商品を値札として整形する

`format-price-tag`を定義し、商品を`"name: $price"`の形式の文字列として返すようにします。価格がない（`f`）商品はここには現れません。

```factor
{ "Skirt" 50 } format-price-tag .
! => "Skirt: $50"
```
