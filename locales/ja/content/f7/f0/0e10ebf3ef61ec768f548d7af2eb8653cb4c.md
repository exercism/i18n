# 概要

[Elixir](https://elixir-lang.org/)は2012年に最初にリリースされた言語で、Erlangがすでに備えていた堅牢な機能をさらに拡張しながら、初心者にとっても親しみやすく、読みやすく、テストしやすく、書きやすい言語です。

Elixirの作者であるJosé Valimは、[2012年のカンファレンスでの講演](https://vimeo.com/53221562)で、どのようなアプリケーションを目指してこの言語を作ったのかを説明しています。

  1. 分散型
  2. 耐障害性
  3. ソフトリアルタイム
  4. ホットコードスワップ（サーバーを止めずに新しいコードを導入できる）

Elixirは実際には[バイトコード](https://en.wikipedia.org/wiki/Bytecode)にコンパイルされ、その後[BEAM Erlang仮想マシン](https://codesync.global/media/robert-virding-co-creator-of-erlang-explains-the-beam/)上で実行されます。

Erlangを呼び出すときの「変換コスト」はかかりません。つまり、Elixirのコードのすぐ隣でErlangのコードを動かせます。

関数型言語であるElixirでは、すべてが式です。

Elixirには「First Class Documentation」という仕組みがあり、関数にコメントを付けられるので、後から取り出しやすくなっています。

正規表現も第一級の扱いを受け、文字列の中でのやっかいなエスケープが不要になります。

Elixirの非同期通信の実装により、コードを軽量に保ちながら、大量の並行処理をこなせます。

プログラマーはElixirを使い、1つのサーバーノード上で*並行して*何千ものリクエストとレスポンスを処理します。

多数のAPIをすばやく利用し、提供する必要があるマイクロサービスで、Elixirはうまく使われてきました。

[Phoenixフレームワーク](https://www.phoenixframework.org/)は、Web向けのElixirアプリケーションを構造化するのに役立ちます。
