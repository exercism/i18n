# はじめに

## JavaScriptの正規表現

[正規表現][mdn-regular-expressions]（Regular Expression、Regexとも呼ばれます）は、文字列の中の特定の要素を対象にして操作するために使える文字の並びです。これを使うと、次のことができます。

- 文字列の中からテキストを**検索**する
- 文字列の中の部分文字列を**置換**する
- 文字列から情報を**抽出**する

> 💡 JavaScriptの正規表現の仕様は、この言語のECMA-262標準の一部です。つまり、ブラウザー固有の互換性を気にする必要はありません。

## 正規表現の作り方

JavaScriptでは、正規表現はおもに`/pattern/modifiers`という形式で書きます。

正規表現を作る方法は2つあります。

1. **正規表現リテラル**:

```javascript
const regex = /[a-z]/;
```

2. **RegExp**コンストラクター:

```javascript
const regex = new RegExp('[a-z]');
```

どちらの場合も、JavaScriptは正規表現からオブジェクトを作ります。基本的には、リテラルを使って不変のパターンを書くのがおすすめです。

`RegExp`コンストラクターは、正規表現が変わるときや、まだ正規表現がわからないとき（たとえば入力から受け取るとき）に使えます。

## 🏴‍☠️ フラグ

正規表現には、追加の機能を使えるようにする[`flags`][mdn-flags]と呼ばれる任意の”超能力”があります。

よく使われるものには、次のようなものがあります。

- `/g` - グローバル検索
- `/i` - 大文字と小文字を区別しない
- `/m` - 複数行検索

簡単な例を見てみましょう。

```javascript
const re = /home/gi;
const str = 'Home, sweet home.';
const myArray = str.match(re);
console.log(myArray);

// => ["Home", "home"]
```

`g`を使うと、文字列の中にある一致をすべて見つけられます。この機能がなければ、JavaScriptは最初に見つかった`Home`だけを抽出します。

大文字と小文字を区別しない`/i`フラグを使うと、パターンを探すときに柔軟に対応できます。探しているものが`UPPERCASE`でも`lowercase`でも関係ありません。

`RegExp`コンストラクターを使う場合、フラグの付け方の構文が変わります。

```javascript
let regex = /[a-z]/gi; // literal notation
let regex = new RegExp('[a-z]', 'gi'); // constructor with string pattern as first argument
let regex = new RegExp(/[a-z]/, 'gi'); // constructor with regular expression literal as first argument (Starting with ECMAScript 6)
```

## よく使う関数

正規表現をJavaScriptの組み込み関数と組み合わせると、文字列を操作したり文字列からデータを取り出したりする強力な方法が使えるようになります。

ここでは、正規表現とともによく使われる関数をいくつか紹介します。

### Test

[test()][mdn-regex-test]]メソッドは、正規表現と指定した文字列の間で一致を検索します。`true`または`false`を返します。

```javascript
const str = 'It is difficult to test if you have a virus';
const result = /virus$/.test(str);

console.log(result);

// => true
```

### Match

[match()][mdn-regex-match]メソッドを使うと、見つかった一致があるかどうかによって内容が変わる、便利な配列が得られます。

こうすると、どんな文字列からでも情報を**検索**することも**抽出**することもできます。たとえば、次のとおりです。

```javascript
const funnyQuote =
  'If you see someone crying, ask if it is because of their haircut.';
const regex1 = /someone/;
const regex2 = /happy/;

funnyQuote.match(regex1);
// => ["someone", index: 3, input: "If you see someone crying, ask if it is because of their haircut.", groups: undefined]

funnyQuote.match(regex2);
// => null
```

グローバル検索の`/g`フラグがある場合、このメソッドは、一致とインデックスや入力などの便利な情報を1つだけ返すのではなく、見つかったすべての出現を配列に並べて返します。

```javascript
const funnyQuote =
  'If you see someone crying, ask if it is because of their haircut.';

const regex3 = /if/gi;

funnyQuote.match(regex3);
// => ["If", "if"];
```

### Replace

JavaScriptの[replace()][mdn-regex-replace]メソッドを使うと、ある文字列の中から値を検索し、それを望む新しい値に置き換えられます。

```javascript
string.replace(searchValue, newValue);
```

置換のために検索するパターンには、1つの文字列か、正規表現を使えます。

```javascript
let string = 'I like dogs!';
let result = string.replace('dogs', 'cats');

let string = 'I would love to travel to Japan';
let result = string.replace(/Japan/g, 'Hawaii');
```

さらに、置換の位置に関数を渡して、それぞれの値に追加の変更を加えることもできます。

```javascript
let text = 'Say hello to the chatbot.';
let result = text.replace(/chatbot|hello/gi, function (word) {
  return word.toUpperCase();
});

// => "Say HELLO to the CHATBOT"
```

### Split

JavaScriptの[split()][mdn-regex-split]メソッドは、正規表現を使って文字列を利用・操作する、また別の方法です。

この方法では、パターンを認識して文字列を分割するために正規表現を使います。たとえば`str.split(/[,.\s]/)`です。このパターンは`separator`として使われます。

```javascript
const str = 'hello,user.how are.you';

const result = str.split(/[,.\s]/);

console.log(result);
// => ['hello', 'user', 'how', 'are', 'you']
```
