# はじめに

## カスタム型

Elmの[カスタム型][custom-types]は、決まった数の名前付きケースを表します。それぞれの値は、その名前付きケースのうちのちょうど1つに対応します。

カスタム型は`type`キーワードを使って定義し、必要な構文はごくわずかです。Elmプログラミングで最も重要なテクニックの1つであり、コード上で取りうる値を現実世界の有効な値と正確に一致させるために使います。そうすることで不正なデータが入り込む余地がなくなり、[ありえない状態をコードで表現できないようにします][impossible-states]。

```elm
type Season
    = Spring
    | Summer
    | Autumn
    | Winter
```

カスタム型の各ケースには、必要に応じてデータを紐付けられます。また、ケースごとに異なる型のデータを持たせられます。どのケースにもデータが紐付いていない場合、この判別共用体は、他の言語で一般に_列挙型_（または_enum_）と呼ばれるものに似ています。

```elm
type FlexibleNumber
    = Integer Int
    | Float Float
    | Invalid
```

特定のケースの値を作るには、その名前（`Spring`）を参照する方法と、完全修飾名（`Season.Spring`）を参照する方法があります。名前で参照できるのは、そのケースが同じモジュールで定義されている場合、または`import SeasonModule exposing (Season(..))`形式の構文でインポートされている場合です。完全修飾名で参照できるのは、`import SeasonModule exposing (Season)`形式の構文でインポートされている場合です。

```elm
integerTwo = Integer 2
invalid = FlexibleNumber.Invalid
```

カスタム型は、Elmのあらゆるものと同様に_構造的等価性_を持ちます。つまり、同じケースで同じ（省略可能な）データを持つ2つの値は等価です。

カスタム型を扱う際に推奨される方法は、[パターンマッチング][pattern-matching]です。

```elm
let describe flexibleNumber =
    case flexibleNumber of
        Integer i ->
            "Integer: " ++ fromInt(i)

        Float f ->
            "Float: " ++ fromFloat(f)

        Invalid   ->
            "Invalid"
```
