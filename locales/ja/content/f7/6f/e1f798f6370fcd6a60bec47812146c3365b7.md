# テスト

テストを実行するには、次の手順に従います。

- 演習のディレクトリに移動します（例：`~/Exercism/hello-world`）。
- ターミナルで`jconsole`のセッションを開始します（例：`jconsole`または`ijconsole`と入力します）。
- 解答ファイルを読み込みます（例：`load 'hello-world.ijs'`）
- `load  'general/unittest'`と入力して、単体テストのフレームワークを読み込みます。
- `unittest 'test.ijs'`と入力して、解答をテストします。
<br></br>
- あるいは、次のように1行でテストを実行することもできます：`jconsole -js "load 'hello-world.ijs'" "echo unittest 'test.ijs'" "exit 0"`。

## スキップされるテスト

最初は、最初のテストだけが有効になっています。
この方法なら、演習を一歩ずつ解き進められます。
各テストには、その定義の上に名詞があり、名前は _'\_ignore'_ で終わります。
テストを実行するには、その値を0に変更します。

### 例：

```
    leap_test_02_ignore=: 1 NB. Change this value to 0 to run this test
    test_leap_test_02  =: monad define
    ...                     NB. test definitions
    )
```
