# はじめに

## 再帰

何かをそれ自身で定義できることを、再帰と呼びます。F#では、再帰は再帰関数でよく見られます。再帰関数とは、自分自身を呼び出す関数のことです。

再帰関数には、少なくとも1つの*ベースケース*と、少なくとも1つの*再帰ケース*が必要です。*ベースケース*は、関数を再び呼び出さずに値を返します。*再帰ケース*は、関数を再び呼び出し、入力に手を加えることで、いずれベースケースに一致するようにします。

再帰関数は通常の関数と同じように定義しますが、`rec`修飾子を付けます。この修飾子を付けないと、関数は自分自身を呼び出すことが*できません*。呼び出そうとすると、コンパイルエラーになります。つまり、再帰を使うには明示的に指定する必要があります。

```fsharp
let rec factorial x =
    // Base case
    if x = 1 then
        1
    // Recursive case
    else
        x * factorial (x - 1)
```

F#では、判別共用体によって再帰的な型もサポートしています。再帰的な判別共用体では、1つ以上のケースが、そのデータの中で判別共用体自身を参照します。再帰関数と同じように、再帰的な型にもベースケースが必要です。再帰関数と違って、再帰的な型では`rec`キーワードは使いません。

```fsharp
type RussianDoll =
    | Doll                 // Base case
    | Layer of RussianDoll // Recursive case
```
