# ヒント

## 全般

- 数値の型を細かく気にする必要はありません。今は`Int32`と`Float64`を使っておきましょう。
- `Int32`と`Float64`はCrystalのデフォルトの数値型なので、指定する必要はありません。

## 1. 温度を摂氏からケルビンに変換する

- 数値を足すには、算術演算子（`+`）を使います。

## 2. 温度を丸める

- `round`メソッドを使うと、数値を指定した小数点以下の桁数に丸めることができます。
- `round`メソッドは、丸める小数点以下の桁数を指定する引数`places`を取ります。

## 3. 温度を摂氏から華氏に変換する

- 数値を掛けるには、算術演算子（`*`）を使います。
- 演算をまとめるには、括弧（`()`）を使います。

## 4. 欠けているセンサーの数を取得する

- 数値を引くには、算術演算子（`-`）を使います。
- 割り算の余りを求めるには、算術演算子（`%`）を使います。
