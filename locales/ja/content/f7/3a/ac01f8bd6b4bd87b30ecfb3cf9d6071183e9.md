# はじめに

C#の[`enum`型](https://docs.microsoft.com/en-us/dotnet/csharp/language-reference/builtin-types/enum)は、名前を付けた定数の固定された集合（列挙）を表します。

通常、`enum`のメンバーは、そうした名前付き定数のうちちょうど1つだけを参照できます。しかし、複数の定数を参照できると便利なこともあります。そのためには、`enum`に[`Flags`属性](https://docs.microsoft.com/en-us/dotnet/api/system.flagsattribute)を付けて指定します。

フラグの`enum`は、次のように定義できます（2進数の整数表記`0b`を使います）。

```csharp
[Flags]
enum PhoneFeatures
{
    Call = 0b00000001,
    Text = 0b00000010
}
```

値が`0b00000011`である`PhoneFeatures`のインスタンスは、`Call`と`Text`の両方のフラグが設定されています。

既定では、`enum`のメンバーの値には`int`型が使われます。`enum`の宣言で型を指定すれば、別の整数型を使うこともできます。

```csharp
[Flags]
enum PhoneFeatures : byte
{
    Call = 0b00000001,
    Text = 0b00000010
}
```
