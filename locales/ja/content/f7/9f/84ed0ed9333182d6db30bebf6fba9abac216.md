# はじめに

状態の一部を、複数のワードの間で共有したいことがあります。そのたびにスタック効果を介して受け渡す必要はありません。Factorの*動的変数*（`SYMBOL:`で宣言します）を使うと、名前空間に格納された値に、どのワードからでもアクセスできます。

```factor
USING: namespaces ;

SYMBOL: counter

0 counter set-global
counter [ 1 + ] change-global
counter get-global .       ! => 1
```

`set-global`と`get-global`は、グローバルな名前空間を扱います。`set`と`get`は、*現在の*動的スコープを扱い、プロセス全体にわたる束縛ではなく、スコープ付きの束縛がほしいときに、`with-variable`ブロックの中で使うのが一般的です。

`SYMBOLS: a b c ;`を使うと、複数のシンボルを一度に宣言できます。
