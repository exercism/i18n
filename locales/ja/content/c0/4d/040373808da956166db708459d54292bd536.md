# はじめに

`if`文のほかに、条件に応じてロジックを実行する`switch`文もあります。これは、1つの変数を複数の値と比較する必要があるときに使います。変数xを例にすると、Haxeの`switch`文は次のような構文です。

```haxe
var a = 2;

switch (a) {
  case 0:
    trace("a is 0");
  case 1:
    trace("a is 1");
  case 2:
    trace("a is 2");
  default:
    trace("a is something else");
}

// a is 2
```

`default`ケースは、ほかのどのケースにも一致しないときに実行されます。
