# 説明

入力テキストが与えられたら、それを転置して出力します。

おおまかに説明すると、次のような行列の転置は、

```text
ABC
DEF
```

次のようになります。

```text
AD
BE
CF
```

行が列になり、列が行になります。詳しくは<https://en.wikipedia.org/wiki/Transpose>を参照してください。

入力の行の長さが異なる場合は、次のように解きます。

- 左側をスペースで埋めます。
- 右側は埋めません。

したがって、この行列を転置すると、

```text
ABC
DE
```

次のようになります。

```text
AD
BE
C
```

また、次を転置すると、

```text
AB
DEF
```

次のようになります。

```text
AD
BE
 F
```

一般に、入力に含まれるすべての文字は、転置された出力にも含まれている必要があります。つまり、入力テキストのある列で、一番下の行がスペースだけになっている場合、対応する出力の行では、一番右の列にスペースが入ります。
