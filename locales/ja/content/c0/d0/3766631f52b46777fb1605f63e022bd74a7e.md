# はじめに

ファイルとは、ディスク上の名前が付いたストリームにすぎません。[`io.files`][io.files]ボキャブラリーには、ファイルを扱う2つの方法があります。1回の呼び出しで全体を読み書きする、ファイル全体を扱うための便利なワードと、少しずつ読み書きしたいときのためのストリームを開くワードです。

ファイルを扱うすべてのワードは、**エンコーディング**を受け取ります。これは、バイトを文字に、文字をバイトに変換する仕組みです。テキストを扱うときは、ほぼ常に`io.encodings.utf8`の`utf8`を使います。

## ファイル全体を読み込む

```
file-contents   ( path encoding -- str )
file-lines      ( path encoding -- seq )
```

`file-contents`はファイル全体を1つの文字列として返し、`file-lines`は改行を取り除いた行の配列を返します。

```factor
USING: io.encodings.utf8 io.files prettyprint ;

"sunny\ncloudy\n" "forecast.txt" utf8 set-file-contents

"forecast.txt" utf8 file-contents .
! => "sunny\ncloudy\n"

"forecast.txt" utf8 file-lines .
! => { "sunny" "cloudy" }
```

## ファイル全体を書き込む

```
set-file-contents   ( str path encoding -- )
set-file-lines      ( seq path encoding -- )
```

どちらもファイルの内容を**置き換えます**（必要ならファイルを作成します）。`set-file-contents`は文字列をそのまま書き込み、`set-file-lines`はシーケンスの各要素をそれぞれの行に書き込み、改行を自動で追加します。

```factor
USING: io.encodings.utf8 io.files prettyprint ;

{ "sunny" "cloudy" } "forecast.txt" utf8 set-file-lines
"forecast.txt" utf8 file-contents .
! => "sunny\ncloudy\n"
```

## ファイルに追記する

すでにある内容を消さずにファイルへ追記するには、`with-…`コンビネーターでファイルを開き、クオテーションの中で現在のストリームに書き込みます。

```
with-file-appender   ( path encoding quot -- )
with-file-reader     ( path encoding quot -- )
with-file-writer     ( path encoding quot -- )
```

```factor
USING: io io.encodings.utf8 io.files prettyprint ;

"sunny\ncloudy\n" "forecast.txt" utf8 set-file-contents
"forecast.txt" utf8 [ "rainy" print ] with-file-appender
"forecast.txt" utf8 file-contents .
! => "sunny\ncloudy\nrainy\n"
```

すべての`with-…`コンビネーターと同様、これらはデストラクタースコープです。クオテーションが終わると、たとえ例外が投げられても、ファイルハンドルは閉じられます。
