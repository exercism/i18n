# テスト

## Clojure CLI

ExercismのClojure演習には、[cognitect-labs test-runner](https://github.com/cognitect-labs/test-runner)を呼び出すための`:test`エイリアスを含む`deps.edn`ファイルが付属しています。

``` bash
$ clj -X:test
```

これは、プロジェクトの`test`ディレクトリを走査して、`clojure.test`を使って定義されたテストを探し出して実行します。

## Leiningen

Leiningenで演習のテストを実行するには、次のように呼び出すだけです。

``` bash
$ lein test

lein test bob-test

Ran 14 tests containing 14 assertions.
0 failures, 0 errors.
```
