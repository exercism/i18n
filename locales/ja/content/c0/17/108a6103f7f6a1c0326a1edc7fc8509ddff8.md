# ヒント

## 全般

- この演習では、[単方向連結リスト][singly linked list]を使って[_スタック_][Baeldung: The Stack Data Structure]を作ります。
- `lists`や`collections.deque`、`queue.LifoQueue`を土台にしたスタックとは違い、ここでは要素を保存してつなぐために、独自の`Node`と`LinkedList`の[`classes`][classes tutorial]を作ります。

![連結リストで実装したスタックを表す図。破線の枠で囲まれたNew_Nodeという円が左端にあり、右向きに伸びる2本の点線の矢印があります。New_Nodeには「(becomes head) - New_Node - next = node_6」と書かれています。上の点線の矢印には「push」というラベルが付き、右上のNode_6を指しています。Node_6には「(current) head - Node_6 - next = node_5」と書かれています。下の点線の矢印には「pop」というラベルが付き、「gets removed on pop()」と書かれた箱を指しています。Node_6からは実線の矢印が右向きに伸び、Node_5を指しています。Node_5には「Node_5 - next = node_4」と書かれています。Node_5からは実線の矢印が右向きに伸び、Node_4を指しています。Node_4には「Node_4 - next = node_3」と書かれています。このパターンはNode_1まで続き、Node_1には「(current) tail - Node_1 - next = None」と書かれています。Node_1からは点線の矢印が右向きに伸び、「None」と書かれたノードを指しています。](https://assets.exercism.org/images/tracks/python/simple-linked-list/linked-list.svg)

- 実装の詳細を確認するには、[Real Python: Linked Lists][Real Python Linked Lists]、[Towards Data Science: Demystifying the Linked List][towards data science demystifying the linked list]、[ADS Stack in Python][Koder Dojo Coding an ADS Stack in Python]が役立ちます。
- `LinkedList`は、_コンストラクター_で`list`引数を受け取りますが、ノードや要素の保存に`list`を使ってはいけません。
- `len()`は、ほとんどのPythonオブジェクトに備わっている組み込み関数です。_カスタムオブジェクト_が`len()`をサポートするには、特殊メソッド[`__len__`][__len__]を定義する必要があります。
- Pythonでは、ほとんどのシーケンス型・コンテナ型・コレクション型のオブジェクトで繰り返しをサポートしています。_カスタム_オブジェクトがループや並べ替えをサポートするには、特殊メソッド`__iter__`を定義する必要があります。[クラスにイテレーターを実装する][implementing iterators]と、その方法がわかります。
