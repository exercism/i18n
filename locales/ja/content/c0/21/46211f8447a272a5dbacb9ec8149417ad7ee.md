# はじめに

Cairoは、コアライブラリの一部として、`Felt252Dict<T>`型で表される辞書を提供しています。

Cairoでは辞書のキーの型は`felt252`に限られており、キーの型を定義できる他の言語とは異なります。

辞書を作成するには、`Default`トレイトの`default`メソッドを次のように使います。

```rust
let mut foo: Felt252Dict<u32> = Default::default();
```

よく使われる基本的な操作は、次の2つです。

1. `insert(felt252, T) -> ()`は、辞書インスタンスに値を書き込みます。
2. `get(felt252) -> T`は、値を読み取ります。

これらの操作は、次のように使います。

```rust
let mut foo: Felt252Dict<u32> = Default::default();
// Add a value to the dictionariy
foo.insert('bar', 42);
// Here we update the element of 'bar'
foo.insert('bar', 73);
// To retrieve a dictionary value, you can use
baz = foo.get('bar');
```

辞書に存在しないキーの値を取り出そうとすると、その値の型のゼロ値が返ります。

これは混乱を招くことがあります。とくに、値の型のデフォルト値（例えば整数なら0）が有効な値である場合はなおさらです。

これはまた、辞書からデータを削除する方法がないということも意味します。

この構造をコードに取り入れるときは、この点を覚えておきましょう。
