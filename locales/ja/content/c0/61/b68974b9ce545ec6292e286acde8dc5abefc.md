# はじめに

構造体やクラスのインスタンスには、それぞれ`self`という名前の暗黙のプロパティがあります。これはそのインスタンス自身を指します。
`self`は、インスタンスのプロパティと、同じ名前の仮引数を区別するためによく使われます：

```swift
struct Position {
    var x = 0

    mutating func move(x: Int) {
        // Here, 'self.x' refers to the struct's property,
        // while 'x' refers to the parameter passed to the method.
        self.x = x
    }
}
```

Swiftの型には、先頭を大文字にした`Self`というキーワードもあります。これはインスタンス自身ではなく、そのインスタンスの*型*を指します。
