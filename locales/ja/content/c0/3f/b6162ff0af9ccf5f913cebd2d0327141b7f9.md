# 指示

この演習では、お気に入りの料理本に載っている絶品ラザニア作りに役立つコードを書いていきます。

ラザニアの調理にかかる時間に関する、4つのタスクがあります。

## 1. 想定されるオーブン時間を分単位で定義する

`expected_minutes_in_oven`という束縛を定義して、ラザニアをオーブンに入れておくべき時間が何分なのかを確認できるようにします。
料理本によると、想定されるオーブン時間は40分です。

```rust
expected_minutes_in_oven()
// Returns: 40
```

## 2. 残りのオーブン時間を分単位で計算する

`remaining_minutes_in_oven`関数を定義します。この関数は、ラザニアを実際にオーブンに入れておいた分数を入力として受け取り、前のタスクで求めた想定オーブン時間をもとに、ラザニアをあと何分オーブンに入れておく必要があるかを返します。

```rust
remaining_minutes_in_oven(30)
// Returns: 10
```

## 3. 準備にかかる時間を分単位で計算する

`preparation_time_in_minutes`関数を定義します。この関数は、ラザニアに重ねた層の数を入力として受け取り、1層あたり2分かかると仮定して、ラザニアの準備に何分かかったかを返します。

```rust
preparation_time_in_minutes(2)
// Returns: 4
```

## 4. 経過時間を分単位で計算する

`elapsed_time_in_minutes`関数を定義します。この関数は2つの入力を受け取ります。1つ目はラザニアに重ねた層の数、2つ目はラザニアをオーブンに入れておいた分数です。この関数は、ラザニアの調理に何分取り組んだかを返します。これは、準備にかかった分数と、その時点でラザニアがオーブンにあった分数を足したものです。

```rust
elapsed_time_in_minutes(3, 20)
// Returns: 26
```
