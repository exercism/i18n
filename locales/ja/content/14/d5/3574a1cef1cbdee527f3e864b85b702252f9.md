# はじめに

## 配列

配列はElixirに組み込まれた基本型のひとつで、角括弧（`[]`）で表します。空の配列も作れますし、どんな型の要素でも好きなだけ入れることもできます。たとえば：

```elixir
empty_list = []
one_item_list = [1]
two_item_list = [1, 2]
multiple_type_list = [1, :pi, 3.14, "four"]
```

Elixirは配列を連結リストとして実装しています。各ノードは、先頭の要素と、残りのすべての要素を含む別の配列という2つの値を保持します。配列の最初の要素を_先頭_、残りの要素の並びを_末尾_と呼びます。この表記はコードの中でも使えます：

```elixir
# [1] represented in [head | tail] notation
[1 | []]

# [1, 2, 3] represented in [head | tail] notation
[1 | [2 | [3 | []]]]
```

_`[head | tail]`_という表記を使うと、配列の先頭に要素を追加できます：

```elixir
# Suppose
list = [2, 1]

[3, 2, 1] == [3 | list]
# => true
```

配列を扱うための関数は`Kernel`モジュールにもいくつかありますが、`List`モジュールにはそれらがひととおり揃っています。

```elixir
# Check if 1 is a member of the list
1 in [1, 2, 3, 4]
# => true
```
