# はじめに

Haxeでは、`class`は主要なデータ構造であり、データ（フィールド）と振る舞い（メソッド）をまとめたものです。フィールドとメソッドは、クラスのメンバーとも呼ばれます。

メンバーへのアクセスは、アクセス修飾子で制限できます。アクセス修飾子には次のものがあります。

- `public`: どこからでもメンバーにアクセスできます。
- `private`: 同じクラスからしかメンバーにアクセスできません。

クラスは、インスタンスを作るためのテンプレートと考えることができます。インスタンスを作るには、`new`キーワードを使うだけです。

```haxe
class Car {
  public function new() {}
}

var myCar = new Car();
var yourCar = new Car();
```

フィールドを定義するには、アクセス修飾子のあとに変数名と型を書きます。

```haxe
class Car {
  public var weight:Int; // Accessable by anyone

  private var color:String; // Accessable only within this class
}
```

フィールドを定義するときに、初期値を設定することもできます。初期値を指定しないフィールドには、`null`という値が入ります。フィールドには、ドット記法でアクセスできます。

```haxe
class Car {
  public var weight:Int = 2500; // Weight will be set to 2500
  public var year:Int; // year will be null

  public function new() {}
}

var newCar = new Car();
newCar.weight; // 2500
newCar.year; // null

// Update value of field
newCar.year = 2020;
```
