# 燃料手当

## 問題文

ABC社の従業員は全員、無制限の燃料手当を受け取ります。従業員は、車に給油するたびに記録を送信する必要があります。これらの記録は同じCSVファイルに追記され、月末に処理されます。

デジタルオペレーションチームの一員として、このCSVファイルを読み込み、その結果を別のCSVファイルに書き出すのが仕事です。出力ファイルには、各従業員ごとに次の詳細を含むエントリが必要です。

- 従業員番号
- 給油回数
- 燃料費の合計
- 合計ガロン数
- 累計走行距離

`string`型の引数が2つ与えられます。

1. 入力CSVファイルのパス
1. 出力CSVファイルのパス

入力CSVファイルには`n`行あり、各行は次の形式です。

| 列名      | Ballerinaの型 |
| ----------- | ----------- |
| employee_id      | `int`       |
| odometer_reading   | `int`       |
| gallons   | `decimal` |
| gas_price(USD)  |`decimal`|

出力ファイルには、`employee_id`の昇順で並べた各従業員のエントリが必要です。各行は次の形式です。

| 列名      | Ballerinaの型 |
| ----------- | ----------- |
| employee_id      | `int`       |
| gas_fill_up_count   | `int`        |
| total_fuel_cost(USD)   | `decimal` |
| total_gallons  |`decimal`|
| total_miles_accrued  |`int`|

## 制約

- 入力CSVファイルの行数`n`:  2 <= n <= 1000
- 会社の従業員数: 97
- ガソリン価格は1ガロンあたり
- 給油記録の欠落はない

## 例1

- 入力: `example01_input.csv`

```csv
2312,230,18.561,4.56
2312,500,19.345,4.89
```

- 出力: `example01_output.csv`

```csv
2312,2,179.23521,37.906,270
```

## ヒント

- CSVファイルの読み書きには[`ballerina/io`モジュール](https://lib.ballerina.io/ballerina/io/latest)を使います
- 入力ファイルと出力ファイルにはヘッダーが含まれません（含めるべきではありません）
- [Ballerinaのテーブル構文](https://ballerina.io/learn/by-example/table)
