# 指示

ニコマコス（西暦60年〜120年）が正の整数に対して考案した分類法に基づいて、ある数がperfect、abundant、deficientのどれにあたるのかを判定します。

ギリシャの数学者[ニコマコス](https://en.wikipedia.org/wiki/Nicomachus)は、正の整数を分類する方法を考案しました。これは、それぞれの数が[アリコット和](https://en.wikipedia.org/wiki/Aliquot_sum)に基づいて、**perfect**、**abundant**、**deficient**のいずれか1つだけに属すると見なすものです。

アリコット和は、その数自身を含めない約数すべての合計として定義されます。たとえば、15のアリコット和は(1 + 3 + 5) = 9です。

- **Perfect**: アリコット和 = その数
  - 6は(1 + 2 + 3) = 6なので完全数です
  - 28は(1 + 2 + 4 + 7 + 14) = 28なので完全数です
- **Abundant**: アリコット和 > その数
  - 12は(1 + 2 + 3 + 4 + 6) = 16なので過剰数です
  - 24は(1 + 2 + 3 + 4 + 6 + 8 + 12) = 36なので過剰数です
- **Deficient**: アリコット和 < その数
  - 8は(1 + 2 + 4) = 7なので不足数です
  - 素数は不足数です

与えられた数が**perfect**かどうかを判定する方法を実装してください。言語トラックによっては、与えられた数が**abundant**か**deficient**かも判定する方法を実装する必要があるかもしれません。
