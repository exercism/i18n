# 説明

暗号ホイールは、2枚の円盤を重ねたもので、アルファベットを回転させます。3に合わせると、すべての文字が3つ先の文字になり、`z`は`a`に戻ります。探偵たちは何世紀にもわたってこれを使ってきました。ここでは、それを自分で作ってみましょう。

5つのタスクはすべて`CIPHER_WHEEL`クラスに書きます。

## 1. 文字かどうかを判定する

```sather
CIPHER_WHEEL::is_letter('m')
-- => true
CIPHER_WHEEL::is_letter('7')
-- => false
```

## 2. 大文字にする

受け取った文字を大文字にして返します。文字以外のものはそのまま返します。

```sather
CIPHER_WHEEL::shout('m')
-- => 'M'
```

## 3. どんな数値か

文字を表す数値を返します。

```sather
CIPHER_WHEEL::code('a')
-- => 97
```

## 4. 最初の文字

文字列の最初の文字を返します。

```sather
CIPHER_WHEEL::first_character("Marlowe")
-- => 'M'
```

## 5. ホイールを回す

小文字と移動する位置の数を受け取り、アルファベットをその数だけ進めた文字を返します。`z`を超えると`a`に戻ります。

```sather
CIPHER_WHEEL::turn('a', 3)
-- => 'd'
CIPHER_WHEEL::turn('z', 1)
-- => 'a'
```

負の数を使えば、逆方向に回すこともできます。

```sather
CIPHER_WHEEL::turn('a', -1)
-- => 'z'
```

渡される文字は小文字であると仮定してかまいません。
