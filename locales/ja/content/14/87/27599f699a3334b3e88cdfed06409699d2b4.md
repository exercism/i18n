# 手順

Isaac's Asteroid Exploration Co.の権利申請部門から、土地の権利申請システムの性能を改善するよう依頼されました。

小惑星の採掘が可能になるたびに、投機家たちは土地の区画を申請するよう招かれます。
小惑星の土地は、重なりのない長方形の区画に分けられています。
区画の大きさはそれぞれ異なりますが、どの辺も座標軸に平行です。
投機家は座標を指定して、区画の1つを申請します。

目標は、かつてウェブサイトをクラッシュさせた土地の争奪戦に対応できる、高性能なシステムを開発することです。

測定の単位は100メートルですが、この課題では無視してかまいません。

## 1. Pointを定義する

`x`座標と`y`座標を保持する`struct`を定義します。
これらはかなり小さな非負の整数なので、`UInt16`型を使います。

```julia-repl
julia> Coord(7, 3)
Coord(0x0007, 0x0003)  # unsigned integers display in hex format by default
```

## 2. Plotを定義する

すべての区画は辺が水平と垂直の長方形でなければならないため、定義には対角にある2つの角だけで十分です。

`Plot`構造体を実装します。コンストラクターでは2つのCoord構造体を受け取ります。

`Plot`はキーワード構造体とし、フィールドは`bottom_left`と`top_right`にします。

```julia-repl
julia> plot = Plot(bottom_left=Coord(10, 1), top_right=Coord(20, 2))
Plot(Coord(0x000a, 0x0001), Coord(0x0014, 0x0002))

julia> plot.top_right
Coord(0x0014, 0x0002)
```

## 3. 申請がすでに登録されているか確認する

これらの申請は競争になるため、申請が認められる前に、登録簿にある既存の申請と照合されます。

`is_claim_staked()`関数を実装し、申請がすでに登録されているかどうかを判定します。

```julia-repl
julia> claim = Plot(bottom_left=Coord(10, 1), top_right=Coord(20, 2));
julia> register = Set{Plot}();
julia> is_claim_staked(claim, register)
false
```

## 4. 投機家が角の座標で特定される区画を指定して申請できるようにする

`stake_claim!()`という破壊的な関数を実装し、申請を登録できるようにします。

同じ申請がすでに登録されている場合は、`false`を返します。

新しい申請が可能なら、登録簿に追加して`true`を返します。

```julia_repl
julia> claim = Plot(bottom_left=Coord(10, 1), top_right=Coord(20, 2));
julia> register = Set{Plot}();
julia> stake_claim!(claim, register)
true
```

## 5. 区画の長いほうの辺の長さを求める

`get_longest_side()`関数を実装し、申請の長いほうの辺（水平または垂直）を取得します。

```julia-repl
claim = Plot(bottom_left=Coord(10, 1), top_right=Coord(20, 2));

julia> get_longest_side(claim)
0x000a
```

## 6. 研究目的で、最も長い辺を持つ申請済みの区画を見つける

`get_claim_with_longest_side()`関数を実装し、登録されているすべての申請を調べて、最も長い辺を持つ申請を返します。

```julia-repl
julia> plot1 = Plot(bottom_left=Coord(5, 3), top_right=Coord(10, 5));
julia> plot2 = Plot(bottom_left=Coord(0, 0), top_right=Coord(3, 3));
julia> register = Set{Plot}([plot1, plot2]);

julia> get_claim_with_longest_side(register)
Plot(Coord(0x0005, 0x0003), Coord(0x000a, 0x0005))
```

Plotを`Set`として返します。最も長い区画が1つだけなら要素は1つ、同点の場合は複数になります。
