# 概要

文字列はテキストデータを表します。
Swiftの[`String`][strings-and-characters]は、`Character`値が順序どおりに並んだコレクションで、各`Character`は1つのUnicode文字を表します。

文字列を作るには、文字列リテラルを使います。文字列リテラルとは、二重引用符（`"`）で囲んだ文字の並びのことです。
複数行にわたる文字列には、二重引用符を3つ（`"""`）使います：

```swift
let hello: String = "Hello, World!"

let poem: String = """
Roses are red,
Violets are blue.
Sugar is sweet,
And so are you.
"""
```

Swiftの文字列は、Foundationフレームワークの[`NSString`][nsstring-docs]クラスとシームレスに連携し、豊富なテキスト処理機能を利用できます。

## 文字

`Character`は1つの拡張書記素クラスタを表します。拡張書記素クラスタとは、1つ以上の[Unicodeスカラー値][unicode-scalar-values]からなる、人間が読める1文字のことです。
Unicodeスカラー値とは、`U+0000`から`U+D7FF`まで、または`U+E000`から`U+10FFFF`までの範囲にある21ビットのコードポイントです。

```swift
let aChar: Character = "A"
```

## 型推論

文字列リテラルを書くと、Swiftが自動的にその型を`String`と推論します。
1文字を`Character`として格納するには、型注釈を明示する必要があります：

```swift
let aString = "A"        // Inferred as String
let aChar: Character = "A" // Explicitly typed as Character
print(type(of: aString)) // Prints String
print(type(of: aChar))   // Prints Character

// The following code will not compile:
let badChar: Character = "Too many characters"
// Error: Cannot convert value of type 'String' to specified type 'Character'
```

## 連結

文字列は、加算演算子（`+`）を使って連結できます：

```swift
print("honey" + "comb")
// Prints "honeycomb"
```

`Character`を先に文字列に変換しないと、`+`で`String`に直接連結することはできません。
ただし、[`append(_:)`][append]メソッドを使えば、文字列や文字を可変の文字列に直接追加できます：

```swift
var greeting = "Hello"
let world = ", world"
let period: Character = "."

greeting.append(world)
print(greeting) // Prints "Hello, world"

greeting.append(period)
print(greeting) // Prints "Hello, world."
```

## 文字列補間

[文字列補間][string-interpolation]を使うと、定数・変数・リテラル・式を文字列リテラルの中に埋め込んで、文字列を組み立てられます。
各式は、バックスラッシュを前に付けた括弧（`\(` ... `)`）で囲みます：

```swift
let radius = 5.0
let circle = "The area of a circle with radius \(radius) is \(Double.pi * radius * radius)"
print(circle) // Prints "The area of a circle with radius 5.0 is 78.53981633974483"
```

## 文字列と文字のプロパティ

文字列と文字には、内容を調べるためのプロパティがいくつか用意されています。

### 文字列のプロパティ

よく使う文字列のプロパティには、次のようなものがあります：

| プロパティ | 説明                                           | 例                                     |
| --------- | ---------------------------------------------- | -------------------------------------- |
| `isEmpty` | 文字列が空の場合に`true`を返します              | `"Hello".isEmpty`は`false`と評価されます |
| `count`   | 文字列の文字数を返します                        | `"Hello".count`は`5`と評価されます       |

プロパティの完全な一覧は、[AppleのStringドキュメント][string-docs]を参照してください。

### 文字のプロパティ

よく使う文字のプロパティには、次のようなものがあります：

| プロパティ      | 説明                                          | 例                                    |
| -------------- | --------------------------------------------- | ------------------------------------- |
| `isLowercase`  | 文字が小文字の場合に`true`を返します            | `"a".isLowercase`は`true`と評価されます |
| `isUppercase`  | 文字が大文字の場合に`true`を返します            | `"A".isUppercase`は`true`と評価されます |
| `isNumber`     | 文字が数字の場合に`true`を返します              | `"1".isNumber`は`true`と評価されます    |
| `isWhitespace` | 文字が空白の場合に`true`を返します              | `" ".isWhitespace`は`true`と評価されます|

プロパティの完全な一覧は、[AppleのCharacterドキュメント][character-docs]を参照してください。

## 型変換

`String(_:)`イニシャライザーを使うと、ほかの型を文字列に変換できます。`Int`や`Double`、`Character`などの標準的な型に対応しています：

```swift
let charX: Character = "x"
print(String(charX))     // Prints "x"
print(String(110))       // Prints "110"
print(String(Double.pi)) // Prints "3.141592653589793"
```

## 特殊文字

Swiftの文字列リテラルでは、特殊文字を表すための[エスケープシーケンス][special-characters]をいくつか使えます：

| シーケンス | 説明                          |
| ---------- | ----------------------------- |
| `\0`       | ヌル文字                      |
| `\\`       | バックスラッシュ              |
| `\t`       | 水平タブ                      |
| `\n`       | ラインフィード（改行）        |
| `\r`       | 復帰（キャリッジリターン）    |
| `\'`       | 一重引用符                    |
| `\"`       | 二重引用符                    |
| `\u{n}`    | 任意のUnicodeスカラー値（16進数） |

```swift
let quote: String = "\"Hello\", he said."
print(quote) // Prints "Hello", he said.

let unicode: Character = "\u{1F496}"
print(unicode) // Prints 💖
```
