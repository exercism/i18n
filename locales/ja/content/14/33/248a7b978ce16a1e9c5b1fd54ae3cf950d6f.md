# インストール

このトラックではReScript 12を使い、[Node.js][nodejs] 22以降が必要です。
多くのシステムには最初からインストールされているか、別のトラックで以前にインストールしたことがあるかもしれません。

ターミナルを開いて、次を実行してみましょう。

```sh
node -v
```

Nodeがインストールされていない場合や、古いバージョンが表示される場合は、お使いのプラットフォーム向けの[Node.js公式のインストール手順][nodejs-install]に従ってください。

## 依存関係のインストール

それぞれのReScriptの演習は、独立したnpmプロジェクトです。
[Exercism CLI][exercism-cli]で演習をダウンロードしたら、ReScriptを含むプロジェクトの依存関係をインストールすれば、準備は完了です。

```sh
cd /path/to/exercise
npm install
```

## エディターのサポート

ReScriptプロジェクトは、[公式およびコミュニティによるエディタープラグインのリスト][rescript-plugins]を管理しています。
