# 説明

イジーは熱心な野鳥観察者で、ある日の庭に何羽の鳥が訪れたかを記録しています。

彼女は、野鳥観察をさらに楽しむために、データの記録と処理に役立つツールをいくつか作ってほしいと頼んできました。

データは整数の配列として保存することにしました。配列の最初の数値は今日庭に訪れた鳥の数、2番目は昨日の数、以下同様です。

## 1. 今日訪れた鳥の数を確認する

`today`関数を実装してください。日ごとの鳥の数の配列を受け取り、今日の数を返します。配列が空の場合は`0`を返します。

```gleam
today([2, 5, 1])
// -> 2
```

## 2. 今日の数を増やす

`increment_day_count`関数を実装してください。日ごとの鳥の数の配列を受け取り、今日の数を1増やします。配列が空の場合は`[1]`を返します。

```gleam
increment_day_count([4, 0, 2])
// -> [5, 0, 2]
```

## 3. 鳥が1羽も訪れなかった日があったかどうかを確認する

`has_day_without_birds`関数を実装してください。日ごとの鳥の数の配列を受け取ります。庭に鳥が1羽も訪れなかった日が少なくとも1日あった場合は`True`を、そうでない場合は`False`を返します。配列が空の場合、これはまだ鳥が記録されていないものとみなします。`False`を返します。

```gleam
has_day_without_birds([2, 0, 4])
// -> True

has_day_without_birds([3, 8, 1, 5])
// -> False
```

## 4. 訪れた鳥の合計数を計算する

`total`関数を実装してください。日ごとの鳥の数の配列を受け取り、データの収集を始めてから庭に訪れた鳥の合計数を返します。

```gleam
total([4, 0, 9, 0, 5])
// -> 18
```

## 5. 忙しい日の数を計算する

日によって忙しさは違います。忙しい日とは、庭に5羽以上の鳥が訪れた日のことです。

`busy_days`関数を実装してください。日ごとの鳥の数の配列を受け取り、忙しい日の数を返します。

```gleam
busy_days([4, 5, 0, 0, 6])
// -> 2
```
