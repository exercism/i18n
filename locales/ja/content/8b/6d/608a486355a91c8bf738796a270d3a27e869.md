# テスト


ウェブサイトのテストランナーには、[pytest][pytest: Getting Started Guide]を使っています。
Pythonトラックのテストをローカルで実行するには、開発用のマシンに`pytest`をインストールする必要があります。
次の`pytest`プラグインもインストールしておきましょう。

- [pytest-cache][pytest-cache]
- [pytest-subtests][pytest-subtests]

詳しい情報は、ウェブサイトの[Pythonのテストガイド][Python track tests page]にあります。


### テストの実行

付属のテストを実行するには、ターミナルで`cd`を使って、演習が保存されているフォルダーに移動します（_以下の`<exercise-folder-location>`はご自身のパスに置き換えてください_）。
テストファイルの名前は通常`_test.py`で終わり、解答をアップロードしたときにウェブサイト上で実行されるテストと同じものです。

Linux/MacOS
```bash
$ cd <path/to/exercise-folder-location>
```

Windows
```powershell
PS C:\Users\foobar> cd <path\to\exercise-folder-location>
```

<br>

次に、ターミナルで`pytest`コマンドを実行します。`<exercise_test.py>`はテストファイルの名前に置き換えてください：

Linux/MacOS
```bash
$ python3 -m pytest -o markers=task <exercise_test.py>
==================== 7 passed in 0.08s ====================
```

Windows
```powershell
PS C:\Users\foobar> py -m pytest -o markers=task <exercise_test.py>
==================== 7 passed in 0.08s ====================
```


### よく使うオプション
- `-o`：デフォルトの`pytest.ini`を上書きします（_マーカーに関する警告を避けたいときに使えます_）
- `-v`：詳細な出力を有効にします。
- `-x`：最初の失敗でテストの実行を停止します。
- `--ff`：前回失敗したテストを、他のテストケースより先に実行します。

その他のオプションについては、`python3 -m pytest -h`または`py -m pytest -h`を使ってください。


### 警告を修正する

`pytest`を実行するときに`pytest -o markers=task`を付けないと、新しい構文を使ったテストで`PytestUnknownMarkWarning`が出ることがあります。

```bash
PytestUnknownMarkWarning: Unknown pytest.mark.task - is this a typo?  You can register custom marks to avoid this warning - for details, see https://docs.pytest.org/en/stable/mark.html
```

テストを実行するたびに`pytest -o markers=task`と入力するのを避けるには、`pytest.ini`設定ファイルを使う方法があります。
Pythonトラックのディレクトリの最上位からダウンロードできるものを用意しています。[pytest.ini][pytest.ini]

次の内容で、自分専用の`pytest.ini`ファイルを作ることもできます。

```ini
[pytest]
markers =
    task: A concept exercise task.
```

`pytest.ini`ファイルを、Pythonトラックの演習の_ルート_ディレクトリまたは_作業_ディレクトリに置くと、マークが登録され、警告が出なくなります。
pytestのマークについての詳しい情報は、`pytest`ドキュメントの[テスト関数にマークを付ける][pytest: marking test functions with attributes]と、`pytest`ドキュメントの[カスタムマーカーを使う][pytest: working with custom markers]にあります。

pytestの設定をカスタマイズする方法については、`pytest`ドキュメントの[設定ファイルの形式][pytest: configuration file formats]にあります。
