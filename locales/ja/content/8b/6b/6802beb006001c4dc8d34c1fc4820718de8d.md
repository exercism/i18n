# 説明

この演習では、パスワードチェッカーを作成します。
パスワードチェッカーは、ユーザーが設定しようとしているパスワードを検証し、対象のリソースへのアクセスを管理する組織が定めた一連の要件を満たしていることを確認します。

この演習では、パスワードの要件は次のとおりです。
* 12文字以上であること
* 大文字を1文字以上含むこと
* 小文字を1文字以上含むこと
* 数字を1文字以上含むこと
* 記号（!@#$%^&*）のうち少なくとも1文字を含むこと

解答では、成功か失敗かの状態を`Result`で表す必要があります。
成功の場合、`Result`は検証済みのパスワードを文字列として伝える必要があります。
失敗の場合、`Result`は違反したルールを伝える必要があります。

~~~~exercism/note
この演習のパスワードチェッカーは簡易的なものです。違反したルールが1つだけの場合にのみ示します。
後続の演習では、複数のルールに同時に違反した場合を示せる、より現実的なパスワードチェッカーを扱います。
~~~~

## 1. `checkPassword`関数を実装してください

`checkPassword`関数は、与えられたパスワードを前述のルールに照らしてチェックします。失敗した場合は、`PasswordRule`の値のいずれかを結果の値に含めることで、違反したルールを示します。

```fsharp
checkPassword "abcdefghij5#"
// => Error MissingUppercaseLetter
```

## 2. ``getStatusMessage`関数を実装してください

`getStatusMessage`関数は、`checkPassword`から返された結果の意味を示す、人間が読めるメッセージを含む文字列を返します。

```fsharp
getStatusMessage (Error MissingDigit)
// => "Error: does not have at least one digit"
```
