# はじめに

フィルタリングとは、あるシーケンスから別のシーケンスを作る操作で、元のシーケンスの要素のうち一部を除いたものをコピーします。
新しいシーケンスにどの要素を含めるかは、述語関数（真偽値に評価される関数）によって決めることもできますし、特定のオブジェクトとの等価性によって決めることもできます。

## 述語による取り除き

`remove-if`は、述語関数とシーケンスを引数に取り、述語が偽と評価した要素だけからなるシーケンスを返す関数です。
言い換えると、述語が真と評価するシーケンスの要素をすべて「取り除く」わけです。ただし、この関数は元のシーケンスを変更しないことに注意してください！
代わりに、該当する要素を含まない新しいシーケンスを返します。すべての値に対して述語が真だった場合は、空のシーケンスが返されます。

```lisp
(remove-if #'evenp '(1 2 3 4 5)) ; => (1 3 5)
(remove-if #'oddp '(1 3 5))      ; => ()
```

## 特定の要素を取り除く

シーケンスから特定の要素を取り除きたいときは、`remove`を使います。これは取り除きたい要素とシーケンスを引数に取ります。
シーケンスの中で、取り除く要素と等しくない値がすべて返されます。
注意：等価性の判定には、デフォルトで`eql`という[汎用等価述語][concept-equality]が使われます。

```lisp
(remove 1 '(1 2 1 3 1 4)) ; => (2 3 4)
(remove #\l "hello")      ; => "heo"
```
