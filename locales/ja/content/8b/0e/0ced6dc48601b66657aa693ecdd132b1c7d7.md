# 説明

現在、高い評価を得ている新作ゲーム**Crystal Hunter**を開発しているところです。
ゲームでは、動き回ってクリスタルを集めるキャラクターを操作します。
プレイヤーは、すべてのクリスタルを拾い集めると勝利します。
プレイヤーが盗賊に接触すると、持っているクリスタルをすべて失い、ゲームにも敗北します。
ただし例外があります。プレイヤーは、盗賊から姿が見えなくなるパワーアップを有効にすることができます。

ここでの目標は、ゲームで使われるいくつかのルールを書くことです。

## 1. キャラクターがボーナスポイントを獲得するかどうかを定義する

ゲームでは、パワーアップを有効にしている状態で盗賊に触れると、キャラクターはボーナスポイントを獲得します。

`Rules#bonus_points?`メソッドを定義します。このメソッドは2つの引数（_キャラクターがパワーアップを有効にしているか_、_キャラクターが盗賊に触れているか_）を取り、キャラクターがボーナスポイントを獲得するかどうかを示す真偽値を返します。
このメソッドは、キャラクターがパワーアップを有効にしていて、かつ盗賊に触れている場合にのみ`true`を返し、それ以外の場合は`false`を返す必要があります。

```Crystal
Rules.new.bonus_points?(false, true)
# => false
```

## 2. キャラクターが得点するかどうかを定義する

ゲームでは、プレイヤーはクリスタルかパワーアップを拾うとポイントを獲得します。

`Rules#score?`メソッドを定義します。このメソッドは2つの引数（_キャラクターがパワーアップに触れているか_、_キャラクターがクリスタルに触れているか_）を取り、キャラクターが得点したかどうかを示す真偽値を返します。
このメソッドは、キャラクターがパワーアップまたはクリスタルに触れた場合に`true`を返し、それ以外の場合は`false`を返す必要があります。

```crystal
Rules.new.score?(true, true)
# => true
```

## 3. キャラクターが負けるかどうかを定義する

`Rules#lose?`メソッドを定義します。このメソッドは2つの引数（_キャラクターがパワーアップを有効にしているか_、_キャラクターが盗賊に触れているか_）を取り、キャラクターが負けるかどうかを示す真偽値を返します。
このメソッドは、キャラクターが盗賊に触れていて、かつパワーアップを有効にしていない場合に`true`を返し、それ以外の場合は`false`を返す必要があります。

```crystal
Rules.new.lose?(false, true)
# => true
```

## 4. キャラクターが勝つかどうかを定義する

`Rules#win?`メソッドを定義します。このメソッドは3つの引数（_キャラクターがすべてのクリスタルを拾い集めたか_、_キャラクターがパワーアップを有効にしているか_、_キャラクターが盗賊に触れているか_）を取り、キャラクターが勝つかどうかを示す真偽値を返します。
このメソッドは、キャラクターがすべてのクリスタルを集めていて、かつ3番で定義した引数に基づいて負けていない場合に`true`を返し、それ以外の場合は`false`を返す必要があります。

```crystal
Rules.new.win?(false, true, false)
# => false
```
