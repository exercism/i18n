# はじめに

## 外部関数

Gleamは、Erlang仮想マシン（BEAM）でも、JavaScriptランタイムでも動かせます。これらのランタイムを使う言語はほかにもたくさんあり、そうした言語で書かれたコードをGleamから呼び出せると便利なことがよくあります。

Gleamの_外部関数_という機能を使うと、ほかの言語の関数をGleamにインポートして、実行時のオーバーヘッドなしで呼び出せます。

GleamプロジェクトがErlang仮想マシン上で動いていて、Erlangの`lists`モジュールの`reverse`関数を呼び出したい場合は、次のようにGleamの関数ヘッドに`@external`属性を付けると呼び出せます。

```gleam
@external(erlang, "lists", "reverse")
pub fn reverse_list(x: List(a)) -> List(a)
```

こうすると、あとは通常のGleam関数と同じように呼び出せます。

```gleam
let reversed = reverse_list([1, 2, 3])
// -> [3, 2, 1]
```

JavaScriptランタイム向けにこのコードをコンパイルしようとすると、JavaScript用の実装がないため、エラーメッセージとともに失敗します。JavaScriptランタイム用には、次のように別の実装を指定できます。

```gleam
@external(erlang, "lists", "reverse")
@external(javascript, "./my_module.mjs", "reverse")
pub fn reverse_list(x: List(a)) -> List(a)
```

現在のコンパイルターゲット向けの外部実装がないときに使われるGleamの実装を書くこともできます。

```gleam
@external(erlang, "lists", "reverse")
pub fn reverse_list(x: List(a)) -> List(a) {
  tail_recursive_reverse(x, [])
}

fn tail_recursive_reverse(list, reversed) {
  case list {
    [] -> reversed
    [x, ..xs] -> tail_recursive_reverse(xs, [x, ..reversed])
  }
}
```

## 外部型

外部型を使うと、ErlangやJavaScriptなど、ほかの言語で定義されたデータ型を参照できます。

外部型を定義するには、型を宣言しますが、コンストラクターは何も指定しません。こうして定義した型は、ほかの型と同じように使えます。

```gleam
pub type OrderedDictionary(element)
```
