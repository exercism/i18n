# はじめに

## 再帰

再帰関数とは、自分自身を呼び出す関数のことです。

再帰関数には、少なくとも1つの_基底ケース_と、少なくとも1つの_再帰ケース_が必要です。

_基底ケース_は、関数を再び呼び出すことなく値を返します。
_再帰ケース_は、入力を変化させながら関数を再び呼び出し、いずれ基底ケースに一致するようにします。

Elmでは、再帰関数は通常、`case`式を使ったパターンマッチングや、複数の関数節を使って定義します。

```elm
count : List a -> Int
count list =
    case list of
        [] ->
            0  -- base case

        _ :: tail ->
            1 + count tail  -- recursive case
```

### 再帰によるループ

Elmでは不変性のため、ループの書き方が命令型言語とは異なります。
たとえば、ループはたいてい次のように書きます。

```c
for(i = 0; i < array.length; i++) {
  // do something with array[i]
}
```

Elmのような関数型言語では、変数を書き換えることはできません。
そのため、ループは再帰を使って実装する必要があります。

Elmで`for`ループに相当するものは、次のようになります。

```elm
loop : List a -> (a -> b) -> List b
loop list f =
    case list of
        [] ->
            []

        head :: tail ->
            f head :: loop tail f
```

実際には、Elmで配列やその他のデータ構造を繰り返し処理するときは、たいてい`List`モジュールの関数を使います。たとえば`List.map`、`List.filter`、`List.foldl`などです。
これらの関数は、内部的には再帰を使って実装されています。
