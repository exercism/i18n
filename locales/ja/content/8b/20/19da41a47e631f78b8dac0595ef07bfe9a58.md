# SQLite固有の指示

**result**列には、JSONでエンコードされたオブジェクトのオブジェクトを格納します。各単語がキーで、カウントが整数値です。

たとえば、上の文を考えてみましょう：`"That's the password: 'PASSWORD 123'!", cried the Special Agent.\nSo I fled.`
この入力に対する**result**は、次のようになります：

```json
{"123":1,"agent":1,"cried":1,"fled":1,"i":1,"password":2,"so":1,"special":1,"that's":1,"the":2}
```

## テーブルスキーマ

```sql
CREATE TABLE "word-count" (
    sentence TEXT NOT NULL,
    result   TEXT               -- json object
);
```
