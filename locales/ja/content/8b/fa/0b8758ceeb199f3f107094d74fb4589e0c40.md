# リプレゼンテーション

[Java representer][github-java-representer]は、次の正規化を行います。

- すべてのコメントが削除されます
- すべての`import`宣言が削除されます
- 識別子がプレースホルダーの値に正規化されます

上記の正規化を行ったあと、得られたリプレゼンテーションは、コードの書式に残った違いをなくすために、[Google Java Style][google-java-style]に従って整形されます。

## 提出する前に

次の点を確認してください。

- アナライザーが伝えているフィードバックと内容が重複していないか確認してください。
- 提出ダイアログの「examples」タブを開き、そのフィードバックがすべてのタブで意味を成すかどうかを確認してください。
- 空白やコメントに言及していないか確認してください。
- 解答に現れる関数名や変数名をそのまま使うのではなく、提供されているマッピングを使っているか（名前を省いているか）を確認してください。
  安全に言及できるのは、演習のテストで使われている識別子だけです。これらは誰にとっても常に同じだからです。

[github-java-representer]: https://github.com/exercism/java-representer
[google-java-style]: https://google.github.io/styleguide/javaguide.html
