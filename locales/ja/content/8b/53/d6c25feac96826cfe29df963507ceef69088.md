# はじめに

## 列挙型

_列挙型_とは、変数があらかじめ定義された定数の集合のいずれかになることを可能にする、特別なデータ型です。
その変数は、あらかじめ定義された値のどれかと一致していなければなりません。
よくある例としては、方位（`NORTH`、`SOUTH`、`EAST`、`WEST`という値）や曜日などがあります。

定数なので、列挙型のフィールドの名前は大文字で書きます。

### 列挙型を定義する

Javaプログラミング言語では、`enum`キーワードを使って列挙型を定義します。
たとえば、曜日の列挙型は次のように書きます。

```java
public enum DayOfWeek {
    SUNDAY,
    MONDAY,
    TUESDAY,
    WEDNESDAY,
    THURSDAY,
    FRIDAY,
    SATURDAY
}
```

決まった定数の集合を表したいときはいつでも、列挙型を使うとよいでしょう。
太陽系の惑星のような自然な列挙型も含まれますし、コンパイル時にすべての値がわかっているデータの集合も含まれます。たとえば、メニューの選択肢やコマンドラインフラグなどです。

### 列挙型を使う

上で定義した`DayOfWeek`列挙型の使い方を、次のコードで見てみましょう。

```java
public class Shop {
    public String getOpeningHours(DayOfWeek dayOfWeek) {
        switch (dayOfWeek) {
            case MONDAY:
            case TUESDAY:
            case WEDNESDAY:
            case THURSDAY:
            case FRIDAY:
                return "9am - 5pm";
            case SATURDAY:
                return "10am - 4pm"
            case SUNDAY:
                return "Closed.";
        }
    }
}
```

```java
var shop = new Shop();
shop.getOpeningHours(DayOfWeek.WEDNESDAY);
// => "9am - 5pm"
```

### メソッドとフィールドを追加する

Javaの列挙型は、他の言語の同等のものよりもはるかに強力です。
`enum`宣言は、_クラス_（_列挙型_と呼ばれます）を定義します。
列挙型のクラス本体には、メソッドやその他のフィールドを含めることができます。

```java
public enum Rating {
    GREAT(5),
    GOOD(4),
    OK(3),
    BAD(2),
    TERRIBLE(1);

    private final int numberOfStars;

    Rating(int numberOfStars) {
        this.numberOfStars = numberOfStars;
    }

    public int getNumberOfStars() {
        return this.numberOfStars;
    }
}
```

`Rating`列挙型のメンバーに対して`getNumberOfStars`メソッドを呼び出します。

```java
Rating.GOOD.getNumberOfStars();
// => 4
```
