# はじめに

ABAPは、ABAP Objectsのクラスとインターフェースを基盤とするオブジェクト指向プログラミングモデルをサポートしています。

## 代入と再代入

ABAPで名前に値を代入する主な方法は、いくつかあります。変数を使うか、定数を使うかです。Exercismでは、変数は常に[スネークケース][wiki-snake-case]で書きます。従うべき公式なガイドはありませんし、会社や組織によってスタイルガイドもそれぞれ異なります。_変数の書き方は自由です_。演習で用意されているとおりに書くことの利点は、WebインターフェースやほとんどのIDEで、変数が違う色でハイライト表示されることです。

ABAPでは、変数は[`constant`][constant]キーワードまたは[`data`][data]キーワードを使って定義できます。

`data`を使う場合、変数はその存続期間中にさまざまな値を参照できます。たとえば、`my_first_variable`は、[代入演算子`=`][assignment]を使って何度も定義し直すことができます。

```abap
DATA my_first_variable TYPE i. " integer

my_first_variable = 1.
my_first_variable = 4711 * 3.
my_first_variable = some_complex_calculation( ).
```

`data`とは異なり、`constant`で定義した変数には一度しか代入できません。ABAPで定数を定義するときは、これを使います。

```abap
CONSTANT my_first_constant TYPE i VALUE 10.

" Can not be re-assigned
my_first_constant = 20.
// => SyntaxError: Assignment to constant variable.
```

## クラスとメソッドの宣言

ABAPでは、機能のまとまりは_メソッド_にカプセル化されます。関連するメソッドは、たいてい同じ[クラス][classes]にまとめられます。これらのメソッドは入力（引数）を受け取ることができ、メソッド定義で`returning`キーワードを使って値を_返す_ことができます。メソッドは`( )`という構文で呼び出します。

```abap
CLASS my_class DEFINITION.

  PUBLIC SECTION.

    METHODS add
      IMPORTING
        num1          TYPE i
        num2          TYPE i
      RETURNING
        VALUE(result) TYPE i.

ENDCLASS.

CLASS my_class IMPLEMENTATION.

  METHOD add.
    result = num1 + num2.
  ENDMETHOD.

ENDCLASS.

add( num1 = 1 num2 = 3 ).
// => 4
```

> 💡 ABAPには、クラスやメソッドを宣言する方法が_たくさん_あります。このトラックでは少しずつ紹介していくようにしていますが、すでに知っている場合はどれを使ってもかまいません。ほとんどの場合、どちらを使うかで良し悪しはありません。
