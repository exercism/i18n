# 説明

Take-A-Numberマシン用の組み込みシステムを書きます。とてもシンプルなモデルで、連続した番号を発行し、最後に発行した番号を報告することができます。

## 1. マシンを起動する

`start/0`関数を実装しましょう。新しいプロセスを起動し、そのプロセスのPIDを返します。新しいプロセスは、まだ何もする必要はありません。

```elixir
TakeANumber.start()
# => #PID<0.138.0>
```

このコードを実行するたびに、PIDが変わる可能性がある点に注意してください。

## 2. マシンの状態を報告する

マシンを変更して、新しく起動したプロセスが、初期状態`0`でメッセージを受信できるように（_受信ループ_を開始するように）します。`{:report_state, sender_pid}`というメッセージを受信できるようにしましょう。これらのメッセージへの応答として、現在の状態（最後に発行したチケット番号）を`sender_pid`に送信し、その後さらにメッセージを待ちます。

```elixir
machine_pid = TakeANumber.start()

# a client sending a message to the machine
send(machine_pid, {:report_state, self()})

# a client receiving a message from the machine
receive do
  msg -> msg
end

# => 0
```

## 3. 番号を発行する

マシンを変更して、`{:take_a_number, sender_pid}`というメッセージを受信できるようにします。状態を1増やし、新しい状態を`sender_pid`に送信してから、さらにメッセージを待ちます。

```elixir
machine_pid = TakeANumber.start()

# a client sending a message to the machine
send(machine_pid, {:take_a_number, self()})

# a client receiving a message from the machine
receive do
  msg -> msg
end

# => 1
```

## 4. マシンを停止する

マシンを変更して、`:stop`メッセージを受信できるようにします。メッセージの受信待ちをやめます。

## 5. 予期しないメッセージを無視する

マシンを変更して、予期しないメッセージを受信したときはそれを無視し、引き続きメッセージを待つようにします。
