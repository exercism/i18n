# はじめに

## null許容性

Javaでは、`null`リテラルは値が存在しないことを表すために使われます。

Javaのプリミティブ型にはすべてデフォルト値があるため、`null`になることはありません。慣例として、`int`のように小文字で始まります。

参照型はオブジェクトのメモリアドレスを保持し、`null`を値として持つことができます。一般的には`String`のように大文字で始まります。

プリミティブ型の変数に`null`を代入しようとすると、その変数は常に代入された型のプリミティブ値を保持するため、コンパイル時エラーになります。

```java
//Throws compile time error stating the required type is int, but null was provided
int number = null;
```

参照型の変数に`null`を代入しても、参照型の変数は`null`を許容するため、コンパイル時エラーにはなりません。

```java
//No error will occur as the String variable str is nullable
String str = null;
```
