# 説明

バイナリパズルを解くことが課題です。
バイナリパズルには、必ず解が_1つだけ_あります。その解は、次のルールを当てはめると見つかります。

1. すべてのマスには、0か1のどちらかが入ります。
2. 同じ数字を3つ以上続けて置くことはできません。つまり、隣り合う2つのマスに同じ数字が入っているとき、その隣のマスにはもう一方の数字が入ります。
3. 各行と各列には、0と1が同じ数ずつ入ります。
4. 各行と各列の並びは、すべて異なります。

未完成のパズルは、0と1の行として渡されます。わからない値の部分はプレースホルダー（`_`）になっています。
ここでの目標は、バイナリパズルのルールを定義することです。ルールを定義すると、テストがプレースホルダーの値を割り出せるようになります（その作業を自分で行う必要はありません）。
実装には、Prologの[有限領域上の制約論理プログラミング（CLP(FD)）](https://www.swi-prolog.org/man/clpfd.html)を使う必要があります。これは、この種の課題にぴったりです。

````exercism/note
すぐに始められるように、スタブファイルでは次のようにして[`clpfd`ライブラリ](https://www.swi-prolog.org/man/clpfd.html)がすでに読み込まれています。

```prolog
:- use_module(library(clpfd)).
```
````
