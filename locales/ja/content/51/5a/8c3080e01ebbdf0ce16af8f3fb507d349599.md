# はじめに

`Agent`モジュールは、[プロセスと_受信と送信_のループ][exercism-processes]を生成するための抽象化を提供します。ここでは、`Agent`モジュールを使って開始したプロセスのことを_「エージェントプロセス」_と呼ぶことにします。_エージェントプロセス_は、中心となる共有状態を表すために選ばれることがあります。

_エージェントプロセス_を開始するには、`Agent`が`start/2`関数を提供しています。_エージェントプロセス_を`start`_する_ときに渡す関数は、そのプロセスの初期状態を返します。

```elixir
# Start an agent process with an initial value of an empty list
{:ok, agent_pid} = Agent.start(fn -> [] end)
```

`Map`や`List`と同じように、`Agent`にも_エージェントプロセス_を扱うための関数がたくさん用意されています。

`Agent`に関連する機能はすべて、モデル化する対象のドメイン用のモジュールにまとめてカプセル化するのが通例です。

[exercism-processes]: https://exercism.org/tracks/elixir/concepts/processes
