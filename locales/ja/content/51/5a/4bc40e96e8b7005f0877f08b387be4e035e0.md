# 説明

この演習では、工場の従業員向けの名札を印刷するコードを書きます。

## 1. 従業員の名札を印刷する

従業員にはID、名前、部署名があります。
従業員の名札のラベルは、次の形式です：`"[id] - name - DEPARTMENT"`。
従業員の名札ラベルを返す`printBadge()`メソッドを実装しましょう：

```kotlin
printBadge(734, "Ernest Johnny Payne", "Strategic Communication")
// => "[734] - Ernest Johnny Payne - STRATEGIC COMMUNICATION"
```

~~~~exercism/note
ラベルでは、部署名を大文字にすることに注意してください。
~~~~

## 2. 新しい従業員の名札を印刷する

コンピューターシステムのちょっとした不具合により、新しい従業員が工場で働き始めるときに、まだIDを持っていないことがあります。
名札は必須なので、IDの接頭辞のない一時的な名札が渡されます。
まだIDを持たない新しい従業員に対応するために、`printBadge()`メソッドを変更しましょう：

```kotlin
printBadge(null, "Jane Johnson", "Procurement")
// => "Jane Johnson - PROCUREMENT"
```

## 3. オーナーの名札を印刷する

工場のオーナーでさえ、いつでも名札を着けていなければなりません。
ただし、オーナーには部署がありません。
この場合、ラベルには部署名の代わりに`"OWNER"`を出力します。
オーナー用のラベルを出力するように、`printBadge()`メソッドを変更しましょう：

```kotlin
printBadge(254, "Charlotte Hale", null)
// => "[254] - Charlotte Hale - OWNER"
```

~~~~exercism/note
オーナーが新しい従業員でもある場合があることに注意してください：

```kotlin
printBadge(null, "Charlotte Hale", null)
// => "Charlotte Hale - OWNER"
```
~~~~
