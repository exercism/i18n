# 概要

Factorのシーケンスには、*変更*を加えたいときに使う2つの種類があります。

- **配列**（`{ … }`）は長さが固定です。`set-nth`/`change-nth`を使えば、各位置*に*あるものを変えられますが、長さを伸ばしたり縮めたりすることはできません。
- **ベクター**（`V{ … }`）は長さを変えられます。`push`は末尾に追加し、`pop`は最後の要素を取り除いて返します。

```factor
USING: arrays kernel sequences ;

! Fixed-length: build a counter array of zeros, then bump one slot.
3 0 <array>            ! { 0 0 0 }
dup [ 1 + ] 1 rot change-nth
.                      ! { 0 1 0 }

! Variable-length: build a vector of names by pushing.
V{ } clone
"alice" over push
"bob" over push
dup pop drop           ! removes "bob"
.                      ! V{ "alice" }
```

| ワード          | スタック効果                                   |
|-----------------|------------------------------------------------|
| `<array>`       | `( n elt -- array )`、`elt`を`n`個コピーした配列 |
| `<vector>`      | `( n -- vector )`、容量`n`の空のベクター       |
| `V{ }`          | 空のベクターリテラル                           |
| `set-nth`       | `( elt n seq -- )`、インデックス`n`の要素を代入する |
| `change-nth`    | `( i seq quot -- )`、`i`番目の要素に`quot`を適用する |
| `push`          | `( elt seq -- )`、ベクターに追加する           |
| `suffix!`       | `( seq elt -- seq )`、その場で追加し、ベクターを返す |
| `pop`           | `( seq -- elt )`、最後の要素を取り除いて返す   |
| `pop*`          | `( seq -- )`、最後の要素を取り除いて捨てる     |
| `clone`         | `( obj -- copy )`、独立した新しいコピー        |
| `new-sequence`  | `( n exemplar -- newseq )`、`exemplar`と同じクラスの新しいシーケンス |
| `new-resizable` | `( n exemplar -- newseq )`、サイズを変更できる新しい変種 |

呼び出し元から渡されたシーケンスを変更すると、その変更は呼び出し元にも見えます。同じオブジェクトを持っているからです。それが望ましくない場合は、先に`clone`して独立したコピーを作りましょう。
