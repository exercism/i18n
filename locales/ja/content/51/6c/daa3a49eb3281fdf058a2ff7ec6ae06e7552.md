# Introduction

## Pairs

`Pair`は、2つの要素を組み合わせただけのものです。
その2つの要素は、`first`と`second`という、想像力豊かな名前で呼ばれます。

作成するには、`=>`演算子か`Pair()`コンストラクターのどちらかを使います。

```julia-repl
julia> p1 = "k" => 2
"k" => 2

julia> p2 = Pair("k", 2)
"k" => 2

# Both forms of syntax give the same result
julia> p1 == p2
true

# Each component has its own separate type
julia> dump(p1)
Pair{String, Int64}
  first: String "k"
  second: Int64 2

# Get a component using dot syntax
julia> p1.first
"k"

julia> p1.second
2
```

## Dicts

Pairsの`Vector`は、他の配列と同じです。順序どおりに並び、型は均一で、メモリ上に連続して格納されます。

```julia-repl
julia> pv = ['a' => 1, 'b' => 2, 'c' => 3]
3-element Vector{Pair{Char, Int64}}:
 'a' => 1
 'b' => 2
 'c' => 3

# Each pair is a single entry
julia> length(pv)
3
```

`Dict`は一見似ていますが、保存の仕組みが異なり、エントリー数が多くなってもキーからすばやく取り出せるようになっています。

```julia-repl
julia> pd = Dict('a' => 1, 'b' => 2, 'c' => 3)
Dict{Char, Int64} with 3 entries:
  'a' => 1
  'c' => 3
  'b' => 2

julia> pd['b']
2

# Key must exist
julia> pd['d']
ERROR: KeyError: key 'd' not found

# Generators are accepted in the constructor (and note the unordered output)
julia> Dict(x => 1 / x for x in 1:5)
Dict{Int64, Float64} with 5 entries:
  5 => 0.2
  4 => 0.25
  2 => 0.5
  3 => 0.333333
  1 => 1.0
  ```

他のプログラミング言語では、`Dict`とよく似たものを辞書（Python）、Hash（Ruby）、HashMap（Java）と呼ぶことがあります。

Pairsの場合、単体でもVectorの中でも、それぞれの要素の型にほとんど制約はありません。

`Dict`で有効であるためには、`Pair`が`key => value`のペアである必要があり、その`key`は「ハッシュ可能」でなければなりません。
最も重要なのは、`key`が_イミュータブル_でなければならないという点です。つまり、`Char`、`Int`、`String`、`Symbol`、`Tuple`は問題ありませんが、`Vector`は使えません。

### Modifying a Dict

新しいキーを使えばエントリーを追加でき、既存のキーを使えば上書きできます。

```julia-repl
julia> pd
Dict{Char, Int64} with 3 entries:
  'a' => 1
  'c' => 3
  'b' => 2

# Add
julia> pd['d'] = 4
4

# Overwrite
julia> pd['a'] = 42
42

julia> pd
Dict{Char, Int64} with 4 entries:
  'a' => 42
  'c' => 3
  'd' => 4
  'b' => 2
```

エントリーを削除するには、`delete!()`関数を使います。キーが存在すればDictが変更され、存在しなければ何もせずにそのまま終わります。

```julia-repl
julia> delete!(pd, 'd')
Dict{Char, Int64} with 3 entries:
  'a' => 42
  'c' => 3
  'b' => 2
```

### Checking if a key or value exists

方法はいくつかあります。
キーを確認するには、`haskey()`関数があります。

```julia-repl
julia> haskey(pd, 'b')
true
```

あるいは、キーまたは値の中を検索することもできます。

```julia-repl
julia> 'b' in keys(pd)
true

julia> 43 in values(pd)
false

julia> 42 ∈ values(pd)
true
```
