# はじめに

ループは、1つ以上の文をまとめて繰り返し実行する方法です。
文のまとまりを1回実行することを、繰り返しと呼びます。

## `while`ループ

`while`ループは、ループの先頭にある真偽値の式が`true`の間、文のまとまりを実行します。
真偽値の式が`false`になると、ループは停止し、ループの次の行のコードに処理が進みます。

最初から真偽値の式が`false`と評価される場合、`while`ループは一度も実行されず、ループの次の行のコードに処理が進みます。

```c
int main() {
    int i = 0;
    while (i < 5) {
        printf("Number is %i\n", i++);
    }    
    return 0;
}
```

ループを終わらせる条件があることが重要です。そうでなければ無限ループになり、コードが一切先に進まなくなります。
上のコードで`i`から`++`を取り除くと、無限ループになります。

## `do`ループ

`do`ループでは、真偽値の式がループの最後でテストされます。
`do`ループは少なくとも1回は必ず実行されます。次の例のとおりです。

```c
do {
    printf("Enter the Answer to the Ultimate Question of Life: ");
    scanf("%d", &answer);
} while (answer != 42); 
// Note that a semicolon is needed after the Boolean expression.
```

これを`while`ループで書くと、もっと冗長になります。

```c
printf(""Enter the Answer to the Ultimate Question of Life: ");
scanf("%d", &answer);
while (answer != 42) {
    printf(""Enter the Answer to the Ultimate Question of Life: ");
    scanf("%d", &answer);
}
```

## `for`ループ

ループでは、変数を更新し、その変数が特定の値になったら終了する、ということがよくあります。
`for`ループは、1つ以上の変数の初期化・更新・テストを、括弧（`()`）の中の1行で行う方法です。
最初の部分は変数の初期化、2番目の部分は変数のテスト、3番目の部分は変数の値の更新に使います。

```c
for (int i = 0; i < 5; i++) {
    printf("Number is %i\n", i);
}
```

これは`while`ループで書いた場合よりも簡潔で、それでいて読みやすさも保たれています。
