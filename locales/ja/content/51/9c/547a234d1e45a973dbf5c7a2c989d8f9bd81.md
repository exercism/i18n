# 説明

この演習では、ラジコンカーを操作して遊びます。ようやくお金を貯めて買えるようになった車です。

車のバッテリーは、満充電（100%）の状態から始まります。リモコンで車を1回動かすたびに、車は20メートル進み、バッテリーが1パーセント減ります。

このラジコンカーには、2つの情報を表示するおしゃれなLEDディスプレイが付いています。

- これまでに走った合計距離。表示は`"Driven <METERS> meters"`です。
- バッテリーの残量。表示は`"Battery at <PERCENTAGE>%"`です。

バッテリーが0%になると、もう車を動かすことはできません。そのとき、バッテリーの表示は`"Battery empty"`になります。

タスクは6つあり、どれもラジコンカーのインスタンスを扱います。

## 1. 新品のラジコンカーを買う

新品のラジコンカーのインスタンスを返す、(_static_な)`RemoteControlCar.Buy()`メソッドを実装してください:

```csharp
RemoteControlCar car = RemoteControlCar.Buy();
```

## 2. 走った距離を表示する

LEDディスプレイに表示される距離を返す`RemoteControlCar.DistanceDisplay()`メソッドを実装してください:

```csharp
var car = RemoteControlCar.Buy();
car.DistanceDisplay();
// => "Driven 0 meters"
```

## 3. バッテリー残量を表示する

LEDディスプレイに表示されるバッテリー残量を返す`RemoteControlCar.BatteryDisplay()`メソッドを実装してください:

```csharp
var car = RemoteControlCar.Buy();
car.BatteryDisplay();
// => "Battery at 100%"
```

## 4. 運転したときに走行距離を更新する

走行距離を更新する`RemoteControlCar.Drive()`メソッドを実装してください:

```csharp
var car = RemoteControlCar.Buy();
car.Drive();
car.Drive();
car.DistanceDisplay();
// => "Driven 40 meters"
```

## 5. 運転したときにバッテリー残量を更新する

バッテリー残量を更新するように`RemoteControlCar.Drive()`メソッドを更新してください:

```csharp
var car = RemoteControlCar.Buy();
car.Drive();
car.Drive();
car.BatteryDisplay();
// => "Battery at 98%"
```

## 6. バッテリーが切れたときは運転できないようにする

バッテリーが切れた（0%の）ときは、走行距離を増やさず、バッテリー残量も減らさないように`RemoteControlCar.Drive()`メソッドを更新してください:

```csharp
var car = RemoteControlCar.Buy();

// Drain the battery
// ...

car.DistanceDisplay();
// => "Driven 2000 meters"

car.BatteryDisplay();
// => "Battery empty"
```
