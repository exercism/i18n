# はじめに

文字リストは、`~c`シジルを使って作成します。

```elixir
~c"hello"
```

~~~~exercism/note
古いバージョンのElixirでは、文字リストはシングルクォートで`'hello'`のように表されていたことに注意してください。
~~~~

文字列とよく似ていますが、この2つのデータ型はまったく別のものです。文字リストは整数のリストです。それぞれの整数は、ある文字のUnicode値（コードポイントとも呼ばれます）を表しています。

```elixir
[65, 66, 67]
# => ~c"ABC"
```

文字の前に`?`を付けると、そのコードポイントを取得できます。

```elixir
?A
# => 65

[?:, ?)]
# => ~c":)"
```

文字リストはリストなので、他のリストと同じように、再帰やパターンマッチングを使って扱えます。

```elixir
[first_letter | _] = ~c"cat"
first_letter
# => 99
```

`++`を使うと、2つのリストを連結できます。

```elixir
~c"hi" ++ ~c"!"
# => ~c"hi!"
```

最初のリストが長いほど連結は遅くなるので、長さが決まっていないリストに繰り返し要素を追加するのは避けましょう。
