# 概要

Clojureでは、値を名前に結びつけることを[_var_][vars]と呼びます。トップレベル（グローバル）のvarは、他の言語の定数に似ていますが、動的な開発をしやすくするために、よく再定義されます。

トップレベルのvarは、[`def`][def]を使って定義します。

```clojure
(def fingers 10)
```

[数値に対する演算][operators]を行うコア関数を使うと、値の計算ができます。

`defn`マクロを使うと、0個以上の引数を受け取る[関数][functions]を定義できます。関数は、必ず本体の最後の式の結果を返します。

```clojure
(defn add [x y]
  (+ x y))
```

関数を呼び出すには、関数名を指定し、関数の各仮引数に引数を渡します。

```clojure
(def five (add 2 3))
```

Clojureの関数や値は、定義した_後_でなければ使えません。定義する前に使うと、コンパイルエラーになります。

```clojure
;; Compile error as `add` has not yet been defined
(def seven (add 3 4))

(defn add [x y]
  (+ x y))
```

Clojureでは、空白は整形以外の意味を持ちません。

Clojureの関数とvarは、名前空間で整理されます。名前空間は関連する機能をまとめるもので、`ns`マクロを使って定義します。

```clojure
(ns calculator)

(def pi 3.14)

(defn add [x y]
  (+ x y))
```

Clojureには2種類のコメントがあります。1行コメントは`;`で始め、`comment`フォームは`(comment`と`)`の間にあるものを評価しないようにするために使います。
