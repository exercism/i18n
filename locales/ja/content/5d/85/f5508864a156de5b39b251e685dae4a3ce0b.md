# はじめに

メソッドの仮引数は、デフォルト値を代入することで省略可能にできます。省略可能な仮引数を持つメソッドを呼び出すとき、呼び出し側はその仮引数に値を渡す必要はありません。省略可能な仮引数に値が渡されなかった場合は、デフォルト値が使われます。

省略可能な仮引数は_必ず_仮引数リストの末尾に置く必要があります。省略可能でない仮引数をその後ろに置くことはできません。

```csharp
class Card
{
    static string NewYear(int year = 2020)
    {
        return $"Happy {year}!";
    }
}

Card.NewYear();     // => "Happy 2020!"
Card.NewYear(1999); // => "Happy 1999!"
```
