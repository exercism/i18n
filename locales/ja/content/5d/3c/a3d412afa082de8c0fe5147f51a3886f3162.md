# はじめに

Rubyは動的な[オブジェクト指向言語][object-oriented-programming]です。
Rubyでは、すべてが[オブジェクト][object]です。

Rubyでオブジェクトに名前を付ける方法は、主に2つあります。変数を使うか、定数を使うかです。
変数は常に[スネークケース][snake-case]で書きます。
変数は、その生涯の中でさまざまなオブジェクトを参照できます。
たとえば、`my_first_variable`は、`=`演算子を使って何度も定義し直すことができます。

```ruby
my_first_variable = 1
my_first_variable = "Some string"
my_first_variable = SomeComplexObject.new
```

一方、定数は一度だけ代入するものです。
定数は大文字で始める必要があり、通常は単語をアンダースコアで区切った大文字だけで書きます。

たとえば、次のようになります。

```ruby
MY_FIRST_CONSTANT = 10

# Redefining not allowed
# MY_FIRST_CONSTANT = "Some String"
```

Rubyはクラスで整理されています。
クラスは、`class`キーワードのあとにクラス名を書いて定義します。
オブジェクトは通常、`.new`メソッドでクラスをインスタンス化して作成します。

たとえば、次のようになります。

```ruby
# Define the class
class Calculator
  #...
end

# Create an instance of it and assign it to a variable
my_first_calc = Calculator.new
```

機能の単位はメソッドにまとめられます。他の言語の_関数_に似ています。
メソッドは、必要に応じて位置引数、または`:`構文で定義・呼び出しするキーワード引数を使って定義できます。
メソッドは、最後に評価された文の結果を暗黙的に返すか、`return`キーワードで明示的にオブジェクトを返します。
メソッドは`.`構文で呼び出します。

```ruby
class Calculator

  # Unnamed params
  def add(num1, num2)
    return num1 + num2 # Explicit return
  end

  # Named params
  def multiply(num1:, num2:)
    num1 * num2 # Implicit return
  end
end

calc = Calculator.new
calc.add(1, 3)
calc.multiply(num1: 2, num2: 5)
```
