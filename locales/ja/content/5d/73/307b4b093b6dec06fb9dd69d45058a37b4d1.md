# はじめに

## 時間

`Time`モジュールは、人が読める形式の日付や時刻を表示するために使います。`Time`で時刻を操作することも技術的には可能ですが、Elmのコミュニティには、その作業にはるかに適したパッケージがあります。たとえば[`justinmimbs/date`][date]や[`CoderDennis/elm-time-format`][elm-time-format]などです。

### Posix

時刻は、不透明型`Posix`で表されます。`Posix`はUnixエポック時間、つまり1970年1月1日0時UTCからの経過ミリ秒数を包んだものです。`Posix`はタイムゾーンによって変化しない曖昧さのない値なので、時刻を扱うための良い選択肢になります。Elmアプリケーションでは、`Posix`の時刻は通常、ブラウザーなどの外部ソースから提供されます。

次の関数を使うと、`Posix`をミリ秒の数値に変換したり、その逆を行ったりできます。

```elm
posixToMillis : Posix -> Int
millisToPosix : Int -> Posix
```

### タイムゾーン

日常生活では、人間は通常`Posix`をそのまま読むことはなく、代わりに現地時間を好みます。現地時間は、地球上のどの位置にいるかや、その地域の夏時間のルールによって決まります。Elmでは、この情報は不透明型`Zone`にエンコードされており、通常はブラウザーから提供されます。

常にアクセスできる特別な`Zone`があります。

```elm
utc : Zone
```

### 人が読める時刻

`Posix`と`Zone`があれば、現地時間をどんな細かさでも表示するのに十分な情報がそろいます。そのために使える関数は次のとおりです。

```elm
toYear : Zone -> Posix -> Int
toMonth : Zone -> Posix -> Month
toDay : Zone -> Posix -> Int
toWeekday : Zone -> Posix -> Weekday
toHour : Zone -> Posix -> Int
toMinute : Zone -> Posix -> Int
toSecond : Zone -> Posix -> Int
toMillis : Zone -> Posix -> Int
```

`Time`には、さらに2つのカスタム型があることにお気づきでしょう。

```elm
type Month = Jan | Feb | Mar | Apr | May | Jun | Jul | Aug | Sep | Oct | Nov | Dec
type Weekday = Mon | Tue | Wed | Thu | Fri | Sat | Sun
```

これらのカスタム型を人が読める値に変換するのは、利用者に任されています。
