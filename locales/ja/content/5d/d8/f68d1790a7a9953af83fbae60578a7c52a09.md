# 指示

[Dungeons & Dragons][DND]（DND）のゲームでは、各プレイヤーはまず、自分が操作するキャラクターを作るところから始めます。
このキャラクターには、さまざまな要素の中でも特に、6つの能力値があります。

- 筋力
- 敏捷力
- 耐久力
- 知力
- 判断力
- 魅力

これら6つの能力値のスコアは、ランダムに決まります。
4つの6面ダイスを振り、大きいほうから3つの出目の合計を記録します。
これを6回、能力値ごとに1回ずつ行います。

キャラクターの初期ヒットポイントは、10 + 耐久力修正値です。
耐久力修正値は、耐久力から10を引き、2で割り、小数点以下を切り捨てることで求められます。

~~~~exercism/advanced
数学的な表記を好むなら、修正値は次のように定義されます

$$

\operatorname{modifier}\left(\text{constitution}\right) = \left\lfloor\frac{\text{constitution} - 10}{2}\right\rfloor

$$

ヒットポイントは次のように定義されます

$$

\operatorname{HP}\left(\text{constitution}\right) = 10 + \operatorname{modifier}\left(\text{constitution}\right)

$$
~~~~

たとえば、4つのダイスを6回振った結果は、次のようになるかもしれません。

* 5, 3, 1, 6: 1を捨て、5 + 3 + 6 = 14を合計して、これを筋力に割り当てます。
* 3, 2, 5, 3: 2を捨て、3 + 5 + 3 = 11を合計して、これを敏捷力に割り当てます。
* 1, 1, 1, 1: 1を捨て、1 + 1 + 1 = 3を合計して、これを耐久力に割り当てます。
* 2, 1, 6, 6: 1を捨て、2 + 6 + 6 = 14を合計して、これを知力に割り当てます。
* 3, 5, 3, 4: 3を捨て、5 + 3 + 4 = 12を合計して、これを判断力に割り当てます。
* 6, 6, 6, 6: 6を捨て、6 + 6 + 6 = 18を合計して、これを魅力に割り当てます。

耐久力が3なので、耐久力修正値は-4となり、ヒットポイントは10 - 4 = 6になります。

## 1. 有効な能力値を生成する

上記のルールに基づいて、1つの能力値を返す関数`ability()`を実装してください。

```julia-repl
julia> ability()
14
```

~~~~exercism/note
この演習の目的は乱数の分布ではありません。そのため、4つのダイスの出目をシミュレートする必要はありません。
能力値には、分布に関係なく、3から18までのランダムな値（両端を含む）を使ってかまいません。
~~~~

## 2. 耐久力修正値を計算する

上記のルールに従い、`ability`の値に基づいて能力修正値を返す関数`modifier(ability)`を実装してください。
戻り値は整数でなければなりません。

```julia-repl
julia> modifier(17)
3
``` 

## 3. 上記のルールに従うランダムなキャラクター生成器を書く

3つのコンストラクターを持つ`DNDCharacter`構造体を実装してください。

| コンストラクター                                                                                    | 説明                                                                       |
| ---------------------------------------------------------------------------------------------- | --------------------------------------------------------------------------------- |
| `DNDCharacter()`                                                                               | ランダムに生成された能力値を持つキャラクターを作成します。                             |
| `DNDCharacter(strength, dexterity, constitution, intelligence, wisdom, charisma, hitpoints)`   | **位置引数**を使って、指定された能力値を持つキャラクターを作成します。 |
| `DNDCharacter(; strength, dexterity, constitution, intelligence, wisdom, charisma, hitpoints)` | **キーワード引数**を使って、指定された能力値を持つキャラクターを作成します。    |

```julia-repl
julia> DNDCharacter()
DNDCharacter(18, 17, 18, 17, 5, 10, 14)

julia> DNDCharacter(4, 12, 13, 18, 13, 7, 11)
DNDCharacter(4, 12, 13, 18, 13, 7, 11)

julia> DNDCharacter(
           strength = 4,
           dexterity = 12,
           constitution = 13,
           intelligence = 18,
           wisdom = 13,
           charisma = 7,
           hitpoints = 11
       )
DNDCharacter(4, 12, 13, 18, 13, 7, 11)
```
