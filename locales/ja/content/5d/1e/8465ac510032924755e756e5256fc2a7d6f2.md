# はじめに

PHPの共変性と反変性という概念は、クラスやインターフェースを継承するときにこれらのルールが守られるようPHPが強制するため、重要です。

共変性は2つの型の関係をそのまま保ち、反変性はその関係を逆にします。つまり、クラスを継承して関数をオーバーライドするときは、メソッドの仮引数により具体的な型もより抽象的な型も指定できます。一方、メソッドから返せるのは、より限定的な型だけです。

## 例

次のクラスを見てみましょう。

```php
class Calculator 
{
    public function add(int $x, int $y): int 
    {
        return $x + $y;
    }
}
```

このクラスを継承する場合、仮引数にはもとで宣言されたよりも多くの型を指定できますが、戻り値にはもとの戻り値の型以外は指定できません。

```php
class Floatulator extends Calculator
{
    // This is valid
    public function add(int|float $x, int|float $y): int 
    {
        return (int)($x + $y);
    }
}
```

次のように継承したクラスは、追加の型やより広い型を戻り値にできないため、有効ではありません。

```php
class BrokenCalculator extends Calculator 
{
    // This is invalid and will not compile
    public function add(int|float $x, int|float $y): int|float{
        return $x + $y;
    }
}
```
