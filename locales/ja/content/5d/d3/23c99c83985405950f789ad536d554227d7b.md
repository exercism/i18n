# はじめに

SQLでは、`SELECT`文を使うとデータベースからデータを取り出せます。
`SELECT`文の結果は結果セットです。
結果セットには、行と列に並んだ値が入っています。
各列は、データの特定の属性を表します。
各行には、すべての列に対する値が入っています。

ひとつの捉え方として、列の集まりがデータ構造を表していて、各列がそのデータ構造のフィールド、各行がそのデータ構造のインスタンスだと考えることもできます。

`SELECT`文では、取り出したいデータを指定できます。
さらに、必要に応じて出力データを変換したり、絞り込んだり、形を変えたりすることもできます。

## 基本

基本的な`SELECT`文の構成は次のとおりです。

```sql
SELECT <columns>
FROM <source>
WHERE <criteria>;
```

~~~~exercism/note
`FROM`句と`WHERE`句は省略できます。
たとえば、`SELECT "Hello, world.";`のような文もまったく問題なく動作します。

また、改行は必須ではありません。`SELECT`文の各句（つまり各部分）を区切るには、何らかの空白があれば十分です。
~~~~

`SELECT`キーワードのすぐ後ろには、結果に含めたい列のリストを書きます。
`FROM`句はデータの取得元を指定します。取得元は通常、データベース内のテーブルです。
`WHERE`句は、1つ以上の条件で出力データを絞り込みます。

## `WHERE`句でデータを絞り込む

`WHERE`句を使うと、`SELECT`文で取り出したデータを絞り込めます。
たとえば、Appliancesだけが欲しい場合は次のように書きます。

```sql
SELECT * FROM inventory
WHERE category = "Appliances";
```

結果：
```
upc           category    supplier        brand      product_name                 weight  stock
------------  ----------  --------------  ---------  ---------------------------  ------  -----
899001234556  Appliances  Culinary Depot  QuickBrew  Single-Serve Coffee Maker    4.2     18   
880012349876  Appliances  Culinary Depot  HeatWave   Compact Toaster Oven         7.5     14   
844110220987  Appliances  Culinary Depot  BlendPro   High-Speed Personal Blender  3.1     16   
```

あるいは、weightが2.0から6.0の間にあるデータだけが欲しいかもしれません。

```sql
SELECT * FROM inventory
WHERE weight BETWEEN 2.0 AND 6.0;
```

結果：
```
upc           category    supplier        brand      product_name                  weight  stock
------------  ----------  --------------  ---------  ----------------------------  ------  -----
899001234556  Appliances  Culinary Depot  QuickBrew  Single-Serve Coffee Maker     4.2     18   
823450987112  Cookware    KitchenCo       FreshKeep  12-Piece Glass Container Set  6       33   
899998877665  Cookware    KitchenCo       IronCraft  Cast-Iron Grill Pan           5.3     21   
844110220987  Appliances  Culinary Depot  BlendPro   High-Speed Personal Blender   3.1     16   
```
