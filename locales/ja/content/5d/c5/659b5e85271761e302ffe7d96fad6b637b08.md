# はじめに

関数がたくさんの引数を取るとき、どの順番で渡せばよいかを覚えておくのは難しいことがあります。読みやすさのために、Gleamでは引数に名前を付けてラベルを付けられます。

引数にラベルを付けるには、引数名の前にラベル名を書き、スペースで区切ります。

```gleam
pub fn replace(
  in string: String,
  each target: String,
  with replacement: String
) -> String {
  // ...
}
```

ラベル付き引数を持つ関数を呼び出すときは、引数をどの順番で渡してもかまいません。次の`replace`の呼び出しはどれも同じ意味です。

```gleam
replace(in: "🍔🍔🍔" each: "🍔", with: "🍕")

replace(each: "🍔", in: "🍔🍔🍔", with: "🍕")

replace(with: "🍕", each: "🍔", in: "🍔🍔🍔")
```

ラベルは常に省略できます。関数がラベル付き引数を持っていても、ラベルなしで呼び出せます。

```gleam
replace("🍔🍔🍔", "🍔", "🍕")
```
