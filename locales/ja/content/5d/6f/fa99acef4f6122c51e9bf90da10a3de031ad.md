# テストを実行する

## 演習をダウンロードする

取り組みたい演習は、[Exercism CLI][cli]を使ってダウンロードします。

```sh
exercism download --track=dart --exercise=hello-world
```

次に、演習のディレクトリに移動します。

```sh
cd /path/to/exercism/dart/hello-world
```

## 依存関係をインストールする

テストを実行する前に、演習の依存関係をダウンロードします。

```sh
dart pub get
```

## テストを実行する

```sh
dart test
```

## テスト結果の見方

## テストを順番に進める

ほとんどの演習には複数のテストがあり、最初の1つ以外はデフォルトでスキップされています。

```dart
void main() {
  final twoFer = TwoFer();

  group('TwoFer', () {
    test('no name given', () {
      final result = twoFer.statement();
      expect(result, equals('One for you, one for me.'));
    }, skip: false);

    test('a name given', () {
      final result = twoFer.statement('Alice');
      expect(result, equals('One for Alice, one for me.'));
    }, skip: true);

    test('another name given', () {
      final result = twoFer.statement('Bob');
      expect(result, equals('One for Bob, one for me.'));
    }, skip: true);
  });
}
```

テストを1つずつ進めるには、それぞれのテストの`skip: true`を`skip: false`に変えていきます。
あるいは、ファイルを編集せずにすべてのテストを一度に実行することもできます。

```sh
dart test --run-skipped
```

提出時には、スキップされたものも含め、すべてのテストがオンラインのテストランナーで実行されます。

## 「Could not find a command named frontend_server.dart.snapshot」というエラーへの対処

しばらく前に解いて提出した演習に、久しぶりに戻ってきたとします。
その演習をテストすると、次のようなエラーが出ることがあります。

```sh
$ dart test
...
Could not find a command named "/path/to/frontend_server.dart.snapshot".
```

解決策は、`pubspec.lock`ファイルを削除することです。
その後、もう一度dartコマンドを実行します。
