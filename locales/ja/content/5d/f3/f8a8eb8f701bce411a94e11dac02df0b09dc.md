# 概要

関数はデフォルトで外部リンケージを持ち、プロジェクト内の他のどのファイルからでも呼び出すことができます。リンケージについて詳しくは、[リンケージの概念](../linkage/introduction.md#Introduction)を参照してください。`static`関数は、それが定義されているソースファイル内からしか呼び出すことができません。

たとえば、次のとおりです。

```c
// file scope, internal linkage
// can only be called from within this file
static void some_function()
{
    // code snipped
}

// file scope, external linkage by default
// can be called from any other file in the project
int main()
{
    // code snipped
}
```

関数がヘッダーで宣言されていても、`static`として定義されていれば、そのソースファイルの外から呼び出すことはできません。ソースファイルがそのヘッダーをインクルードし、ヘッダーで宣言された`static`関数を呼び出してコンパイルすることはできても、リンカーは`static`関数の定義を見つけられずに失敗します。ソースファイル内で`static`とマークされた関数は、そのヘッダーファイルで宣言すべきではありません。
