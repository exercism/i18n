# SQLite特有の指示

**list_one** と **list_two** の列には、整数の配列をJSONエンコードした値が入っています。

例:

```json
[1, 2, 3]
```

## テーブルスキーマ

```sql
CREATE TABLE sublist (
    list_one TEXT NOT NULL,     -- json array
    list_two TEXT NOT NULL,     -- json array
    result   TEXT
);
```
