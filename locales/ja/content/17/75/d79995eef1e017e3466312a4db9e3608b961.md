# はじめに

再帰とは、関数が自分自身を呼び出すことで、関数の中のコードを繰り返す方法です。
ループや繰り返しの、もう一つの書き方と考えることもできます。
ループと同じように、再帰的な実行をいつ止めるかは、真偽値の式や`True`/`False`の判定で決めます。
ループと_違って_、終了条件のない再帰がPythonで無限に実行され続けることはありません。
それぞれの関数呼び出しで使われる値は、Pythonの[インタプリタースタック][what-is-the-call-stack]上の、その呼び出し専用の[フレーム][stack-frame]に置かれます。
関数呼び出しの総数がスタックの容量を超えてしまうと、エラーになります。

```python
def print_increment(step, max_value):
    if step > max_value:
        return
    print(f'The step is {step}')
    print_increment(step + 1, max_value)


def main():
    print_increment(1, 2)
    print("After recursion")

if __name__ == "__main__":
    main()

```

出力は次のようになります。

```
The step is 1
The step is 2
After recursion
```

ループで書くよりも再帰で書いたほうが、読みやすかったり、処理の流れを追いやすかったりする場面もあります。
