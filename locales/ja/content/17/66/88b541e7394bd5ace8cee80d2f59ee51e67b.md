# 概要

メソッドには可変長引数を持たせることができます。呼び出す側は、通常の引数と同じように0個以上の引数を指定できます。メソッドは、これらの引数を1つの配列として受け取ります。

仮引数を可変長引数にするには、その仮引数の宣言に[`params`キーワード](https://docs.microsoft.com/en-us/dotnet/csharp/language-reference/keywords/params)を追加します。

```csharp
public static void PrintNumbers(params int[] numbers)
{
    foreach (var number in numbers)
    {
        Console.Write(number)
    }
}

// No values for a varags parameter is allowed
PrintNumbers();

PrintNumbers(1);
// => 1

PrintNumbers(1, 2, 3);
// => 123
```
