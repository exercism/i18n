# はじめに

ほとんどのプログラミング言語と同様に、Gleamには「副作用」があります。そのため、関数は値を返すだけでなく、世界の状態を読み取ったり変更したりすることができます。

Gleam標準ライブラリの`gleam/io`モジュールには、文字列をコンソールに出力する関数が用意されています。

```gleam
io.println("Hello, Joe!")
// Hello, Joe!
// -> Nil
```

ほかのパッケージには、ファイルの読み書きをする関数を提供する`simplifile`というパッケージなど、別の入出力関数が用意されていることがあります。

```gleam
simplifile.read("favourite-colour.txt")
// -> Ok("Pink\n")
```
