# 概要

Common Lispには、サポートする「枝」の数で分類できる、いくつかの異なる条件式が用意されています。

また、他の多くのプログラミング言語とは異なり、Common Lispの条件式はすべて文ではなく_式_です。つまり、Lispの条件式はすべて何らかの値に評価され、具体的な値の代わりに使うことができます。

例を見てみましょう。

```lisp
;; Doubles x when it's even
(* x (if (evenp x) 2 1))
```

## 枝が1つの条件式

`when`と`unless`という条件式は、与えられたテストがそれぞれ真のとき、偽のときにだけコードを評価し、それ以外の場合は`nil`に評価されます。

テスト式のあとの部分には、複数の式を書くこともできます。

```lisp
(when (= 2 2) "All is well")      ; => "All is well"
(unless (= 2 2) "Time to panic!") ; => NIL
```

## 枝が2つの条件式

`if`条件式は、テストが真のときは本体の最初の式を、それ以外のときは2番目の式を評価します。

```lisp
(if (= 2 2) 'how-honest 'you-liar) ; => HOW-HONEST
```

then節とelse節は、どちらも1つの式しか書けないことに注意してください。

## 枝が多い条件式

Lispの「超条件式」が`cond`で、無限に多くの枝を持つことができます。
各々の枝は、テスト条件と本体の式を持ち、それらはもう1組の括弧（`()`）で囲みます。
すべてのテストが偽に評価されると、`nil`が返されます。

```lisp
(cond ((= 0 2) 'nope)
      ((= 1 2) 'try-again)
      ((= 2 2) 'quite-true)
      ((= 3 2) 'too-far)
      (t 'something-else))
; => QUITE-TRUE
```

テスト式のあとに続く式の数に制限はないことに注意してください。


1つの値をいくつかの枝と比較したいだけなら、よりすっきりと書ける`case`式を使えます。
どのケースにも一致しなければ、`nil`が返されます。
`t`と`otherwise`はどちらも、すべてを受け止めるケースとして使えます。

```lisp
(case 'elder-beast
  (cat "Meow")
  (bird "Chirp")
  (dog "Bark")
  (otherwise "???"))
; => "???"
```

`cond`と同様、テスト式のあとに続く式の数に制限はないことに注意してください。

## 隠れた条件式

Common Lispの真偽値の演算である`and`と`or`は、短絡評価するマクロで、特定の条件式の重複を減らすのに使えます。

`and`マクロは、偽の値が1つでも現れればただちに`nil`を返し、そうでなければ`and`の最後の真の値を返します。

```lisp
(and 42 "Magic" :cool) ; => :COOL
(and () "Magic" :cool) ; => NIL
```

`or`マクロは、最初に見つけた真の値を返します。真の値が1つもなければ`nil`を返します。

```lisp
(or () 42 nil)  ; => 42
(or () NIL nil) ; => NIL
```

## もう、お手上げです…

前述のとおり、`case`式のどの枝にも一致せず、`otherwise`節もない場合は、`nil`が返されます。
しかし、どの枝にも一致しないことをエラーとして扱いたい場合もあります。そこで登場するのが、**網羅的**な一致のための`ecase`です。

使い方は`case`とまったく同じですが、一致するものがなかったときに`nil`を返す代わりにエラーを通知します。

```lisp
(case 'elder-beast
  (cat "Meow")
  (bird "Chirp")
  (dog "Bark"))
; => NIL

(ecase 'elder-beast
  (cat "Meow")
  (bird "Chirp")
  (dog "Bark"))
; => ERROR: ELDER-BEAST fell through ECASE expression. Wanted one of (CAT BIRD DOG).
```
