# はじめに

Javaでは、`java.util.Random`クラスのインスタンスを使って乱数を生成できます。

## ランダムな整数

`nextInt()`メソッドを使うと、ランダムな整数を生成できます。
生成される値の範囲は、`Integer.MIN_VALUE`から`Integer.MAX_VALUE`までです。

```java
Random random = new Random();

random.nextInt();
// => -1169335537
```

生成される値の範囲を限定するには、`nextInt(int)`を使います。
これで生成される値の範囲は、`0`以上、指定した上限未満になります。

たとえば、次のコードは`0`から`9`までのランダムな数値を生成します。

```java
Random random = new Random();

random.nextInt(10);
// => 6
```

そして、次のコードは`10`から`19`までのランダムな数値を生成します。

```java
Random random = new Random();

10 + random.nextInt(10);
// => 11
```

## ランダムな小数

`nextDouble()`メソッドを使うと、ランダムな小数を生成できます。
生成される値の範囲は、`0.0`から`1.0`までです。

```java
Random random = new Random();

random.nextDouble();
// => 0.19250004204021398
```

そして、次のコードは`100.0`から`200.0`までのランダムな数値を生成します。

```java
Random random = new Random();

100.0 + 100.0 * random.nextDouble();
// => 111.31849856260328
```
