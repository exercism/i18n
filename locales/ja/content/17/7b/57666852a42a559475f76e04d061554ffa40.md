# 説明

会社は、ユーザーの入力からCSVレコードを生成する仕事を請け負いました。

[RFC 4180](https://tools.ietf.org/html/rfc4180)で定義されている標準に従って、CSVレコードを組み立てるビルダーが必要です。

正式な仕様は存在しますが、今回実装する必要があるのは次の機能だけです。
- 新しいレコードビルダーを作成する
- レコードに個別のフィールドを追加する
- 基本的なエスケープを行ってレコードをシリアライズする

基本的なエスケープとは、次のとおりです。

- 改行、ダブルクォート、カンマを含むフィールドは、ダブルクォートで囲む必要があります。

- フィールドを囲むのにダブルクォートを使う場合、フィールド内に現れるダブルクォートは、その前に別のダブルクォートを付けてエスケープする必要があります。


## 1. 新しいビルダーを作成する

新しいビルダーを作成するには、`new`メソッドを実装する必要があります。

```rust
let mut builder = CsvRecordBuilder::new();
```

## 2. レコードに個別のフィールドを追加する

レコードビルダーにフィールドを追加するには、`add`メソッドを実装する必要があります。
`add`は、引数として不変の文字列スライス`&str`を取ります。

```rust
builder.add("ant");
builder.add("ba\"t");
builder.add("cat");
```


## 3. 基本的なエスケープを行ってレコードをシリアライズする

`build`メソッドを実装する必要があります。
`build`はビルダーを消費し、CSVレコードを返します。
```rust
let record = builder.build();
// Note that from now on we cannot use `builder`
assert_eq!(&record, r#"ant,"ba""t",cat"#);
```
