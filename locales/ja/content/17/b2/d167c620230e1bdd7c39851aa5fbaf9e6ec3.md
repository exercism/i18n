# 説明

あなたは沿岸を警備する巡視船の信号手です。今日の肩掛けかばんには、朝の見張りが始まる前に、5つの小さなワードを用意しておく必要があります。

## 1. 値をクォートする

観測記録はすべて、*Factorソース形式*で書き留めます。これはパーサーが読み戻すのと同じテキストです。`quote-value`を定義して、どんな値でもソース形式の文字列に変換しましょう。

```factor
123 quote-value .   ! => "123"
"hi" quote-value .  ! => "\"hi\""
```

## 2. 旗の枠を取り除く

入ってくる信号旗は、両端にマーカー文字が付いた状態で届きます。`flag-body`を定義して、2つのマーカーの*間*にあるものをすべて返しましょう。先頭の文字を外し、末尾の文字を外します。

コピーではなく、スライス（ビュー）を返します。

```factor
"#NS-1024#" flag-body .   ! => "NS-1024"
```

## 3. 旗を分割する

それぞれの旗は、短いプレフィックスコードと、それに続くペイロードを持っています。`split-flag`を定義して、旗とヘッダーの長さを受け取り、ヘッダーのスライスと本体のスライスを*両方*返しましょう。

```factor
"NS-1024" 2 split-flag .s
! => "NS"
! => "-1024"
```

## 4. 2つの読み取り値から三角測量する

連続する2つの信号の読み取り値から、3つの測定値が導かれます。それらの*差*`a - b`、*中点*`(a + b) / 2`、そして*比*`a / b`です。どの測定値も、両方の読み取り値を使います。

`triangulate`を定義して、1組の読み取り値からこれら3つを返しましょう。

```factor
100 50 triangulate .s
! => 50
! => 75
! => 2
```

## 5. 3つの読み取り値を要約する

連続する3つの読み取り値は、**合計**、**積**、**最大値**として要約されます。それぞれの統計値は、3つの読み取り値すべてを使います。

`triangle-stats`を定義して、3つすべてを返しましょう。

```factor
5 3 8 triangle-stats .s
! => 16
! => 120
! => 8
```
