# 説明

これから、健康状態をモニタリングするシステムを実装します。その一環として、ユーザーの健康統計を管理する必要があります。

まずは、`impl`ブロックにあるいくつかのスタブ関数と、次の構造体の定義から始めます。

```rust
pub struct User {
    name: String,
    age: u32,
    weight: f32,
}
```

目標は、`impl`ブロックで定義されている`User` `struct`のスタブメソッドを実装することです。

たとえば、`new`メソッドは、指定された名前、年齢、体重を持つ`User`構造体のインスタンスを返す必要があります。

```rust
let mut bob = User::new(String::from("Bob"), 32, 155.2);
// Returns: a User with name "Bob", age 32, and weight 155.2
```

`weight`メソッドは、`User`の体重を返す必要があります。

```rust
bob.weight();
// Returns: 155.2
```

`set_age`メソッドは、`User`の年齢を設定する必要があります。

```rust
bob.set_age(33);
// Updates Bob's age to 33; happy birthday Bob!
```
