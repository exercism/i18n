# はじめに

`use`マクロを使うと、他のモジュールが提供する機能で自分のモジュールを手軽に拡張できます。モジュールを`use`すると、そのモジュールはこちらのモジュールにコードを注入できます。たとえば、関数を定義したり、他のモジュールを`import`や`alias`したり、モジュール属性を設定したりできます。

ExercismのElixirの演習のテストファイルを見たことがあれば、どれも`use ExUnit.Case`で始まっていることに気づいたはずです。このたった1行のコードが、テストモジュールで`test`マクロと`assert`マクロを使えるようにしています。

```elixir
defmodule LasagnaTest do
  use ExUnit.Case

  test "expected minutes in oven" do
    assert Lasagna.expected_minutes_in_oven() === 40
  end
end
```

## `__using__/1`マクロ

モジュールを`use`したときに何が起きるかは、そのモジュールの`__using__/1`マクロが決めます。このマクロは引数を1つ取り、それはオプションを並べたキーワードリストです。そして、[引用式][concept-ast]を返します。この引用式の中のコードが、`use`を呼び出したときにこちらのモジュールに挿入されます。

```elixir
defmodule ExUnit.Case do
  defmacro __using__(opts) do
    # some real-life ExUnit code omitted here
    quote do
      import ExUnit.Assertions
      import ExUnit.Case, only: [describe: 2, test: 1, test: 2, test: 3]
    end
  end
end
```

オプションは、`use`を呼び出すときの第2引数として渡せます。たとえば`use ExUnit.Case, async: true`のように書きます。明示的に渡さない場合は、空のリストが既定値になります。

[concept-ast]: https://exercism.org/tracks/elixir/concepts/ast
