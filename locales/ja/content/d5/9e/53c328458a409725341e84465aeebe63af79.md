# 概要

マッピングとは、関数をシーケンスの各要素に適用し、新しいシーケンスを作り出すことを指します。

`mapcar`を使うと、関数をオブジェクトの配列にマッピングできます。

```lisp
(mapcar #'double '(1 2 3 4)) ; => (2 4 6 8)
```

最初の引数が、呼び出す関数であることに注目してください。`#'`は、関数を指定するための特別なクォート構文です。（ここでは`'double`を使うこともできますが、`#'`を使うのが慣用的で、いわば「より正しい」書き方です。）

## 複数の配列

マッピングは、1つのシーケンスに関数を適用する場合に限りません。複数のシーケンスに対しても行えます。`N`個のシーケンスを渡す場合、関数は`N`個の引数を受け取る必要があります。

```lisp
(mapcar #'list '(1 2) '(a b) '("foo" "bar")) ; => ((1 a "foo") (2 b "bar"))
```

## その他のマッピング関数

`mapcar`のほかにも、配列をマッピングするための関数がいくつかあります。`mapcar`が最もよく使われるのは間違いありませんが、ほかの関数についても知っておくとよいでしょう。

`maplist`は`mapcar`と似た働きをしますが、要素ではなく、連続する部分配列に対して処理を行います。最初は配列全体、次に`cdr`、さらにその`cdr`、というように進みます。

```lisp
(maplist #'identity '(a b c)) ; => ((A B C) (B C) (C))
```

`mapc`と`mapl`は、それぞれ`mapcar`と`maplist`に似ていますが、結果を集めず、代わりに最初の配列を返します。これは副作用を目的とする操作で使います。

`mapcan`と`mapcon`は`mapcar`と`maplist`に似ていますが、結果は`nconc`によって平坦化されます。`nconc`は`append`に似ていますが、最後の引数以外を破壊的に変更します。

## その他のシーケンスへのマッピング

マッピングは[配列][concept-lists]に限られません。（別のコンセプトで扱う）どんなシーケンスでもマッピングできます。配列以外のシーケンスの場合は、`map`関数を使います。

`map`は3つ以上の引数を取ります。

- 1つ目は、結果のシーケンスの型です
- 2つ目は、適用する関数です
- 3つ目以降は、操作の対象となるシーケンスです。

```lisp
(map 'list #'double '(1 2 3))        ; => (2 4 6)
(map 'string #'char-upcase "foobar") ; => "FOOBAR"
```

特殊なケースとして、結果のシーケンスの型に`nil`を指定すると、`nil`が返されます。これ（および上記の`mapc`と`mapl`）は、副作用のために使われます。
