# はじめに

## 正規表現

**正規表現**（regex）とは、テキスト内で検索パターンを指定する文字の並びです。

正規表現の構文を覚えることは、このトピックの範囲を超えています。
ここでは、正規表現を利用するために`jq`が提供している式に焦点を当てます。

### 正規表現の方言

ツールによって、実装されている正規表現のバージョンが異なります。
`jq`は[Oniguruma][oniguruma]という正規表現ライブラリを組み込んでおり、これはPerl v5.8の正規表現とほぼ互換性があります。

`jq`が使う具体的な構文は、[OnigurumaのGitHubリポジトリーで確認できます][onig-syntax]。

<!-- prettier-ignore -->
~~~~exercism/caution
`jq`には、正規表現のための特別な構文はありません。
正規表現は、単に文字列として表されます。
つまり、正規表現内のバックスラッシュは、文字列の中でエスケープする必要があります。

たとえば、数字の文字クラス（`\d`）は`"\\d"`と書く必要があります。
~~~~

<!-- prettier-ignore-end -->

### 正規表現の関数

`jq`の正規表現は、[一連のフィルター][jq-regex-funcs]に限られています。

#### 単純なマッチング

文字列がパターンに一致するかどうかを知りたいときは、`test`フィルターを使います。

```jq
STRING | test(REGEX)
STRING | test(REGEX; FLAGS)
STRING | test([REGEX, FLAGS])
```

このフィルターは、_真偽値_を出力します。

```jq
"Hello World!" | test("W")    # => true
"Goodbye Mars" | test("W")    # => false
```

#### マッチに関する情報

実際にパターンに一致した部分文字列を取り出したいときは、`match`フィルターを使います。

```jq
STRING | match(REGEX)
STRING | match(REGEX; FLAGS)
STRING | match([REGEX, FLAGS])
```

このフィルターは、次のいずれかを出力します。

- 一致しなかった場合は、何も出力しません。
- 一致した場合は、さまざまなプロパティを含むオブジェクトを出力します。

この例では、後方参照の構文`\1`を使って、連続する2つの同じ母音を探します。

```jq
"Hello World!" | match("([aeiou])\\1")
# => empty

"Goodbye Mars" | match("([aeiou])\\1")
# => {
#      "offset": 1,
#      "length": 2,
#      "string": "oo",
#      "captures": [
#        {
#          "offset": 1,
#          "length": 1,
#          "string": "o",
#          "name": null
#        }
#      ]
#    }
```

`match`フィルターは、一致する_たびに_オブジェクトを返します。
次の例では、`"g"`フラグを使ってすべての母音を見つけています。

```jq
"Goodbye Mars" | match("[aeiou]"; "g")
# => { "offset": 1, "length": 1, "string": "o", "captures": [] }
#    { "offset": 2, "length": 1, "string": "o", "captures": [] }
#    { "offset": 6, "length": 1, "string": "e", "captures": [] }
#    { "offset": 9, "length": 1, "string": "a", "captures": [] }
```

#### キャプチャした部分文字列

`match`フィルターと同様に、`capture`フィルターも一致した場合はオブジェクトを返します。

```jq
STRING | capture(REGEX)
STRING | capture(REGEX; FLAGS)
STRING | capture([REGEX, FLAGS])
```

返されるオブジェクトは、**名前付きキャプチャ**のマッピングです。

```jq
"JIRAISSUE-1234" | capture("(?<project>\\w+)-(?<issue_num>\\d+)")
# => {
#      "project": "JIRAISSUE",
#      "issue_num": "1234"
#    }
```

#### 部分文字列だけを取り出す

`scan`フィルターは、`"g"`フラグを付けた`match`に似ています。

```jq
STRING | scan(REGEX)
STRING | scan(REGEX; FLAGS)
```

`scan`は部分文字列の_ストリーム_を出力します。

```jq
"Goodbye Mars" | scan("[aeiou]")
# => "o"
#    "o"
#    "e"
#    "a"
```

部分文字列をまとめて取り出すには、`[...]`という配列コンストラクターを使います。

```jq
"Goodbye Mars" | [ scan("[aeiou]") ]
# => ["o", "o", "e", "a"]
```

#### 文字列の分割

文字列のうち**残したい**部分がわかっているときは、`match`または`scan`を使います。
**捨てたい**部分がわかっているときは、`split`を使います。

```jq
STRING | split(REGEX; FLAGS)
```

<!-- prettier-ignore -->
~~~~exercism/caution
**引数を1つだけ取る**`split`フィルターは、その引数を**固定文字列**として扱います。

`split`で正規表現を使うには、**必ず**2番目の引数を指定する必要があります。空文字列を指定してもかまいません。
~~~~

<!-- prettier-ignore-end -->

任意の空白文字で文字列を分割する例です。

```jq
"first   second           third fourth" | split("\\s+"; "")
# => ["first", "second", "third", "fourth"]
```

#### 置換

`sub`と`gsub`フィルターは、入力文字列を変換し、一致した部分を置換文字列に置き換えることができます。

最初に一致した部分だけを置き換えるには、`sub`を使います。
一致したすべての部分を置き換えるには、`gsub`を使います。

```jq
STRING | sub(REGEX; REPLACEMENT)
STRING | sub(REGEX; REPLACEMENT; FLAGS)
STRING | gsub(REGEX; REPLACEMENT)
STRING | gsub(REGEX; REPLACEMENT; FLAGS)
```

```jq
"Goodnight kittens. Goodnight mittens." | sub("night"; " morning")
# => "Good morning kittens. Goodnight mittens."

"Goodnight kittens. Goodnight mittens." | gsub("night"; " morning")
# => "Good morning kittens. Good morning mittens."
```

置換テキストでは、一致した部分文字列を参照できます。名前付きキャプチャと[文字列補間][jq-interp]を使います。

```jq
"Some 3-letter acronyms: gnu, csv, png"
| gsub( "\\b(?<tla>[[:alpha:]]{3})\\b";     # find words 3 letters long
        "\(.tla | ascii_upcase)" )          # upper-case the match
# => "Some 3-letter acronyms: GNU, CSV, PNG"
```

### フラグ

上記のすべてのフィルターで、FLAGSは、対応しているフラグを0個以上並べた文字列です。

- `g` - グローバル検索（最初の1つだけでなく、すべての一致を探します）
- `i` - 大文字と小文字を区別しない検索
- `m` - 複数行モード（'.'が改行に一致します）
- `n` - 空の一致を無視します
- `p` - sモードとmモードの両方が有効になります
- `s` - 単一行モード（'^' -> '\A'、'$' -> '\Z'）
- `l` - 最も長い一致を探します
- `x` - 拡張正規表現フォーマット（空白とコメントを無視します）

たとえば

```jq
"JIRAISSUE-1234" | capture("(?<project>\\w+)-(?<issue_num>\\d+)")

# or with Extended formatting

"JIRAISSUE-1234" | capture("
                     (?<project>   \\w+ )  # the Jira project
                     -                     # followed by a hyphen
                     (?<issue_num> \\d+ )  # followed by digits
                   "; "x")
```
