# 説明

この演習では、2012年9月15日にオープンしたニューヨークの美容サロン向けの、予約スケジューラーに取り組みます。

4つのタスクがあり、どれも予約の日付を扱います。日付と時刻は、次の3つの形式のいずれかを使います:

- `"7/25/2019 13:45:00"`
- `"July 25, 2019 13:45:00"`
- `"Thursday, July 25, 2019 13:45:00:00"`

~~~~exercism/caution
テストは自動的にカルチャを`en-US`に設定します。カルチャを自分で設定したり指定したりする必要はありません。
~~~~

## 1. 予約日を解析する

`schedule`関数を実装して、予約日のテキスト表現を対応する`DateTime`形式に解析できるようにしましょう:

```fsharp
schedule "7/25/2019 13:45:00"
// => DateTime(2019, 7, 25, 13, 45, 0)
```

## 2. 予約がすでに過ぎているか確認する

`hasPassed`関数を実装して、予約日を受け取り、その予約が過去のどこかで過ぎているかどうかを確認しましょう:

```fsharp
hasPassed (DateTime(1999, 12, 31, 9, 0, 0))
// => true
```

## 3. 予約が午後かどうか確認する

`isAfternoonAppointment`関数を実装して、予約日を受け取り、その予約が午後（12:00以降、18:00未満）かどうかを確認しましょう:

```fsharp
isAfternoonAppointment (DateTime(2019, 03, 29, 15, 0, 0))
// => true
```

## 4. 予約の時刻と日付を説明する

`description`関数を実装して、予約日を受け取り、その日付と時刻の説明を返すようにしましょう:

```fsharp
description (DateTime(2019, 03, 29, 15, 0, 0))
// => "You have an appointment on 3/29/2019 3:00:00 PM."
```

## 5. 記念日を返す

`anniversaryDate`関数を実装して、今年の記念日である9月15日を返すようにしましょう:

```fsharp
anniversaryDate()
// => DateTime(2019, 9, 15, 0, 0, 0)
```
