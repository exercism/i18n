# はじめに

_クラス_のインスタンスを作るには、`new`演算子を使ってその_コンストラクター_を呼び出します。コンストラクターは、新しく作られたインスタンスを初期化することを目的とした、特別な種類のメソッドです。コンストラクターは通常のメソッドとよく似ていますが、戻り値の型を持たず、名前がクラス名と一致するという点が異なります。

```csharp
class Library
{
    private int books;

    public Library()
    {
        // Initialize the books field
        this.books = 10;
    }
}

// This will call the constructor
var library = new Library();
```

通常のメソッドと同じように、コンストラクターにも仮引数を指定できます。コンストラクターの仮引数は、あとから参照できるように（`private`な）フィールドとして保存するのが一般的です。あるいは、その場限りの計算に使われるだけのこともあります。引数は、通常のメソッドに引数を渡すときと同じように、コンストラクターにも渡すことができます。

```csharp
class Building
{
    private int numberOfStories;
    private int totalHeight;

    public Building(int numberOfStories, double storyHeight)
    {
        this.numberOfStories = numberOfStories;
        this.totalHeight = numberOfStories * storyHeight;
    }
}

// Call a constructor with two arguments
var largeBuilding = new Building(55, 6.2)
```
