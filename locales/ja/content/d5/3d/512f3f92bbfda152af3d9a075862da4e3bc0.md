# コマンドラインでのテスト

テストは次のコマンドで実行します。

```bash
scarb cairo-test
```

最初のテスト以外はすべて無視されるようになっています。最初のテストに合格したら、`tests`ディレクトリーにあるテストのソースファイルを開き、次のテストの`#[ignore]`フラグを外して、もう一度テストに合格させましょう。それぞれのテストは、上に`#[test]`フラグが付いた関数です。すべてのテストに合格するまで、これを繰り返します。

テストのソースファイルを編集せずに_すべて_のテストを実行したい場合は、次のようにします。

```bash
scarb cairo-test --include-ignored
```

無視されているかどうかに関わらず、特定のテスト（たとえば`some_test`）を実行するには、次のようにします。

```bash
scarb cairo-test -f some_test
```

Cairoのテストについて詳しく知りたい場合は、オンラインの[テストのドキュメント][cairo-tests]を参照してください。

[cairo-tests]: https://book.cairo-lang.org/ch10-01-how-to-write-tests.html
