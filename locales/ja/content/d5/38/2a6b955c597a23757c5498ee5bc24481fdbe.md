# 概要

Cは静的型付け言語です。つまり、コンパイル時にすべてのものに型があります。変数の名前を決めてその型を設定することを、変数の宣言といいます。

変数を宣言するには、型を明示的に指定します。変数の名前には、英字かアンダースコアで始まるなど、[従わなければならないルール][name-rules]があります。一部の名前は、[キーワード][reserved-keywords]や[その他の識別子][reserved-identifiers]として予約されているため、使えません。

変数の設定や更新は、変数への代入によって行います。値を設定すると、その変数が定義されます。変数を定義することを、初期化ともいいます。

```c
int foo;      // Declare an integer named var
foo = 10;     // Define the variable

int bar = 15; // Both can also be done in a single statement
```

変数の値は、[`=`単純代入演算子][assignment-operator]を使って代入したり更新したりできます。一度定義した変数の型は、決して変わりません。

```c
int foo = 10; // Assign initial value
foo = 25;     // Update to new value

foo = false;  // Compiler error when assigning value of a different type
```

Cは[命令型][imperative]の[手続き型][procedural]言語です。すべての計算は、1つまたは複数の[関数][function]の一部である一連の[文][statements]として行われます。

各関数は、0個以上の[仮引数][parameters]を持てます。関数を定義するときは、すべての仮引数と戻り値の型を明示的に指定しなければなりません。値は、[`return`キーワード][return-keyword]を使って関数から返します。関数はデフォルトで外部[記憶クラス][storage_class]を持ちます。つまり、プログラムが動いている間ずっと存在し、ファイルの外部からも見えるということです。これを防ぐには、`static`キーワードを付けて内部からの可視性を指定します。

```c
static int add(int x, int y) {
  return x + y;
}
```

上の例では、変数`x`と`y`はその関数の中でしか使えません。つまり、関数スコープを持ちます。[スコープ][scope]とは、名前（プログラムの要素の名前）に結び付いた値が、それが定義されたコードの「範囲」の中でしかアクセスできないという考え方です。Cの主なコードの範囲は次のとおりです。

- ファイル
- 関数
- ブロック（ループやその他の構文の中など）

関数を呼び出すには、関数名を指定し、各仮引数に対応する引数を渡します。

```c
int sum = add(1, 2);
```

Cは2種類の[コメント][comments]をサポートしています。1行コメントは`//`で始まり（C99以降）、複数行コメントは`/*`と`*/`の間に書きます。
