# 説明

ある基数で桁の並びとして表された数値を、別の基数に変換します。

一般的な基数変換を実装しましょう。
基数**a**で桁の並びとして表された数値が与えられたとき、それを基数**b**に変換します。

## 注意

- 変換は自分で実装してみましょう。
  変換を代わりにやってくれる何かを使わないでください。

## [位取り記数法][positional-notation]について

位取り記数法では、基数**b**の数値は、**b**の累乗の線形結合として理解できます。

*基数10*の数値42は、次の意味です。

`(4 * 10^1) + (2 * 10^0)`

*基数2*の数値101010は、次の意味です。

`(1 * 2^5) + (0 * 2^4) + (1 * 2^3) + (0 * 2^2) + (1 * 2^1) + (0 * 2^0)`

*基数3*の数値1120は、次の意味です。

`(1 * 3^3) + (1 * 3^2) + (2 * 3^1) + (0 * 3^0)`

もうおわかりですね！

*そうです。上の3つの数値はまったく同じものです。おめでとうございます！*
