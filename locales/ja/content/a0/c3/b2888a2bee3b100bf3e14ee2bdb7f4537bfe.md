# はじめに

C#の数値には、大きく分けて次の2種類があります：

- 整数：小数点以下の桁がない数値（つまり、端数のない数）です。例としては、`-6`、`0`、`1`、`25`、`976`、`500000`があります。
- 浮動小数点数：小数点以下の桁が0個以上ある数値です。例としては、`-2.4`、`0.1`、`3.14`、`16.984025`、`1024.0`があります。

C#で最もよく使われる数値型は、`int`と`double`の2つです。`int`は32ビットの整数で、`double`は64ビットの浮動小数点数です。

計算には、標準的な算術演算子を使います。数値の比較には、標準的な数値比較演算子や、等値演算子（`==`）と非等値演算子（`!=`）を使います。

C#の数値変換には、次の2種類があります：

1. 暗黙的な変換：データが失われることはなく、追加の構文も必要ありません。
2. 明示的な変換：データが失われる可能性があり、_キャスト_という追加の構文が必要です。

`int`は`double`よりも精度が低いため、`int`から`double`への変換は安全であり、暗黙的な変換になります。一方、`double`から`int`への変換はデータが失われる可能性があるため、明示的な変換が必要です。

```csharp
int softCool = 1358938113;
double notLost = 4.8151623;

// implicit cast: no loss of information
double macDebug = softCool;         // 1358938113.0

// explicit cast: possible loss of information 
int somethingLost = (int)notLost;   // 4
```
