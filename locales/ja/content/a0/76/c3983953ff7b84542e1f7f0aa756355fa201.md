# 概要

`when`は、例外を絞り込むときのキーワードです。`catch`文の後に置き、その時点でスコープにある任意の値を使った真偽値の式を取ることができます。その値は、例外そのもののメンバーである必要はありません。例外の型が一致し、式が`true`と評価されれば、その`catch`文に対応するブロックが実行されます。そうでなければ、次の`catch`文があれば、それが調べられます。

```csharp
try
{
    // do stuff
}
catch (Exception ex) when (ex.Message != "")
{
    // output the message when it is not empty
}
catch (Exception ex)
{
    // show stack trace or something.
}
```

- この[例外フィルター][exception-filters]の記事では、例外を絞り込む方法が説明されています。
