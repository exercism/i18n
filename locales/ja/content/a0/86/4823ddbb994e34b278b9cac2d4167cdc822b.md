# 説明の補足

## Prologで日付を扱う

Prologに標準で用意されている日付のサポートは[かなり初歩的です][built-in-dates-support]。日付をもっと快適に扱うには、[date_timeパッケージ][date_time-package]を使う方法があります。

### date_timeパッケージのインストール

インストールされているSwiplのバージョンが十分に新しい場合は、次のコマンドを実行するとパッケージをインストールできます。

```bash
swipl pack install date_time
```

うまくいかない場合は、こちらを実行してみてください。

```shell
swipl -g 'pack_install(date_time)'
```

~~~~exercism/note
オンラインエディターを使っている場合は、手動でインストールする必要はありません。
~~~~

### date_timeパッケージを使う

`date_time`パッケージを使うには、解答ファイルの先頭に次のコードを追加してください。

```prolog
:- use_module(library(date_time)).
```

~~~~exercism/note
ヒント：[date_timeパッケージのソース][https://www.swi-prolog.org/pack/file_details/date_time/prolog/date_time.pl?show=src]はドキュメントが充実しているので、きっと役に立ちます！
~~~~
