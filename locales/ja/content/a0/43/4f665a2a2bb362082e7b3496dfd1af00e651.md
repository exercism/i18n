# はじめに

Haxeでは、**配列**とは（たいていは）同じ型の要素をまとめたものです。Haxeで配列を作る方法は3つあり、コンストラクターを使う方法と、宣言の構文を使う方法があります。Haxeでは、配列の最初の要素のインデックスは0です。

```haxe
var a = [1, 2, 3];
trace(a); // [1,2,3]

// Here the second element is called by index
trace(a[1]); // 2

// The actual first element's index is 0
trace(a[0]); // 1
```

コンストラクターを使って配列を作るには、配列に入れる要素の型を渡す必要があります。

```haxe
var a:Array<Int> = [0, 1, 2, 3];
a[1] = "Hello"; // Error: the array a takes integers only
```

配列に複数の型の要素を入れたいときは、型の指定に`Dynamic`型を追加します。

```haxe
var a:Array<Dynamic> = [10, "Bob", true]
```
