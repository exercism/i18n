# 説明

この演習では、お気に入りの料理本から最高のラザニアを作るためのコードを書いていきます。

ラザニアの調理にかかる時間に関する、4つのタスクがあります。

## 1. オーブンでの想定加熱時間を分単位で定義する

`expectedMinutesInOven()`メソッドを定義しましょう。このメソッドは入力を受け取らず、ラザニアをオーブンに入れておくべき時間を分で返します。料理本によると、オーブンでの想定加熱時間は40分です。

```java
Lasagna lasagna = new Lasagna();
lasagna.expectedMinutesInOven();
// => 40
```

## 2. 残りのオーブン加熱時間を分単位で計算する

`remainingMinutesInOven()`メソッドを定義しましょう。このメソッドは、ラザニアを実際にオーブンに入れておいた時間を分で入力として受け取り、前のタスクで求めた想定加熱時間をもとに、ラザニアをあと何分オーブンに入れておく必要があるかを返します。

```java
Lasagna lasagna = new Lasagna();
lasagna.remainingMinutesInOven(30);
// => 10
```

## 3. 準備時間を分単位で計算する

`preparationTimeInMinutes()`メソッドを定義しましょう。このメソッドは、ラザニアに重ねた層の数を入力として受け取り、ラザニアの準備にかかった時間を分で返します。1層あたり2分かかるものとします。

```java
Lasagna lasagna = new Lasagna();
lasagna.preparationTimeInMinutes(2);
// => 4
```

## 4. 合計作業時間を分単位で計算する

`totalTimeInMinutes()`メソッドを定義しましょう。このメソッドは2つの入力を受け取ります。1つ目は、ラザニアに重ねた層の数です。2つ目は、ラザニアをオーブンに入れておいた時間を分で表したものです。この関数は、ラザニアの調理にかかった合計時間を分で返します。合計時間は、準備にかかった時間と、その時点でラザニアがオーブンに入っていた時間を足したものです。

```java
Lasagna lasagna = new Lasagna();
lasagna.totalTimeInMinutes(3, 20);
// => 26
```
