# 説明

近くに「Tech Palace」という家電量販店があります。
店のオーナーは最近、マーケティングメッセージの表示や、お客さんが入口でポイントカードをスキャンしたときに特別な挨拶を表示するために、大きなディスプレイを設置しました。
このディスプレイはたくさんの小さなLEDライトでできていて、複数行のテキストを表示できます。

店のオーナーは、新しいディスプレイのテキストを生成するコードについて、助けを求めています。

## 1. ウェルカムメッセージを作成する

<!-- markdownlint-disable-next-line MD038 -->
ポイントカードをスキャンするほとんどのお客さんに対して、店のオーナーは、ディスプレイに`Welcome to the Tech Palace, `と、それに続けてお客さんの名前を大文字で表示したいと考えています。

お客さんの名前を短い文字列（`felt252`）の引数として受け取り、目的のメッセージを`ByteArray`として返す関数`welcome_message`を実装してください。

```rust
welcome_message("Judy")
// => Welcome to the Tech Palace, JUDY
```

## 2. 飾りの枠を追加する

店でたくさん買い物をする常連のお客さんのために、オーナーは、ウェルカムメッセージの前後に星の行を追加して、ウェルカム表示をより華やかにしたいと考えています。
星の行にいくつの星を入れるかはまだ決めていないため、その数を設定できるようにしたいと考えています。

ウェルカムメッセージ（`ByteArray`）と、1行あたりの星の数（型`u32`）を引数として受け取る関数`add_border`を書いてください。
この関数は3行からなる`ByteArray`を返します。1行目は指定した数の星、2行目は渡されたままのウェルカムメッセージ、3行目はもう1行の星です。

```rust
add_border("Welcome!", 10)
```

次のようになります。

```bash
**********
Welcome!
**********
```

## 3. 古いマーケティングメッセージをきれいにする

この新しいディスプレイを設置する前は、店には似たようなディスプレイがあり、変更できない固定の行しか表示できませんでした。
オーナーは、古いマーケティングメッセージの一部を新しいディスプレイで再利用したいと考えています。
しかし、そのデータにはすでに星の枠と、いくつかの厄介な空白文字が含まれています。
ここでの課題は、メッセージを再利用できるようにきれいにすることです。

古いマーケティングメッセージを`ByteArray`として受け取る関数`clean_up_message`を実装してください。
この関数はまず、テキストからすべての星を取り除き、その後、残ったテキストの先頭と末尾の空白文字を取り除きます。
そして、きれいにしたメッセージを返します。

```rust
let message: ByteArray = "
**************************
*    BUY NOW, SAVE 10%   *
**************************
";

clean_up_message(message)
// => BUY NOW, SAVE 10%
```
