# 参考資料

Luaを学べる優れた無料のオンライン資料はたくさんあります。

1.  [lua.org][8]
2.  Luaの設計者による、Luaプログラミングのあらゆる側面を網羅した、詳細で信頼できる入門書として特におすすめです：[Programming in Lua（Roberto Ierusalimschy著）][6]
3.  Lua言語の公式な定義については、R. Ierusalimschy、L. H. de Figueiredo、W. Celesによる[Lua 5.4 Reference Manual][7]を参照してください。
4.  [Lua Style Guide][4]
5.  [Learn Lua in 15 minutes][5]
6.  [lua-users.org][14]のwikiは見た目はあまりよくありませんが、役に立つ情報や知識がたくさん詰まっています
7.  リンティングの選択肢
    -   [luacheck][12]
    -   [Detecting Undefined Variables][13]
8.  Lua向けのLanguage Server Protocol実装
    -   [Lua Language Server][9]
    -   [EmmyLua-LanguageServer][10]
