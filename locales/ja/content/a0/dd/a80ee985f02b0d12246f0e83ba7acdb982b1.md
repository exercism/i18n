# 説明

庭に何羽の鳥がやってくるかを記録している、熱心なバードウォッチャーです。
ふだんはノートに正の字を書いて鳥の数を数えていますが、もっとデータをうまく扱いたいと考えています。
ノートに付けていた過去数週間の1日ごとの鳥の数は、すでにデータ化してあります。

ここからは、数えた鳥の合計を求めたり、特定の週の鳥の数を計算したり、数え間違いを修正したりします。

## 1. これまでに数えた鳥の合計を求める

まずは全体像をつかむことから、データの分析を始めましょう。
記録を始めてから数えた鳥が全部で何羽になるかを調べます。

1日ごとの鳥の数を持つ配列のようなオブジェクトを受け取る関数`totalBirdCount`を実装します。
数えた鳥の合計を戻り値として返します。

```javascript
birdsPerDay = [2, 5, 0, 7, 4, 1, 3, 0, 2, 5, 0, 1, 3, 1];
totalBirdCount(birdsPerDay);
// => 34
```

## 2. 特定の週にやってきた鳥の数を計算する

鳥の数の全体像がつかめたので、次はもっと細かく分析してみましょう。

1日ごとの鳥の数の配列のようなオブジェクトと、週番号を受け取る関数`birdsInWeek`を実装します。
その週に数えた鳥の合計を返します。
週は常に完全に記録されているものとします。

```javascript
birdsPerDay = [2, 5, 0, 7, 4, 1, 3, 0, 2, 5, 0, 1, 3, 1];
birdsInWeek(birdsPerDay, 2);
// => 12
```

## 3. 数え間違いを修正する

鳥をずっと記録しているあいだ、庭の遠くの隅に1羽が隠れていたことに気づきました。
その鳥は、1日おきに必ず庭で過ごしていたことがわかりました。
その間の日にどこにいたのかは正確にはわかりませんが、庭にいなかったことは確かです。
バードウォッチャーとしての勘から、リストで記録を始めた最初の日には、その鳥が庭にいたこともわかります。

この新しい情報をもとに、1日ごとに数えた鳥の配列のようなオブジェクトを引数に取る関数`fixBirdCountLog`を書きます。与えられた配列を変更して、数え間違いを修正します。

```javascript
birdsPerDay = [2, 5, 0, 7, 4, 1];
fixBirdCountLog(birdsPerDay);
// => [3, 5, 1, 7, 5, 1]
```
