# 説明の補足

## レジスタ

| レジスタ | 用途        | 型      | 説明                          |
| -------- | ----------- | ------- | ----------------------------- |
| `$a0`    | 入力        | アドレス | null終端された入力文字列       |
| `$a1`    | 入力        | 整数    | シフト量                      |
| `$a2`    | 入力/出力   | アドレス | null終端された結果文字列       |
| `$t0-9`  | 一時        | 任意    | 一時的な保存用                |
