# 概要

**クロージャ**は[Clojureでの][clojure-guide-closures]プログラミングのパターンのひとつで、外側の[レキシカルスコープ][wiki-lexical-scope]にある変数を関数の内部で使えるようにするものです。Clojureはクロージャを意識させることなくサポートしているので、それが何なのかを知らないまま使われることもよくあります。

```clojure
;; Top-level definitions are global-scope
(def dozen 12)

;; Functions create a new scope.
;; Referencing the outer variable here is a closure.
(fn [n] (* dozen n))
```

## 状態を保存し、値を受け渡すクロージャ

アトムを使うと、状態を保持できます。

```clojure
;; This function closure increments the counter's state
;; in the outer lexical context.
;; This way the counter can be shared between many calling contexts.

(def increment
  (let [counter (atom 0)]
    (fn [] (swap! counter inc))))
```

`increment`を呼び出すたびに、カウンターが1ずつ増えていきます。

``` clojure
(increment)
;;=> 1
(increment)
;;=> 2
```
