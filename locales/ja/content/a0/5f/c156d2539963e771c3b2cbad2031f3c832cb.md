# はじめに

## モジュール

モジュールは、関連するコードをまとめて名前の衝突を避けるための仕組みで、ごく単純なコードベースを除けば、たいていどのコードベースにも登場します。

構文は次のとおりです。

```rust
mod my_module {
    pub struct MyStruct {}

    pub struct OtherClass {}
}
```

モジュールのスコープの外では、モジュールに含まれる型を参照するときに、型名の前にダブルコロン`::`を付けます。
あるいは、こちらのほうが一般的ですが、ファイルの先頭（またはモジュールの中）に`use`ディレクティブを置けば、型を接頭辞なしで使えるようになります。
同じモジュールの中では、型名を修飾する必要はありません。

```rust
mod my_module {
    #[derive(Drop)]
    pub struct MyStruct {}

    pub struct Foo {}

    #[generate_trait]
    pub impl FooImpl of FooTrait {
        fn bar() {
            let baz = MyStruct {};
        }
    }
}

#[derive(Drop)]
pub struct Qux {}

#[generate_trait]
impl QuxImpl of QuxTrait {
    fn box() {
        let nux = my_module::MyStruct {};
    }
}

mod other_module {
    use super::my_module::*;

    #[derive(Drop)]
    pub struct Tix {}

    #[generate_trait]
    pub impl TixImpl of TixTrait {
        fn jeg() {
            let lor = MyStruct {};
        }
    }
}
```

`use core::array::ArrayTrait as Arr;`という構文を使えば、モジュールや型に別名を付けられます。そうすれば、そのモジュールや型を使える場所ならどこでも、別名を使えます。
