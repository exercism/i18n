# はじめに

[`function`][function]とは、コードをひとまとまりに分けて、プログラムの1か所または複数の場所から名前で呼び出せるようにする方法です。関数は、特定の作業や繰り返し行う作業を実行するために使われます。

より正式に言うと、関数とは、[`function call`][calls]の操作を適用できるあらゆるPythonオブジェクトです。関数は、何らかの操作の結果として1つまたは複数の値を[`return`][return]するために使うこともあれば、1つまたは複数の[`side effects`][side effects]のために使うこともあります。関数が戻り値を指定していなくても、その関数は`None`を返します。

以下は、副作用のある関数の例です。

```python
>>> def hello():
...     print("Hello")
...
>>> hello()
Hello

```

上の例では、[`def`][def]キーワードで関数定義の始まりを示しています。`hello`は関数の名前です。空の括弧（`()`）は、関数に値が何も渡されていないことを表します。関数の本体は、`print("Hello")`という1つの文です。`print`も関数です。`print`関数の括弧の中にある`"Hello"`は、[`argument`][arguments]と呼ばれます。`print`関数は、この引数を使って何を出力するかを判断します。関数の本体がインデントされていることに注目してください。インデントは重要です。Pythonはインデントによって、そのコードブロックがどこで終わるかを判断するからです。関数の本体は、プログラムの終わりか、インデントされて_いない_次のコード行の直前で終わります。`hello()`は`return`の値を指定していないので、副作用（`print()`の呼び出し）を実行してから、`None`を返します。最後に、関数の名前と括弧を使ってその関数を呼び出します。これにより、この名前が_呼び出し可能_であることがPythonのインタプリターに伝わります。

以下は、戻り値のある関数の例です。

```python
>>> def hello():
...     return "Hello"
... 
print(hello())
Hello

```

この関数の本体は、`print`を_呼び出す_ことから、"Hello"という`string`を_返す_ことに変わりました。最終的に、コードはやはり`"Hello"`を出力しますが、副作用は`hello`関数の中ではなく、_呼び出し側のコード_で起こります。`hello`関数を呼び出すときに括弧を付け忘れると（たとえば`print(hello)`）、`print`は次のようなものを出力します。

```
<function hello at 0x0000026E18E93E20>
```

関数が引数を受け取らない場合（_つまり仮引数がない場合_）でも、正しく_呼び出す_には空の括弧を使わなければならない、という点が重要です。これは、引数のない関数を呼び出すときに空の括弧を必要としない、Rubyのような言語とは異なります。

関数は、0個以上の[`parameters`][parameters]を定義できます。仮引数は、その関数がどんな引数を受け取るかを定義します。

以下は、引数を受け取る関数の例です。

```python
>>> def hello(name):
...     return f"Hello, {name}"
... 
>>> print(hello("Bob"))
Hello, Bob

```

仮引数は`name`として定義されています。`"Bob"`は、プログラムが`hello`関数に渡す引数です。この関数は、"Hello, Bob"という`string`を_返します_。

`hello`を引数なしで呼び出したらどうなるでしょうか？　プログラムはエラーを出します。

```python
print(hello())
Traceback (most recent call last):

  Input In in <line: 1>
    print(hello())

TypeError: hello() missing 1 required positional argument: 'name'
```

引数なしで呼び出したときにプログラムがエラーになるのを避けたい場合（_ただし、呼び出し側のコードが引数を渡さなくてもよいようにしたい場合_）は、[デフォルト引数][default arguments]を定義できます。デフォルト引数は、関数を呼び出すときに引数が省略された場合に、どんな値を使うかを定義します。

以下は、デフォルト引数のある関数の例です。

```python
>>> def hello(name="you"):
...     return f"Hello, {name}"
... 
>>> print(hello())
Hello, you

```

`name`仮引数にはデフォルト引数として`"you"`が与えられているので、`name`引数が渡されなければ、プログラムは`Hello, you`を出力します。

関数の引数についてさらに詳しく知りたい場合は、[関数の引数][function arguments]のコンセプトを参照してください。
