# 無名関数とクロージャについて

PHPでは、関数の中で関数を宣言できます。こうした関数には名前を付ける必要はありませんが、変数に代入したり、関数を入力として受け取る別の関数へ直接渡したりすることもできます。

```php
function onlyOdds(array $numbers): array
{
    return array_filter($numbers, function($num) {
        return $num % 2 === 1;
    });
}
```

上の例で定義され、`array_filter`に渡されている関数が無名関数です。`array_filter`はこれを使って、配列の中のそれぞれの値が`array_filter`の結果に含まれるかどうかを判断します。ある値に対してこの関数が`true`を返せば、その値は結果の配列に含まれます。

無名関数を使うと、関数の外側のスコープにある変数を、関数の内側から参照することもできます。これは、関数が使う変数の上に関数のスコープが「閉じる」ことだと考えられており、「クロージャ」という名前はここから来ています。言語によっては、スコープ内にあるすべての変数をクロージャの中で自動的に使えます。PHPでは、現在のオブジェクトを指す`$this`はクロージャの中で自動的に使えますが、それ以外の変数はすべて、`use`キーワードを使って明示的に参照する必要があります。

```php
function makeAdderFunction(int $number) {
    return function(int $x) use($number) {
        return $x + $number;
    }
}

$add5 = makeAdderFunction(5);
echo $add5(4); // echos 9
```

上の`makeAdderFunction`では、渡された`$number`の値が、内部で定義されて戻り値として返される無名関数の中に「閉じ込められ」ます。すると、その関数が実行されるたびに、渡された`$number`の値を知ることができます。この関数を別の数値でもう一度呼び出すと、まったく別の関数が返されます。最初の呼び出しが返した値や機能が変わることはありません。クロージャに取り込みたい変数が複数ある場合は、`use`キーワードの中にカンマで区切って並べます。

PHPには、`arrow functions`と呼ばれる、より短い関数構文もあります。こちらは、ある程度単純なものに限られます。基本的な形は次のとおりです。

```php
fn(arguments) => expression
```

この書き方では、`use`を使う必要はありません。親スコープにある値は自動的に取り込まれます。また、アロー関数では式が自動的に戻り値となり、`return`キーワードを使う必要はありません。これを使うと、上の`onlyOdds`関数は次のように書き換えられます。

```php
function onlyOdds(array $numbers): array
{
    return array_filter($numbers, fn($n) => $n % 2 == 1);
}
```

上の`makeAdderFunction`も、次のように書き換えられます。

```php
function makeAdderFunction(int $number) {
    return fn(int $x) => $x + $number;
}
```

**注意：** 関数を式として書けない場合は、この短いアロー関数の構文は使えません。

変数は、無名関数やクロージャへ値渡しで渡され、その中でも値として使われます。つまり、関数の中で変数の値を変更しても、関数の外にある変数の値には影響しません。値を変更したい場合は、参照渡しで渡します。

```php
function positiveAverage(array $numbers): float
{
    $total = 0;
    $count = 0;
    return array_walk(
      $numbers,
      function($num) use (&$count, &$total) {
          $total += abs($num);
          $count++;
      }
    );
    return $total / $count;
}
```

上の例では、`array_walk`が配列の各要素を順に処理し、それぞれの値を呼び出しの中で宣言した関数に渡します。`$total`には、各数値の絶対値を足した合計が積み上がっていきます。また、数値がいくつあったかも数えています。どちらの値も、クロージャの中で参照渡しで使われています。これは、`use`の部分で各変数の前に付いている`&`で示されています。つまり、変数に加えられた変更は、`array_walk`が終わったあともそのまま残るので、この関数は配列内の数値の絶対値の平均を返すことができます。

無名関数とクロージャは、一つの場面でしか必要にならないかもしれない関数を定義したり、実際に関数を使うときとは別のタイミングで分かっている一連の入力をもとに、動的に関数を返す関数を定義したりするための便利な手段となります。
