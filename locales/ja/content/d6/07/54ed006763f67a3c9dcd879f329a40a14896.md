# 真偽値

Crystalには、[`Bool`][bools]という型があります。
これは`true`と`false`という値を表します。

## 論理演算子

Crystalには`!`、`||`、`&&`の3つの論理演算子があり、真偽値を組み合わせて、別の値を生み出す式を作ります。

### AND演算子（`&&`）

Crystalの[AND演算子][and]は`&&`で表され、両方の値が`true`なら`true`を返し、そうでなければ`false`を返します。
AND演算子を使うときは、`&&`の右側に一方の真偽値を、左側にもう一方の真偽値を置きます。

```crystal
true && true
# => true

true && false
# => false
```

### OR演算子（`||`）

Crystalの[OR演算子][or]は`||`で表され、与えられた値のうち**少なくとも1つ**が`true`なら`true`を返します。
両方の値が`false`なら、`false`を返します。
OR演算子を使うときは、`||`の右側に一方の真偽値を、左側にもう一方の真偽値を置きます。

```crystal
true || true
# => true

true || false
# => true

false || false
# => false
```

### NOT演算子（`!`）

CrystalのNOT演算子は`!`で表され、与えられた真偽値が`false`なら`true`を返し、`true`なら`false`を返します。
NOT演算子を使うときは、演算子（`!`）のあとに真偽値を1つ置きます。

```crystal
!true
# => false

!false
# => true
```

## 括弧（`()`）を使う

真偽値を扱うときは、括弧を使って、どの真偽値から先に評価するかを決められます。
括弧の使い方によって、結果が変わることがあります。
Crystalでは、括弧の中が先に評価されます。

```crystal
true && false && false || true
# => true

true && false && (false || true)
# => false
```

括弧の中が先に評価されるので、次の例では、NOT演算子は括弧の中の式に適用されます。

```crystal
!true && false
# => false

!(true && false)
# => true
```

~~~~exercism/note
括弧は、結果に影響するときだけ使いましょう。そうでない場合は省略します。
~~~~
