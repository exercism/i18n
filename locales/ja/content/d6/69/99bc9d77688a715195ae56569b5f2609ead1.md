# テスト

テストを実行する前に、インストール手順（具体的には`corepack yarn install`とEditor SDKのセットアップ）に従って、演習のフォルダーが正しくセットアップされていることを確認してください。

テストは次のコマンドで実行します：

```bash
$ corepack yarn test
```

eslintは、コードを静的解析してくれるツールです。他のユーザーと同じように、自分のコードがベストプラクティスに従っているか確認しましょう。このようなツールを使うと、コードのタイプミスやちょっとしたミスを早く見つけられます：

```bash
$ corepack yarn lint
```

または、両方を同時に実行することもできます：

```bash
$ corepack yarn test && corepack yarn lint
```

ExercismのTypeScriptトラックでは、コードの_スタイル_を強制していません。そのため、セミコロンを付けるか、タブとスペースのどちらを使うか、その中間を取るかなど、自由に選ぶことができます。

## 初めてのモジュールを作る

このトラックのテストは通常、あなたの実装をモジュールとしてインポートして読み込みます：`import Bob from './bob';`。
動作させるには、テストがモジュールを探すファイル、`bob.ts`から実装をエクスポートする必要があります：

```typescript
export class Bob {
  public hey(message: string) {
    // Your solution here
  }
}
```

各演習にはスタブを用意してあり、この`export`もあらかじめ書いてあります。
