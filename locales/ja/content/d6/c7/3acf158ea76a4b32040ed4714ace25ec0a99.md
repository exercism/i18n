# 指示の補足

## ワード

`linked-list-node`タプルを定義します。

`linked-list`タプルを定義し、`sequences`の`M: linked-list length`メソッドを用意して、テストがリストに対して直接`length`を呼び出せるようにします。

- `<linked-list> ( -- linked-list )`：空のリストを構築します。
- `>linked-list ( seq -- linked-list )`：`seq`の各要素を、順番に新しいリストへプッシュします。
- `linked-list>array ( linked-list -- array )`：値を、リストの先頭から順に返します。
- `list-push ( linked-list value -- linked-list )`：値を先頭にプッシュします。
- `list-pop ( linked-list -- linked-list value )`：先頭の値を取り除いて返します。
- `list-peek ( linked-list -- value )`：先頭の値を取り除かずに返します。
- `list-reverse ( linked-list -- linked-list )`：要素を逆順に並べたリストを返します。

リストが空のときは、`list-pop`と`list-peek`から`list-empty`エラークラスを投げます。
