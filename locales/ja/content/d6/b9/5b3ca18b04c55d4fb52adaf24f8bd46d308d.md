# 説明

この演習では、フリーランサーがプロジェクトマネージャーとやり取りするのを助けるコードを書きます。目的は、日額と月額をすばやく計算するためのいくつかのユーティリティを用意することです。割引が指定されていれば、それも適用できます。

まず、フリーランサーとプロジェクトマネージャーの間で、いくつかのルールを定めておきます。

- 日額は時給の8倍です。
- 1か月には請求可能な日が22日あります。

ときには、フリーランサーが日額に割引を適用することもあります（たとえば、最も忠実な顧客や非営利の顧客に対してなど）。

割引は、割合を表す小数として扱います。たとえば`25.0`（25%）です。

## 1. 時給から日額を計算する

`daily_rate`という関数を実装して、時給を入力として受け取り、日額を計算しましょう。
契約では、1日は請求可能な8時間と定められています。

```cpp
daily_rate(60)
// => 480.0
```

戻り値となる日額は、`double`型にしてください。

## 2. 割引後の価格を計算する

`apply_discount`という関数を実装して、割引後の価格を計算しましょう。
この関数は、元の価格とパーセントで表した割引率という2つの入力を受け取ります。

```cpp
apply_discount(150, 10)
// => 135.0
```

戻り値は必ず`double`型とし、一切丸めないでください。

## 3. 時給と割引から月額を計算する

`monthly_rate`関数を実装して、割引後の月額を計算しましょう。
この関数は、時給とパーセントで表した割引率という2つの入力を持ちます。

```cpp
monthly_rate(77, 10.5)
// => 12130
```

戻り値となる月額は、最も近い整数に切り上げてください（天井関数を取ります）。

## 4. 予算・時給・割引から、完了できる勤務日数を計算する

`days_in_budget`という関数を実装しましょう。この関数は予算・時給・割引を受け取り、何日分の仕事をまかなえるかを計算します。

```cpp
days_in_budget(20'000, 80, 11.0)
// => 35
```

戻り値となる日数は、次の整数に切り下げてください（床関数を取ります）。
