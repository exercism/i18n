# はじめに

*クォーテーション*、つまり`[ ]`の角括弧で囲んだコードは、数値や文字列と同じように、それ自体がFactorの値です。変数に保存したり、配列に入れたり、別のワードに渡したりでき、あとから*呼び出す*こともできます。

## `call`

`call`（[`kernel`][kernel]にあります）はクォーテーションを実行します。

```factor
3 4 [ + ] call .
! => 7
```

Factorがスタック効果を推論できない文脈でクォーテーションを`call`するときは、その効果を明示的に宣言しなければなりません。

```
call( stack-effect ) ! e.g. call( a b -- c )
```

```factor
: apply-binary ( a b op -- c )
    call( a b -- c ) ;

5 3 [ - ] apply-binary .
! => 2
```

これは、そのクォーテーションが実際に宣言された効果を持っているかどうかを確認する実行時のチェックをコンパイルします。

## シーケンスの中のクォーテーション

クォーテーションは値なので、配列には数値とクォーテーションを混在させて入れることができます。

```factor
{ 3 4 [ + ] }
```

こうすると「プログラム」は通常のシーケンスになり、`each`がそれを実行する自然な方法になります。

```
each ( seq quot -- )
```

```factor
{ [ 1 + ] [ 2 * ] } 5 swap [ call( x -- y ) ] each .
! 5 -> 6 -> 12
```

## シーケンスの末尾をスライスする

`head*`は最後の`n`個の要素を除くすべてを返し、`last2`は最後の2つの要素を返します。

```
head* ( seq n -- headseq )
last2 ( seq -- penultimate last )
```

```factor
{ 1 2 3 4 5 } 2 head* .    ! => { 1 2 3 }
{ 1 2 3 4 5 } last2 .s
! => 4
! => 5
```

`suffix`と組み合わせれば、「スタックの上2つを取り出して、1つの結果を積む」というスタック操作を書くのに必要なものはすべてそろいます。
