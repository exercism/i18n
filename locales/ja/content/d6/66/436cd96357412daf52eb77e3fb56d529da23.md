# はじめに

`Time`モジュールは、人間が読める形式の日付や時刻を表示するために使います。
`Time`でも時刻を操作することは技術的には可能ですが、その目的にはるかに適したElmのコミュニティパッケージがあります。たとえば[`justinmimbs/date`][date]や[`CoderDennis/elm-time-format`][elm-time-format]です。

## Posix

時刻は不透明な型`Posix`で表されます。`Posix`はUnixエポック時刻、つまり1970年1月1日0時UTCから経過したミリ秒数を包んだものです。
`Posix`は曖昧さのない値で、タイムゾーンによって変化しません。そのため、時刻を保持するのに適した選択肢です。
Elmアプリケーションでは、`Posix`の時刻は通常、ブラウザーなどの外部ソースから提供されます。

次の関数を使うと、`Posix`をミリ秒数に変換したり、その逆を行ったりできます。

```elm
posixToMillis : Posix -> Int
millisToPosix : Int -> Posix
```

## タイムゾーン

私たちは日常の中で、ふだん`Posix`を直接読むことはなく、地球上の自分の位置やその地域の夏時間のルールによって決まる現地時刻のほうを好みます。
Elmでは、この情報は不透明な型`Zone`にエンコードされ、通常はブラウザーから提供されます。

いつでも使える特別な`Zone`があります。

```elm
utc : Zone
```

## 人間が読める時刻

`Posix`と`Zone`があれば、現地時刻をどんな細かさでも表示するのに十分な情報がそろいます。
そのために使える関数を次に挙げます。

```elm
toYear : Zone -> Posix -> Int
toMonth : Zone -> Posix -> Month
toDay : Zone -> Posix -> Int
toWeekday : Zone -> Posix -> Weekday
toHour : Zone -> Posix -> Int
toMinute : Zone -> Posix -> Int
toSecond : Zone -> Posix -> Int
toMillis : Zone -> Posix -> Int
```

`Time`のカスタム型がもう2つあることにお気づきでしょう。

```elm
type Month = Jan | Feb | Mar | Apr | May | Jun | Jul | Aug | Sep | Oct | Nov | Dec
type Weekday = Mon | Tue | Wed | Thu | Fri | Sat | Sun
```

これらのカスタム型を人間が読める値に変換するのは、利用者に委ねられています。
