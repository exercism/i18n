# 概要

Javaの`char`プリミティブ型は、1つのUnicode文字を16ビットで表現する型です。

~~~~exercism/note
`char`型は、文字を16ビットで表現していた[最初のUnicode仕様][unicode-specification]に基づいています。
これは一般的な文字のほとんどをカバーするのに十分で、0x0000から0xFFFFまでの範囲の文字を扱えます。
その後、この仕様は表現できる文字の範囲を0x01FFFFまで広げました。

[unicode-specification]: https://www.unicode.org/versions/Unicode1.0.0/
~~~~

複数の`char`を組み合わせて`"word"`のような文字列を作ることもできますし、それぞれの`char`を独立して処理することもできます。
`char`リテラルはシングルクォートで囲みます（例：`'A'`）。

```java
char lowerA = 'a';
char upperB = 'B';
```

## `String`の`char`を取得する

`String.toCharArray`メソッドは、文字列の文字を配列として返します。
[配列][concept-arrays]で説明したように、`for`ループを使って配列を反復処理できます。

```java
String text = "Hello";
char[] asArray = text.toCharArray();

for (char ch: asArray) {
    System.out.println(ch);
}

// Outputs:
// H
// e
// l
// l
// o
```

## [Character][docs-character]クラス

`char`を調べたり操作したりするための組み込みライブラリのメソッドがたくさんあります。
それらは[`java.lang.Character`][docs-character]クラスの静的メソッドとして用意されています。
いくつか例を見てみましょう：

```java
Character.isWhitespace(' ');    // true
Character.isWhitespace('#');    // false

Character.isLetter('a');        // true
Character.isLetter('3');        // false

Character.isDigit('6');         // true
Character.isDigit('?');         // false
```

~~~~exercism/note
Characterクラスの一部のメソッドにはオーバーロードがあり、`char`または`int`のどちらでも受け取れます。
たとえば、`isDigit`には[`char`][is-digit-char]を受け取るものと、[`int`][is-digit-int]を受け取るものがあります。
先ほど説明したように、`char`型は0x0000から0xFFFFまでの範囲の文字しか表現できません。
一方、`int`はすべての文字を表現できるため、`int`のオーバーロードが存在します。

[is-digit-char]: https://docs.oracle.com/en/java/javase/21/docs/api/java.base/java/lang/Character.html#isDigit(char)
[is-digit-int]: https://docs.oracle.com/en/java/javase/21/docs/api/java.base/java/lang/Character.html#isDigit(int)
~~~~

## `char`を`String`に追加する

`+`演算子を使うと、`char`を`String`に追加できます。

```java
'a' + " banana"     // => "a banana"
"banana " + 'a'     // => "banana a"
```

~~~~exercism/caution
2つの`char`を`+`でつなげて`String`を作ろうとしないよう、_注意_してください！
この方法で2つの`char`を足すと、`String`ではなく`int`になります！
たとえば：

```java
'b' + 'c';
// => 197 (not the String "bc")
```

これは、Javaが`char`を`int`に昇格させるためです（[Java言語仕様][jls-main]の[4.2 プリミティブ型と値][jls-primitives]を参照）。

[jls-main]: https://docs.oracle.com/javase/specs/jls/se21/html/
[jls-primitives]: https://docs.oracle.com/javase/specs/jls/se21/html/jls-4.html#jls-4.2
~~~~

ただし、追加する文字が多い場合は、代わりに[`StringBuilder`][docs-stringBuilder]を使うほうが効率的です：

```java
StringBuilder builder = new StringBuilder();
builder.append('a');
builder.append('b');
builder.append('c');

String builtString = builder.toString();
// => abc
```
