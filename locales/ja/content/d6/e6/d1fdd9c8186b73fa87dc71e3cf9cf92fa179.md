# 指示

録音スタジオにある小さなミキシングコンソールのデジタルコアを書いています。

音はサンプルのストリームとして届きます。
各サンプルは、ある瞬間のスピーカーのコーンの位置を表す数値です。
コンソールはサンプルのブロックをまとめて処理し、それぞれに同じ演算を適用します。

5つのタスクがあり、それぞれがメモリ上に保持されたサンプルのブロックを処理します。
オペランドはメモリアドレスを通じて受け取り、答えは結果アドレスを通じて書き込みます。

~~~~exercism/note
この演習の計算は、スカラー演算ではなくSIMD命令を使って行う必要があります。
~~~~

## 1. 2つのトラックをミックスする

スタジオでは、楽器を別々のトラックに録音することがあります。
同じスピーカーから再生するには、2つのトラックを1つに足し合わせます。

`mix_tracks`関数を実装します。この関数は、2つのトラックをサンプルごとに足し合わせます。
各トラックは、8個の符号付き16ビットサンプルのブロックです。
符号付き16ビットの範囲を超える和は、ラップせずに飽和させる必要があります。

この関数は、次の順番で引数を取ります。

- `result`：ミックス後の8個のサンプルを書き込むバッファーの、16バイト境界に整列されたメモリアドレス。
- `track_a`：1つ目のトラックの16バイト境界に整列されたメモリアドレスで、8個の符号付き16ビットサンプルを持ちます。
- `track_b`：2つ目のトラックの16バイト境界に整列されたメモリアドレスで、8個の符号付き16ビットサンプルを持ちます。

```c
track_a = {10000, 30000, 20000, -30000, -20000, -100,  100, 0}
track_b = { 5000,  5000, 20000,  -5000, -20000,  100, -100, 0}
result  = {15000, 32767, 32767, -32768, -32768,    0,    0, 0}
```

この関数に戻り値はありません。

## 2. ブリードを取り除く

2つのマイクで同時に録音すると、それぞれがもう一方の音源のわずかなコピーを拾ってしまいます。
この不要なコピーは_ブリード_と呼ばれます。
このブリードを測定したら、トラックをきれいにするためにそれを差し引く必要があります。

`remove_bleed`関数を実装します。この関数は、トラックのブロックからブリードのブロックをサンプルごとに差し引きます。
各ブロックは8個の符号付き16ビットサンプルで、引き算は飽和させる必要があります。

この関数は、次の順番で引数を取ります。

- `result`：きれいにした8個のサンプルを書き込むメモリアドレス（整列は保証されません）。
- `track`：録音したトラックの16バイト境界に整列されたメモリアドレスで、8個の符号付き16ビットサンプルを持ちます。
- `bleed`：取り除くブリードのメモリアドレスで、8個の符号付き16ビットサンプルを持ちます（整列は保証されません）。

```c
track  = {10000, -30000, 5000, 32767, 0,  200, -200, 15000}
bleed  = { 2000,   5000, 5000,    -5, 0,  300,  300,  5000}
result = { 8000, -32768,    0, 32767, 0, -100, -500, 10000}
```

この関数に戻り値はありません。

## 3. メーターをまとめる

各チャンネルの上にはレベルメーターがあり、その明るさでチャンネルの音の大きさを示す小さなバーです。
フロントパネルにはマスターメーターが1つあり、これは2つのチャンネルを合わせたのと同じくらい明るく光る必要があります。
これを動かすために、2つのメーターブロックを足し合わせます。

明るいメーターは、暗さに戻るようにラップするのではなく最大の明るさにとどまるため、和は飽和する点に注意してください。

`combine_meters`関数を実装します。この関数は、2つのメーターブロックをサンプルごとに足し合わせます。
この関数は、次の順番で引数を取ります。

- `result`：足し合わせた16個の値を書き込む、16バイト境界に整列されたメモリアドレス。
- `meter_a`：1つ目のチャンネルのメーターブロックの16バイト境界に整列されたメモリアドレスで、16個のパックされた符号なし8ビット値を持ちます。
- `meter_b`：2つ目のチャンネルのメーターブロックの16バイト境界に整列されたメモリアドレスで、16個のパックされた符号なし8ビット値を持ちます。

各ブロックは16個の符号なし8ビット値です。
これらは足し合わせ、符号なしの範囲に飽和させます。

```c
meter_a = {200, 100,  50, 255, 0, 128, 10, 240, 1, 2, 3, 4, 5, 6, 7, 8}
meter_b = {100, 100, 200,   1, 0, 128, 10,  20, 1, 2, 3, 4, 5, 6, 7, 8}
result  = {255, 200, 250, 255, 0, 255, 20, 255, 2, 4, 6, 8, 10, 12, 14, 16}
```

この関数に戻り値はありません。

## 4. フェードをかける

曲は急に止まるのではなく、最後にフェードアウトするようにします。
サンプルごとに1つずつ、少しずつ小さくなっていく_ゲイン係数_のブロックがあります。

各係数は、`65536`を分母とする分数で表されます。
たとえば、あるサンプルの値が`16384`なら、実際には`16384 / 65536`、つまり`1 / 4`を表します。
使える最大の値である`32767`は、ちょうど2分の1より少し小さい値です。

`65536`は`2^16`なので、サンプルにその係数を掛けて積の_上位半分_を取ると、`sample * gain / 65536`になります。

`apply_fade`関数を実装します。この関数は、各サンプルをその係数でスケーリングします。
この関数は、次の順番で引数を取ります。

- `result`：スケーリングしたすべてのサンプルを書き込む、16バイト境界に整列されたメモリアドレス。
- `track`：トラックの16バイト境界に整列されたメモリアドレスで、`n`個の符号付き16ビットサンプルを持ちます。
- `gains`：ゲイン係数の16バイト境界に整列されたメモリアドレスで、`n`個の符号付き16ビット値を持ち、それぞれが`0`から`32767`の範囲にあります。
- `n`：サンプルの個数で、常に0以外かつ`8`の倍数であり、64ビットの符号なし整数です。

トラックは`n`個の符号付き16ビットサンプルを保持する配列で、`n`は決して0ではなく常に`8`の倍数である点に注意してください。
各サンプルについて、スケーリングした結果は、符号付きの積`sample * gain`の_上位_16ビットです。

```c
track  = {20000, 20000, 20000, 20000, -20000, -20000, -20000, -20000}
gains  = {32767, 24576, 16384,  8192,  32767,  24576,  16384,   8192}
result = { 9999,  7500,  5000,  2500, -10000,  -7500,  -5000,  -2500}
```

~~~~exercism/note
上位半分を取ると、負の無限大方向に丸められます。
そのため、`20000 * 32767`は`9999`にスケーリングされますが、`-20000 * 32767`は`-9999`ではなく`-10000`にスケーリングされます。
~~~~

この関数に戻り値はありません。

## 5. トラックを減衰させる

ドラマーは音が大きすぎる状態で録音されていました。
トラック全体を小さくするために、すべてのサンプルを定数で割ります。

`attenuate_track`関数を実装します。
この関数は、次の順番で引数を取ります。

- `result`：結果を32ビットの符号付き整数として書き込む、16バイト境界に整列されたメモリアドレス。
- `samples`：サンプルの16バイト境界に整列されたメモリアドレスで、`n`個の符号付き16ビット値を持ちます。
- `divisor`：除数を4つ複製したものの16バイト境界に整列されたメモリアドレスで、32ビット整数です。
- `n`はサンプルの個数で、常に0以外かつ`4`の倍数であり、64ビットの符号なし整数です。

`samples`は`n`個の符号付き16ビットサンプルを保持する配列で、`n`は決して0ではなく常に`4`の倍数である点に注意してください。

除数は、同じ32ビット整数を`4`つ複製した形で渡され、4つのレーンすべてを一度に埋められるようあらかじめ複製されています。

整数SIMDにはパック除算がないため、処理はパック浮動小数点で行い、その後、`result`に格納するためにパックされた32ビット整数に変換し直します。
ゼロ方向に切り捨てて変換し直すので、商が`2.3`なら`2`に、`-2.3`なら`-2`になります。

```c
samples = {300, 150, 90, -120, 100, 50, -50, 7}
divisor = {3, 3, 3, 3}
result  = {100,  50, 30,  -40,  33, 16, -16, 2}
```

この関数に戻り値はありません。
