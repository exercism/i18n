# 概要

Goでは、`struct`は_フィールド_と呼ばれる名前付きの要素を並べたものです。各フィールドは名前と型を持ちます。
フィールドの名前は、structの中で一意でなければなりません。
structは、オブジェクト指向プログラミングのパラダイムにおける_クラス_と比べることができます。

## structを定義する

新しいstructは、`type`と`struct`というキーワードを使って作成し、フィールドの名前と型を明示的に定義します。
たとえば、ここでは図形の名前とサイズを保持する`Shape`というstructを定義します。

```go
type Shape struct {
    name string
    size int
}
```

structのフィールド名はGoの慣習に従います。名前が小文字で始まるフィールドは同じパッケージ内のコードからしか見えませんが、大文字で始まるフィールドは他のパッケージからも見えます。

## structのインスタンスを作成する

`struct`を定義したら、フィールド名を使って、どの順番でもよいのでフィールドを指定し、新しいインスタンスを作成します。

```go
s := Shape {
    name: "Square",
    size: 25,
}
```

インスタンスのフィールドを読み取ったり変更したりするには、`.`記法を使います。

```go
// Update the name and the size
s.name = "Circle"
s.size = 35
fmt.Printf("name: %s size: %d\n", s.name, s.size)
// Output: name: Circle size: 35
```

初期値が代入されていないフィールドは、ゼロ値になります。
たとえば、次のようになります。

```go
s := Shape{name: "Circle"}
fmt.Printf("name: %s size: %d\n", s.name, s.size)
// Output: name: Circle size: 0
```

フィールドを_順番どおり_に定義するなら、フィールド名を使わずに`struct`のインスタンスを作成できます。

```go
s := Shape {
	"Oval",
	20,
}
```

ただし、この構文は_壊れやすいコード_と見なされます。フィールドが追加されたときに壊れる可能性があるからです。特に、新しいフィールドが別の型である場合にそうなります。
次の例では、`Shape`にフィールドを1つ追加します。

```go
type Shape struct {
	name        string
	description string // new field 'description' added
	size        int
}

s := Shape{
    "Circle",
    20,
}
// Since the second field of the struct is now a string and not an int,
// the compiler will throw an error when compiling the program:
// Output: cannot use 20 (type untyped int) as type string in field value
// Output: too few values in Shape{...}
```

## 「New」関数

structのインスタンスを作成するのを助けてくれる関数があると、便利なことがあります。
慣習として、こうした関数は通常`New`と呼ばれるか、名前が`New`で始まります。ただし、これらはただの普通の関数なので、好きな名前を付けてかまいません。
他の言語のコンストラクターを思い起こさせるかもしれませんが、Goではこれらはただの普通の関数です。

次の例では、こうした`New`関数の1つを使って`Shape`の新しいインスタンスを作成し、図形の`size`にデフォルト値を自動的に設定しています。

```go
func NewShape(name string) Shape {
	return Shape{
		name: name,
		size: 100, //default-value for size is 100
	}
}

NewShape("Triangle")
// => Shape { name: "Triangle", size: 100 }

```

`New`関数を使うと、次のような利点があります。

* 与えられた値の検証
* デフォルト値の処理
* `New`関数は、初期化するstructと同じパッケージで宣言されることが多いため、そのstructのプライベートなフィールドも初期化できます

この型をさらに深く学びたい場合は、次のリソースを参照してください。[Go by Example: Structs][go-by-example-structs]、[A Tour of Go: Structs][tour-of-go-structs]、[Structures in Go (structs)][medium-structures-in-go]

## `new`組み込み関数

structの新しいインスタンスを作成するもう1つの方法は、組み込みの`new`を使うことです。

```go
s := new(Shape) // s will be of type *Shape (pointer to shape)
fmt.Printf("name: %s size: %d\n", s.name, s.size)
// Output: name:  size: 0
```

この例では、`new`はstruct`Shape`のインスタンスを、すべての値をその型のゼロ値で初期化して作成し、そのポインターを返します。

~~~~exercism/note
structの新しいインスタンスが`new`ビルトインを使って作成されることは、ほとんどの場合ありません。
structリテラル、独自の`New`関数、あるいはパッケージが提供する、structを組み立てるのに役立つその他の関数を常に優先して使いましょう。
`new`ビルトインを使ってstructの新しいインスタンスを作成するのは、最後の手段にしましょう。
~~~~
