# 説明

*ChronoRealms*の世界へようこそ。ここは、強力なTimekeeperたちが時間の流れを操る魔法の国です。

この世界では、Timekeeperたちが「TimeShard」という特別な単位を管理しています。TimeShardは、足したり引いたり、比べたり、さらには等しいかどうかを調べたりできる単位です。

今回の任務は、Timekeeperたちを手助けするために、これらのTimeShardを操作する独自の演算子を実装することです。

Timekeeperたちは、次の操作をサポートする独自の構造体`TimeShard`を作ることを求めています。

1. **TimeShardの足し算と引き算**: タイムラインを操るには、TimekeeperたちがTimeShardを足したり引いたりできる必要があります。
2. **TimeShardの比較**: どちらが大きいか、あるいは等しいかどうかを確かめるために、TimeShardを比べる必要があります。
3. **等しいかどうかの確認**: 2つのTimeShardの値が同じかどうかを、Timekeeperたちが確認できる必要があります。

使命は、`TimeShard`構造体に次のトレイトを実装することです。

1. **足し算（`Add`）**: 2つの`TimeShard`インスタンス同士を足せるようにします。
2. **引き算（`Sub`）**: ある`TimeShard`から別の`TimeShard`を引けるようにします。
3. **等しいかどうか（`PartialEq`）**: 2つの`TimeShard`インスタンスが同じかどうかを、Timekeeperたちが確認できるようにします。
4. **比較（`PartialOrd`）**: 2つの`TimeShard`インスタンスを比べて、どちらが大きいか小さいかを確かめられるようにします。

`TimeShard`は、整数値（`i32`）を保持する構造体として表されます。

Timekeeperたちの仕事を楽にするために、必要なトレイトを実装しましょう。

```rust
let shard1 = TimeShard { value: 5 };
let shard2 = TimeShard { value: 3 };

// Adding TimeShards
let sum = shard1 + shard2; // TimeShard { value: 8 }

// Subtracting TimeShards
let difference = shard1 - shard2; // TimeShard { value: 2 }

// Checking equality
let are_equal = shard1 == shard2; // false

// Comparing TimeShards
let is_greater = shard1 > shard2; // true
```
