# はじめに

Cairoでは、演算子のオーバーロードを使うと、独自の型を扱うときに`+`や`-`、`==`、`<`などの標準の演算子に独自の動作を定義できます。

これは、独自の型に特定のトレイトを実装することで行います。

## 演算子のための主要なトレイト

### `Add`と`Sub`

`Add`と`Sub`トレイトを使うと、自分の型で加算（`+`）と減算（`-`）がどう働くかを定義できます。

```rust
impl MyTypeAdd of Add<MyType> {
    fn add(lhs: MyType, rhs: MyType) -> MyType {
        // Define addition behavior
    }
}
```

### `PartialEq`

`PartialEq`トレイトを使うと、自分の型のインスタンス同士で等価比較（`==`と`!=`）ができるようになります。

これは多くの場合、`#[derive(PartialEq)]`を使って自動的に導出できます。

### `PartialOrd`

`PartialOrd`トレイトを使うと、自分の型のインスタンス同士で比較演算（`<`、`>`、`<=`、`>=`）ができるようになります。

少なくとも`lt`（less than）メソッドを実装する必要があります。

```rust
impl MyTypePartialOrd of PartialOrd<MyType> {
    fn lt(lhs: MyType, rhs: MyType) -> bool {
        // Define "less than" behavior
    }
}
```
