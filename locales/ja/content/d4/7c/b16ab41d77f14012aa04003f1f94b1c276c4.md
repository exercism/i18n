# 説明

この演習では、バンドの値を覚えておかなくて済むように、便利なプログラムを作ります。
プログラムは、1つ、4つ、または5つの色を入力として受け取り、正しい値をオームで出力します。
色のバンドは、次のようにエンコードされています。

| 色 | 値 |
|-------------|-------|
| Black       | 0     |
| Brown       | 1     |
| Red         | 2     |
| Orange      | 3     |
| Yellow      | 4     |
| Green       | 5     |
| Blue        | 6     |
| Violet      | 7     |
| Gray        | 8     |
| White       | 9     |
|-------------|-------|

[`Resistor Color Trio`][resistor-color-trio-exercise]では、最初の3つの色のバンドを読み解きました。
たとえば、orange-orange-brownは主となる値`330`に変換されます。
この演習では、そこに_許容差_を加える必要があります。
許容差とは、値が主となる値から上または下にどれだけずれることができるかの最大量です。
たとえば、最後のバンドがgreenであれば、最大の許容差は`±0.5%`になります。

許容差のバンドは、次のいずれかの値になります。

| 色 | 許容差 |
|--------|----------:|
| Grey   | ±0.05%    |
| Violet | ±0.10%    |
| Blue   | ±0.25%    |
| Green  | ±0.50%    |
| Brown  | ±1.00%    |
| Red    | ±2.00%    |
| Gold   | ±5.00%    |
| Silver | ±10.00%   |
|--------|-----------|

4バンドの抵抗器は、次のように構成されています。

| バンド1 | バンド2 | バンド3 | バンド4 |
| ------- | ------- | ---------- | --------- |
| 値1 | 値2 | 乗数 | 許容差 |

例：

- orange-orange-brown-greenは、許容差`±0.5%`で`330`オームになります。
- orange-orange-red-greyは、許容差`±0.05%`で`3300`オームになります。

4バンドと5バンドの抵抗器の違いは、5バンドの抵抗器には、より精密な値を示すためのバンドが1つ多くあることです。

| バンド1 | バンド2 | バンド3 | バンド4 | バンド5 |
| ------- | ------- | ------- | ---------- | --------- |
| 値1 | 値2 | 値3 | 乗数 | 許容差 |

例：

- orange-orange-orange-black-greenは、許容差`±0.5%`で`333`オームになります。
- orange-red-orange-blue-violetは、許容差`±0.1%`で`323 million`オームになります。

1バンドの抵抗器もあります。
1バンドの抵抗器の色はblackだけで、値は0です。

作成するプログラムは、抵抗器のバンドの色の入力`list`を、次のようなラベルに変換する必要があります。

「... ohms ±...%」

つまり、`["orange", "orange", "black", "green"]`という入力`list`は、次の値を返す必要があります。

「33 ohms ±0.5%」

オームが千単位になると、「kiloohms」と呼びます。
これは、1000メートルを「キロメートル」、1000グラムを「キログラム」と呼ぶのと似ています。

つまり、`["orange", "orange", "orange", "grey"]`という入力`list`は、次の値を返す必要があります。

「33 kiloohms ±0.05%」

オームが百万単位になると、「megaohms」と呼びます。

つまり、`["orange", "orange", "blue", "red"]`という入力`list`は、次の値を返す必要があります。

「33 megaohms ±2%」
