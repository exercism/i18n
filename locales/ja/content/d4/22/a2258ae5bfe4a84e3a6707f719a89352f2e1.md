# 演習の補足

## ヒント

[双方向連結リスト](https://en.wikipedia.org/wiki/Doubly_linked_list)は、ミュータブルなデータ構造です。F#は関数型を第一に考える言語なので、一般的には不変性が好まれますが、必要な場面ではミュータブルを使えるようにする言語機能も用意されています。

- `mutable`キーワードは、`let`束縛や[レコード](https://docs.microsoft.com/en-us/dotnet/articles/fsharp/language-reference/records)のフィールドの前に置くことができ、それらに新しい値を代入できるようになります。

- [クラス](https://fsharpforfunandprofit.com/posts/classes)のプロパティは、`set`キーワードでプロパティセッターを指定することでミュータブルにできます。

ミュータブルな束縛は、`<-`で再代入する必要があります

```fsharp
let mutable x = "initial value"
x <- "new value"
```
