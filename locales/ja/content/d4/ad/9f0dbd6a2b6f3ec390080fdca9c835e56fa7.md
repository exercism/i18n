# ヒント

## 全般

- `<min-heap>`、`heap-push`、`heap-peek`、`heap-pop-all`はすべて[`heaps`][heaps]にあり、`values`は[`assocs`][assocs]にあります。
- ヒープは各項目を*値*と*キー*の組として保持し、キーが優先度になります。`heap-push`はそれらを`( value key heap -- )`の形で受け取ります。

## 1. キューを開く

- `<min-heap>`は空の最小ヒープを作ります。キーが最も小さい項目から順に処理されます。

## 2. 顧客を追加する

- 顧客の名前が値で、優先度がキーです。これはまさに`heap-push`が求める順番です。
- `heap-push`はキューを消費してしまいます。顧客を追加しつつキューも返すには、`[ heap-push ] keep`を使います。

## 3. 次は誰？

- `heap-peek`は先頭の項目の`value key`を、それを取り除かずに返します。必要なのは名前だけなので、キーは`drop`します。

## 4. 全員に応対する

- `heap-pop-all`はヒープを空にして、`{ key value }`のペアの連想リストにします。すでに優先度順になっています。
- `values`は値だけ、つまり名前だけを取り出します。

[heaps]: https://docs.factorcode.org/content/vocab-heaps.html
[assocs]: https://docs.factorcode.org/content/vocab-assocs.html
