# 説明

ここでは、小さな逆ポーランド記法（RPN）の電卓を作ります。電卓の状態は*値のスタック*で、これはFactorの配列として表されます。*演算*は、そのようなスタックを受け取って新しいスタックを返すクオーテーションです。

```factor
{ 3 4 }   ! the calculator's stack: 3 is below 4
[ ... ]   ! an operation that consumes some values and pushes a result
```

## 1. 足し算を実装する

`add-op`を定義して、スタックの一番上から2つの値をポップし、それらの和をプッシュして、新しいスタックを返すようにしましょう。

```factor
{ 3 4 } add-op .
! => { 7 }

{ 1 2 3 4 } add-op .
! => { 1 2 7 }
```

## 2. 掛け算を実装する

同じようにして、掛け算用の`multiply-op`を定義しましょう。

```factor
{ 3 4 } multiply-op .
! => { 12 }
```

## 3. 1つの演算を適用する

`apply-op`を定義して、データスタックからスタックと演算（クオーテーション）を取り出し、新しい電卓のスタックを返すようにしましょう。

```factor
{ 3 4 } [ add-op ] apply-op .
! => { 7 }
```

## 4. プログラムを評価する

`evaluate`を定義して、開始時のスタックと演算の配列を受け取り、各演算を順に適用して、最終的なスタックを返すようにしましょう。

```factor
{ 3 4 5 } { [ add-op ] [ multiply-op ] } evaluate .
! => { 27 }
```

## 5. 名前で評価する

ここで、プログラムは*演算子の名前*（文字列）のリストになり、電卓はそれぞれの名前を、名前を演算に対応付けるassocの中で探します。

`evaluate-named`を定義して、開始時のスタック、名前付き演算のassoc、名前の配列を受け取り、最終的なスタックを返すようにしましょう。

```factor
{ 3 4 5 } H{ { "+" [ add-op ] } { "*" [ multiply-op ] } } { "+" "*" }
evaluate-named .
! => { 27 }
```

## 6. 安全に割り算する

本物の電卓は、ゼロで割ろうとしたときに黙って間違った結果を返してはいけません。エラークラス`zero-divisor-error`はすでに定義されています。`add-op`や`multiply-op`と同じように`divide-op`を実装しましょう。ただし、スタックの一番上にある除数が`0`のときは、新しい`zero-divisor-error`を`throw`します。

```factor
{ 12 4 } divide-op .
! => { 3 }

{ 1 5 6 2 } divide-op .
! => { 1 5 3 }

{ 5 0 } divide-op
! throws zero-divisor-error
```
