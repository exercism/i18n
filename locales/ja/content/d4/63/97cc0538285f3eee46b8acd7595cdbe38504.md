# はじめに

## 比較演算子

Juliaの比較演算子は、ほかの多くの言語とよく似ていますが、数学好きのための追加の選択肢もいくつか用意されています。

等しいかどうかを比べる演算子には、`==`（等しい）と、`!=`または`≠`（等しくない）があります。

```julia
txt = "abc"
txt == "abc"  # true
txt != "abc"  # false
txt ≠ "abc"  # false (synonym for !=)
```

さらに、大小を比べる演算子もいろいろあります。

```julia
1 < 3  # true
3 > 3  # false
3 <= 3  # true
3 ≤ 3  # true (synonym for <=)
4 >= 3  # true
4 ≥ 3  # true (synonym for >=)
```

Juliaではよくあることですが、適切なエディターを使えば数学記号を簡単に使えます。`\ne`、`\le`、`\ge`と入力してから`TAB`を押すと、`≠`、`≤`、`≥`になります。

先ほどの例では数値だけを使いましたが、シラバスのほかの部分では、ほかのさまざまな型にも順序の考え方があり、大小を比べられることを見ていきます。

比較演算子はつなげて書くこともでき、簡潔でわかりやすい構文になります。

```julia
n = 3
1 ≤ n ≤ 5  # true (n "between" two limits)
```

先ほどの例は、`1 ≤ n && n ≤ 5`と同じ意味です。

## `if`で分岐する

`if`文の完全な形は次のとおりです。

```julia
if conditional1
    statements...
elseif conditional2
    statements...
else
    statements...
end
```

括弧（`()`）や波括弧（`{}`）は必要ありません。インデントは「あくまで」読みやすくするためのものにすぎません_（とはいえ、読みやすさはとても大切です！）_。

`elseif`も`else`も省略でき、`elseif`のブロックは複数書くこともできます。ただし、`end`は必ず必要です。

`if`文を入れ子にすることもできますが、括弧、インデント、コメントをうまく使って読みやすさを助けるとよいでしょう。

`if`文の最短の形は、次のようなものです。

```julia
if n < 0
    n = 0
end
```

念のため言っておくと、条件として使えるのは、`true`か`false`に評価される式だけです。Juliaは「truthiness」のような考え方を意図的に避けているので、ゼロの値、空の文字列、空の配列は`false`と_同じではありません_。

## 三項演算子

よくある単純な場面として、条件に応じて2つの値のどちらかを選びたいことがあります。

Juliaには、多くの言語と同じく、これをより簡潔に書くための三項演算子があります。

構文は`conditional ? value_if_true : value_if_false`です。

つまり、先ほどの例は次のように書き換えられます。

```julia
n = n < 0 ? 0 : n
```

コンパイラーが括弧を必要とするわけではありませんが、あると読みやすくなることもあります。
