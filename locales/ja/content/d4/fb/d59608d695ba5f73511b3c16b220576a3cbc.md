# はじめに

Java 8で導入された`java.time`パッケージには、日付と時刻を扱うためのいくつかのクラスが含まれています。

## `LocalDate`

`java.time.LocalDate`クラスは、[ISO-8601暦体系][iso-8601]におけるタイムゾーンのない日付を表します。たとえば`2007-12-03`のようなものです。

```java
LocalDate date = LocalDate.of(2007, 12, 3);
```

日付はほかの日付と比較できます。

```java
LocalDate date1 = LocalDate.of(2007, 12, 3);
LocalDate date2 = LocalDate.of(2007, 12, 4);

date1.isBefore(date2);
// => true

date1.isAfter(date2);
// => false
```

`LocalDate`のインスタンスには、日付の各部分を取得するためのゲッターがあります。

```java
LocalDate date = LocalDate.of(2007, 12, 3);

date.getDayOfMonth();
// => 3
```

`LocalDate`のインスタンスには、時間の単位を加算するメソッドがあります。

```exercism/note
これらのメソッドは_新しい_`LocalDate`インスタンスを返し、既存のインスタンスは更新しません。`LocalDate`クラスが不変だからです。
```

```java
LocalDate date = LocalDate.of(2007, 12, 3);

date.plusDays(3);
// => 2007-12-06
```

## `LocalDateTime`

`java.time.LocalDateTime`クラスは、[ISO-8601暦体系][iso-8601]におけるタイムゾーンのない日時を表します。たとえば`2007-12-03T10:15:30`のようなものです。

```java
LocalDateTime datetime = LocalDateTime.of(2007, 12, 3, 10, 15, 30);
```

`LocalDate`のインスタンスを`LocalDateTime`に変換できます。

```java
LocalDate date = LocalDate.of(2007, 12, 3);
LocalDateTime datetime = date.atTime(10, 15, 30);
datetime.toString();
// => "2007-12-03T10:15:30"
```

## 日時のフォーマット

`LocalDate`と`LocalDateTime`はどちらも、`String`との相互変換に[ISO-8601][iso-8601]の標準表記を使います。

```java
LocalDateTime datetime = LocalDateTime.of(2007, 12, 3, 10, 15, 30);
LocalDateTime parsed = LocalDateTime.parse("2007-12-03T10:15:30");

datetime.isEqual(parsed);
// => true
```

このように、異なるフォーマットを使って`String`から`LocalDate`や`LocalDateTime`をパースすることはできません。
代わりに、日付を独自のフォーマットで表すには、`java.time.format.DateTimeFormatter`を使います。

```java
DateTimeFormatter parser = DateTimeFormatter.ofPattern("dd/MM/yyyy");
LocalDate date = LocalDate.parse("03/12/2007", parser);

DateTimeFormatter printer = DateTimeFormatter.ofPattern("MMMM d, yyyy");
printer.format(date);
// => "December 3, 2007"
```

独自のフォーマットを作成するときにロケールを指定すると、地域ごとにフォーマットやパースを行うこともできます。

```java
DateTimeFormatter.ofPattern("MMMM d, yyyy", Locale.FRENCH).format(date);
// => décembre 3, 2007

DateTimeFormatter.ofPattern("MMMM d, yyyy", Locale.of("pt")).format(date);
// => dezembro 3, 2007
```

[iso-8601]: https://en.wikipedia.org/wiki/ISO_8601
