# 概要

Common Lispでは、グローバルで名前付きの関数は`defun`で定義します。

このフォームは、最初の引数として、定義する関数の仮引数のリストを取ります（この仮引数のリストは「ラムダリスト」とも呼ばれます）。
その後、オプションで、その関数のドキュメントとして使う文字列を取ることができます。
最後に、関数の本体を構成する0個以上の式があります。

関数を呼び出すには、関数の名前を式の最初の要素として使い、その後にその関数への仮引数を続けます。

```lisp
(defun add-one (x) (1+ x))

(add-one 3) ;; => 4
```

関数は、[オプション仮引数][concept-optional-parameters]、[キーワード仮引数][concept-keyword-parameters]、[残余仮引数][concept-rest-parameters]を取ることもできます。
これらについては、後の概念で説明します。

関数の名前は関数の本体のスコープ内にあるため、再帰を実行できます。

```lisp
(defun countdown (x)
  (if (zerop x) (print 'BLAST-OFF)
    (progn (print x) (countdown (1- x)))))

(countdown 3) ;; will print "3","2", "1" and "BLAST-OFF" to
              ;; standard output before evalutaing to 'BLAST-OFF
```
