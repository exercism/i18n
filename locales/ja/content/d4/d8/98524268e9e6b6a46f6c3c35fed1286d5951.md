# Instructions

あなたは、すでに飽和状態にある市場で他社との差別化を図ろうとしている新しいタクシーサービスに、採用されたばかりです。
これを実現するため、CEOはマンハッタンで超高級なサービスを提供することを決めました。すべての交差点に係員を配置し、乗車の前後で乗客をサポートします。
そこで、このサービスの運営を支えるコードを書く必要があります。

## 1. 単純な複素数

CEOは、マンハッタンの街路が主に格子状に区画されていることから、複素数が通りの交差点を表すのに便利だと判断しました。
ここでは、正と負の実数がそれぞれ東と西を、正と負の虚数がそれぞれ北と南を表します。

Rで複素数をインスタンス化するのは少し、ええと……独特なので、単純な複素数を扱う関数を実装するよう指示されました。

整数`a`と`b`を入力として受け取る`simplex(a, b)`関数を実装します。
複素数`a+bi`を返します。

```r
simplex(1, 1)
#> 1+1i

simplex(-3, 4)
#> -3+4i
```

## 2. ドライバーの方向を取得する

乗客が目的地の交差点を伝えると、ドライバーはそこへの行き方の指示を受け取ります。
この指示は複素数の形で渡され、実部が南北にいくつブロック進むかを、虚部が東西の距離を表します。
標準的な方位磁針に合わせるため、プロジェクトマネージャーは北を正の虚数方向、南を負の虚数方向とすることにしました。
同様に、東は正の実数方向、西は負の実数方向です。

出発地点`start`の交差点座標と、目的地`end`の座標を入力として受け取る`driver_directions(start, end)`関数を実装します。
ドライバーが東西＋南北にいくつブロック進む必要があるかを表す複素数を返します。

```r
driver_directions(0+0i, 7+5i)
#> 7+5i

driver_directions(-2+3i, 4-5i)
#> 6-8i
```

## 3. マンハッタン距離を取得する

乗客は、タクシーが移動しなければならない距離に応じた料金を支払います。
マンハッタンの街路は格子状に区画されているため、タクシーはこの経路に沿ってしか移動できません。
この構造から、格子線に沿うように制約された距離の測り方が生まれます。
この距離は、通過した線の数か、到達した交差点の数（つまり、出発地点の交差点は含みません）を合計することで求められます。
この測り方は一般にマンハッタン距離、またはL1ノルムと呼ばれます。

`start`と`end`の交差点を入力として受け取る`manhattan(start, end)`関数を実装します。
`start`と`end`の交差点間のマンハッタン距離を返します。

```r
manhattan(0+0i, 3+4i)
#> 7

manhattan(-2-3i, -1+1i)
#> 5
```

## 4. 「カラスの直線距離」を取得する

CEOは、このサービスが超高級であるだけでなく環境にも優しいと強調することで、投資銀行を味方につけることに成功しました。訓練されたカラスを使い、交差点にいる係員の間でメッセージを運ぶ（係員は、パーソナライズされた体験のために乗客に関する情報を伝えます）からです。
投資マネーがどんどん流れ込んでいるためか、投資銀行家たちは誰も、これがなぜ環境に優しいのか、そもそもどんなCEOが暇な時間にカラスの調教を楽しむのか、きちんと調べようとはしなかったようです。

このサービスも、移動した距離に応じて料金が発生します。
しかし、カラスは飛べるので、道路の格子網に従う必要はなく、最短経路を進むことができます。
もちろん、巨大な高層ビルがある場所ではそうはいかないかもしれません。しかしCEOは、このサービスをカンザス州マンハッタン（別名「The Little Apple」）に導入しようとしています。ここならカラスは低層の建物を楽に飛び越えられます。
カンザス州マンハッタンでこうしたサービスにどれだけの需要があるのか、そして頭上を飛び交う大量の鳥を地元の歩行者がどう感じるかは、また別の話です。

`start`と`end`の交差点を入力として受け取る`as_crow_flies(start, end)`関数を実装します。
2つの交差点間の直線距離を返します。

```r
as_crow_flies(0+0i, 3+4i)
#> 5
```

## 5. カラスの方向を取得する

CEOは、カラスにドライバーと似た種類の方向指示に従うよう訓練しました。
しかしCEOは南半球を愛しており、カラスには、プロジェクトマネージャーがシステムの他の部分で使っているものとは別の方位磁針で訓練しました。
CEOはなかなかの変わり者であることが分かってきました。
CEOの方位磁針では、北が負の虚数方向、南が正の虚数方向です。
これはドライバーの南北の方向とは逆で、東西は同じままです。

`start`と`end`の交差点を入力として受け取る`crows_directions(start, end)`関数を実装します。
ドライバーの方向指示に相当する複素数を、南北を反転して返します。

```r
driver_directions(0+0i, 7+5i)
#> 7-5i

driver_directions(-2+3i, 4-5i)
#> 6+8i
```
