# 概要

Swiftは標準ライブラリで豊富な機能を提供していますが、外部のライブラリやフレームワークをインポートすると、さらに多くの機能を利用できるようになります。
これらのモジュールは、Swiftプロジェクトが直接提供するもの（[Swift Argument Parser][argument-parser]など）もあれば、Appleのプラットフォームフレームワーク（[Foundation][apple-foundation]や[Network Framework][network-framework]など）や、サードパーティのオープンソースライブラリ（[SwiftyBeaver][swifty-beaver]など）から提供されるものもあります。

Foundationのような主要なモジュールは、Swiftのツールチェーンに含まれています。Foundationは、Swiftで最も広く使われているライブラリの1つです。
サードパーティのライブラリは、インポートする前に、プロジェクトの設定に追加しておく必要があります（たとえばSwift Package Managerを使います）。

モジュールをインポートするには、`import`キーワードの後にモジュール名を書きます。

```swift
import Foundation
```

モジュールをインポートすると、その型・メソッド・関数を自分のコードで使えるようになります。
たとえば、Foundationをインポートすると、`String`に`components(separatedBy:)`のような便利なユーティリティメソッドが追加されます。

慣習として、`import`文はSwiftファイルの先頭に置きます。そうすると、コードを読む人に依存関係がすぐにわかります。

[argument-parser]: https://apple.github.io/swift-argument-parser/documentation/argumentparser/
[network-framework]: https://developer.apple.com/documentation/network
[swifty-beaver]: https://github.com/SwiftyBeaver/SwiftyBeaver
[apple-foundation]: https://developer.apple.com/documentation/foundation
