# はじめに

## 整数

C#は、多くの静的型付け言語と同じように、整数を表すいくつかの型を提供しています。それぞれの型が扱える値の範囲は異なります。最も小さい`sbyte`型は、最小値が-128、最大値が127です。すべての整数型と同様に、これらの値は`<type>.MinValue`と`<type>.MaxValue`で取得できます。最も大きい`long`型は、最小値が-9,223,372,036,854,775,808、最大値が9,223,372,036,854,775,807です。その間には、`short`型と`int`型があります。

範囲は、システムがその型に割り当てる記憶域の幅によって決まります。たとえば、`byte`は8ビット、`long`は64ビットです。

上記のそれぞれの型には、符号なしの対応する型があります。`sbyte`/`byte`、`short`/`ushort`、`int`/`uint`、`long`/`ulong`です。いずれの場合も、値の範囲は0から、符号付きの負の最大値に2を掛けて1を足した値までです。

| 型   | 幅  | 最小値                    | 最大値                     |
| ------ | ------ | -------------------------- | --------------------------- |
| sbyte  | 8ビット  | -128                       | +127                        |
| short  | 16ビット | -32_768                    | +32_767                     |
| int    | 32ビット | -2_147_483_648             | +2_147_483_647              |
| long   | 64ビット | -9_223_372_036_854_775_808 | +9_223_372_036_854_775_807  |
| byte   | 8ビット  | 0                          | +255                        |
| ushort | 16ビット | 0                          | +65_535                     |
| uint   | 32ビット | 0                          | +4_294_967_295              |
| ulong  | 64ビット | 0                          | +18_446_744_073_709_551_615 |

ある型の変数（または式）は、簡単に別の型に変換できます。たとえば代入の操作では、代入する値（lhs）の型が、その値が代入先（rhs）の型の範囲に収まることを保証していれば、単純な代入ができます。

```csharp
uint ui = uint.MaxValue;
ulong ul = ui;    // no problem
```

一方、代入元の型の範囲が代入先の値の範囲の一部ではない場合は、たとえその値が代入先の範囲に収まっていても、キャスト（`()`）の操作が必要です。

```csharp
short s = 42;
uint ui = (uint)s;
```
