# はじめに

## 数値

多くのプログラミング言語には、さまざまな種類の数を表すための専用の数値型がありますが、JavaScriptに用意されているのは2つだけです。

- `number`：倍精度64ビット浮動小数点形式（IEEE 754）の数値データ型です。
  例としては、`-6`、`-2.4`、`0`、`0.1`、`1`、`3.14`、`16.984025`、`25`、`976`、`1024.0`、`500000`などがあります。
- `bigint`：任意精度形式で*整数*を表せる数値データ型です。
  例としては、`-12n`、`0n`、`4n`、`9007199254740991n`などがあります。

任意精度が必要な場合や、非常に大きな数を扱う場合は、`bigint`型を使います。それ以外の場合は、`number`型のほうが適しているでしょう。

### 丸め

`Math`という組み込みのグローバルオブジェクトがあり、[数値を丸めるさまざまな関数][ref-math-object-rounding]が用意されています。
たとえば、小数を切り捨てたり（`floor`）、切り上げたり（`ceil`）して、最も近い整数にできます。

```javascript
Math.floor(234.34); // => 234
Math.ceil(234.34); // => 235
```

## 算術演算子

JavaScriptには、数値の基本的な算術演算を行うための6つの演算子があります。

- `+`：加算演算子は、数値の和を求めるために使います。
- `-`：減算演算子は、2つの数値の差を求めるために使います。
- `*`：乗算演算子は、2つの数値の積を求めるために使います。
- `/`：除算演算子は、2つの数値を割るために使います。

```javascript
2 - 1.5; //=> 0.5
19 / 2; //=> 9.5
```

- `%`：除算の余りを求める演算子です。

  ```javascript
  40 % 4; // => 0
  -11 % 4; // => -3
  ```

- `**`：べき乗演算子は、数値を累乗するために使います。

  ```javascript
  4 ** 3; // => 64
  4 ** 1 / 2; // => 2
  ```

### 演算の順序

1行で複数の演算子を使う場合、JavaScriptは[こちらの優先順位表][mdn-operator-precedence]に示されている優先順位に従います。
これをこの場面に合わせて簡単に言うと、JavaScriptは、小学校の算数の授業で習ったPEDMAS（括弧、指数、除算・乗算、加算・減算）のルールに従います。

<!-- prettier-ignore-start -->
```javascript
const result = 3 ** 3 + 9 * 4 / (3 - 1);
// => 3 ** 3 + 9 * 4/2
// => 27 + 9 * 4/2
// => 27 + 18
// => 45
```
<!-- prettier-ignore-end -->

### 省略記法の代入演算子

省略記法の代入演算子を使うと、変数に対して算術演算を行い、その新しい値を同じ変数に代入するコードを、より短く書けます。
たとえば、2つの変数`x`と`y`を考えてみましょう。
このとき、`x += y`は`x = x + y`と同じです。
多くの場合、変数`y`の代わりに数値と一緒に使われます。
残りの5つの演算も、同じように書くことができます。

```javascript
let x = 5;
x += 25; // x is now 30

let y = 31;
y %= 3; // y is now 1
```
