# 説明

この演習では、熱心なスポーツファンとしてNBAバスケットボールにハマり始めたばかりです。NBAバスケットボールは初心者なので、NBAの歴史を深く掘り下げ、チームやコーチ、その勝敗成績を記録して、互いに比較していきます。

まだ好きなチームがないので、特定のチームを応援すべきかどうかを判断するアルゴリズムも開発します。

独自の_チームを応援するかどうかを判断する_アルゴリズムを開発するために、7つのタスクがあります。

## 1. モデルの定義

次の2つのフィールドを持つ`Coach`レコードを定義します。

- `Name`：コーチの名前（型は`string`です）。
- `FormerPlayer`：コーチが元選手だったかどうかを示します（型は`bool`です）。

次の2つのフィールドを持つ`Stats`レコードを定義します。

- `Wins`：勝ち数（型は`int`です）。
- `Losses`：負け数（型は`int`です）。

次の3つのフィールドを持つ`Team`レコードを定義します。

- `Name`：チームの名前（型は`string`です）。
- `Coach`：チームのコーチ（型は`Coach`です）。
- `Stats`：チームの成績（型は`Stats`です）。

## 2. チームのコーチの作成

コーチの名前と元選手かどうかを入力として受け取り、`Coach`レコードを返す`createCoach`関数を実装します。

```fsharp
createCoach "Larry Bird" true
// => { Name = "Larry Bird"; FormerPlayer = true }
```

## 3. チームの成績の作成

勝ち数と負け数を入力として受け取り、`Stats`レコードを返す`createStats`関数を実装します。

```fsharp
createStats 58 24
// => { Wins = 58; Losses = 24 }
```

## 4. チームの作成

チーム名、コーチ、成績のレコードを入力として受け取り、`Team`レコードを返す`createTeam`関数を実装します。

```fsharp
let coach = createCoach "Larry Bird" true
let record = createStats 58 24
createTeam "Indiana Pacers" coach record
// => { Name = "Indiana Pacers"
//      Coach = { Name = "Larry Bird"; FormerPlayer = true }
//      Stats = { Wins = 58; Losses = 24 } }
```

## 5. コーチの交代

NBAのオーナーはせっかちなので、チームの成績が悪いとコーチが交代させられることがよくあると気づきました。チームと新しいコーチを入力として受け取り、新しいコーチに差し替えたチームを返す`replaceCoach`関数を実装します。

```fsharp
let coach = createCoach "Larry Bird" true
let record = createStats 58 24
let team = createTeam "Indiana Pacers" coach record

let newCoach = createCoach "Isiah Thomas" true
replaceCoach team newCoach
// => { Name = "Indiana Pacers"
//      Coach = { Name = "Isiah Thomas"; FormerPlayer = true }
//      Stats = { Wins = 58; Losses = 24 } }
```

## 6. 同じチームかどうかの確認

成績を調べているうちに、チームとその成績のリストを作っています。ときどき間違えて、リストに重複した項目が入ってしまうことがあります。2つのチームを受け取り、同じチームなら`true`を、そうでなければ`false`を返す`isSameTeam`関数を実装します。

```fsharp
let pacersCoach = createCoach "Larry Bird" true
let pacersStats = createStats 58 24
let pacersTeam = createTeam "Indiana Pacers" pacersCoach pacersStats

let lakersCoach = createCoach "Del Harris" false
let lakersStats = createStats 61 21
let lakersTeam = createTeam "LA Lakers" lakersCoach lakersStats

isSameTeam pacersTeam lakersTeam
// => false
```

## 7. チームを応援すべきかどうかの確認

多くのチームと試合を見てきた結果、あるアルゴリズムを思いつきました。次のいずれかに当てはまるなら、そのチームを応援します。

- コーチの名前が"Gregg Popovich"である
- コーチが元選手である
- チームの名前が"Chicago Bulls"である
- チームが60試合以上勝っている
- チームの負け数が勝ち数より多い

チームを受け取り、そのチームを応援すべきなら`true`を、そうでなければ`return`でfalseを返す`rootForTeam`関数を実装します。

```fsharp
let spursCoach = createCoach "Gregg Popovich" false
let spursStats = createStats 56 26
let spursTeam = createTeam "San Antonio Spurs" spursCoach spursStats
rootForTeam spursTeam
// => true
```
