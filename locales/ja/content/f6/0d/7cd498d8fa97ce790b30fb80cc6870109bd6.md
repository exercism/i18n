# 説明

`accumulate`の操作を実装してください。`accumulate`は、コレクションと、その各要素に対して行う操作を受け取ります。そして、その操作を入力のコレクションの各要素に適用した結果を集めた、新しいコレクションを返します。

次の数値のコレクションがあるとします。

- 1, 2, 3, 4, 5

そして、次の処理を行うクォーテーションがあるとします。

- 数値を2乗する（`[ sq ]`）

コードは、次の2乗した値のコレクションを生成できる必要があります。

- 1, 4, 9, 16, 25

## 制約

標準ライブラリが提供するcollect/map/fmapなどの機能には、手を出さないでください！

代わりに、他の基本的な道具を使って自分で解いてください。
