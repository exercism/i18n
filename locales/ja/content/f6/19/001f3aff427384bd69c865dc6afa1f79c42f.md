# 説明

学校の演劇では、どの役にもアンダースタディがいます。舞台監督に自分が誰だか気づかれないまま、代わりに舞台に立ってその役に必要なことをこなせる人のことです。

5つのタスクはすべて`UNDERSTUDY`クラスに入れます。最初の2つは普通のルーチンで、後のタスクがそれらを束縛します。

## 1. 台詞の2つの言い方

まず、台詞を大文字にして返す`shout`を書きましょう。次に、台詞を小文字にして前後に`"..."`を付けて返す`whisper`を書きましょう。

```sather
UNDERSTUDY::shout("who's there")
-- => "WHO'S THERE"
UNDERSTUDY::whisper("Who's There")
-- => "...who's there..."
```

## 2. 台詞を練習する

`rehearse`は、台詞とその言い方を受け取り、結果を返します。2番目の引数の型は`ROUT{STR}:STR`です。

```sather
UNDERSTUDY::rehearse("who's there", bind(UNDERSTUDY::shout(_)))
-- => "WHO'S THERE"
```

## 3. シーン全体

`run_scene`は、台詞の配列とその言い方を受け取り、すべてをその言い方にしたうえで`" "`でつないで返します。

```sather
UNDERSTUDY::run_scene(|"Enter", "Exit"|, bind(UNDERSTUDY::shout(_)))
-- => "ENTER EXIT"
```

空のシーンは空の文字列です。

## 4. 言い方を返す

`understudy_for`は、スタイルの名前（`"shout"`かそれ以外か）を受け取り、`ROUT{STR}:STR`を返します。`"shout"`なら叫ぶ方、それ以外ならささやく方になります。

```sather
part ::= UNDERSTUDY::understudy_for("shout");
part.call("who's there")
-- => "WHO'S THERE"
```

## 5. 引数を固定する

台詞と回数を受け取り、その台詞をその回数だけ、間に何も挟まずにつないで返す`repeat`を書きましょう。

```sather
UNDERSTUDY::repeat(3, "Ha")
-- => "HaHaHa"
```

次に`doubler`を書きましょう。これは引数を取らず、与えられたものを2回繰り返す`ROUT{STR}:STR`を返します。回数をもう埋めた状態で`repeat`を束縛することで作ります。

```sather
UNDERSTUDY::doubler.call("Ha")
-- => "HaHa"
```
