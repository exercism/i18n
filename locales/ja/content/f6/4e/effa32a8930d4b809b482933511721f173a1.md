# はじめに

Elmでテキストを表すときの基本になるのが、文字と文字列です。
文字列は文字の配列と考えることができ、`List`モジュールの関数のほとんどには、`String`モジュールに対応するものがあります。

## 文字

`Char`型は、シングルクォートで囲んだ1つのUnicode文字を表します。たとえば`'a'`のように書きます。
`Char`モジュールには、文字がどんな性質を持つかを判定する関数（`Char -> Bool`）が用意されています。`isUpper`、`isLower`、`isAlpha`、`isAlphaNum`などです。
また、文字を変換する関数として`toUpper`、`toLower`、`toLocaleUpper`、`toLocaleLower`があり、`toCode`と`fromCode`を使えば、Unicodeの数値（`Int`）との相互変換もできます。

## 文字列

`String`型は、文字列を効率よく操作するための組み込みの表現で、任意のUnicode文字の並びを表せます。たとえば、"this is an Elm string."のような文字列です。
複数行にわたる文字列は、3つのダブルクォートで囲んで表し、その中では引用符や改行をエスケープせずにそのまま書けます。
```elm
"""
    This is a multiline string.
All line-breaks and whitespace,
are preserved. 
"""
```

## 文字列の関数

`String`モジュールには、下の表にまとめた関数がすべて含まれています。
よく使う関数には、次のようなものがあります。

`cons : Char -> String -> String`は、文字列の先頭に1つの文字を追加します。
```elm
cons 'T' "he truth is out there" 
    --> "The truth is out there"
```

`(++): String -> String -> String`は、2つの文字列を連結します。
```elm
"butter" ++ "fly" 
    --> "butterfly"
```

`split : String -> String -> List String`は、文字列を、指定した区切り文字のところで文字列の配列に分割します。
```elm
split ";" "cat;dog;cow" 
    --> ["cat", "dog", "cow"]
```

`join : String -> List String -> String`は、文字列の配列を、指定した区切り文字でつなげます。
```elm
join "a" ["H", "w", "ii", "n"] 
    --> "Hawaiian"
```
`replace : String -> String -> String -> String`は、指定した部分文字列をすべて置き換えます。
```elm
replace "Hello" "Goodbye cruel" "Hello world." 
    --> "Goodbye cruel world."
```

`length : String -> Int`は、文字列の文字数を返します。
```elm 
length "Hello world." 
    --> 12
```

`toInt : String -> Maybe Int`は、文字列を`Just Int`に変換しようとし、形式が正しくない文字列には`Nothing`を返します。
```elm
toInt "-42" 
    --> Just -42
```    

`contains : String -> String -> Bool`は、2番目の文字列に1番目の文字列が含まれているかどうかを調べます。
```elm
contains "the" "theory" 
    --> True
```

`map : (Char -> Char) -> String -> String`は、文字列内のすべての`Char`に、指定した関数を適用します。
ここで渡す関数は、`Char`を受け取って`Char`を返すものでなければならない点に注意してください。
```elm
map (\c -> if c == '/' then '.' else c) "a/b/c" 
    --> "a.b.c"
```
