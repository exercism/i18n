## 手順

ミッキーとミネルバのために、完全な迷路を作るのが今回の課題です。完全な迷路とは、解が1つしかなく、孤立した区画もない迷路のことです。知っておくべきことは次のとおりです。

- 迷路は長方形で、始まりと終わりに開口部があります。
- 迷路には部屋と通路があり、それらは直角に交わります。
- プログラムは、rowsとcolumnsの2つの入力を受け取ります。迷路の大きさは5～100セルとします。
- 幅が`x`列、高さが`y`行の迷路は、幅が`2x + 1`文字、高さが`2y + 1`文字になります。
- シードが指定されていない場合は、ランダムな迷路を生成します。同じシードを何度指定しても、毎回同じ迷路が生成されるようにします。
- 壁の描画には[罫線文字][Box-drawing]を使い、左側の入口と右側の出口には矢印記号（⇨）を使います。

冒険好きなネズミたちのために、完全な迷路を作ってみましょう！

### 例

1. 5x5セルの小さな正方形の迷路（11x11文字）
```text
	┌───────┬─┐
	│       │ │
	│ ┌─┬── │ │
	│ │ │   │ ⇨
	│ │ │ ──┤ │
	⇨ │ │   │ │
	┌─┤ └── │ │
	│ │     │ │
	│ │ ────┘ │
	│         │
	└─────────┘
```
2. 6x18セルの長方形の迷路
```text
	┌───────────┬─────────┬───────────┬─┐
	│           │         │           │ │
	│ ┌───────┐ │ ┌─┐ ──┐ └───┐ ┌───┐ │ │
	│ │       │ │ │ │   │     │ │   │   ⇨
	│ └─┐ ┌─┐ │ │ │ ├── ├───┐ │ │ ──┼── │
	│   │ │ │   │   │   │   │ │ │   │   │
	└── │ │ ├───┴───┤ ┌─┘ ┌─┘ │ ├── │ ──┤
	⇨   │   │       │ │   │   │ │   │   │
	┌─┬─┴─┐ └─┐ ┌─┐ │ └─┐ │ ┌─┘ │ ──┴─┐ │
	│ │   │   │ │ │ │   │   │   │     │ │
	│ │ │ └── │ │ │ └── │ ──┘ ┌─┘ ──┐ │ │
	│   │       │       │     │     │   │
	└───┴───────┴───────┴─────┴─────┴───┘
```

[Box-drawing]: https://en.wikipedia.org/wiki/Box-drawing_character
