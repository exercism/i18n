# スコープ解決演算子

スコープ解決演算子（`::`）を使うと、クラスを参照して、その定数・静的プロパティ・静的メソッドにアクセスできます。

```php
class MyClass
{
  public const MY_VALUE = 1;
}

// MyClass::class => "MyClass"
// MyClass::MY_VALUE => 1
```

## スコープ解決演算子で`self`と`static`を使う

オブジェクトが自分自身のスコープを参照しなければならないことがあります。そのために用意されているのが`self`キーワードで、これを使うとクラスが自分自身のスコープを参照できます。`self`キーワードを使うと、クラスをその名前から切り離せるので、長期的にコードを保守しやすくなります。

```php
class MyClass
{
  public const MY_VALUE = 1;

  public function getMyValue(): int
  {
    return self::MY_VALUE;
  }
}

// (new MyClass)->getMyValue() => 1
```

スコープ解決演算子と`static`キーワードを組み合わせると、参照を現在の子孫クラスに「遅延束縛」できます。

```php
// Update MyClass:
class MyClass
{
  public const MY_VALUE = 1;

  public function getMyValue(): int
  {
    return static::MY_VALUE;
  }
}
```

## スコープ解決演算子で`parent`を使う

`parent`キーワードは、親クラスの定数・プロパティ・メソッドを参照するために使います。よくあるのは、オブジェクトをインスタンス化するときに親クラスのコンストラクターを呼び出す場合です。

```php
class ChildClass extends ParentClass
{
  public function __construct(): void
  {
    parent::__construct();
  }
}
```

## 注意点

### 定数・プロパティ・メソッドの可視性

スコープ解決演算子も、`public`・`private`・`protected`という可視性修飾子が定めるルールに従います。
