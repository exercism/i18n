# データベースでの従業員オンボーディング

## 問題

ABC Corpは、従業員への小口現金の支払い情報をすべてデータベースで管理しようとしています。そこで、ABC Corpの経理部門がこれを実装するのを手伝いましょう。ABC Corpは事業を拡大しているため、新しい従業員が入社するたびに、その従業員をシステムに追加する作業がよく発生します。

この課題では、与えられた新しい従業員の情報をデータベースの`Employee`テーブルに追加し、自動生成された`employee_id`列の値を、それを調べるための別のクエリをデータベースに発行せずに返します。実行中にエラーが発生した場合は、`-1`を返します。

## データベースの詳細

この問題では、用意されたH2データベースを使用します。

> サンプルのデータベースファイルは`gofigure.mv.db`で、データベース名は`gofigure`です。これは`db`フォルダー内にあります。

サンプルのH2データベースには、いくつかのサンプルデータとともに、次のテーブルがすでにあります。列名とデータ型は次のとおりです。

**テーブル名**：`Employee`

| **列:**      | 型 |
| -----------       | ----------- |
| `employee_id`     | 整数、自動インクリメントの主キー       |
| `name`            | 文字列        |
| `city`            | 文字列        |
| `department`      | 文字列        |
| `age`             | 整数        |

**テーブル名**：`Payment`

| **列:**      | 型 |
| -----------       | ----------- |
| `payment_id`      | 整数、自動インクリメントの主キー       |
| `date`            | 日付        |
| `amount`          | 小数        |
| `employee_id`     | 整数        |
| `reason`          | 文字列        |

* データベースファイルは`gofigure.mv.db`です。JDBC URLは`jdbc:h2:file:/path/to/db/file`のように指定します。
* ユーザー名：`root`
* パスワード：`root`

## 制約

* クエリとBallerinaのサンプルを検証するには、`db`フォルダーにあるH2データベースファイルを使用します
* Ballerina.tomlでH2データベースドライバーをプラットフォーム依存関係として追加するには、Mavenの依存関係パラメーターを使う方法を使用します
* 自動生成されたIDを調べるためにデータベースへ別のクエリを発行しないでください


## テスト環境

* `bal test`でテストを実行できます。テストは、用意されたサンプルDBに対して実行されます。

## 例

### 例1

**入力**：dbFilePath: `"./db/gofigure"`、name: `“John Doe”`、city: `“Omaha”`、department: `“Sales”`、age: `24`

**出力**：`4`

### 例2

**入力**：dbFilePath: `"./db/invalidDB"`、name: `“John"`、city: `"Colombo"`、department: `"HR"`、age: `25`

**出力**：`-1`

## ヒント

* データベースを操作するには、[ballerinax/java.jdbc](https://central.ballerina.io/ballerinax/java.jdbc)モジュールを使用します
* JDBCドライバーを依存関係として追加する手順については、[前提条件](https://lib.ballerina.io/ballerinax/java.jdbc/latest)セクションを参照してください
* データを挿入するには、[execute](https://lib.ballerina.io/ballerinax/java.jdbc/latest#Client-execute)リモートメソッドを使用します
* [DMLとDDLの操作](https://ballerina.io/learn/by-example/mysql-execute-operation/)の例を参照してください
