# ウェブサイトのアカウント権限

## ストーリー

この演習では、インターネットフォーラム上のユーザーアカウントの権限を確認します。このフォーラムでは、3種類の権限を扱います：

- Read
- Write
- Delete

アカウントには3つの種類があり、それぞれデフォルトの権限が異なります：

- ゲスト：投稿を読むことができます。
- ユーザー：投稿を読むことと書くことができます。
- モデレーター：投稿を読む、書く、削除することができます。

個々の権限が変更されることもあります。たとえば、ゲストアカウントに投稿を書く権限を追加する場合です。

## タスク

次は、ウェブサイトの権限の演習に合うタスクの例です：

- アカウントの種類ごとにデフォルトの権限を取得する
- 権限を付与する
- 権限を取り消す
- 権限を確認する
