# はじめに

`try..rescue`を使うと、エラーが起きたときにそれを捕まえられる、強力な仕組みになります。エラーを捕捉できると、必要なときに、関数が決まった値を返せるようになります。`try..rescue`には、ほかにも活用できる2つの機能があります。

- `else`ブロック
  - tryブロックが成功したとき、その結果がこのブロックと照合されます。
- `after`ブロック
  - tryブロックが成功しても例外を発生させても、`after`ブロックのコードは、その時点でプログラムが動いていれば必ず実行されます。
  - `after`ブロックの結果は、呼び出し元のスコープには返されません。

```elixir
try do
  :a
rescue
  _ -> :error
else
  :a -> :success
after
  :some_action
end

# => :success
```
