# はじめに

Rubyの例外は、多くの言語と同じく、予期しない出来事に対処するための仕組みです。プログラムがクラッシュするのを防ぐには、例外を適切に扱うことが大切です。

例外は、自分で明示的に発生させることも、Rubyのインタプリターが発生させることもあります。例外が発生すると、プログラムは通常の動作を中断し、最終的にはエラーメッセージを出して終了します。

```ruby
raise ArgumentError.new("Something went wrong!")
=> Traceback (most recent call last):
.
.
ArgumentError (Something went wrong!)
```

```ruby
1/0
=> Traceback (most recent call last):
.
.
ZeroDivisionError (divided by 0)
```

このようにプログラムが終了してしまうのを止めたいときは、例外に反応する必要があります。これを例外の「捕捉」と呼びます。

```ruby
begin
  # ...any code that raises an exception
rescue
  puts 'Got an exception'
end
```

このプログラムはクラッシュせず、"Got an exception"と出力します。終了する代わりに、Rubyは`rescue`ブロックのコードを実行し、そこがメッセージを出力します。

Rubyのすべてがそうであるように、例外もオブジェクトで、通常はその例外に関するデータを持っています。例外オブジェクトを取得するには、次のようにします。

```ruby
begin
  # ...any code that raises an exception
rescue => e
  puts "Exception class: #{ e.class.name }"
  puts "Exception Message:#{e.message}"
end
```

Rubyでは、自分で例外を発生させることもできます。たとえば次のとおりです。

```ruby
begin
  raise ArgumentError.new("Invalid argument")
rescue ArgumentError => e
  puts e.message
end
```

先ほどの例外はRubyに組み込みの例外のひとつですが、独自の例外を定義して発生させることもできます。

```ruby
class CustomError < StandardError
end

raise CustomError.new("Something went wrong")
```
