# 指示

バレンタインデーです。パートナーがいくつかアクティビティの案を考えていて、それぞれを`yes`、`no`、`maybe`で評価してほしいと言っています。

アクティビティは2要素の配列`{ tag value }`で表します。`tag`は`board-game`、`chill`、`movie`、`restaurant`、`walk`のいずれかです。

| アクティビティ                  | 形式                       |
| ------------------------- | --------------------------- |
| ボードゲームで遊ぶ         | `{ board-game f }`          |
| のんびり過ごす             | `{ chill f }`               |
| `genre`の映画を観る  | `{ movie genre }`           |
| `cuisine`の料理店で食べる  | `{ restaurant cuisine }`    |
| `km`キロメートル歩く      | `{ walk km }`               |

ジャンルは`crime`、`horror`、`romance`、`thriller`のいずれかです。料理は`korean`または`turkish`です。

## 1. 料理を評価する

`rate-restaurant`を定義しましょう。スタックから料理を取り出し、評価を返します。

- `korean` → `yes`
- `turkish` → `maybe`

```factor
korean rate-restaurant .   ! => yes
turkish rate-restaurant .  ! => maybe
```

## 2. 映画のジャンルを評価する

`rate-movie`を定義しましょう。ジャンルを受け取り、次を返します。

- `romance` → `yes`
- それ以外 → `no`

```factor
romance rate-movie .   ! => yes
horror rate-movie .    ! => no
```

## 3. 散歩を評価する

`rate-walk`を定義しましょう。キロメートル数を受け取り、次を返します。

- `11`より大きい → `yes`
- `6`より大きく`11`まで → `maybe`
- それ以外 → `no`

```factor
12 rate-walk .   ! => yes
8 rate-walk .    ! => maybe
3 rate-walk .    ! => no
```

## 4. アクティビティを評価する

`rate-activity`を定義しましょう。スタックから`{ tag value }`のアクティビティを取り出し、評価を返します。上で定義した補助の関数を再利用します。

- `board-game`、`chill` → 常に`no`
- `movie` → `rate-movie`に任せる
- `restaurant` → `rate-restaurant`に任せる
- `walk` → `rate-walk`に任せる

```factor
{ restaurant turkish } rate-activity .   ! => maybe
{ movie horror } rate-activity .         ! => no
{ walk 12 } rate-activity .              ! => yes
{ board-game f } rate-activity .         ! => no
```

## 5. 評価を集計する

`approval-counts`を定義しましょう。アクティビティの配列を受け取り、それぞれの評価がいくつあったかを3要素の配列`{ yes-count maybe-count no-count }`として返します。

```factor
{ { restaurant korean } { restaurant turkish } { walk 3 } { movie romance } }
approval-counts .
! => { 2 1 1 }
```
