# はじめに

Common Lispはほとんどの演算で標準的な算術演算子を使いますが、よく知られた「中置記法」ではなく「前置記法」を使うという点で、少し独特です。

視覚的に見てみましょう。

```lisp
;; Infix-notation (non-lisp languages)
1 + 2 + 3 + 4 + 5 ; => 15
;; Prefix-notation (lisp languages)
(+ 1 2 3 4 5)     ; => 15
```

前置記法では、`2 + 2`のような演算が、あまり見慣れない`(+ 2 2)`という形になります。その代わり、複数の数値を一度に扱うのがずっと簡単になります。

## 基本的な計算

Common Lispには、足し算・引き算・掛け算・割り算のための`+`、`-`、`*`、`/`という、おなじみの関数がそろっています。

割り算を考えるときには、割った余りを知りたくなることがあります。それには`mod`（moduloの略）という関数を使います。この関数は、数値と除数を入力として受け取ります。

```lisp
(mod 4 2)  ; => 0
(mod 2 4)  ; => 2
(mod 10 3) ; => 1
```

## 数値の比較

最後に、`=`（等しい）、`/=`（等しくない）、`>=`（以上）といった関数を使って、数値を比較すると便利なことがあります。
これらの比較が真のとき（`(= 1 1)`のように）、戻り値は`T`です。そうでないとき（`(> 0 1)`のように）は`NIL`を返します。
