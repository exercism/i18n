# テスト

## テストの実行

ある演習のディレクトリにいると、2つのサブディレクトリがあるはずです。

* `src`には、その演習の解答が入っています
* `spec`には、その演習で実行するテストが入っています

正しいディレクトリ（つまり、`src`と`spec`が入っているディレクトリ）にいれば、`crystal spec`を実行するとその演習のテストを実行できます。

```bash
$ pwd
/Users/johndoe/Code/exercism/crystal/hello-world

$ ls
GETTING_STARTED.md README.md          spec               src

$ crystal spec
```

これは`spec`ディレクトリにあるすべてのテストファイルを実行します。

それぞれのテストファイルでは、最初のテスト以外はすべてスキップされています。

テストが1つ通ったら、`pending`を`it`に変えて、次のテストのスキップを解除しましょう。

## Crystalのフォーマット

提出する前に、解答に対して`crystal tool format`を実行することをおすすめします。

カレントディレクトリにあるものはすべて、次のようにしてフォーマットできます。

```bash
$ crystal tool format ./
```

あるいは、ファイルを選んでフォーマットすることもできます。

```bash
$ crystal tool format ./<path>/<to>/<file>
```

## 解答の提出

解答を提出するときは、`src`ディレクトリにあるソースファイルを必ず提出してください。

```bash
$ exercism submit src/<exercise>.cr
```
