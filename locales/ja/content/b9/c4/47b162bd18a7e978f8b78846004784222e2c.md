# 手順

パスポートの有効期限がもうすぐ切れるので、更新のために市役所に立ち寄る必要があります。これまでの経験から、自分の市役所が必ずしも対応しやすいわけではないと分かっているので、常に「ハッピーパスに集中する」よう最善を尽くすことにします。

新しいパスポートを受け取るのに必要な申請書を印刷して記入し、車に飛び乗ってブロックを一周し、駐車して役所へ向かいます。

以下のタスクはすべて、`get_new_passport/3`を実装して拡張していく必要があります。

## 1. 建物に入る

実は、この建物は午後しか開いておらず、しかも毎日同じ時間に開いているわけではありません。

現在時刻（`get_new_passport/3`の第1引数として渡されます）を指定して、`enter_building/1`を呼び出します。建物が開いていれば、この関数は`:ok`と、後で必要になるタイムスタンプのタプルを返し、そうでなければ`:error`とメッセージのタプルを返します。とりあえず、ハッピーパスでは`:ok`のタプルを返すようにします。

`:error`のタプルが返ってきた場合は、`else`ブロックでそれを返します。

## 2. 案内所に行き、どの窓口に行くべきかを調べる

案内所は長いコーヒーブレイクで有名です。運よく誰かを見つけられれば、生年月日に応じてどの窓口に行けばよいかを説明してくれる説明書を渡してくれます。

現在時刻を指定して、`find_counter_information/1`を呼び出します。`:ok`と、無名関数で表される説明書のタプルが返るか、`:coffee_break`とさらなる指示のタプルが返るかのどちらかです。説明書を受け取るハッピーパスでは、それを誕生日（`get_new_passport/3`の第2引数）に適用します。行く必要のある窓口の番号が返るので、その窓口番号を含む`:ok`のタプルを返します。

`:coffee_break`のメッセージが返ってきた場合は、`:retry`と、現在時刻の15分後を指す`NaiveDateTime`のタプルを返します。前と同様、`:error`のタプルが返ってきた場合はそれを返します。

## 3. 窓口に行き、申請書にスタンプを押してもらう

どういうわけか、窓口によって必要な申請書の色が異なります。もちろん、ウェブサイトで最初に見つけたものを印刷したので、ハッピーパスに集中して、うまくいくことを願うばかりです。

入り口で受け取ったタイムスタンプ、窓口、持ってきた申請書（`get_new_passport/3`の最後の引数）を指定して、`stamp_form/3`を呼び出します。`:ok`と、パスポート番号の検証に使われるチェックサムのタプルが返るか、`:error`とメッセージのタプルが返るかのどちらかです。ハッピーパスでは、チェックサムを含む`:ok`のタプルを返すようにします。`:error`のタプルが返ってきた場合は、それを返します。

## 4. 新しいパスポートを受け取る

ついに、必要な書類がすべてそろいました。

先ほど受け取ったタイムスタンプ、窓口、チェックサムを指定して、`get_new_passport_number/3`を呼び出します。最終的なパスポート番号の文字列が返ってくるので、あとはその文字列を`:ok`のタプルで返して家に帰るだけです。
