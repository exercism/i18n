# はじめに

Factorは[`io`][io]ストリームを介して読み書きします。ほとんどのコードは、*暗黙の*入出力とやり取りします。`read`や`readln`、`print`、`write`などのワードは、現在束縛されているストリームに対して操作を行い、少数の`with-…`コンビネータが、クォーテーションの間だけその暗黙のストリームを一時的に差し替えます。

```factor
USING: io io.streams.string ;

"hello\nworld" <string-reader> [ readln . readln . ] with-input-stream
! prints "hello"
! prints "world"

[ "captured" print ] with-string-writer .
! prints (returns) "captured\n"
```

`<string-reader>`と`<string-writer>`は、この演習で使うメモリ内のストリームです。`<file-reader>`と`<file-writer>`は、ディスク上の対応するストリームで、同じインターフェースを持ちます。スコープを限定したファイルアクセスには、これらを`with-file-reader`/`with-file-writer`と組み合わせて使います。

[io]: https://docs.factorcode.org/content/vocab-io.html
