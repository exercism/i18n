# 文字列

`STR`はテキストを保持します。文字列は二重引用符で囲んで書きます。

```sather
   composer : STR is
      return "Sibelius";
   end;
```

`STR`は、一度作られると決して変わりません。ここから先の操作はどれも、対象の文字列を書き換えるのではなく、*新しい*文字列を返します。

## 連結

```sather
"Jean" + " " + "Sibelius"      -- "Jean Sibelius"
```

`+`は数値を文字列に連結することもできます。こうして数値が文の中に入ります。

```sather
"Opus " + 27           -- "Opus 27"
```

## 長さ

```sather
"Sibelius".size        -- 8
"".size                -- 0
```

`.size`は文字の数を数え、結果は`INT`になります。

## 部分

| 呼び出し | 結果 |
| --- | --- |
| `"Sibelius".head(3)` | `"Sib"` |
| `"Sibelius".tail(4)` | `"lius"` |

存在する以上の文字を求めても、失敗せずに、存在する分だけを返します。

## 比較

`=`は2つの文字列が同じテキストかどうかを調べ、`/=`は異なるかどうかを調べます。

```sather
"forte" = "forte"      -- true
"forte" = "Forte"      -- false
```

大文字と小文字は区別されます。`.upper`と`.lower`は、一方の大文字小文字に揃えたコピーを返します。区別せずに比較したいときは、これを使うのが一般的です。

```sather
"Forte".lower                    -- "forte"
"Forte".lower = "forte".lower    -- true
```

## サイズについて

`STR`はバイトの並びであり、`.size`はバイト数を数えます。英語のテキストでは、文字を数えるのと同じです。アクセント記号や他の文字体系を含むテキストでは同じにはなりません。そうした文字は1文字あたり複数のバイトを使うからです。
