# 説明

Turndit Inc.は、レコードの曲間をスキップできる新しいターンテーブルを製造しています。それがなぜ良いことなのかは誰にもわかりませんが、当の本人たちはどうしてもやると言い張っているので、そっとしておきましょう。現在同社は、必要なときに針をレコードの正しい位置へ導く方法を解明するための助けを必要としています。

この仕組みには2つの部分があります。

針はターンテーブルの上に吊り下げられており、レコード上を左右と前後に移動できます（クレーンゲームを思い浮かべてください！）。
針を制御する機構は直線的に動くため、その位置を座標の組`(x, y)`で追跡しています。原点はレコードの中心です。

さらに、針の位置と、前の曲または次の曲が始まる位置を追跡する光学装置があります。
レコードは回転しているため、2つの点の間の半径方向の差と角度の隔たりを`(r, θ)`で追跡するほうが簡単です。ここでも原点はレコードの中心です。

Turnditは、別の曲が選ばれたときに針が移動する新しい`(x', y')`座標を求める方法を知る必要があります。

~~~~exercism/note
These operations can be done through trigonometric functions and/or rotation matrices, but they can be made simpler (and more fun, I assure you!) with the use of complex numbers via rotations and radial displacements.
In fact, each function in this exercise can be written in assigment form (i.e. a one-liner) using complex numbers and built-in Julia methods/functionality, should you so desire.
~~~~

## 1. 直交座標から複素数を構成する

`x`座標と複素平面上の`y`座標を受け取り、それに相当する複素数を返す`z(x, y)`関数を実装しましょう。

```julia-repl
julia> z(1, 1)
1.0 + 1.0im

julia> z(4.5, -7.3)
4.5 - 7.3im
```

## 2. 極座標から複素数を構成する

半径座標`r`と角度`θ`（ラジアン）を受け取り、それに相当する複素数を直交形式で返す`euler(r, θ)`関数を実装しましょう。

```julia-repl
julia> euler(1, π)
-1.0 + 0.0im

julia> euler(3, π/2)
0.0 + 3.0im

julia> euler(2, -π/4)
1.4142135623730951 - 1.414213562373095im  # √2 - √2im
```

## 3. 2Dベクトルの回転を行う

`x`座標、`y`座標、角度の変位`θ`（ラジアン）を受け取る`rotate(x, y, θ)`関数を実装しましょう。
この関数は、与えられた角度`θ`だけ原点を中心に点を回転させ、新しい座標をタプル`(x', y')`として返してください。

```julia-repl
julia> rotate(0, 1, π)
(0, -1)

julia> rotate(1, 1, -π/2)
(1, -1)
```
## 4. 半径方向の変位を行う

`x`座標、`y`座標、半径方向の変位`r`を受け取る`rdisplace(x, y, r)`関数を実装しましょう。
この関数は、x-y座標を半径に沿って`r`の分だけ変位させ、新しい座標をタプル`(x', y')`として返してください。

```julia-repl
julia> rdisplace(0, 1, 1)
(0, 2)

julia> rdisplace(1, 1, √2)
(2, 2)
```
## 5. 目的の曲を見つける

針の`x`座標と`y`座標、および針と目的の曲の先頭との間の変位`r`と`θ`を受け取る`findsong(x, y, r, θ)`関数を実装しましょう。針の新しい座標をタプル`(x', y')`として返してください。

```julia-repl
julia> findsong(0, 1, 3, -π/2)
(4, 0)

julia> findsong(√2, √2, 0, 3π/4)
(-2, 0)
```
