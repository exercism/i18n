でも、少し整理されていません。Azaraの座標はRuiのものとは書式も並び順も違うようで、どの宝がどの場所に対応するのかを確かめるには、二つのリストを何度も見比べなければなりません。
駆け出しのPython使いである二人は、宝探しの情報をうまく整理するための小さなプログラム（というより関数の集まり）を書くのを手伝ってほしいと、頼みに来ました。


## 1. 座標を取り出す

Azaraのリストから`(treasure, coordinate)`のペアを受け取り、取り出した地図上の座標だけを返す`get_coordinate()`関数を実装しましょう。


```python
>>> get_coordinate(('Scrimshawed Whale Tooth', '2A'))
2A
```

## 2. 座標を整形する

"2A"という形式の座標を受け取り、`("2", "A")`という形式のタプルを返す`convert_coordinate()`関数を実装しましょう。


```python
>>> convert_coordinate("2A")
("2", "A")
```

## 3. 座標を照合する

`(treasure, coordinate)`のペアと`(location, coordinate, quadrant)`のレコードを受け取り、それぞれの座標を比べる`compare_records()`関数を実装しましょう。
座標が「一致」すれば**`True`**を、一致しなければ**`False`**を返します。
正確に比べられるように、必要に応じて座標を整形し直します。


```python
>>> compare_records(('Brass Spyglass', '4B'), ('Seaside Cottages', ('1', 'C'), 'blue'))
False

>>> compare_records(('Model Ship in Large Bottle', '8A'), ('Harbor Managers Office', ('8', 'A'), 'purple'))
True
```

## 4. 一致したレコードを組み合わせる

Azaraのリストから`(treasure, coordinate)`のペアを、Ruiのリストから`(location, coordinate, quadrant)`のレコードを受け取り、**座標が一致すれば**`(treasure, coordinate, location, coordinate, quadrant)`を返す`create_record()`関数を実装しましょう。
座標が一致_しなければ_、文字列**"not a match"**を返します。
正確に比べられるように、必要に応じて座標を整形し直します。


```python
>>> create_record(('Brass Spyglass', '4B'), ('Abandoned Lighthouse', ('4', 'B'), 'Blue'))
('Brass Spyglass', '4B', 'Abandoned Lighthouse', ('4', 'B'), 'Blue')

>>> create_record(('Brass Spyglass', '4B'), ('Seaside Cottages', ('1', 'C'), 'blue'))
"not a match"
```
