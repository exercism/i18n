# テスト

## セットアップ

必要な依存関係をインストールするには、[WebAssemblyのセットアップ手順][docs-exercism-wasm]に沿って進めてください。

## 必要なもの

演習の依存関係をインストールします：

```shell
# Using npm
npm install

# Alternatively using yarn
yarn
```

## テストスイートを通す

すべての演習には、解答を提出する前に検証するためのテストスイートが付属しています。
演習のディレクトリでコマンドプロンプトを開き、次のコマンドを実行するとテストを実行できます：

```bash
# Using npm
npm test

# Alternatively using yarn
yarn test
```

テストスイートによっては、最初のテスト以外がすべてスキップされています。

1つのテストが通ったら、`xtest`を`test`に変えることで次のテストを有効にできます。

## 独自のテストを書く

追加の独自テストを書きたい場合は、新しいファイル`custom.spec.js`を作成し、新しいファイルと一緒に解答とともに提出してください：

```shell
exercism submit numbers.wat custom.spec.js
```

[docs-exercism-wasm]: https://exercism.org/docs/tracks/wasm/installation
