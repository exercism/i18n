# はじめに

コメントを使うと、コードの動作に影響を与えずにメモを残せます。
1行コメントは`//`で始まり、複数行コメントは`/*`と`*/`で囲みます。

```go
// This is a single-line comment.

/*
This is a
multiline comment.
*/
```

コメントは、書く場所によって役割が異なります。

## コードコメント

コードコメントは、何をするかではなく、なぜそうするのかを説明します。
コードを読んだだけでは判断の理由が分からないときに使いましょう。

```go
results = results[1:] // skipping the header row
```

## ドキュメントコメント

ドキュメントコメントは宣言の直前に置き、コメントと宣言の間に空行は入れません。
[`godoc`][godoc]がこれらを解析して、パッケージのドキュメントを生成します。
ドキュメントコメントは、識別子の名前で始まり、ピリオドで終わる完全な文にします。

パッケージコメントはパッケージ名で始めます。

```go
// Package kelvin provides tools to convert temperatures to and from Kelvin.
package kelvin
```

関数コメントは関数名で始めます。

```go
// CelsiusFreezingTemp returns an integer value equal to the temperature at which water freezes in degrees Celsius.
func CelsiusFreezingTemp() int {
	return 0
}
```

[godoc]: https://go.dev/blog/godoc
