# 概要

真偽値は、条件が`true`か`false`かどうかを表します。
Goでは、`bool`型はこの2つの値のどちらかしか取ることができません。

```go
isDoorLocked := true
hasKey := true
knowsCode := false
```

## 論理演算子

論理演算子は、1つまたは2つの真偽値を受け取り、真偽値の結果を返します。

| 演算子 | 名前 | 動作                                       |
| -------- | ---- | ---------------------------------------------- |
| `!`      | 否定  | 1つの真偽値の反対を返します |
| `&&`     | 論理積  | 両側が`true`のときだけ`true`を返します |
| `\|\|`   | 論理和   | どちらかの側が`true`なら`true`を返します |

真偽値の反対が必要なときは、`!`（否定）を使います。

```go
!isDoorLocked // false
```

両方の条件が`true`でなければならないときは、`&&`（論理積）を使います。

```go
canUnlockDoor := isDoorLocked && hasKey // true
```

少なくとも片方の条件が`true`であればよいときは、`||`（論理和）を使います。

```go
canOpenDoor := canUnlockDoor || knowsCode // true
```

論理演算子は、`!`、`&&`、`||`の順に評価されます。
括弧（`()`）を使ってコードをまとめ、どの演算を先に行うかを制御します。

```go
!true && false   // false because !true is evaluated first
!(true && false) // true because true && false is evaluated first
```
