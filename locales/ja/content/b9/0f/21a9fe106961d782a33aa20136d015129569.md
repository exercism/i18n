# 説明の補足

## Pythonトラックでのこの演習の構成

この演習のテストでは、解答をPythonのRelativeDistanceという`class`として実装することを想定しています。
Pythonの`class`に慣れていない場合は、[concept:python/classes]()や[Python公式ドキュメントの`classes`][classes in python]から始めるのがおすすめです。


`RelativeDistance`は、`family_tree`を使って初期化する必要があります（_詳しくは[`__init__()`][init]を参照してください_）。`family_tree`は、`keys`が個人、`values`がその個人の子どもの`list`である辞書です。
また、`degree_of_separation`[メソッド][methods]も実装する必要があります。これは、渡された家系図に含まれる個人`person_a`と`person_b`の間の分離度を返します。


`RelativeDistance`クラスのインスタンスを作成するために使われる`__init__`[特殊メソッド][special-methods]のスタブと、`degree_of_separation`メソッドのスタブが用意されています。
まず、`family_tree`のデータを表す適切な属性を`self`（_インスタンス_）に持たせるように、`__init__`をカスタマイズします。
次に、`degree_of_separation`メソッドにロジックを追加して、`person_a`と`person_b`の間の分離度を計算します。


## 例外メッセージ

[例外を送出する][raising-exceptions]必要があることもあります。
その際は、エラーの原因が何であるかを示す**意味のあるエラーメッセージ**を必ず含めましょう。
これによりコードが読みやすくなり、デバッグも格段に楽になります。
エラーの原因が特定の種類になるとわかっている場合は、[組み込みのエラー型][base-error-classes]のいずれかを送出しても構いませんが、その場合も意味のあるメッセージを含めるようにしましょう。

この演習では、複数の`ValueError`を「送出」するために[`raise`文][raise-statement]を使う必要があります。
最初のシナリオでは、`RelativeDistance.degree_of_separation`メソッドに渡された人物のどちらか、または両方が家系図に存在しない場合に、`ValueError`を送出する必要があります。

```python
# Example when Person A is not in the tree.
raise ValueError("Person A not in family tree.")
```

両方の人物が家系図に存在する場合は、ルールで定義された有効なつながりが2人の間にないときに、`ValueError`を送出する必要があります。

```python
# Example when there are no valid connections.
raise ValueError("No connection between person A and person B.")
```

テストが通るのは、期待される`exception`型を`raise`し、それに期待されるメッセージを含めた場合だけです。
この説明はすべてを網羅しているわけではないので、テストとその期待される結果をよく確認してください。
