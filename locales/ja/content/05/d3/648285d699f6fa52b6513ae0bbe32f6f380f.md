## GNU awkと任意精度演算

デフォルトでは、`awk`の数値は倍精度浮動小数点数として表されます。これで得られる精度は53ビットです（マニュアルの[表16.3][table-16.3]を参照してください）。残念ながら、この演習を完了するには足りません（ネタバレ注意、あるテストでは63ビットの精度が必要です）。

「精度が足りない」というのは、次のような状態です。
```sh
$ gawk 'BEGIN {
  n = 2 ^ 54
  if (n == n + 1)
    print "not enough precision"
  else
    print "OK"
}'
```
```none
not enough precision
```

GNU `awk`は、任意精度の数値を使うことができます。ただし、必要なライブラリが`awk`の実行ファイルに組み込まれている場合に限ります。`awk`のバージョンを確認して、"GNU MPFR"があるかどうかを見てみましょう。
```sh
$ gawk --version
GNU Awk 5.0.1, API: 2.0 (GNU MPFR 4.0.2, GNU MP 6.2.0)
...
```

組み込まれていれば、`-M`オプションでこの機能を有効にできます。
```sh
$ gawk -M 'BEGIN {
  n = 2 ^ 54
  if (n == n + 1)
    print "not enough precision"
  else
    print "OK"
}'
```
```none
OK
```

自分の`awk`に`-M`がない場合はどうすればよいでしょうか？　その場合は、`bc`のように任意精度演算ができる外部プログラムを呼び出す必要があります。その方法の例は、[パイプから`getline`で変数に読み込む][getline-pipe]の節を参照してください。


さらに詳しく：[任意精度演算][arbitrary]
