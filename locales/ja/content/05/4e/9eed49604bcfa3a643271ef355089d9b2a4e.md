# はじめに

[三項条件演算子][ternary-operator]は、`if-else`式を簡潔に書くための省略記法です。
条件を評価し、その条件が`true`か`false`かに応じて、2つの値のうちどちらかを返します。

この演算子は、`condition ? trueExpression : falseExpression`という3つの部分で構成されます。
`condition`が`true`と評価されれば、`trueExpression`が評価されて返されます。そうでなければ、`falseExpression`が評価されて返されます。

三項演算子は、1行で書けるシンプルな選択に最適です。

```swift
let showFahrenheit = true
let temperatureInCelsius = 30

let temperature = showFahrenheit ? temperatureInCelsius * 9 / 5 + 32 : temperatureInCelsius
print(temperature)
// Prints 86
```

上の例は、次のコードを簡潔に書いたものと同じです。

```swift
let showFahrenheit = true
let temperatureInCelsius = 30

let temperature = if showFahrenheit {
    temperatureInCelsius * 9 / 5 + 32
} else {
    temperatureInCelsius
}
```

[ternary-operator]: https://docs.swift.org/swift-book/LanguageGuide/BasicOperators.html#ID71
