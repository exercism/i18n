# はじめに

`bit`は、コンピューターの世界で最も細かい単位の値です。`bit`という言葉は、"binary digit"（2進数の桁）を短くしたものです。実行環境におけるデータ記憶の単位で、2つの値のどちらかを取るオブジェクトを保持できるだけの大きさがあります。つまり、`1`か`0`のどちらかの2進数の値を持ちます。ほかのすべてのデータ型は、複数の`bits`からできています。たとえば、`byte`は通常8つの`bits`でできています。

## ビットマスク

ビットマスクとは、個々のビットを設定するために使われる値のことです。たとえば、英語のアルファベットには26文字あります。少なくとも26ビットある値、たとえば符号なし32ビット整数をビットマスクとして使い、英語の各文字に対して`true`か`false`の状態を設定できます。必要な`true`か`false`の状態を扱えるだけのビット数があれば、どんな値でもビットマスクとして使えます。個々のビットの設定と読み取りは、ビット演算子を使って行います。

## ビット演算子

ある`string`の中にどの文字が現れるかを記録したいとしましょう。ここでは、英語のアルファベット26文字だけを使います。ビットマスクには符号なし32ビット整数を使います。`0`は、その文字が現れないことを表します。`1`は、その文字が1回以上現れることを表します。最初、ビットマスクのビット表現は、32個の`0s`が並んだ`00000000000000000000000000000000`です。一番右の位置が`A`に対応します。左から2番目の位置が`B`、その次が`C`、というように対応します。文字列内のすべての文字をループで処理するとしましょう。その場合、どの文字を設定するときにも使える1行のコードがあると便利です。

### ビット単位の左シフト演算子：ビットの位置を決める方法

`<<`は左シフトを行うビット演算子です。

文字が`A`なら左シフトは不要ですが、`B`なら1つ左に、`C`なら2つ左にシフトしたいところです。以下同様です。`chars`は`A`や`B`のような文字として見えますが、`char`はメモリー上では整数型として実装されているので、`char`で簡単な計算ができます。処理中の`char`を表す`letter`という変数があるとき、`1`を、`letter`と`A`の`char`との差だけ左にシフトすれば、必要な数だけ左にシフトできます。たとえば`1 << letter - 'A'`のように書きます。`A` - `A`は`0`なので、`letter`が`A`なら`0`だけ左にシフトします。`B` - `A`は`1`なので、`letter`が`B`なら`1`だけ左にシフトします。以下同様です。

### ビット単位の包含的OR演算子：ビットをセットする方法

ビットを*どこに*セットしたいかがわかったら、あとはビット単位の包含的OR演算子`|`を使って実際にセットできます。`|`演算子の結果は、左右どちらかのオペランドのビットが1になっている位置ごとに`1`になります。たとえば、`0010 | 0001`の結果は`0011`です。（この値は2進数では`11`ですが、10進数では`3`であることを覚えておきましょう。）結果を値に代入するには、`|`演算子を代入演算子と組み合わせて`|=`のように書き、ビットをセットします。話を簡単にするため、次の例ではループを使いませんが、ビットマスクで`ABA`という文字を処理する方法を示しています。

```c
#include <stdio.h>
#include <stdint.h>

int main() {
    // it's important to initialize the mask to 0 so we don't get garbage values
    uint32_t mask = 0;
    char letter_A = 'A';
    char letter_B = 'B';
    char letter_A_again = 'A';
    mask |= 1 << letter_A - 'A';
    mask |= 1 << letter_B - 'A';
    mask |= 1 << letter_A_again - 'A';
    // prints 3
    printf("%d", mask);
}
```

`A`に対してマスクの一番右の部分を`0001`にセットし、次に`B`に対してマスクを`0011`にセットします。もう一度`A`をセットしても、既存のマスクは変わりません。`A`がすでにセットされているかを確認すれば、ビットを再びセットせずに済みます。

### ビット単位のAND演算子：ビットを読み取る方法

`&`はビット単位のAND演算子です。`&`演算子の結果は、左右両方のオペランドのビットが1になっている位置ごとに`1`になります。たとえば、`0011 & 0001`の結果は`0001`です。次の例で、実際の動きを確認できます。

```c
#include <stdio.h>
#include <stdint.h>

int main() {
    uint32_t mask = 0;
    char letter_A = 'A';
    char letter_B = 'B';
    char letter_A_again = 'A';
    mask |= 1 << letter_A - 'A';
    mask |= 1 << letter_B - 'A';
    // prints A already set
    if (mask & 1 << letter_A_again - 'A')
        printf("A already set\n");
    else
        mask |= 1 << letter_A_again - 'A';
    printf("%d", mask);
}
```

### ビット単位のXOR演算子：ビットを反転させる方法

`^`はビット単位のXOR演算子です。*包含的*なOR演算子があるということは、動作の異なる*排他的*なOR演算子があるということです。`^`演算子の結果は、左右のオペランドの*片方だけ*のビットが1になっている位置ごとに`1`になります。たとえば、`0001 ^ 0011`の結果は`0010`です。一番右のビットは、*両方*のオペランドの一番右の位置が`1`なので、セットされません。排他的OR演算は、XORと表記されることもあります。ある値をXORした結果をもう一度XORすると、元の値に戻ります。これは、データの暗号化と復号に同じ鍵を使う、とても単純な暗号化に利用できます。たとえば

```c
#include <stdio.h>

int main() {
    char a = 'a';
    char b = 'b';
    char c = 'c';
    // we will use "a" for the "key"
    char first = a ^ 'a';
    char second = b ^ 'a';
    char third = c ^ 'a';
    // prints three "dots" for unprintable characters
    printf("%c %c %c\n", first, second, third);
    // prints the ascii values 0 3 2
    printf("%d %d %d\n", first, second, third);
    first = first ^ 'a';
    second = second ^ 'a';
    third = third ^ 'a';
    // prints a b c
    printf("%c %c %c\n", first, second, third);
    // prints the ascii values 97 98 99
    printf("%d %d %d\n", first, second, third);
}
```

## ビットフィールド

単純なデータ型に詰め込まれたビットを、その位置で指定する方法を見てきました。`struct`に詰め込まれたビットは、名前で指定できます。このようなデータ型を`bit field`と呼びます。`bit fields`の使いどころは、ON/OFFのフラグをまとめて持ちたいときや、メモリーの使用量をできるだけ抑えたいときです。

```c
#include <stdio.h>

int main() {

    struct lights {
        unsigned int number_of_lights;
        unsigned int red   : 1;
        unsigned int green : 1;
        unsigned int blue  : 1;
    };
    struct lights lightboard = {3, 0, 0, 0};
     
    //  prints 000
    printf("%d", lightboard.red);
    printf("%d", lightboard.green);
    printf("%d\n", lightboard.blue);
    
    lightboard.green = 1;

    //  prints 010
    printf("%d", lightboard.red);
    printf("%d", lightboard.green);
    printf("%d\n", lightboard.blue);
    
    // prints 3
    printf("%d\n", lightboard.number_of_lights);
}
```

`unsigned int variable_name : 1;`という構文は、構造体の中に置かれた`unsigned int`の中に、`1`ビットのフィールドを作ります。`unsigned int`の代わりに`signed int`を使うこともできますし、C99以降なら`bool`型を使うこともできます。ビットフィールドを含む構造体には、上の例の`number_of_lights`のように、ほかのデータ型のフィールドも入れられます。
