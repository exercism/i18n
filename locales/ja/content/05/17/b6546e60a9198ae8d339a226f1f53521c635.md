# 説明の補足

## Arturoの文字列に関する補足

テストの中には、まだ見慣れないかもしれない構文が出てきます。`{ braces }`で囲まれた複数行文字列です。

### 参考資料

* 言語リファレンスの[`:string`型][string]
* Stringsモジュールの[Basic Usage][usage]ドキュメント

### Arturoの文字列リテラル

Arturoで文字列リテラルを書く方法はいくつかあります。

1. ダブルクォートで囲んだ1行の文字列

    ```arturo
    greeting: "Hello, World!"

    print express greeting     ; => "Hello, World!"
    ```

1. スマートクォート`«`を使った行末文字列

    ```arturo
    farewell: « Goodbye, Mars!

    print express farewell     ; => "Goodbye, Mars!"
    ```

   短い文字列の配列があると、読みやすく書けます。

    ```arturo
    numberWords: [
        « one
        « two
        « three
        « four, and so on
    ]
 
    print express numberWords    ; => ["one" "two" "three" "four, and so on"]
    ```

1. 波括弧で囲んだ複数行文字列。
   「共通の」インデントは取り除かれます。
   先頭と末尾の改行は取り除かれます。

    ```arturo
    multiline: {
        First line
        Second line
            Third line keeps indentation
        Last line!


    }

    print express first multiline   ; => 'F'
    print express last multiline    ; => '!'
    lines: split.lines multiline
    print size lines                ; => 4
    print express lines\2           ; => "    Third line keeps indentation"
    ```

1. verbatim文字列は、先頭と末尾の空白も含めて、そのままの形で保持されます。

    ```arturo
    code: {:
        greet: function [name][
            print ~"Hello, |name|~"

        greet "World""
    :}

    print ">" ++ code ++ "<"
    print express first code
        ; => prints a literal newline character between single quotes
    print express (split.lines code | get 1)
        ; => "    greet: function [name]["
    ```

1. ヒアドキュメント形式の文字列は、3つ以上のハイフンを並べた行の下に、ファイルの終わりまで置かれます。
   これはPerlの`__DATA__`キーワードと同じように動きます。
   この形式は、モジュールのファイル末尾の変数にドキュメントやライセンス文を保存しておくのに便利です。

    これを"mymodule.art"という名前のファイルに書いたとします。

    ```arturo
    myLicense:
    ---------
    This text has been placed in the public domain.
    Do with it what you will.
    ```

    すると、次のようになります。

    ```arturo
    import {mymodule}!
    print ~">|myLicense|<"  ; => >This text has been placed in the public domain.
                            ; => Do with it what you will.<
    ```
