# はじめに

クラスは、Swiftプログラムの基本的な構成要素です。
関連するプロパティ（データ）とメソッド（関数）を、ひとまとまりの機能としてグループ化できます。

### クラスの定義

クラスを定義するには、`class`キーワードの後にクラス名を書き、クラスの定義を波括弧で囲みます。

```swift
class GameCharacter {
    var characterClass: String?
    var name: String?
    var active = false
    let id = makeRandomID()
}
```

クラスの本体にはストアドプロパティを置くことができます。ストアドプロパティは、通常の定数（`let`）や変数（`var`）と同じように定義され、同じようにふるまいます。

### インスタンス

クラスの定義は設計図のようなものです。新しい型を定義し、その値がどんな形をしているかを表しますが、定義そのものがインスタンスを作るわけではありません。

クラスの*インスタンス*を作るには、クラス名の後に括弧（`()`）を書いてイニシャライザを呼び出します。

```swift
let someCharacter = GameCharacter()
```

これで、クラス定義で指定したデフォルト値でプロパティが初期化された、新しいインスタンスが作られます。
明示的なデフォルト値を持たないオプショナルプロパティ（`name`など）には、Swiftが`nil`をデフォルト値として設定します。

### プロパティへのアクセス

インスタンスのプロパティには、*ドット記法*を使ってアクセスします。インスタンス名、ドット（`.`）、プロパティ名の順に書きます。
ドット記法は、入れ子になったプロパティにも使えます。

ドット記法を使うと値を読み出せます。また、プロパティが可変（`var`）であれば、新しい値を代入できます。

```swift
someCharacter.name
// => nil

someCharacter.name = "Luther"
someCharacter.name
// => "Luther"

someCharacter.id = "new id"
// Error: Cannot assign to property: 'id' is a 'let' constant
```

### メソッド

プロパティに加えて、クラスは*メソッド*、つまりクラスに関連付けられた関数を定義できます。

メソッドは、標準の`func`構文を使ってクラス本体の中に定義します。
メソッドがプロパティを変更する場合、そのプロパティは`var`で宣言する必要があります。

```swift
class GameCharacter {
    var characterClass: String?
    var name: String?
    var active = false
    let id: String = makeRandomID()

    func takesDamage(_ damage: Double) {
        if damage > 100 {
            active = false
        }
    }

    func sayName() -> String {
        return "My name is \(name ?? "no one"), my class is \(characterClass ?? "undetermined")"
    }
}
```

メソッドは、プロパティと同じようにドット記法でインスタンスに対して呼び出します。

```swift
var myChar = GameCharacter()
myChar.active = true
myChar.takesDamage(200)
myChar.active
// => false
```

### self

クラスのすべてのインスタンスには、`self`という暗黙のプロパティがあり、インスタンス自身を指します。
プロパティやメソッドを参照するときにはしばしば省略されますが、プロパティ名とメソッドの仮引数名が同じときは、`self`を使って両者を区別するのが一般的です。
