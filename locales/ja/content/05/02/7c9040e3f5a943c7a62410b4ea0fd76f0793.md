# 説明

この演習では、半構造化されたログメッセージを生成します。

## 1. 半構造化されたメッセージを出力する

まずは、いくつかのスタブ化された関数と、次の列挙型から始めます。

```rust
#[derive(Clone, PartialEq, Debug)]
pub enum LogLevel {
    Info,
    Warning,
    Error,
}
```

目標は、`"[<LEVEL>]: <MESSAGE>"`という形式でログメッセージを出力することです。ログレベルに対応する関数を実装する必要があります。

たとえば、次のスニペットは`log`関数の期待される出力を示しています。

```rust
log(LogLevel::Error, "Stack overflow")
// Returns: "[ERROR]: Stack overflow"
```

`info`の場合は次のようになります。

```rust
info("Timezone changed")
// Returns: "[INFO]: Timezone changed"
```

楽しんでください！

## 2. 任意の追加練習

このテストスイートには、フィーチャーゲート付きのテストが1つあります。フィーチャーゲートを使うと、プログラムの特定の部分をまるごとコンパイルの対象から外せます。これについては後ほど説明します。今は、特別なテスト用の呼び出しを使ったときだけビルドされて実行されるテストがある、ということだけ覚えておいてください。

```sh
cargo test --features add-a-variant
```

このテストは、列挙型にバリアントを追加する方法を示すためのものです。
