# インストール

- macOSでは、`brew install futhark`を実行します
- linuxでは、`brew install futhark`を実行します
- Windowsでは、WSLを使うか、[Windows専用の手順][windows-specific-instructions]に従います

その他のインストール方法は、[公式のインストール手順][instructions]にあります。

[instructions]: https://futhark.readthedocs.io/en/stable/installation.html
[windows-specific-instructions]: https://futhark.readthedocs.io/en/stable/installation.html#windows-installation
