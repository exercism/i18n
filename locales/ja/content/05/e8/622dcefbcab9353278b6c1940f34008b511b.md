# 指示

この演習では、お気に入りの料理本の絶品ラザニア作りに役立つコードを書いていきます。

タスクは4つあり、どれもラザニアを作るのにかかる時間に関するものです。

## 1. 想定されるオーブン時間（分）を定義する

`$expected_minutes_in_oven`という名前の定数を定義します。
料理本によると、想定されるオーブン時間は40分です。

```sh
$ jq -n -f lasagna.jq
{
  "expected_minutes_in_oven": 40,
  ...
```

## 2. 残りのオーブン時間（分）を計算する

この値は、ラザニアをオーブンに入れてからの実際の経過時間（分）を入力として受け取り、前のタスクで定義した想定オーブン時間（分）をもとに、ラザニアをあと何分オーブンに入れておく必要があるかを返します。

```sh
$ echo '{"actual_minutes_in_oven": 18}' | jq -f lasagna.jq
{
  "expected_minutes_in_oven": 40,
  "remaining_minutes_in_oven": 22,
  ...
```

## 3. 準備時間（分）を計算する

準備時間とは、ラザニアをオーブンに入れる前に準備を整えるのにかかる時間です。
1層の準備には2分かかります。

```sh
$ echo '{"number_of_layers": 3}' | jq -f lasagna.jq
{
  ...
  "preparation_time": 6,
  ...
```

## 4. 合計の作業時間（分）を計算する

ラザニア作りに合計何分かけたかを計算します。
これは、準備時間（分）と、現時点でラザニアがオーブンに入っている時間（分）を足したものです。

```sh
$ echo '{"actual_minutes_in_oven": 10, "number_of_layers": 2}' | jq -f lasagna.jq
{
  ...
  "total_time": 14,
  ...
```
