# はじめに

## 型宣言

PHPの型宣言は、関数の引数、戻り値、クラスのプロパティに対して、実行時に型アサーションを行います。
関数では、戻り値の型に`void`を指定すると、その関数が値を返さないことを示せます。
宣言した型は、関数が適切な型の戻り値を返していることを実行時に確認する役割も果たします。

```php
<?php

class Driver
{
    private int $serial_number;

    public function setSerialNumber(int $number): void
    {
        $this->serial_number = $number;
    }

    public function getSerialNumber(): int
    {
        return $this->serial_number; 
    }
}

$driver = new Driver();
$driver->setSerialNumber("Version 1b"); // This will throw a TypeError
```

### 共用体型

関数の引数、戻り値、クラスのプロパティが複数の型を取りうる場合は、共用体型を宣言できます。

```php
<?php

class IdentityCard
{
    private int|null $id = null;

    public function assign(int|float $id): void
    {
        $this->id = intval($id);
    }
}

$card = new IdentityCard();
$card->assign(5.0);
```

### `mixed`型

コードを書いていると、型を特定できないことがあります。
PHP 8.0からは、`mixed`という抜け道になる型が用意されています。
`mixed`は、`object|resource|array|string|float|int|bool|null`という共用体型と同じ意味です。
