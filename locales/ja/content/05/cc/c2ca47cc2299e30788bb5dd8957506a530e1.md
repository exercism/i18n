# テスト

## 対話的にテストする

演習をダウンロードしたディレクトリでREPLを起動しましょう。

テストファイルを`(load "exercise-test")`でREPLに読み込むと、テストを実行できます（`"exercise"`は適切な名前に置き換えてください）。次に`(exercise-test:run-tests)`を評価すると、すべてのテストが実行されます。

REPLに直接コードを書く場合は、`(exercise-test:run-tests)`を評価するだけです。

演習のLispファイルにコードを書く場合は、`(load "exercise")`で読み込んでから`(exercise-test:run-tests)`を評価します。

## コマンドラインからテストする

次のコマンドラインでテストを起動できます（ここでも、2か所の`"exercise"`を適切な名前に置き換えてください）。

```sh
ros run --load exercise-test.lisp --eval '(uiop:quit (if (exercise-test:run-tests) 0 1))'
```
