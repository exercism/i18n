# 概要

通常、関数は決まった数の引数しか受け取れません。しかし、最後の仮引数の型の前に`...`を付けると、関数は後続の引数をいくつでも受け取れるようになります。こうすると、最後の仮引数は_可変長引数_になります。

```go
func sum(nums ...int) int {
    total := 0
    for _, n := range nums {
        total += n
    }
    return total
}
```

関数の中では、可変長引数はスライスになります。

```go
sum(1, 2, 3)    // nums is []int{1, 2, 3}
sum(1, 2, 3, 4) // nums is []int{1, 2, 3, 4}
sum()           // nums is []int{}
```

関数は、可変長引数の前に通常の仮引数を置くことができます。可変長引数は最大1つまでで、必ず最後の仮引数でなければなりません。

```go
func greet(greeting string, names ...string) {
    for _, name := range names {
        fmt.Printf("%s, %s!\n", greeting, name)
    }
}
```

## スライスの展開

スライスを可変長引数に渡すには、そのあとに`...`を付けます。

```go
nums := []int{1, 2, 3}
sum(nums...) // equivalent to sum(1, 2, 3)
```

`...`は、スライスを可変長引数に渡すときだけ有効です。
