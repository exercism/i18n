# 基本の紹介

[Go](https://golang.org)は、静的型付けのコンパイル型プログラミング言語です。
Goの構文はCに似ています。
この言語は、以前のドメイン名であるgolang.orgにちなんでGolangと呼ばれることもよくありますが、正式な名称はGoです。

「基本」では、パッケージ、関数、変数という3つの主要な言語機能を紹介します。

## パッケージ

Goのアプリケーションは、パッケージという単位でまとめられます。
パッケージとは、同じディレクトリにあるソースファイルをひとまとめにしたものです。
同じディレクトリにあるソースファイルは、すべて同じパッケージ名でなければなりません。
パッケージ名には、インポートパスの最後のディレクトリ名を付けるのが慣例です。
たとえば、[`math/rand`パッケージ](https://golang.org/src/math/rand/)のファイルは、`package rand`という文で始まります。
パッケージをインポートすると、名前が大文字で始まるもの（関数、型、変数、定数）だけが利用・アクセスできます。
Goで推奨される命名スタイルでは、識別子は`camelCase`で書きます。ただし、パッケージをまたいでアクセスできるようにするものは`PascalCase`にします。

```go
package lasagna
```

## 変数

Goは静的型付けです。つまり、すべての変数は、コンパイル時に[型が定義されていなければなりません](https://en.wikipedia.org/wiki/Type_system)。

変数は、型を明示的に指定して定義できます。

```go
var explicit int // Explicitly typed
```

初期化子を使うこともできます。その場合、コンパイラーが初期化子の型に合わせて変数の型を決めます。

```go
implicit := 10   // Implicitly typed as an int
```

一度宣言した変数には、`=`演算子で値を代入できます。
一度宣言した変数の型は、あとから変更することはできません。

```go
count := 1 // Assign initial value
count = 2  // Update to new value

count = false // This throws a compiler error due to assigning a non `int` type
```

## 定数

定数は変数と同じようにデータを保持しますが、プログラムの実行中に値を変えることはできません。

定数は`const`キーワードで定義し、数値、文字、文字列、真偽値のいずれかにできます：

```go
const Age = 21 // Defines a numeric constant 'Age' with the value of 21
```

## 関数

Goの関数は、0個以上の入力を受け取ります。
入力には必ず型を明示する必要があり、型推論はありません。

関数から値を返すには、`return`キーワードを使います。

関数を呼び出すには、関数名を指定し、関数の入力それぞれに引数を渡します。

なお、Goでは2種類のコメントが使えます。
1行コメントは`//`で始め、複数行コメントは`/*`と`*/`の間に書きます。

```go
package greeting

// Hello is a public function.
func Hello (name string) string {
    return hi(name)
}

// hi is a private function.
func hi (name string) string {
    return "hi " + name
}
```
