# 指示

ベルリンにある新しい空港が、ロボット研究室のためにエンジニアを採用しました。そこで働き始めることになります。
空港には、ぎこちなくて、どこか人型に見えるロボットたちがいて、カスタマーサービスの改善に使おうとしています。

最初の仕事は、セルフチェックインカウンターでパスポートをスキャンした人に、その人の母語でロボットがあいさつできるようにするプログラムを書くことです。

ロボットは自分の能力に誇りを持っているので、いつも最初に自分が話せる言語を告げてから、その人にあいさつします。
たとえば、ドイツのパスポートをスキャンした場合、ロボットはこう言います。

```txt
I can speak German: Hallo Dietrich!
```

## 1. あいさつ機能を抽象化する

言語ごとのコードを自分で書くわけではないので、あとから他のエンジニアが簡単に言語を追加できるように、ロボットのコードを構成する必要があります。

まずは、2つのメソッドを持つインターフェース`Greeter`を定義します。

- `LanguageName`は、ロボットがその訪問者にあいさつする言語の名前（`string`）を返します。
- `Greet`は、訪問者の名前（`string`）を受け取り、特定の言語でのあいさつメッセージを`string`で返します。

次に、訪問者の名前と、`Greeter`インターフェースを実装しているものを受け取り、目的のあいさつの文字列を返す関数`SayHello`を実装します。
たとえば、`LanguageName`が`"German"`を返し、`Greet`が`"Hallo {name}!"`を返すドイツ語の`Greeter`実装を考えてみましょう。

```go
SayHello("Dietrich", germanGreeter)
// => "I can speak German: Hallo Dietrich!"
```

## 2. イタリア語を実装する

次は、イタリアのパスポートをスキャンした人にロボットが対応できるようにします。

そのために、構造体`Italian`を作成し、タスク1で用意した`Greeter`インターフェースを満たすために必要な2つのメソッドを実装します。
イタリア語では、`"Ciao {name}!"`であいさつできます。

## 3. ポルトガル語を実装する

今日の仕事を終える前に、ポルトガル語であいさつする機能も仕上げておきましょう。

そのために、構造体`Portuguese`を作成し、ここでも`Greeter`インターフェースを満たすために必要な2つのメソッドを実装します。
ポルトガル語では、`"Olá {name}!"`であいさつできます。
