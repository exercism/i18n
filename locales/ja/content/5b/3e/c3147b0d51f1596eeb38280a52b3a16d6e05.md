# ヒント

## 全般

- 公式ガイドで[パターンマッチング][pattern-matching]について読んでみましょう。
- [分割代入][destructuring]についてのこのチートシートを見てみましょう。
- レコードのパターンマッチングについては、[こちら][records-pattern-matching]でさらに詳しく説明されています。

## 1. 空のコメントを検出する

- 引数がペアであれば、関数の引数で直接`(a, b)`を使うことができます。
- 受け取ったけれど使わない値は、ワイルドカード`_`で置き換えることができます。
- 文字列が空かどうかを調べるには、[`String`のドキュメント][string-docs]を確認してください。

## 2. 作成者からのコメントの数を数える

- `type Box = Box AB`のようにバリアントを1つだけ持つカスタム型は、`(Box ab)`のように関数の引数で直接分解できます。
- レコード`{a : A, b : B}`のフィールド`a`は、`{ a }`を使ってパターンマッチングできます。
- レコードを保持するカスタム型では、上記の2つのテクニックを同時に使うことができます。
- レコード`{ ab : (A, B) }`からペア`ab`を直接パターンマッチングすることはできません。まず`{ ab }`をパターンマッチングしてから、`let`束縛の中で`( a, b) = ab`を使う必要があります。
- リストの中で条件を満たす要素の数を調べるには、[`List`の関数][list-docs]を使います。
- 無名関数の引数では、ペアを直接分解できます。

## 3. 開発チームに割り当てられたチケットを検出する

- タスク2と同様に、「ボックス化された」レコードの該当するフィールドは関数の引数でマッチングできます。
- `Just (Box "42")`のような入れ子の値は、パターンマッチングを再帰的に使ってマッチングできます。
- `case`式では、ワイルドカード`_`を使って何にでもマッチングできます。

## 4. IT社員にチケットを割り当てる

- タスク2と3と同様に、「ボックス化された」レコードの該当するフィールドは関数の引数でマッチングできます。
- さらに、`as`キーワードを使うと、フィールドをパターンマッチングしつつ、レコード全体も束縛できます：`(Box ({ a } as ab))`。
- カスタム型の値は、`case`式でパターンマッチングできます。
- チケットを返すには、型コンストラクター`Ticket`を使います。
- レコードを変更するには、[レコード更新構文][record-update]を使います。
