# 最初の演習を追加する

`hello-world`演習を実装したら、次は他の演習を20以上実装します。

## 演習の種類

実装できる演習には、2つの種類があります。

- 概念演習：学習者に1つ以上の概念を教えるために設計されています。詳しくは[ドキュメント](/docs/building/tracks/concept-exercises)を確認してください。
- 実践演習：学んだ概念を練習するために設計されています。詳しくは[ドキュメント](/docs/building/tracks/practice-exercises)を確認してください。

一般に、新しいトラックでは、まず実践演習を実装することをおすすめします。実装が簡単で、事前に考えることも少ないからです。概念演習は、トラックがきちんと動くようになってから、いつでも追加できます。

## 演習を選ぶ

トラックが実践演習を実装しやすくするために、[exercism/problem-specificationsリポジトリ](https://github.com/exercism/problem-specifications)を用意しました。このリポジトリには、[100以上ある実践演習のメタデータ](https://github.com/exercism/problem-specifications/tree/main/exercises)が含まれており、各トラックはこれを使って、そのトラック向けのバージョンの演習を実装できます。そのため、同じ演習が多くのトラックで実装されているのを目にすることになります。

では、この100以上の演習の中から、どのようにして20以上を選べばよいのでしょうか？　いくつかの指針を紹介します。

### 学習者がさまざまな概念を練習できる演習を選ぶ

100以上の演習で使われる概念は、じつにさまざまです。学習者が多様な概念を練習できる演習を実装することを目指しましょう。文字列だけに焦点を当てた演習を20個実装するのではなく、それぞれ異なる概念に焦点を当てた演習を実装してみてください。

いくつかの概念と、その例となる演習を挙げます。

| ---------------------- | ------------------------------------------------------------------------------------ |
| ビット操作 | [allergies][allergies], [secret-handshake][secret-handshake] |
| 真偽値 | [leap][leap] |
| クラス | [circular-buffer][circular-buffer], [robot-name][robot-name] |
| 並行処理 | [bank-account][bank-account] |
| 条件分岐 | [raindrops][raindrops] |
| 日付と時刻 | [gigasecond][gigasecond], [meetup][meetup] |
| 等価性 | [clock][clock] |
| 浮動小数点数 | [darts][darts], [space-age][space-age] |
| 遅延評価 | [alphametics][alphametics], [zebra-puzzle][zebra-puzzle] |
| 配列 | [resistor-color][resistor-color], [spiral-matrix][spiral-matrix] |

### 難易度に幅のある演習を選ぶ

演習によって、実装の難しさは異なります。初級・中級・上級が混ざるように、難易度に幅を持たせて演習を実装することを目指しましょう。

演習の難しさは、関わる概念やトラックの言語など、いくつかの要素によって決まります。同じ演習を実装している他のトラックで、その演習がどんなものかを見ておくと、実装がどんな形になりそうかをつかみやすくなるでしょう。

難易度ごとに、演習の例を挙げます。

| 難易度 | 演習 |
| ------------ | -------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| 初級 | [darts][darts], [gigasecond][gigasecond], [isogram][isogram], [leap][leap], [resistor-color][resistor-color], [space-age][space-age] |
| 中級 | [allergies][allergies], [bob][bob], [meetup][meetup], [protein-translation][protein-translation], [raindrops][raindrops], [secret-handshake][secret-handshake] |
| 上級 | [alphametics][alphametics], [forth][forth], [react], [pov][pov], [zebra-puzzle][zebra-puzzle], [zipper][zipper] |

### 自分のトラックに合った演習を選ぶ

すべての演習が自分のトラックに合うとは限りません。トラックに合う演習だけを選びましょう。意味をなさない演習を実装するより、その演習を_実装しない_ほうがよいのです。たとえば、[lens-person演習](https://github.com/exercism/problem-specifications/tree/main/exercises/lens-person)では、学習者が_レンズ_を扱いますが、これをサポートしていない言語もたくさんあります。

トラックに合わない演習を見つけたら、そのスラッグを[トラックのconfig.jsonファイル](/docs/building/tracks/config-json)にある`exercises.foregone`配列に追加できます。こうすると、ツールがその演習を無視するようになります。
