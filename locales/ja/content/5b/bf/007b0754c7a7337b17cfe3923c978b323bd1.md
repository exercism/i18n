# 説明

クレジットカード番号が[Luhnの公式][luhn]に従って有効かどうかを判定します。

番号は文字列として渡されます。

## 数値の検証

長さが1以下の文字列は有効ではありません。入力にはスペースを含めることができますが、検証の前に取り除く必要があります。それ以外の数字以外の文字は許可されません。

### 例1：有効なクレジットカード番号

```text
4539 3195 0343 6467
```

Luhnアルゴリズムの最初のステップは、右から数えて1つおきの数字を2倍にすることです。ここでは、次の桁を2倍にします。

```text
4539 3195 0343 6467
↑ ↑  ↑ ↑  ↑ ↑  ↑ ↑  (double these)
```

2倍した結果が9より大きくなった場合は、その積から9を引きます。2倍にした結果は次のとおりです。

```text
8569 6195 0383 3437
```

次に、すべての桁を合計します。

```text
8+5+6+9+6+1+9+5+0+3+8+3+3+4+3+7 = 80
```

合計が10で割り切れる場合、その数値は有効です。この数値は有効です！

### 例2：無効なクレジットカード番号

```text
8273 1232 7352 0569
```

右から数えて1つおきの数字を2倍にします。

```text
7253 2262 5312 0539
```

桁を合計します。

```text
7+2+5+3+2+2+6+2+5+3+1+2+0+5+3+9 = 57
```

57は10で割り切れないため、この数値は有効ではありません。

[luhn]: https://en.wikipedia.org/wiki/Luhn_algorithm
