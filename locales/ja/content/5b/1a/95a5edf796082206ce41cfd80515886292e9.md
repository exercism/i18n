# はじめに

Factorは*連結型*言語です。すべてのワードは、共有の**データスタック**から入力を受け取り、その結果を再びスタックに積みます。値を受け渡す方法は、これ以外にありません。

リテラルを書くと、それがスタックの一番上に積まれます。コードは左から右へと読みます。

```factor
1 2 3    ! stack (bottom → top): 1 2 3
```

*スタック効果*の宣言は、ワードの取り決めを記録したものです。

```factor
: restow ( a b -- b a ) swap ;
```

`( a b -- b a )`は、このワードが2つの値を取り出し、順番を入れ替えて2つ残すという意味です。名前は説明のためのもので、コンパイラーが確認するのは入力と出力の*数*だけです。スタックの一番上は、右端に書かれた名前です。

日常的に使う`kernel`の**シャッフルワード**は、スタックの一番上を並べ替えます。

```
dup  ( x   -- x x   )
drop ( x   --       )
swap ( x y -- y x   )
over ( x y -- x y x )
nip  ( x y -- y     )
rot  ( x y z -- y z x )
```

ワードは`:`で定義し、`;`で終わります。宣言した効果と本体が一致しない定義は、コンパイラーが受け付けません。
