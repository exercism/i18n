# はじめに

Factorは、[`calendar`][calendar]ボキャブラリで日付と時刻を扱います。ある時点は`timestamp`、ある期間は`duration`です。

## 日付を作る

`<date>`（[`calendar`][calendar]にあります）は、指定した日の真夜中の`timestamp`を作ります。

```
<date> ( year month day -- timestamp )
```

```factor
USING: calendar ;

1904 11 16 <date> .
! a timestamp at midnight on 1904-11-16
```

`>date<`は、`timestamp`をその構成要素に分解します。

```
>date< ( timestamp -- year month day )
```

```factor
1904 11 16 <date> >date< .   ! => 16   (with 1904 and 11 below it)
```

## 日付を調べる

`day-of-week`は曜日を整数で返します。`0`が日曜日で、`6`が土曜日です。`day-names`（[`calendar.english`][english]にあります）は、対応する名前のリストなので、`day-names nth`で数値を曜日名に変換できます。

```factor
USING: calendar calendar.english sequences ;

2024 1 8 <date> day-of-week .          ! => 1
day-names .   ! { "Sunday" "Monday" ... "Saturday" } — Sunday first
```

`leap-year?`は年（または`timestamp`）を受け取り、`days-in-month`は`timestamp`の月の日数を返します。うるう年もすでに考慮されています。

```
leap-year?    ( obj -- ? )
days-in-month ( timestamp -- n )
```

```factor
2024 leap-year? .                ! => t
2024 2 1 <date> days-in-month .  ! => 29
```

## 日付の計算

`days`、`weeks`、`hours`のようなワードは`duration`を作り、`time+`は`timestamp`をその`duration`だけずらします。

```
days  ( x -- duration )
time+ ( timestamp duration -- timestamp )
```

```factor
2024 2 28 <date> 1 days time+ >date< .
! => 29   (2024-02-29, with 2024 and 2 below it)
```

計算は月や年の境界を正しくまたぎ、同じ瞬間を指す2つの`timestamp`は`=`で等しいと判定されます。

## 時刻

`<timestamp>`は、秒単位までの完全な`timestamp`を作ります。最後の引数はUTCからのオフセットです。`instant`（ゼロの`duration`）を使うと、`timestamp`はUTCのままになります。

```
<timestamp> ( year month day hour minute second gmt-offset -- timestamp )
```

```factor
USING: calendar ;

1969 7 21 2 56 15 instant <timestamp> .
! a timestamp at 02:56:15 on 1969-07-21
```

`>time<`は`>date<`の逆で、`timestamp`を時、分、秒に分解します。

```
>time< ( timestamp -- hour minute second )
```

```factor
1969 7 21 2 56 15 instant <timestamp> >time< .   ! => 15   (with 2 and 56 below it)
```

`seconds`と`minutes`は、`days`、`weeks`、`hours`と同様に`duration`を作るので、どれでも`time+`に渡すことができます。

```
seconds ( x -- duration )
minutes ( x -- duration )
```

`timestamp`の個々のフィールドは、アクセサ`year>>`、`month>>`、`day>>`、`hour>>`、`minute>>`、`second>>`で読み取ります。

```factor
1969 7 21 2 56 15 instant <timestamp> hour>> .   ! => 2
```
