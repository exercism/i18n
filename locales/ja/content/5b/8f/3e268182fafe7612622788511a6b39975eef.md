# 説明

この演習では、ウィンドウシステムを基にしたコンピューターシステムをシミュレーションします。
移動したりサイズを変更したりできるウィンドウを作成します。
以下の図は、このあと扱う値のイメージを表しています。

```text
 ╔════════════════════════════════════════════════════════════╗
 ║                                                            ║
 ║        position::$y,_                                      ║
 ║        position::$x  \                                     ║
 ║                       \<---- size::$width ---->            ║
 ║                 ^      *──────────────────────┐            ║
 ║                 |      │        title         │            ║
 ║                 |      ├──────────────────────┤            ║
 ║                 |      │                      │            ║
 ║          size::$height │                      │            ║
 ║                 |      │       contents       │            ║
 ║                 |      │                      │            ║
 ║                 |      │                      │            ║
 ║                 v      └──────────────────────┘            ║
 ║                                                            ║
 ║                                                            ║
 ╚════════════════════════════════════════════════════════════╝
```

## 1. プログラムウィンドウのプロパティを定義する

用意されているクラスのひな型を使って、`y`、`x`、`height`、`width`の値に対応するプロパティを用意しましょう。

```php
<?php

$window = new ProgramWindow();
$window->y; // => null
$window->x; // => null
$window->height; // => null
$window->width; // => null
```

## 2. プログラムウィンドウの初期値を定義する

`ProgramWindow`のコンストラクター関数を定義しましょう。
引数は受け取りませんが、コンストラクターの実行時にプロパティのデフォルト値を設定します。
`y`と`x`の初期値は`0`に設定します。
`height`と`width`の初期値は、`600x800`の画面サイズに設定します。

```php
<?php

$window = new ProgramWindow();
$window->y; // => 0 
$window->x; // => 0
$window->height; // => 600
$window->width; // => 800
```

## 3. ウィンドウのサイズを変更する関数を定義する

`Size.php`に、Sizeクラスとなる新しいクラスを定義しましょう。
コンストラクターでは、`height`と`width`プロパティを設定する引数を受け取ります。
さらに`ProgramWindow`には、`Size`オブジェクトのインスタンスを受け取って自身のプロパティを更新する`resize`関数が必要です。

```php
<?php 

$window = new ProgramWindow();
$size = new Size(764, 1080);
$window->resize($size)

$window->height;
// => 764
$window->width;
// => 1080
```

## 4. ウィンドウを移動させる関数を定義する

`Position.php`に、Positionクラスとなる新しいクラスを定義しましょう。
コンストラクターでは、`y`と`x`プロパティを設定する引数を受け取ります。
さらに`ProgramWindow`には、`Position`オブジェクトのインスタンスを受け取って自身のプロパティを更新する`move`関数が必要です。

```php
<?php 

$window = new ProgramWindow();
$position = new Position(80, 313);
$window->move($position)

$window->y;
// => 80
$window->x;
// => 313
```
