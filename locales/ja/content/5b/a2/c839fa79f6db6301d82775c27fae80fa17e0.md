# 説明の補足

## ヒント

この演習では、`Planet`という名前の[代数的データ型](https://learnyouahaskell.github.io/making-our-own-types-and-typeclasses)の定義を用意しています。
`ageOn`関数を実装する必要があります。この関数は、秒で与えられた年齢から、ある人が`Planet`上で何歳になるかを計算します。

型について自信がない場合は、用意されたシグネチャを使ってもかまいません。ただし、それで創造性を制限しないでください。

```haskell
ageOn :: Planet -> Float -> Float
```
