# はじめに

PowerShellは、Microsoftが開発した動的で暗黙的に型付けされたスクリプト言語です（[厳密に型指定された][strong typed]変数にも対応しています）。主にタスクの自動化と構成管理に焦点を当てています。

PowerShellは、命令型、関数型、オブジェクト指向、さらにはパイプライン形式のプログラミングをサポートしています。

PowerShellは.NETプラットフォーム上に構築され、2006年に最初にリリースされました。現在のすべてのWindows OSにはデフォルトで含まれており、MacやLinuxにもインストールできます。


## 変数

PowerShellで変数を定義するには、一般的に2つの方法があります。

PowerShellの変数名は`$`で始める必要があり、代入演算子`=`を使って変数名に値を結び付けます。

```powershell
> $intVar = 1
> $doubleVar = 2.0
> $stringVar = "Hello"

# Checking a variable type using the GetType() method
> Write-Host $doubleVar.GetType()
System.Double
```

値が特定の型であることを強制したい場合は、変数の型を明示的に指定することもできます。
PowerShellは、可能であれば値をある型から別の型へ変換しようと最善を尽くします。

```powershell
# String represents a floating number can be converted to integer
> [int]$staticOne = "1.234"
> $staticOne
1

# String of letters can not be converted to double type
> [double]$staticTwo = "hello"
MetadataError: Cannot convert value "hello" to type "System.Double"
```


### 定数

PowerShellの定数は、定義後に**変更**も**削除**もできない変数です。
ここで、変数を定義する2つ目の方法、コマンドレット`New-Variable`を使う方法を紹介します。

```powershell
> New-Variable -Name "MyConstant" -Value 100 -Option Constant
> $MyConstant
```

新しい変数を作成するためのより詳細で発展的な方法については、[New-Variable][New-Variable]をお読みください。


## 関数

PowerShellの[関数][functions]は、`function`キーワードを使って定義します。
各関数は、括弧（`()`）の中に0個以上の仮引数を取ることができ、その後に、`{`で始まり`}`で終わる関数のスコープが続きます。

```powershell
function Greeting {
    return "Hello!"
}
```

PowerShellの関数は、`FuncName $Arg`という構文で呼び出したあと、`return`キーワードを使って明示的に値を返すことができます。

```powershell
function AddTwoNumbers($NumOne, $NumTwo):
    $result = $NumOne + $NumTwo
    return $result

> AddTwoNumbers 10 20
30
```

詳細な関数定義の書き方や、関数が暗黙的にどのように値を返すかといった発展的な内容は、`Functions`のコンセプトモジュールで扱います。


## コメント

PowerShellの単一行コメントは`#`で始まり、行末で終わります。
コメントブロックは`<#`で始まり、`#>`で終わります。
コメントブロックを使ってコメントベースのヘルプを作成する発展的な例は、`Functions`のコンセプトモジュールで扱います。

```powershell
function Main() {
    #This is a comment
    <#
    And this is a comment block
    that can span multiple lines
    #>
}
```
