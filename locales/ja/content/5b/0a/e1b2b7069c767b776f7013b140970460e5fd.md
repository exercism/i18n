# 概要

Haxeでは、`class`は主要なデータ構造で、データ（フィールド）と振る舞い（メソッド）をひとまとめにしたものです。フィールドとメソッドは、クラスのメンバーとも呼ばれます。

メンバーへのアクセスは、[アクセス修飾子][visibility]を使って制限できます。アクセス修飾子には次のものがあります。

- `public`：どの場所からでもメンバーにアクセスできます。
- `private`：同じクラスからのみメンバーにアクセスできます。

クラスは、インスタンスを作るためのテンプレートと考えることができます。[インスタンス][class-instance]を作るには、`new`キーワードを使うだけです。

```haxe
class Car {
  public function new() {}
}

var myCar = new Car();
var yourCar = new Car();
```

フィールドを定義するには、アクセス修飾子のあとに変数名と型を書きます。

```haxe
class Car {
  public var weight:Int; // Accessable by anyone

  private var color:String; // Accessable only within this class
}
```

フィールドを定義するときに、初期値を設定することもできます。初期値を指定しないフィールドには、`null`が入ります。フィールドには、ドット記法でアクセスできます。

```haxe
class Car {
  public var weight:Int = 2500; // Weight will be set to 2500
  public var year:Int; // year will be null

  public function new() {}
}

var newCar = new Car();
newCar.weight; // 2500
newCar.year; // null

// Update value of field
newCar.year = 2020;
```
