# 説明

この演習では、お気に入りの料理本のとおりに最高のラザニアを作れるよう、コードを書いていきます。

タスクは4つあり、どれもラザニアの調理にかかる時間に関するものです。

~~~~exercism/note
型を指定せずに型推論を使う方法と、型を明示する方法のどちらでもかまいません。
後者を選ぶ場合は、型として`int`を使います。
~~~~

## 1. オーブンでの想定加熱時間を分単位で定義しましょう

`expectedMinutesInOven`というバインディングを定義して、ラザニアをオーブンに入れておくべき時間を確認できるようにしましょう。料理本によると、想定加熱時間は40分です。

```fsharp
expectedMinutesInOven
// => 40
```

## 2. 残りのオーブン加熱時間を分単位で計算しましょう

`remainingMinutesInOven`関数を定義しましょう。この関数は、ラザニアを実際にオーブンに入れておいた時間を入力として受け取り、前のタスクで定義した想定加熱時間をもとに、ラザニアをあと何分オーブンに入れておく必要があるかを戻り値として返します。

```fsharp
remainingMinutesInOven 30
// => 10
```

## 3. 準備にかかる時間を分単位で計算しましょう

`preparationTimeInMinutes`関数を定義しましょう。この関数は、ラザニアに重ねた層の数を入力として受け取り、1層につき2分かかるものとして、ラザニアの準備に何分かかったかを戻り値として返します。

```fsharp
preparationTimeInMinutes 2
// => 4
```

## 4. 経過時間を分単位で計算しましょう

`elapsedTimeInMinutes`関数を定義しましょう。この関数は2つの入力を受け取ります。1つ目の入力はラザニアに重ねた層の数、2つ目の入力はラザニアをオーブンに入れておいた時間（分）です。この関数は、ラザニアの調理にかけた時間、つまり準備にかかった時間とその時点までオーブンに入れておいた時間を足したものを戻り値として返します。

```fsharp
elapsedTimeInMinutes 3 20
// => 26
```
