# はじめに

## 定数と関数

定数は`name = expression`という形で定義します。Elmでは、定義以外はすべて式です。

```elm
five = 5

six = 3 + 3
```

関数は`name parameters... = expression`という形で定義します。仮引数は空白だけで区切ります。

```elm
add number1 number2 = number1 + number2
```

関数の呼び出しも式です。関数名を指定し、その関数の各仮引数に渡す値を空白で区切って渡します。関数を定義するときとまったく同じです。

```elm
five = add 2 3
```

括弧（`()`）を使うと、式を評価する順序を指定できます。

```elm
six = add 2 (1 * 4)

twelve = add 2 1 * 4
```

## インデントと意味のある空白

Elmは、コードの範囲を示すために波括弧や括弧、セミコロンといった構文上の記号を使いません。その代わりに空白とインデントを使います。

- モジュール、インポート、トップレベルの関数定義は、最も左の列から始めなければなりません。
- 式を複数行に分ける場合、その式の一部であるコードは、その式の下に少なくとも1つの空白でインデントする必要があります。
- まとまりとして扱う式の部分は、同じ数の空白でインデントします。

```elm
-- A function split over multiple lines, so subsequent lines must be indented
add number1 number2 =
    number1 + number2
```

https://elmprogramming.com/indentation.html

## モジュール

Elmの各ファイルはモジュールであり、ほかのどのコードよりも前に`module`文を書く必要があります。
モジュール名はファイル名と一致する必要があるので、モジュール`Calculator`はファイルCalculator.elmに入れます。
モジュール内で定義したものはそのモジュールにプライベートにスコープされ、`exposing`に挙げられていない限り、このモジュールの外からアクセスできません。

```elm
-- Define the Calculator module, and expose the `add` function
module Calculator exposing (add)

six = 3 + 3

add number1 number2 = number1 + number2
```

```elm
-- Define the Calculator module, and expose everything within: `six` and `add`
module Calculator exposing (..)

six = 3 + 3

add number1 number2 = number1 + number2
```

https://elm-lang.org/docs/syntax#modules

## コメント

コメントとは、Elmファイルの中にあってコードとして解釈されないテキストのことです。
主に自分自身やほかのプログラマーが読むためのものです。
1行コメントには、二重のハイフンに基づく軽量な構文があります。
複数行コメントも、開く区切りと閉じる区切りのペア`{-`と`-}`を使えば可能です。

```elm
-- a single line comment
-- another single line comment

{- a multiline comment
   spawning multiple lines
-}
```
