# 説明

Maryはテレビシリーズ_Star Trek: The Next Generation_の大ファンです。
よく友人たちとペンと紙のロールプレイングゲームをして、_Starship Enterprise_のクルーになりきって遊んでいます。

Maryが演じるのはCaptain Picardで、そのため艦長のログを付けなければなりません。
彼女はゲームの創造的な部分は大好きですが、その場でランダムなデータを生成するのは好きではありません。

艦長のログによく登場するデータのランダム生成器を作って、Maryを手伝いましょう。

## 1. ランダムな惑星を生成する

_Starship Enterprise_は、旅の途中でたくさんの惑星と出会います。
Star Trekの宇宙では、惑星はその性質によってカテゴリーに分けられています。
たとえば、地球はMクラスの惑星です。惑星のクラスには、D、H、J、K、L、M、N、R、T、Yがあります。

`random_planet_class`関数を実装しましょう。
この関数は、必要な数の惑星クラスをランダムに選び、ベクトルとして返します。
クラスが重複していてもかまいません。長いベクトルでは、重複が必要になることもあります。

```R
random_planet_class(number_needed)
#> "K"
```

### 2. ランダムな宇宙船の登録番号を生成する

宇宙を飛び回っているのはEnterprise（登録番号NCC-1701）だけではありません！　別の宇宙船とランデブーしたときは、Maryはその宇宙船の登録番号を記録する必要があります。

登録番号は接頭辞「NCC-」で始まり、そのあとに1000から9999までの数値が続きます（両端を含む）。

ランダムな宇宙船の登録番号を返す`random_ship_registry_number`関数を実装しましょう。

```R
random_ship_registry_number()
#> "NCC-1947"
```

## 3. 宇宙船の艦隊をランダムに並べ替える

ゲームのあるバージョンではほかの宇宙船とやり取りする場面があるので、Maryはその中から選ぶ必要があります。

登場する可能性のある宇宙船の完全なリストがありますが、各ゲームで必要なのはそのうちのわずかで、しかもランダムに選ぶ必要があります。

`shuffle_starships(starships)`関数を実装しましょう。この関数は、重複のない宇宙船の登録番号のベクトルを受け取り、宇宙船がランダムな順に並んだ、同じ長さのベクトルを返します。
そうすれば、Maryはベクトルの先頭から、好きな数だけ簡単にランダムに取り出せます。

結果の値は`starships`から取り出し、重複がないようにします。

```R
shuffle_starships(c("NCC-5011", "NCC-1228", "NCC-7039", "NCC-3978", "NCC-1476"))
#> [1] "NCC-1476" "NCC-7039" "NCC-3978" "NCC-5011" "NCC-1228"
```

## 4. ランダムな宇宙暦を生成する

日付のないログに、何の意味があるのでしょうか？

宇宙暦は浮動小数点数です。
_The Next Generation_の第1シーズンにおける_Starship Enterprise_の冒険は、宇宙暦41000.0から42000.0の間で繰り広げられます。
「4」は24世紀を、「1」は第1シーズンを表しています。

41000.0から42000.0までの浮動小数点数を返す`random_stardate`関数を実装しましょう。

```R
random_stardate()
#> 41037.6
```
