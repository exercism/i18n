# 説明

_Instruments of Texas_での仕事を続けるなか、RPN電卓のElixir実装が進んでいます。チームは、標準ライブラリが提供する一般的なエラーよりも具体的なエラーを発生させられるようにしたいと考えています。まだ調査中の部分もありますが、_Exception Behaviour_を実装する新しいエラーを2つ作ることにしました。

## 1. ゼロ除算のエラー

数値をゼロで割ると結果は未定義になり、チームはこれをエラーで表すのが最適だと判断しました。

`DivisionByZeroError`モジュールを実装し、エラーメッセージを`"division by zero occurred"`にします。

```elixir
raise DivisionByZeroError
# => ** (DivisionByZeroError) division by zero occurred
```

## 2. スタックアンダーフローが起きたときのエラー

RPN電卓は、計算する前の数値を保持しておくために_スタック_を使います。チームはこの_スタック_を数値（整数と浮動小数点数）の配列で表します。例えば`[3, 4.0]`です。各演算では、計算を行うために、スタック上に決まった個数の数値が必要です。スタック上の数値が足りないとき、これをスタックアンダーフローエラーと呼びます。デフォルトのメッセージと、省略可能な追加のコンテキストを提供する`StackUnderflowError`例外を実装します。

```elixir
raise StackUnderflowError
# => ** (StackUnderflowError) stack underflow occurred

raise StackUnderflowError, "when dividing"
# => ** (StackUnderflowError) stack underflow occurred, context: when dividing
```

## 3. 割り算を行う関数を書く

スタック_（2つの数値の配列）_を引数に取る`divide/1`関数を実装します。この関数は次の処理を行います。

- スタックに十分な数値がないときは、_スタックアンダーフロー_を発生させます
- 除数が0のときは、_ゼロ除算_を発生させます（数値のスタックは逆順に格納されていることに注意してください）
- エラーが発生しなければ、割り算を実行します

```elixir
RPNCalculator.Exception.divide([])
# => ** (StackUnderflowError) stack underflow occurred, context: when dividing

RPNCalculator.Exception.divide([0, 100])
# => ** (DivisionByZeroError) division by zero occurred

RPNCalculator.Exception.divide([4, 16])
# => 4
```

> 配列の順序が逆になっている点に注意してください！
