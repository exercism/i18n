# はじめに

Gleamの辞書は、情報をキーと値のペアで保存するためのデータ構造です。他の言語では、連想配列やハッシュ、辞書などと呼ばれることもあります。

辞書では、キーにも値にもどんな型でも使えます。ただし、アクセスしたり返したりするときの項目の順序は保証されません。

## 辞書を扱う

辞書は、`gleam/dict`モジュールの関数を使って作成したり操作したりします。

```gleam
// Create an empty dict
let dict1 = dict.new()

// Create a dict with some values
let dict2 = dict.from_list([
  #("name", "Gleam"),
  #("colour", "Pink"),
])

// Add a value to a dict
let dict3 = dict.insert(dict2, "website", "https://gleam.run")

// Get a value from a dict
let name = dict.get(dict3, "name")
// -> Ok("Gleam")
```
