# 指示の補足

## プロジェクトの構成

ExercismのClojureの演習では、コードの設定と実行に[leiningen](http://leiningen.org/)を使います。ディレクトリ構成も[leiningenの標準的なディレクトリ構成](https://github.com/technomancy/leiningen/blob/master/doc/TUTORIAL.md#directory-layout)に従います。

`test`ディレクトリの中に、`hello_world_test.clj`というテストファイルがあります。コードは`src/hello_world.clj`に書きましょう。テストが読み込めるように、名前空間`hello-world`を使います。

## テストの実行

`lein test`コマンドでテストを実行して、すべて通るようにしましょう。

```
$ lein test

lein test hello-world-test

Ran 3 tests containing 3 assertions.
0 failures, 0 errors.
```

次に、次のコマンドで演習を提出します。

```
$ exercism submit src/hello_world.clj
```

より詳しい指示や学習リソースについては、[ExercismのClojure言語ページ](http://exercism.io/languages/clojure)を参照してください。
