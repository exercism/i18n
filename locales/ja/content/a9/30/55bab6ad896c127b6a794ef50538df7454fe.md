# 概要

Haxeのイテレーターは、`for`ループを使って値を反復処理するために使います。イテレーターには次の2つの種類があります。

- `Iterator`：値を反復処理するもの。
- `Iterable`データ：データ型を反復処理できるようにするもの。

これらの概念は、それぞれ`Iterator<T>`と`Iterable<T>`で表されます。

```haxe
typedef Iterator<T> = {
  function hasNext():Bool;
  function next():T;
}

typedef Iterable<T> = {
  function iterator():Iterator<T>;
}
```

これらの型のいずれかと一致するクラスは、`for`ループで反復処理できます。クラスが`hasNext`と`next`というメソッドを定義していればイテレーターと見なされ、そうでなく`iterator`メソッドを定義していればイテラブル型と見なされます。

```haxe
class MyStringIterator {
  var str:String;
  var i:Int;

  public function new(str:String) {
    this.str = str;
    i = 0;
  }

  public function hasNext():Bool {
    return i < str.length;
  }

  public function next():String {
    return str.charAt(i++);
  }
}
```

上の例では、クラス`MyStringIterator`は`hasNext`と`next`の両方のメソッドを実装しているためイテレーターと見なされ、`Iterator<String>`と互換性があります。

```haxe
class MyArrayWrap<T> {
  var arr:Array<T>;

  public function new(a:Array<T>) {
    this.a = a;
  }

  public function iterator() {
    return a.iterator();
  }
}
```

ここでは、クラス`MyArrayWrap`は`Iterable<Array<T>>`と互換性があるため、イテラブルなデータ型と見なされます。
