# はじめに

`|>`演算子は、パイプ演算子と呼ばれます。これを使うと、複数の関数呼び出しをつなげ、前の関数呼び出しの戻り値を次の関数呼び出しに渡すことができます。

```gleam
"hello"
|> string.uppercase
|> string.append("?!")
// -> "HELLO?!"
```

上のコードは、次のコードと同じです。

```gleam
string.append(string.uppercase("hello"), "?!")
```

パイプ演算子は、値を関数呼び出しの最初の引数として渡すか、あるいは新しい呼び出しの唯一の引数として渡します。どちらになるかは、正しい型になるほうが選ばれます。

```gleam
100
|> function_that_takes_two_arguments(1)

// Is equivalent to
function_that_takes_two_arguments(100, 1)
```

```gleam
100
|> function_that_returns_a_function(1)

// Is equivalent to
function_that_returns_a_function(1)(100)
```

値を別の位置に渡したいこともあります。そのような場合は、`_`プレースホルダーを使って、値をどこに挿入するかを示すことができます。

```gleam
100
|> some_function(1, _, 2)
```
