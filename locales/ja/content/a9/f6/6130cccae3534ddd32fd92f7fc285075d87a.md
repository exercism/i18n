# 概要

Elmは、信頼できるウェブアプリケーションを作るための楽しい言語です。
エラーメッセージは親切で、パフォーマンスもよく、アセットも小さく、実行時例外もありません。

Elmでおそらく最も有名で、最も広くまねされている部分といえば、The Elm Architectureでしょう。
これはウェブアプリケーションを組み立てるためのシンプルなパターンで、Elmのウェブアプリケーションはすべてこの形で書かれます。

中心となる考え方はシンプルです。
コードは、アプリケーションの状態を表す`Model`、そのモデルを`update`する方法、そしてモデルを`view`する方法を中心に組み立てられます。

`Model`にはアプリケーションの状態、つまりアプリケーションが必要とするすべてのデータが入ります。
テキストボックスと、そのテキストを逆にしたものを表示するテキストだけのシンプルなアプリケーションを想像すると、モデルは次のようになります。
この例は[Elm Guide][elm-guide-text-fields]でも見ることができます。

```elm
type alias Model =
  { text : String
  }
```

`update`は、変化があったとき（ユーザーがボタンをクリックしたときなど）に`Msg`を受け取って呼び出される関数です。
`Msg`と現在の`Model`を受け取り、新しい`Model`を返します。

```elm
type Msg
  = TextChanged String

update : Msg -> Model -> Model
update msg model =
  case msg of
    TextChanged newText ->
      { model | text = newText }
```

`view`は、ブラウザーでユーザーに見せるHTMLを返す関数です。
現在の`Model`を受け取り、`Html Msg`（ElmがHTMLを表すために使う型）を返します。

```elm
view : Model -> Html Msg
view model =
  Html.div []
    [ Html.input
      [ Html.Attributes.placeholder "Text to reverse"
      , Html.Attributes.value model.text
      , Html.Events.onInput TextChanged
      ]
      []
    , Html.div [] [ Html.text (String.reverse model.text) ]
    ]
```

[elm-guide-text-fields]: https://guide.elm-lang.org/architecture/text_fields
