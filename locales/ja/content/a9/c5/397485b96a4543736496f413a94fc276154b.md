# 概要

主要な算術演算子と比較演算子は、自作のクラスや構造体で使えるように適応できます。これを _演算子のオーバーロード_ と呼びます。

この[記事][operator-overloading]では、構文に加えて、どの演算子がオーバーロードできて、どれができないかを詳しく論じています。

ほとんどの演算子は次の形をとります。

```csharp
static <return type> operaator <operator symbols>(<parameters>);
```

[キャスト演算子][ud-conversion-operators]は次の形をとります。

```csharp
static (explicit|implicit) operator <cast-to-type>(<cast-from-type> <parameter name>);
```

演算子は静的メソッドと同じように動作します。

- 演算子記号はメソッドの識別子の代わりになり、仮引数と戻り値の型を持ちます。仮引数と戻り値の型に関するルールは直感に沿ったもので、詳しいことはコンパイラーが教えてくれます。
- 二項演算では、最初の仮引数が演算の左側の引数を受け取ります。
- 演算子のシグネチャは、二項演算の場合は2つの仮引数と戻り値の型、単項演算子の場合は1つの仮引数と戻り値の型で構成されます。
- 二項演算子では、仮引数の型のうち1つが、宣言するクラスの型でなければなりません。
- 型変換の場合は、仮引数か戻り値の型のどちらかが、宣言するクラスの型でなければなりません。
- インクリメント演算子とデクリメント演算子では、仮引数と戻り値の型が、宣言するクラスの型でなければなりません。

構文の例：

```csharp
struct Point
{
    decimal x;
    decimal y;

    public static bool operator ==(Point pt, Point ptOther)
    {
        return pt.x == ptOther.x && pt.y == ptOther.y;
    }

    public static bool operator !=(Point pt, Point ptOther)
    {
        return !(pt == ptOther);
    }

    public static Point operator *(Point pt, decimal scale)
    {
        var ptNew = new Point();
        ptNew.x = pt.x * scale;
        ptNew.y = pt.y * scale;
        return ptNew;
    }

    public static implicit operator Point((decimal x, decimal y) xy)
    {
        var pt = new Point();
        pt.x = xy.x;
        pt.y = xy.y;
        return pt;
    }

    public static explicit operator (decimal x, decimal y)(Point pt)
    {
        return (pt.x, pt.y);
    }
}
```

[`Equals()`][equals]メソッドを実装し、それを`==`演算子から呼び出すと、よく効果を発揮します。同様に、比較のために[`IComparable`][icomparable]インターフェースを実装することもできます。どちらの場合も、一石二鳥ならぬ、少し大きめの石ひとつで二鳥を仕留められます。

標準の演算子セットに含まれない記号から演算子を作ることはできない、という点に注意してください。ドキュメントでオーバーロードできると明記されている演算に限り、既存の記号だけを使えます。オーバーロードできる演算子は[こちら][overloadable-operators]に一覧があります。

型が異なる場合、仮引数の順序が重要になることに注意してください。上のサンプルコードでは、`pt * 10m`は有効な式ですが、`10m * pt`はコンパイルできません。
