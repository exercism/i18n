# はじめに

## 配列

Rubyでは、**配列**は順序を持ち、整数のインデックスで要素を指定できる、あらゆるオブジェクトのコレクションです。
配列のインデックスは`0`から始まります。
負のインデックスは、配列の末尾からの位置を表します。たとえば、`-1`は配列の最後の要素、`-2`は後ろから2番目の要素を指し、以下同様に続きます。

### 配列の作成

配列は通常、`[]`という記法で作成します。
どんな型のオブジェクトでも入れることができます。

```ruby
array = [1, "two", 3.0]
```

### 要素の参照

配列の要素は、`#[]`メソッドを使ってインデックスで取得できます。
これは、そのインデックスにある要素を返すか、開始インデックスから指定した長さだけ続く部分配列を返します。
負のインデックスは、配列の末尾からさかのぼって数えます。

```ruby
a = [ "a", "b", "c", "d", "e" ]

a[2]       #=> "c"
a[6]       #=> nil
a[1, 3]    #=> [ "b", "c", "d" ]

a[-1]      #=> "e"
a[-2]      #=> "d"
a[-3, 2]   #=> ["c", "d"]
```

### 便利なメソッド

配列には便利なメソッドがたくさんあります。
よく使うものをいくつか紹介します。

```ruby
fibonacci = [0, 1, 1, 2, 3, 5, 8, 13]

fibonacci.size      #=> 8
fibonacci.sum       #=> 33
fibonacci.reverse   #=> [13, 8, 5, 3, 2, 1, 1, 0]
```

## 列挙

Rubyでは、コレクションを繰り返し処理するためにループを使うのではなく、列挙を使います。

列挙とは、コレクション（ここでは配列）を順に見ていき、各要素に対して何らかの操作を行うことです。列挙はRubyの重要な概念で、並べ替え、グループ化、マッピング、畳み込みなど、さまざまな場面で使われます。

配列の各単語を出力する列挙は、次のようになります。

```ruby
words = ["the", "cat", "sat"]
words.each do |word|
  puts word
end

# Output:
# the
# cat
# sat
```

この例では、配列に対して`.each`メソッドを呼び出し、1つの入力（`word`）を受け取ってそれを出力する_ブロック_を渡しています。

_ブロック_については、このトラックの後半で詳しく見ていきますが、今のところは、0個以上の入力を受け取ることができる名前のない関数だと考えておけば大丈夫です。
ブロックは、`do...end`の構文（上記）でも、`{}`の構文（下記）でも定義できます。

ブロックを使う配列のメソッドの例を、ほかにもいくつか挙げます。

```ruby
fibonacci = [0, 1, 1, 2, 3, 5, 8, 13]

fibonacci.count  { |number| number == 1 }   #=> 2
fibonacci.any?   { |number| number == 6 }   #=> false
fibonacci.select { |number| number.odd? }   #=> [1, 1, 3, 5, 13]
fibonacci.all?   { |number| number < 20 }   #=> true
fibonacci.map    { |number| number * 2  }   #=> [0, 2, 2, 4, 6, 10, 16, 26]
```
