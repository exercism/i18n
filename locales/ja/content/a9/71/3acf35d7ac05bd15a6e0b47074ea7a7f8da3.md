# はじめに

Factorの文字列は、文字の並びです。`sequences`ボキャブラリーのほとんどのワードは、`splitting`、`ascii`などにある文字列専用のワードに加えて、文字列にも使えます。

## 文字列リテラル

文字列は二重引用符で書きます。通常のエスケープシーケンス（`\n`、`\t`、`\r`、`\\`、`\"`）に対応しています。

```factor
"hello, world" .                 ! => "hello, world"
"first\nsecond" print            ! prints two lines
```

## 長さとインデックス

文字列はシーケンスなので、`sequences`ボキャブラリーの`length`と`nth`がそのまま使えます。

`length`は文字数を返します。

```factor
"hello" length .    ! => 5
```

`nth`は0から始まるインデックスとシーケンスを受け取り、その位置にある要素を返します。文字列の場合、その要素は*文字*、つまりコードポイント（整数）であり、1文字の部分文字列ではありません。

```factor
0 "hello" nth .     ! => 104   (CHAR: h)
4 "hello" nth .     ! => 111   (CHAR: o)
```

## 文字から文字列に戻す

1つのコードポイントを1文字の文字列に変えるには、`strings`ボキャブラリーの`1string ( char -- str )`を使います。`CHAR:`は、コードポイントのリテラルをパーサー時に書く形式です。

```factor
CHAR: A 1string .                ! => "A"
0 "hello" nth 1string .          ! => "h"
```

## 分割

`splitting`ボキャブラリーは文字列を断片に切り分けます。

`split1`は区切り文字が*最初に*現れる位置で切り、両方の半分を返します。

```
split1 ( seq subseq -- before after )
```

```factor
"foo: bar" ": " split1 .s
! => "foo"
! => "bar"
```

`split`は区切り文字の集合に含まれる*いずれか*の文字で切り、空の断片ができることもあります。

```factor
"[ERROR]: Stack overflow" "[]" split .
! => { "" "ERROR" ": Stack overflow" }
```

`harvest`（`sequences`ボキャブラリー）は空の断片を取り除きます。

```factor
"[ERROR]: Stack overflow" "[]" split harvest .
! => { "ERROR" ": Stack overflow" }
```

## 断片を取り出す

文字列を断片の配列に分割したら、`first`、`second`、`third`、`fourth`（`sequences`ボキャブラリー）でその位置にある断片を返せます。

```factor
"apple,bee,carrot,duck" "," split first .    ! => "apple"
"apple,bee,carrot,duck" "," split second .   ! => "bee"
"apple,bee,carrot,duck" "," split third .    ! => "carrot"
"apple,bee,carrot,duck" "," split fourth .   ! => "duck"
```

先頭の断片をまとめてスタックに載せたいときは、`first2`と`first3`が2つまたは3つを一度に展開します。

```factor
"apple,bee,carrot,duck" "," split first2 .s
! => "apple"
! => "bee"

"apple,bee,carrot,duck" "," split first3 .s
! => "apple"
! => "bee"
! => "carrot"
```

文字列そのものに対して`first`を使うと、部分文字列ではなく、最初の**文字**（コードポイント）が返ります。

```factor
"hello" first .                         ! => 104   (CHAR: h)
```

## 空白を取り除く

`[ blank? ] trim`（`sequences`ボキャブラリーのワードで、`blank?`は`ascii`ボキャブラリーのもの）は、先頭と末尾の空白を取り除きます。

```factor
"  Disk full \r\n" [ blank? ] trim .
! => "Disk full"
```

## 大文字と小文字の変換

`>lower`と`>upper`（`ascii`ボキャブラリー）は、大文字と小文字を変換した新しい文字列を返します。

```factor
"WARNING" >lower .    ! => "warning"
"hello" >upper .      ! => "HELLO"
```

## 文字列の連結

`sequences`ボキャブラリーの2つのワードで文字列を組み立てられます。

`surround`は文字列を接頭辞と接尾辞で包みます。

```
surround ( seq pre post -- new-seq )
```

```factor
"warning" "(" ")" surround .    ! => "(warning)"
```

`glue`は2つの文字列を、間に区切り文字を挟んでつなぎます。

```
glue ( s1 s2 sep -- s )
```

```factor
"Disk full" "(error)" " " glue .    ! => "Disk full (error)"
```
