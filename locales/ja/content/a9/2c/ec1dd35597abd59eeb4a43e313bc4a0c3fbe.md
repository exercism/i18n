# インストール

[Godot Engine][godot-engine]は、GDScriptのコードを実行するために使います。
Godot Engineは、Windows、Linux、macOS、Androidで動作します。



## Godot Engineのインストール

Godot Engineは、[Godot Engineのウェブサイト][godot-engine]から直接ダウンロードできます。
ダウンロードしたものには、Godot Engineのバージョン名が付いた実行ファイルが1つだけ含まれています。
このファイルは、名前を`godot`に変更し、`$PATH`に含まれるディレクトリのいずれかに置く必要があります。
インストールが完了したら、ターミナルで次のコマンドを実行すると、CLIが正しくインストールされたか確認できます。

```bash
godot --version
```

このトラックでは、Godotのバージョン4.7.2を使用します。
