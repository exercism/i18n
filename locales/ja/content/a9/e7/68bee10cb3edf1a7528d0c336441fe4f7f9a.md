# 概要

[構造体][structs-and-classes]（一般に*struct*と呼ばれます）は、Swiftプログラムの主要な構成要素のひとつです。
構造体を使うと、関連するプロパティ（データ）とメソッド（振る舞い）をひとつにまとめた独自の型を作ることができます。
実際、`Int`、`Double`、`Bool`、`String`、`Array`、`Dictionary`といったSwiftの標準型は、すべて構造体として実装されています。

## 構造体の定義

構造体は、`struct`キーワードに続けて型名を書き、その定義を波括弧（`{}`）で囲んで定義します。
Swiftの慣習では、構造体の名前は`UpperCamelCase`を使います。

```swift
struct CharacterStats {
    var health = 0.0
    var speed = 0
    var strength = 0
}
```

## インスタンスの作成

構造体の定義は設計図です。
構造体の*インスタンス*を作るには、型名のあとに括弧（`()`）を書いてイニシャライザを呼び出します。

```swift
var someStats = CharacterStats()
```

これで、定義にあるデフォルトのプロパティ値が設定されたインスタンスが作られます。

Swiftは、構造体に対して**メンバーワイズイニシャライザ**も自動的に生成します。これを使うと、名前を指定してプロパティを初期化できます。

```swift
let customStats = CharacterStats(health: 100.0, speed: 6, strength: 18)
```

## プロパティへのアクセスと変更

インスタンスのプロパティには、*ドット記法*を使ってアクセスしたり変更したりできます。

```swift
var stats = CharacterStats()

print(stats.health) // Prints 0.0

stats.health = 87.3
print(stats.health) // Prints 87.3
```

構造体は値型なので、インスタンスのプロパティを変更するには、そのインスタンス自体を`var`で宣言する必要があります。
インスタンスを`let`で宣言すると、そのプロパティはすべて不変になります。
