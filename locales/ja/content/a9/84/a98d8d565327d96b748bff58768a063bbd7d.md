# 学習

Rexxというプログラミング言語は、Perl、Tcl、Pythonといった似た言語と比べると、とても学びやすい言語です。その理由は、シンプルな構文、英語に似た命令、そしてミニマルな設計にあります。

Rexxの学習リソースはたくさんありますが、そのほとんどはメインフレーム上のRexxを対象にしており、Rexx言語の機能を深く掘り下げることよりも、プラットフォームの機能との連携に重点を置いたものが一般的です。典型的な例がこちらです：[REXX Tutorial - IBM Mainframer](https://www.ibmmainframer.com/rexx-tutorial/#main)。興味深い内容ですが、メインフレーム以外でRexxを学ぶ人にとっては、理想的なリソースとは言えないでしょう。

より役立ち、初心者にも親しみやすいRexxの学習リソースが[Rexx Tutorial - Tutorials Point](https://www.tutorialspoint.com/rexx/index.htm)です。ループの書き方や組み込み関数の使い方を調べるといった、手軽なリファレンスとして役立ちます。ただし、当てはまらない機能やさまざまなRexxの実装も扱っているため、かえって分かりにくくなることがあります。

## おすすめのチュートリアル
著者の意見では、最も役に立ち、かつ楽しいRexxのチュートリアルは、Jeff Glattによる[Learn REXX Programming in 56,479 Easy Steps](http://nokix.sourceforge.net/help/learn_rexx/language.htm)です。言語の概要を示すだけでなく、さまざまな機能を直感的に、そしてある程度深く掘り下げて解説しています。リファレンスとしても役立ちます。あらゆるスキルレベルの学習者に、ぜひおすすめします。

## おすすめのリファレンス
このトラックではRexxの[Regina](https://regina-rexx.sourceforge.io/index.html)実装を使っているため、最も適したリファレンスは付属のドキュメントです。Reginaの配布物の`docs`フォルダーに入っていますが、[Regina Documentation](https://sourceforge.net/projects/regina-rexx/files/regina-documentation/3.9.5/regina.pdf)から直接ダウンロードすることもできます。
