# 概要
ループとは、まとまった1つ以上の文を繰り返し実行するための仕組みです。
まとまった文を1回実行することを繰り返しと呼びます。

## `while`ループ

`while`ループは、ループの先頭にある真偽値の式が`true`である間、まとまった文を実行し続けます。
真偽値の式が`false`になると、ループは実行を止め、処理はループの次の行へ進みます。

最初から真偽値の式が`false`と評価される場合、`while`ループは一度も実行されず、処理はループの次の行へ進みます。

```c
int main() {
    int i = 0;
    while (i < 5) {
        printf("Number is %i\n", i++);
    }    
    return 0;
}
```

ループを終わらせるための条件を用意することが大切です。そうしないと無限ループになり、コードは先へ進めなくなります。
上のコードで`i`から`++`を外すと、無限ループになります。

## `do`ループ

`do`ループでは、真偽値の式をループの末尾で判定します。
次の例のように、`do`ループは必ず少なくとも1回は実行されます。

```c
do {
    printf("Enter the Answer to the Ultimate Question of Life: ");
    scanf("%d", &answer);
} while (answer != 42); 
// Note that a semicolon is needed after the Boolean expression.
```

同じことを`while`ループで書くと、もっと冗長になります。

```c
printf(""Enter the Answer to the Ultimate Question of Life: ");
scanf("%d", &answer);
while (answer != 42) {
    printf(""Enter the Answer to the Ultimate Question of Life: ");
    scanf("%d", &answer);
}
```

## `for`ループ

ループでは、ある変数を更新しながら、その変数が特定の値になったら終了する、ということがよくあります。
`for`ループは、1つ以上の変数の初期化・更新・判定を、括弧（`()`）の中の1行にまとめて書くための仕組みです。
最初の部分は変数の初期化、2番目の部分は変数の判定、3番目の部分は変数の値の更新に使います。

```c
for (int i = 0; i < 5; i++) {
    printf("Number is %i\n", i);
}
```

同じことを`while`ループで書くよりも簡潔で、それでいて読みやすさも保たれています。

`for`ループの初期化と更新の部分では、条件の中の式をカンマ演算子で区切ることで、複数の変数を扱うこともできます。

```c
    int i, j;
    for (i = 0, j = 5; i < 5 && j > 2; i++, j--) {
        printf("i is %i\n", i);
        printf("j is %i\n", j);
    }
    printf("After the loop");
```

これは次のように出力されます。

```
i is 0
j is 5
i is 1
j is 4
i is 2
j is 3
After the loop
```

`for`ループは、どの部分も省略できます。
空の判定式は`true`と評価されるので、次のように`for`ループで無限ループを書くこともできます。

```c
int i = 0;
for (;;) {
    printf("Number is %i\n", i++);
    if (i == 5) break;
}
```

これは`while`ループとよく似ています。`i`はループの前に初期化され、ループの中でインクリメントされます。
また、`i`の判定はループの中で行われ、ループは`break`文で終わります。

## `break`文

ループが、真偽値の式では判定されない特別な条件で終了しなければならないこともあります。
`break`文を使うとループが終了し、処理はループの次の行へ進みます。

```c
int i, j, k;
for (int i = 0, j = 5, k = 3; i < 5 && j > 2; i++, j--) {
    printf("i is %i\n", i);
    printf("j is %i\n", j);
    if (k == 3) break;
}
printf("After the loop");
```

これは次のように出力されます。

```
i is 0
j is 5
After the loop
```

## `continue`文

ループが、今の繰り返しを最後まで実行せずに次の繰り返しへ進みたいこともあります。
`continue`文を使うと、今の繰り返しの実行を中止し、次の繰り返しの先頭から実行を続けます。

```c
int i, j;
for (int i = 0, j = 4; i < 4 && j > 0; i++, j--) {
    if (i == j) continue;
    printf("i is %i\n", i);
    printf("j is %i\n", j);
}
printf("After the loop");
```

これは次のように出力されます。

```
i is 0
j is 4
i is 1
j is 3
i is 3
j is 1
After the loop
```

`i`と`j`がどちらも`2`のときは、その値は出力されません。
