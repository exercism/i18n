# はじめに

## ジェネリクス

型パラメーターを使って、どんな型の値でも入れられる型を_ジェネリック型_といいます。

たとえば、この`Box`型には型パラメーター`a`があります（小文字で書きます）。

```gleam
pub type Box(a) {
  Box(a)
}
```

`a`という型パラメーターは、どんな型にも当てはまるプレースホルダーです。そのため`Box`は文字列や整数、そのほかのどんな型でも使えます。

```gleam
Box("Hello, Joe!") // The type is Box(String)

Box(42) // The type is Box(Int)
```

型に複数の型パラメーターを持たせることもできます。その場合はカンマで区切ります。

```gleam
pub type Pair(a, b) {
  Pair(a, b)
}
```

### ジェネリック関数

型パラメーターは、関数の引数でも使えます。

この関数は、型`a`の値を受け取り、`a`を受け取って`b`を返す関数を2回呼び出します。

```gleam
pub fn twice(value: a, f: fn(a) -> b) -> b {
  f(value)
  f(value)
}
```
```gleam
// The type is fn(String, fn(String) -> Nil) -> Nil
twice("Hello, Joe!", io.println)
```
