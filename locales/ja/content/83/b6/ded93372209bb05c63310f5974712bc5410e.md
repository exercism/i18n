# 説明の補足

## ワード

名簿を保持する`school`タプルを定義します。その中で生徒をどう格納するかは自由です。その後、以下に挙げるワードを実装しましょう。

- `<school> ( -- school )`：空の学校を作ります。
- `add-student ( school name grade -- ? )`：`name`を`grade`に追加します。成功したら`t`を返し、`name`がすでに追加されている場合（この学年でも他の学年でも）は`f`を返します。その場合、名簿は変更されません。
- `roster ( school -- names )`：すべての生徒を、学年順、次に名前のアルファベット順に並べたものです。
- `grade ( school n -- names )`：学年`n`の生徒を、名前のアルファベット順に並べたものです。
