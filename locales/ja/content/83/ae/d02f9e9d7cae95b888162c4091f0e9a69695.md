# 概要

[シンボル][symbols]は、値の参照に使える名前付きの識別子です。シンボルはシンボルリテラルで作成します。シンボルリテラルとは、名前の前に`:`を付けたもので、たとえば`:foo`のようになります。引用符で囲んで書くこともでき、たとえば`:"foo"`のように書くと、名前にスペースを含められます。

```ruby
:foo # => :foo
:"foo boo" # => :"foo boo"
```

シンボルはこの言語のさまざまな場所で使われています。ハッシュのキーとして使ったり、メソッド名や変数名を表したりします。

## 識別子

シンボルが文字列と違うのは、シンボルが識別子であり、データやテキストを表さないという点です。つまり、同じ名前のシンボルは常に同じオブジェクトになります。

```ruby
"foo".object_id # => 60
"foo".object_id # => 80
:foo.object_id # => 1086748
:foo.object_id # => 1086748
```

## シンボルの変更

シンボルはイミュータブルであり、変更することができません。つまり、シンボルを「変更」しても、実際には新しいシンボルが作成されているのです。シンボルを操作するためのメソッドがいくつかあり、それらはすべて新しいシンボルを返します。すべてのメソッドは[Symbol API][symbols-api]にまとまっています。

```ruby
:foo.upcase # => :FOO

:foo.object_id # => 1086748
:foo.upcase.object_id # => 60
```

シンボルがイミュータブルであることの利点は、文字列よりもメモリ効率がよいこと、そして識別子として使うときに安全であることです。

## 変換

シンボルは文字列に変換でき、その逆も可能です。これは、シンボルを変更したいときや、シンボルを文字列として使いたいときに便利です。文字列をシンボルにするには`String#to_sym`メソッドを使い、その逆には`Symbol#to_s`メソッドを使います。シンボルは使えるメソッドが限られているため、新しいシンボルが必要な場合は、シンボルを文字列に変換して文字列のメソッドを使うと便利です。

```ruby
:foo.to_s # => "foo"
"foo".to_sym # => :foo
```
