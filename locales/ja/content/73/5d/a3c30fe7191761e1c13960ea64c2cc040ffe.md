# 概要

[Lua](https://lua.org)は、シンプルでありながら強力で、効率的かつ軽量な、埋め込み可能なスクリプト言語です。ブラジルの[PUC-RIO](https://www.puc-rio.br/)で、1993年からRoberto Ierusalimschy、Waldemar Celes、Luiz Henrique de Figueiredoのチームによって設計・実装・保守されています。

## コメント

Luaの1行コメントは`--`で始まり、複数行コメントは`--[[`で始まり`]]`で終わります。
```lua
-- This is a single line comment.

--[[This is
a multiline
comment
]]
```

## 変数

Luaの変数には、グローバル変数、ローカル変数、テーブルのフィールドという3つの種類があります。ここでは話を簡単にするため、ローカル変数だけを説明します。デフォルトではすべての変数がグローバルなので、ローカル変数にするには`local`キーワードを付けて宣言する必要があります。
```lua
local x
```

変数に値を代入するには、`=`演算子を使います。
```lua
local x = 1
```

`local`変数のスコープは、宣言されたブロック内に限られます。ブロックとは、制御構造の本体、関数の本体、あるいは変数が宣言されたファイルや文字列のことです。
```lua
local x = 1

if x == 1 then
  local x = 2
  print(x) -- prints 2
end

print(x) -- prints 1
```

## 関数

関数は`function`キーワードで宣言し、変数と同じくデフォルトではグローバルです。関数の定義には、名前、仮引数のリスト、本体があります。関数は`return`キーワードに到達すると終了し、そのあとに並んでいる値をすべて返します。`return`を指定しなければ、関数は`nil`を返します。

```lua
-- Defining a local function which returns "Hello " followed by 
-- the name which was given as parameter
local function say_hello(name)
  return 'Hello ' .. name
end
```

## テーブル

テーブルは、Luaにおける唯一のデータ構造化の仕組みであり、非常に強力です。配列、集合、オブジェクト、モジュールなど、さまざまなものを表すために使われます。Luaのテーブルは、本質的には連想配列です。
```lua
-- create a table and assign its reference to tbl
local tbl = {}

-- new entry with key 'x' and value 1
tbl['x'] = 1

-- printing the value
print(tbl['x'])  --> 1

-- uninitialized table fields evaluate to nil
print(tbl['y'])  --> nil

-- there is also syntactic sugar - the following is the same as above
tbl.y = 1
print(tbl.y)    --> 1
```

これは、次のセクションに必要なほんの少しの予備知識です。この話題には、あとで詳しく戻ってきます。

## モジュール

モジュールとは、`.lua`ソースファイルに保存されたコードの集まりです。モジュールがエクスポートするものはすべてテーブルに格納され、そのテーブルがファイルの最後で返されます。つまり、テーブルは基本的にある種の名前空間として機能します。
```lua
-- say-hello.lua

-- defining the table 'say' which is exported at the end
local say = {}

-- defining the function 'hello' as a table field
-- this is syntax sugar for: say.hello = function() print('Hello!') end
function say.hello()
  print('Hello!')
end

-- returning (exporting) the table 'say'
return say
```

そのモジュールは、`require`関数を使って別のファイルに読み込むことができ、この関数がテーブルを返します。
```lua
-- lets_say_hello.lua
local say = require('say-hello')
say.hello() -- prints "Hello!"
```

`say.hello`を見ると、「モジュール`say`の関数`hello`」と思うでしょう。しかし、`say-hello.lua`がテーブルを返すことを知り、テーブルのセクションを思い返すと、Luaではこの式が「文字列`hello`をキーとしてテーブル`say`をインデックス参照する」という意味だと気づきます。  

モジュールがテーブルを返すのは良い習慣ですが、関数など、ほかの型を返すことも同じように可能です。

```lua
--- say-bye.lua
local function bye()
  print('Bye!')
end

return bye
```
