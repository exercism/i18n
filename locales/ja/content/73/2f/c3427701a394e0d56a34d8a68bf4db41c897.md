# 概要

[`switch`式][switch-expressions]は、[concept:csharp/switch-statements]()で扱った[`switch`文][switch-statements]とよく似た動作をします。入力となる条件を動作や値に対応づける、一種の決定表をサポートしています。

`switch`式の中心にあるのは、_パターンマッチング_です。演習では、値を`const`パターンとマッチングさせました。この場合、`switch`への入力は_範囲式_で、これが`const`値と、_ケースガード_が使う値にマッチングされます。

ケース（`switch`の_アーム_とも呼ばれます）は書かれた順に評価され、マッチが見つかり次第、処理は打ち切られて、対応する値が返されます。

リストの最後にある`_`のケースは、マッチングが網羅的であることを保証し、起こりうる実行時エラーを避けるのに役立ちます。

```csharp
double xx = 42d;

string interesting = xx switch
{
    0 => "I suppose zero is interesting",
    3.14 when DateTime.Now.Day == 14 && DateTime.Now.Month == 3 => "Mmm pie!",
    3.14 => "π",
    42 => "a bit of a cliché",
    1729 => "only if you are a pure mathematician",
    _ => "not interesting"
};

// => interesting == "a bit of a cliché"
```

`switch`の「アーム」は、パターンが範囲変数とマッチし、いずれかのケースガードが真と評価されたときに選ばれます。

`switch`式は、[型パターン][pattern-matching]と再帰的なマッチングもサポートしています。
