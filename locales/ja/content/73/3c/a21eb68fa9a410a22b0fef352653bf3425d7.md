# テスト

Exercismのウェブサイトにあるオンラインエディターを使えば、演習を解くことができます。
または、演習を自分のコンピューターにダウンロードして手元で解き、それからExercismに提出する方法もあります。
このドキュメントの残りでは、手元で作業する方法について説明します。

## Exercism CLI

演習をダウンロードして提出するには、`exercism`コマンドラインツールが必要です。
ダウンロードと設定の手順については、[exercism CLIのドキュメント][exercism-cli]を参照してください。

演習をダウンロードするには、次のようにします。

```bash
exercism download --track 8th --exercise hello-world
```

そして、演習のディレクトリに移動します。

```bash
cd /path/to/your/exercism_workspace/8th/hello-world
```

Windowsを使っている場合はこちらです。

```cmd
cd \path\to\your\exercism_workspace\8th\hello-world
```

`exercism configure`コマンドを使うと、自分のexercismワークスペースを確認できることに注意してください。

## 手元でテストする

演習のテストを実行するには、その演習の正しいディレクトリにいる必要があります。
そして、次のコマンドでテストを起動します。

```bash
8th -f test.8th
```

## スキップされるテスト

演習を解くというのは、そのテストをすべて通すということです。
デフォルトでは、テストを実行したときに実行されるのは1つ目（最初）のテストだけです。
これは意図的なもので、まずはその1つのテストを通すことに集中できます。
それが通ったら、`SKIP-REST-OF-TESTS`の行をその下に移動すると、次のテストを有効にできます。

### スキップを上書きする

`SKIP-REST-OF-TESTS`という語より後のテストも含めて、すべてのテストを実行するには、環境変数`RUN_ALL_TESTS`に`true`を設定します。
テストを実行している間だけこれを設定する方法の1つは、次のとおりです（macOSとLinux）。

```bash
RUN_ALL_TESTS=true 8th -f test.8th
```

## 解答を提出する

exercismツールを使って、自分の解答をExercismのウェブサイトにアップロードするには、次のようにします。

```bash
exercism submit
```

すべてのテストに通っていなくても、コードをアップロードできることに注意してください。
行き詰まってメンターの助けが必要なときには、これが役立ちます。

[exercism-cli]: https://exercism.org/docs/using/solving-exercises/working-locally
