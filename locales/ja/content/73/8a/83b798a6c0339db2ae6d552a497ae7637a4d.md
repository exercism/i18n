# はじめに

ループには、基本的に2つの種類があります。

1. 条件が満たされるまで繰り返す。
2. コレクションの各要素を繰り返し処理する。

どちらもRで実現できますが、1つ目のほうがよく使われるかもしれません。

## `while`と`repeat`

繰り返す回数が前もってわからない、終わりの決まっていない問題には、Rには条件をともなう`while`ループと、条件のない`repeat`ループ（`while (TRUE)`と同じ）があります。

基本的な形はとてもシンプルです。

```R
while (condition) {
  do_something()
}
```

この場合、`condition`が`TRUE`でなくなるまで、プログラムはループを回り続けます。

ループを途中で抜ける方法が2つあります。

- `break`を使うとループを抜け、実行はループを閉じる波括弧`}`の次の行から続きます。
- `return(x)`は現在の関数の実行を止め、戻り値`x`を呼び出し元に返します。

これらの方法があるので、`repeat { ... }`で「無限」ループを作り、ループ本体の中で停止条件を見つけて`break`や`return`を発動させる、という書き方が便利なこともあります。

この3つの書き方は同じ結果になり、どれも`x == 0.4444...`で終わります。

```R
x <- 12
while (x > 1) {
  x <- x / 3
}

x <- 12
while (TRUE) {
  x <- x/3
  if (x <= 1) break
}

x <- 12
# no boolean clause 
repeat { 
  x <- x/3
  if (x <= 1) break
}
```

## ベクトルを繰り返し処理する

Rでは、これは不要なことがよくあります。
ほかの概念でも説明したように、多くの関数はベクトル全体を対象に処理を行います。

しかし、明示的なループが必要になることもあります。
特に次のような場合です。

- ループ本体が、出力やファイル入出力などの副作用を持つ場合。
- 何回繰り返すか予測できないまま、ある条件を満たすまで繰り返しを続ける場合。

ループの条件は括弧（`()`）で囲む必要があります。
関数の本体と同じく、1行のループ本体では波括弧は省略できます（ただし、書くことが多いです）。

```R
words <- c("This", "is", "a", "loop")
for (w in words) { print(w) } # the braces are optional here
#> [1] "This"
#> [1] "is"
#> [1] "a"
#> [1] "loop"
```

現在の繰り返しがある条件を満たさないときは、`next`で次の繰り返しにすぐ進むことができます。

```R
for (n in 1:10) {
    if (is_useless(n)) next
     
    # we decided this iteration could be useful
    do_something_slow(n)
}
```

数値のインデックスが必要なときは、`seq_along()`を使います。

```R
v <- LETTERS[1:3]
v
#> [1] "A" "B" "C"

for (i in seq_along(v)) { print(sprintf("%s%i", v[i], i)) }
#> [1] "A1"
#> [1] "B2"
#> [1] "C3"
```

`i in 1:length(v)`の使用は_おすすめしません_。`length(v)`が0のときに問題を引き起こす可能性があるからです。
範囲`1:0`は`c(1, 0)`と同じなので、ループ本体が実行されて、おそらく失敗します。
`seq_along()`関数は、このような場合を正しく処理するために作られています。
