# 説明

この演習では、お気に入りの料理本をもとに、絶品のラザニアを作るためのコードを書いていきます。

タスクは5つあり、どれもラザニアの調理にかかる時間に関するものです。

## 1. オーブンでの予想時間を分単位で定義する

引数を取らず、ラザニアをオーブンに入れておくべき時間を分で返す`Lasagna.expected_minutes_in_oven/0`関数を定義します。料理本によると、オーブンでの予想時間は40分です。

```elixir
Lasagna.expected_minutes_in_oven()
# => 40
```

## 2. オーブンでの残り時間を分単位で計算する

`Lasagna.remaining_minutes_in_oven/1`関数を定義します。この関数は、ラザニアをオーブンに入れてからの実際の経過時間を引数に取り、前のタスクで定義したオーブンでの予想時間をもとに、ラザニアをあと何分オーブンに入れておく必要があるかを返します。

```elixir
Lasagna.remaining_minutes_in_oven(30)
# => 10
```

## 3. 下準備にかかる時間を分単位で計算する

`Lasagna.preparation_time_in_minutes/1`関数を定義します。この関数は、ラザニアに追加した層の数を引数に取り、1層あたり2分かかると仮定して、ラザニアの下準備にかかった時間を分で返します。

```elixir
Lasagna.preparation_time_in_minutes(2)
# => 4
```

## 4. 合計の作業時間を分単位で計算する

`Lasagna.total_time_in_minutes/2`関数を定義します。この関数は2つの引数を取ります。1つ目の引数はラザニアに追加した層の数、2つ目の引数はラザニアをオーブンに入れてからの経過時間（分）です。この関数は、ラザニアの調理に合計で何分かかったかを返します。これは、下準備にかかった時間と、その時点までにラザニアがオーブンにあった時間の合計です。

```elixir
Lasagna.total_time_in_minutes(3, 20)
# => 26
```

## 5. ラザニアができたことを知らせる通知を作成する

引数を取らず、ラザニアが食べごろになったことを知らせるメッセージを返す`Lasagna.alarm/0`関数を定義します。

```elixir
Lasagna.alarm()
# => "Ding!"
```
