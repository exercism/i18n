# 指示

単語のスクラブルスコアを、それぞれの文字の点数を合計して計算してください。

各文字の点数は、次のとおりです:

| 文字                          | 点数 |
| ---------------------------- | ----- |
| A, E, I, O, U, L, N, R, S, T | 1     |
| D, G                         | 2     |
| B, C, M, P                   | 3     |
| F, H, V, W, Y                | 4     |
| K                            | 5     |
| J, X                         | 8     |
| Q, Z                         | 10    |

たとえば、"cabbage"という単語は14点になります:

- Cは3点
- Aは1点
- Bは3点
- Bは3点
- Aは1点
- Gは2点
- Eは1点
