しかし、少し整理されていません。Aazraの座標は、形式も並び順もRuiのものとは違うようで、どの宝物がどの場所に対応するのかを突き止めるには、2つの配列を何度も見比べなければなりません。Gleamを学び始めたばかりの2人は、宝探しの情報をうまく整理するために、小さなプログラム（実際には関数の集まりです）を書きたいと、助けを求めてやって来ました。

## 1. 場所を変換する

場所を表す`Location`（`#("C", 1)`など）を受け取り、宝物の場所（`#(1, "C")`など）に変換する`place_location_to_treasure_location`関数を実装します。

```gleam
place_location_to_treasure_location(#("C", 1))
// -> #(1, "C")
```

## 2. 宝物の場所と場所を比較する

場所（`#("C", 1)`など）を受け取り、宝物の場所（`#(1, "C")`など）と一致すれば`True`を返す`treasure_location_matches_place_location`関数を実装します。

```gleam
treasure_location_matches_place_location(#("C", 1), #(1, "C"))
// -> True

treasure_location_matches_place_location(#("C", 1), #(2, "C"))
// -> False
```

## 3. 場所にある宝物を数える

場所（`#("Aqua Lagoon (Island of Mystery)", #("F", 1))`など）と宝物の配列を受け取り、そこに見つかる宝物の数を返す`count_place_treasures`関数を実装します。

```gleam
let place = #("Aqua Lagoon (Island of Mystery)", #("F", 1))

count_place_treasures(place, treasures)
// -> 2
```

## 4. 特別な場所

`special_case_swap_possible`関数を実装します。この関数は、宝物（`#("Amethyst Octopus", #(1, "F"))`など）、場所（`#("Seaside Cottages", #("C", 1))`など）、そして交換したい宝物（`#("Crystal Crab", #(6, "A"))`など）を受け取り、次の組み合わせで`True`を返します。

- Abandoned Lighthouseでは、Brass Spyglassをほかのどんな宝物とも交換できます。
- Stormy Breakwaterでは、Amethyst OctopusをCrystal CrabまたはGlass Starfishと交換できます。
- Harbor Managers Officeでは、Vintage Pirate HatをModel Ship in Large BottleまたはAntique Glass Fishnet Floatと交換できます。
