# 概要

コードを分岐させたいときには、[`cond/1`][cond]が使えます。

```elixir
cond do
  x > 10 -> :this_might_be_the_way
  y < 7 -> :or_that_might_be_the_way
  true -> :this_is_the_default_way
end
```

`cond`は、`true`と評価された最初の分岐をたどります。少なくとも1つの節が`true`と評価される必要があります。そうでない場合は、実行時エラーが発生します。

`cond`による条件分岐は、論理的な分岐が3つ以上あり、それぞれの分岐の条件が異なる変数に基づいている場合によく使われます。すべての条件が同じ変数に基づいている場合は、[`case`][case]による条件分岐のほうが適しています。論理的な分岐が2つだけの場合は、代わりに[`if`][if]による条件分岐を使いましょう。

[cond]: https://hexdocs.pm/elixir/case-cond-and-if.html#cond
[case]: https://hexdocs.pm/elixir/case-cond-and-if.html#case
[if]: https://hexdocs.pm/elixir/case-cond-and-if.html#if
