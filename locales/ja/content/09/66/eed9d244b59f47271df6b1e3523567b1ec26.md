# ヒント

## 全般

- `plot`タプル、`registrations`と`next-id`のシンボル、そして`not-found`シンボルは、演習のファイルですでに宣言されています。
- モジュールレベルの状態には、`set-global`、`get-global`、`change-global`を使います。

## 1. 庭を開いて、登録の一覧を表示する

- `registrations`の初期値には`V{ } clone`が適しています（リテラルが呼び出し間で共有されないように、必ず`clone`します）。
- `1 next-id set-global`でカウンターを設定します。
- `list-registrations`には、`registrations get-global`を1つ書くだけで十分です。

## 2. 区画を登録する

- まず`next-id`を読み取り、次に`plot boa`で`id`と`name`から区画を組み立てます。
- `next-id [ 1 + ] change-global`でカウンターを1つ増やします。
- `push`（[`sequences`][sequences]にあります）は、ベクターにその場で要素を追加します。`registrations get-global`にぴったりです。

## 3. 区画を解放する

- `:: release ( id -- )`と定義すると、フィルターの述語の中で`id`が使えるようになります。
- `[ id>> id = ] reject`は、`id`スロットがローカルの`id`と一致*しない*区画だけを残します。これを`change-global`の本体として使います。

## 4. 登録済みの区画を取得する

- `find`は`( index elt/f )`を返します。`nip`でインデックスを捨てます。
- `[ not-found ] unless*`は、何も見つからなかったときにシンボルで置き換えます。

[sequences]: https://docs.factorcode.org/content/vocab-sequences.html
