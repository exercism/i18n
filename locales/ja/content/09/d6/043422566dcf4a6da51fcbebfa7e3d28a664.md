# はじめに

Factorの[`random`][random]ボキャブラリには、引数に応じて動作を変える汎用ワード`random`と、シーケンスをシャッフルしたりサンプリングしたりするための補助ワードが用意されています。

```factor
USING: random ;

6 random .                       ! a value from 0..5
{ "rock" "paper" "scissors" } random .   ! a random element
{ 1 2 3 4 5 } randomize .        ! the same cards, reordered
{ 1 2 3 4 5 } 2 sample .         ! two distinct elements
```

`random`は、整数`n`に対しては`[0, n)`の範囲の値を返し、シーケンスに対してはランダムな要素を1つ返します。`randomize`はその場で並べ替え、`sample`は重複しない要素を取り出します。

デフォルトでは、これらのワードは、システムクロックを基に種を設定して初期化されたグローバルな乱数ジェネレーターから値を取り出します。結果を再現できるようにするには、`<mersenne-twister>`（[`random.mersenne-twister`][mt]にあります）と`with-random`を使って、種を指定した乱数ジェネレーターを設定します。

```factor
USING: random random.mersenne-twister ;

42 <mersenne-twister> [ 6 random ] with-random .   ! same value every run
```

[random]: https://docs.factorcode.org/content/vocab-random.html
[mt]: https://docs.factorcode.org/content/vocab-random.mersenne-twister.html
