# はじめに

## パッケージとモジュール

### インポート

モジュールは通常、`use`キーワードで読み込みます。
これはモジュールを読み込むと同時に、その`import`メソッドを呼び出し、エクスポートされたシンボルをインポートします。

パッケージの`@EXPORT`配列にあるシンボルは、デフォルトでインポートされます。
パッケージの`@EXPORT_OK`配列にあるシンボルは、明示的にインポートする必要があります。

### エクスポート

シンボルをインポートするには、まずエクスポートされている必要があります。
[Exporter][Exporter]モジュールはPerlに標準で含まれており、エクスポートを行うための最も便利な方法の1つです。

モジュールを定義する：
```perl
package Foo;

use Exporter ('import');
our @EXPORT_OK = ('bar');

sub bar { ... }
```

モジュールを使う：
```perl
use Foo ('bar');

bar();
```

### コアモジュール

[Exporter][Exporter]に加えて、Perlにはさまざまな[コアモジュール][perl-core-modules]が用意されており、利用できます。
ここで出会う演習に役立つ例としては、[List::Util][List::Util]、[Time::Piece][Time::Piece]、[Math::BigRat][Math::BigRat]などがあります。

### CPAN

コアモジュールに加えて、[CPAN][metacpan]にはPerlコミュニティによって作られた数千もの追加モジュールが公開されており、インストールできます。
Perlトラックでは[cpanfile][test-runner-cpanfile]を使って、ExercismのPerlテストランナーで使えるモジュールをいくつかインストールしています。
