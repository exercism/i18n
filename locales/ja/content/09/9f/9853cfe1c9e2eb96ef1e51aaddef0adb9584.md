# ヒント

## 全般

- `include`はクラスの中に書きます。ふつうは最初の行です。
- 変わるのは、名前を変えたり省いたりしたものだけです。それ以外はすべて、
  もとのまま取り込まれます。

## 1. ジャズのルーティン

- クラスの中に1行だけ書きます：`include WARM_UP;`
- ほかには何も書きません。クラスの中身はその1行だけです。

## 2. タップのルーティン

- `include WARM_UP describe -> ;`
- 矢印のあとに何も書かない`-> ;`は、`describe`を省きます。こうすることで、
  自分で書く`describe`の入る場所ができます。
- これがないと、コンパイラーは`describe`が2回定義されていると文句を言います。
  そのエラーこそが狙いです。Satherは黙ってどちらか一方を選ぶことはしません。

## 3. フィナーレ

- 1つのincludeに2つの項目を、カンマで区切って書きます：
  `include WARM_UP counts -> warm_up_counts, describe -> ;`
- 次に、`warm_up_counts * 2`を返す`counts`と、`describe`を書きます。
- `describe`は`counts`を呼び出すようにします。数値を計算し直してはいけません。
- 数値に文字列を足すことはできません。ですから、言葉から始まる説明文なら
  問題ありません：`"Finale: " + counts + " counts"`。
