# 概要

入出力を扱う関数は、[`IO`モジュール][module-io]で提供されています。

- [`IO.puts/2`][io-puts]は、文字列を標準出力に書き込み、その後に改行を加えます。戻り値は`:ok`です。
- [`IO.write/2`][io-write]は、文字列を標準出力に書き込みますが、改行は加えません。戻り値は`:ok`です。
- [`IO.gets/2`][io-gets]は、標準入力から1行読み取ります。
- [`IO.inspect/2`][io-inspect]は、どんな値でも標準出力に書き込み、`:label`のような便利なオプションを受け付けます。渡された値をそのまま返します。デバッグに便利です。

## `String.Chars`プロトコル

[`IO.puts/2`][io-puts]に、出力できない値を渡そうとすると、`Protocol.UndefinedError`エラーが表示されます。

```elixir
IO.puts({:ok, 7})
# ** (Protocol.UndefinedError) protocol String.Chars not implemented for {:ok, 7} of type Tuple
```

そんなときは、代わりに[`IO.inspect/2`][io-inspect]を使うとよいでしょう。

## デバッグに便利な`IO.inspect/2`

[`IO.inspect/2`][io-inspect]は、引数をそのまま返し、どんな値でも出力でき、さらに`:label`オプションも使えるので、デバッグにぴったりです。

```elixir
"HELLO\n"
|> String.trim()
|> IO.inspect(label: "step 1")
|> String.downcase()
|> IO.inspect(label: "step 2")

# > step 1: "HELLO"
# > step 2: "hello"
# => "hello"
```

## IOデバイス

これらの関数の第1引数は[IOデバイス][io-devices]で、デフォルト値は`:stdio`（標準入出力）です。標準エラー出力に書き込むには、代わりに`:stderr`を使います。IOデバイスはプロセスでもかまいません。たとえば、[`File.open/2`][file-open]を呼び出して作成したプロセスを使えば、ファイルに書き込むこともできます。
