# 指示の補足

## 実装

この演習では、繰り返し処理できる連結リストのデータ構造を作成する必要があります。

1. `Count`プロパティを実装します。外部からその値を変更できないようにします。
2. リストの先頭に値を追加する`Push(T value)`メソッドを実装します。
3. 先頭から値を取り除いて返す`Pop()`メソッドを実装します。
4. 1つの値、またはイテラブルで初期化できるようにするコンストラクターを追加します。
5. `IEnumerable<T>`インターフェースを実装します。詳しくは、[ienumerable]を参照してください。
6. `Reverse()`メソッドが使えるようにします。

[ienumerable]: https://docs.microsoft.com/en-us/dotnet/api/system.collections.generic.ienumerable-1
