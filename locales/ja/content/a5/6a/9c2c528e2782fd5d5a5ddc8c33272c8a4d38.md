# はじめに

Factorの文字は整数、つまりUnicodeのコードポイントです。なので、数値としての`<`、`>`、`=`を使えば、大文字と小文字を区別した順序付けがそのまま得られます。`unicode`ボキャブラリーを読み込むと、Unicodeを考慮した述語や、1文字単位の大文字・小文字変換が使えるようになります。

## 文字の述語

```
LETTER?  ( c -- ? )    ! uppercase letter
letter?  ( c -- ? )    ! lowercase letter
Letter?  ( c -- ? )    ! letter, either case
digit?   ( c -- ? )    ! decimal digit
digit>   ( c -- n )    ! the integer value of a digit char
blank?   ( c -- ? )    ! whitespace
```

```factor
USING: unicode ;

CHAR: A LETTER? .    ! => t
CHAR: a letter? .    ! => t
CHAR: 7 digit?  .    ! => t
CHAR: 7 digit>  .    ! => 7
```

## 大文字と小文字の変換

`ch>upper`と`ch>lower`は、1文字を変換します。文字列レベルの`>upper`と`>lower`は、それを文字列のすべての文字に適用します。

```factor
CHAR: a ch>upper .   ! => 65   (which is CHAR: A)
"Hello" >upper .     ! => "HELLO"
```

`capitalize`は、文字列全体を小文字にしてから、最初の1文字を大文字にします。これは1語のタイトルケースです。

```factor
"hELLO" capitalize .   ! => "Hello"
```

## 文字リテラル

`CHAR: A`は、`A`のコードポイントの整数値として解釈されます。名前の付いた文字には、`space`、`tab`、`\n`などの名前を使います。

```factor
CHAR: A .        ! => 65
CHAR: space .    ! => 32
CHAR: \n .       ! => 10
```

## シンボル

ワードが値ではなくタグを返す必要があるとき、たとえば真偽値の代わりに`yes`/`no`/`maybe`を返したいときには、それぞれのタグを*シンボル*として宣言します。シンボルは、呼び出すと自分自身をスタックにプッシュするワードです。2つのシンボルは、同じ名前であるときだけ等しいと判定されます。

```factor
USING: kernel ;

SYMBOLS: yes no maybe ;

yes .    ! => yes
yes yes = .    ! => t
yes no = .     ! => f
```

`SYMBOL: name`は1つを宣言し、`SYMBOLS: a b c ;`は複数をまとめて宣言します。
