# はじめに

JavaScriptは動的な言語で、オブジェクト指向・命令型・宣言型（たとえば関数型プログラミング）といったスタイルをサポートしています。

## （再）代入

JavaScriptで名前に値を代入する方法は、主にいくつかあります。変数を使う方法と、定数を使う方法です。Exercismでは、変数は常に[camelCase][wiki-camel-case]で書き、定数は[SCREAMING_SNAKE_CASE][wiki-snake-case]で書きます。従うべき公式のガイドはなく、企業や組織によってスタイルガイドはさまざまです。_変数は好きなように書いてかまいません_。演習で用意されたとおりに書くメリットは、WebインターフェースやほとんどのIDEで違ったふうにハイライトされることです。

JavaScriptの変数は、[`const`][mdn-const]、[`let`][mdn-let]、[`var`][mdn-var]のキーワードで定義できます。

`let`や`var`を使う場合、変数はその生存期間の中でさまざまな値を参照できます。たとえば`myFirstVariable`は、代入演算子`=`を使って何度も定義や再定義ができます。

```javascript
let myFirstVariable = 1;
myFirstVariable = 'Some string';
myFirstVariable = new SomeComplexClass();
```

`let`や`var`とは対照的に、`const`で定義した変数は一度しか代入できません。JavaScriptでは、これを使って定数を定義します。

```javascript
const MY_FIRST_CONSTANT = 10;

// Cannot be re-assigned.
MY_FIRST_CONSTANT = 20;
// => TypeError: Assignment to constant variable.
```

> 💡 後の演習では、_定数_への代入や束縛と、_定数_の値がどう違うのかを掘り下げて説明します。

## 関数宣言

JavaScriptでは、機能のまとまりは_関数_にカプセル化されます。同じファイルにまとめたほうがよい関数は、たいてい1つのファイルにまとめます。関数は仮引数（引数）を受け取ることができ、`return`キーワードを使って値を_返す_ことができます。関数は括弧（`()`）を使って呼び出します。

```javascript
function add(num1, num2) {
  return num1 + num2;
}

add(1, 3);
// => 4
```

> 💡 JavaScriptには、関数を宣言する方法が_たくさん_あります。それらは`function`キーワードを使う方法とは見た目が異なります。ここでは少しずつ紹介していきますが、すでに知っている場合はどれを使ってもかまいません。ほとんどの場合、どちらを使っても良し悪しはありません。

## 他のファイルへの公開

`function`や定数、変数を_他のファイル_で使えるようにするには、`export`キーワードを使って[エクスポート][mdn-export]する必要があります。すると、別のファイルが`import`キーワードを使ってこれらを[インポート][mdn-import]できます。これはモジュールシステムとも呼ばれます。よい例が、すべてのテストの仕組みです。各演習には、少なくとも1つのファイルがあります。たとえば`lasagna.js`で、_実装_が書かれています。さらに、_テスト_が書かれた別のファイルも、少なくとも1つあります。たとえば`lasagna.spec.js`です。このファイルは、実装をテストするために公開された（つまりエクスポートされた）ものを_インポート_します。

```javascript
// file.js
export const MY_VALUE = 10;

export function add(num1, num2) {
  return num1 + num2;
}

// file.spec.js
import { MY_VALUE, add } from './file';

add(MY_VALUE, 5);
// => 15
```
