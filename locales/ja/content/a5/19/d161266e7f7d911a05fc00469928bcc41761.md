# 説明

あなたは、カメ用のキルトを作る会社に、アシスタント生産エンジニアとして雇われました。

注文は一日中、顧客の名前または番号と、注文数量という形で届きます。
それらは朝、その日の生産が始まる前に処理されます。

その日の注文がすべてさばけたら、給料は満額のまますぐに帰宅できます。そのため、作業時間をできるだけ短くしたいという動機が生まれます。
各注文は1台の機械で処理されるので、大きな注文から先にスケジュールすると、仕事を始めるためのオーバーヘッドを小さな注文に押し付けられ、全体の生産時間を短くできます。
そこで、このスケジュールを速めるための並べ替え関数をいくつか用意することにしました。そうすれば早く帰宅して、カメのためにセーターを編めます。

## 1. 数量をソートしよう！

すでに述べたように、数量の配列は大きい順にソートする必要があります。
これらの配列は大きくなる可能性があるため、*インプレース*でソートする必要があります。
すべてを正しく管理するには、数量に合わせて顧客の配列もソートできる必要があります。そのため、数量のソート順列が必要になります。

`Integer`の数量の`Vector`を受け取る、`sortquantity!(qty)`という関数を書いてください。
この関数は、入力`qty`をインプレースで降順にソートし、この並び順のソート順列を返します。

```julia-repl
julia> qty = [8, 9, 5, 6]
4-element Vector{Int64}:
 8
 9
 5
 6

julia> sortquantity!(qty)
4-element Vector{Int64}:
 2
 1
 4
 3

julia> qty # original vector is sorted in-place
4-element Vector{Int64}:
 9
 8
 6
 5
```

## 2. 顧客をソートしよう

前述のとおり、顧客を決まった順序で管理する必要があります。

顧客の`Vector`である`cust`と、ソート順列の`Vector`である`srtperm`を受け取る、`sortcustomer(cust, srtperm)`という関数を書いてください。
この関数は、ソート順列で指定された順序で顧客を並べた新しい配列を返します。

```julia-repl
julia> cust = ["a", "b", "c"]
3-element Vector{String}:
 "a"
 "b"
 "c"

julia> sortcustomer(cust, [2, 3, 1])
3-element Vector{String}:
 "b"
 "c"
 "a"

julia> cust # original vector remains unsorted
3-element Vector{String}:
 "a"
 "b"
 "c"
```

## 3. 生産スケジュール！

これで、すべてを組み合わせて、あのカメたちを暖かくしてあげられます！
これで数量と顧客を正しくソートできますが、発送のために元の並び順を取り戻せる必要もあります。
これは逆ソート順列を使えばできます。

顧客の`Vector`と数量の`Vector`を受け取る、`production_schedule!(cust, qty)`という関数を書いてください。
この関数は、数量をインプレースで降順にソートします。
数量と同じ順序でソートされた顧客の新しい`Vector`と、ソートされたベクトルを元の並び順に戻すのに使える*逆*ソート順列を返します。

```julia-repl
julia> cust, qty = ["a", "b", "c"], [2, 3, 1]
(["a", "b", "c"], [2, 3, 1])

julia> orderedcust, invperm = production_schedule!(cust, qty)
(["b", "a", "c"], [2, 1, 3])

julia> qty # has been sorted in-place
3-element Vector{Int64}:
 3
 2
 1

julia> orderedcust[invperm], qty[invperm] # inverse permutation gives original ordering
(["a", "b", "c"], [2, 3, 1])
```
