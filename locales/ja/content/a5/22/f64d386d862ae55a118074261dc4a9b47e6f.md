# テスト

## Exercism GDScriptトラックのテストランナーをインストールする

テストランナーを使うには、[Godotを正しくインストール][installation]しておく必要があります。

ExercismでGDScriptのスクリプトをビルドしてテストするには、GodotをCLIから「ヘッドレス」モードで実行します。
現在のところ、この手順にはLinuxとbashが必要です。

### ステップ1：テストランナー全体のインフラをインストールする

テストの準備として、[https://github.com/exercism/gdscript-test-runner][gdscript-test-runner]をクローンし、その中身を`/opt/test-runner/`に移動します：

```sh
git clone https://github.com/exercism/gdscript-test-runner.git
sudo mkdir -p /opt/
sudo mv gdscript-test-runner/ /opt/test-runner/
```

### ステップ2：単一演習用のテストランナースクリプトをダウンロードする

`exercism`ツールをセットアップして、GDScriptの演習を少なくとも1つダウンロードしていれば、演習を入れるための`exercism/gdscript`フォルダーが作成されているはずです。
[テストランナー][test-local-gdscript-solution]をこのフォルダーに保存し、ファイルに実行権限を付けるか、単にリンクを作成します：

```sh
cd ~/exercism/gdscript # replace with your exercism/gdscript directory
ln /opt/test-runner/bin/test-local-gdscript-solution.sh
```

## テストを実行する

インストールの手順が終わったら、どの演習のディレクトリ（例：`~/exercism/gdscript/two-fer`）からでも、スクリプト（1つ上の階層、`../`にあります）を実行して、その演習に対するローカルの解答をテストできるはずです：

```sh
../test-local-gdscript-solution.sh
```

[gdscript-test-runner]: https://github.com/exercism/gdscript-test-runner
