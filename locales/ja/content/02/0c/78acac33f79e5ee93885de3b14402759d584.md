# ビット操作

Crystalには、[`Int`][ints]をバイナリレベルで操作するためのビット演算子があります。

## シフト演算子

Crystalには、ビットを左（`<<`）または右（`>>`）にシフトする[シフト演算子][shift]があります。

### 左シフト（`<<`）

左シフト演算子（`<<`）は、ビットを左にシフトします。
シフトする値は左側に、シフトする桁数は右側に指定します。

```crystal
0b0010 << 1
# => 0b0100

0b0010 << 2
# => 0b1000
```

数値が負の場合、代わりに右にシフトします。

```crystal
0b0010 << -1
# => 0b0001
```

### 右シフト（`>>`）

右シフト演算子（`>>`）は、ビットを右にシフトします。
左シフト演算子と同様に、シフトする値は左側に、シフトする桁数は右側に指定します。

```crystal
0b0100 >> 1
# => 0b0010

0b0100 >> 2
# => 0b0001
```

同じように、数値が負の場合、演算子は左にシフトします。

```crystal
0b0100 >> -1
# => 0b1000
```

## 二項演算子

Crystalには、ビット単位の演算を行うための3つの[二項演算子][binary]（`&`、`|`、`^`）と、`~`演算子があります。

### ビット単位のAND（`&`）

二項AND演算子（`&`）は、2つの値に対してビット単位のANDを実行します。
1つ目の値の各ビットを、2つ目の値の同じ位置にあるビットと比較します。
両方のビットが1であれば、結果のビットは1になります。
それ以外の場合は0になります。

```crystal
0b0011 & 0b1010
# => 0b0010
```

### ビット単位のOR（`|`）

二項OR演算子（`|`）は、2つの値に対してビット単位のORを実行します。
これも、1つ目の値の各ビットを、2つ目の値の同じ位置にあるビットと比較します。
どちらかのビットが1であれば、結果のビットは1になります。
それ以外の場合は0になります。

```crystal
0b0011 | 0b1010
# => 0b1011
```

### ビット単位のXOR（`^`）

二項XOR演算子（`^`）は、ビット単位のXORを実行します。
ビット単位のAND演算子やビット単位のOR演算子と同様に、1つ目の値の各ビットを、2つ目の値の同じ位置にあるビットと比較します。
それらのうち_1つだけ_が1であれば、結果のビットは1になります。
それ以外の場合は0です。

```crystal
0b0011 ^ 0b1010
# => 0b1001
```

### ビット単位のNOT（`~`）

最後に、ビット単位のNOT演算子（`~`）は、値の各ビットを反転させます。
他の二項演算子とは異なり、これは単項演算子で、右側の値だけを対象に操作します。

```crystal
~0b1110_0010
# => 0b0001_1101
```
