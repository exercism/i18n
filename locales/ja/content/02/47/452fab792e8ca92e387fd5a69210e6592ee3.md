# はじめに

配列とリストは、スカラーの順序付きコレクションです。リファレンスを使う場合を除けば（これは別の概念で扱います）、配列とリストは常にフラットです。つまり、他の配列やリストを含むことはできません。

ほとんどの場合、リストは括弧（`()`）で囲み、要素はカンマ（`,`）で区切ります。

配列の変数には、通常、リストを代入して値を入れます。たとえば、`my @names = ('Alice', 'Bob', 'Charlie');`のようになります。

配列やリストの要素には、インデックスを指定するとアクセスできます。たとえば、`('Alice', 'Bob', 'Charlie')[1] # 'Bob'`のようになります。

Perlのインデックスは`0`から始まります。負のインデックスは、配列やリストの末尾から数えます。たとえば、`('Alice', 'Bob', 'Charlie')[-1] # 'Charlie'`のようになります。

## 関数

配列やリストを操作するための関数は数多くあります。とくに便利なのは、条件に一致する要素を絞り込んだ新しいリストを作る[grep][grep]、要素を変換して新しいリストを作る[map][map]、要素を並べ替えた新しいリストを作る[sort][sort]です。

配列を操作する関数には、末尾に要素を追加する[push][push]、最後の要素を削除する[pop][pop]、最初の要素を削除する[shift][shift]、先頭に要素を追加する[unshift][unshift]、より複雑な変更を行う[splice][splice]などがあります。

[for(each)][perlsynforeach]文で配列やリストを繰り返し処理する場面も、よくあるはずです。

## シジルによる違い

配列の要素にアクセスするとき、結果を決めるのは使うシジルです。変数名の末尾にある`[]`が、その名前の配列にアクセスしていることをPerlに伝えます。

```perl
my @names = ('Alice', 'Bob', 'Charlie');

$names[0]; # 'Alice'      <- A scalar
@names[0]; # ('Alice')    <- A slice (with only one index, this probably isn't what you want. There will be a warning.)
%names[0]; # (0, 'Alice') <- A key/index + value slice

$names[1, 2]; # 'Charlie'                <- A scalar (via unsupported syntax for an ancient feature. Probably not what you want. There will be a warning.)
@names[1, 2]; # ('Bob', 'Charlie')       <- A slice
%names[1, 2]; # (1, 'Bob', 2, 'Charlie') <- A key/index + value slice
```

許されてはいますが、読みやすさのために、異なる型の変数で同じ名前を共有することはおすすめしません。

## 配列とリスト

配列とリストには多くの共通点があり、多くの場面で同じように使えますが、両者は同じものではありません。リストは、固定された変更不可能なスカラーのコレクションです。配列は、中身と配列自体のサイズを変えられる、可変のスカラーのコレクションです。

状況によっては、両者の動作は異なります。スカラーコンテキストで使った配列は、配列のサイズを返します。スカラーコンテキストで使ったリストは、リストの最後の要素を返し、さらに残りの内容が無効コンテキストで使われているという警告が出ることもあります。

```perl
my @names = ('Alice', 'Bob', 'Charlie');

scalar @names; # 3
scalar ('Alice', 'Bob', 'Charlie'); # 'Charlie' (and some warnings).
```
