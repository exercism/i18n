# はじめに

Elixirのタプルは、データをまとめるデータ構造です。任意の型の要素を決まった数だけ保持しますが、それぞれの要素に名前はありません。タプルは、要素の読み取りが定数時間で済むため、メモリからの読み取りが多い処理でよく使われます。一方、要素を動的に追加したり削除したりする必要がある場合には、通常は使いません。既存のタプルを変更するのではなく新しいタプルを作成することになり、そのためのメモリを事前に確保しなければならないからです。

実際には、タプルは波括弧（`{}`）を使って作成します。タプルの要素には、`elem/2`関数と0から始まるインデックスを使って、1つずつアクセスできます。

```elixir
empty_tuple = {}
one_element_tuple = {1}
multiple_element_tuple = {1, :a, "hello"}

elem(multiple_element_tuple, 2)
# => "hello"
```

## まとまった情報としてのタプル

実際のコードでは、タプルはまとまった情報を表すのによく使われます。

```elixir
Float.ratio(0.25)
# => {1, 4} indicating the numerator and denominator of the fraction ¼
```
