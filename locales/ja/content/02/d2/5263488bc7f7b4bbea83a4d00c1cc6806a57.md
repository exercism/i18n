# 概要

[`switch`文][switch]を使うと、1つの値を複数の候補と照らし合わせて比較できます。複数の`else-if`文を使うよりも簡潔にコードを書けます。`switch`文は、`switch`キーワードで始まり、そのあとに比較する値を書きます。次に、`case`キーワードのあとに比較対象の値を書いて、各ケースを定義します。どのケースにも一致しなかったときの既定のケースは、`default`キーワードで定義します。`else-if`文と同じく、`switch`文が実行するのは、最初に一致したケースに対応するコードのブロックだけです。

```swift
switch value {
case 1:
    print("One")
case 2:
    print("Two")
default:
    print("Other")
}
```

次の例を見てみましょう。

```swift
if str == "apple" {
    print("Let's bake an apple crumble")
} else if str == "lemon" {
    print("Let's bake a lemon meringue pie!")
} else if str == "peach" {
    print("Let's bake a peach pie!")
} else {
    print("Let's buy ice cream.")
}
```

これは、次のように書き換えられます。

```swift
switch str {
case "apple":
    print("Let's bake an apple crumble")
case "lemon":
    print("Let's bake a lemon meringue pie!")
case "peach":
    print("Let's bake a peach pie!")
default:
    print("Let's buy ice cream.")
}
```

## バインディングと`where`節

`switch`文で照合する値には、名前を付けることもできます。その名前はケースの本体で使えます。また、`where`節でも使えます。`where`節は追加の真偽値の式で、ケースが一致するには`true`と評価される必要があります。

```swift
let x = 1337
switch sumOfDivisors(of: x) {
case let total where total == x:
  print(total, "is a perfect number")
default:
  print(x, "is not a perfect number")
}
```
