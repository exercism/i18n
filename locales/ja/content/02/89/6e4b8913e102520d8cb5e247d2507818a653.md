# ヒント

## 1. すべての貨車のベクターを作成する

- `push!`で`Vector`に追加していく、古典的なfor/whileループでも動きます。
- あるいは、[`collect()`][collect]関数を使うともっと簡潔に書けます。
- スプラット展開は、ベクターのコンストラクターの中でも使えます。

```julia-repl
julia> input = (1, 5, 9)
(1, 5, 9)

julia> [input...]
3-element Vector{Int64}:
 1
 5
 9
```

## 2. 貨車のベクターを修正する

- 先頭の貨車と機関車をそれ以外の部分から分けておくと、正しい順序で組み立て直すのに役立ちます。
- スプラット展開を使った多重代入が助けになるかもしれません（導入を参照してください）。

## 3. 不足している停車駅を追加する

- この関数は入力を変更しないことを忘れないでください。新しい`Dict`を作ります。
- 必要なのは停車駅の名前だけで、停車駅の番号は不要なので、各ペアを分割する必要があります。
- 名前のベクターを組み立てる方法はいくつかあります。
  -  `push!()`で`Vector`に追加するFor/Whileループ。
  -  配列の[内包表記][comprehensions]
  -  ベクターに対して関数を[`map()`][map]する。
  -  [無名関数][anonymous]の[ブロードキャスト][broadcasting]も可能です。

 ```julia-repl
julia> (x -> x^4).([1, 2, 3]) == [1, 16, 81]
true
 ```

## 4. 経路情報を拡張する

- スプラット展開したあと、`more_route_information`は`Pairs()`コレクションになります。
- [`merge()`][merge]関数は2つ以上の`Dict`を結合しますが、`Pairs()`コレクションも受け付けます。
  `Pairs()`コレクションから`Dict`への明示的な変換は可能ですが、必要ありません。
