# 概要

[Python][python docs]は、[動的で強い][dynamic typing in python]型付けを持つ[オブジェクト指向][object oriented programming]プログラミング言語です。
[ダックタイピング][duck typing]と[漸進的型付け][gradual typing]（[型ヒント][type hints]による）の両方を取り入れています。
命令型（_オブジェクト指向、手続き型_）や宣言型（_関数型、並行_）など、複数のプログラミングパラダイムをサポートしています。
ただし、騙されてはいけません。パラダイムをまたいだプログラミングは全面的にサポートされていますが、[Pythonではすべてがオブジェクトです][everythings an object]。


PythonはGuido van Rossumによって作られ、1991年に最初にリリースされました。
[Python Software Foundation][psf]は、PythonとCPythonの開発のためのリソースを管理・指揮し、コミュニティの[メンバー][psf membership]から[Python Enhancement Proposals (PEPs)][peps]を通じて言語への変更提案を受け取っています。
[これから学び始める][python for beginners]プログラマーにとって頼もしい言語とされており、温かく迎え入れてくれるコミュニティがあり、あらゆるレベルや興味を持つ学習者が利用できる多くのリソースもそろっています。


Pythonはコードの読みやすさを何より重視しており、（_Haskellと同様に_）関数・メソッド・クラスの定義を示すために[意味のあるインデント][significant indentation]を使います。
コードは、コマンドラインや対話型のインタプリターセッション、[JupyterLab][jupyter]（Jupyter Notebooks）、あるいはさまざまな[コードエディターやIDE][editors for python]で書いて実行できます。

[Pythonは幅広く使われており][python is used extensively]、科学技術計算、金融、ゲーム、ネットワーキング、インターネット開発、そして他のプログラムをつなぐパイプラインの構築などで活躍しています。


[Pythonの禅（PEP 20）][the zen of python]と[What is Pythonic?][what is pythonic]では、この言語に関するさらなる哲学と視点が示されています。


このトラックのテストとツールは現在、`Python 3.10 - 3.13.7`（_テスト_）と[`Python 3.13.7`][313-new-features]（_ツール_）をサポートしています。
このトラックで使われている一部の機能は、それより前のバージョンではサポートされていない可能性があるため、学習者は少なくとも`Python 3.10`にアップグレードすることを強くおすすめします。
とはいえ、ほとんどの演習は`Python 3.6+`、あるいはそれより前のバージョンでも動作します。
ただし、[Active Python Releases][active-python-releases]に記載されていないバージョンのサポートは保証していません。
ある機能が特定のバージョンでのみ利用できる場合は、その旨を記すようにします。
