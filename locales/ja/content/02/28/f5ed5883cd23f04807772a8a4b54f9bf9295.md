# データベースの支払いバッチ

## 問題

支払いデータのバッチを`Payment`テーブルに挿入します。与えられた入力JSONファイルから支払いデータを読み取り、JDBCクライアントの`batchExecute`操作を使って、その支払いデータを`Payment`テーブルに挿入してください。サンプルの入力ファイルは`payments.json`として用意されています。

入力JSONファイルの内容は、次のJSONスキーマに基づいています。

```json
{
  "type": "array",
  "items": [
    {
      "type": "object",
      "properties": {
        "employee_id": {
          "type": "integer"
        },
        "amount": {
          "type": "number"
        },
        "reason": {
          "type": "string"
        },
        "date": {
          "type": "string"
        }
      },
      "required": [
        "employee_id",
        "amount",
        "reason",
        "date"
      ]
    }
  ]
}

```

データベースに再度クエリを発行することなく、バッチで挿入した支払いデータに対して自動生成された支払いIDを、出力として返す必要があります。

`payments.json`ファイルに書かれている`employee_id`は有効で、すでに`Employee`テーブルに含まれていると考えてかまいません。

## データベースの詳細

この問題では、用意されたH2データベースを使います。

> サンプルのデータベースファイルは`gofigure.mv.db`で、データベース名は`gofigure`です。`db`フォルダーの中にあります。

サンプルのH2データベースには、次のテーブルがいくつかのサンプルデータとともにすでに用意されています。カラム名とデータ型は以下のとおりです。

**テーブル名**：`Employee`

| **カラム:**      | 型 |
| -----------       | ----------- |
| `employee_id`     | 整数、自動インクリメントの主キー       |
| `name`            | 文字列        |
| `city`            | 文字列        |
| `department`      | 文字列        |
| `age`             | 整数        |

**テーブル名**：`Payment`

| **カラム:**      | 型 |
| -----------       | ----------- |
| `payment_id`      | 整数、自動インクリメントの主キー       |
| `date`            | 日付        |
| `amount`          | 小数        |
| `employee_id`     | 整数        |
| `reason`          | 文字列        |

* データベースファイルは`gofigure.mv.db`です。JDBC URLは`jdbc:h2:file:/path/to/db/file`のように指定します。
* ユーザー名：`root`
* パスワード：`root`

## 制約

* クエリとBallerinaのサンプルを検証するには、`db`フォルダーにあるH2データベースファイルを使います。
* Ballerina.tomlにH2データベースドライバーをプラットフォーム依存として追加するには、Mavenの依存関係パラメータを使う方法を使います。
* データベースに再度クエリを発行せずに、自動生成された支払いIDを取得する必要があります。

## テスト環境

* テストは`bal test`で実行できます。用意されたサンプルDBに対してテストが実行されます。

## 例

### 例1

**入力:** dbFilePath: `"/path/to/file/gofigure"`, paymentFilePath: `"/path/to/file/payments.json"`

サンプルの`payments.json`ファイルのデータ：

```json
[{
        "employee_id": 4,
        "amount": 12500.50,
        "reason": "Fuel for the month January",
        "date": "2022-02-03"
    },
    {
        "employee_id": 1,
        "amount": 10500.50,
        "reason": "Medical Expenses for the month January",
        "date": "2022-02-04"
    },
    {
        "employee_id": 4,
        "amount": 500.50,
        "reason": "Fuel for the month February",
        "date": "2022-03-03"
    }
]

```

**出力:** `[1,2,3]`

## ヒント

* データベースを操作するには、[ballerinax/java.jdbc](https://central.ballerina.io/ballerinax/java.jdbc)モジュールを使います。
* JDBCドライバーを依存関係として追加する手順については、[Prerequisite](https://lib.ballerina.io/ballerinax/java.jdbc/latest)のセクションを参照してください。
* JSONの入力ファイルを読み取るには、[io:fileReadJson](https://lib.ballerina.io/ballerina/io/latest/functions#fileReadJson)を使います。
* 型安全にデータを扱うために、JSONの値をアプリケーション固有の型に変換します。例については、[Converting to user defined type](https://ballerina.io/learn/by-example/convert-from-json-to-user-defined-type/)を参照してください。
* データベースを操作するには、[sql:ParameterizedQuery](https://lib.ballerina.io/ballerina/sql/latest#ParameterizedQuery)と[batchExecute](https://lib.ballerina.io/ballerinax/java.jdbc/latest#Client-batchExecute)リモートメソッドを使います。
* [batch execute](https://ballerina.io/learn/by-example/mysql-batch-execute-operation/)の例を参照してください。
