最初の解答例のほうが好みです。その簡潔さが、私がこれまでに見てきた慣用的なRustの書き方に沿っているからです。また、標準解答で加えられているクロージャの概念を避けることもできます。

  - 余り

## 解答例1

["desi-belokonska"](https://exercism.org/tracks/rust/exercises/leap/solutions/01d024321b6a491690321844aedf8b09)さんの解答

```rust
pub fn is_leap_year(year: u64) -> bool {
  year % 400 == 0 || year % 4 == 0 && year % 100 != 0
}
```

## 解答例2

[標準解答](https://github.com/exercism/rust/blob/master/exercises/leap/example.rs)

```rust
pub fn is_leap_year(year: u64) -> bool {
    let has_factor = |n| year % n == 0;
    has_factor(4) && (!has_factor(100) || has_factor(400))
}
```
