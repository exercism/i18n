# はじめに

## 数値

Luaでは、数値を64ビット整数と倍精度浮動小数点数の2つの形式で表します。一般的な算術演算子である、加法、減法、乗法、除法、符号反転をサポートしています。さらに、切り捨て除算、余り、べき乗も使えます。

| 演算子 | 例                  |
| ------ | ------------------- |
| `+`    | `1 + 2 --> 3`       |
| `-`    | `2 - 1 --> 1`       |
| `*`    | `2 * 2 --> 4`       |
| `/`    | `4 / 2 --> 2.0`     |
| `//`   | `11 // 3 --> 3`     |
| `%`    | `11 % 3 --> 2`      |
| `^`    | `10 ^ 2 --> 100.0`  |
| `-`    | `-(2 * 2) --> -4`   |
