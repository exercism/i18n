# はじめに

`while`ループを使うと、ある条件が満たされている間、コードを繰り返し実行できます。`while`ループは、`while`キーワードのあとに、丸括弧（`()`）で囲んだ条件と、波括弧（`{}`）で囲んだループの*本体*を含むブロックを続けて書きます。

```javascript
while (condition) {
  // code that is executed repeatedly as long as the condition is true
}
```

JavaScriptには、`do-while`ループもあります。`do-while`ループでは、ループの本体を実行したあとに条件をチェックします。条件がループ本体で実行されるコードの結果によって決まるときに便利です。

```javascript
do {
  // The code here will always be executed once and then
  // repeatedly while the condition is true.
} while (condition);
```

ループの本体の中では、`break`キーワードを使ってループの実行を完全に止めることができます。これに対して、`continue`キーワードは、現在の繰り返しの実行だけを止め、次の繰り返しへと進みます。`continue`を使うと、ループの本体の大部分を`if`文で囲まずに済むことがよくあります。

```javascript
let i = 0;

while (i < 100) {
  i = i + 2;

  if (i % 3 === 0) {
    continue;
  }

  // The code here will only be executed when i was not divisible
  // by 3 in the check above.
}
```
