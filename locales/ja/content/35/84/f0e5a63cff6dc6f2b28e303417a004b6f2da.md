# 説明

この演習の舞台はバレンタインデーです。パートナーと一緒に何か素敵なことをしようと計画しています。パートナーはたくさんのアイデアを持っていて、どの活動をするかを決めるために、それらのアイデアを評価してほしいと頼んできました。

パートナーからは、次のようなアイデアが出ています。

- ボードゲームで遊ぶ
- のんびり過ごす
- 映画を見る
- レストランに行く

バレンタインデーの活動を選ぶための、6つのタスクがあります。

## 1. 承認を定義する

パートナーが提案するそれぞれのアイデアに対して、はい・いいえ・たぶんの3つのうちのどれかで答えます。

これらの選択肢を表す`Approval`カスタム型を、次の3つのケースとして定義してください：`Yes`、`No`、`Maybe`。

## 2. 料理を定義する

パートナーは2つのレストランを候補に挙げています。1つは韓国料理、もう1つはトルコ料理です。

これらの料理を表す`Cuisine`カスタム型を、次の2つのケースとして定義してください：`Korean`、`Turkish`。

## 3. 映画のジャンルを定義する

選べる映画はたくさんあるので、絞り込むために、パートナーはジャンルも挙げています。

次のジャンルをケースとして表す`Genre`カスタム型を定義してください：`Crime`、`Horror`、`Romance`、`Thriller`。

## 4. 活動を定義する

先ほど述べたように、パートナーは5つの活動を思いついています。ボードゲームで遊ぶ、のんびり過ごす、映画を見る、レストランに行く、です。

これらの活動の種類を表す`Activity`カスタム型を定義してください：

- `BoardGame`：関連するデータはありません。
- `Chill`：関連するデータはありません。
- `Movie`：`Genre`を関連データとして持ちます。
- `Restaurant`：`Cuisine`を関連データとして持ちます。

## 5. 活動を評価する

最後に、パートナーのアイデアを評価する準備ができました。パートナーのアイデアに対する気持ちは次のとおりです。

- ボードゲームで遊ぶ：いいえ。
- のんびり過ごす：いいえ。
- 映画を見る：ロマンス映画なら「はい」、それ以外は「いいえ」。
- レストランに行く：韓国料理なら「はい」、トルコ料理なら「たぶん」。

`Activity`の値を受け取り、上記の気持ちに基づいて`Approval`を返す`rateActivity`という関数を実装してください：

```elm
rateActivity (Restaurant Turkish)
-- => Maybe
```
