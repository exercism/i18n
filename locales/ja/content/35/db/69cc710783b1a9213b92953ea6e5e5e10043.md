# gofmtが使われていません

解答に対して`gofmt`を実行しましょう。`gofmt`はGoのコードのフォーマットを整えるのに役立ちます。

Goのコミュニティーでは、コードのフォーマットがとても重視されています。
ほとんどのIDEは、保存するたびにコードを自動でフォーマットするように設定できます。たとえば、次のとおりです。

- Visual Studio Codeには[優れたGoサポート](https://code.visualstudio.com/docs/languages/go)があります
- Vimにも[すばらしいGo拡張機能](https://github.com/fatih/vim-go)があります
- [Jetbrains Goland](https://www.jetbrains.com/go/)は、GoのためのIDEそのものです

`gofmt`を手動で実行するには、次のようにします。

```bash
# will only show the differences
gofmt -d filename.go

# will apply the changes
gofmt -w filename.go
```

```git
%{gofmt}
```
