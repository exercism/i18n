# 説明

この演習では、高校時代から付き合っている恋人同士がSNSで愛を告白するのを手伝います。

## 1. カップルの名前をハートで区切って表示する

2つの名前を受け取り、ハートで区切って表示する静的メソッド`HighSchoolSweethearts.DisplaySingleLine()`を実装してください。
整形されたテキストは幅61文字で、文字列の中央にハートが来るようにします。

名前はすべて、この行の幅に余裕をもって収まることが保証されています。

```csharp
HighSchoolSweethearts.DisplaySingleLine("Lance Green", "Pat Riley");
// => "                  Lance Green ♡ Pat Riley                    "
```

## 2. カップルのイニシャルをアスキーアートのハートで表示する

2組のイニシャルをプラス記号で区切って表示する静的メソッド`HighSchoolSweethearts.DisplayBanner()`を実装してください。

```csharp
HighSchoolSweethearts.DisplayBanner("L. G.", "P. R.");
// see the ascii art below
```

## 3. ドイツからの交換留学生が、ロケールに合わせた書式でくつろげるようにしましょう

付き合い始めた日と、付き合ってきた時間の長さを、ドイツからの交換留学生向けに表示する静的メソッド`HighSchoolSweethearts.DisplayGermanExchangeStudents()`を実装してください。

```csharp
HighSchoolSweethearts.DisplayGermanExchangeStudents("Norbert", "Heidi", new DateTime(2019, 1, 22), 1535.22f);
// => "Norbert and Heidi have been dating since 22.01.2019 - that's 1.535,22 hours"
```
