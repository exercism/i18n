# Babashkaのテキストエディター連携

## nREPL

### Emacs: [CIDER](https://cider.mx/)

これがすべての始まりとなったツールで、その[Orchard](https://metaredux.com/posts/2018/11/09/ciders-orchard-the-heart.html)エコシステムが他の多くのプラグインを支えています。

1. お使いのプラットフォーム用の[Emacs](https://www.gnu.org/software/emacs/download.html)をインストールします。

2. 既存のEmacsディストリビューション（[Prelude](https://prelude.emacsredux.com/)、[Spacemacs](https://www.spacemacs.org/)、[Doom Emacs](https://github.com/hlissner/doom-emacs)はいずれも優れています）を選ぶか、以下を`init.el`に追加します:

```elisp
(unless (package-installed-p 'cider)
  (package-install 'cider))
  
(add-hook 'clojure-mode-hook #'cider-mode)
```

[CIDERのドキュメント](https://docs.cider.mx/cider/platforms/babashka.html)からの要約です:

プロジェクトのディレクトリでnREPLサーバーを起動します:

```bash
$ bb --nrepl-server
```

`C-x C-f`で任意のClojureファイル（`.clj`）を作成または開き、`C-c C-x c j`（cider-connect-clj）で接続します。

[CIDERの基本的なキーバインド](https://docs.cider.mx/cider/usage/cider_mode.html#key-reference):

* `cider-load-buffer` - `C-c C-k`
* `cider-eval-last-sexp` - `C-x C-e` または `C-c C-e`
* `cider-eval-defun-at-point` - `C-M-x` または `C-c C-c`

### VSCode: [Calva](https://github.com/BetterThanTomorrow/calva)

1. [VSCode](https://code.visualstudio.com/)をインストールします。

2. [Calva](https://marketplace.visualstudio.com/items?itemName=betterthantomorrow.calva)をインストールします。

現在、Calvaはソースコードをフォルダー、つまりClojureプロジェクトの文脈にあるものとして認識します。プロジェクトを作る手軽な方法は[clj-new](https://github.com/seancorfield/clj-new)を使うことです:

```bash
$ clj -A:new lib myorg/bbtest
Generating a project called bbtest based on the 'lib' template.
The lib template is intended for library projects, not applications.
```
3. プロジェクトのディレクトリでnREPLサーバーを起動します:

```bash
$ cd bbtest
bbtest$ bb --nrepl-server 1667
Started nREPL server at localhost:1667
For more info visit https://github.com/borkdude/babashka/blob/master/doc/repl.md#nrepl.
```

VSCodeでプロジェクトフォルダーを開く（Ctrl+K Ctrl+O）か、別のターミナルから開きます:

```bash
$ cd bbtest
bbtest$ code .
```

4. VSCodeでCalvaのコマンド`Connect to a running REPL`（ctrl+alt+c ctrl+alt+c）を実行します。プロンプトが表示されたら`Generic`プロジェクトを選び、`localhost:1667`を入力します。

REPLのコマンド:

* `Load Current File and Dependencies` ctrl+alt+c enter
* `Evaluate Current Form Inline` ctrl+alt+c e
* `Evaluate Current Top Level Form (defun)` ctrl+alt+c space

### IntelliJ: [Cursive](https://cursive-ide.com/)

1. [こちら](https://www.jetbrains.com/idea/download/index.html)からIntelliJをダウンロードします。
2. [ユーザーガイド](https://cursive-ide.com/userguide/)に従ってCursiveをインストールし、[depsを設定](https://cursive-ide.com/userguide/deps.html)します。
3. 詳しくは[Cursive: Working with Babashka](https://cursive-ide.com/userguide/babashka.html)を参照してください。

## ソケットREPL

### Atom: [chlorine](https://github.com/mauricioszabo/atom-chlorine)

1. [atom](https://flight-manual.atom.io/getting-started/sections/installing-atom/)をインストールします

2. `chlorine`パッケージをインストールします

3. ソケットREPLを起動します:

 ```
$ bb --socket-repl 1666
Babashka socket REPL started at localhost:1666
 ```

4. Atomのコマンドパレットを開き（ctrl+shift+p）、コマンド`Connect Clojure Socket REPL`を`localhost` `1666`で実行します

5. `Edit`メニュー -> `Keymap...`からkeymap.csonのキーバインドを編集します:

```
'atom-text-editor[data-grammar="source clojure"]':
  'ctrl-; y':       'chlorine:connect-clojure-socket-repl'
  'ctrl-; e':       'chlorine:disconnect'
  'ctrl-; k':       'chlorine:clear-console'
  'ctrl-shift-enter':       'chlorine:load-file'
  'ctrl-enter':       'chlorine:evaluate-block'
  'shift-enter':       'chlorine:evaluate-top-block'
  'ctrl-; i':       'chlorine:inspect-block'
  'ctrl-; I':       'chlorine:inspect-top-block'
  'ctrl-; s':       'chlorine:evaluate-selection'
  'ctrl-; c':       'chlorine:break-evaluation'
  'ctrl-; S':       'chlorine:source-for-var'
  'ctrl-; d':       'chlorine:doc-for-var'
  'ctrl-; x':       'chlorine:run-tests-in-ns'
  'ctrl-; t':       'chlorine:run-test-for-var'
```

### Emacs: [inf-clojure](https://github.com/clojure-emacs/inf-clojure)

Emacsでは、以下を`init.el`に追加して[inf-clojure](https://github.com/clojure-emacs/inf-clojure)をインストールします:

```
(unless (package-installed-p 'inf-clojure)
  (package-refresh-contents)
  (package-install 'inf-clojure))

(add-hook 'clojure-mode-hook #'inf-clojure-minor-mode)
```

上記と同じようにソケットREPLを起動し、Emacsで`M-x inf-clojure-connect`（C-c M-c）を実行します。

フォームはC-c C-eで評価します。inf-clojure-mode（別名REPL）とinf-clojure-minor-modeで利用できるすべてのコマンドの一覧は、C-h f RET inf-clojure-modeとC-h f RET inf-clojure-minor-modeを実行するか、それぞれのメニューを参照すれば確認できます。

### Vim: [vim-iced](https://github.com/liquidz/vim-iced)

[Neovim appimage](https://github.com/neovim/neovim/releases/download/v0.4.3/nvim.appimage)をダウンロードし、`vim`にエイリアスを設定します。

* [vim-plug](https://github.com/junegunn/vim-plug)をインストールします:

```
$ curl -fLo ~/.local/share/nvim/site/autoload/plug.vim --create-dirs \
    https://raw.githubusercontent.com/junegunn/vim-plug/master/plug.vim
```

`~/.config/nvim/init.vim`を作成します:

```
call plug#begin('~/.vim/plugged')

Plug 'liuchengxu/vim-clap'
Plug 'guns/vim-sexp',    {'for': 'clojure'}
Plug 'liquidz/vim-iced', {'for': 'clojure'}

call plug#end()

" Enable vim-iced's default key mapping
" This is recommended for newbies
let g:iced_enable_default_key_mappings = v:true
```

Neovimを開き、コマンド`:PlugInstall`を実行します。

`iced`コマンドを$PATHに追加します:

`$ export PATH=$PATH:~/.vim/plugged/vim-iced/bin`

* ソケットREPLサーバーを起動し、ソースファイルを開いて`:IcedConnectSocketRepl 1666`を実行します。

デフォルトのREPLコマンド（デフォルトの`<Leader>`は`\`）:

- `<Leader>ei` : 内側の要素を評価
- `<Leader>ee` : 外側のリストを評価
- `<Leader>et` : 外側のトップリストを評価
