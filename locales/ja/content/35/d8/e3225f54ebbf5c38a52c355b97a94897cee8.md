# はじめに

この演習では、メソッドの仮引数の詳細と、C#でのその使われ方について説明します。

仮引数は、呼び出す側のメソッドから呼び出される側のメソッドへ情報を伝えます。

- 仮引数の動作は、`ref`や`out`などの修飾子を使うことで変更できます。

- `out`修飾子を付けた仮引数は、呼び出されたメソッドから呼び出し元へ値を返します。この仮引数は、初期化せずに呼び出されたメソッドへ渡すことができ、いずれにしても呼び出されたメソッドの中では、入った時点で初期化されていなかったものとして扱われます。仮引数の修飾子に関する動作とルールは、例（下記参照）とコンパイラーのメッセージを通して理解するのがいちばん簡単です。

```csharp
void Foo(out int val)
{
    val = 42;
}
void Bar(int val)
{
    val = 42;
}

int importantValue = 1729;
Foo(out importantValue);
var result = importantValue == 42;
// => true

importantValue = 1729;
Bar(importantValue);
result = importantValue == 1729;
// => true
```

- `out`仮引数には、呼び出されたメソッドの中で必ず値を代入する必要があります。

- `ref`修飾子を付けた仮引数は、呼び出されたメソッドへ値を渡します。メソッドから戻ると、呼び出し元では、呼び出されたメソッドがその仮引数に加えた更新が反映されています。

```csharp
void Foo(ref int val)
{
    val *= 7;
}

int importantValue = 6;
Foo(ref importantValue);
return importantValue;
// => 42
```

- `ref`仮引数は変数でなければなりません。呼び出されたメソッドは、呼び出し元から見えるその仮引数を直接操作するからです。
- `out`修飾子と`ref`修飾子は、呼び出されたメソッドのシグネチャーと、呼び出し箇所の両方で必要です。
