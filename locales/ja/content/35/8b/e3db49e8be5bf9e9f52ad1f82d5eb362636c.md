# 概要

Factorの文字は*整数*（Unicodeコードポイント）です。そのため、数値の`<`、`>`、`=`だけで、大文字と小文字を区別した順序付けができます。[`unicode`][unicode]ボキャブラリを使えば、Unicodeを考慮した述語や、1文字単位の大文字・小文字変換も利用できます。

## 述語

```
LETTER?  ( c -- ? )    ! uppercase letter
letter?  ( c -- ? )    ! lowercase letter
Letter?  ( c -- ? )    ! letter, either case
digit?   ( c -- ? )    ! decimal digit
digit>   ( c -- n )    ! the integer value of a digit char
blank?   ( c -- ? )    ! whitespace
alpha?   ( c -- ? )    ! letter or decimal digit
```

```factor
USING: unicode ;

CHAR: A LETTER? .    ! => t
CHAR: a letter? .    ! => t
CHAR: 7 digit?  .    ! => t
CHAR: \n blank? .    ! => t
```

## 大文字・小文字の変換

```
ch>upper  ( c -- c' )
ch>lower  ( c -- c' )
ch>title  ( c -- c' )
```

文字列レベルの`>upper`、`>lower`、`>title`は、こうした変換を文字列のすべての文字に適用します。

```factor
CHAR: a ch>upper .   ! => 65   (which is CHAR: A)
"Hello" >upper .     ! => "HELLO"
```
