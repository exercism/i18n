# 型仕様を使いましょう

[comment]: # (この警告は、解答に型仕様がないときに表示されます)

関数の入力と出力のあいだの契約を伝えるために、[型仕様](https://elixir-lang.org/getting-started/typespecs-and-behaviours.html#types-and-specs)（`@spec`）を含めましょう。

- Elixirは動的型付け言語なので、型チェックは実行時にしか行われません。型仕様を書くことで、[`Dialyxir`](https://hexdocs.pm/dialyxir/readme.html)（Erlangの[`Dialyzer`](http://erlang.org/doc/man/dialyzer.html)をベースにしています）のようなリンターや静的解析ツールが、コードに意図しない動作がないかどうかを評価できるようになります。
- 組み込み型の[完全な一覧](https://hexdocs.pm/elixir/typespecs.html#basic-types)は、[言語のドキュメント](https://hexdocs.pm/elixir/typespecs.html#content)にあります。
- 型は、括弧（`()`）を付けても付けなくても指定できます。`atom()`と`atom`がその例です。
  - ExercismのElixirのスタイルでは、括弧を付けずに指定します。

```elixir
# Example 1
@spec add_one(int) :: int
def add_one(n) when is_integer(n) do
  n + 1
end

# Example 2
@spec hello(String.t) :: String.t
def hello(what \\ "world") when is_binary(what) do
  "Hello, #{what}"
end
```
