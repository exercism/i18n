# 説明

この演習では、乗り物の購入準備に役立つコードを書いていきます。

やることは3つあります。免許が必要かどうかを判断すること、2台の乗り物から1台を選ぶこと、そして中古の乗り物の妥当な価格を見積もることです。

## 1. 運転免許証が必要かどうかを判断する

乗り物の種類によっては、運転するのに運転免許証が必要です。
`"car"`と`"truck"`の2種類だけが免許を必要とし、それ以外は免許なしで運転できるものとします。

乗り物の種類を受け取り、その種類に免許が必要かどうかを示す真偽値を返す`needs_license`関数を実装してください。

```jq
"car" | needs_license
# => true

"bike" | needs_license
# => false
```

## 2. 購入する候補の2台の乗り物から1台を選ぶ

買える乗り物の候補を検討した結果、2台まで絞り込めましたが、最終的な判断には助けが必要です。
2台の乗り物の配列を入力として受け取り、辞書順で先に来る方を選んだ結果を返す`choose_vehicle`関数を実装してください。

```jq
["Wuling Hongguang", "Toyota Corolla"] | choose_vehicle
# =>  "Toyota Corolla is clearly the better choice."

["Volkswagen Beetle", "Volkswagen Golf"] | choose_vehicle
# =>  "Volkswagen Beetle is clearly the better choice."
```

## 3. 中古の乗り物の価格を見積もる

選ぶ乗り物が決まったら、ディーラーで納得のいく価格で買えるようにしたいところです。
中古の乗り物を買うわけですから、価格はその乗り物の年数によって変わります。
おおまかに見積もると、年数が3年未満なら、新車だったときの元の価格の80%になります。
10年を超えていれば50%です。
3年以上10年以下なら、元の価格の70%になります。

`if`、`elif`、`else`を使ってこのロジックを適用する`resell_price`関数を実装してください。
元の価格と乗り物の年数を持つオブジェクトを受け取り、ディーラーでの見積もり価格を返します。

```jq
{"original_price": 1000, "age": 1} | resell_price
# => 800

{"original_price": 1000, "age": 5} | resell_price
# => 700

{"original_price": 1000, "age": 15} | resell_price
# => 500
```
