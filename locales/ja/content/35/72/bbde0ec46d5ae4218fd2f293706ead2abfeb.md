# ループ

**ループ**は、同じことを何度も繰り返します。

```sather
   loop
      ...
   end;
```

これだけでは決して止まらないので、ループの中の何かが終わらせる必要があります。

## 数を数える場所

ループには、ほぼ必ず、進むにつれて変化する値が必要です。それが**変数**で、`::=`で作ります。

```sather
   total ::= 0;
```

変数の名前は`total`で、`0`から始まり、Satherは`0`からこれが`INT`だと判断します。その後は、`:=`で新しい値を入れます。

```sather
   total := total + 5;
```

右から左に読みます。今の`total`の値を取り、5を足し、その答えを`total`に戻します。

こうして作った変数は、ルーチンの終わりまで生き続けます。

## until!

`until!`は、問いを受け取ります。ループを1回回るたびにその問いが投げかけられ、答えが真になったとき、その場でループが止まります。

```sather
   sum_to(last : INT) : INT is
      total ::= 0;
      n ::= 1;
      loop
         until!(n > last);
         total := total + n;
         n := n + 1;
      end;
      return total;
   end;
```

`n`は1、2、3…と数えていき、`n`が初めて`last`を超えたときにループが終わります。`n := n + 1`がなければ、問いの答えはいつまでも変わらず、ループは永遠に回り続けます。

`until!`は必ずしも最初の行にある必要はありません。問いが意味をなす場所に置きます。先頭に置けば、ループが一度も回らないこともあります。末尾に置けば、必ず一度は回ります。

`!`は名前の一部です。Satherは、ある種のものにこの印を付けます。この印が何を意味するかは、後で説明します。

## break!

`break!`は、問いを伴わずに、ループを即座に終わらせます。止める理由が作業の途中で見つかったときに役立ちます。

```sather
   loop
      if too_far then break!; end;
      ...
   end;
```

`until!`と`break!`は、`loop`の中でのみ意味を持ちます。どちらも単独では使えません。
