# はじめに

## リスト内包表記

内包表記を使うと、_Enumerable_を簡単に、宣言的に変換できます。

ごく単純な内包表記は、`for`キーワードのあとに_ジェネレーター_と_doブロック_を続けて宣言します。_doブロック_が、列挙された値から新しい値を作ります。

```elixir
for n <- [0, 1, 2, 3], do: n + 1
# => [1, 2, 3, 4]
```

内包表記には_フィルター_を付けることもできます。フィルターを通過しなかった値は、最終的なリストから取り除かれます。

```elixir
for n <- [0, 1, 2, 3], n > 1, do: n + 1
# => [3, 4]
```

より複雑な内包表記は、複数行に分けて書くこともできます。

```elixir
for {atom, number} <- [a: 1, b: 2, c: 3, d: 4],
    rem(number, 2) == 0 do
  atom
end

# => [:b, :d]
```

複数のジェネレーターを使うと、_直積_を作ることができます。つまり、最初のジェネレーターが生成した各値は、2番目のジェネレーターが生成した各値と1回ずつ組み合わされます。

```elixir
for x <- [0, 1],
    y <- [0, 1] do
  {x, y}
end

# => [{0, 0}, {0, 1}, {1, 0}, {1, 1}]
```
