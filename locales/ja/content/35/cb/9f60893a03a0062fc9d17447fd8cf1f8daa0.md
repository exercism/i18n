# 三項演算子

三項演算子は、`if..else..`の比較を行って値を返すための、もう一つの書き方を提供します。

## 構文

PHPには`if`文があり、条件が「真」とみなされるかどうかに基づいて、実行する処理を選べます。

```php
if ($condition) {
  $value = 1;
} else {
  $value = 2
}
```

別の書き方として、三項演算子でも同じ処理を表せます。

```php
$value = $condition
  ? 1  // True branch
  : 2; // False branch
```

比較の構文は短く、`(condition) ? (evaluate if true) : (evaluate if false);`のように表します。
