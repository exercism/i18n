# 説明

友達から、大切な秘密が書かれたメッセージが届きました。他の人に簡単に読まれないように、このメッセージは一連のビット操作によって暗号化されています。メッセージを復号するためのワードを書く必要があります。

## 1. ビットをシフトして戻す

メッセージを復号する最初のステップは、暗号化のときに行われたシフトを打ち消すために、ビットを右へシフトし直すことです。以降のステップでは、左から0が挿入されることを前提としています。

`shift-back`を定義します。これは32ビットの値とシフト量を受け取り、その量だけ右にシフトした値を、0で埋めて返します。

```factor
0b1001 2 shift-back .
! => 0b0010
```

## 2. いくつかのビットを立てる

次に、1に設定する必要のあるビットがあります。

`set-bits`を定義します。これは値とマスクを受け取ります。`mask`の対応するビットが1である`value`のビットはすべて1に設定し、それ以外のビットは変更しません。

```factor
0b0110 0b0101 set-bits .
! => 0b0111
```

## 3. 特定のビットを反転する

暗号化のときに反転されるビットがあります。メッセージを復号するには、それらを反転して戻す必要があります。

`flip-bits`を定義します。これは値とマスクを受け取ります。`mask`の対応するビットが1である`value`のビットはすべて反転し、それ以外のビットは変更しません。

```factor
0b1100 0b0101 flip-bits .
! => 0b1001
```

## 4. 特定のビットをクリアする

最後に、復号すると必ず0になるビットもあります。

`clear-bits`を定義します。これは値とマスクを受け取ります。`mask`の対応するビットが1である`value`のビットはすべて0にクリアし、それ以外のビットは変更しません。

```factor
0b0110 0b0101 clear-bits .
! => 0b0010
```
