# はじめに

`PHP 8.0.0`から利用できる**ユニオン型宣言**は、単一の型ではなく、複数の異なる型の値を受け付けます。ユニオン型を定義するときは、型を区切るためにパイプ（`|`）を使います。

```php
function add(int|float $a, int|float $b): int|float
{
    return $a + $b;
}
```

PHPは、strictモードで渡された入力が`float`でも`int`でもない場合、`TypeError`をスローします。strictモードでない場合は、渡された入力を`float`または`int`に変換できないときに型エラーがスローされます。

同様に、関数が宣言された型のいずれかを返さない場合、PHPは実行時に`TypeError`をスローします。
