# ヒント

## 全般

- `locals`ボキャブラリーには、`::`と`[| | ]`があります。
- ローカル変数はスタックのコードを置き換えるものではありません。コードが読みやすくなる場所で使いましょう。

## 1. 調理の状態を判定する

- [`combinators`][combinators]の`cond`がぴったりの形です。1つの分岐で`dup not`（タイマーが`f`）を確認し、別の分岐で`dup zero?`を確認し、残りはデフォルトで処理します。各分岐では、文字列をプッシュする前にタイマーを`drop`します。

## 2. 準備時間を見積もる

- `:: preparation-time ( layers minutes-per-layer -- total )`と、`layers length minutes-per-layer *`を使います。

## 3. 必要な麺とソースの量を計算する

- ローカル変数を使えば、`dup`なしで`layers`を2回参照できます。述語`[ "noodles" = ]`（または`"sauce" =`）を付けた`count`で、それぞれの層の数を取得できます。
- `1/5`はFactorの有理数リテラルです。

## 4. 秘密の材料を加える

- [`sequences`][sequences]にある`last`は最後の要素を読み取ります。`suffix`は末尾に1つ追加します。

## 5. レシピの分量を変える

- 倍率は`portions / 2`です。ローカル変数を使えば、ラムダの中で`portions`を参照できます。
- [`assocs`][assocs]の`assoc-map`は、`( key value -- newkey newvalue )`というクォーテーションを取ります。`[| key value | … ]`の中で両方の値を返すと、同じキーを保ったまま新しい値を生成できます。
