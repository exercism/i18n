# 指示

この演習では、暗号技術者が安全な通信システムを管理・検証するのを手伝います。
このシステムは、すべての算術演算が決められた範囲内に収まるようにするために、体の要素、とりわけCairoの`felt252`型に大きく依存しています。

## 1. 2つのメッセージの和を計算する

暗号化された2つのメッセージは、それぞれが`felt252`として表され、それらを足し合わせて1つの結合されたメッセージを作る必要があります。
ただし、暗号化の都合上、最大値$P - 1$を超える結果は、$P$で割った余りを使って折り返す必要があります。

2つの`felt252`の値を受け取り、それらの和を返す関数を実装してください。結果は有効な範囲内に収まるようにします。

```rust
add_messages(3618502788666131213697322783095070105623107215331596699973092056135007822949, 987654321)
// => 123456789
```

> **注意:** 戻り値は`felt252`にする必要があります。

## 2. 2つのメッセージの差を計算する

元のデータを取り出すために、メッセージを引く必要があることもあります。
引き算の結果が負の場合、システムは自動的に$P$を足して、有効な`felt252`の値の範囲内に戻します。

2つの`felt252`の値を受け取り、それらの差を返す関数を実装してください。結果は有効な範囲内に収まるようにします。

```rust
subtract_messages(123456789, 987654321)
// => 3618502788666131213697322783095070105623107215331596699973092056135007822949
```

> **注意:** 戻り値は`felt252`にする必要があります。

## 3. 2つのメッセージの有効な積を計算する

暗号化されたデータの完全性を保つために、暗号システムはしばしば2つのメッセージ（`felt252`）を掛け合わせ、その積が有効な範囲内に収まるようにします。
結果は有効な範囲内に収まるように、$P$で割った余りとして計算する必要があります。

2つの`felt252`の値を受け取り、それらの積を返す関数を実装してください。結果は有効な範囲内に収まるようにします。

```rust
multiply_messages(382927772233671078546147897004315551461400594453673204174697055647611, 9449570)
// => 123456789
```

> **注意:** 戻り値は`felt252`にする必要があります。
