# 説明

Lucianのガールフレンドが家に帰ってくるというのに、Lucianは記念日のディナーをまだ作っていません！

この演習では、Lucianがお気に入りの料理本のとおりに絶品のラザニアを作れるよう、コードを書いていきます。

タスクは4つあり、どれもラザニアを調理するのにかかる時間に関するものです。

## 1. 想定されるオーブン加熱時間を分単位で定義する

入力を受け取らず、ラザニアをオーブンに入れておくべき分数を返す`Lasagna.ExpectedMinutesInOven()`メソッドを定義します。料理本によると、想定されるオーブン加熱時間は40分です。

```csharp
var lasagna = new Lasagna();
lasagna.ExpectedMinutesInOven();
// => 40
```

## 2. 残りのオーブン加熱時間を分単位で計算する

ラザニアが実際にオーブンに入っていた分数を入力として受け取り、前のタスクで求めた想定加熱時間をもとに、ラザニアをあと何分オーブンに入れておく必要があるかを返す`Lasagna.RemainingMinutesInOven()`メソッドを定義します。

```csharp
var lasagna = new Lasagna();
lasagna.RemainingMinutesInOven(30);
// => 10
```

## 3. 準備時間を分単位で計算する

ラザニアに重ねた層の数を入力として受け取り、1層につき2分かかるものとして、ラザニアの準備に何分かかったかを返す`Lasagna.PreparationTimeInMinutes()`メソッドを定義します。

```csharp
var lasagna = new Lasagna();
lasagna.PreparationTimeInMinutes(2);
// => 4
```

## 4. 経過時間を分単位で計算する

2つの入力を受け取る`Lasagna.ElapsedTimeInMinutes()`メソッドを定義します。1つ目の入力はラザニアに重ねた層の数で、2つ目の入力はラザニアがオーブンに入っていた分数です。このメソッドは、ラザニアの調理に費やした時間を分単位で返します。それは、準備時間と、その時点までラザニアがオーブンにいた時間を足したものです。

```csharp
var lasagna = new Lasagna();
lasagna.ElapsedTimeInMinutes(3, 20);
// => 26
```
