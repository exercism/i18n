# Elmの構文の基本2

## 関数のエクスポート

関数のエクスポートについては最初のコンセプトで扱いました。ここで簡単におさらいしておきましょう。

Elmのファイルはそれぞれがモジュールであり、他のすべてのコードより前に`module`文を書く必要があります。

モジュール名はファイル名と一致していなければなりません。つまり、モジュール`Calculator`はファイルCalculator.elmに、モジュール`Parser.Utils`はファイルParser/Utils.elmに置く必要があります。

モジュール内で定義されたものは、そのモジュールの中だけのスコープを持ち、`exposing`に載せない限りモジュールの外からアクセスすることはできません。

```elm
-- Calculator.elm
-- Define the Calculator module, and expose the `add` function
module Calculator exposing (add)

six = 3 + 3

add number1 number2 = number1 + number2
```

```elm
-- Calculator.elm
-- Define the Calculator module, and expose everything within: `six` and `add`
module Calculator exposing (..)

six = 3 + 3

add number1 number2 = number1 + number2
```

https://elm-lang.org/docs/syntax#modules

## 他のモジュールからの関数のインポート

他のモジュールで定義された関数にアクセスするには、インポートを使います。
そのモジュールをインポートすると、そこで公開されているすべての関数が使えるようになります。
ただし、それらをどう呼び出すかは、モジュールのインポートのしかたによって変わります。

修飾インポートはデフォルトの方法で、そのようなモジュール内の関数（たとえば`List`モジュールの`map`関数）にアクセスするには、モジュール名を前に付けます（`List.map`）。

オープンインポートを使うと、そのモジュールが公開している関数に、接頭辞を付けずに直接アクセスできます。エクスポートで使ったものと対になる`exposing`キーワードで行います。利用できるすべての関数を公開することも（`..`）、特定の関数だけを公開することもできます（たとえば`map`）。

型やそのコンストラクターを他のモジュールからインポートすることもできますが、これは後のコンセプトで扱います。

名前の衝突を避けてコードを見通しよくするために、修飾インポートが好まれます。

```elm
-- qualified imports
import List                            -- List.map, List.foldl
import List as L                       -- L.map, L.foldl

-- open imports
import List exposing (..)              -- map, foldl, concat, ...
import List exposing ( map, foldl )    -- map, foldl, List.concat
```

https://elm-lang.org/docs/syntax#modules

## 型注釈

型注釈は`name : parameter types -> return type`の形で書き、仮引数の型も`->`で区切ります。

```elm
add : Int -> Int -> Int
add number1 number2 = number1 + number2
```

関数の仮引数を定義するのに括弧（`()`）を使うことができます（仮引数自体も同じ構文で定義するため、括弧が必要になります）。

```elm
-- Transform every character in a string
map : (Char -> Char) -> String -> String
map charMapperFunction string =
    -- ...
```

https://elm-lang.org/docs/syntax#type-annotations

## 数値

Elmで扱える数値には2つの型があり、`Int`型と`Float`型で定義されています。
`Int`は正と負の整数の集合に対応します。
`Float`は実数の集合に対応しますが、コンピューターの精度によって制限されます。
数値に対して定義された演算は、通常どちらか一方の型でしか動かず、両方を混ぜて使うことはできません。
2つの型を相互に変換する関数も用意されています。たとえば`toFloat`は`Int`を`Float`に変換し、`round`、`floor`、`ceiling`、`truncate`はそれぞれ異なる意味で`Float`を`Int`に変換します。

https://package.elm-lang.org/packages/elm/core/latest/Basics#Int

## 文字列の操作

コードの中で単語や文を表すために、Elmには`String`型が標準で用意されています。
文字列リテラルは、`"Hello World!"`のように二重引用符で囲んで書きます。
文字列の連結演算子`++`と等値演算子`==`は、デフォルトで使えます。

```elm
hello : String -> String
hello subject = "Hello " ++ subject

hello "World!" --> "Hello World!"
```

その他の文字列関数のほとんどは`String`モジュールにあり、インポートする必要があります。

https://package.elm-lang.org/packages/elm/core/latest/String
