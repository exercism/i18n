# 手順

メルボルンのトラムはゾーンごとに料金がかかり、市内中心部は無料です。これから、券売機の運賃ルールを書いていきます。運賃はすべてセント単位です。

4つのタスクはすべて`TRAM_FARES`クラスに書きます。

## 1. ゾーンの運賃

ゾーン0はフリートラムゾーンで、料金はかかりません。ゾーン1は550、ゾーン2は370です。それ以外の数値はトラムのゾーンではないので、料金はかかりません。

```sather
TRAM_FARES::zone_fare(1)
-- => 550
TRAM_FARES::zone_fare(7)
-- => 0
```

## 2. どんな種類のチケット？

チケットには1文字の記号が付いています。`'f'`は通常料金です。`'c'`と`'s'`はどちらも割引運賃で、`'c'`は子ども用、`'s'`は学生用です。`'x'`は無料パスです。それ以外は不明です。

```sather
TRAM_FARES::ticket_kind('s')
-- => "Concession"
TRAM_FARES::ticket_kind('q')
-- => "Unknown"
```

4つの答えは`"Full fare"`、`"Concession"`、`"Free pass"`、`"Unknown"`です。

## 3. どんな種類の日？

`"Sat"`と`"Sun"`は週末です。`"Mon"`から`"Fri"`は平日です。それ以外は不明です。

```sather
TRAM_FARES::day_type("Sun")
-- => "Weekend"
```

3つの答えは`"Weekend"`、`"Weekday"`、`"Unknown"`です。

## 4. 1日の上限

何回トラムに乗っても、その日の上限を超えて支払うことはありません。平日は1100、週末は700です。判別できない日には上限がなく、0です。

```sather
TRAM_FARES::daily_cap("Sat")
-- => 700
```
