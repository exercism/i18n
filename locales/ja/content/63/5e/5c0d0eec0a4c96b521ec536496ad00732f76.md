# 説明

動物の名前と、その動物がすむ生息地を対応づけるフィールドガイドを作ります。

5つのタスクは、すべて`FIELD_GUIDE`クラスに書きます。

## 1. ガイドに載っているか

```sather
FIELD_GUIDE::is_listed(guide, "emu")
-- => true
```

## 2. どこに住んでいるか

ある動物について記録されている生息地を返します。ガイドにその動物がまったく登録されていなければ、`"Unknown"`を返します。

```sather
FIELD_GUIDE::habitat_of(guide, "emu")
-- => "grassland"
FIELD_GUIDE::habitat_of(guide, "moa")
-- => "Unknown"
```

## 3. 項目を追加する

動物を1匹追加したガイドを返します。すでに載っている動物は、生息地が置き換わります。

```sather
FIELD_GUIDE::add_entry(guide, "wombat", "forest")
-- => the guide, now with wombat in it
```

この戻り値が、それ以降使うガイドになります。完全に空のガイドに追加しても問題なく、動物が1匹だけ入ったガイドができます。

## 4. 動物はいくつあるか

```sather
FIELD_GUIDE::entry_count(guide)
-- => 3
```

## 5. どんな生息地があるか

ガイドに登場する生息地の集合を返します。複数の動物が同じ生息地に住んでいても、その生息地は1回だけ現れます。

```sather
FIELD_GUIDE::all_habitats(guide)
-- => a set holding "grassland" and "forest"
```
