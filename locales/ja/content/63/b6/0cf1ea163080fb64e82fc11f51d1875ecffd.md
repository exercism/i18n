# はじめに

`Result`型を使うと、関数は次のことをすべて示す単一の値を返せるようになります。
- 操作が成功したか失敗したか
- 成功した場合は、操作の結果の値
- 失敗した場合は、失敗の理由

## 使い方

`Result`型は、2つの型を内部に持つジェネリック型です。
- 操作が成功したときの結果の値の型
- 失敗したときのエラーの型

`Result`型はまた、次のようなケースを持つ[判別共用体][discriminated-union]です。
* 成功した結果を表す`Ok <value>`
* 失敗を表す`Error <reason>`

次の関数は、`Result`の値を作る方法を示しています。

```fsharp
let validateName (name: string) : Result<string, string> = 
    match name with
    | null -> Error "Name not found."
    | "" -> Error "Name is empty."
    | _ -> Ok name
```

この例では、`Ok`の値は文字列（与えられた名前）で、`Error`の値も文字列（エラーの原因を、人が読める形式で表したもの）です。


`openFile`関数を呼び出すコードは、次の例のように、パターンマッチングを使って成功と失敗のケースを処理できます。

```fsharp
match openFile(filename) with
| Ok handle -> doSomethingWithFile(handle)
| Error NotFound -> printfn $"Error: file {filename} was not found."
| Error AccessDenied -> printfn $"Error: you do not have permission to open the file {filename}."
| Error FileLocked -> printfn $"Error: file {filename} is already in use."
```
