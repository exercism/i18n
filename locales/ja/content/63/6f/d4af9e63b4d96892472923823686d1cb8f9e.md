# 学習

Haskellは純粋関数型言語です。純粋関数型は、より一般的に教えられている[オブジェクト指向のアプローチ](https://en.wikipedia.org/wiki/Object-oriented_programming)とは根本的に異なるパラダイムです。そのため、Haskellの学習は、単に別の言語を覚えるのとは違った感覚になることがあります。

幸いなことに、ある程度のプログラミング知識を前提としたリソースが数多くあります。たとえば、次のようなものです。

  - 一家言ある初心者向けのHaskellガイド（[2019](https://github.com/theindigamer/not-a-blog/blob/master/opinionated-haskell-guide-2019.md)、[2018](https://lexi-lambda.github.io/blog/2018/02/10/an-opinionated-guide-to-haskell-in-2018/)）
  - 人気の無料オンライン書籍『[Learn You a Haskell For Great Good!](https://learnyouahaskell.github.io/)』
  - グラスゴー大学の[Functional Programming in Haskell](https://www.futurelearn.com/courses/functional-programming-haskell)コース
  - FP Completeの[School of Haskell](https://www.schoolofhaskell.com/)
  - [Happy Learn Haskell Tutorial](http://www.happylearnhaskelltutorial.com/)
  - [Haskell for Mac](http://learn.hfm.io/)のチュートリアル

近年出版されたHaskellの書籍には、次のようなものがあります。
  - Christopher AllenとJulie Moronuki著『[Haskell Programming From First Principles](https://haskellbook.com)』（この本は事前のプログラミング知識を前提としていません）
  - Graham Hutton著『[Programming in Haskell](https://www.cambridge.org/us/academic/subjects/computer-science/programming-languages-and-applied-logic/programming-haskell-2nd-edition?format=PB&isbn=9781316626221)』

入門にあたっての他のリソースを探したいときは、[Haskellウィキ](https://wiki.haskell.org/Learning_Haskell#Online_tutorials)も参照してみてください。
