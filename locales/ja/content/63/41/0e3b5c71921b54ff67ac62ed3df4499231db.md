# 説明

この演習では、ログ行を処理します。

各ログ行は、`"[<LEVEL>]: <MESSAGE>"`という形式の文字列です。

ログレベルは次の3つです：

- `INFO`
- `WARNING`
- `ERROR`

タスクは3つあり、どれもログ行を受け取って、それを使って何かを行うものです。

base Rの従来の関数でも、`stringr`ライブラリでも、好きな方を使えます。どちらを使っても、短く実用的な解答を書くことができます。

## 1. ログ行からメッセージを取り出す

`message`関数を実装して、ログ行のメッセージを返すようにしましょう：

```R
message("[ERROR]: Invalid operation")
#> "Invalid operation"
```

先頭や末尾の空白は取り除きます：

```R
message("[WARNING]:  Disk almost full\r\n")
#> "Disk almost full"
```

## 2. ログ行からログレベルを取り出す

`log_level`関数を実装して、ログ行のログレベルを返すようにしましょう。ログレベルは小文字で返します：

```R
log_level("[ERROR]: Invalid operation")
#> "error"
```

## 3. ログ行を整形し直す

`reformat`関数を実装して、ログ行を整形し直しましょう。メッセージを先に、そのあとにログレベルを括弧（`()`）に入れて書きます：

```R
reformat("[INFO]: Operation completed")
#> "Operation completed (info)"
```
