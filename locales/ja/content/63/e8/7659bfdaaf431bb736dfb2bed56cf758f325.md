# 説明

この演習では、名作ゲームのPac-Manにまつわるいくつかのルールを、Haskellの関数に置き換えていきます。

変換するルールは4つあり、どれもゲームの状態に関するものです。

> 引数がどのように導かれるかは気にしなくて大丈夫です。引数を組み合わせて、意図した結果を返すことだけに集中しましょう。

## 1. Pac-Manがゴーストを食べられるかどうかを定義する

`eatsGhost`関数を定義してください。この関数は2つの引数（_Pac-Manがパワーエサを食べているかどうか_ と _Pac-Manがゴーストに触れているかどうか_）を取り、Pac-Manがゴーストを食べられるかどうかを示す`Bool`値を返します。
この関数は、Pac-Manがパワーエサを食べていて、かつゴーストに触れているときだけ`True`を返すようにしてください。

```haskell
eatsGhost False True
-- -> False
```

## 2. Pac-Manが得点するかどうかを定義する

`scores`関数を定義してください。この関数は2つの引数（_Pac-Manがパワーエサに触れているかどうか_ と _Pac-Manがドットに触れているかどうか_）を取り、Pac-Manが得点したかどうかを示す`Bool`値を返します。
この関数は、Pac-Manがパワーエサかドットに触れているときに`True`を返すようにしてください。

```haskell
scores True True
-- -> True
```

## 3. Pac-Manが負けるかどうかを定義する

`loses`関数を定義してください。この関数は2つの引数（_Pac-Manがパワーエサを食べているかどうか_ と _Pac-Manがゴーストに触れているかどうか_）を取り、Pac-Manが負けたかどうかを示す`Bool`値を返します。
この関数は、Pac-Manがゴーストに触れていて、パワーエサを食べていないときに`True`を返すようにしてください。

```haskell
loses False True
-- -> True
```

## 4. Pac-Manが勝つかどうかを定義する

`wins`関数を定義してください。この関数は3つの引数（_Pac-Manがすべてのドットを食べたかどうか_、_Pac-Manがパワーエサを食べているかどうか_、_Pac-Manがゴーストに触れているかどうか_）を取り、Pac-Manが勝ったかどうかを示す`Bool`値を返します。
この関数は、Pac-Manがすべてのドットを食べていて、_かつ_、パート3で定義した引数に基づいて負けていないときに`True`を返すようにしてください。

```haskell
wins False True False
-- -> False
```
