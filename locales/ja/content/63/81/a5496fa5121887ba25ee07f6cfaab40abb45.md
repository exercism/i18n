# 指示の補足

Rocでは、レコードの更新構文がほとんどの用途をうまくカバーしてくれるので、レンズはあまり使われません。たとえば、次のような入れ子のレコードを考えてみましょう。

```roc
bob = { hair: { color: Brown, length: Long }, mouth: Smiling, height: 6.0 }
```

では、Bobに散髪してあげましょう。

```roc
new_bob = { ..bob, hair: { ..bob.hair, length: Short } }
```

レンズは必要ありません！　とはいえ、Rocではレンズは珍しいものの、HaskellやScalaのような他の言語ではよく使われるので、Rocでどのように実装できるのか気になるかもしれません。また、パラメーター付きの型や、関数を含むレコードといった、Rocの少し高度な機能を練習するのにも良い方法です。実際、Rocでレンズを表す方法の1つは次のとおりです。

```roc
Lens(whole, part) := {
	get : whole -> part,
	set : whole, part -> whole,
}
```

これはパラメーター付きの型です。`whole`と`part`には任意の型を入れることができます。`whole`は通常レコードで、`part`は任意のフィールドの型です。`get`フィールドには、与えられた`whole`の特定の`part`を返す関数が入り、`set`フィールドには、与えられた`whole`のコピーを返す関数が入ります。ただし、特定の`part`が与えられた`part`に置き換えられたコピーです。

たとえば、ある人の髪を取得したり設定したりするレンズは次のとおりです。

```roc
hair_lens = {
	get: |person| person.hair,
	set: |person, hair| { ..person, hair },
}
```

このレンズを使うと、次のようにしてBobの髪に注目できます。

```roc
bob_hair = bob |> hair_lens.get
```

また、次のようにして髪を変えることもできます。

```roc
new_hair = { ..bob.hair, length: Short }
new_bob = bob |> (hair_lens.set)(new_hair)
```

注意：`hair_lens.set`を囲む括弧は必須です。これがないと、Rocは`hair_lens`の型の中から`set`という名前の関数を探してしまいます。

レンズは、それらを合成し始めると特に便利になります。深く入れ子になった部分を取得したり設定したりできるようになるのです。これは、次のような関数を実装することで実現できます。

```roc
compose : Lens(outer, inner), Lens(inner, part) -> Lens(outer, part)
```

この関数を実装すると、次のようにして髪の長さのレンズを作れます。

```roc
length_lens = {
	get: |hair| hair.length,
	set: |hair, length| { ..hair, length },
}
hair_length_lens = compose(hair_lens, length_lens)

```

これで、Bobをもう一度散髪できます。

```roc
set_hair_length = hair_length_lens.set
new_bob = bob |> set_hair_length(Short)
```

入れ子になった部分に任意の変換を適用できる関数を実装したいと思うかもしれません。

```roc
over : Lens(whole, part), whole, (part -> part) -> whole
```

実装できたら、`over`を次のように使えます。

```roc
cut_hair = |current_length| match current_length {
	Long => Short
	Short => Bald
	Bald => Bald
}
new_bob = hair_length_lens |> over(bob, cut_hair)
```

この演習では、次の入れ子のレコードのさまざまな入れ子部分をコードが変更できるかどうかをテストが確認します。

```roc
test_person : Person
test_person = {
	name: { forenames: "Jane Joanna", surname: "Doe" },
	birth: {
		born_at: { street: "Longway", house_number: 1024, place: "Springfield", country: "United States" },
		born_on: { year: 1984, month: 4, day: 12 },
	},
	address: { street: "Shortlane", house_number: 2, place: "Fallmeadow", country: "Canada" },
}
```

まずはRocのレコード更新構文を使ってテストに合格し、そのあとでレンズを使う方法を試してみることをおすすめします。
