# 真偽値

答えが2つしかない問いもあります。はいか、いいえかです。Satherでそのような答えを表す型が`BOOL`で、2つの答えは`true`と`false`と書きます。

```sather
   ready : BOOL is
      return true;
   end;
```

## 比較

2つの数値を比較すると、`BOOL`が得られます。

| 演算子 | 問い |
| --- | --- |
| `=` | 同じかどうか |
| `/=` | 違うかどうか |
| `<` | 左のほうが小さいかどうか |
| `<=` | 小さいか、同じか |
| `>` | 左のほうが大きいかどうか |
| `>=` | 大きいか、同じか |

```sather
   old_enough(age : INT) : BOOL is
      return age >= 13;
   end;
```

`=`は問いかけであることに注意してください。何かに値を*入れる*のが`:=`で、これはすでに見たとおりです。この2つは同じものではありません。

## 組み合わせ

3つの演算子を使うと、小さな問いを組み合わせて大きな問いを作れます。

`and`は、**両方**の辺が`true`のときに`true`になります。

```sather
harness_on and rope_checked
```

`or`は、**どちらか**の辺が`true`のとき、または両方が`true`のときに`true`になります。

```sather
mat_below or net_below
```

`~`は答えをひっくり返します。`true`を`false`に、`false`を`true`にします。

```sather
~ready       -- true exactly when ready is false
```

`and`と`or`は2つの答えの間に入り、`~`は1つの答えの前に入ります。
