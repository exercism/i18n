# インストール

これらの演習を実行するのに必要なのは、[CommandBox CLI](https://commandbox.ortusbooks.com/getting-started-guide)と[Java 8](https://java.com/en/download/)がインストールされていることだけです。CommandBox CLIはMac・Linux・Windowsでサポートされています。インストールガイドはこちらです：

[https://commandbox.ortusbooks.com/setup/installation](https://commandbox.ortusbooks.com/setup/installation)

MacでHomebrewを使っている場合にCommandBox CLIをセットアップする例は、次のとおりです：

```bash
brew install commandbox
```

CLIをインストールしたら、REPLを試してみましょう：

```bash
box repl
```

.cfmページを直接実行することもできます：

```bash
box exec myTest.cfm
```

さらに、ハードドライブ内のどのディレクトリでもWebサーバーを起動できます：

```bash
box server start
```

CommandBoxには、タブ補完が強化され、より高速に動作する対話型シェルがあります。引数を指定せずに`box`バイナリを実行するだけで起動できます。

```bash
box
```
