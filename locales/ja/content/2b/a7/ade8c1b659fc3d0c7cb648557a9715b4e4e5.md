# 説明

ユーザーがファイルをサーバーにアップロードして、ほかのユーザーと共有できるプロジェクトに取り組んでいます。アップロードされたファイルがその[メディアタイプ][mimetype]と一致するかを検証する関数を書くことになりました。調べてみると、ファイルの最初の数バイトは一般にそのファイルの種類に固有で、一種のシグネチャのようになっていることがわかりました。

参考として、次の表を見てください。

| ファイルの種類 | 一般的な拡張子 | メディアタイプ | バイナリの「シグネチャ」 |
| --------- | ---------------- | ---------------------------- | ------------------------------------------------ |
| ELF       | `"exe"`          | `"application/octet-stream"` | `0x7F, 0x45, 0x4C, 0x46`                         |
| BMP       | `"bmp"`          | `"image/bmp"`                | `0x42, 0x4D`                                     |
| PNG       | `"png"`          | `"image/png"`                | `0x89, 0x50, 0x4E, 0x47, 0x0D, 0x0A, 0x1A, 0x0A` |
| JPG       | `"jpg"`          | `"image/jpg"`                | `0xFF, 0xD8, 0xFF`                               |
| GIF       | `"gif"`          | `"image/gif"`                | `0x47, 0x49, 0x46`                               |

## 1. 拡張子から期待されるメディアタイプを返す

`type_from_extension/1`関数を実装してください。ファイルの拡張子（文字列）を受け取り、メディアタイプ（文字列）を返します。拡張子が期待されるものと一致しない場合は`nil`を返します。

```elixir
FileSniffer.type_from_extension("exe")
# => "application/octet-stream"

FileSniffer.type_from_extension("txt")
# => nil
```

## 2. バイナリファイルから期待されるメディアタイプを返す

`type_from_binary/1`関数を実装してください。ファイル（バイナリ）を受け取り、メディアタイプ（文字列）を返します。ファイルのシグネチャが期待されるものと一致しない場合は`nil`を返します。

```elixir
file = File.read!("application.exe")
FileSniffer.type_from_binary(file)
# => "application/octet-stream"

file = File.read!("example.txt")
FileSniffer.type_from_binary(file)
# => nil
```

ファイルをバイナリとして読み込む必要はありません。それはすでに行われており、テストから引数として渡されると想定してください。

## 3. 拡張子とバイナリファイルから、ファイルが期待される種類と一致することを検証する

`verify/2`関数を実装してください。ファイル（バイナリ）と拡張子（文字列）を受け取り、`:ok`または`:error`のタプルを返します。

```elixir
file = File.read!("application.exe")

FileSniffer.verify(file, "exe")
# => {:ok, "application/octet-stream"}

FileSniffer.verify(file, "png")
# => {:error, "Warning, file format and file extension do not match."}
```

[mimetype]: https://en.wikipedia.org/wiki/Media_type
