# 説明の補足

この演習の解答方法のひとつは、自分で冪剰余を計算する関数を実装することです。詳しくは、[こちらのページ](https://en.wikipedia.org/wiki/Modular_exponentiation)を参照してください。

## ボーナスポイントを目指すには

多くの実装は、入力の定義域全体では動作しません。
すべての有効な入力が正しい結果を返すことを確かめるために、追加の任意テストが用意されています。

ボーナステストを実行するには、`#[ignore]`フラグを外し、`big-primes`フィーチャーを付けてテストを実行します。次のようになります。

```bash
$ cargo test --features big-primes
```
