# はじめに

## 配列

Common Lispでも、他の言語と同じように、配列は整数のインデックスでアクセスする要素の集まりです。
要素の型は異なっていてもかまいません。
配列は多次元にすることもできます（単なる1次元ではありません）。

### 作成

`make-array`を使うと、配列を作成できます。
多くのオプションがありますが、より簡単な使い方では、すべての要素を単一の値で初期化したN次元配列や、別のシーケンス（リストなど）の値で初期化した配列を作成できます。
最初の引数は、各次元のサイズを並べたリストです。

```lisp
(make-array '(4) :initial-element 3)    ; => #(3 3 3 3)
(make-array '(2 2) :initial-element 'x) ; => #2A((X X) (X X))
```

（N次元配列が次元数を付けて表示されていることに注目してください。）

配列は、表示されるときと同じ形式を使って作成することもできます。

```lisp
#(x y z)         ; => #(X Y Z)
#2A((1 2) (3 4)) ; => #2A((1 2) (3 4))
```

### 要素へのアクセス

ベクトルの要素にアクセスするには`aref`を使います。インデックスは0から始まります。
指定するインデックスの数は、配列の階数と一致していなければなりません。

```lisp
(aref #2A((1 2 3) (3 4 5)) 
       1 0)           ; => 3
(aref #3A(((a b) (c d)) 
           ((e f) (g h)) 
           ((t u) (v w))) 
       2 0 1)         ; => U
(aref #2A((1) (2)) 0) ; => ERROR (because not enough indexes provided)
```
