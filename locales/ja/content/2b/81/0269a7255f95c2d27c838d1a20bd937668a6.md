# 概要

Luaは数値の表現方法を2つ使います。64ビット整数と倍精度浮動小数点数です。

~~~exercism/note
バージョン5.3より前は、Luaはすべての数値を倍精度浮動小数点形式で表現していました。
~~~

数値は、省略可能な小数部分と、同じく省略可能な10進数の指数を付けて書くことができます。
```lua
1               --> 1
0.2             --> 0.2
0.3e4           --> 3000.0
4.0e-3          --> 0.004
5.0e+20         --> 5e+20
```

小数点または指数が付いた数値は小数とみなされ、付いていないものは整数として扱われます。ただし、どちらの型も'number'です。
```lua
type(1)         --> number
type(2.0)       --> number
```

小数と整数を区別したいときは、`math`モジュールの`type`関数を使います。
```lua
math.type(1)    --> integer
math.type(2.0)  --> float
```

## 比較

値が同じ整数と小数は、等しいとみなされます。
```lua
1 == 1.0        --> true
-2 == -2.0      --> true
0.3e3 == 300    --> true
```

## 算術演算

Luaは一般的な算術演算子をサポートしています。加算、減算、乗算、除算、符号反転です。さらに、切り捨て除算、余り、べき乗もサポートしています。

### 加算、減算、乗算、符号反転

両方のオペランドが整数であれば、演算の結果も整数になります。小数の場合も同じです。
```lua
1 + 2     --> 3
1.0 + 2.0 --> 3.0
```

一方のオペランドが小数であれば、残りの整数も小数に変換され、演算の結果は小数になります。
```lua
1.0 + 2   --> 3.0
```

### 除算

除算は常に小数を対象とし、結果も小数になります。
```lua
1.0 / 2.0 --> 0.5
2 / 1     --> 2.0
```

ゼロで割ると`inf`または`-inf`になります。ゼロをゼロで割ると`-nan`になります。
```lua
1 / 0     --> inf
-1 / 0    --> -inf
0 / 0     --> -nan
```

### 切り捨て除算

整数の結果が必要なときは、切り捨て除算を使います。切り捨て除算は商を常に負の無限大に向かって丸めるので、どのようなオペランドでも整数の結果が得られます。

~~~exercism/note
バージョン5.3より前には、Luaに切り捨て除算の算術演算子はありませんでした。
~~~

```lua
3 // 2    --> 1
6 // 2    --> 3
```

切り捨て除算も、加算、減算、乗算、符号反転の各演算子と同じ規則に従います。両方のオペランドが整数であれば演算の結果は整数になり、そうでなければ小数になります。

```lua
3.0 // 2   --> 1.0
6.0 // 2.0 --> 3.0
```

切り捨て除算でゼロを割ると、Luaはエラーを発生させます。
```lua
3 // 0     --> stdin:1: attempt to divide by zero
```

### 余り

余りは、2つのオペランドを割ったときの余りを求める演算です。
```lua
8 % 2      --> 0
13 % 9     --> 4
-13 % -9   --> -4
-13 % 9    --> 5
13 % -9    --> -5
0.3 % 0.2  --> 0.1
```

### べき乗

除算と同じく、べき乗も小数を対象とし、結果も小数になります。
```lua
10 ^ 2    --> 100.0
```

## 優先順位

すべての演算は[演算子の優先順位](https://www.lua.org/manual/5.4/manual.html#3.4.8)に従って評価されます。式の優先順位を変えたいときは、括弧（`()`）を使います。

```lua
1 + 2 * 3   --> 7
(1 + 2) * 3 --> 9
```

## 丸め

`math`モジュールには3つの丸め関数があります。`floor`は「下」に（負の無限大に向かって）丸め、`ceil`は「上」に（正の無限大に向かって）丸め、`modf`はゼロに向かって丸めます。

### `math.floor`

`floor`は負の無限大に向かって丸めます。
```lua
math.floor(1.3)    --> 1
math.floor(-1.3)   --> -2
```

### `math.ceil`

`ceil`は正の無限大に向かって丸めます。
```lua
math.ceil(1.3)    --> 2
math.ceil(-1.3)   --> -1
```

### `math.modf`

`modf`はゼロに向かって丸めます。この関数は丸めた値と、その数値の小数部分を返します。小数部分は常に小数です。
```lua
math.modf(1.3)    --> 1    0.3
math.modf(-1.3)   --> -1   -0.3
```

## 変換

整数を小数に変換したいときは、`0.0`を足します。
```lua
1 + 0.0         --> 1.0
```

小数を整数に変換したいときは、0とビット単位のORを取るか、`math`モジュールの`tointeger`関数を使います。
```lua
1.0 | 0              --> 1
math.tointeger(1.0)  --> 1
```

数値を整数に変換できない場合、OR演算子はエラーを発生させ、`tointeger`関数は`nil`を返します。
```lua
1.1 | 0              --> stdin:1: number has no integer representation
math.tointeger(1.1)  --> nil
```

## 16進数

他の多くのプログラミング言語と同じように、Luaは数値の前に`0x`を付けることで16進数を扱えます。しかし、他の多くのプログラミング言語と違い、Luaは浮動小数点の16進数も扱えます。こちらは小数部分と、'p'または'P'で始まる2進指数を持てます。
```lua
0xff            --> 255
0x0.2           --> 0.125
0x3p-1          --> 1.5
0xa.bp2         --> 42.75
```
