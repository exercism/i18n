# 説明

この演習では、高校生の恋人同士がSNSで愛を告白できるよう、二人のイニシャルをあしらったASCIIのハートを作ります。

```
     ******       ******
   **      **   **      **
 **         ** **         **
**            *            **
**                         **
**     J. K.  +  M. B.     **
 **                       **
   **                   **
     **               **
       **           **
         **       **
           **   **
             ***
              *
```

## 1. 名前の頭文字を取得する

`HighSchoolSweetheart::firstLetter`関数を実装します。
名前を受け取り、その頭文字を返します。
名前から不要な空白を取り除きます。

```php
<?php

$sweetheart = new HighSchoolSweetheart();
$sweetheart->firstLetter("Jane");
# => "J"
```

## 2. 頭文字をイニシャルとして整形する

`HighSchoolSweetheart::initial`関数を実装します。
名前を受け取り、その頭文字を大文字にし、ピリオドを付けて返します。
前のステップで定義した`HighSchoolSweetheart::first_letter`を再利用してください。

```php
<?php

$sweetheart = new HighSchoolSweetheart();
$sweetheart->initial("jane");
# => "J."
```

## 3. フルネームを名と姓に分割する

`HighSchoolSweetheart::initials`関数を実装します。
スペースで区切られた名と姓からなるフルネームを受け取り、イニシャルを返します。
前のステップで定義した`HighSchoolSweetheart::initial`を再利用してください。

```php
<?php

$sweetheart = new HighSchoolSweetheart();
$sweetheart->initials("Jane Doe");
# => "J. D."
```

## 4. イニシャルをハートの中に入れる

`HighSchoolSweetheart::pair`関数を実装します。
2つのフルネームを受け取り、ASCIIのハートの中にイニシャルを入れて返します。
前のステップで定義した`HighSchoolSweetheart::initials`を再利用してください。

```php
<?php

$sweetheart = new HighSchoolSweetheart();
$sweetheart->pair("Blake Miller", "Riley Lewis")
# => """
#      ******       ******
#    **      **   **      **
#  **         ** **         **
# **            *            **
# **                         **
# **     B. M.  +  R. L.     **
#  **                       **
#    **                   **
#      **               **
#        **           **
#          **       **
#            **   **
#              ***
#               *
# """
```
