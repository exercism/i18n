# インストール

## インストール方法

Unisonの最新リリースは、Mac OS X・64ビットLinux・Windowsでお使いいただけます！　Unisonを試している方は、ぜひExercismのフォーラムや[Unison Discord](https://unison-lang.org/discord)でお話ししに来てください。質問したり、遭遇した問題を報告したりしてください！　始めるときに、あたたかく前向きな気持ちで取り組んでほしいと思っています！ 😊

Unisonは[homebrew](https://brew.sh/)、[Nix](https://github.com/ceedubs/unison-nix/#usage)、またはパッケージ化されたバイナリを直接使ってダウンロードできます。これらのダウンロード方法はすべて、[公式サイトのインストール手順ページ](https://www.unison-lang.org/learn/quickstart/#installation-options)で説明されています。UCMをインストールできたら、ここに戻ってきてください！

### 方法1: Homebrewを使う

まだの場合は、まず[homebrewをインストール](https://brew.sh/)してください。

次に、コマンドラインで次のコマンドを入力します:

```
brew tap unisonweb/unison
brew install unison-language
```

これで、Unisonコードベースマネージャーの実行ファイル`ucm`がインストールされます。以前のバージョンからアップグレードする場合は、次のコマンドを実行するだけです。

```
brew upgrade unison-language.
```

注意: ここでGitHubのユーザー名とパスワードの入力を求められた場合は、`unisonweb/unison`の綴りが正しいか確認してください。

### 方法2: MacとLinuxで手動インストールする

LinuxとMacの手動インストール用リンクは、[こちら](https://www.unison-lang.org/learn/quickstart/#installation-options)のそれぞれの手動ダウンロードセクションにあります。

シェルでは次のようなコマンドを実行しますが、最新のバイナリは上記のリンクにあります:

```
mkdir unisonlanguage
curl -L https://github.com/unisonweb/unison/releases/download/release_VERSION_NAME/ucm-YOUR_PLATFORM.tar.gz --output unisonlanguage/ucm.tar.gz
tar -xzf unisonlanguage/ucm.tar.gz -C unisonlanguage
./unisonlanguage/ucm
```

### 方法3: Windowsで手動インストールする

1. 最良の結果を得るには、既定のターミナルアプリケーションを「Windows Terminal」に設定します。Settingsで「Terminal」を検索するか、[こちらの手順](https://bit.ly/3IXwdlY)に従ってください。
2. Gitがまだ入っているか分からない場合は、Gitをインストールします:
  * wingetを使う場合: `winget install --id Git.Git -e --source winget`
  * Windows 10を使っていてwingetがない場合は、[Microsoft Store](https://www.microsoft.com/en-us/p/app-installer/9nblggh4nns1)からインストールして、上のコマンドを実行します。
3. [提供されているリンクからUCMをダウンロード](https://www.unison-lang.org/learn/quickstart/#installation-options)し、好きな場所に展開します。
4. `ucm.exe`を実行します。

### 方法4: Nixでのインストール
[https://github.com/ceedubs/unison-nix/#usage](https://github.com/ceedubs/unison-nix/#usage)にアクセスして、そこのreadmeの手順に従ってください。

## Unisonコードベースを作成する

`ucm`を実行すると、`$HOME/.unison`にUnisonコードベースが初期化されます。ここに、Unisonは関数定義や型、名前空間などを保存します。既定では、Unison Codebase Manager（略して「UCM」）が、標準ライブラリである`base`のダウンロードを開始します。`base`は、Unisonのコードを書くときに使うものです。少し時間がかかることがあります！ 🕰

## Unisonのワークフロー

Unisonのコードを書きたいときは、`ucm`コマンドを実行してコードベースマネージャーを起動します。するとUCMは、起動したディレクトリにある`.u`拡張子のファイルの変更を監視します。たとえば、`~/exercism/unison/my-exercise/`というディレクトリの`scratch.u`というファイルに関数を実装しているとします。その場合は、`~/exercism/unison/my-exercise/`に`cd`して、`ucm`を実行してください。こうすると、UCMが`scratch.u`ファイルの変更を確実に監視します。

`ucm`がどのディレクトリのファイル変更を監視しているか分からなくなったら、CLIの起動時に表示されるウェルカム画面に書いてあります。

```
👀 I'm watching for changes to .u files under /Users/myUser/exercism/unison/my-exercise
```

[ワークフローのヒントはこちら！](https://exercism.org/docs/tracks/unison/workflow)

## エディタのサポート

`.u`ファイルを書くには、どんなテキストエディタでも使えます。Unisonは[LSPをサポート](https://github.com/unisonweb/unison/blob/trunk/docs/language-server.markdown)しているので、お気に入りのIDEがホバー時の型の表示や自動補完などを手伝ってくれます。Unisonをサポートする人気のエディタをいくつか挙げます。

### Vim

[vim-plug](https://github.com/junegunn/vim-plug)を使う場合:

1. まだの場合は[`vim-plug`](https://github.com/junegunn/vim-plug)をインストールします。
2. .vimrcに次を追加します: `Plug 'unisonweb/unison', { 'branch': 'trunk', 'rtp': 'editor-support/vim' }`
3. vimのコマンド`:PlugInstall`を実行します。

詳しくは、vim内で`:help unison`を実行するか、[オンラインのヘルプドキュメント](https://github.com/unisonweb/unison/blob/trunk/editor-support/vim/doc/unison.txt)を参照してください。

### Atom
コンソールから次を実行します:

```
apm install unisonweb/atom-unison
```

### VS Code

1. VS Codeの横にあるActivity BarでExtensionsアイコンをクリックするか、⇧⌘XでExtensionsビューを開きます。
2. 「unison」で検索します。
3. [Unison VS Code拡張機能](https://marketplace.visualstudio.com/items?itemName=unison-lang.unison)をインストールします。

### Emacs
[`unison-mode`](https://github.com/dariooddenino/unison-mode-emacs)をインストールします。
