# はじめに

## 末尾呼び出しの再帰

列挙可能なもの（リスト、ビットストリング、文字列）を[再帰][exercism-recursion]で辿っていくとき、しばしば2つの懸念が生じます。

- 再帰的な関数呼び出しの連なりを保持するのに、どれだけのメモリが必要か
- どうすれば解答を効率よく組み立てられるか

こうした懸念に対処するために、_アキュムレーター_を使うことがあります。

アキュムレーターとは、データに加えて渡される変数のことです。関数の実行の現在の状態を、関数呼び出しから関数呼び出しへと受け渡し、_ベースケース_に到達するまで運びます。ベースケースでは、このアキュムレーターを使って、再帰的な関数呼び出しの最終的な値が返されます。

アキュムレーターは、関数の利用者ではなく、関数の作者が初期化するものです。これを実現するには、2つの関数を定義します。必要なデータだけを引数に取り、アキュムレーターを初期化する公開関数と、アキュムレーターも受け取る非公開関数です。Elixirでは、非公開関数の名前の先頭に`do_`を付けるのが一般的なパターンです。

```elixir
# Count the length of a list without an accumulator
def count([]), do: 0
def count([_head | tail]), do: 1 + count(tail)

# Count the length of a list with an accumulator
def count(list), do: do_count(list, 0)

defp do_count([], count), do: count
defp do_count([_head | tail], count), do: do_count(tail, count + 1)
```

アキュムレーターを使うことで、再帰関数を_末尾再帰_関数に変えられます。関数によって_最後_に実行されるのが自分自身への呼び出しであれば、その関数は末尾再帰です。
