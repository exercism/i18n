# 説明

この演習では、乗り物の購入に備えるためのコードを書きます。

タスクは3つあります。1つは、2つの乗り物のどちらを選ぶべきかを判断するのに必要かどうかを確かめるもの、1つは、どの免許が必要かを判断するもの、もう1つは、中古の乗り物の妥当な価格を見積もるものです。

## 1. ある車の月々の支払いを払えるかどうかを計算する

町の自動車販売店はどこも、5年間・金利0%のキャンペーンを行っています。ぜひ利用したいところですが、欲しい車の月々の支払いを払えるかどうかはわかりません。

月々の支払いは、車の総額を5年間の月数で割った金額です。

`canIBuy(vehicle:price:monthlyBudget:)`関数を実装します。この関数は次の引数を取ります。
- `vehicle`：買いたい乗り物の名前。
- `price`：買いたい乗り物の価格。
- `monthlyBudget`：毎月支払える金額。

この関数は、次の条件に応じてメッセージを返します。
- 乗り物の月々の支払いが毎月の予算以下なら、`"Yes! I'm getting a <vehicle>"`というメッセージを返します。
- 乗り物の月々の支払いが毎月の予算を最大10%（10%を含む）上回るなら、`"I'll have to be frugal if I want a <vehicle>"`というメッセージを返します。
- 乗り物の月々の支払いが毎月の予算を10%より大きく上回るなら、`"Darn! No <vehicle> for me"`というメッセージを返します。

```swift
canIBuy(vehicle: "1974 Ford Pinto", price: 516.32, monthlyBudget: 100.00)
// returns "Yes! I'm getting a 1974 Ford Pinto"
canIBuy(vehicle: "2011 Bugatti Veyron", price: 2_250_880.00, monthlyBudget: 10000.00)
// returns "Darn! No 2011 Bugatti Veyron for me"
canIBuy(vehicle: "2020 Indian FTR 1200", price: 12_500, monthlyBudget: 200)
// returns "I'll have to be frugal if I want a 2020 Indian FTR 1200"
```

## 2. 必要な運転免許の種類を判断する

中古の乗り物を買うことに決めたので、それを運転するのにどの種類の運転免許が必要になるかを判断する必要があります。

`licenseType(numberOfWheels:)`関数を実装します。この関数は引数`numberOfWheels`を取ります。これは買いたい乗り物の車輪の数です。

この関数は、次の条件に応じてメッセージを返します。
- 車輪の数が2または3なら、`"You will need a motorcycle license for your vehicle"`というメッセージを返します。
- 車輪の数が4または6なら、`"You will need an automobile license for your vehicle"`というメッセージを返します。
- 車輪の数が18なら、`"You will need a commercial trucking license for your vehicle"`というメッセージを返します。
- それ以外の数なら、`"We do not issue licenses for those types of vehicles"`というメッセージを返します。

```swift
licenseType(numberOfWheels: 2)
// returns "You will need a motorcycle license for your vehicle"
licenseType(numberOfWheels: 6)
// returns "You will need an automobile license for your vehicle"
licenseType(numberOfWheels: 18)
// returns "You will need a commercial trucking license for your vehicle"
licenseType(numberOfWheels: 0)
// returns "We do not issue licenses for those types of vehicles"
```

## 3. 中古の乗り物の価格の見積もりを計算する

買うものを決めたので、販売店で適正な価格で買えるかどうかを確かめておきたいところです。
中古の乗り物の購入を考えているので、価格は乗り物の古さによって決まります。
おおまかな見積もりとして、乗り物が3年未満なら、新品だったときの元の価格の80%になると考えてください。
10年以上経っていれば、50%です。
3年以上、10年以下の場合は、元の価格の70%です。

`calculateResellPrice(originalPrice:yearsOld:)`関数を実装します。この関数は引数`originalPrice`と`yearsOld`を取ります。`originalPrice`は乗り物の元の価格、`yearsOld`は乗り物の年齢（年数）です。
この関数は、乗り物の再販価格を返します。 

```swift
calculateResellPrice(originalPrice: 1000, yearsOld: 1)
// returns 800
calculateResellPrice(originalPrice: 1000, yearsOld: 5)
// returns 700
calculateResellPrice(originalPrice: 1000, yearsOld: 15)
// returns 500
```
