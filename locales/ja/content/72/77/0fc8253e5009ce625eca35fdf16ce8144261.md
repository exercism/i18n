# 説明

海辺のボードウォークにあるゲームセンターで、運任せのゲームを切り盛りしています。お客さんがサイコロを振り、クレーンゲームが景品をつかみ、カードテーブルではデッキをシャッフルして手札を配る必要があります。これらはすべてランダム性によって動いています。一晩の営業が終わったら、判定でもめたゲームを同じシードから再現できるように、「リプレイ」機能も欲しくなります。

## 1. サイコロを振る

`roll-die`を定義して、面の数を受け取り、`1`から`sides`までの範囲（両端を含む）の出目を返すようにしましょう。

```factor
6 roll-die .
! => 4   (some value from 1..6)
```

## 2. 景品をつかむ

`pick-prize`を定義して、景品のシーケンスを受け取り、その中から1つをランダムに返すようにしましょう。

```factor
{ "teddy" "goldfish" "keyring" } pick-prize .
! => "goldfish"
```

## 3. デッキをシャッフルする

`shuffle-deck`を定義して、デッキ（シーケンス）を受け取り、カードをランダムな順序に並べ替えたものを返すようにしましょう。

```factor
{ 1 2 3 4 5 } shuffle-deck .
! => { 3 1 5 2 4 }
```

## 4. 手札を配る

`deal-hand`を定義して、デッキと枚数`n`を受け取り、デッキから*n枚の異なる*カードを返すようにしましょう。

```factor
{ 10 20 30 40 50 } 3 deal-hand .
! => { 40 10 30 }
```

## 5. シードからリプレイする

`play-seeded`を定義して、シードとクォーテーションを受け取り、その整数をシードとするジェネレーターでクォーテーションを実行し、同じシードなら常に同じ結果が再現されるようにしましょう。クォーテーションの結果は呼び出し元に返されるようにします。

```factor
42 [ 6 roll-die ] play-seeded .
! => the same value every time for seed 42

! Same seed, same game:
99 [ 5 deal-hand ] play-seeded   99 [ 5 deal-hand ] play-seeded   =  .
! => t
```
