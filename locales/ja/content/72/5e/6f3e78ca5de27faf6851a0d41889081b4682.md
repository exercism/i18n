# Swiftのインストール

SwiftはmacOS、Linux、Windowsで利用できます。
インストールの手順は、使用しているオペレーティングシステムによって異なります。
Linuxのサポートについて重要なのは、Swiftが公式にサポートしているディストリビューションが次のものだけである点です。
- Ubuntu
- Debian
- RedHat
- Fedora
- Amazon Linux

別のLinuxディストリビューションを使っている場合は、自分でSwiftをインストールする方法を探す必要があります。

## Xcode（macOS）

Swiftは、AppleがmacOSとiOS向けの開発のために提供する統合開発環境（IDE）、Xcodeに含まれています。
Exercismのトラックでは、Xcodeのバージョン16.0以上がインストールされている必要があります。
Xcodeは[Mac App Store][xcode]で無料で入手できます。
その他のバージョンのXcode（最新のベータ版を含む）は、[Appleのデベロッパーセンター][apple-developer-center]で入手できます。

## macOSとLinux

macOSとLinuxには、[swiftly][swiftly]というSwiftのインストールマネージャーがあります。
これはコマンドラインツールで、システムに複数のバージョンのSwiftをインストールして管理できます。
macOSでswiftlyをインストールするコマンドは[こちら][swiftly-macos]に、Linuxの場合は[こちら][swiftly-linux]にあります。

macOSでのその他のインストール方法としては、[Homebrew][homebrew]があります。
Linuxでは、公式の[Swiftのウェブサイト][tarball]にあるターボールを使ってインストールできます。

## Windows

WindowsにSwiftをインストールする際におすすめの方法は、[WinGetインストーラー][winget-windows]を使うことです。
Scoopパッケージマネージャーを使ったり、手動でインストールしたりすることもできます。
すべての選択肢については、[Install Swift for Windows][swift-windows]のページをご覧ください。
