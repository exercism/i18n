# 指示

この演習では、貯蓄口座を扱います。
貯蓄口座の残高は、毎年、その利率に基づいて更新されます。
銀行が提示する利率は、口座に入っているお金の額（残高）によって決まります。

- 残高が`0`ドル未満の場合は3.213%（残高がさらにマイナスになります）。
- 残高が`0`ドル以上`1000`ドル未満の場合は0.5%。
- 残高が`1000`ドル以上`5000`ドル未満の場合は1.621%。
- 残高が`5000`ドル以上の場合は2.475%。

この演習には4つのタスクがあり、それぞれで残高と利率を扱います。

## 1. 利率を計算する

指定された残高に基づいて利率を計算する`InterestRate()`関数を実装しましょう。

```go
InterestRate(200.75)
// => 0.5
```

戻り値は`float32`であることに注意してください。

## 2. 利息を計算する

指定された残高に基づいて利息を計算する`Interest()`関数を実装しましょう。

```go
Interest(200.75)
// => 1.003750
```

戻り値は`float64`であることに注意してください。

## 3. 年間の残高更新を計算する

利率を考慮して、年間の残高更新を計算する`AnnualBalanceUpdate()`関数を実装しましょう。

```go
AnnualBalanceUpdate(200.75)
// => 201.75375
```

戻り値は`float64`であることに注意してください。

## 4. 目標残高に到達するまでの年数を計算する

毎年、残高に利息が加わることを考慮して、目標残高に到達するまでに必要な最小年数を計算する`YearsBeforeDesiredBalance()`関数を実装しましょう。
つまり、1年後の残高は、最初の残高と、それに対する利息を足したものです。
2年後の残高は、1年後の残高と、それに対する利息を足したものです。
これを、その年の残高が目標残高以上になるまで繰り返します。

```go
balance := 200.75
targetBalance := 214.88
YearsBeforeDesiredBalance(balance, targetBalance)
// => 14
```

戻り値は`int`であることに注意してください。
