# テスト

CLIを使って演習のテストを実行するには、演習のディレクトリで次のコマンドを実行してください：

```bash
clojure -M:test
```

## REPL

REPLを使って演習のテストを実行するには、演習のディレクトリで次のコマンドを実行してください：

```bash
$ clojure -m cljs.main -re node
```

次に、演習のテスト名前空間とClojureのテスト名前空間を`require`します：

```clojure
;; replace <exercise> with the exercise's name
=> (require '<exercise>-test)
nil
;; and the test namespace
=> (require 'cljs.test)
```

nsをテスト名前空間に変更します：

```clojure
;; replace <exercise> with the exercise's name
=> (ns <exercise>-test)
nil
```

次に、`run-tests`を呼び出します：

```clojure
=> (cljs.test/run-tests)
```
