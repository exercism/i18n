# テストを実行する

演習のテストを実行するには、演習のディレクトリで`<exercise>.test`スクリプトを実行します：

```bash
tclsh <exercise>.test
```

ほとんどの演習では、最初のテスト以外はすべて「skipped」になります。これにより、エンジニアはテスト駆動開発に取り組めます。テストを1つずつ通すのに必要な分だけコードを書いていくのです。スキップのコマンドを無効にするには、テストスイートを実行する前に、`RUN_ALL`環境変数にTclで真と評価される値を設定します\[1\]：

```bash
RUN_ALL=yes tclsh <exercise>.test
```

\[1\]: Tclの真偽値については、Cライブラリ関数[Tcl_GetBoolean][bool]のmanページに説明があります。

[bool]: https://www.tcl-lang.org/man/tcl8.6/TclLib/GetInt.htm
