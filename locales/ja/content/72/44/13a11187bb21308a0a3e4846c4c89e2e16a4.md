# はじめに

Pythonでは、値が存在しないことを表すために`None`がよく使われます。`null`（空）の変数やオブジェクト、引数を定義するためのプレースホルダーです。

他のプログラミング言語で`NULL`や`nil`という型を見たり使ったりしたことがあれば、Pythonでの`None`のこの使い方には馴染みがあるでしょう。`None`を使うと、まだ値がない変数や関数の引数を宣言しておけます。それらはあとで必要になったときに、具体的な値を代入し直すことができます。

```python
a = None
print(a)
#=> None
type(a)
#=> <class 'NoneType'>

# Adding a Default Argument with `None`
def add_to_todos(new_task, todo_list=None):
  if todo_list is None:
    todo_list = []
    todo_list.append(new_task)
  return todo_list

```

`None`は条件式で使うと`False`と評価されるため、値の有無、つまり_どんな_値でもそれが存在するかどうかを確かめるのに役立ちます。関数や処理がエラーオブジェクトやメッセージを返すかもしれないときによく使われるパターンです。

```python
a = None
if a: #=> a will be evaluated to False when its used in a conditional check.
    print("This will not be printed")
```
