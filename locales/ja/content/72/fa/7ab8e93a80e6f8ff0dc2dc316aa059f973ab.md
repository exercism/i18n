# 説明の補足

## ヒント

この演習を完了するには、関数`anagramsFor`を実装する必要があります。この関数は*単語*と*単語*のグループを受け取り、与えられた*単語*のアナグラムを返します。

アナグラムは、候補の単語に並んでいる順序と同じ順序で返さなければなりません。

この演習を初めて解く場合は、用意されているシグネチャのまま進めることをおすすめします：

```haskell
anagramsFor :: String -> [String] -> [String]
```

慣れてきたら、この問題に戻ってきて、ほかのデータ型やライブラリを試してみるのもよいでしょう：

- パッケージ*text*の`Text`。
- パッケージ*containers*の`Sequence`と`Set`。
- パッケージ*multiset*の`MultiSet`

テストスイートは、意味の通るほぼどんな型シグネチャでも受け入れるように意図的に設計されています。自分がいちばんよいと思うものを見つけてみてください。
