# はじめに

動的メモリは、プログラムの実行中にメモリを確保したり解放したりするためにプログラマーが使うライブラリ関数によって実現されています。
メモリの確保と解放をプログラマーが制御するため、動的メモリの安全性は、プログラマーが人為的なミスを犯さないかどうかにかかっています。
そのため、動的メモリはプログラミングのバグの主要な原因の1つであり、ハッキング攻撃の主要な標的にもなっています。

## malloc

`malloc`は`stdlib.h`で宣言されている関数で、動的メモリを確保するために使います。
確保に成功すると、確保したメモリの先頭バイトのアドレスを指すポインタが返されます。
確保に失敗すると、`NULL`が返されます。
`malloc`の結果が`NULL`かどうかを確認し、失敗した場合は適切に対処するのが賢明です。
返されるポインタの型は`pointer-to-void`で、これは大まかに言えば「汎用的な」ポインタとみなすことができ、そのメモリで使う特定の型に変換できます。
`malloc`の仮引数は1つで、それは確保したいメモリのサイズをバイト単位で表します。
配列を確保するための全体のサイズは、各要素のデータ型のサイズに要素の数を掛けたものです。
各要素のデータ型のサイズを取得するには、`sizeof`演算子をよく使います。
次の例はこれを示しています。

```c
#include <stdio.h>
#include <stdlib.h>

int * my_function(int count) {
    // pointer-to-void from malloc is converted to a pointer-to-int
    int * numbers = malloc(sizeof(int) * count);
    return numbers;
}

int main() {
    int * numbers = my_function(3);
    if (!numbers) return -1;
    // printed The size of numbers is 8 bytes (can vary by system)
    printf("The size of numbers is %zu bytes\n", sizeof(numbers));
    numbers[0] = 1;
    numbers[1] = 2;
    numbers[2] = 3;
    // prints The first element of the array is 1
    printf("The first element of the array is %d\n", numbers[0]);
    // prints The second element of the array is 2
    printf("The second element of the array is %d\n", numbers[1]);
    // prints The third element of the array is 3
    printf("The third element of the array is %d\n", numbers[2]);
    free(numbers);
    numbers = NULL;
}
```

`malloc`で新しく確保したメモリは初期化されておらず、ゴミのような値が入っている可能性があることを覚えておくことが大切です。
`numbers`ポインタの`sizeof`は、配列の要素数でも、確保したメモリの総量でもないことに注意してください。
`malloc`が返すポインタのサイズは、そのシステムにおけるあらゆるポインタのサイズです。
サンプルコードは64ビットシステムで実行したので、ポインタのサイズは8バイトでした（1バイトあたり8ビットを掛けると64ビットになります）。
ポインタの型は`pointer-to-void`から`pointer-to-int`へ暗黙的に変換されました。
次のように明示的に変換することもできます：`int * numbers = (int *) malloc(sizeof(int) * count);`。
値を読み出す前に必ず書き込むのであれば、`malloc`を使うのはメモリを確保する効率的な方法になりえます。
しかし、初期化される前に値を読み出す可能性があるなら、`malloc`を使うのは危険です。
より安全にメモリを確保する方法は`calloc`を使うことで、これは新しく確保したメモリを0で初期化します。

上の例で`free(numbers)`が使われていることに注目してください。

## free

`free`は`stdlib.h`で宣言されている関数で、動的に確保したメモリを解放するために使います。
動的に確保したメモリは、`free`で解放されるまでメモリ上に確保されたままになります。
プログラムの終了時に動的に確保したメモリを自動的に解放するオペレーティングシステムもありますが、それに頼らないのがベストプラクティスです。
`free`の仮引数は1つで、それは動的に確保したメモリへのポインタです。
解放されたあとに`NULL`に設定されていないポインタは、ダングリングポインタと呼ばれます。
ダングリングポインタは、意図していたメモリとは別のメモリを指す可能性があります。
そのため、ダングリングポインタはデータの破壊や、任意のコードの差し替えと実行につながる可能性があります。
確保したメモリへのポインタが`NULL`に設定されてクリアされていないと、そのプログラムをハックするために利用される可能性があります。
ポインタを`free`に渡したあとは、それを`NULL`に設定するのがベストプラクティスです。

## calloc

`calloc`は`stdlib.h`で宣言されている関数で、動的メモリの確保と、新しく確保したメモリを0で初期化することの両方に使います。
確保に成功すると、確保したメモリの先頭バイトのアドレスを指すポインタが返されます。
確保に失敗すると、`NULL`が返されます。
`calloc`の結果が`NULL`かどうかを確認し、失敗した場合は適切に対処するのが賢明です。
返されるポインタの型は`pointer-to-void`で、これは大まかに言えば「汎用的な」ポインタとみなすことができ、そのメモリで使う特定の型に変換できます。
`calloc`の仮引数は2つあります。
1つ目の仮引数は、指定したデータ型を何個確保するかを表します。
2つ目の仮引数は、確保する指定したデータ型のサイズを表します。

次の例では、`calloc`が新しく確保した値を必ず0にするため、すべての`printf`文は常に`0`を表示するはずです。

```c
#include <stdio.h>
#include <stdlib.h>

int * my_function(int count) {
    // allocates the amount of bytes in an int, multiplied by count
    int * numbers = calloc(count, sizeof(int));
    return numbers;
}

int main() {
    int * numbers = my_function(3);
    if (!numbers) return -1;
    // prints The first element of the array is 0
    printf("The first element of the array is %d\n", numbers[0]);
    // prints The second element of the array is 0
    printf("The second element of the array is %d\n", numbers[1]);
    // prints The third element of the array is 0
    printf("The third element of the array is %d\n", numbers[2]);
    free(numbers);
    numbers = NULL;
}
```

## realloc

`realloc`は`stdlib.h`で宣言されている関数で、既に確保したメモリを拡張または縮小するために使います。
再確保に成功すると、再確保したメモリの先頭バイトのアドレスを指すポインタが返されます。
再確保に失敗すると、`NULL`が返されます。
`realloc`の結果が`NULL`かどうかを確認し、失敗した場合は適切に対処するのが賢明です。
`realloc`の仮引数は2つあります。
1つ目の仮引数は、再確保する既存のメモリへのポインタです。
2つ目の仮引数は、再確保するメモリのサイズをバイト単位で表します。
メモリを拡張する前に設定した値は保持されます。
メモリを拡張するときに追加されたメモリは0で初期化されず、その値は何であってもおかしくないことを覚えておくことが大切です。
また、メモリを縮小するときに取り除かれたメモリも初期化されておらず、値がそのまま残っている可能性があります。
次の例は、配列の拡張と縮小を示しています。

```c
#include <stdio.h>
#include <stdlib.h>

int * my_function(int count) {
    // allocates the amount of bytes in an int, multiplied by count
    int * numbers = calloc(count, sizeof(int));
    return numbers;
}

int * my_function_2 (int * ptr , int count) {
    // reallocates the memory to the size of an int multiplied by count
    int * numbers = realloc(ptr, sizeof(int) * count);
    // if realloc fails, exit the program
    if (!numbers) exit(-1);
    return numbers;
}

int main() {
    int * numbers = my_function(3);
    if (!numbers) return -1;
    numbers[0] = 1;
    numbers[1] = 2;
    numbers[2] = 3;
    // expand the size of the array
    numbers = my_function_2(numbers, 6);
    // prints The first element of the array is 1
    printf("The first element of the array is %d\n", numbers[0]);
    // prints The sixth element of the array is [whatever is there]
    // the additional memory is not initialized, so it could be
    // 0 or it could be 18728 or anything else
    printf("The sixth element of the array is %d\n", numbers[5]);
    numbers[5] = 6;
    // shrink the size of the array
    numbers = my_function_2(numbers, 3);
    // prints The sixth element of the array is [whatever is there]
    // the removed memory is not initialized, so it could be
    // 6 or it could be 43164 or anything else
    printf("The sixth element of the array is %d\n", numbers[5]);
}
```
