# はじめに

整数は、単なる数値としてだけでなく、ビットの並びとしても見ることができます。Factorの[`math`][math]ボキャブラリーには、そうしたビットパターンに対する標準的な低レベル操作がそろっています。また、[`math.bitwise`][bitwise]ボキャブラリーには、固定幅の値を扱うための補助的なワードがいくつか追加されています。

## ビットシフト

`shift ( m n -- m' )`は、`m`のビットをシフトします。*正の*`n`は左シフト（1ステップごとに2倍）し、*負の*`n`は右シフト（1ステップごとに2で割る）します。

```factor
3 2 shift .     ! => 12   (3 << 2)
24 -3 shift .   ! => 3    (24 >> 3)
```

正の整数では、右シフトは下位のビットを落とし、0で埋めます。*負の*整数では、Factorの`shift`は算術シフトです。符号ビットを保ち、概念的には左側から符号ビットのコピーで埋めます。（Factorの整数は任意精度なので、「左側」は必要なだけどこまでも広がります。）

## ビット単位の論理演算

基本的な論理演算は次の4つです。

```
bitor  ( x y -- z )   ! 1 in either operand
bitand ( x y -- z )   ! 1 in both operands
bitxor ( x y -- z )   ! 1 in exactly one operand
bitnot ( x   -- z )   ! flip every bit
bit?   ( x n -- ? )   ! true when bit at position n is set
```

```factor
0b1011 0b0010 bitor .    ! => 11  (0b1011)
0b1011 0b0010 bitand .   ! => 2   (0b0010)
0b1011 0b0010 bitxor .   ! => 9   (0b1001)
0b1011 bitnot .          ! => -12
0b1011 0 bit? .          ! => t   (low bit is set)
0b1011 2 bit? .          ! => f   (bit 2 is clear)
```

`0b1011`の`bitnot`が`-12`になるのは、Factorの整数が任意精度だからです。`0b1011`のビットを反転させると、概念的には「すべて1で、下位4ビットが`0100`に反転したもの」になり、これを符号付きの多倍長整数として読むと`-12`になります。

## 値をNビットとして扱う

`math.bitwise`の`bits ( x n -- y )`は、`x`を下位`n`ビットにマスクします。これが、Factorで「値をNビットの符号なし整数として解釈し直す」方法です。

```factor
-1 8 bits .              ! => 255   (lowest 8 bits of -1 are all 1)
-2144333657 32 bits .    ! => 2150633639
```

2つ目の例は、この演習で重要になります。負の2の補数のInt32値から始めて、それを`amount`だけ「論理的」に右シフト（左から0で埋める）したい場合、Factorでの定型は次のとおりです。

```
( value -- shifted )
32 bits  amount neg  shift
```

まず32ビットにマスクして符号なしの解釈に切り替えてから、シフトします。マスク後の値は非負なので、`shift`は単に下位のビットを落として0で埋めます。
