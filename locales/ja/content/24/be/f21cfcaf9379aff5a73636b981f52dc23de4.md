# 数値

Crystalには`Number`という型があり、これはすべての数値型の基本となる型です。
`Number`型には、主に2つのサブタイプがあります。`Int`と`Float`です。

`Int`はintegerの略で、整数を表します。
`Int`は負の数にも正の数にもなり、小数点は持ちません。

```crystal
1.class
# => Int32

-1.class
# => Int32
```

`Float`は小数点を持つ数値を表します。
`Float`も負の数にも正の数にもなります。

```crystal
10.5.class
# => Float64
```

## `Int`と`Float`の変換

`to_i`と`to_f`メソッドを使うと、`Int`と`Float`の間で変換できます。
`Float`から`Int`に変換するときは、小数点以下が切り捨てられます。

```crystal
1.to_f
# => 1.0

1.0.to_i
# => 1

1.9.to_i
# => 1
```

## 算術演算子

`Int`と`Float`では、[基本的な算術演算子][math]を使えます。
演算子には`+`、`-`、`*`、`/`、`%`があります。
これらの演算子を使うときは、`Int`と`Float`を混ぜて使えます。

### 加算・減算・乗算

`+`演算子は加算、`-`演算子は減算、`*`演算子は乗算に使います。

| 演算子 | 例             |
| -------- | -------------- |
| `+`      | `4 + 6 => 10`  |
| `-`      | `15 - 10 => 5` |
| `*`      | `2 * 3 => 6`   |

### 除算

除算は、数値を割るために使います。
除算には`/`演算子を使います。
結果は常に`Float`になります。

```crystal
4 / 2
# => 2.0

4.0 / 2
# => 2.0
```

~~~~exercism/caution
プログラミング言語によっては、0で割るとエラーになります。

Crystalでは、0で割ったときの結果は`Infinity`か`-Infinity`になります。
唯一の例外は0を0で割った場合で、結果は`NaN`（非数）になります。
`Infinity`と`NaN`は、`Float`型にある特別な値です。

```crystal
1 / 0
# => Infinity

-1 / 0
# => -Infinity

0 / 0
# => NaN
```
~~~~

## 整数の除算

整数の除算は、数値を割って、結果の整数部分を得るために使います。
結果は常に切り捨てられて`Int`になります。

```crystal
4.0 // 2
# => 2

4.5 // 2
# => 2
```

~~~~exercism/caution
整数の除算で0で割ると、`DivisionByZeroError`になります。
これは通常の除算とは異なります。
~~~~

### 余り

余りを求めるには、この演算を使います。
余りを求めるには、`%`演算子を使います。

```crystal
5 % 2
# => 1

5.0 % 2
# => 1.0

5 % 3
# => 2
```

~~~~exercism/caution
余りを求める演算で0で割ると、DivisionByZeroErrorになります。
これは通常の除算とは異なります。

```crystal
1 % 0
# Error: Unhandled exception: Division by 0 (DivisionByZeroError)
```
~~~~

## 累乗

累乗は、数をべき乗するために使います。
累乗には`**`演算子を使います。
`Float`と`Int`の演算結果は`Float`になります。

```crystal
2 ** 2
# => 4

2.0 ** 2
# => 4.0
```

## 丸め

`round`メソッドは、省略可能な引数を取ります。丸める小数点以下の桁数です。
小数点以下の桁数の既定値は0です。

```crystal
1.0.round
# => 1

1.5.round
# => 2

1.234.round(2)
# => 1.23
```

### 切り上げと切り捨て

`ceil`と`floor`メソッドを使うと、`Int`に切り上げたり切り捨てたりできます。
`ceil`メソッドは切り上げ、`floor`メソッドは切り捨てを行います。

```crystal
1.0.ceil
# => 1

1.2.ceil
# => 2

1.7.floor
# => 1
```

## 優先順位と括弧

Crystalでは括弧（`()`）を使え、これを使って式をまとめられます。
これは、演算の順序を変えたいときに便利です。

複数の算術演算子を使うとき、演算の順序は数学と同じで、[PEMDAS][pemdas]として知られています。
これは、括弧（`()`）、指数（`**`）、乗算（`*`）と除算（`/`）、加算（`+`）と減算（`-`）の順に従います。

```crystal
2 + 3 - 4 * 4
# => -11

(2 + 3 - 4) * 4
# => 4
```
