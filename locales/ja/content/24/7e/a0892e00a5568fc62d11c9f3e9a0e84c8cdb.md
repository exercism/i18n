# 説明

通常の数値をローマ数字に変換する関数を書きましょう。

ローマ人は賢い人々でした。
ヨーロッパの大部分を征服し、何百年もの間支配しました。
コンクリートやまっすぐな道、さらにはビキニまで発明しました。
ただ、彼らが決して発見できなかったものが一つあります。ゼロという数です。
そのため、彼らの偉業を詳しく記録し、年代を記すのは少し難しくなりましたが、彼らが考案した数の仕組みは今でも使われています。
たとえば、BBCは番組の年をローマ数字で表しています。

ローマ人は、文字を使って数を書きました。I・V・X・L・C・D・Mです。
（これらの文字は直線が多く、そのため石版に刻むのが簡単だったことに注目してください）。

```text
 1  => I
10  => X
 7  => VII
```

この表記法で表せる最大の数は3,999です。
（ローマ人自身は、それ以上を使うことはあまりありませんでした）

Wikipediaにはこう書かれています。現代のローマ数字は…左端の桁から順に各桁を個別に表すことで書かれ、値が0の桁は飛ばします。

実際に確かめるために、1990を例に見てみましょう。

ローマ数字で1990はMCMXCです。

1000=M
900=CM
90=XC

2008はMMVIIIと書きます。

2000=MM
8=VIII

ローマ数字について詳しくは、[Wikipediaのローマ数字][roman-numerals]をご覧ください。

[roman-numerals]: https://wiki.imperivm-romanvm.com/wiki/Roman_Numerals
