# 説明

ラリーは、ゲームをプレイするためのコードを書くのが好きなLispの宇宙人です。
今日は、三目並べによく似たゲームで役立ついくつかの関数を書きたいと思っています。

三目並べと同じように、このゲームは3x3のマス目からなるボードの上で遊びます。

## 1. ゼロから始める

まず、ラリーには空白のボードを作る関数`make-empty-board`が必要です。
ボードのすべてのマスは`NIL`である必要があります。

```lisp
(make-empty-board) ; => #2A((NIL NIL NIL) (NIL NIL NIL) (NIL NIL NIL))
```

## 2. 既存のボードから始める

次に、ラリーには行のリストからボードを作る関数が必要です。
たとえば、次のとおりです。

```lisp
(make-board-from-list '((A B C) (D E F) (G H I))) ; => #2A((A B C) (D E F) (G H I))
```

## 3. 勝利条件

同じ記号が一列に3つ並んだ場合、そのプレイヤーの勝ちです。
ラリーには、3つの要素からなる配列を受け取り、すべての要素が同じ記号であれば`T`と評価される関数`all-the-same-p`が必要です。
（2つの記号が同じかどうかを調べるには、`eq`を使えます。）

```lisp
(all-the-same-p #(A A A)) ; => T
(all-the-same-p #(A B C)) ; => NIL
```

## 4. 行

次に、ラリーには行の要素を取得する方法が必要です。
関数`row`は、ボードと行番号を受け取り、その行の要素を配列として返します。

```lisp
(row #2A((1 2 3) (4 5 6) (7 8 9)) 1) ; => #(4 5 6)
```

## 5. 列

最後に、ラリーには列の要素を取得する方法が必要です。
関数`column`は、ボードと列番号を受け取り、その列の要素を配列として返します。

```lisp
(column #2A((1 2 3) (4 5 6) (7 8 9)) 1) ; => #(2 5 8)
```
