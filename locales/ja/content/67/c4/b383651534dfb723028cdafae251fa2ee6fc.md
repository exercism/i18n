# 説明

ABAPの内部テーブルの基本を学びましょう。

クラスには、`initial_data`という名前の内部テーブルがあります。このテーブルには、`GROUP`、`NUMBER`、`DESCRIPTION`という3つの列があります。

```abap
TYPES group TYPE c LENGTH 1.
TYPES: BEGIN OF initial_type,
         group       TYPE group,
         number      TYPE i,
         description TYPE string,
       END OF initial_type,
       initial_data TYPE STANDARD TABLE OF initial_type WITH EMPTY KEY.
```

## ステップ1

最初のタスクは、メソッド`fill_itab`を完成させ、次の値を持つ6件のレコードをこのテーブルに入れることです。

| GROUP | NUMBER | DESCRIPTION |
| --- | ----------- | ----------- |
| A | 10 | Group A-2 |
| B | 5 | Group B |
| A | 6 | Group A-1 |
| C | 22 | Group C-1 |
| A | 13 | Group A-3 |
| C | 500 | Group C-2 |

## ステップ2

次に、メソッド`add_to_itab`を実装して、次の値を持つレコードを内部テーブルの末尾に追加しましょう。

| GROUP | NUMBER | DESCRIPTION |
| --- | ----------- | ----------- |
| A | 19 | Group A-4 |

## ステップ3

では、メソッド`sort_itab`で内部テーブルを並べ替えましょう。`GROUP`列をアルファベット順に、`NUMBER`列を降順に並べます。

## ステップ4

メソッド`search_itab`では、並べ替え済みのテーブルを検索し、`NUMBER`列の値が6であるレコードのインデックスを返します。
