# 概要

Haxeでは、_継承_を使ってクラスの階層を定義できます。継承を使うと、派生クラス（`Car`）が親クラス（`Vehicle`）の振る舞いとデータを受け継ぐことができます。

親クラスでは、次のことができます。

- オーバーライドできるメソッド
- 派生クラスで必ず実装しなければならない抽象メソッド

```haxe
abstract class Vehicle {
  public function new() {}

  // Can be overridden
  public function drive() {
    // ...
  }

  // Must be implemented
  public abstract function getSpeed():Int;
}

class Car extends Vehicle {
  public function new() {
    super(); // Runs the parent class' constructor
  }

  public override function drive() {
    // ...
  }

  public function getSpeed():Int {
    // ...
  }
}
```

親クラスにコンストラクターがある場合は、`super()`でそれを呼び出します。

```haxe
abstract class Vehicle {
  var wheels:Int;

  public function new(wheels:Int) {
    this.wheels = wheels
  }
}

class Car extends Vehicle {
  var color:String;

  public function new(wheels:Int, color:String) {
    super(wheels);
    this.color = color;
  }
}

```
