# デバッグ

YSには、解答コードのデバッグに役立つ組み込みの`DBG`関数があります。
`DBG`は任意の数の引数を受け取り、それらをstderrに出力します。
最後の引数を返すので、コードの中にそのまま埋め込んで使うこともできます。

`.DBG()`のショートカットである`.>`インライン演算子も使えます。

サンプルのコードファイルを次に示します。

```yaml
# file: program.ys

!YS-v0

defn do-it(nums):
  x =: 5

  DBG: -'my vars' x nums

  nums: .map(\(_ * x)).>
        .reverse().>
        .map(str).>
        .join(' - ')

say: do-it(3 .. 5)
```

このコードを`ys`で実行すると、次のような出力が表示されます。

```txt
>>>
"my vars"
5
(3 4 5)
<<<
>>>(15 20 25)<<<
>>>(25 20 15)<<<
>>>("25" "20" "15")<<<
25 - 20 - 15
```


## コンパイル

問題を突き止めるもう1つのよくある方法は、YSコードがコンパイルされたあとのClojureコードを見ることです。

これには、`ys`コマンドラインインタプリターを`-c`フラグ付きで実行します。

先ほどの`program.ys`ファイルをコンパイルすると、次のようになります。

```clojure
$ ys -c program.ys
(defn do-it [nums]
 (let [x 5]
  (DBG "my vars" x nums)
  (join
   (DBG
    (+map
     (DBG (reverse (DBG (+map nums (fn [& [_1]] (mul+ _1 x))))))
     str))
   " - ")))
(say (do-it (rng 3 5)))
```

`.>`演算子が`DBG`関数呼び出しにコンパイルされているのが、はっきりわかります。
