# 2進数、8進数、16進数

2進数、8進数、16進数（_hexとも呼ばれます_）は、それぞれ基数の異なる[記数法][numeral-systems]です。
2進数は基数2、8進数は基数8、16進数は基数16です。
Pythonでは、通常の整数は基数10です。
2進数、8進数、16進数はどれも整数の表現方法です。
つまり、小数や分数を使わずに正の数と負の数（_ゼロを含む_）を表し、整数でできるすべての演算をサポートするということです。

## 2進数

[2進数][binary]は基数2の記数法で、0と1の数字だけを使います。
コンピューターのトランジスタやスイッチを流れる電気の0（「オフ」）と1（「オン」）の状態や、磁気記憶媒体の正負の電荷を表すためによく使われます。
2進数は、基数10で使われるすべての整数を表せます。

基数2の体系の一部を抜き出すと次のようになります。ただしこれは無限に続き、128で止まるわけではありません。

| 128      | 64       | 32       | 16       | 8        | 4        | 2        | 1        |
| -------- | -------- | -------- | -------- | -------- | -------- | -------- | -------- |
| 2 \*\* 7 | 2 \*\* 6 | 2 \*\* 5 | 2 \*\* 4 | 2 \*\* 3 | 2 \*\* 2 | 2 \*\* 1 | 2 \*\* 0 |

では、数値6を2進数で表すと、110になります。

| 位の値   | 4   | 2   | 1   |
| ------------- | --- | --- | --- |
| 2進数 | 1   | 1   | 0   |

計算は次のようになります：`4 + 2 + 0 = 6`

もう1つの例：19

| 位の値   | 16  | 8   | 4   | 2   | 1   |
| ------------- | --- | --- | --- | --- | --- |
| 2進数 | 1   | 0   | 0   | 1   | 1   |

2進数では10011になります。
計算は次のようになります：`16 + 0 + 0 + 2 + 1 = 19`

## Pythonでの2進数

Pythonでは、`0b`プレフィックスを使って2進数のリテラルを表せます。
`0b10011`と書くと、Pythonはそれを2進数として解釈し、基数10に変換します。

```python
>>> 0b10011
19

>>> type(0b10011)
<class 'int'>
```

Pythonの2進数は、整数を別の書き方で表したものにすぎません。そのため、2進数表現は**整数そのもの**であり、すべての数学演算に使えます。

`0b`プレフィックスを付けた数値が2進数として正しくない場合、`SyntaxError`が発生します。

```python
Traceback (most recent call last):
  File "c:\binary.py", line 1, in <module>
    0b10211
SyntaxError: invalid digit '2' in binary literal
```

### 2進数を使った演算

2進数は整数なので、整数でできるすべての演算を実行できます。

```python
# addition
>>> 0b10011 + 0b10011
38

# multiplication
>>> 0b10011 * 0b10011
361
```

2進数と整数の表現の間でも演算を行えます。
ただし、通常の数学の演算子のルールが適用されます。2つの2進数や整数を割り算すると、割り切れて小数部分が出なくても、結果は`float`になります。

```python
>>> 0b10011 + 19
38

>>> 0b10011/0b10011
1.0

>>> 0b10011/3
6.333333333333333
```


### 2進数表現の相互変換

Pythonは2進数のリテラルを自動的に`int`に変換します。
`int`を2進数表現に変換するには、組み込みの[`bin()`][bin]関数を使います。
`bin()`は、`0b`プレフィックスが付いた2進数の等価な値を`str`として返します。

```python
>>> bin(19)
'0b10011'
```

2進数のリテラルを整数に変換するには、組み込みの`int()`関数を使い、2進数表現の文字列と基数の引数を渡します。

```python
>>> int("0b10011", 2)
19
```

基数を間違えると（_または2進数表現として無効な場合_）、`ValueError`が発生します。

```python
Traceback (most recent call last):
  File "c:\binary.py", line 4, in <module>
    int("0b10011", 3)
ValueError: invalid literal for int() with base 3: '0b10011'
```

### 2進数のメソッド

2進数に対して使える特別な[メソッド][numeral-systems]もいくつかあります。


[`<int>.bit_length()`][bit_length]は、その数値を表すのに必要なビット数を返します。

```python
>>> 0b11011.bit_length()
5
```


[`<int>.bit_count()`][bit_count]は、2進数の中にある**1**の個数を返します。
たとえば、'0b11011'に対して`bit_count()`を呼び出すと4が返ります。

```python
>>> 0b11011.bit_count()
4
```

## 8進数

[8進数][octal]は基数8の記数法です。
0、1、2、3、4、5、6、7の数字を使います。

Pythonでは、`0o`プレフィックスを使って8進数を表せます。
2進数のときと同じく、Pythonは8進数の表現を自動的に`int`に変換します。

```python
>>> 0o123
83
```

2進数のときと同じく、8進数は**intです**。すべての整数演算をサポートします。
`0o`プレフィックスを付けた数値が8進数として正しくない場合、`SyntaxError`が発生します。

### 8進数表現の相互変換

`int`を8進数表現に変換するには、組み込みの[`oct()`][oct]関数を使えます。
これは`bin()`関数と同じように動作し、文字列を返します。

```python
>>> oct(83)
'0o123'
```


8進数を整数に変換するには、`int()`関数を使い、8進数表現の文字列と基数（8）を引数として渡します。

```python
>>> int("0o123", 8)
83
```

2進数のときと同じく、基数を間違えると`ValueError`が発生します。

## 16進数

[16進数][hexadecimal]は基数16の記数法です。
0から9までの数字と、A、B、C、D、E、Fの文字を使います。
Aは10、Bは11、Cは12、Dは13、Eは14、Fは15です。

Pythonでは、`0x`プレフィックスを使って16進数を表せます。
2進数や8進数のときと同じく、Pythonは16進数のリテラルを自動的に`int`に変換します。

```python
>>> 0x123
291
```

2進数や8進数のときと同じく、16進数のリテラルは**intです**。すべての整数演算を実行できます。
16進数でない数値に`0x`を付け加えると、`SyntaxError`が発生します。


### 16進数表現の相互変換

`int`を16進数表現に変換するには、組み込みの[`hex()`][hex]関数を使えます。
これは`bin()`関数と同じように動作し、文字列を返します。

```python
>>> hex(291)
'0x123'
```


16進数表現を整数に変換するには、`int()`関数を使い、16進数の文字列と基数（16）を引数として渡します。

```python
>>> int("0x123", 16)
291
```

2進数や8進数のときと同じく、基数を間違えると`ValueError`が発生します。
