# 概要

Elmは完全な関数型言語なので、文はなく、式だけが存在します。関数も常に1つの式です。

そのため、関数は小さくシンプルに保たれます。これは一般的には良いことですが、どうしても複雑になってしまう関数もあり、そうした関数をエレガントに書くための仕組みが必要になります。

ここで登場するのが`let`式です。`let`式には2つの部分があります。必要なだけ定義を書ける`let`の部分と、その定義を使える単一の式である`in`の部分です。

コンピューターサイエンスの言葉で言えば、`let`は`in`の式にローカルなスコープを作ります。

`let`式は、次のようないくつかの場面で役立ちます。

- 式を簡潔にするとき
- 途中の式の結果に名前を付けるとき
- 式が大きくなってきたときに、より小さな部分に分割するとき

`let`式の中では、分割代入を含め、ほとんどのことができます。ただし、次のことはできません。

- カスタム型
- 型エイリアス
- 名前のシャドーイング（すでにスコープにある名前を再定義したり、再利用したりすることはできません）

## 式を簡潔にする

この式は3つの数の3乗を足し合わせますが、読みにくく、数ごとに計算が食い違ってしまいがちです。

```elm
(a * a * a) + (b * b * b) + (c * c * c)
```

`let`式の中で`cube`関数を定義すれば、計算をよりシンプルに、より表現豊かに、そしてより安全にできます。この関数には型注釈を付けられますが、慣用的なElmのコードではあまり見かけません。

```elm
let
  cube x = x * x * x
in
  cube a + cube b + cube c
```

## 途中の式の結果に名前を付ける

このコードでは、計算をよりシンプルで表現豊かにするためにsideAreaとtopAreaを定義しています。

```elm
cylinderArea : Float -> Float -> Float
cylinderArea radius height =
    let
        sideArea = 2 * pi * radius * height
        topArea = pi * radius ^2
    in
        sideArea + 2 * topArea
```

## 大きな式を分割する

このコードは、[Game of Life](https://playgameoflife.com/)（プログラミングの例題としてよく使われるものです）の初期パターンを作ります。

これがどのように動くかを正確に理解する必要はありませんが、`let`を使わずに1つの式として書いたら、とても大きくなってしまうことはすぐにわかるでしょう。

```elm
beginWithPattern : Size -> Padding -> Pattern -> GameOfLife
beginWithPattern minimumSize padding pattern =
    let
        size = calculateSize minimumSize padding pattern

        center = Size.center size

        centeredPattern = Pattern.centerAt center pattern

        dimensions = { width = size, height = size }

        deadCells = Matrix.create dimensions Dead
    in
    GameOfLife (bringPatternToLife deadCells centeredPattern)
```
