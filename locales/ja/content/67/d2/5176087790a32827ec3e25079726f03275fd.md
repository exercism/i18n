# 説明

友人のLi Meiは、おいしいミックスフルーツジュースを売るジュースバーを営んでいます。よくこの店に通っていたので、友人の仕事を楽にしてあげられることに気づきました。そこで、プログラミングのスキルを活かして、Li Meiの仕事を手伝うことにしました。

## 1. ジュースを混ぜるのにかかる時間を求める

Li Meiは、お客さんがメニューから注文したジュースについて、どれくらい待てばよいかを事前に伝えるのが好きです。ジュースを混ぜるのにかかる時間はまちまちなので、正確な数字を覚えておくのが苦手です。
`"Pure Strawberry Joy"`は0.5分、`"Energizer"`と`"Green Garden"`はそれぞれ1.5分、`"Tropical Island"`は3分、`"All or Nothing"`は5分かかります。
それ以外の飲み物（たとえば特別メニューなど）は、準備に2.5分かかると想定してかまいません。

友人を手伝うために、メニューのジュースを入力として受け取り、その飲み物を混ぜるのにかかる分数を返す関数`time_to_mix_juice`を書いてみましょう。

```R
time_to_mix_juice("Tropical Island")
# => 3

time_to_mix_juice("Berries & Lime")
# => 2.5
```

## 2. ライムウェッジの在庫を補充する

Li Meiが作る飲み物の多くには、材料として、あるいは飾りとして、ライムウェッジが入っています。そのため、朝のシフトが始まるときには、その日のためにライムウェッジの容器をいっぱいにしておく必要があります。

関数`limes_to_cut`を実装しましょう。この関数は、Li Meiが切る必要のあるライムウェッジの数と、手元にある丸ごとのライムの在庫を表す配列を入力として受け取ります。
`"small"`のライムからは6個、`"medium"`のライムからは8個、`"large"`のライムからは10個のウェッジが取れます。
Li Meiはいつも、リストの先頭から順にライムを切っていきます。必要な数に達するか、ライムがなくなるまで切り続けます。

Li Meiは、切る必要のあるライムの数を事前に知りたいと思っています。
`limes_to_cut`関数は、切るライムの数を返すようにしましょう。

```R
limes_to_cut(25, c("small", "small", "large", "medium", "small"))
# => 4
```

## 3. 待ち行列にある各注文を混ぜる時間を一覧にする

Li Meiは、お客さんが待っている注文を混ぜるのにどれくらい時間がかかるかを、モニターで把握するのが好きです。

関数`order_times`を実装しましょう。この関数は注文の待ち行列を入力として受け取り、それぞれを作るのにかかる時間を`stdout`に*出力*します。

```R
order_times(c("Energizer", "Tropical Island"))
# => 1.5 
# => 3
```

~~~~exercism/note
このタスクは`stdout`への出力を必要とする点で、Exercismの中ではかなり珍しいものです。
Exercismの演習タスクのほとんどは、戻り値やその他の副作用を必要とします。
~~~~

## 4. シフトを終える

Li Meiはいつも15時まで働きます。
その後は、従業員のDmitryが引き継ぎます。
Li Meiのシフトが終わる時点で、注文されたもののまだ準備できていない飲み物がよくあります。
そんなときは、Dmitryが残りのジュースを準備します。

引き継ぎを楽にするために、関数`remaining_orders`を実装しましょう。この関数は、Li Meiのシフトに残された分数と、注文されたもののまだ準備できていないジュースの配列を入力として受け取ります。
この関数は、Li Meiが退勤前に準備を始められない注文を返すようにしましょう。

シフトに残された時間は、常に0より大きくなります。
準備するジュースの配列が空になることはありません。
また、注文は配列に並んでいる順に準備します。
Li Meiが何かのジュースを混ぜ始めたら、少し長く働くことになっても、必ずそれを最後まで作り終えます。
Dmitryが対応する必要のある注文が1つも残っていない場合は、空のベクトルを返すようにしましょう。

```R
remaining_orders(5, c("Energizer", "All or Nothing", "Green Garden"))
# => c("Green Garden")
```
