# はじめに

Pythonの辞書（`dict`）は、[ハッシュ可能][term-hashable]な_キー_と_値_を対応付けるデータ構造で、他のプログラミング言語ではサイズを変更できる[ハッシュテーブル][hashtable-wikipedia]、ハッシュマップ、[連想配列][associative-array]などと呼ばれます。
辞書は、Pythonに組み込みで用意されている唯一の[マッピング型][mapping-types-dict]です。


`keys`はハッシュ可能で、辞書全体で一意でなければなりません。
キーの型には、`number`、`str`、`tuple`（_イミュータブル_な値）などがあります。
キーに、`list`、`dict`、`set`のような_ミュータブル_なデータ構造を使うことはできません。
Python 3.7以降、`dict`のキーの順序は、要素を挿入した順序になることが保証されています。

`values`は、どのようなデータ型やデータ構造でもかまいません。
 値は_自由に_入れ子にできるので、リストのリスト、サブ辞書、その他のカスタムまたは複合的なデータ構造を含めることができます。

`key`がわかれば、辞書は（平均して）一定の時間で`value`を取り出すことができます（_要素の数に依存しません_）。
`list`や`array`の中から値を探す場合（_`index`の位置がわからない場合_）と比べて、`dict`はメモリを大幅に多く使いますが、取り出しはとても高速です。

辞書は、要素の集まりが大きく、頻繁にアクセスしたり更新したりする必要がある場面で特に役立ちます。
