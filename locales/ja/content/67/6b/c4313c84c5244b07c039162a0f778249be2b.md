# 手順

友人のJohannesは、DIY（自分で作る）ハードウェアを作るのが大好きです。Johannesはちょうどジュースメーカーを作ったばかりで、とても興奮しています。Johannesの目標は、毎朝新鮮なジュースを作れるようになることです。

Johannesのジュースメーカーは、さまざまな容量に設定できます。Johannesはプログラミングが得意ではありませんが、機械を制御するプログラムを作りたいと考えています。そこで、Johannesから助けてほしいと頼まれました。

## 1. `JuiceMaker`クラスを作成する

`JuiceMaker`クラスを作成します。このクラスには、次の2つのプロパティも渡されます：
- ミリリットル単位の`capacity`（`Int`型）
- メーカーから出るジュースで満たされる`jug`（`Jug`オブジェクト）

## 2. 容量が1,000ミリリットルを超える場合は`jug`を拡張する

容量が1,000ミリリットルを超える場合、ジュースを入れておけるように`jug`を拡張する必要があります。`JuiceMaker`クラスを更新して、1,000ミリリットルを超える容量で生成されたときに`jug`を拡張する（`extend`関数を呼び出す）ようにします。

## 3. スターターをインストールする

モデルによっては、実行するのに何年もかかるような非常に複雑な起動手順があります。幸いなことに、これを速めるための特別なスターターが作られています。

複雑な起動手順を持つモデルをサポートするには、`Starter`オブジェクトも受け取る別のコンストラクターを追加します。このコンストラクターは、`install`関数を呼び出して自身をジュースメーカーにインストールする必要があります。

## 4. `start`関数を追加する

速度を受け取る`start`関数を追加します。ジュースメーカーはその速度で動作し続けます。

## 5. `stop`関数を追加する

ジュースメーカーを停止する`stop`関数を追加します。

## 6. `lightColor`関数を追加する

機械には、どの速度で動作しているかを示すライトがあります。ライトの色は、動作している速度によって変わります：

| 速度 | 色 |
|---|---|
| オフ | red |
| 3以下 | green |
| 3より大きい | yellow |

色を返す`lightColor`関数を追加します。

# 7. よく使われる容量で作る

多くのジュースメーカーを作ったあと、Johanneはよく使われる容量が1,500ミリリットルであることに気づきます。この設定を簡素化するために、ヘルパー関数`buildWithCommonCapacity`を実装します。この関数は`JuiceMaker`クラスの外側で定義する必要があります。
