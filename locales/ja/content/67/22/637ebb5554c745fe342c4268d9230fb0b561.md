# 説明

文字列として表された2進数（例：'101010'）を、基本原理に基づいて10進数に変換します。

2進数から10進数への変換を実装します。
2進数の入力文字列が与えられたら、プログラムは10進数の出力を生成するようにします。
また、不正な入力を処理できるようにします。

## 注意

- 変換は自分で実装してください。
  変換を代わりに行ってくれるものを使用しないでください。

## 2進数（基数2）について

10進数は基数10の体系です。

基数10で表された数23は、10の累乗の線形結合として理解できます。

- 一番右の桁には10^0 = 1が掛けられます
- その次の桁には10^1 = 10が掛けられます
- ...
- n番目の桁には10^_(n-1)_が掛けられます
- これらの値がすべて足し合わされます

つまり、`23 => 2*10^1 + 3*10^0 => 2*10 + 3*1 = 23 base 10`です。

2進数も似ていますが、10の累乗ではなく2の累乗を使います。

つまり、`101 => 1*2^2 + 0*2^1 + 1*2^0 => 1*4 + 0*2 + 1*1 => 4 + 1 => 5 base 10`です。
