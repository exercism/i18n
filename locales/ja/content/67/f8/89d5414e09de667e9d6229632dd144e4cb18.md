# 概要

ビット単位の2進演算は、[Bitwiseモジュール][bitwise-hexdocs]の関数を使って整数に対して行うことができます。

- [`band/2`][bitwise-and]: ビット単位のAND
- [`bsl/2`][bitwise-shift-left]: ビット単位の左シフト
- [`bsr/2`][bitwise-shift-right]: ビット単位の右シフト
- [`bxor/2`][bitwise-xor]: ビット単位のXOR
- [`bor/2`][bitwise-or]: ビット単位のOR
- [`bnot/1`][bitwise-not]: ビット単位のNOT

```elixir
Bitwise.band(0b1110, 0b1001)
# => 8 # 0b1000

Bitwise.bxor(0b1110, 0b1001)
# => 7 # 0b0111
```
