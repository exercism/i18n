# はじめに

メソッドは、特別な_receiver_（レシーバー）引数を持つ関数です。
レシーバーは、`func`キーワードとメソッド名の間にある専用の引数リストに書きます。

```go
func (receiver type) MethodName(parameters) (returnTypes) {

}
```

メソッドを定義できるのは、そのメソッドと同じパッケージで定義された型をレシーバーにする場合だけです。

```go
type Person struct {
    Name string
}

func (p Person) Greetings() string {
	return fmt.Sprintf("Welcome %s!", p.Name)
}

s := Person{Name: "Bronson"}
fmt.Println(s.Greetings())
// Output: Welcome Bronson!
```

レシーバーには、値レシーバーとポインターレシーバーの2種類があります。

値レシーバーを持つメソッドは、渡された値のコピーに対して操作を行います。つまり、メソッドの中でレシーバーに加えた変更は、呼び出し元には見えません。

レシーバーが指す値を変更するには、ポインターレシーバーを持つメソッドを宣言します。
これは、型名の前に`*`を付けることで行います。たとえば`rect`型なら、ポインターレシーバーは`*rect`と宣言します。
このような変更は、メソッドの呼び出し元からも見えます。

```go
type rect struct {
	width, height int
}
func (r *rect) squareIt() {
	r.height = r.width
}

r := rect{width: 10, height: 20}
fmt.Printf("Width: %d, Height: %d\n", r.width, r.height)
// Output: Width: 10, Height: 20

r.squareIt()
fmt.Printf("Width: %d, Height: %d\n", r.width, r.height)
// Output: Width: 10, Height: 10

```
