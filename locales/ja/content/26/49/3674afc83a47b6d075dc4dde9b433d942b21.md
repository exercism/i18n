# インストール

このトラックでは、Wrenをローカルで動かすためのランタイムとして、全体を通して[Wren Console][wren-console]を利用しています。つまり、お使いのコンピューターでWrenを実行するときは、すべて[Wren Console][wren-console]を使うことを前提としています。公式のWrenの<abbr title="コマンドラインインターフェース">CLI</abbr>と混同しないでください。本来ならそのランタイムを使うこともできますが、現時点では[いくつ](https://github.com/wren-lang/wren-cli/pull/74)[かの](https://github.com/wren-lang/wren/pull/1006)[異なる](https://github.com/wren-lang/wren-cli/issues/108)[問題](https://github.com/wren-lang/wren-cli/pull/105)があり、ExercismでWrenを学ぶにはあまり適した選択とは言えません。

Wren ConsoleはWren CLIをフォークしたもので、こうした問題を解決し、学習体験をよりスムーズにする機能を追加しています。心配はいりません。ここで学ぶWrenの言語知識や概念は、将来Wrenをどこで使いたいと思ってもそのまま役立ちます。

## インストールの概要

- `git`コマンドを使えるようにGitをインストールします
- `wrenc`コマンドを使えるように[Wren Console][wren-console]をインストールします

### Gitのインストール

`git`のバイナリがインストールされ、`PATH`が通っている必要があります。Wren Packageがパッケージ（演習のテストに必要なテストスイートなど）をインストールするときにも、この`git`を使います。

- **Windows** - 公式の[Gitのダウンロード](https://git-scm.com/download/win)から始めるのがよいでしょう。
-  **Linux** - お好みのパッケージマネージャーを使えばよいでしょう。
- **Mac** - 最近のバージョンのMac OSには、`git`が最初から入っています。

Gitがインストールされているかは、`git --version`で確認できます：

```
$ git --version
git version 2.31.1
```

バージョンが完全に一致していなくても心配いりません。通常、それほど重要ではありません。


### Wren Consoleのインストール

#### Windows

GitHubから[最新リリースをダウンロード][releases]するのがよいでしょう。その後、zipを展開し、`wrenc`の実行ファイルを`PATH`が通った場所にコピーします。

Visual Studioを使って[ソースからビルド][build-from-source]することもできます。

#### Linux

GitHubから[最新リリースをダウンロード][releases]するか、[ソースからビルド][build-from-source]します。

```sh
wget -c https://github.com/joshgoebel/wren-console/releases/download/v0.3.1/wren-console-v0.3.1-linux.tar.gz
tar xzf wren-console-v0.3.1-linux.tar.gz
```

そして、`PATH`から使えるようにしておいてください。

```sh
cp bin/wrenc /usr/local/bin/
```


#### Mac

もっとも簡単なのは、Exercismの[Homebrew][homebrew]のtapとformulaを使う方法です：

```
brew tap exercism/wren
brew install wren-console
```

または、GitHubから[最新リリースをダウンロード][releases]して、Linuxの手順で示したように手動でインストールすることもできます。そうしたことに慣れていれば、ソースからのビルドもとても簡単です。

### インストールの確認

バイナリが正しくインストールできたと思ったら、すべてが動作するかテストしておくとよいでしょう。

1. _ターミナル_（`Terminal`、`cmd`、`Powershell`、`bash`、...）を開きます
2. `wrenc -v`を実行します

`wrenc`とWrenの両方のバージョンが表示されるはずです：

```
wrenc v0.3.1 (wren v0.4.0)
```

**注意**：_新しい_ターミナルウィンドウを開くことが重要です。すでに開いているターミナルウィンドウは、インストールが完了したあとに更新されていない可能性があります。つまり、開いたままのターミナルは、新しいプログラムがインストールされたことを認識していないのです。

> _**ヘルプ**_: `'wrenc' is not recognised`
>
> `wrenc`を`PATH`に入れていないのでしょう…。MacOSとLinuxでは、次のいずれかを`~/.bash_profile`または`~/.zshrc`に追加するとパスを変更できます：
>
> ```bash
> export PATH=/path/to/your/wrenc/:$PATH
> ```
> **これが正しいかどうかは、まったくわかりません。**
> Windowsではスタートメニューを開いて「environment variables」を検索してください。`PATH`の項目を編集し、ここに`wrenc`のバイナリへのパスを_追加_する必要があります。通常、これらは`C:\Program Files\nodejs`にあります。ここを`File Explorer`で開くと、`node.exe`、`npm.bat`、`npx.bat`が見つかるはずです。
>
> 開いているターミナルをすべて閉じて、新しいターミナルを開いてください。

## 演習の要件

お使いのOS用の`exercism` CLIをダウンロードするには、[こちらの手順][cli-walkthrough]に従ってください。

CLIのセットアップと設定が完了したら、最初の演習`hello-world`をダウンロードします：

```bash
$ exercism download --exercise=hello-world --track=wren
```

各演習では、テストを実行するためにいくつかのWrenパッケージが必要です。これらは、演習のディレクトリで次のコマンドを実行するとインストールできます：

```bash
$ wrenc package.wren install
```
