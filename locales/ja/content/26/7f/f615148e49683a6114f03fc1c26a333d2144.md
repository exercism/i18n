# 説明

複素数は、`a + b * i`という形で表される数です。ここで`a`と`b`は実数で、`i`は`i^2 = -1`を満たします。

`a`を実部、`b`を`z`の虚部といいます。
`a + b * i`の共役は、`a - b * i`です。
複素数`z = a + b * i`の絶対値は、実数`|z| = sqrt(a^2 + b^2)`です。絶対値の2乗`|z|^2`は、`z`にその複素共役を掛けた結果です。

2つの複素数の和や差は、それぞれの実部と虚部を別々に足したり引いたりして求めます。
`(a + i * b) + (c + i * d) = (a + c) + (b + d) * i`,
`(a + i * b) - (c + i * d) = (a - c) + (b - d) * i`.

掛け算の結果は、定義により次のようになります。
`(a + i * b) * (c + i * d) = (a * c - b * d) + (b * c + a * d) * i`.

0でない複素数の逆数は、次のようになります。
`1 / (a + i * b) = a/(a^2 + b^2) - b/(a^2 + b^2) * i`.

複素数`a + i * b`を別の複素数`c + i * d`で割ると、次のようになります。
`(a + i * b) / (c + i * d) = (a * c + b * d)/(c^2 + d^2) + (b * c - a * d)/(c^2 + d^2) * i`.

eの複素数乗は、`e^(a + i * b) = e^a * e^(i * b)`と表せます。この最後の項は、オイラーの公式`e^(i * b) = cos(b) + i * sin(b)`で与えられます。

次の演算を実装してください。
 - 2つの複素数の足し算、引き算、掛け算、割り算
 - 与えられた複素数の共役、絶対値、指数


使っているプログラミング言語に複素数の実装がないものとします。
