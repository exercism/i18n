# 概要

Swiftにおける[クロージャ][closures]は、自己完結したコードのブロックです。パラメータを渡すと計算が実行され、値が返されます。
クロージャはまた、自分の環境から値を取り込み、その値を使って計算を行います。
自己完結しているため、プログラム内では他の値と同じように受け渡したり、定数や変数に代入したりできます。

クロージャはSwiftの関数とよく似ていると感じられるかもしれません。実際そのとおりで、それにはちゃんとした理由があります。
Swiftの関数はクロージャの特別な場合であり、名前を持つ必要があり、少し異なる構文で定義します。

Swiftの関数は厳密にはクロージャですが、Swiftで「クロージャ」と言うときは[クロージャ式][closure-expressions]を指すのが一般的です。
クロージャ式は、仮引数のリスト、戻り値の型、キーワード`in`、そしてクロージャの本体を順に書き、全体を波括弧（`{}`）で囲んだものです。

```swift
{ (a: Double, b: Double) -> Double in
  return (a + b) / 2.0
}
```

これは型`(Double, Double) -> Double`のクロージャ式を定義しています。この型の関数と同じように、適切な型の引数を渡すことで実行できます。

```swift
{ (a: Double, b: Double) -> Double in
  return (a + b) / 2.0
}(10.0, 15.0)
// returns 12.5
```

実行するたびに完全なクロージャ式を書くのはあまり便利ではないので、クロージャはSwiftの他の値と同じように、名前を付けた定数や変数に代入できます。
そうすれば、名前のあとに引数を付けて呼び出せます。

```swift
let mean = { (a: Double, b: Double) -> Double in
  (a + b) / 2.0
}

mean(13.0, 100.0)
// returns 56.5
```

上の例でもわかるように、クロージャは通常の関数と同じく、本体が単一の式であれば`return`キーワードを省略できます。

クロージャはたいてい、高階関数と組み合わせて使います。引数として渡したり、結果として返したりするのです。

```swift
[11, 75, 3, 99, 53].contains(where: { (x: Int) -> Bool in x > 100 })
// returns false

["apple", "ball", "carrot"].sorted(by: { (s1: String, s2: String) -> Bool in s1.count < s2.count })
// returns ["ball", "apple", "carrot"]

func makeAdder(base: Int) -> (Int) -> Int {
  { (x: Int) -> Int in base + x }
}
```

## クロージャの型推論

戻り値の型や仮引数の型を[文脈から推論できる][inferring-closure-types]ときは、クロージャ式でそれらを省略できます。
さらに、仮引数の型を省略できる場合は、仮引数名を囲む括弧も省略できます。

```swift
let mean: (Double, Double) -> Double = { a, b in a + b / 2.0 }

func makeAdder(base: Int) -> (Int) -> Int {
  { x in base + x }
}

["apple", "ball", "carrot"].sorted(by: { s1, s2 in s1.count < s2.count })
```

- 1つ目の例では、定数`mean`の型注釈から型を推論できます。
- 2つ目の例では、コンパイラは`makeAdder`の定義から、`base`が`Int`であること、そして返される関数が型`(Int) -> Int`でなければならないことを知っています。そこから、`x`が`Int`であればクロージャの型は`(Int) -> Int`になると検証できます。したがって、クロージャが取りうる有効なシグネチャは`(Int) -> Int`だけなので、クロージャの型シグネチャを省略できるのです。
- 3つ目の例も似ていますが、コンパイラはメソッドが使われている配列からも型情報を得る必要があります。`sorted(by:)`メソッドは、ソート対象のコレクションの要素と同じ型の2つの仮引数を持ち、`Bool`を返すクロージャを引数に取ることをコンパイラは知っています。そのため、クロージャの戻り値の型は`Bool`でなければならないと推論できます。そして、このメソッドは文字列の配列に対して使われているので、仮引数`s1`と`s2`の型はどちらも`String`でなければならないと判断できます。

## クロージャの制限

前述したとおり、Swiftでは関数とクロージャはよく似ていますが、いくつか重要な違いがあります。

- クロージャは外部引数ラベルを使えません。定義する方法がなく、クロージャを呼び出すときに仮引数名を使おうとするとエラーになります。

```swift
let add5 = { x in x + 5 }
add5(x: 10)
// Error: Extraneous argument label 'x:' in call
```

- クロージャの仮引数には、デフォルト値を設定できません。
- クロージャの仮引数は可変長引数にできますが、名前と型注釈を付ける必要があります。
