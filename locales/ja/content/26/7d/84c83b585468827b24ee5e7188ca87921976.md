# 説明

バイオリンは、基準となる音に合わせて耳でチューニングします。弦によって音の高さは大きく離れていて、扱う数値も整数ばかりではありません。

5つのタスクはすべて`TUNING_THE_STRINGS`クラスに書きます。

## 1. 1オクターブ上げる

1オクターブ高い音は、周波数が2倍になります。

```sather
TUNING_THE_STRINGS::octave_up(440.0d)
-- => 880.0d
```

## 2. 1オクターブ下げる

1オクターブ低い音は、半分になります。

```sather
TUNING_THE_STRINGS::octave_down(440.0d)
-- => 220.0d
```

## 3. ちょうど中間

2つの周波数が与えられたとき、そのちょうど中間にあたる周波数を返します。

```sather
TUNING_THE_STRINGS::midpoint(440.0d, 442.0d)
-- => 441.0d
```

## 4. どれだけずれている？

2つの音が近いけれど同じではないとき、周波数の差が1サイクルごとに、1秒あたり1回のうなりとして聞こえます。2つの周波数がどれだけ離れているかを返します。どちらの音が高くても、答えが負になることはありません。

```sather
TUNING_THE_STRINGS::beats_per_second(441.5d, 440.0d)
-- => 1.5d
```

## 5. 練習時間を分ける

分数と人数が与えられたとき、1人あたり何分になるでしょうか？　分数も人数も整数ですが、答えは整数とは限りません。

```sather
TUNING_THE_STRINGS::minutes_each(45, 2)
-- => 22.5d
```
