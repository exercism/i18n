# 説明

仕事を持っている人なら誰でもそうであるように、LispエイリアンのLaylaも、ときどき他の人に情報を伝えるためのレポートを作る必要があります。そこで、そうしたレポートに使うデータの書式を整えるのを手伝ってくれないかと頼まれました。

## 1. 四半期の値をフォーマットする

Laylaがまず必要としているのは、`format-quarter-value`という関数です。この関数は、四半期と値という2つの入力を受け取り、レポート用にフォーマットします。文字列に評価される必要があります。

```lisp
(format-quarter-value "last" 3.14) ; => "The value last quarter: 3.14"
(format-quarter-value "this" 0) ; => "The value this quarter: 0"
```

## 2. 2つの四半期のレポート

Laylaは`format-quarter-value`関数をありがとうと言い、*次*に必要になる関数でとても役に立つと話しています。

次のレポートでは、2つの四半期の四半期と値を2行に分けて表示する必要があります。

また、出力は最初の引数として渡されたストリームに書き出す必要があります。

例として、`(format-two-quarters t "last" 3.14 "this" 0)`とすると、標準出力に次のように出力されます：

```

The value last quarter: 3.14
The value this quarter: 0

```

前後に空行があることに注意してください。

## 3. 人間にもLispエイリアンにも読める形

Laylaは、LispエイリアンはLispデータとして読める形で値を見るのが好きだということを伝え忘れていました。そこで、Lispデータとして読み取れる新しい関数が必要です（これも指定されたストリームに出力します）：

```lisp
(format-two-quarters-for-reading nil "last" 3.14 "this" 0) ; =>

"(\"The value last quarter: 3.14\" \"The value this quarter: 0\")"
```
