# 説明

中東で生まれた古代の暗号方式であるアフィン暗号を実装してみましょう。

アフィン暗号は、単一換字式暗号の一種です。
各文字は対応する数値に置き換えられ、数学的な関数によって暗号化されたあと、新しく得られた数値に対応する文字に変換されます。
単一換字式暗号はどれも弱いのですが、アフィン暗号は鍵の数がはるかに多いため、アトバシュ暗号よりもずっと強力です。

## 暗号化

暗号化の関数は次のとおりです：

```text
E(x) = (ai + b) mod m
```

ここで、

- `i`は、`0`からアルファベットの長さ-1までの、文字のインデックスです
- `m`はアルファベットの長さです。
  ラテンアルファベットの場合、`m`は`26`です。
- `a`と`b`は、暗号鍵を構成する整数です

自動的に復号できるようにするには、`a`と`m`の値が互いに素である必要があります。つまり、共通の約数が`1`だけである必要があります（詳しくは、[互いに素な整数に関するWikipediaの記事][coprime-integers]を参照してください）。
`a`が`m`と互いに素でない場合は、プログラムはそれをエラーとして示す必要があります。
そうでない場合は、与えられた鍵で暗号化または復号する必要があります。

この演習では、数字は有効な入力ですが、暗号化されません。
空白と句読点は除外されます。
暗号文は、空白で区切られた固定長のグループで書き出されます。伝統的なグループの長さは`5`文字です。
これは、単語の区切りに基づいて暗号文を推測するのを難しくするためです。

## 復号

復号の関数は次のとおりです：

```text
D(y) = (a^-1)(y - b) mod m
```

ここで、

- `y`は、暗号化された文字の数値、つまり`y = E(x)`です
- `a^-1`は`a mod m`のモジュラ乗法逆元（MMI）であることに注意することが重要です
- モジュラ乗法逆元は、`a`と`m`が互いに素である場合にのみ存在します。

`a`のMMIは、`ax`を`m`で割った余りが`1`になるような`x`です：

```text
ax mod m = 1
```

モジュラ乗法逆元の求め方とその意味についての詳細は、[関連するWikipediaの記事][mmi]を参照してください。

## 一般的な例

- 鍵`a = 5`、`b = 7`で`"test"`を暗号化すると`"ybty"`になります
- 鍵`a = 5`、`b = 7`で`"ybty"`を復号すると`"test"`になります
- 間違った鍵`a = 11`、`b = 7`で`"ybty"`を復号すると`"lqul"`になります
- 鍵`a = 19`、`b = 13`で`"kqlfd jzvgy tpaet icdhm rtwly kqlon ubstx"`を復号すると`"thequickbrownfoxjumpsoverthelazydog"`になります
- 鍵`a = 18`、`b = 13`で`"test"`を暗号化すると、`18`と`26`が互いに素でないためエラーになります

## モジュラ乗法逆元（MMI）を求める例

`a = 15`のMMIを求める：

- `(15 * x) mod 26 = 1`
- `(15 * 7) mod 26 = 1`、つまり`105 mod 26 = 1`
- `7`は`15 mod 26`のMMIです
