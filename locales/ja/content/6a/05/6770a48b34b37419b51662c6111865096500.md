# NuVoc

[NuVoc][nuvoc-link]は、Jの決定版リファレンスです。Jのプリミティブと言語について、非常に簡潔で情報密度の高い概要になっています。

# コミュニティ

- [フォーラム][forums-link]のメーリングリスト
- [r/apljk][reddit-link]のサブレディット
- [discord][discord-link]チャンネル

# Rosetta Code

Rosetta Codeのタスクの多くには、`J`の解答があります。学ぶためのJプログラムを探すのに良いリソースです。[こちら](https://rosettacode.org/wiki/Sudoku#J)は、Roger Huiによる数独ソルバーです。
