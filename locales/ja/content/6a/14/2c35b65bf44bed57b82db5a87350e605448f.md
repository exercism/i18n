# `match`の基本

`match`演算子は、ある値を一連のパターンと比較し、どのパターンにマッチしたかに応じてコードを実行します。

## リテラルとのマッチング

最も基本的な形では、`match`はある値を複数の候補と比較し、最初にマッチしたアームを選びます。選ばれるアームは必ず1つだけで、制御が別のアームへ「流れ込む」ことはありません。`match`は、値を評価結果として持つことができる式です。

```rust
enum TrollNumber {
    One,
    Two,
    Many,
    Lots,
}

fn estimated_value(troll_number: TrollNumber) -> u32 {
    match troll_number {
        TrollNumber::One => 1,
        TrollNumber::Two => 2,
        TrollNumber::Many => 10,
        TrollNumber::Lots => 100,
    }
}
```

## 網羅性

マッチングは常に網羅的でなければなりません。値がすり抜けてしまう可能性がある場合、Rustはそのプログラムをコンパイルしません。これを助けてくれるのが`_`で、何にでもマッチするワイルドカードです。

```rust
fn ordinal(n: u32) -> String {
    let ordinal = match n % 10 {
        1 => "st",
        2 => "nd",
        3 => "rd",
        _ => "th",
    };
    format!("{n}{ordinal}")
}
```

## 制御フローとしてのマッチング

`match`は値を生み出す式として使える一方で、純粋に制御フローのためだけに文として使うこともできます。

```rust
// pretend that we've already filtered the key events relevant to the space bar (we don't want a keylogger)
fn space_timer(&mut self, event: Event) {
    match event {
        Event::KeyDown => self.timer = Some(Instant::now()),
        Event::KeyUp => {
            let duration = Instant::now() - self.timer.take().expect("can't have KeyUp without KeyDown");
            self.durations.push(duration);
        }
        // we don't care about any other events; the empty scope is a no-op
        _ => {}
    }
}
```

## 範囲とのマッチング

マッチのアームは単一の値として指定する必要はありません。範囲として指定することもできます。

```rust
fn ascii_type(ch: u8) -> &'static str {
    match ch {
        0..=31 => "non-printable control code",
        32..=126 => "printable character",
        127 => "DEL",
        _ => "extended ASCII; region-specific",
    }
}
```

## ORパターン

マッチのアームは、`|`を区切りとして使うことで、複数の候補のうちの1つにマッチさせることができます。

```rust
fn should_retry(error: std::io::Error) -> bool {
    use std::io::ErrorKind;

    match error.kind() {
        ErrorKind::TimedOut | ErrorKind::Interrupted => true,
        _ => false,
    }
}
```

## 構造的なマッチングと束縛

マッチングでは、特定のマッチのアーム内でだけ有効な束縛を生み出すことができます。これは、バリアントにデータを持つ列挙型を分解するときに特に役立ちます。

```rust
/// Consume a result and proceed, logging any errors.
trait OrLog {
    fn or_log(self);
}

impl<E: std::fmt::Display> OrLog for Result<(), E> {
    fn or_log(self) {
        match self {
            // discard Ok results
            Ok(()) => {},
            // log errors
            Err(err) => println!("ERROR: {err}"),
        }
    }
}
```
