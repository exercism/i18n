# 手順

この演習では、ラジコンカーの作業をもう少し進めます。

実験用の車が開発されたため、テストコースを生産モデルと実験モデルの両方に対応させなければならなくなりました。2種類の車はすでに作られているので、テストコースで両方を扱う方法を考える必要があります。

さらに、生産モデルの車も少しずつ成果を上げ始めています。チームのボスは、生産モデルの車のランキングを公開して、競争心を保ちたいと考えています。

## 1. 同じテストコースで車を走らせられるようにする

2種類の車の`Drive()`の実装を公開するメソッドを、`IRemoteControlCar`インターフェースに追加してください。

```csharp
TestTrack.Race(new ProductionRemoteControlCar());
TestTrack.Race(new ExperimentalRemoteControlCar());
// this should execute without an exception being thrown
```

## 2. テストコースを走った距離をモデルごとに比較できるようにする

2種類の車の`DistanceTravelled`プロパティの実装を公開するプロパティを、`IRemoteControlCar`インターフェースに追加してください。

```csharp
var prod = new ProductionRemoteControlCar();
TestTrack.Race(prod);
var exp = new ExperimentalRemoteControlCar();
TestTrack.Race(exp);
prod.DistanceTravelled
// => 10
exp.DistanceTravelled
// => 20
```

## 3. 生産モデルの車をランキングできるようにする

`ProductionRemoteControlCar`クラスに`IComparable<T>`インターフェースを実装してください。車のデフォルトの並べ替え順は、勝利数の昇順とします。

静的メソッド`TestTrack.GetRankedCars()`を実装し、渡された車を勝利数の昇順に並べ替えて返すようにしてください。

```csharp
var prc1 = new ProductionRemoteControlCar();
var prc2 = new ProductionRemoteControlCar();
prc1.NumberOfVictories = 3;
prc2.NumberOfVictories = 2;
var rankings = TestTrack.GetRankedCars(prc1, prc2);
// => rankings[1] == prc1
```
