# ループ

Rustのループを使うと、コードのブロックを、止めるよう指示するまで、または特定の条件が満たされるまで繰り返し実行できます。

最も基本的なループは、`loop`キーワードを使います。

```rust
fn main() {
    loop {
        println!("again!");
    }
}
```

上のコードは無限ループになります。ループを抜けるには、`break`キーワードを使います。

```rust
fn main() {
    let mut count = 0;
    loop {
        println!("again!");
        count += 1;
        if count > 10 { break; }
    }
}
```

## `for`と`while`を使ったループ

`loop`キーワードのほかに、`for`と`while`でもループを作れます。

`for`ループは、配列やイテレーターの要素を繰り返し処理するときに使います。

```rust
fn main() {
    let a = [10, 20, 30, 40, 50];

    for x in a {
        println!("the value is: {x}");
    }
}
```

範囲もイテレーターなので、`for`ループで順にたどるととても便利です。

```rust
fn main() {
    for x in 0..10 {
        println!("the value is: {x}");
    }
}
```

`while`ループは、条件が満たされるまでコードを繰り返し続けます。先ほどの例は、`while`ループを使って次のように書き直すこともできます。

```rust
fn main() {
    let a = [10, 20, 30, 40, 50];
    let mut index = 0;

    while index < 5 {
        println!("the value is: {}", a[index]);

        index += 1;
    }
}
```

ループについてさらに詳しく知りたいときは、Rustの本の[https://doc.rust-lang.org/book/ch03-05-control-flow.html#repetition-with-loops](repetition with loops)を参照してください。
