# 行動規範

## はじめに

Exercismは、思いやりのある会話を中心に据えたプラットフォームです。誰かが歓迎されていない、支えられていない、侮辱された、差別されたと感じるようなコミュニケーションには、ほとんど寛容ではありません。

## 不快なことを見たり、経験したりしていませんか？

虐待、ハラスメント、差別を見たり経験したりした場合、あるいは安全でない、つらいと感じた場合は、abuse@exercism.orgまでメールでお知らせください。報告は真剣に受け止めます。

## 執行

行動規範（CoC）への違反がないか積極的に監視し、違反の報告はどれも真剣に受け止めます。これまでにも、違反によりコントリビューターやメンター、ユーザーを禁止したことがあります。

CoC違反の報告を受け取ったあと、その人のExercismおよび関連するコミュニケーションチャネルでの会話履歴を確認し、故意にCoCを破ったのか、うっかり一線を越えてしまったのかを理解しようと努めます。通常は、報告された本人に連絡を取り、気にかかっている点を話し合い、違反を繰り返すと禁止につながると警告します。違反が起きていないと判断し、何の措置も必要ないと決めることもあれば、初回の違反で禁止する場合もあります。公平であろうと努めていますが、コミュニティの文化を守る側に判断を倒します。

Exercismの運営チームは、CoC違反に関して、適切と考えるあらゆる措置を取る権利を留保します。

## シンプルに言うと

- 思いやりを持つ
- 歓迎する
- 親切にする
- 正直でいる
- 支える
- 礼儀を守る

## 詳細

Exercismは、次のようなことに関係なく、すべての人にとって安全な場所であるべきです

- 性別、性自認、性表現
- 性的指向
- 障害
- 外見（体格を含みますが、これに限りません）
- 人種
- 年齢
- 宗教
- そのほか、思いつくあらゆること

このコミュニティの一員として、次のことに同意します。

- 安全と包摂に、集団としても個人としても取り組みます。
- 虐待、ハラスメント、差別を一切許容しません。
- 一人ひとりの境界線とアイデンティティを尊重します。
- 攻撃的あるいは抑圧的（系統的なものであってもなくても）と受け取られかねない言葉を使わないようにします。たとえば、性差別的、人種差別的、同性愛嫌悪的、トランスフォビア的、障害者差別的、階級差別的といった表現です。これは、さまざまな蔑称を含みます（が、これに限りません）。
- ユーモアのつもりで攻撃的な話題を使うことを避けます。

次のことに積極的に取り組みます。

- 安全なコミュニティであること
- 互いを支え励ますネットワークを育てること
- 責任ある、多様な表現を奨励すること

次のことを非難します。

- ストーキング、個人情報の暴露（doxxing）、私的な情報の公開
- 暴力、暴力の脅迫、暴力的な言葉
- 誰かの安全を損なうあらゆること
- 性差別的、人種差別的、同性愛嫌悪的、トランスフォビア的、障害者差別的、その他差別的あるいは本質的に攻撃的と見なされかねない言動
- 歓迎されない、下品な、蔑むような、不適切なあだ名や呼び方を使うこと
- 他者への敬意の欠如（冗談、当てこすり、見下す態度）と、意見の違いへの敬意の欠如
- 脅迫やハラスメント（オンラインでも対面でも）。ハラスメントをどう解釈するかについては、[Citizen Code of Conduct](https://github.com/stumpsyn/policies/blob/master/citizen_code_of_conduct.md)をお読みください。
- 不適切な注目や接触
- 建設的な批判と貶しめ言葉の違いを理解しないこと

こうしたことは、決して許されません。

自分の行動が周りにどう影響するかに気をつけてください。誰かを不快にさせるなら、やめてください。

もし攻撃的だと受け取られた発言をして、それを指摘されたら、次のようにしてみてください。

- 遮らずに聞く。
- 相手の言っていることを信じ、その発言を否定しようとしない。
- 今後同じことをしないためのヒントや助けを求める。
- 謝罪し、許しを請う。
