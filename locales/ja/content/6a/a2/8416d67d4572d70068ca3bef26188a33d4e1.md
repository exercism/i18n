# 指示の補足

## 実装

twobucketパッケージで、次のシグネチャを持つGoの関数`Solve`を実装してください。

```go
func Solve(sizeBucketOne,
	sizeBucketTwo, goalAmount int, startBucket string,
) (goalBucket string, numSteps, otherBucketLevel int, e error)
```

`Solve`は4つの値を返します。ゴールとなるバケット（"one"またはtwo"）、ゴールの量に達するまでの移動回数（ステップ数）、もう一方のバケットに残っているリットル数、そしてエラー値です。
パラメータが無効な場合、または解が存在しない場合は、エラーを返します。
