# 並列文字頻度の概念

この演習では、外部クレートの助けを借りることも含めて、実にさまざまな解答が考えられます。作業量を抑えるため、このドキュメントでは可能性の一部だけを紹介します。Crossbeamを使う解答もここに挙げたのと同様の概念を使いますが、Rayonが必要とするのはその一部だけです。

## 概要

- **プリミティブ**
  - `usize`
  - `char`
  - 浮動小数点値
    - 浮動小数点の除算と整数の除算
- **不変性／明示的な可変性**
- **文字列**
  - `&str`型
- **Unicode**
  - UnicodeメソッドとASCIIメソッド
- **スライス**
- **タプル**
- **分配**
- **関数**
  - 高階関数
  - クロージャ
- **可視性**
- **データコレクション**
  - `HashMap`
- **`Option`型**
- **イテレーター**
  - 遅延評価
  - 消費する／消費しない
  - 2つ目の例にあるように: `FromIterator`トレイト
- **`for`ループ**
- **参照**
  - 参照カウンター（この場合は`Arc`）
  - 参照外し
- **ライフタイム**
  - `'Static`
  - `move`
  - ドロップ
- **クレート**
- **並列性**

### 並列性に関連する概念

- **チャネル**
- **`Mutex`と`RwLock`**

## 全般

- 文字列: 特に`str`はここで常に関係します
- Unicode: ASCIIメソッドとUnicodeメソッドの性能／機能面での違い。ベンチマークがUnicodeメソッドを使い、解答がASCIIメソッドを使うと、ベンチマーク結果が偏ります。
- イテレーター: 入力全体またはそのチャンクを反復処理します。
- コレクション: `HashMap`を反復処理し、`Entry`を使います。通常、ハンドルは`Vec`に集められます。
- 参照
- 数値: 特に`Add`トレイト
- `for`ループ: `move`のため、イテレーター内でスレッドを`join`できません。
- **任意** 可視性: 実装の詳細を非公開に保ちます
- **任意** スライス: `.chunks()`は、ワーカースレッド用に入力を分割するためによく使われるメソッドです。代わりに部分スライスを使うこともあります。
- **任意** 高階関数: `HashMap`は、イテレーターを使った高階関数でマージできます。
- **任意** 型: 入力を分割するために、丸めを適用する目的で整数を浮動小数点値にキャストできます
- **任意** クレート

## チャネルあり／なしの標準ライブラリのアプローチ

- 並列性: サブトピック「スレッドの生成と`join`」
- イテレーター: サブトピック「遅延評価」。同じイテレーターでスレッドを生成して`join`すると、並列性が損なわれます。
- ライフタイム: サブトピック「`'static lifetime`」と「明示的な`move`セマンティクス」
- イテレーター／ライフタイム: サブトピック「消費するイテレーター」。イテレーターを使ってスレッドを`join`することはできません。
- `Option`型: スレッドまたはチャネルの結果をアンラップします
- 関数: 特にスレッドの生成には高階関数が必要です。クロージャも選択肢です。

## チャネルを使う標準ライブラリアプローチ

- 並列性: サブトピック「チャネル」
- タプル: `mpsc::channel()`はタプルを返します
- 分配: タプルは代入時に分配できます
- ライフタイム: `drop()`

## 共有変数を使う別のアプローチ

- 参照カウント: 参照カウントされたコレクションを使って、スレッド間で集約データを共有します。
- **参考までに**: 並列性: サブトピック「ミューテックス」。この演習には必要でも有用でもありませんが、よく使われる概念です。関連: `RwLock`。

### チャネルを使う標準ライブラリの例

```rust
use std::collections::HashMap;
use std::thread;
use std::sync::mpsc;

pub fn frequency(input: &[&str], worker_count: usize) -> HashMap<char, usize> {
    let (tx, rx) = mpsc::channel();

    let _handles = input.chunks((input.len() as f64 / worker_count as f64).ceil() as usize)
        .map(|slice| slice.concat())
        .map(|slice| {
            let tx = tx.clone();
            thread::spawn(move || {
                let mut map: HashMap<char, usize> = HashMap::new();
                for chr in slice.chars().filter(|c| c.is_alphabetic()) {
                    if let Some(c) = chr.to_lowercase().next() {
                        (*map.entry(c).or_insert(0)) += 1;
                    };
                }
                tx.send(map).unwrap()
            })
        }).collect::<Vec<_>>();

    drop(tx);

    let mut result: HashMap<char, usize> = HashMap::new();
    for received in rx {
        for (c, count) in received {
            *result.entry(c).or_insert(0) += count;
        }
    }

    result
}
```

### `Arc`を使うクレートの例

```rust
use std::collections::HashMap;
use std::iter::FromIterator;
use std::sync::Arc;
use dashmap::DashMap;

pub fn frequency(input: &[&str], worker_count: usize) -> HashMap<char, usize> {
    let map: Arc<DashMap<char, usize>> = Arc::new(DashMap::new());

    let handles = input
        .chunks((input.len() as f64 / worker_count as f64).ceil() as usize)
        .map(|slice| slice.concat())
        .map(|slice| {
            let map = map.clone();
            std::thread::spawn(move || {
                for c in slice.chars().filter(|c|c.is_alphabetic())
                  .flat_map(|c| c.to_lowercase().next()) {
                    *map.entry(c).or_insert(0) += 1;
                }
            })
        }).collect::<Vec<_>>();

    for h in handles {
        h.join().unwrap();
    }

    map.iter().map(|x| (*x.key(), *x.value())).collect()
}
```
