# はじめに

再帰とは、関数が自分自身を呼び出すことで、その関数の中のコードを繰り返す方法です。
ループや繰り返しの、もう一つのやり方でもあります。ループと同じように、いつ終わるかを知るために、関数は真偽値の式を評価する必要があります。
ループとは違い、終わらない再帰は無限に実行されることはありません。
それぞれの関数呼び出しで使われる値は、スタック上のそれぞれのフレームに置かれることがあります。
関数呼び出しの量がスタックの容量を超えると、スタックオーバーフローエラーになります。

```c
int printIncrement (int i, int maxValue){
    if (i > maxValue) return i;
    printf("The number is %i\n", i++);
    printIncrement(i, maxValue);
}

int main() {
    printIncrement(1, 2);
    printf("After recursion");
    return 0;
}
```

これは次のように出力します。

```
The number is 1
The number is 2
After recursion
```

ループで表現するよりも、再帰で表現したほうが読みやすかったり、筋道を立てて考えやすかったりする状況もあるかもしれません。
