# はじめに

## Pythonのオブジェクト指向プログラミング

関数型、宣言型、命令型のスタイルでプログラミングしてきた人なら、オブジェクト指向プログラミング（OOP）に視点を移すのは、少しとっつきにくく感じるかもしれません。
オブジェクト指向のアプローチでは、問題を、互いにやり取りし、状態を保ち、データに働きかける1つ以上の`objects`としてモデル化することを考えます。
オブジェクトは、現実世界の実体（_車や猫など_）を表すこともできますし、もっと抽象的な概念（_整数や乗り物、哺乳類など_）を表すこともできます。
それぞれのオブジェクトは、コンピューターメモリーの中で一意のインスタンスとなり、モデル全体の一部を表します。

## クラス

`Classes`は新しいオブジェクトの型の定義であり、そこからオブジェクトの新しい`instances`が作られます。
多くの場合、データと、そのデータを操作するコードや関数をひとまとめにします。
この意味で、クラスは_設計図_であり、同じような型の多くのオブジェクトを作って使うための手順の集まりでもあります。
複雑なプログラムにはたくさんのクラスがあり、それぞれがさまざまな種類のオブジェクトを作ります。
クラスからオブジェクトを作るプロセスを`instantiation`（_クラスのインスタンスを作ること_）といいます。

Pythonでのクラスの定義はシンプルです。

```python
class MyClass:
    # Class body goes here
```

### クラスの属性

クラスの本体には、クラスのフィールド（_別名`properties`、`attributes`、`data members`、`variables`_）を追加できます。

```python
class MyClass:
    number = 5
    string = "Hello!"
```

`MyClass`のインスタンス（_オブジェクト_）は、クラスを[_呼び出す_][calling]ことで作成し、名前に束縛できます（_関数を呼び出すのと同じ方法です_）。

```python
>>> new_object = MyClass()

# Class is instantiated and resulting object is bound to the "new_object" name.
# Note: the object address 'at 0x15adc55b0' will vary by computer.
>>> new_object
<__main__.MyClass at 0x15adc55b0>
```

`Class attributes`は、クラスから作られたすべてのオブジェクト（_またはインスタンス_）で共有され、[`dot notation`][dot notation]でアクセスできます。これは、オブジェクト名の後、属性名の前に`.`を置く書き方です。

```python
>>> new_object = MyClass()

# Accessing the class attribute "number" via dot-notation.
>>> new_object.number
5

# Accessing the class attribute "string" via dot-notation.
>>> new_object.string
'Hello!'

# Instantiating an additional object and binding it to the "second_new_object" name.
>>> second_new_object = MyClass()

>>> second_new_object
# Note: the object address "at 0x15ad99970" will vary by computer.
<__main__.MyClass at 0x15ad99970>

# Second_new_object shares the same class attributes as new_object.
>>> new_object.number == second_new_object.number
True
```

クラスの属性は、ほかのどのメソッドよりも先に、クラス本体の中で定義します。
これらはクラスが所有するもので、クラスのインスタンス間で共有できます。
これらの属性は共有されているので、その値にはクラスから_直接_アクセスして操作できます。
クラスの属性の値を変えると、_**そのクラスからインスタンス化されたすべてのオブジェクト**_の値が変わります。

```python
>>> obj_one = MyClass()
>>> obj_two = MyClass()

# Accessing a class attribute from an object.
>>> obj_two.number
5

# Accessing the class attribute from the class itself.
>>> MyClass.number
5

# Modifying the value of the "number" class attribute.
>>> MyClass.number = 27

# Modifying the "number" class attribute changes the "number" attribute for all objects.
>>> obj_one.number
27

>>> obj_two.number
27
```

たくさんのオブジェクトが常に同期したデータを持っている状態は、あまり役に立ちません。
幸いなことに、クラスから作られたオブジェクトは、それぞれ独自の`instance attributes`（_インスタンスプロパティ、変数、フィールドともいいます_）でカスタマイズできます。
名前のとおり、インスタンス属性は各オブジェクトに固有のもので、独立して変更できます。

## `__init__()`でオブジェクトのインスタンス化をカスタマイズする

特別な[「ダンダーメソッド」][dunder]（_「double underscore method」の略_）である`__init__()`は、クラスのインスタンスをカスタマイズするために使われ、オブジェクトのインスタンス属性やプロパティを初期化できます。
インスタンス属性を初期化する役割から、`__init__()`は`class constructor`や`initializer`とも呼ばれます。
`__init__()`は`self`という必須の仮引数を1つ受け取ります。これは新しく初期化、作成されたオブジェクトを指します。
インスタンス属性やプロパティのデータは、`self`仮引数のあとに続けて、`__init__()`の引数として渡せます。

以下の`MyClass`には、`location_x`と`location_y`というインスタンス属性があります。
ご覧のとおり、この2つの属性には、`__init__()`に渡された`location`（_タプル_）引数の1番目と2番目のインデックスが代入されています。
これで、クラスをインスタンス化してオブジェクトを作ると、そのクラスのインスタンスの`location_x`と`location_y`属性が初期化されます。

```python
class MyClass:
    # These are class attributes, variables, or fields.
    number = 5
    string = "Hello!"

    # This is the class "constructor", with a "location" parameter that is a tuple.
    def __init__(self, location):

        # This is an instance or object property, attribute, or variable.
        # Note that we are unpacking the tuple argument into two separate instance variables.
        self.location_x = location[0]
        self.location_y = location[1]

# Create a new object "new_object_one", with object property (1, 2).
>>> new_object_one = MyClass((1, 2))

# Create a second new object "new_object_two" with object property (-8, -9).
>>> new_object_two = MyClass((-8, -9))

# Note that new_object_one.location_x and new_object_two.location_x two different values.
>>> new_object_one.location_x
1

>>> new_object_two.location_x
-8
```

上の`MyClass`を初期化するときに渡す引数は1つだけでよいことに注意してください。クラスを呼び出すと、Pythonが`self`を渡してくれます。

## メソッド

`method`は、クラス自体（_[クラスメソッド][class method]と呼ばれ、後の演習で扱います_）か、クラスの_インスタンス_（オブジェクト）に束縛された`function`です。
オブジェクト（インスタンス）を操作するメソッドは、最初の仮引数を`self`として定義する必要があります。
残りの仮引数は、通常の、束縛されていない関数と同じように定義できます。

```python
class MyClass:
    number = 5
    string = "Hello!"

    # Class constructor.
    def __init__(self, location):
        # Instance properties
        self.location_x = location[0]
        self.location_y = location[1]

    # Instance method. Note "self" as first parameter.
    def change_location(self, amount):
        self.location_x += amount
        self.location_y += amount
        return self.location_x, self.location_y
```

属性へのアクセスと同じように、メソッドを呼び出すには、オブジェクト名の後、メソッド名の前に`.`を置くだけです。
呼び出されたメソッドは、最初の引数としてオブジェクトのコピーを受け取る必要はありません。Pythonが`self`を自動的に埋めてくれます。

```python
class MyClass:
    number = 5
    string = "Hello!"

    def __init__(self, location):
        self.location_x = location[0]
        self.location_y = location[1]

    def change_location(self, amount):
        self.location_x += amount
        self.location_y += amount
        return self.location_x, self.location_y

# Make a new test_object with location (3,7)
>>> test_object = MyClass((3,7))
>>> (test_object.location_x, test_object.location_y)
(3,7)

# Call change_location to increase location_x and location_y by 7.
>>> test_object.change_location(7)
(10, 14)
```

クラスの属性は、クラスの外からアクセスするのと同じように、インスタンスメソッドの中からもアクセスできます。

```python
class MyClass:
    number = 5
    string = "Hello!"

    def __init__(self, location):
        self.location_x = location[0]
        self.location_y = location[1]

    # Alter instance variable location_x and location_y
    def change_location(self, amount):
        self.location_x += amount
        self.location_y += amount
        return self.location_x, self.location_y

    # Alter class variable number for all instances from within an instance.
    def increment_number(self):
        # Increment the 'number' class variable by 1.
        MyClass.number += 1


>>> test_object_one = MyClass((0,0))
>>> test_object_one.number
5

>>> test_object_two = MyClass((13, -3))
>>> test_object_two.increment_number()
>>> test_object_one.number
6
```

## `pass`で実装を仮置き、またはスタブする

これまでのコンセプト演習や、プラクティス演習のスタブでは、実際のコードの代わりに関数の本体の中で`pass`キーワードが使われているのを見たことがあるでしょう。
`pass`キーワードは文法的に有効なプレースホルダーです。空の関数やクラス定義に対してPythonが構文エラーを出すのを防いでくれます。
要するに、Pythonのインタプリターに「心配しないでください！　ここにはいずれ_必ず_コードを書きます。まだ書いていないだけです」と伝える方法です。

```python
class MyClass:
    number = 5
    string = "Hello!"

    def __init__(self, location):
        self.location_x = location[0]
        self.location_y = location[1]

    # Alter instance variable location_x and location_y
    def change_location(self, amount):
        self.location_x += amount
        self.location_y += amount
        return  self.location_x, self.location_y

    # Alter class variable number for all instances
    def increment_number(self):
        # Increment the 'number' class variable by 1.
        MyClass.number += 1

    # This will compile and run without error, but has no current functionality.
    def pending_functionality(self):
       # Stubbing or placholding the body of this method.
       pass
```
