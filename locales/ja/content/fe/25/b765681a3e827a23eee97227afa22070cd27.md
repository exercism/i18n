# 浮動小数点数

PHPでは、実数の一部を表すために浮動小数点数を使います。
小数点で区切られた1桁以上の数字で始まります。

```php
<?php

$a = 1.234; 
$b = 1.2e3; 
$c = 7E-10;
$d = 1_234.567; // as of PHP 7.4.0
```

## よくある落とし穴

浮動小数点数ですべての数値や算術演算を扱えるわけではありません。
ドルやセントを表すのに浮動小数点数を使うと、丸め誤差が生じることがよくあります。

```php
<?php

$result = 0.1 + 0.2; // => 0.30000000000000004
```
