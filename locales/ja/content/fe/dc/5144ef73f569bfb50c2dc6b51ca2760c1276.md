# はじめに

Luaでは、数値を2つの表現で扱います。64ビット整数と倍精度浮動小数点数です。Luaは、加算・減算・乗算・除算・否定といった一般的な算術演算子をサポートしています。さらに、切り捨て除算、余り、べき乗もサポートしています。

| 演算子 | 例                  |
| -------- | ------------------- |
| `+`      | `1 + 2 --> 3`       |
| `-`      | `2 - 1 --> 1`       |
| `*`      | `2 * 2 --> 4`       |
| `/`      | `4 / 2 --> 2.0`     |
| `//`     | `11 // 3 --> 3`     |
| `%`      | `11 % 3 --> 2`      |
| `^`      | `10 ^ 2 --> 100.0`  |
| `-`      | `-(2 * 2) --> -4`   |
