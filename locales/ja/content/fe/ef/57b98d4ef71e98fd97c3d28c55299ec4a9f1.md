# はじめに

## 変数

`jq`のプログラムは_式のパイプライン_であることを思い出しましょう。
**変数の代入**は次のルールに従います。_変数の代入_とは、次のような形をした式です。

```jq
... | expr as $varname | ...
```

### フィルターの出力は入力と同じ

_恒等式_`.`と同じように、_変数の代入_の出力は入力と同じです。
変数の値を設定することは副作用です。

次の例は、代入のあとの`.`が最初の入力と同じであることを示しています。

```sh
$ jq -c -n '42 | (. * 2) as $double | [., $double]'
[42,84]
```

### 変数のスコープ

変数のスコープは「レキシカル」です。その変数は、パイプラインの残りの部分で有効になります。
関数の中で定義された変数（関数については後で扱います）は、その関数に「ローカル」です。

### 変数名

変数名は`$`で始まる必要があります。
変数名の残りの部分は**識別子**です。識別子は、文字またはアンダースコアで始まり、そのあとに文字、数字、アンダースコアが続きます。

### 分割代入

マニュアルにはこう書かれています。

> 単一の`as`式で複数の変数を宣言できます。その際、_入力の構造に一致する_パターンを指定します（これは「分割代入」として知られています）。

例：

```jq
[1, 2, 3] as [$a, $b, $c]
| [$a, $b, $c]     # => [1, 2, 3]
```

```jq
{"foo": "bar", "len": [10, 20]} as {foo: $f, len: [$h, $w]}
| [$f, $h, $w]     # => ["bar", 10, 20]
```

変数名を_オブジェクトのキー_に一致させると、省略して書くことができます。

```jq
{"x": 4, "y": 7} as {$x, $y}
| [$x, $y]         # => [4, 7]
```

```jq
{"foo": "bar", "len": [10, 20]} as {$foo, $len}
| [$foo, $len]     # => ["bar", [10, 20]]
```

### 定数

上の例で見たように、変数は定数を保存するのに便利です。
コードの中に「マジックナンバー」が現れるより、定数には名前を付けたほうがよいでしょう。

### 変数が不要なことも多い

変数を省略したほうが読みやすくなることもよくあります。

数値のリストの平均を計算することを考えてみましょう。

```jq
[2, 4, 8, 7]
| add as $sum
| length as $len
| $sum / $len
```

次の書き方と比べてみましょう。

```jq
[2, 4, 8, 7] | add / length
```

これは、`jq`の最も強力な特徴のひとつを浮き彫りにします。フィルターへの入力は、_すべての_部分式に渡されるのです。

- 入力の配列`[2,4,8,7]`が`add`に渡されます（`add`は、すべての要素に`+`演算子を適用して数値を合計します）
- _同時に_、`[2,4,8,7]`は`length`にも渡されます
- これらの部分式が完了すると、その結果が除算され、入力の配列にある数値の平均値が返されます。

### 学習用の演習で必要になる`jq`の演算子

#### 代替演算子：`//`

式`a // b`は、`a`がfalseまたはnullなら`b`を出力し、そうでなければ`a`を出力します。
変数を設定する場面では、これはデフォルト値を用意するのにとても便利です。

```jq
(.input.theAnswer // 42) as $answer | ...
```

#### 算術演算子

- `+`、`-`、`*`は、通常の数値の加算、減算、乗算の演算子です。
