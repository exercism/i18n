# 説明

この演習では、お気に入りの料理本から最高のラザニアを作れるように、コードを書いていきます。

ラザニアの調理にかかる時間に関する、4つのタスクがあります。

## 1. 想定される焼き時間を定数に保存する

`expected-bake-time`という定数を定義します。これは、ラザニアをオーブンで焼くのに何分かかるかを返すようにします。

料理本によると、ラザニアはオーブンで合計40分焼く必要があります。

```factor
expected-bake-time .
! => 40
```

## 2. 準備時間を分単位で計算する

`preparation-time`というワードを定義します。これは、ラザニアに重ねた層の数をスタックから取り出し、準備にかかった分数をスタックに残します。1層の準備に2分かかるものとします。

```factor
4 preparation-time .
! => 8
```

## 3. 残りの焼き時間を分単位で計算する

`remaining-time`というワードを定義します。これは、ラザニアがすでにオーブンで焼かれていた分数を取り出し、あと何分オーブンに残す必要があるかをスタックに残します。

```factor
25 remaining-time .
! => 15
```

## 4. 合計作業時間を分単位で計算する

`total-working-time`というワードを定義します。これは、スタックから2つの引数（まずラザニアの層の数、次にラザニアがすでにオーブンにあった分数）を取り出し、これまでに調理にかかった合計時間（準備時間とすでにオーブンにあった時間を合わせたもの）をスタックに残します。

```factor
3 20 total-working-time .
! => 26
```
