# はじめに

[`Basics`][basics]のコンセプトでは、関数を定義する2つの方法を紹介しました。

もっとも一般的なのは、複数行にわたる形式です。

```julia
function muladd(x, y, z)
    x * y + z
end
```

短い定義向けの「代入形式」、つまり「1行形式」です。
```julia
muladd(x, y, z) = x * y + z
```

3つ目の、さらに短い形式では、一度しか使わない短い関数を、名前を付けずに作れます。

```julia-repl
julia> map(x -> 2x, 1:3)
4-element Vector{Int64}:
 2
 4
 6

julia> map((x, y) -> x * y, 1:3, 4:6)
3-element Vector{Int64}:
  4
 10
 18
```

この場合、`x -> 2x`は「無名関数」です。
これは、他の言語で「ラムダ関数」と呼ばれているものに相当します。

複数の引数には括弧（`()`）が必要で、`(x, y) -> x * y`のように書きます。

無名関数はJuliaのコードでよく使われます。とくに、`map()`や`filter()`のような高階関数と組み合わせたときはそうで、これらについては後のコンセプトで詳しく扱います。

```julia-repl
julia> map(x -> x^4, [1, 2, 3])
3-element Vector{Int64}:
  1
 16
 81
```

## 関数の引数

ここまでのシラバスでは、引数の数が決まっていて、呼び出すときにはすべての引数を正しい順序で渡さなければならない関数だけを見てきました。
これでは融通がきかず不便なので、ほかにもいくつかの選択肢が用意されています。

### 省略可能な引数

多くの言語と同じように、Juliaでは関数定義で個々の引数にデフォルト値を指定できます。

すると関数を呼び出す側は、その引数に値を渡すことも、省略してデフォルト値に任せることもできます。

```julia-repl
julia> f(x, y=10) = x * y
f (generic function with 2 methods)

julia> f(2, 3)
6

julia> f(2)
20
```

デフォルト値の_ない_引数は、デフォルト値の_ある_引数より前に置かなければなりません。つまり、`f(x=2, y)`は無効です。

### キーワード引数

ここまでの例はすべて`positional arguments`を使っています。これは、関数を呼び出すときに渡す値が、関数定義にある対応する引数の順序と一致していなければならない、というものです。

多くの言語と同じように、Juliaでも`keyword arguments`を使えます。
呼び出すときは引数の名前を指定する必要がありますが、複数のキーワード引数はどのような順序で指定してもかまいません。

Juliaならではの特徴として、関数定義にあるキーワード引数がある場合は、その前にセミコロン`;`を置いて、位置引数と区切らなければなりません。
関数を呼び出すときは、最後の位置引数と最初のキーワード引数の間を`;`または`,`で区切ります。

```julia-repl
julia> b(x; y) = x + y
b (generic function with 1 method)

julia> b(2, y=3)
5

# keyword is required when calling
julia> b(2, 3)
ERROR: MethodError: no method matching b(::Int64, ::Int64)
The function `b` exists, but no method is defined for this combination of argument types.
```

位置引数の場合とまったく同じように、デフォルト値を指定することもできます。

仮引数と同じ名前の変数をあらかじめ計算しておいたときなど、関数呼び出しの中で`myarg=myarg`のような書き方になることがよくあります。
このような場合は、省略記法が使えます。

```julia-repl
julia> width = 4.0
4.0

julia> height = √ width
2.0

julia> area(; width, height) = width * height
area (generic function with 1 method)

# repetition
julia> area(; width=width, height=height)
8.0

# shorthand form
julia> area(; width, height)
8.0
```

### スプラットとスラープ

ちなみに、これらはJuliaの構文の便利な側面につけられた標準的な名前です。
どちらも`...`演算子を指します。

#### スプラット

スプラットは関数の_呼び出し_で使い、コレクションを、その関数が必要とする個々の値へと展開します。

これは、説明するよりも実際に見てもらったほうがわかりやすいでしょう。

```julia-repl
julia> fxyz(x, y, z) = x * y * z
fxyz (generic function with 1 method)

julia> xyz = [2, 3, 4]
3-element Vector{Int64}:
 2
 3
 4

# Using the vector directly in a function call is invalid
julia> fxyz(xyz)
ERROR: MethodError: no method matching fxyz(::Vector{Int64})
The function `fxyz` exists, but no method is defined for this combination of argument types.

# splatting converts the vector to 3 numbers, used as positional arguments
julia> fxyz(xyz...)
24
```

一部の「関数呼び出し」は糖衣構文に隠れているので、スプラットはあまり目立たない形でも使われます。

たとえば、多重代入は内部的にタプルのコンストラクター関数を使っています。

```julia-repl
julia> first, rest... = [1, 2, 3, 4]
4-element Vector{Int64}:
 1
 2
 3
 4

julia> first
1

julia> rest
3-element Vector{Int64}:
 2
 3
 4
```

キーワード引数もスプラットで渡せます。そのときは通常、`named tuple`を使います。
`Dict`でもかまいませんが、キーはシンボルでなければなりません（文字列では動きません）。

```julia-repl
# function with 3 keyword arguments
julia> fabc(; a, b, c) = a + b + c
fabc (generic function with 1 method)

# named tuple
julia> abc_nt = (a=2, b=3, c=4)
(a = 2, b = 3, c = 4)

# there are no positional arguments, so need to use ; before kw argument
julia> fabc(;abc_nt...)
9

# Dict
julia> abc_dict = Dict(:a=>2, :b=>3, :c=>4)
Dict{Symbol, Int64} with 3 entries:
  :a => 2
  :b => 3
  :c => 4

julia> fabc(;abc_dict...)
9
```

#### スラープ

スラープは関数の_定義_で使い、任意の数の個々の値を1つのコレクションにまとめます。

```julia-repl
julia> f_more(i, j, more...) = i + j + sum(more)
f_more (generic function with 1 method)

julia> f_more(1, 3, 5, 7, 9, 11)
36
```

スラープする引数の名前（この場合は`more`）には意味がありません。
この変数の型はコンパイラーが選びますが、位置引数の場合は`tuple`のような型になる可能性が高いです。

キーワード引数もスラープでき、その場合は`Dict`（または同様のもの）になります。

```julia-repl
julia> f_kwslurp(x, y; switches...) = :mult in keys(switches) ? x * y : x + y
f_kwslurp (generic function with 1 method)

julia> f_kwslurp(5, 6; mult=true)
30

julia> f_kwslurp(5, 6)
11
```

呼び出し側ではどのキーワード引数でも使えます。
どのキーワードに反応し、どれを無視するかを決めるのは、関数の定義側です。
