# 説明

この演習では、地元のアーケードホールで一番人気のゲームのハイスコアを記録する仕組みを実装します。

実装する関数は6つあり、そのほとんどがハイスコアを保持するオブジェクトの操作に関するものです。

## 1. 新しいハイスコアボードを作成する

ハイスコアボードとして機能するオブジェクトを作成する関数`create_score_board`を書きます。
このオブジェクトのキーはプレイヤーの名前、値はそのスコアになります。
テストのために、オブジェクトに1つのエントリーを直接含めておきます。
この最初のエントリーは、プレイヤー名が`"The Best Ever"`、スコアが`1000000`です。

```jq
create_score_board
# returns an object with one initial entry
```

## 2. スコアボードにプレイヤーを追加する

ハイスコアボードにプレイヤーを追加するには、関数`add_player`を実装します。
これはスコアボードを入力として受け取り、プレイヤー名とプレイヤーのスコアの2つを入力として受け取ります。
この関数は、新しいプレイヤーを追加したスコアボードのオブジェクトを出力します。

```jq
{"José Valim", 486373}
| add_player("Dave Thomas"; 0)
# => {"Dave Thomas": 0, "José Valim": 486373} -- in some order
```

プレイヤーがすでにボード上にいる場合は、ボードをそのまま出力します。

## 3. スコアボードからプレイヤーを削除する

プレイヤーがアーケードホールのルールに違反した場合、そのプレイヤーは手動でハイスコアボードから削除されます。
`remove_player`を実装します。これはボードを入力として受け取り、削除するプレイヤーの名前という1つの入力を受け取ります。
この関数は、指定されたプレイヤーのエントリーをボードから削除し、新しいボードを出力します。
プレイヤーがそもそもボード上にいなかった場合は、ボードには何も起きず、そのまま返されます。

```q
{"Dave Thomas": 0} | remove_player("Dave Thomas")
# => {}

{"Dave Thomas": 0} | remove_player("Rose Fanaras")
# => {"Dave Thomas": 0}
```

## 4. プレイヤーのスコアを増やす

プレイヤーがアーケードホールで別のゲームを終えると、ボード上の以前のスコアに一定のポイントが加算されます。
`update_score`を実装します。これはスコアボードを入力として受け取り、プレイヤー名と加算するスコアの2つを入力として受け取ります。
この関数は、更新が完了したあとのスコアボードを返します。

```jq
{"Freyja Ćirić": 12771000} | update_score("Freyja Ćirić"; 73)
# => {"Freyja Ćirić": 12771073}
```

この関数は、プレイヤーがまだボード上にいない場合は、そのプレイヤーをボードに追加します。

## 5. 月曜日のボーナスポイントを適用する

アーケードホールでは、月曜日に別のスコアボードを使います。
その日の終わりに、そのボード上の各プレイヤーは100ポイントを追加で受け取ります。

関数`apply_monday_bonus`を実装します。
この関数は、そのボードに載っている各プレイヤーにボーナスポイントを追加します。

```jq
{
  "Dave Thomas": 44,
  "Freyja Ćirić": 539,
  "José Valim": 265
}
| apply_monday_bonus
# => {"Dave Thomas": 144, "Freyja Ćirić": 639, "José Valim": 365}
```

## 6. 合計スコアを求める

アーケードホール同士は、誰が最高のプレイヤーを持っているかを競います。
合計スコアが最も高いアーケードが栄誉を手にします。

関数`total_score`を書きます。
これはスコアボードを入力として受け取り、すべてのプレイヤーのスコアの合計を出力します。

```jq
{
  "Dave Thomas": 44,
  "Freyja Ćirić": 539,
  "José Valim": 265
}
| total_score
# => 848
```
