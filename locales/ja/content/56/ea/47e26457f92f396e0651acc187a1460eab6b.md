# 説明

友人のLi Meiは、おいしいミックスフルーツジュースを売るジュースバーを営んでいます。
その店によく通ううちに、自分のコーディングスキルで友人の負担を減らせるかもしれない、と思いつきました。
そこで、Li Meiの仕事を手伝うことにしました。

## 1. ジュースを混ぜるのにかかる時間を求める

Li Meiは、お客さんがメニューから注文したジュースについて、どれくらい待てばよいかを前もって伝えるのが好きです。
ジュースを混ぜるのにかかる時間はそれぞれ違うので、正確な数字を覚えておくのは大変です。
`'Pure Strawberry Joy'`は0.5分、`'Energizer'`と`'Green Garden'`はそれぞれ1.5分、`'Tropical Island'`は3分、`'All or Nothing'`は5分かかります。
それ以外の飲み物（たとえばおすすめメニューなど）は、準備に2.5分かかると考えておけば大丈夫です。

友人の助けになるよう、メニューのジュースを入力として受け取り、その飲み物を混ぜるのにかかる分数を戻す関数`timeToMixJuice`を書いてみましょう。

```javascript
timeToMixJuice('Tropical Island');
// => 3

timeToMixJuice('Berries & Lime');
// => 2.5
```

## 2. ライムのくし形切りを補充する

Li Meiが作るものの多くには、材料としてであれ飾りとしてであれ、ライムのくし形切りが入っています。
そのため、朝シフトに入るときには、その日の分のライムのくし形切りが入った容器がいっぱいになっていることを確かめる必要があります。

切る必要のあるライムのくし形切りの数と、手元にあるまるごとのライムの在庫を表す配列を入力として受け取る関数`limesToCut`を実装しましょう。
`'small'`のライムからは6切れ、`'medium'`のライムからは8切れ、`'large'`のライムからは10切れ取れます。
Li Meiはいつも、リストに並んでいる順番どおり、最初のものから順にライムを切ります。
必要な数のくし形切りに届くまで、またはライムがなくなるまで、切り続けます。

Li Meiは、あらかじめ何個のライムを切ればよいかを知りたいと思っています。
`limesToCut`関数は、切るライムの個数を戻すようにします。

```javascript
limesToCut(25, ['small', 'small', 'large', 'medium', 'small']);
// => 4
```

## 3. シフトを終える

Li Meiはいつも15時まで働きます。
その後は、従業員のDmitryが引き継ぎます。
Li Meiのシフトが終わる時点で、注文は入っているけれどまだ準備できていない飲み物がよくあります。
そうした残りのジュースは、Dmitryが準備します。

引き継ぎを楽にするために、Li Meiのシフトに残っている分数と、注文済みでまだ準備できていないジュースの配列を入力として受け取る関数`remainingOrders`を実装しましょう。
この関数は、Li Meiが勤務時間の終わりまでに準備を始められない注文を戻すようにします。

シフトの残り時間は、常に0より大きくなります。
準備するジュースの配列が空になることはありません。
さらに、注文は配列に並んでいる順番どおりに準備されます。
Li Meiが何かのジュースを混ぜ始めたら、少し長く働くことになっても、必ず最後まで作り上げます。
Dmitryが引き受ける必要のある残りの注文がなければ、空の配列を戻すようにします。

```javascript
remainingOrders(5, ['Energizer', 'All or Nothing', 'Green Garden']);
// => ['Green Garden']
```
