# 説明

Bellebrook Basketball Leagueは、それぞれが選手名簿を持つ複数のチームからなるリーグです。新しいシーズンがまもなく始まり、試合のチケットを販売するための新しいチケットシステムを作る必要があります。前シーズンはスタジアムの入口でチケットを販売していましたが、人気が爆発的に高まったため、増加する需要に対応するべく、今シーズンはオンラインでチケットを販売することにしました。

リーグから連絡があり、チケット販売を処理するシステムを作るよう依頼されました。

## 1. チケットシステムを作成する

まず、チケット販売を処理するチケットシステムを作成する必要があります。チケットシステムは、ある試合で販売可能なチケットが何枚あるかを示す必要があります。

試合ごとに、`TicketSystem`というクラスのインスタンスを作成します。初期化された状態は、次の情報を保持している必要があります。

1. その試合で販売可能なチケットの枚数。
2. その試合が行われるスタジアム。

販売可能なチケットの枚数と、試合が行われるスタジアムを示す引数から、初期化された状態を構築します。初期化された状態は、インスタンス変数`@tickets_available`と`@stadium`で構成されている必要があります。これらには、それぞれ与えられた1番目と2番目の引数が入ります。

```crystal
TicketSystem.new(100, "Bellebrook")
# => #<TicketSystem:0x10f0b8 @tickets_available=100, @stadium="Bellebrook">
```

## 2. 販売可能なチケットの枚数を取得する

まず、ある試合について販売可能なチケットの枚数を返すメソッドを作成する必要があります。

すでに定義したクラスの上に、`TicketingReservation`という名前のモジュールを定義します。このモジュールは、`TicketSystem`クラスにインクルードします。

モジュールの中に、`tickets_available`というメソッドを定義します。このメソッドは、販売可能なチケットの枚数を返す必要があります。

```crystal
ticket_system = TicketSystem.new(100)
ticket_system.tickets_available
#=> 100
```

## 3. チケットを注文する

ある試合についてチケットが販売可能かどうかを確認するメソッドを作成する必要があります。試合には、常に100枚のチケットを確保しておく必要があります。これは、スタジアムの入口でチケットを買う人たちのために、常にチケットを残しておくためです。

モジュール`TicketingReservation`の中に、`order_ticket?`というメソッドを定義します。このメソッドは、チケットが100枚以上ある場合は`true`を、それ以外の場合は`false`を返す必要があります。また、チケットが100枚以上ある場合は、販売可能なチケットの枚数を1枚減らす必要があります。

```crystal
ticket_system = TicketSystem.new(100)
ticket_system.order_ticket?
#=> true
```

## 4. 注文メッセージ

チケットシステムには、ユーザーが理解しやすいメッセージが必要です。また、メッセージは親しみを感じさせるものであるべきで、ユーザーの名前を含める必要があります。

チケットの購入が成功した場合、ユーザーは、購入が成功したこと、自分のチケット番号、そして試合が行われるスタジアムを伝えるメッセージを受け取ります。チケット番号は、注文前の販売可能なチケットの枚数です。

購入が成功した場合、メッセージは次のようになります。`{name}, your purchase was successful, your ticket number is #{ticket_number}, and the game is played at the {stadium_name} stadium.`
購入が失敗した場合、メッセージは次のようになります。`{name}, your purchase was unsuccessful, there are not enough tickets available.`

モジュール`TicketingReservation,`の中に、購入者の名前を持つ引数`name`を取る`order_message`というメソッドを定義します。このメソッドは、そのメッセージを含む文字列を返す必要があります。

```crystal
ticket_system = TicketSystem.new(100, "Bellebrook")
ticket_system.order_message("John")
#=> "John, your purchase was successful, your ticket number is #100, and the game is played at the Bellebrook stadium."
```
