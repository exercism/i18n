# 説明

この演習では、工場の従業員向けの名札を出力するコードを書きます。従業員にはID、名前、部署名があります。従業員の名札のラベルは、`"[id] - name - DEPARTMENT"`という形式です。

## 1. 従業員の名札を出力する

`NameBadge.print/3`関数を実装します。ID、名前、部署を受け取り、部署名を大文字にした名札のラベルを返します。

```elixir
NameBadge.print(67, "Katherine Williams", "Strategic Communication")
# => "[67] - Katherine Williams - STRATEGIC COMMUNICATION"
```

## 2. 新しい従業員の名札を出力する

コンピューターシステムのちょっとした仕様により、新しい従業員は、工場で働き始めた時点ではまだIDを持っていないことがあります。名札は必須なので、IDの接頭辞のない一時的な名札を受け取ります。

`NameBadge.print/3`関数を拡張します。IDがないときは、IDのない名札を出力します。

```elixir
NameBadge.print(nil, "Robert Johnson", "Procurement")
# => "Robert Johnson - PROCUREMENT"
```

## 3. オーナーの名札を出力する

工場のオーナーでさえ、常に名札を着用しなければなりません。ただし、オーナーには部署がありません。この場合、ラベルには部署名の代わりに`"OWNER"`と出力します。

`NameBadge.print/3`関数を拡張します。部署がないときは、その名札は会社のオーナーのものだとみなします。

```elixir
NameBadge.print(204, "Rachel Miller", nil)
# => "[204] - Rachel Miller - OWNER"
```

オーナーが新しい従業員でもある場合があることに注意してください。

```elixir
NameBadge.print(nil, "Rachel Miller", nil)
# => "Rachel Miller - OWNER"
```
