# 概要

正規表現（regex）は、Elixirで文字列を扱うための強力なツールです。Elixirの正規表現は、**PCRE**仕様（**P**erl **C**ompatible **R**egular **E**xpressions）に従います。正規表現の意味を表す文字列パターンは、まずコンパイルされ、その後、文字列全体または一部のマッチングに使われます。

Elixirで正規表現を作る最も一般的な方法は、[`~r`シジル][sigils-regex]を使うことです。シジルは、Elixirでよくあるタスクを_糖衣構文_で短く書けるようにしてくれるものです。この場合、`~r`は[`Regex.compile!/2`][regex-compile]を使うためのショートカットです。

```elixir
Regex.compile!("test") == ~r/test/
# => true
```

[`=~/2`][regex-match-operator]演算子を使うと、文字列に対して正規表現マッチを行い、`boolean`の結果を返せます。

```elixir
"this is a test" =~ ~r/test/
# => true
```

## 正規表現の構文のおさらい

- 正規表現パターンの中には特別な意味を持つ文字があり、その文字をそのまま使うには`\`でエスケープする必要があります。例えば`~r/\?/`のように書きます。
- _文字クラス_（例：`\d`、`\w`）を使うと、ある範囲の文字にマッチさせられます
- _選択_（`|`）を使うと、複数のパターンのいずれかにマッチさせられます
- _量指定子_（`{N, M}`、`*`、`?`）を使うと、繰り返すパターンの回数を指定してマッチさせられます
- _グループ_（`()`）を使うと、パターンの一部をひとつの単位として扱えます

## キャプチャ

正規表現は、文字列の一部を取り出すのにも便利です。これを_キャプチャ_と呼びます。文字列の一部を_キャプチャ_するには、キャプチャしたい部分のグループ（`()`）を作り、[`Regex.run`][regex-run]を使います。

```elixir
Regex.run(~r/Weight: (\d*)g/, "Weight: 150g")
# => ["Weight: 150g", "150"]
```

キャプチャには番号が付き（1から始まります）、正規表現で文字列の一部を置き換えるときの結果の中でも使えます。

```elixir
Regex.replace(~r/Weight: (\d*)g/, "Weight: 150g", "Gewicht: \\1g")
# => "Gewicht: 150g"
```

キャプチャには、開き括弧のあとに`?<name>`を付けて名前を付けることもできます。[`Regex.named_captures/3`][regex-named-captures]を使うと、名前付きキャプチャを持つマップを取得できます。

```elixir
Regex.named_captures(~r/Weight: (?<weight>\d*)g/, "Weight: 150g")
# => %{"weight" => "150"}
```

## 修飾子

正規表現の動作は、正規表現の末尾に特別なフラグを付けることで変更できます。例えば`~r/test/i`のように書きます。

- `caseless` `i` - 大文字と小文字を区別しません
  ```elixir
  "A" =~ ~r/a/
  # => false
  "A" =~ ~r/a/i
  # => true
  ```
- `unicode` `u` - `\p`のようなUnicode固有のパターンを有効にし、`\w`などの文字クラスがUnicodeにもマッチするようにします
  ```elixir
  "ö" =~ ~r/^\w$/
  # => false
  "ö" =~ ~r/^\w$/u
  # => true
  ```
- [その他：`dotall`、`multiline`、`extended`、`firstline`、`ungreedy`][regex-modifiers]

## 正規表現を動的に組み立てる

`~r`シジルは`"pattern" |> Regex.escape() |> Regex.compile!()`のショートカットなので、文字列補間を使って正規表現パターンを動的に組み立てることもできます。

```elixir
anchor = "$"
regex = ~r/end of the line#{anchor}/
"end of the line?" =~ regex
# => false
"end of the line" =~ regex
# => true
```

## 正規表現と`String`モジュール

正規表現は強力ですが、常に使うのが賢明とは限りません。

- 使う前にコンパイルが必要で、計算時間とメモリを消費します。
- 普通の文字列関数を使うよりも遅くなることがあります。

目安として、できるだけ[`String`モジュールの関数][string-functions]を使うほうがよいでしょう。

```elixir
# Don't use regular expressions to check a suffix:
if "YELLING!" =~ ~r/!$/, do: "Whoa, chill out!"

# Use a string function:
if String.ends_with?("YELLING!", "!"), do: "Whoa, chill out!"
```
