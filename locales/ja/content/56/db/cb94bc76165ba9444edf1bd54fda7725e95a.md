# 説明

友達から、重要な秘密が書かれたメッセージが届きました。
他の人に簡単に読まれないように、このメッセージは一連のビット操作によって暗号化されています。
メッセージを復号するための関数を書く必要があります。

## 1. ビットをシフトし直す

メッセージを復号する最初のステップは、暗号化の過程で行ったシフトを元に戻すために、ビットを右にシフトし直すことです。
このあとの復号のステップでは、左側から`0`が挿入されることを前提としています。

`shiftBack`関数を実装してください。この関数は、シフトする桁数と値を受け取り、シフトを実行します。

```elm
shiftBack 2 42 --> 10
```

## 2. いくつかのビットを設定する

次に、`1`に設定する必要があるビットがあります。

`setBits`関数を実装してください。この関数は、マスクと値を受け取り、値のビットを`1`に設定した結果を返します。
マスクのビットも`1`になっている位置では、値のビットを`1`に設定します。
それ以外のビットはそのままにします。

```elm
setBits 66 212 --> 64
```

## 3. 特定のビットを反転させる

暗号化の際に、いくつかのビットが反転されています。
メッセージを復号するには、それらを元に反転し直す必要があります。

`flipBits`関数を実装してください。この関数は、マスクと値を受け取ります。
マスクは、値のどのビットを反転させるかを示します。
マスクのビットが`1`であれば、値の対応するビットを反転させます。
それ以外のビットはそのままにします。

```elm
flipBits 23 157 --> 138
```

## 4. 特定のビットをクリアする

また、復号すると必ず0になるビットもあります。

`clearBits`関数を実装してください。この関数は、マスクと値を受け取ります。
マスクのビットが1である位置では、`value`のビットを0に設定します。
それ以外のビットはそのままにします。

```elm
clearBits 2 15 --> 13
```

## 5. メッセージを復号する

必要な関数がすべてそろったので、友達のメッセージを復号できます。
次の処理を行う`decrypt`関数を実装してください。

1. 友達が生まれた年（1996）のビットを設定する
2. その結果を、初めて出会った年（2009）で反転させる
3. 一緒に受けている授業の数（5）だけビットをシフトし直す
4. 1番目と5番目のビットをクリアする

```elm
decrypt 380182 --> 11840
```

前のタスクで実装したすべての関数を使って`decrypt`を実装してください。
