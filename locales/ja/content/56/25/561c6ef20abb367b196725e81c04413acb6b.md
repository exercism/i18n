# インストール

お使いのプラットフォームに推奨されるインストール手順は、[Rust公式サイト]を参照してください。

ツールチェーンをインストールすればそれで終わりではありません！
IDEのサポートは生産性を大きく高めてくれるもので、今ではほとんどのエンジニアが当然のように期待しています。
Visual Studio Codeを使っているなら、[Rustサポートのドキュメント][vscode]をチェックしてみましょう。
[clippyによるリンティング][vscode-linting]を有効にするのも、ぜひおすすめします！

[the official Rust website]: https://www.rust-lang.org/tools/install
[vscode]: https://code.visualstudio.com/docs/languages/rust
[vscode-linting]: https://code.visualstudio.com/docs/languages/rust#_linting
