# 概要

Haxeでは、例外はコードの実行中に起きるエラーを安全に扱う方法です。すべての例外には、エラーの内容を説明するメッセージを含める必要があります。例外は、`throw`キーワードを使って_投げる_ことができます。

```haxe
public function main(num:Int) {
  if (num < 10) {
    throw "Argument num cannot be greater than 10";
  }
  // ...
}
```

例外が投げられると、コードはそのエラーを処理する担当の部分を探します。見つからない場合は、エラーメッセージを表示し、あわせてプログラムの実行を停止します。

Haxeで例外を処理するには、`try-catch`ブロックを使います。このブロック文は、1つの`try`ブロックと1つ以上の`catch`ブロックからなります。`try`ブロックはコードの一部の実行を_試し_、`catch`ブロックは、例外が投げられたときにそれを_捕まえ_て実行が止まらないように待ち構えます。`catch`ブロックが例外を捕まえると、そのブロック内の処理もすべて実行します。

```haxe
try {
  if (num < 10) {
    throw "Argument num cannot be greater than 10";
  }
} catch (e) {
  // All exceptions will be caught here
  trace(e.message); // Argument num cannot be greater than 10
}
```

`catch`ブロックの引数の型は省略します。

重要なのは、例外は、例外的なことが起きたとき、つまり特別な処理が必要なエラーが起きたときに使うものだという点です。プログラムの制御フローに使うべきではありません。それは設計として良くないとされており、パフォーマンスや保守性の低下につながることがよくあります。
