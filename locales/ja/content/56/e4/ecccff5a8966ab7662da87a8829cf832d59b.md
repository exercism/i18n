# はじめに

真偽値の式とは、1つ以上の値に対して投げかける問いで、`true`または`false`で答えることができます。
真になる式は`1`を返し、偽になる式は`0`を返します。
また、数値にも真偽の値があります。0は`false`で、0以外は`true`です。

古いCのコードでは、真偽値に`int`型をそのまま使うか、`TRUE`や`FALSE`のような定数を定義して`1`と`0`を真偽値に対応させていました。

C99で`_Bool`型が追加されました。
`stdbool.h`ヘッダーファイルは、`bool`、`true`、`false`という3つの新しい真偽値用のシンボルを定義しています。
`true`は`1`に、`false`は`0`に、`bool`は`_Bool`に対応します。
こうして今では、`int`を直接使ったり、独自の真偽値の対応を自分で作ったりする代わりに、`stdbool.h`をインクルードすれば、コードの中で自動的に真偽値のシンボルを使えるようになりました。

## 比較演算子

Cには6つの比較演算子があります。`==`（等しい）、`!=`（等しくない）、`>`（より大きい）、`<`（より小さい）、`>=`（以上）、`<=`（以下）です。
これらの演算子は値の関係を比較し、その結果を真偽値として求めます。

```c
0 == 0 // true. Although 0 is false, 0 equals 0 is true.
0 != 0 // false
1 > 0 // true
1 < 0 // false
1 >= 0 // true
1 <= 0 // false
```

## 真偽値演算子

Cには3つの真偽値演算子があります。`||`（または）、`&&`（かつ）、`!`（否定）です。

`!`はオペランドを1つ取ります。
オペランドの真偽値を反転させます。
たとえば、`0`は`false`ですが、`!0`は`true`になります。

`||`と`&&`はオペランドを2つ取ります。
右側のオペランドは、左側のオペランドだけでは式の結果が決まらないときにだけ評価されます。
つまり、`||`が右側のオペランドを評価するのは、左側のオペランドが`false`と評価されたときだけです。
`&&`が右側のオペランドを評価するのは、左側のオペランドが`true`と評価されたときだけです。
