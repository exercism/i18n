# 可変長引数

Swiftの[_可変長引数_][variadic-parameters]を使うと、同じ型の0個以上の値を、関数の1つの仮引数にまとめて渡せます。これは、仮引数の型注釈の後ろに`...`を付けることで示します。

渡された値は、可変長引数の型と同じ型の要素をもつ配列に自動的にまとめられます。

```swift
func geometricMean(_ numbers: Double...) -> Double {
  var total = 1.0
  for number in numbers {
      total *= number
  }
  return pow(total, 1.0 / Double(numbers.count))
}

geometricMean(1, 2, 3, 4, 5)
// => 2.605171084697352
```

可変長引数を使う場合、Swiftには1つ制限があることに注意してください。関数の定義で可変長引数の後ろに仮引数が続くとき、可変長引数の直後の仮引数には引数ラベルを付けることが_必須_です。

[variadic-parameters]: https://docs.swift.org/swift-book/documentation/the-swift-programming-language/functions/#Variadic-Parameters
