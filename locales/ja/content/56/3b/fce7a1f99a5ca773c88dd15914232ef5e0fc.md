# 概要

[配列][list]は、Haskellで値の集まりを保持するための基本的なデータ型です。
配列は_イミュータブル_で、変更することができません。
配列を変更する操作は、すべて新しい配列を返します。
Preludeには、配列を扱うための関数がいくつか用意されています。

Haskellの配列は[連結リスト][linked-list-wiki]として実装されていて、連続したメモリー領域に並んだ配列ではありません。
そのため、配列の要素にアクセスするには、配列の長さに比例した線形時間がかかります。

配列は、リテラル形式、head-tail記法（`cons`演算子`:`を使います）、またはその両方を組み合わせて書くことができます。

```haskell
-- Literal Form
[]
[1]
[1, 2, 3]

-- Head-tail Notation
[]
-- same as [1]
1 : []
-- same as [1, 2, 3]
1 : (2 : (3 : []))

-- Mixed
-- same as [1, 2, 3]
1 : [2, 3]
```

head-tail記法を使うと、配列に要素を追加できます。

```haskell
list = [2, 1]

[3, 2, 1] == 3 : list
-- -> True
```

繰り返しの中で配列に要素を追加するのは、アンチパターンとされています。
要素の追加には配列全体をたどって末尾に要素を加える必要があります。そのため、繰り返しのたびに新しい要素を追加すると、毎回、配列全体をたどることになります。

同じ結果は、反転した配列の先頭に要素を追加し、その結果を反転することでも得られます。先頭への追加は高速な操作で、一定の時間で済みます。

```haskell
-- Appending to the end of a list (potentially slow)
[1, 2, 3] ++ [4] ++ [5] ++ [6]

-- Prepend to the start of a list (faster, due to the nature of linked lists)
6 : (5 : (4 : [3, 2, 1]))
-- then reverse!
```

配列を扱うためによく使われるPreludeの関数には、次のようなものがあります。

- [`head`][head]は配列の_先頭_、つまり_最初_の要素を返します。
- [`tail`][tail]は配列の_末尾_、つまり_最初_の要素を_除いた_配列を返します。
- [`length`][length]は配列の要素数を返します。
- [`elem`][elem]は、その要素が配列に含まれているかどうかを示す真偽値を返します。

さらに、[`Data.List`モジュール][list]もあります。

## 配列の型

Haskellでは、配列は**均一**です。
つまり、配列のすべての要素は同じ型を持ちます。
異なる型の要素を同じ配列に入れようとすると、型エラーになります。

```haskell
list = [1, "string"]
-- Error: No instance for (Num String) arising from the literal ‘1’
```

配列の型注釈は`[a]`です。ここで`a`は、その配列が保持する型（たとえば`String`や`Int`）を表します。

``` haskell
a :: [Int] 
a = [1, 2, 3]
```
