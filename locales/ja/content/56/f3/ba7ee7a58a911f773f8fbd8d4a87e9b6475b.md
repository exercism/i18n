# はじめに

Common Lispでは、コンピューターには無視される「コメント」を書くことができます。
1行コメントは1つ以上のセミコロン（`;`）で始まります。ときには、次のようなものを見かけることもあるでしょう。

```lisp
(code...) ; => value
```

ここでは、その行のコードを実行したあとにCommon Lispが返す値を、コメントで示しています。

行の末尾に短いコメントを添えるときはセミコロン1つ、コードのまとまりの上に少し長めのコメントを書くときは2つ、関数など何かの説明をする長いコメントには3つ、ソースファイルの先頭に置くヘッダーのようなコメントには4つ、というのが慣例です。
