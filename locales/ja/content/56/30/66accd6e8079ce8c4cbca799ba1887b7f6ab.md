# 説明の補足

## `Print`は文字列の値を引用符で囲みません

この演習では、数値のスコアを操作します。
#[a: 1]` and `#[a: "1"]`は同じではありません。

```arturo
inspect #[a: 1]
; [ :dictionary
;        a  :        1 :integer
; ]

inspect #[a: "1"]
; [ :dictionary
;        a  :        1 :string
; ]
equal? #[a: "1"] #[a: 1]
; false
```

デバッグでは、値を`print`するのがよく行われます。
しかし、出力では文字列が引用符で囲まれません。
そのため、`"1"`のような数値の文字列は、出力すると整数の`1`と同じように見えます。

```arturo
print #[a: 1]
; [a:1]
print #[a: "1"]
; [a:1]
```
この演習のテスト出力では、`:x: equal? [a:1 e:1 i:1 o:1 u:1] [a:1 e:1 i:1 o:1 u:1]`のような結果が表示されることがあります。
比較している2つの辞書は、出力すると同じに見えます。
しかし、1つ目の辞書は値が数値の文字列で、2つ目は値が整数なので、両者は同じではありません。
デバッグの際は、`inspect`を使って辞書の中身を確認できます。

## `Express`は文字列の値を引用符で囲みます

`express`は値をArturoのコードに変換し、そのコード表現を表す文字列を返します。
その結果では、文字列の値は引用符で囲まれます。
そのため、`express "1"`は`1`ではなく`"1"`を返します。

```arturo
express #[name: "Octavius" age: 22]
; #[name: "Octavius" age: 22 ]
```
```arturo
express #[name: "Octavius" age: "22"]
; #[name: "Octavius" age: "22" ]
```
