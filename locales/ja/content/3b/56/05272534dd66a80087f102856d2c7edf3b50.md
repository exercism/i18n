# 可変性

ブロックチェーン指向の設計を持つCairoは、デフォルトで不変のメモリモデルを採用しています。これは、メモリに書き込まれた値は上書きできず、読み出すことしかできないという意味です。しかし、Cairoには`mut`キーワードを使って可変変数を作る仕組みがあります。変数を可変として宣言し、その値を変更すると、新しい値は新しいメモリセルに書き込まれ、変数はその新しいセルを指すように更新されます。この仕組みによって、不変性の利点を保ちながら柔軟性を持たせることができます。

次の例では、`x`は不変の変数として宣言されています。`x`の値を変更しようとすると、コンパイラーがエラーを出します。

```rust
let x = 5;
x = 2; // Error: cannot assign twice to immutable variable
```

`mut`キーワードを使えば、`x`を可変変数として宣言できます。これにより、宣言したあとで`x`の値を変更できるようになります。

```rust
let mut x = 5;
x = 10;
```

最終的に可変性を使うかどうかは、その状況で何が最もわかりやすいかによって決まります。

## 定数

不変の変数と同じように、定数も名前を結び付けた値で、変更は許されません。ただし、定数と変数にはいくつかの違いがあります。

- 定数は`const`キーワードを使って宣言します
- 定数に`mut`は使えません
- 値の型は必ず明示的に指定しなければなりません
- 定数はグローバルスコープでしか宣言できません
- 定数に設定できるのは定数式だけで、実行時に計算された値の結果は設定できません

```rust
struct AnyStruct {
    a: u256,
    b: u32
}

enum AnyEnum {
    A: felt252,
    B: (usize, u256)
}

const ONE_HOUR_IN_SECONDS: u32 = 3600;
const STRUCT_INSTANCE: AnyStruct = AnyStruct { a: 0, b: 1 };
const ENUM_INSTANCE: AnyEnum = AnyEnum::A('any enum');
const BOOL_FIXED_SIZE_ARRAY: [bool; 2] = [true, false];
```

`consteval_int!`マクロを使うと、何らかの計算結果を値とする`const`変数を作ることができます。

```rust
const ONE_HOUR_IN_SECONDS: u32 = consteval_int!(60 * 60);
```

## シャドーイング

`let`を繰り返し使って再宣言することで、値を変換しながら同じ変数名を再利用できます。これはよく行われる書き方でもあります。これを_シャドーイング_と呼びます。実際には、2つ目の変数が1つ目の変数を覆い隠し、それ自体がさらに覆い隠されるかスコープが終わるまで、その変数名の使用をすべて自分が引き受けます。

```rust
fn main() {
    let s: ByteArray = "my string";
    let s: ByteArray = s + " and a shadow";
    {
        let s: ByteArray = "a nested shadow";
        println!(s); // emits "a nested shadow"
    }
    println!(s); // emits "my string and a shadow"
}
```

シャドーイングを使えば、同じ変数名を再利用しながら、変数の型まで変更できます。

```rust
fn main() {
    let x: u64 = 2;
    println!("x is u64, value: {}", x);               // prints "x is u64, value: 2"
    let x: ByteArray = format!("fizz");               // converts x to a ByteArray, type annotation is required
    println!("x is now ByteArray, value: \"{}\"", x); // prints 'x is now ByteArray, value: "fizz"'
}
```
