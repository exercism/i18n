# Configletでファイルを作成する

新しいアプローチ、記事、演習を追加するときは、決まった名前のファイルを作成する必要があります。さらに、設定ファイルの追加や更新も必要です。`create`コマンドを使えば、[configlet](/docs/building/configlet)がこうした作業をすべて代わりに行ってくれます。

## 使い方

`create`コマンドを使うと、新しいアプローチ、記事、演習を追加するために必要なファイルを作成できるほか、設定ファイルを変更することもできます。

```shell
configlet [global-options] create [command-options]

Options for create:
      --approach <slug>           The slug of the approach
      --article <slug>            The slug of the article
      --practice-exercise <slug>  The slug of the practice exercise
      --concept-exercise <slug>   The slug of the concept exercise
  -e, --exercise <slug>           Only operate on this exercise
  -o, --offline                   Do not update the cached 'problem-specifications' data
```

## プラクティス演習を作成する

[プラクティス演習の追加に関するドキュメント](/docs/building/tracks/practice-exercises/add)に、プラクティス演習の追加方法が詳しく説明されています。

## コンセプト演習を作成する

コンセプト演習を作成するには、そのスラッグを指定します。

```shell
configlet create --concept-exercise bird-watcher
```

これで、[コンセプト演習のドキュメント](/docs/building/tracks/concept-exercises)で説明されているとおりに、コンセプト演習に必要なファイルが作成されます。

もちろん、これは演習を作成するための最初のステップにすぎません。このあと、次のことを行う必要があります。

- テストファイルにテストを追加する
- 模範解答の実装を追加する
- スタブファイルの内容を定義する
- `.docs/introduction.md`にイントロダクションを書く
- `.docs/instructions.md`に説明を書く
- 演習の`.meta/config.json`ファイルでは：
  - `authors`キーに演習の作者のGitHubユーザー名を追加する
- トラックの`config.json`ファイルでは：
  - 演習の難易度を確認・更新する
  - `concepts`キーにコンセプトを追加する
  - `prerequisites`キーにコンセプトを追加する

## アプローチを作成する

アプローチのファイルを作成するには、アプローチとその演習のスラッグを指定します。

```shell
configlet create --approach recursion --exercise collatz-conjecture
```

これで、[アプローチのドキュメント](/docs/building/tracks/approaches)で説明されているとおりに、アプローチに必要なファイルが作成されます。

## 記事を作成する

記事のファイルを作成するには、記事とその演習のスラッグを指定します。

```shell
configlet create --article performance --exercise collatz-conjecture
```

これで、[記事のドキュメント](/docs/building/tracks/articles)で説明されているとおりに、記事に必要なファイルが作成されます。
