# 説明

マジシャンになるElyseは、基本をいくつか練習する必要があります。

Elyseは、思いどおりに動かしたいカードの山を持っています。

少し簡単にするために、使うカードは1から10までに限っています。

カードの山は`Array`で表され、山の一番下が配列の先頭、山の一番上が配列の末尾になります。

## 1. 山の一番上にカードを追加する

関数`insert_top`を実装してください。この関数は、渡された新しいカードを山の一番上に追加した、山のコピーを返します。

```rust
let stack = array![5, 9, 7, 1];
insert_top(stack, 8);
// -> [5, 9, 7, 1, 8]
```

## 2. 山の一番上のカードを取り除く

関数`remove_top_card`を実装してください。この関数は、一番上のカードを取り除いた山のコピーを返します。

渡された山が空の場合は、元の山をそのまま返します。

```rust
let stack = array![3, 2, 6, 4, 8];
remove_top_card(stack);
// -> [3, 2, 6, 4]
```

## 3. 山の一番下にカードを追加する

関数`insert_bottom`を実装してください。この関数は、渡された新しいカードを山の一番下に追加した、山のコピーを返します。

```rust
let stack = array![5, 9, 7, 1];
insert_bottom(stack, 8);
// -> [8, 5, 9, 7, 1]
```

## 4. 山の一番下からカードを取り除く

関数`remove_bottom_card`を実装してください。この関数は、一番下のカードを取り除いた山のコピーを返します。

渡された山が空の場合は、元の山をそのまま返します。

```rust
let stack = array![8, 5, 9, 7, 1];
remove_bottom_card(stack);
// -> [5, 9, 7, 1]
```

## 5. 山のサイズを確認する

関数`check_size_of_stack`を実装してください。この関数は、山のサイズが、渡された`stack_size`と同じかどうかを調べます。

```rust
let stack = array![3, 2, 6, 4, 8];
check_size_of_stack(stack, 4);
// -> false
```
