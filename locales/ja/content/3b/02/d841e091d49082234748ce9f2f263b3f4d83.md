# ヒント

## 全般

- 真偽値を扱うための[論理演算子][boolean-operators]が3つあります。
- 1つの式に複数の演算子を組み合わせることができます。

## 1. 速攻攻撃ができるかどうかを確認する

- NOT演算子（`!`）は、式の前に置くと、その値を否定できます。

## 2. グループをスパイできるかどうかを確認する

- 論理演算子は、通常、2つ以上の式が成り立つかどうかを評価するために使います。

## 3. 囚人に合図を送れるかどうかを確認する

- 論理演算子は、優先順位の高い順に実行されます（`!`、`&&`、`||`）。
- 一般に、意図をわかりやすくするために括弧（`()`）を使うことが推奨されます。
- 詳しくは、[Juliaの公式ドキュメント][operator-precedence]の「演算子の優先順位」セクションを確認してみてください。

## 4. 「囚人解放」オプションを表示すべきかどうかを確認する

- 論理演算子は、優先順位の高い順に実行されます（`!`、`&&`、`||`）。
- 一般に、意図をわかりやすくするために括弧を使うことが推奨されます。
