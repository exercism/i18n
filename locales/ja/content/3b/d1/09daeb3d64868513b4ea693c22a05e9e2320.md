# 概要

C#で数値を扱うときに押さえておきたいポイントのひとつが、整数（小数点以下の桁がない数）と浮動小数点数（小数点以下に0桁以上の桁がある数）の違いです。

C#で最もよく使われる数値型は、`int`（32ビット整数）と`double`（64ビット浮動小数点数）の2つです。

```csharp
int i = 123;
double d = 54.29;
```

整数も浮動小数点数も、`_`という文字を_桁区切り_として使えます。大きな数値を書くときに役立ちます。

```csharp
int largeInt = 1_000_000;
// => 1000000

double largeDouble = 9_876_543.21;
// => 9876543.21
```

計算には、標準の[算術演算子][arithmetic-operators]（`+`、`-`、`*`など）を使います。数値の比較には、標準の[比較演算子][comparison-operators]（`<`、`>=`など）や、[等値演算子][equality-operators]（`==`）、[非等値演算子][equality-operators]（`!=`）を使います。

```csharp
5 * 6;
// => 30

1.2 > 0.8
// => true

2 != 4
// => true
```

数値型の間で変換するとき、数値変換には次の2つの種類があります。

1. 暗黙的な変換：データが失われることはなく、追加の構文も必要ありません。
2. 明示的な変換：データが失われる可能性があり、_キャスト_という形で追加の構文が必要です。

`int`は`double`よりも精度が低いため、`int`から`double`への変換は安全で、暗黙的な変換になります。一方、`double`から`int`への変換ではデータが失われる可能性があるため、明示的な変換が必要です。

```csharp
int i = 9;
double d = 2.66;

// Safe conversion, thus implicit conversion
double fromInt = i;

// Potentially unsafe conversion, thus explicit conversion
int fromDouble = (int)d;
```
