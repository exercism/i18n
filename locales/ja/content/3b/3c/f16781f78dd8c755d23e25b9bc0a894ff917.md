# Instructions

この演習では、[ブラックジャック](https://en.wikipedia.org/wiki/Blackjack)のゲームの最初のターンをシミュレートします。

カードを2枚受け取り、ディーラーの表向きのカードを見ることができます。カードはすべて、"ace"、"king"、"three"、"two"などの文字列で表されます。各カードの値は次のとおりです。

| カード |  値   | カード |  値   |
| :---: | :---: | :---: | :---: |
|  ace  |  11   | eight |   8   |
|  two  |   2   | nine  |   9   |
| three |   3   |  ten  |  10   |
| four  |   4   | jack  |  10   |
| five  |   5   | queen |  10   |
|  six  |   6   | king  |  10   |
| seven |   7   | other |   0   |

**補足**：一般に、エースは1または11の値を取ることができますが、ここでは簡単にするため、11の値しか取らないものとします。

手持ちの2枚のカードとディーラーのカードに応じて、ゲームの最初のターンで取るべき戦略が決まります。選択肢は次のとおりです。

    - スタンド（S）
    - ヒット（H）
    - スプリット（P）
    - 自動的に勝ち（W）

まだ最適とは言えませんが、友人のAlexが開発を進めている戦略に従います。その内容は次のとおりです。

カテゴリー：ラージハンド

- エースのペアを持っている場合は、必ずスプリットします。
- ブラックジャック（2枚のカードの合計が21になる手）で、ディーラーがエース、絵札、10のいずれも持っていない場合は、自動的に勝ちになります。ディーラーがこれらのカードを1枚でも持っている場合は、スタンドして、もう1枚のカードが公開されるのを待たなければなりません。

カテゴリー：スモールハンド

- カードの合計が17以上なら、必ずスタンドします。
- カードの合計が11以下なら、必ずヒットします。
- カードの合計が[12, 16]の範囲にある場合は、ディーラーが7以上を持っているときを除いて、必ずスタンドします。その場合は必ずヒットします。

全体のロジックはすでに実装されています。4つのタスクがあります。

## 1. カードの点数を計算する

条件分岐を使って、カードの名前からそのカードの数値を計算する関数を実装します。

```java
parseCard("ace")
// returns 11
```

## 2. 2枚のカードがブラックジャックになるか判定する

2枚のカードがブラックジャックを構成する場合は`true`を、そうでない場合は`false`を返す関数を実装します。

```java
isBlackjack("queen", "ace")
// returns true
```

## 3. ハンドスコアが20点より大きい場合の意思決定ロジックを実装する

カードに応じた判断を文字列で返す関数を実装します。この関数は、`handScore`が20より大きいときにだけ呼び出されます。`isBlackJack`と`dealerScore`の2つの入力を受け取ります。上記の「ラージハンド」カテゴリーの箇条書きを実装します。

```java
isBlackJack = true
dealerScore = 7
largeHand(isBlackJack, dealerScore)
// returns "W"
```

## 4. ハンドスコアが21点未満の場合の意思決定ロジックを実装する

カードに応じた判断を文字列で返す関数を実装します。この関数は、`handScore`が21未満のときにだけ呼び出されます。`handScore`と`dealerScore`の2つの入力を受け取ります。上記の「スモールハンド」カテゴリーの箇条書きを実装します。

```java
handScore = 15
dealerScore = 12
SmallHand(handScore, dealerScore)
// returns "H"
```
