# `case`文

```sather
   case zone
   when 0 then return 0;
   when 1, 2 then return 550;
   else return 920;
   end;
```

## 照合の仕組み

`case`のあとの値は、`=`を使って、それぞれの`when`の値と上から順に比較されます。最初に一致したものだけが実行されます。残りの`when`は飛ばされ、`end`のあとから実行が続きます。

`=`をサポートする型なら何でも使えます。`INT`、`CHAR`、`STR`、`BOOL`などです。

## `else`について

一致する`when`がなく、`else`もない`case`は、実行時に致命的なエラーになります。必ず書きましょう。残りのケースが本当に起こらないはずなら、`else`を省くのではなく、そう書いておきましょう。

```sather
   else
      raise "unknown zone: " + zone;
   end;
```

`raise`はあとで登場します。それまでは、妥当なデフォルト値を返しておけば大丈夫です。

## `if`が適しているとき

`case`は1つの値を定数と比較します。それ以外のことをしたいときは`if`です。

```sather
   -- ranges
   if age < 13 then ... elsif age < 16 then ... end;

   -- more than one value at a time
   if score >= 8 and sings then ... end;
```

範囲を無理に`case`に押し込もうとすると、置き換えた`if`よりも長くて読みにくいものになります。

## 式としての`case`

`case`は文であり、式ではありません。ですから、これはSatherではありません。

```sather
   -- wrong
   fare := case zone when 1 then 550 else 920 end;
```

各分岐の中で`return`するか、各分岐の中で変数に代入してください。
