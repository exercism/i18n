# 説明の補足

## `smallest`と`largest`の実装に関する注意点

どちらの関数も、2つのキーワード引数を受け取る必要があります:
- `max_factor`: int
- `min_factor`: int、デフォルトは0

戻り値は`tuple -- (value, factors)`でなければなりません。ここで`value`は回文そのもので、`factors`はその回文の2つの因数を任意の順序で含む`iterable`です。


## 例外メッセージ

ときには[例外を発生させる](https://docs.python.org/3/tutorial/errors.html#raising-exceptions)必要があります。そのときは、エラーの原因が何なのかを示す**意味のあるエラーメッセージ**を、必ず含めるようにしましょう。そうするとコードが読みやすくなり、デバッグもぐっと楽になります。エラーの原因が特定の種類であるとわかっている場合は、[組み込みのエラータイプ](https://docs.python.org/3/library/exceptions.html#base-classes)の中から選んで発生させてもかまいませんが、その場合も意味のあるメッセージを含めるようにしましょう。

この演習では、`largest()`関数または`smallest()`関数が正しい範囲にない因数のペアを受け取ったときに、[`raise`文](https://docs.python.org/3/reference/simple_stmts.html#the-raise-statement)を使って`ValueError`を「スロー」する必要があります。テストが通るのは、`exception`を`raise`すると同時に、それにメッセージを添えたときだけです。

メッセージ付きで`ValueError`を発生させるには、`exception`型の引数としてメッセージを書きます:

```python
# if the max_factor is less than the min_factor
raise ValueError("min must be <= max")
```
