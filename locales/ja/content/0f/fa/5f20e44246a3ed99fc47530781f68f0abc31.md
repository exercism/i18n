# はじめに

`if/elif/else`式を使うと、条件に応じて処理を実行できます。F#には、条件に応じて処理を実行する、さらに強力な方法がもう1つあります。それがパターンマッチングです。パターンマッチングでは、1つの値を1つ以上の_パターン_と照らし合わせて調べることができます。そうしたパターンの例が_定数パターン_で、これは値を定数（例えば`1`や`"hello"`）と照合します。

F#では、パターンマッチングは`match`キーワードを使って行います。

```fsharp
let describe number =
    match number with
    | 0 -> "Zero"
    | 1 -> "One"
```

これは他の言語の`switch`文に似ているように見えるかもしれませんが、他のパターンもあわせて使うと、パターンマッチングの真価が発揮されます。そうしたパターンの1つが_変数パターン_で、これを使うと値をキャプチャできます。

```fsharp
match number with
| 0 -> "Zero"
| i -> sprintf "Non zero: %d" i
```

場合によっては、パターンに条件を追加したいこともあるでしょう。これは_ガード_（節）と呼ばれ、`when`キーワードを使って追加できます。

```fsharp
match number with
| 0 -> "Zero"
| i when i < 0 -> "Negative number"
```

上の例では、すべての入力に一致するパターンがあるわけではありません。コンパイラーはこれを検出し、警告を出力します。これは_網羅性チェック_と呼ばれます。警告を解消するには、すべての場合を扱う必要があります。そのために使えるのが_ワイルドカードパターン_で、これはどのような値にも一致するパターンです。

```fsharp
match number with
| i when i < 0 -> "Negative number"
| _ -> "Positive number"

// No compiler warning
```

パターンマッチングは、値を上から順にそれぞれのパターンと照合し、一致するパターンが見つかると、そのパターンに対応する処理を実行します。パターンの順序が重要です！
