# 説明

お気に入りの料理本のラザニア作りを手伝ってくれるコードを書いていきます。

ラザニアを焼く工程に関わる、5つのタスクがあります。

## 1. 期待される焼き時間を分単位で定義する

ラザニアをオーブンで何分焼くべきかを返す`ExpectedBakeTime`定数を定義します。
お気に入りの料理本によると、ラザニアはオーブンに40分入れておきます。

```powershell
> $ExpectedBakeTime
> 40
```

## 2. 残りの焼き時間を分単位で計算する

ラザニアを実際にオーブンに入れておいた分数を引数に取り、`ExpectedBakeTime`を基準にして、ラザニアをあと何分焼く必要があるかを返す`RemainingTime`関数を実装します。

```powershell
> RemainingTime -Minutes 30
> 10
```

## 3. 準備にかかる時間を分単位で計算する

ラザニアに加えたい層の数を引数に取り、それらを作るのに何分かかるかを返す`PreparationTime`関数を実装します。
1層につき2分かかるものとします。

```powershell
> PreparationTime -Layers 2
> 4
```

## 4. 合計の調理時間（準備＋焼き）を分単位で計算する

`ElapsedTime`関数には、`Layers`（_ラザニアに加えた層の数_）と`Minutes`（_ラザニアをオーブンで焼いてきた分数_）という2つの仮引数があります。
この関数は、これまでに調理してきた合計の分数、つまり準備にかかった時間と、ラザニアをオーブンで焼いてきた時間を足したものを返します。

```powershell
> ElapsedTime -Layers 3 -Minutes 20
> 26
```

## 5. ラザニアができたことを知らせる通知を作成する

引数を取らず、ラザニアが食べ頃になったことを知らせるメッセージを返す`Notification`関数を定義します。

```powershell
> Notification
> "Lasagna's ready!"
```
