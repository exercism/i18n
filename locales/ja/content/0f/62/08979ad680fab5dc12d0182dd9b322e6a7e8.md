# 指示の補足

## 入力形式

ゲーム盤を表す`board`仮引数は、文字列の配列という形式です。

```javascript
['  B  ', ' B B ', 'B W B', ' W W ', '  W  '];
```

文字列の各文字が、1つのマスを表します。
マスに入る有効な値は次のとおりです。

- ` `は、空のマスに対応する空白文字です
- `B`は、黒のプレイヤーが所有するマスです
- `W`は、白のプレイヤーが所有するマスです

## 出力形式

`getTerritory`関数は、2つのプロパティを持つオブジェクトを返すことが期待されています。

- `owner`その陣地の所有者（`NONE`、`BLACK`、`WHITE`のいずれか）
- `territory`その陣地の各マスを表す座標の配列

```javascript
{
    owner: 'BLACK',
    territory: [
        [0, 0],
        [0, 1],
        [1, 0],
    ],
}
```

`getTerritories`関数は、3つのプロパティを持つオブジェクトを返すことが期待されています。

- `territoryBlack` `BLACK`のプレイヤーが所有する陣地を表す座標の配列
- `territoryWhite` `WHITE`のプレイヤーが所有する陣地を表す座標の配列
- `territoryNone` 2人のプレイヤーのどちらも所有していない陣地を表す座標の配列

```javascript
{
    territoryBlack: [
        [0, 0],
        [0, 1],
    ],
    territoryWhite: [
        [3, 0],
        [3, 1],
    ],
    territoryNone: [],
}
```
