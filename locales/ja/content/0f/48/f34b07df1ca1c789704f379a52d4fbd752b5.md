# インストール

## どのawkが入っていますか？

ExercismのAWKトラックでは、GNUのAWKである`gawk`を使います。
すでにインストールされているかもしれません。確認するには、次のコマンドを実行してみましょう。
```sh
awk --version
```

実行結果が次のようになったときは、それぞれ次のとおりです。

* `GNU Awk 5.1.0 ...`のような表示
    - GNU awkがすでに入っているので、そのまま演習を進められます。

* `awk version 20200816`のような表示
    - これは`nawk`で、BWK awk（Brian Kernighanの頭文字から）または「one true awk」とも呼ばれます。
    - MacOSやBSD系のシステムにはこれが標準で入っています。
    - インストール方法は以下を読んでください。

* `awk: not an option: --version`というエラー
    - おそらく`mawk`が入っています。
    - `awk -W version`で確認できます。`mawk 1.3.4 20200120`のように表示されるはずです。
    - mawkはとても優秀で高速なawk実装ですが、このトラックで使うgawk特有の機能の一部がありません。
    - インストール方法は以下を読んでください。

* `awk: unrecognized option: version`というエラーに続けて`BusyBox v1.35.0 ...`が表示される場合
    - Alpine Linuxを使っているのかもしれません。
    - インストール方法は以下を読んでください。

* 「command not found」というエラー
    - その場合は、PATHが壊れているか、awkそのものがインストールされていません。
    - インストール方法は以下を読んでください。

### Linux

ディストリビューションのパッケージマネージャーによって異なります。一般的には次のとおりです。
```sh
apt install gawk
yum install gawk
apk add gawk
# and so on
```
適切なコマンドを実行するには、`sudo`が必要かもしれません。

### MacOS

[Homebrew][brew]を使うのがおすすめです。リンク先の手順でインストールしてから、次を実行しましょう。
```sh
brew install gawk
```

### Windows

[WSL][wsl]の場合は、上記のLinuxの手順を参照してください。
cygwinの場合は、`gawk`パッケージをインストールします。

### ソースからコンパイルする

挑戦してみたい人は、[`gawk`のマニュアルにある手順][build]をどうぞ。
