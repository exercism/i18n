# はじめに

`jq`のプログラムは、_式のパイプライン_であることを思い出しましょう。
**変数代入**は次のルールに従います。_変数代入_とは、次のような形の式のことです。

```jq
... | expr as $varname | ...
```

## フィルターは入力をそのまま出力します

_恒等式_`.`と同じように、_変数代入_の出力は入力と同じです。
変数の値を設定することは、副作用にすぎません。

次の例は、代入のあとの`.`が最初の入力と同じであることを示しています。

```sh
$ jq -c -n '42 | (. * 2) as $double | [., $double]'
[42,84]
```

## 変数のスコープ

変数のスコープは「レキシカル」です。つまり、その変数はパイプラインの残りの部分でも使えます。
関数の中で定義された変数（関数については後で扱います）は、その関数に「ローカル」です。

## 変数名

変数名は`$`で始まる必要があります。
変数名の残りの部分は**識別子**です。英字またはアンダースコアで始まり、そのあとに英字、数字、アンダースコアが続きます。

## 分割代入

マニュアルからの引用です。

> 入力の_構造に一致する_パターンを指定することで、1つの`as`式で複数の変数を宣言できます（これは「分割代入」と呼ばれます）。

例：

```jq
[1, 2, 3] as [$a, $b, $c]
| [$a, $b, $c]     # => [1, 2, 3]
```

```jq
{"foo": "bar", "len": [10, 20]} as {foo: $f, len: [$h, $w]}
| [$f, $h, $w]     # => ["bar", 10, 20]
```

変数名を_オブジェクトのキー_に一致させると、ショートカットになります。

```jq
{"x": 4, "y": 7} as {$x, $y}
| [$x, $y]         # => [4, 7]
```

```jq
{"foo": "bar", "len": [10, 20]} as {$foo, $len}
| [$foo, $len]     # => ["bar", [10, 20]]
```

## 定数

上の例で見たように、変数は定数を保存しておくのに便利です。
コードの中に「マジックナンバー」が現れるより、定数に名前を付けたほうがよいです。

## 変数が不要なことも多い

変数を省略したほうが読みやすくなることもよくあります。

数値の配列の平均を計算する場合を考えてみましょう。

```jq
[2, 4, 8, 7]
| add as $sum
| length as $len
| $sum / $len
```

これと比べてみましょう。

```jq
[2, 4, 8, 7] | add / length
```

これは、`jq`の最も強力な側面の一つを浮き彫りにします。フィルターへの入力は、_すべての_部分式に渡されるのです。

- 入力の配列`[2,4,8,7]`が`add`に渡されます（`add`は、すべての要素に`+`演算子を適用して数値を合計します）。
- _同時に_、`[2,4,8,7]`は`length`にも渡されます。
- これらの部分式の評価が終わると、それぞれの結果が割り算され、入力の配列にある数値の平均値が返ります。
