# 詳細

例外はエラー処理の一種です。
予期しない出来事に対処するときに現れることから、例外と呼ばれています。

コードのどこでも、例外を`raise`することができます。
これは`raise`メソッドを使って行います。引数にはオブジェクトを渡します。ふつうは`Exception`オブジェクトですが、基本的な文字列を使うこともできます。
たとえば、演習のスタブでは、メソッドがまだ実装されていないことをRubyに伝えるために、組み込みの`RuntimeError`を使っています。
`raise(ExceptionObject, params)`という省略構文も使えます。
例外クラスを省略すると、デフォルトで`RuntimeError`が使われます。

たとえば、次のとおりです。

```ruby
# These are equivalent
raise RuntimeError.new("Please implement this method")
raise RuntimeError, "Please implement this method"
raise "Please implement this method"
```

Rubyはこれを見つけると、エラーをプログラムの最上位まで伝えてから終了します。

たとえば、何かを0で割ろうとすると、次のような表示になります。

```ruby
5/0

#=> Traceback (most recent call last):
#=> ...
#=> ZeroDivisionError (divided by 0)
```

重要なのは、例外は特別な対処が必要な例外的な出来事が起きたときに使うべきだという点です。
例外をプログラムの制御フローに使うべきではありません。それは悪い設計とみなされ、パフォーマンスや保守性の低下を招くことが多いからです。

## クラス階層

Rubyでは、例外はクラス階層になっており、`Exception`が基底クラスです。
Rubyの組み込み例外でよく使われるものは次のとおりです。

```
Exception
  NoMemoryError
  ScriptError
    LoadError
    NotImplementedError
    SyntaxError
  SignalException
    Interrupt
  StandardError
    ArgumentError
    IOError
    EOFError
    IndexError
    LocalJumpError
    NameError
      NoMethodError
    RangeError
      FloatDomainError
    RegexpError
    RuntimeError
    SecurityError
    SystemCallError
    SystemStackError
    ThreadError
    TypeError
    ZeroDivisionError
  SystemExit
```

あるクラスのエラーを`rescue`すると、その子クラスのエラーも`rescue`されます。
そのため、`Exception`からの`rescue`は危険な場合があります。
Rubyは、オペレーティングシステムからの「シグナル」のようなメッセージを扱うのにも例外を使います。たとえば`ctrl-c`です。
つまり、`Exception`からの`rescue`は、このシステムの「シグナル」も捕まえてしまいます。
そのため、予期しない動作を防ぐには、「すべてのエラー」を捕まえたいときは`StandardError`からの`rescue`を使うのが一般的です。

## `rescue`の構文

Rubyには、特別な対処が必要な状況のための、拡張された`rescue`節もあります。

```ruby
begin
  # ...
rescue CustomError => error
  # This block is run if a CustomError occurs
rescue AnotherCustomError => error
  # This block is run if a AnotherCustomError occurs
else
  # This block is run if no exception occurred at all
ensure
  # This block always run, regardless of whether an exception occurred
end
```

これは、たとえば、常に接続を閉じることを忘れてはいけないネットワークIOを扱うときに役立ちます。

Rubyの`rescue`ブロックでは、`retry`キーワードも使えます。これは`begin`と`rescue`の間にあるすべての処理を再実行します。

```ruby
counter = 0
begin
  counter += 1
  api_request
rescue
  retry if counter <= 3
end
```
