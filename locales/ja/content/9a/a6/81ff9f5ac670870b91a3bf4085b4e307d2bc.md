# 概要

Pythonの[比較演算子][comparisons]（_Pythonでは関係演算子とも呼ばれます_）は、2つの[被演算子][operand]の_値_を調べ、`comparison`の条件が満たされるかどうかに応じて、真偽値の`True`または`False`を返します。

次の表は、Pythonでよく使われる比較演算子をまとめたものです。

| 演算子 | 演算 | 説明 |
| -------- | -------------------------- | ------------------------------------------------------------------------- |
| `>` | 「より大きい」 | `a`の値が`b`より**厳密に**大きいとき、`a > b`は`True`です |
| `<` | 「より小さい」 | `a`の値が`b`より**厳密に**小さいとき、`a < b`は`True`です |
| `==` | 「等しい」 | `a`の値が`b`と**厳密に**等しいとき、`a == b`は`True`です |
| `>=` | 「以上」 | `a > b`であるか、値が`a == b`であるとき、`a >= b`は`True`です |
| `<=` | 「以下」 | `a < b`であるか、値が`a == b`であるとき、`a <= b`は`True`です |
| `!=` | 「等しくない」 | `a == b`が`False`のとき、`a != b`は`True`です |
| `is` | 「同一性」 | `a`と`b`が同じ_オブジェクト_である**場合に限り**、`a is b`は`True`です |
| `is not` | 「同一性の否定」 | `a`と`b`が同じ_オブジェクト_で**ない**場合に限り、`a is not b`は`True`です |
| `in` | 「包含テスト」 | `a`が`b`のメンバー、部分集合、または要素であるとき、`a in b`は`True`です |
| `not in` | 「包含テストの否定」 | `a`が`b`のメンバー、部分集合、または要素でないとき、`a not in b`は`True`です |

これらはすべて同じ優先順位を持ちます（_[ブール演算][boolean operations]より高く、算術演算やビット演算より低い_）。

## 異なるデータ型どうしの比較

異なる型のオブジェクトは（数値型を除いて）、デフォルトでは決して等しいと判定されません。
`class`の同一でないインスタンスも、その`class`がデフォルトの`object`の比較の挙動をカスタマイズする特別な[拡張比較][rich comparisons]メソッドを定義していない限り、等しいとは比較され_**ません**_。
さらに詳しく知りたい場合は、Pythonドキュメントの[値の比較][value comparisons]を参照してください。

数値型は（ほとんどが）この型一致の規則の例外です。
比較のために暗黙的に変換できるのであれば、`integer`は`float`と等しいと見なされる**こともあります**（_[`octal`][octal]が[`hexadecimal`][hex]と等しくなる_場合も同様です）。

その他の数値型（[複素数][complex numbers]、[10進数][decimal numbers]、[分数][rational numbers]）では、比較演算子は「意味をなす」ところ（_暗黙的な変換が結果を変えないところ_）で定義されていますが、比較のために元のオブジェクトを正確に変換できない場合は`TypeError`を送出します。
Pythonが数値変換に用いる規則の詳細については、Pythonドキュメントの[算術変換][arithmetic conversions]を参照してください。

```python
>>> import fractions

# A string cannot be converted to an int.
>>> 17 == '17'
False

# An int can be converted to float for comparison.
>>> 17 == 17.0
True

# The fraction 6/3 can be converted to the int 2
# The int 2 can be converted to 0b10 in binary.
>>> 6/3 == 0b10
True

# An int can be converted to a complex 
# number with a 0 imaginary part.
>>> 17 == complex(17)
True

# The fraction 2/5 can be converted to the float 0.4
>>> 0.4 == 2/5
True

>>> complex(2/5, 1/2) == complex(0.4, 0.5)
True
```

数値と`NaN`（_非数_）型との順序比較は、すべて`False`になります。
Pythonの`NaN`の定義による紛らわしい副作用は、`NaN`が`NaN`と決して等しいと比較されないことです。
Pythonでなぜ`NaN`がこのように定義されたのかに興味があれば、国際標準の策定をめぐるこちらの[NaNに関するStack Overflowの投稿][so nan post]は興味深い読み物です。

```python
>>> x = float('NaN')

>>> 3 < x
False

>>> x < 3
False

# NaN never compares equal to NaN
>>> x == x
False
```

## 文字列の比較

文字列（`str`）は、それぞれのUnicodeコードポイント（_`str`内の各コードポイントを組み込み関数[`ord()`][ord]に渡した結果で、`int`を返します_）を用いて[_辞書順_][lexographic order]に比較されます。
両方の文字列のすべてのコードポイントが一致し、_**同じ順序である**_場合、2つの文字列は等しいと見なされます。
この比較は「ペアごと」に行われます。つまり、1番目どうし、2番目どうし、というふうに進みます。
Python 3.xでは、`str`と`bytes`を直接強制変換したり比較したりすることはできません。

```python
>>> 'Python' > 'Rust'
False

>>> 'Python' > 'JavaScript'
True

# Examples with Mandarin.
# hello < goodbye
>>> '你好' < '再见'
True

# ord() of first characters
>>> ord('你'), ord('再')
(20320, 20877)

# ord() of second characters
>>> ord('好'), ord('见')
(22909, 35265)

# And with Korean words.
# Pretty < beautiful.
>>> '예쁜' < '아름다운'
False

>>> ord('예'), ord('아')
(50696, 50500)
```

## コンテナデータ型の比較

コンテナデータ型（_`lists`、`tuples`、`sets`、`dicts`など_）も[_辞書順_][lexographic order]に比較されます。両方のコンテナが同じデータ**かつ**同じデータ型を持つ場合（_`lists`と`tuples`の場合は、同じ**順序**も持つ必要があります_）は等しく、それ以外は等しくありません。

```python
>>> [1, 2] == [1, 2]
True

# But if the data is not in the same order, they are not equal.
>>> [2, 1] == [1, 2]
False

# The same holds true for tuples
>>> (3,4,5) == (5,4,3)
False

# Length is also compared
>>> [1, 2] < [1, 2, 3]
True

# Comparing dicts
>>> {'name': 'John', 'age': 19} == {'name': 'John', 'age': 18}
False

>>> {'name': 'John', 'age': 19} == {'name': 'John', 'age': 19}
True
```

## 比較の連結

比較演算子は_自由に_連結できます。
式の評価は`left`から`right`へ向かって行われることに注意してください。
たとえば、`x < y <= z`は`x < y and y <= z`と等価ですが、`y`が**一度だけ**評価される点が異なります。
どちらの場合も、`x < y`が`False`であると判明した時点で、`z`は**まったく**評価され_ません_。
これはよく`short-circuit evaluation`と呼ばれます。式の真偽値がすでに確定していれば、評価はそこで止まります。

`Short circuiting`は、さまざまなブール演算子や関数でサポートされており、Pythonでは比較の連結でも同様です。
`C`、`C++`、`C#`、`Java`を含む多くのほかのプログラミング言語とは異なり、Pythonの`a < b < c`のような連結式は、従来の[数学的な解釈][three way boolean comparison]と優先順位を持ちます。

```python
>>> x = 2
>>> y = 5
>>> z = 10

>>> x < y < z
True

>>> x < y > z
False

>>> x > y < z
False
```

## 同一性の比較

演算子`is`と`is not`は、オブジェクトの_値_ではなく、オブジェクトの[_同一性_][object identity]をテストします。
オブジェクトの同一性は作成後に変わることはなく、[`id()`][id function]関数を使って調べられます。

`<apple> is <orange>`は、`id(<apple>)` == `id(<orange>)`である場合に限り`True`と評価されます。
`<apple> is not <orange>`はその逆を返します。

`None`と`NotImplemented`はシングルトンであるため、常に`is`と`is not`を使って項目と比較するべきです。
この慣習の詳細については、Pythonリファレンスの[値の比較][value comparisons none]と[PEP8][PEP8 programming recommendations]を参照してください。

```python

# A list of favorite numbers.
>>> my_fav_numbers = [1, 2, 3]

>>> your_fav_numbers = my_fav_numbers

>>> my_fav_numbers is your_fav_numbers
True

# The returned id will differ by system and Python version.
>>> id(my_fav_numbers)
4517478208

# your_fav_numbers is only an alias pointing to the original my_fav_numbers object.
# Assigning a new name does not create a new object.
>>> id(your_fav_numbers)
4517478208


>>> my_fav_numbers is not your_fav_numbers
False

>>> my_fav_numbers is not None
True

>>> my_fav_numbers is NotImplemented
False
```

## メンバーシップの比較

演算子`in`と`not in`は_メンバーシップ_をテストします。
`<fish> in <soup>`は、`<fish>`が`<soup>`のメンバーである場合（_`<fish>`が`<soup>`の部分集合であるか、`<soup>`に含まれる場合_）に`True`と評価され、それ以外は`False`と評価されます。
`<fish> not in <soup>`は、その否定、つまり`<fish> in <soup>`の_反対_を返します。

文字列型とbytes型では、`<name>`が`<fullname>`の部分文字列である場合に限り、`<name> in <fullname>`は`True`です。

```python

# A set of lucky numbers.
>>> lucky_numbers = {11, 22, 33}
>>> 22 in lucky_numbers
True

>>> 44 in lucky_numbers
False

# A dictionary of employee information.
>>> employee = {'name': 'John Doe', 'id': 67826, 'age': 33, 'title': 'ceo'}

# Checking for the membership of certain keys.
>>> 'age' in employee
True

>>> 33 in employee
False

>>> 'lastname' not in employee
True

# Checking for substring membership
>>> name = 'Super Batman'
>>> 'Bat' in name
True

>>> 'Batwoman' in name
False
```
