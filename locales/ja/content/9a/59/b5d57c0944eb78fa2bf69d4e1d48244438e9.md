# 説明

熱心なバードウォッチャーとして、過去7日間に庭に何羽の鳥が訪れたかを記録しています。

取り組むタスクは6つあり、どれも庭に訪れた鳥の数に関するものです。

## 1. 先週の数を確認する

比較のために、先週の数をいつも手元に控えています。先週の数は、0、2、5、3、7、8、4でした。先週の数を保持する`lastWeek`という束縛を定義してください：

```fsharp
lastWeek
// => [| 0; 2; 5; 3; 7; 8; 4 |]
```

## 2. 昨日訪れた鳥の数を確認する

`yesterday`関数を実装して、昨日庭に訪れた鳥の数を返すようにしてください。鳥の数は日付の順に並んでいて、最初の要素が最も古い日の数、最後の要素が今日の数です。

```fsharp
yesterday [| 3; 5; 0; 7; 4; 1 |]
// => 4
```

## 3. 訪れた鳥の合計数を計算する

`total`関数を実装して、庭に訪れた鳥の合計数を返すようにしてください：

```fsharp
total [| 3; 5; 0; 7; 4; 1 |]
// => 20
```

## 4. 鳥が訪れなかった日があったか確認する

庭に訪れた鳥が0羽だった日があれば`true`を返し、そうでなければ`false`を返す`dayWithoutBirds`関数を実装してください：

```fsharp
dayWithoutBirds [| 3; 5; 0; 7; 4; 1 |]
// => true
```

## 5. 今日の数を増やす

`incrementTodaysCount`関数を実装して、今日の数を1増やし、更新後の数を返すようにしてください：

```fsharp
let birdCount = [| 3; 5; 0; 7; 4; 1 |]
incrementTodaysCount birdCount
// => [| 3; 5; 0; 7; 4; 2 |]
```

## 6. いつもと違う週がないか確認する

この1年間で、いくつかの週には同じいつもと違うパターンがあることに気づきました：
- 週の偶数番目の日には、鳥が1羽もいませんでした
- 週の偶数番目の日には、ちょうど10羽の鳥が確認されました
- 週の奇数番目の日には、ちょうど5羽の鳥が確認されました

今週の鳥の数のパターンが、こうしたパターンのいずれかに一致する場合に`true`を返す`unusualWeek`関数を実装してください：

```fsharp
unusualWeek [| 1; 0; 5; 0; 12; 0; 2 |]
// => true

unusualWeek [| 5; 0; 5; 12; 5; 3; 5|]
// => true
```

（日の偶奇は0始まりではなく1始まりであることに注意してください。配列の最初の要素は奇数番目の日に対応します）
