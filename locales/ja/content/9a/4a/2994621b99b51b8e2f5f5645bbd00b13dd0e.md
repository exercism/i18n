# 指示

近くの学校には、とても活発な生徒会があります。
生徒会は会長によって運営されていて、2年ごとに新しい会長を選ぶ選挙が行われます。

今年の選挙では、票を数えるための新しいデジタルシステムが必要だということになりました。
学校は、この新しいシステムを作るために皆さんの助けを必要としています。

## 1. `ElectionResult`から票の数を取得する

新しいシステムには、カウンターから票の数を取得する方法が必要です。

選挙結果の構造体はすでに用意されていて、次のように定義されています：

```cpp
struct ElectionResult {
    // Name of the candidate
    std::string name{};
    // Number of votes the candidate has
    int votes{};
};
```

`struct`のメンバーはすべてpublicなので、`ElectionResult`オブジェクトを初期化するために`constructor`を書く必要はありません。
代わりに`initializer list`を使うことができます：

```cpp
ElectionResult hamilton{"Alex", 1804};
// => the hamilton object was initialized with the name "Alex" and 1804 votes.
```

`ElectionResult`への参照を引数として受け取り、その`ElectionResult`の票数を返す関数`vote_count`を作成しましょう。

```cpp
vote_count(hamilton);
// => 1804
```

## 2. `ElectionResult`の票を増やす

いよいよ票を処理するときが来ました！　次は、`ElectionResult`の票を増やす方法が必要です。

`ElectionResult`への参照と票数を引数として受け取り、その`ElectionResult`の票をその数だけ増やす`void`関数`increment_vote_count`を作成しましょう。

```cpp
ElectionResult burr{"Aaron " 1801};

increment_vote_count(burr, 3);

vote_count(burr);
// => 1804
```

## 3. 開票と当選

学校は票を提出しました。いよいよ当選者を確認するときです。

最終集計への参照を受け取り、新しい会長の`ElectionResult`への参照を返す関数`determine_result`を作成しましょう。
また、当選者の名前の先頭に"President"を付けて変更します。
最終集計は、立候補したすべての候補者の`ElectionResults`を要素に持つ`std::vector<ElectionResult>`への`reference`として渡されます。

```cpp
ElectionResult sanchez{"Pedro", 471};
ElectionResult wheatley{"Summer", 340};
std::vector<ElectionResult> final_count{sanchez, wheatley};

ElectionResult& winner = determine_result(final_count);

winner.name;
// => "President Pedro"
```

簡単にするために、次のことを前提としてかまいません：
- `vector`には少なくとも1つの要素があります。
- 1位が同点になることはありません。
