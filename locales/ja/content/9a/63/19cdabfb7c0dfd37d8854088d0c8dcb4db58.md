# 概要

メソッドの仮引数は、デフォルト値を代入することで省略可能にできます。仮引数が省略可能なとき、呼び出し側はその仮引数に引数を渡す必要がありません。その場合、デフォルト値が使われます。[省略可能な仮引数][optional-arguments]は、仮引数リストの末尾に _必ず_ 置く必要があり、その後ろに省略可能でない仮引数を置くことはできません。メソッドに複数の省略可能な仮引数がある場合は、[名前付き引数][named-arguments]を使えばその一部だけを指定できます。

```csharp
class Card
{
    static string NewYear(int year = 2020, string sender = "me")
    {
        return $"Happy {year} from {sender}!";
    }
}

Card.NewYear();     // => "Happy 2020 from me!"
Card.NewYear(1999); // => "Happy 1999 from me!"
Card.NewYear(sender: "mom"); // => "Happy 2020 from mom!"
```

省略可能な仮引数の値は、次のいずれかでなければなりません。

- 定数式（例：`"hi"`、`2`、`DayOfWeek.Friday`、`null`など）
- 値型の`new`式
- 値型の`default`式
