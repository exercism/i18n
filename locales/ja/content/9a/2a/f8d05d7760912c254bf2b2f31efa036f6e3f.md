# 説明

チェスの愛好家なら、自分だけのバージョンのゲームを書いてみたくなるでしょう。確かに、オンラインにはすでにたくさんのチェスの実装が出回っていますが、自分で作るものは世界に一つだけのものです！

でも、想像を膨らませる前に、まずは基本を押さえる必要があります。ボードの生成から始めましょう。

チェスボードの各マスは、文字と数字のペアで識別されます。マスの縦の列はファイルと呼ばれ、AからHまでのラベルが付いています。マスの横の行はランクと呼ばれ、1から8までの番号が付いています。

## 1. ランクの範囲を定義する

`rank_range()`関数を実装しましょう。1から8までの整数の範囲を返します。

```julia-repl
julia> rank_range()
# output omitted
```

## 2. ファイルの範囲を定義する

`file_range()`関数を実装しましょう。
大文字の`A`から大文字の`H`までの文字の範囲を返します。

```julia-repl
julia> file_range()
# output omitted
```

## 3. ランクの範囲をランクのベクトルに変換する

`ranks()`関数を実装しましょう。1から8までの整数のベクトルを返します。
ベクトルを手で書かず、`rank_range()`関数が返す範囲から生成しましょう。

```julia-repl
julia> ranks()
[1, 2, 3, 4, 5, 6, 7, 8]
```

## 4. ファイルの範囲をファイルのベクトルに変換する

`files`関数を実装しましょう。`'A'`から`'H'`までの文字のベクトルを返します。
ベクトルを手で書かず、`file_range()`関数が返す範囲から生成しましょう。

```julia-repl
julia> files()
['A', 'B', 'C', 'D', 'E', 'F', 'G', 'H']
```
