# 概要

## `for`ループ

`for`文は、コードのブロックを繰り返し実行します。
その最初の行が、ブロックを何回繰り返すかを制御します。

```go
for init; condition; post {
    // loop body
}
```

- **init**の文は、最初の繰り返しの前に一度だけ実行されます。ループで使うカウンター変数を宣言して初期化するのが一般的です。
- **condition**は、各繰り返しの前に評価される真偽値の式です。これが`false`と評価されると、ループは止まります。
- **post**の文は、繰り返しが1回終わるたびに実行されます。カウンターの更新に使えます。

`init; condition; post`を括弧（`()`）で囲まないでください。
ただし、ループ本体を囲む波括弧（`{ }`）は常に必要です。

次のループは、`i`を`1`から始め、`i`の現在の値を出力し、次の繰り返しのために`i`を増やし、`i`が`10`になったところで止まります。

```go
for i := 1; i < 10; i++ {
    fmt.Println(i)
}
```

## その他のループの形

### conditionだけのループ

initとpostの文は省略できます。
conditionだけを書いた`for`文は、他の言語の`while`ループと同じ役割を果たします。
Goには`while`キーワードはありません。

```go
sum := 1
for sum < 1000 {
    sum += sum
}
fmt.Println(sum)
// Output: 1024
```

### 無限ループ

`for`文は、conditionを書かずに書くこともできます。

```go
for {
    // loop body
}
```

このループは、ひとりでに終わることはありません。ループからは、たとえば`break`や`return`を使って明示的に抜ける必要があります。

## ループの制御

### `break`と`continue`

次のループでは、`break`がループを抜けます。

```go
for n := 0; n <= 5; n++ {
    if n == 3 {
        break
    }
    fmt.Println(n)
}
// Output:
// 0
// 1
// 2
```

`continue`は、現在のループ本体の残りをとばして、次の繰り返しを始めます。

```go
for n := 0; n <= 5; n++ {
    if n % 2 == 0 {
        continue
    }
    fmt.Println(n)
}
// Output:
// 1
// 3
// 5
```

### ラベル付きの`break`と`continue`

入れ子のループでは、ラベルを付けない`break`や`continue`は、最も内側のループに作用します。
外側のループにラベルを付けるには、そのループのすぐ上の行に、識別子とコロンを書きます。
そのうえで、`break`や`continue`の後にそのループのラベルを書くと、動作をそのループに向けられます。

```go
OuterLoop:
for i := 0; i < 10; i++ {
    for j := 0; j < 10; j++ {
        if i + j == 10 {
            break OuterLoop
        }
    }
}
```
