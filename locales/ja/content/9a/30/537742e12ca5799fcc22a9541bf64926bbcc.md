# 指示の補足

## 予約されたメモリ

入力文字列用のバッファーは、線形メモリの64バイト目から191バイト目までを使います。


## 出力形式

一連の数値は、`u8`の数値が連続した1つの配列として返すことが期待されています。この配列は、デシリアライズの際に指定した長さで分割されます。

```js
slice("123456", 3) => UInt8Array[1, 2, 3,   2, 3, 4,   3, 4, 5,   4, 5, 6]
// will be split into          [[1, 2, 3], [2, 3, 4], [3, 4, 5], [4, 5, 6]]
```
