# 概要

デフォルトでは、変数は定義されたスコープに限定されます。関数やクラスの外にあるファイルの中で定義した場合、その変数はファイルのスコープに限定されます。関数やクラスの中で定義した場合、その関数やクラスのスコープに限定されます。

```php
<?php

$file_scoped = "I am file scoped";

function example(): void
{
  $function_scoped = "I am function scoped!";
}
```

## グローバルスコープ

変数への代入の前にキーワード`global`を使うと、グローバルスコープを持つ変数が作られます。このパターンは、[密結合なコード](<https://en.wikipedia.org/wiki/Coupling_(computer_programming)#Disadvantages_of_tight_coupling>)を生み出すため、しばしば推奨されません。

```php
function example(): void
{
  global $hello = "World!";
}

echo $hello; // #=> "World!"
```

## 静的スコープ

変数の代入や宣言の前にキーワード`static`を使うと、変数のスコープはそのままに、その値が実行スコープをまたいで保持されます。

```php
function counter(): int
{
  static $count = 0;
  $count += 1;
  return $count;
}
```

この例では、`$count`変数が0に初期化されるのは_最初の関数呼び出しのときだけ_です。それ以降の呼び出しでは、値は次の呼び出しに引き継がれます。そのため、この関数を呼び出すたびに、増えていく整数が返されます。
