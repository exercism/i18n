# はじめに

`Option`型は、値が存在するかもしれないし、存在しないかもしれない場合を扱うためのF#言語の仕組みです。
こうした値を扱うために他の言語でよく使われる`null`に代わる、型安全な手段を提供します。
F#の標準ライブラリにある多くの関数で使われているため、F#標準ライブラリを効果的に使うには、これを理解することが欠かせません。

## 使い方

`Option`型はジェネリック型（基になる型を持つ型）です。  
`Option`の値は、何らかの具体的な値を表す`Some value`か、値がないことを表す`None`のいずれかです。

次の関数は、`Option`の値を作る方法を示しています。

```fsharp
let keepIfPositive (a: int) : int option = if a > 0 then Some a else None
```

~~~~exercism/note
`T option`は`Option<T>`に相当する後置構文で、2つの構文は同じ意味で使えます。
ただし、F# Style Guideによれば、Option型には後置記法が推奨されています（[F# Style Guideの型の書式設定と型注釈に関するセクション](https://learn.microsoft.com/en-us/dotnet/fsharp/style-guide/formatting#for-types-prefer-prefix-syntax-for-generics-foot-with-some-specific-exceptions)を参照）。
~~~~

## `Option`の値の中身を読む

`Option`の値を読み取る慣用的な方法は、次の例のようにパターンマッチングを使うことです。

```fsharp
// Returns "Hello, <name>!" if the name is provided; otherwise returns "Hello, you!"
let sayHello (optionalName: string option): string = 
    match optionalName with
    | Some name -> "Hello, " + name + "!"
    | None -> "Hello, you!"

sayHello (Some "Matthieu")
// --> "Hello, Matthieu!"

sayHello None
// --> "Hello, you!"
```

## デフォルト値で`Option`を取り出す

`Option`は、`Option.defaultValue`関数でデフォルト値を指定すると「取り出す」（中に入っている型に変換する）ことができます。
これは、値が`None`でないことを確実にしたいときに特に役立ちます。
例えば、次のようになります。

```fsharp
Option.defaultValue "" (Some "F#")
// --> "F#"

Option.defaultValue 0 None
// --> 0
```
