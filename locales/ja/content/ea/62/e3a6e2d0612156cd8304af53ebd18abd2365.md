# 指示の補足

## プロジェクトの構成

ExercismのClojureの演習では、依存関係の管理とテストのための最も一般的な2つのツール、[leiningen][leiningen]と[Clojure CLI][clojure-cli]に対応しています。

`test`ディレクトリの中に、`hello_world_test.clj`というテストファイルがあります。コードは`src/hello_world.clj`に書きましょう。テストが読み込めるように、名前空間`hello-world`を使います。

### Clojure CLIを使ったテストの実行

```
$ clj -X:test
```

### Leiningenを使ったテストの実行

```
$ lein test

lein test hello-world-test

Ran 3 tests containing 3 assertions.
0 failures, 0 errors.
```

次に、次のコマンドで演習を提出します。

```
$ exercism submit src/hello_world.clj
```

より詳しい指示や学習リソースについては、[ExercismのClojure言語ページ][exercism-clojure]を参照してください。

[leiningen]: https://leiningen.org
[clojure-cli]: https://clojure.org/guides/deps_and_cli
[exercism-clojure]: https://exercism.org/tracks/clojure
