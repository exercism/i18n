# はじめに

Raspberry Piを使って何かを作ろうと思ったら、おそらく_抵抗器_を使うことになるでしょう。前の[`Resistor Color Duo`][resistor-color-duo-exercise]と[`Resistor Color Trio`][resistor-color-trio-exercise]の演習と同じように、ここでは抵抗のカラーバンドを、人間が読めるラベルに変換していきます。

- 抵抗器にはそれぞれ抵抗値があります。
- 抵抗器はとても小さく、抵抗値をそのまま印刷しても読み取れないほどです。この問題を回避するために、メーカーは抵抗値を示す色分けされたバンドを抵抗器に印刷しています。
- それぞれのバンドは、数値の1桁を表します。たとえば、茶色のバンド（値1）の次に緑色のバンド（値5）を印刷すると、それは15という数値になります。

[resistor-color-trio-exercise]: https://exercism.org/tracks/python/exercises/resistor-color-trio
