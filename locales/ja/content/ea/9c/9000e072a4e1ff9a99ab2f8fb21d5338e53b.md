# はじめに

Pythonでは、[列挙型](https://docs.python.org/3/library/enum.html)は、一意の`literal`または`constant`値に紐付けられた名前の集合です。列挙型は、`Enum`クラスを継承して定義します。組み込みの列挙型はモジュール`enum`で利用でき、`Enum`クラスは`from enum import Enum`でインポートできます。

```python
class Color(Enum):
    RED = 1
    GREEN = 2
```

列挙型のメンバーの値は、`str`、`tuple`、`float`などの任意のデータ型にできることに注意してください。

```python
class Color(Enum):
    RED = 'red'
    GREEN = 'green'
```

列挙型で同じ値を2つのメンバーに代入すると、後に代入されたメンバーは、先に定義されたメンバーのエイリアスになります。列挙型の2つのメンバーに同じ名前を使うことはできません。

```python
class Color(Enum):
    RED = 1
    GREEN = 2
    ALIAS_OF_RED = 1

Color.ALIAS_OF_RED
#=> <Color.RED: 1>

Color.ALIAS_OF_RED.value
#=> 1
```

列挙型のメンバーを繰り返し処理するには、標準の`for member in`構文を使います。

```python
for member in Color:
    print((member.name, member.value))
#=> (RED, 1)
#=> (GREEN, 2)
```

列挙型のメンバーは、[`is`（_同一性演算子_）](https://www.w3schools.com/python/ref_keyword_is.asp)または`is not`を使って比較できます。`==`または`!=`（_等価演算子_）も同様に機能します。

```python
a = Color.RED

a is Color.RED
#=> True

a == Color.RED
#=> True
```

指定した値の列挙型メンバーにアクセスするには、`EnumName(value)`を使います。

```python
g = Color(2)

g is Color.GREEN
#=> True

g
#=> <Color.GREEN: 2>
```
