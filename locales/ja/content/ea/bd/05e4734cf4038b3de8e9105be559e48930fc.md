# ヒント

## 全般

- Pythonのドキュメントにある[文字列のチュートリアル][python-str-doc]では、Pythonの`str`型の概要が説明されています。
- 文字列を処理するときには、文字列メソッドの[`str.join()`][str-join]と[`str.split()`][str-split]がとても役立ちます。
- Pythonのドキュメントの[シーケンス型][common sequence operations]には、`strings`、`lists`、`tuples`、`ranges`を含む、すべてのシーケンスに共通する操作の一覧があります。

この課題には4つのアクティビティがあり、それぞれ扱うテキストや単語のセットがあります。

## 1. 単語に接頭辞を付ける

- 短い文字列は`+`演算子で連結できます。

## 2. 単語のグループに接頭辞を付ける

- 信じられないかもしれませんが、ここでは[`str.join()`][str-join]だけで十分です。**ループは必要ありません**。
- テストは、あなたの関数に`list`を渡します。適切な区切り文字列を見つけられれば、この`list`を変更する必要はありません。
- 区切り文字列は要素の間に入り、それらを1つの文字列として「接着」することを覚えておきましょう。区切り文字は、スペースを_入れずに_挿入されますが、区切り文字自体にスペース文字を含めることはできます。
- [`str.split()`][str-split]と同様に、`str.join()`は、任意のUnicodeコードポイントで構成された任意の長さの文字列を処理できます。`str.split()`とは_異なり_、`list`、`tuple`、`set`のような任意の長さのイテラブルも処理できます。

## 3. 単語から接尾辞を取り除く

- 文字列は、左（0から始まる）からでも、右（-1から始まる）からでもインデックスやスライスができます。
- 任意の長さの文字列の最後のコードポイントが欲しいときは、`[-1]`を使えます。
- 文字列の最後の3文字は、負のインデックスを使って「スライスして取り除く」ことができます。例：`beautiful'[:-3] == 'beauti`

## 4. 単語を抽出して変換する

- [`str.split()`][str-split]を使うと、空白で分割された文字列の`list`が返されます。
- `lists`はシーケンスであり、インデックスを指定できます。
- [`str.split()`][str-split]には直接インデックスを指定できます：`'Exercism rocks!'.split()[0] == 'Exercism'`
- 句読点に注意しましょう！　ピリオドはスライスで取り除けます：`'dark.'[:-1] == 'dark'`
