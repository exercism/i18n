# はじめに

## 条件文

条件文は、副作用を実行したり、プログラムの実行の流れを制御したりする、意思決定のための文です。
条件文には、`if`文、`if/else`文、`switch`文、`ternary`文があります。

条件文は、ある値や、値どうしの関係について問いを立てるために使います。
その問いは真偽値の答えに評価されますが、`if`文自体はどんな値でも返すことができますし、単に副作用を実行することもできます。

## `if`文

最も単純な`if`文は、式を評価して1行を実行します。
判定する式は、必ず括弧（`()`）で囲みます。

副作用を実行することもできます。

```c
if (count > 10)
    printf("count is greater than 10");
```

実行の流れを変えることもできます。


```c
if (count > 10)
    return sum;
```

`if`文が複数の行を実行する場合は、その行を波括弧で囲む必要があります。

```c
if (count > 10) {
    printf("count is greater than 10");
    return sum;
}
```

開発チームによっては、1行の場合でも常に波括弧を使うように`if`文を統一していることもあります。


## `if`と`else`

`if`文は`else`と組み合わせることができます。

```c
if (number % 2 == 0)
    return "even";
else
    return "odd";
```

## `if`と`else if`


`else`は別の`if`と組み合わせることで、`if-else-if ladder`と呼ばれるものを作ることができます。

```c
if (number == 0)
    return "zero";
else if (number < 0)
    return "negative";
else if (number < 10)
    return "single digit";   
else if (number % 2 == 0)
    return "even";
else
    return "odd";
```

## `switch`文


ときに`if-else-if ladder`は、`switch`を使うとよりうまく表せます。
`if`と同様、判定する式は必ず括弧で囲みます。

```c
switch (number) {
    case -1:
        return "negative one";
    case 0:
        return "zero";
    case 1:
        return "positive one";
    case 10:
        return "positive ten";
    case -10:
        return "negative ten";
    default:
        return "don't care";
}
```

`default`ケースは、判定する値がそれまでのどのケースにも一致しない場合に実行されます。

`switch`のケースが値を返さない場合は、ふつう各ケースを終わらせるために`break`を入れます。そうしないと、処理が次のケースへ「フォールスルー」してしまいます。
フォールスルーが意図的に使われることもあります。

```c
switch (number) {
    case 0:
        msg = "zero"; break;
    case 1:
        msg = "one"; break;
    case 2: case 3: case 4:
        msg = "more than one and less than five"; break;
    default:
        msg = "don't care";
}
```

フォールスルーが意図せず起こったときは、バグです。

```c
switch (number) {
    case 0:
        msg = "zero"; // bug! fallthrough of 0 will set msg to "one"
    case 1:
        msg = "one"; break; 
    case 2: case 3: case 4:
        msg = "more than one and less than five"; break;
    default:
        msg = "don't care";
}
```

`switch`は、値の範囲ではなく特定の値と比較するときに役立ちます。
コンパイラーが`switch`文を、はしごではできない方法で最適化できる場合があるため、`if-else-if ladder`より速くなることがあります。
また、`switch`のほうがはしごより読みやすく見えることもあります。

## 三項演算子（別名、条件演算子）

三項演算子は、値を設定するときによく使われる、3つの部分からなる条件文です。
判定する式は疑問符の前に置き、必ずしも括弧で囲む必要はありません。
真のときに返す値はコロンの前に、偽のときに返す値はコロンの後に置きます。
返す値には、値のリテラルも変数も使えます。

```c
int i = j > 5 ? 5: j;
```

三項演算子は入れ子にして、構文上のごちゃつきを減らすことができます。

```c
// the below could also be 
i = j > 5 ? j :k > 5 ? k: 10;
// but that may not be quite as readable

i = j > 5 ? j
    :k > 5 ? k
    :10;

// which is the same as
if (j > 5) i = j;
else if (k > 5) i = k;
else i = 10;
```
