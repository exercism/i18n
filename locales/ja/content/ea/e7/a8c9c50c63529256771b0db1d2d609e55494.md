# はじめに

内包表記は、_Enumerable_を簡単かつ宣言的に変換するための仕組みです。

とてもシンプルな内包表記を書くには、`for`キーワードのあとに_ジェネレーター_と_doブロック_を続けます。doブロックが、列挙された値から新しい値を作り出します。

```elixir
for n <- [0, 1, 2, 3], do: n + 1
# => [1, 2, 3, 4]
```

内包表記には_フィルター_を付けることもできます。フィルターを通過しない値は、最終的な配列から取り除かれます：

```elixir
for n <- [0, 1, 2, 3], n > 1, do: n + 1
# => [3, 4]
```

もっと複雑な内包表記は、複数行にわたって書くこともできます：

```elixir
for {atom, number} <- [a: 1, b: 2, c: 3, d: 4],
    rem(number, 2) == 0 do
  atom
end

# => [:b, :d]
```

複数のジェネレーターを使うと、_直積_を作ることができます。つまり、最初のジェネレーターが生成するそれぞれの値は、2番目のジェネレーターが生成するそれぞれの値と一度ずつ組み合わされます：

```elixir
for x <- [0, 1],
    y <- [0, 1] do
  {x, y}
end

# => [{0, 0}, {0, 1}, {1, 0}, {1, 1}]
```
