# はじめに

## 定数

`const`修飾子は、値がコンパイル時に決まっていて、プログラムの実行中に変化しないフィールドになら（そして一般にはそうすべきですが）適用できます。

```csharp
private const int num = 1729;
public const string title = "Grand" + " Master";
```

`readonly`修飾子は、`const`にはできないフィールドになら適用できます。そうしたフィールドは、プログラムの実行中に値が変化せず、インライン初期化子か、インスタンス化のとき（コンストラクター、またはコンストラクターから呼ばれるメソッド）に値が設定されます。こちらも一般には適用しておくべきです。

```csharp
private readonly int num;
private readonly System.Random rand = new System.Random();

public MyClass(int num)
{
    this.num = num;
}
```

## 防御的コピー

セキュリティーが重要な場面では（あるいは、開発者の優先順位や思惑がそれぞれ違うような大規模なコードベースでは、それだけでも）、次のような状態は避けるべきです。すなわち、メソッドの可変な引数を受け取って保存したり、クラスの可変なメンバーを戻り値や`out`引数として公開したりして、クラスのパブリックAPIを迂回できてしまう状態です。

## 読み取り専用のコレクション

`readonly`修飾子は、フィールドの値や参照が上書きされるのを防ぎますが、参照型のメンバーは保護しません。

```csharp
readonly List<int> ints = new List<int>();

void Foo()
{
    ints.Add(1);    // ok
    ints = new List<int>(); // fails to compile
}
```

参照型のすべてのメンバーを保護するには、フィールドを`readonly`にし、自動プロパティを`set`アクセサーなしで定義します。

基底クラスライブラリー（BCL）には、コレクションのメンバーが更新されないようにする必要がある場合のための、読み取り専用バージョンのコレクションが用意されています。それらはラッパーという形で提供されます。

- `ReadOnlyDictionary<T>`は、`Dictionary<T>`を読み取り専用として公開します。
- `ReadOnlyCollection<T>`は、`List<T>`を読み取り専用として公開します。
