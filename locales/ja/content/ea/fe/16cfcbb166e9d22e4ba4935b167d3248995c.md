# 説明

そこの君！　そう、勇敢なLisp使いの君です！　[Lisp宇宙人のLenny][alien]が助けを必要としています！　LennyはほかのLisp宇宙人たちと遊びに出かけたがっていますが、両親から、部屋をきれいにするまでどこにも行かせないと言われています。

困ったことに、Lennyには床がほとんど見えません！　アトムとコンスの区別も、シンボルとキーワードの区別も、`car`と`cdr`の区別もつきません！

Lennyがこの散らかった部屋を片付けるのを手伝ってあげませんか？　[括弧][xkcd]を忘れないでくださいね。必要になりますから！

## 1. Lennyにシンボルをおさらいしてもらう

Lennyが始める前に、シンボルとキーワードがどんなものかをもう一度おさらいする必要があります。最後に片付けてからずいぶん時間がたっていますからね…。2つの関数を定義して、Lennyを手伝ってあげましょう。`lennys-favorite-food`は何らかのシンボルに評価され、`lennys-secret-keyword`は何らかのキーワードに評価されます。たとえば次のようになります。

```lisp
(lennys-favorite-food) ; => LASAGNA
```

```lisp
(lennys-secret-keyword) ; => :ALIENS-ARE-REAL
```

好きなシンボルやキーワードを返してかまいません（ラザニアが好きでなかったり、宇宙人の存在を信じていなかったりしても大丈夫です）。

## 2. Lennyがアトムとコンスを見分けられるように手伝う

シンボルとキーワードのおさらいが済んだら、いよいよ掃除の時間です！　部屋のあちこちに散らばったS式を仕分けるために、Lennyはどれがコンスでどれがアトムなのかを見極める助けを必要としています。2つの関数、`is-an-atom-p`と`is-a-cons-p`を実装して手伝ってあげましょう。

```lisp
(is-an-atom-p 'one-thing)    ; => T
(is-an-atom-p '(two things)) ; => NIL
```

```lisp
(is-a-cons-p 'one-thing)    ; => NIL
(is-a-cons-p '(two things)) ; => T
```

このセクションでは、役に立つかもしれないLispの組み込み関数がいくつかあります。また、今のところは、`T`を真、`NIL`を偽と単純に考えておけば大丈夫です。

## 3. Lennyがコンスを分割できるように手伝う

最後に、Lennyのコンスはかさばりすぎてきちんと片付けられないので、小さな部品に分ける必要があります。コンスを分解するための2つの関数（`first-thing`と`rest-of-it`）を定義して、手伝ってあげませんか？

```lisp
(first-thing '(first second third)) ; => FIRST
(rest-of-it  '(first second third)) ; => (SECOND THIRD)
```

ここでも、Common Lispの組み込み関数がいくつか役に立つでしょう。
