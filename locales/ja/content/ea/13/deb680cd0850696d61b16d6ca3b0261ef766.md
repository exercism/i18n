# はじめに

[Go](https://golang.org)は、静的型付けのコンパイル言語です。この演習では、パッケージ、関数、変数という3つの主要な言語機能を紹介します。

## パッケージ

Goのアプリケーションは、パッケージという単位で構成されます。パッケージとは、同じディレクトリにあるソースファイルをまとめたものです。同じディレクトリにあるソースファイルは、すべて同じパッケージ名でなければなりません。パッケージをインポートしたとき、名前が大文字で始まるもの（関数、型、変数、定数）だけが使用・アクセスできます。Goで推奨される命名スタイルでは、識別子は`camelCase`で命名します。ただし、パッケージをまたいでアクセスできるようにするものは`PascalCase`にします。

```go
package lasagna
```

## 変数

Goは静的型付けであり、すべての変数は[コンパイル時に型が定義されている必要があります](https://en.wikipedia.org/wiki/Type_system)。

変数は、型を明示的に指定して定義できます。

```go
var explicit int // Explicitly typed
```

初期化子を使うこともできます。その場合、コンパイラーが初期化子の型に合わせて変数の型を割り当てます。

```go
implicit := 10   // Implicitly typed as an int
```

一度宣言した変数には、`=`演算子を使って値を代入できます。一度宣言すると、変数の型を変更することはできません。

```go
count := 1 // Assign initial value
count = 2  // Update to new value

count = false // This throws a compiler error due to assigning a non `int` type
```

## 定数

定数は変数と同じようにデータを保持しますが、プログラムの実行中にその値を変更することはできません。

定数は`const`キーワードを使って定義し、数値、文字、文字列、真偽値のいずれかにできます。

```go
const Age = 21 // Defines a numeric constant 'Age' with the value of 21
```

## 関数

Goの関数は、0個以上の仮引数を受け取ります。仮引数は明示的に型を指定する必要があり、型推論はありません。

値は`return`キーワードを使って関数から返されます。

関数は、関数名を指定し、その関数の各仮引数に引数を渡すことで呼び出します。

Goでは2種類のコメントが使えることに注意してください。1行コメントは`//`で始め、複数行コメントは`/*`と`*/`の間に書きます。

```go
package greeting

// Hello is a public function.
func Hello (name string) string {
    return hi(name)
}

// hi is a private function.
func hi (name string) string {
    return "hi " + name
}
```
