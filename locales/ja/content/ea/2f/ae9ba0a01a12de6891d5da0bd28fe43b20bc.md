# 指示

この演習では、工場の従業員向けの名札を印刷するコードを書きます。

## 1. 従業員の名札を印刷する

従業員にはID、名前、部署名があります。従業員の名札のラベルは、次のようにフォーマットします：`"[id] - name - DEPARTMENT"`。
`Badge.print()`メソッドを実装して、従業員の名札のラベルを返すようにしましょう：

```java
Badge badge = new Badge();
badge.print(734, "Ernest Johnny Payne", "Strategic Communication");
// => "[734] - Ernest Johnny Payne - STRATEGIC COMMUNICATION"
```

ラベルでは、部署名を大文字にする必要がある点に注意しましょう。

## 2. 新しい従業員の名札を印刷する

コンピューターシステムのちょっとした不具合で、新しい従業員が工場で働き始めるときに、まだIDを持っていないことがあります。
名札は必須なので、そのような従業員にはIDのプレフィックスがない一時的な名札が渡されます。まだIDを持っていない新しい従業員に対応できるように、`Badge.print()`メソッドを変更しましょう：

```java
Badge badge = new Badge();
Badge.print(null, "Jane Johnson", "Procurement");
// => "Jane Johnson - PROCUREMENT"
```

## 3. オーナーの名札を印刷する

工場のオーナーも、いつでも名札を着けなければなりません。
ただし、オーナーには部署がありません。この場合は、ラベルに部署名の代わりに`"OWNER"`と出力します。
オーナー用のラベルを出力できるように、`Badge.print()`メソッドを変更しましょう：

```java
Badge badge = new Badge();
badge.print(254, "Charlotte Hale", null);
// => "[254] - Charlotte Hale - OWNER"
```

オーナーが新しい従業員でもある場合があることに注意しましょう：

```java
Badge badge = new Badge();
badge.print(null, "Charlotte Hale", null);
// => "Charlotte Hale - OWNER"
```
