# 説明

この演習では、バレンタインデーにパートナーと一緒に何か楽しいことをする予定です。パートナーはたくさんのアイデアを持っていて、どの活動をするかを決めるために、それぞれのアイデアを評価してほしいと言っています。

パートナーが提案しているアイデアは次のとおりです。

- ボードゲームで遊ぶ
- のんびり過ごす
- 映画を観る
- レストランに行く
- 散歩する

バレンタインデーの過ごし方を選ぶためのタスクが6つあります。

## 1. approvalを定義する

パートナーが提案するアイデアそれぞれに対して、3つの選択肢のいずれかで答えます。yes、no、maybeです。

`Approval`という判別共用体を定義して、これらの選択肢を次の3つのケースで表しましょう。`Yes`、`No`、`Maybe`です。

## 2. 料理を定義する

パートナーは候補のレストランを2つ選びました。1つは韓国料理、もう1つはトルコ料理です。

`Cuisine`という判別共用体を定義して、これらの料理を次の2つのケースで表しましょう。`Korean`と`Turkish`です。

## 3. 映画のジャンルを定義する

選べる映画は山ほどあるので、候補を絞るために、パートナーはジャンルも挙げてくれています。

`Genre`という判別共用体を定義して、次のジャンルをケースとして表しましょう。`Crime`、`Horror`、`Romance`、`Thriller`です。

## 4. アクティビティを定義する

すでに触れたとおり、パートナーは5つのアクティビティを考えました。ボードゲームで遊ぶ、のんびり過ごす、映画を観る、レストランに行く、散歩するです。

`Activity`という判別共用体を定義して、これらのアクティビティの種類を表しましょう。

- `BoardGame`: 関連するデータはありません。
- `Chill`: 関連するデータはありません。
- `Movie`: `Genre`を関連するデータとして持ちます。
- `Restaurant`: `Cuisine`を関連するデータとして持ちます。
- `Walk`: 歩く距離をキロメートルで表す`int`を関連するデータとして持ちます。

## 5. アクティビティを評価する

いよいよ、パートナーのアイデアを評価する準備ができました。パートナーのアイデアに対する気持ちは次のとおりです。

- ボードゲームで遊ぶ: no。
- のんびり過ごす: no。
- 映画を観る: ロマンス映画なら yes、そうでなければ no。
- レストランに行く: 韓国料理なら yes、トルコ料理なら maybe。
- 散歩する: 3キロメートル未満なら yes、5キロメートル未満なら maybe、それ以外は no。

`Activity`の値を受け取って、上記の気持ちに基づいて`Approval`を返す、`rateActivity`という名前の関数を実装しましょう。

```fsharp
rateActivity (Restaurant Turkish)
// => Maybe
```
