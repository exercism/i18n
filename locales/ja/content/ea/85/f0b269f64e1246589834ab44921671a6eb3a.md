# はじめに

関数宣言や関数式のほかに、JavaScriptには関数を定義するためのとても簡潔な構文がもう1つあります。
この関数は_アロー関数_と呼ばれます。

このコンセプトでは、アロー関数を書くための構文に焦点を当てます。
_this_の束縛など、アロー関数の動作には違いがあり、それらはほかのコンセプトで扱います。

関数宣言とアロー関数を比較してみましょう。

```javascript
function addUpTwoNumbers(num1, num2) {
  return num1 + num2;
}

// function keyword removed and => added
const addUpTwoNumbers = (num1, num2) => {
  return num1 + num2;
};
```

上のコードからわかるように、アロー関数の構文では次のようになっています。

1. キーワード`function`がなくなります
2. 識別子`addUpTwoNumbers`が`const`で宣言されます
3. 太い矢印`=>`が追加されます

上の例のように、関数の本体が`return`文だけなら、`{}`と`return`キーワードは省略できます。

<!-- prettier-ignore-start -->
```javascript
const addUpTwoNumbers = (num1, num2) => { return num1 + num2 };

// can be shortened to
const addUpTwoNumbers = (num1, num2) => num1 + num2;
// braces {} and return removed
```
<!-- prettier-ignore-end -->

アロー関数からオブジェクトだけを返すという特別な場合は、`return`文を省略するために、オブジェクトのまわりに括弧（`()`）が必要です。

```javascript
// explicit return of object
const addUpTwoNumbers = (num1, num2) => {
  return {
    num1,
    num2,
  };
};

// implicit return of object
const addUpTwoNumbers = (num1, num2) => ({ num1, num2 });
```

仮引数を囲む括弧が必要かどうかは、仮引数の数によって変わります。

<!-- prettier-ignore-start -->
```javascript
// one parameter does not need parenthesis
const square = num => num * num;

// two or more parameters need to be wrapped in parenthesis
const addUpTwoNumbers = (num1, num2) => num1 + num2;
```
<!-- prettier-ignore-end -->
