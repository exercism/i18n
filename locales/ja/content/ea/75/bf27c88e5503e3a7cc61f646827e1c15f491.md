# ファッションブティック

## ストーリー

オンラインのファッションブティックを経営しています。ブラックフライデーが近づいてきたので、準備万端にしておくために在庫を確認しておく必要があります。

在庫の商品1つはマップ／辞書で表され、在庫全体はそうしたマップ／辞書の配列です。

```elixir
%{
  name: "White Shirt",
  price: 40,
  quantity_by_size: %{s: 3, m: 7, l: 8, xl: 4}
}
```

## タスク

- 商品を価格で並べ替える
- 価格が設定されていない商品をすべて見つける
- 商品の数量を増やす
- 商品の合計数量を計算する
