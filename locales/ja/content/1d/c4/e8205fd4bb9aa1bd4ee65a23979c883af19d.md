# 概要

Javaの文字列について覚えておきたい最も大切な点は、文字列がUnicode文字（文字、数字、記号など）の並びとしてテキストを表す、不変のオブジェクトだということです。
`String`のインスタンスを定義するには、二重引用符を使います。

```java
String fruit = "Apple";
```

文字列の操作は、[`String`][string-class]クラスのメソッドを使って行えます。
文字列の値は一度定義されると変わることはないため、文字列を操作するメソッドはすべて新しい文字列を返します。

文字列は二重引用符（`"`）で囲んで表します。
特殊な文字の中には、バックスラッシュ（`\`）を使ってエスケープする必要があるものがあります。
Javaでエスケープが必要な文字は次のとおりです。

- `"`
- `\`

```java
String escaped = "c:\\test.txt";
// => c:\test.txt
```

最後に、文字列を連結する方法はたくさんあります。
最も簡単なのは`+`演算子です。

```java
String name = "Jane";
"Hello " + name + "!";
// => "Hello Jane!"
```

単純な連結よりも複雑な文字列の整形には、`String.format`メソッドを使うのがおすすめです。

```java
String name = "Jane";
String.format("Hello %s!",name);
// => "Hello Jane!"
```

そのほかの方法には次のようなものがあります。

- [`StringBuilder`クラス][string-builder]を使う
- [`String.concat`メソッド][string-concat]を使う
