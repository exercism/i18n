# 指示の補足

## 出力形式

歌詞を、null終端された文字列として出力します。

## レジスタ

| レジスタ | 用途         | 型      | 説明                          |
| -------- | ------------ | ------- | ----------------------------- |
| `$a0`    | 入力         | 整数    | 開始するボトルの数            |
| `$a1`    | 入力         | 整数    | 取り下ろすボトルの数          |
| `$a2`    | 入出力       | アドレス | null終端された出力文字列      |
| `$t0-9`  | 一時的       | 任意    | 一時的な保存用                |
