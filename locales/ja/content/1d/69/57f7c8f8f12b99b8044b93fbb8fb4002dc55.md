# 詳細

パターンマッチングとは、値が与えられたパターン（ときに深い入れ子のパターン）にマッチするかどうかによって、処理を分岐させる仕組みです。Haxeでは、**パターンマッチング**は`switch`式と個々の`case`式を使って行います。

次のデータ構造を見てみましょう。

```haxe
enum Tree<T> {
  Leaf(v:T);
  Node(l:Tree<T>, r:Tree<T>);
}
```

- パターンは常に上から下へと順にマッチングされます。
- 入力値にマッチしたうちの最も上のパターンの式が実行されます。
- `_`パターンは何にでもマッチするので、`case _:`は`default:`と同じです。

## 列挙型のマッチング

列挙型は、そのコンストラクターによって自然にマッチングできます。

```haxe
var myTree = Node(Leaf("foo"), Node(Leaf("bar"), Leaf("foobar")));

var match = switch (myTree) {
  // Matches any Leaf
  case Leaf(_):
    "0";

  // Matches any Node that has r = Leaf
  case Node(_, Leaf(_)):
    "1";

  // Matches any Node that has
  // r = another Node which has
  // l = Leaf("bar")
  case Node(_, Node(Leaf("bar", _))):
    "2";

  // Matches anything
  case _:
    "3";
}

trace(match); // 2
```
