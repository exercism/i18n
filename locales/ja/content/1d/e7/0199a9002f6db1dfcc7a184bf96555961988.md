# 概要

## 条件文

条件文は、副作用を実行したり、プログラムの実行の流れを制御したりできる、判断のための文です。
条件文には、`if`文、`if/else`文、`switch`文、`ternary`文があります。

条件文は、ある値や、値同士の関係について問いを立てるために使います。
その問いは真偽値の答えに評価されますが、`if`文自体はどんな値でも返せますし、単に副作用を実行するだけでもかまいません。

## `if`文

最も単純な`if`文は、式を評価して1行を実行します。
テストする式は、必ず括弧（`()`）の中に書きます。

副作用を実行することもできます。

```c
if (count > 10)
    printf("count is greater than 10");
```

実行の流れを変えることもできます。


```c
if (count > 10)
    return sum;
```

`if`文で複数の行を実行する場合は、それらの行を波括弧で囲む必要があります。

```c
if (count > 10) {
    printf("count is greater than 10");
    return sum;
}
```

チームによっては、1行の場合でも`if`文には常に波括弧を使う、と規約で定めていることもあります。


## `if`と`else`

`if`文は、`else`と組み合わせることができます。

```c
if (number % 2 == 0)
    return "even";
else
    return "odd";
```

## `if`と`else if`


`else`は別の`if`と組み合わせることで、いわゆる`if-else-if ladder`と呼ばれるものを作ることができます。

```c
if (number == 0)
    return "zero";
else if (number < 0)
    return "negative";
else if (number < 10)
    return "single digit";   
else if (number % 2 == 0)
    return "even";
else
    return "odd";
```

## `switch`


`if-else-if ladder`は、`switch`でよりうまく表せることもあります。
`if`と同じく、テストする式は必ず括弧の中に書きます。

```c
switch (number) {
    case -1:
        return "negative one";
    case 0:
        return "zero";
    case 1:
        return "positive one";
    case 10:
        return "positive ten";
    case -10:
        return "negative ten";
    default:
        return "don't care";
}
```

`default`ケースは、テストしている値がそれまでのどのケースにも一致しないときに実行されます。

`switch`のケースが値を返さない場合は、ふつう、各ケースを終わらせるために`break`を入れます。そうしないと、ロジックが次のケースへ「フォールスルー」します。
フォールスルーを意図的に使うこともあります。

```c
switch (number) {
    case 0:
        msg = "zero"; break;
    case 1:
        msg = "one"; break;
    case 2: case 3: case 4:
        msg = "more than one and less than five"; break;
    default:
        msg = "don't care";
}
```

フォールスルーが意図せず起きてしまうと、それはバグです。

```c
switch (number) {
    case 0:
        msg = "zero"; // bug! fallthrough of 0 will set msg to "one"
    case 1:
        msg = "one"; break; 
    case 2: case 3: case 4:
        msg = "more than one and less than five"; break;
    default:
        msg = "don't care";
}
```

`switch`は、値の範囲ではなく特定の値に対してテストするときに役立ちます。
コンパイラーが、`if-else-if ladder`ではできない形で`switch`文を最適化できることがあるため、より速くなることがあります。
また、`switch`は`if-else-if ladder`より読みやすく見えることもあります。

## 三項演算子（別名 条件演算子）

三項演算子は、3つの部分からなる条件文で、値を設定するのによく使われます。
テストする式は疑問符の前に置き、括弧で囲む必要はありません。
`true`のときに返される値はコロンの前に、`false`のときに返される値はコロンの後に書きます。
返せるのは、値のリテラルでも変数でもかまいません。

```c
int i = j > 5 ? 5: j;
```

三項演算子は入れ子にすることで、構文上の煩雑さを減らせます。

```c
// the below could also be 
i = j > 5 ? j :k > 5 ? k: 10;
// but that may not be quite as readable

i = j > 5 ? j
    :k > 5 ? k
    :10;

// which is the same as
if (j > 5) i = j;
else if (k > 5) i = k;
else i = 10;
```

## 浮動小数点値の条件比較

浮動小数点数がどのように実装されているかによって、単純な算術演算でも丸め誤差が生じることがあり、等価性のテストが期待どおりの結果を返さない原因になります。

```c
    a = 1.345f;
    b = 1.123f;
    c = a + b;
    // c may equal something like 2.4679999352
    if (c == 2.468)
        return "I won the lottery!";
```

`epsilon`と呼ばれる許容値を使うと、別の値と比較したときに、ある値がどの範囲に収まっていれば等しいとみなせるかを決めることができます。
プラットフォームによっては、`float`や`double`の`epsilon`の定数が組み込みで用意されています。
詳しくは、お使いのコンパイラーのドキュメントを参照してください。
`epsilon`の計算は複雑になることがあり、プラットフォームごとに、さらには個々のマシンごとに異なることもあります。
以下は、単純な比較を使ったプログラムの例です。

```c
#include <stdio.h>
#include <math.h>
#include <stdbool.h>

const double MY_EPSILON = .002;

bool same(double x, double y)
{
    return fabs(x - y) < MY_EPSILON;
}

int main()
{
    // Same should return true if the difference is less than MY_EPSILON
    printf("%s\n", same(1.1, 1.099) ? "true" : "false"); // prints true
    printf("%s\n", same(1.1, 1.098) ? "true" : "false"); // prints false
    return 0;
}
```

`float`や`double`を等価性で比較するときは、注意してください！
