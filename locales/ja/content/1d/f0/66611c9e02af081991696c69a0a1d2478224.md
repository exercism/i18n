# 説明の追記

## 出力

この演習では、指定した行数までのパスカルの三角形を生成する動詞を実装します。動詞の出力は、次の2通りの形式で表せます。

  1. ボックス化された配列の配列。各配列がパスカルの三角形の1行を表します。
  1. 表。数値は右揃えで、左側の空いた部分は0で埋めます。

### 出力例

`pascal 3`に対して有効な出力は、次の2つです。

  - ボックス化された配列の配列として：
```j
  (1 ; 1 1 ; 1 2 1) -: pascal 3          NB. This test will pass
```
  - 余白を埋めた表として：
```j
  (3 3$1 0 0 1 1 0 1 2 1) -: pascal 3   NB. This test also passes
```
