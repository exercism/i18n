# Emacsのインストール

Emacs Lisp（elisp）はEmacsの拡張言語なので、まず[GNU Emacs](http://www.gnu.org/software/emacs/)をインストールする必要があります。

最新のEmacsを入手することをおすすめしますが、演習の対象となる実装は28.1以上と考えてください。
すでにEmacsがインストールされている場合は、`M-x emacs-version RET`でEmacsのバージョンを確認できます。

## OS Xの場合
最も簡単な方法は、[Emacs For Mac OS X](http://emacsformacosx.com/)にアクセスしてdmgをダウンロードすることです。これでGNU EmacsがOS Xアプリとしてインストールされます。

Aquamacs（おすすめしません）を使う方法や、好みに応じて[Homebrew](https://formulae.brew.sh/formula/emacs)でインストールする方法など、別の選択肢もあります。

## Linuxの場合
EmacsはGNUの一部であるため、ディストリビューションによってはすでにインストールされています。

### Ubuntu
現在、最新のEmacsをインストールするために推奨されている方法は、[snap](https://snapcraft.io/emacs)を使うことです：

```
sudo snap install emacs --classic
```

snapを使いたくない場合は、snapでEmacsをインストールすることもできますが、Ubuntuのリポジトリで入手できるバージョンは古いことがよくあります。
aptでより新しいバージョンのEmacsをインストールしたい場合は、[PPA](https://launchpad.net/ubuntu/+ppas?name_filter=emacs)を使うか、[ソースからビルドする](https://www.emacswiki.org/emacs/BuildingEmacs)必要があります。

最新バージョンのインストールにこだわらないのであれば、次のようにするだけです：

```
sudo apt-get install emacs
```

### Arch
Archには通常、最新バージョンのEmacsが同梱されているので、次のコマンドを実行します：

```
sudo pacman -S emacs
```

これで準備は完了です。

### その他のディストリビューション
お使いのディストリビューションでどのバージョンが最新かを確認し、状況に応じてパッケージマネージャーを使うか、ソースからビルドしてください。

### Windows
WindowsにEmacsをインストールするには、最寄りの[FTPアーカイブミラー](https://ftpmirror.gnu.org/emacs/windows)にアクセスし、インストーラー（=emacs-XX.X-installer.exe=）を入手して起動します。
Emacsをインストールせずに使いたい場合は、=emacs-XX.x.zip=というパターンのファイルを入手して解凍し、`bin\runemacs.exe`を起動します。

[MSYS2](https://www.msys2.org/)を使っている場合は、次のコマンドでEmacsの64ビットビルドをインストールできます：

```
pacman -S mingw-w64-x86_64-emacs
```

32ビットビルドなら次のとおりです：

```
pacman -S mingw-w64-i686-emacs
```
