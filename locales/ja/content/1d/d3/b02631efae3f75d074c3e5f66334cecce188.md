# はじめに

ファントム型とは、あるカスタム型の型パラメーターのうち、その型の値コンストラクターのどれにも使われていないものを指します。

少し抽象的ですね。そこで、例を見てみましょう。

```gleam
pub type Length(unit) {
  Length(amount: Float)
}
```

この例では、`unit`型パラメーターは`Length`の値コンストラクターで使われていないので、`unit`はファントム型です。

この使われていない型パラメーターは無意味に見えるかもしれませんが、`Length`の値をどう使えるかにさらに制約を加えるために使えます。

たとえば、長さを2倍にする`double`という関数を考えてみましょう。これはどんな単位の長さでも扱えるので、型パラメーターはジェネリックな型変数になります。

```gleam
// This function accepts all Length values
pub fn double(length: Length(unit)) -> Length(unit) {
  Length(length.amount *. 2.0)
}
```

また、長さがインチのときだけ動く`add_inch`という関数も考えられます。

```gleam
// A unit type for inches. It is never constructed so we don't
// define any constructors for it.
pub type Inches

pub fn add_inch(length: Length(Inches)) -> Length(Inches) {
  Length(length.amount +. 1.0)
}
```

`add_inch`関数は、それ以外の単位のパラメーターを持つ長さを受け付けません。ファントム型のおかげで、正しい単位だけが使われるようになっているのです。

同じ型変数を両方に使えば、2つの長さの値が同じ単位であることを保証する関数も書けます。

```gleam
pub fn add(a: Length(unit), b: Length(unit)) -> Length(unit) {
  Length(a.amount +. b.amount)
}
```
```gleam
let two_meters: Length(Meters) = Length(2.0)
let two_inches: Length(Inches) = Length(2.0)

add(two_meters, two_meters)
// -> Length(4.0): Length(Meters)

add(two_meters, two_inches)
// Type error! The unit type parameters do not match.
```

ファントム型はopaque型と相性がよく、組み合わせて使えます。他のモジュールが`Length`の値を作れないようにすれば、無効な単位の型で値が作られることはなく、上で定義した関数だけがそれらに使えることを保証できます。
