# 指示

友人が庭のあちこちで取った測定値からレポートを作成するのを手伝っています。
残念ながら、友人はそのデータを奇妙な形式で保存していました。
それぞれの測定値は、カンマで区切られた複数のフィールドの集まりです。
ただし、2桁の数値は2つの列に分けて保存されています。

| フィールド番号 | 意味 |
| --- | --- |
| 1 | ID番号 |
| 2 | 場所 |
| 3 | 1つ目の測定値の十の位 |
| 4 | 1つ目の測定値の一の位 |
| 5 | 2つ目の測定値の十の位 |
| 6 | 2つ目の測定値の一の位 |

`101,house,4,2,5,4`のような入力行なら、
- 1つ目の測定値は`42`、
- 2つ目の測定値は`54`です。

## タスク1：レポートを作成する

2つの測定値の平均を求め、各行の結果を次の形式で出力します。

```none
#<id>, <label> = <average>
```

`42`と`54`の平均は`48`なので、この例の行の出力は次のようになります。

```none
#101, house = 48
```
