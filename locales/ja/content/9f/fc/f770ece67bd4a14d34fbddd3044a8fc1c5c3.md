# `Char`について

これは、かなり_大きな_テーマです！
これだけで長い本が1冊書けてしまうほどで、実際に何人もの人が書いています（Amazonで"unicode book"と検索すると、いくつか例が見つかります）。

## ごく簡単な歴史

何十年も前は、コンピューターで文字を扱うのはもっとずっと単純でした。当時のプログラマーは、英語だけが重要な言語だと考えていたのです。
つまり、大文字と小文字あわせて26文字、10個の数字、いくつかの句読点や記号、それにベルを鳴らすためのコード（0x07）で、これらすべてが7ビットに収まりました。それが[ASCII][wiki-ascii]文字セットです。

当然のことながら、àやä、Łはどうするのかという声が上がりはじめ、次にはऄやஹ、ญはどうなんだという声も上がり、若い人たちは絵文字😱を求めるようになりました。
どうすればいいのでしょうか？

手短に言うと、多くの聡明で忍耐強い人たちが何年も委員会に参加して、[Unicode][web-unicode]文字セットや[UTF-8][wiki-utf-8]などのエンコーディングの詳細を詰めていきました。そして、たくさんのソフトウェアに_とても_複雑な書き直しが必要になりました。
さらに、たくさんの新しいバグも生まれました。

_すべて_が壊れるのを防ぐため、Unicode/UTF-8の設計では、最初の127個のコードがASCIIとまったく同じになるようにしています（_ベルのコードまで_）。

## Kotlinにおける文字

2005年ごろ以降に設計された言語には、すでにほどよく安定したUnicode標準が存在していたという大きな利点があります。

Kotlin（2011年に最初にリリースされました）は、ユーザーがさまざまな（人間の）言語を使い、それらを表現するためにUnicodeが必要になるだろうと想定できました。

~~~~exercism/advanced
Kotlinの[文字][ref-char]は、JVMの`char`と同様、16ビット（UTF-16）の[`codepoints`][wiki-codepoint]です。
これでほとんどの文字体系を表せますが、絵文字の全範囲には足りません。

Unicode標準の全体では、1文字あたり最大6バイト（48ビット）を使います（これは[`grapheme`][wiki-grapheme]と呼ばれます）。

Kotlinの`Strings`は、必要に応じて1文字に複数のコードポイントを使うことで、この標準全体をサポートします。
たとえば、😱は`\uD83D`と`\uDE31`になります。

残念ながら、Javaには書記素のサポートが組み込まれておらず、互換性のためKotlinにもありません。

[wiki-grapheme]: https://en.wikipedia.org/wiki/Grapheme
[ref-char]: https://kotlinlang.org/docs/characters.html
~~~~


文字リテラルはシングルクォートで書き、ダブルクォートで書く文字列とは別物です。
これはC/C++の世界から来た人には当然かもしれませんが、PythonやJavaScriptのプログラマーには戸惑うところかもしれません。

```kotlin
val a = 'a'
a::class.qualifiedName  // => kotlin.Char
a.code  // => 97

val jha = 'झ'  // Devanagari alphabet
jha.code  // => 2333

val heart = '❤'  // heart emoji
heart.code  // => 10084

Char.MAX_VALUE.code // => 65535 (64k, the largest code point allowed)

val not_char = 'abc' // => Too many characters in a character literal.
```

`Char`と`Int`の間は、次のようにして簡単に変換できます。

```kotlin
a.code  // => 97
Char(97) // => 'a'
```

コンパイラーは、`Char`に対する_一部の_整数演算を許可しています。

```kotlin
'a' + 5     // => 'f'
'c' - 'a'   // => 2
'c' + 'a'   // => error!

'f' + ('A' - 'a')  // => 'F' (same as 'f'.uppercase()

'f'.dec() // => 'e' (decrement)
'f'.inc() // => 'g' (increment)
```

## `Char`で使える関数

いつものことですが、[関数][ref-char-lib]は多すぎてここでは紹介しきれないので、ほんの一部だけを取り上げます。

- 対応する文字体系では、[`uppercase()`][ref-uppercase]と[`lowercase()`][ref-lowercase]で大文字・小文字を切り替えられます。
- 大文字か小文字かは、[`isUpperCase()`][ref-isuppercase]と[`isLowerCase()`][ref-islowercase]で判定できます。
- 文字の種類を調べるには、次の関数を使います。
  - [`isLetter()`][ref-isletter]：多くの文字体系をカバーします（UnicodeのLu、Ll、Lt、Lm、Loの各カテゴリー）
  - [`isDigit()`][ref-isdigit]：0..9の範囲です（UnicodeのNdカテゴリー）
  - `isLetterOrDigit()`：前の2つを組み合わせたものです
  - [`isWhitespace()`][ref-iswhitespace]：任意の空白文字です（UnicodeのCc、Zp、Zl、Zsの各カテゴリー）

```kotlin
'झ'.isLetter()      // => true
'A'.isLowerCase()   // => false
'4'.isDigit()       // => true
'\t'.isWhitespace() // => true  (tab character)
```

また、[正規表現][ref-regex]（後のコンセプトで扱います）を使うと、強力な検索や操作ができます。

## `Char`のリストと`String`の相互変換

`String`から`Char`の`List`に変換するには、`toList()`を使います。

`Char`の`List`を`String`に変換するには、[`joinToString()`][ref-jointostring]関数を使います。これは区切り文字（多くの場合、空文字列）を入力に取ります。

```kotlin
val kt = "kotlin".toList()  // => [k, o, t, l, i, n]
kt.joinToString("")   // => "kotlin"
kt.joinToString("_")  // => "k_o_t_l_i_n"
```

`joinToString()`は`List`または`Array`に対して動作することに注意してください。
1つの`Char`を1文字の文字列に_キャスト_するには、`toString()`を使います。

```kotlin
'a'.toString() // => "a"
```

ある文字が`String`や`Char`のリスト・配列の中にあるかどうかを調べるには、`in`を使います。これは[`contains()`][ref-contains]関数に対応します。

```kotlin
val clist = "kotlin".toList()  // => [k, o, t, l, i, n]
't' in clist     // => true
't' in "kotlin"  // => true
```
