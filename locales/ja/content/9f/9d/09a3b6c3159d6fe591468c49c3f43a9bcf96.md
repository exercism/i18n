# 構造体

構造体は、独自のデータ型で、関連する複数の値をまとめて名前を付けられます。タプルに似ていますが、より柔軟で、それぞれのデータに名前を付けられるため、コードが読みやすくなります。Cairoの構造体には、次のような特徴があります。

- 構造体の型にはそれぞれ固有の名前があります。
- 構造体の各メンバーは**フィールド**と呼ばれます。
- 構造体の各フィールドには固有の名前があります。
- 可視性はフィールドごとに管理されます。各フィールドは、独立して公開または非公開にできます。

## 構造体の定義とインスタンス化

構造体を定義するには、`struct`キーワードのあとに名前を書き、波括弧（`{}`）の中にフィールドの名前と型を書きます。

```rust
#[derive(Drop)]
struct User {
    active: bool,
    username: ByteArray,
    email: ByteArray,
    sign_in_count: u64,
}
```

`struct`のインスタンスを作るには、`struct`の名前を指定し、波括弧の中にフィールドのキーと値のペアを書きます。インスタンスを作るときは、フィールドをどの順番で並べてもかまいません。

```rust
let user1 = User {
   active: true, username: "someusername123", email: "someone@example.com", sign_in_count: 1
};

let user2 = User {
    sign_in_count: 1, username: "someusername123", active: true, email: "someone@example.com"
};
```

## 構造体のインスタンスを扱う

ドット記法を使うと、`struct`のインスタンスのフィールドにアクセスしたり変更したりできます。フィールドを変更するには、インスタンスが可変である必要があります。

```rust
let mut user1 = User {
    active: true, username: "someusername123", email: "someone@example.com", sign_in_count: 1
};
user1.email = "anotheremail@example.com";
```

他の式と同じように、関数本体の最後の式として`struct`の新しいインスタンスを作れば、その新しいインスタンスを暗黙的に戻り値として返せます。

```rust
fn build_user(email: ByteArray, username: ByteArray) -> User {
    User {
        email: email,
        username: username,
        active: true,
        sign_in_count: 1,
    }
}
```

## フィールド初期化の省略記法

前の例では、`email`と`username`という関数の仮引数に、`struct`のフィールドと同じ名前を付けるのが自然でした。ただ、それを構造体のフィールドに代入するときに同じ名前をもう一度書くのは、少し面倒です。そこで便利なのが、同じ名前の変数から構造体のフィールドを初期化する省略記法です。

```rust
fn build_user_short(email: ByteArray, username: ByteArray) -> User {
    User { email, username, active: true, sign_in_count: 1, }
}
```

## 構造体更新構文で他のインスタンスからインスタンスを作る

構造体更新構文を使うと、既存のインスタンスから新しいインスタンスを作り、一部のフィールドだけを変更して残りはそのままにできます。これは`..`演算子を使って行います。

更新構文を使わない場合：

```rust
let user2 = User {
    active: user1.active,
    username: user1.username,
    email: "another@example.com",
    sign_in_count: user1.sign_in_count,
};
```

更新構文を使う場合：

```rust
let user2 = User { email: "another@example.com", ..user1 };
```

`..user1`という構文は、残りのフィールドを`user1`から`user2`にコピーします。この操作は`user1`のデータを`user2`にムーブするため、`user1`がコピーできない型を含んでいる場合、そのあと`user1`は使えません。
