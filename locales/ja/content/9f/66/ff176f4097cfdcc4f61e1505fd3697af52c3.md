# 説明

この演習では、ログ行を処理します。

各ログ行は、次のようにフォーマットされた文字列です：`"[<LEVEL>]: <MESSAGE>"`。

ログレベルは次の3つです：

- `INFO`
- `WARNING`
- `ERROR`

3つのタスクがあります。それぞれのタスクでは、ログ行を受け取り、それを使って何かを行うよう求められます。

## 1. ログ行からメッセージを取得する

ログ行のメッセージを返す（_static_な）`LogLevels.message()`メソッドを実装してください：

```java
LogLevels.message("[ERROR]: Invalid operation")
// => "Invalid operation"
```

先頭や末尾の空白は取り除いてください：

```java
LogLevels.message("[WARNING]:  Disk almost full\r\n")
// => "Disk almost full"
```

## 2. ログ行からログレベルを取得する

ログ行のログレベルを返す（_static_な）`LogLevels.logLevel()`メソッドを実装してください。ログレベルは小文字で返してください：

```java
LogLevels.logLevel("[ERROR]: Invalid operation")
// => "error"
```

## 3. ログ行を整形する

ログ行を整形する（_static_な）`LogLevels.reformat()`メソッドを実装してください。メッセージを先頭に置き、ログレベルをそのあとに括弧（`()`）で囲んで配置します：

```java
LogLevels.reformat("[INFO]: Operation completed")
// => "Operation completed (info)"
```
