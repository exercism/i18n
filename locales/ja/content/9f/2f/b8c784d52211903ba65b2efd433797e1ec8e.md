# はじめに

FactorのI/Oは*ストリーム*を土台にしています。ストリームとは、バイトや文字を読み込んだり書き込んだりする対象となるオブジェクトです。[`io`][io]ボキャブラリーは、同じ[プロトコル][stream-protocol]を2つの視点から扱えるようにしてくれます。

## 2つの視点

**明示的ストリーム**のワードは、ストリームを引数として受け取ります。いずれも`stream-`で始まります：

```
stream-read       ( n stream -- seq/f )
stream-readln     ( stream -- str/f )
stream-write      ( seq stream -- )
stream-flush      ( stream -- )
stream-contents   ( stream -- seq )
stream-lines      ( stream -- seq )
```

**暗黙的ストリーム**のワードは、*現在束縛されている*ストリーム、つまりプログラム全体で共有される動的変数`input-stream`または`output-stream`から読み書きします。名前は短くなっています：

```
read1 read readln write write1 print flush
```

日常的なコードのほとんどは、暗黙の形式を使います。明示的な形式は、特定のストリームを手元に持っていて、暗黙のストリームと入れ替えたくないときに使います。

## メモリ上のストリーム

この演習では、[`io.streams.string`][io.streams.string]の文字列ベースのストリームを扱います：

```
<string-reader>   ( str -- reader )
<string-writer>   ( -- writer )
```

`<string-reader>`は、文字列リテラルをファイルのように読み込みます。`<string-writer>`は、書き込まれたものをすべて集めておくので、あとから読み返すことができます。どちらもファイルストリームと同じプロトコルを実装しているので、ここで学んだことはそのまま`<file-reader>`/`<file-writer>`にも当てはまります。

## `with-…`によるスコープの設定

クオーテーションの実行中だけ明示的なストリームを暗黙のストリームとして束縛し、そのあとで破棄するには、`with-…`コンビネーターを使います：

```
with-input-stream    ( stream quot -- )
with-output-stream   ( stream quot -- )
with-string-writer   ( quot -- str )
with-file-reader     ( path encoding quot -- )
with-file-writer     ( path encoding quot -- )
```

[`with-string-writer`][with-string-writer]は、「このクオーテーションが出力するものを集める」ための便利な形です。ライターを組み立て、そのライターを暗黙の出力先としてクオーテーションを実行し、取り込んだ文字列を返します：

```factor
USING: io io.streams.string ;

[ "captured" print ] with-string-writer .
! => "captured\n"
```

`with-…`コンビネーターはすべてデストラクターコンビネーターです（[`boatswains-bilge`][boatswains-bilge]の`with-disposal`や`with-destructors`と同じ仲間です）。クオーテーションが例外を投げても、抜けるときにストリームは破棄されます。
