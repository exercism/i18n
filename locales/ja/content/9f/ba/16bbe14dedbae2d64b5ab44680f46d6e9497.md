# 概要

Factorのシーケンスライブラリは、繰り返しをパラメーター化するために、`[ ]`の括弧で囲んだコードである*クオーテーション*に大きく頼っています。その形はいつも同じです。シーケンスとクオーテーションを渡すと、高階ワードが各要素に対してクオーテーションを実行します。

```factor
{ 1 2 3 4 5 } [ even? ] filter .   ! => { 2 4 }
{ 1 2 3 4 5 } [ even? ] reject .   ! => { 1 3 5 }
{ 1 2 3 4 5 } [ 3 > ] find .s      ! => 3 / 4 (index, element)
{ 1 2 3 4 5 } [ sq ] map .         ! => { 1 4 9 16 25 }
{ 1 2 3 4 5 } [ . ] each           ! prints each element
0 { 1 2 3 4 5 } [ + ] reduce .     ! => 15
```

よく使うワードを一覧にすると、次のとおりです。

| word         | shape                                      |
|--------------|--------------------------------------------|
| `each`       | `( seq quot -- )`                          |
| `map`        | `( seq quot -- newseq )`                   |
| `filter`     | `( seq quot -- newseq )`                   |
| `reject`     | `( seq quot -- newseq )`                   |
| `find`       | `( seq quot -- i/f elt/f )`                |
| `find-last`  | `( seq quot -- i/f elt/f )`                |
| `reduce`     | `( seq init quot -- result )`              |
| `map-sum`    | `( seq quot -- n )`                        |
| `count`      | `( seq quot -- n )`                        |
| `any?`       | `( seq quot -- ? )`                        |
| `all?`       | `( seq quot -- ? )`                        |
| `with`       | `( value seq quot -- seq curry )`          |
| `without`    | `( seq exclude -- newseq )`                |
| `sort`       | `( seq -- sortedseq )`                     |
| `sum`        | `( seq -- n )`                             |
| `minimum`    | `( seq -- elt )`                           |
| `maximum`    | `( seq -- elt )`                           |
| `minimum-by` | `( seq quot -- elt )`                      |
| `maximum-by` | `( seq quot -- elt )`                      |

*自分*のワードが実行時のクオーテーションをこれらのコンビネーターに渡すときは、`; inline`を付けてワードを定義しましょう。そうすると、コンビネーターの効果推論が呼び出し地点でクオーテーションの形を認識できるようになります。リテラルのクオーテーションだけから作られたワードには必要ありません。

主要なシーケンス操作のほかにも、次のようなボキャブラリがあります。

| vocab              | provides                                      |
|--------------------|-----------------------------------------------|
| [`sorting`][sorting]          | `sort`, `sort-by`                             |
| [`math.statistics`][math.statistics]  | `cum-sum`, `cum-product`, `cum-min`, `cum-max` |
| [`grouping`][grouping]         | `group`, `clump`, `monotonic-split`           |
| [`sets`][sets]             | `members`, `all-unique?`                      |

ペアのコンビネーター（`bi`、`tri`）や「n項」のコンビネーター（`2map`、`2each`、`zip`）も、クオーテーションが複数の入力を必要とするときには、同じパターンを拡張したものです。
