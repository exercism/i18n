# 概要

`Lambda`クラスは、Haxeで関数型スタイルのプログラミングを行うための、関数型メソッドを集めたものです。`Iterable`全体をまとめて操作できます。これはループを書くよりも間違いが起きにくく、読みやすいため、よく好まれます。便利なことに、`Array`クラスと`List`クラスには、`Lambda`クラスでよく使われるメソッドの一部が用意されています。

`Lambda`クラスにある関数の一部を紹介します。

- `Lambda.array`、`Lambda.list`：`Iterable`を`Array`または`List`に変換します。常に新しいインスタンスを返します。
- `Lambda.count`：要素の数を数えます。`Iterable`が`Array`または`List`なら、`length`プロパティを使うほうが速いです。
- `Lambda.has`：指定した要素が`Iterable`に含まれているかを判定します。
- `Lambda.indexOf`：指定した要素のインデックスを調べます。
- `Lambda.find`：与えられた検索関数に最初に一致する要素を探します。
- `Lambda.concat`：2つの`Iterable`をマージし、新しい`List`を返します。
- `Lambda.filter`：条件を満たす要素を探し、新しい`List`を返します。

いくつかの関数を示す例です。

```haxe
using Lambda;

class Main {
  static function main() {
    var words = ["boat", "dog", "phone", "cat", "food"];

    var isThreeLetters = function(word) return word.length == 3;

    trace(words.filter(isThreeLetters)); // [dog,cat]
  }
}
```
