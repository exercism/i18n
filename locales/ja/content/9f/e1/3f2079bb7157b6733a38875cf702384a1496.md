# 説明

近くに「Tech Palace」という家電店があります。
店のオーナーは最近、マーケティングのメッセージを表示したり、お客さんが入口で会員カードをスキャンしたときに特別な挨拶を表示したりするための大きなディスプレイを設置しました。
このディスプレイはたくさんの小さなLEDライトでできていて、複数行のテキストを表示できます。

店のオーナーは、新しいディスプレイに表示するテキストを生成するコードについて、皆さんの助けを必要としています。

## 1. ウェルカムメッセージを作成する

会員カードをスキャンするほとんどのお客さんには、`"Welcome to the Tech Palace,"`に続けてお客さんの名前を大文字で表示したいと、店のオーナーは考えています。

お客さんの名前を`string`型の引数として受け取り、目的のメッセージを`string`型として返す関数`WelcomeMessage`を実装してください。

```go
WelcomeMessage("Judy")
// => Welcome to the Tech Palace, JUDY
```

## 2. 飾りの枠を追加する

店でたくさん買ってくれる常連のお客さん向けに、オーナーは、ウェルカムメッセージの前後に星の行を追加して、表示をもっと華やかにしたいと考えています。
星の行にいくつの星を入れるかはまだ決まっていないので、設定で変えられるようにしたいそうです。

ウェルカムメッセージ（`string`）と、1行あたりの星の数（`int`型）を引数として受け取る関数`AddBorder`を書いてください。
この関数は3行からなる`string`を返します。指定された数の星の行、渡されたとおりのウェルカムメッセージ、そしてもう1行の星の行です。

```go
AddBorder("Welcome!", 10)
```

これは次のような値を返します。

```text
**********
Welcome!
**********
```

## 3. 古いマーケティングメッセージを整える

この新しいディスプレイを設置する前、店には似たようなディスプレイがありましたが、設定を変えられない固定の行しか表示できませんでした。
オーナーは、古いマーケティングメッセージのいくつかを新しいディスプレイで再利用したいと考えています。
しかし、そのデータにはすでに星の枠と、困ったことに余分な空白が含まれています。
メッセージを再利用できるように整えることが課題です。

古いマーケティングメッセージを文字列として受け取る関数`CleanUpMessage`を実装してください。
この関数は、まずテキストからすべての星を取り除き、その後、残ったテキストの先頭と末尾の空白を取り除きます。
そして、整えたメッセージを返します。

```go
message := `
**************************
*    BUY NOW, SAVE 10%   *
**************************
`

CleanUpMessage(message)
// => BUY NOW, SAVE 10%
```
