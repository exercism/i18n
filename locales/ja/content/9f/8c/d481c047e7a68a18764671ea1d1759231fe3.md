# 説明

遊園地での作業の続きとして、来園者がアトラクションに乗れるかどうかを確認するためのユーティリティメソッドを書くことになりました。

## 1. 来園者がライドパスを持っているかを確認する

`Attendee#has_pass?`メソッドを実装して、ライドパスの有無に基づく真偽値（`true`/`false`）を返すようにしましょう。

```ruby
Attendee.new(100).has_pass?
# => false
```

## 2. 来園者がアトラクションに乗れるかを確認する

`Attendee#fits_ride?`メソッドを実装して、身長に基づいて来園者がアトラクションに乗れるかどうかを確認します。
アトラクションの最低身長は引数として渡されます。
来園者の身長は、アトラクションの最低身長以上でなければなりません。

```ruby
Attendee.new(140).fits_ride?(100)
# => true
```

## 3. 来園者がアトラクションに乗ることを許可されているかを確認する

`Attendee#allowed_to_ride?`メソッドを実装して、来園者がアトラクションに乗ることを許可されているかどうかを確認します。アトラクションの最低身長は引数として渡されます。来園者はライドパスを持っていて、かつアトラクションに乗れる体格である必要があります。

```ruby
attendee = Attendee.new(100)
attendee.issue_pass!(42)
attendee.allowed_to_ride?(120)
# => false
```
