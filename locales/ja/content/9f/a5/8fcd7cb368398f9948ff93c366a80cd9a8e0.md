# 説明

この演習では、2012年9月15日にオープンした美容サロンの予約スケジューラーに取り組みます。

5つのタスクがあり、いずれも予約日時を扱います。

## 1. 予約日時を解析する

`Schedule`関数を実装して、予約日時のテキスト表現を、対応する`time.Time`形式に解析します。

```go
Schedule("7/25/2019 13:45:00")
// => 2019-07-25 13:45:00 +0000 UTC
```

## 2. 予約がすでに過ぎているかどうかを確認する

`HasPassed`関数を実装します。この関数は予約日時を受け取り、その予約が過去のものであるかどうかを確認します。

```go
HasPassed("July 25, 2019 13:45:00")
// => true
```

## 3. 予約が午後にあるかどうかを確認する

`IsAfternoonAppointment`関数を実装します。この関数は予約日時を受け取り、その予約が午後（12:00以降、18:00未満）にあるかどうかを確認します。

```go
IsAfternoonAppointment("Thursday, July 25, 2019 13:45:00")
// => true
```

## 4. 予約の日時を説明する

`Description`関数を実装します。この関数は予約日時を受け取り、その日時の説明を返します。

```go
Description("7/25/2019 13:45:00")
// => "You have an appointment on Thursday, July 25, 2019, at 13:45."
```

## 5. サロンの開店記念日を返す

`AnniversaryDate`関数を実装します。この関数は、サロンの開店記念日を、UTCでの今年の日付として返します。

現在の年が2020年だとします。

```go
AnniversaryDate()

// => 2020-09-15 00:00:00 +0000 UTC
```

**注意:** 戻り値は`time.Time`で、時刻は関係ありません。
