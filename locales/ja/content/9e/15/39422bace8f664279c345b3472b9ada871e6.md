## 真偽値

Rakuには`True`と`False`という真偽値リテラルがあります。
真偽値コンテキストでは、未定義のものはすべて`False`とみなされます。
`Bool::False`自体に加えて、`False`とみなされる定義済みの値には、`0`、`NaN`、`()`（空のリスト）、`""`（空文字列）、そして`Failure`型のオブジェクトがあります。

[前置`?`][&prefix:<?>]演算子は、オブジェクトに真偽値コンテキストを強制します。
その動作は、そのオブジェクトに対して[`Bool`][routine/Bool]メソッドを呼び出すのと同じです。
[前置`!`][&prefix:<!>]演算子は、前置`?`の逆の結果を返します。

## 真偽値の中置演算子

### スマートマッチ

別名スマートマッチ演算子とも呼ばれる[中置`~~`][&infix:<~~>]は、Rakuでよく使われる道具です。
その動作は、演算子の右側に与えられたオブジェクトによって決まります。というのも、これはそのオブジェクトの[`ACCEPTS`][routine/ACCEPTS]メソッドへのショートカットだからです。
左側の値は、`ACCEPTS`への引数として渡されます。
結果は真偽値になります。

### 論理AND/OR

Rakuには、真偽値の論理演算のために、[`&&`][&infix:<&&>]/[`and`][&infix:<and>]、[`||`][&infix:<||>]/[`or`][&infix:<or>]、[`//`][&infix:<//>]/[`orelse`][&infix:<orelse>]、そして[`^^`][&infix:<^^>]/[`xor`][&infix:<xor>]という演算子があります（それぞれ優先順位が高いものと低いものです）。
これらは連鎖させることができます。

```raku
1 xor 1 xor 1;
# Nil in Raku, 1 in Perl (because the latter makes the first pair false).
```

### 三項演算子

Rakuには三項演算子、つまり条件演算子である[中置`?? !!`][infix-??-!!]演算子があり、`$condition ?? $true !! $false`のように書きます。

## 制御フロー

### if/elsif/else

[`if`][control-if]文は、条件に応じてコードのブロックを実行するために使います。
`if`文を作るには、`if`キーワードの後に[式][statements-and-expressions]を書き、その後に[ブロック][control-block]を続けます。

式は[真偽値コンテキスト][contexts-boolean]で評価され、式が`True`と評価されるとブロックが実行されます。

`if`文は、[`elsif`と`else`][control-else/elsif]というキーワードで拡張できます。書き方は`if`と同じです。それより前の式がすべて`False`と評価されると`else`ブロックが実行され、`elsif`ブロックは、それ自身の式が`True`と評価されると、同じように実行されます。

あるいは、`if`は文修飾子の形でも使えます。

```raku
say 'success' if True;
```

文修飾子の形は、`elsif`や`else`とは組み合わせられません。

### given/when/default

[`given`][control-given]文は、Cなどの言語で`switch`がトピックを設定するのと同じように、Rakuでトピックを設定するキーワードです。
個々のケースに対応するキーワードは、[`when`と`default`][control-default-and-when]です。

### for/while/loop

[`for`][control-for]文は、与えられたリストを繰り返し処理し、そのリストにある各要素に対してブロックを実行します。

[`while`][control-while]文は、与えられた式が`True`と評価される間、ブロックを繰り返し実行します。

[`loop`][control-loop]文には2つの書き方があります。
ブロックだけを与えた場合、何かが明示的にループを抜けるまで、そのブロックを繰り返し実行します。
C言語スタイルの`for`ループとしても書くことができ、ブロックの前に括弧（`()`）でくくって、初期化式、条件式、増分式を書きます。

```raku
loop (my $i = 0; $i < 10; $i++) {
    say $i;
}
```
