# 説明の補足

## Odin固有の説明

Odinはデフォルト引数をサポートしています。
デフォルト引数は便利な機能で、関連しているけれど少しずつ異なるAPIが必要な場面で、さまざまな引数の組み合わせでプロシージャを呼び出せるようにします。

デフォルト引数がなければ、APIに必要なプロシージャの数が爆発的に増えてしまうことがあります。
Javaのようにデフォルト引数をサポートしていない言語では、同じことを実現するためにメソッドのオーバーロードに頼るか（その分、コードは増えます）、そうでなければ非常に多くの引数を持つプロシージャを用意しなければなりません。

ここで、`greeting`プロシージャを例に考えてみましょう。このプロシージャでは、言語、名前を大文字にするかどうか、そして挨拶の最後に感嘆符を付けるかどうかを指定できるようにしたいとします。
少し分析してみたところ、最も多いユーザーは言語に英語を指定し、名前を大文字にせず、最後に感嘆符を付けません。2番目に多いユーザーは、挨拶の最後に感嘆符を付けます。

すべての引数を持つプロシージャを1つ用意することもできます。

```odin
greeting :: proc(name: string, language: Language, do_uppercase: bool, add_exclamation: bool) {
	...
}
```

しかし、これではすべてのユーザーがすべての引数のドキュメントを読み、常にすべての引数を指定しなければならなくなります。

デフォルト引数がなければ、異なる引数の組み合わせを持つ複数のプロシージャを定義する方法もあります。

```odin
greeting_common :: proc(name: string) {...}

greeting_with_exclamation :: proc(name: string) {...}

greeting_general :: proc(name: string, language: Language, do_uppercase: bool, add_exclamation: bool) {...}

// Odin supports overloading but it has to be explicitly defined
greeting :: proc {
	greeting_common,
	greeting_with_exclamation,
	greeting_general,
}
```

Odinのようにデフォルト引数をサポートしている言語なら、あまり使われない引数に適切なデフォルト値を用意するだけで済みます。
呼び出し側はデフォルト引数を省略してそのデフォルト値を使うことも、上書きすることもできます。

```odin
greeting :: proc(name: string, language: Language = Language.English, do_uppercase : bool = false, add_exclamation: bool = false) {...}

// Note: because Odin supports type inference, we can simplify the interface.
greeting :: proc(name: string, language:= Language.English, do_uppercase := false, add_exclamation:= false) {...}
```

すべての引数を省略してプロシージャを呼び出すこともできます。

```odin
greeting("John Doe")
```

呼び出し側にとって重要な引数は上書きできます。

```odin
greeting("John Doe", Language.Spanish)
```

必要な引数が上の例のように位置の順序どおりであれば、引数に名前を付ける必要はありません。ただし、いくつかの引数を飛ばしたいときは、飛ばした最初の引数より後ろの引数には名前を付ける必要があります。

```odin
greeting("John Doe", add_exclamation=true)
```

## メモリ管理

この演習では、戻り値の文字列を確保することを意図したプロシージャを実装します。その文字列の解放は、プロシージャの呼び出し側の責任です。

```odin
// The procedure will be called like that:
str := two_fer("Alice")
// ...
// and eventually the caller will delete the string
delete(str)
```
