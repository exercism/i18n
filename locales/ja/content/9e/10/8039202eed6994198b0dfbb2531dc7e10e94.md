# はじめに

`cond`のほかに、Elixirにはマクロ[`if/2`][getting-started-if]も用意されています。これは、条件を1つだけ確認したいときに便利です。

[`if/2`][kernel-if]は条件と2つのオプションを受け取ります。条件が_真とみなされる_場合は1つ目のオプションを、_偽とみなされる_場合は2つ目のオプションを返します。

```elixir
age = 15

if age >= 16 do
  "You are allowed to drink beer in Germany."
else
  "No beer for you!"
end

# => "No beer for you!"
```

`if`式を1行で書くこともできます。条件のあとのカンマに注意してください。

```elixir
if age > 16, do: "beer", else: "no beer"
```

この構文はごく短い式には便利ですが、式が1行に収まらない場合は避けるべきです。

## _真とみなされる値_と_偽とみなされる値_

Elixirでは、すべてのデータ型は、真偽値の文脈（`if`式など）で扱われるとき、_真とみなされる_値または_偽とみなされる_値として評価されます。`false`と`nil`**以外**のすべてのデータは、_真とみなされます_。特に、空文字列、整数の`0`、空のリストは、Elixirではすべて_真とみなされます_。

[kernel-if]: https://hexdocs.pm/elixir/Kernel.html#if/2
