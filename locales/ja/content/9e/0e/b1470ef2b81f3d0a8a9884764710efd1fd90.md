# 概要

[範囲][range]は、1つまたは複数の連続する整数の並びを表します。範囲には次のような特徴があります。

- [`..`演算子][range-operator]を使って作成でき、昇順にも降順にもできます。
- デフォルトのステップは`1`ですが、[`..//`演算子][range-operator-with-step]を使って変更できます（Elixir 1.12以降）。
- 最初と最後の値を含みます。
- [_Enumerableプロトコル_][enumerable]を実装しています。
- 内部的には構造体として表現されますが、`..`を使ってパターンマッチできます。
- 2進数、8進数、16進数、コードポイント表記で書かれた整数と一緒に使えます。
- [`Enum.to_list/1`][enum-to-list]や[`Enum.map/2`][enum-map]といった関数を使って配列に変換できます。

```elixir
Enum.to_list(9..1)
# => [9, 8, 7, 6, 5, 4, 3, 2, 1]

Enum.map(?A..?F, &<<&1>>)
["A", "B", "C", "D", "E", "F"]
```
