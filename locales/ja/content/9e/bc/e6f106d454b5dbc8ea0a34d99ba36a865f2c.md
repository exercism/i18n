# 説明

この演習では、お客さんに配達するピザ屋で働きます。

扱っているピザは、次の3種類です：

- マルゲリータ：\$7
- カプレーゼ：\$9
- フォルマッジョ：\$10

お客さんは、少額の追加料金を払うと、さらに2つのオプションも選べます：

1. 追加ソース：\$1
1. 追加トッピング：\$2

お客さんが注文するとき、注文するピザが1枚か2枚だけだと、追加料金がかかります：

- ピザ1枚：\$3
- ピザ2枚：\$2

タスクは3つあり、どれもピザとその価格を扱います。

## 1. ピザの種類とオプションを定義する

`Pizza`という判別共用体を定義して、ピザの種類と、ピザに追加できる2つのオプションを表します：

- `Margherita`
- `Caprese`
- `Formaggio`
- `ExtraSauce`
- `ExtraToppings`

## 2. ピザの価格を計算する

`pizzaPrice`関数を実装して、ピザの価格を計算します：

```fsharp
pizzaPrice Caprese
// => 9
```

## 3. 注文の価格を計算する

`orderPrice`関数を実装して、ピザの注文の価格を計算します：

```fsharp
orderPrice [Margherita; Formaggio]
// => 19
```
