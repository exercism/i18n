# 説明

ジェンは大きな工場の仕分け室で働いています。
仕分け室では、入ってくるものすべてにラベルを付けて分類する必要があります。
ジェンは、あらかじめ数値として分類されたものを担当していて、その仕分けを手伝ってくれるプログラムを必要としています。

ほとんどのプリミティブ値には、単純なラベルを付けるだけで済みます。
数値の場合は、`"This is the number 2.0"`という文字列を返してほしいと考えています（数値が2の場合）。
整数でも小数でも、ジェンは同じ出力を求めています。

中身を取り出すためにアンラップする必要がある`Box`インターフェースがいくつかあります。
`NumberBox`の場合は、`"This is a box containing the number 3.0"`という文字列を返してほしいと考えています（`Number()`メソッドが3を返す場合）。
`FancyNumberBox`の場合は、`"This is a fancy box containing the number 4.0"`という文字列を返してほしいと考えていますが、それは型が`FancyNumber`の場合だけです。

想定外のものは`"Return to sender"`と返すようにして、ジェンが元あった場所へ送り返せるようにします。

## 1. 単純な数値を説明する

ジェンは、数値が`"This is the number 2.0"`のような文字列を返すことを望んでいます（小数点以下1桁を含みます）:

```go
fmt.Println(DescribeNumber(-12.345))
// Output: This is the number -12.3
```

## 2. 数値ボックスを説明する

ジェンは、数値ボックスが`"This is a box containing the number 2.0"`のような文字列を返すことを望んでいます（こちらも小数点以下1桁を含みます）:

```go
fmt.Println(DescribeNumberBox(numberBoxContaining{12}))
// Output: This is a box containing the number 12.0
```

## 3. ファンシー数値ボックスから数値を取り出すメソッドを実装する

ジェンは、`FancyNumberBox`から数値を取り出すヘルパー関数を必要としています。
`FancyNumberBox`が`FancyNumber`であれば、その値を取り出し、`string`から`int`に変換します。
それ以外の型の`FancyNumberBox`は0を返すようにします。

```go
fmt.Println(ExtractFancyNumber(FancyNumber{"10"}))
// Output: 10
fmt.Println(ExtractFancyNumber(AnotherFancyNumber{"4"}))
// Output: 0
```

## 4. ファンシー数値ボックスを説明する

`FancyNumberBox`が`FancyNumber`であれば、ジェンは`"This is a fancy box containing the number 4.0"`という文字列を返してほしいと考えています。
それ以外の型の`FancyNumberBox`は`"This is a fancy box containing the number 0.0"`と返すようにします。

```go
fmt.Println(DescribeFancyNumberBox(FancyNumber{"10"}))
// Output: This is a fancy box containing the number 10.0
fmt.Println(DescribeFancyNumberBox(AnotherFancyNumber{"4"}))
// Output: This is a fancy box containing the number 0.0
```

注意：`ExtractFancyNumber`関数を使いましょう！

## 5. それらをすべて使う`DescribeAnything`を実装する

これは、任意の入力を受け取る、ジェンが必要とするメイン関数です。
`DescribeAnything`は、渡された値の型に応じて、他の関数に処理を委譲します。
具体的には次のとおりです:

- `int`と`float64`はどちらも`DescribeNumber`に委譲します
- `NumberBox`は`DescribeNumberBox`に委譲します
- `FancyNumberBox`は`DescribeFancyNumberBox`に委譲します
- それ以外は`"Return to sender"`を返すようにします

```go
fmt.Println(DescribeAnything(numberBoxContaining{12.345}))
// Output: This is a box containing the number 12.3
fmt.Println(DescribeAnything("some string"))
// Output: Return to sender
```
