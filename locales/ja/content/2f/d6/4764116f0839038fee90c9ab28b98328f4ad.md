## 省略可能な引数

```julia-repl
julia> f(a, b=1) = a + b
f (generic function with 2 methods)
```

これは、次と同じ意味になります。

```julia-repl
julia> f(a, b) = a + b
f (generic function with 1 method)

julia> f(a) = f(a, 1)
f (generic function with 2 methods)
```

REPLの応答を見ると、最初の定義が一度に2つのメソッドを定義していることがわかります。
