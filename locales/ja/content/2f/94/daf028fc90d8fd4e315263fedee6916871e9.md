# 指示の補足

## 盤面の形式

盤面は、ヌル終端された文字列として表され、各行の末尾には改行文字が入ります。

例を挙げると、`"X  \n XO\nOX \n"`のようになります。

## レジスタ

| レジスタ | 用途        | 型    | 説明                                                             |
| -------- | ------------ | ------- | ----------------------------------------------------------------------- |
| `$a0`    | 入力        | アドレス | ヌル終端された入力文字列                                            |
| `$v0`    | 出力       | 整数 | ゲームの状態（`1`=`ongoing`、`2`=`draw`、`3`=`win`、`-1`=`error`） |
| `$t0-9`  | 一時的    | 任意     | 一時的な保存用                                                   |
