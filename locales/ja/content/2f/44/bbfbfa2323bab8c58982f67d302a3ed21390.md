# golintを満たしていません

[`golint`](https://github.com/golang/lint)という便利なツールがあります。コードを調べて、よくある問題やスタイル上の問題を指摘してくれます。
解答に対して`golint`を実行してみましょう。たとえば`golint two_fer.go`のようにします。いくつか役に立つ提案をしてくれます。

コードはいつも`golint`でチェックするのがおすすめです。
本番用のGoソフトウェアを書くときは、コードが`golint`を通らないと自動的に失敗するビルドパイプラインもたくさんあります。

コードリンターからもっと多くのフィードバックを得たいなら、[golangci-lint](https://github.com/golangci/golangci-lint)というプロジェクトもあります。
1つのコマンドでたくさんのリンターを実行できます。
プロジェクトの設定ファイルで、プロジェクトのニーズに合わせて動作を調整できます。

```
> golint
%{golint}
```
