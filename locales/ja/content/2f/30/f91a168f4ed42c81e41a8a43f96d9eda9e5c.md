# はじめに

Fundamentalsの概念で学んだように、AWKプログラムは**パターンとアクションのペア**で構成されています。

```awk
pattern1 { action1 }
pattern2 { action2 }
...
```

## 「パターン」とは何を指すのでしょうか？

「パターン」とは、任意のAWK式のことです。
式の結果が真とみなされるかどうかで、アクションを実行するかが決まります。

## 空のパターン

パターンは省略できます。
この場合、アクションはすべてのレコードに対して実行されます。

passwdファイルにあるすべてのユーザー名を出力できます。

```sh
awk -F: '{print $1}' /etc/passwd
```

## 正規表現

AWKでは、文字列を正規表現と比較して、真偽値の結果を得ることができます。

特定のフィールドを照合するには、正規表現にマッチする演算子`~`を使います。
この演算子は、左側のオペランドに文字列を、右側のオペランドに正規表現を取ります。
正規表現リテラルは、スラッシュ`/`で囲みます。

passwdファイルの中から、bashでログインするユーザーを見つけるには：

```sh
awk -F: '$7 ~ /bash/ {print $1}' /etc/passwd
```

`!~`は「正規表現が**マッチしない**」ことを表す演算子です。

現在のレコードに対して正規表現を照合するには、`$0 ~ /regex/`と書きます。
これはよく使われるため、省略記法があります。`$0`と`~`を省略して、単に`/regex/`と書くことができます。

```sh
awk '/regex/' data.txt
```

~~~~exercism/note
このAWKのワンライナーを、同等のgrepコマンドと比べてみましょう。

```sh
grep 'regex' data.txt
```

AWKは、簡潔さを犠牲にすることなく、プログラミング言語そのものを提供してくれます。
~~~~

## 式

AWKの式（算術式、論理式、その他の式など）は、パターンとして使えます。

UIDが1000以上のユーザーをすべて抽出するには：

```sh
awk -F: '$3 >= 1000' /etc/passwd
```

AWKで偽とみなされる値は数値のゼロと空文字列で、それ以外の数値や文字列はすべて真とみなされることを思い出しましょう。
数値や文字列に評価される式は、どんなものでもパターンとして使えます。

## 関数

[組み込み][builtins]関数や[ユーザー定義][user-defined]関数は、式の中で使えます。つまりパターンの中でも使えるということです。
いくつか例を挙げます。

```awk
length($1) {print "first field is not empty"}
```
```awk
toupper(substr($1, 1, 1)) ~ /[AEIOU]/ {print "starts with a vowel"}
```

## 定数パターン

AWKでよく使われるイディオムがあります。

```sh
{
    xyz()   # some code that transforms each record
}
1
```

`1`は、対応するアクションのない真のパターンです。
これは「現在のレコードを出力する」という意味です。
