# はじめに

キーワードリストは、キーと値のデータ構造です。

```elixir
[month: "April", year: 2018]
```

キーワードリストは`{key, value}`という[タプル][exercism-tuples]のリストで、そのように書くこともできますが、短い構文のほうがよく使われます。

```elixir
[month: "April"] == [{:month, "April"}]
# => true
```

キーワードリストのキーは[アトム][exercism-atoms]でなければなりませんが、値は何でもかまいません。同じキーを複数回使うこともできます。キーワードリストのキーと値のペアには順序があります。

キーワードリストは、リストと同じ方法で扱うこともできますし、`Keyword`モジュールを使うこともできます。

[exercism-tuples]: https://exercism.org/tracks/elixir/concepts/tuples
[exercism-atoms]: https://exercism.org/tracks/elixir/concepts/atoms
