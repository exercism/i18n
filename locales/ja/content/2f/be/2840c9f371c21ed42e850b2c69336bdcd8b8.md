# はじめに

## 文字列

C#の`string`は、不変のテキストをUnicode文字の並び（文字、数字、句読点など）として表すオブジェクトです。`string`インスタンスを定義するには、二重引用符を使います。

```csharp
string fruit = "Apple";
```

### メソッド

文字列を操作するには、文字列の[組み込みメソッド][docs-string-methods]を呼び出します。たとえば、文字列から空白を削除するには、[Trimメソッド][tutorial-docs.microsoft.com-trim-white-space]を次のように使います。

```csharp
string name = " Jane "
name.Trim()
// => "Jane"
```

一度文字列を作成すると、その値を変更することはできません。文字列を変更しているように見えるメソッドも、実際には新しい文字列を返します。

### 連結

複数の文字列は連結（加算）できます。最も簡単な方法は、`+`演算子を使うことです。

```csharp
string name = "Jane";
"Hello " + name + "!";
// => "Hello Jane!"
```

### 書式設定

単純な連結よりも複雑な文字列の書式設定には、文字列補間を使うのがおすすめです。文字列で補間を使うには、先頭にドル記号（`$`）を付けます。次に、波括弧（`{}`）を使って、文字列内の変数にアクセスできます。

```csharp
string name = "Jane";
$"Hello {name}!";
// => "Hello Jane!"
```
