# はじめに

Cは静的型付け言語です。つまり、コンパイル時にすべてに型が付いています。
変数の名前を決めてその型を設定することを、変数の宣言といいます。

変数は、その型を明示的に指定して宣言します。
変数名は、文字またはアンダースコアで始める必要があります。
一部の名前は、[キーワード][reserved-keywords]や[その他の識別子][reserved-identifiers]として予約されているため、使えません。

変数の設定や更新は、変数の代入によって行います。
値を設定すると、その変数が定義されます。
変数を定義することは、初期化とも呼ばれます。

```c
int foo;      // Declare an integer named var
foo = 10;     // Define the variable

int bar = 15; // Both can also be done in a single statement
```

変数の値は、単純代入演算子`=`を使って代入したり更新したりできます。
一度定義すると、変数の型は決して変えられません。

```c
int foo = 10; // Assign initial value
foo = 25;     // Update to new value

foo = false;  // Compiler error when assigning value of a different type
```

Cは命令型の手続き型言語です。
すべての計算は、1つまたは複数の関数の一部である一連の文として実行されます。

各関数は、0個以上の仮引数を持つことができます。
関数を定義するときは、すべての仮引数と戻り値の型を明示的に指定する必要があります。
値は、`return`キーワードを使って関数から返します。
関数はデフォルトで外部記憶クラスを持ちます。つまり、プログラムが動いている間ずっと存在し、ファイルの外部からも見ることができます。
これを防ぐには、`static`キーワードを付けて内部からのみ見えるように指定します。

```c
static int add(int x, int y) {
  return x + y;
}
```

上の例では、変数`x`と`y`はその関数の中でしか使えません。つまり、関数スコープを持ちます。
スコープとは、名前（プログラム要素の名前）に結び付いた値が、それが定義されたコードの「領域」の中でしかアクセスできないという考え方です。
Cにおける主なコードの領域は次のとおりです。

- ファイル
- 関数
- ブロック（ループなどの構文の中など）

関数は、関数名を指定し、各仮引数に引数を渡すことで呼び出します。

```c
int sum = add(1, 2);
```

Cは2種類のコメントをサポートしています。
1行コメントは`//`で始まり（C99以降）、複数行コメントは`/*`と`*/`の間に書きます。

[reserved-keywords]: https://en.cppreference.com/w/c/keyword
[reserved-identifiers]: https://en.cppreference.com/w/c/language/identifier
