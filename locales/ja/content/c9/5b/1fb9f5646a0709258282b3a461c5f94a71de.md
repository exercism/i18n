# 指示の補足

## レジスタ

| レジスタ | 用途     | 型    | 説明                                      |
| -------- | --------- | ------- | ------------------------------------------------ |
| `$a0`    | 入力     | 整数 | 調べる年                                    |
| `$v0`    | 出力     | 真偽値 | 入力がうるう年かどうか（`0` = `false`、`1` = `true`） |
| `$t0-9`  | 一時     | 任意 | 一時的な保存に使います                       |
