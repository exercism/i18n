# おすすめの学習リソース

ColdFusion（CFML）の学習へようこそ！　CFMLは、動的で型付けが緩やかなJVMスクリプト言語です。ファイルの種類は2つあります。`.cfm`ファイル（ColdFusion Markup）は完全に手続き型で、HTMLをテンプレートとして出力するためにタグベースの構文を使います。ウェブサイトを作る場合は、これをビューに使います。

**index.cfm**

```xml
<cfoutput>
	<html>
		<h1>Welcome to my site, #FirstName# #LastName#!
	</html>
</cfoutput>
```

もう1つのファイルの種類は`.cfc`（ColdFusion Component）で、クラスを宣言するときに使います。コンポーネントは、ビジネスロジックやモデル、コントローラーに使われます。こちらはたいていスクリプト構文で書かれ、JavaScriptに似た書き味です。

**Car.cfc**

```js
component accessors=true {
	property name='make' type='string';
	property name='model' type='string';
	property name='year' type='number';

	function init() {
		return this;
	}
 
}
```
