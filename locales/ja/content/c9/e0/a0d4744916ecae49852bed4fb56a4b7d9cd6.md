# 浮動小数点数

浮動小数点数は、PHPで実数の一部を表すために使います。
小数点で区切られた1つ以上の数字を書いて表します。

```php
<?php

$a = 1.234; 
$b = 1.2e3; 
$c = 7E-10;
$d = 1_234.567; // as of PHP 7.4.0
```

## よくある落とし穴

すべての数値と算術演算を浮動小数点数で扱えるわけではありません。
ドルやセントを表すのに浮動小数点数を使うと、丸め誤差が生じることがあります。

```php
<?php

$result = 0.1 + 0.2; // => 0.30000000000000004
```
