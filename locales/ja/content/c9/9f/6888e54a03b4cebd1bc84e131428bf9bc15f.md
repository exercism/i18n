# 燃料データ変換JSON

## 問題

ABC Corpの従業員には、全員に無制限の燃料手当が支給されます。従業員は、車に給油するたびに記録を送信する必要があります。これらの記録は同じJSONファイルに追加され、月末に処理されます。

デジタル運用チームの一員として、このJSONファイルを読み込み、その結果を別のJSONファイルに書き出すのがタスクです。出力ファイルには、従業員ごとに次の詳細を含むエントリが入っている必要があります。

- 従業員番号
- 給油回数
- 燃料費の合計
- ガロンの合計
- 走行距離の合計（マイル）

2つの`string`引数が与えられます。

1. 入力JSONファイルのパス。
1. 出力JSONファイルのパス。

入力JSONファイルには、JSONオブジェクトの配列が入っています。各JSONオブジェクトは次の形式です。


```json
{
    "type": "array",
    "items": {
        "type": "object",
        "properties": {
            "employeeId": {
                "type": "integer"
            },
            "odometerReading": {
                "type": "integer"
            },
            "gallons": {
                "type": "number"
            },
            "gasPrice": {
                "type": "number"
            }
        },
        "required": [
            "employeeId",
            "odometerReading",
            "gallons",
            "gasPrice"
        ]
    }
}
```

```ballerina
// Ballerina record type definition
type FillUpEntry record {|
    int employeeId;
    int odometerReading;
    decimal gallons;
    decimal gasPrice;
|};
```

JSON入力を次のJSON形式に変換し、その内容を指定されたパスに書き出すのがタスクです。出力ファイルには、`employeeId`の昇順で並べた、従業員ごとのエントリが入っている必要があります。

```json
{
    "type": "array",
    "items": {
        "type": "object",
        "properties": {
            "employeeId": {
                "type": "integer"
            },
            "gasFillUpCount": {
                "type": "integer"
            },
            "totalFuelCost": {
                "type": "number"
            },
            "totalGallons": {
                "type": "number"
            },
            "totalMilesAccrued": {
                "type": "integer"
            }
        },
        "required": [
            "employeeId",
            "gasFillUpCount",
            "totalFuelCost",
            "totalGallons",
            "totalMilesAccrued"
        ]
    }
 }
```

```ballerina
// Ballerina record type definition
type EmployeeFillUpSummary record {|
    int employeeId;
    int gasFillUpCount;
    decimal totalFuelCost;
    decimal totalGallons;
    int totalMilesAccrued;
|};
```

## 制約

- 入力JSONファイル内の給油記録の数`n`：0 <= n <= 1000
- 会社の従業員数：97
- ガソリン価格は1ガロンあたりです
- 給油記録の欠落はありません

## ヒント

- JSONファイルの読み書きには、[`ballerina/io`モジュール](https://lib.ballerina.io/ballerina/io/latest)を使います。
- 型安全にデータを扱うには、JSONの値をアプリケーション固有の型に変換します。詳しくは、Ballerina By Examples（BBE）の[ユーザー定義型への変換の例](https://ballerina.io/learn/by-example/convert-from-json-to-user-defined-type)を参照してください。

```ballerina
   json jsonPayload = {id: "2", title: "Jeru", artist: "Gerry Mulligan", price: 17.99};

   // Using cloneWithType  
   Album album1 = check jsonPayload.cloneWithType();
   io:println(album1);
 
   // Using fromJsonWithType
   Album album2 = check jsonPayload.fromJsonWithType();
   io:println(album2);
```

- [レコードの分割代入](https://ballerina.io/learn/by-example/destructure-records-using-query)は、コードの冗長さを減らすのに役立ちます。

```ballerina
   Album {id, title, artist, price} = album1;
   io:println(id);
   io:println(title);
```

- 式が1つだけの関数には、式本体の関数を使います。たとえば、return文だけを持つ関数です。

```ballerina
   function cfr(int deaths, int cases) returns decimal => <decimal>deaths / <decimal>cases * 100;
```
