# 概要

Common Lispはほとんどの演算で標準の算術演算子を使いますが、より一般的な「中置記法」ではなく「前置記法」を使うという点が少し独特です。

図で見ると、次のようになります。

```lisp
;; Infix-notation (non-lisp languages)
1 + 2 + 3 + 4 + 5 ; => 15
;; Prefix-notation (lisp languages)
(+ 1 2 3 4 5)     ; => 15
```

前置記法では、`2 + 2`のような演算が、やや見慣れない`(+ 2 2)`という形になりますが、その代わり、複数の数値を一度に扱うのがずっと簡単になります。

## 引数が1つの算術演算子

ちょっとした癖として、`-`と`/`の演算子は、数値を1つだけ受け取ったときに特別な意味を持ちます。

```lisp
;; A single number passed to `-` is simply negated
(- 4)   ; => -4
(- -32) ; => 32
;; A single number passed to `/` returns the reciprocal
(/ 8)   ; => 1/8
(/ 0.1) ; => 10.0
```

## 数値の比較

最後に、`=`（等しい）、`/=`（等しくない）、`>=`（以上）などの関数を使って数値を比較すると便利なことがあります。
これらの比較が真であれば（`(= 1 1)`のように）`T`を返し、そうでなければ（`(> 0 1)`のように）`NIL`を返します。

## 数値の述語

この言語には、`zerop`、`evenp`、`oddp`など、名前の通りの条件を調べる便利な述語も用意されています。

## リファレンス

```lisp
;; Addition
(+ 1 2 3 4 5) ; => 15

;; Subtraction
(- 15 3 2)    ; => 10
(- 42)        ; => -42

;; Multiplication
(* 4 3 2 1)   ; => 24

;; Division
(/ 64 16 2)   ; => 2
(/ 5)         ; => 1/5

;; Exponentiation
(expt 2 8)    ; => 256

;; Square Root
(sqrt 25)     ; => 25

;; Modulo (Similar to remainder)
(mod 10 3)    ; => 1

;; Equality
(= 2 2)       ; => T
(= 3 5)       ; => NIL
```
