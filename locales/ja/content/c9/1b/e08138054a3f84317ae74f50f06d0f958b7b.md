# テスト

## テストの実行

テストを実行するには、次のコマンドを実行します。

```bash
dotnet test
```

ソースファイルを変更するたびにテストを自動で実行するには、次のコマンドを実行します。

```bash
dotnet watch test
```

## 演習を解く

演習を解くとは、その演習のテストをすべて通すことです。テストを実行すると、デフォルトでは1つのテスト（最初のテスト）だけが実行されます。これは意図的なもので、まずはその1つのテストを通すことに集中できるようになっています。テストが通ったら、テストの`[Fact]`または`[Theory]`属性から`Skip = "Remove this Skip property to run this test"`を削除すると、次のテストを有効にできます。すべてのテストを有効にして、そのすべてが通る実装になれば、演習は解けたことになります！

始めやすくなるように、各演習にはスタブの実装ファイルが用意されています。このファイルを、解答を作り始めるための出発点として使えます。必要だと思うなら、このファイルを削除したり変更したりしてかまいません。

## パッケージを使う

ほとんどの演習は、外部パッケージを使わずに解けるはずです。ただ、外部パッケージを使いたい演習では、次のコマンドを実行してプロジェクトに追加できます。

```bash
dotnet add package [package-name]
```
