# 指示

英語をピッグ・ラテンに翻訳するプログラムを実装します。

ピッグ・ラテンは、子どもたちが考え出した、わざとわかりにくくした言葉遊びです。いくつかの簡単なルール（下記）に従いますが、すばやく話されると、子ども以外の人（そして母語話者以外の人）にとっては本当に理解するのが難しくなります。

- **ルール1**：単語が母音の音で始まる場合は、その単語の末尾に "ay"の音を付け加えます。
  単語の先頭にある "xr" と "yt" は母音の音になることに注意してください（例："xray" -> "xrayay"、"yttria" -> "yttriaay"）。
- **ルール2**：単語が子音の音で始まる場合は、その音を単語の末尾に移し、そのあとに "ay"の音を付け加えます。
  子音の音は複数の子音からできていることもあり、これを子音クラスターと呼びます（例："chair" -> "airchay"）。
- **ルール3**：単語が子音の音とそれに続く "qu" で始まる場合は、その部分を単語の末尾に移し、そのあとに "ay"の音を付け加えます（例："square" -> "aresquay"）。
- **ルール4**：単語の中で、子音クラスターのあとに "y" が来る場合、または2文字の単語の2文字目が "y" である場合、その "y" は母音の音になります（例："rhythm" -> "ythmrhay"、"my" -> "ymay"）。

ほかにも、例外的なケースに対応するためのルールがいくつかあり、地域による変種もあります。

ピッグ・ラテンについて詳しくは、[ウィキペディアのピッグ・ラテン][pig-latin]をご覧ください。

[pig-latin]: https://en.wikipedia.org/wiki/Pig_latin
