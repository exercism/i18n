## インポート

モジュールは通常、`use`キーワードを使って読み込みます。`use`はモジュールを読み込むと同時に、そのモジュールの`import`メソッドを呼び出し、エクスポートされているシンボルをインポートします。

パッケージの`@EXPORT`配列にあるシンボルは、デフォルトでインポートされます。パッケージの`@EXPORT_OK`配列にあるシンボルは、明示的にインポートする必要があります。

Perl `v5.37`より前では、モジュールが正常に読み込まれたことを示すために、モジュールが真の値（通常は`1`）で終わっている必要がありました。[`module_true`][module_true]機能を使う場合、これは必要ありません。

## エクスポート

シンボルをインポートするには、まずエクスポートされている必要があります。[Exporter][Exporter]モジュールはPerlに同梱されており、エクスポートを行うためのもっとも便利な選択肢の一つです。

モジュールを定義する:
```perl
package Foo;

use Exporter ('import');
our @EXPORT_OK = ('bar');

sub bar { ... }
```

モジュールを使う:
```perl
use Foo ('bar');

bar();
```

## プラグマ

プラグマとは、Perlの動作のある側面に影響を与えるモジュールです。

[`strict`][strict]プラグマと[`warnings`][warnings]プラグマはよく推奨されます。それぞれ、安全でない構文を制限し、問題になりそうな箇所を知らせるためです。`strict`プラグマは、`use v5.12`以上を使うと有効になります。`warnings`プラグマは、`use v5.35`以上を使うと有効になります。

[`feature`][feature]プラグマを使うと、新しい機能や実験的なPerlの機能を有効にできます。`use`キーワードに特定のPerlのバージョンを指定すると、そのバージョンの機能バンドルが有効になります。

## コアモジュール

[Exporter][Exporter]のほかにも、Perlにはさまざまな[コアモジュール][perl-core-modules]が用意されています。ここで出会う演習に役立つ例としては、[List::Util][List::Util]、[Time::Piece][Time::Piece]、[Math::BigRat][Math::BigRat]などがあります。

## CPAN

コアモジュールに加えて、[CPAN][metacpan]にはPerlコミュニティによって作られた数千もの追加モジュールが公開されており、インストールして使えます。Perlトラックでは、[cpanfile][test-runner-cpanfile]を使って、ExercismのPerlテストランナーで使えるモジュールをいくつかインストールしています。
