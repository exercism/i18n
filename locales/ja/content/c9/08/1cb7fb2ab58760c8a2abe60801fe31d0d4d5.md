# はじめに

`for`ループは、ある処理を繰り返し実行するためにもっともよく使われる文の1つです。JavaScriptでは、`for`キーワード、括弧（`()`）で囲まれた_ヘッダー_、そして波括弧で囲まれたループの_本体_を含むブロックからなります。

```javascript
for (initialization; condition; step) {
  // code that is executed repeatedly as long as the condition is true
}
```

初期化ではふつうカウンター変数を用意し、条件はループを続けるか止めるかを判定し、ステップは繰り返しのたびにカウンターを増やします。ヘッダーの各部分はセミコロンで区切られています。

```javascript
const list = ['a', 'b', 'c'];
for (let i = 0; i < list.length; i++) {
  // code that should be executed for each item list[i]
}
```
