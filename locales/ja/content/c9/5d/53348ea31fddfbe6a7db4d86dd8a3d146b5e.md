# 説明

友人のChandlerは、世界中のエキゾチックな国々を訪れる予定です。残念ながら、Chandlerは数学が得意ではありません。旅先で両替所にだまされないかかなり心配していて、あなたに為替計算機を作ってほしいと思っています。アプリの仕様は次のとおりです。

## 1. 両替後の価値を見積もる

2つの仮引数を受け取る`exchange_money()`関数を作成しましょう。

1. `budget`：両替する予定の金額。
2. `exchange_rate`：外国通貨1単位に相当する自国通貨の額。

この関数は、両替した通貨の価値を返します。

**注意：** 自国通貨がUSDで、為替レート`1.20`でUSDをEURに両替したい場合、`1.20 USD == 1 EUR`となります。

```julia
julia> exchange_money(127.5, 1.2)
106.25
```

## 2. 両替後に残る金額を計算する

2つの仮引数を受け取る`get_change()`関数を作成しましょう。

1. `budget`：両替前の金額。
2. `exchanging_value`：両替のために予算から*取り出される*金額。

この関数は、予算から*残った*金額を返します。

```julia
julia> get_change(127.5, 120)
7.5
```

## 3. 紙幣の価値を計算する

2つの仮引数を受け取る`get_value_of_bills()`関数を作成しましょう。

1. `denomination`：紙幣1枚の価値。
2. `number_of_bills`：紙幣の総枚数。

この両替所は、決まった単位の現金しか扱いません。受け取る合計金額は、1枚の「紙幣」、つまり単位の価値で割り切れる必要があり、端数や余りが出ることがあります。この関数は、両替所が返す紙幣の合計金額（_端数の金額は除く_）だけを返します。残念ながら、端数やおつりは両替所がおまけとしてそのまま受け取ります。

```julia
julia> get_value_of_bills(5, 128)
640
```

## 4. 紙幣の枚数を計算する

`amount`と`denomination`を受け取る`get_number_of_bills()`関数を作成しましょう。

この関数は、指定された_amount_の範囲で受け取れる_紙幣の枚数_を返します。言い換えると、開始金額に_丸ごとの紙幣_が何枚収まるでしょうか？　覚えておきましょう。受け取れるのは_丸ごとの紙幣_だけで、紙幣の端数を受け取ることはできません。そのため、それに合わせて割り算しましょう。実質的には、最も近い紙幣、つまり額面に_切り捨て_ていることになります。

```julia
julia> get_number_of_bills(127.5, 5)
25
```

## 5. 紙幣に両替した後の残りを計算する

`amount`と`denomination`を受け取る`get_leftover_of_bills()`関数を作成しましょう。

この関数は、紙幣の額面が与えられたとき、開始した_amount_から返すことのできない_残りの金額_を返します。両替所がいくらを手元に残せるのかを正確に知っておくことがとても大切です。

```julia
julia> get_leftover_of_bills(127.5, 20)
7.5
```

## 6. 両替後の価値を計算する

`budget`、`exchange_rate`、`spread`、`denomination`を受け取る`exchangeable_value()`関数を作成しましょう。

仮引数`spread`は、両替手数料として*取られる割合*を整数で表したものです。これは100で割って小数に変換する必要があります。`1.00 EUR == 1.20 USD`で、*spread*が`10`の場合、実際の為替レートは`1.00 EUR == 1.32 USD`になります。1.20の10%は0.12で、この追加手数料が為替レートに加算されるからです。

この関数は、*為替レート*と*spread*を計算したうえで、新しい通貨の最大値を返します。通貨の*額面*は整数で、分割できないことを覚えておきましょう。

**注意：** 戻り値は整数型にしてください。

```julia
julia> exchangeable_value(127.25, 1.20, 10, 20)
80

julia> exchangeable_value(127.25, 1.20, 10, 5)
95
```
