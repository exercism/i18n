# はじめに

Rの`vector`は、同じ`type`の値の集まりです。`type`には`numeric`や`character`などがあります。型の異なる値が混ざった入力を渡すと、Rはそれらをすべて共通の型、たいていは`character`へと暗黙のうちに変換してしまい、予想外の結果になることがあります。

```R
v <- c(2, 5.4, "txt")
v
#> [1] "2"   "5.4" "txt"
typeof(v)
#> [1] "character"
```

## ベクトルの作成

すべての値がすでに手元にあるなら、`c()`を使います（"concatenate"または"combine"の略です）。

```R
x <- 10
v <- c(4, 7, x)
```

`c()`関数はとても柔軟で、入力には他のベクトルや範囲を含めることもできます。`c()`はどんな数・種類の入力でも受け取り、それらを1つのベクトルに平坦化します。

## 範囲、数列、繰り返し

連続する値の範囲（昇順でも降順でも）には、`:`記法が使えます。

```R
v <- 1:5 # equivalent to c(1, 2, 3, 4, 5)
w <- 10:7 # c(10, 9, 8, 7)
```

`seq()`関数を使うと、より細かく制御できます。

```R
# specify step size
seq(2, 11, by = 3) # c(2, 5, 8, 11)

# specify number of values, evenly-spaced
seq(2.5, 4, length.out = 5) # c(2.500, 2.875, 3.250, 3.625, 4.000) 
```

いくつかの範囲は、組み込み定数としてあらかじめ定義されています。

```R
letters  # LETTERS is the UPPERCASE equivalent
#> [1] "a" "b" "c" "d" "e" "f" "g" "h" "i" "j" "k" "l" "m" "n" "o" "p" "q" "r" "s" "t" "u" "v" "w" "x" "y" "z"

month.name
#> [1] "January"   "February"  "March"     "April"     "May"       "June"      "July"      "August"   
#> [9] "September" "October"   "November"  "December" 

month.abb
#> [1] "Jan" "Feb" "Mar" "Apr" "May" "Jun" "Jul" "Aug" "Sep" "Oct" "Nov" "Dec"
```

## 算術

演算は自動的に、ベクトルに沿って要素ごとに適用されます。
他の言語でよく使われるループやリスト内包表記、再帰は必要なく、（*パフォーマンス上の理由から*）通常は避けたほうがよいでしょう。

```R
2 + 1:3 # c(3, 4, 5)
2 * 1:3 # c(2, 4, 6)
12 / 1:3 # c(12  6  4)
2 ^ (1:3) # c(2, 4, 8) : exponentiation, precedence order here needs ()
```

ベクトルのペア同士でも、要素ごとに計算できます。

```R
v <- 1:3
w <- 5:7

v + w
#> [1]  6  8 10

v * w
#> [1]  5 12 21

v ^ w
#> [1]    1   64 2187
```

## ベクトルの要素へのアクセス

多くの言語と同じように、インデックスを角括弧（`[]`）に書くことで要素を取り出せます。

```R
v <- 4:7
v[2]
#> [1] 5
v[2:4]
#> [1] 5 6 7
```

ただし注意してください。***Rはデフォルトで1始まりのインデックスを使います***。

これは科学技術計算向けの言語（Fortran・Matlab・Julia）ではよくあることですが、Cとその多くの後継言語の0始まりのインデックスとは異なります。

範囲は、上の例のように使えるほか、とても柔軟な`c()`関数の中でも使えます。

```R
v <- c(4, 7, 10)
w <- c(2, v[2:3], 11) # c(2, 7, 10, 11)
```

`vectors`は（Rのほとんどのものと同じように）可変として扱えます。単一の要素にも複数の要素にも、同じように柔軟な構文で書き込めます。

```R
v <- 1:10
v[2] <- 42
v[4:6] <- c(11, 12, 13)
v
#> [1]  1 42  3 11 12 13  7  8  9 10
```

## 負のインデックス

他の言語に慣れたプログラマーなら、`v[-1]`がベクトルの最後の要素を取り出す方法だと思うかもしれません。*間違いです！*　その用途には`tail(v, n=1)`を使ってください。

負のインデックスは、実際には要素を***取り除く***方法で、より短いベクトルを返します。

```R
v <- c(2, 4, 6)
v[-2]
#> [1] 2 6  # second element gone
```

## ベクトルの条件判定

ベクトルに比較を適用すると、同じ長さの真偽値のベクトルが返ります。これは`all()`や`any()`のような関数の中でとても便利です。

```R
v <- c(4, 7, 10)
v >= 6
#> [1] FALSE  TRUE  TRUE
all(v > 6)
#> [1] FALSE    # not all elements match this condition
any(v > 6)
#> [1] TRUE     # at least one element matches
```

より複雑な論理式では、ベクトルに作用する`&`と`|`演算子を使うことが重要です。2文字の`&&`と`||`は、単一の値を比較するためだけのものです。

```R
v %% 2 == 0 & v > 5
#> [1] FALSE FALSE  TRUE
```

## ベクトルはRの*どこにでも*ある

これは、後のトピックでまた取り上げるテーマです。今は、コンソールでの出力の形式だけ覚えておきましょう。

```R

#> [18] 18 19 20
```
