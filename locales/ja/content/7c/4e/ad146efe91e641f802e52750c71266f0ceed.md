# メンテナー向け

## テストを生成する: `bin/generate_tests.py`

テストファイルは、各演習の`.meta/template.j2`に保存されているJinjaテンプレートを使って、[exercism/problem-specifications](https://github.com/exercism/problem-specifications)のカノニカルデータから生成します。

```bash
bin/generate_tests.py bob            # regenerate one exercise
bin/generate_tests.py                # regenerate every exercise that has a template
bin/generate_tests.py --no-pull bob  # skip `git pull` of problem-specifications
```

このスクリプトは、configletのキャッシュ（`~/.cache/exercism/configlet/problem-specifications`、`bin/configlet sync`で埋められます）から、または`problem-specifications`という名前の親ディレクトリからproblem-specificationsを読み込みます。生成されるのは、`.meta/tests.toml`に含まれているケースだけです。

Fortranの文字列リテラルには、`\n`や`\t`のようなエスケープを書けません。テンプレートのフィルター`escape_quote_whitespace`がこれらを`" // NEWLINE // "`、`" // TAB // "`、`" // CARRIAGE_RETURN // "`に書き換えるので、テンプレート側でこれらの定数を宣言しておく必要があります（`exercises/practice/bob/.meta/template.j2`を参照）。

### 前提条件

- 動作するCMakeとFortranコンパイラー
- `jinja2`が入ったPython 3.12以降
- git

### 新しい演習を追加するワークフロー

`bob`を例にします。

- 新しいブランチを作成します（例: `git checkout -b exercise-bob`）
- `bin/add-exercise bob`を実行します（`jq`と`curl`が必要です）。このスクリプトは次のことをします。
  - configletを取得して`configlet create`を実行します。これにより、演習が`config.json`に追加され、ドキュメント・メタデータ・`tests.toml`がproblem-specificationsから同期されます
  - `bin/reorder-exercises`で`config.json`を並べ替えます
  - `exercises/shared/CMakeLists.txt`を演習ディレクトリにコピーします
  - ひな形の解答、ひな形の`.meta/example.f90`、スターターの`.meta/template.j2`（`exercises/shared/template.j2`から）を作成します

  `-a <username>`を渡さない場合はGitHubのユーザー名を尋ね、`-d <difficulty>`を渡さない場合は難易度を1に設定します。

- 各ケースが正しい入力で正しい関数を呼ぶように`.meta/template.j2`を編集し、テストを生成します。

  ```bash
  bin/generate_tests.py bob
  ```

- `.meta/example.f90`に動作する解答を書きます。学習者が取りかかりやすいように、学習者用のファイル（例: `bob.f90`）は、テストが呼び出す関数やサブルーチンの骨組みに置き換えます
- リポジトリのルートから全体をビルドして、すべてのテストが通ることを確認します。

  ```bash
  mkdir -p build && cd build
  cmake ..
  cmake --build .
  ctest -V -R bob
  ```

- `bin/reorder-exercises`と`bin/configlet lint`を実行します
- すべて通ったら、変更を加えたプルリクエストを作成します

### `CMakeLists.txt`を変更する

cmakeファイルを変更するときは、`exercises/shared/`にあるマスターコピーを更新し、`bin/update-cmake-files`を使ってすべての演習ディレクトリにコピーします。
