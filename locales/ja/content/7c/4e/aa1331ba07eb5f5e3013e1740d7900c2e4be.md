# 概要

C#は静的型付け言語です。つまり、コンパイル時にすべてのものに型が付いています。[変数][variable]の名前を決めることを、変数の定義と呼びます。一度変数を定義したあと、値を設定したり更新したりすることを、変数の代入と呼びます。変数は、型を明示的に指定して定義することもできますし、[`var`キーワード][var]を使って、代入された値をもとにC#コンパイラーに型を推論させることもできます。`var`を使うことは、_型推論_と呼ばれます。

```csharp
int explicitVar = 10; // Explicitly typed
var implicitVar = 10; // Implicitly typed
```

変数の値は、[`=`演算子][assignment]を使って代入したり更新したりできます。一度定義すると、変数の型を後から変えることはできません。

```csharp
var count = 1; // Assign initial value
count = 2;     // Update to new value

// Compiler error when assigning different type
// count = false;
```

C#はオブジェクト指向言語であり、すべての[関数][function]を_クラス_の中で定義する必要があります。クラスは[`class`キーワード][classes]を使って定義します。オブジェクト（または_インスタンス_）は、`new`キーワードを使って作成します。

```csharp
class Calculator
{
    // ...
}

var calculator = new Calculator();
```

クラスの中にある関数は、_メソッド_と呼ばれます。各[メソッド][methods]は、0個以上の仮引数を持つことができます。すべての仮引数には明示的に型を付ける必要があり、仮引数には型推論がありません。同様に、戻り値の型も明示する必要があります。値は、[`return`キーワード][return]を使ってメソッドから返します。ほかのファイルのコードからメソッドを呼び出せるようにするには、`public`アクセス修飾子を付ける必要があります。

```csharp
class Calculator
{
    public int Add(int x, int y)
    {
        return x + y;
    }
}
```

メソッドは、インスタンスに対してドット（`.`）構文を使って呼び出します。呼び出すメソッドの名前を指定し、メソッドの仮引数それぞれに実引数を渡します。実引数には、対応する仮引数の名前を指定することもできます。

```csharp
var calculator = new Calculator();
var sum_v1 = calculator.Add(1, 2);
var sum_v2 = calculator.Add(x: 1, y: 2);
```

呼び出すメソッドが、それを呼び出すメソッドと同じクラスで定義されている場合は、クラス名を省略できます。

メソッドがオブジェクトの_状態_を一切使わない場合は、`static`修飾子を使ってそのメソッドを_静的_にできます。静的メソッドもドット（`.`）構文を使って呼び出しますが、クラスのインスタンスではなく、クラス自体に対して呼び出します。

クラスが静的メソッドしか持たない場合、そのクラスも`static`修飾子を使って静的にできます。これはそのクラスの意図を表しています。

```csharp
static class Calculator
{
    public static int Multiply(int x, int y)
    {
        return x * y;
    }
}

Calculator.Multiply(2, 4); // => 8
```

C#のスコープは、`{`と`}`の文字の間に定義されます。

C#は2種類の[コメント][comments]をサポートしています。1行コメントは`//`で始まり、複数行コメントは`/*`と`*/`の間に書きます。

整数値は、1つ以上（連続した）の数字として定義され、[既定の算術演算子][operators]をサポートしています。

変数名には、[従うべきいくつかのルール][identifier-names]があり、たとえば文字またはアンダースコアで始まる必要があります。また、[C#の命名規則に従うことが推奨されます][naming-guidelines]。変数名が[C#の予約キーワード][csharp-keywords]と衝突する場合は、`@`を使ってエスケープする必要があります。この記法の使用は推奨されませんが、例外的なケース、たとえば`var @this`、`var @class`、`var @var`などで見かけることがあります。

C#のようなC言語系の言語にとって、あまりにも基本的で、少し込み入ったコードならほとんど必ず登場する概念がいくつかあります。それが、[ミューテーション][mutation]と[スコープ][scope]です。ミューテーションとは、プログラムの実行中に変数の値を変更できるという考え方です。スコープとは、（プログラムの要素の）名前に関連付けられた値が、それが定義されているコードの「領域」の中でしかアクセスできないという考え方です。C#の主なコード領域は、_クラス/構造体_と_関数_（通常はメソッド）ですが、ループやその他の構文の本体も含まれます。
