# 説明

Lisp星人のLeslieは、買い物に行く必要があります。買い物の配列を作ることはとても大切です。そこに物を追加したり、物を取り除いたりする必要があります。

もちろん、Lisp星人にとっては、紙とペンだけでは物足りません。「List」は「Lisp」という単語の大半を占めているほどです！　買い物を管理するには、いくつかの関数を書く必要があります。

Leslieが買い物の配列をうまく管理できるように、手伝ってあげませんか？

## 1. 新しい配列を作る

まず、Leslieは空の配列を作る必要があります。そのためには`new-list`という関数がぴったりです。

```lisp
(new-list) ; => ()
```

あらら…Leslieにはすでにいくつか買いたいものがあるので、3つの品物を受け取り（幸いなことに、Leslieが作る配列はいつも3つの品物だけです。それ以上でもそれ以下でもありません！）、それらで新しい買い物の配列を作る関数が必要です。3つの品物を受け取り、それらの配列を返す関数`list-of-things`を書いてみましょう。

```lisp
(list-of-things 'bread 'milk 'butter) ; => '(bread milk butter)
```

## 2. 配列に物を追加する

店に行く前に、Leslieは食料庫を覗いて何が必要かを確認します。配列の先頭に品物を追加する関数`add-to-list`を書いて、手伝ってあげましょう。

```lisp
(add-to-list 'butter '(bread)) ; => '(butter bread)
```

## 3. 配列の次の品物は？

買い物中、Leslieは次に何を探せばよいかを知りたくなります。また、配列を先読みして、2番目、3番目、あるいは23番目（Leslieのラッキーナンバー）の品物を確認するのも好きです。

- `first-thing`は配列の最初の品物に評価されます
- `second-thing`は2番目の品物に評価されます
- `third-thing`は3番目の品物に評価されます
- `twenty-third-thing`は23番目の品物に評価されます

```lisp
(first-thing '(bread butter milk)) ; => 'bread
(second-thing '(bread butter milk)) ; => 'butter
(third-thing '(bread butter milk)) ; => 'milk
```

## 4. 配列から品物を取り除く

Leslieは配列の最初の品物を見つけて、それを棚から取り除きたいと思っています。入力の配列から最初の品物以外のすべてを含む配列に評価される関数`remove-first-item`を書いて、手伝ってあげましょう。

```lisp
(remove-first-item '(bread butter milk)) ; => '(butter milk)
```

## 5. 小さな配列から大きな配列を作る

Leslieは、うっかり1つではなく2つの買い物の配列を作ってしまったことに気づきました！　1つ目の配列の要素の後に、2つ目の配列の要素が続く配列を返す関数`list-append`を書いてください。

```lisp
(list-append '(bread salt) '(butter milk)) ; => '(bread salt butter milk)
```

## 6. あとどれくらい？

Leslieは、この買い物が長引きそうで心配になってきました。この配列にはいったい何個の品物があるのでしょうか？　Leslieの配列の長さを教えてくれる関数`just-how-long`を書いてください。

```lisp
(just-how-long '(bread milk butter salt)) ; => 4
```
