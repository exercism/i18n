# はじめに

メソッドの仮引数は、デフォルト値を代入しておくと省略可能になります。省略可能な仮引数を持つメソッドを呼び出すとき、呼び出し側はその仮引数に値を渡す必要はありません。省略可能な仮引数に値が渡されなかった場合は、デフォルト値が使われます。

省略可能な仮引数は、仮引数リストの末尾に置く必要があります。そのあとに、省略可能でない仮引数を置くことはできません。

```haxe
class Card {
  static function newYear(year = 2021):String {
    return "Happy " + year;
  }
}

Card.newYear(); // Happy 2020
Card.newYear(1990); // Happy 1990
```

省略可能な仮引数は、変数名の前に`?`演算子を付けて`null`に設定することもできます。

```haxe
function newYear(?year:Int) {
  if (year != null)
    return "It's " + year;
  return "Year is null";
}

newYear(); // Year is null
```
