# 概要

## オプショナル

Swiftでは、値が存在しない可能性を表現するために[_オプショナル_][optionals]を使います。オプショナルは、値を保持するか、値が存在しないことを表す[`nil`][nil]であるかの、どちらかになる型です。オプショナルを使うには、アンラップしたあとでその値を使う前に、値が実際に存在するかどうかをプログラムで確認する必要があります。

型名の末尾に`?`を付けると、どんな型でもオプショナルにできます。たとえば、オプショナルの整数は`Int?`型、オプショナルの文字列は`String?`型になります。オプショナル型の定数や変数を定義して値を代入する方法は、オプショナルでない型の場合と同じです。

```swift
let x: Int? = 42
var y: String? = "Hello"
y = "Goodbye"
```

値が存在しないことは、特別な値`nil`を代入することでオプショナル型の変数に代入できます。`nil`はすべてのオプショナル型で使えますが、2つの異なるオプショナル型に代入された`nil`は同じ型ではなく、入れ替えることも、比較することもできません。

```swift
let intOpt: Int? = nil
let stringOpt: String? = nil

intOpt = stringOpt
// Compiler error: Cannot assign value of type 'String?' to type 'Int?'

intOpt == stringOpt
// Compiler error: Binary operator '==' cannot be applied to operands of type 'Int?' and 'String?'
```

また、`nil`はどんなオプショナル型にも代入できますが、オプショナルでない型には代入できません（実際には`nil`を保持していない変数であっても同じです）。また、オプショナルでない型を期待するメソッドには、先にアンラップしない限り、オプショナル型を渡せません。

```swift
var x: Int = 42
var y: Int? = 42

y = x
// Works fine
x = y
// error: value of optional type 'Int?' must be unwrapped to a value of type 'Int'
x + y
// error: value of optional type 'Int?' must be unwrapped to a value of type 'Int'
```

## オプショナルの使い方

オプショナル型は元の型と同じ型ではないため、この2つの型は同じようには使えません。たとえば、`Int("123") + 1`はコンパイラエラー"Value of optional type 'Int?' must be unwrapped to a value of type 'Int'"が発生します。これは、`Int("123")`が`Int`型ではなく`Int?`型を返すためです。文字列を整数に変換できない場合、結果は`nil`になるからです。変換の結果から`Int`を取り出すには、まずそれを「アンラップ」する必要があります。

Swiftでは、これはほとんどの場合、[_オプショナルバインディング_][optional-binding]の`if-let`と`guard-let`を使って行います。これらは`nil`かどうかを確認し、値が存在すればアンラップされた値を指定した名前で束縛するコードパスをたどり、`nil`だった場合は別のコードパスをたどります。

```swift
if let safeNum = Int("123") {
	let sum = safeNum + 1
	…
} else {
  // code for the case where nil was found -- may be left out
}
```

`safeNum`変数の型が`Int?`ではなく`Int`である点に注意してください。下の例では、`num`は`Int?`型で、`safeNum`は`Int`型です。

```swift
let num = Int("123")
if let safeNum = num {
  // num is of type Int
}
```

この_オプショナルバインディング_が重要なのは、値からオプショナル型をアンラップ（つまり「取り除く」）し、オプショナルでない値として使えるようにするからです。値が`nil`かどうかを条件で確認するだけでは、値はオプショナル型のままです。

```swift
let num = Int("123")
if num != nil {
  // num is of type Int?
}
```

早期リターンが必要な場合には、`guard-let`も使えます。

```swift
guard let num = Int("123") else { return nil }
let sum = num + 1
…
```

## オプショナルの比較

2つのオプショナルの元の型が標準の比較演算子で比較できたとしても、オプショナル自体は比較できない点に注意してください。できるのは、等しいかどうかの確認だけです。2つのオプショナルは、どちらも`nil`であるか、ラップしている値がそれぞれの元の型で等しい場合に、等しいとみなされます。

ただし、2つのオプショナルの値を独自に比較するコードを書くこともできます。以下は、2つのオプショナルの値がどちらもnilでなく、1つ目の値が2つ目より小さい場合にだけ`true`を返す`switch`文の例です。そのために、_オプショナルパターン_`varName?`を使います。これはnilでないオプショナルにだけマッチし、オプショナルの中の値を`varName`という名前に束縛します。

```swift
switch (optionalA, optionalB) {
case let (valA?, valB?): return valA < valB
default: return false
}
```
