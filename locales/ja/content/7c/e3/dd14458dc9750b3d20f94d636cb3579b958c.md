# 概要

静的拡張を使うと、既存の型のソースコードを変更することなく、あたかもその型を拡張したかのように扱えます。これは、`using`文を使うことで実現できます。静的拡張は、型を実際に変更することなく機能を追加できる、強力な仕組みです。

```haxe
using Main.IntExtender;

class Main {
  public static function main() {
    trace(2.triple()); // 6
  }
}

class IntExtender {
  public static function triple(i:Int):Int {
    return i * 3;
  }
}
```
