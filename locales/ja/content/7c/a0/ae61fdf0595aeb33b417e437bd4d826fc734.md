# 概要

[シンボル][symbols]とは、値に名前を付けて参照するために使える識別子です。
シンボルはシンボルリテラルで作成します。シンボルリテラルとは、名前の前に`:`を付けたもので、たとえば`:foo`のように書きます。
クォートで囲んで書くこともでき、たとえば`:"foo"`のように書くと、名前にスペースを含められます。

```crystal
:foo           # => :foo
:"foo boo"     # => :"foo boo"
:foo == :"foo" # => true
```

シンボルは言語のさまざまな場所で使われており、namedtupleのキーとして使ったり、メソッド名や変数名を表したりします。

## Crystalのシンボル

Crystalのシンボルは、Rubyのものとはかなり異なります。
Crystalでは、シンボルは定数の一種であり、コンパイル時に割り当てられます。
つまり、Rubyでは可能な、シンボルを動的に作成することはできません。

Crystalのシンボルは`Int32`として表現されるため、非常に効率的です。

## 変換

シンボルは文字列に変換できますが、その逆はできません。
これは、シンボルはコンパイル時に作成され、文字列は実行時に作成されるためです。

```crystal
:foo.to_s # => "foo"
```
