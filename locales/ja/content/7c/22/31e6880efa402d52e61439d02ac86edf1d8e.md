# コンストラクタープロパティプロモーション

プロパティをたくさん宣言するクラスでは、クラス、そのプロパティ、そしてプロパティを設定するコンストラクターをそれぞれ別々に宣言すると、同じことを何度も書くことになります。コンストラクタープロパティプロモーションを使えば、この繰り返しを減らすことができます。

```php
<?php

class Book
{
    private string $isbn;
    private string $doi;
    private string $title;

    public function __construct(string $isbn, string, $doi, string $title)
    {
        $this->isbn = $isbn;
        $this->doi = $doi;
        $this->title = $title;
    }
}

// Using constructor property promotion
class Book
{
    public function __construct(
        private string $isbn,
        private string $doi,
        private string $title
    ) {
    }
}
