# 説明

課題は、完成したマインスイーパーのボードにある空のマスに、地雷の数を書き込むことです。ボード自体は長方形で、空のマス（`' '`）か地雷（`'*'`）のどちらかであるマスからできています。

それぞれの空のマスについて、そのマスに隣り合う地雷の数（上下左右と斜め）を数えます。隣り合う地雷が1つもない空のマスは、空のままにします。そうでなければ、隣り合う地雷の数に置き換えます。

たとえば、次のような5×4のボードが渡されることがあります（ここでは、空のマスを画面上に表示するために`'·'`という文字で表しています）。

```text
·*·*·
··*··
··*··
·····
```

これをコードで変換すると、次のようになります。

```text
1*3*1
13*31
·2*2·
·111·
```
