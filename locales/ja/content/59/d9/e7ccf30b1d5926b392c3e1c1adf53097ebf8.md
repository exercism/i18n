# 説明

この演習では、「Wizard and Warriors」という名前のロールプレイングゲームで遊びます。WizardかWarriorのどちらかとしてプレイできます。

WarriorとWizardでは、与えるダメージポイントを決めるルールが異なります。

Warriorのルールは次のとおりです。

- 攻撃対象のキャラクターが脆弱でない場合は、6ポイントのダメージを与えます
- 攻撃対象のキャラクターが脆弱な場合は、10ポイントのダメージを与えます

Wizardのルールは次のとおりです。

- Wizardが事前に呪文を準備している場合は、12ポイントのダメージを与えます
- Wizardが事前に呪文を準備していない場合は、3ポイントのダメージを与えます

通常、キャラクターが脆弱になることはありません。ただし、Wizardは呪文を準備していない場合、脆弱になります。

WarriorとWizardのキャラクターを扱う6つのタスクがあります。

## 1. キャラクターを説明する

`Character`クラスの`ToString()`メソッドをオーバーライドして、キャラクターの説明を`"Character is a <CHARACTER_TYPE>"`という形式で返すようにします。

```csharp
var warrior = new Warrior();
warrior.ToString();
// => "Character is a Warrior"
```

## 2. キャラクターがデフォルトで脆弱にならないようにする

`Character.Vulnerable()`メソッドが常に`false`を返すようにします。

```csharp
var warrior = new Warrior();
warrior.Vulnerable();
// => false
```

## 3. Wizardが呪文を準備できるようにする

`Wizard.PrepareSpell()`メソッドを実装して、Wizardが事前に呪文を準備できるようにします。

```csharp
var wizard = new Wizard();
wizard.PrepareSpell();
```

## 4. 呪文を準備していないWizardを脆弱にする

Wizardが呪文を準備していない場合は、`Vulnerable()`メソッドが`true`を返すようにします。それ以外の場合は`false`を返します。

```csharp
var wizard = new Wizard();
wizard.Vulnerable();
// => true
```

## 5. Wizardのダメージポイントを計算する

`Wizard.DamagePoints()`メソッドを実装して、与えるダメージポイントを返すようにします。呪文を準備している場合は12ダメージポイント、準備していない場合は3ダメージポイントです。

```csharp
var wizard = new Wizard();
var warrior = new Warrior();

wizard.PrepareSpell();
wizard.DamagePoints(warrior);
// => 12
```

## 6. Warriorのダメージポイントを計算する

`Warrior.DamagePoints()`メソッドを実装して、与えるダメージポイントを返すようにします。対象が脆弱な場合は10ダメージポイント、脆弱でない場合は6ダメージポイントです。

```csharp
var warrior = new Warrior();
var wizard = new Wizard();

warrior.DamagePoints(wizard);
// => 10
```
