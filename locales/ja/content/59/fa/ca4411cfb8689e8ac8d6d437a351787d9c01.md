# ループ

```sather
   loop
      ...
   end;
```

Satherには、ループ文が1つだけあります。`while`も`for`もありません。どちらも、`loop`と、それを終わらせるものとを組み合わせて作ります。

## 変数

```sather
   total ::= 0;          -- declare, with a starting value
   total := total + 5;   -- assign
```

`::=`は変数を宣言し、与えられた値から型を決めます。値を入れる前に変数が存在している必要があるときは、代わりに型を付けて宣言します。

```sather
   total : INT;
   total := 0;
```

値を付けずに宣言した変数は、`INT`ならゼロ、`BOOL`なら`false`、文字列やオブジェクトならvoidから始まります。

## ループを終わらせる

| 書き方 | ループが終わるのは |
| --- | --- |
| `until!(q)` | `q`がtrueのとき |
| `while!(q)` | `q`がfalseのとき |
| `break!` | すぐに |

この3つはどれも、ループ本体のどこにでも書けます。1つのループで複数使うこともできます。

```sather
   loop
      until!(n > last);      -- may run no times at all
      ...
   end;

   loop
      ...
      until!(done);          -- always runs at least once
   end;
```

## 感嘆符

`until!`、`while!`、`break!`が`!`で終わるのは、これらが**イテレーター**だからです。イテレーターとは、ループの中にしか書けず、ループを終わらせることができるもののことです。ループの外に書くと、警告ではなくエラーになります。この後の演習では、ライブラリにある他のイテレーターを使い、最終的には新しいイテレーターを自分で書きます。

## 永遠に続くループ

終わらせるものがないループは、永遠に回り続けます。そうしたいこともたまにはありますが、たいていの場合は、条件で尋ねている値が一度も変わっていないということです。プログラムが止まってしまったら、まず確認すべきことは、ループの中の何かがループを終わりに向かって進めているかどうかです。
