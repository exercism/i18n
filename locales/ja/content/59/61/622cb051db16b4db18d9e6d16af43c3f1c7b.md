# 概要

以前のコンセプトで、Juliaの型は階層をなし、最上位に`Any`があることを見ました。

`Number`などの抽象型にはサブタイプがありますが、それ自体をインスタンス化することはできません。
変数に抽象型を設定すると、その変数の値は抽象型の任意のサブタイプに_制約_されます。
例えば：

```julia-repl
julia> x::Number = 3
3

julia> typeof(x)  # one subtype of Number
Int64

julia> x = 4.2
4.2

julia> typeof(x) # another subtype of Number
Float64

julia> x = "fail" # not a number type!
ERROR: MethodError: Cannot `convert` an object of type String to an object of type Number
```

これは、どの入力が有効かを制約する柔軟性の一つの形です。

しかし、変数に整数と文字列の両方の値を受け入れさせたいとします。
これらの型は階層の同じブランチにはありません。

型を[`Any`][any]に設定するか、デフォルトでそのままにすることもできますが、そうすると許可される型をまったく制御できなくなります。

より良い方法として、[`Union{ }`][union]構文があり、波括弧の中に2つ以上の型をリストします。

```julia-repl
julia> y::Union{Integer, String} = 4
4

julia> typeof(y)
Int64

julia> y = "works"
"works"

julia> typeof(y)
String

julia> y = 5.3
ERROR: MethodError: Cannot `convert` an object of type 
  Float64 to an object of type 
  Union{Integer, String}
```

別の例では、同じ型共用体を関数シグネチャで使用します：

```julia-repl
julia> IntOrString = Union{Integer, String}
Union{Integer, String}

julia> f(z::IntOrString) = z^3
f (generic function with 1 method)

julia> f(2) # integers are cubed
8

julia> f("ab") # strings are repeated 3 times
"ababab"
```

ここでは、型に名前を付けました。これは便利な省略記法を提供しますが、厳密には必要ありません。
関数`g(z::Union{Integer, String}) = z^3`も同じように動作します。

関数シグネチャについては、多重ディスパッチのコンセプトでさらに詳しく説明します。

## nothingとの共用体

他のいくつかの言語には、値を含む場合と含まない場合がある型があり、`Option`、`Nullable`、`Maybe`などの名前が付けられています。

Juliaにはこのための特定の構文はありませんが、型共用体は同じアイデアの一般化です。

[`Nothingness`][nothingness]コンセプトで、Juliaには非値を表すさまざまな方法があり、[`nothing`][nothing]や[`missing`][missing]などがあることを見ました。
これらのいずれも型共用体に含めることができます。

例えば、ある種の[連結リスト][linked]を定義する場合、それ以上ノードがないときにリストを終了させる方法が必要です。
`Nothing`はシングルトン値`nothing`を持つ型であり、このNode定義によりチェーンの終わりを知らせることが可能になります：

```julia-repl
julia> struct Node
           value::Any
           next::Union{Node, Nothing}
       end
```

同様に、`missing`は欠損値のプレースホルダーとして使用できます。特にベクトルなどのコレクションでよく使われます。
以下の例は非常に不自然ですが、欠損値は実際のデータセットではよくあります。

```julia-repl
julia> q(x::Real) = x >= 0 ? sqrt(x) : missing  # skip negative values
q (generic function with 1 method)

julia> vals::Vector{Union{Real, Missing}} = q.([4, 3.1, -1, 0])
4-element Vector{Union{Missing, Float64}}:
 2.0
 1.760681686165901
  missing
 0.0
```
