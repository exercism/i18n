# ヒント

## 全般

- 構造体のインスタンスは、構造体の名前を書いたあとに、波括弧（`{}`）で囲んだフィールドの値を続けて作成します。
- `@T`を使うと、ある型`T`のスナップショットを宣言できます。たとえば、`let i: @u32 = @1;`は、`u32`の値`1`のスナップショットである変数`i`を宣言します。
- スナップショットから値を取り出すには、`*`（デスナップ）演算子を使います。たとえば、`let int = *an_int_snapshot;`のように書きます。
- `mut`キーワードを使うと、値を可変として宣言できます。たとえば、`let mut i = 1;`のように書きます。

## 1. 投票カウンターを作成する

- `VoteCounter`構造体へのポインター、つまり`@VoteCounter`を作成する必要があります。
- 構造体のインスタンスを作成するときは、`value`の入力をそのまま代入できます。

## 2. カウンターから票数を取得する

- スナップショットに`*`演算子を使うと、デスナップしてその値を取り出せます。たとえば、`*my_snapshot`のように書きます。

## 3. カウンターの票を増やす

- `@VoteCounter`のスナップショットを変更するのではなく、票を増やした新しい`VoteCounter`のインスタンスを返す必要があります。
- `*`演算子を使って元になっている投票カウンターの値をデスナップするか、前のタスクで作成した関数を呼び出します。

## 4. 選挙結果を作成する

- `name`と`vote_counter`のフィールドに、関数の引数の値が入った新しい`ElectionResult`構造体または変数を作成します。
- 変数名や構造体の宣言の前に`@`演算子を付けると、`VoteCounter`のスナップショットを作成できます。または、前のタスクのいずれかで作成した`new_vote_counter`関数を呼び出します。

## 5. 結果を発表する

- `ElectionResult`へのスナップショットを受け取っていても、スナップショットではないかのように、ドット`.`記法でそのフィールドにアクセスできます！
- 構造体の`name`フィールドと`vote_counter`フィールドにアクセスして、メッセージを組み立てます。
- 入れ子になったスナップショットをデスナップするときは、デスナップする必要があるスナップショットの数だけ`*`演算子を適用します。

```rust
let result = @ElectionResult {
    name: "John",
    vote_counter: @VoteCounter { value: 32 },
};

println!("{}", **result.vote_counter.value); 
// => 32
```

## 6. 票の再集計

- [辞書の実装方法][dictionaries underneath]のために、辞書は変更するにも読み取るにも可変であることが必要です。つまり、関数の中で辞書に加えた変更は、関数の外でも見えるということです。
- `let mut m: Felt252Dict<u32>`のあるキーの値を増やすには、`get`と`insert`の関数を組み合わせます。たとえば、`m.insert('mykey', m.get('mykey') + 1);`のように書きます。

[dictionaries underneath]: https://book.cairo-lang.org/ch03-02-dictionaries.html#dictionaries-underneath
