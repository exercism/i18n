# はじめに

[`switch`文][switch]は、1つの値を複数の一致候補パターンと比較します。複数の`if-else`文を連ねるよりも、すっきりと読みやすいコードを書けます。

`switch`文は、`switch`キーワードの後に判定したい値を続けて書きます。それぞれの一致候補は、`case`キーワードで書き始めます。どの明示的なケースにも一致しなかったときに実行される予備のケースは、`default`キーワードで定義します。`if-else`の連鎖と同じく、`switch`文は、最初に一致したケースに対応するコードのブロックだけを実行します。

```swift
switch value {
case 1:
    print("One")
case 2:
    print("Two")
default:
    print("Other")
}
```

次の`if-else`の連鎖を見てみましょう。

```swift
if str == "apple" {
    print("Let's bake an apple crumble")
} else if str == "lemon" {
    print("Let's bake a lemon meringue pie!")
} else if str == "peach" {
    print("Let's bake a peach pie!")
} else {
    print("Let's buy ice cream.")
}
```

これは、`switch`文を使うとより明確に書けます。

```swift
switch str {
case "apple":
    print("Let's bake an apple crumble")
case "lemon":
    print("Let's bake a lemon meringue pie!")
case "peach":
    print("Let's bake a peach pie!")
default:
    print("Let's buy ice cream.")
}
```

[switch]: https://docs.swift.org/swift-book/documentation/the-swift-programming-language/controlflow/#Switch
