# ゲッターとセッター

ゲッターとセッターは、オブジェクトのプロパティの値を読み書きするためのメソッドです。
Crystalにはマクロがあるので、プロパティのゲッターとセッターを簡単に定義できます。
マクロはコンパイル時にコードを生成する仕組みで、これについては後のマクロの概念で扱います。

Rubyでは、これらのメソッドは`attr_reader`、`attr_writer`、`attr_accessor`というメソッドを使って定義され、表面的にはCrystalの実装とよく似ています。
Crystalでは、これらは`getter`、`setter`、`property`というマクロとして定義しています。

## ゲッター

ゲッターは、インスタンス変数の値を返すメソッドを定義するマクロです。
つまり、インスタンス変数にアクセスしたいときに（`initialize`を除くメソッド内で）その前に`@`を書く必要がなくなり、代わりにゲッターのマクロが定義したメソッドを呼び出せます。

ゲッターのマクロには、カンマで区切って複数のインスタンス変数を渡せます。

```crystal
# This:
class Person
  @name : String
  @age : Int32

  def name
    @name
  end

  def age
    @age
  end
end

# Is the same as this:
class Person
  @name : String
  @age : Int32

  getter name, :age
end
```

見てのとおり、ゲッターを使うと書くコードの量が減り、読みやすくなります。
また、RubyとCrystalは、Crystalがゲッターのマクロの引数として変数名とシンボルの両方を受け付けるという点で異なります。
シンボルについては、後のシンボルの概念で扱います。

## セッター

セッターは、インスタンス変数の値を設定するメソッドを定義するマクロです。
このマクロはあまり使われず、代わりに`property`マクロがよく使われます。
作成されるメソッドは`name_of_method=`のようになります。この`=`があることで、プロパティを設定できるようになります。

このメソッド定義は少し特殊で、メソッドが受け取る引数が`=`記号の後に来ます。
Crystalの他のいくつかの特殊なメソッドも、`+`メソッドのようにこの構文を使います。

ゲッターのマクロと同様に、セッターを定義した後にインスタンス変数の値を更新したいときは、セッターのマクロが定義したメソッドを呼び出せます。

```crystal
# This:
class Person
  @name : String
  @age : Int32

  def name=(name : String)
    @name = name
  end

  def age=(age : Int32)
    @age = age
  end
end

# Is the same as this:
class Person
  @name : String
  @age : Int32

  setter name, :age
end
```

## プロパティ

プロパティは、インスタンス変数のゲッターとセッターの両方を定義するマクロです。

```crystal
class Person
  @name : String
  @age : Int32

  property name, :age
end
```
