# デバッグ

テストが失敗すると、何がうまくいかなかったのか、どの入力に対するものなのかを説明するメッセージが表示されます。「標準出力」に出力された内容も同じように表示されるので、これを利用することもできます。標準出力へは`println!`を使って書き込めます。

```rust
println!("Debug message");
```

変数や式の値を出力するには、波括弧`{}`を使います。

```rust
let secret_number = 4321;
println!("My banking password is {}, which is better than {}.", secret_number, 1200 + 34);
```

この方法で出力できるのはすべての型ではなく、ユーザーに曖昧さなく提示できる型だけです。たとえば、ベクタ（配列）はこのようには出力できません。ベクタをどのようにユーザーに表示すべきかがはっきりしないからです！　こうした他の型では、`println!`マクロに`{:?}`を指定して_デバッグフォーマット_を使うよう伝えられます。この表現はエンジニアだけが見ることを想定しています。例を見てみましょう。

```rust
let words = vec!["hello", "world"];
println!("words that are often combined: {:?}", words);
```

さらに便利な`dbg!`マクロもあります。大きな式を分解して別々の変数宣言にすることなく、その場でデバッグできます。

次のような式があるとします。

```rust
"hello world".split(' ').collect::<Vec<_>>().join("-")
```

ここで、`collect`の呼び出しが何を返すか見てみたいとします。次のように書くこともできます。

```rust
let my_temporary_debug_variable = "hello world".split(' ').collect::<Vec<_>>();
println!("{:?}", my_temporary_debug_variable);
my_temporary_debug_variable.join("-")
```

でも、これは面倒です！　デバッグするためだけに、せっかく書いた式をわざわざ書き直したくはありませんよね。そこで登場するのが`dbg!`です。

```rust
dbg!(
    "hello world".split(' ').collect::<Vec<_>>()
).join("-")
```

空白は見やすくするためだけのものです。`dbg!()`で任意の式を囲むと、その値が（デバッグフォーマットで）出力されます。その後も、`dbg!`が最初からなかったかのように、その値をより大きな式の中で使い続けられます。

デバッグを楽しんでください！
