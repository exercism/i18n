# はじめに

Kotlinの`when`は、いくつかの選択肢から1つを選ぶための条件式です。Javaの`switch`に似ていますが、`if` ... `else if` ... `else`を連ねるよりも柔軟です。

`if`と同じように、`when`も値を生み出す式として使えます。

## 値とマッチさせる

`when`には、マッチさせたい値を括弧（`()`）の中に渡します。各分岐はその値を順に照合し、一致するものが見つかるまで評価されます。

```kotlin
val animal = "chicken"
val type = when (animal) {
    "chicken" -> "bird"
    "poodle" -> "dog"
    else -> "unknown"
}
// type => "bird"
```

- 各分岐は`pattern -> result`の形で書きます。
- 分岐は上から下へ順に試され、一致した時点で止まります。実行されるのは、最初に一致した分岐だけです。
- 上に挙げたどの値にも当てはまらない場合は、`else`を使います（`if`を連ねたときの最後の`else`と同じです）。

これは[パターンマッチング][pattern-matching]に似ています。`pattern`の部分には、マッチさせたい値を書くことも、`is`を使って型でマッチさせることもできます。

```kotlin
fun typeText(subject: Any): String {
    return when(subject) {
        is Animal -> "Animal"
        is Fruit -> "Fruit"
        is String -> "Text"
        else -> "Unknown"
    }
}
```

あるいは`in`を使って、範囲、コレクション、文字列など、`contains`メソッドを持つものに含まれているかどうかを調べることもできます。

```kotlin
fun describe(number: Int, position: String) {
    // Range
    when(number) {
        in 1..10 -> println("From 1 to 10")
        in 11..20 -> println("From 11 to 20")
    }

    // Collection
    when(number) {
        in listOf(2, 4, 6) -> println("small even")
        in listOf(3, 5, 7) -> println("small odd")
    }

    // String
    when(position) {
        in "center middle" -> println("inner")
        in "left right boundary" -> println("outer")
    }
}
```

## ガード条件

値とマッチさせる場合は、パターンの後ろに`if`を置いて、追加の条件を指定できます。この条件をガード条件と呼びます。

```kotlin
val x = 5
val y = 10
val description = when (x) {
    5 if y % 2 == 0 -> "x is 5, y is even"
    else -> "other"
}
// description => "x is 5, y is even"
```

`else if`を使うこともできます。

```kotlin
val x = 7
val y = 10
val description = when (x) {
    5 if y % 2 == 0 -> "x is 5, y is even"
    else if y % 2 == 0 -> "y is an even number"
    else -> "other"
}
// description => "y is an even number"
```


## 条件とマッチさせる

別の方法として、値を省略し、各分岐に真偽値の条件を書くこともできます。

```kotlin
val x = 5
val y = 8
val description = when {
    x % 2 != 0 -> "x is odd"
    y % 2 == 0 -> "y is even"
    else -> "neither condition matched first"
}
// description => "x is odd"
```

ここでも分岐は上から下へ順に調べられ、条件が`true`になる最初の分岐だけが実行されます。

## `when`を式として使う

`when`をその結果のために使う場合（変数に代入する、関数から返すなど）は、考えられるすべてのケースを網羅する必要があります。

- 値とマッチさせる場合は、考えられるすべての値をすでに扱っていない限り（たとえば`Boolean`や`enum`のすべての値）、`else`を追加します。
- 条件とマッチさせる場合は、`else`の分岐が必須です。条件がすべてのケースを網羅していることを、コンパイラは知ることができないからです。

```kotlin
fun label(n: Int): String = when (n) {
    0 -> "zero"
    1 -> "one"
    else -> "other"
}
```
