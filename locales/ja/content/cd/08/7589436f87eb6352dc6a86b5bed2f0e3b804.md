# 説明

人は皆、生物学的な親から、DNAとして知られる化学的な指示のまとまりを受け継いでいます。それは、体がどのようにつくられるかに影響を与えます。知られているすべての生命はDNAに依存しています！

> 補足：この演習を完了するために、ヌクレオチドやDNAについて何かを理解している必要はありません。

DNAは、他の化学物質が長くつながった鎖です。その中で最も重要なのが、アデニン、シトシン、グアニン、チミンという4つのヌクレオチドです。1本のDNA鎖には、これら4つのヌクレオチドが何十億個も含まれることがあり、それらが並ぶ順序が重要です！
DNAのある部分におけるこれらのヌクレオチドの並び順を「DNA配列」と呼びます。

DNA配列は、これら4つのヌクレオチドを順番に並べたものとして表します。その一般的な方法は文字列を使うもので、たとえば6つのヌクレオチドからなるDNA配列なら"ATTACG"のようになります。
'A'はアデニン、'C'はシトシン、'G'はグアニン、'T'はチミンを表します。

DNA配列を表す文字列が与えられたら、それぞれのヌクレオチドがいくつ含まれているかを数えます。
文字列にA、C、G、T以外の文字が含まれている場合、その文字列は無効です。エラーを通知する必要があります。

たとえば、次のようになります。

```
"GATTACA" -> 'A': 3, 'C': 1, 'G': 1, 'T': 2
"INVALID" -> error
```
