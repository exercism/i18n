# はじめに

Gleamの正規表現は、Java、JavaScript、Rubyなどの他の一般的な言語と同様に、**PCRE**仕様（**P**erl **C**ompatible **R**egular **E**xpressions）に従っています。

`gleam/regex`モジュールには、正規表現を扱うための関数が用意されています。

~~~~exercism/note
この演習では、文字クラス、量指定子、グループ、キャプチャといった正規表現の構文をすでに知っていることを前提としています。

正規表現の知識を復習したい場合は、次のような情報源をチェックしてみてください：[Regular-Expressions.info](https://www.regular-expressions.info)、[Rex Egg](https://www.rexegg.com/)、[RegexOne](https://regexone.com/)、[Regular Expressions 101](https://regex101.com/)、[RegExr](https://regexr.com/)。
~~~~

正規表現を作成する最も一般的な方法は、`regex.from_string`関数を使うことです。

```gleam
let assert Ok(re) = regex.from_string("test")
```

`regex.from_string`関数は、正規表現の構文が無効な場合に`Error`を返すため、ここでは正規表現が有効であることを保証するためにletアサーションを使っています。

`regex.check`関数を使うと、正規表現が文字列に一致するかどうかを確認できます。

```gleam
let assert Ok(re) = regex.from_string("test")

regex.check(re, "this is a test")
// -> True

regex.check(re, "this is too")
// -> False
```


## キャプチャ

正規表現を使って部分文字列をキャプチャしたい場合は、`regex.scan`関数を使って一致の配列を取得できます。

```gleam
let assert Ok(re) = regex.from_string("[oi]n a (\\w+)")
regex.scan(with: re, content: "I am on a boat in a lake.")
// -> [
//   Match(
//     content: "on a boat",
//     submatches: [Some("boat")]
//   ),
//   Match(
//     content: "in a lake",
//     submatches: [Some("lake")]
//   )
// ]
```

## 修飾子

正規表現の動作は、`regex.compile`関数で作成するときにオプションを渡すことで変更できます。

```gleam
let options = regex.Options(case_insensitive: True, multi_line: False)
let assert Ok(re) = regex.compile("[A-Z]", with: options)
regex.check(re, "abc123")
// -> True
```
