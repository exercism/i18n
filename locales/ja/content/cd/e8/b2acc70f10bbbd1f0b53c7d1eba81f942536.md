# 手順

この演習では、1980年代の古典的なアーケードゲームである[Pac-Man][Pac-Man]のルールをいくつか実装します。

タスクは全部で6つあり、そのうち4つはゲームの状態に関するルールです。

> _関数の中で引数がどのように導き出されるかは気にせず、引数を組み合わせて意図した結果を返すことだけに集中しましょう。_


## 0. パワー状態を定義する

`PowerOn`という名前の変数を定義し、パワーが確かにオンであることを表す値を設定します。

```powershell
> $PowerOn
True
```

## 1. Pac-Manがゴーストを食べられるかどうかを定義する

`EatGhost`関数を定義します。この関数は2つのパラメータ（_パワーエサが有効になっているか_、_Pac-Manがゴーストに触れているか_）を受け取り、Pac-Manがゴーストを食べられるかどうかを表す真偽値を返します。
この関数は、パワーエサが有効になっていて、かつゴーストに触れているときだけ`True`を返します。

```powershell
> EatGhost -ActivePower $false -TouchingGhost $true
False
```

## 2. Pac-Manが得点するかどうかを定義する

`Score`関数を定義します。この関数は2つのパラメータ（_Pac-Manがパワーエサに触れているか_、_Pac-Manがドットに触れているか_）を受け取り、Pac-Manが得点したかどうかを表す真偽値を返します。
この関数は、Pac-Manがパワーエサかドットに触れているときに`True`を返します。

```powershell
> Score -TouchDot $true -TouchPowerPellet $true
4
```

## 3. Pac-Manが負けるかどうかを定義する

`Lose`関数を定義します。この関数は2つのパラメータ（_パワーエサが有効になっているか_、_Pac-Manがゴーストに触れているか_）を受け取り、Pac-Manが負けるかどうかを表す真偽値を返します。
この関数は、Pac-Manがゴーストに触れていて、かつパワーエサが有効になっていないときに`True`を返します。

```powershell
> Lose -ActivePower $false -TouchingGhost $true
True
```

## 4. Pac-Manが勝つかどうかを定義する

`Win`関数を定義します。この関数は3つのパラメータ（_Pac-Manがすべてのドットを食べたか_、_パワーエサが有効になっているか_、_Pac-Manがゴーストに触れているか_）を受け取り、Pac-Manが勝つかどうかを表す真偽値を返します。
この関数は、Pac-Manがすべてのドットを食べていて、かつタスク3で定義したパラメータに基づいて負けていないときに`True`を返します。

```powershell
> Win -EatenAllDots $false -ActivePower $true -TouchingGhost $false
False
```

## 5. 勝利条件のSynopsisを書く

最後の関数に戻り、コメントブロックに`Synopsis`セクションを追加して、ゲームに勝つ方法を短く説明します。
説明は少なくとも10文字以上にしてください。

```powershell
function MyFunc($Arg) {
    <#
    .DESCRIPTION
    This is a demonstration of the comment-based help with the description keyword.
    #>
}
```
