# ヒント

## 1. 正規表現を使って、カードの生成に必要な情報をキャプチャする

- `\p{L}`は、あらゆる言語のあらゆる種類の文字にマッチします。
- 次の正規表現を使うと、必要な情報をキャプチャできます：
  ```julia
  re = r"""»(.*)«                     # title
           \ –\ (.*?)                 # name
           (?:\ \((.*?)\)|)           # optional pronouns
           (?:,\ from\ (.*?)|).       # optional organisation
           \ Start:\ (.*?),\          # start time
           (?:Q&A:\ (.*?),\ |)        # optional Q&A time
           End:\ (.*)                 # end time
        """x
  ```
