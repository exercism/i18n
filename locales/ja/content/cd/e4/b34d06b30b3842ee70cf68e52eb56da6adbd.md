# 説明の補足

## ヒント

`countWords`の戻り値には、キーが`string`で値が`int`の任意のハッシュテーブル型を使えます。

ハッシュテーブル（他のプログラミング言語では「辞書」や「マップ」とも呼ばれます）は、`tables`モジュールで実装されています。詳しくは[documentation]を参照してください。

たとえば、`countWords`は`TableRef[string, int]`を返すこともできます。

```nim
proc countWords*(sentence: string): TableRef[string, int] =
  ...
```

[documentation]: https://nim-lang.org/docs/tables.html
