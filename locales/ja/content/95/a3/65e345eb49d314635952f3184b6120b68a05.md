# はじめに

## 例外

C#の例外は、実行時に発生するエラー状態を扱うための、構造化された、統一的な、型安全な仕組みです。アプリケーションのクラッシュを防ぐうえでは、例外とエラーを適切に扱うことが重要になります。

C#では、すべての例外の基底型は`System.Exception`クラスです。このクラスには、例外がスローされた理由を人間が読める形で説明する`Message`など、重要なプロパティが含まれています。

コードの特定の箇所でエラーを発生させるには、新しい例外オブジェクトを作成し、`throw`キーワードを使ってスローする必要があります。

```csharp
using System;
static int Square(int number)
{
    if (number >= 46341)
    {
        throw new ArgumentException($"Argument {number} cannot be higher than 46340 as its' square doesn't fit into int type.");
    }
    return number * number;
}
```

例外がスローされると、ランタイムはその例外の処理を担当するコードを探します。適切なハンドラーが見つからない場合、ランタイムは未処理の例外メッセージを表示し、プログラムの実行を停止します。

例外のハンドラーを作成するには、C#ではtry-catch文を使います。これは`try`ブロックと1つ以上の`catch`節から構成されます。`try`ブロックには、例外のスローにつながる可能性のあるコードを入れて保護します。`catch`節には、エラーが発生したあとのプログラムの動作を処理するコードを入れます。`try`ブロックのあとでは例外の順序が重要です。複数の例外が並んでいるときは、最初に一致した`catch`節が実行されます。

```csharp
try
{
   if (number == 42)
   {
       throw new ArgumentException("The number cannot be equal to 42.", "number");
   }

   if (number < 0)
   {
      throw new ArgumentOutOfRangeException("number", "The number cannot be negative.");
   }

    // Process number ...
}
catch (ArgumentOutOfRangeException e)
{
    Console.WriteLine($"Number is out of range: {e.Message}.");
}
catch (ArgumentException)
{
    Console.WriteLine("Invalid number.");
}
```
