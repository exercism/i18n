# 概要

コレクションの定義には、通常、山括弧（`<>`）で囲んだプレースホルダーが含まれます。慣例として、`T`という名前がよく使われます。このようなコレクションをジェネリック型と呼びます。これにより、コレクションを使う側が、そのコレクションにどんな型の要素を格納するかを指定できます。上のコード例では、文字列の配列をインスタンス化しています。

クラスや関数を**ジェネリック**にするには、`@:generic`属性を使います。これにより、コンパイラーがそのクラスや関数をジェネリックとして識別します。

```haxe
@:generic
class MyValue<T> {
  public var value:T;

  public function new(value:T) {
    this.value = value;
  }
}

var a = MyValue<String>("Hello");
trace(a.value); // Hello
```
