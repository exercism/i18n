# はじめに

タプルは、ほかのタプルを継承できます。`TUPLE: child < parent slots ;`は、インスタンスが`parent`のインスタンスでもあるクラスを宣言します。そのインスタンスは、自分自身のスロットに加えて親のスロットも持ち、親のアクセサもそのまま使えます。ちょうど、子で定義されているかのようにです。

```factor
USING: accessors ;

TUPLE: animal name age ;
TUPLE: dog < animal breed ;

"Rex" 4 "labrador" dog boa .
! => T{ dog { name "Rex" } { age 4 } { breed "labrador" } }

"Rex" 4 "labrador" dog boa name>> .   ! => "Rex"   (inherited accessor)
```

## `boa`のスロットの順序

`boa`コンストラクターが受け取るスロットの順序は、*宣言順で、親が先*です。上の`dog`なら、次のようになります。

```
dog boa ( name age breed -- dog )
```

孫にあたる`puppy < dog `に`weeks`を加えると、次のようになります。

```
puppy boa ( name age breed weeks -- puppy )
```

## 述語の階層

`TUPLE:`を宣言するたびに、述語（`name?`）が生成されます。継承を使うと、述語は入れ子になります。すべての子孫は、祖先の述語を満たします。

```factor
"Rex" 4 "labrador" dog boa
dup dog? .        ! => t
dup animal? .     ! => t
```

逆は成り立ちません。`dog`でない`animal`は、`dog?`を満たしません。

## この先の補足

ジェネリックメソッド（`M:`。[`generics`][generics]で学びます）も、階層をさかのぼってディスパッチします。`animal`に対するメソッドは、より具体的なオーバーライドが優先されないかぎり、すべての子孫で呼び出されます。この動きは、この演習のすぐあとにある`boatswains-bilge`で目にすることになります。
