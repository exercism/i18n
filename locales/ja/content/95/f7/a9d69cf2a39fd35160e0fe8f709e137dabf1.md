# 説明

ランレングス符号化と復号を実装しましょう。

ランレングス符号化（RLE）はデータ圧縮のシンプルな方式で、ラン（連続するデータ要素）を1つのデータ値と個数だけに置き換えます。

たとえば、元の53文字をわずか13文字で表せます。

```text
"WWWWWWWWWWWWBWWWWWWWWWWWWBBBWWWWWWWWWWWWWWWWWWWWWWWWB"  ->  "12WB12W3B24WB"
```

RLEを使うと、圧縮されたデータから元のデータを完全に復元できるので、可逆的なデータ圧縮になります。

```text
"AABCCCDEEEE"  ->  "2AB3CD4E"  ->  "AABCCCDEEEE"
```

話を簡単にするため、符号化前の文字列にはAからZまでのアルファベット（大文字または小文字）と空白文字しか含まれないものとします。こうしておくと、符号化するデータに数字が含まれることはなく、復号するデータの中の数字は、必ず続く文字の個数を表します。
