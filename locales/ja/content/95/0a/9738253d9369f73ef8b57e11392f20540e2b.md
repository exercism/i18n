# はじめに

エラーはどうしても起こるものです。Elixirでは、よく「クラッシュさせておこう」と言われますが、ソフトウェアの契約を満たすために、関数呼び出しを安全な状態に救済しなければならないこともあります。言語によっては、エラーを制御フローの手段として使うこともありますが、Elixirではこのパターンは推奨されていません。エラーを発生させる可能性のある関数は、名前を見ただけで見分けられることがよくあります。エラーを発生させる関数には、名前の末尾に`!`を付けます。これは、`{:ok, value}`や`:error`を返す関数とは対照的です。次のライブラリの例を見てみましょう。

```elixir
Map.fetch(%{a: 1}, :b)
# => :error
Map.fetch!(%{a: 1}, :b)
# => raises KeyError
```
