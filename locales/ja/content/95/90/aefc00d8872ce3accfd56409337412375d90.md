# Mapについて

**Map**は、キーと値のペアを保存するためのデータ構造です。
他のプログラミング言語の辞書に似ています。
[Map][map-javadoc]インターフェースは、マップに対して行える操作を定義しています。

## HashMap

Javaには、さまざまな`Map`の実装があります。
[HashMap][hashmap-javadoc]は、よく使われる実装の1つです。

```java
// Make an instance
Map<String, Integer> fruitPrices = new HashMap<>();
```

~~~~exercism/note
`Map`型の変数を定義するときは、上の例のように、具体的な型ではなく`Map`型として定義することをおすすめします。
そうしておくと、あとから`Map`の実装を変更しやすくなります。
~~~~

`HashMap`にはコピーコンストラクターもあります。

```java
// Make a copy of a map
Map<String, Integer> copy = new HashMap<>(fruitPrices);
```

マップに要素を追加するには、[put][map-put-javadoc]を使います。

```java
fruitPrices.put("apple", 100);
fruitPrices.put("pear", 80);
// => { "apple" => 100, "pear" => 80 }
```

1つのキーに紐づけられる値は1つだけです。
同じキーで`put`を呼び出すと、そのキーの値が更新されます。

```java
fruitPrices.put("pear", 40);
// => { "apple" => 100, "pear" => 40 }
```

キーに対応する値を取得するには、[get][map-get-javadoc]を使います。

```java
fruitPrices.get("apple"); // => 100
```

マップに特定のキーが含まれているかどうかを調べるには、[containsKey][map-containskey-javadoc]を使います。

```java
fruitPrices.containsKey("apple");   // => true
fruitPrices.containsKey("orange");  // => false
```

要素を削除するには、[remove][map-remove-javadoc]を使います。

```java
fruitPrices.put("plum", 90);  // Add plum to map
fruitPrices.remove("plum");   // Removes plum from map
```

[size][map-size-javadoc]メソッドは、要素の数を返します。

```java
fruitPrices.size();  // Returns 2
```

[keySet][map-keyset-javadoc]メソッドや[values][map-values-javadoc]メソッドを使うと、`Map`のキーや値を、それぞれ`Set`やコレクションとして取得できます。

```java
fruitPrices.keySet();  // Returns "apple" and "pear" in a set
fruitPrices.values();  // Returns 100 and 80, in a Collection
```

## `HashMap`は`hashCode`と`equals`を使う

`HashMap`は、オブジェクトの[hashCode][object-hashcode-javadoc]メソッドと[equals][object-equals-javadoc]メソッドを使って、キーの値をどこに保存し、どう取り出すかを決めます。
そのため、値を保存してから取り出すまでの間に、これらの戻り値が変わらないことが重要です。変わってしまうと、`HashMap`が値を正しく見つけられなくなることがあります。

たとえば、マップのキーとして使う次のようなクラスがあるとします。

```java
public class Stock {
    private String name;

    public void setName(String name) {
        this.name = name;
    }

    @Override
    public int hashCode() {
        return Objects.hash(name);
    }

    @Override
    public boolean equals(Object obj) {
        if (obj == this) {
            return true;
        }
        if (Objects.equals(Stock.class, obj.getClass()) && obj instanceof Stock other) {
            return Objects.equals(name, other.name);
        }
        return false;
    }
}
```

`hashCode`と`equals`は、`name`フィールドに依存しています。このフィールドは`setName`で変更できます。
`hashCode`を変更すると、意外な結果になることがあります。

```java
Stock stock = new Stock();
stock.setName("Beanies");

Map<Stock, Integer> stockCount = new HashMap<>();
stockCount.put(stock, 80);

stockCount.get(stock); // Returns 80

Stock other = new Stock();
other.setName("Beanies");

stockCount.get(other); // Returns 80 because "other" and "stock" are equal

stock.setName("Choccies");
stockCount.get(stock); // Returns null because hashCode value has changed

stockCount.get(other);  // Also returns null because "other" and "stock" are not equal

stock.setName("Beanies");
stockCount.get(stock); // HashCode restored, so returns 80 again

stockCount.get(other); // Also returns 80 again because "other" and "stock" are back to equal
```

## `Map.of`と`Map.copyOf`

マップを作成するもう1つの一般的な方法は、[Map.of][map-of-javadoc]や[Map.ofEntries][map-ofentries-javadoc]を使うことです。

```java
// Using Map.of
Map<String, Integer> temperatures = Map.of("Mon", 30, "Tue", 28, "Wed", 32);

// or using Map.ofEntries
Map<String, Integer> temperatures2 = Map.ofEntries(
    Map.entry("Mon", 30),
    Map.entry("Tue", 28),
    Map.entry("Wed", 32)
);
```

`HashMap`と違い、これらはあらかじめマップに値を入れて作成し、作成後は読み取り専用になります。
[Map.copyOf][map-copyof-javadoc]は、マップの読み取り専用のコピーを作成します。

```java
Map<String, Integer> readOnlyFruitPrices = Map.copyOf(fruitPrices);
```

`put`、`remove`、`clear`などのメソッドを呼び出すと、`UnsupportedOperationException`が発生します。
