# `for`ループ

繰り返しはプログラミングの基本的な概念で、同じコードのブロックを何度も実行できるようにしてくれます。Swiftには2種類のループ、[`for-in`ループ][for-loops]と`while`ループがあります。この章では、`for-in`ループについて学びます。

`for`ループを使うと、値のシーケンスを順に繰り返し、それぞれの要素を順番に取り出して、自分で決めた名前の変数に束縛できます。Swiftでは、範囲、配列、文字列など、さまざまなシーケンスを繰り返し処理できます（ほかの型については後で扱います）。シーケンスのすべての要素を繰り返し終えると、ループは終了します。

`for`ループは、`for`キーワード、変数名、`in`キーワード、繰り返しの対象となる値のシーケンスの順に書いて宣言します。`for-in`ループで与えられた変数は不変で、つまりループの中でその値を変更することはできません。次は、数値の配列を繰り返し処理する`for-in`ループの例です。

```swift
let numbers = [3, 10, 7, 11]

for number in numbers {
  print(number)
}
print("Done with numbers")

// prints:
// 3
// 10
// 7
// 11
// Done with numbers
```

~~~~exercism/note
`number`変数は`for-in`ループの中で宣言され、ループのスコープの中でだけ利用できます。

```swift
let numbers = [3, 10, 7, 11]

for number in numbers {
    number + 1
}
number + 1
// Error: Use of unresolved identifier 'number'
```
~~~~

## 範囲の繰り返し

`for-in`ループを使えば、数値の範囲を繰り返し処理することもできます。これにより、コードのブロックを決まった回数だけ実行できます。たとえば、範囲`1...5`は1、2、3、4、5と繰り返すので、ループは5回実行されます。配列のようなデータ構造でインデックスを繰り返し処理したいときは、`0..<array.count`という範囲を使えます。

```swift
let numbers = [3, 10, 7, 11]

for i in 0..<numbers.count {
  print(numbers[i])
}

// prints:
// 3
// 10
// 7
// 11
```

## 文字列の繰り返し

`for-in`ループを使って文字列を繰り返し処理することもできます。これにより、文字列の中の1文字ずつを繰り返し処理できます。ここで注目してほしいのは、ループで与えられる型が`Character`であることです。

```swift
let message = "Hello!"

for character in message {
  print(character)
}

// prints:
// H
// e
// l
// l
// o
// !
```

## 使わない変数

ループの中で変数の値が必要ないときは、アンダースコア`_`を使って無視できます。

```swift
let numbers = [3, 10, 7, 11]

for _ in numbers {
  print("Hello!")
}
```

## stride

Swiftには`stride`関数も用意されていて、範囲を指定した間隔で進むシーケンスを作れます。これを`for-in`ループで繰り返し処理できます。`stride`には[`stride(from:to:by:)`][stride-to]と[`stride(from:through:by:)`][stride-through]があり、最初のものは終点を含まず、2つ目のものは終点を含みます。

```swift
for i in stride(from: 0, to: 10, by: 2) {
  print(i)
}

// prints:
// 0
// 2
// 4
// 6
// 8
```

`to`は終点を含まないので、ループは`to`に指定した数値の1つ前まで繰り返します。一方、`through`は終点を含むので、この場合は`10`も含まれます。

[stride-to]: https://developer.apple.com/documentation/swift/stride(from:to:by:)
[stride-through]: https://developer.apple.com/documentation/swift/stride(from:through:by:)
[for-loops]: https://docs.swift.org/swift-book/documentation/the-swift-programming-language/controlflow/#For-In-Loops
