# はじめに

Elixirでは、コードの_ビヘイビア_を使って共通の汎用インターフェースを提供しながら、それを実装するモジュールごとに固有の実装を行えるようにしています。そのような一般的な例の1つが、_Accessビヘイビア_です。

_Accessビヘイビア_は、キーを基にしたデータ構造からデータを取り出すための共通のインターフェースを提供します。_Accessビヘイビア_はマップとキーワードリストに対して実装されていますが、ここでは雰囲気をつかむために、マップでの使い方を見てみましょう。_Accessビヘイビア_では、マップのあとに_角括弧_を続けてキーを指定すると、そのキーに対応する値を取り出せる、というルールが定められています。

```elixir
# Suppose we have these two maps defined (note the difference in the key type)
my_map = %{key: "my value"}
your_map = %{"key" => "your value"}

# Obtain the value using the Access Behaviour
my_map[:key] == "my value"
your_map[:key] == nil
your_map["key"] == "your value"
```

キーがデータ構造の中に存在しない場合は、`nil`が返されます。エラーが発生しないため、これは意図しない挙動の原因になることがあります。なお、`nil`自体もAccessビヘイビアを実装しており、どんなキーに対しても常に`nil`を返します。
