# 説明

ルシアンの恋人がもうすぐ家に帰ってきます。それなのに、ルシアンは二人の記念日のディナーをまだ作っていません！

この演習では、ルシアンがお気に入りの料理本の絶品ラザニアを作るのを手伝うコードを書きます。

ラザニア作りにかかる時間に関する4つのタスクがあります。

## 1. オーブンでの想定加熱時間を分単位で定義しましょう

`EXPECTED_MINUTES_IN_OVEN`という定数を定義します。この定数は、ラザニアをオーブンに入れておくべき分数を表します。定数はエクスポートする必要があります。料理本によると、オーブンでの想定加熱時間は`40`分です。

## 2. オーブンでの残り加熱時間を分単位で計算しましょう

`remainingMinutesInOven`関数を実装します。この関数は、ラザニアがオーブンに入っていた実際の分数を_仮引数_として受け取り、前のタスクの**オーブンでの想定加熱時間（分）**をもとに、ラザニアをあと何分オーブンに入れておく必要があるかを_戻り値_として返します。

```javascript
remainingMinutesInOven(30)
// => 10
```

## 3. 下準備にかかる時間を分単位で計算しましょう

`preparationTimeInMinutes`関数を実装します。この関数は、ラザニアに重ねた層の数を_仮引数_として受け取り、ラザニアの下準備にかかった分数を_戻り値_として返します。ここでは、層を1つ重ねるのに2分かかるとします。

```javascript
preparationTimeInMinutes(2)
// => 4
```

## 4. 合計の作業時間を分単位で計算しましょう

`totalTimeInMinutes`関数を実装します。この関数は_2つの仮引数_を取ります。`numberOfLayers`はラザニアに重ねた層の数、`actualMinutesInOven`はラザニアがオーブンに入っていた分数です。この関数は、ラザニア作りに合計で何分かけたかを_戻り値_として返します。これは、下準備にかかった分数と、その時点でラザニアがオーブンに入っていた分数の合計です。

```javascript
totalTimeInMinutes(3, 20)
// => 26
```
