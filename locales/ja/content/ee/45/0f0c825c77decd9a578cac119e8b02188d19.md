# はじめに

[`Vectors`][vectors]のコンセプトでは、「配列はJulia言語の中心にある」と述べました。そして、ベクトルは1次元の配列です。

そうであれば、それが何を意味するにせよ、ベクトルで_何かをする_ための多様で強力な方法を言語が数多く用意してくれていると期待するのは自然なことです。

## ベクトルを入力にとる関数

ごく単純な関数の中には、ベクトルを入力にとり、スカラーを返すものがあります。

```julia
v = [2, 3, 4]
length(v)  # => 3
sum(v)  # => 9
```

## 算術演算

数値のベクトルがあって、それぞれの値から0.5を引きたいとします。

```julia-repl
julia> v = [1.2, 1.5, 1.7]
3-element Vector{Float64}:
 1.2
 1.5
 1.7

julia> v - 0.5
ERROR: MethodError: no method matching -(::Vector{Float64}, ::Float64)
```

これは失敗します。では、別のベクトルを引いたらどうでしょうか？

```julia-repl
julia> v - [0.5, 0.5, 0.5]
3-element Vector{Float64}:
 0.7
 1.0
 1.2
```

成功しますが、ベクトルが長くなるほど、かなり面倒でメモリも食います。

幸いなことに、Juliaにはこの問題をとても簡単に解決する「魔法の」ドットがあります。`v .- 0.5`と書くだけで済みます。

その理由は次のセクションで説明します。

## ブロードキャスト

`v - 0.5`は失敗するのに、`v .- 0.5`は成功します。ここで、このドットが何をしているのかを理解する必要があります。

ドットは2つのことをしていて、その組み合わせが望みどおりの結果を生みます。

### 1. 要素ごとの適用

まず、中置演算子の_前に_ドットを付けると、「この演算をそれぞれの要素に個別に適用する」という意味になります。

同様に、関数名の_後ろ_にドットを付けると、その関数を「ベクトル化」できます。スカラー入力用に書かれた関数でも可能です。

```julia-repl
julia> sqrt.([1, 4, 9])
3-element Vector{Float64}:
 1.0
 2.0
 3.0
```

### 2. シングルトンの拡張

前の例で、同じ長さのベクトルどうしなら引けることを見ました。ただし、`.-`は要素ごとに演算する意図を明確にする、`-`よりも_安全な_演算子であることを理解しておいてください。

```julia-repl
julia> v .- [0.5, 0.5, 0.5]
3-element Vector{Float64}:
 0.7
 1.0
 1.2
```

長さが違うベクトルではどうでしょうか？

```julia-repl
julia> v .- [0.5, 0.5]
ERROR: DimensionMismatch: arrays could not be broadcast to a common size

julia> v .- [0.5,]
3-element Vector{Float64}:
 0.7
 1.0
 1.2
```

一般に、長さが違うとエラーになります。ただし、一方の長さが1の場合（正確には「シングルトン」次元といいます）は_例外_です。

`[0.5,]`や、単なる`0.5`のようなシングルトンは、繰り返しによって必要な長さまで自動的に拡張されます。
これが`broadcasting`の核心です。

### インプレースでのブロードキャスト

メモリ使用量が気になるときは、アロケーションを減らす手段としてインプレース演算がよく使われます。

しかし、上の例のブロードキャスト演算は、元の`Vector`を変更するのではなく、新しい`Vector`を作ります。

元の`Vector`をインプレースで変更するには、その変更をブロードキャストする必要があります。

```julia-repl
julia> v .= v .+ 1
3-element Vector{Int64}:
 2
 3
 4

julia> v .+= 1  # equivalent operation to above
3-element Vector{Int64}:
 3
 4
 5

julia> v
3-element Vector{Int64}:
 3
 4
 5
```

## インデックス

インデックス番号でベクトルの要素を選ぶ方法は、これまでのコンセプトで扱ってきました。

```julia
a = collect('A':'Z')  # => 26-element Vector{Char}

# index with an integer
a[2]  # => 'B'

# index with a range
 a[12:2:18]  # => ['L', 'N', 'P, 'R']
 
 # index with another vector
 a[ [1, 3, 5] ]  # => ['A', 'C', 'E']
```

### 論理インデックス

ある論理式（正確には「述語」）を満たす要素だけを選ぶこともできます。
これには通常、ブロードキャストが必要です。

```julia-repl
julia> a[a .< 'D']
3-element Vector{Char}:
 'A': ASCII/Unicode U+0041 (category Lu: Letter, uppercase)
 'B': ASCII/Unicode U+0042 (category Lu: Letter, uppercase)
 'C': ASCII/Unicode U+0043 (category Lu: Letter, uppercase)
```

式がもっと複雑になると、ドットがどんどん増えがちです（でも、ドットは小さくて入力も簡単です）。

```julia-repl
julia> a[a .< 'D' .|| a .> 'W']
6-element Vector{Char}:
 'A': ASCII/Unicode U+0041 (category Lu: Letter, uppercase)
 'B': ASCII/Unicode U+0042 (category Lu: Letter, uppercase)
 'C': ASCII/Unicode U+0043 (category Lu: Letter, uppercase)
 'X': ASCII/Unicode U+0058 (category Lu: Letter, uppercase)
 'Y': ASCII/Unicode U+0059 (category Lu: Letter, uppercase)
 'Z': ASCII/Unicode U+005A (category Lu: Letter, uppercase)
```

念のため、「ベクトル」の部分には、範囲のような、順序のある適切なイテラブルなら何でも使えることを思い出してください。

```julia-repl
julia> n = 3:10
3:10

julia> n[isodd.(n)]
4-element Vector{Int64}:
 3
 5
 7
 9
```
