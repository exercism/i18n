# 数値型

Crystalには、さまざまな用途に応じた数値型があります。たとえば、ある型は高速ですが扱える値の範囲が狭く、別の型は扱える値の範囲が広い代わりに低速です。

Crystalには、符号付き整数型と符号なし整数型の両方があります。符号付き整数型は正の値も負の値も扱えます。符号なし整数型は正の値しか扱えません。

## 符号付き整数型

Crystalの[符号付き整数型][int]は次のとおりです:

| 型       | サイズ（ビット） | 範囲                                                                                                        |
| -------- | ----------- | ----------------------------------------------------------------------------------------------------------- |
| `Int8`   | 8           | -128〜127                                                                                                   |
| `Int16`  | 16          | -32_768〜32_767                                                                                             |
| `Int32`  | 32          | -2_147_483_648〜2_147_483_647                                                                               |
| `Int64`  | 64          | -9_223_372_036_854_775_808〜9_223_372_036_854_775_807                                                       |
| `Int128` | 128         | -170_141_183_460_469_231_731_687_303_715_884_105_728〜170_141_183_460_469_231_731_687_303_715_884_105_727 |

小さい型は、大きい型よりも使用するメモリが少なく高速ですが、扱える値の範囲は狭くなります。

値がある範囲に収まるとわかっている場合は、メモリを節約して性能を高めるために、できるだけ小さい型を使うのが一番です。

デフォルトの整数型は`Int32`です。
特定の型の整数を宣言するには、型名を接尾辞として付け、`<number>_I <bit>`のように書きます。

```crystal
1_i8.class
# => Int8
```

`to_i<bit>`メソッドを使うと、異なる整数型の間で変換できます。
`to_i`メソッドは、デフォルトの整数型である`Int32`に変換します。

```crystal
1_i8.to_i16.class
# => Int16

2_i16.to_i.class
# => Int32
```

## 符号なし整数型

Crystalの[符号なし整数][uint]型は次のとおりです:

`UInt8`、`UInt16`、`UInt32`、`UInt64`、`UInt128`

符号付き整数と符号なし整数の唯一の違いは、符号なし整数が正の値しか扱えないことです。
特定の型の符号なし整数を宣言するには、型名を接尾辞として付け、`<number>_u<bit>`のように書きます。
`to_u<bit>`メソッドを使うと、異なる符号なし整数型の間で変換できます。
`to_u`メソッドは、デフォルトの符号なし整数型である`UInt32`に変換します。

```crystal
1_u8.to_u16.class
# => UInt16
```

## 浮動小数点型

Crystalの浮動小数点型は次のとおりです:

| 型        | サイズ（ビット） | 範囲                 |
| --------- | ----------- | -------------------- |
| `Float32` | 32          | 1.2E-38〜3.4E+38     |
| `Float64` | 64          | 2.3E-308〜1.7E+308   |

[浮動小数点型][float]は2種類あり、一方はもう一方よりも精度が高くなっています。

デフォルトの浮動小数点型は`Float64`です。

`to_f<bit>`メソッドを使うと、異なる浮動小数点型の間で変換できます。
`to_f`メソッドは、デフォルトの浮動小数点型である`Float64`に変換します。

[float]: https://crystal-lang.org/api/latest/Float.html
[int]: https://crystal-lang.org/api/latest/Int.html
[uint]: https://crystal-lang.org/api/latest/UInt32.html
