# はじめに

**Map**は、キーと値のペアを保存するためのデータ構造です。
他のプログラミング言語の辞書に似ています。
[Map][map-javadoc]インターフェースは、マップに対する操作を定義します。

Javaには、さまざまなMapの実装があります。
[HashMap][hashmap-javadoc]は、よく使われる実装の1つです。

```java
// Make an instance
Map<String, Integer> fruitPrices = new HashMap<>();
```

[put][map-put-javadoc]を使ってマップにエントリーを追加します。

```java
fruitPrices.put("apple", 100);
fruitPrices.put("pear", 80);
// => { "apple" => 100, "pear" => 80 }
```

各キーに紐づけられる値は1つだけです。
同じキーを指定して`put`を呼び出すと、そのキーの値が更新されます。

```java
fruitPrices.put("pear", 40);
// => { "apple" => 100, "pear" => 40 }
```

キーの値を取得するには、[get][map-get-javadoc]を使います。

```java
fruitPrices.get("apple"); // => 100
```

マップに特定のキーが含まれているかどうかを確かめるには、[containsKey][map-containskey-javadoc]を使います。

```java
fruitPrices.containsKey("apple");   // => true
fruitPrices.containsKey("orange");  // => false
```

エントリーを削除するには、[remove][map-remove-javadoc]を使います。

```java
fruitPrices.put("plum", 90);  // Add plum to map
fruitPrices.remove("plum");   // Removes plum from map
```

[size][map-size-javadoc]メソッドは、エントリーの数を返します。

```java
fruitPrices.size();  // Returns 2
```

[keySet][map-keyset-javadoc]メソッドや[values][map-values-javadoc]メソッドを使うと、Map内のキーや値を、それぞれSetやコレクションとして取り出すことができます。

```java
fruitPrices.keySet();  // Returns "apple" and "pear" in a set
fruitPrices.values();  // Returns 100 and 80, in a Collection
```
