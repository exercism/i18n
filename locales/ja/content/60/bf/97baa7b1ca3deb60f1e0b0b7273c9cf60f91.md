# 説明

あなたは、国際的なボランティアで構成された消防隊の一員です。
チームが国際色豊かであるため、燃えている建物の中の温度を見積もるたびに華氏と摂氏を換算するのに、これまでの何度かの出動で貴重な時間が無駄になってしまっていました。
時間と、そして人命を救うために、国際チームのために華氏と摂氏を自動で変換するプログラムを作ることにします。

## 1. 華氏を摂氏に変換する

`tempToC`関数を実装して、華氏の`Integer`の温度を、小数第2位に四捨五入した摂氏の`Float`に変換しましょう。
摂氏での温度は次のように定義されます。T(°C) = (T(°F) - 32) / 1.8

```haskell
> tempToC 32
0.00
```

## 2. 摂氏を華氏に変換する

`tempToF`関数を実装して、摂氏の`Float`の温度を華氏に変換しましょう。
安全上の理由から、結果は**切り上げて**、**次に大きい**`Integer`にします。
華氏での温度は次のように定義されます。T(°F) = T(°C) × 1.8 + 32

```Haskell
> tempToF 4
40
```
