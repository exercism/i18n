# ヒント

## 全般

- `set-nth ( elt n seq -- )`、`change-nth ( i seq quot -- )`、`push ( elt seq -- )`、`pop ( seq -- elt )`は、いずれも引数のシーケンスを*書き換え*、スタックには何も返しません。その変更こそが効果です。

## 1. 新しいモザイク

- `<array>`（[`arrays`][arrays]内）は、長さと埋める値を受け取り、新しい配列を返します。

## 2. タイルを置く

- `set-nth`が代入を行いますが、`set-nth`が期待するのは`( elt n seq -- )`で、入力は`( row position colour -- )`の順で渡されます。`kernel`の`spin ( x y z -- z y x )`は、3つの値を1つのワードでスタック上で並べ替えるので、`set-nth`の順序どおりになります。

## 3. タイルを取り除く

- 「この位置を`f`にする」というのはタスク2と同じ形ですが、まず`f`をスタックに積む必要があります。

## 4. タイルの色を変える

- `change-nth`は、指定した位置の要素に対してクォーテーションを実行し、その結果を元の位置に書き戻します。

## 5. スナップショット

- `clone`（[`kernel`][kernel]内）は、独立したコピーを返します。

## 6. 一時保存

- `push`は、ベクターに要素をその場で追加します。

## 7. 返す

- `pop`は、ベクターの最後の要素を取り除いて返します。
