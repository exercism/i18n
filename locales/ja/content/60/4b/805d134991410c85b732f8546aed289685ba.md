# 概要

列挙とは、コレクション（`Array`、`Hash`など）を順番に見ていき、それぞれのオブジェクトに対して何らかの操作を行うことです。

列挙はRubyの重要な概念で、並べ替え（`sort_by`）、グループ化（`group_by`）、マッピング（`map`）、畳み込み（`reduce`）など、さまざまな場面で使われます。
コレクションを繰り返し処理する場面では、ループを使うよりも列挙を使うのが、Rubyらしい書き方としてよく見られます。

配列の各単語を出力する、簡単な列挙は次のようになります。

```ruby
words = %w[the cat sat on the mat]
words.each do |word|
  puts word
end

# Output:
# the
# cat
# sat
# on
# the
# mat
```

この例では、`Array#each`メソッドを呼び出し、_ブロック_を渡しています。ブロックは1つの入力（`word`）を受け取り、それを出力します。

Enumerableのメソッドは、チェーンして呼び出すこともできます。
たとえば、`each`に`.with_index`をチェーンすると、オブジェクトの値だけでなくインデックスも出力できます。

```ruby
words = %w[the cat sat on the mat]
list = words.map.with_index { |word, index| "#{index}. #{word}" }
puts list

# Output:
# 0. the
# 1. cat
# ...
# 5. mat
```

`Hash`オブジェクトの列挙も、`Array`オブジェクトの列挙とほとんど同じです。違うのは、ブロックがキーと値の2つの入力を受け取る点だけです。

```ruby
pet_names = {cat: "bob", horse: "caris", mouse: "arya"}
words.each { |animal, name| ... }

# The two arguments should be put in brackets when chaining
words.each.with_index { |(animal, name), index| ... }
```

ここまでに紹介したメソッドは、[`Enumerable`モジュール][enumerable-module]に含まれています。このモジュールは、`Array`や`Hash`など、列挙する機能が必要なクラスに取り込まれています。

[enumerable-module]: https://docs.ruby-lang.org/en/master/Enumerable.html
