# はじめに

[C#の`Attribute`](https://docs.microsoft.com/en-us/dotnet/csharp/programming-guide/concepts/attributes/)を使うと、宣言を修飾してメタデータを関連付けることができます。関連付けられる対象は、クラス、メソッド、列挙型、フィールド、プロパティ、そして[そのほか対応している](https://docs.microsoft.com/en-us/dotnet/csharp/programming-guide/concepts/attributes/#attribute-targets)あらゆる宣言です。

属性を適用するには、`ClassAttribute`や`FieldAttribute`を使って、宣言の前の行に属性を追加します。

```csharp
[Class]
class MyClass
{
    [Field]
    int myField;
}
```

この宣言的なメタデータは、コードに追加の構造化された情報を関連付けるだけで、コードの動作自体は変えません。ただし、このメタデータはコードのほかの部分で使われ、対象の動作を変えたり、機能を追加・変更・削除したり、一部の機能を制限したりします。

[あらかじめ定義されている属性や予約された属性](https://docs.microsoft.com/en-us/dotnet/csharp/language-reference/attributes/general#conditional-attribute)はたくさんあり、たとえば`Flags`、`Obsolete`、`Conditional`などがあります。それぞれに固有の意味があり、C#のドキュメントで調べられます。[`Flags`](https://docs.microsoft.com/en-us/dotnet/api/system.flagsattribute)のような属性の正式な名前は、慣習的に`FlagsAttribute`ですが、宣言に適用するときは_Attribute_という接尾辞を省略できます。
