# 説明

この演習では、フリーランサーがクライアントとプロジェクトの価格についてやり取りするのを手助けするコードを書きます。いくつかのユーティリティ関数を書いて、クライアントの費用をすばやく計算できるようにしましょう。

## 1. 時給から日額を計算する

あるクライアントがフリーランサーに連絡を取り、料金について尋ねてきました。
フリーランサーは、**_1日8時間働いています_**と説明します。
しかし、フリーランサーが把握しているのは、そのプロジェクトの時給だけです。
時給から日額を見積もるのを手伝いましょう。

関数`dailyRateFrom(hourlyRate:)`を実装します。この関数は、フリーランサーの時給を保持する引数`hourlyRate`を受け取ります。  
関数は、時給をもとに日額を返す必要があります。

```swift
dailyRateFrom(hourlyRate: 60)
// Returns 480.0
```

返される日額は`Double`でなければなりません。

## 2. 時給と割引から月額を計算する

ときには、クライアントがフリーランサーをより長い期間雇いたいと考えることもあります。
フリーランサーはクライアントに割引を提示してもよいと考えていますが、それは少なくとも1か月雇ってくれる場合だけです。
合計で**_22営業日_**あります。
フリーランサーが、自分の時給と、提示してもよいとする定額からの割引率をもとに月額を計算できるようにしましょう。計算結果は最も近い整数に四捨五入します。

関数`monthlyRateFrom(hourlyRate:withDiscount:)`を実装します。この関数は、フリーランサーの時給を保持する引数`hourlyRate`と、フリーランサーがクライアントに提示してもよいとする割引を保持する`withDiscount`を受け取ります。
関数は、最も近い整数に四捨五入した月額を返す必要があります。

```swift
monthlyRateFrom(hourlyRate: 77, withDiscount: 10.5)
// Returns 12129
```

## 3. 予算、時給、割引から営業日数を計算する

別の日、プロジェクトマネージャーがフリーランサーに、固定の予算でプロジェクトを進めてみないかと持ちかけます。
固定の予算とフリーランサーの時給をもとに、予算を使い切るまでに何日働けるかを計算するのを手伝いましょう。
この場合、雇われる日数にかかわらず、フリーランサーは常に割引を提示してもよいと考えていることに注意してください。
結果は、_必ず_最も近い整数に**切り捨て**なければなりません。

関数`workdaysIn(budget:hourlyRate:withDiscount:)`を実装します。この関数は次の引数を受け取ります。
- プロジェクトの予算を保持する`budget`。
- フリーランサーの時給を保持する`hourlyRate`。
- フリーランサーがクライアントに提示してもよいとする割引を保持する`withDiscount`。

関数は、フリーランサーがそのプロジェクトで働く営業日数を切り捨てて返す必要があります。

```swift
workdaysIn(budget: 20000, hourlyRate: 80, withDiscount: 11.0)
// Returns 35.0
```
