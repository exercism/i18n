# ヒント

## 全体

- ここにあるループはどれもイテレーターで動くので、カウンター変数も`until!`も必要ありません。
- 答えはいつも、ループの前に宣言した変数に入っています。ループの中で宣言したものは、ループが終わると消えてしまうからです。

## 1. 合計

- `counts.elt!`は、1回ごとに件数を1つ返します。
- 合計は`0`から始めます。こうすると、日が1日もない調査でも正しい答えになります。

## 2. 一番多い日

- これまでで一番良いものを変数に取っておき、`0`から始めます。
- 1回ごとに、その日のほうが上回っていれば置き換えます。`.max`を使えば比較は1ステップでできます：`best := best.max(counts.elt!)`。

## 3. 忙しい日

- 足すのではなく数えます：`if counts.elt! > n then found := found + 1; end;`
- `if`の条件の中で、イテレーターに1回だけ聞きます。同じ本体の中で`counts.elt!`を2回書くと、配列を2度たどることになります。

## 4. 確認する隠れ場所

- ここでは配列をたどっていないので、`elt!`は使えません。`1.upto!(days)`が数を数えてくれます。
- `1.upto!(0)`は何も与えませんが、それこそが0日のときの正しい答えです。

## 5. 最初の忙しい日

- 答えは値ではなく位置なので、位置をたどります：`i ::= 0.upto!(counts.size - 1)`。
- 答えは`-1`から始めます。何も見つからなければ、それがそのまま返すべき値です。
- ある日が見つかったら、`break!`で抜けます。そうしないと、あとで出てくる忙しい日が最初の日を上書きしてしまいます。
