# 説明

入力テキストが与えられたら、それを転置して出力します。

大まかに言うと、行列の転置とは次のようなものです。

```text
ABC
DEF
```

これは次のようになります。

```text
AD
BE
CF
```

行が列になり、列が行になります。
[転置][transpose]を参照してください。

入力の行の長さが異なる場合は、次のように処理します。

- 左側をスペースで埋めます。
- 右側は埋めません。

したがって、この行列を転置すると、

```text
ABC
DE
```

次のようになります。

```text
AD
BE
C
```

また、次を転置すると、

```text
AB
DEF
```

次のようになります。

```text
AD
BE
 F
```

一般的に、入力のすべての文字は、転置後の出力にも含まれている必要があります。
つまり、入力テキストのある列の最下段の行がスペースだけである場合、対応する出力の行では、そのスペースが右端の列に含まれる必要があります。

[transpose]: https://en.wikipedia.org/wiki/Transpose
