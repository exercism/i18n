# はじめに

## 比較

Goでは、数値を次の関係演算子と等値演算子で比較できます。

| 比較        | 演算子  |
| ------------------| --------- |
| 等しい             | `==`      |
| 等しくない         | `!=`      |
| より小さい              | `<`       |
| 以下     | `<=`      |
| より大きい              | `>`       |
| 以上  | `>=`      |

比較の結果は常に真偽値で、`true`か`false`のどちらかになります。

```go
a := 3

a != 4 // true
a > 5  // false
```

上記の比較演算子は、文字列の比較にも使えます。
その場合は、辞書順（辞書の並び順）で比較されます。
たとえば次のとおりです。

```Go
	"apple" < "banana"  // true
	"apple" > "banana"  // false
```

## `if`文

Goの条件分岐は、他の言語の条件分岐とよく似ています。
条件を判定する演算の結果は`bool`型になり、`true`か`false`の値を持ちます。
条件分岐は、さまざまな条件を確認して処理の流れを制御するためによく使われます。

ある条件を確認するには`if`文を使います。条件が`true`のときに、そのコードが実行されます。

```go
var value string

if value == "val" {
    return "was val"
}
```

複数の条件を扱う場面では、`else if`文と`else`文を使って、複数の`if`文をつなげることができます。

```go
var number int
result := "This number is "

if number > 0 {
    result += "positive"
} else if number < 0 {
    result += "negative"
} else {
    result += "zero"
}
```

`if`文には、短い初期化文を書くこともできます。これは、`if`文で使う変数を1つ以上初期化するために使えます。
たとえば次のとおりです。

```go
num := 7
if v := 2 * num; v > 10 {
    fmt.Println(v)
} else {
    fmt.Println(num)
}
// Output: 14
```

> 注意：初期化文で作られた変数は、`if`文の終わりでスコープから外れます。
