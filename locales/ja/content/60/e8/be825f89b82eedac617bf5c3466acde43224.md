# ヒント

## 全般

- 読み取り用のワードは[`io`][io]にあります。文字列ストリームのコンストラクターと`with-string-writer`は[`io.streams.string`][io.streams.string]にあります。
- ライターをフラッシュするタスクでは、同じストリームに2回触れる必要があるときに、ローカル変数（`::`と`:>`）を使うと本文が読みやすくなります。

## 1. すべて聞き取る

- ワードは1つ、`stream-contents`です。

## 2. メッセージを数える

- `stream-lines`がストリームを行の配列に分割し、`length`がその個数を返します。

## 3. 最後の呼び出しをそのまま返す

- 上と同じ`stream-lines`を使い、そのあとに`last`、そして（`ascii`の）`>upper`です。

## 4. メッセージをブロードキャストする

- `stream-write`がメッセージを書き込み、`stream-flush`がそれを送り出します。ライターを2回使うので、`::`のローカル変数を使いましょう。
  `:: broadcast ( message writer -- ) message writer stream-write
  writer stream-flush ;`。

## 5. クォーテーションの出力をキャプチャーする

- ワードは1つ、`with-string-writer`です。閉じる`;`のあとに`inline`を付けると、コンパイラーがクォーテーションの引数を見通せるようになります。
  `: capture ( quot -- captured ) with-string-writer ; inline`。
