# テスト

phixのバイナリにパスが通っている場合は、次のコマンドを入力してください。

```bash
p test 
```
これでテストファイル（test.exw）が実行されます。

phixのバイナリにPATHが通っていない場合は、Windowsでは次のように入力します。

```cmd
\path\to\p.exe test
```

Linuxでは、次のように入力します。

```bash
/path/to/p test
```

## テストのスキップ

演習を解くというのは、そのテストをすべて通すことです。
デフォルトでは、test.exwファイル内のテストがすべて実行されます。
テストをスキップするには、行の先頭にダッシュ2つ（Phixの標準的なコメント記号）を付けます。

なお、テストはtests.tomlのinclude=falseフラグを一切考慮しません。むしろ、Exercismサイトのために実際の状態を反映させるよう、そのファイル内で手作業で維持するのはtest.exwの作者の責任です（たとえばトラックの統計を集めるためなど）。ただし、トラック自身はこれらのフラグをまったく利用していません。具体的には、テストジェネレーターとテストランナーも同様です。
