# ヒント

## 全般

- [範囲][range]についての公式ドキュメントを読んでみましょう。

## 1. ランクの範囲を定義する

- 範囲を作るための[特別な演算子][range-creation-operator]があります。

## 2. ファイルの範囲を定義する

- 範囲を作るための[特別な演算子][range-creation-operator]があります。
- 値そのものを知らなくても、文字のコードポイントを書ける[特別な構文][unicode-code-points]があります。

## 3. ランクの範囲をランクのリストに変換する

- 範囲は`Enumerable`プロトコルを実装しています。
- 列挙可能なデータ構造をリストに変換する[組み込み関数][enum-to-list]があります。

## 4. ファイルの範囲をファイルのリストに変換する

- 範囲は`Enumerable`プロトコルを実装しています。
- 要素を変更しながら、列挙可能なデータ構造をリストに変換する[組み込み関数][enum-map]があります。
- [ビット文字列の特殊形式][bitstring-special-form]を使うと、コードポイントを文字列に変換できます。
