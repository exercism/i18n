# はじめに

代数的データ型（ADT）は、決まった数の名前付きケースを表します。
ADTの値は、名前の付いたケースのうち、ちょうど1つに対応します。

ADTは`data`キーワードで定義し、各ケースはパイプ（`|`）で区切ります。
どのケースにもデータが結び付いていない場合、そのADTは、他の言語で一般に_列挙型_（_enum_）と呼ばれているものに似ています。

```haskell
data Season
  = Spring
  | Summer
  | Autumn
  | Winter
```

ADTの各ケースには、データを結び付けることもできます。また、ケースごとに違う型のデータを持たせることもできます。
データを結び付けるケースには、コンストラクターが必要です。

```haskell
data Number
  = NInt Int      --'NInt' is the constructor for an Int Number.
  | NFloat Float  --'NFloat' is the constructor for an Float Number.
  | Invalid       --'Invalid' does not have data associated to it.
```

特定のケースの値を作るには、そのケースの名前を参照します（例：`NInt 22`）。
ケース名は単なるコンストラクター関数なので、結び付けるデータは通常の関数の引数として渡せます。

ADTには_構造的等価性_があり、これは、同じケースで同じ（省略可能な）データを持つ2つの値が等しいとみなされることを意味します。

`if/else`式でADTを扱うこともできますが、おすすめの方法は、_case_文を使ったパターンマッチングです。

```haskell
add1 :: Number -> String
add1 number =
    case number of
      NInt    i -> show (i + 1)
      NFloat  f -> show (f + 1.0)
      Invalid   -> error "Invalid input"
```
