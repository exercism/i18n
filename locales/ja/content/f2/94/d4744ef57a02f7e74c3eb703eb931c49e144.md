# 説明

この演習では、[ブラックジャック][blackjack]のルールの一部を実装します。たとえば、ゲームの進め方や得点の計算方法などです。

**注意**：この演習では、_`A`_はエース、_`J`_はジャック、_`Q`_はクイーン、_`K`_はキングを表します。ジョーカーは使いません。[標準的なフランス式の52枚組のデッキ][standard_deck]を想定していますが、ほとんどの場合は複数のデッキを混ぜてプレイします。

## 1. カードの値を計算する

ブラックジャックでは、エースを1点にするか11点にするかは、プレイヤーがそれぞれ自分で決められます（_詳しくは後ほど_）。絵札（`J`、`Q`、`K`）は10点で、それ以外のカードは「ピップ」（_数字_）の値と同じ点数になります。

`card`を仮引数とする`value_of_card(<card>)`関数を定義してください。この関数は、渡されたカードの文字列の_数値_を返します。エースは複数の値（1**または**11）を取ることができるので、この関数ではとりあえずエースのカードの値を1に固定しておきます。後ほど、手札がすでにある状態でエースの値を決める関数を実装します。

```python
>>> value_of_card('K')
10

>>> value_of_card('4')
4

>>> value_of_card('A')
1
```

## 2. どちらのカードの値が大きいかを判定する

`card_one`と`card_two`を仮引数とする`higher_card(<card_one>, <card_two>)`関数を定義してください。得点計算では、`J`、`Q`、`K`の値は10です。この関数は、得点計算上どちらのカードの値が大きいかを返します。両方のカードの値が等しい場合は、両方を返します。両方のカードを返すには、`return`文でカンマを使います。

```python
# Using a comma in a return creates a Tuple.  Tuples will be covered in a later exercise.
>>> def returning_two_values(value_one, value_two):
        return value_one, value_two

>>> returning_two_values('K', '3')
('K', '3')
```

エースは複数の値を取ることができるので、このタスクでは`A`のカードの値を1に固定します。

```python
>>> higher_card('K', '10')
('K', '10')

>>> higher_card('4', '6')
'6'

>>> higher_card('K', 'A')
'K'
```

## 3. エースの値を計算する

すでに触れたとおり、エースは1点**または**11点の_どちらか_になります。プレイヤーは、21点を_超える_ことなく（これを「バスト」といいます）、できるだけ21点に近づけようとします。

`card_one`と`card_two`を仮引数とする`value_of_ace(<card_one>, <card_two>)`関数を定義してください。この2枚は、エースのカードを引く_前に_すでに手札にあるカードです。この関数は、これから引くエースを1にするか11にするかを判断し、その値を返す必要があります。エースを含めた手札の値が、21点を超えない範囲でできるだけ大きくなるようにしてください。

**ヒント**：すでに手札にエースがある場合、これから引くエースの値は1になります。

```python
>>> value_of_ace('6', 'K')
1

>>> value_of_ace('7', '3')
11
```

## 4. 「ナチュラル」または「ブラックジャック」の手札を判定する

最初の2枚としてエース（`A`）と10のカード（10、`K`、`Q`、`J`）が配られると、プレイヤーの得点は21点になります。これは**ブラックジャック**の手札と呼ばれます。


`card_one`と`card_two`を仮引数とする`is_blackjack(<card_one>, <card_two>)`関数を定義してください。この2枚はカードの組です。2枚の手札が**ブラックジャック**かどうかを判定し、そうであれば真偽値の`True`を、そうでなければ`False`を返してください。

**注意**：得点の_計算_はさまざまな方法で行えます。ですが、できれば手札の値を_合計する_のではなく、手札に（_または特定の位置に_）エースと10のカードがあるかどうかを確認するようにしてください。

```python
>>> is_blackjack('A', 'K')
True

>>> is_blackjack('10', '9')
False
```

## 5. ペアを分割する

手札の最初の2枚が同じ値の場合（_たとえば、6が2枚、あるいは`Q`と`K`など_）、プレイヤーはそれらを2つの別々の手札として扱うことを選べます。これは「ペアの分割」と呼ばれます。

`card_one`と`card_two`を仮引数とする`can_split_pairs(<card_one>, <card_two>)`関数を定義してください。この2枚はカードの組です。この2枚の手札を2つのペアに分割できるかどうかを判定してください。分割できる場合は真偽値の`True`を返し、そうでなければ`False`を返します。

```python
>>> can_split_pairs('Q', 'K')
True

>>> can_split_pairs('10', 'A')
False
```

## 6. ダブルダウン

配られた最初の2枚の合計が9、10、11点のとき、プレイヤーは元の賭け金と同額の追加の賭け金を置くことができます。これは「ダブルダウン」と呼ばれます。

`card_one`と`card_two`を仮引数とする`can_double_down(<card_one>, <card_two>)`関数を定義してください。この2枚はカードの組です。この2枚の手札を「ダブルダウン」できるかどうかを判定し、できる場合は真偽値の`True`を、そうでなければ`False`を返してください。

```python
>>> can_double_down('A', '9')
True

>>> can_double_down('10', '2')
False
```
