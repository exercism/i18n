# 説明

秒単位の年齢が与えられたとき、太陽系の惑星ではその人が何歳になるかを計算します。

地球での1年は365.25日、つまり31,557,600秒です。
もし誰かが1,000,000,000秒の年齢だとしたら、その人の年齢は地球での31.69年になります。

他の惑星については、地球年での公転周期を考慮する必要があります。

| 惑星  | 地球年での公転周期 |
| ------- | ----------------------------- |
| 水星 | 0.2408467                     |
| 金星   | 0.61519726                    |
| 地球   | 1.0                           |
| 火星    | 1.8808158                     |
| 木星 | 11.862615                     |
| 土星  | 29.447498                     |
| 天王星  | 84.016846                     |
| 海王星 | 164.79132                     |

~~~~exercism/note
地球が太陽の周りを1周する実際の長さは、365.256日（1恒星年）に近い値です。
グレゴリオ暦は、平均すると365.2425日です。
完全に正確ではありませんが、この演習では365.25という値を使います。
1年の測り方については、[Wikipediaの「年」の記事][year]を参照してください。

[year]: https://en.wikipedia.org/wiki/Year#Summary
~~~~
