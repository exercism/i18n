# 概要

C++の条件分岐は、他の言語の条件分岐とよく似ています。
条件に関する演算の基になる型は`bool`型で、`true`または`false`という値を持ちます。
条件分岐は、さまざまな条件を確認するためのフロー制御の仕組みとしてよく使われます。

`if`文を使うと、条件が`true`のときにそのコードを実行できます。たとえば次のようになります。

```cpp
std::string value{"val"};

if (value == "val") {
    return "was val";
}
```

複数のケースを扱う場面では、`else if`文と`else`文を使って、多くの`if`文をつなげることができます。

```cpp
int number{33};

if (number > 0) {
   return "positive";
} else if (number < 0) {
    return "negative";
} else {
   return "zero";
}
```

C++17以降では、`if`文に短い初期化文を書くこともできます。これは、`if`文で使う1つ以上の変数を初期化するために利用できます。
たとえば次のようになります。

```cpp
int num{7};
if (int v{2 * num}; v > 10) {
    return v;
} else {
    return num;
}
// => 14
```

> 注意：初期化で作成した変数は、`if`文の終わりより後ではアクセスできません。
