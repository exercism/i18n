# はじめに

ループの繰り返し回数が前もってわからないとき、つまり「ある述語が真でなくなるまで続ける」ようなときは、Factorでは[`kernel`][kernel]の`while`コンビネーターを使います。

```
while ( pred body -- )
```

`pred`と`body`はどちらも、データスタックを操作するクオーテーションです。`while`はまず`pred`を呼び出します。`pred`がスタックの一番上に真とみなされる値を残せば、`while`は`body`を実行して繰り返します。そうでなければ停止します。ある繰り返しから次の繰り返しへと受け渡される状態は、呼び出しと呼び出しの間はスタック上に置かれます（状態が複数あるときは、名前付きローカルに置かれます）。

```factor
USING: kernel math ;

5 [ dup 0 > ] [ dup . 1 - ] while drop
! prints 5 4 3 2 1
```

`until`は対になる形で、述語が真とみなされるようになる*まで*続けます。

[kernel]: https://docs.factorcode.org/content/vocab-kernel.html
