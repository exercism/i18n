# 説明

駆け出しのマジシャンであるElyseは、基本をいくつか練習する必要があります。彼女は、操ってみたいカードの山を持っています。

少しでも簡単にするために、彼女は1から10までのカードだけを使います。そうすれば、カードの山を数値の配列で表せるからです。あるカードの位置は、配列のインデックスに対応します。つまり、位置0が1枚目のカード、位置1が2枚目のカードを指します。

~~~~exercism/note
すべての関数は、カードの配列を更新してから、更新した配列を返すようにします。これはビルダーパターンと呼ばれる一般的な作り方で、関数をきれいにつなげて書けるようになります。
~~~~

## 1. 山からカードを取り出す

カードを1枚選ぶには、与えられた山のインデックス`position`にあるカードを返します。

関数`getCard(at:from:)`を実装します。この関数は2つの引数を取ります。`at`は山の中でのカードの位置、`from`はカードの山です。この関数は、与えられた山から位置`index`にあるカードを返します。

```swift
let index = 2
getCard(at: index, from: [1, 2, 4, 1])
// returns 4
```

## 2. 山の中のカードを変える

手品のような手さばきで、インデックス`position`にあるカードを、用意された新しいカードと入れ替えます。

関数`setCard(at:in:to)`を実装します。この関数は3つの引数を取ります。`at`は山の中でのカードの位置、`in`はカードの山、`to`は位置`index`のカードと入れ替える新しいカードです。この関数は、位置`index`のカードを新しいカードで置き換えた山のコピーを返します。与えられた`index`が山の中の有効なインデックスでない場合は、元の山をそのまま返します。

```swift
let index = 2
let newCard = 6
setCard(at: index, in: [1, 2, 4, 1], to: newCard)
// returns [1, 2, 6, 1]
```

## 3. 山の一番上にカードを挿入する

山の一番上に新しいカードを挿入して、カードを出現させます。

関数`insert(_:atTopOf:)`を実装します。この関数は2つの引数を取ります。挿入する新しいカードと、カードの山です。この関数は、用意された新しいカードを山の一番上に加えた山のコピーを返します。

```swift
let newCard = 8
insert(newCard, atTopOf: [5, 9, 7, 1])
// returns [5, 9, 7, 1, 8]
```

## 4. 山からカードを取り除く

与えられた`position`にあるカードを山から取り除いて、カードを消します。

関数`removeCard(at:from:)`を実装します。この関数は2つの引数を取ります。`at`は山の中でのカードの位置、`from`はカードの山です。この関数は、位置`index`のカードを取り除いた山のコピーを返します。与えられた`index`が山の中の有効なインデックスでない場合は、元の山をそのまま返します。

```swift
let index = 2
removeCard(at: index, from: [3, 2, 6, 4, 8])
// returns [3, 2, 4, 8]
```

## 5. 山にカードを挿入する

与えられた`position`に新しいカードを挿入して、カードを出現させます。

関数`insert(_:at:from:)`を実装します。この関数は3つの引数を取ります。挿入する新しいカード、新しいカードを挿入する位置、カードの山です。この関数は、用意された新しいカードを与えられた位置に加えた山のコピーを返します。与えられた`index`が山の中の有効なインデックスでない場合は、元の山をそのまま返します。

```swift
let newCard = 8
insert(newCard, at: 2, from: [5, 9, 7, 1])
// returns [5, 9, 8, 7, 1]
```

## 6. 山の枚数を確認する

山の枚数が`stackSize`と同じかどうかを確認します。

関数`checkSizeOfStack(_:_:)`を実装します。この関数は2つの引数を取ります。`stack`はカードの山、`stackSize`は山の枚数です。この関数は、山の枚数が`stackSize`と同じであれば`true`を、そうでなければ`false`を返します。

```swift
let stackSize = 4
checkSizeOfStack([3, 2, 6, 4, 8], stackSize)
// returns false
```
