# はじめに

Clojureの`vector`は、順序を持ち、インデックスでアクセスでき、0個以上の値からなる不変のコレクションです。つまり、いったん作成されたベクターは変更できません。ベクターを操作する関数は新しいベクターを返し、元のベクターは変わりません。ベクターに入れる値は、型が異なっていてもかまいません。ベクターは次のように定義できます。

```clojure
(def empty [])
(def single-value 5)
(def single-value-alternative (vector 5))
(def three-values [a b c]
```

要素は、インデックスを使ってベクターから取り出せます。Clojureのベクターは0から始まるので、最初の要素のインデックスは常に0です。

```clojure
(def numbers [2 3 5])
;; Read value from vector
(get numbers 2)
;;=> 5
;; Update value in vector
(assoc numbers 2 9)
;;=> [2 3 9]
```

元のベクターは変わりません。

```clojure
numbers
;;=> [2 3 5]
```

更新後の値を覚えておくには、その値をそのまま渡していくか、varに束縛しておく必要があります。

```clojure
(def updated-numbers
  (assoc numbers 2 9))
(get updated-numbers 2)
;;=> 9
```
