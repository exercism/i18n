# はじめに

キャストと型変換は、式をあるデータ型から別のデータ型に変える、それぞれ異なる方法です。

式は、キャスト演算子`(<type>)`を使って別の型にキャストできます。

```csharp
long l = 1000L;
int i = (int)l;

object o = new Random();
Random r = (Random)o;
```

型に互換性がない場合は、`InvalidCastException`のインスタンスがスローされます。数値の場合は、受け取る側の型がキャストする値を表現できないことを意味します。クラスの場合は、どちらか一方の型がもう一方から派生していなければなりません（これは構造体にもそのまま当てはまります）。

_キャスト_の代わりに、`is`演算子を使った_型変換_という方法もあります。これは通常、参照型とnull許容型に適用されます。

```csharp
object o = new Random();
if (o is Random rand)
{
    int ii = rand.Next();
    // now, do something random
}
```

オブジェクトの正確な型を判定する必要がある場合、`is`は少し寛容すぎるかもしれません。クラスと、そこから直接的または間接的に派生したすべてのクラスおよびインターフェースに対して`true`を返すからです。この場合は、`typeof`と`Object.GetType()`が解決策になります。

```csharp
object o = new List<int>();

o is ICollection<int> // true
o.GetType() == typeof(ICollection<int>) // false
o is List<int> // true
o.GetType() == typeof(List<int>) // true
```
