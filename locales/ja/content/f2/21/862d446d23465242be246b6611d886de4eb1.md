# はじめに

Kotlinの`when`は、いくつかの選択肢から1つを選ぶための条件式です。
Javaの`switch`に似ていますが、`if` ... `else if` ... `else`を連ねるより柔軟です。

`if`と同じように、`when`も値を生み出す式として使えます。

## 値にマッチさせる

`when`には、マッチさせたい値を括弧（`()`）の中に書きます。
各分岐は、その値を一致するものがあるまで順に比較します。

```kotlin
val animal = "chicken"
val type = when (animal) {
    "chicken" -> "bird"
    "poodle" -> "dog"
    else -> "unknown"
}
// type => "bird"
```

- 各分岐は`pattern -> result`のように書きます。
- 分岐は上から下へ順に試され、マッチした時点で終わります。
  実行されるのは、最初にマッチした分岐だけです。
- 上に挙げたどの値にも当てはまらない場合は`else`を使います（`if`の連鎖の最後の`else`と同じです）。

これは[パターンマッチング][pattern-matching]に似ています。
`pattern`にはマッチさせたい値を書くこともできますし、`is`を使って型でマッチさせることもできます：

```kotlin
fun typeText(subject: Any): String {
    return when(subject) {
        is Animal -> "Animal"
        is Fruit -> "Fruit"
        is String -> "Text"
        else -> "Unknown"
    }
}
```

また`in`を使えば、範囲、コレクション、文字列など、`contains`メソッドを持つものに含まれるかどうかを調べられます：

```kotlin
fun describe(number: Int, position: String) {
    // Range
    when(number) {
        in 1..10 -> println("From 1 to 10")
        in 11..20 -> println("From 11 to 20")
    }

    // Collection
    when(number) {
        in listOf(2, 4, 6) -> println("small even")
        in listOf(3, 5, 7) -> println("small odd")
    }

    // String
    when(position) {
        in "center middle" -> println("inner")
        in "left right boundary" -> println("outer")
    }
}
```

## ガード条件

値にマッチさせるときは、パターンの後ろに`if`を置いて条件を追加できます。
この条件をガード条件と呼びます。

```kotlin
val x = 5
val y = 10
val description = when (x) {
    5 if y % 2 == 0 -> "x is 5, y is even"
    else -> "other"
}
// description => "x is 5, y is even"
```

`else if`を使うこともできます。

```kotlin
val x = 7
val y = 10
val description = when (x) {
    5 if y % 2 == 0 -> "x is 5, y is even"
    else if y % 2 == 0 -> "y is an even number"
    else -> "other"
}
// description => "y is an even number"
```


## 条件にマッチさせる

別の書き方として、値を省略し、各分岐に真偽値の条件を書くこともできます：

```kotlin
val x = 5
val y = 8
val description = when {
    x % 2 != 0 -> "x is odd"
    y % 2 == 0 -> "y is even"
    else -> "neither condition matched first"
}
// description => "x is odd"
```

ここでも分岐は上から下へ確認され、条件が`true`になった最初の分岐だけが実行されます。

## `when`を式として使う

`when`の結果を使う場合（変数に代入する、関数から返す、など）は、考えられるすべてのケースを網羅する必要があります。

- 値でマッチさせる場合は、考えられるすべての値に対処していない限り`else`を追加します（たとえば、`Boolean`や`enum`のすべての値を列挙している場合など）。
- 条件でマッチさせる場合は、`else`の分岐が必須です。書いた条件がすべてのケースを網羅しているかどうかを、コンパイラーは判断できないからです。

```kotlin
fun label(n: Int): String = when (n) {
    0 -> "zero"
    1 -> "one"
    else -> "other"
}
```
