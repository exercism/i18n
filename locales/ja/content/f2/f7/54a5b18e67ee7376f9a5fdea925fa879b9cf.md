# 説明

庭にやってくる鳥の数を記録している、熱心なバードウォッチャーです。
ふだんはノートに正の字を書いて鳥を数えていますが、データを扱いやすくするために、ここ数週間の鳥の数をデジタル化しました。

## 1. これまでに数えた鳥の合計を求める

まずは全体像をつかむことから、データの分析を始めましょう。
記録を付け始めてから数えた鳥の総数を求めてみましょう。

1日あたりの鳥の数を含む`Int`の配列を受け取る関数`totalBirdCount`を実装しましょう。
数えた鳥の合計を返すようにします。

```swift
let birdsPerDay = [2, 5, 0, 7, 4, 1, 3, 0, 2, 5, 0, 1, 3, 1]
totalBirdCount(birdsPerDay)
// Returns 34
```

## 2. 特定の週にやってきた鳥の数を計算する

鳥の数の全体像がつかめたので、次はより細かい分析をしてみましょう。

1日あたりの鳥の数の配列と週番号を受け取る関数`birdsInWeek`を実装しましょう。

その週に数えた鳥の合計を返します。
週は常に完全に記録されていると仮定してかまいません。

```swift
let birdsPerDay = [2, 5, 0, 7, 4, 1, 3, 0, 2, 5, 0, 1, 3, 1]
birdsInWeek(birdsPerDay, weekNumber: 2)
// Returns 12
```

## 3. 数え間違いを修正する

鳥を記録している間ずっと、庭の遠くの隅に隠れている鳥が1羽いたことに気づきました。

その鳥は、1日おきに必ず庭に来ていたことがわかりました。

その間どこにいたのかは正確にはわかりませんが、庭にいなかったことは確かです。

バードウォッチャーとしての勘から、リストで記録を始めた最初の日には、その鳥が庭にいたこともわかります。

この新しい情報をもとに、1日あたりに数えた鳥の配列を引数に取り、数え間違いを修正した後の配列を返す関数`fixBirdCountLog`を書きましょう。

```swift
var birdsPerDay = [2, 5, 0, 7, 4, 1]
fixBirdCountLog(birdsPerDay)
// Returns [3, 5, 1, 7, 5, 1]
```
