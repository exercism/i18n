# はじめに

多くのプログラムでは、現実世界の出来事をシミュレートするために、（一見すると）ランダムな値が必要になります。

よく知られた例としては、次のようなものがあります。

- コイントス：`"H"`または`"T"`というランダムな値。
- サイコロを振る：1から6までのランダムな整数。
- トランプをシャッフルする：カードのリストをランダムに並べ替えたもの。

コンピューターで真にランダムな値を生成するのは[驚くほど難しい技術的課題][web-truly-random]なので、こうした結果は「疑似乱数」と呼ばれることがあります。

***重要***：このコンセプトでは、暗号学的に安全な乱数は扱いません。これははるかに難しい課題です。

ただし、Rは統計パッケージから派生した言語で、シミュレーションによく使われるため、ランダムな値を生成する方法が豊富に用意されています。
その結果は、モデリング・シミュレーション・ゲームのほとんどの用途には十分な品質です。

## [復元抽出と非復元抽出][yt-sampling-with-replacement]

赤い玉が3つ、緑の玉が4つ入った袋から、ランダムに1つ玉を取り出す場面を想像してみましょう。
2つ目の玉を取り出す方法には、次の2通りがあります。

1. 1つ目の玉を袋に戻し、よく振ってからもう1つ取り出します。
   玉の数は元と同じ7つで、*赤と緑の比率も同じです*。
2. 1つ目の玉を袋に戻さずテーブルに置いてから、2つ目を取り出します。
   袋の中の玉は6つだけになり、*赤と緑の比率は1つ目の玉の色によって変わります*。

シナリオ1は復元抽出、シナリオ2は非復元抽出で、*それぞれ結果が異なります*。

## `sample`を使った離散値

限られた数の離散値から選ぶには、`sample()`を復元抽出でも非復元抽出でも使えます。
これは整数や文字列などに便利です。

```R
sample(1:10, 5) # no repeats by default
#> [1] 8 3 4 2 6

sample(1:10, 5, replace = TRUE) # repeats are OK
#> [1] 10 10  7 10  9

languages <- c("Fortran", "R", "Python", "Julia")
sample(languages, 1)
#> [1] "Python"

sample(c("H", "T"), 5, replace = TRUE) # coin flips
#> [1] "T" "T" "H" "H" "H"

sample(c(TRUE, FALSE), 5, replace = TRUE) # alternative coin flips
#> [1] FALSE  TRUE FALSE  TRUE  TRUE
```

サンプリングはデータパイプラインによく合います。
たとえば、ランダムな英数字の文字列を生成するには次のようにします。

```R
library(stringr)

c(letters, LETTERS, 0:9) |> sample(50) |> str_flatten()
#> [1] "5tX71jhbM9zUmKrpENBQyGYaZdJPVAx06leSF2s8gcfw3OviIH"
```

## シャッフル

他の多くの言語には、シーケンスをシャッフルする専用の関数があります。

Rにはシャッフル用の関数がありません。
*なぜでしょうか？*

その理由を理解するために、もう一度`sample`関数を見てみましょう。

完全な形は`sample(x, size, replace = FALSE, prob = NULL)`で、`x`は（通常）サンプリング元のシーケンス、`size`は選ぶ要素の数です。

`replace`についてはすでに説明しました。デフォルトは非復元抽出です。
ここでは`prob`は無視してください。これは`x`の各要素に異なる重みを付けられるようにするものです。

`size`を省略して`x`だけを渡すと、どうなるでしょうか？

```R
x <- letters[1:6]
x
#> [1] "a" "b" "c" "d" "e" "f"
sample(x)
#> [1] "e" "a" "f" "b" "c" "d"
```

典型的なRのスタイルで、パターンはベクトル入力・ベクトル出力であり、`size`のデフォルトは`length(x)`です。

「`x`のすべての要素を非復元抽出でサンプリングする」とは、「`x`をシャッフルする」をより専門的に言い換えただけです。

*つまり*、`sample`がすでに必要なことを正確に行ってくれるので、`shuffle`関数は存在しないのです！

## 分布を扱う

ここまでの例では、すべての結果が同じ確率で起こる場合を扱いました。
たとえば`sample(1:100)`は、1から100までのどの整数も同じ確率で返します。

これは`uniform`分布と呼ばれます。

現実世界の多くの状況は、これよりもはるかに複雑です。
そのため、統計学者たちは現実世界の結果を数学的に記述するために、さまざまな`distributions`を考案してきました。

## 浮動小数点数

### 一様分布

同じ確率で重み付けされた浮動小数点数の分布を得るには、`runif()`を使います（"**r**andom-**unif**orm"に注目してください。"run if"と読んでしまう自然だけど*間違った*傾向に抗いましょう）。
`min`と`max`はどちらも指定できますが、デフォルトは0と1です。

```R
runif(5)  # generate 5 values
#> [1] 0.3038506 0.3527959 0.3319309 0.4846354 0.4386279

# generate 5 non-negative values <= 100.0
runif(5, max = 100)
#> [1] 79.70762 51.62232 52.85281 71.08571 63.94380
```
