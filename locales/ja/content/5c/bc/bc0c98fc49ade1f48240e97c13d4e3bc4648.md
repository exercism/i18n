# はじめに

## Result

`Result`型は、Elm言語でエラーを報告するための解決策であり、エラーからの復帰を可能にするものです。`Maybe`型と少し似ていますが、Maybeは失敗する可能性のある関数から返すことができても、なぜ失敗したのかについては何も教えてくれません。Resultには、なぜ失敗したのかというこの文脈が含まれています。

`Result`型は次のように定義されています。

```elm
type Result error value
  = Ok value
  | Err error
```

これはElmの用語で「カスタム型」定義と呼ばれています。
`OK value`と`Error error`の`error`と`value`は型変数を表していて、`Int`、`Bool`、`String`など、どんな型でもよいという意味です。
このように、`Result String Int`は`Int`を含むことが期待される変数であり、エラーがある場合はそれが`String`で表されます。
Resultには、役に立つヘルパー関数がたくさんある[Resultモジュール](https://package.elm-lang.org/packages/elm/core/latest/Result)があります。
