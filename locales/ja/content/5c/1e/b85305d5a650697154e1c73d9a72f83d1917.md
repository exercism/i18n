# 説明

この演習では、ラジコンカーを動かして遊びます。このラジコンカーは、ようやくお金を貯めて買うことができたものです。

車のバッテリーは、最初は満充電（100%）です。
リモコンで車を動かすたびに、車は20メートル進み、バッテリーを1%消費します。
車のニックネームは、作成されるまで分かりません。

ラジコンカーには、2つの情報を表示する素敵なLEDディスプレイが付いています。

- 走行した合計距離。表示は`"<METERS> meters"`のようになります。
- バッテリーの残量。表示は`"Battery at <PERCENTAGE>%"`のようになります。

バッテリーが0%になると、車を動かすことはできなくなり、バッテリー表示は`"Battery empty"`になります。

## 1. 新品のラジコンカーを作成する

`new_remote_control_car/0`関数を実装して、新品のラジコンカーのオブジェクトを返すようにしましょう。

```jq
new_remote_control_car
# => {
#      "battery_percentage": 100,
#      "distance_driven_in_meters": 0,
#      "nickname": null
#    }
```

## 2. ニックネーム付きの新品のラジコンカーを作成する

`new_remote_control_car/1`関数を実装して、指定したニックネームを持つ新品のラジコンカーのオブジェクトを返すようにしましょう。

```jq
new_remote_control_car("Blue")
# => {
#      "battery_percentage": 100,
#      "distance_driven_in_meters": 0,
#      "nickname": "Blue"
#    }
```

## 3. 距離を表示する

`display_distance/0`関数を実装しましょう。この関数は車のオブジェクトを入力として受け取り、LEDディスプレイに表示される距離の文字列を出力します。

```jq
new_remote_control_car | display_distance
# => "0 meters"
```

## 4. バッテリー残量を表示する

`display_battery/0`関数を実装しましょう。この関数は車のオブジェクトを入力として受け取り、LEDディスプレイに表示されるバッテリー残量の文字列を出力します。

```jq
new_remote_control_car | display_battery
# => "Battery at 100%"
```

バッテリーが0%になると、バッテリー表示は"Battery empty"になります。

## 5. 走行するとバッテリーと走行距離が変わる

`drive/0`関数を実装しましょう。この関数は次の処理を行います。

- 車のオブジェクトを入力として受け取る
- 走行距離を20メートル増やす
- バッテリーを1%消費する
- 変更後の車のオブジェクトを出力する

```jq
new_remote_control_car("Red") | drive
# => {
#      "battery_percentage": 99,
#      "distance_driven_in_meters": 20,
#      "nickname": "Red"
#    }
```

## 6. バッテリー切れでの走行に対応する

`drive/0`関数を更新して、バッテリーが切れているとき（0%のとき）は走行距離を増やさず、バッテリーの残量も減らさないようにしましょう。

```jq
{
  battery_percentage: 0,
  distance_driven_in_meters: 2000,
  nickname: "Red"
} | drive
# => {
#      "battery_percentage": 0,
#      "distance_driven_in_meters": 2000,
#      "nickname": "Red"
#    }
```
