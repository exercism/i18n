# 説明

この演習では、シンプルな整数電卓のエラー処理を実装します。話を簡単にするために、足し算・掛け算・割り算を計算するメソッドはあらかじめ用意されています。

目標は、引数として`16`、`51`、`+`を受け取ったときに、`16 + 51 = 67`というパターンのStringを返す、ちゃんと動く電卓を作ることです。

```java
CalculatorConundrum calculator = new CalculatorConundrum();

calculator.calculate(16, 51, "+");
// => returns "16 + 51 = 67"

calculator.calculate(32, 6, "*");
// => returns "32 * 6 = 192"

calculator.calculate(512, 4, "/");
// => returns "512 / 4 = 128"
```

## 1. 基本的な演算をいくつか扱えるように`calculate`メソッドを実装する

このタスクで実装する中心となるメソッドは、`CalculatorConundrum.calculate()`メソッドです。
このメソッドは3つの引数を取ります。
最初の2つの引数`operand1`と`operand2`は、演算の対象となる整数です。
3つ目の引数`operation`はString型で、この演習では次の演算を実装する必要があります：

- `+`というStringを使った足し算
- `*`というStringを使った掛け算
- `/`というStringを使った割り算

## 2. 不正な演算を処理する

`CalculatorConundrum.calculate()`メソッドを更新して、不正な演算を処理します：

- `operation`引数が`null`のときは、メッセージ`Operation cannot be null`とともに`IllegalArgumentException`をスローします。
- `operation`引数が`""`のときは、メッセージ`Operation cannot be empty`とともに`IllegalArgumentException`をスローします。
- `operation`引数が`+`、`*`、`/`以外の演算のときは、メッセージ`Operation '{operation}' does not exist`とともに`IllegalOperationException`をスローします。

```java
calculator.calculate(10, 1, null);
// => throws IllegalArgumentException with message "Operation cannot be null"

calculator.calculate(10, 1, "");
// => throws IllegalArgumentException with message "Operation cannot be empty"

calculator.calculate(10, 1, "-");
// => throws IllegalOperationException with message "Operation '-' does not exist"
```

## 3. ゼロで割ったときにスローされる例外を処理する

Javaでは、ゼロで割ろうとすると`ArithmeticException`がスローされます。
`CalculatorConundrum.calculate()`メソッドを更新して、この例外をキャッチし、メッセージ`Division by zero is not allowed`と、キャッチした`ArithmeticException`を原因として持つ`IllegalOperationException`をスローします。

```java
calculator.calculate(512, 0, "/");
// => throws IllegalOperationException with message "Division by zero is not allowed"
```
