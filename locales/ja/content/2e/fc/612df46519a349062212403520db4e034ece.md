# はじめに

## 説明

`number`や`string`のようなプリミティブデータ型のほかに、JavaScriptには`object`という重要なデータ型があります。
オブジェクトはキーと値のペアの集まりです。
そのため、他の言語でマップや辞書と呼ばれるものとして使うことができます。

他の言語では、マップ内のすべての値が同じデータ型でなければならないことがよくあります。
JavaScriptでは、制限されるのはキーの型だけです。キーは文字列でなければなりません。
1つのオブジェクトの中の値は、異なる型を持つことができます。
値は数値のようなプリミティブ型だけでなく、配列、他のオブジェクト、さらには関数でもかまいません。
このため、オブジェクトは非常に汎用性が高く、JavaScriptの[オブジェクト指向プログラミング][oop]（OOP）においても中核となる要素です。

以下では、コレクションまたはマップとしてのオブジェクトに焦点を当てます。オブジェクトの他の用途については、別のコンセプトで扱います。たとえば、[クラス][concept-classes]を参照してください。

## オブジェクトの作成

波括弧（`{}`）を使ってオブジェクトを作成します。
いくつかのエントリを直接含めることもできます。
その場合は、最初にキーを書き、その後にコロンと値を続けます。

```javascript
const emptyObject = {};

const obj = {
  favoriteNumber: 42,
  greeting: 'Hello World',
  useGreeting: true,
  address: {
    street: 'Trincomalee Highway',
    city: 'Batticaloa',
  },
  fruits: ['melon', 'papaya'],
  addNumbers: function (a, b) {
    return a + b;
  },
};
```

最後のエントリの後ろにあるカンマは、JavaScriptでは省略できます。

キーは文字列であるはずなのに、なぜ引用符で囲まれていないのか不思議に思うかもしれません。
これは省略記法です。
キーがJavaScriptの[識別子][mdn-identifier]の命名規則に従っている場合は、引用符を省略できます。
名前に特殊文字を含むキーの場合は、通常の文字列記法を使う必要があります。

```javascript
const obj = {
  '1keyStartsWithNumber': '...',
  'key/with/slashes': '...',
  'key-with-dashes': '...',
  'key with spaces': '...',
  '#&()[]{}èä樹keyWithSpecialChars': '...',
};
```

## 値の取得

特定のキーの値を取得する方法は、ドット記法と角括弧（`[]`）記法の2通りがあります。

```javascript
const obj = { greeting: 'hello world' };

obj.greeting;
// => hello world

obj['greeting'];
// => hello world

// Bracket notation also works with variables.
const key = 'greeting';
obj[key];
// => hello world
```

ドット記法を省略形として使う場合、引用符を省略するときと同じ制限があります。
キーが識別子の命名規則に従っている場合にのみ機能します。
言い換えると、キーが英字だけの単一の単語でない場合は、角括弧記法を使う必要があります。

## 値の追加や変更

代入演算子`=`を使って値を追加または変更できます。
ここでも、ドット記法と角括弧記法を使えます。

```javascript
const obj = { greeting: 'hello world' };

obj.greeting = 'Hi there!';
obj['greeting'] = 'Welcome.';

obj.newKey1 = 'new value 1';
obj['new key 2'] = 'new value 2';

const key = 'new key 3';
obj[key] = 'new value 3';
```

## エントリの削除

`delete`キーワードを使って、オブジェクトからキーと値のペアを削除できます。

```javascript
const obj = {
  key1: 'value1',
  key2: 'value2',
};

delete obj.key1;
delete obj['key2'];
```

## キーの存在確認

`hasOwnProperty`メソッドを使うと、特定のキーがオブジェクトに存在するかどうかを確認できます。

```javascript
const obj = { greeting: 'hello world' };

obj.hasOwnProperty('greeting');
// => true

obj.hasOwnProperty('age');
// => false
```

## オブジェクトの繰り返し処理

オブジェクトのすべてのキーを繰り返し処理するための特別な`for...in`ループがあります。

```javascript
const obj = {
  name: 'Ali',
  age: 65,
};

for (let key in obj) {
  console.log(key, obj[key]);
}
// name Ali
// age 65
```

微妙なエラーを避けるために、`for...in`ループがキーを任意の順序で訪問すると常に想定してください。
また、`for...in`がその繰り返しに[継承されたキー][concept-inheritance]を含めることに注意してください。
