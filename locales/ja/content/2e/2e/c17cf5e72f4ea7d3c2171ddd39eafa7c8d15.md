# はじめに

慣用的なElixirコードでは、パターンマッチングを積極的に使います。`=/2`が代入演算子ではなくマッチ演算子と呼ばれていることを覚えているでしょうか。マッチ演算子を使うとき、左辺のパターンが右辺とマッチすれば、左辺の変数が束縛され、右辺の値が返されます。マッチしなければ、`MatchError`が発生します。

```elixir
2 = 2
# => 2
# Literals can be matched if they are the same

2 = 3
# => ** (MatchError) no match of right hand side value: 3

{_, denominator} = Float.ratio(0.25)
# => {1, 4}
# the variable `denominator` is bound to the value 4
```

マッチは右辺から左辺へと行われることを覚えておきましょう。

最後の例で、パターンマッチに不要な変数がある場合は、`_`を書くことでそれを捨てることができます。`_`で始まる変数は、ランタイムに追跡されません。

## 名前付き関数でのパターンマッチング

パターンマッチングは、複数の関数節を作るときにも役立つ仕組みです。パターンマッチングは関数の引数に使うことができ、どの関数節を呼び出すかは、ファイルの先頭から順に見て、最初にマッチした節で決まります。変数は関数ヘッドで束縛し、関数本体で使うことができます。

```elixir
defmodule Example do
  def named_function(:a = variable_a) do
    {variable_a, 1}
  end

  def named_function(:b = variable_b) do
    {variable_b, 2}
  end
end

Example.named_function(:a)
# => {:a, 1}

Example.named_function(:b)
# => {:b, 2}

Example.named_function(:c)
# => ** (FunctionClauseError) no function clause matching in Example.named_function/1
```
