# configletワークフロー

configletワークフローは、[configletツール](/docs/building/configlet)を使って、トラックの（設定）ファイルが構文的にも意味的にも正しく構成されているかをチェックします。
これは[`configlet lint`](/docs/building/configlet/lint)を実行することで行われます。

## ファイルのフォーマットチェックを有効にする

トラックでは、[`configlet fmt`](/docs/building/configlet/format)を使って、トラックのさまざまな設定ファイルをフォーマットできます。
同じコマンドは、すべての設定ファイルが正しくフォーマットされているかどうかのチェックにも使えます。

`configlet`ワークフローは、設定ファイルが正しくフォーマットされているかを検証できますが、これは任意で、デフォルトでは無効になっています。
設定ファイルのフォーマットの検証をオプトインするには、次の手順に従います。

1. 次の内容で`.github/org-wide-files-config.toml`ファイルを作成します

```toml
[configlet]
fmt = true
```

2. このファイルが`main`にマージされると、`configlet.yml`ワークフローを次のように変更するPRが自動的に開かれます。

```diff
  jobs:
    configlet:
      uses: exercism/github-actions/.github/workflows/configlet.yml@main
+     with:
+       fmt: true
```

3. このPRがマージされると、`configlet`ワークフローでもトラックの設定ファイルのフォーマットが検証されるようになります。

## ソース

ワークフローは`.github/workflows/configlet.yml`ファイルで定義されています。
