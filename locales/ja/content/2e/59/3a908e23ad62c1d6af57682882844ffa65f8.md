# はじめに

`readonly`修飾子は、フィールドの値や参照が上書きされるのを防ぎますが、参照型のメンバーを保護するものではありません。

```csharp
readonly List<int> ints = new List<int>();

void Foo()
{
    ints.Add(1);    // ok
    ints = new List<int>(); // fails to compile
}
```

参照型のメンバーをすべて保護するには、フィールドを`readonly`にして、`set`アクセサーのない自動プロパティを定義します。

基底クラスライブラリ（BCL）には、コレクションのメンバーが更新されないようにしたい場合のために、読み取り専用のコレクションが用意されています。これらはラッパーという形で提供されます。

- `ReadOnlyDictionary<T>`は、`Dictionary<T>`を読み取り専用として公開します。
- `ReadOnlyCollection<T>`は、`List<T>`を読み取り専用として公開します。
