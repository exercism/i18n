# はじめに

F#では、値に名前を割り当てることを_束縛_といいます。束縛は不変で、他の言語の定数のようなものです。F#は静的型付け言語なので、それぞれの束縛はコンパイル時に型を持ちます。

束縛は`let`キーワードを使って定義します。ほとんどの束縛では、型の指定は省略できます。F#の_型推論_が、通常は値から型を推測できるからです。束縛は次のように書きます。

```fsharp
// Automatically inferred type
let fingers = 10
```

関数も通常の束縛ですが、1つ以上の仮引数を持ちます。関数は自動的に最後の式を返します。型推論はほとんどの関数でも機能し、その関数がどんな値で呼び出され、どんな値を返すのかを分析して行います。

```fsharp
// Automatically inferred types for parameters and return type
let add x y = x + y
```

関数を呼び出すには、その名前を指定し、関数の仮引数それぞれに引数を渡します。

```fsharp
let five = add 2 3
```

束縛の型を推測できない場合、コンパイラーはエラーを報告します。これを解決するには、束縛に明示的な型注釈を追加します。

```fsharp
// Explicit type annotation
let fingers: int = 10

// Explicit type annotation (also for parameters)
let add (x: int) (y: int): int = x + y
```

F#の束縛は、定義された_後_でないと使えません。定義される前に束縛を使うと、コンパイルエラーになります。

```fsharp
// Compile error as the add binding has not yet been defined
// let seven = add 3 4

let add x y = x + y
```

F#では、スコープを定義するために空白の位置が意味を持ちます。つまり、束縛を宣言する行を基準にして、コードをスペースでインデントすることでスコープが定義されます。デフォルトの慣習では、インデントに4つのスペースを使います。

```fsharp
let toes =
    let left = 5
    let right = 5
    left + right

let multiplyPlusTwo x y =
    let product = x * y
    product + 2

// Trying to access the left, right or product bindings
// here would result in a compile error
```

F#の束縛（関数も含まれます）は、通常モジュールにまとめられます。モジュールは関連する機能をグループ化するもので、`module`キーワードを使って定義します。モジュールの定義は、その束縛より前に置く必要があります。

```fsharp
module Calculator

let pi = 3.14

let add x y = x + y
```

F#は2種類のコメントをサポートしています。1行コメントは`//`で始め、複数行コメントは`(*`と`*)`で囲みます。
