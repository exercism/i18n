# 説明

この演習では、Exercismで学びたいプログラミング言語の配列を管理するコードを書きます。

タスクは6つあり、どれも配列を扱います。

## 1. 新しい配列を作成する

学びたい言語を管理するには、新しい配列を作成する必要があります。新しい空の配列を返す`new_list`関数を定義しましょう。

```gleam
new_list()
// -> []
```

## 2. 既存の配列を定義する

今、学びたい言語を書き出した紙があります。Gleam、Go、TypeScriptです。この配列を返す`existing_list`関数を定義しましょう。

```gleam
existing_list()
// -> ["Gleam", "Go", "TypeScript"]
```

## 3. 配列に新しい言語を追加する

Exercismを見て回るうちに、もっと面白い言語が見つかります。そうした言語は配列に追加したくなります。配列の先頭に新しい言語を追加する`add_language`関数を実装しましょう。

```gleam
add_language(["OCaml", "Elixir"], "Scheme")
// -> ["Scheme", "OCaml", "Elixir"]
```

## 4. 配列にある言語の数を数える

言語を1つずつ数えるのは面倒です。配列にある言語の数を数える`count_languages`関数を実装しましょう。

```gleam
count_languages(["jq", "Elm", "Rust", "Kotlin"])
// -> 4
```

## 5. 配列を逆順にする

あるとき、配列の順番が実は逆になっていることに気づきます！　配列を逆順にする`reverse_list`関数を実装しましょう。

```gleam
reverse_list(["Python", "Julia", "Idris", "COBOL"])
// -> ["COBOL", "Idris", "Julia", "Python"]
```

## 6. 配列がわくわくするものかどうかをチェックする

どの言語も大好きですが、Gleamは心の中で特別な位置を占めています。それだけに、次の条件を満たす言語の配列には、とてもわくわくします。

- 配列の先頭がGleamです。
- 配列の2番目の項目がGleamで、しかも配列に含まれる言語が2つか3つです。

言語の配列がわくわくするものかどうかをチェックする`exciting_list`関数を実装しましょう。

```gleam
exciting_list(["Lua", "Gleam"])
// -> True
```
