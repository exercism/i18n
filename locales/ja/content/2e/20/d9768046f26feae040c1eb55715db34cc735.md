# 説明の補足

## 例外メッセージ

ときには[例外を送出する](https://docs.python.org/3/tutorial/errors.html#raising-exceptions)必要があります。そのときは、エラーの原因を示す**意味のあるエラーメッセージ**を必ず含めるようにしましょう。こうするとコードが読みやすくなり、デバッグもずっと楽になります。エラーの原因が特定のタイプだとわかっている場合は、[組み込みのエラータイプ](https://docs.python.org/3/library/exceptions.html#base-classes)のいずれかを送出するのもよいですが、その場合も意味のあるメッセージを含めるようにしてください。

この演習では、`board()`関数が不正な入力を受け取ったときに、[`raise`文](https://docs.python.org/3/reference/simple_stmts.html#the-raise-statement)を使って`ValueError`を「スロー」する必要があります。テストに通るのは、`exception`を`raise`し、かつメッセージを添えた場合だけです。

メッセージ付きで`ValueError`を送出するには、そのメッセージを`exception`型の引数として書きます。

```python
# when the board receives malformed input
raise ValueError("The board is invalid with current input.")
```
