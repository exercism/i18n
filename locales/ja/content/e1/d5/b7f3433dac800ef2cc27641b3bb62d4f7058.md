# はじめに

コードを整理するための重要な仕組みが、名前空間です。
2つの関数の名前が衝突してしまうことがありますが、それぞれを別の名前空間に入れれば解決できます。
名前空間は入れ子にすることもでき、大きなコードベースを構造化するのに役立つでしょう。
名前空間へのアクセスには、スコープ解決演算子`::`を使います。

次の例では、2つの異なる`foo`関数を使っています。
それぞれの名前空間を先頭に付けることで、2つの関数を一緒に使っています。

```cpp
namespace my_ns {
    int foo() {
        return 44;
    }
    namespace my_inner_ns {
        int baz() {
            return 90;
        }
    }
}
namespace my_other_ns {
    int foo() {
        return -2;
    }
}

int myresult{my_ns::foo() + my_other_ns::foo() * my_ns::my_inner_ns::baz()};
```
