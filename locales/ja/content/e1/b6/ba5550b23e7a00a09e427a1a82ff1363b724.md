# はじめに

## 数値

Goには、整数または浮動小数点の値の集合を表せる基本的な数値型があります。
必要な値の大きさや、アプリケーションが動作しているコンピューターのアーキテクチャ（32ビットや64ビットなど）によって、使う型が変わります。

この演習では、次の型だけを扱います。

- `int`：例：`0`、`255`、`2147483647`。
  少なくとも32ビットの符号付き整数です（値の範囲は-2147483648から2147483647まで）。
  ただし、これはシステムのアーキテクチャによって変わります。
  最近のほとんどのコンピューターは64ビットなので、`int`は64ビットになります（値の範囲は-9223372036854775808から9223372036854775807まで）。

- `float64`：例：`0.0`、`3.14`。
  すべての64ビット浮動小数点数の集合を表します。

- `uint`：例：`0`、`255`。
  `int`と同じサイズの符号なし整数です（値の範囲は、32ビットでは0から4294967295まで、64ビットでは0から18446744073709551615まで）。

数値は、型変換によって他の数値型に変換できます。

## 算術演算子

Goは、標準的な算術演算子を数多くサポートしています。

| 演算子 | 例             |
| -------- | -------------- |
| `+`      | `4 + 6 == 10`  |
| `-`      | `15 - 10 == 5` |
| `*`      | `2 * 3 == 6`   |
| `/`      | `13 / 3 == 4`  |
| `%`      | `13 % 3 == 1`  |

整数の除算では、余りは切り捨てられます（例：`5 / 2 == 2`）。

Goには、上記の演算子の省略記法があります（例：`a += 5`は`a = a + 5`の省略形です）。
Goは、インクリメント文とデクリメント文の`++`と`--`もサポートしています（例：`a++`）。

## 型の変換

型の変換は、変換先の型の名前を持つ関数を使って行います。
例えば：

```go
var x int = 42 // x has type int
f := float64(x) // f has type float64 (ie. 42.0)
var y float64 = 11.9 // y has type float64
i := int(y) // i has type int (ie. 11)
```

## 異なる型での算術演算

多くの言語では、異なる型の変数に対して算術演算を行えますが、Goではエラーになります。
例えば：

```go
var x int = 42

// this line produces an error
value := float32(2.0) * x // invalid operation: mismatched types float32 and int

// you must convert int type to float32 before performing arithmetic operation
value := float32(2.0) * float32(x)
```
