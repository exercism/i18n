# はじめに

TypeScriptは、型のための構文を備えたJavaScriptです。つまり、強い型付けのプログラミング言語であり、オブジェクト指向、命令型、宣言型（たとえば関数型プログラミング）といったスタイルをサポートし、どんな規模でも優れたツールの支援が得られます。

[TypeScriptを学ぶにはJavaScriptを学ぶ必要がある][handbook-js-or-ts]ため、このトラックの内容の一部はJavaScriptの概念の解説に重点を置いており、TypeScript固有の機能だけに焦点を当てた概念もあります。

## （再）代入

TypeScriptで名前に値を代入する主な方法は、いくつかあります。変数を使うか、定数を使うかです。
Exercismでは、変数は常に[camelCase][wiki-camel-case]で書き、定数は[SCREAMING_SNAKE_CASE][wiki-snake-case]で書きます。
従うべき公式のガイドがあるわけではなく、企業や団体によってさまざまなスタイルガイドがあります。
_変数の書き方は、好きなように書いてかまいません_。
演習が用意されているとおりに書くことの利点は、ウェブインターフェースやほとんどのIDEで、変数と定数が違う色でハイライトされることです。

TypeScriptでは、[`const`][mdn-const]、[`let`][mdn-let]、[`var`][mdn-var]のキーワードを使って変数を定義できます。

`let`や`var`を使うと、変数はその寿命の中で異なる値を参照できます。
たとえば`myFirstVariable`は、代入演算子`=`を使って何度も定義し直すことができます。

```typescript
let myFirstVariable = 1
myFirstVariable = 0
myFirstVariable = 42
```

`let`や`var`とは対照的に、`const`で定義した変数は一度しか代入できません。
TypeScriptでは、これを使って定数を定義します。

```typescript
const MY_FIRST_CONSTANT = 10

// Can not be re-assigned.
MY_FIRST_CONSTANT = 20
// => TypeError: Assignment to constant variable.
```

TypeScriptはこれを静的に検出できるので、TypeScriptコンパイラーもエラーを出します。

```typescript
// ^? Cannot assign to 'MY_FIRST_CONSTANT' because it is a constant.(2588)
```

つまり、`TypeError`を検出するためにコードを実行する必要はありません。

## 型推論

[型推論][handbook-type-inference]について深く掘り下げるのは避けますが、型注釈がなくても、代入された変数には通常、推論された型が付くことを知っておいてください。

```typescript
const MY_FIRST_CONSTANT = 10
// ^? const MY_FIRST_CONSTANT: number
```

この型は、その後コード全体で強制されます。
つまり、次のコードがJavaScriptとして有効であっても、

```javascript
let myFirstVariable = 1
myFirstVariable = 'Some string'
```

TypeScriptではエラーになります。

```typescript
let myFirstVariable = 1
myFirstVariable = 'Some string'
// ^? Type 'string' is not assignable to type 'number'.(2322)
```

この機能により、型注釈を使わなくても型の安全性が保たれます。

## 関数宣言

TypeScriptでは、機能のまとまりは_関数_にカプセル化されます。関連する関数は、通常は同じファイルにまとめます。
これらの関数は仮引数（引数）を受け取り、`return`キーワードを使って値を_返す_ことができます。
関数は`()`という構文で呼び出します。

```typescript
function add(num1: number, num2: number): number {
  return num1 + num2
}

add(1, 3)
// => 4
```

関数の仮引数には、通常、コロン（`:`）に続けて型を書くことで、型注釈を付けます。
関数の戻り値には、仮引数リストを閉じたあとに、コロン（`:`）に続けて型を書いて注釈を付けられます。

## 型注釈

`add`の関数宣言で見たとおり、仮引数には明示的な型注釈`: number`が付いています。
変数宣言、クラスのプロパティ、関数宣言など、さまざまな場所で型注釈を使えます。

明示的な型注釈も、推論された型も、どちらも型チェッカーによって強制されます。

```typescript
add('foo', 3)
// ^? Argument of type 'string' is not assignable to parameter of type 'number'.(2345)
```

## 他のファイルへの公開

`function`や定数、変数を_他のファイル_から使えるようにするには、`export`キーワードを使って[エクスポート][mdn-export]する必要があります。
別のファイルは、`import`キーワードを使ってこれらを[インポート][mdn-import]できます。
これはモジュールシステムとも呼ばれます。
良い例が、すべてのテストの仕組みです。
各演習には、少なくとも1つのファイルがあります。たとえば`lasagna.ts`で、これが_実装_を含みます。
さらに、少なくとももう1つのファイル、たとえば`lasagna.test.ts`があり、これが_テスト_を含みます。
このファイルは、実装をテストするために、公開された（つまりエクスポートされた）ものを_インポート_します。

```typescript
// file.ts
export const MY_VALUE = 10

export function add(num1, num2) {
  return num1 + num2
}

// file.test.ts
import { MY_VALUE, add } from './file.js'

add(MY_VALUE, 5)
// => 15
```
