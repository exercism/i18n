# テスト

`${slug}`は演習名です。スペースの代わりにハイフンを使い、すべて小文字で書きます（たとえば`Hello World`の演習なら`hello-world_test.sql`です）。該当する`${slug}_test.sql`ファイルがあるディレクトリに移動してください。

```bash
sqlite3 -bail < ${slug}_test.sql
```

デバッグには`SELECT`文を使えます。
テストが失敗すると、その出力は`user_output.md`に渡され、ウェブエディターに表示されます。

詳しくは、[SQLiteトラックのテストに関するドキュメント](https://exercism.org/docs/tracks/sqlite/tests)を参照してください。
