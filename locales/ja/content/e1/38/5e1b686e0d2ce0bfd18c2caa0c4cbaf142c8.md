# 概要

## 一般的な構文

`for`ループは、同じ処理を繰り返し実行するための最もよく使われる文の1つです。
Goでは、`for`キーワード、ヘッダー、そして波括弧で囲まれたループ本体を含むコードブロックからなります。
ヘッダーは、セミコロン`;`で区切られた3つの要素、init・condition・postで構成されます。

```go
for init; condition; post {
  // loop body - code that is executed repeatedly as long as the condition is true
}
```

- **init**の要素は、ループが始まる前に一度だけ実行されるコードです。
- **condition**の要素は、`true`か`false`に評価され、ループをいつ止めるかを制御する式でなければなりません。
  この条件が`true`と評価される限り、ループ内のコードが実行されます。
  この式が`false`と評価されるとすぐに、ループの繰り返しはそれ以上実行されません。
- **post**の要素は、各繰り返しの最後に実行されるコードです。

**注意:** 他の言語とは異なり、ヘッダーの3つの要素を囲む括弧（`()`）はありません。
実際、そのような括弧を書くとコンパイルエラーになります。
ただし、ループ本体を囲む波括弧（`{ }`）は常に必要です。

## `for`ループの例

通常、initの要素ではカウンター変数を用意し、conditionではループを続けるか止めるかを判定し、postでは各繰り返しの最後にカウンターを増やします。

```go
for i := 1; i < 10; i++ {
  fmt.Println(i)
}
```

このループは`1`から`9`までの数値を出力します（`9`も含みます）。
ステップの指定は、上の例のようにインクリメントやデクリメントの文で行うことがよくあります。

## 省略できるヘッダーの要素

ヘッダーのinitとpostの要素は省略できます。

```go
var sum = 1
for sum < 1000 {
	sum += sum
}
fmt.Println(sum)
// Output: 1024
```

上の例のように`for`ループでinitとpostの要素を省略すると、Goでは`while`ループを作ることになります。
`while`キーワードはありません。
これは、概念は直交しているべきだというGoの原則の一例です。
`while`ループの動作を実現する概念、つまり`for`ループがすでにあるため、`while`は追加の概念として採用されませんでした。

## `break`と`continue`

ループ本体の中では、`break`キーワードを使ってループの実行を完全に止めることができます。

```go
for n := 0; n <= 5; n++ {
  if n == 3 {
    break
  }
  fmt.Println(n)
}
// Output:
// 0
// 1
// 2
```

一方、`continue`キーワードは、現在の繰り返しの実行だけを止め、次の繰り返しへ進みます。

```go
for n := 0; n <= 5; n++ {
  if n%2 == 0 {
    continue
  }
  fmt.Println(n)
}
// Output:
// 1
// 3
// 5
```

## 無限`for`ループ

ループのヘッダーのconditionの部分も省略できます。
実際、ヘッダーをまったく書かないループも作れます。

```go
for {
  // Endless loop...
}
```

このループは、プログラムが終了するか、本体に`break`がある場合にだけ終わります。

## ラベルと`goto`

`break`を使うと、Goは最も内側のループの実行を止めます。
同様に、`continue`を使うと、Goは最も内側のループの次の繰り返しを実行します。

しかし、いつもこれでよいとは限りません。
ラベルを`break`や`continue`と組み合わせると、どのループから抜けたいのか、あるいはどのループを続けたいのかを正確に指定できます。

次の例では、最も外側のループを指す`OuterLoop`というラベルを作ります。
最も内側のループの中で、最も外側のループから抜けたいことを示すには、`break`の後に最も外側のループのラベルの名前を書きます。

```go
OuterLoop:
    for i := 0; i < 10; i++ {
        for j := 0; j < 10; j++ {
            // ...
            break OuterLoop
        }
    }
```

ラベルを`continue`と組み合わせても同じように機能し、その場合は、ラベルが指すループの次の繰り返しへ進みます。

Goには、同様に機能する`goto`キーワードもあり、あるコードからラベルを付けた別のコードへジャンプできます。

**警告:** Goではラベルを付けたコードへジャンプできますが、この言語機能を使うとコードが非常に読みにくくなりがちです。
そのため、ラベルの使用はあまりおすすめされません。
