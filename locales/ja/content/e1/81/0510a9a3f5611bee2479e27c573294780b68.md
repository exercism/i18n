# 概要

[`while`ループ][while-loops]は、ある条件が真である間、コードを実行し続けることのできる制御フローの文です。Swiftには、`while`ループと`repeat-while`ループの2種類があります。`while`ループでは、条件はループ本体が実行される前に評価されます。条件が偽であれば、ループ本体は一度も実行されません。Swiftの`while`ループは、次のような構造になっています。

```swift
while <#condition#> {
  <#code#>
}
```

このコードでは、`count`が0より大きい間ループが実行され、その結果、2、1、"Liftoff!"と出力されます。

```swift
var count = 2
while count > 0 {
  print("\(count)…")
  count -= 1
}
print("Liftoff!")

// prints:
// 2…
// 1…
// Liftoff!
```

[`repeat-while`ループ][while-loops]は`while`ループと似ていますが、条件はループ本体が実行された後に評価されます。つまり、条件が偽であっても、ループ本体は必ず少なくとも1回は実行されます。Swiftの`repeat-while`ループは、次のような構造になっています。

```swift
repeat {
  <#code#>
} while <#condition#>
```

ここでは、条件が偽なので、ループは1回だけ実行されます。`repeat-while`ループなので、ループ本体は条件が評価される前に1回実行されます。

```swift
var count = 2
repeat {
  print("\(count)…")
} while count < 0
print("Liftoff!")
```
