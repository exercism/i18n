# はじめに

## 名前空間

名前空間は、関連するコードをまとめ、名前の衝突を避けるための仕組みで、ごく単純なコードベースを除けば、たいていのコードに登場します。

構文は次のとおりです:

```csharp
namespace MyNameSpace
{
    public class MyClass {}

    public class OtherClass {}
}
```

名前空間に含まれる型を、その名前空間のスコープの外から参照するには、ドット構文を使って型名の前に名前空間名を付けます。あるいは、もっとよく使われる方法として、ファイルの先頭（または名前空間の中）に`using`ディレクティブを書けば、接頭辞を付けずに型を使えます。同じ名前空間の中では、型名を修飾する必要はありません。

```csharp
namespace MySpace
{
    public class MyClass {}

    public class Foo
    {
        public void Bar()
        {
            var baz = new MyClass();
        }
    }
}

public class Qux
{
    public void Box()
    {
        var nux = new MySpace.MyClass();
    }
}

namespace OtherSpace
{
    using MySpace;

    public class Tix
    {
        public void Jeg()
        {
            var lor = new MyClass();
        }
    }
}
```

名前空間には、`using MyAlias = MySpace;`という構文で別名を付けられます。そうすれば、その名前空間を使える場所ならどこでも、その別名を使えます。
