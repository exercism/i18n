# はじめに

`Tuple`は、多くの点で`Vector`（1次元の`array`）とよく似ています。
ただし、いくつか重要な違いがあります。

- タプルは角括弧`[ ]`ではなく、丸括弧`( )`で書きます。ただし、意味が曖昧でない場合は、丸括弧を省略できます。
- タプルは同じ型である必要はありません。各要素の型は個別に保持されます。
- タプルはイミュータブルです。

イミュータブルであることにより、コンパイラーによる最適化がより多く行われ、タプルはベクトルよりも性能が高くなります。そのため、可変である必要がない場合は、タプルを選ぶとよいでしょう。

```julia-repl
julia> t = (3, 5.2, "xyz")
(3, 5.2, "xyz")

# Non-homogeneous:
julia> dump(t)
Tuple{Int64, Float64, String}
  1: Int64 3
  2: Float64 5.2
  3: String "xyz"

julia> t[2]
5.2

# Immutable:
julia> t[2] = 7.3
ERROR: MethodError: no method matching setindex!(::Tuple{Int64, Float64, String})
```

`Tuple()`というコンストラクターもあり、これは任意の反復可能なコレクションをタプルに変換します。便利なことに、文字列は文字の反復可能なコレクションとして扱われます。

```julia-repl
julia> Tuple("Julia")
('J', 'u', 'l', 'i', 'a')
```

どのタプルでも、インデックスで要素にアクセスしたり、ループで要素を順に取り出したりできます。

数値だけからなるタプルは、配列とまったく同じように、`sum()`などの数学関数で使うこともできます。

## アンパック

タプルは、多重代入を使うことで個々の要素にアンパックできます。
必要のない要素には、ダミー変数としてアンダースコア`_`を使います。

```julia-repl
julia> tup = (1, "Julia", true)
(1, "Julia", true)

julia> num, name, _ = tup
(1, "Julia", true)

julia> uppercase(name), 2num
("JULIA", 2)
```

Pythonを使っている人なら、この多重代入の構文にはとても馴染みがあるでしょう。

## 名前付きタプル

`Tuple`は値だけを持ちます。
`NamedTuple`は、それぞれの値に名前を組み合わせたものです。

個々のフィールドには、ドット記法でアクセスできます。

```jullia-repl
julia> nt = (a = 1, b = 7.3)
(a = 1, b = 7.3)

julia> dump(nt)
@NamedTuple{a::Int64, b::Float64}
  a: Int64 1
  b: Float64 7.3

julia> nt.b
7.3
```

名前は内部的には`Symbol`（イミュータブルな型で、コロン`:`が先頭に付きます）として保持されるため、別の構文も使えます。

```julia-repl
julia> nt[:b]
7.3
```

名前（「キー」とも呼ばれます）だけ、あるいは値だけを別々に取り出すのは簡単です。

```julia-repl
julia> nt
(a = 1, b = 7.3)

julia> keys(nt)
(:a, :b)

julia> values(nt)
(1, 7.3)
```

名前付きタプルを繰り返し処理しても取り出せるのは_値_だけで、_名前_は無視されることに注意してください。

タプルは（名前付きかどうかに関わらず）、構造化されたデータを関数に渡したり、関数から受け取ったりするためによく使われる方法です。
このような用途ではイミュータブルであることが役立ち、データの安全性を確保し、コンパイラーによるより積極的な最適化を可能にします。
