# 演習の補足

## 自分だけのDSLを作りましょう

この演習では、思いどおりのグラフDSLを自由に設計できます。

テストが求めているのは、いくつかの特定のグラフを作ることだけです。それをどう組み立てるかは、完全に自由です。

もっと楽しみたいなら、グラフをDOT形式に変換する`to_dot`関数の実装にも、ぜひ挑戦してみてください！

## グラフの表現

DSLは`Graph.roc`で定義し、そのDSLを使って、スタブが要求するグラフを組み立てます。各`EdgeId`に含まれる2つのノードIDは、アルファベット順に並べる必要があります。

| 定義 | 作るグラフ |
| --- | --- |
| `empty_graph` | 空のグラフ |
| `graph_with_one_node` | ノード1つ |
| `graph_with_one_node_with_attribute` | 属性を1つ持つノード |
| `graph_with_one_edge` | 辺1つ |
| `graph_with_one_attribute` | グラフの属性1つ |
| `graph_with_nodes_edges_and_attributes` | ノード、辺、属性 |
| `multiple_edges_on_one_line` | 1行にまとめて書いた複数の辺 |
| `only_1_edge_between_nodes` | 各ノードのペアの間に辺は1つだけ |
