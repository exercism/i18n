# 指示

鳥が大好きなバードウォッチャーで、毎日庭に何羽の鳥がやって来たかを記録しています。

せっかくなので、バードウォッチングを次のレベルに引き上げることにしました。データの記録と処理に役立つツールをいくつか実装することにしたのです。

データは整数の配列として保存することにしました。配列の最初の数値は今日庭に来た鳥の数、2番目は昨日の数、そのあとも同じように続きます。

## 1. 今日来た鳥の数を確認する

`BirdCount.today/1`関数を実装しましょう。日々の鳥の数の配列を受け取り、今日の数を返すようにします。配列が空の場合は、`nil`を返します。

```elixir
BirdCount.today([2, 5, 1])
# => 2
```

## 2. 今日の数を増やす

`BirdCount.increment_day_count/1`関数を実装しましょう。日々の鳥の数の配列を受け取り、今日の数を1増やします。配列が空の場合は、`[1]`を返します。

```elixir
BirdCount.increment_day_count([4, 0, 2])
# => [5, 0, 2]
```

## 3. 鳥が1羽も来なかった日があったかどうかを確認する

`BirdCount.has_day_without_birds?/1`関数を実装しましょう。日々の鳥の数の配列を受け取ります。庭に鳥が1羽も来なかった日が少なくとも1日あれば`true`を、なければ`false`を返します。

```elixir
BirdCount.has_day_without_birds?([2, 0, 4])
# => true

BirdCount.has_day_without_birds?([3, 8, 1, 5])
# => false
```

## 4. 訪れた鳥の合計数を計算する

`BirdCount.total/1`関数を実装しましょう。日々の鳥の数の配列を受け取り、データを集め始めてから庭に来た鳥の合計数を返します。

```elixir
BirdCount.total([4, 0, 9, 0, 5])
# => 18
```

## 5. 忙しかった日の数を計算する

日によっては、ほかの日より忙しいこともあります。忙しい日とは、庭に5羽以上の鳥が来た日のことです。

`BirdCount.busy_days/1`関数を実装しましょう。日々の鳥の数の配列を受け取り、忙しかった日の数を返します。

```elixir
BirdCount.busy_days([4, 5, 0, 0, 6])
# => 2
```
