# 概要

## 継承

Javaは継承を中心的な機能としてサポートしていて、継承を使うことで、抽象化をはじめとする多くのオブジェクト指向の原則を実現できます。

クラスは`extends`キーワードを使って別のクラスを継承でき、`implements`キーワードを使ってインターフェースを実装できます。

## アクセス修飾子

アクセス修飾子は、クラスのメンバー変数やメソッドを、他のクラス（あるいはコードのどこか）からアクセスできるかどうかに関するルールを定めます。

アクセス修飾子は次の4つです。

- `private`
- `public`
- `protected`
- デフォルト（キーワードは不要）

これらについては、[こちらの記事][access-modifiers]で詳しく読むことができます。

## 継承とコンポジション

これらの概念はとてもよく似ていて、しばしば混同されます。

- 継承とは、子クラスが親クラスとIS-A関係にあることを意味します。

```java
interface Animal() {
    public void bark();
}

class Dog implements Animal {
    public void bark() {
        System.out.println("Bark");
    }
}
```

ここでは、`Dog`は`Animal`とのIS-A関係にあります。

- コンポジションはHAS-A関係を表します。

```java
interface Engine {

}

class Car {
    private Engine engine;
}
```

ここでは、`Car`は`Engine`とのHAS-A関係にあります。
