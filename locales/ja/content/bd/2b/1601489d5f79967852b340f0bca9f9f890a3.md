# はじめに

`Result`型を使うと、関数は1つの値を返すだけで、次のことをすべて伝えられます:

- 操作が成功したか失敗したか
- 成功したときは、操作の結果の値
- 失敗したときは、失敗の理由

## 使い方

`Result`は、2つの型を内部に持つジェネリック型です:

- 操作が成功したときの結果の値の型
- 失敗したときの理由を表す型

`Result`型は[判別共用体][discriminated-union]でもあり、次のケースが考えられます:

- 成功した結果を表す`Ok <value>`
- 失敗を表す`Error <reason>`

次の関数は、`Result`の値を作る方法を示しています:

```fsharp
let validateName (name: string) : Result<string, string> =
    match name with
    | null -> Error "Name not found."
    | "" -> Error "Name is empty."
    | _ -> Ok name
```

この例では、`Ok`の値は文字列（渡された名前）で、`Error`の値も文字列です（エラーの原因を、人が読める形で表したもの）。

## `Result`の値の中身を読む

次の型定義と関数シグネチャを見てみましょう:

```
type FileOpenError =
| NotFound
| AccessDenied
| FileLocked

let openFile (filename: string) : Result<int, FileOpenError> =
```

`openFile`関数を呼び出すコードは、パターンマッチングを使って成功と失敗のケースを処理できます。次の例を見てみましょう:

```fsharp
match openFile(filename) with
| Ok handle -> doSomethingWithFile(handle)
| Error NotFound -> printfn $"Error: file {filename} was not found."
| Error AccessDenied -> printfn $"Error: you do not have permission to open the file {filename}."
| Error FileLocked -> printfn $"Error: file {filename} is already in use."
```
