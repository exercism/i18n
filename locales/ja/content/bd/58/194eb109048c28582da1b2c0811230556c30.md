# はじめに

_文字列_は、テキストデータを保存するためのJavaScriptのデータ型です。

## 文字列の作成

文字列を作るには、テキストをシングルクォートかダブルクォートで囲みます。
Exercismでは、シングルクォートを使います。

<!-- prettier-ignore-start -->
```javascript
'Hello, World!'
"Hello, World!"
```
<!-- prettier-ignore-end -->

## 文字の配列としての文字列

文字列は、最初の文字のインデックスが`0`である、文字の配列として扱うことができます。
文字列の個々の文字には、角括弧（`[]`）と、取り出したい文字のインデックスを使ってアクセスできます。

```javascript
'cat'[1];
// => 'a'
```

文字列の文字数は、`length`プロパティで調べることができます。

```javascript
'cat'.length;
// => 3
```

## 連結とメソッド

文字列を連結する最も簡単な方法は、加算演算子`+`を使うことです。

```javascript
'I like' + ' ' + 'cats.';
// => "I like cats."
```

文字列には便利なメソッドがたくさん用意されています。一覧は[MDNの文字列メソッドのドキュメント][mdn-string-methods]を参照してください。
よく使うものを以下に示します。

- [`toUpperCase`][mdn-to-upper-case]と[`toLowerCase`][mdn-to-lower-case]：すべての文字の大文字・小文字を変換します
- [`trim`][mdn-trim]：先頭と末尾の空白を削除します
- [`includes`][mdn-includes]、[`startsWith`][mdn-starts-with]と[`endsWith`][mdn-ends-with]：ある文字列が、与えられた文字列の一部かどうかを判定します
- [`slice`][mdn-slice]：文字列の一部を取り出します

JavaScriptの文字列はイミュータブルです。そのため、上のメソッドなどによる「変更」では、常に新しい文字列が作られます。
