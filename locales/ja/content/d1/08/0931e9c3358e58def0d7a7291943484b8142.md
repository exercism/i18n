# ループについて

Bashのループには2つの形式があります。

* 項目のリストの_各項目に対して_、いくつかのコマンドを繰り返す
* _ある条件が真（または偽）の間_、いくつかのコマンドを繰り返す

## `for`ループ

項目のリストを繰り返し処理するには、`for`ループを使います。

```bash
for varname in words; do COMMANDS; done
```

`words`は、単語分割とファイル名展開（[引用のコンセプト][quoting]で学びました）によって展開されます。
各単語は順番に`varname`へ代入され、COMMANDSが実行されます。

`for`ループが役立つのはどんなときか、例を見てみましょう。

* 複数のファイルに対してコマンドを実行する。

    ```bash
    # source all the bash library files in the current directory
    for file in ./*.bash; do
        source "$file"
    done
    ```

* スクリプトや関数の各引数に対してコマンドを実行する。

    ```bash
    for arg in "$@"; do
        echo "argument: ${arg}"
    done
    ```

* コマンドの出力を空白で区切った単語ごとにコマンドを実行する。

    ```bash
    for i in $(seq 10); do
        echo "${i} squared is $((i * i))"
    done
    ```

    この書き方の注意点は、後ほど見ていきます。

### 算術`for`ループ

Bashには算術ループもあります。
他のプログラミング言語を触ったことがあれば、どこか見覚えがあるでしょう。

```bash
for ((INITIALIZATION; CONDITION; INCREMENT)); do COMMANDS; done
```

bashの二重括弧（`(( ))`）は算術コンテキストを表します（bashの算術については、後のコンセプトで詳しく見ていきます）。
先ほどの`seq`を使った例は、次のように書けます。

```bash
for ((i = 1; i <= 10; i++)); do
    echo "${i} squared is $((i * i))"
done
```

### `for`を使うべきでないとき

[`for`で行を読み込んではいけません][bashfaq1]。

よく見かけるアンチパターンがあります。`cat`の出力を繰り返し処理する、というものです。

```bash
for line in $(cat some.file); do 
    do_something_with "$line"
done
```

これには2つの問題があります。

1. コマンド置換が引用符で囲まれていないため、単語分割の対象になります。
   単語分割は、既定では改行だけでなく_空白_でも分割します。
   この`for`ループは、ファイルの行ではなく、ファイル内の**単語**を繰り返し処理しています。
2. コマンド置換が引用符で囲まれていないため、ファイル名展開の対象になります。
   ファイル内のすべての単語が、グロブパターンとして照合されます。

[引用のコンセプト][quoting]で学んだように、単語分割は`IFS`変数で制御でき、ファイル名展開はオフにできます。
しかし、これは壊れやすい解決策になりがちです。
ファイルの行を繰り返し処理するのに、`for`は適した方法ではありません。
ファイルを読むための定石は、`while`ループを使うことです。

## `while`ループ

ある条件が真の_間_、一連のコマンドを繰り返すには`while`を使います。

```bash
while CONDITION_COMMANDS; do COMMANDS; done
```

`if`のときと同じように（[条件分岐のコンセプト][conditionals]で学びました）、CONDITION_COMMANDSに特別な構文はありません。
コマンドリストの終了ステータスが「真」か「偽」かを決めます。

## ループの制御

`break`コマンドはループから抜け出します。
制御は、ループの終わりを示す`done`の次のコマンドに移ります。

`continue`コマンドは、ループの次の繰り返しに進みます。

## ファイルの行を読み込む

すでに触れましたが、ファイルを読むための定石は`while`ループです。

```bash
while IFS= read -r line; do
    do_something_with "$line"
done < some.file
```

* ファイルの内容は、`<`リダイレクトによってループへの入力として渡されます。
* `read`コマンドは、入力から1行を完全に読み込めると「真」を返します。
  入力を使い切ったとき、または最後の行が改行で終わっていない場合、`read`は「偽」を返します。
  * 最後の行が改行で終わっていなくてもファイルの行を読み込む、_本当に_定石と言える方法は次のとおりです。

    ```bash
    while IFS= read -r line || [[ -n "$line" ]]; do ...
    ```

* `-r`オプションは、`read`にバックスラッシュのシーケンスを置換しないよう指示します。バックスラッシュは、ただの普通の文字として扱われます。
* `IFS=`は、`read`コマンドが実行されている間だけIFSに空文字列を代入します。
  これにより単語分割が一時的にオフになり、読み込んだ行の先頭や末尾の空白がそのまま保たれます。

## `until`

`until`構文は、ある条件が**偽**の間、一連のコマンドを繰り返します。
ループは、条件が真になる_まで_繰り返されます。

```bash
until CONDITION_COMMANDS; do COMMANDS; done
```

`until`を使うことはほとんどありません。
むしろ、条件を否定した`while`ループを使うほうが一般的です。

```bash
while ! CONDITION_COMANDS; do ...
```

## 無限ループ

ずっと繰り返したいこともあります。
その方法は2つあります。

1. 常に成功の終了ステータスになる条件を指定した`while`ループ

    ```bash
    while true; do ...
    ```

2.  式を空にした算術`for`ループ

    ```bash
    for ((;;)); do ...
    ```

## do-while

do-while構文は明示的には用意されていませんが、同じ効果を得ることはできます。

```bash
while true; do
    COMMANDS

    if END_CONDITION; then
        break
    fi
done
```
