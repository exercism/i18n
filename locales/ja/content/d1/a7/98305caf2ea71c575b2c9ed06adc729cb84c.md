# はじめに

リストはElixir言語に組み込まれています。基本的な型とされ、角括弧（`[]`）で表します。リストは空の場合もあれば、任意の型の要素をいくつでも保持できます。例えば次のとおりです。

```elixir
empty_list = []
one_item_list = [1]
two_item_list = [1, 2]
multiple_type_list = [1, :pi, 3.14, "four"]
```

Elixirはリストを連結リストとして実装しています。各ノードは2つの値、つまり先頭の要素と、残りのすべての要素を持つ別のリストを保持します。リストの最初の要素を_先頭_、残りの要素のリストを_末尾_と呼びます。この記法はコードの中で次のように使えます。

```elixir
# [1] represented in [head | tail] notation
[1 | []]

# [1, 2, 3] represented in [head | tail] notation
[1 | [2 | [3 | []]]]
```

_`[head | tail]`_記法を使うと、リストの先頭に要素を追加できます。

```elixir
# Suppose
list = [2, 1]

[3, 2, 1] == [3 | list]
# => true
```

リストを扱うための関数は`Kernel`モジュールにいくつかあり、さらに`List`モジュール全体も用意されています。

```elixir
# Check if 1 is a member of the list
1 in [1, 2, 3, 4]
# => true
```
