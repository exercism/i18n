# はじめに

多くのプログラミング言語には、存在しない値を表すために`null`や`none`のような仕組みがあります。
Juliaは、大量の（しばしば雑然とした）データを扱えるように設計されているため、「何もない」ことを表す形をいくつも持っています。

全体としてのねらいは、欠けていたり怪しかったりする値に出会った時点でそれに印を付け、例外を発生させずにそのまま処理を続けることです。

## `nothing`

値が本当に存在しない場合は、`nothing`で表します。これはおそらく、Cの`NULL`やPythonの`None`がすることに最も近いでしょう。

```julia-repl
julia> n = nothing

julia> isnothing(n)
true

julia> typeof(n)
Nothing
```

つまり`nothing`は`Nothing`型の唯一の値であり、それが`nothing`かどうかを判定できます。

`nothing`はよく、副作用（出力やネットワーク設定など）のためだけに使われる関数の戻り値（値がないこと）として使われます。

## `missing`

値が理屈の上では存在するけれど、それが何なのかわからない、という状況では`missing`を使います。たとえば、道路を走る車を数えるとき、人間の観測者が休憩を必要とすることもあれば、自動センサーが故障することもありますが、交通は流れ続けます。

このように`missing`はプレースホルダーであり、データのこの空白をどう扱うかを決める必要がある、と人間に警告します。

```julia-repl
julia> mv = [1, 2, missing]
3-element Vector{Union{Missing, Int64}}:
 1
 2
  missing

julia> typeof(mv)
Vector{Union{Missing, Int64}} (alias for Array{Union{Missing, Int64}, 1})

julia> ismissing.(mv)  # broadcast function, displays as 1 for true, 0 for false
3-element BitVector:
 0
 0
 1
```

ほかの言語でこの機能が組み込みになっているものはほとんどありませんが、近いものとしてはRの`NA`やSQLの`NULL`があります。

式の中に`missing`の値があると、通常はその式もデフォルトで`missing`を返します。こうした値を無視したい場合は、`skipmissing()`関数を使って、そのことを明示します。

```julia-repl
julia> mv = [1, 2, missing]
3-element Vector{Union{Missing, Int64}}:
 1
 2
  missing

julia> sum(mv)  # missing in, missing out
missing

julia> skipmissing(mv)
skipmissing(Union{Missing, Int64}[1, 2, missing])

julia> collect(skipmissing(mv))
2-element Vector{Int64}:
 1
 2

julia> sum(skipmissing(mv))  # functions like sum() can work with iterators
3
```

`skipmissing`はイテレーターを作るので、ベクターが必要なときは`collect()`で包みます。

`missing`の値を何らかのデフォルト値で置き換えると便利なこともあります。`@coalesce()`マクロがこれに役立ち、最初の`missing`ではない値（ほかに何もなければ`missing`）を返します。

```julia-repl
julia> str = ["I", "exist", missing]
3-element Vector{Union{Missing, String}}:
 "I"
 "exist"
 missing

julia> [@coalesce(s, "-") for  s in str]
3-element Vector{String}:
 "I"
 "exist"
 "-"
```

## `NaN`

"Not a Number"（数ではない）の略で、NaNは数値が期待される場面での計算上の問題に印を付けます。

```julia-repl
julia> v = [0, 1, -1]
3-element Vector{Int64}:
  0
  1
 -1

julia> v / 0
3-element Vector{Float64}:
 NaN
  Inf
 -Inf
 
julia> sum(v / 0)
NaN
```

NaNを含むデータに対してどんな計算をしても、結果は`NaN`になります。

現在、`NaN`の値を取り除く専用の関数はありませんが、標準の`filter()`関数を使えばごく簡単にできます。与えられた条件が`true`になる値だけが、結果の配列にコピーされます。

```julia-repl
julia> filter(!isnan, [1, 2, NaN])
2-element Vector{Float64}:
 1.0
 2.0
```
