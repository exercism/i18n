# 説明の補足

## ヒント

与えられた入力に対してボブの返答を返す`responseFor`関数を実装してください。型がわからない場合は、用意されているシグネチャを使ってもかまいませんが、それを創造性の制約にしないでください。

```haskell
responseFor :: String -> String
```

この演習を解くために、次の資料を読むとよいでしょう。

- [ガード][guards]

[guards]: https://www.futurelearn.com/courses/functional-programming-haskell/0/steps/27226

この演習では、テキストデータを扱います。歴史的な理由から、Haskellの`String`型は文字のリストである`[Char]`と同じ意味です。テキストデータをより効率的に扱うには、`Text`型を使うこともできます。

この演習の発展として、任意で次のこともできます。

- Haskellの[文字列型](https://haskell-lang.org/tutorial/string-types)について読んでみましょう。
- package.yamlの依存関係のリストに`- text`を追加しましょう。
- [次のように](https://hackernoon.com/4-steps-to-a-better-imports-list-in-haskell-43a3d868273c)`Data.Text`をインポートしましょう。

    ```haskell
    import qualified Data.Text as T
    import           Data.Text (Text)
    ```

- これで、例えば`responseFor :: Text -> Text`と書いたり、`Data.Text`のコンビネータを`T.isSuffixOf`のように参照したりできるようになります。
- [`Data.Text`](https://hackage.haskell.org/package/text/docs/Data-Text.html)のドキュメントを調べてみましょう、
- その後、Bob.hsの中にあるすべての`String`を`Text`に置き換えることができます。

    ```haskell
    responseFor :: Text -> Text
    ```

この部分は完全に任意です。
