# テストの実行

`sbt`をインストールしておくと、コマンドラインから次のようにテストを実行できます。

```bash
$ sbt test
```

ただし、毎回`sbt test`を実行すると、呼び出すたびに`sbt`が初期化されるため、遅くなります。

`sbt`はシェルのように動作し、一度起動すればその中でコマンドを実行できます。

たとえば、`sbt`を使えば、ソースファイルが変更されるたびにテストを再実行できます。

```bash
$ sbt
>~ test
```

なお、最初のテスト以外はすべて無効になっていますので、まずはそのテストから取り組めます。
次のテストに進むには、各テストケースの先頭にある`pending`キーワードを削除するだけです。

`sbt`について詳しくは、[こちら](https://www.scala-sbt.org/)をご覧ください。


テストは、以下の統合開発環境（IDE）でも実行できます。

* [Metals](https://scalameta.org/metals/docs/#running-tests)
* [Scala Plugin入りのIntelliJ IDEA](https://www.jetbrains.com/idea/)
