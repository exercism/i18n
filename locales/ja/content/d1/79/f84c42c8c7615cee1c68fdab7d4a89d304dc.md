# 概要

Gleamの標準ライブラリにある`gleam/order`モジュールには、値を比較するために使われる`Order`型が含まれています。

`Order`の定義は次のようになっています。

```gleam
pub type Order {
  Gt
  Eq
  Lt
}
```

この型には3つのバリアントがあり、それぞれがある値と別の値との関係を表すために使われます。

- `Gt` - その値がもう一方の値より_大きい_ことを表します。
- `Eq` - その値がもう一方の値と_等しい_ことを表します。
- `Lt` - その値がもう一方の値より_小さい_ことを表します。

あるデータ型が大きさで比較できる場合、そのモジュールが`Order`値を返す`compare`関数を定義するのが一般的です。たとえば、`gleam/float`と`gleam/int`は、それぞれ小数と整数を対象にした`compare`関数を定義しています。

```gleam
int.compare(1, 2)
// -> Lt

int.compare(2, 2)
// -> Eq

float.compare(1.0, 2.0)
// -> Lt
```

`list.sort`のようなソート関数は、`Order`値を返す関数をとるのが一般的で、これにより呼び出し側がリストをどのようにソートするかを定義できます。

```gleam
list.sort([3, 7, 3, 1], by: int.compare)
// -> [1, 3, 3, 7]
```
