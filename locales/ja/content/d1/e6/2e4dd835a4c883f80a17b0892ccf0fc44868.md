# Case

[`case`][case]は（他の言語ではしばしばswitchと呼ばれます）、`if`-`else`のような制御式の一種です。`case`を使うと、複数の`if`-`else`-`if`文を連ねて書けるので、より読みやすくなり、強力な構文も使えます。

`case`は、キーワード`case`と、それに続く省略可能な式で定義します。次に、それぞれのケースごとにキーワード`when`を使い、そのあとにcase式と比較される式を書きます。`when`キーワードは`case`キーワードからインデントしないようにします。`when`キーワードの後ろには、case式がwhen式と一致したときに実行されるコードを書きます。caseには省略可能な`else`文があり、どのケースにも一致しなかったときに実行されます。

case式は評価されたあと、各when式と比較されます。比較には[case包摂演算子（`===`）][case-subsumption]が使われます。

```Crystal
case 1
when 1
  puts "One"
when 2
  puts "Two"
else
  puts "Other"
end
# => One

# This is the same as:
tmp = 1
if 1 === tmp
  puts "One"
elsif 2 === tmp
  puts "Two"
else
  puts "Other"
end
```

## case包摂演算子（`===`）

case包摂演算子（`===`）は、等価演算子（`==`）とは少し違います。この演算子は、右辺が左辺の表す集合の要素であるかどうかを調べます。つまり、どちらのオペランドをどちら側に置くかが重要になります。どのように判定されるかは左辺の型によって変わり、たとえば`Range`なら右辺がその範囲に入っているかどうかを、`Object`なら右辺がその`Object`のインスタンスかどうかを調べます。

```Crystal
(1..3) == 1  # => false
(1..3) === 1 # => true

String == "foo"  # => false
String === "foo" # => true
```

## 複数の式を指定するcase

caseでは、1つのケースに複数の式を指定して一致させることができます。取りうる値はそれぞれカンマで区切ります。どれか1つでも一致すれば、そのコードが実行されます。1つのケースに複数の取りうる値があるときに便利です。

```Crystal
case 1
when 1, 2
  puts "One or two"
else
  puts "Other"
end
```

## 範囲を使うcase

caseでは、値がある範囲に入っているかどうかも調べられます。そのためには、when式に範囲を指定します。

```Crystal
case var
when 1..3
  puts "One to three"
else
  puts "Other"
end
```

## case式を省略したcase

case式が不要なときは、省略できます。こうすると、それぞれのwhen式が真とみなされるかどうかで評価されるようになります。つまり、`if`-`else`-`if`文と同じように動作します。

```Crystal
case
when 1 == 1
  puts "One is equal to one"
when 1 > 2
  puts "One is greater than two"
else
  puts "Other"
end
```

## 1行で書くwhen

Crystalでは、case文を1行で書けます。シンプルな1行の文を書くときに使えます。1行で書くときは、`when <expression> then <statement>.`のように書きます。else文で使う場合は、`else <statement>`のように書きます。

```Crystal
case var
when 1 then puts "One"
when 2 then puts "Two"
else puts "Other"
end
```

## 型で分岐するcase

caseでは、型によるマッチングができます。比較には`is_a?`演算子を使って、変数の型を調べます。たとえば、ユニオン型のそれぞれの型ごとに分岐を1つずつ書けます。

```Crystal
case var
when Int32
  puts "Int32"
when String
  puts "String"
else
  puts "Other"
end
```

## 暗黙のオブジェクト

caseでは、暗黙のオブジェクトを使えます。これにより、たとえばwhen式をcase式に対するメソッド呼び出しにできます。メソッドが真とみなされる値を返すかどうかで、そのケースが一致するかどうかが決まります。

```Crystal
case 1
when .odd?
  puts "Odd"
when .even?
  puts "Even"
end
```
