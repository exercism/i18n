# 概要

## ビット演算

ビット演算を使うと、2進数の個々の桁を操作できます。
これらの演算はコンピューティングの基礎であり、メモリ内の特定のビットの制御、数学的な計算の最適化、暗号化、通信、データのエンコードやデコードなど、低レベルの処理を効率よく行う手段になります。

### Elmの32ビット整数を理解する

Elmでは、整数は[2の補数](https://en.wikipedia.org/wiki/Two%27s_complement)表現を使った32ビット符号付き整数として保存されます。つまり、各整数の値を保存するのに32桁の2進数（_ビット_）を使います。
このビット数の制限は、Elmが直接表現できる整数の範囲に影響します。

正の範囲：0から2<sup>31</sup> - 1（0から2,147,483,647）
負の範囲：-2<sup>31</sup>から-1（-2,147,483,648から-1）

たとえば、整数の`5`は2進数で`00000000000000000000000000000101`と表されますが、ふつうは先頭の0は無視して、単に`101`と言います。

### Bitwise

Elmは、[Bitwiseモジュール](https://package.elm-lang.org/packages/elm/core/latest/Bitwise)でいくつかのビット演算子を提供しています。

## 基本の演算

数値の個々のビットを操作することを_マスキング_と呼びます。
_マスク_とは、`and`、`or`、`xor`などのビット演算子を使って別の数値を操作するために、特定のビットを特定のしかたで設定した数値のことです。

### and

`and`は、両方の数値で`1`になっているビットだけを残して、2つの数値を組み合わせます。
これは、特定のビットが設定されているかどうかを確認するのに便利です。
たとえば、ある数値の4番目のビットが`1`に設定されているかを確認するには、`01000`（10進数の`8`）というマスクと`and`をとり、結果が0以外になるかを見ます。

```elm
Bitwise.and 13 8 --> 8
--  13 = 01101
--   8 = 01000
-- and = 01000 = 8
```

### or

`or`は、どちらか一方、または両方の数値で`1`になっているビットを`1`にして、2つの数値を組み合わせます。
これは、特定のビットを`1`にするのに便利です。
たとえば、`10101`の2番目のビットを`1`にするには、マスク`00010`と`or`をとります。

```elm
Bitwise.or 21 2 --> 23
-- 21 = 10101
--  2 = 00010
-- or = 10111 = 23
```

### 排他的論理和（xor）

`xor`は、一方の数値では`1`で、もう一方の数値では`0`になっているビットを`1`にして、2つの数値を組み合わせます。
これは、ビットを反対の値に反転させるのに便利です。

```elm
Bitwise.xor 20 5 --> 17
--  20 = 10100
--   5 = 00101
-- xor = 10001 = 17
```

### 補数

`complement`は、数値の各ビットを反転させます（`0`は`1`に、`1`は`0`になります）。

この結果、正の数は負の数に、負の数は正の数になります。
これは、2進数では負の数が左端のビットを`1`にして表されるためです。

```elm
Bitwise.complement 21 --> -22
--         21 = 00000000000000000000000000010101
-- complement = 11111111111111111111111111101010 = -22
```

### ビットシフト

次の演算子は、ビットを指定した桁数だけ左または右に移動させます。これは実質的に、2の累乗を掛けたり割ったりすることになります。

`shiftLeftBy`はビットを左に移動させ、右側から`0`で埋めます。
たとえば、`21`を3桁左にシフトするには、次のようにします。

```elm
Bitwise.shiftLeftBy 3 21 --> 168
--  21 = 10101
-- shiftLeftBy 3 = 10101000 = 168
```

これは`21 * 2^3 = 21 * 2 * 2 * 2 = 168`と同じ意味です。

`shiftRightBy`：ビットを右に移動させます。

```elm
Bitwise.shiftRightBy 2 21 --> 5
--  21 = 10101
-- shiftRightBy 2 = 00101 = 5
```

2桁右にシフトすることは、4で整数除算することと同じです。

この関数は、左端のビットの値をそのまま複製することに注意してください。
そのため、負の数は負のままになります。

```elm
Bitwise.shiftRightBy 3 -21 --> -3
--  -21 = 111...101011
-- shiftRightBy 3 = 111...11101 = -3
```

右にシフトして0で埋めたい場合は、`shiftRightZfBy`を使います。

```elm
Bitwise.shiftRightZfBy 3 -21 --> 536870909
--  -21 = 111...101011
-- shiftRightZfBy 3 = 00111...11101 = 536870909
```
