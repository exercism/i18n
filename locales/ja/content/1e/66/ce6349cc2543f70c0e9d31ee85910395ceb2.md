# 指示の補足

## レジスタ

| レジスタ | 用途         | 型       | 説明                           |
| -------- | ------------ | -------- | ------------------------------ |
| `$a0`    | 入力         | アドレス | null終端の入力文字列           |
| `$a1`    | 入力/出力    | アドレス | null終端の出力文字列           |
| `$t0-9`  | 一時的       | 任意     | 一時的な保存に使われます       |
