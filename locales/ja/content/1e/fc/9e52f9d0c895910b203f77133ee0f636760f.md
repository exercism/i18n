# はじめに

Rには独立した[集合][wiki-set]型はなく、代わりにさまざまな関数を使ってベクトルに対して同様の操作を行います。

[`%in%`][ref-match]演算子は、ある要素が集合に含まれるかどうかを判定します。この中置演算子は、関数`is.element()`の同義語です。

```R
2 %in% 1:10 # TRUE
12 %in% 1:10 # FALSE
```

関連する関数には、次のようなものがあります。

- [`unique()`][ref-unique]：重複を取り除きます。
- [`union()`][ref-sets]：集合を結合します（数学では`A ∪ B`）。
- [`intersect()`][ref-sets]：両方の集合に共通する要素を求めます（`A ∩ B`）。
- [`setdiff()`][ref-sets]：ある集合から別の集合を引きます（`A - B`）。
- [`setequal`][ref-sets]：重複と順序を無視して集合が等しいかどうかを判定します。

```R
> set_1 <- c("a", "b", "c", "b", "a")
> unique(set_1) # deduplicate
[1] "a" "b" "c"

> set_2 <- c('a', "c", "d")
> union(set_1, set_2) # values in either set
[1] "a" "b" "c" "d"

> intersect(set_1, set_2) # values in both sets
[1] "a" "c"

> setdiff(set_1, set_2) # values in set_1 but not set_2
[1] "b"

> setdiff(set_2, set_1) # values in set_2 but not set_1
[1] "d"

setequal(set_1, c("c", "b", "a", "b")) # are elements the same after deduplication?
[1] TRUE
```

いずれの場合も、関数はコピーを返し、引数は変更されません。

## ハッシュテーブル

上で説明したベクトルの操作は、base Rの一部です。小さな問題には便利ですが、集合が大きくなると遅くなります。

さまざまなサードパーティのパッケージが[ハッシュテーブル][wiki-hash]を実装しており、状況によってはパフォーマンスを改善できます。

たとえば、[`hashtable`][ref-hashtable]パッケージは`hashmap`と`hashset`の実装を提供しており、よりうまくスケールします。ほとんどの外部パッケージと同様、Exercism内では利用できませんが、実際の問題に取り組む際には調べてみる価値があります。
