# ヒント

## 全般

- 関数を[他のファイルから参照できるようにする][global]必要があります。
- [NASMのドキュメント][interfacing]には、関数の引数がどのように渡され、戻り値がどのように取り出されるかが書かれています。

## 1. 想定されるオーブンの加熱時間を分単位で定義する

- 関数を[他のファイルから参照できるようにする][global]必要があります。
- [NASMのドキュメント][interfacing]には、関数の引数がどのように渡され、戻り値がどのように取り出されるかが書かれています。
- レジスターに値を格納する[命令][mov]があります。
- `equ`を使って、アセンブル時に決まる定数を定義できます。

## 2. 残りのオーブン加熱時間を分単位で計算する

- 関数を[他のファイルから参照できるようにする][global]必要があります。
- [NASMのドキュメント][interfacing]には、関数の引数がどのように渡され、戻り値がどのように取り出されるかが書かれています。
- 先に定義した他の関数を[呼び出す][call]ことができます。
- 値を引き算する[命令][sub]があります。

## 3. 下準備にかかる時間を分単位で計算する

- 関数を[他のファイルから参照できるようにする][global]必要があります。
- [NASMのドキュメント][interfacing]には、関数の引数がどのように渡され、戻り値がどのように取り出されるかが書かれています。
- 値を掛け算する[命令][imul]があります。

## 4. 経過時間を分単位で計算する

- 関数を[他のファイルから参照できるようにする][global]必要があります。
- [NASMのドキュメント][interfacing]には、関数の引数がどのように渡され、戻り値がどのように取り出されるかが書かれています。
- 先に定義した他の関数を[呼び出す][call]ことができます。
- 値を足し算する[命令][add]があります。
