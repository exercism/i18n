# 説明

この演習では、お気に入りの料理本を見ながら最高のラザニアを作れるように、コードを書いていきます。

タスクは3つあり、どれもラザニアの調理にかかる時間に関するものです。

## 1. オーブンでの想定時間を分単位で定義する

`expectedMinutesInOven`定数を定義して、ラザニアをオーブンに入れておくべき時間が何分かを確認しましょう。料理本によると、オーブンでの想定時間は40分です。

```Haskell
expectedMinutesInOven
    --> 40
```

## 2. 準備にかかる時間を分単位で計算する

`preparationTimeInMinutes`関数を定義しましょう。この関数は、ラザニアに重ねた層の数を仮引数として受け取り、ラザニアの準備に何分かかったかを返します。1層あたり2分かかるものとします。

```Haskell
preparationTimeInMinutes 3
    --> 6
```

## 3. 経過時間を分単位で計算する

`elapsedTimeInMinutes`関数を定義しましょう。この関数は2つの仮引数を取ります。1つ目はラザニアに重ねた層の数、2つ目はラザニアがオーブンに入っている時間（分）です。この関数は、ラザニアの調理に何分かかったかを返します。これは、準備にかかった時間（分）と、その時点でラザニアがオーブンにいた時間（分）を足したものです。

```Haskell
elapsedTimeInMinutes 3 20
    --> 26
```
