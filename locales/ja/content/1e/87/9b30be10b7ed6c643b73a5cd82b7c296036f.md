# 説明

この演習では、さまざまな種類のラジコンカーのレースを組み立てていきます。それぞれのカーには、速度とバッテリー消費という特性があります。

カーはバッテリーが満タン（100%）の状態からスタートします。リモコンでカーを走らせるたびに、車はその速度の分だけメートル進み、バッテリー残量のパーセンテージがバッテリー消費の分だけ減ります。

バッテリー残量がバッテリー消費のパーセンテージを下回ると、そのカーはもう走らせられません。

それぞれのレーストラックには距離があります。カーは、バッテリーを使い切らずにトラックを完走できるかどうかでテストされます。

ここには6つのタスクがあり、それぞれがラジコンカーのインスタンスを扱います。

## 1. ラジコンカーを作成する

`RemoteControlCar`クラスのコンストラクターを定義して、ラジコンカーを作成できるようにします。このコンストラクターは、車の速度（メートル）とバッテリー消費のパーセンテージを2つの仮引数として受け取ります（どちらも`int`型です）。

```csharp
int speed = 5;
int batteryDrain = 2;
var car = new RemoteControlCar(speed, batteryDrain);
```

## 2. レーストラックを作成する

`RaceTrack`クラスのコンストラクターを定義して、レーストラックを作成できるようにします。このコンストラクターは、トラックの距離（メートル）を唯一の仮引数として受け取ります（`int`型です）。

```csharp
int distance = 800;
var raceTrack = new RaceTrack(distance);
```

## 3. カーを走らせる

`RemoteControlCar.Drive()`メソッドを実装し、車の速度に基づいて走行したメートル数を更新します。また、`RemoteControlCar.DistanceDriven()`メソッドを実装して、車が走ったメートル数を返すようにします。

```csharp
int speed = 5;
int batteryDrain = 2;
var car = new RemoteControlCar(speed, batteryDrain);
car.Drive();

car.DistanceDriven();
// => 5
```

## 4. バッテリー切れを確認する

`RemoteControlCar.Drive()`メソッドを更新して、車のバッテリー消費に基づいてバッテリーを消耗させます。また、`RemoteControlCar.BatteryDrained()`メソッドを実装して、バッテリーが切れているかどうかを示すようにします。

```csharp
int speed = 5;
int batteryDrain = 2;
var car = new RemoteControlCar(speed, batteryDrain);
car.Drive();

car.BatteryDrained();
// => false
```

## 5. Nitroラジコンカーを作成する

一番よく売れているラジコンカーはNitroで、驚異の最高速度50メートル、バッテリー消費は4%です。（静的）`RemoteControlCar.Nitro()`メソッドを実装して、このタイプのカーを返すようにします。

```csharp
var car = RemoteControlCar.Nitro();
car.Drive();
car.DistanceDriven();
// => 50
```
## 6. ラジコンカーがレースを完走できるか確認する

レーストラックを完走するには、カーがトラックの距離を走り切れる必要があります。つまり、ゴールラインを越える前にバッテリーを使い切ってはいけないということです。`RaceTrack.TryFinishTrack()`メソッドを実装します。このメソッドは`RemoteControlCar`のインスタンスを仮引数として受け取り、カーがレーストラックを完走できる場合は`true`を、それ以外の場合は`false`を返します。

```csharp
int speed = 5;
int batteryDrain = 2;
var car = new RemoteControlCar(speed, batteryDrain);

int distance = 100;
var raceTrack = new RaceTrack(distance);

raceTrack.TryFinishTrack(car);
// => true
```
