# ヒント

## 全般

- 後片付け用のワードはすべて[`destructors`][destructors]にあります。
- `:>`と`::`（locals）を使うと、複数のポンプを扱う本体が読みやすくなります。使いたくなったら、`USING:`に`locals`を追加しましょう。

## 1. ビルジを排水する

- 使うワードは1つ、`dispose`です。

## 2. ポンプ排出のルーチン

- 使うワードは1つ、`with-disposal`です。閉じ`;`のあとに`inline`を付けると、コンパイラーがクォーテーション引数を見通せるようになります：`: pump-out ( pump quot -- ) with-disposal ; inline`

## 3. シフト全体のルーチン

- `with-destructors`でスコープを開きます。その中で、各ポンプを`&dispose`で登録してから、クォーテーションを`call`します。localsを使う場合：`[ pump-a &dispose pump-b &dispose quot call ] with-destructors`

## 4. 危険なポンプ排出

- タスク3と同じ形ですが、1つのポンプに対して`|dispose`（失敗時のみ）を使います。

## 5. 自作のdisposable：バルブ

- `TUPLE: valve < disposable is-open ;`。ここで`<`は`disposable`を継承するので、フレームワークの仕組みが引き継がれます。
- `<valve>`は`new-disposable`（通常の`new`ではない）を使うので、新しいバルブがフレームワークに登録されます。
- `M: valve dispose*`が後片付けのフックです。スタックに何も残さないことが大切です。`>>is-open`はタプルをスタックの一番上に残すので、最後は`drop`で終わります。

[destructors]: https://docs.factorcode.org/content/vocab-destructors.html
