# はじめに

## オーバーフロー

算術オーバーフローは、算術演算や型変換などの計算の結果が、受け取る側の型に収まる範囲を超えたときに発生します。

`int`型と`long`型、およびそれらの符号なしの型の式では、このような状況で暗黙のうちに値がラップアラウンドします。

整数の計算の動作は、`checked`キーワードを使うことで変更できます。`checked`ブロックの中でオーバーフローが発生すると、`OverflowException`のインスタンスがスローされます。

```csharp
int one = 1;
checked
{
    int expr = int.MaxValue + one;   // OverflowException is thrown
}

// or

int expr2 = checked(int.MaxValue + one);     // OverflowException is thrown
```

`float`型と`double`型の式では、無限大という特別な値になります。

`decimal`型の式では、`OverflowException`のインスタンスがスローされます。
