# 概要

Swiftには、主に3つのループ構文があります。

- **`while`ループ**：指定した条件が`true`のままである限り、コードブロックを繰り返します。条件は、ループ本体を実行する前に評価されます。
- **`repeat-while`ループ**：`while`ループに似ていますが、条件はループ本体を実行したあとに評価されます。そのため、本体が少なくとも1回は実行されることが保証されます。
- **`for-in`ループ**：シーケンスやコレクション（範囲、配列、文字列など）の各要素について、コードブロックを1回ずつ実行します。
