# エディター連携

Clojureの開発に最適なのは、エディターと連携させたREPLを使う方法です。よく使われるエディターや統合開発環境向けのプラグインが公開されています。

- Emacs：[CIDER](https://cider.mx)
- IntelliJ：[Cursive](https://cursive-ide.com)
- VSCode：[Calva](https://calva.io)
- Vim：[Conjure](https://github.com/Olical/conjure)

詳しくは[公式ドキュメント](https://clojure.org/guides/editors)を参照してください。
