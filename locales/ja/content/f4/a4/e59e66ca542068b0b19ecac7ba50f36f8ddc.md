# 分割代入

分割代入とは、値を構成する各部分に分解し、それぞれをより小さな変数に束縛する操作です。

## タプルの分割代入

タプルの分割代入は簡単です。タプルの各フィールドに新しい変数名を割り当てるだけです。

```rust
let (first, second) = (1, 2);
```

## タプル構造体の分割代入

タプル構造体の分割代入は、タプルの分割代入とほとんど同じですが、構造体の名前を付け加えます。

```rust
struct TupleStruct(&'static str, i32);
let my_tuple_struct = TupleStruct("foo", 123);
let TupleStruct(foo, num) = my_tuple_struct;
```

## 構造体の分割代入

構造体の分割代入は、タプル構造体の分割代入とよく似ています。フィールド名を使うだけです。

```rust
struct ArabianNights {
    name: String,
    stories: usize,
}
let teller = ArabianNights { name: "Scheherazade".into(), stories: 1001 };
{
    let ArabianNights { name, stories } = teller;
    println!("{name} told {stories} stories");
}
```

## 一部だけの分割代入

分割代入のときに`..`演算子を使うと、一部のフィールドを無視できます。

```rust
let ArabianNights { name, .. } = teller;
println!("{name} survived by her wits");
```

## 条件付きの分割代入

構造体とタプルの分割代入は必ず成功します。ただし、`if let`、`while let`、`match`といった言語構造を使えば、enumも分割代入できます。

```rust
if let Some(foo) = foo {
    println!("{foo:?}");
}
```
