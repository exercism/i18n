# はじめに

Factorの連想配列（ハッシュテーブルなど）は、[`assocs`][assocs]が提供する共通の[プロトコル][assoc-protocol]を共有しています。ハッシュテーブルのリテラルは`H{ }`です。

```factor
H{ { "coal" 1 } { "wood" 2 } } .

"coal" H{ { "coal" 1 } { "wood" 2 } } at .   ! => 1
"gold" H{ { "coal" 1 } { "wood" 2 } } at .   ! => f
```

よく使う操作は次のとおりです。

```
at        ( key assoc -- value/f )
key?      ( key assoc -- ? )
set-at    ( value key assoc -- )
delete-at ( key assoc -- )
inc-at    ( key assoc -- )
change-at ( key assoc quot -- )
keys      ( assoc -- keys )
values    ( assoc -- values )
>alist    ( assoc -- alist )
```

ハッシュテーブルは*変更可能*です。そのため、変更する前に`H{ }`のリテラルを`clone`してください。そうしないと、リテラルが呼び出しの間で共有されてしまいます。

[assocs]: https://docs.factorcode.org/content/vocab-assocs.html
[assoc-protocol]: https://docs.factorcode.org/content/article-assocs-protocol.html
