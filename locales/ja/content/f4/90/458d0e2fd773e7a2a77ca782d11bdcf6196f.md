# 説明

ルシアンのガールフレンドがもうすぐ家に帰ってきますが、二人の結婚記念日のディナーはまだ作れていません！

この演習では、ルシアンがお気に入りのレシピ本を見ながら絶品ラザニアを作れるように、コードを書いていきます。

ラザニアの調理時間に関する4つのタスクがあります。

## 1. オーブンでの想定焼き時間（分）を定義する

引数を取らず、ラザニアをオーブンに入れておくべき時間を分単位で返す`ovenTime()`関数を定義します。
レシピ本によると、想定されるオーブンでの焼き時間は40分です：

```cpp
ovenTime();
// => 40
```

## 2. オーブンでの残りの焼き時間（分）を計算する

`remainingOvenTime(int actualMinutesInOven)`関数を定義します。この関数は、ラザニアをオーブンに入れてから実際に経過した時間を分単位で引数として受け取り、前のタスクで定義した想定焼き時間をもとに、ラザニアをあと何分オーブンに入れておく必要があるかを返します。

```cpp
remainingOvenTime(30);
// => 10
```

## 3. 準備時間（分）を計算する

`preparationTime(int numberOfLayers)`関数を定義します。この関数は、ラザニアに重ねた層の数を引数として受け取り、1層あたり2分かかるものとして、ラザニアの準備に何分かかったかを返します。

```cpp
preparationTime(2);
// => 4
```

## 4. 経過時間（分）を計算する

`elapsedTime(int numberOfLayers, int actualMinutesInOven)`関数を定義します。この関数は2つの引数を取ります。1つ目の引数はラザニアに重ねた層の数、2つ目の引数はラザニアをオーブンに入れてからの経過時間（分）です。この関数は、ラザニアの調理に費やした時間を分単位で返します。これは、準備にかかった時間と、その時点でラザニアがオーブンにあった時間の合計です。

```cpp
elapsedTime(3, 20);
// => 26
```
