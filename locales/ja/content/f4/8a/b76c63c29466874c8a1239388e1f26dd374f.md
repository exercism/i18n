# 概要

ブロックは、複数回実行できる文を小さくまとめたものです。クロージャや無名関数のようなものだと考えることもできます。ブロックは`do...end`構文（上記）や`{}`（下記）を使って定義します。どちらのスタイルも入れ替えて使うことができ、それぞれをいつ使うべきかについては、さまざまな意見があります。

## 省略記法

ブロックがメソッドを1つだけ呼び出す場合は、そのブロックを`&:`に続けてメソッド名を書く形に置き換えられます。たとえば、次の2行は同じ意味です。

```ruby
people.sum { |person| person.age }
people.sum(&:age)
```
