# はじめに

タプルは、値が順番に並んだ入れ物です。Gleamのすべてのデータ型と同様、タプルはイミュータブルです。タプルの各要素はそれぞれ違う型でもかまいませんし、要素が別のタプルでもかまいません。

タプルは、`#(`と`)`の間にカンマで区切って値を並べて定義します：`#(1, 2.0, "Three")`。

```gleam
#("one", 2)      // Tuple pair (2 values)
#("one", 2, 3.0) // Tuple triplet (3 values)
```

同じ長さで、同じ型（同じ順番）のタプルどうしは、同じかどうかを比べることができます。

```gleam
#(1, 2) == #(1, 2) // Same length, same types, same values, same order
// -> True

#(1, 2) == #(2, 1) // Same length, same types, same values, different order
// -> False

#(1, 2) == #(1, "2") // Same length, different types
// Compile error!

#(1, 2) == #(1, 2, 3) // Different length
// Compile error!
```

タプルの中の値を取り出す方法は、次の3つです。

- インデックスを使う。
- `let`を使ったパターンマッチ。
- `case`を使ったパターンマッチ。

```gleam
let person = #("Jordan", 170)

// Option 1: Indexing
person.0 // -> "Jordan"
person.1 // -> 170

// Option 2: let
let #(name2, length2) = person
// -> name2 = "Jordan"
// -> length2 = 52

// Option 3: case
case person {
  #(name3, length3) -> {
    name3   // -> "Jordan"
    length3 // -> 170
  }
}
```
