# 動的なシンタックスハイライト

動的なシンタックスハイライトとは、ユーザーが変更できるコードをハイライトする仕組みです。
これが行われる場所は1か所だけ、オンラインエディターです。

```exercism/note
コードスニペットやイテレーションなどは、ユーザーがその場でコードを変更できないため_静的_です。
静的シンタックスハイライトをどのように扱っているのか詳しく知りたい場合は、[静的シンタックスハイライトのドキュメント](/docs/building/tracks/new/syntax-highlighting/static)をご覧ください。
```

## 実装

動的なシンタックスハイライトは、[CodeMirrorライブラリ](https://codemirror.net/)を使って実現します。

自分の言語のサポートを追加するときには、3つの選択肢があります。

1. CodeMirrorがその言語を_標準で_サポートしている（つまり、[サポートされている言語](https://codemirror.net/5/mode/)に載っている）。
   その場合は、[言語を有効にする](#enable-language)セクションに進んでください。
2. 既存のCodeMirrorプラグインを通じてサポートされている。
   その場合は、[既存のプラグインを使う](#using-an-existing-plugin)セクションに進んでください。
3. その言語がサポートされて_いない_。
   この場合は3つの選択肢があります。
   1. [新しいプラグインを作成する](#create-a-new-plugin)セクションで説明するように、CodeMirrorプラグインを一から書く。
   2. 自分の言語の構文が別の言語の構文に（よく）似ている（たとえば、Unisonの構文はHaskellに似ています）。その場合は、その言語のシンタックスハイライトを自分の言語に使うことも検討できます。
      詳しくは[言語を有効にする](#enable-language)セクションをご覧ください。
   3. 動的なシンタックスハイライトを導入しない。

### 言語を有効にする

自分の言語に対するCodeMirrorのサポートを有効にするには、[フォーラム](https://forum.exercism.org/c/exercism/building-exercism/125)でトピックを立ててください。
そうすると、Exercismが、ウェブサイトでその言語のCodeMirrorサポートを有効にするプルリクエストを作成します。

### 既存のプラグインを使う

既存のプラグインを使うには、そのプラグインが[NPM](https://www.npmjs.com/)に公開されている必要があります。

プラグインがNPMに公開されていない場合は、次のいずれかを行います。

1. プラグインの作者に、NPMで公開する意思があるか尋ねる。
2. リポジトリをフォークして、自分で公開する。
3. Exercismにリポジトリをフォークしてもらい、公開まで任せる。
   そうするには、[フォーラム](https://forum.exercism.org/c/exercism/building-exercism/125)でトピックを立てて依頼してください。

```exercism/note
CodeMirrorのウェブサイトには、[コミュニティが作成した言語プラグインの一覧](https://codemirror.net/docs/community/#language)があります。
```

次のステップは、[言語を有効にする](#enable-language)ことです。

### 新しいプラグインを作成する

始めるための手順は次のとおりです。

1. [既存の`codemirror-lang-...`がリポジトリ一覧にないかどうか](https://github.com/search?q=org%3Acodemirror-lang&type=repositories)を確認して、まだ存在しないことを確かめます。
2. [Exercismフォーラム][building-exercism]で新しいトピックを立て、どの言語のCodeMirrorプラグインを作りたいのかを伝えます。
3. CodeMirrorプラグインのリポジトリが用意されたら、自分のトラックの文法を実装します。

```exercism/note
始めやすくするために、用意されたリポジトリには、土台として使ったり調整したりできる最小限のサンプル文法が含まれています。
```

Exercismのコミュニティはとても友好的で協力的なので、この作業を進める中で喜んで力になってくれます！
もし行き詰まったら、[Exercismフォーラム][building-exercism]で新しいトピックを立てるか、必要に応じて[exercism/exercism][exercism-repo]で新しいイシューを作成してください🙂

その後、プラグインを[NPM](https://www.npmjs.com/)に公開する必要があります。
次のステップは、[言語を有効にする](#enable-language)ことです。

### 別の言語を使う

自分の言語の構文が別の言語の構文に（よく）似ている場合は、その言語のシンタックスハイライトを自分の言語に使うことも検討できます。
そうするには、その別の言語のCodeMirrorプラグインを使ってトラックを設定します。
詳しくは[言語を有効にする](#enable-language)セクションをご覧ください。
