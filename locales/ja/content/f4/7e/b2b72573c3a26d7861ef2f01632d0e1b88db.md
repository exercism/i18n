# 説明

サーカスでは、安全確認に合格するまで誰も空中ブランコには乗れません。
同じルールが全員に当てはまるように、ここではその確認内容を書き留めていきます。

5つのタスクはすべて`SAFETY_CHECK`クラスの中に書きます。

## 1. マットの準備はできていますか？

マットは、敷いてあり、かつきれいなときだけ準備ができたと言えます。

```sather
SAFETY_CHECK::mat_ready(true, false)
-- => false
```

## 2. 着地するものはありますか？

下にマットがあるか、下にネットがある必要があります。どちらか一方だけでもよく、両方あってもかまいません。

```sather
SAFETY_CHECK::something_below(false, true)
-- => true
```

## 3. まだブリーフィングが必要なのは誰ですか？

ブリーフィングを受けていない人は、誰でもブリーフィングが必要です。

```sather
SAFETY_CHECK::needs_briefing(false)
-- => true
```

## 4. この演者は年齢が足りていますか？

空中ブランコは、13歳以上の演者が対象です。

```sather
SAFETY_CHECK::old_enough(13)
-- => true
```

## 5. すべてを組み合わせる

演者は、年齢が足りていて、ブリーフィングを受けており、マットの準備ができているとき、空中ブランコの許可が下ります。

```sather
SAFETY_CHECK::cleared(14, true, true, true)
-- => true
```

4つの引数は、年齢、ブリーフィングを受けたかどうか、マットが敷いてあるかどうか、マットがきれいかどうかです。
