# はじめに

*タプル*は、Factorにおけるレコード・構造体・クラスに相当する型です。タプルクラスはそれぞれ、決まった数の名前付きスロットを持ち、Factorがそれらのゲッターとセッターを自動生成します。

```factor
TUPLE: point
    { x initial: 0 }
    { y initial: 0 } ;

T{ point { x 3 } { y 4 } } x>> .   ! => 3
3 4 point boa .                    ! => T{ point { x 3 } { y 4 } }
point new .                        ! => T{ point }
```

`boa`（"by order of arguments"、引数の順序どおりに）は、宣言した順序でスタックからスロットを埋めていきます。`new`は、各スロットを宣言された`initial:`の値にしたインスタンスを生成します（`initial:`がなければ`f`です）。

各スロットのゲッターは`slot>>`、セッターは`>>slot`です。セッターは値を*書き換え*るので、元の値を残したまま更新したい場合は、先に`clone`してください。

```factor
T{ point { x 3 } { y 4 } } clone 10 >>x .
! => T{ point { x 10 } { y 4 } }
```

スロットの初期値は`{ name initial: value }`で指定します。`initial:`を書かなければ、初期値は`f`です。
