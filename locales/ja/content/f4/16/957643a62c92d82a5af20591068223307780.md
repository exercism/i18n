# Visual Basicを学ぶ

## ウェブサイト

Visual Basicは長年にわたり大きく進化してきたため、サードパーティのチュートリアルの多くは、古いツールや機能を扱っています。
[Visual Basicの公式ドキュメント](https://learn.microsoft.com/en-us/dotnet/visual-basic/)は、学びの旅を始めるにあたって最も新しく、信頼できる情報源です。

## .NETエコシステム

Visual Basicは.NETランタイム上で動作し、C#やF#と多くのコア機能を共有しています。
そのため、.NETの仕組みを理解しておくと、より優れたVBエンジニアになれます。

- [.NETとは？](https://learn.microsoft.com/en-us/dotnet/core/introduction)
- [.NET用語集](https://learn.microsoft.com/en-us/dotnet/standard/glossary)
- [共通型システム（CTS）](https://learn.microsoft.com/en-us/dotnet/standard/base-types/common-type-system)
