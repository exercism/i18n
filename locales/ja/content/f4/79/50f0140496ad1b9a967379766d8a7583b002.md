# 説明

この演習では、バンドの値を覚えなくて済むように、便利なプログラムを作ります。
プログラムは1色、4色、または5色の色を入力として受け取り、正しい抵抗値をオーム単位で出力します。
カラーバンドは次のように符号化されています：

| 色     | 値    |
| ------ | ----- |
| Black  | 0     |
| Brown  | 1     |
| Red    | 2     |
| Orange | 3     |
| Yellow | 4     |
| Green  | 5     |
| Blue   | 6     |
| Violet | 7     |
| Gray   | 8     |
| White  | 9     |

[`Resistor Color Trio`][resistor-color-trio-exercise]では、最初の3つのカラーバンドを解読しました。
たとえば、orange-orange-brownは主値`330`になります。
この演習では、そこに_許容差_を加える必要があります。
許容差とは、値が主値から上下にどれだけずれる可能性があるかの最大量です。
たとえば、最後のバンドがgreenなら、最大許容差は`±0.5%`になります。

許容差バンドは次のいずれかの値になります：

| 色     | 許容差   |
| ------ | --------: |
| Grey   |    ±0.05% |
| Violet |    ±0.10% |
| Blue   |    ±0.25% |
| Green  |    ±0.50% |
| Brown  |    ±1.00% |
| Red    |    ±2.00% |
| Gold   |    ±5.00% |
| Silver |   ±10.00% |

4本バンドの抵抗器は次のように構成されます：

| バンド1 | バンド2 | バンド3 | バンド4 |
| ------- | ------- | ---------- | --------- |
| 値1 | 値2 | 倍率 | 許容差 |

例：

- orange-orange-brown-greenは、許容差`±0.5%`の`330`オームになります。
- orange-orange-red-greyは、許容差`±0.05%`の`3300`オームになります。

4本バンドと5本バンドの違いは、5本バンドにはより精密な値を示すためのバンドが1本余分にあることです。

| バンド1 | バンド2 | バンド3 | バンド4 | バンド5 |
| ------- | ------- | ------- | ---------- | --------- |
| 値1 | 値2 | 値3 | 倍率 | 許容差 |

例：

- orange-orange-orange-black-greenは、許容差`±0.5%`の`333`オームになります。
- orange-red-orange-blue-violetは、許容差`±0.1%`の`323 million`オームになります。

1本バンドの抵抗器もあります。
1本バンドの抵抗器にはblackだけがあり、値は0です。

プログラムは、抵抗器のバンド色の入力`list`を次のようなラベルに変換する必要があります：

"... ohms ±...%"

したがって、`["orange", "orange", "black", "green"]`という入力`list`は次の値を返す必要があります：

"33 ohms ±0.5%"

オームが千単位になるときは、「kiloohms」と言います。
これは、1000メートルを「キロメートル」、1000グラムを「キログラム」と言うのと似ています。

したがって、`["orange", "orange", "orange", "grey"]`という入力`list`は次の値を返す必要があります：

"33 kiloohms ±0.05%"

オームが百万単位になるときは、「megaohms」と言います。

したがって、`["orange", "orange", "blue", "red"]`という入力`list`は次の値を返す必要があります：

"33 megaohms ±2%"
