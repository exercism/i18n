# 概要

関数がたくさんの引数を取るとき、どの順番で渡せばよいかを覚えておくのが難しいことがあります。読みやすさのために、Gleamでは引数に名前を付けてラベルを付けられます。

引数にラベルを付けるには、引数名の前にラベル名を書き、スペースで区切ります。

```gleam
pub fn replace(
  in string: String,
  each target: String,
  with replacement: String
) -> String {
  // ...
}
```

ラベル付き引数を持つ関数を呼び出すときは、引数をどの順番で渡してもかまいません。次の`replace`の呼び出しは、どれも同じ意味です。

```gleam
replace(in: "🍔🍔🍔" each: "🍔", with: "🍕")

replace(each: "🍔", in: "🍔🍔🍔", with: "🍕")

replace(with: "🍕", each: "🍔", in: "🍔🍔🍔")
```

ラベルは常に省略できます。ラベル付き引数を持つ関数でも、ラベルを付けずに呼び出せます。

```gleam
replace("🍔🍔🍔", "🍔", "🍕")
```

ラベル付き引数を持つ関数を定義するときは、最初のラベル付き引数より後ろの引数にも、すべてラベルを付ける必要があります。

```gleam
// This function is valid
pub fn valid(
  x: Int,
  label1 y: Int,
  label2 z: Int
) -> Int {
  // ...
}

// This function is invalid
pub invalid(
  x: Int,
  label1 y: Int,
  z: Int
) -> Int {
  // ...
}
```
