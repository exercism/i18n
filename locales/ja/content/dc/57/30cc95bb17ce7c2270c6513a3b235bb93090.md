# はじめに

## ジェネリック型

コレクションの定義には、たいてい山括弧（`<>`）で囲まれたプレースホルダーが含まれ、慣習的に`T`という名前を使うことが多いです。このようなコレクションを、ジェネリック型と呼びます。ジェネリック型を使うと、コレクションにどんな型の要素を入れるかを、使う側で指定できます。次のサンプルコードでは、文字列の配列をインスタンス化しています。

## 配列

C#の配列は、プリミティブ値や、構造体・クラスのインスタンスをまとめたコレクションです。基底クラスライブラリでは`List<T>`として実装されており、ここで`T`は配列に入る要素の型を表します。APIには、配列を作成したり操作したりするための豊富なメソッドが用意されています。

配列には要素を追加したり、削除したりできます。必要に応じて大きくなったり、小さくなったりします。

```csharp
var listOfStrings = new List<string>();
```
