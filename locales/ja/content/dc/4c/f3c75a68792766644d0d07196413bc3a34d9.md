# はじめに

Wikipediaでは、`switch`文を「変数や式の値によってプログラムの制御の流れを変えるための、選択制御機構の一種」と説明しています。

この仕組みでは、`switch`、`case`、`break`、`default`というキーワードを使います。

最も単純な形では、プリミティブや文字列の式を評価し、その値に基づいて判断を下します。例えば、次のようになります。

```csharp
string direction = GetDirection();
switch (direction)
{
    case "left":
        GoLeft();
        break;
    case "right":
        GoRight();
        break;
    default:
        MarkTime();
        break;
}
```

最も高度な形になると、ダウンキャスト`case <Type> <variable>:`やガード（`when`）が登場します。

```csharp
Animal animal = GetAnimal();

switch (animal)
{
    case Dog canine:
    case Coyote canine:
        canine.Bark();
        break;
    case Cat cat when cat.HasOnly8Lives():
        cat.IsCareful();
        cat.Meow();
        break;
    case Cat cat:
        cat.Meow();
        break;
}
```
