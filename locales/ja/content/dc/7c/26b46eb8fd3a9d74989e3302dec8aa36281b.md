# 指示の補足

## テスト

テストでは、いくつかの操作が同時に実行されます。
`Account`に対する操作が、どのようなときも一貫した状態を保つようにしてください。
たとえば、複数のゴルーチンが同時に預け入れと引き出しを行うことがあります。2つの引き出しが同時に起きても、残高がマイナスになることはあってはなりません。

ローカルで作業するときは、`-race`フラグを付けてテストを実行すれば、コードが並行処理を正しく扱い、データ競合を起こしていないことを確認できます。

```bash
cd exercism/project/directory/go/bank-account
go test -race
```
