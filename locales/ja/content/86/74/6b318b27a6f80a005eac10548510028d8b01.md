# 説明

この演習では、2012年9月15日にオープンしたニューヨークの美容サロン向けの予約スケジューラーに取り組みます。

タスクは4つあり、どれも予約日時を扱います。日付と時刻には、次の3つの形式のいずれかを使います。

- `"7/25/2019 13:45:00"`
- `"July 25, 2019 13:45:00"`
- `"Thursday, July 25, 2019 13:45:00"`

テストは自動的にカルチャーを`en-US`に設定します。カルチャーを自分で設定したり指定したりする必要はありません。

## 1. 予約日時を解析する

（_static_な）`Appointment.Schedule()`メソッドを実装し、予約日時のテキスト表現を対応する`DateTime`形式に解析します。

```csharp
Appointment.Schedule("7/25/2019 13:45:00")
// => new DateTime(2019, 7, 25, 13, 45, 0)
```

## 2. 予約がすでに過ぎているかどうかを確認する

（_static_な）`Appointment.HasPassed()`メソッドを実装します。このメソッドは予約日時を受け取り、その予約が過去のものかどうかを確認します。

```csharp
Appointment.HasPassed(new DateTime(1999, 12, 31, 9, 0, 0))
// => true
```

## 3. 予約が午後かどうかを確認する

（_static_な）`Appointment.IsAfternoonAppointment()`メソッドを実装します。このメソッドは予約日時を受け取り、その予約が午後（12:00以上、18:00未満）かどうかを確認します。

```csharp
Appointment.IsAfternoonAppointment(new DateTime(2019, 03, 29, 15, 0, 0))
// => true
```

## 4. 予約の時刻と日付を説明する

（_static_な）`Appointment.Description()`メソッドを実装します。このメソッドは予約日時を受け取り、その日時の説明を返します。

```csharp
Appointment.Description(new DateTime(2019, 03, 29, 15, 0, 0))
// => "You have an appointment on 3/29/2019 3:00:00 PM."
```

## 5. 記念日を返す

（_static_な）`Appointment.AnniversaryDate()`メソッドを実装します。このメソッドは、今年の記念日である9月15日を返します。

```csharp
Appointment.AnniversaryDate()
// => new DateTime(2019, 9, 15, 0, 0, 0)
```
