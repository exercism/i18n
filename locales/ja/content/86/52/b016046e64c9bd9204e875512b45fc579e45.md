# 指示

Booking Up For Beautyの演習で手伝ったニューヨークの美容室は順調に営業していて、常連のお客さんがたくさんできました。
常連のお客さんは、毎回の来店を個別に予約するのではなく、「第2火曜日」「毎月最後の金曜日」といった決まった取り決めを持っています。
オーナーから、そうした取り決めが指す日付と、サロン自身の毎月の決まった予定の日付を計算してくれるヘルパーを作ってほしいと頼まれました。

## 1. 常連のお客さんの定例予約を見つける

年、月、第何回目か（`1`が1回目、`2`が2回目、以下同様）、曜日を引数に取る`SalonCalendar.standingAppointment()`メソッドを実装します。
このメソッドは、その月の中で指定した曜日がその回数目に来る日付を返します。

```java
SalonCalendar calendar = new SalonCalendar();
calendar.standingAppointment(2024, Month.AUGUST, 2, DayOfWeek.TUESDAY);
// => LocalDate.of(2024, 8, 13)
```

## 2. 常連のお客さんの月末の予約を見つける

常連のお客さんの中には、その月の最後に来る自分の曜日を好む人もいます。
年、月、曜日を引数に取り、その月の中で指定した曜日が最後に来る日付を返す`SalonCalendar.lastAppointment()`メソッドを実装します。

```java
SalonCalendar calendar = new SalonCalendar();
calendar.lastAppointment(2024, Month.AUGUST, DayOfWeek.FRIDAY);
// => LocalDate.of(2024, 8, 30)
```

## 3. 飛び込みのお客さんの次の空き日を見つける

受付のお客さんが「次の土曜日」を希望しています。
その日がすでに土曜日なら、その当日のことです。
日付と曜日を引数に取り、指定した日付以降で最初にその曜日になる日付を返す`SalonCalendar.nextAvailable()`メソッドを実装します。

```java
SalonCalendar calendar = new SalonCalendar();
calendar.nextAvailable(LocalDate.of(2024, 8, 15), DayOfWeek.SATURDAY);
// => LocalDate.of(2024, 8, 17)
calendar.nextAvailable(LocalDate.of(2024, 8, 17), DayOfWeek.SATURDAY);
// => LocalDate.of(2024, 8, 17)
```

## 4. 帳簿締めの日を見つける

サロンは毎月末日に帳簿を締めます。
ただし週末は休業なので、月末が土曜日か日曜日になる場合は、その前の金曜日に帳簿を締めます。
年と月を引数に取り、その月の帳簿締めの日を返す`SalonCalendar.bookkeepingDay()`メソッドを実装します。

```java
SalonCalendar calendar = new SalonCalendar();
calendar.bookkeepingDay(2024, Month.SEPTEMBER);
// => LocalDate.of(2024, 9, 30)
calendar.bookkeepingDay(2024, Month.AUGUST);
// => LocalDate.of(2024, 8, 30)
```

## 5. 週末のルールを給料日に再利用する

スタッフへの給料は毎月15日に支払われ、同じ週末のルールが適用されます。15日が土曜日か日曜日なら、給料日はその前の金曜日です。
同じルールをもう一度書く代わりに、再利用できるアジャスターにしましょう。

平日はそのままにし、土曜日か日曜日を前の金曜日に移動させる`TemporalAdjuster`を返す`SalonCalendar.precedingWorkday()`メソッドを実装します。
次に、そのアジャスターを使って、年と月を引数に取る`SalonCalendar.payday()`メソッドを実装します。

```java
SalonCalendar calendar = new SalonCalendar();
LocalDate.of(2024, 6, 15).with(calendar.precedingWorkday());
// => LocalDate.of(2024, 6, 14)
calendar.payday(2024, Month.JUNE);
// => LocalDate.of(2024, 6, 14)
calendar.payday(2024, Month.AUGUST);
// => LocalDate.of(2024, 8, 15)
```

`bookkeepingDay()`に戻って、このアジャスターを使ってみてもかまいません。
