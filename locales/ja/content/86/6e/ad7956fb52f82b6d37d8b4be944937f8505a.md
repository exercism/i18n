# 概要

Common Lispでは、時間は3つの方法で表されます。

- 世界時は絶対時刻で、`1900-01-01T00:00:00Z`（UTCの1900年1月1日の真夜中）からの秒数を表す整数です。
- デコード時間は9つの値のタプルで、それらをまとめて特定の暦時刻を表します。秒、分、時、日、月、年、曜日、夏時間フラグ、タイムゾーンです。
（詳しくは後述します。）
- 内部時間は、処理系が定義する「内部時間単位」で表される正の整数で、実行時間の計測に使うことができます。

## 世界時

現在の世界時を取得するには、`get-universal-time`または`get-decoded-time`を使います。
前者は`1900-01-01T00:00Z`からの現在の秒数を返し、後者は同じデータをデコード形式で返します。

この数値は正の整数なので、1900年より前の日付をエンコードすることはできません。

## デコード時間

`decode-universal-time`と`encode-universal-time`は、時間を扱うための主要な関数です。
前者は世界時を受け取り、[多重値][concept-multiple-values]としてデコード時間の値を返します。後者はデコード時間の値を引数として受け取り、世界時を返します。

どちらも省略可能なタイムゾーン引数を受け取ります。
タイムゾーンの形式については後述します。

デコード時間は、次の値の組です。

- *秒*：0から59までの整数
- *分*：0から59までの整数
- *時*：0から23までの整数
- *日*：1から31までの整数（上限は言うまでもなく月と年によって変わります）
- *月*：1から12までの整数
- *年*：年を表す整数。
- *曜日*：0から6までの整数。0は月曜日、1は火曜日、…、6は日曜日を表します。
- *夏時間フラグ*：`true`の値は、夏時間が適用されていることを示します。
- *タイムゾーン*：UTCからのオフセットを時間数で表した、-24から24までの数値です。
この数値は有理数で、`1/3600`の倍数でなければなりません。

```lisp
(encode-universal-time 1 2 3 4 5 2000 0) ; => 3166398121
(decode-universal-time 3166398121 0)     ; => 1
                                         ;    2
                                         ;    3
                                         ;    4
                                         ;    5
                                         ;    2000
                                         ;    3 (Thursday)
                                         ;    NIL
                                         ;    0
(decode-universal-time 2208988800 0)     ; => 0
                                         ;    0
                                         ;    0
                                         ;    1
                                         ;    1
                                         ;    1970
                                         ;    3
                                         ;    NIL
                                         ;    0
```

タイムゾーン引数を指定しなかった場合の動作には、少し興味深いところがあります。詳しくは[`decode-universal-time`][hyperspec-decode-universal-time]と[`encode-universal-time`][hyperspec-encode-universal-time]のドキュメントを確認してください。

## 内部時間

内部時間は、「内部時間単位」の正の整数値です。2つの内部時間の差で、実行中の時間を計測できます。

- `get-internal-real-time`は、現在の「実」時間、つまり「クロック」時間を返します。
- `get-internal-run-time`は処理系に大きく依存し、たとえばページングやガベージコレクションに費やした時間を含む場合もあれば含まない場合もあります。

変数`internal-time-units-per-second`には、現在実行中のLisp環境における1秒あたりの「内部時間単位」の数が入っています。
