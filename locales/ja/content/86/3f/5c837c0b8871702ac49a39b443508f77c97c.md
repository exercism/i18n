# はじめに

## 比較演算子

[比較演算子][comparison-operators]は、同じ型の2つの値を比較し、`Bool`値（`true`または`false`）を返します。
異なる型の値を比較しようとすると、コンパイラーがエラーを出します。

Swiftの標準的な比較演算子は次のとおりです。

| 演算子 | 説明         | 例              |
| ------ | ------------ | --------------- |
| `==`   | 等しい       | `1 == 1` (true) |
| `!=`   | 等しくない   | `1 != 2` (true) |
| `<`    | より小さい   | `4 < 5` (true)  |
| `<=`   | 以下         | `4 <= 4` (true) |
| `>`    | より大きい   | `3 > 1` (true)  |
| `>=`   | 以上         | `2 >= 2` (true) |

## `if`文と`else`文

[条件文][conditional-statement]は、条件が`true`と`false`のどちらに評価されるかに基づいてコードを実行します。
最も一般的な条件文は[`if`文][if]で、条件が`true`のときだけコードブロックを実行します。
`if`文は、`if`キーワードを使って書き、その後に条件と、波括弧（`{}`）で囲んだコードブロックを続けます。

```swift
let wheelCount = 4
if wheelCount == 4 {
    print("Your vehicle is a car")
}
// Prints "Your vehicle is a car"
```

`if`は`else`節と組み合わせて、条件が`false`のときに別のコードを実行できます。

```swift
let precipitationInMM = 0.5
if precipitationInMM > 0.5 {
    print("You will need an umbrella")
} else {
    print("You will not need an umbrella")
}
// Prints "You will not need an umbrella"
```

複数の条件を順番にテストするには、`else if`を使って文をつなげます。
`if`文に`else`の分岐は必須ではありませんが、どの条件にも当てはまらない場合の処理を書くために含めることもできます。

```swift
let favoriteFruit = "Apple"

if favoriteFruit == "Banana" {
    print("Your favorite fruit is a banana")
} else if favoriteFruit == "Orange" {
    print("Your favorite fruit is an orange")
} else if favoriteFruit == "Apple" {
    print("Your favorite fruit is an apple")
} else {
    print("Your favorite fruit is not a banana, orange, or apple")
}
// Prints "Your favorite fruit is an apple"
```

## `if`式

現代のSwiftでは、`if`文を値を作る式としても使えます。
各分岐が値に評価されるので、条件に応じて結果を代入するのが簡単になります。

```swift
let cpuBits = 32
let architecture = if cpuBits == 64 {
    "x86_64"
} else {
    "x86_32"
}

print(architecture)
// Prints "x86_32"
```

## 三項演算子

[三項条件演算子][ternary-operator]は、`if-else`式を簡潔に書くための省略記法です。
条件を評価し、その条件が`true`か`false`かに応じて、2つの値のどちらかを返します。

この演算子は3つの部分を使います：`condition ? trueExpression : falseExpression`。
`condition`が`true`に評価されれば`trueExpression`が評価されて返され、そうでなければ`falseExpression`が評価されて返されます。

三項演算子は、シンプルな1行の選択に最適です。

```swift
let showFahrenheit = true
let temperatureInCelsius = 30

let temperature = showFahrenheit ? temperatureInCelsius * 9 / 5 + 32 : temperatureInCelsius
print(temperature)
// Prints 86
```

上の例は、次のコードを簡潔に書いたものと同じです。

```swift
let showFahrenheit = true
let temperatureInCelsius = 30

let temperature = if showFahrenheit {
    temperatureInCelsius * 9 / 5 + 32
} else {
    temperatureInCelsius
}
```
