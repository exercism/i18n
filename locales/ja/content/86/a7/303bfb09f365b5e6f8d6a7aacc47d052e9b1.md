# テスト

テストを実行するには、MARSシミュレーターのGUIまたはコマンドラインから、演習のテストランナーのファイルをアセンブルして実行します。コマンドラインで実行する場合は、次のように、最初にランナーファイル、次に自分の実装を指定します。

    java -jar /path/to/mars.jar nc runner.mips impl.mips

GUIで実行する場合は、「runner.mips」の最終行のコメントを外して、末尾に自分の実装を`include`します。

テストランナーは、「success」というメッセージを出して完了するか、テストが失敗したときは、どの入力でそのテストが失敗したかを示すメッセージとともに終了します。
