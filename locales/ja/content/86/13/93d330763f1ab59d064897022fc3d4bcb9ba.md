# はじめに

Factorのデータのほとんどは*シーケンス*にあります。配列、ベクター、文字列はすべてシーケンスで、[`sequences`][sequences]ボキャブラリーの共通のワードを共有しています。

## 配列リテラル

配列リテラルは`{ }`を使い、要素の間に空白を入れます。

```factor
{ 1 2 3 } .          ! => { 1 2 3 }
{ "a" "b" "c" } .    ! => { "a" "b" "c" }
```

配列は長さが固定です。そのため、要素数を変える`suffix`や`remove-nth`といったワードは、元の配列を伸ばすのではなく、*新しい*シーケンスを返します。

## 長さとインデックス

```
length   ( seq -- n   )
first    ( seq -- elt )
rest     ( seq -- tailseq )    ! everything but the first element
last     ( seq -- elt )
but-last ( seq -- headseq )    ! everything but the last element
nth      ( n seq -- elt )      ! 0-based
?nth     ( n seq -- elt/f )    ! 0-based; f when out of bounds
```

```factor
{ 10 20 30 } length .       ! => 3
{ 10 20 30 } first .        ! => 10
{ 10 20 30 } rest .         ! => { 20 30 }
{ 10 20 30 } last .         ! => 30
{ 10 20 30 } but-last .     ! => { 10 20 }
1 { 10 20 30 } nth .        ! => 20
```

`?nth`は範囲外でも安全なバージョンです。長さを先に確認しなくても、位置を調べられます。

```factor
1 { 10 20 30 } ?nth .       ! => 20
9 { 10 20 30 } ?nth .       ! => f  (out of bounds, no error)
```

## スライス

```
head ( seq n -- headseq )    ! first n elements
tail ( seq n -- tailseq )    ! drop first n
```

```factor
{ 1 2 3 4 5 } 3 head .   ! => { 1 2 3 }
{ 1 2 3 4 5 } 3 tail .   ! => { 4 5 }
```

`n`がシーケンスより大きい場合、どちらもエラーになります。`n`が大きすぎるときは、`index-or-length`がそれをシーケンスの長さまで縮めてくれるので、そのあとのスライスが末尾をはみ出すことはありません。

```
index-or-length ( seq n -- seq n' )
```

```factor
{ 10 20 30 40 50 } 3 index-or-length head .   ! => { 10 20 30 }
{ 10 20 } 3 index-or-length head .            ! => { 10 20 }
```

アスタリスク付きの`head*`と`tail*`は末尾から数えます。`head*`は最後の`n`個を落とし、`tail*`は最後の`n`個を残します。

```
head* ( seq n -- headseq )   ! everything except the last n
tail* ( seq n -- tailseq )   ! the last n elements
```

```factor
{ 1 2 3 4 5 } 2 head* .   ! => { 1 2 3 }
{ 1 2 3 4 5 } 2 tail* .   ! => { 4 5 }
```

2つのインデックス間の任意のスライスには、`subseq`を使います。これは*開始*（含む）と*終了*（含まない）を取ります。

```
subseq ( from to seq -- subseq )
```

```factor
1 4 { 10 20 30 40 50 } subseq .   ! => { 20 30 40 }
1 4 "hello" subseq .              ! => "ell"
```

*開始位置と長さ*が分かっているときは、それらを足して終了位置を求めます。

```factor
2 dup 3 + "hello world" subseq .  ! => "llo"
```

（これはインデックス範囲`[2, 5)`で、位置2から始まる3文字です。）

逆の質問、つまり*部分シーケンスがどこにあるか*には、`subseq-index`が答えてくれます。これは最初に一致した位置の開始インデックスを返し、見つからなければ`f`を返します。

```
subseq-index ( seq subseq -- i/f )
```

```factor
"hello world" "o w" subseq-index .   ! => 4
"hello world" "xyz" subseq-index .   ! => f
```

## パディング

```
pad-head ( seq n elt -- padded )    ! prepend copies of elt
pad-tail ( seq n elt -- padded )    ! append copies of elt
```

どちらも`seq`を、長さが少なくとも`n`になるまで伸ばします。`seq`がすでにその長さなら、そのまま返されます。

```factor
{ 2 5 0 } 6 0 pad-tail .   ! => { 2 5 0 0 0 0 }
{ 4 1 } 5 9 pad-head .     ! => { 9 9 9 4 1 }
```

## 同じワードが文字列でも使える

文字列は文字のシーケンスなので、ここまでのすべてが文字列でも使えます。結果は配列ではなく、別の文字列になるだけです。

```factor
"hello" length .            ! => 5
"hello" 3 head .             ! => "hel"
"abc" 6 CHAR: . pad-tail .   ! => "abc..."
```

## 集計

`sum`と`product`（[`sequences`][sequences]にあります）は、数値のシーケンスの要素を足し合わせたり掛け合わせたりします。

```factor
{ 2 5 0 7 } sum .        ! => 14
{ 2 5 3 7 } product .    ! => 210
```

`count`はシーケンスに対して述語を実行し、それを真にした要素の個数を返します。

```
count ( seq quot -- n )
```

```factor
{ 2 5 0 7 4 1 } [ even? ] count .    ! => 3
```

## シーケンス全体に対する述語

```
any?   ( seq quot -- ? )
all?   ( seq quot -- ? )
empty? ( seq -- ? )
```

```factor
{ 2 5 0 7 } [ 4 > ] any? .      ! => t
{ 2 5 0 7 } [ 0 > ] all? .      ! => f
```

## 新しいシーケンスを作る

`suffix`はシーケンスの末尾に要素を追加し、`prefix`は先頭に追加します。`unclip`は最初の要素をはがし、`unclip-last`は最後の要素をはがします。

```
prefix      ( seq elt -- newseq )
suffix      ( seq elt -- newseq )
unclip      ( seq -- rest first )
unclip-last ( seq -- butlast last )
```

```factor
{ 7 9 } 3 prefix .             ! => { 3 7 9 }
{ 7 9 } 3 suffix .             ! => { 7 9 3 }
{ 4 0 9 } unclip .s
! => { 0 9 }
! => 4
```

`unclip-last`と`suffix`を組み合わせると、最後の要素を破壊せずに更新できます（`unclip`と`prefix`は最初の要素に対して同じことをします）。

```factor
{ 10 20 30 } unclip-last 2 * suffix .
! => { 10 20 60 }
```

## シーケンス型の間の変換

`>array`、`>vector`、`>string`（[`arrays`][arrays]と対応するボキャブラリーにあります）は、シーケンスを特定の具体的な型に変換します。ある操作がスライスや汎用的なシーケンスを返したときに、配列（または文字列）として欲しい場合に便利です。

```factor
{ 1 2 3 } 1 tail >array .   ! => { 2 3 }
"hello" >array .            ! => { 104 101 108 108 111 }
{ 65 66 67 } >string .      ! => "ABC"
```
