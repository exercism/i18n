# 説明

この演習では、映画館のウェブサイト向けのルールを作っていきます。

## 1. 観客がシニア割引の対象かどうかを確認する

この映画館では、「老齢年金」向けの割引を用意しています。
60歳以上の人はチケット代として10.00を支払います。
それより若い人は通常料金の15.00を支払います。

三項演算子を使って`Moviegoer#ticket_price`メソッドを書いてみましょう。

```ruby
Moviegoer.new(21).ticket_price
#=> 15

Moviegoer.new(65).ticket_price
#=> 10
```

## 2. 観客が怖い映画を観ることが許されているかどうかを確認する

この映画館には、簡略化された年齢確認システムがあります。
18歳以上なら怖い映画を観ることができます。
18歳未満なら観ることはできません。

`Moviegoer#watch_scary_movie?`メソッドを実装しましょう。
このメソッドは、その人が映画を観ることを許されているかどうかを返すようにします。

```ruby
Moviegoer.new(21).watch_scary_movie?
#=> true

Moviegoer.new(17).watch_scary_movie?
#=> false
```

## 3. 観客が無料のポップコーンをもらえるかどうかを確認する

この映画館にはムービークラブというプログラムがあります。
会員はどの映画を観るときも無料のポップコーンをもらえます。

`Moviegoer.claim_free_popcorn!`メソッドを実装しましょう。
観客がムービークラブの会員であれば、無料のポップコーンを渡すようにします。
会員でなければ、このメソッドはコードの先頭で定義されている`UnsupportedOperation`例外を発生させるようにします。

```ruby
Moviegoer.new(21, member: true).claim_free_popcorn!
#=> 🍿

Moviegoer.new(17, member: false).claim_free_popcorn!
#=> Exception was raised! (NotMovieClubMemberError)
```

~~~~exercism/note
この演習では、特定のスコープに対して`UnsupportedOperation`例外を定義することが求められます。
~~~~
