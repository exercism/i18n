# 指示の補足

非標準の文字列リテラルとメタプログラミングを試すのにうってつけの演習です。

非標準の文字列リテラルの簡単な紹介は、こちらの[ブログ記事](https://web.archive.org/web/20170625222109/https://iaindunning.com/blog/julia-unicode.html)にあります。メタプログラミングの詳しいガイドは、[マニュアル](https://docs.julialang.org/en/v1/manual/metaprogramming/)にあります。

以下で説明する機能を追加して、自分の解答を拡張できます。

ボーナスAに必要なのは、ブログ記事で説明されている基本だけです。ボーナスBには、Juliaでのメタプログラミングに関する、より高度な知識が必要です。

## ボーナスA
文字列に対して`ROT13`として働く文字列リテラルを実装しましょう。
```julia
R13"abcdefghijklmnopqrstuvwxyz" == "nopqrstuvwxyzabcdefghijklm"
```

## ボーナスB
文字列を`i`の値だけずらす文字列リテラル`R<i>`（`i = 0, ..., 26`）を実装しましょう。
```julia
R0"Hello, World!" == "Hello, World!"
R4"Testing 1 2 3 testing" == "Xiwxmrk 1 2 3 xiwxmrk"
R13"abcdefghijklmnopqrstuvwxyz" == "nopqrstuvwxyzabcdefghijklm"
```
