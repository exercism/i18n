# 説明

この演習では、ある定番の問題を解いてみましょう。

ボブは泥棒です。
何か月もかけて慎重に計画を練った末、ついに高級マンションのセキュリティシステムを突破することに成功しました。

目の前には、それぞれ価値（v）と重さ（w）を持つたくさんの品物が並んでいます。
ボブはもちろん、手に入る価値の合計を最大にしたいと考えています。できるものなら、品物をすべて持ち帰りたいところです。
しかし、残念なことに、持ち歩いているナップザックに入れられる重さには限界（W）があることに気づきます。

ナップザックに入れられる重さの上限（W）が与えられたとき、ボブが家の中の品物から得られる価値の最大値を求められるよう、手伝ってください。
なお、ボブはそれぞれの品物を1つしか取ることはできません。

与えられる価値はすべて正の値です。
品物は、品物の配列として表されます。
それぞれの品物には、重さと価値があります。

たとえば、次のようになります。

```none
Items: [
  { "weight": 5, "value": 10 },
  { "weight": 4, "value": 40 },
  { "weight": 6, "value": 30 },
  { "weight": 4, "value": 50 }
]

Knapsack Limit: 10
```

上の例では、1つ目の品物は重さが5で価値が10、2つ目の品物は重さが4で価値が40、というようになっています。

この例では、価値を最大にするには、ボブは2つ目と4つ目の品物を取るのがよく、そのときの価値は90になります。
ナップザックに入れられる重さの上限は10なので、90より大きな価値は得られません。
