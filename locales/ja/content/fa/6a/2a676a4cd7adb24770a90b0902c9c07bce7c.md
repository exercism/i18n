# インストール

PureScriptをインストールするもっとも簡単な方法は、Node.jsとNPMを使うことです。

Node.jsがまだパソコンにインストールされていない場合は、[Node.jsのウェブサイト](https://nodejs.org/)からダウンロードできます。Node.jsが使えるようになったら、PureScriptのコンパイラーとSpagoビルドツールをインストールするために、ターミナルに次のコマンドを入力します。

    npm install --global purescript spago

詳しい情報は、[PureScriptのリポジトリ](https://github.com/purescript/purescript/blob/master/INSTALL.md)にあります。
