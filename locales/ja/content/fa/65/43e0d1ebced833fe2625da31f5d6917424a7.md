# メンテナー向け

## Fortranのテストを作成するためのヘルパースクリプト: create_fortran_test.py

演習のテストを作成する簡単な方法は、`bin/create\_fortran\_test.py`というスクリプトを使うことです。

このスクリプトを使って、テストの雛形として使える初期状態の<exercise>\_test.f90ファイルを作成します。
通常は、生成されたファイルの中の「response」関数を、正しい関数呼び出しに置き換える必要があります。

また、Fortranは`\n`や`\t`のような特殊文字の扱いに問題があるため、これらを扱うときは特に注意してください。

### 前提条件

- 動作するCMakeとFortranコンパイラー
- Python3.x（Python2で動くようにすることもできますが、私は後方互換にする手間をかけていません）
- https://github.com/exercism/problem-specifications.gitの最新版
- git

### 新しいテストを作成するワークフロー

- `exercism/problem-specifications`から最新の変更を取得します（例: git clone git@github.com:exercism/problem-specifications.git）
- 新しい演習を作成するための新しいブランチを作成します（例: git checkout -b exercise-bob）
- 作成したい例に対してこのスクリプトを実行します
- `config/CMakeLists.txt`を演習ディレクトリにコピーします（この操作には`bin/update-cmake-files`を使えます）
- 動作する演習を実装します
- 問題になりそうなテストを修正します（例: exercise/bobの「Test 20」と「Test 24」を参照）
- `ctest`コマンドでエラーなく検証できることを確認します
- 解答を.meta/example.f90にコピーし、演習ファイル（例: bob.f90）から実際の実装を削除します
- .docsディレクトリと.metaディレクトリを更新します
  - cp ../problem-specifications/exercises/bob/description.md exercises/practice/bob/.docs/instructions.md
    - 「# Description」を「# Instructions」に置き換えます
  - .meta/tests.tomlを手動で記入します（自動化された方法ができるまで）
  - .meta/config.jsonを手動で記入します（自動化された方法ができるまで）
    - ../problem-specifications/exercises/bob/metadata.ymlを使います
- 変更を加えたプルリクエストを作成します

bobの例:

```bash
$ python bin/create_fortran_test.py -j ../problem-specifications/main/exercises/bob/canonical-data.json -t exercises/practice/bob/bob_test.f90
Namespace(json='../problem-specifications/main/exercises/bob/canonical-data.json', target='exercises/practice/bob/bob_test.f90')
Wrote : exercises/practice/bob/bob_test.f90
$ cp config/CMakeLists.txt exercises/practice/bob/.
$ cd exercises/practice/bob
$ touch bob.f90
$ mkdir build
$ cd build
$ cmake ..
$ make
$ ctest -V
```

### `CMakeLists.txt`を変更する

cmakeファイルを変更するときは、`config/`にあるマスターコピーを更新し、`bin/update-cmake-files`を使ってすべての演習ディレクトリにコピーします。

## 解答

解答ができたら、その解答を「.meta」ディレクトリに「example.f90」としてコピーします。

関数やサブルーチンの骨組みを残して学習者の助けになるようにし、演習ディレクトリには演習名のファイルを残しておくのもよいでしょう。
