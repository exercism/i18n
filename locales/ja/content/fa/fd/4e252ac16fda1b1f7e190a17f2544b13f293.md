# 指示

「ほかの」エンジニアたちが、リモートコントロールカーのプロジェクト[exercise:csharp/remote-control-competition]()に取り組んできました。そのコードをきれいにするために呼ばれました。

## 1. 車本体とテレメトリシステムの関心を分離する

`RemoteControlCar`クラスをリファクタリングして、`Telemetry`プロパティ経由でアクセスするテレメトリのメソッドとプロパティを分離しましょう。

```csharp
var car = new RemoteControlCar();
car.Telemetry.Calibrate();
car.Telemetry.SelfTest();
car.Telemetry.ShowSponsor("Walker Industries Inc.");
car.CurrentSponsor
// => "Walker Industries Inc."
car.Telemetry.SetSpeed(100, "cps");
car.GetSpeed()
// => "100 centimeters per second"
```

## 2. ほかのコードが`Telemetry`型に依存しすぎないようにする

`Telemetry`インスタンスが、車のスコープの外で作成できないようにしましょう。

## 3. ほかのコードが`Speed`構造体に依存しないようにする

`Speed`構造体が、`RemoteControlCar`クラスのスコープの外で使えないようにしましょう。

## 4. ほかのコードが`SpeedUnits`列挙型に依存しないようにする

`SpeedUnits`列挙型が、`RemoteControlCar`クラスのスコープの外で使えないようにしましょう。
