# ヒント

## 共通

- どのタスクも、ループの中でテキストを組み立てます。そのため、どれも`#FSTR`で始まり、`.str`で終わります。
- それぞれの`+`の結果は、ビルダーに代入し直します：`script := script + ...`

## 1. キューを繰り返す

- `1.upto!(times)`は、ループをちょうどその回数だけ回します。返ってくる値は不要なので、使わない変数にそのまま受け取ってもかまいません。値が何も返らない`times.times!`を使うという手もあります。
- 回数が0のときも、特別な処理は要りません。ループが実行されないだけです。

## 2. キャストのイニシャル

- `names.elt!`はそれぞれの名前を取り出します。`[0]`はその最初の文字を取り出します。
- `FSTR`は`CHAR`をそのまま受け取れるので、先に文字列へ変換する必要はありません。

## 3. 行に番号を振る

- 前の演習と同じく、1つのループで2つのイテレーターを使います。`1.up!`で数値を、`lines.elt!`でテキストを取り出します。
- 新しい行は、最初の行を除くすべての行の*前に*入ります。いちばん簡単なのは、数値を確認する方法です：`if number > 1 then ... end`
- `FSTR`は数値をそのまま受け取れるので、`script + number + ". "`は変換せずに使えます。

## 4. 行を叫ぶ

- `line.elt!`は文字列を1文字ずつたどります。
- `.upper`は文字でないものをそのままにするので、空白に特別な処理は要りません。
