# クラス

クラスは、[オブジェクト指向プログラミング][object-oriented-programming]の中心となる概念です。
[Crystalでは、すべてがオブジェクトです][everything-is-an-object]。すべてのオブジェクトには型があり、いくつかのメソッドに応答できます。
クラスはオブジェクトを作るための設計図で、変数のような状態の初期値や、メソッドのような振る舞いの実装を提供します。
オブジェクトはクラスのインスタンスで、すべてのインスタンス変数と状態を保持します。

## クラスの定義

クラスは、`class`キーワードを使い、そのあとに`UpperCamelCase`で書いたクラス名を続けて定義します。

```crystal
class Account
end
```

## インスタンスの作成

[クラスのインスタンスを作成する][new-initialize]には、`new`メソッドを使ってクラス名を呼び出します。

```crystal
class Account
end

account = Account.new
```

上の例では、変数`account`はクラス`Account`のインスタンスです。

インスタンスを作成するとき、`initialize`という特別なメソッドがコンストラクターの役割を果たします。
これはインスタンスが作成されるときに呼び出されます。
コンストラクターを使うと、インスタンスの初期状態を設定できます。
`initialize`メソッドは引数を受け取ることができ、その引数はインスタンスを作成するときに渡します。

```crystal
class Account
  def initialize(number)
    5 + number # => 9
  end
end

Account.new(4)
```

~~~~exercism/note
`initialize`メソッドは値を手動で返すことはできません。代わりに、`new`が新しく作成したインスタンスを返します。

```crystal
class Account
  def initialize(number)
    5 + number
  end
end

Account.new(4)
# => #<Account:0x7f5dc33dcea0>
```
~~~~

## インスタンスメソッド

インスタンスメソッドは、クラスのインスタンスで利用できるメソッドで、そのインスタンスに対して呼び出せます。
インスタンスメソッドは、`def`キーワードを使い、そのあとにメソッド名を続けて定義します。
クラス定義の中に定義します。

```crystal
class Account
  def balance
    100
  end
end

account = Account.new
account.balance # => 100
```

## インスタンス変数

[インスタンス変数][instance-variable]は、そのインスタンスのすべてのメソッドで利用できる変数です。
インスタンス変数にアクセスするには、インスタンスメソッドを定義する必要があります。
インスタンス変数は`initialize`メソッドで初期化できます。
`@`を先頭に付けて定義します。

```crystal
class Account
  def initialize
    @balance = 100
  end

  def balance
    @balance
  end
end

account = Account.new
account.balance
# => 100
```

インスタンス変数は、クラス定義の中でも定義できます。

```crystal
class Account
  @age = 0
end
```

### 初期化をともなうインスタンス変数

インスタンス変数は、`initialize`メソッドに渡された引数で初期化できます。
Crystalは初期化時に使われる引数の型を推論できないため、型を指定する必要があります。
これについて詳しく知りたい場合は、[型推論][type-inference]を読んでみてください。
変数の型を指定するには、`:`記号のあとに型を書きます。
たとえば、`Int32`型の`balance`というインスタンス変数を作りたい場合は、`@balance : Int32`と書きます。
また、`Bool`型の`raining`というインスタンス変数を作りたい場合は、`@raining : Bool`と書きます。

実装方法はいくつかあります。たとえば、`initialize`メソッドの引数に型を宣言し、その引数をインスタンス変数に代入する方法です。

```crystal
class Account
  def initialize(balance : Int32)
    @balance = balance
  end

  def balance
    @balance
  end
end

account = Account.new(1)
account_2 = Account.new(5)

account.balance
# => 1

account_2.balance
# => 5
```

もう一つの方法は、クラス定義の中で`@<variable> : <Type>`の形でインスタンス変数の型を宣言する方法です。

```crystal
class Weather

  @raining : Bool

  def initialize(raining)
    @raining = raining
  end

  def raining
    @raining
  end
end

weather = Weather.new(true)
weather.raining
# => true
```

## インスタンス変数の変更

メソッドはインスタンス変数を変更できます。
これらのメソッドはクラスのインスタンスに対して呼び出せます。
メソッドがインスタンス変数を変更すると、その変更は呼び出したクラスのインスタンスだけに反映されます。

```crystal
class Account
  def initialize(balance : Int32)
    @balance = balance
  end

  def withdraw(amount)
    @balance -= amount
  end

  def balance
    @balance
  end
end

account = Account.new(10)
account_2 = Account.new(10)
account.balance
# => 10

account_2.balance
# => 10

account.withdraw(5)
account.balance
# => 5

account_2.balance
# => 10
```

## クラスメソッド

[クラスメソッド][class-methods]は、クラスに対して定義されるメソッドで、そのインスタンスに対しては定義されません。
インスタンスの状態に依存しないメソッドを作る手段になります。
クラスメソッドは、`def`キーワードを使い、そのあとに`self.<method name>`を続けて定義します。
`self`は、selfが呼び出されている名前空間への参照です。
ここでは、クラス`Account`を指します。
`Account.`と書いた場合と同じになりますが、`self.`を使うのが好ましい書き方です。

```crystal
class Account
  def self.balance
    100
  end
end

Account.balance
# => 100
```
