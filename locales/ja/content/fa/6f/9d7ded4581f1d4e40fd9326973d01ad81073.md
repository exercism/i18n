# はじめに

## 文字列

Common Lispでは、文字列は[文字][concept-characters]の[ベクトル][concept-vectors]です。二重引用符で文字を囲んで書きます（例えば"Hello World!"）。

`stringp`は、与えられた値が文字列のときだけ`true`を返す述語です。

文字列は、`subseq`関数で部分文字列に分割できます。`subseq`は文字列と開始インデックスを取り、終了インデックスは省略できます。インデックスは0から始まります。

```lisp
(subseq "Hello World" 1 5)   ; => "ello"
(subseq "skip to the end" 5) ; => "to the end"
```

文字列が等しいかどうかは、`string=`で比較できます。大文字と小文字を区別したくない場合は、`string-equal`を使います。

```lisp
(string= "macaroni" "macaroni")      ; => T
(string= "macaroni" "MACARONI")      ; => NIL
(string-equal "macaroni" "MACARONI") ; => T
```

文字列を大文字にしたり、小文字にしたり、先頭だけ大文字にしたりする操作は、`string-upcase`、`string-downcase`、`string-capitalize`で行えます。

```lisp
(string-upcase "not too loud")                ; => "NOT TOO LOUD"
(string-downcase "YELL IT FROM THE ROOFTOPS") ; => "yell it from the rooftops"
(string-capitalize "practical COMMON LiSP")   ; => "Practical Common Lisp"
```
