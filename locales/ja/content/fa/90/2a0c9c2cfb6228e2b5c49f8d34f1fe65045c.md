# はじめに

レコードとは、互いに関連し合うフィールドをまとめたものです。フィールドの型はそれぞれ異なっていてもかまいません。レコードを定義するには、`type`キーワードを使います。レコードのフィールドは`{`と`}`の間に定義し、それぞれのフィールドには名前_と_型があります。レコードを作成するには、フィールドの名前を指定し、`{`と`}`の間に値を代入します。レコードを作成するときは、すべてのフィールドに値を代入しなければなりません。レコードのインスタンスのフィールドの値には、ドット記法でアクセスできます。

レコードを定義・作成するときは、各フィールドを別々の行に書くか、1行にまとめる場合はセミコロン（`;`）で区切ります。

```fsharp
// Define a record
type Address =
    { Street: string
      HouseNumber: int }

// Create a record
let oldAddress: Address =
    { Street = "Main Street"
      HouseNumber = 17 }

// Single-line alternative
type ConciseAddress = { Street: string; HouseNumber: int }
let conciseAddress: ConciseAddress = { Street = "Main Street"; HouseNumber = 17 }
```

レコードは不変なので、一度作成したレコードのフィールドの値を後から変えることはできません。レコードの値を変えたい場合は、`with`キーワードを使うと、既存のレコードのコピーを作り、1つ以上のフィールドに新しい値を設定できます。

```fsharp
// Copy the old address but change the house number
let newAddress: Address = { oldAddress with HouseNumber = 86 }
newAddress.Street      // => "Main Street"
newAddress.HouseNumber // => 86
```

レコードには_構造的等価性_があります。つまり、同じレコードの2つのインスタンスは、値がすべて同じであれば等しいとみなされます。

ドット記法でレコードのフィールドにアクセスできるだけでなく、レコードは束縛やパターンマッチングの中で_分解_することもできます。

```fsharp
let myAddress: Address = { Street = "Broadway"; HouseNumber = 123 }
let { Street = myStreet; HouseNumber = myHouseNumber } = myAddress

match myAddress with
| { HouseNumber = 1 } -> printfn "First house"
| { HouseNumber = houseNumber; Street = street } -> printfn "House number %d on %s" houseNumber street
// => "House number 123 on Broadway
```
