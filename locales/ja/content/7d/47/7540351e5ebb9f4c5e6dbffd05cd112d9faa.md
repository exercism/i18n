# 説明の補足

## 庭の形式

庭は、ヌル文字で終端された文字列として表され、各行の末尾には改行文字が付きます。

例は`"   \n * \n   \n"`のようになります。

## レジスタ

| レジスタ | 用途         | 型      | 説明                          |
| -------- | ------------ | ------- | ----------------------------- |
| `$a0`    | 入力         | アドレス | ヌル文字で終端された入力文字列 |
| `$a1`    | 入力／出力   | アドレス | ヌル文字で終端された出力文字列 |
| `$t0-9`  | 一時的       | 任意     | 一時保存用                    |
