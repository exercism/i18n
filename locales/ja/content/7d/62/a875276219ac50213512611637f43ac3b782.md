# はじめに

Exercismで解いた演習には、それぞれ模範解答が用意されています。Juliaトラックでは、その模範解答に[docstring](https://en.wikipedia.org/wiki/Docstring)が含まれているのが普通です。この演習を解き終えるころには、docstringがどのような構造になっているのか、どう書けばよいのか、REPLからどう参照すればよいのかがわかるようになります。

~~~~exercism/note
Juliaトラックで演習を解くときに、関数のdocstringを書くことは必須ではありません。書きたくなければ、書かなくてかまいません。
~~~~

## 構文

Juliaのオブジェクト（関数や型など）の直前に置いた文字列は、そのオブジェクトを説明するdocstringとして解釈されます。たとえば次のとおりです。

```julia
"Tell a joke."
joke() = ...
```

Juliaのdocstringは[Markdown](https://en.wikipedia.org/wiki/Markdown)で書式設定します。そのため、docstringの中ではインデントやコードブロック、太字といった機能を使えます。

~~~~exercism/note
対応しているMarkdownの機能の一覧は、[Markdown標準ライブラリのドキュメント](https://docs.julialang.org/en/v1/stdlib/Markdown/)にあります。
~~~~

もう少し複雑なdocstringは、次のようになります。

````julia
"""
    mean(x, y)

Compute the mean value of `x` and `y`.
"""
mean(x, y) = (x + y) / 2
````

Juliaマニュアルには、いくつか従うべき慣習があります。

> - 関数のシグネチャは必ずドキュメントの先頭に、4スペース分インデントして示します。こうするとJuliaのコードとして表示されます。
> - 簡略化したシグネチャのブロックの後に、その関数が何をするのか、あるいはそのオブジェクトが何を表すのかを説明する一行を入れます。
>    必要であれば、空行を挟んで2つ目の段落に詳しい説明を書きます。
>    関数を説明するときの一行は、三人称ではなく命令形（"Do this"、"Return that"）で書きます（"Returns the length..."のようには書きません）。
>    文末はピリオドで終えます。
> - 同じことを繰り返しません。
>    関数名はシグネチャに書かれているので、ドキュメントを"The function `mean`..."で始める必要はありません。要点から書き始めます。
> - コードと式はバッククォートで囲みます。
> - 始まりと終わりの`"""`は、それぞれ単独の行に置きます。

~~~~exercism/note
上のリストは、Exercismの文脈で必要になったり目にしたりする慣習だけをまとめたものです。省略なしの完全なリストは[Juliaマニュアル](https://docs.julialang.org/en/v1/manual/documentation/)にあります。より高度なJuliaの概念を説明するための慣習は、後の演習でその概念とあわせて紹介します。
~~~~

## docstringにアクセスする

REPLでは、`?`に続けて関数やオブジェクトの名前を入力すると、docstringを検索できます。たとえば次のとおりです。

```julia-repl
help?> println
search: println printstyled print sprint isprint

  println([io::IO], xs...)


  Print (using print) xs followed by a newline. If io is not supplied, prints to stdout.

  Examples
  ==========

  julia> println("Hello, world")
  Hello, world

  julia> io = IOBuffer();

  julia> println(io, "Hello, world")

  julia> String(take!(io))
  "Hello, world\n"
```

これは簡単な検索としても使えます。たとえば、関数のつづりが正確かどうか不安なときに便利です。

```julia-repl
help?> printline
search:

Couldn't find printline
Perhaps you meant println, pipeline, @inline or print
  No documentation found.

  Binding printline does not exist.
```
