# 概要

クォーテーションは、`[ ]`で書く、Factorにおける無名関数やコードブロックのようなものです。第一級の値なので、スタックに積んだり、保存したり、受け渡したりでき、何かがそれを*呼び出す*ときだけ実行されます。

```factor
[ 1 + ]              ! a quotation, sitting on the stack
5 [ 1 + ] call .     ! => 6
```

クォーテーションはワードの並びであり、Factorは、ある振る舞いを後で実行したりパラメーター化したりする必要があるあらゆる場面でこれを使います。

- `if`、`when`、`unless`、`cond`の分岐
- `filter`、`count`、`any?`、`all?`の述語
- `map`、`each`、`reduce`の変換
- `times`、`while`、`loop`の本体

クォーテーションのスタック効果は、たいていは推論できます。できないときは、効果を明示的に宣言します。典型的には、保存しておいて後から`call`する場合です。`call( a b -- c )`のように書きます。

## クォーテーションの組み合わせ

```
compose ( quot1 quot2 -- compound )
curry   ( value quot  -- curried )
```

`compose`は2つのクォーテーションを連結して、1つ目を実行し、続いて2つ目を実行する新しいクォーテーションを作ります。`curry`は固定の値を先頭に付け加え、元のクォーテーションを呼び出す前にその値をスタックに積むクォーテーションを返します。どちらも、`call`したり保存したり、コンビネーターに渡したりできる、普通のクォーテーションを作ります。

```factor
USING: kernel math ;

3 [ 2 * ] [ 1 + ] compose call .   ! 3 2 * 1 + => 7
5 [ 1 + ] curry call .             ! 5 1 +     => 6
```
