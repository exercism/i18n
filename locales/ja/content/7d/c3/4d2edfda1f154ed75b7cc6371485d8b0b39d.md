# 説明

RNAの配列をタンパク質に変換しましょう。

RNAは、コドンと呼ばれる3つのヌクレオチドからなる配列に分けることができ、次のようにしてポリペプチドに翻訳されます。

RNA: `"AUGUUUUCU"` => 次のように翻訳されます

コドン: `"AUG", "UUU", "UCU"`
=> これが次の配列のポリペプチドになります =>

タンパク質: `"Methionine", "Phenylalanine", "Serine"`

コドンは64種類あり、それぞれが20種類のアミノ酸に対応しています。ただし、この演習では、すべてのコドン配列とそれに対応するアミノ酸が重要というわけではありません。
1つのコドンでうまく動けば、プログラムはどのコドンでも動くはずです。
ただ、テストスイートのリストを自由に増やして、すべてのコドンを含めてもかまいません。

終止コドン（'STOP'コドンとも呼ばれます）も3つあります。これらのコドンのいずれかに（リボソームが）出会うと、翻訳はすべて終了し、タンパク質はそこで終わります。

それ以降のコドンはすべて無視されます。次のようになります。

RNA: `"AUGUUUUCUUAAAUG"` =>

コドン: `"AUG", "UUU", "UCU", "UAA", "AUG"` =>

タンパク質: `"Methionine", "Phenylalanine", "Serine"`

終止コドン`"UAA"`で翻訳が終わり、最後のメチオニンはタンパク質の配列には翻訳されないことに注目しましょう。

以下は、この演習で必要なコドンとそれに対応するアミノ酸です。

| コドン             | タンパク質    |
| :----------------- | :------------ |
| AUG                | Methionine    |
| UUU, UUC           | Phenylalanine |
| UUA, UUG           | Leucine       |
| UCU, UCC, UCA, UCG | Serine        |
| UAU, UAC           | Tyrosine      |
| UGU, UGC           | Cysteine      |
| UGG                | Tryptophan    |
| UAA, UAG, UGA      | STOP          |

タンパク質の翻訳についてもっと知りたい場合は、[Wikipediaの記事][protein-translation]を読んでみましょう。

[protein-translation]: https://en.wikipedia.org/wiki/Translation_(biology)
