# 概要

Clojureには、基本的な[フロー制御](https://clojure.org/guides/learn/flow)の構文がいくつかあります。`if`は最も重要な条件式で、条件と「then」、そして省略可能な「else」からなります。`if`が評価するのは、条件によって選ばれた分岐だけです。

```clojure
(if (even? 2) "even" "odd")
```

`cond`は、テストと式を並べたものです。それぞれのテストは順番に評価され、最初に真になったテストに対応する式が評価されて返されます。

```clojure
(cond (= x 5) "Expression to evaluate when x equals 5"
      (> x 7) "Expression to evaluate when x is greater than 7"
      :else   "Expression to evaluate in all other cases")
```
