# はじめに

## 数値

[マニュアル][man-types]より

> jqは、JSONと同じデータ型をサポートしています。数値、文字列、真偽値、配列、オブジェクト（JSONの言い方では、文字列のキーだけを持つハッシュのことです）、そして"null"です。

ここでは**数値**に注目しましょう。

### 数値と数値演算子

すべての数値は、整数であれそれ以外であれ、IEEE754倍精度浮動小数点数です。そのため、精度は53ビットに限られます。

数値には、おなじみの演算子を使えます。

- 算術演算：`+`、`-`、`*`、`/`、`%`
- 比較演算：`==`、`!=`、`<`、`<=`、`>=`、`>`
- 標準の[数学関数][man-math]

  入力が1つの関数では、値をその関数にパイプで渡します。

  ```sh
  $ jq -n '(1 | atan) * 4'
  3.141592653589793
  ```

  入力が2つの関数では、その関数は入力を無視し、値を仮引数として受け取ります（仮引数はセミコロンで区切るのでしたね）。

  ```sh
  $ jq -n 'pow(2; 10)'
  1024
  ```

  関数の引数を区切るのはセミコロンで、カンマではありません。

### その他の`jq`式

この演習を解くには、条件式について知っておく必要があります。

#### 条件式

`jq`では、**条件式**に[`if-then-else`式][if-then-else]を使います。これは_式_なので、パイプラインの中に置きます。

構文は次のとおりです：`if CONDITION then TRUE_EXPR else FALSE_EXPR end`。

`else`節は省略できます。

```jq
42 | if . < 33 then "small" else "larger" end
# => "larger"
```

条件を追加するには`elif`を使います。

```jq
42 | if . < 33 then "small"
     elif . < 67 then "medium"
     else "large"
     end
# => "medium"
```
