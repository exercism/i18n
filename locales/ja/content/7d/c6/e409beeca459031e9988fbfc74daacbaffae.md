# 指示

この演習では、名作ゲーム「パックマン」のルールをElixirの関数に置き換えていきます。

置き換えるルールは4つあり、どれもゲームの状態に関するものです。

> 引数がどのように導かれるかは気にしなくて大丈夫です。引数を組み合わせて、意図した結果を返すことだけに集中しましょう。

## 1. パックマンがゴーストを食べられるかを定義する

2つの引数（_パワーエサの効果が有効かどうか_ と _パックマンがゴーストに触れているかどうか_）を受け取り、パックマンがゴーストを食べられるかどうかを示す真偽値を返す`Rules.eat_ghost?/2`関数を定義します。この関数は、パワーエサの効果が有効で、かつパックマンがゴーストに触れているときだけ`true`を返します。

```elixir
Rules.eat_ghost?(false, true)
# => false
```

## 2. パックマンが得点するかを定義する

2つの引数（_パックマンがパワーエサに触れているかどうか_ と _パックマンがドットに触れているかどうか_）を受け取り、パックマンが得点したかどうかを示す真偽値を返す`Rules.score?/2`関数を定義します。この関数は、パックマンがパワーエサかドットに触れているときに`true`を返します。

```elixir
Rules.score?(true, true)
# => true
```

## 3. パックマンが負けるかを定義する

2つの引数（_パワーエサの効果が有効かどうか_ と _パックマンがゴーストに触れているかどうか_）を受け取り、パックマンが負けたかどうかを示す真偽値を返す`Rules.lose?/2`関数を定義します。この関数は、パックマンがゴーストに触れていて、かつパワーエサの効果が有効でないときに`true`を返します。

```elixir
Rules.lose?(false, true)
# => true
```

## 4. パックマンが勝つかを定義する

3つの引数（_パックマンがすべてのドットを食べたかどうか_、_パワーエサの効果が有効かどうか_、_パックマンがゴーストに触れているかどうか_）を受け取り、パックマンが勝ったかどうかを示す真偽値を返す`Rules.win?/3`関数を定義します。この関数は、パックマンがすべてのドットを食べていて、かつ3番で定義した引数に基づいて負けていないときに`true`を返します。

```elixir
Rules.win?(false, true, false)
# => false
```
