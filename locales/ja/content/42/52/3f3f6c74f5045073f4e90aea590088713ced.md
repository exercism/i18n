# 説明

Chaitanaはとても人気のテーマパークを経営しています。
アトラクションは、美しく手入れされた庭園のちょうど中心に1つだけです。The Biggest Roller Coaster in the World(TM)です。
この1つのアトラクションしかないにもかかわらず、世界中から人々が訪れ、Chaitanaのハイパーコースターに乗るために何時間も列に並びます。

このアトラクションには2つの列があり、それぞれが`array`で表されます。

1. 通常の列
2. エクスプレス列（_ファストトラックとも呼ばれます_）。追加料金を払うことで優先的にアクセスできます。

公園のゲストをもっとうまく管理するためのコードを書くよう頼まれました。
ゲスト（そしてあなたの上司であるChaitana！）が不機嫌になる前に、次の関数をできるだけ早く実装する必要があります。

## 1. 列に人を追加する

`ColossalCoaster.add_to_queue`メソッドを定義します。このメソッドは4つの引数`<express_queue>, <normal_queue>, <ticket_type>, <person_name>`をとり、その人の名前で更新された適切な列を返します。

1. `<ticket_type>`は`Int32`で、1がエクスプレス列、0が通常の列を表します。
2. `<person_name>`は、それぞれの列に追加する人の名前です（`String`として）。

```crystal
express_queue = ["Tony", "Bruce"]
normal_queue = ["RobotGuy", "WW"]
ColossalCoaster.add_to_queue(express_queue, normal_queue, 1, "RichieRich")
# => ["Tony", "Bruce", "RichieRich"]
```

## 2. 友達はどこ？

ある人が公園に遅れて到着しましたが、友達が待っている列に加わりたいと思っています。
しかし、友達がどこに並んでいるのかまったく分からず、電話をかけるための電波もありません。

`ColossalCoaster.find_my_friend`メソッドを定義します。このメソッドは2つの引数`queue`と`friend_name`をとり、その友達の名前が列の何番目にあるかを返します。

1. `<queue>`は、列に並んでいる人たちの`array`です。
2. `<friend_name>`は、インデックス（列の何番目か）を探す友達の名前です。

```crystal
ColossalCoaster.find_my_friend(["Natasha", "Steve", "T'challa", "Wanda", "Rocket"], "Steve")
# => 1
```

## 3. 一緒に並んでもいい？

友達が見つかったので（上のタスク2）、遅れて来た人は、列の中の友達の位置に加わりたいと思っています。
`ColossalCoaster.add_with_friends`メソッドを定義します。このメソッドは3つの引数`queue`、`friend_name`、`person_name`をとります。

1. `<queue>`は、列に並んでいる人たちの`array`です。
2. `<friend_name>`は、その人の位置に追加すべき友達の名前です。
2. `<person_name>`は、そのインデックスの位置に追加する人の名前です。

遅れて来た人の名前で更新された列を返します。

```crystal
ColossalCoaster.add_with_friends(["Natasha", "Steve", "T'challa", "Wanda", "Rocket"], "Steve", "Bucky")
# => ["Natasha", "Bucky", "Steve", "T'challa", "Wanda", "Rocket"]
```

## 4. 列にいる意地悪な人

列から、押したり、叫んだり、問題を起こしたりしている、本当に意地悪な人がいると聞きました。
その悪さをする人を、迷惑行為のために追い出さなければなりません！

`ColossalCoaster.remove_from_queue`メソッドを定義します。このメソッドは2つの引数`queue`と`person_name`をとります。

1. `<queue>`は、列に並んでいる人たちの`array`です。
2. `<person_name>`は、追い出す必要がある人の名前です。

意地悪な人の名前を除いて更新された列を返します。

```crystal
ColossalCoaster.remove_from_queue(["Natasha", "Steve", "Eltran", "Wanda", "Rocket"], "Eltran")
# => ["Natasha", "Steve", "Wanda", "Rocket"]
```

## 5. 列を並べ替える

管理上の目的で、ある列にいるすべての名前をアルファベット順に取得する必要があります。

`ColossalCoaster.sorted_queue`メソッドを定義します。このメソッドは1つの引数`queue`（列に並んでいる人たちの`array`）をとります。
このメソッドは、`array`を並べ替えたコピーを返す必要があります。

```crystal
ColossalCoaster.sorted_queue(["Natasha", "Steve", "Eltran", "Natasha", "Rocket"])
# => ['Eltran', 'Natasha', 'Natasha', 'Rocket', 'Steve']
```
