# 指示の補足

## レジスタ

| Register | Usage     | Type    | Description                                       |
| -------- | --------- | ------- | ------------------------------------------------- |
| `$a0`    | 入力     | 整数 | 数値                                            |
| `$v0`    | 出力     | 真偽値 | アームストロング数かどうか（`0` = `false`、`1` = `true`） |
| `$t0-9`  | 一時的 | 任意 | 一時的な保存に使用                        |
