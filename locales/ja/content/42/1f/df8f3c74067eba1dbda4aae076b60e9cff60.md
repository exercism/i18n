# イテレーター

カウンターを使って配列をたどると、実際の処理が始まる前に4行分の下準備が必要です。

```sather
   i ::= 0;
   loop
      until!(i >= counts.size);
      total := total + counts[i];
      i := i + 1;
   end;
```

カウンター、終了の判定、そしてカウンターの更新。これらは数を足し合わせることとは何の関係もありません。**イテレーター**は、その3つすべてを行ってくれます。

```sather
   loop
      total := total + counts.elt!;
   end;
```

`elt!`は、ループが1回まわるたびに要素を1つずつ渡し、要素がなくなるとループを終わらせます。カウンターもなく、間違えようもなく、配列の末尾を飛び越えてしまうこともありません。

## 感嘆符

`!`はイテレーターを表す印です。すでに3つ登場しました。`until!`、`while!`、`break!`です。これらも同じルールに従います。**イテレーターはループの中でしか呼び出せません。**　ループの外で`counts.elt!`と書くとエラーになります。

ループの中で呼び出されたイテレーターは、1回まわるたびに値を1つ求められます。値がもう残っていなければ、本体のどこでその呼び出しがあっても、ループはその場で終わります。

## まずは2つ

`elt!`は、配列や文字列の要素を順番に渡します。

```sather
   loop
      #OUT + names.elt! + "\n";
   end;
```

`upto!`は数を数えます。`1.upto!(5)`は1、2、3、4、5を順に渡し、その後でループを終わらせます。

```sather
   loop
      total := total + 1.upto!(5);
   end;
```

どちらも、たまたま`!`で終わっているだけの普通のルーチンです。そのため、どちらも配列や数値に対して、ドットを付けて呼び出します。

## 計算結果を残す

ループはひとりでに終わるので、その中で求めたものは**外側**で宣言した変数に残しておく必要があります。そうしないと、ループが終わると同時に消えてしまうからです。

```sather
   total ::= 0;             -- outside
   loop
      total := total + counts.elt!;
   end;
   return total;
```
