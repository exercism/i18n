# 説明

この演習では、[ブラックジャック](https://en.wikipedia.org/wiki/Blackjack)のゲームの最初のターンをシミュレートします。

2枚のカードを受け取り、ディーラーの表向きのカードを見ることができます。
すべてのカードは、"ace"や"king"、"three"、"two"などの文字列で表されます。
各カードの数値は次のとおりです。

| card  | value | card    | value |
| :---: | :---: | :-----: | :---: |
|  ace  |  11   | eight   |   8   |
|  two  |   2   | nine    |   9   |
| three |   3   |  ten    |  10   |
| four  |   4   | jack    |  10   |
| five  |   5   | queen   |  10   |
|  six  |   6   | king    |  10   |
| seven |   7   | *other* |   0   |

**注意**：一般に、aceは1または11の値を取ることができますが、簡単のため、ここでは11の値だけを取るものとします。

手持ちの2枚のカードとディーラーのカードに応じて、ゲームの最初のターンには戦略があり、次の選択肢から選びます。

- スタンド（S）
- ヒット（H）
- スプリット（P）
- 自動的に勝利（W）

まだ最適とは言えませんが、ここでは友人のAlexが開発してきた戦略に従います。その戦略は次のとおりです。

- aceのペアを持っている場合は、必ずスプリットします。
- ブラックジャック（2枚のカードの合計が21になる場合）で、ディーラーがace、絵札（Jack/Queen/King）、tenのいずれも持っていない場合は、自動的に勝利します。
  ディーラーがこれらのカードのいずれかを持っている場合は、スタンドして、もう1枚のカードが公開されるのを待たなければなりません。
- カードの合計が[17, 20]の範囲にある場合は、必ずスタンドします。
- カードの合計が[12, 16]の範囲にある場合は、ディーラーが7以上でない限り必ずスタンドします。ディーラーが7以上の場合は、必ずヒットします。
- カードの合計が11以下の場合は、必ずヒットします。

## 1. 与えられたカードの数値を計算する

カードの数値を計算する関数を実装してください：

```go
value := ParseCard("ace")
fmt.Println(value)
// Output: 11
```

## 2. 最初のターンの判断ロジックを実装する

上で説明した判断ロジックを実装する関数を書いてください：

```go
func FirstTurn(card1, card2, dealerCard string) string
```

期待される結果の例をいくつか示します：

```go
FirstTurn("ace", "ace", "jack") == "P"
FirstTurn("ace", "king", "ace") == "S"
FirstTurn("five", "queen", "ace") == "H"
```
