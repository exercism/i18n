# はじめに

構造体やクラスにデータを保存するプロパティと同じように、構造体やクラスに関数を保存する_メソッド_も定義できます。

メソッドの定義のしかたは通常の関数と同じですが、定義する場所は構造体やクラスの本体の中だけです。なお、構造体のプロパティの値を変更する関数には、先頭に`mutating`キーワードを付ける必要があります。また、メソッドから変更できるプロパティは、通常の変数と同じように、`let`ではなく`var`を使って定義する必要があります。

```swift
struct CharacterStats {
  var health = 0.0
  var speed = 0
  var strength = 0

  mutating func takeHit(_ damage: Double) {
    health = max(0.0, health - damage)
  }
  func canLift(_ weight: Int) -> Bool {
    weight < strength * 100
  }
}
```

これらのメソッドは、プロパティと同じように、ドット記法で呼び出すことができます。

```swift
var stats = CharacterStats(health: 72.8, speed: 19, strength: 6)
stats.canLift(500)
// => true
```
