# 説明

この演習では、ログ行を処理します。

各ログ行は、次のようにフォーマットされた文字列です：`"[<LEVEL>]: <MESSAGE>"`

ログレベルは次の3つです。

- `INFO`
- `WARNING`
- `ERROR`

タスクは3つあり、それぞれのタスクでは、ログ行を受け取ってそれを使って何かをするよう求められます。

## 1. ログ行からメッセージを取得する

`message`関数を実装して、ログ行のメッセージを返すようにしましょう。

```gleam
message("[ERROR]: Invalid operation")
// -> "Invalid operation"
```

先頭や末尾の空白は取り除きます。

```gleam
message("[WARNING]:  Disk almost full\r\n")
// -> "Disk almost full"
```

## 2. ログ行からログレベルを取得する

`log_level`関数を実装して、ログ行のログレベルを返すようにしましょう。ログレベルは小文字で返します。

```gleam
log_level("[ERROR]: Invalid operation")
// -> "error"
```

## 3. ログ行を整形する

`reformat`関数を実装して、ログ行を整形しましょう。メッセージを先にして、そのあとにログレベルを丸括弧で囲んで置きます。

```gleam
reformat("[INFO]: Operation completed")
// -> "Operation completed (info)"
```
