# インストール

Reasonをインストールするには、Node Package Manager（`npm`）が必要です。[こちら](https://www.npmjs.com/get-npm)の手順に従ってください。

`npm`が使えるようになったら、次のコマンドでReasonをインストールします。
```
npm install -g bs-platform
```

Reasonは多くのエディターに対応しています。詳しくは[こちら](https://reasonml.github.io/docs/en/editor-plugins.html#officially-supported-editors)を参照してください。

シェルでReasonの式を評価できるREPLを含む、いくつかのコマンドラインツールは[こちら](https://github.com/reasonml/reason-cli)にあります。
