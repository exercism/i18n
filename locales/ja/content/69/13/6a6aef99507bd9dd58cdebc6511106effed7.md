# 説明

この演習では、Larry the Lisp Alienがログ文字列を解析して整形できるようにするコードを書きます。こうしたログ文字列はさまざまなシステムから送られてくるので、そのメッセージをわかりやすい監視画面に表示できるよう、処理する必要があります。

ログ文字列は`"[<level>]: <message>"`という形式です。レベルは、`info`、`warn`、`ohno`のいずれかになります。

## 1. メッセージを取り出す

ログ文字列を受け取り、その中に含まれるメッセージに評価される関数`log-message`を定義します。

```lisp
(log-message "[ohno]: whoops!") ; => "whoops!"
```

## 2. 深刻度を判定する

ログ文字列のレベルによって、その深刻度が決まります。

- レベルが`info`なら、深刻度は`:everything-ok`です
- レベルが`warn`なら、深刻度は`:getting-worried`です
- レベルが`ohno`なら、深刻度は`:run-for-cover`です

ログ文字列を受け取り、正しい深刻度に評価される関数`log-severity`を定義します。

```lisp
(log-severity "[warn]: might want to get that checked") ; => :getting-worried
```

## 3. 現実の気まぐれに対処する

残念ながら、ログ文字列がいつも正しく整形されているとは限りません。特に、ログレベルが上で指定したようなすべて小文字になっていないことがあります。これに対応できるよう、`log-severity`を修正します。

```lisp
(log-severity "[WaRn]: string case system failing") ; => :getting-worried
```

## 4. ログの深刻度に応じてログメッセージを整形する

深刻度に応じて、メッセージは次のように変更します。

- 深刻度が`:everything-ok`なら、メッセージをすべて小文字に変更します。
- 深刻度が`:getting-worried`なら、メッセージの各単語を先頭が大文字になるように変更します。
- 深刻度が`:run-for-cover`なら、メッセージをすべて大文字に変更します。

ログメッセージを受け取り、適切に整形されたメッセージに評価される関数`log-format`を定義します。

```lisp
(log-format "[ohno]: whoops!") ; => WHOOPS!
```
