# `for`ループについて

[`for`ループ](https://docs.oracle.com/javase/tutorial/java/nutsandbolts/for.html)は、ある条件が満たされるまで、まとまった文を繰り返し実行するための仕組みです。このループは、4つの部分からできています。

```java
for (initialization; test; update) {
    body;
}
```

`initialization`は、ループの初期状態を設定する部分で、ループの開始時にちょうど1回だけ実行されます。ふつうは、テスト式と更新式で使う変数を宣言して代入します。たとえば、次のとおりです。

```java
int i = 1
```

`test`式は、ループを終了すべきかどうかを判定します。真と評価されれば、本体が実行され、続いて更新式が実行されます。偽と評価されれば、本体も更新式も実行されず、ループの閉じ括弧（`}`）の後ろから実行が再開されます。ふつうは、`initialization`ブロックで代入した変数をチェックします。たとえば、次のとおりです。

```java
i <= 10
```

ループ本体を実行したあとに、`update`式が実行されます。ふつうは、ループ変数を何らかの値だけ増やしたり減らしたりします。たとえば、次のとおりです。

```java
i++
```

`for`ループで最初の4つの平方を出力すると、次のようになります。

```java
for (int i = 1; i <= 4; i++) {
    System.out.println(i * i);
}

/* =>
1
4
9
16
*/
```

コレクションのすべての要素を繰り返し処理するなら、`for-each`ループのほうが適していますが、次のように`for`ループでも書けます。

```java
for (int i = 0; i < array.length; i++) {
    System.out.print(array[i]);
}
```

`for`ループには、`for-each`ループにはない利点がいくつかあります。

- 好きなインデックスから始めたり、好きなインデックスで終えたりできます。
- 好きな（真偽値の）終了条件を使えます。
- ループ変数の増やし方を工夫すれば、要素を飛ばせます。
- カウントダウンすれば、コレクションを後ろから前に処理できます。
- コレクションを扱わない場面でも、`for`ループを使えます。
