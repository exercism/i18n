自動フィードバック戦略の第2弾、Representerを正式にリリースしました！　この記事では、Representerの仕組みと、それがどれほど役に立つのかを手短に紹介します。いつもより少し技術的な内容なので、しっかりついてきてくださいね！

## Representerとは？

Representerとは、学習者の解答を受け取り、それを正規化した表現として返すソフトウェアです。そして、この表現を使って自動フィードバックと分類を効率化します。

Representerについて理解するには、例を見るのがいちばんわかりやすいでしょう。2人の学習者がRubyの`hello-world`演習に解答を提出したとします。

```ruby
# Student 1's submission
def self.hello(name = 'World')
  "Hello, #{name}!"
end
```

```ruby
# Student 2's submission
def self.hello(nom='World')
    "Hello, #{nom}!"
end
```

この2つの解答は、コード自体は異なります（インデント、変数名、文字列の書き方などが違います）が、本質的には同じものです。そこで、これらを正規化した表現にすることで、フィードバックを与えるうえで同じものとして_扱う_ことができます。

## なぜ役に立つのでしょうか？

こうした正規化された表現を作ることで、ある解答に与えたフィードバックを、似た他の解答にも自動的に適用できます。つまり、学習者としては、すぐに的を射たフィードバックを受け取れる可能性がぐっと高くなります。メンターとしては、似た解答に同じフィードバックを何度も与える必要はもうありません。Automation UIで一度行えば、あとは魔法のように機能します。

Representerと既存のAnalyzerを組み合わせて使うこともできます。Analyzerは変数名やlintなど一般的な点についてコメントでき、表現はもっと大きな変更点に集中できます。まだほんの表面をかすったばかりで、可能性は計り知れません。

## 誰がフィードバックを追加できるのでしょうか？

表現にフィードバックを追加できるのは、スーパーメンターだけです。スーパーメンターは約150人で、何百人もの学習者をメンタリングし、高いメンター評価を維持している人たちです。

スーパーメンターであれば、Mentoring Dashboardで「Automation」タブが使えるようになっているはずです。ここから、フィードバックを追加できる解答にアクセスできます。うまく行うには細かいコツがたくさんあるので、ドキュメントをよく読んでくださいね！
