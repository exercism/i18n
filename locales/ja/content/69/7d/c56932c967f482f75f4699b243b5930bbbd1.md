# 制御フロー

`if`式とループは、Cairoで実行の流れを次のように制御します。
`

- **`if`式**は、条件が`true`と評価されるかどうかに基づいて、コードを条件付きで実行します。
- **ループ**（`loop`や`while`、`for`など）は、指定した条件が`true`の間、または中断条件を満たすまで、コードを繰り返し実行します。

これらの構文は、Cairoでロジックと繰り返しを実装するための基本的な要素です。

## `if`式

Cairoの`if`式を使うと、条件分岐に基づいて実行の流れを制御できます。
真偽値の条件が`true`と評価されるか`false`と評価されるかによって、実行されるコードが決まるという構造になっています。

```rust
fn main() {
    let temperature = 30;

    if temperature > 25 {
        println!("It's hot outside!");
    }
}
```

この例は、Cairoのシンプルな`if`ブロックを示しています。
メッセージ`"It's hot outside!"`は、条件`temperature > 25`が`true`と評価されたときにだけ表示されます。
条件が`false`のときは何も実行されず、プログラムはそのまま続きます。

```rust
fn main() {
    let number: u32 = 5;

    if number < 10 {
        println!("The number is less than 10.");
    } else {
        println!("The number is 10 or greater.");
    }
}
```

このコードを実行すると、コンソールに`"The number is less than 10."`と表示されます。

### `else if`で複数の条件を扱う

`if`と`else`を組み合わせて`else if`式にすると、複数の条件を扱えます。

```rust
fn main() {
    let score: u64 = 85;

    if score >= 90 {
        println!("Grade: A");
    } else if score >= 80 {
        println!("Grade: B");
    } else if score >= 70 {
        println!("Grade: C");
    } else {
        println!("Grade: F");
    }
}
```

このコードを実行すると、コンソールに`"Grade: B"`と表示されます。

### `let`文で`if`を使う

Cairoの`if`式は、`let`文の右辺に書いて、その結果を変数に代入できます。

```rust
fn main() {
    let condition: bool = true;
    let number: felt252 = if condition {
        5
    } else {
        6
    };

    if number == 5 {
        println!("condition was true and number is {}", number);
    }
}
```

## ループ

ループは、コードブロックを繰り返すための基本的な構文で、タスクを効率よく制御しながら実行できます。
ループは、シーケンスを順にたどったり、条件に基づいてコードを繰り返し実行したりできます。
Cairoには、主に3つのループの書き方があります。

- **loop**：`break`文で明示的に止めない限り、延々と動き続ける基本のループです。
- **while**：指定した条件が`true`の間は実行を続け、条件が`false`になると止まります。
- **for**：配列などのコレクションの要素を1つずつ取り出し、要素ごとにコードを実行します。

### `loop`でコードを繰り返す

`loop`キーワードを使うと、Cairoはコードのブロックを、明示的に止めるよう指示するまで何度も繰り返し実行します。

```rust
fn main() {
    loop {
        println!("again!");
    }
}
```

このコードを実行すると、プログラムのガスが尽きるか、手動で止めるまで、コンソールに`"again!"`が延々と表示されます。

> 補足：Cairoは、ガスメーターを備えることで、無限ループのあるプログラムの実行を防いでいます。
> ガスメーターは、プログラムで実行できる計算量を制限する仕組みです。
> ガスは、命令の計算コストを表す単位です。
> ガスメーターが尽きると、プログラムは停止します。

ループを抜けるには、`break`キーワードをループの中に置き、いつ実行を止めるかをプログラムに伝えます。

```rust
fn main() {
    let mut i: usize = 0;
    loop {
        if i > 10 {
            break;
        }
        println!("i = {}", i);
        i += 1;
    }
}
```

`continue`キーワードは、ループの次の繰り返しに進み、この繰り返しの残りのコードを飛ばすようプログラムに伝えます。

```rust
fn main() {
    let mut i: usize = 0;
    loop {
        if i > 10 {
            break;
        }
        if i == 5 {
            i += 1;
            continue;
        }
        println!("i = {}", i);
        i += 1;
    }
}
```

このプログラムを実行すると、`i`が`5`のときはその値が表示されません。

#### `loop`から値を返す

`break`キーワードのあとに返したい値を書くと、`loop`から値を返せます。
これにより、`loop`を抜けて、その結果をコードの残りの部分に渡せます。

```rust
fn main() {
    let mut counter = 0;

    let result = loop {
        if counter == 10 {
            break counter * 2;
        }
        counter += 1;
    };

    println!("The result is {}", result); // prints "The result is 20"
}
```

### `while`による条件付きループ

`while`は、条件が`true`の間はコードを実行し、条件が`false`になると抜けます。

```rust
fn main() {
    let mut number = 3;
    while number != 0 {
        println!("{}!", number);
        number -= 1;
    }
    println!("LIFTOFF!!!");
}
```

### `for`でコレクションを繰り返す

`for`は、コレクションの各要素を1つずつ取り出し、要素ごとにコードを実行します。

```rust
fn main() {
    let a = [10, 20, 30, 40, 50].span();
    for element in a {
        println!("the value is: {}", element);
    }
}
```
