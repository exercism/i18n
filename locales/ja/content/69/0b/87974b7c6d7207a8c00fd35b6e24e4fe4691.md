# 指示の補足

## ワード

- `<bst> ( data-seq -- tree )` — `data-seq`の各要素を順番に挿入して木を構築します。
- `sorted-data ( tree -- seq )` — 木の要素を昇順で返します（通りがけ順の走査）。

## タプルの階層

二分探索木のノードは、*空*であるか、*データと2つの部分木を持つ*かのどちらかです。これを小さな継承階層としてモデル化します。

```factor
TUPLE: bst ;
TUPLE: leaf < bst ;
TUPLE: branch < bst data left right ;
```

`bst`は抽象的な親で、`leaf`は空の木の場合、`branch`は値と2つの`bst`の子（それぞれが`leaf`か`branch`のどちらか）を持ちます。

## 順序付け

データの比較には`before=?`（`math.order`にあります）を使います。これは数値だけでなく文字列にも使え、テストでは`"1"`、`"2"`、`"3"`のような文字列データを使います。
