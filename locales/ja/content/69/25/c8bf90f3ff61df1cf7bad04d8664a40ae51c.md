# 概要

[ペアと辞書][pairs-dicts]のコンセプトでは、Juliaの辞書型の基本について説明しました。

[`Dict`s][dict]は重要でよく使われるコレクション型なので、それを操作するための関数もたくさんあります。

## エントリーの取得

エントリーを取得するもっとも簡単な方法は、キーを使うことです（多くの言語と同じです）。ただし、存在しないキーを取り出そうとすると`KeyError`になります。

```julia-repl
julia> d = Dict(i => ('a':'c')[i] for i in 1:3)
Dict{Int64, Char} with 3 entries:
  2 => 'b'
  3 => 'c'
  1 => 'a'

julia> d[2]
'b': ASCII/Unicode U+0062 (category Ll: Letter, lowercase)

# missing key
julia> d[4]
ERROR: KeyError: key 4 not found
```

取得する前にキーの存在を確認することもできます（`haskey(d, 4)`や`4 ∈ keys(d)`のようなものを使います）が、存在しないキーに対してはデフォルト値をそのまま返せると便利なことがあります。

そのための関数が、[`get()`][get]と、その破壊的なバージョンである[`get!()`][get-bang]です。この2つは、存在しないキーを`Dict`に追加するかどうかが異なります。

```julia-repl
julia> get(d, 4, '!')
'!': ASCII/Unicode U+0021 (category Po: Punctuation, other)

# get() leaves Dict unchanged
julia> d
Dict{Int64, Char} with 3 entries:
  2 => 'b'
  3 => 'c'
  1 => 'a'

julia> get!(d, 4, '!')
'!': ASCII/Unicode U+0021 (category Po: Punctuation, other)

# get!() adds new key to Dict
julia> d
Dict{Int64, Char} with 4 entries:
  4 => '!'
  2 => 'b'
  3 => 'c'
  1 => 'a'
```

以前のコンセプトで、`delete!()`を使うとキーを指定してエントリーを削除できることを説明しました。これは、`pop!()`関数を使えば値の取得と組み合わせることができます。

```julia-repl
julia> d
Dict{Int64, Char} with 4 entries:
  4 => '!'
  2 => 'b'
  3 => 'c'
  1 => 'a'

# popped value is returned
julia> pop!(d, 3)
'c': ASCII/Unicode U+0063 (category Ll: Letter, lowercase)

# Dict is shrunk
julia> d
Dict{Int64, Char} with 3 entries:
  4 => '!'
  2 => 'b'
  1 => 'a'
```

## 繰り返し

`Dict`を繰り返し処理すると、デフォルトでは`key => value`のペアが生成されます。それぞれの要素には、おなじみの`.first`と`.second`という名前でアクセスできます。

```julia-repl
# d is from the previous example
julia> [(kv.first, kv.second) for kv in d]
3-element Vector{Tuple{Int64, Char}}:
 (4, '!')
 (2, 'b')
 (1, 'a')
```

キーだけ、あるいは値だけを使いたいこともよくありますが、これは簡単です。

```juliajulia> [k for k in keys(d)]
julia> [k for k in keys(d)]
3-element Vector{Int64}:
 4
 2
 1

julia> [v for v in values(d)]
3-element Vector{Char}:
 '!': ASCII/Unicode U+0021 (category Po: Punctuation, other)
 'b': ASCII/Unicode U+0062 (category Ll: Letter, lowercase)
 'a': ASCII/Unicode U+0061 (category Ll: Letter, lowercase)
```

## マージ

2つの`Dict`を組み合わせると便利なことがありますが、複数の入力に同じキーが存在するとき、それをどう扱いたいのかをはっきりさせておく必要があります。

[`merge()`][merge]と[`merge!()`][merge-bang]は、与えられた任意の数の`Dict`を左から右へと組み合わせます。

既存のキーの値はそのまま上書きされるので、いちばん右にある`Dict`が「勝ち」ます。

```julia-repl
julia> d3 = Dict("color" => "red", "shape" => "circle")
Dict{String, String} with 2 entries:
  "shape" => "circle"
  "color" => "red"

julia> d4 = Dict("color" => "blue", "coords" => (3, 2))
Dict{String, Any} with 2 entries:
  "color"  => "blue"
  "coords" => (3, 2)

# color from d3 is lost
julia> merge(d3, d4)
Dict{String, Any} with 3 entries:
  "shape"  => "circle"
  "color"  => "blue"
  "coords" => (3, 2)
```

[`mergewith()`][mergewith]と[`mergewith!()`][mergewith-bang]を使うと、繰り返し現れるキーをどうマージするかを決める関数を、最初の引数として渡すことができます。足し算は簡単な例です。

```julia-repl
julia> d5 = Dict("color" => "red", "area" => 3)
Dict{String, Any} with 2 entries:
  "area"  => 3
  "color" => "red"

julia> d6 = Dict("shape" => "circle", "area" => 5)
Dict{String, Any} with 2 entries:
  "shape" => "circle"
  "area"  => 5

# area values are added, not overwritten
julia> mergewith(+, d5, d6)
Dict{String, Any} with 3 entries:
  "shape" => "circle"
  "area"  => 8
  "color" => "red"
```

2つのベクトルを連結するのも、マージのときによく使う操作です。これにはJuliaの[`vcat()`][vcat]関数を使いますが、その理由は[`Multi Dimensional Arrays`][multidim]のコンセプトで説明されています。

```julia-repl
julia> d7 = Dict("vals" => [1, 2, 3])
Dict{String, Vector{Int64}} with 1 entry:
  "vals" => [1, 2, 3]

julia> d8 = Dict("vals" => [4, 5])
Dict{String, Vector{Int64}} with 1 entry:
  "vals" => [4, 5]

julia> mergewith(vcat, d7, d8)
Dict{String, Vector{Int64}} with 1 entry:
  "vals" => [1, 2, 3, 4, 5]
```

複数の[`Set`][sets]に対しては、対応するマージ関数は[`union`][union]です。

`mergewith`系の関数は、[高階関数][hof]が実際に活躍する良い例であることに注目してください。
