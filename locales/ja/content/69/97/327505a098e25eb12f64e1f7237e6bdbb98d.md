# 説明

この演習では、ログに記録されたレポートの行を処理します。
各ログ行は、`"[<LEVEL>]: <MESSAGE>"`という形式の文字列です。

ログレベルは次の3つです。

- `INFO`
- `WARNING`
- `ERROR`

タスクは3つあり、どれもログ行を受け取って、それを使って何かを行うものです。

## 1. ログ行からメッセージを取り出す

`log_line::message`メソッドを実装しましょう。ログ行のメッセージを返します。

```cpp
log_line::message("[ERROR]: Invalid operation")
// => "Invalid operation"
```

## 2. ログ行からログレベルを取り出す

`log_line::log_level`メソッドを実装しましょう。ログ行のログレベルを返します。ログレベルは大文字で返します。

```cpp
log_line::log_level("[ERROR]: Invalid operation")
// => "ERROR"
```

## 3. ログ行を整形し直す

`log_line::reformat`メソッドを実装しましょう。このメソッドはログ行を整形し直し、メッセージを先に、ログレベルをそのあとに括弧（`()`）で囲んで置きます。

```cpp
log_line::reformat("[INFO]: Operation completed")
// => "Operation completed (INFO)"
```
