# はじめに

Juliaは汎用のプログラミング言語で、ほとんどのプログラミング作業に使えます。
ただし実際には、主な用途は工学や科学の分野になることが多いです。
高速で多用途、そして高度な数値計算が、設計の中心に置かれています。

## 整数

整数は、小数点の付かない「丸い」数です。

[Basics][basics]のコンセプトでは、型を指定しなくても整数の値を変数に代入できることを見ました。

読みやすさのために、アンダースコアを桁区切りとして使えます。
コンパイラーはこれを無視します。

```julia-repl
julia> x = 3
3

julia> typeof(x)
Int64

julia> large_number = 1_234_567_890
1234567890
```


## 浮動小数点数

浮動小数点数には小数点があり、小数点の後ろに小数部があるのは、驚くことではないでしょう。

```julia-repl
julia> f = 3.45
3.45

julia> typeof(f)
Float64
```

もちろん、指数表記にも対応しています。

```julia-repl
julia> avogadro = 6.02e23
6.02e23
```

最大値と最小値には、驚くかもしれません。

```julia-repl
julia> typemax(Float64)
Inf

julia> typemin(Float64)
-Inf
```

無限大も有効な値です！

## 算術演算子

Basicsのコンセプトで説明したように、算術演算子は、子どもに教える普通の算数とほとんど同じように動きます。
べき乗に使うのは`^`で、`**`では_ありません_（どちらも他の言語ではよく使われます）。

```julia
2 + 3  # 5 (addition)
2 - 3  # -1 (subtraction)
2 * 3  # 6 (multiplication)
8 / 2  # 4.0 (division)
8 % 3  # 2 (remainder)
2 ^ 3  # 8 (exponentiation)
```

ただし、Julia特有の細かい点がいくつかあり、説明する価値があります。

### 乗算

```julia-repl
julia> x = 4.2
4.2

julia> 2 * x
8.4

julia> 2x
8.4

julia> 2.4x
10.08
```

これは驚きかもしれません。

ほとんどの他のプログラミング言語と同じように、`*`を中置演算子として使うこともいつでもできます。

しかしJuliaは、コードができるだけ数式のように見えるべきだと考える人たちによって設計されました。

変数名は文字で始めなければならないので、名前の前に数値（整数または浮動小数点数）を置くと、暗黙の乗算として扱われます。

たとえば球の表面積を求めたいときは、`4 * pi * r * r`の代わりに、次のように書けます。

```julia-repl
julia> surface(r) = 4π * r^2
surface (generic function with 1 method)

julia> surface(3)
113.09733552923255
```

πは組み込みの定数ですが、（ギリシャ）文字でもあります。
そのためパーサーは、`π`と`r`を区切るために明示的な`*`を1つ必要とします。

### 除算

`/`を中置演算子として使うと、整数を入力した場合でも、常に浮動小数点数の結果になります。

整数の除算には、他にもいくつか選択肢があります。

```julia-repl
julia> 10 / 3  # floating-point division
3.3333333333333335

julia> div(10, 3)  # integer division
3

julia> 10 ÷ 3  # synonym for div()
3

julia> 10 // 3  # rational number (fraction)
10//3
```

`div()`関数は整数の除算用で、結果はゼロに向かって切り捨てられます。正の数では下方向、負の数では上方向になります。

同義で、中置演算子`÷`も使えます。これもより数学らしく見せるためのものです。
Juliaに対応したエディターを使っているなら、`\div`と入力してから`<Tab>`キーを押します。

`//`演算子は、このコンセプトの範囲を超えています。
今のところは、`//`の結果は「有理数」で、多くの人がこれを_分数_と呼ぶ、と言っておけば十分です。

## 数値型の変換

変換は多くの場合、自動的に行われます。

```julia-repl
julia> x = 2 + 3.5
5.5

julia> typeof(x)
Float64
```

`Int64`と`Float64`を足したら、`Float64`の結果が得られました。

実際には、足し算の前に、整数が暗黙のうちに`Float64`へ変換されています。

**浮動小数点数から整数への**変換は、どうしてもより複雑です。
小数点以下の部分をどう扱いたいのかを考える必要があります。

- `round()`関数は最も近い整数に丸めます。4.5のようにちょうど中間にあたる場合は、最も近い_偶数_の整数に丸められます。
- `floor()`は下方向、`ceil()`は上方向、`trunc()`はゼロに向かって丸めます。
- たとえば`Int32()`で直接キャストしようとすると、`InexactError`で失敗します。

ただし、これらの関数は既定では、期待する整数型を返しません。
出力したい型を指定できます。

```julia-repl
julia> round(4.5)
4.0

julia> ceil(Int, 4.3)
5
```

`digits`キーワードを使えば、小数点以下の桁数を指定して丸めることもできます。

```julia-repl
julia> round(π, digits=10)
3.1415926536
```

## ゼロ除算

きっとエラーになるだけだと思うかもしれませんが、実際はそう単純ではありません。

`÷`や`//`による整数の除算は、予想どおりエラーになります。

`/`による浮動小数点数の除算は、標準的なコンピューターサイエンスの考え方ではなく、工学寄りの考え方をとります。

```julia-repl
julia> 2 / 0
Inf

julia> 0 / 0
NaN
```

前のセクションで説明したように、Juliaでは無限大も有効な浮動小数点数で、`Inf`で表されます。

分子もゼロの場合、結果は数学的に未定義です。
そのときJuliaはこれを「数値ではないもの」として扱い、`NaN`で表します。
