## Z3のインストール

### Pythonのダウンロード（まだインストールしていない場合）

最新バージョンのPythonは[こちら](https://python.org)からダウンロードできます。

* インストールの際は、PythonをPATHに追加するチェックボックスを必ず選択してください。

### Visual Studioのダウンロード（まだインストールしていない場合）

最新バージョンのVisual Studioは[こちら](https://visualstudio.microsoft.com/downloads/?utm_medium=microsoft&utm_source=docs.microsoft.com&utm_campaign=inline+link&utm_content=download+vs2019)からダウンロードできます。

* インストールの際は、**Python Development**ワークロードを選択してください。
* 右側にあるオプションのPython development packageのチェックボックスをすべて選択してください。

インストールが終わったら、Visual Studioを開いて初期設定を行ってください。

### Gitコマンドのインストール

Gitのインストール手順は[こちら](https://git-scm.com/book/en/v2/Getting-Started-Installing-Git)にあります。

* [Gitをシステム環境変数に追加する](https://stackoverflow.com/questions/4492979/git-is-not-recognized-as-an-internal-or-external-command)必要があります。

### Z3のクローン

[Z3のGithubリポジトリ](https://github.com/Z3Prover/z3)に移動して、プロジェクトを確認してください。

コンピューターでターミナルを開き、Z3リポジトリをクローンしたい場所に移動します（例：C:\Z3）。

その場所で、次を実行します。

```bash
git clone https://github.com/z3Prover/z3.git
```

### WindowsでVisual Studio Command Promptを使ってZ3をビルドする

スタートメニューから**Developer Command Prompt for VS 2019**を開きます。

Z3リポジトリをクローンしたフォルダーに移動します（例：C:\Z3）。

32ビットビルドの場合は、次を実行します。

```bash
python scripts/mk_make.py
```

64ビットビルドの場合は、次を実行します。

```bash
python scripts/mk_make.py -x
```

続けて、次を実行します。

```bash
cd build
pip install z3-solver
```



これで、Visual Studioを開き、PythonバインディングでZ3を実行できるようになっているはずです。


動作を確認するには、次を実行してみましょう。
```python
from x3 import *
x = Real('x')
y = Real('y)
s = Solver()
s.add(x + y > 5, x > 1, y > 1)
print(s.check())
print(s.model())
```

最後の2行は、`sat`と`[y = 4, x = 2]`を出力するはずです。
