# テスト

ほとんどのテストでは、[result]に代入するか、[exit]に値を渡すことで、期待される値が返るかどうかを確認します。

一部のテストでは、期待される例外を[raise]するかどうかを確認します。

## テストの実行

テストを実行するには、`make`ユーティリティが必要です。

演習のディレクトリ内で、コンソールまたはターミナルに次のように入力します。

```sh
make
```

演習の解答ファイルにまだ何も手を付けていない場合は、次のようなメッセージが表示されます。

```
Please implement your solution.
```

ですので、解答を書き始める前に、この行を削除しましょう。

デフォルトでは、最初のテストだけが実行されます。

```text
TAP version 14
1..10
ok 1 - ...
```

すべてのテストを実行するには、次のように入力します。

```sh
make test=all
```

```text
TAP version 14
1..10
ok 1 - empty_sentence
ok 2 - perfect_lower_case
ok 3 - only_lower_case
ok 4 - missing_the_letter_x
ok 5 - missing_the_letter_h
ok 6 - with_underscores
ok 7 - with_numbers
ok 8 - missing_letters_replaced_by_numbers
ok 9 - mixed_case_and_punctuation
ok 10 - am_and_AM_are_26_different_characters_but_not_a_pangram
```

すべてのテストが通ったら、その演習は完了です。解答を提出できます。

対応する番号を渡すと、実行するテストを1つだけ選ぶこともできます。たとえば、次のとおりです。

```sh
make test=2
```

このようにすると、2番目のテストだけが実行されます。
