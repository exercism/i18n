# 指示の補足

## レジスター

| レジスター | 用途 | 型 | 説明 |
| -------- | --------- | ------- | -------------------------- |
| `$a0`    | 入力     | アドレス | 品物の重さの配列      |
| `$a1`    | 入力     | アドレス | 品物の価値の配列       |
| `$a2`    | 入力     | 整数 | 品物の数            |
| `$a3`    | 入力     | 整数 | 最大重量             |
| `$v0`    | 出力     | 整数 | 最大価値              |
| `$t0-9`  | 一時的 | 任意     | 一時的な保存に使います |
