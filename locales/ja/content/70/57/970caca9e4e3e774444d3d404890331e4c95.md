# 学習

Odinはシステムプログラミング言語です。
Cと同様に、プログラマーが手動でメモリを管理する必要があります。
それでも、かなりシンプルな言語です。

Odinの学習に役立つリソースを紹介します。

まずは、次のものからOdinに触れてみましょう。

* Odinの作者が紹介する[Odin入門][video]（動画）を見てみましょう。
* [「Understanding the Odin Programming Language」][book]の著者が書いた、[Odin入門][intro]の記事を読んでみましょう。
* Odinの概念をコードで示した[デモファイル][demo]をじっくり読んでみましょう。

さらに深く学ぶには、次のとおりです。

* [Odin言語の概要][overview]
* [公式パッケージ][packages]のドキュメント
* [「Understanding the Odin Programming Language」][book]（有料）
* 公式の[「Odin Examples」][examples]セット
