# 配列

`ARRAY{T}`は、型`T`の値を並べた固定長の列です。

```sather
   row : ARRAY{STR} := |"Mia", "Ana", "Ben"|;
   sizes : ARRAY{INT} := |3, 1, 2|;
```

## 波括弧

`ARRAY{STR}`は「`STR`の配列」と読みます。波括弧に入るのは**型パラメータ**です。配列は何かの配列でなければならないので、`ARRAY`だけでは型になりません。Satherのライブラリの多くはこのように作られており、こうしたクラスを自分で書くのは後のことです。

## 位置

```sather
row[0]                 -- the first
row[row.size - 1]      -- the last
row.size               -- how many
```

位置は`0`から`.size - 1`までです。配列は自分のサイズを把握しており、それを変えることはありません。`ARRAY`に要素を追加する方法はありません。

## リテラルを使わずに作る

`#ARRAY{INT}(n)`は、それぞれが0である`n`個の値からなる配列を作ります。

```sather
   counts ::= #ARRAY{INT}(5);      -- five noughts
   counts[0] := 7;
```

位置へ代入するときも、`:=`の左側で同じ角括弧を使います。

## 範囲外

存在しない位置を読み書きしても、通常のビルドではチェックされません。役に立つメッセージを出してプログラムを止めてくれることはなく、メモリ上でたまたま隣り合っているものを読み書きするだけです。これを避ける習慣は2つあります。目で数えた数値ではなく`.size - 1`を使うこと、そしてループを終えるときはリテラルではなく`until!(i >= a.size)`を使うことです。

## 表示する

`.str`は中身を波括弧で囲んで返すので、何かを考えながら作業するときに便利です。

```sather
   #OUT + row.str;      -- {Mia,Ana,Ben}
```
