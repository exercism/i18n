# 概要

`call`は、クォーテーションをその場で実行するための万能のプリミティブです。コンパイラーがクォーテーションをリテラルとして見られる場合は、効果を推論できます。しかし、クォーテーションが変数や配列、仮引数から来ている場合は、効果を自分で宣言しなければなりません。

```factor
: apply-binary ( a b op -- c )
    call( a b -- c ) ;

5 3 [ - ] apply-binary .   ! => 2
5 3 [ + ] apply-binary .   ! => 8
```

`call( a b -- c )`という宣言は、そのクォーテーションが本当に宣言どおりの効果を持っているかを実行時にチェックするコードにコンパイルされます。一致しなければ、スタックが壊れた状態になるのではなく、はっきりとしたエラーになります。

クォーテーションをデータとして扱うこと、つまりそれを積んだり、配列に入れたり、ワードから返したりすることは、連結的なコードをとても簡潔にしてくれる要素のひとつです。「プログラム」は単なる並びでよく、それを解釈するには`each`と`call`で十分です。
