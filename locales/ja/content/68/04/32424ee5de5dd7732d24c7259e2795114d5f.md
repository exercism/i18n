# 説明の補足

## x86-64アセンブリ固有の注意点

この演習の関数は、1つ以上の数値を含む配列を受け取ります。それぞれの数値は1つの「ゲームのスコア」を表します。

x86-64アセンブリでは、配列の要素は、ベースポインターからのバイト単位のオフセットとしてアクセスします。

このベースポインターは、[System V AMD64 ABI Calling Convention](https://www.uclibc.org/docs/psABI-x86_64.pdf)に従って、レジスタで渡されます。

最初の3つの引数は、この順番で`rdi`、`rsi`、`rdx`に渡されます。

プレイヤーのゲームスコアは4バイトを占める32ビット整数として表されるので、次のように読み出せます。

| `rsi`   |
|---|
| `dword [rsi]` |
| `dword [rsi + 4]` |
| ... |
| `dword [rsi + 4*scores_count - 4]` |

`personal_top_three()`は、プレイヤーの上位のスコアをバッファーに書き込む必要があります。このバッファーもレジスタで渡され、同じ方法でアクセスします。

| `rdi`   |
|---|
| `dword [rdi]` |
| `dword [rdi + 4]` |
| ... |

整数値は、慣例により`rax`レジスタで返されます。
