# はじめに

Cairoのenumを使うと、いくつかの名前付きバリアントのうちのどれか1つをとる型を定義できます。

## 基本

enumはenumerationの略で、あるデータがとり得る値を、あらかじめ決められた集合に限定します。この`enum`がとり得る値のことをバリアントと呼びます。

```rust
#[derive(Drop)]
enum Direction {
    North,
    South,
    East,
    West,
}
```

enumの値は、バリアントを指定して作ります。

```rust
let my_direction = Direction::North;
let another_direction = Direction::West;
```

## パターンマッチング

enumのバリアントごとに処理を分けるには、matchを使います。

```rust
match my_direction {
    Direction::North => println!("Going north!"),
    Direction::South => println!("Going south!"),
    Direction::East => println!("Going east!"),
    Direction::West => println!("Going west!"),
}
```

matchの各アームは、enumのバリアントを1つずつ処理します。

## データを持つenum

enumのバリアントには、追加のデータを持たせられます。

```rust
struct Location {
    x: u32,
    y: u32,
}

enum Message {
    Text: ByteArray,
    Number: u32,
    Location: Location,
}
```

データを取り出すには、パターンマッチを使います。

```rust
match msg {
    Message::Text(content) => println!("Text: {}", content),
    Message::Number(val) => println!("Number: {}", val),
    Message::Location(Location { x, y }) => println!("Position: ({}, {})", x, y),
}
```
