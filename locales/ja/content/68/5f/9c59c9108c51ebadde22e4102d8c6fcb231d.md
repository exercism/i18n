# 説明

友人のLinusは、都市間で貨物列車を運転する機関士です。列車の扱いは素晴らしいのですが、物流やコンピューターの扱いは得意ではありません。Linusは、列車の詳細を整理し、経路データの間違いを修正するために、あなたのプログラミングの助けを借りたいと思っています。

~~~~exercism/note
スライシング、インデックス、そしてさまざまな`hash`メソッドを使えば、この演習は簡単に解けます。
ただし、以下の各タスクを解くにあたっては、パッキング、アンパッキング、多重代入を練習してほしいと思います。
~~~~

## 1. すべての貨車の配列を作成する

友人は貨車ごとの識別子（ID）を記録し続けてきましたが、システムが一度に処理しなければならない貨車の数はいつも定かではありません。
このデータが統一された**配列**にまとめられていれば、残りの物流プログラムはずっと簡単になります。

任意の数の貨車IDを受け取るメソッド`generate_list_of_wagons()`を実装してください。
各IDは正の整数です。
メソッドは、与えられたIDを単一の**配列**として`return`する必要があります。

```ruby
LocomotiveEngineer.generate_list_of_wagons(1, 7, 12, 3, 14, 8, 5)
# => [1, 7, 12, 3, 14, 8, 5]
```

## 2. 貨車の配列を修正する

ここまでで、データとそれが物流プログラムでどのように使われるかが、だんだんわかってきたのではないでしょうか。
IDシステムは常に機関車に**1**のIDを割り当て、列車内の残りの貨車には**1**より大きいランダムに選ばれたIDを割り当てます。

友人は新しい貨車を2両列車につなげなければならなかったのですが、システムを更新するのを忘れてしまいました！
そのため、列車の**配列**の最初の2両を末尾に移動させなければなりません。そうしないと、すべてが順不同になってしまいます。

さらにややこしいことに、友人は、不足している貨車IDが含まれているらしい2つ目の**配列**をちょうど見つけました。
覚えているのは、新しい貨車を移動させたあと、この2つ目の**配列**のIDを指定された機関車の直後に配置する必要がある、ということだけです。

Linusは、間違いを修正してデータを統合してくれたら、とても感謝するでしょう。

貨車IDを含む2つの**配列**を受け取るメソッド`fix_list_of_wagons()`を実装してください。
最初の**配列**の最初の2つの要素を末尾に移動し、2つ目の**配列**の値を機関車のID（**1**）の後ろ（_右側_）に挿入する必要があります。
メソッドは、変更を加えた**配列**を`return`する必要があります。

```ruby
LocomotiveEngineer.fix_list_of_wagons([2, 5, 1, 7, 4, 12, 6, 3, 13], [3, 17, 6, 15])
# => [1, 3, 17, 6, 15, 7, 4, 12, 6, 3, 13, 2, 5]
```

## 3. 不足している停車駅を追加する

貨車のデータがすべて正しくなったので、Linusは、システムの経路情報を更新してほしいと思っています。
輸送経路では、列車が貨物を積み下ろしするために、いくつかの異なる駅に停車することがあります。
それぞれの旅で、こうした中間配送地点の数は異なることがあります。
友人は、不足している、あるいは追加の配送情報で、システムの経路**ハッシュ**を更新してほしいと思っています。

経路の**ハッシュ**と、それに続く可変個のキーワード引数を受け取るメソッド`add_missing_stops()`を実装してください。
これらの引数は、1つ以上の停車駅を保持する**ハッシュ**の形か、任意の数の`stop_<number>: "city"`キーワードペアの形を取ることができます。
メソッドは、追加されたすべての停車駅を順番に保持する追加の**キー**で更新された経路**ハッシュ**を返す必要があります。

```ruby
LocomotiveEngineer.add_missing_stops({from: "New York", to: "Miami"},
                    stop_1: "Washington, DC", stop_2: "Charlotte", stop_3: "Atlanta",
                    stop_4: "Jacksonville", stop_5: "Orlando")
# => {from: "New York", to: "Miami", stops: ["Washington, DC", "Charlotte", "Atlanta", "Jacksonville", "Orlando"]}
```

~~~~exercism/note
停車駅は常に正しい順序で渡されるので、並べ替えについて心配する必要はありません。
~~~~

## 4. 経路情報を拡張する

Linusは経路プログラムに取り組んでいて、特定の経路にいくつかの重要な詳細が欠けていることに気づきました。
初期の経路情報は**ハッシュ**として構築されており、友人は、欠けているものがあればその**ハッシュ**を更新してほしいと思っています。
システム内のすべての経路はそれぞれ少しずつ異なる詳細を必要とするので、Linusは汎用的な解決策をぜひ希望しています。

2つの**ハッシュ**を受け取る`extend_route_information()`というメソッドを実装してください。
最初の**ハッシュ**には、列車の経路が結ぶ出発地と目的地の都市が含まれます。

2つ目の**ハッシュ**には、列車の速度、長さ、温度などの他の経路の詳細が含まれます。
メソッドは、すべての経路情報を含む統合された**ハッシュ**を返す必要があります。

~~~~exercism/note
2つ目の**ハッシュ**には、例に示されているものとは異なる、あるいはより多くのプロパティを含めることができます。
~~~~

```ruby
LocomotiveEngineer.extend_route_information({"from": "Berlin", "to": "Hamburg"}, {"length": "100", "speed": "50"})
# => {"from": "Berlin", "to": "Hamburg", "length": "100", "speed": "50"}
```
