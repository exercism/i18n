# 概要

Elixirのコードは、[BEAM仮想マシン][beam]で動きます。BEAMは、[Erlang][erlang]のランタイムシステムの一部です。Erlangに着想を得て、実行環境を共有しているElixirは、Erlangのライブラリと高い相互運用性を持っています。つまり、Elixirのエンジニアは、自分のElixirコードの中からErlangのライブラリを使うことができます。実際、Erlangのライブラリがすでに提供している機能のためにElixirのライブラリを書くことは、Elixirのコミュニティでは推奨されていません。

その結果、数学的な演算やタイマーの機能など、一部の機能は、ElixirではErlangを介してしか使えません。

ElixirとErlangのこの密接な関係から、一人前のElixirエンジニアになるには、Erlangの基本的な構文を学ぶことに少し時間をかけるとよいかもしれません。

## 使い方

Erlangの標準ライブラリは、特別な手順を踏むことなく、Elixirのコードからそのまま使えます。

Erlangの関数は、Elixirの関数を呼び出すのと同じように呼び出せますが、小さな違いが1つあります。Erlangのモジュール名は`snake_case`のアトムです。たとえば、`math`モジュールのErlang関数`pi/0`を呼び出すには、次のように書きます。

```elixir
:math.pi()
# => 3.141592653589793
```

## よく使われるErlangモジュール

よく使われるErlangモジュールは、Elixirの標準ライブラリに欠けている機能を提供してくれます。次のとおりです。

- `timer`モジュールは、[`sleep/1`][erl-timer-sleep]、[`send_after/2`][erl-timer-send-after]、[`send_interval/2`][erl-timer-send-interval]などの関数を提供します。
- `rand`モジュールは、[`uniform/0`][erl-rand-uniform]、[`normal/0`][erl-rand-normal]、[`seed/2`][erl-rand-seed-2]などの関数を提供します。
- [`:io_lib.format/2`][erl-io-lib-format]は、C言語スタイルの文字列フォーマット（制御シーケンスを使います）を提供します。
- `math`モジュールは、[`sin/1`][erl-math-sin]、[`cos/1`][erl-math-cos]、[`log2/1`][erl-math-log2]、[`log10/1`][erl-math-log10]、[`pow/2`][erl-math-pow]など、さまざまな数学関数を提供します。
- [`queue`][erl-queue]モジュールは、キューのデータ構造を提供します。
- [`crypto`][erl-crypto]モジュールは、暗号関連の関数を提供します。
- [`zip`][erl-zip]モジュールは、zipアーカイブを扱うための関数を提供します。
- [`calendar`][erl-calendar]モジュールは、[`iso_week_number/1`][erl-calendar-iso-week-number]など、日付と時刻を扱うための関数を提供します。Erlangの関数に`Date`、`Time`、`NaiveDateTime`の構造体を渡すには、対応するモジュールの`to_erl`関数を使ってErlangの形式に変換する必要があります。

Erlangの標準ライブラリについて調べるには、[STDLIB Reference Manual][erl-stdlib-ref]を見てみましょう。

ErlangのライブラリとのElixirの相互運用性は、Erlangの標準ライブラリにとどまりません。どんなErlangのライブラリでも、Elixirのコードで使うことができます。
