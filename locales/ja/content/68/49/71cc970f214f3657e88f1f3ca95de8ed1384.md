# 指示の補足

## 入出力の形式

単語のまとまりはそれぞれ、`null`終端された文字列として表され、各単語の末尾には改行文字が付きます。

アナグラムは、候補の単語に並んでいる順番と同じ順番で返す必要があります。

例を示すと、`"tones\nnotes\nSeton\n"`のようになります。

## レジスタ

| レジスタ | 用途         | 型      | 説明                                                           |
| -------- | ------------ | ------- | -------------------------------------------------------------- |
| `$a0`    | 入力         | アドレス | 改行を含まない、`null`終端された対象の文字列                    |
| `$a1`    | 入力         | アドレス | 各単語の後に改行が付いた、`null`終端された候補の文字列          |
| `$a2`    | 入力/出力    | アドレス | 各単語の後に改行が付いた、`null`終端された出力の文字列          |
| `$t0-9`  | 一時         | 任意     | 一時的な保存用                                                 |
