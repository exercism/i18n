# はじめに

## 仮引数のデフォルト値

関数の仮引数には、[仮引数のデフォルト値][default-parameter-values]を指定できます。仮引数リストの中で、その仮引数の型注釈のあとに値を代入すると、デフォルト値が設定されます。デフォルト値が指定された仮引数は、関数を呼び出すときに省略でき、その場合は代わりにデフォルト値が使われます。

```swift
func greeting(name: String = "guest", duration: Int = 2) -> String {
  "Welcome, \(name). Enjoy your \(duration) night stay."
}

greeting(name: "Bobo", duration: 7)
// Returns "Welcome, Bobo. Enjoy your 7 night stay."
greeting(duration: 3)
// Returns "Welcome, guest. Enjoy your 3 night stay."
greeting(name: "Wynona")
// Returns "Welcome, Wynona. Enjoy your 2 night stay."
greeting()
// Returns "Welcome, guest. Enjoy your 2 night stay."
```

## 可変長仮引数

Swiftの[_可変長仮引数_][variadic-parameters]を使うと、同じ型の0個以上の値を、関数の1つの仮引数に渡せます。これは、仮引数の型注釈に`...`を付けて示します。

これらの値は、可変長仮引数の型と同じ型の要素を持つ配列に自動的にまとめられます。

```swift
func geometricMean(_ numbers: Double...) -> Double {
  var total = 1.0
  for number in numbers {
      total *= number
  }
  return pow(total, 1.0 / Double(numbers.count))
}

geometricMean(1, 2, 3, 4, 5)
// => 2.605171084697352
```

可変長仮引数を使うときには、Swiftに1つ制限があることに注意してください。定義の中で可変長仮引数のあとに続く仮引数がある場合、可変長仮引数の直後の仮引数には、引数ラベルを_必ず_付けなければなりません。

## in-out仮引数

関数の本体では、仮引数は変数ではなく定数として扱われます。仮引数の値を変更しようとすると、コンパイル時のエラーになります。仮引数の値を変更したい関数は、[_in-out仮引数_][in-out-parameters]を使って、この変更可能性を明示する必要があります。

in-out仮引数を使うには、次の3つの点を押さえておく必要があります。

1. 関数定義の中で、仮引数の型注釈の`:`と型名の間に`inout`というキーワードを書いて、in-out仮引数であることを明示する必要があります。
2. in-out仮引数に渡す値は、定数ではなく変数として宣言する必要があります。同様に、リテラルを渡すこともできません。
3. 関数を呼び出すときは、変数名の前に`&`を付けて、変更可能であることを明示する必要があります。

これを行うと、関数はin-out仮引数の内部コピーを作り、関数の本体で指示されたとおりに変更し、関数が戻るときに変更後の値を渡された変数へコピーし直します。

```swift
func updateVersion(_ record: inout (version: Int, title: String)) {
  record.version += 1
}

var dbRecord = (version: 2, title: "Exercism")
updateVersion(&dbRecord)

// dbRecord is now (3, "Exercism")
```

~~~~exercism/warning
in-out仮引数については、ほかにも知っておくべきルールがいくつかあります。

1  in-out仮引数を持つ関数の内部では、in-out仮引数として渡された変数を参照することはできません。
2. 同じ関数で、同じ変数を複数のin-out仮引数として渡すことはできません。
   たとえば、`inoutFunc(&mutVar, &mutVar)`はコンパイラーエラーになります。
~~~~

## 入れ子関数

Swiftでは、[関数の中に関数を定義][nested-functions]できます。これは**入れ子関数**と呼ばれます。

入れ子関数は、外側のスコープを散らかすことなく、それを囲む関数のために特定の処理を行う、プライベートなヘルパーとしてよく使われます。

```swift
func makeNumber(_ number: Int) -> Int {
    func double(_ x: Int) -> Int {
        x * 2
    }

    func increment(_ x: Int) -> Int {
        x + 1
    }

    return number.isMultiple(of: 2) ? increment(double(number)) : double(number)
}

print(makeNumber(3)) // Prints 6
print(makeNumber(4)) // Prints 9
```

入れ子関数は通常の関数と同じように動作しますが、その可視性はそれを囲む関数の本体に限られます。
