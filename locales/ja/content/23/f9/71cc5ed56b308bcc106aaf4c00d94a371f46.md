# 説明

友人が、**Gross Store**という古い卸売店を営んでいます。
店の名前は、そこで扱う商品の数量に由来します。数量はすべて[グロス単位][gross-unit]で数えるからです。
友人は、店のために販売時点情報管理（POS）システムを実装してほしいと頼んできました。
**まずは、そのプロトタイプを作りましょう。**
**プロトタイプでは、数量だけを記録するようにします。**
参考までに、友人が単位の一覧を渡してくれました。

| 単位               | 値 |
| ------------------ | ----- |
| quarter_of_a_dozen | 3     |
| half_of_a_dozen    | 6     |
| dozen              | 12    |
| small_gross        | 120   |
| gross              | 144   |
| great_gross        | 1728  |

## 1. 単位をプログラムに保存する

単位を使うには、その単位をプログラムに保存しておく必要があります。

```go
units := Units()
fmt.Println(units)
// Output: map[...] with entries like ("dozen": 12)
```

## 2. 新しい顧客の請求書を作る

顧客のための新しい（空の）請求書を作る関数を実装します。

```go
bill := NewBill()
fmt.Println(bill)
// Output: map[]
```

## 3. 顧客の請求書に商品を追加する

実装するには、次のようにします：

- 与えられた`unit`が`units`マップにない場合は、`false`を返します。
- そうでなければ、商品名をキーとして顧客の`bill`に商品を追加し、`true`を返します。
- 商品がすでに請求書にある場合は、与えられた`unit`に対応する数量だけその数量を増やします。

```go
bill := NewBill()
units := Units()
ok := AddItem(bill, units, "carrot", "dozen")
fmt.Println(ok)
// Output: true (since dozen is a valid unit)
```

> 戻り値の型は`bool`であることに注意してください。

## 4. 顧客の請求書から商品を削除する

実装するには、次のようにします：

- 与えられた商品が請求書に**ない**場合は、`false`を返します。
- 与えられた`unit`が`units`マップにない場合は、`false`を返します。
- 新しい数量が0未満になる場合は、`false`を返します。
- 新しい数量が0になる場合は、`bill`から商品を完全に削除してから`true`を返します。
- それ以外の場合は、商品の数量を減らして`true`を返します。

```go
bill := NewBill()
units := Units()
ok := RemoveItem(bill, units, "carrot", "dozen")
fmt.Println(ok)
// Output: false (because there are no carrots in the bill)
```

> 戻り値の型は`bool`であることに注意してください。

## 5. 顧客の請求書にある特定の商品の数量を返す

実装するには、次のようにします：

- `item`が請求書にない場合は、`0`と`false`を返します。
- それ以外の場合は、`bill`にある商品の数量と`true`を返します。

```go
bill := map[string]int{"carrot": 12, "grapes": 3}
qty, ok := GetItem(bill, "carrot")
fmt.Println(qty)
// Output: 12
fmt.Println(ok)
// Output: true
```

> 戻り値の型は`int`と`bool`であることに注意してください。

[gross-unit]: https://en.wikipedia.org/wiki/Gross_(unit)
