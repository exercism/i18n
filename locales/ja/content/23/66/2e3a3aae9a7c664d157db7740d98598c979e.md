# テスト

## コマンドライン

コマンドラインからテストを実行するには、次のコマンドを使います。

```bash
swipl -f <exercise>.pl -s <exercise>_tests.plt -g run_tests,halt -t 'halt(1)'
```

`<exercise>`は、取り組んでいる演習の名前に置き換えてください。

## インタラクティブ

Prologを対話的に実行するには、まず次のコマンドを実行します。

```bash
swipl
```

Prologのコンソールが起動したら、自分の解答を読み込んで、次のようにテストを実行します。

```
?- ["<exercise>.pl"].
?- ["<exercise>_tests.plt"].
?- run_tests.
```

`<exercise>`は、取り組んでいる演習の名前に置き換えてください。

### 変更の再読み込み

上のファイルを読み込んだあとは、次のコマンドを実行すると、加えた変更を反映できます。

```
?- make.
```

## スキップされるテスト

演習を始めたばかりのときは、最初のテストだけが実行されます。残りのテストは、`test`ゴールに`condition(pending)`を追加してスキップされています。最初のテストが通ったら、`condition(pending)`の`pending`を`true`に変えて、次のテストのスキップを解除します。すべてのテストが実行されて通るようになるまで、これを繰り返します。

### コマンドライン

保留中のテストも実行するには、コマンドの末尾に`-- --all`引数を追加します。

```bash
swipl -f <exercise>.pl -s <exercise>_tests.plt -g run_tests,halt -t 'halt(1)' -- --all
```
