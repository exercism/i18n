# はじめに

継承は、OOP（オブジェクト指向プログラミング）の中心となる考え方です。
これはIS-A関係を表します。
プログラミングにおいても、英語と同じ意味で、親から特徴を受け継ぐことを指します（プログラミングでは、特徴にあたるのは通常、関数と変数です）。

次のような`Animal`クラスを考えてみましょう。

```java
//Creating an Animal class with bark() as a member function.
public class Animal {

    public void bark() {
        System.out.println("This is an animal");
    }

}
```

`Animal`は親クラスです。このクラスが持つ性質は、一般的なすべての動物に受け継ぐことができるからです。

次に、`Lion`という動物を考えてみましょう。クラスは次のようになります。

```java
//Lion class is a child class of Animal.
public class Lion extends Animal {

    @Override
    public void bark() {
        System.out.println("Lion here!!");
    }

}
```

~~~~exercism/note
`Override`アノテーションは、サブクラスのメソッドがスーパークラスのメソッドをオーバーライドしていることを示すために使います。
必ず必要なものではありませんが、付けておくのがよい習慣です。
~~~~

では、次のように書いてみましょう。

```java
Animal animal = new Lion(); //creating instance of Animal, of type Lion
animal.bark();
```

ここでは、`Animal`クラスを`Lion`で初期化している点に注目してください。
出力は次のようになります。

```java
Lion here!!
```

OOPでは、継承には多くの種類がありますが、Javaがサポートしているのはその一部だけです（マルチレベル継承と階層継承）。
詳しくは、[こちら][java-inheritance]をお読みください。
