# 概要

`jq`は、JSONデータを解析して変換するためのツールです。
`jq`は、JSONデータにとっての`sed`のような存在です。`sed`や`awk`、`grep`などがテキストを自由に扱えるのと同じ手軽さで、構造化データを切り出したり、絞り込んだり、写像したり、変換したりできます。

`jq`は動的型付けの関数型プログラミング言語です。
すべての値は不変です。

`jq`のプログラムは、「フィルター」のパイプラインでできています。それぞれのフィルターは、1つの項目を入力として受け取り、それを処理して、変換された0個以上の要素を出力します。
「フィルター」は「式」と呼ぶこともできます。

式の出力は、`|`演算子を使って別の式に渡すことができます。
`expressionA | expressionB`は、ある入力に`expressionA`を適用し、次に`expressionA`の出力それぞれに対して`expressionB`を繰り返し実行します。

式への入力は、`.`として明示的に参照できます。
入力を`1`だけ増やす式は、次のように書きます。`. + 1`（または`1 + .`）。

## `jq`（プログラム）と`jq`（言語）

`jq`は、さまざまなオペレーティングシステムにパッケージとしてインストールしたり、ソースからビルドしたりできるプログラムです（C言語で書かれています）。
便利な[コマンドラインオプション][cli-options]がいくつかあり、動作もかなり高速です。

`jq`というプログラムは、入力データをいくらでも複雑に操作できるようにするための_言語_も実装しています。

このExercismのトラックでは、その言語に焦点を当てます。
テストの中では、`jq`プログラムの使用例を目にすることになります。

## JSON

[json.org][json]より：

> JSON（JavaScript Object Notation）は、軽量なデータ交換フォーマットです。
> 人間が読み書きするのは簡単です。
> 機械が解析して生成するのも簡単です。
> JavaScriptプログラミング言語標準ECMA-262第3版（1999年12月）のサブセットに基づいています。
> JSONは完全に言語に依存しないテキスト形式ですが、C、C++、C#、Java、JavaScript、Perl、Pythonをはじめ、C系言語のプログラマーになじみのある慣習を使っています。
> これらの特性から、JSONはデータ交換に理想的な言語となっています。

このトラックで扱うのは、JSONではなく`jq`です。
[JSONの構文とデータ型][wiki-json]については、すでに知っているものとして進めます。
