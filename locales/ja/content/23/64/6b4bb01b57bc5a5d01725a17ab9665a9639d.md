# 概要

C#の[`Attribute`][attribute-concept]を使うと、宣言を装飾してメタデータを関連付けられます。メタデータを関連付けられる対象は、クラス、メソッド、列挙型、フィールド、プロパティ、その他[対応している][attribute-targets]あらゆる宣言です。

属性を宣言に適用するには、宣言の前に角括弧（`[]`）で囲んで追加します。次の例では、`ClassAttribute`と`FieldAttribute`の両方を使っています。

```csharp
[Class]
public class MyClass
{
    [Field] public int myField;
}
```

宣言的なメタデータは、コードに追加の構造化情報を関連付けるだけで、その動作は変更しません。ただし、コードの別の部分がこのメタデータを使うことで、対象の振る舞いを変えたり、機能の一部を追加・変更・削除したり、制限したりできます。

あらかじめ定義された属性には、`Flags`、`Obsolete`、`Conditional`などがあります。なお、[`Flags`属性][flags-attribute]の完全な名前は`FlagsAttribute`ですが、属性として使うときは"Attribute"という接尾辞を省略できます。

よく使われる定義済みの属性は、次の4つです。

- `[Flags]`：System名前空間であらかじめ定義されています。列挙型がビット演算と`Enum.HasFlag()`メソッドの両方をサポートすることを示します。さらに、`ToString`ですべてのフラグが表示されます。[例を見る][flags-example]
- `[Obsolete]`：System名前空間であらかじめ定義されています。コードがなぜ廃止されたのかを伝えるメッセージを追加できます。コンパイラの警告やエラーを表示するために使えます。
- `[Conditional]`：System.Diagnostics名前空間であらかじめ定義されています。デバッグ（診断）を目的として、コンパイル時に一部のメソッド呼び出しを削除できます。
- `[CallerMemberName]`：System.Runtime.CompilerServices名前空間であらかじめ定義されています。メソッドが呼び出し元の情報を取得できるようにします。
