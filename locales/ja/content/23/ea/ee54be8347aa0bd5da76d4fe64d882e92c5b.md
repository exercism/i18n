# はじめに

[配列][arrays-concept]には、中身を分析するための組み込みメソッドが用意されています。
こうしたメソッドの多くは、`true`か`false`を返す関数を引数として受け取ります。
このような関数は[`predicate`][predicate_in_programming]と呼ばれます。

組み込みメソッドは、_`for`ループや組み込みの`forEach`メソッドの代わり_に使うためのものです。

`for`ループを使った分析の例：

```javascript
const numbers = [1, 'two', 3, 'four'];
for (var i = 0; i < numbers.length; i++) {
  if (numbers[i] === 'two') {
    return i;
  }
}
// => 1
```

組み込みメソッドを使った分析の例：

```javascript
const numbers = [1, 'two', 3, 'four'];
numbers.indexOf('two');
// => 1
```

配列の分析に使える、そのほかの便利な組み込みメソッドを以下に示します。配列メソッドの一覧は[MDN][mdn-array-methods]を参照してください。

## `includes`

> `includes()`メソッドは、配列の要素の中に特定の値が含まれているかどうかを判定し、適切に`true`または`false`を返します。[^1]

```javascript
const numbers = [1, 'two', 3, 'four'];
numbers.includes(1);
// => true
numbers.includes('one');
// => false
```

## `every`

> `every()`メソッドは、配列のすべての要素が、渡された関数によるテストを通過するかどうかを調べます。戻り値は真偽値です。[^2]

```javascript
const numbers = [1, 3, 5, 7, 9];
numbers.every((num) => num % 2 !== 0);
// => true
```

## `some`

> `some()`メソッドは、配列の中に、渡された関数によるテストを通過する要素が少なくとも1つあるかどうかを調べます。[^3]

```javascript
const numbers = [1, 3, 5, 7, 9];
numbers.some((num) => num % 2 !== 0);
// => true
```

## `find`

> `find()`メソッドは、渡されたテスト関数を満たす、配列の最初の要素の値を返します。テスト関数を満たす値がなければ、`undefined`が返されます。[^4]

```javascript
const numbers = [1, 3, 5, 7, 9];
numbers.find((num) => num < 5);
// => 1
```

## `findIndex`

> `findIndex()`メソッドは、渡されたテスト関数を満たす、配列の最初の要素のインデックスを返します。満たす要素がなければ`-1`を返し、テストを通過した要素がなかったことを示します。[^5]

```javascript
const numbers = [1, 3, 5, 7, 9];
numbers.findIndex((num) => num > 7);
// => 4
numbers.findIndex((num) => num > 9);
// => -1
```
