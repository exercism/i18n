# はじめに

C#では、_継承_を使って_クラス_の階層を定義できます。継承を使うと、派生クラス（`Car`）が親クラス（`Vehicle`）の振る舞いとデータを受け継ぐことができます。親クラスを指定しなければ、そのクラスは`object`クラスを継承します。

親クラスが派生クラスに機能を提供する方法は、次の3つです。

- 通常のメソッドを定義する。
- `virtual`メソッドを定義する。これは通常のメソッドに似ていますが、派生クラスが_変更できる_メソッドです。
- `abstract`メソッドを定義する。これは実装を持たないメソッドで、派生クラスが_必ず実装しなければならない_ものです。`abstract`メソッドを持つクラスは、そのクラス自体も`abstract`としてマークする必要があります。抽象クラスはインスタンス化できません。

`protected`アクセス修飾子を使うと、親クラスのメンバーに派生クラスからアクセスできますが、他のクラスからのアクセスは防げます。

派生クラスは、`base`キーワードを通じて親クラスのメンバーにアクセスできます。

```csharp
// Inherits from the 'object' class
abstract class Vehicle
{
    // Can be overridden
    public virtual void Drive()
    {
    }

    // Must be overridden
    protected abstract int Speed();
}

class Car : Vehicle
{
    public override void Drive()
    {
        // Override virtual method

        // Call parent implementation
        base.Drive();
    }

    protected override int Speed()
    {
        // Implement abstract method
    }
}
```

派生クラスのコンストラクターは、自分のコンストラクターのロジックを実行する_前に_、親クラスのコンストラクターを自動的に呼び出します。引数は、`base`キーワードを使って親クラスのコンストラクターに渡すことができます。

```csharp
abstract class Vehicle
{
    protected Vehicle(int wheels)
    {
        Console.WriteLine("Called first");
    }
}

class Car : Vehicle
{
    public Car() : base(4)
    {
        Console.WriteLine("Called second");
    }
}
```

1つの親クラスから複数のクラスが派生している場合、それらのクラスは同じ親クラスのメソッドをそれぞれ違う形で実装することがよくあります。これはポリモーフィズムと呼ばれる、とても重要な原則です。たとえば、上の例を少し変えた次のコードでは、`Vehicle`を使うコードが、どの種類の乗り物がインスタンス化されたかによって振る舞いを変える様子を示しています。

```csharp
abstract class Vehicle
{
   public abstract string GetDescription();
}

class Car : Vehicle
{
   public Car()
   {
   }

   public override string GetDescription()
   {
      return "Runabout";
   }
}

class Rig : Vehicle
{
   public Rig()
   {
   }

   public override string GetDescription()
   {
      return "Big Rig";
   }
}

Vehicle v1 = new Car();
Vehicle v2 = new Rig();

v1.GetDescription();
// => Runabout
v2.GetDescription();
// => Big Rig
```
