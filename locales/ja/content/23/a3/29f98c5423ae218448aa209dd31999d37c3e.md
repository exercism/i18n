# データベースの支払い監査

## 問題

ABC Corpは、SQLデータベースからすべてのデータを、その後の処理のために[Ballerinaのテーブル](https://ballerina.io/learn/by-example/table-syntax/)に読み込むことを求めています。次に、読み込んだBallerinaのテーブルにクエリを実行して、指定された金額（例えば3000.00）を超える支払いエントリーを持つ従業員の名前を見つける必要があります。

**ステップ1：**

次の列を持つBallerinaのテーブルを作成します。

`payment_id` - 整数

`amount` - 小数

`employee_name` - 文字列

**ステップ2：**

H2データベースにある対応するデータセット全体を読み込んで、上記のBallerinaのテーブルにデータを格納します。テーブルの主キーには`payment_id`を使います。

**ステップ3**

Ballerinaのクエリ式を使ってBallerinaのテーブルにクエリを実行し、指定された金額を超える支払いエントリーを持つ従業員の名前を見つけます。結果は従業員の名前の昇順で並べ替えます。返す前に、結果から重複する名前のエントリーを削除します。

> 注意：解答を実装するには、Ballerinaのテーブルを使うことが必須です。

## データベースの詳細

この問題では、用意されたH2データベースを使います。

> サンプルのデータベースファイルは`gofigure.mv.db`で、データベース名は`gofigure`です。これは`db`フォルダーの中にあります。

次のテーブルは、いくつかのサンプルデータとともに、あらかじめサンプルのH2データベースに入っています。列名とデータ型は次のとおりです。

**テーブル名**：`Employee`

| **列：**      | 型 |
| -----------       | ----------- |
| `employee_id`     | 整数、自動インクリメントの主キー       |
| `name`            | 文字列        |
| `city`            | 文字列        |
| `department`      | 文字列        |
| `age`             | 整数       |

**テーブル名**：`Payment`

| **列：**      | 型 |
| -----------       | ----------- |
| `payment_id`      | 整数、自動インクリメントの主キー       |
| `date`            | 日付        |
| `amount`          | 小数        |
| `employee_id`     | 整数        |
| `reason`          | 文字列        |

* データベースファイルは`gofigure.mv.db`です。JDBC URLは`jdbc:h2:file:/path/to/db/file`のように指定します。
* ユーザー名：`root`
* パスワード：`root`

## 制約

* クエリとBallerinaのサンプルを検証するには、`db`フォルダーにあるH2データベースファイルを使います
* Ballerina.tomlにH2データベースドライバーをプラットフォーム依存関係として追加するには、Mavenの依存関係パラメータの方法を使います

## テスト環境

* `bal test`でテストを実行でき、用意されたサンプルDBに対してテストが実行されます。

## 例

### 例1

**入力：** dbFilePath : `“/Path/to/file/gofigure”`, amount : `3000`

**出力：** `["Amanda Hug", "Anita Bath"]`

## ヒント

* データベースを扱うには、[ballerinax/java.jdbc](https://central.ballerina.io/ballerinax/java.jdbc)モジュールを使います
* JDBCドライバーを依存関係として追加する手順は、[前提条件](https://lib.ballerina.io/ballerinax/java.jdbc/latest)のセクションを参照してください
* DBからデータを取得するには、[query](https://lib.ballerina.io/ballerinax/java.jdbc/latest#Client-query)リモートメソッドを使います
* [シンプルなクエリ](https://ballerina.io/learn/by-example/mysql-query-operation)の例を参照してください
* [テーブル構文](https://ballerina.io/learn/by-example/table)の例を参照してください
* Ballerinaのテーブルから必要なデータを見つけるには、[テーブルへのクエリ](https://ballerina.io/learn/by-example/querying-tables)を使います
