# 読み取り専用のクラスとプロパティ

読み取り専用のクラスとプロパティを使うと、クラスはアクセスのしやすい`public`プロパティを定義しつつ、その変更を防ぐことができます。
プロパティを読み取り専用として宣言するには、型指定の前に`readonly`を付ける必要があります。
そのプロパティに代入できるのは1回だけですが、値を再代入したり変更しようとすると、Errorが発生します。

読み取り専用クラスは、この仕組みをさらに発展させたものです。クラスを`readonly`として宣言すると、読み取り専用の宣言が各プロパティに適用されます。
さらに、動的プロパティを追加することもできなくなります。

```php
<?php

class Block
{
    public function __construct(
        public readonly int $length;
        public readonly int $width;
    ) {
    }
}
```

Readonlyクラスはこの振る舞いを土台にしており、`readonly`として宣言すると、読み取り専用の宣言が各プロパティに適用されます。
さらに、動的プロパティの追加も防ぎます。

```php
<?php

readonly class Block
{
    public function __construct(
        public int $length;
        public int $width;
    ) {
    }
}
```
