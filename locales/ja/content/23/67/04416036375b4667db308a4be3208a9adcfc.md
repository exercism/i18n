# はじめに

## 真偽値

Gleamは、真偽の値を`Bool`型で表します。値は`True`と`False`の2つだけです。これらの値は変数に束縛できます。

```gleam
let true_variable = True
let false_variable = False
```

`&&`、`||`、`!`の各演算子を使うと、真偽値を操作できます。

```gleam
True && True  // -> True
True && False // -> False

False || True  // -> True
False || False // -> False

!False // -> True
!True  // -> False
```

`&&`と`||`演算子は短絡評価を使います。これは、演算子の右側の式が必要なときだけ評価されるという意味です。

それぞれの演算子には異なる優先順位があり、`!`は`&&`や`||`より先に評価されます。波括弧（`{}`）を使うと、式の一部を他の部分より先に評価できます。

```gleam
!True && False   // -> False
!{True && False} // -> True
```
