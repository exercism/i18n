# 指示

駆け出しのマジシャンであるElyseは、自分のデッキをさまざまな方法で分析する必要があります。
話を簡単にするため、彼女が使うのは1〜10の値のカードだけです。

## 1. デッキに特定の種類のカードが何枚あるかを調べる

Elyseは、自分のデッキに特定の種類のカードが何枚あるかを知りたいと考えています。

配列（Elyseのデッキ）と数えたいカードの種類という2つの仮引数を取る関数`cardTypeCheck`を書いてください。

<!--prettier-ignore -->
~~~exercism/note
この関数では`forEach`を使い、指定した種類のカードがデッキに何枚あるかを返します。
~~~

```javascript
const cardType = 3;
cardTypeCheck([1, 2, 3, 4], cardType);
// => 1
```

## 2. 奇数または偶数のカードが何枚あるかを調べる

別の手品のために、Elyseは自分のデッキに奇数または偶数のカードが何枚あるかを知る必要があります。

2つの仮引数を取る関数`determineOddEvenCards`を実装してください。仮引数は、カードの配列（Elyseのデッキ）と真偽値で、`true`は「偶数」、`false`は「奇数」に相当します。

この関数は、デッキの中にある奇数または偶数のカードの枚数（どちらを数えるかは2つ目の仮引数の値によって決まります）という1つの数値を返します。

<!--prettier-ignore -->
~~~exercism/note
今回は練習として、関数の実装に`for...of`ループを使ってみましょう。
~~~

```javascript
determineOddEvenCards([1, 2, 3, 1, 5, 6], true);
// => 2

determineOddEvenCards([1, 2, 3, 1, 5, 6], false);
// => 4
```
