# はじめに

## 数値の比較

`jq`では、数値を次の比較演算子と等価演算子で比較できます。

| 比較             | 演算子 |
| ---------------------- | -------- |
| より大きい           | `a > b`  |
| 以上 | `a >= b` |
| より小さい               | `a < b`  |
| 以下    | `a <= b` |
| 等しい                 | `a == b` |
| 等しくない             | `a != b` |

比較の結果は常に真偽値、つまり`true`か`false`のどちらかになります。

```jq
1 < 3,      # => true
2 != 2,     # => false
1 == 1.0    # => true
            # All numbers are floating-points, so this is different syntax
            # for the exact same value.
```

## 文字列の比較

上記の比較演算子は、文字列の比較にも使えます。
その場合は、辞書順（辞書式順序）で比較されます。
並び順は_Unicodeのコードポイントの値_によって決まります。

```jq
"Apple" > "Pear",   # => false
"a" < "above",      # => true
"a" == "A"          # => false
```

数値に見えるけれども文字列型である2つの変数を比較するときは、注意が必要です。
辞書順のため、結果は数値型の値を比較した場合と同じにはなりません。

```jq
10 < 2,     # => false
"10" < "2"  # => true (because "1" comes before "2")
```

## 「厳密な」等価性

`jq`の`==`演算子は、JavaScriptの`===`と同じように、同じに「見える」ものでも型が違えば等しくないと判断します。

```jq
"3" == 3    # => false
            # the value on the left has type string,
            # the value on the right has type number.
```

## 配列の比較

2つの配列は、対応するすべての要素が等しければ等しいとみなされます。

```jq
[1, 2, 3] == [1, 2, 3]      # => true
[1, 2, 3] == [1, 3, 2]      # => false, different order
[1, 2, 3] == [1, 2, "3"]    # => false, different types
```

## オブジェクトの比較

2つのオブジェクトは、同じキーと値のペアを持っていれば等しいとみなされます。

```jq
{name: "Joe", age: 42} == {age: 42, name: "Joe"}                # => true
{name: "Joe", age: 42} == {age: 42, name: "Jane"}               # => false
{name: "Joe", age: 42} == {age: "42", name: "Joe"}              # => false
{name: "Joe", age: 42} == {age: 42, name: "Joe", height: 175}   # => false

# comparisons will drill down as deeply as required
{a: {b: {c: [1, 2]}}} == {a: {b: {c: [1, 2]}}}                  # => true
{a: {b: {c: [1, 2]}}} == {a: {b: {c: [1, 2, 3]}}}               # => false
```
