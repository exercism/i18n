# ヒント

## 全般的なヒント

- 入力がどのように用意されるかは気にしなくてかまいません。入力を組み合わせて、意図した結果を返すことだけに集中しましょう。

## 1. パックマンがゴーストを食べられるかどうかを定義する

- 関数は[真偽値][bool]を返す必要があります。
- [真偽値][bool]演算子の`&&`を使って、入力を組み合わせて結果を求めることができます。

## 2. パックマンが得点するかどうかを定義する

- 関数は[真偽値][bool]を返す必要があります。
- [真偽値][bool]演算子の`||`を使って、入力を組み合わせて結果を求めることができます。

## 3. パックマンが負けるかどうかを定義する

- 関数は[真偽値][bool]を返す必要があります。
- [真偽値][bool]演算子の`&&`と`!`を使って、入力を組み合わせて結果を求めることができます。

## 4. パックマンが勝つかどうかを定義する

- 関数は[真偽値][bool]を返す必要があります。
- [真偽値][bool]演算子の`&&`と`!`を使って、先に実装した関数のどれか1つの入力と結果を組み合わせることができます。

[bool]: https://gleam.run/book/tour/bools.html
