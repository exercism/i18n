# はじめに

## 三項演算子

三項演算子を使うと、単純な`if/else`文をより短く書けます。
`if/else`文が、条件が真のときと偽のときの2つだけの分岐を持つなら、三項演算子で書き直すことができます。

三項演算子では、`?`と`:`を組み合わせて条件を分割します。

```ruby
condition ? true_branch : false_branch
```

`?`の左側のコードが条件で、右側には`:`で区切られた2つの分岐が書かれます。
条件が_真_なら、`:`の_左_側のコードが実行されます。
条件が_偽_なら、`:`の_右_側のコードが実行されます。

たとえば、次のコードは、

```ruby
if traffic_light == 'green'
  cross_the_road
else
  wait
end
```

このように書き直せます。

```ruby
traffic_light == 'green' ? cross_the_road : wait
```
