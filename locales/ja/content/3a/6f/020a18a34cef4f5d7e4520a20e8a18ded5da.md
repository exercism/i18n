# はじめに

C++の真偽値は`bool`型で表します。
`bool`は`true`か`false`のどちらかです。

## 論理演算子

C++では3つの真偽値演算子が使えます。`!`（NOT）、`&&`（AND）、`||`（OR）です。
代替の`not`、`and`、`or`も使えます。

```cpp
true || false // => true
true && false // => false
!true // => false
not false // => true
```

## 優先順位

3つの真偽値演算子には、それぞれ異なる_演算子の優先順位_があります。
そのため、評価される順番は`!`が最初、次に`&&`、最後に`||`です。
違う順番で評価したい場合は、真偽値の式を括弧（`()`）で囲みます。括弧の方が演算子の優先順位がさらに高いからです。

```cpp
!true && false   // => false
!(true and false) // => true
```

## 変換

数値が期待される場所で`true`や`false`を使うと、それぞれ`1`と`0`に変換されます。
真偽値の演算で数値を使うと、`0`以外はすべて`true`として扱われます。負の値でも同じです。

```cpp
!true && 0.0   // => false
true + true + false // => 2
```
