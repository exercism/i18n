# 説明

この演習では、車を買う準備を手伝うためのコードを書きます。

タスクは3つあります。運転免許が必要かどうかを判断するもの、2台の車から1台を選ぶのを手伝うもの、中古車の妥当な価格を見積もるものです。

## 1. 運転免許が必要かどうかを判断する

車両の種類によっては、運転するために運転免許が必要です。
`'car'`と`'truck'`の2種類だけが免許を必要とし、それ以外は免許なしで運転できるものとします。

車両の種類を受け取り、その種類に免許が必要かどうかを示す真偽値を返す`needsLicense(kind)`関数を実装します。

```javascript
needsLicense('car');
// => true

needsLicense('bike');
// => false
```

## 2. 購入する2台の候補から1台を選ぶ

購入できる車の候補を検討します。
2台まで絞り込めましたが、最終的な判断には助けが必要です。
そのために、2台の車を引数に取り、辞書順で先に来る方を含む判断を返す`chooseVehicle(option1, option2)`関数を実装します。

```javascript
chooseVehicle('Wuling Hongguang', 'Toyota Corolla');
// =>  'Toyota Corolla is clearly the better choice.'

chooseVehicle('Volkswagen Beetle', 'Volkswagen Golf');
// =>  'Volkswagen Beetle is clearly the better choice.'
```

## 3. 中古車の価格の見積もりを計算する

判断がついたので、次はディーラーで適正な価格で買えるようにしたいところです。
中古車の購入を考えているので、価格は車がどれくらい古いかによって変わります。
おおまかな見積もりとして、車が3年未満なら、新品だったときの元の価格の80%になるとします。
10年を超えると、50%になります。
車が3年以上10年以下なら、元の価格の70%になります。

`if`、`else if`、`else`を使ってこのロジックを適用する`calculateResellPrice(originalPrice, age)`関数を実装します（練習したいなら、他の書き方もあります）。
元の価格と車の年式を引数に取り、ディーラーでの見積もり価格を返します。

```javascript
calculateResellPrice(1000, 1);
// => 800

calculateResellPrice(1000, 5);
// => 700

calculateResellPrice(1000, 15);
// => 500
```
