# 指示

この演習では、簡単な電卓のエラー処理を実装します。

目標は、引数として`16`、`51`、`+`を受け取ったときに、`16 + 51 = 67`のようなパターンの文字列を返す、動作する電卓を作ることです。

```ruby
SimpleCalculator.calculate(16, 51, "+")
# => "16 + 51 = 67"
SimpleCalculator.calculate(32, 6, "*")
# => "32 * 6 = 192"
SimpleCalculator.calculate(512, 4, "/")
# => "512 / 4 = 128"
```

## 1. `calculate`メソッド内でエラーが発生する可能性のあるコードを処理する

このタスクで実装する中心となるのは、クラスメソッド`SimpleCalculator.calculate()`です。
このメソッドは3つの引数を取ります。
最初の2つの引数は、演算の対象となる数値です。
3番目の引数は文字列で、この演習では次の演算を実装する必要があります。

- `+`という文字列を使った足し算
- `*`という文字列を使った掛け算
- `/`という文字列を使った割り算

## 2. 不正な演算を処理する

未知の演算子記号に対して`UnsupportedOperation`例外を発生させるように、`SimpleCalculator.calculate()`メソッドを更新します。

```ruby
SimpleCalculator.calculate(1, 2, '-')
# => Raises an UnsupportedOperation
```

~~~~exercism/note
この演習では、特定のスコープに対して`UnsupportedOperation`例外を定義することが求められます。
~~~~

## 3. 無効な引数を処理する

無効な引数の型に対して`ArgumentError`例外を発生させるように、`SimpleCalculator.calculate()`メソッドを更新します。

```ruby
SimpleCalculator.calculate(1, '2', '*')
# => Raises an ArgumentError
```

## 4. ゼロ除算の例外を処理する

`ZeroDivisionError`例外を処理するように、`SimpleCalculator.calculate()`を更新します。
処理するコードは、`Division by zero is not allowed.`という内容の文字列を返す必要があります。
その他の例外は、`SimpleCalculator.calculate()`メソッドで処理してはいけません。

```ruby
SimpleCalculator.calculate(512, 0, "/")
# => returns "Division by zero is not allowed."
```
