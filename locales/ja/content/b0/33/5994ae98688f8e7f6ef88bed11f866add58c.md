# 概要

構造体やクラスのインスタンスには、暗黙的に`self`という名前のプロパティがあります。これは、そのインスタンス自身を指します。
`self`がもっともよく使われるのは、同じ名前を持つインスタンスプロパティと仮引数を区別するときです。

```swift
struct Position {
    var x = 0

    mutating func move(x: Int) {
        // Here, 'self.x' refers to the struct's property,
        // while 'x' refers to the parameter passed to the method.
        self.x = x
    }
}
```

Swiftの型には、先頭を大文字にした`Self`というキーワードも用意されています。これは、インスタンス自身ではなく、そのインスタンスの*型*を指します。
