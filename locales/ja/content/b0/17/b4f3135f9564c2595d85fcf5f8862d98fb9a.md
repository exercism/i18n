# 概要

Goには、整数値または浮動小数点値の集合を表せる基本的な数値型があります。
必要な値の大きさや、アプリケーションが動作するコンピューターのアーキテクチャ（32ビットや64ビットなど）によって、異なる型が存在します。

この概念では、2つの数値型に焦点を当てます：

- `int`：例えば`0`、`255`、`2147483647`。
   少なくとも32ビットの符号付き整数です（値の範囲：-2147483648から2147483647まで）。
   ただし、これはシステムのアーキテクチャによって異なります。
   現代のほとんどのコンピューターは64ビットなので、`int`のサイズは64ビットになります（値の範囲：-9223372036854775808から9223372036854775807まで）。

- `float64`：例えば`0.0`、`3.14`。
   すべての64ビット浮動小数点数の集合を含みます。

利用できる数値型の完全なリストと詳細については、以下のリソースを参照してください：

- [Goの組み込み型宣言][go-builtins]
- [Digital Ocean - Goのデータ型を理解する][do-understanding-types]
- [Arden Labs - Goの型を理解する][arden-understanding-types]

Goは、`+`、`-`、`*`、`/`、`%`という標準的な算術演算子をサポートしています（剰余ではなく余りです）。

Goでは、異なる型の間で値を代入するには、明示的な型変換が必要です。
例えば、`int`を`float64`に変換するには、次のようにします：

```go
var x int = 42
f := float64(x)

fmt.Printf("x is of type: %s\n", reflect.TypeOf(x))
// Output: x is of type: int

fmt.Printf("f is of type: %s\n", reflect.TypeOf(f))
// Output: f is of type: float64
```

型変換の詳細については、[A Tour of Go：型変換][type-conversion]を参照してください。
