# はじめに

## `while`ループ

`while`ループを使うと、ある条件が満たされている間、コードを繰り返し実行できます。
`while`キーワードのあとに、丸括弧（`()`）で囲んだ条件と、波括弧（`{}`）で囲まれたループの_本体_を含むブロックを書きます。

```javascript
while (condition) {
  // code that is executed repeatedly as long as the condition is true
}
```

JavaScriptには、`do-while`ループもあります。
こちらは、ループの本体が実行されたあとに条件がチェックされます。
条件がループの本体で行われた評価に依存する場合に便利です。

```javascript
do {
  // The code here will always be executed once and then
  // repeatedly while the condition is true.
} while (condition);
```

ループの本体の中では、`break`キーワードを使ってループを完全に抜けることができます。
これとは対照的に、`continue`キーワードは現在の繰り返しの実行だけを止め、次の繰り返しへ進みます。
`continue`を使うと、ループの本体の大部分を`if`文で囲むのを避けられることがよくあります。

```javascript
let i = 0;

while (i < 100) {
  i = i + 2;

  if (i % 3 === 0) {
    continue;
  }

  // The code here will only be executed when i was not divisible
  // by 3 in the check above.
}
```

## `switch`文

`if`文のほかに、JavaScriptには条件によって処理を分岐させる`switch`文もあります。
`switch`文は、1つの変数を複数の値と比較する必要があるときに使います。
比較は厳密等価（`===`）かどうかで行われます。詳しくは[比較の概念][concept-comparison]を参照してください。
ある変数`x`に対する、JavaScriptの`switch`文の構文は次のとおりです。

<!-- prettier-ignore-start -->
```javascript
switch (x) {
  case option1:
    // code that is executed when "x === option1" is true
    break;
  case option2:
    // code that is executed when "x === option2" is true
    break;
  default:
    // code that is executed when x does not equal any of the options
}
```
<!-- prettier-ignore-end -->

`default`ケースは省略可能で、ほかのどの値も変数と一致しないときに何らかのコードを実行したい場合に使います。

上の`break`文が必要なのは、JavaScriptではデフォルトですべてのケースが「フォールスルー」するからです。
つまり、`break`文がないと、最初に一致した値より下にあるケースのコードが、`x`がそれらの値と一致していなくてもすべて実行されてしまいます。
この「デフォルトでフォールスルーする」という動作は、JavaScriptで`switch`を使うときによくある落とし穴です。
関数の中では、この問題を避けるために`break`の代わりに`return`を使うこともできます。
