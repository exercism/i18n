# 指示の補足

## 例外メッセージ

場合によっては、[例外を発生させる](https://docs.python.org/3/tutorial/errors.html#raising-exceptions)必要があります。そのときは、エラーの原因が何であるかを示す**意味のあるエラーメッセージ**を必ず含めるようにしましょう。これにより、コードが読みやすくなり、デバッグが格段に楽になります。エラーの原因が特定の種類であるとわかっている場合は、[組み込みのエラータイプ](https://docs.python.org/3/library/exceptions.html#base-classes)のいずれかを発生させることもできますが、その場合も意味のあるメッセージを含めるようにしましょう。

この演習では、`largest_product()`関数が不正な入力を受け取ったときに、[`raise`文](https://docs.python.org/3/reference/simple_stmts.html#the-raise-statement)を使って`ValueError`を「送出」する必要があります。テストに合格するには、`exception`を`raise`することと、それにメッセージを含めることの両方が必要です。`series`の演習で書いたコードを再利用してかまいません！

```python
# span of numbers is longer than number series
raise ValueError("span must not exceed string length")

# span of number is negative
raise ValueError("span must not be negative")

# series includes non-number input
raise ValueError("digits input must only contain digits")
```
