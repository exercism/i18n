# 指示の補足

## レジスタ

| レジスタ | 用途        | 型       | 説明                                    |
| -------- | ----------- | -------- | --------------------------------------- |
| `$a0`    | 入力        | アドレス | null終端された質問文字列                |
| `$v0`    | 出力        | 整数     | 結果。質問が無効な場合は0               |
| `$t0-9`  | 一時的      | 任意     | 一時的な保存用                          |
