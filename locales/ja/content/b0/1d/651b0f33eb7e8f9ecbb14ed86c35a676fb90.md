# トップレベルの定数を使いましょう

`GIGASECOND`という数値を定数として切り出すことを検討してみましょう。

```javascript
const %{name} = %{value}

// the rest of your code below it
export const gigasecond = (...)
```

`export`された関数、クラス、定数だけが、外部から見え、アクセスできるようになります。[マジックナンバー](https://en.wikipedia.org/wiki/Magic_number_%%28programming%%29)に名前を付けるのはたいてい理にかなっており、保守性の向上につながります。これらの定数は、他のコードに公開されることなく、同じファイルに置くことができます。
