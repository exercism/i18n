# 概要

[範囲][range]は、2つの値の間の区間を表します。範囲は、`Int`、`String`、`Character`のような型と組み合わせて、シーケンスを繰り返し処理したり、コレクションをスライスしたり、ある値が範囲内に収まっているかを調べたりするのによく使われます。

Swiftには、主に2つの範囲演算子があります：

- **閉範囲演算子（`...`）**：開始値と終了値の両方を含みます（`1...5`は1、2、3、4、5を含みます）。
- **半開範囲演算子（`..<`）**：開始値を含みますが、終了値は含みません（`1..<5`は1、2、3、4を含みます）。

```swift
let closed = 1...5
let halfOpen = 1..<5
```

~~~~exercism/note
範囲リテラルに対して直接メソッドを呼び出すときは、コンパイラーが先に範囲を評価するように、範囲式を括弧（`()`）で囲みます：

```swift
(1...5).contains(3) // Returns true
// 1...5.contains(3) // Error: value of type 'Int' has no member 'contains'
```
~~~~

## 範囲を配列に変換する

`Array(_:)`イニシャライザーを使うと、数値の範囲を`Array`に変換できます：

```swift
let range = 1...5
let numbers = Array(range)
// numbers is [1, 2, 3, 4, 5]
```

## 範囲を使った配列のスライス

範囲を使うと、配列の一部分をスライスできます：

```swift
let array = [10, 20, 30, 40, 50]
let slice = array[1...3]
// slice contains [20, 30, 40]
```

## 範囲のプロパティとメソッド

範囲に対してよく使う操作には、次のようなものがあります：

| メンバー                   | 説明                                                       | 例                                    |
| ----------------------- | ---------------------------------------------------------- | ------------------------------------ |
| `count`                 | 範囲に含まれる要素の数を返します                                  | `(1...5).count`は`5`を返します           |
| [`contains(_:)`][contains] | 範囲に指定した値が含まれていれば`true`を返します                    | `(1...5).contains(3)`は`true`を返します  |

## 片側範囲

Swiftは、開始値または終了値のどちらかを省略する片側範囲（部分範囲）にも対応しています：

- `array[2...]`：インデックス2からコレクションの末尾まで。
- `array[...2]`：コレクションの先頭からインデックス2まで（2を含みます）。
- `array[..<2]`：コレクションの先頭からインデックス2まで（2は含みません）。

## 文字列と文字の範囲

`Comparable`に準拠する文字や文字列の間でも、範囲を作成できます：

```swift
let letters = "a"..."z"
print(letters.contains("m")) // Prints true
print(letters.contains("A")) // Prints false
```
