# はじめに

## 数値

F#には2種類の数値があります。

- 整数：小数点以下の桁がない数値（いわゆる整数）。例は`-6`、`0`、`1`、`25`、`976`、`500000`です。
- 浮動小数点数：小数点以下に0桁以上の桁がある数値。例は`-2.4`、`0.1`、`3.14`、`16.984025`、`1024.0`です。

F#で最もよく使われる数値型は`int`と`float`です。`int`は32ビットの整数で、`float`は64ビットの浮動小数点数です。

計算には、標準の算術演算子を使います。数値は、標準の数値比較演算子や、等値演算子（`=`）と非等値演算子（`<>`）を使って比較できます。

数値型の変換は、組み込みの変換演算子で行います。これらの変換演算子には、変換先の型の名前が付けられています。F#は数値型の自動変換を_サポートしていません_。

## 条件分岐

F#で条件によってコードを実行し分ける最も一般的な方法は、`if/elif/else`式を使うことです。

```fsharp
if x = 5 then
    printfn "Expression to evaluate when x equals 5"
elif x > 7 then
    printfn "Expression to evaluate when x greater than 7"
else
    printfn "Expression to evaluate in all other cases"
```

`if/elif/else`式で使う条件は、`bool`型でなければなりません。F#には_truthy_な値という考え方はありません。
