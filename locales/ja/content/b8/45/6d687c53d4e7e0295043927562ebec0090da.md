# はじめに

[`strings`パッケージ](https://pkg.go.dev/strings)には、文字列を操作するための関数が用意されています。
ここではその一部を紹介します。残りについてはドキュメントを参照してください。

| 役割                  | 関数                                            | 用途                                                             |
| --------------------- | --------------------------------------------------- | ------------------------------------------------------------------- |
| 大文字・小文字の変換       | [ToLower](https://pkg.go.dev/strings#ToLower)       | 文字列を小文字に変換する                                      |
| 大文字・小文字の変換       | [ToUpper](https://pkg.go.dev/strings#ToUpper)       | 文字列を大文字に変換する                                      |
| 検索             | [Contains](https://pkg.go.dev/strings#Contains)     | 文字列が特定の部分文字列を含むか調べる                     |
| 検索             | [Count](https://pkg.go.dev/strings#Count)           | 部分文字列が重複せずに現れる回数を数える                    |
| 検索             | [HasPrefix](https://pkg.go.dev/strings#HasPrefix)   | 文字列が特定の部分文字列で始まるか調べる                  |
| 検索             | [HasSuffix](https://pkg.go.dev/strings#HasSuffix)   | 文字列が特定の部分文字列で終わるか調べる                  |
| 検索             | [Index](https://pkg.go.dev/strings#Index)           | 部分文字列が最初に現れるインデックスを返す。見つからなければ-1      |
| 変更             | [Replace](https://pkg.go.dev/strings#Replace)       | 部分文字列を最大n個まで置き換える                          |
| 変更             | [ReplaceAll](https://pkg.go.dev/strings#ReplaceAll) | 部分文字列をすべて置き換える                              |
| 変更             | [TrimSpace](https://pkg.go.dev/strings#TrimSpace)   | 先頭と末尾の空白を取り除く                              |
| 分割と結合  | [Fields](https://pkg.go.dev/strings#Fields)         | 文字列を空白で区切って単語に分割する                             |
| 分割と結合  | [FieldsSeq](https://pkg.go.dev/strings#FieldsSeq)   | 単語を1つずつ取り出す                                         |
| 分割と結合  | [Join](https://pkg.go.dev/strings#Join)             | 文字列のスライスを区切り文字で連結する                            |
| 分割と結合  | [Split](https://pkg.go.dev/strings#Split)           | 文字列を区切り文字で部分に分割する                            |
| 分割と結合  | [SplitSeq](https://pkg.go.dev/strings#SplitSeq)     | 各部分を1つずつ取り出す                                         |

```go
import (
    "fmt"
    "strings"
)

// Case conversion
strings.ToLower("Gopher")              // "gopher"
strings.ToUpper("Gopher")              // "GOPHER"

// Searching
strings.Contains("Apple", "le")        // true
strings.Index("Apple", "le")           // 3
strings.Index("Apple", "xyz")          // -1
strings.Count("test", "t")             // 2
strings.HasPrefix("Gopher", "Go")      // true
strings.HasSuffix("Gopher", "er")      // true

// Modifying
strings.TrimSpace("  hello  ")         // "hello"
strings.Replace("aabbcc", "b", "x", 1) // "aaxbcc"
strings.ReplaceAll("aabbcc", "b", "x") // "aaxxcc"

// Splitting or Joining
strings.Fields("  a b\tc  ")               // []string{"a", "b", "c"}
strings.Split("a,b,c", ",")                // []string{"a", "b", "c"}
strings.Join([]string{"a", "b", "c"}, ",") // "a,b,c"

// You do not need to worry about this range syntax yet.
// It is covered later in the range iteration concept.
for word := range strings.FieldsSeq("  a b\tc  ") {
    fmt.Println(word)
}
// Output:
// a
// b
// c

for part := range strings.SplitSeq("a,b,c", ",") {
    fmt.Println(part)
}
// Output:
// a
// b
// c
```
