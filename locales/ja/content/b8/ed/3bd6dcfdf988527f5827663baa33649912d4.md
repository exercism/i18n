# 概要

状態を持つオブジェクトを作るための余分な手間が要らないこともあります。そういうときは、`module`を使うことができます。

モジュールはクラスとよく似ています（実際、オブジェクト階層では`Module`は`Classes`の親です）。主な違いは、インスタンスメソッドではなくクラスメソッドを使うという点です。クラスメソッドは`self.`で始まり、モジュールに対して直接呼び出します。

例えば、次のとおりです。

```ruby
module Speaker
  def self.echo(something)
    "#{something} ... #{something}"
  end
end

Speaker.echo("Hello")   #=> "Hello ... Hello"
```
