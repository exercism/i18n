# 状態を持つクラス

```sather
class SCOREBOARD is

   attr home_team, away_team : STR;
   attr home_score, away_score : INT;

   create(home, away : STR) : SAME is
      board ::= new;
      board.home_team := home;
      board.away_team := away;
      return board;
   end;

   home_goal is home_score := home_score + 1; end;

end; -- class SCOREBOARD
```

## attr、readonly attr、private attr

| 書き方 | 外部から読める | 外部から変更できる |
| --- | --- | --- |
| `attr x : INT` | はい | はい |
| `readonly attr x : INT` | はい | いいえ |
| `private attr x : INT` | いいえ | いいえ |

既定で使うなら`readonly`です。誰でもスコアを見ることはできますが、変更するときは必ず`home_goal`を通すように強制できます。得点に関するルールは、そこに書いてあるからです。

## createとnew

`new`は、このクラスのオブジェクトを作ります。このとき、すべての属性は空です。`new`を使えるのは、クラスの内部だけです。

`create`は、名前が決められた、ごく普通のルーチンです。`#C(args)`は、`C::create(args)`とまったく同じ意味になります。`create`は引数の違いによって区別されながら、1つのクラスにいくつも持たせることができます。逆に、`create`を1つも持たないクラスは、`#`で作ることができません。

## SAME

`SAME`は、それが書かれているクラス自身を表します。`create`の中では戻り値の型になり、引数に使うこともできます。継承されたルーチンが、継承元のクラスではなく、継承先のクラスのことを語るようにしてくれるのも、この`SAME`です。

## 戻り値の型がないルーチン

```sather
   home_goal is
      home_score := home_score + 1;
   end;
```

`:`も型もありません。このようなルーチンは文として呼び出し、式の中には書けません。呼び出しの目的が、その呼び出しがもたらす変化そのものにある、というしるしです。

## self

ルーチンの中で、`self`はそのルーチンが呼び出された相手のオブジェクトを表します。ほとんど書く必要はありません。属性やルーチンの名前を単独で書けば、それはすでに`self`のものを意味しているからです。`self`が必要になるのは、オブジェクトそのものを渡したり返したりするときです。

```sather
   with_goal : SAME is
      home_score := home_score + 1;
      return self;
   end;
```

`self`、`new`、`void`、`result`、`value`、`out`は、いずれもSatherがすでに使っている単語なので、自分でつける名前には使えません。

## 参照であって、値ではない

オブジェクトには、参照を通してたどり着きます。同じスコアボードにつけられた2つの名前は、同じスコアを見ます。

```sather
   a ::= #SCOREBOARD("Vixens", "Magpies");
   b ::= a;         -- not a copy
   b.home_goal;
   a.home_score     -- 1
```

もう一方のふるまいを得るには、後の章で説明する`immutable class`を使います。
