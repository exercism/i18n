# はじめに

## `true`と`false`

Rubyでは、真と偽という2つの論理状態を`true`と`false`で表します。これらは単独のリテラルとして使うこともできますし、論理演算や比較の結果として得られることもあります。

```ruby
happy = true
sad = false

true && false
# => false

1 < 2
# => true
```

## *truthy*と*falsey*

`if`文やその他の真偽値の文脈でオブジェクトを評価するとき、`false`と`nil`**を除く**すべてのオブジェクトが*truthy*と評価されます。

## 制御フロー

*truthy*と*falsey*の評価は、制御フローの文脈で役に立ちます。手続き型言語と同じように、Rubyにも`if`...`else`構文がありますが、それよりも`if`を「ガード」として使い、式の評価を変えることのほうが多いかもしれません。

```ruby
def falsey
  nil || false
end

def truthy
  not falsey
end

if truthy
  # this block is evaluated
end

if falsey
  # this block is not evaluated
else
  # this block is evaluated
end

1 + 1 if truthy
# this will evaluate and return 2

2 + 2 if falsey
# the numbers are not added because of the modifier, nil is returned
```

Rubyには、コードを読みやすくする`unless`があります。たとえば、`eat_desert if not too_full`ではなく、`eat_desert unless too_full`と書くこともできます。

```ruby
3 + 3 unless truthy
# the numbers are not added because of the modifier, nil is returned

4 + 4 unless falsey
# this will evaluate and return 8
```
