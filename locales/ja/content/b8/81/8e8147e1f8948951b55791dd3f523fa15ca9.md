# はじめに

## Juliaの真偽値

`true`や`false`といった真偽の値は、`Bool`型で表します。
この型が持つ値は、`true`と`false`の2つだけです。

```julia-repl
julia> true
true

julia> false
false
```

## 真偽値の演算子

Juliaには真偽値の演算子が3つあります。

`&&`は真偽値の「and」です。
`&&`の*両側*の式が`true`であれば、`true`と評価されます。

```julia-repl
julia> true && true
true

julia> true && false
false
```

`||`は真偽値の「or」です。
`||`の*左右どちらか*の式が`true`であれば、`true`と評価されます。

```julia-repl
julia> true || true
true

julia> false || true
true
```

`!`は真偽値の「not」です。
`true`と`false`の値を入れ替えます。

```julia-repl
julia> !true
false

julia> !false
true
```

式が長く複雑になるときは、意図を明確にするために括弧（`()`）を使うのがよいでしょう。

```julia-repl
julia> (true || false) && (false && true)
false
```
