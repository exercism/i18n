# はじめに

C#は、多くの静的型付け言語と同じように、整数を表す型をいくつか用意しています。それぞれの型には、扱える値の範囲があります。一番小さいのは`sbyte`型で、最小値は-128、最大値は127です。どの整数型でも、これらの値は`<type>.MinValue`と`<type>.MaxValue`で取得できます。一番大きいのは`long`型で、最小値は-9,223,372,036,854,775,808、最大値は9,223,372,036,854,775,807です。その間には、`short`型と`int`型があります。

範囲は、システムがその型に割り当てる記憶域の幅によって決まります。たとえば、`byte`は8ビット、`long`は64ビットを使います。

上記の型にはそれぞれ、符号なしの対応する型があります。`sbyte`/`byte`、`short`/`ushort`、`int`/`uint`、`long`/`ulong`です。いずれの場合も、値の範囲は0から、符号ありの最大値を2倍して1を足した値までです。

| 型     | 幅       | 最小値                     | 最大値                       |
| ------ | -------- | -------------------------- | ---------------------------- |
| sbyte  | 8ビット  | -128                       | +127                         |
| short  | 16ビット | -32_768                    | +32_767                      |
| int    | 32ビット | -2_147_483_648             | +2_147_483_647               |
| long   | 64ビット | -9_223_372_036_854_775_808 | +9_223_372_036_854_775_807   |
| byte   | 8ビット  | 0                          | +255                         |
| ushort | 16ビット | 0                          | +65_535                      |
| uint   | 32ビット | 0                          | +4_294_967_295               |
| ulong  | 64ビット | 0                          | +18_446_744_073_709_551_615  |

ある型の変数（または式）は、簡単に別の型へ変換できます。たとえば代入では、代入される値の型（左辺）が、代入先の型（右辺）の範囲に収まることが保証されていれば、そのまま代入できます。

```csharp
uint ui = uint.MaxValue;
ulong ul = ui;    // no problem
```

一方、代入する側の型の範囲が、代入先の型の値の範囲の一部でない場合は、たとえその値が代入先の範囲に収まっていても、キャストという`()`の操作が必要になります。

```csharp
short s = 42;
uint ui = (uint)s;
```
