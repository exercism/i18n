# 範囲

[範囲][range]は、2つの値の間の区間を表します。
範囲をサポートする最も一般的な型は、`Int`、`Char`、`String`です。
コレクションを手早く作ったり、文字列を切り出したり、ある値が範囲に含まれているか調べたり、繰り返し処理をしたりと、さまざまなことに使えます。
範囲は、範囲演算子`..`または`...`を使って作ります（それぞれ終端を含むものと含まないものです）。

```crystal
1..5  # A range containing 1, 2, 3, 4, 5
1...5 # A range containing 1, 2, 3, 4
```

範囲演算子が2つあるのは、終端の値を含む範囲と含まない範囲を作り分けるためです。これは、たとえば0から始まるインデックスを扱うときに便利です。

範囲は、`Range`の初期化でも作ることができます。

```crystal
Range.new(1, 5) # A range containing 1, 2, 3, 4, 5
```

~~~~exercism/note
Crystalで範囲演算子`..`や`...`を使って範囲を作り、その範囲に対してメソッドを呼び出したいときは、範囲を括弧（`()`）で囲む必要があります。
そうしないと、メソッドが範囲演算子の2番目の引数に対して呼び出されてしまうからです。

```crystal
(1..5).size # => 5
1..5.size # => Error: undefined method 'size' for Int32
```
~~~~

## 部分文字列の取得

文字列を切り出したいときは、範囲演算子を使って部分文字列を取得できます。
つまり、部分文字列の開始インデックスと終了インデックスで範囲を作ります。

```crystal
"Hello World"[0..4] # => "Hello"
"Hello World"[6..10] # => "World"
```

負のインデックスを使うと、文字列の末尾から部分文字列を取得することもできます。

```crystal
"Hello World"[-5..-1] # => "World"
"Hello World"[6..-4] # => "Wo"
```

## 範囲のメソッド

範囲には、操作に使えるメソッドがいくつか用意されています。
たとえば、範囲内のすべての値の合計を求めたり、ある値が範囲に含まれているか調べたりするのに使えます。

| メソッド                | 説明                                                                     | 例                              |
|-------------------------|-------------------------------------------------------------------------|---------------------------------|
| [`sum`][sum]            | 範囲内のすべての値の合計を返します                                       | `(1..5).sum # => 15`            |
| [`size`][size]          | 範囲のサイズを返します                                                   | `(1..5).size # => 5`            |
| [`includes?`][indludes] | 指定した値が範囲に含まれていれば`true`、そうでなければ`false`を返します  | `(1..5).includes?(3) # => true` |

## 終端のない範囲と始端のない範囲

範囲は、終端のないものや始端のないものにできます。
終端や始端のない範囲では、開始値または終了値が`nil`になりますが、範囲を定義するときに`nil`は省略できます。

始端や終端のない範囲は、たとえば文字列を先頭から、または末尾まで切り出したいときに便利です。

```crystal
"Hello World"[0..] # => "Hello World"
"Hello World"[4..] # => "o World"
"Hello World"[..5] # => "Hello"
```

~~~~exercism/caution
コレクションに対して使うのでなければ、注意しないと、終端のない範囲が終わりのないシーケンスを生むことがあります。
~~~~

## `Char`の範囲

`Char`も範囲に使えて、2つの文字の間の文字の区間を取得できます。
たとえば、アルファベットを得たいときに便利です。

```crystal
'a'..'z' # A range containing ['a', 'b', 'c', ..., 'z']
```

## `String`の範囲

`String`も範囲に使えて、2つの文字列の間の文字列の区間を取得できます。
ただし、文字列の範囲で複数の文字を使うと、その動作は`Char`の場合とは少し異なります。
より複雑な文字列の範囲を扱うと動作が分かりにくくなることがあるので、注意してください。

```crystal
("aa".."az") # A range containing ["aa", "ab", "ac", ..., "az"]
```
