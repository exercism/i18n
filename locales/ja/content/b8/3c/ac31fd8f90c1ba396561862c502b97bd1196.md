# 配列の紹介

Javaでは、配列を使うと、同じ型の複数の値を1つの構造にまとめて保存できます。
他のデータ構造と違い、配列は一度作成するとサイズが固定されます。
配列の要素は、インデックスを使って代入したり取り出したりできます。
Javaの配列は0から始まるインデックスを使います。最初の要素のインデックスは`0`、2番目の要素のインデックスは`1`、という具合です。

配列を初期化する標準的な構文は次のとおりです。

```java
type[] variableName = new type[size];
```

`type`は配列の要素の型で、プリミティブ型（例：`int`）でもクラス（例：`String`）でもかまいません。

`size`はこの配列が保持する要素の数です（後から変更することはできません）。
配列を作成すると、要素はデフォルト値（通常は`0`、`false`、`null`）で初期化されます。

```java
// Declare array with explicit size (size is 2)
int[] twoInts = new int[2];
```

配列は、作成と値の設定を同時に行える省略記法でも定義できます。

```java
// Two equivalent ways to declare and initialize an array (size is 3)
int[] threeIntsV1 = new int[] { 4, 9, 7 };
int[] threeIntsV2 = { 4, 9, 7 };
```

この場合、コンパイラーが配列の要素数を判断できるので、長さは省略できます。

配列の要素は、角括弧を使ったインデックス記法で代入したり参照したりできます。

```java
// Assign second element by index
twoInts[1] = 8;

// Retrieve the second element by index and assign to the int element
int secondElement = twoInts[1];
```

配列の有効なインデックスの範囲外にアクセスすると、`IndexOutOfBoundsException`が発生します。

配列は、配列インスタンスのメソッドやプロパティを呼び出すか、`Arrays`クラスで定義された静的メソッド（通常はジェネリックコードでのみ使われます）を使うことで操作できます。
`length`プロパティには配列の長さが入っています。
次のようにして参照できます。

```java
int arrayLength = someArray.length;
```

Javaには、配列関連の便利なメソッドをたくさん備えた便利なユーティリティクラス[`java.util.Arrays`](https://docs.oracle.com/en/java/javase/11/docs/api/java.base/java/util/Arrays.html)も用意されています（例：`Arrays.equals`）。

Javaは、`int[][] arr = new int[3][4];`のような[多次元配列](https://www.programiz.com/java-programming/multidimensional-array)もサポートしており、非常に便利です。

配列が_コレクション_でもあるということは、インデックスで値を参照するだけでなく、`for-each`ループを使って_すべての_値を反復処理できるということです。

```java
char[] vowels = { 'a', 'e', 'i', 'o', 'u' };

for(char vowel: vowels) {
    // Output the vowel
    System.out.print(vowel);
}

// => aeiou
```

反復処理する値をより細かく制御したい場合は、`for`ループを使えます。

```java
char[] vowels = { 'a', 'e', 'i', 'o', 'u' };

for (int i = 0; i < 3; i++) {
    // Output the vowel
    System.out.print(vowels[i]);
}

// => aei
```
