# ヒント

## 全般

- `n <iota>`は、整数`0, 1, …, n-1`の仮想シーケンスを生成します。
- `map`（[`sequences`][sequences]内）は、クオーテーションを各要素に対して実行し、その結果を集めます。
- `>string`（[`strings`][strings]内）は、文字コードのシーケンスを文字列に変換します。

## 1. アルファベットのバンティング

- `CHAR: a`は、整数`97`として解釈されます。インデックス`i`を足すと、`i`番目の小文字に対応する文字コードが得られます。

## 2. 数字のバンティング

- `mod`（[`math`][math]内）は、整数除算の余りを返します。
- 数字の文字コードは連続しています（`CHAR: 0`、`CHAR: 1`、…）。したがって、`CHAR: 0 +`とすると、`0..9`の整数が対応する数字の文字に変わります。

## 3. ストライプのバンティング

- `even?`（[`math`][math]内）は、偶数の整数なら`t`、そうでなければ`f`になります。
- `map`のクオーテーションの中では、`if`が判定結果に応じて2つの文字リテラルのどちらかを選びます。

## 4. マーカーのバンティング

- `5 mod zero?`は、位置`0`、`5`、`10`、…でだけ`t`になります。

## 5. 谷のバンティング

- `-5 5 [a..b)`（[`ranges`][ranges]内）は、半開区間`-5, -4, …, 4`です。
- `abs`（[`math`][math]内）は、負の整数を正の整数に変え、負でない整数はそのままにします。
