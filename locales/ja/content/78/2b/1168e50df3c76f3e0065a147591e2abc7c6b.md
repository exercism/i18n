# 概要

SystemVerilogは、[Hardware Description Language][HDL]（HDL）と[Hardware Verification Language][HVL]（HVL）を組み合わせたもので、その頭文字をとってHDVLと略されます。
つまり、電子回路の形や動作を記述すると同時に、ハードウェア記述言語で表現された電子回路を検証するものです。
SystemVerilogは、2005年に[Verilog][Verilog]言語にいくつかの変更を加えたVerilogのスーパーセットとして生まれ、2012年には[IEEE][IEEE] 1800-2012規格としてアップグレードされました。
SystemVerilogは、より動的なクラスレベルのテストベンチを土台にしています。

制約付きランダム生成、アサーションベース検証、カバレッジドリブン検証は、いずれもSystemVerilogで完全な検証環境を作るために使われます。
こうした手法は、検証プロセスを大幅に強化します。
SystemVerilogには、[RTL設計][RTL-Design]の効率を高め、設計プロセスを簡素化する、改良されたハードウェアモデリング技術もあります。

SystemVerilogは、シミュレーションツールの構成要素です。
実行するのに、他のツールやGUI、インターフェース（PLIなど）を必要としません。
新たなコンパイルコマンドも必要ありません。
そのため、SystemVerilogの普及は速く、設計者は使いやすくて簡単だと感じています。
全体的な性能の高さも、この単一の環境の利点のひとつです。
シミュレーションツールへの外部インターフェースを必要とする他の検証言語と比べて、SystemVerilogでの検証は少なくとも2倍速いです。
