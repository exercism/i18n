# 指示の補足

## Callable

PHPには、[callable](https://www.php.net/manual/en/language.types.callable.php)という概念があります。

callableにはいくつかの書き方がありますが、ここでは[無名関数](https://www.php.net/manual/en/functions.anonymous.php)に注目します。

変数に無名関数を代入しておき、引数を渡して呼び出すことができます。

```php
$double = function ($number) {
    return $number * 2;
};

$double(2); // returns 4
$double(4); // returns 8
```
