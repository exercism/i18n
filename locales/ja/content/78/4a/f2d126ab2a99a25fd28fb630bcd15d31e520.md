# 説明

市役所でしばらく働くうちに、日々の業務を効率よく進めるためのツールをいくつか作ってきました。たとえば、書類の記入に役立つものです。

そんな折、新しい同僚が仲間に加わることになり、作ったツールが誰にでもすぐ理解できるものではないと気づきました。職場には、書類は必ず大文字で記入する、欄を空けたままにしない、といったちょっと変わった決まりごとがたくさんあります。

そこで、新しい同僚がすぐに使い始められるように、ドキュメントを書くことにしました。

## 1. 書類ツールの目的をドキュメント化する

`Form`モジュールに、その目的を説明するドキュメントを追加します。内容は次のとおりです。

```
A collection of loosely related functions helpful for filling out various forms at the city office.
```

## 2. 空の値で欄を埋めることをドキュメント化する

`Form.blanks/1`関数に、ドキュメントと型仕様を追加します。ドキュメントの内容は次のとおりです。

```
Generates a string of a given length.

This string can be used to fill out a form field that is supposed to have no value.
Such fields cannot be left empty because a malicious third party could fill them out with false data.
```

型仕様では、この関数が単一の引数（非負の整数）を受け取り、文字列を返すことを説明します。

## 3. 値を大文字のリストに分割することをドキュメント化する

`Form.letters/1`関数に、ドキュメントと型仕様を追加します。ドキュメントの内容は次のとおりです。

```
Splits the string into a list of uppercase letters.

This is needed for form fields that don't offer a single input for the whole string,
but instead require splitting the string into a predefined number of single-letter inputs.
```

型仕様では、この関数が単一の引数（文字列）を受け取り、文字列のリストを返すことを説明します。

## 4. 値が最大長の欄に収まるかどうかを確認することをドキュメント化する

`Form.check_length/2`関数に、ドキュメントと型仕様を追加します。ドキュメントの内容は次のとおりです。

```
Checks if the value has no more than the maximum allowed number of letters.

This is needed to check that the values of fields do not exceed the maximum allowed length.
It also tells you by how much the value exceeds the maximum.
```

型仕様では、この関数が2つの引数（文字列と非負の整数）を受け取り、2通りの値のうちどちらかを返すことを説明します。返すのは、`:ok`アトムか、1つ目の要素が`:error`アトムで2つ目が正の整数である2要素のタプルです。

## 5. 異なる住所形式をドキュメント化する

理由は不明ですが、市役所の内部システムでは、住所を表す方法が2つあります。マップか、タプルです。

3つのカスタム公開型を定義して、このことをドキュメント化します。
- `address_map`は、キー`:street`、`:postal_code`、`:city`を持つマップです。それぞれのキーの値は文字列型です。
- `address_tuple`は、3つの値`street`、`postal_code`、`city`を持つタプルです。それぞれの値は文字列型です。型仕様では、それぞれの値に名前を付けて区別します。
- `address`は、`address_map`か`address_tuple`のどちらかです。

## 6. 住所の書式設定をドキュメント化する

`Form.format_address/1`関数に、ドキュメントと型仕様を追加します。ドキュメントの内容は次のとおりです。

```
Formats the address as an uppercase multiline string.
```

型仕様では、この関数が1つの引数（住所）を受け取り、文字列を返すことを説明します。
