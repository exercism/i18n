# はじめに

多くのプログラムでは、現実世界の出来事をシミュレーションするために（疑似）乱数が必要になります。

よくある身近な例には、次のようなものがあります。

- コイントス：('H', 'T')のいずれかがランダムに得られます。
- サイコロを振る：1から6までのランダムな整数が得られます。
- トランプの山をシャッフルする：カードの配列をランダムな順序に並べ替えます。
- 3Dグラフィックスのシミュレーションで木や茂みを生成する場合。

コンピューターで本当にランダムな値を生成するのは、[驚くほど難しい技術的な課題][why-randomness-is-hard]です。そのため、「疑似乱数」ジェネレーターも存在します。

~~~exercism/advanced
JavaScriptの[言語仕様][spec]では、乱数の生成方法は規定されていません。
主要なブラウザーやJavaScriptランタイムはすべて、PRNG（疑似乱数生成器）を実装しています。
これらの数値は暗号学的に安全ではないため、証明書やパスワードの生成や操作など、真の乱数、あるいは少なくとも暗号学的に安全な乱数が必要な用途には決して使うべきではありません。

JavaScriptで暗号処理を行うためのインターフェースを標準化した[Web Cryptography][rfc]という標準があります。
これは[ブラウザー][crypto-web]のほか、[Node.JS][crypto-node]や[Deno][crypto-deno]などのランタイムでも実装されています。

ここで扱うのはWeb Cryptoではなく、疑似乱数の生成だけです。

[spec]: https://tc39.es/ecma262/multipage/numbers-and-dates.html#sec-math.random

## 乱数を生成する

JavaScriptでは、[`Math.random()`][Math.random]関数を使って疑似乱数を生成できます。
この関数は、0以上1未満の疑似乱数の浮動小数点数を返します。

_min_以上_max_未満の乱数を得るには、次のような関数を使います。

```javascript
function getRandomInRange(min, max) {
  return min + Math.random() * (max - min);
}
getRandomInRange(4, 10);
// => 5.72
```

## ランダムな整数を生成する

ランダムな整数を生成するには、`Math.floor()`または`Math.ceil()`を使って、生成した乱数を整数に変換します。

[why-randomness-is-hard]: https://www.malwarebytes.com/blog/news/2013/09/in-computers-are-random-numbers-really-random
[Math.random]: https://developer.mozilla.org/en-US/docs/Web/JavaScript/Reference/Global_Objects/Math/random
