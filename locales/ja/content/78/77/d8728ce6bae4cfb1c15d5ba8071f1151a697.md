# 指示

この演習では、Exercismで学びたいプログラミング言語の配列を管理するコードを書きます。

6つのタスクがあり、いずれも配列を扱います。

## 1. 新しい配列を作成する

学びたい言語を管理するには、新しい配列を作成する必要があります。新しくて空の配列を保持する`newList`束縛を定義します。

```fsharp
newList
// => []
```

## 2. 既存の配列を定義する

現在、学びたい言語が書かれた紙が1枚あります。F#、Clojure、Haskellです。この配列を表す`existingList`束縛を定義します。

```fsharp
existingList
// => ["F#"; "Clojure"; "Haskell"]
```

## 3. 配列に新しい言語を追加する

Exercismを探検してもっと面白い言語を見つけたら、それを配列に追加したくなります。配列の先頭に新しい言語を追加する`addLanguage`関数を実装します。

```fsharp
addLanguage "TypeScript" ["JavaScript"; "CoffeeScript"]
// => ["TypeScript"; "JavaScript"; "CoffeeScript"]
```

## 4. 配列内の言語を数える

言語を1つずつ数えるのは面倒です。配列にある言語の数を数える`countLanguages`関数を実装します。

```fsharp
countLanguages ["C#"; "Racket"; "Rust"; "Ruby"]
// => 4
```

## 5. 配列を逆順にする

あるとき、配列が実は逆順に並んでいることに気づきます！　配列を逆にする`reverseList`関数を実装します。

```fsharp
reverseList ["Prolog"; "C"; "Idris"; "Assembly"]
// => ["Assembly"; "Idris"; "C"; "Prolog"]
```

## 6. 配列がエキサイティングかどうかを確認する

どの言語も大好きですが、F#は心の中で特別な存在です。そのため、次のような配列には、とてもわくわくします。

- 配列の先頭がF#です。
- 配列の2番目の要素がF#で、配列に含まれる言語が2つか3つです。

配列がエキサイティングかどうかを確認する`excitingList`関数を実装します。

```fsharp
excitingList ["Nim"; "F#"]
// => true
```
