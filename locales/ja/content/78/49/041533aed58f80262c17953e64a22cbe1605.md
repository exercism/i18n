# インストール

演習に取り組むには、次のソフトウェアが必要です。

1. [`OPAM`、OCamlのパッケージマネージャー](https://opam.ocaml.org/)

   お使いのオペレーティングシステムに`OPAM`をインストールして設定する方法は、[Real World Ocaml, 2nd Ed.: Installation Instructions](https://dev.realworldocaml.org/install.html)を参照してください。

2. OCamlコンパイラー

   利用できるバージョンの一覧を表示します。

   ```bash
   opam switch
   ```

   OCaml 5.1のスイッチがすでにある場合は、`opam switch <switch-name>`を実行してそれを読み込むか、次のコマンドで新しいスイッチを作成します。

   ```bash
   opam switch create exercism 5.4.0
   ```

   ここでの`exercism`という名前は省略できますが、スイッチには名前を付けておくのがよい習慣です。

3. 拡張標準ライブラリとテストライブラリのインストール

   このトラックで必要な依存関係をインストールするには、次のコマンドを実行します。

   ```bash
   opam install base core_kernel ounit qcheck
   ```

   演習によってはOCamlの標準ライブラリだけを使うものもあれば、Jane StreetによるBaseとCore_kernelという拡張ライブラリを使うものもあります。
   テストライブラリはOUnitといい、さらに一部の演習ではプロパティベーステストのためにQCheckライブラリも使います。
   上のコマンドを実行すると、これらのライブラリがインストールされます。

4. 対話型シェルのインストールと使用（任意）

   [`utop`のセットアップと使い方](https://dev.realworldocaml.org/install.html)の概要です。

   ```bash
   opam install utop
   ```

   ホームディレクトリに`.ocamlinit`という名前の新しいファイルを作成し、そこに次の行を追加します。

   ```ocaml
   #use "topfind";;
   #require "base";;
   open Base
   ```

5. VS Codeへのツールのインストール（任意）

   VS Codeを使っている場合は次のとおりです。
   - OCaml言語サーバーを[こちら](https://github.com/ocaml/ocaml-lsp)からインストールします。
   - OCamlのVS Code拡張機能を[こちら](https://marketplace.visualstudio.com/items?itemName=ocamllabs.ocaml-platform)からインストールするか、Ocaml Labsによる`OCaml Platform`を検索します。
