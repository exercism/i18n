# はじめに

使っている言語の名前Lispが_LIST Processing_を意味することから、この言語には要素の配列を扱う仕組みがあると思うかもしれません。そのとおりです！

Common Lispには配列以外のデータ構造もありますが、配列は今でも非常によく使われています。

Common Lispの配列は、要素の並びです。主に歴史的な理由から、**cons**とも呼ばれます。
要素自体は同じ型である必要はありません。
たとえば、`1`、`two`、`"III"`からなる配列を作れます。

## 配列の作成

次のように、クォートした配列をそのまま入力できます：`'(1 two "III")`。すると配列が作成され、評価されます（評価結果は`(1 two "III")`です）。

配列を作るための主な関数は、`list`と`cons`の2つです。

`list`は0個以上の引数を取り、それらの値で作られた配列に評価されます：

```lisp
(list 1 'two "III") ; => (1 two "III")
```

`cons`は2つの要素を取り、1つ目の要素を`car`（配列の先頭）、2つ目の要素を`cdr`（配列の残り）とする配列を作ります：

```lisp
(cons 1 2)            ; => (1 . 2) ;; (a list without `nil` as its `cdr` is printed in this way)
(cons 1 nil)          ; => (1)
(cons 1 (cons 2 nil)) ; => (1 2)
```

`car`と`cdr`を使うと、配列の`car`と`cdr`にアクセスできます。

（`first`と`rest`は`car`と`cdr`の同義語で、まったく同じように動作します。）

## 長さとランダムアクセス

配列の長さは`length`で調べられます。
空の配列の長さは0です。

任意の要素には`nth`でアクセスできます（配列のインデックスは0から始まることに注意してください）。

配列の長さよりも大きいインデックスを指定しても、エラーには_なりません_。
代わりに、`nil`に評価されます：

```lisp
(nth 23 '(short list)) ; => nil
```

配列の先頭から数個の要素にアクセスするための補助的な関数もいくつかあります：`first`、`second`、`third`、そして`tenth`までです。便利ですよね？

## 配列の結合

2つ以上の配列は`append`で結合できます：

```lisp
(append '(a b c) '(1 2 3)) ; => (A B C 1 2 3)
(append '(a b c) '())     ; => (A B C)
```

`append`に渡す各引数は配列である必要があります。
