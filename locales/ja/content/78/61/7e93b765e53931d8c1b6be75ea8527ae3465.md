# はじめに

## 数値

C#の数値には、2つの異なる種類があります。

- 整数：小数点以下の桁がない数値（整数）です。例として、`-6`、`0`、`1`、`25`、`976`、`500000`などがあります。
- 小数：小数点以下に0桁以上の桁がある数値です。例として、`-2.4`、`0.1`、`3.14`、`16.984025`、`1024.0`などがあります。

C#で最もよく使われる数値型は、`int`と`double`です。`int`は32ビットの整数で、`double`は64ビットの浮動小数点数です。

計算には、標準の算術演算子を使います。数値の比較には、標準の数値比較演算子のほか、等値（`==`）演算子と非等値（`!=`）演算子を使えます。

C#の数値変換には、2つの種類があります。

1. 暗黙的な変換：データが失われることはなく、追加の構文も必要ありません。
2. 明示的な変換：データが失われる可能性があり、_キャスト_という形の追加の構文が必要です。

`int`は`double`よりも精度が低いため、`int`から`double`への変換は安全で、暗黙的な変換になります。しかし、`double`から`int`への変換ではデータが失われる可能性があるため、明示的な変換が必要です。

```csharp
int softCool = 1358938113;
double notLost = 4.8151623;

// implicit cast: no loss of information
double macDebug = softCool;         // 1358938113.0

// explicit cast: possible loss of information 
int somethingLost = (int)notLost;   // 4
```

## `if`文

この演習では、条件に応じて処理を実行する必要があります。C#でこれを行う最も一般的な方法は、`if/else`文を使うことです。

```csharp
int x = 6;

if (x == 5)
{
    // Execute logic if x equals 5
}
else if (x > 7)
{
    // Execute logic if x greater than 7
}
else
{
    // Execute logic in all other cases
}
```

`if`文の条件は、`bool`型でなければなりません。C#には、_truthy_という概念はありません。
