# 指示の補足

## 実装

アイテムは[レコード](https://lfe.gitbooks.io/reference-guide/content/16.html)で表され、`item.lfe`で定義されています。
重さを取得するには`item-weight`を、値を取得するには`item-value`を使います。

```
;; Create an item with weight=5, value=50
(set item (make-item weight 5 value 50))

;; Get the weight. Returns 5.
(item-weight item)

;; Get the value. Returns 50.
(item-value item)
```
