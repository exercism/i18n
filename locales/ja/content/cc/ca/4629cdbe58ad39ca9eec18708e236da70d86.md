# 概要

[ガード][guards]は、[パターンマッチング][exercism-pattern-matching]を補完するものとして使われます。ガードを使うと、より複雑なチェックができます。パターンマッチングが使える場面のうち、[すべてではありませんが、いくつかの場面][where-guards-can-be-used]で使えます。たとえば、関数の節やcase節などです。

```elixir
def empty?(list) when is_list(list) and length(list) == 0 do
  true
end
```

- ガードは`when`キーワードで始まり、そのあとに真偽値の式が続きます。
- ガード式は特別な関数で、次の条件を満たす必要があります。
  - [純粋][pure-function]であること。グローバルな状態を変更してはいけません。
  - 厳密に`true`または`false`を返すこと。
- よく使われるガードの一覧は、[Elixirのドキュメント][kernel-guards]にあります。次のようなものがあります。
  - 型チェック：[`is_integer/1`][guard-is-integer]、[`is_list/1`][guard-is-list]、[`is_nil/1`][guard-is-nil]など
  - 算術演算子：[`+/2`][guard-plus]、[`-/2`][guard-minus]など
  - 比較：[`==/2`][guard-equals]、[`>/2`][guard-greater]、[`</2`][guard-less]など
  - 真偽値の演算子：[`and/2`][guard-and]、[`or/2`][guard-or]、[`not/1`][guard-not]
  - 所属演算子：[`in/2`][guard-in]
- [`defguard`][defguard]を使えば、独自のガードを定義できます。

  - Elixirの[命名規則][naming]では、ガードの名前は`is_`で始めることになっています。

    ```elixir
    defmodule HTTP do
      defguard is_success(code) when code >= 200 and code < 300

      def handle_response(code) when is_success(code) do
        :ok
      end
    end
    ```
