# 概要

C++では、真偽値は`bool`型で表されます。
`bool`は`true`か`false`のどちらかです。

## 論理演算子

C++では、3つの論理演算子を使うことができます。`!`（NOT）、`&&`（AND）、`||`（OR）です。
`not`、`and`、`or`という別の書き方も使えます。

```cpp
true || false // => true
true && false // => false
!true // => false
not false // => true
```

## 優先順位

3つの論理演算子には、それぞれ異なる_演算子の優先順位_があります。
そのため、評価の順番は`!`が最初、次に`&&`、最後に`||`です。
別の順番で評価させたいときは、論理式を括弧（`()`）で囲みます。括弧の優先順位は演算子よりもさらに高いからです。

```cpp
!true && false   // => false
!(true and false) // => true
```

## 変換

数値が期待される場所で`true`や`false`を使うと、それぞれ`1`と`0`に変換されます。
真偽値の演算で数値を使うと、`0`以外はすべて`true`として扱われます。負の値でも同じです。

```cpp
!true && 0.0   // => false
true + true + false // => 2
```
