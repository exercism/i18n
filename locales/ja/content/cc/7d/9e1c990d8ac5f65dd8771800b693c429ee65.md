# 指示の補足

## レジスタ

| レジスタ | 用途     | 型      | 説明                                   |
| -------- | -------- | ------- | -------------------------------------- |
| `$a0`    | 入力     | アドレス | null終端された入力文字列               |
| `$a1`    | 入力と出力 | アドレス | 最終的なヌクレオチド数を持つワード配列 |
| `$t0-9`  | 一時     | 任意    | 一時的な保存用                         |
