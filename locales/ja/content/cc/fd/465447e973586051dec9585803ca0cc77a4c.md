# 説明の補足

## ワード

`game`タプルと、まだ1回も投げていない新しいゲームを返すコンストラクター`<game> ( -- game )`を定義します。

ゲームを操作する次のワードを用意します。

- `roll ( pins game -- )`：`pins`本のピンが倒れたことを記録します。無効なロールのときは、次のエラーを投げます。
  - ピンの数が負の場合は、`"Negative roll is invalid"`を投げます。
  - 10フレーム（と、あればフィルボール）をすべて投げ終えたあとに投げようとした場合は、`"Cannot roll after game is over"`を投げます。
  - レーンに立っているピンより多く倒そうとした場合は、`"Pin count exceeds pins on the lane"`を投げます。
- `score ( game -- n )`：ゲームの合計スコアです。ゲームがまだ終わっていない場合は、`"Score cannot be taken until the end of the game"`を投げます。

`roll`は、`kernel`ボキャブラリーのシャッフルワード`roll`を隠してしまうことに注意してください。テストスイートは`FROM: bowling => roll ;`でこの2つを区別します。
