# はじめに

Rubyでは、他のすべてのものと同じように、`String`はオブジェクトです。
文字列は任意のバイト列（通常は文字）でできていて、他のオブジェクトと同じように初期化したり操作したりできます。
実際、Rubyの最も便利なところのひとつは、文字列（や他のオブジェクト）に対して呼び出せるメソッドがたくさんあり、コードを書く時間を大幅に節約できることです。
この演習では、そうしたメソッドのいくつかを実際に触りながら見ていきましょう。

## 文字列の作成

`String.new(...)`を使って文字列を作ることもできますが、はるかに一般的なのはリテラルを使う方法です。
使えるリテラルにはたくさんの種類があり、それらは2つのカテゴリーに分かれます。式展開できるものと、できないものです。

もっともよく使うリテラルは、シングルクォートとダブルクォート（`'...'`と`"..."`）です。
シングルクォートでは式展開ができませんが、ダブルクォートではできます。
式展開とは、`#{}`という記法を使って、ある文字列を別の文字列の中に埋め込むことです。

```
# Use single quotes when not interpolated
location = 'World'

# And double quotes when interpolated
puts "Hello, #{location}!"   #=> "Hello, World!"
```

また、式展開したい文字列には`%{... }`、そうでない文字列には`%q{...}`といった、他のリテラルも使えます。
これは、文字列の中に`'`や`"`といった文字が含まれる場合に便利です。

_補足：文字列に式展開が含まれていないからといって、必ず式展開できない文字列を使わなければならない、という絶対的なルールはありません。_

## 文字列を操作する

Rubyの文字列は、配列と同じように考えるとわかりやすいです。
文字列には長さがあり、それぞれの文字はインデックスで参照できます（最初のインデックスは`0`です）。

```ruby
my_string = "Some string"

my_string.size   #=> 11

my_string[0]    #=> 'S'
my_string[1]    #=> 'o'
my_string[-1]   #=> 'g'

# Find the first index of a character
my_string.index('m')   #=> 2
```

文字列の一部は、インデックスや`slice`を使って取り出せます。
```ruby
my_string = "Some string"

# Find three characters starting with the second character (index 1)
my_string[1, 3]         #=> "ome"
my_string.slice(1, 3)   #=> "ome"
```

文字列の値そのものを操作することもできます。
すべてのメソッドについて知るには[Rubyのドキュメント][docs-string]を見てみる価値がありますが、よく使う例をいくつか挙げます。
```
"hello".capitalize   #=> "Hello"
"HELLO".downcase     #=> "hello"
"hello".center(9)    #=> "  hello  "
"  hello  ".strip    #=> "hello"

"hello world".split(" ")   #=> ["hello", "world"]
```

`gsub`のようなメソッドを使えば、文字を置き換えることもできます。
```
# Replace one character with another
"noob".gsub("o","0")   #=> "n00b"

# (Advanced) Replace a regular expression
"Ruby really rocks".gsub(/[aieou]/,'')   #=> "Rby rlly rcks"
```

ここまでの例では、いずれも新しい`String`が返されます。
ただし、多くのメソッドには`!`で終わる同等のものがあり、そちらは文字列そのものを変更します。

```
# Use normal methods to return new strings
my_string = "hello"
my_string.capitalize   #=> "Hello"
puts my_string         #=> "hello"

# And bang-methods (...!) to modify the object
my_string = "hello"
my_string.capitalize!  #=> "Hello"
puts my_string         #=> "Hello"
```

[docs-string]: https://docs.ruby-lang.org/en/master/String.html
