# はじめに

## 配列

F#の`array`は、長さが固定された、0個以上の値を保持する変更可能なコレクションです。つまり、一度配列を作成すると、そのサイズは変更できませんが、値は変更できます。配列内の値はすべて同じ型でなければなりません。配列は次のように定義できます：

```fsharp
let empty = [| |]
let emptyAlternative = Array.empty

let singleValue = [| 5 |]
let singleValueAlternative = Array.singleton 5

let threeValues = [| "a"; "b"; "c" |]
```

要素は、インデックスを使って配列に代入したり、配列から取得したりできます。F#の配列は0から始まるため、最初の要素のインデックスは常に0です：

```fsharp
let numbers = [| 2; 3; 5 |]

// Update value in array
numbers[2] <- 9

// Read value from array
numbers[2]
// => 9
```

配列は、`Array`モジュールで定義された関数や演算子を使って操作するか、_配列_パターンを使ったパターンマッチングで手動で操作します：

```fsharp
let describe array =
    match array with
    | [| |] -> "Empty"
    | [| 1; 2; three |] -> sprintf "1, 2, %d" three
    | _ -> "Other"

describe [| |]         // => "Empty"
describe [| 1; 2; 4 |] // => "1, 2, 4"
describe [| 5; 7; 9 |] // => "Other"
```

パターンマッチングの際に値を_破棄_することもできます。特定のケースで値を_気にしない_場合（つまり、値を_使用_しない場合）は、アンダースコア（`'_'`）を使ってこれを表すことができます：

```fsharp
let describe array =
    match array with
    | [| |] -> "Empty array"
    | [| x |] -> "Array with one item"
    | [| _; y |] -> "Array with two items (first item ignored)"
    | _ -> "Array with many items (all items ignored)"

describe [| |]          // => "Empty array"
describe [| 1 |]        // => "Array with one item"
describe [| 5; 7 |]     // => "Array with two items (first item ignored)"
describe [| 5; 7; 9 |]  // => "Array with many items (all items ignored)"
```

単一の`'_'`は、パターンマッチングの際に常に_最後_に来る必要があります。他のどのケースにも_一致しない_値はすべて、このケースで処理されます。
