# 説明

この演習では、貯蓄口座を扱います。
貯蓄口座の残高は、毎年、その利率に基づいて更新されます。
銀行が適用する利率は、口座に入っている金額（残高）によって決まります。

- 残高がマイナスの場合（残高はさらにマイナスになります）は3.213%です。
- 残高がプラスで`1000`ドル未満の場合は0.5%です。
- 残高がプラスで`1000`ドル以上`5000`ドル未満の場合は1.621%です。
- 残高がプラスで`5000`ドル以上の場合は2.475%です。

4つのタスクがあり、それぞれで残高と利率を扱います。

## 1. 利率を計算する

残高を引数に取る`SavingsAccount.interest_rate()`メソッドを実装します。
このメソッドは、与えられた残高に対する利率を返すようにします。

```Crystal
SavingsAccount.interest_rate(200.75)
# => 0.5
```

## 2. 利息を計算する

残高を引数に取る`SavingsAccount.interest()`メソッドを実装します。
このメソッドは、与えられた残高に対する利息を返すようにします。

```Crystal
SavingsAccount.interest(200.75)
# => 1.00375
```

## 3. 年間の残高更新を計算する

残高を引数に取る`SavingsAccount.annual_balance_update()`メソッドを実装します。
このメソッドは、1年後の残高を返すようにします。

```Crystal
SavingsAccount.annual_balance_update(200.75)
# => 201.75375
```

## 4. 目標残高に達するまでの年数を計算する

残高と目標残高を引数に取る`SavingsAccount.years_before_desired_balance()`メソッドを実装します。
このメソッドは、目標残高に達するまでにかかる年数を返すようにします。

```Crystal
balance = 200.75
target_balance = 214.88
SavingsAccount.years_before_desired_balance(balance, target_balance)
# => 14
```

~~~~exercism/note
単利を元本残高に適用するときは、残高に利率を掛け、その積が利息額になります。

一方、複利は利息を定期的に適用することで計算します。
適用のたびに利息額を計算して元本残高に加算するので、その後の利息計算は、より大きな元本残高に対して行われることになります。
~~~~
