# はじめに

PowerShellは、Microsoftが提供するスクリプト言語で、動的な暗黙的型付けを採用しています（強い型付けの変数もサポートします）。主にタスクの自動化と構成管理に焦点を当てています。

PowerShellは、命令型、関数型、オブジェクト指向のプログラミングに対応しており、パイプラインスタイルも扱えます。

PowerShellは.NETプラットフォーム上に作られ、2006年に最初にリリースされました。現在のWindows OSにはすべて標準で搭載されており、MacやLinuxにもインストールできます。


## 変数

PowerShellで変数を定義する方法には、よく使われるものが2つあります。

PowerShellでは、変数名は`$`で始める必要があり、代入演算子`=`を使って変数名に値を結び付けます。

```powershell
> $intVar = 1
> $doubleVar = 2.0
> $stringVar = "Hello"

# Checking a variable type using the GetType() method
> Write-Host $doubleVar.GetType()
System.Double
```

特定の[型][strong typed]を強制したい場合は、変数の型を明示的に指定することもできます。PowerShellは、可能であれば、値をある型から別の型へできる限り変換しようとします。

```powershell
# String represents a floating number can be converted to integer
> [int]$staticOne = "1.234"
> $staticOne
1

# String of letters can not be converted to double type
> [double]$staticTwo = "hello"
MetadataError: Cannot convert value "hello" to type "System.Double"
```


### 定数

PowerShellの定数は読み取り専用の変数で、一度定義すると**削除**できません。そこで、`New-Variable`というコマンドレットを使って変数を定義する2つ目の方法が出てきます。

```powershell
> New-Variable -Name "MyConstant" -Value 100 -Option Constant
> $MyConstant
```

さまざまなオプションを指定して新しい変数を作る、より詳しく高度な方法については、[New-Variable][New-Variable]コマンドレットを参照してください。


## 関数

PowerShellの[関数][functions]は、`function`キーワードを使って定義します。各関数は、`()`の括弧の中に0個以上の仮引数を取ることができ、そのあとに[スコープ][scope]が続きます。スコープは`{`で始まり`}`で終わります。

```powershell
function Greeting {
    return "Hello!"
}
```

PowerShellの関数は、`FuncName $Arg`という構文で呼び出したあと、`return`キーワードを使って明示的に値を返すことができます。

```powershell
function AddTwoNumbers($NumOne, $NumTwo):
    $result = $NumOne + $NumTwo
    return $result

> AddTwoNumbers 10 20
30
```

詳細な関数定義の書き方や、関数が暗黙的に値を返す仕組みについての高度な内容は、`Functions`コンセプトモジュールで扱います。


## コメント

PowerShellの単一行コメントは`#`で始まり、行の終わりで終わります。コメントブロックは`<#`で始まり`#>`で終わります。コメントブロックを使ってコメントベースのヘルプを作る高度な例は、`Functions`コンセプトモジュールで扱います。

```powershell
function Main() {
    #This is a comment
}
```
