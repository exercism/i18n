# アームストロング数のコンセプト

> [アームストロング数](https://en.wikipedia.org/wiki/Narcissistic_number)とは、各桁の数字を桁数で累乗して足し合わせたものが、その数自身と等しくなる数のことです。

## 解答例

```rust
pub fn is_armstrong_number(num: u32) -> bool {
    let digits = format!("{}", num);
    digits
        .chars()
        .map(|c| c.to_digit(10).unwrap().pow(digits.len() as u32))
        .sum::<u32>()
    == num
}
```

## コンセプト

- 関数：解答を検証し、ロジックを組み立てるために欠かせない
- テストスイート：解答の検証に必要
- 整数：引数と同一性の判定に使う`u32`
- `&str`：Rustは型付けが厳密なので、桁数を数えるために必要
- `Option<T>`：`char::to_digit`の実際の値にアクセスするために必要
- 型キャスト：算術演算を行うために必要
- イテレーターの機能：
  - turbofish：単一の式で解答を書くために使う
  - `map`と`sum`：式を、検証したい形へ手軽にまとめるために使う
