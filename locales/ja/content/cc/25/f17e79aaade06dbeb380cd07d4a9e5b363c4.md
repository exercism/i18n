# 説明

最近買ったあのラジコンカーが、すっかり新しい趣味になりましたね。ラジコンカーのレースを開催しています。

レースのシミュレーションを実行できるプログラムを、もう少しで書き終えるところでした。ところが、猫がキーボードに飛びついて、コードを数行消してしまいました。そのせいで、プログラムがコンパイルできなくなってしまいました…

## 1. コンパイルエラー`Race.__struct__/0 is undefined`を修正する

モジュール`NeedForSpeed.Race`を、より短い名前`Race`で参照できるように、エイリアスを追加してください。

## 2. コンパイルエラー`Car.__struct__/0 is undefined`を修正する

モジュール`NeedForSpeed.RemoteControlCar`を、より短い名前`Car`で参照できるように、エイリアスを追加してください。

## 3. コンパイルエラー`undefined function puts/1`を修正する

関数`puts/1`は、モジュール`IO`で定義されています。モジュールを参照せずに使えるように、インポートしてください。

## 4. コンパイルエラー`undefined function default_color/0`を修正する

関数`default_color/0`・`red/0`・`cyan/0`・`green/0`は、いずれもモジュール`IO.ANSI`で定義されています。ほかの車の色にも対応させたいと考えているので、モジュール全体をインポートしたいところです。残念ながら、モジュール`IO.ANSI`の関数`color/1`は、ローカルで定義した関数の1つと衝突します。その1つの関数を除いて、`IO.ANSI`モジュール全体をインポートしてください。
