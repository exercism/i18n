# 説明

この演習では、予約を管理するためのいくつかの関数に取り組みます。
システムはすべてをISO 8601形式の文字列で保存しますが、人がカレンダーを使うときの感覚とは違います。
さまざまな形式の間で変換するには、複数の関数が必要です。

## 1. 予約を作成しましょう

現在時刻から`n`日後に予約を作成します。
この関数は`n`日を受け取り、`n`日後の予約時刻を返します。

```javascript
createAppointment(4, now);
// Given now is Sun Oct 05 2022 23:28:43 GMT+0600 (Bangladesh Standard Time)
// => Sun Oct 09 2022 23:28:43 GMT+0600 (Bangladesh Standard Time)
```

2番目の仮引数`now`を使わない場合は、代わりに現在時刻を使います。

## 2. 日付をタイムスタンプに変換しましょう

さまざまなツールは、国際標準のISO 8601形式でしか扱えません。
日付を受け取って、その形式の文字列を返す関数`getAppointmentTimestamp`を書きます。

```javascript
const appointment = new Date(Date.UTC(2010, 6, 16, 12, 42, 0, 0));

getAppointmentTimestamp(appointment);
// => '2010-07-16T12:42:00.000Z'
```

## 3. 予約の詳細を取得しましょう

タイムスタンプは読みにくいものです。予約の詳細を取得する関数があると、その助けになります。
関数`getAppointmentDetails`はISO 8601形式のタイムスタンプを受け取り、年、月、日、時、分を返します。

```javascript
getAppointmentDetails('2022-04-24T08:15:00.000');
// => { year: 2022, month: 3, date: 24, hour: 8, minute: 15 }
```

## 4. 指定されたオプションで予約を更新しましょう

この関数は、第1引数に予約時刻、第2引数にいくつかのオプションを持つオブジェクトを受け取ります。
オブジェクト内のオプションに従って予約を更新し、新しい予約日時を返します。
オプションオブジェクトには複数のオプションを指定できます。

```javascript
updateAppointment('2022-02-09T09:20:00.000', { month: 6 });
// => { year: 2022, month: 6, date: 9, hour: 10, minute: 20 }
```

## 5. 2つの予約間の空き時間を取得しましょう

この関数は、2つの予約（タイムスタンプ）を引数として受け取ります。
2つの時刻の差を秒で返します。

0.5秒はほとんど意味がないので、返す前に数値を丸めます。

```javascript
timeBetween('2022-12-12T09:20:00.000', '2022-12-18T08:30:00.000');
// => 515400
```

## 6. 予約が現在有効かどうかを確認しましょう

最後に、予約が作成されると、システムはそれが有効かどうかを確認する必要があります。
つまり、予約は未来の時刻でなければならず、過去の時刻であってはなりません。

2つの引数、予約のタイムスタンプ（文字列）と現在時刻のタイムスタンプ（文字列）を受け取り、現在時刻を基準にして予約が未来であれば`true`を返す関数`isValid`を書きます。

```javascript
isValid('2022-02-11T23:00:00.000', '2022-02-08T23:00:00.000');
// => true
```
