# 指示

エレナは新聞工場の新しい品質管理責任者です。入社したばかりの彼女は、工場のいくつかの工程を見直し、改善できる点がないか確かめることにしました。
調べてみると、技術者たちが多くの品質チェックを手作業で行っていることがわかりました。
彼女はそこに自動化の絶好のチャンスを見出し、フリーランスのエンジニアであるあなたに、いくつかの機械を監視するソフトウェアの開発を依頼します。

## 1. 部屋の湿度を監視する

最初の任務は、生産室の湿度を監視するソフトウェアを書くことです。社内のソフトウェアにはすでにセンサーが接続されていて、部屋の湿度のパーセンテージを定期的に返してくれます。

湿度のパーセンテージが高すぎる場合にエラーを投げる関数を、ソフトウェアに実装する必要があります。
関数の名前は`checkHumidityLevel`とし、湿度のパーセンテージを仮引数として受け取ります。

湿度が70%を超えたらエラーを投げてください（メッセージの内容は重要ではありません）。

```javascript
checkHumidityLevel(60);
// => undefined
```

```javascript
checkHumidityLevel(100);
// Throws an error
```

## 2. 過熱を検知する

エレナは最初の仕事をとても気に入り、次は機械の温度の監視を任せたいと言います。
技術者のグレッグと雑談していると、機械の温度が500°Cを超えると、技術者たちは過熱を心配し始める、と教えられます。

機械には、内部温度を測るセンサーが取り付けられています。
このセンサーはとても繊細で、よく壊れてしまうことを覚えておいてください。
壊れてしまった場合は、技術者が交換する必要があります。

あなたの仕事は、温度を仮引数として受け取り、センサーが壊れているとき、または機械が過熱し始めたときにエラーを投げる関数`reportOverheating`を実装することです。
あとでエラーの種類に応じて違う対応をする必要があるので、2種類のエラーを区別する仕組みが要ります。
エラーメッセージに頼ることもできますが、メッセージが更新されると壊れてしまうので、コードがもろくなります。
そこで、きちんと区別できるように、異なるエラークラスのインスタンスを投げます。

- センサーが壊れていると、温度は`null`になります。
  この場合は、`ArgumentError`を投げてください。
- すべてが正常に動いているとき、温度が500°Cを超えたら、`OverheatingError`を投げてください。
  このエラークラスは、温度を引数としてインスタンス化されます。
  投げる`OverheatingError`に、temperatureプロパティが付いていることを確認してください。

```javascript
reportOverheating(null);
// Throws an ArgumentError
```

```javascript
reportOverheating(800);
// Throws an OverheatingError
```

## 3. 機械を監視する

機械がエラーを検知できるようになったので、次はそのエラーに応じてさまざまな対応をする関数を実装します。

- センサーが壊れている場合は、技術者に警告する必要があります
- 温度が高すぎる場合は、600°Cを超えていれば機械を停止し、それ未満であれば警告灯を点けます。
- それ以外のエラーが起きた場合は、そのエラーをそのまま投げ直します。

引数`actions`を受け取る関数`monitorTheMachine`を実装してください。

`actions`は、4つのプロパティを持つオブジェクトです。

| property           | description                                                                         |
| ------------------ | ----------------------------------------------------------------------------------- |
| `check`            | _*関数*_。機械の温度をチェックします。さまざまなエラーを投げる可能性があります。 |
| `alertDeadSensor`  | _*関数*_。温度センサーが壊れていることを技術者に知らせます。          |
| `alertOverheating` | _*関数*_。機械の警告灯を点けます。                        |
| `shutdown`         | _*関数*_。機械の電源を切ります。                                          |

`monitorTheMachine(actions)`関数は、内部で`check()`を呼び出します。
問題なければ、この関数は何も返しません。
呼び出しでエラーが`throw`された場合は、次のように動作します。

| exception          | expected behaviour                   |
| ------------------ | ------------------------------------ |
| `ArgumentError`    | `alertDeadSensor`関数を呼び出します。 |
| `OverheatingError` | 過熱プロトコルを実行します。    |
| _（それ以外）_  | エラーを投げ直します                    |

**過熱プロトコル**
温度が600°C未満であれば、`alertOverheating`関数を呼び出して警告灯を点けます。
温度が600°Cを超えていれば状況は危機的なので、`shutdown`関数を呼び出します。

```javascript
monitorTheMachine({
  check,
  alertDeadSensor,
  alertOverheating,
  shutdown,
});
```
