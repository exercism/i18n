## 一般的な構文

PHPの開始タグ`<?php`は、PHPコードの始まりを表します。
すべての文は、命令を区切るために`;`で終わらなければなりません。

```php
<?php

$message = "Success!"; // Statement correctly ends with `;`
$message = "I fail." // PHP Parse error: syntax error, [...]
```

読みやすくするために、以降のコード例ではPHPの開始タグ`<?php`を省略しています。

## コメント

1行コメントは`//`で始まります。

```php
// Single line comment
```

## 値と変数

代入演算子`=`を使うと、値を変数に代入できます。
変数名はドル記号`$`で始まる必要があり、[命名規則][exercism-concept-naming-conventions]に従います。

```php
$count = 1; // Assign value of 1

// Strings can be created by enclosing the characters
// within single `'` quotes or double `"` quotes.
$message = "Success!";
```

## 関数とメソッド

値や変数は関数に渡すことができます。
関数の入力は、渡された値を保持する新しい変数になります。
関数は、キーワード`return`を使って任意の値を返すことができます。

```php
function window_height($height)
{
    return $height + 10;
}

window_height(100);
// => 110
```

クラスとそのインスタンスの内部にある関数は、メソッドと呼ばれます。
メソッドを呼び出すには、名前の前にインスタンスと`->`を書きます。
メソッドは、現在のインスタンスを指す特別な変数`$this`にアクセスできます。

```php
<?php

class Calculator {
    public function sub($x, $y)
    {
        return $this->add($x, -$y); // Calls the method add() of the current instance
    }

    public function add($x, $y)
    {
        return $x + $y;
    }
}

$calculator = new Calculator(); // Creates a new instance of Calculator class
$calculator->sub(3, 1); // Calls the method sub() of the instance stored in $calculator
// => 2
```
