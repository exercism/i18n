# はじめに

[`Rational numbers`][rational]は、整数の分子を整数の分母で割った分数です。

たとえば、`2//3`を、`Float64`による近似値`0.6666...`ではなく、正確な分数として保存できます。

この利点は、（[整数オーバーフロー][integer-overflow]という極端な場合を除いて）有理数が正確なまま保たれ、浮動小数点数では避けられないことが多い丸め誤差を防げることです。

さらに詳しい説明は、Juliaの[マニュアルのページ][julia-rational]にあります。

有理数はとてもシンプルな数値型で、予想どおりに動くように作られています。
初期のバージョンからJuliaの標準の型であるため、ほとんどの関数は、整数や小数と同じように有理数を入力として受け付けます。

## 有理数の作り方

作り方は、2つの整数の間に`//`を使うだけです。

```julia-repl
julia> 3//4
3//4

julia> a = 3; b = 4;

julia> a//b
3//4
```

共通の因数は自動的に取り除かれ、分数は[「最も簡単な形」][lowest-terms]に変換されます。つまり、その分数を正確に表す最小の整数で、分母が負でない形です。

```julia-repl
julia> 5//15
1//3

julia> 5//-15
-1//3
```

無限大の結果は受け付けますが、[`NaN`][NaN]は受け付けません。

```julia-repl
julia> 1//0
1//0

julia> float(1//0)
Inf

julia> 0//0
ERROR: ArgumentError: invalid rational: zero(Int64)//zero(Int64)
```

## 有理数の計算

通常の[`arithmetic operators`][operators]、つまり`+ - * / ^ %`は、他の数値型とほぼ同じように有理数でも使えます。

整数や他の`Rational`を含めることもでき、結果は`Rational`になります。
`float`を式に含めると結果は`float`になり、その分だけ精度が失われる可能性があります。

`float`が必要な場合は、`float()`関数を使って有理数を変換するだけです。
長い計算のあいだ精度を保つために有理数を使い、最後に小数へ変換するのは、ごく普通のことです。

```julia-repl
julia> 3//4 + 1//3  # addition
13//12

julia> 3//4 * 1//3  # multiplication
1//4

julia> 3//4 / 1//3  # division
9//4

julia> 3//4 ^ 2  # exponentiation
3//16

julia> 3//4 + 5  # rational and int => rational
23//4

julia> 3//4 + 5.3  # rational and float => float
6.05

julia> float(3//4)  # casting
0.75
```

有理数と[複素数][complex]を組み合わせることもできます。
複素数については、[別の概念][complex-concept]で説明しています。

## その他の操作

Juliaでは、有理数はただの数値です。
コンパイラーは通常、必要に応じて型を変換します。

ただし、比較がうまくいくのは、有限の小数で表せる分数だけであることに注意してください。

```julia-repl
julia> 3//4 == 0.75
true

julia> 3//4 < 0.74
false
```

それ以外の場合は、比較のために`Rational`を`Float`に変換する必要があります。

```julia-repl
julia> 1//3 == 1/3
false

julia> float(1//3) == 1/3
true
```

数学関数は有理数を入力として受け取りますが、結果が浮動小数点数になることがあります。

```julia-repl
julia> sqrt(9//16)
0.75
```
