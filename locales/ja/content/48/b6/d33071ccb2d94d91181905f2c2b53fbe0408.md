# はじめに

Elixirでは、1つの関数に複数の節を持たせることができます。そのため、**オープン・クローズドの原則**に沿った書き方がしやすくなり、ごちゃごちゃとした制御ロジックをハードコードするのではなく、振る舞いを簡単に追加したり削除したりできる、目的を絞った関数を書けるようになります。

Elixirには、次のようなコードを書くための_複数の関数節_と_ガード_があります。

```elixir
def number(n) when n == 7 do
  "Awesome, that's my favorite"
end

def number(_n) do
  "That's not my favorite"
end
```

実行時、Elixirはソースファイルを上から下へとたどり、どの関数節を呼び出すかを判定します。

使われていない変数は、名前の先頭にアンダースコアを付けます。
