# テスト

依存関係をインストールしましょう。

```sh
dart pub get
```

テストを実行しましょう。

```sh
dart test
```

テストごとのより詳細な出力が必要な場合は、`expanded`レポーターを使います。

```sh
dart test -r expanded
```

ほとんどの演習には複数のテストがあり、最初のテスト以外はデフォルトでスキップされます。
テストを1つずつ進めるには、各テストの`skip: true`を`skip: false`に変えながら進めます。

または、ファイルを編集せずにすべてのテストを一度に実行することもできます。

```sh
dart test --run-skipped
```

提出時には、スキップされたテストも含め、すべてのテストがオンラインのテストランナーによって実行されます。
