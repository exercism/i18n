# はじめに

## アロー関数

関数宣言や関数式のほかにも、JavaScriptには関数を定義するための、とても簡潔な構文があります。
このような関数は、_アロー関数_と呼ばれます。

関数宣言とアロー関数を比べてみましょう。

```javascript
function addUpTwoNumbers(num1, num2) {
  return num1 + num2;
}
// function keyword removed and => added
const addUpTwoNumbers = (num1, num2) => {
  return num1 + num2;
};
```

上の例のように、関数の本体が`return`文だけの場合は、波括弧（`{}`）と`return`キーワードを省略できます。
入力が1つだけの場合は、括弧（`()`）も省略できます。

<!-- prettier-ignore-start -->
```javascript
const addUpTwoNumbers = (num1, num2) => num1 + num2;
const square = num => num * num;
```
<!-- prettier-ignore-end -->

アロー関数は、短いコールバック関数を関数呼び出しの中に直接定義するときによく使われます。

<!-- prettier-ignore-start -->
```javascript
applyToSquare(number => number * number);
```
<!-- prettier-ignore-end -->

## 配列の分析

[配列][arrays-concept]には、配列の中身を分析するための組み込みメソッドがあります。
これらのメソッドのほとんどは、`true`または`false`を返す関数を入力として受け取ります。
このような関数は、[`predicate`][predicate_in_programming]と呼ばれます。

これらの組み込みメソッドは、_`for`ループや組み込みの`forEach`メソッドの代わりに_使うためのものです。

`for`ループを使った分析の例：

```javascript
const numbers = [1, 'two', 3, 'four'];
for (var i = 0; i < numbers.length; i++) {
  if (numbers[i] === 'two') {
    return i;
  }
}
// => 1
```

組み込みメソッドを使った分析の例：

```javascript
const numbers = [1, 'two', 3, 'four'];
numbers.indexOf('two');
// => 1
```

配列を分析するときに役立つ、そのほかの組み込みメソッドを以下に紹介します。
配列のメソッドの一覧は、[MDN][mdn-array-methods]を参照してください。

### `includes`

`includes(value)`メソッドは、配列に特定の値が含まれているかどうかを判定します。
値が含まれていれば`true`を、含まれていなければ`false`を返します。

```javascript
const numbers = [1, 'two', 3, 'four'];
numbers.includes(1);
// => true
numbers.includes('one');
// => false
```

### `every`

`every(predicate)`メソッドは、_述語_である関数を入力として受け取ります。
これは、配列のすべての要素を述語に渡したときに`true`を返すかどうかを調べます。
言い換えると、すべての要素が、このメソッドに渡したテストに通るかどうかを調べるということです。
すべての要素が述語のテストに合格したら`true`を、そうでなければ`false`を返します。

```javascript
const numbers = [1, 3, 5, 7, 9];
numbers.every((num) => num % 2 !== 0);
// => true
```

### `some`

`some(predicate)`メソッドは`every`メソッドと同じですが、配列の中の少なくとも1つの要素が_述語_のテストに合格したときに`true`を返します。

```javascript
const numbers = [1, 3, 5, 7, 9];
numbers.some((num) => num % 2 !== 0);
// => true
```

### `find`

`find(predicate)`メソッドは、`predicate`のテストに合格した最初の要素の値を返します。
`some()`が合格したときに`true`を返すのに対し、`find()`は配列内の実際の値を返します。
配列のどの要素も_述語_のテストに合格しなかった場合、このメソッドは`undefined`を返します。

```javascript
const numbers = [1, 3, 5, 7, 9];
numbers.find((num) => num < 5);
// => 1
```

### `findIndex`

`findIndex(predicate)`は`find()`メソッドと同じですが、_述語_のテストに合格した要素の（最初の）_インデックス_を、`value`の代わりに返します。
配列のどの要素も_述語_のテストに合格しなかった場合、このメソッドは`-1`を返します。

```javascript
const numbers = [1, 3, 5, 7, 9];
numbers.findIndex((num) => num > 7);
// => 4
numbers.findIndex((num) => num > 9);
// => -1
```
