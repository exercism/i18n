# 説明

地震計アレイの処理ステーションを運用します。地震計アレイは、地面がどのように動いたかを記録するセンサーのネットワークです。

観測値は値のブロックとして届きます。一部は32ビット浮動小数点数として格納された地盤変位で、それ以外は32ビット整数として格納された生のカウントとステータスワードです。ステーションはブロック全体を一度に処理し、各値に同じ操作を適用します。

6つのタスクに取り組みます。どのタスクも、メモリ上に置かれた値のブロックを操作します。オペランドはメモリアドレスを通して受け取り、答えは結果アドレスを通して書き込みます。この演習のメモリアドレスはすべて16バイト境界に整列されています。

~~~~exercism/note
この演習の計算は、スカラー演算ではなく、SIMDのビット演算とシフトを使って行ってください。
~~~~

## 1. トレースを整流する

大きさを解析するときは、各地盤変位の大きさだけが重要で、向きは関係ありません。最初の処理ステップでは、すべての観測値を非負の値に変換します。

`rectify_trace`関数を実装してください。この関数は、各観測値の絶対値を計算します。1つのブロックには4つの観測値が入っており、それぞれが32ビット浮動小数点数です。

この関数は、次の順に引数を受け取ります。

- `result`：4つの整流後の観測値が書き込まれるバッファのメモリアドレス。
- `trace`：記録された観測値のメモリアドレス。4つの値があり、それぞれが32ビット浮動小数点数です。

```c
trace  = {1.5, -2.25, 0.0, -135.75}
result = {1.5,  2.25, 0.0,  135.75}
```

この関数に戻り値はありません。

## 2. 揺れのスケールを読み取る

解析担当者は、揺れを2のべき乗のスケールで等級付けします。`8.0`に近い観測値はスケール`3`、`0.25`に近い観測値はスケール`-2`になります。そのスケールは、各浮動小数点数の指数部としてすでに格納されています。

32ビット浮動小数点数は、ビット31が符号ビット、ビット30から23が8ビットの指数部、ビット22から0が23ビットの仮数部という構成になっています。格納されている指数には127のバイアスがかかっているため、この値は`(-1)^sign * 1.fraction * 2^(exponent - 127)`で表されます。

`reading_scale`関数を実装してください。この関数は、各観測値のバイアスを除いた指数を符号付き32ビット整数として取り出します。

この関数は、次の順に引数を受け取ります。

- `result`：4つのスケールが書き込まれるバッファのメモリアドレス。それぞれ符号付き32ビット整数です。
- `trace`：整流後の観測値のメモリアドレス。4つの値があり、それぞれが32ビット浮動小数点数です。

```c
trace  = {8.0, 0.25, 1.0, 13.5}
result = {  3,   -2,   0,   3}
```

この関数に戻り値はありません。すべての観測値は正規の非ゼロ浮動小数点数です。

## 3. 分解能を粗くする

長期保存では、生の変位カウントをより粗い分解能で保持します。各カウントは2のべき乗で割られます。

変位カウントには符号があります。地面はどちらの向きにも動くからです。正しく割るには、符号を保つシフトを使う必要があります。

`coarsen_displacements`関数を実装してください。この関数は、各符号付きカウントを`2^shift`で割り、負の無限大方向に丸めます。

この関数は、次の順に引数を受け取ります。

- `result`：4つの粗くしたカウントが書き込まれるバッファのメモリアドレス。それぞれ符号付き32ビット整数です。
- `counts`：生のカウントのメモリアドレス。4つの符号付き32ビット整数です。
- `shift`：割る2のべき乗。`0`から`31`までの64ビット符号なし整数です。

```c
counts = {1024, -1024, 25, -25}
shift  = 3
result = { 128,  -128,  3,  -4}
```

~~~~exercism/note
`movq`命令を使うと、64ビット整数を汎用レジスタから`xmm`レジスタへ、ビット表現を変えずにコピーできます。
~~~~

この関数に戻り値はありません。

## 4. チャンネルをゲートする

各ステーションは2つの記録キャンペーンを統合し、そのあと、ハードウェアのレポートが故障と示したチャンネルをオフにします。各ブロックには4つのチャンネルマスクが入っており、それぞれが符号なし32ビット整数で、各ビットが1つのチャンネルを表します。`1`が有効、`0`が無効です。

`gate_channels`関数を実装してください。この関数は、どちらかのキャンペーンで有効になっているチャンネルを組み合わせ、そのあと故障と示されたすべてのチャンネルをクリアします。

この関数は、次の順に引数を受け取ります。

- `result`：4つのゲート後のマスクが書き込まれるバッファのメモリアドレス。それぞれ符号なし32ビット整数です。
- `enable_a`：1つ目のキャンペーンの有効化マスクのメモリアドレス。4つの符号なし32ビット整数です。
- `enable_b`：2つ目のキャンペーンの有効化マスクのメモリアドレス。4つの符号なし32ビット整数です。
- `faulty`：故障チャンネルのマスクのメモリアドレス。4つの符号なし32ビット整数です。

```c
enable_a = {0b1100, 0b0001, 0b1111, 0b0000}
enable_b = {0b0110, 0b0001, 0b0000, 0b0000}
faulty   = {0b0100, 0b0011, 0b1001, 0b1111}
result   = {0b1010, 0b0000, 0b0110, 0b0000}
```

この関数に戻り値はありません。

## 5. 校正ビットを反転する

ステーションは1日に1回、校正パスを実行し、各ステータスワードの選ばれた設定ビットを反転させ、それ以外のビットはそのままにします。ただし、一部のビットはハードウェアによってロックされており、パスが何を要求しても決して変わってはいけません。同じパスを2回実行すると、元の設定に戻ります。

`toggle_calibration`関数を実装してください。この関数は、各ステータスワードにおいて、対応するトグルマスクでセットされていて、かつ対応するロックマスクでセットされていないビットだけを反転させます。

この関数は、次の順に引数を受け取ります。

- `result`：4つの更新後のステータスワードが書き込まれるバッファのメモリアドレス。それぞれ符号なし32ビット整数です。
- `status`：現在のステータスワードのメモリアドレス。4つの符号なし32ビット整数です。
- `toggle`：トグルマスクのメモリアドレス。4つの符号なし32ビット整数です。
- `locked`：ロックマスクのメモリアドレス。4つの符号なし32ビット整数です。

```c
status = {0b1100, 0b0001, 0b1111, 0b1010}
toggle = {0b0110, 0b0011, 0b1111, 0b1010}
locked = {0b0010, 0b0001, 0b1100, 0b0000}
result = {0b1000, 0b0011, 0b1100, 0b0000}
```

この関数に戻り値はありません。

## 6. トレースを増幅する

アレイの各チャンネルには独自のゲイン調整があり、2のべき乗で表されます。ゲイン`3`はそのチャンネルの観測値を`8`倍し、ゲイン`-5`は`32`で割ります。

ステーションは、各浮動小数点数の指数部を操作することで、掛け算を1回も使わずにこれらのゲインを適用します。

`amplify_trace`関数を実装してください。この関数は、各観測値に、そのチャンネルのゲインを指数とする`2`のべき乗を掛けます。操作するのは生のビットだけです。

この関数は、次の順に引数を受け取ります。

- `result`：4つの増幅後の観測値が書き込まれるバッファのメモリアドレス。
- `trace`：観測値のメモリアドレス。4つの値があり、それぞれが32ビット浮動小数点数です。
- `gains`：チャンネルごとのゲインのメモリアドレス。4つの符号付き32ビット整数です。

```c
trace  = {1.5, -2.0, 0.25, 96.0}
gains  = {  2,    1,    3,   -5}
result = {6.0, -4.0,  2.0,  3.0}
```

この関数に戻り値はありません。すべての観測値は正規の非ゼロ浮動小数点数で、増幅後の結果もすべて正規数です。
