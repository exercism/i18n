# 指示

この演習では、高校時代の恋人同士がSNSで愛を告白できるよう、二人のイニシャルをASCIIのボックスにして生成するお手伝いをします。

```
❤-------------------❤
|  J. K.  +  M. B.  |
❤-------------------❤
```

## 1. 名前の最初の文字を取得する

`HighSchoolSweetheart.first_letter/1`関数を実装します。名前を受け取り、その最初の文字を返すようにします。名前に含まれる不要な空白は取り除きます。

```elixir
HighSchoolSweetheart.first_letter("Jane")
# => "J"
```

## 2. 最初の文字をイニシャルとして整形する

`HighSchoolSweetheart.initial/1`関数を実装します。名前を受け取り、その最初の文字を大文字にして、ピリオドを付けたものを返します。前のステップで定義した`HighSchoolSweetheart.first_letter/1`を必ず再利用しましょう。

```elixir
HighSchoolSweetheart.initial("Robert")
# => "R."
```

## 3. フルネームを名と姓に分割する

`HighSchoolSweetheart.initials/1`関数を実装します。スペースで区切られた名と姓からなるフルネームを受け取り、イニシャルを返します。前のステップで定義した`HighSchoolSweetheart.initial/1`を必ず再利用しましょう。

```elixir
HighSchoolSweetheart.initials("Lance Green")
# => "L. G."
```

## 4. イニシャルをASCIIのボックスの中に入れる

`HighSchoolSweetheart.pair/2`関数を実装します。二つのフルネームを受け取り、ASCIIのボックスの中にイニシャルを入れて返します。ボックスを自分で描く必要はありません。コードのコメントに含まれているボックスを利用しましょう。前のステップで定義した`HighSchoolSweetheart.initials/1`を必ず再利用しましょう。

```elixir
HighSchoolSweetheart.pair("Blake Miller", "Riley Lewis")
# => """
# ❤-------------------❤
# |  B. M.  +  R. L.  |
# ❤-------------------❤
# """
```
