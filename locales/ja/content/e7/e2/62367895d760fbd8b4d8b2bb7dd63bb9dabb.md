# 説明

この演習では、エンジニアが識別子名をきれいにするのを助ける、ユーティリティルーチンの一部を実装します。

4つのタスクを通して、`clean`というルーチンを少しずつ作り上げていきます。有効な識別子は、0個以上の文字とアンダースコアで構成されます。

どの場合でも、入力の文字列はnil以外であることが保証されています。`clean`関数に空の文字列が渡された場合は、空の文字列を返すようにします。

なお、空の識別子で`clean`ルーチンを呼び出すのは避けましょう。そのような識別子には意味がないからです。

## 1. 空白をアンダースコアに置き換える

`clean`関数を実装して、空白をアンダースコアに置き換えます。先頭と末尾の空白にも適用されます。

```clojure
(clean "my   Id")
;;=> "my___Id"
```

## 2. 制御文字を大文字の文字列"CTRL"に置き換える

`clean`関数を変更して、制御文字を大文字の文字列`"CTRL"`に置き換えます。

```clojure
(clean "my\0Id")
;;=> "myCTRLId"
```

## 3. ケバブケースをキャメルケースに変換する

`clean`関数を変更して、ケバブケースをキャメルケースに変換します。

```clojure
(clean "à-ḃç")
;;=> "àḂç"
```

## 4. ギリシャ文字の小文字を除外する

`clean`関数を変更して、'α'から'ω'の範囲のギリシャ文字を除外します。

```clojure
(clean "MyΟβιεγτFinder")
;;=> "MyΟFinder"
```
