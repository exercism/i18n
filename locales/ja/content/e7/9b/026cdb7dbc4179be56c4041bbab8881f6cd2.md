# 概要

Flags属性を使うと、判別共用体で定義した値をビット位置（つまりフラグ）として表せます。フラグとして扱えば、そうした値を組み合わせることができ、複数の真偽値の条件を1つの値で表せるようになります。

```fsharp
[<Flags>]
type PhoneFeatures =
| Call = 1
| Text = 2
```

```fsharp
[<Flags>]
type PhoneFeaturesBinary =
| Call = 0b00000001
| Text = 0b00000010
```

フラグの設定には、ビット単位のOR演算子（`|||`）を使います。フラグの解除には、ビット単位のAND演算子（`&&&`）とビット単位の否定演算子（`~~~`）を組み合わせます。フラグの状態を確認するにはビット単位のAND演算子を使いますが、HasFlag()メソッドを使うこともできます。

```fsharp
let features = PhoneFeatures.Call

// Set the Text flag
let moreFeatures = features ||| PhoneFeatures.Text

moreFeatures.HasFlag(PhoneFeatures.Call) // => true
moreFeatures.HasFlag(PhoneFeatures.Text) // => true

// Unset the Call flag
let lessFeatures = features &&& ~~~PhoneFeatures.Call

lessFeatures.HasFlag(PhoneFeatures.Call) // => false
lessFeatures.HasFlag(PhoneFeatures.Text) // => true
```

F#言語で使えるビット演算子の完全な一覧は、[ビット演算子の概要][bitwise-operators]を参照してください。
