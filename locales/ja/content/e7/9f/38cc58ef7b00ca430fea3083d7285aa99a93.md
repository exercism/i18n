# ヒント

## 1. オーブンにかかる時間を分単位で定義する

- レシピで指定された[`number`][numbers]の値を持つ[定数][constants]を定義します。
- その定数を[`export`][export]します。

## 2. 残りのオーブン時間を分単位で計算する

- 関数から[数値を明示的に返します][return]。
- 値を引くには、[引き算の数学演算子][operators]を使います。

## 3. 準備にかかる時間を分単位で計算する

- 関数から[数値を明示的に返します][return]。
- 値を掛けるには、[掛け算の数学演算子][operators]を使います。
- 1層あたりの分数には、追加の定数を使います。

## 4. 合計の作業時間を分単位で計算する

- 関数から[数値を明示的に返します][return]。
- 以前に実装した他のメソッドの1つを[呼び出します][invocation]。
- 値を足すには、[足し算の数学演算子][operators]を使います。
