# 説明

ロールプレイングゲームを実装しています。
プレイヤーのキャラクターは次のように表されます。

```rust
pub struct Player {
    health: u32,
    mana: Option<u32>,
    level: u32,
}
```

このゲームのプレイヤーは、レベル10に達するまではマナプールを使えません。マナプールは、呪文を唱えるために使います。
それまでは、Playerのマナは`Option::None`です。

このゲームでは、2つの機能に取り組みます。復活の仕組みと、呪文詠唱の仕組みです。

`revive`メソッドは、Playerが本当に死んでいるかどうか（体力が0になっているか）を確認し、死んでいれば、体力が100の新しいPlayerインスタンスを返す必要があります。
`revive`メソッドは、Playerのレベルを保持する必要があります。
Playerのレベルが10以上であれば、マナ100で復活させます。
Playerのレベルが10未満であれば、マナは`Option::None`になります。

```rust
let dead_player = Player { health: 0, mana: Option::None, level: 2 };
dead_player.revive()
// Returns Player { health: 100, mana: Option::None, level: 2 }
```

体力が1以上のPlayerに対して`revive`メソッドを呼び出した場合、メソッドは`Option::None`を返す必要があります。

```rust
let alive_player = Player { health: 1, mana: Option::Some(15), level: 11 };
alive_player.revive()
// Returns Option::None
```

`cast_spell`メソッドは、Playerへの可変参照と、呪文にかかるマナの量を示す仮引数`mana_cost`を受け取ります。
戻り値は、唱えた呪文が与えるダメージ量です。

- プレイヤーがマナプールを使えない場合、呪文を唱えようとすると、呪文のマナコストの分だけ体力が減ります。
  返されるダメージは0でなければなりません。

  ```rust
  let not_a_wizard_yet = Player { health: 79, mana: Option::None, level: 9 };
  assert_eq!(not_a_wizard_yet.cast_spell(5), 0)
  assert_eq!(not_a_wizard_yet.health, 74);
  assert_eq!(not_a_wizard_yet.mana, Option::None);
  ```

- プレイヤーがマナプールを持っていてもマナが足りない場合、メソッドはマナプールに影響を与えません。
返されるダメージは0でなければなりません。

  ```rust
  let low_mana_wizard = Player { health: 93, mana: Option::Some(3), level: 12 };
  assert_eq!(low_mana_wizard.cast_spell(10), 0);
  assert_eq!(low_mana_wizard.health, 93);
  assert_eq!(low_mana_wizard.mana, Option::Some(3));
  ```

- それ以外の場合、呪文は正常に唱えられます。
  `mana_cost`はPlayerのマナプールから差し引かれます。
  返されるダメージは、呪文のマナコストの2倍でなければなりません。

  ```rust
  let wizard = Player { health: 123, mana: Option::Some(30), level: 18 };
  assert_eq!(wizard.cast_spell(10), 20);
  assert_eq!(wizard.health, 123);
  assert_eq!(wizard.mana, Option::Some(20));
  ```
