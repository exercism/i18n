# はじめに

Juliaでは、主に次の3つの条件文が使われます：

- `if`式
- 三項演算子
- 短絡評価

## `if`式

Juliaの`if`式は、他の言語で見られるものとよく似ています：

```julia-repl
julia> function say_if_positive(n)
           if n > 0
               println("n is positive!")
           else
               println("n is not positive!")
           end
       end
say_if_positive (generic function with 1 method)

julia> say_if_positive(10)
n is positive!

julia> say_if_positive(-10)
n is not positive!
```

`if`に続く真偽値の式が`true`と評価されると、最初のコードブロックが実行され、2番目のブロックはスキップされます。
`if`に続く真偽値の式が`false`と評価されると、最初のコードブロックはスキップされ、2番目のブロックが実行されます。
プログラムは、`end`キーワードの後の最初のコード行から実行を続けます。

~~~~exercism/note
Juliaでは、`end`キーワードはすべてのブロック式の終わりを表します。
この構文は、`if`式や関数定義に固有のものではありません。
~~~~

2番目のコードブロックが単なる別の`if`式になる場合は、`elseif`を使うことで、ブロックの中に`if`式を入れ子にせずに済みます：

```julia-repl
julia> function dessert(fruit)
           if fruit == "apple"
               return "Apple Crumble"
           elseif fruit == "lemon"
               return "Lemon Meringue Pie"
           else
               return "Fruit Salad"
           end
       end
dessert (generic function with 1 method)

julia> dessert("apple")
"Apple Crumble"

julia> dessert("lemon")
"Lemon Meringue Pie"

julia> dessert("peach")
"Fruit Salad"
```

`if`式で、一方のケースのコードだけを実行すればよいなら、`else`節を書く必要はありません。

## 三項演算子

単純な`if-else`文は、三項演算子`a ? b : c`を使って書くこともできます。
`a`が真なら、`b`が評価されます。
そうでなければ、`c`を評価します。

たとえば、次の関数は

```julia-repl
julia> function diagnose(heartrate)
           if heartrate > 100
               println("Elevated heart rate.")
           else
               println("Nominal heart rate or dead.")
           end
       end
diagnose (generic function with 1 method)
```

次のようにも書けます

```julia-repl
julia> diagnose(heartrate) = heartrate > 100 ? println("Elevated heart rate.") : println("Nominal heart rate or dead.")
diagnose (generic function with 1 method)
```

これは、条件に応じて変数に別の値を代入したいときに特に便利です。
`x = a ? b : c`は、`a`が`true`なら`b`を`x`に代入し、そうでなければ`c`を`x`に代入します。
たとえば：

```julia-repl
julia> function patient_status(heartrate)
           status = heartrate > 0 ? "alive" : "dead"

           println("The patient is ", status)
       end

julia> patient_status(100)
The patient is alive

julia> patient_status(0)
The patient is dead
```

## 短絡評価

複数の真偽値の式が`&&`演算子と`||`演算子でつながれている場合、Juliaは、式全体の値を判断するのに必要な最小限の式だけを評価します。

たとえば、式の連鎖`n > 0 && k > 10`を考えてみましょう。
`n`が`5`に等しいとき、連鎖の最初の部分`n > 0`は`true`なので、式全体が`true`かどうかを判断するには、2番目の式`k > 10`を評価する必要があります。
しかし、`n`が`-5`に等しいときは、最初の式が`false`なので、連鎖全体が`true`に**なることはありません**。

代わりに`n > 0 || k > 10`を考えると、逆のことが起こります。
`n`が`5`に等しいとき、連鎖の最初の部分`n > 0`は`true`なので、2番目の式に関係なく連鎖全体が`true`になることがわかります。
しかし、`n`が`-5`に等しいときは、2番目の式を評価する必要があります。

この動作を利用すると、とても短い`if`文を書けます：

```julia
if a
    b
end
```

これは次と等価です：

```julia
a && b
```

`&&`と`||`の連鎖では、最後の式は真偽値の式である必要はありません。
この機能は、早めにエラーを出したり、早期リターンしたりするためによく使われます。
たとえば、上で定義した`dessert(fruit)`関数を使います：

```julia-repl
julia> function whats_for_dessert(fruit, allergic_to)
           fruit == allergic_to && return "I can't eat that, guess I'll not have dessert tonight!"

           return dessert(fruit)
       end
whats_for_dinner (generic function with 1 method)

julia> whats_for_dinner("apple", "peach")
"Apple Crumble"

julia> whats_for_dinner("apple", "apple")
"I can't eat that, guess I'll not have dessert tonight!"
```
