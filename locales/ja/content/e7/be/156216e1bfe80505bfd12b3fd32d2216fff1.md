# 説明

この演習では、お気に入りの料理本に載っている最高のラザニア作りに役立つコードを、もう少し書いていきます。

タスクは5つあり、どれもラザニア作りにかかる時間に関係しています。

## 1. オーブンの予定時間を変更できるようにする

前のタスクで求めたオーブンの予定時間（分）をもとに、ラザニアをあと何分オーブンに入れておく必要があるかを返す、改良版の`remainingMinutesInOven`関数を書きたくなりました。この関数は、ラザニアをオーブンに入れてから経過した分数を仮引数として受け取ります。
以前は、`remainingMinutesInOven`関数の外にある定数`expectedMinutesInOven`に頼っていました。
しかし、それは少しゴチャゴチャしすぎていて好みに合いませんし、オーブンの予定時間を変更できないため、柔軟性も十分ではありませんでした。

すっきりさせるために、`remainingMinutesInOven`関数を定義しましょう。この関数は、ラザニアをオーブンに入れてから経過した分数と、デフォルト値が40の`expectedMinutesInOven`仮引数を受け取ります。
関数は、前のタスクで求めたオーブンの予定時間（分）をもとに、ラザニアをあと何分オーブンに入れておく必要があるかを返すようにします。

```swift
remainingMinutesInOven(elapsedMinutes: 30)
// Returns 10
remainingMinutesInOven(elapsedMinutes: 30, expectedMinutesInOven: 75)
// Returns 45
```

## 2. 層の数を変えられるようにする

以前、`preparationTimeInMinutes`関数を書きました。これは、ラザニアに加えた層の数を仮引数として受け取り、1つの層の準備に2分かかると仮定して、ラザニアの準備に何分かかったかを返すものでした。
しかし、この関数を呼び出す前にラザニアの層の数を自分で数えなければならず、あまり満足していません。そんなことをする時間が、誰にあるでしょうか？

もっと楽をするために、`preparationTimeInMinutes`関数を書きましょう。これは可変長の`String`型の仮引数`layers`を受け取り、そこにラザニアのさまざまな層を並べます。
関数はラザニアの層の数を数え、必要な準備時間を返します。

```swift
preparationTimeInMinutes(layers: "sauce", "noodles")
// Returns 4
preparationTimeInMinutes(layers: "sauce", "noodles", "sauce", "meat", "mozzarella", "noodles", "sauce", "eggplant", "béchamel", "noodles", "sauce", "mozzarella")
// Returns 24
```

## 3. 麺とソースの量を計算する

ラザニアを組み立て始める前に、夢のラザニアを作るのに十分なソースと麺があるか確認したいところです。
ラザニアの麺の層1つにつき、麺が3枚必要です。
ソースの層1つにつき、ソースが0.2リットル必要です。

`quantities`関数を定義しましょう。これは可変長の`String`型の仮引数`layers`を受け取り、そこにラザニアのさまざまな層を並べます。
関数は、料理を作るのに必要な麺とソースの量を求めます。結果は`(noodles: Int, sauce: Double)`型のタプルで返します。

```swift
quantities(layers: "sauce", "noodles", "sauce", "meat", "mozzarella", "noodles", "sauce", "eggplant", "béchamel", "noodles", "sauce", "mozzarella")
// Returns (noodles: 9, sauce: 0.8)
quantities(layers: "sauce", "noodles", "sauce", "noodles", "meat", "noodles", "mozzarella")
// Returns (noodles: 9, sauce: 0.4)
```

## 4. リットルを液量オンスにその場で変換する

残念ながら、手元にあるソースは、量がリットルではなく液量オンスで表示されています。
手元のソースが足りるかどうかを知るために、`toOz`関数を書きましょう。これはin-outのタプル仮引数`(noodles: Int, sauce: Double)`を受け取り、ソースの量を液量オンスに変換します。
1リットルは33.814液量オンスであることに注意してください。

```swift
var amount = (noodles: 9, sauce: 0.8)
toOz(&amount)

amount
// Returns (noodles: 9, sauce: 27.0512)
```

## 5. 合わせるのに最適なワインを決める

最後に、ラザニアに合わせるワインの種類を知りたくなりました。
ラザニアにモッツァレラ、リコッタ、ベシャメルが肉とソースより多い場合は白ワインを、それ以外の場合は赤ワインを合わせるとよいと聞きました。
`redWine`関数を書きましょう。これは可変長の`String`型の仮引数`layers`を受け取り、そこにラザニアのさまざまな層を並べます。
関数は5つの入れ子の関数を使って、ラザニアの中のモッツァレラ、リコッタ、ベシャメル、ソース、肉の層の数を求め、その層の数を比べて赤ワインを合わせるべきかどうかを判断します。赤ワインなら`true`を、そうでなければ`false`を返します。

```swift
redWine(layers: "sauce", "noodles", "sauce", "meat", "mozzarella", "noodles", "sauce", "eggplant", "béchamel", "noodles", "sauce", "mozzarella")
// Returns true
redWine(layers: "sauce", "noodles", "béchamel", "meat", "mozzarella", "noodles", "ricotta", "eggplant", "béchamel", "noodles", "sauce", "mozzarella")
// Returns false
```
