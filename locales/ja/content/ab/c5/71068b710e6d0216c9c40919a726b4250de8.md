# リソース

## フォーラム

 * [Euphoriaフォーラム][forum]では、Phixに関する質問を歓迎しています。

## その他のリソース

### RosettaCode

123件の[基本的なエントリ][basic]を厳選したリストです。このサイトで検索すれば、探しているものが見つかることがよくあります。
1674以上あるrosettacodeのエントリのうち、5分の1から4分の1ほどは標準ディストリビューションに同梱されています。

### Github

Phixのソースは[GitHubリポジトリ][github]にあります。
公式リリースのたびに更新されるのは明らかですが、一般的に「最先端（bleeding edge）」のビルドを維持しているわけではない点に注意してください。
ほとんどのユーザーは前者にとどめておくべきです。後者については、フォーラムで尋ねてみる価値があるでしょう。

### PCAN

[Phix Comprehensive Archive Network][pcan]は、CPANを模したものです。多くのエントリがやや古くなっているのは否めません。
実質的には、[Euphoriaのアーカイブ][archive]のミラーで、初期の頃から2018年までのものに、いくつかの新しいエントリが加わった形です。
