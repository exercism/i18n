# 説明

ハルの波止場では夜勤の時間です。貨物船*Olwen*が横付けされ、港湾作業員の一団がマニフェストを並行して処理しています。どのクレートも船に積み込む前に重量を量らなければなりません。そして港湾管理者は、すべての巻き上げが更新する1つの**トン数の累計**をつけています。厄介なのは、岸壁のクレーンが1台しかないことです。2人の作業員が同時に更新すると、累計が壊れてしまいます。

各クレートは品物の重量の配列です。クレートの重量は、それらの品物の合計です。

## 1. クレートの重量を量る

`weigh-crate`を定義し、クレートを受け取って合計重量を返すようにします。これは単純な逐次処理です。クレート1つにつき、数値が1つ返ります。

```factor
{ 12 8 15 } weigh-crate .
! => 35
```

## 2. マニフェスト全体を並行して量る

`weigh-all`を定義し、クレートの配列を受け取って、同じ順序でそれらの重量の配列を返すようにします。クレートごとの処理が並行して行われるように、`parallel-map`を使います。

```factor
{ { 5 5 } { 10 } { 3 4 5 } } weigh-all .
! => { 10 10 12 }
```

## 3. 新しいクレーンを組み立てる

`<crane>`を定義し、新しいクレーンを組み立てます。新しい`<lock>`とトン数`0`を持つタプルです。クレーンは、以降のタスクが保護する共有リソースです。

```factor
<crane> tonnage>> .
! => 0
```

## 4. クレートを巻き上げて累計に加える

`hoist-crate`を定義し、`weight`と`crane`を受け取って、**クレーンのロックの下で**クレーンのトン数に重量を加えます。こうすることで、他の作業員が同時に巻き上げても、読み取り・加算・書き込みがアトミックになります。

```factor
<crane>
35 over hoist-crate
17 over hoist-crate
tonnage>> .
! => 52
```

## 5. 累計のトン数を読み取る

`crane-tonnage`を定義し、クレーンの現在のトン数を返します。これもロックの下で行うので、巻き上げの途中で読み取りが壊れた値を見ることはありません。

```factor
<crane>
35 over hoist-crate
crane-tonnage .
! => 35
```

## 6. 貨物を積み込む

`load-cargo`を定義し、クレートの配列とクレーンを受け取って、**クレートごとに港湾作業員スレッドを生成**します。そのスレッドがクレートを量り、その重量をクレーンに巻き上げます。このワードは、すべての作業員が終了して初めて戻ります。合流を調整するには、`<promise>`と`?promise`を使います。

```factor
<crane> :> crane
{ { 5 5 } { 10 } { 3 4 5 } } crane load-cargo
crane crane-tonnage .
! => 32
```
