# 指示の補足

## トラック固有の指示

少し趣向を変えたいときは、`unfold`関数を使った解答も試してみてはいかがでしょうか。`foldLeft/Right`はもう知っているはずです。コレクション全体を別の何か（通常はコレクションではないもの）に「写像」するものでしたね。`unfold`はその「逆」の操作で、何か（通常はコレクションではないもの）をコレクションに「写像」します。そう考えると、`unfold`は理にかなった追加であり、関数型プログラミングの標準的な道具立ての一部でもあります。

この演習は、`unfold`する好例と言えます。`Int`を`String`に「写像」するわけです（`String`は言うまでもなく暗黙のうちに`Seq[Char]`です）。

Scalaのコレクションには2.13からこれが含まれています。たとえば[`List.unfold`][list]や`Iterator.unfold`です。開始状態と、次の要素と次の状態を返す関数を受け取ります。停止させたいときは`None`を返します。

```scala
List.unfold(1234)(n => Option.when(n > 0)((n % 10, n / 10)))
// List(4, 3, 2, 1)
```

[list]: https://www.scala-lang.org/api/current/scala/collection/immutable/List$.html
