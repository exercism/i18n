# はじめに

JavaScriptでは、`Array`クラスに、配列を変換するための強力な組み込みメソッドがたくさん用意されています。こうしたメソッドを使うと、単純な`for`ループやより直接的な操作で行うよりも、ずっと簡単に配列を別の配列へ変換できます。

メソッドの中には[_純粋_][pure-function-definition]なものもあり、元の配列を変更しません。その代わりに、新しい配列を返します。一方で、呼び出された配列自体を操作し、変更後の配列を返さ**ない**メソッドもあります。

配列を変換するためによく使われるメソッドの一部を、以下で紹介します。利用できるメソッドの一覧は、[MDNのドキュメント][array-methods]にあります。

### map（純粋）

引数として渡された関数に従って各要素を変換し、新しい配列を作ります。こうしたコールバック関数は、多くの場合[アロー関数][concept-arrow-functions]として書かれます。

```javascript
let arr = [1, 2, 3, 4];

const newArr = arr.map((value) => value - 1);
console.log(newArr);
// => [0, 1, 2, 3]
console.log(arr);
// => [1, 2, 3, 4]
```

結果として得られる配列は、常に元の配列と同じ長さになる点に注目してください。

### filter（純粋）

フィルタリング関数を渡すと、その関数（要素を残す場合は`true`、取り除く場合は`false`を返します）に従って現在の配列を絞り込み、新しい配列を作ります。

```javascript
let arr = [1, 2, 3, 4];

arr.filter((value) => value % 2 === 0);
// => [2, 4]
```

### reduce（純粋）

_アキュムレーター_と配列の現在の要素を引数にとる関数を使って、配列を単一の値にまとめます。この関数は、現在の要素をどのようにアキュムレーターへ統合するかを指示し、次の繰り返しで使われるアキュムレーターを返します。

```javascript
let arr = [1, 2, 3, 4];

// Get the sum of elements
arr.reduce((accumulator, currentValue) => accumulator + currentValue, 0);
// => 10

// Classify the numbers by whether they are odd or not
arr.reduce(
  (accumulator, currentValue) => {
    if (currentValue % 2 === 0) {
      accumulator.even.push(currentValue);
    } else {
      accumulator.odd.push(currentValue);
    }

    return accumulator;
  },
  { even: [], odd: [] },
);
// => { even: [2, 4], odd: [1, 3] }
```

### reverse

配列の要素を逆順に並べ替えます。

```javascript
const arr = [1, 2, 3, 4];

arr.reverse();
// => [4, 3, 2, 1]
```

このメソッドは、呼び出された配列自体を変更します。

### slice（純粋）

開始インデックスと終了インデックスを指定すると、呼び出された配列から部分配列を作ります。

終了インデックスにある要素は含まれません。
また、すべての入力は省略可能です。
開始インデックスの既定値は`0`、終了インデックスの既定値は配列の長さです。

```javascript
const arr = [1, 2, 3, 4];

arr.slice(1, 2); // [2]
arr.slice(1); // [2, 3, 4]
// You can also use negative numbers, that represent the indexes
// starting from the end of the array
arr.slice(-2); // [3, 4]
```

### splice

配列の要素を削除したり、置き換えたり、新しい要素を追加したりします。

次の入力を受け取ります。

- 配列の変更を開始する要素のインデックス
- 削除する要素の数
- 配列に挿入する要素（省略可能）

`splice`は、削除された要素を返します。

```javascript
const arr = ['1', '2', '5', '6'];

// Insert an element at index 2
arr.splice(2, 0, '3');
console.log(arr);
// => ['1', '2', '3', '5', '6']

// Remove 2 elements, starting at index 3 and insert 2 elements
const removed = arr.splice(3, 2, '4', '5');
console.log(removed);
// => ['5', '6']
console.log(arr);
// => ['1', '2', '3', '4', '5']

// Remove 1 element at index 1
arr.splice(1, 1);
console.log(arr);
// => ['1', '3', '4', '5']
```

### sort

既定では、`sort`はまず要素を文字列に変換し、それから文字列の比較を適用して、配列の要素を並べ替えます（[比較の概念][concept-comparison]を参照）。
並べ替えは_その場で_行われるため、元の配列が変更されます。
`sort`は変更後の配列も返すので、他のメソッドをつなげて呼び出したいときに便利です。

```javascript
const arr = ['c', 'a', 'z', 'b'];
const result = arr.sort();
console.log(result);
// => ['a', 'b', 'c', 'z']
console.log(arr);
// => ['a', 'b', 'c', 'z']
```

並べ替えの動作をカスタマイズしたい場合は、比較関数を引数として渡します。
この比較関数は、配列の2つの要素を引数として呼び出されます。
そして、次のいずれかを返す必要があります。

- 1つ目の引数を2つ目の引数より前に並べ替える場合は負の数
- 1つ目の引数を2つ目の引数より後に並べ替える場合は正の数
- 要素の順序を変えない場合は`0`

たとえば、数値を並べ替えるには、次の比較関数を使います。

```javascript
const arr = [3, 1, 2, 10];
arr.sort((a, b) => a - b);
// => [1, 2, 3, 10]
// "a - b" is negative when b is greater than a, positive when
// a is greater than b and 0 when they are equal.
```
