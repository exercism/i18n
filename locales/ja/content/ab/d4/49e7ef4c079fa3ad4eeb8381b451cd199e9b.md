# 説明

マジシャンの卵であるElyseは、基本をいくつか練習する必要があります。
彼女には、自由に操りたい山札があります。

少しでも簡単にするため、彼女は1から10のカードだけを使います。こうすると、山札は数値のベクトルで表せます。
あるカードの位置は、ベクトル内のインデックスに対応します。

## 1. 山札からカードを1枚取り出す

カードを1枚選ぶには、与えられた山札から、インデックス`position`にあるカードを返します。

```julia-repl
julia> stack = [1, 2, 4, 1];
julia> position = 3;
julia> get_item(stack, position)
4
```

## 2. 山札のカードを交換する

ちょっとした手品で、インデックス`position`にあるカードを、与えられた交換用のカードと入れ替えます。
入れ替えた後の山札を返します。

```julia-repl
julia> stack = [1, 2, 4, 1];
julia> position = 3;
julia> replacement_card = 6;
julia> set_item!(stack, position, replacement_card)
[1, 2, 6, 1]
```

## 3. 山札の一番上にカードを挿入する

山札の一番上に新しいカードを挿入して、カードを出現させます。
挿入した後の山札を返します。

```julia-repl
julia> stack = [5, 9, 7, 1];
julia> new_card = 8;
julia> insert_item_at_top!(stack, new_card)
[5, 9, 7, 1, 8]
```

## 4. 山札からカードを1枚取り除く

山札から、指定された`position`にあるカードを取り除いて、カードを消します。
取り除いた後の山札を返します。

```julia-repl
julia> stack = [3, 2, 6, 4, 8];
julia> position = 3;
julia> remove_item!(stack, position)
[3, 2, 4, 8]
```

## 5. 山札の一番上のカードを取り除く

山札の一番上にあるカードを取り除いて、カードを消します。
取り除いた後の山札を返します。

```julia-repl
julia> stack = [3, 2, 6, 4, 8];
julia> remove_item_from_top!(stack)
[3, 2, 6, 4]
```

## 6. 山札の一番下にカードを挿入する

山札の一番下に新しいカードを挿入して、カードを出現させます。
挿入した後の山札を返します。

```julia-repl
julia> stack = [5, 9, 7, 1];
julia> new_card = 8;
julia> insert_item_at_bottom!(stack, new_card)
[8, 5, 9, 7, 1]
```

## 7. 山札の一番下からカードを取り除く

山札の一番下にあるカードを取り除いて、カードを消します。
取り除いた後の山札を返します。

```julia-repl
julia> stack = [8, 5, 9, 7, 1];
julia> remove_item_at_bottom!(stack)
[5, 9, 7, 1]
```

## 8. 山札の枚数を確認する

山札の枚数が`stack_size`と同じかどうかを確認します。

```julia-repl
julia> stack = [3, 2, 6, 4, 8];
julia> stack_size = 4;
julia> check_size_of_stack(stack, stack_size)
false
```
