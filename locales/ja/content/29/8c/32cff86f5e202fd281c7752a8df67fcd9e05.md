# クラス

クラスは、PHPでコードを整理するための単位です。
あるものの振る舞いや、ある処理の振る舞いを表すコードは、クラスとしてまとめることができます。
クラスに属する関数は、慣習的に`methods`と呼ばれます。

```php
<?php

class Door
{
    function lock()
    {
        // ...
    }

    function unlock()
    {
        // ...
    }
}
```

クラスは`new`キーワードでインスタンス化します。これにより、そのクラスのインスタンス用のメモリが確保され、クラスのコンストラクターが呼び出されます。
インスタンス化したクラスは、変数に代入できます。
クラスのインスタンスのメソッドを呼び出すには、アクセス演算子`->`を使います。

```php
<?php

$a_door = new Door();
$a_door->lock();
$a_door->unlock();
```

インスタンス化されたクラスは、特別な変数`$this`を使って自分自身のインスタンスを参照できます。
クラスはプロパティを持つこともできます。プロパティは、そのクラスのオブジェクトのインスタンスに結び付いた変数として機能します。
これらのプロパティは、クラスの内部からも外部からも参照できます。

```php
<?php

class Car
{
    public $color;

    function __construct($color)
    {
        $this->color = $color;
    }

    function getColor()
    {
        return $this->color;
    }
}

$a_car = new Car("red");
$a_car->color; // => "red" by accessing the property
$a_car->getColor(); // => "red" by invoking the instance method
```
