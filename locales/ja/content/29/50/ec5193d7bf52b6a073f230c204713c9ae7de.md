# 束縛ルーチン

ここまでは、*値*を受け渡してきました。数値、文字列、オブジェクトなどです。**束縛ルーチン**を使えば、ルーチンそのものを受け渡せます。あとになって、それが何なのかを知らないコードから呼び出してもらうためです。

代役はまさにこの考え方そのものです。舞台監督は、それが誰なのか、何をするのかを知らないまま、その役を演じる手段を手にしています。

## 作り方

`bind`は、穴の空いた呼び出しを受け取ります。穴は`_`と書きます。

```sather
   shout(line : STR) : STR is return line.upper; end;

   ...

   part ::= bind(shout(_));
```

`part`はこれで、ほかの値と同じように扱える値になりました。呼び出すのは、あとになってからです。

```sather
   part.call("who's there")      -- "WHO'S THERE"
```

## 型

束縛ルーチンの型は`ROUT`です。波括弧の中に引数の型を書き、コロンのあとに戻り値の型を書きます。

```sather
   part : ROUT{STR}:STR := bind(shout(_));
```

`ROUT{STR}:STR`は『`STR`を受け取って`STR`を返すルーチン』と読みます。

| 表記 | 意味 |
| --- | --- |
| `ROUT{STR}:STR` | `STR`を受け取り、`STR`を返す |
| `ROUT{INT,INT}:BOOL` | 2つの`INT`を受け取り、`BOOL`を返す |
| `ROUT{STR}` | `STR`を受け取り、何も返さない |
| `ROUT:INT` | 何も受け取らず、`INT`を返す |

型なので、引数にもなれます。

```sather
   rehearse(line : STR, part : ROUT{STR}:STR) : STR is
      return part.call(line);
   end;
```

`rehearse`は、`part`が何をするのか一切知りません。そこが要点です。`shout`でも、`whisper`でも、同じ形をしたものなら何でも渡せます。

## 引数の一部を埋める

すべての引数を穴にする必要はありません。そのまま書き出したものは、束縛した時点で固定されます。

```sather
   repeat(times : INT, line : STR) : STR is ... end;

   twice ::= bind(repeat(2, _));      -- ROUT{STR}:STR
```

`twice`が受け取るのは行だけです。`2`はすでに決まっているからです。値は束縛した時点で計算されて保持されるので、あとから元の変数を変えても何も変わりません。

こうして、1つの汎用的なルーチンから、たくさんの具体的なルーチンが生まれます。

## オブジェクトも束縛する

オブジェクトのルーチンの場合、そのオブジェクトは呼び出しの最初に置くものなので、固定することも、穴のままにしておくこともできます。

```sather
   bind(board.home_goal)      -- this board's, always
   bind(_.home_goal)          -- whichever board is handed in later
```
