# 説明

この演習では、さまざまな種類のラジコンカーのレースを組み立てていきます。それぞれの車には、速度とバッテリー消費の特性があります。

車は満充電（100%）のバッテリーでスタートします。ラジコンで車を走らせるたびに、車は速度の分だけメートル進み、バッテリー残量はバッテリー消費の割合だけ減ります。

車のバッテリーがバッテリー消費の割合を下回ると、その車はもう走らせられません。

それぞれのレースコースには距離があります。車のテストでは、バッテリーを切らすことなくコースを完走できるかどうかを確認します。

タスクは6つあり、それぞれでラジコンカーのインスタンスを扱います。

## 1. ラジコンカーを作成する

`NeedForSpeed`クラスのコンストラクターを定義して、ラジコンカーを作成できるようにしましょう。このコンストラクターは、車の速度（メートル）とバッテリー消費の割合を2つのパラメーターとして受け取ります（どちらも`int`型です）：

```java
int speed = 5;
int batteryDrain = 2;
var car = new NeedForSpeed(speed, batteryDrain);
```

## 2. レースコースを作成する

`RaceTrack`クラスのコンストラクターを定義して、レースコースを作成できるようにしましょう。このコンストラクターは、コースの距離（メートル）を唯一のパラメーターとして受け取ります（`int`型です）：

```java
int distance = 800;
var raceTrack = new RaceTrack(distance);
```

## 3. 車を走らせる

`NeedForSpeed.drive()`メソッドを実装して、車の速度に応じて走行距離を更新します。また、`NeedForSpeed.distanceDriven()`メソッドを実装して、車が走った距離を返すようにします：

```java
int speed = 5;
int batteryDrain = 2;
var car = new NeedForSpeed(speed, batteryDrain);
car.drive();

car.distanceDriven();
// => 5
```

## 4. バッテリー切れを確認する

`NeedForSpeed.drive()`メソッドを更新して、車のバッテリー消費に応じてバッテリーを減らします。また、`NeedForSpeed.batteryDrained()`メソッドを実装して、バッテリーが減りすぎて走れないかどうかを示すようにします：

```java
int speed = 5;
int batteryDrain = 2;
var car = new NeedForSpeed(speed, batteryDrain);
car.drive();

car.batteryDrained();
// => false
```

## 5. ニトロのラジコンカーを作成する

一番の売れ筋はNitroというラジコンカーで、最高速度は50メートル、バッテリー消費は4%です。`static`な`NeedForSpeed.nitro()`メソッドを実装して、このタイプの車を返すようにします：

```java
var car = NeedForSpeed.nitro();
car.drive();
car.distanceDriven();
// => 50
```

## 6. ラジコンカーがレースを完走できるか確認する

レースを完走するには、車がコースの距離を走りきれる必要があります。つまり、ゴールラインを越える前にバッテリーを使い切らないということです。`RaceTrack.canFinishRace()`メソッドを実装します。このメソッドは`NeedForSpeed`のインスタンスをパラメーターとして受け取り、車がレースを完走できるなら`true`を、そうでなければ`false`を返します：

```java
int speed = 5;
int batteryDrain = 2;
var car = new NeedForSpeed(speed, batteryDrain);

int distance1 = 100;
var race1 = new RaceTrack(distance1);

int distance2 = 300;
var race2 = new RaceTrack(distance2);

race1.canFinishRace(car);
// => true

race2.canFinishRace(car);
// => false
```
