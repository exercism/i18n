# 指示の補足

## 実装

Forthでは、関数は`words`と呼ばれ、データスタック上で動作します。
各ワードはスタックから入力を受け取り、結果をスタックに返します。

Forthのドキュメントでは、ワードを実行する前と実行した後のデータスタックの状態を、常に`( p1 p2 ... pN --- r1 r2 ... rN )`のように表記します。
`p1`から`pN`は、呼び出し前にスタックにあるワードの入力を表し（スタックのさらに下のほうには、ここには示していないデータが残っていることもあります）、`r1`から`rN`は、呼び出し後にスタックにあるワードの戻り値を表します。
区切りの`---`は、ワードを実行する前と後でスタックの状態がどう変わるかを示しています。

実装するワードは、次のとおりです。

- ToSはスタックの先頭（Top of Stack）のことです
- スタックの先頭は、一番右の値として表します

| ワード   | スタックの状態             | 説明                          |
| ------ | ----------------------- | ------------------------------------ |
| `+`    | `( a b --- sum )`       | `sum = a + b`                        |
| `-`    | `( a b --- diff )`      | `diff = a - b`                       |
| `*`    | `( a b --- prod )`      | `prod = a * b`                       |
| `/`    | `( a b --- quot )`      | `quot = a / b`                       |
| `dup`  | `( a --- a a )`         | ToSの値を複製します       |
| `drop` | `( a --- )`             | ToSの値を取り除きます            |
| `swap` | `( a b --- b a )`       | ToSの2つの値を入れ替えます       |
| `over`  | `( a b c --- a b c b )` | 2番目の値をToSにコピーします |

オンラインのForthインタプリターで遊んでみたい方や、実装するワードについてもっと知りたい方は、[Easy Forth][easy-forth]を試してみてください（特にAdding Some Numbers、Defining Words、Stack Manipulationのセクションです）。

[easy-forth]: https://skilldrick.github.io/easyforth/
