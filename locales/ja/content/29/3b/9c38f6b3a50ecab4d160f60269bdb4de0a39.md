# `for-each`ループについて

[`for-each`ループ](https://docs.oracle.com/javase/tutorial/java/nutsandbolts/for.html)を使うと、コレクションの各要素に対してコードのブロックを実行できます。
ドキュメントによっては（例えばOracleのドキュメントなど）、これを拡張`for`ループと呼んでいます。

一般的な構文は次のとおりです。

```java
for(declaration: collection) {
    body;
}
```

`declaration`は、コレクションから取り出した値を受け取る変数を宣言します。

`collection`は、ループ変数に代入される値を保持する配列またはコレクションです。

`body`には、コレクション内の各値に対して1回ずつ実行される文を書きます。

例えば、次のようになります。

```java
char[] vowels = {'a', 'e', 'i', 'o', 'u'};

for(char vowel: vowels) {
    System.out.println(vowel);
}
```

これを実行すると、次のように出力されます。

```text
a
e
i
o
u
```

一般に、`for-each`ループは次の理由から`for`ループよりも好まれます。

- `for-each`ループは、_すべての_値に対して繰り返し処理を行うことが保証されています。
- `for-each`ループはより_宣言的_で、コードが_どのように_行うかではなく_何を_行うかを伝えてくれます。
- `for-each`ループは間違いが起きにくいのに対し、`for`ループではオフバイワンエラーが起こりがちです（`<`と`<=`のどちらを使うかを考えてみてください）。
- `for-each`ループは、インデックスを使って要素にアクセスできないものを含め、すべてのコレクション型で使えます（例えば`Set`）。
