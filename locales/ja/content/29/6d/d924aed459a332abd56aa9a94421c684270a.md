# テスト

## テストの実行

テストを実行するには、次のコマンドを実行します：

```bash
bats test-<exercise-slug>.bats
```

### batsはbashで実装されています

batsファイルはbashスクリプトで、`bats`コマンドが認識するいくつかの特別な関数を含んでいます。
次のようなテストがあります：

```bash
sed -E -f <exercise-slug>.sed <<< "$input"
```

この`<<<`構文はbashの*Here String*です。
右辺の文字列を、左辺のプログラムの標準入力に送り込みます。
これは、ほぼ次と同じです：

```bash
echo "$input" | sed -E -f <exercise-slug>.sed
```

## スキップされるテスト

演習を解くということは、そのすべてのテストに合格させることを意味します。
デフォルトでは、テストを実行すると1つのテスト（最初のテスト）だけが実行されます。
これは意図的なもので、まずはその1つのテストに合格させることに集中できるようになっています。
合格したら、他のテストの前に付いている

    [[ $BATS_RUN_SKIPPED == true ]] || skip

というアノテーションをコメントアウトするか削除すると、次のテストを有効にできます。

## スキップを上書きする

`skip`アノテーションが付いたものも含め、すべてのテストを実行するには、次のようにします：

```bash
BATS_RUN_SKIPPED=true bats test-<exercise-slug>.bats
```

または、テストファイルから次の行をコメントアウトするか削除します：

```bash
[[ $BATS_RUN_SKIPPED == "true" ]] || skip
```
