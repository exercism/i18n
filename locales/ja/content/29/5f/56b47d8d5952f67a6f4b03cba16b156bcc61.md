# 概要

F#の文字列は、Unicode文字（英字、数字、記号など）の並びでテキストを表すイミュータブルなオブジェクトです。`string`のインスタンスを定義するには、二重引用符（`"`）を使います。

```fsharp
let fruit = "Apple"
```

文字列を操作するには、その[メソッド][methods]や[プロパティ][properties]を呼び出すか、[`String`モジュール][string-module]の関数を使います。文字列の値は一度定義すると変わることはないため、文字列を操作するメソッドや関数は、すべて新しい文字列を返します。

文字列は、二重引用符（`"`）で区切られます。特別な文字の中には、バックスラッシュ（`\`）を使って[エスケープ][escaping]する必要があるものがあります。また、文字列の先頭にアットマーク（`@`）を付けると、[verbatim文字列][verbatim]になり、エスケープ文字がすべて無視されます。

```fsharp
let escaped = "c:\\test.txt"
let verbatim = @"c:\test.txt"
escaped = verbatim
// => true
```

別の方法として、[三重引用符][triple-quoted]（`"""`）を使えば、文字列を定義することもできます。この方法なら、文字列内の二重引用符をエスケープせずに使えます。

```fsharp
let tripledQuoted = """<movie title="Se7en" />"""
// => "<movie title="Se7en" />
```

最後に、文字列の連結は、[`+`演算子][plus-operator]で行えます。

```fsharp
let name = "Jane"
"Hello " + name + "!"
// => "Hello Jane!"
```
