# はじめに

他の言語と同じように、C++にも`switch`文があります。
`switch`文は、長い`if ... else if`文を短く書く方法です。
switch文を作るには、まず`switch`というキーワードの後に整数を書きます。
次に、それぞれの条件を`case`キーワードで宣言します。
また、`default`ケースを宣言することもできます。これは、前の`case`条件のどれにも一致しないときに実行されます。
各ケースは、`break`（または`return`）文で終わる必要があります。

```cpp
int price{0};
int adults{3};
int kids{2};

switch (int group_size{adults + kids}) {
    case 1:
        price = 50;
        break;
    case 2:
        price = 70;
        break;
    default:
        price = group_size * 30;
}
```

## フォールスルー

switch構文について重要なことの1つは、コードが`break`（または`return`）文で止められるまで実行され続けることです。
これにより、予期しない動作が起こることがあります。

```cpp
int adults{1};
int kids{0};
switch (int group_size{adults + kids}) {
    case 1:
        price = 50;
    case 2:
        price = 70;
    default:
        price = group_size * 30;
}
// price will be 30!
```

このフォールスルー機能の主な用途は、複数のラベルを持つ文です。
複数のswitchの結果を、実行する同じコードに対応付けることができます。
こうすると、たとえば予約アプリでは、グループサイズ2と3に対して呼び出される関数を同じにできます：
```cpp
switch (group_size) {
case 1:
    book_room();
    break;
case 2:
case 3:
    book_apartment(group_size);
    break;
default:
    book_house(group_size);
}
// book_apartment happens when group_size is 2 or 3
```
