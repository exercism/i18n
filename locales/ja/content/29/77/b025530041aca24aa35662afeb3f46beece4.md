# 説明の補足

## ヒント

数値を雨粒の音に変換して返す`convert`関数を実装する必要があります。型について自信がなければ、用意されているシグネチャを使ってもかまいませんが、それによって自由な発想が制限されないようにしましょう。

```haskell
convert :: Int -> String
```

この演習ではテキストデータを扱います。歴史的な理由から、Haskellの`String`型は文字のリストである`[Char]`と同義です。テキストデータをより効率よく扱うには、`Text`型を使うこともできます。

この演習の任意の拡張として、次のことができます。

- Haskellの[文字列型](https://haskell-lang.org/tutorial/string-types)について読んでみましょう。
- package.yamlの依存関係のリストに`- text`を追加しましょう。
- `Data.Text`を[次のように](https://hackernoon.com/4-steps-to-a-better-imports-list-in-haskell-43a3d868273c)インポートしましょう。

```haskell
import qualified Data.Text as T
import           Data.Text (Text)
```

- これで、たとえば`convert :: Int -> Text`と書いたり、`Data.Text`のコンビネーターを`T.pack`のように参照したりできます。
- [`Data.Text`](https://hackage.haskell.org/package/text/docs/Data-Text.html)のドキュメントを調べましょう。
- その後、Raindrops.hs内の`String`をすべて`Text`に置き換えられます。

```haskell
convert :: Int -> Text
```

この部分は完全に任意です。
