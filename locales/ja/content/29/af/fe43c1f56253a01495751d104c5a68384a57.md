# 繰り返し

プログラミングでは、[繰り返し][iteration]とは、コードのブロックを何度も繰り返す処理のことです。
これは、`while`ループや`until`ループといった仕組みを使うことで実現できます。
自分自身を呼び出す関数である再帰を使うことでもできます。

しかし、たいていの場合は、`Array`、`Range`、`String`のようなコレクションを繰り返し処理したいはずです。
Crystalの`Array`クラスと`Range`クラスはどちらも[`Enumerable`][enumerable]モジュールをインクルードしており、このモジュールには要素を繰り返し処理するためのメソッドが多数用意されています。
一方、`String`クラスには、文字を繰り返し処理するための独自のメソッドがあります。

また、Crystalには他の言語にあるような`for`文がありません。
その代わりに、繰り返し処理に使えるメソッドがいくつか用意されています。

## 繰り返し処理

コレクションを繰り返し処理する最も一般的な方法は、[`each`][each]メソッドを使うことです。このメソッドは、コレクションの各要素をブロックに渡します。
これは`Range`を使えば簡単にできます。
たとえば、1から3まで繰り返したいときは、`each`メソッドを使ってその範囲を繰り返し処理できます。

```crystal
(1..3).each do |n|
  puts n
end

# Output:
# 1
# 2
# 3
```

もっと簡単に、決まった回数だけ繰り返したいだけであれば、`Int`クラスにある[`times`][times]メソッドを使えます。

```crystal
3.times do |n|
  puts n
end

# Output:
# 0
# 1
# 2
```

## `String`の繰り返し処理

`String`は文字の並びであり、`Enumerable`モジュールには含まれていません。そのため、文字を繰り返し処理するための独自のメソッドを持っています。
`String`を繰り返し処理する最も一般的な方法は、[`each_char`][each_char]メソッドを使うことです。このメソッドは、`String`の各文字をブロックに渡します。

~~~~exercism/note
`each_char`メソッドがブロックに渡すのは、`String`オブジェクトではなく`Char`オブジェクトです。
~~~~

```crystal
str = "hello"
str.each_char { |char| puts char }

# Output:
# h
# e
# l
# l
# o
```

`String`を繰り返し処理するもう一つの方法は、[`each_line`][each_line]メソッドを使うことです。
このメソッドは、ファイルを1行ずつ読み込むときによく使われます。

```crystal
str = "hello\nworld"
str.each_line do |line|
  puts line
end

# Output:
# hello
# world
```

## `Enumerable`モジュールをインクルードしたオブジェクトの繰り返し処理

[`Enumerable`][enumerable]モジュールには、コレクションの要素を繰り返し処理するためのメソッドが多数用意されています。
`Enumerable`モジュールをインクルードしているコレクションには、`Array`、`Range`、`Hash`、`Set`などがあります。後者については、後の概念で扱います。

`Array`を繰り返し処理する最も一般的な方法は、[`each`][each]メソッドを使うことです。このメソッドは、`Array`の各要素をブロックに渡します。

```crystal
arr = [5, 2, 3]
arr.each do |element|
  puts element
end

# Output:
# 5
# 2
# 3
```

### `map`

[`map`][map]メソッドも`Array`を繰り返し処理する方法の一つで、各要素にブロックを適用した結果を含む新しい`Array`を返します。
`each`メソッドに似ていますが、変換後の要素を持つ新しい`Array`を返します。
変換は、コレクションの各要素に関数を適用したいときに非常に便利で、よく行われる操作です。

```crystal
arr = [1, 2, 3]
new_arr = arr.map do |element|
  element * 2
end

new_arr
# => [2, 4, 6]
```

`if`のような制御フローを使えば、どの要素を変換するかを絞り込むこともできます。

```crystal
arr = [1, 2, 3]
new_arr = arr.map do |element|
  if element.odd?
    element * 2
  else
    element
  end
end

new_arr
# => [2, 2, 6]
```

### インデックス付き

繰り返し処理している要素のインデックスを知りたいことがあります。その場合は、[`each_with_index`][each_with_index]メソッドや[`map_with_index`][map_with_index]メソッドを使います。
これらのメソッドは、各要素とそのインデックスをブロックに渡します。また、開始インデックスを指定するための省略可能な引数も受け取ります。

```crystal
arr = [1, 2, 3]
arr.each_with_index(4) do |element, index|
  puts "Element: #{element}, Index: #{index}"
end

# Output:
# Element: 1, Index: 4
# Element: 2, Index: 5
# Element: 3, Index: 6
```

なお、`String`オブジェクトには[`each_char_with_index`][each_char_with_index]メソッドも使えます。

### `sum`

[`sum`][sum]メソッドは、コレクション内のすべての要素の合計を返します。また、合計する前に要素を変換するための省略可能なブロックも受け取ります。
さらに、合計の初期値を指定するための省略可能な引数も受け取ります。

```crystal
arr = [1, 2, 3]
arr.sum
# => 6

arr.sum(2) { |n| n * 2 }
# => 14
```

### `reduce`

[`reduce`][reduce]（他の言語ではfoldとして知られています）は、結合する方法と初期値を与えると、コレクション内のすべての要素を結合するメソッドです。
`reduce`メソッドには、ブロックに渡されるアキュムレーターがあります。アキュムレーターは、前回の繰り返しの結果です。
これは再帰的な処理になり、コレクション内のすべての要素を結合します。

```crystal
arr = [1, 2, 3]
arr.reduce(0) do |acc, n|
  acc + n
end
# => 6
```

`reduce`は`sum`に似ているように見えるかもしれませんが、アキュムレーターの初期値と結合方法を指定できるため、`reduce`のほうが柔軟です。
`reduce`を使って、`sum`や`count`などのメソッドを実装できます。
