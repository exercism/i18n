# はじめに

## 関数

Gleamでは、関数を定義するには`pub fn`という構文を使います。

```gleam
pub fn add(x: Int, y: Int) -> Int {
  x + y
}
```

この関数は2つの入力を受け取り、どちらも`Int`型で、`Int`型の値を返します。Gleamには`return`キーワードはありません。関数の最後の式の値が、常に_暗黙的に戻り値として返されます_。

入力と戻り値の型注釈は省略できます。Gleamは常にコードの型チェックを完全に行います。通常、Gleamプログラマーは明確さのために型注釈を付けますが、省略したい場合は省いてもかまいません。

```gleam
pub fn add(x, y) {
  x + y
}
```

関数は`function_name(argument1, argument2)`という構文で呼び出せます。

```gleam
pub fn double(x: Int) -> Int {
  // Call the add function defined above
  add(x, x)
}
```

## 変数

Gleamでは、変数を定義するには`let name = expression`という構文を使います。

```gleam
pub fn main() {
  let count = 1
}
```

変数は型注釈を付けて宣言することもできます。関数の入力と同様、これは省略可能ですが、簡潔にするため、ほとんどのGleamプログラマーは変数の型注釈を省略します。

```gleam
pub fn main() {
  let count: Int = 1
}
```

## 文字列リテラル

Gleamでは、文字列は二重引用符で書きます。

```gleam
pub fn greeting() {
  "Hello, world!"
}
```

## コードのコメント

コメントを使うと、ソースコードを読む他のエンジニアに向けてメモを残せます。Gleamのコメントは、`//`で始まる1行のコメントです。

```gleam
pub fn main() {
  // This is a comment
  let x = 1
}
```
