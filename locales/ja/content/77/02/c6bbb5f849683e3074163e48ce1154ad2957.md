# 説明

[Luhnの公式][luhn]に従って、ある数値が有効かどうかを判定します。

数値は文字列として渡されます。

## 数値の検証

長さが1以下の文字列は有効ではありません。
入力にはスペースを含めることができますが、検証の前に取り除く必要があります。
その他の数字以外の文字はすべて許可されません。

## 例

### 有効なクレジットカード番号

検証する数値は`4539 3195 0343 6467`です。

Luhnアルゴリズムの最初のステップでは、数値の末尾から始めて、右から2番目の数字から左に向かって、1つおきに数字を2倍にします。

```text
4539 3195 0343 6467
↑ ↑  ↑ ↑  ↑ ↑  ↑ ↑  (double these)
```

数字を2倍にした結果が9より大きい場合は、その結果から9を引きます。
すると、次のようになります。

```text
8569 6195 0383 3437
```

最後に、すべての数字を合計します。
合計が10で割り切れる場合、元の数値は有効です。

```text
8 + 5 + 6 + 9 + 6 + 1 + 9 + 5 + 0 + 3 + 8 + 3 + 3 + 4 + 3 + 7 = 80
```

80は10で割り切れるので、`4539 3195 0343 6467`は有効です！

### 無効なカナダのSIN

検証する数値は`066 123 478`です。

数値の末尾から始めて、右から2番目の数字から左に向かって、1つおきに数字を2倍にします。

```text
066 123 478
 ↑  ↑ ↑  ↑  (double these)
```

数字を2倍にした結果が9より大きい場合は、その結果から9を引きます。
すると、次のようになります。

```text
036 226 458
```

数字を合計します。

```text
0 + 3 + 6 + 2 + 2 + 6 + 4 + 5 + 8 = 36
```

36は10で割り切れないので、`066 123 478`は有効ではありません！
