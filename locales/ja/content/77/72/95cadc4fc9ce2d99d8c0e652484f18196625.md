# 説明

友人のChandlerは、世界中のエキゾチックな国々を訪れる計画を立てています。残念ながら、Chandlerは計算が得意ではありません。旅行中に両替でだまされてしまうのではないかとかなり心配していて、あなたに通貨計算機を作ってほしいと考えています。

## 1. 両替後の価値を見積もる

`exchange-money`を定義しましょう。`budget`と`exchange-rate`を受け取り、両替後の通貨の価値を返します。

**注意:** 通貨がUSDで、為替レート`1.20`でUSDをEURに両替する場合、`1.20 USD == 1 EUR`になります。

```factor
127.5 1.2 exchange-money .
! => 106.25
```

## 2. 両替後に残る金額を計算する

`get-change`を定義しましょう。`budget`（両替前）と`exchanging-value`（両替のために予算から取り分ける金額）を受け取り、残った金額を返します。

```factor
127.5 120 get-change .
! => 7.5
```

## 3. 紙幣の価値を計算する

`value-of-bills`を定義しましょう。`denomination`（紙幣1枚の価値）と`number-of-bills`を受け取り、紙幣の合計金額を返します。

```factor
5 128 value-of-bills .
! => 640
```

## 4. 紙幣の枚数を計算する

`number-of-bills`を定義しましょう。`amount`と`denomination`を受け取り、その金額に収まる、指定された額面の*丸ごとの紙幣*の枚数を返します。切り捨てます。半端な紙幣は存在しないからです。

```factor
127.5 5 number-of-bills .
! => 25
```

## 5. 紙幣に両替した後の余りを計算する

`leftover-of-bills`を定義しましょう。`amount`と`denomination`を受け取り、丸ごとの紙幣として返せない余りの金額を返します。

```factor
127.5 20 leftover-of-bills .
! => 7.5
```

## 6. 両替後の価値を計算する

`exchangeable-value`を定義しましょう。`denomination`、`budget`、`spread`、`exchange-rate`を受け取ります。

`spread`は、両替手数料として取られる*割合*で、整数で表します。これは為替レートに小数として足す必要があります。`1.00 EUR == 1.20 USD`でスプレッドが`10`なら、合計の為替レートは`1.00 EUR == 1.32 USD`になります（1.20の10%は0.12で、これを1.20に足したものです）。

レートにスプレッドを加えたものを適用した後の新しい通貨の最大値を、指定された`denomination`の丸ごとの紙幣に切り捨てて返します。戻り値は整数です。

```factor
20 127.25 10 1.20 exchangeable-value .
! => 80

5 127.25 10 1.20 exchangeable-value .
! => 95
```

## 7. 安全なお釣り

`get-change`と似ていますが、Chandlerが誤って予算より大きい両替額を入力してしまった場合は、負の数ではなく`0`を返します。`safe-change`を定義しましょう。`budget`と`exchanging-value`を受け取ります。

```factor
127.5 120 safe-change .
! => 7.5

50 100 safe-change .
! => 0
```

## 8. 予算による上限

Chandlerはお土産の値段を交渉しています。`cap-spend`を定義しましょう。`budget`と`price`を受け取り、小さいほうを返します。それが実際に支払える上限です。

```factor
100 30 cap-spend .
! => 30

20 30 cap-spend .
! => 20
```
