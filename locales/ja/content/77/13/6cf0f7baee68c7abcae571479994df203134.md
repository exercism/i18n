# 指示

1から31までの数値を、秘密のハンドシェイクの一連の動作に変換するのがこの演習のタスクです。

動作の並びは、数値を2進数に変換したあと、右端の5桁を見て決まります。右端の桁から始めて、左へ進みます。

それぞれの位に対応する動作は次のとおりです。

```plaintext
00001 = wink
00010 = double blink
00100 = close your eyes
01000 = jump
10000 = Reverse the order of the operations in the secret handshake.
```

例として、数値`9`を使ってみましょう。

- 9を2進数にすると`1001`です。
- いちばん右の桁は1なので、最初の動作は`wink`です。
- 左に進むと、次の桁は0なので、double blinkはありません。
- さらに左に進むと、次の桁は0なので、目は開いたままです。
- もう一度左に進むと、次の桁は1なので、ジャンプします。

これで最後の桁まで見たので、最終的なコードは次のとおりです。

```plaintext
wink, jump
```

26という数値は2進数で`11010`なので、次の動作になります。

- double blink
- jump
- reverse actions

したがって、26の秘密のハンドシェイクは次のとおりです。

```plaintext
jump, double blink
```
