# ヒント

## 全般

- [`roc-random`パッケージ](https://github.com/kili-ilo/roc-random)は、テストアプリで`random`というエイリアスで利用できます。
  スタブは`random.Random`をインポートします。

- `Random.Generator(a)`は、型`a`の値を生成する方法を表します。

- 複数の乱数生成を組み合わせるには`Random.list`を、その結果を変換するには`Random.map`を使います。

- `Random.step(state, generator)`は`{ value, state }`を返します。同じサンプルを繰り返さないように、シミュレーションするグループ間では更新された状態を引き継ぎましょう。
