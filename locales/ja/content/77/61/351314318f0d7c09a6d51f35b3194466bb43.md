# 手順

この演習では、妹が学校の作文を編集するのを手伝います。先生は、正しい句読点と文法、そして優れた言葉選びを求めています。

文字列を整えて修正するタスクが4つあります。

## 1. 作文のタイトルを大文字にする

よい作文には、きちんと整ったタイトルが必要です。
タイトル`str`を仮引数として受け取り、各単語の最初の文字を大文字にする関数`capitalize_title(<title>)`を実装してください。
この関数は、タイトルケースにした`str`を返すようにします。


```python
>>> capitalize_title("my hobbies")
"My Hobbies"
```

## 2. 各文がピリオドで終わっているか確認する

作文の句読点が完璧かどうかを確かめたいですね。
`sentence`を仮引数として受け取る関数`check_sentence_ending()`を実装してください。この関数は`bool`を返すようにします。


```python
>>> check_sentence_ending("I like to hike, bake, and read.")
True
```

## 3. 空白を整える

作文をプロらしく見せるには、不要な空白を取り除く必要があります。
`sentence`を仮引数として受け取る関数`clean_up_spacing()`を実装してください。
この関数は、文の先頭と末尾にある余分な空白を取り除き、更新された新しい文の`str`を返すようにします。


```python
>>> clean_up_spacing(" I like to go on hikes with my dog.  ")
"I like to go on hikes with my dog."
```

## 4. 単語を類義語に置き換える

作文を_さらに良くする_ために、一部の形容詞を類義語に置き換えることができます。
`sentence`、`old_word`、`new_word`を仮引数として受け取る関数`replace_word_choice()`を書いてください。
この関数は、`old_word`をすべて`new_word`に置き換え、更新された文の新しい`str`を返すようにします。


```python
>>> replace_word_choice("I bake good cakes.", "good", "amazing")
"I bake amazing cakes."
```
