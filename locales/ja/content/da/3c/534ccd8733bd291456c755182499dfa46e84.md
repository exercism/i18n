# はじめに

Cairoの関数を使うと、コードを再利用できるひとつのまとまりにでき、プログラムをよりモジュール化して、わかりやすくできます。
Cairoの関数は、`fn`キーワード、関数名、括弧（`()`）で囲んだ仮引数のリスト、そして関数が何をするかを定義するコードブロックで構成されます。

## 関数の仮引数

Cairoでは、関数の仮引数にはすべて明示的に型を指定する必要があります。
一部の言語とは異なり、Cairoは型を推論しませんし、仮引数のデフォルト値もないため、すべての仮引数が必須です。

```rust
// Function with no parameters
fn print_hello() {
    // Function body
}

// Function with two parameters
fn print_greeting_name(greeting: ByteArray, name: ByteArray) {
    // Function body
}
```

## 仮引数と引数

`parameters`と`arguments`は区別することが大切です。

- **仮引数**とは、関数の定義で使われる変数名のことで、たとえば関数`print_greeting_name`における`greeting`と`name`がこれにあたります。
- **引数**とは、関数を呼び出すときに実際に渡される値のことです。

```rust
// Calling the function with arguments
print_greeting_name(123, 456)
```

## 文と式

関数の本体は、一連の文からなり、その最後に式を置くこともできます。

- 文は、何らかの処理を行う命令で、値を返しません。
- 式は、評価されて何らかの値になります。

`let`キーワードで変数を作り、値を代入するのは文です。

```rust
let y = 6;
```

ただし、上の文の中の`6`は式で、評価すると値`6`になります。

関数の呼び出しは式です。呼び出しは必ず何らかの値に評価されるからです。その値は、指定されていれば関数の明示的な戻り値、そうでなければ「ユニット」型の`()`です。

## 戻り値

Cairoの関数は、呼び出し元のコードに値を返すことができます。
戻り値は、仮引数のあとに、矢印`->`で区切って書きます。
Cairoでは、関数の戻り値は、関数本体のブロックの最後の式の値と同じです。
`return`キーワードを使って値を指定すれば、関数の途中で戻ることもできます。

```rust
// Function returning the last (and only) expression
fn hello(name: ByteArray) -> ByteArray {
    "Hello " + name
}

// Function returning using the `return` keyword
fn double_if_even(value: u32) -> u32 {
    if value % 2 == 0 {
        return value * 2;
    }
    return value;
}
```

## 関数の呼び出し

Cairoで関数を呼び出すには、関数名のあとに括弧で囲んだ引数を書くだけです。

```rust
// Calling a function with no parameters
print_hello()

// Calling a function with one parameter
let greeting = hello("John")

// Calling a function with multiple parameters
print_greeting_name("Howdy", "Joel")
```
