# 説明

この演習では、お気に入りの料理本に載っている絶品ラザニアの準備と調理に関するコードをもう少し書いていきます。

4つのタスクがあります。
最初のタスクは調理そのものに関係し、残りの3つは完璧な準備に関するものです。

## 1. 準備時間を見積もる

次に準備するラザニアのために、調理を楽しめるように、十分な時間を確保しておきたいですね。
ラザニアにどの層を入れるかはもう決めてあります。
そこで、それをもとに準備にどれくらい時間がかかるかを見積もりたくなります。

層のスライスを`[]string`として、1層あたりの平均準備時間（分）を`int`として受け取る関数`PreparationTime`を実装します。
この関数は、層の数に基づく総準備時間の見積もりを`int`として返します。
Goの関数にはデフォルト値がありません。
平均準備時間として`0`（`int`のデフォルトの初期値）が渡された場合は、デフォルト値の`2`を使います。

```go
layers := []string{"sauce", "noodles", "sauce", "meat", "mozzarella", "noodles"}
PreparationTime(layers, 3)
// => 18
PreparationTime(layers, 0)
// => 12
```

## 2. 必要な麺とソースの量を計算する

時間を確保するだけでなく、夢のラザニアを作るのに十分なソースと麺があることも確認したいですね。
ラザニアの麺の層ごとに、50グラムの麺が必要です。
ソースの層ごとに、0.2リットルのソースが必要です。

層のスライスを`[]string`の入力として受け取る関数`Quantities`を定義します。
この関数は、食事を作るのに必要な麺とソースの量を求めます。
結果は、`noodles`を`int`、`sauce`を`float64`とした2つの値として返します。

```go
Quantities([]string{"sauce", "noodles", "sauce", "meat", "mozzarella", "noodles"})
// => 100, 0.4
```

## 3. 秘密の材料を加える

少し前、友人の家を訪ねてラザニアを食べました。
それは素晴らしく、何か特別なものがありました。
友人は材料のリストを送ってくれて、リストの最後の項目が、その料理を特別にした「秘密の材料」だと教えてくれました。
今度はその秘密の材料を自分のレシピにも加えたくなります。

`[]string`型の材料のスライスを2つ、入力として受け取る関数`AddSecretIngredient`を書きます。
1つ目の入力は友人が送ってくれたリストで、2つ目は自分のレシピの材料リストです。
自分の材料リストの最後の要素は常に`"?"`です。
この関数は、それを友人のリストの最後の項目で置き換えます。
**注意:**`AddSecretIngredient`は何も返しません。自分の材料リストを直接変更します。
友人の材料のリストは**変更してはいけません**。
また、`slice`はポインターとして関数に渡されるため、`AddSecretIngredient`に渡された2つの`[]string`引数への変更は直接反映されます。

```go
friendsList := []string{"noodles", "sauce", "mozzarella", "kampot pepper"}
myList := []string{"noodles", "meat", "sauce", "mozzarella","?"}

AddSecretIngredient(friendsList, myList)
// myList => []string{"noodles", "meat", "sauce", "mozzarella", "kampot pepper"}
```

## 4. レシピの分量を調整する

料理本に載っている分量では、ラザニアは2人分しかできません。
次はもっと多くの人のために料理したいので、人数に応じた分量を計算したくなります。

2つの入力を受け取る関数`ScaleRecipe`を実装します。

- 2人分に必要な`float64`の分量のスライス。
- 作りたい人数分。

この関数は、希望する人数分に必要な分量を`float64`のスライスとして返します。
ただし、元のレシピはそのままにしておきたいです。
つまり、この関数では`quantities`引数を変更してはいけません。

```go
quantities := []float64{ 1.2, 3.6, 10.5 }
scaledQuantities := ScaleRecipe(quantities, 4)
// => []float64{ 2.4, 7.2, 21 }
```
