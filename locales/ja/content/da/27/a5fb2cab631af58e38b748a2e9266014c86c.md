# 説明

この演習では、友人が開発中の新しいロールプレイングゲームに向けて、クエストのロジックを拡張していきます。
ゲームをもっと面白くするために、友人は状況を変えるランダムイベントを追加したいと考えています。

全体的な設定は前の演習から変わっていません。
新しいランダムイベントは、以下の文章で強調表示されています。

ゲームの主人公はアナリン。勇敢な少女で、獰猛で忠実な飼い犬を連れています。
ところが不幸にも、森でベリーを探していた親友が誘拐されてしまいます。
アナリンは親友を見つけて救い出そうとします。このクエストに飼い犬を連れていくかどうかは自由です。

親友の足取りをしばらく追ったあと、彼女は親友が囚われている野営地を見つけます。誘拐犯は2人いました。屈強な騎士と、ずる賢い射手です。

誘拐犯を見つけたアナリンは、次のうちどの行動を取れるかを考えます：

- _速攻_：騎士が眠っていれば速攻を仕掛けられます。鎧を着るには時間がかかるため、騎士は無防備になるからです。<!-- **アナリンが騎士に近づく途中でつまずく確率は5%です。そうなると騎士は目を覚まし、鎧を着るだけの時間を稼げるため、速攻はできなくなります。** [将来のテストケース候補] -->
- _スパイ_：一味のうち少なくとも1人が起きていれば、様子を探れます。そうでなければ、スパイは時間の無駄です。**プレイの_半分_では霧が立ちこめているため、スパイはできません。**
- _囚人に合図を送る_：囚人が起きていて、射手が眠っていれば、鳥のさえずりを使って囚人に合図を送れます。射手は鳥のさえずりによる合図の訓練を受けているため、そのメッセージを傍受される可能性があるからです。
- _囚人を解放する_：アナリンは野営地に忍び込んで囚人を解放しようとできますが、この戦法がうまくいくのは、囚人が起きていて、ほかの2人が眠っているときだけです。囚人が眠っていると、突然現れたアナリンに驚いてしまい、ほかの2人を起こしてしまいます。射手が眠っていて、アナリンが飼い犬を連れている場合も囚人を解放できます。騎士は犬におびえて引き下がりますし、射手は弓を装備するのが間に合わず、囚人の解放を止められないからです。**残念ながら、アナリンの犬はウサギを追いかけるのが大好きです。野営地へ向かう途中で犬がウサギに出くわす確率は25%です。その場合、犬は騎士をおびえさせるために使えなくなります。**

**親友を解放したあと、アナリンには野営地から素早く戦利品を奪う時間がまだ少しあります。見つかるコインは3枚から13枚の間です。また、中にランダムなアイテムが入った宝箱にも出くわします。**

ここでのタスクは、これらのランダムイベントが起こるかどうかを判定する関数を実装し、アナリンの戦利品を決めることです。

### 1. 霧が出ているかどうかを判定する関数を追加する

`is_foggy`という名前の関数を実装します。この関数は半分の確率で`true`を返します。それ以外の場合は`false`を返します。

```julia-repl
julia> is_foggy()
true

julia> is_foggy()
false
```

### 2. 犬が気をそらされたかどうかを判定する関数を追加する

`is_dog_distracted`という名前の関数を実装します。この関数は25%の確率で`true`を返します。それ以外の場合は`false`を返します。

```julia-repl
julia> is_dog_distracted()
false

julia> is_dog_distracted()
true

julia> is_dog_distracted()
false
```

### 3. コインを奪うアクションを追加する

野営地でアナリンが見つけるコインの枚数を返す、`loot`という名前の関数を実装します。たとえば：

```julia-repl
julia> loot()
4

julia> loot()
7

julia> loot()
3
```

### 4. 宝箱を奪うアクションを追加する

アイテムのコレクションを引数に取り、宝箱の中でアナリンが見つけるアイテムを返す、`loot`という名前の関数を実装します。たとえば：

```julia-repl
julia> loot(["Cabbage", "Daring Dagger", "Sneaky Shoes"])
"Cabbage"

julia> loot(["Cabbage", "Daring Dagger", "Sneaky Shoes"])
"Sneaky Shoes"
```
