# 概要

Factorの`<iota>`は、整数`0, 1, …, n-1`の*仮想的な*シーケンスを生成します。これを`map`でたどっていくと、各要素がその位置の関数になっている、表のように並んだシーケンスが得られます。

```factor
USING: math sequences ;

5 <iota> [ sq ] map .         ! => { 0 1 4 9 16 }
8 <iota> [ 1 + ] map .        ! => { 1 2 3 4 5 6 7 8 }
```

整数のコードのシーケンスを文字列に変えるには、2つのワードがあります。

| ワード | 役割 |
|-----------|---------------------------------------------------------|
| `CHAR:`   | パース時のリテラルで、文字のコードポイントを積みます |
| `>string` | コードポイントのシーケンスを文字列に変換します |

この2つを組み合わせると、位置をインデックスにして文字を並べた行を作る、定番の書き方になります。

```factor
USING: kernel math sequences strings ;

10 <iota> [ 2 mod zero? [ CHAR: O ] [ CHAR: . ] if ] map >string .
! => "O.O.O.O.O."
```

クォーテーションの中で`if`（または`?`）を使って文字を選ぶと、位置ごとの判断を、それが依存するインデックスのすぐ近くに置けます。
