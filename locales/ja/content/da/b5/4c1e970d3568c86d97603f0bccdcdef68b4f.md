# breakとcontinue

ループや繰り返しの制御構造を使うときは、`break`と`continue`というキーワードが、プログラムの流れを制御するのに役立ちます。
`break`キーワードは、ループのコンテキストから外側のスコープへ抜け出し、ループを終了させます。
`continue`キーワードは、現在の繰り返しの残りをスキップし、次の繰り返しの先頭からループのコンテキストを再開します。
あまり一般的ではありませんが、キーワードと一緒に数値を指定すると、いくつのコンテキストを抜け出すか、またはいくつのコンテキストをスキップして次の繰り返しに進むかを制御できます。

```php
<?php
$i = 1;
while ($i <= 10) {

    if ($i <= 5) {
        i += 1;
        continue;
    }
    break;
}
```

前の例では、`continue`は5回実行されますが、6回目の繰り返しで`break`が実行されるため、コードはループを抜けます。
