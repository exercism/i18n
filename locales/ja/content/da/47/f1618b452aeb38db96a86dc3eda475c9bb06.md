# インストール

## はじめに

Regina Rexxは多くの環境に移植されていますが、ここでは64ビットのデスクトッププラットフォーム（Windows、Linux、MacOS）でのインストール手順を中心に説明します。

## インストール手順

このトラックでは、最新バージョンの[Regina](https://sourceforge.net/projects/regina-rexx/files/regina-rexx/3.9.5/)がインストールされていることを前提としています（執筆時点では3.9.5）。上のリンクをたどるとFilesセクションに直接移動するので、そこからダウンロードするファイルを選んでください。

### Windows

Windows上でネイティブに（CMDまたはPowerShellのウィンドウから）実行するためのインストールは、ブラウザで[`Download Latest Version`](https://sourceforge.net/projects/regina-rexx/files/regina-rexx/3.9.5/Regina395w64.exe/download)ボタンをクリックすれば簡単に行えます。クリックして、ダウンロードして、インストールするだけです。

次のようなLinuxエミュレーション環境をお持ちの場合、または使いたい場合は：

* [Git for Windows](https://gitforwindows.org/)
* [Cygwin](https://cygwin.com/)
* [MinGW](http://mingw.org/)

WindowsネイティブのReginaバイナリを利用できるはずなので、これらの環境でそのまま実行できます。ほとんどの用途では、これで問題ありません。

ただし、1つ注意点があります。ADDRESS命令は（ホストオペレーティングシステムとやり取りするため）正しく動作しません。これらの環境で最良の結果を得るには、環境に固有のパッケージを入手してインストールしてください。たとえばReginaのウェブサイトでは、[Cygwin専用](https://sourceforge.net/projects/regina-rexx/files/regina-rexx/3.9.5/regina-rexx-3.9.5-x86_64-pc-cygwin.tgz/download)のビルドが公開されており、これをインストールできます。

あるいは、[WSL](https://docs.microsoft.com/en-us/windows/wsl/about)や[Virtual Box](https://www.virtualbox.org/)のように、Windows上で動く_本物の_Linuxディストリビューションをお持ちの場合、または使いたい場合は、該当するディストリビューションについてLinuxのセクションの手順に従ってください。

### Linux

Linuxへのインストールは、通常、システムのパッケージマネージャーを使えばとても簡単です。ただし、入手できるパッケージが最新のもので_ない_場合は厄介です。残念ながら、Reginaはまさにそのケースです。

最新のパッケージを手動で入手すれば、パッケージベースのインストールも可能です。[Regina](https://sourceforge.net/projects/regina-rexx/files/regina-rexx/3.9.5/)のウェブサイトでは、Debian系（Ubuntuを含む）やRHEL系（Fedora、CentOS、Rocky、Almaを含む）などのディストリビューション向けのパッケージが公開されています。

選んだディストリビューションに応じて、ライブラリパッケージとバイナリパッケージの2つをダウンロードする必要があります。たとえばDebianやUbuntuにインストールするには、次のようにします：

```plain
sudo apt update && sudo apt -y install curl
curl -sLk https://sourceforge.net/projects/regina-rexx/files/regina-rexx/3.9.5/regina-rexx_3.9.5-2_amd64-Debian-11.deb > regina-rexx_3.9.5-2_amd64-Debian-11.deb
curl -sLk https://sourceforge.net/projects/regina-rexx/files/regina-rexx/3.9.5/libregina3_3.9.5-2_amd64-Debian-11.deb > libregina3_3.9.5-2_amd64-Debian-11.deb
sudo apt -y install libregina3_3.9.5-2_amd64-Debian-11.deb regina-rexx_3.9.5-2_amd64-Debian-11.deb
```

CentOSやRHEL 7では、次のようにしてみてください：
```plain
sudo yum update && sudo yum install curl
curl -sLk https://sourceforge.net/projects/regina-rexx/files/regina-rexx/3.9.5/regina-rexx-3.9.5-220823.1647.x86_64-CentOS-7.9.2009.rpm > regina-rexx-3.9.5-220823.1647.x86_64-CentOS-7.9.2009.rpm
curl -sLk https://sourceforge.net/projects/regina-rexx/files/regina-rexx/3.9.5/libregina3-3.9.5-220823.1647.x86_64-CentOS-7.9.2009.rpm > libregina3-3.9.5-220823.1647.x86_64-CentOS-7.9.2009.rpm
sudo yum localinstall libregina3-3.9.5-220823.1647.x86_64-CentOS-7.9.2009.rpm regina-rexx-3.9.5-220823.1647.x86_64-CentOS-7.9.2009.rpm
```

Fedora、Rocky、Almaでは、次のようにしてみてください：
```plain
sudo dnf update && sudo dnf install curl
curl -sLk https://sourceforge.net/projects/regina-rexx/files/regina-rexx/3.9.5/regina-rexx-3.9.5-220826.0951.x86_64-rocky-9.0.rpm > regina-rexx-3.9.5-220826.0951.x86_64-rocky-9.0.rpm
curl -sLk https://sourceforge.net/projects/regina-rexx/files/regina-rexx/3.9.5/libregina3-3.9.5-220826.0951.x86_64-rocky-9.0.rpm > libregina3-3.9.5-220826.0951.x86_64-rocky-9.0.rpm
sudo dnf localinstall libregina3-3.9.5-220826.0951.x86_64-rocky-9.0.rpm regina-rexx-3.9.5-220826.0951.x86_64-rocky-9.0.rpm
```

パッケージベースのインストールができない場合や、ほかの方法ではうまくいかない場合は、いつでもソースからビルドできます。アーカイブは次の方法で入手できます：

```plain
curl -sLk https://sourceforge.net/projects/regina-rexx/files/regina-rexx/3.9.5/regina-rexx-3.9.5.tar.gz > regina-rexx-3.9.5.tar.gz
```

標準的なビルドツール（gcc、make）がインストールされていることを前提とします（まだの場合は、こちらに従ってください：[開発ツールのインストール](https://ostechnix.com/install-development-tools-linux/)）。そのうえで、次の手順を実行します：

```plain
tar -xzvf regina-rexx-3.9.5.tar.gz && cd regina-rexx-3.9.5
./configure
sudo make
sudo make install
```

ライブラリ（`libregina.so`）と2組のバイナリ（`rexx`と`regina`）がインストールされます（デフォルトの場所は`/usr/local/bin`です）。

`rexx`バイナリは静的リンクされているので自己完結しており、すぐに使えます。

`regina`バイナリは動的リンクされているため、実行時に`libregina.so`共有ライブラリを見つけられるように、多少の設定が必要です。そのためには、次の手順を行います：

```plain
# Configure shared library location
sudo su
echo /usr/local/lib64/ > /etc/ld.so.conf.d/regina-rexx-3.9.5-x86_64.conf
echo /usr/local/lib64/regina-rexx/addons > /etc/ld.so.conf.d/regina-rexx-addons-x86_64.conf
cd /usr/local/lib64
rm -f libregina.so libregina.so.3
ln -s libregina.so.3.9 libregina.so
ln -s libregina.so.3.9 libregina.so.3
ldconfig
exit

# Check symbolic link creation
ls -l /usr/local/lib64/

# Output should be similar. Note symbolic links.
-rw-r--r--. 1 root root 3887554 Dec  1 18:22 libregina.a
lrwxrwxrwx. 1 root root      16 Dec  2 06:03 libregina.so -> libregina.so.3.9
lrwxrwxrwx. 1 root root      16 Dec  2 06:03 libregina.so.3 -> libregina.so.3.9
-rwxr-xr-x. 1 root root  574104 Dec  1 18:22 libregina.so.3.9
drwxr-xr-x. 2 root root      26 Dec  1 18:22 pkgconfig
drwxr-xr-x. 4 root root      33 Dec  1 18:22 regina-rexx

# Check library path, and executable using that path
ldconfig -p | grep regina
ldd /usr/local/bin/regina

# Alternate for local user
export LD_LIBRARY_PATH=${LD_LIBRARY_PATH}:/usr/local/lib64:/usr/local/lib64/regina-rexx/addons
```

ソースからのビルドとそれに伴うシステム設定は、経験豊富なユーザーが行うのがよい作業ですので、ご注意ください。

### MacOS

インストールは3つのステップで進みます：

* [Homebrew](https://brew.sh)パッケージマネージャーをインストールします
* `Terminal`アプリケーションを探して起動します
* `Terminal`のコマンドラインから、次のように入力します：

   `brew install regina-rexx`

これで最新バージョンがインストールされる_はず_です。

そうならない場合は、[Regina for MacOS](https://sourceforge.net/projects/regina-rexx/files/regina-rexx/3.9.5/regina-rexx-3.9.5-x86_64-apple-darwin21.6.0.tgz/download)パッケージをダウンロードして、手動でインストールできます。

## インストール後

### インストールの確認

インストールが完了したら、ターミナルで次のコマンドを実行すると、[Regina](https://sourceforge.net/projects/regina-rexx/files/regina-rexx/3.9.5/)が正常にインストールされたかどうかを確認できます：

```plain
rexx --version=v
```

WindowsとLinuxのどちらのプラットフォームでも、ターミナルには次のように出力されます：

```plain
3.9.5
```

これはインタプリターのバージョン番号です。

もう1つのバイナリ`regina`もインストールされます。これは共有ライブラリにリンクしている点を除けば、あらゆる面で`rexx`と同一です。外部のユーティリティ関数を利用したい場合に使うインタプリターはこちらです。詳しくは[外部ルーチンへのアクセス](###accessing-external-routines)のセクションを参照してください。

トラックを使い始めるために、ほかにインストールが必要なソフトウェアはありません（Exercism CLIがインストール済みであることが前提です）。

以下の使用例では、コマンドラインからインタプリターを使うための基本を説明します。

### 使い方

Rexxスクリプトの拡張子は通常_`.rexx`_ですが、これは必須ではありません。インタプリターは引数として渡されたファイル名をそのまま実行しようとし、有効なRexxコードが含まれていれば正常に実行されます。

次のコマンドは、`hello.rexx`というファイルを実行しようとします：

```plain
rexx hello.rexx
```

このファイルに次のコードが書かれているとします：

```rexx
say "Hello, world!"
exit 0
```

すると、ターミナルには次のように出力されます：

```plain
Hello, world!
```

ファイル名を`hello.txt`に変更して、次のように実行しても、同じ出力が得られます：

```plain
rexx hello.txt
```

また、スクリプトのコードはファイルに置いておくだけでなく、インタプリターにパイプで渡すこともできると知っておくとよいでしょう。先ほどのコードは、次のようにパイプで実行できます：

```plain
echo "say 'Hello, world' ; exit 0" | rexx
```

これはLinuxのターミナルでも、WindowsのPowerShellのターミナルでも、同じように動作します。

### 応用的な使い方

スクリプトファイルには、1つ以上のコマンドライン引数を渡すことができ、任意の整数のリターンコードを返せます。ただし、スクリプトに複数の引数が渡されることをインタプリターに知らせる必要があり、それは`-a`オプションで行います。

たとえば、`multiarg.rexx`というファイルに次のコードが書かれているとします：

```rexx
say "My name is" ARG(1) || ", your name is" ARG(2) || ", and the script return code will be" ARG(3) || "."
exit ABS(ARG(3))
```

複数のスクリプト引数が正しく解釈されるようにするには、スクリプトを次のように実行します：

```plain
rexx -a multiarg.rexx "John" "Jill" 5
```

すると、ターミナルには次のように出力されます：

```plain
My name is John, your name is Jill, and the script return code will be 5.
```

また、プログラムのリターンコード（Linuxでは`$?`、Windowsでは`%errorlevel%`で確認できます）は5に設定されます。

### 外部ルーチンへのアクセス

Reginaは、外部の共有ライブラリにあるルーチンを使うことができます。いくつかはReginaのウェブサイトから入手できます。ただし、そうしたライブラリのインストールについては、ここでは扱いません。

Reginaには、そうしたライブラリの1つである_regutil_が同梱されています。数学、ファイルやファイルシステムの操作、システムアクセスなど、いくつかの汎用ルーチンが含まれています。

追加のインストール作業は必要ありません。ただし、これらのルーチンをスクリプトで使うには、インタプリターの読み込み時にそれらを登録する必要があります。必要なのは2つの関数呼び出しだけで、その流れを次に示します。

`access-external.rexx`というファイルに、次のコードが書かれています：

```rexx
/* Register external library and functions */
call RxFuncAdd 'SysLoadFuncs', 'regutil', 'SysLoadFuncs'
call SysLoadFuncs

say "Value of pi is" SysPi()
say "Square root of 25 is" SysSqrt(25)
say "Square root of 2 is" SysSqrt(2)

/* Deregister */
call SysDropFuncs

exit 0
```

これらのルーチンを読み込んで使うには、`regina`バイナリを使う必要があるので、スクリプトは次のように実行します：

```plain
regina access-external.rexx
```

すると、ターミナルには次のように出力されます：

```plain
Value of pi is 3.141592654
Square root of 25 is 5.000000000
Square root of 2 is 1.414213562
```

もし代わりに`rexx`バイナリを使っていたら、Windowsプラットフォームでのターミナル出力は次のようになります：

```plain
'SYSLOADFUNCS' is not recognized as an internal or external command,
operable program or batch file.
'SYSPI' is not recognized as an internal or external command,
operable program or batch file.
'SYSSQRT' is not recognized as an internal or external command,
operable program or batch file.
'SYSSQRT' is not recognized as an internal or external command,
operable program or batch file.
'SYSDROPFUNCS' is not recognized as an internal or external command,
operable program or batch file.
```

一方、Linuxプラットフォームでは次のようになります：

```plain
sh: SYSLOADFUNCS: command not found
sh: SYSPI: command not found
sh: SYSSQRT: command not found
sh: SYSSQRT: command not found
sh: SYSDROPFUNCS: command not found
```
