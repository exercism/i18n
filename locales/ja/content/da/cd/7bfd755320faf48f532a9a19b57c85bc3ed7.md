# 概要

Pythonでは、[`enum`][enum-docs]とは、一意な名前をそれぞれ一意で**定数**の値に結び付けた集合です。
`Enums`は、`Enum`クラスを継承することで定義します。
組み込みの`enum`型はモジュール`enum`で利用でき、`Enum`クラスは`from enum import Enum`を使ってインポートできます。


```python
from enum import Enum

class Color(Enum):
    RED = 1
    GREEN = 2
```

`enum`のメンバーの値には、`str`や`tuple`、`float`など、任意のデータ型を使えることに注意してください。

```python
class Color(Enum):
    RED = 'red'
    GREEN = 'green'
```

`Enums`は、[関数呼び出しの構文][enum-functional-example]を使って作成することもできます。

```python
from enum import Enum

Animal = Enum('Animal', 'ANT BEE CAT DOG')
list(Animal)
#=> [<Animal.ANT: 1>, <Animal.BEE: 2>, <Animal.CAT: 3>, <Animal.DOG: 4>]

Animal.ANT.value
#=> 1
```

`enum`内の2つのメンバーに同じ値を代入すると、あとで代入したメンバーは、先に代入したメンバーのエイリアスになります。1つの`enum`の異なる2つのメンバーに同じ名前を使うことはできません。

```python
class Color(Enum):
    RED = 1
    GREEN = 2
    ALIAS_OF_RED = 1

Color.ALIAS_OF_RED
#=> <Color.RED: 1>
```

`enum`のメンバーを繰り返し処理するには、標準の`for member in`構文を使います：

```python
for member in Color:
    print((member.name, member.value))
#=> (RED, 1)
#=> (GREEN, 2)

# __members__.items() helps you to loop through alias as well
for member in Color.__members__.items():
    print(member)
#=> ('RED', <Color.RED: 1>)
#=> ('GREEN', <Color.GREEN: 2>)
#=> ('ALIAS_OF_RED', <Color.RED: 1>)
```

`Enum`のメンバーは、[`is`（_同一性演算子_）][identity-keyword]や`is not`で比較できます。`==`や`!=`（_等価演算子_）も同様に機能します：


```python
a = Color.RED

a is Color.RED
#=> True

a == Color.RED
#=> True
```

整数値を代入するには、[`auto()`関数][enum-auto-docs]を使うと、`1`から始まって以降の値が自動的に設定されます。

```python
class Shape(Enum):
    CIRCLE = auto()
    SQUARE = auto()
    OVAL = auto()
```

エイリアスを禁止する（_異なる名前で同じ値が重複するのを防ぐ_）には、[クラスデコレーター][class-decorator]の[`@enum.unique`][enum-unique-decorator]デコレーターを使うとよいでしょう。

```python
@enum.unique
class Shape(Enum):
    CIRCLE = 1
    SQUARE = 2
    TRIANGLE = 1
#=> ValueError: duplicate values found in <enum 'Shape'>: TRIANGLE -> CIRCLE
```

ある値に対応する`enum`メンバーにアクセスするには、`<EnumName>(<value>)`という記法を使います。

```python
g = Color(2)

g is Color.GREEN
#=> True

g
#=> <Color.GREEN: 2>
```

任意のミックスインやデータ型を使って`Enum`クラスをサブクラス化することで、独自の[制限付き`Enum`][restricted-enums]を書くことができます。
たとえば、次のとおりです：


```python
class StrEnum(str, Enum):
    pass
```

`Enum`のサブクラス化は、`enum`がメンバーを**1つも**定義していない場合にのみ許可されます。
