# はじめに

定数とは、コンパイル時に設定される値で、再代入することはできません。
ひとつの定数を宣言するには、`const`キーワードを使います。

```go
const greeting = "hello"
```

複数の定数は、ブロックにまとめて宣言できます。
ブロック内では、値を明示せずに書いた定数は、ひとつ前の式を繰り返します。

```go
const (
    greeting    = "hello"
    buffSize    = 4096
    chunkSize   // 4096
)
```

定数は通常、パッケージレベルで宣言しますが、関数の中でも宣言できます。

## 型付き定数と型なし定数

型を指定せずに定数を宣言すると、その定数は型なしになります。
型なし定数は決まった型を持たず、その値によって、どの型と互換性があるかが決まります。
元の値が互換性を持つ限り、コンパイラーは使われるたびに、その値を必要な型へ変換します。

```go
const numA = 2

math.Sqrt(numA)  // numA is treated as float64 here
var numB int = numA  // numA is treated as int here
```

型付きの定数は、宣言の時点で型を固定します。

```go
const num int = 2

math.Sqrt(num)  // compile error because a float is expected
```

## 定数にできるもの

定数にできるのは、真偽値、数値、文字列、そしてルーンだけです。
値はコンパイル時に設定されるため、関数呼び出しの結果を定数に使うことはできません。

```go
const s = math.Sqrt(4)  // compile error because the value isn't known at compile time
```

## `iota`

定数のブロックの中では、`iota`はそのブロック内での定数の位置を表します。

```go
const (
    Sunday    = iota // 0
    Monday           // 1
    Tuesday          // 2
    Wednesday        // 3
)
```

最初の定数のあとに続く各定数は、同じ式を引き継ぎ、`iota`は1ずつ増えていきます。

`iota`は式の中でも使えます。

```go
const (
    _  = iota             // position 0: value discarded
    KB = 1 << (10 * iota) // position 1: 1 << 10 = 1024
    MB                    // position 2: 1 << 20 = 1048576
    GB                    // position 3: 1 << 30 = 1073741824
)
```
