# 演習の補足

## 自分だけのDSLを作りましょう

この演習では、思いどおりのグラフDSLを自由に設計できます。

タグとレコードのリストに基づくDSLを作るなら、たとえば次のように書けるでしょう。

```roc
my_graph =
    Graph.new([
        Title("My Graph"),
        Node("a", { color: Green }),
        Node("b", { color: Blue }),
        Edge("a", "b", { style: Dotted }),
    ])
```

あるいは、関数呼び出しのチェーンに基づくDSLのほうが好みかもしれません。

```roc
my_graph =
    Graph.new
        .with_title("My Graph")
        .add_node("a", Attr.new.with_color(Green))
        ...
```

それとも、まったく別のやり方を考えていますか？　ぜひやってみましょう！　テストが求めているのは、いくつかの特定のグラフを作ることだけです。それをどう組み立てるかは、完全に自由です。

とはいえ、DSLはたいてい、明確で簡潔、そしてあまり驚きのないほうがよいものです（たとえば、`minus`関数は引き算のためのもので、`node("a") - node("b")`のように2つのノードの間に辺を作るためのものではありません）。

もっと楽しみたいなら、グラフをDOT形式に変換する`to_dot`関数の実装にも、ぜひ挑戦してみてください！
