# 可視性

クラスでコードを整理するとき、プロパティやメソッド、定数の可視性を意識すると、適切な抽象化と責務につながります。
プロパティやメソッド、定数の可視性は、宣言するときに`public`、`private`、`protected`のどのキーワードを使うかで決まります。
可視性は、常にクラスのプロパティやメソッド、定数を外部から使うときのことを指します。
つまり、`public`で宣言されたプロパティは、外部からの呼び出しで参照でき、使うことができます。
`private`なプロパティやメソッド、定数は、外部からの呼び出しで参照することも使うこともできません。

```php
<?php

class SecretDocument
{
    private $encryption_key;

    public $title;

    public function __construct($encryption_key, $title)
    {
        $this->encryption_key = $encryption_key;
        $this->title = $title;
    }
}

$document = new SecretDocument('secret_password', 'Secret Plans');
$title = $document->title; // => succeeds
$key = $document->encryption_key; // => fails
```

`protected`なプロパティやメソッド、定数は、自分自身と、継承した子クラスからのみ参照することができます。

```php
<?php

class Shape
{
    protected $color = "blue";
}

class Square extends Shape
{
    public function getColor()
    {
        return $this->color;
    }
}

$square = new Square();
$color = $square->getColor(); // => succeeds
```
