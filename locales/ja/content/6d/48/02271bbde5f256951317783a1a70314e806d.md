# インストール

## .NETのインストール

C#トラックは、[.NET](https://dotnet.microsoft.com/learn/dotnet/what-is-dotnet)プラットフォームの上に構築されています。このプラットフォームは、Windows、Linux、macOSで動作します。
.NETプロジェクトをビルドするには、.NETコマンドラインインターフェース（CLI）を使います。
このCLIは.NET SDKの一部で、[インストール手順](https://dotnet.microsoft.com/download/dotnet/8.0)に従ってインストールできます。
注意：C#トラックにはSDKバージョン9.0以上が必要です。

インストールが完了したら、ターミナルで次のコマンドを実行すると、CLIが正常にインストールされたか確認できます。

```bash
dotnet --version
```

出力されたバージョンが`9.0.100`以上であれば、.NET SDKは正常にインストールされています。

## IDEを使う

より高機能な編集環境がほしい場合は、[IDE（統合開発環境）](https://en.wikipedia.org/wiki/Integrated_development_environment)を使うとよいでしょう。
.NETプロジェクトのビルドに対応している、もっともよく使われているIDEは次のとおりです。

- [Visual Studio 2022](https://www.visualstudio.com/downloads/)
- [Visual Studio Code](https://code.visualstudio.com/download)と[C#拡張機能](https://marketplace.visualstudio.com/items?itemName=ms-dotnettools.csharp)
- [Visual Studio for Mac](https://www.visualstudio.com/vs/visual-studio-mac/)
- [Project Rider](https://www.jetbrains.com/rider/download/)

注意：.NETプロジェクトの形式は以前のバージョンとは大きく異なるため、Visual Studio 2015のような古いIDEはサポートされていません。
