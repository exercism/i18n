# はじめに

Gleamで値のパターンマッチングを行うときは、その型が取りうるすべての値にパターンが一致するようにしなければなりません。そうでないと、コードはコンパイルされません。

次の関数は、配列が空の場合を処理していないため、コンパイルエラーになります:

```gleam
pub fn get_first_element_or_crash(items: List(e)) -> e {
  case items {
    [item, ..] -> item
  }
}
```

Gleamのプログラムでは、ほとんどの場合、起こりうるすべてのケースを扱いたいものです。しかし、プロトタイプやちょっとしたスクリプトなどでは、うまくいく場合だけに注目し、それ以外のケースのコードは書かないようにしたいこともあります。そこで役立つのが、Gleamの`let assert`です。

letアサーションを使うと、パターンはその型が取りうる値の一部にだけ一致すればよくなり、値がパターンに一致しなければプログラムはクラッシュします。`let assert`を使えば、先ほどの関数は次のように書けます:

```gleam
pub fn get_first_element_or_crash(items: List(e)) -> e {
  let assert [item, ..] = items
  item
}
```

Gleamのライブラリでは、letアサーションを決して使うべきではありません。プログラムがクラッシュする可能性があるからです。代わりに`Result`型を使い、エラーの扱い方はアプリケーションのエンジニアが決められるようにしましょう。
