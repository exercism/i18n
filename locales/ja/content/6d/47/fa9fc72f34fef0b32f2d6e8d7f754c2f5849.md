# インストール

このトラックの解答は32ビットのRISC-Vアセンブリで書かれており、エミュレーション上で実行されるため、RISC-Vのハードウェアは必要ありません。
各演習には、テストをビルドして実行するMakefileが付属しています。
これを使うには、次の3つのツールが必要です。

- [Zig][zig]。`zig cc`を通じて、RISC-Vのアセンブラ、Cコンパイラ、リンカーを提供します。
- [Make][make]。ビルドを実行します。
- [QEMU][qemu]の`qemu-riscv32`。生成されたプログラムを実行します。

## macOS

適切な仮想化ソリューション（例：[Lima][lima]）を使ってLinux仮想マシンを起動し、以下のLinuxディストリビューションのセクションに従ってください。

## Windows

[Windows Subsystem for Linux][wsl]を使い、以下のLinuxディストリビューションのセクションに従ってください。または、Linux仮想マシンをセットアップしてください。

## Debian / Ubuntu

MakeとQEMUのユーザーモードエミュレーターをインストールします。

```shell
sudo apt install make qemu-user
```

次に、[直接ダウンロード][zig-install]に書かれている方法でZig 0.15.2以降をインストールします。

## Fedora

3つのツールをまとめてインストールします。

```shell
sudo dnf install zig make qemu-user
```

## Arch Linux

3つのツールをまとめてインストールします。

```shell
sudo pacman -S zig make qemu-user
```

## openSUSE Tumbleweed

3つのツールをまとめてインストールします。

```shell
sudo zypper install zig make qemu-linux-user
```

## インストールの確認

3つのツールがすべて見つかることを確認します。

```shell
zig version
make --version
qemu-riscv32 --version
```

次に、Exercism CLIで演習をダウンロードして、そのテストを実行します。

```shell
exercism download --track=risc-v --exercise=hello-world
cd ~/exercism/risc-v/hello-world/
make
```
