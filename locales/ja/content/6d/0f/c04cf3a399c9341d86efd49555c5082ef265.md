# はじめに

## IO

入力と出力を扱う関数は、`IO`モジュールで提供されています。

### 出力

標準出力に文字列を書き込むには、`IO.puts`を使います。`IO.puts`は、文字列の末尾に必ず改行を追加します。その動作が不要な場合は、代わりに`IO.write`を使いましょう。どちらの関数も、成功するとアトム`:ok`を返します。

```elixir
IO.puts("Hi!")
# > Hi!
# => :ok
```

`IO.puts`は文字列の書き込みには便利ですが、それ以外の用途にはあまり向いていません。任意の値を標準出力に書き込めるデバッグ用のツールが必要なら、代わりに`IO.inspect`を使いましょう。`IO.inspect`は、渡された値をそのまま返すので、コードの好きな位置に挿入できます。また、`:label`をはじめとする多くのオプションを受け付けるので、他の`IO.inspect`の呼び出しと区別できます。

### 入力

標準入力から1行読み込むには、`IO.gets`を使います。`IO.gets`は引数を1つ受け取ります。これは、入力のプロンプトとして表示される文字列です。`IO.gets`はプロンプトのあとに改行を追加しません。必要な場合は、自分で含めてください。

```elixir
IO.gets("What's your name?\n")
# > What's your name?
# < Mary
# => "Mary\n"
```
