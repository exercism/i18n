# 学習

## Emacsを始める

Emacsをインストールしたのはいいけれど、次は何をすればいいのでしょうか？

まずは`C-h t`を押してチュートリアルを始めるのがよいでしょう。ここから始めるのは悪くない選択です。チュートリアルでは、Emacsでの編集・検索・移動の基本を学べます。

Emacsがまったく初めてなら、設定やパッケージがあらかじめ用意されたスターターキットを手に入れるのもよいでしょう。

[Emacs Prelude](http://batsov.com/prelude/)パッケージには、理にかなったデフォルト設定とパッケージがひとそろい用意されています。

Emacs Preludeをインストールするには、ターミナルで次を実行します。

```
curl -L https://github.com/bbatsov/prelude/raw/master/utils/installer.sh | sh
```

詳しい手順については、[インストールガイド](https://prelude.emacsredux.com/en/latest/installation/)を確認してください。

vimに慣れているなら、[evil-mode](https://github.com/emacs-evil/evil)によるvimエミュレーションを組み込んだスターターキットの[Doom Emacs](https://github.com/doomemacs/doomemacs)も興味深いかもしれません。

Doom Emacsをインストールするには、ターミナルで次を実行します。

```
git clone --depth 1 https://github.com/doomemacs/doomemacs ~/.emacs.d
~/.emacs.d/bin/doom install
```

詳しい手順については、[インストールガイド](https://github.com/doomemacs/doomemacs#install)を確認してください。

## 構文チェックとリントの設定

[Flycheck](https://www.flycheck.org/en/latest/)を使って構文チェックとリントを設定することをおすすめします。

まだ[MELPA](https://melpa.org/)リポジトリをEmacsに追加していない場合は、[initファイル](https://www.flycheck.org/en/latest/glossary.html#term-init-file)に次を追加してください。

```elisp
(require 'package)

(add-to-list 'package-archives
             '("MELPA Stable" . "https://stable.melpa.org/packages/") t)
(package-initialize)
(package-refresh-contents)
```

[use-package](https://github.com/jwiegley/use-package)を使わずにFlycheckをインストールして設定するには、[initファイル](https://www.flycheck.org/en/latest/glossary.html#term-init-file)に次を追加します。

```elisp
(package-install 'flycheck)
(add-hook 'after-init-hook #'global-flycheck-mode)
```

[use-package](https://github.com/jwiegley/use-package)を使ってFlycheckをインストールして設定するには、[initファイル](https://www.flycheck.org/en/latest/glossary.html#term-init-file)に次を追加します。

```elisp
(use-package flycheck
  :ensure t
  :init (global-flycheck-mode))
```

さらに詳しい情報やトラブルシューティングについては、[Flycheckのドキュメント](https://www.flycheck.org/en/latest/user/troubleshooting.html)を確認してください。

## Emacs Lispを学ぶ

Emacs Lispについての最高のドキュメントは…実はEmacs自体に付属しています！　[Emacs Lisp Reference](https://www.gnu.org/software/emacs/manual/elisp.html)を開くには、`C-h i`と入力してElispの項目を探すか、Help &rarr; More Manuals &rarr; Emacs Lisp Referenceを選びます。ディストリビューションによってはマニュアルが含まれていないこともありますが、その場合は[オンライン](https://www.gnu.org/software/emacs/manual/elisp.html)で読むことができます。

Elispがまったく初めてなら、[Introduction to Emacs Lisp](http://www.emacswiki.org/emacs/EmacsLispIntro)を読むとよいでしょう。これも同じ方法で開けます。

## Emacs Lispのベストプラクティスと規約

Emacsマニュアルには、Emacs Lispの[Coding Conventions](https://www.gnu.org/software/emacs/manual/html_node/elisp/Coding-Conventions.html)というセクションがあります。GitHubでは、コミュニティ主導の[Style Guide](https://github.com/bbatsov/emacs-lisp-style-guide)も管理されています。
