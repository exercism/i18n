# はじめに

[Cargo Shuffle][cargo-shuffle]では、Factorの**データスタック**と、それを並べ替えるシャッフルワードを学びました。この演習はその続きです。今回は、入力をただ動かすのではなく、入力を使って*計算する*ワードを定義します。

## コメント

`!`は行コメントの始まりです。Factorは`!`から行末までのすべてを無視します。以下の例では、`!`をコードの動作を説明するためと、出力される内容を示すための両方に使っています。

## ワード

**ワード**は、Factorで関数を表す名前です。ワードを呼び出すと、スタックの一番上からいくつかの値が取り出され、代わりにいくつかの値が積まれます。`.`は一番上の値を取り出して表示します。整数演算のワード`+`、`-`、`*`は、2つの数値を取り出して結果を積みます。

```factor
2 3 + .    ! prints 5
8 3 - .    ! prints 5    (8 - 3, not 3 - 8)
2 3 * .    ! prints 6
```

関連するワード`.s`は、何も消費せずにデータスタックの*全体*を表示します。リスナー（Factorの対話型プロンプトで、コードを入力すると結果が表示されます）で、あるコードが何を残したかを確かめるのに便利です。後の例が`.`ではなく`.s`で終わっていることがあるのはそのためです。そうした例では、スタックに複数の値が残り、`.s`がそれをすべて表示します。

算術ワードは`math`ボキャブラリーにあります。そのため、これらを使うファイルでは、`USING:`の行に`math`が必要です。

## スタック効果

すべてのワードは、`( inputs -- outputs )`という形式の**スタック効果**とともに説明されています。これはワードの契約です。ワードはスタックの一番上から入力を取り出し、その代わりに出力を残します。中の名前は、読むときの助けにすぎません。Factorはそれらを使いません。Factorが追跡するのは、スタック上で値が並ぶ*順序*だけです。

```factor
! + is specified as ( x y -- sum )
! . is specified as ( x   --     )
```

スタックの一番上は*右側*の入力です。つまり、`8 3 -`では`3`が一番上にあるので、スタック効果は`( x y -- difference )`となり、結果は`8 - 3`です。

出力の末尾の`?`は「真偽値」を表す慣習です。ただし、ラザニアの演習では数値しか使いません。

このあと、Cargo Shuffleで登場したシャッフルワードが1つ出てきます。`swap` `( x y -- y x )`です。これは、次のワードにとってスタック上位2つの値の順序が都合が悪いときに、それらを入れ替えます。

## ワードを定義する

`:`でワードの定義を始めます。次にスタック効果、その後に本体を書き、`;`で終わります。

```factor
: square ( x -- x^2 ) dup * ;

4 square .    ! => 16
```

Factorのコンパイラーは、本体が宣言されたスタック効果と実際に合っているかを検査します。`( x -- y )`と宣言しながら、スタックに値を0個または2個残すワードはコンパイルされません。

## 定数

`CONSTANT:`は、固定の値に名前を付けます。定数もそれ自体がワードです。呼び出すと、その値がスタックに積まれます。

```factor
CONSTANT: pi 3

pi pi * .    ! => 9
```

`CONSTANT:`はコア構文なので、`USING:`の行は必要ありません。定数はファイルの先頭、それを使うワードより前に置きます。

## あるワードから別のワードを呼び出す

ワードの本体からは、すでにスコープにあるワードならどれでも呼び出せます。同じファイル内で先に定義したワードも含まれます。

```factor
: double    ( x -- 2x ) 2 * ;
: quadruple ( x -- 4x ) double double ;

5 quadruple .    ! => 20
```

演習の最後のタスクが、それより前のタスクを再利用できるのは、この仕組みがあるからです。

## 命名規則

ワードも定数も`lowercase-kebab-case`を使います。小文字の英字をハイフンでつないだ形式です（例：`expected-bake-time`、`preparation-time`）。
