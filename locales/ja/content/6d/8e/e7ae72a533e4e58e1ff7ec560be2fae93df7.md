# 参考資料

* [The Rust Programming Language](https://doc.rust-lang.org/book/)は、Rustを始めるのにも、Rustの特定の機能を深く掘り下げるのにも最適なリソースです。
* [Rust by Example](https://doc.rust-lang.org/stable/rust-by-example/)では、Rustでよく書くことの例を見ることができます。
* [Rust API Documentation](http://doc.rust-lang.org/std/)を使うと、新しいメソッドとその使い方を見つけることができます。
* [Stack Overflow](http://stackoverflow.com/questions/tagged/rust)では、自分の問題を検索して、すでに回答があるかどうかを確認できます。質問したり、答えたりすることもできます。
* [Rust User Forum](http://users.rust-lang.org)は、Rustに関する一般的な議論の場です。
* [/r/rust](http://www.reddit.com/r/rust/)は、Rustの公式subredditです。
* [The Rust Programming Language](https://discord.gg/rust-lang)の[Discord](https://discordapp.com/)公式サーバーは、言語についてのちょっとした質問や議論に利用できます。
