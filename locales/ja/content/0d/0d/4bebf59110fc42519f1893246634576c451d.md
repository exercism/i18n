# 冗長な括弧

`||`式を使って2つの小さな式をORし、どちらかの式が括弧（`()`）で囲まれていて、その式がいくつかの項をANDでつないでいるだけの場合（例：`knightIsAwake || (archerIsAwake && !prisonerIsAwake)`）、`&&`は`||`より優先順位が高いため、括弧は省略できます。

```java
// instead of
knightIsAwake || (archerIsAwake && !prisonerIsAwake);

// use
knightIsAwake || archerIsAwake && !prisonerIsAwake;
```

なお、複雑な場合によっては、括弧を使うことで条件が読みやすく、理解しやすくなることがあります。
