# 説明

ニコマコス（西暦60年から120年）による正の整数の分類法に基づいて、ある数値がperfect、abundant、deficientのどれであるかを判定します。

ギリシャの数学者[ニコマコス][nicomachus]は、正の整数の分類法を考え出しました。各整数は、その[アリコート和][aliquot-sum]に基づいて、**perfect**、**abundant**、**deficient**のいずれか1つに一意に分類されます。

アリコート和は、その数自身を除いた約数の和と定義されています。

たとえば、15のアリコート和は（1 + 3 + 5）= 9です。

- **Perfect**: アリコート和 = 数値
  - 6は（1 + 2 + 3）= 6なのでperfectです。
  - 28は（1 + 2 + 4 + 7 + 14）= 28なのでperfectです。
- **Abundant**: アリコート和 > 数値
  - 12は（1 + 2 + 3 + 4 + 6）= 16なのでabundantです。
  - 24は（1 + 2 + 3 + 4 + 6 + 8 + 12）= 36なのでabundantです。
- **Deficient**: アリコート和 < 数値
  - 8は（1 + 2 + 4）= 7なのでdeficientです。
  - 素数はすべてdeficientです。

与えられた数値が**perfect**かどうかを判定する方法を実装しましょう。
言語トラックによっては、与えられた数値が**abundant**か**deficient**かも判定する方法を実装する必要があります。
