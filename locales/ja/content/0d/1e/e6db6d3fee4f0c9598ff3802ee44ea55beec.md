# はじめに

## File

ファイルを扱うための関数は、`File`モジュールで提供されています。

ファイル全体を読み取るには、`File.read/1`を使います。ファイルに書き込むには、`File.write/2`を使います。

`File.write/2`でファイルに書き込むたびに、ファイルディスクリプターが開かれ、新しいElixirの[プロセス][exercism-processes]が生成されます。そのため、`File.write/2`を使ってループの中でファイルに書き込むのは避けましょう。

代わりに、`File.open/2`を使ってファイルを開くことができます。`File.open/2`の2番目の引数はモードのリストで、ファイルを読み取り用に開くのか、書き込み用に開くのかを指定できます。

`File.open/2`は、そのファイルを扱うプロセスのPIDを返します。ファイルの読み取りと書き込みを行うには、`IO`モジュールの関数を使い、このPIDをIOデバイスとして渡します。

ファイルの操作が終わったら、`File.close/1`で閉じます。

ここまでに挙げた`File`モジュールの関数には、エラータプルを返す代わりにエラーを発生させる`!`付きの変種もあります（例：`File.read!/1`）。ファイルが存在しない、権限がないといったエラーを処理するつもりがない場合は、こちらの変種を使いましょう。

[exercism-processes]: https://exercism.org/tracks/elixir/concepts/processes
