# 説明

舞台監督は、稽古台本を文字に起こしてほしいと思っています。台本のいくつかの部分は、繰り返したり、つなげたりして作ります。

4つのタスクはすべて`REHEARSAL_SCRIPT`クラスに書きます。

## 1. キューを繰り返す

キューと数値が与えられたとき、そのキューをその回数だけ、間に何も挟まずに繰り返して返します。

```sather
REHEARSAL_SCRIPT::repeat_cue("Ha", 3)
-- => "HaHaHa"
```

何かを0回繰り返すと、空文字列になります。

## 2. 出演者の頭文字

出演者リストが与えられたとき、それぞれの名前の最初の文字をつなげて返します。

```sather
REHEARSAL_SCRIPT::initials(|"Mia", "Ana", "Ben"|)
-- => "MAB"
```

## 3. セリフに番号を振る

場面のセリフが与えられたとき、1から番号を振り、それぞれを別の行にします。

```sather
REHEARSAL_SCRIPT::numbered_lines(|"Enter", "Exit"|)
-- => "1. Enter\n2. Exit"
```

行と行の*間*には改行が入り、最後の行のあとには入りません。セリフが1つもない場面は空文字列になります。

## 4. セリフを叫ぶ

すべての文字を大文字にしたセリフを返します。

```sather
REHEARSAL_SCRIPT::shout("quiet please")
-- => "QUIET PLEASE"
```
