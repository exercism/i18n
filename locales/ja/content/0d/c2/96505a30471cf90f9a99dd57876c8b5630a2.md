# 説明

友達にクッキーを焼いてあげようと準備していると、レシピで使われているいくつかの計量単位を変換しなければならないことに気づきました。
メートル法にしか馴染みがないので、自分が使いやすいように、アメリカでよく使われるお菓子作りの計量をミリリットル（mL）に変換する方法を考える必要があります。

解答には、次の変換表を使いましょう。

| 変換する単位 | 体積 | ミリリットル（mL） |
| --------------- | ------ | ------------------- |
| mL              | 1      | 1                   |
| 米国カップ          | 1      | 240                 |
| 米国液量オンス  | 1      | 30                  |
| 米国小さじ     | 1      | 5                   |
| 米国大さじ   | 1      | 15                  |

優秀なプログラマーを目指して腕を磨いているなら、ここに挙げたどの単位からどの単位へでも（同じ単位へでも）変換しやすくするために、ミリリットルを中間の単位として使うのがよいでしょう。

## 1. 体積ペアから数値の部分を取り出す

`KitchenCalculator.get_volume`メソッドを実装しましょう。
体積ペアのタプルが与えられたら、数値の部分だけを返します。

```crystal
KitchenCalculator.get_volume({:cup, 2.0})
# => 2.0
```

## 2. 体積ペアをミリリットルに変換する

`KitchenCalculator.to_milliliter`メソッドを実装しましょう。
体積ペアのタプルが与えられたら、変換表を使って体積をミリリットルに変換します。

```crystal
KitchenCalculator.to_milliliter({:cup, 2.5})
# => {:milliliter, 600.0}
```

## 3. ミリリットルの体積ペアを別の単位に変換する

`KitchenCalculator.from_milliliter`メソッドを実装しましょう。
体積ペアのタプルと変換したい単位が与えられたら、変換表を使って、その単位に体積を変換します。

```crystal
KitchenCalculator.from_milliliter({:milliliter, 1320.0}, :cup)
# => {:cup, 5.5}
```

## 4. どの単位からどの単位へでも変換する

`KitchenCalculator.convert`メソッドを実装しましょう。
体積ペアのタプルと変換したい単位が与えられたら、与えられた体積をその単位に変換します。

```crystal
KitchenCalculator.convert({:teaspoon, 9.0}, :tablespoon)
# => {:tablespoon, 3.0}
```
