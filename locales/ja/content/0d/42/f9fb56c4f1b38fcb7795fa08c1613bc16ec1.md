# 概要

クラスは、Swiftプログラムの基本的な構成要素です。関連するプロパティ（データ）とメソッド（関数）をまとめて、自己完結したひとつの機能の単位にすることができます。

### クラスの定義

クラスを定義するには、`class`キーワードのあとにクラス名を書き、クラスの定義を波括弧（`{}`）で囲みます。

```swift
class GameCharacter {
    var characterClass: String?
    var name: String?
    var active = false
    let id = makeRandomID()
}
```

クラスの本体には格納プロパティを書くことができます。格納プロパティは、通常の定数（`let`）や変数（`var`）と同じように定義し、同じようにふるまいます。

### インスタンス

クラス定義は設計図のようなものです。新しい型を定義し、その値がどんな形をしているかを表しますが、それ自体はインスタンスを1つも作りません。

クラスの*インスタンス*を作るには、クラス名のあとに括弧（`()`）を書いて、そのイニシャライザーを呼び出します。

```swift
let someCharacter = GameCharacter()
```

こうすると、クラス定義で指定したデフォルト値でプロパティが初期化された、新しいインスタンスが作られます。
`name`のように明示的なデフォルト値を持たないオプショナルのプロパティは、Swiftによって`nil`になります。

### プロパティへのアクセス

インスタンスのプロパティには、*ドット記法*でアクセスします。インスタンス名、ドット（`.`）、プロパティ名の順に書きます。
ドット記法は、入れ子になったプロパティにも使えます。

ドット記法を使うと値を読み出せます。また、そのプロパティが可変（`var`）であれば、新しい値を代入できます。

```swift
someCharacter.name
// => nil

someCharacter.name = "Luther"
someCharacter.name
// => "Luther"

someCharacter.id = "new id"
// Error: Cannot assign to property: 'id' is a 'let' constant
```

### メソッド

プロパティに加えて、クラスでは*メソッド*（そのクラスに関連付けられた関数）も定義できます。

メソッドは、クラスの本体の中で通常の`func`構文を使って定義します。
メソッドがプロパティを変更する場合、そのプロパティは`var`で宣言しておく必要があります。

```swift
class GameCharacter {
    var characterClass: String?
    var name: String?
    var active = false
    let id: String = makeRandomID()

    func takesDamage(_ damage: Double) {
        if damage > 100 {
            active = false
        }
    }

    func sayName() -> String {
        return "My name is \(name ?? "no one"), my class is \(characterClass ?? "undetermined")"
    }
}
```

メソッドは、プロパティと同じように、インスタンスに対してドット記法で呼び出します。

```swift
var myChar = GameCharacter()
myChar.active = true
myChar.takesDamage(200)
myChar.active
// => false
```

### `self`

クラスのすべてのインスタンスには、`self`という暗黙のプロパティがあり、これはインスタンス自身を指します。
プロパティやメソッドを参照するときにはよく省略されますが、プロパティ名とメソッドの仮引数名が同じときには、両者を区別するために`self`がよく使われます。
