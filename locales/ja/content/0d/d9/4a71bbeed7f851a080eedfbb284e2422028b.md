# 説明

あなたは、Chatbotを開発している会社で正規表現スペシャリストとして雇われました。

開発はまだごく初期の段階なので、正規表現を使ってChatbotが自然言語を理解し、生成する能力を高めるのがあなたの使命です。

## 有効なコマンドをチェックする

Chatbotは賢いだけでなく、忠実なアシスタントでもあります。

Chatbotに何かを尋ねるときは、コマンドの先頭で「**Chatbot**」という単語を言う必要があります。

キーワードが大文字でも小文字でもかまいません。ここで重要なのは、その単語の位置です。

ユーザーがコマンドを出しているのかをChatbotが認識できるようにする`isValidCommand()`関数を実装しましょう。

```javascript
isValidCommand("Chatbot, play a song from the 80's.";
// => True
isValidCommand("Hey Chatbot, where is the closest pharmacy?";
// => False
isValidCommand("CHATBOT, do you have a solution for this challenge?";
// => True
```

## 暗号化された絵文字を削除する

Chatbotは、人間が感情を表すために絵文字をどう使うのかを理解するのが苦手です。

Chatbotがユーザーからのメッセージを受け取ると、それぞれの絵文字は「_emoji_」のあとにその_id_番号が続く形で表されます。

文字列を受け取り、メッセージ全体から絵文字の暗号をすべて取り除く`removeEmoji()`メソッドを実装しましょう。

絵文字のテキストを含まない行は、そのまま返してください。

絵文字の文字列だけを取り除きます。空白を調整しようとはしないでください。

この演習では、正規表現を作るのにコンストラクター構文を使います。

```javascript
removeEmoji("I love playing videogames emoji3465 it's one of my hobbies");
// => "I love playing videogames  it's one of my hobbies"
```

## 有効な電話番号をチェックする

モバイルアプリでChatbotの機能をダウンロードすることを想定しているため、ユーザーは会話の中で電話番号を入力することが求められます。

問題は、Chatbotが特定の形式の番号しか読み取って検証できないことです。

番号が有効な場合（**正規表現**で指定された文字の並びに一致する場合）、Chatbotはユーザーに感謝し、番号を確認するメッセージで応答します。番号が無効な場合は、その電話番号は有効でないことを伝えます。

想定されている形式は次のとおりです：(+##) ###-###-###

```javascript
checkPhoneNumber('(+34) 659-771-594');
// => "Thanks! You can now download me to your phone."
checkPhoneNumber('659-771-594');
// => "Oops, it seems like I can't reach out to 659-771-594"
```

## ウェブサイトのリンクを取得する

Chatbotはとても好奇心旺盛なソフトウェアです。特定のトピックについてインターネットで検索できても、関連する情報を探せるような、クールなウェブサイトやURLをユーザーに尋ねるのが好きです。

会話の例：

- **Chatbot**: ねえusername、JavaScriptでコードを書く方法を学びたいんだけど、学べるいいウェブサイトを知らない？
- **User**: [exercism.org](http://exercism.org)からたくさん学びました

各ウェブサイトのリンクだけを含む配列を返す`getURL()`関数を実装しましょう。どんなURLでも認識できる正規表現を書くのはとても複雑になりますが、ChatbotはシンプルなURLを読めれば十分です。この演習では、URLとは`"."`で区切られた単語の並びのことです。

```javascript
getURL(
  'I learned a lot from exercism.org and developer.mozilla.org, but I found ts39.es very boring!',
);
// => ["exercism.org", "developer.mozilla.org", "ts39.es"];
```

## ユーザーに挨拶する

Chatbotと会話したすべての人のデータを保存するために、Chatbotはユーザーのプロフィールからフルネームをこの形式で取得できます：**“smith, john”**。

こうすることで、Chatbotに礼儀正しく、よい印象を与えてもらいたいと考えています。

ユーザーのフルネームが入った文字列を受け取り、文字列**“Nice to meet you, John Smith”**を返す`niceToMeetYou()`関数を書いてください。

学習のために、正規表現の**置換メソッド**を使ってこの関数を実装しましょう。

```javascript
let str = 'Smith, John';

niceToMeetYou(str);
// => "Nice to meet you, John Smith"
```
