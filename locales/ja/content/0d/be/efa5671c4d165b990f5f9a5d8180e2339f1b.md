# 概要

Elmの[カスタム型][custom-types]は、決まった数の名前付きケースを表します。それぞれの値は、名前の付いたケースのうち、ちょうど1つに対応します。他の言語や文脈では、これらは_直和型_、_判別共用体_、_タグ付き共用体_、_代数的データ型_などと呼ばれます。

判別共用体の各ケースには、必要に応じてデータを紐付けられます。また、ケースごとに持てるデータの型を変えることもできます。どのケースにもデータが紐付いていない場合、判別共用体は、他の言語で一般に_列挙型_（または_enum_）と呼ばれるものに似ています。

カスタム型は`type`キーワードで定義し、書くべき構文はごくわずかです。カスタム型はElmプログラミングにおける最も重要なテクニックの1つであり、コード上で取りうる値を、現実世界で有効な値と正確に一致させるために使います。そうすれば、不正なデータが入り込む余地がなくなり、[あり得ない状態をコードで表現できないようにできます][impossible-states]。

```elm
-- Custom Type without associated data
type Season
    = Spring
    | Summer
    | Autumn
    | Winter

-- Custom Type with associated data
type FlexibleNumber
    = Integer Int
    | Float Float
    | Invalid
```

特定のケースの値を作るには、その名前（`Spring`）を参照します。これは、同じモジュールで定義されている場合、または`import SeasonModule exposing (Season(..))`という構文でインポートした場合に使えます。完全修飾名（`Season.Spring`）を参照する方法もあります。こちらは`import SeasonModule exposing (Season)`という構文でインポートした場合に使えます。

```elm
integerTwo = Integer 2
invalid = FlexibleNumber.Invalid
```

カスタム型は、Elmのあらゆる値と同じく、_構造的等価性_を持っています。つまり、同じケースで、同じ（省略可能な）データを持つ2つの値は、等しいと見なされます。

カスタム型を扱うのに好ましい方法は、[パターンマッチング][pattern-matching]を使うことです。

```elm
let describe flexibleNumber =
    case flexibleNumber of
        Integer i ->
            "Integer: " ++ fromInt(i)

        Float f ->
            "Float: " ++ fromFloat(f)

        Invalid   ->
            "Invalid"
```
