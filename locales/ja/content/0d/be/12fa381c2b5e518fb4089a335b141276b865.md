# はじめに

関数では、1つ以上の引数にデフォルト値を宣言できます。次の関数を見てみましょう。

```elixir
def number(n \\ 13), do: "That's not my favorite"
```

コンパイルされると、Elixirは`number/0`（引数なし）と`number/1`（引数1つ）の関数定義を作成します。

複数の引数にデフォルト値が設定されている場合、デフォルト値は左から右の順に、省略された引数を埋めるように適用されます。

関数に複数の節がある場合は、デフォルト引数は、関数の節の前に置く関数ヘッド（本体を持たない関数）で定義する必要があります。

```elixir
def number(n \\ 13)
def number(n) when n < 10, do: "Dream bigger!"
def number(n) when n > 100, do: "Not that big..."
```

[kernel-guards]: https://hexdocs.pm/elixir/Kernel.html#guards
