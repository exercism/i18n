# 参考資料

* Libera Chatにある[#haskell](https://web.libera.chat/?channel=#haskell)IRCチャンネルは、「Haskell、関数型プログラミング、そしてプログラミング全般についての学習と議論を促す」ことを目的としています。このIRCチャンネルの詳細は、[チャンネルについてのHaskell Wikiのページ](https://wiki.haskell.org/IRC_channel)にあります。
* [Hoogle](https://www.haskell.org/hoogle/)はHaskellのAPI検索エンジンです。関数の名前しかわからなくても、その関数が何をするのか調べることができます。さらに面白いのは、型シグネチャーでも検索できることです。型シグネチャーが[(a -> b) -> [a] -> [b]](https://www.haskell.org/hoogle/?hoogle=%28a+-%3E+b%29+-%3E+[a]+-%3E+[b])である関数を知りたいときは、Hoogleが探し出してくれます！
* [Stack Overflow](https://stackoverflow.com/questions/tagged/haskell)では、自分の問題を検索して、すでに回答されているかどうかを確認できます。質問したり回答したりすることもできます。
* [/r/haskell](https://www.reddit.com/r/haskell)はHaskellのサブレディットです。
* [Haskellコミュニティページ](https://www.haskell.org/community/)には、Haskellを書く人たちが集まって交流しているさまざまなコミュニティへのリンクがあります。ここから、自分に合ったコミュニケーションの手段を選べます。
