# 概要

どんな値でもエラーになり得ます。`throw`（`kernel`内）はシグナルを発します。現在のワードのスタック効果は破棄され、制御は最も内側の`recover`まで巻き戻ります。

```factor
[ 0 1 / ] [ "div by zero" prepend ] recover
```

`ERROR:`は、エラータプルクラス*と*コンストラクターワードを一度に定義するパースワードです。

```factor
ERROR: not-found path ;
! defines:
!   TUPLE: not-found path ;
!   : not-found ( path -- * ) \ not-found boa throw ;
!   : not-found? ( object -- ? ) … class predicate
```

これにより、すべてのカスタムエラーに、一意のクラス、エラーを投げるための使いやすいコンストラクター、そして捕捉したエラーを判定するためのクラス述語（`name?`）が与えられます。

```factor
[ "/missing" not-found ]
[ dup not-found? [ path>> "missing: " prepend ] [ drop "other" ] if ]
recover
```

finallyのような後処理については、`continuations`の`cleanup`を参照してください。再開可能な条件については、`condition`を参照してください。
