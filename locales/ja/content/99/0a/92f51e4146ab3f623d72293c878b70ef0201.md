# 文字列補間を使いましょう

[comment]: # (この警告は、解答で文字列補間を使っていないときに表示されます)

出力する文字列に`name`仮引数を埋め込むには、[文字列補間](https://github.com/elixir-lang/elixir/blob/9cac52833e91b5ebac0d322b20e39605d8dafad9/lib/elixir/lib/string.ex#L20)を使いましょう。

- 可能であれば、ExercismのElixirトラックでは、読みやすさのために文字列の連結ではなく文字列補間を使うことが推奨されています。

```elixir
def hello(what) do
  "Hello, #{what}"
end
```

- 文字列補間の構文には、[あらゆるElixirの式](https://github.com/elixir-lang/elixir/blob/9cac52833e91b5ebac0d322b20e39605d8dafad9/lib/elixir/lib/string.ex#L30)を書くことができます

```elixir
def pluralize_apple(n) when n >= 1 do
  "apple#{if n > 1, do: "s"}"
end
```
