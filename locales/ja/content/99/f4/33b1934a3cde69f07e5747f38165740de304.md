# はじめに

リテラルとは、コードの中に直接書く固定の値のことです。
実行時に計算する必要はありません。
さまざまな形があり、それぞれのデータ型を効率よく表せるようになっています。
もっともよく使われるのは数値のリテラルですが、日付・時刻・文字列型のためのリテラル演算子もあります。
ユーザー定義リテラル演算子の使い方は、後のコンセプトで説明します。

## 数値リテラル

数値リテラルには、10進数、8進数、16進数、2進数の表記があります。
この基本は、[数値のコンセプト][numbers-concept]ですでに扱いました。

`23`、`0x50f7ba11`、`0xba5eba11`のような表記は、どれもコンパイラーに`int`として解釈されます。
一般的な`int`型は符号付きで、多くの場合、（[コンパイラーとシステムによって異なりますが][in-depth-integers]）`-2'147'483'648`から`2'147'483'647`までの範囲を持ちます。
ほとんどの場合はこれで足りるので、細かい型を気にする必要はありません。

なかには、より広い範囲や、プログラムのごく小さなメモリ使用量が必要になる場面もあります。
そのようなときは、数値リテラルに具体的な整数型を直接指定できます。

負の数が不要で、範囲を広げたい場合は、_符号なし_ 整数を表す`u`または`U`の接尾辞を使います。
さらに広い範囲が必要なら、long型とlong long型を表す`L`、あるいは`LL`を使えます。

~~~~exercism/caution
小文字の`l`の使用は認められていますが、数字の`1`と紛らわしいため、おすすめしません。
~~~~

```cpp
auto net_worth_christian_grey{2'500'000'000U}; // out of range for 32-bit integers
auto net_worth_carlisle_cullen{46'000'000'000LL}; // int and uint are not enough
```

浮動小数点数は、通常コンパイル時に`double`として解決されます。
これはよい既定の動作で、より狭い`float`型を使う場面は、上の符号なし整数の例よりも少ないです。

~~~~exercism/advanced
[C++23標準][cpp23-literals]では、`f128`や`F16`のようなリテラルで、より細かな制御ができるようになります。
一部のコンパイラーは独自のリテラルを許可しています。
GCCは`d`をリテラルとして使えますが、これは標準で想定されておらず、クロスプラットフォームの互換性を損なうおそれがあります。

[cpp23-literals]: https://en.cppreference.com/w/cpp/language/floating_literal

~~~~

```cpp
auto light_year_in_m{9.46073e+15f}; // well in the range of float
auto earth_to_edge_comoving_distance_in_nm{4.32355e+32}; // needs double type for magnitude
auto eulers_number{2.718281828459045}; // needs double type for precision
```

## 文字と文字列のリテラル

ほかのコンセプトでは、`'}'`や`'@'`のようなシングルクォートの文字リテラルをすでに使いました。

C++の`char`は、最初の128個の[ASCII文字コード][ascii-code]に限られます。
複数のASCII文字や、`‰`のような拡張ASCII文字、さらには`麗`や`ẞ`のようなUnicode文字を使うには、別の型が必要です。
前のコンセプトでは、_ダブルクォート_を使った文字列リテラルを紹介しました。`"一体どういう意味ですか。C++です"`のようなものです。
この日本語のフレーズの実際の型は、Cスタイル文字列の`const char (&)[46]`です。

文字列リテラルは、既定では有効になっていません。
_string_ リテラルの`""s`や、_string-view_ リテラルの`""sv`を使うには、関連する名前空間を使って、その使用を明示する必要があります。

```cpp
#include <string>
#include <string_view>

using namespace std::literals;

auto green_light{"무궁화 꽃 이 피었 습니다"};
// green_light type is const char (&)[36]
auto umbrella{"달고나"s};
// umbrella type is std::basic_string<char>, the same as std::string
auto il_nam{"보는 것이 하는 것보다 더 재미있을 수가 없지"sv};
// il_nam type is std::basic_string_view<char>
```

_string_view_ は、const文字列への参照と考えることができます。
