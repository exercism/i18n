# はじめに

`Promise`クラスが登場する前は、非同期のコードを扱う方法が1つしかありませんでした。それが、_コールバックパターン_です。

コールバックとは、別の関数に引数として渡される関数で、その渡した先の関数で何らかの処理が終わると呼び出されます。そうしたコールバック関数では、最初の引数として`error`を受け取るという書き方がよく使われます（下の例を見てください）。

```javascript
function callback(error, arg2, arg3) {}
```

これと非同期コードには、どんな関係があるのでしょうか？

これまでコールバックは、非同期の処理が終わったあとに、プログラム全体を止めることなく何らかの作業を行うために使われてきました。

```javascript
fetchProduct(productId, function (error, data) {
  if (error) {
    // Handle the error
  } else {
    // Do some work
  }
});
```

上の例で、`fetchProduct`関数（非同期の関数です）は、2番目の引数としてコールバックを受け取ります。商品のデータを取得したあとに何をするかは、このコールバックが決めます。
