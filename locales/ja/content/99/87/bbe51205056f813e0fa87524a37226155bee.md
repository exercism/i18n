# Kotlinのインストール

ExercismのCLIとお気に入りのテキストエディターに加えて、ExercismのKotlin演習に取り組むには、次のものが必要です。

* **Java Development Kit**（JDK）。KotlinはJavaのバイトコードにコンパイルされるため、JDKをインストールする必要があります。JDKにはJava Runtime*と*開発ツール（特にJavaコンパイラー）の両方が含まれています。
* **Gradle**。JVMベースのプロジェクト向けのビルドツールで、Kotlinをサポートしています。

お使いのオペレーティングシステムを選んでください：

* [Windows](#h-windows)
* [macOS](#h-macos)
* [Linux](#h-linux)

... または ...
* パッケージマネージャーを使いたくない場合は、[手動でインストールする](#h-install-manually)こともできます。

また、必要に応じて[Java IDE](#h-java-ides)を使うこともできます。

----

## Windows

管理者権限でコマンドプロンプトを開きます。（管理者権限でプロンプトを開く方法がわからない場合は、[Windows 8以降で管理者権限のプロンプトを開く](http://www.howtogeek.com/194041/how-to-open-the-command-prompt-as-administrator-in-windows-8.1/)（または[Windows 7](http://www.howtogeek.com/howto/windows-vista/run-a-command-as-administrator-from-the-windows-vista-run-box/)）を参照してください。）

1. Chocolateyをまだインストールしていない場合は、今すぐインストールしましょう：

      ```batchfile
        C:\Windows\system32> @powershell -NoProfile -ExecutionPolicy unrestricted -Command "iex ((new-object net.webclient).DownloadString('https://chocolatey.org/install.ps1'))" && SET PATH=%PATH%;%ALLUSERSPROFILE%\chocolatey\bin
      ```

2.  JDKをインストールします：

       ```batchfile
        C:\Windows\system32> choco install openjdk11
        ...
        C:\Windows\system32> refreshenv
        ...
       ```

管理者権限で開いたコマンドプロンプトは閉じて、新しいコマンドプロンプトを開くことをおすすめします。Exercismの演習に取り組むのに管理者権限は必要ありません。

これで、ExercismのKotlinトラックを始める準備が整いました！

始めるには、「[テストの実行](https://exercism.org/docs/tracks/kotlin/tests)」を参照してください。

## macOS

以下は、最も一般的な方法であるHomebrewを使ったインストール手順です。よろしければ、[Homebrewを使わずにmacOSへインストールする](#h-installing-on-macos-without-homebrew)こともできます。

### インストール

1. [Homebrew](http://brew.sh)をまだインストールしていない場合は、今すぐインストールしましょう：

      ```sh
        $ /usr/bin/ruby -e "$(curl -fsSL https://raw.githubusercontent.com/Homebrew/install/master/install)"
      ```

2. [Homebrew Cask](https://caskroom.github.io/)をtapします。これで、JDKのようなビルド済みのバイナリをインストールできます。

      ```
        $ brew tap adoptopenjdk/openjdk
      ```

3.  JDKをインストールします：

       ```
        $ brew install --cask adoptopenjdk11
       ```

これで、ExercismのKotlinトラックを始める準備が整いました！

始めるには、「[テストの実行](https://exercism.org/docs/tracks/kotlin/tests)」を参照してください。

## Linux

以下は、お使いのディストリビューションのパッケージマネージャーを使ったインストール手順です。よろしければ、[パッケージマネージャーを使わずにLinuxへインストールする](#h-installing-on-linux-without-a-package-manager)こともできます。

* [Debian](#h-debian)
* [その他のLinuxディストリビューション](#h-other-linux-distributions)

### Debian

Debianまたはその派生ディストリビューション（UbuntuやLinux Mintなど）を使っている場合は、APTを使います：

*（確認済み：Ubuntu 14、16、18）*

1. JDKをインストールします：

      ```sh
        $ sudo apt-get update
        $ sudo apt-get install software-properties-common
        $ sudo add-apt-repository ppa:openjdk-r/ppa
        $ sudo apt-get update
        $ sudo apt-get install openjdk-11-jdk
      ```


これで、ExercismのKotlinトラックを始める準備が整いました！

始めるには、「[テストの実行](https://exercism.org/docs/tracks/kotlin/tests)」を参照してください。

----

### その他のLinuxディストリビューション

Jdk 11をインストールする方法はたくさんありますが、最も簡単な方法の1つはSDKMANを使うことです。SDKMANを使えば、OpenJdk11を簡単にインストールできます。次の手順で進めましょう：

1. SDKMANをインストールします：
    ```sh
    $ curl -s "https://get.sdkman.io" | bash
    ``` 
    （うまくいかない場合は、こちらの手順を参照してください：https://sdkman.io/install）
1. openjdk11をインストールします：
    ```
    $ sdk install java 11.0.2-open
    ``` 

これで、ExercismのKotlinトラックを始める準備が整いました！

始めるには、「[テストの実行](https://exercism.org/docs/tracks/kotlin/tests)」を参照してください。

### Windowsに手動でインストールする

*注意：この手順は、Windowsに慣れたユーザー向けです。環境変数の設定方法がわからない、あるいはディレクトリ構造の管理に不安がある場合は、[上記](#h-windows)のChocolateyを使ったインストールを強くおすすめします。*

1. JDKをインストールします：
   1. [AdoptOpenJDK](https://adoptopenjdk.net/releases.html?variant=openjdk11#x64_win)から「**OpenJDK 11 (LTS)**」をダウンロードします（**「Install JDK」**を選びます）。
   -  インストーラーを実行します。すべて既定の設定のままでかまいません。

これで、ExercismのKotlinトラックを始める準備が整いました！

始めるには、「[テストの実行](https://exercism.org/docs/tracks/kotlin/tests)」を参照してください。

## Java IDE

Java IDEはたくさんあります。特に人気の高い3つは次のとおりです：

* [IntelliJ IDEA](https://www.jetbrains.com/idea/download/)（「Community」エディションをダウンロードします）
  - Kotlinの作者によるこのIDEは、Kotlinを最もよくサポートしています。
- [Eclipse](https://www.eclipse.org/downloads/)
- [NetBeans](https://netbeans.org/downloads/)（「Java SE」バンドルをダウンロードします）

そのほかにも[さまざまなIDE](https://en.wikibooks.org/wiki/Java_Programming/Java_IDEs)があります。
