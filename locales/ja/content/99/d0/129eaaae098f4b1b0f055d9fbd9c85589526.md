# 説明

友人のリーナスは、都市の間で貨物列車を運転する機関士です。
列車の扱いはとても得意ですが、物流やコンピューターの扱いは得意ではありません。
そこで、列車の情報を整理し、ルートのデータの間違いを直すために、あなたのプログラミングの力を借りたいと考えています。

~~~~exercism/note
この演習は、スライスやインデックス、さまざまな`dict`のメソッドを使えば簡単に解けます。
ただし、以下の各タスクは、パッキング、アンパッキング、多重代入の練習になるように解いてほしいと思っています。
~~~~

## 1. すべての貨車のリストを作成する

友人はこれまで各貨車の識別子（ID）を記録してきましたが、システムが一度に処理しなければならない貨車の数はいつもはっきりしません。
このデータを1つの`list`にまとめておけば、残りの物流プログラムはずっと扱いやすくなります。

任意の数の貨車IDを受け取る関数`get_list_of_wagons()`を実装しましょう。
それぞれのIDは正の整数です。
関数は、受け取ったIDを1つの`list`として`return`する必要があります。

```python
>>> get_list_of_wagons(1, 7, 12, 3, 14, 8, 5)
[1, 7, 12, 3, 14, 8, 5]
```

## 2. 貨車のリストを修正する

ここまでで、データとそれが物流プログラムでどのように使われるかが少しずつ見えてきたはずです。
IDシステムでは、機関車には必ず**1**というIDが割り当てられ、列車内の残りの貨車には**1**より大きいランダムなIDが割り当てられます。

友人は新しい貨車を2両、列車につなぐことになりましたが、システムを更新するのを忘れてしまいました！
そのため、列車の`list`の先頭2両を末尾に移動させないと、すべての順序が狂ってしまいます。

さらにややこしいことに、友人は、欠けていた貨車IDを含んでいるらしい2つ目の`list`をたった今見つけました。
覚えているのは、新しい貨車を移動させたあと、この2つ目の`list`にあるIDを、指定された機関車のすぐ後ろに置くべきだということだけです。

リーナスは、間違いを直してデータを一つにまとめてくれたら、とても感謝するでしょう。

貨車IDを含む2つの`list`を受け取る関数`fix_list_of_wagons()`を実装しましょう。
1つ目の`list`の最初の2つの要素を末尾に移動し、2つ目の`list`の値を機関車ID（**1**）の後ろ（_右側_）に挿入します。
関数は、変更を加えた`list`を`return`する必要があります。

```python
>>> fix_list_of_wagons([2, 5, 1, 7, 4, 12, 6, 3, 13], [3, 17, 6, 15])
[1, 3, 17, 6, 15, 7, 4, 12, 6, 3, 13, 2, 5]
```

## 3. 足りない停車駅を追加する

貨車のデータがすべて正しくなったので、リーナスは、システムのルート情報を更新してほしいと考えています。
輸送ルートでは、列車が貨物を積み下ろしするために、いくつかの駅に停車することがあります。
それぞれの輸送では、こうした中間の配送地点の数が異なることがあります。
友人は、足りない、または追加の配送情報を、システムのルート`dict`に反映してほしいと考えています。

ルートの`dict`と、その後に続く任意の数のキーワード引数を受け取る関数`add_missing_stops()`を実装しましょう。
これらの引数は、1つ以上の停車駅を持つ`dict`の形でも、任意の数の`stop_number=city`というキーワードペアでもかまいません。
関数は、追加されたすべての停車駅を順番に並べた`list`を持つ追加の`key`で更新したルート`dict`を返す必要があります。

```python
>>> add_missing_stops({"from": "New York", "to": "Miami"},
                      stop_1="Washington, DC", stop_2="Charlotte", stop_3="Atlanta",
                      stop_4="Jacksonville", stop_5="Orlando")

{"from": "New York", "to": "Miami", "stops": ["Washington, DC", "Charlotte", "Atlanta", "Jacksonville", "Orlando"]}
```

## 4. ルート情報を拡張する

リーナスはルートプログラムに取り組む中で、特定のルートに重要な詳細がいくつか欠けていることに気づきました。
最初のルート情報は`dict`として組み立てられており、友人は、足りないものがあればその`dict`を更新してほしいと考えています。
システム内のルートごとに必要な詳細は少しずつ異なるため、リーナスは汎用的な解決策をぜひとも望んでいます。

2つの`dict`を受け取る`extend_route_information()`という関数を実装しましょう。
1つ目の`dict`には、列車が走る区間の出発地と目的地の都市が入っています。

2つ目の`dict`には、列車の速度、長さ、温度など、その他のルートの詳細が入っています。
関数は、すべてのルート情報をまとめた`dict`を返す必要があります。

~~~~exercism/note
2つ目の`lists`には、例に示したものとは異なる、あるいはより多くのプロパティが含まれることがあります。
~~~~

```python
>>> extend_route_information({"from": "Berlin", "to": "Hamburg"}, {"length": "100", "speed": "50"})
{"from": "Berlin", "to": "Hamburg", "length": "100", "speed": "50"}
```

## 5. 貨車の車庫を修正する

リーナスが貨車の車庫を調査したところ、貨車が正しい順序で保管されていないことに気づきました。
各貨車にはIDのほかに、積んでいる貨物の種類に対応する色があります。
車庫では貨車は格子状に保管され、格子の各列には同じ色の貨車が並びます。

しかし、物流システムが表示する、車庫に保管する貨車の`list`では、_行_が色ごとにまとまっています。
ただし、保管用の格子が正しく機能するには、_列_が色でそろうように、各_行_に3つの異なる色が必要です。
友人は、貨車が正しく保管されるように、車両基地の`list`を整理してほしいと考えています。

3つの要素を持つ`dicts`を受け取る`fix_wagon_depot()`という関数を実装しましょう。
各`lists`の要素は、3つの`tuple`を含むサブリスト（つまり「行」）です。
各`lists`は`(<wagon ID>, <wagon color>)`のペアです。

関数は、貨車が正しい位置に入れ替わるように3つの「行」の`tuples`を並べ替えた`lists`を返す必要があります。

```python
>>> fix_wagon_depot([
                    [(2, "red"), (4, "red"), (8, "red")],
                    [(5, "blue"), (9, "blue"), (13,"blue")],
                    [(3, "orange"), (7, "orange"), (11, "orange")],
                    ])

[
[(2, "red"), (5, "blue"), (3, "orange")],
[(4, "red"), (9, "blue"), (7, "orange")],
[(8, "red"), (13,"blue"), (11, "orange")]
]
```
