## ヒント

*戻り値の型*を持つ関数は、その*型*のデータと`null`しか返せません。
しかし、関数を呼び出す側は1つのデータ型しか想定していません。

例：
```dart
String hello(int a){
    if ( a == 0){
        return "a";
    } else {
        return null;
    }
}
```
この関数が`null`やそれ以外のデータ型も返せることをより明確にするには、`dynamic`を使います。
```dart
dynamic hello(int a){
    if ( a == 0){
        return "a";
    } else {
        return null;
    }
}
