# 説明の補足

## レジスタ

| レジスタ | 用途 | 型 | 説明 |
| -------- | ------------ | ------- | ---------------------------- |
| `$a0`    | 入力        | 整数 | N、三角形の3辺の合計  |
| `$a1`    | 入出力 | アドレス | aの値                     |
| `$a2`    | 入出力 | アドレス | bの値                     |
| `$a3`    | 入出力 | アドレス | cの値                     |
| `$v0`    | 出力       | 整数 | 三つ組の個数           |
| `$t0-9`  | 一時的    | 任意     | 一時保存用        |
