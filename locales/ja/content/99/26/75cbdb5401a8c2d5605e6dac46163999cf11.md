# ローカル環境で演習を解く

自分のマシンで演習を解くと、使い慣れた環境でコードを書くことができます。

## CLIのインストール

自分のマシンで演習を解くには、まず[こちらの手順](https://exercism.org/cli-walkthrough)に従ってExercismのコマンドラインインターフェースをインストールし、設定する必要があります。

### 設定

正しくダウンロードできるように、CLIに自分が誰であるかを伝える必要があります。
トークンは[設定ページ](/settings/api_cli)で確認できます。
次に、以下のコマンドでCLIを設定します。`<your-api-token>`は設定ページの値に置き換えてください。

```
exercism configure --token=<your-api-token>
```

## 演習のダウンロード

インストールが完了したら、次のコマンドでCLIを使って演習を自分のマシンにダウンロードできます（`<exercise-slug>`と`<track-slug>`は該当する値に置き換えてください）。

```
exercism download --exercise=<exercise-slug> --track=<track-slug>
```

このコマンドを覚えておく必要はありません。演習ページに、その演習に適したコマンドが書かれています。

ダウンロードコマンドが完了すると、演習のファイルが自分のマシンにダウンロードされます。

## 演習を解く

それぞれの演習の目標は、すべてのテストに合格する実装を作ることです。
そのような実装は_解答_と呼ばれます。

その助けとして、各演習には次のファイルが含まれています。

- README.md: 自分に何が求められているかを説明する手順
- HELP.md: テストの実行方法と、行き詰まったときの助けの求め方に関する情報
- HINTS.md（任意）: 演習を解くためのヒント
- テストファイル: 解答が正しいかを検証するテストが入っています
- スタブファイル: 実装を始めるための出発点となるファイルです

トラックによっては、テストを実行するためにトラックのツールが必要とする他のファイルがあるかもしれません。

## 解答の提出

解答がすべてのテストに合格したら、次のコマンドで解答を提出できます。

```
exercism submit <implementation_file_paths>
```

このコマンドは解答をExercismのウェブサイトにアップロードし、解答ページのURLを表示します。

繰り返しになりますが、このコマンドを覚えておく必要はありません。演習の`HELP.md`ファイルに正しいコマンドが書かれています。

未完成の解答を提出することもでき、そうすると次のことができます。

- 他の人がどのように演習を解いたかを見る
- メンターに助けを求める

## CLIのその他の機能

### すべてのコマンドを確認する

利用できるコマンドの一覧を取得するには、helpサブコマンドを実行します。

```bash
exercism help
```

### トラブルシューティング

最新バージョンを使っていることを確認しましょう。

どのバージョンを使っているかを確認します。

```bash
exercism version
```

最新のリリースと照らし合わせ、自分のバージョンが最新でなければアップグレードしましょう。

アップグレードしたら、バージョンをもう一度確認しましょう。バージョンが変わっていない場合は、アップグレード後のバイナリが実行されていることを確認してください。

```bash
which exercism
```

それでも解決しない場合は、exercism/cliのGitHubリポジトリで、troubleshootコマンドの出力を添えてissueを作成してください。

```bash
exercism troubleshoot
```

[issueトラッカー](https://github.com/exercism/exercism/issues)でissueを作成できます。コミュニティが助けようとしてくれます。**issueを作成する前に、必ず[インタラクティブウォークスルー](https://exercism.org/cli-walkthrough)を一通り行っておいてください。**
