# 概要

.NETの基本クラスライブラリには、正規表現を処理するための[`Regex`][regex]クラスが用意されています。

C#と他の正規表現の方言との比較については、こちらの[記事][regex-comparison]を参照してください。

## キャプチャグループ

考慮すべき点の1つは、正規表現パターンのさまざまな部分に一致するテキストの部分を返すキャプチャグループです。キャプチャグループの扱いには慣れが必要です。詳しくはこちらの[ドキュメント][capture]を参照してください。

キャプチャグループ（`(?<capture-name>pattern)`）が関わる階層構造があることに注意してください。

- まず、0個以上のマッチの集合が返されます（テキスト内で見つかったマッチごとに1つ）。
- 各マッチには、複数のキャプチャグループが含まれます。
- 各グループには、複数のキャプチャが含まれます。

さらに：

- `Match`は`Group`から派生しています。
- `Group`は`Capture`から派生しています。

注意点：

- 最も安全な方法は、名前付きキャプチャを使うことです。
- キャプチャグループは、通常、テキスト内に現れるのと同じ順序で`Groups`コレクションに格納されます。
- `Groups[0]`はマッチ全体に関係しているようです。
- `Groups[<capture name>].Value`が、ほぼ間違いなく目的のものです。個々のキャプチャ（`Caputures[0]`以外）は、存在する場合、診断目的を意図しているようです。

## 正規表現オプション

[`RegexOptions`][regex-options]に慣れておきましょう。

通常の`IgnoreCase`オプションに加えて、複数行のテキストを一度に処理するのに便利な`MultiLine`や、逐語的文字列・文字列補間・コメントと組み合わせると非常に表現力豊かになる`IgnorePatternWhitespace`などがあります。次の例を見てください。

```csharp
const string PREAMBLE = "preamble";
const string PWTEXT = "pwtext";
const string PW = "pw";
const string SPACE = "space";
const string POSTAMBLE = "postamble";

var pattern = $@"
    ^
    (?<{PREAMBLE}>.*)          # any text
    (?<{PWTEXT}>password)      # the literal text - password
    (?<{SPACE}>\s+)
    (?<{PW}>\w*)               # the password itself
    (?<{POSTAMBLE}>.*)         # any text
    $
  ";

var rewrittenLine = $"{grps[PREAMBLE].Value}{grps[PWTEXT].Value}{grps[SPACE].Value}{mask}{grps[POSTAMBLE].Value}";
```

もう1つ注目すべきオプションは、[コンパイル済み][regex-compilation]の正規表現のための`RegexOptions.Compiled`です。
