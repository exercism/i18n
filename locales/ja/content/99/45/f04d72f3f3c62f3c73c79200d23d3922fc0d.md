# 説明

注：この演習は`need-for-speed`演習の続きです。

この演習では、さまざまな種類のラジコンカーのレースを開催します。
それぞれの車には、独自の速度とバッテリー消費の特性があります。

車は満充電（100%）のバッテリーでスタートします。
リモコンで車を走らせるたびに、車は速度と同じメートル数だけ進み、バッテリーの残り割合が消費分だけ減ります。

車のバッテリーが消費量の割合を下回ると、その車はもう走らせられません。

ラジコンカーには、2つの情報を表示するおしゃれなLEDディスプレイが付いています：

- 走行した合計距離。表示は`"Driven <METERS> meters"`。
- バッテリーの残量。表示は`"Battery at <PERCENTAGE>%"`。

レースコースにはそれぞれ距離があります。
車は、バッテリー切れを起こさずにコースを完走できるかどうかで試されます。

## 1. 車を走らせる

`Car`に`Drive`メソッドを実装して、車の速度に応じて走行したメートル数を更新し、バッテリー消費に応じてバッテリーを減らします：

```go
speed := 5
batteryDrain := 2
car := NewCar(speed, batteryDrain)
car.Drive()
// car is now Car{speed: 5, batteryDrain: 2, battery: 98, distance: 5}
```

注：走らせた結果バッテリーが0を下回る場合は、その車を走らせないようにしてください。

## 2. 走行距離を表示する

`Car`に`DisplayDistance`メソッドを実装して、LEDディスプレイに表示される距離を`string`として返します：

```go
speed := 5
batteryDrain := 2
car := NewCar(speed, batteryDrain)

fmt.Println(car.DisplayDistance())
// Output: "Driven 0 meters"
```

## 3. バッテリー残量を表示する

`Car`に`DisplayBattery`メソッドを実装して、LEDディスプレイに表示されるバッテリー残量を`string`として返します：

```go
speed := 5
batteryDrain := 2
car := NewCar(speed, batteryDrain)

fmt.Println(car.DisplayBattery())
// Output: "Battery at 100%"
```

## 4. ラジコンカーがレースを完走できるか確認する

レースを完走するには、車がレースの距離を走りきれる必要があります。
つまり、ゴールラインを越える前にバッテリーを使い切らないということです。
`CanFinish`メソッドを実装してください。このメソッドは`trackDistance int`を仮引数にとり、車がレースを完走できる場合は`true`を返し、そうでない場合は`false`を返します：

```go
speed := 5
batteryDrain := 2
car := NewCar(speed, batteryDrain)

trackDistance := 100

car.CanFinish(trackDistance)
// => true
```
