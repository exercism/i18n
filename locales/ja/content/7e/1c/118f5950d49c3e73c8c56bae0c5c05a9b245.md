# 説明

この演習では、ログの行を処理します。

それぞれのログの行は、`"[<LEVEL>]: <MESSAGE>"`という形式の文字列です。

ログレベルは、`INFO`、`WARNING`、`ERROR`の3つです。

課題は3つあります。それぞれが、スタックからログの行を1つ取り出します。

## 1. ログの行からメッセージを取得する

`message`を定義して、ログの行のメッセージを返すようにします。先頭や末尾の空白は取り除きます。

```factor
"[ERROR]: Invalid operation" message .
! => "Invalid operation"

"[WARNING]:  Disk almost full\r\n" message .
! => "Disk almost full"
```

## 2. ログの行からログレベルを取得する

`log-level`を定義して、ログの行のレベルを小文字にして返すようにします。

```factor
"[ERROR]: Invalid operation" log-level .
! => "error"
```

## 3. ログの行を整形する

`reformat`を定義して、メッセージを先頭に置き、そのあとに小文字のログレベルを括弧（`()`）で囲んで置くようにします。

```factor
"[INFO]: Operation completed" reformat .
! => "Operation completed (info)"
```

----

***注:*** この演習の文字列はすべてASCIIです。Unicodeを考慮した文字列処理は、後の演習で扱います。
