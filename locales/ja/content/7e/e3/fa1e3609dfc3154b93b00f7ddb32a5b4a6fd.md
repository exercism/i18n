# 演習

マジシャンの卵であるElyseは、修行を続けています。彼女は手品を披露するために、いくつかのカードの山を渡されます。
少しでも簡単にするため、使うカードは1から10までに限られています。

この演習では、組み込みのメソッドを使ってベクトルの内容を分析します。

## 1. カードが存在するかどうかを判定する

Elyseは、カードが山札にあるかどうか、つまり山札に特定の数値が含まれているかどうかを判定したいと考えています。

```R
card = 3;
does_stack_include_card(c(2, 3, 4, 5), card);
# => TRUE
```

## 2. カードの位置を見つける

Elyseは、山札の中でのカードの位置（インデックス）を知りたいと考えています。
カードが山札にない場合は、`-1`を返します。

```R
card = 2;
get_card_position(c(9, 7, 3, 2), card);
# => 4
```

## 3. それぞれのカードが偶数かどうかを判定する

Elyseは、すべてのカードが偶数かどうか、つまり山札のそれぞれの数値が偶数かどうかを知りたいと考えています。

```R
is_each_card_even(c(2, 4, 6, 7));
# => FALSE
```

## 4. 山札に奇数の値のカードが含まれているか確認する

Elyseは、山札に奇数があるかどうかを知りたいと考えています。

```R
does_stack_include_odd_card(c(3, 2, 6, 4, 8));
# => TRUE
```

## 5. 山札から最初の奇数のカードを取得する

Elyseは、最初に現れる奇数のカードの値を知りたいと考えています。  
山札に奇数のカードがない場合は、`-1`を返します。

```R
get_first_odd_card(c(4, 2, 8, 7, 9));
# => 7
```

## 6. 最初の偶数のカードの位置を判定する

Elyseは、最初に現れる偶数のカードの位置を知りたいと考えています。
山札に偶数のカードがない場合は、`-1`を返します。

```R
get_first_even_card_position(c(5, 2, 3, 1));
# => 2
```
