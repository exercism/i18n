# `jq`の関数

`jq`では、必要なロジックをまとめるために、**独自の関数**を定義できます。_関数_は組み込み関数とまったく同じように動きます。入力を受け取り、0個、1個、またはそれ以上の出力を返します。

## 関数を定義する

`jq`の_関数_は、次の構文で定義します。

```jq
# no arguments
def funcname: expression;

# or with arguments
def funcname(args): expression;
```

- `def`キーワードで始まります。
- 関数本体の前にコロンがあります。
- 本体は1つの式で構成されます。
- セミコロンで終わります。
- `jq`のほかの構文と同じように、読みやすさのために自由に空白を入れられます。

## 関数をどこに置くか

_関数_は、使う前に定義しておく必要があります。次のコードはエラーになります。

```jq
def A: B(10);
def B(n): n + 1;
A
# => error: B/1 is not defined
```

つまり、_関数_は`jq`コードの先頭、つまり「メイン」の式より前に置く必要があります。

### 入れ子の関数

_関数_は入れ子にできます。

```jq
def A:
    def B(n): n + 1;
    B(10)
    ;
A
# => 11
```

ここでは、`B`という_関数_は`A`の本体の中でしか見えません。

## スコープ

_関数_は、変数と入れ子の関数に対して新しい**スコープ**を導入します。

## 引数

_関数_の**引数**は、カンマではなく_セミコロン_で区切ります。
たとえば、ある数値を受け取り、それに数値を足してから、さらに数値を掛ける_関数_は次のようになります。

```jq
def add_mul(adder; multiplier): (. + adder) * multiplier;

10 | add_mul(5; 4)    # => 60
```

10 | add_mul(5, 4)

### 引数は_式_

関数の_引数_は値ではなく、フィルターです。
この意味で、引数は、ほかの言語でコールバックと呼ばれるものと同じように働きます。

`add_mul`関数を例に見てみましょう。

```jq
10 | add_mul(. + 5; . - 2)    # => 200
```

ここで何が起きているのでしょうか？

- `adder`引数には_式_`. + 5`が入ります。
  - 関数が`. + adder`を評価すると、これは`. + . + 5`になります。
  - `. == 10`なので、25と評価されます。
- 同様に、`multiplier`引数は式`. - 2`です。
  - これは8と評価されます。
  - すると、結果は`25 * 8 == 200`になります。

### 値としての引数

_引数_を変数に「実体化」したいことがあります。

```jq
def my_func(arg):
    arg as $arg
    | other stuff ...
;
```

これには省略記法があります。

```jq
def my_func($arg):
    other stuff ...
;
```

ただし、これは単なる「糖衣構文」にすぎないことに注意してください。`$`の付いていない`arg`という名前も、_関数_の中ではスコープに入っています。

## アリティ

_関数_には**アリティ**、つまり受け取る_引数_の数があります。

_関数_は、同じ名前を異なる_アリティ_で使えます。
組み込みの[`range`][man-range]関数がその例です。`range/1`、`range/2`、`range/3`がすべて共存しています。

これは、引数を介して状態を引き継ぐ再帰関数を定義するときに役立ちます。
たとえば、`map`は次のように実装する_こともできます_。

```jq
def my_map($accumulator; func):
    if length == 0
        then $accumulator
        else first as $elem | .[1:] | my_map($accumulator + [$elem | func]; func)
    end
    ;

def my_map(func):
    my_map([]; func)
    ;

[1, 2, 3, 4] | my_map(. * 10)   # => [10, 20, 30, 40]
```

## 再帰

`jq`は末尾呼び出し最適化を行いますが、それはアリティ0の関数に限られます。

## モジュール

`jq`のモジュールは、関数だけを含むファイルです。
モジュールは、[`include`][man-include]または[`import`][man-import]コマンドで`jq`プログラムに読み込みます。
