# 指示

庭に何羽の鳥が訪れたかを、この7日間記録し続けている熱心なバードウォッチャーです。

タスクは6つあり、どれも庭に訪れた鳥の数に関するものです。

## 1. 今日訪れた鳥の数を確認する

`today()`関数を実装して、今日庭に訪れた鳥の数を返します。鳥の数は日ごとに並んでいて、最初の要素が最も古い日の数、最後の要素が今日の数です。

```R
birds_per_day <- c(2, 5, 0, 7, 4, 1)
today(birds_per_day)
# => 1
```

## 2. 今日の数を増やす

`increment_todays_count()`関数を実装して、今日の数を1増やします。

```R
birds_per_day <- c(2, 5, 0, 7, 4, 1)
increment_todays_count(birds_per_day)
# => c(2, 5, 0, 7, 4, 2)
```

## 3. 鳥が訪れなかった日があるか確認する

`has_day_without_birds()`関数を実装します。鳥が1羽も庭に訪れなかった日があれば`TRUE`を返し、そうでなければ`FALSE`を返します。

```R
birds_per_day <- c(2, 5, 0, 7, 4, 1)
has_day_without_birds(birds_per_day)
# => true
```

## 4. 最初の指定日数に訪れた鳥の数を計算する

`count_for_first_days()`関数を実装します。これは、週の初めから庭に訪れた鳥の数を返しますが、数えるのは週の初めから指定された日数までに限定します。

```R
birds_per_day <- c(2, 5, 0, 7, 4, 1)
count_for_first_days(birds_per_day, 4)
# => 14
```

## 5. 忙しい日の数を計算する

日によっては、ほかの日より忙しいこともあります。忙しい日とは、庭に5羽以上の鳥が訪れた日のことです。
`busy_days()`関数を実装して、忙しい日の数を返します。

```R
birds_per_day <- c(2, 5, 0, 7, 4, 1)
busy_days(birds_per_day)
# => 2
```

## 6. この1週間の鳥の訪問数の累計を計算する

今週ここまでに、合計で何羽の鳥が訪れたのか気になりますね。
日ごとの累計を計算しましょう。

```R
running_total(c(7, 6, 5, 4, 3, 2, 1))
#> [1]  7 13 18 22 25 27 28
```

## 7. 日付の名前を混雑度順に並べ替える

鳥の訪問数は、近くの道路交通のパターン、つまり平日と週末の違いに影響されているのではないかと考えています。

日付の略称を、訪れた鳥の数の多い順、つまり_降順_に並べ替えましょう。

```R
day_names <- c("Mon", "Tue", "Wed", "Thu", "Fri", "Sat", "Sun")
birds_per_day <- c(5, 2, 4, 6, 0, 9, 8)
busy_days_of_week(birds_per_day, day_names)
#> [1] "Sat" "Sun" "Thu" "Mon" "Wed" "Tue" "Fri"
```
