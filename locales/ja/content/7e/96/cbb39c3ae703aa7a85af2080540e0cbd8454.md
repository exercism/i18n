# はじめに

## 配列とベクター

C++には、同じ型の要素を順番に並べて保持するための、さまざまなコンテナーが用意されています。サイズが固定のコンテナーには`std::array`があり、動的にサイズを変更できる`std::vector`もあります。

### 構築

配列やベクターを宣言するときは、そのコンテナーが保持する要素の型を指定する必要があります。配列にはサイズも必要です。次の例で、2つのコンテナーの初期化のしかたを確認しましょう。

```cpp
#include <array>
#include <string>

// std::array<element_type, size> variable_name {list of elements}
std::array<std::string, 3> indie_rock {"yeah", "yeah", "yeah"};
// indie_rock contains the elements "yeah" three times
```

ベクターは、さらなる成長に備えてメモリーを確保するため、通常はより多くの領域を必要としますが、サイズを指定する必要はありません。

```cpp
#include <vector>

// std::vector<element_type> variable_name {list of elements}
std::vector<int> countdown {3, 2, 1};
// countdown contains the elements 3, 2 and 1
```

> 注意：テンプレートという仕組みの裏側を今すぐ正確に知っておく必要はありません。テンプレートには、シラバスツリーのさらに下のほうに専用のコンセプトが用意されています。

### 要素へのアクセス

ベクターと配列は、要素にアクセスするための関数が共通しています。メンバー関数の`front`と`back`を使うと、コンテナーの最初と最後の要素を取得できます。ほかにも、特定の要素にアクセスするための`at`と`[]`演算子があります。

```cpp
countdown[0];
// => 3
countdown.at(2);
// => 1
countdown[1] = 4;
// countdown now contains 3, 4 and 1
indie_rock.back() = "yeahs";
// indie_rock is now "yeah", "yeah", "yeahs"
```

> 注意：コンテナーの範囲にない位置を指定すると、`[]`は未定義動作を引き起こす可能性があります。`at`関数なら例外が発生するので、長い目で見ればそのほうが扱いやすいかもしれません。

### ベクターの変更

`vector`はサイズが固定ではないので、要素を追加したり削除したりできます。そのためのよく使われる関数が`emplace_back`と`pop_back`です。

```cpp
std::vector<std::string> witches {"Holly", "Alyssa", "Shannen"};
witches.pop_back();
// Shannen is no longer with the witches
witches.emplace_back("Rose");
// Rose has joined the team
```

### 容量

コンテナーが空かどうかは、メンバー関数の`empty`で確認できます。要素の数を知りたいときは`size`を使います。
