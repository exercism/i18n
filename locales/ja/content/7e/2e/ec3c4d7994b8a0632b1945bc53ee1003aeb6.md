# `for-each`ループ入門

[`for-each`ループ](https://docs.oracle.com/javase/tutorial/java/nutsandbolts/for.html)を使うと、コレクションの要素ごとにコードのブロックを実行できます。
ドキュメントによっては（たとえばOracleのドキュメントでは）、これを拡張`for`ループと呼んでいます。

一般的な構文は次のとおりです。

```java
for(declaration: collection) {
    body;
}
```

`declaration`は、コレクションから取り出した値を保持する変数を宣言する部分です。

`collection`は、ループ変数に代入される値を保持している配列またはコレクションです。

`body`には、コレクション内の値ごとに1回実行される文を書きます。

たとえば、次のようになります。

```java
char[] vowels = {'a', 'e', 'i', 'o', 'u'};

for(char vowel: vowels) {
    System.out.println(vowel);
}
```

このコードの出力は次のとおりです。

```text
a
e
i
o
u
```

一般に、`for-each`ループは次の理由から`for`ループよりも好まれます。

- `for-each`ループは、_すべて_の値を必ず繰り返し処理します。
- `for-each`ループはより_宣言的_で、コードが_どのように_処理するかではなく、_何を_するかを伝えてくれます。
- `for-each`ループなら間違いようがありませんが、`for`ループではオフバイワンエラーが起きやすくなります（`<`と`<=`のどちらを使うか考えてみてください）。
- `for-each`ループは、インデックスを使って要素にアクセスできない型（たとえば`Set`）も含め、すべてのコレクション型で使えます。
