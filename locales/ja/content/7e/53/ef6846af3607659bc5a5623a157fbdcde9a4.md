# 三項演算子

三項演算子は、単純な`if/else`文を短く書く方法です。
`if/else`文の分岐が2つだけ、つまり条件が真のときの分岐と偽のときの分岐しかないなら、三項演算子で書き直すことができます。

三項演算子では、`?`と`:`という2つの記号を組み合わせて条件を分けます。
```ruby
condition ? true_branch : false_branch
```

`?`の左側のコードが条件で、右側には`:`で区切られた2つの分岐が入ります。
条件が_真_なら、`:`の_左_側のコードが実行されます。
条件が_偽_なら、`:`の_右_側のコードが実行されます。

たとえば、次のコードは、

```ruby
if traffic_light == 'green'
  cross_the_road
else
  wait
end
```

このように書き直せます。

```ruby
traffic_light == 'green' ? cross_the_road : wait
```
