# はじめに

JavaScriptでは、_テンプレート文字列_を使うと、文字列の中に式を埋め込むことができます。これは文字列補間とも呼ばれます。この機能は、組み込みのグローバルオブジェクト[`String`][string-reference]の機能を拡張したものです。

JavaScriptでテンプレート文字列を作るには、テキストをバッククォートで囲みます。テンプレート文字列では、テキストに改行やその他の特殊文字を含められるだけでなく、変数やその他の式を埋め込むこともできます。

```javascript
const num1 = 1;
const num2 = 2;

`Adding ${num1} and ${num2} gives ${num1 + num2}.`;
// => Adding 1 and 2 gives 3.
```

上の例では、バッククォート（<code>\`\`</code>）を使ってテンプレート文字列を表しています。`${...}`は、置き換えに使われるプレースホルダーです。文字列以外の型は、_暗黙的に_文字列に変換されます。この話題は[型変換][type-conversion-concept]のコンセプトで扱っています。テンプレート文字列では、あらゆる種類の式を使うことができます。

```javascript
const track = 'JavaScript';

`This track on exercism.org is ${track.toUpperCase()}.`;
// => This track on exercism.org is JAVASCRIPT.
```

文字列を複数行にわたって整形したいときは：

```javascript
`This is an example of using template
strings to accomplish multiple
lines`;
```

置き換えの機能を使えば、出力する文字列をどうするかを決めるロジックを組み込むこともできます。ロジックを扱う方法の1つは、[三項演算子][ternary-operator]を使うことです。これは、`if/else`と同じ条件分岐の機能を、少し違う書き方で実現します。

テンプレート文字列の構文にロジックを組み込むには：

```javascript
const grade = 95;

`You have ${grade > 90 ? 'passed' : 'failed'} the exam.`;
// => You have passed the exam.
```
