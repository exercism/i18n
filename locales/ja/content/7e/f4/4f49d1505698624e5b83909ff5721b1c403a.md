# はじめに

Rubyには標準ライブラリ（よく「stdlib」と略されます）が付属しています。日付やjson、ネットワークなどを扱うためのクラスの集まりです。コードを扱いやすくするための便利な機能も用意されています。

`OpenStruct`は標準ライブラリの一部で、`Hash`から手軽にオブジェクトを作ることができます。`Hash`のキーでアクセスする代わりに、`OpenStruct`ではメソッドを使って値の取得や設定ができます。

標準ライブラリやその他のライブラリのクラスを使うときは、`require`メソッドでそのクラスを読み込む必要があります。

```ruby
require 'ostruct'

attributes = { name: "Jeremy Walker", age: 21, location: "Nomadic" }
person = OpenStruct.new(attributes)

person.name
#=> Jeremy Walker

person.location
#=> Nomadic

# Update the age
person.age = 35

# It sets correctly
person.age
#=> 35
```

このおまけの利点として、ブロック構文を使うときにショートカットを利用できます。ブロックが1つのメソッドを呼び出すだけの場合は、そのブロックを`&:`とメソッド名に置き換えられます。たとえば、次の2行は同じ意味です。

```ruby
people.sum { |person| person.age }
people.sum(&:age)
```
