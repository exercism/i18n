# 手順

波止場で貨物箱を積み直す甲板員です。各タスクは1つのワードで、その本体ではシャッフルワードだけを使います。算術は使いません。

## 1. 上から2つの箱を入れ替える

`swap-crates`ワードを定義します。スタックから箱を2つ取り出し、それらを逆の順序でスタックに残します。

```factor
1 2 swap-crates .s
! 2
! 1
```

## 2. こぼれた箱を取り除く

`clear-spill`ワードを定義します。スタックから箱を3つ取り出し、下の2つを残して、一番上の箱は捨てます。

```factor
1 2 3 clear-spill .s
! 1
! 2
```

## 3. 下にある箱のコピーを残す

`peek-under`ワードを定義します。スタックから箱を2つ取り出し、下の箱のコピーを一番上に置いて、それらをスタックに残します。

```factor
1 2 peek-under .s
! 1
! 2
! 1
```

## 4. デッキを整える

`tidy-deck`ワードを定義します。スタックから箱を3つ、`x y z`の順に取り出し、`z z y`を残します。つまり、一番下の箱は捨て、一番上の箱のコピー2つを真ん中の箱の下に残します。

```factor
1 2 3 tidy-deck .s
! 3
! 3
! 2
```
