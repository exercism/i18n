# はじめに

Rには集合専用のデータ型はなく、代わりにさまざまな関数を使って、ベクトルに対して同じような操作を行います。

`%in%`演算子は、集合に含まれるかどうかを判定します。

```R
2 %in% 1:10 # TRUE
12 %in% 1:10 # FALSE
```

関連する関数には、`unique`（重複を取り除く）をはじめ、2つの集合を操作する`union()`、`intersect()`、`setdiff()`、`setequal()`があります。

```R
> set_1 <- c("a", "b", "c", "b", "a")
> unique(set_1) # deduplicate
[1] "a" "b" "c"

> set_2 <- c('a', "c", "d")
> union(set_1, set_2) # values in either set
[1] "a" "b" "c" "d"

> intersect(set_1, set_2) # values in both sets
[1] "a" "c"

> setdiff(set_1, set_2) # values in set_1 but not set_2
[1] "b"

> setdiff(set_2, set_1) # values in set_2 but not set_1
[1] "d"

setequal(set_1, c("c", "b", "a", "b")) # are elements the same after deduplication?
[1] TRUE
```

いずれの場合も、`set_1`と`set_2`は変わりません。
