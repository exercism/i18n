# はじめに

Javaでは、`null`リテラルは値が存在しないことを表すために使います。

Javaのプリミティブ型はすべてデフォルト値を持つため、決して`null`にはなりません。慣習として、小文字で始まります。例えば`int`です。

参照型はオブジェクトのメモリアドレスを保持し、`null`という値を持つことができます。参照型は一般的に大文字で始まります。例えば`String`です。

プリミティブ型の変数に`null`を代入しようとすると、コンパイル時エラーになります。その変数には常に、代入された型のプリミティブ値が入るからです。

```java
//Throws compile time error stating the required type is int, but null was provided
int number = null;
```

参照型の変数に`null`を代入しても、参照型の変数は`null`を許容するため、コンパイル時エラーにはなりません。

```java
//No error will occur as the String variable str is nullable
String str = null;
```
