# はじめに

`Bool`型は、言語の基本的な構成要素の1つです。
何かが真偽のどちらであるかを、それぞれ`True`と`False`という値で表すための型です。

真偽値は、`&&`の「AND」演算子と`||`の「OR」演算子で組み合わせたり、`not`関数で否定したりできます。

真偽値は、特定の条件が満たされたときだけ実行される分岐をコードに作るときにも、とても便利です。
Elmでは、`if-then-else`式を使って、次のように書きます。

```elm
if someCondition || (someOtherCondition && anotherCondition) then
    doSomething
else
    doSomethingElse
```
