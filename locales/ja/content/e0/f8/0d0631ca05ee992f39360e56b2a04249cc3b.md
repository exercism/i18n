# 例

```riscvasm
.equ FRAME_SIZE, 16

.text
.global is_triple
```

ドットで始まる行は_ディレクティブ_です。プロセッサーではなく、アセンブラーに対する指示です。
`.equ`は、数値16に`FRAME_SIZE`という名前を付けます。
`.text`は、その後に続くものがコードであることを示します。
`.global`は、ラベル`is_triple`をこのファイルの外から見えるようにするので、他のコードから呼び出せます。
`.globl`という書き方を見ることもありますが、意味は同じです。

```riscvasm
/* bool is_triple(unsigned a, unsigned b, unsigned c); */
is_triple:
```

`is_triple`は、`a² + b² = c²`かどうかを調べ、そうであれば1を、そうでなければ0を返します。
たとえば、`(6, 8, 10)`は1になります。`36 + 64 = 100`だからです。
ラベル`is_triple`は、関数が始まる場所を示します。
この関数は、`a`、`b`、`c`をレジスター`a0`、`a1`、`a2`に入れて呼び出されます。

```riscvasm
        addi    sp, sp, -FRAME_SIZE
        sw      ra, 12(sp)      /* save the return address */
        sw      a1, 8(sp)       /* save b */
        sw      a2, 4(sp)       /* save c */
```

レジスター`ra`には_戻りアドレス_、つまり処理が終わったときに戻る、呼び出し元の場所が入っています。
`call`はそのたびに`ra`を上書きするので、まず_スタック_に保存します。
スタックは小さいアドレスの方向へ、下に向かって伸びるので、スタックポインター`sp`から16を引くと、16バイトを確保できます。
（`sp`は常に16の倍数でなければなりません。）
呼び出す関数は`a`レジスターを書き換えてよいことになっているので、`b`と`c`も保存します。

```riscvasm
        call    square          /* a0 = a * a */
        sw      a0, 0(sp)       /* save a * a */
```

`a`はすでに`a0`にあり、`square`はそこに入力を期待しています。
`call`は`ra`に次の命令のアドレスを設定して`square`へジャンプし、`square`は結果を`a0`に返します。

```riscvasm
        lw      a0, 8(sp)       /* a0 = b */
        call    square          /* a0 = b * b */
        lw      t0, 0(sp)       /* t0 = a * a */
        add     t0, t0, a0      /* t0 = a * a + b * b */
        sw      t0, 0(sp)       /* save a * a + b * b */
```

スタックから`b`を読み戻し、2乗して、`a * a`に足します。

```riscvasm
        lw      a0, 4(sp)       /* a0 = c */
        call    square          /* a0 = c * c */
        lw      t0, 0(sp)       /* t0 = a * a + b * b */
        sub     a0, t0, a0      /* a0 = a * a + b * b - c * c */
        seqz    a0, a0          /* a0 = 1 if that is zero, otherwise 0 */
```

差がゼロになるのは、ちょうど`a² + b² = c²`のときです。
`seqz`（"set if equal to zero"、つまりゼロと等しければ設定する）は、それを1または0に変えます。

```riscvasm
        lw      ra, 12(sp)      /* restore the return address */
        addi    sp, sp, FRAME_SIZE
        ret
```

`ra`を復元し、16バイトのスタックを返します。
その後`ret`が`ra`のアドレスへジャンプし、呼び出し元に戻ります。

```riscvasm
/* unsigned square(unsigned n); */
square:
        mul     a0, a0, a0      /* n * n */
        ret
```

`square`は他の関数を呼び出さないので、`ra`はそのまま保たれ、保存するものはありません。
`is_triple`だけが使うので、`.global`は付けていません。
