# ヒント

## 全般

- 最初の6つの整数引数は、`rdi`、`rsi`、`rdx`、`rcx`、`r8`、`r9`のレジスタで関数に渡されます。
- メモリ内のアドレスは64ビット（8バイト）の値です。

## 1. 各アイテムのエントリーを作成する

- 最初の6つの整数引数は、`rdi`、`rsi`、`rdx`、`rcx`、`r8`、`r9`のレジスタで関数に渡されます。
- メモリ内のアドレスは64ビット（8バイト）の値です。
- 7番目以降の整数引数はすべてスタックで渡され、最初のものは`rsp + 8`にあります。
- 追加の引数の数はカテゴリーの数と同じです。カテゴリーの数は`r9`で渡されます。
- ループを使って追加の引数を1つずつ加えることもできますし、[movsq][movs]と[rep][rep]を組み合わせて使うこともできます。

## 2. アイテムの月間リスト用のスペースを確保する

- 最初の6つの整数引数は、`rdi`、`rsi`、`rdx`、`rcx`、`r8`、`r9`のレジスタで関数に渡されます。
- メモリ内のアドレスは64ビット（8バイト）の値です。
- メモリ割り当て関数を呼び出したあとにそのバイト列をクリアするには、配列のサイズを知っておく必要があります。
- 外部関数を呼び出すと、その関数は任意の_呼び出し元が保存すべきレジスタ_の値を書き換える可能性があります。
- [push][push]を使うか、`rsp`を直接操作することで、レジスタの値をスタックに保存できます。
- `push`によるものも含め、`rsp`への変更は、[pop][pop]を使うか`rsp`を直接変更することで、関数から戻る前に元に戻さなければなりません。

## 3. 月間リストにアイテムを挿入する

- 最初の6つの整数引数は、`rdi`、`rsi`、`rdx`、`rcx`、`r8`、`r9`のレジスタで関数に渡されます。
- メモリ内のアドレスは64ビット（8バイト）の値です。
- レジスタに収まらない値は、スタックに置いて関数に渡されます。
- アイテム1つ分のエントリーは120バイトの領域を占め、これはレジスタの最大サイズ（8バイト）よりずっと大きいです。
- スタックで渡される引数は、`rsp + 8`から始まるアドレスにあります。
- ループを使って値をコピー先のメモリ位置に加えることもできますし、[movsb][movs]と[rep][rep]を組み合わせて使うこともできます。

## 4. アイテムを出力する

- 最初の6つの整数引数は、`rdi`、`rsi`、`rdx`、`rcx`、`r8`、`r9`のレジスタで関数に渡されます。
- メモリ内のアドレスは64ビット（8バイト）の値です。
- 冒頭の文字列は省略できます。その場合は、代わりに`0`を指定して出力用の関数を呼び出してください。
- 冒頭の文字列を出力用の関数に渡す場合、その文字列は最大50文字のASCII文字でなければならず、NUL終端（値`0`）もこれに含まれます。
- 関数を呼び出すときはいつでも、7番目以降の引数用にスタックのスペースを確保する必要があります。
- System V ABIでは、関数を呼び出す前にスタックを16バイト境界に整列させる必要があると定められており、これは特に外部関数で重要です。
- リスト内のアイテム1つ分のエントリーは120バイトの領域を占めます。
