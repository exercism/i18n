# ヒント

## 全体

- Pythonのドキュメントの[制御フローツール][control flow tools]と、Real Pythonの[条件分岐][real python conditionals]のチュートリアルは、まずここから始めるのがおすすめです。
- Pythonのドキュメントの[ブール演算][boolean operations]は`bools`の良い復習になります。Real Pythonの[ブール値][python booleans]のチュートリアルも同じく役立ちます。
- Pythonのドキュメントの[比較][comparisons]と[比較の例][python comparisons examples]は、比較の良い復習になります。

## 1. 臨界かどうかを確認する

- 比較演算子（[比較の復習][comparisons review]）とブール演算（[concept:python/bools]()）は、組み合わせて条件分岐と一緒に使うことができます。
- 条件式は`True`または`False`に評価される必要があります。
- すべての条件テストが`False`を返したときに実行されるコードブロックには、`else`を使えます。

  ```python
     >>> item = 'blue'
     >>> item_2 = 'green'
     
     >>>  if len(item) >= 3 and len(item_2) < 5:
            print('Both pass the test!')
          elif len(item) >= 3 or len(item_2) < 5:
            print('One passes the test!')
          else:
            print('None pass the test!')
    ...
    One passes the test!
  ```

## 2. 出力の範囲を求める

- 比較演算子は、組み合わせて条件分岐と一緒に使うことができます。
- `elif`文は、判断の「分岐」として好きなだけ使えます。
- それぞれの「分岐」に個別の`return`を書くこともできますが、リントツールには「行儀が悪い」と見なされるかもしれません。
- リンターが文句を言う場合は、分岐の出力を共通の変数に代入してから、その変数を`return`することを検討してみましょう。
