# 説明

この演習では、インターネットフォーラムのユーザーアカウントの権限を確認します。このフォーラムが扱う権限は、次の3つです。

- Read
- Write
- Delete

アカウントには3つの種類があり、それぞれデフォルトの権限が異なります。

- ゲスト：投稿を読むことができます。
- ユーザー：投稿を読むことと書くことができます。
- モデレーター：投稿を読むこと、書くこと、削除することができ、すべての権限を持ちます。

個々の権限は変更できることもあります。たとえば、ゲストアカウントに投稿の書き込み権限を追加したり、逆にアカウントからすべての権限を剥奪して、どの権限も持たない状態にすることもできます。

## 1. アカウントの種類ごとのデフォルト権限を取得する

まず、3つのアカウントの種類を表す`AccountType`列挙型を定義します。値は`Guest`、`User`、`Moderator`です。

次に、3つの権限の種類を表す`Permission`列挙型を定義します。`Read`、`Write`、`Delete`に加えて、特別な値が2つあります。すべての権限を持つことを表す`All`と、どの権限も持たないことを表す`None`です。

続いて、(_static_)`Permissions.Default()`メソッドを実装し、特定のアカウントの種類に対するデフォルトの権限を返すようにします。

```csharp
Permissions.Default(AccountType.Guest)
// => Permission.Read
```

## 2. 権限を付与する

(_static_)`Permissions.Grant()`メソッドを実装します。このメソッドは権限を付与（追加）します。

```csharp
Permissions.Grant(current: Permission.None, grant: Permission.Read)
// => Permission.Read
```

## 3. 権限を剥奪する

(_static_)`Permissions.Revoke()`メソッドを実装します。このメソッドは権限を剥奪（削除）します。

```csharp
Permissions.Revoke(current: Permission.Read, revoke: Permission.Read)
// => Permission.None
```

## 4. 権限を確認する

(_static_)`Permissions.Check()`メソッドを実装します。このメソッドは、現在のアカウントの権限を受け取り、指定された権限がそのアカウントに許可されているかどうかを確認します。

```csharp
Permissions.Check(current: Permission.Write, check: Permission.Read)
// => false
```
