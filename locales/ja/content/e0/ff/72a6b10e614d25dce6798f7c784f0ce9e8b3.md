# はじめに

`for`ループを使うと、条件を満たすまでコードを繰り返し実行できます。

```csharp
for (int i = 0; i < 5; i++)
{
    System.Console.Write(i);
}

// => 01234
```

`for`ループは、4つの部分から成ります。

1. 初期化子：ループに入る前に1回だけ実行されます。通常は、ループの中で使う変数を定義するために使います。
2. 条件：各繰り返しの前に実行されます。これが`true`と評価される間、ループの実行が続きます。
3. 反復子：各繰り返しの後に実行されます。通常は、ループ変数を変更する（多くの場合、インクリメントまたはデクリメントする）ために使います。
4. 本体：各繰り返しで実行されるコードです。
