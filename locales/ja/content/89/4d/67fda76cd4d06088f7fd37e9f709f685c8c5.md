# ヒント

## 全般

- レコード更新の構文がほとんどの用途をうまくカバーしてくれるので、Rocではレンズはあまり使われません。たとえば、次のような入れ子のレコードを考えてみましょう。

  ```roc
  bob = { hair: { color: Brown, length: Long }, mouth: Smiling, height: 6.0 }
  ```

  では、ボブの髪を切ってみましょう。

  ```roc
  new_bob = { ..bob, hair: { ..bob.hair, length: Short } }
  ```

  レンズは必要ありません！

- とはいえ、Rocでレンズがほとんど使われないとしても、HaskellやScalaといった他の言語ではよく使われます。なので、Rocでレンズをどう実装するのか気になるかもしれません。パラメーター化された型や、関数を含むレコードといったRocの高度な機能を練習するのにもぴったりです。実際、Rocでレンズを表す方法のひとつがこちらです。

  ```roc
  Lens(whole, part) := {
      get : whole -> part,
      set : whole, part -> whole,
  }
  ```

  これはパラメーター化された型で、`whole`と`part`にはどんな型でも入ります。`whole`はふつうレコードで、`part`はどんなフィールドの型でもかまいません。`get`フィールドには、与えられた`whole`の特定の`part`を返す関数が入っています。一方、`set`フィールドには、与えられた`whole`のコピーを返す関数が入っていて、そのコピーでは特定の`part`だけが与えられた`part`に置き換わります。

  たとえば、人の髪を取得したり設定したりするレンズは次のとおりです。

  ```roc
  hair_lens = {
      get: |person| person.hair,
      set: |person, hair| { ..person, hair },
  }
  ```

  このレンズを使うと、次のようにボブの髪に焦点を合わせられます。

  ```roc
  bob_hair = bob |> hair_lens.get
  ```

  そして、次のようにボブの髪を変えられます。

  ```roc
  new_hair = { ..bob.hair, length: Short }
  new_bob = bob |> (hair_lens.set)(new_hair)
  ```

- 注意：`hair_lens.set`を囲む括弧は必須です。これがないと、Rocは`hair_lens`の型の中から`set`という名前の関数を探してしまいます。

- レンズは、組み合わせて使うようになると特に便利になります。深く入れ子になった部分を取得したり設定したりできるようになるからです。これは、次のような関数を実装すれば実現できます。

  ```roc
  compose : Lens(outer, inner), Lens(inner, part) -> Lens(outer, part)
  ```

  この関数を実装すれば、次のように髪の長さのレンズを作れます。

  ```roc
  length_lens = {
      get: |hair| hair.length,
      set: |hair, length| { ..hair, length },
  }
  hair_length_lens = compose(hair_lens, length_lens)

  ```

  これで、ボブの髪をもう一度切れます。

  ```roc
  set_hair_length = hair_length_lens.set
  new_bob = bob |> set_hair_length(Short)
  ```

- 入れ子になった部分に好きな変換を適用できる関数を実装したくなるかもしれません。

  ```roc
  over : Lens(whole, part), whole, (part -> part) -> whole
  ```

  実装できたら、`over`を次のように使えます。

  ```roc
  cut_hair = |current_length| match current_length {
      Long => Short
      Short => Bald
      Bald => Bald
  }
  new_bob = hair_length_lens |> over(bob, cut_hair)
  ```

- まずはRocのレコード更新の構文でテストをすべて通してから、代わりにレンズを使ってみることをおすすめします。
