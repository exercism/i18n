# 条件分岐について

## 比較演算子

[比較演算子][operators]は、多くの言語とよく似ていますが、いくつかの拡張があります。

等しいかどうかを調べる演算子は、`==`（等しい）と`!=`（等しくない）です。

```Kotlin
val txt = "abc"
txt == "abc" // => true
txt != "abc" // => false
```

さらに、`===`と`!==`は[「参照の等価性」][referential-equality]を調べる演算子です。`a === b`が成り立つのは、`a`と`b`が同じオブジェクトを指しているときだけです。
このことは、シラバスの後のほうで学ぶと、よりしっくりくるはずです。

大小を比べる演算子も、一般的なものです。

```Kotlin
1 < 3 // => true
3 > 3 // => false
3 <= 3 // => true
4 >= 3 // => true
```

## `if`による分岐

これが、[`if`式][if-else]の完全な形です。

```Kotlin
if (conditional1) {
//    something...
} else if (conditional2) {
//    something...
} else {
//    something...
}
```

- 条件を囲む括弧（`()`）は必須です。
- 条件は、真偽値の`true`または`false`に評価される必要があります。
  Kotlinには、一部の言語にあるような「truthy」や「falsy」という考え方はありません。
- 波括弧（`{}`）は、式が1つだけなら省略できます。
- `else if`と`else`はどちらも省略でき、`else if`ブロックは複数書けます。

`if`式は、値を「選ぶ」ために使うこともできます。

```Kotlin
val number = 100000
val description = if (number > 100) "number is over 100" else "number is less than 100"
// => description = "number is over 100"
```

## 代わりの書き方は？

意図的に、KotlinにはJavaにある三項演算子`? :`は_ありません_。代わりに、簡潔な`if ... else`の形が好まれます。

```Kotlin
val result = if (isOk) goodValue else badValue

return if (isOK) goodValue else badValue
```

Rubyとは違い、簡潔な`if ... else`の形は、*常に*`else`が必要で、そのためガード節としては使えません。

```kotlin
return 42 if (isOk)
// Syntax error: Unexpected tokens (use ';' to separate expressions on the same line).
// Syntax error: Expecting an expression.

return if (isOk) true
// 'if' must have both main and 'else' branches when used as an expression.
```

Kotlinでは、`if`は値を返す[_式_][expression]です。Javaのように[_文_][statement]ではありません。

後のコンセプトで見ていきますが、Kotlinには強力な[`when`][when]構文があり、長く連なる`else if`をパターンマッチングで置き換えることを目的としています。
