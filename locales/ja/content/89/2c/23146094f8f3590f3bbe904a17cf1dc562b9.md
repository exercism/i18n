# 説明の補足

## Tclの`apply`コマンド

テストケースは紛らわしく見えるかもしれません。
実装が求められているのは、次のとおりです。

```tcl
set myList {alpha beta gamma delta}
listOps::filter $myList {{word} {expr {[string length $word] == 4}}
```

なぜ最後の引数にはそんなにたくさんの波括弧があるのでしょうか？

`proc`コマンドは次のように定義されていることを思い出してください。

```tcl
proc procName argList body
```

Tclには、`apply`コマンドがあります。

```tcl
apply func ?arg1 arg2 ...?
```

この「func」は、2つの要素からなる配列`{argList body}`で、本質的には無名のproc（または「lambda」）です。
`apply`コマンドはその無名のprocを呼び出し、必要な引数を渡します。

例として、次はどれも同じ意味です。

```tcl
# using proc
proc myReverse {str} {return [string reverse $str]}
puts [myReverse "Hello, World!"]

# using apply
puts [apply {{str} {string reverse $str}} "Hello, World!"]

# or, store the func in a variable
set func {{str} {string reverse $str}}
puts [apply $func "Hello, World!"]
```

`apply`を使うと、コードのブロックを渡しやすくなります。

参考：[`apply`](https://tcl.tk/man/tcl8.6/TclCmd/apply.htm)、[`proc`](https://tcl.tk/man/tcl8.6/TclCmd/proc.htm)。
