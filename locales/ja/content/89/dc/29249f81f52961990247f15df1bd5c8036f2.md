# 文字列

文字列は、引用符で囲まれた一連の文字です。
シングルクォートとダブルクォートのどちらも使えます。

```php
<?php

$where = "Spain";
$what = 'rain';
```

## 文字列内での変数展開

ダブルクォートで囲んだ文字列では、スコープ内にある変数を参照すると、その値が文字列に埋め込まれます。

```php
<?php

$answer = 42;
$expanded = "The answer to life, the universe, and everything is $answer"; 
```

## 文字エンコーディングのサポート

歴史的に、PHPの文字列関数はASCII文字しかサポートしておらず、現代のUnicodeエンコーディングには対応していませんでした。
ASCII文字はそれぞれ1バイトですが、Unicode文字は1〜4バイトの長さになります。
Unicode文字列を安全に操作する必要がある場合は、従来の関数の[マルチバイト版][multi-byte-fns]を参照してください。

```php
<?php

$byte_length = strlen('😃'); // => 4
$string_length = mb_strlen('😃'); // => 1
```

[multi-byte-fns]: https://www.php.net/manual/en/ref.mbstring.php
