# はじめに

JavaScriptでは、配列は長さが決まっていないリストのような構造で、プリミティブでもオブジェクトでも、どんな型でも入れることができます。型が混ざっていてもかまいません。

配列を作るには、角括弧（`[]`）の中に要素を並べます。
配列から値を読み出すには、識別子のあとに角括弧でインデックスを指定します。
配列のインデックスは0から始まります。

たとえば、次のとおりです。

```javascript
const numbers = [1, 'two', 3, 'four'];
numbers[2];
// => 3
```

配列に入っている要素の数を取得するには、`length`プロパティを使います。

```javascript
const numbers = [1, 'two', 3, 'four'];
numbers.length;
// => 4
```

配列の要素を変更するには、そのインデックスに値を代入します。

```javascript
const numbers = [1, 'two', 3, 'four'];
numbers[0] = 'one';
numbers;
// => ['one', 'two', 3, 'four']
```

## メソッド

すべてのArrayオブジェクトで使える[メソッド][array_methods]の中には、配列に要素を追加したり、配列から要素を削除したりできるものがあります。

### push

> `push()`メソッドは、1つ以上の要素を配列の末尾に追加し、配列の新しい長さを返します。[^1]

```javascript
const numbers = [1, 'two', 3, 'four'];
numbers.push(5); // => 5
numbers;
// => [1, 'two', 3, 'four', 5]
```

### pop

> `pop()`メソッドは、配列の最後の要素を削除し、その要素を返します。
> このメソッドは配列の長さを変更します。[^2]

```javascript
const numbers = [1, 'two', 3, 'four'];
numbers.pop(); // => four
numbers;
// => [1, 'two', 3]
```

### shift

> `shift()`メソッドは、配列の最初の要素を削除し、削除したその要素を返します。
> このメソッドは配列の長さを変更します。[^3]

```javascript
const numbers = [1, 'two', 3, 'four'];
numbers.shift(); // => 1
numbers;
// => ['two', 3, 'four']
```

### unshift

> unshift()メソッドは、1つ以上の要素を配列の先頭に追加し、配列の新しい長さを返します。[^4]

```javascript
const numbers = [1, 'two', 3, 'four'];
numbers.unshift('one'); // => 5
numbers;
// => ['one', 1, 'two', 3, 'four']
```

### splice

> splice()メソッドは、既存の要素を削除したり置き換えたり、新しい要素を追加したりして、配列の内容をその場で変更します。このメソッドは、削除された要素を含む配列を返します。[^5]

```javascript
const numbers = [1, 'two', 3, 'four'];
numbers.splice(2, 1, 'one'); // => [3]
numbers;
// => [1, 'two', 'one', 'four']
```
