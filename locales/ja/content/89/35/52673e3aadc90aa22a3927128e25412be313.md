# セットアップ

このトラックでは、テストスイートを実行し、ベストプラクティスを守るために、2つのツールを使います：

1. [vader.vim](https://github.com/junegunn/vader.vim)
2. [vint](https://github.com/Kuniwak/vint)

## テストの実行

1. [vader.vim](https://github.com/junegunn/vader.vim/#installation)をインストールします。
1. 解答を開きます：
    ```
    $ vim exercise.vim
    ```
1. 現在のファイルを`source`して、そのグローバル関数をVimから使えるようにします：
    ```
    :source %
    ```
1. テストを実行します：
    ```
    :Vader exercise.vader
    ```

パスは環境によって異なる場合があります。

ここまでの手順を手軽に実行できるショートカットがほしい場合は、これを`vimrc`に書きます：

```vim
function! s:exercism_tests()
  if expand('%:e') == 'vim'
    let testfile = printf('%s/%s.vader', expand('%:p:h'),
          \ tr(expand('%:p:h:t'), '-', '_'))
    if !filereadable(testfile)
      echoerr 'File does not exist: '. testfile
      return
    endif
    source %
    execute 'Vader' testfile
  else
    let sourcefile = printf('%s/%s.vim', expand('%:p:h'),
          \ tr(expand('%:p:h:t'), '-', '_'))
    if !filereadable(sourcefile)
      echoerr 'File does not exist: '. sourcefile
      return
    endif
    execute 'source' sourcefile
    Vader
  endif
endfunction

autocmd BufRead *.{vader,vim}
      \ command! -buffer Test call s:exercism_tests()
```

その後、演習のディレクトリにある`.vim`ファイルか`.vader`ファイルを開いて、`:Test`コマンドを実行します。

## Vimファイルのlint

1. [vint](https://github.com/Kuniwak/vint#quick-start)をインストールします。
1. すべてのVimファイルを再帰的にlintします：
    ```
    $ vint .
    ```

Vim scriptトラックの詳細については、[ヘルプページ](https://exercism.org/languages/vimscript)を参照してください。
