# 概要

## 用語

C++の関数は、いくつかのコンセプトですでに使ったり書いたりしてきました。
そろそろ技術的な話に入りましょう。
次のコードは、よく使われる用語をまとめたものです。
C++は空白を無視するので、ここでは書式を変えて、それぞれの要素を1行ずつに分けてあります。

```cpp
// Function declaration:
bool                                              // Return type
admin_detected(string user, string password)      // Type signature
;                                                 // Don't forget the ';' for the declaration

// Function definition:
bool                                              // Return type
admin_detected                                    // Function name
(string user, string password)                    // Parameter list
{ return user == "admin" && password == "1234"; } // Function body
```
~~~~exercism/advanced
宣言は、その名前・戻り値の型・仮引数リストを持つ関数があることをコンパイラーに伝えるメモのようなものです。
定義がないと、コードは動きません。
宣言は必須ではありませんが、関数をその定義より前に使う場合には必要になります。
宣言は、循環参照のような問題を解決し、インターフェースと実装を分けるのにも役立ちます。
~~~~

## `const`修飾子

値を初期化したあとに変更できないようにしたいことがあります。
C++では、定数であることを示す修飾子として`const`キーワードを使います。

```cpp
const int number_of_dragon_balls{7};
number_of_dragon_balls--; // compilation error
```

~~~~exercism/note
定数は _UPPER_SNAKE_CASE_ で書かれることがよくあります。
ほかに決まった慣習がなければ、この書き方はマクロのために取っておくことをおすすめします。
~~~~

一度設定した定数を変更しようとすると、コードはコンパイルされません。
これは意図しない変更を防ぐだけでなく、コンパイラーによる最適化の可能性も広げます。
また、ある部分が影響を受けないとわかっていれば、人間にとってもコードを考えやすくなります。

`const`は関数の仮引数につける修飾子としても使えます。

```cpp
string guess_number(const int& secret, const int& guess) {
    if (secret < guess) return "lower.";
    if (secret > guess) return "higher.";
    return "exact!";
}
```

`const`参照を関数に渡すと、その値が変更されないことを保証できます。
コピーにコストがかかるオブジェクト（長めの文字列など）では、`const`参照をよく見かけます。
`const`修飾子の3つ目の使い道は、クラスのインスタンスを変更しないメンバー関数です。

```cpp
class Stubborn {
    public:
    Stubborn(string reply) {
        response = reply;
    }
    string answer(const string& question) const {
        if (question.length() == 0) { return "";}
        return response;
    }
    private:
    string response{};
};
```

`Stubborn`のメンバー関数`answer`は、仮引数に`const string&`参照を使っています。
これにより、関数に渡された元のオブジェクトからのコピーを避けられます。

## 関数のオーバーロード

仮引数リストが異なれば、複数の関数が同じ名前を持てます。
これを関数のオーバーロードと呼び、よく似た処理を行う関数によく使われます。

戻り値の型を除いた関数のヘッダーが、その関数の__型シグネチャ__です。
型シグネチャが変われば、それは別の関数になります。

`play_sound`の例には、さまざまな場面に対応する6つのオーバーロードがあります。

```cpp
// different argument types:
void play_sound(char note);         // C, D, E, ..., B
void play_sound(string solfege);    // do, re, mi, ..., ti
void play_sound(int jianpu);        // 1, 2, 3, ..., 7

// different number of arguments:
void play_sound(string solfege, double duration);

// different qualifiers:
void play_sound(vector<string>& solfege);
void play_sound(const vector<string>& solfege);
```

~~~~exercism/advanced
型シグネチャは、関数の名前、仮引数の数、それぞれの型、そして修飾子によって決まります（仮引数の名前は含まれません）。
戻り値の型は型シグネチャには含まれず、戻り値の型だけが異なる2つの関数を書くとコンパイルエラーになります。
どちらを使うべきか判別できないため、コンパイラーがエラーを出します。
~~~~

## デフォルト引数

仮引数がとても多くなり、その呼び出しの多くで同じ値を使う関数もあります。
そうした呼び出しの繰り返しは、デフォルト引数で避けられます。

```cpp
void record_new_horse_birth(string name, int weight, string color="brown-ish", string dam="Alruccaba", string sire="Poseidon");

record_new_horse_birth("Urban Sea", 130); // color will be brown, dam "Alruccabam", sire "Poseidon"
record_new_horse_birth("Highclere", 175, "off-white", "Fall Aspen");   // sire will be "Poseidon"
```

関数の宣言は定義より先に読まれることが多いので、デフォルト引数は宣言で設定するのがよいでしょう。
ある仮引数にデフォルト値がある場合、その右側の仮引数にもすべてデフォルト値が必要です。
複雑な関数のオーバーロードは、デフォルト引数を使ってより少ない関数に整理し、保守しやすくできることがあります。
