# イントロダクション

## モジュール

これまで見てきた演習は、すべてクラスを使ってきました。
状態を持つオブジェクトを作る手間が不要なこともあります。そんなときは、代わりに`module`を使います。

モジュールはクラスとよく似ています（実際、オブジェクト階層では`Module`は`Class`の親です）。主な違いは、インスタンスメソッドではなくクラスメソッドを使うことです。
クラスメソッドは`self.`で始まり、モジュールに対して直接呼び出します。

たとえば、次のようになります。

```ruby
module Speaker
  def self.echo(something)
    "#{something} ... #{something}"
  end
end

Speaker.echo("Hello")   #=> "Hello ... Hello"
```

## ループ

Rubyでループを書く方法はいくつかありますが、一般にはループよりもイテレーションを使うことが多いため、おそらく最もよく見かけるループは`while`ループでしょう。

```ruby
counter = 0

while counter < 5
  counter += 1
end
```

その兄弟分である`until`も使えます。

```ruby
counter = 0

until counter == 5
  counter += 1
end
```
