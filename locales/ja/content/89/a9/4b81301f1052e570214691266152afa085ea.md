# 概要

Goの関数とメソッドは、複数の戻り値を返すことができます：

```go
func GetCard() (Card, error) { ... }
```

すべての戻り値は、順番に代入し、カンマで区切る必要があります：

```go
card, err := GetCard()
```

## ブランク識別子

代入の各位置では、変数を宣言します。
宣言した変数を使わないことは、Goでは許されていません。
その戻り値をスキップするには、変数名の代わりにブランク識別子`_`を使います。

```go
card, _ := GetCard() // error intentionally ignored
_, err := GetCard()  // card ignored, only checking for error
```

## エラー処理

`error`は組み込みのインターフェースです。
エラーが`nil`であればエラーは発生しなかったことを意味し、`nil`以外の値であれば何か問題が起きたことを意味します。
慣例として、失敗する可能性のある関数は、最後の戻り値として`error`を返すべきです。
呼び出し元は、他の戻り値を使う前に、それを確認する必要があります：

```go
card, err := GetCard()
if err != nil {
    // unsafe to use card here
    return err
}
// safe to use card here
```

## カンマOKイディオム

2値代入のパターンは、`error`の処理以外にも現れます。
マップの参照、型アサーション、チャネルの受信はすべて、成功またはデータの有無を示すために、慣例で`ok`と名付けられた2つ目の真偽値を使います：

```go
m := map[string]int{"a": 1}
v, ok := m["a"] // ok is true
v, ok = m["z"]  // ok is false
```

```go
var i interface{} = "hello"
v, ok := i.(string) // ok is true
v, ok = i.(int)     // ok is false
```

```go
v, ok := <-ch // ok is false if ch is closed and empty
```

## 名前付き戻り値

戻り値には、関数シグネチャで名前を付けることもできます。
これらの変数は、関数本体の中でアクセスできます。

```go
func divide(a, b int) (quotient, remainder int) {
    quotient = a / b
    remainder = a % b
    return quotient, remainder
}
```

名前付き戻り値は、それぞれの戻り値の位置が何を意味するかを示します。
これらは、値を書かずに済ませる裸のreturnと組み合わせて使うこともできます。
裸のreturnは、名前付き変数の現在の値を暗黙的に返します：

```go
func split(sum int) (x, y int) {
    x = sum * 4 / 9
    y = sum - x
    return
}
```

長い関数では、何が返されているのか分かりにくいため、裸のreturnは可読性を損ないがちです。
関数が短く、シグネチャが常に目に入る場合を除いて、明示的な戻り値を優先しましょう。
