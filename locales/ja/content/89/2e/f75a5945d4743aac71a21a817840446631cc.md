# 概要

C#では、タプルはデータをまとめるデータ構造で、任意の型のフィールドを2つ以上保持します。

タプルは通常、2つ以上の式をコンマで区切って、括弧（`()`）の中に並べて作ります。

```csharp
string boast = "All you need to know";
bool success = !string.IsNullOrWhiteSpace(boast);
(bool, int, string) tripple = (success, 42, boast);
```

ほかの式と同じように、タプルはさまざまな場面で使えます。[代入][tuple-assignment]で使ったり、フィールドや変数の初期化、メソッドの[戻り値][tuple-return-values]、引数としての受け渡しなどです。タプルの[等価性][tuple-equality]も判定できます。タプルの等価性については`pattern-matching-tuples`演習で詳しく説明しますが、念のため下のコードにも例を挙げておきます。

フィールドはドット構文で取り出します。既定では、最初のフィールドは`Item1`、2番目は`Item2`、というようになります。既定以外の名前については、後述の_名前付け_で説明します。

タプルはジェネリックの型パラメーターとしても使えます。例：`IList<(bool, string)>`

さらに、タプルは「分解」に対応しています。これは後述します。また、パターンマッチングでも使えますが、これについては後の演習で扱います。

```csharp
// initialization
(int, int, int) vertices = (90, 45, 45);

// assignment
vertices = (60, 60, 60);

//  return value
(bool, int) GetSameOrBigger(int num1, int num2)
{
    return (num1 == num2, num1 > num2 ? num1 : num2);
}

// method argument
int Add((int, int) operands)
{
    return operands.Item1 + operands.Item2;
}

// equality testing
var estimateA = (42, 1729);
var estimateB = (2*3*7, 7*13*19);
bool result = estimateA == estimateB;
// => result == true
```

この[入門][tuples]では、タプルの定義と使い方を紹介します。

## 名前付け

`Item1`のようなフィールド名は、読みやすいコードにはなりません。フィールドに名前を付ける方法は3つあります。a) 型の宣言で付ける、b) タプルを生成する式で付ける、c) [タプル射影初期化子][tuple-projection-initializers]を使う（ここでは例を示しません）。

```csharp
// name items in declaration
(bool success, string message) results = (true, "well done!");
bool mySuccess = results.success;
string myMessaage = results.message;

// name items in creating expression
var results2 = (success: true, message: "well done!");
bool mySuccess2 = results2.success;
string myMessaage2 = results2.message;
```

名前付けの仕組みで気の利いたことをしようとしないでください。これは実際には単なる糖衣構文です。たとえば、別のタプルから代入するときに、タプルの名前を変えることはできません。

## 分解

タプルからフィールドを取り出して複数の変数に代入し、必要に応じて初期化できると便利なことがあります。この仕組みは[分解][tuple-deconstruction]と呼ばれます。（自分で定義したオブジェクトにも適用できます。詳しくは[こちら][udt-deconstruction]を参照してください）。

```csharp
var goodNumbers = (42, 3.142, 1729);
(int ultimateQuestion, var π, var ramanujan) = goodNumbers;
return ultimateQuestion;
// => 42
```

## フィールドへの代入

タプルのフィールドには、個別に代入できます。ただし、C#では不変性が重視される傾向にあるため、このような使い方はあまり一般的ではありません。タプルは不変であるかのように使われることがよくありますが、もちろん不変ではありません。

```csharp
(int, string) tpl;
tpl.Item1 = 1;
tpl.Item2 = "bad";
tpl.Item2 = "even worse";
// => (1, "even worse";
```

## 背景

ここで説明しているタプルを、[`System.Tuple`][system-tuple]と混同しないでください。`System.Tuple`は、おそらくレガシーなコードベースでしか見かけません。

`System.ValueTuple`となると、話はもう少し紛らわしくなります。[`System.ValueTuple`][system-value-tuple]の最後のオーバーロードの[ドキュメント][system-value-tuple]には、「値タプル型は、C#のタプルを支えるランタイム実装を提供します」と書かれています。ここでいう「値タプル型」とは、`System.ValueTuple`のジェネリックオーバーロードを指します。そして「タプル」とは、この演習で扱ってきたものを指します。つまり、`System.ValueTuple`はタプルの実装の詳細である、と言っているわけです。これは、ほとんどの人にとって、ほとんどの場合、あまり興味のない話でしょう。残念ながら、「タプル」に関するドキュメントの多くには、Microsoft自身のものも含めて、`System.ValueTuple`への参照がふんだんに散りばめられています。こうした記述は、さらっと読み飛ばしてしまっておそらく問題ありません。

## そのほかの用途と制限

パターンマッチングは、タプルの特に生産的な使い方です。これについては、後の演習で扱います。

タプルを使うと、ほかにもちょっとした書き方ができます。

- 多重代入（特にコンストラクター内）。例：`(this.field1, this.field2) = (arg1, arg2);`
- 値の入れ替えや再利用。例：`(a, b) = (b, a);`
- 配列の中で`struct`の代わりに使う
- 辞書のキーや、セットの要素として使う
- LINQで使う。（LINQは後の演習で扱います）。

ドキュメントでは、タプルは軽量な仕組みだと説明されています。それがタプルをうまく使う鍵です。タプルをクラスや`struct`の代わりに使うと、フィールドの型や、場合によっては名前を、くどいほど繰り返すことになりかねません。これは特に、メソッドの引数やコレクションのジェネリック引数として使う場合に当てはまります。

多重代入や入れ替えのような技は、賢く使い分けるのが一番です。

等価と非等価以外の関係演算はサポートされていません。

タプルが言語に導入されたのは比較的最近（C# 7）のことです。そのため、タプルを使いたい場合は、コードベースが言語の[バージョン][language-version]7以降を使っていることを確認してください。
