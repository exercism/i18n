# 説明

ハイペリアという国は、さまざまな問題を抱えています。とりわけ深刻なのが、制御不能なインフレです。中央銀行での仕事を引き受けるため、はるばる呼び寄せられました。

## 1. 紙幣の額面を出力する

中央銀行は、内部の管理を簡単にするために、それぞれの額面を2つの部分に分けました。比較的変化しない_ベース_と、すべての額面で共通の_倍率_です。この_倍率_は、年に一度でも、週に一度でも、毎日でも変更できます。

紙幣に印刷される額面は、_ベース_と_倍率_の積になります。

この仕組みが導入された時点で、最小の紙幣の額面はすでに10,000,000でした。下の表は、この仕組みが最初に導入されたときの状況（最初の3つの額面）を示しています。それからというもの、状況はさらに悪化し、倍率だけでなくベースまで変わるようになりました。

| ベース  | 倍率  | 額面         |
| ------- | ---------- | ------------ |
| 10,000  | 1,000      | 10,000,000   |
| 50,000  | 1,000      | 50,000,000   |
| 100,000 | 1,000      | 100,000,000  |
| ...     | 1,000      | ...          |

まとめると、_額面_ = _ベース_ \* _倍率_ ということです。

`CentralBank.DisplayDenomination()`メソッドを実装してください。このメソッドはベースと倍率を受け取り、その積（ベース \* 倍率）を文字列として返します。返される数値の文字列は整形しないでください。

乗算でオーバーフローが発生した場合は、文字列`"*** Too Big ***"`を返してください。

```csharp
CentralBank.DisplayDenomination(10000L, 1000L);
// => "10000000"
CentralBank.DisplayDenomination(long.MaxValue / 2, 10000L);
// => "*** Too Big ***"
```

## 2. ハイペリアのGDPを表示する

中央銀行は、内部でGDPを記録するときにも同じ倍率の考え方を使っています。統計はベースの額面で記録され、その後、倍率を使って引き上げられます。

`CentralBank.DisplayGDP()`メソッドを実装してください。このメソッドはベースのGDPと現在の倍率を受け取り、GDPを文字列として返します。

GDPを計算できない場合は、`"*** Too Big ***"`が返されます。

```csharp
CentralBank.DisplayGDP(555f, 10000f);
// => "5550000"
CentralBank.DisplayGDP(float.MaxValue / 2, 10000f);
// => "*** Too Big ***"
```

## 3. 主任エコノミストの給与を表示する

銀行の上司は、給与支払いのときに問題が起きないようにしたいと考えています。

`CentralBank.DisplayChiefEconomistSalary()`メソッドを実装してください。このメソッドは、ベース単位で表された給与（上記と同じ）と倍率を受け取り、その積を含む文字列を返します。

給与を計算できない場合は、`"*** Much Too Big ***"`が返されます。

```csharp
CentralBank.DisplayChiefEconomistSalary(555000m, 10000m);
// => "5550000000"
CentralBank.DisplayChiefEconomistSalary(555000m, decimal.MaxValue / 2L);
// => "*** Much Too Big ***"
```
