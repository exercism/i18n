# テスト

OCamlはコンパイル言語なので、テストを実行する前に、解答とテストコードをコンパイルする必要があります。
ビルドには[`dune`](https://dune.build/)を使います。
各フォルダーには、ビルド方法を指定するduneファイルと、duneに処理を任せるMakefileがあります。

テストをコンパイルして実行するには、演習のフォルダーで次のように入力するだけです。

```bash
make
```
