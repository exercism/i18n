# 概要

*素集合*（Union-Findとも呼ばれるデータ構造）は、値の集まりを重なりのないグループに分割して保持し、「この2つの値は同じグループにあるか？」という1つの問いに素早く答えてくれます。[`disjoint-sets`][disjoint-sets]というボキャブラリに入っています。

`<disjoint-set>`は空の構造を作ります。値、つまり*アトム*は、`add-atom`で1つずつ追加するか、`add-atoms`でまとめて追加します。追加されたアトムは、それぞれ自分だけのグループから始まります。

```
<disjoint-set> ( -- disjoint-set )
add-atom       ( atom disjoint-set -- )
add-atoms      ( seq disjoint-set -- )
```

```factor
USING: disjoint-sets ;

<disjoint-set>
{ "a" "b" "c" "d" } over add-atoms   ! four singleton groups
```

`equate`は、2つのアトムが属するグループを併合します。併合は推移的です。`a`を`b`と、`b`を`c`と`equate`すると、3つとも同じグループに入ります。

```
equate ( atom1 atom2 disjoint-set -- )
```

各グループは、*代表元*と呼ばれる1つのメンバーによって識別されます。`representative`はその代表元を返し、2つのアトムは、それぞれの代表元が等しいときに限り同じグループに属します。この判定を直接行うのが`equiv?`です。

```
representative ( atom disjoint-set -- representative )
equiv?         ( atom1 atom2 disjoint-set -- ? )
```

```factor
USING: disjoint-sets ;

<disjoint-set>
{ "a" "b" "c" "d" } over add-atoms
"a" "b" pick equate
"b" "c" pick equate
"a" "c" pick equiv? .          ! => t   (transitively connected)
"a" "d" pick equiv? .          ! => f
"a" over representative
"c" pick representative = .     ! => t   (same representative)
```

グループの代表元としてどのアトムが選ばれるかは、内部の詳細です。グループのどのメンバーでもよく、グループの併合にともなって変わることもあります。特定のアトムが代表元であることに依存してはいけません。同じグループにある2つのアトムの代表元が一致することだけを頼りにしてください。

`disjoint-set-members`は、追加されたすべてのアトムを返します。

この構造は*ミュータブル*です。`equate`と`add-atom`は、新しい素集合を返すのではなく、その場で素集合を書き換えます。実装にはランクによる併合と経路圧縮が使われているため、`equate`や`representative`を長く続けて呼び出しても、1回あたりは実質的に定数時間で済みます。
