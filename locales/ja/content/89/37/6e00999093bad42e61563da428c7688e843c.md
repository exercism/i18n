# 概要

Swiftの[クロージャ][closures]は、自己完結したコードのまとまりで、引数を渡すとその計算が実行され、値を返します。クロージャはまた、自分の環境から値をキャプチャして、計算の中で使います。自己完結しているので、ほかの値と同じようにプログラムの中を受け渡ったり、定数や変数に代入したりできます。

クロージャはSwiftの関数とよく似ていると感じるかもしれません。実際そのとおりで、それにはちゃんとした理由があります。Swiftの関数はクロージャの特別な場合で、名前を持つことが必要で、少し違う構文で定義します。

Swiftの関数は技術的にはクロージャですが、Swiftで「クロージャ」と言うときは[クロージャ式][closure-expressions]を指します。クロージャ式は、仮引数のリスト、戻り値の型、キーワード`in`、クロージャの本体をこの順に書き、全体を波括弧で囲みます。

```swift
{ (a: Double, b: Double) -> Double in
  return (a + b) / 2.0
}
```

これは型`(Double, Double) -> Double`のクロージャ式を定義しています。この型の関数と同じように、適切な型の引数を与えることで実行できます。

```swift
{ (a: Double, b: Double) -> Double in
  return (a + b) / 2.0
}(10.0, 15.0)
// returns 12.5
```

実行するたびに完全なクロージャ式を書くのはあまり便利ではないので、クロージャには、Swiftのほかの値と同じように名前を付けて代入できます。そうすれば、その名前を引数に適用して呼び出せます。

```swift
let mean = { (a: Double, b: Double) -> Double in
  (a + b) / 2.0
}

mean(13.0, 100.0)
// returns 56.5
```

上で見たように、クロージャは通常の関数と同じく、本体が単一の式であればキーワード`return`を省略できます。

クロージャは、高階関数と組み合わせて使われることが最も多く、引数として渡されたり、結果として返されたりします。

```swift
[11, 75, 3, 99, 53].contains(where: { (x: Int) -> Bool in x > 100 })
// returns false

["apple", "ball", "carrot"].sorted(by: { (s1: String, s2: String) -> Bool in s1.count < s2.count })
// returns ["ball", "apple", "carrot"]

func makeAdder(base: Int) -> (Int) -> Int {
  { (x: Int) -> Int in base + x }
}
```
