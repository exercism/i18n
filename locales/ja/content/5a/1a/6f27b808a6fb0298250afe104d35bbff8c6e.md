# ABAPトラックをクローンする

## 前提条件

1. ABAPシステムのリリース7.4以上
2. abapGit v1.115.0以上
3. ABAPパッケージ、プログラム、クラスを実装する権限

## abapGitのインストール

すべての演習を含むABAPトラックは、abapGitリポジトリとして実装されています。トラックを自分のシステムにクローンするには、まずabapGitをインストールする必要があります。

1. [https://github.com/abapGit/abapGit](https://github.com/abapGit/abapGit)にアクセスします
2. `zabapgit_standalone.prog.abap`ファイルをダウンロードします
3. 自分のシステムにプログラム`zabapgit_standalone`を作成します
4. `zabapgit_standalone.prog.abap`のソースをプログラム`zabapgit_standalone`にアップロードします
5. プログラムを有効化します

## Exercism ABAPトラックのインストール

### オンラインリポジトリ

システムがインターネットに接続されていて、GitHub.comにアクセスできる場合は、この方法を使います（推奨）。

1. abapGitを実行します

![abapGitのオンラインリポジトリ](https://github.com/exercism/abap/blob/main/docs/clone_01.png?raw=true)

2. 「Repository Overview」で「New Online」を選択します
3. 次の値を入力します
- URL: `https://github.com/exercism/abap`
- Package: `$exer`
- Display Name: `Exercism - ABAP Track`

注意：`$exercism`のようにパッケージ名が長すぎると、リポジトリをインポートしようとしたときにエラーが発生します。上記のように、名前は短くしておきましょう。

![abapGitのオンラインリポジトリ](https://github.com/exercism/abap/blob/main/docs/clone_02.png?raw=true)

4. 「Create Online Repository」を選択します。ステータスが「A」のオブジェクトの一覧が表示されます。

![abapGitのオンラインリポジトリ](https://github.com/exercism/abap/blob/main/docs/clone_03.png?raw=true)

5. 「Pull」を選択して、すべてのオブジェクトを自分のシステムにクローンします。完了すると、すべてのオブジェクトのステータスが空になります

![abapGitのオンラインリポジトリ](https://github.com/exercism/abap/blob/main/docs/clone_04.png?raw=true)

### オフラインリポジトリ

システムがインターネットに接続されて*いない*場合は、この方法を使います。

1. [https://github.com/exercism/abap](https://github.com/exercism/abap)にアクセスします
2. リポジトリのZIPファイルをダウンロードします

![abapGitのオフラインリポジトリ](https://github.com/exercism/abap/blob/main/docs/clone_10.png?raw=true)

3. abapGitを実行します
4. 「Repository Overview」で「New Offline」を選択します
5. 次の値を入力します
- Repository Name: `Exercism - ABAP Track`
- Package: `$exer`

![abapGitのオフラインリポジトリ](https://github.com/exercism/abap/blob/main/docs/clone_11.png?raw=true)

6. 「Create Offline Repository」を選択します

![abapGitのオフラインリポジトリ](https://github.com/exercism/abap/blob/main/docs/clone_12.png?raw=true)

7. 「Import ZIP」を選択し、ダウンロードしたZIPファイルを選びます。ステータスが「A」のオブジェクトの一覧が表示されます。

![abapGitのオフラインリポジトリ](https://github.com/exercism/abap/blob/main/docs/clone_13.png?raw=true)

8. 「Pull ZIP」を選択して、すべてのオブジェクトを自分のシステムにクローンします。完了すると、すべてのオブジェクトのステータスが空になります

![abapGitのオフラインリポジトリ](https://github.com/exercism/abap/blob/main/docs/clone_14.png?raw=true)

## Exercism ABAPトラックのアンインストール

次の手順で、すべてのオブジェクトをシステムから削除できます。

1. abapGitを実行します
2. `Execism - ABAP Track`リポジトリに移動します
3. 「Advanced > Uninstall」を選択します
4. すべてのオブジェクトとリポジトリの削除を確定します

## トラブルシューティング

- 接続に問題がある場合は、[SSL Setup](https://docs.abapgit.org/user-guide/setup/ssl-setup.html)を確認してください。
- エラー`Package $EXERCISM_DIFFERENCE-OF-SQUARES exceeds ABAP 30-characters name limit`が発生した場合は、`$exer`のような短いパッケージ名を使ってください。
- ABAPシステムにプルしたあと、一部のファイルで差分が表示されることがあります。ファイル終端文字やバイトオーダーマークに関連する差分は無視してかまいません。
