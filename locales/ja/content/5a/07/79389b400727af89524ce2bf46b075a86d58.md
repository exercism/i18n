# 概要

`if`文のほかにも、条件に応じて処理を実行する`switch`文があります。1つの変数を複数の値と比較する必要があるときに使います。Haxeでは、ある変数xに対する`switch`文は次のような構文になります。

```haxe
var a = 2;

switch (a) {
  case 0:
    trace("a is 0");
  case 1:
    trace("a is 1");
  case 2:
    trace("a is 2");
  default:
    trace("a is something else");
}

// a is 2
```

`default`ケースは、ほかのどのケースにも一致しないときに実行されます。
