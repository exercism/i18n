# はじめに

ブロックとは、複数の文と宣言を1つの構文的な単位にまとめたものです。
ブロックは、波括弧（`{}`）で定義されることがよくありますが、必ずしもそうとは限りません。
ブロックは、関数の中に入れ子にすることも、他のブロックの中に入れ子にすることもできます。

関数は、どこかブロックに似た働きをします。
関数の中で定義された変数の識別子は、その関数の外からは見えません。これは、ブロックの中で定義された変数の識別子が、そのブロックの外からは見えないのと同じです。
2つの関数にある2つの変数には、同じ名前を付けられます。2つの関数は互いの内部を見ることができないからです。これは、2つのブロックにある2つの変数に同じ名前を付けられるのと同じで、2つのブロックは互いの内部を見ることができません。
ただし、関数とブロックは同じものではありません。
関数を別の関数の中に入れ子にすることはできませんが、ブロックは別のブロックの中に入れ子にできます。

次の例では、`number`は`main`関数の中で定義されています。
`flag`は、`main`関数の中に入れ子になった`if`ブロックの中で定義されています。
ブロックの中で定義された変数は、そのブロックの中でだけ有効です。
そのため、このコードをコンパイルしようとすると、コンパイルエラーになります。

```c
#include <stdio.h>

int main() {

  int number = 1;

  if (number == 1) {
      int flag = 1;
      printf("%d", flag);
  }

  // this line generates a compilation error
  // error: 'flag' undeclared (first use in this function)
  printf("%d", flag);
    
}
```

`flag`は関数の前の方で確かに使われているので、このエラーメッセージは紛らわしく感じられるかもしれません。
しかし、`flag`は関数の中のブロックで定義されています。
内側のブロックは、外側の関数にある変数`number`を「見る」ことができますが、外側の関数は、内側のブロックで定義された`flag`変数を「見る」ことができません。
実行がそのブロックを抜けると、`flag`変数は自動的に破棄され、プログラムからは利用できなくなります。
`main`関数が`flag`という識別子を初めて目にするのは、最後の`printf`文においてです。
最後の`printf`文を取り除けば、プログラムはコンパイルでき、実行すると`1`を出力します。
これは、`flag`変数が、最初の`printf`文を含むブロックの中で有効だからです。

`C99`以降では、1行の`if`文、`for`文、`while`文、`do`文もブロックとみなされます。
次の例では、`i`は波括弧の中で定義されていませんが、`for`文で定義されたブロックの中にだけ存在し、外側の`main`関数からは見えません。

```c
#include <stdio.h>

int main() {

    for (int i = 0, j = 11; i < j; i+=2)
        printf("%d", i);

    // this line generates a compilation error
    // error: 'i' undeclared (first use in this function)
    printf("%d", i);
    
}
```

最後の`printf`文を取り除けば、プログラムはコンパイルでき、実行すると`0 2 4 6 8 10 `を出力します。
GoやRustのようないくつかの言語では、1行の条件文やループ文もブロックを構成すると明示されています。
これらの言語では、そのような1行の文も波括弧で囲むことが求められます。
