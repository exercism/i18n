# はじめに

## コンストラクター

_クラス_のインスタンスを作るには、`new`演算子を使ってその_コンストラクター_を呼び出します。コンストラクターは、新しく作られたインスタンスを初期化することを目的とした特別な種類のメソッドです。コンストラクターは普通のメソッドと似ていますが、戻り値の型がなく、名前がクラス名と一致します。

```java
class Library {
    private int books;

    public Library() {
        // Initialize the books field
        this.books = 10;
    }
}

// This will call the constructor
var library = new Library();
```

普通のメソッドと同じように、コンストラクターは仮引数を持つことができます。コンストラクターの仮引数は、ふつうはあとで参照するために（privateな）フィールドとして保存されるか、一度きりの計算に使われます。実引数は、普通のメソッドに渡すときと同じように、コンストラクターにも渡すことができます。

```java
class Building {
    private int numberOfStories;
    private int totalHeight;

    public Building(int numberOfStories, double storyHeight) {
        this.numberOfStories = numberOfStories;
        this.totalHeight = numberOfStories * storyHeight;
    }
}

// Call a constructor with two arguments
var largeBuilding = new Building(55, 6.2);
```
