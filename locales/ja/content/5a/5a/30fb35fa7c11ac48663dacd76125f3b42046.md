# 概要

関数は、1つ以上の引数に[デフォルト値][default-arguments]を宣言できます。

```elixir
def number(n \\ 13), do: "That's not my favorite"
```

- 上の例をコンパイルすると、Elixirは`number/0`（引数なし）と`number/1`（引数1つ）の関数定義を作成します。
- デフォルト値を持つ引数が複数ある場合、デフォルト値は左から右へ順に適用され、足りない引数を埋めます。
- 関数に複数の節がある場合は、デフォルト引数用の[関数ヘッダー][function-header]を書く必要があります。
- デフォルト値には、どんな式でも使えます。
- 無名関数はデフォルト引数を持てません。

```elixir
def guess(number \\ 5)
def guess(number) when number != 5, do: false
def guess(number) when number == 5, do: true

guess()
# => true
```
