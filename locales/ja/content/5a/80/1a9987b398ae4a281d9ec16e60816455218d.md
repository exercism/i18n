# はじめに

Elixirには、_Bitwiseモジュール_にあるビットを扱うための多くの関数が用意されています。

- `band/2`: ビット単位のAND
- `bsl/2`: ビット単位の左シフト
- `bsr/2`: ビット単位の右シフト
- `bxor/2`: ビット単位のXOR
- `bor/2`: ビット単位のOR
- `bnot/1`: ビット単位のNOT

ビット単位の関数の使い方の例を見てみましょう。

```elixir
Bitwise.bsl(1, 3)
# => 8
```

ビット単位の関数はすべて、整数に対してのみ動作します。

Elixirのバージョン1.9以前を使っている場合は、_Bitwise_モジュールを使うために、モジュール定義の先頭で`require Bitwise`を呼び出す必要があります。
