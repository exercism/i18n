# 概要

ファイルを扱うための関数は、[`File`][file]モジュールで提供されています。

ファイル全体を読み込むには、[`File.read/1`][file-read]を使います。ファイルに書き込むには、[`File.write/2`][file-write]を使います。

このモジュールには、コピー、削除、名前の変更などを行うファイル関数も用意されています。こうした関数の名前は、UNIXの同等のものと似ています。たとえば、次のとおりです。

- [`File.cp/3`][file-cp] - ファイルをコピーします。
- [`File.rm/1`][file-rm] - ファイルを削除します。
- [`File.rename/2`][file-rename] - ファイルの名前を変更したり、移動したりします。
- [`File.mkdir/1`][file-mkdir] - ディレクトリを作成します。
- [`File.cwd/0`][file-cwd] - 現在の作業ディレクトリを取得します。

`File`モジュールのここで挙げた関数には、エラータプルを返す代わりにエラーを発生させる、`!`付きのバリアントもあります（例: [`File.read!/1`][file-read-bang]）。ファイルが存在しない、権限がないといったエラーを処理するつもりがない場合は、そのバリアントを使いましょう。

```elixir
File.read("does_not_exist")
# => {:error, :enoent}

File.read!("does_not_exist")
# => ** (File.Error) could not read file "does_not_exist": no such file or directory
#        (elixir 1.10.4) lib/file.ex:353: File.read!/1
```

## ファイルとプロセス

[`File.write/2`][file-write]でファイルに書き込むたびに、ファイルディスクリプターが開かれ、新しいElixir[プロセス][exercism-processes]が生成されます。そのため、ループの中で[`File.write/2`][file-write]を使ってファイルに書き込むのは避けるべきです。

代わりに、[`File.open/2`][file-open]を使ってファイルを開くことができます。[`File.open/2`][file-open]の第2引数はモードのリストで、ファイルを読み込み用に開くか、書き込み用に開くかを指定できます。

よく使われるモードは次のとおりです。

- `:read` - 読み込み用に開きます。ファイルが存在している必要があります。
- `:write` - 書き込み用に開きます。ファイルが存在しない場合は作成され、既存の内容は上書きされます。
- `:append` - 書き込み用に開きます。ファイルが存在しない場合は作成され、既存の内容は保持されます。

すべてのモードの完全な一覧については、[`File.open/2`][file-open]のドキュメントを参照してください。

[`File.open/2`][file-open]は、そのファイルを扱うプロセスのPIDを返します。ファイルの読み書きには、[`IO`][io]モジュールの関数を使い、このPIDを[IOデバイス][io-io-devices]として渡します。

ファイルの操作が終わったら、[`File.close/1`][file-close]で閉じましょう。

```elixir
file = File.open!("README.txt", [:write])
# => #PID<0.157.0>

IO.puts(file, "# README")
# => :ok

File.close(file)
# => :ok
```

## ファイルのストリーミング

[`File.read/1`][file-read]でファイルを読み込むと、ファイル全体が一度にメモリに読み込まれます。これは、とても大きなファイルを扱うときに問題になるかもしれません。そのようなファイルを効率よく扱うには、[`File.open/2`][file-open]と[`IO.read/2`][io-read]を使って1行ずつ読み込むか、[`File.stream/3`][file-stream]でファイルをストリーミングします。ストリームは[`Enumerable`][enumerable]と[`Collectable`][collectable]の両方のプロトコルを実装しているので、読み込みにも書き込みにも使えます。

```elixir
File.stream!("file.txt")
|> Stream.map(&(&1 <> "!"))
|> Stream.into(File.stream!("new_file.txt"))
|> Stream.run()
```

## パス

ファイルを扱うすべての関数には、ファイルパスが必要です。ファイルパスには、絶対パスか、現在のディレクトリからの相対パスを指定します。パスを操作するには、[`Path`][path]モジュールの関数を使います。クロスプラットフォームで互換性を保つには、パスの作成に[`Path.join/1`][path-join]を使いましょう。プラットフォームに適した区切り文字が選ばれます。

```elixir
Path.expand(Path.join(["~", "documents", "important.txt"]))
"/home/user/documents/important.txt"
```
