# 説明

この演習では、自動車工場の組み立てラインの生産を分析するコードを書きます。組み立てラインの速度は、`0`（停止）から`10`（最大）までの範囲で設定できます。

最も低い速度（`1`）では、1時間に`221`台の車が生産されます。生産台数は速度に比例して増加します。つまり、速度を`4`に設定すると、1時間に`4 * 221 = 884`台の車が生産される計算になります。ただし、速度が上がるほど、欠陥のある車が生産される可能性が高くなり、そうした車は廃棄しなければなりません。次の表は、速度が成功率にどう影響するかを示しています。

- `1`から`4`：成功率100%。
- `5`から`8`：成功率90%。
- `9`：成功率80%。
- `10`：成功率77%。

取り組む課題は2つあります。

## 1. 1時間あたりの生産率を計算する

組み立てラインの現在の速度と成功率を考慮して、1時間あたりの生産率を計算する`CarsAssemble.productionRatePerHour()`メソッドを実装しましょう。

```Java
CarsAssemble.productionRatePerHour(6)
// => 1193.4
```

戻り値は`double`であることに注意してください。

## 2. 1分あたりに生産される、動作する車の台数を計算する

1分あたりに何台の動作する車が生産されるかを計算する`CarsAssemble.workingItemsPerMinute()`メソッドを実装しましょう。

```Java
CarsAssemble.workingItemsPerMinute(6)
// => 19
```

戻り値は`int`であることに注意してください。
