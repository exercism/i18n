# 説明

完璧なテーブルの席順を見つけるのが、今回の課題です。
これは、_事実_（常に成り立つもの）と_ルール_（条件付きで成り立つもの）を宣言することで行います。

## 1. おしゃべりな人を挙げる

おしゃべりな人たちを表す`chatty`という事実を定義します。
`chatty`という事実は、引数を1つ取ります。それは、おしゃべりな人の小文字の名前です。

```prolog
chatty(gustavo).
true.
```

## 2. 誰が誰を好きかを挙げる

誰が誰を好きなのかを表す`likes`という事実を定義します。
`likes`という事実は、引数を2つ取ります。

1. 相手を好きな人の小文字の名前
2. 好かれている人の小文字の名前

```prolog
likes(esteban, malena).
true.
```

## 3. 互いに好き合っている人たちは、よいペアになる

2人が互いに好き合っているとき、`pairing`ルールが成り立つように定義します。
pairingルールは、引数を2つ取ります。

1. 1人目の小文字の名前
2. 2人目の小文字の名前

```prolog
pairing(malena, esteban).
true.
```

## 4. おしゃべりな人は誰とでもペアになる

ペアになる2人のうち（少なくとも）1人がおしゃべりなとき、`pairing`ルールが成り立つように定義します。

```prolog
pairing(valeria, jaime).
true.
```

## 5. 席順を確認する

5つのペアがすべてよいペアであるとき、`seating`ルールが成り立つように定義します。

pairingルールは、引数を5つ取ります。

1. 1人目の小文字の名前
2. 2人目の小文字の名前
3. 3人目の小文字の名前
4. 4人目の小文字の名前
5. 5人目の小文字の名前

先ほど定義した事実とルールを使って、席順を確認します。

```prolog
seating(esteban, jaime, gustavo, malena, valeria).
false.
```
