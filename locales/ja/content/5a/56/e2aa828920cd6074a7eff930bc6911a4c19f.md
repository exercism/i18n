# 説明

メアリーは、テレビドラマ_Star Trek: The Next Generation_の大ファンです。彼女はよくペンと紙を使うロールプレイングゲームで遊び、友人たちと一緒に宇宙船エンタープライズの乗組員になりきります。メアリーのキャラクターはピカード艦長なので、艦長日誌を付けなければなりません。彼女はゲームの創作的な部分が大好きですが、その場でランダムなデータを生成するのは好きではありません。

艦長日誌によく登場するデータをランダムに生成する仕組みを作って、メアリーを手伝いましょう。

## 1. ランダムな惑星を生成する

宇宙船エンタープライズは、旅の途中でたくさんの惑星と遭遇します。スタートレックの世界の惑星は、その性質によっていくつかのクラスに分類されています。たとえば、地球はMクラスの惑星です。惑星クラスとしてあり得るのは、D・H・J・K・L・M・N・R・T・Yです。

`random_planet_class/0`関数を実装しましょう。この関数は、惑星クラスのいずれかをランダムに返します。

```elixir
CaptainsLog.random_planet_class()
# => "K"
```

## 2. 宇宙船の登録番号をランダムに生成する

宇宙を飛び回っているのは、エンタープライズ（登録番号NCC-1701）だけではありません！　別の宇宙船とランデブーするとき、メアリーはその宇宙船の登録番号を記録する必要があります。

登録番号は、接頭辞"NCC-"で始まり、そのあとに1000から9999までの数値（両端を含む）が続きます。

宇宙船の登録番号をランダムに返す`random_ship_registry_number/0`関数を実装しましょう。

```elixir
CaptainsLog.random_ship_registry_number()
# => "NCC-1947"
```

## 3. ランダムなスターデートを生成する

日付が含まれていなければ、ログに何の意味があるのでしょうか？

スターデートは浮動小数点数です。_The Next Generation_のシーズン1における宇宙船エンタープライズの冒険は、スターデート41000.0から42000.0の間で繰り広げられます。"4"は24世紀を、"1"はシーズン1を表しています。

41000.0以上42000.0未満の浮動小数点数を返す`random_stardate/0`関数を実装しましょう。

実装にはErlangの関数を使います。

```elixir
CaptainsLog.random_stardate()
# => 41458.15721310934
```

## 4. スターデートをフォーマットする

艦長日誌では、スターデートは通常、小数点以下1桁に丸められます。

浮動小数点数を受け取り、小数点以下1桁に丸めた数値を文字列として返す`format_stardate/1`関数を実装しましょう。

実装にはErlangの関数を使います。

```elixir
CaptainsLog.format_stardate(41458.15721310934)
# => "41458.2"
```
