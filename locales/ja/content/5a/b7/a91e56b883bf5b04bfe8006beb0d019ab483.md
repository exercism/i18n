# はじめに

## Rの真偽値

真偽の値は、`logical`型で表されます。
`logical`型が持つ値は、`TRUE`と`FALSE`の2つだけです。

```R
TRUE
#> [1] TRUE
FALSE
#> [1] FALSE
typeof(TRUE)
#> [1] "logical"
```

## 真偽値の演算子

Rには5つの真偽値演算子がありますが、このシラバスの段階で関係するのは3つだけです。
残りの2つは、ベクトルを扱うときに重要になります。ベクトルについては、後のいくつかのコンセプトで扱います。

`&&`は真偽値の「and」です。
`&&`の*両側*の式が`TRUE`であれば、`TRUE`と評価されます。

```R
TRUE && TRUE
#> [1] TRUE
TRUE && FALSE
#> [1] FALSE
```

`||`は真偽値の「or」です。
`||`の*どちらか*片側の式が`TRUE`であれば、`TRUE`と評価されます。

```R
TRUE || TRUE
#> [1] TRUE
FALSE || TRUE
#> [1] TRUE
```

`!`は真偽値の「not」です。
`TRUE`と`FALSE`の値を入れ替えます。

```R
!TRUE
#> [1] FALSE
!FALSE
#> [1] TRUE
```

より長く複雑な式では、意図を明確にするために括弧（`()`）を使うのがよいでしょう。

```R
(TRUE || FALSE) && (FALSE && TRUE)
#> [1] FALSE

TRUE || FALSE && (FALSE && TRUE)
#> [1] TRUE
```
