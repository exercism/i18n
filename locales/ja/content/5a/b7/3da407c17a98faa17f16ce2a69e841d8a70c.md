# Char

`Char`は、Crystalで32ビットの[Unicode][unicode]コードポイントを表すデータ型です。
そのサイズによりメモリ効率がよく、Stringにはない独自の性質を持っています。
シングルクォート（`'`）で作成し、中にはUnicodeコードポイントを1つだけ書くことができます。

```crystal
'a' # => 'a'
'a'.class # => Char
```

CrystalでStringを扱うとき、Charを扱う機会はよくあります。Stringクラスの多くのメソッドがCharを返したり、引数としてCharを取るからです。
たとえば、[`String#[]`][index]メソッドはCharを返し、[`String#chars`][chars]メソッドはCharのコレクションを返します。

## インクリメントとデクリメント

Charは32ビットのUnicodeコードポイントなので、インクリメントとデクリメントに対応しています。そのため、`'a'`に1を足すと`'b'`が得られます。

```crystal
'a' + 5
# => 'f'

'z' - 25
# => 'a'
```

Unicodeテーブルで次の文字を返す[`Char#succ`][succ]メソッドや、前の文字を返す[`Char#pred`][pred]メソッドもあります。

```crystal
'a'.succ
# => 'b'

'z'.pred
# => 'y'
```

## 連結

Charは32ビットのUnicodeを表すだけのものなので、2つのCharを連結することはできません。
そのため、Charを連結できるのはStringだけです。

```Crystal
'a' + "bc"
# => "abc"

'a' + 'b'
# => error: expected argument #1 to 'Char#+' to be Int or String, not Char
```

## プロパティのメソッド

Crystalには、ある文字についての情報を得るためのメソッドがいくつかあります。たとえば、数値かどうか、文字かどうか、大文字か小文字か、といったことです。
以下はメソッドの一部です。完全なリストは[Char API][char-api]を参照してください。

| メソッド                         | 説明                                                 |
| -------------------------------- | ---------------------------------------------------- |
| [`Char#number?`][number]         | Charが数値であれば`true`を返します                   |
| [`Char#letter?`][letter]         | Charが文字であれば`true`を返します                   |
| [`Char#lowercase?`][lowercase]   | Charが小文字であれば`true`を返します                 |
| [`Char#uppercase?`][uppercase]   | Charが大文字であれば`true`を返します                 |
| [`Char#ascii?`][ascii]           | CharがASCII文字であれば`true`を返します              |
| [`Char#whitespace?`][whitespace] | Charが空白文字であれば`true`を返します               |

## 変換

### コードポイントとCharの相互変換

Charは32ビットのUnicodeコードポイントなので、Charとコードポイント（Int）を相互に変換できます。
これは、Charのコードポイントを返す[`Char#ord`][ord]メソッドや、コードポイントのCharを返す[`Int#chr`][chr]メソッドを使うとできます。

```crystal
'a'.ord
# => 97

97.chr
# => 'a'
```

### 型の変換

他のデータ型と同様に、Charにも型を変換するためのメソッドがいくつかあります。
もっともよく使うのは`Char#to_s`メソッドで、これはCharをStringに変換します。ほかにも、CharをIntに変換する`Char#to_i`メソッドや、CharをFloatに変換する`Char#to_f`メソッドがあります。

```crystal
'a'.to_s
# => "a"

'4'.to_i
# => 4

'a'.to_i
# => Error: Invalid integer: a (ArgumentError)
```

## エスケープ

Stringと同様に、そのままでは書けない文字があり、書くにはエスケープする必要があります。
エスケープしたい文字の前に`\`を付けて、エスケープシーケンスとして書くことができます。

Crystalの特殊文字は次のとおりです。

| 値       | 説明                          |
| -------- | ----------------------------- |
| `\a`     | アラート                      |
| `\b`     | バックスペース                |
| `\e`     | エスケープ                    |
| `\f`     | フォームフィード              |
| `\n`     | ラインフィード（改行）        |
| `\r`     | キャリッジリターン            |
| `\t`     | 水平タブ                      |
| `\v`     | 垂直タブ                      |
| `\\`     | バックスラッシュ              |
| `\'`     | シングルクォート              |
| `\"`     | ダブルクォート                |
| `\377`   | 8進数のASCII文字              |
| `\xFF`   | 16進数のASCII文字             |
| `\uFFFF` | 16進数のUnicode文字           |
