# 説明

この演習では、`Map`を使って国際電話の国番号の辞書を管理するコードを書きます。

この辞書を使うと、国際電話の国番号（マップのキーで、`Integer`）から国名（マップの値で、`String`）を調べることができます。

## 1. コードをマップで返す

仮引数を取らず、現在辞書に入っている国番号から国へのマップを返す`getCodes`メソッドを実装します。

```java
DialingCodes dialingCodes = new DialingCodes();
dialingCodes.getCodes();
// => empty map 
```

## 2. 辞書にエントリーを追加する

辞書にデータを入れる必要があります。
国番号と対応する国を受け取り、その国番号と国を追加する`setDialingCode`メソッドを実装します。
国番号がすでにマップにある場合は、渡された国番号と国でマップを更新します。

```java
DialingCodes dialingCodes = new DialingCodes();
dialingCodes.setDialingCode(679, "Unknown");
// => { 679 => "Unknown" }

dialingCodes.setDialingCode(679, "Fiji");
// => { 679 => "Fiji" }
```

## 3. 国番号から国を調べる

国番号を受け取り、その国番号に対応する国名を返す`getCountry`メソッドを実装します。

```java
DialingCodes dialingCodes = new DialingCodes();
dialingCodes.setDialingCode(55, "Brazil");
dialingCodes.getCountry(55);
// => "Brazil"
```

## 4. 重複を許可しない

国番号を追加するときは、国番号や国が二重に追加されないように注意する必要があります。
そのような状況では、最初のエントリーが正しいエントリーだとみなすことができます。
指定された国番号と国のエントリーを追加する`addNewDialingCode`メソッドを実装します。
ただし、`setDialingCode`とは違い、国番号または国がすでにマップにある場合は何もしません。

```java
DialingCodes dialingCodes = new DialingCodes();
dialingCodes.addNewDialingCode(32, "Belgium");
dialingCodes.addNewDialingCode(379, "Vatican City");
// => { 32 => "Belgium", 379 => "Vatican City" }


dialingCodes.addNewDialingCode(32, "Other");
dialingCodes.addNewDialingCode(39, "Vatican City");
// => { 32 => "Belgium", 379 => "Vatican City" }
```

## 5. 国から国番号を探す

珍しいことですが、間違いは起こりえます。
間違いを訂正するには、その国が現在どの国番号にマッピングされているかを知る必要があります。
どの国番号を訂正する必要があるかを見つけるために、国を受け取ってその国の国番号を返す`findDialingCode`メソッドを実装します。
その国がマップに_ない_場合は`null`を返します。

```java
DialingCodes dialingCodes = new DialingCodes();
dialingCodes.addDialingCode(44, "UK");
dialingCodes.findDialingCode("UK");
// => 44

dialingCodes.findDialingCode("Unlisted");
// => null
```

## 6. 国の国番号を更新する

訂正すべき国番号がわかったので、次はそのコードを更新します。
その国の新しい国番号と国名を受け取り、それに合わせて更新する`updateCountryDialingCode`メソッドを実装します。
その国がマップに_ない_場合は何もしません（このメソッドは間違いの訂正を助けるためだけのものだからです）。

```java
DialingCodes dialingCodes = new DialingCodes();
dialingCodes.addDialingCode(88, "Japan");
// => { 88 => "Japan" }

dialingCodes.updateCountryDialingCode(81, "Japan");
// => { 81 => "Japan" }

dialingCodes.updateCountryDialingCode(32, "Mars");
// => { 81 => "Japan"}
```
