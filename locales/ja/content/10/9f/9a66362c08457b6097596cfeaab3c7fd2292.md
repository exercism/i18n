# はじめに

再帰関数とは、自分自身を呼び出す関数のことです。

再帰関数には、少なくとも1つの_ベースケース_と、少なくとも1つの_再帰ケース_が必要です。

_ベースケース_は、関数を再び呼び出さずに値を返します。
_再帰ケース_は、いずれベースケースに一致するように入力を変えつつ、関数を再び呼び出します。

Elmでは、再帰関数はふつう、`case`式によるパターンマッチングや、複数の節に分けた関数定義を使って定義します。

```elm
count : List a -> Int
count list =
    case list of
        [] ->
            0  -- base case

        _ :: tail ->
            1 + count tail  -- recursive case
```

## 再帰によるループ

Elmでは不変性のため、ループは命令型言語とは書き方が異なります。
たとえば、ループはよく次のようになります。

```c
for(i = 0; i < array.length; i++) {
  // do something with array[i]
}
```

Elmのような関数型言語では、変数を書き換えることはできません。
そのため、ループは再帰を使って実装する必要があります。

Elmで`for`ループに相当するものは、次のようになります。

```elm
loop : List a -> (a -> b) -> List b
loop list f =
    case list of
        [] ->
            []

        head :: tail ->
            f head :: loop tail f
```

実際には、Elmでリストなどのデータ構造を繰り返し処理するときは、`List`モジュールの`List.map`や`List.filter`、`List.foldl`といった関数を使うのがほとんどです。
これらの関数は、内部では再帰を使って実装されています。
