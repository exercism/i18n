そこで手伝いを申し出ると、Ellenは大喜びで、プレイヤーが戦うエイリアンのプログラミングという任務を任せてきました。


## 1. Alienクラスを作成しましょう

二つのパラメーター`<x_coordinate>`と`<y_coordinate>`を受け取るコンストラクターを持つAlienクラスを定義し、それらをインスタンス変数`x_coordinate`と`y_coordinate`に格納します。
エイリアンはどの個体も体力が3の状態から始まるので、`health`変数もあわせて初期化します。

```python
>>> alien = Alien(2, 0)
>>> alien.x_coordinate
2
>>> alien.y_coordinate
0
>>> alien.health
3
```

これで、各エイリアンは自分の位置と体力を内部で管理できるようになります。

## 2. `hit`メソッド

Ellenは、Alien`class`に`hit`メソッドを持たせたいと考えています。呼び出されたときに、エイリアンオブジェクトの体力を1減らすものです。
そうすれば、エイリアンの体力を手作業で書き換えなくても、`<alien>.hit()`を呼び出すだけで済みます。
`hit()`が体力を0_まで_減らすのか、0_より下_まで減らすのかは、あなた次第です。

```python
>>> alien = Alien(0, 0)

# Initialized health value.
>>> alien.health
3

# Decrements health by 1 point.
>>> alien.hit()
>>> alien.health
2
```

## 3. `is_alive`メソッド

体力が減り続ければ、いつかは0に（_それ以下にだって!_）なるでしょう。
そこで、エイリアンが…その…生きているかどうかをすぐに確認できる`is_alive`メソッドを追加しておくといいでしょう。😉
`<alien>.is_alive()`は真偽値を返すようにします。

```python
>>> alien.health
1
>>> alien.is_alive()
True
>>> alien.hit()
>>> alien.health
0
>>> alien.is_alive()
False
```

## 4. `teleport`メソッド

Ellenのゲームでは、エイリアンはテレポートできます！
新しい`x_coordinate`と`y_coordinate`の値を受け取り、それに応じてエイリアンの座標を変更する`teleport`メソッドを書く必要があります。

```python
>>> alien.teleport(5, -4)
>>> alien.x_coordinate
5
>>> alien.y_coordinate
-4
```

当然ながら、エイリアンが何かに当たることがあるなら、そうした衝突が起きたことを検知できる必要があります。
とはいえ、衝突検知のアルゴリズムは厄介になりがちで、その実装方法をまだ知りません。
Ellenは後で自分がやると言っていますが、機能を作り込むときの備忘として、`collision_detection`メソッドをクラスに置いておきたいとも思っています。
何らかの変数（おそらくは別のオブジェクト）を受け取る必要がありますが、それだけしかわかっていません。
メソッド定義をクラスに書いても、呼び出したときにエラーが起きないようにしておく必要があります。

```python

```

## 6. エイリアンのカウンター

Ellenが新たなお願いを持って戻ってきました。
ゲームが続く間に何体のエイリアンが作られたかを記録しておきたいのだそうです。
スコアシステムと何か関係があるのだとか。

例えば、次のようになります。

```python
>>> alien_one = Alien(5, 1)
>>> alien_one.total_aliens_created
1
>>> alien_two = Alien(3, 0)
>>> alien_two.total_aliens_created
2
>>> alien_one.total_aliens_created
2
# Accessing the variable from the class directly
>>> Alien.total_aliens_created
2
```
