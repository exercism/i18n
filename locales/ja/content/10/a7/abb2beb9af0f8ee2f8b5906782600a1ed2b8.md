# はじめに

C#は静的型付け言語です。つまり、コンパイル時にはすべてのものに型があります。名前に値を代入することを、変数の定義といいます。変数は、型を明示して定義することもできますし、代入する値をもとにC#コンパイラーに型を推測させることでも定義できます（これを_型推論_といいます）。したがって、次の2つの変数の定義は同じ意味になります。

```csharp
int explicitVar = 10; // Explicitly typed
var implicitVar = 10; // Implicitly typed
```

変数の値の更新は、`=`演算子で行います。一度定義したら、変数の型を変えることはできません。

```csharp
var count = 1; // Assign initial value
count = 2;     // Update to new value

// Compiler error when assigning different type
// count = false;
```

C#は[オブジェクト指向言語][object-oriented-programming]であり、すべての関数を_クラス_の中に定義する必要があります。クラスを定義するには、`class`キーワードを使います。オブジェクト（または_インスタンス_）は、`new`キーワードを使って作ります。

```csharp
class Calculator
{
    // ...
}

var calculator = new Calculator();
```

クラスの中の関数は、_メソッド_といいます。メソッドには、0個以上の入力を持たせることができます。入力はすべて型を明示する必要があり、入力に型推論はありません。同様に、戻り値の型も明示する必要があります。メソッドから値を返すには、`return`キーワードを使います。他のファイルのコードからメソッドを呼び出せるようにするには、`public`アクセス修飾子を付ける必要があります。

```csharp
class Calculator
{
    public int Add(int x, int y)
    {
        return x + y;
    }
}
```

メソッドは、インスタンスに対してドット（`.`）の構文で呼び出します。呼び出すメソッドの名前を指定し、メソッドの入力それぞれに値を渡します。値を渡すときに、対応する入力の名前を指定することもできます。

```csharp
var calculator = new Calculator();
var sum_v1 = calculator.Add(1, 2);
var sum_v2 = calculator.Add(x: 1, y: 2);
```

C#のスコープは、`{`と`}`の間に定義されます。

C#では、2種類のコメントが使えます。1行コメントは`//`で始め、複数行コメントは`/*`と`*/`の間に書きます。

[object-oriented-programming]: https://docs.microsoft.com/en-us/dotnet/csharp/programming-guide/concepts/object-oriented-programming
