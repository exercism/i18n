# 説明

ある博物学者が、カルデラの周辺に住むドラゴンたちを分類しています。ドラゴンたちには共通の特徴があります。どのドラゴンにも名前、色、年齢があり、それぞれが独自の方法で特殊化しています。ここでは、ドラゴンのクラスの小さな継承ツリーと、どんな子孫でも年を取らせる1つのワードを作ります。

## 1. ドラゴンの一族

タプルクラスの継承ツリー全体を最初に定義します（それぞれのコンストラクターは、このあとのタスクで登場します）。

- スロット`name`、`color`、`age`を持つ`dragon`。
- `dragon`のサブクラスで、スロット`flame-temp`を追加した`fire-dragon`。
- `dragon`のもう1つのサブクラスで、スロット`chill-temp`を追加した`ice-dragon`。
- `fire-dragon`のサブクラスで、スロット`lava-volume`を追加した`volcano-dragon`。

次に、`dragon`に`<dragon>`コンストラクターを定義します。

```factor
"Falkor" "white" 100 <dragon> name>> .   ! => "Falkor"
```

## 2. 火を吹くドラゴンたち

`fire-dragon`に`<fire-dragon>`コンストラクターを定義します。

```factor
"Smaug" "red" 500 1200 <fire-dragon> flame-temp>> .   ! => 1200
"Smaug" "red" 500 1200 <fire-dragon> dragon? .        ! => t
```

## 3. 氷を吹くドラゴンたち

`ice-dragon`に`<ice-dragon>`コンストラクターを定義します。

```factor
"Frosty" "blue" 200 -40 <ice-dragon> chill-temp>> .   ! => -40
"Frosty" "blue" 200 -40 <ice-dragon> fire-dragon? .   ! => f   (siblings)
```

## 4. 火山に住むドラゴンたち

`volcano-dragon`に`<volcano-dragon>`コンストラクターを定義します。

```factor
"Vesuvius" "red" 1000 1500 99 <volcano-dragon> dragon? .       ! => t
"Vesuvius" "red" 1000 1500 99 <volcano-dragon> fire-dragon? .  ! => t
```

## 5. どんなドラゴンでも年を取らせる

`age-dragon`を定義して、どんなドラゴン（またはその子孫）の`age`スロットも1つ増やします。戻り値はありません。

```factor
"Falkor" "white" 100 <dragon> dup age-dragon age>> .   ! => 101
```

同じワードがどの子孫でも動くはずです。これこそが、共通のアクセサーを使う目的です。
