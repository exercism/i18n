# Case

[Case][case]（他の言語ではしばしば`switch`と呼ばれます）は、`if`-`else`のような制御式の一種です。
caseでは複数の`if`-`elsif`文をつなげて書くことができ、制御フローを保ったまま、より読みやすく書けます。

caseは、`case`というキーワードと、そのあとに続く省略可能な式で定義します。
次に、それぞれの分岐には`when`というキーワードを使い、そのあとに`case`の式と比較される式を書きます。
`when`キーワードは、`case`キーワードよりインデントしてはいけません。
`when`キーワードのあとには、`case`の式が`when`の式に一致したときに実行されるコードを書きます。
caseには省略可能な`else`文があり、どの分岐にも一致しなかったときに実行されます。

`case`の式が評価され、次にそれぞれの`when`の式と比較されます。
比較には、`case`等価演算子（`===`）を使います。

```ruby
value = 1
case value
when 1
  "One"
when 2
  "Two"
else
  "Other"
end

# This is the same as:
value = 1
if 1 === value
  "One"
elsif 2 === value
  "Two"
else
  "Other"
end
```

## `case`等価演算子（`===`）

`case`等価演算子（`===`）は、等値演算子（`==`）とは少し違います。
この演算子は、右辺が左辺の表す集合に含まれるかどうかを調べます。
つまり、それぞれのオペランドをどちら側に置くかが重要になります。
どのように判定されるかは左辺の型によって変わり、たとえば`Range`なら右辺がその範囲に含まれるかどうかを調べ、`Object`なら右辺が`Object`のインスタンスかどうかを調べます。

```ruby
(1..3) == 1  # => false
(1..3) === 1 # => true

String == "foo"  # => false
String === "foo" # => true
```

## 複数の式を使うcase

caseでは、複数の式を1つの分岐で一致させることができ、それぞれの値をカンマで区切って書きます。
いずれかの式が一致すれば、そのコードが実行されます。
1つの分岐に複数の値を指定したいときに便利です。

```ruby
case var
when 1, 2
  "One or two"
else
  "Other"
end
```

## 範囲を使うcase

caseでは、値が範囲に含まれるかどうかも調べられます。
これは、`when`の式に範囲を指定して行います。

```ruby
case var
when 1..3
  puts "One to three"
else
  puts "Other"
end
```

## `case`の式を省略する

`case`の式が不要なときは、省略できます。
省略すると、各`when`の式が真かどうかで評価されます。
そのため、`if`-`elsif`文と同じように動作します。

```ruby
case
when 1 == 1
  "One is equal to one"
when 1 > 2
  "One is greater than two"
else
  "Other"
end
```

## 1行の`when`

Rubyでは、case文を1行で書くことができます。
これは、単純な1行の文を書きたいときに使えます。
1行の`when`文は`when <expression> then <statement>`のように書きます。
また、`else`で使う場合は`else <statement>`のように書きます。

```ruby
case var
when 1 then "One"
when 2 then "Two"
else "Other"
end
```

## 型を使うcase

caseでは、型に基づいて一致させることもできます。
変数の型によって動作を変えたいときに便利です。

```ruby
case var
when Integer
  "Integer"
when String
  "String"
else
  "Other"
end
```
