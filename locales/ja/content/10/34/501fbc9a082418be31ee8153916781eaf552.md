# 説明

Lispの宇宙人Loganは、数値が好きで、整理整頓も好きです。

Loganは、数値の配列を受け取り、2つの配列のペアを作る関数を書くのを手伝ってほしいと頼んできました。1つ目の配列にはすべての奇数、2つ目にはすべての偶数が入ります。

## 1. 数値を分類する

まず、2つの配列のペアと数値を受け取り、その数値が奇数か偶数かに応じて正しい方の配列に入れる関数を作る必要があります。

```lisp
(categorize-number '((1) . (2)) 23) ; => ((23 1) . (2))
(categorize-number '((1) . (2)) 42) ; => ((1) . (42 2))
```

## 2. たくさんの数値を分類する

次に、先ほど作成した関数を使って、数値の配列を受け取り、上と同じように分類する別の関数を書くことができます。

```lisp
(partition-numbers '(1 2 3 4))     ; => ((3 1) . (4 2))
(partition-numbers '(42 31 24 13)) ; => ((13 31) . (24 42))
```
