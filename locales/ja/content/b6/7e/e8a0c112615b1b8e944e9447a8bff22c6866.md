# はじめに

## 基本

C#は静的型付け言語です。つまり、コンパイル時にすべてのものに型が付きます。名前を付けて値を代入することを、変数の定義と呼びます。変数は、型を明示的に指定して定義する方法と、代入する値からC#コンパイラーに型を推論させる方法（これは_型推論_と呼ばれます）のどちらでも定義できます。したがって、次の2つの変数定義は同じ意味になります。

```csharp
int explicitVar = 10; // Explicitly typed
var implicitVar = 10; // Implicitly typed
```

変数の値を更新するには、`=`演算子を使います。一度定義すると、変数の型は変えることができません。

```csharp
var count = 1; // Assign initial value
count = 2;     // Update to new value

// Compiler error when assigning different type
// count = false;
```

C#は[オブジェクト指向言語][object-oriented-programming]であり、すべての関数を_クラス_の中で定義する必要があります。クラスを定義するには、`class`キーワードを使います。オブジェクト（または_インスタンス_）は、`new`キーワードを使って生成します。

```csharp
class Calculator
{
    // ...
}

var calculator = new Calculator();
```

クラスの中にある関数は、_メソッド_と呼びます。各メソッドは、0個以上の仮引数を持てます。すべての仮引数には型を明示する必要があり、仮引数には型推論がありません。同様に、戻り値の型も明示する必要があります。メソッドから値を返すには、`return`キーワードを使います。ほかのファイルのコードからメソッドを呼び出せるようにするには、`public`アクセス修飾子を付ける必要があります。

```csharp
class Calculator
{
    public int Add(int x, int y)
    {
        return x + y;
    }
}
```

メソッドは、インスタンスに対してドット（`.`）構文を使って呼び出します。呼び出すメソッド名を指定し、メソッドの各仮引数に対応する引数を渡します。引数には、対応する仮引数の名前を任意で指定できます。

```csharp
var calculator = new Calculator();
var sum_v1 = calculator.Add(1, 2);
var sum_v2 = calculator.Add(x: 1, y: 2);
```

C#のスコープは、`{`と`}`の文字の間に定義されます。

C#では、2種類のコメントを書けます。1行コメントは`//`で始め、複数行コメントは`/*`と`*/`の間に書きます。

[object-oriented-programming]: https://docs.microsoft.com/en-us/dotnet/csharp/programming-guide/concepts/object-oriented-programming
