# ラベルの同期ワークフロー

ラベルの同期ワークフローは、リポジトリの[GitHubラベル](https://docs.github.com/en/issues/using-labels-and-milestones-to-track-work/managing-labels)を`.github/labels.yml`ファイルの内容と同期します。`.github/labels.yml`ファイルが変更されるたびに、ラベルの同期ワークフローがリポジトリのラベルを自動的に更新します。

## ラベルのカスタマイズ

`.github/labels.yml`で定義されているラベルには、2つの種類があります。

- 共有ラベル：_すべての_Exercismリポジトリで使われるラベルで、[org-wide-filesリポジトリ](https://github.com/exercism/org-wide-files/blob/main/global-files/.github/labels.yml)で定義されています。
- トラック固有のラベル：`.appends/.github/labels.yml`ファイルで定義されています。

トラック固有のラベルを追加するには、`.appends/.github/labels.yml`ファイルに追加する必要があります（[こちらの例](https://github.com/exercism/python/blob/main/.appends/.github/labels.yml)を参照してください）。`main`への変更をマージすると、`.github/labels.yml`ファイルを変更するプルリクエストが自動的に作成されます。そのPRをマージすると、ラベルが自動的に更新されます（上記の説明を参照してください）。

```exercism/caution
`.github/labels.yml`ファイルは決して手動で編集しないでください。次にラベルが同期されるときに、その変更は上書きされます。
```

## ソース

ワークフローは`.github/workflows/sync-labels.yml`ファイルで定義されています。
