# Factorのインストール

Factorトラックでは、**Factor 0.101**を使用します。それより前のバージョンはサポートしていません。

[安定版](#stable)または[ナイトリー版](#nightly)をインストールするか、[ソースからビルドする](#build-from-source)ことができます。

インストールできたかどうかは、`factor -e='vm-version print'`を実行して確認してみましょう。`0.101`以上が表示されれば成功です。

---
### 安定版

<https://factorcode.org#stable-release>では、「Stable release」セクションで安定版のバイナリを提供しています。

---
### ナイトリー版

<https://factorcode.org#development-release>では、「Development release」セクションでナイトリー版のバイナリを提供しています。これらのバイナリはgitからビルドされますが、表示されるのはビルドが成功したものだけです。

---
### ソースからビルドする

最先端を試したい方、ナイトリー版でも古すぎると感じる方には、モダンなC++コンパイラー（GCC >=4.8またはClang >=3.5）、`make`、`curl`が必要です。

これだけの条件を満たしたら、次の手順を実行します。

1. `build`シェルスクリプトをダウンロードします。[**こちら**（Unix系 / POSIXシェル）](https://raw.githubusercontent.com/factor/factor/master/build.sh)または[**こちら**（Windows）](https://raw.githubusercontent.com/factor/factor/master/build.cmd)からどうぞ。Factorをインストールしたいディレクトリに置いてください。コードベースを含む`factor`というディレクトリが作成されます。

2. `./build.sh install`のように実行します（Windowsでは`.\build.cmd install`）。<sub>これはFactorの`git`リポジトリをクローンしてビルドし、<https://factorcode.org>からFactorのVMイメージをダウンロードします。この処理には2分から20分ほどかかります。時間は回線速度とCPUのクロック数によって変わります。</sub>

3. これで、`factor`サブディレクトリ内に生成された`factor`または`factor.exe`のバイナリを実行できます。ヘルプを見たいときは`factor --help`を試してみてください。コマンドラインからドキュメントを参照することもできますし、GUI Listenerで<kbd>F1</kbd>を押すとヘルプブラウザーが開きます。

4. 今後は、`factor`サブディレクトリ内の`build.sh`（Windowsでは`build.cmd`）を使ってgitから取得し、その場で再ビルドします。必要に応じて新しいVMイメージもダウンロードされます。

このとき、ファイル構成は次のようになっているはずです。

```
.
├── build.sh                   <- delete if you like
└── factor
    ├── basis
    ├── boot.unix-x86.64.image
    ├── build.cmd              <- use these from now on
    ├── build.sh               <-
    ├── core
    ├── extra
    ├── factor
    ├── Factor.app
    ├── factor.image
    ├── GNUmakefile
    ├── libfactor.a
    ├── libfactor-ffi-test.so
    ├── LICENSE.txt
    ├── misc
    ├── Nmakefile
    ├── README.md
    ├── unmaintained
    ├── vm
    └── work
```

今後はダウンロードしたスクリプトを使うため、最上位の`build`スクリプトはもう必要ありません。

---

### 手動でソースからビルドする（おすすめしません）

[リポジトリ](https://github.com/factor/factor)をクローンし、そのフォルダーで`make`を実行します。

`make`が存在しないターゲットに関するエラーで失敗する場合は、`make factor`を試してみてください。Makefileを読める方なら、`GNUmakefile`から自分のプラットフォーム向けのmakeターゲットを探してください。

*それでも*失敗する場合は、エラーの内容を添えて[factor/factor](https://github.com/factor/factor)でissueを作成してください。親切な開発者たちが喜んで助けてくれます。
