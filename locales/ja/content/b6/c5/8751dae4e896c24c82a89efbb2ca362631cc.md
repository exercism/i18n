# 説明

## 1. 概要

[逆ポーランド記法](https://en.wikipedia.org/wiki/Reverse_Polish_notation)（RPN）は、数式を書くための方法のひとつです。従来の中置記法とは異なり、RPNでは演算子が被演算子の*後ろ*に来ます。たとえば、次のように書く代わりに、

```
2 + 2
```

このように書きます。

```
2 2 +
```

逆ポーランド記法の大きな利点は、中置記法よりもずっと解析しやすいことです。RPNを使えば、複雑な式でも演算の順序や括弧を気にする必要がありません。たとえば、

```
(4 + 8) / (7 - 5)
```

は、次のように書けます。

```
4 8 + 7 5 - /
```

どちらの場合も、式を評価すると6になります。

## 2. 例

この複雑な式を手動で評価してみましょう。イントロダクションで学んだとおり、RPNの評価にはスタックが必要です。このスタックは、演算子が操作する数値を保持するために使います。まず空のスタックで計算機を始め、要素を1つずつ評価していきます。

まず`4`が出てきたので、できたばかりのスタックにプッシュします。

```
4
```

次に`8`が出てきます。これもスタックにプッシュします。

```
4 8
```

今度は`+`です。スタックの一番上にある2つの値（4と8）をポップし、それらを足して、その合計をスタックにプッシュし直します。

```
12
```

`7`、`5`、`-`についても同じようにします。

```
12 7
12 7 5
12 2
```

次に`/`が出てきます。直前に`-`が出てきたとしても、スタックには2つの要素があります。その2つの要素をポップし、割って、結果をスタックにプッシュし直します。

```
6
```

最後に、スタックには要素がちょうど1つあるので、この式は6と評価されたと言えます。

## 3. ゴール

目標は、逆ポーランド記法の順に並んだ入力のリストを評価し、スタックの最後の要素を返す計算機を書くことです。

最後にスタックの要素がちょうど1つでない場合は、`None`を返します。

オペランドが少なすぎる演算子がある場合（たとえば入力`2 +`）、`None`を返します。

    Value(i32),
}
