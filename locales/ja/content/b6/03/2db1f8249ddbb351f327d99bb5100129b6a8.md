# 指示の補足

## レジスタ

| レジスタ | 用途        | 型    | 説明                   |
| -------- | ------------ | ------- | ----------------------------- |
| `$a0`    | 入力        | アドレス | null終端された数字列 |
| `$a1`    | 入力        | 整数 | 連続する桁数                          |
| `$v0`    | 出力       | 整数 | 連続する数字の積の最大値        |
| `$t0-9`  | 一時利用    | 任意     | 一時的な保存用         |
