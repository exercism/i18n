# 指示

学校の劇のオーディションが終わり、演出家は決定を書き留めておく必要があります。

4つの課題はすべて`CASTING_CALL`クラスに書きます。

## 1. 判定

出演者はそれぞれ10点満点で採点されます。8点以上なら配役が決まり、5点から7点なら呼び戻され、5点未満ならお礼を言われます。

```sather
CASTING_CALL::audition_outcome(8)
-- => "Cast"
CASTING_CALL::audition_outcome(6)
-- => "Recalled"
CASTING_CALL::audition_outcome(2)
-- => "Thank you"
```

## 2. どのグループ？

13歳未満の出演者はJuniorsです。13歳から15歳はMiddles、16歳以上はSeniorsです。

```sather
CASTING_CALL::age_group(13)
-- => "Middles"
```

## 3. いつ戻ってくるか

Juniorsは16時、Middlesは17時、それ以外の全員は18時に呼び戻されます。

```sather
CASTING_CALL::callback_time("Middles")
-- => "5pm"
```

引数はグループの名前で、課題2とまったく同じつづりで書きます。

## 4. 用紙に何を書くか

8点以上で歌える人は`"Lead"`です。8点以上でも歌えない場合は`"Speaking part"`、それ以外の人は全員`"Chorus"`です。

```sather
CASTING_CALL::casting_note(9, true)
-- => "Lead"
CASTING_CALL::casting_note(9, false)
-- => "Speaking part"
CASTING_CALL::casting_note(4, true)
-- => "Chorus"
```
