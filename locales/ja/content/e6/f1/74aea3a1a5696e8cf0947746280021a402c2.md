# 説明

この演習では、友人が開発中の新しいRPGゲームのクエストロジックを実装します。

ゲームの主人公はAnnalyn。勇敢な女の子で、獰猛で忠実な飼い犬を連れています。ところが不幸にも、森で木の実を探していた親友が誘拐されてしまいます。

Annalynは親友を探し出して解放しようとします。この冒険に飼い犬を連れて行くかどうかは自由です。

親友の足跡をたどってしばらく進むと、親友が囚われている野営地を見つけます。誘拐犯は2人いました。屈強な騎士と、ずる賢い弓使いです。

誘拐犯を見つけたAnnalynは、次のどの行動が取れるかを考えます。

- _速攻_：騎士が眠っていれば速攻を仕掛けられます。鎧を着るのに時間がかかり、その間は無防備になるからです。
- _スパイ_：集団のうち少なくとも1人が起きていれば、スパイできます。そうでなければ、スパイは時間の無駄です。
- _囚人への合図_：囚人が起きていて、弓使いが眠っていれば、鳥のさえずりを使って囚人に合図を送れます。弓使いは鳥のさえずりによる合図の訓練を受けているので、メッセージを傍受されるおそれがあるからです。
- _囚人の解放_：Annalynは野営地に忍び込んで囚人を解放しようと試みることができます。
  これは危険な行為で、次の2通りの方法のどちらかでしか成功しません。
  - Annalynが飼い犬を連れている場合、弓使いが眠っていれば囚人を助け出せます。
    騎士は犬を怖がり、弓使いはAnnalynと囚人が逃げる前に準備する時間がありません。
  - Annalynが犬を連れていない場合、彼女と囚人はとても慎重に行動しなければなりません。
    囚人が起きていて、騎士と弓使いが2人とも眠っていれば囚人を解放できます。しかし囚人が眠っている場合は助け出せません。Annalynが突然現れると囚人が驚いて、騎士と弓使いを起こしてしまうからです。

演習は4つのタスクに分かれています。森で見つけた3人の状態と、Annalynの飼い犬がいるかどうかに基づいて、上記の行動が可能かどうかを判断するロジックを実装しましょう。

## 1. 速攻ができるか確認する

騎士が起きているかどうかを示す真偽値を受け取る`can_fast_attack()`メソッドを実装します。このメソッドは、騎士の状態に基づいて速攻ができる場合に`TRUE`を返し、それ以外の場合は`FALSE`を返します。

```R
knight_is_awake <- TRUE
can_fast_attack(knight_is_awake)
# => FALSE
```

## 2. 集団をスパイできるか確認する

騎士、弓使い、囚人がそれぞれ起きているかどうかを示す3つの真偽値を受け取る`can_spy()`メソッドを実装します。このメソッドは、3人の状態に基づいて集団をスパイできる場合に`TRUE`を返し、それ以外の場合は`FALSE`を返します。

```R
knight_is_awake <- FALSE
archer_is_awake <- TRUE
prisoner_is_awake <- FALSE
can_spy(knight_is_awake, archer_is_awake, prisoner_is_awake)
# => TRUE
```

## 3. 囚人に合図を送れるか確認する

弓使いと囚人がそれぞれ起きているかどうかを示す2つの真偽値を受け取る`can_signal_prisoner()`メソッドを実装します。このメソッドは、2人の状態に基づいて囚人に合図を送れる場合に`TRUE`を返し、それ以外の場合は`FALSE`を返します。

```R
archer_is_awake <- FALSE
prisoner_is_awake <- TRUE
can_signal_prisoner(archer_is_awake, prisoner_is_awake)
# => TRUE
```

## 4. 囚人を解放できるか確認する

4つの真偽値を受け取る`can_free_prisoner()`メソッドを実装します。最初の3つの仮引数は、騎士、弓使い、囚人がそれぞれ起きているかどうかを示します。最後の仮引数は、Annalynの飼い犬がいるかどうかを示します。このメソッドは、3人の状態とAnnalynの飼い犬の有無に基づいて囚人を解放できる場合に`TRUE`を返します。それ以外の場合は`FALSE`を返します。

```R
knight_is_awake <- FALSE
archer_is_awake <- TRUE
prisoner_is_awake <- FALSE
pet_dog_is_present <- FALSE
can_free_prisoner(knight_is_awake, archer_is_awake, prisoner_is_awake, pet_dog_is_present)
# => FALSE
```
