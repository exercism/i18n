# インストール

## クイックスタート

``` shellsession
$ bash <(curl -s https://raw.githubusercontent.com/borkdude/babashka/master/install)
```

デフォルトでは、これは`/usr/local/bin`にインストールされます。変更するには、ディレクトリ名を指定してください：

``` shellsession
$ bash <(curl -s https://raw.githubusercontent.com/borkdude/babashka/master/install) /tmp
```

## Brew

LinuxとmacOSのバイナリはbrewで提供されています。

インストール：

    brew install borkdude/brew/babashka

アップグレード：

    brew upgrade babashka

## Arch（Linux）

`babashka`は[Arch User Repository](https://aur.archlinux.org)で[利用できます](https://aur.archlinux.org/packages/babashka-bin/)。[yay](https://github.com/Jguer/yay)、[yaourt](https://github.com/archlinuxfr/yaourt)、[apacman](https://github.com/oshazard/apacman)、[pacaur](https://github.com/rmarquis/pacaur)などのお気に入りの[AUR](https://aur.archlinux.org)ヘルパーを使ってインストールできます。`yay`を使った例を次に示します：

    yay -S babashka-bin

## Windows

Windowsでは、[scoop](https://scoop.sh/)と[scoop-clojure](https://github.com/littleli/scoop-clojure)バケットを使ってインストールできます。

## ダウンロード

[Github](https://github.com/borkdude/babashka/releases)からバイナリをダウンロードすることもできます。Linux向けには、Alpineで使える静的バイナリが用意されています。

## Docker

[Docker hub](https://hub.docker.com/r/borkdude/babashka/)でイメージを確認してみてください。
