# 配列

Cairoでは、配列は同じ型の要素をまとめて格納できるデータ構造です。
Cairoの配列は、変更できる操作が限られています。
配列の末尾に要素を追加することと、先頭から要素を取り除くことだけができます。
実際のところ、配列は値を変更できないキューです。

## 配列の作成

配列は主に`ArrayTrait`トレイトを使って作成します。要素`[1, 2]`の配列を作る方法は、次の4つです。

```rust
// 1. Passing the type to the `ArrayTrait`
let mut arr_type_in_trait = ArrayTrait::<felt252>::new();
arr_type_in_trait.append(1);
arr_type_in_trait.append(2);

// 2. Setting the type on the variable itself
let mut arr_explicit_type: Array<felt252> = ArrayTrait::new();
arr_explicit_type.append(1);
arr_explicit_type.append(2);

// 3. Using the `array!` macro
let mut arr_from_macro: Array<felt252> = array![1, 2]; // assign values in-line

// 4. Allowing the compiler to infer the type from the type of values being assigned to it
let mut arr_implicit_type = ArrayTrait::new(); // compiler "knows" this is a `felt252` array
arr_implicit_type.append(1);
arr_implicit_type.append(2);
```

> `append()`を呼ぶたびに、配列の末尾に新しい数値が追加されます。

## 配列の要素を取り除く

Cairoで配列から要素を取り除けるのは、先頭からだけです。
この操作には`pop_front()`メソッドを使います。このメソッドは`Option`を返し、アンラップすると取り除かれた要素が得られます。配列が空の場合は`Option::None`になります。

```rust
fn main() {
    let mut a = array![10, 1, 2];
    let first_value = a.pop_front().unwrap(); // `unwrap()` is used to get the value from `Option`
    println!("The first value is {}", first_value); // prints "The first value is 10"
}
```

## 配列の値にアクセスする

配列の要素にアクセスするには、`get()`または`at()`という配列のメソッドを使います。これらはそれぞれ違う型を返します。
`arr.at(index)`と等価なのが、添字演算子`arr[index]`です。

### `get()`メソッドを使う

`get()`メソッドは、配列の中の項目を番号で調べるようなものです。次のように動きます。

- `arr.get(index)`を使うと、配列内の特定の位置（インデックス）にある項目を取得できます。
- 指定したインデックスに項目があれば`Option::Some(value)`を返し、インデックスが範囲外なら`Option::None`を返します。

このメソッドは、インデックスが無効かもしれない場合に、プログラムをクラッシュさせずに対処したいときに最適です。

```rust
fn main() {
    let arr: Array<u32> = array![1, 2, 3];

    let index = 1;

    match arr.get(index) {
        Option::Some(value) => { println!("Element at index {}: {}", index, value.unbox()); },
        Option::None => { println!("Index {} is out of bounds!", index); }
    }
}
```

### `at()`メソッドを使う

`at()`メソッドは、特定のインデックスにある要素のスナップショットを直接返します。その際、`unbox()`演算でボックスから格納された値を取り出します。
このメソッドの省略記法が、添字演算子`arr[index]`です。
存在しないインデックス（範囲外）にアクセスしようとすると、プログラムはエラーでパニックします。

```rust
fn main() {
    let a: Array<u32> = array![5, 8];

    println!("First: {}", *a.at(0)); // prints "First: 5"
    println!("Second: {}", a[1]); // prints "Second: 8"
    println!("Third: {}", a[2]); // panics with 'Index out of bounds'
}
```

## サイズに関するメソッド

配列の要素の数を調べるには、`len()`メソッドを使います。
戻り値の型は`usize`です。

配列が空かどうかを確認したいときは、`is_empty()`メソッドを使います。配列が空なら`true`を、そうでなければ`false`を返します。

## `Span`

`Span`は、`Array`のスナップショットを表す構造体です。
元の配列を変更せずに、配列の要素へ安全かつ制御されたアクセスを提供するように設計されています。
`Span`は、関数間で配列を渡すときや、読み取り専用の操作を行うときに、データの整合性を保ち、借用の問題を避けるのに特に役立ちます。

> `Array`が提供するメソッドは、`append()`メソッドを除いて、すべて`Span`でも使えます。

`Array`の`Span`を作るには、`span()`メソッドを呼びます。

```rust
let my_array: Array<u32> = array![1, 2, 3];
let my_span: Span<u32> = my_array.span();
```

## 固定長の`Array`型

固定長配列の値は、角括弧の中にカンマ区切りのリストとして書きます。
配列の型は、角括弧の中に各要素の型、セミコロン、そして配列の要素数を書いて表します。

```rust
let arr: [u64; 5] = [1, 2, 3, 4, 5];
```

> 注意：定数として使えるのは、固定長配列だけです

固定長配列の要素には、配列を分解するか、インデックス指定に対応した`Span`に変換することでアクセスできます。

```rust
fn main() {
    let arr = [1, 2, 3, 4, 5]; // implicit `felt252` array type

    // Accessing elements of a fixed-size array by deconstruction
    let [a, b, c, _, _] = arr;
    println!("c: {}", c); // c: 3
    
    // Accessing elements of a fixed-size array by index
    let my_span = arr.span();
    println!("my_span[2]: {}", my_span[2]); // my_span[2]: 3
}
```
