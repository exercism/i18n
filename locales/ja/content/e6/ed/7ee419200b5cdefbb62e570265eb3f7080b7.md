# 指示の補足

## 有理数の演算子

算術用の関数は、通常の関数呼び出し、静的ディスパッチ（メソッド呼び出し構文）、演算子という3つの形で使えます。

| 関数呼び出し | メソッド呼び出し | 演算子 |
| --- | --- | --- |
| `plus(r1, r2)` | `r1.plus(r2)` | `r1 + r2` |
| `minus(r1, r2)` | `r1.minus(r2)` | `r1 - r2` |
| `times(r1, r2)` | `r1.times(r2)` | `r1 * r2` |
| `div_by(r1, r2)` | `r1.div_by(r2)` | `r1 / r2` |

`reduce`を実装して、有理数を最も簡単な形に約分できるようにしましょう。たとえば、`6 / 8`を`3 / 4`にします。
