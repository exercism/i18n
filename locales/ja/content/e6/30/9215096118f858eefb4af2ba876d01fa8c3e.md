# はじめに

[範囲][range]は、2つの値の間の区間を表します。
範囲は、`Int`や`String`、`Character`のような型と組み合わせて、シーケンスを繰り返し処理したり、コレクションの一部を切り出したり、値が範囲内に収まっているかを確認したりするのによく使われます。

Swiftには、主に2つの範囲演算子があります。

- **閉範囲演算子（`...`）**: 始点と終点の両方の値を含みます（`1...5`は1、2、3、4、5を含みます）。
- **半開範囲演算子（`..<`）**: 始点の値は含みますが、終点の値は含みません（`1..<5`は1、2、3、4を含みます）。

```swift
let closed = 1...5
let halfOpen = 1..<5
```

~~~~exercism/note
範囲リテラルに対して直接メソッドを呼び出すときは、コンパイラーが先に範囲を評価するように、範囲式を括弧（`()`）で囲みます。

```swift
(1...5).contains(3) // Returns true
// 1...5.contains(3) // Error: value of type 'Int' has no member 'contains'
```
~~~~

## 範囲を配列に変換する

数値の範囲は、`Array(_:)`イニシャライザーを使って`Array`に変換できます。

```swift
let range = 1...5
let numbers = Array(range)
// numbers is [1, 2, 3, 4, 5]
```

## 範囲で配列を切り出す

範囲を使うと、配列の一部分を切り出すことができます。

```swift
let array = [10, 20, 30, 40, 50]
let slice = array[1...3]
// slice contains [20, 30, 40]
```

## 範囲のプロパティとメソッド

範囲でよく使う操作には、次のようなものがあります。

| Member                  | Description                                                | Example                              |
| ----------------------- | ---------------------------------------------------------- | ------------------------------------ |
| `count`                 | 範囲内の要素の数を返します                | `(1...5).count`は`5`を返します          |
| [`contains(_:)`][contains] | 指定した値が範囲に含まれていれば`true`を返します | `(1...5).contains(3)`は`true`を返します |

## 片側範囲

Swiftでは、始点または終点のどちらかを省略した片側範囲（部分範囲）も使えます。

- `array[2...]`: インデックス2からコレクションの終わりまで。
- `array[...2]`: コレクションの先頭からインデックス2まで（インデックス2を含みます）。
- `array[..<2]`: コレクションの先頭からインデックス2の手前まで（インデックス2は含みません）。

## 文字列と文字の範囲

`Comparable`に準拠した文字や文字列の間でも、範囲を作ることができます。

```swift
let letters = "a"..."z"
print(letters.contains("m")) // Prints true
print(letters.contains("A")) // Prints false
```
