# ヒント

## 全般

- `TUPLE:`と`boa`は、`kernel`に隣接するボキャブラリで宣言されています。クラスを宣言するのに特別なUSINGは必要ありません。アクセサーのワードは[`accessors`][accessors]にあります。

## 1. 基底クラス

- `TUPLE: dragon name color age ;`は、3つのスロットを持つクラスをその順番で宣言します。`<dragon>`の定義は1行、`dragon boa`だけです。

## 2. 火を吐くドラゴン

- `<`という親の構文を使うと、親のスロットを継承します。`TUPLE: fire-dragon < dragon flame-temp ;`のように書きます。`boa`コンストラクターは、親のスロットを先に受け取ります。

## 3. 氷を吐くドラゴン

- タスク2と同じ形で、追加のスロットが違うだけです。兄弟のサブクラス同士は干渉しません。`fire-dragon`と`ice-dragon`はどちらも`dragon`を直接継承しています。

## 4. 火山に住むドラゴン

- `dragon`を直接ではなく`fire-dragon`を継承させます。すると`volcano-dragon`は、`dragon`のスロットと`fire-dragon`の`flame-temp`の両方を引き継ぎます。`boa`コンストラクターは、name、color、age、flame-temp、lava-volumeの5つの値を受け取ります。

## 5. あらゆるドラゴンの年齢を変える

- `change-age`は値を書き換えるアクセサーです。`( tuple quot -- tuple )`は、現在のageにクォーテーションを適用して書き戻します。`[ 1 + ] change-age drop`はageを1増やし、返されたタプルを捨てます。すべての派生クラスがこのスロットを継承するので、同じワードをどれにも使えます。

[accessors]: https://docs.factorcode.org/content/vocab-accessors.html
