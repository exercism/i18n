# はじめに

quotationが周囲の値を*覚えておく*必要があるとき、Factorには2つの道具があります。[`kernel`][kernel]の`curry`と`compose`、そして[`fry`][fry]のfry構文`'[ … ]`です。

`curry`は、1つの値をquotationの先頭に組み込みます。

```
curry ( value quot -- newquot )
```

```factor
3 [ + ] curry .          ! => [ 3 + ]
10 3 [ + ] curry call .  ! => 13
```

`compose`は、2つのquotationをつなぎ合わせます。

```factor
[ 1 + ] [ 2 * ] compose .       ! => [ 1 + 2 * ]
5 [ 1 + ] [ 2 * ] compose call . ! => 12
```

取り込む値が1つや2つではなく、もっと多くなるなら、fryのほうがすっきり書けます。それぞれの`_`プレースホルダーには、スタックから取り出した値が順番に埋められます。

```factor
2 3 '[ _ _ + + ] .    ! => [ 2 3 + + ]
```

fryは、入れ子になったquotationの中にまで届きます。

[fry]: https://docs.factorcode.org/content/vocab-fry.html
