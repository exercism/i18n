# インストール

elmの現在のバージョンは0.19.1です。
インストール手順は、言語の進化に合わせて変わっていきます。
最新のインストール手順については、[elmガイドのインストール手順][elm-install]をご覧ください。

[elm-install]: https://guide.elm-lang.org/install/elm.html

## 追加のツール

**elm-test**

コマンドラインからテストを実行するためのツールは、elm-testと呼ばれます。
現在、elm-testにはNode.jsとnpmが必要です。まだインストールしていない場合は、[先にNode.jsとnpmをインストール][npm-install]してください。
npmをインストールしたら、次のコマンドでelm-testをインストールできます。

```shell
npm install --global elm-test@latest-0.19.1
```

詳しくは、[elm-testのnpmホームページ][elm-test]をご覧ください。

[npm-install]: https://www.npmjs.com/get-npm
[elm-test]: https://www.npmjs.com/package/elm-test

**elm-format**

ほとんどのelmプログラマーは、elmのコードを整形するためにelm-formatを使っています。
これは、設定が不要なコード整形ツールです。
自動整形ツールに慣れていないと、最初は少しもどかしく感じるかもしれません。でも、一度慣れてしまうと、今までどうやってこれなしでコードを書いていたのか不思議に思うようになります。
こちらもnpmでインストールできます。

```shell
npm install --global elm-format@latest-0.19.1
```

詳しくは、[GitHubのelm-formatホームページ][elm-format]をご覧ください。

[elm-format]: https://github.com/avh4/elm-format

**テキストエディター**

少なくとも[IntelliJ][intellij]と、[elm language server][els]に対応したVS Code、Sublime Text、Vimなどのテキストエディターでは、Elmのサポートが充実しています。

[els]: https://github.com/elm-tooling/elm-language-server
[intellij]: https://github.com/klazuka/intellij-elm

## npmの権限エラー

elm-testやelm-formatをインストールするときに、npmでEACCESS権限エラーが発生することがあります。
その場合は、npmのウェブサイトの手順に従ってください。
[パッケージをグローバルにインストールするときのEACCES権限エラーを解決する][eaccess]。

[eaccess]: https://docs.npmjs.com/resolving-eacces-permissions-errors-when-installing-packages-globally
