# 概要

[Stringer][stringer-interface]は、値の文字列フォーマットを定義するためのインターフェースです。

このインターフェースは、`String`メソッドを1つだけ持ちます。

```go
type Stringer interface {
    String() string
}
```

このインターフェースを実装したい型は、その型を人間にわかりやすく表した文字列を返す`String()`メソッドを持たなければなりません。
[fmt][fmt-package]パッケージ（そして他の多くのパッケージ）は、値を整形して出力するためにこのメソッドを探します。

## 例：距離

さまざまな単位で測られた地理的な距離を扱うアプリケーションを開発しているとします。
次のように`DistanceUnit`型と`Distance`型を定義しました。

```go
type DistanceUnit int

const (
	Kilometer    DistanceUnit = 0
	Mile         DistanceUnit = 1
)

type Distance struct {
	number float64
	unit   DistanceUnit
}
```

上の例では、`Kilometer`と`Mile`は`DistanceUnit`型の定数です。

これらの型は`String`メソッドを持たないため、`Stringer`インターフェースを実装していません。
そのため、`fmt`の関数はGoの「デフォルトフォーマット」で`Distance`の値を出力します。

```go
mileUnit := Mile
fmt.Sprint(mileUnit)
// => 1
// The result is '1' because that is the underlying value of the 'Mile' constant (see constant declarations above)

dist := Distance{number: 790.7, unit: Kilometer}
fmt.Sprint(dist)
// => {790.7 0}
// not a very useful output!
```

出力をよりわかりやすくするために、`DistanceUnit`型と`Distance`型のそれぞれに`String`メソッドを追加して、`Stringer`インターフェースを実装します。

```go
func (sc DistanceUnit) String() string {
	units := []string{"km", "mi"}
	return units[sc]
}

func (d Distance) String() string {
	return fmt.Sprintf("%v %v", d.number, d.unit)
}
```

`fmt`パッケージの関数は、`Distance`の値をフォーマットするときにこれらのメソッドを呼び出します。

```go
kmUnit := Kilometer
kmUnit.String()
// => km

mileUnit := Mile
mileUnit.String()
// => mi

dist := Distance{
	number: 790.7,
	unit: Kilometer,
}
dist.String()
// => 790.7 km
```
