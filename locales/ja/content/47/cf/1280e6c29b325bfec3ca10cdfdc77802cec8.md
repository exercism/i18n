# 概要

Goでは、`map`はハッシュテーブルを表す組み込みのデータ型です。
他のプログラミング言語では、`map`は`dict`や連想配列、キーと値のストアとして知られているかもしれません。
こうした概念に馴染みがなければ、`map`は辞書のようなものだと考えてみてください。辞書では、各単語が`key`で、その定義が`map`の`element`にあたります。

> 始める前に、`map`についてさらに深く掘り下げるために、[mapのGo仕様][gospec-map]と[mapのGoブログ][goblog-map]を紹介しておきます。

構文的には、`map`は次のようになります。

```go
map[KeyType]ElementType
```

_`KeyType`は[比較可能な型][gospec-comparable]である必要がありますが、`ElementType`はGoで有効な任意の型にできます。つまり、プリミティブな変数からスライスまで、どんなものでも格納できます。_

Goの`map`は**順序を持たない**ことを覚えておくことが大切です。`map`をループして要素を出力しようとすると、要素がランダムな順序で出力されるのを見て驚くかもしれません（よければ試してみてください）。

また、各キーは一意であることも重要です。同じキーを2回代入すると、対応するキーの値が上書きされます。

`map`は参照型です。つまり、`map`を渡してもGoはmap全体をコピーしません。
代わりにGoが行うのは、mapのポインターのコピーです。これにより、`map`を関数や変数に渡すのが低コストになります。
初期化されていないmapの値は`nil`です。

mapは次のように定義できます（これは**nil map**とも呼ばれます）。

```go
  var foo map[string]int
```

mapを初期化するには、次のようにします。

```go
  // With map literal
  foo := map[string]int{}
```

または

```go
  // or with make function
  foo := make(map[string]int)
```

> nil mapは初期化されたmapとは異なります。nil mapに書き込むと、ランタイムエラーが発生します。
>
> ```txt
> panic: assignment to entry in nil map
> ```
>
> そのため、使う前にmapを初期化することが大切です

mapでできる操作をいくつか紹介します。

```go
  // Add a value in a map with the `=` operator:
  foo["bar"] = 42
  // Here we update the element of `bar`
  foo["bar"] = 73
  // To retrieve a map value, you can use
  baz := foo["bar"]
  // To delete an item from a map, you can use
  delete(foo, "bar")
```

mapに存在しないキーの値を取得しようとすると、値の型のゼロ値が返されます。
これは、`ElementType`のデフォルト値（たとえばintなら0）が有効な値である場合に、特に混乱を招くかもしれません。
mapにキーが存在するかどうかを確認するには、次のようにします。

```go
  value, exists := foo["baz"]
  // If the key "baz" does not exist,
  // value: 0; exists: false
```

これまで見てきたように、`map`が初期化されているかどうかを判別するのは簡単で、単純に`nil`と比較すればよいのですが、他のmap同士ではどうでしょうか？
`map`は比較可能ではないので`==`演算子は使えませんが、`reflect`パッケージに助けがあります。それは`DeepEqual`と呼ばれるもので、次のように使えます。

```go
import "reflect"

// ....

equal := reflect.DeepEqual(map[string]int{}, map[string]int{})
fmt.Println(equal)
// Output: true
```

_でも待ってください。mapが比較可能でないのなら、なぜ`nil`とは比較できるのでしょうか？　仕様がこれについて例外を設けています。[比較可能の仕様][gospec-comparable]をご覧ください。_

最後に、複数のゴルーチンから`map`に書き込もうとすると、レース検出器が作動します。[Goのドキュメント][godoc-race-detector]と[Goブログ][goblog-race-detector]をご覧ください。
別の方法として、この問題を回避するために`sync.Map`や`atomic`、`mutex`を使うこともできます。
