# 説明の補足

## ヒント

この演習では、テキストデータを扱います。歴史的な理由から、Haskellの`String`型は、文字のリストである`[Char]`と同じものです。テキストデータをより効率的に扱うには、`Text`型を使うこともできます。

この演習の任意の発展として、次のことができます。

- Haskellの[文字列型](https://haskell-lang.org/tutorial/string-types)について読んでみましょう。
- package.yamlの依存関係のリストに`- text`を追加しましょう。
- `Data.Text`を[次のように](https://hackernoon.com/4-steps-to-a-better-imports-list-in-haskell-43a3d868273c)インポートしましょう。

        import qualified Data.Text as T
        import           Data.Text (Text)

- これで、例えば`isIsogram :: Text -> Bool`と書いたり、`Data.Text`のコンビネーターを、例えば`T.toLower`のように参照できるようになります。
- [`Data.Text`](https://hackage.haskell.org/package/text/docs/Data-Text.html)のドキュメントを調べてみましょう。

この部分は完全に任意です。
