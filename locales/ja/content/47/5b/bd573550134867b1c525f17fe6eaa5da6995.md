# 指示の補足

## ヒント

実装する必要がある関数は、次のとおりです。

```haskell
value :: (Color, Color) -> Int
```

この関数は2つの色だけを受け取り、抵抗器の抵抗値の数値部分を返します。

**ボーナス：プロパティテスト**

この演習は、[プロパティテスト](https://en.wikipedia.org/wiki/Property_testing)を書くのにうってつけの機会です。これまでに書いたことがない場合は、次の資料を参考にしてください。

1. [School of Haskell](https://www.schoolofhaskell.com/user/pbv/an-introduction-to-quickcheck-testing)。
2. [Real world Haskell](http://book.realworldhaskell.org/read/testing-and-quality-assurance.html)

テストファイルには、QuickCheckのプロパティテストのサンプルを1つ用意してあります。

テストできるプロパティの例を挙げます。

- `x`が`Black`でないすべての`(x, y)`について、`value (x, y) >= 10`が成り立ちます。

- `value (x, y)`に`show`を呼び出すと、`value (y, x)`に`show`を呼び出した結果を`reverse`した文字列が得られます。

- すべての色は一意な名前を持ちます。（任意の2つの色について、色が異なれば名前も異なります。）
