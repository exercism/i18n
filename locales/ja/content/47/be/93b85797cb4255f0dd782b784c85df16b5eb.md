# 関数ヘッダーの使用

[comment]: # (このエラーは、解答で関数ヘッダーを使用したときに発生します)

関数ヘッダー（本体のない関数定義）が必要になるのは、デフォルト引数を持ち、節が複数ある関数だけです。

```elixir
# necessary function header
def hello(what \\ "World")
def hello("Alice"), do: "Hello, darling!"
def hello(name), do: "Hello, #{name}!"
```

デフォルト引数を持ち、節が1つしかない関数では、その節にデフォルト引数を直接指定できます。

```elixir
# preferred
def bye(name \\ "World"), do: "See you, #{name}!"

# not preferred - unnecessary function header
def bye(what \\ "World")
def bye(name), do: "See you, #{name}!"
```

`two_fer/1`関数には節が1つあればよいので、関数ヘッダーは必要ありません。
