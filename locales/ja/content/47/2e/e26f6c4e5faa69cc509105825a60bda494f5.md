# 説明

図が与えられたとき、幼稚園のクラスの各園児がどの植物を担当しているかを判断します。

幼稚園のクラスでは、植物の育て方について学んでいます。
先生は、実際の種を渡して実際の土に植え、本物の植物を育ててみるのがよい考えだと思いました。

育てることにしたのは、grass、clover、radishes、violetsです。

そこで園児たちは、窓辺に小さなカップを並べ、それぞれのカップに1種類ずつ、選べる種の中からランダムに選んで植えました。

```text
[window][window][window]
........................ # each dot represents a cup
........................
```

クラスには12人の園児がいます:

- Alice、Bob、Charlie、David、
- Eve、Fred、Ginny、Harriet、
- Ileana、Joseph、Kincaid、Larry

それぞれの園児にカップが4つずつ、各列に2つずつ割り当てられます。
先生は、園児の名前のアルファベット順にカップを割り当てます。

次の図はAliceの植物を表しています:

```text
[window][window][window]
VR......................
RG......................
```

窓に一番近い1列目には、violetとradishがあります。
2列目にはradishとgrassがあります。

プログラムには、窓に一番近い列から始めて、左から右へ植物が与えられます。
そこから、どの植物がどの園児のものかを判断できるようにしましょう。

例えば、庭が次のようになっているとします:

```text
[window][window][window]
VRCGVVRVCGGCCGVRGCVCGCGV
VRCCCGCRRGVCGCRVVCVGCGCV
```

このときAliceの植物を尋ねられたら、次のように答えます:

- Violets, radishes, violets, radishes

Bobの植物を尋ねた場合は、次のようになります:

- Clover, grass, clover, clover
