# はじめに

## ジェネリクス

### はじめに

ジェネリクスは、コードの再利用を可能にする言語の機能です。
たとえば、配列の長さを計算するのに、その配列がどんな型を持つかは関係ないはずです。
だからこそ、`length`関数は型シグネチャの中でジェネリックな型パラメーター`a`を使っています。

```elm
length : List a -> Int
```

### 型のパラメーター

ある型が別の型に対してジェネリックであるとき、その別の型には小文字の名前を使い、それを型パラメーターと呼びます。
よくある例は、`List`、`Maybe`、`Result`というカスタム型です。

```elm
-- Maybe is generic over the type a
type Maybe a
    = Nothing
    | Just a

someString : Maybe String
someString = Just "hello"

someInt : Maybe Int
someInt = Just 42
```

型パラメーターの名前について大切なのは、複数の文字を使えるということです。
唯一の制約は、小文字の名前でなければならないことです。
そのため、役に立つときには、説明的な名前を付けることがよくあります。

型は複数の別の型に対してジェネリックになれるので、複数の型パラメーターを持つこともできます。
その場合、それぞれ独立した型に違う小文字の名前を付けます。
独立しているからといって、同じ型になれないわけではありません。ただ、違う型になれるようになるだけです。

```elm
-- Result is generic over the types error and value
type Result error value
    = Ok value
    | Err error
```

レコードの型エイリアスも型パラメーターを持てますが、あまり一般的ではありません。

```elm
-- Event is generic over the type a
type alias Event a =
    { at : Time
    , data : a 
    }
```

### 関数における型パラメーター

型がジェネリックになれるのですから、関数も同様です。
ジェネリックな型を扱う関数を書くこともできます。たとえば`Maybe.withDefault`です。

```elm
withDefault : a -> Maybe a -> a
withDefault default maybe =
    case maybe of
      Just value -> value
      Nothing -> default
```

他の関数を仮引数として受け取る関数は高階関数と呼ばれ、これらもジェネリックになれます。

```elm
map : (a -> b) -> Maybe a -> Maybe b
map function maybe =
  case maybe of
    Just value ->
      Just (function value)

    Nothing ->
      Nothing
```
