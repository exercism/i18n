# タプル

タプルは、決まった数の、さまざまな型のデータをまとめる手軽な方法です。タプルには特定の名前がありません。データ構造に名前を付けると、それは`struct`になります。タプルのフィールドには名前がありません。フィールドにアクセスするには、分配を使うか、位置を指定します。

## 構文

タプルは、括弧（`()`）で囲まれたフィールドのリストです。

- `()` は `unit type` で、[特殊なケース](https://doc.rust-lang.org/std/primitive.unit.html)です
- **(** _式_ **,)** は単一要素のタプル式です
- **(** _型_ **,)** は単一要素のタプル型です
- **(** _式_ **,** ... **)** は一般的なタプル式です
- **(** _型_ **,** ... **)** は一般的なタプル型です

### 作成

タプルは常にタプル式で作成します。

```rust
// pointless but legal
let unit = ();
// single element
let single_element = ("note the comma",);
// two element
let two_element = (123, "elements can be of differing types");
```

タプルは任意の数の要素を持てます。

### 分配によるアクセス

分配を使ってタプルの要素にアクセスできます。これは、タプルの個々の要素に変数名を割り当てて、タプルを消費するということだけです。

```rust
let (elem1, _elem2) = two_element;
assert_eq!(elem1, 123);
```

### 位置によるアクセス

数値の位置インデックスを使ってタプルの要素にアクセスすることもできます。インデックスは、いつもどおり0から始まります。

```rust
let notation = single_element.0;
assert_eq!(notation, "note the comma");
```

## タプル構造体

タプル構造体も扱うことになります。通常の構造体と同じく、これらは名前付きの型です。ただし通常の構造体と違い、フィールドは匿名です。その構文は通常のタプルの構文とよく似ています。分配と位置によるアクセスの両方を使えます。

```rust
struct TupleStruct(u8, i32);
let my_tuple_struct = TupleStruct(123, -321);
let borrowed_neg = &my_tuple_struct.1;
let TupleStruct(borrowed_byte, _) = &my_tuple_struct;
assert_eq!(borrowed_neg, &-321);
assert_eq!(borrowed_byte, &123);
```

### フィールドの可視性

匿名タプルのフィールドはすべて常に公開されています。ただし、タプル構造体のフィールドには個別の可視性があり、標準の構造体のフィールドと同じく、既定では非公開です。標準の構造体と同じように、`pub`修飾子を付けるとフィールドを公開できます。

```rust
// fails due to private fields
mod tuple { pub struct TupleStruct(u8, i32); }
fn main() { let _my_tuple_struct = tuple::TupleStruct(123, -321); }
```

```rust
// succeeds: fields are public
mod tuple { pub struct TupleStruct(pub u8, pub i32); }
fn main() { let _my_tuple_struct = tuple::TupleStruct(123, -321); }
```
