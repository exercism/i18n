# はじめに

## 正規表現

Gleamの正規表現は、Java、JavaScript、Rubyといった他の人気のある言語と同様に、**PCRE**（**P**erl **C**ompatible **R**egular **E**xpressions）仕様に従います。

`gleam_regexp`パッケージの`gleam/regexp`モジュールには、正規表現を扱うための関数が用意されています。

~~~~exercism/note
この演習は、文字クラス、量指定子、グループ、キャプチャを含む正規表現の構文をすでに知っていることを前提としています。

正規表現の知識を復習したい場合は、次のいずれかの情報源をチェックしてみてください：[Regular-Expressions.info](https://www.regular-expressions.info)、[Rex Egg](https://www.rexegg.com/)、[RegexOne](https://regexone.com/)、[Regular Expressions 101](https://regex101.com/)、[RegExr](https://regexr.com/)。
~~~~

正規表現を作成するもっとも一般的な方法は、`regexp.from_string`関数を使うことです。

```gleam
let assert Ok(re) = regexp.from_string("test")
```

正規表現を作成する関数は、正規表現の構文が無効な場合にエラーを返します。そのためここでは、正規表現が有効であることを確認するためにletアサーションを使っています。

`regexp.check`関数を使うと、正規表現が文字列に一致するかどうかを確認できます。

```gleam
let assert Ok(re) = regexp.from_string("test")

regexp.check(re, "this is a test")
// -> True

regexp.check(re, "this is too")
// -> False
```


### キャプチャ

正規表現を使って部分文字列をキャプチャしたい場合は、`regexp.scan`関数を使うと、一致したものの配列を返すことができます。

```gleam
let assert Ok(re) = regexp.from_string("[oi]n a (\\w+)")
regexp.scan(with: re, content: "I am on a boat in a lake.")
// -> [
//   Match(
//     content: "on a boat",
//     submatches: [Some("boat")]
//   ),
//   Match(
//     content: "in a lake",
//     submatches: [Some("lake")]
//   )
// ]
```

### 修飾子

正規表現の動作は、`regexp.compile`関数で作成するときにオプションを渡すことで変更できます。

```gleam
let options = regexp.Options(case_insensitive: True, multi_line: False)
let assert Ok(re) = regexp.compile("[A-Z]", with: options)
regexp.check(re, "abc123")
// -> True
```
