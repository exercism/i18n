# はじめに

C#におけるオブジェクト指向の中心的な構成要素は_クラス_です。クラスは、データ（_フィールド_）と振る舞い（_メソッド_）を組み合わせたものです。クラスのフィールドとメソッドは、その_メンバー_と呼ばれます。

メンバーへのアクセスは、アクセス修飾子で制限できます。特によく使われるのは、次の2つです：

- `public`: どのコードからでもメンバーにアクセスできます（制限なし）。
- `private`: 同じクラス内のコードからしかメンバーにアクセスできません。

クラスは、そのクラスのインスタンスを作るためのテンプレートだと考えることができます。クラスのインスタンス（_オブジェクト_とも呼ばれます）を作るには、`new`キーワードを使います：

```csharp
class Car
{
}

// Create two car instances
var myCar = new Car();
var yourCar = new Car();
```

フィールドには型があり、クラス内のどこにでも定義できます。
パブリックなフィールドはPascalCaseで、プライベートなフィールドはcamelCaseで定義し、先頭にアンダースコア`_`を付けます：

```csharp
class Car
{
    // Accessible by anyone
    public int Weight;

    // Only accessible by code in this class
    private string _color;
}
```

フィールドには、初期値を任意で割り当てることができます。フィールドが初期値を指定して_いない_場合、その型の既定値が設定されます。インスタンスのフィールドの値には、ドット記法を使ってアクセスしたり更新したりできます。

```csharp
class Car
{
    // Will be set to specified value
    public int Weight = 2500;

    // Will be set to default value (0)
    public int Year;
}

var newCar = new Car();
newCar.Weight; // => 2500
newCar.Year;   // => 0

// Update value of the field
newCar.Year = 2018;
```

プライベートなフィールドは、通常、メソッドを呼び出した副作用として更新されます。そのようなメソッドは通常、値を返しません。その場合、戻り値の型は`void`にします：

```csharp
class CarImporter
{
    private int _carsImported;

    public void ImportCars(int numberOfCars)
    {
        // Update private field from public method
        _carsImported = _carsImported + numberOfCars;
    }
}
```
