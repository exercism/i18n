# 説明

この演習では、貯蓄口座を扱います。貯蓄口座の残高は、毎年、その利率に基づいて更新されます。銀行が提示する利率は、口座に入っている金額（残高）によって決まります：

- 残高がマイナスの場合は3.213%（利息もマイナスになります）。
- 残高がプラスで`1000`ドル未満の場合は0.5%。
- 残高がプラスで`1000`ドル以上`5000`ドル未満の場合は1.621%。
- 残高がプラスで`5000`ドル以上の場合は2.475%。

毎年、政府は資金の一定割合を非課税で慈善団体に寄付することを認めています。親切な人なので、年末に残高がプラスになっていれば、その非課税の割合を2倍にし、1ドル単位で切り捨てます。寄付の後半分に税金がかかっても気にしません。

タスクは3つあり、それぞれが残高とその利率を扱います。

## 1. 利率を計算する

指定された残高に基づいて利率を計算する`interestRate`関数を実装します：

```fsharp
interestRate 200.75m
// => 0.5f
```

戻り値は`single`であることに注意してください。

## 2. 利息を計算する

指定された残高に基づいて利息を計算する`interest`メソッドを実装します：

```fsharp
interest 200.75m
// => 1.00375m
```

戻り値は`decimal`であることに注意してください。

## 3. 年間の残高更新額を計算する

利率を考慮して、年間の残高更新額を計算する`annualBalanceUpdate`関数を実装します：

```fsharp
annualBalanceUpdate 200.75m
// => 201.75375m
```

戻り値は`decimal`であることに注意してください。

## 4. 寄付する金額を計算する

残高と、政府が認める非課税の割合に基づいて、慈善団体に寄付する金額を計算する`amountToDonate`関数を実装します：

```fsharp
let balance = 550.5m
let taxFreePercentage = 2.5
amountToDonate balance taxFreePercentage
// => 27
```

戻り値は`int`であることに注意してください。
