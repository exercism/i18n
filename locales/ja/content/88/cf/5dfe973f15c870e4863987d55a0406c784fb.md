# リソース

## 学習

- [Nim basics](https://narimiran.github.io/nim-basics/) - プログラミング初心者向けです。
- [Nim tutorial, part 1](https://nim-lang.org/docs/tut1.html) - ある程度プログラミングの経験がある人向けです。
- [Learn X in Y minutes for Nim](https://learnxinyminutes.com/docs/nim/) - 文法の概要です。
- [Nim for Python programmers](https://github.com/nim-lang/Nim/wiki/Nim-for-Python-Programmers)
- [Nim for C programmers](https://github.com/nim-lang/Nim/wiki/Nim-for-C-programmers)
- [Nim in Action](https://www.manning.com/books/nim-in-action) - 紙の書籍または電子書籍で入手できます。

さらに詳しくは、公式の[Learn Nim](https://nim-lang.org/learn.html)ページを見てみましょう。

## ドキュメント

- [Standard Library](https://nim-lang.org/docs/lib.html) - 標準ライブラリのモジュールの概要です。
- [Nim Manual](https://nim-lang.org/docs/manual.html) - Nim言語の仕様です。
- [Searchable index](https://nim-lang.org/docs/theindex.html)

さらに詳しくは、公式の[Nim Documentation](https://nim-lang.org/documentation.html)ページを見てみましょう。
