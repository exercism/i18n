# 説明

この演習では、フリーランサーがプロジェクトマネージャーとやり取りできるよう、コードを書きます。日額と月額の料金をすばやく計算するためのいくつかのユーティリティを用意するのが、ここでの課題です。割引を指定して適用することもできます。

まず、フリーランサーとプロジェクトマネージャーの間で、いくつかのルールを決めておきます。

- 日額は時給の8倍です。
- 1か月は請求可能な22日とします。

フリーランサーは、日額に割引を適用することがあります（たとえば、最も忠実な顧客や非営利の顧客向けです）。

割引は、パーセンテージを表す小数として扱います。たとえば`25.0`（25%）です。

## 1. 時給から日額を計算する

`daily_rate`という関数を実装しましょう。この関数は、時給を入力として受け取り、日額を計算します。契約では、1日は請求可能な8時間と定められています。

```elixir
FreelancerRates.daily_rate(60)
# => 480.0
```

返される日額は小数にします。

## 2. 割引後の価格を計算する

割引後の価格を計算する`apply_discount`関数を実装しましょう。

```elixir
FreelancerRates.apply_discount(150, 10)
# => 135.0
```

返される値は常に小数とし、一切丸めないようにします。

## 3. 時給と割引から月額を計算する

割引後の月額を計算する`monthly_rate`関数を実装しましょう。時給と、パーセントで表した割引の2つを入力として受け取ります。

```elixir
FreelancerRates.monthly_rate(77, 10.5)
# => 12130
```

返される月額は、最も近い整数に切り上げます（天井をとります）。

## 4. 予算、時給、割引から、まるまる働ける日数を計算する

予算、時給、割引を受け取り、それで何日分まるまる働けるかを計算する`days_in_budget`関数を実装しましょう。

```elixir
FreelancerRates.days_in_budget(20000, 80, 11.0)
# => 35.1
```

返される日数は、小数点以下1桁に切り捨てます（床をとります）。
