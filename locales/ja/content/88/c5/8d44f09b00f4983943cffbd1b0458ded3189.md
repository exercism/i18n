# はじめに

Factorの文字は整数であり、Unicodeのコードポイントです。そのため、数値の`<`、`>`、`=`を使えば、大文字と小文字を区別した順序付けがそのまま得られます。[`unicode`][unicode]のボキャブラリは、Unicodeを考慮した述語と、1文字単位の大文字・小文字変換を追加します。

## 文字の述語

```
LETTER?  ( c -- ? )    ! uppercase letter
letter?  ( c -- ? )    ! lowercase letter
Letter?  ( c -- ? )    ! letter, either case
digit?   ( c -- ? )    ! decimal digit
blank?   ( c -- ? )    ! whitespace
```

```factor
USING: unicode ;

CHAR: A LETTER? .    ! => t
CHAR: a letter? .    ! => t
CHAR: 7 digit?  .    ! => t
```

## 大文字と小文字の変換

`ch>upper`と`ch>lower`は1文字だけを変換します。文字列全体を対象にする`>upper`と`>lower`は、これを文字列のすべての文字に適用します。

```factor
CHAR: a ch>upper .   ! => 65   (which is CHAR: A)
"Hello" >upper .     ! => "HELLO"
```
