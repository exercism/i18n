# はじめに

同じコードを何度も使いたい場面があります。そんなときは、そのコードを関数にまとめておくと便利です。関数は、たいてい1つの特定の処理だけを行います。Rustでは、関数を定義するために```fn```キーワードを使います。関数に属するコードは、必ず波括弧（`{}`）の間に書きます。`main`という名前の関数は、プログラムのエントリーポイントになる特別な関数です。この関数から、他の関数を呼び出すことができます。

```rust
fn say_my_name(name: &str) -> &str {
    name
}
```

関数は、```say_my_name()```の```name: &str```のように、仮引数を受け取ることもできます。また、上の`-> &str`のように、戻り値を返すこともできます。
