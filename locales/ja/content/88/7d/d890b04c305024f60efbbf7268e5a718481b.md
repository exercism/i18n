# 手順

画家を目指している友人が、あるプロジェクトのアイデアを持ちかけてきました。彼の視覚的な創造性と、技術的な専門知識を組み合わせてみましょう。そろそろ[ジェネラティブアート][generative-art]に手を出してみる時です！

制約は創造性を後押しし、プロジェクトの締め切りを短くします。そこで2人は、傑作に使う図形を円たった1つに絞ることにしました。でも、円はたくさん登場します。しかも、動き回ります！　名前は……そう、「dancing dots」に決まりです。

友人はきっと、ドットのための新しい複雑な動きを次々と考えたくなるはずです。そこでまずは、あとから新しいアニメーションを簡単に定義できるような設計を作ることからコーディングを始めましょう。

## 1. アニメーションの振る舞いを定義する

各アニメーションモジュールは、`init/1`と`handle_frame/3`という2つのコールバックを実装する必要があります。これらを`Animation`モジュールに定義します。

`init/1`コールバックを定義します。これは`opts`型の引数を1つ取り、`{:ok, opts}`タプルか`{:error, error}`タプルのいずれかを返す必要があります。このコールバックの実装では、与えられたオプションがその種類のアニメーションにとって有効かどうかを確認します。

`handle_frame/3`コールバックを定義します。これは3つの引数、つまりドット、フレーム番号、オプションを取ります。常にドットを返す必要があります。このコールバックの実装では、現在のフレーム番号とアニメーションのオプションに基づいて、ドットの属性を変更します。

## 2. `init/1`コールバックのデフォルト実装を用意する

`Animation`の振る舞いは、`use DancingDots.Animation`を呼び出すだけで他のモジュールに簡単に組み込めるようにするべきです。

これを実現するために、`Animation`モジュールに`__using__`マクロを実装し、`Animation`モジュールを他のモジュールの振る舞いとして設定するようにします。また、`init/1`コールバックのデフォルト実装も提供する必要があります。`init/1`のデフォルト実装は、与えられたオプションをそのまま返す必要があります。

```elixir
defmodule MyCustomAnimation do
  use DancingDots.Animation
end

MyCustomAnimation.init(some_option: true)
# => {:ok, [some_option: true]}
```

## 3. `Flicker`アニメーションを実装する

`Animation`の振る舞いを使って、点滅するアニメーションを実装します。

このアニメーションはオプションを取らないため、デフォルトの`init/1`コールバックを使う必要があります。

1つのフレームを処理する`handle_frame/3`コールバックを実装します。フレーム番号が4の倍数のとき、関数はドットを元の不透明度の半分にして返す必要があります。それ以外のフレームでは、ドットをそのまま返す必要があります。

フレームは`1`から数えます。`handle_frame/3`に渡されるドットは、常に元の状態のドットであり、前のフレームの状態ではありません。

```elixir
dot = %DancingDots.Dot{x: 100, y: 100, radius: 24, opacity: 1}

DancingDots.Flicker.handle_frame(dot, 1, [])
# => %DancingDots.Dot{opacity: 1, radius: 24, x: 100, y: 100}

DancingDots.Flicker.handle_frame(dot, 4, [])
# => %DancingDots.Dot{opacity: 0.5, radius: 24, x: 100, y: 100}
```

## 4. `Zoom`アニメーションを実装する

`Animation`の振る舞いを使って、ズームするアニメーションを実装します。

このアニメーションは1つのオプション、つまり速度を取ります。速度には任意の数値を指定できます。負の値の場合は、ドットはズームインではなくズームアウトします。

`init/1`コールバックを実装します。渡されたオプションが`:velocity`キーを持つキーワードリストであることを検証する必要があります。速度の値は数値でなければなりません。数値でない場合は、エラー`"The :velocity option is required, and its value must be a number. Got: #{inspect(velocity)}"`を返します。

`handle_frame/3`コールバックを実装します。現在のフレーム番号から1を引いた値に速度を掛けた分だけ、半径を増やしたドットを返す必要があります。

フレームは`1`から数えます。`handle_frame/3`に渡されるドットは、常に元の状態のドットであり、前のフレームの状態ではありません。

```elixir
DancingDots.Zoom.init(velocity: nil)
# => {:error, "The :velocity option is required, and its value must be a number. Got: nil"}

dot = %DancingDots.Dot{x: 100, y: 100, radius: 24, opacity: 1}

DancingDots.Zoom.handle_frame(dot, 1, velocity: 10)
# => %DancingDots.Dot{radius: 24, opacity: 1, x: 100, y: 100}

DancingDots.Zoom.handle_frame(dot, 2, velocity: 10)
# => %DancingDots.Dot{radius: 34, opacity: 1, x: 100, y: 100}
```
