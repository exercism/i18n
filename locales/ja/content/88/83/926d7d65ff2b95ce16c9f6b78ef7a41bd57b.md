# 数値

Crystalには`Number`という型があり、これはすべての数値型の基本となる型です。
`Number`型には、主に2つのサブタイプがあります。[`Int`][int]と[`Float`][float]です。

`Int`はintegerの略で、整数を表します。
`Int`は負にも正にもなり、小数点は含みません。

```crystal
1.class
# => Int32

-1.class
# => Int32
```

`Float`は小数点を含む数値を表します。
`Float`も負と正の両方の値をとることができます。

```crystal
10.5.class
# => Float64
```

## `Int`と`Float`の変換

'to_i'と'to_f'メソッドを使うと、`Int`と`Float`の間で変換できます。
`Float`から`Int`に変換するときは、小数点以下が切り捨てられます。

```crystal
1.to_f
# => 1.0

1.0.to_i
# => 1

1.9.to_i
# => 1
```

## 算術演算子

`Int`と`Float`に対しては、[基本的な算術演算子][math]を使えます。
演算子は`+`、`-`、`*`、`/`、`%`です。
これらの演算子を使うときは、`Int`と`Float`を混在させることができます。

### 足し算・引き算・掛け算

`+`は足し算、`-`は引き算、`*`は掛け算に使います。

| 演算子 | 例             |
| ------ | -------------- |
| `+`    | `4 + 6 => 10`  |
| `-`    | `15 - 10 => 5` |
| `*`    | `2 * 3 => 6`   |

### 割り算

割り算は数値を割るために使います。
`/`が割り算の演算子です。
結果は必ずFloatになります。

```crystal
4 / 2
# => 2.0

4.0 / 2
# => 2.0
```

~~~~exercism/caution
プログラミング言語によっては、0で割るとエラーになります。

Crystalでは、0で割ったときの結果は`Infinity`か`-Infinity`になります。
唯一の例外は0を0で割った場合で、結果は`NaN`（Not a Number）になります。
`Infinity`と`NaN`は、`Float`型にある特別な値です。

```crystal
1 / 0
# => Infinity

-1 / 0
# => -Infinity

0 / 0
# => NaN
```
~~~~

### 余り

余りは、割り算をして残った数を求めるために使います。
`%`が余りの演算子です。

```crystal
5 % 2
# => 1

5.0 % 2
# => 1.0

5 % 3
# => 2
```

~~~~exercism/caution
余りを求めるときに0で割ると、DivisionByZeroErrorになります。
これは通常の割り算とは異なります。

```crystal
1 % 0
# Error: Unhandled exception: Division by 0 (DivisionByZeroError)
```
~~~~

## 丸め

`round`メソッドは、省略可能な引数として、丸める小数点以下の桁数をとります。
デフォルトの桁数は0です。

```crystal
1.0.round
# => 1

1.5.round
# => 2

1.234.round(2)
# => 1.23
```

## 優先順位と括弧

Crystalでは括弧（`()`）を使うことができ、式をまとめるのに役立ちます。
これは、演算の順序を変えたいときに便利です。

複数の算術演算子を使うときの演算の順序は数学と同じで、[PEMDAS][pemdas]と呼ばれます。
括弧（`()`）、指数（`**`）、掛け算（`*`）と割り算（`/`）、そして足し算（`+`）と引き算（`-`）の順に計算します。

```crystal
2 + 3 - 4 * 4
# => -11

(2 + 3 - 4) * 4
# => 4
```
