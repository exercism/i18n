# 概要

Clojureのベクターは、0個以上の値からなる、順序があり、インデックスでアクセスできる不変のコレクションです。つまり、一度作成したベクターは変更できません。ベクターを操作する関数は新しいベクターを返し、元のベクターはそのまま残ります。ベクターに入れる値は、それぞれ違う型でもかまいません。ベクターは次のように定義します。

```clojure
(def empty [])
(def single-value [5])
(def single-value-alternative (vector 5))
(def three-values [1 "a" "b"])
```

要素は、インデックスを指定してベクターから取り出せます。Clojureのベクターは0始まりで、最初の要素のインデックスは常に0です。

```clojure
(def numbers [2 3 5])
;; Read value from vector
(get numbers 2)
;;=> 5
;; Update value in vector
(assoc numbers 2 9)
;;=> [2 3 9]
```

元のベクターは変わりません。

```clojure
numbers
;;=> [2 3 5]
```

更新後の値を覚えておくには、その値を次に渡していくか、`vector`に保存しておく必要があります。

```clojure
(def updated-numbers
  (assoc numbers 2 9))
(get updated-numbers 2)
;;=> 9
```
