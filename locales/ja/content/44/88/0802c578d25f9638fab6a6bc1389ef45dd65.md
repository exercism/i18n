# 説明

RNA配列をタンパク質に翻訳します。

RNAは、コドンと呼ばれる3つのヌクレオチドからなる配列に分割でき、その後、次のようにタンパク質へと翻訳されます。

RNA: `"AUGUUUUCU"` => 次のように翻訳されます

コドン: `"AUG", "UUU", "UCU"`
=> 次の配列を持つタンパク質になります =>

タンパク質: `"Methionine", "Phenylalanine", "Serine"`

コドンは64種類あり、それらは20種類のアミノ酸に対応します。ただし、この演習では、すべてのコドン配列とそれに対応するアミノ酸が重要というわけではありません。
1つのコドンでうまく動けば、プログラムはすべてのコドンでも動くはずです。
ただし、テストスイートのリストを自由に拡張して、それらをすべて含めてもかまいません。

また、3つの終止コドン（'STOP'コドンとも呼ばれます）があります。これらのコドンのいずれかに（リボソームによって）遭遇すると、翻訳はすべて終了し、タンパク質はそこで終わります。

それ以降のコドンはすべて無視されます。次のようになります。

RNA: `"AUGUUUUCUUAAAUG"` =>

コドン: `"AUG", "UUU", "UCU", "UAA", "AUG"` =>

タンパク質: `"Methionine", "Phenylalanine", "Serine"`

終止コドン`"UAA"`で翻訳が終了し、最後のメチオニンはタンパク質配列に翻訳されないことに注意してください。

以下は、この演習に必要なコドンと対応するアミノ酸です。

| コドン              | アミノ酸      |
| :----------------- | :------------ |
| AUG                | Methionine    |
| UUU, UUC           | Phenylalanine |
| UUA, UUG           | Leucine       |
| UCU, UCC, UCA, UCG | Serine        |
| UAU, UAC           | Tyrosine      |
| UGU, UGC           | Cysteine      |
| UGG                | Tryptophan    |
| UAA, UAG, UGA      | STOP          |
