# 概要

Elixirは、[_ビヘイビア_][behaviours]を使うことで、共通の汎用インターフェースを提供しながら、そのビヘイビアを実装するモジュールごとに固有の実装を可能にします。そのようなビヘイビアのひとつが、_アクセスビヘイビア_です。

_アクセスビヘイビア_は、データ構造からキーを使ったデータを取り出すための共通のインターフェースを提供します。マップとキーワードリストに対して実装されています。

[`Access`][access]モジュールは、このインターフェースに必要なコールバックを定義します。そして[`Map`][map]モジュールと[`Keyword`][keyword]モジュールが、必要なコールバックである[`fetch/2`][map-fetch]、[`get_and_update/3`][map-get-and-update]、[`pop/2`][map-pop]を実装します。

このビヘイビアを使うには、束縛された変数のあとに_角括弧_を続けて書き、その中にキーを書くと、そのキーに対応する値を取り出すことができます。マップはどの型のキーも使えますが、キーワードリストはアトムのキーだけを使えます。

```elixir
# Atom as key
my_map = %{key: "my value"}
my_map[:key]
# => "my value"

# String as key
another_map = %{"key" => "my value"}
another_map["key"]
# => "my value"
```

データ構造にキーが存在しない場合は、`nil`が返ります。エラーにはならないため、意図しない動作の原因になることがあります。

```elixir
my_map = %{key: "my value"}
my_map[:wrong_key][:other_wrong_key]
# => nil
```

`nil`自身がアクセスビヘイビアを実装していて、どのキーに対しても常に`nil`を返すことに注意してください。

```elixir
nil[:key]
# => nil
```

構造体はアクセスビヘイビアを実装していません。
