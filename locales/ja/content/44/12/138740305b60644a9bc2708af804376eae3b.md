# はじめに

クラスのインスタンスを作るには、`new`演算子を使って[_コンストラクター_][constructor]を呼び出します。コンストラクターはクラスの中にある特別なメソッドで、その目的はクラスを初期化することです。Haxeでは、コンストラクターのメソッド名は`new()`です。

```haxe
class Library {
  private var books:Int;

  public function new() {
    this.books = 10; // Initialize the books field
  }
}

var library = new Library(); // This calls the constructor
```

普通のメソッドと同じように、コンストラクターにも仮引数を持たせることができます。これらの仮引数は（通常は）プライベートフィールドに保存され、あとから参照されます。

```haxe
class Building {
  private var numberOfStories:Int;
  private var totalHeight: Float;

  public function new(numberOfStories:Int, storyHeight:Float) {
    this.numberOfStories = numberOfStories;
    this.totalHeight = storyHeight * numberOfStories;
  }
}

var largeBuilding = new Building(55, 6.2);
```

コンストラクターを持たないクラスでは、新しいインスタンスを**作ることはできません**。そのため、空のコンストラクターを使うしかありません。

```haxe
class Car {
  public var weight:Int = 1000;

  public function new() {}
}

var myCar = new Car();
```

[constructor]: https://haxe.org/manual/types-class-constructor.html
