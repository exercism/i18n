# インストール

お使いのシステムにセットアップする方法については、[System/Installation][install-link]を参照してください。

~~~exercism/caution
Java Development Kit（JDK）をインストールしている場合、`jconsole`実行ファイルが、同じ名前を使うJava Consoleと競合する可能性があります。

対処法としては、次のようなものがあります。

- Jプログラミング言語の`jconsole`実行ファイルを、一意の名前（例：`jconsole-jlang`）に変更する。

- システムの環境変数やPATHを調整して、Jプログラミング言語の`jconsole`が優先されるようにする。

- **Linuxユーザーの場合**、`bin/install.sh`にbashスクリプトがあり、`/usr/`ディレクトリに`ijconsole`という**シンボリックリンク**を作成します。このリンクは、ターミナルで`ijconsole`と入力すると使えます。
~~~

Jをインストールしたら、ターミナルでJのコンソールを開き、次のコマンドを入力してユニットテストフレームワークをインストールします。

```j
  load 'pacman'
  'update' jpkg ''
  'install' jpkg 'general/unittest'
  exit 0
```
