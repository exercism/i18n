# 説明

この演習では、2012年9月15日にオープンしたニューヨークの美容サロン向けの予約スケジューラーに取り組みます。

5つのタスクがあり、いずれも予約の日付を扱います。
時刻は24時間形式（AM/PMなし）です。
タイムゾーンの問題をできるだけシンプルにするため、すべてUTCで扱うものとします。

## 1. 数字だけの予約日時を解析する

`schedule_appointment()`関数を実装して、テキスト形式の予約日時を対応する`DateTime`形式に解析しましょう。

入力はアメリカ式の月/日/年の順であることに注意してください。

```julia-repl
julia> schedule_appointment("07/25/2023 13:45:00")
2023-07-25T13:45:00
```

## 2. 予約がすでに過ぎているかどうかを確認する

`has_passed()`関数を実装します。この関数は予約日時を受け取り、その予約が過去のものであるかどうかを確認します。

```julia-repl
julia> has_passed(DateTime(1999, 12, 31, 9, 0, 0))
true
```

## 3. 予約が午後かどうかを確認する

`is_afternoon_appointment()`関数を実装します。この関数は予約日時を受け取り、その予約が午後（12:00以降、18:00より前）かどうかを確認します。

```julia-repl
julia> is_afternoon_appointment(DateTime(2023, 3, 29, 15, 0, 0))
true
```

## 4. 予約の曜日を確認する

`day_of_week()`関数を実装します。この関数は週の曜日を_数値_で返します。
サロンは日曜日が定休日なので、月曜日が1日目、土曜日が6日目です。

```R
# a Friday
day_of_week(make_datetime(2026, 06, 05, 12, 30, 00))
#> [1] 5
```

## 5. 予約を変更する

お客さんが予約を変更する必要があるときは、自動的に次の金曜日の同じ時刻に変更されます（金曜日は週で最も予約が少ない日だからです）。

`reschedule()`関数を実装します。この関数は元の予約（月/日/年の順のテキスト文字列）を受け取り、変更後の予約を返します。

```R
# a Saturday
reschedule("06/13/2026 12:30:00")
#> [1] "2026-06-19 12:30:00 UTC"
```

元の予約が月曜日から木曜日の場合、_今週_の金曜日に変更します。
予約が金曜日または土曜日の場合は、_来週_の金曜日に変更します。
