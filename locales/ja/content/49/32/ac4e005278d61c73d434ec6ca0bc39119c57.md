# in-out仮引数

関数の本体の中では、仮引数は変数ではなく定数として扱われます。仮引数の値を変更しようとすると、コンパイル時のエラーになります。
関数の中で仮引数の値を変更したい場合は、in-out仮引数を使って、その可変性を明示する必要があります。

in-out仮引数を使うには、次の3つのポイントを押さえる必要があります。

1. 関数の定義では、仮引数の型注釈の中で`:`と型名の間にキーワード`inout`を書き、in-out仮引数であることを明示しなければなりません。
2. in-out仮引数に渡す値は、定数ではなく変数として宣言されている必要があります。同様に、リテラルを渡すこともできません。
3. 関数を呼び出すときは、変数名の前に`&`を付け、変更可能であることを明示しなければなりません。

このようにすると、関数はin-out仮引数の内部コピーを作り、関数本体で指示されたとおりにそれを変更してから、関数が戻るときに変更後の値を、渡された変数へコピーし直します。

```swift
func updateVersion(_ record: inout (version: Int, title: String)) {
  record.version += 1
}

var dbRecord = (version: 2, title: "Exercism")
updateVersion(&dbRecord)

// dbRecord is now (3, "Exercism")
```

~~~~exercism/warning
in-out仮引数については、ほかにも知っておきたいルールがいくつかあります。

1  in-out仮引数を持つ関数の内部では、in-out仮引数として渡された変数を参照することはできません。
2. 同じ変数を、同じ関数の複数のin-out仮引数として渡すことはできません。
   たとえば、`inoutFunc(&mutVar, &mutVar)`と書くと、コンパイラエラーになります。
~~~~
