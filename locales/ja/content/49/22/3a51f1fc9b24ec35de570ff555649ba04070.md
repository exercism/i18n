# 指示

自分だけのロールプレイングゲームを開発しているとしましょう。ゲームの中には、_キャラクター_と_アイテム_が登場します。アイテムに対してできる操作はたくさんありますが、その1つが、キャラクターにアイテムを食べさせることです。

すべてのアイテムが食べられるわけではなく、食べられるアイテムがすべて同じ効果をキャラクターに及ぼすわけでもありません。食べると別のアイテムに変わるものもあります（たとえば、りんごを食べると、りんごの芯が残ります）。

こうした柔軟性を実現するために、一部のアイテムが実装できる`Edible`プロトコルを作ることにしました。

## 1. 食べられるかどうかを定義する

`RPG.Edible`プロトコルを作成します。このプロトコルが持つ関数は1つ、`eat`です。`eat`関数は、アイテムとキャラクターを受け取り、副産物とキャラクターを返します。

## 2. パンを食べられるようにする

`RPG.LoafOfBread`アイテムに`RPG.Edible`プロトコルを実装します。パンは、食べられるとキャラクターに体力ポイントを5与え、副産物はありません。

```elixir
RPG.Edible.eat(%RPG.LoafOfBread{}, %RPG.Character{health: 31})
# => {nil, %RPG.Character{health: 36, mana: 0}}
```

## 3. マナポーションを食べられるようにする

`RPG.ManaPotion`アイテムに`RPG.Edible`プロトコルを実装します。マナポーションは、食べられると、ポーションの強さと同じだけのマナポイントをキャラクターに与え、空のビンを生み出します。

```elixir
RPG.Edible.eat(%RPG.ManaPotion{strength: 13}, %RPG.Character{mana: 50})
# => {%RPG.EmptyBottle{}, %RPG.Character{health: 100, mana: 63}}
```

## 4. 毒を食べられるようにする

`RPG.Poison`アイテムに`RPG.Edible`プロトコルを実装します。毒は、食べられると、キャラクターから体力ポイントをすべて奪い、空のビンを生み出します。

```elixir
RPG.Edible.eat(%RPG.Poison{}, %RPG.Character{health: 3000})
# => {%RPG.EmptyBottle{}, %RPG.Character{health: 0, mana: 0}}
```
