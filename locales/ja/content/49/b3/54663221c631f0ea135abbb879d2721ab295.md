# 説明

むかしむかし、鉄格子のついた窓のある不思議な家に住む、風変わりなプログラマーがいました。ある日、彼はオンラインの求人サイトで、パーティーロボットを作る仕事を引き受けました。そのロボットは、人々にあいさつして、席へ案内するはずのものでした。最初のバージョンはとても機械的で、プログラマーが人づきあいを苦手としていることがにじみ出ていました。その一部は、次のバージョンにもそのまま残ってしまいました。

## 1. パーティーに来た新しいゲストを歓迎する

`welcome`メソッドを実装して、与えられた名前を使った歓迎のメッセージを返すようにしましょう。

```crystal
PartyRobot.welcome("Christiane")
# => Welcome to my party, Christiane!
```

## 2. 今日が誕生日の新しいゲストを歓迎する

`happy_birthday`メソッドを実装して、与えられた名前と年齢を使った誕生日のメッセージを返すようにしましょう。残念ながら、このプログラマーは少し見せびらかしたがりなので、ロボットはゲスト全員の誕生日を知っているところを見せなければなりません。

```crystal
PartyRobot.happy_birthday("Frank", 58)
# => Happy birthday Frank! You are now 58 years old!
```

## 3. 道案内をする

`assign_table`関数を実装して、道案内をするようにしましょう。この関数は5つの入力を受け取ります。

- 歓迎する新しいゲストの名前（`String`）
- テーブル番号（`Int`）
- 隣に座る人の名前（`String`）
- テーブルのある方向（`String`）
- テーブルまでの距離（`Float64`）

正確な結果のフォーマットは、以下の例で確認できます。

隣に座る人の名前は、その名前の最初と最後の文字に短縮します。FrankはFk、ChristianはCn、というようになります。

ロボットはテーブル番号を伝えます。また、テーブルまでの距離にも触れます。ありがたいことに、その精度は小数点以下1桁までに限られています。

```crystal
PartyRobot.assign_table("Christiane", "on the left", 27, 23.7834298, "Frank")
# =>
# Welcome to my party, Christiane!
# You have been assigned to table 27. Your table is on the left, exactly 23.8 meters from here.
# You will be sitting next to Fk.
```
