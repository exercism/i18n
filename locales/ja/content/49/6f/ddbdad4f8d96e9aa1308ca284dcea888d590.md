# 概要

Factorは、`random`ボキャブラリの中でランダム性を、1つの総称ワードに集約しています。

```
random ( obj -- elt )
```

これは、引数の型に応じて処理を切り替えます。

- **整数**`n`を渡すと、`[0, n)`の範囲のランダムな整数を返します。
- **シーケンス**を渡すと、ランダムな要素を1つ返します。
- 連想配列やハッシュセット、`uniform-distribution`タプルにも対応しています。

これを土台にした、シーケンス用の補助ワードが2つあります。

```factor
USING: random ;

{ 1 2 3 4 5 } randomize .   ! shuffle in place (Fisher–Yates)
{ 1 2 3 4 5 } 3 sample .    ! 3 distinct elements; error if too many
```

`randomize`はシーケンスをその場で変更し、そのシーケンスを返します。元の順序を保っておきたい場合は、先に`clone`しておきましょう。

## ランダム性はどこから来るのか

`random`は、`random-generator`という動的変数に保持されているジェネレーターから値を読み取ります。デフォルトでは、システムクロックを種としたメルセンヌ・ツイスターなので、プロセスごとに結果が異なります。クォーテーションの実行中だけ、別のジェネレーターを設定することもできます。

```
<mersenne-twister> ( seed -- rnd )
with-random        ( rnd quot -- )
```

```factor
USING: random random.mersenne-twister ;

42 <mersenne-twister> [ { 1 2 3 } randomize ] with-random .
! => the same ordering on every run
```

`with-random`は、クォーテーションの動的範囲の間だけ`random-generator`を束縛するだけなので、これをラップするワードには`inline`を付けておくべきです。そうすれば、クォーテーションが結果をスタックに残し、呼び出し元がそれを受け取れます。

これ以外にも、`random`には他の分布のための`random-bits`、`random-unit`、`uniform-random`、`normal-random`があり、さらに再現不可能な乱数や暗号用途のための`system-random-generator`と`secure-random-generator`も用意されています。
