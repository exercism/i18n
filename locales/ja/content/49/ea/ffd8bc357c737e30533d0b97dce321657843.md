# はじめに

友人のEliudは、祖母のTigistから農場を受け継ぎました。
祖母は発明家で、物事を必要以上に複雑に作り上げる癖がありました。
鶏小屋にはデジタルディスプレイがあり、拾うことができる卵の位置を符号化した数値が表示されています。

Eliudは、鶏小屋にある実際の卵の数を表示するプログラムを書くよう頼んできています。

位置情報の符号化は、次のように計算します。

1. 卵が産まれそうな場所をすべて確認し、卵があれば`1`、空っぽであれば`0`を書き留めます。
2. その数を2進数から10進数に変換します。
3. 結果をディスプレイに表示します。

例1：

```text
Chicken Coop:
 _ _ _ _ _ _ _
|E| |E|E| | |E|

Resulting Binary:
 1 0 1 1 0 0 1

Decimal number on the display:
89

Actual eggs in the coop:
4
```

例2：

```text
Chicken Coop:
 _ _ _ _ _ _ _ _
| | | |E| | | | |

Resulting Binary:
 0 0 0 1 0 0 0 0

Decimal number on the display:
16

Actual eggs in the coop:
1
```
