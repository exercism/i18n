# 説明

この演習では、はかりをモデル化します。

## 1. はかりの初期状態を作成する

初期化されるとき、はかりは工場出荷時の設定を参照する必要があります。この設定は、はかりが販売される地域によって異なります。
そのため、はかりは精度と、メートル法かヤード・ポンド法かの指定を付けて初期化できるようにします。

2つの引数を取る`WeighingMachine#initialize`メソッドを実装します。`precision`は`Int32`、`metric`は`Bool`です。
`metric`引数が`true`のときはメートル法を、そうでなければヤード・ポンド法を使うことを意味します。
また、初期化メソッドでは、インスタンス変数`@weight`を`0.0`に設定します。

```crystal
precision = 3
metric = true
vm = WeighingMachine.new(precision, metric)
```

## 2. はかりに精度を持たせる

さまざまな要求に応えるため、各はかりは精度（小数点以下の桁数）を指定してカスタマイズできるようにします。

`WeighingMachine#precision`ゲッターメソッドを実装し、はかりの精度を返すようにします。

```crystal
precision = 3
metric = true
vm = WeighingMachine.new(precision, metric)
vm.precision
# => 3
```

## 3. はかりに重さを設定できるようにする

`WeighingMachine#weight`プロパティを実装し、重さの取得と設定の_両方_ができるようにします。

```crystal
precision = 3
metric = true
wm = WeighingMachine.new(precision, metric)
wm.weight = 60.5
wm.weight
# => 60.5

wm.weigh
# => 60.5
```

## 4. メートル法とヤード・ポンド法を切り替えられるようにする

`WeighingMachine#metric=`プロパティを実装し、単位を設定できるようにします。
真偽値を受け取れるようにします。

```crystal
precision = 3
metric = true
wm = WeighingMachine.new(precision, metric)
vm.weight = 60.5
wm.metric = false

vm.weigh
# => 133.377
```
