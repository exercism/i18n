# はじめに

AWKはとても小さな言語で、基本的なデータ型が少ししかありません。
このレッスンでは、数値と文字列について見ていきます。

## 数値

AWKの数値は、倍精度浮動小数点数として実装されています。
整数、小数、倍精度小数の区別はありません。

AWKは、8進数の定数（`0`で始まる）と16進数の定数（`0x`または`0X`で始まる）を理解します。

### 数値の演算

標準的な算術演算子`+`、`-`、`*`、`/`、`%`を使えます。
べき乗の演算子は`^`です。
三角関数、乱数生成、数値を_x_と0の間の最も近い整数に切り捨てる`int(x)`など、組み込みの数値関数がいくつかあります。

## 文字列

AWKの文字列は文字の並びです。
文字列の定数は、二重引用符で指定します。

### 文字列の演算

文字列の演算は1つだけです。それは連結です。
連結には特別な演算子はありません。
2つの文字列を単に並べるだけで連結されます。

```awk
BEGIN {
    hw = "Hello" "World"
    print hw
}
# => HelloWorld
```

~~~~exercism/note
`print`は関数ではなく**文**です。
`print`に括弧は必要ありません。
~~~~

AWKには文字列を操作する関数が豊富に用意されています。
それらについては、トラックを進めていく中で詳しく紹介していきます。

## 数値と文字列の変換

数値と文字列を変換する明示的な演算子はありません。
AWKは、プログラムの文脈に応じて、これを暗黙的に行います。
そのため、入力フィールドの値を扱うのはとても簡単です。AWKはたいてい、思いどおりに動いてくれます。

* `print x + y`は、`+`の数値演算によって、変数`x`と`y`の値を数値に変換します。
* `print x y`は、連結によって、変数`x`と`y`の値を文字列に変換します。

明示的に変換したい場合は、`0 + x`が_x_の数値表現、`"" x`が_x_の文字列表現になります。

### 文字列から数値へ

AWKが文字列を数値に変換する方法は、戸惑うことがあります。
簡単に言うと、AWKは文字列の先頭から数値として読める文字を読み込み、数値として読めない文字が見つかったところで止まります。
例をいくつか挙げます。

* `"2.5"`は数値`2.5`に変換されます。
* `"1e3"`は数値`1000`に変換されます（指数表記）。
* `"456abc"`は数値`456`に変換されます（`a`は数字ではないので、そこで変換が止まります）。
* `"abc789"`は数値`0`に変換されます（文字列の**先頭**に数字がないからです）。
