# 説明

この演習では、友達と数の当てっこゲームをします。ルールは簡単です。`1`から`100`までの数を心の中で選び、友達がその数を当てようとします。友達の助けになるように、選んだ数（`42`）にどれだけ近いかによって、返事を変えます。それぞれの返事のルールは、次のとおりです。

- 推測が`42`のとき："Correct"
- 推測が`41`か`43`のとき："So close"
- 推測が`41`より小さいとき："Too low"
- 推測が`43`より大きいとき："Too high"

推測への返事を書く4つのタスクがあります。

## 1. 正解の推測に返事をする

正解の推測に返事をする`reply`関数を実装します：

```gleam
reply(42)
// -> "Correct"
```

## 2. 惜しい推測に返事をする

惜しい推測にも返事をするように`reply`関数を変更します：

```gleam
reply(41)
// -> "So close"
```

## 3. 低すぎる推測に返事をする

低すぎる推測にも返事をするように`reply`関数を変更します：

```gleam
reply(25)
// -> "Too low"
```

## 4. 高すぎる推測に返事をする

高すぎる推測にも返事をするように`reply`関数を変更します：

```gleam
reply(88)
// -> "Too high"
```
