# はじめに

C++では、真偽値は`bool`型で表します。
`bool`の値は、`true`か`false`のどちらかです。

## 論理演算子

C++では、3つの論理演算子を使うことができます。`!`（NOT演算子）、`&&`（AND演算子）、`||`（OR演算子）です。
別の書き方として、`not`、`and`、`or`も使えます。

```cpp
true || false // => true
true && false // => false
!true // => false
not false // => true
```

## 優先順位

3つの論理演算子には、それぞれ異なる_優先順位_があります。
そのため、評価される順番は`!`が最初、次に`&&`、そして最後に`||`です。
順番を変えたいときは、論理式を括弧（`()`）で囲みます。括弧のほうが演算子よりもさらに優先順位が高いからです。

```cpp
!true && false   // => false
!(true and false) // => true
```

## 変換

`true`や`false`を、数値が期待される場所で使うと、それぞれ`1`と`0`に変換されます。
真偽値の演算で数値を使うと、`0`以外はすべて`true`とみなされます。負の値であっても同じです。

```cpp
!true && 0.0   // => false
true + true + false // => 2
```
