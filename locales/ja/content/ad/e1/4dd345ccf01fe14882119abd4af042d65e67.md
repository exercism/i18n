# テストを実行する

お使いのオペレーティングシステムを選んでください：

- [Windows](#windows)
- [macOS](#macos)
- [Linux](#linux)

## Windows

1. Command Promptを開きます。
2. 最初の演習をダウンロードします：

   ```batchfile
   C:\Users\JohnDoe>exercism download --exercise hello-world --track java
   ```

3. 演習のディレクトリに移動します：

   ```batchfile
   C:\Users\JohnDoe>cd C:\Users\JohnDoe\exercism\java\hello-world
   ```

4. テストを実行します：

   ```batchfile
   C:\Users\JohnDoe>gradlew.bat test
   ```

   _（最初はテストが失敗しても心配しないでください。どの演習もこうやって始めます。）_

5. 演習を解きます。`instructions.append.md`ガイドを見つけて、順に進めましょう（[GitHubで見る](https://github.com/exercism/java/blob/main/exercises/practice/hello-world/.docs/instructions.append.md#tutorial)）。

がんばってください！楽しんでください！
