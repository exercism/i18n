# はじめに

## 構造体

構造体は、[マップ][exercism-maps]を基盤にした拡張で、コンパイル時のチェックとデフォルト値を提供します。構造体の名前は、それが定義されているモジュール名になります。構造体を定義するには、`defstruct`を使います。この構文は通常、モジュール定義のすぐ後に書きます。`defstruct`には、アトムのリスト（デフォルト値が`nil`の場合）またはキーワードリスト（デフォルト値を指定する場合）を渡します。デフォルト値のないフィールドは、デフォルト値のあるフィールドより前に置く必要があります。

```elixir
defmodule Plane do
  defstruct [:engine, wings: 2]
end

plane = %Plane{}
# => %Plane{engine: nil, wings: 2}
```

### フィールドへのアクセスと更新

構造体はマップを基盤にしているので、ほとんどのマップ関数を使って値の取得や操作ができます。構造体には、_Access Behaviour_は**実装されていません**。構造体のフィールドにアクセスするには、代わりに_静的アクセス演算子_の`.`を使うことをおすすめします。

- フィールド値の取得

  ```elixir
  plane = %Plane{}
  plane.engine
  # => nil
  Map.fetch(plane, :wings)
  # => {:ok, 2}
  ```

- フィールド値の更新

  ```elixir
  plane = %Plane{}
  %{plane | wings: 4}
  # => %Plane{engine: nil, wings: 4}
  ```

### パターンマッチング

構造体は、構造体名を付けてでも、付けなくても、パターンマッチングに使えます。

```elixir
plane = %Plane{}
%Plane{wings: wings} = plane
%{wings: wings} = plane
```

パターンに構造体名を含めることで、左辺と右辺がどちらも同じ型の構造体であることを保証できます。

```elixir
defmodule Helicopter do
  defstruct [:engine, rotors: 1]
end

%Plane{} = %Helicopter{}
# => (MatchError) no match of right hand side value: %Helicopter{engine: nil, rotors: 1}
```

### フィールド値の初期化を強制する

`@enforce_keys`モジュール属性にフィールドキーのリストを指定すると、構造体の作成時に値が初期化されていることを保証できます。キーがリストに含まれていない場合、その値は上の例で見たように`nil`になります。強制されたキーが初期化されていない場合は、エラーが発生します。

```elixir
defmodule User do
  @enforce_keys [:username]
  defstruct [:username]
end

%User{}
# => (ArgumentError) the following keys must also be given when building struct User: [:username]
```
