# 説明

リリーは料理が大好きです。
友達と一緒にピザパーティーを開きたいと思っています。
材料を無駄なく使い切るには、作り始める前にそれぞれの材料がどれくらい必要かを知っておかなければなりません。

そこでリリーは、計画の一部を自動化するプログラムを書き始めましたが、完成させるには助けが必要です。
リリーが分量ぴったりのピザパーティーを開くのを手伝ってみませんか？

## 1. 生地の比率

リリーは、耳まで薄いパリッとしたクリスピーなピザが好きです。
中央部分に必要な生地は最低200gですが、食べる人が1人増えるごとに生地がさらに20g必要になります。

`grams = pizzas * ((persons * 20) + 200)`

リリーが必要としているのは、次のような関数です。

- ピザの枚数を受け取り
- 1枚のピザを何人で分けるかを表す人数を受け取り
- 必要な生地の量を、1g単位で四捨五入して返します。

たとえば、8人分になるピザを4枚作る場合を考えてみましょう。

```php
<?php

$pizza_pi = new PizzaPi();
$pizza_pi->calculateDoughRequirement(4, 8);
// => 1440
```

## 2. ソースを少々

リリーはソースをかける量にはとても細かく気を配りますが、ピザの大きさは毎回同じとは限りません。
経験から、ピザ1枚につき125mLのソースが必要だと知っています。
リリーが必要としているのは、ソースを何缶買えばよいかを計算する関数です。

`cans of sauce = pizzas * sauce per pizza / sauce can volume`

たとえば、8枚のピザを作る必要があり、1缶が250mLの場合を考えてみましょう。

```php
<?php

$pizza_pi = new PizzaPi();
$pizza_pi->calculateSauceRequirement(8, 250);
// => 4
```

## 3. チーズもお願いします

チーズはきれいな立方体の形で、大きさごとに売られています。

リリーが使う式はピザの面積を求める式ではありません。チーズをピザ全体に敷き詰めたいわけでは_ない_からです。
そこでリリーは、ある一辺の長さ（`cheese_dimension`）のチーズの立方体から、ある直径（`diameter`）のピザが何枚作れるかを求めるために、次の式を使うことにしました。

`pizzas = (cheese_dimension³) / (thickness * PI * diameter)`

次のような関数を作成してください。

- チーズの立方体の一辺の長さを受け取り
- チーズ層の希望の厚さを受け取り
- ピザの直径を受け取り
- リリーの式を使って、作れるピザの枚数を小数点以下を切り捨てて返します。

たとえば、25x25x25cmのチーズの立方体、厚さ0.5cmのチーズ層、直径30cmのピザの場合を考えてみましょう。

```php
<?php

$pizza_pi = new PizzaPi();
$pizza_pi->calculateCheeseCubeCoverage(25, 0.5, 30);
// => 331
```

## 4. 公平な分配

最後に、リリーはピザを1枚8切れに分けて、友達に公平に配りたいと思っています。

次のような関数を作成してください。

- ピザの枚数と友達の人数を受け取り
- 1人が同じ数ずつ切れを受け取ったときに残る切れの数を返します。

たとえば、次のようになります。

```php
<?php

$pizza_pi = new PizzaPi();
$pizza_pi->calculateLeftOverSlices(2, 4);
// => 0
$pizza_pi->calculateLeftOverSlices(4, 3);
// => 2
```
