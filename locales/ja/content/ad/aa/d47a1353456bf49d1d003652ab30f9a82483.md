# 前提条件

D言語トラックでは、次のソフトウェアがシステムにインストールされている必要があります：

* D version 2のコンパイラー
* （任意ですが推奨）DUB

## 前提条件：D version 2コンパイラー

D言語の公式サイト[dlang.org](https://dlang.org)では、リファレンスコンパイラーであるDMD（Digital Mars D）の最新バージョンを、いくつかのプラットフォーム向けにダウンロードしてインストールできます。
詳しくは[公式のダウンロードページ](https://dlang.org/download.html)をご覧ください。
Windowsでは、別の方法として[Chocolateyを使う](https://chocolatey.org/packages/dmd)こともできます。
IntelベースのMacでは、別の方法として[Homebrewを使う](https://formulae.brew.sh/formula/dmd)こともできます。

### その他のコンパイラー
独自のバックエンドを使うDMDリファレンスコンパイラーのほかに、dlang.orgのダウンロードセクションから入手できるコンパイラーが2つあります：

* GCCのバックエンドを使う[GDC](http://gdcproject.org/downloads)
* LLVMのバックエンドをベースにした[LDC](https://github.com/ldc-developers/ldc#installation)

GDCとLDCは、必ずしも最新のDMDフロントエンドのバージョンというわけではありませんが、より優れた最適化レベルや、ARMなどのほかのプラットフォームへの対応を提供しています。

詳しくはwikiの[こちらのページ](https://wiki.dlang.org/Compilers)をご覧ください。

### IDEのサポート

さまざまなIDEでもD言語をサポートしています。たとえば、Visual Studio用の[VisualD](http://rainers.github.io/visuald/visuald/StartPage.html)や、IntelliJのCLion用の[D plugin](https://plugins.jetbrains.com/plugin/7727?pr=clion)などです。
詳しくはwikiの[こちらのページ](https://wiki.dlang.org/IDEs)をご覧ください。

### 前提条件：DUB

[DUB](https://github.com/dlang/dub)は、D言語のビルドマネージャーです。

テストを実行する手順を簡単にするために、DUBの利用をおすすめします。ただし、インストールできない場合や、インストールしたくない場合でも、DUBなしで実行することはできます。

#### Windows

[DUB公式サイトのダウンロードページ](https://code.dlang.org/download)に、Windows用のインストーラーがあります。

#### MacOS

* [DUB公式サイトのダウンロードページ](https://code.dlang.org/download)に、macOS用のバイナリがあります。
* IntelベースとApple SiliconベースのどちらのMacでも、[Homebrewのパッケージが利用できます](https://formulae.brew.sh/formula/dub)：

#### Linux

* [DUB公式サイトのダウンロードページ](https://code.dlang.org/download)に、Linux用のバイナリがあります。
* さまざまなディストリビューション向けのパッケージが用意されています：
    * [ArchLinux](https://www.archlinux.org/packages/community/x86_64/dub/)
    * [Debian/Ubuntu](http://d-apt.sourceforge.net/)
    * [Gentoo](https://github.com/gentoo/dlang/tree/master/dev-util/dub)
    * [OpenSUSE](http://software.opensuse.org/download.html?project=devel%3Alanguages%3AD&package=dub)
