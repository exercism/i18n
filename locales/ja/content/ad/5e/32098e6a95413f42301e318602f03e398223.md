# はじめに

[`Basics`][basics]のコンセプトでは、関数を定義する2つの方法を紹介しました。

もっとも一般的なのは、複数行にわたる書き方です。

```julia
function muladd(x, y, z)
    x * y + z
end
```

短い定義に向いた「代入形式」、または「1行形式」は次のとおりです。
```julia
muladd(x, y, z) = x * y + z
```

3つ目のさらに短い形式では、短くて一度しか使わない関数を、名前なしで作ることができます。

```julia-repl
julia> map(x -> 2x, 1:3)
4-element Vector{Int64}:
 2
 4
 6

julia> map((x, y) -> x * y, 1:3, 4:6)
3-element Vector{Int64}:
  4
 10
 18
```

この場合、`x -> 2x`は「無名関数」です。
これは、ほかの言語で「ラムダ関数」と呼ばれるものに相当します。

なお、引数が複数の場合は`(x, y) -> x * y`のように括弧（`()`）で囲む必要があります。

無名関数はJuliaのコードでよく使われます。とくに`map()`や`filter()`のような高階関数と組み合わせると便利です。

## 関数の引数

シラバスではこれまで、引数の数が決まっていて、関数を呼び出すときにそのすべてを正しい順序で渡さなければならない関数だけを見てきました。
これでは制約が多く不便なので、ほかにもいくつかの方法があります。

### オプション引数

多くの言語と同じように、Juliaでは関数の定義で個々の引数にデフォルト値を指定できます。

関数を呼び出すときは、その引数に値を渡しても、省略してデフォルト値を使ってもかまいません。

```julia-repl
julia> f(x, y=10) = x * y
f (generic function with 2 methods)

julia> f(2, 3)
6

julia> f(2)
20
```

デフォルト値の_ない_引数はすべて、デフォルト値の_ある_引数より前に置く必要があります。つまり、`f(x=2, y)`は無効です。

### キーワード引数

ここまでの例はすべて`positional arguments`を使っています。位置引数では、関数を呼び出すときに渡す値の順序が、関数の定義にある対応する引数の順序と一致していなければなりません。

多くの言語と同じように、Juliaでは`keyword arguments`も使えます。
関数を呼び出すときは引数の名前を指定する必要がありますが、複数のキーワード引数をどんな順序で指定してもかまいません。

Juliaの特徴的な点は、関数の定義にキーワード引数がある場合、位置引数と区別するためにその前にセミコロン`;`を付けなければならないことです。
関数を呼び出すときは、最後の位置引数と最初のキーワード引数のあいだに`;`または`,`のどちらを使ってもかまいません。

```julia-repl
julia> b(x; y) = x + y
b (generic function with 1 method)

julia> b(2, y=3)
5

# keyword is required when calling
julia> b(2, 3)
ERROR: MethodError: no method matching b(::Int64, ::Int64)
The function `b` exists, but no method is defined for this combination of argument types.
```

位置引数のときと同じように、デフォルト値も指定できます。

引数と同じ名前の変数をあらかじめ計算しておくと、関数の呼び出しの中で`myarg=myarg`のような書き方になることがよくあります。
こういうときは、省略した書き方ができます。

```julia-repl
julia> width = 4.0
4.0

julia> height = √ width
2.0

julia> area(; width, height) = width * height
area (generic function with 1 method)

# repetition
julia> area(; width=width, height=height)
8.0

# shorthand form
julia> area(; width, height)
8.0
```

### スプラットとスラープ

ご存じない方のために言っておくと、これらはJuliaの構文の便利な機能につけられた標準的な名前です。
どちらも`...`演算子を指します。

#### スプラット

スプラットは関数の_呼び出し_で使い、コレクションを、関数が必要とする個々の値に展開します。

これは説明するより、実際に見たほうがわかりやすいでしょう。

```julia-repl
julia> fxyz(x, y, z) = x * y * z
fxyz (generic function with 1 method)

julia> xyz = [2, 3, 4]
3-element Vector{Int64}:
 2
 3
 4

# Using the vector directly in a function call is invalid
julia> fxyz(xyz)
ERROR: MethodError: no method matching fxyz(::Vector{Int64})
The function `fxyz` exists, but no method is defined for this combination of argument types.

# splatting converts the vector to 3 numbers, used as positional arguments
julia> fxyz(xyz...)
24
```

一部の「関数呼び出し」は糖衣構文に隠れているので、スプラットはあまり目立たない場面でも使われます。

たとえば、多重代入は内部的にタプルのコンストラクター関数を使っています。

```julia-repl
julia> first, rest... = [1, 2, 3, 4]
4-element Vector{Int64}:
 1
 2
 3
 4

julia> first
1

julia> rest
3-element Vector{Int64}:
 2
 3
 4
```

キーワード引数もスプラットで渡せます。ふつうは`named tuple`を使います。
`Dict`でも動きますが、キーはシンボルでなければなりません（文字列では動きません）。

```julia-repl
# function with 3 keyword arguments
julia> fabc(; a, b, c) = a + b + c
fabc (generic function with 1 method)

# named tuple
julia> abc_nt = (a=2, b=3, c=4)
(a = 2, b = 3, c = 4)

# there are no positional arguments, so need to use ; before kw argument
julia> fabc(;abc_nt...)
9

# Dict
julia> abc_dict = Dict(:a=>2, :b=>3, :c=>4)
Dict{Symbol, Int64} with 3 entries:
  :a => 2
  :b => 3
  :c => 4

julia> fabc(;abc_dict...)
9
```

#### スラープ

スラープは関数の_定義_で使い、任意の個数の値を1つのコレクションにまとめます。

```julia-repl
julia> f_more(i, j, more...) = i + j + sum(more)
f_more (generic function with 1 method)

julia> f_more(1, 3, 5, 7, 9, 11)
36
```

スラープする引数の名前（この場合は`more`）に意味はありません。
この変数の型はコンパイラーが選びますが、位置引数の場合は`tuple`かそれに近い型になるでしょう。

キーワード引数もスラープでき、その場合は`Dict`（または同様のもの）になります。

```julia-repl
julia> f_kwslurp(x, y; switches...) = :mult in keys(switches) ? x * y : x + y
f_kwslurp (generic function with 1 method)

julia> f_kwslurp(5, 6; mult=true)
30

julia> f_kwslurp(5, 6)
11
```

呼び出しではどんなキーワード引数でも使えます。
どのキーワードに反応し、どれを無視するかは、関数の定義が決めます。
