# はじめに

## カスタム型

カスタム型を使うと、Gleamで新しいデータ型を定義できます。カスタム型には複数の_バリアント_を持たせることができ、それぞれに名前を付けられます。

```gleam
pub type Season {
  Spring
  Summer
  Autumn
  Winter
}
```

カスタム型の各ケースには、必要に応じてデータを持たせることができ、ケースごとに持てるデータの型も変えられます。データを持つバリアントのことを_レコード_と呼びます。

```gleam
pub type Number {
  SomeInt(Int)
  SomeFloat(Float)
  Invalid
}
```

特定のケースの値を作るには、追加のデータを持たない場合はその名前をそのまま使います（`Spring`）。データを持つ場合は、関数のように呼び出します（`SomeInt(2)`）。

```gleam
let spring = Spring
let integerTwo = SomeInt(2)
```

カスタム型は、Gleamのあらゆる値と同じく、_構造的等価性_を持ちます。これは、同じバリアントで同じデータを持つ2つの値は等しいとみなされるという意味です。

```gleam
Spring == Spring // -> True
Spring == Autumn // -> False
SomeInt(2) == SomeInt(2) // -> True
SomeInt(2) == SomeFloat(2.0) // -> False
```

カスタム型のバリアントは、case式を使ってパターンマッチできます。

```gleam
import gleam/int
import gleam/float

pub fn describe(flexible_number: Number) -> String {
  case flexible_number {
    SomeFloat(f) -> "Float: " <> float.to_string(f)
    SomeInt(i) -> "Int: " <> int.to_string(i)
    Invalid -> "Neither a float nor an int"
  }
}
```
