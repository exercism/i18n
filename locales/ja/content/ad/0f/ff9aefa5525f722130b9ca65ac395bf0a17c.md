# インストール

## 必要なもの

Common Lispで開発するために必要な基本のものは、次のとおりです。

- Lispの「実装」。コードをコンパイルして実行でき、REPLも提供してくれます。
- Lispコードを書くための機能を備えたテキストエディター。
- （あると便利）Common Lispのリファレンスとしてよく使われる[「Common Lisp Hyperspec」][hyperspec]。

## Roswell

[Roswell][roswell]は、Common Lispの実装をインストールして管理するためのコマンドで、Lispアプリケーションの開発と配布を簡単にする多くの機能を備えています。
ここでは、インストールとテストの手順を簡単にするためにRoswellを使います。

### Roswellのインストール

[インストールガイド][ros-inst]を見て、お使いのプラットフォーム向けの手順に従ってください。
ほとんどの人には、次の方法で十分でしょう。

* MacOSとLinuxなら、[Homebrew][brew]を使うと簡単です。
  ```sh
  brew install roswell
  ```
* Windowsなら、[Scoop][scoop]を使います。
  ```powershell
  scoop install roswell
  ```

Roswellを初めて使うときは、SBCLとQuicklispを取得してインストールします。
次のコマンドを実行するだけです。
```sh
ros help
```

REPLを起動するには、次のようにします。
```sh
ros run
```

## テキストエディターを設定する

Common Lispが初めての人、とくにEmacsを使った経験がある人は、[Portacle（ポータブルCommon Lisp環境）][portacle]をインストールすると、手軽にすばやく始められます。
無料で全機能を備えており、一般的なプラットフォームすべてで動作し、すぐに使える状態に設定済みです。次のものが含まれます。

- Lispの実装：QuicklispとASDFを含むSBCL
- テキストエディター：Emacs

さらに、Lispコードを書くための多くのアドオンも付いてきます。
- SLIME（Superior Lisp Interaction Mode for Emacs）は、EmacsをCommon LispのIDEに変えてくれます。
- ParEditは、括弧を扱う作業を楽にしてくれます。

すべてが最初から設定済みの状態で届きます。Portacleは[フロントページ][portacle]からダウンロードしてインストールします。

注：Emacs（テキストエディター）は、慣れていないと最初は戸惑うかもしれません。幸い、EmacsとSLIMEの入門記事はオンラインにたくさんあります。

## 従来の始め方

必要なツールを個別にインストールしたい場合は、次のものをインストールして設定する必要があります。

- Lispに対応したテキストエディター：[Slime][slime]または[Sly][sly]パッケージを入れた[Emacs][emacs]がよく選ばれますが、[SLIMV][slimv]を入れた[VIM][vim]、[SLIMA][slima]を入れた[Atom][atom]、[Common Lispプラグイン][vscode-plugin]を入れた[VSCode][vscode]もおすすめです。
- Common Lispの実装：Linux、MacOS、Windowsで動作する[SBCL][sbcl]が「無難」な選択です。この言語は標準に基づいているので、ほかの[標準に準拠した実装][awesome-cl-implementations]でも問題なく動作します。
- ライブラリ管理には[Quicklisp][quicklisp]。ダウンロードしたら、[手順][quicklisp-install]に従って、お使いのCommon Lisp実装と正しく連携させてください。
