# はじめに

## 数学関数

平方根や角度、成長曲線を`+`や`-`、`*`、`/`だけで計算するのは大変です。[`math.functions`][math.functions]のボキャブラリーには、そうした計算をしてくれるワードがそろっています。πは[`math.constants`][math.constants]にあります。ほかのどのワードと同じように、それぞれがスタックから入力を受け取り、答えをスタックに残します。

## 平方根

```
sqrt ( x -- y )
```

```factor
USING: kernel math math.constants math.functions math.libm prettyprint ;

9 sqrt .     ! => 3.0
2 sqrt .     ! => 1.4142135623730951
```

長さ5メートルのはしごを、足を壁から3メートル離して立てると、壁を4メートル上まで届きます。

```factor
5 sq 3 sq - sqrt .   ! => 4.0
```

## 円周率

`pi`（`math.constants`にあります）は、円の直径が円周に何回入るかを表す数、πをスタックに積みます。

```factor
: wheel-edge ( diameter -- edge ) pi * ;

2 wheel-edge .   ! => 6.283185307179586
```

## 角度はラジアン

```
sin ( x -- y )
cos ( x -- y )
tan ( x -- y )
```

`sin`、`cos`、`tan`は角度を受け取りますが、度では受け取りません。これらは**ラジアン**を使い、半回転は180ではなくπになります。度をそのまま渡してもエラーにはなりませんが、静かに間違った答えが返ってきます。

`deg>rad`は度をラジアンに変換し、`rad>deg`はその逆に変換します。どちらもπを掛けて180で割るのと同じで、逆向きはその反対になります。

```
deg>rad ( x -- y )
rad>deg ( x -- y )
```

```factor
30 deg>rad .       ! => 0.5235987755982988
30 pi * 180 / .    ! => 0.5235987755982988
pi rad>deg .       ! => 180.0
```

`sin`を呼ぶ前に、度をラジアンに変換しましょう。

```factor
: ramp-rise ( length degrees -- rise ) deg>rad sin * ;

10 30 ramp-rise .   ! => 4.999999999999999
```

長さ10メートルの坂を30度の角度で上ると、5メートル上がります。答えが`4.999999999999999`と表示されるのは、数学関数が正確な値ではなく、最も近い浮動小数点数を返すからです。変換をしないと、`30 sin`は30をラジアン（ほぼ5回転分）として扱い、坂は`-9.88`メートル「上る」ことになります。

## 角度を求める

`fatan2`は逆の向きに働きます。どれだけ上に、どれだけ横に進んだかを受け取ると、角度をラジアンで返します。[`math.libm`][math.libm]にあります。スタックには*上*方向の距離を先に、次に*横*方向の距離を積みます。

```
fatan2 ( y x -- radians )
```

```factor
1.0 1.0 fatan2 .              ! => 0.7853981633974483
1.0 1.0 fatan2 rad>deg .      ! => 45.0
-1.0 -1.0 fatan2 rad>deg .    ! => -135.0
0.0 -1.0 fatan2 rad>deg .     ! => 180.0
```

角度は*横*方向の正の向きから測ります。`fatan2`は2つの距離の符号を見るので、−180度から180度までのどこでも答えることができます。

## 10の累乗：10^とlog10

`10^`は10を累乗します。

```factor
5 10^ .     ! => 100000
2 10^ .     ! => 100
0.5 10^ .   ! => 3.1622776601683795
```

`log10`はその逆です。「10を何乗するとこの数になるか」という問いに答えます。その答えが、その数の**対数**です。

```factor
100000 log10 .   ! => 5.0
100 log10 .      ! => 2.0
1 log10 .        ! => 0.0
0.001 log10 .    ! => -3.0
```

## e^とlog

`e^`と`log`も同じ組み合わせで、10の代わりに*e*（約2.718）を使います。`e^`は*e*を累乗し、`log`は「*e*を何乗するとこの数になるか」に答えます。

```
e^  ( x -- y )
log ( x -- y )
```

数学者は、1ステップごとに同じ割合で増えたり減ったりするものには*e*を使います。利息で増えるお金もその一例ですし、冷めていく紅茶もそうです。

```factor
! 80 degrees hotter than the room, the gap shrinking by 5% a minute
: tea-gap ( minutes -- gap ) -0.05 * e^ 80 * ;

0 tea-gap .    ! => 80.0
10 tea-gap .   ! => 48.52245277701067
```

`log`は`e^`を打ち消します。これを使うと、逆の問いに答えられます。温度差が40度まで下がるのは何分後でしょうか？

```factor
80 40 / log 0.05 / .   ! => 13.862943611198904
```
