# はじめに

`n`個の値からなるシーケンスが必要で、しかも各値が自分のインデックスに依存するときは、Factorの`<iota>`と`map`を使います。`<iota>`は、整数`0, 1, …, n-1`を並べた仮想のシーケンスです。

```factor
USING: math sequences ;

5 <iota> [ 2 * ] map .   ! => { 0 2 4 6 8 }
```

`<iota>`はあらかじめ整数を確保するわけではありません。`map`がそれらを順番にたどり、それぞれにクォーテーションを適用します。

位置ごとの結果が文字コードであれば、`>string`がその結果を文字列に変えてくれます。インデックスに応じた判断から文字の並びを組み立てる、自然なやり方です。

```factor
USING: strings ;

5 <iota> [ CHAR: a + ] map >string .   ! => "abcde"
```

[strings]: https://docs.factorcode.org/content/article-strings.html
