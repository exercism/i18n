# 概要

Gleamの文字列は、ダブルクォートで囲まれた不変のテキストです。Unicode文字を扱うことができ、複数行にわたることもできます。

```gleam
let greeting = "Hello, Joe! 📞"

let multi_line_string = "one
two
three"
```

文字列は、`<>`演算子を使って連結できます。

```gleam
let name = "Mike"
"Hello, " <> name <> "!"
// -> "Hello, Mike!"
```

標準ライブラリの[`gleam/string`][stdlib]モジュールには、文字列を扱うための関数が用意されています。

文字列は、`case`式でマッチさせることができます。

```gleam
pub fn on_an_excellent_adventure(name: String) -> Bool {
  case name {
    "Bill" -> True
    "Ted" -> True
    _ -> False
  }
}
```

文字列の先頭にマッチさせ、残りを変数に代入したいときは、`<>`演算子のパターンを使うことができます。

```gleam
pub fn profession(name: String) -> String {
  case name {
    "Dr " <> rest -> rest <> " is a doctor"
    _ -> "I'm not sure what " <> name <> " does"
  }
}
```

[stdlib]: https://hexdocs.pm/gleam_stdlib/gleam/string.html
