# 概要

Haxeは、型とフィールドの実行時リフレクションをサポートしています。リフレクションを正しく使うには、どのような操作がサポートされていて、どれがサポートされていないのかを理解する必要があります。リフレクションは動的な性質を持つため、これをコンパイル時に常に判断できるとは限りません。

リフレクション`API`は、2つのクラスから構成されています。

- `Reflect`：無名構造に対して最もよく機能する軽量な`API`で、クラスのサポートは限定的です。
- `Type`：クラスと列挙型を扱うための、より堅牢な`API`です。

利用できるメソッドの詳細は、[Reflect][reflect]と[Type][type]の`API`に記載されています。

次の例では、JavaScriptターゲットを使用します。

```haxe
class Main {
  public static function main() {
    trace(Type.resolveClass("Main"));
  }
}

// This outputs
// class Test { static main() { console.log("Test.hx:3:",$hxClasses["Test"]); } }
```

[reflect]: https://api.haxe.org/Reflect.html
[type]: https://api.haxe.org/Type.html
