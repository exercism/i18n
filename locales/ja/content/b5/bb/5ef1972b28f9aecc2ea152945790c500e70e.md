# 説明

`classes`演習で始めたラジコンカーのプロジェクトは順調に進みました（おめでとうございます！）。そして、最近いくつかのスポンサー契約がまとまったおかげで、機能強化に使える予算が確保できました。

予算の一部は、テレメトリーを提供するために使われます。

スポンサーを満足させるために、カーがトラックを周回する間にスポンサー名を表示するパネルが車に取り付けられました。

こうした新しい技術の導入によって、カーのバッテリー寿命が劇的に短くなったことにお気づきでしょう。

## 1. ラジコンカーにスポンサー名を表示できるようにする

`SetSponsors()`を実装し、1つまたは複数のスポンサー名を受け取ってカーに保存するようにします。

`SetSponsors()`メソッドの引数はnullでないことが保証されています。

`DisplaySponsor()`を実装して、選択したスポンサーを表示します。最初に渡されたスポンサーの`sponsorNum`は0、2番目は1、というようになります。

```csharp
var car = RemoteControlCar.Buy();
car.SetSponsors("Exercism", "Walker Industries", "Acme Co.");
var sp2 = car.DisplaySponsor(sponsorNum: 1);
// => "Walker Industries"
```

## 2. カーのテレメトリーデータを取得する

`RemoteControlCar.GetTelemetryData()`メソッドを実装します。

`GetTelemetryData()`は、バッテリー残量のパーセンテージと走行距離（メートル）を`out`仮引数を通じて利用できるようにします。

`GetTelemetryData()`は、serialNum引数が以前に受け取った値より小さい場合に`false`を返します。（複数のテレメトリーノードが関係しているという問題があります。）この場合、`serialNum`は以前の最大の`serialNum`に設定され、バッテリー残量のパーセンテージと走行距離（メートル）はどちらも`-1`に設定されます。呼び出しが成功した場合、`serialNum`は変更されません。

```csharp
var car = RemoteControlCar.Buy();
car.Drive();
car.Drive();
int serialNum = 4;
car.GetTelemetryData(ref serialNum, out int batteryPercentage, out int distanceDrivenInMeters);
// => true, 4L, 80, 4

serialNum = 1;
car.GetTelemetryData(ref serialNum, out batteryPercentage, out distanceDrivenInMeters);
// => false, 4L, -1, -1
```

## 3. テレメトリーシステムが1メートルあたりのバッテリー消費量を取得できるように機能を追加する

`TelemetryClient.GetBatteryUsagePerMeter()`メソッドを実装します。

これは`RemoteControlCar.GetTelemetryData()`を呼び出します。`GetTelemetryData()`が`false`を返すか、カーがまだ走行していない場合、このルーチンは"no data"を返します。`GetTelemetryData()`が`true`を返す場合、"usage-per-meter=BATTERY-USAGE-PER-METER"という形式のメッセージを返します。計算式は、（100から現在のバッテリー残量のパーセンテージを引いた値）をこれまでの走行距離（メートル）で割ったものになります。

```csharp
var car = RemoteControlCar.Buy();
car.Drive();
car.Drive();
var tc = new TelemetryClient(car);
int serialNum = 4;
tc.GetBatteryUsagePerMeter(serialNum);
// => "usage-per-meter=5"

serialNum = 1;
tc.GetBatteryUsagePerMeter(serialNum);
// => "no data"
```
