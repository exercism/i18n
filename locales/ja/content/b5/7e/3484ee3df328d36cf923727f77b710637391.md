# ヒント

## 全般

- `accessors`は、自動生成される`slot>>`ゲッター、`>>slot`セッター、`change-slot`アップデーターを提供します。
- セッターと`change-slot`はタプルを*書き換え*ます。元のタプルを残したまま更新したいときは、先に`clone`しておきましょう。

## 1. `player`タプルを定義する

- スロットの書式は、`TUPLE: …  ;`の中に`{ name initial: value }`と書きます。
- `initial:`句のないスロットの既定値は`f`になります。

## 2. プレイヤーを登場させる

- `name>>`は`name`スロットを読み取ります。
- [`kernel`][kernel]の`unless*`は、「`f`のときの既定値」を表すイディオムです。

## 3. 倒れたプレイヤーを復活させる

- `health>>`はスロットを読み取り、[`math`][math]の`zero?`はゼロかどうかを判定します。
- 新しいプレイヤーは、`clone`に続けて`100 >>health`と`100 >>mana`を書いて作ります。
- 「まだ生きている」場合は、`f`を返します。

## 4. ダメージを受ける

- `change-health`は、クォーテーション`( old-health -- new-health )`を受け取ります。
- fryクォーテーション`'[ _ - 0 max ]`（`max`は[`math.order`][math.order]にあります）を使うと、「受け取ったダメージを引いて、0で下限をそろえる」ことができます。
- 変更する前に`clone`するのを忘れないようにしましょう。

[math]: https://docs.factorcode.org/content/vocab-math.html
