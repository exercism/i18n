# 説明

学校の劇で、小道具の管理を担当しています。小道具は、小道具の名前からその個数へのマップです。

3つの課題はすべて`MISSING_PROPS`クラスに書きます。

## 1. いくつある？

小道具がいくつあるかを返します。その小道具が管理表にまったく載っていない場合は、文字列`"Unknown prop: "`のあとにその名前を続けたものを送出します。

```sather
MISSING_PROPS::count_of(props, "crown")
-- => 2

MISSING_PROPS::count_of(props, "sword")
-- raises "Unknown prop: sword"
```

0個であることと、そもそもそんなものはないことの違いに注意しましょう。0個として載っている小道具は管理表に知られているもので、単に使い切っただけです。

## 2. 1つ取る

1つ取ったあとに残っている個数を返します。その小道具が載っていてもう残りがない場合は、`"Out of "`のあとにその名前を続けたものを送出します。

```sather
MISSING_PROPS::take_one(props, "crown")
-- => 1

MISSING_PROPS::take_one(props, "lantern")
-- raises "Out of lantern"
```

管理表にまったく載っていない小道具の場合も、同じく`"Unknown prop: ..."`を送出します。同じメッセージを2回書く必要はありません。

## 3. 報告する

何が起きても、送出するのではなく、メッセージを返します。

```sather
MISSING_PROPS::report(props, "crown")
-- => "Took crown, 1 left"

MISSING_PROPS::report(props, "lantern")
-- => "Out of lantern"

MISSING_PROPS::report(props, "sword")
-- => "Unknown prop: sword"
```

うまくいったときのメッセージは、`"Took "`、名前、`", "`、残りの個数、`" left"`をつなげたものです。うまくいかなかったときのメッセージは、送出されたものがそのままになります。
