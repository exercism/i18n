# 説明

この課題では、試合の得点者のリストを受け取り、各選手が何ゴール決めたかを数えます。

`PlayerName`は`String`の型エイリアスです。コードを読みやすくし、この`String`の使い方を他の`String`の使い方と区別するためにあります。

## 1. 得点者を集計する

まず、ある選手のゴール数を初期化またはインクリメントする`updateGoalCountForPlayer`を実装します。
次に、`updateGoalCountForPlayer`を使うことで、各選手が何ゴール決めたかを数える`aggregateScorers`関数を実装します。
この関数は`List PlayerName`（得点した選手の名前のリストで、同じ選手の名前が重複して含まれることもあります）を受け取り、リスト内のすべての選手と、それぞれが決めたゴール数を表す`Dict PlayerName Int`を返します。

```elm
aggregateScorers [ "Betty", "Cedd", "Betty" ]
--> Dict.fromList [ ( "Betty", 2 ), ( "Cedd", 1 ) ]
```

## 2. 重要でない選手を除外する

`removeInsignificantPlayers`関数を実装して、しきい値よりも少ないゴールしか決めていない選手を除外します。

```elm
removeInsignificantPlayers 2 (Dict.fromList [ ( "Betty", 2 ), ( "Cedd", 1 ) ] )
--> Dict.fromList [ ( "Betty", 2 ) ]
```

## 3. 選手のゴール数をリセットする

`resetPlayerGoalCount`関数を実装して、ある選手のゴール数を0にリセットします。

```elm
resetPlayerGoalCount "Cedd" (Dict.fromList [ ( "Betty", 2 ), ( "Cedd", 1 ) ] )
--> Dict.fromList [ ( "Betty", 2 ), ( "Cedd", 0 ) ]
```

## 4. 1人の選手のゴール数を整形する

1人の選手のゴール数を文字列として整形する`formatPlayer`関数を実装します。その選手がdictに存在しない場合は、ゴール数を0とみなします。

```elm
formatPlayer "Betty" (Dict.fromList [ ( "Betty", 2 ), ( "Cedd", 1 ) ] )
--> "Betty: 2"
```

## 5. すべての選手のゴール数を整形する

すべての選手のゴール数を文字列として整形する`formatPlayers`関数を実装します。選手は名前の順に並べます。

```elm
formatPlayers (Dict.fromList [ ( "Betty", 2 ), ( "Cedd", 1 ) ] )
--> "Betty: 2, Cedd: 1"
```

## 6. 試合を合算する

`combineGames`関数を実装して、両方の試合で各選手が決めたゴールの合計数を数えます。

```elm
combine Games
  (Dict.fromList [ ( "Betty", 2 ), ( "Cedd", 1 ) ] )
  (Dict.fromList [ ( "Betty", 2 ), ( "Mario", 3 ) ] )
--> Dict.fromList [ ( "Betty", 4 ), ( "Cedd", 1 ), ( "Mario", 3 ) ]
```
