# 説明

この演習では、友人が開発しているビデオゲームのためのロジックを書いていきます。ゲームの主人公はアナリン。勇敢な女の子で、獰猛で忠実な飼い犬がいます。ところが不幸にも、森で木の実を探していた親友が誘拐されてしまいます。アナリンは友人を見つけて助け出そうとします。その冒険に犬を連れていくかどうかは選べます。

やがてアナリンは、友人が囚われている野営地を見つけます。誘拐犯は2人いました。屈強な騎士と、ずる賢い弓兵です。

次にどうするかについて、プレイヤーにはいくつかの選択肢が示されます。4つの選択肢それぞれについて、その選択肢を表示すべきかどうかをゲームに伝えるワードを書く必要があります。

## 1. 「速攻」の選択肢を表示すべきかどうかを確認する

騎士が眠っていれば、アナリンは騎士が完全に目を覚まして鎧を身につける前に、素早く野営地に攻撃を仕掛けることができます。

騎士が起きているかどうかを示す真偽値を受け取る`can-do-fast-attack`というワードを実装します。「速攻」の行動が可能なら`t`を返し、そうでなければ`f`を返します。

```factor
t can-do-fast-attack .
! => f
```

## 2. 「スパイ」の選択肢を表示すべきかどうかを確認する

3人のうち少なくとも1人が起きていれば、一行をスパイできます。そうでなければ、スパイは時間の無駄です。

騎士、弓兵、囚人がそれぞれ起きているかどうかを示す3つの真偽値を受け取る`can-spy`というワードを実装します。「スパイ」の行動が可能なら`t`を返し、そうでなければ`f`を返します。

```factor
f t f can-spy .
! => t
```

## 3. 「囚人に合図」の選択肢を表示すべきかどうかを確認する

囚人が起きていて、弓兵が眠っていれば、鳥の鳴き声を使って囚人に合図を送ることができます。弓兵が起きている場合は、弓兵も鳥の鳴き声による合図の訓練を受けているため、安全に合図を送ることはできません。

弓兵と囚人がそれぞれ起きているかどうかを示す2つの真偽値を受け取る`can-signal-prisoner`というワードを実装します。「囚人に合図」の行動が可能なら`t`を返し、そうでなければ`f`を返します。

```factor
f t can-signal-prisoner .
! => t
```

## 4. 「囚人を解放」の選択肢を表示すべきかどうかを確認する

アナリンは、友人を解放するために野営地に忍び込むこともできます。これは危険な行動で、次の2つの方法のどちらかでしか成功しません。

- 飼い犬を連れている場合、弓兵が眠っていれば囚人を助け出せます。騎士は犬を恐れていて、弓兵が準備を整える前にアナリンと友人は逃げ出せるからです。

- 犬を連れていない場合は、アナリンと囚人がよほどこっそり行動しなければなりません。囚人が起きていて、騎士と弓兵の両方が眠っていれば、囚人を解放できます。囚人が眠っていると助け出せません。アナリンが突然現れるのに驚いて、騎士と弓兵を起こしてしまうからです。

4つの真偽値を受け取る`can-free-prisoner`というワードを実装します。入力は順に、弓兵が起きているかどうか、犬がいるかどうか、囚人が起きているかどうか、騎士が起きているかどうかを示します。「囚人を解放」の行動が可能なら`t`を返し、そうでなければ`f`を返します。

```factor
f t t f can-free-prisoner .
! => t      (archer asleep, dog present, prisoner awake, knight asleep)

t t f f can-free-prisoner .
! => f      (archer is awake, so no rescue possible)
```
