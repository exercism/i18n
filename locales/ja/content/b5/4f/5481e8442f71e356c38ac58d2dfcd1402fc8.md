# はじめに

## 配列

JSONは**配列**を次のように定義しています。

> 配列は、順序付けられた値の集まりです。
> 配列は左角括弧（`[`）で始まり、右角括弧（`]`）で終わります。
> 値はコンマ（`,`）で区切られます。

配列には、_あらゆる種類_のJSON値を0個以上入れることができます。
配列の要素がすべて同じ型である必要はありません。

### 配列の作成

要素を配列にまとめるには、角括弧を使います。

```jq
[1, 2, 3]
```

_ストリーム_の要素は、角括弧で囲むことで配列にまとめることができます。

```jq
range(5)     # => a stream of 5 numbers
[range(5)]   # => the array [0, 1, 2, 3, 4]
```

### サイズ

`length`関数は、配列の要素数を返します。

### インデックスとスライス

配列のインデックスは0から始まります。

角括弧を使った式で、配列から要素を取り出せます。
`.[2]`は3番目の要素を取得します。

負のインデックスは、配列の末尾から逆向きに数えます。
`.[-1]`は最後の要素を取得し、`.[-2]`は後ろから2番目の要素です。

**スライス**は、配列の部分列です。
`.[10:15]`は、インデックス10から始まる5つの要素を返します。終了のインデックスは_含まれません_。

便利な関数もいくつかあります。

- `first`は最初の要素を取得します。
- `last`は最後の要素を取得します。
- `nth(n)`はインデックス`n`の要素を取得します。

### 繰り返し

`jq`には、よくある繰り返しの機能をカバーする関数がたくさん用意されています。

- `map(expr)`は、`expr`を各要素に順番に適用した新しい配列を返します。

  ```jq
  [1, 2, 3] | map(. * 10)    # => [10, 20, 30]

  ```

- `select(expr)`は、_1つの値_に`expr`を適用する関数です。
  式の結果が真であれば、その値が返されます。
  偽であれば、_何も_返されません。`null`ではなく、本当に何も返されません。

  これを配列に適用するには、`map`と組み合わせます。

  ```jq
  [range(10)] | map(select(. % 2 == 0))    # => [0, 2, 4, 6, 8]
  ```

  もう一つの方法として、_ストリーム_に`select`を適用して、その結果をまとめることもできます。

  ```jq
  [range(10) | select(. % 2 == 0)]    # => [0, 2, 4, 6, 8]
  ```

- `any(condition)`と`all(condition)`は、配列の要素のいずれか、またはすべてが条件を満たすかどうかを表す真偽値を返します。

  ```jq
  [1, 2, 3, 4] | any(. > 4)    # false
  [1, 2, 3, 4] | any(. >= 4)   # true

  [1, 2, 3, 4] | all(. >= 4)   # false
  [1, 2, 3, 4] | all(. <= 4)   # true
  ```
