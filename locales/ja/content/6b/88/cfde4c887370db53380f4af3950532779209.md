# はじめに

Unisonは、`true`と`false`という値を`Boolean`型で表します。値は`true`と`false`の2つだけです。

```unison
trueVariable = true
falseVariable = false
```

真偽値の式は、and（`&&`）、or（`||`）、not（`not`）の各演算子を使って評価できます。

```unison
trueVariable = true && true
falseVariable = true && false

trueVariable = false || true
falseVariable = false || false

trueVariable = not false
falseVariable = not true
```
