# 説明

この演習では、エンジニアがSqueakyClean名をきれいにするための、ユーティリティルーチンの一部を実装します。

4つのタスクを通して、`clean`メソッドを少しずつ作り上げていきます。
有効なSqueakyClean名は、0個以上の英字とアンダースコアで構成されます。

どのような場合でも、入力文字列はnullでないことが保証されています。なお、`clean`メソッドは空文字列を有効なものとして扱う必要があります。

## 1. 空白をアンダースコアに置き換える

（_静的_）`SqueakyClean.clean()`メソッドを実装して、空白をアンダースコアに置き換えます。これは先頭と末尾の空白にも当てはまります。

```java
SqueakyClean.clean("my   Id");
// => "my___Id"
```

## 2. ケバブケースをキャメルケースに変換する

（_静的_）`SqueakyClean.clean()`メソッドを変更して、ケバブケースをキャメルケースに変換します。

```java
SqueakyClean.clean("a-bc");
// => "aBc"
```

## 3. リート語を通常のテキストに変換する

（_静的_）`SqueakyClean.clean()`メソッドを変更して、[リート語][leet-speak]を通常のテキストに変換します。

簡単のため、`4`、`3`、`0`、`1`、`7`をそれぞれ`a`、`e`、`o`、`l`、`t`に置き換えるだけにします。

```java
SqueakyClean.clean("H3ll0 W0rld");
// => "Hello_World"
SqueakyClean.clean("4 73s7");
// => "a_test"
```

## 4. 英字以外の文字を省略する

（_静的_）`SqueakyClean.clean()`メソッドを変更して、英字以外の文字をすべて省略します。

```java
SqueakyClean.clean("a$#.b");
// => "ab"
```

[leet-speak]: https://en.wikipedia.org/wiki/Leet
