# 概要

Gleamの`Iterator`は、すべての値が同じ型である、順序づけられた値の集まりという点では配列に似ています。配列と違うのは、遅延評価であるという点です。つまり、すべての値を一度にメモリに保存するのではなく、必要になったときに計算します。

これは、とても大きな、あるいは無限の長さのシーケンスを扱うときに役立ちます。すべてを一度に保存するだけの空きメモリがない場合でも、扱うことができるからです。

`gleam/iterator`モジュールは、`Iterator`型と、イテレーターを扱うための関数を定義しています。

配列にある関数の多くは、イテレーターにも用意されています。`map`、`filter`、`take`などです。これらの関数はイテレーターを返すので、イテレーターが消費されるまで、実際には何の処理も行いません。

```gleam
let iter = 
  [1, 2, 3, 4, 5, 6]
  |> iterator.from_list
  |> iterator.filter(fn(x) { x > 2 })
  |> iterator.take(2)

// No work has been done yet as the iterator has not been consumed

// Consume the iterator and collect the values into a list
iterator.to_list(iter)
// -> [3, 4]
```

`unfold`関数を使うと、シーケンスの次の値を生成するために繰り返し呼び出される関数から、イテレーターを作成できます。

ここでは、`unfold`関数を使って、フィボナッチ数列を生成するイテレーターを作成しています。

```gleam 
iterator.unfold(#(0, 1), fn(pair) {
  let x = pair.0 + pair.1
  iterator.Next(element: x, accumulator: #(pair.1, x))
})
|> iterator.take(6)
|> iterator.to_list
// -> [1, 2, 3, 5, 8, 13]
```

ここでのシーケンスは無限なので、値を配列に集める前に、`take`関数を使って有限にしています。無限のイテレーターに対して`to_list`を呼び出すと、プログラムはメモリを使い果たしてクラッシュするまで動き続けます。
