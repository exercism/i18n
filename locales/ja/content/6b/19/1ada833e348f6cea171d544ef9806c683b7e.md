# 説明

この演習では、自転車と部品のオンラインショップ、Betty's Bike Shopを手伝うためのコードを書きます。
タスクは3つあり、いずれもウェブサイト上で自転車と部品の価格を正しく表示するためのものです。

## 1. `penceToPounds`関数をエクスポートする

同僚はすでにモジュールの骨組み、つまり未定義の`penceToPounds`関数と`poundsToString`関数を書いています。
しかし、`penceToPounds`関数のエクスポートを忘れているため、現時点では他のモジュールからもテストスイートからも見えません。

エクスポートする関数のリストに`penceToPounds`を追加しましょう。

## 2. ペンスをポンドに変換する

現在、価格は整数の*ペンス*として保存されています（この自転車店はイギリスにあります）。
ウェブサイトでは、価格を*ポンド*で表示したいと考えています。1.00ポンドは100ペンスに相当します。
2つ目のタスクは、`penceToPounds`関数を実装することです。この関数はペンスの額を`Int`で受け取り、それに相当するポンドを`Float`として返します。
この関数の型注釈も定義しましょう。

```elm
penceToPounds 106
    --> 1.06
```

## 3. ウェブサイトに表示するために価格をフォーマットする

Betty's Bike Shopの自転車はポンドで販売されているため、価格は"£"という記号を付けて表示します。
3つ目のタスクは、`poundsToString`関数を実装することです。この関数はポンドの額を`Float`で受け取り、ポンド記号を先頭に付けた価格を`String`として返します。
`String`モジュールには、このために役立つ`String.fromFloat`関数があります。
使用する前に`String`モジュールをインポートしましょう。
`poundsToString`の型注釈も定義しましょう。

```elm
poundsToString 1.06
    --> "£1.06"
```
