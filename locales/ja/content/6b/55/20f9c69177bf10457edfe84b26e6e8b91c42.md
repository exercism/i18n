# 説明

チームは気象学のアプリケーションに取り組んでいます。
気象データを表すさまざまな型と定数を使ったAPIを定義しています。詳しくは`meteorology.go`ファイルを見てください。

ここでの課題は、すべての型に適切な`String`メソッドを追加して、`Stringer`インターフェースを実装することです。

## 1. `TemperatureUnit`型に`Stringer`インターフェースを実装する

話し合いの結果、チームは温度の単位を`Celsius`または`Fahrenheit`のいずれかにすることに決めました。
値は、以下の例のようにフォーマットする必要があります。

`TemperatureUnit`型に`String`メソッドを追加して、`Stringer`インターフェースを実装させましょう。
このメソッドは、温度の単位が`Celsius`なら`"°C"`、`Fahrenheit`なら`"°F"`という文字列を返す必要があります。

```go
celsiusUnit := Celsius
fahrenheitUnit := Fahrenheit

celsiusUnit.String()
// => °C
fahrenheitUnit.String()
// => °F
fmt.Sprint(celsiusUnit)
// Output: °C
```

## 2. `Temperature`型に`Stringer`インターフェースを実装する

`Temperature`の値は、整数と温度の単位から構成されます。
以下の例のようにフォーマットする必要があります。

そのためには、`Temperature`型に`String`メソッドを追加して、`Stringer`インターフェースを実装させましょう。
このメソッドは、温度の数値と温度の単位をスペースで区切った文字列を返すようにします：`<temperature> <unit>`：

```go
celsiusTemp := Temperature{
    degree: 21,
    unit: Celsius,
}
celsiusTemp.String()
// => 21 °C
fmt.Sprint(celsiusTemp)
// Output: 21 °C

fahrenheitTemp := Temperature{
    degree: 75,
    unit: Fahrenheit,
}
fahrenheitTemp.String()
// => 75 °F
fmt.Sprint(fahrenheitTemp)
// Output: 75 °F
```

## 3. `SpeedUnit`型に`Stringer`インターフェースを実装する

長い議論のすえ、チームは風速の単位を`KmPerHour`または`MilesPerHour`のいずれかにすることに決めました。
値は、以下の例のようにフォーマットする必要があります。

そのためには、`SpeedUnit`型に`String`メソッドを追加して、`Stringer`インターフェースを実装させましょう。
このメソッドは、速度の単位がキロメートル毎時なら`"km/h"`、マイル毎時なら`"mph"`という文字列を返す必要があります。

```go
mphUnit := MilesPerHour
mphUnit.String()
// => mph
fmt.Sprint(mphUnit)
// Output: mph

kmhUnit := KmPerHour
kmhUnit.String()
// => km/h
fmt.Sprint(kmhUnit)
// Output: km/h
```

## 4. `Speed`に`Stringer`インターフェースを実装する

風速の値は、整数と速度の単位から構成されます。
以下の例のようにフォーマットする必要があります。

そのためには、`Speed`型に`String`メソッドを追加して、`Stringer`インターフェースを実装させましょう。
このメソッドは、速度の数値と速度の単位をスペースで区切った文字列を返すようにします：`<speed> <unit>`：

```go
windSpeedNow := Speed{
    magnitude: 18,
    unit: KmPerHour,
}
windSpeedNow.String()
// => 18 km/h
fmt.Sprintf(windSpeedNow)
// Output: 18 km/h

windSpeedYesterday := Speed{
    magnitude: 22,
    unit: MilesPerHour,
}
windSpeedYesterday.String()
// => 22 mph
fmt.Sprint(windSpeedYesterday)
// Output: 22 mph
```

## 5. `MeteorologyData`型に`Stringer`インターフェースを実装する

気象データは、場所、気温、風向、風速、湿度を指定します。
以下の例のようにフォーマットする必要があります。

そのためには、`MeteorologyData`型に`String`メソッドを追加して、`Stringer`インターフェースを実装させましょう。
このメソッドは、気象データを次の形式で返すようにします：

```text
<location>: <temperature>, Wind <wind_direction> at <wind_speed>, <humidity>% Humidity
```

```go
sfData := MeteorologyData{
    location: "San Francisco",
    temperature: Temperature{
        degree: 57,
        unit: Fahrenheit
    },
    windDirection: "NW",
    windSpeed: Speed{
        magnitude: 19,
        unit: MilesPerHour
    },
    humidity: 60
}

sfData.String()
// => San Francisco: 57 °F, Wind NW at 19 mph, 60% Humidity
fmt.Sprint(sfData)
// Output: San Francisco: 57 °F, Wind NW at 19 mph, 60% Humidity
```
