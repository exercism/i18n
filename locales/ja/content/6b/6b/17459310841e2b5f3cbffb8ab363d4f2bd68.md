# 指示

_Instruments of Texas_では、RPN Calculatorの作業が順調に進んでいます。チームは今、方程式の文字列版を_IO_リソースに書き出せるようにしたいと考えています。

## 1. ファイルを開く

方程式をどの種類のデバイスに書き出すかは、チーム内でまだ決まっていません。そこで、リソースを関数にハードコードするのではなく、外部から注入できるように、_動的ディスパッチ_のアプローチを使うことを提案します。`write/3`関数を実装し、リソースとファイル名を使って_IOデバイス_を開いてください。

`resource`は常に、`{:ok, io_device}`を返す`open/1`関数を持つモジュールを表すアトムだと想定してかまいません。

関数が成功したら、方程式を含むokタプルを返してください。

```elixir
RPNCalculator.Output.write(resource, "file_to_be_written", "1 4 +")
# {:ok, "1 4 +"}
```

## 2. IOデバイスへの書き込みを試す

_IOデバイス_を開いたので、次は`IO.write/2`を使って書き込んでみてください。

`write/3`関数を拡張して、この操作を行ってください。書き込み操作はエラーを発生させる可能性があります。そのエラーから`rescue`し、エラータプルを返します。

```elixir
RPNCalculator.Output.write(resource, "bad_file", "1 4 +")
# {:error, "Unable to write to resource"}
```

## 3. IOデバイスを閉じる

開いたリソースは、それを利用する関数がエラーを発生させたとしても、常に解放しようとするのが良い習慣です。`write/3`関数を拡張して、リソースのclose関数を呼び出し、_IOデバイス_を閉じてください。

`resource`は常に、_IOデバイス_を引数に取る`close/1`関数を持つモジュールを表すアトムだと想定してかまいません。
