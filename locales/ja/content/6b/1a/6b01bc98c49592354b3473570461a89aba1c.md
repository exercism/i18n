# 概要

## モジュール

Gleamのコードはモジュールに整理され、1つのファイルが1つのGleamモジュールになります。

これまでは、`pub fn`という構文で関数を書いてきました。これは、他のモジュールから公開して利用できる関数を定義するものです。`fn`で定義された関数は、それを定義したモジュール内だけのもので、他のモジュールから使うことはできません。

```gleam
// This function is public
pub fn add(x, y) {
  x + y
}

// This function is private
fn subtract(x, y) {
  x - y
}
```

Gleamのモジュールには名前があり、その名前は`src`ディレクトリまたは`test`ディレクトリ内のファイルパスに基づきます。

たとえば、`src\geometry\rectangle.gleam`（Windowsの場合）または`src/geometry/rectangle.gleam`（UNIX系オペレーティングシステムの場合）で定義されたモジュールは、`geometry/rectangle`という名前になります。

## 他のモジュールから関数をインポートする

他のモジュールで定義された関数にアクセスするには、インポートを使います。モジュールをインポートすると、そのモジュールが公開しているすべての関数が使えるようになります。ただし、それらの関数へのアクセス方法は、モジュールのインポートのしかたによって変わります。

修飾インポートは既定の方法で、そのようなモジュール内の関数（たとえば`gleam/list`モジュールの`map`関数）にアクセスするには、モジュール名を前に付けます（`list.map`）。

```gleam
// Import the int module
import gleam/int

pub fn run(x: Int) -> String {
  // Use the to_string function from the int module
  int.to_string(x)
}
```

既定では、モジュールを指すために使う名前は、モジュール名の最後の部分です。この場合は`int`ですが、`as`キーワードを使うと変更できます。

```gleam
// Import the int module and refer to it as i
import gleam/int as i

pub fn run(x: Int) -> String {
  i.to_string(x)
}
```

非修飾インポートを使うと、そのモジュールが公開している関数に、接頭辞を付けずに直接アクセスできます。

```gleam
// Import the to_string function from the int module
import gleam/int.{to_string}

pub fn run(x: Int) -> String {
  to_string(x)
}
```

関数がどこから来たのかが読み手に分かりやすく、名前の衝突も避けられるので、修飾インポートのほうが好まれます。
