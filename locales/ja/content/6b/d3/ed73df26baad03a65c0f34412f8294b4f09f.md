# 説明

この演習では、フリーランサーがプロジェクトマネージャーとやり取りするためのコードを書きます。日額と月額をすばやく計算するためのユーティリティをいくつか提供します。必要に応じて割引を適用することもできます。

まず、フリーランサーとプロジェクトマネージャーの間で、いくつかのルールを決めておきます。

- 日額は時給の8倍です。
- 1か月は請求可能な22日とします。

場合によっては、フリーランサーが日額に割引を適用することもあります（たとえば、最も忠実な顧客や非営利の顧客に対して）。

割引は、パーセンテージを表す小数としてモデル化します。たとえば`25.0`（25%）です。

## 1. 時給から日額を計算する

時給から日額を計算する関数を実装してください。

```haskell
dailyRate 60
-- -> 480.0
```

戻り値の日額は小数にします。

## 2. 割引後の価格を計算する

割引後の価格を計算する関数を実装してください。

```haskell
applyDiscount 150 10
-- -> 135.0
```

戻り値は常に小数とし、決して丸めないようにします。

## 3. 時給と割引から月額を計算する

月額を計算し、割引を適用する関数を実装してください。

```haskell
monthlyRate 77 10.5
-- -> 12130
```

戻り値の月額は、最も近い整数に切り上げます（天井をとります）。

## 4. 予算、時給、割引から勤務日数を計算する

予算、時給、割引を受け取り、その予算で何日分の作業ができるかを計算する関数を実装してください。

```haskell
daysInBudget 20000 80 11.0
-- -> 35.1
```

戻り値の日数は、小数点以下1桁に切り捨てます（床をとります）。
