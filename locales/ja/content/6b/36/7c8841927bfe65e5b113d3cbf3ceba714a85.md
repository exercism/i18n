# 指示の補足

## ヒント

`decode`と`encode`という関数を実装する必要があります。この2つの関数は、アフィン暗号を使って`String`をデコードしたりエンコードしたりします。
型がわからない場合は、用意されているシグネチャーを使ってもかまいません。ただし、それに縛られて自由な発想を狭めないようにしましょう。

この演習では、テキストデータを扱います。
歴史的な理由から、Haskellの`String`型は、文字のリストである`[Char]`と同じ意味を持ちます。
テキストデータをより効率よく扱うには、`Text`型を使うこともできます。

この演習の発展として、任意で次のことができます。

- package.yamlの依存関係のリストに`- text`を追加する。
- `Data.Text`を[次のように](https://hackernoon.com/4-steps-to-a-better-imports-list-in-haskell-43a3d868273c)インポートする。

```haskell
import qualified Data.Text as T
import           Data.Text (Text)
```

- `Text`型を使う（例：`decode :: Text -> Text`）。そして`Data.Text`のコンビネーターを、例えば`T.pack`のように参照する。
- [`Data.Text`](https://hackage.haskell.org/package/text/docs/Data-Text.html)のドキュメントを調べる。
- Affine.hsの中で`String`となっている箇所をすべて`Text`に置き換える。つまり、次のとおりです。

```haskell
encode :: (Int, Int) -> Text -> Maybe Text
encode key plainText = ...

decode :: (Int, Int) -> Text -> Maybe Text
decode key cipherText = ...
```

この部分はまったくの任意です。
