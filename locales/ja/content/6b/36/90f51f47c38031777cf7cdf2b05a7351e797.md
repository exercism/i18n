# 概要

F#の真偽値は`bool`型で表され、その値は`true`か`false`のどちらかです。

F#は3つの[真偽値演算子][operators]、`not`（NOT）、`&&`（AND）、`||`（OR）に対応しています。`&&`と`||`演算子は_短絡評価_を使います。これは、演算子の右辺が必要なときにだけ評価されるという意味です。

```fsharp
true || false // => true
true && false // => false
```

3つの真偽値演算子は、それぞれ[_演算子の優先順位_][precedence]が異なります。そのため、`not`、`&&`、`||`の順に評価されます。このルールを「回避」したいときは、真偽値の式を括弧（`()`）で囲みます。括弧は演算子の優先順位がさらに高いからです。

```fsharp
not true && false   // => false
not (true && false) // => true
```

[precedence]: https://docs.microsoft.com/en-us/dotnet/fsharp/language-reference/symbol-and-operator-reference/#operator-precedence
