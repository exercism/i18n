# 問題解決のための戦略


このページの最初の記事でも述べられているとおり、**_問題解決はメタスキルです_**。
課題を解くうえで最も難しいのは、プログラミング言語の文法や構造ではないことが少なくありません。難しいのは、_何をコードに書くのか_、_どこから始めるのか_を見きわめることです。
問題をコードにできる手順へと分解するための戦略と仕組みを身につけることは、ぜひ磨きたい**すばらしい**スキルです。
以下では、このスーパースキルを磨くのに役立つ、コミュニティから寄せられた記事や動画、書籍を紹介します。


- Free Code Campには、[How to Think Like a Programmer - Lessons in Problem-Solving][free-code-camp-think-like-a-programmer]というわかりやすい概説記事があります。
- fast.aiの創業者であるJeremy Howardが、[G. Polya's Problem Solving Techniques][g-polya-how-to-solve-it-summary]をうまくまとめています。
- 1945年に複雑な数学の問題に取り組むための手引きとして書かれた[G. Polya's How To Solve It][g-polya-how-to-solve-it]（書籍全文）は、今なお一般的な問題解決において_すばらしい_指針です。
- Towards Data Scienceに寄稿しているKurtis Pykesによる、[問題解決のための実践的なチュートリアル][Kurtis Pykes: Hands-on Tutorial - How to Improve Your Problem-Solving Skills as A Programmer]も参考になります。
- Free Code Campの記事でも紹介されているV. Anton Spraulの[Think Like a Programmer: An Introduction to Creative Problem Solving][v-anton-spraul-think-like-a-programmer]は、Polyaが数学について示したのと同じ一般的な手法を、より現代的に、プログラミングに焦点を当てて扱ったものです。
- [Felienne Hermans][felienne-hermans]は、人がコードを書くという技術を_どのように_学ぶのか、そしてそれが一般的な学習とどう対応するのかに、より焦点を当てています。
  彼女は[The Programmer's Brian][programmers-brain-free-online]を執筆しており、その中では、コードをよりよく読む、コードを明確に考える、よりよいコードを書く、よりよいコードの協働者になるための戦略が示されています。
  - 彼女の書籍の紙の版は[こちら][programmers-brain-manning]から注文できます。
  - 同じテーマについて、興味深い動画も2本あります。[How to Teach Programming (and other things)?][felienne-hermans-how-to-teach-programming]と[Programming is Writing is Programming ][felienne-hermans-programming-is-writing-is-programming]です。
- No Starch Pressの[Algorithmic Thinking (Daniel Zingaro)][daniel-zingaro-algorithmic-thinking]と、[How to think like a programmer (Paul Vickers)][paul-vickers-how-to-think-like-a-programmer]も、コーディングにおける問題解決を扱っています。
- [Computational Thinking: A beginner's guide to problem-solving and programming (Karl Beecher)][beecher-computational-thinking]と[Computational Thinking for the Modern Problem-Solver (Riley and Hunt)][riley-and-hunt-computational-thinking]も、問題を考え、コーディングによる解決へと分解するための戦略を提供しています。
- [From Computing to Computational Thinking (Paul S. Wang)][wang-computational-thinking]は、少し一般向けで学術的ですが、コーディング以外にも応用できる問題解決の戦略と構造を示しており、事前のプログラミング知識は必要ありません。

これらの書籍の一部は、Association of Computing Machinery（ACM）のライブラリを通して読むこともできます。
会員（有料）の情報は[acm(dot)org][association-for-computing-machinery]で確認できます。
