# はじめに

## 判別共用体

判別共用体は、決まった数の名前付きケースを表す型です。判別共用体の各値は、名前付きケースのうちのちょうど1つに対応します。

判別共用体は`type`キーワードを使って定義し、各ケースはパイプ（`|`）文字で区切ります。

```fsharp
type Season =
    | Spring
    | Summer
    | Autumn
    | Winter
```

判別共用体の各ケースには、必要に応じてデータを関連付けることができ、ケースごとに異なる型のデータを持たせることができます。どのケースにもデータが関連付けられていない場合、判別共用体は、他の言語で一般に_列挙型_（または_enum_）と呼ばれるものに似ています。

```fsharp
type Number =
    | Integer of int
    | Float of float
    | Invalid
```

特定のケースの値を作るには、その名前（例えば`Success`）を参照します。ケース名は単なるコンストラクター関数なので、関連するデータは通常の関数の引数として渡すことができます。別の判別共用体が同じ名前のケースを定義している場合は、その完全な名前（例えば`Result.Success`）を使う必要があります。

```fsharp
let byName = Integer 2
let byFullName = Number.Invalid
```

判別共用体には_構造的等価性_があり、同じケースで同じ（省略可能な）データを持つ2つの値は等価であることを意味します。

判別共用体を扱うのに`if/elif/else`式を使うこともできますが、推奨される方法は、_識別子パターン_を使ったパターンマッチングです。

```fsharp
let describe number =
    match number with
    | Integer i -> sprintf "Integer: %d" i
    | Float d  -> sprintf "Float: %f" d
    | Invalid   -> "Invalid"
```
