# はじめに

Kotlinの関数は第一級オブジェクトです。
つまり、変数に代入したり、引数として渡したり、ほかの関数から返したりできます。
たとえば、関数を変数`addOne`に代入する場合は次のようになります。

```kotlin
val addOne = fun (num : Int) : Int {
    return num + 1
}
```

関数は、別の関数を返すこともできます。

```kotlin
fun makeAddOne() : (Int) -> Int {
    return fun(num : Int) : Int {
        return num + 1
    }
}

val addOne = makeAddOne()
```

代入したあとは、変数を通して、ほかの関数と同じように呼び出せます。

```kotlin
addOne(3)
// => 4
```

## 関数の型を宣言する

変数や引数の型は、`(parameter types) -> return type`という構文で宣言できます。
たとえば、変数を宣言する場合は次のようになります。

```kotlin
val addOne : (Int) -> Int = fun (num : Int) : Int {
    return num + 1
}
```

関数の引数の場合はこちらです。

```kotlin
fun perform(operation : (Int) -> Int) {
    operation(3)
}
```

## ラムダ式

ラムダ式は、関数をもっと短く定義する方法です。
`{ parameters -> body }`という形で書きます。
本体の最後の文の値が、その式の戻り値になります。
たとえば次のようになります。

```kotlin
// Assigning to a variable
val addOne = { num : Int -> num +  1}

// In a function call
perform({ num : Int -> num + 1 })
```

Kotlinは、情報が十分にあれば型を推論してくれます。
たとえば、上の例は次のようにも書けます。

```kotlin
// Assigning to a variable
val addOne : (Int) -> Int = { num -> num + 1 }

// Or ...
val addOne  = { num : Int -> num + 1 }

// Using in a function
perform({ num -> num + 1 })
```

## 引数が1つのラムダには`it`を使う

式の引数が1つだけのときは、その引数を省略できます。
するとKotlinは、本体で使える`it`という名前の引数を用意してくれます。
たとえば次のようになります。

```kotlin
val addOne : (Int) -> Int = { it +  1 }
```

## 末尾のラムダを渡す

関数の最後の引数がラムダのときは、ラムダ式を括弧（`()`）の_直後_に書きます。
たとえば次のようになります。

```kotlin
// Function that takes a function as last argument
fun calculateFrom(from : Int, operation : (Int) -> Int) : Int {
    return operation(from)
}

// Call the calculateFrom function
calculateFrom(2) { it * 3 }
// => 6
```
