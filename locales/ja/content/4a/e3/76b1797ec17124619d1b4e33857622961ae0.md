# はじめに

関数はデフォルトで外部リンケージを持ち、プロジェクト内のほかのどのファイルからでも呼び出すことができます。リンケージについて詳しくは、[リンケージのコンセプト](../linkage/introduction.md#Introduction)を参照してください。`static`関数は、それが定義されているソースファイル内からしか呼び出せません。

たとえば、次のようになります。

```c
// file scope, internal linkage
// can only be called from within this file
static void some_function()
{
    // code snipped
}

// file scope, external linkage by default
// can be called from any other file in the project
int main()
{
    // code snipped
}
```
