# 概要

多くの演算子は、[複合代入][compound-assignment]としても使えます。複合代入とは、`x = op y`を`x op= y`と書けるようにする省略記法です。

```csharp
var features = PhoneFeatures.Call;
features |= PhoneFeatures.Text;
features &= ~PhoneFeatures.Call;
```
