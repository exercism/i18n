# 説明

あなたは、チャットボットを開発している会社で、正規表現のスペシャリストとして働くことになりました。

開発はまだごく初期の段階です。
ミッションは、正規表現を使って、チャットボットが自然言語を理解し、生成する能力を高めることです。

## 1. 有効なコマンドかどうかを確認する

チャットボットは賢いだけでなく、忠実なアシスタントでもあります。
チャットボットに何かを尋ねるには、ユーザーはコマンドの先頭で**"Chatbot"**という単語を言わなければなりません。
キーワードが大文字でも小文字でもかまいません。
重要なのは、その単語の位置です。

ユーザーがコマンドを出しているときにチャットボットがそれを認識できるようにする、`is_valid_command`関数を実装しましょう。

```jq
"Chatbot, play a song from the 80's." | is_valid_command
# => true
"Hey Chatbot, where is the closest pharmacy?" | is_valid_command
# => false
"CHATBOT, do you have a solution for this challenge?" | is_valid_command
# => true
```

## 2. 暗号化された絵文字を削除する

チャットボットは、人間が感情を表すために絵文字をどのように使うのかを理解するのが苦手です。
チャットボットがユーザーのメッセージを受け取ると、それぞれの絵文字は"emoji"という文字列のあとに_id番号_が続く形で表されます。

文字列を受け取り、メッセージ全体からすべての絵文字を削除する`remove_emoji`メソッドを実装しましょう。

絵文字を含まない行は、そのままの形で返します。
絵文字の文字列だけを削除します。
空白は調整しないでください。

```jq
"I love playing videogames emoji3465 it's one of my hobbies" | remove_emoji
# => "I love playing videogames  it's one of my hobbies"
```

## 3. 有効な電話番号かどうかを確認する

チャットボットとのやり取りの中で、ユーザーが電話番号を伝えることがあります。
チャットボットは、特定の形式の番号にしか発信できません。

`check_phone_number`関数を実装しましょう。

番号が有効であれば、チャットボットはユーザーに感謝し、番号を確認するメッセージで応答します。
番号が無効であれば、チャットボットはその電話番号が有効でないことをユーザーに伝えます。

期待される形式は`(+NN) NNN-NNN-NNN`で、Nは数字です。

```jq
"chatbot my phone number is (+34) 659-771-594" | check_phone_number
# => "Thanks! Your phone number is OK."
"chatbot, call me at 659-771-594" | check_phone_number
# => "Oops, it seems like I can't reach out to 659-771-594."
```

## 4. ウェブサイトのリンクを取得する

チャットボットはとても好奇心旺盛なソフトウェアです。
特定の話題についてインターネットで検索できるにもかかわらず、関連する情報を見つけるために訪れるのにぴったりな素敵なウェブサイトを、ユーザーに尋ねるのが好きです。

会話の例:

> **チャットボット**: ねえユーザー、JavaScriptでコードを書く方法を学びたいんです。どこか学べる素敵なウェブサイトを知りませんか？

> **ユーザー**: exercism.orgでたくさん学びました。あそこには素晴らしいコンテンツがたくさんあります。

ウェブサイトのドメインの配列を返す`get_domains`関数を実装しましょう。

```jq
"I learned a lot from exercism.org and google.com" | get_domains
# => ["exercism.org", "google.com"]
```

## 5. ユーザーにあいさつする

礼儀正しいチャットボットは、ユーザーを名前で呼びかけます。
ユーザーが自己紹介をすると、チャットボットはその名前を検出して、親しみやすいあいさつで応えます。

`nice_to_meet_you`関数を書きましょう。

入力文字列に"My name is Someone."が含まれている場合は、名前を取り出して、"Nice to meet you, Someone."という文字列を返します。

```jq
"My name is Jean-Luc" | nice_to_meet_you
# => "Nice to meet you, Jean-Luc"
```

## 6. とてもシンプルなCSV解析

「どんどん機能を足したくなる病」に屈して、チャットボットにCSV解析関数を追加することにします。

文字列を受け取り、解析結果のフィールドの配列を返す`parse_csv`関数を実装しましょう。
フィールドの区切りは「カンマと、それに続く任意の空白」とします。

CSV形式のエッジケース（カンマを含むフィールドなど）は気にしません。

```jq
"first, second,third,   fourth" | parse_csv
# => ["first", "second", "third", "fourth"]
```
