# 説明の追記

## レジスタ

| レジスタ | 用途     | 型    | 説明                              |
| -------- | --------- | ------- | ---------------------------------------- |
| `$a0`    | 入力     | アドレス | ヌル終端された入力文字列             |
| `$v0`    | 出力     | 真偽値 | 有効なISBNかどうか（`0` = `false`、`1` = `true`） |
| `$t0-9`  | 一時     | 任意     | 一時的な保存に使われる               |
