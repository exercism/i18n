# 概要

C#の真偽値は`bool`型で表され、その値は`true`か`false`のどちらかです。

C#では、`!`（NOT）、`&&`（AND）、`||`（OR）、`^`（XOR）という4つの[論理演算子][operators]が使えます。`&&`と`||`は_短絡評価_を行います。つまり、演算子の右辺は必要なときにだけ評価されます。

```csharp
true || false // => true
true && false // => false
true ^ false  // => true
true ^ true   // => false
```

3つの論理演算子には、それぞれ異なる[_演算子の優先順位_][precedence]があります。その結果、評価の順序は`not`が最初、次に`&&`、3番目に`^`、最後に`||`となります。この規則を「逃れる」には、真偽値の式を括弧（`()`）で囲みます。括弧は演算子の優先順位がさらに高いからです。

```csharp
!true && false   // => false
!(true && false) // => true
```
