# 概要

ABAPでは、数値に対する一般的な算術演算子を使うことができます。

- `+`は値を足します。
- `-`は値を引きます。
- `*`は値を掛けます。
- `/`は値を割ります。
- `MOD`は整数の割り算の余りを返します。

```abap
DATA total TYPE i.
total = 6 + 4 * 2.

DATA remaining_days TYPE i.
remaining_days = 70 MOD 22.
```

掛け算と割り算は、足し算と引き算より先に評価されます。計算を明示的にまとめたいときは、括弧（`()`）を使います。

```abap
DATA result TYPE i.
result = ( 6 + 4 ) * 2.
```
