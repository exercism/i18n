# コマンドラインでのテスト

テストは次のコマンドで実行します。

```bash
$ cargo test
```

最初のテスト以外は、すべて無視されるようになっています。最初のテストに合格したら、`tests`ディレクトリにあるテストのソースファイルを開き、次のテストから`#[ignore]`フラグを外して、もう一度テストに合格させましょう。それぞれのテストは、上に`#[test]`フラグが付いた関数です。すべてのテストに合格するまで、これを繰り返します。

テストのソースファイルを編集せずに、_無視された_テストだけを実行したい場合は、次のコマンドを使います。

```bash
$ cargo test -- --ignored
```

Rust 1.51以降を使っている場合は、次のコマンドで_すべての_テストを実行できます。

```bash
$ cargo test -- --include-ignored
```

特定のテストだけを実行するには、たとえば`some_test`なら、次のようにします。

```bash
$ cargo test some_test
```

その特定のテストが無視される設定になっている場合は、次のようにします。

```bash
$ cargo test some_test -- --ignored
```

Rustのテストについて詳しく知りたい場合は、オンラインの[テストのドキュメント][rust-tests]を参照してください。

[rust-tests]: https://doc.rust-lang.org/book/ch11-02-running-tests.html
