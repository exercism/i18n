# 概要

条件分岐とは、条件が`true`か`false`かによって、実行するコードが変わる文のことです。

[`if`文][if_statement]は、条件が`true`のときだけ本体を実行します。
Goにはtruthyやfalsyといった考え方がないため、条件は`bool`型でなければなりません。
`if mySlice { ... }`や`if 1 { ... }`のような式はコンパイルエラーになります。

```go
func describe(val string) string {
    if val == "val" {
        return "was val"
    }
    return "was not val"
}
```

追加の条件を確認するには`else if`を、どの条件にも当てはまらない場合の受け皿として`else`を使います。
条件は上から順に評価され、条件が真になった最初の分岐だけが実行されます。

```go
number := 0
result := "This number is "

if number > 0 {
    result += "positive"
} else if number < 0 {
    result += "negative"
} else {
    result += "zero"
}
```

一般に、Goでは例外的なケースでは早めにreturnして抜け、`else`を避けるスタイルが好まれます。

```go
func getVal(connected bool) int {
    if !connected {
        return readLocalVal()
    }

    return readVal()
}
```

`if`文には、短い初期化文を含めることもできます。
これは、呼び出しの直後にエラーを確認するときによく使われます。

```go
num := 7
if v := 2 * num; v > 10 {
    fmt.Println(v)
} else {
    fmt.Println(num)
}
// Output: 14
```

初期化文で宣言した変数のスコープは、`if`/`else`の連鎖全体の中だけです。
注目すべき点として、Goには三項演算子がありません。これはコードを読みやすく保つための、意図的な設計上の選択です。

さらに詳しく知りたい場合は、[Go by Example: If/Else][go_by_example_if]を参照してください。
