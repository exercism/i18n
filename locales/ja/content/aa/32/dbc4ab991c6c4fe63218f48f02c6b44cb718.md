# 概要

`awk`は、テキスト処理のために設計されたインタプリター型のプログラミング言語で、ふつうはデータの抽出やレポート作成のツールとして使われます。
ほとんどのUnix系オペレーティングシステムに標準で備わっており、[POSIXの仕様][posix]もあります。

`awk`のプログラミングパラダイムは「データ駆動型」と言えます。
`awk`のプログラムは行（またはその他のテキストの単位）を読み込み、_パターン_に一致するものを探します。
一致すると、指定した_アクション_が実行されます。

`awk`のプログラムは、だいたい次のような形をしています。
```awk
pattern1 {action1}
pattern2 {action2}
...
```

_パターン_には正規表現や、真偽値に評価されるその他の式を書けます。
_パターン_は省略できます。その場合、_アクション_はテキストの各レコードに対して実行されます。
_アクション_も省略できます。その場合のデフォルトの動作は、現在のレコードを出力することです。

`awk`はユーザーの道具箱にぜひ加えておきたいツールです。
コマンドラインで入力する短い「ワンライナー」プログラムがとても得意です。
`awk`のプログラム1つで、`grep`、`sed`、`tr`、`cut`のパイプラインのほとんどを置き換えられます

## 実装

`awk`は1977年に、Alfred Aho、Peter Weinberger、Brian Kernighanという作者たちによって考案されました（この3人の名字が、この言語の名前のもとになっています）。
この実装は「old awk」として知られるようになりました。
1985年には改良版がリリースされ、「BWK awk」「new awk」「the one-true-awk」として知られています。
これがmacOSや一部の\*BSDディストリビューションに同梱されているバージョンです

もう1つよく使われる実装が`mawk`で、バイトコードインタプリターを基にしています。
`mawk`はとても高速です。
`mawk`は、多くのLinuxディストリビューションでデフォルトの`/usr/bin/awk`として同梱されています。

### GNU awk

このトラックでは、GNUによるawkの実装である`gawk`を使います。
`gawk`は`mawk`ほどの生のスピードはないかもしれませんが、機能がとても豊富で、ドキュメントも充実しており、便利なコマンドラインオプションもいくつかあります。

### シェバン

プラットフォームによっては、ファイルの先頭に[シェバン][shebang]の行を追加すると、awkスクリプトを実行できます。
ほとんどのシステムでは、次の2つのシェバンのどちらかが動くはずです。
ただし、すべてのシステムで動くシェバンは1つではないため、ここではシェバンを省略することにしました。

```bash
#!/usr/bin/env -S gawk -f
#!/usr/bin/gawk -f
```
