# はじめに

Elixirでは、モジュール属性を定義して、関数の中で定数として使うことができます。

```elixir
defmodule Example do
  # Defines the attribute as the value 1
  @constant_number 1

  def example_value() do
    # Returns the value 1
    @constant_number
  end
end
```

モジュールの定数を定義するのに使う場合、属性の値にはコンパイル時に評価できる任意の式を指定できます。コンパイル後は、モジュール属性はコンパイル中に展開されるため、アクセスできません。Cなどの言語で定義されるマクロと似ています。
