# テストの実行

ターミナルで演習のベースディレクトリに移動してから、次のコマンドでテストを実行します：

```bash
$ gleam test
```

これで、`test`サブフォルダーにある、名前が`_test.gleam`で終わるテストファイルが実行されます。

## テスト関数

テストには[独自のテストフレームワーク](https://github.com/exercism/gleam-test-runner/tree/main/runner)を使います。`test`ディレクトリにある公開関数のうち、名前が`_test`で終わるものは、テストフレームワークによってテストとみなされます。

例えば、次のように書きます：

```gleam
import bob
import exercism/should

pub fn shouting_test {
  bob.hey("WATCH OUT!")
  |> should.equal("Whoa, chill out!")
}
```
