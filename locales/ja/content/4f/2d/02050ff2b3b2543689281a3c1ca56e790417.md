# ヒント

## 1. 3つの演目

- クラスのヘッダーでは、`<`のあとに抽象クラスの名前を書きます：`class JUGGLING < $ACT is`。
- それぞれが、抽象クラスで宣言されているとおりに、`name`と`minutes`の両方を定義しなければなりません。片方でも欠けると、そのルーチンの名前を示すコンパイルエラーになります。
- また、それぞれに`create`が必要です。そうでないと、`#JUGGLING`が呼び出せるものを何も持ちません。そのうち2つにとっては、`create : SAME is return new; end;`だけで十分です。
- `TRAPEZE`には、高さのための属性と、それを受け取る`create`が必要です。
- `+`は数値を文字列につなげるので、`"Trapeze at " + height + "m"`に変換は要りません。

## 2. ショー

- 引数の型は`ARRAY{$ACT}`です。これにより、1つの配列に3種類すべてを入れられます。
- `acts.elt!`は`$ACT`を取り出します。それに対して`.minutes`を呼び出すと、適切なほうが自動的に実行されます。これがディスパッチであり、この演習の要点です。チェックすべきことは何もなく、`typecase`を書く必要もありません。
- `billing`はループの中で文字列を組み立てるので、`FSTR`を使います。また、`", "`は最初の名前以外のすべての名前の前に付けます。
- `longest`は、ここまでで最も良い演目を保持します。最良の分数を`-1`から始めれば、最初の演目が必ずそれを上回るので、特別な場合分けなしに空のショーにも対応できます。名前は`""`のままです。
