# ヒント

## 全般

- イントロダクションを読みましょう。似た例を順を追って説明しています。
- Juliaのマニュアルにある[インターフェース][iteration-interface]のセクションにも、別の例があります。

## 1. `Fiberator`型を定義する

- `n`は、生成する数値の個数です。
- シンプルに保ちましょう。ほかの情報は必要ありません。

## 2. `iterate`メソッドを実装する

- 重要な実装の詳細はイントロダクションを参照してください。
- `state`引数は整数である必要はありません。どんな型でもかまいません。
- 次の要素を計算するにはどの値が必要かを考えましょう。それらをまとめたタプルが`state`引数になります。
- `iterate`メソッドは、2つの値`(item, state)`を持つ`Tuple`を返します。`item`はフィボナッチ数、つまり`for item in Fiberator(10)`の`item`です。
- `state`に複数の値が含まれる場合は、名前付きタプルを使うと各値の意味が明確になるので検討してみましょう。
  - これは分割代入に便利ですが、必須ではありません。

## 3. `collect`を動くようにする

- 小さなメソッドを1つ（重要な実装の詳細はイントロダクションを参照してください）。
- これがない場合は、エラーメッセージを読んで手がかりを探しましょう。

## 4. 型推論を有効にする

- 小さなメソッドを1つ（重要な実装の詳細はイントロダクションを参照してください）。
- メソッドの引数には注意してください。
- `collect`のあとの結果は、`Vector{Any}`に_ならない_ようにします。

[iteration-interface]: https://docs.julialang.org/en/v1/manual/interfaces/#man-interface-iteration
