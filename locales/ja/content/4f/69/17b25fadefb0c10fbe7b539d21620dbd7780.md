# 指示

友達から、大切な秘密が書かれたメッセージが届きました。
他の人に簡単に読まれたくないので、そのメッセージは一連のビット操作によって暗号化されています。
このメッセージを復号するための関数を書く必要があります。

## 1. ビットをシフトして戻す

メッセージを復号する最初のステップは、暗号化でシフトされた分を、ビットを右にシフトし直して元に戻すことです。
このあとの復号のステップでは、左側から0が挿入されることを前提としています。

値とシフトする桁数を入力として受け取り、シフトを実行する`shift_back()`関数を実装しましょう。

```julia
shift_back(0b1001, 2) # => 0b0010
```

## 2. ビットを立てる

次に、1に設定する必要があるビットがあります。

値とマスクを入力として受け取り、値のビットを1に設定した結果を返す`set_bits()`関数を実装しましょう。
`mask`のビットが1になっている位置では、`value`のビットも1に設定します。
それ以外のビットは変更しません。

```julia
set_bits(0b0110, 0b0101) # => 0b0111
```

## 3. 特定のビットを反転させる

暗号化のときに反転されるビットもあります。
メッセージを復号するには、それらをもう一度反転して元に戻す必要があります。

値とマスクを入力として受け取る`flip_bits()`関数を実装しましょう。
マスクは、値のどのビットを反転するかを示します。
`mask`のビットが1であれば、`value`のビットを反転します。
それ以外のビットは変更しません。

```julia
flip_bits(0b1100, 0b0101) # => 0b1001
```

## 4. 特定のビットをクリアする

最後に、復号すると必ず0になるビットもあります。

値とマスクを入力として受け取る`clear_bits()`関数を実装しましょう。
マスクのビットが1になっている位置では、`value`のビットを0に設定します。
それ以外のビットは変更しません。

```julia
clear_bits(0b0110, 0b0101) # => 0b0010
```
