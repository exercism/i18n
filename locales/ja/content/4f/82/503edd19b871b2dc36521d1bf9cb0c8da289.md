# はじめに

Pythonには2つのループ構文があります。
`while`ループは_不定_（回数を数えない）繰り返しに、`for`ループは_定_（回数を数える）繰り返しに使います。
キーワード`break`、`continue`、`else`を使うと、ループの動作をカスタマイズできます。
`range(<length of sequence>)`関数と`enumerate(<iterable>)`関数は、ループの回数管理やインデックス付けに役立ちます。


`while`ループには実行する回数が指定されず、`loop`式（「テスト」）が`True`と評価される限り続きます。
ループ式が`False`と評価されると、ループは終了します。

```python
while expression:
    set_of_statements
```

`for`ループは任意のシーケンスの値を順にたどり、返される値がなくなると終了します。
`range(<length of sequence>)`関数は、繰り返しの対象となるデータ構造やイテラブルがないときに、ループのカウンターやシーケンスを提供します。

```python
# Python will keep track of the loop count internally.
for item in sequence:
    set_of_statements
    
# `range()` is used as an explicit loop counter.  
# This will loop 12 times, from index 0 to index 11.
for item in range(12):
    set_of_statements
```
