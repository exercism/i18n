Haxeで文字列を手動で連結することもできますが、Haxeは[文字列補間][string-interpolation]をサポートしており、より短く便利な構文を提供します。

```haxe
var x = 42;
//The following two statements are equivalent:

// manual concatenation
trace("the number is " + x);

// using interpolation
trace('the number is $x');
```

上で見たように、補間文字列は通常の[文字列][strings]とは異なり、単一引用符（`'`）で囲みます。また、補間を引き起こすドル記号（`$`）で示される特別な識別子を含めることができます。

`${expr}`を使うと式全体を含めることができます。ここで`expr`は任意の有効なHaxe式です。

```haxe
trace('the next number is ${x + 1}');
```

実際のドル記号を使いたい場面で補間を抑制するには、`$$`を使います。

```haxe
trace('the price is $$42'); // outputs: the price is $42
```

最後に、文字列補間はコンパイル時の機能であり、実行時のパフォーマンスには影響しない点に注意しましょう。内部的には、Haxeコンパイラーが手動で連結した場合と同等のコードを生成します。

[string-interpolation]: https://haxe.org/manual/lf-string-interpolation.html
[strings]: https://haxe.org/manual/std-String.html
