# はじめに

Haxeは型付けが厳密な言語ですが、必要に応じて型システムを回避できます。名前を付けて値を代入することを、変数の定義と呼びます。変数は、型を明示的に指定して定義することも、Haxeのコンパイラーに型を推論させることで定義することもできます。つまり、次の2つの変数定義は同じ意味です。

```haxe
var explicitVariable:Int = 10; // Explicitly typed
var implicitVariable = 10; // Implicit typed
```

変数の値を更新するには、`=`演算子を使います。

```haxe
var number = 0; // Initial value
number = 1; // Updated value
```

変数とは異なる型の値を代入しようとすると、コンパイラーがエラーを出します。

```haxe
var number = 1; // Variable number is of integer type
number = "Hello" // Error trying to assign a string to an integer variable
```

クラスの中にある関数は、_メソッド_と呼びます。メソッドは、0個以上の仮引数を持つことができます。仮引数はすべて、型を明示的に指定する必要があります。仮引数と同様に、メソッドの戻り値の型は推論できず、明示的に指定する必要があります。メソッドから値を返すには、`return`キーワードを使います。

```haxe
function add(x:Int, y:Int):Int {
  return x + y;
}
```

メソッドを呼び出すには、クラス名とメソッド名を指定して、引数を渡します。

```haxe
var sum = add(1, 2) // sum = 3
```

Haxeのスコープは、`{`と`}`の間に定義されます。

Haxeでは、2種類のコメントが使えます。1行コメントは`//`で始まり、複数行コメントは`/*`と`*/`の間に書きます。
