# テスト

## Clojure CLI

ExercismのClojure演習には、[cognitect-labs test-runner](https://github.com/cognitect-labs/test-runner)を呼び出すための`:test`エイリアスを設定した`deps.edn`ファイルが付属しています。

``` bash
$ clj -X:test
```

## Leiningen

Leiningenを使えば、演習のディレクトリで次のコマンドを実行して、演習のテストを実行することもできます。

```bash
lein test
```

## REPL

REPLを使って演習のテストを実行するには、演習のディレクトリで次のコマンドを実行します。

```bash
$ clj
```

または

```bash
$ lein repl
```

次に、演習のテスト名前空間とClojureのテスト名前空間を`require`します）：

```clojure
;; replace <exercise> with the exercise's name
=> (require '<exercise>-test)
```

次に、`<exercise>-test`に対して`run-tests`を呼び出します：

```clojure
;; replace <exercise> with the exercise's name
=> (clojure.test/run-tests '<exercise>-test)
```
