# 説明

この演習では、フリーランサーがクライアントと特定のプロジェクトの料金についてやり取りするのを助けるコードを書きます。
クライアントの費用をすばやく計算するためのユーティリティメソッドをいくつか書きます。

```exercism/note
`rate_per_hour`仮引数と`day_rate`メソッドは、お金に関係しています。
単位は「時間あたりの金額」です。それぞれ、1時間あたりと1日あたりのお金を表します。
```

## 1. 時給から日額を計算する

あるクライアントが、料金について尋ねるためにフリーランサーに連絡してきます。
フリーランサーは、**_1日8時間働いている_**と説明します。
しかし、フリーランサーはプロジェクトの時給しか知りません。
時給から日額を見積もるのを手伝いましょう。

```abap
DATA(freelancer_rates) = NEW zcl_freelancer_rates( ).

freelancer_rates->day_rate( 89 ).
// => 712
```

日額は、丸めたり「固定」の精度に変換したりする必要はありません。

## 2. 固定予算から労働日数を計算する

別の日、プロジェクトマネージャーがフリーランサーに、固定予算のプロジェクトを提案します。
固定予算とフリーランサーの時給が与えられたとき、予算を使い切るまでに働く日数を計算するのを手伝いましょう。
結果は、最も近い整数に**切り捨て**る_必要があります_。

```abap
freelancer_rates->days_in_budget(
  budget        = 20000
  rate_per_hour = 89 ).
// => 28
```

## 3. 大規模プロジェクトの割引料金を計算する

フリーランサーのクライアントは、何か月にもわたるプロジェクトを依頼することがよくあります。
こうした場合、フリーランサーは、まるまる1か月ごとに割引を提供することにし、残りの日数は日額で請求します。
ワークライフバランスが素晴らしいので、暦月ごとに22日しか働きません。つまり、**_どの月も請求可能な日数は22日です。_**
時給、プロジェクトに含まれる請求可能な日数、月ごとの割引率が与えられたとき、そのようなプロジェクトの費用を見積もるのを手伝いましょう。
割引は常に数値として渡されます。たとえば`42%`は`0.42`になります。結果は、最も近い整数に**切り上げ**る_必要があります_。

```abap
freelancer_rates->price_with_monthly_discount(
  rate_per_hour = 89
  num_days      = 230
  discount      = '0.42' ).
// => 97972
```
