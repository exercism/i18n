# 説明

次のようなASCIIで描かれた図の中にある長方形を数えましょう。

```text
   +--+
  ++  |
+-++--+
|  |  |
+--+--+
```

上の図には、次の6つの長方形が含まれています。

```text


+-----+
|     |
+-----+
```

```text
   +--+
   |  |
   |  |
   |  |
   +--+
```

```text
   +--+
   |  |
   +--+


```

```text


   +--+
   |  |
   +--+
```

```text


+--+
|  |
+--+
```

```text

  ++
  ++


```

入力は常に整った長方形であると仮定してかまいません（つまり、どの行の長さも1行目の長さと同じです）。
