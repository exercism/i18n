# ヒント

## 全般

- 各文の最後に`;`を忘れないようにしましょう。
- 整数は`int myInteger = 44;`のように定義できます。

## 1. 焼き時間を求める

- レシピの時間に関する情報は、説明に載っています。
- 関数は`return 2;`の形で値を返すことができます。

## 2. 準備時間を求める

- 層の数は、対応する仮引数を使って取得できます。
- 整数を定義するときに計算を行うことができます：`int myInteger = 3 + myOtherInteger;`

## 3. オーブンに残っている時間を計算する

- 他の関数を呼び出して、その戻り値を変数のように使うことができます：`return 22 * myOtherCalculation();`

## 4. ラザニアに費やした合計時間を計算する

- 出力は、準備にかかった時間と、ラザニアがすでにオーブンに入っていた時間を合わせたものにします。
