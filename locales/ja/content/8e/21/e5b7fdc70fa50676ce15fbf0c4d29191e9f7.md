# 演算子のオーバーロード

演算子のオーバーロードは、一部のプログラミング言語にある機能で、加算（`+`）や減算（`-`）、乗算（`*`）、除算（`/`）といった標準の演算子を再定義して、ユーザー定義型でも使えるようにします。

これにより、ユーザー定義型に対する演算を、プリミティブ型に対する演算と同じように書けるようになり、コードの構文がより直感的になります。

Cairoでは、演算子のオーバーロードは、特定のトレイトを実装することで実現します。

演算子にはそれぞれ対応するトレイトがあり、その演算子をオーバーロードするには、独自の型に対してそのトレイトの実装を用意します。
ただし、演算子のオーバーロードは、使いどころを見極めることが大切です。

たとえば、オーバーロードする演算子に意味的なつながりがない場合など、誤った使い方をすると混乱を招き、コードの保守が難しくなります。

2つの`Potions`を組み合わせる例を考えてみましょう。

`Potions`には、manaとhealthという2つのデータフィールドがあります。

2つの`Potions`を組み合わせるときは、それぞれのフィールドを足し合わせます。

```rust
struct Potion {
    health: felt252,
    mana: felt252,
}

impl PotionAdd of Add<Potion> {
    fn add(lhs: Potion, rhs: Potion) -> Potion {
        Potion { health: lhs.health + rhs.health, mana: lhs.mana + rhs.mana }
    }
}

fn main() {
    let health_potion: Potion = Potion { health: 100, mana: 0 };
    let mana_potion: Potion = Potion { health: 0, mana: 100 };
    let super_potion: Potion = health_potion + mana_potion;
    // Both potions were combined with the `+` operator.
    assert(super_potion.health == 100, '');
    assert(super_potion.mana == 100, '');
}
```

上のコードでは、`Potion`型に対して`Add`トレイトを実装しています。

add関数は、`lhs`と`rhs`という2つの引数を受け取ります（左辺と右辺です）。

関数本体は新しい`Potion`インスタンスを返し、そのフィールドの値は`lhs`と`rhs`を組み合わせたものになります。

例で示したように、演算子をオーバーロードするには、オーバーロードする具体的な型を指定する必要があります。

オーバーロードするジェネリックトレイトは`Add<T>`で、`Potion`型に対しては`Add<Potion>`で具体的な実装を定義します。
