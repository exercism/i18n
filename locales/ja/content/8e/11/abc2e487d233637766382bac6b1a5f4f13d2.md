# はじめに

Swiftには、ループの通常の制御フローを変えるために使える文がいくつかあります。これらは制御転送文と呼ばれます。`return`はすでに見てきましたが、この概念ではそれ以外の`continue`、`break`、ラベルを紹介します。

## `continue`

ループの現在の繰り返しで残りの文をすべて実行せず、早めに次の繰り返しへ進みたいことがあります。そんなときは`continue`キーワードを使います。`continue`が実行されると、ループは次の繰り返しを実行できるかどうかのチェックへ移ります。つまり、`while`ループと`repeat-while`ループでは`while`の条件、`for-in`ループではシーケンスに次の要素があるかどうかのチェックです。

```swift
count = 1
while count < 6 {
  count += 1
  if count == 4 { continue }
  print(count)
}

// prints:
// 2
// 3
// 5
```

## `break`

`break`は、ループを途中で抜けるために使います。`break`が実行されると、ループはすぐに終了し、プログラムはループの直後の文から続きます。

```swift
for fruit in ["banana", "grapes", "apple", "strawberry", "kiwi", "lemon"] {
  if !fruit.count.isMultiple(of: 2) { break }
  print(fruit)
}

// prints:
// banana
// grapes
```

## ラベル

ループが入れ子になっていると、`break`や`continue`を使って、それが使われているループを囲む外側のループを抜けたり、やり直したりしたいことがあります。こうした場合は、ラベルを使うことで、抜けるループややり直すループを指定できます。ループを始める`while`、`repeat`、`for`の前に、名前とコロンを置くと、そのループにラベルを付けられます。

このようにラベルを使うとどんな効果があるか、次のループで見てみましょう。

```swift
outerLoop: for fruit in ["banana", "grapes", "apple", "strawberry", "kiwi", "lemon"] {
  print("\n--- \(fruit) ---")
  for letter in fruit {
    guard letter != "n" else { break outerLoop }
    print(letter)
  }
}

// prints:
// --- banana ---
// b
// a
```

## `fallthrough`

`fallthrough`キーワードは、`switch`文で次のケースにそのまま移るために使います。つまり、次のケースの条件をチェックせずに、そのケース内のコードが実行されます。これにより、ケースに一致したあとに`switch`文を抜けるために`break`文を必要としない他のプログラミング言語と同じように、`switch`文が動作します。`fallthrough`について詳しくは、[Swift book][fallthrough]を参照してください。

```swift
let value = 1
switch value {
case 1:
  print("One")
  fallthrough
case 2:
  print("Two")
}

// prints:
// One
// Two
```
