# 指示の補足

## 実装

ロボットの名前が足りなくなることがあります。考えられる名前をすべて割り当ててしまったら、エラーを返す必要があります。

## ボーナステスト

`go test`が通るようになると、テストスイートの中に`TestCollisions`というテストがあることに気づくでしょう。このテストは、実行に長い時間がかかることがあるため、デフォルトではスキップされます。
このテストは、新しい名前を割り当てられなくなるまで、新しいロボットを作り続けます。

このテストを実行するには、次の行を削除してください。

```go
t.Skip("skipping test as it can take a long time to run if solution is sub-optimal.")
```

このテストに通るには、あるロボットの名前がそれまでに使われていないこと、そして名前を効率よく割り当てられることを確実にする必要があります。
