# 説明

この演習では、ラジコンカーをあれこれ動かしてみます。このラジコンカーは、お金をやっと貯めて買えるようになったものです。

車は満充電（100%）のバッテリーからスタートします。リモコンで車を走らせるたびに、車は20メートル進み、バッテリーを1%消費します。

このラジコンカーには、2つの情報を表示するおしゃれなLEDディスプレイが付いています。

- これまでに走った合計距離。表示は`"Driven <METERS> meters"`です。
- バッテリーの残量。表示は`"Battery at <PERCENTAGE>%"`です。

バッテリーが0%になると、もう車を走らせることはできず、バッテリーの表示は`"Battery empty"`になります。

課題は6つあり、どれもラジコンカーのインスタンスを扱います。

## 1. 新品のラジコンカーを買う

新品のラジコンカーのインスタンスを返す（_静的_）な`JedliksToyCar.buy()`メソッドを実装しましょう。

```java
JedliksToyCar car = JedliksToyCar.buy();
```

## 2. 走った距離を表示する

LEDディスプレイに表示される距離を返す`JedliksToyCar.distanceDisplay()`メソッドを実装しましょう。

```java
JedliksToyCar car = JedliksToyCar.buy();
car.distanceDisplay();
// => "Driven 0 meters"
```

## 3. バッテリーの残量を表示する

LEDディスプレイに表示されるバッテリーの残量を返す`JedliksToyCar.batteryDisplay()`メソッドを実装しましょう。

```java
JedliksToyCar car = JedliksToyCar.buy();
car.batteryDisplay();
// => "Battery at 100%"
```

## 4. 走行時に走行距離を更新する

走行したメートル数を更新する`JedliksToyCar.drive()`メソッドを実装しましょう。

```java
JedliksToyCar car = JedliksToyCar.buy();
car.drive();
car.drive();
car.distanceDisplay();
// => "Driven 40 meters"
```

## 5. 走行時にバッテリーの残量を更新する

バッテリーの残量を更新するように`JedliksToyCar.drive()`メソッドを更新しましょう。

```java
JedliksToyCar car = JedliksToyCar.buy();
car.drive();
car.drive();
car.batteryDisplay();
// => "Battery at 98%"
```

## 6. バッテリーが切れているときは走らせない

バッテリーが切れている（0%）ときは、走行距離を増やさず、バッテリーの残量も減らさないように`JedliksToyCar.drive()`メソッドを更新しましょう。

```java
JedliksToyCar car = JedliksToyCar.buy();

// Drain the battery
// ...

car.distanceDisplay();
// => "Driven 2000 meters"

car.batteryDisplay();
// => "Battery empty"
```
