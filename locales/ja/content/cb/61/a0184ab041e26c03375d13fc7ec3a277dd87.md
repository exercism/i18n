# はじめに

Pythonは、[動的型付けでありながら強い型付けも持つ][dynamic typing in python]プログラミング言語です。
[ダックタイピング][duck typing]と[漸進的型付け][gradual typing]の両方を、[型ヒント][type hints]によって取り入れています。
Pythonはコードの読みやすさを強く重視しており、（_Haskellと同様に_）関数やメソッド、クラスの定義を表すために[有意なインデント][significant indentation]を使います。

PythonはGuido van Rossumによって作られ、1991年に最初に公開されました。

命令型、宣言型（たとえば関数型）、オブジェクト指向といったプログラミングの_スタイル_はすべてサポートされていますが、その内部では**[Pythonのすべてはオブジェクトです][everythings an object]**。

これらの意味については、Pythonトラックの概念を進めていく中で、さらに詳しく掘り下げていきます。

この最初の概念（`basics`）では、Python言語の4つの主要な機能を紹介します。
1.  名前の代入（_変数と定数_）
2.  関数（_`def`キーワードと`return`キーワード_）
3.  コメント
4.  docstring

<br>

## 名前の代入（変数と定数）

プログラマーは、代入演算子`=`を使って、あらゆる型のオブジェクトに[_名前_][facts-and-myths-about-python-names]（_変数_とも呼ばれます）を結びつけることができます：`<name> = <value>`。
名前は、その存在する間、別の値（別のオブジェクト型）に再代入（再バインド）できます。


```python
>>> my_first_variable = 1  # <--my_first_variable bound to an integer object of value one.
>>> my_first_variable = 2  # <--my_first_variable re-assigned to integer value 2.

>>> print(type(my_first_variable))
<class 'int'>

>>> print(my_first_variable)
2

>>> my_first_variable = "Now, I'm a string." # <--You may re-bind a name to a different object type and value.
>>> print(type(my_first_variable))
<class 'str'>

>>> my_first_variable = 'You can call me "str".' # <--Strings can be declared using single or double quote marks.
>>> print(my_first_variable)
You can call me "str".
```


### 定数

定数とは、プログラム内で一度だけ代入されることを意図した名前です。ただし、Pythonが再代入を防いでくれるわけではありません。
`SCREAMING_SNAKE_CASE`を使うと、コードを読む人に、その名前を再代入したり値を変更したりすべきでは**ない**ことを示せます。
定数は[モジュール][module]（ファイル）のレベルで定義するのがよく、通常はプログラム内のすべての関数やクラスから参照できます。



## 関数

`def`キーワードで[関数定義][function definition]を始めます。
各関数は、`()`括弧の中に0個以上の[仮引数][parameters]を置くことができ、そのあとに`:`コロンが続きます。
関数の_本体_となる文は、`def`の次の行から始まり、_ブロックとしてインデント_する必要があります。


```python
# The body of this function is indented by 2 spaces & prints the sum of the numbers.
def add_two_numbers(number_one, number_two):
  total = number_one + number_two
  print(total)  

>>> add_two_numbers(3, 4)
7


# Inconsistent indentation in your code blocks will raise an error.
>>> def add_three_numbers_misformatted(number_one, number_two, number_three):
...     result = number_one + number_two + number_three   # This was indented by 4 spaces.
...    print(result)     # <--This was only indented by 3 spaces.
...
...
  File "<stdin>", line 3
    print(result)
    ^
IndentationError: unindent does not match any outer indentation level
```


関数は、[`return`][return]キーワードを使って、値やオブジェクトを_明示的に_返します。


```python
# Function definition on first line, explicit return used on final line.
def add_two_numbers(number_one, number_two):
  return number_one + number_two   


# Calling the function in the Python shell returns the sum of the numbers.
>>> add_two_numbers(3, 4)
7

# Assigning the function call to a variable and printing 
# the variable will also return the value.
>>> sum_with_return = add_two_numbers(5, 6)
>>> print(sum_with_return)
11
```


`return`のあとに_明示的な_式がない関数は、_暗黙的に_[`None`][none]オブジェクトを返します。
`None`の詳細は、あとの概念で扱います。
この演習と説明では、`None`は、何もないこと、つまりnullを表すプレースホルダーです。


```python
# This function will return `None`
def square_a_number(number):
    square = number * number
    return # <-- note that this return is not followed by an expression

# Calling the function in the Python shell appears 
# to not return anything at all.
>>> square_a_number(2)
>>>


# Using print() with the function call shows that 
# the function is actually returning the **None** object.
>>> print(square_a_number(2))
None
```

`return`を省略した関数も、_暗黙的に_[`None`][none]オブジェクトを返します。
つまり、関数の中で`return`を使わない場合、Pythonが代わりに`None`オブジェクトを返します。

```python
# This function omits a return keyword altogether.
def add_two_numbers(number_one, number_two):
  result = number_one + number_two

>>> add_two_numbers(5, 7)
>>> print(add_two_numbers(5, 7))
None

# Assigning the function call to a variable and printing 
# the variable will also show None.
>>> sum_without_return = add_two_numbers(5, 6)
>>> print(sum_without_return)
None
```


## コメント

Pythonの[コメント][comments]は、文字列の一部ではない`#`で始まり、行の終わりで終わります。
他の多くのプログラミング言語と違い、Pythonは複数行コメントの記号を**サポートしていません**。
コメントブロックの各行は、`#`で始める必要があります。


## docstring

関数の本体の最初の文は、任意で[_docstring_][docstring]にすることができます。docstringは、関数やオブジェクトの目的を簡潔にまとめたものです。
docstringは[Sphinx][sphinx]のような自動ドキュメントツールに読み込まれ、関数やメソッド、クラス名に対して特別な属性`.__doc__`を呼び出すと返されます。
docstringの一般的な規約は[PEP257][pep257]にまとめられていますが、正確な形式はプロジェクトやチームによって異なります。
docstringは、コードブロックと同じレベルにインデントした三連の二重引用符（"""）を使って宣言します。

    """Form a complex number.

        imag (float): The imaginary part of the number (default 0.0)
