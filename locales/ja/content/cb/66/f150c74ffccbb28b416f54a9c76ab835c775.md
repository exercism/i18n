# 説明

この演習では、銀行の業務で使う定数をいくつか定義します。

タスクは5つあります。

## 1. ローンの固定金利を表す

5%（5/100）の値を保持する型なし数値定数`FixedInterestRate`を作成し、その値を返す`GetFixedInterestRate`関数を実装します。

```go
GetFixedInterestRate()
// => 0.05
```

## 2. 1年の日数を表す

値365を保持する`int`型の定数`DaysPerYear`を作成し、その値を返す`GetDaysPerYear`関数を実装します。

```go
GetDaysPerYear()
// => 365
```

## 3. 1年の月を表す

ブロックの中でGoの列挙機能を使い、1年12か月分の値1から12を保持する12個の型なし数値定数を作成します。
それぞれ`Jan`、`Feb`、`Mar`などと名付け、指定した月の値を返す`GetMonth`関数を実装します。

```go
GetMonth(Jan)
// => 1
```

## 4. 口座番号を表す

値XF348IJを保持する型なし文字列定数`AccountNo`を作成し、その値を返す`GetAccountNumber`関数を実装します。

```go
GetAccountNumber()
// => "XF348IJ"
```
