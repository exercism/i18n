# 説明

チェスの愛好家なら、自分だけのチェスを作ってみたいはずです。確かに、オンラインにはすでにたくさんのチェスの実装があるかもしれませんが、自分で作るものは唯一無二です！

まずはチェスボードの実装から始めましょう。

チェスは、縦8マス、横8マスのボードの上で行われます。マスは、文字と数字の組み合わせで識別します。

## 1. ランクとファイルの範囲を定義する

ゲームでは、ボードのランクを保存する必要があります。ランクはボードの行にあたり、1から8までの番号が付いています。

ゲームでは、ボードのファイルも保存する必要があります。ファイルはボードの列にあたり、AからHまでの文字で識別します。

ランクとファイルの範囲をそれぞれ保存する`ranks`定数と`files`定数を定義します。

```swift
ranks
// Returns 1..8

files
// Returns "A".."H"
```

## 2. マスが有効かどうかを確認する

ゲームでは、マスが有効かどうかを確認する必要があります。ランクとファイルが、それぞれランクとファイルの範囲内にあれば、そのマスは有効です。

`isValidSquare(rank:file:)`メソッドを定義します。このメソッドは、ランクを表す`Int`を保持する`rank`引数と、ファイルを表す`String`を保持する`file`引数を受け取ります。
ランクとファイルがランクとファイルの範囲内にあれば`true`を返し、そうでなければ`false`を返します。

```swift
isValidSquare(rank: 1, file: "A")
// Returns true
```

## 3. 行を取得する

ゲームでは、ボードのすべてのマスを1次元の配列に保存します。
マスは、ランクとファイルを組み合わせた文字列として表します。たとえば"1A"や"8B"、"4G"などです。
あるマスの行を取得するには、その行の最初のマスのインデックスを計算する必要があります。

`getRow(rank:)`メソッドを定義します。このメソッドは、ランクを表す`Int`を保持する`rank`引数を受け取ります。
その行のマスを表す文字列の配列を返します。

```swift
let board = ["1A", "1B", "1C", "1D", "1E", "1F", "1G", "1H", "2A", ..., "8H"]
getRow(board, rank: 1)
// Returns ["1A", "1B", "1C", "1D", "1E", "1F", "1G", "1H"]
```
