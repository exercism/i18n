# はじめに

Juliaの`String`は、順序づけられた文字の並びです。マニュアルにもあるとおり、「もちろん、本当に厄介なのは、文字とは何かと問い始めたときです」と述べられています。

この複雑さの多くは、`Chars` Conceptでより詳しく扱いますが、手短に言うと次のとおりです。

- Juliaの文字列はすべてUnicodeです。
- たまたまASCIIでもある文字列（AからZの英字の大文字と小文字、数字、いくつかの句読点）は、_扱いが簡単_です。
- 世界のほかのほとんどの文字体系も、_扱うことは可能_ですが、より慎重な対応が必要です。

## 文字列リテラル

一般的に、文字列は二重引用符`" "`で囲みます。
単一引用符`' '`は`Chars`にのみ使います。

三重の二重引用符`""" """`を使うこともできます。これを使うと、文字列の中の`"`をエスケープせずに書けます。
さらに重要なのは、複数行の文字列から余分なインデントが取り除かれることです。

```julia-repl
julia> """
       Multiline
       String
       """
"Multiline\nString\n"
```

### 文字のエスケープ

C以降のほとんどの言語と同じように、Juliaはエスケープにバックスラッシュ`\`を使います。

1. 前の例の改行`\n`のように、表示されない文字を入力するためです。
2. そうしなければ特別な意味を持ってしまう文字を保護するためです（例えば`\$`。後述します）。

## インデックス

原理的には、文字列はベクトルとまったく同じようにインデックスできます。

```julia-repl
julia> s[1], s[5]
('J', 'a')
```

これは"Julia"のようなASCII文字列には明らかにうまく働きますが、それでは世界のほとんどの言語を無視してしまいます。

約15世紀前に古英語で書かれた『ベオウルフ』に出てくる文字を1つ見てみましょう。

"Hrōðgār"は明らかに7文字ですが、そのすべてがASCIIというわけではありません。

```julia-repl
julia> king = "Hrōðgār"
"Hrōðgār"

julia> length(king)
7

julia> isascii(king)
false

# collect() converts to a Char vector:
julia> collect(king)
7-element Vector{Char}:
 'H': ASCII/Unicode U+0048 (category Lu: Letter, uppercase)
 'r': ASCII/Unicode U+0072 (category Ll: Letter, lowercase)
 'ō': Unicode U+014D (category Ll: Letter, lowercase)
 'ð': Unicode U+00F0 (category Ll: Letter, lowercase)
 'g': ASCII/Unicode U+0067 (category Ll: Letter, lowercase)
 'ā': Unicode U+0101 (category Ll: Letter, lowercase)
 'r': ASCII/Unicode U+0072 (category Ll: Letter, lowercase)
```

このような文字列へのインデックスは、最初はうまくいきますが、途中で破綻します。

```julia-repl
julia> king[3]
'ō': Unicode U+014D (category Ll: Letter, lowercase)

julia> king[4]
ERROR: StringIndexError: invalid index [4], valid nearby indices [3]=>'ō', [5]=>'ð'
```

問題は、このようなインデックスが_バイト_を数えていることです。非ASCIIの文字列では、バイトと文字は1対1の関係にはありません。
Unicode/UTF-8の文字は、表すのに最大4バイト必要なことがあります。これについては`Chars` Conceptでさらに詳しく見ていきます。

## 文字列を組み立てる

### 連結

多くの言語では文字列の連結演算子として`+`を使いますが、Juliaは違います。
せめてエラーメッセージだけは親切です。

```julia-repl
julia> "s1 " + "s2"
ERROR: MethodError: no method matching +(::String, ::String)
The function `+` exists, but no method is defined for this combination of argument types.
String concatenation is performed with * 

julia> "s1 " * "s2"
"s1 s2"
```

`string()`関数は、任意の数の文字列を連結します。

```julia-repl
julia> string("lots ", "of ", "bits")
"lots of bits"
```

`join()`関数も同じことができます。さらに、文字列のベクトルを受け取り、指定した区切り文字で連結します（デフォルトは`""`）。

```julia-repl
julia> join(["lots", "of", "bits"], "_")
"lots_of_bits"
```

文字列はイミュータブルで、連結にはコピーが伴うことに注意してください。
そのため、ループの中で連結を繰り返すのは効率が悪く、断片をベクトルに集めて最後にまとめて連結するほうがよいです。

### 繰り返し

簡単です。

```julia-repl
julia> repeat("Abc", 5)
"AbcAbcAbcAbcAbc"
```

### 文字列補間

多くの言語には、計算した値を文字列に埋め込む方法がありますが、その最適な構文については驚くほど意見が分かれています。

Juliaでは、補間する値の前に`$`を付けます。

```julia-repl
julia> myvar = 42
42

julia> "myvar evaluates to $myvar"
"myvar evaluates to 42"

julia> r = 5.3
5.3

julia> "A circle of radius $r has area $(π * r^2)"
"A circle of radius 5.3 has area 88.24733763933729"
```

省略すると曖昧になる場合は括弧（`()`）が必要ですが、空白が続く単一の識別子なら省略できます。

文字列に$を含めるには、`\$`のようにエスケープします。

現時点では、補間で表示する小数点以下の桁数などの書式指定ができないという制限があることに注意してください。

### `@sprintf()`

文字列の組み立てをより細かく制御するために、JuliaはCの`sprintf`関数をそのまま取り入れています（後発の言語の多くも同様です。Wikipediaには約30の言語が挙げられています）。

Juliaでは、これは`Printf`モジュール内の`macro`として実装されているため、`@`が付きます。

```julia-repl
julia> using Printf

julia> r = 5.3
5.3

julia> @sprintf("A circle of radius %.1f has area %.2f", r, π * r^2)
"A circle of radius 5.3 has area 88.25"
```

## 文字列の関数

話を簡単にするため、このセクションでは、新しい文字列を返し、入力は変更しない関数に絞ります。
その多くには、`!`を付けた名前の同等の関数があり、入力そのものを変更します。

### 長さ

文字列の長さはどれくらいでしょうか？　数え方によって変わることがあります。

単純なのはASCII文字列の場合で、どの文字も1バイトを占めます。

```julia-repl
julia> string_asc = "Julia"
"Julia"

julia> length(string_asc)
5

julia> sizeof(string_asc)
5
```

`length()`関数は_文字_の数を返し、`sizeof()`関数は_バイト_数を返します。

この違いは、他の文字セットを扱うときに重要になります。

```julia-repl
julia> king = "Hrōðgār"
"Hrōðgār"

julia> length(king)
7

julia> sizeof(king)
10
```

### 分割

プログラミングでよくある操作は、長い文字列を、1文字以上の区切り文字列をもとに、いくつかの部分に分割することです。

もっとも一般的には、`split()`関数を使います。区切り文字のデフォルトは（任意の）空白ですが、別のものを指定することもできます。

```julia-repl
julia> split("my little string")
3-element Vector{SubString{String}}:
 "my"
 "little"
 "string"

julia> split("My_snake_case_string", "_")
4-element Vector{SubString{String}}:
 "My"
 "snake"
 "case"
 "string"
```

これらの例は、文字列をより小さな_文字列_に分割しています。文字列を_文字_に分割するのは別の操作です。

### 検索と置換

文字列に指定した部分文字列が含まれているかどうかを調べるには、奇妙なことに2つの関数があります。`occursin()`と`contains()`で、違いは引数の順序だけです。

```julia-repl
julia> needle = "Julia"
"Julia"

julia> haystack = "Python, Julia and R"
"Python, Julia and R"

julia> occursin(needle, haystack)
true

julia> contains(haystack, needle)
true
```

位置をより具体的に指定するには、次のようにします。

```julia-repl
julia> startswith(haystack, "Python")
true

julia> endswith(haystack, "Python")
false
```

部分文字列の開始:終了のインデックスを取得するには、いくつかの関数があります。

- `findfirst()`
- `findlast()`
- `findprev()`
- `findnext()`

```julia-repl
julia> findfirst(needle, haystack)
9:13
```

部分文字列を置換するには、`x => y`構文で変更を並べます。

```julia-repl
julia> replace("abc", "a"=>"b", "b"=>"c", "c"=>"a")
"bca"
```

Julia 1.7以降、`replace`関数は任意の数の変更を受け取れます。置換の間に、どの文字も2回以上変更されないことが保証されています。

`x => y`構文は`pair`と呼ばれ、Juliaで重要な型です。詳しくは`Dicts and Pairs` Conceptで扱います。

### 空白

文字列の先頭や末尾の空白を取り除きたいことはよくあります。

そのための関数は`lstrip()`（左）、`rstrip()`（右）、`strip()`（両方）です。

```julia-repl
julia> strip("\n\t  useful_bit\n\n")
"useful_bit"
```

### 大文字と小文字の変換

これらの関数の名前は、ほぼ見たままです。

```julia-repl
julia> s = repeat("aBcD ", 5)
"aBcD aBcD aBcD aBcD aBcD "

julia> uppercase(s)
"ABCD ABCD ABCD ABCD ABCD "

julia> lowercase(s)
"abcd abcd abcd abcd abcd "

julia> titlecase(s)  # Initial letter of each word uppercase
"Abcd Abcd Abcd Abcd Abcd "
```
