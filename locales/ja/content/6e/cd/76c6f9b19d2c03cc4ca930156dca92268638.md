# はじめに

条件によって処理を分岐するコードを書きたいことはよくあります。Elixirでこれを実現する方法はたくさんありますが、もっとも簡単な方法のひとつは`cond/1`を使うことです。

`cond`は、もっとも単純な形では、1つ以上の分岐のうち、最初に`true`と評価された分岐をたどります。

```elixir
cond do
  x > 10 -> :this_might_be_the_way
  y < 7 -> :or_that_might_be_the_way
  true -> :this_is_the_default_way
end
```

どの分岐も`true`と評価されない場合、ランタイムがエラーを発生させます。
