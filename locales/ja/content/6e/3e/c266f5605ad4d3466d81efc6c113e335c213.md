# インストール

## インストール

[Pharo](http://pharo.org)をインストールするもっとも簡単な方法は、ターミナルのコマンドラインから[zero conf](http://pharo.org/download#//*[@id="main"]/div/h2[3])ダウンロードを使うことです。
<br/>_注意：すでにインストールされているものをアップグレードしようとしている場合は、[アップグレード手順](https://github.com/exercism/pharo-smalltalk/blob/main/docs/UPGRADE.md)を参照してください。_

UNIX系のシェルがインストールされていないWindowsユーザーは、下記の[Windowsへのインストール](#windows-installation-skip-for-osxlinux)の手順に進んでください。<br/>
Linuxに詳しい方は、[Linuxハッカー向けインストール](https://github.com/exercism/pharo-smalltalk/blob/main/docs/LINUX.md)を参照するとよいでしょう。

### Linux/OSXへのインストール

Linux/OSXの場合（[Exercismをインストール](https://exercism.io/getting-started)し、[Pharoトラック](https://exercism.io/my/tracks/pharo-smalltalk)に参加していることを前提とします）、`/Exercism/pharo-smalltalk`ディレクトリに移動して、次のように入力します。

```bash
curl https://get.pharo.org/64/ | bash
```

そして、次の「ロードスクリプト」を貼り付けて、Exercismのツールを組み込んだPharoを起動します。

```smalltalk
./pharo-ui Pharo.image eval "
Iceberg remoteTypeSelector: #httpsUrl.
Metacello new
 baseline: 'Exercism';
 repository: 'github://exercism/pharo-smalltalk:main/releases/latest';
 load.
#ExercismManager asClass welcome.
"
```

ツールの読み込み中にTIMEOUTの問題が起きた場合は、Pharoを終了し、次のように入力してgitキャッシュをクリアしてください。

```rm -rf pharo-local/iceberg/```

その後、上記の```./pharo-ui ...```の例をもう一度実行します。

それでも問題が解決しない場合は、[Pharo Community](http://pharo.org/community)ページで紹介されているPharo Discordチャンネルにアクセスしてください。

すべてが正しく動作していれば、画面いっぱいに読み込みのプログレスバーが点滅し、その後System Browserウィンドウが表示されます。

**ヒント：** Pharoを終了するときは、変更を保存してください（Pharoメニューを開き、「Save and Quit」を選択します）。
これで、次のように入力するだけで、Exercismが読み込まれた状態のPharoを起動できます。

```bash
./pharo-ui Pharo.image
```

### Windowsへのインストール（OSX/Linuxの場合は飛ばしてください）

Windows向けのコマンドラインツールの前提条件については、まだ最適な方法を検討中です。ただし、[Windows Pharo Launcher](https://files.pharo.org/pharo-launcher/windows)（複数のPharoイメージを管理するのに便利なツール）を使えば、グラフィカルにPharoをインストールすることもできます。このランチャーは、GUIのほうが好みであれば、OSXやLinuxでも[利用できます](http://pharo.org/download)。

1. ダウンロードした.msiファイルを実行して、Pharo Launcherをインストールします。  
2. Pharo Launcherを起動します。  
3. 左上隅にある「New」をクリックします。 
4. ウィンドウ内のテンプレートカテゴリから「Official distributions」を選択します。  
5. Exercismの演習には、Pharoイメージテンプレートの一覧から最新の安定版リリースを選びます（現在は「Pharo 10.0 64-bit (stable)」が推奨されています）。 
6. イメージテンプレートをクリックして選択し、名前を付けてから、下部にあるイメージ作成ボタン（オレンジ色の歯車の形）をクリックします。  
![ランチャーからイメージを作成](https://github.com/exercism/pharo-smalltalk/raw/main/docs/images/Create-image-from-launcher.png)
7. テンプレートのダウンロードが完了すると、右側のExisting Imagesテーブルに表示されます。それをクリックし、次に上部にある起動ボタン（緑色の_再生_矢印）をクリックします。  
![イメージを起動](https://github.com/exercism/pharo-smalltalk/raw/main/docs/images/Launch-image.png)


8. Pharoイメージが起動したら、_Browse_メニューから_Playground_を選んでPlaygroundを開きます。または`ctrl + o + w`を使います。  
![Playgroundを開く](https://github.com/exercism/pharo-smalltalk/raw/main/docs/images/Open-Playground.png)


9. 最後に、次のスニペットをPlaygroundにコピー＆ペーストします。
```smalltalk
Iceberg remoteTypeSelector: #httpsUrl.
Metacello new
 baseline: 'Exercism';
 repository: 'github://exercism/pharo-smalltalk:main/releases/latest';
 load.
#ExercismManager asClass welcome.
```

次に、貼り付けたコードをすべて選択し、右クリックしてメニューから_Do it_を選んで評価します（または`ctrl + d`を使います）。

**すべてが正しく動作していれば**、画面いっぱいに読み込みのプログレスバーが点滅し、その後System Browserウィンドウが表示されます。


## はじめに（すべての環境）

Pharoを起動すると、[System Browser](https://medium.com/@richardeng/pharo-quick-start-5bab70944ce2#3099)にWelcomeプロジェクトが表示されます（_ヒント：_ このウィンドウを閉じてしまった場合は、Tools|System Browserメニューから新しいウィンドウを開けます）。


![Pharoのウェルカム画面](https://github.com/exercism/pharo-smalltalk/raw/main/docs/images/PharoWelcomeScreen.png)

System Browserの左上のパネルには、環境内のパッケージが表示されます。インストールスクリプトによって`Exercism`というパッケージがすでに設定されており、その中に`Welcome`というサブプロジェクトタグが含まれていることがわかるでしょう。2つ目のパネルにはクラスが表示され、ここにも`Welcome`というクラスがあります。クラスのパネルの下には4つのラジオボタンがあります。「Flat」（パッケージ内のクラスを表示）、「Hier.」（クラス階層を表示）、「Inst. side」（インスタンスメソッドを表示）、「Class side」（クラスメソッド／コンストラクターを表示）です。

Commentタブをクリックすると、Pharo Exercismを使うための最新の手順が表示されます。コメントを読んで、最初のテストを実行してみましょう。

ファイルベースの言語であれば、この時点で通常ターミナルに切り替えて、Exercism CLIを使って次の演習を取得します。Pharoも同じようにファイルを扱えますが、この環境はむしろ生きたオブジェクトを扱うように作られています。面白いことに、クラスもメソッドもソースコードも、Pharoにある他のすべてと同じようにオブジェクトです。このことは、このトラックを進めていく中で詳しくわかってきます。

## 演習の読み込み

Exercismでは、IDEの中からPharoの演習を取得して提出できるプラグインを用意しています。演習のパッケージ（ここでは左上のパネルにあるWelcomeパッケージ）を右クリックし、`Exercism | Fetch Exercise`メニュー項目を選ぶだけです。演習名（例：hello-world）の入力を求められるので、入力すると自動的に取得されます。

演習名は、[Pharoトラック](https://exercism.io/my/tracks/pharo)のページ（右端）にある各演習の説明で確認できます。*Download*の手順に、各演習のキーを含むCLI文字列が載っています。CLI手順の隣にあるコピーボタンを使って、その文字列全体を取得プロンプトに貼り付けることもできます（キーは自動的に抽出されます）。

有効な演習を入力すると、プラグインが該当するコードを取得してSystem Browserに表示し、[テストを使ったコーディング](tests.md)を始められる状態になります。

すべてのテストが通ったら、演習のパッケージで同じコンテキストメニューを使って解答を提出できます（パッケージタグを右クリックし、`Exercism | Submit Exercise...`を選択します）。

![Exercismの提出メニュー](https://github.com/exercism/pharo-smalltalk/raw/main/docs/images/SubmitExercise.png)

最後に、`Exercism | View Track Progress`メニューからExercismのウェブサイトを開くと、他にどんな演習がアンロックされたかを確認できます。また、自分の解答についての質問を投稿して、メンターに読んでもらうこともできます。

<br/>

**知っていましたか：** *Pharoを起動するとき、実際には実行イメージのスナップショットを復元しています。これはVMwareのOSイメージに似ています。これは強力な仕組みで、作業を途中で中断できます。デバッグ中であっても可能です。次にPharoを起動し直すと、復元されたデバッガーでコードのステップ実行の続きを進めたり、リファクタリングの続きを行ったりできます。*

## CLIトークンをリセットする方法

セキュリティ上の問題でCLIトークンをリセットする必要がある場合は、[Exercismの設定ページ](https://exercism.io/my/settings)にアクセスし、トークンをリセットするボタンを使ってください。リセットしたら、Playgroundで次のコードを評価して、Pharo Exercismの古いトークンをクリアする必要があります。

```smalltalk
ExercismHttpClient
    reset;
    promptForToken.
```
