# 説明

この演習では、地元のゲームセンターで一番人気のゲームのハイスコアを管理する仕組みを実装します。

実装する関数は5つあり、そのほとんどはハイスコアを保持するオブジェクトを操作することに関係しています。

## 1. 新しいハイスコアボードを作成する

ハイスコアボードの役割を果たす`dict`を返す関数`create_score_board`を作成します。
このオブジェクトのキーはプレイヤーの名前、値はそのスコアになります。
テストのために、オブジェクトに最初から1件のエントリーを直接含めておきます。
この最初のエントリーは、プレイヤー名を`"The Best Ever"`、スコアを`1_000_000`にします。

```gleam
create_score_board()
// returns an object with one initial entry
```

## 2. スコアボードにプレイヤーを追加する

ハイスコアボードにプレイヤーを追加するには、関数`add_player`を定義します。
これは3つの仮引数を受け取ります:

- 1つ目の仮引数は、既存のスコアボードの`dict`です。
- 2つ目の仮引数は、プレイヤーの名前を表す文字列です。
- 3つ目の仮引数は、スコアを表す整数です。

この関数は、新しいプレイヤーとスコアを追加した`dict`を返します。

## 3. スコアボードからプレイヤーを削除する

プレイヤーがゲームセンターのルールに違反した場合は、そのプレイヤーは手作業でハイスコアボードから削除されます。
2つの仮引数を取る`remove_player`を定義します:

- 1つ目の仮引数は、既存のスコアボードの`dict`です。
- 2つ目の仮引数は、プレイヤーの名前を表す文字列です。

この関数は、削除されたプレイヤーを除いた`dict`を返します。

そもそもそのプレイヤーがボードにいなかった場合は、ボードには何も起こらず、そのまま返します。

## 4. プレイヤーのスコアを増やす

プレイヤーがゲームセンターでもう一度ゲームを終えると、ボードの以前のスコアに一定のポイントが加算されます。
3つの仮引数を取る`update_score`を実装します:

- 1つ目の仮引数は、既存のスコアボードの`dict`です。
- 2つ目の仮引数は、スコアを増やしたいプレイヤーの名前です。
- 3つ目の仮引数は、記録されているハイスコアに**加算**したいスコアです。

この関数は、更新されたスコアを持つ`dict`を返します。

そもそもそのプレイヤーがボードにいなかった場合は、ボードには何も起こらず、そのまま返します。

## 5. 月曜日のボーナスポイントを適用する

ゲームセンターでは、月曜日には別のスコアボードを使っています。
その日の終わりに、そのボードに載っている各プレイヤーに100ポイントが追加されます。

スコアボードを受け取る関数`apply_monday_bonus`を実装します。
この関数は、そのボードに載っている各プレイヤーにボーナスポイントを加えた`dict`を返します。
