# はじめに

Common Lispでは、関数に省略可能な引数を持たせることができます。
これらは、ラムダリストの中でラムダリストキーワード`&optional`を使って指定します。
値を指定しなかった仮引数には、`nil`が束縛されます。
省略可能な仮引数が複数ある場合は、それらは順番に束縛されます。
省略可能な仮引数には、デフォルト値を指定できます。
最後に、省略可能な仮引数ごとにシンボルを指定できます。このシンボルには、関数の呼び出し側がその仮引数を渡したかどうかに応じて、真偽値が束縛されます（これを「supplied-pパラメーター」と呼びます）。

```lisp
(defun optional-parameters (&optional x (y 'default) (z nil z-supplied-p))
  (list x y (if z-supplied-p (list :z-was-supplied z)
                             (list :z-was-not-supplied z))))

(optional-parameters)          ; => (NIL DEFAULT (:Z-WAS-NOT-SUPPLIED NIL))
(optional-parameters 5 nil 10) ; => (5 NIL (:Z-WAS-SUPPLIED 10))
```
