# 説明

この演習では、エンジニアが識別子の名前をきれいにするのを手助けする、ユーティリティルーチンの一部を実装します。

6つのタスクを通して、1文字を変換する`transform`関数と、文字列を変換する`clean`関数を少しずつ作り上げていきます。

有効な識別子は、0個以上の英字、アンダースコア、ハイフン、疑問符、絵文字で構成されます。

`clean`関数に空文字列が渡された場合は、空文字列を返す必要があります。

## 1. ハイフンをアンダースコアに置き換える

`transform`関数を実装して、ハイフンをアンダースコアに置き換えます。

```fsharp
transform '-'  // => "_"
```

## 2. すべての空白を削除する

すべての空白文字を削除します。先頭と末尾の空白も含まれます。

```fsharp
transform ' '  // => ""
```

## 3. camelCaseをkebab-caseに変換する

`transform`関数を変更して、camelCaseをkebab-caseに変換します。

```fsharp
transform 'D'  // => "-d"
```

## 4. 数字である文字を省略する

`transform`関数を変更して、数字である文字をすべて省略します。

```fsharp
transform '7'  // => ""
```

## 5. ギリシャ文字の小文字を疑問符に置き換える

`transform`関数を変更して、'α'から'ω'までの範囲にあるギリシャ文字を置き換えます。

```fsharp
transform 'β' // => "?"
```

## 6. これらの操作を組み合わせて文字列を処理する

`clean`関数を実装して、これらの操作を文字列全体に適用します。

ルールに当てはまらない文字は、そのまま変更されずに通されます。

```fsharp
clean "  a2b Cd-ω😀  " //  => "ab-cd_?😀"
```

## 文字から文字列を組み立てる

このトピックは、シラバスの後半で詳しく扱います。

今のところ、[`String.collect`][string-collect]という[高階関数][higher-order-function]があることを知っておくと役に立つでしょう。これを使うと、自分で用意した関数を使って、`char`のコレクションを文字列に変換できます。

```fsharp
let transform ch = $"{ch}_"
String.collect transform "abc"  // =>  "a_b_c_"
```

[higher-order-function]: https://exercism.org/tracks/fsharp/concepts/higher-order-functions
[string-collect]: https://fsharp.github.io/fsharp-core-docs/reference/fsharp-core-stringmodule.html#collect
