# 指示

2つの配列が与えられたとき、1つ目の配列が2つ目の配列に含まれているか、2つ目の配列が1つ目の配列に含まれているか、2つの配列が互いに含まれ合っているか、それともどれにも当てはまらないかを判定します。

具体的には、配列Bの先頭から0個以上の要素を取り除き、末尾からも0個以上の要素を取り除いたときに、配列Aと完全に同じ配列が得られれば、配列Aは配列Bのサブリストです。

例：

 * A = [1, 2, 3], B = [1, 2, 3, 4, 5], AはBのサブリストです
 * A = [3, 4, 5], B = [1, 2, 3, 4, 5], AはBのサブリストです
 * A = [3, 4], B = [1, 2, 3, 4, 5], AはBのサブリストです
 * A = [1, 2, 3], B = [1, 2, 3], AはBと同じです
 * A = [1, 2, 3, 4, 5], B = [2, 3, 4], AはBのスーパーリストです
 * A = [1, 2, 4], B = [1, 2, 3, 4, 5], AはBのスーパーリストでもサブリストでもなく、同じでもありません
