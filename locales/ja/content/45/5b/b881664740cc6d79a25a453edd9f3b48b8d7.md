# 手順

この演習では、ログ行を処理します。

各ログ行は、`"[<LEVEL>]: <MESSAGE>"`という形式の文字列です。

ログレベルは次の3つです：

- `INFO`
- `WARNING`
- `ERROR`

タスクは3つあり、それぞれがログ行を受け取って、それを使って何かをするように求めています。

## 1. ログ行からメッセージを取得する

`message`関数を実装して、ログ行のメッセージを返すようにしましょう：

```clojure
(message "[ERROR]: Invalid operation")
;;=> "Invalid operation"
```

先頭や末尾にある空白は取り除きます：

```clojure
(message "[WARNING]:  Disk almost full\r\n")
;;=> "Disk almost full"
```

## 2. ログ行からログレベルを取得する

`log-level`関数を実装して、ログ行のログレベルを返すようにしましょう。ログレベルは小文字にして返します：

```clojure
(log-level "[ERROR]: Invalid operation")
;;=> "error"
```

## 3. ログ行を整形し直す

`reformat`関数を実装して、ログ行を整形し直しましょう。メッセージを先にして、そのあとにログレベルを括弧（`()`）で囲んで置きます：

```clojure
(reformat "[INFO]: Operation completed")
;;=> "Operation completed (info)"
```
