# ヒント

## 全般

- 構造体のアラインメントは、そのフィールドの中で_最大_のアラインメントです。
- 構造体のサイズは、そのアラインメントの倍数です。

## 1. 遠隔操作の車を作成する

- 構造体のアラインメントは、そのフィールドの中で_最大_のアラインメントです。
- 構造体のサイズは、そのアラインメントの倍数です。
- 配列のアラインメントは、その要素のアラインメントと同じです。
- 構造体の8バイトごとに個別に分類する必要があります。
- 整数と浮動小数点値が同じ8バイトを共有する場合、その8バイト全体が汎用レジスター（GPR）で渡されます。
- 浮動小数点値は、`equ`で定義するアセンブル時の定数にはできませんが、セクション`.rodata`の定数にはできます。
- `xmm`レジスターからGPRへ、ビット表現を変えずに生のバイトを移動するには、[movd][mov]命令または[movq][mov]命令を使えます。

## 2. 新しいトラックを作成する

- 構造体のアラインメントは、そのフィールドの中で_最大_のアラインメントです。
- 構造体のサイズは、そのアラインメントの倍数です。
- 構造体内の隣り合うフィールドをまとめてもそのアラインメントに収まらない場合は、パディングバイトが挿入されます。

## 3. レースイベントを作成する

- 構造体のアラインメントは、そのフィールドの中で_最大_のアラインメントです。
- 構造体のサイズは、そのアラインメントの倍数です。
- 16バイトまでの構造体は、レジスターで関数に渡されます。
- 16バイトを超える構造体は、通常メモリに置かれます。
- 関数がメモリ上の構造体を返すとき、その構造体を格納するメモリ位置のアドレスが、暗黙の最初の引数として`rdi`で渡されます。
- この場合、関数はこのアドレスを`rax`で返す必要があります。

## 4. 車をレースに登録する

- 構造体のアラインメントは、そのフィールドの中で_最大_のアラインメントです。
- 構造体のサイズは、そのアラインメントの倍数です。
- ポインターは8バイトを占め、それが指す型のサイズに関係なく、汎用レジスター（GPR）で渡されます。
- `cars`配列と走行中の車の数の両方を`race`で更新する必要があります。

## 5. トーナメントを作成する

- 構造体のアラインメントは、そのフィールドの中で_最大_のアラインメントです。
- 構造体のサイズは、そのアラインメントの倍数です。
- 16バイトを超える構造体は、通常メモリに置かれます。
- 関数がメモリ上の構造体を引数として受け取る場合、その構造体はスタックで渡されます。
- `races`配列とレースの数の両方を`tournament`で更新する必要があります。

[mov]: https://www.felixcloutier.com/x86/movd:movq
