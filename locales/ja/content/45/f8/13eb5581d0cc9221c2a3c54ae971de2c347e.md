# テスト

## セットアップ

必要な依存関係をインストールするには、[JavaScriptのセットアップ手順][docs-exercism-javascript]に沿って進めましょう。

## 必要なもの

演習の依存関係をインストールします：

```shell
corepack pnpm install
```

`corepack`が有効になっていないと警告する場合は、次のコマンドを実行して有効にできます：

```bash
corepack enable pnpm
```

## テストスイートをパスさせる

すべての演習には、提出する前に解答を検証するためのテストスイートが用意されています。
演習のディレクトリでコマンドプロンプトを開き、次のコマンドを実行すると、これらのテストを実行できます：

```bash
corepack pnpm test
```

テストスイートによっては、最初のテスト以外がすべてスキップされています。

1つのテストが通ったら、`xtest`を`test`に変えることで、次のテストを有効にできます。

## 独自のテストを書く

独自のテストを追加で書きたい場合は、新しいファイル`custom.spec.js`を作成し、解答と一緒にそのファイルを提出します：

```shell
exercism submit numbers.js custom.spec.js
```
