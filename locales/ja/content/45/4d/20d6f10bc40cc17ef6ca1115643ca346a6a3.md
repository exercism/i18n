# はじめに

Goでは、関数は第一級の値です。
つまり、他のすべての値と同じことができるということです。関数を変数に代入したり、他の関数に引数として渡したり、さらには関数から関数を戻り値として返したりできます。

以下の例では、`engGreeting`と`espGreeting`という2つの関数を作り、それらを変数`greeting`に代入しています。

```go
import "fmt"

func engGreeting(name string) string {
	return fmt.Sprintf("Hello %s, nice to meet you!", name)
}

func espGreeting(name string) string {
	return fmt.Sprintf("¡Hola %s, mucho gusto!", name)
}

greeting := engGreeting			// greeting is a variable of type func(string) string
fmt.Println(greeting("Alice"))	// Hello Alice, nice to meet you!

greeting = espGreeting
fmt.Println(greeting("Alice")) 	// ¡Hola Alice, mucho gusto!
```

関数値を使うと、関数にデータだけでなく振る舞いも渡せるようになります。
次の例では、`greetingFunc`仮引数を介して`dialog`関数に振る舞いを渡しています。

```go
func dialog(name string, greetingFunc func(string) string) {
	fmt.Println(greetingFunc(name))
	fmt.Println("I'm a dialog bot.")
}

func espGreeting(name string) string {
	return fmt.Sprintf("¡Hola %s, mucho gusto!", name)
}

greeting := espGreeting
dialog("Alice", greeting)
// Output:
// ¡Hola Alice, mucho gusto!
// I'm a dialog bot.
```

初期化されていない関数型の変数の値は`nil`です。
そのため、`nil`の関数値を呼び出すとパニックが発生します。

```go
var dutchGreeting func(string) string
dutchGreeting("Alice") // panic: call of nil function
```

関数値は`nil`と比較できます。
これは、不要なパニックを避けるのに役立ちます。

```go
var dutchGreeting func(string) string
if dutchGreeting != nil {
	dutchGreeting("Alice") // safe to call dutchGreeting
}
```

## 関数型

Goで関数値を使えるのは、関数型のおかげです。
関数型は、仮引数の型の並びと戻り値の型の並びが同じであるすべての関数の集合を表します。
関数型を基にして、ユーザー定義型を宣言することもできます。
たとえば、先ほどの例の`dialog`関数は、次のように書き換えられます。

```go
type greetingFunc func(string) string

func dialog(name string, f greetingFunc) {
	fmt.Println(f(name))
	fmt.Println("I'm a dialog bot.")
}
```

## 無名関数

第一級関数がサポートされていることで使える、もう一つの強力な道具が無名関数です。
無名関数は、使う場所で`func`キーワードのあとに名前を付けずに定義します。
このような関数は、それを囲む関数の変数にアクセスできます。

たとえば、次のとおりです。

```go
func fib() func() int {
	var n1, n2 int

	return func() int {
		if n1 == 0 && n2 == 0 {
			n1 = 1
		} else {
			n1, n2 = n2, n1 + n2
		}
		return n2
	}
}

next := fib()
for i := 0; i < N; i++ {
  fmt.Printf("F%d\t= %4d\n", i, next())
}
```

`fib`を呼び出すと、変数`n1`と`n2`が宣言され、呼び出されるたびにこれらの変数の値を変える無名関数が返されます。
その無名関数をN回呼び出すと、0から始まるフィボナッチ数列のN番目の数が返ります。内側の無名関数は、それを囲む`fib`関数のローカル変数（`n1`と`n2`）にアクセスできます。
これは、関数値に呼び出しの間の状態を保持させる、とてもよい方法です。
このとき、無名関数は変数`n1`と`n2`のクロージャであると言います。
[クロージャ][closure]はプログラミングで広く使われており、他の言語でもサポートされているのを見かけるかもしれません。

[closure]: https://en.wikipedia.org/wiki/Closure_(computer_programming)
