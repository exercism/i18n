# 概要

Elixirでは、列挙可能なデータ構造（配列や範囲など）からランダムな要素を選ぶには、[`Enum.random/1`][enum-random]を使います。この関数は要素を1つ選び、どの要素が選ばれる確率も同じです。範囲からランダムな値を1つ選ぶ処理は、範囲全体を走査することなく、定数時間で実行されます。

## ランダムな整数と文字

- ランダムな整数を選ぶ
  ```elixir
  Enum.random(1..10)
  # => 7
  ```
- ランダムな文字を文字列として選ぶ
  ```elixir
  <<Enum.random(?A..?Z)>>
  # => "K"
  ```
- ランダムな文字を文字リストとして選ぶ
  ```elixir
  [Enum.random(?A..?Z)]
  # => ~c"J"
  ```

列挙可能なデータ構造から複数の要素を選ぶには、[`Enum.take_random/2`][enum-take-random]を使います。列挙可能なデータ構造をランダムな順序に並べ替えるには、[`Enum.shuffle/1`][enum-shuffle]を使います。

## ランダムな小数

Elixirには、ランダムな小数を選ぶための独自の関数はありません。それを行うには、Erlangの[`rand`][erl-rand]モジュールを使う必要があります。これは、`Enum.random`が内部で使っているモジュールでもあります。

- ランダムな小数を選ぶ（0.0以上1.0未満）:

  ```elixir
  :rand.uniform()
  # => 0.275329955448815
  ```

- ランダムな小数を選ぶ（`a`以上`b`未満）:
  ```elixir
  a = 13
  b = 20
  :rand.uniform() * (b - a) + a
  # => 18.96815556890448
  ```

## 正規分布

上で紹介した関数はすべて、どの値も同じ確率で選ばれるように、ランダムな値を選びます。これを_一様分布_といいます。`rand`モジュールには、[正規分布][normal-distribution]に従ってランダムな小数を選ぶ[`normal/0`][erl-rand-normal-0]と[`normal/2`][erl-rand-normal-2]という関数もあります。

## シード

「ランダムな」値は、_疑似_乱数生成器によって生成されることを理解しておくことが大切です。PRNGは、_シード_と呼ばれる初期値を受け取ると、ランダムに見えるけれど実際にはまったくランダムではない数列を生成するアルゴリズムです。

このことは、デバッグのときに役立つかもしれません。[`:rand.seed/2`][rand-seed-2]を使ってシードをリセットすると、Erlangの（つまりElixirの）疑似乱数生成器に同じ数列を生成させることができます。1つ目の引数は特定のPRNGアルゴリズムで、2つ目の引数は3つの整数のタプル、つまりシードです。

```elixir
:rand.seed(:exsss, {1, 2, 3})
Enum.take_random(100..999, 3)
# => [680, 127, 622]

:rand.seed(:exsss, {1, 2, 3})
Enum.take_random(100..999, 3)
# => [680, 127, 622]
```

## 暗号

`Enum.random`やErlangの`rand`モジュールが返すランダムな値は、[暗号学的に安全][cryptographically-secure-rng]ではありません。暗号鍵、パスワード、ノンスの生成には使わないでください。この用途には、Erlangの[`:crypto.strong_rand_bytes/1`][erl-crypto-strong-rand-bytes]があります。
