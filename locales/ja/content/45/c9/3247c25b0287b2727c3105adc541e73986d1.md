# はじめに

## パッケージ

Goでは、アプリケーションはパッケージという単位で構成されます。
パッケージとは、同じフォルダーにあるソースファイルをまとめたものです。
1つのフォルダーにあるソースファイルは、すべてファイルの先頭で同じパッケージ名にする必要があります。
慣習として、パッケージ名はそれが置かれているフォルダーと同じ名前にします。

```go
package greeting
```

Goには、標準ライブラリとして多数のパッケージが用意されており、`import`キーワードを使うと自分のプログラムで利用できます。
標準ライブラリのパッケージは、その名前を使ってインポートします。

```go
package greeting

import "fmt"
```

インポートしたパッケージは、パッケージ名で参照します。

```go
world := "World"
fmt.Sprintf("Hello %s", world)
```

Goでは、ある要素を他のパッケージのコードから呼び出せるかどうかは、その宣言の仕方で決まります。
関数、型、変数、定数、構造体のフィールドを外部から見えるようにする（これを_エクスポート_と呼びます）には、名前を大文字で始める必要があります。

```go
package greeting

// Hello is a public function (callable from other packages).
func Hello(name string) string {
    return "Hello " + name
}

// hello is a private function (not callable from other packages).
func hello(name string) string {
    return "Hello " + name
}
```

## 文字列のフォーマット

Goには`fmt`という組み込みパッケージがあります（フォーマットパッケージ）。
入出力の書式を操作するための、さまざまな関数が用意されています。
最もよく使われるのは`Sprintf`で、`%s`のような動詞を使って値を文字列に埋め込み、その文字列を返します。

```go
import "fmt"

food := "taco"
fmt.Sprintf("Bring me a %s", food)
// Returns: Bring me a taco
```

Goでは、浮動小数点数の値はSprintfの動詞を使うと手軽にフォーマットできます。`%g`（コンパクトな表現）、`%e`（指数）、`%f`（指数なし）です。
3つの動詞はどれも、フィールドの幅と数値の位置を制御できます。

```go
import "fmt"

number := 4.3242
fmt.Sprintf("%.2f", number)
// Returns: 4.32
```

利用できる動詞の一覧は、[フォーマットパッケージのドキュメント][fmt-docs]にあります。

`fmt`には、文字列を扱う他の関数もあります。たとえば`Println`は受け取った引数をそのままコンソールに出力し、`Printf`は`Sprintf`と同じように入力をフォーマットしてから出力します。

[fmt-docs]: https://pkg.go.dev/fmt
