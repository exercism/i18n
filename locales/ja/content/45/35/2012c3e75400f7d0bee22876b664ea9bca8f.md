# 型宣言

PHPは_動的型付け_の言語です。つまり、変数にはどんな型の情報でも入れられます。
PHPでは、クラスのプロパティ、関数の引数、関数の戻り値に対して、_任意_の強い型宣言を使えます。
PHPの強い型宣言は、実行時に型のアサーションを行います。ただし、PHPは可能であれば、宣言に合わせてスカラー型を変換しようとします。
この変換の挙動は、ファイルの先頭で`strict_types`宣言を使うことで無効にできます。

```php
<?php
declare(strict_types=1);
```

さらに、関数の戻り値の型に`void`を指定して、その関数から値が返されないことを示すこともできます。

```php
<?php
declare(strict_types=1);

class Driver
{
    string $serial_number;

    function setSerialNumber(string $number): void
    {
        $this->serial_number = $number;
    }

    function getSerialNumber(): string
    {
        return $this->serial_number; 
    }
}

$driver = new Driver(); 
$driver->setSerialNumber(1234);
// => This will throw a TypeError with strict_types=1
```

## 共用型

関数の引数、戻り値、クラスのプロパティが複数の型を取りうる場合は、共用型を宣言できます。

```php
<?php

class IdentityCard
{
    private int|float $id = 0;

    public function assign(int|float $id): void
    {
        $this->id = intval($id);
    }
}

$card = new IdentityCard();
$card->assign(5.0);
```

## mixed型

コードを書いていく中で、型を指定できないことがあります。
PHP 8.0以降では、`mixed`という逃げ道となる型が用意されています。
mixedは、`object|resource|array|string|float|int|bool|null`の共用型と同等です。
