# はじめに

JavaScriptには、日付と時刻を保持し、それらを管理するためのメソッドを提供する組み込みオブジェクト`Date`があります。

<!-- prettier-ignore -->
~~~exercism/caution
これはJavaの`java.util.Date`クラスを基にしていました。このクラスは2010年代初頭に置き換えられましたが、後方互換性のために、JavaScriptの`Date`は残り続けています。

一般的にDateの扱いが難しいこと、そしてタイムゾーンの処理がお粗末か、まったく存在しないことから、`moment.js`、`day.js`、`date-fns`、`luxon`など、多くのライブラリが存在します。
ただし、Exercismではこれらのどれも利用できません。

自分のプロジェクトでは、`moment.js`のような非推奨・メンテナンスされていないパッケージは使わず、`luxon`のようなより現代的な代替や、まだ広く使われていない[Temporal][mdn-temporal]を利用しましょう。
この演習では`Date`に焦点を当てます。`Date`は、JavaScriptが存在し続ける限りずっと重要であり続けるでしょう。

## 生成

`Date`オブジェクトは`Date`クラスのインスタンスです。
コンストラクター関数に引数を渡さずに生成することもできます。
この場合、現在の日付と時刻を表す`Date`オブジェクトが生成されます。

```javascript
const now = new Date();
// => Thu Apr 14 2022 11:46:08 GMT+0530 (India Standard Time)
// Shows current day, date and time (in your time zone).
```

### Unixタイムスタンプ（数値）

数値を渡すと、それは`timestamp`として解釈されます。
タイムスタンプは、**1970年1月1日[UTC][defn-utc]+0**から経過した**ミリ秒**数を表す整数です。

```javascript
const epoch = new Date(0);
// Thu Jan 01 1970 01:00:00 GMT+0100 (Central European Standard Time)

const another = new Date(1749508766627);
// Tue Jun 10 2025 00:39:26 GMT+0200 (Central European Summer Time)
```

`new Date(0)`が「最も早い」日付オブジェクトを生成すると期待するかもしれませんが、JavaScriptはその日付をローカルのタイムゾーンに変換します。そのため、[GMT / UTC+0][defn-gmt]のタイムゾーンにいる人だけが、実際に[Unixエポック][defn-unix-epoch]の値を得ることになります。

### ISO 8601タイムスタンプ（文字列）

`Date`コンストラクターには、日付を表す文字列の値を渡すことができます。
実装間で一貫している**唯一**の形式は、国際的に認識され標準化されている、いわゆる[ISO 8601タイムスタンプ文字列][defn-iso8601]の[簡略版][mdn-date-string-format]です。

[UTC][defn-gmt]でのある時点は、次のように書きます。

```text
YYYY-MM-DDTHH:mm:ss.mssZ
YYYYMMDDTHHmmss.mssZ
```

ここでは、次の置き換えが行われます。

| キー | 説明                                               | デフォルト |
| ---- | -------------------------------------------------- | ---------- |
| YYYY | 暦年。4桁で表します                                |            |
| MM   | 暦月。2桁で表します                                | 01         |
| DD   | 暦日。2桁で表します                                | 01         |
| T    | 日付と時刻を区切るリテラルの文字T                  |            |
| HH   | 24時間制の時。2桁                                  | 00         |
| mm   | 分。2桁                                            | 00         |
| ss   | 秒。2桁                                            | 00         |
| mss  | ミリ秒。3桁                                        | 000        |
| Z    | リテラルの文字Z、またはオフセット`+/-HH:mm`        |            |

リテラルの文字`Z`はUTCを表します（タイムゾーンなし、夏時間なし）。

ほとんどの要素にはデフォルト値があるため、末尾の部分を省略しても有効です。

```text
YYYY-MM-DD
```

時刻はデフォルトで00:00:00.000になります。

タイムスタンプが`Z`で終わらず、`+HH:mm`や`-HH:mm`（タイムゾーンのオフセットを表します）でも終わらない場合、歴史的な理由から、次のことが当てはまります。

> タイムゾーンのオフセットがない場合、日付のみの形式はUTC時刻として、日付と時刻の形式はローカル時刻として解釈されます。
> UTC時刻として解釈されるのは、ISO 8601と一致していなかった歴史的な仕様の誤りによるもので、ウェブ互換性のために変更できませんでした。
> 詳しくは[Broken Parser – A Web Reality Issue][ref-broken-parser]を参照してください。

### Dateオブジェクト

既存のDateオブジェクトをコンストラクターの引数として使うこともできます。
これは、同じ日付と時刻を持つ既存の`Date`オブジェクトのコピーを作成します。

```javascript
const t1 = new Date();
const t2 = new Date(t1);
// Values of t1 and t2 will be the same.
```

### 日付と時刻の各要素の値を個別に指定する

日付を表す値は、3つの数値を渡して生成できます。
日付と時刻を表す値は、6つの数値を渡して生成できます。

```javascript
const date1 = new Date(95, 11, 17);
// Creates Date for Dec 17 1995 00:00 if your local timezone is equivalent to UTC.

const date2 = new Date(2013, 12, 5, 13, 24, 0);
// Creates Date for Jan 5 2014 13:24 if your local timezone is equivalent to UTC.
```

2番目の値は`month`で、1月が`0`、12月が`11`です。

## `Date.parse()`

日付を解析する関数`Date.parse`への言及や参照を見かけるかもしれません。
この関数にはごくわずかな不変条件（常に成り立つこと）しかなく、残りの実装は仕様化されていない（つまり標準ではない）ため、使うべきではありません。

## `Date`の要素にアクセスする

Dateオブジェクトには、日付の各要素を返すさまざまなメソッドがあります。

```javascript
getFullYear(); // Get the year (4 digits)
getMonth(); // Get the month, from 0 to 11.
getDate(); // Get the day of month, from 1 to 31.
getHours(); // Get the hour in a 24 clock, from 0 to 23
getMinutes(); // Get the minutes, from 0 to 59
getSeconds(); // Get the seconds, from 0 to 59
getMilliseconds(); // Get the milliseconds, from 0 and 999
getDay(); // Get the day of week, from 0 (Sunday) to 6 (Saturday).
```

これらのそれぞれには、値を更新するための対応する`set`系のメソッドがあります（例：`setFullYear`）。
あふれた値は、次の要素に繰り越されます。

```javascript
const date = new Date('2025-02-28T12:42:00Z');
// => Fri Feb 28 2025 13:42:00 GMT+0100 (Central European Standard Time)

date.setDate(29);
// there was no February 29th in 2025.

date.getDate();
// => 1

date.toString();
// => Sat Mar 01 2025 13:42:00 GMT+0100 (Central European Standard Time)
```

すべてのメソッドには、ローカルのタイムゾーンを無視するUTC版があります。

## 日付からの変換

Dateオブジェクトには、UNIXタイムスタンプをミリ秒で返す`getTime()`メソッドがあります。つまり、UTCでの1970年1月1日の始まりの午前0時からの経過ミリ秒数です。
さらに、DateオブジェクトをISO 8601タイムスタンプ文字列に変換する`toISOString()`メソッドも利用できます。

## Dateの比較

大なり（`>`）と以上（`>=`）、および小なり（`<`）と以下（`<=`）は、2つの日付の間、または日付と数値の間で直接使うことができます。
これは、JavaScriptが日付をプリミティブに変換しようとするために機能します。

<!-- prettier-ignore -->
~~~exercism/advanced
2つの日付の間、または日付と数値の間で比較を行うとき、JavaScriptは[`[Symbol.toPrimitive]("number")`][mdn-to-primitive]を呼び出し、その内部で[`date.valueOf()`][mdn-date-value-of]を呼び出します。
後者は[`date.getTime()`][mdn-date-get-time]を呼び出すのと同じです。

この挙動に頼りたくない場合は、まず`getTime()`を使って数値に変換しましょう。

[mdn-to-primitive]: https://developer.mozilla.org/en-US/docs/Web/JavaScript/Reference/Global_Objects/Date/Symbol.toPrimitive
[mdn-date-value-of]: https://developer.mozilla.org/en-US/docs/Web/JavaScript/Reference/Global_Objects/Date/valueOf
[mdn-date-get-time]: https://developer.mozilla.org/en-US/docs/Web/JavaScript/Reference/Global_Objects/Date/getTime
~~~

日付は等価演算子（`==`と`===`）で比較することはできませんが、`.getTime()`の結果なら比較できます。
