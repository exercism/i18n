# はじめに

Swiftには、ループの通常の制御フローを変えるために使える文がいくつかあります。これらは制御転送文と呼ばれます。`return`はすでに見ましたね。この概念では、`continue`、`break`、ラベルなど、その他のものを紹介します。この概念では`fallthrough`は扱いませんが、[Swiftの書籍][fallthrough]で読むことができます。

## continue

ループの現在の繰り返しにある残りの文を最後まで実行せずに、早めに次の繰り返しへ進みたいことがあります。そんなときは`continue`キーワードを使います。`continue`が実行されると、ループは次の確認へとジャンプします。つまり、`while`ループと`repeat-while`ループでは`while`の条件、`for-in`ループではシーケンスに次の要素があるかどうかの確認です。

```swift
count = 1
while count < 6 {
  count += 1
  if count == 4 { continue }
  print(count)
}

// prints:
// 2
// 3
// 5
```

## break

`break`はループを早めに抜けるために使います。`break`が実行されると、ループはすぐに終了し、プログラムはループの後にある最初の文から続けます。

```swift
for fruit in ["banana", "grapes", "apple", "strawberry", "kiwi", "lemon"] {
  if !fruit.count.isMultiple(of: 2) { break }
  print(fruit)
}

// prints:
// banana
// grapes
```

## ラベル

ループが入れ子になっているとき、`break`や`continue`を使ったループを囲む外側のループを抜けたり再開したりするために、`break`や`continue`を使いたいことがあります。こうした場合、ラベルを使って、抜けたり再開したりするループを指定できます。ループにラベルを付けるには、ループを始める`while`、`repeat`、`for`の前に、名前とコロンを書きます。

このようにラベルを使う効果を見るために、次のループを見てみましょう。

```swift
outerLoop: for fruit in ["banana", "grapes", "apple", "strawberry", "kiwi", "lemon"] {
  print("\n--- \(fruit) ---")
  for letter in fruit {
    guard letter != "n" else { break outerLoop }
    print(letter)
  }
}

// prints:
// --- banana ---
// b
// a
```
