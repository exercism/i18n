# 指示の補足

## 例外のカスタマイズと送出

コードの中で例外を[カスタマイズ](https://docs.python.org/3/tutorial/errors.html#user-defined-exceptions)したり、[`raise`](https://docs.python.org/3/tutorial/errors.html#raising-exceptions)したりする必要があることがあります。その際は、エラーの原因が何であるかを示す**意味のあるエラーメッセージ**を必ず含めるようにしましょう。これにより、コードが読みやすくなり、デバッグもぐっとはかどります。

カスタム例外は、新しい例外クラスを作ることで定義できます（詳しくは[`classes`](https://docs.python.org/3/tutorial/classes.html#tut-classes)を参照してください）。こうしたクラスは、通常は[`Exception`](https://docs.python.org/3/library/exceptions.html#Exception)のサブクラスです。

エラーの原因が特定の例外型から派生したものであると分かっている場合は、_Exception_クラスの下にある[`built in error types`](https://docs.python.org/3/library/exceptions.html#base-classes)のいずれかを継承することを選べます。エラーを送出するときも、意味のあるメッセージを含めるようにしましょう。

この演習では、スタックの中身が足りないときに[送出](https://docs.python.org/3/reference/simple_stmts.html#the-raise-statement)（"スロー"）される_カスタム例外_を作成する必要があります。テストに合格するには、適切な例外をカスタマイズし、その例外を`raise`し、適切なエラーメッセージを含める必要があります。


```python
# subclassing the Exception to create a StackUnderflowError
class StackUnderflowError(Exception):
    """Exception raised when Stack is not full.
       message: explanation of the error.
    """
    def __init__(self, message):
        self.message = message

        
# raising a StackUnderflowError
raise StackUnderflowError("Insufficient number of items in stack")
```

さらに、この演習では、エラーメッセージ付きでいくつかの`built-in exceptions`を送出する必要があります。
メッセージ付きで`built-in exception`を送出するには、そのメッセージを`exception`型の引数として書きます。

```python
# an example when division by zero is attempted.
raise ZeroDivisionError("divide by zero")

#an example when the operation is undefined.
raise ValueError("undefined operation")
```
