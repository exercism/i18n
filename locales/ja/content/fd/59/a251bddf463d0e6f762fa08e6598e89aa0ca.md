# 指示

この演習では、自動車工場の組み立てラインの生産を分析するコードを書きます。組み立てラインの速度は`0`（停止）から`10`（最大）まで設定できます。

最も低い速度（`1`）では、1時間に`221`台の車が生産されます。生産量は速度に比例して増えていきます。そのため、速度を`4`に設定すると、1時間に`4 * 221 = 884`台の車が生産されるはずです。ただし、速度が上がると故障した車が作られる可能性が高くなり、そうした車は廃棄しなければなりません。

3つのタスクがあります。

## 1. 成功率を計算する

`success_rate()`メソッドを実装して、指定された速度に対して、製品がエラーなく作られる割合を計算しましょう。次の表は、速度が成功率にどのように影響するかを示しています。

- `0`：成功率0%。
- `1`から`4`：成功率100%。
- `5`から`8`：成功率90%。
- `9`：成功率80%。
- `10`：成功率77%。

```R
success_rate(10)
# => 0.77
```

## 2. 1時間あたりの生産率を計算する

`production_rate_per_hour()`メソッドを実装して、成功率を考慮した組み立てラインの1時間あたりの生産率を計算しましょう。

```R
production_rate_per_hour(6)
# => 1193.4
```

返される値は`double`であることに注意してください。

## 3. 1分あたりに生産される良品の数を計算する

`working_items_per_minute()`メソッドを実装して、1分あたりに何台の良品が生産されるかを計算しましょう。

```R
working_items_per_minute(6)
# => 19
```

返される値は整数であることに注意してください。不完全な製品は含まれません。
