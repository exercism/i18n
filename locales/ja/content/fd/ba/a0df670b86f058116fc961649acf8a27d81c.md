# 手順

この演習では、ログ行を処理します。

各ログ行は、次の形式の文字列です：`"[<LEVEL>]: <MESSAGE>"`。

ログレベルは3つあります。

- `INFO`
- `WARNING`
- `ERROR`

タスクは3つあり、それぞれがログ行を受け取り、それを使って何をするかを求めます。

## 1. ログ行からメッセージを取得する

ログ行のメッセージを返す`message()`関数を実装しましょう。

```haxe
message("[ERROR]: Invalid operation")
// => "Invalid operation"
```

先頭と末尾の空白は取り除きます。

```haxe
message("[WARNING]:  Disk almost full\r\n")/ => "Disk almost full"
```

## 2. ログ行からログレベルを取得する

`logLevel()`関数を実装して、ログ行のログレベルを返すようにしましょう。ログレベルは小文字で返します。

```haxe
logLevel("[ERROR]: Invalid operation")
// => "error"
```

## 3. ログ行を整形し直す

`reformat()`関数を実装して、ログ行を整形し直しましょう。メッセージを先に置き、そのあとにログレベルを括弧（`()`）で囲んで置きます。

```haxe
reformat("[INFO]: Operation completed")
// => "Operation completed (info)"
```
