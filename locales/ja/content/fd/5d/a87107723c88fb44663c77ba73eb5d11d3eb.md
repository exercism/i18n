# はじめに

Factorへようこそ！　Factorは*連結型*の言語です。`square(add(2, 3))`のように関数を呼び出すのではなく、**ワード**を左から右へと並べて書きます（`2 3 + square`）。ワード同士は、共有された**データスタック**を通じて値を受け渡します。埠頭に積み上げられた貨物のクレートを思い浮かべてください。新しい荷物ほど上にあります。

## コメント

`!`で行コメントが始まります。Factorは`!`から行末までのすべてを無視します。以下の例では、コードが何をするのかを注記するために`!`を使っています。

## データスタック

リテラルを書くと、その値がスタックの一番上に積まれます。コードは左から右へ読まれます。

```factor
1 2 3    ! stack (bottom → top): 1 2 3
```

どのワードも、スタックの一番上から入力を受け取り、結果をそこへ書き戻します。`.`は一番上の値を取り出して表示します。`.s`は何も消費せずに、スタックの*全体*を表示します。これは、あるコード片が何を残したかを確認するのに便利です。

## スタック効果

どのワードも、`( inputs -- outputs )`という形式の**スタック効果**で記述されています。これはワードの契約です。ワードはスタックの一番上から入力を取り出し、その場所に結果を残します。中に書かれた名前は人間のための説明であり、スタックそのものは名前ではなく位置で扱われます。スタックの一番上は、*右端*の名前です。

## ワードの定義

`:`でワードの定義が始まり、次にスタック効果、続いて本体、最後に`;`で終わります。Factorのコンパイラーは、本体が本当にスタック効果で宣言したとおりの結果を残すかどうかを検査します。

```factor
: restow ( a b -- b a ) swap ;
```

## 並べ替えワード

これらの`kernel`のワードは、計算を一切せずにスタックの一番上を並べ替えます。クレートを動かすだけです。

```
dup  ( x   -- x x   )    ! copy the top crate
drop ( x   --       )    ! remove the top crate
swap ( x y -- y x   )    ! flip the top two
over ( x y -- x y x )    ! copy the second crate onto the top
nip  ( x y -- y     )    ! remove the second crate
rot  ( x y z -- y z x )  ! roll the third crate up to the top
```

1つのクレートを2つのワードに渡したいときは`dup`、クレートを捨てたいときは`drop`、一番上の2つが逆になっているときは`swap`、下にあるクレートを扱いたいときは`over`か`nip`、埋もれたクレートを一番上に持ち上げたいときは`rot`を使います。

より広い仲間（`-rot`、`dupd`、`swapd`、`2dup`など）も同じ考え方に従います。これらのワードには、このあと出会います。

## ワードの組み合わせ

並べて書かれたワードは**左から右へ**実行されます。それぞれのワードは、その前のワードが残したスタックに対して働きかけます。`swap nip`がスタック`1 2`（下→上）に対して、1ワードずつ何をするかを示します。

```factor
1 2     ! 1 2     the starting crates
swap    ! 2 1     swap flipped the top two
nip     ! 1       nip dropped the 2nd-from-top crate (the 2)
```

次に、同じ最初のクレートに対する`dup rot`を、これも1ワードずつ見てみます。

```factor
1 2     ! 1 2     the starting crates
dup     ! 1 2 2   dup copied the top crate
rot     ! 2 2 1   rot rolled the 3rd-from-top crate up to the top
```

## 命名規則

ワードには`lowercase-kebab-case`を使います。小文字をハイフンでつないだ形です。
