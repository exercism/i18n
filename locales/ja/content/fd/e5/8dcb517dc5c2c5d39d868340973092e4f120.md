# はじめに

Goでは、定数とは`const`キーワードで名前に割り当てられた、変化しない単純な値のことです。

```go
const myWebsite = "Exercism"
```

このような定数は型を持ちませんが、型が必要なとき、たとえばメソッドに渡すときには、構文に基づいてデフォルトの型が与えられます。
型を明示的に付けると、型付きの定数を作ることができます。

```go
const myWebsite string = "Exercism"
```

Goには、他の言語にあるような列挙型はありませんが、列挙定数を作るための`iota`という事前宣言された識別子があります。
ブロック内の定数は暗黙的に繰り返されます。

```go
const (
    a = 9
    b
    c
    d = iota
    e
    f
    g
)
fmt.Print(a, b, c, d, e, f, g)
// Output: 9 9 9 3 4 5 6
```
