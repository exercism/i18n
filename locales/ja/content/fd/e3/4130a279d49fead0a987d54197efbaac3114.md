# はじめに

Common Lispでグローバル関数を定義するには、`defun`式を使います。
この式は、最初の引数として仮引数のリストを取ります（空のリストなら、その関数は引数を取らないという意味です）。
続いて省略可能なドキュメンテーション文字列（後述します）を書き、そのあとに0個以上の式を書きます。この式たちが関数の「本体」になります。

関数は、0個以上の仮引数を持てます。

```lisp
(defun no-args () (+ 1 1))

(defun add-one (x) (1+ x))

(defun add-nums (x y) (+ x y))
```

関数を呼び出すには、その関数を表すシンボルを式の最初の要素にし、関数への引数（あれば）を残りの要素にした式を評価します。

関数が評価した結果の値は、関数の本体の中で最後に評価された式の値です。
すべての関数は、何らかの値に評価されます。

```lisp
(add-nums 2 2) ;; => 4
```

関数には、省略可能で、ドキュメンテーション文字列（docstringとも呼びます）を持たせることもできます。
書く場合は、引数リストのあと、関数の本体の前に置きます。
ドキュメンテーション文字列には、`documentation`でアクセスできます。

```lisp
(defun add-nums (x y) "Add X and Y together" (+ x y))

(documentation 'add-nums 'function) ;; => "Add X and Y together"

;; Note that if one provides a docstring but fails to provide a body
;; then the docstring is interpreted by Common Lisp as the body, not
;; the docstring
(defun no-body ())
(no-body) ;; => NIL

(defun mistake () "This is not a docstring")
(mistake) ;; => "This is not a docstring"
(documentation 'mistake 'function) ;; => NIL
```
