# はじめに

*ヒープ*は、常に自分の最小の要素を把握していて、それをすばやく取り出せるコレクションです。*優先度付きキュー*を実装するときの自然な選択肢になります。ヒープは[`heaps`][heaps]ボキャブラリーにあります。

`<min-heap>`は、最小のキーが最初に取り出される空のヒープを作ります。`<max-heap>`はその逆です。各要素は、*キー*に紐づけて格納される*値*で、そのキーが優先度になります。

```
<min-heap> ( -- min-heap )
heap-push  ( value key heap -- )
```

```factor
USING: heaps ;

<min-heap>
"alice" 5 pick heap-push
"bob"   2 pick heap-push
```

ヒープは*変更可能*で、`heap-push`はヒープをその場で書き換えます。`heap-peek`は先頭の値とキーをヒープから取り除かずに返し、`heap-pop`は取り除いてから返します。`heap-pop-all`はヒープの中身をすべて取り出して、`{ key value }`のペアを優先順位の順に並べた連想リストにします。

```
heap-peek    ( heap -- value key )
heap-pop     ( heap -- value key )
heap-pop-all ( heap -- alist )
```

```factor
USING: heaps kernel prettyprint ;

<min-heap>
"alice" 5 pick heap-push
"bob"   2 pick heap-push
dup heap-peek drop .     ! => "bob"
heap-pop-all .           ! => { { 2 "bob" } { 5 "alice" } }
```

[heaps]: https://docs.factorcode.org/content/vocab-heaps.html
