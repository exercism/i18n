# はじめに

もっとも役に立つシーケンスのワードは、入力のひとつとして*クォーテーション*を受け取り、それを使って処理を進めます。

```
each   ( seq quot -- )
map    ( seq quot -- newseq )
filter ( seq quot -- newseq )
reject ( seq quot -- newseq )
count  ( seq quot -- n )
any?   ( seq quot -- ? )
all?   ( seq quot -- ? )
```

```factor
{ 1 2 3 4 5 } [ even? ] filter .   ! => { 2 4 }
{ 1 2 3 4 5 } [ sq ] map .         ! => { 1 4 9 16 25 }
{ 1 2 3 4 5 } [ 2 > ] count .      ! => 3
```

`map-sum`（`sequences`にもあります）は、クォーテーションをシーケンス全体に適用し、その結果を一度に足し合わせます。同じパターンは、`sort-by`（[`sorting`][sorting]にあります）や`minimum-by`／`maximum-by`（`sequences`にあります）でも使われています。

[sorting]: https://docs.factorcode.org/content/vocab-sorting.html
