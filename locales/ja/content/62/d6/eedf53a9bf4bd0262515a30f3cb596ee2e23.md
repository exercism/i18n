# 真偽値

`bool`型（真偽値の略）がとる値は、`true`と`false`の2つだけです。コードの中では、`true`と`false`というリテラルの大文字と小文字は区別されません。

```php
<?php

$value_is_true = true;
$value_is_false = false;
```

真偽値は、論理式の中で演算子の結果として使われ、そのあと制御構造の中で使われることがよくあります。

## 論理演算子

論理演算子には、次のようなものがあります。

- `!$a`：`$a`が`true`でないときに`true`を返します
- `$a && $b`：`$a`と`$b`がどちらも`true`のときに`true`を返します
- `$a || $b`：`$a`と`$b`の少なくとも一方が`true`のときに`true`を返します

~~~~exercism/caution
`and`演算子と`or`演算子があり、それぞれ`&&`と`||`に対応しています。ただし、`&&`と`||`とは動作が異なり、予期しない結果を招くことがあるため、使用はおすすめしません。
~~~~
