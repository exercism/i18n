# 概要

`switch`文には、プログラミング言語の中で由緒ある[歴史][wiki-switch]があります。`switch`文が導入されたのは[`C`][c-switch]で、その速さが重宝されました。しかし、その速さと引き換えに、機能は大きく制限されていました。C#では、`switch`文の役割は整数にとどまらず広がっています。`switch`文は、任意の型、値、参照を扱うことができます。

関数型言語から来た場合、`switch`文（および別の場所で説明する[`switch`式][switch-expression]）を扱うことは、C#で判別共用体とパターンマッチングを使うことに最も近い体験になります。ただし、型の安全性を強制する力は、判別共用体には遠く及びません。

単純な`switch`文は`C`の先祖に似ており、[`switch`][switch]、[`case`][case]、[`break`][switch-break]、[`default`][switch-default]を組み合わせて使います。

```csharp
int direction = GetDirection();
switch (direction)
{
    case 1:
        GoLeft();
        break;
    case 2:
        GoRight();
        break;
    default:
        MarkTime();
        break;
}
```

上のパターンは、あらゆる単純な型（プリミティブと文字列）で使えます。

参照型が加わると、[追加の構文][switch-pattern-matching]が必要になります。まず型をダウンキャストし、次にガード（[`when`][switch-when]）を追加します。ただし、ガードは単純な値の`case`でも使えます。次に例を示します。

```csharp
Animal animal = GetAnimal();

switch(animal)
{
    case Dog canine:
    case Coyote canine:
        canine.Bark();
        break;
    case Cat cat when cat.HasOnly8Lives():
        cat.IsCareful();
        cat.Meow();
        break;
    case Cat cat:
        cat.Meow();
        break;
}
```

- `default`節は省略できますが、通常は書いておくのが望ましいです。
- 空でない`case`節には、`break`文が必須です。
- 言うまでもなく、`case`ラベルの引数の型はすべて、`switch`の引数の型から派生している必要があります。`switch`の引数が`Object`型であれば、当然ながら最も広い範囲を扱えます。
- ガード式には、`case`の引数のメンバーだけでなく、スコープ内にあるものなら何でも書けます。
- 異なる`case`引数を持つ複数の`case`から、同じコードブロックを参照できます。

[`switch`文][switch-statement]のドキュメントでは、`switch`文の入門が説明されています。
