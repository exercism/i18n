# 説明

この演習では、友達と数の当てゲームをします。ルールはかんたんです。`1`から`100`までの数をひとつこっそり選び、友達がその数を当てようとします。友達の助けになるように、その推測が選んだ数（`42`）にどれだけ近いかによって、返す言葉を変えます。それぞれの返事のルールは次のとおりです。

- 推測が`42`のとき："Correct"
- 推測が`41`または`43`のとき："So close"
- 推測が`41`より小さいとき："Too low"
- 推測が`43`より大きいとき："Too high"

推測に応じた返事を実装するタスクが4つあります。

## 1. 正解に返事をする

正解に返事をする`reply`関数を実装しましょう：

```fsharp
reply 42
// => "Correct"
```

## 2. 近い推測に返事をする

近い推測に返事ができるように、`reply`関数を変更しましょう：

```fsharp
reply 41
// => "So close"
```

## 3. 低すぎる推測に返事をする

低すぎる推測に返事ができるように、`reply`関数を変更しましょう：

```fsharp
reply 25
// => "Too low"
```

## 4. 高すぎる推測に返事をする

高すぎる推測に返事ができるように、`reply`関数を変更しましょう：

```fsharp
reply 88
// => "Too high"
```
