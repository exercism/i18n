# はじめに

## 乱数

`java.util.Random`クラスのインスタンスを使うと、Javaで乱数を生成できます。

### 整数の乱数

整数の乱数は、`nextInt()`メソッドを使って生成できます。
これで、`Integer.MIN_VALUE`から`Integer.MAX_VALUE`までの範囲の値が生成されます。

```java
Random random = new Random();

random.nextInt();
// => -1169335537
```

生成される値の範囲を制限するには、`nextInt(int)`を使います。
これで、`0`（含む）から指定した上限（含まない）までの範囲の値が生成されます。

たとえば、次のコードは`0`から`9`までの乱数を生成します。

```java
Random random = new Random();

random.nextInt(10);
// => 6
```

そして、次のコードは`10`から`19`までの乱数を生成します。

```java
Random random = new Random();

10 + random.nextInt(10);
// => 11
```

### 小数の乱数

小数の乱数は、`nextDouble()`メソッドを使って生成できます。
これで、`0.0`から`1.0`までの範囲の値が生成されます。

```java
Random random = new Random();

random.nextDouble();
// => 0.19250004204021398
```

そして、次のコードは`100.0`から`200.0`までの乱数を生成します。

```java
Random random = new Random();

100.0 + 100.0 * random.nextDouble();
// => 111.31849856260328
```
