# ヒント

## 全般

- `throw`は[`kernel`][kernel]に、`recover`は[`continuations`][continuations]にあります。

## 1. 湿度をチェックする

- `>`で比較してから、`[ "humidity too high" throw ] when`を実行すると、よくないケースのときだけエラーを発生させられます。

## 2. 温度をチェックする

## 3. 独自のエラーを定義する

- `ERROR: machine-error ;`は、クラス*と*、新しいインスタンスをthrowするコンストラクターのワードを宣言します。

## 4. 機械を監視する

- それぞれのチェックを`[ check-… ] [ drop machine-error ] recover`で包みます。リカバリー用のクォーテーションは、元のエラーをdropして新しい`machine-error`をthrowします。これで「どちらが失敗しても同じ」という意味を保ちながら、元の例外が何だったかは隠せます。
- [`kernel`][kernel]の`bi*`は、1つのクォーテーションをそれぞれの入力に適用します。
