# 説明

この演習では、エンジニアが識別子の名前を整えるのを手助けする、ユーティリティルーチンの一部を実装します。
5つのタスクを通して、`Clean`ルーチンを少しずつ作り上げていきます。
有効な識別子は、0個以上の英字とアンダースコアで構成されます。
どの場合も、入力文字列がnullでないことは保証されています。
`Clean`関数に空文字列を渡した場合は、空文字列を返すようにしてください。
なお、空の識別子は効果がないため、呼び出し側は空の識別子で`Clean`ルーチンを呼び出さないようにしましょう。

## 1. 空白をアンダースコアに置き換える

(_static_) `Identifier.Clean()`メソッドを実装して、空白をアンダースコアに置き換えます。
先頭と末尾の空白も対象です。

```csharp
Identifier.Clean("my   Id");
// => "my___Id"
```

## 2. 制御文字を大文字の文字列"CTRL"に置き換える

(_static_) `Identifier.Clean()`メソッドを変更して、制御文字を大文字の文字列`"CTRL"`に置き換えます。

```csharp
Identifier.Clean("my\0Id");
// => "myCTRLId",
```

## 3. ケバブケースをキャメルケースに変換する

(_static_) `Identifier.Clean()`メソッドを変更して、ケバブケースをキャメルケースに変換します。

```csharp
Identifier.Clean("à-ḃç");
// => "àḂç"
```

## 4. 英字以外の文字を除外する

(_static_) `Identifier.Clean()`メソッドを変更して、英字以外の文字を除外します。

```csharp
Identifier.Clean("1😀2😀3😀");
// => ""
```

## 5. ギリシャ文字の小文字を除外する

(_static_) `Identifier.Clean()`メソッドを変更して、'α'から'ω'までの範囲のギリシャ文字を除外します。

```csharp
Identifier.Clean("MyΟβιεγτFinder");
// => "MyΟFinder"
```
