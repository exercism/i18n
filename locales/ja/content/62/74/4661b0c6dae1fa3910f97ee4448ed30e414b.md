# PowerShell

すべてを自動化しましょう！
どんなOSでも、ファイル、プロセス、データセンター、クラウドサービスを管理するスクリプトを書けます。
JSON、XML、CSVなどの構造化データを対話的に探索し、Web APIやCIMからコマンドラインアプリまで、あらゆる管理インターフェースを扱えます。

# PowerShellについて

オープンソースでクロスプラットフォームな.NETのスクリプト言語、シェル、そして構成管理フレームワークであるPowerShellは、ITプロフェッショナルやパワーユーザーが、ほぼあらゆるものを制御し自動化する助けになります。

PowerShellは.NET Frameworkの上に構築されており、古典的なUNIXのパイプの考え方を変革します。テキストやバイナリのストリームだけを渡すのではなく、型情報（日付や時刻など）を含むオブジェクトのインスタンスや、構造化データを伴う複雑な状態も渡せるように拡張しているのです。
従来のシェルでは、コマンドの出力から特定の情報を取り出すのにテキスト処理を使うことがあるかもしれません。PowerShellでは、プロパティとメソッドにアクセスできます（どのプロパティやメソッドが使えるかを調べるためにオブジェクトを検査する方法も含まれます）。
CSVファイルを扱ったり、JSONをハッシュテーブルに変換したり、XMLドキュメントをたどったりと、できることはほかにもたくさんあります。テキスト解析では難しかったり現実的でなかったりする多くの作業が、簡単に組み合わせられるようになるのです。

PowerShellは拡張できます。
他のシェルがスタンドアロンのコマンドラインツールで拡張できるのに対し、PowerShellはそれだけではなく、モジュールで配布されるスクリプト、関数、コマンドレットでも拡張できます。それらはPowerShellのヘルプシステム、構文をハイライトするコマンドラインエディター、仮引数の自動検出、タブ補完と完全に統合されています。
ファイルシステムのシンプルで探索しやすいプロパティとコンテンツの構文を、Windowsレジストリや証明書ストア、SQL Server、果てはAzureのようなデータストアにまで拡張することもできます！

PowerShellには、ほかにもたくさんの機能があります。

- ファイルやサービス、プロセス、さらにはレジストリ、イベントログ、Common Information Model（CIM）、Webリクエストなどを管理するといった、一般的なシステム管理タスクのための組み込みの「コマンドレット」。
- 既存のスクリプトやコマンドラインツールとの互換性。
- 拡張可能なインターフェースと、簡単に見つけられるモジュールやコマンド。
- .NET Frameworkへの完全なアクセスと、NuGetの.NETアセンブリによる拡張性。
- コマンドの実行が成功したかどうかや、その実行時間の情報を含む、充実したコマンド履歴。
- 強力なオブジェクト操作機能。オブジェクトを直接操作したり、シリアル化したり、ほかのツールやデータベースに送ったりもできます。

PowerShellという言語や、その中心となる概念と機能についての詳しいドキュメントは、インストーラーとあわせてhttps://docs.microsoft.com/en-us/powershellで参照できます。
