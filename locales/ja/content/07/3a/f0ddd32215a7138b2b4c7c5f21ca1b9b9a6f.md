# 概要

ループには基本的に2つの種類があります。

1. 条件が満たされるまで繰り返す。
2. コレクションの要素を順に処理する。

どちらも[Rで可能です][web-loops]が、前者のほうがよく使われるかもしれません。

## `while`と`repeat`

何回繰り返すか事前にわからない、終わりの決まっていない問題のために、Rには条件をとる[`while`][ref-control]ループと、条件をとらない[`repeat`][ref-control]ループ（`while (TRUE)`と同じ）があります。

基本的な形はとてもシンプルです。

```R
while (condition) {
  do_something()
}
```

この場合、`condition`が`TRUE`でなくなるまで、プログラムはループを回り続けます。

ループを途中で抜ける方法が2つあります。

- `break`を使うとループを抜け、ループを閉じる波括弧`}`の次の行から実行が続きます。
- `return(x)`は現在の関数の実行を止め、戻り値`x`を呼び出し元に返します。

これらの方法があるので、`repeat { ... }`で「無限」ループを作り、ループ本体の中で止まる条件を見つけたら`break`や`return`を実行する、という書き方が便利なこともあります。

次の3つの書き方はどれも同じで、いずれも`x == 0.4444...`になります。

```R
x <- 12
while (x > 1) {
  x <- x / 3
}

x <- 12
while (TRUE) {
  x <- x/3
  if (x <= 1) break
}

x <- 12
# no boolean clause 
repeat { 
  x <- x/3
  if (x <= 1) break
}
```

## ベクトル（または他のコレクション）の繰り返し

Rでは、これはしばしば不要です。
他のコンセプトで説明したように、多くの関数はベクトル全体を対象に処理を行います。

しかし、明示的なループが必要になることもあります。
特に次のような場合です。

- ループ本体が、出力やファイル入出力のような副作用を持つ。
- 何回繰り返すか予測できないまま、ある基準に達するまでループを続ける。

ループの条件は括弧（`()`）で囲む必要があります。
関数本体と同様、1行のループ本体では波括弧は省略できます（ただし、よく付けます）。

```R
words <- c("This", "is", "a", "loop")
for (w in words) { print(w) } # the braces are optional here
#> [1] "This"
#> [1] "is"
#> [1] "a"
#> [1] "loop"
```

現在の繰り返しが何らかの条件を満たさない場合、`next`で直ちに次の繰り返しへ進むことができます。

```R
for (n in 1:5) {
  if (n %% 2 == 0) next
  print(n)
}
#> [1] 1
#> [1] 3
#> [1] 5
```

数値のインデックスが必要な場合は、[`seq_along()`][ref-seq_along]を使います。

```R
v <- LETTERS[1:3]
v
#> [1] "A" "B" "C"

for (i in seq_along(v)) { print(sprintf("%s%i", v[i], i)) }
#> [1] "A1"
#> [1] "B2"
#> [1] "C3"
```

`i in 1:length(v)`の使用は_おすすめしません_。`length(v)`がゼロのときに問題が起きるためです。
範囲`1:0`は`c(1, 0)`と同じなので、ループ本体が実行され、おそらく失敗します。
`seq_along()`関数は、このケースを正しく処理するように作られています。
