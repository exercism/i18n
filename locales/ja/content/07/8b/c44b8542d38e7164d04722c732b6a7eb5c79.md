# 演習のテスト

以下の手順に沿って演習の解答を開発し、ローカルでテストしてみましょう。

## 演習をダウンロードする

Command Promptを開き、ダウンロードしたい演習の名前を指定して、以下のコマンドを実行します。

```sh
exercism download --track ballerina --exercise <exercise-name>
```

## 解答を開発する

1. 以下のコマンドを実行して、ダウンロードした演習のディレクトリに移動します。

     >**ヒント：**以下のコマンドに示すディレクトリの場所は、お使いのOSと設定済みのExercismワークスペースによって異なります。ワークスペースの場所は、`exercism configure`コマンドを実行すると確認できます。

     ```sh
     cd ~/exercism/ballerina/hello-world/
     ```

2. 提供された指示に従って、演習の解答を開発します。

## 解答をテストする

Ballerinaの演習には、テストが1つだけのものもあれば、複数あるものもあります。テストは、演習のルートディレクトリ内にある`/tests`ディレクトリの、それぞれ対応するテストファイルに書かれています。

### テストが1つだけの演習の場合

以下のコマンドを実行すると、演習のテストを実行できます。

デフォルトでは、最初のテストだけが有効になっています。これは意図的なもので、まずその1つのテストに合格することだけに集中できるようになっています。

```sh
bal test
```

### テストが複数の演習の場合

複数のテストがある演習をテストするには、以下の手順に従います。

1. 最初のテストに合格したら、`@test:Config`アノテーションの`enable: false`プロパティを削除して、次のテストを有効にします。

     ```ballerina
     @test:Config {
       enable: false
     }
     function nextTestCase() {
     }
     ``` 

2. 以下のコマンドを実行して、有効にしたテストを実行します。

   ```sh
     bal test
   ```

3. 上記の2つの手順を繰り返して、残りのテストを有効にします。

すべてのテストを有効にして、それぞれのテストに実装が合格することを確認できれば、その演習は無事に完了です。

演習を楽しみながら解いていってください。うまくいくことを願っています！
