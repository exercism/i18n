# ヒント

## 全般

- イミュータブルなクラスに`new`はありません。`create`は、すでに存在しているそのクラスの変数から始めます。

  ```sather
     create(d : INT) : SAME is
        b : SAME;
        return b.degrees(...);
     end;
  ```

- `b.degrees(x)`は`b`を変更しません。新しい方位を返すので、それが戻り値になっているのです。

## 1. 方位を求める

- `%`は数値を範囲内に収めますが、`-10 % 360`が`350`になるのは、右辺が正のときにSatherの`%`が負の値を返さないからです。つまり、`d % 360`だけで十分です。

## 2. 回転する

- 回転量を度数に足して、その合計から新しい方位を作ります：`#BEARING(degrees + by)`
- `create`がすでに答えを範囲内に戻してくれるので、北を越えて回転することについては何もする必要はありません。

## 3. 比較する

- たった1行です。2つの`degrees`を比較します。
- 入力の型は`SAME`で、その属性はいつもどおりに読み取ります：`other.degrees`

## 4. 方位点に名前を付ける

- コツは、割り算をする前に半区画分だけずらすことです。こうすると、各方位点はその*中心*から測られるようになります：`((degrees + 22) / 45) % 8`は、北なら0、北東なら1、というふうになります。
- 次に、その数値に対して`case`を書き、8つの名前を並べます。`else`も必要です。`case`は、8つの分岐が考えられるすべての値を網羅していても、必ず`else`を必要とします。

## 5. 文字列にする

- `+`は断片をつなぎますが、何かを足せるのは文字列だけです。ここでは数値が先に来るので、つなぎ始めるには`degrees.str`が必要です。`"a" + 1`は問題ありませんが、`1 + "a"`はコンパイルできません。
- 名前をもう一度計算するのではなく、`point`を呼び出します。
