# 説明

与えられた3枚のドミノを、正しいドミノの連鎖になるように並べられるかどうかを判定します。正しい連鎖とは、石の半分にある目が、隣り合う石の向かい側の半分にある目と一致し、かつ隣り合う石がない側の半分の目（最初と最後の石）どうしが一致しているものです。テストケースによっては、連鎖の解答に同じ石を重複して使うこともあります。正しいドミノの連鎖を並べられる場合は`True`を、そうでない場合は`False`を返します。

```text
For example, given: [(2,1),(2,3),(1,3)]
    True

For example, given: [(1,2),(4,1),(2,3)]
    False
```
