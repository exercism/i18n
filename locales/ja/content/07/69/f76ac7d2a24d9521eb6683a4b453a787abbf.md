# よいサポート依頼の書き方

Exercismの演習で助けが必要ですか？
よいサポート依頼の書き方を身につければ、コミュニティから協力してもらいやすくなります。

大切なポイントをいくつか紹介します。

## 画像ではなくコードブロックを使いましょう

コード（自分で書いたものや手順など）を共有したいときは、画像ではなくコードブロックを使いましょう。

エンジニアにとって、画像を拡大して見るより、コードをそのまま読むほうがずっと速く理解できます。
また、多くのユーザーがスクリーンリーダーを使っていますが、スクリーンリーダーは画像を読み上げることができません。
よいコミュニティの一員として振る舞い、ボランティアのみなさんに協力してもらい、プロらしく見せたいなら、コードは画像ではなくテキストで共有しましょう！

たとえば、次のように入力します。

````
```
for number in range(10):
  total += number;
```
````

これは次のように表示されます。

```
for number in range(10):
  total += number;
```

コードブロックの開始部分に言語を指定すると、シンタックスハイライトも付きます。

````
```python
for number in range(10):
  total += number;
```
````

こうなります。

```python
for number in range(10):
  total += number;
```

## 誰も排除しない言葉づかいをしましょう

Exercismには、さまざまな性別の人が参加しています。
Discordに来て「Hey boys」などと言うと、コミュニティの半分をすぐに排除してしまいます。
すると、その人たちはあなたを助けてくれにくくなります。それだけでなく、コミュニティのほかの人たちも助けてくれにくくなります。Exercismは、誰も排除しないことを大切にしているからです。

ですから、助けてもらいたい、そして感じのよい人でありたいなら、性別を限定する言葉は使わないようにしましょう。
「Hey folks」「Hey everyone」などを使ってみましょう。思い切って「Hey fellow Exercists!」を選ぶのもいいですね。

詳しくは、[私たちが使う言葉](./the-words-that-we-use)についての記事をお読みください。
