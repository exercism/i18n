# ヒント

## 全般

- ファントムビルダーパターンについてのJeroen Engelsの[素晴らしいトーク][phantom-builder-pattern]を観てみましょう

## 1. 宝箱のプレースホルダーを用意する

- `Chest`は`TreasureChest`と同じにできます。ファントム型を追加した単一のバリアントです
- プレースホルダーの`Chest todo`には型引数が足りません。ファントム型が欠けています
- ファントム型はレコードにする必要があります。そうすれば拡張できます
- 開始時の型は制約のない`Chest treasure {}`で、最終的な型は完全に検証済みの`Chest treasure { conditions | securePassword : (), uniqueTreasure : () }`です
- 開始時の型からもう一方の型にするには、`securePassword : ()`と`uniqueTreasure : ()`という条件が、`secureChest`と`uniqueTreasures`によってそれぞれ独立に追加されます

## 2. 安全な宝箱を選ぶ

- 関数の引数にある`Chest`をパターンマッチできます
- パスワードを検証するには、関数[`String.length`][string-length]を使えます
- `securePassword : ()`という条件は、関数の本体ではなく型シグネチャーによって追加されます
- 制約のない`Chest`を`Just`に入れても、型が変わることは期待できません。`Chest`コンストラクターで新しい値を作る必要があります

## 3. 一意の宝物を選ぶ

- 使える`List.unique`関数はないので、自分で作る必要があります
- ひとつの方法は、`secureChest`に似た型のヘルパー関数と一緒に`List.filterMap`を使うことです
- `uniqueTreasure : ()`という条件は、関数の本体ではなく型シグネチャーによって追加されます
- 制約のない`Chest`を`Just`に入れても、型が変わることは期待できません。`Chest`コンストラクターで新しい値を作る必要があります

## 4. 完成品を楽しむ

- `makeTreasureChest`は`TreasureChest`型コンストラクターを利用する必要があります
