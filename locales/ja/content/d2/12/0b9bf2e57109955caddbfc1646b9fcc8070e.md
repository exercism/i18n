# 説明

課題は、1から31までの数を秘密の握手の一連の動作に変換することです。

動作の並びは、数を2進数に変換したときの右端から5桁を見て決めます。右端の桁から始めて、左へ進みます。

それぞれの位に対応する動作は次のとおりです。

```plaintext
00001 = wink
00010 = double blink
00100 = close your eyes
01000 = jump
10000 = Reverse the order of the operations in the secret handshake.
```

例として、数`9`を使ってみましょう。

- 9を2進数にすると`1001`です。
- 一番右端の桁は1なので、最初の動作は`wink`です。
- 左に進むと、次の桁は0なので、double blinkはありません。
- さらに左に進むと、次の桁は0なので、目は開けたままです。
- さらに左に進むと、次の桁は1なので、jumpを実行します。

これで最後の桁なので、最終的なコードは次のとおりです。

```plaintext
wink, jump
```

26という数は2進数で`11010`なので、次の動作になります。

- double blink
- jump
- 動作を逆順にする

したがって、26の秘密の握手は次のとおりです。

```plaintext
jump, double blink
```
