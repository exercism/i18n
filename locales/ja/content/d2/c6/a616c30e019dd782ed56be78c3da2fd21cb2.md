# 三項演算子

三項演算子は、`if..else..`による比較を行って値を返すための、もうひとつの書き方です。

## 構文

PHPには`if`文があり、条件の真偽に基づいて処理を評価できます。

```php
if ($condition) {
  $value = 1;
} else {
  $value = 2
}
```

別の書き方として、三項演算子でも同じ処理を表せます。

```php
$value = $condition
  ? 1  // True branch
  : 2; // False branch
```

比較の構文は短く、`(condition) ? (evaluate if true) : (evaluate if false);`と表します。

## メリット

三項演算子を使う明白なメリットは簡潔さで、`if..else..`文に比べて条件式を短く書けますが、ほかにもいくつかの利点があります。

- 式であるため、ほかの式の内部で使えます
- 各分岐を遅延評価できます。

  ```php
  function expensiveCalculation(): int
  {
    // An expensive calculation is performed
    $answerToEverything = 42;
    return $answerToEverything;
  }

  $needExactAnswer = false;
  $estimatedAnswer = 40;
  $answer = $needExactAnswer ? expensiveCalculation() : $estimatedAnswer;
  ```

  この例では、正確な答えが必要でなければ、コストのかかる計算は呼び出されません。

## デメリット

三項演算子にはいくつかのデメリットがあるため、使うかどうかをよく考える必要があります。

- キーワードではなく記号の解釈にたよるため、`if`文よりも読みにくくなることがあります。
- PHPの三項演算子は、ほとんどの現代的な言語（C、Java、JavaScriptなど）とは異なり左結合であるため、思わぬバグにつながることがあります。
- 真の分岐と偽の分岐で評価される式は、値を返さなければなりません。

## さらに短く

三項演算子の構文は、`(condition) ?: (evaluate if falsey)`とさらに短くできます。
その使い方のひとつは、式の中でフォールバック値を用意するものです。

```php
$fruit = null;
eat($fruit ?: 'apple');
```

これは_エルビス演算子_（`?:`）とも呼ばれます。
