# キッチン計算機

## ストーリー

このストーリーは、あるプログラミング言語における[タプル][type-tuple]の探求を促すものです。

基本的な前提として、台所の材料はしばしばわかりにくい単位で量られ、分量や手元にある道具によって異なる換算が必要になります。タプルを使うと、計量の数値部分に[ダックタイピング][concept-duck-typing]を持たせることができます。

つまり、小数を使った値の基本的な換算を学ぶ内容です。

### 換算

| 変換元             | 変換先  |
| ------------------ | ------- |
| 1 mL               | 1mL     |
| 1 cup              | 240mL   |
| 1 fluid ounce (US) | 29.57mL |
| 1 teaspoon         | 5 mL    |
| 1 tablespoon       | 15 mL   |

## タスク

この演習では、次のことを使えるように導きます。

- タプル
- 情報をまとめたものとしてのタプル
- 要素のインデックスを使ってタプルから値を取り出すこと
- パターンマッチングを使ってタプルから値を取り出すこと
- 新しいタプルを作ること
