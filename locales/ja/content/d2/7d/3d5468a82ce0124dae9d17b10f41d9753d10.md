# はじめに

## モジュール

Gleamのコードはモジュールという単位で整理されており、1つのファイルが1つのGleamモジュールになります。

これまでは、`pub fn`という構文で関数を書いてきました。これは、ほかのモジュールからも使える公開された関数を定義します。`fn`で定義した関数は、それが定義されたモジュールの中だけの非公開の関数で、ほかのモジュールからは使えません。

```gleam
// This function is public
pub fn add(x, y) {
  x + y
}

// This function is private
fn subtract(x, y) {
  x - y
}
```

Gleamのモジュールには名前があり、その名前は`src`ディレクトリまたは`test`ディレクトリ内のファイルパスをもとに決まります。

たとえば、`src\geometry\rectangle.gleam`（Windowsの場合）または`src/geometry/rectangle.gleam`（UNIX系オペレーティングシステムの場合）で定義されたモジュールは、`geometry/rectangle`という名前になります。

## ほかのモジュールから関数をインポートする

ほかのモジュールで定義された関数にアクセスするには、インポートを使います。モジュールをインポートすると、そのモジュールが公開している関数すべてが使えるようになります。ただし、それらの関数へのアクセスのしかたは、モジュールのインポートのしかたによって変わります。

修飾インポートが既定で、そのようにインポートしたモジュール内の関数（たとえば`gleam/list`モジュールの`map`関数）にアクセスするには、モジュール名を前に付けます（`list.map`）。

```gleam
// Import the int module
import gleam/int

pub fn run(x: Int) -> String {
  // Use the to_string function from the int module
  int.to_string(x)
}
```

既定では、そのモジュールを指すために使う名前はモジュール名の最後の部分で、この場合は`int`です。ただし、これは`as`キーワードを使うと変えられます。

```gleam
// Import the int module and refer to it as i
import gleam/int as i

pub fn run(x: Int) -> String {
  i.to_string(x)
}
```

非修飾インポートを使うと、前に何も付けずに、そのモジュールが公開している関数に直接アクセスできます。

```gleam
// Import the to_string function from the int module
import gleam/int.{to_string}

pub fn run(x: Int) -> String {
  to_string(x)
}
```

修飾インポートのほうが好まれます。関数がどこから来たのかが読み手にわかりやすくなり、名前の衝突も避けられるからです。


## 標準ライブラリ

Gleamには、充実していてドキュメントも整った標準ライブラリがあります。ドキュメントは[hexdocs.pm/gleam_stdlib][docs]でオンラインで見られます。このリンクはどこかに保存しておきましょう。何度も使うことになります！

ほとんどの組み込みデータ型には、そのデータ型を扱う関数を提供する対応するモジュールがあります。たとえば、整数には`gleam/int`モジュール、文字列には`gleam/string`モジュール、リストには`gleam/list`モジュールなどがあります。

[docs]: https://hexdocs.pm/gleam_stdlib/
