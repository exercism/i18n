# はじめに

## 整数

整数とは、`{..., -2, -1, 0, 1, 2, ...}`の集合に属する数です。
整数の最大値と最小値は、PHPが動作しているシステムによって決まります。
通常、最近のほとんどのシステムでは、整数は64ビットの値です。つまり、`-9_223_372_036_854_775_808`から`9_223_372_036_854_775_807`までを表すことができます。

```php
<?php

$a = 1234;
$a = 1_234_567;
```

基数の接頭辞を使うと、10進数以外の基数で整数リテラルを書くことができます。

```php
<?php

$a = 0123; // octal number (equivalent to 83 decimal)
$a = 0o123; // octal number (as of PHP 8.1.0)
$a = 0x1A; // hexadecimal number (equivalent to 26 decimal)
$a = 0b11111111; // binary number (equivalent to 255 decimal)
```

## 浮動小数点数

PHPでは、実数の一部を表すために浮動小数点数を使います。
小数点で区切られた1桁以上の数字で始まります。

```php
<?php

$a = 1.234; 
$b = 1.2e3; 
$c = 7E-10;
$d = 1_234.567; // as of PHP 7.4.0
```

### よくある落とし穴

すべての数値と算術演算が浮動小数点数で扱えるわけではありません。
ドルとセントを表すのに浮動小数点数を使うと、丸め誤差につながることがあります。

```php
<?php

$result = 0.1 + 0.2; // => 0.30000000000000004
```

## 算術演算子

PHPには、算術演算を行うための演算子がいくつか用意されています。PHPの算術演算子は、数学の標準的な演算の順序に従います。PHPで用意されている演算子は次のとおりです。

* 単項プラス (+)
* 単項マイナス (-)
* 加算 (+)
* 減算 (-)
* 乗算 (*)
* 除算 (/)
* 余り (%)
* 累乗 (**)

```php
$moles = +'10';
$aLotOfMoles = 6.022 * 10**23 * $moles;
```
