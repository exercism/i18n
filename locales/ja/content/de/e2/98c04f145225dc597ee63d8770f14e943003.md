# 概要

`bit`は、コンピューターの世界で最も細かい値です。
`bit`という言葉は、"binary digit"（2進数の桁）の略です。
実行環境において、2つの値のうちどちらか一方をとりうるオブジェクトを格納できるだけの大きさを持つ、データ保存の単位です。
そのため、`1`か`0`のどちらかの2進数の値を持ちます。
他のすべてのデータ型は、複数の`bits`で構成されます。
たとえば、`byte`は一般に8つの`bits`で構成されます。

## ビット値の書き方

`Bits`が集まって2進数の体系をつくります。
`2`の倍数が、いわゆる十の位・百の位・千の位に入っていきますが、ここでは「十」が「2」、「百」が「4」、「千」が「8」にあたります。
つまり、10進数の`2`は2進数では`10`、`4`は`100`、`8`は`1000`になります。
10進数と同じように、右から左へ進むほど値が大きくなります。
10進数の`5`は、2進数の`101`で表されると考えられます。「1の位」に`1`があり、「4の位」に`1`があるわけです。
ただし、2進数のリテラルはC言語の標準規格には含まれていません。
C言語の標準規格がサポートする2進数の値は、単独の`1`か`0`だけです。
2進数のリテラルは、gnuコンパイラーのようないくつかの非標準のコンパイラー拡張機能では_サポートされています_。リテラルの前に`0b`を付けることで使えます。

```c
#include <stdio.h>

int main() {
    int binary_five = 0b101;
    printf("%d", binary_five);
    return 0;
}
```

このような表記がすべてのコンパイラーでサポートされているわけではなく、コンパイラー間でコードを持ち運ぶときの障壁になりうることを覚えておくことが大切です。

2進数の値をコードで書くときによく使われるのが、16進数の表記です。これは16を基数とする数の体系です。
C言語の16進数表記では、リテラルの前に`0x`または`0X`を付けます。
10進数の`16`が十の位に`1`として表されることから、10進数の`10`は16進数で`0xA`、`11`は`0xB`、`12`は`0xC`、`13`は`0xD`、`14`は`0xE`、`15`は`0xF`と表されます。
たとえば、10進数の`42`は`0x2A`と書きます。これは`2`×`16`（= `32`）に`10`を足したもの（= `42`）です。

2進数では、`42`は`00101010`、つまり`32`＋`8`＋`2`と考えられます。
このとき、右から2番目、4番目、6番目のビットが「セットされている」、つまり`0`ではなく`1`になっていると言います。
2番目のビットは`2`、4番目のビットは`8`、6番目のビットは`32`です。
この3つのビットをセットすると、`42`という値になります。

## ビットマスク

ビットマスクは、個々のビットをセットするために使われる任意の値です。
たとえば、英語のアルファベットには26文字あります。
符号なし32ビット整数のように、少なくとも26ビットある値なら、英語の各文字に対して`true`か`false`の状態を設定するビットマスクとして使えます。
必要な`true`か`false`の状態の組を扱えるだけのビット数があれば、どんな値でもビットマスクとして使えます。
個々のビットのセットと読み取りは、ビット演算子を使って行います。

## ビット演算子

ある`string`の中にどの文字が現れるかを記録したいとしましょう。
この例では、英語のアルファベット26文字だけを使います。
ビットマスクには符号なし32ビット整数を使います。
`0`はその文字が現れないことを表します。
`1`はその文字が1回以上現れることを表します。
最初のうち、ビットマスクのビット表現は`0`が32個並んだ`00000000000000000000000000000000`です。
一番右の位置が`A`に対応します。
左から2番目が`B`に対応し、以下同様です。
文字列内のすべての文字をループで処理するとします。そのため、どの文字をセットするのにも使える1行のコードがほしいところです。

### ビットごとの左シフト演算子：ビットを位置づける方法

`<<`は左へシフトするためのビット演算子です。

文字が`A`なら左にシフトしたくありませんが、`B`なら1つ左にシフトし、`C`なら2つ左にシフトしたい、ということになります。
`char`を`A`や`B`のような文字として認識することはできますが、`char`はメモリー上では整数型として実装されているので、`char`で簡単な計算ができます。
処理中の`char`を表す`letter`という変数があれば、`letter`と`A`の`0s`との差だけ`1`を左にシフトすることで、必要な数だけ左へシフトできます。たとえば`1 << letter - 'A'`のように書きます。
`A` - `A`は`0`なので、`letter`が`A`なら`chars`だけ左にシフトします。
`B` - `A`は`1`なので、`letter`が`B`なら`1`だけ左にシフトします。以下同様です。

### ビットごとの論理和（OR）演算子：ビットをセットする方法

ビットを_どこに_セットしたいかがわかったら、ビットごとの論理和（OR）演算子`|`を使って実際にセットできます。
`|`演算子の結果は、左または右のオペランドのどちらかにビットがセットされている各位置で`1`になります。
つまり、`0010 | 0001`の結果は`0011`になります。
（この値は2進数では`11`、10進数では`3`であることを覚えておきましょう。）
結果を値に代入するには、`|`演算子と代入演算子を組み合わせて`|=`のようにビットをセットできます。
話を簡単にするため、次の例ではループを使いませんが、`ABA`という文字をビットマスクで処理する方法を示しています。

```c
#include <stdio.h>
#include <stdint.h>

int main() {
    // it's important to initialize the mask to 0 so we don't get garbage values
    uint32_t mask = 0;
    char letter_A = 'A';
    char letter_B = 'B';
    char letter_A_again = 'A';
    mask |= 1 << letter_A - 'A';
    mask |= 1 << letter_B - 'A';
    mask |= 1 << letter_A_again - 'A';
    // prints 3
    printf("%d", mask);
}
```

マスクの一番右の部分を`A`に対して`0001`にセットし、次に`B`に対してマスクを`0011`にセットします。
もう一度`A`をセットしても、既存のマスクは変わりません。
`A`がすでにセットされているかを確認すれば、ビットを再びセットせずに済んだはずです。

### ビットごとの論理積（AND）演算子：ビットを読み取る方法

`&`はビットごとの論理積（AND）演算子です。
`&`演算子の結果は、左右両方のオペランドにビットがセットされている各位置で`1`になります。
つまり、`0011 & 0001`の結果は`0001`になります。
次の例で実際に確かめられます。

```c
#include <stdio.h>
#include <stdint.h>

int main() {
    uint32_t mask = 0;
    char letter_A = 'A';
    char letter_B = 'B';
    char letter_A_again = 'A';
    mask |= 1 << letter_A - 'A';
    mask |= 1 << letter_B - 'A';
    // prints A already set
    if (mask & 1 << letter_A_again - 'A')
        printf("A already set\n");
    else
        mask |= 1 << letter_A_again - 'A';
    printf("%d", mask);
}
```

### ビットごとの排他的論理和（XOR）演算子：ビットを反転させる方法

`^`はビットごとの排他的論理和（XOR）演算子です。
_論理和_（OR）演算子があるということは、振る舞いの異なる_排他的論理和_（XOR）演算子もあるということです。
`^`演算子の結果は、左右のオペランドの_片方だけ_にビットがセットされている各位置で`1`になります。
つまり、`0001 ^ 0011`の結果は`0010`になります。
一番右のビットは、_両方_のオペランドの一番右が`1`なのでセットされません。
排他的論理和はXORと表記されることもあります。
XORした結果をもう一度XORすると、元の値に戻ります。
これは、データの暗号化と復号に同じ鍵を使う、とても単純な暗号化に利用できます。
たとえば、次のとおりです。

```c
#include <stdio.h>

int main() {
    char a = 'a';
    char b = 'b';
    char c = 'c';
    // we will use "a" for the "key"
    char first = a ^ 'a';
    char second = b ^ 'a';
    char third = c ^ 'a';
    // prints three "dots" for unprintable characters
    printf("%c %c %c\n", first, second, third);
    // prints the ascii values 0 3 2
    printf("%d %d %d\n", first, second, third);
    first = first ^ 'a';
    second = second ^ 'a';
    third = third ^ 'a';
    // prints a b c
    printf("%c %c %c\n", first, second, third);
    // prints the ascii values 97 98 99
    printf("%d %d %d\n", first, second, third);
}
```

### ビットごとの右シフト演算子：値を半分にする方法

`>>`は右へシフトするためのビット演算子です。
通常、値のビットを1つ右にシフトするごとに、結果は値を2で割ったものになります。
たとえば、次のとおりです。

```c
#include <stdio.h>

int main() {
    int number = 16;
    number >>= 2;
    // prints 4, or 16 / 2 = 8 / 2 = 4
    printf("%d\n", number);
}
```

右オペランドの値が負であるか、昇格後の左オペランドの幅以上である場合、動作は未定義です。
これは左シフト演算子にも当てはまります。
符号なし整数ではなく符号付き整数を使う場合には、符号の有無も影響することがあります。
次の例は、符号付き整数を左や右にシフトしすぎたときの、あるシステムでの動作を示しています。

```c
#include <stdio.h>

int main() {
    int number = 16;
    number <<= 250;
    // prints 1073741824
    printf("%d\n", number);
    number <<= 1;
    // prints -2147483648
    printf("%d\n", number);
    number <<= 1;
    // prints 0
    printf("%d\n", number);
    // total shifts are now 256, done incrementally
    number <<= 4;
    // prints 0
    printf("%d\n", number);
    number = 16;
    // prints 16 when 256 total shifts done at once
    printf("%d\n", number << 256);
    // prints 0 when bits shifted right far enough
    printf("%d\n", number >> 5);    
    // still prints 0
    printf("%d\n", number >> 255);
    // prints 16 when shifted right far enough to "wrap around"
    printf("%d\n", number >> 256);
}
```

動作が未定義なので、別のシステムでは違う結果になるかもしれません。
ビットをシフトするときは、使っているデータ型の範囲を理解しておくことが大切です。

## ビットフィールド

単純なデータ型に詰め込まれたビットを、その位置によって扱えることを見てきました。
`struct`に詰め込まれたビットは、名前で扱えます。
このようなデータ型を`bit field`と呼びます。
`bit fields`の使いどころとしては、ON/OFFのフラグをまとめて持ちたいときに、メモリーの使用量をできるだけ小さくしたい場合が挙げられます。

```c
#include <stdio.h>

int main() {

    struct lights {
        unsigned int number_of_lights;
        unsigned int red   : 1;
        unsigned int green : 1;
        unsigned int blue  : 1;
    };
    struct lights lightboard = {3, 0, 0, 0};
     
    //  prints 000
    printf("%d", lightboard.red);
    printf("%d", lightboard.green);
    printf("%d\n", lightboard.blue);
    
    lightboard.green = 1;

    //  prints 010
    printf("%d", lightboard.red);
    printf("%d", lightboard.green);
    printf("%d\n", lightboard.blue);
    
    // prints 3
    printf("%d\n", lightboard.number_of_lights);
}
```

`unsigned int variable_name : 1;`という構文は、struct内に置かれた`unsigned int`の中に`1`ビットのフィールドを作ります。
`unsigned int`の代わりに`signed int`を使うこともできますし、C99以降では`bool`型を使うこともできます。
ビットフィールドを含むstructは、上の例の`number_of_lights`のように、他のデータ型のフィールドも持つことができます。
