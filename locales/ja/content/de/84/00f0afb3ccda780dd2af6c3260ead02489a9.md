# はじめに

入力と出力を扱う関数は、`IO`モジュールが提供しています。

## 出力

文字列を標準出力に書き出すには、`IO.puts`を使います。`IO.puts`は、文字列の末尾に必ず改行を1つ加えます。それが不要なときは、代わりに`IO.write`を使いましょう。どちらの関数も、成功するとアトム`:ok`を返します。

```elixir
IO.puts("Hi!")
# > Hi!
# => :ok
```

`IO.puts`は文字列の書き出しには便利ですが、それ以外の用途にはあまり向いていません。標準出力にどんな値でも書き出せるデバッグ用のツールが必要なら、代わりに`IO.inspect`を使いましょう。`IO.inspect`は、渡された値をそのまま返すので、コードのどの位置にでも差し込むことができます。また、`:label`をはじめとする多くのオプションを受け取るので、他の`IO.inspect`の呼び出しと区別することもできます。

## 入力

標準入力から1行読み込むには、`IO.gets`を使います。`IO.gets`は引数を1つ受け取ります。これは、入力のプロンプトとして表示される文字列です。`IO.gets`はプロンプトのあとに改行を加えないので、必要なら自分で含めておきましょう。

```elixir
IO.gets("What's your name?\n")
# > What's your name?
# < Mary
# => "Mary\n"
```
