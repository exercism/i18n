# はじめに

Haxeの数値の型は2つあります。整数と小数です。

- `Int`: 整数を表します。
- `Float`: 倍精度の64ビット浮動小数点数を表します。

```haxe
var integer:Int = 10;
var floating:Float = 5.4;
```

`Float`が期待される場所ならどこでも`Int`を使えます（つまり、`Int`は`Float`に**代入可能**で、`Float`と**単一化**します）。しかし、その逆は成り立ちません。`Float`を`Int`に代入すると精度が失われる可能性があるため、暗黙のうちに許可されることはありません。
