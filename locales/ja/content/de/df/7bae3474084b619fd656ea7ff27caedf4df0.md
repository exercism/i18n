# 概要

[`Exception`ビヘイビア][exception-behaviour]は、[`errors`][getting-started-errors]がどのように発生して表示されるかを定義します。

次の2つの任意のコールバックが含まれます。

- `message/1`は、エラー構造体を読みやすいメッセージに変換します。
- `exception/1`は、`raise/2`の2番目の引数からメッセージを作成し、メッセージを変更できるようにします。

定義されたエラーは次のとおりです。

- 実装されているモジュールと同じ名前を持ちます。
- 構造体を拡張したものです。
- `:message`フィールドを持ちます。
- 意図したエラーを発生させるために、`raise/1`と`raise/2`で使うことができます。

## 例外を定義する

エラーモジュールから例外を定義するには、[`defexception`][defexception]マクロを使います。

```elixir
# Defines a minimal error, with the name `MyError`
defmodule MyError do
  defexception message: "error"
end

# Defines an error with a customized exception/1 function
defmodule MyCustomizedError do
  defexception message: "custom error"

  @impl true
  def exception(value) do
    case value do
      [] ->
        %MyCustomizedError{}

      _ ->
        %MyCustomizedError{message: "Alert: " <> value}
    end
  end
end
```

## 例外を使う

定義したエラーは、組み込みのエラーと同じように、`raise/1`または`raise/2`を使って発生させることができます。

```elixir
raise MyError
# => ** (MyError) error

raise MyError, "an error occurred"
# => ** (MyError) an error occurred

raise MyCustomizedError
# => ** (MyCustomizedError) "custom error"

raise MyCustomizedError, "a very bad error occurred"
# => ** (MyCustomizedError) Alert: a very bad error occurred
```
