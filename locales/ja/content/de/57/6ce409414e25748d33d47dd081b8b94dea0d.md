# はじめに

ジェネリクスを使うと、同じコードを複数の型で使い回せます。いちいち同じことを書き直す必要はありません。ジェネリックな型は、山括弧（`<>`）を使って、たとえば`<T>`のように定義します。ここで`T`は、任意の型のプレースホルダーです。

```rust
fn largest_list<T>(l1: Array<T>, l2: Array<T>) -> Array<T> {
    if l1.len() > l2.len() {
        l1
    } else {
        l2
    }
}
```

Cairoでは、ジェネリック型がどんな操作に対応している必要があるかを指定するために、トレイト境界が必要です。制約は、`+`の構文で追加できます。

```rust
fn process_data<T, +Drop<T>, +Copy<T>>(value: T) -> T {
    // Function body
}
```

構造体もジェネリックにできます。

```rust
#[derive(Drop)]
struct Container<T> {
    value: T,
}
```

トレイトもジェネリックにできます。これにより、さまざまな型に対応できるようになります。

```rust
trait Processor<T> {
    fn process(self: @T) -> ByteArray;
}

impl MyProcessor<T, +Drop<T>> of Processor<T> {
    fn process(self: @T) -> ByteArray {
        "processed"
    }
}
```

関数でも、トレイト境界を付けたジェネリックな型を入力として受け取れます。こうすると、必要なトレイトを実装したどんな型でも扱えるようになります。

```rust
fn use_processor<T, +Processor<T>, +Drop<T>>(item: T) -> ByteArray {
    item.process()
}
```
