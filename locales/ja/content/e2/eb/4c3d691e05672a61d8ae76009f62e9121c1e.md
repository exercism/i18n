# はじめに

## 型のジャグリング

型のジャグリングは、型強制とも呼ばれます。
型のジャグリングとは、異なる型の2つの値が、演算を行うために同じ型に変換されることです。

```php
$baskets = 5 // int
$apples_per_basket = "3" // string
$baskets * $apples_per_basket
# => 15
```

これは暗黙的に行われる場合もあれば（上の例を参照）、`C`言語スタイルの型キャストを使って明示的に行う場合もあります。

```php
$apples_per_basket = "3" // string
$my_number = (int) $apples_per_basket // cast string to int
# => 3 // int
```

手動の型キャストで使用できる型は、`bool`、`int`、`float`、`string`、`array`、`object`です。
型キャストは、整数（`int`）を浮動小数点数（`float`）に変換する場合や、その逆の場合によく使われます。
