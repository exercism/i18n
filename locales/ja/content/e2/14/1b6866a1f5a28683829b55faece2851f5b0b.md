# 概要

ハッシュはPerlのデータ型で、文字列のキーとスカラーの値のペアを順不同で保持します。

ハッシュ変数は通常、配列を代入して値を設定します。たとえば`my %scores = (Alice => 10, Bob => 15, Charlie => 20);`のようにします。

配列の要素は通常カンマで区切りますが、配列の中でキーと値を区切る際には「ファットコンマ」と呼ばれる`=>`をよく目にします。その動作はカンマとほぼ同じですが、左側の要素を文字列として解釈してくれるという利点があります。

ハッシュには、個々のキーに代入して値を設定することもできます。たとえば`$scores{Alice} = 10;`のようにします。

ハッシュの値には、添字でキーを指定してアクセスできます。たとえば`$scores{Bob} # 15`のようにします。

ハッシュのキーは一意です。同じキーを複数回指定した場合、最後に指定した値だけが残ります。

## 関数

ハッシュを扱う関数には、それぞれハッシュのキーと値を配列として取り出す[keys][keys]と[values][values]があります。[keys][keys]と[values][values]が返す配列は、[grep][grep]、[map][map]、[sort][sort]といった配列向けの関数や、[for][for]ループで役立ちます。

その他のハッシュ関数には、キーがハッシュに存在するかどうか（値が`undef`の場合でも）を確認する[exists][exists]と、ハッシュからキーを削除する[delete][delete]があります。

## シジルによる違い

ハッシュの値を取り出すとき、結果は使うシジルによって決まります。変数名の末尾に付く波括弧（`{}`）が、その名前のハッシュにアクセスしていることをPerlに伝えます。

```perl
my %names = (Alice => 10, Bob => 15, Charlie => 20);

$names{Alice}; # 10            <- A scalar
@names{Alice}; # (10)          <- A slice (with only one key, this probably isn't what you want. There will be a warning.)
%names{Alice}; # ('Alice', 10) <- A key/index + value slice

$names{'Bob', 'Charlie'}; #                            <- An error (disabled syntax for an ancient feature.)
@names{'Bob', 'Charlie'}; # (15, 20)                   <- A slice
%names{'Bob', 'Charlie'}; # ('Bob', 15, 'Charlie', 20) <- A key/index + value slice
```

許可されてはいますが、読みやすさのために、異なる型の変数で同じ名前を共有しないことをおすすめします。
