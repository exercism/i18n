# 説明の補足

## ワード

`real`と`imaginary`というスロットを持つ`cmplx`タプルを定義します。スロットアクセサの`real>>`と`imaginary>>`は、タプルを定義すれば自動的に付いてきて、テストがそれぞれの要素を読み取るのに使うものです。

- `<cmplx> ( real imag -- cmplx )`は、複素数を生成します。
- `>cmplx ( pair -- cmplx )`は、`{ real imaginary }`から`cmplx`を作ります。
- `cmplx>pair ( cmplx -- pair )`は、`{ real imaginary }`を返します。
- `c+ ( a b -- c )`、`c- ( a b -- c )`、`c* ( a b -- c )`、`c/ ( a b -- c )`は、2つの複素数の間の四則演算です。
- `c-abs ( a -- |a| )`は、絶対値（実数）を求めます。
- `c-conj ( a -- a* )`は、複素共役を求めます。
- `c-exp ( z -- e^z )`は、複素指数関数を求めます。

Factorの`MATH:`ジェネリック（`+`、`-`、`*`、`/`）は、組み込みの数学階層に対してしかディスパッチしないため、この演習では、これらのジェネリックのメソッドではなく、専用のワード名を使います。

実数と複素数を混ぜた演算のテストは含まれていません。ここにある演算はすべて、2つの`cmplx`の値の間で行うものです。
