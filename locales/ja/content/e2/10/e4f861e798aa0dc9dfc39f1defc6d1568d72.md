# はじめに

[構造体][structs-and-classes]（一般には*struct*と呼ばれます）は、Swiftプログラムの主要な構成要素の1つです。
構造体を使うと、関連するプロパティ（データ）とメソッド（振る舞い）をまとめた独自の型を作れます。
実際、`Int`、`Double`、`Bool`、`String`、`Array`、`Dictionary`を含むSwiftの標準型は、すべて構造体として実装されています。

## 構造体の定義

構造体は、`struct`キーワードに続けて型名を書き、その定義を波括弧で囲んで定義します。
Swiftの慣習では、構造体の名前には`UpperCamelCase`を使います。

```swift
struct CharacterStats {
    var health = 0.0
    var speed = 0
    var strength = 0
}
```

## インスタンスの作成

構造体の定義は設計図です。
構造体の*インスタンス*を作るには、型名のあとに括弧（`()`）を書いてイニシャライザーを呼び出します。

```swift
var someStats = CharacterStats()
```

これで、定義に書かれたデフォルトのプロパティ値が設定されたインスタンスが作られます。

Swiftは構造体に対して、**メンバーワイズイニシャライザー**を自動で生成します。これを使うと、プロパティを名前で指定して初期化できます。

```swift
let customStats = CharacterStats(health: 100.0, speed: 6, strength: 18)
```

## プロパティへのアクセスと変更

インスタンスのプロパティには、*ドット記法*でアクセスしたり変更したりできます。

```swift
var stats = CharacterStats()

print(stats.health) // Prints 0.0

stats.health = 87.3
print(stats.health) // Prints 87.3
```

構造体は値型なので、インスタンスのプロパティを変更するには、インスタンス自体を`var`で宣言する必要があります。
インスタンスを`let`で宣言すると、そのプロパティはすべて不変になります。
