# ヒント

## 全般

- Goのスライスは0始まりです。スライスの最初のインデックスは`0`です。
- 組み込みの[`append`][append-builtin]関数は[`variadic`][variadic-gobyexample]です。
- 3つのドット記法を使うと、あるスライスの要素を別のスライスに追加できます。

```go
a := []int{1, 3}
b := []int{4, 2, 6}
c := append(a, b...)
fmt.Println(c)
// Output: [1 3 4 2 6]
```

## 1. 特定のカードを含むスライスを作成する

- あらかじめデータを入れたスライスを作成するには、スライスリテラル記法を使います：`s := []T{x1, x2, ..., xn}`。

## 2. 山札からカードを取得する

- スライスの`n`番目の要素を取得するには、[インデックスを使います][go-slices]。
- スライスに要素が存在するかどうかを確認するには、条件式を使い、インデックスを[スライスの長さ][len-builtin]と比較します。

## 3. 山札のカードを交換する

- スライスの`n`番目の要素を設定するには、[インデックスを使い][go-slices]、そこに新しい値を代入します。
- スライスの末尾に新しい要素を追加するには、`append`関数を使います。

## 4. 山札の一番上にカードを追加する

- スライスの先頭に要素を追加するには、元のスライスの要素を`value`引数のスライスに追加します。

## 5. 山札からカードを削除する

- スライスから要素を削除するには、`index`より後の部分をindexより前の部分に追加します。
