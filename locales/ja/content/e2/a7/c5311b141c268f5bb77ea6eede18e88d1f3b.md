# ヒント

## 全般

- [整数値][integers]は、1つ以上の連続した数字として定義できます。
- テストを実行したときに`panic:`エラーが表示される場合は、いずれかの関数を実装していない（どの関数かは表示されるはずです）か、定型コードをそのまま残しているためです。与えられたコードから`panic(...)`の行を削除し、実際の実装に置き換える必要があります。

## 1. 想定されるオーブンの加熱時間を分単位で定義する

- [定数][constants]を定義し、想定されるオーブンの加熱時間を分単位で代入する必要があります。
- `undefined: OvenTime`エラーが表示される場合は、定数が定義されているかもう一度確認してください。
- `invalid operation: got != tc.expected (mismatched types float64 and int)`エラーが表示される場合は、`OvenTime`に小数点を入れてしまったため、Goが型を浮動小数点数と推論した可能性が高いです。小数点を削除すれば、型は`int`と推論されます。
- `syntax error: non-declaration statement outside function body`エラーが表示される場合は、`const`キーワードを忘れている可能性が高いです。
- `syntax error: unexpected :=, expecting =`エラーが表示される場合は、変数のように`:=`を使って定数を代入しようとしている可能性が高いです。定数の代入には`:=`ではなく`=`を使います。

## 2. 残りのオーブン加熱時間を分単位で計算する

- 仮引数を1つ持つ[関数][functions]を定義する必要があります。
- 関数からは[整数を明示的に返す][return]必要があります。
- 関数の仮引数は[整数][integers]です。
- 以前に定義した別の関数を[呼び出す][calls]ことができます。
- [引き算の数学演算子][operators]を使って値を引くことができます。

## 3. 準備にかかる時間を分単位で計算する

- 仮引数を1つ持つ[関数][functions]を定義する必要があります。
- 関数からは[整数を明示的に返す][return]必要があります。
- 関数の仮引数は[整数][integers]です。
- [掛け算の数学演算子][operators]を使って値を掛けることができます。

## 4. 経過した作業時間を分単位で計算する

- 仮引数を2つ持つ[関数][functions]を定義する必要があります。
- 関数からは[整数を明示的に返す][return]必要があります。
- 関数の仮引数は[整数][integers]です。
- 以前に定義した別の関数を[呼び出す][calls]ことができます。
- [足し算の数学演算子][operators]を使って値を足すことができます。
