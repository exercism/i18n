# デバッグ

Redスクリプトからの出力は、テストを実行するたびにすべてコンソールに表示されます。`print`を使えば、好きなものを表示できます。たとえば、単語の値なら次のように書きます：

```red
print ["x =" x]
```

また、`probe`関数もとても便利です。評価されると、まず入力を評価し、その型がわかる形で結果を表示してから、その結果を返します。つまり、ほとんどの場合「透過的」なので、式の途中にそのまま入れておけます：

```red
x: 10
y: probe x + 5
```

値の型を確認したいときには、`type?`という関数（そう、名前に疑問符が付いています！）が役立つこともあります：

```red
print ["x type:" type? x]
```

さらに高度なデバッグ手法も、[RedのWikiにまとめられています](https://github.com/red/red/wiki/%5BDOC%5D-Debugging)。
