# 説明

この演習では、大のスポーツファンであり、NBAバスケットボールに情熱を燃やし始めたばかりです。
NBAバスケットボールはまだ初心者なので、NBAの歴史を深く掘り下げ、チームやコーチ、その勝敗の成績を追いかけながら、それらを互いに比較しています。

まだお気に入りのチームがないので、特定のチームを応援すべきかどうかを判断するアルゴリズムも開発します。
独自の_チーム応援_アルゴリズムを開発するための、7つのタスクがあります。

## 1. モデルを定義する

次の2つのフィールドをこの順序で持つレコードとして、`Coach`型エイリアスを定義します。

- `name`: コーチの名前。型は`String`。
- `formerPlayer`: コーチが元選手かどうかを示します。型は`Bool`。

次の2つのフィールドをこの順序で持つレコードとして、`Stats`型エイリアスを定義します。

- `wins`: 勝利数。型は`Int`。
- `losses`: 敗戦数。型は`Int`。

次の3つのフィールドをこの順序で持つレコードとして、`Team`型エイリアスを定義します。

- `name`: チームの名前。型は`String`。
- `coach`: チームのコーチ。型は`Coach`。
- `stats`: チームの成績。型は`Stats`。

## 2. チームを作成する

チームという概念を持つサードパーティのコードと連携したいのですが、そのコードは入力を異なる順序で渡してきます。
次のシグネチャ`String -> Stats -> Coach -> Team`を持つ`createTeam`関数を追加します。

## 3. コーチを交代させる

NBAのオーナーはせっかちなので、チームの成績が悪いとコーチが交代させられることがよくあると気づきました。
新しいコーチとチームを入力として受け取り、新しいコーチに置き換えたチームを返す`replaceCoach`関数を実装します。

```elm
let
    coach = { name = "Larry Bird", formerPlayer = True }
    stats = { wins = 58, losses =  24 }
    team = { name = "Indiana Pacers", coach = coach, stats =  stats }
    newCoach = { name = "Isiah Thomas", formerPlayer = True }
in
replaceCoach newCoach team
--> { name = "Indiana Pacers"
--  , coach = { name = "Isiah Thomas", formerPlayer = True }
--  , stats = { wins = 58, losses = 24 } }
```

## 4. チームを応援すべきか確認する

将来的には、チームを応援すべきかどうかを判断する複雑なアルゴリズムを考案するつもりですが、最初の試みとしては、勝利数が敗戦数を上回るチームを応援することにします。

この関数を他の場面でも再利用できるようにしたいので、型シグネチャに拡張可能なレコードを使い、該当するフィールドを持つどんなレコードでも受け入れられるようにします。
関数をできるだけ簡潔に保つために、パターンマッチングを使って関数の入力から`stats`を取り出します。
チームを受け取り、そのチームを応援すべきなら`True`を、そうでなければ`False`を返す`rootForTeam`関数を実装します。

```elm
let
    spursCoach = { name = "Gregg Popovich", formerPlayer =  False }
    spursStats = { wins = 56, losses = 26 }
    spursTeam = { name = "San Antonio Spurs", coach = spursCoach, stats = spursStats }
in
rootForTeam spursTeam
--> True
```
