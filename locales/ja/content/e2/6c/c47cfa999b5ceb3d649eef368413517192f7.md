# ビットについて

2進数は、最終的にはCPUやRAMの中のトランジスタに直接対応しています。それぞれのトランジスタが「オン」なのか「オフ」なのか、ということです。

低レベルな操作は、口語では「bit-twiddling」と呼ばれ、特にシステム言語では重要です。

Kotlinのような高水準言語では、こうした詳細のほとんどが通常は抽象化されています。
しかし、基本的なビット操作の範囲は[利用できます][ref-bitwise]。

~~~~exercism/note
人が読める2進数の出力を見るには、以下の例のほとんどすべてを[`Integer.toBinaryString()`][web-binstring]関数で包むか、`toString(radix = 2)`で変換する必要があります。
 
これは視覚的に邪魔になるため、この関数のほとんどの登場箇所は省略してあり、結果は`0b`表記で示しています。

## ビットシフト演算

`Int`型や`Long`型は、符号付きでも符号なしでも、1と0の文字列として表現でき、ビットの並びとして操作できます。

意外かもしれませんが、`Byte`型や`Short`型は、Kotlinのほとんどのビット演算には対応していません。
以下の例はすべて32ビット整数（`Int`または`UInt`）を使っています。

```kotlin
val ns = 0b111  // 7 decimal
Integer.toBinaryString(ns)  // => "111"
```

ビットシフトは、指定した桁数だけすべてを左または右に動かします。一方の端からはビットがこぼれ落ち、もう一方の端は0または1で埋められます。

- `shl`による左シフト：0で埋める。
- `shr`または`ushr`による右シフト：正の数では0で埋める（負の数については後のセクションを参照）。

```kotlin
val ns = 0b111  // 7 decimal
ns shl 1  // => 0b1110, decimal 14
ns shr 1  // => 0b11, decimal 3
ns ushr 1  // => 0b11

val nu: UInt = 0b111u  // 7 unsigned
nu shr 1  //  => 0b11
```

左シフトするたびに値は2倍になり、右シフトするたびに半分になります（切り捨てを伴います）。これは10進数で表すとよりはっきりわかります。

```kotlin
3 shl 2  // => 12
24 shr 3 // => 3
```

このようなビットシフトは「正規の」算術よりもはるかに速く、そのためこのテクニックは低レベルのコーディングでとても人気があります。

### 負の整数のビットシフト

_負の整数_では、もう少し注意が必要です。

負の値は[2の補数][wiki-2complement]の形で保存されるため、いちばん左のビットは1になります。左シフトなら問題ありませんが、右シフトするとき、いちばん左のビットはどう埋めるのでしょうか？

```kotlin
val ns = -0b111  // => 0b11111111111111111111111111111001

// shift left: simple
ns shl 1  // => 0b11111111111111111111111111110010, decimal -14

// shift right: preserves sign bit
ns shr 1  // => 0b11111111111111111111111111111100, decimal -4

// unsigned shift right: left-pads with zeros
ns ushr 1 // => 0b01111111111111111111111111111100, decimal 2147483644
```

[`shr`][ref-shr]演算子は[算術シフト][wiki-arithmetic]を行い、符号ビットを保持します。

[`ushr`][ref-ushr]演算子は[論理シフト][wiki-logical]を行い、その数が符号なしであるかのように0で埋めます。

## ビットごとの論理演算

[真偽値の概念][concept-booleans]では、`&&`（and）、`||`（or）、`!`（not）という演算子を真偽値に使うことを見ました。

2つの整数のビットを比較するための、同じはたらきをする`and`、`or`、`xor`（[排他的論理和][wiki-xor]）演算子と、すべてのビットを反転させる`inv`（反転）関数があります。

```kotlin
0b1011 and 0b0010 //  bit is 1 in both numbers
// => 0b0010

0b1011 or 0b0010 // bit is 1 in at least one number
// => 0b1011

0b1011 xor 0b0010 // bit is 1 in exactly one number, not both
// => 0b1001

0b1011.inv() // flip all bits (in a 32-bit signed Int)
// => 0b11111111111111111111111111110100
```
