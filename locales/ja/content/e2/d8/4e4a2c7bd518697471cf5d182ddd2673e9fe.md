# 説明の補足

## 出力形式

それぞれの国籍は、1文字で表します。（`E`＝`Englishman`、`J`＝`Japanese`、`N`＝`Norwegian`、`S`＝`Spaniard`、`U`＝`Ukrainian`）

## レジスター

| レジスター | 用途 | 型 | 説明 |
| -------- | --------- | ------- | ---------------------------- |
| `$v0`    | 出力    | バイト    | 水を飲む人の国籍 |
| `$v1`    | 出力    | バイト    | シマウマを飼っている人の国籍   |
| `$t0-9`  | 一時    | 任意     | 一時的な保存用        |
