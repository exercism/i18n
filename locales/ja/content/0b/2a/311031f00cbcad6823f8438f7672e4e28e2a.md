# 指示の補足

## トラック固有の指示

この演習では、`robot`という名前の**ロケール**を定義する必要があります。このロケールでは、**名詞**である`position`と`direction`、そして**動詞**である`move`を定義します。

- `robot`の`create`動詞は、初期の位置と方向をボックスの配列として受け取ります。
    
    ```j
      r=. (0 0;'north') conew 'robot'
    ```
- `move`は、作成した**インスタンス**にある`position`と`direction`の値を更新します。
    ```j
      r=. (0,0;'north') conew 'robot'
      
      NB. initial state
      NB. ====================================
      position__r
        0 0
      direction__r
        north
      
      NB. new states after `move` is executed 
      NB. ====================================
      move__r 'LA'
      position__r
        _1 0
      direction__r
        west      
    ```
