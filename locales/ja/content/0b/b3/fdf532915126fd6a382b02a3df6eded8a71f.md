# はじめに

Common Lispでは、多くの言語と同様に、数値にはいくつかの種類があります。もっとも基本的なもののうち2つを紹介します。

## 整数

多くの言語と同様に、Common Lispには整数があります。
これらは小数点を含まない整数です（`-6`、`0`、`25`、`1234`など）。

Common Lispでは、整数の大きさに制限がありません。
整数はいくらでも大きくできます（負の場合はいくらでも小さくできます）。

一般的に、整数だけを扱う場合は、整数を使うのがおすすめです。浮動小数点数では多くの計算を繰り返すうちに精度が失われますが、整数にはその心配がありません。

## 浮動小数点数

多くの言語と同様に、Common Lispには浮動小数点数があります。
これらは小数点を含む、小数または整数です（`3.14`、`-1.7`、`99.99`、`2048.0`など）。

## 算術

Common Lispでは、ほとんどの演算で標準的な算術演算子を使いますが、より見慣れた「中置記法」ではなく「前置記法」を使う点がやや独特です。

視覚的に見ると次のようになります。

```lisp
;; Infix-notation (non-lisp languages)
1 + 2 + 3 + 4 + 5 ; => 15
;; Prefix-notation (lisp languages)
(+ 1 2 3 4 5)     ; => 15
```

前置記法では、`2 + 2`のような演算が、少し見慣れない`(+ 2 2)`の形になりますが、複数の数値を一度に扱うのはずっと簡単になります。

### 基本的な算術

Common Lispには、一般的な関数がすべてそろっています。足し算、引き算、掛け算、割り算には、`+`、`-`、`*`、`/`を使います。

割り算を考えるとき、割り算の余りを知りたいことがあります。それには`mod`関数（moduloの略）を使います。これは数値と割る数を引数に取ります。

```lisp
(mod 4 2)  ; => 0
(mod 2 4)  ; => 2
(mod 10 3) ; => 1
```

### 数値の比較

最後に、`=`（等しい）、`/=`（等しくない）、`>=`（以上）などの関数を使って、数値を比較すると便利です。

これらの比較が真の場合（`(= 1 1)`のように）は`T`を返し、真でない場合（`(> 0 1)`のように）は`NIL`を返します。
