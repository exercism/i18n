# 無視

## jqの追加コマンドラインオプション

テストでは、`jq`にいつもとは違うオプションが付いていることに気づくでしょう。

```sh
run jq -s -R -c -f flower-field.jq << 'END_INPUT'
```

これらは何でしょうか？

- `-s`

  これは「slurp」モードです。
  入力をJSONオブジェクトのストリームとして扱う代わりに、
  入力全体を1つの配列にまとめて読み込みます。

  ```sh
  $ seq 5 | jq -c '.'
  1
  2
  3
  4
  5
  $ seq 5 | jq -s -c '.'
  [1,2,3,4,5]
  ```

- `-R`

  `-r`はすでに見たことがあるかもしれません。これは「生の」文字列（引用符なし）を出力するためのものです。
  `-R`はその反対で、
  入力の各行を1つの文字列として扱います。

  2つの例を見てみましょう。

  ```sh
  $ seq 5 | jq -R -c .
  "1"
  "2"
  "3"
  "4"
  "5"

  $ echo 42 | jq '. * 2'      # input is a JSON number
  84
  $ echo 42 | jq -R '. * 2'   # input is a JSON string
  "4242"
  ```

この2つのオプションを一緒に使っても、結果は文字列の配列には*なりません*。
行末の改行も含めて、入力全体が1つの文字列になります。

```sh
$ seq 5 | jq -s -R -c .
"1\n2\n3\n4\n5\n"
```

これをどう扱うかも、この演習のやりがいのひとつです。
