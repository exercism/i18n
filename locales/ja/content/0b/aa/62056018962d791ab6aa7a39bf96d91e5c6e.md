# プレースホルダー

## AWKの新しい概念

これは、解答が"main"スクリプトではない最初の演習です。
目標は、他のawkプログラムに読み込ませる関数のライブラリを書くことです。
この演習では、興味深い新しい概念をいくつか見ていきます。

以下で"(gawk)"というタグが付いているセクションは、GNU awk固有の拡張機能です。

### ファイルから読み込む

この演習では、データをメインの入力ストリームからではなく、ファイルから読み込みます。 
Gnu awkマニュアルの[`getline`][getline]について、特に`Getline/File`と`Getline/Variable/File`の形式を読んでみましょう。

### 配列についてもう少し

この解答を実装するには、2次元配列が使えるかもしれません。
GNU awkには、それを表す方法が2つあります。

* [多次元配列][multi]
* [配列の配列][a-of-a] <sup><sup>(gawk)</sup></sup>

### インクルードファイル <sup><sup>(gawk)</sup></sup>

テストファイルにある[`@include`][d-include]ディレクティブに注目してください。  
これは、指定したファイルを読み込んで評価するようgawkに指示します。

### 名前空間 <sup><sup>(gawk)</sup></sup>

awkの変数はすべてグローバルです（関数の仮引数だけは、その関数内でローカルです）。
特にサードパーティのライブラリを読み込むときは、名前が衝突する可能性が高くなります。 
[名前空間][namespaces]は、変数をどこに保存するかを区切る仕組みです。
演習のファイルにある[`@namespace`][d-namespace]ディレクティブに注目してください。

デフォルトの名前空間の名前は"awk"です。 
デフォルトの名前空間があることで、別の名前空間にある関数の中から、awkの組み込み関数を呼び出せます。

### 関数の仮引数はどのように渡されるか

配列の仮引数は**参照渡し**で渡されます。
関数内で加えられた配列の変更は、呼び出し側からも見えます。

配列以外の仮引数は**値渡し**で渡されます。

_型なし_の仮引数については、関数がそれをどう扱うかによって変わります。
- 関数がそれを配列として初期化すれば、参照渡しの仮引数になります。
- 関数がそれをスカラー値（数値または文字列）として初期化すれば、参照にはなりません。

詳しくは、マニュアルの[Passing Function Arguments by Value Or by Reference][pass-by]に書かれています。

#### ローカル変数

関数スコープの（ローカルな）変数は、「値渡し」の仮引数を使うと作れます。
関数に渡す値が、並んでいる仮引数の数より少なくてもエラーにはなりません。余った仮引数は、使われるまで「型なし」のままです。
これらには、関数内でスカラー値を代入でき、その値はグローバルな名前空間には保存されません。

- 仮引数にスカラー値を代入すると、それはその関数内でローカルになります。
- 仮引数のリストに**ない**変数にスカラーを代入すると、その変数はグローバルになります。

慣例として、関数のシグネチャでは、受け取る仮引数が先に並び、そのあとに空白を挟んでローカルな仮引数が続きます。
例を示します。

```awk
function add(a, b,    total) {
    # here, `typeof(total)` is "untyped"
    total = a + b
    # now, `typeof(total)` is "number"
    return total
}

BEGIN {
    sum = add(5, 10)
    print sum             # 15
    print typeof(total)   # untyped, meaning "total" is unused in this scope
}
```
