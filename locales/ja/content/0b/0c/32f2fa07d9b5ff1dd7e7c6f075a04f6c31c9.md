# 整数

整数は、`{..., -2, -1, 0, 1, 2, ...}`という集合に属する、小数部分を持たない数です。整数の最大値と最小値は、PHPが動作するシステムによって決まります。通常、現代のほとんどのシステムでは、整数は64ビットの値です。つまり、`-9_223_372_036_854_775_808`から`9_223_372_036_854_775_807`まで（両端を含む）を表すことができます。

```php
<?php

$a = 1234;
$a = 1_234_567;
```

整数リテラルの値は、基数の接頭辞を使うと、10進数以外でも書くことができます。

```php
<?php

$a = 0123; // octal number (equivalent to 83 decimal)
$a = 0o123; // octal number (as of PHP 8.1.0)
$a = 0x1A; // hexadecimal number (equivalent to 26 decimal)
$a = 0b11111111; // binary number (equivalent to 255 decimal)
```

> PHPの[ドキュメント][syntax]からの引用です。

[syntax]: https://www.php.net/manual/en/language.types.integer.php#language.types.integer.syntax
