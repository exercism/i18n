# はじめに

Rの`list`は項目を順序付けて集めたもので、`vectors`とはいくつかの点で異なります：

- 要素は異なる型を持つことができます（例：`numeric`と`character`を混ぜる）。
- 要素は複雑な構造を持つことができます（例：ベクトル、他の`list`など）。
- 要素にアクセスするための構文が少し異なります。

他の言語とのたとえは正確ではありません。
Rの`list`はPythonの辞書にいくらか似ていますが、`list`は順序を持ち、数値インデックスでアクセスできます。
Cの`struct`にもいくらか似ていますが、`list`は実行時に簡単に拡張できます。

## `list`の作成

要素に名前（よく「タグ」と呼ばれます）を付けることは、ベクトルよりも`list`でよく行われます：

```R
list(x = 5.3, y = 4.2, color = "blue")
$x
#> [1] 5.3

$y
#> [1] 4.2

$color
#> [1] "blue"
```

ただし、タグは省略可能で、その場合Rは単にインデックス番号を使います：

```R
list(5.3, 4.2, "blue")
#> [[1]]
#> [1] 5.3

#> [[2]]
#> [1] 4.2

#> [[3]]
#> [1] "blue"
```

## `list`の要素へのアクセス

これには3つの方法があり、それぞれ異なる場面で役立ちます。

### 1. `$tag`記法を使う

タグ名を事前に知っている場合によく使います。

```R
point <- list(x = 5.3, y = 4.2, color = "blue")
point$x
#> [1] 5.3
point$color
#> [1] "blue"
```

### 2. `[[tag]]`記法を使う

タグ名を実行時に選べるという利点があります。
角括弧が2つ重なっていることに注意してください。

```R
want <- "y"
point[[want]] # same as point$y
#> [1] 4.2
```

### 3. 位置インデックスを使う

`list`にタグがあってもなくても使えます。
ここでも、角括弧を2つ重ねます。

```R
point[[3]] # same as point$color
#> [1] "blue"
```

## 要素の追加と削除

簡単です。要素に代入すると、すでに存在すれば変更され、新しければ挿入されます。

```R
point$color <- "red"
point[[trust]] <- TRUE
str(point)
#> List of 4
#>  $ x    : num 5.3
#>  $ y    : num 4.2
#>  $ color: chr "red"
#>  $ trust: logi TRUE
```

削除するには、不要な要素に`NULL`を代入します。

```R
point$trust <- NULL
str(point)
#> List of 3
#>  $ x    : num 5.3
#>  $ y    : num 4.2
#>  $ color: chr "red"
```
