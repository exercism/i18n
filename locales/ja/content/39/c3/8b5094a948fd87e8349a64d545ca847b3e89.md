# 指示

最初のN個の自然数について、和の平方と平方の和の差を求めてください。

最初の10個の自然数の和の平方は
(1 + 2 + ... + 10)² = 55² = 3025です。

最初の10個の自然数の平方の和は
1² + 2² + ... + 10² = 385です。

したがって、最初の10個の自然数の和の平方と、最初の10個の自然数の平方の和との差は、3025 - 385 = 2640になります。

この問題の効率的な解法を、基本原理から自分で導き出す必要はありません。調べることは認められていますし、むしろ推奨します。
問題に最適なアルゴリズムを見つけることは、ソフトウェアエンジニアリングにおける重要なスキルです。
