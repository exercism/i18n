# はじめに

## alias

同じプロジェクト内の異なるElixirモジュール間でコードを共有するには、外部のモジュールをそのフルネームで参照する必要があります。でも、その名前が長すぎたり紛らわしかったりしたらどうでしょう？

特殊形式の`alias`を使うと、外部モジュールを参照するときの名前を短くしたり変更したりできます。引数なしで使うと、モジュール名は最後の部分だけに切り詰められます。たとえば、`MyApp.Logger.Settings`は`Settings`になります。`:as`オプションを使えば、独自の名前を指定できます。

通常、エイリアスはモジュール定義の先頭に追加します。

```elixir
defmodule Square do
  alias Integer, as: I

  def area(a), do: I.pow(a, 2)
end
```

## import

特殊形式の`import`を使うと、外部モジュールの名前を使わずに、そのモジュールの関数を利用できます。

外部モジュール全体をインポートすると、既存のローカル関数と衝突する可能性があります。これを避けるには、`:except`と`:only`の2つのオプションがあります。どちらもキーワードリストを想定しており、キーは関数名、値はその関数のアリティです。

通常、インポートはモジュール定義の先頭に追加します。

```elixir
defmodule Square do
  import Integer, only: [pow: 2]

  def area(a), do: pow(a, 2)
end
```
