# 説明

ルシアンの恋人が帰宅途中なのに、彼は記念日のディナーをまだ作っていません！

この演習では、ルシアンがお気に入りの料理本のレシピで絶品ラザニアを作るのを手伝うコードを書いていきます。

ラザニアの調理にかかる時間に関係する4つのタスクがあります。

## 1. オーブンに入れておくべき時間（分）を定義しましょう

ラザニアをオーブンに入れておくべき時間（分）を表す`EXPECTED_MINUTES_IN_OVEN`定数を定義しましょう。この定数はエクスポートする必要があります。料理本によると、オーブンに入れておくべき時間（分）は`40`です。

## 2. オーブンでの残り時間（分）を計算しましょう

ラザニアをオーブンに入れていた実際の時間（分）を_入力_として受け取り、前のタスクの**オーブンに入れておくべき時間（分）**をもとに、ラザニアをあと何分オーブンに入れておく必要があるかを_返す_`remainingMinutesInOven`関数を実装しましょう。

```javascript
remainingMinutesInOven(30);
// => 10
```

## 3. 準備時間（分）を計算しましょう

ラザニアに追加した層の数を_入力_として受け取り、各層の準備に2分かかると仮定して、ラザニアの準備に何分かかったかを_返す_`preparationTimeInMinutes`関数を実装しましょう。

```javascript
preparationTimeInMinutes(2);
// => 4
```

## 4. 合計の作業時間（分）を計算しましょう

_2つの入力_を受け取る`totalTimeInMinutes`関数を実装しましょう。`numberOfLayers`は、ラザニアに追加した層の数です。`actualMinutesInOven`は、ラザニアをオーブンに入れておいた時間（分）です。この関数は、ラザニアの調理に合計で何分取り組んだかを_返します_。これは、準備時間（分）と、その時点でラザニアがオーブンに入っていた時間（分）の合計です。

```javascript
totalTimeInMinutes(3, 20);
// => 26
```
