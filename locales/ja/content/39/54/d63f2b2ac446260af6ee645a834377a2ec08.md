# 概要

PHPには、`while`などの繰り返し制御構造がいくつか用意されています。`while`文の基本形は次のとおりです。

```php
while (expr) {
  // statements
}
```

式（_expr_）が真とみなされる値に評価されるあいだ、ループ内の文が繰り返し実行されます。最初の繰り返しの前に式（_expr_）が`false`に評価されると、その文は一度も実行されません。

別の方法として、`do-while`ループを使うこともできます。`do-while`ループは、式（_expr_）を評価する前に、ループ内の文を一度実行します。

```php
do {
  // statements
} while (expr);
```
