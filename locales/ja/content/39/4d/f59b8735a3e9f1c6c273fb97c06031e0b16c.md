# Configletによるドキュメント生成

[configlet](/docs/building/configlet)の副次的な用途は、ドキュメントの生成です。

## 使い方

`generate`コマンドを使うと、テンプレートからinstructions/introductionsのドキュメントを生成できます。

```
configlet [global-options] generate

Global options:
  -h, --help                   Show this help message and exit
      --version                Show this tool's version information and exit
  -t, --track-dir <dir>        Specify a track directory to use instead of the current directory
  -v, --verbosity <verbosity>  The verbosity of output. Allowed values: q[uiet], n[ormal], d[etailed]
```

## ドキュメント

configletが生成できるドキュメントは次のとおりです。

### ドキュメント：概念演習のintroduction.mdファイル

それぞれの[概念演習](/docs/building/tracks/concept-exercises)には、[`introduction.md`ファイル](/docs/building/tracks/concept-exercises#docsintroductionmd)があります。また、各演習には任意で[`introduction.md.tpl`ファイル](/docs/building/tracks/concept-exercises#docsintroductionmdtploptional)を持たせることができます。

テンプレートファイルは通常のMarkdownファイルと同じように扱いますが、1つだけ追加の機能があります。プレースホルダーを指定できるのです。次のプレースホルダーが使えます。

- `%{concept:<slug>}`：その概念の[`introduction.md`ドキュメント](/docs/building/tracks/concepts#fileintroductionmd)を参照します

configletが、概念演習に`introduction.md.tpl`ファイルがあることを検出すると、そこから`introduction.md`ファイルを生成します。生成されるintroductionの内容はテンプレートと同じです。ただし、プレースホルダーは、それが参照するドキュメントの内容に置き換えられます。

### ドキュメント：実践演習のintroduction.mdファイル

configletが、実践演習が`introduction.md`ファイルを持つ[Problem Specificationsの演習](https://github.com/exercism/problem-specifications/)を実装していることを検出すると、その実践演習の`.meta/introduction.md`ファイルを、Problem Specificationsの演習の`introduction.md`ファイルと同期します。

### ドキュメント：実践演習のinstructions.mdファイル

configletが、実践演習が[Problem Specificationsの演習](https://github.com/exercism/problem-specifications/)を実装していることを検出すると、その実践演習の`.meta/instructions.md`ファイルを、Problem Specificationsの演習の`instructions.md`ファイルと同期します。`instructions.md`ファイルが見つからない場合は、`description.md`ファイルと同期します。

### ドキュメント：実践演習の.meta/config.jsonファイル

configletが、実践演習が[Problem Specificationsの演習](https://github.com/exercism/problem-specifications/)を実装していることを検出すると、Problem Specificationsの演習の`metadata.yml`ファイルにある`source`キーと`source_url`キーを、その実践演習の`.meta/config.json`ファイルにある`source`プロパティと`source_url`プロパティに同期します。
