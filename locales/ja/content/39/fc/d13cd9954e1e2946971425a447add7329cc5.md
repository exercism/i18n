# はじめに

エラーは、プログラムやコードの一部に間違いや予期しないことが起きたときに、それを知らせるのに役立ちます。

エラーはJavaScriptのオブジェクトです。

このオブジェクトの主なプロパティは`message`です。

```javascript
const error = new Error('Oops, something went wrong');

console.log(error.message);
// => "Oops, something went wrong"
```

`throw`という構文を使うと、エラーをスローできます。

```javascript
throw new Error('Oops');
```

`Error`がスローされると、その時点の実行は止まり、コールスタックの最初のcatchブロックから再開します。

```javascript
try {
  throw new Error('Oops');
} catch (error) {
  console.log(error.message);
  // => "Oops"
}
```

JavaScriptの他のクラスと同じように、`extends`キーワードを使うと`Error`を継承してカスタムエラーを作ることができます。
`instanceof`を使うと、捕まえたエラーが`Error`の特定のサブクラスのインスタンスかどうかを確認できます。

```javascript
class CustomError extends Error {}

try {
  // ... Code that may throw an error
} catch (error) {
  if (error instanceof CustomError) {
    console.log('The error thrown is an instance of the CustomError');
  }
}
```
