# 説明

友人が、**Gross Store**という古い卸売店を営んでいます。

この名前は、店で扱う商品の量に由来します。すべて[グロス単位][gross-unit]で売られているからです。

友人は、店のための販売時点管理（POS）システムの実装を依頼してきました。

**まずは、そのためのプロトタイプを作ります。**

**プロトタイプでは、数量だけを記録します。**

友人が、参考になる単位の一覧を渡してくれました：

| 単位               | 数値 |
| ------------------ | ----- |
| quarter_of_a_dozen | 3     |
| half_of_a_dozen    | 6     |
| dozen              | 12    |
| small_gross        | 120   |
| gross              | 144   |
| great_gross        | 1728  |

## 1. 単位をプログラムに保存する

単位を使うには、まずプログラムに単位を保存する必要があります。

```rust
let units = units();
// Felt252Dictionary with entries like { 'dozen': 12 }
```

## 2. 新しい顧客の伝票を作成する

顧客の新しい（空の）伝票を作成する関数を実装する必要があります。

```rust
let bill = new_bill();
// Empty Felt252Dictionary
```

## 3. 顧客の伝票に商品を追加する

これを実装するには、次のことを行います：

- 指定された`unit`が`units`マップにない場合は、`false`を返します。
- そうでなければ、商品名をキーとして顧客の`bill`に商品を追加し、`true`を返します。
- 商品がすでに伝票にある場合は、指定された`unit`に対応する数だけ数量を増やします。

```rust
let bill = new_bill();
let units = units();
let ok = add_item(bill, units, 'carrot', 'dozen');
println!(ok);
// Output: true (since dozen is a valid unit)
```

> なお、戻り値の型は`bool`です。

## 4. 顧客の伝票から商品を削除する

これを実装するには、次のことを行います：

- 指定された商品が伝票に**ない**場合は、`false`を返します。
数量が0の商品は、伝票にないものとみなします。
- 指定された`unit`が`units`マップにない場合は、`false`を返します。
- 新しい数量が0未満になる場合は、`false`を返します。
- 新しい数量が0の場合、その商品は`bill`から削除されたものとみなされるので、`true`を返します。
- そうでなければ、その商品の数量を減らし、`true`を返します。

```rust
let bill = new_bill();
let units = units();
let ok = remove_item(bill, units, 'carrot', 'dozen');
println!(ok);
// Output: false (because there are no carrots in the bill)
```

> なお、戻り値の型は`bool`です。

## 5. 顧客の伝票にある特定の商品の数量を返す

```rust
let mut bill: Felt252Dict<u32> = Default::default();
bill.insert('carrot', 12);
bill.insert('grapes', 3);
let qty = get_item(bill, 'carrot');
println!(qty);
// Output: 12
```

> なお、戻り値の型は`u32`です。
