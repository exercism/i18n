# 説明

ネットボールの練習はラップから始まります。コーチはラップを重ねるごとに少しずつ長くしていきます。1本目は100メートル、2本目は110メートル、3本目は120メートル、といった具合で、毎回10メートルずつ増えていきます。

3つのタスクはすべて`WARM_UP_LAPS`クラスに書きます。

## 1. 合計でどれくらい？

ラップの本数が与えられたとき、走る合計距離を求めます。

```sather
WARM_UP_LAPS::distance_run(3)
-- => 330
```

これは100 + 110 + 120です。ラップが0本なら、距離も0メートルです。

## 2. ある距離に届くには何本？

メートル単位の距離が与えられたとき、合計が少なくともその距離に届くまでに、何本のラップが必要でしょうか？

```sather
WARM_UP_LAPS::laps_to_reach(330)
-- => 3
WARM_UP_LAPS::laps_to_reach(331)
-- => 4
```

0メートルなら、ラップは1本もいりません。

## 3. 最初に長くなるラップはどれ？

メートル単位の距離が与えられたとき、*それ自体*がその距離より長くなる最初のラップはどれでしょうか？ラップ1は100メートル、ラップ2は110メートル、と続きます。

```sather
WARM_UP_LAPS::first_long_lap(115)
-- => 3
```

ラップ3は120メートルで、115を超える最初のラップです。
