# はじめに

Common Lispのハッシュテーブルは、連想データを格納するためのデータ構造です。
キー（任意のオブジェクト）を値（これも任意のオブジェクト）に対応付けます。
他の言語では、この概念をマップ・辞書・ハッシュなどと呼ぶことがあります。

## ハッシュテーブルの作成

ハッシュテーブルは`make-hash-table`関数で作成できます。

`(make-hash-table) ; => #<HASH-TABLE :TEST EQL :COUNT 0 {10024AD2B3}>`

（ハッシュテーブルがどう表示されるかは処理系によって異なるため、お使いのREPLでは違って見えることもあります。）

## キーによる値の取得

ハッシュテーブルからキーで値を取得するには、`gethash`関数を使います。

```lisp
*h* ; => #<HASH-TABLE :TEST EQL :COUNT 3 {10024AD2B3}>`
(gethash :foo *h*) ; => :bar
                   ;    T
```

`gethash`は[複数の値][concept-multiple-values]を返します。これについては別の概念で説明します。

## 値の挿入

ハッシュテーブルに値を挿入するには、次のように`gethash`と一緒に`setf`を使います。

`(setf (gethash :foo *hash-table*) :bar) : => :bar`

これは、ハッシュテーブル`*hash-table*`のキー`:foo`の値を`:bar`に変更します。戻り値はその値です。

`setf`の使い方は別の概念で説明します。
