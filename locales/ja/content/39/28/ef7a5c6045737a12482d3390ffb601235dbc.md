# 数値

`INT`は、Satherで整数を表す型で、`0`、`7`、`-3`のような値に使います。整数を返すルーチンは、コロンのあとにそのことを示します。テキストを返すルーチンが`STR`と書くのと同じです。

```sather
   goals : INT is
      return 42;
   end;
```

ルーチンは**入力**を受け取ることができます。入力とは、ルーチンを呼び出すときに渡す値のことです。それぞれの入力には名前を付け、型を指定します。どちらもルーチン名のあとの括弧（`()`）の中に書きます。

```sather
   total(first : INT, second : INT) : INT is
      return first + second;
   end;
```

2つの入力が同じ型なら、まとめて名前を付けられます。

```sather
   total(first, second : INT) : INT is
```

呼び出すときは、値を括弧の中に書きます。

```sather
SCORES::total(3, 4)     -- this is 7
```

算術演算子は`+`、`-`、`*`、`/`、`%`の5つです。

2つの`INT`に対する`/`は**整数除算**です。小数にはならず、余りは切り捨てられます。

```sather
7 / 2      -- 3, not 3.5
```

`%`は、その割り算で余った分を返します。

```sather
7 % 2      -- 1
```

この2つは組み合わせて考えます。`7`は`2`が`3`つで、`1`余る、という関係です。
