# タプル

Elmのタプルは、2つか3つの値を保持でき、それぞれの値はどんな型でもかまいません。
Elmでは、タプルは主に単純な一時的な型に使われます。
そのため、タプルが持てる値は最大3つで、さらに後押しするかのように、2つの値のための便利な関数しか用意されていません。
より複雑なデータには、レコードに切り替えるのが一番です。
よくある使い方は、関数から複数の値を返す必要がある場合です。
タプルのフィールドには名前がなく、分割代入か位置によってアクセスします。

[タプルの簡潔な入門][tuples-concise]を読むことができます。
[より詳しい入門][tuples-in-depth]もあり、[TupleモジュールのAPIドキュメント][tuple-core]にはコード例と詳しい解説が載っています。

## 宣言

タプルの型は括弧（`()`）で作成し、要素の型はカンマで区切ります。

```elm
type alias IntStringTuple = (Int, String)
```

### 作成

タプルは括弧で作成し、要素はカンマで区切ります。

```elm
aTuple : IntStringTuple
aTuple = (123, "elements can be of differing types")
```

`Tuple.pair`を使って、2つの値を持つタプルを作ることもできます。

```elm
anotherTuple : (String, String)
anotherTuple = Tuple.pair "this time it's" "two strings"
    --> ("this time it's", "two strings")
```

### アクセス

位置によってタプルの値にアクセスする関数もあり、`Tuple.first`と`Tuple.second`です。

```elm
Tuple.first aTuple
    --> 123

Tuple.second aTuple
    --> "elements can be of differing types"
```

タプルは、タプルのパターンマッチングを使って束縛の中で_分割代入_できます。
分割代入は、let式、関数宣言、case文の中で行えます。

```elm
repeatString : (Int, String) -> Bool
repeatString aTuple =
let
    (aNumber, aString) = aTuple
in
    String.repeat aNumber aString

repeatStringAgain : (Int, String) -> Bool
repeatStringAgain (aNumber, aString) = String.repeat aNumber aString
```

case文でのパターンマッチングを使うと、値の中身にマッチさせることもできます。

```elm
has123 : (Int, String, Bool) -> Bool
has123 aTuple =
    case aTuple of
        (123, _, _) ->
            True
        (_, "123", _) ->
            True
        (_, _, True) ->
            True
        _ ->
            False
```
