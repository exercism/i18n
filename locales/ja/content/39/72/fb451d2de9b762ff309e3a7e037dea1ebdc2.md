# はじめに

`Enum`は、列挙可能なものを扱うためのアルゴリズムを集めた、とても便利なモジュールです。ソート、絞り込み、グループ化、数え上げ、検索、最小値や最大値の探索など、ほかにも多くの機能があります。

一般に、_列挙可能なもの_とは、繰り返し処理できるデータ、つまりコレクションのことです。Elixirでは、`Enumerable`[プロトコル][exercism-protocols]を実装したデータ型が列挙可能です。最もよく使われるのは、[配列][exercism-lists]と[マップ][exercism-maps]です。

`Enum`の関数の多くは、関数を引数として受け取ります。

```elixir
Enum.all?([1, 2, 3, 4, 5], fn x -> x > 3 end)
# => false
```

`Enum`で最もよく使われる関数は、`map`と`reduce`です。

## `map/2`

`Enum.map/2`を使うと、列挙可能なものの各要素を別の要素に置き換えられます。`Enum.map/2`の第2引数は、元の要素を受け取って、その置き換え後の要素を返す関数です。

## `reduce/3`

`Enum.reduce/3`を使うと、列挙可能なもの全体を1つの値に_畳み込む_ことができます。そのために、_アキュムレーター_と呼ばれる特別な変数を使います。アキュムレーターは、繰り返しの間で、その時点での畳み込みの状態を保持します。

`Enum.reduce/3`の第2引数は、アキュムレーターの初期値です。第3引数は、要素とアキュムレーターを受け取り、アキュムレーターの新しい値を返す関数です。

## マップを扱う

マップを`Enum`の関数と一緒に使うと、マップは自動的に`{key, value}`という2要素のタプルの配列に変換されます。

これをマップに戻すには、`Enum.into/2`を使います。`Enum.into/2`は、列挙可能なものをコレクタブル（`Collectable`プロトコルを実装したデータ構造）に変換する関数です。`Enum.reduce/3`の反対のものと考えることができます。

`Enum`には`Enum.into/3`もあります。`Enum.into/3`は`Enum.into/2`の変種で、列挙可能なものをコレクタブルに変換する際に適用する変換関数を受け取ります。

### マップのマッピング

マップに変換（マッピング）を適用するのに、`Enum.into/3`や、`Enum.map/2`と`Enum.into/2`を組み合わせる代わりに、専用の`Map.new/2`関数を使うこともできます。これは、列挙可能なものと変換関数を受け取るという点で`Enum.into/3`とまったく同じように動作しますが、変換先を選べるのではなく、常に新しいマップを返します。
