# はじめに

Swiftには、ループや`switch`文の実行フローを変えるための制御転送文があります。`return`に加えて、Swiftには`continue`、`break`、ループラベル、`fallthrough`があります。

## continue

`continue`文は、ループに現在の繰り返しの実行を止めて、すぐに次の繰り返しを始めるよう指示します。`while`ループや`repeat-while`ループでは、条件の確認へ直接ジャンプします。`for-in`ループでは、シーケンスの次の要素へ進みます。

```swift
var count = 1
while count < 6 {
    count += 1
    if count == 4 {
        continue
    }
    print(count)
}

// Prints:
// 2
// 3
// 5
// 6
```

## break

`break`文は、ループや`switch`文全体をすぐに終了します。実行は、ループや`switch`の後に続く最初のコードから再開します。

```swift
for fruit in ["banana", "grapes", "apple", "strawberry", "kiwi", "lemon"] {
    if !fruit.count.isMultiple(of: 2) {
        break
    }
    print(fruit)
}

// Prints:
// banana
// grapes
```

## ラベル付き文

入れ子になったループでは、`break`や`continue`を、最も内側のループではなく外側のループに作用させたいことがあります。ループには、名前とコロン（`labelName:`）を前に付けてラベルを付けられます。そして、そのラベルを`break`や`continue`に渡せます。

```swift
outerLoop: for fruit in ["banana", "grapes", "apple", "strawberry", "kiwi", "lemon"] {
    print("\n--- \(fruit) ---")
    for letter in fruit {
        guard letter != "n" else {
            break outerLoop
        }
        print(letter)
    }
}

// Prints:
// --- banana ---
// b
// a
```
