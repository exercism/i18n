# はじめに

JavaScriptには、日時を保持し、その管理のためのメソッドを提供する組み込みオブジェクト`Date`があります。

<!-- prettier-ignore -->
~~~exercism/caution
これはJavaの`java.util.Date`クラスを基にしたもので、そのクラスは2010年代初頭に置き換えられましたが、後方互換性のためにJavaScriptの`Date`は残り続けています。

そもそもDateの扱いは難しく、タイムゾーンの処理もお粗末か存在しないことが多いため、`moment.js`、`day.js`、`date-fns`、`luxon`など、多くのライブラリが存在します。
これらのライブラリはどれもExercismでは利用できません。

自分のプロジェクトでは、`moment.js`のような非推奨またはメンテナンスされていないパッケージは使わず、`luxon`のようなより現代的な代替品や、まだ広く普及していない[Temporal][mdn-temporal]に頼りましょう。
この演習では`Date`に焦点を当てます。`Date`はJavaScriptが終わるまでずっと重要であり続けます。

[mdn-temporal]: https://developer.mozilla.org/en-US/docs/Web/JavaScript/Reference/Global_Objects/Temporal
~~~

## 作成

`Date`オブジェクトは`Date`クラスのインスタンスです。
コンストラクター関数に引数を何も渡さずに作成できます。
こうすると、現在の日時を表す`Date`オブジェクトが得られます。

```javascript
const now = new Date();
// => Thu Apr 14 2022 11:46:08 GMT+0530 (India Standard Time)
// Shows current day, date and time (in your time zone).
```

### Unixタイムスタンプ（数値）

数値を渡すと、それは`timestamp`として解釈されます。
タイムスタンプとは、**1970年1月1日 [UTC][defn-utc]+0** 以降に経過した**ミリ秒**数を表す整数です。

```javascript
const epoch = new Date(0);
// Thu Jan 01 1970 01:00:00 GMT+0100 (Central European Standard Time)

const another = new Date(1749508766627);
// Tue Jun 10 2025 00:39:26 GMT+0200 (Central European Summer Time)
```

`new Date(0)`は「最も古い」日付オブジェクトを生成すると期待するかもしれませんが、JavaScriptはその日付をローカルタイムゾーンに変換するため、実際に[Unixエポック][defn-unix-epoch]の値を得られるのは、[GMT / UTC+0][defn-gmt]のタイムゾーン周辺にいる人だけです。

### ISO 8601タイムスタンプ（文字列）

`Date`コンストラクターには、日付を表す文字列を渡せます。
実装間で一貫している**唯一**の形式は、国際的に認識され標準化されているいわゆる[ISO 8601タイムスタンプ文字列][defn-iso8601]の[簡略版][mdn-date-string-format]です。

[UTC][defn-gmt]のある時点は、次のように表されます。

```text
YYYY-MM-DDTHH:mm:ss.mssZ
YYYYMMDDTHHmmss.mssZ
```

ここで、次の置き換えが行われます。

| キー | 説明                                   | デフォルト |
| ---- | ------------------------------------------- | ------- |
| YYYY | 暦年、4桁で表す  |         |
| MM   | 暦月、2桁で表す | 01      |
| DD   | 暦日、2桁で表す   | 01      |
| T    | リテラルの文字T、日付と時刻を区切る  | T       |
| HH   | 24時間制の時、2桁      | 00      |
| mm   | 分、2桁                       | 00      |
| ss   | 秒、2桁                       | 00      |
| mss  | ミリ秒、3桁                  | 000     |
| Z    | リテラルの文字Z、またはオフセット`+/-HH:mm` |         |

リテラルの文字`Z`はUTCを表します（タイムゾーンなし、夏時間なし）。

ほとんどの要素にデフォルト値があるため、末尾の部分を省略しても有効です。

```text
YYYY-MM-DD
```

時刻はデフォルトで00:00:00.000になります。

タイムスタンプが`Z`で終わらず、`+HH:mm`や`-HH:mm`（タイムゾーンのオフセットを表す）でも終わらない場合、歴史的な理由から、次のことが適用されます。

> タイムゾーンのオフセットがない場合、日付のみの形式はUTC時刻として解釈され、日時形式はローカル時刻として解釈されます。
> UTC時刻として解釈されるのは、ISO 8601と一致しない歴史的な仕様の誤りによるもので、Webの互換性のために変更できませんでした。
> 詳しくは[Broken Parser – A Web Reality Issue][ref-broken-parser]を参照してください。

### Dateオブジェクト

既存の日付オブジェクトも、コンストラクターの引数として使えます。
これは、同じ日時を持つ既存の`Date`オブジェクトのコピーを作ります。

```javascript
const t1 = new Date();
const t2 = new Date(t1);
// Values of t1 and t2 will be the same.
```

### 日付と時刻の各要素を個別に指定する

日付だけを表す`Date`は、数値を3つ渡して作成できます。
日付と時刻を表す`Date`は、数値を6つ渡して作成できます。

```javascript
const date1 = new Date(95, 11, 17);
// Creates Date for Dec 17 1995 00:00 if your local timezone is equivalent to UTC.

const date2 = new Date(2013, 12, 5, 13, 24, 0);
// Creates Date for Jan 5 2014 13:24 if your local timezone is equivalent to UTC.
```

2番目の値は`month`で、1月が`0`、12月が`11`です。

## `Date.parse()`

日付を解析する関数`Date.parse`への言及や参照を見かけることがあるかもしれません。
この関数には不変の（常に成り立つ）性質がごくわずかしかなく、残りの実装は仕様化されていない（したがって標準ではない）ため、使うべきではありません。

## `Date`の要素にアクセスする

日付オブジェクトには、日付の各要素を返すさまざまなメソッドがあります。

```javascript
getFullYear(); // Get the year (4 digits)
getMonth(); // Get the month, from 0 to 11.
getDate(); // Get the day of month, from 1 to 31.
getHours(); // Get the hour in a 24 clock, from 0 to 23
getMinutes(); // Get the minutes, from 0 to 59
getSeconds(); // Get the seconds, from 0 to 59
getMilliseconds(); // Get the milliseconds, from 0 and 999
getDay(); // Get the day of week, from 0 (Sunday) to 6 (Saturday).
```

これらのそれぞれには、値を更新するための対応する`set`版（例：`setFullYear`）があります。
あふれた値は次の要素に繰り越されます。

```javascript
const date = new Date('2025-02-28T12:42:00Z');
// => Fri Feb 28 2025 13:42:00 GMT+0100 (Central European Standard Time)

date.setDate(29);
// there was no February 29th in 2025.

date.getDate();
// => 1

date.toString();
// => Sat Mar 01 2025 13:42:00 GMT+0100 (Central European Standard Time)
```

すべてのメソッドには、ローカルタイムゾーンを無視するUTC版もあります。

## 日付からの変換

日付オブジェクトには、UNIXタイムスタンプをミリ秒で返す`getTime()`メソッドがあります。つまり、1970年1月1日UTCの始まりの真夜中からのミリ秒数です。
さらに、日付オブジェクトをISO 8601タイムスタンプ文字列に変換する`toISOString()`メソッドも利用できます。

## 日付の比較

大なり（`>`）と以上（`>=`）、および小なり（`<`）と以下（`<=`）は、2つの日付の間、または日付と数値の間で直接使えます。
これが機能するのは、JavaScriptが日付をプリミティブに変換しようとするからです。

<!-- prettier-ignore -->
~~~exercism/advanced
2つの日付、または日付と数値を比較するとき、JavaScriptは[`[Symbol.toPrimitive]("number")`][mdn-to-primitive]を呼び出し、これは内部的に[`date.valueOf()`][mdn-date-value-of]を呼び出します。
後者は[`date.getTime()`][mdn-date-get-time]を呼び出すのと同じです。

この動作に頼りたくない場合は、まず`getTime()`を使って数値に変換しましょう。

[mdn-to-primitive]: https://developer.mozilla.org/en-US/docs/Web/JavaScript/Reference/Global_Objects/Date/Symbol.toPrimitive
[mdn-date-value-of]: https://developer.mozilla.org/en-US/docs/Web/JavaScript/Reference/Global_Objects/Date/valueOf
[mdn-date-get-time]: https://developer.mozilla.org/en-US/docs/Web/JavaScript/Reference/Global_Objects/Date/getTime
~~~

日付は等値（`==`と`===`）では比較できませんが、`.getTime()`の結果なら比較できます。
