# 説明

会員制の映画館を運営しているとしましょう。
映画を観るには年間パスを購入する必要があり、購入すれば映画は無料で観られます。

映画館では、入場者の記録をつけています。
この記録を使って、今月どの会員が年間パスを使ったかを把握したいと考えています。
お客さんの年齢層についても知りたいところです。
これらの目的は、セットを使えば達成できることに気づきます。

## セット

セットは、こうしたデータを保存するのにうってつけのデータ型です。

セットとは、重複しない一意の値を、特定の順序を持たせずに保存するデータ型です。
重複しない一意の値とは、ある要素がセットに入っているかいないかのどちらかである、という意味です。配列とは違い、同じ要素をセットに複数入れることはできません。
セットは通常、順序を持ちません。セットの要素を並べてみると、得られる順序は追加した順序と違うかもしれませんし、前回並べたときの順序と違うことさえあります！

セットの基本的な性質のひとつが、メンバーシップの判定です。ある要素がセットに含まれているかどうかを調べる機能のことです。
セットを使う場面のほとんどで、このメンバーシップの判定が中心になります。

Goには、標準でセットというデータ型が用意されているわけではありません。
セットの代わりに`map[<type>]struct{}`や`map[<type>]bool`を使うのが一般的です。`map`もセットと同様に、重複しない一意の要素を追加でき、メンバーシップの判定にも対応しています。

## 1. 参加者の情報を保存する場所

入場者と年齢層を追跡するには、セットを使うのがよいでしょう。

名前用と年齢用に別々のセットを書く必要はありません。ジェネリックなセットをひとつ作れば、両方に使えます。
参加者を保存するために、`Set`型を`map[T comparable]struct{}`として定義します。
空の`Set[T]`を返す`NewSet[T comparable]()`関数を書きましょう。

```go
names := NewSet[string]()
```

## 2. 参加者を記録する

これで、参加者の情報を記録する準備ができました。

セットに要素を追加する`Add[T]()`メソッドを書きましょう。

```go
names := NewSet[string]()
names.Add("Alice")
```

## 3. 参加者を確認する

参加者のセットができたので、特定の会員や年齢層が来場したかどうかを確認できます。
会員や年齢層が`Set`に入っているかどうかを返す`Contains[T](element)`メソッドを書きましょう。

```
names := NewSet[string]()
names.Add("Alice")
names.Contains("Alice")
// => true
names.Contains("Bob")
// => false
```

## 4. 参加者を比較する

さらに1か月がたち、年齢層の新しい`Set`ができました。
マーケティング担当のマネージャーは、今月の新作によって来場する年齢層が変わったかどうかを知りたがっています。
2つのセットが同じ要素を持っているかを判定する`Equals[T](other)`メソッドを書きましょう。

```go
agesOne := NewSet[int]()
names.Add(25)

agesTwo := NewSet[int]()
names.Add(25)

agesOne.Equals(agesTwo)
// => true

agesThree := NewSet[int]()
names.Add(35)

agesOne.Equals(agesThree)
// => false
```
