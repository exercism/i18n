# はじめに

Goでは、`struct`は _フィールド_ と呼ばれる名前付きの要素を並べたもので、各フィールドは名前と型を持ちます。フィールドの名前は、その構造体の中で一意でなければなりません。構造体は、オブジェクト指向プログラミングのパラダイムにおける _クラス_ にたとえることができます。

## 構造体を定義する

新しい構造体は、`type`キーワードと`struct`キーワードを使って作成し、フィールドの名前と型を明示的に定義します。たとえば、ここでは図形の名前とサイズを保持する`Shape`構造体を定義します。

```go
type Shape struct {
    name string
    size int
}
```

構造体のフィールド名はGoの慣習に従います。小文字で始まる名前のフィールドは同じパッケージ内のコードからしか参照できませんが、大文字で始まる名前のフィールドは他のパッケージからも参照できます。

## 構造体のインスタンスを作成する

`struct`を定義したら、次は新しいインスタンスを作成します。このとき、フィールド名を使って、任意の順序でフィールドを指定します。

```go
s := Shape {
    name: "Square",
    size: 25,
}
```

インスタンスのフィールドを読み取ったり変更したりするには、`.`記法を使います。

```go
// Update the name and the size
s.name = "Circle"
s.size = 35
fmt.Printf("name: %s size: %d\n", s.name, s.size)
// Output: name: Circle size: 35
```

初期値が代入されていないフィールドは、ゼロ値になります。たとえば、次のとおりです。

```go
s := Shape{name: "Circle"}
fmt.Printf("name: %s size: %d\n", s.name, s.size)
// Output: name: Circle size: 0
```

フィールドを _順番どおり_ に定義すれば、フィールド名を使わずに`struct`のインスタンスを作成できます。

```go
s := Shape {
	"Oval",
	20,
}
```

ただし、この構文は _壊れやすいコード_ とみなされます。フィールドを追加したときに壊れる可能性があるからです。特に、追加するフィールドの型が異なる場合はそうです。次の例では、`Shape`にフィールドを1つ追加します。

```go
type Shape struct {
	name        string
	description string // new field 'description' added
	size        int
}

s := Shape{
    "Circle",
    20,
}
// Since the second field of the struct is now a string and not an int,
// the compiler will throw an error when compiling the program:
// Output: cannot use 20 (type untyped int) as type string in field value
// Output: too few values in Shape{...}
```

## 「New」関数

構造体のインスタンスを作成するのを助けてくれる関数があると、便利なことがあります。慣習として、こうした関数は通常`New`という名前か、`New`で始まる名前を付けます。ただし、これらはただの普通の関数なので、好きな名前を付けてかまいません。他の言語のコンストラクターを思い浮かべるかもしれませんが、Goではこれらはただの普通の関数です。

次の例では、こうした`New`関数の1つを使って`Shape`の新しいインスタンスを作成し、図形の`size`にデフォルト値を自動的に設定しています。

```go
func NewShape(name string) Shape {
	return Shape{
		name: name,
		size: 100, //default-value for size is 100
	}
}

NewShape("Triangle")
// => Shape { name: "Triangle", size: 100 }

```

`New`関数を使うと、次のような利点があります。

* 与えられた値の検証
* デフォルト値の処理
* `New`関数は、初期化する構造体と同じパッケージで宣言されることが多いため、その構造体の非公開フィールドも初期化できます

この型をさらに深く学ぶには、次のリソースをチェックしてみてください。[Go by Example: Structs][go-by-example-structs]、[A Tour of Go: Structs][tour-of-go-structs]、[Structures in Go (structs)][medium-structures-in-go]

## `new`組み込み関数

構造体の新しいインスタンスを作成するもう1つの方法は、`new`組み込み関数を使うことです。

```go
s := new(Shape) // s will be of type *Shape (pointer to shape)
fmt.Printf("name: %s size: %d\n", s.name, s.size)
// Output: name:  size: 0
```

この例では、`new`が構造体`Shape`のインスタンスを作成し、すべての値をその型のゼロ値で初期化して、そのポインターを返します。

~~~~exercism/note
構造体の新しいインスタンスを`new`組み込み関数で作成する場面は、ほとんどの場合ありません。構造体リテラル、独自の`New`関数、あるいは構造体の組み立てに役立つ、パッケージが提供するその他の関数を常に優先してください。`new`組み込み関数は、どうしても他に方法がないときの最後の手段として使います。
~~~~
