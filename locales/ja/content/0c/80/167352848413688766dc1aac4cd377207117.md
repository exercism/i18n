# 概要

再帰とは、関数が自分自身を呼び出すことで、関数の中のコードを繰り返す方法です。
これは、ループ（繰り返し）のもう一つの方法です。ループと同じように、関数はいつ終わるかを知るために、真偽値の式を判定する必要があります。
ループとは違い、終わらない再帰が無限に動き続けることはありません。
関数呼び出しごとに使われる値は、スタック上のそれぞれのフレームに置かれることがあります。
関数呼び出しの量がスタックの容量より多くの領域を占めると、スタックオーバーフローエラーが発生します。

```c
int printIncrement (int i, int maxValue){
    if (i > maxValue) return i;
    printf("The number is %i\n", i++);
    printIncrement(i, maxValue);
}

int main() {
    printIncrement(1, 2);
    printf("After recursion");
    return 0;
}
```

出力は次のようになります。

```
The number is 1
The number is 2
After recursion
```

ループで表すよりも、再帰で表すほうが読みやすく、筋道を立てて考えやすい状況もあるでしょう。


## 末尾呼び出し

末尾呼び出しとは、関数の最後の文が自分自身を呼び出すだけで、それ以上何もしないものをいいます。

末尾呼び出しは再帰の特別な形で、コンパイラーがコンパイル後のコードでその再帰をループに最適化できることがあります。
これは、いいとこ取りができます。つまり、再帰の読みやすさと、ループの性能を併せ持てます。
再帰をループにコンパイルすることを、`tail call elimination`または`tail call optimization.`と呼びます。

末尾呼び出しがループにコンパイルされると、関数呼び出しごとに新しいスタックフレームは作られません。
もともと関数が呼び出されたときのアドレスに、更新された値が渡されるため、スタックの領域を節約でき、性能も向上します。

次の例は末尾呼び出しではありません。関数が自分自身を呼び出した結果に1を足しているからです。

```c
int printIncrement (int i, int maxValue){
    if (i > maxValue) return 1;
    printf("The number is %i\n", i++);
    return 1 + printIncrement(i, maxValue);
}

int main() {
    int j = printIncrement(1, 2);
    printf("j is %i after recursion", j);
    return 0;
}
```

出力は次のようになります。

```
The number is 1
The number is 2
j is 3 after recursion
```

これを末尾呼び出しにリファクタリングするには、`j`を`printIncrement`の仮引数にします。

```c
int printIncrement (int i, int maxValue, int j){
    if (i > maxValue) return j;
    printf("The number is %i\n", i++);
    return printIncrement(i, maxValue, ++j);
}

int main() {
    int j = printIncrement(1, 2, 1);
    printf("j is %i after recursion", j);
    return 0;
}
```

末尾呼び出しは、末尾呼び出しではない再帰呼び出しよりも、筋道を立てて考えやすいと感じるかもしれません。
ただし、通常、コンパイラーはすべての末尾呼び出しが最適化されることを保証しているわけではありません。
再帰を使うときはいつも、スタックがあふれてしまうほど多くの繰り返しが行われないことを把握しておくことが大切です。
