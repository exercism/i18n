# 説明

Toriは気候ジャーナリストで、さまざまな都市の天気についての記事を書こうとしています。Toriはいろいろな都市の天気のデータを持っていて、気温をもとにそれらの都市を順位づけしたいと考えています。ただ、気温の単位が華氏のものと摂氏のものに分かれています。そこで、気温を同じ単位に変換して順位づけるために、助けが必要です。

## 1. 華氏を摂氏に変換する

`fahrenheit_to_celsius`関数を定義してください。この関数は、華氏の気温を入力として受け取り、摂氏の気温を返します。

華氏を摂氏に変換するには、華氏の値から32を引いて、その結果を1.8で割ります。

```gleam
fahrenheit_to_celsius(72.5)
// -> 22.5
```

## 2. 2つの気温を比較する

`compare_temperature`関数を定義してください。この関数は2つの気温を受け取り、1つ目の気温が2つ目の気温より小さいか、等しいか、大きいかを示す`Order`の値を返します。

```gleam
compare_temperature(Celsius(30.5), Fahrenheit(82.1))
// -> Gt
```

## 3. 気温で都市を並べ替える

`sort_cities_by_temperature`関数を定義してください。この関数は都市の配列を受け取り、最も寒い都市から最も暖かい都市の順に並べて返します。

```gleam
sort_cities_by_temperature([
  City(name: "London", temperature: Celsius(30.5)),
  City(name: "Paris", temperature: Fahrenheit(82.1))
])
// -> [
//   City(name: "Paris", temperature: Fahrenheit(82.1)),
//   City(name: "London", temperature: Celsius(30.5)))
// ]
```
