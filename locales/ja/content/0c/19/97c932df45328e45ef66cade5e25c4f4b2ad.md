Rakuは、驚くほど豊かで柔軟、そして強力なプログラミング言語です。その柔軟さのおかげで、プログラマーは自分のスタイルに合った表現豊かなコードを書くことができます。

Rakuは大きく、学び、探求し、実験するための深さが十分にあります。このシラバスでは、学習を始めるための基礎を扱うことを目指しています。

オブジェクト指向プログラミングはRakuの中心にありますが、オブジェクト指向の作法を押し付けるものではありません。オブジェクト指向の性質上、このシラバスでは[オブジェクト、クラス、メソッド][object-orientation]をたびたび参照します。

## 変数

基礎では、話を簡単にするためにスカラー[変数][variables]だけを使います。

スカラー変数は、`$`シジルを先頭に付けた[識別子][identifiers]です。

スカラー変数には事実上どんなものでも入れられ、デフォルトの型は[`Any`][Any]です。

使う変数のほとんどには[宣言][variable-declarator]が必要です。今のところは、[`my`][my]と[`constant`][constant]だけを使いましょう。

```raku
my $foo;
constant $BAR;
```

## サブルーチン

サブルーチンは[`sub`][sub-declarator]宣言子で宣言します。

`sub`宣言のあとには、省略可能な[識別子][identifiers]、省略可能な[シグネチャ][signatures]、そして[ブロック][blocks]が続きます。

サブルーチンは（ほかのものと同様に）、[`is export`][exporting]トレイトを付けることでエクスポートできます。

サブルーチンは、識別子のあとに[後置環状 `( )`][postcircumfix-()]演算子を付けて呼び出せます。

```raku
sub foo ($bar) is export { ... } # Subroutine definition

foo($bar); # Subroutine call
```

## 演算子

Rakuには多種多様な[演算子][operators]があります。基礎の概念の演習では、`+`や`-`など、Rakuの基本的な数学演算子をいくつか使います。

```raku
say 0.1 + 0.2 - 0.3;
# Raku is not like other languages -> https://0.30000000000000004.com/#raku
```

Rakuでは、必要であれば自分で演算子を簡単に定義できます。組み込み演算子のほとんどはサブルーチンとしても利用できます。

## パッケージとモジュール

Rakuにはいくつかの種類の[パッケージ][package-declarator]があります。基礎では`module`だけを使います。

ファイル全体を`module`として宣言するには、モジュール宣言の先頭に`unit`を付けます。

```raku
unit module Foo;

sub bar () { ... }
```

## コメント

Rakuには[単一行][single-line-comments]コメントと[複数行・埋め込み][multi-line-comments]コメントがあります。

単一行コメントは`#`で始まり、行の終わりまで続きます。

複数行・埋め込みコメントは、ハッシュのあとにバッククォートとUnicodeの開き句読点文字を続けて始めます。対応する閉じ文字で終わります。

```raku
# This is a single-line comment

#`(
    This is a
    multi-line/embedded comment
)
```

## スタイル規約

Rakuでは、変数とサブルーチンの[識別子][identifiers]は`kebab-case`で書きます。定数は`ALL-CAPS`で書きます。パッケージ名は`PascalCase`で書きます。
