# 概要

`cond`に加えて、Elixirには[`if/2`][getting-started-if]というマクロも用意されています。これは、条件を1つだけ確認したいときに便利です。

[`if/2`][kernel-if]は、条件と2つのオプションを受け取ります。条件が_真とみなされる_場合は1つ目のオプションを返し、条件が_偽とみなされる_場合は2つ目のオプションを返します。

```elixir
age = 15

if age >= 16 do
  "You are allowed to drink beer in Germany."
else
  "No beer for you!"
end

# => "No beer for you!"
```

2つ目のオプションを指定しなかった場合は、`nil`が返されます。

```elixir
age = 15

if age >= 16 do
  "You are allowed to drink beer in Germany."
end

# => nil
```

`if`式は1行で書くこともできます。条件のあとのカンマに注意してください。

```elixir
if age >= 16, do: "beer", else: "no beer"
```

この構文はとても短い式には便利ですが、式が1行に収まらない場合は避けたほうがよいでしょう。

## _真とみなされる値_と_偽とみなされる値_

Elixirでは、すべてのデータ型は、真偽値が求められる文脈（`if`式など）で扱われると、_真とみなされる_値または_偽とみなされる_値に評価されます。`false`と`nil`**以外**のすべてのデータは、_真とみなされます_。特に、空の文字列、整数の`0`、空の配列は、Elixirではすべて_真とみなされます_。この点で、[ElixirはRubyに似ていますが、JavaScript、Python、PHPとは異なっています][falsy-various-langs]。

```elixir
truthy? = fn x -> if x, do: "truthy", else: "falsy" end

truthy?.(true)
# => "truthy"
truthy?.(0)
# => "truthy"
truthy?.([])
# => "truthy"

truthy?.(false)
# => "falsy"
truthy?.(nil)
# => "falsy"
```

[`&&/2`][kernel-and]、[`||/2`][kernel-or]、[`!/1`][kernel-not]は、どんな値でも扱える_真とみなされる_値の論理演算子で、_厳密な_論理演算子である[`and/2`][kernel-boolean-and]、[`or/2`][kernel-boolean-or]、[`not/1`][kernel-boolean-not]を補完するものです。

```elixir
0 and true
# => ** (BadBooleanError) expected a boolean on left-side of "and", got: 0

0 && true
# => true
```
