# はじめに

`const`修飾子は、コンパイル時に値がわかり、プログラムの実行中も変化しないフィールドになら適用できます（そして、たいていは適用すべきです）。

```csharp
private const int num = 1729;
public const string title = "Grand" + " Master";
```

`readonly`修飾子は、`const`にできないフィールドのうち、プログラムの実行中に値が変化せず、インライン初期化子で設定されるか、インスタンス化のとき（コンストラクター、またはコンストラクターから呼ばれるメソッド）に設定されるものになら適用できます（そして、たいていは適用すべきです）。

```csharp
private readonly int num;
private readonly System.Random rand = new System.Random();

public MyClass(int num)
{
    this.num = num;
}
```
