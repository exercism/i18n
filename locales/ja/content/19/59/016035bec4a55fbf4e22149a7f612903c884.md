# はじめに

再帰関数とは、自分自身を呼び出す関数のことです。

再帰関数には、少なくとも1つの_ベースケース_と、少なくとも1つの_再帰ケース_が必要です。

_ベースケース_は、関数を再度呼び出さずに値を返します。_再帰ケース_は、関数を再度呼び出します。そのとき、いずれベースケースに一致するように入力を変えておきます。

たいていの場合、それぞれのケースはそれぞれ別の関数節として書きます。

```elixir
# base case
def count([]), do: 0

# recursive case
def count([_head | tail]), do: 1 + count(tail)
```
