# 説明の補足

## レジスタ

| レジスタ | 用途     | 型      | 説明                          |
| -------- | -------- | ------- | ----------------------------- |
| `$a0`    | 入力     | アドレス | 1つ目のnull終端文字列         |
| `$a1`    | 入力     | アドレス | 2つ目のnull終端文字列         |
| `$v0`    | 出力     | 整数    | ハミング距離                  |
| `$t0-9`  | 一時的   | 任意    | 一時的な保存用                |
