# はじめに

## ビット配列

バイナリデータを扱うのは難しいことがあるため、Gleamには`BitArray`型と、バイナリデータを構築したりパターンマッチングしたりするための構文が用意されています。

ビット配列リテラルは`<<>>`構文を使って定義します。ビット配列リテラルはセグメント単位で記述します。各セグメントは値と注釈を持ち、それらは`:`で区切られます。注釈は、その値をエンコードするのに何ビット使うかを指定するもので、完全に省略することもできます。省略した場合のデフォルトは8ビットの整数値です。

```gleam
// This defines a bit array with three segments of a single bit each
<<0:1, 1:1, 0:1>>

// This defines a bit array with three segments of 8 bits each
<<0, 1, 0>>
```

型を`:1`と指定するのは、`:size(1)`と書く省略形です。ビット数が変数から決まる場合は、長いほうの構文を使う必要があります。

```gleam
let segment_size = 1
<<0:size(segment_size), 1:size(segment_size), 0:size(segment_size)>>
```

### 2進数

2進数の整数リテラルを書くときは、リテラルの先頭に`0b`を付けることで、2進数表記で直接書くことができます。テストやプログラムで出力されるときには、10進数として表示されることに注意してください。

```gleam
<<0b1011:4>> == <<11:4>>
// -> True
```

### 切り詰め

セグメントの値がそのセグメントの型の容量を超えると、左側から切り詰められます。

```gleam
<<0b1011:3>> == <<0b0011:3>>
// -> True
```

### 先頭への追加と末尾への追加

ビット配列構文を使うと、既存のビット配列の先頭にも末尾にも要素を追加できます。既存のビット配列には`:bits`注釈を使う必要があります。

```gleam
let value = <<0b110:3, 0b001:3>>
let new_value = <<0b011:3, value:bits, 0b000:3>>
// -> <<120, 8:size(4)>>
```

### 連結

変数に格納されたビット配列は、ビット配列構文を使って連結できます。サイズが可変の2つのビット配列を連結するときは、`:bits`注釈を使う必要があります。

```gleam
let first = <<0b110:3>>
let second = <<0b001:3>>
let concatenated = <<first:bits, second:bits>>
// -> <<49:size(6)>>
```

### パターンマッチング

パターンマッチングを使って、ビット配列から値を取り出すこともできます。取り出したい各セグメントについて、そのビット数を知っておく必要があります。ひとつだけ例外があります。`:bits`注釈を使えば、サイズがわからないビット配列をパターンマッチングできますが、これは最後のセグメントにしか使えません。

```gleam
let assert <<value:4, rest:bits>> = <<0b01101001:8>>
value == 0b0110
// -> True
```

### ビット配列を調べる

~~~~exercism/note
ビット配列は、作成したときの形式とは違う形式で出力されることがあります。これは、ビット配列を学ぶときに混乱の原因になりがちです。
~~~~

デフォルトでは、ビット配列は8ビット（1バイト）のセグメントで表示されます。違うサイズのセグメントで作成した場合でも同じです。

```gleam
<<2011:11>>
// -> <<251, 3:size(3)>>
```

印刷可能なUTF-8エンコード文字列を表すビット配列を作成すると、`io.debug`のような関数によって文字列として表示されることがあります。これは、Gleamが内部的に文字列を表現する方法の実装上の詳細によるものです。

```gleam
<<>>
// -> ""

<<65, 66, 67>>
// -> "ABC"
```
