# 説明の補足

## レジスター

| レジスター | 用途     | 型    | 説明                                                |
| -------- | --------- | ------- | ---------------------------------------------------------- |
| `$a0`    | 入力     | アドレス | 配列1の要素                                         |
| `$a1`    | 入力     | 整数 | 配列1のサイズ（ワード単位）                                |
| `$a2`    | 入力     | アドレス | 配列2の要素                                         |
| `$a3`    | 入力     | 整数 | 配列2のサイズ（ワード単位）                                |
| `$v0`    | 出力     | 整数 | `0` = 同じ、`1` = 同じでない、`2` = 部分リスト、`3` = 上位リスト |
| `$t0-9`  | 一時     | 任意     | 一時的な保存に使います                                 |
