# はじめに

[Pythonの禅][zen-of-python]では、何かをするための_明白な_方法が1つあるべきだと説いています。
Python 3.6以降では、[**リテラル文字列補間**][string-interpolation]（[**`f-string`**][f-string]）が、文字列をフォーマットするうえで明白で好ましい方法であることがよくあります。

```python
>>> adjective = "easy"
>>> f"This is an {adjective} way to format strings!"
'This is an easy way to format strings!'
```

しかし、Pythonの長い歴史とさまざまな用途を考えると、Pythonで文字列をフォーマットする一般的な方法が**ほかにも3つ**あることは、それほど驚きではないでしょう。

1. [`str.format()`][str-format]は汎用性が高く、非常に強力で、[`gnu gettext`][gettext]ともほとんどのバージョンのPythonとも互換性があります。
2. シンプルさ、安全性、あるいは本格的な国際化が必要なときは、[`string.Template()`][string-template]を使うことで、入力を扱う必要がある場合のリスクを軽減したり、翻訳文字列をラップしたりできます。
3. `%`演算子は、新しいコードでは一般的に非推奨とされていますが、現代のPythonでも動作します。
  主に古いコードベースとの互換性のために使うべきです。
  `%`フォーマットは、ASCII以外の文字やUnicode文字を表示するときに問題を引き起こすことがあり、他の方法に比べてエラーが多く、機能も少なくなっています。
  使うつもりなら、対応状況の詳細について、使用しているPythonディストリビューションを確認してください。

さらに深く学びたいなら、[all about formatting][all-about-formatting]と[Python String Formatting Best Practices][formatting-best-practices]が良い出発点です。
