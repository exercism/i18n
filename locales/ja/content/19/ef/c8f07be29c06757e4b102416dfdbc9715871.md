# 指示

この演習では、ログ行を処理します。

各ログ行は、`"[<LEVEL>]: <MESSAGE>"`という形式の文字列です。

ログレベルは次の3つです。

- `INFO`
- `WARNING`
- `ERROR`

タスクは3つあり、それぞれがログ行を受け取って、それを使って何かをするよう求めます。
これらのタスクを解く方法はたくさんあります。上の例からお気に入りのメソッドを選んで、どんなコードを書けるか試してみましょう。

## 1. ログ行からメッセージを取得する

`LogLineParser#message`メソッドを実装して、ログ行のメッセージを返すようにしてください。

```ruby
LogLineParser.new('[ERROR]: Invalid operation').message
# => "Invalid operation"
```

先頭と末尾の空白は取り除いてください。

```ruby
LogLineParser.new("[WARNING]:  Disk almost full\r\n").message
# => "Disk almost full"
```

## 2. ログ行からログレベルを取得する

`LogLineParser#log_level`メソッドを実装して、ログ行のログレベルを返すようにしてください。ログレベルは小文字で返します。

```ruby
LogLineParser.new('[ERROR]: Invalid operation').log_level
# => "error"
```

## 3. ログ行を整形し直す

ログ行を整形し直す`LogLineParser#reformat`メソッドを実装してください。メッセージを先に、そのあとに括弧（`()`）で囲んだログレベルを置きます。

```ruby
LogLineParser.new('[INFO]: Operation completed').reformat
# => "Operation completed (info)"
```
