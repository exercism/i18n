# 指示

この演習では、バレンタインデーにパートナーと何をするかを計画します。パートナーはたくさんのアイデアを出していて、一番よい活動を見つけるために、そのアイデアを評価してほしいと頼んできています。

パートナーが提案してきたアイデアは次のとおりです：

- ボードゲームで遊ぶ
- のんびり過ごす
- 映画を見る
- レストランに行く
- 散歩する

バレンタインデーの過ごし方を選ぶための、6つのタスクがあります。

## 1. 承認を定義する

パートナーが提案するそれぞれのアイデアに対して、はい・いいえ・たぶんの3つのうちのどれかで答えます。

これらの選択肢を表すために、次の3つのケースを持つ代数的データ型`Approval`を定義します：`Yes`、`No`、`Maybe`。

## 2. 料理の種類を定義する

パートナーは2つのレストラン候補を選びました。1つは韓国料理、もう1つはトルコ料理です。

これらのレストランを表すために、次の2つのケースを持つ代数的データ型`Cuisine`を定義します：`Korean`、`Turkish`。

## 3. 映画のジャンルを定義する

選べる映画は山ほどあるので、絞り込むために、パートナーは好みのジャンルも挙げています。

次のジャンルのケースを表すために、代数的データ型`Genre`を定義します：`Crime`、`Horror`、`Romance`、`Thriller`。

## 4. 活動を定義する

すでに触れたとおり、パートナーはボードゲームで遊ぶ、のんびり過ごす、映画を見る、レストランに行く、散歩するという5つの活動を思いつきました。

これらの活動の種類を表すために、代数的データ型`Activity`を定義します：

- `BoardGame`：関連するデータはありません。
- `Chill`：関連するデータはありません。
- `Movie`：関連するデータとして`Genre`を持ちます。
- `Restaurant`：関連するデータとして`Cuisine`を持ちます。
- `Walk`：歩く距離をキロメートルで表す`Int`を関連するデータとして持ちます。

## 5. 活動を評価する

いよいよ、パートナーのアイデアを評価する準備ができました。
パートナーのアイデアに対するあなたの気持ちは次のとおりです：

- ボードゲームで遊ぶ：いいえ。
- のんびり過ごす：いいえ。
- 映画を見る：ロマンチックな映画なら「はい」、それ以外は「いいえ」。
- レストランに行く：韓国料理なら「はい」、トルコ料理なら「たぶん」。
- 散歩する：歩く距離が3キロメートル未満なら「はい」、3キロメートル以上5キロメートル以下なら「たぶん」、それ以外は「いいえ」。

`Activity`の値を受け取り、上記の気持ちに基づいて`Approval`を返す`rateActivity`という名前の関数を実装します。
例えば：

```haskell
rateActivity (Restaurant Turkish)
-- -> Maybe
```
