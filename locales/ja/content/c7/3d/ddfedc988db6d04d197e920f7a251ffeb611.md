Rakuでは、コードブロックが多用されます。関数には欠かせませんが、`grep`や`map`といったツールの中でも、`if`文、`for`文、`while`文、`given`文のブロックとしても、さらには配列のインデックスとしても使われます。

## ルーチン

Rakuでは、[`Subs`][type/Sub]と[`Methods`][type/Method]は[`Routines`][type/Routine]の一種です。

ルーチンは、[`return`][control-return]キーワードを使うと、いつでも戻り値を返して終了できます。関数を作るときに便利な道具です。
`return`を指定しなければ、ルーチンの最後の文が暗黙の戻り値になります。

ルーチンは、コードブロックの前に、括弧（`()`）の中に[`Signature`][language/signatures]を持たせることができます。

[`Routine`][type/Routine]は[`Block`][type/Block]のサブクラスです。

```raku
sub add ($x, $y --> Int) { return $x + $y }
say add(1, 2); # 3
```

メソッドについては、クラスとオブジェクトに関する別の概念で扱います。

## ブロック

[`Block`][type/Block]は再利用できるコードオブジェクトで、ふつうはラムダを作るために使われます。

ブロックの最後の文が、その暗黙の戻り値になります。

ブロックは、コードブロックの前に`->`を付けた[`Signature`][language/signatures]を持たせることができます。

[`Block`][type/Block]は[`Code`][type/Code]のサブクラスで、`Code`はRakuのすべてのコードオブジェクトの最上位の基底クラスです。

```raku
my $add = -> $x, $y { $x + $y };
say $add(1, 2); # 3
```

## シグネチャ

[`Signature`][language/signatures]は、0個以上の[`Parameters`][type/Parameter]をカンマで区切って並べたものです。

シグネチャの末尾には、[戻り値の型の矢印][signatures-return-type-arrow]`-->`を使って戻り値の型を指定できます。

シグネチャを使うと、`Block`が受け取る引数を指定できます。

この概念では、シグネチャをシンプルに保ちます。使うのは、スカラーのシジルが付いた変数を使う位置指定の仮引数と、戻り値の型だけです。
これらについては、ほかの概念で詳しく説明します。

## マルチディスパッチ

Rakuでは、`multi`キーワードを使うと、同じ名前でシグネチャが異なる複数のルーチンを書くことができます。
この機能は[マルチディスパッチ][multi-dispatch]と呼ばれます。
ルーチンが名前で呼び出されると、実行環境が適切な候補を判断して呼び出します。

これについては、型に関する概念でさらに詳しく扱います。

```raku
multi foo () { say 'No arguments given'}

multi foo ($bar) { say "One argument given: $bar" }
```

## WhateverCode

[`Whatever`][type/Whatever]のスター`*`をほとんどの演算子と組み合わせて使うと、[`WhateverCode`][type/WhateverCode]オブジェクトが作られます。
これにより、よりシンプルな構文でブロックを作れます。

```raku
# These will all give code blocks that increment a single argument by 1:
-> $x { $x  + 1 }; # Explicit signature
      { $^x + 1 }; # Signature via placeholder variable
      { $_  + 1 }; # Topic variable
          * + 1;   # WhateverCode
```
