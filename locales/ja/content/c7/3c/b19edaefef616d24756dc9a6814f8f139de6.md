## タプル

[タプル][tuple]は、情報をひとまとめにするのによく使われます。配列との違いは、サイズが固定で、異なるデータ型を保持できることです。
タプルは波括弧（`()`）で作り、関数から複数の値を返すのによく使われます。

```haskell
tuple = (1, "abc", False)
```

これは、たとえば2次元空間の座標を保存したいときに便利です。そのとき、タプルが常にx座標とy座標という2つの要素を持つことがわかります。

```haskell
coordinate = (3, 4)
```

### 要素へのアクセス

短いタプルを扱うことがよくあります。その場合、`fst`と`snd`という関数を使って要素にアクセスできます。

```haskell
x = fst coordinate
-- x = 3
y = snd coordinate
-- y = 4
```

## パターンマッチング

Haskellの関数を書くときは、[パターンマッチング][pattern-match-doc]を使った[断定的なスタイル][assertive-style]を活用できます。
パターンマッチングはHaskellの非常に強力な機能で、データコンストラクターにマッチさせたり、その中の値に変数を束縛したりできます。
名前のとおり、行っているのは値とパターンの照合です。値がパターンに一致すれば、パターンの中の値に変数を束縛できます。
パターンマッチングは主に、値の認識、変数の束縛、値の分解という考え方から成り立っています。

たとえば、次の関数を見てみましょう。

```haskell
lucky :: Int -> String
lucky 7 = "Lucky number seven!"
lucky x = "Sorry, you're out of luck, pal!"
```

ここには、`Int`を受け取って`String`を返す`lucky`関数があります。
この関数には2つのパターンを定義しています。1つは数値`7`にマッチするもの、もう1つはそれ以外の数値にマッチするものです。名前は何でもかまいませんが（Haskellの命名規則に従う必要があります）、ここでは`x`を使っています。
数値が`7`なら、この関数は`"Lucky number seven!"`を返し、それ以外なら`"Sorry, you're out of luck, pal!"`を返します。
ここで重要なのは、パターンが上から下へ順にチェックされるという点です。もしパターンの順番を入れ替えていたら、この関数は常に`"Lucky number seven!"`を返していたでしょう。

### 配列のパターン

よくあるパターンは配列にマッチさせるもので、配列の先頭と残りを取り出します。
これは配列が連結リストであるという性質によるものです。
次は、配列の先頭と残りを返す関数の例です。

```haskell
headAndTail :: [Int] -> (Int, [Int])
headAndTail [] = error "Can't call head on an empty list"
headAndTail (x:xs) = (x, xs)
```

ここでは2つのパターンがあります。1つは空の配列にマッチするもの、もう1つは要素が1つ以上ある配列にマッチするものです。
これは、配列が空の場合のケースを用意しておかないと実行時エラーになるためです。
配列が空でなければ、配列の先頭を`x`に、残りを`xs`にマッチさせることができます。
これは`:`（cons）演算子を使って行います。この演算子は、配列の先頭に要素を追加するときに使うものです。
しかしパターンマッチングでは、配列を先頭と残りに分解できます。いわば逆のことをしているわけです。

`xs`は配列の残りによく使われる名前で、それが配列であることを示しています。入れ子の配列を扱う場合は、`xss`を使って配列の配列であることを示すこともできます。

### タプルのパターン

配列と同様に、タプルにもマッチさせることができます。
次は、タプルを受け取って1番目と2番目の要素を返す関数の例です。

```haskell
sumTuple :: (Int, Int) -> Int
sumTuple (x, y) = x + y
```

ここでは、2つの要素を持つタプルにマッチするパターンを使っています。1番目の要素は`x`に、2番目の要素は`y`に束縛されます。

### ワイルドカードパターン

変数の値が必要なく、ただパターンにマッチさせたいだけということもあります。
そこで登場するのがワイルドカードパターンで、アンダースコア`_`で表します。

次は、配列の最初の要素を返す関数の例です。

```haskell
head' :: [Int] -> Int
head' [] = error "Can't call head on an empty list"
head' (x:_) = x
```

ここでは配列の残りは必要ないので、ワイルドカードパターンを使って無視しています。

### 型のパターン

型にマッチさせることもできます。これはその型のコンストラクターを使うことで行います。
タプルのときと同じように、型から値を取り出すこともできます。

```haskell
data AccountType = Guest | User String 

greet :: AccountType -> String
greet Guest = "Welcome, guest!"
greet (User name) = "Welcome, " ++ name ++ "!"
```

1つ目のパターンでは`Guest`コンストラクターにマッチさせ、2つ目のパターンでは`User`コンストラクターにマッチさせて、その中の値を`name`に束縛しています。
