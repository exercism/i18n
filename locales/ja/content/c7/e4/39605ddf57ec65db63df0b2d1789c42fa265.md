# 説明

お気に入りの料理本のラザニアを作るために、コードを書いてみましょう。

タスクは5つあり、どれもレシピの調理に関係しています。

## 1. オーブンでの想定焼き時間（分）を定義する

ラザニアをオーブンに入れておくべき分数を、定数`$EXPECTED-MINUTES-IN-OVEN`に設定します。料理本によると、オーブンでの想定焼き時間は40分です。

```raku
$EXPECTED-MINUTES-IN-OVEN
# => 40
```

## 2. 残りのオーブン焼き時間（分）を計算する

`remaining-minutes-in-oven`サブルーチンを修正します。このサブルーチンは、ラザニアを実際にオーブンに入れておいた分数を引数として受け取り、前のタスクで定義した想定焼き時間をもとに、ラザニアをあと何分オーブンに入れておく必要があるかを返します。

```raku
remaining-minutes-in-oven(30)
# => 10
```

## 3. 準備時間（分）を計算する

`preparation-time-in-minutes`サブルーチンを修正します。このサブルーチンは、ラザニアに重ねた層の数を引数として受け取り、1層あたり2分かかると仮定して、ラザニアの準備に何分かかったかを返します。

```raku
preparation-time-in-minutes(2)
# => 4
```

## 4. 合計作業時間（分）を計算する

`total-time-in-minutes`サブルーチンを修正します。このサブルーチンは2つの引数を取ります。1つ目の引数はラザニアに重ねた層の数、2つ目の引数はラザニアをオーブンに入れておいた分数です。
このサブルーチンは、ラザニアの調理に合計で何分かかったかを返すようにします。これは、準備時間（分）と、その時点でラザニアがオーブンに入っていた時間（分）を足したものです。

```raku
total-time-in-minutes(3, 20)
# => 26
```

## 5. ラザニアができたことを知らせる通知を作成する

`oven-alarm`サブルーチンを修正します。このサブルーチンは引数を取らず、ラザニアが食べごろになったことを知らせるメッセージを返します。

```raku
oven-alarm()
# => 'Ding!'
```
