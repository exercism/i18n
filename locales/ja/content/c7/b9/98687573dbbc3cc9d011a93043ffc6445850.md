# ヒント

## 全般

- [Random class][random-class]を使うと、乱数を生成できます。
- 詳しくは、こちらの記事を読んでみてください：[Random Number Generators in Java 17][random-number-generators]。

## 迷路の生成

完全な迷路を生成するには、どんなアルゴリズムを使ってもかまいません。[recursive backtracker][recursive-backtracker]がよい選択です。
