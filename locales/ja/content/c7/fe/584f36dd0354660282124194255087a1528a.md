# 概要

Elmのような純粋関数型言語では、同じ引数で呼び出した関数は、常に同じ値を返さなければなりません。
そのため、`rand : Int`という型シグネチャを持つ関数は、(`rand = 4`)[xkcd-random]としてしか実装できず、これではランダムな整数を生成できる見込みはありません。

では、Elmでランダムな値はどうやって生成するのでしょうか？
問題を2つに分けます。まず、生成したい値を`Random.Generator a`で記述し、次にその値を生成します。

値を生成する1つ目の方法は、`initialSeed : Int -> Seed`で`Random.Seed`を作ることです。
`Seed`は、整数を1つ保持し、その整数をランダムに見えるように（これを疑似ランダムと呼びます）変換する方法を知っている不透明型です。
`Seed`を手に入れたら、それを使って`Generator a`で値を生成できます。
`Generator a`は、シードの中の整数を使って、型`a`の疑似ランダムな値と、整数を更新した新しいシードを作る方法を知っている不透明型です。

値を生成するには、`step : Generator a -> Seed -> ( a, Seed )`を使います。これは値と新しいシードを返し、そのシードを使ってさらに値を生成できます。

これらの関数を使って、ジェネレーターから`n`個のランダムな値を取り出してみましょう。

```elm
generate : Int -> Generator a -> List a
generate n generator = generateValuesFromSeed n generator (Random.initialSeed 42)

generateValuesFromSeed : Int -> Generator a -> Seed -> List a
generateValuesFromSeed n generator seed =
    if n <= 0 then
        []
    else
        let ( value, nextSeed ) = Random.step generator seed
        in value :: generateValuesFromSeed (n - 1) generator nextSeed
```

これらの関数はすべて純粋なので、同じ引数で2回呼び出しても同じ値が生成されることに注意してください。

```elm
generate 10 (Random.int 1 6)
    --> [4, 5, 3, 3, 5, 1, 2, 4, 6, 6]

generate 10 (Random.int 1 6)
    --> [4, 5, 3, 3, 5, 1, 2, 4, 6, 6]
```

値を生成する2つ目の方法は、`Random.generate : (a -> msg) -> Generator a -> Cmd msg`を使うことですが、これはElmアプリケーションの中でしか行えません。
その場合、Elmランタイムは`step`だけでなく、外部の非純粋なリソースも使ってシードを生成することがあり、同じ関数を2回呼び出すと異なる結果になります。

ここからは、ジェネレーターに焦点を当てます。

`Random`モジュールには、特定の範囲内の整数と浮動小数点数を作るための基本的なジェネレーターが2つ用意されています。

```elm
generate 5 (Random.int -5 5)
    --> [0, 3, -5, 5, 0]

generate 3 (Random.float 0 5)
    --> [1.61803, 3.14159, 2.71828]
```

これらの値は、タプルにまとめたり、値の配列にまとめたりできます。

```elm
generate 2 (Random.list 3 (Random.int 0 3))
    --> [[0, 3, 3], [1, 3, 2]]

generate 2 (Random.pair (Random.int 0 3) (Random.float 10 10.3))
    --> [(0, 10.23412), (2, 10.17094)]
```

(`elm-community/random-extra`)[random-extra]パッケージには、文字列、日付、辞書、配列、集合など、さまざまなデータ構造向けのジェネレーターがもっとたくさん用意されています。

`Random.constant`を使うと、常に1つの値だけを返すジェネレーターを作れます。

```elm
generate 4 (Random.constant "hello")
    --> ["hello", "hello", "hello", "hello"]
```

`Random.uniform`を使うと、与えられた要素から等しい確率でランダムに選べます。

```elm
generate 5 (Random.uniform Red [Green, Blue])
    --> [Red, Blue, Blue, Green, Red]
```

`Random.uniform`が2つの引数（`Red`と`[Green, Blue]`）を取るのは、選べる値が少なくとも1つあることを保証するためです。配列を1つだけ受け取る形にすると、その配列が空である可能性があるからです。

`Random.weighted`を使えば、確率を調整することもできます。

```elm
generate 5 (Random.weighted (80, Red) [(15, Green), (5, Blue)])
    --> [Red, Red, Green, Red, Red]
```

値の合計は100である必要はありません。いずれにせよ正規化されます。

`Random.map`を使うと、ジェネレーターの中身に手を加えられます。

```elm
generate 3 (Random.int 1 6 |> Random.map (\n -> n * 10))
    --> [30, 60, 10]
```

`Random.map2`から`Random.map5`までを使えば、さらに多くのジェネレーターを組み合わせられます。

```elm
position =
    Random.map3
      (\x y z -> Position x y z)
      (Random.float -100 100)
      (Random.float -100 100)
      (Random.float -100 100)

generate 1 position
    --> [Position 33.788 -98.321 10.0845]
```

より複雑な用途には、`Random.andThen : (a -> Generator b) -> Generator a -> Generator b`があります。これは、あるジェネレーターが生成した値を使って別のジェネレーターを作れます。

```elm
bool = Random.uniform True [False]

failHalfOfTheTime : Generator a -> Generator (Maybe a)
failHalfOfTheTime generator =
    bool
        |> Random.andThen
            (\boolResult ->
                if boolResult then
                    Random.map Just generator

                else
                    Random.constant Nothing
            )

generate 6 (Random.int 0 1 |> failHalfOfTheTime)
    --> [Nothing, Just 1, Just 0, Nothing, Just 1, Nothing]
```

ジェネレーターを自己再帰的に定義すると便利なことがあります。
そのような場合は、コンパイラーがジェネレーターを無限に展開しないように、`Random.lazy`を使う必要があるかもしれません。

```elm
type Peano
    = Zero
    | Next Peano


peano : Generator Peano
peano =
    Random.uniform (Random.constant Zero)
        [ Random.map Next (Random.lazy (\_ -> peano))
        ]
        |> Random.andThen identity

generate 12 peano
    --> [Zero, Next(Next(Zero)), Zero, Next(Zero), Zero, Zero, Next(Zero), Zero, Zero, Next(Zero), Next(Next(Next(Zero)))]
```

この例は少し重たいので、順に分解して見ていきましょう。

`Peano`は正の整数を表す型です。`Zero`は0、`Next(Zero)`は1、`Next(Next(Zero))`は2、という具合です。
`peano`は、ランダムな`Peano`の数を得るために定義します。

まず、`Random.lazy`はロジックに何も付け加えず、コンパイラーが`peano`を`peano`の中に無限に書き込み続けるのを防ぐだけであることに注意してください。

`Random.uniform`を使って、0（50%の確率）と、別の`Peano`の数に1を足したもの（50%の確率）のどちらかを選びます。
ただし、前の例とは違い、ここでは`peano`自身を使いたいので、`Random.uniform`は値（`Zero`など）からではなく、ジェネレーター（`Random.constant Zero`など）から選んでいます。
つまり、`Random.uniform`は`Generator (Generator Peano)`型の値を返すことになり、これは必要なものではありません。

ジェネレーターを「平坦化」するために、これを`Random.andThen : (a -> Generator b) -> Generator a -> Generator b`にパイプします。ここでは`b`を`Peano`にしたいわけです。
`Generator a`が`Generator (Generator Peano)`なので、`a`は`Generator Peano`であり、関数`(a -> Generator b)`は`(Generator Peano -> Generator Peano)`型でなければなりません。
何も変更したくないので、`identity`が適切な選択です。

最後に、`peano`はどんな数を作るのでしょうか？
50%の確率で0を、残りの50%の確率で自分自身の別の繰り返しに1を足したものを生成することがわかっています。
つまり、生成される数は、0（50%）、1（25%）、2（12%）、3（6%）などになります。
`peano`はいくらでも大きな数を生成できますが、その確率は指数的に減少します。
