# はじめに

Javaでは、メソッドのオーバーロードは、仮引数リストが異なっていれば、1つのクラスに同じ名前のメソッドを複数持つことを可能にする機能です。これはコンパイル時ポリモーフィズム（静的ポリモーフィズム）に関係します。この概念は、似た処理を異なる入力で行うメソッドを作るうえで重要です。

## なぜメソッドをオーバーロードするのか？

メソッドのオーバーロードは、プログラムの可読性を高めます。仮引数の数や型が異なれば、異なるメソッドに同じ名前を付けることができます。仮引数の数や型に応じて、対応するメソッドが呼び出されます。

## メソッドをオーバーロードするには

メソッドのオーバーロードの鍵となるのは、メソッドのシグネチャです。シグネチャが異なれば、2つのメソッドは別のものと見なされます。メソッドをオーバーロードするには、2つの方法があります。

1. **仮引数の数が異なる場合**：同じ名前でも、仮引数の数が異なるメソッドを定義できます。

   ```java
   public class Display {

       public void show(int x) {
           System.out.println("Show with int: " + x);
       }

       public void show(int x, int y) {
           System.out.println("Show with two ints: " + x + ", " + y);
       }
   }
   ```

2. **仮引数の型が異なる場合**：同じ名前で仮引数の数も同じでも、型が異なるメソッドを定義できます。

   ```java
   public class Display {

       public void show(int x) {
           System.out.println("Show with int: " + x);
       }

       public void show(String s) {
           System.out.println("Show with String: " + s);
       }
   }
   ```

## 覚えておきたいポイント

- オーバーロードしたメソッドは、引数リストを変更する必要があります。
- オーバーロードしたメソッドは戻り値の型も変更できますが、戻り値の型を変えただけではメソッドのオーバーロードにはなりません。
- メソッドは、同じクラス内でもサブクラス内でもオーバーロードできます。

この概念では、Javaにおけるメソッドのオーバーロードのさまざまな例とニュアンスを見ていきます。
