# 詳細

[マップ][maps]は、キーと値のペアを保持するデータ構造です。

- キーはどんな型でも構いませんが、一意でなければなりません。
- 値もどんな型でも構いません。一意である必要はありません。
- マップは、そのように見えることがあるものの、内容の順序を保証しません。
  - この誤った認識は、内部の実装によるものです。
    - 要素数が少ないとき（32エントリ以下）は、順序を持つ[キーワードリスト][keyword-list]として実装されます。
    - 要素数が多いとき（32エントリより大きい場合）は、[hash array mapped trie][hamt] &#91;[1][stackoverflow]&#93;として実装されます。
- マップはリテラル形式で宣言できます。

  ```elixir
  # An empty map
  %{}

  # A map with the atom key :a associated to the integer value 1
  %{a: 1}

  # A map with the string key "a" associated to the float value 2.0
  %{"a" => 2.0}

  # A map with the map key %{} with the list value [1 ,2, 3]
  %{%{} => [1, 2, 3]}

  # A map with keys of different types
  %{:a => 1, "b" => 2}
  ```

- マップは、[Mapモジュール][map-module]の[`Map.new`][map-new]を使って生成することもできます。すでにマップに変換したい列挙可能なコレクションがある場合に使えます。

  ```elixir
  kw_list = [a: 1, b: 2]
  Map.new(kw_list)
  # => %{a: 1, b: 2}
  ```

- マップの値には、さまざまな方法でアクセスできます。

  ```elixir
  my_map = %{key: "value"}

  # with a dot if the key is an atom
  my_map.key
  # => "value"

  # with [], a syntax provided by the Access behaviour
  my_map[:key]
  # => "value"

  # with pattern matching
  %{key: x} = my_map
  x
  # => "value"

  # with Map.get/2
  Map.get(my_map, :key)
  # => "value"
  ```

- 標準ライブラリに含まれる[Mapモジュール][map-module]には、マップを扱うための便利な関数がたくさんあります。

  ```elixir
  Map.delete(%{a: 2, b: 3}, :a)
  # => %{b: 3}
  ```

- マップは[`Enumerable`][enumerable]プロトコルを実装しているので、[Enumモジュール][enum]の関数を使えます。
- [Map][map-module]や[Enumモジュール][enum]の関数では、[無名関数][anon-fn]や[キャプチャした関数参照][captured-fn]を引数として求められることがよくあります。

  ```elixir
  # Increment the value by one, if it is not found, update it with 0
  Map.update(%{a: 1}, :a, 0, &(&1 + 1))
  # => %{a: 2}

  # Sorting by a specific sub-value
  list = [{"A", 4}, {"B", 3}, {"C", 2}, {"D", 1}]
  Enum.sort_by(list, &Kernel.elem(&1, 1))
  # => [{"D", 1}, {"C", 2}, {"B", 3}, {"A", 4}]
  ```
