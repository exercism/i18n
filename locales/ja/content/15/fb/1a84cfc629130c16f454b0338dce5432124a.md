# 概要

Elmの[`Array`][array]は、同じ型の0個以上の値を保持する、高速で不変なコレクションです。
配列は不変なので、一度作成されると、その値を変更することはできません。
配列には（リストのような）リテラル構文がないため、代わりにArray.fromListの構文を使います。
たとえば、"a"、"b"、"c"が入った`Array`は、通常`Array.fromList ["a", "b", "c"]`のように表されます。
これは、コンソール出力やデバッガーなど、いろいろな場所で目にすることになります。

[デフォルトインポート][default-imports]である`List`とは異なり、`Array`モジュールは明示的にインポートする必要があります。`import Array`などと書いてインポートします。

リストの型注釈は、次のように定義できます。

```elm
Array String --> an array of String
Array Int --> an array of Int
```

配列は次のように定義できます。

```elm
import Array exposing (Array)

empty : Array Char
empty = Array.empty

singleValue = Array.fromList [ 5 ] --> Array Int

repeatSingleValue = Array.repeat 2 5 --> Array.fromList [ 5, 5 ]

initialiseFromIndex = Array.initialise 3 (\index -> index * 2) --> Array.fromList [ 0, 2, 4 ]

initialisefromList = Array.fromList [ "a", "b", "c" ] --> Array.fromList [ "a", "b", "c" ]
```

配列に要素を追加するには、`Array.push`を使います。

```elm
twoToFour = Array.fromList [ 2, 3, 4 ]
oneToFour = Array.push 1 twoToFour --> Array.fromList [ 1, 2, 3, 4 ]
```

配列を連結するには、`Array.append`を使います。

```elm
sixSeven = Array.fromList [ 6, 7 ]
eightNine = Array.fromList [ 8, 9 ]
Array.append sixSeven eightNine --> Array.fromList [ 6, 7, 8, 9 ]
```

配列の要素を取り出すには、`Array.get`を使います。

```elm
sixSeven = Array.fromList [ 6, 7 ]
Array.get 0 sixSeven --> Just 6
```

配列の要素を設定するには、`Array.set`を使います。

```elm
sixSeven = Array.fromList [ 6, 7 ]
Array.set 1 8 sixSeven --> Array.fromList [ 6, 8 ]
```

配列を操作するのは、[`Array`モジュール][array-module]で定義された関数です。

```elm
oneTwo = Array.fromList [ 1, 2 ]
Array.length oneTwo --> 2
```

`Array`を変更するように見える関数や演算子も（要素の追加など）、実際には新しい`Array`を返します。
ただし、`Array`の実装が不要な割り当てやコピーを防いでくれるため、通常はパフォーマンスが問題になることはありません。
