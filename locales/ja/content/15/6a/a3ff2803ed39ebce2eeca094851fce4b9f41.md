# はじめに

[`fractions`][fractions]モジュールを使うと、[`rational numbers`][rational]を扱えるようになります。有理数とは、整数の分子を整数の分母で割った分数のことです。
たとえば、`2/3`を近似値である`float`の`0.6666...`ではなく、正確な分数として保存できます。

`int`、`float`、`complex`の数値とは異なり、分数にはリテラル表現がありません。
ただし、分数のコンストラクターはとても柔軟です。

最もわかりやすいのは、2つの整数を引数に取る使い方です。
公約数は自動的に約分され、分数は「最も簡単な形」（_その分数を正確に表す最小の整数_）に変換されます。

```python
>>> from fractions import Fraction

>>> f1 = Fraction(2, 3) # 2/3
>>> f1
Fraction(2, 3)

>>> f2 = Fraction(6, 9)
>>> f2
Fraction(2, 3)  # automatically simplified

>>> f1 == f2
True
```

分数のコンストラクターは、文字列の表現を解析することもできます。

```python
>>> f3 = Fraction('2/3')
>>> f3
Fraction(2, 3)
```

分数は`float`の引数も扱えますが、小数の値を内部で2進数として近似して表現する性質上、問題が起きることがあります。
この表現の問題について詳しくは、[0.30000000000000004][0.30000000000000004]のウェブサイトと、Pythonドキュメントの[浮動小数点数の算術演算：問題と制限][fp-issues]を参照してください。

浮動小数点数を分数と一緒に使うときに、より信頼できる結果を得たい場合は、`<fraction>.limit_denominator()`メソッドがあります。


## 分数を使った算術

通常の[`arithmetic operators`][operators]`+ - * / **`は、他の数値型と同じように分数でも使えます。

整数や別の`Fraction`を式に含めると、結果は`Fraction`になります。
`float`を式に含めると結果は`float`になり、精度が（おそらく）失われます。

```python
>>> Fraction(2, 3) + Fraction(1, 4) # addition
Fraction(11, 12)

>>> Fraction(2, 3) * Fraction(6, 5) # multiply fractions
Fraction(4, 5)

>>> Fraction(2, 3) * 6 / 5 # fraction with integers
Fraction(4, 5)

>>> Fraction(2, 3) * 1.2  # fraction with float -> float
0.7999999999999999

>>> Fraction(2, 3) ** 2  # exponentiation with integer
Fraction(4, 9)
```

さまざまな標準のPython数値関数も、`int`や`float`型を扱うときと同じように、期待どおりの結果を返します。

```python
>>> round(Fraction(11, 3))
4

>>> from math import floor, ceil
>>> floor(Fraction(11, 3))
3
>>> ceil(Fraction(11, 3))
4

>>> float(Fraction(11, 3))
3.6666666666666665
```
