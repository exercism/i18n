# リプレゼンターの正規化

[JavaScriptのリプレゼンター][github-javascript-representer]では、次の正規化が行われます。

## コメントの削除

コメントはすべて削除されます。
次の例は、どちらも同じものとして扱われます。

### コメント付きの例

```javascript
/**
 * Returns the string literal 'hi there' just to say hello
 * @return [String]
 */
function hello(/* nothing*/) {
  // just return it
  return 'hi there';
}
```

### コメントなしの例

```javascript
function hello() {
  return 'hi there';
}
```

## 空白の正規化

コードをリプレゼンターで処理するとき、重要なのはその_順序_であり、物理的な位置ではありません。
つまり、空白が正規化されます。
次の例は、どちらも同じものとして扱われます。

### 2スペースでインデントした例

```javascript
function hello() {
  return 'hello world';
}
```

### 4スペースでインデントした例

```javascript
function hello() {
  return 'hello world';
}
```

### 変わったインデントの例

```javascript
function hello() {
  return 'hello world';
}
```

## 識別子の正規化

識別子はプレースホルダーの値に正規化されます。

### 変更前

```javascript
const MY_CONSTANT = 42;

function answer(multiplier, addition = 1) {
  return MY_CONSTANT * multiplier + addition;
}
```

### 変更後

```javascript
const PLACEHOLDER_1 = 42;

function PLACEHOLDER_2(PLACEHOLDER_3, PLACEHOLDER_4 = 1) {
  return PLACEHOLDER_1 * PLACEHOLDER_3 + PLACEHOLDER_4;
}
```

[github-javascript-representer]: https://github.com/exercism/javascript-representer
