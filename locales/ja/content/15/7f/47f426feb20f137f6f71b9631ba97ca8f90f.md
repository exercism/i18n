# ヒント

## 全般

- インスタンス変数を参照したり定義したりするには、`@`に続けて変数名を書きます。

## 1. `TaskHandler`を初期化する

- `Proc`を作るには、`-> (args) { block }`という構文を使います。
- `Proc`をインスタンス変数に定義するときは、型を明示する必要があります。変数名のあとに`: Proc(<arg_type>, <return_type>)`を追加すると明示できます。または、`-> (arg_1 : <arg_type>) : <return_type> { block }`という構文を使います。
- `Proc`は、引数が0以上かどうかを比較する必要があります。

## 2. タスクの条件ロジックを更新する

- このメソッドは、ブロックを引数として受け取り、それを`@task_condition_logic`インスタンス変数に代入する必要があります。

## 3. 次のタスクを実行する

- `Proc`を実行するには、`call`メソッドを使います。このメソッドは、その`Proc`への引数を受け取ります。
