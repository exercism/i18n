# 説明

この演習では、国際ダイヤルコードの辞書を使って、国際ダイヤルコードを管理するコードを書きます。

この辞書では、キーに整数（ダイヤルコード）、値に文字列（国名）を使います。

`DialingCodes`静的クラスを扱う9つのタスクがあります。

## 1. 新しい辞書を作成する

空の辞書を返す（静的）メソッド`DialingCodes.GetEmptyDictionary()`を実装してください。

```csharp
DialingCodes.GetEmptyDictionary();
// => empty dictionary
```

## 2. あらかじめ値が入った辞書を作成する

あらかじめ値が入った辞書があり、次の3つのダイヤルコードが含まれています。"United States of America"はコード1、"Brazil"はコード55、"India"はコード91です。あらかじめ値が入った辞書を返す（静的）メソッド`DialingCodes.GetExistingDictionary()`を実装してください。

```csharp
DialingCodes.GetExistingDictionary();
// => 1 => "United States of America", 55 => "Brazil", 91 => "India"
```

## 3. 空の辞書に国を追加する

辞書を作成し、ダイヤルコードと対応する国名を追加する（静的）メソッド`DialingCodes.AddCountryToEmptyDictionary()`を実装してください。

```csharp
DialingCodes.AddCountryToEmptyDictionary(44, "United Kingdom");
// => 44 => "United Kingdom"
```

## 4. 既存の辞書に国を追加する

空でない辞書に、ダイヤルコードと対応する国名を追加する（静的）メソッド`DialingCodes.AddCountryToExistingDictionary()`を実装してください。

```csharp
DialingCodes.AddCountryToExistingDictionary(DialingCodes.GetExistingDictionary(),
  44, "United Kingdom");
// => 1 => "United States of America", 44 => "United Kingdom", 55 => "Brazil", 91 => "India"
```

## 5. ダイヤルコードに対応する国名を取得する

ダイヤルコードを受け取り、対応する国名を返す（静的）メソッド`DialingCodes.GetCountryNameFromDictionary()`を実装してください。そのダイヤルコードが辞書に含まれていない場合は、空の文字列を返します。

```csharp
DialingCodes.GetCountryNameFromDictionary(
  DialingCodes.GetExistingDictionary(), 55);
// => "Brazil"

DialingCodes.GetCountryNameFromDictionary(
  DialingCodes.GetExistingDictionary(), 999);
// => string.Empty
```

## 6. 辞書に国が存在するか確認する

辞書にダイヤルコードが存在するかどうかを確認する（静的）メソッド`DialingCodes.CheckCodeExists()`を実装してください。

```csharp
DialingCodes.CheckCodeExists(DialingCodes.GetExistingDictionary(), 55);
// => true
```

## 7. 国名を更新する

ダイヤルコードを受け取り、辞書内の対応する国名を、引数として渡された国名に置き換える（静的）メソッド`DialingCodes.UpdateDictionary()`を実装してください。そのダイヤルコードが辞書に存在しない場合、辞書は変更されません。

```csharp
DialingCodes.UpdateDictionary(
  DialingCodes.GetExistingDictionary(), 1, "Les États-Unis");
// => 1 => "Les États-Unis", 55 => "Brazil", 91 => "India"

DialingCodes.UpdateDictionary(
  DialingCodes.GetExistingDictionary(), 999, "Newlands");
// 1 => "United States of America", 55 => "Brazil", 91 => "India"
```

## 8. 辞書から国を削除する

ダイヤルコードを受け取り、対応するレコード（ダイヤルコードと国名）を辞書から削除する（静的）メソッド`DialingCodes.RemoveCountryFromDictionary()`を実装してください。

```csharp
DialingCodes.RemoveCountryFromDictionary(
  DialingCodes.GetExistingDictionary(), 91);
// => 1 => "United States of America", 55 => "Brazil"
```

## 9. 最も長い名前の国を見つける

辞書に格納されている中で最も長い国名を返す（静的）メソッド`DialingCodes.FindLongestCountryName()`を実装してください。

```csharp
DialingCodes.FindLongestCountryName(
  DialingCodes.GetExistingDictionary());
// => "United States of America"
```
