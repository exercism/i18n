# はじめに

Fundamentalsの概念で見たように、AWKのプログラムは**パターンとアクションの組**でできています。

```awk
pattern1 { action1 }
pattern2 { action2 }
...
```

## 「パターン」とは

「パターン」とは、任意のAWK式のことです。
式を評価した結果が真とみなされるかどうかで、アクションを実行するかどうかが決まります。

## 空のパターン

パターンは省略できます。
その場合、アクションはすべてのレコードに対して実行されます。

passwdファイルにあるすべてのユーザー名を出力してみましょう。

```sh
awk -F: '{print $1}' /etc/passwd
```

## 正規表現

AWKでは、文字列を正規表現と照合して、真偽値の結果を得ることができます。

特定のフィールドを照合するには、正規表現の照合演算子`~`を使います。
この演算子は、左側のオペランドに文字列、右側のオペランドに正規表現を取ります。
正規表現リテラルは、`/`で囲んで書きます。

passwdファイルの中から、bashでログインするユーザーを見つけるには、次のようにします。

```sh
awk -F: '$7 ~ /bash/ {print $1}' /etc/passwd
```

`!~`は「正規表現が一致**しない**」ことを表す演算子です。

現在のレコードに対して正規表現を照合するには、`$0 ~ /regex/`と書きます。
これは非常によく使われるので、省略形が用意されています。`$0`と`~`を省いて、単に`/regex/`と書けるのです。

```sh
awk '/regex/' data.txt
```

~~~~exercism/note
そのAWKのワンライナーを、同等のgrepコマンドと比べてみましょう。

```sh
grep 'regex' data.txt
```

AWKは、簡潔さを犠牲にすることなく、プログラミング言語そのものを与えてくれます。
~~~~

## 式

AWKの式（算術式でも論理式でも、その他の式でも）は、パターンとして使えます。

UIDが1000以上のユーザーをすべて取り出すには、次のようにします。

```sh
awk -F: '$3 >= 1000' /etc/passwd
```

AWKで偽とみなされるのは、数値のゼロと空文字列だけです。それ以外の数値や文字列はすべて真になります。
数値や文字列に評価される式であれば、どんな式でもパターンとして使えます。

## 関数

[組み込み][builtins]関数や[ユーザー定義][user-defined]関数は、式の中で、つまりパターンの中で使えます。
例をいくつか挙げます。

```awk
length($1) {print "first field is not empty"}
```
```awk
toupper(substr($1, 1, 1)) ~ /[AEIOU]/ {print "starts with a vowel"}
```

## 定数のパターン

AWKでよく使われる書き方があります。

```sh
{
    xyz()   # some code that transforms each record
}
1
```

`1`は真になるパターンで、対応するアクションがありません。
これは「現在のレコードを出力する」という意味です。
