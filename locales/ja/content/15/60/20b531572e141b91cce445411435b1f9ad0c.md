# はじめに

繰り返しとは、コレクション（`Array`や`Hash`など）の中身を順番に見ていき、それぞれのオブジェクトに何らかの操作を加えることです。

繰り返しはRubyの重要な概念で、並べ替え（`sort_by`）やグループ化（`group_by`）、変換（`map`）、畳み込み（`reduce`）など、さまざまな場面で使われます。
コレクションを順に処理するときは、ループではなく繰り返しを使うのがRubyらしい書き方で、実際によく目にします。

`map`と`with_index`を使ったシンプルな繰り返しは、次のとおりです。

```ruby
words = %w[the cat sat on the mat]
list = words.map.with_index do |word, index|
  "#{index}. #{word}"
end

puts list

# Output:
# 0. the
# 1. cat
# 2. sat
# 3. on
# 4. the
# 5. mat
```
