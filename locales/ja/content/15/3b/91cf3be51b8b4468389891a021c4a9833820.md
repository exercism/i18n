# はじめに

Pythonの組み込みの数値には、整数（[`int`][int]）、浮動小数点数（[`float`][float]）、複素数（[`complex`][complex]）の3種類があります。
分数（[`fractions.Fraction`][fractions]）と小数（[`decimal.Decimal`][decimals]）も、標準ライブラリからのインポートで利用できます。

小数点以下を**持たない**整数、たとえば16進数（[_`hex()`_][hex]）、8進数（[_`oct()`_][oct]）、2進数（[_`bin()`_][bin]）の数値も、`ints`として扱われます。

```python
# Ints are whole numbers.
>>> 1234
1234
>>> type(1234)
<class 'int'>

>>> -12
-12
```

小数点を含む数値は、小数部分があってもなくても、`floats`として扱われます。

```python
>>> 3.45
3.45
>>> type(3.45)
<class 'float'>
```

## 算術

Pythonは、これらの異なる数値型の間での算術演算を完全にサポートしており、二項算術演算子（`+`・`-`・`*`・`/`・`//`・`%`）を使うときには、より範囲の狭い数値を、より範囲の広い相手に合わせて変換します。

### 足し算と引き算

足し算と引き算の演算子は、普通の数学と同じように動作します。
オペランドの1つ以上が`float`であれば、残りの`int`も`float`に変換されます。

```python
>>> 5 - 3
2
# The int is widened to a float here, and a float is returned.
>>> 3 + 4.0
7.0
```

### 掛け算

足し算や引き算と同様、掛け算でも、より範囲の狭い数値を、より範囲の広い相手に合わせて変換します。

```python
>>> 3 * 2
6

>>> 3 * 2.0
6.0
```

### 割り算

割り算は、結果が整数になっても、常に`float`を返します。

```python
>>> 6/5
1.2

>>> 6/2
3.0
```

### 切り捨て除算

`int`の結果が必要なときは、切り捨て除算を使って結果を切り捨てられます。
切り捨て除算は`//`演算子で行います。

```python
>>> 6//5
1

>>> 6//2
3
```

### 余り

余りの演算子（`%`）は、2つのオペランドを割った余りを返します。

```python
# The result of % is zero here, because dividing 8 by 2 leaves no remainder
>>> 8 % 2
0

# The result of % is 2 here, because 3 only goes into 5 once, with 2 leftover
>>> 5 % 3
2
```

5 % 3を別の見方で考えると、次のようになります。

```python
>>> whole_part = int(5/3)
1

>>> decimal_part = 5/3 - whole_part
0.6666666666666667

>>> whole_remainder = decimal_part * 3
2.0
```

## 丸め

Pythonには、浮動小数点数を指定した小数点以下の桁数に丸めるための組み込み関数[`round(number, <decimal_places>)`][round]があります。
小数点以下の桁数を指定しない場合、数値は最も近い整数に丸められ、`int`を返します。

```python
>>> round(3.1415926535, 2)
3.14

>>> round(3.1415926535)
3
```

## 優先順位と括弧

Pythonでは、括弧を使って式をまとめることができます。
これは、演算の既定の順序を変えたいときに便利です。

```python
>>> 2 + 3 * 4
14

>>> (2 + 3) * 4
20
```

Pythonは、演算子の優先順位について[PEMDAS][pemdas]の規則に従います。
つまり、`()`の中の計算が最も優先され、次に`**`、その次に`*`・`/`・`//`・`%`・`+`・`-`の順になります。

```python
>>> 2 + 3 - 4 * 4
-11

>>> (2 + 3 - 4) * 4
4

# In the following example, the `**` operator has the highest priority, then `*`, then `+`
# Meaning we first do 4 ** 4, then 3 * 64, then 2 + 192
>>> 2 + 3 * 4 ** 4
770
```

## 精度と表現

Pythonの整数は[任意精度][arbitrary-precision]を持ち、桁数はホストシステムで利用できるメモリによってのみ制限されます。

浮動小数点数は通常、Cの`double`（_精度は小数点以下15桁_）を使って実装されますが、表現はホストシステムによって異なります。
複素数には`real`と`imaginary`の部分があり、どちらも浮動小数点数で表されます。

プログラミング言語をまたいだ浮動小数点演算の問題や制限についてさらに詳しく知りたい場合は、[0.30000000000000004.com][0.30000000000000004.com]と[The Python Tutorial][floating point math]を見てみましょう。
