# 配列のメソッド

配列は、よく使われるデータ構造です。
そのため、配列を扱うためのメソッドが数多く用意されています。
並べ替え、逆順、挿入など、さまざまなものがあります。

これらのメソッドには、元の配列を変更するもの（破壊的メソッド）もあれば、元の配列を変更せず、新しい配列を返すもの（非破壊的メソッド）もあります。

ここでは、配列を扱うときによく使うメソッドをいくつか紹介します。

## insert

配列に要素を挿入するには、[`insert`][insert]メソッドを使います。このメソッドは、インデックスと要素を引数に取ります。
要素は指定したインデックスに挿入され、それ以降の配列の要素は右にずれます。
インデックスが範囲外の場合、`IndexError`が発生します。

```crystal
numbers = [1, 2, 3]
numbers.insert(1, 4)
numbers # => [1, 4, 2, 3]

numbers.insert(5, 5) # => Error: Index out of bounds (IndexError)
```

## delete

配列から特定の要素を削除したいときは、[`delete`][delete]メソッドを使います。このメソッドは、要素を引数に取ります。
このメソッドは、削除された要素を返します。
配列にその要素が存在しない場合は、`nil`が返されます。

```crystal
numbers = [1, 2, 3]
numbers.delete(2) # => 2
numbers           # => [1, 3]
```

## first & last

配列の最初または最後の要素を取得したいときは、[`first`][first]メソッドと[`last`][last]メソッドを使います。
これらのメソッドは、返す要素の数を指定する省略可能な引数を取ります。
インデックス`0`や`-1`を使ったり、範囲を使ったりするよりも、読みやすくなります。
配列が空の場合、`Enumerable::EmptyError`が発生します。

```crystal
numbers = [1, 2, 3]
numbers.first # => 1
numbers.last  # => 3

numbers.first(2) # => [1, 2]
numbers.last(2)  # => [2, 3]

empty_array = [] of Int32
empty_array.last # => Error: Empty enumerable (Enumerable::EmptyError)
```

## reverse

配列を逆順にしたいときは、[`reverse`][reverse]メソッドを使います。このメソッドは、要素を逆順にした新しい配列を返します。
`reverse`は新しい配列を返し、元の配列は変更しないことに注意してください。
元の配列を変更したい場合は、メソッド名の末尾に`!`を付けます。

```crystal
numbers = [1, 2, 3]
numbers.reverse # => [3, 2, 1]
numbers         # => [1, 2, 3]

numbers.reverse! # => [3, 2, 1]
numbers          # => [3, 2, 1]
```

## flatten & compact & transpose & uniq

次のメソッドは、配列を一次元にしたり、`nil`の要素を削除したり、重複を削除したり、配列の配列を転置したりするときに便利です。
`reverse`と同様に、これらのメソッドは新しい配列を返し、元の配列は変更しません。

| メソッド | 説明 | 例 |
| ------ | ----------- | ------- |
| [`flatten`][flatten] | この配列を（再帰的に）一次元に平坦化した新しい配列を返します。つまり、各配列要素について、その要素を新しい配列に展開します。 | `[[1, 2], [3, 4]].flatten # => [1, 2, 3, 4]` |
| [`compact`][compact] | すべての`nil`要素を取り除いた自身のコピーを返します。 | `[1, nil, 2, nil, 3].compact # => [1, 2, 3]` |
| [`transpose`][transpose] | selfが配列の配列であると仮定し、行と列を[転置][transpose]します。 | `[[1, 2], [3, 4]].transpose # => [[1, 3], [2, 4]]` |
| [`uniq`][uniq] | 自身の重複する値を取り除いた新しい配列を返します。 | `[1, 2, 1, 3, 1].uniq # => [1, 2, 3]` |

## Concat(`+`)

配列にオブジェクトを追加したいときは、appendメソッド（`<<`）が便利です。
ただし、2つの配列を結合するときは、[`+`][concat]演算子を使います。これは、両方の配列の要素を持つ新しい配列を返します。

```crystal
[1, 2] + [3, 4] # => [1, 2, 3, 4]
```

ある配列に別の配列を追加すると、その配列は1つの要素として追加されます。

```crystal
[1, 2] << [3, 4] # => [1, 2, [3, 4]]
```

## empty?

配列が空かどうかを確認するには、[`empty?`][empty?]メソッドを使います。このメソッドは、配列が空なら`true`を、そうでなければ`false`を返します。
配列の長さを`0`と比較するよりも、読みやすくなります。

```crystal
[].empty? # => true
[1, 2, 3].empty? # => false
```

## index

配列内の要素のインデックスを取得したいときは、[`index`][index]メソッドを使います。このメソッドは、要素を引数に取ります。
配列にその要素が存在しない場合は、`nil`が返されます。

```crystal
numbers = [1, 2, 3]
numbers.index(2) # => 1
```

## size

配列の要素数を知りたいときは、[`size`][size]メソッドを使います。

```crystal
numbers = [1, 2, 3]
numbers.size # => 3
```

## count

配列に要素が何回現れるかを数えたいときは、[`count`][count]メソッドを使います。

```crystal
fruits = ["apple", "banana", "apple"]
fruits.count("apple")      # => 2
fruits.count("banana")     # => 1
fruits.count("watermelon") # => 0
```

## sort

配列を並べ替えたいときは、[`sort`][sort]メソッドを使います。このメソッドは、要素を並べ替えた新しい配列を返します。
`reverse`と同様に、このメソッドは新しい配列を返し、元の配列は変更しません。

```crystal
numbers = [3, 2, 1]
numbers.sort # => [1, 2, 3]
numbers      # => [3, 2, 1]

numbers.sort! # => [1, 2, 3]
numbers       # => [1, 2, 3]
```
