# 説明

近所の学校には、とても活発な生徒会があります。
生徒会は会長によって運営され、2年ごとに新しい会長を選ぶ選挙が行われます。

今年の選挙では、票を数えるための新しいデジタルシステムが必要だということになりました。
学校は、この新しいシステムの構築に助けを求めています。

## 1. 投票カウンターを作りましょう

新しい投票システムに最初に必要なものの1つが、票を数えるカウンターです。
このカウンターは、特定の候補者が獲得した票を把握しておくためのものです。

`NewVoteCounter`という関数を作りましょう。この関数は、候補者の初期の票数を受け取り、その票数で初期化された`int`を指すポインタを返します。

```go
var initialVotes int
initialVotes = 2

var counter *int
counter = NewVoteCounter(initialVotes)
*counter == initialVotes // true
```

## 2. カウンターから票数を取得しましょう

これで新しいカウンターを作れるようになりました！　しかし、新しいシステムにはカウンターから票数を取得する方法も必要だということに気づきます。

`VoteCount`という関数を作りましょう。この関数はカウンター（`*int`）を引数に取り、そのカウンターの票数を返します。
カウンターが`nil`の場合は、票がないものとして扱います。

```go
var votes int
votes = 3

var voteCounter *int
voteCounter = &votes

VoteCount(voteCounter)
// => 3

var nilVoteCounter *int
VoteCount(nilVoteCounter)
// => 0
```

## 3. カウンターの票を増やしましょう

いよいよ票を数えるときです！　次に必要なのは、カウンターの票を増やす方法です。

`IncrementVoteCount`という関数を作りましょう。この関数はカウンター（`*int`）と票数を引数に取り、その票数だけカウンターを増やします。
渡されるポインタは決して`nil`にならないと仮定してかまいません。

```go
var votes int
votes = 3

var voteCounter *int
voteCounter = &votes

IncrementVoteCount(voteCounter, 2)

votes == 5          // true
*voteCounter == 5   // true
```

## 4. 選挙結果を作りましょう

すべての票を数え終えたので、次は学校全体への結果発表を準備するときです。
ただ、ここで、票のカウンターだけでは足りないことに気づきます。
票数を特定の候補者と結びつける方法が必要です。

`NewElectionResult`という関数を作りましょう。この関数は候補者の名前とその票数を受け取り、新しい選挙結果を返します。

```go
var result *ElectionResult
result = NewElectionResult("Peter", 3)

result.Name == "Peter"  // true
result.Votes == 3       // true
```

選挙結果の構造体はすでに用意されており、次のように定義されています：

```go
type ElectionResult struct {
    // Name of the candidate
    Name    string
    // Votes of votes the candidate had
    Votes   int
}
```

## 5. 結果を発表しましょう

新しい会長を学校に発表するときです！
会長は、学校にある小さなデジタル掲示板で発表されます。
メッセージには、新しい会長の名前と獲得した票数を、`<candidate_name> (<votes>)`という形式で表示します。
そのようなメッセージの例は、`"Peter (51)"`です。

`DisplayResult`という関数を作りましょう。この関数は`*ElectionResult`を引数に取り、表示するメッセージの文字列を返します。

```go
var result *ElectionResult
result = &ElectionResult{
    Name: "John",
    Votes: 32,
}

DisplayResult(result)
// => John (32)
```

## 6. 票の数え直し

最終結果が正確かどうかを確かめるために、票が数え直されました。
数え直しでは、一部の候補者の票数が1票ずれていることが分かりました。

`DecrementVotesOfCandidate`という関数を作りましょう。この関数は最終結果と、票数を1減らす対象の候補者の名前を受け取ります。
最終結果は`map[string]int`の形式で渡され、キーは候補者の名前、値はその候補者の総票数です。

```go
var finalResults = map[string]int{
    "Mary":  10,
    "John":  51,
}

DecrementVotesOfCandidate(finalResults, "Mary")

finalResults["Mary"]
// => 9
```
