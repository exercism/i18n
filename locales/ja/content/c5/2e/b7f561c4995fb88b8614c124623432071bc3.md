# 説明

この演習では、半構造化されたログメッセージを生成します。

## 半構造化メッセージを出力する

まず、いくつかのスタブ関数と、次の列挙型から始めます。

```rust
#[derive(Drop, Clone, PartialEq, Debug)]
pub enum LogLevel {
    Info,
    Warning,
    Error,
    Debug
}
```

目標は、次の形式でログメッセージを出力することです：`"[<LEVEL>]: <MESSAGE>"`。
ログレベルに対応する関数を実装する必要があります。

たとえば、次のコードは`log`関数で期待される出力を示しています。

```rust
log(LogLevel::Error, "Stack overflow")
// Returns: "[ERROR]: Stack overflow"
```

`info`の場合は次のとおりです。

```rust
info("Timezone changed")
// Returns: "[INFO]: Timezone changed"
```

それでは、楽しんでください！
