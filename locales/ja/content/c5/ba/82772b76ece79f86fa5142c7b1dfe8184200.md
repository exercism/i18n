# 概要

Haxeでは、**配列**は（たいていは）同じ型の要素を集めたものです。Haxeで配列を作る方法は3つあります。コンストラクターを使う方法と、宣言構文を使う方法です。Haxeでは、配列の最初の要素のインデックスは0です。

```haxe
var a = [1, 2, 3];
trace(a); // [1,2,3]

// Here the second element is called by index
trace(a[1]); // 2

// The actual first element's index is 0
trace(a[0]); // 1
```

コンストラクターを使って配列を作るには、その配列に含める要素の型を渡す必要があります。

```haxe
var a:Array<Int> = [0, 1, 2, 3];
a[1] = "Hello"; // Error: the array a takes integers only
```

Haxeの配列アクセスには境界チェックがなく、つまり例外が投げられないことが保証されているので、これについてはもう少し詳しく説明する必要があります。

- 存在しないインデックスを読み取ると、ターゲットに依存する値が返されます。
- 範囲外の正のインデックスに書き込むと、最後に定義されているインデックスと新しく書き込んだインデックスの間のすべての位置に、`null`（静的ターゲットでは基本型のデフォルト値）が挿入されます。
- 負のインデックスに書き込んだ場合、結果は未定義です。

配列に複数の型の要素を入れたい場合は、型指定に`Dynamic`型を追加します。

```haxe
var a:Array<Dynamic> = [10, "Bob", true]
```

## 繰り返し

配列は`for`ループを使って繰り返し処理できます。

```haxe
var nums = [2, 3, 5];
var sum = 0;
for (num in nums) {
  sum += num;
}
trace(sum); // 10
```
