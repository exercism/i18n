# はじめに

## 型変換

Goでは、異なる型の間で明示的に変換する必要があります。
型の間の変換（**型キャスト**とも呼ばれます）は、変換先の型と同じ名前の関数を使って行います。
たとえば、`int`を`float64`に変換するには、次のようにします:

```go
var x int = 42 // x has type int
f := float64(x) // f has type float64 (ie. 42.0)
```

## プリミティブ型と文字列の変換

プリミティブ型（`int`など）と`string`の間の変換には、`strconv`パッケージがあります。

```go
import "strconv"

var intString string = "42"
var i, err = strconv.Atoi(intString)

var number int = 12
var s string = strconv.Itoa(number)
```

## 型アサーション

Goのインターフェースは、その基になっている型について曖昧さを生むことがあります。
型アサーションを使うと、`interfaceVariable.(concreteType)`という構文で、インターフェース値が基にしている具体的な値を取り出せます。

たとえば:

```go
var input any = 12
number := input.(int)
```

注意: インターフェース変数がその具体的な型の値を持っていない場合、これはパニックを引き起こします。

インターフェース値が特定の具体的な型の値を持っているかどうかは、型アサーションの2つの戻り値、つまり基になっている値と、アサーションが成功したかどうかを報告する真偽値の両方を使うことで確認できます。
たとえば:

```go
str, ok := input.(string) // no panic if input is not a string
```

`input`が`string`を持っていれば、`str`が基になっている値になり、`ok`は`true`になります。
`input`が`string`を持っていなければ、`str`は`string`型のゼロ値（つまり`""`、空の文字列）になり、`ok`は`false`になります。
どちらの場合もパニックは起きません。

## 型スイッチ

**型スイッチ**を使うと、複数の型アサーションを連続して実行できます。
構文は型アサーション（`interfaceVariable.(concreteType)`）と同じですが、`concreteType`がキーワード`type`に置き換わります。
例を見てみましょう:

```go
var i any = 12 // try: 12.3, true, int64(12), []int{}, map[string]int{}

switch v := i.(type) {
case int:
    fmt.Printf("the integer %d\n", v)
case string:
    fmt.Printf("the string %s\n", v)
default:
    fmt.Printf("type, %T, not handled explicitly: %#v\n", v, v)
}
```
