# はじめに

Common Lispには、さまざまな等価性述語があります。
これは、等価性述語が1つか2つしかないこともある他のプログラミング言語とは異なります（たとえば`==`と`===`など）。
Common Lispのこれらの述語には、特定の型に固有のものもあれば、汎用的なものもあります。ここでは後者について見ていきます。

汎用的な等価性述語は4つあり、何を「等しい」とみなすかの厳しさがそれぞれ異なります。
厳しいものから緩いものへと並べると、`eq`、`eql`、`equal`、`equalp`の順になります。

簡単に定義すると、次のようになります（細かい点はいくつか省きます）。

- `eq`: 2つのオブジェクトが同一であることを「等しい」と定義します。
  例:

```lisp
(eq 'a 'a)                 ; => T
(eq (list 1 2) (list 1 2)) ; => NIL
```

- `eql`: 同じ型と同じ値を持つ2つの数値、同じ文字、あるいはそれ以外のものであれば`eq`であることを「等しい」と定義します。
  例:

```lisp
(eql 1 1)     ; => T
(eql #\a #\a) ; => T
(eql 1 1.0)   ; => NIL
(eql #\a #\A) ; => NIL
```

- `equal`: 「等しい」を次のように定義します。2つのリストは、すべての要素も`equal`であれば`equal`です。2つの文字列は、すべての要素が`eql`であれば`equal`です。2つの配列は、`eq`であれば`equal`です。それ以外はすべて、`eql`であれば`equal`です。
  例:

```lisp
(equal (list 1 2) (list 1 2)) ; => T
(equal #(1 2) #(1 2))         ; => NIL
(equal "foo" "foo")           ; => T
```

- `equalp`: 「等しい」を次のように定義します。文字列と文字は大文字と小文字を区別せずに比較します。数値は何らかの型変換を行って比較します。リストと配列は、すべての要素が`equalp`であれば`equalp`です。構造体は、同じ型で、すべてのスロットが`equalp`であれば`equalp`です。ハッシュテーブルは、キーと値が`equalp`であれば`equalp`です。
  例:

```lisp
(equalp "foo" "FoO")                          ; => T
(equalp 3 3.0)                                ; => T
(equalp (make-a-structure :slot1 1 :slot2 2) 
        (make-a-structure :slot1 1 :slot2 2)) ; => T
```
