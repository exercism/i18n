# はじめに

タプルは、決まった個数の任意の型のデータをひとまとめにする、手軽な方法です。タプルには特定の名前がありません。データ構造に名前を付けると、それは`struct`になります。タプルのフィールドにも名前がなく、分解するか、位置を指定するかのどちらかでアクセスします。

## 構文

### 作成

タプルは常にタプル式で作成します。

```rust
// pointless but legal
let unit = ();
// single element
let single_element = ("note the comma",);
// two element
let two_element = (123, "elements can be of differing types");
```

タプルは任意の個数の要素を持てます。

### 分解によるアクセス

タプルの要素には、分解によってアクセスできます。これはつまり、タプルの個々の要素に変数名を割り当てて、タプルを消費するということです。

```rust
let (elem1, _elem2) = two_element;
assert_eq!(elem1, 123);
```

### 位置によるアクセス

タプルの要素には、数値の位置インデックスによってもアクセスできます。インデックスは、いつもどおり0から始まります。

```rust
let notation = single_element.0;
assert_eq!(notation, "note the comma");
```

## タプル構造体

タプル構造体も扱うことになります。通常の構造体と同じく、これらは名前を持った型です。通常の構造体と違うのは、フィールドが無名である点です。その構文は通常のタプルの構文とよく似ています。分解と位置によるアクセスのどちらも使えます。

```rust
struct TupleStruct(u8, i32);
let my_tuple_struct = TupleStruct(123, -321);
let neg = my_tuple_struct.1;
let TupleStruct(byte, _) = my_tuple_struct;
assert_eq!(neg, -321);
assert_eq!(byte, 123);
```

### フィールドの可視性

無名タプルのフィールドは、常にすべて公開されています。ただし、タプル構造体のフィールドにはそれぞれ可視性があり、標準の構造体のフィールドと同じく、既定では非公開です。標準の構造体と同じように、`pub`修飾子を使えばフィールドを公開できます。

```rust
// fails due to private fields
mod tuple { pub struct TupleStruct(u8, i32); }
fn main() { let _my_tuple_struct = tuple::TupleStruct(123, -321); }
```

```rust
// succeeds: fields are public
mod tuple { pub struct TupleStruct(pub u8, pub i32); }
fn main() { let _my_tuple_struct = tuple::TupleStruct(123, -321); }
```
