# 説明

文字列で表された8進数の数値（例：'1735263'）を、基本原理に従って10進数に変換してください（つまり、変換のために組み込みライブラリや外部ライブラリを使ってはいけません）。

8進数から10進数への変換を実装します。
8進数の入力文字列が与えられたら、プログラムは10進数の出力を生成します。

## 注意

- 変換は自分で実装してください。
  変換を代わりに行ってくれるものを利用してはいけません。
- 無効な入力は8進数の0として扱ってください。

## 8進数（基数8）について

10進数は基数10の数体系です。

基数10で表された数233は、10の累乗の線形結合として理解できます。

- 一番右の桁には10^0 = 1が掛けられます
- 次の桁には10^1 = 10が掛けられます
- ...
- n番目の桁には10^_(n-1)_が掛けられます。
- これらの値はすべて足し合わされます。

つまり:

```text
   233 # decimal
 = 2*10^2 + 3*10^1 + 3*10^0
 = 2*100  + 3*10   + 3*1
```

8進数も似ていますが、10の累乗ではなく8の累乗を使います。

つまり:

```text
   233 # octal
 = 2*8^2 + 3*8^1 + 3*8^0
 = 2*64  + 3*8   + 3*1
 = 128   + 24    + 3
 = 155
```
