# テスト

テストランナーを使うには、[Godotを正しくインストール][installation]しておく必要があります。

## テストを実行する

[テストランナー][test runner]は、解答を読み込んでテストするために使います。
テストランナーを実行するには、まずローカルにダウンロードしてから、`godot`でテストランナーを実行します。
将来的には、`exercism download`を使うと、演習と一緒にテストランナーが自動的にダウンロードされるようになります。

### テストランナーを取得する

次のシェルスニペットを使うと、テストランナーをダウンロードできます。

```bash
exercism download --track gdscript --exercise hello-world
cd "$(exercism workspace)/gdscript"
curl --remote-name https://raw.githubusercontent.com/exercism/gdscript-test-runner/refs/heads/main/bin/test_runner.gd
```

### テストランナーを実行する

テストランナーは、ヘッドレスモード（IDEなし）の`godot`で実行します。
`-s`または`--script`は、Godotにテストランナーのスクリプトを実行するよう指示します。
テストランナーには、スラッグと解答ディレクトリへのパスという2つの引数を渡します。

```bash
godot --headless -s to/test_runner.gd -- <solution-slug> <path/to/solution>
```

たとえば、

```bash
godot --headless -s "$(exercism workspace)/gdscript/test_runner.gd" -- hello-world "$(exercism workspace)/gdscript/hello-world
```
