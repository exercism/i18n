# 概要

Elixirでは、関数を動的にディスパッチできます。

モジュール名はすべてアトムです。Elixirのモジュール名はすべて、コンパイル時に自動的に`Elixir.`が先頭に付きます。

```elixir
is_atom(Enum)
# => true
Enum == Elixir.Enum
# => true
```

Elixirでは、実行時に呼び出す関数を解決できます。その際、モジュール名を使って検索します。モジュール名が変数に束縛されていれば、この検索を動的に行えます。

```elixir
defmodule MyModule do
  def message(), do: "My message"
end

atom = MyModule
atom.message()
# => "My message"
```
