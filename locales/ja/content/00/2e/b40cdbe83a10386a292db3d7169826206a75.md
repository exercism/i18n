# はじめに

Common LispにはThe Printerという概念があり、Lispのデータをテキストとして表現するためのすべての関数が含まれます。そのような関数の1つが`format`で、プログラマーが思いどおりにデータを整形できます。

`format`の機能、そしてLispのプリンター全般は広大なトピックです。ここでは`format`の基本的な使い方を説明します。

## `format`関数

`format`関数は少なくとも2つの引数を取ります。出力先のストリームと、何をどのように出力するかを定義する制御文字列です。

ストリームはそれ自体が1つの概念で、別の場所で説明します。ここでは、出力はストリームに対して行われ、この引数には`t`と`nil`という2つの特別な値があることだけ知っておけば十分です。`t`は標準出力（実際には変数`*standard-output*`が束縛されているストリーム）に出力することを意味し、`nil`は文字列を作成してそれを返すことを意味します。

`format`は、ストリームとして`nil`を指定した後者の場合を除いて、常に`nil`に評価されることに注意してください。これは、単純な文字列補間や文字列の組み立てを行うよくある方法です。

```lisp
(format nil "hello world") ; => "hello world"
(format t "hello world")   ; => NIL (but "hello world" is printed to standard output)
```

## フォーマット指示子

制御文字列には「フォーマット指示子」を含めることができ、何を出力するか、`format`への他の引数をどのように解釈するかを`format`に指示します。ある意味で、制御文字列は`format`が解釈して実行するプログラムです。すべての指示子は`~`で始まり、その後に文字が続きます（_例_：`~A`、`~D`、`~&`）。その文字は大文字でも小文字でも構いません。

ほとんどのフォーマット指示子は、`format`への引数を単に出力に埋め込むだけです。これはその引数を「消費する」と言われます。指示子の中には引数を消費しないものや、2つ以上消費するものもあります。引数リストの中を飛び回ったり、引数を飛ばしたりできる指示子さえあります。

## 基本的なフォーマット

とても汎用的なフォーマット指示子が`~A`です。これはデータを「人が読める」形で出力します。

```lisp
(format nil "Value = ~a" 10)                ; => "10"
(format nil "hello ~a" "world")             ; => "hello world"
(format nil "The list is: ~A" (list 1 2 3)) ; => "The list is: (1 2 3)"
```

もう1つ便利なフォーマット指示子が`~S`です。これはデータを「機械が読める」形で出力します。作成された出力をLispデータとして解釈できるようにしたい場合、とても役立ちます。多くのものでは`~A`と同じに見えますが、たとえば文字列の場合、出力に引用符が含まれる（別の文字列の中に入れるときはエスケープされる）ので、その値を文字列の引数として読み戻せることに注意してください。

```lisp
(format nil "~s" 10)            ; => "10"
(format nil "~s" "hello world") ; => "\"hello world\""
(format nil "~s" (list 1 2 3))  ; => "(1 2 3)"
```

もう2つ、とても便利な指示子が`~%`と`~&`です。前者は改行文字を出力し、後者は「新しい行」を出力します。違いは、`~%`が常に改行を出力するのに対し、`~&`は現在行の先頭にいない場合にのみ改行を出力する点です。どちらも引数を消費しません。

```lisp
(format nil "~%new~%lines") ; => "
                                  new
                                  lines"

(format nil "~&new~&lines"  ; => "new
                                  lines"
```

最後に、`~~`はリテラルの`~`を出力する単純な指示子です。
