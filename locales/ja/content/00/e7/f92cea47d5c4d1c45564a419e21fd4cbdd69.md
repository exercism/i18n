# はじめに

## クラス

クラスは、PHPでコードを整理するための単位です。
あるものの振る舞いや、ある処理の振る舞いを表すコードは、クラスとしてまとめることができます。
クラスに割り当てられた関数は、慣習的に`methods`と呼ばれます。

```php
<?php

class Door
{
    function lock()
    {
        // ...
    }

    function unlock()
    {
        // ...
    }
}
```

クラスは`new`キーワードでインスタンス化します。これにより、そのクラスのインスタンス用のメモリが確保され、クラスのコンストラクターメソッドが呼び出されます。
インスタンス化したクラスは、変数に代入できます。
クラスのインスタンスのメソッドを呼び出すには、`->`アクセス演算子を使います。

```php
<?php

$a_door = new Door();
$a_door->lock();
$a_door->unlock();
```

インスタンス化されたクラスは、特別な`$this`変数を使って自分自身のインスタンスを参照できます。
クラスはプロパティを持つこともできます。プロパティは、そのクラスのオブジェクトのインスタンスに結び付いた変数のように働きます。
これらのプロパティは、内部からも外部からも参照できます。

```php
<?php

class Car
{
    public $color;

    function __construct($color)
    {
        $this->color = $color;
    }

    function getColor()
    {
        return $this->color;
    }
}

$a_car = new Car("red");
$a_car->color; // => "red" by accessing the property
$a_car->getColor(); // => "red" by invoking the instance method
```
