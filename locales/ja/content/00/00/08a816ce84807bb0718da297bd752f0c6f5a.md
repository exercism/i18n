# はじめに

*正規表現*（regex）とは、テキストがどんな形であるべきかを表す小さなパターンです。Factorの正規表現ツールは[`regexp`][regexp]ボキャブラリにあり、パターンは`R/ `と`/`の間に書きます。

パターンの中のほとんどの文字は、それ自体を表します。いくつかの特別な記号は、文字の*種類*や、*いくつ*現れるかを表します。

```
\d        ! any digit 0–9
\s        ! any whitespace; \S means any non-whitespace
[A-Z]     ! any one capital letter
.         ! any single character

{4}       ! exactly 4 times       +   ! one or more
{2,5}     ! 2 to 5 times          *   ! zero or more
?         ! optional (0 or 1)
```

つまり、`R/ [A-Z]{2}-\d{4}/`は「大文字2つ、ハイフン、数字4つ」という意味です。

`matches?`は、文字列*全体*がそのパターンに当てはまるかどうかを調べます。

```
matches? ( string regexp -- ? )
```

```factor
USING: regexp ;

"NS-1024" R/ [A-Z]{2}-\d{4}/ matches? .   ! => t
"NS-10"   R/ [A-Z]{2}-\d{4}/ matches? .   ! => f
```

ほかのワードは文字列の*中*を調べます。`all-matching-subseqs`はすべての一致を返し、`count-matches`はその数を数え、`re-contains?`は一致があるかどうかを報告し、`re-replace`はそれぞれの一致を新しいテキストに置き換えます。

```
all-matching-subseqs ( string regexp -- seq )
count-matches        ( string regexp -- n )
re-contains?         ( string regexp -- ? )
re-replace           ( string regexp replacement -- result )
```

```factor
USING: regexp ;

"seen NS-1024 then AB-0007" R/ [A-Z]{2}-\d{4}/ all-matching-subseqs .
! => { "NS-1024" "AB-0007" }

"user=alice pass=hunter2" R/ pass=\S+/ "pass=****" re-replace .
! => "user=alice pass=****"
```
