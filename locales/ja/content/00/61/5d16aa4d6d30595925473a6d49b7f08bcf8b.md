# 指示

サーカスにあるハーネスはどれも、キログラム単位の荷重に耐えられるように定格が定められています。そして、その数値を確認するまでは、誰も上に上がりません。

`SAFETY_HARNESS`クラスには、次のものが必要です。スタブにはクラスとその属性が用意されています。残りを追加しましょう。以下に挙げる各ルーチンには、契約が伴います。それぞれどの契約が必要かは、ヒントに書いてあります。

## 1. ハーネスを用意する

`create`は、ハーネスの定格となる荷重を受け取り、ハーネスを返します。定格が0以下のものはハーネスとは言えないので、これは`pre`です。

```sather
harness ::= #SAFETY_HARNESS(120);
harness.limit
-- => 120
```

## 2. 余裕はどれだけある？

`spare_capacity`は、ハーネスにかかる荷重を受け取り、あとどれだけ耐えられるかを返します。荷重は負の値であってはならず、限界を超えることもできません。どちらも`pre`です。また、答えが負になることはありません。これは`post`です。

```sather
harness.spare_capacity(40)
-- => 80
```

## 3. どれくらい埋まっている？

`percent_used`は荷重を受け取り、それを限界に対するパーセンテージとして、切り捨てて返します。荷重は負の値であってはならず、答えが負になることもありません。

```sather
harness.percent_used(60)
-- => 50
```

## 4. 安全かどうか

`is_safe`は荷重を受け取り、それが限界内かどうかを答えます。どんな荷重でも、ばかげた値であっても問い合わせることができるので、荷重に対する`pre`はありません。ただし、荷重が限界内にあるとき、かつそのときに限り答えが真になる、という`post`を書きましょう。

```sather
harness.is_safe(200)
-- => false
```
