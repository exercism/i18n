# 基本

Satherのプログラムは**クラス**でできています。クラスとは、ルーチンを入れておく名前付きの箱です。**ルーチン**とは、答えを生み出す名前付きの仕事のかたまりです。

```sather
class GREETER is

   hello : STR is
      return "Hello!";
   end;

end; -- class GREETER
```

これを上から順に読んでみましょう。

- `class GREETER is`は箱を開き、名前を付けます。クラス名は大文字で書きます。
- `hello : STR is`は`hello`というルーチンを始めます。このルーチンは`STR`、つまり*文字列*と呼ばれるテキストを生み出します。`: STR`は、どんな種類の答えが返ってくるかという約束です。
- `return "Hello!";`は答えを返します。テキストは二重引用符の間に書きます。
- `end;`はルーチンを閉じ、2つ目の`end;`はクラスを閉じます。

行の中で`--`より後ろはすべて**コメント**です。Satherは無視します。これは人間のために書かれています。

```sather
-- This line is for the reader, not the computer.
```

別の場所からルーチンを使うには、クラス名、コロン2つ、ルーチン名を書きます。

```sather
GREETER::hello        -- this is "Hello!"
```

同じクラスの中なら、クラス名を省けます。

```sather
class GREETER is

   hello : STR is
      return "Hello!";
   end;

   greeting_again : STR is
      return hello;      -- calls the routine just above
   end;

end; -- class GREETER
```

引数を取らないルーチンは、括弧（`()`）なしで呼び出します。`hello`であって、`hello()`ではありません。
