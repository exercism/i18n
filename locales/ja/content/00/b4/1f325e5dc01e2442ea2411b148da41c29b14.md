# 概要

[`list`][list]は、要素を_順序_どおりに並べた、変更可能なコレクションです。ほとんどのコレクション（組み込みの[`tuple`][tuple]、[`dict`][dict]、[`set`][set]など）と同様に、配列は任意のデータ型（複数のデータ型でも可）への参照を保持できます。ほかの配列への参照も含まれます。Pythonでは[シーケンス型][sequence type]とみなされ、[スライス記法][slice notation]を使えば全体も一部もコピーできます。ほかのシーケンスと同じく、`lists`内の要素は、左からは`0-based index`番号、右からは`-1-based index`番号で参照できます。

配列は、[共通の][common sequence operations]シーケンス操作と[変更可能な][mutable sequence operations]シーケンス操作の両方をサポートしています。たとえば、`min(<list>)`/`max(<list>)`、`<list>.index()`、`<list>.append()`、`<list>.reverse()`などです。`for item in <list>`という構文を使えば要素を繰り返し処理できます。要素とそのインデックスの両方が必要なときは、`for index, item in enumerate(<list>)`を使います。

Pythonには、配列を扱うための便利な[メソッド][list-methods]がたくさん用意されています。配列は変更可能なので、配列のメソッドは、そのメソッドに渡された**元の配列オブジェクト自体を変更します**。変更したくない場合は、`slice`または`<list>.copy()`を使って、元の`list`の`shallow copy`（_少なくとも_）を作る必要があります。

## 要素の追加

既存の配列の末尾に要素を追加するには、`<list>.append(<item>)`を使います。

```python
>>> numbers = [1, 2, 3]
>>> numbers.append(9)

>>> numbers
[1, 2, 3, 9]
```

_追加_ではなく、`<list>.insert(<index>, <item>)`を使うと、配列内の_特定のインデックス_に要素を追加できます。`<index>`は、新しい要素をその_直前に_入れたい要素のインデックスです。`<item>`は挿入する要素です。

**注意**：`<index>`が0の場合、要素は配列の先頭に追加されます。`<index>`が配列の最後のインデックスより大きい場合、要素は末尾に追加されます。これは`<list>.append(<item>)`を使った場合と同じです。

```python
>>> numbers = [1, 2, 3]
>>> numbers.insert(0, -2)

>>> numbers
[-2, 1, 2, 3]

>>> numbers.insert(1, 0)

>>> numbers
[-2, 0, 1, 2, 3]
```

`<list>.extend(<iterable>)`を使うと、`iterable`を既存の配列と_連結_できます（2つをつなげる）。`<list>.extend(<iterable>)`は、渡されたイテラブルを_展開_し、その要素を同じ順序で対象の配列の末尾に追加します。この場面で`<list>.append(<item>)`を使うと、イテラブル全体が_**1つの要素**_として追加されてしまいます。

```python
>>> numbers = [1, 2, 3]
>>> other_numbers = [5, 6, 7]

>>> numbers.extend(other_numbers)

>>> numbers
[1, 2, 3, 5, 6, 7]

>>> numbers.extend([8, 9])

>>> numbers
[1, 2, 3, 5, 6, 7, 8, 9]
```

## 要素の削除

`<list>.remove(<item>)`を使うと、配列から要素を削除できます。配列にその要素が存在しない場合、`<list>.remove(<item>)`は`ValueError`を投げます。

```python
>>> numbers = [1, 2, 3]
>>> numbers.remove(2)

>>> numbers
[1, 3]

# Trying to remove a value that is not in the list throws a ValueError.
>>> numbers.remove(0)
ValueError: list.remove(x): x not in list
```

別の方法として、`<list>.pop(<index>)`メソッドを使うと、要素を削除すると同時に、その要素を`return`で返して利用できます。

`<list>.pop(<index>)`は、省略可能な仮引数を1つ取ります。削除して返す要素の`index`です。省略可能な`<index>`引数を指定しない場合は、配列の最後の要素が削除されて返されます。`<index>`が配列の最後のインデックスより大きい数値の場合、`IndexError`が投げられます。

```python
>>> numbers = [1, 2, 3]
>>> numbers.pop(0)
1

>>> numbers
[2, 3]
>>> numbers.pop()
3

>>> numbers
[2]

# This will throw an error because there is only index 0.
>>> numbers.pop(1)
Traceback (most recent call last):
  File "<stdin>", line 1, in <module>
IndexError: pop index out of range
```

`<list>.clear()`を使うと、`list`からすべての要素を削除できます。引数は取りません。

```python
>>> numbers = [1, 2, 3]
>>> numbers.clear()

>>> numbers
[]
```

## 順序の反転と並べ替え

配列の要素の順序は、`<list>.reverse()`を使うと_**その場で**_反転できます。これは元の配列を変更します。

```python
>>> numbers = [1, 2, 3]
>>> numbers.reverse()

>>> numbers
[3, 2, 1]
```

配列は、[`<list>.sort()`][sort]を使うと_**その場で**_並べ替えられます。既定の並べ替え順は、左から_昇順_です。Pythonのドキュメントには[並べ替えの追加のヒントとテクニック][sorting how to]が載っています。

~~~~exercism/note
2002年から2022年まで、Pythonは内部的に[`Timsort`][timsort]というアルゴリズムを使って配列を並べ替えていましたが、`Python 3.11`以降は[`Powersort`][powersort]に切り替えました。この変更についての詳細と、Pythonコアチームによる議論は、GitHubの[issue 78742][78742]で読むことができます。  

アルゴリズムの技術的な詳細については、J. Ian MunroとSebastian Wildによる論文[Nearly-Optimal Mergesorts: Fast, Practical Sorting Methods That Optimally Adapt to Existing Runs][nearly-optimal-mergesorts]をご覧ください。

[78742]: https://github.com/python/cpython/issues/78742
[nearly-optimal-mergesorts]: https://arxiv.org/abs/1805.04154
[powersort]: https://www.wild-inter.net/publications/munro-wild-2018
[timsort]: https://en.wikipedia.org/wiki/Timsort
~~~~

```python
>>> names = ["Tony", "Natasha", "Thor", "Bruce"]

# The default sort order is *ascending*.
>>> names.sort()

>>> names
["Bruce", "Natasha", "Thor", "Tony"]
```

配列を_降順_に並べ替えるには、メソッドに`reverse=True`という引数を渡します。

```python
>>> names = ["Tony", "Natasha", "Thor", "Bruce"]
>>> names.sort(reverse=True)

>>> names
["Tony", "Thor", "Natasha", "Bruce"]
```

元の`list`を変更したくない場合は、組み込み関数の[`sorted()`][sorted]と[`reversed()`][reversed]を使えます。`sorted(<list>)`は並べ替えた_コピー_を返し、`<list>.sort()`と同じ仮引数を取ります。`reversed(<list>)`は、配列の要素を逆順に生成する_イテレーター_を返します。`Iterators`については、別の演習で詳しく扱います。

## 配列内での要素の出現回数

配列内のある要素が何回出現するかを調べるには、`<list>.count(<item>)`を使います。配列内に`<item>`が要素として現れる回数の合計を返します。

```python
>>> items = [1, 4, 7, 8, 2, 9, 2, 1, 1, 0, 4, 3]

>>> items.count(1)
3
```

## 要素のインデックスを調べる

`<list>.index(<item>)`は、渡された要素が_最初に出現する_位置のインデックス番号を返します。出現しない場合は、`ValueError`が発生します。インデックスは左から`0-based`で、最初の要素の位置はインデックス`0`です。右からのインデックス付けもサポートされており、`-1`から始まります。

```python
>>> items = [7, 4, 1, 0, 2, 5]
>>> items.index(4)
1

>>> items.index(10)
ValueError: 10 is not in list
```

`start`と`end`のインデックスを指定すると、配列の特定の範囲内を検索します。

```python
>>> names = ["Tina", "Leo", "Thomas", "Tina", "Emily", "Justin"]
>>> names.index("Tina")
0

>>> names.index("Tina", 2, 5)
3
```

要素の正確な位置が必要ない場合は、組み込みの`in`演算子を使ったほうが、要素が含まれているかを効率よく確認できます。

```python
>>> names = ["Tina", "Leo", "Thomas", "Tina", "Emily", "Justin"]

>>> "Thomas" in names
True
```

## コピーの作成

Pythonの変数は、背後にあるオブジェクトを指す名前であることを覚えておきましょう。名前は、プログラムの実行中に別のオブジェクトに束縛したり、束縛し直したりできます。`list`オブジェクトを新しい変数_**名**_に代入しても、そのオブジェクトや参照しているデータはコピーされません。新しい名前も古い名前も、同じ`list`オブジェクトを指します。さらに、配列は_コンテナ_型のオブジェクトです。領域を節約するため、コンテナはメンバーの要素そのものではなく、要素への_参照_だけを保持します。この「最適化」は、油断していると思わぬ結果を招くことがあります。

`<list>.copy()`は新しい`list`オブジェクトを作成しますが、参照されている配列の_要素_に対して新しいオブジェクトを作成する**ことはありません**。このコピーは「浅い」コピーです。一方の`list`オブジェクトに要素を追加したり削除したりしても、もう一方を変更したくない場合には、`shallow copy`で通常は十分です。ただし、`list`の_背後の要素_が誤って変更される可能性が少しでもある場合（_その結果、関連する浅いコピーがすべて変更されます_）は、`copy`モジュールの[`copy.deepcopy()`][deepcopy]を使って、**すべての**参照とオブジェクトの完全な、つまり「深い」コピーを作成してください。

名前、値、配列、入れ子になった配列の動作についての詳しい説明は、[Ned Batchelder][ned batchelder]によるこちらの優れたブログ記事、[Names and values: making a game board][names and values]をご覧ください。[Shallow vs Deep Copying of Python Objects][shallow vs deep]にも、コピーに関する考慮事項がよくまとまっています。
