# はじめに

列を1つ1つの要素としてではなく、*かたまり*の並びとして見たいことがあります。[`grouping`][grouping]、[`splitting`][splitting]、[`splitting.monotonic`][splitting.monotonic]というボキャブラリーを使うと、そのための4つの方法が手に入ります。

## `group`（サイズ*n*の重なりのないかたまり）

```
group ( seq n -- groups )
```

```factor
USING: grouping ;

{ 1 2 3 4 5 6 7 } 3 group .
! => { { 1 2 3 } { 4 5 6 } { 7 } }
```

列の長さが*n*の倍数でない場合、最後のかたまりは*n*より短くなります。

## `clump`（サイズ*n*の重なり合うスライド窓）

```
clump ( seq n -- clumps )
```

```factor
USING: grouping ;

{ 1 2 3 4 5 } 2 clump .
! => { { 1 2 } { 2 3 } { 3 4 } { 4 5 } }
```

列が*n*より短い場合、結果は空になります。

## `split-when`（述語が該当したところで区切る）

```
split-when ( seq quot: ( elt -- ? ) -- pieces )
```

```factor
USING: splitting ;

{ 1 2 0 3 4 0 5 } [ zero? ] split-when .
! => { { 1 2 } { 3 4 } { 5 } }
```

各要素に対してそれぞれ述語が呼び出されます。真となる要素が*区切り位置*であり、結果には含まれません。

## `monotonic-split`（隣り合うペアのチェックが失敗したところで連続を区切る）

```
monotonic-split ( seq quot: ( a b -- ? ) -- pieces )
```

```factor
USING: splitting.monotonic ;

{ 1 1 2 2 2 3 } [ = ] monotonic-split .
! => { { 1 1 } { 2 2 2 } { 3 } }
```

述語は*隣り合うペア*に対して実行されます。真を返している間は同じ連続が続き、`f`を返すと新しいかたまりが始まります。`[ = ]`なら等しい要素の連続、`[ <= ]`なら減少しない連続、といった具合です。

## どれを使うべきか

- **`group`/`clump`**：欲しい*サイズ*がわかっているとき。
- **`split-when`**：*区切りになる要素*がどんなものかわかっているとき。
- **`monotonic-split`**：隣り合う2つの要素が*まだ同じかたまりに属する*のはどんな条件かわかっているとき。
