# はじめに

Goの`string`は、不変のバイト列です。そのバイトが、必ずしも文字を表しているとは限りません。

文字列リテラルは、ダブルクォーテーションで囲んで定義します。

```go
const name = "Jane"
```

文字列は、`+`演算子で連結できます。

```go
"Jane" + " " + "Austen"
// => "Jane Austen"
```

タブを表す`\t`や、文字列中の改行を表す`\n`など、一部の特殊文字は、先頭にバックスラッシュを付けてエスケープする必要があります。

```go
"How is the weather today?\nIt's sunny"  
// =>
// How is the weather today?
// It's sunny
```

`strings`パッケージには、文字列を扱うための便利な関数がたくさんあります。
文字列関数について詳しくは、[stringsパッケージのドキュメント](https://pkg.go.dev/strings)を参照してください。
以下にいくつか例を示します。

```go
import "strings"

// strings.ToLower returns the string given as argument with all its characters lowercased
strings.ToLower("MaKEmeLoweRCase")
// => "makemelowercase"

// strings.Repeat returns a string with a substring given as argument repeated many times
strings.Repeat("Go", 3)
// => "GoGoGo"
```
