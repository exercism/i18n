# はじめに

`Tuple`は、多くの点で`Vector`（1次元の`array`）とよく似ています。
ただし、いくつか重要な違いがあります。

- タプルは、角括弧（`[ ]`）ではなく丸括弧（`( )`）で書きます。ただし、意味が曖昧でない場合は丸括弧を省略できます。
- タプルは、要素が均一である必要はありません。各要素の型は個別に保持されます。
- タプルは不変です。

不変であることで、コンパイラーによる最適化がより多く行われるようになり、タプルはベクターよりも高速になります。そのため、可変性が必要ない場面では、タプルのほうを選ぶとよいでしょう。

```julia-repl
julia> t = (3, 5.2, "xyz")
(3, 5.2, "xyz")

# Non-homogeneous:
julia> dump(t)
Tuple{Int64, Float64, String}
  1: Int64 3
  2: Float64 5.2
  3: String "xyz"

julia> t[2]
5.2

# Immutable:
julia> t[2] = 7.3
ERROR: MethodError: no method matching setindex!(::Tuple{Int64, Float64, String})
```

`Tuple()`というコンストラクターもあります。これは、反復可能なコレクションをタプルに変換します。便利なことに、文字列は文字を要素とする反復可能なコレクションとして扱われます。

```julia-repl
julia> Tuple("Julia")
('J', 'u', 'l', 'i', 'a')
```

どのタプルでも、インデックスで要素にアクセスしたり、要素を繰り返し処理したりできます。

数値だけのタプルは、配列とまったく同じように、`sum()`のような数学関数で使うこともできます。

## アンパック

複数代入を使うと、タプルを個々の要素にアンパックできます。
必要のない要素には、ダミー変数としてアンダースコア`_`を使います。

```julia-repl
julia> tup = (1, "Julia", true)
(1, "Julia", true)

julia> num, name, _ = tup
(1, "Julia", true)

julia> uppercase(name), 2num
("JULIA", 2)
```

Pythonプログラマーには、この複数代入の構文はとてもなじみ深いでしょう。

## 名前付きタプル

`Tuple`が保持するのは値だけです。
`NamedTuple`は、それぞれの値に名前を組み合わせます。

個々のフィールドには、「ドット」記法でアクセスできます。

```jullia-repl
julia> nt = (a = 1, b = 7.3)
(a = 1, b = 7.3)

julia> dump(nt)
@NamedTuple{a::Int64, b::Float64}
  a: Int64 1
  b: Float64 7.3

julia> nt.b
7.3
```

名前は内部的に`Symbol`として保持されます（不変の型で、名前の先頭にはコロン`:`が付きます）。そのため、別の構文も使えます。

```julia-repl
julia> nt[:b]
7.3
```

名前（「キー」とも呼ばれます）と値は、それぞれ簡単に取り出せます。

```julia-repl
julia> nt
(a = 1, b = 7.3)

julia> keys(nt)
(:a, :b)

julia> values(nt)
(1, 7.3)
```

名前付きタプルを繰り返し処理しても得られるのは_値_だけで、_名前_は無視されることに注意してください。

タプルは（名前付きかどうかにかかわらず）、関数との間で構造化データを受け渡す、とても一般的な方法です。この用途では不変であることが役立ち、データの安全性を確保し、コンパイラーによるより積極的な最適化を可能にします。
