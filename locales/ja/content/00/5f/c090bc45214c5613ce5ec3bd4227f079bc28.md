# 説明

_Instruments of Texas_ で働くあなたは、Elixirで書かれた実験的な逆ポーランド記法[RPN]の計算機の開発を任されました。チームでは、一部の演算でエラーが発生してプロセスがクラッシュするという問題が起きています。そこで、演算関数をラップし、Elixirらしいコードでよりエレガントにエラーを処理できる関数を書くことになりました。

## 1. チームに警告する

`calculate!/2`関数を実装して、スタックだけを引数として演算関数を呼び出します。演算関数は別の場所で定義されていますが、正常に完了するかエラーを発生させるかのどちらかであることがわかっています。

```elixir
stack = []
operation = fn _ -> :ok end
RPNCalculator.calculate!(stack, operation)
# => :ok

stack = []
operation = fn _ -> raise ArgumentError, "An error occurred" end
RPNCalculator.calculate!(stack, operation)
# => ** (ArgumentError) An error occurred
```

> 名前が`!`で終わる関数は、その関数がエラーを発生させる可能性があることをプログラマーに警告するものです

## 2. エラーをラップする

さらに調べていると、多くの関数がアトムとタプルを使って成功・失敗を表していることに気づきます。この方法で`calculate/2`を実装しましょう。

```elixir
stack = []
operation = fn _ -> "operation completed" end
RPNCalculator.calculate(stack, operation)
# => {:ok, "operation completed"}

stack = []
operation = fn _ -> raise ArgumentError, "An error occurred" end
RPNCalculator.calculate(stack, operation)
# => :error
```

## 3. メッセージを伝える

エラーの中には、システムが正しく動作するために同僚が知っておく必要のある重要な情報が含まれています。エラーメッセージを伝えるために`calculate_verbose/2`を実装しましょう。エラーは`:message`フィールドを持つ構造体です。

```elixir
stack = []
operation = fn _ -> "operation completed" end
RPNCalculator.calculate_verbose(stack, operation)
# => {:ok, "operation completed"}

stack = []
operation = fn _ -> raise ArgumentError, "An error occurred" end
RPNCalculator.calculate_verbose(stack, operation)
# => {:error, "An error occurred"}
```
