# 説明の補足

## Prologで日付を扱う

Prologに標準で備わっている日付のサポートは[かなり初歩的です][built-in-dates-support]。Prologに標準で備わっている機能だけでもこの演習は解けますが、日付を扱うなら[date_timeパッケージ][date-time-package]を使うほうがずっと快適です。

### date_timeパッケージのインストール

インストールされているSwiplのバージョンが十分に新しい場合は、次のコマンドを実行してパッケージをインストールできます。

```bash
swipl pack install date_time
```

うまくいかない場合は、次のように実行してみてください。

```shell
swipl -g 'pack_install(date_time)'
```

~~~~exercism/note
オンラインエディターを使っている場合は、手動で何かをインストールする必要はありません。
~~~~

### date_timeパッケージを使う

`date_time`パッケージを使うには、解答ファイルの先頭に次のコードを追加します。

```prolog
:- use_module(library(date_time)).
```
