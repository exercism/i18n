# 指示

遊園地の仕事で、来場者とアトラクションを管理するシステムを設計するための仕様書を渡されました。任されたのは、来園者（公園を訪れる人）を表すAttendeeをモデル化することです。

## 1. 新しい来園者を作成する

`Attendee`クラスの`Attendee#initialize`メソッドを実装しましょう。身長（センチメートル単位）を引数に取り、インスタンス変数として保存します。

```ruby
Attendee.new(106)
# => #<Attendee:0x000055c33e6c7e18 @height=106>
```

## 2. 来園者の身長

`Attendee`クラスの`Attendee#height`ゲッターを実装しましょう。インスタンスの身長を返します。

```ruby
Attendee.new(106).height
# => 106
```

## 3. 乗車パスのIDは何か

すべての来園者が乗車パスを購入しているわけではありませんが、パスを持っているかどうかを知る必要があります。`Attendee`クラスの`Attendee#pass_id`ゲッターを実装しましょう。インスタンスのpass_idを返し、その来園者がパスを持っていない場合は`nil`を返します。

```ruby
Attendee.new(106).pass_id
# => nil
```

## 4. 来園者がパスを購入できるようにする

`Attendee#issue_pass!`を実装してインスタンスの状態を変更し、パスIDのインスタンス変数に引数を設定しましょう。パスIDを返します。

```ruby
attendee = Attendee.new(106)
attendee.issue_pass!(42)
attendee.pass_id
# => 42
```

## 5. パスを取り消す

安全でない行動でルールを破る来園者もいるため、遊園地側はパスを取り消せるようにしたいと考えています。`Attendee#revoke_pass!`を実装してインスタンスの状態を変更し、パスIDを`nil`に設定しましょう。

```ruby
attendee = Attendee.new(106)
attendee.issue_pass!(42)
attendee.revoke_pass!
attendee.pass_id
# => nil
```
