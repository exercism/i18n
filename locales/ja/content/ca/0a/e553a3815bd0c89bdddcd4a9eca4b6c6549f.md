# はじめに

Goの関数やメソッドは、複数の値を返すことができます：

```go
func GetCard() (Card, error) { ... }
```

戻り値はすべて、順番どおりにカンマで区切って代入する必要があります：

```go
card, err := GetCard()
```

代入のそれぞれの位置が、変数を宣言します。宣言した変数が1つでも使われていないと、Goはコンパイルできません。ブランク識別子`_`は、変数名の代わりに置くことで、その戻り値を読み飛ばします：

```go
card, _ := GetCard()
```

`error`は組み込みのインターフェースです。`nil`の`error`はエラーが起きなかったことを意味し、`nil`以外の値は何かがうまくいかなかったことを意味します。慣習として、失敗する可能性のある関数は、最後の値として`error`を返すべきです。呼び出し側は、ほかの戻り値を使う前に、必ずこれを確認する必要があります：

```go
card, err := GetCard()
if err != nil {
    return err // do not use card here
}
// safe to use card here
```
