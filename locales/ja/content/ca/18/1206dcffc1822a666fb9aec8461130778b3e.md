# 概要

Haxeには、正規表現が標準で組み込まれています。正規表現を使うと、文字列の形式を検証したり、文字列を変換したり、与えられたテキストから規則的なデータを抽出したりできます。

正規表現を作成するには、`~/`と`/`の間に書きます：

```haxe
var r = ~/haxe/i;
```

別の方法として、`EReg()`インスタンスを使うこともできます：

```haxe
var r = new EReg("haxe", "i");
```

ここで`i`は、パターンの大文字と小文字を区別しないようにするフラグです。ほかにも次のようなフラグがあります：

- `g`：グローバル置換
- `m`：複数行マッチング

`~/`と`/`の間には、正規表現のパターンを書きます。たとえば、AからZまでの文字を含む文字列を探したいとします。ここでは、範囲パターン`[A-Z]`を使えます。ほかにも、次のようなパターンがあります：

- `.`：任意の文字
- `*`：0回以上の繰り返し
- `+`：1回以上の繰り返し
- `[A-Z0-9]`：文字の範囲
