# はじめに

Elmの[`List`][lists]は、同じ型の0個以上の値からなるイミュータブルなコレクションです。

配列は次のように定義できます。

```elm
empty = []
singleValue = [ 5 ]
threeValues = [ "a", "b", "c" ]
```

配列に要素を追加する最も一般的な方法は、`::`（cons）演算子を使うことです。

```elm
twoToFour = [ 2, 3, 4 ]
oneToFour = 1 :: twoToFour --> [ 1, 2, 3, 4 ]
```

配列は、[`List`モジュール][list-module]で定義されている関数や演算子、または[パターンマッチング][list-destructuring]で操作します。

```elm
describe : List String -> String
describe list =
    case list of
        [] ->
            "Empty list"

        [ "hello" ] ->
            "Singleton list with: hello"

        x :: xs ->
            "Non-empty list with head: " ++ x

describe []                   --> "Empty list"
describe [ "hello" ]          --> "Singleton list with: hello"
describe [ "hello", "world" ] --> "Non-empty list with head: hello"
```

[list-module]: https://package.elm-lang.org/packages/elm/core/latest/List
