# リプレゼンターの正規化

[F#のリプレゼンター][representer]は、次の正規化を行います。

## コメントの削除

すべてのコメントが削除されます。

### 変更前

```fsharp
module Fake

(* Block comment
   on multiple lines *)

let message = "Hi" (* Block comment after code *)

// Double-slash comment on single line
let reply = "Yo" // Double-slash comment after code

/// <summary>This function adds two numbers</summary>
/// <param name="x">The first number</param>
/// <param name="y">The second number</param>
/// <returns>The first number added to the second number</param>
let add x y = x + y
```

### 変更後

```fsharp
module Fake

let message = "Hi"

let reply = "Yo"

let add x y = x + y
```

## インポート宣言の削除

すべてのインポート宣言が削除されます。

### 変更前

```fsharp
module Fake

open System
open System.IO

let message = "Hi"
```

### 変更後

```fsharp
module Fake

let message = "Hi"
```

## コードのフォーマット

コードは[fantomasライブラリ][fantomas]を使ってフォーマットされます。fantomasは、F#のスタイルガイドに沿ってコードを整形します。fantomasが適用する変換の一覧は、[こちら][fantomas-formatting]で確認できます。

### 変更前

```fsharp
module Fake

let  add ( birthDate  :  DateTime)  =
    birthDate.Add (    2.0)

type Volume =
| Liter of float
| USPint of float
| ImperialPint of float
```

### 変更後

```fsharp
module Fake

let add (birthDate: DateTime) =
    birthDate.Add(2.0)

type Volume =
    | Liter of float
    | USPint of float
    | ImperialPint of float
```

## 識別子の正規化

識別子はプレースホルダーの値に正規化されます。

### 変更前

```fsharp
module Fake

let foo x = x + 1
```

### 変更後

```fsharp
module PLACEHOLDER_1

let PLACEHOLDER_3 PLACEHOLDER_2 = PLACEHOLDER_2 + 1
```
