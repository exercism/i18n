# 説明

勤め先の会社はカーボンフットプリントを削減したいと考えており、そのため電気製品の消費電力と使用コストを計算するプログラムを書いてほしいと依頼されました。

## 1. 余分な時間を求める

雇用主は、さまざまな電気製品を動かすのにかかる時間を計算するプログラムを持っています。現在、その時間データは時間単位で保存されています。雇用主が時間を足したところ、時間の長さが正しくないことに気づきました。そこで、時間データに3時間を余分に加えてほしいと考えています。さらに、データを「丸1日」（1日は24時間）に変換したあと、何時間の「余分な」時間が残るのかも知りたいようです。変換する時間が、まる1日分にならないこともあります。

時間の数値を保持する整数を引数にとる関数`get_extra_hours()`を実装してください。この関数は適切な「余分な時間」の調整を行い、そのうえで、合計から何時間を取り除けば「丸1日」単位の時間になるかを表す整数を`return`するようにします。

```python
>>> get_extra_hours(25)
4
```

## 2. kWの値を求める

雇用主は、それぞれの電気製品の消費電力をkWで知りたいと考えています。kWはキロワットのことで、ワットは電力の単位です。単位名のキロは、メートル法で1000を表す接頭辞です。1キロワット == 1000ワットです。

ワットの数値を保持する整数を引数にとる関数`get_kW_value()`を実装してください。この関数は、ワットをキロワットに変換し、小数点以下1桁に丸めて`return`するようにします。

```python
>>> get_kW_value(1150)
1.2
```

## 3. kWhの値を求める

電気製品を動かすコストを計算するために、雇用主は消費電力をkWhで知る必要があります。kWhはキロワット時（kilowatt-hour）のことで、時は時間の単位です。1キロワット時 == 1000ワットを1時間使った量です。1時間は60分で、1分は60秒です。つまり1時間は3600秒です。kWhの値を計算するには、ワットをkWに変換し、その結果を3600で切り捨て除算します。

ワットの数値を保持する整数を引数にとる関数`get_kWh_value()`を実装してください。この関数は、キロワット時を整数で`return`するようにします。

```python
>>> get_kWh_value(5000000)
1
```

## 4. 効率を求める

電気製品は100%の効率では動きません。そこで雇用主は、電気製品の_効率_を計算してほしいと考えています。効率を求めるには、力率（_0から100の間の浮動小数点数_）を100で割ります。

力率を保持する浮動小数点数を引数にとる関数`get_efficiency()`を実装してください。この関数は、計算した効率を浮動小数点数で`return`するようにします。

```python
>>> get_efficiency(80)
0.8
```

## 5. コストを求める

雇用主は、電気製品を動かすコストを知りたいと考えています。電気製品を動かすコストは、使用電力に1kWhあたりの料金を掛けたものです。使用電力は、与えられた電力を計算した効率で割った値です。

ワットの数値を保持する整数、力率を持つ浮動小数点数、1kWhあたりの料金を保持する浮動小数点数を引数にとる関数`get_cost(<watts>,<power_factor>,<price>)`を実装してください。この関数は、電気製品を動かすコストを浮動小数点数で`return`するようにします。

```python
>>> get_cost(5000000, 80, 0.25)
0.3125
```
