# ヒント

## 全般

## 1. `new()`メソッドを実装する

- `new()`メソッドは、`User`インスタンスを生成するために必要な引数を受け取ります。指定した名前、年齢、体重を持つ`User`のインスタンスを返す必要があります。

- 構造体の定義と生成の例については、[構造体のドキュメント][structs]を参照してください。

## 2. ゲッターメソッドを実装する

- `name()`、`age()`、`weight()`メソッドはゲッターです。つまり、構造体インスタンスから対応するフィールドを返す役割を担います。

- Cairoでは、関数やメソッドを早めに終了させたいと明確に意図しているのでなければ、`return`文を使う必要はありません。それ以外の場合は、関数やメソッドに返してほしい結果のセミコロンを省略して、_暗黙的な_ 戻り値を利用するほうがより慣用的です。明示的に`return`するのが_間違い_というわけではありませんが、可能な場合は暗黙的な戻り値を活用するほうがすっきりします。

```rust
fn foo() -> i32 {
    1
}
```

- 構造体にメソッドを定義する例をもっと見るには、[メソッドのドキュメント][methods]を参照してください。

## 3. セッターメソッドを実装する

- `set_age()`と`set_weight()`メソッドはセッターで、入力引数を使って構造体インスタンスの対応するフィールドを更新する役割を担います。

- これらのメソッドのシグネチャが示すとおり、セッターメソッドは何も返すべきではありません。
