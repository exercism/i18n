# 説明

この演習では、預金口座を扱います。預金口座の残高は、毎年、その金利に基づいて更新されます。銀行が適用する金利は、口座に入っている金額（残高）によって決まります。

- 残高がマイナスの場合は-3.213%。
- 残高が`1000`ドル未満の場合は0.5%。
- 残高が`1000`ドル以上`5000`ドル未満の場合は1.621%。
- 残高が`5000`ドル以上の場合は2.475%。

毎年、預金口座の残高が更新される**前に**、政府は収入の一定割合を非課税で慈善団体に寄付することを認めています。あなたは優しい人なので、年末に残高がプラスであれば、その2倍の金額を慈善団体に寄付します。端数は1ドル単位で切り捨てます。

ここには3つのタスクがあり、それぞれ残高とその金利を扱います。

## 1. 金利を計算する

指定された残高から金利を計算する`interest-rate`関数を実装してください。

```clojure
(interest-rate 200.75M)
;;=> 0.5
```

戻り値は`Double`であることに注意してください。

## 2. 年間の残高更新を計算する

金利を考慮して、年間の残高更新を計算する`annual-balance-update`関数を実装してください。

```clojure
(annual-balance-update 200.75M)
;;=> 201.75375M
```

戻り値は`BigDecimal`であることに注意してください。

## 3. 寄付する金額を計算する

残高と、政府が認める非課税の割合から、慈善団体に寄付する金額を計算する`amount-to-donate`関数を実装してください。

```clojure
(def balance 550.5M)
(def tax-free-percentage 2.5)

(amount-to-donate balance tax-free-percentage)
;;=> 27
```

戻り値は`int`であることに注意してください。
