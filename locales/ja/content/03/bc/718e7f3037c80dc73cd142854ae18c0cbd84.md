# はじめに

`Vectors`の概念では、ベクトルを条件式の中で使うと、論理ベクトルが得られることを学びました。これはさらに、`all()`や`any()`といった関数でも使うことができます。

```R
v <- c(4, 7, 10)
v >= 6
#> [1] FALSE  TRUE  TRUE
all(v > 6)
#> [1] FALSE    # not all elements match this condition
any(v > 6)
#> [1] TRUE     # at least one element matches
```

このテクニックは、ここまでに紹介したものよりずっと強力です。

## ベクトルの一部を取り出す

ベクトルから特定の要素を取り出すには、インデックスの数値か、インデックスのベクトルを使います。

```R
v <- 5:10
v
#> [1]  5  6  7  8  9 10
v[3] 
#> [1] 7
v[c(2, 4)]
#> [1] 6 8
```

別の方法として、論理ベクトルを使って元のベクトルを絞り込むと、`TRUE`に対応する要素だけを取り出せます。

```R
v <- 1:3
bools <- c(FALSE, TRUE, TRUE)
v[bools]
#> [1] 2 3
```

ここから、条件式で真偽値ベクトルを作るのは、ほんの少しのステップです。

```R
bools <- v >= 2
bools
#> [1] FALSE  TRUE  TRUE

v[bools]
#> [1] 2 3

# simpler form
v[v >= 2]
#> [1] 2 3
```

## インデックスを見つける

`which()`関数は真偽値の引数を受け取り、`TRUE`になるインデックスのベクトルを返します。

```R
v
#> [1] 2 7 9

v[v > 5]  # returns values
#> [1]  7  9

which(v > 5) # returns indices
#> [1] 2 3
```

## 要素が存在するか調べる

ここまでの節では、ある条件に一致する要素を見つける方法を扱ってきました。

特定の要素がベクトルに含まれているかどうかだけを知りたいときは、`%in%`演算子を使います。

```R
3 %in% 1:5
#> [1] TRUE
7 %in% 1:5
#> [1] FALSE
```

これは、次のコードと機能的には同じですが、ずっと便利です。

```R
v <- 1:5
length(v[v == 3]) > 0
#> [1] TRUE
```
