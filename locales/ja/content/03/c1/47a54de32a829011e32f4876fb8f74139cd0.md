# 範囲

[範囲][range]は、2つの値の間の区間を表します。
範囲を扱える最も一般的な型は、`Int`、`Char`、`String`です。
コレクションを手早く作る、文字列を切り出す、ある値が範囲に含まれるかを調べる、繰り返し処理を行うなど、さまざまな場面で使えます。
範囲は、範囲演算子の`..`または`...`を使って作ります（それぞれ終端を含むものと含まないものです）。

```crystal
1..5  # A range containing 1, 2, 3, 4, 5
1...5 # A range containing 1, 2, 3, 4
```

範囲演算子が2つあるのは、終端の値を範囲に含めるか含めないかを選べるようにするためです。たとえば、0から始まるインデックスを扱うときに役立ちます。

範囲は、`Range`の初期化子を使って作ることもできます。

```crystal
Range.new(1, 5) # A range containing 1, 2, 3, 4, 5
```

~~~~exercism/note
Crystalで範囲演算子の`..`や`...`を使って範囲を作り、その範囲に対してメソッドを呼び出したいときは、範囲を括弧（`()`）で囲む必要があります。
そうしないと、メソッドが範囲演算子の2番目の引数に対して呼び出されてしまうからです。

```crystal
(1..5).size # => 5
1..5.size # => Error: undefined method 'size' for Int32
```
~~~~

## 部分文字列の取得

文字列を切り出したいときは、範囲演算子を使って部分文字列を取り出せます。
つまり、部分文字列の開始インデックスと終了インデックスを指定した範囲を作ります。

```crystal
"Hello World"[0..4] # => "Hello"
"Hello World"[6..10] # => "World"
```

負のインデックスを使うと、文字列の末尾から部分文字列を取り出すこともできます。

```crystal
"Hello World"[-5..-1] # => "World"
"Hello World"[6..-4] # => "Wo"
```

## 範囲のメソッド

範囲には、それを扱うためのメソッドがいくつか用意されています。
たとえば、範囲に含まれるすべての値の合計を求めたり、ある値が範囲に含まれるかを調べたりするのに使えます。

| メソッド                | 説明                                                                    | 例                              |
|-------------------------|-------------------------------------------------------------------------|---------------------------------|
| [`sum`][sum]            | 範囲に含まれるすべての値の合計を返します                                | `(1..5).sum # => 15`            |
| [`size`][size]          | 範囲の大きさを返します                                                  | `(1..5).size # => 5`            |
| [`includes?`][indludes] | 範囲が与えられた値を含んでいれば`true`、そうでなければ`false`を返します | `(1..5).includes?(3) # => true` |

## 終端のない範囲と始端のない範囲

範囲には、終端のないものと始端のないものがあります。
終端や始端のない範囲では、開始値または終了値が`nil`になりますが、範囲を定義するときに`nil`は省略できます。

始端や終端のない範囲は、たとえば文字列を先頭から、あるいは末尾まで切り出したいときに便利です。

```crystal
"Hello World"[0..] # => "Hello World"
"Hello World"[4..] # => "o World"
"Hello World"[..5] # => "Hello"
```

~~~~exercism/caution
コレクションに対して使わない場合、終端のない範囲は、注意せずに使うと終わりのないシーケンスを引き起こすことがあります。
~~~~

## Charの範囲

`Char`は範囲に使うことができ、2つの文字の間の文字の区間を得られます。
たとえば、アルファベットを取得したいときに便利です。

```crystal
'a'..'z' # A range containing ['a', 'b', 'c', ..., 'z']
```

## Stringの範囲

`String`も範囲に使うことができ、2つの文字列の間の文字列の区間を得られます。
ただし、文字列の範囲で複数の文字を使う場合、その動作は`Char`のときとは少し異なります。
より複雑な文字列の範囲を扱うと動作がわかりにくくなることがあるので、注意してください。

```crystal
("aa".."az") # A range containing ["aa", "ab", "ac", ..., "az"]
```

## 範囲でのカスタムオブジェクト

~~~~exercism/advanced
Crystalでは、カスタムオブジェクトを範囲に使えます。
そのために必要なのは、オブジェクトが次を実装していることです。

- `Comparable`モジュールをインクルードする
- `succ`メソッド
- `<=>`メソッド

これらのメソッドによって、範囲はそのオブジェクトを繰り返し処理し、範囲内のオブジェクト同士を比較できるようになります。

```crystal
class Foo
  include Comparable(Foo)

  getter value

  def initialize(@value : Int32)
  end

  def succ
    Foo.new(value + 1)
  end

  def <=>(other : Foo)
 value <=> other.value
  end
end

Foo.new(1)..Foo.new(5)
# => #<Foo:0x7f3552bebe70 @value=1>, #<Foo:0x7f3552bebe50 @value=2>, #<Foo:0x7f3552bebe40 @value=3>, #<Foo:0x7f3552bebe30 @value=4>, #<Foo:0x7f3552bebe20 @value=5>
```
