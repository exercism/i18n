# 指示

この演習では、自転車と部品のオンラインショップであるBetty's Bike Shopを手伝うためのコードを書きます。自転車と部品の価格をウェブサイトに正しく表示することを目指して、3つのタスクに取り組みます。

## 1. `pence_to_pounds`関数をエクスポートする

同僚がすでにモジュールの骨組みと、未完成の`pence_to_pounds`関数、`pounds_to_string`関数を書いています。しかし、`pence_to_pounds`関数をエクスポートし忘れているため、現時点では他のモジュールやテストスイートからは見えません。

`pence_to_pounds`関数をエクスポートしてください。

## 2. ペンスをポンドに変換する

現在、価格は*ペンス*の整数値として保存されています（この自転車店はイギリスにあります）。ウェブサイトでは、価格を*ポンド*で表示したいと考えています。1.00ポンドは100ペンスに相当します。最初のタスクは、`pence_to_pounds`関数を実装することです。この関数は、ペンスの量を`Int`で受け取り、それに相当するポンドを`Float`として返します。この関数には型注釈も追加してください。

```gleam
pence_to_pounds(106)
// -> 1.06
```

## 3. ウェブサイトに表示するために価格をフォーマットする

Bettyの自転車はポンドで販売されているので、価格は「£」という記号を付けて表示する必要があります。したがって2つ目のタスクは、`pounds_to_string`関数を実装することです。この関数は、ポンドの量を`Float`で受け取り、先頭にポンド記号を付けた価格を`String`として返します。

`gleam/float`モジュールと`gleam/string`モジュールは、使用する前にインポートしてください。

`pounds_to_string`の型注釈も定義してください。

```gleam
pounds_to_string(1.06)
// -> "£1.06"
```
