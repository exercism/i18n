# はじめに

## 基本

[Lua](https://lua.org)は、シンプルでありながら強力で、効率的かつ軽量な、埋め込み可能なスクリプト言語です。1993年からブラジルの[PUC-RIO](https://www.puc-rio.br/)で、Roberto Ierusalimschy、Waldemar Celes、Luiz Henrique de Figueiredoのチームによって設計・実装・保守されています。

### コメント

Luaの単一行コメントは`--`で始まり、複数行コメントは`--[[`で始まって`]]`で終わります。
```lua
-- This is a single line comment.

--[[This is
a multiline
comment
]]
```

### 変数

Luaの変数には、グローバル変数、ローカル変数、テーブルのフィールドの3種類があります。ここでは話を簡単にするため、ローカル変数だけを説明します。デフォルトではすべての変数がグローバルなので、ローカル変数はキーワード`local`を使ってローカルであることを宣言する必要があります。
```lua
local x
```

変数には`=`演算子を使って値を代入できます。
```lua
local x = 1
```

`local`変数のスコープは、それが宣言されたブロックに限られます。ブロックとは、制御構造の本体、関数の本体、あるいは変数が宣言されたファイルや文字列のことです。
```lua
local x = 1

if x == 1 then
  local x = 2
  print(x) -- prints 2
end

print(x) -- prints 1
```

### 関数

関数はキーワード`function`で宣言し、変数と同じくデフォルトではグローバルです。関数の定義には、名前、入力のリスト、本体があります。キーワード`return`に到達すると関数は終了し、そのあとに並んだすべての値を返します。`return`を指定しなければ、関数は`nil`を返します。

```lua
-- Defining a local function which returns "Hello " followed by 
-- the name which was given as parameter
local function say_hello(name)
  return 'Hello ' .. name
end
```

### テーブル

テーブルはLuaで唯一のデータ構造の仕組みであり、とても強力です。配列、集合、オブジェクト、モジュールなど、さまざまなものを表すのに使われます。本質的に、Luaのテーブルは連想配列です。
```lua
-- create a table and assign its reference to tbl
local tbl = {}

-- new entry with key 'x' and value 1
tbl['x'] = 1

-- printing the value
print(tbl['x'])  --> 1

-- uninitialized table fields evaluate to nil
print(tbl['y'])  --> nil

-- there is also syntactic sugar - the following is the same as above
tbl.y = 1
print(tbl.y)    --> 1
```

ここでは、次のセクションに必要なほんの少しの知識だけを紹介しました。この話題はあとで詳しく取り上げます。

### モジュール

モジュールとは、`.lua`ソースファイルに保存されたコードの集まりです。モジュールがエクスポートするものはすべてテーブルに保存され、そのテーブルがファイルの最後で返されます。つまり、このテーブルは一種の名前空間として機能します。
```lua
-- say-hello.lua

-- defining the table 'say' which is exported at the end
local say = {}

-- defining the function 'hello' as a table field
-- this is syntax sugar for: say.hello = function() print('Hello!') end
function say.hello()
  print('Hello!')
end

-- returning (exporting) the table 'say'
return say
```

そのモジュールは、テーブルを返す関数`require`を通して、別のファイルに読み込むことができます。
```lua
-- lets_say_hello.lua
local say = require('say-hello')
say.hello() -- prints "Hello!"
```

`say.hello`を見ると、「モジュール`say`の関数`hello`」と考えるでしょう。しかし、`say-hello.lua`がテーブルを返すことを知り、テーブルのセクションを振り返ってみると、Luaではこの式が「文字列`hello`をキーとしてテーブル`say`をインデックス参照する」という意味だと気づきます。

モジュールがテーブルを返すのは良い習慣ですが、関数など、ほかの型を返すことも同じように可能です。

```lua
--- say-bye.lua
local function bye()
  print('Bye!')
end

return bye
```
