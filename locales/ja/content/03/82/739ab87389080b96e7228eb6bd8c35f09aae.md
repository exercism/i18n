# 説明

Ellenは、プレイヤーがエイリアンと戦うゲームを作っています。
彼女はオブジェクト指向プログラミング（OOP）を学んだばかりで、`classes`を使えば自分のプログラムにどんなことができるようになるのか、ぜひ試してみたいと思っています。

手伝いを申し出ると、Ellenは大喜びで、プレイヤーが戦うエイリアンのプログラミングを任せてくれました。


## 1. `Alien`クラスを作成しましょう

`Alien`クラスを定義します。コンストラクターは、`x`と`y`という2つの`int`の仮引数を受け取り、それらをメンバー変数`x_coordinate`と`y_coordinate`に格納します。
エイリアンはどれも体力`3`でスタートするので、メンバー変数`health`も初期化する必要があります。

`health`はプライベートなメンバー変数にします。
プログラムの他の部分から体力の情報を読み取れるように、Ellenは`int`を返す`public`な`get_health()`メソッドを用意したいと考えています。

```cpp
Alien alien{2, 0};
alien.x_coordinate;
// => 2
alien.y_coordinate;
// => 0
alien.get_health();
// => 3
```

これで、各エイリアンは自分の位置と体力を内部で管理できるようになります。

## 2. `hit`関数

Ellenは、呼び出されるとエイリアンオブジェクトの体力を`1`減らす`hit`メソッドを、`class`クラスに持たせたいと考えています。
こうすれば、エイリアンの体力を手動で変える代わりに、`some_alien_instance.hit()`を呼び出すだけで済みます。
体力が0を下回らないようにしてください。
この関数は`true`を返します。
Ellenは後でシールドを導入したいと考えており、そのときはシールドが張られている場合に`false`を返すようにします。

```cpp
Alien alien {0, 0};
alien.get_health();
// => 3 (Initial health value)

alien.hit(); // Decrements health by 1 point.
alien.get_health();
// => 2
```

## 3. `is_alive`関数

体力が減り続ければ、いつかは`0`になるでしょう。
そこで、エイリアンが……まあ……生きているかどうかを、Ellenがすぐに呼び出して確認できる`is_alive`メソッドを追加するとよいでしょう。😉
`some_alien_instance.is_alive()`は真偽値を返します。

```cpp
alien.get_health();
// => 1
alien.is_alive();
// => true
alien.hit();
alien.get_health();
// => 0
alien.is_alive();
// => false
```

## 4. `teleport`関数

Ellenのゲームでは、エイリアンはテレポートできます！　`x_new`と`y_new`の値を受け取り、それに応じてエイリアンの座標を変える`teleport`メソッドを書く必要があります。
今のところ、この関数は`true`を返します。
Ellenは後のレベルでテレポートを妨害する爆弾を追加したいと考えており、そのときはテレポートに失敗した場合に`false`を返すようにします。

```cpp
alien.teleport(5, -4);
alien.x_coordinate;
// => 5
alien.y_coordinate;
// => -4
```

## 5. `collision_detection`関数

エイリアンが何かに当たる可能性があるのなら、そのような衝突がいつ起こるかを検知できる必要があります。
Ellenは、2体のエイリアンが同じ座標にいるかどうかを知りたいのです。
`collision_detection()`関数は、別のエイリアンオブジェクトを引数に取り、`bool`を返します。

```cpp
Alien lrrr {3, 6};
Alien ndnd {-2, 12};
lrrr.collision_detection(ndnd);
// => false
ndnd.teleport(3, 6);
ndnd.collision_detection(lrrr);
// => true
```
