# はじめに

Goでは、関数は第一級の値です。
これは、他のすべての値に対してできることと同じことを、関数に対してもできるという意味です。関数を変数に代入したり、他の関数に引数として渡したり、他の関数から関数を返したりできます。

次のコードでは、`engGreeting`と`espGreeting`という2つの関数を作り、それらを変数`greeting`に代入しています。

```go
import "fmt"

func engGreeting(name string) string {
	return fmt.Sprintf("Hello %s, nice to meet you!", name)
}

func espGreeting(name string) string {
	return fmt.Sprintf("¡Hola %s, mucho gusto!", name)
}

greeting := engGreeting			// greeting is a variable of type func(string) string
fmt.Println(greeting("Alice"))	// Hello Alice, nice to meet you!

greeting = espGreeting
fmt.Println(greeting("Alice")) 	// ¡Hola Alice, mucho gusto!
```

関数の値を使うと、関数をデータだけでなく振る舞いによってもパラメーター化できます。
次の例では、`greetingFunc`という仮引数を通じて、`dialog`関数に振る舞いを渡しています。

```go
func dialog(name string, greetingFunc func(string) string) {
	fmt.Println(greetingFunc(name))
	fmt.Println("I'm a dialog bot.")
}

func espGreeting(name string) string {
	return fmt.Sprintf("¡Hola %s, mucho gusto!", name)
}

greeting := espGreeting
dialog("Alice", greeting)
// =>
// ¡Hola Alice, mucho gusto!
// I'm a dialog bot.
```

関数型の変数を初期化しない場合、その値は`nil`です。
そのため、`nil`の関数値を呼び出すとパニックが発生します。

```go
var dutchGreeting func(string) string
dutchGreeting("Alice") // panic: call of nil function
```

関数の値は`nil`と比較できます。
これは、不要なプログラムのパニックを避けるのに役立ちます。

```go
var dutchGreeting func(string) string
if dutchGreeting != nil {
	dutchGreeting("Alice") // safe to call dutchGreeting
}
```

## 関数型

関数の値を使えるのは、Goの関数型のおかげです。
関数型は、仮引数の型の並びと戻り値の型の並びが同じである、すべての関数の集合を表します。
ユーザー定義型は、関数型を基に宣言できます。
たとえば、前の例の`dialog`関数は、次のように書き換えられます。

```go
type greetingFunc func(string) string

func dialog(name string, f greetingFunc) {
	fmt.Println(f(name))
	fmt.Println("I'm a dialog bot.")
}
```

## 無名関数

第一級関数が使えるおかげで利用できる、もう1つの強力な道具が無名関数です。
無名関数は、使う場所で定義され、`func`キーワードの後に名前が続きません。
このような関数は、外側の関数の変数にアクセスできます。

たとえば、次のようになります。

```go
func fib() func() int {
	var n1, n2 int

	return func() int {
		if n1 == 0 && n2 == 0 {
			n1 = 1
		} else {
			n1, n2 = n2, n1 + n2
		}
		return n2
	}
}

next := fib()
for i := range N {
  fmt.Printf("F%d\t= %4d\n", i, next())
}
```

`fib`を呼び出すと、変数`n1`と`n2`が宣言され、無名関数が返されます。この無名関数は、呼び出されるたびにこれらの変数の値を変えます。
無名関数をn回呼び出すと、0から始まるフィボナッチ数列のn番目の数が返されます。内側の無名関数は、外側の関数`fib`のローカル変数（`n1`と`n2`）にアクセスできます。
これは、関数の値に呼び出し間の状態を保持させる優れた方法です。
無名関数は、変数`n1`と`n2`のクロージャーであると言います。[クロージャー][closure]はプログラミングで広く使われており、他の言語でもサポートされているのを見かけるかもしれません。

[closure]: https://en.wikipedia.org/wiki/Closure_(computer_programming)
