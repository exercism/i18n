# はじめに

## Agent

`Agent`モジュールは、[プロセスと_receive-send_ループ][exercism-processes]を生成するための抽象化を提供します。ここからは、`Agent`モジュールを使って開始したプロセスを「_エージェントプロセス_」と呼ぶことにします。_エージェントプロセス_は、中心となる共有状態を表すために選ばれることがあります。

_エージェントプロセス_を開始するには、`Agent`が提供する`start/2`関数を使います。`start`するときに渡した関数が、その_エージェントプロセス_の初期状態を返します。

```elixir
# Start an agent process with an initial value of an empty list
{:ok, agent_pid} = Agent.start(fn -> [] end)
```

`Map`や`List`と同じように、`Agent`にも_エージェントプロセス_を扱うための関数がたくさん用意されています。

モデル化しようとしているドメインについて、`Agent`関連の機能をすべて1つのモジュールにまとめてカプセル化するのが通例です。

[exercism-processes]: https://exercism.org/tracks/elixir/concepts/processes
