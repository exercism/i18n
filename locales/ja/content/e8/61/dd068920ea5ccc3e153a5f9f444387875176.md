# 概要

[`while`ループ][while-loops]は、ある条件が`true`の間コードを繰り返し実行する制御フローの文です。
Swiftには`while`ループと`repeat-while`ループの2種類の`while`ループがあります。
`while`ループでは、ループ本体が実行される前に条件が評価されます。条件が`false`の場合、ループ本体は一度も実行されません。
Swiftの`while`ループは、次のような構造になっています。

```swift
while <#condition#> {
  <#code#>
}
```

この例では、`count`が0より大きい間ループが実行され、その結果として2、1、`"Liftoff!"`が出力されます。

```swift
var count = 2
while count > 0 {
  print("\(count)…")
  count -= 1
}
print("Liftoff!")

// prints:
// 2…
// 1…
// Liftoff!
```

[`repeat-while`ループ][while-loops]は`while`ループと似ていますが、条件が評価されるのはループ本体が実行されたあとです。
つまり、条件が`false`であっても、ループ本体は必ず1回は実行されます。
Swiftの`repeat-while`ループは、次のような構造になっています。

```swift
repeat {
  <#code#>
} while <#condition#>
```

この例では、条件が`false`なので、ループは1回だけ実行されます。
`repeat-while`ループでは、条件が評価される前にループ本体が1回実行されるからです。

```swift
var count = 2
repeat {
  print("\(count)…")
} while count < 0
print("Liftoff!")
```

## オプショナルバインディングループ

Swiftの`while`ループでよく使われる書き方の1つに、オプショナルバインディングを使った`while`ループがあります。
このループは、オプショナルな値を返す関数の呼び出しが`nil`以外の値を返す限り、繰り返されます。
その（非オプショナルの）値には好きな名前を付けて束縛でき、ループ本体の中で使うことができます。

```swift
var arr = [1,2]
while let count = arr.popLast() {
  print("\(count)…")
}
print("Liftoff!")

// prints:
// 2…
// 1…
// Liftoff!
```
