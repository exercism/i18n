# はじめに

## `try`・`rescue`・`else`・`after`

`try..rescue`は、エラーが発生したときにそれを捕捉するための強力な構文です。エラーを捕捉することで、関数は必要なときに決まった値を返せます。`try..rescue`構文には、ほかにも活用できる2つの機能があります。

- `else`ブロック
  - `try`ブロックが成功すると、その結果がこのブロックにマッチします。
- `after`ブロック
  - `try`ブロックが成功しても例外を発生させても、プログラムがその時点で動作していれば、`after`ブロックのコードは必ず実行されます。
  - `after`ブロックの結果は、呼び出し元には返されません。

```elixir
try do
  :a
rescue
  _ -> :error
else
  :a -> :success
after
  :some_action
end

# => :success
```

## 動的ディスパッチ

Elixirは、呼び出す関数を解決するとき、モジュールの名前を使って検索を行います。モジュールの名前が変数に束縛されていれば、この検索は動的に行えます。

```elixir
defmodule MyModule do
  def message(), do: "My message"
end

atom = MyModule
atom.message()
# => "My message"
```

内部的には、モジュールの名前はアトムです。Elixirのモジュールのアトムには、すべて自動的に`Elixir.`が付けられます。

```elixir
is_atom(Enum)
# => true
Enum == Elixir.Enum
# => true
```
