# はじめに

Factorの条件分岐は、**クォーテーション**のどちらを実行するかを選びます。クォーテーションとは、角括弧（`[ ... ]`）で書くコードの断片です。`[ ... ]`と書くと、コードは実行されず、値としてスタックに積まれます。条件分岐は、そのあとでどちらのクォーテーションを実行するかを決めます。（クォーテーションについては、後の演習で詳しく扱います。）

[`kernel`][kernel]にある`if`は、Factorの基本的な条件分岐です。真偽値と2つのクォーテーションを取り、真偽値が真の場合は1つ目を、そうでなければ2つ目を実行します。

```
if ( ? then-quot else-quot -- )
```

```factor
: abs ( x -- y ) dup 0 < [ neg ] [ ] if ;
```

`when`は、真偽値が真の場合にだけそのクォーテーションを実行し、`unless`は偽の場合にだけ実行します。多分岐には、[`combinators`][combinators]の`cond`を使います。

```factor
USING: combinators ;

: classify ( n -- s )
    {
        { [ dup 0 <  ] [ drop "negative" ] }
        { [ dup 0 =  ] [ drop "zero"     ] }
        [ drop "positive" ]
    } cond ;
```
