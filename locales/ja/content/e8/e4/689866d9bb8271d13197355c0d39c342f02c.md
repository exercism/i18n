# はじめに

状態をいくつかのワードの間で共有したいけれど、そのたびにスタック効果を通して受け渡すのは避けたい、ということがあります。Factorの*動的変数*は、`SYMBOL:`で宣言し、名前空間に保存された値に各ワードからアクセスできるようにします。

## `SYMBOL:`と`SYMBOLS:`

`SYMBOL: name`は変数を1つ宣言します。`SYMBOLS: a b c ;`を使うと、複数をまとめて宣言できます。

```factor
USING: namespaces ;

SYMBOLS: counter total ;
```

## 値の設定と取得

`set-global`と`get-global`（[`namespaces`][namespaces]にあります）は、グローバル名前空間を操作します。

```
set-global    ( value variable -- )
get-global    ( variable -- value )
change-global ( variable quot: ( old -- new ) -- )
```

```factor
0 counter set-global
counter get-global .         ! => 0
counter [ 10 + ] change-global
counter get-global .         ! => 10
```

モジュールレベルの状態を扱うなら、`-global`が付いたほうを使います。

## `with-variable`によるスコープ付きの束縛

動的変数には、もう1つ*スコープ付き*の使い方があります。`set` / `get` / `change`（`-global`が付かないほう）は*現在の*動的スコープを読み書きし、`with-variable`（[`namespaces`][namespaces]にあります）はクオーテーションが実行されている間だけ有効な新しいスコープを作ります。

```
with-variable ( value variable quot -- )
set           ( value variable -- )
get           ( variable -- value )
change        ( variable quot: ( old -- new ) -- )
```

`quot`が実行されている間、変数には`value`が束縛されます。`quot`が戻ると、その束縛は消えます。これにより、外側の呼び出し元が値を「注入」して、内側のコードがスタックシグネチャをいちいち経由せずにその値を読めるようになります。

```factor
SYMBOL: greeting

"Hello" greeting [
    greeting get .                ! => "Hello"
    "Howdy" greeting set
    greeting get .                ! => "Howdy"
    greeting [ "!" append ] change
    greeting get .                ! => "Howdy!"
] with-variable

greeting get-global .    ! => f   (the scoped binding is gone)
```

この演習では全体を通してグローバルなほうを使いますが、`set`/`get`/`change`という対になるファミリーを知っておくと、他の人のコードを読むときに役立ちます。

## ミュータブルなベクター

動的変数は参照を保持するので、その中に*ミュータブル*なコレクションを入れておき、その場で更新できます。

```factor
SYMBOL: history

V{ } clone history set-global
"first event" history get-global push
"second event" history get-global push
history get-global .
! => V{ "first event" "second event" }
```

`V{ … }`はベクターのリテラルです。`V{ }`のリテラルを保存する前には、必ず`clone`してください。リテラルは呼び出しの間で共有されるからです。

## `find`：最初に一致する要素

`find`（[`sequences`][sequences]にあります）は、述語が真になる最初の要素と、そのインデックスを返します。

```
find ( seq quot -- index elt/f )
```

一致するものがなければ、どちらの値も`f`です。`nip`でインデックスを落とし、`unless*`を使うのが、「見つからなかったときの既定値」の定番の組み合わせです。

## `reject`：一致する要素を落とす

`reject`（こちらも[`sequences`][sequences]にあります）は`filter`の反対で、述語を*満たさない*要素を返します。
