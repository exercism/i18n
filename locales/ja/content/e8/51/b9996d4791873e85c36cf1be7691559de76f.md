# 余り

数学では、**余り**とは、ある計算を行ったあとに「残った」分のことです。たとえば、`5 / 3`の余りは`2`です。

多くのプログラミング言語では、余りを計算する演算子としてパーセント記号（`%`）を使います。たとえば、次のようになります。
```javascript
5 % 3 == 2
```

余りは、整数でも浮動小数点数でも計算できることがよくあります。たとえば、次のようになります。
```javascript
5.3 % 3 == 2.3
```

負の数を扱う場合、結果の符号は常に被除数（左側にある、割られる数）と同じになります。たとえば、次のようになります。
```javascript
-5 % 3 == -2
5 % -3 == 2
-5 % -3 == -2
```

Pythonなどの言語では、余りではなく剰余を計算するために`%`演算子を使います。そのため、負の数の扱いが異なります。詳しくは[Wikipedia](https://en.wikipedia.org/wiki/Modulo)で学べます。
