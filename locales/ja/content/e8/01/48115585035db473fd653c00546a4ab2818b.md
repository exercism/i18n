# 概要

Rustの真偽値は`bool`型で表され、その値は`true`か`false`のどちらかです。

Rustがサポートする[真偽値の否定演算子][negation operators]は、`!`（Not）の1つです。

Rustがサポートする[比較演算子][comparison operators]は6つあります：`==`（Equal）、`!=`（Not equal）、`>`（Greater than）、`<`（Less than）、`>=`（Greater than or equal to）、`<=`（Less than or equal to）。これらを使うと、真偽値以外の値の関係を評価して、真偽値として得られます。

```rust
1 > 0 // true
1 < 0 // false
1 == 0 // false
1 != 0 // true
1 >= 0 // true
1 <= 0 // false
```

他の言語とは違い、`0`が`false`になるわけではなく、0以外の値が`true`になるわけでもありません。

Rustがサポートする[論理二項演算子][logical binary operators]は3つあります：`&`（Logical And）、`|`（Logical Or）、`^`（Logical Xor）。

Rustがサポートする[真偽値演算子][lazy boolean operators]は2つあります：`||`（Or）、`&&`（And）。これらが`|`や`&`と違うのは、左側の値だけで式の結果が決まらないときにだけ、右側の値が評価される点です。つまり、`||`は左側の値が`false`と評価されたときにだけ右側の値を評価し、`&&`は`true`のときにだけ評価します。

```rust
true || false // == true; the right-hand side was not evaluated
true && false // == false
```
