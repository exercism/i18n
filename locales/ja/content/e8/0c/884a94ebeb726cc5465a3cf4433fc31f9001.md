# はじめに

## 条件分岐と`if`

### 論理演算子

Javaは、`&&`（AND）、`||`（OR）、`!`（NOT）という3つの論理演算子をサポートしています。

### `if`文

条件式の基になるのは`boolean`型で、値は`true`または`false`です。条件分岐は、いろいろな条件を調べるために、処理の流れを制御する仕組みとしてよく使われます。ある特定のケースを調べるには`if`文を使います。`if`文は、条件が`true`のときにそのコードを実行します。たとえば次のようになります。

```java
int val;

if(val == 9) {
    // conditional code
}
```

複数のケースを扱う場面では、`else if`文と`else`文を使って、たくさんの`if`文をつなげることができます。

```java
if(val == 10) {
    // conditional code
} else if(val == 17) {
    // conditional code
} else {
    // executes when val is different from 10 and 17
}
```

### `switch`文

Javaには、複数の選択肢がある場面で使える`switch`文もあります。

```java
int val;

// switch statement on variable content
switch(val) {
    case 1:
        // conditional code
        break;
    case 2: case 3: case 4:
        // conditional code
        break;
    default:
        // if all cases fail
        break;
}
```
