# 指示の補足

## レジスター

| レジスター | 用途   | 型      | 説明                                     |
| ---------- | ------ | ------- | ---------------------------------------- |
| `$a0`      | 入力   | アドレス | null終端された8進数の文字列              |
| `$v0`      | 出力   | 整数    | 入力文字列の10進数の値                   |
| `$t0-9`    | 一時的 | 任意    | 一時的な保存に使われます                 |
