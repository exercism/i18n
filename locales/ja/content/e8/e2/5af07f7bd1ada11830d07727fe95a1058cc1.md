# 説明

この演習では、プログラミング言語の配列を操作するためのいくつかの関数を実装します。

## 1. 空の言語の配列を返す関数を定義する

引数を取らず、空の配列を返す`new/0`関数を定義しましょう。

```elixir
LanguageList.new()
# => []
```

## 2. 配列に言語を追加する関数を定義する

2つの引数（_言語の配列_と_言語_の文字列リテラル）を取る`add/2`関数を定義しましょう。与えられた配列の先頭に新しい言語を追加した結果の配列を返すようにします。

```elixir
language_list = LanguageList.new()
# => []
language_list = LanguageList.add(language_list, "Clojure")
# => ["Clojure"]
language_list = LanguageList.add(language_list, "Haskell")
# => ["Haskell", "Clojure"]
```

## 3. 配列から言語を削除する関数を定義する

1つの引数（_言語の配列_）を取る`remove/1`関数を定義しましょう。最初の要素を除いた配列を返すようにします。配列には常に少なくとも1つの要素があると仮定します。

```elixir
language_list = LanguageList.new()
# => []
language_list = LanguageList.add(language_list, "Clojure")
# => ["Clojure"]
language_list = LanguageList.add(language_list, "Haskell")
# => ["Haskell", "Clojure"]
language_list = LanguageList.remove(language_list)
# => ["Clojure"]
```

## 4. 配列の最初の要素を返す関数を定義する

1つの引数（_言語の配列_）を取る`first/1`関数を定義しましょう。配列の最初の言語を返すようにします。配列には常に少なくとも1つの要素があると仮定します。

```elixir
language_list = LanguageList.new()
# => []
language_list = LanguageList.add(language_list, "Elm")
# => ["Elm"]
language_list = LanguageList.add(language_list, "Prolog")
# => ["Prolog", "Elm"]
LanguageList.first(language_list)
# => "Prolog"
```

## 5. 配列に含まれる言語の数を返す関数を定義する

1つの引数（_言語の配列_）を取る`count/1`関数を定義しましょう。配列に含まれる言語の数を返すようにします。

```elixir
language_list = LanguageList.new()
# => []
language_list = LanguageList.add(language_list, "Elm")
# => ["Elm"]
language_list = LanguageList.add(language_list, "Prolog")
# => ["Prolog", "Elm"]
LanguageList.count(language_list)
# => 2
```

## 6. 配列に関数型言語が含まれているかを判定する関数を定義する

1つの引数（_言語の配列_）を取る`functional_list?/1`関数を定義しましょう。真偽値を返すようにします。_"Elixir"_が配列に含まれる言語の1つであれば`true`を返すようにします。

```elixir
language_list = LanguageList.new()
# => []
language_list = LanguageList.add(language_list, "Elixir")
# => ["Elixir"]
LanguageList.functional_list?(language_list)
# => true
```
