# はじめに

Common Lispでは、文字列は[文字][concept-characters]の[ベクター][concept-vectors]です。文字列は、二重引用符で囲んだ文字として書きます（例えば、"Hello World!"）。

`stringp`述語は、与えられた値が文字列である場合にのみ`true`を返します。

文字列は、`subseq`関数を使って部分文字列に分割できます。`subseq`には文字列、開始インデックス、そして省略可能な終了インデックスを渡します。インデックスは0から始まります。

```lisp
(subseq "Hello World" 1 5)   ; => "ello"
(subseq "skip to the end" 5) ; => "to the end"
```

文字列の等価性は`string=`で比較できます。文字の大文字・小文字を無視したい場合は、`string-equal`を使います。

```lisp
(string= "macaroni" "macaroni")      ; => T
(string= "macaroni" "MACARONI")      ; => NIL
(string-equal "macaroni" "MACARONI") ; => T
```

文字列の大文字化、小文字化、先頭文字の大文字化といった操作は、`string-upcase`、`string-downcase`、`string-capitalize`で行えます。

```lisp
(string-upcase "not too loud")                ; => "NOT TOO LOUD"
(string-downcase "YELL IT FROM THE ROOFTOPS") ; => "yell it from the rooftops"
(string-capitalize "practical COMMON LiSP")   ; => "Practical Common Lisp"
```
