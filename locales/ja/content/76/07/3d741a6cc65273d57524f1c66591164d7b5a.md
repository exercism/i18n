# 概要

`if/elif/else`式を使うと、条件に応じて処理を実行できます。F#には、条件に応じて処理を実行するための、より強力な方法がもう1つあります。それが[パターンマッチング][pattern-matching]です。パターンマッチングを使うと、ある値が1つ以上の_パターン_に当てはまるかどうかを調べられます。そのようなパターンの1つに、[_定数パターン_][constant-patterns]があります。これは、値が定数（たとえば`1`や`"hello"`）と一致するかどうかを調べるパターンです。

F#では、パターンマッチングは`match`キーワードを使って行います。

```fsharp
let describe number =
    match number with
    | 0 -> "Zero"
    | 1 -> "One"
```

これは他の言語の`switch`文に似ているように見えるかもしれませんが、他のパターンも組み合わせると、パターンマッチングの真価が発揮されます。その1つが[_変数パターン_][variable-patterns]で、これを使うと値を取り出せます。

```fsharp
match number with
| 0 -> "Zero"
| i -> sprintf "Non zero: %d" i
```

場合によっては、パターンにさらに条件を加えたいことがあります。これは_ガード_節と呼ばれ、`when`キーワードを使って追加できます。

```fsharp
match number with
| 0 -> "Zero"
| i when i < 0 -> "Negative number"
```

ガード節には、関数の呼び出しを含め、有効な式であれば何でも書けます。

上の例では、すべての入力に一致するパターンがあるわけではありません。コンパイラーはこれを検出し、警告を出力します。これは[_網羅的なマッチング_][exhaustive-matching]と呼ばれます。警告を解消するには、すべてのケースを処理する必要があります。そのために使えるのが[_ワイルドカードパターン_][wildcard-pattern]で、これはどの値にも一致するパターンです。

```fsharp
match number with
| i when i < 0 -> "Negative number"
| _ -> "Positive number"

// No compiler warning
```

コンパイラーは`when`節を使って網羅性を推論することはできない点に注意してください。

```fsharp
match number with
| i when i < 0 -> "Negative number"
| i when i >= 0 -> "Positive number"

// Compiler warning
```

パターンマッチングでは、値が上から順に各パターンと照合され、一致するパターンが見つかると、そのパターンに対応する処理が実行されます。パターンの順番は重要です！　そのため、破棄パターンは必ず`match`式の最後のパターンにします。

パターンマッチングは非常に強力ですが、単純な条件分岐なら、ふつうは`if/else`式を使ったほうが明確に書けます。

```fsharp
let usingPatternMatching number =
    match number with
    | 0 -> "Zero"
    | _ -> "Non-zero"

let usingIfElse number = if number = 0 then "Zero" else "Non-zero"
```
