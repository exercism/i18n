# 説明

チェスの愛好家なら、自分だけのバージョンのゲームを書いてみたいと思うのではないでしょうか。確かに、ネット上にはすでにたくさんのチェスの実装が公開されているかもしれません。でも、自分で作るものは唯一無二です！

チェス盤の各マスは、アルファベットと数字の組み合わせで表されます。

- 横方向のマスの並びはランクと呼ばれ、1から8までの番号が付けられています。
- 縦方向のマスの並びはファイルと呼ばれ、AからHまでのラベルが付けられています。

```text
   A B C D E F G H
 8 # _ _ _ # _ _ # 8
 7 _ _ _ _ _ _ _ _ 7
 6 _ _ _ _ # _ _ # 6
 5 _ # _ _ _ _ _ # 5
 4 _ _ _ _ _ _ # # 4
 3 # _ # _ _ _ _ # 3
 2 _ _ _ _ _ _ _ # 2
 1 # _ _ _ _ _ _ # 1
   A B C D E F G H
```

## 1. チェス盤とファイルから、埋まっているマスの数を数える

`CountInFile(board Chessboard, file string) int`関数を実装しましょう。
マップをrangeで繰り返し処理して、埋まっているマスの合計数を数えます。
整数を返します。
指定されたファイルがマップの中に見つからない場合は、`0`を返します。

```go
CountInFile(board, "A")
// => 3
```

## 2. チェス盤とランクから、埋まっているマスの数を数える

`CountInRank(board Chessboard, rank int) int`関数を実装しましょう。
指定されたランクをrangeで繰り返し処理して、埋まっているマスの合計数を数えます。
整数を返します。
指定されたランクが有効でない場合（`1`から`8`までに含まれない場合）は、`0`を返します。

```go
CountInRank(board, 2)
// => 1
```

## 3. 与えられたチェス盤にあるマスの数を数える

`CountAll(board Chessboard) int`関数を実装しましょう。
チェス盤にあるマスの数を数え、整数を返します。
マスの中身を調べる必要はないので、`index`と`value`の両方を省略したrangeを使うことを考えてみましょう。

```go
CountAll(board)
// => 64
```

## 4. 与えられたチェス盤で埋まっているマスの数を数える

`CountOccupied(board Chessboard) int`関数を実装しましょう。
チェス盤で埋まっているマスの数を数えます。
整数を返します。

```go
CountOccupied(board)
// => 15
```
