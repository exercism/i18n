# はじめに

JavaScriptは動的な言語で、オブジェクト指向、命令型、宣言型（たとえば関数型プログラミング）といったスタイルをサポートしています。

## （再）代入

JavaScriptで名前に値を代入する主な方法はいくつかあります。変数を使う方法と定数を使う方法です。Exercismでは、変数は常に[camelCase][wiki-camel-case]で書き、定数は[SCREAMING_SNAKE_CASE][wiki-snake-case]で書きます。従うべき公式のガイドがあるわけではなく、企業や組織によってスタイルガイドはさまざまです。_変数の書き方は、好きなように書いてかまいません_。演習で用意されているとおりに書くことの利点は、WebインターフェースやほとんどのIDEで変数が別の色で強調表示されることです。

JavaScriptでは、変数は[`const`][mdn-const]、[`let`][mdn-let]、[`var`][mdn-var]のキーワードを使って定義できます。

`let`や`var`を使うと、変数はその寿命の中で異なる値を参照できます。たとえば、`myFirstVariable`は代入演算子`=`を使って何度も定義し直すことができます。

```javascript
let myFirstVariable = 1
myFirstVariable = 'Some string'
myFirstVariable = new SomeComplexClass()
```

`let`や`var`とは対照的に、`const`で定義した変数に代入できるのは一度だけです。JavaScriptではこれを定数の定義に使います。

```javascript
const MY_FIRST_CONSTANT = 10

// Can not be re-assigned.
MY_FIRST_CONSTANT = 20
// => TypeError: Assignment to constant variable.
```

> 💡 後のコンセプト演習で、_定数_への代入・束縛と、_定数_の値の違いを掘り下げて説明します。

## 関数宣言

JavaScriptでは、機能の単位は_関数_にまとめられます。通常、互いに関係する関数は同じファイルにまとめます。これらの関数は入力（引数）を受け取り、`return`キーワードを使って値を_返す_ことができます。関数は`()`という構文で呼び出します。

```javascript
function add(num1, num2) {
  return num1 + num2
}

add(1, 3)
// => 4
```

> 💡 JavaScriptでは、関数を宣言する方法が_たくさん_あります。そうした方法は、`function`キーワードを使う場合とは見た目が異なります。このトラックでは、それらを少しずつ紹介していきますが、すでに知っている場合はどれを使ってもかまいません。ほとんどの場合、どちらを使っても良し悪しはありません。

## 他のファイルに公開する

`function`、定数、変数を_他のファイル_から使えるようにするには、`export`キーワードを使って[エクスポート][mdn-export]する必要があります。そうすると、別のファイルから`import`キーワードを使ってこれらを[インポート][mdn-import]できます。これはモジュールシステムとも呼ばれます。良い例が、すべてのテストの仕組みです。各演習には少なくとも1つのファイルがあり、たとえば`lasagna.js`には_実装_が入っています。さらに、_テスト_が入ったファイルが少なくとも1つあります。たとえば`lasagna.spec.js`です。このファイルは、実装をテストするために、公開された（つまりエクスポートされた）要素を_インポート_します。

```javascript
// file.js
export const MY_VALUE = 10

export function add(num1, num2) {
  return num1 + num2
}

// file.spec.js
import { MY_VALUE, add } from './file'

add(MY_VALUE, 5)
// => 15
```
