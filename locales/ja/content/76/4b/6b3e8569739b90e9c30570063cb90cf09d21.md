# 概要

C++の旅の始まりとして、まずは変数、関数呼び出し、コメントから見ていきましょう。

## コメント

コメントには、1行コメントと複数行コメントの2種類があります。
同じ行で`//`より後にあるものはすべて、コンパイラーに無視されます。
複数行コメントは、Cスタイルのコメントとも呼ばれます。
`/*`と`*/`で囲みます。
これらの間にあるものも同様に無視されます。

## 変数

C++は型付き言語です。
すべての型はコンパイル時に判明している必要があり、通常は明示的に指定する必要があります。
変数の型は変更できません。
`years`という名前の整数変数は、次のように宣言できます。

```cpp
int years;
```

変数は宣言時に初期化するのが良い習慣です。
C++には、そのためのさまざまな仕組みがあります。
波括弧を使う書き方はモダンなC++により沿っていますが、等号を使う書き方もとても一般的です。

```cpp
int tomatoes{80};
int potatoes = 40;
```

~~~~exercism/caution
C++では、初期化していない変数を使うこともできます。
変数に意図的に値を設定するまでは、その値は未定義で、何が入っているかわかりません。
設定前の使用エラーや未定義の動作を避けるために、**常に初期化する**ことをおすすめします。
未定義の動作は、それまで問題なく動いていたプログラムを、最もまずいタイミングでクラッシュさせることがあります。
いくら強調してもしすぎることはありません。未定義の動作は絶対に避けましょう。
~~~~

## 算術演算

`*`、`+`、`-`のような算術演算子は、`3 * 2`や`tomatoes + potatoes`のような式の一部になります。

## 変数の更新

同じ型を保っている限り、変数には新しい値を代入し直せます。

```cpp
tomatoes = tomatoes - 5; // tomatoes is now 75
potatoes = (32 * 2) + 11; // potatoes is now 75 as well
```

## 関数

関数には、名前、戻り値の型、そして（空の場合もある）仮引数リストがあります。
`always_fortyseven`という名前で、常に47を返す関数の例は次のようになります。

```cpp
int always_fortyseven() {
    return 47;
}
```

次は、仮引数を1つ持つ`vip_fee`です。
```cpp
int vip_fee(int standard_fee) {
    /*
    vip_fee calculates the vip fee based on the standard_fee.
    */
    int vip_multi{3};
    return standard_fee * vip_multi;
}
```

あるいは、仮引数を3つ持ち、別の関数を呼び出す`total_fee`です。

```cpp
int total_fee(int vips, int adults, int kids) {
    /*
    total_fee calculates the total price for a group of VIP and adult guests with kids.
    Kids get a flat discount on the standard fee.
    VIP guest fees are calculated by calling vip_fee.
    */
    int standard_fee{30};
    int kids_discount{15};

    int kids_total_fee = kids  * (standard_fee - kids_discount);
    int vips_total_fee = vips * vip_fee(standard_fee);
    int adult_total_fee = adults * standard_fee;

    return vips_total_fee + adult_total_fee + kids_total_fee;
}
```

C++の関数は、他のいくつかの言語のように、最後の文の値を返すことはありません。
コードがコンパイルされるには、`return`キーワードが必要です。

### 空白

空白はソースコードの整形に使われ、スペース、タブ、改行などを含みます。
コンパイラーは不要な空白を無視するので、コードを構造化するために空白を利用できます。
空白を上手に使うと、コードが読みやすくなります。
さまざまな整形スタイルがありますが、それらはすべて慣習的なもので、コンパイラーによって強制されるものではありません。

```cpp
// Formatting makes it easier to find bugs

int eggs_yolks =  3;
int      yeast = 15;

int flour=500;int sugar=200;// compact, but difficult to read
```
