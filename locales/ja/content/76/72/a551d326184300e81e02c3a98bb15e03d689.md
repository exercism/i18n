# `return`

Crystalでは、メソッドの最後の式がその値を返します。ただ、最後の式より前に値を返したいこともあります。そんなときは`return`キーワードを使います。`return`のあとに書いた式の値が返されるのです。`return`のあとに書かれたコードは実行されません。

```crystal
def speed_limit(road_number)
    if road_number == 1
        return 50
        puts "This will not be executed"
    elsif road_number == 2
        return 80
        puts "This will not be executed"
    end
    100
end

p speed_limit(1) # => 50
p speed_limit(2) # => 80
p speed_limit(3) # => 100
```

~~~~exercism/note
メソッドの最後の式が返すべき値であるときは、`return`キーワードは省略しましょう。
~~~~
