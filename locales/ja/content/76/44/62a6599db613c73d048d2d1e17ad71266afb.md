# 概要

`reduce`は、Factorの汎用的な畳み込みです。シーケンスを順にたどりながら、二項クオーテーションにアキュムレーターを渡していきます。このクオーテーションは、現在のアキュムレーターと次の要素を受け取り、新しいアキュムレーターを返します。

```
reduce ( seq init quot: ( prev elt -- next ) -- result )
```

```factor
USING: math sequences ;

{ 1 2 3 4 } 0 [ + ] reduce .         ! => 10
{ 1 2 3 4 } 1 [ * ] reduce .         ! => 24
```

独自の初期値を渡せば、`sum`や`product`では表現できない畳み込みも`reduce`で表せます。たとえば、すべての要素が比較に負けたときの既定値を用意して、シーケンスの中の最大値を求める例です。

```factor
USING: math.order ;

{ 3 1 -4 5 -2 } 0 [ max ] reduce .   ! => 5
{ -3 -1 -4 }    0 [ max ] reduce .   ! => 0
```

初期値の`0`も比較に加わるので、すべてが負のシーケンスでも、最小値ではなく`0`が返ります。

## `produce`：展開

`reduce`の双対にあたるのが、[`sequences`][sequences]にある`produce`です。`reduce`がシーケンスを*消費*するのに対し、`produce`はシーケンスを*生成*します。述語のクオーテーションが現在の状態を判定し、それが真とみなせる値を返す間、本体のクオーテーションが次の要素を生成します。

```
produce ( pred quot -- seq )
```

`reduce`と`produce`を組み合わせると、Factorの畳み込みと展開のペアになります。

## 累積の畳み込み

[`math.statistics`][math.statistics]にある累積系のワードは、入力と同じ長さのシーケンスを返します。各要素は、その位置までの先頭部分（その位置を含む）を畳み込んだ結果です。

| ワード        | 累積の演算   |
|---------------|-------------------|
| `cum-sum`     | 累積の合計          |
| `cum-product` | 累積の積            |
| `cum-min`     | 累積の最小値        |
| `cum-max`     | 累積の最大値        |

```factor
USING: math.statistics ;

{ 3 1 4 1 5 9 2 6 } cum-sum .         ! => { 3 4 8 9 14 23 25 31 }
{ 3 1 4 1 5 9 2 6 } cum-min .         ! => { 3 1 1 1 1 1 1 1 }
{ 3 1 4 1 5 9 2 6 } cum-max .         ! => { 3 3 4 4 5 9 9 9 }
```

累積の畳み込みは、ある量がシーケンスに沿って*どのように*変化してきたかを見たいときに便利です。最終的な値だけでは足りない場面で役立ちます。また、つなげて使うのも便利です。ある累積のワードの出力はそれ自体がシーケンスなので、そのまま次のワードに渡せます。

[math.statistics]: https://docs.factorcode.org/content/vocab-math.statistics.html
[sequences]: https://docs.factorcode.org/content/vocab-sequences.html
