# はじめに

Juliaの中心的な目標の1つは、数値データに対する計算を、すばやく効率的に実行できるようにすることです。しかも、_大量の_数値データを扱います。

通常、データは配列（またはそれに類する型）に格納されるので、配列がJulia言語の中心にあると言ってもよいでしょう。

配列は任意のサイズにでき（ハードウェアのメモリの制約を受けるだけです）、任意の数の次元を持てます。

この入門では、ベクトルと呼ばれる1次元配列の基本に焦点を当てます。

## ベクトルの作成

Juliaでは、ベクトルはインデックス番号でアクセスできる、順序付けられた値の並びです。

ベクトルを作るもっとも簡単な方法は、角括弧（`[]`）の中に値を並べることです。

```julia-repl
julia> num_vec = [1, 4, 9]
3-element Vector{Int64}:
 1
 4
 9

julia> str_vec = ["arrays", "are", "important"]
3-element Vector{String}:
 "arrays"
 "are"
 "important"
```

ベクトルの型は、各要素の型と一致します。

_つまり、ベクトルはすべての要素が同じ型でなければならないのでしょうか？_

ある意味では、そのとおりです。最高のパフォーマンスを求めるなら、そうすることをおすすめします。ただしJuliaは、必要なときには`Any`型を使うことで、この制約を回避できます。

```julia-repl
julia> mixed_vector = [1, "str", 'c']
3-element Vector{Any}:
 1
  "str"
  'c': ASCII/Unicode U+0063 (category Ll: Letter, lowercase)
```

空のベクトルを作成するとき、Juliaは要素の型を`Any`にします。ただし、空の配列に目的の要素型を注釈として付けると、より具体的な型を指定できます。

```julia-repl
julia> empty_vec = []
Any[]

julia> empty_int_vec = Int64[]
Int64[]
```

# インデックス

次のルールをよく読んで、覚えておいてください。

- ***Juliaのインデックスは、既定では0ではなく1から始まります***。

他のデータサイエンス言語（R、Matlab、Fortranなど）を使ったことがある人にはおなじみですが、Cに似た言語を学んできた人には驚きに映るかもしれません。

それ以外は、インデックスは予想どおりに機能します。角括弧に入れるだけです。

```julia
squares = [0, 1, 4, 9, 16]
squares[1]  # 0
squares[3]  # 4
squares[begin]  # 0 ("begin" is synonym for 1)
squares[end]  # 16 ("end" is synonym for length(squares))
```

`end`（とても便利です）と`begin`（おそらくあまり使われません）でインデックスできる手軽さに注目してください。

Pythonプログラマーは、負のインデックスはどうなのかと気になるかもしれません。気にしないでください。負のインデックスはJuliaには存在せず、`BoundsError`になります。1より小さいインデックスや、`length(squares)`より大きいインデックスも同様です。

## ベクトルの操作

Juliaのベクトルは_可変_です。個々の要素の中身を変更できます。

```julia-repl
julia> vals = [1, 3, 5, 7]
4-element Vector{Int64}:
 1
 3
 5
 7

julia> vals[2] = 4  # reassign the value of this element
4

# Only the value at position 2 changes:
julia> vals
4-element Vector{Int64}:
 1
 4
 5
 7
```

ベクトルを操作するための関数はたくさんあります。ただしJuliaのドキュメントでは、これらはベクトルではなく「コレクション」として一般化されています。

慣例として、入力を変更する関数の名前には`!`が付きます。コンパイラーがこれを強制することはありませんが、Juliaの世界ではとても_強い_慣例です。

便利な関数をいくつか紹介します。

- ベクトルの末尾に値を追加するには、`push!()`を使います。
- 最後の値を取り除くには、`pop!()`を使います。
- ベクトルの先頭を操作するには、対応する`pushfirst!()`と`popfirst!()`を使います。
- 任意の位置に要素を挿入したり取り除いたりするには、`insert!()`と`deleteat!()`があります。

```julia-repl
julia> vals = [1, 3]
2-element Vector{Int64}:
 1
 3

julia> push!(vals, 5, 6)  # can add multiple values
4-element Vector{Int64}:
 1
 3
 5
 6

julia> pop!(vals)  # mutates vals, return popped value
6

julia> vals
3-element Vector{Int64}:
 1
 3
 5
```
