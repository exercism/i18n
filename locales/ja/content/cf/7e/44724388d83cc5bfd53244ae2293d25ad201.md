# はじめに

関数を使うと、コードを再利用できるひとつの単位にまとめることができます。
関数は、`func`キーワード、関数名、そして括弧（`()`）の中にカンマで区切って並べた0個以上の仮引数とその型で構成されます。

## 関数の仮引数

仮引数はすべて型を明示する必要があり、仮引数に対する型推論はありません。
仮引数にデフォルト値はないので、関数の仮引数はすべて必須です。

```go
import "fmt"

// No parameters
func PrintHello() {
    fmt.Println("Hello")
}

// One parameter
func PrintHelloName(name string) {
  fmt.Println("Hello " + name)
}
```

同じ型の仮引数はまとめて宣言でき、そのあとに型を一度だけ書きます。

```go
import "fmt"

func PrintGreetingName(greeting, name string) {
  fmt.Println(greeting + " " + name)
}
```

## 仮引数と実引数

よく混同される2つの用語、`parameters`と`arguments`について、簡単に見ておきましょう。
関数の仮引数とは、関数のシグネチャで定義されている名前のことです。たとえば、上の関数`PrintGreetingName`における`greeting`と`name`がそれにあたります。
関数の実引数とは、関数を呼び出すときに仮引数へ渡される具体的な値のことです。
たとえば次の例では、`"Hello"`と`"Katrina"`が、`greeting`と`name`という仮引数に渡される実引数です。

```go
PrintGreetingName("Hello", "Katrina")
```

## 戻り値

仮引数のあとには、0個以上の戻り値が続きます。戻り値にも型を明示する必要があります。
戻り値が1つのときはそのまま書き、複数のときは括弧でくくります。
値は`return`キーワードを使って、関数から呼び出し元のコードに返されます。
1つの関数に複数の`return`文を書くこともできます。
関数の実行は、これらの`return`文のいずれかに到達した時点で終わります。
関数から複数の値を返す場合は、カンマで区切ります。

```go
func Hello(name string) string {
  return "Hello " + name
}

func HelloAndGoodbye(name string) (string, string) {
  return "Hello " + name, "Goodbye " + name
}
```

## 関数の呼び出し

関数を呼び出すには、関数名を指定し、関数の各仮引数に対する実引数を括弧の中に渡します。

```go
import "fmt"

// No parameters, no return value
func PrintHello() {
    fmt.Println("Hello")
}
// Called like this:
PrintHello()

// One parameter, one return value
func Hello(name string) string {
  return "Hello " + name
}
// Called like this:
greeting := Hello("Dave")

// Multiple parameters, multiple return values
func SumAndMultiply(a, b int) (int, int) {
    return a+b, a*b
}
// Called like this:
aplusb, atimesb := SumAndMultiply(a, b)
```

## 名前付き戻り値とnaked return

仮引数と同じように、戻り値にも名前を付けることができます。
名前付き戻り値を使うと、引数のない`return`文がそれらの値を返します。
これは「naked」なreturnとして知られています。

```go
func SumAndMultiplyThenMinus(a, b, c int) (sum, mult int) {
    sum, mult = a+b, a*b
    sum -= c
    mult -= c
    return
}
```
