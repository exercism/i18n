# はじめに

この演習では、条件に応じて処理を実行する必要があります。C#でこれを行う最も一般的な方法は、`if/else`文を使うことです。

```csharp
int x = 6;

if (x == 5)
{
    // Execute logic if x equals 5
}
else if (x > 7)
{
    // Execute logic if x greater than 7
}
else
{
    // Execute logic in all other cases
}
```

`if`文の条件は、`bool`型でなければなりません。C#には _truthy_ な値という概念はありません。
