# 説明

Blorkemon™️のカードへの懐かしさは、まだまだ薄れる気配がありません。もう一度集め始めてしまっただけでなく、友達まで巻き込んでいます。

この演習では、カードのコレクションを`MapSet`で表します。というのも、存在するカードをすべて集めるのが目標なら、重複したカードは重要ではないからです。

## 1. コレクションを始める

友達にもBlorkemon™️熱にどっぷり浸かってほしいですよね。その一番の近道は、カードを1枚あげて、コレクションの第一歩を踏み出してもらうことです。

カードをコレクションに変換する`GottaSnatchEmAll.new_collection`を実装しましょう。

```elixir
GottaSnatchEmAll.new_collection("Newthree")
# => MapSet.new(["Newthree"])
```

## 2. コレクションを育てる

コレクションができたら、それは独り歩きを始め、育てていかなければなりません。

カードとコレクションを受け取り、2つの値を持つタプルを返す`GottaSnatchEmAll.add_card`を実装しましょう。2つの値とは、そのカードがすでにコレクションに入っていたかどうかを示す真偽値と、そのカードを追加したコレクションです。

```elixir
GottaSnatchEmAll.add_card("Scientuna", MapSet.new(["Newthree"]))
# => {false, MapSet.new(["Newthree", "Scientuna"])}
```

## 3. 交換を始める

友達がまたBlorkemon™️にハマった今なら、カードを交換して自分のコレクションを増やせます。

すべての交換が価値があるわけでも、そもそもできるわけでもありません。
持っていないカードは交換に出せませんし、すでに持っているカードのために手放すべきでもありません。

交換する2枚のカード（自分と相手のもの）と、現在のコレクションを受け取る`GottaSnatchEmAll.trade_card`を実装しましょう。
戻り値は2つの値を持つタプルです。1つは、その交換が可能で価値があるかどうかを示す真偽値、もう1つは、実際に交換した場合に手元に残るコレクションです（実際には不可能な場合でも）。

```elixir
GottaSnatchEmAll.trade_card("Scientuna", "Newthree", MapSet.new(["Scientuna"]))
# => {true, MapSet.new(["Newthree"])}
```

## 4. 同じカードは1枚だけ

フリーマーケットで古いカードの山を見つけます。
そのリストを自分のコレクションと比べるために、カードを並べ替えて重複を取り除く必要があります。

カードのリストを並べ替え、並べ替え済みで重複のないカードのリストを返す`GottaSnatchEmAll.remove_duplicates`を実装しましょう。

```elixir
GottaSnatchEmAll.remove_duplicates(["Newthree", "Newthree", "Newthree", "Scientuna"])
# => ["Newthree", "Scientuna"]
```

## 5. 相手が持っていないカード

自分のコレクションを誇りに思うときです。

自分のコレクションと他の誰かのコレクションを受け取り、その相手のコレクションが持っていないカードの枚数を返す`GottaSnatchEmAll.extra_cards`を実装しましょう。

```elixir
GottaSnatchEmAll.extra_cards(MapSet.new(["Scientuna"]), MapSet.new(["Newthree", "Scientuna"]))
# => 0
```

## 6. 全員が持っているカード

Blorkemon™️好きの友達と集まって、どのカードが一番ありふれているのかと考えます。

コレクションのリストを受け取り、すべてのコレクションが持っているカードを並べ替えたリストを返す`GottaSnatchEmAll.boring_cards`を実装しましょう。

```elixir
GottaSnatchEmAll.boring_cards([MapSet.new(["Scientuna"]), MapSet.new(["Newthree", "Scientuna"])])
# => ["Scientuna"]
```

## 7. すべてのカード

友達と力を合わせれば、Blorkemon™️のカードをすべて持っていることになるでしょうか？

コレクションのリストを受け取り、すべてのコレクションにある異なるカードの合計枚数を返す`GottaSnatchEmAll.total_cards`を実装しましょう。

```elixir
GottaSnatchEmAll.total_cards([MapSet.new(["Scientuna"]), MapSet.new(["Newthree", "Scientuna"])])
# => 2
```

## 8. キラキラで決まり

もうすぐ甥っ子が遊びに来ます。ここはひとつ、かっこいいところを見せたいところです。
子どもはキラキラしたものが好きですよね？
Blorkemon™️のカードにもキラキラしたものがあります！

コレクションを受け取り、並べ替えたカードの2つのリストを持つタプルを返す`GottaSnatchEmAll.split_shiny_cards`を実装しましょう。1つは`"Shiny"`で始まるすべてのカード、もう1つはそれ以外のカードです。

```elixir
GottaSnatchEmAll.split_shiny_cards(MapSet.new(["Newthree", "Scientuna", "Shiny Scientuna"]))
# => {["Shiny Scientuna"], ["Newthree", "Scientuna"]}
```
