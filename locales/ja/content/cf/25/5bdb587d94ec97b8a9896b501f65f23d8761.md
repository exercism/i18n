# 文字列のメソッド

`String`には、文字列を操作するためのメソッドがいくつかあります。
これらのメソッドは文字列自体に対して呼び出し、1つの文字列に複数の操作を行うために、つなげて呼び出すことがよくあります。

以下は、特によく使われるメソッドの一部です。
メソッドの完全な一覧は、[`String`のAPIドキュメント][string-api]を参照してください。

## String#upcaseとString#downcase

[`upcase`][upcase]メソッドは、すべての文字を大文字に変換した新しい文字列を返します。

```crystal
"hello".upcase
# => "HELLO"
```

[`downcase`][downcase]メソッドは、すべての文字を小文字に変換した新しい文字列を返します。

```crystal
"HELLO".downcase
# => "hello"
```

## String#capitalizeとString#camelcaseとString#underscoreとString#titleize

より具体的な大文字小文字の変換を行うメソッドもあります。
文字列を特定の形式に変換したいときに役立ちます。
よく使われるメソッドをいくつか挙げます：

| メソッド                          | 説明                                                                                                               | 例                                                   |
| --------------------------------- | ------------------------------------------------------------------------------------------------------------------ | ---------------------------------------------------- |
| [`String#capitalize`][capitalize] | 最初の文字を大文字に、残りを小文字に変換します                                                                     | `"hEllO" # => "Hello"`                               |
| [`String#camelcase`][camel-case]  | アンダースコアをキャメルケースに変換します                                                                         | `"eiffel_tower" # => "EiffelTower"`                  |
| `String#camelcase(lower: true)`   | String#camelcaseと同じですが、最初の文字を小文字のままにします                                                     | `"empire_state_building" # => "empireStateBuilding"` |
| [`String#underscore`][underscore] | すべての文字を小文字に変換し、小文字と大文字の間にアンダースコアを入れます                                         | `"PartyInTheUSA" # => "party_in_the_usa"`            |
| [`String#titleize`][titleize]     | 各単語の最初の文字を大文字に、残りを小文字に変換します                                                             | `"the great gatsBY" # => "The Great Gatsby"`         |

## String#subとString#gsub

Crystalには、文字列の一部を置き換えるメソッドがあります。
これらは[`sub`][sub]（_substitution_、置換）と[`gsub`][gsub]（_global substitution_、全体置換）と呼ばれます。

これらのメソッドは、第一引数に文字列、文字、または正規表現を、第二引数に文字列または文字を取ることができます。
第一引数は置き換えられる文字列の部分で、第二引数は置き換え後の値です。
`Char`と正規表現については、後のコンセプトで説明します。

`sub`メソッドは、第一引数が最初に現れる箇所を第二引数で置き換えます。

```crystal
"hello".sub("l", "r")
# => "herlo"
```

`gsub`メソッドは`sub`と同じように動作しますが、第一引数が現れるすべての箇所を第二引数で置き換えます。

```crystal
"hello".gsub("l", "r")
# => "herro"
```

## String#chompとString#strip

chompとstripを使うと、文字列から不要な文字を削除できます。

[`chomp`][chomp]メソッドは、デフォルトでは文字列の末尾から`\r`、`\n`、または`\r\n`を削除します。
引数を渡して呼び出すと、文字列の末尾から指定した値を削除します。
ただし、その値が文字列の末尾にある場合に限ります。

```crystal
"hello\n".chomp
# => "hello"

"hello".chomp("llo")
# => "he"
```

[`strip`][strip]メソッドは、デフォルトでは文字列の先頭と末尾からすべての空白を削除します。
引数を渡して呼び出すと、文字列の先頭と末尾からその引数を削除します。
ただし、その値が文字列の先頭または末尾にある場合に限ります。

```crystal
" hello ".strip
# => "hello"
```

## String#reverse

[`reverse`][reverse]メソッドを使うと、文字列を逆にできます。
このメソッドは、文字を逆順に並べた新しい文字列を返します。

```crystal
"hello".reverse
# => "olleh"
```

## String#index

[`index`][index]メソッドを使うと、文字列内での文字のインデックスを調べられます。
`index`メソッドは、引数に`String`、`Char`、または正規表現を取ります。
検索を開始するインデックスを指定する、省略可能な第二引数を取ることもできます。
`index`メソッドは、引数が最初に現れるインデックスを返します。

```crystal
"hello".index("l")
# => 2

"hello".index("l", 3)
# => 3
```

## String#delete_at

[`delete_at`][delete_at]メソッドを使うと、文字列から文字を削除できます。
`delete_at`メソッドは引数にインデックスを取り、そのインデックスにある文字を削除します。

```crystal
"hello".delete_at(0)
# => "ello"

"hello".delete_at(3)
# => "helo"
```

## String#insert

[`insert`][insert]メソッドを使うと、特定のインデックスに文字列を挿入できます。
`insert`メソッドは、第一引数にインデックスを、第二引数に文字列を取ります。
`insert`メソッドは、第二引数をそのインデックスに挿入した新しい文字列を返します。

```crystal
"hello".insert(0, "h")
# => "hhello"

"hello".insert(3, "l")
# => "helllo"
```
