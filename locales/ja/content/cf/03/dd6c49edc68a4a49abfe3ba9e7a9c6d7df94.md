# はじめに

Rの`vector`は、同じ`mode`（`numeric`や`character`など）の値の集まりです。異なる型の値を混ぜて渡すと、Rはそれらをすべて共通の型に知らないうちに変換してしまいます。多くの場合はcharacterになり、思わぬ結果を招くことがあります。

## ベクトルの作成

すべての値がすでに手元にある場合は、`c()`（"concatenate"または"combine"の略）を使います。

```R
x <- 10
v <- c(4, 7, x)
```

`c()`関数はとても柔軟で、入力には他のベクトルや範囲を指定することもできます。`c()`はどんな数・種類の入力でも受け取り、それらを1つのベクトルにまとめます。

## 範囲

連続した値の範囲（増加でも減少でも）を表すには、`:`表記を使えます。

```R
v <- 1:5 # equivalent to c(1, 2, 3, 4, 5)
w <- 10:7 # c(10, 9, 8, 7)
```

## ベクトルの要素へのアクセス

多くの言語と同じように、角括弧（`[]`）の中にインデックスを書いて要素を取り出せます。

```R
> v <- 4:7
> v[2]
[1] 5
> v[2:4]
[1] 5 6 7
```

ただし注意してください。***Rのインデックスはデフォルトで1から始まります***。

これは科学技術計算向けの言語（Fortran・Matlab・Julia）では一般的ですが、Cとその多くの後継言語の0始まりのインデックスとは異なります。

範囲は上の例のように使えるほか、非常に柔軟な`c()`関数の中でも使えます。

```R
v <- c(4, 7, 10)
w <- c(2, v[2:3], 11) # c(2, 7, 10, 11)
```

`vectors`は（Rのほとんどのものと同じく）変更可能で、同じように柔軟な構文を使って1つまたは複数の要素に書き込めます。

```R
> v <- 1:10
> v[2] <- 42
> v[4:6] <- c(11, 12, 13)
> v
 [1]  1 42  3 11 12 13  7  8  9 10
```

## 負のインデックス

他の言語に慣れたプログラマーなら、`v[-1]`がベクトルの最後の要素にアクセスする方法だと思うかもしれません。
でも、それは間違いです！

負のインデックスは、実は要素を***取り除く***ための方法で、より短いベクトルを返します。

```R
> v <- c(2, 4, 6)
> v[-2]
[1] 2 6  # second element gone
```
