# はじめに

## `switch`文

Wikipediaは`switch`文を「選択制御機構の一種で、変数や式の値によってプログラムの制御の流れを変えるためのもの」と説明しています。

この仕組みには、`switch`、`case`、`break`、`default`というキーワードが関わってきます。

最も単純な使い方では、プリミティブ型や文字列の式を調べ、その値に基づいて判断を下します。たとえば、次のようになります。

```csharp
string direction = GetDirection();
switch (direction)
{
    case "left":
        GoLeft();
        break;
    case "right":
        GoRight();
        break;
    default:
        MarkTime();
        break;
}
```

最も高度な使い方になると、ダウンキャスト`case <Type> <variable>:`やガード（`when`）が登場します。

```csharp
Animal animal = GetAnimal();

switch (animal)
{
    case Dog canine:
    case Coyote canine:
        canine.Bark();
        break;
    case Cat cat when cat.HasOnly8Lives():
        cat.IsCareful();
        cat.Meow();
        break;
    case Cat cat:
        cat.Meow();
        break;
}
```
