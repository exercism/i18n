# インストール

## PowerShellトラックの必要条件

ExercismのPowerShellトラックでは、次のものがシステムにインストールされている必要があります。

- PowerShellまたはWindows PowerShell Core
- Pesterのテスト・モックフレームワークモジュールがインストールされていること

（補足：PowerShellのサポートは重要な修正に限られます。PowerShell Coreは継続的にメンテナンスされており、クロスプラットフォーム対応もより充実しています）

### PowerShellのインストール

PowerShellは、Windows 7 SP1以降のすべてのWindowsオペレーティングシステムにプリインストールされています。

PowerShellの最新バージョンと、すべてのプラットフォーム（Linux、macOS、Windows）向けのインストール手順は[こちら][installation]にあります。

[PowerShell][source-code]のソースコードと手動インストールも利用できます。

### Pesterフレームワークのインストールと更新

[Pester][pester]はPowerShellのテストフレームワークです。
バージョン4.0.9以降は、Windows、Linux、MacOS上のPowerShell Coreと互換性があります（一部制限があります）。

Windows 10にはプリインストールされていますが、次のPowerShellコマンドを実行して更新することをおすすめします。

```PowerShell
Install-Module -Name Pester -Force -SkipPublisherCheck
```

以降の更新では、次を実行します。

```PowerShell
Update-Module -Name Pester
```

必要であれば、インストールの詳しい手順はこちらで確認できます。[https://github.com/pester/Pester/wiki/Installation-and-Update]()

## IDEを使う

より高機能な編集環境を求めるなら、IDEを使うのがよいでしょう。
PowerShellプロジェクトのビルドに対応した、特に人気の高いIDEは次のとおりです。

### すべてのプラットフォーム

- [PowerShell ISE (Integrated Scripting Environment)][ise]は、PowerShellに付属するグラフィカルなIDEです（Windowsのみ）。
  PowerShell ISEを起動するには、PowerShellコンソールで`powershell_ise.exe`と入力します。
- [Visual Studio Code][vsc]と[PowerShell拡張機能][vsc-extension]。
  Visual Studio Codeでは、テストの実行とコードのデバッグもできます。
- [Sublime Text 3][sublime]と[PowerShellパッケージ][sublime-package]。
