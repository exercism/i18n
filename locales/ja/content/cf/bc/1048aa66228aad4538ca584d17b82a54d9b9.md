# 説明

友達が秘密の数値を当てる、ちょっとしたオンラインゲームを作っているとします。いくつかフィードバックを返したいものの、1回の予想で答えを明かすわけにはいきません。そこで、予想と秘密の数値の関係に応じて、違う応答を返す関数を考える必要があります。

| 条件                                                     | 応答       |
| ------------------------------------------------------------- | -------------- |
| 予想が秘密の数値と一致するとき                      | "Correct"      |
| 予想が秘密の数値より1つ大きいか1つ小さいとき | "So close"     |
| 予想が秘密の数値より大きいとき              | "Too high"     |
| 予想が秘密の数値より小さいとき              | "Too low"      |
| 予想がされていないとき                                       | "Make a guess" |

予想と秘密の数値は、すべて整数です。

## 1. 予想が秘密の数値と一致するときの応答を返す

2つの引数`secret_number`と`guess`（どちらも整数）を取る`compare/2`関数を実装します。

```elixir
GuessingGame.compare(5, 5)
# => "Correct"
```

## 2. 予想が秘密の数値より大きいときの応答を返す

秘密の数値より大きい予想に応答するように、`compare`関数を変更します。

```elixir
GuessingGame.compare(5, 8)
# => "Too high"
```

## 3. 予想が秘密の数値より小さいときの応答を返す

秘密の数値より小さい予想に応答するように、`compare`関数を変更します。

```elixir
GuessingGame.compare(5, 2)
# => "Too low"
```

## 4. 予想が秘密の数値より1つ大きいか1つ小さいときの応答を返す

秘密の数値に近い予想に応答するように、`compare`関数を変更します。

```elixir
GuessingGame.compare(5, 6)
# => "So close"
GuessingGame.compare(5, 4)
# => "So close"
```

## 5. 予想がないときの応答を返す

予想がない場合に応答するように、`compare`関数を変更します。

```elixir
GuessingGame.compare(5)
# => "Make a guess"

GuessingGame.compare(5, :no_guess)
# => "Make a guess"
```
