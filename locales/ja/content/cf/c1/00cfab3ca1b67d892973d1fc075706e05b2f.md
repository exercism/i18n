# はじめに

## 複数の節を持つ関数

Elixirは、関数に複数の節を持たせることで、**開放閉鎖原則**の実践をしやすくしています。制御ロジックをあちこちに散らかしてハードコードするのではなく、的を絞った関数を書けば、振る舞いを簡単に追加したり削除したりできるのです。

Elixirには、次のように書くための_複数の関数節_と_ガード_があります。

```elixir
def number(n) when n == 7 do
  "Awesome, that's my favorite"
end

def number(_n) do
  "That's not my favorite"
end
```

実行時、Elixirはソースファイルの上から下に向かって、どの関数節を呼び出すかを調べます。

使われていない変数には、先頭にアンダースコアを付けます。

## ガード

ガードは、ガード関数による引数の評価に基づいて、Elixirが関数を呼び出すのを防ぐために使われます。ガードは`when`キーワードで始まり、その後に真偽値の式が続きます。ガード関数は、次の条件を満たす特別な関数です。

- 純粋であり、グローバルな状態を一切変更しないこと。
- 厳密に`true`または`false`の値を返すこと。

よく使われるガードの一覧は、[Elixirのドキュメント][kernel-guards]にあります。これには、型チェック、基本的な算術、比較、厳密な真偽値演算子が含まれます。

## デフォルト引数

関数は、1つ以上の引数にデフォルト値を宣言できます。次の関数を見てみましょう。

```elixir
def number(n \\ 13), do: "That's not my favorite"
```

コンパイルすると、Elixirは`number/0`（引数なし）と`number/1`（引数1つ）の関数定義を作成します。

複数の引数にデフォルト値がある場合、デフォルト値は左から右へと関数に適用され、足りない引数を埋めます。

関数に複数の節がある場合、デフォルト引数は、関数節の前にある関数ヘッダー（本体のない関数）で定義します。

```elixir
def number(n \\ 13)
def number(n) when n < 10, do: "Dream bigger!"
def number(n) when n > 100, do: "Not that big..."
```

[kernel-guards]: https://hexdocs.pm/elixir/Kernel.html#guards
