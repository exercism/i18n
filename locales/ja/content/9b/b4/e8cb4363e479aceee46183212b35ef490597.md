# 概要

## 算術演算子

JavaScriptには、数値に対して基本的な算術演算を行うための6つの演算子があります。

- `+`：加算演算子は、数値の和を求めるために使います。

  ```javascript
  1 + 2; // => 3
  2.5 + 3.9; // => 6.5
  ```

- `-`：減算演算子は、2つの数値の差を求めるために使います。

  ```javascript
  19 - 2; // => 17
  7.4 - 1.2; // => 6.2
  ```

- `*`：乗算演算子は、2つの数値の積を求めるために使います。

  ```javascript
  7 * 5; // => 35
  9.2 * 6.3; // => 57.959999999999994
  ```

- `/`：除算演算子は、2つの数値を割るために使います。
  JavaScriptの数値は常に浮動小数点数なので、整数の除算はありません。

  ```javascript
  8 / 2; // => 4
  25 / 3; // => 8.333333333333334
  ```

- `%`：余り演算子は、割り算を行ったときの余りを求めるために使います。

  ```javascript
  40 % 4; // => 0
  11 % 4; // => 3
  -11 % 4; // => -3
  ```

- `**`：べき乗演算子は、数値を累乗するために使います。
  [`Math.pow()`][mdn-math-pow]を使うのと同じです。

  ```javascript
  4 ** 3; // => 64
  4 ** 1 / 2; // => 2
  ```

## 計算の順序

1行の中で複数の演算子を使う場合、JavaScriptは[こちらの優先順位表][mdn-operator-precedence]に示されている優先順位に従います。
これを今の話に当てはめて簡単に言うと、JavaScriptは、小学校の算数で習ったPEDMAS（括弧、指数、割り算・掛け算、足し算・引き算）のルールに従います。

<!-- prettier-ignore-start -->
```javascript
const result = 3 ** 3 + 9 * 4 / (3 - 1);
// => 3 ** 3 + 9 * 4/2
// => 27 + 9 * 4/2
// => 27 + 18
// => 45
```
<!-- prettier-ignore-end -->

## 省略形の代入演算子

省略形の代入演算子を使うと、変数に対して算術演算を行い、その新しい値を同じ変数に代入するコードを短く書けます。
たとえば、2つの変数`x`と`y`を考えてみましょう。
このとき、`x += y`は`x = x + y`と同じです。
多くの場合、変数`y`の代わりに数値が使われます。
ほかの5つの演算も、同じように書くことができます。

```javascript
let x = 5;
x += 25; // x is now 30

let y = 31;
y %= 3; // y is now 1
```
