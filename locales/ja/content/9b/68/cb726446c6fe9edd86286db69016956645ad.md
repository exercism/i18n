## MacOS

まず、[Homebrew][1]を使ってLuaと[Luarocks][2]をインストールします。

```shell
$ brew install lua luarocks
```

次に、Luaのテストフレームワークである[Busted][3]をインストールします。

```shell
$ luarocks install --local busted
```

システムの`$PATH`に`~/.luarocks/bin`を追加します。

```shell
export PATH="$HOME/.luarocks/bin:$PATH"
```

ただし、この設定は一時的なものです。`$PATH`に恒久的に追加するには、使っているシェルに応じて`.bashrc`、`.zshrc`、`config.fish`のいずれかに記述する必要があります。

あとはテストを実行します。

```shell
$ busted
```

## Ubuntu

まず、[Apt][6]を使ってLuaと[Luarocks][2]をインストールします。

```shell
$ sudo apt-get install lua5.4 liblua5.4-dev luarocks
```

次に、Luaのテストフレームワークである[Busted][3]をインストールします。

```shell
$ luarocks install --local busted
```

システムの`$PATH`に`~/.luarocks/bin`を追加します。

```shell
export PATH="$HOME/.luarocks/bin:$PATH"
```

ただし、この設定は一時的なものです。`$PATH`に恒久的に追加するには、使っているシェルに応じて`.bashrc`、`.zshrc`、`config.fish`のいずれかに記述する必要があります。

あとはテストを実行します。

```shell
$ busted
```

## Windows 10: WSL

まず、[PowerShell][8]（管理者として実行）を使って[WSL (Windows Subsystem for Linux)][7]を有効にする必要があります。

```shell
PS> Enable-WindowsOptionalFeature -Online -FeatureName Microsoft-Windows-Subsystem-Linux
```

この作業には再起動が必要です。

次に、[Microsoft Store][9]からUbuntuをインストールするか、**または**PowerShellを使ってダウンロードしてインストールします。

```shell
PS> curl.exe -L -o ubuntu1804.appx https://aka.ms/wsl-ubuntu-1804
PS> Add-AppxPackage .\ubuntu1804.appx; rm .\ubuntu1804.appx
PS> ubuntu1804
```

次に、パッケージリストを更新します。

```shell
PS> wsl
$ sudo apt-get update
```

これで、上の[Ubuntuの手順](#ubuntu)に従って[LuaRocks][2]と[Busted][3]をインストールする準備が整いました。

完了したら、任意のWindowsコマンドラインから直接テストを実行できます。

```cmd
C:\> wsl busted
```

## Windows 10: Docker

### Gitbashのインストール

この手順は任意です。Windows標準のCLIや別のCLIを使いたい場合は、以下の手順を少し調整する必要があるかもしれません。

ダウンロードは[こちら][10]から。
インストール手順は[こちら][11]です。

### Dockerのインストール

手順に従って[Docker for Windows][12]をインストールします。
インストールが完了したら、次のコマンドを実行して正しくインストールされたことを確認できます。

```shell
$ docker --version
```

_初めてDockerを実行しようとすると、エラーが発生することがあります。_

`cannot enable hyper-v service`

_このエラーが発生した場合は、[Hyper Vを有効にする][13]手順に従ってください。設定を無効にしてコンピューターを再起動し、起動後に再度有効にする必要があるかもしれません。_

### bustedのインストール

GitbashとDockerをインストールしたら、bustedの「コンテナ」をインストールできるようになります。

Gitbashで次を実行します。

広く使われている次のDockerコンテナを取得するには、次を実行します。

```shell
$ docker pull imega/busted
```

毎回コマンド全体を入力しなくて済むように、関数を作成します。
これを`.bashrc`に追加します。

```shell
dbusted() { docker run --rm -t -v "/$@":/data imega/busted; }
```

あとは、CLIでテストを実行したいディレクトリに移動して、次を実行します。

```shell
$ dbusted $PWD
```

bustedのテストの出力が表示されるはずです。
