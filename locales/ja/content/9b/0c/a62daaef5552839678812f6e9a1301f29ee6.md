# はじめに

Goには、整数または浮動小数点の値を表せる基本的な数値型があります。

この概念では、2つの数値型を取り上げます。

- `int`：例：`0`、`255`、`2147483647`。
   少なくとも32ビットのサイズを持つ符号付き整数です（値の範囲：-2147483648から2147483647）。
   ただし、これはシステムのアーキテクチャによって異なります。
   現代のほとんどのコンピューターは64ビットなので、`int`のサイズは64ビットになります（値の範囲：-9223372036854775808から9223372036854775807）。

- `float64`：例：`0.0`、`3.14`。
   64ビットの浮動小数点数全体の集合を表します。

Goは、`+`、`-`、`*`、`/`、`%`という標準的な算術演算子をサポートしています（モジュロではなく余りです）。

Goでは、異なる型の間で値を代入するには、明示的な変換が必要です。
たとえば、`int`を`float64`に変換するには、次のようにします。

```go
var x int = 42
f := float64(x)

fmt.Printf("x is of type: %s\n", reflect.TypeOf(x))
// Output: x is of type: int

fmt.Printf("f is of type: %s\n", reflect.TypeOf(f))
// Output: f is of type: float64
```
