# 説明の補足

## ヒント

この演習を完了するには、関数`wordCount`を実装する必要があります。この関数は*テキスト*を受け取り、各*単語*が何回現れるかを返します。

この演習を初めて解く場合は、用意されているシグネチャのまま進めることをおすすめします：

```haskell
wordCount :: String -> [(String, Int)]
```

慣れてきたら、この問題にもう一度取り組んで、ほかのデータ型やライブラリを試してみるのもよいでしょう：

- *text*パッケージの`Text`。
- *containers*パッケージの`Map`。
- *multiset*パッケージの`MultiSet`。

テストスイートは、意味の通るほとんどどんな型シグネチャでも受け入れるように意図的に設計されています。ですから、自分がいちばんよいと思うものを探してみてください。
