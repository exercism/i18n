# 説明

地元の詩人会が新しいシーズンを迎えます。詩人たちは会に加わり、そのうちの2人が一緒に詩を書くと、2人は同じ*創作サークル*の一員になります。会は、誰が誰と同じサークルなのかを把握したいと考えており、それを管理するワードを書くよう依頼されました。

素集合がうってつけです。詩人ひとりひとりが要素で、創作サークルがグループになります。

## 1. 会を立ち上げる

`new-club`を定義します。詩人の並びを受け取り、すべての詩人を登録した新しい素集合を返します。各詩人は、それぞれ自分だけの創作サークルから始まります。

```factor
{ "Keats" "Byron" "Dickinson" } new-club
! => a disjoint set holding the three poets
```

## 2. 共作を記録する

`collaborate`を定義します。詩人を2人と会を受け取ります。2人の詩人の創作サークルを統合して会を返すので、共作を次々と記録できます。

```factor
{ "Keats" "Byron" "Dickinson" } new-club
"Keats" "Byron" rot collaborate
! => the club, with Keats and Byron now in one circle
```

## 3. 詩人のサークルを探す

`circle-of`を定義します。詩人と会を受け取り、その詩人の創作サークルの代表を返します。同じサークルに属する2人の詩人は、いつも同じ代表を返します。

```factor
{ "Keats" "Byron" "Dickinson" } new-club
"Dickinson" swap circle-of
! => "Dickinson"   (still in a circle of their own)
```

## 4. 同じサークル？

`same-circle?`を定義します。詩人を2人と会を受け取り、2人の詩人が同じ創作サークルに属していれば`t`を、そうでなければ`f`を返します。組み込みの同値テストを使うのではなく、詩人の代表を比較します。

```factor
{ "Keats" "Byron" "Dickinson" } new-club
"Keats" "Byron" rot collaborate
dup [ "Keats" "Byron" ] dip same-circle? .      ! => t
    [ "Keats" "Dickinson" ] dip same-circle? .  ! => f
```
