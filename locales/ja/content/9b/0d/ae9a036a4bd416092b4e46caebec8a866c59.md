# 説明

学校の遺失物保管所では、すべての物を箱に入れて保管しています。箱に入るものは何でもよく、セーターだったり、数値だったり、名前だったりします。

`LOST_BOX{T}`クラスを書いてみましょう。クラスヘッダーはスタブに書いてあります。

## 1. 品物を預かる

`create`は品物と、それを届け出た人の名前を受け取り、箱を返します。箱は最初は引き取られていない状態です。

```sather
box ::= #LOST_BOX{STR}("blue jumper", "Mia");
box.item
-- => "blue jumper"
box.handed_in_by
-- => "Mia"
box.claimed
-- => false
```

## 2. 引き取る

`claim`は箱を引き取り済みにします。何も返しません。

```sather
box.claim;
box.claimed
-- => true
```

## 3. まだ引き取り待ちか

`waiting`は、箱がまだ引き取られていないかどうかを返します。

```sather
box.waiting
-- => false
```

## 4. 中身を入れ替える

`replace`は新しい品物を受け取り、それを箱に入れて、それまで入っていたものを返します。入ってくるものも、出てくるものも、どちらも`T`です。

```sather
old ::= box.replace("red jumper");
old
-- => "blue jumper"
box.item
-- => "red jumper"
```

## 5. 説明文を書く

`describe`は箱についての1行を返します。たとえば`"blue jumper, handed in by Mia"`のようなものです。

品物を文字列にするには、`T`が文字列に変換できることをクラスが知っている必要があります。型パラメーターに制約を付けましょう。クラスヘッダーを`class LOST_BOX{T < $STR}`と書けば、`item.str`が使えるようになります。

```sather
box.describe
-- => "blue jumper, handed in by Mia"
```
