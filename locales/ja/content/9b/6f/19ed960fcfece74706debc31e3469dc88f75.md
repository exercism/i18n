# 概要

PHPでは、変数に括弧（`()`）を付けると、その変数を関数として呼び出すことができます。PHPが関数を呼び出そうとすると、変数の値と同じ名前の関数を探します。

```php
function foo(): string
{
    return "foo() invoked";
}

$func = 'foo';
$func(); // This calls foo()
```

## 静的クラス関数の呼び出し

静的クラスの関数も同じように呼び出すことができます。

```php
class Rocket
{
    public static function launch()
    {
        return '3, 2, 1, Liftoff!';
    }
}

$func = 'Rocket::launch';
$func(); // This calls Rocket::launch()
```

## インスタンスのクラス関数の呼び出し

クラスのインスタンスの関数を呼び出すこともできます。

```php
class Rocket
{
    public function openDoor()
    {
        return 'Door open.';
    }
}

$rocket = new Rocket();
$func = [$rocket, 'openDoor'];
$func(); // This calls Rocket::openDoor()
```
