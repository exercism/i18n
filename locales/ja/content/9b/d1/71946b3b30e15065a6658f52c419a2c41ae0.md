## 「Hello, World!」に会ってみよう

「Hello, World!」は、おそらく世界で最も有名なプログラムです。
プログラミングを学んだ人なら、ほとんど誰でも一度は書いたことがあるはずです。
そのシンプルさと親しみやすいメッセージは、素晴らしいプログラミングの世界への第一歩を象徴することがよくあります。

Exercismでは、`hello`という名前の関数が提供され、それは「Goodbye, Mars!」を返します。

```python
def hello():
    return 'Goodbye, Mars!'
```

課題は、代わりに「Hello, World!」を返すように変更することです。

## 従来のアプローチ

まずは、最もシンプルなアプローチであり、Exercismが実装してほしいと考えている方法です。
「Goodbye, Mars!」から「Hello, World!」への文字列の簡単な変更だけで、安全にそれを返せます！

```python
def hello() -> str:
    return 'Hello, World'
```

私は、思いつく限りのさまざまな方法を使ってこの演習を解いてみます。

### 順列

激しい雷雨が通り過ぎ、かわいそうな不運なマシンが雷に打たれました。
電源はまだ入りますが、今は奇妙な動きをしています。
挨拶メッセージを組み立てる文字はすべて残っていますが、順番がバラバラで、ロジックボードの損傷により、マシンはメッセージの正しい順番をもう取得できません。
しかも運の悪いことに、以前作った信じられないほど信頼できる*壊れない*小さいマシンは、実は盗まれてしまいました（そう、もうありません！）。
そこで、いつもの相棒に、これらの文字を並べ替えて正しいメッセージにするあらゆる方法を試させることにしました。
なにしろ13文字しかなく、マシンにはたくさんのメモリがあります。すぐに終わるはずです…。

```python
from itertools import permutations

def hello() -> str:
    chars = ['H', 'e', 'l', 'l', 'o', ',', ' ', 'W', 'o', 'r', 'l', 'd', '!']

    all_permutations = permutations(chars)
    for perm in all_permutations:
        if ("".join(perm) == "Hello, World!"):
            return ''.join(perm)
```

### 探索

そのせいでどれを選べばいいのかわからなくなりましたが、少なくとも何らかの順番にはなっています。

### 上品

もっとカジュアルにして「Hi」と言い始めることも考えましたが、*上品な*人なので、いつも`hello`メソッドだけを使い、もう一方にはテープを貼ってふさぐことにしました。

salutation = Greeting()

### 再帰

なぜか、マシンが少し遅延して10秒遅れてしか応答しないと面白いと思いました。弟はまたも、この機能の背後にある論理について疑問を投げかけます。彼によれば、このマシンを使っているのは自分だけだからです。

```python
import time

def hello(n=10):
    if n == 0:
        return "Hello, World!"
    else:
        time.sleep(1)
        return hello(n-1)
```

### ランダム

突然、ある日、同じ挨拶を何度も繰り返すのにうんざりして、最後に一度だけ挨拶させて、マシンを完全に引退させ、もう二度と触らないことにしました。
マシンは長い間、苦楽を共にしてきたので、「友達」同士のこの最後の対面を運命に任せることにしました。
 最後にもう一度電源を入れ、ただ回してみます…。

```python
import random

def hello():
    chars = list("Helo,Wrld!")
    greeting = ""
    while (greeting != "Hello, World!"):
        greeting = "".join(random.choices(chars, k=13))
    return greeting
```
