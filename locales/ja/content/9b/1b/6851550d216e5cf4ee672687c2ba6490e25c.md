# はじめに

C#の型は、クラスや構造体のスコープ内で定義できます。外側の型は、一種の名前空間のような役割を果たします。内側の型にアクセスするには、外側の型をドット記法でつなぎます。

```csharp
class Outer
{
    public interface IInner {}
    public enum EInner {}
    public class CInner {}
    public struct SInner {}
}

var outer = new Outer();
var inner = new Outer.CInner();
```

内側の型には、アクセスレベルを設定できます。

外側の型のprivateメンバーは、内側の型のメンバーから参照できますが、その逆はできません。
