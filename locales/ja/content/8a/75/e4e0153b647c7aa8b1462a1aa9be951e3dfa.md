# 概要

Factorの条件分岐はどれも、**quotations**を分岐として受け取ります。**quotations**とは角括弧（`[]`）で書かれたコード、つまり`[ ... ]`のことで、条件分岐がそれを選ぶまでは実行されず、値としてスタックに積まれます。（**quotations**そのものについては、後の演習で詳しく扱います。）

基本的な3つは`kernel`にあります。

```
if      ( ? then-quot else-quot -- )
when    ( ? quot -- )
unless  ( ? quot -- )
```

アスタリスクの付いた2つのバリアントは、真偽値が真のとき、その値を活かす価値のあるものとして扱います。いわゆる「値または`f`」のペアです。

```
if*     ( ? true false -- )    ! truthy: true called WITH value
unless* ( ? false      -- )    ! falsy: false runs and pushes default
```

```factor
: abs   ( x -- y ) dup 0 < [ neg ] [ ] if ;
: shout ( s -- )   dup empty? [ drop ] [ >upper print ] if ;
```

分岐が2つより多いときは、`combinators`にある`cond`を使います。`cond`は`{ predicate body }`のペアを並べた配列を順にたどり、最初に成立した述語の本体を実行します。定番の書き方では、各述語の中で`dup`を使って入力を残し、本体の先頭で`drop`してその入力を捨ててから、結果をスタックに積みます。

```factor
{
    { [ dup 0 <  ] [ drop "negative" ] }
    { [ dup 0 =  ] [ drop "zero"     ] }
    [ drop "positive" ]
} cond
```

末尾にある、述語のない項目がデフォルトの分岐になります。
