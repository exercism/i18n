# 関数レベルのガードを使う

[comment]: # (このエラーは、解答でガードを使っているものの、それを関数節では使っていない場合に発生します)

関数節で[ガード](https://hexdocs.pm/elixir/master/guards.html)を使うと、`two_fer/1`がバイナリ以外の入力でコードを実行するのを防げます。

```elixir
def hello(what) when is_binary(what) do
  "Hello, #{what}!"
end
```

与えられた節のどれにも一致しない引数で関数が呼び出されると、`FunctionClauseError`が発生します。

```elixir
hello(123)

# => ** (FunctionClauseError) no function clause matching in hello/1
#
#    The following arguments were given to Foo.hello/1:
#
#    # 1
#    123
```
