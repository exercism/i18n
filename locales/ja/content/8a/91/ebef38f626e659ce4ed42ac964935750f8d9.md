# はじめに

この演習は、[Leah's Luscious Lasagna][lasagna]の整数演算を土台にしています。ここでは浮動小数点数を扱い、目的に合った除算のワードを選べるようになります。

## 整数と浮動小数点数

Factorは整数（`1`、`42`、`1_000_000`）と浮動小数点数（`1.0`、`3.14`、`6.02e23`）を区別します。1つの計算の中で整数と浮動小数点数を混ぜると、結果は浮動小数点数になります。

```factor
2 3 + .      ! => 5
2 3.0 + .    ! => 5.0
```

数字の桁を区切るために、数値の中にアンダースコアを入れることができます（`1_000_000`）。Factorはそれを単に無視します。

## 除算のワード

Factorには除算のための専用ワードがいくつかあります。それらはすべて[`math`][math]ボキャブラリに収められています。

```
/    ( x y -- x/y )    ! exact: ratio for two integers, float if either is a float
/f   ( x y -- f   )    ! always a float
/i   ( x y -- q   )    ! integer division (truncates toward zero)
mod  ( x y -- r   )    ! remainder
/mod ( x y -- q r )    ! quotient and remainder together
```

```factor
1 2 / .        ! => 1/2     (a proper ratio)
16 3 / .       ! => 5+1/3   (an improper ratio, printed as a mixed numeral)
16 3 /f .      ! => 5.333333333333333
16 3 /i .      ! => 5      (truncated)
16 3 mod .     ! => 1
16 3 /mod .s   ! quotient and remainder in one pass
! => 5
! => 1
16.0 3 / .     ! => 5.333333333333333
```

`/`は、2つの整数に対しては`ratio`（Factorの正確な有理数型）を生成し、どちらかの入力が浮動小数点数であれば`float`を生成します。`/f`は、2つの整数であっても必ず浮動小数点数の結果にします。`/i`は常に0に向かって切り捨てます。

## 判定

[`math`][math]、[`math.functions`][math.functions]、[`math.primes`][math.primes]にある数値の述語を紹介します。

```
zero?    ( x       -- ? )
even?    ( x       -- ? )
odd?     ( x       -- ? )
prime?   ( x       -- ? )
divisor? ( m n     -- ? )    ! true when n divides m
integer? ( x       -- ? )    ! true for ints (fixnum or bignum)
float?   ( x       -- ? )    ! true for floats
number?  ( x       -- ? )    ! true for any numeric kind
```

```factor
0 zero? .            ! => t
0.0 zero? .          ! => t
3 zero? .            ! => f

4 even? .            ! => t
7 even? .            ! => f
7 odd? .             ! => t

7 prime? .           ! => t
9 prime? .           ! => f

15 5 divisor? .      ! => t   (5 divides 15)
15 4 divisor? .      ! => f
```

## 浮動小数点数から整数へ

[`math.functions`][math.functions]ボキャブラリの`floor`、`ceiling`、`round`は、いずれも浮動小数点数を返します（`3`ではなく`3.0`）。本当の整数を得るには、`>integer`をつなげます。

```factor
3.7 floor >integer .       ! => 3
3.2 ceiling >integer .     ! => 4
```

## 累乗と絶対値

`sq`、`^`、`abs`（[`math.functions`][math.functions]にあります）は、平方、任意の累乗、絶対値を計算します。

```
sq  ( x   -- x*x )
^   ( x y -- x^y )
abs ( x   -- |x| )
```

```factor
5 sq .          ! => 25
2 10 ^ .        ! => 1024
2 0.5 ^ .       ! => 1.4142135623730951
-7 abs .        ! => 7
3 abs .         ! => 3
```

## 最小値と最大値

`min ( x y -- z )`と`max ( x y -- z )`（[`math.order`][math.order]にあります）は、2つの数値のうち小さい方、または大きい方を返します。

```factor
3 7 min .       ! => 3
3 7 max .       ! => 7
```

最もよくある使い方は*クランプ*です。`max`で値の下限を、`min`で上限を固定します（たとえば`0 max`は値を負でない状態に保ちます）。

## 順序の述語

`math.order`には、比較用の述語である`before?`、`after?`、`before=?`、`after=?`も用意されています。これらは順序付けできるあらゆる型（数値、文字列、文字）で使えます。

```
before?  ( obj1 obj2 -- ? )   ! obj1 <  obj2
before=? ( obj1 obj2 -- ? )   ! obj1 <= obj2
after?   ( obj1 obj2 -- ? )   ! obj1 >  obj2
after=?  ( obj1 obj2 -- ? )   ! obj1 >= obj2
```

値が文字列かもしれないときは、`<`や`<=`の代わりにこれらを使いましょう。算術演算子は文字列には対応していないからです。
