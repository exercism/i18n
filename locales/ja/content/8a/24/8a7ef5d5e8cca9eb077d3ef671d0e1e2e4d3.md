# 説明

魔法の世界Echoesには、EchoSpeakと呼ばれる強力な呪文があります。
この呪文を使うと、魔法使いは自分の考えや観察したことを話し言葉で伝えることができ、それが魔法の羽根ペンによって書き出されます。
この呪文をマスターするには、魔法使いは、数値、オブジェクト、複雑な魔法の構造物などについてであっても、自分の言葉や考えを明確かつ簡潔に組み立てる方法を学ぶ必要があります。

Wizard's Apprenticeとして、EchoSpeakの技をマスターすることが課題です。
そのためには、さまざまな種類の魔法のデータを魔法の巻物に出力する方法を学ぶ必要があります。
EchoSpeakは、`ByteArray`で表される特別な魔法のインクを取り、`println!`や`print!`のような呪文を使って、フォーマットされたメッセージを巻物に書き記す仕組みです。

しかし、魔法のアイテムや呪文のようなカスタムの魔法の構造物を扱うときには、EchoSpeakがこれらのオブジェクトをどのように表現するかを理解するために、特別な詠唱が必要です。
ここで魔法の出番です。カスタムの魔法のアイテムのために`traits`と呼ばれる特別な呪文を実装することを学びます。

## 1. 魔法の言葉をフォーマットする

魔法使いはときどき、魔法の言葉を巻物に書き記す前にフォーマットする必要があります。
3つの魔法の言葉を1つのメッセージにフォーマットする関数を書きます。

`format_magical_chant`という関数を実装します。この関数は"chant1-chant2-chant3"という形式のフォーマット済み文字列を返します。

例：

```rust
let result = format_magical_chant("Spark", "Shine", "Glow");
assert_eq!(result, "Spark-Shine-Glow");
```

## 2. カスタムの魔法のアイテムをエコーする

Echoesの世界は魔法のアイテムで満ちています。
その1つがEchoStoneで、powerとdurationという2つの魔法の属性を持っています。
`stringify_echo_stone`関数を実装することが課題です。この関数は、`Display`トレイトを実装することで、EchoStoneを`"EchoStone [power: x, duration: y]"`という特別な形式の`ByteArray`に変換します。

例：

```rust
let stone = EchoStone { power: 100, duration: 300 };
assert_eq!(stringify(stone), "EchoStone [power: 100, duration: 300]");
```

## 3. 魔法をデバッグする

魔法使いの見習いとして、複雑な魔法の構造物を扱うにはデバッグが欠かせません。
`Debug`トレイトを使ってデバッグ用に`EchoStone`を出力する関数を作成します。
フォーマットは`"Debugging EchoStone: { power: x, duration: y }"`とします。

例：

```rust
let stone = EchoStone { power: 25, duration: 10 };
assert_eq!(format!("{:?}", stone), "Debugging EchoStone: { power: 25, duration: 10 }");
```
