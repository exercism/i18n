# はじめに

## 例外

Elixirのすべてのエラーは、_例外ビヘイビア_を実装しています。_アクセスビヘイビア_と同じように、_例外ビヘイビア_は、ビヘイビアというソフトウェア上の契約を満たすためにモジュールが実装しなければならないコールバック関数を定義します。エラーを定義すると、次のような性質を持つようになります：

- モジュール名がエラーの名前になります。
- モジュールがエラー構造体を定義します。
- 構造体には`:message`フィールドがあります。
- `raise/1`と`raise/2`でそのモジュールを使い、目的のエラーを発生させることができます。

_例外ビヘイビア_は、`message/1`と`exception/1`という2つのコールバックも指定します。実装しなかった場合は、デフォルトの実装が使われます。`message/1`は、`raise`から呼ばれると、エラー構造体を読みやすいメッセージに変換します。`exception/1`は、`raise/2`から呼ばれると、メッセージに追加の文脈を加えられるようにします。

### 例外を定義する

エラーモジュールから例外を定義するには、`defexception`マクロを使います：

```elixir
# Defines a minimal error, with the name `MyError`
defmodule MyError do
  defexception message: "error"
end

# Defines an error with a customized exception/1 function
defmodule MyCustomizedError do
  defexception message: "custom error"

  @impl true
  def exception(value) do
    case value do
      [] ->
        %MyCustomizedError{}

      _ ->
        %MyCustomizedError{message: "Alert: " <> value}
    end
  end
end
```

### 例外を使う

定義したエラーは、組み込みのエラーと同じように、`raise/1`または`raise/2`を使って発生させられます。

- `raise/1`は、モジュール名を指定して特定のエラーを発生させます。引数が文字列の場合は、その文字列をメッセージとする`RuntimeError`を発生させます。
- `raise/2`は、モジュール名を指定して特定のエラーを発生させます。属性の引数を受け取り、それを使って適切なメッセージを持つエラーを取得します。
