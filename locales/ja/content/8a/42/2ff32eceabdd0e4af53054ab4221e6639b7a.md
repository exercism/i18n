# テスト

各演習にはテストファイルが含まれています。
テストは`bats`プログラムで実行します。

```bash
bats hello_world.bats
```

ローカルでテストを実行するときにデバッグ出力を表示したい場合は、[ローカルでのデバッグ][debugging]を参照してください。

`bats`をインストールしておく必要があります。
お使いのシステムに`bats`をインストールする方法は、[Bashトラックのテスト][tests]ページを参照してください。

[tests]: https://exercism.org/docs/tracks/bash/tests
[debugging]: https://exercism.org/docs/tracks/bash/debugging

## `assert`関数のヘルプ

テストでは、[bats-assert][bats-assert]ライブラリの関数を使っています。
さまざまな`assert*`関数のヘルプは、そこで確認できます。

[bats-assert]: https://github.com/bats-core/bats-assert

## スキップされるテスト

演習を解くとは、そのテストをすべてパスさせることです。
デフォルトでは、テストを実行すると、1つのテスト（最初のテスト）だけが実行されます。
これは意図的なもので、まずはその1つのテストをパスさせることに集中できます。
それがパスしたら、次のアノテーションをコメントアウトするか削除すると、次のテストを有効にできます。

```bash
[[ $BATS_RUN_SKIPPED == true ]] || skip
```

## スキップを上書きする

`skip`アノテーションが付いたテストも含め、すべてのテストを実行するには、次のようにします。

```bash
BATS_RUN_SKIPPED=true bats exercise_name.bats
```

入力を減らすために、ラッパー関数を使うと便利です。

```bash
bats() {
    BATS_RUN_SKIPPED=true command bats *.bats
}
```

そうすれば、次のコマンドだけでテストを実行できます。

```bash
bats
```
