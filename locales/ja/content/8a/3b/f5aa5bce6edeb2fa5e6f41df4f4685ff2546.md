# ExercismのRustトラックでは、何が対象外ですか？

このファイルは、ExercismのRustトラックが、Rustという言語、コミュニティ、エコシステムの枠内で、何を教えることができ、何を教えることができないのかを説明するためのものです。

特定の演習について、_design.md_の「Out of scope」で扱われている内容は、その話題がほかに十分な注目を得られていないと感じられる場合を除いて、ここで繰り返すべきではありません。

## Web UIの限界

Web UIを使う学習者は、Webインターフェースとテストランナーで許可されていることしかできません。そのため、Web UIでできることが、事実上Rustトラックの外側の限界になります。

学習者にできることは次のとおりです。

- 1つの`.rs`ファイルを編集できます
- `stdout`からの出力（たとえば`dbg!`の出力）を受け取れます

特に、これはCargo.tomlを編集できないことを意味するので、外部クレートに依存する演習は、必要な依存関係をすべてCargo.tomlにあらかじめ含めておく必要があります。

## Exercismが目指すものではないこと

Exercismは、プログラミング言語を使いこなせるようになるための場であり、ソフトウェア設計やコンピューターサイエンスのような、より抽象的なスキルを教える場ではありません。ですから、Rustというプログラミング言語にあまり関係しない話題は、Rustトラックの対象外です。

## 対象外の話題の例

対象外となる話題には、たとえば次のようなものがあります。

### Cargo

- Cargo.tomlの編集
- CLIコマンド（`new`・`update`・`bench`など）

### フレームワーク

- Amethyst
- Yew・Iced・Sauronなど

### 相互運用

- CFFI
- `asm!`

### 一般的なもの

- ファイル操作
- ネットワーク
