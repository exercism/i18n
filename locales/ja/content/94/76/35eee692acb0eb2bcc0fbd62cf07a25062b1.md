# 説明

サンタクロースの物流部門で働くエルフは、上司からシステムのソフトウェアをアップグレードするための2つの仕事を任されました。

## 1. おもちゃの名前を取得する

システムは、データベースからおもちゃの名前を取得できる必要があります。
データベースは、`(name: String, quantity: Int)`型のタプルでできています。

タプル`(name: String, quantity: Int)`を受け取る関数`getName(_:)`を実装しましょう。

```swift
let toy = (name: "Doll", quantity: 10)
getName(toy)
// Returns "Doll"
```

## 2. データベースに新しいおもちゃを追加する

おもちゃの市場は移り変わりが早く、人気の商品もめまぐるしく変わります。
そのため、新しいおもちゃを作成する関数が必要です。

おもちゃの名前を持つ引数`name`と、おもちゃの数量を持つ引数`amount`を受け取る関数`createToy(name:amount:)`を実装しましょう。

```swift
createToy(name: "Doll", amount: 10)
// Returns (name: "Doll", amount: 10)
```

## 3. おもちゃの数量を更新する

サンタの工房のエルフたちは絶えずおもちゃを作り続けているので、サンタはおもちゃごとの数量を把握しておく必要があります。
そのために、システムはデータベース内のおもちゃの数量を更新できる必要があります。

次の引数を受け取る関数`updateQuantity(_:toy:Amount:)`を実装しましょう。
- `toys`は、タプル`(name: String, quantity: Int)`の配列を持ちます。
- `toy`は、更新するおもちゃの名前を持ちます。
- `amount`は、おもちゃの新しい数量を持ちます。

おもちゃはすでにデータベースにあると想定してよく、その確認は必要ありません。

```swift
let toys = [(name: "Doll", quantity: 10), (name: "Car", quantity: 5), (name: "Train", quantity: 3)]
updateQuantity(toys, toy: "Doll", amount: 15)
// Returns [(name: "Doll", quantity: 15), (name: "Car", quantity: 5), (name: "Train", quantity: 3)]
```

## 4. おもちゃにカテゴリーキーを追加する

サンタは、データベース内のおもちゃを分類できるようにしたいと考えています。
こうすると、配達が必要なときに目的のおもちゃをすぐ見つけられ、データベース内のおもちゃを並べ替えることもできます。

しかし、システムを最初に実装したとき、カテゴリーキーは忘れられていました。
そこで今度は、システムがデータベース内のおもちゃにカテゴリーキーを追加できる必要があります。

次の引数を受け取る関数`addCategory(_:category:)`を実装しましょう。
- `toys`は、タプル`(name: String, quantity: Int)`の配列を持ちます。
- `category`は、おもちゃに追加するカテゴリーキーを持ちます。

おもちゃはすでにデータベースにあると想定してよく、その確認は必要ありません。
また、おもちゃにカテゴリーキーがまだないことも想定してかまいません。

```swift
let toys = [(name: "Car", quantity: 5), (name: "Train", quantity: 3)]
addCategory(toys, category: "Vehicle")
// Returns [(name: "Car", quantity: 5, category: "Vehicle"), (name: "Train", quantity: 3, category: "Vehicle")]
```
