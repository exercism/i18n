# はじめに

Cairoでは、真偽値はあらかじめ用意されている真偽値型`bool`で表します。`bool`がとる値は、`true`か`false`のどちらかです。

```rust
let speeding = true;   // Boolean variable 'speeding' set to 'true'
let has_error = false; // Boolean variable 'has_error' set to 'false' 
```

Cairoには、式を真偽値に評価して`true`か`false`を返す論理演算子が3つあります。

| 演算子      | 意味                                          |
| ----------- | --------------------------------------------- |
| `&&`（論理積）  | 両方の命題が真であれば、真になります。       |
| `\|\|`（論理和） | 少なくとも一方の命題が真であれば、真になります。 |
| `!`（否定）   | 命題が偽のときだけ、真になります。    |
