# はじめに

Pythonの`str`は、[Unicodeコードポイント][unicode code points]の[イミュータブルなシーケンス][text sequence]です。
これらには、文字、ダイアクリティカルマーク、位置指定文字、数字、通貨記号、絵文字、句読点、さまざまな空白、改行などが含まれます。

文字列は[共通のシーケンス演算][common sequence operations]をすべて実装しており、`for item in <str>`や`for index, item in enumerate(<str>)`という構文で繰り返し処理できます。
`<str> + <other str>`や`<str>.join(<iterable>)`で連結したり、`<str>.split(<separator>)`で分割したりでき、さらにさまざまな書式設定や組み立てのオプションも用意されています。

文字列をさらに扱うために、Pythonには、検索、クリーニング、変換、翻訳など、さまざまな操作に役立つ豊富な[文字列メソッド][str-methods]がそろっています。

`str`オブジェクトは_イミュータブル_なので、メモリ上にあるその値が変わることはありません。文字列を変更しているように見えるメソッドは、その`str`オブジェクトの新しいコピー、つまり新しいインスタンスを返します。
