# データベースの高額経費

## 問題

ABC Corpは、指定した金額（例：`3000.00`）を超える支払いエントリを持つ従業員の名前と部署を探す必要があります。

必要なデータを返すために、`HighPayment`という名前のレコードを作成します。レコードの定義は次のとおりです。

```ballerina
type HighPayment record {
    string name;
    string department;
    decimal amount;
    string reason;
};
```

データベースから必要なデータを取得するには、JDBCクライアントの`query`操作を使います。

> 注意：結果は`payment_id`の昇順で並べ替えます。

## データベースの詳細

この問題では、用意されたH2データベースを使います。

> サンプルデータベースのファイルは`gofigure.mv.db`で、データベース名は`gofigure`です。`db`フォルダーの中に用意されています。

サンプルのH2データベースには、次のテーブルがいくつかのサンプルデータとともに入っています。列名とデータ型は次のとおりです。

**テーブル名**：`Employee`

| **列：**      | 型 |
| -----------       | ----------- |
| `employee_id`     | 整数、自動インクリメントの主キー       |
| `name`            | 文字列        |
| `city`            | 文字列        |
| `department`      | 文字列        |
| `age`             | 整数        |

**テーブル名**：`Payment`

| **列：**      | 型 |
| -----------       | ----------- |
| `payment_id`      | 整数、自動インクリメントの主キー       |
| `date`            | 日付        |
| `amount`          | 小数        |
| `employee_id`     | 整数        |
| `reason`          | 文字列        |

* データベースファイルは`gofigure.mv.db`です。JDBC URLは`jdbc:h2:file:/path/to/db/file`のように指定します
* ユーザー名：`root`
* パスワード：`root`

## 制約

* `db`フォルダーに用意されたH2データベースファイルを使って、クエリとBallerinaのサンプルを検証します
* `Ballerina.toml`でH2データベースドライバーをプラットフォーム依存関係として追加するには、Mavenの依存関係パラメータを使う方法を使います

## テスト環境

* テストは`bal test`で実行でき、用意されたサンプルDBに対して実行されます。

## 例

### 例1

**入力：** dbFilePath : `“/Path/to/file/gofigure”`, amount : `3000`

**出力：** `[{"name":"Anita Bath","department":"Marketing", "amount":3400, "reason": "Stationary"}, {"name":"Amanda Hug","department":"Engineering", "amount":4400, "reason": "Travel expenses"}]`

## ヒント

* データベースを操作するには、[ballerinax/java.jdbc](https://central.ballerina.io/ballerinax/java.jdbc)モジュールを使います
* JDBCドライバーを依存関係として追加する手順については、[前提条件](https://lib.ballerina.io/ballerinax/java.jdbc/latest)のセクションを参照してください
* DBからデータをクエリするには、[query](https://lib.ballerina.io/ballerinax/java.jdbc/latest#Client-query)リモートメソッドを使います
* [シンプルなクエリ](https://ballerina.io/learn/by-example/mysql-query-operation)の例を参照してください
* データにアクセスするには、Ballerinaの[stream](https://ballerina.io/learn/by-example/stream-type)型を使います
* DBから必要なデータセットを見つけるには、SQLの結合を使います
