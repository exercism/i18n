# 指示

Elenaは、新聞工場の新しい品質管理責任者です。
入社したばかりのElenaは、工場の工程をいくつか見直し、改善できるところがないか確認することにしました。

調べてみると、技術者たちが多くの品質チェックを手作業で行っていることがわかりました。

自動化のよい機会だと気づいたElenaは、フリーランスのエンジニアに、いくつかの機械を監視するソフトウェアの開発を依頼しました。

## 1. 部屋の湿度レベルを監視する

最初のミッションは、生産室の湿度レベルを監視するソフトウェアを書くことです。
すでに、会社のソフトウェアに接続されたセンサーがあり、部屋の湿度のパーセンテージを定期的に返します。

湿度のパーセンテージが高すぎる場合にエラーを投げる関数を、ソフトウェアに実装する必要があります。
関数名は`check_humidity_level`とし、湿度のパーセンテージを入力として受け取ります。

パーセンテージが70%を超える場合は、エラーで停止してください（メッセージの内容は重要ではありません）。
そうでなければ、"humidity test passed"を含むメッセージを出し、測定が正常であることを示す`TRUE`を返します。

```R
check_humidity_level(60)
#> humidity test passed
#> [1] TRUE

check_humidity_level(100)
#> Error in check_humidity_level(100) : pct_humidity <= 70 is not TRUE
```

## 2. 過熱を検知する

Elenaは最初の仕事にとても満足し、今度は機械の温度の監視を任せてほしいと依頼してきます。
技術者のGregと雑談していると、機械の温度が500°Cを超えると、技術者たちは過熱を心配し始めるのだと教えてくれます。

その機械には、内部の温度を測るセンサーが取り付けられています。
このセンサーはとても繊細で、よく壊れてしまうことを知っておいてください。
その場合は、技術者が交換する必要があります。

ここでの仕事は、温度を入力として受け取り、センサーが壊れている場合や機械が過熱し始めた場合にエラーを投げる関数`report_overheating`を実装することです。

あとでエラーの種類に応じて異なる対応をする必要があるため、2種類のエラーを区別する仕組みが要ります。

- センサーが壊れている場合、温度は`NULL`になります。
  この場合は、"Sensor Broken"を文字列に含むエラーメッセージを出して停止してください。
- センサーが正常に動いているとき、温度が600°Cを超える場合は、温度を含むメッセージを出して停止してください。
- 温度が500°Cを超えているが600°Cを超えていない場合は、温度を含む警告を出し、`FALSE`を返します。
- それ以外はすべて正常なので、`"temperature check passed: t °C"`というメッセージを出し、`TRUE`を返します。ここで`t`は温度です。

```R
report_overheating(NULL)
#> Error in report_overheating(NULL) : Sensor Broken

report_overheating(800)
#> Error in report_overheating(800) : Overheating: 800 C

report_overheating(550)
#> [1] FALSE
#> Warning message:
#> In report_overheating(550) : Risk of overheating: 550 C

report_overheating(450)
#> temperature check passed: 450 °C
#> [1] TRUE
```


## 3. 機械を監視する

機械がエラーを検知できるようになり、独自の機械エラーもできたところで、全体がどう動いているかを報告するラッパー関数を追加します。
前の関数からのログを返すだけでなく、このラッパーは、発生した障害の種類に応じてログを追加する必要もあります。

- 湿度と温度をチェックします。
- 問題があれば、`check_humidity_level()`と`report_overheating()`にそのままログを出力させます。
- すべて正常なら、"All OK"を含むメッセージを追加します。

湿度と温度を入力として受け取る関数`monitor_the_machine()`を実装してください。

```R
# Working well
monitor_the_machine(53, 200)
#> humidity test passed
#> temperature check passed: 200 °C
#> All OK!

# High humidity
monitor_the_machine(90, 200)
#> Error in check_humidity_level(pct_humidity) : 
#>   pct_humidity <= 70 is not TRUE

# Faulty sensor
monitor_the_machine(53, NULL)
#> humidity test passed
#> Error in report_overheating(temperature) : Sensor Broken

# Mild overheating
monitor_the_machine(53, 550)
#> humidity test passed
#> Warning message:
#> In report_overheating(temperature) : Risk of overheating: 550 C

# Dangerous overheating: shutdown
monitor_the_machine(53, 650)
#> humidity test passed
#> Error in report_overheating(temperature) : Overheating: 650 C
```
