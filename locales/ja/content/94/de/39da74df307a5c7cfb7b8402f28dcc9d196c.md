# 説明

この演習では、友人が開発している新しいRPGゲームのクエストロジックを実装します。

ゲームの主人公はアナリン。勇敢な女の子で、勇敢で忠実な愛犬を連れています。ところが不幸にも、森でベリーを探していた親友が誘拐されてしまいます。

アナリンは親友を見つけて助け出そうとします。このクエストに犬を連れていくかどうかは自由です。

親友の足跡をしばらくたどった末に、親友が囚われている野営地を見つけます。誘拐犯は2人いました。強力な騎士と、ずる賢い弓使いです。

誘拐犯を見つけたアナリンは、次のうちどの行動を取れるかを考えます。

- _速攻_: 騎士が眠っていれば速攻できます。鎧を身に着けるのに時間がかかるため、騎士は無防備になります。
- _スパイ_: 少なくとも1人が起きていれば、集団をスパイできます。そうでなければ、スパイは時間の無駄です。
- _囚人への合図_: 囚人が起きていて弓使いが眠っていれば、鳥のさえずりで囚人に合図できます。弓使いは鳥の合図の訓練を受けているので、メッセージを傍受できてしまうからです。
- _囚人の解放_: アナリンは野営地に忍び込んで囚人を解放しようとします。
  これは危険な作戦で、成功するのは次の2つの場合だけです。
  - アナリンが愛犬を連れている場合、弓使いが眠っていれば囚人を救出できます。
    騎士は犬を怖がり、弓使いが準備する暇もなく、アナリンと囚人は逃げ出せます。
  - アナリンが犬を連れていない場合は、アナリンと囚人はとても慎重に動かなければなりません！
    囚人が起きていて、騎士と弓使いがどちらも眠っていれば、アナリンは囚人を解放できます。しかし囚人が眠っていると救出できません。囚人はアナリンの突然の登場に驚いて、騎士と弓使いを起こしてしまうからです。

この演習のタスクは4つです。森で見つけた3人の状態と、アナリンの愛犬がいるかどうかに基づいて、上記の行動が可能かどうかを判定するロジックを実装しましょう。

## 1. 速攻できるかを確認する

`canFastAttack()`メソッドを実装します。このメソッドは、騎士が起きているかどうかを示す真偽値を受け取ります。騎士の状態に基づいて速攻できる場合、このメソッドは`true`を返します。そうでなければ`false`を返します。

```haxe
var knightIsAwake = true;
canFastAttack(knightIsAwake);
// => false
```

## 2. 集団をスパイできるかを確認する

`canSpy()`メソッドを実装します。このメソッドは3つの真偽値を受け取り、それぞれ騎士、弓使い、囚人が起きているかどうかを示します。この3人の状態に基づいて集団をスパイできる場合、メソッドは`true`を返します。そうでなければ`false`を返します。

```haxe
var knightIsAwake = false;
var archerIsAwake = true;
var prisonerIsAwake = false;
canSpy(knightIsAwake, archerIsAwake, prisonerIsAwake);
// => true
```

## 3. 囚人に合図できるかを確認する

`canSignalPrisoner()`メソッドを実装します。このメソッドは2つの真偽値を受け取り、それぞれ弓使いと囚人が起きているかどうかを示します。この2人の状態に基づいて囚人に合図できる場合、メソッドは`true`を返します。そうでなければ`false`を返します。

```haxe
var archerIsAwake = false;
var prisonerIsAwake = true;
canSignalPrisoner(archerIsAwake, prisonerIsAwake);
// => true
```

## 4. 囚人を解放できるかを確認する

`canFreePrisoner()`メソッドを実装します。このメソッドは4つの真偽値を受け取ります。最初の3つの仮引数は、それぞれ騎士、弓使い、囚人が起きているかどうかを示します。最後の仮引数は、アナリンの愛犬がいるかどうかを示します。3人の状態とアナリンの愛犬の有無に基づいて囚人を解放できる場合、メソッドは`true`を返します。そうでなければ`false`を返します。

```haxe
var knightIsAwake = false;
var archerIsAwake = true;
var prisonerIsAwake = false;
var petDogIsPresent = false;
canFreePrisoner(knightIsAwake, archerIsAwake, prisonerIsAwake, petDogIsPresent);
// => false
```
