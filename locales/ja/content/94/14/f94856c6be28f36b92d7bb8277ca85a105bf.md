# はじめに

## `for`ループ

`for`文は、コードのブロックを繰り返し実行します。その最初の行で、ブロックを何回繰り返すかを制御します。

```go
for init; condition; post {
    // loop body
}
```

- **init**文は、最初の繰り返しの前に一度だけ実行されます。ループで使うカウンター変数を宣言して初期化するのが一般的です。
- **condition**は、各繰り返しの前に評価される真偽値の式です。これが`false`と評価されると、ループは止まります。
- **post**文は、繰り返しが1回終わるたびに実行されます。カウンターの更新に使えます。

`init; condition; post`を括弧（`()`）で囲まないでください。ただし、ループ本体を囲む波括弧は常に必要です。

このループは、`i`を`1`から始め、現在の`i`の値を出力し、次の繰り返しに向けて値を増やし、`i`が`10`に達すると止まります。

```go
for i := 1; i < 10; i++ {
    fmt.Println(i)
}
```
