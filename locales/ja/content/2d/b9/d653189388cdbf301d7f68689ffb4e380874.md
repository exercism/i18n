# 概要

`|>`演算子は、[パイプ演算子][pipe]と呼ばれます。関数呼び出しをつなげて、前の関数呼び出しが返した戻り値を、次の関数呼び出しの最初の引数として渡せるようにするものです。

```elixir
String.replace_suffix(String.upcase(String.duplicate("go ", 3)), " ", "!")

# versus

"go "
|> String.duplicate(3)
|> String.upcase()
|> String.replace_suffix(" ", "!")
```

1行で書くこともできます。

```elixir
"go " |> String.duplicate(3) |> String.upcase() |> String.replace_suffix(" ", "!")
```

`Kernel`の関数は、ふだんは`Kernel`というモジュール名を付けずにどこでも使いますが、パイプの連鎖の中でこれらの関数を使うときは、モジュール名が必要です。たとえば、`2 * 3 == 6`は次のようにも書けます。

```elixir
2 |> Kernel.*(3) |> Kernel.==(6)
```

パイプ演算子をいつ使うか、いつ使わないかは、好みの問題です。Elixirのエンジニアの中には、次のようなルールに従うことを好む人もいます。

- 関数を1つだけ呼び出すときは、パイプ演算子を使いません。

  ```elixir
  # do
  String.split("hello", "")

  # don't
  "hello" |> String.split("")
  ```

- パイプの連鎖の中で、無名関数を直接作りません。

  ```elixir
  # do
  take_n_letters = fn n -> Enum.take(?a..?z, n) end
  2 |> Kernel.*(3) |> take_n_letters.()

  # don't
  2 |> Kernel.*(3) |> (fn n -> Enum.take(?a..?z, n) end).()
  ```

- パイプの連鎖は、関数呼び出しではなく、必ず変数かリテラルの値から始めます。

  ```elixir
  # do
  "hello" |> String.upcase() |> String.split("")

  # don't
  String.upcase("hello") |> String.split("")
  ```
