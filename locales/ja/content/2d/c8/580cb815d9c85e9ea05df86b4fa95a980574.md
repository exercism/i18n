# 基本について

Kotlinは静的型付け言語で、Javaとの完全な相互運用を目指して設計されています。

Javaと異なるのは、次の点です。

- よりすっきりと簡潔な構文
- 関数型言語の機能を数多く取り入れた設計
- nullを許容する値への手厚いサポート

## 変数

Kotlinは静的型付けなので、コンパイル時にそれぞれの値の型を_把握_しておく必要があります。

ただし、Kotlinの[型推論][inference]は非常に強力なので、型を_明示する_ことは多くの場合省略できます。

変数を宣言する方法は2つあります。

1. `val`は不変の変数を作ります。値を変更しようとするとコンパイルエラーになります。

```kotlin
val x = 42  // => 42
x = 43      // => 'val' cannot be reasssigned
```

2. `var`は可変の変数を作ります。

```Kotlin
var x = 42  // => 42
x = 43      // => 43
```

不変の変数はよくある種類のバグを取り除いてくれるので、できるだけ`val`を使うことが推奨されます。

また、`var`でも型を変えることはできません。

```kotlin
var x = 42
x = "foobar" // => Type mismatch: inferred type is String but Int was expected
```

見た目の煩雑さを減らすため、このシラバスでは型の明示はほとんど省略します。
それでも、少なくとも次の場合は型を明示することが推奨されます。

- 公開API
- 関数のシグネチャ
- ドキュメントが必要な箇所

企業や組織によっては、厳密な型安全性を求めて型推論を禁止しているところもあれば、"単純な"型にだけ型推論を制限しているところ、型推論を全面的に受け入れているところもあります。

```kotlin
val x: Int = 42  // => 42
```

一般に、変数や関数の名前は`snake_case`ではなく`camelCase`にします。

## 関数

関数は`fun`キーワードで宣言します。
Javaと違い、関数はクラスの一部である必要はありません。

```Kotlin
fun hello(): String {
    return "Hello, World!"
}

fun add(x: Int, y: Int): Int {
    return x + y
}
```

いくつか注意すべき点があります。

- 関数名のあとには、仮引数がない関数でも括弧（`()`）が必要です。
- 仮引数には型を指定する必要があります。変数と違い、型推論は働きません。
- 関数の本体は波括弧（`{ }`）で囲みます（ただし、後述の例外があります）。
- 値を返す場合は、`return`キーワードが必要です。
- 行末のセミコロン（`;`）は省略可能で、通常は省略します。
- 算術演算子の`+`、`-`、`*`、`/`は、ほとんどの主要な言語と似ています。

ただし、こうしたごく単純な"単一式"の関数には、省略した書き方があります。

```Kotlin
// return type is usually omitted for single-expression functions
fun add(x: Int, y: Int) = x + y  
```
関数の仮引数には、デフォルト値を設定できます。
関数を呼び出すときにその値を省略すると、デフォルト値が使われます。

```kotlin
fun ping(host: String = "localhost") {
    println("PING --> $host")
}

ping("exercism.io")  // PING --> exercism.io
ping()               // PING --> localhost
```

Exercismの関数は、たいてい値を返します（テストランナーの仕組みがそうなっているためです）。
Kotlinをもっと広く使いこなすには、値を返さない関数では戻り値の型と`return`キーワードを省略できることを知っておくと役立ちます。

そのような関数は`Unit`型を返すと言います。Javaやほかのいくつかの言語の`void`に相当します。

## コメント

1行コメントは`//`で始まり、その行の残りは無視されます。

複数行コメントは`/*`で始まり、`*/`で終わります。

```Kotlin
fun hello(): String {
    /*
     * Failing to run this program on a new installation 
     * is considered bad luck
    */
    return "Hello, World!" // the compiler pixies are now happy
}
```

これはJavaと同じです。
