# 説明

鳥の調査を手伝ってもらいます。毎日、誰かが観察小屋に座って、飛んでいく鳥を数えます。その日の数え上げは配列として返ってきます。

5つのタスクはすべて`BIRD_SURVEY`クラスに書きます。

## 1. 合計

毎日の数を足し合わせます。

```sather
BIRD_SURVEY::total_seen(|3, 0, 7|)
-- => 10
```

1日もない調査では、鳥は0羽です。

## 2. 一番多かった日

最も多い数を返します。1日もなければ、答えは0です。

```sather
BIRD_SURVEY::busiest_day(|3, 0, 7|)
-- => 7
```

## 3. 数が多かった日

ある数を超えた日は何日あったでしょうか？

```sather
BIRD_SURVEY::days_over(|3, 0, 7|, 2)
-- => 2
```

超えるとは、本当に超えるということです。ちょうど2の数は含みません。

## 4. 確認する観察小屋

調査の1日目は観察小屋を1か所、2日目は2か所、というように確認します。これを全部合わせると、観察小屋の確認は何回になるでしょうか？

```sather
BIRD_SURVEY::hides_to_check(4)
-- => 10
```

つまり、1 + 2 + 3 + 4です。

## 5. 最初の数が多かった日

ある数を超えた最初の日は何日目でしょうか？　日は、配列の位置と同じように0から数えます。それほど多くなかった場合は、答えは`-1`です。

```sather
BIRD_SURVEY::first_busy_day(|3, 0, 7|, 5)
-- => 2
BIRD_SURVEY::first_busy_day(|3, 0, 7|, 9)
-- => -1
```
