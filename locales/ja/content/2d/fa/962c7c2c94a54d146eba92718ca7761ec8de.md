# 名前付きエクスポートがありません

[`export %{export.name}`](https://developer.mozilla.org/en-US/docs/Web/JavaScript/Reference/Statements/export)が見つかりませんでした。これがないと、テストに合格できません。

`%{export.name}`が存在することを確認して、その前に`export`を付けてください：
```javascript
// exporting a "const"
export const %{export.name} = /*...*/

// exporting a named function declaration
export function %{export.name}() { /* ... */ }
```
