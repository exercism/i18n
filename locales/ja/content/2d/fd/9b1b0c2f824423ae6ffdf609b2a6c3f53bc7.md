# 説明

低消費電力の組み込みシステムを対象としたゲームに取り組んでいます。ここでは、ゲームの他の部分から使われる便利な関数をいくつか書く必要があります。

## 1. 割り算の商と余りを計算する

商とは、割り算の結果のことです。

```rust
fn divmod(dividend: i16, divisor: i16) -> (i16, i16)
```

例：

```rust
assert_eq!(divmod(10, 3), (3, 1));
```

## 2. イテレーターから偶数番目の要素を選ぶ

上司の話では、これは画面バッファの最適化に役立つそうです。

イテレーターとは、[`Iterator`トレイト](https://doc.rust-lang.org/std/iter/trait.Iterator.html)で定義されたメソッドを備えたものです。このドキュメントがかなり充実しているのは、多くのメソッドが用意されているからです。ここでは、特に関係の深い性質を挙げます。

- イテレーターは、任意の長さの要素のストリームです
- 各値に対してタプル`(i, val)`を返す[`enumerate`メソッド](https://doc.rust-lang.org/std/iter/trait.Iterator.html#method.enumerate)があります
- クロージャーを使って、イテレーターの要素を返すかどうかを決める[`filter`メソッド](https://doc.rust-lang.org/std/iter/trait.Iterator.html#method.filter)があります
- クロージャーを使って、イテレーターの要素を変換する[`map`メソッド](https://doc.rust-lang.org/std/iter/trait.Iterator.html#method.map)があります

この関数はどんな種類のイテレーターでも動作するので、単なる要素ではなくトレイトのインスタンスであることを示すために`impl`を使います。同様に、`<Item=T>`という構文は、イテレーターが生み出す要素の種類が何であっても構わない、という意味にすぎません。この関数は、どんなイテレーターの偶数番目の要素でも取り出すことができます。

```rust
fn evens<T>(iter: impl Iterator<Item=T>) -> impl Iterator<Item=T>
```

例：

```rust
let mut even_ints = evens(0_u8..);
assert_eq!(even_ints.next(), Some(0));
assert_eq!(even_ints.next(), Some(2));
assert_eq!(even_ints.next(), Some(4));
assert_eq!(even_ints.next(), Some(6));
```

```rust
let mut evens_from_odds = evens(1_i16..);
assert_eq!(evens_from_odds.next(), Some(1));
assert_eq!(evens_from_odds.next(), Some(3));
assert_eq!(evens_from_odds.next(), Some(5));
assert_eq!(evens_from_odds.next(), Some(7));
```

## 3. 原点から見た位置のマンハッタン距離を計算する

マッピングを便利にするために、タプル構造体`Position`が用意されています。

```rust
struct Position(i16, i16);
```

`Position`に、原点（`Position(0, 0)`）からのその位置の[マンハッタン距離](https://en.wikipedia.org/wiki/Taxicab_geometry)を返すメソッド`manhattan`を実装する必要があります。

```rust
impl Position {
    fn manhattan(&self) -> i16
}
```

例：

```rust
assert_eq!(Position(3, 4).manhattan(), 7);
```
