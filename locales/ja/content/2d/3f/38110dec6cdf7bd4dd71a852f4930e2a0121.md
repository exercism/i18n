# 概要

Swiftには、ループや`switch`文の実行フローを変えるための制御転送文があります。`return`に加えて、`continue`、`break`、ループラベル、`fallthrough`があります。

## `continue`

`continue`文は、ループに対して現在の繰り返しの実行を止め、すぐに次の繰り返しを始めるよう指示します。`while`ループや`repeat-while`ループでは、条件のチェックへ直接移動します。`for-in`ループでは、シーケンスの次の要素へ進みます。

```swift
var count = 1
while count < 6 {
    count += 1
    if count == 4 {
        continue
    }
    print(count)
}

// Prints:
// 2
// 3
// 5
// 6
```

## `break`

`break`文は、ループ全体または`switch`文をすぐに終了します。実行は、ループまたは`switch`の直後のコードの最初の行から再開します。

```swift
for fruit in ["banana", "grapes", "apple", "strawberry", "kiwi", "lemon"] {
    if !fruit.count.isMultiple(of: 2) {
        break
    }
    print(fruit)
}

// Prints:
// banana
// grapes
```

## ラベル付き文

入れ子のループでは、`break`や`continue`を、最も内側のループではなく外側のループに作用させたいことがあります。ループの前に名前とコロン（`labelName:`）を付けると、そのループにラベルを付けられます。その後、そのラベルを`break`や`continue`に渡せます。

```swift
outerLoop: for fruit in ["banana", "grapes", "apple", "strawberry", "kiwi", "lemon"] {
    print("\n--- \(fruit) ---")
    for letter in fruit {
        guard letter != "n" else {
            break outerLoop
        }
        print(letter)
    }
}

// Prints:
// --- banana ---
// b
// a
```

## `fallthrough`

Swiftでは、`switch`文はデフォルトでは次のケースにフォールスルーしません。実行は、一致したケースの末尾で自動的に止まります。パターンを評価せずに次のケースへ実行を続けたい場合は、`fallthrough`キーワードを使います。

```swift
let value = 1
switch value {
case 1:
    print("One")
    fallthrough
case 2:
    print("Two")
default:
    break
}

// Prints:
// One
// Two
```
