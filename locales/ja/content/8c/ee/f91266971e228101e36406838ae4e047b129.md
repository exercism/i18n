## 基礎2

### 関数をエクスポートする

関数のエクスポートは最初のコンセプトで扱いました。ここで簡単におさらいしておきましょう。

Elmの各ファイルはモジュールであり、他のどのコードよりも先に`module`文を書かなければなりません。

モジュール名はファイル名と一致していなければなりません。つまり、モジュール`Calculator`はファイルCalculator.elmに、モジュール`Parser.Utils`はファイルParser/Utils.elmに置く必要があります。

モジュール内で定義したものは、`exposing`に挙げない限り、そのモジュールの中だけに閉じていて、外からアクセスすることはできません。

```elm
-- Calculator.elm
-- Define the Calculator module, and expose the `add` function
module Calculator exposing (add)

six = 3 + 3

add number1 number2 = number1 + number2
```

```elm
-- Calculator.elm
-- Define the Calculator module, and expose everything within: `six` and `add`
module Calculator exposing (..)

six = 3 + 3

add number1 number2 = number1 + number2
```

https://elm-lang.org/docs/syntax#modules

### 他のモジュールから関数をインポートする

他のモジュールで定義された関数にアクセスするには、インポートを使います。
そのモジュールをインポートすると、そこで公開されている関数はすべてアクセスできるようになります。
ただし、アクセスのしかたはモジュールのインポートのしかたによって変わります。

デフォルトは修飾インポートで、このようにインポートしたモジュールの関数（たとえば`List`モジュールの`map`関数）にアクセスするときは、モジュール名を前に付けます（`List.map`）。

オープンインポートを使うと、そのモジュールで公開されている関数に、接頭辞なしで直接アクセスできます。これは`exposing`キーワードで行い、エクスポートで使うものとちょうど対になります。利用できる関数をすべて公開することも（`..`）、特定の関数だけを公開することもできます（たとえば`map`）。

他のモジュールから型やそのコンストラクターをインポートすることもできますが、これは後のコンセプトで扱います。

名前の衝突を避けて読みやすくするために、修飾インポートが好まれます。

```elm
-- qualified imports
import List                            -- List.map, List.foldl
import List as L                       -- L.map, L.foldl

-- open imports
import List exposing (..)              -- map, foldl, concat, ...
import List exposing ( map, foldl )    -- map, foldl, List.concat
```

https://elm-lang.org/docs/syntax#modules

### 型注釈

型注釈は`name : parameter types -> return type`のように定義し、引数の型も`->`で区切ります。

```elm
add : Int -> Int -> Int
add number1 number2 = number1 + number2
```

関数の引数を定義するときは、括弧（`()`）を使うこともできます（引数自身も同じ構文で定義するため、括弧が必要になるからです）。

```elm
-- Transform every character in a string
map : (Char -> Char) -> String -> String
map charMapperFunction string =
    -- ...
```

https://elm-lang.org/docs/syntax#type-annotations

### 数値

Elmで使える数値には2つの型があり、`Int`型と`Float`型で定義されています。
`Int`は正と負の整数の集合に対応します。
`Float`は実数の集合に対応し、コンピューターの精度によって制限されます。
数値に対して定義された演算は、ふつうどちらか一方の型でしか使えず、両者を混ぜることはできません。
2つの型の間で変換する関数も用意されています。たとえば`toFloat`は`Int`を`Float`に変換し、`round`、`floor`、`ceiling`、`truncate`はそれぞれ異なる意味で`Float`を`Int`に変換します。

https://package.elm-lang.org/packages/elm/core/latest/Basics#Int

### 文字列の操作

コードで単語や文を表すために、Elmにはネイティブの`String`型があります。
文字列リテラルは、`"Hello World!"`のように二重引用符で囲んで書きます。
文字列の連結演算子`++`と等価演算子`==`は標準で使えます。

```elm
hello : String -> String
hello subject = "Hello " ++ subject

hello "World!" --> "Hello World!"
```

その他の文字列関数のほとんどは`String`モジュールにあり、インポートが必要です。

https://package.elm-lang.org/packages/elm/core/latest/String
