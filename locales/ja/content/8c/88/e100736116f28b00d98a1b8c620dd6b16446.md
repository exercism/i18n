# 指示

Raspberry Piを使って何かを作ろうとしているなら、おそらく_抵抗器_を使うでしょう。
この演習では、抵抗器について2つのことを知っておく必要があります。

- 抵抗器にはそれぞれ抵抗値があります。
- 抵抗器はとても小さく、抵抗値を印刷したとしても読み取るのが難しいほどです。

この問題を回避するために、メーカーは抵抗器に色分けされたバンドを印刷して、抵抗値を示しています。
各バンドには位置と数値が割り当てられています。

抵抗器の最初の2本のバンドには、単純な符号化の仕組みがあります。それぞれの色が1つの数値に対応します。

3本目のバンドは乗数です。

この演習では、バンドの値を覚えなくて済むように、便利なプログラムを作ります。

抵抗器のカラーコードについての詳しい情報は、[Wikipediaの「電子カラーコード」の記事][e-color-code]にあります。

## 1. 名前付きベクトルを定義する

色は次のように符号化されています。

- black: 0
- brown: 1
- red: 2
- orange: 3
- yellow: 4
- green: 5
- blue: 6
- violet: 7
- grey: 8
- white: 9

色を名前、数値を値とする名前付きベクトル`resistor_bands`を作成してください。

## 2. バンドに対応する値を返す

まずは、どの色のバンドについても、対応する値を1つ見つけられるようにしましょう。

バンドの色を表す`string`を受け取る関数`band_value(band)`を定義してください。
この関数は、その色に対応する値を返します。

```R
band_value("green")
# => [1] 5

band_value("violet")
# => [1] 7
```

## 3. 2本のバンドに対応する値を返す

抵抗器の最初の2本のバンドは、組み合わさって1つの数値になります。
最初の2本のバンドの数値がそれぞれ`m`と`n`である場合、それらは組み合わさって1つの数値`mn`になります。

2つのバンドの色を持つ`string`の`vector`を受け取る関数`two_band_value(bands)`を定義してください。
この関数は、その2つの色の組み合わせに対応する値を返します。

```R
two_band_value(c("yellow", "red"))
# => [1] 42

two_band_value(c("green", "violet"))
# => [1] 57
```

## 4. 3本すべてのバンドに対応するオーム値を返す

最後に、最初の2本のバンドと3本目のバンドを組み合わせて、全体のオーム値を求める必要があります。
そのためには、2本のバンドの値と乗数を見つける必要があります。
乗数は、2本のバンドの値にゼロをいくつ付けるか、と考えることができます。

3つのバンドの色を持つ`string`の`vector`を受け取る関数`ohms(bands)`を定義してください。
この関数は、その3つの色の組み合わせに対応するオーム値を返します。

```R
ohms(c("yellow", "red", "orange"))
# => [1] 42000

ohms(c("green", "violet", "yellow"))
# => [1] 570000
```
