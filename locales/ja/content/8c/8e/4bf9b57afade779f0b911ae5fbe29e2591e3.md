# 配列のメソッド

配列は、よく扱うデータ構造の1つです。
そのため、配列を操作するためのメソッドが数多く用意されています。
並べ替え、逆順、要素の挿入など、その種類は多岐にわたります。

これらのメソッドには、元の配列を変更する破壊的なものと、新しい配列を返して元の配列を変更しない非破壊的なものがあります。

ここでは、配列を扱うときによく使われるメソッドをいくつか紹介します。

## insert

配列に要素を挿入するには、[`insert`][insert]メソッドを使います。このメソッドは、インデックスと要素を引数に取ります。
要素は指定したインデックスの位置に挿入され、それ以降の要素は1つずつ右にずれます。
インデックスが範囲外の場合、`IndexError`が発生します。

```crystal
numbers = [1, 2, 3]
numbers.insert(1, 4)
numbers # => [1, 4, 2, 3]

numbers.insert(5, 5) # => Error: Index out of bounds (IndexError)
```

## delete

配列から特定の要素を削除したいときは、[`delete`][delete]メソッドを使います。このメソッドは、要素を引数に取ります。
削除された要素が戻り値として返ります。
配列にその要素が存在しない場合は、`nil`が返ります。

```crystal
numbers = [1, 2, 3]
numbers.delete(2) # => 2
numbers           # => [1, 3]
```

## first & last

配列の最初または最後の要素を取得したいときは、[`first`][first]メソッドと[`last`][last]メソッドを使います。
これらのメソッドは、返す要素の数を指定する省略可能な引数を取ります。
インデックスの`0`や`-1`を使ったり、範囲を使ったりするよりも、読みやすく書けます。
配列が空の場合は、`Enumerable::EmptyError`が発生します。

```crystal
numbers = [1, 2, 3]
numbers.first # => 1
numbers.last  # => 3

numbers.first(2) # => [1, 2]
numbers.last(2)  # => [2, 3]

empty_array = [] of Int32
empty_array.last # => Error: Empty enumerable (Enumerable::EmptyError)
```

## reverse

配列を逆順にしたいときは、[`reverse`][reverse]メソッドを使います。このメソッドは、要素を逆順にした新しい配列を返します。
`reverse`は新しい配列を返し、元の配列は変更しないことに注意してください。
元の配列自体を変更したい場合は、メソッド名の末尾に`!`を付けます。

```crystal
numbers = [1, 2, 3]
numbers.reverse # => [3, 2, 1]
numbers         # => [1, 2, 3]

numbers.reverse! # => [3, 2, 1]
numbers          # => [3, 2, 1]
```

## Concat(`+`)

appendメソッド（`<<`）は、配列にオブジェクトを追加したいときに便利です。
ただし、2つの配列を結合したいときは、[`+`][concat]演算子を使います。これは、両方の配列の要素を持つ新しい配列を返します。

```crystal
[1, 2] + [3, 4] # => [1, 2, 3, 4]
```

ある配列に別の配列を追加すると、その配列は1つの要素として追加されます。

```crystal
[1, 2] << [3, 4] # => [1, 2, [3, 4]]
```

## empty?

配列が空かどうかを調べるときは、[`empty?`][empty?]メソッドを使います。このメソッドは、配列が空であれば`true`を、そうでなければ`false`を返します。
配列の長さを`0`と比較するよりも、読みやすく書けます。

```crystal
[].empty? # => true
[1, 2, 3].empty? # => false
```

## index

配列中の要素のインデックスを取得したいときは、[`index`][index]メソッドを使います。このメソッドは、要素を引数に取ります。
配列にその要素が存在しない場合は、`nil`が返ります。

```crystal
numbers = [1, 2, 3]
numbers.index(2) # => 1
```

## size

配列の要素数を知りたいときは、[`size`][size]メソッドを使います。

```crystal
numbers = [1, 2, 3]
numbers.size # => 3
```

## count

配列中に要素がいくつあるか数えたいときは、[`count`][count]メソッドを使います。

```crystal
fruits = ["apple", "banana", "apple"]
fruits.count("apple")      # => 2
fruits.count("banana")     # => 1
fruits.count("watermelon") # => 0
```

## sort

配列を並べ替えたいときは、[`sort`][sort]メソッドを使います。このメソッドは、要素を並べ替えた新しい配列を返します。
`reverse`と同様に、このメソッドは新しい配列を返し、元の配列は変更しません。

```crystal
numbers = [3, 2, 1]
numbers.sort # => [1, 2, 3]
numbers      # => [3, 2, 1]

numbers.sort! # => [1, 2, 3]
numbers       # => [1, 2, 3]
```
