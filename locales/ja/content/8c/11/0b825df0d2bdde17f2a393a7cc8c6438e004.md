# コマンドと引数の入門

このトラックは、bashを対話的なシェルとして使う方法を扱うものではありません。
プログラミング言語としてのbashを使って、プログラムを書くことを学ぶためのものです。

bashのプログラム、つまり_スクリプト_は、ファイルに保存された一連のコマンドです。
bash（実行ファイル）がそのファイルを読み、コマンドを順番に実行します。

## シバン

スクリプトの最初の行は、通常_インタプリター指示子_で、_ハッシュバン_や_シバン_とも呼ばれます：

```bash
#!/usr/bin/env bash
```

オペレーティングシステムが非バイナリのファイルを実行するとき、そのファイルの最初の行を読み取ります。
その行が`#!`で始まっていれば、カーネルはそれを使って、ファイルを実行するインタプリターを決めます。
`#!`はファイルの先頭そのものになければならず、その前にスペースや空行があってはいけません。

ここで、`env`は`PATH`から`bash`の実行ファイルを探します。
よりシンプルな`#!/bin/bash`を見かけることもあります。こちらはインタプリターの場所を直接指定するもので、`env`の形式のほうが移植性が高いです。

~~~~exercism/note
インターネット上で`/bin/sh`をインタプリターとして使っているスクリプトや例に、惑わされないでください。
**`sh`は`bash`ではありません！**
Bashは「sh互換」で、ほとんどの`sh`スクリプトを実行できますが、bashの一部の機能は`sh`では壊れたり予期しない動作をしたりします。
~~~~

## コメント

`#`で始まる行は_コメント_で、bashはそれを無視します。
コメントはコマンドと同じ行の後ろに書くこともできます。`#`から行の終わりまでは、すべて無視されます。
コメントは、スクリプトを読む人間のためにあります。

## 単語と引数

Bashは、入力（通常はターミナルかファイル）からコマンドを読み取ります。
読み取った入力の各行は、_コマンド_として扱われます。つまり、実行すべき指示です。
（複数行にまたがるコマンドなど、いくつか高度なケースがありますが、それについては後で説明します。）

Bashは各コマンドを、空白文字（スペースとタブ）で区切られた**単語**に分割します。
最初の単語が、実行する_コマンド_の名前です。
残りの単語はすべて、そのコマンドへの_引数_になります（オプション、ファイル名など）。

コマンドは、`echo`のようなbashの_組み込みコマンド_にも、`head`や`awk`、`sed`のような_実行ファイル_のプログラムにもなります。

## `echo`コマンド

`echo`は引数を1つのスペースで区切って出力し、最後に改行を付けます：

```bash
echo flour sugar eggs
```

出力：

```text
flour sugar eggs
```

引数の間の空白の量は関係ありません：

```bash
echo flour       sugar        eggs
```

```text
flour sugar eggs
```

`echo`を引数なしで呼び出すと、空行が出力されます。

## オプションも引数のひとつ

多くのコマンドは、動作を変える_オプション_を受け付けます。
bashにとって、オプションは特別なものではありません。他の単語と同じく、空白で隣り合う単語と区切られた、ただの単語です。
その引数をどう解釈するかは、コマンド自身が決めます。
慣習として、オプションは`-`で始まります。

`head`コマンドは、ファイルの最初の数行を出力します。
`list.txt`というファイルがあるとします：

```bash
head -n 2 list.txt
```

Bashはこの行を4つの単語に分割します：

| 単語 | 役割 |
| ---------- | ------------------------------------------- |
| `head`     | 実行するコマンド |
| `-n`       | オプション。`head`に_行_を数えるよう指示します |
| `2`        | `-n`オプションの値 |
| `list.txt` | 読み込むファイル |

Bashは最後の3つの単語をそのまま`head`に渡します。
`-n`の次に数値が来ること、そして残りの単語がファイルであることを理解しているのは、`head`のほうです。

単語を区切るのは空白なので、どこに空白を置くかが重要になります。
`head -n 2`は`head`に2つの引数（`-n`と`2`）を渡し、`head -n2`は1つ（`-n2`）を渡します。
多くのコマンドはどちらの形式も受け付けますが、それはコマンド次第です。
bashは気にしません。bashは行を単語に分割するだけです。

## 引数のクォート

[クォート][Quotes]は、単語をまとめて_1つの引数_にします。
クォートの中の空白はそのまま保たれ、クォート文字自体は引数の一部にはなりません：

```bash
echo "flour       sugar        eggs"
```

```text
flour       sugar        eggs
```

ファイル名のように空白を含む引数は、クォートで囲みます：

```bash
head -n 1 my shopping list.txt     # three files: "my", "shopping", "list.txt"
head -n 1 "my shopping list.txt"   # one file
```

## スクリプトの実行

スクリプトを実行するには、`bash`コマンドの引数として渡します：

```bash
bash myscript
```

この方法で実行すると、`#!`の行は単なるコメントになります。
ファイルをどう実行するかを、オペレーティングシステムに伝えているのです。

別の方法として、スクリプトファイルに実行権限を付けて、他のプログラムと同じように実行することもできます：

```bash
chmod +x myscript
./myscript
```

こうすると、オペレーティングシステムが`#!`の行を使って、使うインタプリターを決めます。
