# インストール

## Rランタイムをインストールする
[CRANのホームページ](https://cran.r-project.org/)にアクセスしましょう。そこにはLinux、Mac OSX、Windows用のダウンロードリンクがあります。お使いのオペレーティングシステム用のインストーラーをダウンロードして実行してください。

## RStudio IDEをインストールする（推奨）
RStudioは、Rでプログラミングするための人気のあるクロスプラットフォームな統合開発環境（IDE）です（Python、JavaScript、Markdownなど他の言語もサポートしています）。RStudioを使うと、解答コードを書いたりテストを実行したりするのが楽になります。

[RStudioの最新安定版](https://www.rstudio.com/products/rstudio/download/)をダウンロードしてインストールしてください。あるいは、次期リリースの[プレビュー版](https://www.rstudio.com/products/rstudio/download/preview/)を入手することもできます。

## R用のVisual Studio Code拡張機能をインストールする（代替案）
Visual Studio Code用のR拡張機能は、拡張されたシンタックスハイライト、コード補完、リンティング、フォーマット、Rターミナルとのやり取り、データ・プロット・ワークスペース変数・ヘルプページの表示、パッケージの管理、R Markdownドキュメントの操作をサポートしています。

[R拡張機能の最新版](https://code.visualstudio.com/docs/languages/r)をダウンロードしてインストールしてください。

## テストを実行するためのRパッケージをインストールする
テストを実行するためのテストランナーは、Hadley Wickhamによる[`testthat`](https://github.com/hadley/testthat)ライブラリです。これはRパッケージの作者の間で人気のある選択肢です。

このライブラリをインストールするには、RStudioのコンソール（またはRを使っている場所）で次を入力します。

```{R}
install.packages("testthat")
```

演習問題を解くためにパッケージをインストールする_必要_があることはほとんどありませんが、自分のプログラミングスタイルに合った[`tidyverse`](https://github.com/tidyverse/tidyverse)のような汎用ユーティリティパッケージを取り入れたくなるかもしれません。`tidyverse`のようなパッケージをインストールして読み込むには、次のようにします。

```{R}
install.packages("tidyverse")
library(tidyverse)
```
