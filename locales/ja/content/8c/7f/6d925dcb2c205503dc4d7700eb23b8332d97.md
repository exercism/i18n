# はじめに

`call`（[`kernel`][kernel]にあります）は、クォーテーションを実行します。クォーテーションのスタック効果を推論できないときは、`call`に対してスタック効果を明示的に宣言します。推論できないのは、ふつう、そのクォーテーションがどこか別の場所から来ている場合です。

```
call( stack-effect ) ! e.g. call( a b -- c )
```

```factor
3 4 [ + ] call .                 ! => 7
3 4 [ + ] call( a b -- c ) .     ! => 7

: apply-binary ( a b op -- c )
    call( a b -- c ) ;

5 3 [ - ] apply-binary .         ! => 2
```

クォーテーションは値なので、配列には数値とクォーテーションを混ぜて入れることができます。つまり、「プログラム」もただの並びのひとつになるわけです。

```factor
{ [ 1 + ] [ 2 * ] } 5 swap [ call( x -- y ) ] each .   ! 5 -> 6 -> 12
```
