# はじめに

## 数値

Haskellには、すべての数値型の基本となる型`Num`があります。
数値型には、主に4つのサブタイプがあります。[`Int`][int]、[`Integer`][integer]、[`Double`][double]、[`Float`][float]です。

Haskellには数を表す整数型が2つあります。
`Int`はサイズが固定された整数で、`Integer`は任意精度の整数です。
`Integer`は、マシンのメモリの限界まで、どれだけ大きな数でも保持できます。一方`Int`は、32ビットまたは64ビットで表現できる正負の整数の集合に対応します（少なくとも-2^29から2^29 - 1までが保証されています）。

負の数を書くときは、曖昧さを避けるために括弧（`()`）を使います。

```haskell
1

(-1)
```

`Float`は実数の集合に対応し、コンピューターの精度によって制限されます。
数値に対して定義された演算は、通常はどちらか一方の型にしか使えず、両方に使えるわけではありません。
`Double`は倍精度の浮動小数点数です。

```haskell
10.5
```

### 整数と小数の変換

`toFloat`関数を使うと、`Int`や`Integer`を`Float`に変換できます。

```haskell
toFloat 1
-- -> 1.0
```

`fromIntegral`もあり、こちらは任意の数値型を、必要と推論された数値型に変換します。

```haskell
fromIntegral 1
-- -> 1.0
```

`Float`を`Int`に変換するには、[`round`][round]、[`floor`][floor]、[`ceiling`][ceiling]の各関数を使います。
`round`関数は最も近い整数に丸め、`floor`は切り捨て、`ceiling`は切り上げます。

```haskell
round 1.5
-- -> 2

floor 1.5
-- -> 1

ceiling 1.5
-- -> 2
```

### 算術演算子

数値型では、[基本的な算術演算子][math]を使えます。
演算子は`+`、`-`、`*`、`/`、`%`です。
これらの演算子を使うときは、数値の型が一致している必要があります。
`fromIntegral`関数を使えば、型が一致するように変換できます。

#### 加算・減算・乗算

`+`演算子は加算に、`-`演算子は減算に、`*`演算子は乗算に使います。

| 演算子 | 例             |
| -------- | -------------- |
| `+`      | `4 + 6 => 10`  |
| `-`      | `15 - 10 => 5` |
| `*`      | `2 * 3 => 6`   |

#### 除算

除算は数値を割る計算です。
`/`演算子を除算に使います。
結果は常に浮動小数点数になります。

```haskell
4.0 / 2.5
-- -> 1.6

4 / 2
-- -> 2.0
```

~~~~exercism/caution
プログラミング言語によっては、0で割るとエラーになります。

Haskellでは、0で割った結果は`Infinity`または`-Infinity`になります。
唯一の例外は0を0で割った場合で、結果は`NaN`（Not a Number）になります。

```haskell
1 / 0
-- -> Infinity

(-1) / 0
-- -> -Infinity

0 / 0
-- -> NaN
```
~~~~

### 整数の除算

整数の除算は、整数同士を割って結果の整数部分を得るために使います。
Haskellには整数除算の関数が2つあり、結果が負になるときの丸め方が異なります。

- `div`は負の無限大に向かって切り捨てます。
- `quot`は0に向かって丸めます。

```haskell
6 `div` 2
-- -> 3

5 `div` 2
-- -> 2

(-5) `div` 2
-- -> -3

5 `quot` 2
-- -> 2

(-5) `quot` 2
-- -> -2
```

~~~~exercism/caution
整数の除算で0で割ると、例外が発生します。
これは通常の除算とは異なります。
~~~~

#### 余り

整数の除算の余りは、`mod`または`rem`で求められます。
どちらかの数が負のとき、結果の符号が異なります。

- `mod`は`div`と対応し、結果の符号は除数と同じになります。
- `rem`は`quot`と対応し、結果の符号は被除数と同じになります。

```haskell
5 `mod` 3
-- -> 2

(-5) `mod` 3
-- -> 1

5 `mod` (-3)
-- -> -1

5 `rem` 3
-- -> 2

(-5) `rem` 3
-- -> -2

5 `rem` (-3)
-- -> 2
```

任意の`x`と`y`（`y`が0でない場合）について、次の法則が成り立ちます。

```haskell
(x `div` y) * y + (x `mod` y) == x
(x `quot` y) * y + (x `rem` y) == x
```

~~~~exercism/note
どちらの数も正のときは、`div`と`quot`が同じ結果になり、`mod`と`rem`も同じ結果になります。
その場合、`quot`と`rem`のほうが少し効率的です。`div`と`mod`は負の数を扱うために余分な処理が必要になるからです。
~~~~

~~~~exercism/caution
`mod`や`rem`で0で割ると、例外が発生します。
これは通常の除算とは異なります。

```haskell
1 `mod` 0
-- Exception: divide by zero
```
~~~~

### 累乗

Haskellには「累乗を計算する」演算子が3つあり、動作も受け取る引数の型もそれぞれ異なります。

- `**`は2つの**浮動小数点数**を受け取り、対数を使って累乗を計算します。
- `^^`は**浮動小数点数**を受け取り、それを正または負の**整数**乗します。
- `^`は**任意の数値型**を受け取り、それを**正の整数**乗します。

```haskell
3.0 ** 2.1
-- -> 10.04510856630514

2.5 ^^ 2
-- -> 6.25

2 ^ 3
-- -> 8
```

### 優先順位と括弧

Haskellでは括弧（`()`）を使え、式をまとめるのに役立ちます。
演算の順序を変えたいときに便利です。

複数の算術演算子を使うときの演算の順序は数学と同じで、[PEMDAS][pemdas]と呼ばれます。
括弧（`()`）、指数（`**`）、乗算（`*`）と除算（`/`）、そして加算（`+`）と減算（`-`）の順に従います。

```haskell
2 + 3 - 4 * 4
-- -> -11

(2 + 3 - 4) * 4
-- -> 4
```
