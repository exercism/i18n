# はじめに

## 算術演算子

JavaScriptには、数値に対して基本的な計算を行うための6つの演算子が用意されています。

- `+`：足し算の演算子です。数値の和を求めます。
- `-`：引き算の演算子です。2つの数値の差を求めます。
- `*`：掛け算の演算子です。2つの数値の積を求めます。
- `/`：割り算の演算子です。2つの数値を割ります。

```javascript
2 - 1.5; //=> 0.5
19 / 2; //=> 9.5
```

- `%`：割り算の余りを求める演算子です。

  ```javascript
  40 % 4; // => 0
  -11 % 4; // => -3
  ```

- `**`：べき乗の演算子です。数値を累乗します。

  ```javascript
  4 ** 3; // => 64
  4 ** 1 / 2; // => 2
  ```

## 演算の順序

1行で複数の演算子を使うとき、JavaScriptは[こちらの優先順位表][mdn-operator-precedence]に示されている優先順位に従って計算します。
ここでの話に合わせて簡単に言うと、JavaScriptは、算数の授業で習ったPEDMASの規則に従います。これは、括弧（`()`）、指数、除算・乗算、加算・減算の順に計算するというものです。

<!-- prettier-ignore-start -->
```javascript
const result = 3 ** 3 + 9 * 4 / (3 - 1);
// => 3 ** 3 + 9 * 4/2
// => 27 + 9 * 4/2
// => 27 + 18
// => 45
```
<!-- prettier-ignore-end -->

## 複合代入演算子

複合代入演算子を使うと、変数に対して計算を行い、その新しい値を同じ変数に代入するコードを、より短く書けます。
たとえば、2つの変数`x`と`y`を考えてみましょう。
このとき、`x += y`は`x = x + y`と同じです。
多くの場合、変数`y`の代わりに数値を使います。
他の5つの演算も、同じように書くことができます。

```javascript
let x = 5;
x += 25; // x is now 30

let y = 31;
y %= 3; // y is now 1
```

[mdn-operator-precedence]: https://developer.mozilla.org/en-US/docs/Web/JavaScript/Reference/Operators/Operator_Precedence#table
