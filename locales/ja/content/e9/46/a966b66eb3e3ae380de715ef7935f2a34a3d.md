# 概要

基本的な`try .. rescue`の仕組みは、`else`節と`after`節に対応させるよう拡張できます。

- `else`ブロック：
  - tryブロックが成功した結果に対してパターンマッチが行われる場所です。
- `after`ブロック：
  - プログラムが動いている限り、tryブロックが成功してもrescueされても、関数が呼び出される場所です。
  - `after`ブロックの結果は、呼び出し元のスコープには返されません。

```elixir
try do
  :a
rescue
  _ -> :error
else
  :a -> :success
after
  :some_action
end

# => :success
```
