# 概要

クロージャは、環境にある値を覚えておくクオーテーションです。Factorはクロージャを使って、再利用できる変換を組み立てます。簡単なケースは`curry`と`compose`がカバーし、残りはfryクオーテーションが受け持ちます。

```factor
3 [ + ] curry .      ! [ 3 + ]
[ 1 + ] [ 2 * ] compose .   ! [ 1 + 2 * ]
2 3 '[ _ _ + + ] .   ! [ 2 3 + + ]
```

| ツール | 形 | どんなときに使うか |
|-----------|--------------------------------------|--------------------------------|
| `curry`   | `value quot -- newquot`              | 値を1つ取り込むとき |
| `2curry`  | `v1 v2 quot -- newquot`              | 値を2つ、どちらも先頭に置くとき |
| `compose` | `quot1 quot2 -- combined`            | 2つのクオーテーションを端から端までつなぐとき |
| `'[ _ ]`  | `… -- newquot`                       | たくさんの値を取り込み、内側のどこにでも置ける |

fryはコンパイル時の書き換えです。`'[ _ + ]`は、`[ + ]`に対する`curry`呼び出しに展開されます。面倒な処理はコンパイラーが引き受けてくれるので、取り込んだ値を置きたい場所にアンダースコアを書くだけです。
