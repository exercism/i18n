# 指示の補足

## ここでは`random`と`secrets`のどちらを使うべき？

Python 3.6以降、「ランダム」な数値を生成するためのモジュールが2つあります。

[`random`][random]というモジュールは[_疑似ランダム_][pseudo-random]です。つまり、真のランダム性を生成するのでは**なく**、ランダム性を_シミュレート_するアルゴリズムに従っています。
こうした「乱数」は既知のアルゴリズムで生成されるため、真にランダムとは言えません。
その結果、まさに疑似ランダムであるという理由から、`random`モジュールは暗号技術には適しておらず、使うべきではありません。


[`secrets`][secrets]というモジュールは、[暗号学的に強力な][crypto-strong]「乱数」を生成し、暗号技術に求められるより高い安全性を提供します。
厳密な意味では、これらも依然として疑似ランダムです。ただし、生成される数値が絶対に予測不可能であるという保証があります。


これはあくまで練習用の演習なので、`random`モジュールを使ってもかまいません。ただし、**実際に暗号技術に使うと非常に危険である**ことに注意してください。

[crypto-strong]: https://cryptobook.nakov.com/secure-random-generators/secure-random-generators-csprng
[pseudo-random]: https://en.wikipedia.org/wiki/Pseudorandomness
[random]: https://docs.python.org/3/library/random.html
[secrets]: https://docs.python.org/3/library/secrets.html
