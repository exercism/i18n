# 概要

- [バイナリ][binary]型は、[ビット列][bitstring]型を特殊化したものです。
  - バイナリは[バイト][wiki-byte]からできています。
  - 1バイトは8[ビット][wiki-bit]です。
  - バイトは`0`から`255`までの数値を表すことができます。
  - バイトを扱うときは、[16進数][wiki-hexadecimal]の整数値がよく使われます。たとえば`0x00`から`0xFF`までです。
- バイナリリテラルは、[`<<>>`という特殊形式][special-form]を使って定義します。
  - バイトに`255`より大きい整数を使った場合、[`::`][type-operator]演算子で[使用する単位やサイズ][bin-size]を指定しない限り、最後の8ビットだけが使われます。
- [`<>/2`][bin-concat]を使うと、ビット列・バイナリ・文字列を連結できます。

```elixir
<<255>> == <<0xFF>>
# Overflowing bits are truncated
<<256>> == <<0>>
<<256::size(16)>> == <<1, 0>>

<<"Hello">> == <<72, 101, 108, 108, 111>>
```

_ヌルバイト_は`<<0>>`の別名です。

## 文字列はエンコードされたバイナリデータ

- 文字列は、[UTF-8][wiki-utf8]形式でエンコードされたバイナリデータです。
  - 8ビット（1バイト）単位でエンコードされ、255文字を超える文字を表すには最大4バイト使います。
  - [文字列の長さ][string-length]は、その[バイトサイズ][byte-size]と同じとは限りません。

```elixir
# This string has a string length of 5, but is made up of 7 bytes
string = "cześć"
String.length(string) != byte_size(string)

# Even emoji strings are encoded binaries
"👍" == <<240, 159, 145, 141>>
```

## バイナリデータのパターンマッチング

- バイナリは、[まるごとパターンマッチさせることも、特殊形式を使って一部分だけをマッチさせることもできます][special-form]。
  - パターンマッチで可変サイズにできるのは、最後の部分だけです。

```elixir
# Ignore the first 8 bytes, bind the remaining variable sized binary to `body`
<<_::binary-size(8), body::binary>>
```

これは文字列でも同じようにできます。

```elixir
# bind the first 5 bytes to `name`,
# match the string literal " the ",
# bind remaining bytes to `species`
<<name::binary-size(5), " the ", species::binary>> = <<"Frank the Walrus">>
{name, species}
# => {"Frank", "Walrus"}
```
