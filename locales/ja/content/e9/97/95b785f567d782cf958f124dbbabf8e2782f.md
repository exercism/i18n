# テスト

提供されているテストを実行するには、Minitest gemが必要です。ターミナルウィンドウを開き、以下のコマンドを実行してminitestをインストールしましょう。

```
gem install minitest
```


テストは、演習のディレクトリで以下のコマンドを実行して走らせます。

```
ruby <snake-case-exercise>_test.rb
```

`<snake-case-exercise>`の部分は、ご自身の演習名を`snake_case`で書いたものに置き換えてください。

## 色付きの出力

`require 'minitest/pride'`を書くか、以下のコマンドを実行すると、色付きの出力が得られます。

```
ruby -r minitest/pride <snake-case-exercise>_test.rb
```
