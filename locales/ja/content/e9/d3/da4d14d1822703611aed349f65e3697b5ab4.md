# はじめに

関数の引数の基本については、[関数の概念][function concept]を参照してください。

## 仮引数の名前

[仮引数の名前][parameters]は、変数の名前と同じように、文字かアンダースコアで始める必要があり、文字、アンダースコア、数字を含めることができます。
仮引数の名前にスペースや記号を含めることはできません。


## 位置引数

位置引数とは、それに対応する仮引数と同じ順番で関数に渡される値のことです。
仮引数の名前を指定して渡すこともできます。


```python
def concat(greeting, name):
    return f"{greeting}{name}"
 
# Passing data to the function by position.
print(concat("Hello, ", "Judy"))
#->  Hello, Judy

# Passing data to the function using the parameter name.
print(concat(name="Sally", greeting="Hello, "))
#-> Hello, Sally
```

最初の`concat`の呼び出しでは、引数を位置で渡しています。
2回目の`concat`の呼び出しでは、引数を_名前_で渡しているので、順番を入れ替えられます。

位置引数は、名前を指定して渡した引数（_これは[キーワード引数][keyword-arguments]とも呼ばれます。可変長位置引数や[**kwargs][kwargs]と混同**しないで**ください**）の後ろに置くことはできません。

次のような引数の組み合わせは、

```python
>>> print(concat(greeting="Hello, ", "Zed"))
```

次のエラーになります。

```
SyntaxError: positional argument follows keyword argument
```

## 引数のデフォルト値

[デフォルト値][default arguments]は、仮引数リストの中で1つ以上の引数に対して指定できます。
これにより、必要であれば_より少ない_引数で関数を呼び出せるようになります。
デフォルト値は、その代わりに新しい引数を渡して関数を呼び出すことで上書きできます。


```python
# Note the default arguments for both greeting and name.
def concat(greeting="Hello, ", name="you"):
    return f"{greeting}{name}"
 
# Function call overriding the defaults
print(concat(name="Jerry", greeting="Hello, "))
#-> Hello, Jerry

# Function call without arguments resulting in the defaults being used.
print(concat())
#-> Hello, you
```

## キーワード引数

キーワード引数は、関数に引数を渡すときに仮引数の名前を使うものです。
これは、任意で位置で指定することもできます。


```python
# Note the default arguments for both greeting and name.
def concat(greeting="Hello, ", name="you"):
    return f"{greeting}{name}"

# Function call using parameter names as argument keywords.
print(concat(name="Jerry", greeting="Hello, "))
#-> Hello, Jerry

# Function call with positional data as arguments.
print(concat("Hello, ", "Isaac"))
#-> Hello, Isaac
```
