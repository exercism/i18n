# Ceylonのテストを実行する

テストを実行する前に、[`ceylon compile`](https://ceylon-lang.org/documentation/current/reference/tool/ceylon/subcommands/ceylon-compile.html)でコードをコンパイルしておく必要があります。

テストは[`ceylon test`](https://ceylon-lang.org/documentation/reference/tool/ceylon/subcommands/ceylon-test.html)コマンドで実行します。

`ceylon test`は、テストを実行する対象のモジュール名を必要とします。
Ceylonトラックでは、各演習が持つモジュールは1つだけです。

したがって、次のようにしてテストを実行できます。

```bash
ceylon compile && ceylon test $(basename source/*)
```
