# スレッド

この演習では、同時に操作したときに銀行口座がどれだけ堅牢かを確かめるために、スレッドを導入します。Tclのスレッドに関する参考資料をいくつか挙げます。

* [Tcl Threading Model](https://www.tcl.tk/doc/howto/thread_model.html)
* [Threads Done Right… with Tcl](https://www.activestate.com/blog/threads-done-right-tcl/)
* [Multi-Threaded Tcl Scripts](http://www.beedub.com/book/4th/Threads.pdf)、
  _Practical Programming in Tcl and Tk, 4th Ed._からの1章
copyright 2003 © Brent Welch, Ken Jones
[http://www.beedub.com/book/](http://www.beedub.com/book/)
    * なお、この章には「Tclのバイナリ配布物のほとんどはスレッドが有効になっていない」と書かれています。現在はそうではありません。Tclの配布物はスレッドサポート付きでビルドされるようになっています（参考：[TIP 364](https://core.tcl-lang.org/tips/doc/trunk/tip/364.md)）
* [Thread Package Commands](https://tcl.tk/man/tcl8.6/ThreadCmd/contents.htm)（Tclのドキュメントより）

## インストール

Tclの配布物の中には、Threadパッケージが標準で含まれていないものもあります。その場合は別途インストールする必要があります。
次のコマンドで確認してみましょう。
```bash
$ echo 'package require Thread' | tclsh
```
ここで_何も出力されなければ_、Threadパッケージはすでにインストールされています。

必要に応じて、`apt install tcl-thread`（または`dnf install tcl-thread`）を実行してください。
