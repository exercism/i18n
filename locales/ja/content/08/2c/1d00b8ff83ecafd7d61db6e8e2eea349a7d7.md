# 説明

友達から、重要な秘密が書かれたメッセージが届いたばかりです。
他の人に簡単には読まれないように、このメッセージは一連のビット操作によって暗号化されていました。
メッセージを復号するための関数を書いていきましょう。

## 1. ビットをシフトして戻す

メッセージの復号で最初にやることは、暗号化のときにシフトした分を、ビットを右にシフトし直して元に戻すことです。
以降の復号の手順は、左側から0が入ることを前提にしています。

値と、シフトする桁数を受け取ってシフトを行う`shiftBack`関数を実装しましょう。

```kotlin
shiftBack(0b1001, 2)
# => 0b0010
```

## 2. いくつかのビットを1にする

次に、1に設定する必要があるビットがあります。

値とマスクを受け取り、値の中のビットを1にした結果を返す`setBits`関数を実装しましょう。
マスクのビットも1になっているところでは、値の対応するビットを1にします。
それ以外のビットは変更しません。

```kotlin
setBits(0b0110, 0b0101);
# => 0b0111
```

## 3. 特定のビットを反転する

暗号化のときに、いくつかのビットが反転されています。
メッセージを復号するには、それらをもう一度反転して元に戻す必要があります。

値とマスクを受け取る`flipBits`関数を実装しましょう。
マスクは、値の中のどのビットを反転するかを示しています。
マスクのビットが1なら、値のそのビットを反転します。
それ以外のビットは変更しません。

```java
flipBits(0b1100, 0b0101);
# => 0b1001
```

## 4. 特定のビットを0にする

最後に、復号すると必ず0になるビットもあります。

値とマスクを受け取る`clearBits`関数を実装しましょう。
マスクのビットが1のところでは、`value`のビットを0にします。
それ以外のビットは変更しません。

```java
clearBits(0b0110, 0b0101);
# => 0b0010
```
