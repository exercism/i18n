# 基礎について

基礎のコンセプトでは、[Go](https://golang.org)を静的型付けのコンパイル型プログラミング言語として紹介しました。
この言語は、以前のドメイン名golang.orgにちなんでGolangと呼ばれることがよくありますが、正式な名前はGoです。

基礎のコンセプトでは、パッケージ、関数、変数という3つの主要な言語機能を紹介します。

## パッケージ

Goのアプリケーションは、パッケージで構成されています。
パッケージとは、同じディレクトリにあるソースファイルの集まりです。
同じディレクトリ内のすべてのソースファイルは、同じパッケージ名でなければなりません。
パッケージ名は、インポートパスの最後のディレクトリ名にするのが慣例です。
たとえば、["math/rand"パッケージ](https://golang.org/src/math/rand/)内のファイルは、`package rand`という文で始まります。
パッケージをインポートすると、名前が大文字で始まるエンティティ（関数、型、変数、定数）だけを使用またはアクセスできます。
Goで推奨される命名規則では、識別子は`camelCase`で命名します。ただし、パッケージをまたいでアクセスできるようにするものは`PascalCase`にします。

```go
package lasagna
```

## 変数

Goは静的型付けなので、すべての変数はコンパイル時に[型が定義されている必要があります](https://en.wikipedia.org/wiki/Type_system)。

変数は、型を明示的に指定して定義できます。

```go
var explicit int // Explicitly typed
```

初期化子を使うこともできます。その場合、コンパイラーが初期化子の型に合わせて変数の型を割り当てます。

```go
implicit := 10   // Implicitly typed as an int
```

一度宣言すると、変数には`=`演算子を使って値を代入できます。
一度宣言すると、変数の型は決して変更できません。

```go
count := 1 // Assign initial value
count = 2  // Update to new value

count = false // This throws a compiler error due to assigning a non `int` type
```

## 定数

定数は変数と同じようにデータを保持しますが、プログラムの実行中に値を変更することはできません。

定数は`const`キーワードを使って定義し、数値、文字、文字列、真偽値のいずれかにできます。

```go
const Age = 21 // Defines a numeric constant 'Age' with the value of 21
```

## 関数

Goの関数は、0個以上の仮引数を受け取ります。
仮引数は明示的に型を指定する必要があり、型推論はありません。

関数から値を返すには、`return`キーワードを使います。

関数を呼び出すには、関数名を指定し、関数の各仮引数に引数を渡します。

Goでは、2種類のコメントがサポートされています。
1行コメントは`//`で始まり、複数行コメントは`/*`と`*/`の間に挿入されます。

```go
package greeting

// Hello is a public function.
func Hello (name string) string {
    return hi(name)
}

// hi is a private function.
func hi (name string) string {
    return "hi " + name
}
```
