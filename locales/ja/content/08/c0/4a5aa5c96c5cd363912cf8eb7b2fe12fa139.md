# はじめに

Javaにおけるオブジェクト指向の中心的な仕組みは、_クラス_です。クラスは、データ（_フィールド_）と振る舞い（_メソッド_）を組み合わせたものです。クラスのフィールドとメソッドは、その_メンバー_と呼ばれます。

メンバーへのアクセスは、アクセス修飾子で制御できます。よく使われる2つは次のとおりです。

- `public`：メンバーはどのコードからでもアクセスできます（制限なし）。
- `private`：メンバーは同じクラス内のコードからのみアクセスできます。

クラスは、そのクラスのインスタンスを作成するためのテンプレートだと考えることができます。クラスのインスタンス（_オブジェクト_とも呼ばれます）を作成するには、`new`キーワードを使います。

```java
class Car {
}

// Create two car instances
Car myCar = new Car();
Car yourCar = new Car();
```

フィールドには型と名前があり（camelCaseで定義します）、クラス内のどこにでも定義できます（慣例では、クラスはPascalCaseで書きます）。

```java
class Car {
    // Accessible by anyone
    public int weight;

    // Only accessible by code in this class
    private String color;
}
```

フィールドには任意で初期値を代入できます。フィールドに初期値を指定_しない_場合、その型のデフォルト値が設定されます。インスタンスのフィールドの値には、ドット記法を使ってアクセスしたり更新したりできます。

```java
class Car {
    // Will be set to specified value
    public int weight = 2500;

    // Will be set to default value (0)
    public int year;
}

Car newCar = new Car();
newCar.weight; // => 2500
newCar.year;   // => 0

// Update value of the field
newCar.year = 2018;
```

プライベートフィールドは通常、メソッドの呼び出しの副作用として更新されます。そのようなメソッドは通常、値を返しません。その場合、戻り値の型は`void`にする必要があります。

```java
class CarImporter {
    private int carsImported;

    public void importCars(int numberOfCars)
    {
        // Update private field from public method
        carsImported = carsImported + numberOfCars;
    }
}
```
