# はじめに

Cairoの制御フローを使うと、条件や繰り返しに応じてプログラムの実行の流れを変えられます。

## 条件分岐

`if`式を使うと、条件に応じてコードを実行できます。

```rust
let number = 42;
if number > 0 {
    println!("Positive number");
} else if number < 0 {
    println!("Negative number");  
} else {
    println!("Zero");
}
```

`if`は式なので、値を返すこともできます。

```rust
let result = if condition { 5 } else { 10 };
```

## ループ

`loop`を使うと、コードを繰り返し実行できます。
ループは、止めない限りずっと動き続けます。条件が満たされたときにループを抜けるには、`break`を使います。

```rust
let mut counter = 0;
loop {
    if counter == 5 {
        break;
    }
    println!("Counter: {}", counter);
    counter += 1;
}
```

ループは、`break`を使って値を返すこともできます。

```rust
let result = loop {
    counter += 1;
    if counter == 10 {
        break counter * 2; // Returns 20
    }
};
```

`continue`を使うと、次の繰り返しにスキップできます。

```rust
let mut i = 0;
loop {
    i += 1;
    if i % 2 == 0 {
        continue; // Skip even numbers
    }
    if i > 10 {
        break;
    }
    println!("{}", i); // Only prints odd numbers
}
```
