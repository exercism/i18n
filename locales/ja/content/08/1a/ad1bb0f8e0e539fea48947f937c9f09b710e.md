# 説明

この演習では、ウィンドウシステムを備えたコンピューターをシミュレーションします。
移動したりサイズを変更したりできるウィンドウを作成し、その内容を表示させます。
次の図は、このあと扱う値を示したものです。

```
                  <--------------------- screenSize.width --------------------->

       ^          ╔════════════════════════════════════════════════════════════╗
       |          ║                                                            ║
       |          ║          position.x,_                                      ║
       |          ║          position.y  \                                     ║
       |          ║                       \<----- size.width ----->            ║
       |          ║                 ^      *──────────────────────┐            ║
       |          ║                 |      │        title         │            ║
       |          ║                 |      ├──────────────────────┤            ║
screenSize.height ║                 |      │                      │            ║
       |          ║            size.height │                      │            ║
       |          ║                 |      │       contents       │            ║
       |          ║                 |      │                      │            ║
       |          ║                 |      │                      │            ║
       |          ║                 v      └──────────────────────┘            ║
       |          ║                                                            ║
       |          ║                                                            ║
       v          ╚════════════════════════════════════════════════════════════╝
```

## 1. Size構造体を定義しましょう

`Size`という名前の構造体を定義し、ウィンドウの現在の幅と高さを格納する2つの`Int`プロパティ、`width`と`height`を持たせましょう。
幅と高さの初期値は、それぞれ80と60にします。
新しい幅と高さをパラメータとして受け取り、プロパティを新しいサイズに更新するメソッド`resize(newWidth:newHeight:)`も用意しましょう。

```swift
let size1080x764 = Size(width: 1080, height: 764)
// Returns Size
var size1200x800 = size1080x764
// Returns Size
size1200x800.resize(newWidth: 1200, newHeight: 800)
size1200x800.height
// Returns 800
```

## 2. Position構造体を定義しましょう

`Position`という名前の構造体を定義し、ウィンドウの左上隅の現在の水平位置と垂直位置を格納する2つの`Int`プロパティ、`x`と`y`を持たせましょう。
xとyの初期値は、それぞれ0にします。
位置（0, 0）は画面の左上隅で、右へ移動するほど`x`の値が大きくなり、下へ移動するほど`y`の値が大きくなります。

新しいxとyをパラメータとして受け取り、プロパティを新しい位置に更新するメソッド`moveTo(newX:newY:)`も用意しましょう。

```swift
var point = Position(x: 10, y: 20)
// Returns Position
point.moveTo(newX: 100, newY: -100)
point.y
// Returns -100
```

## 3. Windowクラスを定義しましょう

次のプロパティを持つウィンドウクラスを定義しましょう。

- `title` : `String`、初期値は"New Window"
- `screenSize` : `Size`、`width` = 800、`height` = 600の定数値
- `size` : `Size`、初期値は`Size`構造体のデフォルト値
- `position` : `Position`、初期値は`Position`構造体のデフォルト値
- `contents` : `String?`、初期値は`nil`

このクラスのために、空のイニシャライザも定義しましょう。

```swift
let window = Window()
window.title
// Returns "New Window"
```

## 4. ウィンドウのサイズを変更するメソッドを追加しましょう

- `resize(to:)` : `(Size) -> ()` - このメソッドは`Size`構造体を入力として受け取り、ウィンドウを指定されたサイズに変更しようとします。ただし、新しいサイズは一定の範囲を超えることはできません。
- 高さと幅の最小値は1です。
  1未満の高さや幅が要求された場合は、1に切り詰められます。
- 高さと幅の最大値は、ウィンドウの現在の位置によって決まります。ウィンドウの端が画面の端を越えることはできません。
  この範囲を超える値は、取り得る最大のサイズに切り詰められます。
  たとえば、ウィンドウの位置が`x` = 400、`y` = 300で、`height` = 400、`width` = 300へのサイズ変更が要求された場合、`y`方向に画面が十分な大きさでないため、ウィンドウは`height` = 300、`width` = 300に変更されます。

## 5. ウィンドウを移動するメソッドを追加しましょう

- `move(to:)` : `(Position) -> ()` - これは`resize(to:)`と似ていますが、サイズではなく、ウィンドウの_位置_を要求された値に調整するメソッドです。`resize`と同様に、新しい位置も一定の範囲を超えることはできません。
- 位置の最小値は、`x`と`y`のどちらも0です。
- どちらの方向でも、位置の最大値はウィンドウの現在のサイズによって決まります。ウィンドウの端が画面の端を越えることはできません。
  この範囲を超える値は、取り得る最大のサイズに切り詰められます。たとえば、ウィンドウのサイズが`x` = 250、`y` = 100で、`x` = 600、`y` = 200への移動が要求された場合、`x`方向に画面が十分な大きさでないため、ウィンドウは`x` = 550、`y` = 200に移動されます。

## 6. ウィンドウのテキストを更新してウィンドウの情報を表示するメソッドを追加しましょう

- `update(title:)` : `(String) -> ()` - このメソッドは、渡された文字列の値を`title`プロパティに設定します。
- `update(text:)` : `(String?) -> ()` - このメソッドは、渡されたオプショナルな文字列の値を`contents`プロパティに設定します。
- `display()` : `() -> String` - このメソッドは、ウィンドウの現在の状態を表す文字列を返します。たとえば、ウィンドウの`title`が"My First Window"、位置がx = 10、y = 100、サイズがwidth = 200、height = 150、contentsが"I 😍 my window"の場合、次の文字列を返します。`"My First Window\nPosition: (10, 100), Size: (200 x 150)\nI 😍 my window\n"` - `contents`がnilの場合、最後の行は"[This window intentionally left blank]"となります。

## 7. Windowクラスのイニシャライザを作成しましょう

ウィンドウシステムには、独自の入力でウィンドウを作成できるイニシャライザが必要です。
`Window`クラスに**もう1つ**イニシャライザを作成しましょう。
このイニシャライザは、`title`、`contents`、そして2つのオプショナルなパラメータ`size`と`position`を取ります。
`size`と`position`パラメータのデフォルト値は、それぞれ`Size`構造体と`Position`構造体のデフォルト値にします。

```swift
let window = Window(title: "My First Window", contents: "I 😍 my window")
window.display()
// Returns "My First Window\nPosition: (0, 0), Size: (80 x 60)\nI 😍 my window\n"

let window2 = Window(title: "My Second Window", contents: "I 😍 my window", size: Size(width: 200, height: 150), position: Position(x: 10, y: 100))
window2.display()
// Returns "My Second Window\nPosition: (10, 100), Size: (200 x 150)\nI 😍 my window\n"
```
