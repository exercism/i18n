# テスト

テストは次のコマンドで実行します：

```bash
$ wrenc exercise-name.spec.wren
```

たとえば`hello-world`の場合はこうです：

```bash
$ wrenc hello-world.spec.wren
```


## `skip`テストを理解する

`skip`メソッドは、特定のテストを実行しないようテストスイートに指示します。

- なぜスキップされるのでしょうか？

一度に1つのテストに集中でき、解答を育てながら1つずつ有効にしていけるようにするためです。

- どうやって有効にするのでしょうか？

スキップされたテスト：

```js
// this test will be skipped and not run
skip.test("title cased phrases") {
    Expect.value(Acronyms.parse("Portable Network Graphics")).toEqual("PNG")
}
```

`skip.test`を`do.test`に変えるだけです。

```js
// now the test will be run normally
do.test("title cased phrases") {
    Expect.value(Acronyms.parse("Portable Network Graphics")).toEqual("PNG")
}
```

## はじめてのWrenモジュールを作る

このトラックのテストは、実装をWrenモジュールとしてインポートして読み込みます：`import "./bob" for Bob`。実装をエクスポートするための特別な構文はありません。インポート文の`for Bob`に合わせてクラスを`Bob`と名付ければ、あとはすべてうまく動きます。

```javascript
class Bob {
  static hey(message) {
    // Your solution to the exercise goes here
  }
}
```

モジュールについてさらに詳しく知りたい場合は、[Wrenのモジュール化に関するドキュメント][modularity]を参照してください。すぐに始められるように、各演習のディレクトリには_スケルトン_のWrenファイルが用意されています。

[modularity]: https://wren.io/modularity.html
