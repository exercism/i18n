# 概要

Goでは、等価演算子と順序演算子を使って値を比較できます。これらの演算子は6つあります。

| 比較              | 演算子    |
| ------------------| --------- |
| 等しい            | `==`      |
| 等しくない        | `!=`      |
| より小さい        | `<`       |
| 以下              | `<=`      |
| より大きい        | `>`       |
| 以上              | `>=`      |

比較の結果は、常に真偽値になります。

```go
a := 3

a != 4 // true
a > 5  // false
```

## 等価演算子

等価演算子`==`と`!=`は、それぞれ値が別の値と等しいかどうかを調べます。Goでは、ほとんどの型で等価演算子を使えます。よくある例をいくつか挙げます。

```go
2 == 3 // false, integer comparison

2.1 != 2.2 // true, float comparison 

"hello" == "hello" // true, string comparison

'a' != 'b' // true, rune/byte comparison
```

## 順序演算子

順序演算子は、ある値が別の値より大きい（`>`）か、以上（`>=`）か、小さい（`<`）か、以下（`<=`）かを調べます。この種の比較は、数値、バイト、ルーン、文字列で使えます。文字列を比較するときは、辞書順（辞書式順序とも呼ばれます）に従います。

```go
2 > 3 // false, integer comparison

1.2 < 1.3 // true, float comparison

'a' > 'b' // false, rune/byte comparison

"Hello" < "World" // true, string comparison
```
