# 説明

カールは、Exercismのサイトで学ぶ言語のリストを管理したいと考えています。
カールは、新しい言語を追加したり、古い言語を削除したり、特定の言語がリストに入っているかどうかを確認したりできる必要があります。
カールがJavaやKotlinを学びたいと思ったら、とてもわくわくしますね！

## 1. 言語リストが空かどうかを確認する関数を定義する

カールは、自分の言語リストが空になったらすぐに気づいて、もっと学ぶ言語を探しに行きたいのです！
`isEmpty`というメソッドを定義して、リストに言語が1つもないときに`true`を返すようにしましょう。

```java
if (languageList.isEmpty()) {
    findMoreLanguagesToLearn();
}
```

## 2. 言語をリストに追加する関数を定義する

カールはKotlinとPythonを学ぶのを楽しみにしています！
`addLanguage`というメソッドを定義して、カールが学びたい言語を受け取ってリストに追加できるようにしましょう。

```java
languageList.addLanguage("Kotlin");
languageList.addLanguage("Python");
```

## 3. 言語をリストから削除する関数を定義する

カールは、今はScalaを学びたくないと思いました。
`removeLanguage`というメソッドを定義して、削除する言語を受け取ってリストから削除できるようにして、カールを手伝いましょう。

```java
languageList.removeLanguage("Scala");
```

## 4. リストの最初の項目を返す関数を定義する

カールは、自分が最初にリストに追加した言語（まだリストに残っているもの）を覚えておきたいのです。
`firstLanguage`というメソッドを定義して、リストの最初の言語を返すようにしましょう。

```java
String kotlin = languageList.firstLanguage(); // "Kotlin"
```

## 5. リストにいくつの言語があるかを返す関数を定義する

カールは、自分が学ぼうとしている言語がいくつあるのか知りたいのです。
`count`というメソッドを定義して、リストにある言語の数を返すようにして、カールが答えを見つけるのを手伝いましょう。

```java
int two = languageList.count(); // 2
```

## 6. ある言語がリストに入っているかどうかを判定する関数を定義する

カールは、自分が学びたかったのはPythonだったかRubyだったかを思い出そうとしています。
`containsLanguage`というメソッドを定義して、カールが確認したい言語を受け取れるようにしましょう。そうすれば答えがわかります！

```java
boolean learningPython = languageList.containsLanguage("Python"); // true
boolean learningRuby = languageList.containsLanguage("Ruby"); // false
```

## 7. リストがわくわくするものかどうかを判定する関数を定義する

カールがJavaやKotlinを学びたいと思っているなら、それはとてもわくわくします！
`isExciting`というメソッドを定義して、カールがJavaまたはKotlinを学びたいときにtrueを返すようにしましょう。

```java
javaLanguageList.isExciting() // true
neitherKotlinNorJavaLanguageList.isExciting() // false
```
