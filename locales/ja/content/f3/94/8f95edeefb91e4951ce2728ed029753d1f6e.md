# はじめに

## リスト

ここで使っている言語の名前であるLispは、_LIST Processing_の略です。となれば、この言語には要素のリストを扱う仕組みが備わっていると考えるかもしれませんが、そのとおりです！

Common Lispにはリスト以外のデータ構造もありますが、リストは今でも非常によく使われています。

Common Lispにおけるリストは、要素の並びです。主に歴史的な理由から、**cons**とも呼ばれます。
要素は同じ型である必要はありません。
たとえば、`1`、`two`、`"III"`からなるリストを作ることができます。

### リストの作成

次のように、クォートしたリストをそのまま入力するだけでかまいません。`'(1 two "III")`と書くと、リストが作成されて評価されます（評価結果は`(1 two "III")`です）。

リストを作るための主な関数としては、`list`と`cons`の2つがあります。

`list`は0個以上の引数を取り、それらの値で作られたリストに評価されます：

```lisp
(list 1 'two "III") ; => (1 two "III")
```

`cons`は2つの要素を取り、1つ目の要素を`car`（リストの先頭）、2つ目の要素を`cdr`（リストの残り）とするリストを作ります：

```lisp
(cons 1 2)            ; => (1 . 2) ;; (a list without `nil` as its `cdr` is printed in this way)
(cons 1 nil)          ; => (1)
(cons 1 (cons 2 nil)) ; => (1 2)
```

`car`と`cdr`という関数を使うと、リストの`car`と`cdr`にアクセスできます。

（`first`と`rest`は`car`と`cdr`の同義語で、まったく同じように動作します。）

### 長さとランダムアクセス

リストの長さは`length`で調べることができます。
空のリストの長さは0です。

任意の要素には`nth`でアクセスできます（リストのインデックスは0から始まることに注意してください）。

リストの長さより大きいインデックスを指定しても、エラーには_なりません_。
その場合は`nil`に評価されます：

```lisp
(nth 23 '(short list)) ; => nil
```

リストの先頭のほうの要素にアクセスするための補助メソッドもいくつかあります。`first`、`second`、`third`と続き、`tenth`まであります。便利ですよね？

### リストの結合

2つ以上のリストは`append`で結合できます：

```lisp
(append '(a b c) '(1 2 3)) ; => (A B C 1 2 3)
(append '(a b c) '())     ; => (A B C)
```

`append`に渡す引数は、それぞれリストである必要があります。
