# 概要

Rustは、1文字を表すために[char][char type]型を実装しています。`char`リテラルは、`'a'`のようにシングルクォートで囲んで書きます。
それぞれの`char`は4バイトの大きさで、1つの[Unicodeスカラー値][unicode scalar]を表します。

ただし、[`char`][character type]が、いつも文字だと思われているものとは限りません。ヒンディー語のように[ダイアクリティカルマーク][diacritics]を使う言語もあります。ダイアクリティカルマークとは、それが付いている文字を変化させる特別な記号です。Rustではダイアクリティカルマークは独立した`char`ですが、一般に文字だと考えられているのは、ダイアクリティカルマークとそれが付いている文字を合わせたものです。

文字とそのダイアクリティカルマークを合わせたものは、[書記素クラスタ][grapheme cluster]と呼ばれます。書記素クラスタを処理するために使える外部クレートがあり、たとえば[unicode-segmentation][unicode-segmentation]があります。

例

```rust
pub fn main() {
    let text = "ü"; // a "u" with a diacritic
    let text_vec: Vec<char> = text.chars().collect(); // this gets the chars in "ü"
    println!("{:?}", text_vec.len()); // this prints the number of chars in "ü"
    println!("{:?}", text_vec[0]); // this prints the first char in "ü"
    println!("{:?}", text_vec[1]); // this prints the second char in "ü"
}
```

出力は次のようになります。

```rust
2
'u'
'\u{308}'
```

`'\u{308}'`は、`char`リテラルを書くもう1つの方法です。`\u`は、それがUnicodeの`char`であることを示し、`{308}`はその文字またはダイアクリティカルマークに固有のUnicode番号です。
