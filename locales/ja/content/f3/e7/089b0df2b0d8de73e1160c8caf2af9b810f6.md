# 指示

友達から、重要な秘密が書かれたメッセージが届きました。
他の人に簡単に読まれないように、このメッセージは一連のビット操作によって暗号化されています。
メッセージの復号を手助けするメソッドを書く必要があります。

## 1. ビットをシフトし直す

メッセージを復号する最初のステップは、暗号化の過程で行ったシフトを元に戻すことです。ビットを右にシフトし直します。
このあとの復号のステップでは、左側から0が挿入されることを前提としています。

値とシフトする桁数を受け取り、シフトを実行する`Secrets.shiftBack`メソッドを実装しましょう。

```java
Secrets.shiftBack(0b1001, 2);
# => 0b0010
```

## 2. いくつかのビットを立てる

次に、1に設定する必要があるビットがあります。

値とマスクを受け取り、値のビットを1に設定した結果を返す`Secrets.setBits`メソッドを実装しましょう。
マスクのビットが1のところでは、値の対応するビットも1に設定します。
それ以外のビットは変更しません。

```java
Secrets.setBits(0b0110, 0b0101);
# => 0b0111
```

## 3. 特定のビットを反転させる

暗号化の際に、いくつかのビットが反転しています。
メッセージを復号するには、それらを反転し直す必要があります。

値とマスクを受け取る`Secrets.flipBits`メソッドを実装しましょう。
マスクは、値のどのビットを反転させるかを示します。
マスクのビットが1であれば、値の対応するビットを反転します。
それ以外のビットは変更しません。

```java
Secrets.flipBits(0b1100, 0b0101);
# => 0b1001
```

## 4. 特定のビットをクリアする

最後に、復号すると必ず0になるビットもあります。

値とマスクを受け取る`Secrets.clearBits`メソッドを実装しましょう。
マスクのビットが1のところでは、`value`のビットを0に設定します。
それ以外のビットは変更しません。

```java
Secrets.clearBits(0b0110, 0b0101);
# => 0b0010
```
