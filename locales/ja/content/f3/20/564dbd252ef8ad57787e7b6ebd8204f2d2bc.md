# 指示

この演習では、ログ行を処理します。

それぞれのログ行は、"[<LEVEL>]: <MESSAGE>*"という形式の文字列です。

## 1. ログ行からメッセージを取得する

先頭と末尾の空白を取り除いたメッセージをログ行から返す`LogLevels.message()`関数を実装します。

## 2. ログ行からログレベルを取得する

ログ行からログレベルを小文字で返す`LogLevels.logLevel()`関数を実装します。

## 3. ログ行を整形し直す

ログ行とロケーション文字列を受け取り、2行からなるメッセージに整形し直す`LogLevels.reformat()`メソッドを実装します。
1行目は`<LEVEL>@<LOCATIOON>:`という形式です。それぞれの要素は次のとおりです。

* `<LEVEL>`は小文字のログレベルです（「2. ログ行からログレベルを取得する」と同様です）。
* `<LOCATION>`は、2番目の引数として渡されたロケーションです。

2行目は、ちょうど2つのスペースのあとにログメッセージが続きます（「1. ログ行からメッセージを取得する」と同様です）：

```kotlin
reformat("[TRACE]: Start of function", 2, 8)
// => "trace@208:
  Start of function"
```
