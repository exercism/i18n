# 説明

この演習では、シンプルな整数電卓のエラー処理を実装します。この電卓は、加算・乗算・除算をサポートし、結果をフォーマットされた文字列として返す必要があります。また、不正な演算とゼロによる除算に対処するためのエラー処理も実装します。

目標は、次の形式の文字列を返す、動作する電卓を作ることです。

```rust
SimpleCalculator::calculate(16, 51, "+"); // => returns "16 + 51 = 67"

SimpleCalculator::calculate(32, 6, "*"); // => returns "32 * 6 = 192"

SimpleCalculator::calculate(512, 4, "/"); // => returns "512 / 4 = 128"
```

## 1. 電卓の演算を実装する

このタスクのメイン関数は`SimpleCalculator::calculate`です。これは3つの引数を取ります。2つの整数と、演算を表す`ByteArray`です。次の演算を実装してください。

- `+`記号による**加算**
- `*`記号による**乗算**
- `/`記号による**除算**

## 2. 不正な演算を処理する

演算記号が`+`、`*`、`/`のいずれでもない場合、電卓はパニックするか、エラーを返す必要があります。

- 演算が空文字列の場合、`ByteArray`のエラーメッセージ`"Operation cannot be an empty string"`でパニックします。
- それ以外の不正な演算の場合は、`Result::Err("Operation is out of range")`を返します。

```rust
SimpleCalculator::calculate(100, 10, "-"); // => returns Result::Err("Operation is out of range")

SimpleCalculator::calculate(8, 2, ""); // => panics with "Operation cannot be an empty string"
```

## 3. ゼロによる除算のエラーを処理する

`0`で除算しようとしたとき、電卓はゼロによる除算が許可されていないことを示すエラーメッセージでパニックする必要があります。返される結果は、`felt252`値の`'Division by zero is not allowed'`である必要があります。

```rust
SimpleCalculator::calculate(512, 0, "/"); // => panics with 'Division by zero is not allowed'
```
