# DelphiとDUnitXテストフレームワークのインストール #
## Windows ###

無料の[Community Edition](https://www.embarcadero.com/products/delphi/starter)が利用できます。インストール手順は製品に同梱されているものに従ってください。

## Windows以外のオペレーティングシステム ###

DelphiはWindowsベースのオペレーティングシステムでしか動作しません。Windowsをホストする仮想マシンの中であれば、Delphiを実行できます。

## DUnitXテストフレームワークのインストール ###
Delphi XE8以降をインストールする際に、DUnitXを一緒にインストールすることもできます。ただし、以下の手順に従い、作者のGitHubリポジトリからDUnitXのコピーを手動で入手することをおすすめします。そのほうが更新の頻度が高いからです。

Delphiのインストールが無事に完了したら、そのDelphiにこのテストフレームワークが含まれていない場合、以下の手順でDUnitXを入手してインストールしてください。

- DUnitXは[VSoftTechnologies](https://www.github.com/VSoftTechnologies)によるオープンソースプロジェクトです。DUnitXのGitHubリポジトリは[こちら](https://github.com/VSoftTechnologies/DUnitX)にあります。
- リポジトリをフォークし、それをクローンするなどしてローカルマシンにダウンロードするのがよいでしょう。
- DUnitXをDelphiにインストールする手順の詳細は、Vincent Parrettがブログ記事[こちら](https://www.finalbuilder.com/resources/blogs/postid/702/dunitx-has-a-wizard)で公開しています。

## DUnitXのためのDelphiの設定 ###

DelphiにDUnitXが同梱されておらず、手動でインストールした場合は、DelphiがDUnitXのインストール先を認識できるように、必要な設定を変更します。以下の図解付きの手順に従ってください。

*注：この時点でDelphiのインストールが完了していることを前提としています。*

- Delphiを起動します。インストールしたばかりであれば、おそらく次のような`Welcome Page`が表示されます。

[![Welcome Page](https://raw.githubusercontent.com/exercism/delphi/master/docs/img/00delphiwelcomepageLogo.png)](https://raw.githubusercontent.com/exercism/delphi/master/docs/img/00delphiwelcomepage.png)

- 上部のメニューにある`Tools`を探してクリックします。
 
![Tools](https://raw.githubusercontent.com/exercism/delphi/master/docs/img/01delphiclicktools.png)

- `Options`をクリックします。

![Options](https://raw.githubusercontent.com/exercism/delphi/master/docs/img/02delphiclickoptions.png)

- Options画面の左側にある`Environment Variables`を探してクリックします。

[![Options画面のEnvironment Variables](https://raw.githubusercontent.com/exercism/delphi/master/docs/img/03delphioptionsenvironmentvariablesLogo.png)](https://raw.githubusercontent.com/exercism/delphi/master/docs/img/03delphioptionsenvironmentvariables.png)

- `User overrides`グループにある`New`ボタンをクリックします。

![Newをクリック](https://raw.githubusercontent.com/exercism/delphi/master/docs/img/04delphioptionsenvironmentvariablesclicknew.png)

- New User Variableウィンドウが表示され、2つの入力欄があります。上の欄には変数名として`DUNITX`を入力します。下の欄には、DUnitXのコピーがある場所の完全なパスを入力します。たとえば私の場合、`C:\Program Files\Embarcadero\Studio\19.0\source\DUnitX`です。*19.0というフォルダーがない場合もあります。インストールされているDelphiのバージョンによって異なります。* その後、`Ok`ボタンをクリックしてこのウィンドウを閉じます。

![New User Variable](https://raw.githubusercontent.com/exercism/delphi/master/docs/img/05delphinewuservariable.png)

- Options画面の左側にある`Library`を探してクリックします。

[![Library](https://raw.githubusercontent.com/exercism/delphi/master/docs/img/06delphioptionslibraryLogo.png)](https://raw.githubusercontent.com/exercism/delphi/master/docs/img/06delphioptionslibrary.png)

- Directoriesグループにある`Library path`の`...`ボタンをクリックします。

[![...ボタン](https://raw.githubusercontent.com/exercism/delphi/master/docs/img/07delphiclicklibrarypathbuttonLogo.png)](https://raw.githubusercontent.com/exercism/delphi/master/docs/img/07delphiclicklibrarypathbutton.png)

- Directoriesウィンドウに、先ほど作成した変数名を入力します。入力内容は`$(DUNITX)`のようになります。

![Directories](https://raw.githubusercontent.com/exercism/delphi/master/docs/img/08delphidirectoriesinputvarnameclickadd.png)

- `Add`ボタンをクリックして、この新しい項目をリストに追加します。

- `Ok`ボタンをクリックして、変更を保存します。


- 最後に、Optionsウィンドウの`Ok`ボタンをクリックして、すべての変更を保存します。

これでDelphiは、DUnitXテストフレームワークライブラリーに関連するユニットを認識できるようになります。

*注：受講者がDelphi XE以降を使用していることを前提としています。*
