# はじめに

## バイナリ

Elixirには、バイナリデータを扱うためのエレガントな構文があります。それは、[ビット列][exercism-bitstrings]を扱うために用意された`<<>>`という特殊形式で、すでに見てきたとおりです。

バイナリ型は、ビット列型を特殊化した型です。ビット列はどのような長さ（任意の[ビット][wiki-bit]数）にすることもできますが、バイナリはビット数を8で割り切れる場合のものです。つまり、バイナリを扱うときは、[バイト][wiki-byte]（8ビット）という単位で考えることがよくあります。1バイトで`0`から`255`までの整数を表せます。バイトの値は、[16進数][wiki-hexadecimal]の`0x00 - 0xFF`で扱うのが一般的です。

バイナリリテラルは、ビット列の特殊形式`<<>>`を使って定義します。バイナリリテラルを定義するときには、整数リテラルと文字列リテラルを使えます。255より大きい整数はオーバーフローし、整数の最後の8ビットだけが使われます。デフォルトでは、値に`::binary`修飾子が適用されます。バイナリは`<>/2`演算子で連結できます。

```elixir
<<255>> == <<0xFF>>
# Overflowing bits are truncated
<<256>> == <<0>>
<<2, 4, 6, 8, 10, 12, 14, 16>> == <<0x02, 0x04, 0x06, 0x08, 0x0A, 0x0C, 0x0E, 0x10>>
```

_ヌルバイト_ は`<<0>>`の別名です。

### バイナリデータのパターンマッチング

[パターンマッチング][exercism-pattern-matching]はバイナリにも拡張されていて、リストの場合と同じように、バイナリデータの一部分にパターンマッチできます。

```elixir
# Ignore the first 8 bytes, match and bind the remaining to `body`
<<_::binary-size(8), body::binary>>
```

他の種類のパターンマッチングと同様に、これを関数の定義で使うと、複数の関数節から選ぶときのマッチングに利用できます。
