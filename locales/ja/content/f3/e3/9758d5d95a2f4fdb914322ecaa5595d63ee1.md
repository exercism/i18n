# クラスの`static`キーワード

クラスは、PHPでコードを整理するための単位で、何かのインスタンスやサービス、手順を表すことがよくあります。`static`と`self`キーワードを使うと、プロパティやメソッドを、すべてのインスタンス（インスタンスが1つもない場合でも）から参照できる形でクラスに持たせることができます。

```php
<?php

class Book
{
    static $genre = 'Adventure';

    static function getGenre()
    {
        return self::$genre;
    }
}

// Usage
$genre = Book::$genre;
$genre = Book::getGenre();
```

## 制限

`static`なクラスメソッドは、同じクラスにある他の`static`プロパティやクラスメソッドしか呼び出せません。
