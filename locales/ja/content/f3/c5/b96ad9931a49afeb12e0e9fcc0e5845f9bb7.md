# 説明

この演習では、データに変換を加えることで動作する暗号化デバイスのソフトウェアを書くことになりました。より単純な関数を組み合わせて、複雑な関数を柔軟に作れる方法が必要です。

それぞれのタスクでは、呼び出し元のスコープから呼び出せる匿名関数を返してください。

## 1. 加算器を作る

`secret_add`を実装しましょう。これは1つの引数を受け取り、その引数に`secret_add`に渡された引数を足す関数を返します。

```gleam
let adder = secret_add(2)
adder(2)
// -> 4
```

## 2. 減算器を作る

`secret_subtract`を実装しましょう。これは1つの引数を受け取り、その引数から`secret_subtract`に渡された秘密の値を引く関数を返します。

```gleam
let subtractor = secret_subtract(2)
subtractor(3)
// -> 1
```

## 3. 乗算器を作る

`secret_multiply`を実装しましょう。これは1つの引数を受け取り、その引数に`secret_multiply`に渡された秘密の値を掛ける関数を返します。

```gleam
let multiplier = secret_multiply(7)
multiplier(3)
// -> 21
```

## 4. 除算器を作る

`secret_divide`を実装しましょう。これは1つの引数を受け取り、その引数を`secret_divide`に渡された秘密の値で割る関数を返します。

```gleam
let divider = secret_divide(3)
divider(32)
// -> 10
```

## 5. 関数を組み合わせる関数を作る

`secret_combine`を実装しましょう。これは1つの引数を受け取り、その引数に、`secret_combine`に渡された2つの関数を順番に適用する関数を返します。

```gleam
let multiply = secret_multiply(7)
let divide = secret_divide(3)
let combined = secret_combine(multiply, divide)

combined(6)
// -> 14
```
