# 状態を持つクラス

これまでのクラスは、どれもルーチンを詰めた箱のようなものでした。引数を受け取り、答えを計算して、あとは何も覚えていませんでした。

クラスは、その代わりに物事を**覚えておく**ことができます。スコアボードはそうでなければなりません。スコアは、試合が始まってからのすべてのゴールによって決まるからです。

## 属性

`attr`を使うと、クラスに覚えておくものを与えられます。

```sather
class SCOREBOARD is

   attr home_score : INT;
   attr away_score : INT;

end; -- class SCOREBOARD
```

それぞれの`attr`は、値を読み取るルーチンと、値を変更するルーチンになります。

```sather
   board.home_score            -- read it
   board.home_score := 4;      -- change it
```

同じ型の属性は、引数と同じように、宣言をまとめられます。

```sather
   attr home_score, away_score : INT;
```

## オブジェクト

属性を持つクラスは、**オブジェクト**を作るためのひな形です。各オブジェクトは属性のコピーをそれぞれ持つので、2つのスコアボードは2つのスコアを保ちます。

`new`はオブジェクトを作ります。`create`というルーチンの中に書きます。このルーチンがオブジェクトの中身を埋めてから、それを返します。

```sather
   create(home, away : STR) : SAME is
      board ::= new;
      board.home_team := home;
      board.away_team := away;
      return board;
   end;
```

`SAME`は「このクラス」という意味です。そこに`SCOREBOARD`と書いても同じことですが、クラスの名前を変えても`SAME`はそのまま動きます。

## オブジェクトを作る

`#`は`create`を呼び出します。

```sather
   board ::= #SCOREBOARD("Vixens", "Magpies");
```

`#`は`rehearsal-script`のときから使ってきました。`#FSTR`もまさにこれです。

## オブジェクトを変更するルーチン

クラスの中では、属性はオブジェクトを前に付けず、名前だけで使います。それは、そのルーチンが呼び出されたオブジェクトを指します。

```sather
   home_goal is
      home_score := home_score + 1;
   end;
```

`home_goal`は戻り値の型を宣言していません。何も返さず、代わりにオブジェクトを変更するからです。文として呼び出します。

```sather
   board.home_goal;
```

## 属性の初期値は空

まだ誰も設定していない属性は、`INT`なら0、`BOOL`なら`false`、文字列やオブジェクトならvoidを保持します。そのため、新しいスコアボードは、何も指定しなくても0対0を表します。
