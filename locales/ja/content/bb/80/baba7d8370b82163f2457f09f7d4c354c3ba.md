# はじめに

## chars

Javaの`char`プリミティブ型は、1文字を16ビットで表したものです。
複数の`char`を組み合わせて`"word"`のような文字列を作ることもできますし、`char`を1つずつ独立して扱うこともできます。
`char`リテラルは、シングルクォートで囲みます（例：`'A'`）。

```java
char lowerA = 'a';
char upperB = 'B';
```

## `String`の`char`を取得する

`String.toCharArray`メソッドは、文字列の`char`を配列として返します。
配列のページで触れたように、`for`ループを使えばその配列を繰り返し処理できます。

```java
String text = "Hello";
char[] asArray = text.toCharArray();

for (char ch: asArray) {
    System.out.println(ch);
}

// Outputs:
// H
// e
// l
// l
// o
```

## `Character`クラス

`char`を調べたり操作したりするための、標準ライブラリのメソッドがたくさんあります。
これらは`java.lang.Character`クラスの静的メソッドとして用意されています。
いくつか例を見てみましょう。

```java
Character.isWhitespace(' ');    // true
Character.isWhitespace('#');    // false

Character.isLetter('a');        // true
Character.isLetter('3');        // false

Character.isDigit('6');         // true
Character.isDigit('?');         // false
```

## `String`に`char`を追加する

`+`演算子を使うと、`String`に`char`を追加できます。

```java
'a' + " banana"     // => "a banana"
"banana " + 'a'     // => "banana a"
```

~~~~exercism/caution
2つの`char`を`+`でつなげて`String`を作ろうとしないように気をつけてください！
この方法で2つの`char`を足すと、`String`ではなく`int`になります！
たとえば、次のようになります。

```java
'b' + 'c';
// => 197 (not the String "bc")
```

これは、Javaが`char`を`int`に昇格させるためです（[Java Language Specification][jls-main]の[4.2 Primitive Types and Values ][jls-primitives]を参照してください）。

[jls-main]: https://docs.oracle.com/javase/specs/jls/se21/html/
[jls-primitives]: https://docs.oracle.com/javase/specs/jls/se21/html/jls-4.html#jls-4.2
~~~~

ただし、追加する文字が多い場合は、代わりに`StringBuilder`を使うほうが効率的なことがあります。

```java
StringBuilder builder = new StringBuilder();
builder.append('a');
builder.append('b');
builder.append('c');

String builtString = builder.toString();
// => abc
```
