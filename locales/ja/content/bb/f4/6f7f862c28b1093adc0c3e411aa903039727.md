# 説明

この演習では、ラジコンカーを使った作業をさらに進めていきます。

実験用の車が開発されたので、テストコースを改良して、量産モデルと実験モデルの両方を扱えるようにする必要があります。2種類の車はすでに完成しているので、両方をテストコースで扱う方法を考えましょう。

さらに、量産車も少しずつ成果を上げ始めています。チームのボスは、量産車のランキングを公開して競争心を維持したいと考えています。

## 1. インターフェースを実装する

`RemoteControlCar`インターフェースに次の2つのメソッドを追加してください。

- `drive()`：何も返しません
- `getDistanceTravelled()`：`int`を返します

次に、`ProductionRemoteControlCar`と`ExperimentalRemoteControlCar`に`RemoteControlCar`インターフェースを実装させます。インターフェースが要求するすべてのメソッドを実装する必要があります。

## 2. 走行

`.drive()`を呼び出すたびに、車は一定の距離を進むようにします。

- `ProductionRemoteControlCar`は10単位進みます
- `ExperimentalRemoteControlCar`は20単位進みます

`.getDistanceTravelled()`メソッドは、その車がこれまでに走行した単位数を返すようにします。

```java
ProductionRemoteControlCar prod = new ProductionRemoteControlCar();
prod.drive();
prod.getDistanceTravelled();
// => 10
        
ExperimentalRemoteControlCar exp = new ExperimentalRemoteControlCar();
exp.drive();
exp.getDistanceTravelled();
// => 20
```

## 3. レース

`TestTrack.race(RemoteControlCar car)`メソッドを実装し、その中で`car`が`drive()`を実行できるようにします。

```java
TestTrack.race(new ProductionRemoteControlCar());
TestTrack.race(new ExperimentalRemoteControlCar());
// this should execute without an exception being thrown
```

## 4. 量産車を並べ替えられるようにする

`ProductionRemoteControlCar`クラスに`Comparable<T>`インターフェースを実装してください。車のデフォルトの並べ替え順は、勝利数の降順にします。

静的メソッド`TestTrack.getRankedCars()`を実装して、渡された車を勝利数の降順に並べ替えて返すようにします。

```java
ProductionRemoteControlCar prc1 = new ProductionRemoteControlCar();
ProductionRemoteControlCar prc2 = new ProductionRemoteControlCar();
prc1.setNumberOfVictories(2);
prc2.setNumberOfVictories(3);
List<ProductionRemoteControlCar> unsortedCars = new ArrayList<>();
unsortedCars.add(prc1);
unsortedCars.add(prc2);
List<ProductionRemoteControlCar> rankings = TestTrack.getRankedCars(unsortedCars);
// => rankings.get(0) == prc2
// => rankings.get(1) == prc1
```
