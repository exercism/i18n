# 説明

通常の数値をローマ数字に変換する関数を書いてください。

ローマ人たちは賢い人々でした。
彼らはヨーロッパのほとんどを征服し、何百年もの間それを支配していました。
彼らはコンクリートやまっすぐな道、さらにはビキニまで発明しました。
しかし、彼らが決して発見しなかったものが一つあります。それはゼロという数値です。
そのため、彼らの偉業について詳しく歴史を書き、年代を記すのは少し難しくなりましたが、彼らが考案した数値の仕組みは今でも使われています。
たとえば、BBCは番組の年代を表すのにローマ数字を使っています。

ローマ人は文字を使って数値を書きました。I、V、X、L、C、D、Mです。
（これらの文字は直線が多く、そのため石板に刻むのは簡単だったことに気づくでしょう）。

```text
 1  => I
10  => X
 7  => VII
```

この表記法で扱える最大の数値は3,999です。
（ローマ人自身はそれ以上を使うことはほとんどありませんでした）

Wikipediaにはこう書かれています。現代のローマ数字は…各桁を左端の桁から順に個別に表記し、値がゼロの桁は飛ばして書きます。

実際の例として、1990を見てみましょう。

ローマ数字では、1990はMCMXCです。

1000=M
900=CM
90=XC

2008はMMVIIIと書きます。

2000=MM
8=VIII
