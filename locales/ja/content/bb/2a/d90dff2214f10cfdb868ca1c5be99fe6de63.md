# 概要

C#の型は、クラスや構造体のスコープの中で定義できます。外側の型は、一種の名前空間のような役割を果たします。その型にアクセスするには、外側の型を通してドット記法で指定します。

```csharp
class Outer
{
    public interface IInner {}
    public enum EInner {}
    public class CInner {}
    public struct SInner {}
}

var outer = new Outer();
var inner = new Outer.CInner();
```

## アクセスレベル

アクセスレベルは、内側の型にも適用できます。たとえば、クラスを`private`にすると、外側の型のスコープの外からそのクラスを見ることはできず、もちろんインスタンスもスコープの外から見たり使ったりすることはできません。

外側のクラスのprivateメンバーには、内側のクラスのすべてのメンバーがアクセスできますが、外側のクラスのメンバーがアクセスできるのは、内側のクラスのprivateでないメンバーだけです。外側のクラスのメンバーにアクセスするには、内側のクラスに外側のクラスのインスタンスを渡す必要があります。

次の例で確認できます。

```csharp
class Outer
{
    public class InnerImpl
    {
        private Outer outer;

        public int Interesting = 42;

        public InnerImpl(Outer outer, int interesting)
        {
            this.outer = outer;
            Interesting = interesting;
        }

    }

    public InnerImpl Inner;
    public Outer()
    {
        Inner = new InnerImpl(this, 42);
    }
}

var outer = new Outer();
outer.Inner.Interesting
// => 42
var inner = new Outer.InnerImpl(outer, 1729);
outer.Inner.Interesting
// => 1729
```

## 独立したインスタンス化を防ぐ

インスタンス化できる型が、外側の型の外で作られないようにするパターンがあります。publicなインターフェースを公開しつつ、実装するクラスはprivateにしておくのです。

```csharp
class Outer
{
    public interface IInner
    {
        void DoSomething();
    }

    private class InnerImpl : IInner
    {
        private Outer outer;
        public InnerImpl(Outer outer)
        {
            this.outer = outer;
        }
        public void DoSomething()
        {
            outer.DoSomethingElse();
        }
    }

    public IInner Inner;

    public Outer()
    {
        Inner = new InnerImpl(this);
    }
    private void DoSomethingElse()
    {
    }
}

var outer = new Outer();
outer.Inner.DoSomething();

// NOT var inner = new Outer.Inner(outer);
```

## Java開発者向けの補足

C#の入れ子クラスは、Javaのstaticな入れ子クラスと内部クラスを掛け合わせたようなものです。C#では、外側のクラスのprivateメンバーに、入れ子クラスのメンバーからアクセスできますが、それをインスタンス化して外側のクラスのインスタンスに結び付けるための特別な構文はありません。上の例で示したパターンを何らかの形で応用する必要があります。

C#にもstaticな入れ子クラスはありますが、それは単に静的な振る舞いを持つ、囲まれたクラスにすぎません。
