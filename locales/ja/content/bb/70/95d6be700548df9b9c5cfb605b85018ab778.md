# 概要

浮動小数点数は、小数点以下の桁が0桁以上ある数値です。例えば、`-2.4`、`0.1`、`3.14`、`16.984025`、`1024.0`などです。

F#には3つの浮動小数点型があります。

- `single`: 4バイト（精度は約6〜9桁）。`2.45f`または`2.45F`と書きます。`float32`型をエイリアスとして使えます。
- `float`: 8バイト（精度は約15〜17桁）。最もよく使われる型です。`2.45`と書くか、指数表記を使って`2.3E+32`や`2.3e+32`のように書きます。`double`型をエイリアスとして使えます。
- `decimal`: 16バイト（精度は28〜29桁）。通常、金額データを扱うときに使います。その精度により、丸め誤差が少なくなるためです。`2.45m`または`2.45M`と書きます。

各浮動小数点型には、それぞれ独自の[精度、おおよその範囲、サイズ][floating-point-types]があります。精度は、小数点以下の桁をいくつまで格納できるかを示します。つまり、PIを`single`に格納しようとしても、最初の6〜9桁しか格納されません（最後の桁は丸められます）。

異なる浮動小数点型の間の変換は、[変換演算子][conversion-operators]を使って行います。

```fsharp
let floatFromSingle = float 2.45f
```

浮動小数点型の値を等しいかどうか比較するときは、常に注意してください。同じ値を表しているように見えても、実際には異なる値である可能性があるからです。詳しくは[こちらの記事][precision-in-comparisons]を参照してください（コード例はC#で書かれています）。

浮動小数点数についての短い入門は、[0.30000000000000004.com][0.30000000000000004.com]で読むことができます。[Float Toyのページ][evanw.github.io-float-toy]では、浮動小数点数のビットが実際の浮動小数点値にどのように変換されるかを、図を使ってわかりやすく説明しています。
