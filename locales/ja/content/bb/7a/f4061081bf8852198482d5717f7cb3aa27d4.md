# 説明

デザインチームは、レイアウト作業の一部をCSSの変形からFactorに移行しています。チームのほかのメンバーに喜んでもらうために、2次元の点を受け取って2次元の点を返す、小さくて再利用可能な変換をクォーテーションとして作ります。

点は2要素の配列`{ x y }`です。

## 1. 座標を平行移動する

`translate-2d`を定義して、スタックから2つの値`dx`と`dy`を取り出し、点を`(dx, dy)`だけ平行移動するクォーテーションを返します。

```factor
{ 4 8 } 2 0 translate-2d call( p -- p' ) .
! => { 6 8 }
```

## 2. 座標を拡大縮小する

`scale-2d`も同じように定義して、点を`(sx, sy)`だけ拡大縮小するクォーテーションを返します。

```factor
{ 6 -3 } 2 2 scale-2d call( p -- p' ) .
! => { 12 -6 }
```

## 3. 2つの変換を合成する

`compose-transformations`を定義して、2つの変換クォーテーション`f`と`g`を受け取り、まず`f`を適用し、次に`g`を適用する1つのクォーテーションを返します。

```factor
{ 0 1 } 2 0 translate-2d 2 2 scale-2d compose-transformations
call( p -- p' ) .
! => { 4 2 }
```

## 4. 変換を適用する

`apply-transformation`を定義して、スタックから点と変換クォーテーションを取り出し、変換後の点を返します。

```factor
{ 4 8 } 2 0 translate-2d apply-transformation .
! => { 6 8 }
```

## 5. 一度に多くの点を変換する

`transform-points`を定義して、点の配列と変換クォーテーションを受け取り、変換後の点の配列を返します。

```factor
{ { 0 0 } { 1 1 } { 2 2 } } 1 0 translate-2d transform-points .
! => { { 1 0 } { 2 1 } { 3 2 } }
```
