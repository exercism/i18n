# 説明

完成したFlower Fieldの庭にある空きマスに、花の数を書き込むのが課題です。
庭は長方形の盤で、マスは空きマス（`' '`）か花（`'*'`）のどちらかです。

空きマスごとに、そのマスに隣接する花の数（横・縦・斜め）を数えます。
隣接する花が1つもない空きマスは、空きマスのままにします。
それ以外の場合は、隣接する花の数で置き換えます。

たとえば、次のような5 x 4の盤が渡されることがあります（ここでは画面上に表示するため、空きマスを'·'という文字で表しています）：

```text
·*·*·
··*··
··*··
·····
```

コードはこれを次のように変換します：

```text
1*3*1
13*31
·2*2·
·111·
```
