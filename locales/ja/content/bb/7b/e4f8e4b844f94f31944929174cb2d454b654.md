# 概要

一般的な数学関数は[`math.functions`][math.functions]にあり、定数は[`math.constants`][math.constants]、小数専用のワードがいくつか[`math.libm`][math.libm]にあります。どれもスタックから入力を受け取ります。

```factor
USING: kernel math math.constants math.functions math.libm prettyprint ;

9 sqrt .            ! => 3.0
1.0 1.0 fatan2 .    ! => 0.7853981633974483
```

## 定数

| ワード | 値 |
| --- | --- |
| `pi` | π、3.14159… |
| `e` | *e*、2.71828… |

## 根と累乗

| ワード | スタック効果 | 結果 |
| --- | --- | --- |
| `sqrt` | `( x -- y )` | `x`の平方根 |
| `sq` | `( x -- y )` | `x * x` |
| `^` | `( x y -- z )` | `x`の`y`乗（`y`は整数でなくてもかまいません） |

## 三角関数

| ワード | スタック効果 | 結果 |
| --- | --- | --- |
| `sin` `cos` `tan` | `( x -- y )` | 角度`x`（ラジアン）に対する値 |
| `asin` `acos` `atan` | `( x -- y )` | サイン・コサイン・タンジェントが`x`になる角度（ラジアン） |
| `fatan2` | `( y x -- z )` | 正の`x`方向から点(`x`, `y`)までの角度（ラジアン） |
| `deg>rad` | `( x -- y )` | 度をラジアンに変換したもの |
| `rad>deg` | `( x -- y )` | ラジアンを度に変換したもの |

角度はすべて**ラジアン**です。1周は360ではなく2πです。入出力の境目で変換し、その間はずっとラジアンのまま計算しましょう。

方向を求めるなら、`atan`より`fatan2`（`math.libm`にあります）のほうが優れています。`1 1 / atan`は(1, 1)と(−1, −1)を区別できません。どちらも割ると`1`になるからです。しかも`x`が0のときには失敗します。`fatan2`は2つの符号を見て、−πからπまでの範囲で答えを返します。

```factor
1 1 / atan rad>deg .          ! => 45.0
-1 -1 / atan rad>deg .        ! => 45.0
-1.0 -1.0 fatan2 rad>deg .    ! => -135.0
```

## 指数と対数

| ワード | スタック効果 | 結果 |
| --- | --- | --- |
| `e^` | `( x -- y )` | *e*の`x`乗 |
| `log` | `( x -- y )` | 自然対数。`x`を得るために*e*を累乗する指数 |
| `10^` | `( x -- y )` | 10の`x`乗 |
| `log10` | `( x -- y )` | 底が10の対数 |
| `log2` | `( x -- y )` | 底が2の対数 |

`e^`と`log`は互いに打ち消し合います。`10^`と`log10`も同じです。

一定の割合ずつ減っていくものは、`start * e^(-rate * t)`に従います。`start`から`level`まで下がるのにかかる時間は、`log(start / level) / rate`です。

## 実数の答えがないとき

これらのワードは、変わった入力に対してもエラーを出しません。負の数の平方根や対数は**複素数**の結果になり、普通の数値ではなく`C{ ... }`で囲まれて表示されます。

```factor
-1 sqrt .     ! => C{ 0.0 1.0 }
-1.0 log .    ! => C{ 0.0 3.141592653589793 }
0.0 log .     ! => -1/0.
```

`-1/0.`は負の無限大です。おかしな値を渡す可能性があるなら、呼び出す前に引数を確認しましょう。3回計算したあとで見つかった複素数や無限大は、原因をたどるのが難しくなります。

## 丸めもやはり近似です

これらのワードは正確な値ではなく、最も近い小数を返します。そのため結果を比べるときは、`=`ではなく`~ ( x y epsilon -- ? )`を使って許容誤差つきで比較しましょう。

```factor
pi 6 / sin .             ! => 0.49999999999999994
pi 6 / sin 0.5 = .       ! => f
pi 6 / sin 0.5 1e-9 ~ .  ! => t
```
