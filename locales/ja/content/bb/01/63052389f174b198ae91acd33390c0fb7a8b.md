# はじめに

## `case`式

Gleamでは、`case`式を使って条件に応じてコードを実行できます。`case`式を使うと、ある値を1つ以上の_パターン_と照合できます。そうしたパターンの1つが_リテラルパターン_で、これは値をリテラル値（例えば`1`や`"hello"`）と照合します。

`case`式は`case`キーワードを使って書きます。

```gleam
pub fn describe(number: Int) -> String {
  case number {
    0 -> "Zero"
    1 -> "One"
  }
}
```

他の言語の`switch`文と似ているように見えるかもしれませんが、パターンマッチングの真価は、他のパターンも組み合わせたときに発揮されます。そのようなパターンの1つが_変数パターン_で、値に変数を割り当てることができます。次の例では、`number`が`0`でなければ、変数`i`にその値が割り当てられます。

```gleam
pub fn describe(number: Int) -> String {
  case number {
    0 -> "Zero"
    i -> "Non zero"
  }
}
```

パターンに条件を追加したい場合もあります。これは_ガード_（節）と呼ばれ、`if`キーワードを使って追加できます。

```gleam
pub fn describe(number: Int) -> String {
  case number {
    0 -> "Zero"
    i if i < 0 -> "Negative number"
  }
}
```

パフォーマンス上の理由から、ガードに使えるのは基本的な数学演算子と真偽値演算子だけです。他の関数をガードの中で使うことはできません。

上の例では、すべての入力に一致するパターンがあるわけではありません。コンパイラーがこれを検出し、エラーを出力します。これは_網羅性チェック_と呼ばれます。警告を解消するには、すべてのケースを処理する必要があります。そのために使えるのが_破棄パターン_で、どんな値にも一致するパターンです。

```gleam
pub fn describe(number: Int) -> String {
  case number {
    0 -> "Zero"
    i if i < 0 -> "Negative number"
    _ -> "Positive number"
  }
}

// No compiler error
```

1つの節で複数のパターンを照合できます。各パターンは`|`で区切ります。ガードは1つの節に1つだけ追加できます。

```gleam
pub fn describe(number: Int) -> String {
  let yell = True
  case number {
    0 -> "Zero"
    3 | 5 -> "One of the first odd prime numbers"
    2 | 4 | 6 | 8 if !yell -> "One of the even numbers less than 10"
    i if i % 2 == 0 && yell -> "[Yelling] I'm telling you! It's a even nunber"
    i if i < 0 -> "Negative number"
    _ -> "Positive number"
  }
}
// No compiler error
```

`case`式は、上から順にそれぞれのパターンと値を照合し、一致するパターンを見つけると、そのパターンに対応する処理を実行します。パターンの順番が重要です！
