# 指示

この演習では、お気に入りの料理本をもとに、最高のラザニアを作るためのコードを書きます。

4つのタスクがあり、どれもラザニアの調理にかかる時間に関するものです。

## 1. オーブンでの想定加熱時間（分）を定義する

ラザニアをオーブンに入れておくべき時間を分で返す定数`Lasagna::EXPECTED_MINUTES_IN_OVEN`を定義します。料理本によると、オーブンでの想定加熱時間は40分です。

```ruby
Lasagna::EXPECTED_MINUTES_IN_OVEN
# => 40
```

## 2. 残りのオーブン加熱時間（分）を計算する

ラザニアが実際にオーブンに入っていた時間を分で入力として受け取り、前のタスクで求めた想定加熱時間を基に、ラザニアをあと何分オーブンに入れておく必要があるかを返すメソッド`Lasagna#remaining_minutes_in_oven`を定義します。

```ruby
lasagna = Lasagna.new
lasagna.remaining_minutes_in_oven(30)
# => 10
```

## 3. 準備時間（分）を計算する

ラザニアに重ねた層の数を入力として受け取り、1層あたり2分かかると仮定して、ラザニアの準備に何分かかったかを返すメソッド`Lasagna#preparation_time_in_minutes`を定義します。

```ruby
lasagna = Lasagna.new
lasagna.preparation_time_in_minutes(2)
# => 4
```

## 4. 合計作業時間（分）を計算する

メソッド`Lasagna#total_time_in_minutes`を定義します。このメソッドは2つの名前付き入力を受け取ります。`number_of_layers`はラザニアに重ねた層の数で、`actual_minutes_in_oven`はラザニアがオーブンに入っていた時間（分）です。このメソッドは、ラザニアの調理に合計で何分かかったかを返す必要があります。合計は、準備にかかった時間（分）と、その時点でラザニアがオーブンに入っていた時間（分）を足したものです。

```ruby
lasagna = Lasagna.new
lasagna.total_time_in_minutes(number_of_layers: 3, actual_minutes_in_oven: 20)
# => 26
```
