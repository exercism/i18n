# 指示の補足

## セットアップ

必要な依存関係をインストールするために、TypeScriptのセットアップ手順を確認しましょう：

[https://exercism.org/docs/tracks/typescript/installation](https://exercism.org/docs/tracks/typescript/installation)

## 必要なもの

課題の依存関係をインストールします：

```bash
$ yarn install
```

## テストスイートをパスさせるには

次のコマンドでテストを実行します：

```bash
$ yarn test
```

多くのテストスイートでは、最初のテスト以外はすべてスキップされています。

テストが1つ通ったら、`xit`を`it`に変えると、次のテストのスキップを解除できます。

## チュートリアル

ここでは、この演習を解く手順を順を追って説明します。

この演習には2つのファイルがあります：

- hello-world.ts
- hello-world.test.ts

1つ目のファイルにコードを書きます。
2つ目のファイルにはテストが定義されています。

テストは、書いたコードが正しく動いているかを確認してくれます。
テストスイートを一から書ける必要はありませんが、テストがどんな見た目で、何をしているのかを理解しておくと役立ちます。

テストファイルのhello-world.test.tsを開いてみましょう。
中にはテストが1つだけあります：

```typescript
it('says hello world', () => {
  expect(hello()).toEqual('Hello, World!')
})
```

では、コマンドラインで次のコマンドを実行して、テストを走らせてみましょう：

```bash
$ yarn test
```

テストは失敗します。まだコードを書いていないのですから、当然ですね。

失敗すると、次のように表示されます：

```
    × says hello world (5ms)

  ● Hello World › says hello world

    expect(received).toEqual(expected) // deep equality

    Expected: "Hello, World!"
    Received: "Goodbye, Mars!"

      4 |
      5 |   it('says hello world', () => {
    > 6 |     expect(hello()).toEqual('Hello, World!')
        |                     ^
      7 |   })
      8 |
      9 | })

      at Object.it (hello-world.test.ts:6:32)
```

そして、これが`hello-world.test.ts`ファイルの中で問題がありそうなコードの行です：

6行目：

```typescript
    expect(hello()).toEqual('Hello, World!')
                    ^
```

つまり、問題は`hello()`の呼び出しにあります。
テストは`'Hello, World!'`を出力として期待しているのに、実際には`"Goodbye, Mars!"`が返ってきていることがわかります。

では、`hello-worlds.ts`ファイルのこの関数を確認してみましょう：

```typescript
export function hello(): string {
  return 'Goodbye, Mars!'
}
```

関数が間違った文字列を返しているのが、失敗の原因です。戻り値を変えて修正しましょう：

```typescript
export function hello(): string {
  return 'Hello, World!'
}
```

もう一度テストを実行してみましょう：

```bash
 PASS  ./hello-world.test.ts
  Hello World
    √ says hello world (4ms)
```

今度は通りました！
