# 説明の追記

この演習を解く方法はたくさんありますが、この演習は、自分で[abilityハンドラー][ability-handler-docs]を書く練習をしたい人向けに作られています。

`Zipper`というabilityを書いて、二分木のデータ構造の中をたどれるようにしましょう。

`Zipper`というability自体はすでに定義されているので、あとは、用意された二分木のデータ構造をたどれるようにするハンドラーを実装するだけです。

次の二分木があるとします。ここで`Zipper.right`、`Zipper.right`、`Zipper.up`、`Zipper.left`の順に呼び出すと、値が`5`のノードに立っているはずです。

```
     1
   /   \
  2     4
 /     /  \
3     5    7
```

この演習では、左右の枝がない二分木に対して`left`や`right`を呼び出したときは、現在のノードの値をそのまま返してかまいません。
