# はじめに

`Integer`は、マシンのメモリの許す限り、どんなに大きな数でも保持できます。一方、`Int`は、32ビットまたは64ビットで表現できる正負の整数の集合に対応します（少なくとも-2^29から2^29までが保証されています）。

`Float`は実数の集合に対応し、コンピューターの精度によって制限されます。

数値に対して定義された演算は、ふつうどちらか一方の型では機能しますが、両方では機能しません。

`Float`と`Integer`の間で変換する関数には、`Int`/`Integer`を`Float`に変換する`toFloat`や、`Float`を`Int`に変換する`ceiling`などがあります。

整数型（`Int`または`Integer`）から他の数値型への変換には、関数`fromIntegral`を使います。
変換先の型は自動的に推論されます。
たとえば、次のようになります。

```haskell
n :: Integer
n = 6
x :: Float
x = fromIntegral n      --> x = 6.0

m :: Int
m = 7
y :: Double
y = fromIntegral m      --> y = 7.0
```
