# 文字列について

Kotlinの[`string`][ref-string]は、Unicode文字の不変なシーケンスです。

[`Immutable`][wiki-immutable]とは、文字列に対するどんな操作も新しい文字列を返さなければならないということです。元の文字列が変わることは決してありません。

[`Unicode`][wiki-unicode]とは、世界のほとんどの文字体系を表現できるという意味ですが、（Cのような古い言語とは対照的に）文字とバイトの間に1対1の対応はありません。
これについては、[`Chars`][concept-chars]の概念でさらに詳しく説明します。

文字列は二重引用符（`" "`）で囲みます。

一部の文字はエスケープが必要です。`\\`のほか、`\t`（タブ）や`\n`（改行）のような一般的な非表示文字も同様です。

```kotlin
val s = "Escape backslash \\."
// Escape backslash \.
```

複数行文字列は3つの二重引用符で囲み、任意のテキストを含めることができます（エスケープは不要です）。

```kotlin
val multi = """I'm a
    multi-line
    string with special characters \ \t """
//I'm a
//    multi-line
//    string with special characters  \ \t 
```

[`trimIndent`][trimIndent-doc]を使うと、各行に共通するインデントを取り除けます。
これは文字列を整形するのに便利です。

```kotlin
val multi = """
    I'm a
      multi-line
    string""".trimIndent()

//I'm a
//  multi-line
//string
```

別の方法として、[`trimMargin`][trimMargin-doc]を使うと区切り文字を指定できます。
すると、`String`内の各行は区切り文字の後から始まります。
区切り文字の既定値は`|`ですが、別の区切り文字を仮引数として指定できます。
たとえば、次のようにします。

```kotlin
val multi = """
    |I'm a
    |  multi-line
    |string""".trimMargin()

//I'm a
//  multi-line
//string

val multi2 = """
    start>I'm a
    start>  multi-line
    start>string""".trimMargin("start>")

//I'm a
//  multi-line
//string
```

文字列は`+`で連結できますが、短く単純な場合に限るのがよいでしょう。
ほかにも、多くの場合よりよい方法があります。

## 文字列テンプレート

[`Templates`][ref-templates]は、ほかの言語で「補間」と呼ばれているものです。

文字列にドル記号`$`の後に識別子が続く場合、または式を囲む波括弧（`{expression}`）が含まれる場合、それらはそれぞれ値または式の結果に置き換えられます。

```kotlin
val x = 42
val st = "x is $x, x squared is {x * x}"
// x is 42, x squared is 1764
```

## 文字列の書式設定

JVMプラットフォームの場合に限り、`String.format()`を使うと、文字列テンプレートより精密な書式設定ができます。その[構文][web-formats]は、（とても古い！）[`printf`][wiki-printf]関数に似ています。

```kotlin
String.format("%s %.3f", "π ≈", 3.14159)
//π ≈ 3.142
```

## 文字列関数

Kotlinには、文字列を操作するための_たくさんの_[`functions`][ref-string-functions]があります。

ほとんどの場合、これらは`String`クラスのメンバーではなく[`extensions functions`][ref-extensions]ですが、使い方にはほとんど影響しません。

~~~~exercism/note
Kotlinのやや複雑な[ドキュメント][ref-string-functions]ページでは、既定の表示で拡張関数が隠れています。
これを書いている時点では、最も価値のある内容は`Members & Extensions`というタブに隠されています。
それをクリックしてこのセクションを展開すると、`String`クラスで利用できるすべてのメンバーと拡張機能が表示されます。

[ref-string-functions]: https://kotlinlang.org/api/core/kotlin-stdlib/kotlin/-string/
~~~~

次の例は、利用できるもののほんの一部を示しています。

```kotlin
val str = "Hello World!"

str.length              // => 12 (a property, not a function)
str.elementAt(6)        // => W
str.elementAtOrNull(20) // => null (index out of range)
str.substring(6, 11)    // => "World"
str.substringAfter(" ") // => "World!"

str.lowercase()         // => "hello world!"
str.uppercase()         // => "HELLO WORLD!"

str.startsWith("Hel")   // => true
str.endsWith("xyz")     // => false
str.indexOf("0")        // => 4

str.toCharArray()       // => [H, e, l, l, o,  , W, o, r, l, d, !]
"42".toInt() + 1        // => 43  (parsing; see also toFloat)

"Howdy!  ".trim()       // => "Howdy"
```

## 文字列を組み立てる

長い文字列を段階的に組み立てる必要があることもあります。たとえばループの中などです。

文字列を`+`で連結すると、まもなくエレガントでも高性能でもなくなります。不変であるということは、_大量の_コピーが必要になるということです。

Kotlinには、複数の文字列を組み合わせるより効率的な方法がいろいろあります。

- 文字列テンプレート。前述のとおりです。
- [`joinToString()`][ref-jointostring]。これは[配列][concept-lists]の概念で扱います。
- Javaの[`StringBuilder`][ref-stringbuilder]。これはKotlinらしい書き方とはあまりみなされていません。
- Kotlinの[`buildString()`][ref-buildstring]。これは`StringBuilder`をより簡潔で慣用的な構文で包みます。
これは文字列組み立てのロジックをラムダの引数として受け取ります。このラムダについては、後の概念で説明します。

本質的に、`StringBuilder`はリストのような構造で、便利なメソッドがたくさんあります。
以下はその一部です。

- [`append()`][ref-sb-append]で末尾に追加します。
- [`insert()`][ref-sb-insert]で指定した位置に追加します。
- [`deleteAt()`][ref-sb-deleteat]と[`deleteRange()`][ref-sb-deleterange]で指定した位置から削除します。
- `toString()`で最後に通常の文字列に変換します。すべてを一度の高性能な操作で連結します。

```kotlin
// Available, not recommended
val sb = StringBuilder()
sb.append("Hello ")
sb.append("World!")
sb.toString()
//Hello World!
```

後の概念の構文を使った`buildString()`の例です。

```kotlin
val countDown = buildString {
    for (i in 5 downTo 1) {
        append(i)
        append("_")
    }
}
// countDown is "5_4_3_2_1_"
```
