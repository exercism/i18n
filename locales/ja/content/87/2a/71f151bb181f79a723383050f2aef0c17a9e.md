# 説明

Blorkemon™️のカードへの懐かしさは、ますます強くなるばかりです。気づけばまた集め始めていて、友達まで誘ってしまっています。

この演習では、カードのコレクションを`Set(String)`で表します。というのも、存在するカードをすべて集めることが目的なら、重複したカードは重要ではないからです。

## 1. コレクションを始める

友達にもBlorkemon™️の世界にハマってほしいですよね。その一番の近道は、カードを1枚あげてコレクションのきっかけを作ることです。

カードをコレクションに変換する`new_collection`を実装しましょう。

```gleam
new_collection("Newthree")
// -> set.from_list(["Newthree"])
```

## 2. コレクションを育てる

いったんコレクションができると、それはもう一人歩きを始めます。育てていかなくてはなりません。

カードとコレクションを受け取り、2つの値からなるタプルを返す`add_card`を実装しましょう。1つ目は、そのカードがすでにコレクションに入っていたかを示す`Bool`、2つ目はカードを追加したコレクションです。

```gleam
add_card(set.from_list(["Newthree"]), "Scientuna")
// -> #(False, set.from_list(["Newthree", "Scientuna"]))
```

## 3. 交換を始める

友達もまたBlorkemon™️に夢中になった今、カードを交換して自分のコレクションを育てられます。

すべての交換が価値あるものとは限りませんし、そもそもできないこともあります。
持っていないカードは交換に出せませんし、すでに持っているカードと交換するべきでもありません。

交換する2枚のカード（自分のものと相手のもの）と、今のコレクションを受け取る`trade_card`を実装しましょう。
戻り値は2つの値からなるタプルです。1つ目は、その交換が可能で、しかも価値があるかを示す`Bool`、2つ目は交換した場合に最終的に手に入るコレクションです（実際には不可能でも構いません）。

```gleam
trade_card("Scientuna", "Newthree", set.from_list(["Scientuna"]))
// -> #(True, set.from_list(["Newthree"]))
```

## 4. みんなが持っているカード

Blorkemon™️好きの友達と集まって、どのカードが一番よくあるのか気になります。

コレクションのリストを受け取り、すべてのコレクションが持っているカードをソートしたリストで返す`boring_cards`を実装しましょう。

```gleam
boring_cards([set.from_list(["Scientuna"]), set.from_list(["Newthree", "Scientuna"])])
// -> ["Scientuna"]
```

## 5. すべてのカード

友達と力を合わせれば、Blorkemon™️のカードを全部持っていることになるのでしょうか？

コレクションのリストを受け取り、すべてのコレクションにある異なるカードの総数を返す`total_cards`を実装しましょう。

```gleam
total_cards([set.from_list(["Scientuna"]), set.from_list(["Newthree", "Scientuna"])])
// -> 2
```

## 6. キラキラで決まり

もうすぐ甥っ子が遊びに来ます。ここはひとつ、かっこいいところを見せたいですね。
子どもはキラキラしたものが好きですよね？　Blorkemon™️のカードもキラキラにできるんです！

コレクションを受け取り、`"Shiny "`で始まるカードをすべて含むセットを返す`shiny_cards`を実装しましょう。

```gleam
shiny_cards(set.from_list(["Newthree", "Scientuna", "Shiny Scientuna"]))
// -> set.from_list(["Shiny Scientuna"])
```
