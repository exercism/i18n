# 説明

この演習では、ログ行を処理します。

各ログ行は、`"[<LEVEL>]: <MESSAGE>"`という形式の文字列です。

ログレベルは次の3つです。

- `INFO`
- `WARNING`
- `ERROR`

タスクは3つあります。それぞれのタスクでは、ログ行を1つ受け取り、それに対して何らかの処理を行います。

## 1. ログ行からメッセージを取得する

ログ行のメッセージを返す（_static_）`LogLine.Message()`メソッドを実装しましょう。

```csharp
LogLine.Message("[ERROR]: Invalid operation")
// => "Invalid operation"
```

先頭と末尾の空白は取り除きます。

```csharp
LogLine.Message("[WARNING]:  Disk almost full\r\n")
// => "Disk almost full"
```

## 2. ログ行からログレベルを取得する

ログ行のログレベルを小文字で返す（_static_）`LogLine.LogLevel()`メソッドを実装しましょう。

```csharp
LogLine.LogLevel("[ERROR]: Invalid operation")
// => "error"
```

## 3. ログ行を整形する

ログ行を整形する（_static_）`LogLine.Reformat()`メソッドを実装しましょう。メッセージを先に、ログレベルをその後ろに括弧（`()`）で囲んで置きます。

```csharp
LogLine.Reformat("[INFO]: Operation completed")
// => "Operation completed (info)"
```
