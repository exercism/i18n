# 説明の補足

## ワード

`numerator`と`denominator`のスロットを持つ`rat`タプルを定義してください。
`<rat>`は、引数を約分して、符号を分子に付けます（そのため、分母は常に正になります）。

- `<rat> ( numerator denominator -- rat )`は、約分された有理数を作ります。
- `>rat ( pair -- rat )`は、`{ numerator denominator }`から`rat`を作ります。
- `rat>pair ( rat -- pair )`は、`{ numerator denominator }`を返します。
- `r+ ( a b -- c )`、`r- ( a b -- c )`、`r* ( a b -- c )`、`r/ ( a b -- c )`は、2つの有理数に対する四則演算を行います。
- `r-abs ( a -- |a| )`は、絶対値を返します。
- `r^ ( a n -- a^n )`は、有理数を整数乗します（負の指数も使えます）。
- `real^r ( x a -- y )`は、実数を有理数乗して、小数を返します。

Factorの`MATH:`ジェネリック（`+`、`-`、`*`、`/`）は、組み込みの数値階層に対してしかディスパッチできないため、この演習では、それらのジェネリックにメソッドを定義するのではなく、専用のワード名を使います。
