# ヒント

## 1. `GbTree`外部型を定義する

- 外部型は`pub type TypeName(a, b, c)`という構文で定義できます。

## 2. `new_gb_tree`関数を定義する

- 外部関数は`@external(erlang, "module", "function")`という構文で定義できます。
- この関数では`gb_trees:empty/0`を使います。

## 3. `insert`関数を定義する

- `gb_trees:insert/3`のドキュメントを確認して、引数の正しい順序を確かめましょう。
- 外部関数は、引数の順序を入れ替えるために`insert`関数から呼び出されるプライベート関数にできます。
- この関数では`gb_trees:insert/3`を使います。

## 4. `delete`関数を定義する

- `gb_trees:delete_any/2`のドキュメントを確認して、引数の正しい順序を確かめましょう。
- 外部関数は、引数の順序を入れ替えるために`delete`関数から呼び出されるプライベート関数にできます。
- この関数では`gb_trees:delete_any/2`を使います。
- `gb_trees:delete/2`関数は、キーが見つからないとクラッシュするため、使うべきではありません。
