# はじめに

`List`は`Array`とよく似ています。ただし、見逃せない大きな違いがいくつかあります。

1. リストは角括弧（`[]`）、つまり`[0]`のような書き方でインデックスを付けられません。
2. リストは初期化できません。
3. リスト内包表記はありません。
4. リストは、繰り返し処理の最中でも要素を自由に変更できます。

`List`は`haxe.ds`パッケージに含まれているので、リストを使いたいときは毎回そのパッケージをインポートする必要があります。

```haxe
import haxe.ds.List;

class Main {
  static function main() {
    var myList = List<Int>();

    for (i in 0...5) {
      myList.add(i);
    }

    trace(myList); // {0, 1, 2, 3, 4}
  }
}
```
