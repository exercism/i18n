# 説明

アントワープ操車場では、また忙しい夜が始まりました。今晩の当直は操車係です。入ってくる貨車を行き先ごとの列車に組み直し、連結器を点検し、分岐点でルートを分け、同じ貨物は請求のためにひとまとめにしなければなりません。

それぞれの*貨車*は、積んでいるものを表す文字列です。たとえば`"coal"`、`"timber"`、`"crates"`などです。

## 1. 貨車をつないで列車にする

`couple`を定義して、貨車の配列と長さ`n`を受け取り、それぞれ`n`両の貨車からなる、重なりのない列車を返すようにしましょう。貨車の数が割り切れない場合、最後の列車は短くなってもかまいません。

```factor
{ "coal" "coal" "coke" "ore" "ore" "timber" "timber" } 3 couple .
! => { { "coal" "coal" "coke" } { "ore" "ore" "timber" } { "timber" } }
```

## 2. 連結器をのぞく

`peek-couplings`を定義して、貨車の配列を受け取り、隣り合う貨車のペアをすべて返すようにしましょう。そうすれば、点検員がそれぞれの連結器を調べられます。

```factor
{ "coal" "ore" "timber" "crates" } peek-couplings .
! => { { "coal" "ore" } { "ore" "timber" } { "timber" "crates" } }
```

## 3. 分岐点で編成を分ける

`split-at-junctions`を定義して、貨車の配列と、`junctions`（切れ目を表す貨車）の配列を受け取り、分岐点の貨車の間にある区間を返すようにしましょう。分岐点の貨車自体は残しません。

```factor
{ "coal" "coal" "switch" "ore" "switch" "timber" }
{ "switch" } split-at-junctions .
! => { { "coal" "coal" } { "ore" } { "timber" } }
```

## 4. 同じ貨物をまとめる

`coalesce-cargo`を定義して、貨車の配列を受け取り、同じ貨物を積んだ*連続する*貨車をまとまりにグループ化するようにしましょう。

```factor
{ "coal" "coal" "ore" "ore" "ore" "timber" "coal" } coalesce-cargo .
! => { { "coal" "coal" } { "ore" "ore" "ore" } { "timber" } { "coal" } }
```
