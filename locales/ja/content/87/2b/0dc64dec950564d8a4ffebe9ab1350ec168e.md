# 説明

ここは、風変わりな遺言の依頼を専門に扱う一流の法律事務所です。

この演習では、謎に包まれた金庫を開けることになります。遺言執行者として、3つの家系が長く守ってきた秘密のコードを組み合わせ、口座番号とそれに対応するコードを手に入れましょう。

どの家系も単独では金庫を開けられないようにするため、金庫は、それぞれの家系の知識に、遺言から知ることになる秘密の修飾子を組み合わせたときにだけ開くようになっています。

家系が金庫を開けるのを手助けするための、3つのタスクがあります。

## 1. 家系の人々の前に席に着き、書類を広げる

`EstateExecutor`という名前の名前空間を定義します。以降のタスクのコードは、`EstateExecutor`名前空間の本体の中に定義します。

```ruby
class SomeName
  # The space between the class/module name
  # and the `end` keyword
  # is called body of the  namespace.
end
```

## 2. 秘密の口座番号を見つける

いよいよ本番です。秘密の口座番号を明かすための秘密の修飾キーを持っているのは、ここでは1人だけです。

`Integer`の秘密の修飾子を引数に取り、組み立てられた口座番号を`Integer`として返す、`assemble_account_number(secret_modifier)`メソッドを定義します。

正しい番号を求めるには、3つの家系それぞれの`bank_number_part`を合計します。

## 3. 最後のステップ：秘密のコードを入力する

遺言の指示では、まず青い断片をすべて足し、次に赤い断片をすべて足すよう求められています。できあがるコードは、この2つの合計を掛け合わせることで得られます。

3つの家系の断片を組み合わせて1つの`Integer`の結果とし、できあがるコードを返す`assemble_code`メソッドを定義します。このメソッドは引数を取らず、家系の該当する名前空間にある情報だけを使います。
