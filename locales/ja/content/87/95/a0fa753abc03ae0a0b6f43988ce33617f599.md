# はじめに

`Option`型は、値が存在する場合と存在しない場合を表すために使います。

`gleam/option`モジュールでは、次のように定義されています。

```gleam
type Option(a) {
  Some(a)
  None
}
```

`Some`コンストラクターは、値が存在するときにその値を包むために使い、`None`コンストラクターは、値が存在しないことを表すために使います。

`Option`の中身にアクセスするには、パターンマッチングをよく使います。

```gleam
import gleam/option.{type Option, None, Some}

pub fn say_hello(person: Option(String)) -> String {
  case person {
    Some(name) -> "Hello, " <> name <> "!"
    None -> "Hello, Friend!"
  }
}
```

```gleam
say_hello(Some("Matthieu"))
// -> "Hello, Matthieu!"

say_hello(None)
// -> "Hello, Friend!"
```

`gleam/option`モジュールには、`Option`型を扱うのに便利な関数もいくつか定義されています。たとえば`unwrap`は、`Option`の中身を返す関数で、`None`の場合はデフォルト値を返します。

```gleam
import gleam/option.{type Option}

pub fn say_hello_again(person: Option(String)) -> String {
  let name = option.unwrap(person, "Friend")
  "Hello, " <> name <> "!"
}
```
