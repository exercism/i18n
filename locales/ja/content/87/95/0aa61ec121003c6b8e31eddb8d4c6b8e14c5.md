# はじめに

## 継承

C#では、_継承_を使って_クラス_の階層を定義できます。継承を使うと、派生クラス（`Car`）が親クラス（`Vehicle`）の振る舞いとデータを引き継げます。親クラスを指定しない場合、そのクラスは`object`クラスを継承します。

親クラスは、次の3つの方法で派生クラスに機能を提供できます。

- 通常のメソッドを定義します。
- `virtual`メソッドを定義します。これは通常のメソッドに似ていますが、派生クラスが変更_できる_メソッドです。
- `abstract`メソッドを定義します。これは実装を持たないメソッドで、派生クラスが必ず実装しなければならないものです。`abstract`メソッドを持つクラスは、そのクラス自体も`abstract`としてマークする必要があります。抽象クラスはインスタンス化できません。

`protected`アクセス修飾子を使うと、親クラスのメンバーに派生クラスからアクセスできますが、他のクラスからはアクセスできません。

派生クラスは、`base`キーワードを通じて親クラスのメンバーにアクセスできます。

```csharp
// Inherits from the 'object' class
abstract class Vehicle
{
    // Can be overridden
    public virtual void Drive()
    {
    }

    // Must be overridden
    protected abstract int Speed();
}

class Car : Vehicle
{
    public override void Drive()
    {
        // Override virtual method

        // Call parent implementation
        base.Drive();
    }

    protected override int Speed()
    {
        // Implement abstract method
    }
}
```

派生クラスのコンストラクターは、自身のコンストラクターの処理を実行する_前に_、親クラスのコンストラクターを自動的に呼び出します。親クラスのコンストラクターには、`base`キーワードを使って引数を渡せます。

```csharp
abstract class Vehicle
{
    protected Vehicle(int wheels)
    {
        Console.WriteLine("Called first");
    }
}

class Car : Vehicle
{
    public Car() : base(4)
    {
        Console.WriteLine("Called second");
    }
}
```

複数のクラスが1つの基底クラスから派生している場合、それら2つ（またはそれ以上）のクラスは、基底クラスのメソッドに対してしばしば異なるバージョンを実装します。これはポリモーフィズムと呼ばれる、とても重要な原則です。たとえば、上の例を少し変えた次の例では、`Vehicle`を使うコードが、どの種類の乗り物がインスタンス化されたかに応じて振る舞いを変えられることを示しています。

```csharp
abstract class Vehicle
{
   public abstract string GetDescription();
}

class Car : Vehicle
{
   public Car()
   {
   }

   public override string GetDescription()
   {
      return "Runabout";
   }
}

class Rig : Vehicle
{
   public Rig()
   {
   }

   public override string GetDescription()
   {
      return "Big Rig";
   }
}

Vehicle v1 = new Car();
Vehicle v2 = new Rig();

v1.GetDescription();
// => Runabout
v2.GetDescription();
// => Big Rig
```
