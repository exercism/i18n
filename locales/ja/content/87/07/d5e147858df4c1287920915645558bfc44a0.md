## ごく簡単な歴史

数十年前には、コンピューターで文字を扱うのはもっとずっと簡単でした。プログラマーは、英語だけが重要な言語だと考えていたからです。
つまり、大文字と小文字のアルファベット26文字、数字10文字、いくつかの句読点、それにベルを鳴らすためのコード（0x07）で、すべてが7ビットに収まりました。それが[ASCII][wiki-ascii]文字セットです。

当然、àやä、Łはどうするのかと人々が尋ね始め、次にऄやஹ、ญはどうするのかと別の人々が尋ね始め、若い人たちは絵文字を欲しがりました😱。
どうすればいいのでしょうか？

手短に言えば、多くの賢く辛抱強い人たちが何年も委員会に参加して、[Unicode][web-unicode]文字セットや[UTF-8][wiki-utf-8]のようなエンコーディングの詳細を詰めなければなりませんでした。そして、たくさんのソフトウェアが_とても_複雑な書き直しを必要としました。
さらに、たくさんの新しいバグも生まれました。

_すべて_が壊れてしまうのを防ぐため、Unicode/UTF-8の設計では、最初の127個のコードがASCIIとまったく同じになるようにしています_（ベルを鳴らすコードも含めて）_。

## Kotlinの文字

2005年以降に設計された言語には、すでにかなり安定したUnicode標準が存在していたという大きな利点があります。

Kotlin（最初のリリースは2011年）は、利用者がさまざまな（人間の）言語を使い、それらを表現するためにUnicodeが必要になると想定できました。

文字リテラルはシングルクォートで書き、ダブルクォートで書く文字列とは別のものです。
CやC++の世界の人には当然かもしれませんが、PythonやJavaScriptのプログラマーには戸惑うところかもしれません。

```kotlin
val a = 'a'
a::class.qualifiedName  // => kotlin.Char
a.code  // => 97

val jha = 'झ'  // Devanagari alphabet
jha.code  // => 2333

val heart = '❤'  // heart emoji
heart.code  // => 10084

Char.MAX_VALUE.code  // => 65535 (64k, the largest code point allowed)
```

`Char`と`Int`の相互変換は簡単です：

```kotlin
a.code  // => 97  (a.toInt() is deprecated)
Char(97) // => 'a'
```

コンパイラーは、`Char`に対する_一部の_整数演算を許可しています：

```kotlin
'a' + 5       // => 'f'
'c' - 'a'   // => 2
'c' + 'a'   // => error!

'f' + ('A' - 'a')  // => 'F' (same as 'f'.uppercase()

'f'.dec() // => 'e' (decrement)
'f'.inc() // => 'g' (increment)
```

## `Char`のいくつかの関数

いつもながら、ここで扱うには[たくさんの関数][ref-char-lib]がありすぎるので、ほんの一部だけを紹介します。

- 対応しているアルファベットなら、[`uppercase()`][ref-uppercase]と[`lowercase()`][ref-lowercase]で大文字と小文字を切り替えられます。
- 大文字か小文字かは、[`isUpperCase()`][ref-isuppercase]と[`isLowerCase()`][ref-islowercase]で判定できます。
- 文字の種類は、次のもので判定できます：
    - [`isLetter()`][ref-isletter]：多くのアルファベットをカバーします
    - [`isDigit()`][ref-isdigit]：0〜9の範囲です
    - `isLetterOrDigit()`：前の2つを組み合わせたものです
    - [`isWhitespace()`][ref-iswhitespace]：あらゆる空白文字です

```kotlin
'झ'.isLetter()      // => true
'A'.isLowerCase()   // => false
'4'.isDigit()       // => true
'\t'.isWhitespace() // => true  (tab character)
```

## CharのリストとStringの相互変換

StringからCharのリストへは、`toList()`を使います。

CharのリストからStringへは、[`joinToString()`][ref-jointostring]関数があります。これは区切り文字（多くの場合は空文字列）を渡します。

```kotlin
val kt = "kotlin".toList()  // => [k, o, t, l, i, n]
kt.joinToString("")   // => "kotlin"
kt.joinToString("_")  // => "k_o_t_l_i_n"
```

`joinToString()`はListまたはArrayに対して動作することに注意してください。
1つの`Char`を1文字の文字列に_キャスト_するには、`toString()`を使います。

```kotlin
'a'.toString() // => "a"
```

ある文字が`String`の中に、あるいはCharのリストや配列の中に存在するかどうかを調べるには、`in`を使います。これは[`contains()`][ref-contains]関数に対応します。

```kotlin
val clist = "kotlin".toList()  // => [k, o, t, l, i, n]
't' in clist     // => true
't' in "kotlin"  // => true
```
