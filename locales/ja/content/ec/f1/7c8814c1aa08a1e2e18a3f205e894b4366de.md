# Break, Continue

ループや繰り返しの制御構造を使うときは、`break`と`continue`のキーワードがプログラムの流れを制御するのに役立ちます。
`break`キーワードはループの内側から外側のスコープへ抜け出し、ループを終了させます。
`continue`キーワードは、現在の繰り返しの残りの部分を飛ばして、次の繰り返しの先頭からループを再開します。
めったにありませんが、キーワードに数値を付けて、いくつのループから抜け出すか、あるいはいくつの繰り返しを飛ばして次に進むかを制御できます。

```php
<?php
$i = 1;
while ($i <= 10) {

    if ($i <= 5) {
        i += 1;
        continue;
    }
    break;
}
```

前の例では、`continue`は5回実行されますが、6回目の繰り返しで`break`が実行され、コードはループを抜けます。
