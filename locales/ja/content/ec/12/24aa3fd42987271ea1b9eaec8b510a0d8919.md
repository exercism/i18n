# はじめに

`jq`がJSONと同じデータ型をサポートしていることを思い出してください。
JSONは**文字列**を次のように説明しています：

> 文字列とは、0個以上のUnicode文字からなる並びで、二重引用符で囲み、バックスラッシュによるエスケープを用います。

## エスケープシーケンス

文字列の中では、バックスラッシュ文字を使って「特別な」文字を埋め込みます：

- `\"` 引用符そのもの
- `\\` バックスラッシュそのもの
- 空白文字 `\n`、`\t`、`\r`、`\f`、`\b`
- Unicode文字 `\uAAAA`（`A`は16進数の桁）

## 文字列の長さ

文字数を調べるには、`length`関数を使います。

```sh
$ jq -cn --args  '$ARGS.positional[] | length' "Hello world!" "❄🌡🤧🤒🏥🕰😀"
12
7
```

## 部分文字列

**スライス**記法を使うと、部分文字列を取り出せます。
構文は`.[i:j]`です。
返される部分文字列の長さは`j - i`で、インデックス`i`からインデックス`j`までの文字を返します（`i`は含み、`j`は含みません）。
どちらのインデックスも負の値にでき、その場合は文字列の末尾から逆向きに数えます。
どちらのインデックスも省略でき、その場合は文字列の先頭または末尾を指します。
インデックスは0から始まります。

```jq
"abcdefghij"[3:6]   # => "def"
"abcdefghij"[3:]    # => "defghij"
"abcdefghij"[:-2]   # => "abcdefgh"
```

## 連結

`+`を使うと、文字列を連結できます：

```jq
"Hello" + " " + "world!"
# => "Hello world!"
```

文字列の配列がある場合は、`add`を使います：

```jq
["Hello", " ", "world!"] | add
# => "Hello world!"
```

## 分割と結合

分割には`split/1`関数か`/`演算子を使います：

```jq
"Hello beautiful world!" | split(" ")   # => ["Hello", "beautiful", "world!"]
```

```jq
"Hello beautiful world!" / " "          # => ["Hello", "beautiful", "world!"]
```

`split/1`の逆は`join/1`です。

文字列を文字の配列に変換する必要はよくあります。
これには2つの方法があります：

1. 空文字列で分割する

   ```jq
   "Hi friend 😀" / ""   # => ["H","i"," ","f","r","i","e","n","d"," ","😀"]
   ```

1. `explode`で_コードポイント_の配列に変換する

   ```jq
   "Hi friend 😀" | explode   # => [72,105,32,102,114,105,101,110,100,32,128512]
   ```

   `implode`は`explode`の逆です。

## 部分文字列のインデックスを探す

`index/1`関数を使います。インデックスは0から始まります。

```jq
"hello" | index("el")'   # => 1
```

部分文字列が文字列の中にない場合、結果は`null`です。

```jq
"hello" | index("elk")   # => null
```

## 文字列の補間

文字列の中では、`\(expression)`という並びで、その式の_結果_を[文字列に埋め込みます][interpolate]：

```jq
"The current datetime is \(now | strflocaltime("%c"))"   # => "The current datetime is Wed Nov 16 17:06:33 2022"
```

## 大文字・小文字の変換

`ascii_downcase`関数と`ascii_upcase`関数を使います。

## 正規表現

`jq`は正規表現を豊富にサポートしています。これは後のレッスンで扱います。

[interpolate]: https://jqlang.org/manual/#string-interpolation
