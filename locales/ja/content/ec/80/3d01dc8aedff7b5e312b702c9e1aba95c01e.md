# 表現

[PythonのRepresenter][representer]は、学習者の解答を処理し、より「汎用的な」形に正規化します。

- コードは、[PythonのASTモジュール][python-ast]を使ってASTに変換されます。
- 最終的なASTツリーは、空白やインデントのない文字列に変換され、`representation.txt`として出力されます。
- トラブルシューティングのために、`representation.out`には、変換前のAST、編集後のAST、正規化を適用したコード表現が含まれます。

- 削除：
    - 型ヒント（*dataclassの型ヒントも含みます。後述の「正規化」を参照してください*）
    - `print()`文
    - `if __name__ == __main__`ブロック
    -  コメント
    -  docstring

- 置き換え：
    - ユーザー定義の名前はプレースホルダーに置き換えられます（*関数名、仮引数、ラムダ式の変数も含みます*）

- 正規化：
  - 文字列の引用符`'`は`"`（*二重引用符*）に変更されます。ただしエスケープが必要な場合は、そのまま残ります。
  - 数値リテラルはアンダースコアがすべて取り除かれ、指数表記は位ごとに計算されます：
    - **66_777_888_433** --> 66777888433
    - **1_999_878_473.66** --> 1999878473.66
    - **77_555_998_125.445_779** --> 77555998125.44579
    - **44_573_123.445_312+123_674.889_12j** --> 44573123.445312 + 123674.88912j
    - **1e6** --> 1000000.0 #1000000
    -  **1e2+.23** --> 100.0 + 0.23 #100.23
    - **1e2+1_23e0+4.4e-1** --> 100.0 + 123.0 + 0.44 #223.44
    - **7e6+7e5+5e4+9.98e2+4.45_779e-1** -->7000000.0 + 700000.0 + 50000.0 + 998.0 + 0.445779 #7750998.445779
    - **(7e6+7e5+5e4+9.98e1+4.457_79e-1)+(1e2+1.23e1+4.444_23e-1)*1*j** --> (7000000.0 + 700000.0 + 50000.0 + 99.8 + 0.445779 + (100.0 + 12.3 + 0.444423) * 1j)  #7750100.245779+112.744423j
  - docstringの削除後に本体が空になる関数やクラスには、本体に`pass`が割り当てられます。
  - 型ヒントはあるものの値が代入されていないデータメンバーを持つdataclassでは、それらのデータメンバーに値として`None`が割り当てられます。詳しくは、normalizer.pyの153行目から始まるdocstringを参照してください。
