# はじめに

ディクショナリは要素の集まりで、各要素はキーと値からなります。キーをディクショナリのメソッドに渡すと、対応する値が返されます。他の言語のマップや連想配列と同じ役割を果たします。

ディクショナリは次のように作成できます：

```csharp
new Dictionary<int, string>();
// Empty dictionary
```

または

```csharp
new Dictionary<int, string>
{
    [1] = "One",
    [2] = "Two"
};

// Or

new Dictionary<int, string>
{
    {1, "One"},
    {2, "Two"}
};
// 1 => "One", 2 => "Two"
```

キーと値の型がディクショナリの定義の一部になっている点に注意しましょう。

一度作成すれば、組み込みのメソッド`Add`と`Remove`を使ってディクショナリにエントリを追加したり、削除したりできます。

ディクショナリの値の取得や更新は、キーを使ってディクショナリにインデックスでアクセスすることで行います：

```csharp
var numbers = new Dictionary<int, string>
{
   {1, "One"},
   {2, "Two"}
};

// Set the value of the element with key 2 to "Deux"
numbers[2] = "Deux";

// Get the value of the element with key 2
numbers[2];
// => "Deux"
```

値がディクショナリに存在するかどうかは、次のようにして確認できます：

```csharp
var dict = new Dictionary<string, string>{/*...*/};
dict.ContainsKey("some key that exists");
// => true
```

ディクショナリを列挙すると、そのキーと値のペアが列挙されます。ディクショナリには、キーだけ、または値だけを列挙できるプロパティもあります。
