# 指示の補足

## 出力形式

年齢は1年の100分の1の単位で出力します。

たとえば、100 × 1,000,000,000 ÷ 31,557,600 ≈ 3,169なので、年齢が1,000,000,000秒の人は、地球での年齢が1年の100分の1の単位で`3169`になります。

## レジスタ

| レジスタ | 用途     | 型    | 説明                   |
| -------- | --------- | ------- | ----------------------------- |
| `$a0`    | 入力     | 整数 | 惑星（`0` = 水星、`1` = 金星、`2` = 地球、`3` = 火星、`4` = 木星、`5` = 土星、`6` = 天王星、`7` = 海王星） |
| `$a1`    | 入力     | 整数 | 秒                       |
| `$v0`    | 出力    | 整数 | 1年の100分の1の単位で表した年齢   |
| `$t0-9`  | 一時的 | 任意     | 一時的な保管に使われます    |
