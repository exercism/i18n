# はじめに

## マップ

マップは、Elixirで情報をキーと値のペアで保存するためのデータ構造です。他の言語では、連想配列（PHP）、ハッシュ（Perl 5、Raku）、辞書（Python）と呼ばれることもあります。

キーと値にはどんなデータ型でも使えますが、キーがアトムのときは省略した書き方を使えます。マップは、アクセスや返却のときにエントリの順序を保証しません。

### リテラルの書き方

空のマップは、単に`%{}`と書いて宣言します。マップリテラルに要素を追加したいときは、2つの書き方があります。

```elixir
# If the key is an atom:
%{atom_key: 1}

# If the key is a different type:
%{1 => :atom_value}

# You can even mix these if the atom form comes second:
%{"first_form" => :a, atom_form: :b}
```

決まった書き方が定められているわけではありませんが、キーと値のリテラルのペアは一貫した書き方で表すようにしましょう。

### `Map`モジュールの関数

Elixirには、マップを扱うための関数が_Mapモジュール_にたくさん用意されています。_Mapモジュール_の関数の中には、マップの変換を助けるために、_無名関数_を引数として渡す必要があるものもあります。

## 定数としてのモジュール属性

Elixirでは、モジュール属性を定義して、関数の中で定数として使うことができます。

```elixir
defmodule Example do
  # Defines the attribute as the value 1
  @constant_number 1

  def example_value() do
    # Returns the value 1
    @constant_number
  end
end
```

モジュールの定数を定義するために使う場合、属性にはコンパイル時に評価できる任意の式を書けます。コンパイル後は、モジュール属性はコンパイル中に展開されてしまうため、アクセスできません。これは、Cなどの言語で定義するマクロに似ています。
