# はじめに

## 等価性

Common Lispには、さまざまな等価性の述語があります。
他のプログラミング言語では、1つか2つしか持たないことが多いのとは異なります（たとえば`==`と`===`など）。
Common Lispのこれらの述語には、型に固有のものもあれば、汎用的なものもあります。
ここでは、後者の汎用的な述語を取り上げます。

汎用的な等価性の述語は4つあり、「等しい」と見なす範囲の厳しさがそれぞれ異なります。
厳しいものから緩いものへ順に並べると、`eq`、`eql`、`equal`、`equalp`です。

簡単な定義は次のとおりです（細かい点はいくつか省きます）。

- `eq`: 2つのオブジェクトが同一であることを「等しい」と定義します。
  _例_:

```lisp
(eq 'a 'a)                 ; => T
(eq (list 1 2) (list 1 2)) ; => NIL
```

- `eql`: 同じ型と同じ値を持つ2つの数値、同じ2つの文字、それ以外については`eq`であることを「等しい」と定義します。
  _例_:

```lisp
(eql 1 1)     ; => T
(eql #\a #\a) ; => T
(eql 1 1.0)   ; => NIL
(eql #\a #\A) ; => NIL
```

- `equal`: 「等しい」を次のように定義します。2つのリストは、それぞれの要素も`equal`であれば`equal`です。2つの文字列は、それぞれの要素が`eql`であれば`equal`です。2つの配列は、`eq`であれば`equal`です。それ以外はすべて、`eql`であれば`equal`です。
  _例_:

```lisp
(equal (list 1 2) (list 1 2)) ; => T
(equal #(1 2) #(1 2))         ; => NIL
(equal "foo" "foo")           ; => T
```

- `equalp`: 「等しい」を次のように定義します。文字列と文字は大文字と小文字を区別せずに比較されます。数値は何らかの型変換を伴って比較されます。リストと配列は、すべての要素が`equalp`であれば`equalp`、構造体は同じ型ですべてのスロットが`equalp`であれば`equalp`、ハッシュテーブルはキーと値が`equalp`であれば`equalp`です。
  _例_:

```lisp
(equalp "foo" "FoO")                          ; => T
(equalp 3 3.0)                                ; => T
(equalp (make-a-structure :slot1 1 :slot2 2) 
        (make-a-structure :slot1 1 :slot2 2)) ; => T
```
