# 概要

## 構造体型

構造体型はすでに見てきましたね。おさらいすると、`struct`は、_フィールド_と呼ばれる名前の付いた要素を並べたもので、それぞれのフィールドが名前と型を持ちます。
フィールドの名前は、その構造体の中で一意でなければなりません。
`Structs`は、オブジェクト指向プログラミングのパラダイムにおける_クラス_と比較できます。

新しい構造体を作るには、`type`と`struct`というキーワードを使って、下の例のようにフィールドの名前と型を明示的に定義します。

```go
type StructName struct{
    field1 fieldType1
    field2 fieldType2
}
```

## 構造体以外の型

構造体以外の型を定義して、組み込み型の宣言のエイリアスとして使うこともできます。

```go
type Name string
func SayHello(n Name) {
  fmt.Printf("Hello %s\n", n)
}
n := Name("Fred")
SayHello(n)
// Output: Hello Fred
```

配列やマップで構成された、構造体以外の型を定義することもできます。

```go
type Names []string
func SayHello(n Names) {
  for _, name := range n {
    fmt.Printf("Hello %s\n", name)
  }
}
n := Names([]string{"Fred", "Bill"})
SayHello(n)
// Output:
// Hello Fred
// Hello Bill
```
