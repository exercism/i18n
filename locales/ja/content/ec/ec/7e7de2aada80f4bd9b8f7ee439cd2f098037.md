# 浮動小数点数

`INT`が表せるのは整数だけです。2つの`INT`を割ると、余りは切り捨てられます。

```sather
7 / 2        -- 3, not 3.5
```

小数部分が必要なときは、`FLTD`という型を使います。これは**浮動小数点数**といって、整数と整数の間の値も表せます。

## 書き方

浮動小数点のリテラルには、小数点と末尾の`d`が必要です。

```sather
   concert_a : FLTD is
      return 440.0d;
   end;
```

`d`は省略できません。`440.0`だけだと、精度の低い別の型になります。`d`を付けると、このトラックでどこでも使っている型を指定できます。

`2d`ではなく`2.0d`と書きましょう。小数点も必要なのです。

## 計算

`+`、`-`、`*`、`/`がすべて使えて、`/`では小数部分がそのまま残ります。

```sather
7.0d / 2.0d      -- 3.5
```

両側とも`FLTD`である必要があります。Satherは2つの型を黙って混ぜ合わせたりはしません。ですから`7 / 2.0d`は、思わぬ結果ではなくエラーになります。

## 整数から変換する

`.fltd`を使うと、`INT`を`FLTD`に変換できます。

```sather
   halve(n : INT) : FLTD is
      return n.fltd / 2.0d;
   end;
```

`halve(7)`は`3.5`になります。変換をどこで行うかに注目してください。`(7 / 2).fltd`は`3.0`になります。割り算の時点ですでに半分が切り捨てられているからです。割り算の**前に**変換しましょう。後ではいけません。

## どれだけ離れている？

`.abs`はマイナス符号を取り除きます。2つの値がどれだけ離れているかを、どちらが大きいかを気にせずに調べるときに使います。

```sather
(440.0d - 442.0d).abs      -- 2.0
```
