# 手順

この演習では、車を買う準備を手伝うプログラムを書きます。

やることは2つあります。免許が必要かどうかを判断することと、中古車の妥当な価格を見積もることです。

## 1. 運転免許が必要かどうかを判断する

乗り物の中には、運転するのに運転免許が必要なものがあります。
`car`または`truck`を含む乗り物だけが免許を必要とし、それ以外は免許なしで運転できると考えてください。

最初のフィールドが`needs_license`のときにマッチする`pattern {action}`のペアを実装しましょう。
2番目のフィールドから乗り物の種類を取得し、その種類に免許が必要なら"true"を出力します。
免許が必要なければ、何も出力する必要はありません。

```sh
echo "needs_license,dumptruck" | gawk -f vehicle-purchase.awk
# => true

echo "needs_license,bike" | gawk -f vehicle-purchase.awk
# => (empty output)
```

## 2. 中古車の価格を見積もる

判断がついたところで、次はディーラーで適正な価格で買えるようにしたいですね。
中古車の購入を考えているので、価格はその車の古さによって変わります。
ざっくりとした見積もりとして、車の年数が3年未満なら、新車だったときの価格の80%になると考えてください。
10年を超えると、50%になります。
3年以上10年以下なら、元の価格の70%になります。

最初のフィールドが`resell_price`のときにマッチする`pattern {action}`のペアを実装しましょう。
2番目のフィールドから車の元の価格を、3番目のフィールドから年数を取得します。
アクションでは、見積もり価格を出力します。

```sh
echo "resell_price,1000,1" | gawk -f vehicle-purchase.awk
# => 800

echo "resell_price,1000,5" | gawk -f vehicle-purchase.awk
# => 700

echo "resell_price,1000,15" | gawk -f vehicle-purchase.awk
# => 500
```
