# テスト

お使いのOSを選んでください：

* [Windows](##windows)
* [macOS](##macos)
* [Linux](##linux)

# テストの実行

## Windows

1. Command Promptを開きます。

2. 最初の演習をダウンロードします：

    ```batchfile
     C:\Users\USERNAME> exercism download --exercise hello-world --track cobol
    ```

3. 演習のフォルダーに移動します：

    ```batchfile
     C:\Users\USERNAME> cd C:\Users\USERNAME\exercism\cobol\hello-world
    ```
   
4. テストを実行します：

    ```batchfile
     C:\Users\USERNAME\exercism\cobol\hello-world> test.ps1
    ```
    *（最初に実行したときにテストが失敗しても心配いりません。どの演習もそうやって始まります。）*

5. 演習を解きます。 
    `instructions.md`を読んで、演習の解き方を確認しましょう（[GitHubで見る](https://github.com/exercism/cobol/blob/main/exercises/practice/hello-world/.docs/instructions.md)）。


COBOLトラックへようこそ！　幸運を祈ります。楽しんでください！

## macOS

1. Terminalウィンドウを開きます。

2. 最初の演習をダウンロードします：

    ```
     $ exercism download --exercise hello-world --track cobol
    ```

3. 演習のフォルダーに移動します：

    ```
     $ cd /Users/USERNAME/exercism/cobol/hello-world
    ```

4. テストを実行します：

    ```
     $ bash test.sh
    ```
    *（最初に実行したときにテストが失敗しても心配いりません。どの演習もそうやって始まります。）*

    ヒント：`basename`が見つからないというメッセージが表示された場合は、[brew](https://brew.sh/)を使ってcoreutilsをインストールできます。（`brew install coreutils`）

5. 演習を解きます。 

    `instructions.md`を読んで、演習の解き方を確認しましょう（[GitHubで見る](https://github.com/exercism/cobol/blob/main/exercises/practice/hello-world/.docs/instructions.md)）。


COBOLトラックへようこそ！　幸運を祈ります。楽しんでください！
