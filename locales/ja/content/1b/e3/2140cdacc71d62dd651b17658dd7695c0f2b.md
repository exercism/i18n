# 条件分岐

Crystalには、制御式と呼ばれるものがあります。これらはプログラムの実行の流れを制御するために使い、真または偽として評価される値を受け取ります。
真または偽の値を作るために使える演算子もあり、これらは[等値演算子と比較演算子][equality-and-comparison]と呼ばれます。

主な制御式は2つあり、どのコードを実行し、どのコードを実行しないかを制御するために使います。言い換えれば、どの分岐が実行されるかです。

その2つとは、`if`と`unless`式です。

## 比較演算子

比較演算子は、値を比較して`true`または`false`を返すために使います。
これらの演算子で比較するには、同じ型の値が2つ必要です。
値の型が異なると、コンパイラーがエラーを出します。
以下は比較演算子の一覧と、`true`になる例です。

| Method | Description           | Example |
| ------ | --------------------- | ------- |
| <      | less than             | 4 < 5   |
| <=     | less than or equal    | 4 <= 4  |
| >      | greater than          | 3 > 1   |
| >=     | greater than or equal | 2 >= 2  |

## 等値演算子

等値演算子は比較演算子に似ていますが、2つの値が等しいかどうかを調べるために使います。

`==`演算子は、値の型も含めて、2つの値が等しいかどうかを調べます。
値が同じであれば`true`を返し、そうでなければ`false`を返します。
`==`演算子は、ある型の値を他のどんな型の値とでも比較できます。
`!=`も同じように動作しますが、値が等しくなければ`true`を、等しければ`false`を返します。

## 宇宙船演算子

宇宙船演算子は独特な比較演算子で、その名前は見た目から来ています。
真や偽ではなく数値を返すという点で独特です。
`<=>`と書き、2つの値を比較するために使います。
左の値が右の値より大きければ`1`、左の値が右の値より小さければ`-1`、値が等しければ`0`を返します。

```crystal
1 <=> 2 # => -1
2 <=> 2 # => 0
3 <=> 2 # => 1
```

## `if`文

[`if`][if]文は、与えられた条件が真か偽かを調べるために使います。
条件が真であれば、`if`文の中のコードが実行されます。
`if`文は`end`キーワードで終わります。

```crystal
if 1 == 1
  puts "1 is equal to 1"
end
# => 1 is equal to 1

if 1 > 2
  puts "1 is greater than 2"
end
# => no output
```

## `unless`文

[`unless`][unless]文は`if`文とよく似た動作をしますが、条件が偽のときに`unless`文の中のコードを実行します。

```crystal
unless 1 == 1
  puts "1 is not equal to 1"
end
# => no output

unless 1 > 2
  puts "1 is not greater than 2"
end
# => 1 is not greater than 2
```

## `else`文

`else`文は、`if`文や`unless`文と組み合わせて使うことができます。
`if`の分岐または`unless`の分岐が実行されなかったときに、`else`文が実行されます。

~~~~exercism/warning
`else`の分岐は`unless,`と組み合わせて使うこともできますが、読みやすさを損なうため、おすすめしません。
代わりに、`if !condition`を`else`の分岐と組み合わせて使うことをおすすめします。
~~~~

```crystal
if 1 == 1
  puts "1 is equal to 1"
else
  puts "1 is not equal to 1"
end
# => 1 is equal to 1

unless 1 < 2
  puts "1 is not greater than 2"
else
  puts "1 is greater than 2"
end
# => 1 is greater than 2
```

## 「カスケード`if`」文

`elsif`文は`if`文と組み合わせて使うことができます。
`if`の分岐が実行されず、かつ`elsif`文の条件が真であるときに、`elsif`文が実行されます。
`elsif`文はつなげて書くことができ、最初に真になった条件が実行されます。
また、`if`文の最後に`else`文を置くこともでき、それより前のどの条件も真にならなかったときに実行されます。

```crystal
if 1 != 1
  puts "1 is not equal to 1"
elsif 1 > 2
  puts "1 is greater than 2"
else
  puts "1 is not equal to 1 and 1 is not greater than 2"
end
# => 1 is not equal to 1 and 1 is not greater than 2
```

## 三項演算子

Crystalには三項演算子があり、1行で書く`if`・`else`文です：`condition ? expression_if_truthy : expression_if_falsey`

```crystal
1 == 1 ? puts("1 is equal to 1") : puts("1 is not equal to 1")
# => 1 is equal to 1
```

## 接尾辞としての`if`と`unless`

`if`文と`unless`文は[接尾辞][if-as-suffix]としても使えます。これは、条件が真のときに1行のコードを実行したいときに便利です。
実行したいコードの後に`if`または`unless`文を書きます。

```crystal
puts "1 is equal to 1" if 1 == 1
# => 1 is equal to 1

puts "1 is not equal to 1" unless 1 == 1
# => no output
```

## 条件分岐と型

異なる型を代入すると、変数は両方の型を持つことになります。
これは、コンパイラーがどちらの分岐が実行されるかを知らないためです。
この複数の代入は、ユニオンとも呼ばれ、後のコンセプトで説明します。
次の例で確認できます。

```crystal
if 1 == 1
  a = 1
else
  a = "1"
end

typeof(a) # => Int32 | String
```
