# コントリビューター向けのツール

学習者に必要なのは、[INSTALLATION.md](INSTALLATION.md)にあるツールだけです。
コントリビューターにはもう少し必要です。トラックのスクリプトがそれらを使うからです。

- `git`：リポジトリをクローンしてプルリクエストを作成するために使います。
- `jq`：`bin/verify-exercises`と`bin/add-practice-exercise`で使います。
- `curl`：`bin/fetch-configlet`で使います。
- Python 3.11以降：テストジェネレーターで使います。
- `clang-format`：テストジェネレーターが、書き出したファイルに対して実行します。
- `pre-commit`：コミットする前に、リポジトリのチェックを実行します。

お使いのディストリビューションに合わせたコマンドでこれらをインストールし、その後「リポジトリのセットアップ」の手順に進みましょう。

## Debian / Ubuntu

```shell
sudo apt install git jq curl clang-format pre-commit
```

## Fedora

```shell
sudo dnf install git jq curl pre-commit clang-tools-extra diffutils
```

## Arch Linux

```shell
sudo pacman -S git jq curl pre-commit clang diffutils
```

## openSUSE Tumbleweed

```shell
sudo zypper install git jq curl python3-pre-commit clang-tools diffutils
```

## リポジトリのセットアップ

リポジトリのルートで、次のコマンドを実行します。

```shell
bin/fetch-configlet
bin/configlet info
pre-commit install
pre-commit run --all-files
```
