# クラス

クラスは、[オブジェクト指向プログラミング][object-oriented-programming]の中心となる概念です。[Crystalでは、すべてがオブジェクト][everything-is-an-object]で、すべてのオブジェクトには型があり、いくつかのメソッドに応答できます。クラスはオブジェクトを作成するための設計図で、変数のような状態の初期値や、メソッドのような振る舞いの実装を提供します。オブジェクトは、すべてのインスタンス変数と状態を保持するクラスのインスタンスです。

## クラスの定義

クラスは`class`キーワードで定義し、そのあとに`UpperCamelCase`で書いたクラス名を続けます。

```crystal
class Account
end
```

## インスタンスの作成

[クラスのインスタンスを作成する][new-initialize]には、クラス名に対して`new`メソッドを呼び出します。

```crystal
class Account
end

account = Account.new
```

上の例では、変数`account`はクラス`Account`のインスタンスです。

インスタンスを作成するとき、`initialize`という特別なメソッドがコンストラクターとして働きます。これはインスタンスが作成されるときに呼び出されます。コンストラクターを使うと、インスタンスの初期状態を設定できます。`initialize`メソッドは引数を取ることができ、その引数はインスタンスを作成するときに渡されます。

```crystal
class Account
  def initialize(number)
    5 + number # => 9
  end
end

Account.new(4)
```

~~~~exercism/note
`initialize`メソッドは自分で値を返すことはできません。その代わり、`new`が新しく作成されたインスタンスを返します。

```crystal
class Account
  def initialize(number)
    5 + number
  end
end

Account.new(4)
# => #<Account:0x7f5dc33dcea0>
```
~~~~

## インスタンスメソッド

インスタンスメソッドは、クラスのインスタンスから利用できるメソッドで、そのインスタンスに対して呼び出すことができます。インスタンスメソッドは`def`キーワードで定義し、そのあとにメソッド名を続けます。クラス定義の中に書きます。

```crystal
class Account
  def balance
    100
  end
end

account = Account.new
account.balance # => 100
```

## インスタンス変数

[インスタンス変数][instance-variable]は、そのインスタンスのすべてのメソッドから利用できる変数です。インスタンス変数にアクセスするには、インスタンスメソッドを定義する必要があります。`initialize`メソッドの中で初期化できます。インスタンス変数は`@`を先頭に付けて定義します。

```crystal
class Account
  def initialize
    @balance = 100
  end

  def balance
    @balance
  end
end

account = Account.new
account.balance
# => 100
```

インスタンス変数は、クラス定義の中でも定義できます。

```crystal
class Account
  @age = 0
end
```

### 初期化をともなうインスタンス変数

インスタンス変数は、`initialize`メソッドに渡される引数で初期化できます。Crystalは初期化のときに使われる引数の型を推論できないため、型を指定する必要があります。これについて詳しく知りたい場合は、[型推論][type-inference]を読んでみてください。変数の型を指定するには、`:`記号のあとに型を書きます。たとえば、`Int32`型の`balance`というインスタンス変数を作りたい場合は、`@balance : Int32`のように書きます。`Bool`型の`raining`というインスタンス変数を作りたい場合は、`@raining : Bool`のように書きます。

これを実装する方法はいくつかあります。たとえば、`initialize`メソッドで引数に型を付けて宣言し、その引数をインスタンス変数に代入する方法です。

```crystal
class Account
  def initialize(balance : Int32)
    @balance = balance
  end

  def balance
    @balance
  end
end

account = Account.new(1)
account_2 = Account.new(5)

account.balance
# => 1

account_2.balance
# => 5
```

もう1つの方法は、クラス定義の中で`@<variable> : <Type>`という形でインスタンス変数の型を宣言する方法です。次の例のようになります。

```crystal
class Weather

  @raining : Bool

  def initialize(raining)
    @raining = raining
  end

  def raining
    @raining
  end
end

weather = Weather.new(true)
weather.raining
# => true
```

### インスタンス変数を初期化する省略記法

`initialize`メソッドの引数でインスタンス変数を初期化する省略記法があり、同じ`@<variable> : <Type>`という構文を使います。これは、引数をインスタンス変数に代入することと、インスタンス変数の型を宣言することを1つにまとめたものです。

```crystal
class Account
  def initialize(@balance : Int32)
  end
end
```

## インスタンス変数の変更

メソッドはインスタンス変数を変更できます。これらのメソッドは、クラスのインスタンスに対して呼び出すことができます。メソッドがインスタンス変数を変更すると、その変更は呼び出したインスタンスの中だけで有効です。

```crystal
class Account
  def initialize(balance : Int32)
    @balance = balance
  end

  def withdraw(amount)
    @balance -= amount
  end

  def balance
    @balance
  end
end

account = Account.new(10)
account_2 = Account.new(10)
account.balance
# => 10

account_2.balance
# => 10

account.withdraw(5)
account.balance
# => 5

account_2.balance
# => 10
```

## クラスメソッド

[クラスメソッド][class-methods]は、クラスに対して定義されるメソッドで、そのインスタンスに対しては定義されません。インスタンスの状態に依存しないメソッドを作る方法を提供します。`def`キーワードで定義し、そのあとに`self.<method name>`を続けます。`self`は、そこからselfが呼び出されている名前空間への参照です。ここではクラス`Account`を指します。`Account.`と書いた場合と同じになりますが、`self.`と書くのが好ましい方法です。

```crystal
class Account
  def self.balance
    100
  end
end

Account.balance
# => 100
```
