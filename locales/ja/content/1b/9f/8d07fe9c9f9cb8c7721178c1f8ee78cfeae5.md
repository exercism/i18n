# 指示の補足

## Enumについて

enum文を使うと、強く型付けされたラベルの集合を作ることができます。この列挙型をコードの中で使えば、文字列を解析したり、スペルミスを確認したりする必要はありません。

列挙型は、内部的には0から始まる整数として表現されます。デフォルトでは、PowerShellはリストの最初のラベルに0を割り当て、残りのラベルには連続する整数を割り当てます。

例：
```pwsh
Enum Fruits {
    APPLE       #default internal value 0
    ORANGE      #default internal value 1
    MANGO       #default internal value 2
}

$myFavFruit = [Fruits]::APPLE
Write-host $myFavFruit => APPLE
``````

PowerShellのenumについて詳しく知りたい場合は、[Enumモジュール](https://learn.microsoft.com/en-us/powershell/module/microsoft.powershell.core/about/about_enum)をチェックしてみてください。
