# はじめに

Elixirの正規表現は、Java、JavaScript、Rubyなどの他の人気言語と同様に、**PCRE**仕様（**P**erl **C**ompatible **R**egular **E**xpressions）に従います。

`Regex`モジュールには、正規表現を扱うための関数が用意されています。`String`モジュールの関数の中にも、引数として正規表現を受け取るものがあります。

~~~~exercism/note
この演習では、文字クラス、数量子、グループ、キャプチャなど、正規表現の構文をすでに知っていることを前提としています。

正規表現の知識を復習したい場合は、次のいずれかを参照してみてください。[Regular-Expressions.info](https://www.regular-expressions.info)、[Rex Egg](https://www.rexegg.com/)、[RegexOne](https://regexone.com/)、[Regular Expressions 101](https://regex101.com/)、[RegExr](https://regexr.com/)。
~~~~

## シジル

正規表現を作る最も一般的な方法は、`~r`シジルを使うことです。

```elixir
~r/test/
```

Elixirのシジルはすべて、`/`だけでなく、[さまざまな種類の区切り文字][sigils]をサポートしていることに注意してください。

## マッチング

`=~/2`演算子を使うと、`boolean`の結果を返す正規表現のマッチを実行できます。あるいは、`Regex`モジュールだけでなく`String`モジュールにも`match?/2`関数があります。

```elixir
"this is a test" =~ ~r/test/
# => true

String.match?("Alice has 7 apples", ~r/\d{2}/)
# => false
```

## キャプチャ

単純な真偽値のチェックでは足りない場合は、`Regex.run/3`関数を使って、すべてのキャプチャのリストを取得しましょう（マッチしなかった場合は`nil`）。返されるリストの最初の要素は、常に正規表現全体にマッチした部分で、それに続く要素がマッチしたグループです。

```elixir
Regex.run(~r/(\d) apples/, "Alice has 7 apples")
# => ["7 apples", "7"]
```

## 修飾子

正規表現の動作は、特別なフラグを付けることで変更できます。シジルを使って正規表現を作る場合は、2つ目の区切り文字のあとに修飾子を追加します。

よく使われる修飾子は次のとおりです。
- `i` - マッチで大文字と小文字を区別しないようにします。
- `u` - `\p`のようなUnicode固有のパターンを有効にし、`\w`や`\s`などの文字クラスがUnicodeにもマッチするようにします。

```elixir
"this is a TEST" =~ ~r/test/i
# => true
```
