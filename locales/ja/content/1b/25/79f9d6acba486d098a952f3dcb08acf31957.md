# 説明

ミッキーとミネルバのために、完璧な迷路を作ってあげましょう。解が1つだけで、孤立した区画がない迷路のことです。
知っておくべきことは、次のとおりです。

- 迷路は長方形で、始点と終点に開いた入口があります。
- 迷路には部屋と通路があり、それらは直角に交わります。
- プログラムは、行と列という2つの仮引数を受け取ります。迷路の大きさは、5マス以上100マス以下とします。
- 幅が`x`列、高さが`y`行の迷路は、幅が`2x + 1`文字、高さが`2y + 1`文字になります。
- シードを指定しない場合は、ランダムな迷路を生成します。同じシードを複数回指定した場合は、毎回同じ迷路が生成されます。
- 壁を描くには[罫線素片][Box-drawing]を使い、左側の入口と右側の出口には矢印記号（⇨）を使います。

さあ、冒険好きなこのネズミたちのために、完璧な迷路を作りましょう！

## 例

1. 小さな正方形の迷路、5x5マス（11x11文字）

    ```text
    ┌───────┬─┐
    │       │ │
    │ ┌─┬── │ │
    │ │ │   │ ⇨
    │ │ │ ──┤ │
    ⇨ │ │   │ │
    ┌─┤ └── │ │
    │ │     │ │
    │ │ ────┘ │
    │         │
    └─────────┘
    ```

2. 長方形の迷路、6x18マス

    ```text
    ┌───────────┬─────────┬───────────┬─┐
    │           │         │           │ │
    │ ┌───────┐ │ ┌─┐ ──┐ └───┐ ┌───┐ │ │
    │ │       │ │ │ │   │     │ │   │   ⇨
    │ └─┐ ┌─┐ │ │ │ ├── ├───┐ │ │ ──┼── │
    │   │ │ │   │   │   │   │ │ │   │   │
    └── │ │ ├───┴───┤ ┌─┘ ┌─┘ │ ├── │ ──┤
    ⇨   │   │       │ │   │   │ │   │   │
    ┌─┬─┴─┐ └─┐ ┌─┐ │ └─┐ │ ┌─┘ │ ──┴─┐ │
    │ │   │   │ │ │ │   │   │   │     │ │
    │ │ │ └── │ │ │ └── │ ──┘ ┌─┘ ──┐ │ │
    │   │       │       │     │     │   │
    └───┴───────┴───────┴─────┴─────┴───┘
    ```

[Box-drawing]: https://en.wikipedia.org/wiki/Box-drawing_character
