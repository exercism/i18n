# 指示の補足

## 例外メッセージ

ときには[例外を送出する](https://docs.python.org/3/tutorial/errors.html#raising-exceptions)必要があります。そのときは、エラーの原因が何であるかを示す**意味のあるエラーメッセージ**を必ず含めましょう。そうするとコードが読みやすくなり、デバッグもぐっと楽になります。エラーの原因がある決まった種類になるとわかっている場合は、[組み込みのエラータイプ](https://docs.python.org/3/library/exceptions.html#base-classes)の中から1つを選んで送出してもかまいませんが、その場合も意味のあるメッセージを含めるようにしましょう。

この演習では、デコードまたはエンコードするシーケンスが不完全な場合に、[`raise`文](https://docs.python.org/3/reference/simple_stmts.html#the-raise-statement)を使って`ValueError`を「投げる」必要があります。テストに合格するのは、`exception`を`raise`し、メッセージも添えたときだけです。

メッセージ付きで`ValueError`を送出するには、そのメッセージを`exception`型の引数として書きます。

```python
# if the sequence is incomplete
raise ValueError("incomplete sequence")
```
