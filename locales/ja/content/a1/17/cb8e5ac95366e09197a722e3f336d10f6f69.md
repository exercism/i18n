# 説明

高校時代の恋人同士がSNSで愛を告白できるよう、二人のイニシャルを入れたUnicodeのハートを作ってあげましょう。

```
❤ J.  +  M. ❤
```

## 1. 名前を整える

スタックから名前を取り出して`cleanupname`を定義します。すべての`-`をスペースに置き換え、先頭と末尾の空白を取り除きます。

```factor
"Jane-Ann" cleanupname .
! => "Jane Ann"
```

## 2. 名前の最初の文字を取り出す

名前を受け取って`firstletter`を定義します。前のタスクの`cleanupname`を再利用し、その結果の最初の文字を取り出して、1文字の文字列として返します。

```factor
"Jane" firstletter .
! => "J"
```

## 3. 最初の文字をイニシャルとして整える

名前を受け取って`initial`を定義します。前のタスクの`firstletter`を再利用して大文字にし、最後に`.`を付け加えます。

```factor
"Robert" initial .
! => "R."
```

## 4. イニシャルをハートの中に入れる

スタックから2つの名前を取り出して`couple`を定義します。それぞれの名前について前のタスクの`initial`を再利用し、その結果を組み立てます。

```factor
"Blake Miller" "Riley Lewis" couple .
! => "❤ B.  +  R. ❤"
```
