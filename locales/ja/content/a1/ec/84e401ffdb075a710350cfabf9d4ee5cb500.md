# はじめに

Gleamの標準ライブラリには、`gleam/queue`モジュールで`Queue`型が実装されています。`List`型と似ていますが、いくつか重要な違いがあります：

- `Queue`型には、キューを構築したりパターンマッチしたりするためのリテラル構文がありません。
- `Queue`型では、先頭と末尾の両方から要素を効率よく追加・削除できますが、`List`型では先頭からしか要素を効率よく追加・削除できません。

ほとんどの場合、`List`型を使いたくなるでしょうが、コレクションの末尾から要素を追加・削除する必要があるときは、`Queue`型が適しています。

キューは、`queue.new`関数と`queue.from_list`関数を使って作成できます：

```gleam
let empty = queue.new()
let one_to_four = queue.from_list([1, 2, 3, 4])
```

要素は、`queue.push_front`関数と`queue.push_back`関数を使ってキューに追加できます：

```gleam
let one_to_four = queue.from_list([1, 2, 3, 4])
let one_to_five = queue.push_back(one_to_four, 5)
let zero_to_five = queue.push_front(one_to_five, 0)
```

要素は、`queue.pop_front`関数と`queue.pop_back`関数を使ってキューから削除できます：

```gleam
let one_to_four = queue.from_list([1, 2, 3, 4])

queue.pop_back(one_to_four)
// -> Ok(#(4, queue.from_list([1, 2, 3])))

queue.pop_front(one_to_four)
// -> Ok(#(1, queue.from_list([2, 3, 4])))

queue.pop_front(queue.new())
// -> Error(Nil)
```

キューは、`queue.to_list`関数を使って配列に変換できます：

```gleam
let one_to_four = queue.from_list([1, 2, 3, 4])
queue.to_list(one_to_four)
// -> [1, 2, 3, 4]
```

## キューの等価性

キューの実装方法により、同じ要素を同じ順序で持つ2つのキューでも、値を構造的に比較する`==`演算子では等しいと判定されないことがあります。たとえば：

```gleam
let empty = queue.new()
let a = queue.push_front(empty, 1)
let b = queue.push_back(empty, 1)
a == b
// -> False
```

2つのキューが等しいかどうかを比較する必要がある場合は、`queue.is_logically_equal`関数を使えます。

```gleam
queue.is_logically_equal(a, b, fn(x, y) { x == y })))
// -> True
```
