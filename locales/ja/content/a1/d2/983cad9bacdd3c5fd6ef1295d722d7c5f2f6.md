# はじめに

## 変数の定義

変数を定義するとは、名前を値に割り当てることです。Scalaには、`val`と`var`という2種類の変数があります。

`val`は不変なので、最初の代入のあとで値を変更することはできません。

```scala
val numberTen = 10

numberTen = 11
// --> raises a compile error "reassignment to val"
```

一方、`var`は同じ型の新しい値を再代入できます。

```scala
var someNumber = 10

someNumber = 11
// now someNumber has been reassigned
```

Scalaは静的型付け言語です。つまり、すべてのものはコンパイル時に型を持ちます。変数は、型を明示的に指定するか、代入された値に基づいてScalaコンパイラーに型を推論させるか（これを型推論といいます）のどちらかで定義できます。したがって、次の2つの変数定義は同じ意味になります。

```scala
val explicitNumber: Int = 10; // Explicitly typed
val implicitNumber = 10; // Implicitly typed
```

一度定義されると、変数の型を変更することはできません。

```scala
var count = 1; // Assigning an initial value of type Int
count = 2;     // Updating to new value is possible, because it is defined as var

count = false;
// --> raises a compile error "type mismatch"
```

## クラス内でのメソッドの定義

Scalaは_オブジェクト指向言語_であり、すべてのメソッドを_クラス_の中で定義する必要があります。クラスを定義するには、`class`キーワードを使います。

```scala
class Calculator {
  // ...
}
```

クラスの中では、`def`キーワードに続けて名前を書くことでメソッドを定義できます。各メソッドは0個以上の仮引数を持てます。仮引数は括弧（`()`）の中に、カンマで区切って並べます。仮引数の型はすべて明示的に指定する必要があり、仮引数に型推論はありません。仮引数のリストのあとに、コロンで区切ってメソッドの戻り値の型を指定します。

メソッドの定義のあとには`=`記号を書き、そこからメソッドの本体が始まります。次の例では、メソッドの本体は2つの文からなり、波括弧（`{}`）で囲まれています。

メソッドは最後の式の値を返します。この場合、`add`メソッドは変数`sum`の値を返します。

```scala
class Calculator {
  // long form
  def add(x: Int, y: Int): Int = {
    val sum = x + y
    sum
  }
}
```

このメソッドは、読みやすくするために短くできる改善点がいくつかあります。

- 変数`sum`は値を返すために一度しか参照されないので、省略できます
- 1つの文だけからなるメソッドには波括弧は必要ありません
- メソッドの戻り値の型は、変数の型と同じように推論できます

すると、同じ機能を持つ次の1行のメソッドになります。

```scala
class Calculator {
  // shortened form
  def add(x: Int, y: Int) = x + y
}
```

## クラスのインスタンス化とメソッドの呼び出し

メソッドを呼び出すには、まずクラスのインスタンスを作成し、次にそのインスタンスに対して引数を渡してメソッドを呼び出します。

```scala
val calculator = new Calculator()
val sum = calculator.add(5, 7)
// sum is of type Int with assigned value of 12
```

## コメント

Scalaは2種類のコメントをサポートしています。1行コメントと複数行コメントです。

```scala
// this is a single line comment

/*
This comment spans across
multiple lines.
*/
```
