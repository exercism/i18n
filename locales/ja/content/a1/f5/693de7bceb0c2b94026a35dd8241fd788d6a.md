# 説明

いくつかのアプリケーションで構成されるシステムを運用していて、それらが大量のログを出力しているとします。それらのログを集約し、重要度に応じてラベルを付ける小さなプログラムを書きたいとします。システム内のすべてのアプリケーションは同じログコードを使いますが、一部のレガシーアプリケーションはすべてのコードに対応しているわけではありません。

| ログコード | ログのラベル | レガシーアプリでの対応 |
|-----------------------| --------- | ------------------------- |
| 0                     | trace     | いいえ                     |
| 1                     | debug     | はい                       |
| 2                     | info      | はい                       |
| 3                     | warning   | はい                       |
| 4                     | error     | はい                       |
| 5                     | fatal     | いいえ                     |
| その他 / 未対応        | unknown   | -                         |

## 1. ログのラベルを判定する

`LogLevel.to_label/2`関数を実装しましょう。この関数は、整数のコードと、そのログがレガシーアプリからのものかどうかを示す真偽値のフラグを受け取り、ログの行のラベルをアトムとして返します。

表にないログコードは、_unknown_というラベルを返すようにします。表でレガシーアプリでは未対応とされているログコードも、そのログがレガシーアプリから来たものであれば、_unknown_というラベルを返します。

```elixir
LogLevel.to_label(0, false)
# => :trace

LogLevel.to_label(0, true)
# => :unknown
```

## 2. アラートを送信する

予期しないことが起きたときには、誰かに通知する必要があります。

アラートを誰に送るべきかを判定するために、`LogLevel.alert_recipient/2`関数を実装しましょう。この関数は、整数のコードと、そのログがレガシーアプリからのものかどうかを示す真偽値のフラグを受け取り、通知先の名前をアトムとして返します。

前のタスクの`LogLevel.to_label/2`関数を使います。ログのラベルが_error_または_fatal_なら、_ops_チームにアラートを送ります。レガシーシステムから_unknown_というラベルのログを受け取った場合は、_dev1_チームにアラートを送ります。それ以外の_unknown_ラベルは_dev2_チームに送ります。そのほかのログのラベルはすべて、_false_を返して無視して問題ありません。

```elixir
LogLevel.alert_recipient(-1, true)
# => :dev1

LogLevel.alert_recipient(0, false)
# => false
```
