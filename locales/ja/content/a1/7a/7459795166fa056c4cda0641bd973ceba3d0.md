# 概要

Swiftの`guard`文は、必要な条件が満たされていないときに、関数やループ、メソッドから早期に抜けるために使います。

```swift
guard myValue >= 0 else { return 0 }
let root = myValue.squareRoot()
```

上の例では、`guard`はそれに続く真偽値の式を評価します。条件が`true`なら、`guard`文に続くコードがそのまま実行されます。条件が`false`なら、`else`ブロックの中のコードが実行されます。

`if`文とは、次の点が違います。

- `guard`文には`else`節が**必ず**必要です。
- `else`節は、**必ず**周囲のスコープから抜けるように制御を移さなければなりません（たとえば、`return`、`continue`、`break`を使うか、エラーをスローします）。

`guard`は、事前条件をすっきりと検証するのによく使います。たとえば、sinc関数を考えてみましょう（$\text{sinc}(x) = \frac{\sin(x)}{x}$で、0による除算を避けるために$\text{sinc}(0) = 1$と定義します）。

```swift
func sinc(_ x: Double) -> Double {
    guard x != 0 else { return 1 }
    return sin(x) / x
}

sinc(0)             // returns 1
sinc(Double.pi / 2) // returns 0.6366197723675814
```
