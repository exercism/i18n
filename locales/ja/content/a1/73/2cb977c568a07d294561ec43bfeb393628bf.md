# テスト

## テストの実行

テストを実行するには、次のコマンドを入力します。

```bash
$ gradle test
```

## さらにテストを有効にする

コードが有効なテストをすべて通ったら、次に気になるテストの前にある`@Ignore`を外して、別のテストを有効にします。方法は、`@Ignore`の行を削除するか、行の先頭にスラッシュを2つ付けてコメントアウトします。

```Groovy
//@Ignore
def 'outputs "Hello, Alice!" when given the name "Alice"'() {
    expect: hello.hello('Alice') == 'Hello, Alice!'
}
```
