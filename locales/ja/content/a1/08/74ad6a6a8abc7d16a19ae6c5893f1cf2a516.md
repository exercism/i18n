# 説明の補足

提供された電話番号の文字列を上書きします。
電話番号が無効な場合は、空の文字列に置き換えます。

## レジスタ

| レジスタ | 用途        | 型    | 説明                            |
| -------- | ------------ | ------- | -------------------------------------- |
| `$a0`    | 入力/出力 | アドレス | ヌル終端文字列としての電話番号 |
| `$t0-9`  | 一時    | 任意     | 一時的な保存に使います             |
