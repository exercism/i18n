# 説明の補足

## 入力例

```j
  INPUTS=: 2 ; 1 0 0 1 0 1 ; 10
```

つまり、入力は次のとおりです。
```
  0{INPUTS NB. is the input base.
  1{INPUTS NB. is the digits.
  2{INPUTS NB. is the output base.
```
## 無効な入力の扱い

入力値のいずれかが無効な場合、作成した動詞は`empty`（例：`0$0`や`''`）を返す必要があります。

### 例

- _入力の基数_が2より小さい場合：
    ```j
      '' -: rebase 10 ; 0 0 0 0 ; 1
    ```

- _出力の基数_が2より小さい場合：
    ```j
      '' -: rebase 1 ; 0 0 0 0 ; _7
    ```

- _数字_に、入力の基数以上の値が含まれている場合：
    ```j
      '' -: rebase 10 ; 1 0 2 0 ; 2
    ```
