# テスト

## テストを実行する

[インストール手順][test-installation-steps]が済んだら、どの演習ディレクトリ（例：`~/exercism/gdscript/two-fer`）からでも、スクリプト（1つ上の階層、`../`にあります）を実行して、その演習に対するローカルの解答をテストできるようになります。

```sh
../test-local-gdscript-solution.sh
```

## 演習を解く

演習を解くとは、その演習のテストをすべて通すことです。

まずは取りかかりやすくするために、各演習には演習名と同じ名前のGDScriptファイルが付いてきます（例：`exercism/gdscript/two-fer/two_fer.gd`）。
このファイルを出発点として、解答を作っていくことができます。
必要に応じて自由に変更してかまいませんが、テストは最初に用意されたままの関数名を期待しています。

[test-installation-steps]: https://exercism.org/docs/tracks/gdscript/tests
