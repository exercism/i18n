# はじめに

`Result`型は、Elmでエラーを報告するための解決策であり、エラーから復帰することを可能にしてくれるものでもあります。`Maybe`型と少し似ていますが、`Maybe`は失敗する可能性のある関数から返されることがあるものの、なぜ失敗したのかは何も教えてくれません。`Result`には、なぜ失敗したのかというこの文脈が含まれています。

`Result`型は次のように定義されています。

```elm
type Result error value
  = Ok value
  | Err error
```

これはElmの用語では「カスタム型」の定義と呼ばれます。`OK value`と`Error error`の`error`と`value`は型変数を表しており、`Int`や`Bool`、`String`など、どんな型でもよいという意味です。つまり、`Result String Int`は`Int`を持つことが期待される値で、エラーがある場合はそれが`String`で表されます。結果を扱うための便利な補助関数がたくさん入った[Resultモジュール](https://package.elm-lang.org/packages/elm/core/latest/Result)もあります。
