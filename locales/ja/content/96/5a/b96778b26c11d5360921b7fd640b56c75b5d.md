# 説明

ボースンは毎日、甲板で当直のブリーフィングを行います。決まった挨拶、勤務中の乗組員の点呼、そして最後に解散の言葉という流れです。このブリーフィングを、名前を付けた小さな行に分けて組み立てていきます。

この演習では、**2つのファイル**を編集します。

- `bosuns-briefing/helpers/helpers.factor`は、小さくて再利用できる部品です。ボキャブラリーは`bosuns-briefing.helpers`です。
- `bosuns-briefing/bosuns-briefing.factor`は、ヘルパーを組み立てるメインファイルです。ボキャブラリーは`bosuns-briefing`です。

## 1. 挨拶

`helpers.factor`で`greeting`を定義し、決まった書き出しの文字列`"All hands, attention!"`を返すようにします。

```factor
greeting .
! => "All hands, attention!"
```

## 2. 乗組員の行

`helpers.factor`で`crew-line`を定義し、名前の文字列を受け取って、その名前の前に`"  - "`（スペース2つ、ハイフン、スペース1つ）を付けたものを返すようにします。

```factor
"Lopez" crew-line .
! => "  - Lopez"
```

## 3. 締めの言葉

`helpers.factor`で`closing`を定義し、決まった解散の文字列`"Carry on."`を返すようにします。

```factor
closing .
! => "Carry on."
```

## 4. 名簿

`bosuns-briefing.factor`で`roster`を定義し、乗組員の名前の配列を受け取って、各名前を`crew-line`で整形し、改行でつないだ1つの複数行文字列を返すようにします。

```factor
{ "Lopez" "Mwangi" } roster .
! => "  - Lopez\n  - Mwangi"

{ } roster .
! => ""
```

## 5. ブリーフィング

`bosuns-briefing.factor`で`briefing`を定義し、乗組員の名前の配列を受け取って、ブリーフィング全体を1つの文字列として返すようにします。1行目に挨拶、続く行に名簿、最終行に締めの言葉を入れます。ヘルパーと`roster`を使います。

```factor
{ "Lopez" "Mwangi" } briefing .
! => "All hands, attention!\n  - Lopez\n  - Mwangi\nCarry on."

{ } briefing .
! => "All hands, attention!\n\nCarry on."
```
