# 説明

チェスの愛好家なら、このゲームの自分だけのバージョンを書いてみたくなるでしょう。ええ、すでにオンラインにはたくさんのチェスの実装があるかもしれませんが、自分だけのものは唯一無二です！

しかし、想像力を存分に働かせる前に、基本を押さえる必要があります。まずは盤面を生成するところから始めましょう。

チェス盤の各マスは、文字と数字の組み合わせで識別されます。マスの縦の列はファイルと呼ばれ、AからHまでのラベルが付いています。マスの横の行はランクと呼ばれ、1から8までの番号が付いています。

## 1. ランクの範囲を定義する

`rank_range/0`関数を実装してください。1から8までの整数の範囲を返す必要があります。

```elixir
Chessboard.rank_range()
```

## 2. ファイルの範囲を定義する

`file_range/0`関数を実装してください。大文字のAのコードポイントから、大文字のHのコードポイントまでの整数の範囲を返す必要があります。

```elixir
Chessboard.file_range()
```

## 3. ランクの範囲をランクの配列に変換する

`ranks/0`関数を実装してください。1から8までの整数の配列を返す必要があります。配列を手で書かず、`rank_range/0`関数が返す範囲から生成してください。

```elixir
Chessboard.ranks()
# => [1, 2, 3, 4, 5, 6, 7, 8]
```

## 4. ファイルの範囲をファイルの配列に変換する

`files/0`関数を実装してください。"A"から"H"までの文字（文字列）の配列を返す必要があります。配列を手で書かず、`file_range/0`関数が返す範囲から生成してください。

```elixir
Chessboard.files()
# => ["A", "B", "C", "D", "E", "F", "G", "H"]
```
