# はじめに

## 定数と関数

Haskellのプログラムは、定義と式からできています。

定数の値は、`name = expression`で定義します。

```haskell
five = 5

six = 3 + 3
```

関数は、`name parameters... = expression`で定義します。仮引数は、スペースだけで区切ります。

```haskell
add number1 number2 = number1 + number2
```

関数の呼び出しもまた式であり、関数名を指定して、その関数の仮引数それぞれに実引数をスペースで区切って渡すことで行います。書き方は関数の定義と同じです。

```haskell
five = add 2 3
```

括弧（`()`）を使うと、式を評価する順序を指定できます。

```haskell
six = add 2 (1 * 4)

twelve = add 2 1 * 4
```

## インデントと意味を持つ空白文字

Haskellでは、空白文字とインデントを使ってコードの境界を指定します。
***ある式の一部であるコードは、その式の先頭よりも深くインデントする必要があります。***

- モジュール、インポート、トップレベルの関数定義は、いちばん左の列から始めなければなりません。
- 式を複数の行に分ける場合、その式の一部であるコードは、その式の下に少なくとも1つのスペースでインデントしなければなりません。
- ひとまとまりになっている式の部分は、同じ数のスペースでインデントします。

```haskell
-- A function split over multiple lines, so subsequent lines must be indented
add number1 number2 =
    number1 + number2
```

https://en.wikibooks.org/wiki/Haskell/Indentation

## モジュール

モジュールは関数をエクスポートします。
つまり、モジュールがエクスポート文で公開している関数を使うことができます。
モジュールは、内部でだけ使う関数を定義することもできます。
デフォルトでは、明示的にエクスポートされていない関数は、モジュールの外部から使うことができません。

モジュールの先頭で、モジュール名を指定します。
Calculator.hsというファイルがあるなら、モジュールの名前もCalculatorにします。
そして、エクスポートする関数を指定し、そのあとで関数を書き始めます。
まずは、次のように書き始めます。

```haskell
module Calculator ( add ) where
```

https://learnyouahaskell.github.io/modules#making-our-own-modules

## コメント

コメントとは、Haskellのファイルの中にあるテキストのうち、コードとして解釈されないものです。
主に、書いた本人やほかのプログラマーが読むためのものです。
1行コメント用の軽量な書き方があり、2つのダッシュを使います。
複数行コメントも可能で、`{-`と`-}`の開き・閉じの区切り文字のペアを使います。

```haskell
-- a single line comment
-- another single line comment

{- a multiline comment
   spanning multiple lines
-}
```
