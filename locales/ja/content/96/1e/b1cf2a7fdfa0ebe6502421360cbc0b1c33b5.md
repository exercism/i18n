# 概要

C#では、[`null`リテラル][null-keyword]は値が存在しないことを表すために使います。_null許容_な型とは、`null`値を許容する型のことです。

C# 8.0より前は、参照型は常にnull許容で、値型はそうではありませんでした。ただし、[値型は、疑問符（`?`）を付けることでnull許容にできます][nullable-value-types]。

```csharp
string nullableReferenceType = "hello";
nullableReferenceType = null; // Valid as type is nullable

int nonNullableValueType = 5;
nonNullableValueType = null; // Compile error as type is not nullable

int? nullableValueType = 5; // Define nullable value type
nullableValueType = null;   // Valid as type is nullable
```

値が`null`の変数のメンバーにアクセスすると、コンパイルは通りますが、実行時に`NullReferenceException`がスローされます。

```csharp
string sentence = "What a nice day!";

// Throws NullReferenceException at runtime
sentence.Length;
```

このよくある種類のミスに対処するため、C# 8では、[参照型をデフォルトで非null許容にする][nullable-reference-types]機能に[オプトインする][nullable-csharp-8]ことができます。

```csharp
string nonNullableReferenceType = "book";
nonNullableReferenceType = null; // Compile warning (no error!)

string? nullableReferenceType = "movie";
nullableReferenceType = null; // Valid as type is nullable
```

[null許容の値を安全に扱う][nullable-types-tutorial]には、扱う前に値が`null`かどうかを確認しましょう。

```csharp
string NormalizedName(string? name)
{
    if (name == null)
    {
        return "UNKNOWN";
    }
    else
    {
        // Value is not null at this point, so no compile warning
        // and no runtime NullReferenceException being thrown
        return name.ToUpper();
    }
}

NormalizedName(null); // => "UNKNOWN"
NormalizedName("Elisabeth"); // => "ELISABETH"
```

[`??`演算子][null-coalescing-operator]を使うと、値が`null`のときにデフォルト値を返すことができます。

```csharp
string? name1 = "John";
name1 ?? "Paul"; // => "John"

string? name2 = null;
name2 ?? "George"; // => "George"
```

[`?.`演算子][null-conditional-operator]を使うと、`null`の可能性がある値に対して安全にメンバーを呼び出せます。

```csharp
string? fruit = "apple";
fruit?.Length; // => 5

string? vegetable = null;
vegetable?.Length; // => null
```

コンパイラーが値は`null`かもしれないと考えていても、`null`にはならないと確信できる場合は、[`!.`演算子][null-forgiving-operator]を使って警告を抑制できます。ただし、この演算子は最後の手段としてのみ使いましょう。

```csharp
void PrintName(string? name)
{
    // Assume that the IsValid() method only return true
    // when its argument is not null
    if (IsValid(name))
    {
        // No compile warning
        Console.WriteLine(name!.Length);
    }
}
```
