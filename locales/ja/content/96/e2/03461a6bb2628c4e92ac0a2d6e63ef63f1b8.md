# 指示の補足

## `Stream`アビリティについて

`Stream`は、値を発行するために使うUnisonのアビリティです。

呼び出されている間に、副次的な効果として値を生成する関数があるなら、`Stream`アビリティを使うことになるでしょう。たとえば、次の関数は配列の最後の値を返しますが、要素を1つ見るたびにそれまでの合計を発行します。

```
emitRunningTotal : '{Stream Nat} Nat
emitRunningTotal = 'let
  use Nat +
  List.foldLeft (
    acc a -> let
      runningTotal = acc + a
      Stream.emit runningTotal
      a
    ) 0 [1,2,3,4,5]
```

アビリティハンドラーを使えば、`Stream`を生成する関数の戻り値と一緒に、その`Stream`を`List`として実体化できます。

```
> Stream.toListWithResult! emitRunningTotal
  ⧩
  ([1, 3, 5, 7, 9], 5)
```
