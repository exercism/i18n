# 説明

この演習では、乗り物を買う準備を手伝うコードを書きます。

タスクは3つあります。1つは運転免許証が必要かどうかを判断すること、1つは2つの乗り物から選ぶ手助けをすること、もう1つは中古の乗り物の妥当な価格を見積もることです。

## 1. 運転免許証が必要かどうかを判断する

乗り物の種類によっては、運転するのに運転免許証が必要です。
種類が`"car"`と`"truck"`の場合だけ免許証が必要で、それ以外は免許証なしで運転できると仮定します。

乗り物の種類を引数に取り、その種類に運転免許証が必要かどうかを示す真偽値を返す`NeedsLicense(kind)`関数を実装します。

```go
needLicense := NeedsLicense("car")
// => true

needLicense = NeedsLicense("bike")
// => false

needLicense = NeedsLicense("truck")
// => true
```

## 2. 購入する乗り物を2つの候補から選ぶ

購入できる乗り物の選択肢を検討します。
2つの候補まで絞り込めましたが、最終的な決定には助けが必要です。
そのために、2つの乗り物を引数に取り、辞書順で先に来る方を含む判断を返す`ChooseVehicle(option1, option2)`関数を実装します。

```go
vehicle := ChooseVehicle("Wuling Hongguang", "Toyota Corolla")
// => "Toyota Corolla is clearly the better choice."

ChooseVehicle("Volkswagen Beetle", "Volkswagen Golf")
// => "Volkswagen Beetle is clearly the better choice."
```

## 3. 中古の乗り物の価格を見積もる

購入する乗り物が決まったので、ディーラーで妥当な価格で買えるようにしたいところです。
中古の乗り物を買うとなると、価格はその乗り物がどれくらい古いかによって変わります。
おおよその見積もりとして、乗り物が3年未満なら、新品だったときの価格の80%になるとします。
10年以上なら50%です。
3年以上10年未満なら、元の価格の70%です。

この条件を`if`、`else if`、`else`を使って処理する`CalculateResellPrice(originalPrice, age)`関数を実装します（練習したい場合は別の書き方でもかまいません）。
元の価格と乗り物の経過年数を引数に取り、ディーラーでの見積もり価格を返します。

```go
CalculateResellPrice(1000, 1)
// => 800

CalculateResellPrice(1000, 5)
// => 700

CalculateResellPrice(1000, 15)
// => 500
```

**注意**：戻り値は`float64`です。
