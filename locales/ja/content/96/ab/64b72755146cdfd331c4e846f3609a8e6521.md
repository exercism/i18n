# 指示

この演習では、お気に入りの料理本をもとに、最高のラザニアを作るためのコードを書いていきます。

ラザニアの調理にかかる時間に関わる、4つのタスクがあります。

## 1. オーブンに入れておくべき時間（分）を定義する

ラザニアをオーブンに入れておくべき時間（分）を確認するために、変数`expected-time`を定義します。料理本によると、オーブンに入れておくべき時間は40分です。

```clojure
expected-time
;;=> 40
```

## 2. オーブンに入れておく残りの時間（分）を計算する

`remaining-time`関数を定義します。この関数は、ラザニアを実際にオーブンに入れておいた時間（分）を引数として受け取り、前のタスクで求めたオーブンに入れておくべき時間（分）をもとに、あと何分オーブンに入れておく必要があるかを返します。

```clojure
(remaining-time 30)
;;=> 10
```

## 3. 準備にかかる時間（分）を計算する

`prep-time`関数を定義します。この関数は、ラザニアに重ねた層の数を引数として受け取り、1層あたり2分かかるものとして、ラザニアの準備に何分かかったかを返します。

```clojure
(prep-time 2)
;;=> 4
```

## 4. 作業時間の合計（分）を計算する

`total-time`関数を定義します。この関数は2つの引数を取ります。1つ目の引数はラザニアに重ねた層の数、2つ目の引数はラザニアをオーブンに入れておいた時間（分）です。この関数は、ラザニアの調理にかけた合計時間（分）を返します。これは、準備にかかった時間（分）と、その時点までラザニアがオーブンにあった時間（分）を足したものです。

```clojure
(total-time 3 20)
;;=> 26
```
