# 概要

曜日や方位、コントローラーのボタンなど、取り得る状態が限られているデータをモデル化するとき、`Int`や`String`のような基本的な型には大きな欠点があります。
整数や文字列を使うと、コードは無効な値（`999`というステータスコードや`"leftt"`のようなタイプミスなど）を常にチェックしなければならず、人間の読者もその数値が何を表しているのかをすぐには読み取れません。

Swiftは、この問題を[_列挙型_][enumerations]（しばしば*enum*と略されます）で解決します。
列挙型は、関連する名前付きの値のグループに対して共通の型を定義します。コンパイラはあり得るすべてのケースをあらかじめ把握しているため、コンパイル時にコードの正確さと網羅性をチェックできます。
列挙型はメソッド、イニシャライザ、計算プロパティを持つこともできます。

## 列挙型の定義

`enum`キーワードに続けて型名を書き、波括弧の中にケースを並べて列挙型を定義します。
Swiftの慣習では、型名は`UpperCamelCase`、各ケースは`lowerCamelCase`を使います。

```swift
enum NESButton {
    case up
    case down
    case left
    case right
    case a
    case b
    case select
    case start
}
```

複数のケースをカンマで区切って1行にまとめて定義することもできます。

```swift
enum NESButton {
    case up, down, left, right, a, b, select, start
}
```

列挙型のケースを参照するには、列挙型の型名、ドット（`.`）、そしてケース名を書きます。型が既知であるか、コンパイラが推論できる場合は、型名を省略してより短いドット構文を使えます。

```swift
var lastPressed = NESButton.up

// Swift infers the type, so you can omit the type name:
lastPressed = .down

let konamiCode: [NESButton] = [.up, .up, .down, .down, .left, .right, .left, .right, .b, .a]
```

## 列挙型と`switch`文

列挙型は[`switch`文][enums-and-switches]とシームレスに組み合わせられます。
Swiftの`switch`は網羅的でなければならないため、コンパイラはあり得るすべてのケースを処理していることを保証します。

```swift
lastPressed = .left
switch lastPressed {
case .up: print("You pressed the UP button")
case .down: print("You pressed the DOWN button")
case .left: print("You pressed the LEFT button")
case .right: print("You pressed the RIGHT button")
case .a: print("You pressed the A button")
case .b: print("You pressed the B button")
case .select: print("You pressed the SELECT button")
case .start: print("You pressed the START button")
}
// Prints "You pressed the LEFT button"
```

`default`句を指定せずにいずれかのケースを漏らすと、コンパイラがエラーを報告します。

```swift
switch lastPressed {
case .up, .down, .left, .right:
    print("You pressed a direction button.")
}
// Error: Switch must be exhaustive
```

すべてのケースを明示的に列挙することは、しばしば`default`を使うよりも好ましいです。そうしておけば、将来新しいケースを追加したときに、その列挙型を扱うすべての`switch`文を更新するよう、コンパイラがすぐに知らせてくれます。

## メソッドとイニシャライザ

列挙型は、クラスや構造体と同じように、メソッドやカスタムイニシャライザを定義できます。列挙型のメソッドの内部では、`self`は現在のケースの値を指します。

```swift
enum Coin {
    case heads
    case tails

    init(_ value: Int) {
        if value.isMultiple(of: 2) {
            self = .heads
        } else {
            self = .tails
        }
    }

    func flip() -> Coin {
        switch self {
        case .heads: return .tails
        case .tails: return .heads
        }
    }
}

let tails = Coin(13)     // .tails
let heads = Coin(0)      // .heads
let flipped = heads.flip() // .tails
```

## 生の値

列挙型のケースには、あらかじめデフォルト値を設定できます。これを[_生の値_][raw-values]と呼びます。
列挙型の生の値はすべて同じ型（`Int`、`String`、`Character`など）でなければなりません。

```swift
enum NESButton: Character {
    case up = "⬆️"
    case down = "⬇️"
    case left = "⬅️"
    case right = "➡️"
    case a = "🅰️"
    case b = "🅱️"
    case select = "✅"
    case start = "🚦"
}

print(NESButton.left.rawValue) // Prints "⬅️"
```

`init(rawValue:)`を使って生の値から列挙型を初期化できます。無効な生の値が渡される可能性があるため、このイニシャライザはオプショナルを返します。

```swift
let upButton = NESButton(rawValue: "⬆️") // Optional(NESButton.up)
let invalid = NESButton(rawValue: "🙄")  // nil
```

Swiftは`String`と`Int`の列挙型には生の値を自動的に割り当てることができます。

- `String`の列挙型では、各ケースの生の値はデフォルトでそのケース名になります。
- `Int`の列挙型では、特に指定しない限り、生の値は`0`から始まり1ずつ増えていきます。

```swift
enum Planet: Int {
    case mercury = 1, venus, earth, mars
}

print(Planet.earth.rawValue) // Prints 3
```

## 関連値

列挙型のケースは、各ケースと一緒に、さまざまな型のカスタム値を保持することもできます。これを[_関連値_][associated-values]と呼びます。

```swift
enum Suit: Character {
    case diamonds = "♦️", clubs = "♣️", hearts = "♥️", spades = "♠️"
}

enum Card {
    case ace(Suit)
    case king(Suit)
    case queen(Suit)
    case jack(Suit)
    case number(Suit, Int)

    func description() -> String {
        switch self {
        case .ace(let suit): return "A\(suit.rawValue)"
        case .king(let suit): return "K\(suit.rawValue)"
        case .queen(let suit): return "Q\(suit.rawValue)"
        case .jack(let suit): return "J\(suit.rawValue)"
        case let .number(suit, value): return "\(value)\(suit.rawValue)"
        }
    }
}

let aceOfSpades = Card.ace(.spades)
let twoOfHearts = Card.number(.hearts, 2)

print(aceOfSpades.description()) // Prints "A♠️"
print(twoOfHearts.description()) // Prints "2♥️"
```

列挙型は生の値と関連値のどちらか一方を使えますが、両方を使うことはできません。

## 再帰的列挙型

[再帰的列挙型][recursive-enumerations]とは、1つ以上のケースの関連値として、その列挙型自身の別のインスタンスを持つ列挙型です。
再帰を可能にするには、そのケース（または列挙型全体）に`indirect`キーワードを付けます。

```swift
enum BinaryTree {
    case leaf(value: Int)
    indirect case node(left: BinaryTree, value: Int, right: BinaryTree)
}

let tree: BinaryTree = .node(
    left: .leaf(value: 1),
    value: 3,
    right: .node(left: .leaf(value: 5), value: 6, right: .leaf(value: 9))
)
```
