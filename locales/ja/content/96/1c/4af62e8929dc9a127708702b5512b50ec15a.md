# はじめに

## 変数

Elixirは動的型付け言語です。つまり、変数の型がチェックされるのは実行時だけです。マッチ演算子`=`を使うと、どんな型の値でも変数名に束縛できます。

```elixir
# Bound an integer value of 1
count = 1
# You may re-bind variables
count = 2

# You may re-bind any type to a variable
count = false

# Strings can be created by enclosing characters within double quotes
message = "Success!"
```

## モジュール

Elixirは[関数型プログラミング言語][functional-programming]であり、名前を持つ関数はすべて_モジュール_の中で定義する必要があります。モジュールを定義するには`defmodule`キーワードを使います。すべてのモジュールは実行時にほかのすべてのモジュールから利用でき、プログラムのほかの部分から見えるようにするための_アクセス修飾子_は必要ありません。_モジュール_は、ほかのプログラミング言語でいう_クラス_に似ています。

```elixir
defmodule Calculator do
  # ...
end
```

## 名前付き関数

_名前付き関数_はモジュールの中で定義する必要があります。`def`キーワードを使うと、_公開_の名前付き関数を定義できます。

関数は、引数を0個以上受け取ることができます。関数内の最後の式の値は、常に_暗黙的に返され_ます。

```elixir
defmodule Calculator do
  def add(x, y) do
    x + y
  end
end
```

関数を呼び出すには、そのモジュール名と関数名を指定し、関数の引数それぞれに値を渡します。

```elixir
sum = Calculator.add(1, 2)
# => 3
```

`def`の代わりに`defp`キーワードを使うと、_非公開_の関数を定義できます。非公開の関数は、それを定義した同じモジュールの中からしか使えません。

定義されているのと同じモジュールの中で関数を呼び出すときは、モジュール名を省略できます。

短い関数は、1行の構文で書くこともできます（キーワード`do`の前後のカンマ`,`とコロン`:`に注目してください）。

```elixir
defmodule Calculator do
  def subtract(x, y) do
    private_subtract(x, y)
  end

  defp private_subtract(x, y), do: x - y
end

difference = Calculator.subtract(7, 2)
# => 5

difference = Calculator.private_subtract(7, 2)
# => ** (UndefinedFunctionError) function Calculator.private_subtract/2 is undefined or private
#       Calculator.private_subtract(7, 2)
```

## 関数のアリティ

関数は、その_アリティ_を添えて呼ぶことが一般的です。関数の_アリティ_とは、その関数が受け取る引数の数です。

```elixir
# add/3 because this function has three arguments, thus an arity of 3
def add(x, y, z) do
  x + y + z
end
```

## 命名規則

モジュール名には`PascalCase`を使います。モジュール名は大文字の`A-Z`で始まる必要があり、英字`a-zA-Z`、数字`0-9`、アンダースコア`_`を含めることができます。

変数名と関数名には`snake_case`を使います。変数名や関数名は小文字の`a-z`かアンダースコア`_`で始まる必要があり、英字`a-zA-Z`、数字`0-9`、アンダースコア`_`を含めることができ、疑問符`?`や感嘆符`!`で終わることもあります。

## 標準ライブラリ

Elixirには、とても充実していてドキュメントも整った標準ライブラリがあります。ドキュメントは[hexdocs.pm/elixir][docs]でオンライン公開されています。このリンクはどこかに保存しておきましょう。頻繁に使うことになりますよ！

ほとんどの組み込みデータ型には、そのデータ型を扱う関数を提供する対応するモジュールがあります。たとえば、整数には`Integer`モジュール、文字列には`String`モジュール、リストには`List`モジュールがあります。

特に注目すべきは`Kernel`モジュールです。算術演算子や制御フローのマクロなど、標準ライブラリの残りの部分がその上に成り立っている基本的な機能を提供しています。`Kernel`モジュールの関数は自動的にインポートされるので、`Kernel.`というプレフィックスなしで使えます。

## コードコメント

コメントを使うと、ソースコードを読むほかのエンジニアのためにメモを残せます。Elixirの1行コメントは、`#`を行の先頭に付けます。
