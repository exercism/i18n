# はじめに

Haskellには、すべての数値型の基底となる型`Num`があります。
数値型には、主に4つのサブタイプがあります：[`Int`][int]、[`Integer`][integer]、[`Double`][double]、[`Float`][float]。

Haskellには、整数を表す整数型が2つあります。
`Int`は固定サイズの整数で、`Integer`は任意精度の整数です。
`Integer`は、マシンのメモリの許す限り、どんなに大きな数でも保持できます。一方、`Int`は、32ビットまたは64ビットで表現できる正負の整数の集合に対応します（少なくとも-2^29から2^29 - 1までが保証されています）。

負の数を書くときは、曖昧さを避けるために括弧を使うようにしましょう。

```haskell
1

(-1)
```

`Float`は実数の集合に対応し、コンピューターの精度によって制限されます。
数値に対して定義された演算は、ふつうどちらか一方の型では機能しますが、両方では機能しません。
`Double`は倍精度の浮動小数点数です。

```haskell
10.5
```

## 整数と浮動小数点数の変換

`toFloat`関数を使うと、`Int`や`Integer`を`Float`に変換できます。

```haskell
toFloat 1
-- -> 1.0
```

また、`fromIntegral`を使うと、任意の数値型を、推論された必要な数値型に変換できます。

```haskell
fromIntegral 1
-- -> 1.0
```

`Float`を`Int`に変換するには、[`round`][round]、[`floor`][floor]、[`ceiling`][ceiling]の各関数を使います。
`round`関数は最も近い整数に丸め、`floor`は切り捨て、`ceiling`は切り上げます。

```haskell
round 1.5
-- -> 2

floor 1.5
-- -> 1

ceiling 1.5
-- -> 2
```

## 算術演算子

数値型では、[基本的な算術演算子][math]を使えます。
演算子は`+`、`-`、`*`、`/`、`%`です。
これらの演算子を使うときは、数値の型が一致している必要があります。
`fromIntegral`関数を使うと、型が一致するように変換されます。

### 加算・減算・乗算

`+`演算子は加算に、`-`演算子は減算に、`*`演算子は乗算に使います。

| 演算子 | 例 |
| -------- | -------------- |
| `+`      | `4 + 6 => 10`  |
| `-`      | `15 - 10 => 5` |
| `*`      | `2 * 3 => 6`   |

### 除算

除算は、数を割るために使います。
除算には`/`演算子を使います。
結果は常に浮動小数点数になります。

```haskell
4.0 / 2.5
-- -> 1.6

4 / 2
-- -> 2.0
```

~~~~exercism/caution
プログラミング言語によっては、ゼロで割るとエラーになります。

Haskellでは、ゼロで割ると、結果は`Infinity`または`-Infinity`になります。
唯一の例外はゼロをゼロで割る場合で、結果は`NaN`（Not a Number）になります。

```haskell
1 / 0
-- -> Infinity

(-1) / 0
-- -> -Infinity

0 / 0
-- -> NaN
```
~~~~

## 整数除算

整数除算は、整数同士を割って結果の整数部分を求めるために使います。
Haskellには整数除算の関数が2つあり、結果が負になるときの丸め方が異なります。

- `div`は負の無限大に向かって切り捨てます。
- `quot`はゼロに向かって丸めます。

```haskell
6 `div` 2
-- -> 3

5 `div` 2
-- -> 2

(-5) `div` 2
-- -> -3

5 `quot` 2
-- -> 2

(-5) `quot` 2
-- -> -2
```

~~~~exercism/caution
整数除算でゼロ除算を行うと、例外が発生します。
これは通常の除算とは異なります。
~~~~

### 余り

整数除算の余りは、`mod`または`rem`を使って求められます。
どちらも、一方の数が負のときの結果の符号が異なります。

- `mod`は`div`と対応し、結果の符号は除数と同じになります。
- `rem`は`quot`と対応し、結果の符号は被除数と同じになります。

```haskell
5 `mod` 3
-- -> 2

(-5) `mod` 3
-- -> 1

5 `mod` (-3)
-- -> -1

5 `rem` 3
-- -> 2

(-5) `rem` 3
-- -> -2

5 `rem` (-3)
-- -> 2
```

任意の`x`と`y`（`y`がゼロでない場合）について、次の法則が成り立ちます。

```haskell
(x `div` y) * y + (x `mod` y) == x
(x `quot` y) * y + (x `rem` y) == x
```

~~~~exercism/note
両方の数が正のときは、`div`と`quot`は同じ結果になり、`mod`と`rem`も同じ結果になります。
その場合、`quot`と`rem`のほうがわずかに効率的です。`div`と`mod`は負の数を扱うために追加の処理が必要だからです。
~~~~

~~~~exercism/caution
`mod`や`rem`でゼロ除算を行うと、例外が発生します。
これは通常の除算とは異なります。

```haskell
1 `mod` 0
-- Exception: divide by zero
```
~~~~

## べき乗

Haskellには「べき乗」を行う3つの演算子があり、それぞれ動作と受け取る引数の型が異なります。

- `**`は2つの**浮動小数点数**を受け取り、対数を使ってべき乗を計算します。
- `^^`は**浮動小数点数**を受け取り、正または負の**整数**乗を行います。
- `^`は**任意の数値型**を受け取り、**正の整数**乗を行います。

```haskell
3.0 ** 2.1
-- -> 10.04510856630514

2.5 ^^ 2
-- -> 6.25

2 ^ 3
-- -> 8
```

## 優先順位と括弧

Haskellでは括弧（`()`）を使え、式をまとめることができます。
演算の順序を変えたいときに便利です。

複数の算術演算子を使う場合、演算の順序は数学と同じで、[PEMDAS][pemdas]としても知られています。
括弧（`()`）、指数（`**`）、乗算（`*`）と除算（`/`）、加算（`+`）と減算（`-`）の順に従います。

```haskell
2 + 3 - 4 * 4
-- -> -11

(2 + 3 - 4) * 4
-- -> 4
```
