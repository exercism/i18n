# 真偽値

Crystalには、[`Bool`][bools]という型があります。
これは`true`と`false`という値を表します。

## 論理演算子

Crystalには3つの論理演算子（`!`、`||`、`&&`）があり、これらは真偽値を組み合わせて、異なる値を生み出す式を作ります。

### AND（`&&`）

Crystalの[AND演算子][and]は`&&`で表され、2つの値がどちらも`true`なら`true`を返し、そうでなければ`false`を返します。
AND演算子を使うときは、`&&`の右側に1つの真偽値を、左側にもう1つの真偽値を置きます。

```crystal
true && true
# => true

true && false
# => false
```

### OR（`||`）

Crystalの[OR演算子][or]は`||`で表され、与えられた値のうち**少なくとも1つ**が`true`なら`true`を返します。
2つの値がどちらも`false`なら、`false`を返します。
OR演算子を使うときは、`||`の右側に1つの真偽値を、左側にもう1つの真偽値を置きます。

```crystal
true || true
# => true

true || false
# => true

false || false
# => false
```

### NOT（`!`）

CrystalのNOT演算子は`!`で表され、与えられた真偽値が`false`なら`true`を返し、`true`なら`false`を返します。
NOT演算子を使うときは、演算子（`!`）の後に1つの真偽値を置きます。

```crystal
!true
# => false

!false
# => true
```

## 括弧（`()`）を使う

真偽値を扱うときは、括弧を使って、どの真偽値を先に評価するかを決められます。
括弧の使い方によって、結果が変わることがあります。
Crystalでは、括弧の中が先に評価されます。

```crystal
true && false && false || true
# => true

true && false && (false || true)
# => false
```

括弧の中が先に評価されるので、次の例ではNOT演算子は括弧の中の式に適用されます。

```crystal
!true && false
# => false

!(true && false)
# => true
```

~~~~exercism/note
括弧は、結果に影響するときだけ使ってください。それ以外の場合は省略してください。
~~~~

## truthyとfalsey

Crystalでは、「falsey」とされる値は`false`、`nil`、そしてヌルポインターです。それ以外はすべて「truthy」です。
これらの値は、上で説明した論理演算子と一緒に使えます。

```crystal

true && nil
# => false

false && 4
# => false

true || nil
# => true
```

## 真偽値に関するメソッドの命名規則

Crystalでは、truthyまたはfalseyな値を返すメソッドには、疑問符（`?`）を付けるのが一般的です。
ほとんどの場合、そのメソッドは真偽値を返しますが、必ずしもそうとは限りません。
つまり、そのメソッドは、truthyまたはfalseyな値が期待される場所、たとえば`if`文の条件で使えます。

```crystal
def exchange(value)
    if value.nil?
        value = 5
    end
    value
end

exchange(10)
# => 10

exchange(nil)
# => 5
```

名前に疑問符が付いていても真偽値を返さないメソッドは、代わりに`nil`を返すことがよくあります。`nil`は、他の言語の`None`や`null`に似たものです。
