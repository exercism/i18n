## ペア

`Pair`は、ちょうど2つの要素を持つデータ構造で、その要素には`first`と`second`というフィールドでアクセスできます。

`x => y`を使って作成できます。

```julia-repl
julia> p = 3 => true
3 => true

julia> p.first
3

julia> p.second
true
```

`Pair`の要素は、それぞれ異なる型でもかまいません。

```julia-repl
julia> typeof(p)
Pair{Int64,Bool}
```

`Pair`はJuliaでよく使われる場面が2つあります。辞書と置換です。

### 置換

多くの置換メソッドは、どの要素を置き換えるのかを分かりやすくするために、引数として`Pair`を受け取ります。
これにより、次のような構文が書けます。

```julia-repl
julia> replace!([1, 3, 4, 1], 4 => 0)
4-element Array{Int64,1}:
 1
 3
 0
 1
```

ここでは、コレクション内の各`4`が`0`に置き換わります。次のような、より分かりにくい構文を使うのではなく、

```julia
replace!([1, 3, 4, 1], 4, 0) # this method doesn't exist
```
