# 補足説明

## トラック固有の説明

かつてElmは関数的リアクティブプログラミングを採用していましたが、のちにElmアーキテクチャへと特化していきました。

Elmアーキテクチャを使ってWebアプリを書くつもりで、この演習を解いてみましょう。
プログラムの出力は、次の構造のHTMLにします。

```html
<div>
  <dl>
    <dt>State</dt>
    <dd>Ongoing</dd>
    <dt>Word</dt>
    <dd>______</dd>
    <dt>Remaining failures</dt>
    <dd>5</dd>
  </dl>
</div>
```

ここで`<dl>`は記述リスト要素、`<dt>`は記述項目要素、`<dd>`は記述内容要素で、いずれも標準のHTML要素です。

エラーが発生した場合は、出力を次の構造にします。

```html
<div>
  <p>error message</p>
</div>
```
