# はじめに

## 比較

C++では、比較演算子を使って値を比較できます。

| 比較              | 演算子    |
| ------------------| --------- |
| 等しい            | `==`      |
| 等しくない        | `!=`      |
| より小さい        | `<`       |
| 以下              | `<=`      |
| より大きい        | `>`       |
| 以上              | `>=`      |

これらの比較の結果は、常に真偽値になります。

```cpp
int a{3};

bool eq1 = a != 4; // true

bool eq2 = a > 5;  // false
```

`==`と`!=`の演算子は、それぞれある値が別の値と等しいかどうかを調べます。
よくある例をいくつか見てみましょう。

```cpp
bool eq3 = 2 == 3; // false, integer comparison

bool eq4 = 2.1 != 2.2; // true, float comparison

bool eq5 = "hello" == "hello"; // true, string comparison
```

その他の演算子は、ある値が別の値より大きいか（`>`）、以上か（`>=`）、より小さいか（`<`）、以下か（`<=`）を調べます。
この種の比較は、数値と文字列で使うことができます。
文字列を比較するときは、辞書順（辞書式順序とも呼ばれます）に従います。

```cpp
bool eq6 = 2 > 3; // false, integer comparison

bool eq7 = 1.2 < 1.3; // true, float comparison

bool eq8 = "Hello" < "World"; // true, string comparison
```

## `if`文

C++の条件分岐は、他の言語の条件分岐とよく似ています。
条件式の基になる型は`bool`型で、値は`true`か`false`のどちらかです。
条件分岐は、さまざまな条件を調べるための流れの制御としてよく使われます。

条件が`true`のときにコードを実行する`if`文は、次のように書きます。

```cpp
std::string value{"val"};

if (value == "val") {
    return "was val";
}
```

複数の場合を扱うときは、`else if`文と`else`文を使って、たくさんの`if`文をつなげることができます。

```cpp
int number{33};

if (number > 0) {
   return "positive";
} else if (number < 0) {
    return "negative";
} else {
   return "zero";
}
```

C++17以降では、`if`文に短い初期化文を書くこともできます。
これは、その`if`文で使う1つ以上の変数を初期化するために使えます。
たとえば、次のようになります。

```cpp
int num{7};
if (int v{2 * num}; v > 10) {
    return v;
} else {
    return num;
}
// => 14
```

> 注意：初期化で作られた変数は、`if`文の終わりより後ではアクセスできません。
