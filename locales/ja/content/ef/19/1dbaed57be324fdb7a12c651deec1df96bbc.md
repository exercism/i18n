# はじめに

## 正規表現

正規表現（regex）は、Elixirで文字列を扱うための強力なツールです。Elixirの正規表現は、**PCRE**仕様（**P**erl **C**ompatible **R**egular **E**xpressions）に従います。正規表現の意味を表す文字列パターンは、まずコンパイルされ、その後、文字列全体または一部のマッチングに使われます。

Elixirで正規表現を作る最も一般的な方法は、`~r`シジルを使うことです。シジルは、Elixirでよくある作業を短く書くための_糖衣構文_を提供します。_文字列リテラル_にマッチさせるには、シジルの後ろにその文字列自体をパターンとして書きます。

```elixir
~r/test/
```

`=~/2`演算子を使うと、文字列に対して正規表現のマッチを行い、`boolean`の結果を得ることができます。

```elixir
"this is a test" =~ ~r/test/
# => true
```

シジルを使う際の注意点が2つあります。

- 要件に応じて、`/`以外にもさまざまな区切り文字を使えます
- 文字列パターンはすでに_エスケープ_されています。正規表現を使わずにパターンを文字列として書く場合は、バックスラッシュ（`\`）を_エスケープ_する必要があります

### 文字クラス

角括弧`[]`を使って文字の範囲を指定すると、_文字クラス_を定義できます。これは、クラスに含まれる文字のいずれか1文字にマッチします。始点と終点が連続したコードポイントの範囲を表していれば、`a-z`のように文字の範囲を指定することもできます。

```elixir
regex = ~r/[a-z][ADKZ][0-9][!?]/
"jZ5!" =~ regex
# => true
"jB5?" =~ regex
# => false
```

_省略形の文字クラス_を使うと、パターンをより簡潔に書けます。たとえば、次のとおりです。

- `\d`は`[0-9]`の省略形（任意の数字）
- `\w`は`[A-Za-z0-9_]`の省略形（任意の「単語」文字）
- `\s`は`[ \t\r\n\f]`の省略形（任意の空白文字）

_省略形の文字クラス_をシジルの外で使う場合は、エスケープする必要があります：`"\\d"`

### 選択

_選択_では、`|`を特殊文字として使い、どちらか一方にマッチすることを表します。

```elixir
regex = ~r/cat|bat/
"bat" =~ regex
# => true
"cat" =~ regex
# => true
```

### 量指定子

_量指定子_を使うと、正規表現でパターンを繰り返せます。量指定子は、その直前のグループに作用します。

- `{N, M}`：`N`が繰り返しの最小回数、`M`が最大回数
- `{N,}`：`N`回以上の繰り返しにマッチ
  - `{0,}`は`*`とも書けます：0回以上の繰り返しにマッチ
  - `{1,}`は`+`とも書けます：1回以上の繰り返しにマッチ
- `{,N}`：最大`N`回の繰り返しにマッチ

### グループ

丸括弧`()`は、_グループ_と_キャプチャ_を表すために使います。グループは、場合によっては_キャプチャ_され、あとで使えるように返されます。Elixirでは、キャプチャに名前を付けることも、付けないこともできます。名前を付けるには、開き括弧の後に`?<name>`を追加します。グループは、_量指定子_が続く場合のように、1つのまとまりとして機能します。

```elixir
regex = ~r/(h)at/
Regex.replace(regex, "hat", "\\1op")
# => "hop"

regex = ~r/(?<letter_b>b)/
Regex.scan(regex, "blueberry", capture: :all_names)
# => [["b"], ["b"]]
```

### アンカー

_アンカー_は、正規表現をマッチ対象の文字列の先頭または末尾に固定するために使います。

- `^`は文字列の先頭に固定します
- `$`は文字列の末尾に固定します

### 補間

`~r`は`"pattern" |> Regex.escape() |> Regex.compile!()`の省略形なので、文字列補間を使って正規表現パターンを動的に組み立てることもできます。

```elixir
anchor = "$"
regex = ~r/end of the line#{anchor}/
"end of the line?" =~ regex
# => false
"end of the line" =~ regex
# => true
```
