# はじめに

C#の例外を使うと、実行時に起きるエラーを、構造化された統一的な、型安全な方法で扱えます。アプリケーションのクラッシュを防ぐには、例外やエラーを適切に扱うことが大切です。

C#では、すべての例外の基底型は`System.Exception`クラスです。このクラスには、`Message`のようないくつかの重要なプロパティがあります。`Message`には、例外がスローされた理由を人間が読める形で表した説明が入っています。

コードのある部分でエラーが起きたことを知らせるには、新しい例外オブジェクトを作成し、`throw`キーワードを使ってスローします。

```csharp
using System;
static int Square(int number)
{
    if (number >= 46341)
    {
        throw new ArgumentException($"Argument {number} cannot be higher than 46340 as its' square doesn't fit into int type.");
    }
    return number * number;
}
```

例外がスローされると、ランタイムは、その例外の処理を担当するコードを探す役割を担います。適切なハンドラーが見つからない場合、ランタイムはプログラムの実行を停止し、あわせて未処理の例外のメッセージを表示します。

例外のハンドラーを作るには、C#ではtry-catch文を使います。これは`try`ブロックと1つ以上の`catch`節で構成されます。`try`ブロックには、例外がスローされる可能性のあるコードを入れて保護します。`catch`節には、エラーが起きたあとのプログラムの動作を扱うコードを書きます。`try`ブロックのあとでは例外の順序が重要になることに注意してください。複数の例外を並べたときは、最初に一致した`catch`節が実行されます。

```csharp
try
{
   if (number == 42)
   {
       throw new ArgumentException("The number cannot be equal to 42.", "number");
   }

   if (number < 0)
   {
      throw new ArgumentOutOfRangeException("number", "The number cannot be negative.");
   }

    // Process number ...
}
catch (ArgumentOutOfRangeException e)
{
    Console.WriteLine($"Number is out of range: {e.Message}.");
}
catch (ArgumentException)
{
    Console.WriteLine("Invalid number.");
}
```
