# デバッグ

現在のテストランナーは[PonyTest](https://stdlib.ponylang.io/pony_test--index/)を利用しているため、`Main`アクターは`test.pony`にあり、解答の一部として編集するべきではありません。

Ponyアプリケーションのベストプラクティスとして、必要でない限り`Env`へのアクセスは提供していません。つまり、ほとんどすべての場合において、`env.out.print()`を使ったprintf形式のデバッグはできません。

しかし、Ponyには[debug](https://stdlib.ponylang.io/debug--index/)モジュールがあり、`-d`フラグを付けてコンパイルされたプログラムは、`Env`にアクセスしなくてもSTDOUTとSTDERRに特別にアクセスできます。

printf形式のデバッグが必要なときは、この機能を使いましょう。

デバッグの例：

```pony
use "debug"

actor Main
  new create(env: Env) =>
    MySolution.examplefn("First String", 42)

primitive MySolution
  fun examplefn(arg1: String, arg2: USize) =>
    Debug.out("arg1: " + arg1 + ", arg2: " + arg2.string() + " were provided to MySolution.examplefn()")
```
