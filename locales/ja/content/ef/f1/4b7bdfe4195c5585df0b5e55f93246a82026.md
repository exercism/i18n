# 概要

Common Lispでは、すべてが式です。  
式は、単一のもの（これをアトムと呼びます）か、括弧（`()`）で区切られたもののリストのどちらかです。

## クォート

シンボルをはじめ、すべてのS式はクォートできます。

```lisp
;; This line is evaluated as code
(gimme-foo)  ; => FOO

;; This line is treated as data
'(gimme-foo) ; => (GIMME-FOO)
```

このクォートによって、S式は評価されなくなり、代わりにデータとして扱われます。
