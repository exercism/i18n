# 説明

オンラインのファッションブティックでの仕事は続きます。ユーザーにコーディネートを提案するウェブサイトの機能を思いつきます。たくさんの提案をしたい一方で、質の悪い提案はしたくありません。そこで、リスト内包表記を使うことにします。コーディネートの組み合わせを簡単に_生成_し、その後、いくつかの条件で_絞り込める_からです。

衣類のアイテムはマップとして保存されています：

```elixir
%{
  item_name: "Descriptive Name",
  price: 99.00,
  color: "Ochre Red",
  base_color: "red"
}
```

## 1. 組み合わせを提案する

`get_combinations/3`を実装し、トップスの配列、ボトムスの配列、そしてオプションのキーワードリストを受け取るようにします。とりあえず、オプションのデフォルトは空のキーワードリストにします。関数は、これらの配列の直積を返すようにします。

```elixir
tops = [
  %{item_name: "Dress shirt"},
  %{item_name: "Casual shirt"}
]

bottoms = [
  %{item_name: "Jeans"},
  %{item_name: "Dress trousers"}
]

BoutiqueSuggestions.get_combinations(tops, bottoms)
# => [
#      {%{item_name: "Dress shirt"}, %{item_name: "Jeans"}},
#      {%{item_name: "Dress shirt"}, %{item_name: "Dress trousers"}},
#      {%{item_name: "Casual shirt"}, %{item_name: "Jeans"}},
#      {%{item_name: "Casual shirt"}, %{item_name: "Dress trousers"}}
#    ]
```

## 2. 色がぶつかるコーディネートを除外する

それぞれの衣類には`:base_color`フィールドがあります。このフィールドを使って、トップスとボトムスのベースカラーが同じ組み合わせをすべて除外します。

```elixir
tops = [
  %{item_name: "Dress shirt", base_color: "blue"},
  %{item_name: "Casual shirt", base_color: "black"}
]

bottoms = [
  %{item_name: "Jeans", base_color: "blue"},
  %{item_name: "Dress trousers", base_color: "black"}
]

BoutiqueSuggestions.get_combinations(tops, bottoms)
# => [
#      {%{item_name: "Dress shirt", base_color: "blue"},
#       %{item_name: "Dress trousers", base_color: "black"}},
#      {%{item_name: "Casual shirt", base_color: "black"},
#       %{item_name: "Jeans", base_color: "blue"}}
#    ]
```

## 3. 組み合わせの価格で絞り込む

それぞれの衣類には`:price`フィールドが紐づいています。たくさんの提案をしたい一方で、予算内の価格を選べる機会をユーザーに提供したいと考えています。オプションのキーワードリストから`:maximum_price`を使い、トップスとボトムスの価格が上限価格を超える組み合わせを除外します。

maximum_priceが指定されていない場合、デフォルトは`100.00`にします。

```elixir
tops = [
  %{item_name: "Dress shirt", base_color: "blue", price: 35},
  %{item_name: "Casual shirt", base_color: "black", price: 20}
]

bottoms = [
  %{item_name: "Jeans", base_color: "blue", price: 30},
  %{item_name: "Dress trousers", base_color: "black", price: 75}
]

BoutiqueSuggestions.get_combinations(tops, bottoms, maximum_price: 50)
# => [
#      {%{item_name: "Casual shirt", base_color: "black", price: 20},
#       %{item_name: "Jeans", base_color: "blue", price: 30}}
#    ]
```
