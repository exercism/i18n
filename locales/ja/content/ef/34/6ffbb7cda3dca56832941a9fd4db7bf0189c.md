# はじめに

## `Base.@kwdef`

マクロ`Base.@kwdef`を使うと、[`struct`][struct]の定義でキーワード引数を受け取るコンストラクターを自動的に定義できます。フィールドにデフォルト値を設定することもできます。

たとえば、次の定義では

```julia
Base.@kwdef struct HumanStats
    birthyear::Int
    height::Int
    mass::Int
    bmi::Float64 = mass / (0.01 * height)^2
end
```

3つのコンストラクターが一度に定義されます。

```julia-repl
julia> methods(HumanStats)
# 3 methods for type constructor:
[1] HumanStats(; birthyear, height, mass, bmi) [...]
[2] HumanStats(birthyear::Int64, height::Int64, mass::Int64, bmi::Float64) [...]
[3] HumanStats(birthyear, height, mass, bmi) [...]
```

その中には、キーワード引数を使うコンストラクターも含まれます。

```julia-repl
julia> HumanStats(
           birthyear = 2002,
           height = 193,
           mass = 83
       )
HumanStats(2002, 193, 83, 22.28247738194314)
```

一方、標準の定義では

```julia
struct HumanStats
    birthyear::Int
    height::Int
    mass::Int
    bmi::Float64
end
```

次の2つしか定義されません。

```julia-repl
julia> methods(HumanStats)
# 2 methods for type constructor:
[1] HumanStats(birthyear::Int64, height::Int64, mass::Int64, bmi::Float64) [...]
[2] HumanStats(birthyear, height, mass, bmi) [...]
```

そのため、キーワード引数を使うコンストラクターは手動で定義しなければなりません。

### `Base.@kwdef`はどんなときに使う？

キーワード引数を使うコンストラクターは、たくさんの引数を取る`struct`を作るときに特に便利です。とりわけ、引数の型や値がその意味を直接表していない場合に役立ちます。

次の定義を見てみましょう。

```julia
dirk = BasketballPlayer(1978, 1994, 2019, 213, 111, 42, 1998, [2011], 31560, 11489, 3651)
```

型の定義を知らなければ、それぞれの値が何を意味するのかはわかりません。定義を知っていたとしても、引数の順番を何度も確認することになるでしょう。

しかし、キーワード引数を使うコンストラクターなら、それぞれの意味がひと目でわかります。

```julia
dirk = BasketballPlayer(
    birthyear = 1978,
    career_start = 1994,
    career_end = 2019,
    height = 213,
    weight = 111,
    number = 42,
    drafted = 1998,
    championships = [2011],
    points = 31560,
    rebounds = 11489,
    assists = 3651
)
```

~~~~exercism/caution
`Base.@kwdef`はエクスポートされておらず、マニュアルにも記載されていないため、[Juliaの公開API][public-api]の一部ではありません。
つまり、そのインターフェースが安定していることは技術的には保証されておらず、Juliaのマイナーアップデートで変更される可能性があります。

ただし、このマクロはエコシステム全体で広く使われており、互換性を壊す形で変更される可能性は低いです。

詳しくは、次を参照してください。

- [`@kwdef`とは何をするもの？][discourse-kwdef]
- [`@kwdef`をマニュアルに追加するJulia Issue #32659][add-kwdef-to-manual]
- [`@kwdef`をエクスポートするJulia Issue #33192][export-kwdef]

~~~~
