# ヒント

## 全般

- [回復不能なエラー][unrecoverable]：エラーメッセージ付きでパニックを発生させます。
- [`panic!`マクロ][panic-excl-macro]：`ByteArray`のエラーメッセージ付きでパニックを発生させます。
- [`assert!`マクロ][assert]：条件が`false`と評価されたときにパニックを発生させます。
- [Result列挙型][result]：`Result`列挙型の使い方。

## 2. 不正な演算を処理する

- ここでは[エラーを返す][result]必要があります。

## 3. 演算が指定されていない場合を処理する

- 演算が空の文字列だった場合に対処するには、ここで`ByteArray`のメッセージ付きで[パニックを発生させる][panic-excl-macro]必要があります。

## 4. 0で割ったときのエラーを処理する

- 0で割った場合に対処するには、ここでパニックを発生させる必要があります。
