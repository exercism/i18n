# 説明

町に新しいポエトリークラブができました。入会してみたいと思っています。
過去にいくつか事件があったため、このクラブにはとても特殊な入場規則があり、入場を試みる前にそれをマスターする必要があります。

ポエトリークラブには正面と裏口の2つの扉があり、どちらにもガードが立っています。
中に入るには、その日の合言葉を導き出す必要があります。

合言葉はいつも詩に基づいていて、2つのステップで導き出せます。

1. ガードが詩を一行ずつ暗唱するので、その行の適切な文字で応答します。
2. 次にガードが、応答した文字をまとめて伝えるので、それを特定の形式で紙に書き留めます。

手順の詳細は、どちらの扉から入ろうとしているかによって変わります。

~~~~exercism/note
この演習のすべての文字列はASCIIでエンコードされ、NULで終端されます。
つまり、すべての文字はASCIIでエンコードされ、各文字列は'\0'（NUL文字、値は`0`）が見つかった時点で終わります。
~~~~

~~~~exercism/note
これは、このコンセプトで言及されている文字列命令です：

| 命令   | 動作                                                                                                |
|--------------|-------------------------------------------------------------------------------------------------------------------|
| `lods`       | `rsi`が示すメモリ位置から`rax`に値を読み込む                                                |
| `stos`       | `rax`の値を`rdi`が示すメモリ位置に格納する                                               |
| `movs`       | `rsi`が示すメモリ位置から値をコピーし、`rdi`が示すメモリ位置に格納する    |

いずれも、操作のサイズを示す接尾辞を付ける必要があります：

| 接尾辞 | サイズ             |
|--------|------------------|
| `b`    | バイト             |
| `w`    | ワード（2バイト）   |
| `d`    | ダブルワード（4バイト）  |
| `q`    | クアッドワード（8バイト）  |

また、すべての文字列命令は`rsi`や`rdi`のアドレスも変更します（その命令が使うレジスターのみ）。
デフォルトでは、アドレスは操作のサイズ分だけ増加します。

上記の文字列命令には`rep`接頭辞を付けて、`rcx`に等しい回数だけ繰り返すことができます。
~~~~

## 1. 文の最初の文字を取得する

正面の扉の合言葉に使う文字を決めるには、ガードが暗唱する詩の行の最初の文字で応答する必要があります。

素敵な合言葉にするために、ポエトリークラブのメンバーは_アクロスティック_の詩を好んで使います。
これは、各文の最初の文字が単語を形成する詩のことです。
ここに、彼らが大好きな作家の一人、Michael Lockwoodによる例を挙げます。

```text
Stands so high
Huge hooves too
Impatiently waits for
Reins and harness
Eager to leave
```

ですから、ガードが**Stands so high**と暗唱したら**S**で応答し、ガードが**Huge hooves too**と暗唱したら**H**で応答します。

詩の一行が格納されたメモリのアドレスを引数に取り、その行の最初の文字を返す関数`front_door_response`を実装してください。
この文字は、1バイトを占めるASCIIエンコードされた文字として返す必要があります。

```c
front_door_response("Stands so high");
// => 'S'
```

## 2. 単語の先頭を大文字にする

正しい文字がすべてそろったので、正面の扉の合言葉を得るために必要なのは、単語を正しく大文字化することだけです。

タスク1で見つけた文字をつなげただけの文字列が格納されたメモリのアドレスを引数に取る関数`front_door_password`を実装してください。
入力文字列を[その場で][in-place]変更して、正しく大文字化する必要があります。
つまり、正しい文字列は入力と同じメモリ位置に格納されます。

この関数には戻り値がありません。

```c
front_door_password('SHIRE');
// => buffer == "Shire"

front_door_password('shire');
// => buffer == "Shire"
```

## 3. 文の最後の文字を取得する

裏口の合言葉に使う文字を決めるには、ガードが暗唱する詩の行の最後の文字で応答する必要があります。

ポエトリークラブのメンバーは本当に賢いのです。
先ほどの詩は_テレステイック_でもあり、これは各文の最後の文字も単語を形成することを意味します：

```text
Stands so high
Huge hooves too
Impatiently waits for
Reins and harness
Eager to leave
```

ガードが**Stands so high**と暗唱したら**h**で応答し、ガードが**Huge hooves too**と暗唱したら**o**で応答します。

ときどきガードは、詩を暗唱するときに（句読点や空白の形で）スタイル上のポーズを入れることに注意してください。
正しい文字を導き出すには、そうしたポーズを無視する必要があります。

詩の一行が格納されたメモリのアドレスを引数に取り、その行の最後の文字を返す関数`back_door_response`を実装してください。
この文字は、1バイトを占めるASCIIエンコードされた文字として返す必要があります。

```c
back_door_response('Stands so high');
// => "h"

back_door_response('Stands ... so high   ');
// => "h"
```

## 4. 礼儀正しくする

裏口からポエトリークラブに入るには、とりわけ礼儀正しくある必要があります。
そこで合言葉を導き出すには、今回は単語を正しく大文字化し、末尾に`", please."`を追加します。

この順序で引数を受け取る関数`back_door_password`を実装してください：

1. 結果の文字列を格納するバッファが置かれたメモリのアドレス。
2. タスク3で見つけた文字をつなげた文字列が格納されたメモリのアドレス。

この関数は、大文字化した合言葉の礼儀正しいバージョンを[buffer][buffer]に格納します。
_バッファ_とは、異なる関数の間で値を受け渡すためにメモリに値を保存しておける配列のことです。

この関数には戻り値がありません。

```c
back_door_password("horse");
// => "Horse, please."
```

[in-place]: https://en.wikipedia.org/wiki/In-place_algorithm
[buffer]: https://en.wikipedia.org/wiki/Data_buffer
