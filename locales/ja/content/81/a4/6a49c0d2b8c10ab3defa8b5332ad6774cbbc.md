この演習では、お気に入りの料理本から最高のラザニアを作るために、コードを書いていきます。

ラザニアの調理にかかる時間に関する4つのタスクがあります。

## 1. オーブンでの想定時間を分単位で定義する

引数を取らず、ラザニアをオーブンに入れておくべき時間を分単位で返す`expected_minutes_in_oven()`関数を定義します。料理本によると、オーブンでの想定時間は60分です。

```r
> expected_minutes_in_oven()
[1] 60
```

## 2. 残りのオーブン時間を分単位で計算する

ラザニアをオーブンに入れてから実際に経過した分数を入力として受け取り、前のタスクで求めたオーブンでの想定時間をもとに、ラザニアをあと何分オーブンに入れておく必要があるかを返す`remaining_time_in_minutes`関数を定義します。

```r
> remaining_time_in_minutes(50)
[1] 10
```

## 3. 下準備にかかる時間を分単位で計算する

ラザニアに重ねた層の数を入力として受け取り、1層あたり2分かかると仮定して、ラザニアの下準備にかかった時間を分単位で返す`prep_time_in_minutes()`関数を定義します。

```r
> prep_time_in_minutes(2)
[1] 4
```

## 4. 経過時間を分単位で計算する

2つの入力を受け取る`elapsed_time_in_minutes`関数を定義します。1つ目の入力はラザニアに重ねた層の数、2つ目の入力はラザニアをオーブンに入れてからの経過時間（分）です。この関数は、ラザニアの調理に合計で何分かかったかを返します。これは、下準備にかかった時間と、現時点でラザニアがオーブンに入っていた時間を足したものです。

```r
> elapsed_time_in_minutes(3, 20)
[1] 26
```
