# 概要

`Bool`型は、この言語の基本的な構成要素の1つです。
何かが真か偽かを、それぞれ`True`と`False`という値で表すための型です。
`Bool`という名前は真偽値の略で、真偽値は論理的な思考に関わる数学の分野であり、その名前はジョージ・ブールの業績に由来します。

## 真偽値の演算子

`Bool`型の値を操作するには、2つの関数と2つの演算子があります。

- `not : Bool -> Bool`
  この関数は`True`を`False`に、`False`を`True`に変換します。
- `(&&) : Bool -> Bool -> Bool`
  「AND」と呼ばれるこの演算子は、2つの真偽値を受け取り、両方とも`True`なら`True`を返します。
  たとえば、`True && True`は`True`を返しますが、`True && False`は`False`を返します。
- `(||) : Bool -> Bool -> Bool`
  「OR」と呼ばれるこの演算子は、2つの真偽値を受け取り、少なくとも片方が`True`なら`True`を返します。
  たとえば、`False || False`は`False`を返しますが、`True || False`は`True`を返します。
- `xor : Bool -> Bool -> Bool`
  「XOR」と呼ばれるこの関数（演算子ではありません）は、2つの真偽値を受け取り、片方が`True`でもう片方が`False`のときだけ`True`を返します。

`&&`と`||`では優先順位が異なります。
`&&`の優先順位は`||`よりも高く、掛け算の`*`と足し算の`+`の関係と同じです。
そのため、式`True || False && False`は`True || (False && False)`と同じ意味になり、`(True || False) && False`とは異なります。
前者は`True`を返し、後者は`False`を返します。

## 条件分岐

真偽値は、特定の条件を満たしたときだけ実行される分岐をコードに作るときに、とても役立ちます。
Elmでは、これを`if-then-else`式で行います。使い方は次のとおりです。

```elm
if someCondition || (someOtherCondition && anotherCondition) then
    doSomething
else
    doSomethingElse
```

`someCondition`には、`Bool`を返す任意の式を書くことができます。
その真偽値が`True`なら、`doSomething`が実行されます。
そうでなければ`False`なので、`doSomethingElse`が実行されます。
他のプログラミング言語とは違い、`else`の分岐は省略できません。

条件をつなげたいときは、`if-then-else`式をつなげるだけでかまいません。

```elm
if someCondition then
    doSomething
else if someOtherCondition then
    doAnotherThing
else
    doSomethingElse
```
