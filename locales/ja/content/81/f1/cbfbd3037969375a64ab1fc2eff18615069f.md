# トラックのツール

トラックのツールには、次の2種類があります。

- 本番用：その言語の学習体験に欠かせない役割を担います
- メンテナンス用：トラックのメンテナンスを支えます

ツールは（一般的には）そのトラックの言語で書かれており、メンテナーによって作られ、保守されています。

## 本番用のツール

これらのツールは、Exercismの本番サーバーで動きます。

### トラック固有の本番用ツール

トラック固有の本番用ツールは、次の3つです。

- **[Test Runners](/docs/building/tooling/test-runners)**（必須）
- **[Representers](/docs/building/tooling/representers)**（任意）
- **[Analyzers](/docs/building/tooling/analyzers)**（任意）

### 共通の本番用ツール

トラック用に設定できる共通の本番用ツールが、次の2つです。

- **[Lines of Code Counter](/docs/building/tooling/lines-of-code-counter)**（任意）
- **[Snippet Extractor](/docs/building/tooling/snippet-extractor)**（任意）

### デプロイ

本番用ツールはDockerイメージとしてビルドされます。
CIワークフローを使って、Exercismの本番サーバーへ自動デプロイされます。

## メンテナンス用のツール

メンテナンス用のツールは、トラックのメンテナンスを助けるためのものです。
ふだんは（メンテナーやコントリビューターのマシン上で）ローカルに動き、ときにはCIでも動きますが、本番環境で動くことはありません。

メンテナンス用のツールの例をいくつか挙げます。

- **[Test Generators](/docs/building/tooling/test-generators)**

## 実装

トラックのツールは、通常は（ほとんどは）そのトラックの言語で書かれています。

```exercism/caution
他の言語を使うのは自由ですが、言語が増えるほど、トラックのメンテナンスやコントリビュートが難しくなります。
そのため、できるだけトラックの言語を使うことをおすすめします。そのほうがメンテナンスやコントリビュートがしやすくなるからです。
```
