# 概要

Rustでは、メソッドは構造体（または`enum`や`trait`オブジェクト）に対して定義された関数です。
これにより呼び出し方が変わり、`frobnicate(foo)`ではなく`foo.frobnicate()`のように呼び出します。

メソッドは関数と似ています。`fn`キーワードで宣言し、名前があり、引数と戻り値を持てます。

関数と違い、メソッドの最初の引数は常に`self`（またはその変種）で、メソッドを呼び出している構造体のインスタンスを表します（詳細は後述）。

Hogwartsの寮を表す`enum`と、魔法使いの`age`と`house`を表す`struct`を作ってみましょう。

```rust
#[derive(Debug)]
enum House {
    Gryffindor,
    Hufflepuff,
    Ravenclaw,
    Slytherin,
}

struct Wizard {
    age: u32,
    house: House,
}
```

## メソッドの定義

構造体`Wizard`にメソッドを定義するには、`Wizard`のための`impl`（implementationの略）ブロックを開始します。

```rust
impl Wizard { }
```

この`impl`ブロック内のすべては`Wizard`型に関連付けられます。
構造体は複数の`impl`ブロックを持てることに注意してください。

### `self`を使う

メソッドは、最初の引数として型`Self`の`self`という名前の引数を持たなければなりません。
型`Self`は、その`impl`ブロックが対象とする型の別名です。
この例では、`Self`は`Wizard`を表します。

Rustでは便宜上、最初の引数の位置に`self`という名前だけを書いて省略できます。
メソッドでよく使われる`self`の型には次のものがあります。

- `self`: `self: Self`の省略形です。裸の`self`シグネチャはインスタンスを消費します。
- `&self`: `self: &Self`の省略形です。インスタンスを不変で借用します。
- `&mut self`: `self: &mut Self`の省略形です。インスタンスを可変で借用します。

より高度なコードでは、`self: Pin<&self>`、`self: Rc<Self>`などのシグネチャも見かけるかもしれません。
ただし、これは現在のチュートリアルの範囲を超えています。

### `&self`を使ったメソッドの定義

魔法使いの基本情報を表示する`info`メソッドを実装したい場合、このメソッドを`Wizard`の`impl`ブロック内に定義できます。

```rust
impl Wizard {
    fn info(&self) {
        println!(
            "A wizard of age {} who studies in House {:?} at Hogwarts",
            self.age,
            self.house,
        );
    }
}
```

`info`のシグネチャでは、`&self`でインスタンスを不変に借用していることに注意してください。
これにより、`Wizard`インスタンスの`age`と`house`フィールドを変更せずに読むことができます。
借用ではなく消費する`self`を使った場合、メソッド呼び出し後にインスタンスへアクセスできなくなります。

`info`メソッドを実装すると、魔法使いの基本情報を出力できます。

```rust
let harry = Wizard { age: 11, house: House::Gryffindor };
harry.info();
// => A wizard of age 11 who studies in House Gryffindor at Hogwarts
```

### `&mut self`を使ったメソッドの定義

構造体インスタンスのフィールドを変更するメソッドを実装したい場合、メソッドのシグネチャで`&mut self`を使ってインスタンスを可変に借用します。

Hogwartsで学生が寮を変えられる新しいルールを設けたいとします。
次のように`switch_house`メソッドを実装できます。

```rust
impl Wizard {
    fn switch_house(&mut self, new_house: House) {
        self.house = new_house;
    }
}
```

これで、Hogwartsで学ぶ魔法使いの寮を変えられます。

```rust
// Note that the variable must be mutable
let mut cedric = Wizard {age: 14, house: House::Hufflepuff};
cedric.info();
// => A wizard of age 14 who studies in House Hufflepuff at Hogwarts
cedric.switch_house(House::Slytherin);
cedric.info()
// => A wizard of age 14 who studies in House Slytherin at Hogwarts
```

## 複数の'impl'ブロック

Rustでは、各アイテムは複数の`impl`ブロックを持てます。
そのため、すべてのメソッドを同じ`impl`ブロックにまとめることも、メソッドのグループごとに複数の`impl`ブロックに分けることもできます。
どちらの方法も有効な構文ですが、一般的なプロジェクト構成では、`impl`レベルの`where`境界の組み合わせごとに単一の`impl`ブロックを使います。

## 関連関数

`impl`ブロック内に、`self`引数を含まない関数を定義することもできます。
`self`引数がないため、これらはメソッドではありません。
しかし、実装された型には関連付けられており、その型の名前を使って呼び出されます。
そのため、これらは関連関数（または型に関連付けられた関数）と呼ばれます。

すでに`String::from()`のようないくつかの関連関数を見てきたでしょう。

```rust
let some_string = String::from("This is an associated function but not a method");
```

コンストラクターは関連関数として実装されることがよくあります。
`Wizard`型に関連付けられた`new`関数を作ってみましょう。

```rust
impl Wizard {
    fn new(age: u32, house: House) -> Self {
        Self {
            age,
            house,
        }
    }
}
```

関数から返される型を示すために、`Wizard`の代わりに`Self`を使えることに注意してください。
このように`Self`型エイリアスを使うことは必須ではありませんが、複雑な名前や長い名前を持つ型では実装を簡潔にできます。
これで、次のコードを実行できます。

```rust
let myrtle = Wizard::new(14, House::Ravenclaw);

myrtle.info();
// => A wizard of age 14 who studies in House Ravenclaw at Hogwarts
```
