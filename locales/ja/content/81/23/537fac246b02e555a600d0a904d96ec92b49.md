# 概要

Clojureの標準データ型はすべて不変なので、Clojureには制御された変更を行える*参照型*が用意されています。その中で最もシンプルで、最もよく使われるものがアトムです。

アトムは`atom`関数で作成します。`atom`関数には初期値を渡します。

```clojure
(def players (atom ()))
```

アトムの現在の値は、`deref`または省略記法の`@`でデリファレンスします。

```clojure
@players
;;=> ()
```

`players`アトムの現在の値は、`swap!`を使って変更できます。`swap!`は関数を適用して値を更新します。

```clojure
(swap! players conj :player1)
;;=> (:player1)
```

`reset!`関数は、現在の値に関係なくアトムの値を置き換えます。

```clojure
(reset! players ())
```
