# はじめに

Gleamは、真偽の値を`Bool`型で表します。値は`True`と`False`の2つだけです。これらの値は変数に束縛できます。

```gleam
let true_variable = True
let false_variable = False
```

`&&`、`||`、`!`の演算子を使うと、真偽値を操作できます。

```gleam
True && True  // -> True
True && False // -> False

False || True  // -> True
False || False // -> False

!False // -> True
!True  // -> False
```

`&&`と`||`の演算子は、短絡評価を行います。つまり、演算子の右辺の式は必要なときにだけ評価されるということです。

それぞれの演算子には異なる優先順位があり、`!`は`&&`や`||`より先に評価されます。式の一部を他の部分より先に評価したいときは、波括弧（`{}`）を使えます。

```gleam
!True && False   // -> False
!{True && False} // -> True
```
