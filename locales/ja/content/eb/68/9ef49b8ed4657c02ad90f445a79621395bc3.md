# 概要

Factorでの繰り返しは、ほとんどの場合コンビネーター（`each`、`map`、`reduce`）で表現します。しかし、明示的な再帰にも出番はあります。再帰が配列の形をしていないとき、基底ケースが単純でないとき、あるいは自分でコンビネーターを実装するときです。

```factor
: total ( seq -- sum )
    [ 0 ] [ unclip swap total + ] if-empty ;

: gcd ( a b -- g )
    dup zero? [ drop ] [ tuck mod gcd ] if ;
```

知っておきたいことがいくつかあります。

- 通常の`:`定義は、特別な構文なしで再帰できます。コンパイラーが再帰呼び出しをまたいでスタック効果を推論します。
- `loop ( quot -- )`を使うと、真偽値を返すクォーテーションを繰り返せます。真と評価される間は続けます。
- 末尾呼び出しはジャンプにコンパイルされるので、深く再帰するワードでもスタックを使い果たしません。

`unclip`と`if-empty`の組み合わせは、配列に対する再帰の標準的な形です。`cond`は複数のケースを分岐させる標準的な形です。
