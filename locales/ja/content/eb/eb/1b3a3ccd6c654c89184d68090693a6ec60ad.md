# 概要

Java 8で導入された`java.time`パッケージには、日付と時刻を扱うためのいくつかのクラスが含まれています。

## `LocalDate`

[`java.time.LocalDate`][localdate-docs]クラスは、[ISO-8601の暦][iso-8601]におけるタイムゾーンのない日付を表します。たとえば`2007-12-03`のようなものです。

```java
LocalDate date = LocalDate.of(2007, 12, 3);
```

日付はほかの日付と比較できます。

```java
LocalDate date1 = LocalDate.of(2007, 12, 3);
LocalDate date2 = LocalDate.of(2007, 12, 4);

date1.isBefore(date2);
// => true

date1.isAfter(date2);
// => false
```

`LocalDate`のインスタンスには、その各部分を取り出すためのゲッターがあります。

```java
LocalDate date = LocalDate.of(2007, 12, 3);

date.getYear();
// => 2007

date.getMonthValue();
// => 12

date.getDayOfMonth();
// => 3
```

`LocalDate`のインスタンスには、時間の単位を加算するためのメソッドがあります。

```exercism/note
これらのメソッドは、_新しい_`LocalDate`のインスタンスを返します。`LocalDate`クラスは不変なので、既存のインスタンスは更新されません。
```

```java
LocalDate date = LocalDate.of(2007, 12, 3);

date.plusDays(3);
// => 2007-12-06

date.plusMonths(1);
// => 2008-01-03

date.plusYears(1);
// => 2008-12-03
```

## `LocalDateTime`

[`java.time.LocalDateTime`][localdatetime-docs]クラスは、[ISO-8601の暦][iso-8601]におけるタイムゾーンのない日時を表します。たとえば`2007-12-03T10:15:30`のようなものです。

```java
LocalDateTime datetime = LocalDateTime.of(2007, 12, 3, 10, 15, 30);

datetime.getYear();
// => 2007

datetime.getMonthValue();
// => 12

datetime.getDayOfMonth();
// => 3

datetime.getHours();
// => 10

datetime.getMinutes();
// => 15

datetime.getSeconds();
// => 30
```

`LocalDate`クラスと同様に、`LocalDateTime`のインスタンスにも、ほかの`LocalDateTime`と比較したり、時間の単位を加算したりするための同じメソッドがあります。

`LocalDate`のインスタンスを`LocalDateTime`に変換することもできます。

```java
LocalDate date = LocalDate.of(2007, 12, 3);
LocalDateTime datetime = date.atTime(10, 15, 30);
datetime.toString();
// => "2007-12-03T10:15:30"
```

## 日時のフォーマット

`LocalDate`と`LocalDateTime`はどちらも、`String`との相互変換に[ISO-8601][iso-8601]の標準表記を使います。

```java
LocalDateTime datetime = LocalDateTime.of(2007, 12, 3, 10, 15, 30);
LocalDateTime parsed = LocalDateTime.parse("2007-12-03T10:15:30");

datetime.isEqual(parsed);
// => true
```

このように、異なるフォーマットを使って`String`から`LocalDate`や`LocalDateTime`をパースすることはできません。
代わりに、独自のフォーマットで日付を整形したい場合は、[`java.time.format.DateTimeFormatter`][datetimeformatter-docs]を使います。

```java
DateTimeFormatter parser = DateTimeFormatter.ofPattern("dd/MM/yyyy");
LocalDate date = LocalDate.parse("03/12/2007", formatter);

DateTimeFormatter printer = DateTimeFormatter.ofPattern("MMMM d, yyyy");
printer.format(date);
// => "December 3, 2007"
```

独自のフォーマットを作成するときに[ロケール][locale]を指定すれば、地域ごとに整形したりパースしたりできます。

```java
DateTimeFormatter.ofPattern("MMMM d, yyyy", Locale.FRENCH).format(date);
// => décembre 3, 2007

DateTimeFormatter.ofPattern("MMMM d, yyyy", Locale.of("pt")).format(date);
// => dezembro 3, 2007
```
