# 説明

この演習では、お気に入りの料理本をもとに、絶品のラザニアを作るためのコードを書いていきます。

4つの課題があり、いずれもラザニアの調理にかかる時間に関わるものです。

## 1. オーブンでの想定加熱時間を分単位で定義する

`Lasagna.expectedMinutesInOven()`メソッドを定義しましょう。このメソッドは入力を受け取らず、ラザニアをオーブンに入れておくべき時間を分単位で返します。料理本によると、オーブンでの想定加熱時間は40分です。

```scala
val lasagna = new Lasagna()
lasagna.expectedMinutesInOven()
// => 40
```

## 2. 残りのオーブン加熱時間を分単位で計算する

`Lasagna.remainingMinutesInOven()`メソッドを定義しましょう。このメソッドは、実際にラザニアをオーブンに入れておいた時間を入力として受け取り、前の課題で求めた想定加熱時間をもとに、ラザニアをあと何分オーブンに入れておく必要があるかを返します。

```scala
val lasagna = new Lasagna()
lasagna.remainingMinutesInOven(30)
// => 10
```

## 3. 準備時間を分単位で計算する

`Lasagna.preparationTimeInMinutes()`メソッドを定義しましょう。このメソッドは、ラザニアに重ねた層の数を入力として受け取り、1層につき2分かかると仮定して、ラザニアの準備に何分かかったかを返します。

```scala
val lasagna = new Lasagna()
lasagna.preparationTimeInMinutes(2)
// => 4
```

## 4. 経過時間を分単位で計算する

`Lasagna.elapsedTimeInMinutes()`メソッドを定義しましょう。このメソッドは2つの入力を受け取ります。1つ目はラザニアに重ねた層の数、2つ目はラザニアをオーブンに入れておいた分数です。この関数は、ラザニアの調理に何分かけたかを返します。これは、準備にかかった分数と、その時点でラザニアがオーブンにあった分数を足したものです。

```scala
var lasagna = new Lasagna()
lasagna.elapsedTimeInMinutes(3, 20)
// => 26
```
