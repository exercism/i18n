# テスト

解答をテストするには、**テストスクリプトを実行する**だけです。Red Consoleから、関数`do`とテストスクリプトのパスを使って実行することもできます。次のようにします：

```red
do %exercism/red/hello-world/hello-world-test.red
```

あるいは、システムのターミナルでRedのバイナリに引数として渡すだけでもかまいません：

```shell
red exercism/red/hello-world/hello-world-test.red
```

最初は、テストファイルの最初のテストだけが有効になっています。これは、演習を1つずつ解き進めてもらうためのものです。最初のテストが通ったら、テストファイルの先頭にある`test-init`関数の2番目の*引数*を変更して、もう一度実行します。この値は有効にするテストの数なので、`1`から`2`に変えると2番目のテストが有効になります。`test-init`関数の`\limit`リファインメントと2番目の引数を削除すれば、すべてのテストをスキップせずに実行することもできます。
