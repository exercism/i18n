# はじめに

Elixirが呼び出す関数を解決するときは、モジュール名を使って検索を行います。モジュール名が変数に束縛されていれば、この検索を動的に行えます。

```elixir
defmodule MyModule do
  def message(), do: "My message"
end

atom = MyModule
atom.message()
# => "My message"
```

内部的には、モジュール名はアトムです。Elixirのモジュールのアトムには、すべて自動的に`Elixir.`が付けられます。

```elixir
is_atom(Enum)
# => true
Enum == Elixir.Enum
# => true
```
