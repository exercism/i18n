# 説明の補足

## レジスタ

| Register | Usage        | Type    | Description                                 |
| -------- | ------------ | ------- | ------------------------------------------- |
| `$a0`    | 入力         | 整数    | 入力するコインの枚数                        |
| `$a1`    | 入力         | 整数    | 目標金額                                    |
| `$a2`    | 入出力       | アドレス | 上書き可能な、コインを表すワードの配列      |
| `$v0`    | 出力         | 整数    | 出力するコインの枚数。入力が無効な場合は-1  |
| `$t0-9`  | 一時         | 任意    | 一時的な保存に使います                      |
