# はじめに

## 配列

Javaでは、配列を使うと、同じ型の複数の値を1つの構造にまとめて保存できます。他のデータ構造と違い、配列は一度作成するとサイズを変更できません。配列の要素には、インデックスを使って値を代入したり、取り出したりできます。Javaの配列は0から始まるインデックスを使います。最初の要素のインデックスは0、2番目の要素のインデックスは1、といった具合です。

配列を初期化する標準的な構文は次のとおりです。

```java
type[] variableName = new type[size];
```

`type`は配列の要素の型で、プリミティブ型（`int`など）またはクラス（`String`など）を指定できます。

`size`はこの配列が保持する要素の数です（後から変更することはできません）。配列を作成すると、要素はそれぞれのデフォルト値（通常は`0`、`false`、`null`）で初期化されます。

```java
// Declare array with explicit size (size is 2)
int[] twoInts = new int[2];
```

配列は、作成と値の設定を同時に行える省略記法でも定義できます。

```java
// Two equivalent ways to declare and initialize an array (size is 3)
int[] threeIntsV1 = new int[] { 4, 9, 7 };
int[] threeIntsV2 = { 4, 9, 7 };
```

コンパイラーが配列の要素数を判断できるため、長さは省略できます。

配列の要素は、角括弧を使ったインデックス表記で代入したりアクセスしたりできます。

```java
// Assign second element by index
twoInts[1] = 8;

// Retrieve the second element by index and assign to the int element
int secondElement = twoInts[1];
```

配列の有効なインデックスの範囲外にアクセスすると、`IndexOutOfBoundsException`が発生します。

配列は、配列インスタンスのメソッドやプロパティを呼び出すか、`Arrays`クラスで定義された静的メソッド（通常はジェネリックなコードでのみ使用します）を使って操作できます。`length`プロパティには配列の長さが入っています。次のようにアクセスできます。

```java
int arrayLength = someArray.length;
```

Javaには、配列に関する便利なメソッドを数多く備えたユーティリティクラス[`java.util.Arrays`](https://docs.oracle.com/en/java/javase/11/docs/api/java.base/java/util/Arrays.html)も用意されています（例：`Arrays.equals`）。

Javaは、`int[][] arr = new int[3][4];`のような[多次元配列](https://www.programiz.com/java-programming/multidimensional-array)もサポートしており、とても便利です。

配列が_コレクション_でもあるということは、インデックスで値にアクセスする以外に、`for-each`ループを使って_すべての_値を繰り返し処理できるということです。

```java
char[] vowels = { 'a', 'e', 'i', 'o', 'u' };

for(char vowel: vowels) {
    // Output the vowel
    System.out.print(vowel);
}

// => aeiou
```

繰り返し処理する値をより細かく制御したい場合は、`for`ループを使えます。

```java
char[] vowels = { 'a', 'e', 'i', 'o', 'u' };

for (int i = 0; i < 3; i++) {
    // Output the vowel
    System.out.print(vowels[i]);
}

// => aei
```
