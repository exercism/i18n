# 説明

ウェリントンの気象観測所は、手作業による温度記録システムを、新しいデジタルシステムに置き換えます。
これまでのシステムでは、計算は手作業で行っていました。
新しいシステムでは、計算は自動化されます。
計算には、温度を摂氏から華氏に変換することや、平均温度を求めることが含まれます。
新しいシステムには、温度のデータを摂氏で記録するセンサーがあります。

ウェリントンの気象観測所は、新しいシステムづくりへの協力を求めています。

## 1. 温度を摂氏からケルビンに変換する

気象観測所のウェブサイトには、研究者向けのセクションがあります。
研究者は、ケルビンで表した温度に関心があります。

ケルビンは、温度を測るための単位です。
摂氏と同じ目盛りですが、基準点が異なります。
その基準点は絶対零度で、0K（ケルビン）または-273.15°C（摂氏）です。

摂氏とケルビンの変換をまとめた表は次のとおりです。

| Celsius(°C) | Kelvin(K) |
| ----------- | --------- |
| -273.15     | 0         |
| -100        | 173.15    |
| 0           | 273.15    |
| 100         | 373.15    |

気象観測所は、温度を摂氏からケルビンに変換するメソッドの実装を求めています。

入力`celsius`を受け取り、与えられた`celsius`の値に273.15を足して、温度をケルビンで返す`Temperature#to_kelvin`メソッドを実装します。

```crystal
Temperature.new.to_kelvin(0)
# => 273.15
```

## 2. 温度を丸める

気象観測所の温度センサーは正確です。
温度を0.0001°C単位で測ることができます。
ほとんどの利用者はそこまでの精度を必要としないため、気象観測所は小数点以下1桁に丸めた温度だけを表示したいと考えています。

気象観測所は、温度を小数点以下1桁に丸めるメソッドの実装を求めています。

入力`celsius`を受け取り、小数点以下1桁に丸めた温度を返す`Temperature#round`メソッドを実装します。

```crystal
Temperature.new.round(10.1234)
# => 10.1

Temperature.new.round(10.1567)
# => 10.2
```

## 3. 温度を摂氏から華氏に変換する

気象観測所のウェブサイトには、観光客向けのセクションがあります。
観光客は、華氏で表した温度に関心があります。

華氏は温度の単位です。
摂氏とは目盛りが異なります。
0°Cは32°Fで、摂氏1度は華氏1.8度に相当します。

摂氏と華氏の変換をまとめた表は次のとおりです。

| Celsius(°C) | Fahrenheit(°F) |
| ----------- | -------------- |
| -273.15     | -459.8         |
| -100        | -148           |
| 0           | 32             |
| 100         | 212            |

気象観測所は、温度を摂氏から華氏に変換するメソッドの実装を求めています。

入力`celsius`を受け取り、華氏の温度を整数で返す`Temperature#to_fahrenheit`メソッドを実装します。

```crystal
Temperature.new.to_fahrenheit(10)
# => 50
```

## 4. 足りないセンサーの数を求める

温度センサーの設置中に、保守作業員はセンサーがいくつか足りないことに気づきました。
温度測定ユニット1つにつき、温度センサーが4つ必要です。
保守チームは手持ちのセンサーの数を数えましたが、足りない数を知る必要がありました。
もう1つ完全な温度測定ユニットを組み立てるために、あと何個センサーを買えばよいかを数える手助けを求めています。

入力`number_of_sensors`を受け取り、足りないセンサーの数を返す`Temperature#number_missing_sensors`メソッドを実装します。

```crystal
Temperature.new.number_missing_sensors(10)
# => 2
```
