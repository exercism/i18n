# はじめに

型定義は、新しい名前付きの型を作ります。それは、基底型が同じであっても、ほかのどの型とも異なる型です。

## 型の定義

型定義は`type`キーワードで始まり、そのあとに新しい型の名前と基底型を書きます。

```go
type File []bool
```

ここでの`File`は、チェス盤の縦1列を指します。ふつうはAからHのラベルが付けられています。
この列の各マスは、そこに駒があるかどうかを示す真偽値で表されます。
`File`を定義したので、ほかの定義の中でも使えるようになりました。

```go
type Chessboard map[string]File

board := Chessboard{
    "A": File{true, false, true},
    "B": File{false, true, false},
}
```

`Chessboard`は、ファイルの識別子を`File`の値に対応付けます。
各`File`は、1つのチェスのファイルにあるマスを表す真偽値のスライスです。
これらの型定義がなければ、`board`は`map[string][]bool`となり、何を表しているのかがわかりにくくなります。
