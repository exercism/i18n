# はじめに

Goでは、すべての変数に値があります。
値を代入せずに変数を宣言すると、その変数は型のゼロ値になります。

`bool`、数値型、`string`などの基本型には、それぞれ決まったゼロ値があります。

| Type                   | Zero Value |
| ---------------------- | ---------- |
| bool                   | `false`    |
| int, int8, int64, など | `0`        |
| float32, float64       | `0`        |
| complex64, complex128  | `0+0i`     |
| string                 | `""`       |

ポインター、関数、インターフェース、スライス、チャネル、マップのゼロ値は、いずれも`nil`です。

配列と構造体は、データへの参照ではなくデータそのものを直接保持するため、`nil`になることはありません。
配列の各要素と構造体の各フィールドは、それぞれの型のゼロ値に初期化されます。
たとえば、`var a [3]int`と書くと、配列`[0, 0, 0]`が作られます。

## ゼロ値の宣言

宣言には`var`を使います。

```go
var myBool bool   // false
var mySlice []int // nil
```

構造体には複合リテラル`T{}`を使います。

```go
type Person struct {
    Name string
    Age  int
}

myPerson := Person{} // Person{Name: "", Age: 0}
```
