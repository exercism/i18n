# 概要

## はじめに

不透明型は、Elmにおけるカプセル化の手法です。
情報隠蔽、あるいは実装の詳細の隠蔽と呼ぶ人もいます。
また、[Parse, dont validate][parse-dont-validate]パターンを使って検証を強制するのにもよく使われます。
たとえば、有効なメールアドレスしか保持できない`EmailAddress`という不透明型を作ることができます（どんな文字列でも入る`String`とは対照的です）。

## 不透明型の作り方

[カスタム型][custom-types]には1つ以上の*バリアント*があり、コンパイラーは*バリアント*の名前を使って、それぞれの*バリアント*を作る関数を自動的に生成します。
カスタム型を作れるのは、これが唯一の方法です。
コンパイラーは、これらのバリアントを分解することも許しています。

```elm
type Maybe a
    = Nothing --> Variant implies a 'Nothing' function, with type 'Maybe a', and destructuring of 'Nothing'
    | Just a  --> Variant implies a 'Just' function, with type 'a -> Maybe a', and destructuring of 'Just _'
```

デフォルトでは、これらはすべてファイルやモジュールの内部にあり、何を公開するかは`exposing`キーワードで選びます。
`Maybe`モジュールは`Maybe`型を公開していて（ほかのモジュールが既存の`Maybe`の値を使えるようにするためです）、さらに`Nothing`と`Just`のバリアントも公開しています（ほかのモジュールが`Maybe`の値を作ったり分解したりできるようにするためです）。
そのための構文は次のとおりです。
`Maybe(..)`の部分は、カスタム型の定義だけでなく、すべての*バリアント*も公開するようElmに伝えます。

```elm
module Maybe exposing
  ( Maybe(..)
  -- ...
  )
```

不透明型を作るには、*バリアント*を公開しないように選ぶだけです。
`Maybe`型でこれを行うには、次の構文を使います。

```elm
module Maybe exposing
  ( Maybe
  -- ...
  )
```

こうすると、ほとんどの場合、*バリアント*を作ったり取得したりする別の方法を、カスタム関数を公開することで用意する必要があります。
これらのカスタム関数を使うと、*バリアント*を作ったり取得したりするときに何らかのロジックを適用できます。
これにより、モジュール内部の実装の詳細が隠され、公開している関数が同じままであれば、実装の詳細をいくらでも変更できます。
また、型を作ったり使ったりするときに[不変条件を守る][uphold-invariants]ことにも役立ちます。

## Parse, don't validate

不透明型の最も一般的な使い道は、[Parse, dont validate][parse-dont-validate]パターンを使って検証を強制することでしょう。
このパターンでは、`String`のように、望むよりも構造や型安全性の少ない入力を取る関数を公開し、それを`EmailAddress`のようなより構造化された型へパースします。戻り値はその型か、エラー（ふつうは`Maybe`か`Result`）です。

たとえば、次のコードでは、外部のモジュールが`EmailAddress`型を作れるのは`parseEmailAddress`関数を使う場合だけなので、`EmailAddress`型を扱っているときは、それが有効であると確信できます。

```elm
module EmailAddress exposing ( EmailAddress, parseEmailAddress, getEmailAddress )

-- The `EmailAddress` custom type has one variant, also called `EmailAddress`
-- When a custom type has one variant, it is idiomatic to use the same name for both.
type EmailAddress = 
  EmailAddress String

-- create an EmailAddress variant
parseEmailAddress: String -> Maybe EmailAddress
parseEmailAddress candidateEmailAddress =   
  if isValidEmailAddress candidateEmailAddress then
    Just (EmailAddress candidateEmailAddress)
  else
    Nothing

-- get an EmailAddress variant
getEmailAddress: EmailAddress -> String
getEmailAddress ( EmailAddress  emailAdress ) =
  emailAdress

isValidEmailAddress: String -> bool
-- ... 
```
