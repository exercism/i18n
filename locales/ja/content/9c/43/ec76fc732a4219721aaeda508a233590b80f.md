# はじめに

配列は、Factorにおける主要な固定長のシーケンス型で、`{ … }`と書きます。要素は変更できますが、長さは変えられません。`arrays`と`sequences`の2つのボキャブラリーを合わせると、スタックから値を取り出す小さなコンストラクターと、連結・逆順・要素の取得といった日常的によく使う操作が使えるようになります。

```factor
USING: arrays sequences ;

42 1array .                ! => { 42 }
"a" "b" "c" 3array .       ! => { "a" "b" "c" }
{ { 1 2 } { 3 4 } } concat .   ! => { 1 2 3 4 }
{ 1 2 3 } reverse .            ! => { 3 2 1 }
```

[arrays]: https://docs.factorcode.org/content/vocab-arrays.html
[sequences]: https://docs.factorcode.org/content/vocab-sequences.html
