# はじめに

## 数値の比較

JavaScriptでは、次の関係演算子と等値演算子を使って数値を比較できます。

| 比較             | 演算子  |
| ---------------------- | --------- |
| より大きい           | `a > b`   |
| 以上 | `a >= b`  |
| より小さい              | `a < b`   |
| 以下    | `a <= b`  |
| （厳密）等しい        | `a === b` |
| （厳密）等しくない    | `a !== b` |

比較の結果は常に真偽値、つまり`true`か`false`のどちらかになります。

```javascript
1 < 3;
// => true

2 !== 2;
// => false

1 === 1.0;
// => true
// All numbers are floating-points, so this is different syntax for
// the exact same value.
```

## 文字列の比較

JavaScriptでは、上記の比較演算子を使って文字列を比較することもできます。
その場合は、辞書順（辞書式順序）が適用されます。
すべての文字の正確な順序の一覧は[こちら][utf-16-list]にあります。

```javascript
'Apple' > 'Pear';
// => false

'a' < 'above';
// => true

'a' === 'A';
// => false
```

## 厳密等価

JavaScriptで等しいかどうかを確認するときに、イコールが3つ並んでいるのを不思議に思うかもしれません。
`===`は_厳密等価_かどうかを確認するもので、型変換は行われず、異なる型の値は常に等しくないとみなされます。

```javascript
'3' === 3;
// => false
// The value on the left has type string, the value on the right has type number.

1 === 1n;
// => false
// The value on the left has type number, the value on the right has type bigint.
```

JavaScriptで等しいかどうかを確認するには、`===`と`!==`を使うのがおすすめです。

`==`と`!=`という、_緩い等価_かどうかを確認するものもあります。
比較を行う前に暗黙の型変換が行われるため、避けるべきです。
このような場合の結果は予測しにくく、ときに予想外のものになります。

```javascript
0 == false;
// => true
```
