# 説明の補足

## 出力の形式

`treeFromTraversals`関数は、3つのプロパティを持つオブジェクトを返すことが期待されます。

- `value`現在のノードの値
- `left`ノードの左の子を持つオブジェクト
- `right`ノードの右の子を持つオブジェクト

```javascript
{
    value: 'a',
    left: { value: 'i', left: {}, right: {} },
    right: { value: 'x', left: {}, right: {} },
}
```

ツリーが空の場合は、空のオブジェクトを返します。
