# 概要

Common Lispでは、偽の値は空の配列（`()`）またはシンボル`nil`で表されます。
これらの値は、クォートしてもクォートしなくてもかまいません。

```lisp
;; Equivalent False Values
()   ; => NIL
nil  ; => NIL
'()  ; => NIL
'nil ; => NIL
```

Lispでは、それ以外の値はすべて真とみなされます。
また、常に`t`自身と等しい特別な定数シンボル`t`も存在します（したがって、常に真です）。

```lisp
;; Some Different True Values
42                        ; => 42
"this statement is false" ; => "this statement is false"
t                         ; => T
't                        ; => T
```
