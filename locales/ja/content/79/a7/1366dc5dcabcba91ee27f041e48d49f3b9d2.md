# 指示

この演習では、さまざまな種類のラジコンカーのレースを運営します。
それぞれの車には独自の特徴があり、トーナメントシーズンを通じて開催されるレースで、さまざまなトラックを走ります。

~~~~exercism/note
この演習の関数は、提示されたシグネチャを持つCのソースファイル内で宣言されています。
x86-64アセンブリのコードは、その仕様に従う必要があります。
~~~~

## 1. ラジコンカーを作成する

ラジコンカーを表すために、構造体`car_t`を定義しました：

```c
struct car_t {
    char name[10];
    int16_t speed;
    float battery;
};
```

x86-64アセンブリで関数`new_car`を定義して、ラジコンカーを作成できるようにします。
フィールド`battery`は常に値`100.0`から始まります。

```c
struct car_t new_car(short speed, const char name[]);
```

## 2. 新しいトラックを作成する

トラックは構造体`track_t`で表されます：

```c
struct track_t {
    enum surface_t surface;
    size_t distance;
};
```

`enum surface_t`は、トラックのさまざまな路面を管理します：

```c
enum surface_t {
    ASPHALT,
    SAND,
    ICE,
    CLAY
};
```

x86-64アセンブリで関数`new_track`を定義して、新しいトラックを作成できるようにします。

```c
struct track_t new_track(enum surface_t surface, size_t distance);
```

## 3. レースイベントを作成する

1つのレースには最大6台の車が参加し、トラックを指定された周回数だけ走ります。
レースは構造体`race_t`で表されます：

```c
struct race_t {
    struct track_t track;
    uint8_t num_of_laps;
    struct car_t cars[6];
    uint8_t num_of_running_cars;
};
```

x86-64アセンブリで関数`new_race`を定義します。
開始時点では、レースへの参加が確定した車は1台もありません：

```c
struct race_t new_race(struct track_t track, uint8_t num_of_laps);
```

## 4. レースへの車の参加を確定する

車のオーナーがレースへの参加を申し込んだとき、リストにまだ空きがあれば、その参加が確定します。

x86-64アセンブリで関数`add_participant`を定義します。
レースにもう1台分の空きがあれば、その車はリストに追加され、カウンターが更新されて、参加が確定します。
空きがなければ、レースの主催者は、今回は参加できないことを車のオーナーに伝えなければなりません。

```c
bool add_participant(struct race_t *race, struct car_t car);
```

## 5. トーナメントを作成する

シーズンに予定されているレースは、構造体`tournament_t`で管理します：

```c
struct tournament_t {
    struct race_t races[20];
    size_t num_of_races;
};
```

x86アセンブリで関数`add_race`を定義し、トーナメントの配列にレースを追加するとともに、カウンターも更新します。
`races`配列には、新しいレースのための十分な空きが常にあると考えてかまいません。

```c
void add_race(struct tournament_t *tournament, struct race_t race);
```
