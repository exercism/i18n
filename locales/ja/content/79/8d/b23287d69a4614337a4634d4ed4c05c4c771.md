# ヒント

## 概要

- タグとレコードのリストに基づいたDSLを作りたくなるかもしれません。たとえば次のようなものです。

  ```roc
  my_graph =
      Graph.create([
          Title("My Graph"),
          Node("a", { color: Green }),
          Node("b", { color: Blue }),
          Edge("a", "b", { style: Dotted }),
      ])
  ```

- あるいは、関数呼び出しの連鎖に基づいたDSLのほうがよいかもしれません。たとえば次のようなものです。

  ```roc
  my_graph =
      Graph.create()
          .with_title("My Graph")
          .add_node("a", Attr.create().with_color(Green))
          ...
  ```

  それとも、まったく別の方法を考えているでしょうか？　ぜひやってみてください！

- とはいえ、DSLはたいてい、明確で簡潔で、あまり驚かせないほうがよいものです（たとえば`minus`関数は引き算のためのものであり、`node("a") - node("b")`のように2つのノードの間に辺を作るためのものではありません）。
