# 指示

エージェントDouble-Null0111、また会いましたね。

UMBRAの勢力が再び動き出しました。その最新の計画を阻止するのはエージェントDouble-Null0111の任務です。情報部門によると、ミニオンたちは知事の舞踏会で悪臭爆弾を爆発させる計画を立てているとのことです。

ミニオンたちはとても不器用なので、研究室やオフィスでうっかり悪臭爆弾の起爆装置を作動させてしまうことがよくあります。そこで、悪臭爆弾の解除方法をいつも忘れてしまう彼らは、爆弾のID番号からワイヤーを切る順番を示す解除手順を生成するシステムを導入しました。

エージェントDouble-Null0111の仕事は、舞踏会の悪臭爆弾が爆発する前に解除できるようにするコードを書くことです。

## 1. 2本のワイヤーを入れ替えるクロージャを書く

悪臭爆弾にはそれぞれ、色の異なる3本のワイヤーがあります。
`(String, String, String)`のタプルを受け取り、最初の2つの要素の順番を入れ替えたタプルを返すクロージャを書きます。
このクロージャを`flip`という名前に代入します。

型は`ChangeClosure`（またはsendableな型）でなければならない点に注意してください。型定義はスタブファイルに書かれています。
そうでないと、コードはコンパイルできません。

```swift
flip(("red", "yellow", "blue"))
// Returns ("yellow", "red", "blue")
```

## 2. ワイヤーを回転させるクロージャを書く

`(String, String, String)`のタプルを受け取り、ワイヤーの順番を左に回転させたタプルを返すクロージャを書きます。
このクロージャを`rotate`という名前に代入します。

型は`ChangeClosure`（またはsendableな型）でなければならない点に注意してください。型定義はスタブファイルに書かれています。

```swift
rotate(("red", "yellow", "blue"))
// Returns ("yellow", "blue", "red")
```

## 3. ワイヤーのシャッフル生成器を実装する

悪臭爆弾のワイヤーを切る順番を割り出すには、悪臭爆弾のID番号に基づいて適切なシャッフル関数を生成する関数を実装する必要があります。

次の関数を実装します。

```swift
makeShuffle(
  flipper: @escaping ((String, String, String)) -> (String, String, String),
  rotator: @escaping ((String, String, String)) -> (String, String, String)
) -> ([UInt8], (String, String, String)) -> (String, String, String)
```

この関数は、2本のワイヤーを入れ替えるクロージャと3本のワイヤーを回転させるクロージャを入力として受け取り、クロージャを返します。
返されたクロージャは、悪臭爆弾のID番号と3本のワイヤーの順番を受け取り、ワイヤーを切るべき順番を計算します。
ID番号は8ビットでできており、各ビットがワイヤーを入れ替えるか回転させるかを決めます。

ID番号の各ビットについて、右端のビットから順に、ビットが0なら`flipper`クロージャを、1なら`rotator`クロージャをワイヤーのタプルに適用し、新しいワイヤーの状態を得ます。
IDの8ビットすべてに対して適切なクロージャを適用したあと、ワイヤーの最終的な状態が、切るべき順番になります。

```swift
let shuffler = makeShuffle(flipper: flip, rotator: rotate)
// Returns ([UInt8], (String, String, String)) -> (String, String, String)
shuffler([1, 0, 0, 1, 1, 0, 1, 1], ("red", "yellow", "blue"))
// Returns ("red", "blue", "yellow")
```
