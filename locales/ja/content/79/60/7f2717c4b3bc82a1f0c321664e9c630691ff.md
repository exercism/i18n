# 概要

[`Set`][set-docs]は、順序を持たないコレクションで、`List`とは異なり、重複する値が含まれないことが保証されています。

`Set`インターフェースのジェネリック型パラメーターは、`Set`に含まれる要素の型を表します。

```java
Set<Integer> ints = Set.of(1, 2, 3);
Set<String> strings = Set.of("alpha", "beta", "gamma");
Set<Object> mixed = Set.of(1, false, "foo");
```

なお、`Set.of()`メソッドは[_変更できない_][unmodifiable-set-docs]`Set`のインスタンスを作成することに注意してください。
このインスタンスに対して`add`や`remove`のようなメソッドを呼び出そうとすると、実行時に例外が発生します。

変更可能な`Set`を作成するには、`Set`インターフェースを実装するクラスをインスタンス化する必要があります。
このインターフェースを実装する最もよく使われる組み込みクラスは、[`HashSet`][hashset-docs]クラスです。

```java
Set<Integer> ints = new HashSet<>();
```

`Set`インターフェースは[`Collection`][collection-docs]インターフェースと[`Iterable`][iterable-docs]インターフェースを拡張しているため、他の種類のコレクションと多くのメソッドを共有しています。
ただし、`Collection`インターフェースとの大きな違いは、`add`や`remove`のようなメソッドが（`void`ではなく）`boolean`を返し、そのメソッドを呼び出したときに要素がセットに含まれていたかどうかを示す点です：

```java
Set<Integer> set = new HashSet<>();
set.add(1);
// => true
set.add(2);
// => true
set.add(1);
// => false
set.size();
// => 2
set.contains(1);
// => true
set.contains(3);
// => false
set.remove(3);
// => false
set.remove(2);
// => true
set.size();
// => 1
```
