# 説明

友達にクッキーを焼こうと準備していると、レシピで使われている分量のいくつかを変換しなければならないことに気づきました。メートル法にしか慣れていないので、自分が楽に使えるように、アメリカの料理でよく使われる分量をミリリットル（mL）に変換する方法を考え出す必要があります。

解答には、次の変換表を使いましょう。

| 変換する単位 | 量 | ミリリットル（mL）換算 |
| --------------- | ------ | ------------------- |
| mL              | 1      | 1                   |
| アメリカのカップ          | 1      | 240                 |
| アメリカの液量オンス  | 1      | 30                  |
| アメリカの小さじ     | 1      | 5                   |
| アメリカの大さじ   | 1      | 15                  |

才能ある見習いプログラマーであれば、一覧にあるどの単位からどの単位へも（同じ単位へでさえも）変換を楽にするため、ミリリットルを経由する単位として使うことにします。

## 1. 量のペアから数値の部分を取り出す

`getVolume`関数を実装しましょう。量のペアのタプルが与えられたら、数値の部分だけを返します。

```haskell
getVolume (Cup, 2.0)
-- -> 2.0
```

## 2. 量のペアをミリリットルに変換する

`toMilliliter`関数を実装しましょう。量のペアのタプルが与えられたら、変換表を使ってその量をミリリットルに変換します。

複数の関数節とパターンマッチを使って、各単位に対応する関数を作りましょう。各単位を表すアトムは、`Cup`、`FluidOunce`、`Teaspoon`、`Tablespoon`、`Milliliter`です。変換結果はタプルに包んで返します。

```haskell
toMilliliter (Cup, 2.5)
-- -> (Milliliter, 600.0)
```

## 3. ミリリットルの量のペアを別の単位に変換する

`fromMilliliter`関数を実装しましょう。量のペアのタプルと目的の単位が与えられたら、変換表を使ってその量を目的の単位に変換します。

複数の関数節とパターンマッチを使って、各単位に対応する関数を作りましょう。各単位を表すアトムは、`Cup`、`FluidOunce`、`Teaspoon`、`Tablespoon`、`Milliliter`です。

```haskell
fromMilliliter (Milliliter, 1320.0) Cup
-- -> (Cup, 5.5)
```

## 4. どの単位からでも別の単位に変換する

`convert`関数を実装しましょう。量のペアのタプルと目的の単位が与えられたら、与えられた量を目的の単位に変換します。

```haskell
convert (Teaspoon, 9.0) Tablespoon
-- -> (Tablespoon, 3.0)
```
