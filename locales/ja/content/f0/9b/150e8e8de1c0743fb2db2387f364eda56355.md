# デバッグ

```pyret
fun print-forty-two():
  print(42) # 42
end
```

```pyret
fun return-forty-two() block:
  print(42) # 42
  42
end
```

[print][print]は値を返す式です。Pyretでは、外側のブロックに`block`を付けない限り、1つのブロックの中に書ける式は1つだけです。2つ目の例では、関数の宣言に`block`を付けることで、42を返す前に出力できます。

## スパイ

```pyret
fun do-something():
    x = "foo"
    y = "bar"
    spy "strings": x, y end
    a = 1
    b = 2
    spy "numbers": a, b end
end
do-something();

# Spying "strings" (at <clipped>/example.arr:4:4-4:27)
#  x: "foo"
#  y: "bar"
# Spying "numbers" (at <clipped>/example.arr:7:4-7:27)
#  a: 1
#  b: 2
```

スパイ文は、省略可能なラベルと1つ以上の変数を取り、それぞれの変数とその値を報告します。式ではないので、外側のブロックに`block`を付けなくても、ブロックの中でスパイを使えます。

[print]: https://pyret.org/docs/latest/_global_.html#%28idx._%28gentag._57%29%29
[spy]: https://pyret.org/docs/latest/s_spies.html
