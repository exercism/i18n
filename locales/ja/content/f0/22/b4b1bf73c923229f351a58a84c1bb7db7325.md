# テストの実行

ターミナルで演習のベースディレクトリに移動し、次のコマンドでテストを実行します：

```bash
$ mix test
```

これで、`test`サブフォルダーにあるテストファイル（ファイル名が`_test.exs`で終わるもの）が実行されます。

ドキュメント：

* [`mix test`：Elixirのテスト実行ツール](https://hexdocs.pm/mix/Mix.Tasks.Test.html)
* [`ExUnit`：Elixirの単体テストライブラリ](https://hexdocs.pm/ex_unit/ExUnit.html)

## 保留中のテスト

練習用の演習のテストスイートでは、最初のテスト以外はすべてスキップされるようにタグ付けされています。

テストが1つ通ったら、該当する`@tag :pending`を`#`記号でコメントアウトすると、次のテストのスキップを解除できます。

たとえば：

```elixir
# @tag :pending
test "shouting" do
  assert Bob.hey("WATCH OUT!") == "Whoa, chill out!"
end
```

すべてのテストを一度に実行したい場合は、`mix test`コマンドに`--include`フラグを付けると、スキップされたテストをすべて含めることができます：

```bash
$ mix test --include pending
```

または、`test/test_helper.exs`ファイルにある`ExUnit.configure`の行をコメントアウトすると、すべてのテストを有効にできます。

```elixir
# ExUnit.configure(exclude: :pending, trace: true)
```

## 便利な`mix test`オプション

* `test/<FILE>.exs:LINENUM`：1つのテストだけを実行します。`<FILE>.exs`の中で定義が`LINENUM`行目にあるテストです
* `--failed`：前回実行したときに失敗したテストだけを実行します
* `--max-failures`：テストの失敗がこの数に達すると、スイートはテストの評価を停止します
* `--seed 0`：ランダム化を無効にするので、1つのファイル内のテストは常に定義した順序で実行されます
