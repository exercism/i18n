# 概要

Elmの[`List`][lists]は、同じ型の0個以上の値からなる不変のコレクションです。
リストは不変なので、一度作られたリストの値が後から変わることは決してありません。
Elmのリストには_先頭_（最初の要素）と_残り_（最初の要素より後ろのすべて）があります。
リストの残りもまた、それ自体がリストです。

リストの型注釈は、次のように定義できます。

```elm
List String --> a list of String
List Int --> a list of Int
```

リストは次のように定義できます。

```elm
empty : List Char
empty = []

singleValue = [ 5 ] --> List Int
singleValueAlternative = List.singleton 5 --> List Int

threeValues = [ "a", "b", "c" ] --> List String
```

リストに要素を追加する最も一般的な方法は、`::`（cons）演算子を使うことです。

```elm
twoToFour = [ 2, 3, 4 ]
oneToFour = 1 :: twoToFour --> [1; 2; 3; 4]
```

リストは`++`演算子または`List.append`を使って連結できます。

```elm
[ 6, 7 ] ++ [ 8, 9 ]           --> [6, 7, 8, 9]
List.append [ 6, 7 ] [ 8, 9 ]  --> [6, 7, 8, 9]
```

リストは、[`List`モジュール][list-module]で定義された関数や演算子を使って操作します。

```elm
List.length [ 7, 8 ] --> 2
```

リストを変更するように見える関数や演算子（要素の追加など）は、実際には新しいリストを返します。
ただし、リストの実装では不要な割り当てやコピーが避けられるため、通常はパフォーマンスが問題になることはありません。

リストは[パターンマッチング][list-destructuring]を使って処理することもできます。

```elm
describe : List String -> String
describe list =
    case list of
        [] ->
            "Empty list"

        [ "hello" ] ->
            "Singleton list with: hello"

        x :: xs ->
            "Non-empty list with head: " ++ x

describe []                   --> "Empty list"
describe [ "hello" ]          --> "Singleton list with: hello"
describe [ "hello", "world" ] --> "Non-empty list with head: hello"
```
