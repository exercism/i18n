# はじめに

Factorでは、`: name ( stack-effect ) body ;`と書いて新しいワードを定義します。本体はワードの並びで、新しいワードを呼び出すと、その並びが順番に実行されます。

```factor
USING: kernel ;
IN: my-vocab

: shout ( str -- str ) "!" append ;
```

処理が大きくなってきたら、それを*factor*することができます。いえ、すべきです。ワードのまとまりを、それぞれ1つの役割を持つ小さな名前付きワードに切り出しましょう。Factorという言語の名前は、ここから来ています。

## ボキャブラリ

各`.factor`ファイルは、`IN:`でボキャブラリを宣言します。あるボキャブラリのワードは、`USING:`に別のボキャブラリを並べることで、そのボキャブラリのワードを呼び出せます。

```factor
! file: my-vocab/helpers/helpers.factor
USING: kernel ;
IN: my-vocab.helpers

: shout-line ( str -- str ) "!" append ;
```

```factor
! file: my-vocab/my-vocab.factor
USING: kernel my-vocab.helpers sequences ;
IN: my-vocab

: announce ( names -- strs )
    [ shout-line ] map ;
```

ディレクトリ構成は、ドットで区切られたボキャブラリ名に対応しています。ボキャブラリ`my-vocab`は`my-vocab/my-vocab.factor`に、ボキャブラリ`my-vocab.helpers`は`my-vocab/helpers/helpers.factor`に置きます。Factorのローダーは、`USING:`の宣言を再帰的にたどり、必要になったボキャブラリをそのつど読み込みます。
