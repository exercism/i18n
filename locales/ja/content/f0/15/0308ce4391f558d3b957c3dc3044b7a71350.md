# 概要

## 数値と数値演算子

**数値**は、整数であれそれ以外であれ、すべてIEEE754の倍精度浮動小数点数です。
`jq`の実装は、C言語の`double`型を使っています。
このため、精度は53ビットに制限されます。

数値には、次のようないつもの演算子が使えます。

- 算術: `+`、`-`、`*`、`/`、`%`
- 比較: `==`、`!=`、`<`、`<=`、`>=`、`>`
- 標準の[数学関数][man-math]

  入力が1つの関数では、値をその関数にパイプで渡します。

  ```sh
  $ jq -n '(1 | atan) * 4'
  3.141592653589793
  ```

  入力が2つの関数では、入力は無視され、2つの値を引数として渡します。

  ```sh
  $ jq -n 'pow(2; 10)'
  1024
  ```

  関数の引数の区切りには、カンマではなくセミコロンを使います。

~~~~exercism/caution
「精度は53ビットに制限されます」とは、どういう意味でしょうか？

実際に見てみましょう。

```sh
$ jq -n 'pow(2;52) as $n | [$n, $n+1]'
[
  4503599627370496,
  4503599627370497
]
```

よさそうです。では、指数を増やしたらどうなるでしょうか？

```sh
$ jq -n 'pow(2;53) as $n | [$n, $n+1]'
[
  9007199254740992,
  9007199254740992
]
```

この2つの数値は、等しくならないはずです。
これが「精度の低下」というものです。
つまり、`jq`は任意の大きさの数値を扱えるわけではありません。
~~~~

## 条件式

`jq`では、**条件式**に[`if-then-else`式][if-then-else]を使います。
これは_式_なので、パイプラインの中に置きます。

構文は`if CONDTITION then TRUE_EXPR else FALSE_EXPR end`です。

`else`節は省略できます。

```jq
42 | if . < 33 then "small" else "larger" end
# => "larger"
```

条件を追加するには`elif`を使います。

```jq
42 | if . < 33 then "small"
     elif . < 67 then "medium"
     else "large"
     end
# => "medium"
```
