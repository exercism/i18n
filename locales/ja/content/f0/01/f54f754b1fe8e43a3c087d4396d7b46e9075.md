# 指示

この演習では、自動車工場の組み立てラインの生産を分析するコードを書きます。
組み立てラインの速度は、`0`（停止）から`10`（最大）まで設定できます。

最も低い速度（`1`）では、1時間あたり`221`台の車が生産されます。
生産量は速度に比例して増加します。
ですから、速度を`4`に設定すると、1時間あたり`4 * 221 = 884`台の車を生産することになります。
ただし、速度が上がるほど不良品が作られる可能性が高くなり、そうした車は廃棄しなければなりません。

取り組むタスクは3つあります。
必要な各関数は、整数の入力を1つ受け取ります。その入力は組み立てラインの速度です。

## 1. 成功率を計算する

与えられた速度に対して、製品がエラーなく作られる確率を計算する`success_rate()`メソッドを実装しましょう。
次の表は、速度が成功率にどう影響するかを示しています。

- `0`: 成功率0%。
- `1`から`4`まで: 成功率100%。
- `5`から`8`まで: 成功率90%。
- `9`: 成功率80%。
- `10`: 成功率77%。

```julia-repl
julia> success_rate(10)
0.77
```

## 2. 1時間あたりの生産量を計算する

成功率を考慮に入れて、組み立てラインの1時間あたりの生産量を計算する`production_rate_per_hour()`メソッドを実装しましょう。

```julia-repl
julia> production_rate_per_hour(6)
1193.4
```

戻り値は浮動小数点数であることに注意してください。

## 3. 1分あたりに生産される正常な車の数を計算する

1分あたりに何台の正常な車が生産されるかを計算する`working_items_per_minute()`メソッドを実装しましょう。

```julia-repl
julia> working_items_per_minute(6)
19
```

戻り値は整数であることに注意してください。未完成の車は含まれません。
