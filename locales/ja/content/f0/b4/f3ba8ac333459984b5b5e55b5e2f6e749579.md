# 概要

仮引数の型を推論できる場合は、Swiftではクロージャの定義から仮引数名とキーワード`in`を省略することもできます。その代わりに、[特別な省略記法][shorthand-argument-names]を使って仮引数を参照できます。この記法では、`$0`が1つ目の仮引数、`$1`が2つ目の仮引数を指し、以下同様に続きます。

```swift
let mean: (Double, Double) -> Double = { $0 + $1 / 2.0 }

["apple", "ball", "carrot"].sorted(by: { $0.count < $1.count })
```

この書き方は、クロージャを高階関数に渡すときに、簡潔さが重視される場面で特によく使われます。

[shorthand-argument-names]: https://docs.swift.org/swift-book/LanguageGuide/Closures.html#ID100
