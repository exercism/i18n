# 説明

冒険好きの錬金術師アストリッドは、さまざまな世界から集めた魔法の計量単位を標準化しようとしています。
世界によっては符号付きの測定値（負の値もあり得ます）を使い、別の世界では符号なしの測定値（常に正の値）を使っています。
さらにアストリッドには、ある珍しい材料のための2つのカスタム型があり、これらの型の間で簡単に変換する方法が必要です。

今回の目標は、アストリッドが符号付き整数と符号なし整数の間で変換できるようにし、Cairoの`Into`と`TryInto`トレイトを使って、アストリッドの特別な材料の型に対するカスタム型変換を作成することです。

## 1. 符号付きと符号なしの魔法の単位の変換

アストリッドの測定値は、正の値にも負の値にもなることがあります（符号付き整数）。しかし、特定の作業では、値が常に正であること（符号なし整数）を保証する必要があります。

次の変換を行う関数を書いて、アストリッドを手伝いましょう。

1. 符号付き整数（`i32`）から符号なし整数（`u16`）へ。
2. 符号なし整数（`u16`）から符号付き整数（`i32`）へ。

```rust
let signed_value: i32 = -42;
match convert_signed_to_unsigned(signed_value) {
    Option::Some(v) => println!("Converted to unsigned: {}", v),
    Option::None => println!("Failed to convert: {}", signed_value),
} // prints "Failed to convert: -42"

let unsigned_value: u16 = 42;
let signed_value: i32 = convert_unsigned_to_signed(unsigned_value);
println!("Converted to signed: {}", signed_value); // prints "Converted to signed: 42"
```

## 2. 材料のカスタム型の変換

アストリッドは、**Essence**と**Elixir**という2つの珍しい材料を扱っています。これらはカスタム型で表されます。
アストリッドは、**Essence**を**Elixir**に変換できるようにしたいと考えていますが、その逆は望んでいません。

2つのカスタム型`Essence`と`Elixir`を作成し、`Essence`から`Elixir`への変換を行う`Into`トレイトを実装して、アストリッドを手伝いましょう。

`Essence`を受け取り、`.into()`を使って`Elixir`に変換する関数を書いてみましょう。

```rust
#[derive(Drop)]
struct Essence {
    potency: u16,
}

#[derive(Drop)]
struct Elixir {
    strength: u16,
}

fn convert_essence_to_elixir(essence: Essence) -> Elixir {
    // Convert the Essence to Elixir using the Into trait.
    essence.into()
}

fn main() {
    let essence = Essence { potency: 100 };
    let elixir: Elixir = convert_essence_to_elixir(essence);
    println!("Elixir strength: {}", elixir.strength); // Elixir strength: 100
}
```
