# はじめに

Clojureでは、値に名前を結びつけることを_var_と呼びます。トップレベル（グローバル）のvarは、他の言語の定数に似ています。

トップレベルのvarは、`def`を使って定義します。

```clojure
(def fingers 10)

fingers
;;=> 10
```

`defn`を使うと、0個以上の引数を取る関数を定義できます。これは、2つの数値を足し合わせる関数です。

```clojure
(defn add [x y]
  (+ x y))
```

この関数は2つの引数を取り、それらはベクター`[x y]`に置かれます。その後に、任意の数の式を書ける関数の*本体*が続きます。戻り値は、必ず本体の最後の式`(+ x y)`を評価した結果です。この式は、関数呼び出しを表すリストです。リストの先頭の要素が`+`関数であり、その後に続く要素`x`と`y`を引数として評価されます。

上で定義した`add`関数も、同じように呼び出します。

```clojure
(add 2 3)
;;=> 5
```

Clojureの関数や値は、定義した_後_にしか使えません。つまり、フォームは常に書かれた順に評価されます。

Clojureでは、空白文字は整形以外の意味を持ちません。

Clojureの関数とvarは、名前空間にまとめられています。名前空間は、関連する機能をひとつにまとめるもので、`ns`マクロを使って定義します。

```clojure
(ns calculator)

(def pi 3.14)

(defn add [x y]
  (+ x y))
```

Clojureでは、2種類のコメントを書けます。1行コメントは`;`で始めます。また、`comment`フォームは、`(comment`と`)`の間にあるすべての式を評価しないようにするために使います。
