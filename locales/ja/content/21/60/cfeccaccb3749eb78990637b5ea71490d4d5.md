# ヒント

## 全般

- `USING:`の行に`math.functions`と`math.constants`を追加します。タスク3では`math.libm`も必要です。
- テストではごくわずかな誤差が許容されるので、掛け算と割り算の順序は関係ありません。

## 1. 境界までのロープ

- 3つの値を掛け合わせます。そのうち1つは`pi`です。

## 2. ピッチからどれだけ離れているか？

- `[ sq ] bi@`は、スタックの上にある2つの数値をそれぞれ2乗します。
- 2乗した値を足してから、`sqrt`を呼びます。

## 3. どちらの方向に飛んだか？

- `fatan2`は、横方向の距離`y`を、地面に沿った距離`x`の*下*に取ります。これは値が届く順序とは逆なので、まず`swap`で入れ替えます。
- 戻り値はラジアンです。`rad>deg`を使うと度に変換できます。

## 4. ボールはどれだけ飛んだか？

- `sin`はラジアンを必要としますが、`angle`は度です。まず`deg>rad`で変換してから、2倍します。
- `bi*`は、1つのクォーテーションを`speed`に、もう1つを`angle`に適用します: `[ sq ] [ ... ] bi*`。

## 5. 芝生の上で減速する

- *e*のべき乗は`e^`で、べき乗の値を対象に呼び出します。まず`-0.02 * metres`を計算します。

## 6. 追いかける価値がなくなるのはどこか？

- lnは`log`です。`speed / target`に対して呼び出し、その結果を`0.02`で割ります。
