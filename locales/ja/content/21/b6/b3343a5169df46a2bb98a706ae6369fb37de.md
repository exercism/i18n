駆け出しのマジシャンであるElyseは、基本の練習をする必要があります。
彼女には、自由に操りたいトランプのデッキがあります。

少し簡単にするために、使うカードは1から10までだけにしています。

## 1. デッキからカードを取得する

与えられたデッキから、位置`idx`にあるカードを返します。

```julia-repl
julia> idx = 2;

julia> card([1, 3, 4, 1], idx)
3
```

## 2. デッキのカードを交換する

位置`idx`にあるカードを、指定された新しいカードと交換し、更新後のデッキを返します。
これは入力のベクトルをミューテート（変更）することになりますが、問題ありません。

```julia-repl
julia> idx = 2; new_card = 6;

julia> replace_card!([1, 3, 4, 1], idx => new_card)
[1, 6, 4, 1]
```

## 3. デッキの一番上にカードを挿入する

デッキの一番上に新しいカードを挿入し、そのデッキを返します。

```julia-repl
julia> new_card = 8;

julia> insert_card_at_top!([1, 3, 4, 1], new_card)
[1, 3, 4, 1, 8]
```

## 4. デッキからカードを取り除く

デッキから位置`idx`にあるカードを取り除き、そのデッキを返します。

```julia-repl
julia> idx = 2;

julia> remove_card!([1, 3, 4, 1], idx)
[1, 4, 1]
```

## 5. デッキの一番上のカードを取り除く

デッキの一番上のカードを取り除き、そのデッキを返します。

```julia-repl
julia> remove_card_from_top!([1, 3, 4, 1])
[1, 3, 4]
```

## 6. デッキの一番下にカードを挿入する

デッキの一番下に新しいカードを挿入し、そのデッキを返します。

```julia-repl
julia> new_card = 8;

julia> insert_card_at_bottom!([1, 3, 4, 1], new_card)
[8, 1, 3, 4, 1]
```

## 7. デッキの一番下のカードを取り除く

デッキの一番下のカードを取り除き、そのデッキを返します。

```julia-repl
julia> remove_card_at_bottom!([1, 3, 4, 1])
[3, 4, 1]
```

## 8. デッキの枚数を確認する

デッキの枚数が、指定された`deck_size`と同じかどうかを確認します。

```julia-repl
julia> deck_size = 4;

julia> check_deck_size([1, 3, 4, 1], deck_size)
true

julia> check_deck_size([1, 3, 4, 1, 5], deck_size)
false
```
