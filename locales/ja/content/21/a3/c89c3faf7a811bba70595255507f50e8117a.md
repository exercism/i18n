# 辞書

Cairoの辞書は、他の言語のマップやハッシュテーブルのような、キーと値のストアです。

しかし、Cairoの不変のメモリモデルのため、いくつか独特な特徴があります。

## 基本的な考え方

`Felt252Dict<T>`型は、キーの型を`felt252`、値の型を対応する任意の型`T`とする辞書の機能をCairoで提供します。

```rust
use core::dict::Felt252Dict;

fn main() {
    let mut balances: Felt252Dict<u64> = Default::default();
    balances.insert('Alice', 100);
    let balance = balances.get('Alice'); // Returns 100
}
```

## 重要な特徴

他の言語の辞書とは違い、Cairoの辞書にはいくつか特別な性質があります。

1. キーは`felt252`の値でなければなりません。
2. すべてのキーは、暗黙的に値0から始まります。
3. エントリーを削除することはできません。値の更新だけができます。
4. 値は`Felt252DictValue`トレイトを実装している必要があります。

## パフォーマンスに関する注意

Cairoの不変のメモリモデルのため、辞書の操作は$O(n)$の計算量になります。ここで$n$は、その辞書に対して行われる操作の数です。

操作を行うたびに、その変更を記録する新しいエントリーが作られます。

## 複雑な型を扱う

`Felt252DictValue`を実装していない型（配列や構造体など）は、`Nullable<T>`で包むことができます。

```rust
let mut dict: Felt252Dict<Nullable<Span<felt252>>> = Default::default();
dict.insert(0, NullableTrait::new(array![1, 2, 3].span()));
```

## メモリ管理

辞書は`Destruct`トレイトを実装しています。つまり、スコープから外れると自動的に「squash」されます（検証され、最適化されます）。

これはCairoの証明システムの一部で、裏側で行われます。

覚えておきましょう。辞書は他の言語のものより効率が悪いように見えるかもしれませんが、Cairo独自のメモリモデルと証明システムの要件に合わせて、このように設計されています。
