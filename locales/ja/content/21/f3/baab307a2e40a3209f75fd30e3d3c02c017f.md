# はじめに

Gleamは、Erlang仮想マシン（BEAM）またはJavaScriptランタイム上で動作します。これらのランタイムを使う言語はほかにもたくさんあり、そうした言語で書かれたコードをGleamから呼び出せると便利なことがよくあります。

Gleamの_外部関数_機能を使うと、他の言語の関数をGleamにインポートし、ランタイムオーバーヘッドなしで呼び出せます。

GleamプロジェクトがErlang仮想マシン上で動作していて、Erlangの`lists`モジュールの`reverse`関数を呼び出したい場合は、次のように、Gleamの関数ヘッドに`@external`属性を追加すると呼び出せます：

```gleam
@external(erlang, "lists", "reverse")
pub fn reverse_list(x: List(a)) -> List(a)
```

これは、通常のGleam関数と同じように呼び出せます：

```gleam
let reversed = reverse_list([1, 2, 3])
// -> [3, 2, 1]
```

このコードをJavaScriptランタイム向けにコンパイルしようとすると、JavaScript向けの実装がないため、エラーメッセージが出て失敗します。JavaScriptランタイム向けには、次のように別の実装を指定できます：

```gleam
@external(erlang, "lists", "reverse")
@external(javascript, "./my_module.mjs", "reverse")
pub fn reverse_list(x: List(a)) -> List(a)
```

現在のコンパイルターゲット向けの外部実装がないときに使われるGleamの実装を書くこともできます：

```gleam
@external(erlang, "lists", "reverse")
pub fn reverse_list(x: List(a)) -> List(a) {
  tail_recursive_reverse(x, [])
}

fn tail_recursive_reverse(list, reversed) {
  case list {
    [] -> reversed
    [x, ..xs] -> tail_recursive_reverse(xs, [x, ..reversed])
  }
}
```
