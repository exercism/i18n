# 説明

弦楽グループが発表会で演奏することになり、プログラムを書く人が必要です。

5つのタスクはすべて`PROGRAMME_NOTES`クラスに書きます。

## 1. 曲名と作曲者を書く

曲名を先に、そのあとに` by `、最後に作曲者を書きます。

```sather
PROGRAMME_NOTES::full_title("Nocturne", "Chopin")
-- => "Nocturne by Chopin"
```

## 2. 1行の長さを測る

印刷する人は、1行がどれくらいの長さかを知る必要があります。

```sather
PROGRAMME_NOTES::title_length("Nocturne")
-- => 8
```

## 3. 最初の数文字

曲名と数値を受け取り、先頭からその文字数分の文字を返します。

```sather
PROGRAMME_NOTES::opening_letters("Nocturne", 3)
-- => "Noc"
```

## 4. 最後の数文字

同じことを、末尾から数えて行います。

```sather
PROGRAMME_NOTES::closing_letters("Nocturne", 4)
-- => "urne"
```

## 5. 長い曲名を短くする

収まらない曲名は、最初の6文字まで切り詰め、そのあとにピリオドを3つ付けます。

```sather
PROGRAMME_NOTES::short_title("Nocturne in E flat")
-- => "Noctur..."
```
