# 概要

[`Box`][box]を理解するには、[スタックとヒープ][stack and heap]とは何かを知っておくと役立ちます。

スタックは、後入れ先出し（LIFO）バッファーのように動作するメモリ領域です。スタックへのデータのプッシュは非常に速く、ポップも高速です。データには変数や関数のアドレスを含めることができますが、コンパイル時に既知の固定サイズでなければなりません。

コンパイル時にサイズが不明なデータや、サイズが変わる可能性のあるデータは、ヒープに割り当てる必要があります。割り当てのプロセスでは、データを格納するのに十分な大きさの領域をヒープから探し、データをヒープに書き込み、そのデータのメモリアドレスをスタックにプッシュする必要があります。これらはすべて、単にデータをスタックに置くよりもはるかに時間がかかります。ヒープからデータを取り出すのは少し遅くなります。スタック上のアドレスをたどり、そこからヒープ上のデータの位置にたどり着く必要があるからです。

`Box`は、データをヒープに割り当てるスマートポインターです。アドレスはスタック上にあり、ヒープ上のデータを指しています。`Box`を使う[理由][reasons]の1つは、コンパイル時にサイズがわからない型があり、その型の値を正確なサイズが要求されるコンテキストで使いたいときに、データをヒープに置くことです。その実用的な例として、複数の構造体があり、それらがすべて実装しているトレイトを通じて同じように扱いたい場合が挙げられます。以下の例のようにです。

2つの構造体があるとしましょう。それぞれの構造体は、人をイライラさせうるものを表しています。次のように、各構造体にAnnoyanceトレイトを実装させることができます。

```rust
struct WerewolfOfLondon;
struct Rooster;

trait Annoyance {
    fn annoy(&self) -> &'static str;
}

impl Annoyance for WerewolfOfLondon {
    fn annoy(&self) -> &'static str {
        "ahhh-OOOOOOO!"
    }
}

impl Annoyance for Rooster {
    fn annoy(&self) -> &'static str {
        "errr-errr-errr-errr-ERRRRRRRRR!"
    }
}
```

次に、渡された時刻に基づいてAnnoyanceを返す関数が欲しいとしましょう。まずこれを試してみますが、コンパイルできないことがわかります。

```rust
enum TimeOfDay {
    Midnight,
    Morning,
}

//return something that implements Annoyance
fn annoy_me(time_of_day: TimeOfDay) -> impl Annoyance {
    match time_of_day {
        TimeOfDay::Midnight => WerewolfOfLondon,
        TimeOfDay::Morning => Rooster,
    }
}

// `match` arms have incompatible types
// expected struct `WerewolfOfLondon`, found struct `Rooster`
// this is found to be of type `WerewolfOfLondon`
// `match` arms have incompatible types
// you could change the return type to be a boxed trait object
// if you change the return type to expect trait objects, box the returned expressions

```

コンパイラーは、その親切さで、何をすべきかを正確に教えてくれます。それは、ボックス化されたトレイトオブジェクトを返すことです。トレイトオブジェクトが何かわからない場合、簡単に言えば、指定されたトレイトを実装する任意のオブジェクトを返しうる関数から、[動的ディスパッチ][dynamic dispatch]を介して特定のオブジェクトを返す方法です。動的ディスパッチが必要なので、トレイト名の前に`dyn`を置くだけでうまくいくか試してみましょう。

```rust
fn annoy_me(time_of_day: TimeOfDay) -> dyn Annoyance {
    match time_of_day {
        TimeOfDay::Midnight => WerewolfOfLondon,
        TimeOfDay::Morning => Rooster,
    }
}

// the size for values of type `dyn Annoyance` cannot be known at compilation time
// the trait `Sized` is not implemented for `dyn Annoyance`
// all local variables must have a statically known size
// unsized locals are gated as an unstable feature
```

エラーの1つは、`dyn Annoyance`のサイズがコンパイル時にわからないことです。これは、`annoy_me`が、呼び出される前に、どの特定のトレイトオブジェクトを返すのかを知らないためです。Annoyanceを実装する構造体は、異なるフィールドを持ち、異なるサイズになる可能性があります。そして、`Box`の用途の1つは、コンパイル時にサイズがわからない型のためであることを思い出します。そこで今度は、`Box`化した戻り値を使ってみます。match式から返される値を次のように`Box`で包みます。

```rust
fn annoy_me(time_of_day: TimeOfDay) -> Box<dyn Annoyance> {
    match time_of_day {
        TimeOfDay::Midnight => Box::new(WerewolfOfLondon),
        TimeOfDay::Morning => Box::new(Rooster),
    }
}
```

`Box`のシグネチャは`Box<T>`です。`T`はボックス化する具体的な型を表し、山括弧の中に置かれます。上の`Box<dyn Annoyance>`のようにです。

ボックス化されたトレイトオブジェクトは、次のように利用できます。

```rust
fn be_annoying(annoying_one: &dyn Annoyance) {
    println!("{:?}", annoying_one.annoy());
}

pub fn main() {
    let my_annoyance = annoy_me(TimeOfDay::Midnight);
    be_annoying(&*my_annoyance);
    let my_annoyance = annoy_me(TimeOfDay::Morning);
    be_annoying(&*my_annoyance);
}
```

これは次のように出力します。

```rust
"ahhh-OOOOOOO!"
"errr-errr-errr-errr-ERRRRRRRRR!"
```

`my_annoyance`は`Box<dyn Annoyance>`型なので、deref演算子`*`を使って`Box`から参照を外す必要があります。その後、`be_annoying`関数が借用できるように、`dyn Annoyance`として参照されます。

もう1つの実装方法は、パラメーターがサイズを持つという要件を取り除くことです。その場合、コンパイルでは、静的にディスパッチできるように（このプロセスは[単相化][monomorphization]と呼ばれます）、Annoyanceの各バリアントごとに個別の関数が作成されます。次のようになります。

```rust
fn be_annoying<A: Annoyance + ?Sized>(annoying_one: &A) {
    println!("{:?}", annoying_one.annoy());
}
```

さらに別の実装方法は、`be_annoying`関数が`Box<dyn Annoyance>`を受け取り、[参照外し型強制][deref coercion]を使って`Box`を手動で参照外しする手間を省くことです。これにより、Annoyanceトレイトオブジェクトの所有権が`be_annoying`関数に移ります。関数の終わりにスコープを抜け、利用できなくなります。

```rust
fn be_annoying(annoying_one: Box<dyn Annoyance>) {
    println!("{:?}", annoying_one.annoy());
}

pub fn main() {
    let my_annoyance = annoy_me(TimeOfDay::Midnight);
    be_annoying(my_annoyance);
    let my_annoyance = annoy_me(TimeOfDay::Morning);
    be_annoying(my_annoyance);
}
```
