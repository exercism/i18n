# 説明

この演習では、自動車工場の組み立てラインの生産を分析するコードを書きます。組み立てラインの速度は、`0`（オフ）から`10`（最大）までの範囲です。

最低速度（`1`）では、1時間に`221`台の車が生産されます。生産量は速度に比例して増加します。つまり、速度を`4`に設定すると、1時間に`4 * 221 = 884`台の車を生産することになります。ただし、速度が上がるほど、不良車が生産される可能性が高くなり、そうした車は廃棄しなければなりません。次の表は、速度が成功率にどのように影響するかを示しています。

- `1`から`4`：成功率は100%です。
- `5`から`8`：成功率は90%です。
- `9`と`10`：成功率は77%です。

ここには2つのタスクがあります。

## 1. 1時間あたりの生産率を計算する

成功率を考慮して、組み立てラインの1時間あたりの生産率を計算するメソッドを実装します。

```rust
assembly_line::production_rate_per_hour(6)
// Returns: 1193.4
```

戻り値が`f64`であることに注意してください。

## 2. 1分あたりに生産される良品の数を計算する

1分あたりに何台の良品の車が生産されるかを計算するメソッドを実装します。

```rust
assembly_line::working_items_per_minute(6)
// Returns: 19
```

戻り値が`u32`であることに注意してください。
