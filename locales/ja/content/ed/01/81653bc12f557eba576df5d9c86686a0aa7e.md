# 手順

森の中に歩く道を引く作業をしています。距離も見かけたものも、どちらも並びとして渡されるので、どちらもイテレーターです。

4つとも`BUSH_WALK`クラスに入れます。どれもイテレーターなので、名前はすべて`!`で終わります。

## 1. 標識

`markers!`は、メートル単位の間隔と個数を受け取り、それぞれの標識がスタート地点からどれだけ離れているかを返します。

```sather
loop
   #OUT + BUSH_WALK::markers!(100, 3) + " ";
end;
-- 100 200 300
```

個数が0なら、何も返しません。

## 2. 道が終わるまで

`until_end!`は、道中で見かけたものを受け取り、`"end"`に出会うとそこで止まりながら、1つずつ返します。`"end"`そのものは返しません。

```sather
loop
   #OUT + BUSH_WALK::until_end!(|"gum", "wattle", "end", "banksia"|) + " ";
end;
-- gum wattle
```

`"end"`がなければ、すべて返します。

## 3. 鳥だけ

`birds!`は、見かけたもののうち、大文字で始まるものだけを返します。この調査では、鳥はそうやって書き留めることになっています。

```sather
loop
   #OUT + BUSH_WALK::birds!(|"gum", "Emu", "wattle", "Galah"|) + " ";
end;
-- Emu Galah
```

## 4. 番号付き

`numbered!`は、見かけたものを受け取り、それぞれの先頭に1から数えた位置を付けて返します。

```sather
loop
   #OUT + BUSH_WALK::numbered!(|"gum", "Emu"|) + " ";
end;
-- 1. gum 2. Emu
```
