# 概要

[`switch`文][switch]を使うと、1つの値を複数の候補となる値と比較できます。複数の`else-if`文を使うよりも、簡潔にコードを書くことができます。`switch`文は、`switch`キーワードの後に比較したい値を続けて書きます。次に、`case`キーワードの後に比較対象の値を続けて、それぞれのケースを定義します。どのケースにも一致しないときのデフォルトのケースは、`default`キーワードで定義します。`else-if`文と同じく、`switch`文は、最初に一致したケースに対応するコードのブロックだけを実行します。

```swift
switch value {
case 1:
    print("One")
case 2:
    print("Two")
default:
    print("Other")
}
```

次の例を見てみましょう。

```swift
if str == "apple" {
    print("Let's bake an apple crumble")
} else if str == "lemon" {
    print("Let's bake a lemon meringue pie!")
} else if str == "peach" {
    print("Let's bake a peach pie!")
} else {
    print("Let's buy ice cream.")
}
```

これは、次のように書き換えられます。

```swift
switch str {
case "apple":
    print("Let's bake an apple crumble")
case "lemon":
    print("Let's bake a lemon meringue pie!")
case "peach":
    print("Let's bake a peach pie!")
default:
    print("Let's buy ice cream.")
}
```

[switch]: https://docs.swift.org/swift-book/documentation/the-swift-programming-language/controlflow/#Switch
