# はじめに

Elixirでは、関数は第一級オブジェクトとして扱われます。つまり、次のようなことができます。

- 名前付き関数も無名関数も、変数に代入できます。
- 名前付き関数も無名関数も、データと同じように、引数や戻り値として渡せます。
- 無名関数は動的に作成できます。

無名関数は、名前付き関数とは違い、静的な参照を持っていません。変数に代入するか、その場で呼び出すかしない限り、使うことはできません。

無名関数は、次のような場面で使います。

- レキシカルスコープ（クロージャとも呼ばれます）を使ってデータを隠す。
- 実行時に動的に関数を作成する。

無名関数は予約語`fn`で始まり、引数は`->`というトークンで関数の本体と区切られ、`end`で終わります。名前付き関数と同じように、関数の最後の式は、呼び出し元に_暗黙的に_返されます。

関数の参照を呼び出すには、参照の変数と引数のリストの間に`.`を書く必要があります。

```elixir
function_variable = fn param ->
  param + 1
end

function_variable.(1)
# => 2
```

さらに、省略記法であるキャプチャを使って、もっと簡潔に書くこともできます。

```elixir
variable = &(&1 + 1)

variable.(1)
# => 2
```
