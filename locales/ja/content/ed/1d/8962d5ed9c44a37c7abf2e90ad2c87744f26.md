# 変数について

## 変数

_変数_とは、データを入れておく場所のことです。
Bashが扱うデータには、文字列と配列の2種類があります。
配列については、あとで説明します。

変数への代入は、次のように書きます。

```bash
name="value"
```

~~~~exercism/note
**重要**：イコールの前後に_スペースを入れてはいけません_！

次の例のようにスペースがあると、

```bash
x = 10
```

bashは`x`という**コマンド**を、`=`と`10`という**2つの引数**を付けて呼び出そうとします！
~~~~

変数は_パラメーター_と呼ばれることもあります。
このドキュメントでは、この2つの用語を同じ意味で使います。

bashが使用したり設定したりする重要なパラメーターには、次のようなものがあります。

* `PATH`：外部コマンドを探すときに使う、コロンで区切られたディレクトリの一覧です。
* `IFS`：「内部フィールドセパレーター」です。
   これがどのように使われるかは、あとで見ていきます。
* `PWD`：現在の作業ディレクトリです。
   `pwd`コマンドの出力と同じ値になります。
* `RANDOM`：0から32767までの疑似乱数の整数です。
* `BASH_VERSION`：実行中のbashのバージョン文字列です。

## 変数名

変数名は、_英大文字、英小文字、数字、アンダースコア_で構成されます。
先頭を数字にすることはできません。

~~~~exercism/caution
**すべて大文字の変数名を使うのは避ける**のがよい習慣です。
シェルはこの書き方をパラメーターに使っているので、特別な意味を持つシェルパラメーターを、うっかり上書きしたくはありませんよね。
たとえば、[1][1]、[2][2]、[3][3]です。

## パラメーター展開

パラメーターの値は、`$varname`という構文で取得します。

```bash
x=10
echo "The value of x is $x"
```

変数名が周りのテキストと紛れないようにするには、変数名を波括弧（`{}`）で囲みます。
たとえば、`10x10`という文字列を出力するには、次のようにします。

```bash
echo "${x}x$x"
# or
echo "${x}x${x}"
```

読みやすさや一貫性のために、ほとんどの場面で波括弧を使うことを勧めている[スタイルガイド][google-style-guide]もあります。

## 位置パラメーター

[コマンドと引数][cmds-args]のレッスンで説明したように、コマンドは引数を受け取ることができます。
Bashスクリプトも例外ではありません。
現在実行中のbashに渡される引数は、_位置パラメーター_と呼ばれます。
これらは、次の特別なパラメーターで取り出せます。

* `$1`：1番目の位置パラメーター
* `$2` ... `$9`：それ以降のパラメーター
* `${10}` ...：2桁以上の数字には波括弧が必要です。
* `$0`：現在のスクリプトの名前です。

シェル関数への引数も同じく位置パラメーターで、扱い方もまったく同じです。
関数については、あとのレッスンでさらに詳しく見ていきます。

### 特別な位置パラメーター

位置パラメーターを扱うのに役立つ_特別なパラメーター_がいくつかあります。

* `$#`：位置パラメーターの_数_に展開されます。
* `"$@"`：すべての位置パラメーターを、それぞれ別の単語として並べたリストに展開されます。
* `"$*"`：すべての位置パラメーターを、ある文字でつなげた1つの文字列に展開されます。
  * つなげる文字は、`$IFS`変数の_最初の文字_です。デフォルトではスペースです。

`"$@"`は、位置パラメーターを安全に引用したまま別のコマンドに渡す、もっとも安全な方法です。
位置パラメーターをループで処理するときにも、これを使います。

```bash
for arg in "$@"; do
    do_something_with "$arg"
done
```

実際には、`"$*"`よりも`"$@"`のほうがよく使われます。

## コマンド置換

bashスクリプトでよく行う操作のひとつに、コマンドの出力を受け取って変数に保存する、というものがあります。
これには_コマンド置換_を使います。

```bash
var=$(command)
```

たとえば、文字列を大文字にするには、次のようにします。

```bash
text="Hello world!"
uppercase=$(echo "$text" | tr '[:lower:]' '[:upper:]')
echo "$uppercase"
# => HELLO WORLD!
```

## パラメーター展開をもっと詳しく

Bashには、外部コマンドを呼び出さなくても済むように、変数や文字列を操作する組み込みの機能がたくさん用意されています。

* テキストを大文字にする。
  前のセクションでは、`tr`を使ってテキストを大文字にする方法を紹介しました。
  bashでこれを行うには、次のようにします。

  ```bash
  echo "${text^^}"
  ```

  同じように、`${text,,}`とすると値を小文字にできます。

* 変数が空のときに、デフォルト値を用意する。

  ```bash
  default="nothing here"
  result=""
  echo "${result:-$default}"
  # => nothing here
  ```

* 検索と置換。

  ```bash
  text="Hello world!"
  echo "${text//[aeiou]/X}"
  # => HXllX wXrld!"
  ```

ほかにも興味深いパラメーター展開がたくさんあります。部分文字列の取り出し、文字列の長さの取得、デフォルト値の_代入_、値の先頭や末尾からのテキストの削除など、さまざまです。
詳しくは[マニュアル][param-exp]を読んでください。
