# はじめに

Common Lispのコードはすべて、S式（シンボリック式）でできています。S式は、略してsexprと呼ばれます。sexprは、アトムかコンスのどちらかです。S式は評価されると、自動的に何らかの値を返し、その値が式の代わりになります。`defun`を使って自分で関数を書くときは、`defun`の本体の中で最後の値が自動的に戻り値になります。

```lisp
;; Defining a new function
(defun gimme-foo () 'foo)
;; Calling the function as an S-Expression
(gimme-foo) ; => FOO
```
