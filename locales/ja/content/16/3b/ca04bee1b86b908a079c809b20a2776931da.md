# 説明

こんにちは、エージェント・ダブルヌル0111。

任務を引き受けるかどうかは任せますが、その内容は、UMBRA（本当に最低な手下たちの連合）の本部に潜入し、彼らの最新の、本当にひどい計画の書類を回収するための、2つのツールを書くことです。この任務を遂行するには、2つのツールが必要です。

## 1. 回収した秘密計画をパスワードで保護する

秘密計画を手に入れたら、パスワードを知っている人だけがそれを取り戻せるように、計画を保護する必要があります。

これを行うには、関数`protectSecret(_ secret: String, withPassword password: String) -> (String) -> String`を実装する必要があります。
この関数は、パスワードの候補を文字列として受け取る別の関数を返します。
入力されたパスワードが正しければ、新しい関数は隠された秘密を返しますが、パスワードが正しくない場合、関数は "Sorry. No hidden secrets here." を返します。

```swift
let secretFunction = protectSecret("Steal the world's supply of french fries!", withPassword: "5up3r53cr37")

secretFunction("Open sesame")
// Returns "Sorry. No hidden secrets here."

secretFunction("5up3r53cr37")
// Returns "Steal the world's supply of french fries!"
```

## 2. 金庫を開けるための組み合わせを生成する

UMBRAは、金庫の組み合わせをすべて、自分たちがいる部屋の番号に基づいて決めていることがわかりました。
金庫の組み合わせは、部屋の番号に特殊な関数を繰り返し適用して生成されます。
つまり、組み合わせの1つ目の数値は部屋の番号に関数を適用して得られ、2つ目は1つ目の数値に関数を適用して得られ、3つ目は2つ目の数値に関数を適用して得られます。

ただし、UMBRAは組み合わせの生成に使う関数を定期的に変更するので、ツールは組み合わせを生成するために、部屋の番号と適切な関数の両方を受け取る必要があります。

必要な組み合わせを生成する関数`generateCombination(forRoom room: Int, usingFunction f: (Int) -> Int) -> (Int, Int, Int)`を実装してください。

```swift
func makeCombo(_ x: Int) -> Int {
  (x * 13) % 256
}

generateCombination(forRoom: 227, usingFunction: makeCombo)
// Returns (135, 219, 31)
```
