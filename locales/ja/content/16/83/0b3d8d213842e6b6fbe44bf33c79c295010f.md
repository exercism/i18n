# はじめに

## `switch`文

[`switch`文][switch]は、1つの値を複数の候補パターンと比較します。
複数の`if-else`文を連ねる代わりに、よりすっきりと読みやすく書けます。

`switch`文は`switch`キーワードから始まり、その後にテストする値を書きます。
それぞれの候補は`case`キーワードで示します。
どれにも一致しないときに実行されるフォールバックのケースは、`default`キーワードで定義します。
`if-else`の連鎖と同じように、`switch`文は最初に一致したケースに対応するコードブロックだけを実行します。

```swift
switch value {
case 1:
    print("One")
case 2:
    print("Two")
default:
    print("Other")
}
```

次の`if-else`の連鎖を見てみましょう。

```swift
if str == "apple" {
    print("Let's bake an apple crumble")
} else if str == "lemon" {
    print("Let's bake a lemon meringue pie!")
} else if str == "peach" {
    print("Let's bake a peach pie!")
} else {
    print("Let's buy ice cream.")
}
```

これは、`switch`文を使うとより明確に書けます。

```swift
switch str {
case "apple":
    print("Let's bake an apple crumble")
case "lemon":
    print("Let's bake a lemon meringue pie!")
case "peach":
    print("Let's bake a peach pie!")
default:
    print("Let's buy ice cream.")
}
```

## `while`ループ

[`while`ループ][while-loops]は、ある条件が真である間、コードを実行し続ける制御フローの文です。
Swiftには、`while`ループと`repeat-while`ループの2種類があります。
`while`ループでは、ループ本体を実行する前に条件が評価されます。条件が偽なら、ループ本体は一度も実行されません。
Swiftの`while`ループは、次のような構造になっています。

```swift
while <#condition#> {
  <#code#>
}
```

このループは`count`が0より大きい間実行され、その結果、2、1、"Liftoff!"と出力します。

```swift
var count = 2
while count > 0 {
  print("\(count)…")
  count -= 1
}
print("Liftoff!")

// prints:
// 2…
// 1…
// Liftoff!
```

[`repeat-while`ループ][while-loops]は`while`ループに似ていますが、条件はループ本体を実行した後に評価されます。
つまり、条件が偽であっても、ループ本体は必ず少なくとも1回は実行されます。
Swiftの`repeat-while`ループは、次のような構造になっています。

```swift
repeat {
  <#code#>
} while <#condition#>
```

この例では条件が偽なので、ループは1回だけ実行されます。
`repeat-while`ループなので、条件が評価される前にループ本体が1回実行されます。

```swift
var count = 2
repeat {
  print("\(count)…")
} while count < 0
print("Liftoff!")
```

## 制御転送

Swiftには、ループや`switch`文の実行の流れを変えるための制御転送文が用意されています。
`return`に加えて、`continue`、`break`、ループのラベル、`fallthrough`があります。

### `continue`

`continue`文は、ループに対して、現在の繰り返しの実行を止めてすぐに次の繰り返しを始めるよう指示します。
`while`ループや`repeat-while`ループでは、条件の判定へ直接移ります。
`for-in`ループでは、シーケンスの次の要素へ進みます。

```swift
var count = 1
while count < 6 {
    count += 1
    if count == 4 {
        continue
    }
    print(count)
}

// Prints:
// 2
// 3
// 5
// 6
```

### `break`

`break`文は、ループや`switch`文全体をすぐに終了します。
実行は、ループや`switch`の次にある最初のコード行から再開します。

```swift
for fruit in ["banana", "grapes", "apple", "strawberry", "kiwi", "lemon"] {
    if !fruit.count.isMultiple(of: 2) {
        break
    }
    print(fruit)
}

// Prints:
// banana
// grapes
```

### ラベル付きの文

ループが入れ子になっているとき、`break`や`continue`を、いちばん内側のループではなく外側のループに作用させたいことがあります。
ループには、名前とコロン（`labelName:`）を前に付けてラベルを付けられます。
そうすれば、そのラベルを`break`や`continue`に渡せます。

```swift
outerLoop: for fruit in ["banana", "grapes", "apple", "strawberry", "kiwi", "lemon"] {
    print("\n--- \(fruit) ---")
    for letter in fruit {
        guard letter != "n" else {
            break outerLoop
        }
        print(letter)
    }
}

// Prints:
// --- banana ---
// b
// a
```
