# はじめに

多くのプログラムでは、現実世界の出来事をシミュレーションするために、（一見すると）ランダムな値が必要になります。

よくある身近な例を挙げると、次のようなものがあります。
- コイン投げ：`('Heads', 'Tails')`からランダムに選んだ値。
- サイコロを振る：1から6までのランダムな整数。
- トランプをシャッフルする：カードの配列をランダムな順序に並べ替えたもの。
- 3Dグラフィックスのシミュレーションで木や茂みを生成すること。

コンピューターで_真に_ランダムな値を生成するのは、[驚くほど難しい技術的課題][truly-random]です。そのため、こうした結果は「疑似ランダム」と呼ばれることがあります。

実際には、Python標準ライブラリの[`random`][random]モジュールのようなよく設計されたライブラリは高速で柔軟であり、モデリングやシミュレーション、ゲームのほとんどの用途で十分に使える結果を返します。

この短い紹介では、このモジュールの中でも特によく使われる4つの関数を紹介します。[`random`][random]のドキュメントにはたくさんのツールとオプションがあるので、ぜひ全体を読んでみてください。

`random`モジュールのツールを使うには、まずそれをインポートする必要があります。

```python
>>> import random

# Choose random integer from a range
>>> random.randrange(1000)
360

>>> random.randrange(-1, 500)
228

>>> random.randrange(-10, 11, 2)
-8

# Choose random integer between two values (inclusive)
>>> random.randint(5, 25)
22

```

モジュール名をいちいち入力するのを避けるには、特定の関数を名前でインポートします。

```python
>>> from random import choice, choices

# Using choice() to pick Heads or Tails 10 times
>>> tosses = []
... for side in range(10):
...    tosses.append(choice(['H', 'T']))    

>>> print(tosses)
['H', 'H', 'H', 'H', 'H', 'H', 'H', 'T', 'T', 'H']


# Using choices() to pick Heads or Tails 8 times
>>> picks = []
... picks.extend(choices(['H', 'T'], k=8))
... print(picks)
['T', 'H', 'H', 'T', 'H', 'H', 'T', 'T']
```



## `randrange()`と`randint()`

上の最初の例で示したように、`randrange()`関数には3つの形式があります。

1. `randrange(stop)`は、`0 <= n < stop`となる整数`n`を返します。
2. `randrange(start, stop)`は、`start <= n < stop`となる整数`n`を返します。
3. `randrange(start, stop, step)`は、`start <= n < stop`となり、かつ`n`が`start, start + step, start + 2*step...`という数列に含まれる整数`n`を返します。

最もよくある`step == 1`の場合には、`randint(a, b)`のほうが便利で読みやすいこともあります。`randint()`の結果には上限の値も_含まれる_ので、`randint(a, b)`は`randrange(a, b+1)`を使うのと同じです。



## `choice()`と`choices()`

これら2つの関数は、何らかの[シーケンス][sequence-types]やその他のコンテナを出発点とすることを前提としています。通常は`list`ですが、いくつかの制限付きで`tuple`や`set`も使えます（`tuple`はイミュータブルで、`set`は順序を持ちません）。

`choice()`関数は、与えられたシーケンスからランダムに選んだ1つの要素を返し、`choices()`は、与えられたシーケンスからランダムに選んだ指定個数（`k`）の要素を返します。上の例では、表と裏が同じ確率で出る公平なコインを前提にしましたが、重みを指定することもできます。

たとえば、袋の中に赤いボールが10個と緑のボールが15個入っていて、そこからランダムに1つ取り出したいとします。


```python
>>> random.choices(['red', 'green'], [10, 15])
['red']
```
