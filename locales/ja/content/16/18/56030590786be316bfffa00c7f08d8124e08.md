# 説明の補足

## ワード

`disposable`（`destructors`にあるもの）を拡張し、元になるストリームと、`bytes`と`ops`という整数のカウンターを保持するラッパータプルを2つ定義します。

- `metered-input < disposable`（スロットは`stream`、`bytes`、`ops`）
- `metered-output < disposable`（スロットは`stream`、`bytes`、`ops`）

ラッパーがデストラクターのフレームワークに登録されるように、それぞれを`new`ではなく`new-disposable`で作成します。

- `<metered-input> ( stream -- m )`は、入力ストリームをラップします。
- `<metered-output> ( stream -- m )`は、出力ストリームをラップします。

それぞれのタプルを、対応するストリームミックスインのインスタンスとして宣言します。

```
INSTANCE: metered-input  input-stream
INSTANCE: metered-output output-stream
```

次に、カウンターを更新しながら、元になるストリームに処理を委譲する`M:`メソッドを用意します。

- `metered-input`の場合：[`stream-read1`][stream-read1]、[`stream-read-unsafe`][stream-read-unsafe]、[`stream-element-type`][stream-element-type]（委譲）、[`dispose*`][dispose*]。
- `metered-output`の場合：[`stream-write1`][stream-write1]、[`stream-write`][stream-write]、[`stream-flush`][stream-flush]（委譲）、[`dispose*`][dispose*]。

読み取りや書き込みが成功するたびに、転送されたバイト数を`bytes>>`に加算し、`ops>>`を1つ増やします。ファイルの終わりに達した読み取りも1回の操作として数えますが、転送されるバイト数は0です。`dispose*`は、元になるストリームにそのまま渡すようにします。
