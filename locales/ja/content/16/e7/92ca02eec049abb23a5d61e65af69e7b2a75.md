# はじめに

Gleamの標準ライブラリにある`gleam/order`モジュールには、値を比較するために使う`Order`型が含まれています。

`Order`の定義は次のとおりです。

```gleam
pub type Order {
  Gt
  Eq
  Lt
}
```

この型には3つのバリアントがあり、それぞれがある値と別の値との関係を表すために使われます。

- `Gt` - 値がもう一方の値より_大きい_ことを表します。
- `Eq` - 値がもう一方の値と_等しい_ことを表します。
- `Lt` - 値がもう一方の値より_小さい_ことを表します。

データ型を大きさで比較できる場合、そのモジュールが`Order`の値を返す`compare`関数を定義するのが一般的です。たとえば、`gleam/float`と`gleam/int`は、それぞれ小数と整数を対象とした`compare`関数を定義しています。

```gleam
int.compare(1, 2)
// -> Lt

int.compare(2, 2)
// -> Eq

float.compare(1.0, 2.0)
// -> Lt
```

`list.sort`のような並べ替え関数は、`Order`の値を返す関数を引数として受け取るのが一般的です。これにより、呼び出し側が配列をどのように並べ替えるかを決められます。

```gleam
list.sort([3, 7, 3, 1], by: int.compare)
// -> [1, 3, 3, 7]
```
