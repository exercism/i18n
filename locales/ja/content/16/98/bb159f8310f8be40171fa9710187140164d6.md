# 説明

友人のJohannesは、DIY（自分で作ること）のハードウェアが大好きです。
Johannesはちょうどジューサーメーカーを作り終えたところで、とてもわくわくしています。
Johannesの目標は、毎朝新鮮なジュースを作れるようになることです。

Johannesのジューサーメーカーには、たくさんのすてきな機能が備わっています。
たとえば、カップにどれだけジュースが入っているかを教えてくれる、組み込みの計量システムです。
マシンがどのくらい動いているかを教えてくれるタイマーもあります。

Johannesはプログラミングが得意というわけではありませんが、このマシンを制御するプログラムを作りたいと思っています。
そこで、手伝ってほしいと頼んできました。

## 1. デバッグライト

マシンにはデバッグライトが付いています。仕組みは単純で、マシンに電力が供給されていればデバッグライトが点灯します。
プログラムは、デバッグライトが点灯しているときだけ実行されます。

このメソッドは、`JuiceMaker`という名前のクラスメソッドにします。

`true`を返すクラスメソッド`JuiceMaker.debug_light_on?`を定義します。

```crystal
JuiceMaker.debug_light_on?
#=> true
```

## 2. マシンを初期化する

マシンの電源が入ると、`JuiceMaker`というクラスのインスタンスが生成されるようにします。
マシンには、初期化された状態を持たせることにします。
この初期状態には、次の情報を保持させます。

1. マシンが動作中かどうか。電源を入れたときは、常に`false`になります。
2. カップに入っているジュースの量。これは、カップの中のジュースの量を測るセンサーになります。

カップに入っているジュースの量を引数に取る初期化処理を定義し、初期状態を組み立てます。
この初期状態には、`false`に設定されたインスタンス変数`@running`と、クラスの初期化時に渡された引数に基づくインスタンス変数`@fluid`を持たせます。

```crystal
JuiceMaker.new(5)
#=> #<JuiceMaker:0x10f0b8 @running=false, @fluid=5>
```

## 3. マシンの電源を入れる

マシンは電源を入れたり切ったりできます。
マシンの電源を入れるメソッドを定義する必要があります。
マシンの電源を入れると、動作状態は`true`に設定されます。

マシンの電源を入れるメソッド`JuiceMaker#start`を定義します。

```crystal
juice_maker = JuiceMaker.new(5)
juice_maker.start

juice_maker
#=> #<JuiceMaker:0x10f0b8 @running=true, @fluid=5>
```

## 4. マシンの状態

マシンは、自分の状態を教えてくれる必要があります。
マシンが動作中なら`true`を、動作していなければ`false`を返します。

マシンの状態を返すメソッド`JuiceMaker#running?`を定義します。

```crystal
juice_maker = JuiceMaker.new(5)
juice_maker.start

juice_maker.running?
#=> true
```

## 5. ジュースを追加する

マシンはカップにジュースを追加できます。
追加されたジュースの量は、マシンが把握できます。
ジュースを追加したあとにカップへ入っているジュースの量を知るには、マシンに手助けが必要です。

追加するジュースの量を引数に取り、カップの中のジュースの量を更新するメソッド`JuiceMaker#add_fluid`を定義します。

```crystal
juice_maker = JuiceMaker.new(5)
juice_maker.add_fluid(5)

juice_maker
#=> #<JuiceMaker:0x10f0b8 @running=false, @fluid=10>
```

## 6. マシンの電源を切る

マシンは電源を入れたり切ったりできます。
マシンの電源を切るメソッドを定義する必要があります。
このメソッドは、マシンが動作しているときだけ呼び出されます。
マシンの電源を切ると、動作状態は`false`に設定されます。
また、電源を切ったあとにカップへ入っているジュースの量を求めるのにも、マシンには手助けが必要です。
マシンは1分あたり5単位のジュースを消費します。

マシンが動作していた分数を引数に取り、電源を切ったあとのカップの中のジュースの量を返すメソッド`JuiceMaker#stop`を定義します。

```crystal
juice_maker = JuiceMaker.new(5)

juice_maker.start
juice_maker
#=> <JuiceMaker:0x10f0b8 @running=true, @fluid=5>

juice_maker.stop(1)
#=> #<JuiceMaker:0x10f0b8 @running=false, @fluid=0>
```
