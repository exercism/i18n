# Exercismの24 Pull Requests - Ruby版！

このプロジェクトでは、コントリビューターを歓迎しています。

イシューリストでは、次のラベルを探してみてください。

* first-timers only
* good first patch
* bug
* enhancement

それとも、何か貢献できそうなものを見つけましたか？　ドキュメントが今ひとつ物足りない？　何か足りないものはありませんか？　Exercismで演習を提出したりレビューしたりしていて、気に入らないところに気づいたことはありませんか？　ぜひプルリクエストを作成しましょう！

[トラックへの参加](https://github.com/exercism/docs/blob/master/contributing-to-language-tracks/README.md#getting-involved-in-an-exercism-language-track)に関するドキュメントと、実装が求められている演習についての[アイデア](http://exercism.io/languages/ruby/todo)をチェックしてみてください。

ご質問は、フォーラムの[building-exercism]でお答えします。
