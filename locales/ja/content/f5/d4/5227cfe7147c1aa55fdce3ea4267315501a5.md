# テスト

各演習にはテストファイルがあります。
テストは`bats`プログラムで実行します。

```bash
bats test-hello-world.bats
```

`bats`はインストールしておく必要があります。お使いのシステムに`bats`をインストールする方法は、[Bashトラックのテスト][bash]のページをご覧ください。

### batsはbashで実装されています

batsファイルはbashスクリプトで、`bats`コマンドが認識する特別な関数がいくつか含まれています。次のようなテストが出てきます。

```sh
jq -f some-exercise.jq <<< "{some,json,here}"
```

この`<<<`という構文は、bashの[ヒアストリング][here-string]です。右側の文字列を、左側のプログラムの標準入力に送り込みます。これは、次のコードと（[ほぼ][so]）同じです。

```sh
echo "{some,json,here}" | jq -f some-exercise.jq
```

## assert関数のヘルプ

テストでは、[bats-assert][bats-assert]ライブラリの関数を使います。さまざまな`assert*`関数のヘルプはそこにあります。

## スキップされるテスト

演習を解くというのは、その演習のテストをすべて通すことです。デフォルトでは、テストを実行したときに最初のテストだけが実行されます。これは意図的なもので、まずはその1つのテストを通すことに集中できます。それが通ったら、他のテストの先頭に付いている

    [[ $BATS_RUN_SKIPPED == true ]] || skip

という注釈をコメントアウトするか削除すれば、次のテストを有効にできます。

## スキップを上書きする

`skip`注釈が付いたテストも含めてすべてのテストを実行するには、次のようにします。

```bash
BATS_RUN_SKIPPED=true bats test-some-exercise.bats
```

入力を省くためにラッパー関数を使うと便利です。`bash`では次のように書けます。

```bash
bats() {
    BATS_RUN_SKIPPED=true command bats *.bats
}
```

そうすれば、テストは次のコマンドだけで実行できます。

```bash
bats
```

## `jq`でのデバッグ

`jq`には便利な[`debug`][debug]フィルターが付属しています。演習の解答を書いているときにこれを使うと、その時点でjqのパイプラインにあるデータを調べられます。詳しくは[デバッグのドキュメント][debugging]をご覧ください。
