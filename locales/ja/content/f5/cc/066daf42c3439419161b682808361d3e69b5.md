# コードを書く

コードは`<exercise_name>.zig`に書きます。
演習によっては、[定数][constants]、[関数][functions]、[インポート][imports]、[構造体][structs]、そして[ほかにもたくさんの構文][et-cetera]に対するシグネチャがあらかじめ書かれた状態で用意されています！

これらのシグネチャは、明確な出発点を示してくれるので、演習を最後まで進める助けになります。
ただし、これらのシグネチャから書き始める必要はありません。
テストに通るコードであれば、どのように書いたものでもまったく問題のない解答です。

## テストを実行する

テストを実行するには、次のコマンドを実行するだけです。

```bash
zig test test_exercise_name.zig
```

`exercise_name`の部分は、演習の名前に置き換えてください。
上のコマンドは、演習のルートディレクトリで実行する必要があります。テストファイルも同じ場所にあるはずだからです。
さらに、どの演習でも、すべてのテストはデフォルトで有効になっており、スキップできるテストは1つもありません。

すべてのテストにこの条件があるため、テストを1つずつ順番に見ていきたい場合は、通らないテストを[コメントアウト][comments]する必要があります。
テストのコメントアウトは、各行の先頭に`//`を付けるだけです。
一方、自分の解答がテストに通ると確信できたら、それらのテストのコメントアウトを解除して、通るかどうかを確かめられます。
