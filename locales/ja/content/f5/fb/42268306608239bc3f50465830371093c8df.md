# はじめに

## 再帰

何かがそれ自身を使って定義されることを、再帰と呼びます。Gleamでは、再帰は再帰関数で最もよく見られます。再帰関数とは、自分自身を呼び出す関数のことです。

再帰関数には、少なくとも1つの_ベースケース_と、少なくとも1つの_再帰ケース_が必要です。_ベースケース_は、関数を再び呼び出すことなく値を返します。_再帰ケース_は、入力を変更しながら関数を再び呼び出します。こうすることで、いずれはベースケースに一致します。

```gleam
pub fn factorial(x: Int) -> Int {
  case x {
    // Base case
    1 -> 1

    // Recursive case
    _ -> x * factorial(x - 1)
  }
}
```

Gleamにはループのための特別な構文がないため、繰り返しはすべて再帰で行います。

```gleam
pub fn list_length(list: List(String)) -> Int {
  case list {
    [] -> 0
    [_, ..rest] -> 1 + list_length(rest)
  }
}
```

Gleamは再帰的なカスタム型もサポートしています。再帰的なカスタム型では、1つ以上のバリアントが、内包するデータの中で自分自身を参照します。

```gleam
pub type RussianDoll {
  Child               // Base case
  Mother(RussianDoll) // Recursive case
}
```
```gleam
let very_big_doll = Mother(Mother(Mother(Child)))
let small_doll = Mother(Child)
```
