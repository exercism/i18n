# 説明

この演習では、エンジニアが識別子の名前を整えるのを助けるユーティリティ関数の一部を実装します。

5つのタスクを通して、`clean`関数を少しずつ組み立てていきます。
有効な識別子は、0個以上の英字とアンダースコアで構成されます。

`clean`関数に空の文字列を渡した場合は、空の文字列が返されます。

## 1. スペースをアンダースコアに置き換える

スペースをアンダースコアに置き換える`clean1`関数を実装します。先頭と末尾のスペースも対象です。

```elm
clean1 "my   Id"
    --> "my___Id"
```

## 2. 制御文字を大文字の文字列"[CTRL]"に置き換える

`clean2`を実装して、前の関数と同じ処理に加えて、一般的な制御文字（\n、\t、\r）を文字列`"[CTRL]"`に置き換えます。

```elm
clean2 "my\nId"
    --> "my[CTRL]Id",
```

## 3. ケバブケースをキャメルケースに変換する

`clean3`を実装して、前の関数と同じ処理に加えて、ケバブケースをキャメルケースに変換します。

```elm
clean3 "à-ḃç"
    --> "àḂç"
```

## 4. 数字を除く

`clean4`を実装して、前の関数と同じ処理に加えて、すべての数字を除きます。

```elm
clean4 "123"
    --> ""
```

## 5. ギリシャ文字の小文字を除く

最後に、`clean`を実装して、前の関数と同じ処理に加えて、'α'から'ω'の範囲のギリシャ文字を除きます。

```elm
clean "My Οβιεγτ Finder"
    --> "My_Ο_Finder"
```
