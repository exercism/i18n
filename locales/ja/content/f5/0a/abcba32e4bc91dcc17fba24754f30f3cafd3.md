# 説明の補足

## グリッドの形式

グリッドはヌル終端された文字列として表され、各行の末尾には改行文字が入ります。

## レジスタ

| Register | Usage        | Type    | Description                                                               |
| -------- | ------------ | ------- | ------------------------------------------------------------------------- |
| `$a0`    | 入力         | アドレス | ヌル終端された入力文字列                                                  |
| `$a1`    | 入出力       | アドレス | ヌル終端された結果文字列。グリッドの次元が無効な場合は空                  |
| `$v0`    | 出力         | 整数     | グリッドの状態（`0` = `ok`、`-1` = `invalid columns`、`-2` = `invalid rows`） |
| `$t0-9`  | 一時         | 任意     | 一時的な保存用                                                            |
