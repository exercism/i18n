# 説明

2つの異なる内部テーブルのデータを1つの結果の内部テーブルにまとめる方法を学びましょう。

クラスには、まったく異なる2つのデータセット、ALPHASとNUMSを含む2つの内部テーブルが渡されます。

```abap
TYPES: BEGIN OF alphatab_type,
         cola TYPE string,
         colb TYPE string,
         colc TYPE string,
       END OF alphatab_type.
TYPES: alphas TYPE STANDARD TABLE OF alphatab_type.
TYPES: BEGIN OF numtab_type,
         col1 TYPE string,
         col2 TYPE string,
         col3 TYPE string,
       END OF numtab_type.
TYPES: nums TYPE STANDARD TABLE OF numtab_type.
```

ALPHAテーブルのデータは次のとおりです。

| COLA | COLB | COLC |
| --- | --- | --- |
| A | B | C | 
| D | E | F |
| G | H | I |

NUMSテーブルのデータは次のとおりです。

| COL1 | COL2 | COL3 |
| --- | --- | --- |
| 1 | 2 | 3 | 
| 4 | 5 | 6 |
| 7 | 8 | 9 |

この演習のタスクは、内部テーブルALPHASと内部テーブルNUMSの各セルの値を組み合わせたレコードを持つ内部テーブルを返すことです。たとえば、COMBINED_DATA内部テーブルの1行目の1列目の値は"A1"になります。

返されるテーブルは次のように定義されています。

```abap
TYPES: BEGIN OF combined_data_type,
         colx TYPE string,
         coly TYPE string,
         colz TYPE string,
       END OF combined_data_type.
TYPES: combined_data TYPE STANDARD TABLE OF combined_data_type WITH EMPTY KEY.
```
