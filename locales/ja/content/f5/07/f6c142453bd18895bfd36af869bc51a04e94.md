# 概要

*ヒープ*は、常に最小（または最大）の要素を把握していて、それをすばやく取り出せるコレクションです。*優先度付きキュー*を実装するときの自然な選択肢です。ヒープは[`heaps`][heaps]ボキャブラリに入っています。

`<min-heap>`は、最小のキーから先に出てくる空のヒープを作ります。`<max-heap>`は、最大のものを先に返します。それぞれの要素は*キー*に紐づけて保存される*値*で、このキーがFactorの並び順を決める優先度になります。

```
<min-heap> ( -- min-heap )
<max-heap> ( -- max-heap )
heap-push  ( value key heap -- )
heap-push-all ( assoc heap -- )
```

```factor
USING: heaps ;

<min-heap>
"alice" 5 pick heap-push
"bob"   2 pick heap-push
```

ヒープは*可変*です。`heap-push`と`heap-pop`はヒープをその場で書き換えます。

```
heap-peek    ( heap -- value key )
heap-pop     ( heap -- value key )
heap-pop-all ( heap -- alist )
heap-empty?  ( heap -- ? )
heap-size    ( heap -- n )
```

`heap-peek`は先頭を読み取るだけで、取り出しはしません。`heap-pop`は取り出して返します。`heap-pop-all`はヒープを空にして、優先度順の`{ key value }`ペアの連想リストにします。

```factor
USING: assocs heaps kernel prettyprint ;

<min-heap>
"alice" 5 pick heap-push
"bob"   2 pick heap-push
"carol" 9 pick heap-push
dup heap-pop .           ! => 2 "bob"   (removed; value then key)
heap-pop-all values .    ! => { "alice" "carol" }
```

プッシュは`O(log n)`、先頭の読み取りは`O(1)`なので、「最も優先度の高い要素を取り出して、さらに追加する」を繰り返しても、キューが大きくても高速なままです。実装は、可変長配列に格納された二分ヒープです。キーには、順序を比べられる値なら何でも使えます（数値、文字列など）。

[heaps]: https://docs.factorcode.org/content/vocab-heaps.html
