# 説明

この演習では、[三目並べ][tic-tac-toe]ゲームの状態を判定するプログラムを実装します。
（このゲームは「noughts and crosses」や「Xs and Os」とも呼ばれます。）

ゲームは3×3のマス目で行われます。
プレイヤーは交互に、マス目に`X`と`O`を置いていきます。
ゲームは、どちらかのプレイヤーが同じマークを縦・横・斜めのいずれかに3つ並べて勝利するか、マス目がすべて埋まったときに終了します。

この演習では、`X`が先手だと仮定します。

与えられたゲームがどの状態にあるのかを判定するのが、今回の課題です。

ゲームの状態は3つあります。

- ゲームが**ongoing**です。
- ゲームが**draw**で終了しました。
- ゲームが**win**で終了しました。

与えられた盤面が無効な場合は、適切なエラーを投げてください。

盤面が次の条件を満たす場合、それは無効です。

- 正しい順番で手番を進めても、与えられた盤面に到達できない（`X`が先手であることを思い出してください）。
- ゲームがすでに終了したあとにも続けられた。

## 例

### 進行中のゲーム

```text
   |   |
 X |   |
___|___|___
   |   |
   | X | O
___|___|___
   |   |
 O | X |
   |   |
```

### 引き分け

```text
   |   |
 X | O | X
___|___|___
   |   |
 X | X | O
___|___|___
   |   |
 O | X | O
   |   |
```

### 勝利

```text
   |   |
 X | X | X
___|___|___
   |   |
   | O | O
___|___|___
   |   |
   |   |
   |   |
```

### 無効

#### 手番の順序が間違っている

```text
   |   |
 O | O | X
___|___|___
   |   |
   |   |
___|___|___
   |   |
   |   |
   |   |
```

#### 勝利後もプレイを続けた

```text
   |   |
 X | X | X
___|___|___
   |   |
 O | O | O
___|___|___
   |   |
   |   |
   |   |
```

[tic-tac-toe]: https://en.wikipedia.org/wiki/Tic-tac-toe
