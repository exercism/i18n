# はじめに

C#の`string`は、Unicode文字（文字、数字、句読点など）の並びとして、不変のテキストを表すオブジェクトです。`string`のインスタンスを定義するには、二重引用符を使います。

```csharp
string fruit = "Apple";
```

文字列は、その文字列のメソッドを呼び出すことで操作します。一度文字列が作られると、その値を変えることはできません。文字列を変更しているように見えるメソッドも、実際には新しい文字列を返します。

複数の文字列は連結（追加）できます。最も簡単な方法は、`+`演算子を使うことです。

```csharp
string name = "Jane";
"Hello " + name + "!";
// => "Hello Jane!"
```

単純な連結よりも複雑な文字列の書式設定には、文字列補間が好まれます。文字列で補間を使うには、先頭にドル記号（`$`）を付けます。すると、波括弧（`{}`）を使って文字列内の変数にアクセスできます。

```csharp
string name = "Jane";
$"Hello {name}!";
// => "Hello Jane!"
```
