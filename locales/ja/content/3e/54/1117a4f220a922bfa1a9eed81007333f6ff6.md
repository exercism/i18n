# テスト

CLIツールで演習をダウンロードすると、演習名の付いたUiuaファイルと`tests.ua`ファイルがあるはずです。
このファイルにはすべてのテストケースが入っていて、解答をアップロードしたときにテストランナーが実行するものと同じ内容です。
試してみたい場合は、テストケースを自由に追加してかまいません。
ただし、テストを書き換えても、オンラインでのテスト実行には影響しません。

## ローカルでのテスト

演習のテストを実行するには、演習のディレクトリでターミナルを開き、`uiua test tests.ua`コマンドを実行します。

たとえば、手を加えていない`hello-world`演習の出力は次のようになります。

```bash
$ uiua test tests.ua
Error: Goodbye, Mars!
  at tests.ua:3:1
3 | ⍤⤙≍ "Hello, World!" Hello
    ─
Test failed
```

`Error`の行には、書いたコードが実際に出力した内容が表示されます。
行番号は、`tests.ua`内で期待される結果がある位置を示しています。
正しい解答では、次のように表示されます。

```bash
$ uiua test tests.ua
Test passed
```
