# 説明

この演習では、美容サロンの予約スケジューラーに取り組みます。

タスクは3つあり、いずれも予約の日時を扱います。

## 1. 予約の時間が過ぎていないかを確認する

`appointment_has_passed`サブルーチンを実装しましょう。このサブルーチンは日付の文字列を受け取り、その予約が過去のものかどうかを確認します。

```perl
appointment_has_passed("2019-07-25T13:45:00")
// => true
```

日付の文字列は、`YYYY-mm-ddTHH:MM:SS`というISO 8601の日時形式で渡されます。

非公開の`_parse_datetime`サブルーチンを実装する必要があります。
モジュールをいくつか挙げておきます。

- [Time::Piece][time-piece]はPerlのコアモジュールです。
- [DateTime::Tiny][datetime-tiny]はCPANから入手できます。

## 2. 予約が午後にあるかどうかを確認する

`is_afternoon_appointment`関数を実装しましょう。この関数は日付の文字列を受け取り、その予約が午後（12:00以降、18:00より前）かどうかを確認します。

```perl
is_afternoon_appointment("2019-07-25T13:45:00")
// => true
```

## 3. 予約の日時を説明する

`describe_appointment`関数を実装しましょう。この関数は日付の文字列を受け取り、その日時の説明を返します。

```perl
describe_appointment("2019-07-25T13:45:00")
// => "You have an appointment on 07/25/2019 1:45 PM"
```

時の部分は0〜12の範囲で、先頭にゼロや空白が付かないことに注意してください。

[time-piece]: https://perldoc.perl.org/Time::Piece
[datetime-tiny]: https://metacpan.org/pod/DateTime::Tiny
