# はじめに

**ワード**は、Factorが関数に付けた呼び名です。`basics`で学んだデータスタックを土台に、このコンセプトでは自分のワードを定義していきます。計算をする、固定の値に名前を付ける、そしてワードを他のワードから組み立てる、という内容です。

定義は`:`で始まり、スタック効果を書いて、次に本体、最後に`;`で終わります。コンパイラーは、本体が宣言したスタック効果と一致しているかどうかを検査します。

```factor
: square ( x -- x*x ) dup * ;

4 square .    ! => 16
```

整数演算のワード`+`、`-`、`*`は、それぞれ数値を2つ取り出して、その結果を積みます。これらは`math`ボキャブラリに属しているので、使うファイルでは`USING:`の行に`math`を書く必要があります。スタックの一番上にあるのが、右側のオペランドです。

```factor
2 3 + .    ! => 5
8 3 - .    ! => 5    (8 - 3, not 3 - 8)
2 3 * .    ! => 6
```

`CONSTANT:`は、固定の値に名前を付けます。定数もそれ自体がワードで、呼び出すとその値が積まれます。

```factor
CONSTANT: pi 3

pi pi * .    ! => 9
```

ワードの本体からは、スコープにあるワードならどれでも呼び出せます。同じファイルの前の方で定義したワードも含みます。

```factor
: double    ( x -- 2x ) 2 * ;
: quadruple ( x -- 4x ) double double ;

5 quadruple .    ! => 20
```

出力の末尾に付く`?`は「真偽値」を表す慣習です。ワードも定数も`lowercase-kebab-case`を使います。
