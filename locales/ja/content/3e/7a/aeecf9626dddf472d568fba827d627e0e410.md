# 指示の補足

## レジスタ

| レジスタ | 用途 | 型 | 説明 |
| -------- | --------- | ------- | ---------------------------------------------------------------------------------- |
| `$a0`    | 入力     | 整数 | 辺a                                                                             |
| `$a1`    | 入力     | 整数 | 辺b                                                                             |
| `$a2`    | 入力     | 整数 | 辺c                                                                             |
| `$v0`    | 出力     | 整数 | 三角形の種類（`0`=不等辺三角形、`1`=二等辺三角形、`2`=正三角形、`3`=無効） |
| `$t0-9`  | 一時 | 任意     | 一時的な保存用                                                         |
