# 配列入門

Bashには2種類のパラメーターがあります。スカラーの値と配列です。
スカラーの値は文字列か数値で、1つの「もの」を表します。

ほとんどの場合、データを保持するにはスカラーの値で十分です。
しかし、複数のスカラーの値をまとめて保存したいこともあります。
そんなときは_配列_を使います。

配列には2種類あります。

* 数値インデックス配列は、整数のキーを文字列の値に対応付けます。
  （他の言語では「リスト」や「シーケンス」と呼ばれることもあります。）
* 連想配列は、文字列のキーを文字列の値に対応付けます。
  （他の言語では「マップ」や「辞書」と呼ばれることもあります。）

このドキュメントの最初のいくつかの節では、数値インデックス配列（以下、単に「配列」と呼びます）を扱います。
連想配列の詳細は最後に登場します。

~~~~exercism/caution
Bashの配列は、スカラーの値_しか_保存できません。
二次元配列（配列の配列）を作ることはできません。
~~~~

## 配列変数の宣言と初期化

変数に、括弧で囲んだ要素の配列（空でもかまいません）を代入すると、配列を初期化できます。

```bash
myarray=("one" "two" "three")
```

どの変数の代入でもそうですが、イコールの前後にスペースを入れてはいけません。

要素の間にカンマの区切りはありません。空白で区切られた文字列の配列です。

実際、括弧の中の空白の量はまったく自由です。
改行も使えるので、読みやすくするために好きなだけ使ってください。

```bash
myarray=(
    "first element"
    "second element"
    "this is the last element"
)
```

このようにして文字列の配列を配列変数に代入すると、最初の文字列はインデックス0に、次の文字列はインデックス1に、その次はインデックス2に、というように保存されます。

必要なインデックスを指定すれば、「疎な配列」を初期化することもできます。

```bash
raindrops=([3]="Pling" [5]="Plang [7]="Plong")
```

~~~~exercism/note
繰り返しますが、配列のインデックスは0から始まります。
このスニペットは「true」を出力します：

```bash
myarray=("one" "two" "three")
[[ "${myarray[0]}" == "one" ]] && echo true || echo false
```
~~~~

`declare`コマンド（関数の中では`local`）を使うと、その変数が配列を保持することを指定できます。

```bash
declare -a myarray
```

変数を初期化するには、括弧で囲んだ配列（空でもかまいません）をそのまま代入するほうが一般的です。

## 配列の要素へのアクセス

上の注記で見たとおり、配列の要素にアクセスする構文は`${myarray[$index]}`です。
インデックスは角括弧で指定します。
波括弧は必須です。

~~~~exercism/note
数値インデックス配列では、インデックスは算術式です。
Bashのマニュアルには次のように[書かれています][arithmetic]：

> 算術式の中では、シェル変数はパラメーター展開の構文を使わずに、名前で参照することもできます。

つまり、単純な変数展開では`$`は必要ありません。
次のように要素にアクセスでき、こちらのほうが少し読みやすくなります：

```bash
i=5
echo "${myarray[i]}"
# ..............^
```

[arithmetic]: https://www.gnu.org/software/bash/manual/bash.html#Shell-Arithmetic
~~~~

指定したインデックスが配列に存在しない場合、展開の結果は空の文字列になります。

## 配列への代入

特定の配列の要素に代入するには、次の構文を使います：

```bash
myarray[10]="hello"
```

配列に要素を_追加_するには、連結代入演算子`+=`を使い、括弧を使います：

```bash
myarray+=("new element 1" "new element 2")
```

## 配列の繰り返し処理

通常は、配列の_値_を繰り返し処理する必要があります。
[ループ][looping]のコンセプトで見た`for`ループを使います：

```bash
myarray=("one" "two" "three")
for value in "${myarray[@]}"; do
    echo "$value"
done
```

配列を展開する特別な構文`"${myarray[@]}"`に注目してください。
このパラメーター展開の形式は、配列の値を別々の単語として置き換えます。
これは、次のものとだいたい同じです：

```bash
for value in "${myarray[0]}" "${myarray[1]}" ... "${myarray[n]}"
```

`"${myarray[@]}"`の形式は疎な配列でも機能し、定義されている値だけに展開されます。

インデックスがアンパサンド（`@`）であるこの特別な展開は、二重引用符の中でのみ特別な意味を持ちます。

#### その他の特別なパラメーター展開

配列を繰り返し処理するために必要な、もういくつかの特別な構文を紹介します。
これらはマニュアルの[シェルパラメーター展開][man-expn]で説明されています。

配列の_長さ_を調べるには、名前の前に`#`を付けて`${#myarray[@]}`と書きます。
配列の「長さ」とは、その中にある要素の数のことです。

配列の_インデックス_の配列を取り出すには、名前の前に`!`を付け、展開を二重引用符で囲んで`"${!myarray[@]}"`と書きます。
数値インデックス配列では、インデックスは数値の順に展開されます。

### 配列のインデックスを繰り返し処理する

値だけでなくインデックスも必要なことがあります。
これにはいくつかの方法があります。

1. インデックスが途切れずに連続しているとわかっている場合は、_算術_の`for`ループを使えます。

   ```bash
   for ((i = 0; i < ${#myarray[@]}; i++)); do
       echo "$i -> ${myarray[i]}"
   done
   ```

   `#`が配列名の前に付いた`${#myarray[@]}`という構文に注目してください。
   配列のインデックスは0から始まるので、配列の最後のインデックスは配列の長さより1だけ小さくなります。

2. 配列が疎な場合は、次の形式を使えます：

   ```bash
   for index in "${!raindrops[@]}"; do
       echo "$index -> ${raindrops[index]}"
   done
   ```

   `!`が配列名の前に付いた`${!myarray[@]}`という構文に注目してください。

## 配列の中身を調べる

配列の中身を見たいときは、`declare`コマンドに`-p`オプションを付けて使います：

```bash
a=("the 'first' element"
   second
   third
   'the "last" element')
declare -p a
```

これは、シェルの標準的なクォート形式で中身を出力します。

```bash
declare -a a=([0]="the 'first' element" [1]="second" [2]="third" [3]="the \"last\" element")
```

## 連想配列

繰り返しますが、連想配列はインデックスに数値ではなく文字列を使います。
ここまでに書いたことはすべて連想配列にも当てはまりますが、少し違いがあります。
一般に、連想配列では「インデックス」ではなく「キー」という用語を使います。連想配列はキーを値に対応付けます。

### 連想配列の宣言

配列とは異なり、連想配列は**必ず**宣言する必要があります。
`declare`に`-A`オプションを付けます（関数の中では`local`）：

```bash
declare -A mymap

myfunc() {
    local -A my_local_map
    # ...
}
```

### 連想配列の初期化

キーと値のペアは、括弧で囲んだ配列の中で指定します：

```bash
mymap=([first]=foo [second]=bar [third]=baz)
declare -p mymap
```

これは次のように出力します：

```
declare -A mymap=([second]="bar" [first]="foo" [third]="baz")
```

~~~~exercism/note
連想配列には**順序がない**ことに注意してください。
~~~~

宣言と初期化は1行で行えます。

```bash
declare -A mymap=([first]=foo [second]=bar [third]=baz)
```

最近のBashでは、初期化に`(key value key value ...)`という形の配列を使えます。

```bash
declare -A mymap=(first foo second bar third baz)
```

### 値へのアクセス

要素にアクセスするには、これまでと同じ構文`${mymap[$key]}`を使います。

連想配列のキーは算術の文脈では評価されません。
通常のパラメーター展開の構文が必要です。

### 連想配列への代入

代入もこれまでと同じ構文を使います：

```bash
mymap[$key]="$value"
```

### 繰り返し処理

繰り返し処理には`for value in "${mymap[@]}"`ループを使えます。
ただし、通常は値と一緒にキーも必要になります。

上で見た`"${!mymap[@]}"`の構文を使います。

```bash
for key in "${!mymap[@]}"; do
    echo "$key -> ${mymap[$key]}"
done
```

これは次のように出力します：

```
second -> bar
first -> foo
third -> baz
```

もう一度強調すると、キーには順序がありません。
