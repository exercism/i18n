# 説明

魔法使いの見習いであるElyseは、修行を続けています。彼女は手品を披露するために、いくつかのカードの山札を渡されます。
少し簡単にするため、彼女は1から10までのカードだけを使います。

この演習では、組み込みのメソッドを使って配列の中身を分析します。

## 1. カードの位置を調べる

Elyseは、山札の中にあるカードの位置（インデックス）を知りたいと思っています。

```javascript
const card = 2;
getCardPosition([9, 7, 3, 2], card);
// => 3
```

## 2. カードがあるかどうかを調べる

Elyseは、あるカードが山札にあるかどうかを調べたいと思っています。つまり、山札に特定の`number`が含まれているかどうかです。

```javascript
const card = 3;
doesStackIncludeCard([2, 3, 4, 5], card);
// => true
```

## 3. すべてのカードが偶数かどうかを調べる

Elyseは、すべてのカードが偶数かどうかを知りたいと思っています。つまり、山札にあるそれぞれの数値が偶数の`number`かどうかです。

```javascript
isEachCardEven([2, 4, 6, 7]);
// => false
```

## 4. 山札に奇数のカードがあるかどうかを調べる

Elyseは、山札に奇数の数値があるかどうかを知りたいと思っています。

```javascript
doesStackIncludeOddCard([3, 2, 6, 4, 8]);
// => true
```

## 5. 山札から最初の奇数のカードを取り出す

Elyseは、最初の奇数のカードの値を知りたいと思っています。

```javascript
getFirstOddCard([4, 2, 8, 7, 9]);
// => 7
```

## 6. 最初の偶数のカードの位置を調べる

Elyseは、最初の偶数のカードの位置を知りたいと思っています。

```javascript
getFirstEvenCardPosition([5, 2, 3, 1]);
// => 1
```
