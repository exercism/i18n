# はじめに

インターフェースは、クラスの公開フィールドを記述するものなので、クラスのシグネチャと考えることができます。クラスは、`implments`キーワードを使って`interface`を_実装_します。

その構文はクラスとよく似ていますが、メソッドが本体のないシグネチャとして現れる点が異なります：

```haxe
interface Language {
  private var languageName:String;

  public function speak():String;
}

class FrenchSpeaker implements Language {
  var languageName = "French";

  public function speak():String {
    return "Bonjour!";
  }
}
```

インターフェースから実装されるフィールドは、**必ず**同じ可視性修飾子を使わなければなりません。たとえば、変数`a`がインターフェースで`public`である場合、その実装も`public`でなければなりません。
