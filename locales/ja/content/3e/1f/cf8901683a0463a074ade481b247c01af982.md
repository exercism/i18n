# 説明

この演習では、大のスポーツファンとして、NBAバスケットボールに夢中になったばかりです。NBAバスケットボールは初心者なので、NBAの歴史を深く掘り下げ、チームやコーチ、その勝敗の記録を追いかけ、互いに比較しています。

まだお気に入りのチームがないので、特定のチームを応援すべきかどうかを判断するアルゴリズムも作ることになります。

独自の_チーム応援_アルゴリズムを開発するための7つのタスクがあります。

## 1. モデルを定義する

次の2つのフィールドを持つ`Coach`レコードを定義します。

- `name`: コーチの名前。型は`String`。
- `former_player`: コーチが元選手かどうかを示します。型は`Bool`。

次の2つのフィールドを持つ`Stats`レコードを定義します。

- `wins`: 勝利数。型は`Int`。
- `losses`: 敗北数。型は`Int`。

次の3つのフィールドを持つ`Team`レコードを定義します。

- `name`: チームの名前。型は`String`。
- `coach`: チームのコーチ。型は`Coach`。
- `stats`: チームの成績。型は`Stats`。

## 2. チームのコーチを作成する

コーチの名前と元選手かどうかを引数に取り、`Coach`レコードを返す`create_coach`関数を実装します。

```gleam
create_coach("Larry Bird", True)
// -> Coach(name: "Larry Bird", former_player: True)
```

## 3. チームの成績を作成する

勝利数と敗北数を引数に取り、`Stats`レコードを返す`create_stats`関数を実装します。

```gleam
create_stats(58, 24)
// -> Stats(wins: 58, losses: 24)
```

## 4. チームを作成する

チーム名、コーチ、成績を引数に取り、`Team`レコードを返す`create_team`関数を実装します。

```gleam
let coach = create_coach("Larry Bird", True)
let stats = create_stats(58, 24)
create_team("Indiana Pacers", coach, stats)
// -> Team(
//   name: "Indiana Pacers",
//   coach: Coach(name: "Larry Bird", FormerPlayer = True),
//   stats: Stats(wins: 58, losses: 24),
// ) 
```

## 5. コーチを交代させる

NBAのオーナーはせっかちなので、チームの成績が悪いとコーチが交代させられることがよくあると気づきました。チームと新しいコーチを引数に取り、新しいコーチに置き換えたチームを返す`replace_coach`関数を実装します。

```gleam
let coach = create_coach("Larry Bird", True)
let record = create_stats(58, 24)
let team = create_team("Indiana Pacers", coach, record)

let new_coach = create_coach("Isiah Thomas", True)
replace_coach(team, new_coach)
// -> Team(
//   name: "Indiana Pacers",
//   coach: Coach(name: "Isiah Thomas", FormerPlayer = True),
//   stats: Stats(wins: 58, losses: 24),
// ) 
```

## 6. 同じチームかどうかを確認する

成績を調べるうちに、チームとその記録のリストを作っています。ときには間違えてしまい、リストに重複した項目が入ってしまうこともあります。2つのチームを引数に取り、同じチームなら`True`、そうでなければ`False`を返す`is_same_team`関数を実装します。

```gleam
let pacers_coach = create_coach("Larry Bird", True)
let pacers_stats = create_stats(58, 24)
let pacers_team = create_team("Indiana Pacers", pacers_coach, pacers_stats)

let lakers_coach = create_coach("Del Harris", False)
let lakers_stats = create_stats(61, 21)
let lakers_team = create_team("LA Lakers", lakers_coach, lakers_stats)

is_same_team(pacers_team, lakers_team)
// -> False
```

## 7. そのチームを応援すべきかどうかを確認する

多くのチームと試合を見てきた結果、あるアルゴリズムを考え出しました。次のいずれかに当てはまれば、そのチームを応援します。

- コーチの名前が"Gregg Popovich"である
- コーチが元選手である
- チームの名前が"Chicago Bulls"である
- チームが60試合以上勝利している
- チームの敗北数が勝利数より多い

チームを引数に取り、そのチームを応援すべきなら`True`、そうでなければ`False`を返す`root_for_team`関数を実装します。

```gleam
let spurs_coach = create_coach("Gregg Popovich", False)
let spurs_stats = create_stats(56, 26)
let spurs_team = create_team("San Antonio Spurs", spurs_coach, spurs_stats)
root_for_team(spurs_team)
// -> True
```
