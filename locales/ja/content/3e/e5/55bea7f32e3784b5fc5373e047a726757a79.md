# 説明

町にはピザのスライスを売る店がいくつかあり、2つのピザの構成を比べて、どちらの店がより大きなスライスをくれるのかがわかるWebアプリを作りたいと考えています。

## 1. 無効な入力に対してはnilを返す、スライスの大きさを計算する関数を書く

関数`sliceSize(diameter: Double?, slices: Int?) -> Double?`を実装します。この関数は、ピザの直径とピザ1枚あたりのスライスの数を受け取り、スライス1枚の面積を返します。
直径が負の場合と、スライスの数が1未満の場合は`nil`を返します。直径が負のピザは存在しませんし、ピザを1枚未満に切り分けることもできないからです。
どちらかの仮引数が`nil`の場合も、`nil`を返します。

```swift
sliceSize(diameter: 16, slices: 12)
// Returns 16.75516081914556
sliceSize(diameter: nil, slices: 8)
// Returns nil
```

## 2. Webアプリからの入力を処理して、より大きなスライスを判定する

Webアプリは、関数`biggestSlice(diameterA: String, slicesA: String, diameterB: String, slicesB: String) -> String`に4つの文字列を渡します。
1つ目と2つ目の文字列は、それぞれ1つ目のピザの直径とスライスの数です。3つ目と4つ目は、それぞれ2つ目のピザの直径とスライスの数です。

`biggestSlice`は、各ピザの直径とスライスの数を、それぞれ`Double`と`Int`に変換しようと試みるように実装します。
両方の値を文字列から取得できた場合は、1つ目の関数を使って面積の計算を試みます。そうでなければ、そのスライスの面積は`nil`です。
2つのスライスの面積が求まったら、次のルールに従って2つの面積を比較します。

1. スライスAの面積が`Double`で、スライスBの面積が`nil`の場合は、"Slice A is bigger"を返します。逆の場合は、"Slice B is bigger"を返します。
2. 両方の面積が`Double`の場合は、面積が大きいほうのスライスに応じて、"Slice A is bigger"または"Slice B is bigger"を返します。
3. 両方の面積が`nil`の場合、または両方が`Double`で等しい場合は、"Neither slice is bigger"を返します。

~~~~exercism/note
入力の結果、スライスの面積が0になったとしても、そのスライスは有効とみなされます。また、面積が`nil`のスライスより大きいものとして扱うべきです。
~~~~

```swift
biggestSlice(diameterA: "10", slicesA: "6", diameterB: "14", slicesB: "12")
// Returns "Slice A is bigger"
biggestSlice(diameterA: "10", slicesA: "6", diameterB: "12", slicesB: "8")
// Returns "Slice B is bigger"
biggestSlice(diameterA: "Pepperoni", slicesA: "6", diameterB: "Sausage", slicesB: "12")
// Returns "Neither slice is bigger"
```
