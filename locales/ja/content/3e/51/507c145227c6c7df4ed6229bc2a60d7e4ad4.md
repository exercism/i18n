## はじめに

ポインタとは、その値が別の変数や定数のアドレスであるような、変数または定数のことです。
ポインタは、Cの強力で、ときに危険をともなう機能です。
ポインタを理解するのは難しいこともあります。

変数や定数は、その値をメモリ上の場所に格納します。
そのメモリ上の場所は、変数や定数のアドレスと呼ばれます。

変数のアドレスを取得するには、アドレス演算子を使います。それが`&`です。
```c
int i = 5;
int *i_address = &i;
```

型のあとに`*`、さらに識別子を続けるのが、その型の変数へのポインタを宣言する方法です。
`*`は間接演算子と呼ばれます。ポインタがアドレスを保持している値に、間接的に言及するからです。

次のようにして配列を作ると

```c
int my_ints[] = {1, 2};
```

`my_ints`の値は、実はそれ自身のアドレスです。そしてこれは、その最初の要素のアドレスと同じでもあります。
2番目の要素のアドレスは、最初の要素のアドレスに、そのシステムにおける`int`のサイズを足したものになります。

これが、ポインタがある特定の型として宣言される理由です。
ポインタが自分がどの型を指しているかを知らなければ、それに`1`を足すときに何バイト進めればよいかわかりません。
ポインタに`1`を足すことは、必ずしもアドレスに1バイトを足すという意味ではありません。
それは、その型の長さをバイトで表したものの`1`倍を足す、という意味です。
