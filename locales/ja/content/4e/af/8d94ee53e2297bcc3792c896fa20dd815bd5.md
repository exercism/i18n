# はじめに

## インターフェース

インターフェースとは、関連する機能をひとまとめにしたメンバーを持つ型です。クラスの利用側を実装から切り離すことで、複数の異なる実装を可能にしたり、書式設定、比較、変換といった汎用的な振る舞いに対応したりできます。

インターフェースの構文はクラスや構造体とよく似ていますが、メソッドとプロパティはシグネチャだけを書き、本体は持ちません。

```csharp
public interface ILanguage
{
    string LanguageName { get; set; }
    string Speak();
}

public class ItalianTaveller : ILanguage, ICloneable
{
    public string LanguageName { get; set; } =  "Italiano";

    public string Speak()
    {
        return "Ciao mondo";
    }

    public object Clone()
    {
        ItalianTaveller it = new ItalianTaveller();
        it.LanguageName = this.LanguageName;
        return it;
    }
}
```

インターフェースで定義されたすべての操作を実装する必要があります。

インターフェースには、ほかのメンバーに加えて、インスタンスメソッドやプロパティを含めることができます。

## 順序付け

あるオブジェクトを別のオブジェクトと比較できるようにするには、そのオブジェクトが`IComparable<T>`インターフェースを実装している必要があります。このインターフェースには、実装が必要なメソッドが1つだけあります。それが`int CompareTo(T other)`です。

`CompareTo`メソッドの戻り値は、次の3つのいずれかです。

- 0より小さい値：現在のオブジェクトは相手のオブジェクトより小さい。
- 0より大きい値：現在のオブジェクトは相手のオブジェクトより大きい。
- 0に等しい値：現在のオブジェクトは相手のオブジェクトと等しい。
