# はじめに

## 変数と代入

Rは動的型付け言語なので、一般的に、変数の型を指定する必要はありません。代入演算子としては`<-`が好まれます。

```R
x <- 42
avogadro <- 6.02e23
mystr <- "Hello, World!"
```

`<-`の代わりに`=`を使っても、多くの場合は動きますが、必ず動くとは限りません。また、良いスタイルではないとされているので避けましょう。
RStudioで作業している場合は、キーボードショートカットの`Alt-minus`で入力できます。

演算子はほとんど一般的なものですが、`%/%`と`%%`には注意してください。

```R
2 + 3   # 5
2 - 3   # -1
2 * 3   # 6
2 / 3   # 0.6666667
8 %/% 3 # 2 (integer division)
8 %% 3  # 2 (remainder)
2 ^ 3   # 8 (exponential)
```

Rでは、`#`から始まる1行コメントを書けます。
複数行コメントのための専用の構文はありません。

## 関数

関数を定義するには、次のように書きます。

```R
squareit <- function(x) {
    x * x
}
```

関数は0個以上の入力を取ることができ、それらはカンマで区切ります。
`function()`と書くときは、入力がなくても括弧（`()`）が必要です。

関数の入力にはデフォルト値を指定できますが、デフォルト値のない入力よりも後に置く必要があり、デフォルト値の代入には`<-`ではなく`=`を使います。
あまり意味のない例ですが、次のようになります。

```R
squareit <- function(x = 42) {
    x * x
}

squareit()
#> [1] 1764
```

波括弧（`{ }`）は、1行の関数本体には厳密には必要ありませんが、付けておくのが良いスタイルとされています。

上の例のように、Rは関数の最後の値を自動的に戻り値として返します。

`return()`は、関数本体のどこでも使うことができ、戻り値を明示できます。

関数の呼び出しは、他の多くの言語と同じです。

```R
squareit(3)
#> [1] 9
```
