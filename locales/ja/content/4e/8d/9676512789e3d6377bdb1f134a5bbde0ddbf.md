# 説明

Lisp AlienのLillyが戻ってきて、また料理をしています！　今度は、人間のラザニアとそれほど変わらない「Lisp Alienラザニア」を作ろうとしています。

Lillyは、ラザニアを焼く時間を計算するための関数をいくつか書く必要があります。しかも、それぞれの関数が何をするのか忘れないように、きちんとドキュメントを付けておく必要があります。

Lillyがラザニアの調理時間を計れるように、関数を書くのを手伝ってあげませんか？

## 1. オーブンに入れておくべき時間（分）を定義する

入力を受け取らず、ラザニアをオーブンに入れておくべき時間を分で返す`expected-time-in-oven`関数を定義します。Lisp Alienの伝統（Lillyの親ユニットも同じように料理していました）によると、オーブンに入れておくべき時間は337分です。

```lisp
(expected-time-in-oven) ;; => 337
```

## 2. オーブンでの残り時間（分）を計算する

`remaining-minutes-in-oven`関数を定義します。この関数は、ラザニアがすでにオーブンに入っていた実際の分数を入力として受け取り、前のタスクで定義したオーブンに入れておくべき時間（分）をもとに、あと何分オーブンに入れておく必要があるかを返します。

```lisp
(remaining-minutes-in-oven 100) ;; => 237
```

## 3. 準備時間（分）を計算する

`preparation-time-in-minutes`関数を定義します。この関数は、Lillyがラザニアに重ねた層の枚数を入力として受け取り、1枚あたり19分かかるものとして、ラザニアの準備に何分かかったかを返します。

```lisp
(preparation-time-in-minutes 3) ;; => 57
```

## 4. 経過時間（分）を計算する

`elapsed-time-in-minutes`関数を定義します。この関数は2つの入力を受け取ります。1つ目はLillyがラザニアに重ねた層の枚数、2つ目はラザニアがオーブンに入っていた分数です。この関数は、ラザニアの調理にLillyがこれまで取り組んだ時間を分で返します。これは、準備時間（分）と、その時点でラザニアがオーブンに入っていた時間（分）の合計です。

```lisp
(elapsed-time-in-minutes 3 100) ;; => 157
```
