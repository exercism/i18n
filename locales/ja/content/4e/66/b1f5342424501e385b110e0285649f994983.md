# 指示

信号所のコード生成ツールキットを保守しています。各マクロは*ステンシル*、つまりコンパイラーが各呼び出し地点で特化したコードを打ち出すのに使う小さなテンプレートです。

書くのは4つのマクロだけです。テストファイルには、あなたのマクロを*呼び出す*小さなラッパーワードが定義されていて（マクロは、それが生成するコードを通してしか観察できません）、そのラッパーの実行時の結果を確認します。ラッパーはそのままにしておいてください。

各タスクでは、本体はスタック上で呼び出し地点のリテラル入力を受け取り、**1つのクォーテーション**を残さなければなりません。「コンパイル結果」の行は、あなたのクォーテーションが生成すべき直線的なコードを示します。

## 1. 2回繰り返す

`twice`はリテラルのクォーテーションを受け取り、元のクォーテーションを続けて2回実行するクォーテーションを返します。

```factor
! : inc-twice ( x -- y ) [ 1 + ] twice ;
! body receives [ 1 + ]  ->  must build [ 1 + 1 + ]
5 inc-twice .   ! => 7
```

## 2. N回の繰り返し

`repeat-quot`はリテラルのクォーテーションとリテラルのカウント`n`を受け取り、元のクォーテーションを続けて`n`回実行するクォーテーションを返します。`n = 0`のときは空のクォーテーション`[ ]`を返します。

```factor
! : inc-thrice ( x -- y ) [ 1 + ] 3 repeat-quot ;
! body receives [ 1 + ] 3  ->  must build [ 1 + 1 + 1 + ]
5 inc-thrice .   ! => 8
```

## 3. まとめて合成

`compose-many`はクォーテーションのリテラル配列を受け取り、それぞれを順番に実行する1つのクォーテーションを返します。空の配列のときは空のクォーテーションを返します。

```factor
! : pipeline ( x -- y ) { [ 1 + ] [ 2 * ] [ 1 - ] } compose-many ;
! body receives { [ 1 + ] [ 2 * ] [ 1 - ] }  ->  must build [ 1 + 2 * 1 - ]
5 pipeline .   ! => 11
```

## 4. 展開された繰り返し

`each-literal`はリテラルのシーケンスとクォーテーションを受け取ります。そして、シーケンスの各要素について、その要素をプッシュしてからクォーテーションを実行するクォーテーションを返します。コンパイル時に起こる繰り返しなので、生成されるコードは直線的になります。

```factor
! : sum-three ( -- n ) 0 { 10 20 30 } [ + ] each-literal ;
! body receives { 10 20 30 } [ + ]  ->  must build [ 10 + 20 + 30 + ]
sum-three .   ! => 60
```

これは4つの中で最も構造的なマクロです。シーケンスの長さ*と*要素の値の両方が、生成されるコードを形作ります。ヒントでは、それを1歩ずつ組み立てていきます。
