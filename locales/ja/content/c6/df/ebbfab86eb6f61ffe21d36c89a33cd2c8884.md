# はじめに

Swiftの標準ライブラリには豊富な機能が用意されていますが、外部のライブラリやフレームワークをインポートすると、さらに多くの機能を利用できます。
これらのモジュールは、Swiftプロジェクトから直接提供されることも（[Swift Argument Parser][argument-parser]など）、Appleのプラットフォームフレームワークに含まれることも（[Foundation][apple-foundation]や[Network Framework][network-framework]など）、サードパーティのオープンソースライブラリに含まれることもあります（[SwiftyBeaver][swifty-beaver]など）。

Foundationのようなコアモジュールは、Swiftのツールチェーンに含まれています。Foundationは、Swiftで最も広く使われているライブラリの1つです。
サードパーティのライブラリは、インポートする前にプロジェクトの設定に追加しておく必要があります（たとえば、Swift Package Managerを使います）。

モジュールをインポートするには、`import`キーワードに続けてモジュール名を書きます。

```swift
import Foundation
```

モジュールをインポートすると、その型やメソッド、関数を自分のコードから使えるようになります。
たとえば、Foundationをインポートすると、`String`に`components(separatedBy:)`のような便利なユーティリティメソッドが追加されます。

慣例として、`import`文はSwiftファイルの先頭に置きます。こうすると、コードを読む人に依存関係がすぐわかります。

[argument-parser]: https://apple.github.io/swift-argument-parser/documentation/argumentparser/
[network-framework]: https://developer.apple.com/documentation/network
[swifty-beaver]: https://github.com/SwiftyBeaver/SwiftyBeaver
[apple-foundation]: https://developer.apple.com/documentation/foundation
