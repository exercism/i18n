# はじめに

Factorのエラーシステムは、3つの要素からできています。エラーを知らせる`throw`、エラーを処理する`recover`、そして独自のエラーを定義する`ERROR:`です。

## `throw`

`throw`（[`kernel`][kernel]にあります）はエラーを発生させます。引数には文字列・数値・タプルなど、*どんな*値でも渡すことができ、その値が後から確認できるエラーになります。

```factor
! DOCTEST: SKIP
"file not found" throw
```

`throw`は戻りません。現在のワードの残りの部分はスキップされます。

## `recover`

`recover`（[`continuations`][continuations]にあります）は、Factorのtry/catchです。*try*クォーテーションと*recovery*クォーテーションを受け取ります。

```
recover ( try recovery -- )
```

`try`がthrowせずに終われば、`recovery`は無視されます。`try`がthrowすると、エラーがスタックに積まれ、`recovery`が実行されます。

```factor
[ "boom" throw ] [ drop "caught" ] recover .
! => "caught"

[ "ok" ] [ drop "never runs" ] recover .
! => "ok"
```

[`kernel`][kernel]の`when`は自然な相棒です。スタックの一番上が真と評価されるときだけ、クォーテーションを実行します。

```factor
: check-positive ( n -- )
    0 < [ "negative!" throw ] when ;
```

## `ERROR:`

`ERROR:`はタプルクラス*と*、新しいインスタンスを生成してthrowするワードを定義します。

```factor
! DOCTEST: SKIP
ERROR: not-found path ;

"/missing" not-found
! throws T{ not-found { path "/missing" } }
```

スロットを持たないエラーは、単に`ERROR: name ;`と書くだけです。`name`を呼び出すと、空のインスタンスがthrowされます。`ERROR:`で定義したタプルには、クラスの述語`name?`が付いており、捕まえたエラーがその型のものかどうかを確かめられます。

## スロットの値を取り出す

捕まえたエラーはただのタプルなので、`ERROR:`の各スロットには、ほかのタプルと同じ、自動生成された`slot>>`リーダーが付いています。

```factor
! DOCTEST: SKIP
{
    T{ not-found { path "/a" } }
    T{ not-found { path "/b" } }
}
[ path>> ] map .   ! => { "/a" "/b" }
```
