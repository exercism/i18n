# 説明

勤めている会社が、まもなく**Smarty 5**という新しいスマートフォンを発売しようとしています。新しいカメラシステム、新しいデザイン、そして**smartyOS**という新しいオペレーティングシステムで動く、革新的な新しいプロセッサーを搭載しています。

新しいプロセッサーは、これまで以上に安全なパスワードを扱える性能を備えています。会社はこれを活用することにしました。そして、スマートフォン用のパスワードロックシステムの実装を依頼してきました。これは、ユーザーがパスワードを設定し、そのあと、入力されたパスワードが正しいかどうかを確認できるようにするものです。

~~~~exercism/caution
この演習で扱うパスワードシステムは安全ではなく、教育目的でのみ使われます。実際のアプリケーションで使うべきでは**ありません**。
~~~~

## 1. パスワードを設定する

このスマートフォンでは、ユーザーがいくつもの異なる種類のパスワードを使えます。単純な数字のパスワードから、より安全な英数字のパスワード、さらには指紋を記憶するパスワードまであります。

これらのパスワードはそれぞれ異なる型を使います。数字のパスワードは`Int32`、英数字のパスワードは`String`、指紋のパスワードは`Float64`を使います。

`PasswordLock`クラスを実装してください。イニシャライザーは3種類のパスワードのいずれかを引数に取り、それを`@password`というインスタンス変数に保存します。

```crystal
password_lock = PasswordLock.new(1234)
# => #<PasswordLock:0x7f8e1b8c0b80 @password=1234>
```

## 2. パスワードを暗号化する

会社は、パスワードが平文で保存されないよう暗号化することにしました。そして、それを暗号化するメソッドの実装を依頼してきました。

パスワードの種類ごとに、暗号化の方法が異なります。

- `Int32`のパスワード：パスワードを2で割り、最も近い整数に丸めます。
- `String`のパスワード：パスワードを逆にします。
- `Float64`のパスワード：パスワードを4倍します。

`encrypt`というインスタンスメソッドを実装してください。このメソッドは引数を取らず、`@password`インスタンス変数を暗号化された状態に変更します。

```crystal
password_lock = PasswordLock.new(1234)
# => #<PasswordLock:0x7f8e1b8c0b80 @password=1234>

password_lock.encrypt
# => #<PasswordLock:0x7f8e1b8c0b80 @password=617>
```

## 3. パスワードが正しいかどうかを確認する

会社は、入力されたパスワードが正しいかどうかを確認するメソッドの実装も依頼してきました。

パスワードが正しくなければ`nil`を、正しければ`"Unlocked"`を返すメソッドにしたいのです。

`unlock?`というインスタンスメソッドを実装してください。確認するパスワードを引数に取ります。
このメソッドは、パスワードが正しくなければ`nil`を、正しければ`"Unlocked"`を返します。

```crystal
password_lock = PasswordLock.new(1234)
password_lock.encrypt
password_lock.unlock?(1234)
# => "Unlocked"
```
