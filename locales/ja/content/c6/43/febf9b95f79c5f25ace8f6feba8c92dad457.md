# 説明の補足

## 実装上の注意

テストプログラムは、可変長の`New`関数を繰り返し適用して木を構築します。
たとえば、次の文は

```go
tree := New("a",New("b"),New("c",New("d")))
```

次の木を構築します。

```text
      "a"
       |
    -------
    |     |
   "b"   "c"
          |
         "d"
```

テスト用の木に重複した値はないと考えてかまいません。

テストプログラムは、木を分解するために`Value`メソッドと`Children`メソッドを使います。

演習の面白い部分に取りかかる前に、基本的な木の構築と分解が動いている必要があります。そのため、最初の3つのテストで個別にテストされます。

---

`FromPov`メソッドと`PathTo`メソッドが、この演習の面白い部分です。

`FromPov`メソッドは、文字列の引数`from`を取ります。この引数は、値によって木の中のノードを指定します。
値`from`をルートに持つ木を返す必要があります。
元の木を変更してそれを返しても、新しい木を作ってそれを返してもかまいません。
新しい木を返す場合、元の木を自由に消費したり破壊したりできます。
もちろん、元の木を変更せずに残しておくのもよいでしょう。

`PathTo`メソッドは、2つの文字列の引数`from`と`to`を取ります。これらは、値によって木の中の2つのノードを指定します。
1つ目のノードから2つ目のノードへの、木の中の最短経路を返す必要があります。
