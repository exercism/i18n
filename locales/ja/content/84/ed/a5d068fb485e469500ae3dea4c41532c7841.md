# 補足説明

## 入力形式

各ドミノは1バイトとして格納され、左半分が上位の[ニブル][nibble]、右半分が下位の[ニブル][nibble]になります。たとえば、石`[2|1]`、`[2|3]`、`[1|3]`は、バイト`0x21 0x23 0x13`として表されます。

## レジスタ

| レジスタ | 用途     | 型    | 説明                                      |
| -------- | --------- | ------- | ------------------------------------------------ |
| `$a0`    | 入力     | アドレス | 石のバイト列の配列                             |
| `$a1`    | 入力     | 整数 | 石の数                                 |
| `$v0`    | 出力     | 真偽値 | ドミノがつながるかどうか（`0` = `false`、`1` = `true`） |
| `$t0-9`  | 一時的 | 任意     | 一時的な保存に使う                       |


[nibble]: https://en.wikipedia.org/wiki/Nibble
