# 説明

この演習では、高校時代の恋人同士がSNSで愛を告白できるよう手伝います。二人のイニシャルを使ったASCIIのハートを生成しましょう。

```
❤ J.  +  M. ❤
```

## 1. 名前を整える

`HighSchoolSweetheart.clean_up_name`メソッドを実装します。
名前を受け取り、その中の`-`をすべて取り除いてスペースに置き換えます。
名前の先頭と末尾にある空白も取り除きます。

```crystal
HighSchoolSweetheart.clean_up_name("Jane-Ann")
# => "Jane Ann"
```

## 2. 名前の最初の文字を取得する

`HighSchoolSweetheart.first_letter`メソッドを実装します。
名前を受け取り、その最初の文字を返します。
前のステップで定義した`HighSchoolSweetheart.clean_up_name`を必ず再利用してください。

```crystal
HighSchoolSweetheart.first_letter("Jane")
# => "J"
```

## 3. 最初の文字をイニシャルとして整形する

`HighSchoolSweetheart.initial`メソッドを実装します。
名前を受け取り、その最初の文字を大文字にし、その後にドットを付けて返します。
前のステップで定義した`HighSchoolSweetheart.first_letter`を必ず再利用してください。

```crystal
HighSchoolSweetheart.initial("Robert")
# => "R."
```

## 4. イニシャルをハートの中に入れる

`HighSchoolSweetheart.pair`メソッドを実装します。
2つの名前を受け取り、イニシャルを絵文字のハートで挟んだものを返します。
前のステップで定義した`HighSchoolSweetheart.initial`を必ず再利用してください。

```crystal
HighSchoolSweetheart.pair("Blake Miller", "Riley Lewis")
# => "❤ B.  +  R. ❤"
```
