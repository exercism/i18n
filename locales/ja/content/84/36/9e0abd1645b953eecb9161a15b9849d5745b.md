# 基礎

## はじめに

### 変数

[変数][variables]を宣言するには、`=`代入演算子を使います。
Crystalでは、変数には[snake_case][snake-case]形式を使います。

```crystal
number = 1
puts number # => 1

number = 2
puts number # => 2
```

### 定数

[定数][constants]も同じ`=`代入演算子で宣言しますが、SCREAMING_SNAKE_CASEと呼ばれるすべて大文字を使います。

```crystal
NUMBER = 1
puts NUMBER # => 1
```

すでに定義済みの定数に値を代入すると、コンパイルエラーになります。

```crystal
NUMBER = 1

NUMBER = 2
# Error: already initialized constant NUMBER
```

### 型

Crystalはコンパイル言語です。つまり、すべての変数やメソッドの引数には、コンパイル時に型が割り当てられます。
コンパイラーは、変数やメソッドの引数の型を推論できます。
ただし、場合によっては型を指定する必要があります。
型の指定が必要になるケースは、後の概念で説明します。

### メソッド

[メソッド][methods]は、再利用できる一連の命令をまとめる仕組みです。
Crystalでは、メソッドはクラス、モジュール、構造体の中で定義することが多いです。
ただし、クラス、モジュール、構造体の外で定義することもできます。
メソッドは`def`キーワードを使って宣言し、その後にメソッド名を続けます。
Crystalでは、メソッド名にはsnake_caseを使います。
メソッドに引数がない場合は、括弧（`()`）を省略できます。
メソッドの終わりを宣言するには、`end`キーワードを使います。

```crystal
def hello
  puts "Hello World!"
end
```

変数やメソッドの引数の型に存在しないメソッドを使うと、コンパイルエラーになります。

```crystal
number = 1
number + "1"
# Error: no overload matches 'Int32#+' with type String
```

### 引数

メソッドには[引数][arguments]を持たせることができます。
引数は、メソッドに渡されるデータです。
メソッドに引数を渡せるようにするには、引数の名前を指定する必要があります。
Crystalでは、引数にもsnake_caseを使います。
メソッドには複数の引数を持たせることができますが、引数はコンマで区切る必要があります。

```crystal
def hello(name)
  puts "Hello #{name}!"
end
```

メソッドには複数の引数を持たせることもできます。
この場合、引数はコンマで区切ります。

```crystal
def hello(name, language)
  puts "Hello #{name}! You are learning #{language}."
end
```

### メソッドの呼び出し

クラス、モジュール、構造体に属するメソッドを呼び出すときは、ドット演算子（`.`）を使います。
形式は`<ClassName>.<method_name>`とします。
メソッドがクラス、モジュール、構造体に属していない場合は、名前を書くだけで呼び出せます。
メソッドは常に、最後の式の値を暗黙的に返します。

メソッドに引数がある場合は、メソッドの呼び出しと定義のどちらでも、次のように括弧を使って引数を指定できます： `<method_name>(<argument_1>, <argument_2>, ...)`。
メソッドに引数がない場合は、括弧を省略します。

```crystal
def hello(name)
  "Hello #{name}!"
end

hello("Crystal")
# => Hello Crystal!
```

複数の引数を持つメソッドを呼び出すときは、引数をコンマで区切ります。
引数は、メソッドの引数と同じ順番で指定する必要があります。

```crystal
def hello_language(name, language)
  "Hello #{name}! You are learning #{language}."
end

hello_language("World", "Crystal")
# => Hello World! You are learning Crystal.
```

引数の数が合わないメソッドを呼び出すと、コンパイルエラーになります。

```crystal
hello_language("Crystal")
# wrong number of arguments for 'hello_language' (given 1, expected 2)
```

### 足し算・引き算・掛け算

Crystalでは、`+`演算子で2つの数値を足せます。
`-`演算子で2つの数値を引くこともできます。
そして`*`演算子で2つの数値を掛けることもできます。

```crystal
1 + 1
# => 2

2 - 1
# => 1

2 * 2
# => 4
```

### コメント

Crystalでは、[コメント][comments]は`#`文字で書き、その後にスペース、そしてコメントを続けます。
コメントはコードを説明するために使います。
コンパイラーはコメントを実行しません。

```crystal
# This is a comment
```
