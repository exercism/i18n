# 概要

## 真偽値

PowerShellには、真偽の値を表す[`bool`][booleans]型があります。
この型に存在する値は、`True`と`False`の2つだけです。
これらの値は、`$`を付けた変数に代入できます：

```powershell
> $TrueVar  = $true
> $FalseVar = $FALSE
#Case senstitivity doesn't matter here
```

`-and`、`-or`、`-not`などの[論理演算子][logical-operators]を使うと、真偽値の式を組み合わせて評価できます。

```powershell
> $TrueVar  = $true -and $true
> $FalseVar = $true -and $false

> $TrueVar  = $true -or $false
> $FalseVar = $false -or $false

> $TrueVar  = -not $false
> $FalseVar = -not $true
```

## 変換と真偽値の評価

PowerShellでは、どんな型でも暗黙的に真偽値として扱うことができます。
ただし、真偽値の型アクセラレータ`[bool]`を使えば、明示的に変換することもできます。

PowerShellが他の型を真偽値に変換するときの、一般的なルールをいくつか紹介します：

$false:
- `''`や`""`のような空の文字列
- `$null`のようなnull値
- 値がゼロ（0）の数値型

$true:
- 空でない文字列
- その他のコレクション以外の型のインスタンス

```powershell
> [bool] 0
False

> [bool] 0.0
False

> [bool] ""
False

> [bool] "Hello"
True

> [bool] 1234
True
```

コレクション型から真偽値への変換についての詳しいルールは、[こちら][collection-conversion]を参照してください。
