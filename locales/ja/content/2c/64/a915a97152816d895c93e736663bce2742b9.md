# はじめに

静的拡張を使うと、既存の型のソースコードを変更することなく、その型を擬似的に拡張できます。これは`using`文を使うことで実現します。静的拡張は、型そのものを実際に変更することなく機能を追加できる強力なツールです。

```haxe
using Main.IntExtender;

class Main {
  public static function main() {
    trace(2.triple()); // 6
  }
}

class IntExtender {
  public static function triple(i:Int):Int {
    return i * 3;
  }
}
```
