# 説明

この演習では、名作ゲーム「パックマン」のルールをいくつか実装します。

実装するルールは4つで、いずれもゲームの状態に関するものです。

## 1. パックマンがゴーストを食べられるかどうかを定義する

パックマンがパワークッキーを食べている状態かどうか、そしてパックマンがゴーストに触れているかどうかを入力として受け取り、パックマンがゴーストを食べられるかどうかを表す真偽値を返す関数を実装してください。この関数は、パックマンがパワークッキーを食べている状態で、かつゴーストに触れているときだけ`true`を返します。

```lua
rules.eat_ghost(false, true)
-- => false
```

## 2. パックマンが得点するかどうかを定義する

パックマンがパワークッキーに触れているかどうか、そしてパックマンがドットに触れているかどうかを入力として受け取り、パックマンが得点したかどうかを表す真偽値を返す関数を実装してください。この関数は、パックマンがパワークッキーかドットに触れているときに`true`を返します。

```lua
rules.score(true, true)
-- => true
```

## 3. パックマンが負けるかどうかを定義する

パックマンがパワークッキーを食べている状態かどうか、そしてパックマンがゴーストに触れているかどうかを入力として受け取り、パックマンが負けるかどうかを表す真偽値を返す関数を実装してください。この関数は、パックマンがゴーストに触れていて、かつパワークッキーを食べている状態でないときに`true`を返します。

```lua
rules.lose(false, true)
-- => true
```

## 4. パックマンが勝つかどうかを定義する

パックマンがすべてのドットを食べたかどうか、パックマンがパワークッキーを食べている状態かどうか、そしてパックマンがゴーストに触れているかどうかを入力として受け取り、パックマンが勝つかどうかを表す真偽値を返す関数を実装してください。この関数は、パックマンがすべてのドットを食べていて、かつパート3で定義した入力に基づいて負けていないときに`true`を返します。

```lua
rules.win(false, true, false)
-- => false
```
