# タスク

タスクとは、テキストの校正からコンセプト演習の作成まで、みなさんに手伝ってもらいたいGitHubのイシューです。
タスクはウェブサイトに表示され、GitHub上の対応するイシューにリンクしています。
各タスクには1つ以上のプロパティが付いていて、プロパティはイシューのラベルから設定されます。
ユーザーは、プロパティをもとにタスクを絞り込めます。

## タグ

イシューがタスクとして扱われるには、タスク専用のラベルが1つ以上付いている必要があります。
こうすることで、メンテナーは一部のイシューだけをタスクとして表示させることができます。

タスクのラベルはそれぞれ`x:<type>/<value>`として定義され、タスクタイプは5つあります。

- `action`
- `knowledge`
- `module`
- `size`
- `type`

### アクションタグ

`x:action/<value>`ラベルは、そのイシューに取り組むときにコントリビューターがどんな作業をするかを表します。

| タグ                 | 説明                                   |
| -------------------- | -------------------------------------- |
| `x:action/create`    | ゼロから何かを作る作業                 |
| `x:action/fix`       | イシューを修正する                     |
| `x:action/improve`   | 既存の機能やコンテンツを改善する       |
| `x:action/proofread` | テキストを校正する                     |
| `x:action/sync`      | コンテンツを最新バージョンと同期する   |

### ナレッジタグ

`x:knowledge/<value>`ラベルは、コントリビューターにどれだけExercismの知識が必要かを表します。

| タグ                       | 説明                             |
| -------------------------- | -------------------------------- |
| `x:knowledge/none`         | Exercismの知識は不要             |
| `x:knowledge/elementary`   | Exercismの知識が少し必要         |
| `x:knowledge/intermediate` | Exercismの知識がかなり必要       |
| `x:knowledge/advanced`     | Exercismの幅広い知識が必要       |

### モジュールタグ

`x:module/<value>`ラベルは、コントリビューターがExercismのどの部分に取り組むかを示します。

| タグ                         | 説明                         |
| ---------------------------- | ---------------------------- |
| `x:module/analyzer`          | アナライザーに取り組む       |
| `x:module/concept`           | コンセプトに取り組む         |
| `x:module/concept-exercise`  | コンセプト演習に取り組む     |
| `x:module/generator`         | 演習ジェネレーターに取り組む |
| `x:module/practice-exercise` | プラクティス演習に取り組む   |
| `x:module/representer`       | リプレゼンターに取り組む     |
| `x:module/test-runner`       | テストランナーに取り組む     |

### サイズタグ

`x:size/<value>`ラベルは、コントリビューターが行うと想定される作業量を表します。

| タグ             | 説明                 |
| ---------------- | -------------------- |
| `x:size/tiny`    | ごくわずかな作業量   |
| `x:size/small`   | 少ない作業量         |
| `x:size/medium`  | 中程度の作業量       |
| `x:size/large`   | 多い作業量           |
| `x:size/massive` | 膨大な作業量         |

### タイプタグ

`x:type/<value>`ラベルは、コントリビューターがどんな種類の作業をするかを表します。

| タグ             | 説明                                                                                                                                                                                                    |
| ---------------- | -------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| `x:type/ci`      | 継続的インテグレーション（CI）の作業（GitHub Actionsのワークフローなど）                                                                                                                                                 |
| `x:type/coding`  | 学習者向けのコンテンツには含まれないコードを書きます。通常は、プロダクションツール（テストランナーなど）、内部ツール（ジェネレーター）、またはExercismが保守しているライブラリに関連するタスクです。 |
| `x:type/content` | コンテンツ（演習やコンセプトなど）の作業                                                                                                                                                                     |
| `x:type/docker`  | Dockerfileの作業                                                                                                                                                                                            |
| `x:type/docs`    | ドキュメントの作業                                                                                                                                                                                          |

## 引き受け済みのタグと未引き受けのタグ

誰かがすでに作業しているタスクを非表示にするには、イシューに`x:status/claimed`ラベルを付けます。
