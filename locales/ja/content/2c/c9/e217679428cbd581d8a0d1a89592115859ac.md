# 概要

条件によってコードを実行するには、[`if/elif/else`式][conditional-expression]を使います。`if/elif/else`式で使う条件は、`bool`型である必要があります。F#には、_truthy_という概念はありません。

```fsharp
if x = 5 then
    printfn "x equals 5"
elif x > 7 then
    printfn "x is not 5 and greater than 7"
else
    printfn "x is not 5 and not greater than 7"
```

`if/elif/else`は式なので、名前に束縛したり、関数から返したりできます。

```fsharp
let message =
    if x = 5 then
        "x equals 5"
    elif x > 7 then
        "x is not 5 and greater than 7"
    else
        "x is not 5 and not greater than 7"
```

すべての分岐は同じ型を返す必要があります。そうでない場合はコンパイラエラーになります。

```fsharp
if x = 5 then
    true
elif x > 7 then
    5.6

// Results in compiler error
```

`else`と`elif`の分岐は省略できますが、それは返す式の型が[`unit`][unit-type]の場合だけです。

```fsharp
// Valid if expression
if x > 2 then
    printfn "x is greater than two"

// Invalid if expression, results in compiler warning
if x > 2 then
    true
```

`if/else`式は1行に書くこともできます。ただし、これは単純な`if`式にだけ使うようにしましょう。

```fsharp
let y = if x > 5 then 10 else 20
```
