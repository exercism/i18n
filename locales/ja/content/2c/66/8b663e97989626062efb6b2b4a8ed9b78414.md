# 説明

サッカークラブのウェブサイトで、スタッフが試合をレポートできるようにするシステムを開発しています。データはさまざまなソースから受け取り、クリーンアップされたあとに1つのストリームへまとめられます。

## 1. シャツの番号から選手の説明を出力する

このチームは4-3-3のフォーメーションしか使いません。選手交代を認める1965年のルール変更にも同意していませんし、ましてや選手層の拡大など問題外です。

選手の説明は次のとおりです。

```text
1 -> "goalie"
2 -> "left back"
3 & 4 "center back"
5 -> "right back"
6, 7, & 8 -> "midfielder"
9 -> "left wing"
10 -> "striker"
11 -> "right wing"
```

シャツの番号から選手の説明を出力するstaticな`FootballMatchReports.onField()`メソッドを実装しましょう。

```java
FootballMatchReports.onField(10);
// => "striker"
```

## 2. シャツの番号が公式リストに含まれない場合は"invalid"を出力する

1〜11の範囲外のシャツの番号が処理されたときは'invalid'を返すように、`FootballMatchReports.onField()`メソッドを修正しましょう。

```java
FootballMatchReports.onField(13);
// => "invalid"
```
