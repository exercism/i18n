# インストール

[コンパイル済みのUiuaバイナリ][releases]が用意されているので、自分でコンパイルする必要はありません。
最新の手順については、[公式インストールガイド][install-guide]を参照してください。IDE連携やフォントについても書かれています。

```exercism/note
現在、オンラインのテストランナーはバージョン`0.18.1`を使用しています。
Uiuaは開発のペースが速いため、このバージョンは変わる可能性があります。ウェブサイトで表示されるテスト結果を再現できないときは、この点を覚えておいてください。
```

任意の場所にダウンロードしたら、UiuaをシステムのPATHに追加する必要があります。

- **macOS:** Finderで`Applications > Utilities > Terminal`を開きます。どこからでもUiuaを実行できるようにするには、`export PATH="/path/to/uiua:$PATH"`と入力します。

- **Windows:** スタートメニューから「Edit Environment Variables」を開きます。「Path」にUiuaのフォルダーを追加します。

- **Linux:** ターミナルを開き、`~/.bashrc`または`~/.profile`に`export PATH="/path/to/uiua:$PATH"`を追加すると、すぐに使えるようになります。
