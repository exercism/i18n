# 説明

この演習では、Exercismのプラットフォームで練習する予定のプログラミング言語の配列を処理するコードを書きます。

この演習には6つのタスクがあります。

## 1. 新しい配列を作る

言語を追加するには、まず新しい配列を作るところから始める必要があります。空の配列を返す関数を定義しましょう。

```clojure
(new-list)
;; => ()
```

## 2. 配列に新しい言語を追加する

Exercismを眺めていて学びたい言語が見つかったら、それを自分の配列に追加できる必要があります。新しい言語を配列の先頭に追加する関数を定義しましょう。

```clojure
(add-language "JavaScript" '("Clojurescript"))
;; => '("JavaScript" "Clojurescript")
```

## 3. 最後に追加した言語を確認する

今追加したばかりの言語をすぐに確認したくなるでしょう。配列の最初の言語を返す関数を定義しましょう。

```clojure
(first-language '("Haskell" "Python"))
;; => "Haskell"
```

## 4. 配列から最初の言語を削除する

追加したばかりの言語について、気が変わることもあるでしょう。配列から最初の言語を削除する関数を定義しましょう。

```clojure
(remove-language '("Common Lisp" "Racket" "Scheme"))
;; => '("Racket" "Scheme")
```

## 5. 配列内の言語を数える

言語を1つずつ数えるのは面倒です。配列にある言語の数を数える関数を定義しましょう。

```clojure
(count-languages '("C#" "Racket" "Rust" "Ruby"))
;; => 4
```

## 6. すべてをまとめる

`learning-list`関数を定義しましょう。この関数の中では、上で定義したいくつかの関数を使います。

- 空の配列を作る
- 配列に新しいプログラミング言語を2つ追加する。

  - "Clojure"
  - "Lisp"

- 1年で学ぶには時間が足りないかもしれませんし、Clojureにとてもよく似ているので、配列から"Lisp"を削除する。
- さらにプログラミング言語を2つ追加する。

  - "Java"
  - "JavaScript"

- 言語の合計数を返す。ヒント：3になるはずです。

```clojure
(learning-list)
;; => 3
```
