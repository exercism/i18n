# `case`文

1つの値をいくつもの候補と比べるとき、`elsif`を連ねた書き方では、同じことを何度も繰り返すことになります。

```sather
   if zone = 0 then
      return 0;
   elsif zone = 1 then
      return 550;
   elsif zone = 2 then
      return 370;
   else
      return 920;
   end;
```

`case`なら、一度書くだけで済みます。

```sather
   case zone
   when 0 then return 0;
   when 1 then return 550;
   when 2 then return 370;
   else return 920;
   end;
```

比べる値は`case`のあとに書きます。それぞれの`when`には、比べる相手の値を書きます。最初に一致したものが実行されます。

## 1つの`when`に複数の値を書く

`when`には、カンマで区切って複数の値を並べられます。

```sather
   case day
   when "Sat", "Sun" then return "Weekend";
   when "Mon", "Tue", "Wed", "Thu", "Fri" then return "Weekday";
   else return "Unknown";
   end;
```

これは整数でも文字でも文字列でも使えます。`=`で比べられるものなら、何でもかまいません。

## `else`は省略できません

**どの`when`にも一致せず、`else`もない`case`は、エラーになり、その時点でプログラムが停止します。**

これは`if`とは違います。`if`で`else`を省略しても、何も起こらないだけです。ほとんどの言語とも違います。それらの言語では、どの`when`にも一致しなければ、何も起こらずに静かに通り過ぎます。

ですから、どの`case`にも`else`が必要です。`when`がすべての値を網羅していると確信していてもです。あとから4つ目のゾーンが追加され、`case`がそれに合わせて更新されないままだと、そのゾーンを使う最初の乗客のところでプログラムが止まってしまいます。

## 実行される`when`は1つだけ

`when`が一致すると、その`then`のあとの文が実行され、`case`はそこで終わります。プログラムは`end`のあとから続きます。その下にある`when`はまったく見られません。ですから、次の`when`が続けて実行されないようにするために、何かを書く必要はありません。
