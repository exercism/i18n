# 予期しない必須の仮引数

仮引数`${'parameter.name'}`は、テストの中で値がある場合とない場合の両方で呼び出されています。しかし、_省略可能としてマークされていない_ため、テストは通りません。TypeScriptでは、仮引数の後ろに`?`を付けて、省略可能であることを明示できます。

```typescript
function(${'parameter.name'}?: ${'parameter.type'}) {
  //
}
```

または、デフォルト値を代入する方法もあります。

```typescript
function(${'parameter.name'}: ${'parameter.type'} = <default>) {
  //
}
```
