# はじめに

一般的に、プログラミングでは車輪の再発明は避けたいものです。
多くの標準的なアルゴリズムには、すでに誰かが作ってくれているものがあります。

## インクルード

他のファイルの内容を取り込むために、C++では`include`ディレクティブを使います。
このインクルードは、ファイルの先頭に書きます。
コンパイルの際、そのディレクティブが書かれた行は、対応するファイルの内容に置き換えられます。
インクルードの後も、名前空間は元のファイルでの状態のまま保たれます。

## 標準ライブラリ

標準ライブラリには、よく使う関数やアルゴリズム、データ構造がたくさん用意されています。
標準ライブラリは`std`名前空間を使います。

その一例が、Cの数値演算ライブラリである`cmath`です。
よく使う数学の演算がたくさん用意されています。

```cpp
#include <cmath>

int cube_me(int a) {
    // raise `a` to the third power
    return std::pow(a, 3);
}
```

~~~~exercism/note
標準ライブラリは、二重引用符`"`ではなく山括弧`<>`でインクルードします。
この違いは、コンパイラーがそれぞれのファイルを探す場所にあります。
山括弧を使う場合は現在のプロジェクト内の検索が省略され、システムのインクルードディレクトリから直接探し始めます。
ローカルのファイルをインクルードしたいときは、二重引用符を使います：`#include "myfile"`
~~~~
