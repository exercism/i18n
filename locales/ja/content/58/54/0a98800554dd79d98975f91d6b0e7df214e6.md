# 説明の補足

## 実装

この演習を完了するには、データ型`Clock`を定義し、`BEq`と`ToString`のインスタンスを追加し、次の関数を実装する必要があります。

* `create`は、時間と分をそれぞれ表す、負の値もあり得る2つの整数を受け取り、有効なClockを生成します。
* `add`は、Clockと、そのClockの時刻に加算する分数を受け取り、新しいClockを生成します。
* `subtract`は、Clockと、そのClockの時刻から減算する分数を受け取り、新しいClockを生成します。

Clock型は、"00:00"から"23:59"までの24時間制の時刻を表すことに注意してください。

~~~~exercism/advanced
`Clock`の時間と分にはそれぞれ上限と下限があることに注意してください：

- `0 <= hour < 24`
- `0 <= minute < 60`

Leanでは、このような制約を型レベルで表現するのが慣用的で、そうすることで不正な値が_表現不可能_になります。
ただし、そのためには、与えられた値がこれらの制約を満たすことを_証明_する必要もあります。
