# 説明

イベントを取り込むサービスを書くことになりました。各イベントには日付が紐づいていますが、サービスのエンドポイントには3つの異なる形式が送られてくることに気づきます。

- `"01/01/1970"`
- `"January 1, 1970"`
- `"Thursday, January 1, 1970"`

それぞれに共通点があることに気づき、組み合わせ可能な正規表現パターンを書くことにします。

## 1. 日付から日、月、年をマッチさせる

`day/0`、`month/0`、`year/0`を実装し、コンパイルすると`"01/01/1970"`（`dd/mm/yyyy`）の数値部分にマッチする文字列パターンを返すようにしましょう。日と月は`1`または`01`（0で左詰め）のように現れることがあります。

```elixir
"31" =~ DateParser.day() |> Regex.compile!()
# => true
"12" =~ DateParser.month() |> Regex.compile!()
# => true
"1970" =~ DateParser.year() |> Regex.compile!()
# => true
```

## 2. 曜日と月名をマッチさせる

`day_names/0`と`month_names/0`を実装し、コンパイルするとそれぞれ曜日名と月名にマッチする文字列パターンを返すようにしましょう。

```elixir
"Tuesday" =~ DateParser.day_names() |> Regex.compile!()
# => true
"June" =~ DateParser.month_names() |> Regex.compile!()
# => true
```

## 3. 日、月、年をキャプチャする

`capture_day/0`、`capture_month/0`、`capture_year/0`、`capture_day_name/0`、`capture_month_name/0`を実装し、それぞれの部分を`"day"`、`"month"`、`"year"`、`"day_name"`、`"month_name"`という名前でキャプチャする文字列パターンを返すようにしましょう。

```elixir
DateParser.capture_month_name()
|> Regex.compile!()
|> Regex.named_captures("December")

# => %{"month_name" => "December"}
```

## 4. キャプチャを組み合わせて日付全体をキャプチャする

`capture_numeric_date/0`、`capture_month_name_date()`、`capture_day_month_name_date/0`を実装し、パート3の各部分を、それぞれの日付形式に従ってキャプチャする文字列パターンを返すようにしましょう。

- 数値の日付 - `"01/01/1970"`
- 月名の日付 - `"January 1, 1970"`
- 曜日と月名の日付 - `"Thursday, January 1, 1970"`

```elixir
DateParser.capture_numeric_date()
|> Regex.compile!()
|> Regex.named_captures("01/01/1970")

# => %{"day" => "01", "month" => "01", "year" => "1970"}
```

## 5. キャプチャを絞り込んで日付だけにマッチさせる

`match_numeric_date/0`、`match_month_name_date/0`、`match_day_month_name_date/0`を実装し、日付だけにマッチし、かつ各部分をキャプチャできるコンパイル済みの正規表現を返すようにしましょう。

```elixir
"Thursday, January 1, 1970 was the Unix epoch." =~ DateParser.match_day_month_name_date()
# => false
"Thursday, January 1, 1970" =~ DateParser.match_day_month_name_date()
# => true

DateParser.match_day_month_name_date()
|> Regex.named_captures("Thursday, January 1, 1970")

# => %{
#     "day" => "1",
#     "day_name" => "Thursday",
#     "month_name" => "January",
#     "year" => "1970"
#   }
```
