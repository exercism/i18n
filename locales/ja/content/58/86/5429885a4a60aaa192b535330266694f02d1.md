# はじめに

## 比較演算子

Rには、他の多くの言語と同じ演算子がそろっています。

```R
1 == 2 # FALSE
1 != 2 # TRUE
1 < 2 # TRUE
1 > 2 # FALSE
1 <= 2 # TRUE
1 >= 2 # FALSE
```

## 分岐

if-elseの基本形は次のとおりです。

```R
if (x > 10) {
    y <- "big"
} else if (x > 2) {
    y <- "medium"
} else {
    y <- "tiny"
}
```

この場合、真偽値の周りの括弧（`()`）と、文の周りの波括弧（`{}`）はどちらも必要です。
単純な`if`文は、次のように短く書けます。

```R
if (x == 0) return("success")
```
