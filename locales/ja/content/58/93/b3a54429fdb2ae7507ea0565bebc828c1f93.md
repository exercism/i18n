# 概要

[ガード][guards]は、[パターンマッチング][exercism-pattern-matching]を補うものとして使います。パターンマッチングは、後の概念で扱います。
ガードを使うと、入力の値に応じて関数の実装を変えられます。また、より複雑な条件をチェックできます。

ガード文は、パイプ`|`とそれに続く真偽値の式で定義し、最後に等号`=`とその関数の本体を書きます。
1つの関数に複数のガード文を書くことができます。
ガード文は上から下へ順に評価され、最初に`True`と評価されたものが実行されます。
ガード文では`otherwise`を書くことができます。これは、それまでのガード文に一致しなかったすべての値を受け止めます。

```haskell
isEven :: Int -> String
isEven n
    | even n = "n is even"
    | otherwise = "n is odd"
```

自分で関数を定義して、それをガード文の中で使うこともできます。

```haskell
isEven' :: Int -> Bool
isEven' n = even n

isEven :: Int -> String
isEven n
    | isEven' n = "n is even"
    | otherwise = "n is odd"
```
