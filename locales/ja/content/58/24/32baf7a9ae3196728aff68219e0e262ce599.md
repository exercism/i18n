# 文字列

`String`データ型は、UTF-8でエンコードされた文字が一列に並んだものです。テキストデータを保存するのに役立ちます。

## 文字列を作成する

文字列は、`String::new()`や`String::from()`といった関連関数を使って作成できます。多くの型には、たとえば数値から文字列を生成する`to_string`メソッドが用意されています。

```rust
let my_string = String::from("The answer is");
let answer = 42.to_string();
println!("{my_string} {answer}");
```

### `format!`マクロ

複数の小さなデータ型から大きな文字列を組み立てるのはよくある操作なので、Rustには、`to_string`を呼び出す手間を省いてくれる省略記法も用意されています。それが`format!`マクロです。たとえば、先ほどの複合的な文字列の組み立ては、次のように簡略化できます。

```rust
let the_answer = format!("{} {}.", "The answer is", 42);
assert_eq!("The answer is 42.", the_answer);
```

## 文字列スライス

文字列は、文字列スライスと密接な関係があります。文字列スライスは、UTF-8でエンコードされた文字が一列に並んだ、サイズがわかっているメモリ領域への不変の参照です。どの文字列も、参照外し演算子（`&`）を使って借用することで、文字列スライスに変換できます。文字列スライスを文字列に変換するには、`to_string()`メソッドか`String::from`のどちらを使ってもかまいません。

Rustのコードでは、文字列リテラルは二重引用符で囲みます。こうした文字列リテラルは常に文字列スライスです。というのも、プログラムの実行ファイル内の不変のメモリ領域を参照しているからです。

```rust
let string = String::from("string");
let slice = "string";
assert_eq!(slice, &string);
```

## 文字列を変更する

文字列に1文字を連結するには、`push`メソッドを使います。文字列に文字列スライスを連結するには、`push_str`メソッドか`+`演算子を使います。

```rust
fn main() {
    // For demonstration purposes, we're not using `format!`
    let s1 = String::from("tic");
    let s2 = String::from("tac");
    let s3 = String::from("toe");

    let s = s1 + "-" + &s2 + "-" + &s3;
    println!("{s}");
}
```

## 文字列内の文字にアクセスする

Rustの文字列はUTF-8でエンコードされているため、個々の文字がすべて同じサイズとは限りません。そのため、`String`データ型にはインデックス演算子（`[]`）がありません。文字列内のすべての文字、または特定の文字にアクセスするには、`chars()`メソッドを使います。これは文字列内の各文字を順番に繰り返し処理します。

```rust
let alphabet: String = ('a'..='z').collect();
for c in alphabet.chars() {
    println!("{c}");
}
let j = alphabet.chars().nth(9);
println!("{j:?}"); // prints Some('j')
```
