Markdown文書の中でこれらのウィジェットを自分で表示することもできます。たとえば、文書の最後に置いて、さらに読むとよい資料や、学習に役立つ演習を提案することができます。

**補足:** インラインテキストには通常のリンクも使えます。その場合、ツールチップが自動で追加されます。詳しくは、[内部リンクのドキュメント](/docs/building/markdown/internal-linking)をご覧ください。

## 使い方

ウィジェットは、Markdownを使える場所ならどこでも使用できます。たとえば、ドキュメント、アプローチ、学習者とメンターのディスカッションなどです。

次の形式で表示されます。

```md
[<type>:<id>]()
```

`<type>`と`<id>`の部分は可変で、使用するウィジェットによって異なります。

リンク参照、つまり`()`の中身は、ウェブサイトでは無視されます。メンテナンス目的で、好きな内容を指定してかまいません。

## 演習ウィジェット

リンク形式は`[exercise:<track-slug>/<exercise-slug>]()`です。

### 例

```markdown
Great job on solving this exercise! Some other exercises that you might also like to try:

- [exercise:fsharp/anagram]()
- [exercise:fsharp/isogram]()
```

## コンセプトウィジェット

リンク形式は`[concept:<track-slug>/<concept-slug>]()`です。

### 例

```markdown
There are three primary conditional statements that are used in Julia:

- [concept:julia/if-statements]()
- [concept:julia/ternary-operator]()
- [concept:julia/short-circuiting]()
```

## アプローチウィジェット

リンク形式は`[approach:<track-slug>/<exercise-slug>/<approach-slug>]()`です。

### 例

```markdown
Here are some approaches you might want to checkout!

- [approach:csharp/two-fer/method-overloading]()
- [approach:csharp/two-fer/optional-parameter]()
```

## 記事ウィジェット

リンク形式は`[article:<track-slug>/<exercise-slug>/<article-slug>]()`です。

### 例

```markdown
We have an article you might be interested in:

- [article:csharp/reverse-string/performance]()
```
