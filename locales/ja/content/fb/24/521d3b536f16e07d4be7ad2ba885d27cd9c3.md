# 概要

フィルタリングとは、あるシーケンスから別のシーケンスを作る操作で、元のシーケンスの要素のうち特定のものを除いてコピーします。
新しいシーケンスにどの要素を含めるかは、述語関数（真偽値に評価される関数）で決めることもできますし、特定のオブジェクトとの等価性で決めることもできます。

## 述語で取り除く

`remove-if`は、述語関数とシーケンスを引数に取り、述語が偽に評価された要素だけを集めたシーケンスを返す関数です。
言い換えると、述語が真に評価されたシーケンスの要素をすべて「取り除き」ます。ただし、この関数は元のシーケンスを変更しないことに注意してください！
代わりに、該当する要素を取り除いた新しいシーケンスを返します。すべての値で述語が真だった場合は、空のシーケンスが返されます。

```lisp
(remove-if #'evenp '(1 2 3 4 5)) ; => (1 3 5)
(remove-if #'oddp '(1 3 5))      ; => ()
```

## 述語で要素を残す

`remove-if-not`という関数があります。これは`remove-if`とほぼ同じですが、述語が真に評価された要素を*残す*という点だけが違います。

別の方法として、`complement`を使って述語を「反対」の述語に変えることもできます。

```lisp
(remove-if #'evenp '(1 2 3 4 5 6))             ; => (1 3 5)
(remove-if-not #'oddp '(1 2 3 4 5 6))          ; => (1 3 5)
(remove-if (complement #'oddp) '(1 2 3 4 5 6)) ; => (1 3 5)
```

## 特定の要素を取り除く

シーケンスから特定の要素を取り除きたいときは、`remove`を使います。これは取り除きたい要素とシーケンスを引数に取ります。
シーケンスの中で、取り除きたい要素と等しくない値がすべて返されます。

```lisp
(remove 1 '(1 2 1 3 1 4)) ; => (2 3 4)
(remove #\l "hello")      ; => "heo"
```

等価性の判定に使う関数は、`:test`[キーワードパラメータ][concept-keyword-parameters]で指定できます。

`remove`は、あるオブジェクトが特定の要素と等しいかどうかを調べる述語を書くことで、`remove-if`を使って実装できることに注意してください。

## さまざまなオプション

これらの関数はそれぞれ、ほかにも多くの[キーワードパラメータ][concept-keyword-parameters]を取り、部分シーケンスだけを対象にしたり、適用回数を指定したりすることができます。詳しくは[Hyperspecのドキュメント][hyperspec-remove]を参照してください。


## 破壊的なオプション

`remove`、`remove-if`、`remove-if-not`に加えて、`delete`、`delete-if`、`delete-if-not`もあります。これらは同じ効果を持ちますが、渡されたシーケンスを変更する可能性がある点が異なります。
