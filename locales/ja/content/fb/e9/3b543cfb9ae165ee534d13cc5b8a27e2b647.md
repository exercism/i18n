# 説明

突然パンケーキが無性に食べたくなりました。
現代の技術に詳しい人らしく、パンケーキの材料の買い物リストをJSON形式で書くことにします。
リストの構造は次のとおりです。

```json
{
  "name": "name of shopping list",
  "ingredients": [ ...list of ingredients... ],
  "optional ingredients": [ ...list of ingredients... ]
}
```

材料は、次のようなJSONオブジェクトで表します。

```json
{
  "item": "flour",
  "amount": {
    "quantity": 2,
    "unit": "cup"
  }
}
```

材料には、代わりに使える別の品目の文字列を保持する、`"substitute"`という任意のプロパティがあります。

`jq`を使って買い物リストを調べる方法を見てみましょう

## 1. 買い物リストの名前を取り出す

買い物リストの"name"要素を出力する式を書きましょう。

## 2. 必要な材料の数を数える

必須の材料だけを数えましょう。任意の材料は含めないでください。

## 3. 砂糖はどのくらい？

砂糖の量を出力する式を書きましょう。必要なのは数値の部分だけです。

## 4. 代用できる材料をマッピングする

材料の中には代用できるものがあります（材料XがないときはYを使えます）。推奨される材料をその代用品に対応付けるJSONオブジェクトを出力しましょう。マッピングには任意の材料も含めてください。
