# 概要

Swiftの`guard`文は、処理を続けるために必要な条件が満たされていないときに、関数から早期リターンするために使います。たとえば、次のとおりです。

```swift
guard myValue = 0 else { return 0 }
let root = myValue.squareRoot()
```

ここでは、`guard`は、`guard`キーワードに続く真偽値の式が`true`と評価されるかどうかを確認します。`true`と評価されれば、guard文に続くコード（ここでは`let root = myValue.squareRoot()`）がそのまま実行されます。そうでなければ、else節のコードが実行されます。`if`文とは違い、`guard`文にはelse節が_必ず_必要です。また、if-elseのelse節とは違い、guardのelse節は、guard文のスコープから_必ず_抜けなければなりません。つまり、`return`や`continue`、`break`のような制御転送文を使うか、エラーをスローするか、プログラムを終了しなければなりません。

使用例として、sinc関数があります。sinc関数はsin(x)/xに等しく、sinc(0)を1と定義することで、0による除算の問題を避けています。この関数は、`guard`を使って次のようにSwiftで書けます。

```swift
func sinc(_ x: Double) -> Double {
    guard x != 0 else { return 1 }
    return sin(x) / x
}

sinc(0)              // returns 1
sinc(Double.pi / 2)  // returns 0.6366197723675814
```
