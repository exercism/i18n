# 不要な条件分岐

この解答では、[条件分岐][conditionals]が不要に使われています。
[デフォルト引数][default argument]と、[str.format][str.format]または[f-strings][f-strings]（_別名「書式付き文字列リテラル」や「補間文字列」_）を組み合わせて使うと、コードをより明確で簡潔にできます。

詳しくは、[Pythonのデフォルト引数][python default arguments]に関するこちらの記事をご覧ください。
ブログ記事[Pythonの文字列フォーマット][string formatting in python]も、Pythonの文字列フォーマットの選択肢を学ぶための良い出発点になるでしょう。
