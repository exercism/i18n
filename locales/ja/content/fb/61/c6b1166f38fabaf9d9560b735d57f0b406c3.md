# Elmの構文の基本1

## 定数と関数

Elmのプログラムは、定義と式からできています。
Elmでは、すべてが定義か式のどちらかです。

定数の値は、`name = expression`のように定義します。

```elm
five = 5

six = 3 + 3
```

関数は`name parameters... = expression`の形で定義します。入力はスペースで区切るだけです。

```elm
add number1 number2 = number1 + number2
```

関数を呼び出すのも式のひとつです。関数の名前を書き、それぞれの入力に渡す値をスペースで区切って並べます。書き方は関数を定義するときと同じです。

```elm
five = add 2 3
```

括弧（`()`）を使うと、式が評価される順序を指定できます。

```elm
six = add 2 (1 * 4)

twelve = add 2 1 * 4
```

## インデントと空白の意味

Elmでは、コードのまとまりを示すのに波括弧（`{}`）や丸括弧（`()`）、セミコロンといった文法上の記号を使いません。その代わりに、空白とインデントを使います。

- モジュール、`import`、トップレベルの関数定義は、いちばん左の列から始めなければなりません。
- 式を複数の行に分ける場合、その式の一部であるコードは、その式の下で1つ以上のスペース分インデントする必要があります。
- ひとまとまりになっている式の部分は、同じ数のスペースでインデントします。

```elm
-- A function split over multiple lines, so subsequent lines must be indented
add number1 number2 =
    number1 + number2
```

https://elmprogramming.com/indentation.html

## モジュール

Elmでは、それぞれのファイルがモジュールです。そして、他のどのコードよりも前に`module`文を書かなければなりません。
モジュール名はファイル名と一致している必要があります。つまり、モジュール`Calculator`はファイルCalculator.elmの中に置きます。
モジュール内で定義されたものは、そのモジュールだけのスコープを持ち、`exposing`に挙げられていない限り、このモジュールの外からアクセスすることはできません。

```elm
-- Define the Calculator module, and expose the `add` function
module Calculator exposing (add)

six = 3 + 3

add number1 number2 = number1 + number2
```

```elm
-- Define the Calculator module, and expose everything within: `six` and `add`
module Calculator exposing (..)

six = 3 + 3

add number1 number2 = number1 + number2
```

https://elm-lang.org/docs/syntax#modules

## コメント

コメントとは、Elmのファイルの中にある、コードとして解釈されないテキストのことです。
主に、自分自身や他のプログラマーが読むためのものです。
1行コメントには、二重のハイフンを使った手軽な書き方があります。
複数行のコメントも、開きと閉じの区切りになる`{-`と`-}`のペアを使えば書けます。

```elm
-- a single line comment
-- another single line comment

{- a multiline comment
   spawning multiple lines
-}
```
