# はじめに

Swiftでは、`string[3]`のように整数を使って文字列の1文字にアクセスすることはできません。Swiftの文字列は長さの異なるUnicode文字で構成されているため、目的の文字を見つけるには、それより前の文字を順にたどる必要があります。

特定の位置の文字にアクセスするには、`String.Index`型のインデックスを計算する必要があります。このインデックスは*不透明インデックス*と呼ばれます。内部構造をSwiftが管理していて、生の整数のように直接操作することはできないためです。

```swift
let csv = "apple,pear,peach,orange,cherry,lime,gooseberry"
let index = csv.index(csv.startIndex, offsetBy: 21)
print(csv[index])
// Prints "g"

print(index)
// Prints internal representation: Index(_rawBits: ...)
```
