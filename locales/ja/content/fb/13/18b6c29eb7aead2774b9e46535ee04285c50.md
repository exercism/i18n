# 説明

この演習では、ログ行を処理します。

ログ行はそれぞれ、`"[<LEVEL>]: <MESSAGE>"`という形式の文字列です。

ログレベルは3種類あります。

- `INFO`
- `WARNING`
- `ERROR`

タスクはいくつかあり、それぞれが1つのログ行を受け取って、それに対して何かを行うものです。

## 1. 特定の部分文字列より後ろの文字列を取得できるようにする

先月のログを見てみると、テストメッセージがいつも特定の部分文字列の後ろにあることがわかります。近いうちにテストメッセージを取り出す必要が出てきそうなので、そのためのヘルパーメソッドを作ることにします。

実装するのは、何らかの文字列の区切り文字を受け取り、その区切り文字より後ろの部分文字列を返す、（_static_）`LogAnalysis.SubstringAfter()`拡張メソッドです。

```csharp
var log = "[INFO]: File Deleted.";
log.SubstringAfter(": "); // => returns "File Deleted."
```

## 2. 2つの部分文字列の間にある文字列を取得できるようにする

さらに詳しく調べてみると、ログレベルはいつも角括弧（`[`と`]`）の間にあることがわかります。こちらも近いうちにログレベルを取り出す必要が出てきそうなので、そのためのヘルパーメソッドをもう1つ作ることにします。

実装するのは、2つの文字列の区切り文字を受け取り、その2つの区切り文字の間にある部分文字列を返す、（_static_）`LogAnalysis.SubstringBetween()`拡張メソッドです。

```csharp
var log = "[INFO]: File Deleted.";
log.SubstringBetween("[", "]"); // => returns "INFO"
```

## 3. ログからメッセージを解析する

実装するのは、ログに含まれるメッセージを返す、（_static_）`LogAnalysis.Message()`拡張メソッドです。

```csharp
var log = "[ERROR]: Missing ; on line 20.";
log.Message(); // => returns "Missing ; on line 20."
```

## 4. ログからログレベルを解析する

実装するのは、ログのログレベルを返す、（_static_）`LogAnalysis.LogLevel()`拡張メソッドです。

```csharp
var log = "[ERROR]: Missing ; on line 20.";
log.LogLevel(); // => returns "ERROR"
```
