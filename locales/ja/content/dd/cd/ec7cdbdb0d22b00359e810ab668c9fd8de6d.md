# 説明

この演習では、プログラミング言語の配列を操作するためのいくつかの関数を実装します。

## 1. 空の言語の配列を返す関数を定義する

入力を受け取らず、空の配列を返す`new`関数を定義します。

```haskell
new
-- -> []
```

## 2. 言語を配列に追加する関数を定義する

2つの入力（_言語の配列_ と、_言語_ の文字列リテラル）を取る`add/2`関数を定義します。
与えられた配列の先頭に新しい言語を追加した、結果の配列を返します。

```haskell
add new "Clojure"
-- -> ["Clojure"]
add ["Clojure"] "Haskell"
-- -> ["Haskell", "Clojure"]
```

## 3. 言語を配列から削除する関数を定義する

1つの入力（_言語の配列_）を取る`remove`関数を定義します。
先頭の要素を除いた配列を返します。配列には常に少なくとも1つの要素があると仮定します。

```haskell
remove ["Haskell", "Clojure", "Erlang"]
-- -> ["Clojure", "Erlang"]
```

## 4. 配列の先頭の要素を返す関数を定義する

1つの入力（_言語の配列_）を取る`first`関数を定義します。
配列の最初の言語を返します。
配列には常に少なくとも1つの要素があると仮定します。

```haskell
first ["Elixir", "Haskell", "Clojure", "Prolog"]
-- -> "Elixir"
```

## 5. 配列にある言語の数を返す関数を定義する

1つの入力（_言語の配列_）を取る`count`関数を定義します。
配列にある言語の数を返します。

```haskell
count ["Prolog", "Elm"]
-- -> 2
```

## 6. 配列に関数型言語が含まれているかを判定する関数を定義する

1つの入力（_言語の配列_）を取る`isFunctionalList`関数を定義します。
真偽値を返します。
配列に含まれる言語の1つが _"Haskell"_ であれば`True`を返します。

```haskell
isFunctionalList ["Haskell"]
-- -> True
```
