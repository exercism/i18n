# 指示の補足

## トラック固有の指示

「Yacht」の演習では、ゲーム「Yacht」でサイコロを5つ振ったときのスコアを、選んだカテゴリーに基づいて計算する動詞を作ります。

この演習で、動詞は次の2つの引数を受け取ります。

- **左の引数**：サイコロの目に適用するスコアのカテゴリーを表す文字列。
- **右の引数**：振った5つのサイコロを表す整数の配列。

動詞は、これらの入力を次のように処理するように定義します。

```j
  category =. 'Full House'
  dice     =. 1 3 3 3 5
  
  category scoreYacht dice
```
