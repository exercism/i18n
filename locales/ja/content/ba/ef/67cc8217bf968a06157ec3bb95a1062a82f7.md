# ヒント

## 1. 新しいリストの作り方

- Common Lispには、_LIST_を作るための[とてもわかりやすい名前の関数][hyper-list]があります。

## 2. リストに要素を追加する

- リストの先頭に要素を追加するには、その要素を`car`、元のリストを`cdr`にした新しいリストを*CONS*tructするのが一般的です。Hyperspecには、この関数を説明した[ページ][hyper-cons]があります。

## 3. リストのn番目の要素は？

- Common Lispには、[リストの任意のインデックスから][hyper-nth]要素を取得する汎用関数があります。
- また、11未満のインデックスにアクセスするための[いくつかのヘルパー][hyper-first-tenth]もあります。
- リストのインデックスは0から始まります。

## 4. リストから要素を削除する

- リストの最初の要素を削除する一般的な方法は、リストの`car`と`cdr`を分ける関数を使うことです。Hyperspecには、これを行う関数の1つを説明した[ページ][hyper-rest]があります。

## 5. 小さなリストから大きなリストを作る

- Common Lispには、[あるリストを別のリストの先頭に追加するための][hyper-append]関数があります。

## 6. 長さはどれくらい？

- Common Lispには、リストの長さを取得する[名前のとおりの][hyper-length]関数があります。
