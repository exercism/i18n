# 説明

学校の公演で、キュー出しを担当することになりました。ステージマネージャーは、誰でもキュー出しを任せられるように、決まった台詞を書き留めておいてほしいと考えています。

やることは4つあり、どれも`STAGE_DIRECTIONS`クラスに含まれます。

## 1. 開演を告げる

ショーの始まりを告げる台詞を返します。

```sather
STAGE_DIRECTIONS::opening_line
-- => "The curtain rises."
```

## 2. 休憩を告げる

休憩のときに告げる台詞を返します。

```sather
STAGE_DIRECTIONS::interval_line
-- => "Interval. Fifteen minutes."
```

## 3. 終演を告げる

ショーの終わりを告げる台詞を返します。

```sather
STAGE_DIRECTIONS::closing_line
-- => "The curtain falls."
```

## 4. 最後のキューを出す

最後のキューは、ショーの終わりを告げる台詞と同じです。同じテキストをもう一度書くのではなく、すでに書いたルーチンを呼び出します。

```sather
STAGE_DIRECTIONS::final_cue
-- => "The curtain falls."
```
