# 説明

図をもとに、幼稚園のクラスの子どもたちがそれぞれどの植物を担当しているかを求めてください。

幼稚園のクラスでは、植物を育てることについて学んでいます。先生は、実際の種を子どもたちに渡し、それを実際の土に植えて、実際の植物を育ててもらうのがよい考えだと思いました。

育てることにしたのは、grass、clover、radishes、violetsです。

そのために、子どもたちは窓辺に小さなカップを並べ、それぞれのカップに、用意された種類の種の中からランダムに1種類を選んで植えました。

```text
[window][window][window]
........................ # each dot represents a cup
........................
```

クラスには12人の子どもがいます。

- Alice, Bob, Charlie, David,
- Eve, Fred, Ginny, Harriet,
- Ileana, Joseph, Kincaid, and Larry.

それぞれの子どもには4つのカップが割り当てられ、各列に2つずつあります。先生は、名前のアルファベット順に子どもたちへカップを割り当てます。

次の図は、Aliceの植物を表しています。

```text
[window][window][window]
VR......................
RG......................
```

窓にいちばん近い1列目には、violetとradishがあります。2列目には、radishとgrassがあります。

プログラムには、窓にいちばん近い列を先頭にして、植物が左から右へと与えられます。それをもとに、どの植物がどの生徒のものかを判断できます。

たとえば、庭が次のようになっていると伝えられたとします。

```text
[window][window][window]
VRCGVVRVCGGCCGVRGCVCGCGV
VRCCCGCRRGVCGCRVVCVGCGCV
```

このとき、Aliceの植物を求められると、次のようになります。

- Violets, radishes, violets, radishes

一方、Bobの植物を求めると、次のようになります。

- Clover, grass, clover, clover
