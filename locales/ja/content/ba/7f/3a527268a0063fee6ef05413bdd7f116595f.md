# はじめに

## クラス

C#の中心となるオブジェクト指向の構成要素は、_クラス_です。クラスは、データ（_フィールド_）と振る舞い（_メソッド_）を組み合わせたものです。クラスのフィールドとメソッドは、その_メンバー_と呼ばれます。

メンバーへのアクセスは、アクセス修飾子で制限できます。よく使われるのは次の2つです。

- `public`：メンバーはどのコードからもアクセスできます（制限なし）。
- `private`：メンバーは同じクラス内のコードからしかアクセスできません。

クラスは、そのクラスのインスタンスを作るためのテンプレートだと考えることができます。クラスのインスタンス（_オブジェクト_とも呼ばれます）を作るには、`new`キーワードを使います。

```csharp
class Car
{
}

// Create two car instances
var myCar = new Car();
var yourCar = new Car();
```

フィールドには型があり、クラス内のどこにでも定義できます。
`public`フィールドはパスカルケースで、`private`フィールドはキャメルケースで定義し、先頭にアンダースコア`_`を付けます。

```csharp
class Car
{
    // Accessible by anyone
    public int Weight;

    // Only accessible by code in this class
    private string _color;
}
```

フィールドには、必要に応じて初期値を代入できます。フィールドに初期値を指定_しない_場合、そのフィールドは型の既定値に設定されます。インスタンスのフィールドの値には、ドット記法を使ってアクセスしたり更新したりできます。

```csharp
class Car
{
    // Will be set to specified value
    public int Weight = 2500;

    // Will be set to default value (0)
    public int Year;
}

var newCar = new Car();
newCar.Weight; // => 2500
newCar.Year;   // => 0

// Update value of the field
newCar.Year = 2018;
```

`private`フィールドは通常、メソッドを呼び出した副作用として更新されます。このようなメソッドは通常、値を返しません。その場合、戻り値の型は`void`にする必要があります。

```csharp
class CarImporter
{
    private int _carsImported;

    public void ImportCars(int numberOfCars)
    {
        // Update private field from public method
        _carsImported = _carsImported + numberOfCars;
    }
}
```
