# はじめに

多くのプログラミング言語には、存在しない値を表すために`null`や`none`といった方法があります。
Rは大量の（しばしば乱雑な）データを扱えるように設計されているため、「何もないこと」を表す形が複数あります。

全体としての狙いは、欠けている値や疑わしい値に出会った時点でそれに印を付け、例外を発生させずに処理を続けることです。

## NULL

値が本当に存在しない場合、それは`NULL`で表されます。これはおそらく、CやPythonのやり方に最も近いものです。

```R
v <- c() # zero-length vector
v
#> NULL
is.null(v)
#> [1] TRUE
```

多くの場面で、`NULL`の値は単に無視されます。

```R
c(2, 3, NULL, 5)
#> [1] 2 3 5
```

## NA

値は存在するけれど、それが何なのかわからない状況では、`NA`を使います。たとえば、道路を走る車を数えるとき、人間の観測者が病気で休んだり、自動センサーが故障したりすることがありますが、交通の流れは続いていきます。

```R
v <- c(1, 2, NA, 4, 5)
v
#> [1]  1  2 NA 4  5
is.na(v) # test for data gaps
#> [1] FALSE FALSE  TRUE FALSE FALSE
```

このように、`NA`はプレースホルダーであり、これをどう扱うかを決める必要があると人間に警告します。

## 空のベクトル

意外かもしれませんが、Rには「空であること」を調べる標準的な方法がありません。ただし、一部のサードパーティ製パッケージは`is.empty()`のような独自の関数を実装しています。

空のベクトルを生成することさえ、それほど明らかではありません。
前のセクションで見たように、引数なしの`c()`はベクトルではなく`NULL`を返します。

```R
is.vector(c())
#> [1] FALSE
```

`logical()`や`integer()`といった関数は、望む長さを指定する引数を取ります。この長さは0にすることもできます。

```R
z <- logical(0)
is.vector(z)
#> [1] TRUE
length(z)
#> [1] 0
```

[ベクトルの概念][concept-vectors]で説明したように、ベクトルを生成してからすべての要素を削除することもできます。
こうすると、適切な型の長さ0のベクトルになります。

```R
v <- 5
v[-1]  # delete the first element
#> numeric(0)
```
