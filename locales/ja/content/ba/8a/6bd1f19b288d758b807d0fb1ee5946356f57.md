# インストール

Exercismでは、ブラウザーから直接ABAPのコードを書いてテストできます。追加のインストールは必要ありません。ただし、自分の環境でコードを書いてテストしたい場合は、ABAPのトライアルシステムを用意することもできます。

もちろん、勤務先でSAPを運用しているということもあるでしょう。ABAPの開発サンドボックスにアクセスできるかどうか、またその方法については、IT部門に確認してください。

## どのバージョンを選ぶか

アクティブサポートが継続している、現行リリースのABAPプラットフォームを使うことをおすすめします。現時点では**ABAP 7.5以上**です。現行リリースとそのサポート期間の詳細は、[SAP Developer Center](hhttps://developers.sap.com/tutorials/mission-get-started-with-abap-development-on-premise)にあります。

## 何をインストールするか

最新の[ABAP Cloud Developer Trial](https://hub.docker.com/r/sapse/abap-cloud-developer-trial)を使うことをおすすめします。これはABAP 7.58をベースにしています。SAP ABAPシステムは、Dockerイメージとしてインストールすることも、SAP Cloud Appliance Libraryでホストされているものを利用することもできます。さらに、お使いのオペレーティングシステムに応じて、Windows用またはJava用のSAP GUIをインストールする必要があります。SAP GUIは[こちら](https://www.sap.com/products/try-sap/trials-downloads.html?search=sap+gui)からダウンロードできます。

詳しくは、こちらの[SAP Community](https://community.sap.com/t5/technology-blog-posts-by-sap/abap-cloud-developer-trial-2023-available-now/ba-p/14057183)のブログを参照してください。
