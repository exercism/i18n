# はじめに

## 構造体

C#の`struct`は`class`とよく似ています。どちらも状態と振る舞いを持ちます。引数を受け取るコンストラクターがあり、インスタンスは代入したり、同じかどうかを比較したり、コレクションに格納したりできます。

```csharp
enum Unit
{
    Kg,
    Lb
}
struct Weight
{
    private double count;
    private Unit unit;

    public Weight(double count, Unit unit)
    {
        this.count = count;
        this.unit = unit;
    }

    public override string ToString()
    {
        return count.ToString() + unit.ToString();
    }
}

new Weight(77.5, Unit.Kg).ToString();
// => "77.6Kg"
```
