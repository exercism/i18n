# テストの実行

対象の演習のテストを実行するには、そのフォルダーに`cd`して、次のように実行します：

```bash 
box task run TestRunner
# Or start up a test watcher that will rerun when files change
box task run TestRunner --:watcher
```

テストには、xUnitとBDDスタイルのテストをサポートするTestBoxというライブラリを使います。すべてのテストスイートは、クロージャを使ってテスト仕様を定義する[BDDスタイル](https://testbox.ortusbooks.com/content/primers/bdd/specs.html)で書かれます。TestBoxのインストールを心配する必要はありません。CLIのテストランナーがその処理をしてくれます。初めて実行するときだけ、インターネットに接続している必要があります。詳しくはこちらから読むことができます：

[https://testbox.ortusbooks.com](https://testbox.ortusbooks.com)
