# 説明

あなたの課題は、次のルールを使って英語のテキストをピッグ・ラテンに翻訳することです：

- **ルール1**：単語が母音の音で始まる場合、その単語の末尾に"ay"の音を付けます（例："apple" -> "appleay"）。
  "xr"と"yt"が単語の先頭にある場合は母音の音になることに注意してください（例："xray" -> "xrayay"、"yttria" -> "yttriaay"）。
- **ルール2**：単語が子音の音で始まる場合、その子音を単語の末尾に移動し、次に"ay"の音を単語の末尾に付けます（例："pig" -> "igpay"）。
  子音の音は複数の子音からできていることがあります。たとえば"chair"の"ch"や"stand"の"st"です（例："chair" -> "airchay"）。
- **ルール3**：単語が子音の音の後に"qu"が続く形で始まる場合、それらを単語の末尾に移動し、次に"ay"の音を単語の末尾に付けます（例："square" -> "aresquay"）。
- **ルール4**：単語が子音の連続の後に"y"を含む場合、または2文字の単語の2番目の文字として"y"を含む場合、"y"は母音の音になります（例："rhythm" -> "ythmrhay"、"my" -> "ymay"）。
