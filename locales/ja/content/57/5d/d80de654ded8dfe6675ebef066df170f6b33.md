# はじめに

Rustでは、[`Iterator`](https://doc.rust-lang.org/stable/std/iter/trait.Iterator.html)トレイトを実装した型は、どれもイテレーターとして扱うことができます。
Rustに標準で用意されている[`collections`](https://doc.rust-lang.org/std/collections/index.html)は、`iter`、`iter_mut`、`into_iter`メソッドを使うことでイテレーターに変換できます。
イテレーターには、データを操作するための[強力なメソッド](https://doc.rust-lang.org/stable/std/iter/trait.Iterator.html#provided-methods)が豊富に用意されており、たとえば`collect`、`map`、`filter`、`fold`などがあります。

```rust
use std::collections::HashMap;

let v = vec![0, 1, 2];

let mut iter = v.iter();

// Call next() to return the next value
assert_eq!(Some(&0), iter.next());
assert_eq!(Some(&1), iter.next());
assert_eq!(Some(&2), iter.next());
// Ahen None once it's over
assert_eq!(None, iter.next());

// Loop over iterators with built-in methods, such as `map` and `collect`
let w: HashMap<_, _> = v.into_iter().map(|x| (x, x + 1)).collect();
println!("{w:?}");
// => {1: 2, 0: 1, 2: 3}
```
