# 説明

Lamontは、自分でビデオゲームを作りたいと思っているLispの宇宙人です。そのうちの1つとして、ハイスコアリストを管理するというタスクの手伝いを頼まれています。

## 1. ハイスコアテーブルを作成する

引数を一切取らず、新しい空のハッシュテーブルに評価される関数`make-high-score-table`を定義します。

```lisp
(make-high-score-table) ; => #<HASH-TABLE :TEST EQL :COUNT 0 {1005A90103}>
```

## 2. テーブルにプレイヤーを追加する

テーブルにプレイヤーを追加するには、次の2つの引数を取る関数`add-player`を定義します。
- ハイスコアテーブル
- キーワードで表したプレイヤーの名前

プレイヤーの初期スコアは0に設定します。

```lisp
(add-player hash-table :louis) ; => 0
(add-player hash-table :lilly) ; => 0
```

## 3. プレイヤーのスコアを設定する

プレイヤーのスコアを設定するには、次の3つの引数を取る関数`set-score`を定義します。
- ハイスコアテーブル
- キーワードで表したプレイヤーの名前
- 整数で表したプレイヤーのスコア

```lisp
(set-score hash-table :louis 1234) ; => 1234
```

## 4. テーブルからスコアを取得する

テーブルからプレイヤーのスコアを取得するには、次の2つの引数を取る関数`get-score`を定義します。
- ハイスコアテーブル
- キーワードで表したプレイヤーの名前

この関数は、そのプレイヤーに保存されているスコアに評価される必要があります。
そのプレイヤーのスコアが保存されていない場合、またはそのプレイヤーがまだテーブルに存在しない場合は、`0`に評価されます。

```lisp
(get-score hash-table :louis)                         ; => 1234
(get-score hash-table :lilly)                         ; => 0
(get-score hash-table :not-a-character-in-this-story) ; => 0
```

## 5. テーブルからプレイヤーを削除する

ハイスコアテーブルからプレイヤーを削除するには、次の2つの引数を取る関数`remove-player`を定義します。
- ハイスコアテーブル
- キーワードで表したプレイヤーの名前

この関数は、プレイヤーがまだテーブルに追加されていない場合も問題なく処理する必要があります。
当然ながら、プレイヤーを削除したあとにテーブルからそのスコアを取得すると、0になります。

```lisp
(set-score hash-table :louis 1234)           ; => 1234
(remove-player hash-table :louis)            ; => T
(get-score hash-table :louis)                ; => 0

(remove-player hash-table :not-in-the-table) ; => NIL
```
