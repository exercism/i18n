# 説明の補足

## 出力形式

ダイヤモンドを、各行の末尾に改行文字を付けたヌル終端文字列として出力します。

出力例は`"  A  \n B B \nC   C\n B B \n  A  \n"`です。

## レジスター

| Register | Usage        | Type    | Description                   |
| -------- | ------------ | ------- | ----------------------------- |
| `$a0`    | 入力         | byte    | 文字                          |
| `$a1`    | 入力／出力   | address | ヌル終端の結果文字列          |
| `$t0-9`  | 一時         | any     | 一時保存用                    |
