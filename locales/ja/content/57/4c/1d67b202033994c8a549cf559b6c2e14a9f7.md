# 指示の補足

## レジスタ

| レジスタ | 用途     | 型    | 説明                                       |
| -------- | --------- | ------- | ------------------------------------------------- |
| `$a0`    | 入力     | アドレス | null終端された入力文字列                      |
| `$v0`    | 出力    | 真偽値 | 入力がアイソグラムかどうか（`0` = `false`、`1` = `true`） |
| `$t0-9`  | 一時的 | 任意     | 一時的な保存に使う                        |
