# 説明の補足

## レジスタ

| レジスタ | 用途     | 型    | 説明                 |
| -------- | --------- | ------- | --------------------------- |
| `$a0`    | 入力     | アドレス | 本を表す単語の配列         |
| `$a1`    | 入力     | 整数 | 本の数             |
| `$v0`    | 出力     | 整数 | 価格（セント単位）             |
| `$t0-9`  | 一時     | 任意     | 一時的な保存に使われる  |
