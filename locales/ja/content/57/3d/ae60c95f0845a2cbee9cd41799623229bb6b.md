# はじめに

`GENERIC:`宣言は、引数の1つの*クラス*によって動作が変わるワードを作成します。具体的な動作は、`M:`で定義する*メソッド*からもたらされます。

```factor
GENERIC: area ( shape -- n )

TUPLE: square side ;
TUPLE: circle radius ;

M: square area
    side>> dup * ;
M: circle area
    radius>> dup * pi * ;
```

`area`が呼び出されると、Factorはスタックの先頭を調べ、クラスが一致する最も具体的なメソッドを探し出して実行します。ローカルを使う場合は`M::`を使えます。

```factor
TUPLE: rectangle width height ;

M:: rectangle area ( r -- n )
    r width>> r height>> * ;

T{ rectangle { width 3 } { height 4 } } area .   ! => 12
```

ジェネリックを使うと、呼び出し側のコードを変えることなく、あとから新しい表現を追加できます。`area`は`square`と`circle`ですでに機能しており、`rectangle`メソッドは`area`が呼ばれるあらゆる場所で自動的に拾われます。

## ジェネリックが適切な選択となるのはどんなときか

次のようなときは`GENERIC:`を使いましょう。

- 1つの操作が、入力によって*本当に異なる*実装を持つ場合。
- 将来のコードによって新しい型が追加されることを想定している場合。
- 型システムにクラスごとの定義を強制させたい場合。

ばらつきが単なる少数のラベルの列挙にすぎないなら、`case`のほうが簡単です。

## `INSTANCE:`でミックスインに加わる

*ミックスイン*とは*オープン*なジェネリッククラスです。誰でも新しいクラスをメンバーとして登録できます。Factorの組み込みプロトコルの多く（シーケンス、集合、ストリームなど）はミックスインとして公開されているので、独自のタプルは自分自身をインスタンスとして宣言することで、そのプロトコルのデフォルトメソッドを使えるようになります。

```factor
MIXIN: shape
M: shape area                   ! a default area for any shape
    drop 0 ;

TUPLE: my-shape ;
INSTANCE: my-shape shape         ! my-shape is now a `shape`

T{ my-shape } area .   ! => 0
```

`INSTANCE:`のあとは、すべてのデフォルトメソッド`M: shape …`が自動的に`my-shape`に対してディスパッチされ、`shape`を要求するあらゆるコードが`my-shape`を受け入れます。`M:`はジェネリックにメソッドを追加するためのもので、`INSTANCE:`はクラスをミックスインに加えるためのものです。

## `TYPED::`：普通のワードの入力をチェックする

`GENERIC:`/`M:`は引数のクラスによってメソッドを選びます。ディスパッチは望まず、入力が特定のクラスであることを要求する*1つの*ワードだけがほしいこともあるでしょう。`TYPED::`（`typed`ボキャブラリにあります）は、各入力名のあとにクラスを書く`::`です。

```factor
TYPED:: triple ( n: integer -- m )
    n 3 * ;

14 triple .   ! => 42
```

`n: integer`は、すでに使っているローカルと同じように読めますが、コロンのあとにクラスが書かれています。ディスパッチはなく、定義は1つ、動作も1つですが、各引数はそのクラスに対してチェックされるようになります。`"x" triple`のような不一致は、そのまま素通りするのではなく拒否されます（*expected input value of type integer but got string*）。

出力も同じように型注釈を付けられます。`yes?`は入力と結果の両方に型を付けます。

```factor
TYPED:: yes? ( word: string -- answer: boolean )
    word "yes" = ;

"yes" yes? .   ! => t
"no" yes? .    ! => f
```

## 数学関数と定数

この演習では、ここで初めて出会う`math.constants`と`math.functions`のいくつかのワードにも頼ります。

- `pi`：`math.constants`にある定数πです。
- `sin ( x -- y )`、`cos ( x -- y )`：ラジアンで表した角度の正弦と余弦です。
- `e^ ( x -- y )`：`e`を`x`乗したものです。（任意の底を使いたい場合は`^`を使います。）

```factor
pi 2 / sin   ! → 1.0
0 cos        ! → 1.0
1 e^         ! → 2.718281828459045
```
