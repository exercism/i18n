# はじめに

## Enum

`Enum`はとても便利なモジュールで、列挙可能なデータを扱うためのアルゴリズムを一式提供してくれます。並べ替え、絞り込み、グループ化、数え上げ、検索、最小値や最大値の取得など、さまざまな機能を備えています。

一般に、_列挙可能_とは、繰り返し処理できるデータ、つまりコレクションのことです。Elixirでは、`Enumerable`[プロトコル][exercism-protocols]を実装したデータ型が列挙可能です。その中でもよく使われるのは、[配列][exercism-lists]と[マップ][exercism-maps]です。

`Enum`の関数の多くは、引数として関数を受け取ります。

```elixir
Enum.all?([1, 2, 3, 4, 5], fn x -> x > 3 end)
# => false
```

`Enum`でもっともよく使われる関数は、`map`と`reduce`です。

### `map/2`

`Enum.map/2`を使うと、列挙可能なデータの各要素を別の要素に置き換えられます。`Enum.map/2`の第2引数は、元の要素を受け取って、その置き換え後の要素を返す関数です。

### `reduce/3`

`Enum.reduce/3`を使うと、列挙可能なデータ全体を1つの値に_畳み込む_ことができます。そのために、_アキュムレーター_と呼ばれる特別な変数を使います。アキュムレーターは、繰り返しの間で畳み込みの途中状態を保持します。

`Enum.reduce/3`の第2引数は、アキュムレーターの初期値です。第3引数は、要素とアキュムレーターを受け取り、アキュムレーターの新しい値を返す関数です。

### マップを扱う

`Enum`の関数でマップを扱うと、そのマップは自動的に2つの`{key, value}`タプルからなる配列に変換されます。

マップに戻すには、`Enum.into/2`を使います。`Enum.into/2`は、列挙可能なデータをコレクタブルに変換する関数です。コレクタブルとは、`Collectable`プロトコルを実装したデータ構造のことです。`Enum.reduce/3`の反対のものと考えるとよいでしょう。

`Enum`には`Enum.into/3`もあります。`Enum.into/3`は`Enum.into/2`の派生版で、列挙可能なデータをコレクタブルに変換するときに適用する変換関数を受け取ります。

#### マップをマッピングする

マップに変換（マッピング）を適用するのに、`Enum.into/3`や`Enum.map/2`に`Enum.into/2`を組み合わせる代わりに、専用の`Map.new/2`関数を使うこともできます。`Map.new/2`は、列挙可能なデータと変換関数を受け取るという点では`Enum.into/3`とまったく同じように動作しますが、コレクタブルを選べるのではなく、常に新しいマップを返します。
