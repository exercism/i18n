# 手順

Borisは大の鉄道模型ファンで、その情熱を世界と共有しようとニュースレターを始めることにしました。まずは、同じ趣味を持つ友人や知り合いにニュースレターの第1号を送るところから始めます。その人たちのメールアドレスはテキストファイルに保存されています。

ヒント: ファイル操作には[simplifile](https://hexdocs.pm/simplifile/simplifile.html)モジュールを使います。

## 1. ファイルからメールアドレスを読み込む

`read_emails`関数を実装します。この関数は、メールアドレスが改行で区切られて書かれたテキストファイルのパス文字列を受け取り、ファイル内のメールアドレスの配列を返します。

```gleam
read_emails("/home/my_user/documents/model_train_friends_emails.txt")
// -> Ok(["rick@example.com", "choochoo42@example.com", "anna@example.com"])
```

## 2. 書き込み用のログファイルを作成する

メールの送信は、メールアドレスの打ち間違いや一時的なネットワークの問題など、予測できないさまざまな理由で失敗することがある作業です。すべての友人に重複して送ることなくメールの送信を再試行できるようにするには、すでにメールを受け取ったアドレスを記録しておく必要があります。そのためにはログファイルが要ります。

`create_log_file`関数を実装します。この関数はファイルパスを受け取り、その場所に新しい空のファイルを作成します。

```gleam
create_log_file("/home/my_user/documents/newsletter_issue1_log.txt")
// -> Ok(Nil)
```

## 3. 送信済みのメールを記録する

`log_sent_email`関数を実装します。この関数はログファイルのパスと、メールアドレスが入った文字列を受け取ります。そして、メールアドレスをその後に改行を付けてファイルに書き込みます。

```gleam
log_sent_email(
  "/home/my_user/documents/newsletter_issue1_log.txt",
  "joe@example.com",
)
// -> Ok(Nil)
```

## 4. ニュースレターを送信する

メール送信の手順に必要な部品がそろったので、それらを1つの関数に組み合わせましょう。

`send_newsletter`関数を実装します。この関数は、メールアドレスが書かれたファイルのパス、ログファイルのパス、そして指定されたメールアドレスにメールを送る無名関数を受け取ります。

与えられたファイルからすべてのメールアドレスを読み込み、その一つひとつにメールを送信してみる必要があります。メールを送る無名関数が`Ok`の値を返したら、そのメールアドレスをログファイルに書き込みます。書き込みは、メールを送った直後に行うようにしましょう。

```gleam
send_newsletter(
  "model_train_friends_emails.txt",
  "newsletter_issue1_log.txt",
  send_email,
)
// -> Ok(Nil)
```
