# 説明

この演習では、貯蓄口座を扱います。
毎年、貯蓄口座の残高は利率に基づいて更新されます。
銀行が適用する利率は、口座にあるお金の額（残高）によって決まります：

- 残高が`0`ドル未満の場合は3.213%（残高はさらにマイナスになります）。
- 残高が`0`ドル以上`1000`ドル未満の場合は0.5%。
- 残高が`1000`ドル以上`5000`ドル未満の場合は1.621%。
- 残高が`5000`ドル以上の場合は2.475%。

タスクは4つあり、それぞれで残高とその利率を扱います。

## 1. 利率を計算する

指定された残高に基づいて利率を計算する`interest_rate`関数を実装します：

```cpp
interest_rate(200.75);
// => 0.5
```

## 2. 利息を計算する

指定された残高に基づいて利息を計算する`yearly_interest`関数を実装します：

```cpp
yearly_interest(200.75):
// => 1.003750
```

## 3. 年間の残高更新を計算する

利率を考慮して、年間の残高更新を計算する`annual_balance_update`関数を実装します：

```cpp
annual_balance_update(200.75);
// => 201.75375
```

## 4. 希望の残高に到達するまでの年数を計算する

希望の残高に到達するのに必要な最小年数を計算する`years_until_desired_balance`関数を実装します。
このとき、毎年、利息が残高に加算されることを考慮します。
つまり、1年後の残高は「開始時の残高＋開始時の残高に対する利息」です。
2年後の残高は「1年後の残高＋1年後の残高に対する利息」です。
これを、その年の残高が目標の残高以上になるまで繰り返します。

```cpp
double balance {200.75};
double targetBalance {214.88};
years_until_desired_balance(balance, targetBalance)
// => 14
```

戻り値は`int`であることに注意してください。
