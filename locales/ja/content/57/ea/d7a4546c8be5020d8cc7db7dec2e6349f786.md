# はじめに

`OpenStruct`を使うと、`Hash`から簡単にオブジェクトを作ることができます。
`Hash`のキーでアクセスする代わりに、`OpenStruct`ではメソッドを使って値にアクセスしたり、値を設定したりできます。

```ruby
attributes = { name: "Jeremy Walker", age: 21, location: "Nomadic" }
person = OpenStruct.new(attributes)

person.name
#=> Jeremy Walker

person.location
#=> Nomadic

# Update the age
person.age = 35

# It sets correctly
person.age
#=> 35
```

この方法のうれしい点は、ブロック構文を使うときにショートカットを利用できることです。
ブロックがメソッドを1つだけ呼び出す場合は、そのブロックを`&:`とメソッド名に置き換えられます。
たとえば、次の2行は同じ意味です。

```ruby
people.sum { |person| person.age }
people.sum(&:age)
```

## 標準ライブラリ

これまでの演習で見てきたクラスはすべて、Rubyのコアライブラリに含まれていました。

OpenStructはRubyの標準ライブラリ（しばしば「stdlib」と略されます）の一部です。標準ライブラリは、日付やjson、ネットワークなどを扱うためのクラスを集めたものです。
また、コードを扱いやすくするための便利な機能も提供しています。

コアライブラリ以外のクラス（別のファイルに書いた自分のコード、標準ライブラリのクラス、外部の依存関係など）を使うときは、使う前に`require`メソッドで読み込む必要があります。
たとえば、次のようになります。

```ruby
require 'ostruct'

person = OpenStruct.new(name: "Jeremy Walker")
# ...
```
