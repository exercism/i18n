# 概要

`LocalDate`や`LocalDateTime`のようなクラスは、時間の_一点_を表します。`java.time`パッケージには、時間の_長さ_を表す2つのクラスもあります。

- [`Period`][period-docs]は、年・月・日で表す日付ベースの長さで、「2か月と5日」のようなものです。
- [`Duration`][duration-docs]は、時・分・秒・ミリ秒・ナノ秒で表す時間ベースの長さで、「1時間30分」のようなものです。

この違いが重要なのは、暦の単位には決まった長さがないからです。1か月は28日にも29日にも30日にも31日にもなるので、「1か月」は決まった秒数ではありません。`Period`は暦に従い、`Duration`は正確な時間を測ります。

| | `Period` | `Duration` |
| --- | --- | --- |
| 保持するもの | 年、月、日 | 秒、ナノ秒 |
| 組み合わせる相手 | `LocalDate`、`LocalDateTime` | `LocalTime`、`LocalDateTime`、`Instant` |

どちらのクラスもイミュータブルです。`plusDays()`や`multipliedBy()`のようなメソッドは_新しい_インスタンスを返し、元のインスタンスは変わりません。

## `Period`

### `Period`を作る

```java
Period.ofDays(10);
// => P10D

Period.ofWeeks(2);
// => P14D

Period.ofMonths(3);
// => P3M

Period.of(1, 2, 15);
// => P1Y2M15D
```

`toString()`の結果は[ISO-8601の期間形式][iso-8601-durations]に従います。先頭に`P`を置き、そのあとに年（`Y`）、月（`M`）、日（`D`）の数を続けます。`Period`に週はありません。`Period.ofWeeks(2)`は14日として保存されます。同じ表記は`Period.parse()`で元に戻せます。

```java
Period.parse("P1Y2M15D");
// => P1Y2M15D
```

### 日付に`Period`を足す

日付に対して`Period`を足したり引いたりするには、`plus()`と`minus()`を使います。

```java
LocalDate date = LocalDate.of(2024, 3, 10);

date.plus(Period.ofMonths(2));
// => 2024-05-10

date.minus(Period.ofDays(10));
// => 2024-02-29
```

`LocalDateTime`にも同じように`Period`を足せます。時刻は変わりません。

```java
LocalDateTime.of(2024, 3, 10, 9, 30).plus(Period.ofMonths(1));
// => 2024-04-10T09:30
```

`Instant`には暦がないので、日の単位の`Period`しか足せません。年や月を含む`Period`を足すと例外がスローされます。

```java
Instant instant = Instant.parse("2024-03-10T09:30:00Z");

instant.plus(Period.ofDays(2));
// => 2024-03-12T09:30:00Z

instant.plus(Period.ofMonths(1));
// => throws UnsupportedTemporalTypeException
```

まず年、次に月、最後に日を足します。年や月を足した結果が存在しない日になったときは、その月の最後の有効な日に戻されます。

```java
LocalDate.of(2025, 1, 31).plus(Period.ofMonths(1));
// => 2025-02-28

LocalDate.of(2024, 2, 29).plus(Period.ofYears(1));
// => 2025-02-28
```

つまり、`Period`を足してから同じ`Period`を引いても、元の日付に戻るとは限りません。

```java
LocalDate.of(2025, 1, 31).plus(Period.ofMonths(1)).minus(Period.ofMonths(1));
// => 2025-01-28
```

### 2つの日付の間の`Period`

`Period.between()`は、ある日付（この日を含む）から別の日付（この日を含まない）までの期間を返します。同じ結果は`LocalDate.until()`でも得られます。

```java
LocalDate start = LocalDate.of(2023, 3, 10);
LocalDate end = LocalDate.of(2024, 5, 25);

Period.between(start, end);
// => P1Y2M15D

start.until(end);
// => P1Y2M15D
```

`Period`の各部分は`getYears()`、`getMonths()`、`getDays()`で取得できます。これらの部分はそれぞれ独立しています。`getDays()`が返すのは日の部分だけで、総日数ではありません。`toTotalMonths()`は年と月を合わせた月数を返しますが、総日数を返すメソッドはありません。総日数はどの月が関わるかによって変わるからです。

```java
Period period = Period.between(LocalDate.of(2024, 1, 15), LocalDate.of(2024, 3, 20));
// => P2M5D

period.getDays();
// => 5

period.toTotalMonths();
// => 2
```

### `Period`を正規化する

ファクトリメソッドで作った`Period`は、指定した単位をそのまま保持します。また、`equals()`は単位を1つずつ比較します。`normalized()`は月を年に繰り上げますが、日には手を付けません。

```java
Period.ofMonths(14);
// => P14M

Period.ofMonths(14).equals(Period.of(1, 2, 0));
// => false

Period.ofMonths(14).normalized();
// => P1Y2M

Period.ofDays(45).normalized();
// => P45D
```

## `ChronoUnit`で単位を数える

2つの時点の間にある、1つの単位の総数を求めるには、[`ChronoUnit`][chronounit-docs]の定数の`between()`メソッドを使います。

```java
LocalDate start = LocalDate.of(2024, 1, 15);
LocalDate end = LocalDate.of(2024, 3, 20);

ChronoUnit.DAYS.between(start, end);
// => 65

ChronoUnit.WEEKS.between(start, end);
// => 9

ChronoUnit.MONTHS.between(start, end);
// => 2
```

数えられるのは完全な単位だけです。2番目の引数が1番目より前にある場合、結果は負になります。

```java
ChronoUnit.DAYS.between(end, start);
// => -65
```

`ChronoUnit`は時間ベースの単位や日時にも使えます。

```java
ChronoUnit.MINUTES.between(
    LocalDateTime.of(2024, 3, 10, 18, 5),
    LocalDateTime.of(2024, 3, 10, 19, 40));
// => 95
```

## `Duration`

### `Duration`を作る

```java
Duration.ofMinutes(90);
// => PT1H30M

Duration.ofSeconds(3725);
// => PT1H2M5S

Duration.ofDays(2);
// => PT48H

Duration.ofHours(2).plusMinutes(15);
// => PT2H15M
```

ISO-8601の表記では、`T`が日付の部分と時刻の部分を区切ります。`Duration`には日付の部分がないので、`toString()`の結果は必ず`PT`で始まります。`Duration.ofDays()`は1日をちょうど24時間として扱います。

`Duration`は`Duration.parse()`で解析することもできます。

```java
Duration.parse("PT1H30M");
// => PT1H30M
```

### 時刻に`Duration`を足す

`LocalTime`、`LocalDateTime`、`Instant`に対して`Duration`を足したり引いたりするには、`plus()`と`minus()`を使います。

```java
LocalDateTime start = LocalDateTime.of(2024, 3, 10, 22, 30);

start.plus(Duration.ofMinutes(90));
// => 2024-03-11T00:00

LocalTime.of(23, 0).plus(Duration.ofHours(2));
// => 01:00
```

最後の例が示すように、`LocalTime`は真夜中をまたぐと0時に戻ります。

`LocalDate`には時刻がないので、`Duration`とは組み合わせられません。

```java
LocalDate.of(2024, 3, 10).plus(Duration.ofHours(1));
// => throws UnsupportedTemporalTypeException
```

### 2つの時刻の間の`Duration`

`Duration.between()`は、2つの時刻または日時の間の正確な時間を返します。

```java
LocalDateTime checkIn = LocalDateTime.of(2024, 3, 10, 18, 5);
LocalDateTime checkOut = LocalDateTime.of(2024, 3, 10, 19, 40);

Duration.between(checkIn, checkOut);
// => PT1H35M

Duration.between(checkOut, checkIn);
// => PT-1H-35M
```

`Duration.between()`は2つの`LocalDate`を受け付けません。日付には測るべき秒がないからです。

```java
Duration.between(LocalDate.of(2024, 1, 15), LocalDate.of(2024, 3, 20));
// => throws UnsupportedTemporalTypeException
```

日付には`Period.between()`か`ChronoUnit.DAYS.between()`を使いましょう。

### `Duration`を変換する

`toXxx()`メソッドは、`Duration`を1つの単位の_総量_に変換します。端数は切り捨てます。

```java
Duration duration = Duration.ofSeconds(5730); // 1 hour, 35 minutes and 30 seconds

duration.toHours();
// => 1

duration.toMinutes();
// => 95

duration.toSeconds();
// => 5730
```

`toXxxPart()`メソッドは、時計と同じように`Duration`を各部分に分解します。

```java
Duration duration = Duration.ofSeconds(5730);

duration.toHoursPart();
// => 1

duration.toMinutesPart();
// => 35

duration.toSecondsPart();
// => 30
```

`toHoursPart()`は23で止まります。それより上の時間は`toDaysPart()`が数えるからです。

### `Duration`の比較と計算

`Duration`は`compareTo()`で比較でき、`isZero()`や`isNegative()`で確認できます。

```java
Duration visit = Duration.ofMinutes(95);
Duration limit = Duration.ofHours(2);

visit.compareTo(limit) > 0;
// => false

Duration.between(LocalTime.of(10, 0), LocalTime.of(9, 0)).isNegative();
// => true
```

`plus()`、`minus()`、`multipliedBy()`、`dividedBy()`といった計算もできます。

```java
Duration.ofMinutes(20).multipliedBy(3);
// => PT1H

Duration.ofHours(2).dividedBy(Duration.ofMinutes(15));
// => 8
```

## `Period`と`Duration`のどちらを使うか

`LocalDate`や`LocalTime`の場合は、選ぶ必要はありません。日付には測るべき時刻がなく、時刻には暦がないからです。`LocalDateTime`には両方ありますが、タイムゾーンはありません。そのため、`Period.ofDays(1)`を足しても`Duration.ofDays(1)`を足しても結果は同じです。違いが表れるのはタイムゾーンが関わるときです。夏時間で時計が進むと、暦の上の1日は23時間しかありません。

```java
ZonedDateTime noon = ZonedDateTime.of(2025, 3, 29, 12, 0, 0, 0, ZoneId.of("Europe/Amsterdam"));

noon.plus(Period.ofDays(1));
// => 2025-03-30T12:00+02:00[Europe/Amsterdam]

noon.plus(Duration.ofDays(1));
// => 2025-03-30T13:00+02:00[Europe/Amsterdam]
```

1日の`Period`を足すと時刻はそのまま保たれ、1日の`Duration`を足すとちょうど24時間が加わります。暦で考える長さ（「来月の同じ時刻」など）には`Period`を、経過した時間（「駐車券は2時間有効」など）には`Duration`を使いましょう。
