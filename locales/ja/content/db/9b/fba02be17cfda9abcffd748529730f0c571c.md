# 説明の補足

## ワード

`stopwatch`タプルと、コンストラクター`<stopwatch> ( -- stopwatch )`を定義します。このコンストラクターは、経過時間も以前のラップもない、`"ready"`状態の新しいストップウォッチを返します。

ストップウォッチを操作する次のワードを用意します。

- `state ( stopwatch -- str )`：`"ready"`、`"running"`、`"stopped"`のいずれか。
- `current-lap ( stopwatch -- str )`：現在のラップの経過時間を`"HH:MM:SS"`形式の文字列で表したもの。
- `total ( stopwatch -- str )`：現在のラップと以前のすべてのラップを合わせた経過時間を`"HH:MM:SS"`形式の文字列で表したもの。
- `previous-laps ( stopwatch -- seq )`：以前に記録したラップの配列で、各要素は`"HH:MM:SS"`形式の文字列です。
- `start ( stopwatch -- )`、`stop ( stopwatch -- )`、`reset ( stopwatch -- )`、`lap ( stopwatch -- )`：上の表にある4つのコマンドです。呼び出しが許されない状態から呼び出すと、`throw`でエラーになります。

時間を進めるには、次のワードを使います。

- `advance-time ( str stopwatch -- )`：`"HH:MM:SS"`の期間を現在のラップに加算します。これはストップウォッチが動いている間だけ効果があります。
