# はじめに

## 型エイリアス

### 型エイリアス

Gleamでは、型エイリアスを使うと、そのまま書くと煩雑になってしまう既存の型に、便利な名前を付けられます。

```gleam
pub type Headers =
  List(#(String, String))

pub fn html_headers() -> Headers {
  [
    #("content-type", "text/html"),
    #("x-frame-options", "DENY"),
  ]
}
```

`pub type`を付けて書くと、そのエイリアスは定義したモジュールの外でも使えます。`pub`を省略するとエイリアスはプライベートになり、他のモジュールから参照できません。

## `Dict`

Gleamの`Dict`は、キーと値のペアで情報を保存するためのデータ構造です。他の言語では、連想配列、ハッシュ、辞書などと呼ばれることもあります。

`Dict`のキーと値にはどんな型でも使えますが、アクセスしたり返したりするときの項目の順序は保証されません。

### `Dict`を扱う

`Dict`は、`gleam/dict`モジュールの関数を使って作成・操作します。

```gleam
// Create an empty dict
let dict1 = dict.new()

// Create a dict with some values
let dict2 = dict.from_list([
  #("name", "Gleam"),
  #("colour", "Pink"),
])

// Add a value to a dict
let dict3 = dict.insert(dict2, "website", "https://gleam.run")

// Get a value from a dict
let name = dict.get(dict3, "name")
// -> Ok("Gleam")
```
