# 型宣言

PHPの型宣言は、関数の引数、戻り値、クラスのプロパティに対して、実行時に型をチェックします。
関数では、`void`という戻り値の型を付けることで、その関数が値を返さないことを示せます。
宣言した型は、関数が妥当な型の応答を返しているかどうかを実行時にチェックする役割も果たします。

```php
<?php

class Driver
{
    private int $serial_number;

    public function setSerialNumber(int $number): void
    {
        $this->serial_number = $number;
    }

    public function getSerialNumber(): int
    {
        return $this->serial_number; 
    }
}

$driver = new Driver();
$driver->setSerialNumber("Version 1b"); // This will throw a TypeError
```

## ユニオン型

関数の引数、戻り値、クラスのプロパティが複数の型を取りうる場合は、ユニオン型を宣言できます。

```php
<?php

class IdentityCard
{
    private int|null $id = null;

    public function assign(int|float $id): void
    {
        $this->id = intval($id);
    }
}

$card = new IdentityCard();
$card->assign(5.0);
```

## mixed型

コードを書いていると、型を特定できないこともあります。
PHP 8.0からは、そういうときの逃げ道として`mixed`という型が用意されています。
`mixed`は、`object|resource|array|string|float|int|bool|null`というユニオン型と同等です。
