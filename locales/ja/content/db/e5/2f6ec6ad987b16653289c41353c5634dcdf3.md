# ヒント

## 1. 自己紹介をする

`introduce`関数は、`player.Name`に含まれる値を「unwrap」する必要があります。`player.Name`が`Some`のときはその「ラップされた」値に、`None`のときは指定されたデフォルト値に変換するために、[`Options.defaultValue`関数][defaultvalue]を使ってみましょう。

## 2. 復活の仕組みを実装する

`revive`関数は、`Some <player>`か`None`のどちらかを返す必要があります。ここで`<player>`は、フィールドがいくつか変更されている可能性のある`Player`レコードです。

## 3. 呪文詠唱の仕組みを実装する

次の例のように、`Some`と`None`の両方のケースを扱うために`match`式を使ってみましょう：

```fsharp
let exists (x: int option) =
    match x with
    | Some n -> true
    | None -> false
```

[defaultvalue]: https://learn.microsoft.com/en-us/dotnet/fsharp/language-reference/options#converting-options-with-default-values
