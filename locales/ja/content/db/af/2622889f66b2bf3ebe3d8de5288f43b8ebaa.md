# 説明

目が飛び出るほどの日当につられて、Hyperia（インフレの進んだ国）に戻ってきてしまいました。

中央銀行は、米ドルを第二の通貨として導入することを検討しています。そのため、すべての会計システムを、複数の通貨を扱えるように改修しなければなりません。

そこで、通貨額を表すオブジェクトの実装を任されました。

## 1. 通貨額の等価比較を可能にする

`CurrencyAmount`構造体を変更して、等価比較を扱えるようにしてください。2つの通貨額構造体の通貨（"USD"または"HD"）が同じでない場合は、`ArgumentException`のインスタンスをスローする必要があります。

```csharp
CurrencyAmount amountA = new CurrencyAmount(55, "HD");
CurrencyAmount amountB = new CurrencyAmount(55, "HD");
CurrencyAmount amountC = new CurrencyAmount(55, "USD");
amountA == amountB
// => true
amountA != amountB
// => false
amountA == amountC
// => ArgumentException
amountA != amountC
// => ArgumentException
```

## 2. 通貨額を比較する

`CurrencyAmount`構造体を変更して、比較（`>`と`<`のみ）を扱えるようにしてください。2つの通貨額構造体の通貨（"USD"または"HD"）が同じでない場合は、`ArgumentException`のインスタンスをスローする必要があります。

```csharp
CurrencyAmount amountA = new CurrencyAmount(55, "HD");
amountA > new CurrencyAmount(50, "HD")
// => true
amountA < new CurrencyAmount(50, "HD")
// => false
amountA > new CurrencyAmount(50, "USD")
// => ArgumentException
```

## 3. 通貨額を加算・減算する

`CurrencyAmount`構造体を変更して、加算と減算（`+`と`-`のみ）を扱えるようにしてください。2つの通貨額構造体の通貨（"USD"または"HD"）が同じでない場合は、`ArgumentException`のインスタンスをスローする必要があります。

```csharp
CurrencyAmount amountA = new CurrencyAmount(55, "HD");
CurrencyAmount amountB = new CurrencyAmount(100, "HD");
CurrencyAmount amountC = new CurrencyAmount(55, "USD");
amountA + amountB
// => {155, HD}
amountB - amountA
// => {45, HD}
amountA + amountC
// => ArgumentException
```

## 4. 通貨額を乗算・除算する

`CurrencyAmount`構造体を変更して、乗算と除算（`*`と`/`のみ）を扱えるようにしてください。

```csharp
CurrencyAmount amountA = new CurrencyAmount(10, "HD");
amountA * 2m
// => {20, HD}
amountA / 2m
// => {5, HD}
```

## 5. 通貨額を`double`に変換する

`CurrencyAmount`構造体を変更して、インスタンスを明示的に`double`へキャストできるようにしてください。

```csharp
CurrencyAmount amountA = new CurrencyAmount(55.5m, "HD");
(double)amountA
// => 55.5d
```

## 6. 通貨額を`decimal`に変換する

`CurrencyAmount`構造体を変更して、インスタンスを暗黙的に`decimal`へ変換できるようにしてください。

```csharp
CurrencyAmount amountA = new CurrencyAmount(55.5m, "HD");
decimal d = amountA;
// => d == 55.5m
```
