# 説明

この演習では、キログラムを単位とするはかりをモデル化します。

6つのタスクがあり、それぞれで1つ以上のプロパティを実装する必要があります。

## 1. はかりに精度を持たせる

さまざまな要求に応えるため、各はかりを精度（小数点以下の桁数）でカスタマイズできるようにします。
`WeighingMachine`クラスに、取得専用の`Precision`プロパティを実装し、コンストラクターの`precision`引数で設定します。

```csharp
var wm = new WeighingMachine(precision: 3);

//  => wm.Precision == 3
```

## 2. はかりに重さを設定できるようにする

`WeighingMachine.Weight`プロパティを実装し、重さを取得_および_設定できるようにします。

```csharp
var wm = new WeighingMachine(precision: 3);
wm.Weight = 60.5;

//  => wm.Weight == 60.5
```

## 3. 負の入力重量が拒否されるようにする

言うまでもなく、重さが負になることはありえません。
`WeighingMachine.Weight`プロパティに検証を追加し、負の重さを設定しようとしたときに`ArgumentOutOfRangeException`をスローするようにします。

```csharp
var wm = new WeighingMachine(precision: 3);
wm.Weight = -10; // Throws an ArgumentOutOfRangeException
```

## 4. はかりに風袋調整を適用できるようにする

風袋調整には任意の値（負の値や、表示重量が負になるような値でもかまいません）を指定できます。
`WeighingMachine.TareAdjustment`プロパティを実装し、風袋調整を設定できるようにします。

```csharp
var wm = new WeighingMachine(precision: 3);
wm.TareAdjustment = -10.6;

// => wm.TareAdjustment == -10.6
```

## 5. はかりにデフォルトの風袋調整があるようにする

入念にテストした結果、製造上の問題により、すべてのはかりが重さを`5`だけ過大に見積もる傾向があることがわかりました。
`WeighingMachine.TareAdjustment`プロパティのデフォルト値を`5`に変更します。

```csharp
var wm = new WeighingMachine(precision: 3);

// => wm.TareAdjustment == 5.0
```

## 6. 重さを取得できるようにする

`WeighingMachine.DisplayWeight`プロパティを実装します。このプロパティは、風袋調整後の重さを、正しい精度を適用し、単位を付けた文字列として返す必要があります。
次の点に注意してください。
``` display-weight = input-weight - tare-adjustment ```

```csharp
var wm = new WeighingMachine(precision: 3);
wm.Weight = 60.567;
wm.TareAdjustment = 10;

// => wm.DisplayWeight == "50.567 kg"
```
