# 説明

この演習では、データを変換することで動作する暗号化デバイスのソフトウェアを書くという課題に取り組みます。より単純な関数を組み合わせて複雑な関数を柔軟に作る方法が必要です。

各タスクでは、呼び出し元のスコープから呼び出せる無名関数を返します。

どの関数も整数の引数を取るものとします。また、Elixirでビット演算を行う場合にも整数が適しています。

## 1. 加算器を作る

`Secrets.secret_add/1`を実装します。これは、1つの引数を取り、それに`secret_add`へ渡された引数を加算する関数を返します。

```elixir
adder = Secrets.secret_add(3)
adder.(2)
# => 5
```

## 2. 減算器を作る

`Secrets.secret_subtract/1`を実装します。これは、1つの引数を取り、その引数から`secret_subtract`へ渡された秘密の値を引く関数を返します。

```elixir
subtractor = Secrets.secret_subtract(2)
subtractor.(3)
# => 1
```

## 3. 乗算器を作る

`Secrets.secret_multiply/1`を実装します。これは、1つの引数を取り、それに`secret_multiply`へ渡された秘密の値を掛ける関数を返します。

```elixir
multiplier = Secrets.secret_multiply(7)
multiplier.(3)
# => 21
```

## 4. 除算器を作る

`Secrets.secret_divide/1`を実装します。これは、1つの引数を取り、それを`secret_divide`へ渡された秘密の値で割る関数を返します。

```elixir
divider = Secrets.secret_divide(3)
divider.(32)
# => 10
```

出力が他の関数の期待する入力と互換になるように、整数除算を利用します。

## 5. 「and」を行う関数を作る

`Secrets.secret_and/1`を実装します。これは、1つの引数を取り、その引数と`secret_and`へ渡された秘密の値に対してビット単位の_and_演算を行う関数を返します。

```elixir
ander = Secrets.secret_and(1)
ander.(2)
# => 0
```

## 6. 「xor」を行う関数を作る

`Secrets.secret_xor/1`を実装します。これは、1つの引数を取り、その引数と`secret_xor`へ渡された秘密の値に対してビット単位の_xor_演算を行う関数を返します。

```elixir
xorer = Secrets.secret_xor(1)
xorer.(3)
# => 2
```

## 7. 関数を組み合わせる関数を作る

`Secrets.secret_combine/2`を実装します。これは、1つの引数を取り、`secret_combine`へ渡された2つの関数を順番にその引数へ適用する関数を返します。

```elixir
add_one = Secrets.secret_add(1)
multiply_by_2 = Secrets.secret_multiply(2)
combined = Secrets.secret_combine(add_one, multiply_by_2)

combined.(3)
# => 8
```
