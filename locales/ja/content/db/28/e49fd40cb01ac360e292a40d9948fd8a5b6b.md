# はじめに

## 配列

Cairoのコアライブラリには、`Array`型が実装されています。

他のプログラミング言語にある一般的な配列型と似ていますが、いくつか重要な違いがあります。

- 要素を効率よく追加できるのは`Array`型の末尾だけで、効率よく削除できるのは先頭だけです。
- 配列のインデックスを使って要素を手動で設定することはできません。

配列は、`ArrayTrait::new`関数や`array!`マクロを使って作成できます。

```rust
let empty: Array<u32> = ArrayTrait::new();
let one_to_four = array![1, 2, 3, 4];
```

要素は`ArrayTrait::append`関数を使って配列に追加できます。

```rust
let mut num_array = array![1, 2, 3, 4];
num_array.append(5);
// -> [1, 2, 3, 4, 5]
```

要素は`ArrayTrait::pop_front`関数を使って配列から削除できます。

```rust
let mut one_to_four = array![1, 2, 3, 4];

one_to_four.pop_front();
// -> [2, 3, 4]
```

Cairoには、`Array`の「スナップショット」のように機能する`Span`型もあります。

すべての`Array`は、`ToSpanTrait::span`関数を使うと`Span`に変換できます。

```rust
let one_to_four = array![1, 2, 3, 4];
let one_to_four_span = one_to_four.span();
// -> [1, 2, 3, 4]
```

配列を`Span`に変換するのはとても効率的です。`Span`は、Cairoが配列の一部分を「見る」ことを可能にするデータ構造にすぎず、配列を一切変更しないからです。

配列を`Span`に変換することで、Cairoでは`Array`に直接許されるよりも多くの操作を行えます。たとえば、`Span`の先頭から要素を削除できます。

```rust
let one_to_four = array![1, 2, 3, 4];
let mut one_to_four_span = one_to_four.span();
one_to_four_span.pop_back();
// -> [2, 3, 4]
```

`pop_back`を呼び出すには、`mut`キーワードを使って`one_to_four_span`を可変にする必要があったことに注意してください。`pop_back`は、`Span`が「見ている」配列の範囲を短くすることで、`Span`を変更します。
