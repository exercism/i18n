# 説明

ジョシュは新しいロールプレイングゲームを制作中で、いくつかの仕組みの実装に助けが必要です。

## 1. 自己紹介をしましょう

`introduce`関数を実装しましょう。

ステルス状態のプレイヤーは名前を隠していることがあり、その場合は`"Mighty Magician"`として紹介されます。
それ以外の場合は、プレイヤーの名前を使って紹介します。

```gleam
introduce(Player(name: None, level: 2, health: 8, mana: None))
// -> "Mighty Magician"

introduce(Player(name: Some("Merlin"), level: 2, health: 8, mana: None))
// -> "Merlin"
```

## 2. 復活の仕組みを実装しましょう

`revive`関数は、プレイヤーのキャラクターが本当に死んでいるか（体力が0になっているか）を確認します。
死んでいる場合は、体力100の新しい`Player`インスタンスを返します。
そうでない場合、プレイヤーのキャラクターが死んでいなければ、`revive`関数は`None`を返します。

プレイヤーのレベルが10以上なら、マナも100にして復活させます。
プレイヤーのレベルが10未満なら、マナはそのままにします。
`revive`関数はプレイヤーのレベルを保持します。

```gleam
let dead_player = Player(name: None, level: 2, health: 0, mana: None)

revive(dead_player)
// -> Some(Player(name: None, level: 2, health: 100, mana: None))
```

体力が1以上あるプレイヤーに対して`revive`メソッドを呼び出すと、この関数は`None`を返します。

```gleam
let alive_player = Player(name: None, level: 2, health: 42, mana: None)

revive(alive_player)
// -> None
```

## 3. 呪文詠唱の仕組みを実装しましょう

`cast_spell`関数は、呪文に必要なマナの量を表す`Int`と、`Player`を引数に取ります。
更新されたプレイヤーと、唱えた呪文が与えるダメージ量を返します。
呪文の詠唱に成功すると、呪文のマナコストの2倍のダメージを与えます。
ただし、プレイヤーのマナが足りない場合は何も起こらず、プレイヤーは変化せず、ダメージも与えられません。
プレイヤーにマナプールすらない場合、呪文を唱えようとすると、呪文のマナコスト分だけ体力が減り、ダメージは与えられません。
プレイヤーの体力は0未満にはならないことに注意してください。

```gleam
let wizard = Player(name: None, level: 18, health: 123, mana: Some(30))
let #(wizard, damage) = cast_spell(wizard, 14)

wizard.mana // -> Some 16
damage      // -> 28
```
