# はじめに

Rustでは、真偽値は`bool`型で表され、その値は`true`または`false`のいずれかです。

Rustは6つの比較演算子をサポートしています：`==`（等しい）、`!=`（等しくない）、`>`（より大きい）、`<`（より小さい）、`>=`（以上）、`<=`（以下）です。これらを使うと、真偽値以外の値の関係を評価して、真偽値にできます。

```rust
1 > 0 // true
1 < 0 // false
1 == 0 // false
1 != 0 // true
1 >= 0 // true
1 <= 0 // false
```

他の言語とは異なり、Rustでは`0`は`false`ではなく、0以外の値が`true`になるわけでもありません。

Rustは2つの論理演算子をサポートしています：`||`（OR）と`&&`（AND）です。これらの演算子の右側のオペランドは、左側のオペランドだけで式の結果が決まらない場合にのみ評価されます。つまり、`||`は左側のオペランドが`false`と評価されたときにのみ右側のオペランドを評価し、`&&`は`true`と評価されたときにのみ右側のオペランドを評価します。
