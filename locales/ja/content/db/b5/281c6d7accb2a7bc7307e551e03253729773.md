# テスト

テストはいくつかの方法で実行できます。

## Emacsの中で対話的に実行する

1. テストファイルを開き、`M-x eval-buffer RET`を実行します
2. `M-x ert RET test-name RET`で、テストを1つずつ対話的に実行します
3. `M-x ert RET t RET`で、すべてのテストをまとめて対話的に実行します
   この方法では、そのときEmacsに読み込まれているすべてのテストが実行されることに注意してください！
4. コードを変更したときは、テストの前に毎回`M-x eval-buffer RET`を実行し直します

現在のバッファにあるテストだけを実行したい場合は、`.emacs`または`init.el`に次を追加します。

```elisp
(defun my-eval-and-run-all-tests-in-buffer ()
  "Deletes all loaded tests from the runtime, evaluates the current buffer and runs all loaded tests with ert."
  (interactive)
  (ert-delete-all-tests)
  (eval-buffer)
  (ert 't))
```

Emacsを再起動したら、次のようにします。

1. テストファイルを開きます
2. `M-x my-eval-and-run-all-tests-in-buffer RET`を実行します

## ターミナルから実行する

ターミナルからバッチモードですべてのテストを実行するには、`emacs -batch -l ert -l *-test.el -f ert-run-tests-batch-and-exit`を実行します。

上のコマンドは少し扱いにくいので、よければ次のようにしてください。

1. `$PATH`の通った場所（おそらく`~/bin`）に`ert-run`というファイルを作ります
2. ファイルの内容は次のとおりにします。
   ```sh
   #!/usr/bin/env sh
   emacs -batch -l ert -l $1 -f ert-run-tests-batch-and-exit
   ```
3. `chmod +x ert-run`でファイルに実行権限を与えます

これで、`ert-run *-test.el`を呼び出すだけで、バッチモードでテストを実行できるはずです。

## その他の方法

その他の方法はドキュメントに載っています。`C-h i m ert RET`を参照してください。
