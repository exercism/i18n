# テスト

テストスイートを実行するには：
```bash
tclsh exercise.test
```

## スキップされるテスト

演習を解くというのは、その演習のテストをすべて通すということです。デフォルトでは、テストを実行すると、最初の1つのテストだけが実行されます。これは意図的なもので、まずはその1つのテストに通すことだけに集中できるようになっています。そのテストに通ったら、その前にある`skip`コマンドをコメントアウトするか削除すれば、次のテストを有効にできます。

または、テストの「スキップ」状態に関係なく、すべてのテストを実行するには：
```bash
RUN_ALL=1 tclsh exercise.test
```
