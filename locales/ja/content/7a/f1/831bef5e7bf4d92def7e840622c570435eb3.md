# はじめに

Rの`list`は、要素を順序どおりに並べた集まりです。`vectors`とはいくつかの点で異なります。

- 要素にさまざまな型を混在させることができます（たとえば`numeric`と`character`を混ぜるなど）。
- 要素に複雑な構造を入れることができます（たとえばベクトルや別のリストなど）。
- 要素にアクセスするための構文が少し異なります。

他の言語との類似は、あくまでおおまかなものです。
Rの`list`はPythonの辞書にいくらか似ていますが、`list`は順序を持ち、数値のインデックスでアクセスできます。
Cの`struct`にもいくらか似ていますが、`list`は実行時に簡単に拡張できるという違いがあります。

## リストの作成

要素に名前を付けること（しばしば「タグ」と呼ばれます）は、ベクトルよりもリストでよく行われます。

```R
list(x = 5.3, y = 4.2, color = "blue")
$x
#> [1] 5.3

$y
#> [1] 4.2

$color
#> [1] "blue"
```

ただし、タグは省略できます。その場合、Rは単にインデックスの番号を使います。

```R
list(5.3, 4.2, "blue")
#> [[1]]
#> [1] 5.3

#> [[2]]
#> [1] 4.2

#> [[3]]
#> [1] "blue"
```

## リストの要素へのアクセス

方法は3つあり、それぞれ異なる場面で役立ちます。

### 1. `$tag`表記を使う

タグ名があらかじめわかっている場合によく使われます。

```R
point <- list(x = 5.3, y = 4.2, color = "blue")
point$x
#> [1] 5.3
point$color
#> [1] "blue"
```

### 2. `[[tag]]`表記を使う

タグ名を実行時に決められるという利点があります。
角括弧が二重になっている点に注意しましょう。

```R
want <- "y"
point[[want]] # same as point$y
#> [1] 4.2
```

### 3. 位置のインデックスを使う

リストにタグがあるかどうかに関わらず使えます。
ここでも角括弧は二重です。

```R
point[[3]] # same as point$color
#> [1] "blue"
```

## 要素の追加と削除

簡単です。要素に代入すると、すでにあれば更新され、新しければ追加されます。

```R
point$color <- "red"
point$trust <- TRUE
str(point)
#> List of 4
#>  $ x    : num 5.3
#>  $ y    : num 4.2
#>  $ color: chr "red"
#>  $ trust: logi TRUE
```

削除するには、不要な要素に`NULL`を代入します。

```R
point$trust <- NULL
str(point)
#> List of 3
#>  $ x    : num 5.3
#>  $ y    : num 4.2
#>  $ color: chr "red"
```
