# 概要

関数を使うと、コードを再利用できる単位にまとめることができます。
関数は、`func`キーワード、関数名、そして丸括弧（`()`）の中にカンマで区切って並べた0個以上の仮引数とその型からなります。

## 仮引数

仮引数には、必ず型を明示する必要があります。仮引数の型推論は行われません。
仮引数にデフォルト値はないので、関数の仮引数はすべて必須です。

```go
import "fmt"

// No parameters
func PrintHello() {
    fmt.Println("Hello")
}

// One parameter
func PrintHelloName(name string) {
  fmt.Println("Hello " + name)
}
```

同じ型の仮引数は、まとめて宣言し、そのあとに型を1つだけ書くことができます。

```go
import "fmt"

func PrintGreetingName(greeting, name string) {
  fmt.Println(greeting + " " + name)
}
```

## 仮引数と入力

よく混同されがちな2つの用語、`parameters`と`arguments`について、簡単に確認しておきましょう。
仮引数とは、関数のシグネチャで定義される名前のことです。たとえば、上の関数`PrintGreetingName`では`greeting`と`name`が仮引数です。
入力とは、関数を呼び出すときに仮引数へ渡す具体的な値のことです。
たとえば、次の例では`"Hello"`と`"Katrina"`が、仮引数`greeting`と`name`に渡される入力です。

```go
PrintGreetingName("Hello", "Katrina")
```

## 戻り値

仮引数のあとには、0個以上の戻り値を書きます。戻り値にも型を明示する必要があります。
戻り値が1つのときはそのまま書き、複数あるときは括弧で囲みます。
値は、[`return`キーワード][return]を使って、関数から呼び出し元のコードに返されます。
1つの関数の中に`return`文を複数書くこともできます。
関数の実行は、`return`文のいずれかに到達した時点で終了します。
複数の値を返す場合は、カンマで区切って並べます。
[複数の戻り値][concept-multiple-return-values]の慣用的な使い方について詳しくは、リンク先のコンセプトを参照してください。

```go
func Hello(name string) string {
  return "Hello " + name
}

func HelloAndGoodbye(name string) (string, string) {
  return "Hello " + name, "Goodbye " + name
}
```

## 関数の呼び出し

関数を呼び出すには、関数名を書き、括弧の中に各仮引数に対応する入力を渡します。

```go
import "fmt"

// No parameters, no return value
func PrintHello() {
    fmt.Println("Hello")
}
// Called like this:
PrintHello()

// One parameter, one return value
func Hello(name string) string {
  return "Hello " + name
}
// Called like this:
greeting := Hello("Dave")

// Multiple parameters, multiple return values
func SumAndMultiply(a, b int) (int, int) {
    return a+b, a*b
}
// Called like this:
aplusb, atimesb := SumAndMultiply(a, b)
```

## 名前付き戻り値と裸のreturn

仮引数と同様に、戻り値にも名前を付けることができます。
名前付き戻り値を使う場合、引数なしの`return`文を書くと、それらの値が返されます。
これは「裸のreturn」と呼ばれます。

```go
func SumAndMultiplyThenMinus(a, b, c int) (sum, mult int) {
    sum, mult = a+b, a*b
    sum -= c
    mult -= c
    return
}
```

## 値渡しと参照渡し

値渡しと参照渡しの違いについても、はっきりさせておきましょう。

まずは値渡しから見てみましょう。
次の例では、変数`val`を関数`MultiplyByTwo`に渡すとき、`val`のコピーが渡されます。
そのため、`newVal`は更新された値`4`を持ちますが、元の変数`val`は`2`のままです。
内部的には、Goは元の値のコピーを作るので、関数によって変更されるのはこのコピー、つまり`v`だけです。

```go
val := 2
func MultiplyByTwo(v int) int {
    v = v * 2
    return v
}
newVal := MultiplyByTwo(val)
// newval is 4, val is still 2 because only a copy of its value was passed into the function
```

厳密に言えば、Goではすべての入力が値渡しで渡されます。つまり、関数に渡された値やデータのコピーが作られます。
しかし、関数に渡すデータのコピーを作らず、関数の中でそのデータを変更したい場合は、入力として`pointers`を使います。これが参照渡しです。

## ポインター

参照渡しを実現するには、`pointer`を使います。
`pointer`を入力として関数に渡すと、データのコピーを操作するのではなく、関数に渡された元のデータを変更できます。

今のところは、ポインター型は関数のシグネチャで型の前に付く`*`で見分けられる、とだけ知っておけば十分です。

```go
func HandlePointers(x, y *int) {
    // Some logic to handle integer values referenced by pointers x and y
}
```

`pointer`の考え方が難しく感じても、心配いりません。
シラバスの後半に、ポインターをマスターするための専用のセクションがあります。

## 例外

`slices`と`maps`は、上で述べたルールの例外であることに注意してください。
`slice`や`map`を入力として関数に渡すと、型に`*`が明示されていなくても、ポインター型として扱われます。
つまり、スライスやマップを関数に渡してその元のデータを変更すると、その変更は元のスライスやマップにも反映されます。

## その他の種類の関数

Goでは、関数は[第一級オブジェクト][first-class-functions]とみなされるため、とても強力です。
関数に関しては、[メソッド][concept-methods]や無名関数など、ほかにもさまざまなコンセプトがあり、この後の学習で出てきます。
