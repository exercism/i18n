# 説明

友人のChandlerは、世界中のエキゾチックな国々を旅する予定です。残念ながら、Chandlerは計算が得意ではありません。旅先の両替所にだまされてしまうのではと、かなり心配しています。そして、あなたに為替計算機を作ってほしいと考えています。彼がアプリに求めている仕様は、次のとおりです：

## 1. 両替後の金額を見積もる

`exchange_money()`関数を作成してください。仮引数は2つです：

1. `budget`：両替する予定の金額。
2. `exchange_rate`：外貨1単位に相当する自国通貨の金額。

この関数は、両替した後の金額を返します。

**注意：**自国通貨がUSDで、為替レート`1.20`でUSDをEURに両替したい場合、`1.20 USD == 1 EUR`となります。

```python
>>> exchange_money(127.5, 1.2)
106.25
```

## 2. 両替後に残る金額を計算する

`get_change()`関数を作成してください。仮引数は2つです：

1. `budget`：両替前の金額。
2. `exchanging_value`：両替のために予算から*取り除かれる*金額。

この関数は、予算から*残った*金額を返します。

```python
>>> get_change(127.5, 120)
7.5
```

## 3. 紙幣の金額を計算する

`get_value_of_bills()`関数を作成してください。仮引数は2つです：

1. `denomination`：紙幣1枚の金額。
2. `number_of_bills`：紙幣の合計枚数。

この両替所は、決まった単位の現金しか扱いません。
受け取る合計金額は、1枚の「紙幣」、つまり1単位の金額で割り切れる必要があり、端数や余りが出ることがあります。
この関数は、両替所が返す紙幣の合計金額（_端数の金額を除く_）だけを返します。
残念ながら、その余りやおつりは、両替所がおまけとしてそのまま受け取ることになります。

```python
>>> get_value_of_bills(5, 128)
640
```

## 4. 紙幣の枚数を計算する

`get_number_of_bills()`関数を作成してください。仮引数は`amount`と`denomination`です。

この関数は、与えられた_金額_の中で受け取れる_紙幣の枚数_を返します。
言い換えると、最初の金額の中に、紙幣が_まるごと_何枚入るかということです。
受け取れるのは_まるごとの紙幣_だけで、紙幣の端数は受け取れません。ですから、それに合わせて割り算してください。
つまり、紙幣の単位まで_切り捨てて_いることになります。

```python
>>> get_number_of_bills(127.5, 5)
25
```

## 5. 紙幣に両替したあとの残りを計算する

`get_leftover_of_bills()`関数を作成してください。仮引数は`amount`と`denomination`です。

この関数は、紙幣の単位を考えると、最初の_金額_からは返せない_残りの金額_を返します。
両替所がいくらを懐に入れるのかを正確に知ることは、とても重要です。

```python
>>> get_leftover_of_bills(127.5, 20)
7.5
```

## 6. 両替後の金額を計算する

`exchangeable_value()`関数を作成してください。仮引数は`budget`、`exchange_rate`、`spread`、`denomination`です。

仮引数`spread`は、両替手数料として*差し引かれる割合*を整数で表したものです。
100で割って小数に変換する必要があります。
`1.00 EUR == 1.20 USD`で*spread*が`10`の場合、実際の為替レートは`1.00 EUR == 1.32 USD`になります。1.20の10%は0.12で、この追加手数料が為替レートに加算されるからです。

この関数は、*為替レート*に*spread*を加味したうえで、新しい通貨で受け取れる最大金額を返します。
通貨の*denomination*は整数であり、分割できないことを忘れないでください。

**注意：**戻り値の型は`int`です。

```python
>>> exchangeable_value(127.25, 1.20, 10, 20)
80
>>> exchangeable_value(127.25, 1.20, 10, 5)
95
```
