# 説明

この演習では、さまざまな種類のラジコンカーのレースを運営します。それぞれの車には、独自の速度とバッテリー消費の特性があります。

車はバッテリーが満充電（100%）の状態でスタートします。リモコンで車を操作するたびに、車はその速度の分だけメートル進み、残りのバッテリー残量がバッテリー消費の分だけ減ります。

車のバッテリーがバッテリー消費の割合を下回っていると、その車はもう動かせません。

レースコースにはそれぞれ独自の長さがあります。車は、バッテリー切れを起こさずにコースを完走できるかどうかでテストされます。

## 1. ラジコンカーを作成する

次の要素を持つ`car`配列を定義します。

- speed
- battery_drain
- battery
- distance_traveled

車の速度（メートル）とバッテリー消費の割合を2つの入力として受け取り、`car`配列を返す関数`new_car`を定義すると、ラジコンカーを作成できます。

新しい車では、バッテリーは100%で、走行距離はゼロです。

```R
speed <- 5
battery_drain <- 2
car <- new_car(speed, battery_drain)
str(car)
#> List of 4
#>  $ speed             : num 5
#>  $ battery_drain     : num 2
#>  $ battery           : num 100
#>  $ distance_traveled : num 0
```

## 2. レースコースを作成する

`track_length`という単一の要素を持つ、`track`という別の配列を定義します。
コースの距離（メートル）を受け取る関数`new_track`を定義すると、レースコースを作成できます。

```R
track_length <- 800
track <- new_track(track_length)
str(track)
#> List of 1
#>  $ track_length: num 800
```

## 3. バッテリー切れを確認する

バッテリーが切れているかどうかを示す関数`battery_drained()`を実装します。もう一度動かすのに十分なバッテリーが残っていない場合、バッテリーは切れているとみなされます。

```R
speed <- 5;
battery_drain <- 2;
car <- new_car(speed, battery_drain);
car <- drive(car);

battery_drained(car);
#> [1] FALSE
```

## 4. 車を走らせる

車の速度に基づいて走行距離を更新し、バッテリー消費に応じてバッテリーを減らす関数`drive`を実装します。
もう一度走らせるのに十分なバッテリーがない場合、車は動きません。

```R
speed <- 5
battery_drain <- 2
car <- new_car(speed, battery_drain)
car <- drive(car)
str(car)
#> List of 4
#>  $ speed             : num 5
#>  $ battery_drain     : num 2
#>  $ battery           : num 98
#>  $ distance_traveled : num 5
```

## 5. ラジコンカーがレースを完走できるか確認する

レースを完走するには、車がレースの距離を走り切れる必要があります。つまり、ゴールラインを越える前にバッテリーを使い切らないということです。 

`car`と`track`を入力として受け取り、その車がレースを完走できる場合は`TRUE`を、そうでない場合は`FALSE`を返す関数`can_finish`を実装します。

レースのスタートラインにいて、これからレースのために車のエンジンをかけるところだとします。レースの開始時に、車のバッテリーが必ずしも満充電とは限らないことに注意してください。

```R
speed <- 5
battery_drain <- 5
car <- new_car(speed, battery_drain)

name <- "track1"
track_length <- 100
track <- new_track(track_length)

can_finish(car, track)
#> [1] TRUE

# partial battery charge
car$battery <- 50
can_finish(car, track)
#> [1] FALSE
```

## 6. 満充電のバッテリーで車がコースを完走できるかどうかを保存する

長さの異なるコースをいくつか作成したので、満充電であれば車がそれらを完走できるかどうかを保存する必要があります。

車、コース、コース名を受け取り、要素を1つ追加した更新済みの車を返す関数`store_track`を実装します。
この要素の名前はコースの`name`で、その値は`track_length`と、車がそれを`complete`できるかどうかを持つサブ配列である必要があります。

渡される車は満充電とは限らないので、使う前にバッテリーと走行距離をリセットしてください。

```R
speed <- 5
battery_drain <- 5
car <- new_car(speed, battery_drain)
car$battery <- 50

name <- "track1"
track_length <- 100
track <- new_track(track_length)

track1 <- store_track(car, track, "Imola")
str(track1)
#> List of 5
#>  $ speed             : num 5
#>  $ battery_drain     : num 5
#>  $ battery           : num 100
#>  $ distance_traveled : num 0
#>  $ Imola             :List of 2
#>   ..$ track_length: num 100
#>   ..$ complete    : logi TRUE
```
