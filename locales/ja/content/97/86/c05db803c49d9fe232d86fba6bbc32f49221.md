# PowerShellを学ぶ

PowerShellの学習を始めるのに最適なのは、PowerShellの公式サイトにある[学習セクション][learning section]で学習リソースを選ぶことです。
ここには膨大な情報があり、幅広いPowerShellのトピックへのリンクがまとめられています。

PowerShellには、自分自身の使い方を説明してくれる、とても充実したヘルプシステムもあります。
PowerShellが提供する機能の多くは、`Get-Help`コマンドレットを使って調べることができます。
PowerShellの中で、次のように試してみましょう。

```PowerShell
Get-Help about
```

3ページ分ほどのトピックが表示され、それぞれを調べていけます。
さらにもう2つ、とても役立つ関数があります。

- Get-Command
- Get-Member

何をするものなのか知りたいですか？　それなら、もちろん`Get-Help Get-Command`と`Get-Help Get-Member`を試してみてください。

## PowerShellの動詞と名詞

PowerShellのコマンドレットの名前は、かなり厳密な「動詞-名詞」の形に従っています。
経験豊富なプログラマーには、最初は戸惑うものかもしれません。
関数には好きな名前を付けられますが、標準の動詞に慣れてそれを使うようにすると、PowerShellのコードを書く力が上がります。

承認されているすべての動詞の一覧を見るには、次のコマンドを実行するだけです。

```PowerShell
Get-Verb
```
