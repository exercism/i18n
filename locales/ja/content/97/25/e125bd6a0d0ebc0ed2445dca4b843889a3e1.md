# 概要

ゲームでも、ウェブブラウザーでも、スマートフォンのアプリでも、これまでに実行したことのあるプログラムはすべて、最終的にはプロセッサーが一つずつ実行する小さな命令の長いリストになります。
アセンブリ言語を使えば、そうした命令を自分で書くことができます。
変数や配列、`for`ループの代わりに扱うのは、プロセッサー自身の部品です。少数のレジスター、メモリーアドレス、そしてある命令から別の命令へのジャンプです。

RISC-V（「リスクファイブ」と読みます）は、2010年にカリフォルニア大学バークレー校で始まったプロセッサーの設計です。
ほとんどのプロセッサーの設計とは違い、これはオープンな標準です。RISC-Vチップを作るために料金を払ったり許可を求めたりする必要はなく、仕様書は誰でも無料で読むことができます。
RISC-Vチップは、マイクロコントローラー、シングルボードコンピューター、ストレージデバイスなどで使われています。

RISC-Vは、シンプルになるように設計されているので、初めて学ぶアセンブリ言語として適しています。
命令は少数の規則的なパターンに従っており、32個のレジスターには明確で一貫した役割があるので、ほとんどのノートパソコンのプロセッサーに比べて覚えることがずっと少なくて済みます。
そのシンプルさから、今では多くの大学が、コンピューターの仕組みを教えるためにRISC-Vを使っています。

ここで少しだけ紹介します。2つの数値を足す関数です。

```riscvasm
add_numbers:
        add     a0, a0, a1      /* a0 = a0 + a1 */
        ret                     /* return to the caller, with the answer in a0 */
```

このトラックでは、32ビットのRISC-Vアセンブリを書きます。
RISC-Vのハードウェアは必要ありません。プログラムは、RISC-Vプロセッサーのふりをするエミュレーターでテストされます。
演習は、オンラインエディターで解くことも、無料のツールを使って自分のコンピューターで解くこともできます。

アセンブリの学習には忍耐が必要ですが、その分の見返りはあります。
ループや関数呼び出しがプロセッサーにとってどんなものかを一度見てしまえば、ほかのどのプログラミング言語も、少しだけよくわかるようになります。
