# はじめに

## 浮動小数点数

浮動小数点数とは、小数点以下に0桁以上の数字を持つ数のことです。たとえば、`-2.4`、`0.1`、`3.14`、`16.984025`、`1024.0`などがあります。

浮動小数点型によって、小数点以下に保持できる桁数は異なります。この桁数のことを精度と呼びます。

C#には3つの浮動小数点型があります。

- `float`: 4バイト（精度は約6〜9桁）。`2.45f`のように書きます。
- `double`: 8バイト（精度は約15〜17桁）。もっともよく使われる型です。`2.45`または`2.45d`のように書きます。
- `decimal`: 16バイト（精度は28〜29桁）。ふつうは金額データを扱うときに使います。精度が高いため、丸め誤差が起こる可能性を減らせるからです。`2.45m`のように書きます。

このように、型によって保持できる桁数は異なります。たとえば、PIを`float`に保持しようとすると、小数点以下6桁までしか保持されません（最後に保持される桁は丸められます）。

## `while`ループ

この演習では、ループを使いたくなるかもしれません。C#でループを書く方法はいくつかありますが、ここでは`while`ループがもっとも適しています。

```csharp
int x = 23;

while (x > 10)
{
    // Execute logic if x > 10
    x = x - 2;
}
```

## `do`/`while`ループ

ループの中のコードを必ず1回以上実行したい場合は、`do`/`while`ループを使います。

```csharp
int x = 23;

do
{
    // Execute body, repeating only if x > 10
    x = x - 2;
} while (x > 10);
```
