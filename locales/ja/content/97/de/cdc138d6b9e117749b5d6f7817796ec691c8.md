# はじめに

文字クラスや量指定子だけでなく、正規表現では*構造*や*文脈*を表すこともできます。これらの機能も、同じ[`regexp`][regexp]という語彙、そして同じ`R/ /`リテラルの中にあります。

丸括弧（`( )`）を使うと、パターンの一部をグループにまとめられます。すると、量指定子や`|`（「これか、あれ」）がグループ全体にかかるようになります。グループの後ろに`?`を付けると、そのグループを省略可能にできます。

```factor
USING: regexp ;

"abab"    R/ (ab)+/ matches? .             ! => t
"$100"    R/ \$\d+(\.\d{2})?/ matches? .   ! => t   (optional group)
```

アンカーは、パターンをある位置に固定します。`^`（先頭）、`$`（末尾）、`\b`（単語の境界）です。

*ルックアラウンド*は、ある位置の周りにあるものを使ってマッチさせますが、その位置自体は消費しません。

```
(?=...)    ! lookahead — ... must follow
(?!...)    ! negative lookahead — ... must not follow
(?<=...)   ! lookbehind — ... must come before
```

```factor
USING: regexp ;

"spent $100 and $25" R/ (?<=\$)\d+/ all-matching-subseqs .
! => { "100" "25" }

"up 5% then 12%" R/ \d+(?=%)/ all-matching-subseqs .
! => { "5" "12" }
```

閉じの`/`のあとに付けるオプション文字は、パターン全体の動作を変えます。`i`を付けると、大文字と小文字を区別しなくなります。

```factor
USING: regexp ;

"REFUND" R/ refund/i matches? .   ! => t
```

Factorはキャプチャグループの代わりにルックアラウンドを使います。Factorには、キャプチャグループの取り出し、後方参照、最短一致の量指定子がありません。

[regexp]: https://docs.factorcode.org/content/vocab-regexp.html
