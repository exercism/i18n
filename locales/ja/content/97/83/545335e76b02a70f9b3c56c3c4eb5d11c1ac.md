# 指示

この演習では、車両の購入の準備を手伝うコードを書きます。

タスクは3つあります。1つは運転免許証が必要かどうかを判断するもの、1つは2つの車両から選ぶのを手伝うもの、もう1つは中古車の適正価格を見積もるものです。

## 1. 運転免許証が必要かどうかを判断する

車両の種類によっては、運転するために運転免許証が必要です。
`"car"`と`"truck"`の2種類だけが免許を必要とし、それ以外は免許なしで運転できるものとします。

`needs_license(kind)`関数を実装してください。この関数は車両の種類を文字列として受け取り、その種類の車両に免許が必要かどうかを示す真偽値を返します。

```cpp
needs_license("car")
// => true

needs_license("bike")
// => false

needs_license("truck")
// => true
```

## 2. 購入候補の2つの車両から1つを選ぶ

購入できる車両の中から、選択肢を検討します。
2つの候補まで絞り込むことができましたが、最終的な決断を下すには助けが必要です。
そのために、`choose_vehicle(option1, option2)`関数を実装してください。この関数は2つの車両を引数として受け取り、辞書順で先に来る方の選択肢を含む判断を返します。

```cpp
choose_vehicle("Wuling Hongguang", "Toyota Corolla")
// => "Toyota Corolla is clearly the better choice."

choose_vehicle("Volkswagen Beetle", "Volkswagen Golf")
// => "Volkswagen Beetle is clearly the better choice."
```

返される文字列は、"<CHOSEN_VEHICLE> is clearly the better choice."というパターンに従う必要があります。ここで`<CHOSEN_VEHICLE>`は、渡された引数のうち選んだ方の車両です。

## 3. 中古車の価格の見積もりを計算する

決断を下したので、ディーラーで適正な価格で買えるようにしたいところです。
中古車の購入を考えているので、価格は車両の使用年数によって変わります。
大まかな見積もりとして、車両が3年未満なら、新車だったときの価格の80%になると仮定します。
10年以上経過していれば、50%になります。
車両が3年以上10年未満であれば、元の価格の70%になります。

`calculate_resell_price(original_price, age)`関数を実装してください。この関数は`if`、`else if`、`else`を使ってこのロジックを適用します（練習したい場合は他の書き方もあります）。
元の価格と車両の使用年数を引数として受け取り、ディーラーでの見積もり価格を返します。

```cpp
calculate_resell_price(1000, 1)
// => 800

calculate_resell_price(1000, 5)
// => 700

calculate_resell_price(1000.0, 15)
// => 500
```

> 注: 戻り値の型は`double`です。
