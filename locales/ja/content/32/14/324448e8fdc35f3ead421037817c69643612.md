# 説明

友達とゲーム会を計画するなかで、みんなは子供のころに夢中になったゲームをもう一度遊ぶことにしました。そこでドイツ人の友達が提案したのが『Mensch ärgere Dich nicht』（「人よ、怒るな」の意味）です。これはヨーロッパの多くの国で定番のゲームで、英語圏の『Ludo』や北米の『Parcheesi』に似ています。

ゲームの準備として、サイコロを振る関数をElixirで実装することにしました。

『Mensch ärgere Dich nicht』では、プレイヤーは6面サイコロを1つ振って次の手を決めます。運よく6が出たら、もう一度振って進むことができます。

## 1. 6面サイコロを1回振る

`d6/0`関数を実装しましょう。呼び出すたびに、1から6までの整数をランダムに1つ選んで返します。

```elixir
MenschAergereDichNicht.d6()
# => 1
MenschAergereDichNicht.d6()
# => 5
```

## 2. 6が出る限り振り続ける

`roll/0`関数を実装しましょう。サイコロの出目のストリームを返します。出目はゲームのルールに従う必要があります。6を出したら、もう一度振ることができます。それ以外なら、振るのをやめます。前のステップで定義した`d6/0`関数を使います。

```elixir
MenschAergereDichNicht.roll() |> Enum.to_list()
# => [5]
MenschAergereDichNicht.roll() |> Enum.to_list()
# => [6, 3]
```

## 3. 細工されたサイコロを使えるようにする

コードをテストしやすくするために、細工されたサイコロを使えるようにしましょう。

`roll/0`関数を拡張します。省略可能な引数として、関数を受け取れるようにします。引数が渡されたら、それを使ってサイコロを振ります。渡されなければ、`MenschAergereDichNicht.d6/0`を使います。

```elixir
MenschAergereDichNicht.roll(fn -> 3 end) |> Enum.to_list()
# => [3]
```
