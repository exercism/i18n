# 概要

Gleamの不透明型は、その型を定義したモジュールだけが、その型の値を作成したりパターンマッチしたりできるカスタム型です。特定の使い方だけを想定した型を作りたいときに便利です。

不透明型は、`opaque`キーワードを使って定義します。

```gleam
pub opaque type PositiveInt {
  PositiveInt(inner: Int)
}
```

この`PositiveInt`型は、整数が欲しいけれど、その値が0以上でなければならない場面で使います。通常のGleamの`Int`は負の値も取れるため、この用途には使えません。

この型を定義しているモジュールでは、内側の整数値を取り出す関数と、`PositiveInt`型を作る関数を定義できます。後者は、値が正でなければエラーを返します。

```gleam
pub fn from_int(i: Int) -> Result(PositiveInt, String) {
  case i {
    _ if i < 0 -> Error("Value must be positive")
    _ -> Ok(PositiveInt(i))
  }
}

pub fn to_int(i: PositiveInt) -> Int {
  i.inner
}
```

このAPIがあれば、他のモジュールが負の値を持つ`PositiveInt`を作成することはできません。そのため、`PositiveInt`を受け取る関数は、その値が正であると確信できます。
