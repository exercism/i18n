# はじめに

状態を持つオブジェクトを作るという手間が不要な場合もあります。
そんなときは、`module`を使えます。

モジュールはクラスとよく似ています（実際、オブジェクトの階層では`Module`は`Class`の祖先です）。主な違いは、インスタンスメソッドではなくクラスメソッドを使うという点です。
クラスメソッドは`self.`で始まり、モジュールから直接呼び出します。

たとえば、次のとおりです。

```ruby
module Speaker
  def self.echo(something)
    "#{something} ... #{something}"
  end
end

Speaker.echo("Hello")   #=> "Hello ... Hello"
```
