# 指示の補足

有理数を実数でべき乗するには、非整数を指数とする計算が必要です。これはWebAssemblyでは標準で利用できない機能です。

ただし、`x ^ y`は`x ^ y = exp(y * ln(x))`と表すこともできます。

そして幸いなことに、指数関数と自然対数を計算するには、さまざまな級数を利用できます。

## 指数関数

指数関数の計算には、[テイラー級数](https://en.wikipedia.org/wiki/Taylor_series)を使うのが最善です。

```
exp(x) ≃ 1 + x + x ^ 2 / 2! + x ^ 3 / 3! + x ^ 4 / 4! + ... + x ^ n / n!
```

## 対数関数（正のxの場合）

自然対数を効率よく計算する方法はいくつかあります。その1つは、[逆双曲線正接](https://en.wikipedia.org/wiki/Logarithm#Inverse_hyperbolic_tangent)に基づく級数です。

```
ln(x) / 2 ≃ y + y ^ 3 / 3 + y ^ 5 / 5 + ... + y ^ n / n where y = (x - 1) / (x + 1)
```

自然対数を計算する別のテイラー級数もあります。

```
ln(x) = (x - 1) - (x - 1) ^ 2 / 2 + (x  - 1) ^ 3 / 3 - (x - 1) ^ 4 / 4 ... + (x - 1) ^ n / n
```

これは`x`が0から2の間でのみ正確です。ただし、`ln(x) = - ln(1 / x)`も使えます。

## 整数のべき乗

整数のべき乗には、性能と精度の両方の理由から、乗算と、ループまたは再帰を使うのがよいでしょう。さらに性能を高めるには、乗算の回数を減らすために[ホーナー法](https://en.wikipedia.org/wiki/Horner%27s_method)を使うこともできます。
