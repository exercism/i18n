# はじめに

`if`文に加えて、JavaScriptには条件によって処理を切り替える`switch`文もあります。
これは、1つの変数を複数の候補と比較するときに使います。
比較は厳密等価（`===`）かどうかで行います。詳しくは[比較の概念][concept-comparison]を参照してください。
ある変数`x`に対して、JavaScriptの`switch`文は次のような構文になります。

<!-- prettier-ignore-start -->
```javascript
switch (x) {
  case option1:
    // code that is executed when "x === option1" is true
    break;
  case option2:
    // code that is executed when "x === option2" is true
    break;
  default:
    // code that is executed when x does not equal any of the options
}
```
<!-- prettier-ignore-end -->

`default`ケースは省略可能で、どの候補も変数と一致しなかったときに実行したいコードがある場合に使います。

上の`break`文が必要なのは、JavaScriptでは既定ですべてのケースが「フォールスルー」するからです。
つまり、`break`文がないと、`x`がそれらの候補と一致していなくても、最初に一致した候補より下にあるケースのコードがすべて実行されてしまいます。
この「既定でフォールスルーする」という動作は、JavaScriptで`switch`を使うときによくある落とし穴です。
関数の中では、この問題を避けるために`break`の代わりに`return`を使うこともできます。
