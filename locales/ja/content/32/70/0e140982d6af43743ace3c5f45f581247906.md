# 概要

Haskellで関数を書くときは、[パターンマッチ][pattern-matching]を活用できます。
パターンマッチはHaskellのとても強力な機能で、データコンストラクターにマッチさせたり、中の値に変数を束縛したりできます。
名前のとおり、値とパターンを照らし合わせ、値がパターンにマッチすれば、そのパターンの中の値に変数を束縛できます。
パターンマッチは主に、値を見分けること、変数を束縛すること、値を分解すること、という考え方から成り立っています。

~~~~exercism/note
Elixirなどの言語のパターンマッチは、Haskellのパターンマッチとは少し違います。
たとえばElixirでは、1つのパターンの中に同じ束縛名を複数書けますが、Haskellではできません。
~~~~


では、次の関数を見てみましょう。

```haskell
lucky :: Int -> String
lucky 7 = "Lucky number seven!"
lucky x = "Sorry, you're out of luck, pal!"
```

ここには、`Int`を受け取って`String`を返す`lucky`という関数があります。
この関数には2つのパターンを定義しています。1つは数値の`7`にマッチするもの、もう1つはそれ以外のどんな数値にもマッチするもので、名前は何でもかまいません（Haskellの命名規則に従っていればよいのですが、ここでは`x`を使っています）。
数値が`7`なら、この関数は`"Lucky number seven!"`を返し、そうでなければ`"Sorry, you're out of luck, pal!"`を返します。
ここで大切なのは、パターンは上から下へ順に調べられるという点です。もしパターンの順番を入れ替えていたら、この関数はいつも`"Lucky number seven!"`を返すことになります。

## リストのパターン

よく使われるパターンが、リストにマッチさせるものです。これはリストの先頭と残りを取り出すものです。
これは、リストが連結リストであるという性質によるものです。
次は、リストの先頭と残りを返す関数の例です。

```haskell
headAndTail :: [Int] -> (Int, [Int])
headAndTail [] = error "Can't call head on an empty list"
headAndTail (x:xs) = (x, xs)
```

ここには2つのパターンがあります。1つは空のリストにマッチするもの、もう1つは要素を1つ以上もつリストにマッチするものです。
リストが空の場合、そのための場合分けを用意しないと、実行時エラーになってしまうからです。
リストが空でなければ、リストの先頭を`x`に、残りを`xs`にマッチさせられます。
これには`:`（cons）演算子を使います。この演算子は、リストの先頭に要素を追加するためのものです。
しかしパターンマッチでは、リストを先頭と残りに分解できます。ある意味で、逆のことをしているわけです。

`xs`はリストの残りによく使われる名前で、これがリストであることを示しています。入れ子のリストを扱うなら、`xss`を使えば、リストのリストであることを示せます。

## タプルのパターン

リストと同じように、タプルにもマッチさせられます。
次は、タプルを受け取って1番目と2番目の要素を返す関数の例です。

```haskell
sumTuple :: (Int, Int) -> Int
sumTuple (x, y) = x + y
```

ここでは、2つの要素をもつタプルにマッチするパターンがあり、1番目の要素は`x`に、2番目の要素は`y`に束縛されます。

## ワイルドカードパターン

変数の値が必要ないこともあります。ただパターンにマッチさせたいだけの場合です。
そこで登場するのがワイルドカードパターンで、アンダースコア`_`で表します。

次は、リストの最初の要素を返す関数の例です。

```haskell
head' :: [Int] -> Int
head' [] = error "Can't call head on an empty list"
head' (x:_) = x
```

ここでは、リストの残りは必要ないので、ワイルドカードパターンを使って無視しています。

## 型のパターン

型にもマッチさせられます。これは、その型のコンストラクターを使うことで行います。
タプルのときと同じように、型から値を取り出すこともできます。

```haskell
data AccountType = Guest | User String 

greet :: AccountType -> String
greet Guest = "Welcome, guest!"
greet (User name) = "Welcome, " ++ name ++ "!"
```

最初のパターンでは`Guest`コンストラクターにマッチさせ、2番目のパターンでは`User`コンストラクターにマッチさせて、中の値を`name`に束縛します。

[pattern-matching]: https://en.wikibooks.org/wiki/Haskell/Pattern_matching
