# ヒント

## 全般

- 契約は、戻り値の型のあと、`is`の前に書きます。

  ```sather
     spare_capacity(load : INT) : INT
        pre load >= 0
     is
        ...
     end;
  ```

- 契約の中では引数とオブジェクトの属性を使えるので、`limit`も使えます。
- テストは`-chk`なしでビルドされるので、契約が間違っていてもテストは失敗しません。読む人のために書きましょう。

## 1. ハーネスを仕込む

- `create`に`pre kg > 0`を付けます。
- 本体はいつもどおりの`new`です。属性に値を設定して、それを返します。

## 2. 余裕はどれくらいある？

- `and`でつないだ2つの条件、`pre load >= 0 and load <= limit`。
- `post result >= 0`。これは`pre`から導かれることで、だからこそ書く価値があります。答えをなぜ信頼できるのかが記録されるからです。

## 3. どれくらい埋まっている？

- `pre load >= 0`と`post result >= 0`。
- `load * 100 / limit`の順で書きます。先に割り算をすると、`tuning-the-strings`の場合と同じように、すべてが失われてしまいます。

## 4. 安全か？

- `pre`はまったく書きません。どんな`load`についても問い合わせられることこそが要点だからです。
- `post`は問いをそのまま言い直したものです。`post result = (load <= limit)`。`=`を2つの別の意味で使っているので、括弧（`()`）を付けます。
