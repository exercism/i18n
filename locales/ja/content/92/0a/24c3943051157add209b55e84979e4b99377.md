# 指示

この演習では、Cairoの制御フローの構文を使って、小さなベーカリーの日々の業務を管理します。

## 1. 注文の合計を計算する

ペストリーの種類と数量をもとに注文の金額を計算する`calculate_total`を実装します。

- クロワッサン：1つ3コイン
- マフィン：1つ2コイン
- クッキー：1つ1コイン

```rust
calculate_total(Pastry::Croissant, 4) // Returns: 12 (4 * 3)
calculate_total(Pastry::Cookie, 10)   // Returns: 10 (10 * 1)
```

## 2. 数量割引を適用する

注文の合計金額に応じて割引を適用する`apply_discount`を実装します。
割引率を合計金額に掛けてから、コイン単位の整数になるように切り捨てます（floor）。

- 20コイン以上の注文：10%割引
- 10コイン以上の注文：5%割引
- 10コイン未満の注文：割引なし

```rust
apply_discount(25) // Returns: 22
apply_discount(15) // Returns: 14
apply_discount(8)  // Returns: 8
```

## 3. 焼きスケジュールを作成する

1日の焼き計画を作る`baking_schedule`を実装します。
ベーカリーは1時間に5件の注文ずつ、バッチに分けて焼きます。

```rust
baking_schedule(18) // Returns: [5, 5, 5, 3] (3 full batches + 3 remaining)
baking_schedule(10) // Returns: [5, 5] (2 full batches)
baking_schedule(3)  // Returns: [3] (1 partial batch)
```

それぞれの問題を効率よく解くには、適切な制御フローの構文（`if`/`else`、`loop`）を使いましょう。
