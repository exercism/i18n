# 説明の補足

## スタブ

`src/TreeBuilding.hs`には、すべてのテストに合格する動作する解答がすでに含まれています。
遅くて読みにくいですが、テストを壊さずに改善するのが課題です。

レコードが有効なツリーにならない場合、`buildTree`は`Nothing`を返します。

## 表現の変更

テストは`Tree`のコンストラクタを直接使うことはありません。
代わりに、次の関数で期待するツリーを組み立てます。

```haskell
node :: Int -> [Tree] -> Tree
```

ここで、`node i children`は、idが`i`で、指定された子をidの昇順に持つノードです。

つまり、`Tree`の表現方法は自由に変更できます。たとえば、次のように変更してもかまいません。

```haskell
import qualified Data.Tree as T

type Tree = T.Tree Int

node :: Int -> [Tree] -> Tree
node = T.Node
```

ただし、`Tree`が`Eq`と`Show`のインスタンスを引き続き持ち、`node`の意味が変わらないことが条件です。
`containers`などのライブラリを使う場合は、`package.yaml`の`dependencies`に追加するのを忘れないでください。
