# 説明

町に新しい詩のクラブができました。入ってみようかと考えています。
過去にいくつか事件が起きているため、このクラブにはとても独特な入室ポリシーがあり、中に入ろうとする前にそれをマスターしておく必要があります。

詩のクラブには2つの扉があり、どちらにもガードが立っています。
中に入るには、その日のパスワードを割り出す必要があります：

## 1. 文字列を行ごとに分割する

まず最初に、詩を行ごとに分割します。
ガードが詩を暗唱するので、それを行ごとに分割することになります。

文字列を受け取り、改行文字を区切りとして文字列の配列に分割する関数`splitOnNewlines`を実装します。
この関数は文字列の配列を返します。各要素は、詩の1行です。

```swift
splitOnNewlines("Hello.\nHow are you?\n\nI'm doing fine.")
// returns ["Hello." ,"How are you?", "", "I'm doing fine"].
```

## 2. 正面の扉

1. ガードが詩を暗唱します。
2. 詩を行ごとに分割します。
3. 各行の最初の文字を取り出します。
   - 行が空の場合は、代わりに`_`を使います。
4. それらの文字をつなげると、1つの単語になります。

たとえば、彼らが好きな作家の一人にMichael Lockwoodがいます。彼は次のような_アクロスティック_の詩を書いています。アクロスティックとは、各行の最初の文字をつなげると1つの単語になる詩のことです：

```text
Stands so high
Huge hooves too
Impatiently waits for
Reins and harness
Eager to leave
```

ガードがこの詩を暗唱したら、それを行ごとに分割し、各行の最初の文字を答えます。つまり`["S", "H", "I", "R", "E"]`です。

するとガードは、あなたが答えた文字の配列からできた単語を渡してくるので、それを大文字の形にします。
こうして最終的に返すパスワードは`"SHIRE"`となり、中に入れます。

詩を表す文字列を受け取る関数`frontDoorPassword`を実装します。
この関数は、ガードに渡すパスワードを返すようにします。

```swift
frontDoorPassword("Stands so high\nHuge hooves too\nImpatiently waits for\nReins and harness\nEager to leave")
// returns "SHIRE"
```

## 3. 裏の扉

クラブの奥には、VIPエリアのような、最も著名な詩人たちが集まっています。
誰もが入れる場所ではないので、裏口の手順はもう少し込み入っています。

1. ガードが詩を暗唱します。
2. 詩を行ごとに分割します。
3. 各行の最後の文字を取り出します。
   - 行の末尾に空白が付いていることがあるので、それを取り除く必要があります。
4. それらの文字をつなげてから、できた単語の末尾に`", please"`を付け加えます。

たとえば、先ほどの詩は_テレスティック_でもあります。テレスティックとは、各行の最後の文字をつなげると1つの単語になる詩のことです：

```text
Stands so high
Huge hooves too
Impatiently waits for
Reins and harness
Eager to leave
```

ガードがこの詩を暗唱したら、それを行ごとに分割し、末尾の空白を取り除いて、各行の最初の文字を答えます。つまり`["h", "o", "r", "s", "e"]`です。

するとガードは、あなたが答えた文字の配列からできた単語を渡してくるので、それを大文字の形にして、末尾に`", please"`を付け加えます。
こうして最終的に返すパスワードは`"horse, please"`となり、中に入れます。

詩を表す文字列を受け取る関数`backDoorPassword`を実装します。
この関数は、ガードに渡すパスワードを返すようにします。

```swift
backDoorPassword("Stands so high\nHuge hooves too\nImpatiently waits for\nReins and harness\nEager to leave")
// returns "horse, please"
```

## 4. 秘密の部屋

クラブの奥の部屋にはもう1つ扉があり、その先の秘密の部屋には、ごく一部の一流の詩人だけが入ることができます。

1. ガードが詩を暗唱します。
2. 詩を行ごとに分割します。
3. i<sup>番目</sup>の行のi<sup>番目</sup>の文字を取り出します。
4. それらの文字をつなげてから、できた単語の末尾に`"!"`を付け加えます。
5. その単語をすべて大文字にします。

たとえば、先ほどの詩を少し変えたものは、このパターンに当てはまります：

```text
Stands so high
Huge hooves too
Impatiently waits for
Rider with harness
Eager to leave
```

ガードがこの詩を暗唱したら、それを行ごとに分割し、末尾の空白を取り除いて、各行のi<sup>番目</sup>の文字を答えます。つまり["S", "u", "p", "e", "r"]です。

するとガードは、あなたが答えた文字の配列からできた単語を渡してくるので、それをすべて大文字にして、末尾に`"!"`を付け加えます。
こうして最終的に返すパスワードは`SUPER!`となり、中に入れます。

詩を表す文字列を受け取る関数`secretRoomPassword`を実装します。
この関数は、ガードに渡すパスワードを返すようにします。

```swift
secretRoomPassword("Stands so high\nHuge hooves too\nImpatiently waits for\nRider with harness\nEager to leave")
// returns "SUPER!"
```
