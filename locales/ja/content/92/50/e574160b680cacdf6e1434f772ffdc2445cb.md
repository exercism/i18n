# 指示

この演習では、往年の名作ゲーム「パックマン」のルールをいくつかGleamの関数に翻訳していきます。

翻訳するルールは4つあり、いずれもゲームの状態に関するものです。

> 入力がどのようにして生まれるかは気にしなくて構いません。入力を組み合わせて、意図した結果を返すことだけに集中しましょう。

## 1. パックマンがゴーストを食べるかどうかを定義する

2つの入力（_パワーエサの効果が有効かどうか_と_ゴーストに触れているかどうか_）を受け取り、パックマンがゴーストを食べられるかどうかを真偽値で返す`eat_ghost`関数を定義します。この関数は、パワーエサの効果が有効で、かつゴーストに触れているときだけ`True`を返すようにします。

```gleam
eat_ghost(False, True)
// -> False
```

## 2. パックマンが得点するかどうかを定義する

2つの入力（_パワーエサに触れているかどうか_と_ドットに触れているかどうか_）を受け取り、パックマンが得点したかどうかを真偽値で返す`score`関数を定義します。この関数は、パワーエサかドットに触れているときに`True`を返すようにします。

```gleam
score(True, True)
// -> True
```

## 3. パックマンが負けるかどうかを定義する

2つの入力（_パワーエサの効果が有効かどうか_と_ゴーストに触れているかどうか_）を受け取り、パックマンが負けるかどうかを真偽値で返す`lose`関数を定義します。この関数は、ゴーストに触れていて、かつパワーエサの効果が有効でないときに`True`を返すようにします。

```gleam
lose(False, True)
// -> True
```

## 4. パックマンが勝つかどうかを定義する

3つの入力（_すべてのドットを食べたかどうか_、_パワーエサの効果が有効かどうか_、_ゴーストに触れているかどうか_）を受け取り、パックマンが勝つかどうかを真偽値で返す`win`関数を定義します。この関数は、すべてのドットを食べていて、かつパート3で定義した入力をもとに負けていないときに`True`を返すようにします。

```gleam
win(False, True, False)
// -> False
```
