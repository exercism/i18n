# 説明

海辺の無線小屋で、チャンネルの交信を聞きながら過ごしています。メッセージは回線を通って届き、それを記録し、返信を送り返します。この5つの小さなワードが、1回の勤務分の仕事を引き受けます。

テストでは、入力（受信トラフィック）として`<string-reader>`が渡され、出力には`<string-writer>`が使われます。ただ、ここで扱うどのワードも、実際の`<file-reader>`やソケットに対しても同じように動きます。

## 1. すべて聞き取る

`hear-out`を定義し、入力ストリームを1つの文字列に読み切ります。

```factor
"all quiet on the channel" <string-reader> hear-out .
! => "all quiet on the channel"
```

## 2. メッセージを数える

`count-messages`を定義し、入力ストリームから各行を読み込んで、行が何行あったかを返します。

```factor
"alpha\nbravo\ncharlie\n" <string-reader> count-messages .
! => 3
```

## 3. 最後の交信を復唱する

`echo-back`を定義し、各行を読み込んで、**最後の1行を大文字にして**返します。これが無線でおなじみの「あなたはXと言いました」という復唱です。

```factor
"alpha\nbravo\n" <string-reader> echo-back .
! => "BRAVO"
```

## 4. メッセージを一斉送信する

`broadcast`を定義し、渡されたライターにメッセージを書き込み、ストリームをフラッシュしてすぐに送出されるようにします。戻り値はありません。

```factor
[ "mayday" output-stream get broadcast ] with-string-writer .
! => "mayday"
```

## 5. クォーテーションの出力を取り込む

`capture`を定義し、新しいstring-writerをその時点の出力先としてクォーテーションを実行し、クォーテーションが出力したものをそのまま返します。このクォーテーションは引数を取りません。いつもどおり、その場のストリームに書き込むだけです。

```factor
[ "test broadcast" print ] capture .
! => "test broadcast\n"
```
