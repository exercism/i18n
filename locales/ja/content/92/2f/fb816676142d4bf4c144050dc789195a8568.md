# 真偽値型

Cairoでは、真偽値型は論理演算と条件文に欠かせません。Cairoの真偽値はサイズが`felt252`1つ分で、スペースを効率的に使いながら、true/falseロジックの単純さを保ちます。

Cairoで真偽値型を指定するには、キーワード`bool`を使います。これにより、言語内で真偽値変数を宣言したり操作したりできます。たとえば、次の例を見てみましょう。

```rust
fn main() {
    let t = true;
    let f: bool = false; // with explicit type annotation
}
```

この例では、2つの真偽値変数を宣言しています。変数`t`には値`true`が代入され、暗黙的に真偽値型として宣言されます。一方、変数`f`は`bool`型であると明示的に注釈され、値`false`が代入されます。

注意すべき重要な点が1つあります。Cairoで真偽値変数を宣言するときは、値として`true`または`false`のリテラルを使うことが必須です。つまり、`0`や`1`のような整数リテラルを、`false`や`true`の代わりに使うことはできません。このルールを厳格に適用することで、型安全性が確保され、スマートコントラクト開発における潜在的な論理エラーを防げます。

## Cairoの真偽値演算子

- `||`（論理OR）：少なくとも一方のオペランドが`true`なら`true`を返します。
- `&&`（論理AND）：両方のオペランドが`true`なら`true`を返します。
- `!`（否定）：オペランドの真偽値を反転させた値を返します。

## コード例

次のコードは、Cairoで真偽値型を使う方法を示しています。真偽値変数の宣言、真偽値式の代入、真偽値ロジックが正しいことを検証するアサーションの使い方を示しています。

```rust
fn main() {
    // Declaration of Boolean variables
    let t: bool = true;
    let f: bool = false;

    // Boolean expression evaluation
    let true_expr = 5 == 5; // true
    let false_expr = 7 == 5; // false

    // Using Boolean operators
    let or_expr = t || f; // true || false => true
    let and_expr = t && f; // true && false => false
    let not_expr = !f; // !false => true

    // Assertions to verify the correctness
    assert(t == true_expr, 'this should be true'); // t == true
    assert(f == false_expr, 'this should be false'); // f == false
    assert(or_expr == true, 'this should be true for OR'); // true
    assert(and_expr == false, 'this should be false for AND'); // false
    assert(not_expr == true, 'this should be true for NOT'); // true
}
```
