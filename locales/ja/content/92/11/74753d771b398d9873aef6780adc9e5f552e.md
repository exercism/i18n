# はじめに

## セット

[`Set`][set-docs]は、順序を持たないコレクションで、`List`とは違って重複する値を含まないことが保証されています。

`Set`インターフェースの総称型パラメーターは、`Set`に含まれる要素の型を表します。

```java
Set<Integer> ints = Set.of(1, 2, 3);
Set<String> strings = Set.of("alpha", "beta", "gamma");
Set<Object> mixed = Set.of(1, false, "foo");
```

`Set.of()`メソッドは[_変更不可能_][unmodifiable-set-docs]な`Set`インスタンスを作成することに注意しましょう。
このインスタンスに対して`add`や`remove`のようなメソッドを呼び出そうとすると、実行時に例外が発生します。

変更可能な`Set`を作るには、`Set`インターフェースを実装したクラスをインスタンス化する必要があります。
このインターフェースを実装する最もよく使われる標準クラスが、[`HashSet`][hashset-docs]クラスです。

```java
Set<Integer> ints = new HashSet<>();
```

`Set`インターフェースは[`Collection`][collection-docs]インターフェースと[`Iterable`][iterable-docs]インターフェースを継承しているため、他の種類のコレクションと多くのメソッドを共有しています。
ただし、`Collection`インターフェースとの大きな違いは、`add`や`remove`のようなメソッドが（`void`ではなく）`boolean`を返す点です。これは、そのメソッドを呼び出した時点で要素がセットに含まれていたかどうかを示します。

```java
Set<Integer> set = new HashSet<>();
set.add(1);
// => true
set.add(2);
// => true
set.add(1);
// => false
set.size();
// => 2
set.contains(1);
// => true
set.contains(3);
// => false
set.remove(3);
// => false
set.remove(2);
// => true
set.size();
// => 1
```
