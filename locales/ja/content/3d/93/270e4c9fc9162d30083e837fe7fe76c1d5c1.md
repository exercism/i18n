# 説明

この演習では、熱心なバードウォッチャーとして、過去7日間に庭に何羽の鳥が訪れたかを記録します。庭に訪れた鳥の数に関する、5つのタスクに取り組みます。

## 1. 先週の記録を確認する

比較のため、先週の記録をいつも手元に控えてあります。先週の記録は、0、2、5、3、7、8、4でした。先週の記録を返す`BirdCount.last_week`メソッドを実装しましょう。

```ruby
BirdCount.last_week
# => [0, 2, 5, 3, 7, 8, 4]
```

## 2. 昨日訪れた鳥の数を確認する

昨日庭に訪れた鳥の数を返す`BirdCount#yesterday`メソッドを実装しましょう。鳥の数は日付順に並んでいて、最初の要素が最も古い日の数、最後の要素が今日の数です。

```ruby
birds_per_day = [2, 5, 0, 7, 4, 1]
bird_count = BirdCount.new(birds_per_day)
bird_count.yesterday
# => 4
```

## 3. 訪れた鳥の合計数を計算する

庭に訪れた鳥の合計数を返す`BirdCount#total`メソッドを実装しましょう。

```ruby
birds_per_day = [2, 5, 0, 7, 4, 1]
bird_count = BirdCount.new(birds_per_day)
bird_count.total
# => 19
```

## 4. 忙しい日の数を計算する

日によって、鳥が多く訪れる日もあれば少ない日もあります。忙しい日とは、庭に5羽以上の鳥が訪れた日のことです。
忙しい日の数を返す`BirdCount#busy_days`メソッドを実装しましょう。

```ruby
birds_per_day = [2, 5, 0, 7, 4, 1]
bird_count = BirdCount.new(birds_per_day)
bird_count.busy_days
# => 2
```

## 5. 鳥が1羽も訪れなかった日があったか確認する

庭に鳥が1羽も訪れなかった日があれば`true`を、そうでなければ`false`を返す`BirdCount#day_without_birds?`メソッドを実装しましょう。

```ruby
birds_per_day = [2, 5, 0, 7, 4, 1]
bird_count = BirdCount.new(birds_per_day)
bird_count.day_without_birds?
# => true
```
