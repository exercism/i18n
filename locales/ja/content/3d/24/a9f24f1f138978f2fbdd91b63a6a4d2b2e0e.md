# はじめに

## 基本

F#では、値に名前を割り当てることを_束縛_と呼びます。束縛は不変なので、他の言語の定数に似ています。F#は静的型付け言語であるため、各束縛はコンパイル時に型を持ちます。

束縛は`let`キーワードを使って定義します。ほとんどの束縛では、束縛の型を指定する必要はありません。F#の_型推論_が通常、その値に基づいて型を推論できるためです。束縛は次のようになります。

```fsharp
// Automatically inferred type
let fingers = 10
```

関数も通常の束縛ですが、1つ以上の仮引数を持ちます。関数は最後の式を自動的に返します。型推論はほとんどの関数でも機能し、関数がどのような値で呼び出されるか、どのような値を返すかを分析します。

```fsharp
// Automatically inferred types for parameters and return type
let add x y = x + y
```

関数を呼び出すには、その名前を指定し、関数の仮引数それぞれに引数を渡します。

```fsharp
let five = add 2 3
```

束縛の型を推論できない場合、コンパイラーがエラーを報告します。これを修正するには、束縛に明示的な型注釈を追加します。

```fsharp
// Explicit type annotation
let fingers: int = 10

// Explicit type annotation (also for parameters)
let add (x: int) (y: int): int = x + y
```

F#の束縛は、定義された_後_でのみ使用できます。定義前に束縛を使用すると、コンパイルエラーになります。

```fsharp
// Compile error as the add binding has not yet been defined
// let seven = add 3 4

let add x y = x + y
```

F#では、スコープを定義するために空白に意味を持たせます。つまり、束縛を宣言する行を基準にして、コードをスペースでインデントすることでスコープが定義されます。既定の慣習では、インデントに4つのスペースを使います。

```fsharp
let toes =
    let left = 5
    let right = 5
    left + right

let multiplyPlusTwo x y =
    let product = x * y
    product + 2

// Trying to access the left, right or product bindings
// here would result in a compile error
```

F#の束縛（関数も含まれます）は通常、モジュールにまとめられます。モジュールは関連する機能をまとめ、`module`キーワードを使って定義します。モジュール定義は、その束縛より前に置く必要があります。

```fsharp
module Calculator

let pi = 3.14

let add x y = x + y
```

F#では2種類のコメントが使えます。1行コメントは`//`で始まり、複数行コメントは`(*`と`*)`の間に書きます。
