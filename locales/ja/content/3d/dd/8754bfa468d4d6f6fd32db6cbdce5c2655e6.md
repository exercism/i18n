# 説明

事件が進むにつれて探偵の手帳は書き込みで埋まっていき、調べる手がかりが消えていくにつれて、また空になっていきます。

5つのタスクはすべて、`CASE_NOTES`クラスの中に書きます。

## 1. 事件を始める

新しい空の手帳を返します。

```sather
notes ::= CASE_NOTES::new_case;
notes.size
-- => 0
```

## 2. 手がかりを書き留める

手帳の末尾に手がかりを追加します。これは何も返しません。渡された手帳そのものを書き換えるんです。

```sather
CASE_NOTES::add_clue(notes, "muddy boots");
notes.size
-- => 1
```

## 3. 手がかりはいくつある？

```sather
CASE_NOTES::clue_count(notes)
-- => 1
```

## 4. 1つを除外する

指定した位置にある手がかりを手帳から取り除きます。それより後ろの手がかりはすべて1つ前に詰まります。これも何も返しません。

```sather
CASE_NOTES::rule_out(notes, 0);
```

## 5. 事件を読み返す

手帳にあるすべての手がかりを`"; "`でつないで返します。空の手帳は空の文字列として読み取られます。

```sather
CASE_NOTES::summary(notes)
-- => "muddy boots; broken window"
```
