# はじめに

Haxeは、型とフィールドの実行時リフレクションをサポートしています。リフレクションを正しく使うには、どのような操作がサポートされていて、どのような操作がサポートされていないのかを理解しておく必要があります。リフレクションは動的な性質を持つため、コンパイル時に常に判断できるとは限りません。

リフレクションのAPIは、2つのクラスから構成されています。

- `Reflect`：軽量なAPIで、匿名構造体に対して最もよく機能し、クラスへの対応は限定的です。
- `Type`：クラスと列挙型を扱うための、より堅牢なAPIです。

次の例では、JavaScriptのターゲットを使っています。

```haxe
class Main {
  public static function main() {
    trace(Type.resolveClass("Main"));
  }
}

// This outputs
// class Test { static main() { console.log("Test.hx:3:",$hxClasses["Test"]); } }
```
