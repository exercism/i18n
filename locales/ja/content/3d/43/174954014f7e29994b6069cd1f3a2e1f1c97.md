# 学習

Vimには、優れたドキュメントが最初から組み込まれています。ドキュメントを読むためのインターフェースは、`:help`コマンドです。

入門編については、`:h user-manual`を見てください。

ほとんどすべてのVimには、対話形式のチュートリアルも付属しています。

```
$ vimtutor
```

Vimは登場から何十年も経っていますが、今でも人気があります。ウェブ上にはVimについての情報がたくさんあり、内容には良し悪しがあります。優れたものは[こちら](https://exercism.org/docs/tracks/vimscript/resources)にまとめられています。
