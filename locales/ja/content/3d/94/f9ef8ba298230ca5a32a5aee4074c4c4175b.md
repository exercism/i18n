# はじめに


## 真偽値

PowerShellには、真偽の値を表す[`bool`][booleans]型があります。この型が持つ値は`True`と`False`の2つだけです。これらの値は、頭に`$`を付けた変数に代入できます。

```powershell
> $TrueVar  = $true
> $FalseVar = $FALSE
#Case senstitivity doesn't matter here
```

`-and`、`-or`、`-not`のような[論理演算子][logical-operators]を使うと、真偽値の式を組み合わせて評価できます。

```powershell
> $TrueVar  = $true -and $true
> $FalseVar = $true -and $false

> $TrueVar  = $true -or $false
> $FalseVar = $false -or $false

> $TrueVar  = -not $false
> $FalseVar = -not $true
```


## コメントベースのヘルプ

PowerShellの[`Comment-based help`][comment-based help]を使うと、コメントに書いた関数やスクリプトについて、詳しい情報を提供できます。注目する話題を指定するには、`.SYNOPSIS`、`.EXAMPLE`、`.NOTES`といった特別なヘルプコメントのキーワードを使います。

```powershell
function ExampleFunction($Arg) {
    <#
    .DESCRIPTION
    A detailed description of the function or script. This keyword can be used only once in each topic.

    .PARAMETER Arg
    The description of a parameter, it must be follow with the parameter name.
    #>
}
```

コメントベースのヘルプの情報は、コマンドレット`Get-Help`で表示できます。

```powershell
> Get-Help -Name "ExampleFunction"
```
