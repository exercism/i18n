# テスト

## clojure.test

Babashkaにはclojure.testが同梱されています。演習に取り組む準備ができ、解答を保存するファイル（`bob.clj`など）を作成したら、[ここで説明されているように](http://clojure.github.io/clojure/clojure.test-api.html#clojure.test/run-tests)`clojure.test/run-tests`を使ってテストを実行できます。


REPLを使うと、コードを手軽に実行してすぐにフィードバックを得られるほか、テストの実行にも使えます。上下の矢印キーで行編集とコマンド履歴を使えるようにするために、`rlwrap`の使用をおすすめします。演習をテストするには、そのディレクトリに移動し、`src`ディレクトリと`test`ディレクトリをクラスパスに追加してソケットREPLを開きます。
``` bash
/bob $ rlwrap bb --classpath src:test socket-repl 1666
```

まず、テストの名前空間を`require`します。
``` clojure
=> (require 'bob-test)
nil
```

次に、`bob-test`に対して`run-tests`を呼び出します。
``` clojure
=> (clojure.test/run-tests 'bob-test)

Testing bob-test

Ran 25 tests containing 25 assertions.
0 failures, 0 errors.
{:test 25, :pass 25, :fail 0, :error 0, :type :summary}
```

テストランナーのスクリプトを作成するには:

``` clojure
#!/usr/bin/env bb

(require '[clojure.test :as t]
         '[babashka.classpath :as cp])

(cp/add-classpath "src:test")                        

(require 'bob-test)                  

(def test-results
  (t/run-tests 'bob-test))           

(def failures-and-errors
  (let [{:keys [:fail :error]} test-results]
    (+ fail error)))                                 

(System/exit failures-and-errors)
```
