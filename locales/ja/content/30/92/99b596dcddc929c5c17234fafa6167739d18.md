# 説明

この演習では、2012年9月15日にオープンしたニューヨークの美容サロン向けの、予約スケジューラーに取り組みます。

タスクは5つあり、どれも予約の日付を扱います。
時刻は24時間表記です（AM/PMは使いません）。

## 1. 数字だけの予約日付を解析する

`schedule_appointment()`関数を実装して、テキストで書かれた予約日付を対応する`DateTime`形式に解析しましょう。

入力はアメリカ式の月/日/年の順であることに注意してください。

```julia-repl
julia> schedule_appointment("07/25/2023 13:45:00")
2023-07-25T13:45:00
```

## 2. 予約がすでに過ぎているかどうかを確認する

`has_passed()`関数を実装しましょう。この関数は予約日付を受け取り、その予約が過去のものかどうかを確認します。

```julia-repl
julia> has_passed(DateTime(1999, 12, 31, 9, 0, 0))
true
```

## 3. 予約が午後かどうかを確認する

`is_afternoon_appointment()`関数を実装しましょう。この関数は予約日付を受け取り、その予約が午後（12:00以降、18:00より前）かどうかを確認します。

```julia-repl
julia> is_afternoon_appointment(DateTime(2023, 3, 29, 15, 0, 0))
true
```

## 4. 予約の日時を説明する

`description()`関数を実装しましょう。この関数は予約日付を受け取り、その日時の説明を返します。

```julia-repl
julia> describe(DateTime(2023, 3, 29, 15, 0, 0))
"You have an appointment on Wednesday, March 29, 2023 at 15:00"
```

## 5. 記念日を返す

`anniversary_date()`関数を実装しましょう。この関数は今年の記念日、つまり9月15日を返します。

```julia-repl
julia> anniversary_date()  # run during 2025
2025-09-15
```
