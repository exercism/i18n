# 概要

`assocs`は単一のデータ型ではなく、[プロトコル][assoc-protocol]です。ハッシュテーブル（`H{ }`）、連想リスト（`{ key value }`のペアの並び）、ツリーマップは、どれもこのプロトコルを実装しています。そのため、`assocs`のワードの多くは、これらの中でそのまま使い回すことができます。

```factor
USING: assocs ;

H{ } clone "coal" over inc-at
"coal" over inc-at
"wood" over inc-at      ! => H{ { "coal" 2 } { "wood" 1 } }
```

`assocs`に用意されているワードは多岐にわたります。ソート順の繰り返し、マッピング、フィルタリングなどがありますが、演習で使うのはごく一部のワードです。

| ワード      | スタック効果                                  |
|-------------|-----------------------------------------------|
| `at`        | `( key assoc -- value/f )`                    |
| `at*`       | `( key assoc -- value ? )`（値が`f`の場合と、キーが存在しない場合を区別します） |
| `key?`      | `( key assoc -- ? )`                          |
| `set-at`    | `( value key assoc -- )`（assocを書き換えます） |
| `change-at` | `( key assoc quot -- )`（`quot`は`( old -- new )`です） |
| `inc-at`    | `( key assoc -- )`（`+1`します。キーがなければ`1`を挿入します） |
| `delete-at` | `( key assoc -- )`（assocを書き換えます）     |
| `>alist`    | `( assoc -- pairs )`                          |

`sort-keys`と`sort-values`（`sorting`にあります）は、選んだフィールドで連想リストをソートします。

[assoc-protocol]: https://docs.factorcode.org/content/article-assocs-protocol.html
