# はじめに

## 関数型

Swiftの関数シグネチャから名前とラベルをすべて取り除くと、その関数の型が残ります。

```swift
func shoppingList(item: String, quantity: Int) -> String {
  "You need to buy \(quantity) \(item)."
}
// shoppingList: (String, Int) -> String

func repeater(_ phrase: String, times: Int) -> String {
  var result = ""
  for _ in 1...times {
    result += phrase
  }
  return result
}
// repeater: (String, Int) -> String

func printString(line: String) {
  print(line)
}
// printString: (String) -> ()
```

最初の2つの関数の型が同じ`(String, Int) -> String`であることに注目してください。シグネチャは異なり、2つの関数の働きも大きく違いますが、型は同じです。どちらも`String`と`Int`を入力として受け取り、`String`を返します。そして、3つ目の関数の型からわかるように、その関数本体は何も返していないように見えても、実際には暗黙的に`()`を返しています。`()`は`Void`型の唯一の値です。

これらの関数型は、Swiftの他の型とまったく同じように使えます。たとえば、変数や定数の宣言に使うことができます。また、Swiftでは関数も値なので、すでにある関数をこれらの定数や変数に代入できます。

```swift
var stringAndIntToString: (String, Int) -> String

stringAndIntToString = shoppingList
stringAndIntToString("carrots", 3)
// => "You need to buy 3 carrots."
```

他の変数や定数と同じく、代入する値は正しい型でなければなりません。

```swift
stringAndIntToString = printShoppingList
// Error: Cannot assign value of type '(String) -> ()' to type '(String, Int) -> String'
```

### 仮引数の型としての関数型

関数型は他の型が使えるところならどこでも使えるので、当然、仮引数の型としても使えます。他の関数に渡して、その関数の中で呼び出すこともできます。

```swift
func apply3(to str: String, function f: (String, Int) -> String) -> String {
  f(str,3)
}
// apply3: ([String], (String, Int) -> String) -> [String]

apply3(to: "eggs", function: shoppingList)
// => "You need to buy 3 eggs."

apply3(to: "eggs", function: repeater)
// => "eggseggseggs"
```

## 戻り値の型としての関数型

同じように、関数型は関数の戻り値の型としても使えます。つまり、他の関数を作って返す関数を書くことができます。こうした関数を作るとき、返される関数は、親の関数に渡された他の仮引数や、親の関数の中で作られたローカル変数を使うことができます。

```swift
func makeAdder(base: Int) -> (Int) -> Int {
  func adder(_ i: Int) -> Int {
    base + i
  }
  return adder
}
// makeAdder: (Int) -> (Int) -> Int

let add10 = makeAdder(base: 10)
// add10: (Int) -> Int

let subtract20 = makeAdder(base: -20)
// subtract10: (Int) -> Int

add10(5)
// => 15

subtract20(5)
// => -15
```
