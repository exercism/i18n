# はじめに

Clojureでは、値に名前を結びつけることを_var_と呼びます。トップレベル（グローバル）のvarは、他の言語の定数に似ていますが、動的な開発をしやすくするために、よく再定義されます。

トップレベルのvarは、`def`を使って定義します。

```clojure
(def fingers 10)
```

`defn`マクロを使うと、0個以上の引数を取る関数を定義できます。関数は、必ず本体の最後の式の結果を返します。

```clojure
(defn add [x y]
  (+ x y))
```

関数を呼び出すには、その名前を指定し、関数の各仮引数に引数を渡します。

```clojure
(def five (add 2 3))
```

Clojureの関数や値は、定義した_後_にしか使えません。定義する前に使うと、コンパイルエラーになります。

```clojure
;; Compile error as `add` has not yet been defined
(def seven (add 3 4))

(defn add [x y]
  (+ x y))
```

Clojureでは、空白文字は整形以外の意味を持ちません。

Clojureの関数とvarは、名前空間にまとめられています。名前空間は、関連する機能をひとつにまとめるもので、`ns`マクロを使って定義します。

```clojure
(ns calculator)

(def pi 3.14)

(defn add [x y]
  (+ x y))
```

Clojureでは、2種類のコメントを書けます。1行コメントは`;`で始めます。また、`comment`フォームは、`(comment`と`)`の間にあるすべての式を評価しないようにするために使います。
