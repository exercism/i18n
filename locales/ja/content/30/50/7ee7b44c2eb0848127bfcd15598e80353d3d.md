# 説明の補足

## ヒント

この演習を完了するには、ボウリングの一連の*投球*を受け取り、最終スコアか、適切なエラーを返す関数`score`を実装する必要があります：

```haskell
score :: [Int] -> Either BowlingError Int

data BowlingError = IncompleteGame
                  | InvalidRoll { rollIndex :: Int, rollValue :: Int }
                  deriving (Eq, Show)
```

これらの定義はすでに用意されていますが、関数を定義するのはみなさん自身です。

テストスイートでは、投球の番号が0から始まることを前提にしている点に注意してください。
