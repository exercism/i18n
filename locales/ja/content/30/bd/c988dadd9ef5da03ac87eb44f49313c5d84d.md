# 説明

この演習では、ラップタイムを正確に記録するストップウォッチを作ります。

ストップウォッチは4つのコマンド（start、stop、lap、reset）を使って、次の2つを記録します。

1. 現在のラップの計測時間
2. それまでに記録されたラップタイム

使えるコマンドは、ストップウォッチがどの状態にあるかによって変わります。

1. Ready：初期状態
2. Running：時間を計測中
3. Stopped：時間を計測していない状態

| コマンド | 開始時の状態 | 終了時の状態 | 効果                                                     |
| ------- | ----------- | --------- | -------------------------------------------------------- |
| Start   | Ready       | Running   | 時間の計測を開始する                                      |
| Start   | Stopped     | Running   | 時間の計測を再開する                                     |
| Stop    | Running     | Stopped   | 時間の計測を止める                                        |
| Lap     | Running     | Running   | 現在のラップをそれまでのラップに追加し、現在のラップをリセットする |
| Reset   | Stopped     | Ready     | 現在のラップをリセットし、それまでのラップを消去する        |
